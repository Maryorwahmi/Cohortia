Practice Prompts
  • Declare and initialize an int, a double, and a char, then print them.
  • Choose types for a small user profile and explain your choices in comments.
  • Refactor constants such as PI into const double and attempt to reassign to see the compiler error.
  • Compute an expression mixing multiplication and division; show how parentheses change the result.
Verification Hints
Compile early and often. If you observe garbage values, you likely used an uninitialized variable. If integer division truncates, cast one operand to a floating type to get a precise result. When mixing formatted extraction with full-line reads, use the input ignore call to clear the leftover newline.
Mnemonic & Tip
Remember: Initialize, Prefer the right type, Protect constants, and Check I/O boundaries. Small tests prove correctness quickly.
