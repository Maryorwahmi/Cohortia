Module 1 › Chapter 1.2 › const Keyword
What const Does
const prevents reassignment after initialization. It documents invariants and lets the compiler enforce them at compile time.
Example
const double PI = 3.14159; // PI cannot be changed later
Common Mistake
Trying to assign to a const causes a compile-time error. Use that error as guidance to protect invariants.
Illustrative Code
#include <iostream>
int main() {
  const double PI = 3.14159;
  // PI = 3.14; // compile-time error: assignment of read-only variable
  std::cout << "PI = " << PI << std::endl;
  return 0;
}
Practical Advice
Mark values const when they are truly fixed. This reduces bugs and makes code contracts explicit to readers and the compiler.
