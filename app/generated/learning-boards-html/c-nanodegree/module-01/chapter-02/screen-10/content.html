Module 1 › Chapter 1.2 › std::cin & std::cout
How It Works
std::cin reads formatted data until whitespace. std::getline reads the remainder of a line including spaces. Use ignore to remove a leftover newline.
Common Pitfall
Mixing operator>> with getline without clearing the newline leads to an immediate empty line read. Use std::cin.ignore(1000, ' ') to clear it.
Code Example
#include <iostream>
#include <string>

int main() {
  int userAge;
  std::cout << "Please enter your age: ";
  std::cin >> userAge; // reads integer

  // clear leftover newline before a getline
  std::cin.ignore(1000, '
');

  std::string name;
  std::cout << "Please enter your full name: ";
  std::getline(std::cin, name); // reads the whole line including spaces

  std::cout << "Hello, " << name << "! You are " << userAge << " years old." << std::endl;
  return 0;
}
Practical Test
Try entering a number and then a full name. If the name is empty, you likely forgot the ignore step.
