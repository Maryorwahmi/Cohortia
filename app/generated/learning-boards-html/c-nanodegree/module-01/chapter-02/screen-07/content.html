Module 1 › Chapter 1.2 › Char & Bool
Char
Stores a single character like 'A'. Internally a small integer; use string for sequences of characters.
Example
char grade = 'A'; // stores one character
Caution
Do not treat char as a string. Use std::string when you need multiple characters or human-readable text.
Bool
Represents true or false. Use for flags, conditions, and clear intent in boolean logic.
Example
bool isActive = true; // use in conditionals like if (isActive) { ... }
Conversion Note
An integer converts to bool: zero becomes false, nonzero becomes true. Make such conversions explicit when clarity matters.
