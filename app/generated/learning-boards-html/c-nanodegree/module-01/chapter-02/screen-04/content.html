Module 1 › Chapter 1.2 › Variables & Types
Definition
A variable is a named storage slot. The data type determines size and valid operations. Initialize to avoid garbage values.
Explanation
  • Types reserve a fixed number of bytes and set allowed operations.
  • Choosing the wrong type can cause truncation or wasted memory.
  • Uninitialized variables hold unpredictable values; always initialize when possible.
Key Takeaway
Think about range and precision before picking a type; initialize immediately.
Memory View — Example Variables
int age = 30;
range: approx -2 billion to +2 billion · size ~4 bytes
double price = 19.99;
precision: ~15 decimal digits · size ~8 bytes
char grade = 'A';
stores a single character as a small integer · size ~1 byte
bool isActive = true;
represents truth values, use true or false
Common Mistake
Declaring without initializing leads to garbage values. Example: int x; then reading x before assignment is undefined behavior.
