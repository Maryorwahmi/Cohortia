Module 1 › Chapter 1.2 › What to Remember
Variables
Named storage with a type; initialize to avoid garbage values.
Types
int, float/double, char, bool — choose based on range and precision.
const
Make values immutable to document intent and let the compiler enforce stability.
Summary Takeaway

Good type choices and initialization prevent many bugs. Use const for invariants, cast before floating division, and manage input buffers when mixing input styles to build reliable programs.
