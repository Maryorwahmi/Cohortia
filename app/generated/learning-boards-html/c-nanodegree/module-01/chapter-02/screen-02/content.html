Why these objectives matter

Correct declarations and type choices prevent bugs and surprising behavior. Using const makes code easier to reason about. Proper I/O and operator use lets your programs interact with users and compute accurate results.

Mnemonic
Think: Declare, Initialize, Validate, Protect — D I V P.
Quick Check
Can you write an int and a double, initialize both, and print a calculation that mixes them? That confirms progress toward these objectives.
