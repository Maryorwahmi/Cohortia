Integer Types
Use short, int, long, or long long depending on range and memory trade-offs. Use unsigned for non-negative-only values.
Example: Counter
unsigned int count = 0; // good when count never negative
Example: Large IDs
long long id = 9223372036854775807; // when values exceed 32-bit range
Caution
Mixing signed and unsigned may produce unexpected large positive numbers due to implicit conversions. Prefer consistent signedness in expressions.
Visual Comparison
int x = -10;
signed: stores negative and positive values
unsigned int y = 10;
unsigned: stores 0 and up, larger positive range
Practical Tip
When in doubt, use signed int for general logic; constrain to unsigned only when the domain is guaranteed non-negative and conversions are managed carefully.
