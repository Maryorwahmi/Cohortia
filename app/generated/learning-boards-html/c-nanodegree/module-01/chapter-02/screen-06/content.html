Floating-Point Types
float for lower precision, double for most use cases, long double for extended precision when available.
Example: Precise Division
double a = 10.0; double b = 3.0; // result ~3.3333333
Common Mistake
Using float for high-precision needs like finance can introduce rounding errors. Consider double or fixed-point techniques for exactness.
Pro Tip
Default to double unless memory or ABI requires float. Use long double only when precision needs exceed double and performance is acceptable.
Precision Illustration
Accumulated Rounding Example
Adding 0.1 repeatedly in float may lose the final increments due to binary representation inexactness. Use double for smaller error accumulation.
Why It Matters
Numerical algorithms and measurement code depend on predictable precision. Choosing the wrong type can silently degrade results.
