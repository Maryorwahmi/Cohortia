Operators Overview
  • Addition, subtraction, multiplication, division, modulo for integers.
  • Compound assignments: +=, -=, *=, /=, %= for compact updates.
  • Precedence: multiplication/division before addition/subtraction unless parentheses change order.
Rule
If you need a fractional result, make at least one operand a floating-point value or cast before dividing.
Side-by-Side Example
Integer division
int a = 10;
int b = 3;
double result1 = a / b; // result1 becomes 3.0 because a/b performs integer division
Floating division
double precise = static_cast(a) / b; // precise becomes 3.333...
Takeaway
Cast before the operation if precision is required. Parentheses control grouping when precedence alone is ambiguous.
