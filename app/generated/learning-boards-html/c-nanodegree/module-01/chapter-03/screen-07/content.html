Core Concept Logical Operators: AND, OR, NOT

Combine simple comparisons into clear rules

How they work
  • AND (&&): both sides must be true.
  • OR (||): at least one side must be true.
  • NOT (!): flips the boolean result.
Pro tip
Name intermediate results, for example isAdult and hasLicense, then combine them. This documents intent and simplifies testing.
Examples and short-circuit behavior
int age = 20;
bool hasLicense = true;

if (age >= 18 && hasLicense) {
  std::cout << "Eligible to drive." << std::endl;
}

bool isRaining = false;
if (!isRaining) {
  std::cout << "Let's go outside!" << std::endl;
}
Key Takeaway

Short-circuiting can prevent code on the right side from running. Use that intentionally and avoid side effects in conditions.
