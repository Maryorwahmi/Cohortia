Core Concept while loops and infinite-loop risk

Pre-condition checks and safe termination

When to use while
  • When iteration count depends on dynamic conditions.
  • When input or external state determines when to stop.
  • When you need to check the condition before the first iteration.
Warning
If the condition never becomes false, the loop will run forever. Add counters or sanity checks for safety.
Example
int count = 0;
while (count < 3) {
  std::cout << "While loop iteration: " << count << std::endl;
  count++;
}

// If the condition starts false, the body never runs.
int start = 10;
while (start < 5) {
  // this code is skipped
}
Check your understanding

Identify the variable(s) that must change each iteration. If they can fail to change, add a guard or counter.
