Definition if, else if, else — building decision chains

Sequential checks, nesting, and readable fallbacks

Explanation

A chain evaluates each condition in order. The first true condition executes its block and the rest are skipped. Use else to handle everything else explicitly.

  • Order tests from strict to broad to avoid accidental matches.
  • Keep nested ifs for cases where a subsequent test only makes sense when the earlier one is true.
  • Test with boundary values to catch off-by-one errors.
Common mistake
Checking overlapping ranges in the wrong order can produce incorrect grades. Always place the highest threshold first.
Code example — trace with values
#include <iostream>

int main() {
  int score = 85;
  bool isStudent = true;

  if (score >= 90) {
    std::cout << "Grade: A" << std::endl;
  } else if (score >= 80) {
    std::cout << "Grade: B" << std::endl;
  } else if (score >= 70) {
    std::cout << "Grade: C" << std::endl;
  } else {
    std::cout << "Grade: F" << std::endl;
  }

  if (score >= 60) {
    if (isStudent) {
      std::cout << "Passed as a student." << std::endl;
    } else {
      std::cout << "Passed." << std::endl;
    }
  }
  return 0;
}
Key Takeaway

When ranges overlap, ordering decides which branch runs. Trace a few example inputs to confirm behavior.
