Core Concept break and continue — altering loop flow

Exit early or skip to the next iteration intentionally

When to use each
  • break: when you can finish the loop early, e.g., a successful search.
  • continue: when this iteration has nothing to do and you should move on.
  • Always ensure updates that affect the loop condition still occur or termination may fail.
Analogy
Think of break as walking out of a meeting when the decision is made; continue is skipping one agenda item and moving to the next.
Examples
// Example with break
for (int i = 0; i < 10; ++i) {
  if (i == 5) {
    break; // Exit when i is 5
  }
  std::cout << i << " ";
}

// Example with continue
for (int i = 0; i < 5; ++i) {
  if (i == 2) {
    continue; // Skip printing for i == 2
  }
  std::cout << i << " ";
}
Key Takeaway

Use break and continue deliberately. Always reason about how they affect loop termination and variable updates.
