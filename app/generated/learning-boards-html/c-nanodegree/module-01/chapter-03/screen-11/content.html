Core Concept do-while — run once, then check

Guarantee a single execution before condition testing

Use case

Input validation that requires an initial prompt is the canonical use. Validate that the input becomes valid; otherwise repeat the prompt.

Example scenario
Ask a user for a positive integer. The prompt and read happen at least once; the condition then checks positivity and repeats until valid.
Code examples
int k = 0;
do {
  std::cout << "Do-while loop iteration: " << k << std::endl;
  k++;
} while (k < 3);

int m = 5;
do {
  std::cout << "This will run once even though m < 3 is false." << std::endl;
} while (m < 3);
Key Takeaway

Use do-while when a single initial action must always occur. Otherwise prefer while for a pre-checked loop.
