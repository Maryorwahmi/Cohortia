Bloom: Learn → Understand → Apply → Master
01
Implement if / else chains

Write decisions using if, else if, and else to run different code based on boolean conditions. This lets your program respond to input and state changes without duplicated code.

VERIFIED COMPETENCY MILESTONE
02
Use logical operators

Combine comparisons with AND, OR, and NOT so conditions are expressive and correct. This reduces nested checks and improves readability.

VERIFIED COMPETENCY MILESTONE
03
Employ switch branching

Use switch for discrete value selection. Remember to include break to avoid fall-through unless fall-through is intentional.

VERIFIED COMPETENCY MILESTONE
04
Build reliable loops

Create for, while, and do-while loops for repeated work. Control loops with break and continue, and watch for off-by-one and infinite-loop mistakes.
