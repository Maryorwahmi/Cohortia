Bloom: Learn → Understand → Apply → Master
05
Control loop execution
break / continue

Learn when to exit a loop early and when to skip just this iteration. Use break to stop when a condition is satisfied; use continue to ignore the rest of the iteration and re-evaluate the loop condition.

VERIFIED COMPETENCY MILESTONE
06
Comparison operators
== != < >

Use equality and relational operators to build boolean conditions. Make comparisons explicit to avoid accidental assignments in conditional contexts.

VERIFIED COMPETENCY MILESTONE
07
Avoid common mistakes
Off-by-one / infinite loop

Trace boundaries, test edge values, and check loop termination conditions to prevent off-by-one errors and infinite loops that hang programs.

VERIFIED COMPETENCY MILESTONE
08
Apply to real programs
Menu-driven apps

Combine loops and switch to build menus that repeat until the user exits, validating input and handling invalid choices gracefully.
