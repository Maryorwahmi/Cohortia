Core Concept Comparison Operators and Conditions

Building boolean expressions with comparisons

Operators to know
  • == equal to
  • != not equal to
  • < less than, > greater than
  • <= less than or equal, >= greater than or equal
Concrete example
If you check age >= 18 AND hasLicense equals true, both conditions must be satisfied to allow driving. Test exact boundary values like 18 and 17.
Short code snippets
int age = 20;
bool hasLicense = true;

if (age >= 18 && hasLicense) {
  std::cout << "Eligible to drive." << std::endl;
}

std::string day = "Sunday";
if (day == "Saturday" || day == "Sunday") {
  std::cout << "It's the weekend!" << std::endl;
}
Check this

Always ask whether the boundary should be inclusive or exclusive. That decision prevents many bugs.
