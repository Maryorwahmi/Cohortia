Process Flow for loops — counted iteration and common off-by-one traps

Initialization, condition, and update in three parts

When to use for
  • When the number of iterations is known or computed beforehand.
  • When you want the loop variable scoped to the loop header.
  • When you need a compact, readable iteration pattern.
Off-by-one check
Check the start, the condition, and the update so that the first and last values are exactly what you expect.
Examples
// Print numbers from 1 to 5
for (int i = 1; i <= 5; ++i) {
  std::cout << i << " ";
}
std::cout << std::endl; // Output: 1 2 3 4 5

// Iterate backwards
for (int j = 5; j > 0; --j) {
  std::cout << j << " ";
}
std::cout << std::endl; // Output: 5 4 3 2 1
Key Takeaway

For loops are concise and clear; confirm inclusive or exclusive bounds by tracing the first and last iterations with sample values.
