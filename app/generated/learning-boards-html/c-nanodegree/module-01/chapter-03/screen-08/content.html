Definition switch — multi-way branching

Readable handling of discrete values and fall-through risks

When to prefer switch
  • Many branches testing the same variable against literal values.
  • Menu selections keyed by integers or enums.
  • When a clear default action is needed for unmatched values.
Common mistake
Missing break causes fall-through. Fall-through executes subsequent cases and often produces wrong outputs.
Code example — watch for break
int choice = 2;

switch (choice) {
  case 1:
    std::cout << "You chose option 1." << std::endl;
    break;
  case 2:
    std::cout << "You chose option 2." << std::endl;
    break;
  case 3:
    std::cout << "You chose option 3." << std::endl;
    break;
  default:
    std::cout << "Invalid choice." << std::endl;
    break;
}
Key Takeaway

Refactor long else-if ladders into switch when testing one value against many constants. Always deliberate about break and fall-through.
