Core Concept What is Control Flow?

How execution paths and repetition change program behavior

Definition and purpose

Control flow controls which blocks of code run and how many times. Use it to react to input, validate data, and repeat tasks without duplicating code.

  • Conditionals pick between branches based on boolean expressions.
  • Loops repeat a block until a condition fails or a count completes.
  • Flow-control statements alter loop progress without changing the loop header.
Example
Assign letter grades by checking numeric score ranges with chained if statements.
Common mistake
Omitting an else fallback can leave some inputs unhandled, producing no output or incorrect behavior.
Trace example
// Grade decision example
int score = 85;
if (score >= 90) {
  // Grade A
} else if (score >= 80) {
  // Grade B
} else if (score >= 70) {
  // Grade C
} else {
  // Grade F
}
Key Takeaway

Think in terms of conditions that must change to move between branches or stop a loop. Trace edge values to prevent errors.
