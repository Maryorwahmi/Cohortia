Headers and output explained
#include <iostream>
Provides declarations for standard streams used for input and output operations. Omitting it leads to undeclared identifier errors for std::cout.
Analogy: think of the header as a recipe card that tells the compiler what tools are available.
std::cout and std::endl
std::cout sends text to the console. std::endl writes a newline and flushes the stream so output appears immediately.
Best practice: use explicit std:: to avoid namespace collisions as projects grow.
Concrete example
std::cout << "Hello, Cohortia!" << std::endl; prints the greeting and ensures the line ends and the buffer flushes so the output appears right away.
