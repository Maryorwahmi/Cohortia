Definition
CMake and the role of build automation
Why use a build system
  • Coordinates compilation of many files and libraries.
  • Encodes platform-specific flags so builds are reproducible.
  • Makes CI and cross-platform builds manageable.
Practical note
For our initial exercises you will compile single files directly. Keep CMake in mind when your project grows or when you need consistent builds across systems.
Analogy: a build system is like a kitchen manager that ensures all dishes are prepared and plated correctly for a large dinner service.
Key Takeaway

Start with direct compilation, and adopt CMake or another build system when you need automation for many files or continuous integration.
