Source code (copy exactly)
#include <iostream> // Include the input/output stream library

int main() { // The main function, entry point of every C++ program
    // Print "Hello, Cohortia!" to the console, followed by a newline
    std::cout << "Hello, Cohortia!" << std::endl; 
    return 0; // Indicate successful execution
}
Explanation
  • #include <iostream> brings in the standard input/output utilities used by std::cout.
  • int main() is the single entry point where execution begins and a status code is returned.
  • std::cout << ... writes output to the console; std::endl inserts a newline and flushes output.
Concrete tip: Keep the std:: prefix to avoid namespace collisions in larger projects.
Key Takeaway

This minimal program demonstrates the essential structure you need to compile and run code successfully.
