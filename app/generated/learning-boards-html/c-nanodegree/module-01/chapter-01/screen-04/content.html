Process Flow
Source → Compiler → Object → Linker → Executable
Stages and what they produce
Preprocessing
Handles directives like #include and macro expansion. Produces code ready for compilation.
Compilation
Transforms preprocessed code into assembly or intermediate object representation.
Linking
Combines object files and libraries into a runnable executable.
Example
Running g++ hello_cohortia.cpp -o hello_cohortia triggers all stages for a single source file, producing an executable named hello_cohortia.
Troubleshooting hints
  • Preprocessor errors often mention missing headers or invalid directives.
  • Compilation errors point to syntax problems and undeclared identifiers.
  • Linker errors indicate missing function definitions or library links.
Key Takeaway
Break failures down by compilation stage to find the root cause faster.
Check your assumption
If the compiler cannot find a header, don’t assume code is wrong—verify include paths and installed SDKs first.
