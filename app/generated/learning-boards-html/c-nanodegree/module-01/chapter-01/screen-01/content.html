Orientation

This chapter teaches the essential tools and steps to take source code and produce a running program. You will install or verify a compiler, pick an IDE, edit a file, compile with g++ or clang++, and execute the resulting program. Along the way we discuss common errors and how to fix them.

In this lesson
  • Install and confirm a compiler (g++ or clang++)
  • Use an IDE like VS Code for editing and terminal access
  • Compile and run a first program and learn basic troubleshooting
