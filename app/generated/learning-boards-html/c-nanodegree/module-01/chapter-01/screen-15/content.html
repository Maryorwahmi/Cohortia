Module 1 › Chapter 1.1 › What to Remember
main()
The single function where program execution starts and returns an integer exit code.
#include <iostream>
Makes std::cout and std::endl available for console I/O operations.
Executable
The file produced by the compiler and linker that your OS can run directly.
Final thought
Master the tools and the simple edit-compile-run cycle; the language features will follow once your environment is stable.
