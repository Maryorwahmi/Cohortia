Hands-on Activity
Terminal-first lab
Task steps
  1. Create file my_greeting.cpp and add a minimal C++ program that includes <iostream> and prints a personalized greeting.
  2. Save file, open terminal in the same folder, and run: g++ my_greeting.cpp -o my_greeting
  3. Run the executable: ./my_greeting and confirm the greeting prints.
  4. If errors occur, read the first compiler message, fix the code, and recompile until successful.
Example starter code
#include <iostream>

int main() {
  std::cout << "Hello, Your Name! Welcome to Cohortia C++ Nanodegree." << std::endl;
  return 0;
}
Key Takeaway

Completing this exercise verifies your toolchain and builds your confidence to continue.
