Process Flow
Terminal-first demo
Commands
Compile:
g++ hello_cohortia.cpp -o hello_cohortia
Alternative order:
g++ -o hello_cohortia hello_cohortia.cpp
Run (Unix):
./hello_cohortia
Expected output
Hello, Cohortia!
Quick troubleshooting
  • If the compiler reports a missing file, verify you are in the correct directory.
  • If the compiler is not found, confirm it is installed and in your PATH.
  • If you see syntax errors, read the line number the compiler reports and inspect nearby tokens for missing semicolons or braces.
Key Takeaway

A single compile command typically runs all stages for a small program; repeat edit-compile-run to iterate fast.
