Installation and PATH tips
Symptoms
  • Terminal reports: command not found for g++ or clang++.
  • IDE cannot run build tasks that call the compiler.
Action: install the compiler and add its bin directory to PATH, then open a new terminal.
Platform note
On Unix-like systems, run the executable with ./name; on Windows, the executable may appear as name.exe. Always check the directory contents to confirm the output exists.
Key Takeaway

A missing compiler is usually a PATH or installation issue; fix the environment and restart your terminal before retrying.
