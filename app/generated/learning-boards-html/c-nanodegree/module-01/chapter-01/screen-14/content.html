Module 1 › Chapter 1.1 › Key Concepts
Compiler
Translates .cpp files into executables through preprocessing, compilation, and linking.
IDE
Editor plus terminal and debugger that streamlines writing and testing code.
-o option
Specifies the name of the output executable produced by the compiler.
Summary Takeaway
Master the edit-compile-run loop on your platform so you can focus on learning C++ language features next.
