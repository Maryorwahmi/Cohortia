Learning Objectives
Learn the tools and commands to compile C++ and troubleshoot common issues.
01
Install and verify a C++ compiler

Set up g++ or clang++ on your OS and confirm the compiler runs. This ensures you can translate source files into executables for testing.

VERIFIED COMPETENCY MILESTONE
02
Explain compiler and build roles

Describe how a compiler converts source code and how a build system orchestrates multi-file builds and linking. This mental model helps you troubleshoot errors.

VERIFIED COMPETENCY MILESTONE
03
Write and run a Hello program

Create hello_cohortia.cpp, compile it with g++ or clang++, and run the executable to verify output. This proves the end-to-end workflow.

VERIFIED COMPETENCY MILESTONE
04
Identify and fix common errors

Recognize missing semicolons, typos, and PATH problems. Learn how compiler diagnostics point you to a solution.

VERIFIED COMPETENCY MILESTONE
