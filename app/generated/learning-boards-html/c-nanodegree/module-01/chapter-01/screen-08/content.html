Common errors and remedies
Frequent issues
  • Missing semicolon — add the semicolon at the end of the statement.
  • Typos / undeclared identifier — check spelling and scope of names.
  • Compiler not found — install g++/clang++ or add to PATH.
  • Linker errors — ensure all definitions exist and are linked.
Pro tip: Fix the first reported error, then recompile. Many later messages are caused by an earlier issue.
Concrete scenario
If you forget the semicolon after std::endl, the compiler will point to the line; add the missing semicolon and re-run the compile. If the compiler is not recognized, open a terminal and run the compiler command to see the system message about an unknown command.
Common mistake
Using using namespace std globally can hide where names come from and lead to collisions in larger codebases.
Key Takeaway

Compiler messages are your friend: use file and line hints to find and fix issues quickly.
