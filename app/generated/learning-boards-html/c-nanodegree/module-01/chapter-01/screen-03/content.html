Use an editor with terminal

VS Code gives syntax highlighting, auto-completion, and an integrated terminal so you can compile and run without context switching. This speeds iteration during learning and debugging.

Control output name with -o

The -o option tells the compiler the name of the executable. Consistent naming makes running and scripting predictable across platforms.

Know when to use a build system

For one-file exercises you can compile directly. As your project grows, use tools like CMake to manage many files, libraries, and platform differences.

VERIFIED COMPETENCY MILESTONE
Read and act on compiler diagnostics

Compiler messages point to line numbers and nearby tokens. Learn to interpret them to fix syntax and linker issues faster.
