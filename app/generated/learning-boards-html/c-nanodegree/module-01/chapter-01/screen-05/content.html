Comparison
GCC (g++) vs Clang (clang++)
g++ (GCC)
Widely available on Linux and many toolchains, commonly used in examples and scripts.
Usage example:
g++ hello_cohortia.cpp -o hello_cohortia
clang++ (Clang)
Also open-source, with different diagnostics and packaging on some platforms, and fully compatible for our examples.
Usage example:
clang++ hello_cohortia.cpp -o hello_cohortia
Practical guidance
  • If one compiler is missing, use the other; the course examples work with either.
  • Compare diagnostics only to learn; do not assume identical messages or flags.
  • Check the compiler in your PATH to ensure you invoke the intended tool.
