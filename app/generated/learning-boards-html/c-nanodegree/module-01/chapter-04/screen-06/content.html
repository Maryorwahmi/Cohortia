Process Flow

Declaration vs Definition

Declare in headers, define in sources, and let the compiler and linker connect them during build.

Quick flow
  1. Write prototype in header (.h).
  2. Implement function in .cpp.
  3. Include header where you call the function.
  4. Compile and link all .cpp files together.
Code example
// my_functions.h
#ifndef MY_FUNCTIONS_H
#define MY_FUNCTIONS_H

void greet(std::string name);
int add(int a, int b);

#endif

// my_functions.cpp
#include "my_functions.h"
#include 

void greet(std::string name) {
  std::cout << "Hello, " << name << "!" << std::endl;
}

int add(int a, int b) {
  return a + b;
}
Why it matters

Headers let many files share interfaces without including implementation details, improving compile-time organization.
