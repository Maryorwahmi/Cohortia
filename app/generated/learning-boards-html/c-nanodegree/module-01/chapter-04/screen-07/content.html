Calling Functions

Provide arguments, receive returns, and keep side effects explicit rather than implicit when possible.

#include 

void greet(std::string name) {
  std::cout << "Hello, " << name << "!" << std::endl;
}

int add(int a, int b) {
  return a + b;
}

int main() {
  greet("Cohortia Learner");
  int sum = add(5, 3);
  std::cout << "Sum is: " << sum << std::endl;
  return 0;
}
Explanation
  • Arguments are the actual values supplied at the call site.
  • Parameters are local names used by the function body.
  • Return a value when the result is needed; otherwise use void for side-effect functions.
Key Takeaway

Prefer returning results over hidden mutation to make functions predictable and testable.
