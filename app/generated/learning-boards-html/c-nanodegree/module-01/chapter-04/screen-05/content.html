Definition

Function Signature

Return type, name, and parameters together form the function's public interface.

Design checklist
  • Choose the narrowest return type that conveys the result.
  • Keep parameter lists minimal and ordered by importance.
  • Use const and references when appropriate to communicate intent (later modules cover references in depth).
Mnemonic

Think: Output = Name(Inputs)

Example signatures
void greet(std::string name);
int add(int a, int b);
std::string join(std::string s1, std::string s2);
Tip

When declaring prototypes in headers, parameter names help document expected values for callers.

Mistake

Relying on vague types like generic integers for values that need more precision or domain meaning.
