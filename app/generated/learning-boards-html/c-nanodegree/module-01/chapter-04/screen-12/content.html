Hands-on Activity

Refactor the Simple Calculator

  1. Create calculator_functions.h with prototypes and include guards.
  2. Write implementations in calculator_functions.cpp and include the header.
  3. Update main.cpp to include the header and call functions instead of inline math.
  4. Compile: g++ main.cpp calculator_functions.cpp -o modular_calculator
Edge case

For divide, check for zero and print an error to standard error, returning a safe sentinel value.

Example header template
#ifndef CALCULATOR_FUNCTIONS_H
#define CALCULATOR_FUNCTIONS_H

double add(double a, double b);
double subtract(double a, double b);
double multiply(double a, double b);
double divide(double a, double b);

#endif // CALCULATOR_FUNCTIONS_H
Success check

Program compiles and outputs the same results as before; functions are testable in isolation.
