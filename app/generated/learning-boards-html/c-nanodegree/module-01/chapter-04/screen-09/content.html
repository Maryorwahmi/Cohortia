Function Overloading

Use the same name for related operations that accept different parameter lists. The compiler resolves which version to call based on arguments.

int add(int a, int b) { return a + b; }
int add(int a, int b, int c) { return a + b + c; }
std::string add(std::string s1, std::string s2) { return s1 + s2; }
Notes
  • Overload by different parameter count, types, or order.
  • Do not overload solely by return type — this is not allowed.
  • Keep overloads logically related to reduce cognitive load for users.
Common Mistake

Attempting to create two functions that differ only by return type causes compilation errors because the call remains ambiguous.
