Headers & Include Guards

Keep declarations in headers, implementations in sources, and add include guards to headers to avoid multiple-definition issues.

// calculator_functions.h
#ifndef CALCULATOR_FUNCTIONS_H
#define CALCULATOR_FUNCTIONS_H

double add(double a, double b);
double divide(double a, double b);

#endif // CALCULATOR_FUNCTIONS_H
Compile & Link
Compile command example:
g++ main.cpp calculator_functions.cpp -o modular_calculator
Why it helps

Separating declarations from definitions reduces recompilation and clarifies public interfaces between modules.
