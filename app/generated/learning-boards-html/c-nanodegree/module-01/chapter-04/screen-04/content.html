Core Concept

What is a Function?

A named block that accepts inputs, runs code, and optionally returns a value. Use it to encapsulate a single task.

Benefits
  • Modularity: break big problems into small ones.
  • Reusability: call the same logic from many places.
  • Abstraction: hide implementation details from callers.
Analogy

Like bakery stations: mix, bake, and decorate are independent steps that can be tested and reused in different recipes.

Key Takeaway

Prefer small, single-responsibility functions to keep code understandable and testable.

Structure
// Function signature: return-type name(parameter-list)
void greet(std::string name) {
  // body: implementation for greeting
}

int add(int a, int b) {
  return a + b;
}
Common Mistake

Treating functions as large dumping grounds. Keep them focused to avoid tangled logic and hidden side effects.
