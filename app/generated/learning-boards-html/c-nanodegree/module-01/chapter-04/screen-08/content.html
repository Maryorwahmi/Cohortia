Definition

Parameters vs Arguments

Parameters name the expected inputs. Arguments are the actual values provided at call time.

Example
If a function takes an integer parameter, calling it with a variable copies the value into the parameter. Mutations inside the function do not affect the caller's variable.
Misconception

Expecting parameters to change caller variables by default. Default semantics are copy-based; use references when you explicitly mean to modify the caller.

Scenario
void resetToZero(int x) {
  x = 0; // only affects the copy inside the function
}

int main() {
  int a = 5;
  resetToZero(a);
  // a is still 5 here because x was a copy
}
Practical tip

Return new values from functions when you want to produce a result. Reserve references for intentional in-place updates in later modules.
