Learning Objectives — Practice Milestones

Each card below maps an objective to a concrete coding step you can complete right away.

01 — Refactor to functions

Extract repeated operations into named functions, run the program, and confirm identical output. This proves modularity preserves behavior.

VERIFIED COMPETENCY MILESTONE
02 — Prototype & Compile

Place function prototypes in a header, definitions in a .cpp file, and compile both to see how declarations guide the compiler.

VERIFIED COMPETENCY MILESTONE
03 — Overload safely

Implement overloaded functions for integers and strings, call them with matching arguments, and note the compiler chooses by parameter list.

VERIFIED COMPETENCY MILESTONE
04 — Scope checks

Experiment with global and local variables, shadow a global with a local, and use the scope operator to access the global variable when needed.
