What to Remember

Six short rules you can apply immediately.

Design signatures
Make inputs and outputs explicit so callers know what to provide and expect.
Return results
Prefer returning computed values rather than implicit mutations for clarity.
Keep headers lean
Headers should declare interfaces, not hold heavy implementations.
Use include guards
Prevent multiple inclusion and redefinition errors by wrapping headers with guards.
Avoid ambiguous overloads
Make overload sets clear and avoid relying on subtle conversions that create ambiguity.
Limit globals
Use local state and parameters to avoid hidden coupling and make functions easier to reason about.
