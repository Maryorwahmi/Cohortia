Definition

Variable Scope

Where a name can be referenced and how long it lives are critical for correct behavior and reasoning about code.

int globalVar = 100; // global

void f() {
  int localVar = 50; // local to f
}

int main() {
  int globalVar = 200; // shadows global
  std::cout << ::globalVar << std::endl; // access global explicitly
}
Practical guidance
  • Limit global variables to well-documented constants or controlled singletons.
  • Prefer passing data through parameters and return values for clarity.
  • When shadowing occurs, use explicit scope resolution to disambiguate if needed.
Common Bug

Unintended shadowing can silently change which variable you read or write, leading to confusing behavior.
