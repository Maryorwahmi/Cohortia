Pro Tip

Common Mistakes

  • Mismatched prototypes and implementations.
  • Missing include guards in headers leading to redefinitions.
  • Overloading only by return type — not allowed.
  • Excessive use of mutable globals creating side effects.
Debugging checklist
  1. Compare prototype and definition signatures exactly.
  2. Confirm headers use include guards and include correct headers.
  3. Enable compiler warnings and read the first error — later messages often follow from the first problem.
  4. Write small tests for each function to validate expected outputs.
Quick fix

If an overload is ambiguous, rename one overload or make the call explicit to remove ambiguity.
