Module 3 › Chapter 3.1 › Heap Allocation & Deallocation
Step-by-step
  1. Allocate: Call new to reserve memory and receive a pointer.
  2. Use: Read and write through the pointer as needed.
  3. Free: Call delete or delete[] to release memory.
  4. Nullify: Set pointer to nullptr to avoid dangling use.
Common mistake
Mixing delete and delete[] or forgetting to delete leads to undefined behavior or leaks.
Concrete example (from chapter)
int* dynamicInt = new int;
*dynamicInt = 42;
std::cout << *dynamicInt << std::endl;
delete dynamicInt;
dynamicInt = nullptr;

int* dynamicArray = new int[5];
// initialize
delete[] dynamicArray;
dynamicArray = nullptr;
Allocate, use, then free. Using RAII or container classes reduces manual delete calls and lowers error risk.
