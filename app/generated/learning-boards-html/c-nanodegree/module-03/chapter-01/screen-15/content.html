Module 3 › Chapter 3.1 › Key Concepts
Stack Memory
LIFO frames for local variables; automatic deallocation when scope ends.
Heap (Free Store)
Dynamic allocation with new/delete; lifetime persists until explicitly freed.
Common Errors
Stack overflow, memory leaks, dangling pointers; prevent with small habits and RAII.
Summary Takeaway

Match storage choice to lifetime and size, pair allocations with deallocations, and prefer automatic management to reduce bugs.
