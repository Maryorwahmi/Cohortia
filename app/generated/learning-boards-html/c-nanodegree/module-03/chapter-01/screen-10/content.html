Example from the chapter
void processData() {
    int* data = new int[100];
    // ... use data ...
    // Missing delete[] data;
}

int main() {
    for (int i = 0; i < 1000; ++i) {
        processData();
    }
}
Here, each call allocates but never deallocates; after many iterations the program will leak a significant amount of memory.
Mitigations
  • Always pair new with delete and new[] with delete[].
  • Prefer containers like vectors that manage heap memory automatically.
  • Use tools and tests that detect leaks during development.
Common misconception

Assuming the OS will prevent leaks during long runs is risky; persistent services must manage memory carefully.
