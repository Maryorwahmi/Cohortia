Module 3 › Chapter 3.1 › Stack vs Heap — Choosing
Side-by-side
Stack
Automatic lifetime, fast allocation, limited size, tied to scope.
Heap
Dynamic lifetime, allocate with new, larger space, requires explicit deallocation.
Example decision flow
  1. Is the required size known and small? If yes, consider stack.
  2. Does the data need to outlive the function? If yes, use heap.
  3. For large per-object needs, choose heap or container abstractions.
Concrete scenario

If you read a file with unknown number of lines and store them for later processing, allocate on the heap or use standard containers that allocate on the heap. If you need a temporary loop counter, keep it on the stack.

Key Takeaway

Match lifetime and size requirements to the memory region; prefer automatic management when safe.
