Module 3 › Chapter 3.1 › Dangling Pointers
Example habit
int* heapInt = new int;
*heapInt = 200;
std::cout << *heapInt << std::endl;
delete heapInt; // Deallocate
heapInt = nullptr; // Prevent dangling pointer
Setting heapInt to nullptr after delete prevents accidental dereference of memory that no longer belongs to you.
Why this matters
  • Dereferencing a dangling pointer is undefined behavior.
  • Setting to nullptr makes bugs fail fast when you check before use.
  • Smart pointers and containers reduce the need for manual delete and null checks.
