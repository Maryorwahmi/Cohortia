Module 3 › Chapter 3.1 › What is the Heap?
Definition

The heap is a larger, more flexible memory region used for dynamic allocation at runtime. Its lifetime is controlled by explicit allocate and deallocate operations.

When to use
When size or lifetime is unknown at compile time, or when objects must outlive their creating scope.
Concrete code
int main() {
    int* dynamicInt = new int; // Allocate an int on the heap
    *dynamicInt = 42;
    std::cout << "Dynamic int: " << *dynamicInt << std::endl;

    delete dynamicInt; // Deallocate the memory
    dynamicInt = nullptr; // Good practice

    int* dynamicArray = new int[5];
    // ... initialize and use ...
    delete[] dynamicArray; // Deallocate the array
    dynamicArray = nullptr;
    return 0;
}
Note the explicit delete and delete array. Forgetting these calls leaves memory allocated with no reference, causing leaks over time.
