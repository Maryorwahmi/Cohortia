Module 3 › Chapter 3.1 › Practice & Safety
Verification checks
  • Print addresses to observe stack locality and heap dispersion.
  • Allocate arrays on the heap with new[] and free with delete[].
  • Use small, incremental recursion to study stack usage safely; never run unchecked deep recursion.
  • Prefer containers that manage memory automatically when appropriate.
Safety notes
Caution: stack overflow
The chapter includes a commented-out stack overflow function. Do not run it without understanding the risk. If you test, start with very small depths and observe system behavior.
Good practice
After delete, set pointers to nullptr to avoid accidental access to freed memory.
