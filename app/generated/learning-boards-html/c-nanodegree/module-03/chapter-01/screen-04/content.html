Module 3 › Chapter 3.1 › What is the Stack?
Definition

The stack stores local variables, parameters, and return addresses in a LIFO sequence. Lifetime is automatic and bound to scope.

Analogy — plate stack
Each function call pushes a frame, and returning pops it. Allocation is pointer arithmetic, so it is fast and predictable.
When to use
Small fixed-size local variables and parameters.
Watch out
Very large local arrays or very deep recursion can cause stack overflow.
Concrete example
// from chapter
void calculateSum(int a, int b) {
  int sum = a + b; // 'sum', 'a', and 'b' are on the stack
  std::cout << "Sum: " << sum << std::endl;
}

int main() {
  int x = 10; // 'x' is on the stack
  int y = 20; // 'y' is on the stack
  calculateSum(x, y);
  return 0;
}
In this example, local variables are automatically reclaimed when the function returns. Printing their addresses will show that stack addresses cluster together.
Key Takeaway

Use stack for fast, scope-limited storage. Avoid large allocations or unbounded recursion on the stack.
