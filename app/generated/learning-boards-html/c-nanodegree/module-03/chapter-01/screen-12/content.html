Module 3 › Chapter 3.1 › Hands-on Activity
Starter tasks
  1. Compile and run the provided program and record printed addresses for stack and heap variables.
  2. Observe locality: are stack addresses close to each other? Are heap addresses spread out?
  3. Verify proper use of delete and delete array and that pointers are set to nullptr after deletion.
  4. Read the commented stack overflow function and explain why uncommenting it risks crashing the program.
Observation card
Record at least three runs and note whether addresses shift between runs and how locality persists.
Safety note
Do not uncomment stack overflow code in production or on machines where a crash is unacceptable.
Key Takeaway

Hands-on observation cements the abstract rules: lifetime, locality, and ownership matter more than raw addresses.
