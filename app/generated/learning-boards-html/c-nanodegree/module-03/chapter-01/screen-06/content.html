Why overflow happens

Stack frames accumulate with each function call. Large frames or many nested calls increase memory usage until the stack limit is reached.

Example note
The chapter includes a causeStackOverflow function with a commented-out large array. Do not enable it without understanding the crash risk.
Safe alternative
Use heap allocation for large buffers or convert recursion to iteration.
Testing tip
Start with small recursion depth and monitor process memory before increasing tests.
