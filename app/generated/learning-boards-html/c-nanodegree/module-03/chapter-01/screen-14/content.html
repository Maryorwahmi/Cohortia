Module 3 › Chapter 3.1 › Assessment & Reflection
Quick assessment items
  1. Which storage region should hold a temporary loop counter? Explain why.
  2. Given a function that reads an unknown number of elements, where should they be stored and why?
  3. Inspect code paths: is every new paired with a matching delete? If not, where is the leak?
  4. When you delete memory, do you set the pointer to nullptr? Why is this helpful?
Debugging step
Run loops that allocate and free repeatedly and watch memory usage to reveal leaks.
Reflection
Ask: who owns this memory and when should it be freed? Ownership guides correct placement and deallocation.
