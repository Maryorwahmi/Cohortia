Module 3 › Chapter 3.2 › Dereferencing
Code walkthrough
// Declare and initialize
int value = 10;
int* ptr = &value; // ptr holds address of value

// Read via pointer
std::cout << "value: " << value << std::endl;    // prints 10
std::cout << "*ptr: " << *ptr << std::endl;      // prints 10

// Modify via pointer
*ptr = 25; // writes to the storage at ptr's address
std::cout << "value after *ptr = 25: " << value << std::endl; // prints 25

// Safety: check before dereference
int* maybeNull = nullptr;
if (maybeNull != nullptr) {
  // safe to dereference
  std::cout << *maybeNull << std::endl;
}
Common mistake
Dereferencing nullptr
Always check pointers that may be null; undefined behavior is the result otherwise.
Example
Modify original via ptr
Changing *ptr changes the original variable because they share storage.
Explanation bullets
  • Declaration int* p reserves space for an address. The pointer itself is a value stored somewhere in memory.
  • &variable returns the address; *pointer accesses the value at that address.
  • Assignment to *pointer changes the pointee's storage directly.
  • Always ensure pointer validity; prefer nullptr initialization and checks where needed.
Key Takeaway

Dereference only valid pointers; modification through a pointer updates the original storage directly.
