Module 3 › Chapter 3.2 › Pointers vs References
Pointers
  • Can be nullptr; may be uninitialized if not set.
  • Can be reassigned to different addresses.
  • Requires explicit dereference with * to read/write pointee.
  • Useful for optional relationships and low-level APIs.
References
  • Must be initialized at declaration and cannot be null.
  • Cannot be reseated; acts as an alias to the original object.
  • No explicit dereference operator; use like the variable itself.
  • Excellent for pass-by-reference and const reference parameters.
Practical contrast
Pointer example
int* p = &a; p = nullptr; // allowed
Reference example
int& r = a; // must initialize and cannot become another alias
Misconception check
References are not simply pointers with nicer syntax; they impose binding rules that affect lifetime and safety guarantees.
