Module 3 › Chapter 3.2 › Parameter Passing
Three functions, one variable
// Pass-by-value: does not modify caller
void modifyByValue(int num) {
  num += 10;
}

// Pass-by-pointer: can modify caller (if not nullptr)
void modifyByPointer(int* ptr) {
  if (ptr != nullptr) {
    *ptr += 20;
  }
}

// Pass-by-reference: modifies caller directly
void modifyByReference(int& ref) {
  ref += 30;
}

Call these with an int myValue and observe how only the pointer and reference functions change the original.

Practical notes
  • Use pointer parameters to indicate optional arguments with null representing absence.
  • Use references when the function requires a valid object and you want clearer syntax.
  • Always check pointer arguments for nullptr before dereferencing.
Misconception
References provide optional semantics. They do not; they always bind to a real object.
