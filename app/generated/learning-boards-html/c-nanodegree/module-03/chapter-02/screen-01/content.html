Direct Memory Access with Pointers and References

Understand addresses, dereferencing, pointer arithmetic, and reference aliasing so you can write efficient and correct C++.

In this lesson
Declare pointers & references, dereference, and use pointer arithmetic safely.
Coming up
Compare pointer reassignment vs reference immutability; avoid dangling pointers.
Why it matters
Direct memory control enables dynamic data structures and performant APIs.
Memory map snapshot
A conceptual card set linking variables to addresses and values
Variable
int value = 10;
Holds the value directly in memory.
Pointer
int* p = &value;
Stores the address of the variable above.
Reference
int& r = value;
Alias for the same storage; cannot be reseated.
Key Takeaway

Pointers let you refer to addresses directly; references provide safer, alias-like syntax where reseating is not needed.
