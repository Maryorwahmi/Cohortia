Module 3 › Chapter 3.2 › Key Concepts
Pointer
Stores an address; declared with *; use * to access the pointee.
Reference
An alias to existing storage; declared with &; must be initialized and cannot be reseated.
Pointer Arithmetic
Pointer+1 advances by one element size; use start/end pointers to iterate safely.
Quick takeaway

Initialize pointers, check for nullptr, avoid dangling pointers, prefer references when reseating and nullability are not needed, and use const references for efficient read-only parameters.
