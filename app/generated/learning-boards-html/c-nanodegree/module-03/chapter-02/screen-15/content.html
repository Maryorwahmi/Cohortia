Module 3 › Chapter 3.2 › Remember
Pointers need validation
Initialize to nullptr, check before dereference, and nullify after delete.
References are stable aliases
Must be initialized and cannot be reseated; ideal for pass-by-reference and const binding.
Pointer arithmetic is typed
Increment moves by element size; use start/end to avoid out-of-bounds access.
Final takeaway

These rules form the basis for safe direct memory access; practice the examples, check pointers, and prefer references where appropriate.
