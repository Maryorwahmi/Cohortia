Reference example
int originalValue = 100;
int& ref = originalValue; // ref is an alias for originalValue
std::cout << originalValue << ", " << ref << std::endl; // both print 100
ref = 200; // modifies originalValue
std::cout << originalValue << std::endl; // prints 200
  • References must be initialized and cannot be null.
  • Assignment to a reference changes the original object, not the binding.
  • References are preferred for clear, safe aliasing and for pass-by-reference in functions.
Common misconception

People often think references can be reseated like pointers. They cannot: ref = otherValue assigns a value, it does not change what ref refers to.

When to use a reference
Use references when you need a guaranteed alias and you don’t need nullability or reseating.
Key Takeaway

References are safer and simpler aliases; prefer them when you want guaranteed binding and cleaner syntax.
