Module 3 › Chapter 3.2 › Practice & Safety
What to practice
  • Print addresses with the address-of operator and confirm pointer values match.
  • Use the dereference operator to both read and assign values through a pointer.
  • Iterate arrays using pointer increments and confirm each step matches indexing.
  • Write functions showing pass-by-value, pointer, and reference to compare effects on variables.
Quick safety checklist
  1. Initialize pointers to nullptr or a valid address.
  2. Check for nullptr before dereferencing when null is possible.
  3. After delete, set pointer to nullptr to avoid dangling references.
  4. Avoid non-const references to temporaries; prefer const reference for read-only temporaries.
