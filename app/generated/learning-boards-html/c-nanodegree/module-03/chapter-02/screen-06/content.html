Step-by-step: iterate an array
int numbers[] = {10, 20, 30, 40, 50};
int* p = numbers; // points to numbers[0]
int* end = numbers + 5; // one past last element

for (; p < end; ++p) {
  std::cout << *p << " "; // reads each element in order
}
  • Pointer addition uses element size. p + 1 points to the next int, not the next byte.
  • p[index] is shorthand for *(p + index).
  • Never dereference pointers outside [start, end). The loop pattern above prevents out-of-bounds access.
Concrete analogy

Think of p as a pointer to the first seat in a row. Adding one moves you to the next seat, not one meter forward. The seat size corresponds to the data type size.

Common mistake
Assuming +1 adds a single byte. That leads to incorrect offsets when switching types.
Key Takeaway

Pointer arithmetic advances by element size; use start/end pointers to safely traverse arrays.
