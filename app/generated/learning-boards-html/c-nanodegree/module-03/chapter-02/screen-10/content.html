Error types & examples
  • Uninitialized pointer: int* p; // contains garbage address — dangerous to dereference.
  • Null pointer: int* p = nullptr; // safe until assigned — check before use.
  • Dangling pointer: int* p = new int(5); delete p; // p now dangles; set p = nullptr to avoid reuse.
  • Returning local address: int* f(){ int x; return &x; } // invalid, x goes out of scope.
Prevention checklist
  1. Initialize pointers to nullptr or a valid address.
  2. Check for nullptr before dereferencing when null is a possible value.
  3. After delete, set pointer to nullptr to avoid accidental reuse.
  4. Prefer references or smart pointers for clear ownership and lifetime semantics when possible.
