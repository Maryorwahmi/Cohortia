Module 3 › Chapter 3.2 › What is a Pointer?
Definition & example

A pointer holds the memory address of another variable. Use address-of to assign and * to dereference.

// Example: pointer declaration and dereference
int value = 10;        // 'value' stores 10
int* ptr = &value;     // 'ptr' holds the address of value
// Reading via pointer
std::cout << "*ptr = " << *ptr << std::endl; // prints 10
// Modifying via pointer
*ptr = 20; // now value == 20
Misconception
Asterisk meaning
Declaration context vs expression context matters; the symbol plays different roles.
Pro tip
Initialize pointers
Set unused pointers to nullptr to avoid wild pointer bugs.
Key Takeaway

Pointers give explicit control over addresses and memory access; they must be initialized and validated before use.

Annotated value → address → pointer
Variable
int value = 10;
Contains the stored integer in memory.
Address
&value → 0x7ffe... (conceptual)
Address that points to where the integer is stored.
Pointer
int* ptr = &value;
Holds the address and can be used with *ptr to access the value.
