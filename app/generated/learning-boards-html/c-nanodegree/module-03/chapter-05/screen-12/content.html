Module 4 › Chapter 3.5 › Hands-on Activity
Task steps
  1. Create ParentNodeEnhanced inheriting enable_shared_from_this and children vector.
  2. Create ChildNode with std::weak_ptr<ParentNode> parent and printParentName that uses lock().
  3. Add children with parent->addChild(child) where addChild sets child->parent = shared_from_this().
  4. Reset the root parent and observe destructor output and child behaviour.
Expected result
Parent destructor runs when root shared_ptr resets; children detect parent absence when they call lock() and print that parent no longer exists.
Verification
Run the activity and confirm that all destructors execute and no leaks remain. If destructors do not run, inspect fields for shared_ptr cycles and refactor one direction to weak_ptr.
Key Takeaway

Hands-on verification by observing constructors and destructors is the most reliable way to confirm correct ownership design and the absence of cycles.
