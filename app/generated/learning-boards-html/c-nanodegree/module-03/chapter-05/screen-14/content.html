Module 4 › Chapter 3.5 › Final reminders
Prefer make_shared
Single allocation for object and control block improves efficiency.
Track use_count
Print counts during debugging to confirm ownership behavior.
Break cycles with weak_ptr
Use lock() to access observed objects and check for emptiness.
Closing thought

Design ownership clearly: owning pointers extend lifetime, observers do not. Using shared_ptr and weak_ptr consciously makes lifetimes predictable and code safer.
