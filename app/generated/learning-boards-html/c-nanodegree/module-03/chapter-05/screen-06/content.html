Module 4 › Chapter 3.5 › make_shared example
Code (excerpt)
#include <iostream>
#include <memory>
#include <string>

int main() {
  auto mainProcessor = std::make_shared<DataProcessor>("Main_CPU");
  std::cout << "Main: Ref count: " << mainProcessor.use_count() << std::endl; // Expected 1

  auto backupProcessor = mainProcessor; // copy, ref count increments
  std::cout << "Main: Ref count: " << mainProcessor.use_count() << std::endl; // Expected 2

  consumerFunction(backupProcessor); // pass by value, temporary copy increments count inside
  return 0;
}
Note: DataProcessor prints messages in constructor and destructor so you can observe creation and destruction in program output.
Explanation & example output
Run the code and watch: creation message appears when make_shared constructs the object. Each copy increases use_count; when temporary copies end, the count drops. Final destructor prints when the last shared_ptr is destroyed. This visible sequence is the best way to confirm your ownership reasoning.
Misconception
make_shared does not alter ownership semantics; it only reduces allocations and can improve locality.
Key Takeaway

Use make_shared for creation and instrument your code with use_count and destructor messages to see exact lifetime behavior.
