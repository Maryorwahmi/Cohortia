Module 4 › Chapter 3.5 › enable_shared_from_this
Why enable_shared_from_this

When an object needs to create shared_ptrs to itself safely, inherit from std::enable_shared_from_this. This guarantees shared_from_this returns a shared_ptr tied to the existing control block rather than creating a separate owner.

class ParentNodeEnhanced : public std::enable_shared_from_this<ParentNodeEnhanced> {
public:
  void addChild(std::shared_ptr<ChildNode> child) {
    children.push_back(child);
    child->parent = shared_from_this(); // safe when Parent is owned by shared_ptr
  }
};
Practical warnings
  • Do not call shared_from_this in a constructor before a shared_ptr owns the object.
  • Confirm the parent is created with make_shared so shared_from_this returns a valid shared_ptr.
  • Use the returned shared_ptr to initialize weak_ptr observers in children.
Key Takeaway

enable_shared_from_this ensures self-references belong to the same control block, avoiding ownership inconsistencies.
