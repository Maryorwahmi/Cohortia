Module 4 › Chapter 3.5 › Key Concepts
std::shared_ptr
Shared ownership; object destroyed when last owner is gone.
Reference Counting
Copies increment, destruction decrements; deallocate at zero.
std::weak_ptr
Non-owning observer; use lock() to safely access target.
Summary takeaway

Design ownership deliberately: prefer unique_ptr when possible, use shared_ptr for true multi-ownership, and apply weak_ptr to break cycles and observe safely.
