Leaking example
A loop allocates ints and never deletes them, causing memory consumption to grow.
void createLeak() {
  int* data = new int[100];
  // ... use data ...
  // forgot delete[] data; -> leak
}
Fixed version
Call delete[] before letting the pointer go out of scope, and set pointer to nullptr.
void fixLeak() {
  int* data = new int[100];
  // ... use data ...
  delete[] data; // free memory
  data = nullptr;
}
Key Takeaway
Always free every allocation on every path, or use RAII wrappers that free automatically.
