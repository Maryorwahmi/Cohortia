Allocate an array of Products
Observe constructor and destructor calls and practice correct delete[] usage.
Product* products = nullptr;
try {
  products = new Product[numProducts];
} catch (const std::bad_alloc& e) {
  // handle failure
}
// populate products[i] = Product(name, price);
// later:
delete[] products;
products = nullptr;
Observations
  • new Product[n] calls default constructor n times.
  • Assigning into elements can create temporaries and use copy assignment.
  • delete[] calls all destructors; without it, destructors won't run.
Common pitfall
If population code throws an exception, ensure allocated array is still freed — this is why RAII is recommended.
