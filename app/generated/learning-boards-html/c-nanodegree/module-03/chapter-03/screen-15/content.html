Module 3 › Chapter 3.3 › Key Concepts
new / new[]
Allocate single objects or arrays on the heap and return pointers.
delete / delete[]
Deallocate memory; delete[] must match new[] to call all destructors.
Memory Leak
Occurs when allocated memory is never deallocated and becomes unreachable.
Summary takeaway: Manual heap management gives control but requires strict ownership discipline. Use nullptr assignments, match new/delete forms, and prefer RAII to avoid common failures.
