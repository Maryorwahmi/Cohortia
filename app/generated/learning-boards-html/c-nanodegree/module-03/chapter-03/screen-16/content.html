Module 3 › Chapter 3.3 › Key Concepts
Double Free
Deleting the same pointer twice leads to undefined behavior and possible heap corruption.
Dangling Pointer
Pointer that references memory already freed; dereferencing causes undefined behavior.
std::bad_alloc
Exception thrown when memory allocation with new fails; plan cleanup or use RAII.
Final reminder: practice the lab, inspect constructor and destructor output, and adopt RAII in future code to make programs robust and exception-safe.
