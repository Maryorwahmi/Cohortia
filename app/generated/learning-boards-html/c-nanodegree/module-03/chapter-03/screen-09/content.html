Module 3 › Chapter 3.3 › createStudentNames
Code Walkthrough
Function allocates an array of std::string, fills each element, and returns the pointer. Caller checks for nullptr, uses the array, then delete[] and sets to nullptr.
std::string* createStudentNames(int count) {
  if (count <= 0) return nullptr;
  std::string* names = new std::string[count];
  for (int i = 0; i < count; ++i) {
    names[i] = "Student_" + std::to_string(i + 1);
  }
  return names; // Caller owns and must delete[]
}

// Caller:
int numStudents = 3;
std::string* studentList = createStudentNames(numStudents);
if (studentList != nullptr) {
  // use studentList
  delete[] studentList;
  studentList = nullptr;
}
Notes and pitfalls
  • Document that the function transfers ownership to the caller.
  • Caller must delete[] to free all elements and avoid leaks.
  • Consider returning a standard container to avoid manual ownership semantics.
Key Takeaway
Raw returned pointers make ownership explicit but error-prone; prefer RAII when possible.
