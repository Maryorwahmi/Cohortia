Process
Allocate and use an array
Create a contiguous block, assign elements by index, and manage size and lifetime manually.
  • new Type[count] returns a pointer to the first element.
  • Built-in types may be uninitialized unless value-initialized.
  • Keep track of the array length; there is no built-in size metadata.
  • Always free with delete[] to invoke all destructors and return the whole block.
Key Takeaway
Use new[] for simple manual arrays but prefer containers when you need automatic size and lifetime management.
Code example
int arraySize = 5;
double* myDoubleArray = new double[arraySize]; // allocate 5 doubles
for (int i = 0; i < arraySize; ++i) {
  myDoubleArray[i] = static_cast<double>(i) * 1.5;
}
// use elements...
// Correct deallocation:
delete[] myDoubleArray;
myDoubleArray = nullptr;
Common misconception
Treating raw arrays like vectors ignores size, capacity, and exception safety; prefer std::vector for most use cases.
