Module 3 › Chapter 3.3 › delete vs delete[]
Comparison
Single object (new) vs Array (new[])
Which deallocator to use changes how destructors are run and how memory is released.
Allocated with new
Use delete. delete[] is incorrect and may try to read deallocation metadata that isn't present.
Allocated with new[]
Use delete[]. delete may call only first destructor and fail to free whole block.
Common mistake
Assuming delete is 'good enough' for arrays. This leads to subtle runtime corruption.
Illustrative scenario
Imagine default-constructed objects in an array have non-trivial destructors. If delete[] is not used, some destructors won't run and resources referenced by those objects won't be released, causing leaks and potential resource corruption.
Check your understanding

Which deallocation is correct for MyObject* a = new MyObject[10]; ?

Answer: delete[] a; because the allocation used new[].
Key Takeaway

Treat allocation and deallocation forms as a pair; mismatches are undefined behavior.
