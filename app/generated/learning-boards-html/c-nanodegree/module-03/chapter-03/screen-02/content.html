Learning Objectives
Practice allocation, deallocation, safety, and reasoning about ownership.
Bloom: Learn → Understand → Apply → Master
01
Allocate single objects and arrays
Use new to allocate a single object and new[] to allocate arrays when sizes are dynamic.
Mnemonic: single box vs. crate of boxes.
VERIFIED COMPETENCY MILESTONE
02
Deallocate with delete and delete[]
Return heap memory correctly so destructors run and memory is freed.
Mnemonic: matching keys to locks.
VERIFIED COMPETENCY MILESTONE
03
Match allocation and deallocation forms
Always pair new with delete and new[] with delete[] to avoid undefined behavior.
Mnemonic: brackets go together.
VERIFIED COMPETENCY MILESTONE
04
Handle nullptr and prevent leaks
Set pointers to nullptr after delete, check before dereference, and reason about ownership to avoid leaks.
Mnemonic: null is safe ground.
