Dynamic Memory Allocation with new and delete
Allocate objects at runtime and learn safe deallocation patterns that prevent leaks and crashes.
In this lesson
Syntax for new/new[], safe delete/delete[], and practical pitfalls.
Why it matters
Dynamic allocation enables flexible data structures but requires discipline to manage lifetime.
Outcome
By the end you will allocate, free, and reason about ownership for basic heap objects.
Concept map
Allocation
new / new[]
Request memory on the heap; returns a pointer to the block.
Deallocation
delete / delete[]
Return memory and run destructors; must match allocation form.
Safety
nullptr, RAII
Set pointers to nullptr after delete; prefer RAII patterns later.
Interactive 16:9 Masterclass
Visual overview
Heap blocks hold objects for flexible lifetimes.
Deleting incorrectly or not at all causes crashes or leaks.
Smart pointers later provide automatic cleanup and exception safety.
