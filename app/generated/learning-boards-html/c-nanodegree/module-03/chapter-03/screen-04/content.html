Module 3 › Chapter 3.3 › The new operator
Core Concept
What new does
Allocates memory, constructs the object, returns a pointer to it. You own it until you delete it.
Key bullets
  • new allocates and constructs a single object on the heap and returns a pointer.
  • If allocation fails, new typically throws std::bad_alloc.
  • You must delete the returned pointer to free memory and call the destructor.
  • After delete set pointer to nullptr to prevent dangling pointers.
Example
Allocate an int on the heap, assign 100, then delete it and set the pointer to nullptr.
Key Takeaway

Use new for heap lifetime control, but always plan who deletes the memory.

Code example
int* myIntPtr = new int; // Allocates one integer on the heap
*myIntPtr = 100;         // Assign via pointer
std::cout << *myIntPtr << std::endl;

// When finished:
delete myIntPtr;         // Free the heap memory
myIntPtr = nullptr;      // Prevent dangling pointer
Common mistake
Forgetting delete causes a memory leak; relying on program end to free memory is unsafe for long-running processes.
Pro tip
Consider ownership: mark who must delete the pointer and set it to nullptr immediately after deletion.
