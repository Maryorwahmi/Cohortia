Learning Objectives — Advanced Safety
Learn to reason about failure modes and why automatic resource management matters.
Deliverable: safe allocation examples
01
Explain memory leaks
Identify when allocated memory becomes unreachable and how that affects long-running programs.
Mnemonic: lost keys keep resources locked.

02
Recognize double free and dangling pointer risks
Understand that deleting twice or using freed memory causes undefined behavior and heap corruption.
Mnemonic: one delete per owner.

03
Handle allocation failure
Know that new can throw std::bad_alloc and plan code paths to avoid leaks when exceptions occur.
Mnemonic: clean up before you leave.
VERIFIED COMPETENCY MILESTONE
04
Introduction to RAII
Understand why tying resource release to object lifetime prevents leaks, especially with exceptions.
Mnemonic: ownership equals cleanup.
