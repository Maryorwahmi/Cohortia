Module 3 › Chapter 3.3 › Assessment
Assessment ideas
Use short code fixes, multiple-choice, and output inspection to verify understanding.
Quiz question
If MyObject* arr = new MyObject[10]; which deallocation is correct? Answer: delete[] arr;
Code fix task
Given a function that leaks, add delete/delete[] and nullptr assignments so every path frees allocated memory.
Output inspection
Students run the Product example and show constructor and destructor messages to demonstrate correct destructors on delete[].
Key Takeaway

Good assessments combine code modification, runtime observation, and short explanation of ownership decisions.
