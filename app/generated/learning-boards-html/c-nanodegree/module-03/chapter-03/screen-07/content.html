Module 3 › Chapter 3.3 › Safe deallocation
Process Flow
Steps for safe deletion
  1. Confirm ownership and that the pointer is not nullptr.
  2. Call delete or delete[] as appropriate.
  3. Set the pointer to nullptr immediately after delete.
  4. Avoid using the pointer after deletion; check for nullptr before dereferencing.
Example pattern
delete ptr; ptr = nullptr; — simple but powerful to avoid double free and dangling pointer errors.
Common mistakes & checks
  • Double free: calling delete twice on the same memory corrupts the heap.
  • Dangling pointer: pointer still points to freed memory; dereferencing causes undefined behavior.
  • Null deletion is safe: delete nullptr; does nothing, so setting pointer to nullptr is a defensive practice.
Check your understanding
True or False: Setting ptr = nullptr replaces the need to call delete. (Answer: False — nullptr prevents dangling dereference but does not free memory unless delete was called beforehand.)
