unique_ptr in containers
Store ownership inside the container using moves so the container becomes the sole owner of those objects.
std::vector<std::unique_ptr<Gadget>> gadgets;
gadgets.push_back(std::make_unique<Gadget>("G301"));
// or move an existing one
gadgets.push_back(std::move(funcGadget));
When the vector is destroyed, each unique_ptr destructor runs, destructing the owned gadgets.
Extraction
To remove and keep an element, move it out first: auto item = std::move(gadgets[i]); gadgets.erase(gadgets.begin()+i);
Key Takeaway

Use moves to place unique_ptrs into containers. The container then owns and cleans up the resources.
