Learning Objectives
Learn → Understand → Apply → Master
Bloom: Learn · Understand · Apply · Master
01
Explain RAII
Describe how acquiring a resource in a constructor and releasing it in a destructor ensures deterministic cleanup, even with exceptions.
VERIFIED COMPETENCY MILESTONE
02
Recognize raw pointer risks
Identify leaks, double frees, and dangling pointers that arise from manual new/delete and unpredictable object lifetime.
VERIFIED COMPETENCY MILESTONE
03
Declare and initialize
Write std::unique_ptr for single objects and arrays and prefer the make_unique helper for safety and clarity.
VERIFIED COMPETENCY MILESTONE
04
Explain exclusive ownership
Understand why unique_ptr forbids copying and how that prevents double deletion and clarifies which object is responsible for cleanup.
VERIFIED COMPETENCY MILESTONE
