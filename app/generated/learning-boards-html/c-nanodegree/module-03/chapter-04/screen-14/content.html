Module 3 › Chapter 3.4 › Key Concepts
RAII
Acquire resources in constructors and release them in destructors for deterministic cleanup.
std::unique_ptr
A lightweight smart pointer that enforces exclusive ownership and automatic deletion.
Move semantics
Transfer ownership using move so the source becomes empty and the destination owns the resource.
Summary

Prefer unique_ptr for single ownership, construct with make_unique, move to transfer, and avoid manual deletes.
