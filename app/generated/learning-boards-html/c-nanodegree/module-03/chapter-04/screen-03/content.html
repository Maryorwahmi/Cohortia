Objectives — Apply and Avoid

Move from concept to practice: learn move semantics, arrays, container storage, and common pitfalls.

05 Transfer ownership
Use move operations to pass unique_ptr by value or store it in containers, leaving the source empty and preventing copies.
VERIFIED COMPETENCY MILESTONE
06 Identify use cases
Choose unique_ptr for single ownership: function returns, class members, and scoped dynamic lifetimes.
VERIFIED COMPETENCY MILESTONE
07 Arrays with unique_ptr
Use the array form to ensure delete[] is called automatically when the pointer is destroyed.
VERIFIED COMPETENCY MILESTONE
08 Avoid common mistakes
Don't copy unique_ptr, don't delete a resource managed by unique_ptr, and be cautious when exposing raw pointers via get().
VERIFIED COMPETENCY MILESTONE
Mnemonic
Think: Make, Move, Manage. Make with make_unique, Move with std::move, Manage with RAII rules. When uncertain, prefer a unique owner and explicit transfer.
