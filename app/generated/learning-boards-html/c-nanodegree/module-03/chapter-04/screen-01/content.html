Introduction to std::unique_ptr
Why RAII and exclusive ownership reduce runtime errors in C++ programs.

Smart pointers are thin wrapper objects that manage raw pointers' lifetime. std::unique_ptr enforces a single owner and calls the appropriate delete when it is destroyed, so memory is released deterministically. Use make_unique to construct safely and prefer move for transfers.
