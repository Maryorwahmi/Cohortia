Module 3 › Chapter 3.4 › Move semantics
Transfer ownership with move
Moving transfers ownership without copying the resource.
Step 1: Construct a unique_ptr using make_unique.
Step 2: Transfer ownership with std::move(destination = std::move(source)).
Step 3: After move, source becomes null; do not dereference it.
Example: function return
std::unique_ptr<LargeObject> createLargeData() {
  return std::make_unique<LargeObject>(); // moved to caller
}
Common misconception
Moving is not copying. The managed object is not duplicated; only the pointer ownership moves to a new wrapper.
Key Takeaway

Use move semantics when handing ownership across scopes. After the move, treat the source as empty.
