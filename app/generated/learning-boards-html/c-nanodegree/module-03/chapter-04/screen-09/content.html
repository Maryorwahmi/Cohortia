Module 3 › Chapter 3.4 › Passing & returning
Pass by value to transfer ownership
Use std::move at the call site to transfer ownership into a function that should take responsibility.
void processResource(std::unique_ptr<MyResource> res) {
  res->doSomething();
} // res destroyed here

// caller
processResource(std::move(resourcePtr));
Factory return pattern
Returning a unique_ptr from a function hands ownership to the caller without copies.
std::unique_ptr<Gadget> createGadget() {
  return std::make_unique<Gadget>("G101");
}
Key Takeaway

Decide who should own a resource before passing. Use move for transfer and prefer returning unique_ptr from factories.
