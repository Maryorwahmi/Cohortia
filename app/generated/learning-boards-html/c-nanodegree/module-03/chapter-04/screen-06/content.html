Smart Pointer — definition and behavior
Acts like a pointer while owning and managing the lifetime of a resource automatically.
Mechanism: wrapper holds raw pointer and calls delete in its destructor.
Operators: supports arrow and dereference so usage remains familiar.
Ownership: the type encodes ownership policy — unique, shared, or weak.
Quick rule
If no two components should delete the same resource, use unique_ptr. If multiple owners must coexist, consider shared_ptr instead.
Concrete refactor
// before
Foo* f = new Foo();
// ...
delete f;

// after
auto f = std::make_unique<Foo>(); // destroyed automatically
Key Takeaway

Smart pointers preserve pointer syntax while giving deterministic cleanup. unique_ptr is the single-owner form.
