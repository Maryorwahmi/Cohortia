unique_ptr for arrays
Use the array specialization so delete[] is called at destruction.
std::unique_ptr<MyResource[]> resourceArray = std::make_unique<MyResource[]>(3);
resourceArray[0] = MyResource("ArrayElem1");
resourceArray[1] = MyResource("ArrayElem2");
When resourceArray goes out of scope, delete[] is called automatically. Never pair unique_ptr<T[]> with manual delete[].
Caveat
For polymorphic arrays or when element construction is complex, consider using containers like std::vector or smart pointers per element to avoid slicing and complicated lifetime rules.
Key Takeaway

Use unique_ptr<T[]> for simple dynamic arrays so you get correct delete[] semantics and automatic cleanup.
