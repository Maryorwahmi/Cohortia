Definition
std::lock_guard<std::mutex>
Lightweight RAII wrapper that locks in constructor and unlocks in destructor.
int shared_counter_lg = 0;
std::mutex counter_mutex_lg;

void increment_counter_lg() {
  for (int i = 0; i < 100000; ++i) {
    std::lock_guard<std::mutex> lock(counter_mutex_lg);
    shared_counter_lg++;
  }
}
Because the lock_guard object is destroyed at the end of each iteration, the mutex is always released, even if exceptions occur.
When to use
  • Simple critical sections with clear lexical scope.
  • When you want automatic unlocking on exceptions or early returns.
Key Takeaway

Prefer std::lock_guard for short, scope-bound critical sections to ensure exception safety with minimal syntax.

Pro tip: declare the lock_guard as close as possible to the critical operation so the locked region is obviously minimal.
