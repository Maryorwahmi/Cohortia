Definition
std::recursive_mutex
Allows the same thread to lock multiple times; counts lock depth per thread.
When to consider it
  • Recursive functions that must lock at multiple levels.
  • Complex APIs where inner and outer code both need the same lock.
Warning: it can hide design issues; prefer clearer ownership and smaller critical sections.
Short analogy
Think of recursive_mutex as a bathroom key that counts how many times the same person has locked the door; it helps when the same thread re-enters locked code, but it doesn't help two people trying to use two different doors.
Key Takeaway

Prefer refactoring over recursive_mutex; only use recursive_mutex when re-entrancy is unavoidable and well-documented.
