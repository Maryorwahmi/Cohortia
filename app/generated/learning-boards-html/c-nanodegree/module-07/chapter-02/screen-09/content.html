Process Flow
Deadlock Patterns
  1. Establish a global order for mutex acquisition and follow it everywhere.
  2. Use std::lock(m1, m2, ...) to acquire multiple mutexes atomically.
  3. Use try_lock or timed try_lock to attempt and back off instead of blocking forever.
Example: if you always lock mutex A then B, no two threads can deadlock by reversing the order.
std::lock example
std::mutex m1, m2;

void transfer() {
  std::lock(m1, m2); // acquires both without deadlock
  std::lock_guard<std::mutex> lk1(m1, std::adopt_lock);
  std::lock_guard<std::mutex> lk2(m2, std::adopt_lock);
  // safe to work with both resources
}
std::adopt_lock tells lock_guard that the mutexes are already locked by std::lock. This prevents a deadlock in many multi-mutex scenarios.
