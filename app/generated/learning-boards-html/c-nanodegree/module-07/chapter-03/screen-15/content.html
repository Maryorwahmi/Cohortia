Module 7 › Chapter 7.3 › Quick Reference
Use predicates
Always check the condition after wake to handle spurious wakeups safely.
Same mutex for state
Guard flags and shared containers with the same mutex the predicate examines to avoid races.
Pick the right primitive
Condition variables for coordination, futures for one-time results, async for quick tasks, shared_mutex for reads.
Closing thought
Correctness first: write predicates and protect shared state, then optimize with shared locks or async once behavior is validated.
