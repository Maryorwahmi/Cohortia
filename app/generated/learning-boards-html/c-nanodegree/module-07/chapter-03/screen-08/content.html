Module 7 › Chapter 7.3 › std::promise & std::future
How they relate
A promise sets either a value or an exception. The associated future is retrieved by calling promise.get_future() and can block on get() to receive the result. Use this pair for single, one‑time results between threads.
Behavior notes
get() blocks until the value or exception is set. get() can be called only once; calling it again is an error.
When to use
For one-off tasks where a single result is produced asynchronously, such as computing a value on a background thread and returning it to the requester.
Concrete example
// promise/future pattern (excerpt)
std::promise<int> p;
std::future<int> f = p.get_future();
std::thread t([&p]{ int r = calculate_sum(10,20); p.set_value(r); });
// Main thread can do other work...
int sum = f.get(); // blocks until promise set_value
Misuse to avoid
Do not use promise/future for frequent updates. If you need many results over time, prefer a queue protected by a mutex and signaled with condition variables.
