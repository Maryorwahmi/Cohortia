01
Producer‑Consumer: real scenario
Create a task queue where a producer adds jobs and multiple consumers process them. Use notify_one and a finished flag to terminate consumers predictably.
VERIFIED COMPETENCY MILESTONE
02
Spurious wakeups: defensive coding
Always supply a predicate to wait() so a wakeup only proceeds when the condition is true. This prevents subtle timing bugs in high concurrency.
VERIFIED COMPETENCY MILESTONE
03
promise & future: ownership
Use promise to deliver a single result and future to receive it. Remember futures are single‑use; calling get() twice is an error.
VERIFIED COMPETENCY MILESTONE
04
std::async: choose policy
Experiment with async and deferred policies to control whether work runs on a new thread or when get() is called. Pick the policy that matches responsiveness and resource cost.
