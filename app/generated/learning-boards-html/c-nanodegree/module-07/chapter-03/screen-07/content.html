Module 7 › Chapter 7.3 › Spurious Wakeups
What is a spurious wakeup?

A spurious wakeup is when a thread waiting on a condition variable wakes without a matching notify. Because these can occur, code must re-check the condition it cares about before proceeding. That is the role of a predicate in wait().

Best practice
Use wait(lock, predicate) or while(!predicate) cv.wait(lock) so the condition is always verified after wake.
Concrete predicate example
A consumer's predicate often looks like: []{ return !queue.empty() || finished; } This ensures the consumer only continues when there is data or when production is done.
Misconception check

Spurious wakeups are not caused by incorrect notify usage. They are an allowed behavior. Defensive predicates make your code portable and correct.
