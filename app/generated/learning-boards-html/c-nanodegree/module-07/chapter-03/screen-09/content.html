Module 7 › Chapter 7.3 › promise & future Example
Example code
#include <iostream>
#include <thread>
#include <future>
#include <chrono>

int calculate_sum(int a, int b) {
  std::this_thread::sleep_for(std::chrono::seconds(2));
  return a + b;
}

int main() {
  std::promise<int> p;
  std::future<int> f = p.get_future();

  std::thread t([&p]{
    try {
      int result = calculate_sum(10, 20);
      p.set_value(result);
    } catch(...) {
      p.set_exception(std::current_exception());
    }
  });

  std::cout << "Main thread doing other work..." << std::endl;
  int sum = f.get();
  std::cout << "Sum is: " << sum << std::endl;
  t.join();
}
Notes and pitfalls
  • Call set_exception on the promise to propagate errors to the waiting thread.
  • Ensure the promise remains valid until set_value or set_exception is called.
  • Remember that future::get is single-use; design ownership accordingly.
Try this
Modify the worker to throw an exception and verify that get() rethrows it in main. That helps you see cross-thread exception propagation in action.
