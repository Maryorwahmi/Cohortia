Checklist
  • Verify capture lifetimes before launching threads.
  • Prefer const auto& for read-only range loops.
  • Use auto for iterator types and lambda returns.
  • Use structured bindings to name pair/tuple elements.
  • Use shared ownership for large objects passed to threads when needed.
  • Avoid detaching threads unless lifetimes are explicit and safe.
Pro tip
When in doubt, prefer clarity over micro-optimization. Explicit code is easier to audit for concurrency bugs.
