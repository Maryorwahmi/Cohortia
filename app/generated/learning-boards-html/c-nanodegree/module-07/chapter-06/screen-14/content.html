Worker snapshot
Capture only the data the worker needs by value, or pass shared ownership if copying is expensive.
std::vector<std::pair<std::string,int>> users = ...;
std::thread t([users]() { // users copied safely
  for (const auto& [id, score] : users) {
    // process
  }
});
t.join();
Concurrency note
If you need to mutate shared data, use mutexes or atomics. The modern syntax helps you focus on logic while you design synchronization separately.
Takeaway
Use modern syntax to express intent. Then check lifetimes and synchronization as a separate step.
