When to use auto
  • For iterators: avoid long template names.
  • For lambda results: the compiler usually deduces return types.
  • When the initializer makes the type obvious from context.
Caution
Avoid auto when the type affects overload resolution, signedness, or performance characteristics.
Examples
std::map<std::string,int> scores;
// Without auto:
std::map<std::string,int>::iterator it = scores.begin();
// With auto:
auto it = scores.begin();

// Lambda and auto:
auto add = [](int a, int b) { return a + b; };
auto sum = add(2,3); // sum deduced as int
