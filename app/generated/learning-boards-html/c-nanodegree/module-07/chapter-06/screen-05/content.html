Value capture
Creates copies of captured variables. Safe when the lambda may outlive locals, often used for thread entry points.
Example card: snapshot semantics for a thread.
Use when: lambda is stored, run asynchronously, or passed to a thread.
Reference capture
Refers to original variables without copying. Efficient for large read-only structures when lifetime is guaranteed by scope.
Example card: short callback in the same scope that modifies a local counter.
Use when: lambda is short-lived and you need to modify or avoid copying large objects.
Concrete example — safe thread capture
Capture only what the thread needs by value; pass large read-only containers by shared pointer or copy if needed to guarantee lifetime.
// Safe: capture x by value and message by value
int x = 10;
std::string message = "Hi";
std::thread t([x, message]() {
  std::cout << "x: " << x << ", msg: " << message << std::endl;
});
t.join();
Pitfall

Capturing by reference a local that is destroyed before the thread runs leads to undefined behavior. Always consider object lifetime first.
