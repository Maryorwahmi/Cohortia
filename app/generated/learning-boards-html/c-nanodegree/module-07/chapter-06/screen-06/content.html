Spawn, capture safely, join

We will create a thread that prints captured values and then join it. Observe how captured value differs from the original after modification.
#include <iostream>
#include <thread>
#include <string>

int main() {
  int x = 1;
  std::string msg = "Hello";
  std::thread t([x, msg]() {
    std::cout << "Thread sees: " << x << ", " << msg << std::endl;
  });
  x = 42; // original changed after thread created
  msg = "World";
  t.join();
  std::cout << "Original x: " << x << std::endl;
}
Explanation
  • Capturing x and msg by value creates independent copies for the thread.
  • Changes to the originals after thread creation do not affect captured copies.
  • Joining ensures the thread completes before main exits, preventing premature destruction.
  • Do not detach unless you explicitly manage object lifetimes across threads.
Pro tip

For large read-only containers, prefer passing a shared pointer by value to the lambda to avoid copying while guaranteeing lifetime.
