Module 7 › Chapter 7.6 › Practice tips
Avoid detached refs
Detached threads with reference captures often lead to lifetime bugs. Prefer join or value capture.
Balance copies
For large data, prefer shared ownership to copies when safe; for small data, copying is simpler and safer.
Run quick experiments
Modify originals after thread start to see whether captured values are snapshots or live references.
Final thought

Modern syntax helps express intent. Use it alongside careful lifetime and synchronization reasoning to build safer concurrent programs.
