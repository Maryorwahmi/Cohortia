By value
for (int n : numbers) — copies elements. Use for small types or when you need a local copy.
std::vector<int> v = {1,2,3};
for (int n : v) {
  std::cout << n << std::endl;
}
By reference / const reference
for (int& n : numbers) modifies elements. for (const int& n : numbers) reads without copy.
for (int& n : v) { n *= 2; }
for (const int& n : v) { std::cout << n; }
Real-world rule
Default to const auto& for read-only containers of complex objects; use non-const reference only when intentional mutation is required.
