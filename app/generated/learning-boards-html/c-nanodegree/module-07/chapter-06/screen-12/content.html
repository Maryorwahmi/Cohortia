Starter code
using UserData = std::vector<std::pair<std::string,int>>;
UserData users = {{"userA",100},{"userB",150}};

std::thread t([&users]() {
  for (const auto& [id, score] : users) {
    std::cout << id << ": " << score << std::endl;
  }
});

t.join();
Notes
  • Capturing users by const reference is acceptable here because t.join() happens before users is destroyed.
  • If t was detached, capturing by value or using a shared pointer would be safer.
  • Always reason about lifetime when a lambda escapes its defining scope.
