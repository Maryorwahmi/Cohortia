Module 7 › Chapter 7.1 › Creating std::thread
How to construct
std::thread t(callable, arg1, arg2); will start a new execution path that invokes callable(arg1, arg2).
Argument rules
  • Values are forwarded and often copied into the new thread.
  • Passing references requires ensuring the referenced object lives long enough.
  • Move heavy objects into the thread to avoid expensive copies.
Concrete example
If workerFunction expects an int and const string&, prefer passing a string that outlives the thread or pass a moved string to transfer ownership.
Common mistake
Passing a reference to a local variable that is destroyed when the creating function returns leads to undefined behavior when the thread later accesses it.
Pro Tip

Prefer small value types or explicit moves when transferring ownership into a thread.
