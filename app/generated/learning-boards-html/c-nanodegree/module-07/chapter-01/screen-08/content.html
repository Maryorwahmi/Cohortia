Module 7 › Chapter 7.1 › detach()
What detach does
detach makes the thread run independently; the std::thread object no longer controls it and resources are reclaimed when it finishes.
When to use
  • Fire-and-forget background tasks with no shared lifetime concerns.
  • Short-lived logging or telemetry tasks that do not access transient data.
Risks
Detached threads can outlive main or reference destroyed objects, which leads to undefined behavior and subtle bugs.
Practical guidance
Prefer join for predictable cleanup. If detaching, ensure the thread owns or copies needed data and handles its own errors.
Warning

Detached threads remove control; only detach when you can guarantee safe independent execution.
