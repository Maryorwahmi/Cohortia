Module 7 › Chapter 7.1 › What is a Thread?
Definition
A thread is the smallest unit of execution schedulable by the OS inside a process.
Properties
  • Shares process memory and resources.
  • Has its own call stack and instruction pointer.
  • Starts executing immediately after creation.
Concrete scenario
A server process using one thread per client can process requests concurrently while sharing a cache in memory. That cache must be accessed carefully to avoid corruption.
Misconception
Threads are not the same as processes; they are lighter weight and share memory, so errors propagate more easily between threads.
Key Takeaway

Threads make concurrent programs possible but demand discipline when sharing memory.
