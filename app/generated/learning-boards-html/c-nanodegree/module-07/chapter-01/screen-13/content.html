Module 7 › Chapter 7.1 › Thread Ownership
Container + join
Store threads in a vector then iterate and join before leaving scope. Good for batch tasks.
Detach per request
Useful for server loops that must remain responsive. Ensure detached threads own their data.
RAII wrappers
Wrap threads in types that join on destruction to avoid forgotten joins; apply intentionally to avoid hidden blocking.
Key Takeaway

Pick one ownership model per subsystem and document it so threads are consistently created and cleaned up.
