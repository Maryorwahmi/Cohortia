Module 7 › Chapter 7.1 › UI Responsiveness
Problem
Long work on the main thread makes the UI freeze and lose interactivity.
Solution
Move heavy tasks to background threads and communicate progress or completion back to the UI thread safely.
Concrete example
A photo editor applies a filter in a worker thread and periodically posts progress to the UI thread, which updates a progress bar without freezing.
Best practice
Limit background threads, own data per worker, and use safe communication primitives for UI updates.
Key Takeaway

Background threads improve perceived performance by keeping the UI responsive while work runs asynchronously.
