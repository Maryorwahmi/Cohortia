Module 7 › Chapter 7.1 › Race Conditions
What is a race?
When the result depends on the relative timing of thread operations on shared state.
Simple example
Two threads incrementing the same counter can read, compute, and write in overlapping ways that lose updates.
Symptoms
  • Non-deterministic or incorrect final values.
  • Bugs that appear only under heavy load or on different hardware.
  • Hard-to-reproduce failures tied to scheduling.
Warning

Race conditions break correctness. Plan synchronization for any shared mutable data.
