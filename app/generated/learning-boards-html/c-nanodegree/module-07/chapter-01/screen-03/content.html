Practice: launch threads with arguments

Create threads that call the same function with different ids and messages. Observe how arguments are copied or referenced.

Mnemonic
Think ID + message per thread: each thread gets its own inputs so work is independent unless you share state.
Safety tip: always pair a thread with join or detach before destruction.
Practice: compare join and detach

Run the hands-on activity: join all threads, then try detaching some and watch how the main program exit changes and whether background work completes.

VERIFIED COMPETENCY MILESTONE
You can explain the observed runtime difference and the risks of detached threads that outlive main.
