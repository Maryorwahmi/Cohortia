Module 7 › Chapter 7.1 › Hands-on Activity
Steps
  1. Implement performTask that prints start, sleeps, then prints finish.
  2. Create three threads with durations 2, 4, and 6 seconds.
  3. Run with all threads joined and observe output and total time.
  4. Modify to detach two threads, join one, and optionally sleep in main to allow detached threads to run.
Observations to record
  • Does the main program wait for detached threads to finish?
  • Is total runtime reduced when detaching threads?
  • Do detached threads sometimes not complete if main exits early?
Tip: add a sleep in main after detaching if you want detached threads time to complete during the experiment.
Key Takeaway

Hands-on comparison clarifies lifecycle trade-offs between join and detach.
