Module 7 › Chapter 7.1 › join() Explained
What join does
join blocks the calling thread until the joined thread finishes, making it safe to rely on its results or cleaned-up resources.
Typical pattern
  1. Create thread and store it.
  2. Later, call join to wait for completion.
  3. Proceed once all required threads have joined.
Concrete code habit
When creating multiple threads in a vector, iterate and call join on each before leaving the scope where shared objects live.
Mistake to avoid
Letting a joinable std::thread be destroyed triggers std::terminate. Always pair create with explicit join if you require the thread to finish.
Key Takeaway

Call join to wait and prevent premature destruction of joinable threads.
