Module 7 › Chapter 7.1 › workerFunction Example
Code
#include <iostream>
#include <thread>
#include <chrono>
#include <string>

void workerFunction(int id, const std::string& message) {
  std::cout << "Worker thread " << id << " started with message: " << message << std::endl;
  std::this_thread::sleep_for(std::chrono::seconds(2));
  std::cout << "Worker thread " << id << " finished." << std::endl;
}

int main() {
  std::thread t1(workerFunction, 1, "Hello from thread 1!");
  std::thread t2(workerFunction, 2, "Greetings from thread 2!");
  t1.join();
  t2.join();
  return 0;
}
Explanation
  • Each thread calls workerFunction with its own id and message.
  • sleep_for simulates work; join waits for that work to finish.
  • Argument passing uses copying or const reference; ensure lifetimes match.
Check: remove joins and the program likely terminates due to joinable destructors.
Key Takeaway

Join threads when you rely on their results or when they touch shared, in-scope resources.
