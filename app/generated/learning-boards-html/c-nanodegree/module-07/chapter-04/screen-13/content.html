Module 7 › Chapter 7.4 › Choosing memory order
Step 1
Is ordering with other memory required? If no, use relaxed.
Step 2
Are you publishing data written earlier? Use release on store and acquire on load.
Step 3
If unsure or for global reasoning, choose seq_cst then refine only after proof or measurement.
Key Takeaway

Always match the memory order to your data dependencies; prefer simpler rules until performance demands a weaker order.
