Module 7 › Chapter 7.4 › Key Concepts
Atomic Operation
An indivisible update that other threads never observe partially.
std::atomic<T>
Template providing atomic types and operations like load, store, fetch_add, and compare_exchange.
Memory Order
Defines ordering constraints: relaxed, acquire, release, acq_rel, and seq_cst; pick the weakest that preserves correctness.
Summary
Use atomics for efficient single-variable safety, CAS patterns for lock-free updates, and acquire-release to publish data; prefer seq_cst when simplicity is critical and only relax ordering after proof or measurement.
