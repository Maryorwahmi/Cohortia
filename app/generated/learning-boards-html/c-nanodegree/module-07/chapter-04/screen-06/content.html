Module 7 › Chapter 7.4 › Compare-and-swap
Pattern
CAS retry loop
std::atomic<int> value{0};
int expected = value.load();
int desired = compute_new(expected);
while (!value.compare_exchange_weak(expected, desired)) {
  if (expected != condition_value) return; // another thread changed it
  desired = compute_new(expected); // recompute if needed
}
compare_exchange_weak may fail spuriously; the loop handles retries gracefully.
Weak vs Strong
  • Weak: may fail spuriously; efficient in loops.
  • Strong: no spurious failures; useful when not looping.
Common mistake
Using weak without a retry loop can make an operation wrongly give up on a spurious failure, causing correctness bugs.
Key Takeaway

CAS is powerful for lock-free updates; prefer weak in retry loops and strong when no retries are expected.
