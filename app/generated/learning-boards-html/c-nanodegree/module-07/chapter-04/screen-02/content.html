Learning Objectives

These objectives focus on practical skills: using std::atomic, implementing CAS-based updates, and reasoning about memory ordering for correctness and performance.

01
Limitations of mutexes
Explain why using a mutex for simple single-variable updates can be overkill and cause contention. This matters for performance-critical loops like counters.
VERIFIED COMPETENCY MILESTONE
02
Use std::atomic types
Declare atomic variables and perform atomic load/store to ensure thread-safe access without explicit locks, reducing latency for small operations.
VERIFIED COMPETENCY MILESTONE
03
Implement CAS operations
Use compare_exchange_weak in retry loops and pick compare_exchange_strong when spurious failures must be avoided for correctness.
VERIFIED COMPETENCY MILESTONE
04
Understand memory ordering
Differentiate relaxed, acquire, release, and seq_cst orders and choose the smallest order that preserves program correctness.
VERIFIED COMPETENCY MILESTONE
