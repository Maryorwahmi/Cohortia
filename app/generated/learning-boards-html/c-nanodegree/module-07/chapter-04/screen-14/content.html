Module 7 › Chapter 7.4 › Experiment checklist
Implement
  1. Write mutex-protected increment function.
  2. Write atomic increment function.
  3. Reset counters between runs.
Measure
  • Run multiple trials and average.
  • Vary thread count to see scaling.
  • Record timing and final values.
Reason
Justify memory order choices and decide whether replacing a mutex is warranted given performance and maintainability.
Key Takeaway

Careful measurement and documented reasoning are essential before adopting lock-free code in production.
