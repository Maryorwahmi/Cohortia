Module 7 › Chapter 7.4 › std::atomic basics
Definition
What is std::atomic?
A template that provides atomic operations on fundamental types. It makes common operations indivisible without an explicit lock.
  • load() — atomic read
  • store() — atomic write
  • fetch_add()/fetch_sub() — perform arithmetic and return old value
  • exchange() — replace and return old value
Concrete example
#include <atomic>
std::atomic<int> atomic_counter(0);
// Many threads:
atomic_counter.fetch_add(1);
int v = atomic_counter.load();
Use the API directly for explicit ordering and portability.
Example card
Reference counting: call fetch_add when acquiring a reference and fetch_sub when releasing, returning the previous count to decide when to free resources.
Pro tip
Prefer explicit fetch_* and load/store calls to make memory order arguments visible in code review and to avoid accidental portability issues.
Key Takeaway

Atomic APIs give you safe, lock-free primitives for per-variable updates; choose operations that also return the values you need.
