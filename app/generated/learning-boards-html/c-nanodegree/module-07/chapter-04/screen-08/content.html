Module 7 › Chapter 7.4 › Memory Model
Core idea
Reordering improves performance but requires explicit ordering when threads must observe writes in a specific order. Acquire and release establish a happens-before relationship between a writer and a reader.
Producer-consumer example
Producer writes data into memory, then does ready_flag.store(true, release). Consumer spins on ready_flag.load(acquire) and then reads the data. Acquire ensures the consumer sees the writes the producer made before its release.
Misconception
Seeing a flag set does not automatically guarantee the visibility of earlier writes unless you use matching acquire-release semantics. Relying on plain atomic loads/stores without the right order may produce stale or partially initialized data reads.
Key Takeaway

Acquire-release pairs are the fundamental tool for establishing visibility between threads in lock-free designs.
