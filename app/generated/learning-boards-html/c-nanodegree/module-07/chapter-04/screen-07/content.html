Module 7 › Chapter 7.4 › Lock-free set-if-zero
Steps
1. Load current value
Read into expected.
2. Prepare desired
Decide the new value if expected is acceptable.
3. Retry CAS
Loop using compare_exchange_weak until success or a different value observed.
Code walkthrough
std::atomic<int> value{0};
void set_if_zero() {
  int expected = 0;
  int desired = 1;
  while (!value.compare_exchange_weak(expected, desired)) {
    if (expected != 0) return; // someone else beat us
    // spurious failure — retry with expected still 0
  }
  // success: we set value to 1
}
Key Takeaway

CAS-based one-shot setters are efficient and safe when implemented with a retry loop and minimal side effects inside the loop.
