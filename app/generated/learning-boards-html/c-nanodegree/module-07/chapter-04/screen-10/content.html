Module 7 › Chapter 7.4 › Acquire-Release Pattern
Producer
data.push_back(1);
data.push_back(2);
ready_flag.store(true, std::memory_order_release);
All writes to data happen-before the release store.
Consumer
while (!ready_flag.load(std::memory_order_acquire)) {
  sleep();
}
read data; // guaranteed to see producer writes
Acquire load ensures visibility of prior writes.
Key Takeaway

Acquire-release is the canonical memory-order pair to publish initialized data safely without locks.
