Learning Objectives — Continued

These objectives emphasize implementation, shutdown, and design trade-offs.

Worker loop and synchronization
  • Worker waits on condition_variable until tasks available or stop flag true.
  • Use mutex to protect queue access and stop flag checks.
  • Notify all workers on shutdown so they can exit cleanly.
VERIFIED COMPETENCY MILESTONE
Enqueue and futures
  • Wrap callable in packaged_task and push a wrapper that invokes it.
  • Return the associated future to the caller so values can be retrieved.
  • Handle exceptions inside the packaged_task so futures propagate them.
