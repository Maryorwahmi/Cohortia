Sizing and workload
CPU-bound tasks: limit threads near core count. I/O-bound tasks: more threads can be effective, but measure and tune.
Dynamic sizing & prioritization
Resizing adds complexity. Priorities need a different queue structure and careful fairness rules.
Practical checklist
  • Decide fixed or dynamic size.
  • Consider bounded queues and rejection strategy.
  • Capture task exceptions via packaged_task so futures report errors.
  • Provide cooperative cancellation points in tasks if needed.
