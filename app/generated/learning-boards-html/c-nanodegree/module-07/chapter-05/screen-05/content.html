Definition

Cooperative cancellation

Worker checks a stop token and exits gracefully when a stop is requested, allowing safe cleanup.

  • request_stop sets the stop request; the worker observes it via stop_token.
  • Worker decides when to stop, so invariants can be preserved.
  • Use frequent, well-defined cancellation points for responsiveness.
Misconception

Cancellation is not pre-emptive; the worker must check the token and perform a safe exit.

Example: jthread with stop_token
void workerFunction_jthread(int id, const std::string& message, std::stop_token stoken) {
  std::cout << "JThread " << id << " started" << std::endl;
  for (int i = 0; i < 5; ++i) {
    if (stoken.stop_requested()) {
      std::cout << "JThread " << id << ": Stop requested, exiting early." << std::endl;
      return;
    }
    // do a chunk of work
    std::this_thread::sleep_for(std::chrono::milliseconds(500));
  }
}
When to use
Long-running loops, background jobs, and cancelable tasks.
Pro tip
Place checks at natural safe points where invariants hold so cleanup is simple.
