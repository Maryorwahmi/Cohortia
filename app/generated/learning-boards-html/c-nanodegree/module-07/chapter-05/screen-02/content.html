Learning Objectives

01
Safe thread lifecycle
Explain how std::jthread's RAII automatic join reduces termination bugs.
Mnemonic: lock-and-release pattern — jthread ties join to object lifetime.

Cooperative cancellation
Use stop_source and stop_token to request and observe cancellation requests.
Mnemonic: flag-check loop — long work checks stop_requested.

Thread pool design
Design a task queue, workers, and a stop mechanism for graceful shutdown.
Mnemonic: assembly line — queue feeds workers.

04
Returning results
Wrap callables with packaged_task to obtain futures and collect results.
Mnemonic: envelope-inbox — packaged_task sends back a future.
