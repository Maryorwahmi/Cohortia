Architecture

ThreadPool components

Task queue
Holds std::function wrappers; push when tasks are enqueued.
Worker threads
Loop on condition_variable, pop task, execute, repeat until stop.
Mutex & condition_variable
Protects queue and synchronizes worker wake-ups.
Stop flag
Signals shutdown; set under mutex and notify all workers.
Key takeaway
All pool operations that access shared state must be synchronized. Shutdown must notify workers and join threads to avoid leaks or crashes.
