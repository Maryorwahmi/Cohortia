Worker lambda

workers.emplace_back([this] {
  while (true) {
    std::function<void()> task;
    {
      std::unique_lock<std::mutex> lock(this->queue_mutex);
      this->condition.wait(lock, [this] { return this->stop || !this->tasks.empty(); });
      if (this->stop && this->tasks.empty())
        return; // exit worker
      task = std::move(this->tasks.front());
      this->tasks.pop();
    }
    task(); // execute outside lock
  }
});
Supporting notes
  • Move tasks out of the queue to avoid copies and to run without holding the lock.
  • Use condition.wait with a predicate to avoid spurious wakeups causing busy loops.
  • On shutdown, set stop, notify_all, and join workers in the destructor.
Pro tip
Keep the critical section around minimal queue operations; run the heavy work outside the lock.
