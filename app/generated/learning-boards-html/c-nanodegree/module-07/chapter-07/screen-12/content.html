Module 8 › Chapter 7.7 › Common Mistakes
Control block duplication

Never build two shared_ptrs from the same raw pointer. Use std::make_shared to create one control block safely.

this and shared_from_this

If an object must provide a shared_ptr to itself, inherit enable_shared_from_this and use shared_from_this instead of creating a new shared_ptr from this.

weak_ptr pitfalls

Always call lock() and check the returned shared_ptr before accessing the object; otherwise you risk use-after-free.

Thread-safety

shared_ptr updates are atomic, but object state is not. Protect shared mutable state with mutexes even when using shared_ptr for lifetime management.

Pro-tip

Default to unique_ptr and only move to shared_ptr when shared lifetime is required; this reduces overhead and surprises.
