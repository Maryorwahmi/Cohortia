Module 8 › Chapter 7.7 › std::weak_ptr
Concept

Observe without ownership

weak_ptr does not affect reference count; lock to obtain a temporary shared_ptr if the object survives.

Pattern

Use weak_ptr for cache entries, observers, and back-references in graphs to avoid cycles.

Safe access idiom
std::weak_ptr<A> w = ...;
auto s = w.lock();
if (s) {
  s->do_something(); // safe while s is alive
} else {
  // object already destroyed
}
Misconception: weak_ptr magically prevents races — it only prevents ownership cycles; you still need synchronization when using the obtained shared_ptr across threads.
