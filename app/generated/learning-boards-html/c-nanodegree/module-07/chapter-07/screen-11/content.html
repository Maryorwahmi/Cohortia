Module 8 › Chapter 7.7 › Custom Deleters
Why use them

They make RAII applicable to FILE*, sockets, and other OS resources so cleanup always runs at destruction.

Design note

unique_ptr<T, Deleter> encodes the deleter type; shared_ptr stores the deleter in the control block.

Example (FILE*)
struct FileDeleter {
  void operator()(FILE* file) const {
    if (file) {
      std::cout << "Closing file using custom deleter." << std::endl;
      std::fclose(file);
    }
  }
};

void manage_file_with_unique_ptr() {
  FILE* f = std::fopen("example.txt", "w");
  std::unique_ptr<FILE, FileDeleter> file_ptr(f, FileDeleter{});
  if (file_ptr) std::fprintf(file_ptr.get(), "Hello
");
} // file closed by FileDeleter
Takeaway: prefer delegating cleanup to a deleter rather than spreading fclose or close calls across the codebase.
