Module 8 › Chapter 7.7 › Key Concepts
RAII
Bind resource lifetime to object lifetime for predictable cleanup.
unique_ptr
Exclusive, move-only ownership; prefer by default for clarity and performance.
shared_ptr / weak_ptr
shared_ptr shares lifetime via ref-count; weak_ptr observes without owning to prevent cycles.
Summary

Choose the simplest ownership that meets your needs, ensure synchronization for shared state, and use weak_ptr to keep graphs leak-free.
