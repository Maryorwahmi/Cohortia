Module 8 › Chapter 7.7 › unique_ptr Thread Handoff
Step-by-step
1
Create resource
Factory returns std::unique_ptr indicating ownership belongs to caller.
2
Move into thread
Use std::move to pass the unique_ptr into the thread function parameter.
3
Thread owns and cleans up
When the thread finishes, the unique_ptr is destroyed and the resource is released automatically.
Misconception check: moving does not copy; if you find yourself needing copies, reconsider whether shared ownership is the correct model.
Example snippet
// Producer thread
std::unique_ptr make_resource() {
  return std::make_unique(...);
}

// Consumer thread entry
void consumer(std::unique_ptr<Resource> r) {
  r->use();
} 

// Handoff
std::thread t(consumer, std::move(make_resource()));
Why it matters: the move expresses intent clearly and prevents accidental shared state that would require complex synchronization.
