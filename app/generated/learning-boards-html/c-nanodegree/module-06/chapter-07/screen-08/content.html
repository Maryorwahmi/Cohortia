Reconstructing Objects from a Stream

The `deserialize` Method for Text-Based Input

#include <sstream> // For stringstream in parsing
#include <exception> // For std::exception

class Book {
public:
    // ... existing members ...

    // Manual deserialization from an istream
    bool deserialize(std::istream& is) {
        std::string line;
        if (!std::getline(is, line)) {
            return false; // No more data or read error
        }

        std::stringstream ss(line);
        std::string yearStr, priceStr;

        // Read delimited fields
        if (std::getline(ss, title, '|') &&
            std::getline(ss, author, '|') &&
            std::getline(ss, yearStr, '|') &&
            std::getline(ss, priceStr)) { // Last field doesn't need a delimiter
            try {
                publicationYear = std::stoi(yearStr);
                price = std::stod(priceStr);
                return true;
            } catch (const std::exception& e) {
                std::cerr << "Deserialization error: Invalid number format in line: '" << line << "' - " << e.what() << std::endl;
                return false;
            }
        }
        std::cerr << "Deserialization error: Malformed line: '" << line << "'" << std::endl;
        return false; // Malformed line
    }
// ... rest of class ...
};
Parsing Steps
  • Reads a full line from `std::istream`.
  • Uses `std::stringstream` to parse the line.
  • `std::getline` extracts fields using `|` delimiter.
  • `std::stoi` and `std::stod` convert string fields to `int` and `double`.
  • Returns `true` on success, `false` on failure (e.g., EOF, malformed line, conversion error).
Error Handling

Robust error handling is critical. `try-catch` blocks manage exceptions from `stoi`/`stod` for invalid number formats, and checks for malformed lines ensure data integrity during reconstruction.

Key Takeaway

The `deserialize` method is responsible for safely parsing serialized text data, converting it back into native C++ types, and reconstructing the object's state while handling potential errors.
