Saving and Loading a Library

Demonstrating Manual Serialization with a `main` Function

#include <fstream>
#include <vector>
#include <cstdio>  // For std::remove
// ... Book class definition (as before) ...

int main() {
    const std::string filename = "books.dat";
    std::vector<Book> library = {
        {"The Hitchhiker's Guide to the Galaxy", "Douglas Adams", 1979, 12.99},
        {"1984", "George Orwell", 1949, 9.50}
    };

    // --- Serialization ---
    std::ofstream outFile(filename);
    if (!outFile.is_open()) {
        std::cerr << "Error: Could not open file for writing." << std::endl;
        return 1;
    }
    for (const auto& book : library) {
        book.serialize(outFile);
    }
    outFile.close();
    std::cout << "Library serialized to " << filename << std::endl;

    // --- Deserialization ---
    std::vector<Book> loadedLibrary;
    std::ifstream inFile(filename);
    if (!inFile.is_open()) {
        std::cerr << "Error: Could not open file for reading." << std::endl;
        return 1;
    }

    Book b;
    while (b.deserialize(inFile)) {
        loadedLibrary.push_back(b);
    }
    inFile.close();

    std::cout << "
--- Loaded Library ---" << std::endl;
    for (const auto& book : loadedLibrary) {
        book.print();
    }
    std::cout << "----------------------" << std::endl;

    std::remove(filename.c_str()); // Clean up
    return 0;
}
Serialization Flow
  • Create `std::vector` with initial data.
  • Open `std::ofstream` to `books.dat`.
  • Loop through books, calling `book.serialize(outFile)`.
  • Close `outFile`.
Deserialization Flow
  • Create empty `std::vector` for loaded data.
  • Open `std::ifstream` from `books.dat`.
  • Loop: create temporary `Book`, call `book.deserialize(inFile)`.
  • If successful, `push_back` to `loadedLibrary`.
  • Close `inFile`. Print `loadedLibrary` to verify.
Key Takeaway

This `main` function demonstrates the complete lifecycle of manual serialization and deserialization, from object creation to file I/O and data verification.
