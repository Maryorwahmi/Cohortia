Module 6 › Chapter 6.1 › Learning Objectives
Bloom Progress: Learn → Understand → Apply → Master
01
Understand importance
Explain why robust error handling prevents crashes, avoids data corruption, and signals recoverable failure conditions.
VERIFIED COMPETENCY MILESTONE
02
Try, Throw, Catch
Read and write guarded blocks that throw exceptions, and implement handlers that allow graceful recovery or orderly termination.
VERIFIED COMPETENCY MILESTONE
03
Standard Exceptions
Identify and use standard types such as runtime_error and bad_alloc for common failure modes.
VERIFIED COMPETENCY MILESTONE
04
Custom Exceptions
Design exceptions that carry application data by deriving from std::exception or a suitable base class.
VERIFIED COMPETENCY MILESTONE
05
Avoid Pitfalls
Recognize object slicing, copying, and destructor-throw risks and prefer safe catch patterns and resource cleanup strategies.
VERIFIED COMPETENCY MILESTONE
06
Catch-by-Reference
Catch exceptions by const reference to avoid slicing and unnecessary copies, preserving derived-class data and behavior.
VERIFIED COMPETENCY MILESTONE
07
Ordering Handlers
Place specific catch handlers before general ones and use catch-all only at high-level boundaries.
VERIFIED COMPETENCY MILESTONE
08
Resource Safety Awareness
Understand that exceptions interact with resource cleanup, and that RAII is the recommended approach to ensure deterministic release.
VERIFIED COMPETENCY MILESTONE
