Module 6 › Chapter 6.1 › Key Concepts
Exception Handling
Use exceptions to report exceptional runtime errors and centralize recovery logic for clearer code.
Catch by const reference
Avoid copies and object slicing by catching exceptions as const references, preserving derived data and behavior.
Destructor safety & RAII
Prevent throws from destructors and use RAII so resources are released safely during stack unwinding.
Summary takeaway
Signal clear errors with exceptions, preserve exception type and data by catching by const reference, and ensure deterministic cleanup to keep programs robust under failure.
