Stack unwinding
As propagation moves out of a function, local destructors are run. This ensures RAII-managed resources are released before reaching a handler.
Handler order matters
Place specific types before general ones. If a derived exception is thrown and a base type is caught by value first, derived information can be lost.
Example scenario
Call divide; if the function throws a runtime error for division by zero, the runtime will find a matching catch or continue unwinding up the stack until one is found or program termination occurs.
Common mistake
Using catch-all early hides the actual error type and makes correct recovery harder.
Key Takeaway

Throw to signal errors, let the runtime unwind safely, and catch where you can make the right decision based on the exception type.
