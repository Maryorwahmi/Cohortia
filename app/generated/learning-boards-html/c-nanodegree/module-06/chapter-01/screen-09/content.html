Comparison

By value vs By const reference

Catching by value
Copies the exception object; risk of slicing and extra cost.
Catching by const reference
Preserves the dynamic type, avoids copying, and prevents slicing.
Common mistake
Catching by value using a base type can strip derived data, making handlers blind to the full error context.
Concrete scenario
If InsufficientFundsException is thrown, handlers that catch the specific custom type by const reference can read current balance and requested amount. If a handler catches std::runtime_error by value first, that numeric context is gone.
Key Takeaway

Adopt catch (const T& e) as your default to preserve information and avoid slicing or unnecessary copies.
