Definition

Std exception types

std::bad_alloc
Used when memory allocation fails; handlers can try alternative strategies or fail gracefully.
std::out_of_range
Signals invalid container access like an index outside bounds.
std::invalid_argument
Indicates the caller passed an unacceptable argument value.
std::runtime_error
A general runtime problem when no more specific type suits the error.
Practical guidance
  • Prefer specific standard types that communicate intent and let callers choose appropriate recovery.
  • Use std::exception as a fallback handler to log unexpected standard errors.
  • Avoid throwing plain strings; std::exception derivatives provide polymorphism and a standard what() method.
Key Takeaway

Choose the most precise standard exception that fits the failure and reserve generic catches for top-level logging or shutdown handling.
