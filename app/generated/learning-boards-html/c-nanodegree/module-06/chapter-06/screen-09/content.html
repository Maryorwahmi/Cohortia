Definition
The engine behind iostream
streambuf handles buffering, conversion, and raw I/O for all streams.
• Virtual hooks: underflow (input), overflow (output) are overridden by derived classes.
• std::ifstream/ofstream and std::stringstream use different streambuf implementations.
• rdbuf() returns or sets the stream's associated streambuf pointer.
When to extend

Create a custom streambuf when you need on-the-fly transformation, multiplexing, or a nonstandard backend like a network socket.

Conceptual diagram
Streams delegate formatted I/O to streambuf implementations which talk to devices or memory.
Stream layers
  • High-level: std::ostream / std::istream — formatting and operators
  • Low-level: std::streambuf — buffering and device I/O
  • Device: file, memory, socket — the actual destination/source
