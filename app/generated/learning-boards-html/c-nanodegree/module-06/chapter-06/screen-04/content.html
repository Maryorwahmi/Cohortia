Core Concept
std::stringstream explained
Treat strings as readable or writable streams to reuse stream parsing/formatting logic.
• istringstream: read tokens, numbers, and lines from a string
• ostringstream: build formatted text with manipulators like fixed and setprecision
• Use str() to get or set the internal string
• Reset with str("") and clear() before reuse
Key Takeaway

Use stringstreams when stream-style parsing or formatted output improves clarity and safety over manual splitting or concatenation.

Concrete example (formatting)
#include <iostream>
#include <sstream> // std::ostringstream
#include <iomanip> // std::fixed, std::setprecision

std::ostringstream oss;
double price = 123.456;
oss << std::fixed << std::setprecision(2);
oss << "Price: $" << price << "
";
std::string s = oss.str(); // "Price: $123.46
"
Note: angle brackets are escaped here for display. When reusing oss, call oss.str("") and oss.clear().
