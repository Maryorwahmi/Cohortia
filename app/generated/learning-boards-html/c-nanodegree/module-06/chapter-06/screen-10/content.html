Process Flow
Redirect std::cout safely
Swap rdbuf, write, and restore.
// Redirect to a file:
std::streambuf* original = std::cout.rdbuf();
std::ofstream outFile("out.txt");
std::cout.rdbuf(outFile.rdbuf());
std::cout << "This goes to the file.
";
std::cout.rdbuf(original); // restore
outFile.close();

// Redirect to a stringstream:
std::ostringstream oss;
std::cout.rdbuf(oss.rdbuf());
std::cout << "Captured output." << std::endl;
std::cout.rdbuf(original);
std::string captured = oss.str();
Use RAII wrappers to guarantee restoration of the original buffer even on exceptions.
Concrete uses
  • Capture output for unit tests without changing function signatures.
  • Temporarily log to a file for diagnostics, then restore console output.
  • Collect output from third-party libraries that only write to std::cout.
Warning

Always restore the original rdbuf to avoid leaving output redirected after the operation completes.
