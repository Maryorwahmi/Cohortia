Key Concepts
Three compact reminders
std::stringstream
In-memory stream for parsing and formatted string construction using << and >>.
rdbuf() redirection
Swap a stream's streambuf to capture or reroute output to files or strings.
Custom streambuf
Derive and override underflow/overflow to implement custom I/O behaviors like filtering or multiplexing.
Summary
Use stringstreams for parsing and formatting, use rdbuf swaps for safe redirection, and consider custom streambufs only when transformation or special routing is required.
