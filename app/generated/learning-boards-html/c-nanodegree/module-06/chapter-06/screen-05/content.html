Build a formatted string
Use ostringstream and manipulators for consistent, localized formatting.
#include <sstream>
#include <iomanip>

std::ostringstream report;
report << "--- Sales Report ---
";
report << std::fixed << std::setprecision(2);
report << std::setw(10) << std::left << "Product"
       << " Qty " << "Price" << " Total
";

report << std::setw(10) << std::left << "Laptop"
       << std::setw(4) << std::right << 2
       << " $" << std::setw(7) << std::right << 1200.50
       << " $" << std::setw(8) << std::right << (2 * 1200.50) << "
";

std::string out = report.str();
• Use fixed and setprecision for monetary values.
• Use setw with left/right to align columns predictably.
• Reset with str("") and clear() when reusing the stream.
Concrete analogy
Think of ostringstream like filling labeled slots on a printed form: manipulators decide how each slot appears, and str() gives you the completed form as text.
Key Takeaway

Prefer ostringstream for robust formatted output; it handles types and spacing in a maintainable way.
