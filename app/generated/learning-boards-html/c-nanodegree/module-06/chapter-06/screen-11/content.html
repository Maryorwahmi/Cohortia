Advanced Concept
Custom std::streambuf
Override the low-level hooks to control I/O behavior.
• override overflow(int_type) to handle output buffering and flushing.
• override underflow() to supply buffered characters for input.
• ensure proper return values and error signaling expected by iostreams.
When to implement

When you must transform data at the byte level or route it to nonstandard backends, a custom streambuf is appropriate.

Use-case examples
  • Compress output in-memory before writing to disk.
  • Encrypt data as it is written to a log stream.
  • Forward every write to multiple destinations simultaneously.
Key Takeaway

Custom streambufs are powerful but require careful implementation of buffer semantics and correctness for formatted streams to behave properly.
