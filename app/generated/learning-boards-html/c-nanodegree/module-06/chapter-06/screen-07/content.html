Resetting a stringstream
Two-step reset: buffer and flags.
1. Call ss.str("") to clear or set the internal string.
2. Call ss.clear() to reset eof/fail flags.
3. Optionally reuse or reinitialize variables before new operations.
Pro tip

When parsing multiple lines, prefer constructing a fresh istringstream per line to avoid state mistakes.

Example
std::stringstream ss;
ss << "Hello " << 2023;
std::string s = ss.str(); // "Hello 2023"

ss.str(""); // clear content
ss.clear(); // reset flags
ss << "New data: " << 100;
std::string newData = ss.str();
