Learning Objectives
Skills to practice and verify
Bloom's Path: Learn → Understand → Apply → Master
01
Use std::stringstream
Create and use istringstream and ostringstream to parse and format data in memory, enabling clean string-based I/O without files.
VERIFIED COMPETENCY MILESTONE
02
Parse structured text
Extract tokens, numbers, and strings using >> and getline to handle CSV or labeled log lines robustly.
VERIFIED COMPETENCY MILESTONE
03
Redirect standard streams
Save and swap rdbuf pointers to capture std::cout into files or strings, useful for tests and logging capture.
VERIFIED COMPETENCY MILESTONE
04
Understand streambuf
Explain the role of std::streambuf and the functions to override when implementing a custom buffer for transformation or forwarding.
VERIFIED COMPETENCY MILESTONE
