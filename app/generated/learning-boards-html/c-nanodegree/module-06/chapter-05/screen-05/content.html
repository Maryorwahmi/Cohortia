Module 6 › Chapter 6.5 › Writing and Appending Text Files
Process Flow

Write or append safely

1. Choose mode

ofstream(filename) truncates. ofstream(filename, ios::app) appends.

2. Open and check

Call is_open and handle failures before writing.

3. Write data

Use insertion operator and manipulators for formatting.

4. Check errors

Check fail or bad after heavy writes to detect disk issues.

// Append example
std::ofstream logFile("log.txt", std::ios::app);
if (!logFile.is_open()) { /* handle error */ }
logFile << "New entry" << std::endl;
// logFile closed by RAII
Example Scenario

Sensor logger: open with ios::app each run so data accumulates across program executions while preserving prior readings.

Common Mistake

Opening without ios::app when you intended to append causes accidental truncation and data loss.

Key Takeaway

Use ios::app for logs; use default truncation when replacing files intentionally.
