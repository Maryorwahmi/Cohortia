Binary File I/O Basics

Open with ios::binary and use write/read with reinterpret_cast to transfer raw bytes for structs and arrays.

struct Point { int x; int y; double z; };
std::ofstream out("points.bin", std::ios::binary);
out.write(reinterpret_cast(&p1), sizeof(Point));
out.write(reinterpret_cast(&p2), sizeof(Point));
// Read back:
std::ifstream in("points.bin", std::ios::binary);
Point r;
while (in.read(reinterpret_cast(&r), sizeof(Point))) {
  // process r.x, r.y, r.z
}
Concrete example

Writing a small array of Point structs to a file and reading them back recreates the in-memory objects efficiently.

Portability note

Raw binary captures exact memory layout. For cross-platform exchange, define explicit byte formats or use serialization libraries.

Key Takeaway

Use ios::binary and read/write with size checks; be aware of endianness and padding for portability.
