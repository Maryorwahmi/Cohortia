Module 6 › Chapter 6.5 › Reading Files Correctly
Definition

Prefer post-read checks

Use while(std::getline(...)) or while(inFile >> var) so you only act on valid input.

std::ifstream inFile("scores.txt");
if (!inFile.is_open()) { /* handle missing file */ }
std::string name; int score;
while (inFile >> name >> score) {
  // process successful read of name and score
}
if (inFile.fail() && !inFile.eof()) {
  std::cerr << "Error: invalid format" << std::endl;
}
Why it matters

Eof-based loops can duplicate the last item or attempt to use partially filled buffers. Post-read checks avoid this class of bugs.

Concrete example

Loading high scores using extraction or getline ensures each parsed entry is valid before processing and storing.

Key Takeaway

Loop on the read operation, not on eof. Then check fail/eof to diagnose issues after the loop.
