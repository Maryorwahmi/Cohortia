Lab Walkthrough Goals

Follow these checkpoints to validate behavior and handle errors properly.

Checkpoint 1: Write text file

Use ofstream, check is_open, and observe truncation on open without ios::app.

Checkpoint 2: Read safely

Use std::getline or while(inFile >> data) to avoid eof-based loops.

Checkpoint 3: Append

Open with ios::app to add lines without deleting existing content.

Checkpoint 4: Binary I/O

Write structs with write and read, using reinterpret_cast and sizeof for byte accuracy.
