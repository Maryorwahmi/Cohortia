Core Concept

Verify binary transfers

Check the number of bytes read or the stream's state after operations to detect partial reads or write failures.

// Reading fixed-size records
Point p;
while (inFile.read(reinterpret_cast(&p), sizeof(Point))) {
  // full record read successfully
}
if (inFile.gcount() != 0 && inFile.gcount() != sizeof(Point)) {
  // partial trailing read: handle error
}
Practical tip

Write a simple header with a record count to validate file length before deserializing arrays of structs.

Common error

Forgetting ios::binary can corrupt binary data via newline translations on some platforms.

Key Takeaway

Always verify byte counts and include simple validation metadata for robust binary files.
