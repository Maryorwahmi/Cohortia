Learning Objectives

Skills to practice in the lab and verify competency.

Bloom: Learn → Understand → Apply → Master
01
Use ifstream/ofstream

Create, open, and close file streams, relying on RAII to release resources automatically. This prevents file descriptor leaks and ensures files close on scope exit.

VERIFIED COMPETENCY MILESTONE
02
Choose opening modes

Combine flags like in, out, app, binary to control truncation, appending, or binary access so data is read or preserved as intended.

VERIFIED COMPETENCY MILESTONE
03
Check stream state

Use is_open, fail, bad, eof, clear, and exceptions to detect and handle I/O errors reliably during read/write operations.

VERIFIED COMPETENCY MILESTONE
04
Binary read/write

Write and read raw bytes with write and read, using reinterpret_cast and sizeof for correct memory transfer. Watch portability concerns like padding.

VERIFIED COMPETENCY MILESTONE
