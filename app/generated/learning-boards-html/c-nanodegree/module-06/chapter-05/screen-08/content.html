Core Concept

Stream State Flags

Interpret flags to distinguish normal EOF from format errors and unrecoverable I/O failures.

good()

True if no error flags set.

fail()

True if failbit or badbit set (formatting or logical error).

bad()

True for unrecoverable errors (hardware, disk full).

eof()

True when end-of-file reached by a read operation.

Practical check

After reading loop, if fail() and not eof(), report format error; if bad(), halt and report I/O failure.
