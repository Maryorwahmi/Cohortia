Definition

File Opening Modes

Use flags to control whether files are read, written, appended, truncated, or opened in binary mode.

std::ios::in

Open for reading (default for ifstream).

std::ios::out

Open for writing (ofstream default; often truncates).

std::ios::app

All writes append to end; safe for logs.

std::ios::ate

Seek to end on open, but writing may occur elsewhere if you seek.

std::ios::trunc

Truncate file when opening; beware data loss.

std::ios::binary

Open in binary mode to read/write raw bytes (no translations).

Combine with |

Example: std::ofstream(f, std::ios::out | std::ios::app | std::ios::binary) opens for binary appending writes.
