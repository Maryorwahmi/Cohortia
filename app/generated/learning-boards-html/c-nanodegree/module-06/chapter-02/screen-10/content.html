Module 6 › Chapter 6.2 › unique_ptr walkthrough
Trace the lifetime
Creation, exception, and destructor messages illustrate RAII behavior.
// Construct resources with unique_ptr std::unique_ptr<MyResource> res1 = std::make_unique<MyResource>(1); std::unique_ptr<MyResource> res2 = std::make_unique<MyResource>(2); std::unique_ptr<MyResource> res3 = std::make_unique<MyResource>(3); res1->doWork(); res2->doWork(); // throws here // res3 may not be constructed or used
Observed runtime output
You would see acquisition messages for resources constructed, then when an exception occurs you'll see release messages for those same resources as destructors run during unwinding.
Key Takeaway

unique_ptr provides deterministic cleanup even when exceptions disrupt control flow.
