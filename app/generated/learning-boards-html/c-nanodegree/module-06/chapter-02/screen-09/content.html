Module 6 › Chapter 6.2 › Smart pointers
Smart pointers implement RAII
unique_ptr for exclusive ownership, shared_ptr for shared ownership; both call delete when their lifetime ends.
std::unique_ptr
Exclusive ownership; destructor calls delete on the managed pointer when it goes out of scope.
std::shared_ptr
Shared ownership; resource is destroyed when the last owner is destroyed.
Concrete usage
std::unique_ptr<MyResource> res = std::make_unique<MyResource>(1);
res->doWork(); // If exception is thrown, res's destructor still runs and deletes the object.

std::shared_ptr<MyResource> s1 = std::make_shared<MyResource>(2);
{
  auto s2 = s1; // shared ownership, destructor runs when last shared_ptr is destroyed
}
Key Takeaway

Smart pointers provide RAII semantics for dynamic memory and prevent leaks during exceptions.

Misuse warning
Do not delete memory managed by a smart pointer elsewhere; prefer one ownership model per resource.
