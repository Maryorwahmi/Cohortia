Non-RAII file handling
void processFile(const std::string& filename) {
  FILE* file = fopen(filename.c_str(), "r");
  if (!file) throw std::runtime_error("Failed to open file.");
  // ... complex logic that may throw ...
  fclose(file); // may be skipped if an exception occurs
}
Risk
Leaks and stale file handles when exceptions interrupt the normal close call.
RAII approach
Use std::fstream or a custom wrapper whose destructor calls close, so the file is closed even if an exception occurs.
Benefit
Automatic, central cleanup that is reliable during both normal control flow and exceptions.
