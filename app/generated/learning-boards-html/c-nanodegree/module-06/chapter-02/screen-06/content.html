Module 6 › Chapter 6.2 › Stack Unwinding
What is stack unwinding?
It is the process that destroys automatic objects as an exception moves up the call stack.
Definition
Destructors for local objects are invoked in reverse order of construction until a catch block is found.
Concrete example
If a local resource's method throws, previously constructed resources still have their destructors executed, freeing handles or memory.
// MyResource example (conceptual) class MyResource { public: MyResource(int id) : id_(id) { std::cout << "Acquired " << id_ << std::endl; } ~MyResource() { std::cout << "Released " << id_ << std::endl; } void doWork() { if (id_ == 2) throw std::runtime_error("Error in resource 2"); } private: int id_; }; // When doWork() throws, destructors for constructed objects are run during unwinding.
Misconception
Raw pointers are not automatically freed during unwinding; objects with destructors are.
Key Takeaway

Design resources as objects with safe destructors so stack unwinding reliably releases them.
