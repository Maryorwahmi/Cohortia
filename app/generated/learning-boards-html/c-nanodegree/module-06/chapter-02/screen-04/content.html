noexcept: a non-throwing contract
Declare functions that are guaranteed not to throw, and enable runtime and container optimizations.
Definition
A function declared noexcept promises no exceptions will escape. If one does, std::terminate() is called.
Concrete example
Mark a move constructor noexcept so containers can move elements instead of copying during reallocation, improving performance.
Common misconception
noexcept does not suppress exceptions. It is a promise; violating it causes termination, not recovery.
<!-- Example adapted from chapter content --> #include <iostream> #include <stdexcept> void doSomethingNonThrowing() noexcept { std::cout << "Inside doSomethingNonThrowing." << std::endl; // throwing here would call std::terminate() } void doSomethingPotentiallyThrowing(int value) { if (value < 0) { throw std::runtime_error("Negative value encountered."); } std::cout << "Working with value: " << value << std::endl; } // If doSomethingNonThrowing threw, the program would terminate.
Key Takeaway

Use noexcept when you can guarantee no exceptions and you want clearer intent and better performance.

Pro tip
Prefer noexcept for destructors and for move operations that do not allocate or throw.
