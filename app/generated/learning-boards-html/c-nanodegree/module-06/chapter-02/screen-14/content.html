Module 6 › Chapter 6.2 › Key Concepts
noexcept specifier
Declares a function will not throw; violating it calls std::terminate.
Stack Unwinding
Destructors of automatic objects run in reverse order as exceptions propagate, enabling cleanup.
RAII
Acquire in constructors and release in destructors so resources are always cleaned up.
Summary

Together, these concepts let you write C++ that is both efficient and safe in the face of exceptions.
