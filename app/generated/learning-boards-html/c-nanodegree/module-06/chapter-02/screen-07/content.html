Module 6 › Chapter 6.2 › RAII
RAII: resource lifetime equals object lifetime
Wrap resources in objects whose destructors release them so cleanup is automatic.
Non-RAII risk
Manual close calls can be skipped when exceptions occur, leading to leaks.
RAII example
std::fstream and smart pointers are RAII types that free resources in their destructors.
File handling example (non-RAII)
void processFile(const std::string& filename) {
  FILE* file = fopen(filename.c_str(), "r");
  if (!file) throw std::runtime_error("Failed to open file.");
  // If an exception is thrown before fclose, file is leaked.
  fclose(file);
}
Key Takeaway

Prefer RAII wrappers so resources are freed automatically during normal execution and stack unwinding.

Pro tip
If an operation in a destructor can fail, handle the failure internally; do not throw.
