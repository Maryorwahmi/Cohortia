Learning Objectives
Build concrete skills for exception-safe resource management and performance-sensitive code.
01
Explain noexcept
Describe the contract of noexcept and what happens if it is violated. This matters because it affects optimizations and runtime behavior.
VERIFIED COMPETENCY MILESTONE
02
Explain stack unwinding
Understand how automatic objects are destructed as exceptions propagate, enabling reliable cleanup with RAII.
VERIFIED COMPETENCY MILESTONE
03
Master RAII
Apply the idiom of acquiring resources in constructors and releasing them in destructors to guarantee cleanup even on exceptions.
VERIFIED COMPETENCY MILESTONE
04
Apply smart pointers
Use std::unique_ptr and std::shared_ptr as RAII wrappers so dynamic memory is freed automatically when scopes end.
VERIFIED COMPETENCY MILESTONE
