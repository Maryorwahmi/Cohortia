Module 6 › Chapter 6.3 › ConfigLoader Design
Class responsibilities
  • Return std::error_code when the file is missing so callers can recover or retry.
  • Throw MalformedConfigFileException when content is invalid or missing required separators.
  • Assert that internal structures are initialized and never null during development.
Starter code excerpt
// In ConfigLoader::load
assert(configMap_ != nullptr && "Config map should not be null!");
std::ifstream file(filename);
if (!file.is_open()) {
  return std::make_error_code(std::errc::no_such_file_or_directory);
}

Design checklist
  • Document which failures are returned and which throw.
  • Ensure callers both check error codes and catch expected exceptions.
  • Keep asserts limited to internal invariants without production side-effects.
Key Takeaway

A consistent mixed approach balances clarity, performance, and robustness.
