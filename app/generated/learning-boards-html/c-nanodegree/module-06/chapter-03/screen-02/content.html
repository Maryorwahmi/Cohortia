Module 6 › Chapter 6.3 › Learning Objectives
01
Compare exceptions and error codes
Explain control-flow and performance trade-offs.

You will be able to describe why exceptions suit non-local, unexpected failures, while error codes are preferable for expected, frequent failures and low-overhead paths.

VERIFIED COMPETENCY MILESTONE
02
Understand std::error_code / condition
Map system errors to portable conditions.

You will read code that returns std::error_code, inspect ec.message and ec.value, and explain when to use error_condition to provide cross-platform semantics.

VERIFIED COMPETENCY MILESTONE
03
Use assertions correctly
Detect programming errors without adding runtime cost in release builds.

You will know why assert is for developer-only invariants and why it should not validate user input or external data in production releases.

VERIFIED COMPETENCY MILESTONE
04
Integrate mixed strategies
Design a function or class using error codes, exceptions, and asserts together.

You will design a ConfigLoader that returns an error code for missing files, throws for malformed content, and asserts internal invariants during development.
