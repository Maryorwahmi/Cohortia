What assert does

Assert evaluates a condition and aborts if false, usually emitting file and line information. It's a developer-focused check, not a user-facing error handler.

Example
int divide(int numerator, int denominator) {
  assert(denominator != 0 && "Denominator cannot be zero!");
  return numerator / denominator;
}
Why it matters
  • Catches programming errors early in testing and development.
  • Has zero runtime cost in release builds when NDEBUG is defined.
  • Do not use assert to check external input or recoverable runtime errors.
Common pitfall

Using assert to validate user data will leave production code unchecked when NDEBUG is active.
