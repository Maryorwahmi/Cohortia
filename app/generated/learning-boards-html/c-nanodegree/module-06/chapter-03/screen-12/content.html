Step-by-step
  1. Define MalformedConfigFileException : std::runtime_error.
  2. Initialize configMap_ in constructor to avoid assert failure.
  3. Return std::error_code for missing files using std::errc.
  4. Throw exception for empty or malformed files during parsing.
  5. Test with the three provided files and verify outputs match expectations.
Diagnostics to expect
  • For missing file: printed ec.message and ec.value identifying "No such file or directory".
  • For malformed or empty: exception caught with descriptive what() message.
  • For valid config: loader prints loaded key-value pairs.
