std::error_code

Holds a numeric code and category representing platform-specific failures. Check it via if (ec), read ec.message for diagnostics, and use ec.value to log the numeric value.

Concrete example
Return std::make_error_code(std::errc::no_such_file_or_directory) when a requested file is missing so callers can match that condition.
std::error_condition

Represents an abstract, portable error meaning. Use it to map many platform error codes to a single condition, enabling portable comparisons in client code.

Practical note
Prefer comparing to std::errc values or error_condition rather than relying solely on numeric error codes.
Quick checklist
  • Return std::error_code for expected system-level failures.
  • Compare ec against std::errc or use mapping via error_condition for portability.
  • Log ec.message for clear diagnostics.
