Module 6 › Chapter 6.3 › Assertion Builds
Behavior summary
  • Debug builds: assert checks active, failing an assert aborts with diagnostics.
  • Release builds with NDEBUG: assert checks are compiled out and impose no runtime cost.
  • Do not put critical logic or side-effecting calls inside assert expressions.
Illustrative example
double calculate_sqrt(double value) {
  assert(value >= 0.0 && "Input for square root must be non-negative!");
  return std::sqrt(value);
}
Checklist for developers
  • Use asserts only for developer guarantees and internal invariants.
  • Validate user or external data with error codes or exceptions in production.
  • Document assumptions asserted so reviewers understand the rationale.
