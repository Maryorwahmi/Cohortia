Module 6 › Chapter 6.3 › Key Concepts
Error Codes
Functions return explicit values to indicate expected failures.
std::error_code / condition
Provide system-level codes and portable mappings for cross-platform checks.
Assertions
Detect programming errors in development; removed in release builds with NDEBUG.
Summary Takeaway

Choose the tool that matches the error's nature: expected → error code, exceptional → exception, programming bug → assert.
