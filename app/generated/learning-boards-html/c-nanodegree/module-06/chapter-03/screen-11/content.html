  std::error_code load(const std::string& filename) {
    assert(configMap_ != nullptr && "Config map should not be null!");
    std::ifstream file(filename);
    if (!file.is_open()) {
      return std::make_error_code(std::errc::no_such_file_or_directory);
    }
    // parse lines, throw MalformedConfigFileException for malformed or empty file
  }
};
Test scenarios & outcomes
  • non_existent.txt → expects std::error_code indicating file missing.
  • valid_config.txt → loader returns success and prints key-value pairs.
  • empty_config.txt → loader throws MalformedConfigFileException.
  • malformed_config.txt → loader throws MalformedConfigFileException for invalid lines.
Pro tip

Derive the custom exception from std::runtime_error so callers can catch by reference and inspect what().
