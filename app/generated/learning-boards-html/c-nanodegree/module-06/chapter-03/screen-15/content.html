Module 6 › Chapter 6.3 › What to Remember
Check error returns
Always assign and test std::error_code rather than ignoring it.
Prefer portable checks
Compare to std::errc or map to std::error_condition for cross-platform behavior.
Asserts are dev-only
Do not use assert to validate user input in production; it is removed with NDEBUG.
Final thought

Design clear, documented contracts for failure handling so callers always know whether to check a return or catch an exception.
