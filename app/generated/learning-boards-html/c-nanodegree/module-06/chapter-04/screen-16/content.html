Buffering
std::cerr is unbuffered; std::cout and std::clog are buffered.
Validation
On extraction failure: clear flags and ignore the invalid input before retrying.
Formatting
Use manipulators for precision, width, and base; reset state when needed.
Final takeaway
Small, repeatable input and formatting patterns make console programs robust. Practice them in the calculator activity to internalize these habits.
