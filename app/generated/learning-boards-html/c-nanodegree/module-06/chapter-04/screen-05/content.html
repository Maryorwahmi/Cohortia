Insertion operator and formatting
Example usage and before/after formatting using manipulators from <iomanip>.
<!-- Example C++ snippet shown for study -->
#include <iostream>
#include <iomanip>

int main() {
  double price = 19.99;
  std::cout << "Default double: " << price << '
';

  // Fixed with two decimals
  std::cout << std::fixed << std::setprecision(2);
  std::cout << "Fixed 2-decimal: " << price << '
';

  // Reset to default float format
  std::cout << std::defaultfloat;
  std::cout << "Back to default: " << price << std::endl;

  return 0;
}
Explanation
  • std::cout uses << to accept values and format them as text.
  • std::fixed and std::setprecision affect how floating numbers are printed.
  • std::setw affects the next item only; std::defaultfloat restores float format.
Key Takeaway

Apply manipulators intentionally: some change persistent state, others apply to the next value only.

Misconception
Using std::endl always is acceptable. In practice, avoid frequent std::endl because it flushes the buffer and may hurt performance.
