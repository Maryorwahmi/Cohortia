Integer bases and boolean text
Switch numeric base for debugging or protocols; use boolalpha for readable booleans.
#include <iostream>

int main() {
  int num = 255;
  bool flag = true;

  std::cout << "Dec: " << std::dec << num << '
';
  std::cout << "Hex: " << std::hex << num << '
';
  std::cout << std::dec << "Back to dec: " << num << '
';

  std::cout << "Bool numeric: " << std::noboolalpha << flag << '
';
  std::cout << "Bool text: " << std::boolalpha << flag << std::endl;
}
Key Takeaway

Remember to reset base and boolean format when switching contexts to avoid surprising output later.
