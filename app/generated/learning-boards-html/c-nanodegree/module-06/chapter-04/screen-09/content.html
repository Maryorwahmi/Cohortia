Definition & Pattern
Robust input loop using cin.fail
Detect failed extractions, clear flags, and discard the rest of the line before retrying.
#include <iostream>
#include <limits>

double getDoubleInput(const std::string& prompt) {
  double value;
  while (true) {
    std::cout << prompt;
    std::cin >> value;

    if (std::cin.fail()) {
      std::cerr << "ERROR: Invalid input. Please enter a number." << std::endl;
      std::cin.clear();
      std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '
');
    } else {
      std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '
');
      return value;
    }
  }
}
Explanation
  • Check std::cin.fail() after extraction to detect conversion errors.
  • Clear flags with std::cin.clear() before ignoring input.
  • Ignore the rest of the invalid line to avoid repeated failure.
Pro tip

Report validation failures to std::cerr for immediate visibility during interaction or debugging.
