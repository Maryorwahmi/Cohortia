Comparison
std::endl (newline + flush) vs ' ' (newline only)
Which to use depends on whether you need the output immediately or prefer buffered efficiency.
// Using '
' is efficient
for (int i = 0; i < 1000; ++i) {
  std::cout << i << '
';
}

// Using std::endl flushes each line
for (int i = 0; i < 1000; ++i) {
  std::cout << i << std::endl; // slower due to flush
}
Explanation
  • std::endl inserts a newline and flushes the stream.
  • ' ' inserts only a newline and lets buffering decide when to write.
  • std::cerr is typically unbuffered; use it for immediate error messages.
Common Mistake

Overusing std::endl in loops for normal output causes unnecessary flushes and performance loss.

Quick check
When debugging a crash, why might you prefer std::cerr? Think about buffering and the chance the buffer may never be flushed before a process terminates.
