Safe sequence when mixing >> and getline
Follow these steps to avoid empty-line reads and ensure robust input handling.
Step 1: Extract token
Use std::cin >> value for numbers or single words.
Step 2: Ignore leftover
Call std::cin.ignore(std::numeric_limits<std::streamsize>::max(), ' ');
Step 3: Read full line
Call std::getline to read user input that may contain spaces.
#include <iostream>
#include <string>
#include <limits>

int main() {
  int age;
  std::string fullName;

  std::cin >> age;
  // discard leftover newline
  std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '
');

  std::getline(std::cin, fullName);
  std::cout << "Name: " << fullName << " Age: " << age << std::endl;
}
Key Takeaway

Always clear the buffer before switching from token extraction to line-based reads; use the numeric-limits pattern for safety.
