Definition & Code
fixed, scientific, and setprecision
Choose manipulators to produce consistent numeric output for reports and results.
#include <iostream>
#include <iomanip>

int main() {
  double pi = 3.1415926535;

  std::cout << "Default: " << pi << '
';
  std::cout << std::fixed << std::setprecision(2) << "Fixed 2-decimal: " << pi << '
';
  std::cout << std::scientific << std::setprecision(4) << "Scientific 4: " << pi << '
';
  std::cout << std::defaultfloat << "Back to default: " << pi << std::endl;
}
Practical use
Use fixed for currency, scientific for large/small numbers, and remember to reset formatting when needed.
Misconception
setprecision always sets decimal places. It sets significant digits unless fixed is active.
