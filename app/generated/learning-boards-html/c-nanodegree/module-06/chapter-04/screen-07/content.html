Extraction operator and token parsing
The operator parses until it fills the target type, leaving trailing whitespace in the buffer.
#include <iostream>
#include <string>

int main() {
  int num;
  std::string word;
  double decimal;

  std::cout << "Enter an integer: ";
  std::cin >> num; // reads an integer token

  std::cout << "Enter a word: ";
  std::cin >> word; // reads a single whitespace-separated word

  std::cout << "Enter a decimal number: ";
  std::cin >> decimal; // reads a floating-point token

  std::cout << "You entered: " << num << ", " << word << ", " << decimal << std::endl;
  return 0;
}
Key points
  • Extraction reads tokens separated by whitespace.
  • Extraction does not read trailing newline; it stays in the buffer.
  • Invalid conversions set the stream fail bit; handle with clear and ignore.
Common Mistake

Assuming extraction reads a full line of text including spaces. Use getline for that purpose.
