Practice & Assessment
Four hands-on verification steps to prove competency.
01 Validate numeric input
Loop on std::cin until a valid number is entered, clear fail flags, and ignore the rest of the invalid line.
VERIFIED COMPETENCY MILESTONE
02 Read full lines safely
Use std::getline after consuming leftover newlines with cin.ignore and confirm the line contains expected content.
VERIFIED COMPETENCY MILESTONE
03 Format results
Apply std::fixed and std::setprecision to control decimal places and setw to align columns for readability.
VERIFIED COMPETENCY MILESTONE
04 Use error and log streams
Demonstrate sending immediate errors to std::cerr and non-critical logs to std::clog in the calculator activity.
VERIFIED COMPETENCY MILESTONE
