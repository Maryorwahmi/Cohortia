Aligning columns with setw
Use setw for human-readable columns in console output.
#include <iostream>
#include <iomanip>

int main() {
  std::cout << std::left << std::setw(12) << "Name" << std::right << std::setw(6) << "Age" << '
';
  std::cout << std::left << std::setw(12) << "Alice" << std::right << std::setw(6) << 30 << '
';
  std::cout << std::left << std::setw(12) << "Bob" << std::right << std::setw(6) << 25 << std::endl;
  return 0;
}
Key Takeaway

Call setw for each field and combine with left or right to produce tidy columns; values longer than the width expand the field.
