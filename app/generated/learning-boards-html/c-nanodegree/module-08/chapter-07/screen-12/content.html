Starter commands
mkdir cpp_git_project
cd cpp_git_project
git init
# create CMakeLists.txt and main.cpp, then:
git add CMakeLists.txt main.cpp
git commit -m "Initial project setup with basic app"
Then add .gitignore, build in build/, and verify git status shows nothing to commit for build artifacts.
Feature branch & LFS demo
# feature branch
git checkout -b feature/add-greeting
# make changes and commit

# Git LFS demo
git lfs install
git lfs track "*.bin"
git add .gitattributes large_data.bin
git commit -m "feat: Add large_data.bin using Git LFS"
Key Takeaway

Perform the track step before adding a binary, and commit .gitattributes so tracking applies for everyone.
