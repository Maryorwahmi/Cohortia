Module 8 › Chapter 8.7 › Feature Branch Workflow
Steps
1. Create branch
git checkout -b feature/your-feature from develop
2. Commit often
Small, atomic commits that capture one logical change.
3. Open PR
Trigger CI, request reviewers, and iterate on feedback.
4. Merge & cleanup
Use squash or rebase; delete the feature branch after merge.
Example scenario
Feature: add custom greeting

Create feature/add-greeting, add a helper that returns a formatted string, commit, open a PR, run CI to ensure cross-platform builds succeed, review for string lifetime and include guards, then merge.

Key Takeaway

Feature branches let you iterate safely and have reviewers focus on one change at a time.
