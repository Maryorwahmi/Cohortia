Verification milestones

Concrete artifacts show you’ve mastered each objective. Use these as quick checks on pull requests and code reviews.

.gitignore Check

Demonstrate that build/, *.o, and IDE folders are ignored and not tracked by Git after a build.

Feature Branch Check

Open a PR from a feature branch, include CI results and a review, then merge with a squash or rebase strategy.

Git LFS Check

Add a dummy binary, run git lfs track, commit .gitattributes and confirm git lfs ls-files shows the file.

Commit & Review Check

Make atomic commits with descriptive bodies. During review, check for correctness, performance, and memory safety concerns.
