Learning Objectives

Learn, understand, apply, and master version control practices suited for C++ teams.

01
Configure .gitignore

Create and maintain an ignore list that excludes build artifacts, IDE settings, and generated files so commits stay focused on source code. Think of it as a pre-commit filter that prevents repository bloat and platform-specific conflicts.

VERIFIED COMPETENCY MILESTONE
02
Adopt Feature Branch Workflow

Use short-lived feature branches from develop, open PRs for review and CI, then merge with squash or rebase to keep history clean. This reduces merge conflicts and clarifies intent for each change.

VERIFIED COMPETENCY MILESTONE
03
Manage Large Files with Git LFS

Track binary patterns in .gitattributes so Git stores pointers instead of large blobs, improving clone and fetch performance. Remember to commit the .gitattributes file so teammates get the same tracking rules.

VERIFIED COMPETENCY MILESTONE
04
Write Atomic Commits & Perform Reviews

Make each commit a single, logical change with a descriptive subject and body. Use reviews to check correctness, performance, and memory safety — critical in C++ projects.
