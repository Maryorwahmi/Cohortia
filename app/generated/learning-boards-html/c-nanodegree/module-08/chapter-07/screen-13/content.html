Module 8 › Chapter 8.7 › Common Pitfalls
Accidental large file commit
If a large binary is committed before LFS tracking, you must remove it from history and push rewritten history or use a migration tool. Prevention is far easier.
Quick check

Run git status after a build to confirm ignored files are not staged.

Force push hazards
Force pushes can overwrite collaborators’ work. Use protected branches and require PRs for main or develop to avoid accidental history rewrites.
Preventive step

Add branch protection rules in your remote to block force pushes to critical branches.
