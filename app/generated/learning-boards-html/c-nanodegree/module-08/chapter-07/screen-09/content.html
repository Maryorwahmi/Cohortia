Module 8 › Chapter 8.7 › Git LFS & .gitattributes
What .gitattributes contains
*.bin filter=lfs diff=lfs merge=lfs -text
assets/*.obj filter=lfs diff=lfs merge=lfs -text
Always run git status after git lfs track and commit .gitattributes before adding the large files you intend to track.
Verification
Commands to check
git lfs ls-files
cat .gitattributes
git status
Why commit .gitattributes?

If it’s not committed, teammates won’t track the files and large binaries may end up in history.
