Module 8 › Chapter 8.1 › What is CMake?
Definition

CMake as a generator

CMake reads high-level build scripts and emits native build files appropriate for the platform and generator you choose.

Quick example
set(CMAKE_CXX_STANDARD 17)
project(MyApp CXX)
add_executable(myapp main.cpp)
Key Takeaway

Think of CMake as the portability layer: declare intent, not low-level commands.

Why it matters
  • Single source of truth for platform-specific build differences.
  • Centralized policies like C++ standard propagate to targets when set properly.
  • Modern CMake focuses on per-target properties for scalability.
Common misconception

People often treat CMake as a macro language to hack flags globally. Instead, prefer target-level settings and imported targets to avoid global leakage.

Key Takeaway

Use CMake to express build structure and let generators produce platform-specific files.
