Module 8 › Chapter 8.1 › Top-level CMakeLists

Standard responsibilities

  • cmake_minimum_required and project() declaration.
  • Set CMAKE_CXX_STANDARD and global policies.
  • Define user-facing option() toggles with sensible defaults.
  • Call add_subdirectory for each component.
Best practice

Use functions/macros to encapsulate repeated target setup while keeping the file readable and consistent.

Example top-level CMake
cmake_minimum_required(VERSION 3.10)
project(MyComplexProject CXX)
set(CMAKE_CXX_STANDARD 17)
set(CMAKE_CXX_STANDARD_REQUIRED ON)
set(CMAKE_CXX_EXTENSIONS OFF)

option(BUILD_TESTS "Enable building unit tests" ON)

add_subdirectory(lib)
add_subdirectory(app)
Key Takeaway

Keep project-wide policies at the root and per-target configuration near the target for clarity and maintainability.
