Learning Objectives

Skills you will practice and verify during the hands-on activity.

Learn → Understand → Apply → Master
01
Organize multi-target projects

Split components into subdirectories and include them with add_subdirectory so each target manages its own sources and properties.

Mnemonic: nested prefabs
VERIFIED COMPETENCY MILESTONE
02
Manage external libraries

Use find_package and imported targets so include dirs, link libraries, and compile definitions travel with the target automatically.

Mnemonic: bring the whole service, not just a header
VERIFIED COMPETENCY MILESTONE
03
Automate generation steps

Define add_custom_command and add_custom_target with OUTPUT and DEPENDS so generated files are tracked and rebuilt correctly.

Mnemonic: declare outputs to avoid stale builds
VERIFIED COMPETENCY MILESTONE
04
Control dependency exposure

Use PRIVATE/PUBLIC/INTERFACE in target_link_libraries to avoid leaking implementation dependencies to consumers.

Mnemonic: hide internal screws
VERIFIED COMPETENCY MILESTONE
