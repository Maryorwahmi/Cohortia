Troubleshooting checklist
  1. Missing generated file: confirm add_custom_command has OUTPUT and add_dependencies is set on the consuming target.
  2. Stale artifacts: ensure DEPENDS lists actual inputs so files regenerate only when needed.
  3. Unexpected dependency propagation: check PRIVATE/PUBLIC/INTERFACE usage in target_link_libraries.
  4. Include path issues: verify target_include_directories includes the build binary dir when using generated headers.
  5. When in doubt, create a fresh build dir and reconfigure to validate the graph.
Common mistake

Not declaring OUTPUT or DEPENDS for generated files is the primary reason for missing or stale build artifacts.

Key Takeaway

Treat the build graph as data: every produced file must be declared as OUTPUT and every input as DEPENDS for reliable incremental builds.
