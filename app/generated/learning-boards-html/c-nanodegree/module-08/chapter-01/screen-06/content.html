Definition

find_package and imported targets

Use find_package to locate external packages. When available, imported targets like Foo::Foo encapsulate include dirs and link flags.

Example usage
find_package(Boost REQUIRED COMPONENTS filesystem)
if(TARGET Boost::filesystem)
  target_link_libraries(my_app PRIVATE Boost::filesystem)
endif()
Why prefer imported targets?
  • They carry include_dirs, link libraries, and compile definitions together.
  • They reduce manual platform checks and keep CMakeLists concise.
  • If unavailable, guard the build and provide a clear message to the user.
Common pitfall

Assuming find_package sets variables or targets for every library. Always check what the package exports and prefer targets when present.

Key Takeaway

Imported targets provide a robust, self-contained way to consume external libraries found by find_package.
