Module 8 › Chapter 8.1 › Configurable builds
Creating options
option(BUILD_TESTS "Enable building unit tests" ON)
if(BUILD_TESTS)
  add_subdirectory(test)
endif()
Best practices
  • Document what each option toggles in top-level CMakeLists.
  • Use clear prefixes for variables to avoid collisions.
  • Prefer explicit options to environment-dependent behavior.
Using options in CI

Invoke CMake with -DBUILD_TESTS=OFF or ON to control what runs in CI. Keep CI scripts explicit for reproducibility.

Real-world tip

Prefer toolchain files for machine-specific settings and options for feature toggles so builds remain reproducible across developers.
