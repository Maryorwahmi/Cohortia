Module 8 › Chapter 8.1 › PRIVATE / PUBLIC / INTERFACE
PRIVATE

Dependency is only used to build this target. Do not propagate to dependents.

target_link_libraries(MyLib PRIVATE LibB)
PUBLIC

Required to build this target and also required by anything that links this target.

target_link_libraries(MyLib PUBLIC LibCore)
INTERFACE

Only describes usage requirements for consumers; this target itself does not need the dependency to compile.

target_link_libraries(MyHeaderOnly INTERFACE LibHeaders)
Concrete example

LibA uses LibB internally. Use target_link_libraries(LibA PRIVATE LibB). App links LibA as PRIVATE. App will not inherit LibB because LibB is an implementation detail of LibA.

Key Takeaway

Answer the question: does a consumer need this dependency to compile against my target's headers? Use PRIVATE unless it must be visible.

Common mistake

Using PUBLIC for internal-only libs, which propagates unnecessary dependencies to consumers.
