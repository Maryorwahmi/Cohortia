05
Avoid anti-patterns
Learn to test behavior, not private implementation. Keep tests independent and prefer real objects where feasible to avoid brittle mocks.
VERIFIED COMPETENCY MILESTONE
06
Set up GTest with CMake
Use find_package(GTest REQUIRED) or add GTest as a subdirectory, link tests to GTest::gtest_main, and run tests via your CMake test target.
VERIFIED COMPETENCY MILESTONE
07
Use assertions wisely
Choose ASSERT_* when subsequent checks depend on a condition; use EXPECT_* to record a failure but continue executing remaining checks.
VERIFIED COMPETENCY MILESTONE
08
TDD hands-on: Stack
Follow the chapter activity: write failing tests, implement minimal code, then add more tests until the Stack supports push, pop, peek, size, and exceptions.
