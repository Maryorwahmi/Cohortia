Unit Testing & TDD in C++
Write tests with Google Test, design fixtures, and practice Red-Green-Refactor.

This unit shows how to express expected behavior via tests, keep tests isolated using fixtures, and use TDD to guide design. You’ll follow a hands-on Stack implementation using CMake and GTest.

In this lesson
Learn testing fundamentals, write Google Test cases, manage fixtures, and apply TDD to build a correct Stack implementation with exception handling.
Coming up
Testing
Write focused unit tests that verify behaviors and edge cases.
Fixtures
Use SetUp/TearDown for clean, repeatable test state.
TDD
Follow Red-Green-Refactor to design and verify APIs early.
Visual
Test Suite
Test file groups cases with TEST and TEST_F, uses ASSERT/EXPECT for checks, and reports a clear pass/fail summary.
TDD Cycle
Red: write a failing test. Green: write minimum code. Refactor: improve design safely.
Key Takeaway

Tests describe correct behavior and enable safe change. Start small, test behavior not internals, and use fixtures for isolation.
