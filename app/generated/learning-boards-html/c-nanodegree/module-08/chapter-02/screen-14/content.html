Module 8 › Chapter 8.2 › Key Concepts
Unit Testing
Test individual components in isolation to verify correctness and document behavior.
Google Test (GTest)
A C++ framework providing TEST/TEST_F, assertions, and fixture support for structured tests.
Assertions
EXPECT_* records failures and continues; ASSERT_* aborts the current test when subsequent checks would be invalid.
Summary: use fixtures for isolation, write small focused tests, follow Red-Green-Refactor, and treat tests as a safety net for refactoring.
