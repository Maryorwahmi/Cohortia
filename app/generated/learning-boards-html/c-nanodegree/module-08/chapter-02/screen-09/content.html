Initial failing test
// test/test_stack.cpp
#include "gtest/gtest.h"
#include "stack.h" // This will fail to compile initially

TEST(StackTest, IsEmptyInitially) {
    Stack s;
    EXPECT_TRUE(s.isEmpty());
}
Try compiling now. The missing or incomplete Stack API produces a failure, confirming the test is valuable and drives design.
Red Checklist
  • Keep the test minimal and focused
  • Name the test to reveal intent
  • Confirm the test fails before implementing
Avoid
Don't write large feature tests first. Small failing tests guide incremental design.
