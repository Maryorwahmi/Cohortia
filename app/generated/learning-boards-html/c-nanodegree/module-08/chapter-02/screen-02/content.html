Module 8 › Chapter 8.2 › Learning Objectives
01
Understand unit testing principles
You will learn why unit testing isolates components, how tests reduce regressions, and how tests act as documentation for expected behavior. A simple mnemonic: Test = Verify + Document.
VERIFIED COMPETENCY MILESTONE
02
Write tests with Google Test
Practice TEST and TEST_F, use assertions like EXPECT_EQ and ASSERT_THROW, and structure suites so each test checks one behavior. Visual mnemonic: test file -> cases -> assertions.
VERIFIED COMPETENCY MILESTONE
03
Use test fixtures for isolation
Implement SetUp and TearDown on a fixture class so resources are reset before each test. Think: one clean environment per test to avoid order dependencies.
VERIFIED COMPETENCY MILESTONE
04
Apply TDD: Red-Green-Refactor
Write a failing test first, implement minimal code to pass it, then refactor. This drives API design and keeps changes small and verifiable.
VERIFIED COMPETENCY MILESTONE
