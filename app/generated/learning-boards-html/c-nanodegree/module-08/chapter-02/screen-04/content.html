Module 8 › Chapter 8.2 › What is Unit Testing?
Definition & Scope

Unit testing verifies the smallest testable units of code in isolation. Tests are fast, focused, and designed to run frequently during development.

Benefits
  • Early bug detection and regression prevention
  • Easier refactoring with safety nets
  • Executable documentation of behavior
Common misconception
Unit tests are not integration tests. They should not verify inter-module wiring; that belongs in higher-level tests.
Example: add(int a, int b)
// calculator.h
#pragma once
int add(int a, int b);

// calculator.cpp
#include "calculator.h"
int add(int a, int b) {
  return a + b;
}

// calculator_test.cpp
#include "gtest/gtest.h"
#include "calculator.h"

TEST(CalculatorFunctions, HandlesPositiveNumbers) {
  EXPECT_EQ(5, add(2, 3));
  EXPECT_EQ(10, add(5, 5));
}
Key Takeaway

Keep tests behavior-focused, fast, and independent so they provide quick feedback during development.
