Module 8 › Chapter 8.4 › Compiler Flags
Definition

Compiler optimization flags

Optimization levels enable transformations that can dramatically affect performance and code layout. Always test changes and keep debug symbols for profiling.

-O2
A balanced level that enables many optimizations with conservative trade-offs.
-O3
Enables more aggressive transformations; may increase code size or change behavior under undefined conditions.
-g
Include debug symbols so profilers can map performance samples to source lines.
Function attributes
Attributes like always inline can force optimizations for hot functions, but use sparingly.
Practical workflow
Compile with debug symbols and an optimization level used in production, measure with perf stat, then experiment with higher or lower optimization levels and re-measure.
Key Takeaway

Compiler flags can offer large wins but may change code behavior; always validate correctness and measure the effect on realistic workloads.
