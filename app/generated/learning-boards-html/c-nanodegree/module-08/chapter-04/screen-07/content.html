Module 8 › Chapter 8.4 › perf Overview
Core Tool

perf (Linux Performance Events)

perf samples CPU and hardware counters, revealing cache misses, branch mispredictions, and other events without recompilation.

Useful commands
perf record -g to collect samples; perf report to analyze; perf stat to get counter summaries for a run.
When to use
When you need to connect slow code regions to hardware-level causes like cache misses or mispredicted branches.
Interpretation
  • High cache-miss rates point to poor data locality rather than slow arithmetic.
  • High branch-misprediction counts indicate unpredictable conditionals inside hot loops.
  • Compare perf stat before and after changes for measurable evidence.
Key Takeaway

perf connects profile hotspots to hardware events, guiding targeted fixes like changing memory access patterns or reducing unpredictable branches.
