Learning Objectives

Skills to measure, analyze, and optimize C++ performance
Learn → Understand → Apply → Master
01
Measure before optimize
Practice forming hypotheses and running profilers to confirm them. This avoids wasted or harmful changes.
VERIFIED COMPETENCY MILESTONE
02
Use gprof and perf
Collect flat and call-graph profiles, and hardware counters for cache and branch events to pinpoint hotspots precisely.
VERIFIED COMPETENCY MILESTONE
03
Optimize algorithms and data structures
Prioritize algorithmic complexity and choose data structures that match access patterns for the biggest gains.
VERIFIED COMPETENCY MILESTONE
04
Understand hardware effects
Recognize how CPU caches, branch prediction, and memory access patterns influence performance decisions.
VERIFIED COMPETENCY MILESTONE
