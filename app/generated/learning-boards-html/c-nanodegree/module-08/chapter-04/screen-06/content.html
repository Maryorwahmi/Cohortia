Module 8 › Chapter 8.4 › gprof Walkthrough
Definition

gprof

Instrument the program at compile time, run it to create the profile data file, and analyze with gprof to get flat and call-graph views.

Typical commands
Compile with instrumentation, run to produce the data file, and analyze with gprof to view call graph and flat profile.
When to use
Function-level attribution and call-tree analysis for single-threaded workloads.
Limitations
Less accurate for multi-threaded programs and does not provide hardware counter events like cache misses.
Example flow
  1. Compile with instrumentation flag for gprof.
  2. Run the instrumented program to produce the profiling output file.
  3. Run gprof on the output to get flat and call-graph reports.
Key Takeaway

Use gprof to understand which functions and call paths consume time; pair with perf for low-level hardware events.
