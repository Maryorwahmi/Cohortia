Process Flow

Profiling fundamentals

Step 1: Choose a tool suited to your question: sampling for CPU hotspots, event counters for cache and branch analysis.
Step 2: Run a realistic workload long enough to collect stable samples.
Step 3: Analyze the flat profile for top consumers and the call graph for context.
Step 4: Form hypothesis, change code, and re-measure to confirm improvements.
Key counters to watch
  • CPU cycles and instructions retired
  • Cache references and misses (L1, LLC)
  • Branch mispredictions
Practical tip

Compile with debug symbols so your profiler maps to source. Use consistent inputs and record the command lines and environment for reproducibility.

Key Takeaway

Sampling and event counters complement each other: use both to connect high-level hotspots with low-level hardware causes.
