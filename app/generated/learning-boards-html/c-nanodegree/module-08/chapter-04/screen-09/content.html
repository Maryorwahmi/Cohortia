Module 8 › Chapter 8.4 › Algorithmic Optimizations
Definition

Algorithmic optimizations

Choose data structures or algorithms that reduce work from quadratic to linear or linearithmic time when possible.

Example
Switching from nested loops to a hash-based approach can reduce an O(N^2) check to O(N) average time.
Why it matters
As input size grows, asymptotic gains dominate micro-optimizations and are more sustainable.
Misconception
Don't assume small local tweaks will outperform a better algorithm on large data sets.
Strategy
  1. Identify hotspots with profiling.
  2. Ask whether a different algorithm or data structure reduces asymptotic cost.
  3. Implement, test correctness, and re-measure with realistic inputs.
Key Takeaway

Fix complexity before tuning constants. Algorithmic changes scale far better with larger inputs.
