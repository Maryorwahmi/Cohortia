Learning Objectives

These objectives guide hands-on setup and verification of CI/CD for a C++ project.

01
Understand CI & CD
Explain the goals of Continuous Integration and Continuous Deployment and how they apply to C++ projects.
Mnemonic: Venn of build + test → deploy
VERIFIED COMPETENCY MILESTONE
02
Set up a CI pipeline
Create a GitHub Actions or GitLab CI YAML that triggers on push and pull requests and runs an automated build.
Mnemonic: YAML checklist
VERIFIED COMPETENCY MILESTONE
03
Build, test & analyze
Configure CI jobs to run CMake, build, run ctest, and execute Clang-Tidy to enforce code quality.
Mnemonic: Gear icons for build → test → lint
VERIFIED COMPETENCY MILESTONE
04
Use Docker for reproducibility
Create a Dockerfile that pins compiler and tool versions so CI runs are identical across machines.
Mnemonic: Container box
VERIFIED COMPETENCY MILESTONE
