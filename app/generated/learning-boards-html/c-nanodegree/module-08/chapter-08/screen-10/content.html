Add googletest as submodule

Run these commands locally then push the updated .gitmodules to the repo so CI can fetch the test harness.

git submodule add https://github.com/google/googletest.git test/googletest
git submodule update --init --recursive

Update CMake:

# in CMakeLists.txt
add_subdirectory(test/googletest)
# link your test executable with GTest::gtest_main or similar
CI checkout with submodules

Ensure your CI checkout step initializes submodules so the runner gets the googletest sources.

- uses: actions/checkout@v3
  with:
    submodules: true
Pro Tip

Prefer submodules for test libs if you want exact reproducibility; otherwise use a package manager integrated into CI.

Example test file (test/test_math.cpp)
#include "gtest/gtest.h"
// Forward declaration of add
int add(int a, int b);

TEST(MathFunctions, AddPositiveNumbers) {
  EXPECT_EQ(5, add(2, 3));
}

TEST(MathFunctions, AddNegativeNumbers) {
  EXPECT_EQ(-5, add(-2, -3));
}

TEST(MathFunctions, AddZero) {
  EXPECT_EQ(7, add(7, 0));
}
