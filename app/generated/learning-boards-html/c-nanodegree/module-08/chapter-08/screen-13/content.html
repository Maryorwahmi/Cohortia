Sanitizer flags (CI diagnostic)
# Configure CMake for sanitizers
cmake -B build -DCMAKE_BUILD_TYPE=Debug -DCMAKE_CXX_FLAGS="-fsanitize=address -g -O0"
# For thread data races, use -fsanitize=thread
cmake -B build -DCMAKE_CXX_FLAGS="-fsanitize=thread -g -O0"

Run failing tests under the sanitizer build. The sanitizer output provides stack traces and cause locations to guide fixes.

Dockerfile example for reproducibility
# Dockerfile
FROM ubuntu:22.04
RUN apt-get update && apt-get install -y \
  build-essential cmake git python3-pip \
  && pip3 install conan
WORKDIR /app
COPY . /app

Build and publish this image, then configure CI to use it so every run uses the exact same toolchain.

Caching & artifact strategy
  • Cache dependency downloads (Conan, vcpkg) between runs to avoid repeated network fetches.
  • Cache heavy build outputs where safe; invalidate caches when toolchain or dependencies change.
  • Store build artifacts (executables, installers) in a registry or artifact store for later deployment steps.
