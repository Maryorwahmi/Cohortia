build_and_test.yml (excerpt)

This example demonstrates the essential steps for a CMake-based CI job.

Explanation
  • Trigger: on push and pull_request ensures CI runs for merges and PRs.
  • Runs-on: choose ubuntu-latest or another OS; use matrix jobs for cross-platform tests.
  • Steps: checkout, install dependencies, configure with CMake, build, then run tests with ctest.
  • To add static analysis, run Clang-Tidy against files listed in compile_commands.json.
Common mistake
Assuming the CI runner includes all libraries; always install or use a controlled container image.
YAML example
# .github/workflows/build_and_test.yml name: C++ CI Build and Test on: push: branches: [ main, develop ] pull_request: branches: [ main, develop ] jobs: build: runs-on: ubuntu-latest # Or windows-latest, macos-latest steps: - uses: actions/checkout@v3 # Step 1: Checkout the repository - name: Install Dependencies # Step 2: Install system dependencies (e.g., vcpkg if used) run: | sudo apt-get update sudo apt-get install -y build-essential cmake - name: Configure CMake # Step 3: Configure the build run: cmake -B ${{github.workspace}}/build -DCMAKE_BUILD_TYPE=Release - name: Build Project # Step 4: Build the project run: cmake --build ${{github.workspace}}/build --config Release - name: Run Tests # Step 5: Run unit tests run: | cd ${{github.workspace}}/build ctest --output-on-failure # End of example
