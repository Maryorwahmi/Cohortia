Simulated bug

Change the implementation to introduce a failing test:

int add(int a, int b) { return a - b; } // intentional bug

Commit and push. CI will fail in the test step. Open the failing step to read the ctest output and failing assertions.

Interpreting logs
  1. Locate the failing step in Actions and expand its log.
  2. Find the test name and assertion that failed in ctest output.
  3. Copy the exact failing command, run it locally to reproduce quickly.
  4. Run clang-tidy locally (using compile_commands.json) to inspect static warnings.
Check your assumptions

A failing test can come from a logic bug, undefined behavior, or a build configuration mismatch. Reproducing the failing command locally with the same flags is the fastest diagnostic path.
