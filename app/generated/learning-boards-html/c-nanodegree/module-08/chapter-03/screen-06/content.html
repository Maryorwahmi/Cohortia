Process Flow
Inspecting program state
A recommended sequence when you reach a breakpoint.
Typical sequence
  1. Set breakpoint near suspected logic.
  2. Run until breakpoint triggers.
  3. Use info locals to scan local variables.
  4. Use p var or p *ptr to inspect particular values.
  5. Step with n or s and re-inspect to see changes.
Commands at a glance
(gdb) b someFunction
(gdb) r
(gdb) info locals
(gdb) p myVar
(gdb) p *ptr
(gdb) l    # list source
(gdb) n    # step over
(gdb) s    # step into
Example
If a pointer is dereferenced and causes a segfault, use p ptr to check if it is null. If it is null, print the caller's variables to determine why no valid address was passed. Use bt to trace the call chain that led to the bad value.
