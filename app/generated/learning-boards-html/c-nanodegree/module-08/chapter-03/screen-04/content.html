Definition
Compile with -g
Embed source-level symbolic information so debuggers and Valgrind can map execution to source lines and variable names.
Command pattern
g++ -g -O0 source.cpp -o myapp
# -g embeds symbols
# -O0 disables optimization for predictable debugging
Tip: Split debug and release builds in your build system so you don't accidentally ship -g in production artifacts.
Why -g helps
  • GDB can show source lines and variable names instead of raw addresses.
  • Valgrind can attribute leaks and invalid accesses to the correct file and line.
  • Backtraces become readable and actionable during a crash analysis.
Common misconception
Some developers assume -g is only for beginners. In practice, -g is essential at any stage to map runtime behavior to source. The real trap is debugging optimized builds; prefer -O0 while investigating logic and memory errors.
Key Takeaway

Compile with -g and -O0 for debugging. If your tools show raw addresses instead of file:line, rebuild with debugging symbols.
