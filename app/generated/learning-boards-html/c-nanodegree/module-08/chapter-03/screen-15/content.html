Summary
What to remember
GDB
Interactive debugging: breakpoints, step, print, and backtrace to trace crashes to source lines.
-g and -O0
Compile with symbols and no optimizations for reliable debugger and Valgrind output.
Valgrind Memcheck
Find leaks, invalid accesses, and uninitialized values; follow the stack traces to allocation sites.
Summary Takeaway

Combine GDB’s control with Valgrind’s memory checks and disciplined build settings to diagnose and fix runtime memory issues efficiently.
