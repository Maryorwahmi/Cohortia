Module 08 › Chapter 8.3 › Learning Objectives — 1
What you will learn
These objectives are verifiable skills you can demonstrate in a terminal session.
01
Master core GDB commands
Learn to set breakpoints, run, continue, step into and over, and print variables so you can control and inspect execution precisely.
Verified competency milestone
02
Compile with debugging symbols (-g)
Ensure your build contains symbolic information so GDB and Valgrind can report file names, line numbers, and variable names during analysis.
Verified competency milestone
03
Use Valgrind Memcheck
Run Valgrind with leak-check and show-leak-kinds to locate definite memory leaks and allocation sites in your program.
Verified competency milestone
04
Interpret common Valgrind errors
Recognize invalid reads/writes, use-after-free, and uninitialized value reports and map them back to source lines using the stack trace Valgrind provides.
Verified competency milestone
