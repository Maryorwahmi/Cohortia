Definition
Call stack (backtrace)
Use bt in GDB to see how you arrived at the current execution point and inspect earlier frames.
GDB example
#0  0x000055555555519b in buggy_function(int*) (ptr=0x0) at segfault.cpp:6
#1  0x00005555555551d2 in main () at segfault.cpp:14
Switch frames with frame 1 and inspect variables in that caller to see how the null pointer was passed.
Valgrind traces
Valgrind prints a stack for each reported error, and for leaks it points to the allocation site. Use that stack to find the allocation line and the caller that failed to free memory.
Key Takeaway

A backtrace shows context. Don’t stop at the crash line; inspect earlier frames to find where the bad data originated.
