Case Study
Segmentation fault walkthrough
Reproduce and inspect a null-pointer dereference using GDB.
segfault.cpp (source)
#include <iostream>
#include <vector>

void buggy_function(int* ptr) {
  *ptr = 100; // Dereferencing a potentially invalid pointer
}

int main() {
  int* p = nullptr; // Initialize to nullptr
  // If we uncomment the next line, it works.
  // int x = 0;
  // p = &x;

  buggy_function(p); // Pass nullptr to buggy_function
  std::cout << "Program finished." << std::endl;
  return 0;
}
GDB session (example)
g++ -g segfault.cpp -o segfault
gdb ./segfault
(gdb) r
Program received signal SIGSEGV, Segmentation fault.
0x... in buggy_function(int*) (ptr=0x0) at segfault.cpp:6
(gdb) bt
#0  buggy_function(ptr=0x0) at segfault.cpp:6
#1  main () at segfault.cpp:14
(gdb) p ptr
$1 = (int *) 0x0
This confirms that ptr is null and the dereference caused the crash. Inspect the caller to fix the initialization or add a guard.
Common mistake

Running the program without -g or with heavy optimizations can hide file:line information and make this analysis much harder.
