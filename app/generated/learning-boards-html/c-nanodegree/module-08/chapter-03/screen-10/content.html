Definition
Valgrind Memcheck
A dynamic analysis tool that tracks memory operations to report leaks and invalid accesses.
Run command
g++ -g myprog.cpp -o myprog
valgrind --leak-check=full --show-leak-kinds=all ./myprog
The flags provide detailed leak reports and categorize leak kinds for triage.
Interpreting results
  • Definitely lost — memory that has no remaining pointer and is a true leak.
  • Indirectly lost — memory only reachable through leaked blocks.
  • Still reachable — memory not freed but potentially intended; review for lifecycle issues.
Why it matters
Memory errors can cause crashes, corruption, and resource exhaustion. Memcheck exposes issues that unit tests and casual runs may not reveal, making it an essential part of C++ testing.
