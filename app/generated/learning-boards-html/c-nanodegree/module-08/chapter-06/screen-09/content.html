Steps
  1. Clone the vcpkg repo and run the bootstrap script for your OS.
  2. Install libraries with a triplet, for example fmt:x64-linux.
  3. Configure CMake with the vcpkg toolchain file to enable find_package CONFIG mode.
  4. Link imported targets in CMake and build.
Tip
Keep vcpkg in your repo or as an external submodule so CI uses the same vcpkg version and ports.
Command callout
/path/to/vcpkg/vcpkg install fmt spdlog:x64-linux
cmake -DCMAKE_TOOLCHAIN_FILE=/path/to/vcpkg/scripts/buildsystems/vcpkg.cmake ..
cmake --build .
Key Takeaway

Triplets are how you guarantee consistent target settings. Use them for team and CI parity.
