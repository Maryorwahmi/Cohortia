Common Mistakes & Safety
  • Mixing Conan and vcpkg for the same dependency set leads to conflicts.
  • Using inconsistent profiles or triplets across team members breaks binary compatibility.
  • Not committing lockfiles allows dependency graphs to drift over time.
  • Relying on system packages can cause version and build-option mismatches.
Fixes
Standardize on one manager per project, share profiles/triplets in repo, commit lockfiles, and use CI to enforce builds.
Quick checklist
  1. Pick Conan or vcpkg for the project
  2. Share profile/triplet files in version control
  3. Commit and use lockfiles or CI pinning
Key Takeaway

Policies and shared files are the best defense against environment drift and compatibility issues.
