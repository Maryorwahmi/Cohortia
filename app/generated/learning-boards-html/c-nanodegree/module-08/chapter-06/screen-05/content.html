Definition
Conan fundamentals
Conan uses recipes and profiles to manage C++ packages and their build environment. Generators create CMake toolchain and dependency files for integration.
conanfile.py — recipe for package creation and packaging steps.
conanfile.txt — simple consumer list of requires and generators.
Profiles — define compiler, build type, architecture, and settings.
Remotes — servers like ConanCenter or private remotes.
Pro tip
Create a profile for every CI configuration and check them into version control so everyone builds the same binaries.
Example conanfile.txt
[requires]
fmt/8.1.1
spdlog/1.10.0

[generators]
CMakeDeps
CMakeToolchain

[layout]
cmake_layout
Key Takeaway

Use conanfile + profiles to capture both dependencies and the build environment; generators bridge Conan and CMake.
