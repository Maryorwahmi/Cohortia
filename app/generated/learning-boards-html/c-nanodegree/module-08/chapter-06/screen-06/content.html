Process Flow
Conan install → CMake configure → Build
1
Write conanfile.txt or conanfile.py listing required packages and desired generators.
2
Run conan install . --output-folder=build --build=missing with a profile to resolve and populate dependencies.
3
Configure CMake using the generated conan_toolchain.cmake so include and link paths are set.
4
Call find_package and target_link_libraries in CMakeLists.txt and build.
Command examples
conan install . --output-folder=build --build=missing
cmake .. -DCMAKE_TOOLCHAIN_FILE=conan_toolchain.cmake
cmake --build .
Common mistake
Running find_package but forgetting to link the library with target_link_libraries will produce undefined references at link time.
Key Takeaway

The install step produces the CMake bridge. Use it; otherwise CMake won't know the correct include and library paths.
