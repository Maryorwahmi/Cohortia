Dependency Management with Conan and vcpkg
How package managers reduce build friction, ensure reproducible binaries, and integrate with CMake
Interactive 16:9 Masterclass
In this lesson

You will learn the core compatibility problems in C++, how Conan and vcpkg address them, the common commands and files you need, and a practical lab using the fmt library. Examples are CMake-based to match common workflows.

Problem
Compiler, ABI, and platform mismatches cause build and runtime failures unless dependencies are managed consistently.
Conan
Recipe-driven, supports binaries and source, profiles control build settings and compatibility.
vcpkg
Curated ports and triplets; builds from source and integrates via a CMake toolchain file.
