Definition
vcpkg fundamentals
vcpkg focuses on building libraries from source using ports and triplets and integrates with CMake via a toolchain file.
Ports — recipes (CMake scripts and patches) that fetch and build libraries.
Triplets — strings describing target OS, architecture, and toolchain settings.
Toolchain file — tells CMake where vcpkg installed packages live and enables find_package in CONFIG mode.
Pro tip
Pick and share a standard triplet for your team so installs produce identical artifacts across machines.
Commands
git clone https://github.com/microsoft/vcpkg.git
./vcpkg/bootstrap-vcpkg.sh
/path/to/vcpkg/vcpkg install fmt spdlog:x64-linux
cmake -DCMAKE_TOOLCHAIN_FILE=/path/to/vcpkg/scripts/buildsystems/vcpkg.cmake ..
Key Takeaway

vcpkg provides a curated path to build libraries from source and a simple CMake toolchain to consume them via find_package in CONFIG mode.
