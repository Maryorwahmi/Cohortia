Conan demo commands
cd conan_project
mkdir build_conan && cd build_conan
conan install .. --output-folder=. --build=missing
cmake .. -DCMAKE_TOOLCHAIN_FILE=conan_toolchain.cmake
cmake --build .
./conan_app
Expect to see fmt output. If find_package fails, open conan_deps.cmake to inspect targets and paths.
vcpkg demo commands
git clone https://github.com/microsoft/vcpkg.git
cd vcpkg && ./bootstrap-vcpkg.sh
/path/to/vcpkg/vcpkg install fmt:x64-linux
cd vcpkg_project
mkdir build_vcpkg && cd build_vcpkg
cmake .. -DCMAKE_TOOLCHAIN_FILE=/path/to/vcpkg/scripts/buildsystems/vcpkg.cmake
cmake --build .
./vcpkg_app
Check the vcpkg output to confirm the triplet used and that CMake used the vcpkg toolchain for dependency resolution.
Key Takeaway

Running both flows helps you see where toolchain files set include and link paths; that’s the integration contract between the manager and CMake.
