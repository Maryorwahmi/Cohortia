Module 8 › Chapter 8.5 › Run Clang-Tidy
Process

Run checks at scale

Use a wrapper script or CI job to run Clang-Tidy across the compilation database rather than invoking it per file manually.

Wrapper script
python /path/to/run-clang-tidy.py -p build_directory
CMake target example
add_custom_target(check-tidy COMMAND clang-tidy -p ${CMAKE_BINARY_DIR} src/main.cpp)
Handling legacy warnings
Treat new warnings on changed code as blocking while cleaning up older warnings incrementally. This prevents developer churn and focuses effort where it matters.
Key Takeaway

Automate project-wide runs and prioritize new warnings to maintain steady improvements without blocking development.
