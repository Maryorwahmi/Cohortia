Module 8 › Chapter 8.5 › Interpreting Warnings
Example

bugprone-uninitialized-local-variable

This diagnostic points to a variable that may be used without initialization. The remedy is to initialize the variable or adjust control flow.

int uninitialized_value;
std::cout << uninitialized_value; // warning: uninitialized local variable
Example

modernize-loop-convert

Suggests using a range-based for loop instead of indexing the container manually for clarity and safety.

for(int i = 0; i < data.size(); i++) {
  std::cout << data[i] << " ";
}
// Suggested: for (int v : data) { std::cout << v << " "; }
Fix and re-run
After applying a change, run clang-tidy again to ensure the diagnostic is resolved and no new ones appear.
Caution
Automated fixes can sometimes alter behavior; always review fixes before committing.
Key Takeaway

Read the diagnostic name and message, apply a careful fix, and re-run checks to confirm the issue is gone.
