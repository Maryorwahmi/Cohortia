Module 8 › Chapter 8.5 › Automation
Process

Automate in editors, hooks, and CI

Remove manual steps by integrating formatters and static checks into developer workflows and CI pipelines.

Editor integration
Enable format on save and inline diagnostics so developers receive feedback immediately.
Pre-commit hook
Run clang-format then a quick clang-tidy on staged files before commit.
CI job
Run full clang-tidy across the build; consider failing on new warnings only to reduce disruption.
Key Takeaway

Automate checks and formatting where developers work and in CI, and align tool versions to avoid surprises.
