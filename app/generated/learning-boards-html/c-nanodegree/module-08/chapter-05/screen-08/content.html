Code Walkthrough

src/main.cpp (problematic)

#include <iostream>
#include <vector>

int calculate_discount(int price) {
    if(price > 100) {
        return price - (price * 10 / 100);
    }
    return price;
}

void process_data() {
    int uninitialized_value;
    std::cout << "Uninitialized value: " << uninitialized_value << std::endl;

    std::vector data;
    data.push_back(1);
    data.push_back(2);
    for(int i = 0; i < data.size(); i++) {
        std::cout << data[i] << " ";
    }
    std::cout << std::endl;
}

int main() {
    std::cout << "Hello, Quality World!" << std::endl;
    int final_price = calculate_discount(150);
    std::cout << "Discounted price: " << final_price << std::endl;
    process_data();
    return 0;
}
Run this sequence
mkdir build && cd build cmake .. clang-format -i ../src/main.cpp clang-tidy -p . ../src/main.cpp
Expected results
  • main.cpp is reformatted according to .clang-format
  • Clang-Tidy warns about the uninitialized variable and suggests modernizing the loop
Key Takeaway

Use a small project to iterate: format first, then run static checks with a compilation database for accurate diagnostics.
