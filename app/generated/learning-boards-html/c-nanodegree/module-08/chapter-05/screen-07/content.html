Process Flow

Create the compilation database

Follow these steps to produce compile_commands.json so Clang-Tidy runs with full context.

1. Add to CMakeLists
set(CMAKE_EXPORT_COMPILE_COMMANDS ON)
2. Create build dir
mkdir build && cd build
3. Run CMake
cmake ..
Run Clang-Tidy with the DB
clang-tidy -p build_directory/path/to/source_file.cpp
# Or use a wrapper to run across the whole database
python /path/to/run-clang-tidy.py -p build_directory
Tip
Confirm paths inside compile_commands.json if Clang-Tidy shows missing headers.
Pitfall
Don't expect compile_commands.json in the source root; look in the build folder created by CMake.
Key Takeaway

Generate and point Clang-Tidy to the compilation database so diagnostics reflect real compile flags.
