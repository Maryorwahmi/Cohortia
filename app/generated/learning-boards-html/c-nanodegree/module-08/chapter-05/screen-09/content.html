Module 8 › Chapter 8.5 › .clang-format
Definition

Create a shared style

Use a .clang-format file to standardize indent, brace placement, pointer alignment, and more.

# .clang-format example
BasedOnStyle: Google
IndentWidth: 4
TabWidth: 4
UseTab: Never
BreakBeforeBraces: Attach
PointerAlignment: Left
AccessModifierOffset: -4
Apply formatting
clang-format -i path/to/source_file.cpp
Tip
Enable editor integration to format on save so developers rarely see unformatted changes.
Key Takeaway

Adopt a base style, tune a few options, and automate formatting to remove style discussions from review.
