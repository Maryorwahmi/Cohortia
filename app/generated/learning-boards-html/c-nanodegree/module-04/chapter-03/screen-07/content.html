Undefined reference: walkthrough
Examine which TU performs instantiation and which provides definitions.
Files
my_template.h (declaration), my_template.cpp (definition), main.cpp (uses template)
Compiler behavior
  • Compiling main.cpp: sees declaration, needs printValue<int>, cannot instantiate without definition.
  • Compiling my_template.cpp: has definition but does not instantiate printValue<int> unless used there.
  • Linker: fails to find any object file that contains printValue<int>.
Broken example (simplified)
// my_template.h
template <typename T>
void printValue(const T& value); // declaration

// my_template.cpp
#include "my_template.h"
#include <iostream>

template <typename T>
void printValue(const T& value) {
  std::cout << "Value: " << value << std::endl;
}

// main.cpp includes my_template.h and calls printValue(10)
Diagnosis checklist
Check whether the .o files actually contain the instantiated symbol. If not, verify where instantiation should occur and whether the definition is visible there.
Key Takeaway

When a needed instantiation is not produced, move the definition into the header or add explicit instantiation for the needed types in a .cpp.
