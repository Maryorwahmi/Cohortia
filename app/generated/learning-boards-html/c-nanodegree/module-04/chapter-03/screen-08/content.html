Module 4 › Chapter 4.3 › Fix: Header Move
Move definition to header
Make the definition visible so instantiation runs where usage appears.
Corrected my_template.h
// my_template.h
#include <iostream>

template <typename T>
void printValue(const T& value) { // definition in header
  std::cout << "Value: " << value << std::endl;
}
Why this fixes it
When compiling main.cpp, phase two sees the definition and can generate printValue<int> in that compilation unit.
Alternate: Explicit instantiation
Add explicit instantiations in my_template.cpp for each type you want the .o file to provide.
// my_template.cpp
#include "my_template.h"

// explicitly instantiate for int and std::string
template void printValue<int>(const int&);
template void printValue<std::string>(const std::string&);
Key Takeaway

Use header definitions for flexibility. Use explicit instantiation only when you can enumerate all needed types and accept reduced flexibility.
