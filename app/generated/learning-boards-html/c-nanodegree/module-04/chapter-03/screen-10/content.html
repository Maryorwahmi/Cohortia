Module 4 › Chapter 4.3 › Common Mistakes
Forgetting template prefixes
Always write template <typename T> and qualify the member as MyClass<T>::method when defining outside the class body.
Circular includes
Templates typically require full definitions, so forward declarations are limited. Structure headers to avoid cycles and include what you use.
Key Takeaway

Small errors in template syntax or file structure produce confusing messages; consistent header organization prevents many issues.

Code bloat
Each distinct instantiation may add code. If many types are used, consider trade-offs between performance, clarity, and binary size.
Cryptic error messages
Read template diagnostics from the bottom up. Focus on lines that reference your code and the instantiated type list.
Practical check
If you see undefined reference, run nm or objdump on object files to see which symbols they contain and where instantiation happened.
