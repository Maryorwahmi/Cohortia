Instantiation
How the compiler makes a concrete function or class from a template.
Definition
A template is a blueprint. Instantiation substitutes template parameters with concrete types and then compiles and checks the resulting code.
Concrete example
Calling printValue(10) causes creation of printValue. The compiler checks the body using int now.
Common misconception
Templates are not compiled for every possible type by default; only used combinations are instantiated.
Key Takeaway

Think "instantiate on use." If no translation unit asks for a type, no code is generated for it there.

Annotated Example
// template declaration and definition
template <typename T>
void printValue(const T& value) {
  std::cout << "Value: " << value << std::endl;
}

// usage in main
printValue(10); // instantiates printValue<int>
printValue("hi"); // instantiates printValue<const char*>
Example Card: Implicit instantiation happens when usage appears in the translation unit.
Check: If a .cpp file contains only a declaration, other .cpp files may request instantiation without seeing the definition.
Try this
Ask yourself: which translation unit will instantiate printValue<int>? If the .cpp with the definition never uses int, the linker will not find the symbol.
