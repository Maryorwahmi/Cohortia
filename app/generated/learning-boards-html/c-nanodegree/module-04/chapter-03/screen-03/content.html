Module 4 › Chapter 4.3 › Learning Objectives
Objective
Diagnose linker errors
Map the undefined reference message to a missing instantiation or misplacement of template definitions.
Mnemonic: "Read the mangled name to find the template and the type arguments." Use the symbol name to find the template declaration that lacked a visible definition.

Objective
Use explicit instantiation when needed
When you can predict all types, explicitly instantiate them in a single .cpp so the linker finds concrete symbols.
Mnemonic: "Lock and load: instantiate the exact types you want once." This reduces header exposure but is less flexible.
VERIFIED COMPETENCY MILESTONE
Objective
Avoid template pitfalls
Prevent circular includes, remember template prefixes for out-of-class definitions, and be mindful of code bloat from many instantiations.
VERIFIED COMPETENCY MILESTONE
Objective
Explain export's history
Understand that export was intended to separate definitions, but it was removed because compilers rarely implemented it and it added complexity.
