Template Instantiation and Linker Errors
Understand the two-phase translation model and practical file-organization rules to avoid undefined references.
In this lesson
How templates are parsed and instantiated, why definitions go in headers, and how to fix the linker error produced by hidden definitions.
Why it matters
Correct organization prevents build breakage and long linker hunts. These rules reduce wasted debugging time.
Phase 1
Parse template syntax without concrete types.
Phase 2
Instantiate and semantic-check for each used type.
Fix
Place definitions in headers or use explicit instantiation carefully.
Key Takeaway

Treat templates as header-visible blueprints. When the compiler must build a concrete version, the definition must be visible in that translation unit.
