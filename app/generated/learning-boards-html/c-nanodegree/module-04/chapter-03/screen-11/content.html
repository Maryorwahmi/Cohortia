Starter files
Reproduce the linker error, then fix by moving the definition or using explicit instantiation.
calculator.h
#ifndef CALCULATOR_H
#define CALCULATOR_H

template <typename T>
class Calculator {
public:
  T add(T a, T b); // declaration only
};

#endif // CALCULATOR_H
calculator.cpp
#include "calculator.h"

template <typename T>
T Calculator<T>::add(T a, T b) {
  return a + b;
}
main.cpp
Uses Calculator<int> and Calculator<double> to exercise add.
Compile & Fix
Compile: g++ main.cpp calculator.cpp -o app (may produce undefined reference). Fix: move definition to calculator.h or add explicit instantiation in calculator.cpp.
Key Takeaway

Doing the lab makes the instantiation rule tangible: the translation unit that needs a type must see the definition to instantiate it.
