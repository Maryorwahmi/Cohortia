What assessments check

printArray question
Which calls correctly instantiate printArray(const T arr[], int size)? Valid ones pass a named array of matching element type and an int for size. Braced-init-lists cannot be passed directly in this context; declare a variable first.
Why this matters
It tests your understanding of parameter types and how arrays decay to pointers for deduction.
compareAndPrint question
compareAndPrint with different template parameters compiles and uses implicit conversions for comparisons. Calling compareAndPrint(5, 5.0) will usually print 'Values are equal' because the int is promoted to double for equality checking.
Pitfall
Relying on implicit conversions can hide precision loss; tests may expect you to reason about conversion results.
Key Takeaway

Practice common edge cases: mixed types, array passing, and size parameter types so you can explain the compiler's behavior in assessments.
