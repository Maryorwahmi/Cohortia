How deduction works

Deduction steps
  1. Match call arguments to parameter types declared with template parameters.
  2. For each template parameter, deduce a concrete type from the argument.
  3. If deduction is ambiguous, require explicit template arguments or multiple parameters.
Example
max(5,10) → T = int. max(3.14,2.71) → T = double. max(5,3.14) can be ambiguous without conversions.
Caveats & patterns
  • Use multiple template parameters when arguments are different types and you need to preserve them.
  • Explicit casts resolve ambiguity but may hide precision loss.
  • Array literals and braced-init-lists may not deduce the same way as named arrays; declare arrays first when needed.
Misconception
Deduction is not a conversion tool; it selects types, and conversions follow normal language rules.
Key Takeaway

Predict deduction by matching argument types to template parameters; use explicit parameters or multiple type parameters for mixed-type scenarios.
