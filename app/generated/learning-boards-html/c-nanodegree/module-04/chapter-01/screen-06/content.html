Module 4 › Chapter 4.1 › Template Syntax

Write the template, see the compiler produce code

Template declaration
template <typename T>
T max(T a, T b) {
  return (a > b) ? a : b;
}

// Calls
// max(5, 10)   -> instantiates int max(int, int)
// max(3.14, 2.71) -> instantiates double max(double, double)
Notes & implications
  • Type deduction occurs from call-site arguments; explicit template arguments are also possible.
  • Each distinct deduced type produces a separate compiled instantiation.
  • Instantiation happens at compile time, not at runtime.
  • Templates keep runtime performance equal to handwritten type-specific functions.
Misconception
Templates add runtime overhead — not true; the compiler generates optimized type-specific code.
Key Takeaway

Template syntax declares type placeholders; instantiation is the compile-time creation of concrete functions for those types.
