Definitions to keep handy

Type Deduction
Compiler determines concrete template parameter types from function call arguments.
Instantiation
The compiler produces concrete functions or classes from a template for specific types used.
Code Duplication
Repeated nearly identical code across types that templates help eliminate.
Final takeaway

Use templates when you have repeated logic across types, predict deduction when calling templates, and design for mixed types with multiple parameters.
