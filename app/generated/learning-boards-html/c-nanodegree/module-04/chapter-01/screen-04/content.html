Generic Programming

Write algorithms in terms of types to maximize reuse and keep performance.

Definition & Analogy

Generic programming expresses algorithms using placeholders for types, which are supplied later. The recipe analogy helps: a single instruction set works with different ingredients.

Concrete example
A single template max function replaces separate int and double overloads and works for any comparable type.
Misconception
Templates are not a runtime polymorphism feature; they perform work at compile time and generate type-specific code.
Analogy Card & Quick Notes
Recipe analogy
Placeholder types are like ingredients that get specified when you cook.
Why it matters
Reduces repeated code and keeps the compiler generating optimized, type-safe functions.
Check your understanding
Name one function you write often that could be turned into a template and why.
Key Takeaway

Generic programming abstracts over types so a single implementation can serve many concrete types without runtime overhead.
