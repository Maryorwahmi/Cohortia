Why duplication happens

Two nearly identical functions for different types increase maintenance and risk inconsistent behavior.

Non-template example
// Separate functions for each type
int max_int(int a, int b) {
  return (a > b) ? a : b;
}

double max_double(double a, double b) {
  return (a > b) ? a : b;
}
Maintenance: fix logic in multiple places. Tests must cover each overload.
Template solution
// One template replaces many overloads
template <typename T>
T max(T a, T b) {
  return (a > b) ? a : b;
}
The compiler instantiates concrete functions like max<int> and max<double> for calls you make.
Example
max(5, 10) deduces int, max(3.14, 2.71) deduces double.
Common mistake
Writing many overloads instead of a template duplicates logic and creates drift between implementations.
Key takeaway
One template keeps behavior consistent and reduces maintenance surface.
