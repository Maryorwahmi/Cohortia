Accepting mixed argument types

Problem
A single template parameter fails when arguments are different types, causing ambiguous deduction or implicit conversion and possible precision loss.
Bad pattern
template <typename T> T add(T a, T b);
add(5, 3.14); // ambiguous or converts int to double
Better pattern
Use multiple parameters and deduce the return type with auto when appropriate.
template <typename T1, typename T2>
auto add(T1 a, T2 b) { return a + b; }
Example
compareAndPrint(5, 5.0) prints both values; equality uses implicit numeric promotion and may evaluate as equal.
Key Takeaway

When arguments have different types, prefer multiple template parameters and an explicit or deduced return type to avoid ambiguity and preserve precision.
