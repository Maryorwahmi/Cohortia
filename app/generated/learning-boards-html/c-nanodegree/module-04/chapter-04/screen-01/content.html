Template Metaprogramming (TMP) Basics

Learn how templates and compile-time features produce pre-computed results and specialized code paths. We’ll explore recursive templates, type traits, SFINAE, and the modern if constexpr alternative.

Orientation

This chapter pairs short code walkthroughs with conceptual visuals. Expect live-coding examples for factorial and conditional templates, plus a hands-on starter to practice if constexpr with type traits.

Visual Concept
Compile-time
Templates and constexpr evaluated by the compiler. Produces constants or specialized code.
Runtime
Regular functions and loops executed when the program runs. Flexible but costs time each run.
Example: Factorial
Recursive template instantiation yields Factorial<5> as a compile-time constant. A constexpr function can compute it at compile time when its input is constant.
