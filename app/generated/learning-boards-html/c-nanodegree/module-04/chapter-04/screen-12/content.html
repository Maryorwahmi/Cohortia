Module 4 › Chapter 4.4 › Key Concepts
Template Metaprogramming
Use templates as a compile-time language to compute values and generate specialized code.
Compile-time Computation
Computation by the compiler yields pre-computed constants and optimized binaries.
Recursive Templates
Recursive instantiation with a base specialization implements compile-time loops and constants like factorial and Fibonacci.
Summary Takeaway

Use TMP selectively for performance and type-level needs; prefer constexpr and if constexpr for clarity when they meet requirements.
