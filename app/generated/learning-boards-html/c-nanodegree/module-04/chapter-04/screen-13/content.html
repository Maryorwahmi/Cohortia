Type Traits
std::is_integral, std::is_convertible, std::is_pointer — the predicates used to decide compile-time behavior.
SFINAE / enable_if
Use to conditionally remove overloads. Powerful but can complicate diagnostics and readability.
if constexpr
Prefer for in-body compile-time branching. Only the true branch is instantiated, simplifying code and errors.
Final Reflection

Before using TMP, measure whether compile-time specialization yields meaningful runtime benefits and whether maintainability remains acceptable.
