Code Walkthrough

Factorial as a template struct

#include <iostream>

// Base case for Factorial
template <int N>
struct Factorial {
  static const long long value = N * Factorial<N - 1>::value;
};

// Specialization for Factorial<0>
template <>
struct Factorial<0> {
  static const long long value = 1;
};

// Usage: Factorial<5>::value is computed at compile time
This code forces compile-time computation. The base specialization Factorial<0> stops recursion. If the base were missing, the compiler would produce an instantiation-depth error.
Step-by-step instantiation
Request: Factorial<5>::value 1) Instantiate Factorial<5> which needs Factorial<4>::value 2) Instantiate Factorial<4> which needs Factorial<3>::value 3) Continue until Factorial<0> specialization is used and returns 1 4) Multiply back up: 1 * 1 * 2 * 3 * 4 * 5 = 120
Common Mistake
Forgetting the base case or mis-declaring the specialization causes non-terminating instantiation errors or deep template recursion diagnostics.
Pro Tip
Test with small N values and read instantiation traces to find which specialization the compiler selects.
