Module 4 › Chapter 4.4 › Compile-time vs. Runtime
Process Flow

Where work happens

Write
Templates or constexpr functions in source code.
Compile
Compiler instantiates templates and evaluates constexpr expressions, producing concrete types and values.
Run
Program uses pre-computed values or specialized code for faster execution.
Why it matters

Shift expensive, repeated computations to compile time only when the benefit outweighs increased compile time and potential complexity.

Concrete Example
Imagine a polynomial evaluator used in a tight loop. If coefficients and degree are known at compile time, the compiler can unroll and specialize evaluation logic so the loop runs faster. Otherwise, repeated runtime evaluation may dominate cost. Test both approaches and prefer compile-time work for hot paths.
Common Mistake
Overusing TMP for non-critical code increases compile time and makes maintenance harder. Prefer clear code unless profiling shows runtime cost.
Check Your Understanding
When would you prefer constexpr over TMP templates? Answer: prefer constexpr for value computation when type-level specialization is not required.
