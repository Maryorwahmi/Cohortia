Learning Objectives

Skills to demonstrate after completing this chapter.

01
Define TMP and purpose
Explain how templates drive compile-time computation, and why moving work to compilation improves runtime speed and enforces type constraints.
VERIFIED COMPETENCY MILESTONE
02
Write recursive compile-time templates
Create templates with base specializations that terminate recursion, producing compile-time constants like factorial or Fibonacci.
VERIFIED COMPETENCY MILESTONE
03
Use type traits
Apply utilities like std::is_integral to branch code or enable specific overloads based on compile-time type properties.
VERIFIED COMPETENCY MILESTONE
04
Apply if constexpr for clarity
Use C++17 if constexpr to compile only the valid branch, simplifying older SFINAE-based conditional code.
VERIFIED COMPETENCY MILESTONE
