Hints & Mistakes
Hint
Use if constexpr (std::is_arithmetic<T>::value) { ... } else if constexpr (std::is_convertible_v<T, std::string>) { ... } else { ... }
Common Mistake
Calling .length() or string operations outside a guarded branch causes compilation errors because those expressions get instantiated for all template instantiations unless guarded by if constexpr.
