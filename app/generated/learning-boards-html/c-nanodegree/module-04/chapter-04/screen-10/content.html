Module 4 › Chapter 4.4 › if constexpr
Example
#include <iostream>
#include <type_traits>

template <typename T>
void modernProcessValue(T value) {
  if constexpr (std::is_integral<T>::value) {
    std::cout << "Modern: Processing integral number: " << value << std::endl;
  } else if constexpr (std::is_floating_point<T>::value) {
    std::cout << "Modern: Processing floating-point number: " << value << std::endl;
  } else {
    std::cout << "Modern: Processing other value: " << value << std::endl;
  }
}
Only the branch that matches T will be compiled. If the discarded branch contains expressions invalid for T, they do not cause errors because they are not instantiated.
Practice
Call modernProcessValue with int, float, string, and a custom struct to observe which branch is compiled. This exercise shows the clarity and robustness of if constexpr compared to SFINAE overloads.
Pro Tip
Prefer if constexpr inside a template when all branches are determined by compile-time traits; it reduces template proliferation and improves diagnostics.
