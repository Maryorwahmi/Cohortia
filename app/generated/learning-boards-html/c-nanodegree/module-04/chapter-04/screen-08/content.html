Definition

What are type traits?

Compile-time predicates and utilities that report properties of types, like whether a type is integral or pointer, or whether it is convertible to another type.

Examples
std::is_integral<T>, std::is_pointer<T>, std::is_convertible<T, U>.
Use cases
Enable overloads, perform compile-time assertions, or branch code with if constexpr based on type properties.
Quick Example
#include <type_traits>

static_assert(std::is_integral<int>::value, "int is integral");
// std::is_integral<double>::value is false
Traits are the building blocks for conditional templates. They don’t perform operations themselves, they report properties so you can select appropriate code paths at compile time.
