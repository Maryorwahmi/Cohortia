Pair<T1,T2> — code
#include <iostream>
#include <string>

template <typename T1, typename T2>
class Pair {
private:
    T1 first;
    T2 second;

public:
    Pair(T1 f, T2 s) : first(f), second(s) {}

    T1 getFirst() const { return first; }
    T2 getSecond() const { return second; }

    void setFirst(T1 f) { first = f; }
    void setSecond(T2 s) { second = s; }

    void print() const {
        std::cout << "(" << first << ", " << second << ")" << std::endl;
    }
};
Try instantiating Pair with different combinations. Ensure each type used supports the operations you call, for example printing to standard output in print().
Usage examples
Pair<int,double> p1(10, 20.5); Pair<std::string,char> p2("Hello", 'W'); Pair<int,int> p3(100,200);
  • When used with printable types, print() produces human-readable output.
  • Construction is explicit unless using C++17 CTAD to deduce types.
  • If you move definitions outside the class body remember the template prefix and qualified name.
Key Takeaway
Multiple template parameters let Pair store different types in one concise class template.
