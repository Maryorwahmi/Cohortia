Stack<T> — code
#include <iostream>
#include <vector>
#include <stdexcept>

template <typename T>
class Stack {
private:
    std::vector<T> elements;

public:
    void push(const T& item) { elements.push_back(item); }

    T pop() {
        if (isEmpty()) throw std::out_of_range("Stack is empty, cannot pop.");
        T top_element = elements.back();
        elements.pop_back();
        return top_element;
    }

    const T& top() const {
        if (isEmpty()) throw std::out_of_range("Stack is empty, no top element.");
        return elements.back();
    }

    bool isEmpty() const { return elements.empty(); }
    size_t size() const { return elements.size(); }
};
This implementation emphasizes correct API behavior and exception handling. Test with primitive and user-defined types to see how requirements on T shape your design.
Usage and notes
  • Push and pop delegate storage to std::vector<T>. Ensure T is copyable or movable.
  • top() returns a const reference to avoid copying; pop() returns a value after removal.
  • Throwing exceptions for empty operations is a clear contract for callers.
Key Takeaway
Compose templates: use std::vector<T> inside Stack<T> to create a flexible container while preserving type requirements.
