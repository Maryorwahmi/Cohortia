Module 4 › Chapter 4.2 › Member Function Syntax
Required pattern
template <typename T1, typename T2>
void Pair<T1, T2>::print() const {
    std::cout << "(" << first << ", " << second << ")" << std::endl;
}
Notice the two pieces: the template prefix and the Pair<T1, T2> qualification. Missing either leads to compiler confusion or errors indicating the function is not a member of a template instantiation.
Explanation bullets
  • The template line introduces the parameter names for this definition.
  • The qualified name Pair<T1, T2>::print ties the definition to the templated class.
  • These repetitions are required because templates are instantiated separately by the compiler.
Pro Tip
When moving functions out, compile early: fix one function at a time to isolate missing prefixes or wrong qualifications.
