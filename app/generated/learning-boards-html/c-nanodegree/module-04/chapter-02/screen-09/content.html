Keep template definitions visible
Placing definitions in .cpp hides them from instantiation sites and leads to errors.
Symptom
Linker errors like undefined reference to MyTemplate<int>::method when using the template in another translation unit.
Solution patterns include: put definitions in the header, or include an implementation file from the header (for example MyTemplate.hpp includes MyTemplate.ipp).
Why it matters
Templates are instantiated where used. If the compiler doesn't see the definition at that point, it can't generate the code for the concrete type.
Takeaway: prefer header-only templates or clearly included implementation files for predictable builds.
