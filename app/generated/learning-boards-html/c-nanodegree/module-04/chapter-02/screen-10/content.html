    int priority;
    Task(std::string desc, int prio) : description(std::move(desc)), priority(prio) {}
    friend std::ostream& operator<<(std::ostream& os, const Task& t) {
        os << "[" << t.description << ", P" << t.priority << "]";

Hints & design notes
  • enqueue: push_back to the vector.
  • dequeue: check isEmpty, remove front element; throw std::out_of_range when empty.
  • front: return const T& to the front element; do not return a reference to a temporary.
  • Performance: vector erase at front is O(n); acceptable for this exercise but consider deque for production.
