Module 4 › Chapter 4.2 › Instantiation: explicit vs CTAD
Explicit instantiation
Pair<int,double> p1(10, 20.5);
Stack<std::string> s;
Explicit types are reliable in all standards and are often preferred in headers and library interfaces for clarity.
CTAD (C++17)
Pair p1(10, 20.5); // deduced as Pair<int,double>
Stack s;           // may deduce if constructors allow
Deduction simplifies local code but can fail for ambiguous constructors. Use compiler diagnostics to confirm the deduced types.
When to prefer explicit
Library APIs and code intended for multiple standards should prefer explicit template arguments for clarity and portability.
When CTAD helps
Short, local examples and interactive demos benefit from CTAD to reduce visual clutter when deduction is obvious.
