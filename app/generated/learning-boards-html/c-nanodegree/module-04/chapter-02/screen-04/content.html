Module 4 › Chapter 4.2 › Why Class Templates?
Definition & Motivation
Class templates parameterize types so a single implementation supports many concrete types.
  • Templates use placeholders like T that become real types on instantiation.
  • They remove duplicated code such as separate stacks per type while keeping compile-time checks.
  • Templates create distinct types for each parameter instantiation rather than runtime polymorphism.
  • Design your template's requirements on T explicitly in comments or documentation.
Key Takeaway
Use class templates to capture reusable container logic for any stored type without losing type checks.
Common Mistake
Treat templates like runtime polymorphism; they generate separate types at compile time instead.
Concrete example
// A single Stack template serves many types
template <typename T>
class Stack {
  // push, pop, top, isEmpty, size using std::vector<T>
};

// Then in main
Stack<int> intStack;
Stack<std::string> stringStack;
This shows the same Stack implementation works for int and string. The compiler instantiates separate Stack<int> and Stack<std::string> types from one template.
