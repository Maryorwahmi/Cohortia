Class Templates
Write one class blueprint that works with many types while keeping compile-time safety.
Class templates let you parameterize a class with type placeholders like T. When you create objects, you supply concrete types or rely on deduction when available. This removes duplicated classes such as IntStack and StringStack and makes library-quality containers possible.

Why templates?
Save effort by eliminating duplicate container implementations while retaining strong type checking at compile time.
Common pitfall
Putting template definitions in .cpp causes linker errors because the compiler can't instantiate the template where it’s needed.
