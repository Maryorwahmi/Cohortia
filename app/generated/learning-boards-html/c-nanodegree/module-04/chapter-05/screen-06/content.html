Example expansions
// Call-site expansion func(args...); // If args = {1, 2.5, "hi"} this becomes func(1, 2.5, "hi"); // Expression expansion with comma operator ((std::cout << args << ' '), ...); // Expands to ( (cout << a1 << ' '), (cout << a2 << ' '), ... )
Expansion preserves evaluation order for comma-operator folds; conversions and overload resolution happen per expanded element. Use helpers to control conversions before expansion.
Bulleted guide
  • Ellipsis after an expression expands the pack into a comma-separated sequence.
  • Positioning matters: expression... vs ...expression have different semantics.
  • To control conversions, wrap each element with a helper before expansion.
Common mistake: placing the ellipsis in the wrong syntactic location. The compiler error messages often point to where the expansion was expected.
Key Takeaway

Pack expansion turns a pack into many expressions; get the ellipsis placement right to avoid syntax errors.
