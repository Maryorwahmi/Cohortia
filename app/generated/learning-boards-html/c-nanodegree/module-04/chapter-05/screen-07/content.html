Fold Expressions
Forms at a glance
  • (... op pack) — unary left fold
  • (pack op ...) — unary right fold
  • (init op ... op pack) — binary left fold
  • (pack op ... op init) — binary right fold
// Sum example template <typename... Args> auto sumAll(Args... args) { return (args + ...); // binary left fold across args } // Safe with empty pack return (0 + ... + args); // yields 0 when args is empty
Practical notes
Use binary folds with an explicit initializer when you need a well-defined result for empty packs. Use the comma operator fold to sequence side effects like printing. Remember that some unary forms require at least one element in the pack.
Misconception: unary folds always handle empty packs. They often require at least one element; use a binary fold with init to be safe.
Key Takeaway

Pick the fold form with the empty-pack behavior you need: initializer for safety, unary for simpler non-empty reductions.
