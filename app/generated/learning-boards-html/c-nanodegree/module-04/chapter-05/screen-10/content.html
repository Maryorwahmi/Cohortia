Hands-on Activity › concat using fold
Starter helper + concat
#include <iostream> #include <string> #include <sstream> template <typename T> std::string toString(const T& val) { std::ostringstream oss; oss << val; return oss.str(); } template <typename... Args> std::string concat(Args... args) { return (std::string("") + ... + toString(args)); }
This uses a binary left fold with an empty-string initializer so concat() returns an empty string when called without arguments.
Example tests
concat("Hello"," ","World") → "Hello World". concat() → "". concat("Num:", 42, ", pi=", 3.14) → "Num:42, pi=3.14".
Pitfall: relying on operator+ between mixed types without converting can lead to overload ambiguity. Convert first.
Key Takeaway

Use a converter and a fold with an initializer to implement safe, variadic concatenation.
