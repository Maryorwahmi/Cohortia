Example › Fold-based Printing
Unary right fold with comma operator
template <typename... Args> void printFold(Args... args) { ((std::cout << args << " "), ...); std::cout << std::endl; } // Usage: printFold("A", 10, true); // prints: A 10 1
This expands each output expression and sequences them with the comma operator. Add an explicit cast to void if your compiler warns about unused results.
Binary fold for separators
template <typename T, typename... Args> void printWithSeparator(T first, Args... rest) { std::cout << first; ((std::cout << ", " << rest), ...); std::cout << std::endl; } // Usage: printWithSeparator("apple", "banana", "cherry");
This avoids printing a leading separator and handles any number of remaining items. If there are no remaining items the fold simply does nothing.
Misconception: folds change evaluation order. They preserve the sequence defined by the operator and expansion; the comma operator evaluates left to right.
