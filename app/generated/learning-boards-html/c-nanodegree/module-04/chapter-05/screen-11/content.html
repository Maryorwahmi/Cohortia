Warnings › Common Mistakes
Missing base case
Always include a non-variadic overload or an initializer for folds. Example fix: use (0 + ... + args) for sums.
Ellipsis placement
Attach the ellipsis to the expression to expand. Misplacements cause cryptic compiler errors.
Type ambiguity
Convert elements before folding to avoid relying on operator overload resolution between mixed types.
Empty packs and folds
Use binary folds with initializers when empty packs are valid inputs.
Forwarding semantics
Use forwarding references and std::forward for perfect forwarding when processing rvalues and lvalues through packs.
Debug tip
Compile small examples and read template instantiation traces; they reveal where ellipses or missing cases cause failures.
