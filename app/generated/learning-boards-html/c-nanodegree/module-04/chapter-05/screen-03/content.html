Hands-on Activity
Implement concat using folds
Starter idea: use a toString helper to convert each argument, then apply a binary fold with an initial empty std::string so that the empty-pack case returns an empty string. Test with std::string, const char*, int, and double inputs to ensure conversions behave as expected.
Test: concat("Hello", " ", "World") → "Hello World"
Test: concat() → "" (empty)
Assessment: answer the log output question and identify the correct areAllEqual fold implementation from given options.
Why this matters
Variadic templates are used throughout modern C++ libraries. Being able to reason about them and to write concise fold expressions improves both library design and everyday utility functions.
