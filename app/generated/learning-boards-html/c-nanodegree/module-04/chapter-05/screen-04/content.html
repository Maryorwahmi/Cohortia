Parameter pack basics
A parameter pack groups zero or more parameters under a single name so templates can accept variable numbers of types or values. Use sizeof... to get the compile-time count of elements in a pack. Remember that packs can be empty, so code must account for that.
// Template parameter pack example template <typename... Args> struct CountTypes { static constexpr std::size_t value = sizeof...(Args); }; // Usage: CountTypes<int, double, char>::value == 3
Misconception: the ellipsis alone does nothing. It is attached to a name to declare a pack or to an expression to expand it.
Pro tip: use sizeof... in compile-time logic to specialize implementations by pack size.
Quick checklist
  • Declare template packs with typename... Name.
  • Declare function packs with Name... args.
  • Use sizeof... to count elements at compile time.
Key Takeaway

Parameter packs make templates variadic; always consider empty-pack scenarios.
