Modern C++ (C++11+)

decltype(auto) for Perfect Forwarding

Preserving value categories and qualifiers in generic forwarding functions.

Key Feature

Deduces the exact type, including reference and const/volatile qualifiers, of an expression.

Use Case

Crucial for implementing perfect forwarding, ensuring arguments are passed with their original value category.

Key Takeaway

Employ decltype(auto) when you need precise type preservation, especially for return types in perfect forwarding scenarios, to avoid unintended copies or type decay.

#include <iostream>
#include <utility> // For std::forward

int& get_int_ref(int& x) { return x; }
const int& get_const_int_ref(const int& x) { return x; }
int get_int_val(int x) { return x; }

// A generic forwarding function
template <typename Func, typename... Args>
decltype(auto) callAndForward(Func f, Args&&... args) {
    // decltype(auto) preserves reference and const-ness of f's return type
    return f(std::forward<Args>(args)...);
}

int main() {
    int a = 10;
    const int b = 20;

    // callAndForward preserves the reference type
    int& ref_a = callAndForward(get_int_ref, a);
    ref_a = 15; // Modifies 'a'
    std::cout << "a: " << a << std::endl; // Output: a: 15

    // callAndForward preserves the const reference type
    const int& cref_b = callAndForward(get_const_int_ref, b);
    // cref_b = 25; // Error: cannot assign to const reference
    std::cout << "b: " << b << std::endl; // Output: b: 20

    // callAndForward preserves the value type
    int val_c = callAndForward(get_int_val, 30);
    std::cout << "val_c: " << val_c << std::endl; // Output: val_c: 30

    return 0;
}
Example: Using decltype(auto) for perfect forwarding.
