C++20 Concepts: Introduction and Motivation

Addressing SFINAE complexity and improving template error messages.

Problem: SFINAE

Older template constraint techniques (SFINAE) led to complex code and cryptic, lengthy error messages.

Solution: Concepts

Concepts provide a direct, readable way to specify template requirements, resulting in clear error diagnostics.

Key Takeaway

C++20 Concepts simplify generic programming by replacing obscure SFINAE with explicit constraints, making template code more readable and debuggable.

// Old way (implicit SFINAE or explicit std::enable_if)
template <typename T>
T add_old(T a, T b) {
    return a + b; // Fails with cryptic error if T doesn't support +
}

// New way (C++20 Concepts)
#include <concepts>

template <typename T>
concept Addable = requires(T a, T b) {
    { a + b } -> std::same_as<T>;
};

template <Addable T>
T add_new(T a, T b) {
    return a + b; // Fails with clear concept error if T not Addable
}

int main() {
    // add_old("hello", "world"); // Long, confusing error
    // add_new("hello", "world"); // Clear error: 'std::string' does not satisfy 'Addable'
    return 0;
}
