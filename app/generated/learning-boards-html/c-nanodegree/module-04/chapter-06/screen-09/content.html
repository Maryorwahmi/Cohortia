auto for Return Type Deduction

Simplifying function template signatures with automatic type deduction.

Benefit

Reduces verbose type specifications, making generic function signatures cleaner and easier to write.

How it Works

The compiler infers the return type from the expression in the return statement.

Key Takeaway

Use auto as a return type for function templates to let the compiler handle complex type deduction, improving code conciseness.

template <typename T1, typename T2>
auto add(T1 a, T2 b) { // Return type deduced by compiler
    return a + b;
}

template <typename T>
auto get_first_element(const std::vector<T>& vec) {
    return vec[0]; // Return type will be T
}

int main() {
    auto result1 = add(5, 3.14); // result1 is double
    std::cout << "Result 1: " << result1 << std::endl;

    std::vector<std::string> names = {"Alice", "Bob"};
    auto first_name = get_first_element(names); // first_name is std::string
    std::cout << "First name: " << first_name << std::endl;
    return 0;
}
