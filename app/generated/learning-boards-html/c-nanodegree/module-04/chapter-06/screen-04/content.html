Core Concept

Template Best Practices: Structure and Types

Ensuring proper visibility and type handling for generic code.

Key Principle

Templates must be fully defined in header files for successful compilation and linking across translation units.

Common Pitfall

Forgetting typename for dependent types leads to ambiguous parsing errors, as the compiler can't distinguish types from static members.

Key Takeaway

Always define templates in headers and use typename for dependent types to ensure correct compilation and avoid linker errors.

// my_template.hpp
#ifndef MY_TEMPLATE_HPP
#define MY_TEMPLATE_HPP

template <typename T>
class MyContainer {
public:
    // 'typename' is crucial here because T::iterator is a dependent type
    typename T::iterator begin() { return data_.begin(); }
    typename T::iterator end() { return data_.end(); }

private:
    T data_;
};

template <typename U>
void process(U val) {
    // Function template definition also in header
    // ...
}

#endif // MY_TEMPLATE_HPP
