Structured bindings in practice

Use bindings to extract values with clear names and correct reference semantics.

#include <tuple>
#include <map>
#include <string>

std::pair<std::string,int> get_pair() {
  return {"Alice", 101};
}

int main() {
  auto [name, id] = get_pair(); // name is string, id is int

  std::map<std::string,int> m{{"a",1},{"b",2}};
  for (const auto& [k, v] : m) {
    // k is a const reference to key, v is const ref to value
  }
}
Example
Iterating a map with structured bindings is concise and expressive.
Common mistake
Binding to temporary values without capturing by reference can yield dangling references.
Pro tip
Use const auto& for read-only access to avoid copies when iterating large containers.
