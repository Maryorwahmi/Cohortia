Definition

std::optional — a safe container for absence

It either contains a value or it does not. Checking presence is explicit and required for safe access.

  • Check presence with has_value() or if(optional) before accessing.
  • Use value_or to supply a safe default when appropriate.
  • Do not dereference empty optional — undefined behavior.
Example
#include <optional>
#include <string>

std::optional<std::string> findUserById(int id) {
  if (id == 123) return "Alice";
  return std::nullopt;
}

// Usage
if (auto user = findUserById(123)) {
  // safe to access *user
} else {
  // handle absence
}
Key takeaway
Optional forces explicit handling of absence and replaces magic sentinel values.
Common mistake
Dereferencing without checking presence. Always validate first.
