Definition

std::variant

A discriminated union that knows which alternative it currently holds. Use it when the alternatives are a known set.

  • Access via std::get or use std::visit to handle each alternative safely.
  • std::get on wrong type throws std::bad_variant_access; catch or avoid by visiting.
  • Prefer variant to any when types are known in advance for better safety and performance.
Example
#include <variant>
#include <string>
#include <iostream>

std::variant<int,double,std::string> data;

data = 10;
std::cout << std::get<int>(data) << '
';

data = "Hello";
std::visit([](auto&& value){ std::cout << value << '
'; }, data);
Best practice
Prefer std::visit for type-safe, centralized handling of all alternatives.
