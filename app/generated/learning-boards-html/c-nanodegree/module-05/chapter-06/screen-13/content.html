Launching and joining threads

#include <thread>
#include <iostream>

void worker_function(int id) {
  std::cout << "Worker " << id << " starting...
";
  std::this_thread::sleep_for(std::chrono::milliseconds(100 + id * 50));
  std::cout << "Worker " << id << " finished.
";
}

int main() {
  std::vector<std::thread> workers;
  for (int i = 0; i < 3; ++i) workers.emplace_back(worker_function, i);

  // Do other work, then join
  for (auto& &t : workers) {
    if (t.joinable()) t.join();
  }
}
Safety notes
  • Always ensure a thread is joined or detached before its destructor runs.
  • Avoid data races by protecting shared data with mutexes or by message passing.
  • For complex coordination, prefer higher-level abstractions like task queues.
Common mistake
Destroying a joinable std::thread causes std::terminate. Always join or detach.
