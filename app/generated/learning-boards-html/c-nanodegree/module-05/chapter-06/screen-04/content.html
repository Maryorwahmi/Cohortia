Definition

std::pair and std::tuple

Lightweight, type-safe containers for fixed numbers of heterogeneous elements. Pair holds two; tuple holds many.

  • Access pair via first and second; access tuple via std::get or structured bindings.
  • Use std::make_pair and std::make_tuple to construct values concisely.
  • Prefer structured bindings for clarity: they name tuple components.
Concrete example
#include <tuple>
#include <string>

std::tuple<std::string,int,double> person() {
  return std::make_tuple("Bob", 30, 75.5);
}

// Structured binding
auto [name, age, weight] = person();
// name is a string, age is an int
Practical notes

When to avoid tuples

If fields carry meaning, a small struct with named members improves readability and reduces indexing mistakes.

Misconception
Tuples are not records; overuse leads to code that is hard to maintain.
Pro tip
Use structured bindings for immediate, readable names instead of repeated std::get calls.
Check your understanding
Which is clearer: tuple of three ints or a struct with named fields? Prefer the struct.
