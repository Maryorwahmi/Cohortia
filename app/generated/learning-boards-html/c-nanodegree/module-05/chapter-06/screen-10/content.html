Definition

std::any

Type-erased container for a single value of any copy-constructible type, retrieved via any_cast.

  • Useful for heterogeneous property bags and dynamic data.
  • Retrieval involves runtime type checking and potential exceptions.
  • A performance and safety trade-off compared to variant.
Example
#include <any>
#include <string>
#include <iostream>

std::any a = 10;
std::cout << std::any_cast<int>(a) << '
';

a = std::string("Hello Any");
try {
  std::cout << std::any_cast<double>(a) << '
'; // throws
} catch (const std::bad_any_cast& e) {
  std::cerr << "Bad cast: " << e.what() << '
';
}
