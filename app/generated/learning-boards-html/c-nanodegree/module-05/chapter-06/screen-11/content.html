Timing a block of work

#include <chrono>
#include <thread> // for sleep_for in demos
#include <iostream>

using namespace std::chrono;

int main() {
  auto start = high_resolution_clock::now();

  // simulate work
  std::this_thread::sleep_for(milliseconds(150));

  auto end = high_resolution_clock::now();
  duration<double, std::milli> elapsed = end - start;
  std::cout << "Work took " << elapsed.count() << " ms." << '
';
}
Tips
  • Use explicit duration types when printing or comparing.
  • Prefer high_resolution_clock for short measurements, system_clock for wall time.
  • Converting durations with std::chrono::duration_cast prevents unit mistakes.
Key takeaway
Chrono enforces unit clarity and safe time arithmetic; use it instead of manual timestamps and magic conversions.
