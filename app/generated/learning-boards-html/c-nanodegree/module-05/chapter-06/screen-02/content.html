Learning Objectives

Learn, understand, and apply utility components to express intent and avoid common mistakes.

Bloom

Group heterogeneous data
Use std::pair and std::tuple to return related values without extra structs.
Mnemonic: pair = two, tuple = many

02
Represent optional values
Apply std::optional to express absence clearly and force presence checks.
Mnemonic: box that might be empty
VERIFIED COMPETENCY MILESTONE
03
Manage alternative types
Use std::variant for known alternatives and std::any for type-erased storage.
Mnemonic: variant = known set, any = anything
VERIFIED COMPETENCY MILESTONE
04
Measure and run tasks
Use std::chrono for timing and std::thread for basic concurrency patterns with join/detach safety.
Mnemonic: clock it, then thread it
