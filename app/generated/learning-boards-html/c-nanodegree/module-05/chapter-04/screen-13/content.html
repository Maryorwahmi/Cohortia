Readability

Prefer short lambdas at call sites for clarity. If the logic grows, extract to a named functor or function for readability and testability.

Safety

Use explicit captures and prefer value captures for lambdas that may live beyond the creating scope to avoid dangling references.

Performance

When performance matters, prefer concrete callable types or templates. std::function adds convenience at a small runtime cost.

Checklist
  • Is the capture list explicit and minimal?
  • Does the lambda outlive captured variables?
  • Would a named functor improve clarity or reuse?
