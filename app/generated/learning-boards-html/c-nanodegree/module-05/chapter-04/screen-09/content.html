Why use std::function

It lets you accept or store any callable with a matching signature. This is especially useful for callbacks or plugin-style extension points.

#include <functional>
int add(int a, int b) { return a + b; }

std::function<int(int,int)> op1 = add;            // function
std::function<int(int,int)> op2 = Subtract();    // functor
std::function<int(int,int)> op3 = [](int a,int b){ return a*b; }; // lambda
Trade-offs
  • Convenience and uniformity vs small runtime cost and possible allocation.
  • Prefer std::function for API-level flexibility; prefer templates for hot loops when type is known.
Key Takeaway

std::function trades compile-time type knowledge for runtime flexibility, ideal for callbacks and polymorphic storage.
