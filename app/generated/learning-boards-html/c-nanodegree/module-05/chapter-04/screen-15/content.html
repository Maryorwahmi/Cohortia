Module 05 › Chapter 5.4 › Key Concepts
Mutable Lambda
Allows modification of captured-by-value copies inside the closure; outer variables remain unchanged.
std::function
Uniformly store callables that match a signature; useful for callbacks and C++ style polymorphism.
Dangling Reference
Occurs when a lambda references a variable that has gone out of scope; leads to undefined behavior.
Final Takeaway
Be explicit about ownership and lifetime when writing callables. That habit prevents a class of runtime errors and makes your code easier to reason about.
