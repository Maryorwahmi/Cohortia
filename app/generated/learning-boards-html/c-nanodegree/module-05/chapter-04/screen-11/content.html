Danger Example
std::function<void()> create_lambda() {
  int x = 10;
  return [&]() { std::cout << x << std::endl; }; // captures x by reference
}

int main() {
  auto bad_lambda = create_lambda();
  // calling bad_lambda here would access a dangling reference
}
Safer Alternatives
  • Capture by value to make the lambda own a copy.
  • Ensure referenced objects outlive stored callables.
  • Prefer explicit captures to make ownership clear.
Common Bug

Storing a lambda that references locals is a frequent source of subtle crashes and non-deterministic behavior.
