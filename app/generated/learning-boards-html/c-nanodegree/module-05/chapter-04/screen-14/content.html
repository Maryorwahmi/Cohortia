Module 05 › Chapter 5.4 › Key Concepts
Function Object
An object with operator parentheses that can hold state and be invoked like a function.
Lambda Expression
An inline anonymous function object with a capture list for accessing surrounding variables.
Capture List
Specifies how a lambda accesses external variables: by value, by reference, or implicitly.
Takeaway
Keep capture choices explicit and match them to the callable's lifetime to avoid subtle bugs.
