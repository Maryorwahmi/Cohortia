Transform with Lambda
int factor = 5;
std::transform(numbers.begin(), numbers.end(), out.begin(), [factor](int n){
  return n * factor;
});
Value capture is appropriate here because the lambda is used immediately and a copy of factor is cheap.
Sort and For_each
// Sort by string length
std::sort(words.begin(), words.end(), [](const std::string& a, const std::string& b){
  return a.length() < b.length();
});

// Print formatted output
std::for_each(students.begin(), students.end(), [](const Student& s){
  std::cout << "Student ID: " << s.id << ", Name: " << s.name << std::endl;
});
Key Takeaway

Compose small lambdas with algorithms to express transformations and side effects succinctly, but always confirm capture safety.
