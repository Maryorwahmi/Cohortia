Walkthrough: PrintWithIndex

Create the object, then pass it to std::for_each. The object's state persists across each call from the algorithm until the call completes.

#include <iostream>
#include <vector>
#include <algorithm>

std::vector<int> numbers = {1,2,3,4,5};
std::for_each(numbers.begin(), numbers.end(), PrintWithIndex());
Example output shows the index increasing for each element. The counter lives in the functor, not globally.
Walkthrough: Multiplier + std::transform

Construct a Multiplier with a factor and pass it to transform to produce a multiplied sequence. The functor's factor is configured once at construction.

std::vector<int> input = {1,2,3,4,5};
std::vector<int> output(input.size());
Multiplier multiplyBy5(5);
std::transform(input.begin(), input.end(), output.begin(), multiplyBy5);
// output now holds 5,10,15,20,25
Key Takeaway

Functor construction separates setup from repeated invocation, making code explicit and testable.

Pro Tip

If the operation is used only once in place, prefer a lambda for brevity; if reused, prefer a functor.
