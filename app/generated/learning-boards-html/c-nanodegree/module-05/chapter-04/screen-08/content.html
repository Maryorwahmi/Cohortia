When to use mutable

Use mutable when the lambda should keep and update its own internal copy between invocations while leaving the original variable unchanged.

int counter = 0;
auto incrementer = [counter]() mutable {
  counter++; // modifies the captured copy inside the closure
  std::cout << "Counter: " << counter << std::endl;
};

incrementer(); // prints 1
incrementer(); // prints 2
// original 'counter' remains 0
Notes & Pitfalls
  • Mutable affects the closure's copy, not the outer variable.
  • Prefer explicit intent: use mutable only when you mean to own the copy.
Pro Tip

If you need shared mutation, capture by reference and document the reason clearly.
