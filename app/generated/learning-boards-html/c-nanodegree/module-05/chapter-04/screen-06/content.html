Lambda Anatomy
Capture List
Controls which external variables the lambda can access and whether by value or by reference.
Parameters & Return
Parameters are regular; return type is optional and often deduced by the compiler.
Readability tip

Prefer explicit captures like [factor] or [&index] to make dependencies clear at a glance.

Code Examples
// Capture factor by value
int factor = 5;
std::transform(nums.begin(), nums.end(), out.begin(), [factor](int n){ return n * factor; });

// Capture index by reference to modify it
int index_counter = 0;
std::for_each(nums.begin(), nums.end(), [&](int n){
  std::cout << "Element at index " << index_counter++ << ": " << n << std::endl;
});
Common Mistake

Avoid over-capturing with [=] or [&] unless you know exactly which variables will be used and their lifetimes.
