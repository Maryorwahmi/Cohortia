Working with std::vector

Basic Operations and Bounds Checking

#include <vector>
#include <iostream>

int main() {
    std::vector<int> numbers; // Empty vector
    std::cout << "Initial size: " << numbers.size() << ", capacity: " << numbers.capacity() << std::endl;

    numbers.push_back(10); // Add elements
    numbers.push_back(20);
    numbers.push_back(30);
    std::cout << "After 3 push_backs: size: " << numbers.size() << ", capacity: " << numbers.capacity() << std::endl;

    numbers.reserve(10); // Reserve space
    std::cout << "After reserve(10): size: " << numbers.size() << ", capacity: " << numbers.capacity() << std::endl;

    numbers.pop_back(); // Remove last element
    std::cout << "After pop_back: size: " << numbers.size() << ", capacity: " << numbers.capacity() << std::endl;

    // Access elements
    std::cout << "First element: " << numbers[0] << std::endl;
    try {
        std::cout << "Element at index 5 (safe access): " << numbers.at(5) << std::endl;
    } catch (const std::out_of_range& e) {
        std::cerr << "Error: " << e.what() << std::endl;
    }

    // Iterate through vector
    for (int n : numbers) {
        std::cout << n << " ";
    }
    std::cout << std::endl;

    return 0;
}

Key Operations Illustrated

  • Initialization: Create an empty std::vector.
  • Adding Elements: Use push_back() to append to the end.
  • Capacity Management: Observe size() and capacity(), and use reserve() to pre-allocate.
  • Removing Elements: pop_back() removes the last element.
  • Access: Direct [] access (no bounds check) vs. safe at() access (throws exception).
  • Iteration: Use range-based for loops for simple traversal.
Safety Note

Always be cautious with myVector[index] as it doesn't perform bounds checking. For robust applications, especially when user input determines the index, prefer myVector.at(index) to catch out-of-range errors.

Key Takeaway

std::vector provides dynamic array functionality with efficient operations, but requires careful attention to bounds checking for safe element access.
