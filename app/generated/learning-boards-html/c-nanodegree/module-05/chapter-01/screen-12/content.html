Implementing with std::deque

Demonstrating Front and Back Manipulations

#include <deque>
#include <iostream>

int main() {
    std::deque<char> charBuffer;

    charBuffer.push_back('A');
    charBuffer.push_back('B');
    charBuffer.push_front('X'); // Insert at front
    charBuffer.push_front('Y'); // Insert at front

    std::cout << "Deque elements: ";
    for (char c : charBuffer) {
        std::cout << c << " ";
    }
    std::cout << std::endl; // Output: Y X A B

    std::cout << "Front element: " << charBuffer.front() << std::endl; // Y
    std::cout << "Back element: " << charBuffer.back() << std::endl;   // B

    charBuffer.pop_front(); // Remove Y
    charBuffer.pop_back();  // Remove B

    std::cout << "Deque after pop_front and pop_back: ";
    for (char c : charBuffer) {
        std::cout << c << " ";
    }
    std::cout << std::endl; // Output: X A

    return 0;
}

`std::deque` Operations

  • push_back(): Adds an element to the end.
  • push_front(): Adds an element to the beginning (efficiently).
  • front(): Accesses the first element.
  • back(): Accesses the last element.
  • pop_front(): Removes the first element (efficiently).
  • pop_back(): Removes the last element.
Scenario Example

Imagine a system logging sensor readings. New readings arrive at the back, and old readings are processed and removed from the front. A std::deque is perfectly suited for this, maintaining a dynamic buffer with efficient updates at both ends.

Key Takeaway

std::deque's ability to efficiently add and remove elements from both ends makes it invaluable for implementing dynamic queues and buffers where bidirectional growth and shrinkage are common.
