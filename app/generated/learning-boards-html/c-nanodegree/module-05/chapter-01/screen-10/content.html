Using std::array Effectively

Initialization, Access, and Fixed-Size Constraints

#include <array>
#include <iostream>

int main() {
    std::array<int, 5> data = {1, 2, 3, 4, 5}; // Fixed size of 5 integers
    std::cout << "Array size: " << data.size() << std::endl;

    // Access elements
    std::cout << "Element at index 2: " << data[2] << std::endl; // Output: 3
    data.at(0) = 100; // Safe modification
    std::cout << "Modified element at index 0: " << data.front() << std::endl;

    // Iterate
    for (int x : data) {
        std::cout << x << " ";
    }
    std::cout << std::endl;

    // Common mistake: Trying to add elements beyond fixed size
    // data.push_back(6); // This would be a compile-time error!

    return 0;
}

Key Aspects of `std::array`

  • Compile-Time Size: The size is part of its type, fixed at compilation.
  • Direct Initialization: Can be initialized with an initializer list.
  • No Dynamic Operations: Lacks methods like push_back() or pop_back().
  • Bounds Checking: Supports both [] (no check) and at() (safe, throws exception).
  • Iteration: Fully compatible with range-based for loops.
Use Case Example

Consider a program that needs to store the scores of exactly 5 players in a fixed-size leaderboard. std::array<int, 5> scores; would be perfect here, as the number of players is constant and known upfront.

Key Takeaway

std::array is a powerful choice when data size is fixed, offering C++ container benefits with the efficiency and predictability of stack-allocated memory.
