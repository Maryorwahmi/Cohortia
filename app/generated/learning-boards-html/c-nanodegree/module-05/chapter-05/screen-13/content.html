Starter checklist
  1. Implement Document with constructor/destructor messages and a print method.
  2. Create unique_ptr via make_unique, move ownership, and observe destruction.
  3. Create shared_ptr via make_shared, copy into a vector, and print use_count at steps.
  4. Optional: build a pair of classes with a shared_ptr/weak_ptr relationship to break a cycle.

Observation tips
  • Watch standard output for create/destroy messages to confirm lifetime.
  • Use use_count to inspect shared ownership during testing but not for logic.
  • Replace suspected cycles with weak_ptr and observe destruction to validate fixes.
Key Takeaway

Small experiments that print lifecycle events are the fastest way to understand ownership semantics and verify correct use of smart pointers.
