Module 5 › Chapter 5.5 › Learning Objectives — Part 2

Practical safety

Use factory helpers to make allocation atomic with construction. Observe object lifetimes with print statements to confirm cleanup.

Factory helpers
make_unique and make_shared reduce exception-related leaks and may optimize allocations.
Custom deleters
Provide cleanup logic for non-delete resources, extending RAII beyond memory.

Hands-on

Document manager exercise walks through unique_ptr moves, shared_ptr copies and use_count observations, and an optional weak_ptr back-reference pattern to prevent cycles.
Activity
Implement the starter code, run it, and watch the creation and destruction messages to confirm ownership behavior.
