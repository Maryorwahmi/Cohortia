Module 5 › Chapter 5.5 › Quick Reference
Use unique_ptr
Single owner; move-only; prefer make_unique.
Use shared_ptr
Multiple owners; reference counting; prefer make_shared.
Use weak_ptr
Non-owning observer; break cycles; use lock() to obtain shared_ptr.
Final takeaway

Choose the least permissive ownership model needed, use make_* helpers, and replace cycles with weak_ptr to keep resource lifetimes predictable and safe.
