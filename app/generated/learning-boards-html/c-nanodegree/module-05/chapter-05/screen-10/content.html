Module 5 › Chapter 5.5 › Document Manager — unique_ptr
Starter code snippet
#include <memory>
#include <iostream>

std::unique_ptr<Document> doc1 = std::make_unique<Document>("Report Q1","Sales figures are up.");
doc1->print();

std::unique_ptr<Document> doc2 = std::move(doc1); // ownership moved
if (!doc1) std::cout << "doc1 is now empty." << std::endl;
Run this to see constructor and destructor messages. The destructor runs when doc2 leaves scope, confirming unique ownership.
Checklist
  • Create with make_unique.
  • Transfer with std::move explicitly.
  • After move, do not dereference the source without checking for null.
Key Takeaway

unique_ptr models exclusive ownership. Use moves to transfer ownership and validate lifetime by observing constructor/destructor output during testing.
