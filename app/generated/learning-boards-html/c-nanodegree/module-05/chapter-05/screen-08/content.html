Module 5 › Chapter 5.5 › make_unique vs make_shared
make_unique

Used to create std::unique_ptr safely and efficiently. It prevents leaks if construction throws.

auto u = std::make_unique<Document>("Title","Content");
Best when ownership is exclusive.
make_shared

Creates std::shared_ptr and its control block efficiently, often in a single allocation.

auto s = std::make_shared<Document>("Meeting","Notes");
std::cout << s.use_count() << std::endl; // typically 1
Best when objects are shared across multiple owners.
Key Takeaway

Use factory helpers to get exception-safe allocation and construction. Choose make_unique for unique ownership and make_shared when you need shared ownership and allocation efficiency.
