Module 5 › Chapter 5.5 › Moving unique_ptr
Step-by-step ownership transfer
1. Create with make_unique
std::unique_ptr<T> p = std::make_unique<T>(args);
2. Move to another owner
std::unique_ptr<T> q = std::move(p); // p becomes empty
3. Pass into functions
void process(std::unique_ptr<T> in) { /* owns it */ }
Concrete code snippet
#include <memory>
void process(std::unique_ptr<MyResource> r) {
  if (r) r->operation();
} 

std::unique_ptr<MyResource> a = std::make_unique<MyResource>(1);
process(std::move(a)); // ownership moved; 'a' is now empty
Common pitfall

Do not use the moved-from pointer without checking; it may be null and using it causes runtime errors.
