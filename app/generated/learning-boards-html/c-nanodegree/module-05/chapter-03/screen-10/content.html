Module 5 › Chapter 5.3 › std::sort Requirements
Why random access is needed
Sorting algorithms commonly choose pivot positions and swap elements that may be far apart. Random access lets the algorithm reach those positions in constant time.
#include <vector>
#include <algorithm>

std::vector<int> data = {5,2,8,1,9};
std::sort(data.begin(), data.end()); // OK: vector has random access iterators

// std::list<int> l = {...};
// std::sort(l.begin(), l.end()); // compile-time error: iterators not random access
Alternatives
Use list::sort for linked lists or copy to a vector, sort, then copy back if copying cost is acceptable.
Key Takeaway
Match algorithm requirements to iterator capabilities or choose container-specific member algorithms where available.
