Module 5 › Chapter 5.3 › Bidirectional & Random Access
Bidirectional
Supports operator-- to move backward. Ideal for containers where insertion and removal in the middle are common, and where you need to iterate both directions.
Random Access
Supports arithmetic, indexing, and constant-time distance. Required by algorithms that jump or index elements freely.
Example
std::vector provides random access. std::list provides bidirectional only.
Performance implications
  • std::distance is O(1) for random access, O(n) for bidirectional.
  • Algorithms that repeatedly compute distances perform poorly on non-random access iterators.
Misconception
Assuming all containers have cheap indexing leads to hidden O(n^2) behavior.
