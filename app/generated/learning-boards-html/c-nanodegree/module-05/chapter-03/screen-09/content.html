Module 5 › Chapter 5.3 › for_each & find
Code Walkthrough
#include <vector>
#include <algorithm>
#include <iostream>

int main() {
  std::vector<int> numbers = {10, 20, 30, 40, 50};

  // print doubled values using a lambda
  std::for_each(numbers.begin(), numbers.end(), [](int n){
    std::cout << (n * 2) << ' ';
  });
  std::cout << std::endl;

  // find a value
  auto it = std::find(numbers.begin(), numbers.end(), 30);
  if (it != numbers.end()) {
    // compute index only when efficient (random access)
    std::cout << "Found at index: " << std::distance(numbers.begin(), it) << std::endl;
  }
}
Explanation
  • for_each applies a callable to every element in [begin, end).
  • find returns an iterator; compare it with end() to detect success.
  • Use std::distance for an index when iterators support efficient distance computation.
