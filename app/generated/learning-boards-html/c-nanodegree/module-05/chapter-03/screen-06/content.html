Module 5 › Chapter 5.3 › Input vs Output vs Forward
Feature matrix
Input
Single-pass read only. Use for stream-like sources. Does not support repeated traversal.
Output
Single-pass write only. Used to fill an output range.
Forward
Multi-pass read/write forward-only. Stable for repeated traversals.
Example
Reading a file uses input iterators; writing to an output stream uses output iterators; iterating a container multiple times requires forward iterators.
Practical checks
Before relying on repeated traversal or saving iterators for later use, confirm the iterator category. If your algorithm needs to revisit elements, do not use input iterators.
Misuse to avoid
Attempting to read twice from an input iterator or dereferencing an output iterator are common mistakes that lead to logic errors or undefined behavior.
Pro tip
Use the weakest iterator category that satisfies your needs to make container implementations and algorithms as flexible as possible.
