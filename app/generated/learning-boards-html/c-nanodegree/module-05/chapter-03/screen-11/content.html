Transform then remove_if (chapter example)
#include <vector>
#include <algorithm>
#include <iostream>

std::vector<int> original = {1,2,3,4,5};
std::vector<int> temp(original.size());

std::transform(original.begin(), original.end(), temp.begin(), [](int r){
  return (r % 2 == 0) ? (r * r) : r; // square evens, keep odds
});

auto new_end = std::remove_if(temp.begin(), temp.end(), [](int r){ return (r % 2 != 0); });
temp.erase(new_end, temp.end()); // now temp contains only squared evens
Alternative: copy_if then transform
Filter first, then transform. This avoids remove/erase and is often clearer.
Key Takeaway
Compose copy_if and transform for a clear filter-then-map pipeline. Use remove-erase idiom carefully when using transform first.
