Iterator invalidation example
#include <vector>
#include <iostream>

int main() {
  std::vector<int> numbers = {1,2,3,4,5};
  auto it = numbers.begin();
  numbers.push_back(6); // may reallocate
  std::cout << *it << std::endl; // undefined if reallocation occurred
}
If push_back causes reallocation, iterators obtained before the call become invalid. Dereferencing them may crash or give garbage.
Guidelines
  • Check container-specific invalidation rules before saving iterators.
  • Prefer re-acquiring iterators after modifying the container.
  • Use reserve() on vectors to avoid reallocation when you know size in advance.
Key Takeaway
Treat iterator validity as an explicit precondition: modifying the container can break saved iterators.
