Module 5 › Chapter 5.3 › Key Concepts
Iterator
An object that generalizes pointers to traverse and access elements.
Iterator Categories
Input, Output, Forward, Bidirectional, Random Access — each adds capabilities.
Range
A half-open sequence [begin, end) used by STL algorithms.
Algorithms
Generic functions like for_each, find, sort, transform operate on iterator ranges.
Invalidation
Container modifications can invalidate iterators; consult container rules.
std::sort requirement
Requires Random Access Iterators due to arbitrary jumps and indexing.
Final takeaway

Match algorithm requirements to iterator capabilities, use half-open ranges, and guard against invalidation to write safe, generic STL code.
