Module 5 › Chapter 5.3 › Iterator Categories
Category Hierarchy
Input Iterator
Single-pass read; like reading from a stream; supports operator*, operator++ and comparison.
Output Iterator
Single-pass write; used for writing into an output range.
Forward Iterator
Multi-pass read/write moving forward; stable for repeated traversals.
Bidirectional Iterator
All Forward operations plus operator-- to move backward.
Random Access Iterator
All Bidirectional operations plus arithmetic, indexing, and constant-time distance.
Container examples
Random Access
std::vector, std::deque
Bidirectional
std::list, std::map
Practical note
If an algorithm needs to jump or index, it requires random access iterators. A compile-time error usually signals a mismatch.
Key Takeaway

Match algorithm requirements to iterator capabilities to ensure correctness and performance.
