Module 5 › Chapter 5.3 › What is an Iterator?
Definition
An iterator abstracts element access and traversal operations. It may support reading, writing, single-pass or multi-pass traversal, and movement operations.
Why this matters
  • Algorithms written for iterators work across container types.
  • Function signatures that take iterator pairs become highly reusable.
  • Knowing capabilities prevents misuse: not every iterator supports random access.
Common misconception
An iterator is not always equivalent to a pointer. Only random access iterators match pointer-like indexing.
Key Takeaway

Design algorithms against iterator interfaces to keep code generic and maintainable.

Concrete Example
Using std::for_each with a vector and a list uses the same algorithm call because both provide begin and end iterators.
// Example: same algorithm call works for many containers
#include <vector>
#include <list>
#include <algorithm>
#include <iostream>

void print(int n) { std::cout << n << ' '; }

// vector and list both provide begin/end iterators
// so std::for_each can be used for both.
