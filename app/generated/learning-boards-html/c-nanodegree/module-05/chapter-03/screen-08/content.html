Half-open ranges
Use [begin, end) so algorithms compose and loops terminate cleanly without off-by-one errors.
#include <vector>
#include <algorithm>
#include <iostream>

std::vector<int> v = {1,2,3};
for (auto it = v.begin(); it != v.end(); ++it) {
  std::cout << *it << ' ';
}
Safety note
Never dereference end(); it is the sentinel one past the last element and has no value to read.
Subrange examples
To pass a subrange to an algorithm, supply two iterators where the second points after the subrange's last element.
Key Takeaway

Half-open ranges are a simple convention that prevents off-by-one mistakes and composes across algorithms.
