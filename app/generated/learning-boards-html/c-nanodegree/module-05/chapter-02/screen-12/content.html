Safe insertion patterns
Choose insertion APIs based on whether you want creation, overwrite, or detection of duplicates.
operator[]
Creates or overwrites values. Use when you explicitly want to initialize or update an entry.
insert / emplace
Return success flags so you can detect duplicates and avoid accidental changes.
Key Takeaway

Be explicit about creation. Use insert/emplace for safe adds and operator[] for intentional initialization or updates.

Example patterns
  • Check presence: if (m.count(key)) { /* exists */ } else { m.insert({key, val}); }
  • Attempt add: auto [it, ok] = m.insert({key, val}); if (!ok) { /* key existed */ }
  • Create or update explicitly: m[key] = newVal; // intentional overwrite
Common mistake
Using operator[] inside a conditional that intended only to check presence will create a new element unexpectedly.
