Definition
std::map
Unique key-value pairs kept sorted by key; implemented as a balanced tree with O(log N) operations.
Insert safely
Prefer insert/emplace when you want to detect duplicates. operator[] will create or overwrite.
Iteration
Iterating yields keys in sorted order, which is useful for reports and deterministic output.
Key Takeaway

Use std::map when order and predictable O(log N) behavior are required; insert to detect duplicates.

Code Example
Student scores stored in a map are printed in alphabetical order.
<#include > <map>
#include <string>
#include <iostream>

int main() {
  std::map<std::string, int> student_scores;
  student_scores["Alice"] = 95;    // creates or overwrites
  student_scores.insert({"Bob", 88}); // insert returns a pair indicating success

  // Iterate in sorted key order
  for (const auto &p : student_scores) {
    std::cout << p.first << ": " << p.second << std::endl;
  }
  return 0;
}
Note: the example uses insert to detect existing keys. If insert fails, the existing value remains unchanged.
