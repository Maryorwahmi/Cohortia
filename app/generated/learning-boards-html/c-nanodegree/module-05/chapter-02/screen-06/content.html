Core Concept
std::set
A sorted collection of unique values for membership and ordered traversal.
Unique items
Duplicates are ignored on insert, simplifying deduplication.
When to prefer
Choose set when you need sorted distinct elements and deterministic iteration order.
Example
Insert words into a set to get a sorted list of unique words for a report, or to efficiently check presence with O(log N) guarantees.
Code Example
#include <set>
#include <string>
#include <iostream>

int main() {
  std::set<std::string> unique_words;
  unique_words.insert("apple");
  unique_words.insert("banana");
  unique_words.insert("apple"); // duplicate, ignored

  for (const auto &w : unique_words) {
    std::cout << w << " ";
  }
  std::cout << std::endl;
  return 0;
}
Output is sorted alphabetically. If you only care about presence and need speed, compare with unordered_set.
