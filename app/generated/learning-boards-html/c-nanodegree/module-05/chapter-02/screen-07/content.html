Definition
std::unordered_map
Key-value pairs stored by hash, offering fast average-case lookups for cache-like use cases.
Average O(1)
Excellent for frequent queries; worst-case can be O(N) if collisions are extreme.
Hash quality matters
Default hashes work for built-in types; custom types need std::hash and operator== to avoid collisions and slowdown.
Key Takeaway

Use unordered_map for fastest average lookups when order is irrelevant; ensure good hash behavior for custom keys.

Code Example
#include <unordered_map>
#include <string>
#include <iostream>

int main() {
  std::unordered_map<std::string, double> item_prices;
  item_prices["Milk"] = 2.99;
  item_prices["Bread"] = 3.50;

  std::cout << "Price of Bread: $" << item_prices["Bread"] << std::endl;
  return 0;
}
Iteration order is not guaranteed. Use when you need fast lookups and can accept arbitrary iteration order.
