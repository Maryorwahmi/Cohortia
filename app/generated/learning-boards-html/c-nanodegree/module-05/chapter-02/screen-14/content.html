Key Concepts
Three compact reminders from this chapter.
Associative Containers
Containers designed for key-based lookup rather than index-based access.
Ordered vs Unordered
Ordered: map/set with O(log N). Unordered: unordered_map/set with average O(1) but no ordering guarantee.
Key Requirements
Ordered keys need comparators; unordered keys need hash and equality. Use the correct interface for custom types.
Summary Takeaway

Match container choice to your needs: sorted iteration and predictable bounds versus fastest average lookup and memory trade-offs.
