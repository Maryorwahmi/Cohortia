Core Concept
std::unordered_set
Fast membership checks for unique elements with average O(1) performance.
Use cases
Blacklists, fast membership queries, and deduplication when order doesn't matter.
Watchouts
Iteration is unordered. Provide a good hash and operator== for custom types to avoid collisions and correctness issues.
Key Takeaway

Use unordered_set for membership performance when you do not require sorted output; ensure proper hashing for custom keys.

Code Example
#include <unordered_set>
#include <string>
#include <iostream>

int main() {
  std::unordered_set<std::string> banned_usernames;
  banned_usernames.insert("admin");
  banned_usernames.insert("root");

  std::string user_input = "root";
  if (banned_usernames.count(user_input)) {
    std::cout << "'" << user_input << "' is a banned username." << std::endl;
  }
  return 0;
}
The set ignores duplicate inserts and checks membership quickly; iteration order is arbitrary.
