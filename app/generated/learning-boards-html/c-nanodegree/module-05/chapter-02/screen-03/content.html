Practical Skills & Misconceptions
Common mistakes and patterns you will practice in lab exercises.
Safe Insertion
Use insert/emplace to check if a key was added. operator[] will create or overwrite — use it intentionally.
Custom Types
Ordered containers need operator< or comparator; unordered containers need std::hash specialization and operator== for custom keys.
Choose by Use
Pick map/set for sorted iteration and predictable O(log N); pick unordered_map/set for fastest average lookup when order is irrelevant.
