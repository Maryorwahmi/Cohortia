Associative Containers
Understand tree-based ordered containers and hash-based unordered containers, and learn when to prefer one over the other.
Interactive 16:9 Masterclass
Focus: Performance & Correctness
Key idea
Ordered containers keep elements sorted and predictable; unordered containers prefer fast average lookup using hashing.
Why this matters
Choosing the wrong container can cost you performance or correctness, for example accidental reordering or slow lookups under heavy collision.
Explore Key Topics
Ordered
std::map and std::set keep data sorted and give O(log N) operations, useful when order matters.
Unordered
std::unordered_map and unordered_set use hashing for average O(1) performance; order is not guaranteed.
Practical
Real code examples: word counters, thesauruses, and tracking unique items demonstrate trade-offs.
