Practice tasks
Concrete exercises that verify mastery
Task
Refactor BankAccount
Make accountNumber and balance private, add const getters, and validate setters.
Practice
Use this explicitly
Call this->balance in deposit and withdraw to practice disambiguation and readability.
Design check
Friend vs getter
Decide whether a friend is necessary, or if a public accessor preserves encapsulation better.
Pro tip

When in doubt, prefer a small public interface with validation over exposing raw members. It prevents accidental invalid states.

Common mistake

Making everything public for convenience. That convenience often costs long-term maintainability.
