Disambiguation example
// Point example using this
class Point {
private:
  int x, y;
public:
  Point(int x, int y) : x(x), y(y) {} // initializer list uses implicit names

  void setCoordinates(int x, int y) {
    this->x = x; // explicit this to avoid ambiguity
    this->y = y;
  }

  Point& moveBy(int dx, int dy) {
    x += dx;
    y += dy;
    return *this; // return reference to current object
  }
};
Notes
  • this is implicit; write it only when needed to clarify or return the object.
  • Returning *this permits method chaining; ensure you return by reference when appropriate.
  • In const methods, this has type pointer to const, preventing modification.
Practice: deliberately use this->member in two methods to get comfortable with the syntax and to show intent.
