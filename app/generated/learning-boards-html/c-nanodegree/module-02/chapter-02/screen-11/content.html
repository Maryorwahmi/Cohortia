Module 2 › Chapter 2.2 › Design Checklist
1. Define responsibilities
Only expose operations clients actually need.
2. Hide representation
Make fields private so you can change them later without breaking users.
3. Validate mutations
Setters should enforce invariants rather than trusting callers.
4. Mark read-only methods const
This enables safe use of const objects and compiler checks.
Test guidance
Write unit tests that try invalid inputs and attempts to mutate state through public interfaces. Tests reveal gaps in your encapsulation decisions.
