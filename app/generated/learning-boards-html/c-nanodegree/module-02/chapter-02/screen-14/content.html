Quick Reference
Three concise rules to apply immediately.
Minimize visibility
Make fields private; expose only what clients need.
Mark reads const
Declare getters const so const objects can still be useful.
Use friend sparingly
Reserve it for specific non-member operations that need private access.
Closing takeaway

Small, consistent encapsulation choices yield more maintainable and safer code. Apply them one class at a time.
