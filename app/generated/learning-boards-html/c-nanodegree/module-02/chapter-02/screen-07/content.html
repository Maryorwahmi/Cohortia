Student class code
// Student grade example
class Student {
private:
  int grade; // stored privately

public:
  Student(int initGrade) : grade(initGrade) {}

  // Const getter
  int getGrade() const {
    return grade;
  }

  // Setter with validation
  void setGrade(int newGrade) {
    if (newGrade >= 0 && newGrade <= 100) {
      grade = newGrade;
      std::cout << "Grade updated" << std::endl;
    } else {
      std::cout << "Error: grade must be between 0 and 100." << std::endl;
    }
  }
};
Walkthrough
  • The grade field is private and cannot be written from outside.
  • getGrade is const, so it can be called on const Student objects.
  • setGrade enforces the 0–100 invariant, preventing invalid assignments.
Analogy: think of grade as a sealed gauge; only the setter updates it through a safe doorway that checks inputs.
