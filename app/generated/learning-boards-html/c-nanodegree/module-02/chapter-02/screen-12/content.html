Starter code excerpt
// Key parts to implement
class BankAccount {
private:
  std::string accountNumber;
  double balance;

public:
  BankAccount(std::string accNum, double initialBalance) {
    this->accountNumber = accNum;
    this->balance = initialBalance;
  }

  std::string getAccountNumber() const { return this->accountNumber; }
  double getBalance() const { return this->balance; }

  void setBalance(double newBalance) {
    // Implement validation: reject negative balances
  }

  void deposit(double amount) {
    if (amount > 0) { this->balance += amount; }
  }

  void withdraw(double amount) {
    if (amount > 0 && this->balance >= amount) { this->balance -= amount; }
  }
};
Guided checklist
  1. Make accountNumber and balance private.
  2. Implement getAccountNumber and getBalance as const methods.
  3. Implement setBalance to reject negative values and print or return an error.
  4. Use this->balance in deposit and withdraw to practice explicit member reference.
  5. Create a const BankAccount in main and verify only const methods are callable.
Testing tip: write a unit that attempts to set a negative balance and asserts the operation failed so you know the setter protects invariants.
