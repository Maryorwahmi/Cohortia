Core Concept

Object Slicing

Copying derived objects into base values discards derived-specific data and behavior.

Bad pattern
Animal a = Dog("Buddy"); // Slicing: Dog parts lost
a.makeSound(); // may not call Dog behavior
Good pattern

Use pointers or references to preserve the actual object and enable virtual dispatch: Animal* a = new Dog("Buddy");

Misconception: virtual functions prevent slicing — they do not; slicing happens at the value level before any virtual dispatch can occur.
Key Takeaway

Avoid copying polymorphic objects by value. Use pointers or references to preserve derived data and behavior.
