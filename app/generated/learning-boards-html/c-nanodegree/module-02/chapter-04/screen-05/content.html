Definition

Base Pointers and References

They hold derived objects behind a common interface; do not expose derived-only members.

Example snippet
Vehicle* myVehicle = new Car("Blue", 80.0, 4);
myVehicle->accelerate(10.0);
myVehicle->displayInfo();
delete myVehicle;
Note: displayInfo must be virtual to call Car's override; destructor must be virtual to free derived resources.
Design tip: Keep the base interface focused on operations all derived types share.
Quick facts
  • Pointers/references preserve polymorphic behavior; values do not.
  • Base type restricts accessible members to those declared on base.
  • Use override on derived methods to ensure they match signatures.
Misconception

A base pointer does not give access to derived-only methods; call those through a derived pointer or add virtual hooks in the base.

Key Takeaway

Use pointers or references for polymorphism; never copy into a base object if you want derived behavior preserved.
