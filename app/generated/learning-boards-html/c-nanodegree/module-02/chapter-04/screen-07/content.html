How Virtual Functions Work

Follow this minimal process to enable runtime dispatch.

1
Identify the varying operation
Choose the method that derived types must customize (for example displayInfo or processPayment).
2
Declare it virtual in the base
Add the virtual keyword so calls can be resolved at runtime.
3
Override in derived classes
Implement the specific behavior and add the override specifier for safety.
4
Call via base pointer/reference
Use Vehicle* or Shape& so the correct derived override runs at runtime.
Misconception

override is not what makes a function virtual; it only instructs the compiler to check you intended to override a virtual base method.

Key Takeaway

Virtual + override + base pointer/reference = reliable runtime dispatch and clearer intent when maintaining code.
