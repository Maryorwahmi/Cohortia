PaymentMethod Example

Read the implementation and observe how virtuals and destructors behave at runtime.

#include <iostream>
#include <string>
#include <vector>

class PaymentMethod {
protected:
  double amount;
public:
  PaymentMethod(double amt) : amount(amt) {
    std::cout << "PaymentMethod constructor called for amount: " << amount << std::endl;
  }
  virtual bool processPayment() = 0;
  virtual void displayPaymentDetails() const = 0;
  virtual ~PaymentMethod() {
    std::cout << "PaymentMethod destructor called." << std::endl;
  }
};

Runtime behavior checklist
  • Derived displayPaymentDetails runs when called through PaymentMethod*.
  • processPayment returns true for both CreditCard and PayPal implementations.
  • Deleting via base pointer triggers derived destructor then base destructor.
Check your change: modify a derived signature slightly; the compiler will catch it if you used override. If not, you may silently get static binding.
