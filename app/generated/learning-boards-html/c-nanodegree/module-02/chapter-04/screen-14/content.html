Polymorphism in Collections and Iteration

Keep collections heterogeneous but interface-consistent using pointers or smart pointers.

Example pattern
std::vector<PaymentMethod*> payments;
payments.push_back(new CreditCard(...));
payments.push_back(new PayPal(...));
for (auto pm : payments) {
  pm->displayPaymentDetails();
  pm->processPayment();
}
for (auto pm : payments) delete pm;
Modern alternative

Use std::vector<std::unique_ptr<PaymentMethod>> so ownership is clear and cleanup is automatic even on exceptions.

Pro tip: If you need polymorphic copies, add a virtual clone() method to the base that returns a unique_ptr to a newly copied derived object.
Key Takeaway

Use pointers or smart pointers in collections, avoid slicing, and express ownership clearly to keep polymorphic containers safe and maintainable.
