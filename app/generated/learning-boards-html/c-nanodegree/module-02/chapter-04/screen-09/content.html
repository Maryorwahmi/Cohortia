Definition

Pure Virtual Functions and Abstract Classes

Declare interface methods without implementation to require derived classes to provide behavior.

Example
class Shape {
public:
  virtual double getArea() = 0; // pure virtual
  virtual ~Shape() {}
};
Circle must implement getArea to be concrete.
Design note

Abstract classes can still provide helper functions or protected members; they act as partial implementations of an interface.

Key Takeaway

Use pure virtuals to force derived classes to implement required behavior while allowing the base to host shared helpers and a virtual destructor.
