Learning Objectives

Understand and apply polymorphism across class hierarchies.

Bloom: Learn → Understand → Apply → Master
01
Define polymorphism

Explain 'many forms' in C++ and why a single interface reduces duplication and improves extensibility. Mnemonic: one interface, many behaviors. VERIFIED COMPETENCY MILESTONE

02
Use base pointers/references

Practice assigning derived objects to base pointers/references and access shared interface safely; avoid slicing by not copying. VERIFIED COMPETENCY MILESTONE

03
Implement virtual functions

Turn base methods virtual to enable runtime dispatch; test that derived overrides run correctly. VERIFIED COMPETENCY MILESTONE

04
Design abstract classes

Declare pure virtual functions to force derived classes to implement required behavior and include a virtual destructor for safe deletion. VERIFIED COMPETENCY MILESTONE
