Core Concept

What is Polymorphism?

Many forms through a common interface; supports extensibility.

Definition + Analogy
Analogy: One remote controls different TV models — same interface, different internals.
Key idea
  • Base pointer/reference holds derived objects.
  • Virtual functions enable runtime selection of the override.
  • Use pointers/references to avoid slicing.
Common misconception

Polymorphism is not runtime type casting; it is dispatch via virtual functions. Copying by value does not give polymorphic behavior.

Concrete example

Imagine Shape* s = new Circle(3.0); calling s->getArea when getArea is virtual runs Circle's implementation and returns the correct area for the circle.

Check your understanding: Why use pointers here instead of copying an object into a Shape value?
Key Takeaway

Polymorphism lets a base interface call derived behavior at runtime; design with pointers or references and virtual functions.
