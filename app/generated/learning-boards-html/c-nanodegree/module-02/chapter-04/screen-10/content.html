Core Concept

Designing Abstract Base Classes

Define clear contracts, share protected state, and ensure safe cleanup.

1. Interface

Declare required operations as pure virtual so derived classes must implement them.

2. Shared state

Use protected members for data common to derived classes, but avoid exposing internals publicly.

3. Virtual destructor

Always include a virtual destructor to ensure derived resources are freed on deletion via base pointer.

Pro tip: prefer unique_ptr in containers to express ownership and avoid manual delete.
Key Takeaway

A clean abstract base class defines the contract and resource rules; keep it focused and explicit about ownership.
