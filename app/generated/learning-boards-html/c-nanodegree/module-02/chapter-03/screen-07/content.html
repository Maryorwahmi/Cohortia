Module 2 › Chapter 2.3 › Constructor chaining
Process
  1. Allocate object memory for derived type.
  2. Call base class constructors (most base first).
  3. Initialize derived members using initializer list.
  4. Execute derived constructor body.
Example initializer list
Car(std::string c, double s, int doors) : Vehicle(c, s), numDoors(doors) { std::cout << "Car constructor" << std::endl; }
Why initializer lists matter
  • Directly construct base subobject with correct arguments.
  • Avoids assignment after default construction, which can be inefficient.
  • Required for const and reference members that cannot be assigned later.
