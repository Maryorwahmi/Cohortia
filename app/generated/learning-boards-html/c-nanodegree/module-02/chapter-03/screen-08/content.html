Module 2 › Chapter 2.3 › Destructor order
Observation

Constructors go base→derived. Destructors go derived→base. This pattern protects derived resources during teardown.

Example output
Vehicle constructor called.
Car constructor called.
Car destructor called.
Vehicle destructor called.
Polymorphism note
If you delete derived objects through base pointers, make the base destructor virtual so the derived destructor runs.
Common mistake
Omitting virtual destructor in base classes can silently skip derived cleanup when deleting via base pointers.
Key Takeaway

Destructor order protects derived cleanup. Use virtual destructors for polymorphic base classes.
