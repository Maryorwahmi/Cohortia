Module 2 › Chapter 2.3 › Quick Reference
Inheritance
Derived types reuse base behavior and can specialize it.
Access Modes
public/protected/private determine how inherited members are exposed.
Lifecycle
Use initializer lists; constructors base→derived, destructors derived→base.
Overriding
Override signatures must match; call base explicitly when composing behavior.
Virtual Destructors
Make base destructor virtual when deleting derived objects via base pointers.
Composition
Prefer composition for 'has-a' relationships; extract helpers for reuse.
Final Tip

When designing, use the substitutability check: if Derived cannot stand in for Base, do not inherit.
