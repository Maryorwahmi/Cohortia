Module 2 › Chapter 2.3 › Key Concepts
Inheritance
Derived classes reuse and extend base class attributes and behavior.
Access Modes
public/protected/private change visibility of inherited members in the derived class.
Constructor/Destructor Order
Base constructors run first; destructors run in reverse order. Use initializer lists to forward args.
Method Overriding
Derived classes can provide specialized implementations and call the base version explicitly.
Common Mistakes
Avoid using inheritance for 'has-a' relationships and forget to forward base constructors or virtual destructors.
Composition
Prefer composition for ownership and flexible behavior; extract helpers instead of inheriting for reuse.
Summary takeaway

Design hierarchies by substitutability, control visibility with access modes, and manage lifecycle with proper constructor/destructor patterns.
