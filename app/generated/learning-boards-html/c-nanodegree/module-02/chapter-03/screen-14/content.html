Module 2 › Chapter 2.3 › Mistakes & Best Practices
Common mistakes
  • Not calling required base constructors in initializer list.
  • Missing virtual destructor in polymorphic base classes.
  • Using inheritance for 'has-a' relationships instead of composition.
  • Overexposing protected data and creating tight coupling.
Best practices
  • Prefer public inheritance for true subtypes.
  • Use initializer lists for predictable initialization.
  • Mark base methods virtual when polymorphism is intended and use override in derived methods.
  • Prefer composition when the relationship is not subtype.
Check before you inherit
Can you substitute the derived type everywhere the base is used? If not, choose composition.
