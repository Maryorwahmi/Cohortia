Module 2 › Chapter 2.3 › Base vs Derived
Base Class
Vehicle
  • Defines shared data: color, speed.
  • Defines behaviors: accelerate, brake, displayInfo.
  • Can expose protected members to derived classes.
Design tip: keep stable API in base classes to avoid breaking derived types.
Derived Class
Car : public Vehicle
  • Adds specific data: numDoors.
  • Specializes behavior: startEngine, override displayInfo.
  • Can call base methods using scope resolution.
Practical check: if you need a Car object where a Vehicle is expected, inheritance is correct.
Substitutability
Can the derived object be used in place of the base type?
Visibility
public/protected/private inheritance affect how inherited members are exposed.
Design smell
Inheriting for code reuse rather than logical taxonomy often indicates a design smell.
