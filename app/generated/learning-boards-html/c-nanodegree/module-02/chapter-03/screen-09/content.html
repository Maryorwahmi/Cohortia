Module 2 › Chapter 2.3 › Method overriding
Code example
#include <iostream>
#include <string>

class Vehicle {
public:
  Vehicle(std::string c, double s) : color(c), speed(s) {}
  void displayInfo() const {
    std::cout << "Color: " << color << ", Speed: " << speed << " km/h" << std::endl;
  }
protected:
  std::string color;
  double speed;
};

class Car : public Vehicle {
private:
  int numDoors;
public:
  Car(std::string c, double s, int d) : Vehicle(c, s), numDoors(d) {}
  void displayInfo() const {              // override (not virtual in this example)
    Vehicle::displayInfo();               // call base implementation
    std::cout << "Number of doors: " << numDoors << std::endl;
  }
};

int main() {
  Car myCar("Red", 60.0, 4);
  myCar.displayInfo();
  return 0;
}
Explanation
  • Car defines its own displayInfo with the same signature as Vehicle.
  • Vehicle::displayInfo is explicitly called to reuse base behavior.
  • To enable polymorphic calls through base pointers, declare Vehicle::displayInfo as virtual.
Misconception
Overriding does not implicitly call the base version; you must call it if needed.
Key Takeaway

Use overriding to specialize behavior; explicitly call the base version to compose behaviors.
