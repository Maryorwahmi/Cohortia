Module 2 › Chapter 2.3 › What is inheritance?
Definition

Inheritance in one sentence

A derived class reuses the data and behavior of a base class and can extend or override it.

Key bullets
  • Promotes code reuse and logical modeling.
  • Base class is parent; derived class is child.
  • Protected members accessible to derived classes.
  • Choose inheritance only for true subtype relationships.
Key Takeaway

Use inheritance to model 'is-a' relationships and keep implementation details hidden via access control.

Example
Vehicle (base)
protected: color, speed • public: accelerate(), brake(), displayInfo()
Car : public Vehicle (derived)
private: numDoors • public: startEngine(), overridden displayInfo()
Common misconception

Do not use inheritance to model 'has-a' relationships such as Car inheriting from Engine. Composition is the correct design for ownership or usage relationships.

When to inherit
If the derived object truly is a kind of the base object.
When to avoid
If you only need access to functionality, prefer a member object instead of inheritance.
