Module 2 › Chapter 2.3 › Composition vs Inheritance
Composition (has-a)
  • Car has an Engine as a member.
  • Ownership and lifetimes are clearer.
  • Swap components to change behavior at runtime.
Inheritance (is-a)
  • Car is a Vehicle — it can be used where Vehicle is expected.
  • Enables polymorphism when base methods are virtual.
  • Should model true subtype relationships only.
Rule of thumb
If you cannot truthfully say Derived is a Base, prefer composition.
Refactor tip
Extract shared code into helper classes rather than using inheritance for reuse.
Design smell
Multiple unrelated responsibilities in a base class indicate poor abstraction for inheritance.
