Process
Steps when object is created
  1. Memory for the object is allocated (stack or heap).
  2. Member initializers run (if provided) in declaration order.
  3. Constructor body executes to finalize initialization and validation.
  4. Object is ready for use; destructor will run when scope ends or object is deleted.
Code examples
// Parameterized constructor
BankAccount(std::string accNum, double initialBalance) {
  accountNumber = accNum;
  balance = initialBalance;
}

// Explicit default constructor
BankAccount() : accountNumber(""), balance(0.0) {}
If you omit the explicit default after adding a parameterized constructor, code like BankAccount a; will fail to compile.
