Architecture
Data members (state)
Keep state private and validate all changes through member functions. Examples: accountNumber, balance, width, height.
Member function guidance
  • Keep functions focused: one responsibility per method.
  • Use const for getters that do not mutate state.
  • Validate inputs in setters and public methods.
Concrete snippet
// Conceptual members
private:
    std::string accountNumber;
    double balance;

public:
    double getBalance() const { return balance; }
    void deposit(double amount) { if(amount>0) balance += amount; }
The getter is const to signal it does not modify object state. Deposit validates the input before changing balance.
Key Takeaway

Design members to protect invariants and expose only the operations the rest of the program should use.
