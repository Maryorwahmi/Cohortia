Module 2 › Chapter 2.1 › Const Members
Guideline
Declare member functions const if they do not change any observable state. This improves safety and expresses intent clearly to users of your class.
double getBalance() const {
  return balance;
}
Practical benefit
Const correctness helps the compiler catch unintended mutations and lets your class be used in more contexts.
Key Takeaway

Make non-mutating functions const to document behavior and increase compiler-enforced safety.
