Module 2 › Chapter 2.1 › Destructors
Definition
Destructor = Cleanup
Destructor signature: tilde followed by class name, no params, no return. Run automatically when an object goes out of scope or is deleted.
When to implement
Implement a destructor when your class opens files, allocates memory, or holds other system resources that must be released deterministically.
Practical guidance
  • Match allocations in constructors with releases in destructors.
  • Set members to safe defaults so destructors are safe even after partial construction.
  • Avoid heavy work in destructors that can throw exceptions; prefer noexcept-safe cleanup.
Key Takeaway

Destructors ensure predictable cleanup. For any resource acquired, design a matching cleanup path.
