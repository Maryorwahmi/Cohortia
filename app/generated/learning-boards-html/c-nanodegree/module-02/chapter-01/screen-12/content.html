Process to keep objects valid
  1. Define the invariants your class must maintain.
  2. Implement validation logic in setters or a shared helper.
  3. Call setters from constructors so all initialization paths validate consistently.
  4. Test edge cases where invalid inputs are supplied and confirm safe defaults.
Example rule
Width and height must be > 0; otherwise set to 1.0 and warn the user.
RAII reminder
Acquire resources in constructors and release them in destructors to avoid leaks.
