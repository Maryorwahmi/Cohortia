Module 2 › Chapter 2.1 › Access Specifiers
Comparison
public vs private
private
Restricts access to members inside the class. Use it for data that must not be changed arbitrarily.
public
Exposes functions or values intended for external use, such as APIs to change an object safely.
Concrete scenario
Consider a BankAccount: make balance private. Provide public deposit and withdraw methods that check amounts and available funds. This prevents accidental state corruption and centralizes validation.
Common mistake
Making data public to 'save time' loses control. Later, you cannot enforce rules without changing all call sites.
Key Takeaway

Encapsulation is about invariants and clear interfaces; prefer private data with public methods that validate.
