Module 3 › Chapter 2.5 › Copy Assignment
Recommended steps
  1. Check self-assignment: if (this == &other) return *this;
  2. Delete existing resources held by this object.
  3. Allocate new resources and copy contents from source.
  4. Return *this to allow chained assignment.
This pattern prevents accidental deletion of source data and avoids double frees. It is simple and effective for classes that manage raw memory.
Example
MyString& operator=(const MyString& other) {
  if (this == &other) return *this;
  delete[] data;
  length = other.length;
  data = new char[length + 1];
  std::strcpy(data, other.data);
  return *this;
}
Pitfall
Deleting resources before copying without a self-check risks losing data when assigning an object to itself.
Performance note
Copying large resources can be costly; move semantics can avoid copies in many scenarios.
Key Takeaway
Always protect assignment with a self-check and ensure resources are cleaned and reallocated safely.
