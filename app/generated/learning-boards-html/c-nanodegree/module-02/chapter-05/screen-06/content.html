Module 3 › Chapter 2.5 › Prefix vs Postfix
Implementation pattern
// Prefix: ++vec
Vector2D& operator++() {
  ++x; ++y;
  return *this;
}

// Postfix: vec++
Vector2D operator++(int) {
  Vector2D temp = *this; // copy current state
  ++(*this);             // call prefix
  return temp;           // return old state
}
Concrete example
If v is (1,1), then printing ++v yields (2,2). Printing v++ yields (1,1) and the stored v becomes (2,2) afterwards.
Common mistake
Returning a reference from postfix creates a reference to a temporary. Always return by value for postfix.
Key Takeaway
Match return type to meaning: reference for updated object, value for previous state.
