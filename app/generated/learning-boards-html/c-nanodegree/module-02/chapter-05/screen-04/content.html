Module 3 › Chapter 2.5 › Vector Addition
Before — plain function
// Free function
Vector2D addVectors(const Vector2D& a, const Vector2D& b) {
  return Vector2D(a.getX() + b.getX(), a.getY() + b.getY());
}

// call site
Vector2D c = addVectors(v1, v2);
After — member operator+
class Vector2D {
  double x, y;
public:
  Vector2D(double x_val = 0.0, double y_val = 0.0) : x(x_val), y(y_val) {}
  Vector2D operator+(const Vector2D& other) const {
    return Vector2D(x + other.x, y + other.y);
  }
};

// call site
Vector2D c = v1 + v2;
Explanation
  • Member operator+ uses the left operand as *this and returns a new value.
  • Make operator+ const so it can be called on rvalues and consts.
  • Return by value is typical for arithmetic operators to avoid aliasing issues.
Concrete example
Using operator+ reduces visual noise in loops that sum many vectors, improving readability and lowering cognitive load.
Key Takeaway
Use operator+ when behavior matches arithmetic expectations and keep it const-correct.
