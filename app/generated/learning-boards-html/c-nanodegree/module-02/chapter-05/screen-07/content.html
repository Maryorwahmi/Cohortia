Module 3 › Chapter 2.5 › Stream I/O
operator<< and operator>> (friend non-members)
friend std::ostream& operator<<(std::ostream& os, const Vector2D& vec) {
  os << "(" << vec.x << ", " << vec.y << ")";
  return os;
}

friend std::istream& operator>>(std::istream& is, Vector2D& vec) {
  char paren, comma;
  is >> paren >> vec.x >> comma >> vec.y >> paren; // expects (x, y)
  return is;
}
Supporting notes
  • Return the stream to allow chaining with other I/O operations.
  • Keep input parsing simple and document the expected format, e.g. (x, y).
  • Use friend only when necessary to access private members; prefer public getters if available.
Concrete example
Printing a Vector2D with the print function now yields a human-readable pair like (1.0, 2.0) without extra helper calls.
Misconception
operator>> must not perform complex validation silently; keep behavior predictable for callers.
Key Takeaway
Implement stream operators as non-members that return the stream reference for chaining and clarity.
