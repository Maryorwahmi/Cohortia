01
Overload binary operators

Write operator+ and similar functions so objects can be combined with natural syntax. This improves readability and reduces boilerplate calls like add(a,b).

02
Overload unary operators

Implement prefix and postfix forms like ++ and --, returning references or values appropriately to match expected semantics.

VERIFIED COMPETENCY MILESTONE
03
Stream insertion & extraction

Provide operator<< and operator>> as non-member functions so objects integrate with streams for printing and reading.

VERIFIED COMPETENCY MILESTONE
04
Rule of Three / Five / Zero

Know when to implement copy/move constructors and assignment operators, or avoid them entirely by using standard containers and smart pointers.
