Move constructor and move assignment
// Move Constructor
MyString(MyString&& other) noexcept {
  data = other.data;
  length = other.length;
  other.data = nullptr;
  other.length = 0;
}

// Move Assignment
MyString& operator=(MyString&& other) noexcept {
  if (this == &other) return *this;
  delete[] data;
  data = other.data;
  length = other.length;
  other.data = nullptr;
  other.length = 0;
  return *this;
}
Practical notes
  • After move, source must be left in a valid, destructible state.
  • Mark moves noexcept when possible so containers can employ them during reallocation.
  • Nullify pointers in source to avoid double-free.
Concrete example
Constructing a large string from a temporary can use move constructor, avoiding an expensive deep copy and improving performance.
Common mistake
Forgetting to set the moved-from pointer to null will cause double deletion when the source is destroyed.
Key Takeaway
Use move semantics to transfer ownership efficiently and always nullify the source to prevent double-free.
