MyString — deep copy pattern
// Copy Constructor
MyString(const MyString& other) {
  length = other.length;
  data = new char[length + 1];
  std::strcpy(data, other.data);
}

// Copy Assignment
MyString& operator=(const MyString& other) {
  if (this == &other) return *this;
  delete[] data;
  length = other.length;
  data = new char[length + 1];
  std::strcpy(data, other.data);
  return *this;
}

// Destructor
~MyString() { delete[] data; }
Why deep copy matters
  • Avoids two objects owning the same raw memory.
  • Prevents double-free and dangling-pointer errors.
  • Makes destruction predictable and safe for each object.
Concrete example
Creating a copy of MyString allocates separate storage so both objects remain valid after destruction of either one.
Misconception
Relying on compiler-generated copy semantics when you own raw pointers leads to shallow copies and bugs.
Key Takeaway
Implement all three special members when your class directly manages raw resources.
