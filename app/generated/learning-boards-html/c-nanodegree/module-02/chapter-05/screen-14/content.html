Ownership checks
  • Do any members point to raw memory?
  • Should copies allocate fresh storage?
Assignment safety
  • Handle self-assignment.
  • Free old resources before/after acquiring new ones safely.
Move and streams
  • Nullify moved-from sources.
  • Mark move operations noexcept where possible.
  • Document stream formats and validation rules.
Action
Use this checklist during code review to reduce resource-related defects and ensure operator overloads behave as users expect.
