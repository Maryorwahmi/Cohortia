Module 3 › Chapter 2.5 › Key Concepts
Operator Overloading
Redefine operator behaviour for custom types to make expressions clear and idiomatic.
Member vs Non-member
Members when left operand is your type; non-members for stream I/O or different left operands.
Prefix vs Postfix
Prefix returns updated reference; postfix returns the previous value by copy.
Summary

Design operators to be intuitive, implement correct special members for resource safety, and prefer standard containers when possible to follow the Rule of Zero.
