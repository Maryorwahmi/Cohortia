Module 3 › Chapter 2.5 › Member vs Non-member
When to use a member
  • Assignment operators (=, +=) must be members.
  • Subscript operator and function call operator must be members.
  • Unary operators that act on the object are often members.
When to use a non-member
  • Stream operators << and >> must be non-member friends.
  • Binary operators where left operand is not your type must be non-members.
  • Use friend if you need access to private members.
Example — non-member scalar * vector
// non-member function
Vector2D operator*(double scalar, const Vector2D& v) {
  return Vector2D(v.x * scalar, v.y * scalar);
}
Misconception
Choosing member by default prevents expressions where the left operand is not your type.
Pro tip
When in doubt, implement symmetric non-member overloads and declare them friend only if needed.
Key Takeaway
Pick the form that preserves natural operand order and access needs.
