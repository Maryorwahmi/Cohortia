Making Fabric Binaries Accessible

Updating Your PATH Environment Variable

What is PATH?

A system environment variable that tells your shell where to look for executable commands.

Why Update PATH?

Allows you to run Fabric commands (e.g., peer, configtxgen) without specifying their full directory path.

Temporary vs. Permanent

Can be set for the current session or permanently added to your shell's configuration file (e.g., ~/.bashrc).

# Navigate to fabric-samples directory
cd fabric-samples
# Add bin to PATH for current session
export PATH=$PATH:$(pwd)/bin
# To make permanent (e.g., for Bash)
echo "export PATH=\$PATH:$(pwd)/bin" >> ~/.bashrc
source ~/.bashrc
Common Mistake

Forgetting to source your shell config file after making permanent changes, which means the changes won't take effect until you restart your terminal or explicitly source it.
