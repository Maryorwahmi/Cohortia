Understanding the PATH Variable

The PATH environment variable is a list of directories that your operating system searches for executable programs when you type a command in the terminal. If a command's executable is not in any of these directories, the shell won't find it.

How to Resolve 'Command Not Found'

  • Identify the installation directory of the missing executable.
  • Add this directory to your PATH in your shell's config file (e.g., ~/.bashrc).
  • source the config file or restart your terminal.
Key Takeaway

Correctly configuring your PATH environment variable is essential to avoid 'command not found' errors and ensure tool accessibility.

# Example: 'go: command not found'
$ go version
bash: go: command not found
# Edit ~/.bashrc (or ~/.zshrc)
nano ~/.bashrc
# Add this line:
export PATH=$PATH:/usr/local/go/bin
# Apply changes
source ~/.bashrc
# Now try again:
go version
go version go1.20.1 linux/amd64
Always verify changes after modifying environment variables.
