Verify Docker Engine Installation

Ensure Docker Engine is correctly installed and operational using these essential commands.

# Check Docker version
docker --version
# Expected Output:
Docker version 24.0.7, build afdd53b
# Run a test container
docker run hello-world
Why it matters

Confirming the version ensures the CLI can communicate with the daemon. Running hello-world validates core Docker functionality.

Expected Result

For hello-world, you should see a message like "Hello from Docker!" and a confirmation that your installation works.

Key Takeaway

Always verify your Docker Engine installation with both version and functional tests to ensure a stable foundation for Fabric development.
