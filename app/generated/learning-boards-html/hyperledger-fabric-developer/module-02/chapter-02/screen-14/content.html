Essential Docker Terminology

Revisiting the core components and practices for your Fabric development.

Docker Engine

The core component that runs and manages Docker containers on your host system.

Docker Desktop

A bundled application for macOS and Windows, including Docker Engine, Compose, and a GUI.

Docker Compose

A tool for defining and running multi-container Docker applications using a single YAML file.

Summary Takeaway

Docker Engine, Docker Desktop, and Docker Compose are the foundational tools for building and managing containerized Hyperledger Fabric networks.
