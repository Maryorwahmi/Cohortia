Verify Docker Compose Installation

Confirm Docker Compose is installed and accessible for orchestrating multi-container applications.

# Check Docker Compose version (legacy)
docker-compose --version
# Expected Output:
Docker Compose version v2.23.3
# Check Docker Compose version (plugin)
docker compose version
# Expected Output:
Docker Compose version v2.23.3
Why it matters

Verifying Compose ensures you can define and manage multi-container Fabric networks from a single YAML file.

Installation Note

Docker Compose is bundled with Docker Desktop. For Linux, it might be a standalone binary or a plugin (docker compose).

Key Takeaway

A successful Docker Compose verification confirms your ability to orchestrate complex Fabric environments with ease.
