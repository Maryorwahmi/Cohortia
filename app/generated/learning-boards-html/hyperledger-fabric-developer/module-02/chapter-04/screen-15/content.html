Key Concepts

Core Tools and Operations

Chaincode

Smart contracts defining business logic and ledger state management.

network.sh

Primary script for managing the `test-network` lifecycle.

peer CLI

Command-line interface for interacting with peer nodes and chaincode.

Invoke

A transaction that modifies the ledger state.

Query

A transaction that reads the ledger state without modifying it.

Summary Takeaway

The `network.sh` script and `peer` CLI are your primary tools for deploying chaincode and interacting with the ledger through invoke and query operations.
