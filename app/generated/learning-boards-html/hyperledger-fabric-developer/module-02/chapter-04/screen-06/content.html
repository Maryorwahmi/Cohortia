Network Management

The network.sh Control Script

Orchestrating Your Fabric Environment

The network.sh script, located in fabric-samples/test-network, is a powerful shell script designed to simplify the management of your Hyperledger Fabric test-network. It automates many complex, multi-step operations.

Key Functions
  • Bring up the network (up)
  • Create channels (createChannel)
  • Deploy chaincode (deployCC)
  • Shut down and clean up (down)
Benefit

It abstracts away the complexities of manual Docker commands and cryptographic tool execution, saving significant time and reducing errors.

Key Takeaway

network.sh is your essential command-line utility for efficient lifecycle management of the test-network.

Terminal: fabric-samples/test-network
$ ./network.sh --help
Usage:
  network.sh <Mode> [Flags]
  Modes:
    up             - Bring up the network
    down           - Tear down the network
    createChannel  - Create a channel
    deployCC       - Deploy chaincode
    ...
Flags:
  -c <channel name>  - Channel name
  -ccn <chaincode name> - Chaincode name
  -ccp <chaincode path> - Chaincode path
  -ccl <chaincode language> - Chaincode language

This output shows the various commands and flags available with network.sh, highlighting its versatility in managing the Fabric network lifecycle.
