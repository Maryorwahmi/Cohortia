Querying the Ledger State

Reading Data Without Modification

Terminal: Query All Assets
$ peer chaincode query -C mychannel -n basic -c '{"Args":["GetAllAssets"]}'
[{"ID":"asset1","color":"blue","size":5,"owner":"Tomoko","appraisedValue":300},
 {"ID":"asset2","color":"red","size":5,"owner":"Brad","appraisedValue":400},
 {"ID":"asset3","color":"green","size":10,"owner":"Jin","appraisedValue":500},
 {"ID":"asset4","color":"yellow","size":10,"owner":"Aarav","appraisedValue":600},
 {"ID":"asset5","color":"black","size":15,"owner":"Pari","appraisedValue":700},
 {"ID":"asset6","color":"white","size":15,"owner":"Valeria","appraisedValue":800}]

This output shows a JSON array of assets, representing the current state of the ledger.

Query Purpose

Reads data from the ledger without initiating a transaction or modifying the state. It's a read-only operation.

Key Parameters
  • -C: Channel name.
  • -n: Chaincode name.
  • -c: JSON payload specifying the function and arguments (e.g., GetAllAssets).
Consistency Check

While queries are typically against a single peer, the ledger's immutability ensures consistency across all peers on the channel. Inconsistent results may indicate a synchronization issue.

Key Takeaway

Query operations are essential for retrieving and displaying the current state of the blockchain to users without altering the ledger.
