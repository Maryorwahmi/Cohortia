Shutting Down and Cleaning Up

Ensuring a Fresh Start for Your Environment

Terminal: Shut Down Network
$ ./network.sh down
Tearing down network with command 'down'
...
Removing Org1 CA ... Done
Removing Org2 CA ... Done
Removing Orderer ... Done
Removing Org1 peer ... Done
Removing Org2 peer ... Done
Removing generated crypto material and config artifacts ... Done
Network torn down successfully!

This output confirms the complete shutdown and removal of all network components and artifacts.

Cleanup Actions
  • Stops and removes all Docker containers (CAs, orderers, peers).
  • Deletes generated cryptographic material (certificates, keys).
  • Removes configuration artifacts and chaincode images.
Why Cleanup is Important

Frees up system resources, prevents conflicts with future deployments, and ensures a clean slate for consistent development and testing.

Troubleshooting Tip

Always read terminal output carefully; Fabric provides detailed error messages that can guide your troubleshooting efforts.

Key Takeaway

Regular cleanup with ./network.sh down is crucial for maintaining a healthy and predictable development environment.
