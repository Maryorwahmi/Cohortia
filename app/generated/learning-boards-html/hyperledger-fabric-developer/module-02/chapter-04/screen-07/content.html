Bringing Up the Test Network

Initializing Your Fabric Environment

Terminal: fabric-samples/test-network
$ ./network.sh up
Creating network with command 'up'
...
Creating Org1 CA ... Done
Creating Org2 CA ... Done
Creating Orderer ... Done
Creating Org1 peer ... Done
Creating Org2 peer ... Done
...
Network started successfully!

This output confirms the successful startup of all necessary Docker containers for the `test-network`.

Process Steps
  • Cryptographic Material Generation: `cryptogen` creates identities for organizations and the orderer.
  • Configuration Artifacts: `configtxgen` creates the genesis block and channel configuration.
  • Docker Container Launch: CAs, orderer, and peer nodes are started via `docker-compose`.
Common Mistake

Forgetting to navigate into the fabric-samples/test-network directory before running ./network.sh up will result in a "command not found" error.

Key Takeaway

./network.sh up orchestrates the entire initial setup, from crypto generation to container startup, establishing the network's foundation.
