Smart Contract Deployment

Deploying Chaincode to the Channel

Bringing Business Logic to the Ledger

Terminal: fabric-samples/test-network
$ ./network.sh deployCC -ccn basic -ccp ../asset-transfer-basic/chaincode-go -ccl go
Deploying chaincode 'basic' to channel 'mychannel'
...
Chaincode 'basic' installed on peer0.org1.example.com
Chaincode 'basic' installed on peer0.org2.example.com
Chaincode definition 'basic' approved by Org1MSP
Chaincode definition 'basic' approved by Org2MSP
Chaincode definition 'basic' committed to channel 'mychannel'
Chaincode 'basic' deployed successfully!

This output confirms the successful installation, approval, and commitment of the chaincode to the channel.

Chaincode Parameters
  • -ccn <name>: Specifies the chaincode name (e.g., basic).
  • -ccp <path>: Path to the chaincode's source code.
  • -ccl <language>: Programming language of the chaincode (e.g., go).
Deployment Stages

Installation on peers, approval by organizations, and final commitment to the channel.

Troubleshooting Tip

Double-check the chaincode path (-ccp) and language (-ccl) parameters, as incorrect values are common causes of deployment failures.

Key Takeaway

Chaincode deployment is a multi-step process ensuring all participating organizations agree on the smart contract's definition before activation.
