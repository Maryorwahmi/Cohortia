Dedicated Functions for PDCs

  • •stub.PutPrivateData(collection, key, value): Stores data.
  • •stub.GetPrivateData(collection, key): Retrieves data.
  • •stub.DelPrivateData(collection, key): Deletes data.
Critical Warning

Never store private data directly on the public ledger. Always use the dedicated PutPrivateData function and ensure your collection configuration is correct to prevent data leakage.

Key Takeaway

Always use the specific stub.PutPrivateData(), GetPrivateData(), and DelPrivateData() functions with the correct collection argument for confidential data.

Code Example: Storing Private Data

// Store private data in 'myPrivateCollection'
collectionName := "myPrivateCollection"
assetID := "asset123"
privateData := []byte("{\"creditScore\": 750}")

err := stub.PutPrivateData(collectionName, assetID, privateData)
if err != nil {
    // Handle error
    return shim.Error("Failed to put private data")
}

This snippet demonstrates how to store a JSON object representing a credit score into a private collection. The collectionName argument is crucial for directing the data to the correct private database.
