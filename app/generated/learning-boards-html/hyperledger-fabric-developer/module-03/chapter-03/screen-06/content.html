Why Indexes are Crucial

  • •Without indexes, rich queries can be very slow and resource-intensive.
  • •CouchDB would perform full ledger scans, impacting performance on large datasets.
  • •Indexes are deployed as JSON files alongside your chaincode.
Important Note

Rich queries and indexes are only supported when your Hyperledger Fabric network uses CouchDB as its state database. LevelDB is limited to key-based queries.

Key Takeaway

Always define appropriate CouchDB indexes for frequently queried fields to ensure optimal chaincode performance and scalability.

Example: CouchDB Index Definition

// META-INF/statedb/couchdb/indexes/indexCarOwner.json
{
  "index": {
    "fields": ["docType", "owner"]
  },
  "ddoc": "indexCarOwnerDoc",
  "name": "indexCarOwner",
  "type": "json"
}

This index allows efficient queries on:

  • •docType field
  • •owner field

It's crucial to match your index fields to your common query patterns.
