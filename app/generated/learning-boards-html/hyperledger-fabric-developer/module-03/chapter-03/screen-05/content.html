Using stub.GetQueryResult()

The stub.GetQueryResult() function is your gateway to rich queries. It accepts a CouchDB selector string, which is a JSON object defining your query criteria.

Best Practice

Always include a docType field in your asset structs. This allows you to filter for specific asset types, preventing unintended query results.

Key Takeaway

CouchDB selectors, combined with docType, enable precise and efficient filtering of ledger data.

Example: CouchDB Selector

{
  "selector": {
    "docType": "car",
    "color": "red",
    "owner": "Alice",
    "value": { "$gt": 15000 }
  }
}

This selector finds all documents where:

  • •docType is "car"
  • •color is "red"
  • •owner is "Alice"
  • •value is greater than 15000
