Key CID Functions

  • •stub.GetCreator(): Raw identity of transaction creator.
  • •cid.GetID(): Unique ID of the client.
  • •cid.GetMSPID(): MSP ID of the client's organization.
  • •cid.AssertAttributeValue(name, value): Checks for specific attribute.
  • •cid.GetAttributeValue(name): Retrieves attribute value.
Use Case

Restrict functions to specific organizations or users based on their MSP ID or X.509 certificate attributes.

Key Takeaway

CID functions provide the tools to implement robust, identity-based access control directly within your chaincode logic.

Code Example: Restricting by MSP ID

func (s *SimpleChaincode) restrictedFunction(stub shim.ChaincodeStubInterface, args []string) peer.Response {
    id, err := cid.New(stub)
    if err != nil {
        return shim.Error("Failed to get client identity: " + err.Error())
    }

    mspID, err := id.GetMSPID()
    if err != nil {
        return shim.Error("Failed to get MSP ID: " + err.Error())
    }

    if mspID != "Org1MSP" {
        return shim.Error("Unauthorized: Only Org1MSP members can execute this function.")
    }
    // ... continue with function logic
    return shim.Success(nil)
}

This Go example demonstrates how to check the transaction creator's MSP ID and return an error if they are not from "Org1MSP", effectively restricting access.
