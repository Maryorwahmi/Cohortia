Key Concepts

More Essential Takeaways from This Chapter

Private Data Collections (PDCs)

A Fabric feature allowing a subset of organizations to share confidential data, with only a hash on the main ledger.

Client Identity (CID)

Mechanism in chaincode to access the identity of the transaction initiator for implementing access control.

cid.GetMSPID()

A CID function that retrieves the MSP ID of the transaction creator's organization, used for authorization.
