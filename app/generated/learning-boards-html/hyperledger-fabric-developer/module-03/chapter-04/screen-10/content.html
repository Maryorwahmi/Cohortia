Approving Chaincode Definition

Organizations agree on chaincode parameters before activation.

What's in a Definition?
  • Chaincode Name & Version: Identifiers for the smart contract.
  • Package ID: Link to the installed chaincode package.
  • Sequence Number: An integer that must be incremented for each upgrade.
  • Endorsement Policy: Defines which organizations must endorse transactions.
  • Private Data Collections: Specifies any private data configurations.
  • --init-required: Flag indicating if Init function must be called post-commitment.
Key Takeaway

The approval step ensures multi-organizational consensus on the chaincode's operational parameters, including its version and endorsement policy.

Terminal Command: Approve for My Org
# Step 3: Approve Chaincode Definition for Org1
peer lifecycle chaincode approveformyorg \
  -o orderer.example.com:7050 \
  --channelID mychannel \
  --name mycc \
  --version 1.0 \
  --package-id <PACKAGE_ID> \
  --sequence 1 \
  --init-required \
  --waitForEvent

# Repeat for Org2 (after setting Org2 environment variables)
peer lifecycle chaincode approveformyorg \
  -o orderer.example.com:7050 \
  --channelID mychannel \
  --name mycc \
  --version 1.0 \
  --package-id <PACKAGE_ID> \
  --sequence 1 \
  --init-required \
  --waitForEvent
Common Mistake

Forgetting to increment `--sequence` when upgrading chaincode. This will cause errors and prevent the upgrade.
