Key Concepts: Deployment Lifecycle

Understanding the Fabric v2.x chaincode deployment process.

Chaincode Lifecycle

The multi-step process for packaging, installing, approving, and committing chaincode definitions to a channel.

peer lifecycle chaincode package

CLI command to package chaincode source into a deployable .tar.gz archive.

peer lifecycle chaincode install

CLI command to install a chaincode package onto an endorsing peer, returning a Package ID.

peer lifecycle chaincode approveformyorg

CLI command for an organization to approve a chaincode definition on a channel.

peer lifecycle chaincode commit

CLI command to commit an approved chaincode definition to a channel, making it active.

peer chaincode invoke/query

CLI commands to send transaction proposals (invoke) or read data (query) via chaincode functions.

Summary Takeaway

The Fabric chaincode lifecycle, managed by `peer` CLI commands, ensures a secure, transparent, and collaborative deployment process for smart contracts.
