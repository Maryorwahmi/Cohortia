Key Concepts: Testing Fundamentals

Essential terms for validating your chaincode.

Unit Testing

Testing individual components (functions) of the chaincode in isolation, typically using mock objects.

mockstub

A utility in shim/test that simulates the ChaincodeStubInterface for isolated unit testing of chaincode.

Integration Testing

Testing the chaincode on a live Fabric network to verify interactions with the ledger and other components.

Summary Takeaway

Comprehensive testing, encompassing both isolated unit tests and network-wide integration tests, is fundamental to developing reliable Hyperledger Fabric chaincode.
