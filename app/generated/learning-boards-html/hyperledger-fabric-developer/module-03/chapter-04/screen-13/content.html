Common Mistakes and Safety Notes

Avoiding pitfalls in chaincode deployment and management.

Forgetting Init

If --init-required is set, you MUST explicitly invoke the Init function once after commitment. Skipping this prevents subsequent Invoke calls.

Incorrect Sequence

When upgrading chaincode, always increment the --sequence number in approve and commit steps. Reusing the same number causes errors.

Package ID Mismatch

Double-check that the Package ID used in approveformyorg matches the one generated during install. Any discrepancy will lead to deployment failure.

Endorsement Policy

Ensure the endorsement policy specified in the chaincode definition matches your desired security requirements. A default policy might be too permissive or restrictive.

CouchDB Index Deployment

For efficient rich queries, remember to deploy CouchDB index files with your chaincode package in the META-INF/statedb/couchdb/indexes directory.

Network Configuration

Ensure your core.yaml and connection.json files are correctly configured for your peer CLI to connect to the right peers and orderers.

Key Takeaway

Proactive awareness of common mistakes and careful configuration are vital for successful and secure chaincode deployment and operation.
