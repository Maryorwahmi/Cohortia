Ledger Operations

Reading and Writing Data: PutState and GetState

Essential Methods for Ledger Manipulation

PUTSTATE

Writing Data to the Ledger

stub.PutState(key string, value []byte) writes or updates a key-value pair. The value must be a byte array.

assetID := "asset1"
value := "value1"
err := stub.PutState(assetID, []byte(value))
Key Takeaway

PutState and GetState are fundamental for managing the state of assets on the ledger, requiring careful handling of byte array conversions.

GETSTATE

Reading Data from the Ledger

stub.GetState(key string) retrieves the value for a given key as a byte array. Returns nil if key not found.

assetAsBytes, err := stub.GetState(assetID)
if assetAsBytes == nil {
  // Handle asset not found
}
Common Mistake

Forgetting to convert data to []byte before PutState or from []byte after GetState can lead to runtime errors or incorrect data handling.
