The shim Package: Your Ledger Interface

Bridging Your Chaincode to Hyperledger Fabric

What is shim?

The shim package is the Hyperledger Fabric Chaincode Shim API, providing the necessary interfaces and functions for your chaincode to interact with the ledger and transaction context.

ChaincodeStubInterface

This interface within the shim package grants chaincode access to ledger operations (PutState, GetState, DelState) and transaction context (GetTxID, GetCreator).

Key Takeaway

The shim package is your chaincode's gateway to the Fabric ledger, enabling all data interactions and access to transaction details.

Ledger Interaction Methods
  • PutState(key, value []byte): Writes a key-value pair.
  • GetState(key string): Retrieves a value by key.
  • DelState(key string): Deletes a key-value pair.
  • GetStateByRange(startKey, endKey string): Queries a range of keys.
Transaction Context Methods
  • GetTxID(): Returns the unique transaction ID.
  • GetCreator(): Returns the identity of the transaction initiator.
  • GetChannelID(): Returns the ID of the channel.
  • InvokeChaincode(): Invokes another chaincode on the same channel.
