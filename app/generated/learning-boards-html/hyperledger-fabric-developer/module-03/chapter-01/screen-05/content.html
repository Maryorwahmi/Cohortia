Fundamental Principle

Deterministic Execution: The Fabric Cornerstone

Ensuring Consistent Outcomes Across All Peers

What is Determinism?

Given the same input, chaincode will always produce the same output, ensuring consistent results across all endorsing peers.

Why it Matters

It's crucial for blockchain consensus, guaranteeing that all peers agree on the validity of a transaction before it's committed to the ledger.

Key Takeaway

Deterministic chaincode is fundamental for maintaining ledger consistency and trust in a decentralized network.

Avoid Non-Deterministic Operations
  • Generating random numbers (e.g., math/rand.Intn())
  • Using system time directly (e.g., time.Now())
  • Making external API calls
  • Any operation that could yield different results on different machines or at different times.
Example: Random Number

If a chaincode function generates a random number, Peer A might get '5' while Peer B gets '12'. This breaks consensus, as they cannot agree on the transaction's outcome.

Pro-Tip: Deterministic Wrappers

For operations like timestamps, use the transaction timestamp provided by the Fabric stub, which is consistent across all peers, instead of system time.
