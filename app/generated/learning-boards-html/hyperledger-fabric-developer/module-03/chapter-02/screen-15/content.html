Key Concepts

Essential terms from this chapter

Asset

Any item of value (physical or digital) represented and managed on the blockchain ledger.

GoLang Struct

A composite data type in GoLang used to define the structure and properties of an asset.

JSON Tags

Used in Go structs to specify how fields should be named when marshaling to and unmarshaling from JSON.

Chapter Summary

This chapter laid the groundwork for chaincode development by focusing on asset modeling with Go structs and the critical role of JSON for data serialization on the ledger.
