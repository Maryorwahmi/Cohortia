Transaction Dispatch: The Invoke Method

Routing client requests to specific chaincode functions

Invoke's Role

  • Main entry point for all transaction proposals.
  • Parses function name and arguments from client.
  • Dispatches to appropriate helper functions (e.g., createCar, queryCar).
Key Takeaway

The Invoke method is the central hub for all chaincode operations, responsible for directing incoming transaction requests to specialized helper functions.

func (s *SimpleChaincode) Invoke(stub shim.ChaincodeStubInterface) peer.Response {
function, args := stub.GetFunctionAndParameters()
fmt.Printf("Invoke received: function=%s, args=%v ", function, args)
if function == "createCar" {
return s.createCar(stub, args)
} else if function == "queryCar" {
return s.queryCar(stub, args)
} else if function == "transferCar" {
return s.transferCar(stub, args)
} else if function == "deleteCar" {
return s.deleteCar(stub, args)
}
return shim.Error(fmt.Sprintf("Unknown function: %s", function))
}
