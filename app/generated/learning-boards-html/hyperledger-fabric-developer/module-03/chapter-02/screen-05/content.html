Why JSON?

JSON provides a standardized, human-readable format for structured data, making it ideal for interoperability between different systems and languages on the blockchain.

Key Takeaway

Always marshal Go structs to JSON bytes before PutState and unmarshal JSON bytes to structs after GetState for consistent ledger interaction.
