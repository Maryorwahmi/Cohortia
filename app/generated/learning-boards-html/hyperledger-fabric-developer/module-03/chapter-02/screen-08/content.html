Ledger Interaction

CRUD Operations Overview

The fundamental actions for managing data on the ledger

Create

Add new assets to the ledger.

stub.PutState(key, value)

Read

Retrieve assets from the ledger.

stub.GetState(key)

Update

Modify existing assets on the ledger.

stub.PutState(key, new_value)

Delete

Remove assets from the ledger.

stub.DelState(key)
Key Takeaway

PutState, GetState, and DelState are the core functions for all ledger interactions, enabling the full spectrum of data management within your chaincode.
