Defining Assets: GoLang Structs

Representing real-world items on the ledger

What is an Asset?

An asset is any item of value—physical or digital—that you want to track or manage on the blockchain ledger. It's the fundamental unit of data in your chaincode.

Key Takeaway

GoLang structs provide a clear, organized way to define the properties of your blockchain assets, ensuring consistent data representation.

type Car struct {
ID string `json:"id"` // Unique identifier for the car
Make string `json:"make"` // Manufacturer
Model string `json:"model"` // Model name
Color string `json:"color"` // Color of the car
Owner string `json:"owner"` // Current owner of the car
Value int `json:"value"` // Monetary value
}
Example: Car Asset

A Car struct defines properties like ID, Make, Model, Color, Owner, and Value, providing a clear schema for vehicle data on the ledger.
