Key Concepts

Essential terms from this chapter

encoding/json package

GoLang package for encoding (marshaling) and decoding (unmarshaling) JSON data.

json.Marshal()

Converts a Go data structure (like a struct) into a JSON byte array for ledger storage.

json.Unmarshal()

Converts a JSON byte array retrieved from the ledger into a Go data structure.

Chapter Summary

We explored the Go encoding/json package for serialization and deserialization, and the fundamental CRUD operations (Create, Read, Update, Delete) for managing assets on the ledger.
