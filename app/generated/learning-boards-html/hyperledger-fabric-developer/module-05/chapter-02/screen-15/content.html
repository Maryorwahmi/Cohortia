Key Concepts

Essential terms and ideas from this chapter

Chaincode Lifecycle (New)

The decentralized, multi-organization process for managing chaincode deployment and upgrades in Hyperledger Fabric v2.0+.

Package

The `.tar.gz` archive containing chaincode source and metadata, uniquely identified by a `label`.

Install

The process of deploying a chaincode package onto an endorsing peer, making it available for execution. Generates a `packageID`.

Chapter Summary

The new chaincode lifecycle in Fabric v2.0+ introduces a collaborative, secure model for managing smart contracts, starting with packaging and installing them on network peers.
