Process Flow

Adding a New Organization to a Channel

A step-by-step walkthrough of the update process

01

Generate Org's MSP

Create cryptographic material and MSP definition for the new organization.

02

Fetch & Decode Config

Retrieve the current channel configuration block and decode it to JSON.

03

Modify & Compute Update

Add the new Org's MSP to the JSON and compute the configuration update delta.

04

Sign Configuration Update

Existing organizations sign the update transaction according to the channel's modification policy.

05

Submit & Verify

Submit the signed transaction to the orderer, then verify the channel configuration update.
