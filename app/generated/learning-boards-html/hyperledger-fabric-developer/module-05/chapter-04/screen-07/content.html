Config Update: Modifying and Computing Delta

Injecting new organization details and generating the update

# 1. Create a new Org3 MSP definition (e.g., from configtxgen output)
# configtxgen -printOrg Org3MSP > org3.json
# For this example, assume org3.json exists with Org3's MSP config.

# 2. Add Org3's MSP to the 'Application' group in config.json
jq -s '.[0] * {"channel_group":{"groups":{"Application":{"groups": {"Org3MSP":.[1]}}}}}' config.json ./organizations/org3.json > updated_config.json

# Output (no direct console output, creates updated_config.json)

# 3. Encode original and updated configs back to protobuf
configtxlator proto_encode \
  --input config.json \
  --type common.Config \
  --output original_config.pb

configtxlator proto_encode \
  --input updated_config.json \
  --type common.Config \
  --output updated_config.pb

# Output (no direct console output, creates .pb files)

# 4. Compute the delta (config update)
configtxlator compute_update \
  --channel_id mychannel \
  --original original_config.pb \
  --updated updated_config.pb \
  --output config_update.pb

# Output (no direct console output, creates config_update.pb)

# 5. Decode the config update to JSON for inspection (optional)
configtxlator proto_decode \
  --input config_update.pb \
  --type common.ConfigUpdate \
  --output config_update.json

# Output (no direct console output, creates config_update.json)

Command Breakdown

  • jq -s '.[0] * ...': Merges the original config with the new Org3 MSP definition.
  • configtxlator proto_encode: Converts JSON back to protobuf.
  • configtxlator compute_update: Generates the minimal configuration update transaction (the 'delta').
  • --channel_id: Specifies the target channel.
  • --original, --updated: Paths to the original and modified protobuf configurations.
Common Mistake

Incorrect jq syntax or invalid JSON structure can lead to errors during proto_encode or compute_update. Always test your jq commands on small JSON snippets first.

Key Takeaway

The compute_update command is crucial for generating a concise delta, representing only the changes, which is then signed and submitted to the network.
