Data Encryption at Rest

Fabric ensures access control, but application-layer encryption may be needed.

Access Control vs. Encryption

PDCs control who sees data; encryption protects data even if storage is breached.

Application Layer

Consider encrypting sensitive data before sending it to chaincode.

Handling Missing Private Data

Chaincode must gracefully manage scenarios where private data is inaccessible.

getPrivateData Returns nil

For unauthorized organizations, the API returns nil, not an error.

Graceful Handling

Chaincode should anticipate and handle nil returns without crashing.

Key Takeaway

Supplement PDC access control with application-layer encryption for sensitive data, and always design chaincode to gracefully handle nil returns from getPrivateData for unauthorized access.
