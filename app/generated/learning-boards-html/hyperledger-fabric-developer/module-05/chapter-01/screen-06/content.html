The `CollectionConfig` Object

A JSON array of CollectionConfig objects defines your private data collections.

Name

Unique identifier for the collection.

Policy

Defines authorized organizations (by MSP ID).

Required Peer Count

Min peers for transaction endorsement.

Max Peer Count

Max peers to disseminate private data to.

Data Retention & Endorsement

Additional parameters control data lifecycle and validation.

Block To Live

Number of blocks after which private data can be purged.

Endorsement Policy

Defines specific endorsement rules for the collection.

Key Takeaway

The CollectionConfig object is central to defining a PDC, controlling its members, endorsement requirements, and data retention policies.
