Private Data Transaction Flow

A step-by-step look at how private data moves through the network.

1.Client Proposal

Client sends private data to authorized endorsing peers.

2.Peer Validation & Storage

Endorsing peers validate and commit data to private DBs.

3.Hash to Ordering Service

Only a hash of private data is sent to the ordering service.

4.Block Commit

Block with private data hash is committed to the main ledger.

Key Takeaway

The private data flow ensures confidentiality by restricting raw data to authorized peers while maintaining an immutable, verifiable hash on the public ledger.
