Key Concepts to Remember

Essential Takeaways (Part 2 of 2)

Collection Policy

A JSON definition specifying collection members, endorsement requirements, and data retention rules.

PutPrivateData/GetPrivateData

Chaincode APIs used specifically to store and retrieve data within a private data collection.

Gossip Protocol

Used by Fabric peers to securely disseminate private data to authorized peers within a collection.

Summary Takeaway

Effective PDC implementation relies on correctly defining collection policies, using dedicated chaincode APIs, and understanding the secure data dissemination via the gossip protocol.
