Public State APIs

For data visible to all organizations on the channel.

stub.putState(key, value)

Stores data on the public ledger.

stub.getState(key)

Retrieves data from the public ledger.

Private Data APIs

For data restricted to specific organizations within a collection.

stub.putPrivateData(collectionName, key, value)

Stores data in a private collection.

stub.getPrivateData(collectionName, key)

Retrieves data from a private collection.

Key Takeaway

Always use the dedicated putPrivateData and getPrivateData APIs, specifying the collection name, for interacting with private data collections.
