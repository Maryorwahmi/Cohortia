Defining Collection Membership

The policy field specifies which organizations are authorized members.

Member Organizations

Identified by their MSP IDs, e.g., 'Org1MSP.member'.

Policy Example

OR('Org1MSP.member', 'Org2MSP.member') allows members from either Org1 or Org2.

Collection Endorsement Rules

The endorsementPolicy specifies validation requirements for private data transactions.

Transaction Validation

Defines which peers must endorse transactions involving this collection.

Distinction

policy = who can access; endorsementPolicy = who must validate.

Key Takeaway

Careful configuration of both collection membership and endorsement policies is vital for robust private data management.
