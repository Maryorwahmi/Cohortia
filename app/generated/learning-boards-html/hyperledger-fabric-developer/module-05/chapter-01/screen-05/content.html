The Dual Storage Model

Private Data Collections use a hybrid approach for data storage.

Private Database

Actual private data is stored off-chain on authorized peers.

Main Ledger

Only a cryptographic hash of the private data is committed.

Ensuring Confidentiality & Integrity

This design provides both data privacy and verifiable proof of existence.

Confidentiality

Unauthorized organizations cannot access the raw private data.

Integrity

The hash provides immutable proof of data existence and agreement.

Key Takeaway

PDCs store private data off-chain, with only a hash on the ledger, ensuring data privacy while maintaining blockchain integrity and auditability.
