Monitoring Tools

Prometheus & Grafana for Fabric

Leverage industry-standard tools for comprehensive metric collection and visualization.

Prometheus

Collects time-series metrics: peer health, transaction rates, block height, resource utilization.

Grafana

Visualizes Prometheus data through dashboards for trend analysis and anomaly detection.

Risk of Neglect

Without proper monitoring, issues can escalate undetected, leading to network instability and application downtime.

Kubernetes Integration

Liveness and Readiness Probes

Automated health checks for Fabric components deployed in Kubernetes.

1

Liveness Probes

Checks if a container is running. If it fails, Kubernetes restarts the container (e.g., `peer node status`).

2

Readiness Probes

Checks if a container is ready to serve traffic. Prevents traffic until ready (e.g., peer synced with ledger).

3

Automated Recovery

Probes enable Kubernetes to automatically manage and recover unhealthy Fabric pods, enhancing uptime.

Key Takeaway

Integrating monitoring tools and Kubernetes health probes provides critical visibility and automated resilience for production Fabric deployments.
