Client Event Listener: Node.js Example Walkthrough

Subscribing to Chaincode Events with Fabric Node.js SDK

const { Gateway, Wallets } = require('fabric-network');
// ... (connection setup)

async function main() {
    // ... (gateway connection)
    const network = await gateway.getNetwork('mychannel');
    const contract = network.getContract('myasset');

    // 1. Listen for 'assetTransferEvent'
    console.log('Listening for assetTransferEvent...');
    const listener = await contract.addContractListener('assetTransferEvent', (event) => {
        console.log(`*** Contract Event Received: ${event.eventName}`);
        console.log(`Transaction ID: ${event.transactionId}`);
        console.log(`Payload: ${event.payload.toString('utf8')}`);
        const eventData = JSON.parse(event.payload.toString('utf8'));
        console.log(`Asset ${eventData.assetID} transferred to ${eventData.newOwner}`);
        // 2. Implement application logic here
    });

    // 3. Invoke chaincode to trigger event
    console.log('Invoking transferAsset to trigger an event...');
    await contract.submitTransaction('transferAsset', 'asset123', 'newOrg2Owner', '500 USD');

    // ... (keep alive or disconnect)
}
main();

Code Explanation

  • •**Gateway & Contract:** Initialize the Fabric Gateway and get the contract instance for your chaincode.
  • •**`addContractListener`:** Register a listener for a specific event name (e.g., `assetTransferEvent`). The callback function receives the event object.
  • •**Payload Processing:** Inside the callback, parse the `event.payload` (a Buffer) into a JSON object to access event data.
  • •**Triggering Event:** Invoke a chaincode function (e.g., `transferAsset`) that is configured to emit the event, demonstrating the full flow.
Pro-Tip

Ensure your client application handles potential errors during event parsing and processing gracefully.

Why it Matters

This client-side code completes the reactive loop, allowing off-chain systems to respond to on-chain changes.

Key Takeaway

Fabric SDKs provide powerful tools for building event-driven client applications that interact with your blockchain.
