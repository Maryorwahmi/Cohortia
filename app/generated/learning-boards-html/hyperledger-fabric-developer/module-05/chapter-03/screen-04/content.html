Core Concept

Real-time Notifications from the Ledger

Why Chaincode Events are Essential for Reactive Applications

The Polling Problem

  • •Inefficiently consumes network resources by constantly querying the ledger for changes.
  • •Introduces delays as applications only detect changes at the polling interval.
  • •Scales poorly with more applications or higher transaction volumes.

The Event Solution

  • •Provides real-time, push-based notifications for significant on-chain occurrences.
  • •Enables reactive applications to respond instantly to ledger state changes.
  • •Improves efficiency and scalability by reducing unnecessary network traffic.
Concrete Example

An 'Asset Transferred' event can trigger an email notification to the new owner, updating them instantly.

Why it Matters

Events are crucial for integrating blockchain with traditional enterprise systems, enabling seamless workflows.

Key Takeaway

Chaincode events are the backbone of reactive, integrated Hyperledger Fabric applications.
