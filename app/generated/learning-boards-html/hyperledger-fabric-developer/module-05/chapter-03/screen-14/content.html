Case Study: Secure Medical Imaging

Linking Large, Sensitive Files to the Blockchain

Medical Image

Large, sensitive file (off-chain)

Hash & Reference

Image hash + IPFS CID/URL

On-Chain Record

`recordID`, hash, reference

Client Verification

Retrieve image, re-hash, compare to on-chain hash for integrity.

Why it Matters

This hybrid approach ensures data integrity and privacy for sensitive, large files without bloating the blockchain.

Security Note

The off-chain image itself must be encrypted to ensure confidentiality, as the hash only proves integrity.

Key Takeaway

Real-world solutions often combine on-chain metadata with off-chain data, secured by cryptographic hashes.
