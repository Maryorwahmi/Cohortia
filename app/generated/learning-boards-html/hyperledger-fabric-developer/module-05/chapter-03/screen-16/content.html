Key Concepts

Essential Terms to Remember

Chaincode Events

A mechanism for chaincode to publish notifications about significant state changes or occurrences on the ledger to interested client applications.

`stub.SetEvent()`

The chaincode API used to emit an event with a specified name and payload, signaling a state change to external applications.

Event Listener

A component in a client application (using Fabric SDKs) that subscribes to and processes chaincode events in real-time.

Chapter Summary

Chaincode events provide a powerful, real-time mechanism for smart contracts to notify client applications about significant occurrences on the ledger, enabling reactive and integrated solutions.
