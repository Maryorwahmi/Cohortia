Triggering Events from Your Smart Contract

Using `stub.SetEvent` to Publish On-Chain Occurrences

The `stub.SetEvent()` API

err = stub.SetEvent("eventName", payloadBytes)
  • •`eventName`: A string identifier for the event type (e.g., "assetTransferEvent").
  • •`payload`: A byte array, typically a JSON string, containing event-specific data.

Event Payload Details

  • •Payload should be a JSON string for easy parsing by client applications.
  • •Include all relevant data for the event, such as IDs, new states, or timestamps.
  • •Example: `{"assetID": "asset123", "newOwner": "Org2", "amount": "500"}`.
Concrete Example

After a successful asset transfer, emit an event with the asset's new owner and transfer amount.

Common Mistake

Forgetting to marshal the payload into a JSON byte array, leading to parsing errors on the client side.

Key Takeaway

`stub.SetEvent` is how chaincode proactively communicates critical state changes to external applications.
