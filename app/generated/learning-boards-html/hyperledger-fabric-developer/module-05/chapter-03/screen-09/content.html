Chaincode Event Emission: Go Example Walkthrough

A Step-by-Step Look at Emitting a Custom Event

func (s *SmartContract) transferAsset(stub shim.ChaincodeStubInterface, args []string) peer.Response {
    // ... (asset retrieval and update logic)

    // 1. Define event payload
    eventPayload := map[string]string{
        "assetID":        assetID,
        "oldOwner":       oldOwner,
        "newOwner":       newOwner,
        "transferAmount": transferAmount,
        "timestamp":      time.Now().Format(time.RFC3339),
    }

    // 2. Marshal payload to bytes
    eventPayloadBytes, err := json.Marshal(eventPayload)
    if err != nil {
        return shim.Error(fmt.Sprintf("Failed to marshal event payload: %s", err.Error()))
    }

    // 3. Emit the event
    err = stub.SetEvent("assetTransferEvent", eventPayloadBytes)
    if err != nil {
        return shim.Error(fmt.Sprintf("Failed to set event: %s", err.Error()))
    }

    return shim.Success([]byte(fmt.Sprintf("Asset %s transferred from %s to %s.", assetID, oldOwner, newOwner)))
}

Code Explanation

  • •**Payload Definition:** Create a `map[string]string` to hold key-value pairs of event data.
  • •**JSON Marshaling:** Convert the Go map into a JSON byte array, which is the required format for the event payload. Error handling is crucial here.
  • •**Event Emission:** Call `stub.SetEvent()` with the event name (e.g., "assetTransferEvent") and the prepared byte payload.
  • •**Error Handling:** Always check for errors after `json.Marshal` and `stub.SetEvent` to ensure robust chaincode.
Pro-Tip

Design your event payloads to be concise yet comprehensive, providing enough context for clients without being overly large.
