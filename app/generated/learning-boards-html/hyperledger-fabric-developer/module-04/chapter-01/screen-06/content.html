The Fabric Gateway: Your Single Point of Entry

Abstracting Network Complexity for Seamless Interaction

What is a Gateway?

A logical abstraction provided by the SDK that simplifies connecting to a Fabric network.

Key Functions

Manages underlying network communication, including peer discovery, transaction endorsement, and commitment.

Developer Benefit

Reduces complexity, allowing developers to focus on application business logic rather than network intricacies.

Key Takeaway

The Fabric Gateway acts as an intelligent intermediary, simplifying client-network interactions and orchestrating transaction flows.
