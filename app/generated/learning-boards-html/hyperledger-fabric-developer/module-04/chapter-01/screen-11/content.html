The Connection Profile: Mapping Your Fabric Network

How SDKs Discover Network Components

What is it?

A JSON or YAML file that describes the topology of a Fabric network (peers, orderers, CAs, channels).

Its Purpose

Used by the SDK to dynamically discover and connect to the various components of the Fabric network.

Key Sections

Includes definitions for organizations, peers, certificate authorities, and orderers, with their respective endpoints and TLS certificates.

Key Takeaway

The connection profile is the essential configuration that enables your client application to locate and securely interact with the Fabric network.
