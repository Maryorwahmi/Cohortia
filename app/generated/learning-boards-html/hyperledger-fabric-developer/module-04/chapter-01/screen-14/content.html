Key Concepts

Essential Terms to Remember

Wallet

A secure storage mechanism provided by the SDK to hold user identities (certificates and private keys).

Connection Profile

A JSON or YAML file that describes the topology of a Fabric network, used by the SDK to connect.

Contract

The programmatic interface to a deployed chaincode, allowing client applications to invoke its functions.

Chapter Summary

Wallets provide secure identity storage, connection profiles map the network, and contracts define how applications interact with chaincode.
