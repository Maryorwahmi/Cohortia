Event Type

Block Events: Tracking All Ledger Activity

Notified when a new block is added to the ledger.

What are Block Events?

  • Emitted by a peer whenever a new block is successfully added to its ledger.
  • A block contains a collection of validated and committed transactions.
  • Provides a comprehensive view of all activity on a channel.
Key Takeaway

Block events are fundamental for auditing and monitoring, offering a broad perspective on ledger updates.

Common Use Cases

  • **Auditing & Compliance:** Track all transactions in chronological order for regulatory purposes.
  • **Monitoring Tools:** Display real-time ledger activity, block numbers, and transaction counts.
  • **Data Synchronization:** Keep off-chain databases or analytics systems synchronized with the ledger state.
Common Mistake

Using block events for granular business logic reactions; they require parsing all transactions within the block to find specific events.
