Security Considerations

Core Security: Identity Management & TLS Configuration

Protecting client applications and network communications.

Identity Management

  • Never hardcode private keys directly into your application code.
  • Use secure wallet implementations (e.g., encrypted file system wallets, HSMs).
  • Ensure strict access control to your wallet and its contents.
Key Takeaway

Secure identity management and proper TLS configuration are non-negotiable for protecting client applications and network integrity.

TLS Configuration

  • Always use TLS for gRPC connections to peers and orderers.
  • Never use `verify: false` for TLS roots in production environments.
  • Provide trusted root certificates to ensure secure, mutually authenticated connections.
Common Mistake

Using `discovery: { asLocalhost: true }` in production, which bypasses TLS verification and is only suitable for development.
