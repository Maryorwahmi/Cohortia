Ensuring Application Stability

Implementing try...catch...finally for graceful execution and resource management.

Error Handling & Cleanup

  • •try block: Contains the main application logic.
  • •catch block: Handles errors, logs messages, and exits gracefully.
  • •finally block: Guarantees execution for critical cleanup tasks.
  • •Resource Cleanup: Disconnects Gateway and removes event listeners to prevent leaks.
Key Takeaway

Proper error handling and resource cleanup using try...catch...finally are vital for stable and performant Fabric client applications.

errorHandling.jsNode.js
// --- Main application logic (simplified) ---
async function main() {
    let gateway;
    let blockListener;

    try {
        // ... application operations ...
    } catch (error) {
        console.error(`Application encountered an error: ${error}`);
        process.exit(1);
    } finally {
        if (gateway) {
            gateway.disconnect();
            console.log('Gateway disconnected.');
        }
        if (blockListener) {
            network.removeBlockListener(blockListener);
            console.log('Block listener removed.');
        }
    }
}

main();
