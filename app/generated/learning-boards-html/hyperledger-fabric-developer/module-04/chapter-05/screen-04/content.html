Application Overview

Building the Asset Tracker

Integrating core Fabric client operations into a single application.

Application Goal

Develop a basic asset management application (e.g., car or land registry) that interacts with a Hyperledger Fabric network.

Key Takeaway

The Asset Tracker app demonstrates how to unify various Fabric client operations into a single, functional application.

Asset Tracker Capabilities

Create New Assets: Use CreateAsset(id, color, size, owner, value)

Query Existing Assets: Use ReadAsset(id) and GetAllAssets()

Update Asset Owner: Use UpdateAsset(id, newOwner)

Assumes fabcar chaincode deployed on mychannel.
