Retrieving Asset Data

Implementing queryAllAssets and queryAssetById for read-only operations.

Query Mechanism

  • •Use contract.evaluateTransaction() for all read-only calls.
  • •queryAllAssets calls chaincode's GetAllAssets.
  • •queryAssetById calls chaincode's ReadAsset with a specific ID.
  • •Results are byte arrays; parse them to JSON for usability.
Key Takeaway

Queries are read-only operations using evaluateTransaction to fetch data without altering the blockchain state.

queryFunctions.jsNode.js
// --- Query all assets ---
async function queryAllAssets(contract) {
    console.log('
--- Querying all assets ---');
    const resultBytes = await contract.evaluateTransaction('GetAllAssets');
    const result = JSON.parse(resultBytes.toString());
    console.log(`All Assets: ${JSON.stringify(result, null, 2)}`);
    return result;
}

// --- Query a specific asset by ID ---
async function queryAssetById(contract, assetId) {
    console.log(`
--- Querying asset: ${assetId} ---`);
    const resultBytes = await contract.evaluateTransaction('ReadAsset', assetId);
    const result = JSON.parse(resultBytes.toString());
    console.log(`Asset ${assetId} Details: ${JSON.stringify(result, null, 2)}`);
    return result;
}
