The Query Lifecycle

How `evaluateTransaction` retrieves data efficiently.

1. Client Sends Proposal

Application sends a read-only transaction proposal.

2. Peer Executes Chaincode

Endorsing peer simulates transaction against its local ledger state.

3. Result Returned to Client

Execution result is sent directly back; no ledger update occurs.

Key Takeaway

The query lifecycle is optimized for speed, bypassing the full consensus mechanism as no state change is intended.
