Connection Profile & Wallet

Essential components for secure and authenticated access to the network.

Connection Profile (CCP)

  • •**Definition:** A JSON file describing the Fabric network's topology.
  • •**Contents:** Includes peer, orderer, and certificate authority endpoints.
  • •**Purpose:** Guides the SDK on how to connect to various network components.
  • •**Example:** `connection-org1.json` specifies details for Organization 1.
Key Takeaway

The CCP is your application's map to the Fabric network, detailing all necessary connection points.

Wallet & Identities

  • •**Definition:** A secure storage for user identities (e.g., 'appUser').
  • •**Contents:** Cryptographic keys and certificates for authentication.
  • •**Purpose:** Proves who you are and what permissions you have on the network.
  • •**Mechanism:** Used by the Gateway to authenticate client applications.
Common Mistake

Using an identity that doesn't exist in the wallet will lead to authentication failure.
