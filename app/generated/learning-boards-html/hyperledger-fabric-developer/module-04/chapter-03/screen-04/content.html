Core Concept

Querying vs. Invoking

Understanding the two primary ways to interact with chaincode.

Querying the Ledger

  • •**Purpose:** Read-only operations to retrieve current ledger state.
  • •**Method:** Uses `evaluateTransaction` in the SDK.
  • •**Process:** Sends proposal to a single endorsing peer; bypasses ordering service.
  • •**Outcome:** Returns data directly to the client; no ledger modification.
  • •**Efficiency:** Fast and efficient for data retrieval.
Key Takeaway

Use queries for quick, efficient data retrieval without altering the blockchain's state.

Invoking Transactions

  • •**Purpose:** Modify the ledger state (create, update, delete assets).
  • •**Method:** Uses `submitTransaction` in the SDK.
  • •**Process:** Requires endorsement, ordering, and commitment to the ledger.
  • •**Outcome:** State change is permanently recorded on the blockchain.
  • •**Guarantees:** Provides strong guarantees of finality.
Common Mistake

Never use `evaluateTransaction` for functions that intend to modify the ledger state.
