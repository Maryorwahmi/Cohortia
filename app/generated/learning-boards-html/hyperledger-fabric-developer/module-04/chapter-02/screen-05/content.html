Module 4›Chapter 4.2›Install SDK Packages

Step-by-Step Installation

1Initialize Project

Navigate to your project directory and run npm init -y to create a package.json file, which manages your project's dependencies.

2Install SDKs

Execute npm install fabric-network fabric-ca-client to download and add the core Fabric SDK packages to your project.

Why it matters

Installing these packages correctly ensures your Node.js application has the necessary libraries to interact with the Hyperledger Fabric network, enabling functions like transaction submission and identity management.
