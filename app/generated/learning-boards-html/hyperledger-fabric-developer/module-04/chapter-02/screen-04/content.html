Essential Prerequisites

Node.js Runtime

Provides the JavaScript runtime environment for executing your application code. A stable LTS version is highly recommended.

npm (Node Package Manager)

Manages project dependencies, allowing you to install and update necessary SDK packages.

Core SDK Packages

fabric-network

Provides the high-level Gateway API for interacting with the Fabric network, submitting transactions, and querying the ledger.

fabric-ca-client

Used for managing identities by interacting directly with the Fabric Certificate Authority (CA) for enrollment and registration.

Why it matters

A correctly configured environment ensures your application can reliably communicate with the Hyperledger Fabric network, preventing common errors and enabling secure operations. Without these foundational tools, your application cannot interact with the blockchain.

Concrete Example

Imagine building a supply chain application. Without `fabric-network`, your app couldn't submit a transaction to record a new shipment. Without `fabric-ca-client`, you couldn't onboard new participants by issuing them digital identities.

Key Takeaway

Node.js and npm are essential prerequisites, while `fabric-network` and `fabric-ca-client` are the core SDK packages for network interaction and identity management, respectively.
