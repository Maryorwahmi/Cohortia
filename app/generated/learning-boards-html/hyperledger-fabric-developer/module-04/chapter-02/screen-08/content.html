What are Wallets?

Wallets are secure storage mechanisms provided by the Hyperledger Fabric SDK to manage and store user identities. Each identity comprises an X.509 certificate and a private key, essential for authentication and authorization on the network.

Secure Credential Storage

Wallets hold digital identities (certificates and private keys) securely, which are used to prove a user's identity to the Fabric network.

`Wallets` Class

The SDK's `Wallets` class provides an abstraction layer for creating and interacting with various wallet implementations.

Wallet Types
  • FileSystemWallet: Stores identities in a local directory (common for development).
  • InMemoryWallet: Stores identities in memory (suitable for transient use).
  • CouchDBWallet: Stores identities in a CouchDB database (for more robust, persistent storage).
Why it matters

Proper wallet management is fundamental for secure authentication and authorization in a permissioned blockchain network. It ensures that only legitimate users can interact with the ledger.

Key Takeaway

Wallets are essential for securely storing user identities, with `FileSystemWallet` being a practical choice for development environments.
