createWallet.js
const { Wallets } = require('fabric-network');
const path = require('path');

async function createWallet() {
    const walletPath = path.join(process.cwd(), 'wallet'); // 'wallet' directory in current working directory
    const wallet = await Wallets.newFileSystemWallet(walletPath);
    console.log(`Wallet created at: ${walletPath}`);
    return wallet;
}

createWallet().then(() => console.log('Wallet setup complete.'));
Code Breakdown
  • Import `Wallets`: Accesses the SDK's wallet management class.
  • Define `walletPath`: Specifies the local directory where identities will be stored (e.g., `./wallet`).
  • `newFileSystemWallet()`: Asynchronously creates the wallet directory and returns a `FileSystemWallet` instance.
  • Console Log: Confirms the wallet creation and its location.
Security Note

The `wallet` directory contains sensitive cryptographic material. Ensure it is properly secured and not exposed to unauthorized access, especially in production environments.

Key Takeaway

Initializing a `FileSystemWallet` creates a local directory to securely store user identities, which are crucial for authenticating with the Fabric network.
