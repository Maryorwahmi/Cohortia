Key Concepts

Essential Terms to Remember

Node.js SDK Packages

fabric-network (Gateway API) and fabric-ca-client (CA interactions) are core for Fabric application development.

Connection Profile

A JSON/YAML file detailing the Fabric network topology, including peers, orderers, CAs, and TLS certificates for secure connections.

Wallet Types

Different implementations for identity storage, such as FileSystemWallet, InMemoryWallet, and CouchDBWallet.

Chapter Summary

Setting up the Node.js SDK environment involves installing key packages, configuring network connectivity via a connection profile, and managing user identities through various wallet types.
