Peers: Hosting Ledgers and Chaincode

Exploring the fundamental building blocks that store data and execute smart contracts.

Definition of Peers

Peers are network entities that host ledgers and instances of chaincode (smart contracts), forming the backbone of data and logic execution.

Endorsing Peers

Simulate transactions, execute chaincode, and return an endorsement signature, vouching for transaction validity.

Committing Peers

Receive ordered blocks from the Orderer, validate them, and commit them to their copy of the ledger.

Peer Roles in Transaction Flow

1.

Client Proposal: Application sends transaction to endorsing peers.

2.

Endorsement: Endorsing peers simulate, execute chaincode, and sign the proposal.

3.

Commitment: Committing peers validate ordered blocks and update the ledger.

Each peer type has a distinct, yet collaborative, role.
Common Misconception

All peers are identical. In reality, peers have specialized roles (endorsing vs. committing) that are crucial for the transaction lifecycle.
