Client Applications: Gateway to the Network

How users and systems connect to and interact with the Hyperledger Fabric network.

Definition

Software that users and systems employ to interact with the Fabric network, proposing transactions and querying data.

SDKs for Interaction

Utilize SDKs (Node.js, Java, Go, Python) to connect to peers, propose transactions, query the ledger, and receive events.

Key Functions

Propose transactions, query the current state of the ledger, and subscribe to events for real-time updates.

Real-world Connection

Think of a client application as the web or mobile interface you use daily, but instead of a central server, it's interacting with a decentralized Fabric network.
