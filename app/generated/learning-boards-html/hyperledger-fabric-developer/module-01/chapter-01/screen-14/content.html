Module 1 › Chapter 1.1 › Key Concepts
Blockchain
A DLT that links blocks cryptographically to create an append-only chain.
Distributed Ledger Technology
A shared, replicated database maintained by multiple participants.
Immutability
Records are tamper-evident once written; corrections should be explicit and auditable.
Takeaway
These three concepts form the conceptual core: shared copies, cryptographic linking, and tamper evidence. Use them to evaluate if and how DLT fits a problem.
