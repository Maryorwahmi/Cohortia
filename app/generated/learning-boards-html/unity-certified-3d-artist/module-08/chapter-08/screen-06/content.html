Parameter types
Float: continuous values like Speed used for blends or thresholds.
Bool: toggles such as IsGrounded or IsAiming.
Int: discrete states or counters.
Trigger: one-time events for actions like Attack.
Troubleshooting checklist
  1. Verify parameter exists and is spelled exactly as in code.
  2. Check runtime values in Play mode using the Animator inspector.
  3. Confirm transition conditions and threshold ranges align with values sent from code.
  4. Inspect exit time and interruption settings when transitions are delayed.
Concrete example
In FixedUpdate set animator.SetFloat("Speed", inputMagnitude); use a transition Idle→Walk when Speed > 0.1 and Walk→Run when Speed > 0.6.
If Walk never fires, inspect whether Speed is being scaled differently or a Bool gating the transition prevents it.
Common mistake

Assuming parameters automatically match code values. Always test live values and confirm thresholds and units match your code logic.
