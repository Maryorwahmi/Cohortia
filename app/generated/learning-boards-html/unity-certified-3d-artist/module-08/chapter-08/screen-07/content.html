What is a Blend Tree?
Interpolating animations via parameters
1D blends along one parameter such as Speed to smoothly move between Idle, Walk and Run.
2D Freeform Directional uses two parameters, for example Speed (Y) and Direction (X), to position motions in a plane.
Design tip
Place motions at positions that reflect their intended movement. Ensure clips share root intent to avoid popping. Test parameter combinations in Play mode to observe interpolation.
2D Freeform example
Positions: Idle (0,0), Walk Forward (0,0.5), Run Forward (0,1), Walk Left (-0.5,0.5), Walk Right (0.5,0.5).
Parameters: Speed (Y), Direction (X). The tree blends based on the vector composed of these values.
Key Takeaway

Use 2D blending when combining speed and direction. Set precise positions and check boundary cases to avoid unexpected interpolation artifacts.
