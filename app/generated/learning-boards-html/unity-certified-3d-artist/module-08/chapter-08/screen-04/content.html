Module 8 › Chapter 8.8 › Animator Controller
Definition
Animator Controller as a state machine
  • States hold Animation Clips or Blend Trees and represent named behaviors.
  • Transitions connect states; conditions determine when a change occurs.
  • Parameters are variables updated by code or input and used by transition conditions.
Quick checks when animations fail
Animator component has Controller assigned and enabled.
Parameter exists and receives expected runtime values.
Transition conditions are correct and thresholds align with parameter scaling.
Key Takeaway

Model animation around gameplay states and keep parameter naming and thresholds consistent with code updates to avoid mismatches.

Annotated architecture
State examples
Idle, Walk, Run, Jump — each maps to a Clip or Blend Tree.
Parameters
Float Speed, Bool IsGrounded, Trigger Jump trigger the transitions.
Transition example
Idle -> Walk when Speed > 0.1, Walk -> Run when Speed > 0.6.
Misconception
Treating the Animator as a simple clip player can hide logic bugs. Always inspect conditions and whether parameters are updated at runtime before concluding the clip is wrong.
