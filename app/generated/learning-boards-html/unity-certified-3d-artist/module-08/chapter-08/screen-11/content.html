Module 8 › Chapter 8.8 › Diagnosing Failures
Step-by-step checklist
  1. Verify Animator component and Controller assignment.
  2. Observe parameter values in Play mode; confirm code updates them.
  3. Check transitions and condition thresholds for matches.
  4. Inspect Blend Tree positions and root motion settings.
  5. Validate Avatar retargeting and layer masks/weights.
Pro tip

Use the Animator window during Play to both change parameter values manually and watch how transitions occur; this isolates whether the issue is in code or setup.

Exam scenario example
Symptom: Character never transitions from Idle to Walk. Apply checklist: is controller assigned? Is Speed changing? Does transition use Speed > threshold? Is another Bool blocking?
Using this pipeline you can turn a textual symptom into targeted checks and a likely fix within minutes.
Common exam trap
Questions may describe a symptom and several plausible fixes. Use the diagnostic flow to eliminate incorrect choices that do not match the observed parameter and transition behavior.
