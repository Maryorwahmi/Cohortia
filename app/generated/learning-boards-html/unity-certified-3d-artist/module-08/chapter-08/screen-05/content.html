Module 8 › Chapter 8.8 › Animation Clips
Core definition
Animation Clip

A self-contained motion sequence that animates properties on a GameObject or skeletal rig.

Create in Unity: fast iteration for props, UI, and simple adjustments.
Import from DCC: complex character motion and mocap quality movements.
Rig types: Humanoid enables retargeting via Avatar; Generic is rig-specific.
Common mistakes
Forgetting to set the Rig type on import, using Generic when Humanoid retargeting is needed, or assuming imported clips will use the same root motion setup as your character.
Concrete scenarios
Button animation: record directly in Unity for quick tweaks.
Character run cycle: import from DCC and set Rig to Humanoid for retargeting.
Prop swing: lightweight clip in Unity is usually sufficient.
Key Takeaway

Pick clip source based on iteration speed and motion complexity; always verify rig and Avatar settings after import.
