Alpha Channel & Transparency

Ensure the camera clear color has zero alpha and use a RenderTexture format like ARGB32 so exported PNGs retain a transparent background for clean UI compositing.

Checklist:
  • RenderTexture set to ARGB32 or equivalent.
  • Camera clear flags set to Solid Color with alpha = 0.
  • Anti-aliasing tuned to avoid haloing on edges.
Quick test
Place the exported PNG over multiple UI backgrounds to check for halos and verify transparency. If edges look jagged, adjust anti-aliasing and re-export.
Key Takeaway

Alpha-friendly exports are required for flexible icon placement across various UI panels and colors.
