Module 8 › Chapter 8.2 › Orthographic Camera
Definition

Orthographic Projection

Renders objects without perspective distortion, preserving scale and making icon sets consistent across depth.

When to use
Grid-based UI, inventory thumbnails, when consistent scale is more important than apparent depth.
Misconception
Orthographic removes perspective but does not remove shading or material detail; lighting still defines form.
Concrete Example
Set IconCamera to Orthographic and adjust size to frame a 256x256 RenderTexture for a potion model. Save as PNG with alpha for UI use.
Key Takeaway

Orthographic helps produce visually consistent icons; pair it with lighting to keep shapes readable.
