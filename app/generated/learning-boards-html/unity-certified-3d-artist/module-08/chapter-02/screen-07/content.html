Lighting

Three-Point Rig for Icons

  • Key light: primary shape, medium intensity, slightly above the model.
  • Fill light: soft opposite light at lower intensity to reveal shadow details.
  • Back/rim light: thin highlight to separate silhouette from background.
  • Tune shadow softness and intensity to avoid noisy artifacts at small resolutions.
Example adjustment
Increase rim intensity slightly for dark materials so edges read clearly at 64x64, while keeping key/fill balance unchanged.
Pitfall

Different light directions across icon groups breaks UI cohesion; fix by using the same studio rig for all related icons.
