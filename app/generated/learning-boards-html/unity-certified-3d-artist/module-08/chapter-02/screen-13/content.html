Activity

Render a 3D Model to a PNG

  1. Create IconRenderScene and position your model at origin.
  2. Add IconCamera, set Projection to Orthographic, adjust size to frame model.
  3. Create RenderTexture 256×256, ARGB32, Depth ≥ 16, assign to IconCamera.
  4. Add three-point lighting and attach IconRenderer to IconManager.
  5. Use Render And Save Icon to produce PNG in Assets/GeneratedIcons/.
Concrete Result
You should end with a 256x256 PNG with transparent background that imports as a Unity Sprite and displays correctly in a UI Image component.
Key Takeaway

A single successful icon render validates your studio settings and becomes the template for batch exports.
