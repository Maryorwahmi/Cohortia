Module 8 › Chapter 8.2 › Batch Rendering
Process

Automate model iteration and export

  1. Create IconRenderScene with IconCamera and lights; save as studio.
  2. Iterate models: instantiate, set transforms, set iconName, call RenderAndSaveIcon.
  3. Handle errors, verify disk space, and refresh assets after saving each PNG.
Practical tip
Render at 512x512 and downscale to 256 or 64 for different UI sizes to retain crisp details on high-DPI displays.
Check

Spot-check exports for alpha correctness, framing consistency, and lighting before committing the full batch.
