Module 8 › Chapter 8.2 › RenderTexture Pipeline
Architecture

Camera → RenderTexture → Texture2D → PNG

  1. Assign RenderTexture to IconCamera.targetTexture.
  2. Call IconCamera.Render() to draw into the RenderTexture.
  3. Set RenderTexture.active, ReadPixels into a Texture2D, then Apply.
  4. Encode to PNG and write to disk; refresh the editor asset database.
Important settings
RenderTexture size matches target icon resolution; Color Format ARGB32 for alpha; Depth at least 16 bits for correct depth testing.
Key Takeaway

RenderTexture enables deterministic captures from a dedicated studio camera, making batch exports and dynamic icons practical.
