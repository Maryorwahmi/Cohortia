Process

Stage, choose projection, frame

1. Choose a silhouette that communicates the item clearly at small sizes.
2. Select orthographic projection for consistent scale or narrow FOV perspective when subtle depth is needed.
3. Adjust orthographic size or FOV until the model fills the frame without clipping.
4. Save the camera and transforms as a studio preset for batch renders.
Visual guide
Compose so the silhouette fills the icon with a small margin for anti-aliasing.
Common Mistake

Using inconsistent camera distance or rotation across icons causes a disjointed UI; lock studio settings to avoid this.
