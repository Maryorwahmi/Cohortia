Module 8 › Chapter 8.6 › Skill Breakdown
Task List
  1. Create a Canvas and set Render Mode and UI Scale Mode with a 1920x1080 reference.
  2. Add a Slider for Health, set Fill Method to Horizontal and delete the handle.
  3. Add TextMeshPro score text; import TMP Essentials and generate a TMP Font Asset.
  4. Add an Image as an objective marker and set anchors for edge pinning or convert to World Space for floating UI.
Why this matters
  • Predictable layout across screens reduces polish time and bug fixes during QA.
  • TMP ensures text remains crisp and stylable with outlines and gradients.
  • Simple Image-based markers let artists iterate without scripting changes.
  • Keeping the UI hierarchy clean and using atlases improves runtime performance.
