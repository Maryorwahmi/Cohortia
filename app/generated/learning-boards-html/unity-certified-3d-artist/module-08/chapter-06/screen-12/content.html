Module 8 › Chapter 8.6 › TextMeshPro
Essentials

Import TMP Essentials, create TMP Font Assets for chosen fonts, and assign them to TextMeshPro components. Use different atlas resolutions for titles versus body text.

Styling & Icons

Use TMP rich text tags for color and sprite assets to embed icons directly in text. This keeps text and icons batched together when possible.

Practical Setup
  1. Create a TMP Font Asset from a TTF/OTF font file.
  2. Adjust Atlas Resolution and Glyph Padding to avoid bleeding.
  3. Reuse the same asset across UI, change size via the component, not by creating new assets.
Key Takeaway

TMP is the standard for game UI text: generate sensible font assets, reuse them, and embed sprites to keep rendering efficient and sharp.
