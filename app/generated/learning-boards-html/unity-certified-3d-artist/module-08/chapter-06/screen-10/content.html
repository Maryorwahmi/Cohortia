Module 8 › Chapter 8.6 › Canvas Batching
Problem

Full-canvas rebuilds hurt FPS

A single change to many elements can force a Canvas to recompute meshes and textures, increasing draw work and CPU-GPU sync.

Static background
Dynamic HUD (health/score)
Animated menus
Single-icon canvases
Key Takeaway

Isolate high-update UI into small canvases to limit rebuild scope; group static visuals separately for best batching.

Visual Pattern
Canvas Layout Example
Background canvas, HUD canvas for values, small canvases for animated badges.
Misconception
Adding many canvases without thought can be unnecessary. Prefer splitting where contents change at different rates.
Checklist
  • Group static art and rarely-changed layout into one canvas.
  • Place frequently-updated elements (health, score) in small canvases.
  • Avoid expensive masks and nested layouts that trigger rebuilds.
