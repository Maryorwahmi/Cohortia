Objective Markers

Use Image components for icons. Anchor to edges for pinned UI, or use World Space Canvas for floating markers attached to objects. Provide clear icon art and limit runtime layout changes.

Edge-pinned marker
Set anchors to the target edge (for example Min X 0.4 Max X 0.6 and Min Y 0 Max Y 0.1 for a bottom-center marker) and use fixed width/height like 64x64.
World-attached marker
Use a World Space Canvas as a child of the object so the marker scales and rotates naturally with its parent.
Performance rules
Pack icons into sprite atlases, avoid per-frame RectTransform layout changes, and use simple shader passes for UI images.

Checklist
  • Use clear silhouette iconography.
  • Anchor correctly for edge-pinned elements.
  • Pack into sprite atlases and reuse materials.
  • Test across multiple aspect ratios and in busy scenes.
Key Takeaway

Design markers for instant recognition and pack assets for efficiency. Prefer shallow hierarchies and minimal per-frame layout changes.
