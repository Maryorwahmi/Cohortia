Module 8 › Chapter 8.6 › Canvas Scaling
Core Idea

Reference resolution & Match

Define a design baseline and how scaling favors width or height. Use Match to blend behaviors.

Example: baseline 1920×1080, Match 0.5 balances devices; Match 0 favors width-based scaling.
Step Checklist
  • Set Canvas to Scale With Screen Size and choose a Reference Resolution.
  • Adjust Match slider to favor width, height, or balance.
  • Preview multiple aspect ratios in the Game view to validate scale.
Key Takeaway

Reference Resolution and Match keep typography and spacing consistent; combine with good anchors for robust layouts.

Visual Guide
Design Baseline
Reference: 1920×1080. Use this as your artboard when placing HUD elements and defining safe areas.
Match Slider
0 = width-focused, 1 = height-focused, 0.5 = balanced. Choose based on layout orientation.
Practical Tip
If HUD feels cramped on narrow mobile screens, increase safe padding and reduce font size slightly rather than changing anchors.
Try This
Open Game view presets, toggle between 16:9 and 9:16, and tune Match until elements maintain visual weight. Ask: which value minimizes layout shifts?
