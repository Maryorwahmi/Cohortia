Core Concept

Canvas Render Modes

Decide whether UI should be fixed to the screen or exist as a world object. Your choice affects depth, post-processing, and how UI follows scene objects.

Screen Space - Overlay
Default for HUDs and menus. Drawn on top of the scene, ignores camera depth.
Screen Space - Camera
Placed at a distance from a camera so post-processing can affect the UI. Good for cinematic overlays.
World Space
Canvas behaves like a 3D object. Use for nameplates and floating health bars that follow objects in the scene.
Example
A health bar above an enemy should be placed on a World Space Canvas so it moves and scales with the enemy, preserving depth and attachment.
Common Mistake
Using Overlay for world-attached UI makes the element ignore perspective and can break immersion when it should feel attached to a character or object.
Quick Comparison
Overlay
Stable HUDs, menus, no camera influence.
Camera
Camera-relative UI that can receive post-processing effects.
World
UI is a 3D object and can be parented to in-world GameObjects.
Key Takeaway

Choose the Canvas mode by whether the UI must follow a world object, react to camera effects, or stay fixed as a HUD.
