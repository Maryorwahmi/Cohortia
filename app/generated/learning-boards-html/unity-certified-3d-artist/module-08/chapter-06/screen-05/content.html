Anchors & Pivots

Anchors tie an element to parent edges; pivots define its rotation and scale center. Use presets, then fine-tune offsets for padding and spacing.

Step 1: Canvas setup
Set UI Scale Mode to Scale With Screen Size and choose a reference resolution like 1920x1080.
Step 2: Anchor with intent
Use anchor presets to pin to corners or edges. For a top-left HUD element, choose Top-Left anchors and adjust Pos X/Y for padding.
Step 3: Pivot for motion
If the element should scale from its left edge, set pivot X to 0; from center use 0.5. This prevents unexpected shifts during animations.

Common Mistake
Leaving anchors on stretch while setting explicit width makes elements resize unpredictably. Fix by setting anchors to fixed points or identical min/max values.
Key Takeaway

Always choose anchors to express the element's intended relation to its parent, then use pivot to control scale origin.
