Definition RectTransform & Animatable Properties
Animatable properties
  • Scale: micro-interactions like press and hover.
  • Anchored position: slide-ins and drops without changing layout.
  • Rotation: subtle tilts and secondary motion.
  • Color / Alpha: fades, highlights, and emphasis.
Best practices
Avoid animating properties that force expensive layout recalculations like explicit width and height. Instead animate transforms and material properties that GPU can handle efficiently.
Example
Inventory slot eases from Y = +30 to Y = 0 and pulses emissive intensity for 300ms when a rare item appears.
