Process Authoring Animation Clips
Step-by-step pattern to create distinct UI animation clips.
Step 1 — Setup
  1. Create a Canvas and AnimatedButton; set RectTransform size to sensible values.
  2. Open the Animation window and create Button_Normal clip as baseline.
Mnemonic
Baseline, Hover, Pressed, Effect = B H P E.
Step 2 — Record focused clips
Record Hover, Pressed, and ClickEffect as separate clips. Keep each clip short and non-looping unless intentionally continuous.
Example timing
Hover: ~100ms. Press: total ~120–200ms including rebound. ClickEffect: <500ms burst.
Why separate clips? It keeps your Animator Controller modular and makes tuning a single micro-interaction easy without affecting others. If you need a stronger click for a rare reward, adjust only the ClickEffect clip instead of rewriting a long combined timeline.
