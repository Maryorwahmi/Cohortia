Lab Walkthrough Animated Button — Checklist
Step-by-step
  1. Create Canvas and AnimatedButton. Set RectTransform: 200x80.
  2. Record Button_Normal, Button_Hover, Button_Pressed, Button_ClickEffect clips.
  3. Open Animator, add parameters IsHovering, IsPressed, ClickTrigger and transitions.
  4. Add child Particle System; configure single burst, short life, disable by default.
  5. Attach script and assign the particle reference; test in Play mode.
Checkpoint
Hover and click produce expected animation and a single particle burst under 500ms total.
Editor view
Imagine a split view: Animation window to record, Animator window to set transitions, and Scene/Game to preview your timing. Keep the lab focused and iterative.
