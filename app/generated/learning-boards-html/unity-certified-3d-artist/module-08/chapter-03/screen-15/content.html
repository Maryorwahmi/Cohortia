Key Concepts Practical Terms
RectTransform
UI transform controlling anchors, pivot, position and size; animate scale and anchored position for motion.
Animation Clip
A short, self-contained animation like Hover or Pressed that can be reused and blended by an Animator Controller.
Particle System
A visual effect system; for UI use short bursts configured for low lifetime and small particle size.
