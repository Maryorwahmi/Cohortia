Definition Particle Systems for UI
Design rules
  • Duration: ~0.2–0.5s for a burst.
  • Emission: single burst, small count suited to resolution.
  • Size: small motes that don't occlude UI text.
  • Parent to UI element and keep disabled until triggered.
Performance & accessibility
Profile systems when multiple UI elements can fire simultaneously. Provide options to reduce particle density and avoid intense flashes to be considerate of sensitive players.
Example
On click: burst with Start Lifetime 0.5, Start Speed 2, small cone shape, color fades over lifetime.
