Architecture Material Effects & Shader Pulses
How to expose properties
Create a shader with a float property like _EmissiveIntensity. In the material, expose the property and reference it from an Animator or script to animate its value over time.
Example
Animate emissive from 0 → 1 → 0 in 300ms for a pulse when a rare item appears.
Best practices
  • Keep shader math simple for UI materials.
  • Prefer a single uniform for intensity rather than heavy texture lookups.
  • Provide an option to disable complex material effects for low-end devices.
