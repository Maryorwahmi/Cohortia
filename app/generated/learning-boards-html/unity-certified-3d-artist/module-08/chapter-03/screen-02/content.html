Bloom: Learn → Understand → Apply → Master
01 Apply animation principles
Use squash, anticipation, and easing on UI elements for tactile feedback. These principles give motion purpose and communicate intent to the player.
Verified Competency Milestone
02 Use Unity Animator
Create Animation Clips and an Animator Controller for UI states. Drive transitions with booleans and triggers for predictable, reusable behavior.
Verified Competency Milestone
03 Integrate particles & materials
Add particle bursts or shader pulses to amplify important events without dominating the interface.
Verified Competency Milestone
04 Avoid common pitfalls
Keep animations snappy, consistent, and profiled. Avoid over-animation and accessibility issues like intense flashes or motion that causes discomfort.
Verified Competency Milestone
