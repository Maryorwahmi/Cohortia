Architecture Animator Controller for UI
Parameters & States
Create booleans: IsHovering, IsPressed. Create trigger: ClickTrigger. Add states: Normal (default), Hover, Pressed, ClickEffect.
Pattern
Use triggers for one-shot effects and booleans for continuous states like hover.
Pro tip
Make ClickEffect transit from Any State with no exit time so it fires instantly on click.
Transitions
  • Normal → Hover: IsHovering = true, ease-in for attention.
  • Hover → Normal: IsHovering = false, quick ease-out.
  • Hover → Pressed: IsPressed = true, snappy squash animation.
  • Pressed → Normal: IsPressed = false, settle back to default.
Key takeaway
Drive visual state with parameters, not hard-coded timings. This keeps controllers reusable.
