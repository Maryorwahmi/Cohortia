Process Flow Occlusion Culling
Bake occlusion and validate with visualization
Bake steps
  1. Mark large, static geometry as Static so occlusion data includes it.
  2. Open Window → Rendering → Occlusion Culling and switch to the Bake tab.
  3. Set Voxel Size and Backface Tolerance and click Bake.
  4. Use the Visualization tab in Scene view to confirm which objects are culled as you move the camera.
Example
In a multi-room interior, bake occlusion so rooms not visible to the camera aren't rendered, reducing draw and fragment cost.
Visualization tips
Move the Scene view camera and watch the culling overlay: culled objects are not drawn. If dynamic actors are culled incorrectly, ensure they are not marked static or adjust bake settings.
Key Takeaway

Bake occlusion against large static occluders and verify results with the visualization tools to ensure correct culling and improved performance.
