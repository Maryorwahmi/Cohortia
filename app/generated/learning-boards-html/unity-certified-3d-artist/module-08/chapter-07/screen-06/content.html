Process Flow Lighting Bake Workflow
Step-by-step bake checklist
A repeatable sequence for consistent bakes.
Editor Checklist (practice in a simple scene)
// Bake workflow - conceptual steps
1. Identify and mark static geometry: Inspector -> Lightmap Static
2. Place Light Probe Group near dynamic paths and actors
3. Add Reflection Probes in rooms and polished areas
4. Configure Lightmap Parameters: texels per unit, sample counts
5. Run Bake and inspect lightmaps and probe influence
6. Iterate: increase probes or lower resolution based on visual and memory cost
  • Concrete example: mark an interior's walls and furniture as static and place probes at chest height along navigation routes.
  • Misconception: a single probe grid always suffices — probe density matters near high-contrast lighting changes.
  • Takeaway: test in Play mode to verify dynamic objects sample probes correctly.
Example: Interior bake
Mark floor, walls, large props as Lightmap Static. Place probes along corridors. Add one reflection probe per room. Run a low-resolution test bake, adjust, then use final settings for release.
Key Takeaway

Plan static geometry and probes before baking; iterate with quick bakes to converge on quality and performance.
