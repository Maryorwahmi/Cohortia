01 — Lighting Strategy
Decide between real-time, baked, and mixed lighting for a given scene to balance fidelity and runtime cost.
Mnemonic: Bake for static, real-time for motion, probes for the moving parts.
Verified Competency Milestone
02 — Probes & Reflection
Set up Light Probes for dynamic objects and Reflection Probes for PBR materials to match baked lighting.
Mnemonic: Probes fill the gaps between baked and real-time geometry.
Verified Competency Milestone
03 — Modular & Terrain
Create modular assets and use Terrain tools so environments are varied, tileable, and batch-friendly.
Mnemonic: Reuse pieces to scale detail without unique materials.
Verified Competency Milestone
04 — Rendering Cost
Implement LOD, occlusion culling, and batching techniques to reduce draw calls and GPU work.
Mnemonic: Reduce what the GPU must draw, not what you want to see.
Verified Competency Milestone
