Core Concept Real-time vs Baked vs Mixed
Lighting pipeline comparison
Define each approach, example use, and common misconception.
Definitions & Examples
  • Real-time: Dynamic per-frame lighting. Example: player flashlight that must update shadows as you move.
  • Baked: Precomputed lightmaps for static geometry. Example: a static interior with complex indirect light.
  • Mixed: Bake indirect lighting while keeping direct shadows or key lights dynamic for interaction.
Common mistake
Relying on real-time lights for mostly static scenes increases runtime cost unnecessarily.
Editor checklist (practice steps)
// Editor steps - not API calls, just workflow
1. Identify static geometry (walls, floors, large props).
2. Mark those objects as Lightmap Static in the Inspector.
3. Place Light Probes for moving actors near their paths.
4. Configure Lightmap Parameters and run a bake.
5. Play and verify dynamic objects sample probes and look coherent.
Key Takeaway

Bake static light, probe dynamic objects, and reserve real-time for motion to balance fidelity and performance.
