Hands-on Activity LOD & Occlusion Lab
Implement LODs and bake occlusion
Activity Steps
1. Import model; duplicate and reduce detail for LOD0, LOD1, LOD2.
2. Add LOD Group, assign renderers, set transitions (e.g., 70/30/10).
3. Place multiple instances at various distances.
4. Mark static geometry, open Occlusion Culling, set voxel size and bake.
5. Use LOD Debug and Occlusion Visualization to confirm behavior.
6. Measure draw calls before and after changes.
Example expectation
You should see fewer draw calls after static batching and atlas use, and far fewer visible objects when occlusion is effective. LODs will reduce vertex load for distant objects.
Check your understanding

If draw calls do not drop, verify material sharing, static flags, and that LOD renderers are correctly assigned.
