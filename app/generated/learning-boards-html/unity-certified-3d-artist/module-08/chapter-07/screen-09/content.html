Comparison Draw Call Techniques
Static Batching · Dynamic Batching · Texture Atlasing
Static Batching
Combines static meshes that share materials to reduce draw calls. Best for static level pieces like walls, floors, and repeated props.
Mistake: marking everything static prevents dynamic movement and can increase memory usage.
Dynamic Batching
Groups small dynamic meshes at runtime. Useful for many small moving objects but limited by vertex counts and not a silver bullet.
Tip: keep vertex counts low and share simple materials.
Texture Atlasing
Pack many small textures into one to reduce unique materials and enable batching. Carefully choose atlas sizes and mip map settings for target platforms.
Common pitfall: atlases that are too large for mobile memory budgets.
Quick Checklist
Share materials, atlas repeated small textures, mark truly static geometry for static batching, and measure draw calls in the profiler to confirm gains.
