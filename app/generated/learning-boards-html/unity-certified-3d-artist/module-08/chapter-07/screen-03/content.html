Module 8 › Chapter 8.7 › Objectives — Practice
Practical editor skills to practice
Mark Lightmap Static
Prepare static geometry for lightmap baking to capture high-quality indirect lighting offline.
Practice: mark floors, walls, and large props. Then run a small bake to compare cost.
Place Light Probes
Scatter probes where dynamic objects move so they receive believable baked lighting samples.
Practice: place denser probes near player paths and important props.
Bake Occlusion Culling
Mark static geometry for occlusion and choose a voxel size that balances bake time with accuracy.
Practice: build a simple hallway scene and compare frame rendering with and without baked occlusion.
