Module 8 › Chapter 8.1 › Integrating 3D Assets
System flow
Artist provides: particle prefabs, highlight materials, suggested timing and color. Programmer provides: event hooks, pooling, shader parameter control. Together they form a reliable runtime pipeline.
Prefab design
Make feedback prefabs self-contained, parameter-driven, and pool-friendly.
Shader parameters
Expose emissive color or flash intensity instead of swapping unique materials where possible.
Concrete example
Create a CollectibleFeedback prefab with a child Particle System and a short script to auto-return to a pool. Expose color and lifetime so designers can reuse it for different item types.
Collaboration note
Discuss which parameters artists will tune and which values developers will change at runtime to avoid unnecessary asset churn.
