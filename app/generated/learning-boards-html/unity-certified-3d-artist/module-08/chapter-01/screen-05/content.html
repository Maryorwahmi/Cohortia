Module 8 › Chapter 8.1 › Types of Visual Feedback
Compare categories
Screen-space effects
Global cues like vignettes, full-screen tints, and post-processing used for severity or state changes.
World-space cues
Anchored indicators such as floating health, emissive outlines, or interaction highlights on models.
Particle systems
Short bursts, trails, and impact effects that mark location and add tactile satisfaction.
Example: Collectible pickup
Use a particle burst to mark pickup location, swap to an emissive highlight material on the item, and optionally add a small success vignette. Each layer reinforces the event without obscuring gameplay.
Performance tip
Pool particle prefabs and prefer GPU particles for many simultaneous effects.
Check
If the effect causes frame drops, reduce particle count or lifetime before simplifying artistic intent.
