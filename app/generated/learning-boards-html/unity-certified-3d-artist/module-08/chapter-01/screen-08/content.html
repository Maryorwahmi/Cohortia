Module 8 › Chapter 8.1 › Collectible Pickup
Step list
  1. Create a simple mesh (sphere or cube) and assign a renderer.
  2. Author HighlightMaterial with emissive color matching your design language.
  3. Make a Particle System prefab: 20–30 particles, 0.5–1s lifetime, gradient to transparent.
  4. Create CollectibleFeedback root and set particle as child; expose color and lifetime.
  5. Test timing and disable the collectible after playing feedback.
Common pitfalls
  • Particles that last too long after the object is gone.
  • Overly bright emissive that breaks scene lighting.
  • Relying only on color to convey meaning.
Key Takeaway

Precise timing and brief duration make pickups feel satisfying and clear without visual clutter.
