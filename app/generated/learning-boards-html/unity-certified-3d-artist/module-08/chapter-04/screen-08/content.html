Module 8 › Chapter 8.4 › Performance

Reduce draw calls

Use shared materials and texture atlases to batch many UI instances into fewer draw calls.

Shared materials
Use the same material and atlas for health bars so Unity can combine geometry into a single draw call.
TextMeshPro
Prefer TextMeshPro for sharp text, better atlas usage, and improved batching over legacy text components.
Simplify geometry
Avoid excess canvases, masks, and overlays; each adds complexity and can break batching.
Concrete example
If 50 enemies each have a distinct material for their health bar, expect many draw calls. Instead, use a single atlas and material shared by all health bars and update fillAmount per instance.
Misconception
Assuming only visible UI costs performance. Even offscreen UI can add to batch and state costs if canvases are not grouped correctly.
Key Takeaway

Use shared assets and minimal geometry to keep many World Space UI elements affordable in production scenes.
