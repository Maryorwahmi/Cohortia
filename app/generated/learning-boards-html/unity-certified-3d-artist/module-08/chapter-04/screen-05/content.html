Setup steps

Follow these steps in the Unity Editor to make a functional World Space Canvas.

1
Create Canvas & set Render Mode
Change Render Mode to World Space so the canvas exists as a scene object.
2
Adjust RectTransform size & scale
Start with Width 100, Height 10 and then scale down the transform for scene fit.
3
Assign Event Camera
Set the Canvas Event Camera to your main camera so raycasts register correctly.
4
Parent to object
Make the Canvas a child of the object to inherit movement and rotation.
Example: Health bar images
Inside the Canvas add a dark background Image and a green Fill Image set to Filled, Horizontal, Origin Left. The Fill Image's fillAmount will represent current health.

Key Takeaway

Every Canvas must have size and event camera set correctly to be usable in World Space.
