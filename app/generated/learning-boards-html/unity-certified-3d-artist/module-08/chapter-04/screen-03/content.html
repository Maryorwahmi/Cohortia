Implementation Checkpoints

Concrete verifications to run in your Unity scene before the lab demo.

Sizing
Start with RectTransform Width 100 and Height 10 and scale to fit the camera view. Verify readability at gameplay distances.
Parenting
Make the Canvas a child of the object so it follows movement and rotation automatically without manual updates.
Event Camera
Assign the main camera to the Canvas Event Camera to enable raycasts and interaction with world space UI elements.
Billboarding
Implement a script that rotates the Canvas toward the camera while keeping it upright so labels never tilt awkwardly.
