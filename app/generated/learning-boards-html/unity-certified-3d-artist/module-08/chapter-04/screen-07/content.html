RectTransform in World Space

Combine RectTransform size with the object's transform scale to control on-screen size and placement.

Typical starting values
Width: 100, Height: 10, Transform Scale: 0.01 on X/Y/Z, Pivot: (0.5, 0)
Pivot & anchors
Set pivot and anchors so the element stays positioned above the model when parented.
Misconception
World Space width is not pixels — screen size depends on distance and camera FOV unless you adjust scale programmatically.
Scenario
Parent a Canvas to a Capsule and set position Y to 1.5. Use pivot 0.5,0 so the bar sits just above the head. Adjust scale until it appears correct in the Game view.
Key Takeaway

Iteratively tune RectTransform and transform scale, then lock or script scale adjustments for consistent on-screen sizing.
