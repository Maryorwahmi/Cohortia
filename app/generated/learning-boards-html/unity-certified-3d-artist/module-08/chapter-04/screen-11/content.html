Activity: Build the health bar

  1. Create a Capsule as enemy and position it in the scene.
  2. Create a UI Canvas and set Render Mode to World Space.
  3. Set RectTransform Width 100, Height 10, then set Transform Scale to 0.01.
  4. Assign main camera to Event Camera on the Canvas.
  5. Make Canvas a child of the Capsule and position Y around 1.5 with pivot 0.5,0.
  6. Inside Canvas add HealthBarBackground and HealthBarFill images; set Fill to Horizontal for the fill image.
  7. Attach BillboardUI script and assign camera and health fill references.
  8. Play and press the test key to simulate damage and confirm behavior.
Testing checklist
  • Bar faces the camera and remains upright as you move.
  • Fill amount updates when damage is applied.
  • No flicker or z-fighting with the capsule model.
  • Event camera allows pointer events if needed.
Key Takeaway

Follow the sequence and the checklist to produce a reliable World Space health bar for testing and iteration.
