Learning Objectives

Tasks you'll practice and verify in the lab.

Bloom: Learn → Understand → Apply → Master
01
Differentiate Canvas modes
Explain Screen Space - Overlay, Screen Space - Camera, and World Space, and pick the correct mode for HUD or world-anchored prompts.
Mnemonic: Overlay = always on top.
Verified Competency Milestone
02
Implement World Space UI
Create a World Space Canvas, set RectTransform size and scale, and parent it to a scene object so it moves with the object.
Mnemonic: 'Child of object' keeps UI anchored.
Verified Competency Milestone
03
Make UI face the camera
Use a simple billboarding script to rotate the UI toward the camera while preserving upright orientation for legibility.
Mnemonic: Billboard = always readable.
Verified Competency Milestone
04
Optimize and troubleshoot
Apply batching, shared materials, TextMeshPro, and spacing fixes to avoid z-fighting and performance issues.
Mnemonic: Batch, simplify, and test.
Verified Competency Milestone
