World Space UI

Learn how to place UI in the world so it responds to perspective, occlusion, and scene scale while remaining readable and performant.

In this lesson

Set Canvas to World Space, size RectTransform, attach to objects, and make UI face the camera.

Why it matters

World Space UI ties feedback to objects, improving player orientation and immersion in 3D gameplay.

Common pitfalls

Scale mismatch, occlusion, z-fighting, and too many draw calls reduce clarity and performance.

Quick win

Use TextMeshPro and shared materials, and make the Canvas a child of the object it annotates.
