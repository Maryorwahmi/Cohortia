Comparison

Canvas Render Modes

Choose based on whether UI should be independent of scene depth or integrated into it.

Screen Space - Overlay
Always on top, no occlusion. Best for HUDs and menus that must remain visible at all times.
Screen Space - Camera
Tied to a camera's frustum and scales with camera. Use for camera-specific UI.
World Space
UI exists as 3D geometry, can be occluded, and follows scene transforms.
Concrete example
Imagine an enemy with a floating health bar. If it must move with the enemy and be occluded by geometry, use World Space. If you want a persistent life meter in the corner, use Overlay.
Misconception
Assuming World Space guarantees legibility. You must manage scale or script dynamic resizing based on camera distance.
Key Takeaway

Match the Canvas mode to how UI should behave with depth and camera, not only to convenience.
