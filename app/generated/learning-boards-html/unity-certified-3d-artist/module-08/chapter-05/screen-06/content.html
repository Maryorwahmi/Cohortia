Texture Import Checklist
A brief hierarchy of decisions to validate on import.
Albedo
Texture Type: Default. Ensure it has no baked lighting. sRGB (Gamma) typically enabled for albedo in PBR workflows.
Normal Map
Texture Type: Normal Map. Create From Grayscale must be unchecked for pre-baked normal maps to avoid corruption.
Other Maps
Metallic, Roughness/Smoothness, AO: use Linear color space; pack channels when appropriate to save memory.
Quick test

Import the textures, assign them to a Standard material, and inspect shading at neutral lighting. This verifies normal and sRGB/linear interpretations.

Model Import Notes
Check Scale Factor and Normal/Tangent settings. Decide whether to import materials or author them in-engine. Generate colliders only when physics demands it.
Example import checklist
Albedo: Texture Type = Default, sRGB = On, Generate Mip Maps = On
Normal: Texture Type = Normal Map, Create From Grayscale = Off
Metallic/Roughness: sRGB = Off (Linear), Single Channel if packed
Model: Scale Factor = correct units, Normals = Import or Calculate, Tangents = Calculate if needed
Read/Write: Off unless you modify texture at runtime
