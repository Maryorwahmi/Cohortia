Real-time vs Baked
Compare characteristics and choose based on scene dynamics and performance needs.
Real-time Lighting
Dynamic updates, required for moving lights and animated objects; higher runtime cost.
Baked Lighting
Precomputed lightmaps and probes for static scenes — low runtime cost with high fidelity, but not dynamic.
Reflection & Light Probes
Help static and dynamic objects share believable lighting without full real-time GI.
Example Choice
For a mostly static outdoor level, bake global illumination and use a small number of real-time lights for moving actors. Use LODs and baked reflection probes to maintain performance.
Common Mistake

Relying solely on real-time GI for static scenes when baking would give better performance and similar visual quality.

Try this: sketch a lighting plan for a level with static architecture and a few moving NPCs. Decide which objects are baked and which receive real-time lighting.
