Animator Controller Basics
States, transitions, and parameters form the control logic for character animation.
States & Transitions
States reference animation clips; transitions determine when you move between states and how long blends last.
Blend Trees
Blend multiple clips based on parameters (like speed) to achieve smooth continuous motion without many transitions.
Example Drill
Create an idle-walk-run blend tree driven by a single speed parameter. Adjust thresholds and observe motion continuity across parameter ranges.
Misconception Check

Do not use many distinct transitions for smooth locomotion; blend trees handle interpolation more cleanly for parameter-driven movement.
