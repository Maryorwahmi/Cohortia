Exam Formats
Recognize what each format is assessing and how to approach it.
Multiple-choice
Single correct answer. Tests specific factual knowledge such as import settings or shader property names.
Multiple-select
Select all correct options. Look for answers that together form a complete solution; beware partial truths used as distractors.
Scenario-based
Presents an issue and several plausible fixes. Prioritize performance, workflow, and maintainability when selecting the best answer.
Practical drill

Write a concise problem statement for a project bug and list three ranked fixes. Practice converting that into a single best answer under a 90-second timer.

Example Scenario
An open-world scene runs slowly on target hardware. Options include adding LODs, enabling occlusion culling, reducing real-time lights, or writing custom AI. As a 3D artist, select the three artist-focused actions that reduce rendering cost without altering core gameplay.
Correct artist actions
  • • Add LOD groups for distant models.
  • • Use occlusion culling to skip hidden geometry.
  • • Reduce draw calls via texture atlasing and batching.
Common Mistake
Choosing a technically correct but impractical answer, such as writing custom systems that belong to programmers rather than applying artist-level optimizations.
