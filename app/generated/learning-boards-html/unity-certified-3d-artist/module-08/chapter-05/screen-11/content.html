Artist Optimization Toolbox
Techniques within an artist's remit that the exam tests regularly.
Level of Detail (LOD)
Swap lower-poly meshes at distance to reduce vertex processing.
Occlusion Culling
Prevent rendering of objects that are not visible to the camera.
Atlasing & Batching
Combine textures and materials to reduce draw calls and state changes.
Example Assessment Item
Question: Which three techniques should a 3D artist apply to improve performance in a large outdoor scene? Correct answers: LODs, Occlusion Culling, Reduce Draw Calls by Atlasing.
Practical Workflow
Profile, identify heavy meshes and expensive materials, apply LODs, atlas small textures, and bake where possible. Re-profile to measure gains.
