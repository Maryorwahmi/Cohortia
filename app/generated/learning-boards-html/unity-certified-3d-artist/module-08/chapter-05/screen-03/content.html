Actionable Study Steps
Turn objectives into practice habits you can repeat before the exam.
Domain Map

List exam domains and match course chapters to each. Mark 1–5 confidence scores to spot priorities.

Hands-on Checkpoints

Import a model, set up a PBR material from separate maps, and test a small bake or reflection probe to verify results.

Timed Practice

Run two 30–45 minute question sets. Flag uncertain items and practice educated guessing under time limits.

Error Checklist
  • • Normal maps imported as "Normal Map" with "Create From Grayscale" unchecked.
  • • Albedo maps without baked lighting information.
  • • Smoothness correctly mapped or inverted from Roughness when needed.
Quick Reflection

After each practice block, note one decision you changed based on practical tests — that reflection builds judgment.
