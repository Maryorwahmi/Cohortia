Hands-on Activity
Create House_Prefab
  1. Import a house model or use a cube as placeholder.
  2. Drag it into the Hierarchy and add a child cube for the chimney.
  3. Add a Box Collider to the house Game Object and assign materials.
  4. Drag the configured Game Object into Project to create House_Prefab.
  5. Place several instances, change an instance material, and observe the bold override in the Inspector.
  6. Use Overrides → Apply All or Revert All to test propagation.
  7. Create a Prefab Variant of House_Prefab and change only the roof material.
Scenario
Lab Goal
Build a reusable House_Prefab, practice overrides on an instance, and create a RedRoof variant.
Reflection
Question
When you change the base House_Prefab later, which parts will update across all variants and instances?
