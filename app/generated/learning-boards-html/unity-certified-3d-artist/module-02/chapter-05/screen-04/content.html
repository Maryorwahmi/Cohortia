Core Concept
What is a Prefab?
A stored template for configured Game Objects and their settings.
A Prefab stores assemblies: components, children, and property values. It references mesh assets but holds the configured object you reuse.
Key Takeaway

Prefabs centralize configuration so you can update one source and propagate changes to every instance.

Definition Card
Prefab = Configured Game Object Asset
Includes components, children, and default property values that instances inherit.
Concrete Example
Barrel_Prefab
Mesh from barrel.fbx, Rigidbody component, Box Collider, and LOD Group all saved in one Prefab asset.
Misconception
Prefab ≠ simple mesh copy
The Prefab contains configuration and references; the imported mesh remains a separate asset used by the Prefab.
