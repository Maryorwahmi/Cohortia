Core Concept
Prefab Variants
Create variations of a base Prefab while retaining inheritance for shared changes.
Tree_Base → Tree_Autumn
Parent adds shared components; variant overrides leaf materials and color maps.
When to use
When many items share core configuration but need unique details.
Pitfall
Deep variant chains can obscure which Prefab controls a property. Keep variant depth manageable.
Concrete Example
Enemy_Base → Enemy_Ranged / Enemy_Melee
Share health and movement components on the base; add weapon models and AI scripts on each variant.
