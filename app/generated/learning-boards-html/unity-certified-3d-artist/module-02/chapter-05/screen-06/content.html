Comparison
Prefab Asset
Stored in the Project window as a .prefab file. Acts as the authoritative template for instances.
Prefab Instance
Placed in a scene, linked to the Prefab asset, can have local overrides shown in bold in the Inspector.
Apply Override
Save instance changes back to the Prefab asset to affect all instances.
Revert
Discard local changes and return to asset defaults.
Unpack Prefab
Break the link and make the object a stand-alone Game Object.
Concrete Example
Five Barrel Instances
Change color on one instance; the Inspector shows the material color in bold for that instance. Choose Apply to update the master or Revert to restore the original.
Misconception
"Editing one instance updates the asset"
Not true unless you Apply the override. Local edits remain instance-specific until applied.
Key Takeaway

Manage overrides intentionally: apply to share, revert to reset, unpack only when you need a unique object.
