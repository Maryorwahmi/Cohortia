Definition
Overrides
Properties edited on an instance that diverge from the Prefab asset. Shown in bold in the Inspector.
When to Apply
If the change should affect all instances, apply it to the Prefab asset.
When to Revert
If the change is local or accidental, revert to return to defaults.
When to Unpack
Only if you need an unlinked Game Object and are comfortable losing prefab linkage.
Concrete Example
Chimney Color Override
Change the chimney material color on a single House_Prefab instance. Inspector shows color in bold. Apply if every house should have that color; revert if it was only for one scene.
Mistake to Avoid
Applying accidental fixes across all instances can propagate undesired results. Revert when in doubt.
