Practice & Pitfalls
Concrete steps to form a reliable Prefab workflow and avoid common errors.
Workflow Mnemonic
Configure → Save → Place → Manage
Configure
Set components, colliders, and materials on the in-scene Game Object before saving.
Save
Drag the configured Game Object into the Project to create the Original Prefab asset.
Place
Drag Prefab instances into scenes to reuse the setup.
Manage
Use overrides, variants, and nesting to keep assets modular and updatable.
Common Mistakes
  • Not using Prefabs: duplication and inconsistent updates.
  • Unpacking unnecessarily: lose link to master Prefab.
  • Confusing instance changes with asset changes: apply or revert consciously.
  • Over-nesting: keep modular depth manageable.
