Process Flow
Create a Prefab from an Imported Model
1
Import model
Bring mesh into Project window (e.g., barrel.fbx or house.fbx).
2
Drag to Hierarchy and configure
Add Rigidbody, colliders, materials, children, or scripts to the scene Game Object.
3
Save as Prefab
Drag the configured Game Object back into Project to create the Original Prefab asset.
Common Pitfall
If you create a Prefab before adding required components, you'll need to reconfigure the asset or apply changes from instances. Always configure in-scene first.
Example Scenario
House_Prefab Example
Import house model, add chimney child, attach Box Collider, then drag the configured Game Object to Project and name House_Prefab.
Check Your Understanding
Try this
Place several instances of House_Prefab and change a component on the master to confirm propagation.
