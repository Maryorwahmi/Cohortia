01
Define Prefab
You will explain what a Prefab is: a stored template Game Object that includes components and children. This matters because it removes repetitive configuration and enables global updates across scenes.
VERIFIED COMPETENCY MILESTONE
02
Create from Model
You will convert an imported model into an Original Prefab by configuring it in the scene and dragging it into the Project. This preserves configuration while keeping mesh data separate.
VERIFIED COMPETENCY MILESTONE
03
Variants & Nested
You will create Prefab Variants to make family members that inherit from a base, and nest Prefabs to compose complex objects from reusable parts.
VERIFIED COMPETENCY MILESTONE
04
Overrides & Runtime
You will manage overrides in the Inspector and understand runtime instantiation so scripts can spawn Prefab instances during gameplay.
