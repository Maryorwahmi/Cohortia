Safety Note
Saving, Applying & Persistence
After applying overrides, save scenes and the Project, then commit Prefab changes to version control.
Quick Checklist
  • Apply overrides intentionally.
  • Save the scene and Project after changes.
  • Commit .prefab changes to version control.
  • Test across scenes after applying shared updates.
Runtime Note
Runtime Instances
Objects instantiated at runtime reflect the Prefab at spawn time and will not auto-update if the asset changes later.
Why it matters

Treat applying overrides and saving as a deliberate step; it avoids accidental data loss and keeps team collaboration stable.
