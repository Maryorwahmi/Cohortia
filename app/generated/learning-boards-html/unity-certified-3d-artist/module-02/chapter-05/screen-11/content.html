Best Practice
Prefab Organization & Naming
Use clear names and folder structures so teams can find and reuse assets easily.
Naming
Use descriptive names and suffixes such as _Prefab and _Variant.
Folder Structure
Group by type: Prefabs/Props, Prefabs/Vehicles, Prefabs/Characters.
Lean Prefabs
Keep shared configuration in the Prefab and avoid embedding scene-specific data.
Example Structure
Prefabs/Buildings/House_Prefab
House_Prefab and House_RedRoof_Variant live together for easy discovery.
Team Tip
Commit Prefab changes frequently
Test applied overrides before sharing changes to avoid breaking scenes for others.
