Runtime Instantiation
Spawn Prefab instances from script to create gameplay objects on demand.
Developer Example
// Conceptual example of instantiation
GameObject spawned = Instantiate(myPrefab, spawnPosition, spawnRotation);
// spawned now has the components and default values from myPrefab at spawn time
Note: the example shows the idea; actual code will use the project's scripting conventions. Runtime clones are created in the scene and are not Project assets.
Artist Checklist
  • Ensure Prefab includes required scripts and components for runtime behavior.
  • Keep default values tested so spawned objects behave predictably.
  • Consider pooling for frequently spawned objects to improve performance.
Key Takeaway

Runtime instantiation uses the Prefab's current configuration at spawn; existing runtime copies do not auto-update when the asset changes.
