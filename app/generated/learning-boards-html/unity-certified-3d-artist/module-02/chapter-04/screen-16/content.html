Key Concepts Quick Glossary
Occluder / Occludee
Inspector flags that include objects in occlusion baking as occluders or occludees.
Mesh Simplification
Reducing vertices/triangles to lower rendering cost while protecting silhouette.
Frustum Culling
Automatic culling of objects outside the camera view; complements occlusion culling.
Closing takeaway
Use clear asset roles, apply the right tool for each asset, and measure changes with the Profiler to confirm real performance gains.
