Verification Testing Occlusion
Validation checklist
  • Enable Occlusion visualization in Scene view and inspect culled geometry.
  • Walk or fly camera along player paths and watch for sudden disappearance.
  • Confirm dynamic objects are not marked static by mistake.
  • If needed, adjust bake parameters and re-bake.
Example fix
If an NPC disappears when visible, check its static flag. If flagged static, clear it and re-bake. If the issue persists, raise 'Smallest Occluder' so small gaps no longer create culling errors.
Measurement
Compare draw calls and frame time in the Profiler before and after baking to verify the optimization’s impact.
