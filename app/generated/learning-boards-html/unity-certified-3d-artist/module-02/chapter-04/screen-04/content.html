What LOD is

Multiple mesh resolutions are authored and swapped by a runtime rule. The goal is to reduce triangles the GPU must process for distant, low-importance geometry.

Supporting points
  • LOD Group defines slots like LOD0, LOD1, LOD2 and a Culled state.
  • Screen Percentage controls when Unity swaps meshes based on on-screen size.
  • Create distinct visual differences between levels to avoid wasted effort.
Example
A park with hundreds of trees uses 3 LODs so distant trees render as low-poly billboards and close trees keep sculpted detail.
Key Takeaway

Apply LODs where a single asset appears many times at varied distances; tune thresholds to avoid popping and to maximize performance gain.

Common mistake
Creating LODs that are too similar defeats the optimization; create meaningful polygon reduction between levels.
