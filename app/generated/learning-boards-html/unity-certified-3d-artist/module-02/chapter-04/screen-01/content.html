Optimizing Imported Models
Practical Unity techniques to keep scenes performant while preserving visual quality.

This chapter focuses on three tactics: swapping meshes based on camera distance, preventing rendering of hidden geometry, and reducing mesh complexity while keeping silhouettes. Each tactic reduces GPU work, but must be balanced against visual fidelity.

In this lesson
  • LODs: configure LOD Group to swap meshes by screen percentage.
  • Occlusion Culling: bake static visibility so hidden objects stop drawing.
  • Mesh Simplification: reduce triangles while preserving silhouette.
