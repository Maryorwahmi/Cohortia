Process Creating an LOD Group
Step-by-step
  1. Select the model root in the Scene and add the LOD Group component.
  2. Prepare or import high, mid, low mesh variants as child GameObjects.
  3. Drag each mesh's Renderer into the matching LOD slot.
  4. Adjust Screen Percentage sliders to set transition points.
  5. Test by moving the camera and fine-tune to avoid visible popping.
Example
A bench uses LOD0 from 100%–60%, LOD1 from 60%–20%, LOD2 below 20% and Culled under 2% screen size. Adjust until transitions are smooth.
Tuning tips
  • Make LOD changes where detail loss is least noticeable.
  • Avoid many tiny LOD thresholds; use 2–4 levels for most assets.
  • Test on the target platform; mobile devices may need earlier swaps.
Common mistake
Assigning renderers incorrectly or forgetting to include all visible submeshes can cause parts of a model to disappear at runtime.
Key Takeaway

Follow a repeatable series: add LOD Group, assign renderers, set thresholds, test movement, and iterate.
