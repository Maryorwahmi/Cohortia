Process Baking Occlusion
Bake steps
  1. Mark static occluders and occludees in each object's Inspector.
  2. Open Window → Rendering → Occlusion Culling and inspect Object flags.
  3. Adjust 'Smallest Occluder' and 'Smallest Hole' for desired granularity.
  4. Click Bake and wait for computation to finish.
  5. Enable Scene view Occlusion visualization and test camera movement.
Tuning tips
  • Start with medium granularity and reduce values if important occlusions are missed.
  • Increase 'Smallest Hole' if small openings cause too much culling complexity.
  • Re-bake after major scene edits.
Example
In a house scene, set walls as occluders and furniture as occludees. After baking, objects in other rooms should not render when walls block line of sight.
