Core Concept Occlusion Culling
Why use Occlusion Culling

It saves GPU time by preventing draw calls for objects hidden behind occluders like walls or large geometry. Best used in interiors and dense scenes.

Key points
  • Requires a bake step so it only works for static geometry.
  • Frustum culling is complementary; occlusion culling covers hidden objects inside the frustum.
  • Careful bake settings avoid premature disappearance of objects.
Example
A player in room A cannot see furniture in room B; those items will not be rendered when properly baked and flagged static.
Setup reminders
  • Mark large geometry as Occluder Static.
  • Mark furniture and props as Occludee Static if they will not move.
  • Open Window → Rendering → Occlusion Culling and adjust smallest occluder and hole before Bake.
Common mistake
Marking dynamic objects as static to trick occlusion; moving objects will not be handled correctly and can disappear unexpectedly.
