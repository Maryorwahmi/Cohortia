Module 2 › Chapter 2.1 › Pivot Point (Origin)
Pivot Purpose
Define the logical anchor for transforms and animation.
Good pivot examples
Feet for characters, hinge for doors, center for organic props that rotate around their center.
DCC action
Move origin to the logical point and apply transforms so the exported mesh uses that pivot in Unity.
Misconception
Changing pivots only in-engine is possible, but fixing the source keeps skinning and animation aligned.
Concrete Scenario
A door rotates incorrectly because its pivot is centered in the mesh instead of at the hinge.
Fix
Set the origin at the hinge in your DCC tool, apply transforms, then re-export so rotation in Unity looks natural.
Key question: where does this asset logically anchor in the world? Place pivot there before export.
