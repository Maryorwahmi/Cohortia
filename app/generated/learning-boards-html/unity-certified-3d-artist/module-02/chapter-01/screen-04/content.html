Format Comparison
Assess strengths and limitations before export.
FBX — Comprehensive
  • Supports animation, skeletons, blend shapes, materials, and hierarchy.
  • Preferred for rigged characters and animated props.
OBJ — Simple mesh
  • Stores geometry, normals, UVs; no animation or rigging.
  • Great for static props and quick mesh exchange.
GLTF/GLB — Efficient
  • Designed for efficient transmission and PBR-ready materials.
  • Well-suited for web and runtime-optimized assets.
Key Takeaway

Select a format that carries the data you need: animation needs FBX or GLTF, static geometry can use OBJ.

Concrete Example
Decide format for a character and a rock prop.
Character (animated)
Use FBX to export skeleton, skin weights, and animation clips so Unity receives complete rig data.
Rock (static)
OBJ is sufficient if you only need geometry and UVs; avoid FBX overhead if no animation is required.
Common misconception: OBJ carries animation — it does not. For animation choose FBX or GLTF.
