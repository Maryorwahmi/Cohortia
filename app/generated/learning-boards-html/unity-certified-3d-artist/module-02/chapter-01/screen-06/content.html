OBJ Overview
A text-based format for geometry exchange.
What OBJ stores
Vertex positions, normals, UVs, and references to a material file (.mtl). No animation, no rigging.
Practical use
Export static props or environment models where only mesh and UVs are required.
Trade-offs
Simple and readable but requires separate texture management, which can be inconvenient for large projects.
Key Takeaway

Use OBJ for straightforward mesh exchange; avoid it for animated assets.

Concrete Example
Exporting an unanimated rock or a static piece of architecture.
Rock prop
OBJ exports the geometry and UVs. Keep textures alongside the .obj and .mtl files for Unity to link.
Misconception check: OBJ is not a substitute for FBX when animation is required.
