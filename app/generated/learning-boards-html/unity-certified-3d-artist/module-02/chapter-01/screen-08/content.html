Scale Checklist
A step-by-step process to avoid size mismatches.
  1. Set scene units to meters (Unit Scale 1.0).
  2. Model at real-world dimensions using those units.
  3. Apply transforms (bake scale) so object scale becomes 1.0 in object space.
  4. Export with scale = 1.0 or use export scaling only when necessary.
  5. Import into Unity and spot-check dimensions quickly.
Key Takeaway

Consistent units and applied transforms prevent scale surprises and physics/animation inconsistencies in Unity.

Concrete Example
Model a 2 meter column and export correctly.
Export filename: MyColumn_Correct.fbx
Scene units: Meters
Unit Scale: 1.0
Apply Transforms: Yes
Export Scale: 1.0
Misconception check: changing import scale in Unity hides inconsistent source units; fix the source instead.
