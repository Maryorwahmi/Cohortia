Module 2 › Chapter 2.1 › GLTF / GLB
GLTF Overview
Optimized for compactness and runtime.
What GLTF stores
Meshes, PBR materials, animations, and scene graphs in a compact form; GLB packages binary data into one file.
Practical example
Export assets for web viewers or mobile builds where download size and load speed matter.
Considerations
Unity supports GLTF through packages — useful for runtime-focused pipelines but not a blanket replacement for existing FBX workflows.
Key Takeaway

Use GLTF/GLB when you need compact, runtime-friendly assets with PBR materials and animations.

Concrete Example
Publishing an asset pack for a web viewer.
Web bundle
GLTF reduces load cost and bundles PBR materials for consistent appearance across viewers.
Misconception check: GLTF is efficient, but does not automatically replace entrenched FBX pipelines for complex rigs without review.
