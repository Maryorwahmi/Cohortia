Module 2 › Chapter 2.1 › Naming & Organization
Naming Taxonomy
Use clear prefixes and avoid special characters.
Examples
SM_Barrel_01, SK_PlayerCharacter, MAT_WoodGrain — these indicate mesh type and purpose for quick identification.
Export hygiene
Uncheck cameras, lights, and helper objects unless explicitly needed to avoid cluttering the Unity project.
Key Takeaway

A consistent naming scheme accelerates collaboration and prevents import conflicts.

Concrete Scenario
You export a scene with multiple props and materials.
Avoiding conflicts
Use unique names and per-asset folders so materials link clearly and don’t overwrite when re-importing.
Misconception check: descriptive names are not optional—they prevent accidental asset overwrites and confusion.
