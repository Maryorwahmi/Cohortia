Export Steps
A repeatable sequence to validate before exporting.
  1. Set scene units to meters and verify model dimensions.
  2. Place pivot points logically and apply transforms.
  3. Resolve N-gons and non-manifold geometry; triangulate if you need deterministic triangles.
  4. Optimize polygon count for the asset’s intended use.
  5. Name meshes, materials, and clips consistently.
  6. Choose format and adjust export options; exclude cameras/lights if not needed.
Key Takeaway

A rigid checklist prevents avoidable mistakes and makes import results predictable.

Concrete Example — Blender
A sample set of choices for a correct FBX export.
Blender export settings:
- File Type: FBX
- Apply Transform: Yes
- Scale: 1.0
- Include: Selected Objects
- Transform: Apply Unit: Yes
Try exporting a correct file and an intentionally incorrect scale file to train your eye for common import errors.
