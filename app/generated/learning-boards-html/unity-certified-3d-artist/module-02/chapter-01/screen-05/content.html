FBX Overview
Full feature support for complex assets.
What FBX stores
Mesh geometry, UVs, materials, skeletons, skin weights, blend shapes, animations, cameras, and lights (toggle during export).
Practical example
Export a rigged character with walk and idle animations. FBX preserves skeleton and clips so Unity can play them directly.
Caveat
Embedding textures simplifies small projects but increases file size and reduces texture-edit flexibility.
Key Takeaway

Use FBX for assets that must carry animation, rigging, or scene hierarchy into Unity intact.

Export Decision
Questions to ask before exporting an FBX.
  • Does the asset need a skeleton or animation clips?
  • Will you edit textures externally after export?
  • Do you require scene hierarchy preservation?
Misconception check: FBX is not always the smallest on disk; prioritize data fidelity when rigging matters.
