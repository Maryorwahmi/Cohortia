Understanding 3D Model Formats & Export
How the format and export settings you pick in Blender, Maya, or 3ds Max affect import behavior in Unity.
In this lesson
Compare FBX, OBJ, and GLTF; learn export checks for scale, pivot, triangulation, and naming; and export a correct and incorrect FBX to observe the difference.
Why it matters
Correct exports save time, avoid visual glitches, ensure animations import, and keep build sizes predictable.
Explore Key Topics
Format choice
Pick FBX for animation, OBJ for simple meshes, GLTF for efficient runtime transfer.
Export checks
Units, pivot, apply transforms, triangulate, and exclude helpers you don’t need.
Naming & pipeline
Clear names and consistent conventions reduce conflicts and speed teamwork.
Visual Concept
FBX — Full data
Geometry, UVs, materials, skeletons, blend shapes, animations.
OBJ — Simple mesh
Geometry and UVs only; no animation support.
GLTF/GLB — Efficient runtime
PBR-ready, compact, and fast to load for web and real-time uses.
A quick mental model: FBX for rigs and animation, OBJ for static geometry, GLTF for optimized real-time transfer.
