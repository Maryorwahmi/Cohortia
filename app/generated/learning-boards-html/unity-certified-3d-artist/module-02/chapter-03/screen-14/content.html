Module 2 › Chapter 2.3 › Key Concepts
Materials Tab
Controls how Unity creates, finds, and extracts materials for an imported model.
Texture Type
Selects how Unity interprets the image data: Default, Normal Map, Sprite, etc.
sRGB
Enable for color textures like Albedo; disable for data textures such as normal or metallic maps.
Takeaway

Treat import settings as part of your art pipeline: extract when you need editability, set texture roles correctly, and test on target platforms.
