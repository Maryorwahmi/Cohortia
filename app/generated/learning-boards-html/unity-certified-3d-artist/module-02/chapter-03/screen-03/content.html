Why these steps matter

Making these choices during import prevents later rework. If materials are left embedded you cannot adjust shader parameters in Unity. If texture types or sRGB are wrong, lighting and color will be incorrect. Compression and mip map decisions directly affect runtime memory and visual quality, so they must fit your platform targets.

Mnemonic
Create → Extract → Configure → Validate.
Pitfall
Skipping extraction locks materials inside the FBX and forces re-exports for edits.
