Compression Options
Common schemes include DXT1/DXT5 for PC, PVRTC/ETC/ASTC for mobile platforms. Choose by platform and whether alpha is needed. Use quality settings to tune artifact levels.
None
Highest quality and memory usage; use sparingly for key textures.
Normal / High Quality
Balanced compression with reasonable fidelity for many assets.
Practical Example
For a mobile build, test textures with ETC or ASTC and compare sizes and visual results. For PC builds, DXT formats are a good default. Always inspect compressed normal maps and albedo textures for visible banding or artifacts.
Check
Use platform overrides in the texture inspector and compare build sizes and in-scene look.
Mistake
Using a single universal compression setting leads to suboptimal results on some platforms.
