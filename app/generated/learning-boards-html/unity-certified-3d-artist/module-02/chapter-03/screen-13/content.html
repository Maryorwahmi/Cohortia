Module 2 › Chapter 2.3 › Common Import Mistakes and How to Fix Them
Top Mistakes
  • Not extracting embedded materials, leaving them uneditable.
  • Normal map imported as Default with sRGB enabled.
  • Disabling mip maps on 3D textures causing shimmering.
  • Using uncompressed textures everywhere inflating builds.
Fixes & Checks
Extract materials, set correct Texture Type and sRGB, enable mip maps where appropriate, and apply platform compression. Use a quick visual check in Scene view to confirm results.
Example Fix
If normals are wrong, re-open texture import, set Normal Map type, disable sRGB, and Apply.
Maintenance
Adopt naming conventions so Material Search can find and reuse existing assets automatically.
