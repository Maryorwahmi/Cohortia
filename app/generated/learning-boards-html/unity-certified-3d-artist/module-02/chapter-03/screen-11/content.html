Module 2 › Chapter 2.3 › Wrap Mode, Filter Mode & Aniso Level
Wrap Mode
Repeat vs Clamp: Repeat for tiled patterns, Clamp for single textures or decals.
Filter Mode
Point for crisp pixels, Bilinear for smooth scaling, Trilinear for smoother mip transitions.
Aniso Level
Improves clarity at glancing angles. Useful for terrain and long surfaces viewed obliquely; costs performance on some devices.
Example
Set higher Aniso on floor/albedo textures in a racing game to keep road detail readable at angle.
Avoid
Using high Aniso indiscriminately increases GPU cost on mobile hardware.
