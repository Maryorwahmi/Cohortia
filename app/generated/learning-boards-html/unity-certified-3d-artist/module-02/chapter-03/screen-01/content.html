Material & Texture Import Configuration

Learn how Unity reads materials embedded in model files, how to extract them for editing, and how to set texture types and compression for the right balance of quality and performance.

In this lesson: Materials tab, extract workflow, texture types.
Why it matters: Editability and performance for runtime builds.
Explore Key Topics
Materials Tab
Controls how Unity creates or finds materials for an imported model and offers extract tools.
Texture Type & sRGB
Pick Default for Albedo, Normal Map for normal textures, and enable or disable sRGB depending on data type.
Mipmaps & Compression
Generate mip maps for 3D textures and choose platform-specific compression to reduce memory and build size.
Visual Concept
Static illustration
Imported Model
FBX file may contain embedded materials and textures. Unity can recreate or link to existing assets in your project.
Extracted Assets
Extracting creates .mat and texture files you can edit. This enables shader changes and texture reassignments without re-exporting the model.
Texture Settings
Texture Type, sRGB, Mip Maps and Compression all determine rendering accuracy and memory use.
Runtime Balance
Good import settings keep visuals faithful while reducing memory and build size across platforms.
