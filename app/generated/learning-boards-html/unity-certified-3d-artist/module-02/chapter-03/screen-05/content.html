Definition & Modes

Material Creation Mode

Options include "From Model's Material", "PBR (Physically Based Rendering)", "Standard (Legacy)", and "None". Each affects whether Unity generates materials and which shader defaults are used.
From Model's Material
Recreates materials from the FBX metadata. Best when your DCC names and sets materials consistently.
PBR / Standard
Forces materials to use Unity PBR or Standard shader; useful when you want consistent shader behavior across assets.
None
Prevents material creation. Use when you control material assignment manually from a project library.
Practical Example
If you import a modular environment set and allow auto-creation, Unity often produces separate materials per mesh leading to many similar materials. Instead, set Material Search to match by base texture name or set creation to "None" and assign your canonical materials. This keeps the project clean and ensures shader parameters remain consistent.
Check
After import, look in Project window for duplicated .mat files to verify your search settings worked.
Mistake
Relying on default creation in large projects leads to scattered material variants that are hard to maintain.
