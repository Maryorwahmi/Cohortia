Module 2 › Chapter 2.3 › Hands-on: Import, Extract, Configure, Validate
Steps
  1. Import an FBX with Albedo and Normal textures.
  2. Open Materials tab and click "Extract Materials..." into Assets/Materials.
  3. Set Albedo: Texture Type = Default, sRGB = enabled, Generate Mip Maps = on.
  4. Set Normal: Texture Type = Normal Map, sRGB = disabled, Generate Mip Maps = on.
  5. Choose compression per platform and click Apply on each texture.
Validation
Assign the material to a simple sphere and move the directional light to ensure normals and color render as expected.
Notes & Pitfalls
Remember to apply changes in the Inspector. If the normal map still looks wrong, re-open the texture, confirm Texture Type, and ensure sRGB is disabled. Organize extracted assets into predictable folders to avoid accidental duplicates.
Quick Tip
Use a standard test geometry like a sphere to compare material changes quickly.
Common Mistake
Forgetting to disable sRGB on normal maps is the most frequent reason for poor normal map results.
