Module 2 › Chapter 2.3 › Extracting Materials and Textures
Step-by-step
  1. Select the imported FBX in Project window and open the Materials tab in the Inspector.
  2. Click "Extract Materials..." and choose a folder such as Assets/Materials to save .mat files.
  3. Locate the created .mat files and open them to change shader properties or assign different textures.
  4. For textures, use "Extract Textures..." to generate image files you can set Texture Import Settings on.
Best Practice
Extract into organized folders and remove duplicates; this keeps your project assets clean and editable.
Concrete Scenario
You import a vehicle with embedded materials but want to use a specific car paint shader in Unity. Extract the materials, open the .mat, switch to your paint shader, and tweak metallic and smoothness until it matches the desired look—no DCC re-export required.
Check
Verify that extracted textures are referenced by the .mat and accessible in Project window.
Pitfall
Extracting into many scattered folders creates maintenance headaches; consolidate extracted assets.
