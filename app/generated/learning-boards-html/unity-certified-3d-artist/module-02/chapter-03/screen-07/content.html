Module 2 › Chapter 2.3 › Texture Import Settings — Overview
Primary Settings
Texture Type
Default, Normal Map, Sprite, Lightmap, HDR. Choose the one that matches texture purpose.
sRGB (Color Texture)
Enable for Albedo; disable for data textures like normals, metallic, or height maps.
Generate Mip Maps
Enable for 3D textures to improve visual stability and reduce GPU bandwidth at distance.
Support & Examples
UI sprite: Texture Type = Sprite, sRGB enabled, mip maps disabled, point or bilinear filter for crisp pixels. Normal map: Texture Type = Normal Map, sRGB disabled to preserve vector data. Albedo: Default with sRGB enabled, mips on, and platform compression as appropriate.
Key Takeaway
Every texture needs role-based settings; a one-size-fits-all approach causes visual or performance problems.
Common Mistake
Leaving Normal Maps as Default and sRGB enabled breaks lighting calculations and surface detail.
