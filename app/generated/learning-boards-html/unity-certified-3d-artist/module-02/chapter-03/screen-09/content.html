Module 2 › Chapter 2.3 › Mip Maps: Purpose and When to Use Them
Why Mip Maps

Reduce aliasing and bandwidth

Mip maps provide smaller precomputed versions of a texture so GPUs can sample an appropriate level. They prevent shimmering and save bandwidth at distance.

When to enable
Enable for most 3D surface textures like terrain, props, and characters. Disable for UI and pixel art.
Concrete Example
A distant city wall without mip maps will exhibit aliasing and cause the GPU to sample full-resolution texture repeatedly. Enabling mip maps gives the GPU smaller textures to use at distance and reduces both aliasing and bandwidth.
Key Takeaway
Mips improve stability and performance; prefer them for 3D assets.
Exception
Disable for UI sprites or pixel-art where mip smoothing would blur desired sharp edges.
