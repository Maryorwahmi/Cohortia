Module 2 › Chapter 2.2 › Lab Walkthrough
Steps
Follow this guided sequence to learn by doing.
  1. Import MyFirstProp_IncorrectScale.fbx into Project.
  2. Drag into Scene and compare to a reference character or grid.
  3. Adjust Scale Factor until size matches the reference and Apply.
  4. Import MyFirstProp_Correct.fbx and confirm Scale Factor 1.
  5. With the correct asset selected, toggle Mesh Compression and note visual and size changes.
  6. Toggle Read/Write Enabled only if runtime deformation will be used.
Checkpoints
Checkpoint 1: Scene-scale matches reference after Scale Factor adjustment.
Checkpoint 2: Compression set to acceptable quality level with observed filesize savings.
Checkpoint 3: Read/Write enabled only if your scripts require vertex access.
Reflection

Which setting changed the asset most noticeably? Record the chosen values as a baseline for future imports.
