Module 2 › Chapter 2.2 › Accessing Import Settings
Process
A compact workflow to inspect and apply import changes without breaking the pipeline.
1
Import the asset into Project
Drag FBX/OBJ into Project window to create an asset entry.
2
Select and open the Model tab
Inspect Scale Factor, Compression, Read/Write, and other mesh settings.
3
Drag into Scene and preview
Evaluate scale, normals, and collider presence visually before applying changes.
4
Adjust settings and Apply
Make all edits then press Apply to reimport the asset with new options.
Key Takeaway

Confirm scale and visuals in the Scene before and after applying Model tab changes to avoid repeated reimports.

Supporting notes
  • Misconception: Unity always fixes units automatically — it may try, but verify.
  • Example: Import a prop exported in centimeters and check Scale Factor if it appears tiny.
  • Pro tip: Apply only once after multiple edits to avoid needless reimports.
Scenario
You import a chair that looks 1/10th scale. Adjust Scale Factor and reapply until the model matches human scale in Scene view.
