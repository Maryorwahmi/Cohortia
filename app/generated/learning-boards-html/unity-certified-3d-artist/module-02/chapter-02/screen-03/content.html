05 • Test compression visually
Cycle through Off, Low, Medium, High to find a balance between file size and artifacts for each asset.

06 • Read/Write: enable only when needed
Understand the memory cost of doubling mesh storage and enable it only for deformation or CPU-side scripts.
VERIFIED COMPETENCY MILESTONE
07 • Decide collider strategy
Choose mesh colliders for precise static geometry, primitives for moving objects to save performance.
VERIFIED COMPETENCY MILESTONE
08 • Normals & Tangents decisions
Prefer 'Import' if your DCC exported correct data; use 'Calculate' only when necessary.

Quick checklist
  • Confirm DCC unit & export scale before changing Scale Factor.
  • Preview compression at multiple levels for the same model.
  • Enable Read/Write only when your script needs vertex access.
  • Generate Lightmap UVs for any object that will be baked.
