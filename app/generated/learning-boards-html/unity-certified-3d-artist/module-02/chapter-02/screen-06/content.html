Compression Levels
Understand Off, Low, Medium, High and their impact on size and artifacts.
Off — highest quality, largest size. Use for characters and deforming meshes.
Low — small savings with minimal artifacts. Good default for many props.
Medium — moderate savings; inspect for visible artifacts.
High — greatest savings, risk of visible detail loss on smooth surfaces.
Testing approach
  1. Pick a representative asset and set compression to Off.
  2. Toggle Low, Medium, High and observe visual changes in Scene view under normal lighting.
  3. Check Inspector for reported filesize and memory changes to weigh trade-offs.
Misconception
Compression only affects build size — it also affects runtime vertex fidelity and can create shading artifacts.
Key Takeaway

Balance compression with visual need: environment props tolerate more compression than characters and finely detailed meshes.
