Practical mnemonics
Scale: 1 unit = 1 meter — think meters when in doubt.
Read/Write: enable only when you need CPU-side mesh edits at runtime.
Colliders: use mesh colliders for static geometry, primitives for moving objects.
Lightmap UVs: ensure UV2 for baked lighting or generate them for static assets.
