Diagnostic steps
Follow this order to find the root cause quickly.
  1. Scale: confirm DCC units and Scale Factor.
  2. Memory: check Read/Write and disable if not needed.
  3. Physics: inspect colliders and replace mesh colliders on moving objects.
  4. Visuals: test compression levels for artifacts.
  5. Lighting: ensure UV2 exists for baked lightmaps.
Common fixes
Incorrect scale → check DCC export units, then adjust Scale Factor as a fix.
High memory → disable Read/Write for static meshes.
Physics slowdown → replace Mesh Colliders with primitive colliders for moving objects.
Key Takeaway

Use a consistent diagnostic order and conservative defaults. Enable costly features only when asset requirements require them.
