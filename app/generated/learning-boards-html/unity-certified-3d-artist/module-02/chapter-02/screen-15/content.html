Module 2 › Chapter 2.2 › Key Concepts
Import Settings Window
Panel where mesh properties are configured for import.
Scale Factor
Multiplier to map exported units to Unity units.
Mesh Compression
Reduce size with quality trade-offs; test per asset.
Read/Write Enabled
Enable only when scripts require CPU-side mesh access.
Generate Colliders
Mesh Colliders are precise but expensive; use for static geometry.
Generate Lightmap UVs
Create UV2 for baked lighting or author UV2 in DCC for high quality.
Keep this checklist handy: Scale, Compression, Read/Write, Colliders, Normals/Tangents, Lightmap UVs. Verify each during import to avoid common problems.
