Module 2 › Chapter 2.2 › Generate Colliders
Decision flow
Choose the collider type based on object motion and required precision.
Static, precise surfaces → Mesh Collider acceptable.
Moving objects → use Box/Sphere/Capsule colliders or composite primitives.
Performance pitfall → avoid Mesh Colliders on Rigidbody-driven objects.
Concrete scenario
You import a detailed medieval gate. For the static gate embedded in terrain, generate a Mesh Collider to allow precise player walking. For an animated swinging gate, add a simplified capsule or box collider to the moving part to preserve performance.
Misconception
Mesh Colliders are always correct — they are correct but expensive. Use them selectively for static precision only.
Key Takeaway

Prefer primitive colliders for moving objects. Reserve Mesh Colliders for static geometry that needs exact collision.
