Module 2 › Chapter 2.2 › Scale Factor
Definition & Example
Scale Factor multiplies model vertices at import to map DCC units to Unity units.
Example: 100 cm in DCC → Scale Factor 0.01 → 1.0 Unity unit
Check
Drag the asset into the Scene and compare with a character model or grid to validate size.
Misconception
Don't rely on Unity to auto-correct units. Confirm DCC export and use Scale Factor intentionally.
Practical steps
  1. Export from DCC with correct unit settings where possible.
  2. If scaling is wrong, change Scale Factor and Apply.
  3. Verify placement and physics interactions in Scene view.
Key Takeaway

Align DCC units with Unity. Use Scale Factor only to correct an export mistake and always validate visually.
