Module 2 › Chapter 2.2 › Normals & Tangents
What they are
Normals control lighting direction; tangents allow correct normal map application.
Import — keep DCC-provided normals/tangents when artist-authored.
Calculate — let Unity recalculate when import data is missing or broken.
None — rarely used except when procedural data is generated later.
Testing hints
  • View the model under directional lighting to reveal normal artifacts.
  • Toggle normal maps to ensure tangents align correctly with shading.
  • For animated assets, confirm shading across poses to avoid seams.
Misconception
Calculate isn't a universal fix. Artist-authored normals usually produce the desired shading for characters and stylized assets.
Key Takeaway

Prefer Import for authored normals and tangents. Use Calculate only when necessary and test under animation and lighting.
