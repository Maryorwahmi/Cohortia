Module 6 › Chapter 6.2 › Grid & Surface Snapping
Grid Snapping
Set Move Snap values in Snap Settings to lock transforms to a grid. Useful for tiles and repetitive architecture.
Practical
When building floors and walls, grid snapping prevents small spacing errors that compound across repeated pieces.
Surface Snapping
Use physics drops, collider contact, or custom projection tools to make props rest naturally on uneven surfaces.
Example: drop a barrel onto sloped cobbles and then nudge rotation so it reads as resting, not slipping.
Mistake: relying on grid snapping on sloped surfaces results in floating or clipped objects; use surface methods instead.
