Module 6 › Chapter 6.2 › Prefab Workflow
Prefab lifecycle
Create a base GameObject, configure components and materials, then drag it into Project to create a Prefab asset. Use instances to populate scenes.
When to edit Prefab asset
Change an asset when you want consistency across scenes. Use instance overrides when only one placement needs variation.
Performance note: Prefabs enable easier batching and instancing optimizations.
Concrete example
Create a barrel with a collider and a material, drag it to Project to make a Prefab. Place many instances. Later change the material on the Prefab to update all barrels at once.
Common Pitfall
Forgetting that instance changes are overrides can lead to inconsistent props across a scene. Prefer editing the Prefab asset for global changes.
Key Takeaway
Prefabs are the backbone of scalable dressing — use them to keep edits manageable and consistent.
