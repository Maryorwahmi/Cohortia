Quick Reference: Snapping Modes
Vertex Snapping (V key)
Snap an object's pivot to a target vertex for exact joins. Use for modular architecture and stacked objects.
Grid Snapping
Set move snap values in Snap Settings to lock movement to a grid for uniform spacing.
Surface Snapping
Drop objects onto colliders or use custom surface projection to conform props to uneven terrain.
Practical checklist
  • 1. Choose snapping mode appropriate to the task.
  • 2. Align a base piece first, then place supporting props.
  • 3. Duplicate with offsets, then visually inspect from camera angles.
  • 4. Use small manual nudges to avoid perfectly even spacing for organic feel.
Example
Build a corner by vertex-snapping two wall sections, grid-snap the floor tiles, and then place barrels using surface checks so they conform to small height offsets.
Common Mistake
Relying only on one snapping mode can create hidden overlaps or gaps. Always verify visually.
