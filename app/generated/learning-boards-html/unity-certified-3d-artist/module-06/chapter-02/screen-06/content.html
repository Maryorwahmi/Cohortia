How Vertex Snapping Works
Snap a selected object's pivot to a vertex on another object for perfect contact points when assembling modular parts.
Practical steps
  1. Set clean pivots in your modeling package or use Unity's pivot tools.
  2. Select the object, hold the vertex snap key, drag to target vertex.
  3. Verify rotation and scale before snapping to avoid mismatch.
Pro tip: make small test snaps and then cancel to see how the pivot aligns before committing.
Example scenario
You have a modular wall and a window trim. Vertex-snap the trim pivot to a window corner vertex so the trim sits flush without manual numeric adjustment.
Common Mistake
Snapping without checking pivot placement leads to off-center or rotated joints. Fix the pivot first.
Key Takeaway
Vertex snapping is precise but depends on correct pivot and consistent scale — treat it as a precision tool, not an automatic fix for poorly authored assets.
