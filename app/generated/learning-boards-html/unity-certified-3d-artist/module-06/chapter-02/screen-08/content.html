Module 6 › Chapter 6.2 › Duplication Patterns
Shortcuts & Workflows
Use Cmd/Ctrl + D for quick copies, and Cmd/Ctrl + Shift + D for controlled duplicates placed at the same position for offsetting.
Cluster Duplication
Group 3–5 varied props, make the group a Prefab, then duplicate that prefab to produce believable clusters without repetitive artifacts.
Pro tip: when duplicating many items, vary scale within a small range (0.9–1.1) and rotate on Y to break symmetry.
Example workflow
Create a crate cluster, save as Prefab. Duplicate the cluster, scatter with small offsets, then adjust one instance if needed for a unique detail.
Key Takeaway
Cluster-based duplication preserves variation while minimizing authoring time and maintaining editability via Prefabs.
Watchout
Excessive unique models are expensive; cluster duplication provides a middle ground between repetition and full uniqueness.
