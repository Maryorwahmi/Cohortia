Module 6 › Chapter 6.6 › Lab Walkthrough
Follow these specific editor steps to reproduce the scene and test occlusion culling.
Build the scene
Floor plane, four walls, ceiling, large pillar, several small props behind pillar.
Mark static flags
Walls/pillar -> Occluder Static. Props -> Occludee Static (if static).
Open Occlusion Culling
Window > Rendering > Occlusion Culling, Bake tab.
Bake and inspect
Click Bake, then Visualization and Scene Draw Modes to verify culling.
Tip: If results are unexpected, toggle material opacity and re-check static flags before retuning bake values.
