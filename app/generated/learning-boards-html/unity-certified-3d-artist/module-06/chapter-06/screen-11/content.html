Module 6 › Chapter 6.6 › Runtime Behavior
Baked cells and visibility lists are the core runtime structure.
Camera position maps to a cell. Unity checks that cell's visibility list to skip entire groups of objects, lowering draw calls.
Note: dynamic occluders are not represented in bake; design accordingly.
Example scenario
Player stands in room A. The bake shows room B is invisible because a closed door blocks sight. Objects in room B are not drawn even if they are within the camera frustum.
Key Takeaway

Baked visibility speeds up runtime decisions, but it assumes static scene geometry; moving occluders break that assumption.
