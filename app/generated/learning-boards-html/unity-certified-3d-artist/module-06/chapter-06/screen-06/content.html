Module 6 › Chapter 6.6 › Marking Objects
Follow this numbered workflow to set up your scene for an efficient occlusion bake.
1. Choose occluders
Walls, floors, large pillars — geometry that actually blocks sight.
2. Set Occluder Static
Use the Inspector Static dropdown to mark these objects.
3. Mark occludees
Static props that can be hidden should be Occludee Static for better culling.
Quick checks
  • Don't mark moving actors as occluders.
  • Don't mark transparent materials as occluders.
  • Large occluders give the best return on bake time.
Key Takeaway

Mark only meaningful, static, opaque geometry as occluders and mark static props as occludees to get useful baked results without unnecessary bake cost.
