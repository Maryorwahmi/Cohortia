Core definition

Occlusion culling explained

Precomputed visibility data prevents rendering of objects that are occluded by static opaque geometry during gameplay.

Occluder: Large, static, opaque geometry. Mark as Occluder Static.
Occludee: Objects that can be hidden. Mark as Occludee Static if static.
Dynamic objects are not baked as occludees but are tested against baked cells at runtime.
Example
A pillar in a room hides several decorative props. After baking, the props disappear from the draw list when the pillar blocks them, reducing GPU load.
Misconception
Transparent materials or moving objects cannot be used as baked occluders; marking them as occluder static won't produce correct results.
Key Takeaway

Occlusion culling needs static, opaque occluders and a bake step, but it can cut rendering cost for complex indoor scenes.
