Smallest Occluder / Hole
Tune for precision vs bake cost; lower values increase both.
Backface Culling
Use for single-sided occluders; usually off for solid meshes.
Pitfalls
Transparent occluders, dynamic occluders, and messy overlapping geometry cause errors.
Summary

Use occlusion culling where it matters, validate with visualization, and tune selectively to keep iteration efficient and runtime performance high.
