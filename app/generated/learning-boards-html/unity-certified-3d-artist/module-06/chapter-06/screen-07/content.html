Module 6 › Chapter 6.6 › Bake Settings
Adjust these bake settings carefully to balance precision and build cost.
Smallest Occluder
Minimum size for geometry to be considered an occluder. Lower values increase precision and bake time.
Smallest Hole
Minimum size of gaps that permit visibility through geometry. Smaller picks up tight openings.
Backface Culling
Treats backfaces as transparent; useful for single-sided geometry but usually off for solid meshes.
Min/Max Occluder Distance
Limits how far occluders affect the bake. Helpful to reduce data for distant occlusion relationships.
Start moderate, bake, inspect, then tweak one parameter at a time.
Avoid tiny thresholds for everything — bake times and file sizes rise quickly.
