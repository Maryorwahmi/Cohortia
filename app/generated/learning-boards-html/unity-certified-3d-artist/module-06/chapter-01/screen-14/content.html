Key Concepts

Remember these compact ideas as you iterate in Unity.

Rule of Thirds
Place important elements on grid lines or intersections for balanced framing.
Leading Lines
Use paths or aligned objects to guide the viewer deeper into the scene.
Negative Space
Empty areas define form and mood — use them deliberately to emphasize your subject.
Focal Point
Make one object stand out using contrast, scale, or lighting so attention is immediate.
Visual Hierarchy
Order elements by size, detail and light so the viewer reads them in sequence.
Tangents & Cropping
Perspective issues that confuse silhouettes — fix with small camera or object adjustments.
Key Takeaway

Composition is a toolset: frame intentionally, guide the eye, and iterate in Game view until the narrative reads at a glance.
