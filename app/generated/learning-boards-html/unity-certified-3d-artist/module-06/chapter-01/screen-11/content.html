Tooling Tip

Camera & Overlays

Validate framing in Game view, use overlays for grids, and take iterative screenshots for objective comparison.

Lock the camera

Set a transform for the camera and lock it while composing to avoid accidental edits.

Use temporary overlays

Add a UI canvas grid in play mode or overlay an image in post to check thirds and alignment.

Compare screenshots

Capture alternatives and compare them to choose the clearest read; this reduces bias when iterating.

Quick commands
// Example: workflow notes (non-executable)
1. Frame scene in Game view.
2. Lock camera transform in the Inspector.
3. Toggle props to test negative space.
4. Take screenshot (Game view > Screen Capture).
5. Overlay thirds grid in an editor for comparison.
Concrete example
Widen FOV for environmental shots; tighten FOV for character portraits and test both.
Misconception
Don't assume Scene view is an exact preview — only Game view shows the player‑facing composition.
