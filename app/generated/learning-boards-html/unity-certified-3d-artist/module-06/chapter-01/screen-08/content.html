Visual Hierarchy

Order elements by importance so the player perceives the scene in the intended order.

Primary

Largest, brightest, most detailed element that defines the immediate focus.

Secondary

Supports the story or leads the eye toward the primary element.

Tertiary

Background context with lower contrast and detail.

Implementation tips
  • Scale key objects slightly larger to assert priority.
  • Use saturated color or higher contrast for primary items.
  • Reduce texture contrast and brightness on background assets.
Example
A bright archway larger than surrounding facades signals an entrance and objective.
Common mistake
Lighting every object equally removes hierarchy; create contrast intentionally.
