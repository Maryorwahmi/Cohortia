Assessment & Reflection
Use targeted checks to measure blockout quality and choose next iterations.
Core Questions
  • Does the environment guide the player clearly to objectives?
  • Do sightlines support intended combat or exploration?
  • Does cover create meaningful decisions?
Practical Checks
  • Player capsule fits doorways and platforms.
  • No collision traps or unreachable ledges.
  • Color coding communicates function during tests.
Mini Assessment Activity
Quick Test
Run a 2-minute playtest and write down the top three geometry changes you would make. Prioritize changes that improve navigation or reduce ambiguity.
Reflection Prompt

After testing, which single change will you implement first to improve player clarity?
