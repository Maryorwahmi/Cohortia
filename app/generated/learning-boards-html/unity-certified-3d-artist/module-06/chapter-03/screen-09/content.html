Hands-on Activity
Blockout a Small Arena
Follow the checklist in the chapter to create a functional blockout.
Starter Steps
1. Create Arena_Blockout empty object. 2. Add Plane and scale X=10 Z=10. 3. Place Capsule at (0,1,0) as player.
Build Boundaries
Use Cubes for walls (10x3x0.5). Snap to floor to avoid collision gaps.
Add Cover & Elevation
Mix Cubes and Cylinders as cover. Add a raised Cube platform and verify capsule reachability.
Choke Point & Color Coding
Create a narrow corridor and optionally color-code areas for clarity during tests.
Starter Notes (No code required)
// No code template required for this activity.
// Use Unity Editor: GameObject > 3D Object > Plane / Capsule / Cube / Cylinder.
// Keep transforms simple and test movement frequently.
Playtest Prompt
Walk the capsule through entrances, test cover by standing and crouching, and identify any stuck spots or unfair sightlines.
Reflection
Decide which element to iterate first: a choke point, an unreachable ledge, or unclear cover placement.
