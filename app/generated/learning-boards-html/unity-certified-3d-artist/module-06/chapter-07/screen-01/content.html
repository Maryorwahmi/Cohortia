Profiling and Performance Analysis for Artists
Measure CPU, GPU, memory and translate profiler signals into art fixes that maintain visual quality on target hardware.
In this lesson you will learn to interpret Profiler graphs, identify artistic culprits such as draw calls and overdraw, and apply an iterative optimization workflow so visual fidelity and performance co-exist.
Explore Key Topics
CPU: Draw Calls
When draw calls spike, the CPU is issuing many commands. Batching and material sharing help.
GPU: Overdraw
Stacked transparency and complex shaders cause pixels to be re-drawn; reduce layered transparency.
Memory: Textures
Large textures raise memory use; compress and resize to the object's importance.
