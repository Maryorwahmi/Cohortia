Profiling: a working definition
Measure runtime cost and map the highest-cost items to artistic fixes.
Core claim
Profiling turns subjective stutters into objective data so you can prioritize fixes.
Common misconception
Assuming visual lag is always GPU-bound. The Profiler may show CPU draw call pressure instead.
Concrete example
If Camera.Render spikes and DrawMeshes is high, the scene likely has many unique materials or unbatched static props. The artist fix is material consolidation or static batching, not immediately changing shaders.
Key Takeaway

Profiling gives you actionable evidence about performance and points directly to artist-level solutions.

Definition Cards
Profiler
Unity's Window > Analysis > Profiler shows timelines for CPU, GPU, Memory and Rendering stats.
Bottleneck
The subsystem (CPU, GPU, memory) that most limits frame time.
Signal → Fix
A profiler signal should map to an artist action: batching, LOD, shader simplification or compression.
