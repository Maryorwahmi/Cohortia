Module 7 › Chapter 6.7 › Hands-on Activity
Activity steps
Follow the scripted unoptimized setup and use the Profiler to diagnose and fix.
  1. Create a Plane and add 200–300 Cubes; do not mark them Static and give each a duplicated material.
  2. Add 50–100 transparent Spheres and stack some to create overdraw.
  3. Add a single high-poly model prominently visible.
  4. Open Window > Analysis > Profiler and enter Play Mode on target hardware if possible.
  5. Observe CPU main thread and Rendering stats; identify spikes and entries like Camera.Render, DrawMeshes, Render.OpaqueGeometry.
  6. Apply one change—mark cubes Static or share a material—then re-profile and record differences.
Record
Note the profiler entries observed, the single change you made, and the before/after metric that improved.
Example troubleshooting log
Observation: Camera.Render dominated and Draw Calls = 800+
Action: Consolidated materials and marked props Static.
Result: Draw Calls dropped to 120 and Main Thread spikes reduced.
