Techniques to reduce draw calls
Choose the right consolidation for repeated assets.
Static Batching
Mark environment props as static so Unity combines them into fewer draw calls at build time.
GPU Instancing
For identical non-static objects, enable GPU instancing on the material to draw many instances in one call.
Texture Atlases
Combine many small textures into one to allow many objects to use the same material.
Example: 300 cubes each with a unique material produce many draw calls. Share one material and mark cubes static to see draw calls drop dramatically in the Profiler.
Comparison panel
When to use each
  • Static batching: best for immovable environment pieces.
  • GPU instancing: best for many identical moving objects like grass or trees.
  • Atlases: best for many small props that can share UV space.
Key Takeaway

Start with material sharing, then choose static batching or GPU instancing depending on mobility and repetition.
