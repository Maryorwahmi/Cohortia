Key Concepts
Draw Call
A CPU command to render geometry; many draw calls can make the renderer CPU-bound.
Static Batching
Combines non-moving GameObjects that share the exact same material into a single combined mesh and draw call.
GPU Instancing
Render many identical meshes with one draw call by supplying per-instance transforms to an instancing-capable shader.
Summary

Measure draw calls, choose the appropriate batching technique, and verify improvements with the Stats window to avoid CPU-bound rendering.
