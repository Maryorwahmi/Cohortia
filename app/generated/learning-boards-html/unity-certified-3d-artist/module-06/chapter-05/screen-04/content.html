What Is a Draw Call?
The CPU-to-GPU command that instructs rendering of geometry with a specific material and state.
Definition & Context

A draw call packages mesh data, material, shader settings, and transform into a GPU command. Each call costs CPU time to prepare. Multiple small draw calls can make the renderer CPU-bound even if the GPU could handle more triangles.

  • Example: Fifty crates with unique materials often cause fifty draw calls.
  • Contrast: One combined mesh or instanced draw reduces the number of times the CPU must issue commands.
  • Misconception: High GPU usage is the only problem — often CPU bottlenecks from draw calls are the limiting factor.
Key Takeaway

Treat draw calls as a CPU resource. Reducing them often yields immediate frame rate gains on CPU-bound platforms.

Visual Explanation
CPU prepares many commands → GPU executes
Each object with a unique material is another command. Combine or instance to lower count.
Check Your Understanding
If you see high draw calls but low GPU time, what does that imply? Answer: likely CPU-bound due to many draw calls; batching or instancing can help.
