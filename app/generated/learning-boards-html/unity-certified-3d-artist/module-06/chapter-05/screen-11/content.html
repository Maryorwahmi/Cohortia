Choosing the Right Technique
A practical workflow to select static batching, dynamic batching, or GPU instancing.
Step 1 — Immobile?
If objects won’t move, use static batching. Mark them Static and share one material.
Step 2 — Identical Mesh?
If many objects share the exact same mesh and material but need unique transforms, prefer GPU instancing.
Step 3 — Small & Moving?
Dynamic batching can help for a few small moving objects but has strict vertex limits and CPU cost per frame.
Example scenarios: static decorative rocks → static batching; field of identical grass swaying in wind → GPU instancing; a handful of simple moving props → dynamic batching may apply.
