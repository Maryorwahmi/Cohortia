Learning Objectives
Learn to measure, configure, and verify batching strategies to reduce draw calls and CPU overhead.
01
Explain Draw Calls
Describe what a draw call is, why many draw calls create CPU-bound rendering, and how that impacts frame rate. Use a short scene example to illustrate.
VERIFIED COMPETENCY MILESTONE
02
Differentiate Batching Types
Identify when to use static batching, dynamic batching, or GPU instancing based on object mobility, mesh sameness, and shader support.
VERIFIED COMPETENCY MILESTONE
03
Configure Static Batching
Mark GameObjects as Static and ensure materials match exactly so Unity can combine meshes into a single draw call.
VERIFIED COMPETENCY MILESTONE
04
Enable GPU Instancing
Prepare materials and ensure the shader supports instancing so many identical meshes can be drawn with one call.
VERIFIED COMPETENCY MILESTONE
