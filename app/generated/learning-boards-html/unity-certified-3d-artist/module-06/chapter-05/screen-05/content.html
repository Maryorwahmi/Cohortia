Static Batching Explained
Combine meshes of non-moving GameObjects that share the same material into one draw call.
How to Enable
  1. Select the GameObjects you want to batch.
  2. In the Inspector, check the Static checkbox near the top right.
  3. Ensure the objects share the exact same material instance and shader settings.
Example: 50 rocks, one material, all marked Static—expect draw calls for rocks to drop dramatically. Misconception: marking everything Static is not free; it increases combined mesh memory.
Key Takeaway

Static batching is excellent for many small, static props. Check memory costs and prefer it over dynamic batching when objects do not move.

Requirements & Limitations
  • Objects must be marked Static.
  • Objects must share the exact same material; any difference breaks batching.
  • Objects cannot move, rotate, or scale during gameplay.
  • Static batching increases memory because Unity creates combined meshes.
Common Use Cases
Environmental props like rocks, modular buildings, fences, and debris are ideal for static batching.
