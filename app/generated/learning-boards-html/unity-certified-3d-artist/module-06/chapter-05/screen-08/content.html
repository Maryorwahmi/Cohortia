Hands-On: Static Batching and GPU Instancing
A reproducible Editor test to compare draw calls before and after optimizations.
Static Batching Steps
  1. Create a Cube and a new Material. Apply the material to the cube.
  2. Duplicate the cube 50 times and arrange them.
  3. Open Game view Stats and note Batches and Draw Calls.
  4. Select all cubes and check Static in the Inspector, then re-check Stats.
Look for a large drop in draw calls when batching succeeds.
GPU Instancing Steps
  1. Create a Sphere and a new Material. In the material Inspector enable GPU Instancing.
  2. Duplicate the sphere 50 times and arrange them.
  3. Compare Stats with instancing enabled vs disabled to observe the change.
Experiment: uncheck instancing to see draw calls rise, then re-enable to confirm improvement.
