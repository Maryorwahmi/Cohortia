Using the Stats Window
Read Batches and Draw Calls after changes to confirm improvements.
Key Fields to Watch
  • Batches — groups of geometry the renderer issues, often reduced by batching.
  • Draw Calls — number of CPU calls to the GPU. Lower is better for CPU-bound scenes.
  • Triangles — GPU workload; check alongside draw calls to understand balance.
Testing pattern: isolate the system, measure baseline, change batching settings, and re-measure. Repeat until the improvement stabilizes.
Troubleshooting Steps
  1. Confirm objects share the exact same material instance.
  2. Check the shader for features that disable batching.
  3. Verify Static flag for static batching or instancing enabled for GPU instancing.
Quick test: change a single property on one material instance to see batching break. This helps identify invisible material differences.
