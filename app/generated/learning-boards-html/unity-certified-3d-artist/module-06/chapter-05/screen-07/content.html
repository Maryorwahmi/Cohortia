GPU Instancing
Draw many copies of the same mesh with one draw call and per-instance data supplied to the GPU.
How It Works

The CPU submits one draw call for the mesh and passes arrays of transforms or small per-instance values. The GPU then draws every instance efficiently without additional draw calls.

Example: thousands of identical grass blades or a forest of identical trees. Each instance can have unique position, rotation, and small tints handled by the shader.
Requirements & Limitations
  • Use the exact same mesh and material.
  • The material’s shader must support instancing; enable 'GPU Instancing' on the material.
  • Not suitable when each instance needs large, unique per-instance data without extra shader work.
Misconception: Instancing eliminates all per-instance cost. It removes draw call overhead, but if you need heavy per-instance data you may still incur GPU memory or shader complexity costs.
