Objectives: Measurement and Diagnosis
Learn a simple, repeatable verification workflow to ensure batching actually reduced draw calls.
Verification Checklist
  • Open Game view and click Stats. Observe Batches and Draw Calls before changes.
  • Apply Static or enable instancing, then re-check Stats for reduced counts.
  • If batching fails, compare materials and check shader features that break batching.
Quick Tip
When testing, keep the scene minimal so changes in draw calls are easier to read. Add one system at a time and re-measure.
