Definition
Material Instancing
Sharing a single material asset across objects to reduce draw calls.
Example
Twenty identical crates using one material instead of twenty separate materials can be batched, cutting draw calls significantly.
Key Takeaway

Prefer shared materials and use material property blocks for per-object tweaks.

Supporting points
  • Unique material instances break batching and increase draw calls.
  • Material Property Blocks let you change color or parameters per object without new materials.
  • Atlasing textures allows many objects to use the same material with different UVs.
Misconception
Assuming shaders are the only cost. Unique materials drive draw calls and CPU overhead, which also limit frame rate.
