Process
Texture Atlasing Steps
  1. Gather small textures for props that can share an atlas.
  2. Create a single atlas image in an editor and export at an appropriate size.
  3. Remap each model’s UVs to match its region of the atlas.
  4. Create a shared material with the atlas as the albedo and assign it to props.
  5. Validate correct mapping and texel density in Unity.
Example
Combine five 1024 textures into one 2048 atlas and remap UVs so multiple props use SharedProps_Mat, reducing draws dramatically.
Common Mistake

Not adjusting UVs before import. If UVs still point to original textures, the atlas will display wrong regions.

Pro tip
Keep consistent texel density across props to avoid visible quality mismatch when sharing an atlas.
