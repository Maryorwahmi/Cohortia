Hands-on Activity
Implement LODs
  1. Import high, medium, and low-poly meshes and drag the high model into the scene.
  2. Add an LOD Group component to the parent GameObject.
  3. Assign meshes to LOD0, LOD1, LOD2 and set screen percentage sliders.
  4. Move camera in Scene view to verify swaps and adjust thresholds to reduce popping.
Material Sharing
  1. Create a texture atlas by combining small albedo textures into one image.
  2. Remap UVs so each prop points to its atlas region, then create SharedProps_Mat with the atlas.
  3. Apply the material to props and duplicate them to watch batching and draw call changes.
  4. Open Stats or Profiler and compare draw calls and triangles before and after changes.
Checkpoint

You should see fewer draw calls and lower triangle counts for distant objects after applying LODs and shared materials.
