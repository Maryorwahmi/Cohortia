Process Flow
Mesh Simplification Steps
  1. Profile scene and list heavy meshes by triangle count.
  2. Apply automated decimation to create a lower‑poly test version.
  3. Check silhouette, UVs, and normals for visual regressions.
  4. Use Unity import mesh compression when appropriate for quick savings.
  5. Reserve manual retopology for hero assets or deforming geometry.
Example
A wooden crate with 10k triangles can be decimated to 2–3k without visible loss, while a character head requires manual retopology to preserve animation.
Supporting notes
  • Always inspect UVs after reduction; decimation can distort UV islands.
  • Keep normal maps to preserve fine detail after polygon reduction.
  • Remove unseen faces such as bottoms of buildings or interiors not shown.
Common Mistake

Decimating everything blindly. Not all assets benefit equally; target the biggest offenders first.
