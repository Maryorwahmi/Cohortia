Learning Objectives
These objectives map to real tasks: reducing GPU load, tuning LODs, and sharing materials to cut draw calls.
01
Measure mesh cost
Identify how polygon count affects rendering. Knowing the cost lets you prioritize which assets to optimize.
Venn: cost vs detail
VERIFIED COMPETENCY MILESTONE
02
Reduce polygons
Use decimation, compression, or manual retopology to remove unnecessary triangles while keeping silhouettes intact.
Mnemonic: silhouette first
VERIFIED COMPETENCY MILESTONE
03
Create LOD Groups
Assemble LOD0, LOD1, LOD2 and tune screen percentages so distant objects cost less GPU time.
Timeline: near → far
VERIFIED COMPETENCY MILESTONE
04
Share and atlas materials
Reduce draw calls by sharing material assets and combining small textures into atlases. Use property blocks for small variations.
Mnemonic: one material, many uses
