Module 5 › Chapter 5.2 › Sub-Emitter Configuration
Step-by-step
  1. Open the parent particle system and enable Sub-Emitters.
  2. Click + to add a new sub-emitter slot and drag the child from the Hierarchy into the Particle System field.
  3. Select Type = On Death (or On Birth/On Collision as needed).
  4. Play the scene and observe timing; adjust child lifetime or parent lifetime to maintain cohesion.
Troubleshooting
Child not emitting? Confirm it is assigned in the sub-emitter slot and that the parent's particles actually reach the chosen event (e.g., death).
Example wiring
MagicImpact_Parent.SubEmitters: Slot 0 → Particle System: MagicImpact_Sparks_Child • Type: On Death
Pro Tip
Use different triggers for sequential behavior: On Birth for instantaneous debris, On Death for lingering smoke.
