Module 5 › Chapter 5.2 › Texture Sheet Animation
Process

Create an atlas and animate frames

Set tiles to match rows and columns, then drive frame selection by lifetime to animate a particle's visual over time.

Inspector-style walkthrough
Texture Sheet Animation:
  Mode: Whole Sheet
  Tiles: X=4, Y=4
  Frame over Time: Enabled
  Frame Rate: match particle lifetime
  Start Frame: 0
Key Tip

Sync your frame progression to the particle lifetime so the sprite evolves naturally from birth to death.

Example
A 4x4 atlas for a smoke puff: with Start Lifetime of 1 second and Frame over Time full range, the puff transitions through the 16 frames and fades via Color over Lifetime to transparent.
Misconception
More frames doesn't always improve perception. If lifetime is short, fewer frames or faster playback reads cleaner.
Optimization note
Atlases reduce texture binds and draw calls. Keep atlas sizes reasonable to avoid wasted memory.
