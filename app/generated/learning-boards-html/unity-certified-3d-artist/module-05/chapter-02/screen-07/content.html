Module 5 › Chapter 5.2 › Sub-Emitters
Definition

Child systems triggered by parent events

A sub-emitter is a separate particle system you reference in the parent. Configure its trigger type and it will emit on that event.

Common triggers
  • On Birth — spawn child when parent particle is created
  • On Death — spawn child at end of parent lifetime
  • On Collision — spawn child when parent collides
  • On Trigger — spawn child on trigger events
Misconception
Sub-emitters are not inherently expensive; cost depends on child particle counts and duration. Short bursts can be efficient.
Example: Explosion
Parent: large fire burst with short lifetime. Sub-Emitter (On Death): spawn smoke puffs and sparks with smaller sizes and longer lifetimes to produce a convincing aftermath.
Pro Tip
Tune child emission counts and gravity so that sparks fall while smoke rises, creating depth and readable motion.
