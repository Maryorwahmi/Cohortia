Definition

Particle material and Renderer explained

The Renderer binds a material and determines how particles are drawn. A particle material's shader decides transparency and blending behavior.

Practical inspector example
Renderer:
  Material: Assets/Materials/Particles_Additive
  Render Mode: Billboard
  Sorting: By Distance
Common mistake
Using Alpha Blended for inherently emissive effects like fire makes them appear flat. Use Additive when overlap should brighten.
Key Takeaway

Pick shader and render mode that match artistic goal: glow vs soft occlusion, sprite vs mesh.

Visual comparison
Additive (Glow)
Overlapping sprites brighten. Good for fire and magic.
Alpha Blended (Fade)
Uses texture alpha to occlude. Good for smoke and soft particles.
Mini checklist
  • Choose shader by intended light interaction
  • Test overlapping sprites for additive brightness
  • Use atlas for efficient sprite animations
