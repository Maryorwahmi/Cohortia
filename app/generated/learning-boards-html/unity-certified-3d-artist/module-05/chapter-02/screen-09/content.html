Inspector-style settings
MagicImpact_Sparks_Child - Main Module:
  Duration: 1.0
  Looping: Off
  Start Lifetime: RandomBetween(0.5, 1.0)
  Start Speed: RandomBetween(3, 7)
  Start Size: RandomBetween(0.05, 0.15)
  Start Color: White/Yellow
  Gravity Modifier: 1.0

Emission:
  Bursts:
    - time: 0, count: 15-25

Shape:
  Shape: Sphere
  Radius: 0.1

Color over Lifetime:
  Curve: white/yellow -> transparent

Renderer:
  Material: Particles/Additive
Why these choices
High initial speed and gravity create arcing sparks. Burst counts create perceived intensity; keep lifetimes short to avoid long tails.
Key Takeaway
Tune count, speed, and lifetime together so sparks read as a continuation of the parent impact.
