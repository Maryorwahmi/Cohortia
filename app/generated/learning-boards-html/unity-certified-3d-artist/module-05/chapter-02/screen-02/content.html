Module 5 › Chapter 5.2 › Learning Objectives
01
Apply custom textures & materials
Assign particle materials and atlases so art direction, color, and performance align. A single atlas reduces draw calls when animating many sprites.
VERIFIED COMPETENCY MILESTONE
Mnemonic: picture a sprite sheet and a single material acting like a flipbook.
02
Understand blending modes
Choose Additive for glowing light and Alpha Blended for soft, occluding materials like smoke. Using the wrong mode will break believability.
VERIFIED COMPETENCY MILESTONE
Mnemonic: additive = light, alpha = soft surface.
03
Implement sub-emitters
Trigger child systems on events like death or collision to produce sparks, smoke, or debris automatically from a parent burst.
VERIFIED COMPETENCY MILESTONE
Mnemonic: parent sparks spawn children like an orchestra cue.
04
Configure collision & forces
Use Collision module types, damping, bounce and lifetime loss plus forces and velocity limits to make interactions believable and performant.
VERIFIED COMPETENCY MILESTONE
Mnemonic: collisions temper motion; forces shape drift.
