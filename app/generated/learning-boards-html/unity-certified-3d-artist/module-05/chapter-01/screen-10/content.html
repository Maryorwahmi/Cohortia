Module 5 › Chapter 5.1 › Campfire Smoke
Step-by-step
1. Create empty GameObject named "CampfireSmoke_VFX".
2. Add Particle System (GameObject > Effects > Particle System).
3. Main: Duration = 5.0, Looping = On.
4. Start Lifetime: Random Between Two Constants (3.0, 5.0).
5. Start Speed: Random Between Two Constants (0.5, 1.5).
6. Start Size: Random Between Two Constants (0.2, 0.5).
7. Start Color: dark gray to light gray gradient.
8. Gravity Modifier = -0.1.
9. Simulation Space = World.
10. Max Particles = 100.
11. Emission: Rate over Time = 5.
12. Shape: Cone, Angle = 15, Radius = 0.1.
13. Renderer: use Default-Particle material for prototyping.
Play the scene and observe smoke rising. Tune Start Speed and Lifetime to change density; lower Rate over Time or Max Particles if performance drops.
Why these values?
The random ranges add organic variation. Negative gravity makes smoke rise. World space keeps smoke stationary relative to the world, producing a believable column above the campfire.
Key Takeaway
This configuration provides a reliable baseline; iterate with real scene lighting and materials for the final look.
