Renderer responsibilities
  • Draw particles using a material and shader.
  • Control blending, sorting, and sprite shape.
  • Display color and alpha provided by the Particle System if the material supports vertex colors.
Prototyping tip: use Default-Particle, then replace with a soft sprite material for final art.
Practical example
To simulate smoke that desaturates over time, set color over lifetime in the Main module and ensure your material multiplies vertex color. If the material ignores vertex colors, the effect will not appear regardless of your Main settings.
Material checklist: supports alpha, supports vertex color/tint, uses soft sprite texture.
Key Takeaway: Renderer shows visuals; it does not change behavior. Tune logic in modules and appearance in the material.
