Particle System (Logic)
  • Main: lifetime, speed, size, color, simulation space.
  • Emission: rate over time and bursts for spawn timing.
  • Shape: emitter volume and distribution.
Misconception check
Renderer does not control physics or lifetime. If particles move wrong, adjust Main or Simulation Space.
Particle System Renderer (Appearance)

Assign a material to define particle sprites, shaders, and blending. Renderer choices determine how particles look and sort with the scene.

Quick tip: use Default-Particle while prototyping, then swap to a custom soft sprite for final visuals.
Example: color transitions set in Main are visible only if the Renderer material supports vertex color or tinting.
Key Takeaway

Tune behavior in the system and appearance in the renderer; both are needed for the final effect.
