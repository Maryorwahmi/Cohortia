Key properties
Duration & Looping — how long the system runs and whether it repeats.
Start Lifetime — how long each particle exists; longer for smoke, shorter for sparks.
Start Speed — initial velocity; tied to perceived force of the effect.
Start Size & Color — initial scale and tint for each particle.
Gravity Modifier — affects vertical acceleration; negative values make stuff rise slowly.
Simulation Space — World vs Local changes whether particles follow the emitter.
Examples & tuning
Smoke tuning
Start Lifetime: 3–5s, Start Speed: 0.5–1.5, Start Size: 0.2–0.5, Gravity Modifier: -0.1.
Explosion tuning
Start Lifetime: 0.5–1s, Start Speed: high, use Bursts for immediate particle release.
Misconception
Changing Renderer materials will not alter lifetime or speed. Always verify Main settings when behavior is wrong.
Key Takeaway

Main sets the lifecycle and movement of particles; simulation space determines their relation to the emitter's motion.
