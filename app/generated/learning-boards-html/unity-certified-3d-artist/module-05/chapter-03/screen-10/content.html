Module 5 › Chapter 5.3 › Falling Stars: Assembly
Assembly checklist
  1. Create FallingStars_VFXGraph.
  2. Spawn: Spawn Rate = 50; Set Position > Random Box: Center(0,5,0), Size(10,0,10).
  3. Initialize: Set Velocity (0,-2,0); Set Size 0.1; Set Color = pale yellow.
  4. Update: Set Color over Lifetime (fade to transparent); optional Add Velocity with Curl Noise for drift.
  5. Output: Output Particle Quad; Blend Mode = Additive; assign small star texture.
  6. Create Visual Effect GameObject and assign the graph; press Play and iterate.
Example tweak
Expose Spawn Rate as a property named spawnRate. In the Inspector, you can now increase spawnRate to test how the scene performs at higher particle counts without reopening the graph.
Performance tip: When increasing spawn rate, also check the Output material and particle size to avoid unnecessary overdraw.
