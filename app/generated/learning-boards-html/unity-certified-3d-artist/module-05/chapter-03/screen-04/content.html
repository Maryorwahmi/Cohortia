Module 5 › Chapter 5.3 › VFX Graph vs Shuriken
CPU-driven: Shuriken
When to use
  • Small to moderate particle counts
  • Fast setup for UI and editor-focused effects
  • When per-particle CPU access is required
Common misconception

CPU-based means easier authoring for tiny systems, but not always better performance at scale.

GPU-driven: VFX Graph
When to use
  • Very high particle counts (swarms, weather, large debris)
  • Complex procedural motion using noise or custom operators
  • Performance-critical scenes where CPU is saturated
Practical note

GPU simulation reduces CPU load but you must monitor GPU costs like shader complexity and fill rate.

Example

A dust storm with hundreds of thousands of particles runs smoothly on VFX Graph but would likely stall the CPU if implemented with Shuriken.

Check

Ask: Which resource is the current bottleneck — CPU or GPU — before choosing the system.

Key Takeaway

Use VFX Graph to scale effects that would otherwise overload the CPU; prefer Shuriken for simple, quick effects.
