Module 5 › Chapter 5.3 › Key Concepts
Visual Effect Graph
A node-based, GPU-driven system for high-performance particle effects.
SRP Requirement
URP or HDRP must be configured for VFX Graph to render correctly.
Contexts
Spawn, Initialize, Update, Output — the execution stages for particle behavior.
Final takeaway

Use VFX Graph when you need scale and complex GPU-driven simulation, ensure SRP is configured, and structure your graphs using contexts, blocks, and operators for clear, performant effects.
