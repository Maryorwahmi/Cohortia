Module 5 › Chapter 5.3 › Create Asset & GameObject
Quick walkthrough
// Steps to create and assign a VFX Graph asset
1. Window > Package Manager → Install "Visual Effect Graph"
2. Assets > Create > Visual Effect > Visual Effect Graph → name: FallingStars_VFXGraph
3. GameObject > Visual Effects > Visual Effect → name: FallingStars_SceneVFX
4. Select GameObject, drag FallingStars_VFXGraph into the Visual Effect Asset field
5. Double-click FallingStars_VFXGraph to open the VFX Graph Editor
This code-style checklist helps you follow steps reliably in the editor. Each step has a visual confirmation: package installed, asset created, GameObject present, and asset assigned.
Common pitfall

If you can create the asset but the Visual Effect menu is missing, confirm the SRP is installed and active. The asset creation menu appears only when prerequisites are met.

Check

After assignment, the Visual Effect component should list the asset name in the Inspector. If empty, drag the asset into the slot to connect them.
