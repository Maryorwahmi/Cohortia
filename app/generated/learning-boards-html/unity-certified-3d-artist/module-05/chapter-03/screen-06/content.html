Contexts explained
Spawn
Defines birth timing and position using blocks like Spawn Rate and Set Position.
Initialize
Sets initial attributes such as velocity, size, and color for each particle.
Update
Runs every frame to change particle state, apply forces or noise.
Output
Defines rendering: material, blend mode, and particle mesh or quad.
Blocks vs Operators
Blocks are building blocks that perform common tasks in a context. Operators are atomic functions — math nodes, random generators, texture samplers — used to feed block parameters. Because both run per particle on the GPU, keep operator graphs minimal for expensive effects.
Example
Spawn: add Spawn Rate block. Initialize: Set Velocity to (0, -2, 0) using a constant operator. Update: Add a Set Color over Lifetime block with a fade gradient. Output: set blend mode to additive for glowing stars.
Common mistake

Forgetting Output context leads to particles being simulated but not rendered.

Pro tip

Expose expensive parameters so artists can tune them in the Inspector without re-editing the graph.
