Module 5 › Chapter 5.3 › Quick Reference
Blocks
Pre-built functions like Spawn Rate, Set Velocity, and Set Color used inside contexts.
Operators
Atomic nodes that compute math, randomness, and sample textures to drive block parameters.
Properties
Exposed variables that appear on the Visual Effect component for fast tuning and scripting control.
Final tip

Start simple, expose a couple of parameters, test performance, and then add complexity. This workflow keeps iteration fast and effects scalable.
