Module 5 › Chapter 5.3 › Project Setup
Step-by-step
  1. Open Window > Package Manager and install Universal RP or HDRP.
  2. Create a pipeline asset: Assets > Create > Rendering > URP Asset (or HDRP Asset).
  3. Assign the pipeline asset in Edit > Project Settings > Graphics > Scriptable Render Pipeline Settings.
  4. Install Visual Effect Graph from Unity Registry in Package Manager.
  5. Create a Visual Effect Asset: Assets > Create > Visual Effect > Visual Effect Graph.
Common error: VFX package installed but no SRP assigned — effects won’t render.
Quick verification
Create a Visual Effect GameObject (GameObject > Visual Effects > Visual Effect), then assign your new Visual Effect Graph asset into its Visual Effect component. If you can assign it and see no console SRP errors, setup is correct.
Checklist
  • SRP package installed
  • Pipeline asset created and assigned
  • VFX Graph package installed
  • Visual Effect asset creatable and assignable
