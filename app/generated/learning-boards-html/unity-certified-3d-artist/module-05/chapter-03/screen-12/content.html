Module 5 › Chapter 5.3 › Expose Properties
Why expose properties?

Exposed properties let designers and artists adjust parameters without authoring graphs. They speed iteration, enable runtime tuning, and allow driving values from scripts or animations.

Suggested properties to expose
  • spawnRate — control particle count quickly
  • startVelocity — tweak fall speed
  • starSize — change visual scale without reauthoring
  • noiseStrength — dial turbulence up or down for performance tests
Best practice

Expose a small, meaningful set of parameters with clear names and defaults. Avoid exposing many internal nodes; instead, provide artist-friendly controls for the most important behaviors.

Try: Expose spawnRate and starSize first to test density and visibility before adjusting more complex operators.
