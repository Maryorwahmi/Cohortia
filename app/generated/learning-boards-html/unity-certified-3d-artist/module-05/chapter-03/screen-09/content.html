Module 5 › Chapter 5.3 › Update & Output
Update context — common blocks
  • Set Color over Lifetime — use a gradient to fade to transparent.
  • Add Velocity / Apply Force — change motion each frame.
  • Operators like Curl Noise — generate procedural turbulence.
Performance note: Complex operator graphs increase GPU cost.
Output context — render settings
Choose Output Particle Quad or Mesh. Set Blend Mode to Additive for glowing stars. Assign a simple texture or sprite. Keep shader operations light to protect fill-rate performance.
Check

If particles appear but look opaque or not textured, verify the Output context has the correct material and Main Texture assigned, and ensure blend mode suits the visual.

Example

Set Color gradient from white to transparent and Output blend to Additive to create fading glowing stars.

Common mistake

Using a complex lit shader for billboards can cost lots of GPU time; prefer simple unlit additive shaders for particle sprites.

Key Takeaway

Match Update behavior with a lightweight Output material to balance motion and render cost for performant VFX.
