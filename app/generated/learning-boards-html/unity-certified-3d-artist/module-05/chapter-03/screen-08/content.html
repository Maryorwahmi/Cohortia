Spawn context — example settings
Add Spawn Rate: Rate = 50. Add Set Position with Operator: Random Box. Random Box Center = (0, 5, 0). Size = (10, 0, 10). This distributes spawns across the X-Z plane at Y = 5.
Why it matters

Spawn controls how many particles are created and where; use operators to introduce randomness and area shapes for natural placement.

Initialize context — example settings
  • Set Velocity → (0, -2, 0) to make particles fall.
  • Set Size → 0.1 for small star sprites.
  • Set Color → white or light yellow to emit a star-like glow.
Tip: Keep initial values simple and expose one or two as properties so you can tweak spawn rate and velocity from the Inspector.
Example question

How would you change the Random Box to spawn stars in a narrow stream instead of a wide area?

Common mistake

Setting Spawn Rate but not adding an Initialize Set Velocity will create particles that don’t move as expected.

Key Takeaway

Spawn births particles; Initialize gives them motion and appearance. Both are required for a visible, moving effect.
