Module 5 › Chapter 5.3 › Troubleshooting
No particles visible?
  • Is the VFX asset assigned to a Visual Effect GameObject?
  • Is there an Output context configured and visible?
  • Is the project using URP or HDRP?
Particles look wrong?
  • Check Initialize values: size and velocity
  • Check Update: color gradients and noise strength
  • Check Output: texture, blend mode, and shader
Performance checks
  • Reduce Spawn Rate to diagnose performance scaling
  • Simplify operator graphs to measure GPU time
  • Swap to a basic unlit additive material for testing
