Module 5 › Chapter 5.3 › Practical Milestones
Milestone 1: Explain GPU-driven advantage

Show a large particle scene and explain why GPU simulation moves per-particle math off the CPU, allowing thousands to millions of particles without the same CPU overhead.

Check: Can you describe one scenario where Shuriken would struggle but VFX Graph performs well?
Milestone 2: Install & configure SRP

Install URP or HDRP, add a pipeline asset, and confirm Visual Effect Graph appears in Package Manager. Create a VFX asset to confirm tools are available.

Check: Is a VFX Graph asset creatable in the Assets > Create menu?
Milestone 3: Identify contexts and blocks

Open a graph and find Spawn, Initialize, Update, and Output contexts. Point out a common block such as Spawn Rate, Set Velocity, or Set Color.

Check: Can you name a block in each of the four contexts?
Milestone 4: Build and expose a property

Create the falling-stars effect and expose Spawn Rate to the Inspector so artists can tweak without reopening the graph.

Check: Can you change the spawned particle count at runtime via the Inspector?
