Module 5 › Chapter 5.5 › Screen Space Ambient Occlusion
Definition
Approximate soft shadows where ambient light is occluded to enhance depth perception in a scene.
Intensity
Controls darkness of occlusion.
Radius
How far occlusion spreads from geometry.
Thickness Modifier
Adjusts sensitivity to thin features.
Concrete example
Enable SSAO with Intensity 1.0 and Radius 0.5 to add subtle shadows in gaps beneath objects and along corners. This helps the scene feel grounded without fully darkening midtones.
Key Takeaway

SSAO is a lightweight depth cue. Keep it subtle to avoid a dirty or crushed look.

Common mistake
Using high intensity or radius values that create unrealistic darkening around objects and reduce material clarity.
