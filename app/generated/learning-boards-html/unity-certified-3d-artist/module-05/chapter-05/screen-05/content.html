Module 5 › Chapter 5.5 › Tuning Depth of Field
Process
  1. Identify the subject and set Focus Distance to its depth.
  2. Reduce Aperture incrementally to introduce subtle blur.
  3. Tweak Focal Length for compression if desired.
  4. Validate across camera positions and motion speeds.
  5. Use local volumes for scene-specific DoF changes.
Key Takeaway

Iterative checks in play mode are essential; subtle DoF often reads better than strong blur.

Concrete example
For a 3rd-person character close-up, set Focus Distance to the head at 2–5 units and set Aperture to a conservative value, then reduce until the background separation reads without obscuring the hands or UI.
Pitfall
Assuming a single DoF profile fits all cameras; instead use local volumes or camera-specific profiles for dramatic shots.
Try toggling DoF in play mode to compare readability and cinematic effect. Start subtle, then push only where the scene benefits; always confirm the result on your target hardware.
