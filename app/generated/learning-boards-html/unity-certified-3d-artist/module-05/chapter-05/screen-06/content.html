Module 5 › Chapter 5.5 › Screen Space Reflections
Core Concept
Screen Space Reflections
Real-time reflections calculated from pixels already rendered to the screen.
Strengths
Dynamic reflections for moving objects and specular surfaces without baking.
Limits
Only reflects what appears on-screen; off-screen geometry and occluded rays create artifacts.
Key Takeaway

Use SSR for dynamic, on-screen reflections and combine with probes for coverage where SSR cannot reach.

Tunable parameters
Max Roughness
Defines how rough a surface can be and still show SSR reflections.
Resolution
Internal buffer quality. Half or Quarter reduce cost with softer results.
Intensity
Scales reflection contribution to the final shaded result.
