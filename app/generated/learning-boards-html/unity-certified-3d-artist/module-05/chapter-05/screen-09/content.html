Module 5 › Chapter 5.5 › Add DoF, SSR, SSAO
Follow these steps in your Post-Process Profile and validate in play mode.
1. Add Depth of Field
  • Click Add Effect > Unity > Depth Of Field.
  • Override Mode to Gaussian and set Focus Distance to subject.
  • Set Aperture conservatively and test in play mode.
2. Add Screen Space Reflections
  • Add Screen Space Reflections and enable Intensity override at 0.5.
  • Set Max Roughness to around 0.8 and Resolution to Half for performance.
3. Add SSAO
  • Add Screen Space Ambient Occlusion and set Intensity to 1.0.
  • Start with Radius 0.5 and adjust Thickness Modifier for thin features.
Check your result
Play the scene, look for SSR artifacts, verify that DoF does not obscure UI or gameplay, and ensure SSAO adds depth without crushing midtones. If performance drops, reduce SSR resolution or lower DoF precision.
