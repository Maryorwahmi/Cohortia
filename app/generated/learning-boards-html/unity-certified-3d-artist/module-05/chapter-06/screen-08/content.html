Architecture

Why atlases reduce draw calls

Atlases place multiple sprite regions in a single texture and allow many particles to share one material pass, cutting state changes and draw calls.

When to atlas

Multiple particle variants using different tiny textures are ideal candidates for atlasing.

Considerations
  • Atlas resolution vs memory usage
  • Padding to avoid bleeding between regions
  • Material compatibility for batching
Concrete example

Combining four spark textures into a single 1024 atlas reduced draw calls from four to one for that particle emitter, improving frame time on mobile.

Key Takeaway

Atlasing reduces draw calls when materials and states are shared; balance atlas size with memory limits.

Common mistake

Creating huge atlases without testing memory impact on target hardware can cause worse problems than the draw calls they save.
