Definition

Unity Profiler basics

Capture CPU and GPU metrics, rendering statistics, and memory to identify where visual effects cost the most.

What to inspect
  • CPU Usage → ParticleSystem.Update, PostProcessLayer.Render
  • GPU Usage → post-processing passes and fill rate
  • Rendering → draw calls and overdraw visualization
Quick workflow
  1. Record baseline while effect plays
  2. Note hotspot timing and counts
  3. Make one change and re-record to compare

Key Takeaway

Profiling yields the single most reliable insight into where to optimize visual costs.

Common mistake

Changing effects before capturing a baseline prevents measuring real impact.
