Module 6 › Chapter 5.6 › Key Concepts
Unity Profiler

Use CPU and GPU sections plus Rendering to find VFX and post-process hotspots.

Overdraw

Multiple transparent pixels increase fill rate; reduce covered pixels to save GPU time.

Particle Optimization

Reduce emission, size, lifetime, use culling and atlases, and add LODs to balance cost and fidelity.

Summary takeaway

Adopt the measure-act-verify cycle for every effect: it ensures predictable, measurable performance improvements while preserving art direction.
