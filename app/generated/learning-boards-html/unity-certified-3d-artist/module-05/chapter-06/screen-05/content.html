Module 6 › Chapter 5.6 › Overdraw
Definition

What is overdraw?

The GPU has to process every transparent pixel that is drawn. Overdraw multiplies that work when many transparent pixels overlap.

How to see it

Use Scene View Draw Mode → Overdraw. Bright red areas signal heavy overdraw and high fill rate.

Why it matters

High overdraw drives the GPU fill rate and reduces frame rate on constrained devices.

Mitigation tactics
  • Reduce overlapping particles and particle size
  • Use simpler blend shaders or opaque particles where possible
  • Fade particles earlier to reduce covered pixels
Concrete example

A smoke effect with 800 semi-transparent quads shows heavy overdraw in Scene View. Reduce emission and particle size and the Overdraw visualization darkens, indicating fewer pixel writes and lower fill rate.

Key Takeaway

Overdraw is a pixel problem. Reduce covered pixels, not just particle counts, to improve GPU performance.

Common mistake

Focusing only on particle count without checking particle size and blending can miss the real GPU cost.
