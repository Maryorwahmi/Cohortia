Module 6 › Chapter 5.6 › Particle Workflow
Step-by-step
1. Baseline profile

Record while the effect plays; note ParticleSystem.Update, draw calls, and overdraw intensity.

2. Low-cost changes

Reduce Rate over Time, Max Particles, particle size, and lifetime to lower both CPU and GPU cost.

3. Shader and atlasing

Use simpler blend shaders or texture atlases to reduce draw calls and shader complexity.

4. Culling & LOD

Set Culling Mode to Pause And Catch-up and create LOD swaps for distant cameras to reduce simulation cost.

5. Re-profile and compare

After each change, capture a new trace to measure which edits produced the greatest improvement.

Pro tip

When possible, test on target hardware early: desktop and mobile budgets differ significantly.

Key Takeaway

A repeatable, single-change workflow makes it easy to know what worked and keep visual consistency.
