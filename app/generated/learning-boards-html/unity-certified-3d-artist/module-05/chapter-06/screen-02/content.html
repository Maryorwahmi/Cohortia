Learning Objectives

Master profiling and apply particle and post-processing optimizations that preserve visual quality.

Bloom: Learn → Understand → Apply → Master
01
Identify bottlenecks

Recognize CPU vs GPU issues such as ParticleSystem.Update spikes and overdraw hot zones. This matters because correct diagnosis leads to the right fix.

VERIFIED COMPETENCY MILESTONE
02
Use the Unity Profiler

Capture recordings to inspect CPU Usage, GPU Usage, Rendering, and memory. This matters because data guides optimization choices.

VERIFIED COMPETENCY MILESTONE
03
Optimize particle systems

Apply culling, LOD, particle count reduction, and texture atlasing to reduce draw calls and simulation cost.

VERIFIED COMPETENCY MILESTONE
04
Tune post-processing

Disable or lower expensive effects like SSR and high-sample AO and test the visual impact on target hardware.

VERIFIED COMPETENCY MILESTONE
