Module 6 › Chapter 5.6 › Culling Modes
Definition

Culling Mode options

Choose how a particle system behaves when it leaves the camera view to reduce unnecessary simulation and rendering costs.

Always Simulate

System continues regardless of visibility; useful when particles affect gameplay or physics.

Pause And Catch-up

Pauses simulation off-screen and resumes without heavy catch-up cost—good for decorative effects.

Stop Action

Stops and optionally clears particles. Use when an effect should reset when invisible.

Concrete example

An ambient campfire near the player that is invisible when the camera looks away can switch to Pause And Catch-up to drop CPU and GPU cost while preserving visual continuity when viewed again.

Key Takeaway

Cull decorative particle systems when off-screen to save CPU and GPU resources without breaking gameplay logic.

Common mistake

Using aggressive culling for systems tied to gameplay can break expected behavior; always consider game logic first.
