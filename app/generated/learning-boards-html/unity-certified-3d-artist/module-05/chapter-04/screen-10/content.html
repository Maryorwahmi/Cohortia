Core Concept Color Grading

Practical grading controls

Controls to try
  • Temperature: warm/cool shifts. Try -10 for slightly cooler tones.
  • Contrast: increases midtone separation. Try +15 to refine clarity.
  • Saturation: adjust overall color intensity modestly.
Example profile snippet
// Example inspector starting values
Temperature: -10
Contrast: +15
Saturation: 0
Color Wheels

Use separate adjustments for shadows, midtones, and highlights to keep skin tones natural while altering scene ambiance.

Misconception

Avoid extreme global shifts to fix a single issue. Instead isolate changes to highlights or shadows via color wheels when necessary.

Key Takeaway

Color Grading is powerful; use small incremental changes and verify on multiple scenes to avoid unintended clipping or color shifts.
