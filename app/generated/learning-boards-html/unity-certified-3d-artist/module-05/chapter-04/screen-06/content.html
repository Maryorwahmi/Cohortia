Add Post-Process Layer to your Camera

Why the layer mask matters

The layer mask defines which volumes the camera will process. Create a "PostProcessing" layer and assign your volume GameObjects to it so the camera recognizes them reliably.

  • Create layer: Layers > Add Layer...
  • Select Main Camera > Add Component > Post-Process Layer
  • Set Layer mask to your dedicated layer
Common mistake

If layers don’t match between camera and volume, effects won’t show even if the profile is correct.

Validation example

Create a PostProcessGlobalVolume on the PostProcessing layer, link a profile with Bloom enabled, and play the scene. If no change appears, recheck the camera mask.

Pro tip

Use one dedicated layer per post-processing workflow so multiple cameras or split-screen setups remain predictable.
