Install via Package Manager

Step-by-step
  1. Open Window > Package Manager.
  2. Search for "Post Processing" and choose the official package.
  3. Click Install and wait for completion.
  4. Create a Profile: Assets > Create > Post-Process Profile.
  5. Confirm Add Component shows Post-Process Layer on camera.
Quick verification

Create a profile, add a small Bloom effect, and attach the profile to a volume to ensure the install works and the menu shows new components.

Editor tip

If the component options don’t appear, try reselecting the camera or restarting the editor. The package exposes Inspector components that must be added manually.

Key Takeaway

Installation unlocks components and assets, but you must wire the camera and volume to see effects.
