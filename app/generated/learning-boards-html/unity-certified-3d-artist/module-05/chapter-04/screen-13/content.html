Troubleshooting Common Mistakes

Quick troubleshooting checklist

Checklist
  • Camera has Post-Process Layer and correct mask.
  • Volume GameObject is on the same layer as camera mask.
  • Profile asset is assigned and property overrides are enabled.
  • Is Global checked if you need scene-wide effects.
Validation steps
  1. Toggle the Profile on and off while watching the Game view.
  2. Move the camera into a local volume to test blending.
  3. Try minimal values so you can see subtle changes easily.
Misconception

Don’t assume post-processing will look identical across different exposure or device displays; always check target hardware.

Key Takeaway

Follow the checklist in order: camera mask, volume layer, profile overrides, and Is Global. These resolve most display issues quickly.
