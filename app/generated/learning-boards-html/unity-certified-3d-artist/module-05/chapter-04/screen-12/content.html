Hands-on Activity Setup Walkthrough

Step-by-step setup

Editor steps
  1. Ensure project uses URP or HDRP.
  2. Window > Package Manager > install Post Processing.
  3. Layers > Add Layer... > add "PostProcessing".
  4. Main Camera: Add Component > Post-Process Layer > set mask to PostProcessing.
  5. Create GameObject > Add Post-Process Volume > set to PostProcessing layer > check Is Global.
  6. Assets > Create > Post-Process Profile > drag to Profile slot.
  7. Add Bloom, Vignette, Color Grading and tune starting values.
Starting values to try
Bloom: Intensity = 0.5, Threshold = 1.05
Vignette: Intensity = 0.3
Color Grading: Temperature = -10, Contrast = +15
Play the scene and toggle each effect to compare. If nothing appears, recheck the camera’s Post-Process Layer and its layer mask.
Key Takeaway

Follow each editor step and validate by toggling effects. Consistent layering is the most common point of failure.
