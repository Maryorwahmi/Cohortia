Definition Bloom

Bloom: glow from bright pixels

Key controls
  • Intensity: overall glow strength. Start at 0.5.
  • Threshold: how bright a pixel must be to bloom. Try ~1.05.
  • Scatter: bloom spread and softness.
Example

Set Intensity to 0.5 and Threshold to 1.05 on a scene with emissive neon. Toggle to compare the glow effect on and off.

Common mistakes
  • Pushing intensity too far and losing contrast.
  • Not accounting for exposure changes that affect threshold.
Try this

Increase intensity in small steps while observing highlights and midtones. If highlights clip, reduce intensity or raise threshold.

Key Takeaway

Bloom adds cinematic glow when used subtly; tune threshold and intensity together to avoid washed-out images.
