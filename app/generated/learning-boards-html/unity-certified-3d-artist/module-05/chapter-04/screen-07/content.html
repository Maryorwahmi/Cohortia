Process Post-Process Volume

Create and scope a Post-Process Volume

Global vs Local

Global volumes apply everywhere when Is Global is checked. Local volumes apply only inside bounds and can blend with others for smooth transitions.

  • Create empty GameObject > Add Post-Process Volume.
  • Assign the GameObject to the PostProcessing layer.
  • Check or uncheck Is Global depending on scope.
Attach a Profile

Create a Post-Process Profile asset and drag it to the Profile slot of your volume. The profile stores effect overrides, not the volume itself.

Example workflow

Start with a global volume set to a neutral mood. Then add local volumes at doorways or tunnels to subtly change color grading during transitions.

Key Takeaway

Volumes scope effect application; profiles store the adjustable effect values you will tune for mood and clarity.
