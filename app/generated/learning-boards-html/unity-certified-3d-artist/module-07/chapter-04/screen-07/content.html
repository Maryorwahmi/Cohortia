Module 07 › Chapter 7.4 › Retargeting Demo
Steps to reproduce
Follow these Editor steps to see retargeting live in Play mode.
  1. Create CharacterA and CharacterB empty parents and place different humanoid models under each.
  2. Add Animator components to both parents and assign the same Animator Controller.
  3. Drag a humanoid animation clip into the controller as a state, save and press Play.
  4. Observe both models animating the same state; inspect avatars if motion looks off.
Scenario note
Use this pattern during early prototyping to test how a single animation fits multiple characters before committing to custom clips.
Example observation
If foot placement looks too high on the short model, retargeting may need to be combined with IK foot placement to correct contact points.
Tip
Retarget for general motion; reserve IK or custom clips for precise interactions like grabbing or precise foot planting.
