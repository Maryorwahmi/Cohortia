More Key Concepts
End Effector
The terminal joint in an IK chain, typically a hand or foot.
IK Weight
Blend value from 0 to 1 that controls IK influence over the animated limb.
Pole Vector
A hint transform that guides the bending direction of intermediate joints like elbows or knees.
Final takeaway
Combine retargeting for broad reuse with selective IK to handle runtime interaction. Validate avatars, set weights, and clamp targets for stable results.
