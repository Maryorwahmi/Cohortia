Module 07 › Chapter 7.4 › FK vs IK
Forward Kinematics (FK)
Animate by rotating parent bones; children follow. Best for authored, precise motion.
  • Artist controls joint-by-joint rotation.
  • Predictable curves and polish for full-body actions.
  • Poor at dynamic environment contacts without many variants.
Inverse Kinematics (IK)
Define where an end effector should be; solver computes joint rotations to reach it.
  • Great for foot placement, grabbing, aiming, and look-at behavior.
  • Works atop existing animations by adjusting specific limbs.
  • Requires care with target reachability and pole vectors for stable bending.
Practical pattern
Author base motion using FK. Apply IK to hands/feet/head to adapt to runtime objects and terrain. This limits the number of bespoke clips while keeping interactions realistic.
