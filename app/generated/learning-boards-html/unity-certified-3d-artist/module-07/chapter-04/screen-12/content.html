Checklist to diagnose IK issues
A short list of symptoms and fixes to stabilize IK behavior.
Symptom: IK has no effect.
Fix: Ensure IK weights are set and not being overwritten elsewhere.
Symptom: Limbs stretch toward target.
Fix: Clamp target distance to anatomical reach or use a fallback pose.
Symptom: Elbow/knee flips.
Fix: Set IK hint positions (pole vectors) to guide intermediate joint bending.
Debug tip
Visualize target transforms in the Scene view and step through OnAnimatorIK with logging to confirm values each frame.
Pole vector guide
Place a hint Transform in front of the elbow or knee direction you want. Use animator.SetIKHintPosition and SetIKHintPositionWeight to apply it.
Takeaway
Stability comes from validating weights, reachability, and hints; treat IK like a constrained solver rather than a magic position tool.
