OnAnimatorIK flow
A reliable pattern for setting IK each frame.
Typical steps
  • Compute or sample the world target (raycast for foot or scene object for hand).
  • Clamp the target to a reachable range for the avatar.
  • Call animator.SetIKPosition and SetIKRotation for the desired AvatarIKGoal.
  • Set IK weights with SetIKPositionWeight and SetIKRotationWeight to blend effect.
Common mistakes
  • Forgetting to set weights so IK has zero influence.
  • Feeding unreachable target positions without clamping.
  • Not resetting look-at or IK weights when disabling IK.
Key Takeaway
Use OnAnimatorIK to set targets and weights each frame, and always validate weights and reachability to avoid artifacts.
