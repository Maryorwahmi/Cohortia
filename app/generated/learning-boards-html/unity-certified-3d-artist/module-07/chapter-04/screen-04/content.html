Module 07 › Chapter 7.4 › What is Retargeting?
Retargeting — concept
Map authored motion to different humanoid anatomies using the Humanoid Avatar as intermediary.
How it works:
  • Author animation for a source model. Unity records animation data in a clip.
  • Both source and target are imported as Humanoid and have avatars.
  • Mecanim maps clip motion to the avatar; the avatar applies adapted motion to each model.
Key Takeaway
Retargeting saves time but requires validated avatars and correct rig settings to avoid artifacts.
Example: Tall Elf → Stocky Orc
Source
Tall Elf Walk
Author performed stride length and arm swing tuned for long limbs. The clip encodes the motion as rotations and curves.
Target
Stocky Orc
Avatar remaps motion so feet land and arms swing, but step height and rotation magnitudes adapt to shorter limb lengths.
Common mistake
Skipping avatar validation. A misaligned T-pose or wrong bone mapping causes unnatural rotations.
Pro tip
Always check the Avatar preview in the Rig import tab and correct bone assignments before relying on retargeted results.
