Editor checklist for Retargeting
A short process to make retargeting predictable in Play.
  1. Open FBX Importer → Rig tab → set Animation Type to Humanoid and Apply.
  2. Open Avatar Configuration, confirm T-pose and assign core bones (hips, spine, head, shoulders, arms, legs).
  3. Use the Avatar Validation preview to detect misaligned or missing bones; fix and reapply.
  4. Create an Animator Controller, add the clip, attach Animator components to both character parents, and assign the controller to both.
  5. Run the scene and verify both models play the same state; inspect the Animator and Avatar if motion looks wrong.
Example checklist item
If your model was authored in a different bind pose, correct the T-pose alignment before trusting retargeted results.
Quick troubleshooting
Symptom: Arms twist oddly after retarget.
Fix: Check avatar bone orientation, mirror settings, and reassign arm bones.
Symptom: Animation not applied on target.
Fix: Ensure both Animator components reference the same Controller and both rigs are Humanoid.
Key Takeaway
Small import misconfigurations break retargeting; validate avatars before runtime tests.
