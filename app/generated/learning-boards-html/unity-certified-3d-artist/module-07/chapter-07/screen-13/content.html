Module 8 › Chapter 7.7 › Assessment: Plan a Dramatic Sequence
Task Outline
Goal: Transition from desaturated to vibrant as the hero appears.
Camera: WideShot → CloseUp timed with the hero entrance.
Post-Processing: Animate Color Grading saturation or blend two volumes using Control Track.
Assessment Criteria

Clear camera beats, correctly bound Cinemachine Shots, PostProcessLayer present on main camera, and smooth saturation transition timed to the hero reveal.

Example Keyframes
// Animation Track for Color Grading Saturation
t = 0s  -> Saturation = -100 (desaturated)
t = 4s  -> Saturation = 0 (hero appears)
Common Mistake

Animating the profile asset rather than the instantiated volume can prevent Timeline from recording the changes. Animate the GameObject instance or use volume weight.
