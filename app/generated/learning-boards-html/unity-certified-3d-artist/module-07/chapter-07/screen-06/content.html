Role of the Brain
The Brain receives virtual camera outputs and blends them into the main camera transform during playback.
Bind vcams: ensure each Cinemachine Shot clip references the intended virtual camera.
Blend control: overlap clips to create a blend; adjust clip handles to set blend duration.
Nested control: add an Animation Track inside a Cinemachine Shot for properties like lens or noise.
Visual: Brain + Timeline
Cinemachine Brain
Composes active virtual cameras and blends during overlaps.
Cinemachine Track
Feeds Cinemachine Shot clips to the Brain for timeline-based control.
Key Takeaway

The Brain is the single composer of virtual cameras. Bind correctly and use clip overlaps for smooth cinematic transitions.
