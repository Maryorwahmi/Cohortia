Module 8 › Chapter 7.7 › Installing and Binding Cinemachine
Step-by-step
1. Open Package Manager → install Cinemachine.
2. Add Cinemachine Brain to the main Camera if missing.
3. Create vcams via GameObject → Cinemachine → Virtual Camera. Name them for shot intent.
4. In Timeline add a Cinemachine Track and drag each vcam into it to create Cinemachine Shot clips.
Practical Tip
If a clip is unbound in Timeline, drag its virtual camera into the clip's inspector slot to bind it. Naming vcams matters for readable timelines.
