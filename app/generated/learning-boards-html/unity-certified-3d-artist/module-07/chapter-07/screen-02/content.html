Module 8 › Chapter 7.7 › Learning Objectives
01
Install & Configure Cinemachine
Learn to add the Cinemachine package and ensure the Cinemachine Brain is on the main camera.

Create virtual cameras and assign follow and look targets so framing adapts to character movement. This saves time compared with manual keyframing and supports non-destructive iteration.

Verified Competency Milestone
02
Use Cinemachine Brain & Tracks
Bind virtual cameras to a Cinemachine Track and let Timeline control shot duration and blends.

Understanding the Brain's role prevents common errors where clips don't affect the main view. Proper binding gives you smooth automatic blends between shots.

Verified Competency Milestone
03
Apply Post-Processing Stack
Create global or local Post-Process Volumes and assign a Post-Process Profile with effects like Bloom and Color Grading.

Post-processing enhances mood and image fidelity. Using profiles keeps settings reusable across scenes and cinematics.

Verified Competency Milestone
04
Animate Effects in Timeline
Use Animation Tracks or Control Tracks to keyframe effect parameters or activate volumes at specific times.

Animating weights or property values gives you smooth visual transitions that match camera beats and storytelling choices.

Verified Competency Milestone
