Volume & Profile Workflow
Volumes define where effects apply; profiles store the effect settings you can reuse.
Create: Right-click → 3D Object → Post-process Volume. Check 'Is Global' for scene-wide use.
Profile: In Project, Create → Post-process Profile and assign it to the volume.
Camera: Add PostProcessLayer to the main camera and set the Layer property to match the volume.
Key Takeaway

Separate placement from configuration: volumes control where effects apply, profiles store consistent effect settings for reuse.

Common Mistake

If effects do not appear, check that the PostProcessLayer exists on the camera and that layer settings match the volume's layer.
