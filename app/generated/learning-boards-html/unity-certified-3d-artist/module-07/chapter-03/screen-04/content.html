Core Concept

Blend Tree — definition

A Blend Tree is a single Animator state that interpolates multiple clips based on one or more numeric parameters. It simplifies many similar states into a configurable node.

Why this matters
  • Reduces transitions and conditions in the Animator graph.
  • Makes locomotion and directional movement feel continuous and responsive.
  • Works naturally with analog inputs that produce floats.
Key Takeaway

Treat a Blend Tree as a dial you drive with parameters to blend related clips smoothly.

Illustration: 1D example
Idle
Threshold: 0
Walk
Threshold: 0.5
Run
Threshold: 1.0
Concrete example
Imagine a gamepad returning 0.3 for slow walking. The Blend Tree mixes Idle and Walk so the character lifts feet and leans forward gradually rather than snapping between two poses.
Common mistake
Incorrect thresholds can produce jerky transitions or gaps where no clip is dominant — always preview by dragging the parameter slider.
