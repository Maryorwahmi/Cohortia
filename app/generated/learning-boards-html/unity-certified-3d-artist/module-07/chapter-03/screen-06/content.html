Comparison

1D Blend Tree

Best for a single control value like speed. Simple to set up and easy to tune thresholds.

Example
Idle (0) → Walk (0.5) → Run (1.0) driven by Speed.
Comparison

2D Blend Tree

Use when two parameters, typically forward and sideways, determine which animation blend to play. Choose the 2D blend type that fits how clips are laid out.

Example
Forward, Backward, Strafe Left, Strafe Right blended by Forward and Sideways floats.
Common mistake
Using 1D when your controls are directional forces awkward crossfades and incomplete movement coverage.
