Definition

Thresholds

Assign numeric values to motion fields so the Blend Tree knows which clip should be active at which parameter value.

Preview tip
Use the Animator’s parameter slider to scrub values and observe clip weights in real time. Make adjustments while watching the character for smoothness.
Example scenario
A twin-stick control scheme often produces small input magnitudes while aiming; map your Walk threshold to the most frequent walking magnitude rather than averaging extremes.
Mistake to avoid
Don’t base thresholds on clip names or perceived energy. Base them on measured input ranges from playtesting to avoid unnatural blends.
Try this

Record joystick values during play and use the distribution to place thresholds where the player actually spends time.
