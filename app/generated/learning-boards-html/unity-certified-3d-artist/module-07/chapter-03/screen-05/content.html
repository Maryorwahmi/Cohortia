Process

Build the 1D Blend Tree

1
Create Blend Tree state
Right-click in Animator → Create State → From New Blend Tree. Name it Locomotion.
2
Add Speed parameter
In Parameters tab add a Float named Speed and set the Blend Parameter to Speed.
3
Add clips and thresholds
Add Idle (0), Walk (0.5), Run (1.0). Tune values while previewing the slider.
4
Set default state
Back in Base Layer, right-click Locomotion → Set as Layer Default State.
Validation & example
Normalize your runtime speed before feeding it to the Animator so that 0 maps to Idle and 1 maps to Run. Preview the blend in the Animator by dragging the Speed slider and watching the model. If transitions feel jerky, adjust thresholds and check that clips are authored to blend well.
Concrete code pattern
// Normalize speed example
float normalized = Mathf.Clamp(currentSpeed / runSpeed, 0f, 1f);
animator.SetFloat("Speed", normalized);
Common misconception
Thresholds are parameter values, not clip timing. Setting them wrong causes unexpected blends even with correct clips.
