Core Concept

Animation Layers

Layers let you run multiple state machines in parallel and blend their results. They are ideal for overlaying actions like aim, wave, or reload on top of locomotion.

Layer Weight
Weight controls influence. A value of 1 fully applies the layer to its masked bones; less than 1 blends with lower layers.
Example: UpperBody layer
Create a new layer named UpperBody, set Weight to 1, assign an Avatar Mask that selects spine, chest, shoulders, arms and hands, then add a Wave state to that layer. Trigger it via a WaveTrigger parameter.
Common pitfall
Forgetting an Avatar Mask makes the layer affect the whole skeleton, causing leg animations to stop when the upper body plays an action.
