Comparison

Weight: influence control

Weight = 1 fully applies layer to masked bones. Weight < 1 blends with layers below. Use lower weights for additive subtle motions, and full weight when overriding masked bones is required.
Sync option
Enable Sync to mirror the structure and timing of another layer. Useful for variations of the same state machine but dangerous if you want independent timing.
Common mistake
Turning on Sync unintentionally ties the layer lifecycle to another layer’s states, which can cause unexpected transitions.
