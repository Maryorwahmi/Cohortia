Process

Create Avatar Mask

  1. Create → Avatar Mask in Project window.
  2. In Inspector choose Humanoid and expand skeleton.
  3. Deselect lower body bones; select spine, chest, shoulders, arms, hands.
  4. Assign mask to layer Mask slot and set Weight appropriately.
Validation
After assignment, play a Wave animation on the UpperBody layer and confirm the Base Layer locomotion continues on the legs. If the legs stop, check that the mask actually has lower bones deselected and the layer contains only upper-body states.
Gotcha
An avatar mask will not fix an animation that already animates the entire skeleton — ensure the clip itself targets only the bones you intend, or use masks and retargeted clips.
