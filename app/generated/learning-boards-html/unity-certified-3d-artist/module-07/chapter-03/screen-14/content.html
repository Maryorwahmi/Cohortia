Lab Steps
  1. Prepare clips: Idle, Walk, Run, Wave.
  2. Create Locomotion 1D Blend Tree; add Speed parameter and thresholds 0, 0.5, 1.
  3. Create Avatar Mask UpperBodyMask and select upper bones only.
  4. Add UpperBody layer, set Weight=1, assign the mask, add Wave state and WaveTrigger.
  5. Wire PlayerMovementAnimator to set Speed and trigger WaveTrigger on input.
  6. Play and test: adjust thresholds and mask selections as needed.
Checkpoints
  • Blend Tree preview shows smooth transitions.
  • UpperBody wave plays while legs continue walking.
  • No unintended full-body overrides occur when WaveTrigger fires.
Why it matters

This lab teaches composition: blending related motions with Blend Trees and composing independent actions using layers and masks for scalable, maintainable Animator graphs.
