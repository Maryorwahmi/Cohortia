Module 7 › Chapter 7.3 › Key Concepts
Blend Tree
A state that blends clips by parameter values for continuous transitions.
Animation Layer
An independent state machine that can run parallel to the Base Layer and blend by weight.
Avatar Mask
An asset that specifies which bones an animation layer will affect, enabling partial overrides.
Summary

Combine normalized runtime parameters with Blend Trees and use masked layers for composed, responsive character animation.
