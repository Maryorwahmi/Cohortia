Steps
  1. Add new layer in Layers tab and name it UpperBody.
  2. Assign the Avatar Mask to the layer Mask slot and set Weight to 1.
  3. Add Wave clip as a state and create WaveTrigger in Parameters.
  4. Transition Any State → Wave with condition WaveTrigger and no Exit Time.
  5. From Wave set a transition back with Has Exit Time true and short duration.
Testing checklist
  • Press the configured input to fire the trigger and observe the upper body only.
  • Confirm base locomotion continues on the legs while Wave plays.
  • If legs stop, inspect the Avatar Mask and layer Weight settings.
Pro tip

Use short transition durations for transient actions to keep animation flow responsive.
