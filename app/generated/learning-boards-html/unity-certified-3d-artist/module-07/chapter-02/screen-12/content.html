Module 7 › Chapter 7.2 › Attach Controller to Character
Assign the controller
Select character → Inspector → Animator component → drag PlayerAnimatorController into Controller slot.
Check: Animator component exists on the correct GameObject.
Check: Avatar is assigned and matches rig for the model.
Root Motion: enable if animations move the model, otherwise move via script.
Troubleshooting
If animations don’t play, confirm the controller is assigned and the Animator is enabled.
Verification
Enter Play mode and observe the Animator window. Parameters and state nodes should be visible, and the default state should be active at startup.
Key Takeaway

The Animator component executes the controller at runtime; ensure the correct GameObject has both the Animator and assigned controller.
