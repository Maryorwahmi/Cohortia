Module 7 › Chapter 7.2 › Creating Transitions
Make Transition workflow
Right-click a source state → Make Transition → click target. Then select the transition to configure Conditions, Has Exit Time, and Transition Duration.
Configuration checklist
  • Add parameter-based conditions in the Conditions list.
  • Decide if Has Exit Time is needed; disable for locomotion responsiveness.
  • Tune Transition Duration to balance snappiness and smoothness.
Example
Idle→Walk with IsWalking == true, Has Exit Time unchecked, Duration 0.2.
Mistake
Leaving Has Exit Time enabled on locomotion causes input lag and poor responsiveness.
Practical tuning
Start with short durations (0.1–0.25) for player-controlled movement. For longer, stylized blends such as crossfades in cutscenes, increase duration. Always test in Play mode while adjusting parameters to observe responsiveness.
Key Takeaway

Transitions are tuned via conditions, Has Exit Time, and duration; tune these for the right balance of responsiveness and smoothness.
