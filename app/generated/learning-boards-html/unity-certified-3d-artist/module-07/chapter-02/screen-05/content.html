Authoring states
Drag clips into the Animator window to create state nodes. Entry and Any State are special, created automatically.
Practical steps
  1. Import Idle and Walk clips into Project.
  2. Open Animator window and drag Idle to create a state.
  3. Right-click Idle → Set as Layer Default State.
Example
Use Idle as default so your character starts idle before input arrives.
Pro tip
Use sub-state machines for grouped behaviors like combat or locomotion.
Visual checklist
Make sure states are clearly named. Avoid generic names like Clip1. Use descriptive names such as Idle, Walk, Run, Jump. This prevents confusion when creating transitions and conditions.
Key Takeaway

States are the building blocks of the Animator Controller; name them clearly and set the default to control initial behavior.
