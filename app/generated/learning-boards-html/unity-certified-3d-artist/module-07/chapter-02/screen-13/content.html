Module 7 › Chapter 7.2 › Common Mistakes
Delayed response
Cause: Has Exit Time enabled on locomotion transitions. Fix: uncheck Has Exit Time for immediate transitions.
No animation plays
Cause: Controller not assigned to Animator. Fix: assign PlayerAnimatorController to Animator component on the character.
Parameter mismatch
Cause: misspelled parameter name or wrong type. Fix: confirm names and types in Animator and code.
Dead-end states
Cause: missing outgoing transitions. Fix: add return transitions so every state can be left when needed.
Triggers misused
Cause: using trigger for persistent state. Fix: use Bool for persistent conditions and Trigger for one-shot events only.
Debugging tip
Open Animator during Play to watch parameter values change live and verify the expected conditions are set.
