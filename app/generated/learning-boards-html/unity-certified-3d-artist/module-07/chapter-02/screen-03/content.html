Module 7 › Chapter 7.2 › Learning Objectives — Skills
01 — Identify Mecanim parts
Recognize Animator Controller asset and Animator component on a GameObject. Milestone: open Animator window and see Entry and Any State.
VERIFIED COMPETENCY MILESTONE
02 — Author states from clips
Drag Idle and Walk clips into Animator to create states. Milestone: default state set to Idle and Walk state exists.
VERIFIED COMPETENCY MILESTONE
03 — Configure parameters & conditions
Create IsWalking (bool) and Speed (float) parameters and use them in transition conditions.
VERIFIED COMPETENCY MILESTONE
04 — Connect controller and script
Assign the controller to the Animator component and write code to call SetBool or SetFloat. Milestone: character responds to WASD input.
VERIFIED COMPETENCY MILESTONE
