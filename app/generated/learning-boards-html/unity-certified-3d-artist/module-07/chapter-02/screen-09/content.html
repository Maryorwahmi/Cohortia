Module 7 › Chapter 7.2 › Lab: Create Controller
Steps — Create Animator Controller
  1. Project window → Right-click → Create → Animator Controller.
  2. Name it PlayerAnimatorController and double-click to open the Animator window.
  3. Drag Idle clip into Animator to create Idle state, drag Walk clip to create Walk.
  4. Right-click Idle → Set as Layer Default State.
Verification: visually confirm Entry points to Idle and both states appear in the graph.
Why this matters
Setting the default avoids unexpected animation at scene start and establishes predictable runtime behavior.
Common issues
  • Clips not visible because they aren't imported or filtered in Project view.
  • State names unclear — rename to Idle/Walk for clarity.
Key Takeaway

Create the controller and states before wiring transitions; it keeps the workflow organized.
