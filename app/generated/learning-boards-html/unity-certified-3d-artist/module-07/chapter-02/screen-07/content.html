Module 7 › Chapter 7.2 › Animator Parameters
Parameter types and uses
Float — continuous values like Speed for blending between walk and run.
Int — discrete choices like WeaponType or Emote index.
Bool — persistent true/false states like IsWalking.
Trigger — one-shot events such as Attack that reset after use.
Concrete example
Set animator.SetBool("IsWalking", true) when player moves; set animator.SetTrigger("Attack") on button press.
Common mistake
Misspelling parameter names in code prevents transitions from firing.
Parameter checklist
  • Create parameters in the Animator Parameters tab before using them in conditions.
  • Use triggers for single events, not persistent states.
  • Test parameter changes in Play mode to observe behavior live.
Key Takeaway

Animator Parameters are the clean interface between scripts and the Animator Controller. Use them deliberately and verify names match.
