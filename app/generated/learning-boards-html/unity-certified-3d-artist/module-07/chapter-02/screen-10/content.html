Module 7 › Chapter 7.2 › Lab: Create Parameters
Add parameters
Open Parameters tab in Animator and add a Bool: IsWalking, and a Float: Speed.
Why each matters
  • IsWalking: explicit on/off state for transitions.
  • Speed: continuous value for blending and future run thresholds.
Mnemonic
Think Bool = switch, Float = dial.
Practical notes
Set parameters from code with animator.SetBool("IsWalking", value) or animator.SetFloat("Speed", value). Test names in Play mode to see values change in the Animator window.
Key Takeaway

Choose parameter types to match the decision you need: persistent, discrete, continuous, or one-shot.
