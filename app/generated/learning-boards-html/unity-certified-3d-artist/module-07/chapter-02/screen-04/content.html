Mecanim — a working definition
A visual state machine and toolset for choosing and blending animation clips driven by parameters from code.
Key points
  • Animator Controller contains states and transitions that reference clips.
  • Animator Component applies the controller to a GameObject at runtime.
  • Parameters are the contract between scripts and the controller.
Example
Set a Speed float in code and let Mecanim blend Idle, Walk, Run automatically.
Common mistake
Trying to manage all blends in code instead of using the Animator Controller makes tuning harder.
Analogy: traffic controller
Think of Mecanim as a traffic controller that directs which animation clip's traffic flows when parameters change. The Animator Controller decides the path, and the Animator component executes those instructions at run-time.
Check your understanding
If your character delays before running when you press the run key, is the likely cause a script timing issue or an Animator transition setting? Use the Animator to inspect Has Exit Time first.
Key Takeaway

Mecanim centralizes animation flow into a visual controller, making animation behavior easier to tune and reuse.
