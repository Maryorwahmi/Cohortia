Module 7 › Chapter 7.2 › Lab: Configure Transitions
Idle → Walk
Make Transition and configure: uncheck Has Exit Time, set Duration 0.2, add Condition IsWalking == true.
Walk → Idle
Create reverse transition with IsWalking == false and same duration settings.
Why disable Has Exit Time?
So the character responds immediately to player input rather than waiting for the current clip to reach an exit point.
Verification steps
  • Enter Play mode and press movement keys; IsWalking should change state in the Animator window.
  • Observe the blend between Idle and Walk; tune duration if the motion feels wrong.
Key Takeaway

Transitions must have clear outgoing paths and correct conditions; otherwise states can become unreachable or stuck.
