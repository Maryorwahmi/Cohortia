Module 7 › Chapter 7.6 › Add & Bind
Actions
  • Drag clip from Project onto a track to create a playable.
  • Trim or change clip speed to match timing.
  • Drag the Hierarchy GameObject onto the track header to bind it.
Tip: bind before recording keyframes so Timeline knows where to store property changes.
Example scenario
Add an Activation Track for the character, bind the character GameObject, then add an Animation Track and drag the Walk clip onto it. Ensure the character is initially disabled in the Hierarchy so the Activation Track reveals it at the correct time.
Common Mistake

Placing clips without binding the GameObject — the clip will not affect any scene object until bound.
