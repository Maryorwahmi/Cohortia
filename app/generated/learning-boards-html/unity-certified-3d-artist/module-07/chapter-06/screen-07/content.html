Module 7 › Chapter 7.6 › Animation Track
How to use clips
Drag animation clips to the track to create playables. Set start and end times, adjust speed, and use overlap to blend between clips automatically.
Recording
Select the bound GameObject and click the record button to key transforms over time. Ideal for camera pans and prop interactions.
Practical example
Place an 'Idle' clip, then drag a 'Walk' clip to start when the character enters. Overlap them slightly to let Timeline blend the transition.
Watch clip speed and loop settings to avoid sliding or unexpected repeats.
Key Takeaway

Animation Tracks are for clip placement and keyframe recording; use Animator Tracks when you need Animator-driven root motion and state behavior.
