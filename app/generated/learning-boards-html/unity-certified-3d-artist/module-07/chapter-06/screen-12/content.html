Module 7 › Chapter 7.6 › Control Tracks
Why nest timelines
Nesting keeps sequences modular. Create small Timeline Assets for reusable moments and trigger them from a master Timeline using a Control Track.
Benefit: smaller assets are easier to version, test, and update independently.
Example
Create a 'sparkle' Timeline for a particle effect and trigger it from the chest Timeline using a Control Track when the chest opens.
Key Takeaway

Control Tracks let you compose sequences from smaller, reusable Timeline Assets to keep cinematic projects manageable.
