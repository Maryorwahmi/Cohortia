Module 7 › Chapter 7.6 › Create Asset & Director
Step-by-step
  1. Create Timeline Asset in Project (right-click → Create → Timeline)
  2. Create an empty GameObject in the scene and name it (e.g., IntroSequenceManager)
  3. Add a Playable Director component to that GameObject
  4. Drag the Timeline Asset into the Playable field
  5. Open Window → Sequencing → Timeline to author tracks
Tip: store Timeline Assets in a dedicated folder and add to version control early.
Visual checklist
Timeline Asset
A file in your Project that holds tracks and clips.
Playable Director
Attaches to an empty GameObject and plays the asset in-scene.
Manager Pattern
Keep the director on a manager object to centralize playback and triggers.
Key Takeaway

A Timeline Asset plus Playable Director is the canonical pattern for reusable cinematic sequences in Unity.
