Module 7 › Chapter 7.6 › Key Concepts
Timeline
A non-linear editor that sequences tracks and clips to build cinematics.
Playable Director
Component that references and plays a Timeline Asset in a scene.
Tracks
Animation, Activation, Audio, Control — lanes that drive different elements over time.
Takeaway

Use the right track type, bind targets, and prefer Animator Tracks for root motion. Modularize with nested timelines and version Timeline Assets to keep work stable.
