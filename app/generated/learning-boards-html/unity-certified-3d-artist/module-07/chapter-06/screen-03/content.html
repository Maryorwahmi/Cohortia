01
Create a Timeline Asset
Right-click Project → Create → Timeline, then add a Playable Director to an empty GameObject and assign the asset.
VERIFIED COMPETENCY MILESTONE
02
Bind Tracks
Drag the target GameObject onto a track header to bind controls; unbound tracks have no effect.
VERIFIED COMPETENCY MILESTONE
03
Record Camera Motion
Use the record button on an Animation Track bound to a camera to capture position, rotation, and FOV keyframes over time.
VERIFIED COMPETENCY MILESTONE
04
Sync Audio & Events
Place audio clips on Audio Tracks and use snapping to line them up with visual events for precise timing.
VERIFIED COMPETENCY MILESTONE
