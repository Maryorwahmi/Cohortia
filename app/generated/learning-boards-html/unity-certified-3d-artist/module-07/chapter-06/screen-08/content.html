Module 7 › Chapter 7.6 › Animation vs Animator
Side-by-side
Animation Track
Best for cameras, props, and direct clip placement. Controls transforms directly.
Animator Track
Best for characters that rely on Animator Controller logic and root motion.
Practical guidance
  • Use Animation Tracks for camera pans and simple clip sequencing.
  • Use Animator Tracks when you need root motion or parameter-driven transitions.
  • Test movement in-play to check for sliding and adjust by switching track type if needed.
Common Mistake

Placing root-motion clips on Animation Tracks can cause sliding. Prefer Animator Track for root motion.
