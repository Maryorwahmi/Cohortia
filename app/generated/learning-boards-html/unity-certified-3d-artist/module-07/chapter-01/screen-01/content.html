Importing & Preparing 3D Animations
A practical guide to FBX import settings, rig configuration, clip splitting, and root motion decisions.
In this lesson

You’ll import an FBX, set the Rig type, configure the avatar, split the timeline into clips, and inspect root transform curves to decide whether to apply root motion.

Why it matters

Correct import prevents jumps, enables retargeting across humanoid characters, and keeps scripted movement and animated displacement in sync.

Explore Key Topics
FBX Import

Unity reads animations in FBX; inspect Rig and Animation tabs to make them useful for games.

Clip Splitting

Define precise start/end frames and enable Loop Time for seamless cycles like walk and idle.

Root Motion

Root-driven movement gives accurate displacement, but must not be doubled by scripts driving the transform.
