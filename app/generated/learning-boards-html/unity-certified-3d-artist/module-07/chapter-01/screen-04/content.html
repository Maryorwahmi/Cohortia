What Unity imports from an FBX
  • Geometry and mesh hierarchy.
  • Bone hierarchy and skinning information.
  • Animation curves and baked transforms.

Concrete Example
You import a Mixamo FBX that contains idle and walk cycles in one timeline. Instead of leaving the single default clip, you will split the timeline into two named clips and enable loop settings so the walk cycles smoothly in game.
Common Mistake

Relying on default import without checking Rig type; this can prevent retargeting or cause distorted limbs later.

Key Takeaway

Treat import as a verification step: inspect, correct, and only then use the asset in scenes.
