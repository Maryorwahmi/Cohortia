Module 07 › Chapter 7.1 › Loop Time & Loop Pose
Loop Time

Repeats the clip continuously. Use this for idles, walks, and any cyclic motions.

When to use
  • Idle, breathing, repeated gestures.
  • Walk cycles where footsteps repeat.
Loop Pose

Attempts to match start and end poses to avoid pops. Helpful for small mismatches but not a fix for badly authored cycles.

Misconception

Loop Pose will not repair completely different start and end poses. If the animation is misaligned, adjust frame ranges or fix in the source file.

Key Takeaway

Use Loop Time for repetition and Loop Pose to smooth minor mismatches. Always preview at runtime speed to validate.
