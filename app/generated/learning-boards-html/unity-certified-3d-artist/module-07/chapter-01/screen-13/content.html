Module 07 › Chapter 7.1 › Hands-on Activity
Activity Steps
  1. Import a sample FBX with multiple animations.
  2. Set Rig to Humanoid, Apply, then Configure Avatar and fix bones.
  3. In Animation tab, add clips, set frame ranges, enable Loop Time/Pose.
  4. Apply and preview clips; inspect Root Transform curves for displacement.
Verification

Preview each clip at playback speed. Look for smooth loops and check if forward motion exists in the Root Transform Position curves for the Walk clip.

Reflective Question

If Walk shows root displacement, will you use Apply Root Motion in-scene or move the character via script? Why?

Key Takeaway

Practice the import-to-verify loop: importing without verification invites runtime surprises.
