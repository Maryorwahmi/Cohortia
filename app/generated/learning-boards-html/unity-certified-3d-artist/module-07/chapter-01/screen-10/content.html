Module 07 › Chapter 7.1 › Root Motion Explained
What it is

Root Motion uses the animation’s root bone curves to drive the GameObject transform, so the character moves exactly as the animation dictates.

Why use it
  • Accurate foot placement and natural translation.
  • Useful for cinematic or tightly synchronized movement.
When to avoid

If you need deterministic physics-driven movement, network smoothing, or simple controller-driven displacement, prefer script-driven motion and keep Apply Root Motion off.

Common Mistake

Allowing both root motion and a script to set position — this creates doubled movement and jitter.

Key Takeaway

Decide whether animation or script owns translation. Don’t let both move the character at once.
