Module 07 › Chapter 7.1 › Learning Objectives
Verification Workflow
  1. Import FBX and inspect Model tab for scale/orientation.
  2. Set Rig type to Humanoid or Generic, click Apply.
  3. Open Configure Avatar, fix any red/yellow bones, confirm T-pose.
  4. Open Animation tab and split clips with precise frames, then Apply.
  5. Preview clips and check root transform curves for displacement.
Common Symptoms
  • Animation plays but character stays in place — root motion not applied.
  • Limb distortion — avatar bone mapping incorrect or T-pose mismatch.
  • Pops at loop boundary — frame range imprecise or Loop Pose disabled.
