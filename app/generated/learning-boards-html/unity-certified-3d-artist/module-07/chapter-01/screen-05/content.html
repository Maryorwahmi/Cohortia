Module 07 › Chapter 7.1 › Inspector Tabs
Step-by-step
Model
Check Scale Factor, import settings, and meshes. Fix orientation or scale before animating.
Rig
Choose Humanoid or Generic. Click Apply, then Configure Avatar to map bones.
Animation
Split clips, set frame ranges, enable Loop Time and Loop Pose when needed.
Misconception: Setting Humanoid automatically fixes all bone mapping. Reality: Configure Avatar is required to verify and correct mappings for reliable retargeting.
Concrete Scenario

You import a Mixamo character, set Rig to Humanoid, apply, then open Configure Avatar. You see a missing toe bone mapping marked yellow. You assign the correct bone and save. Without this, retargeting a different animation will distort the foot.

Key Takeaway

Run the same Inspector flow for every FBX to catch rig and clip problems early.
