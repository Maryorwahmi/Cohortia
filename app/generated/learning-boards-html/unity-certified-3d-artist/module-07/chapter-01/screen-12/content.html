Module 07 › Chapter 7.1 › Common Issues
Symptom

Character walks in place in scene but moves in preview.

Fix: Check Apply Root Motion on the Animator or check for scripts overriding transform movement.
Symptom

Limb distortions after retargeting.

Fix: Re-run Configure Avatar, assign correct bones, and ensure source T-pose matches Unity’s expected pose.
Symptom

Pops at loop boundaries.

Fix: Refine start/end frames and enable Loop Pose; if large mismatch, fix in DCC and re-export.
Key Takeaway

Diagnose the visible symptom, then apply the matching fix: rig type, avatar mapping, frame ranges, export settings, or Animator configuration.
