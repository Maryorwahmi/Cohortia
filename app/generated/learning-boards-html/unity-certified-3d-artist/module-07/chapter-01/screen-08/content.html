Module 07 › Chapter 7.1 › Splitting Clips
Step-by-step
  1. Open the Animation tab for the FBX asset.
  2. Click + under Clips to add a new clip and name it.
  3. Set Start and End frames precisely using the scrubber.
  4. Enable Loop Time and Loop Pose for cycles; click Apply.
Example: Isolate Idle from frames 0–45, Walk from 46–120. Check foot contacts to align loops.
Example Card
You add two clips, name them Idle and Walk. Idle is looped and requires minimal pose change at the end. Walk must have matching start/end foot positions. Use Loop Pose to blend their boundary.
Common Mistake

Using approximate frames so the first and last frames differ; this creates a popping loop. Scrub precisely and preview at playback speed.

Key Takeaway

Precise frame selection and Loop Pose are essential for seamless cyclic animations.
