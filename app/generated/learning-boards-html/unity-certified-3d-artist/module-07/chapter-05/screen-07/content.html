Parameter types
Float: Pass continuous values like intensity or volume.
Int: Pass discrete numbers such as damage amount.
String: Pass identifiers like "LeftFoot" to reuse handlers.
Object: Reference an asset or GameObject for advanced behaviors.
Signature requirement
The method must accept exactly the type you configured. If no parameter is used, define a parameterless public void method.
Examples
String example
public void PlayFootstep(string foot)
Use the string to select left or right foot sound.
Int example
public void TriggerAttackDamage(int amount)
Pass damage so a single handler can apply variable damage values.
Watch out

Changing a method signature after placing events can break calls. Keep scripts and clips in sync.
