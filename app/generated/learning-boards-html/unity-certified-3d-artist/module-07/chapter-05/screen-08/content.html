Key methods
animator.SetFloat("Parameter", value) — continuous values for Blend Trees.
animator.SetBool("Parameter", value) — binary states like IsGrounded.
animator.SetInteger("Parameter", value) — discrete selection indices.
animator.SetTrigger("Parameter") — fire a one-time transition event.
Example use
float vertical = Input.GetAxis("Vertical");
animator.SetFloat("MoveSpeed", Mathf.Abs(vertical));
if (Input.GetButtonDown("Jump")) animator.SetTrigger("JumpTrigger");
Best practices
  • Cache the Animator reference in Start for performance.
  • Match parameter names exactly between code and the Animator Controller.
  • Use GetCurrentAnimatorStateInfo to gate actions while another animation is active.
Key Takeaway

Animator parameter methods let code express intent while the Animator system handles blending and transitions; keep the boundary clean and explicit.
