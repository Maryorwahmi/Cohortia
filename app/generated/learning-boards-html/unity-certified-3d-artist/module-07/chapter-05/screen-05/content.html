Workflow
  1. Select clip. Open the animation in the Inspector preview to reach the timeline.
  2. Place marker. Move the scrubber to the target frame and click Add Event.
  3. Configure. Set Function name and optional parameter type and value.
  4. Apply. Click Apply on the clip so the event is saved with the asset.
Pitfalls
  • Misspelling the Function name causes a warning and no call.
  • Forgetting to Apply leaves temporary events that won't persist.
  • Events belong to the clip; reused clips will call the same Function for each GameObject using them.
Visual checklist
Marker placed
Ensure the marker sits exactly on the intended frame.
Function set
Function name must match a public method on the GameObject.
Parameter checked
If you pass a parameter, the method signature must accept the matching type.
Apply clip
Click Apply to make the event persistent on the asset.
Pro tip

Use clear Function names like PlayFootstep or TriggerAttackDamage so many events are easy to read in the Inspector.
