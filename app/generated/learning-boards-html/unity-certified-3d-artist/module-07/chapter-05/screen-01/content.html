Animation Events & Scripting Integration

Use animation timeline markers to call public C# methods and use script-driven parameter control to make animations respond to game state and player input.

Concept Map
Event → Method
A clip marker triggers a public method on the same GameObject.
Parameters
Float, Int, String or Object can be passed with the event.
Animator Control
Set parameters from code to drive blend trees and transitions.
Explore Key Topics
Three focused areas you will practice in this chapter.
Add Events
Place markers on a clip timeline and assign a Function name and optional parameter.
Event Methods
Write public handler methods that play audio, spawn effects, or apply damage safely.
Animator Params
