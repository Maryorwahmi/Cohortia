Definition

Animation Event

A frame-precise marker inside an animation clip that calls a public method on a component attached to the same GameObject as the Animator.

Why it matters
  • Sync audio and VFX exactly to animation timing.
  • Trigger gameplay logic at the visually correct moment.
  • Keep animation-driven behavior reusable across characters.
Common misconception

Events are not global; they call methods only on the same GameObject as the Animator and require public methods with matching signatures.

Example: Footstep
Add an event at each footfall frame and set the Function to PlayFootstep or PlayFootstepSound. The named method will be invoked at those frames to play an AudioClip via an AudioSource component.
Concrete example

If PlayFootstep is called by the event, ensure the method is public and that an AudioSource exists so the handler can call PlayOneShot without errors.

Example call
PlayFootstep() → plays a footstep sound when a foot hits the ground.
Parameter note
Events can pass a String like "LeftFoot" so one handler can choose which sound to play.
Key Takeaway

Use Animation Events for frame-accurate triggers, but add runtime checks so your game is robust if the event fails.
