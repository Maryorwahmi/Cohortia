State queries
IsName("AttackState") — check whether a specific state is playing on the base layer.
normalizedTime — returns progress; use thresholds to time follow-up actions or combos.
Example
var info = animator.GetCurrentAnimatorStateInfo(0);
if (info.IsName("AttackState") && info.normalizedTime > 0.7f)
{
  // allow combo
}
Guidance
  • Use normalizedTime thresholds, not exact values, to tolerate small timing variations.
  • Test thresholds with transitions and blends enabled in your Animator Controller.
  • Combine state checks with event handlers for redundancy when dealing with critical gameplay logic.
Pro tip

Use state checks to prevent input spam or conflicting animations, and validate normalizedTime values in Play mode for your specific controller.
