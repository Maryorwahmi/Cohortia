Module 07 › Chapter 7.5 › Key Concepts
Animation Event
A clip marker that calls a public method on the same GameObject at a specific frame.
Animator.SetX
SetFloat, SetBool, SetInteger and SetTrigger change Animator parameter values from code.
Parameters
Events can pass Float, Int, String or Object to the handler; signature must match.
Takeaway
Use events for precise timing and visuals, use scripting and physics checks for authoritative gameplay, and keep handlers safe and testable.
