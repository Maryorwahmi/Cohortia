Module 1 › Chapter 1.3 › Assessment: Robot Arm
Assessment Idea
// Structure
Create Empty → RobotArm
Create Cube → Shoulder → parent to RobotArm
Create Cube → UpperArm → parent to Shoulder
Create Cube → Elbow → parent to UpperArm
Create Cube → Forearm → parent to Elbow
Create Cube → Wrist → parent to Forearm
Create Cube → Hand → parent to Wrist
// Pivot proxy
Create Empty → Wrist_Pivot → position at wrist joint
Make Hand a child of Wrist_Pivot
Rotate Shoulder → entire arm follows
Rotate Elbow → downstream segments follow
Evaluation checklist
  • Hierarchy correctly parented
  • Pivot proxies used where needed
  • Local vs Global understood on rotated segments
Key Takeaway
A clean hierarchy and correct pivot placement enable joint-based animation and predictable transforms.
