Module 1 › Chapter 1.3 › Pivot Point
Definition

Pivot: rotation and scale origin

Pivot placement controls how an object rotates and scales. Incorrect pivots cause unnatural motion during animation or rotation.

Workaround — Pivot Proxy
  1. Create Empty GameObject at desired pivot location.
  2. Make the imported model a child of the Empty pivot.
  3. Rotate or scale the Empty to affect the child model as if its pivot were moved.
Misconception
Toggling Pivot/Center only affects editor selection behavior, it does not edit the model's stored pivot inside the mesh asset.
Key Takeaway

Use pivot proxies for quick in-editor pivot fixes and reserve re-exporting for permanent corrections when you have access to the source model.

Concrete Example — Sword Pivot
// Fixing a pivot in-editor
Import sword model → pivot at tip (undesired)
Create Empty → Sword_Pivot → position at hilt
Make Sword model a child of Sword_Pivot
Animate Sword_Pivot rotation to swing sword from hilt
Reflect
When working at scale, pivot proxies are quick; re-exporting is cleaner when you can correct many assets at source.
