Module 1 › Chapter 1.3 › Hands-on Activity
Step-by-step
// Scene setup: ObjectManipulationScene
Create Scene → save as ObjectManipulationScene
Right-click Hierarchy → 3D Object → Plane
Rename Plane → Floor
Set Floor Transform: Position (0,0,0) Scale (5,1,5)
Right-click Hierarchy → 3D Object → Cube → rename TableTop
Set TableTop Transform: Position (0,0.5,0) Scale (2,0.2,1)
Select TableTop → Ctrl/Cmd+D → rename TableLeg_1 → set Position/Scale for leg
Duplicate legs to make four legs and position them
Create Empty → rename Table_Group → parent TableTop and legs under Table_Group
Create Cylinder → rename RotatedCylinder → Rotate (45,30,60)
Practice toggling Local/Global and vertex snapping (hold V) while positioning
Why this helps
The recipe enforces naming, grouping, and consistent transforms — the habits that prevent errors later in animation and lighting passes.
Key Takeaway
Adopt a reproducible scene build pattern: create, name, parent, then refine with transforms and snapping.
Reflection
Which operation gave you the most time savings? Grouping and pivot management usually make the biggest difference.
