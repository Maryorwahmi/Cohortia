Learning Objectives

Master the skills to create, organize, and transform objects in a scene.

Bloom
Learn → Understand → Apply → Master
01
Differentiate GameObject & Component
Explain how a GameObject is a container and Components like Mesh Renderer add functionality. Recognize why Transform is always present.
Venn mnemonic: Container vs Function
VERIFIED COMPETENCY MILESTONE
02
Create, Duplicate, Delete
Perform scene assembly tasks: create empty, add primitives, duplicate with shortcuts, and delete unused objects to keep the Hierarchy tidy.
Timeline mnemonic: Add → Duplicate → Clean
VERIFIED COMPETENCY MILESTONE
03
Move, Rotate, Scale tools
Apply transform gizmos precisely and understand the visual cues for axes, handles, and uniform vs axis scaling.
Icon mnemonic: Arrows, Circles, Cubes
VERIFIED COMPETENCY MILESTONE
04
Parent-Child Relationships
Organize multiple parts under a parent for unified transforms, reuse, and predictable animation behavior.
Diagram mnemonic: Tree branches
VERIFIED COMPETENCY MILESTONE
