Core Concept

GameObject vs Component

GameObject is the identity and container; Components attach to add appearance and behavior. Always check Transform first when positioning.

Common Components
  • Transform — position, rotation, scale (present on every object)
  • Mesh Filter — holds the mesh geometry
  • Mesh Renderer — draws the mesh
  • Light — provides illumination in the scene
Misconception
The visible mesh is not the GameObject itself — it's a Component attached to the GameObject container.
Key Takeaway

Think in pieces: object identity (GameObject) and attached behaviors or visuals (Components) are separate so you can reuse and compose easily.

Concrete Example — Lamp
// Editor steps (illustrative)
Create Empty → rename to LampRoot
Add Component: Mesh Filter (assign lamp mesh)
Add Component: Mesh Renderer (assign material)
Create Child: Empty → add Light component → position at lamp bulb
// LampRoot holds identity; Mesh and Light are components
Check your understanding
  • Is Transform attached to every GameObject? Yes — it's required for spatial placement.
  • Would you edit a mesh inside Transform? No — edit the Mesh Filter or model source instead.
