Scene Hierarchy & Object Manipulation

Understand what GameObjects and Components do, and how transforms, pivots, and snapping let you place and animate parts precisely.

In this lesson
Create objects, group them, and master transform tools so your scene is clean and animatable.
Why it matters
Good hierarchy and precise transforms save hours when animating, lighting, and iterating assets.
Explore Key Topics
GameObject vs Component
GameObject is a container; Components provide mesh, renderer, lights, and behavior.
Transforms & Tools
Move, Rotate, Scale tools affect position, rotation, and size. Learn local vs global modes.
Hierarchy & Pivot
Parenting groups children so one transform controls many parts; pivot determines rotation origin.
Visual Concept
Table_Group
Parent empty object grouping top and legs so a single transform moves the table.
Pivot Proxy
Use an empty GameObject to define a custom pivot when imports lack one.
Quick Steps
  1. Create GameObject or 3D object.
  2. Attach or verify components (Mesh Filter, Mesh Renderer).
  3. Group parts under an empty parent for unified transforms.
Key Takeaway

Organize assets into parents and children and control transforms with the correct pivot and space mode to ensure predictable movement and animation.
