Module 1 › Chapter 1.3 › Parent-Child Relationships
Hierarchy

Group parts with parents for predictable transforms

Use empty GameObjects as logical containers so transforms apply to many children at once and scene organization becomes readable.

How inheritance works
  • Parent transforms affect children automatically.
  • Children store local transforms relative to their parent.
  • Use empty parents for pivot adjustments and logical grouping.
Misconception
Selecting multiple objects is not the same as parenting; a parent persists as structure while a multi-select is temporary and error-prone.
Key Takeaway

Design hierarchy intentionally: parents for assembly-level control and empty pivot proxies where animation or rotation points differ from mesh origins.

Concrete Example — Robot Arm
