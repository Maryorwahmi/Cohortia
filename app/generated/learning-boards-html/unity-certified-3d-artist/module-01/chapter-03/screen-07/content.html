Comparison

Global vs Local — choose the right frame of reference

Local aligns to the object's own axes; Global aligns to the scene. Use Local for object-relative adjustments, Global for scene alignment.

Global
Gizmos follow world axes; ideal for grid-aligned placement and consistent scene orientation.
Local
Gizmos align to object axes; ideal to move or extend rotated parts along their own direction.
Misconception
Switching modes does not alter Transform values; it only changes gizmo orientation. Numeric edits remain explicit and unchanged unless you modify them.
Key Takeaway

Pick Global for scene-aligned operations and Local when moving or extending parts relative to their own orientation. Use both as complementary tools.

Concrete Scenario
// Scenario: Rotated ramp
Create Ramp → rotate (0,30,0)
Press W → toggle Local → move along local Z to extend length
Observe how movement follows ramp direction rather than world X
// Use Local when you want object-relative movement
Check
When inside a rotated parent, Local movement uses the child's own axes, which themselves inherit parent rotations — plan your hierarchy accordingly.
