Module 1 › Chapter 1.3 › Create / Duplicate / Delete
Process Flow

Create → Rename → Position → Group

Adopt a short process when adding assets so each new object is meaningful and discoverable in the Hierarchy.

Steps (quick reference)
  1. Create: Right-click Hierarchy → Create Empty or 3D Object → Cube.
  2. Duplicate: Select object → Ctrl+D or Cmd+D.
  3. Delete: Select object → Delete.
  4. Group: Create Empty → name group → drag children into group.
Common Mistake
Duplicating without parenting or renaming leads to ambiguous objects. Always rename duplicates immediately.
Key Takeaway

Make creation and organization a single step: name and parent as you create to maintain a tidy Hierarchy.

Concrete Example — Building a Table
// Editor recipe
Right-click Hierarchy → 3D Object → Plane → rename Floor
Right-click Hierarchy → 3D Object → Cube → rename TableTop
Set TableTop Transform: Position (0,0.5,0), Scale (2,0.2,1)
Duplicate TableTop → rename TableLeg_1, set Position and Scale for leg
Duplicate TableLeg_1 three times and position legs
Create Empty → rename Table_Group → drag TableTop and legs into Table_Group
Select Table_Group → use Move/Rotate/Scale to manipulate the entire table
Try this
After duplicating, inspect children and materials. Change one material to verify whether instances share resources or are unique.
