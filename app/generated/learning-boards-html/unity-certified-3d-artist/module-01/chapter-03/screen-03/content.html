Learning Objectives — Precision & Control

Practice pivots, snapping, and local/global control for clean placement and animation-ready assets.

Bloom
Learn → Understand → Apply → Master
01
Local vs Global Space
Learn when the gizmo should align to world axes or to the object's own axes. Use Local for object-forward moves, Global for scene-aligned placement.
Icon mnemonic: Globe vs Compass
VERIFIED COMPETENCY MILESTONE
02
Pivot Handling
Identify a model's pivot origin, and use an empty GameObject as a pivot proxy when the import pivot is inconvenient for animation.
Diagram mnemonic: Hinge at the pivot
VERIFIED COMPETENCY MILESTONE
03
Snapping Techniques
Practice vertex, grid, and surface snapping to ensure modular assets meet cleanly without manual nudging.
Icon mnemonic: Magnet
VERIFIED COMPETENCY MILESTONE
04
Hands-on Scene Build
Assemble a floor, table group, and rotated object to exercise local vs global moves and snapping in a small scene.
Timeline mnemonic: Floor → Table → Test
