Module 1 › Chapter 1.1 › Customize and Save an Artist Layout
Layout recipe
  1. Drag Game tab next to Scene to create a split preview/edit setup.
  2. Dock Project to bottom across width for easy asset browsing.
  3. Keep Hierarchy left and Inspector right for fast selection and editing.
  4. Save layout via Window → Layouts → Save Layout and name it clearly.
Key Takeaway

Save multiple layouts for modeling, lighting, and UI work so you can switch quickly without rebuilding the workspace.

Concrete example

Create a layout named "Artist Layout" with a large Scene view for composition, a visible Game view for framing checks, and a wide Project window for quick drag-and-drop of textures onto materials.

Common mistake
Not testing the saved layout on a new project; saved positions may need small adjustments across different screen resolutions.
Pro tip
Keep a tiny floating window with frequently used tools or console logs for quick debugging while working on art.
