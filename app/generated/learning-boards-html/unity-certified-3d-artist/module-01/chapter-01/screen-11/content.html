Shortcut list
  • Q — Hand tool (contextual)
  • W — Move tool (translate along axes)
  • E — Rotate tool (orient object)
  • R — Scale tool (resize uniformly or per-axis)
  • F — Focus on selection
Key Takeaway

Practice switching tools by habit; it preserves flow and avoids repetitive menu clicks.

Example workflow

When aligning a decorative object, focus with F, nudge position with W, correct rotation with E, and scale to fit with R. Use snap and numeric fields for precise alignment when needed.

Common mistake
Trying to get pixel-perfect alignment by dragging alone; instead use focus and numeric input when precision is required.
Pro tip
Learn a short keyboard routine for frequent tasks so your hands rarely leave the keyboard.
