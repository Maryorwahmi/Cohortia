Module 1 › Chapter 1.1 › Activity — Build and Save an Artist Workspace
Step-by-step
  1. Create a new 3D Core project named ArtistWorkspace_YourName.
  2. Try Window → Layouts to compare Default, 2 by 3, and Tall.
  3. Dock Game next to Scene for a split view; Project at bottom; Hierarchy left; Inspector right.
  4. Save layout as "Artist Layout" and confirm it loads in a new project.
Key Takeaway

Follow the steps and check the layout loads in a fresh project to ensure portability.

Verification tasks
  • Import a model into Models/YourName and set Import Scale appropriately in the Inspector.
  • Place the model in the Scene, press F, orbit to inspect, then check in Game view.
  • Document your layout and import choices in a short README in the project root.
Common mistake
Not testing saved layouts across different monitor sizes. If it looks wrong, tweak and save again.
