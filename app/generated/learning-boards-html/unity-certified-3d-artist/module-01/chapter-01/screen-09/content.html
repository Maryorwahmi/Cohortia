Module 1 › Chapter 1.1 › Inspector Window — Adjusting properties
Inspector essentials
  • Edit import settings by selecting an asset in the Project window.
  • Tune material parameters like Metallic and Smoothness to control reflections.
  • Adjust transforms, light intensity, and camera FOV directly on selected GameObjects.
Key Takeaway

Use the Inspector to iterate quickly: make a small change, then check the Game view to validate the visible result.

Concrete example

Select a texture in the Project window and change its Compression or Max Size in the Inspector to balance quality and memory. Then assign it to a material and check lighting response in the Game view.

Common mistake
Editing a scene instance’s property when the underlying asset needs change. To alter import settings, select the asset in the Project window.
Pro tip
Use the Inspector search box to find a specific component quickly on complex GameObjects.
