Module 1 › Chapter 1.1 › Objectives — Practical outcomes
Objective Checklist
  • Identify Scene, Game, Hierarchy, Project, Inspector and describe their roles.
  • Navigate scene with middle-click pan, scroll zoom, right-click orbit and WASD fly keys.
  • Import a model, adjust import scale, and verify materials in the Inspector.
  • Create and save a custom Artist Layout for faster iteration.
Practice Examples
Import an FBX into a Models folder and set Import Scale to match your scene units.
Select the Main Camera and compare Game view to Scene view to check composition.
Use F to focus a small object and then orbit to check alignments and normals visually.
