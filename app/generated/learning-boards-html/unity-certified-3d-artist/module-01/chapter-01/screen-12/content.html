Module 1 › Chapter 1.1 › Import Settings and Model Adjustments
Import settings to check
  • Scale Factor / Import Scale — match scene units early.
  • Normals & Tangents — control shading and normal mapping behavior.
  • Mesh Compression & Read/Write Flags — balance memory vs fidelity.
  • Texture Max Size & Compression — manage visual quality and runtime cost.
Key Takeaway

Fix scale and shading at import so assets behave predictably and avoid later fixes that break links or animations.

Practical example

Import a prop and adjust Import Scale until it aligns with a 1.8 meter character model. Then inspect normals and assign material to verify shading under scene lights in Game view.

Common mistake
Rescaling instances in the scene instead of changing the import scale, which can break animation scales or prefab references.
Pro tip
Document import scale and texture compression standards in a team README to keep assets consistent.
