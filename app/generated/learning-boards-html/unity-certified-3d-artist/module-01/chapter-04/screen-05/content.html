Module 2 › Chapter 1.4 › Create & Assign
Step-by-step
1
Create Material
Right-click Assets/Art/Materials → Create > Material. Name M_PBR_Cube to keep projects organized.
2
Assign Textures
Drag Albedo, Metallic, Normal, and Smoothness textures into Inspector slots or use the picker.
3
Apply to Object
Drag material onto a Scene object or onto the Mesh Renderer material slot to see changes live.
Pro tip: keep a preview primitive to iterate on material properties in real time.
Example: Apply to a Cube
Create a Cube named PBR_Cube, set position to 0,1,0. After creating M_PBR_Cube, drag it to the cube. Adjust Metallic and Smoothness sliders to observe reflective behavior.
Key Takeaway

Material creation and assignment are straightforward repeatable steps that drive visual iteration.
