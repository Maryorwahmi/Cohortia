Module 2 › Chapter 1.4 › Lab Walkthrough
Editor Steps (visualized)
// Create and place preview object
Create -> 3D Object -> Cube
Rename: PBR_Cube
Transform.position = (0, 1, 0)

// Import textures
Assets/Art/Textures: copy Albedo.png, Normal.png, Metallic.png, Roughness.png
Select Normal.png -> Texture Type = Normal Map -> Apply
Select Roughness.png -> set non-color or invert for Smoothness

// Create material
Assets/Art/Materials -> Create -> Material -> M_PBR_Cube
Assign: Albedo -> Albedo slot
Assign: Metallic -> Metallic slot
Assign: Normal -> Normal Map slot
Assign: Roughness (inverted) -> Smoothness slot

// Apply
Drag M_PBR_Cube onto PBR_Cube and adjust Metallic and Smoothness sliders to observe changes
Explanation & Tips
  • Set Normal map type to ensure correct normal decoding by Unity.
  • Invert Roughness if your pipeline uses Smoothness instead.
  • Use tiling to avoid stretching; small objects may need smaller max size textures for performance.
  • Keep AO separate so you can tweak its influence independently.
Key Takeaway

Follow import and assignment steps closely. Small import mistakes are the most common source of incorrect material appearance.
