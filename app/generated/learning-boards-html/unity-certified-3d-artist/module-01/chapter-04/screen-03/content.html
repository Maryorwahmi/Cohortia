Module 2 › Chapter 1.4 › Skills Checklist
Prepare Textures
  • Import Albedo, Normal, Metallic, Roughness
  • Set Normal map Texture Type to "Normal Map"
  • Mark non-color data for masks and AO
Create Material
Create Material in Assets/Art/Materials and name descriptively. Assign textures to slots and adjust tiling.
Apply & Test
Drag Material to Mesh Renderer or object in Scene. Adjust Metallic and Smoothness to observe changes in real time.
