Property Comparison
Albedo
Base color map defining diffuse appearance for non-metals.
Metallic
0 means dielectric, 1 means metal; changes how reflections are colored.
Smoothness
Controls glossiness. Smoothness = 1 yields sharp reflections; 0 yields matte surfaces.
Normal Map
Fakes bumps and fine detail by changing surface normals without adding polygons.
Occlusion
AO darkens crevices for perceived depth from ambient lighting.
Example Pairings
Wood: Albedo texture + Metallic 0 + Normal for grain + Smoothness low. Metal: Neutral Albedo + Metallic 1 + Normal for dents + Smoothness per polish.
Common mistake: using a Roughness map without inverting it for Smoothness sliders. Check shader expectations and invert if necessary.
