Module 2 › Chapter 1.4 › Key Concepts
Material
Defines surface-light interaction and shader slots.
PBR
A physics-based model for consistent material behavior.
Standard Shader
Unity's built-in PBR shader with Albedo, Metallic, Smoothness, Normal, AO slots.
Albedo
Base color texture used as color data.
Metallic / Smoothness
Define reflection type and clarity; Roughness may need inversion.
Normal / Occlusion
Normal for bumps, AO for soft crevice shadows; import as non-color where appropriate.
Summary

Correct texture types and shader settings produce consistent, realistic surfaces that respond correctly to lighting.
