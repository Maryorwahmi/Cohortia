Core Concept

Naming conventions

Prefixes indicate type and speed up search. Keep names descriptive but concise to aid teammates and tools.
  • • SM_ for Static Meshes — e.g., SM_Tree_Oak_01
  • • T_ for Textures — e.g., T_Tree_Oak_Albedo
  • • M_ for Materials — e.g., M_Tree_Oak
  • • P_ for Prefabs — e.g., P_Door_Wooden
Example practice
When exporting assets from DCC tools, rename files before importing or immediately rename them in the Project window following the convention.
Common misconception
Using generic names like "New Material" or "Texture1". These names make debugging and collaboration harder later on.
Key Takeaway

Adopt short, consistent filename rules so assets remain easy to find, identify, and maintain.
