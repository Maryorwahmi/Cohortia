Best Practice

Version control for artists

Use a large-file solution and keep asset history safe. Don’t commit Library; commit scenes and ProjectSettings as needed.
  • • Use Git LFS or Perforce for textures and models.
  • • Exclude Library from version control; Unity rebuilds it.
  • • Commit scenes and small metadata files frequently.
Concrete example
Configure your repository to track Assets and ProjectSettings, enable Git LFS for large files, and perform commits after you finish importing and prefab assembly.
Common misconception
Thinking version control isn't needed for art. In reality it prevents lost work and helps teams roll back problematic changes safely.
Key Takeaway

Choose a large-file strategy early and commit often to keep artistic work safe and shareable.
