Activity: Set up your first art project

  1. Create a new Unity project using the 3D Core template and name it MyArtProject_YourName.
  2. In the Project window, create folders: _Scenes, Art/Models, Art/Materials, Art/Textures, Prefabs.
  3. Drag a simple model into Art/Models and its albedo into Art/Textures/Albedo.
  4. Check the imported model's Scale Factor in the Inspector and adjust if needed.
  5. Create M_YourAsset in Art/Materials, assign the texture to Albedo, apply material, then drag the GameObject into Prefabs as P_YourAsset.
Tips
  • • Name assets immediately using prefixes like SM_, T_, M_, P_.
  • • Import textures separately; avoid relying on embedded materials.
  • • Save your scene and commit to version control regularly.
Checkpoint

You should have a named prefab in Prefabs and the Assets folder following the recommended layout.
