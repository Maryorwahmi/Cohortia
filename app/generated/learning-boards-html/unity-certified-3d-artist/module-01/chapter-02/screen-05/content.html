Definition

Unity project folder anatomy

Learn the role of Assets, Library, Packages, and ProjectSettings so you make safe edits and collaborate effectively.

Assets
Your models, textures, materials, scenes, and prefabs. Edit here.
Library
Unity-managed cache. Do not edit directly; reimport if needed.
Packages
Package metadata and dependencies.
ProjectSettings
Shared project configuration; store in version control for team consistency.
Example scenario
If a texture appears wrong on another machine, ensure the file is present under Assets and reimport it rather than editing Library files directly.
Common mistake
Editing Library artifacts to "fix" an import. Unity will overwrite or corrupt these changes; reimport or delete Library safely.
Key Takeaway

Edit Assets only; treat Library as Unity's cache and use ProjectSettings for shared configuration.
