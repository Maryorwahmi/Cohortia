Definition

Texture Inspector essentials

  • • Texture Type: Default (albedo), Normal Map, or Mask for packed channels.
  • • Max Size: choose 512, 1024, 2048 depending on on-screen importance.
  • • Compression: reduces memory but can soften detail; test visually.
Always preview the texture on a material in the scene to validate choices for real-world viewing distances and lighting.
Example sizing guidance
Hero character albedo: 2048; prop albedos: 1024; tiling ground textures: 512. These are starting points; adjust per scene and platform.
Common misconception
Assuming highest resolution equals best results. Reality: high-resolution textures increase memory and load time; use resolution where it matters visually.
Key Takeaway

Match Texture Type to map role, choose sensible Max Size, and validate compression by testing in-scene.
