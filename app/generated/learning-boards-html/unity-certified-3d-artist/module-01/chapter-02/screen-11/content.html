Architecture

Import → Material → Prefab

Assemble imported assets into prefabs to capture components and references for reuse.
1. Import model to Art/Models/
2. Import textures to Art/Textures/
3. Create material in Art/Materials/ and assign maps
4. Drag configured GameObject to Assets/Prefabs as P_Name
Concrete example
Import a wall model, create T_Brick_Albedo, make M_Brick and assign the albedo, then save as P_Wall_Brick for level building.
Common misconception
Assuming prefab only stores mesh. Prefabs retain component settings, scripts, and material links which saves reconfiguring assets across scenes.
Key Takeaway

Make prefabs part of your import routine to ensure consistency and speed assembly tasks.
