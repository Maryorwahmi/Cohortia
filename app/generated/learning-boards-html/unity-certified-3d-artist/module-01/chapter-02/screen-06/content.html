Hierarchy

Recommended Assets layout

Assets/
├── _Scenes/
├── Art/
│   ├── Models/
│   │   ├── Characters/
│   │   ├── Environment/
│   │   └── Props/
│   ├── Materials/
│   ├── Textures/
│   │   ├── Albedo/
│   │   ├── Normal/
│   │   └── RoughnessMetallic/
│   ├── VFX/
│   └── Animations/
├── Audio/
├── Prefabs/
└── ThirdParty/
Why this layout helps
  • • Separation of concerns: art files grouped by type and usage improves discoverability.
  • • Easier bulk operations: when tweaking normal maps, you can operate on a single folder of Normal maps.
  • • Cleaner collaboration: teammates know where to check for models, textures, or prefabs.
Scenario
When adding a new tree asset, place the model in Art/Models/Environment, place its albedo in Art/Textures/Albedo, and create a material in Art/Materials named M_Tree_Oak.
Key Takeaway

Create and follow a folder scheme early so assets remain organized as your library grows.
