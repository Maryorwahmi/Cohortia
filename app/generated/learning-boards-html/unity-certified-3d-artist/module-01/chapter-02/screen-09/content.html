Comparison

Embedded Materials vs Unity-made Materials

Embedded Materials
May include shader assumptions; quicker but less predictable.
Unity Materials
Explicit shader choice and texture slots, predictable across projects.
Practical example
Import textures into Art/Textures and create M_Prop_Rock in Art/Materials. Assign Albedo and Normal maps, then save as a prefab for reuse.
Common mistake
Relying on embedded materials that reference non-existent shaders or incorrect texture paths. Reauthor materials in Unity to avoid this.
Key Takeaway

Author materials in Unity using imported textures for robust shader control and consistent visuals.
