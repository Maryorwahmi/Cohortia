Process Flow

Model import checklist

  1. Drag the model file into Assets/Art/Models/ appropriate subfolder.
  2. Select the model asset and open the Model tab in the Inspector.
  3. Adjust Scale Factor to match Unity scene units; test by placing the mesh in a scene.
  4. Review mesh compression, read/write, and collider generation settings.
  5. Import textures separately and create materials in Unity for consistent shader control.
Concrete example
If a Blender model is imported and appears too large, try Scale Factor 0.01 and re-check in the Scene view; this converts centimeters to meters for consistent placement with other models.
Common mistake
Leaving model scale unchecked and then manually resizing in Scene view for many assets. Fix by correcting the Scale Factor at import so physics and prefab sizes remain consistent.
Key Takeaway

Use a repeatable import checklist to avoid scale and collider inconsistencies across assets.
