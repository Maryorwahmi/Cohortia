Learning Objectives

Learn foundational setup and asset-management habits for 3D art projects in Unity.

01
Create a 3D Core project
Select the 3D Core template and initialize your project to prioritize art iteration without pipeline complexity.
Verified Competency Milestone
02
Understand Unity folders
Know what Assets, Library, Packages, and ProjectSettings hold and why you should not edit Library directly.
Verified Competency Milestone
03
Import assets correctly
Set model scale, texture type, and compression to balance fidelity and performance for the target platform.
Verified Competency Milestone
04
Apply naming & structure
Use prefixes like SM_, T_, M_ and a stable folder layout so others can find and reuse assets quickly.
Verified Competency Milestone
