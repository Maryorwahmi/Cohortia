Core Concept

Material vs Shader

Distinct roles and dependencies you must understand to author predictable surfaces.

Material (data)
Holds Albedo, Metallic, Smoothness, Normal, Occlusion, Emission maps and scalar values.
Shader (program)
Performs lighting and surface math on the GPU to convert material data into pixels.
Quick checklist
  • Materials supply values and textures.
  • Shaders interpret those values using lighting and camera data.
  • Swap shader to change rendering model without changing texture assets.
Example
Two toy models using the Standard Shader with different Albedo and Smoothness values produce distinct looks while the same shader executes rendering code for both.
Misconception
Calling a material a shader hides the difference: one is data, the other is code. They are not interchangeable.
Key Takeaway

Always think in terms of data versus execution: materials describe, shaders compute.

Visual Aid
Recipe analogy

Material lists ingredients like color and maps. Shader follows that list and mixes lighting math to produce the final rendered surface.

Practical check

If a texture has no effect, confirm that the active shader exposes that map slot and that the map is authored for a PBR workflow.
