Module 3 › Chapter 3.1 › What is PBR?
Definition

Physically Based Rendering (PBR)

A workflow that uses physically meaningful parameters so materials react predictably to lighting.

Core properties
  • Albedo — base color and diffuse reflectance.
  • Metallic — how metallic a surface is; affects reflectance color.
  • Smoothness — determines sharpness of reflections.
  • Normal map — simulates fine surface detail for lighting.
  • Ambient Occlusion — darkens crevices to simulate self-shadowing.
Why it matters
Consistency across environments, clearer artist intent, and reusability of materials.
Example
Set Metallic high and Smoothness high on a sphere to produce a bright, reflective metallic look under environment lighting.
Misconception
PBR is not a shortcut to realism without correct inputs. Textures and maps must be authored for a PBR workflow.
Key Takeaway

Use PBR parameters deliberately. Good inputs plus the Standard Shader produce predictable, physically plausible results.
