Key Concepts

A concise set of reminders from the chapter.

Material
Data asset with maps and values describing the surface.
Shader
GPU program that computes final color from material and lighting.
PBR
Physically motivated parameters for consistent lighting behavior.
Summary

Keep materials as clean data, pick shaders that match your needs, and author textures for PBR to achieve predictable, realistic results.
