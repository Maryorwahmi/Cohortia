Module 3 › Chapter 3.2 › Troubleshooting
Checklist

Diagnose visual issues

  • Normal Map looks wrong: ensure Texture Type = Normal Map.
  • Strange reflections: verify Metallic & Smoothness maps are not in sRGB.
  • Seams or stretching: inspect UVs and adjust islands, scale, or orientation.
  • Roughness vs Smoothness: invert maps or configure shader expectations.
Common Error

Applying all textures at once hides which map caused an issue. Add maps one by one to isolate the cause.

Checkered Test

Apply a checkered texture to the model to reveal UV stretching and inconsistent texel density. Use it before painting final textures.

Step-by-step debug
  1. Apply Albedo only and check color.
  2. Add Normal Map and verify surface detail.
  3. Add Metallic/Smoothness and verify reflections.
  4. Add AO and confirm crevice darkening.
