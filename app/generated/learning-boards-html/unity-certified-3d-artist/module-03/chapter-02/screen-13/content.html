Module 3 › Chapter 3.2 › Lab: Apply PBR Set
Lab Steps
  1. Create Textures folder and import files (Albedo, Normal, Metallic, Smoothness, AO).
  2. Set Normal Map texture type and Apply.
  3. Uncheck sRGB for Metallic, Smoothness, and AO as they are data maps.
  4. Create material, assign maps, place a cube in the scene, and apply the material.
  5. Toggle maps on and off, and adjust tiling to check scale and repetition.
Validation

Test under different light directions to ensure the material reacts naturally. Fix any Normal or sRGB issues and reapply.

Reflection Prompt

Which map had the largest immediate visual impact when you assigned it, and why? Use that observation to guide troubleshooting next time.
