Step-by-step

Import Checklist

  1. Create a Textures folder and drag files in.
  2. For Normal Maps: set Texture Type = Normal Map and Apply.
  3. For Metallic/Smoothness/AO: uncheck sRGB to keep data linear.
  4. Keep Albedo and Emission as color (sRGB enabled).
  5. Consider packing channels and set compression/max size appropriately.
Troubleshoot

If materials look wrong after assignment, re-open each texture's Inspector to verify type and sRGB settings before changing shaders.
