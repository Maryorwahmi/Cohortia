Lab Focus

Step-by-step tasks you'll perform to apply a PBR texture set and validate results.

Task 1
Import textures into a Textures folder

Drag and drop PNG or JPG files into the Project window and inspect default import settings.

Task 2
Configure Normal and data maps

Set Normal Map type and uncheck sRGB for Metallic, Smoothness, and AO when they are data maps.

Task 3
Create a material and assign maps

Place Albedo, Normal, Metallic, Smoothness, and Occlusion into material slots and observe the shaded result.

Task 4
Troubleshoot common mistakes

Diagnose incorrect Normal import, wrong color spaces, or UV issues and apply fixes.

Lab Hint

Keep a simple cube in the scene to quickly preview each map as you assign it. Change tiling to see scale issues immediately.
