Module 3 › Chapter 3.2 › AO, Height, Emission
Definition

Ambient Occlusion

A grayscale map that darkens areas where light is occluded. Use it to deepen crevices without changing scene lighting.

Height Map

Stores relative height values for parallax or displacement. Treated as data — disable sRGB.

Emission Map

Defines glowing areas. Emission is color data and typically stays in sRGB so hues are preserved.

Key Takeaway

Treat AO and Height as data maps and disable sRGB; treat Emission as color when it encodes color glow.

Stone Wall Example

Albedo for stone color, Normal for chipped faces, AO for darker mortar crevices, Height for deeper cracks, and Emission if bioluminescent moss is present.

Import Check
  • AO: uncheck sRGB.
  • Height: uncheck sRGB.
  • Emission: keep sRGB if it contains color information.
