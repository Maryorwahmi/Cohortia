Concept Overview
What is a Texture Map?

A texture map is a 2D image used by a shader to define visual traits like color, normals, reflectivity, and occlusion. Maps work together to simulate surface detail in PBR without adding geometry.

Why Import Settings Matter

Unity's texture importer interprets image data. Setting the correct Texture Type and color space prevents lighting errors and preserves data fidelity for non-color maps.
