Learning Objectives

Skills to demonstrate by the end of this chapter.

Bloom: Learn → Understand → Apply → Master
01
Identify PBR texture maps

Recognize Albedo, Normal, Metallic, Smoothness, AO, Height, and Emission maps and explain what each controls in a shader.

VERIFIED COMPETENCY MILESTONE
02
Configure texture imports

Set Texture Type for Normals and disable sRGB for data maps so values are preserved for shading calculations.

VERIFIED COMPETENCY MILESTONE
03
Explain UV mapping

Describe UV coordinates and why well-laid UVs prevent seams, stretching, and misalignment of textures on models.

VERIFIED COMPETENCY MILESTONE
04
Apply and troubleshoot

Assign Albedo, Normal, Metallic, Smoothness, and AO to a material and diagnose common visual issues like incorrect normal import or color-space errors.
