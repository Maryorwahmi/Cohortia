Walkthrough

Create Material and Assign Maps

  1. Create a material and name it, e.g., StoneWall_Mat.
  2. Assign Albedo to the Albedo slot and check color.
  3. Assign Normal Map, verifying Texture Type = Normal Map.
  4. Assign Metallic and Smoothness, or packed Metallic+Smoothness texture.
  5. Assign Ambient Occlusion to Occlusion slot and adjust tiling as needed.
Scene Preview

Use a cube to preview changes quickly. Watch how each map changes the shading so you can isolate the source of an issue.

Common Mistake

Assigning a Normal Map without changing its Texture Type will result in incorrect lighting. Always set it first.
