Module 3 › Chapter 3.2 › Albedo and Base Color
Definition

Albedo (Base Color)

A color map without lighting baked in. It provides hue and visible surface pattern for the shader to use with scene lighting.

Keep these in mind
  • Do not include shadows or specular highlights in Albedo.
  • Import as color texture with sRGB enabled.
  • High color fidelity helps for material mixing and decoration.
Common misconception

Some artists bake lighting into Albedo. This prevents accurate interaction with dynamic lights and breaks the PBR pipeline.

Key Takeaway

Treat Albedo as pure color data. Remove baked lighting so the shader can handle dynamic illumination correctly.

Practical Example: Wooden Plank
Albedo: grain, knots, and color variation. No shadows. Normal map provides perceived depth. AO darkens crevices.
Check your Albedo
  • Open the image and look for soft shadows — remove them if present.
  • Ensure color profile is suitable for art assets and export as PNG or TGA where needed.
Try this

Assign the Albedo to a material on a cube, then add a Normal Map. Notice how color stays consistent while shading changes with the Normal map.
