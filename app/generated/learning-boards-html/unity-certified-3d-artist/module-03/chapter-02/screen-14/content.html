What to Remember

Texture Map
A 2D image that encodes color or surface data used by a shader.
UV Mapping
Unwrap geometry into UV space so texture pixels map correctly to the model.
Import Settings
Set Normal Map type and disable sRGB for data maps to preserve numeric correctness.
Summary

Combine correct maps, clean UVs, and proper import settings to create believable PBR materials that respond to lighting predictably.
