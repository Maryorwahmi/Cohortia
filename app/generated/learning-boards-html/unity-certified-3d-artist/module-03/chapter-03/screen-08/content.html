Definition

Color Tinting & Emission

Albedo Tint: Multiplies the texture color so you can produce variations without new textures.

Emission: Adds self-lit color to the material; use an Emission Map to localize glow.

Intensity: Scales how bright the emission appears on the surface.

Misconception: Emission does not automatically cast real-time light onto other objects unless you add lights or bake GI.
Concrete Example
Use the same Albedo texture and tint it green to create a mossy variation quickly.
Enable Emission, assign the pattern as Emission Map, set color to cyan and Intensity to 2 for a glowing panel effect.
Pro Tip

Use emission selectively for readable indicators and pair with small lights for believable interactive illumination.
