Process Flow

Create & Assign

Follow these numbered steps to create a new Material asset and apply it to geometry so you can edit and preview it live.

  1. Create Material. Right-click in Project → Create → Material. Name it descriptively for reuse.
  2. Select Target. Pick a Plane, Cube, or model in the Hierarchy to test the material.
  3. Assign Material. Drag the material onto the object or its name in the Hierarchy.
  4. Open Inspector. Edit Albedo, Metallic, Smoothness and add textures as needed.
Key Takeaway

Assign materials to test meshes and iterate in the Scene. Naming and organization speed up reuse.
