Lab Walkthrough

Build a Glowing Panel

1. Create Plane: Hierarchy → 3D Object → Plane
2. Create Material: Project → Create → Material → M_SciFiPanel
3. Assign textures: Albedo (pattern), Normal Map, optional Metallic/Smoothness maps
4. Tiling: set X,Y to 5 to shrink pattern; Offset as needed to align motifs
5. Set Metallic 0.8, Smoothness 0.7 for a polished look
6. Enable Emission: assign map, pick color, increase Intensity to 2–3
7. If you need real light: add small Point Light or bake GI for emissive contribution
Example Values
Tiling: 5,5
Metallic: 0.8
Smoothness: 0.7
Emission Intensity: 2–3
Safety Tip
Avoid excessive tiling which reveals repetition. Use decals or variation maps to break patterns.
