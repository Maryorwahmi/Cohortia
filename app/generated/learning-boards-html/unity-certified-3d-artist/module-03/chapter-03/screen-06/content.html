Definition

Texture Map Roles

  • Albedo: Color detail and patterning; usually sRGB.
  • Normal Map: Encodes surface direction, import as Normal Map to read correctly.
  • Metallic: Grayscale or packed channel defining metalness per pixel.
  • Smoothness: Controls specular blur; may be a slider or a texture channel.
  • Occlusion: Ambient occlusion mask to darken crevices.
Practical Example
Assign wood_albedo.png to Albedo and ensure it is sRGB for correct color.
Import wood_normal.png as Normal Map to add bump detail without changing geometry.
Use wood_metallic.png only if parts of the material are metallic; otherwise set Metallic to 0.
Check each map in the Inspector and preview with lighting to confirm correct visual results.
