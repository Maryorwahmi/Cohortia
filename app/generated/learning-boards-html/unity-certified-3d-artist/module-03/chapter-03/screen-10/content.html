Problem vs Expectation

Problem: Purple or wrong colors on material.
Fix: Ensure Normal map is imported as Normal Map and placed in the Normal slot.
Problem: Bright emission, no scene illumination.
Fix: Add real lights for dynamic illumination or enable baked Global Illumination for emission contribution.
Problem: Textures look oversized or stretched.
Fix: Adjust Tiling and check model UVs; reduce tiling to hide repetition and fix seams with offset or decals.
Checklist
  • Confirm each texture is in the correct slot.
  • Verify import type: Normal Map vs sRGB color textures.
  • Use physically plausible Metallic/Smoothness combinations.
  • Test on a neutral plane under consistent lighting.
Pro Tip

Keep a small library of test materials and a neutral preview mesh so you can compare changes quickly.
