Module 4 › Chapter 3.5 › Emission: Visual vs Scene Light
Visual emission
Makes pixels appear bright on the object itself but doesn't automatically light the environment.
What you see
The object looks glowing even in dark scenes because the shader outputs brightness for those pixels.
When environment is affected
Set Emission GI to Baked or Realtime and bake lighting, or use Realtime GI, to allow emission to contribute indirect lighting.
Concrete example
A rune stone with Emission only looks bright; set Emission GI to Baked and mark static, then bake to make the surrounding plane pick up a subtle colored tint.
Practice steps
Enable emission, set GI to Baked, mark object Static, open Lighting settings and Generate Lighting. Observe lightmap tint changes.
Pitfall
Relying only on emission for directional lighting removes cues and realistic shadows; combine with low-intensity real lights for clarity.
Key Takeaway

Enable Emission GI and bake for static glow that affects surroundings; use realtime GI only when dynamic contribution is strictly required and budget allows.
