Module 4 › Chapter 3.5 › Global Illumination
Baked GI
Precomputes indirect lighting into textures for static geometry. Efficient at runtime and great for stable environments.
When to use
Static scenes or static parts of a scene where you want affordable high-quality indirect light and color bleeding.
How emission fits
Set material Emission GI to Baked and mark object Static so its glow is baked into lightmaps as indirect light.
Realtime GI
Updates indirect lighting each frame and supports dynamic elements but at higher runtime cost and complexity.
When to use
Use for moving emissive objects or when light intensity changes during gameplay and budget allows.
Tradeoffs
Realtime GI can be expensive; profile and prefer baked GI for static scene elements to save memory and CPU/GPU time.
Key Takeaway

Prefer baked GI for static emission to get cheap indirect lighting; reserve realtime GI for dynamic needs and always consider performance tradeoffs.
