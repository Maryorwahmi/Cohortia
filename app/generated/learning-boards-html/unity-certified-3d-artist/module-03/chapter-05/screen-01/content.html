Lighting Interactions and Emission
Learn how different Unity light types affect PBR materials, how Emission maps create self-illuminating surfaces, and when emission actually contributes to Global Illumination.
In this lesson
PBR, light types, emission, and baking workflows.
Why it matters
Lighting defines mood and material realism; emission adds practical atmosphere without heavy geometry.
Visual Concept
Interactive 16:9 Masterclass
Light types alter highlights and shadows.
Emission can tint surrounding surfaces when baked.
Explore Key Topics
Light Types
Directional, Point, and Spot lights each create different falloff and shadow patterns that change material appearance.
Emission Maps
Use an emission map to make pixels appear self-lit; set color and intensity to control glow.
Baked GI
For static scenes, bake emission into lightmaps so glowing objects tint nearby surfaces affordably.
