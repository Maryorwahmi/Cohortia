Common mistakes
Watch for these frequent errors when using emission and GI.
Over-bright emission
High intensity can hide surface detail and break perceived material properties; test with final exposure settings.
Unnecessary realtime GI
Use realtime GI only when objects move or emission changes at runtime; otherwise prefer baked GI for performance.
Oversized lightmaps
Large resolutions increase build times and memory; tune resolution per-object and per-platform.
Static flag omission
Forgetting to mark objects static prevents emission from being included in baked lightmaps.
Key Takeaway

Tune emission and bake settings thoughtfully, prefer baked GI for fixed glow, and profile on target hardware to avoid runtime surprises.
