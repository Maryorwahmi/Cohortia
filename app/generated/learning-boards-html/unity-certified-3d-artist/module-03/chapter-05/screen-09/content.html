Module 4 › Chapter 3.5 › Material → GI Configuration
Inspector steps
A clear checklist prevents missed steps when baking emission into lightmaps.
1. Enable Emission
Check Emission, assign Emission Map, choose Emission Color and set Intensity.
2. Set GI mode
In Emission dropdown select 'Baked' for static contribution or 'Realtime' if needed and supported.
3. Mark object Static
Select the object in Hierarchy and enable the Static checkbox so it is included in lightmapping.
Baking steps
Control baking from the Lighting window to produce lightmaps that include emission contribution.
Open Lighting Settings
Window → Rendering → Lighting → Settings. Uncheck Auto Generate for manual control if preferred.
Generate Lighting
Click Generate Lighting to bake; inspect the lightmaps and scene to confirm the emission tint.
Common oversight
Forgetting to mark the object Static or leaving Emission GI on 'None' are the most frequent reasons emission does not affect the bake.
Key Takeaway

Follow the Inspector checklist and bake process: enable emission, choose GI mode, mark static, then generate lighting to capture emission into lightmaps.
