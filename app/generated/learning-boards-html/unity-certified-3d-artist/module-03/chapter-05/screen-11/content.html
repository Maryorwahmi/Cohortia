Module 4 › Chapter 3.5 › Bake & Iterate
Bake checklist
Use controlled bakes to tune emission impact and manage cost.
1. Bake control
Turn off Auto Generate if you want manual iteration. Adjust lightmap resolution and padding with care.
2. Tune emission
If tint is weak, increase intensity or tweak the map; if too bright, lower intensity or reduce emissive area.
3. Compare results
Bake with and without the Point Light to evaluate emission-only versus combined lighting approaches.
Memory note
Higher lightmap resolution improves quality but increases memory and bake time; optimize per target platform.
Misconception
A single bake will not automatically match runtime exposure changes; bake with final post-processing settings to match in-game appearance.
Key Takeaway

Bake intentionally: iterate emission and lightmap settings, compare emission-only and mixed lighting, and monitor memory and build time when increasing resolution.
