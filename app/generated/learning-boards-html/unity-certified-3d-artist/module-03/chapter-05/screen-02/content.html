Learning Objectives
Use these milestones to verify competency in lighting interaction, emission setup, GI configuration, and practical optimization.
01
Predict material response to light
Explain how Directional, Point, and Spot lights affect Albedo, Metallic, and Smoothness values. This helps you place lights for believable highlights and silhouettes.
VERIFIED COMPETENCY MILESTONE
02
Author Emission maps and color
Create or assign an emission texture and set an intensity and color so glow reads correctly at your target exposure and platform.
VERIFIED COMPETENCY MILESTONE
03
Differentiate real-time and baked GI
Choose between dynamic lighting for moving objects or baked lightmaps for performance on static geometry.
VERIFIED COMPETENCY MILESTONE
04
Configure material contribution to GI
Set the Emission 'Global Illumination' dropdown to the correct mode and mark static objects before baking lightmaps.
VERIFIED COMPETENCY MILESTONE
