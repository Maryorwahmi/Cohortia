Module 4 › Chapter 3.5 › Glowing Rune Stone
Step-by-step
Follow these steps in Unity to author an emissive rune that contributes to baked GI.
1. Scene setup
Create a Plane and Cube, position cube slightly above plane, and mark both Static in the Inspector.
2. Material
Create M_RuneStone, set Albedo to dark gray, Metallic 0.1, Smoothness 0.2, enable Emission, choose blue color and Intensity 5, assign black-and-white rune texture to Emission map.
3. GI and lighting
Set Emission 'Global Illumination' to Baked, add a Point Light with intensity ~0.5 and warm color for contrast, open Lighting Settings and generate lighting.
Expected result
After baking, nearby static surfaces show a soft blue tint from the rune emission blended with the orange point light.
Variation
Change Emission Color to red and re-bake to see how indirect lighting color shifts in the lightmaps.
Key Takeaway

This practical flow shows how to author emission and include it in baked GI for a convincing, performance-friendly glow.
