Module 3 › Chapter 3.4 › Outline Shader Walkthrough
Step-by-step
Create properties and connect Position and Normal to push vertices away along normals.
// Graph steps (informational)
1. Create Float property: OutlineWidth = 0.01
2. Create Color property: OutlineColor
3. Add Position node (Object space)
4. Add Normal Vector node (Object space)
5. Multiply: Normal * OutlineWidth
6. Add: Position + (Normal*OutlineWidth)
7. Connect Add -> Vertex Position
8. Connect OutlineColor -> Base Color / Fragment
9. Graph Settings: Render Face = Both; Surface = Opaque
Test case
Sphere: OutlineWidth 0.02, OutlineColor bright magenta.
Common error
Too-large offsets cause silhouette overlap and Z-fighting; keep values conservative.
Material creation
Save the Shader Graph, then create a Material from the graph asset. Adjust OutlineWidth and OutlineColor from the Inspector to iterate quickly.
Check your understanding

Why does setting Render Face to Both make the outline visible? Consider how vertex offsets affect backfaces.
