What is a Material Instance?
A variation of a base material that keeps the same shader and structure but exposes property differences so Unity can still batch rendering when possible.
Definition: Multiple objects reference a shared material or shader while per-object values are supplied via property blocks or instanced parameters.
Why it matters: Reduces draw calls and GPU overhead in scenes with many repeated assets like foliage or modular pieces.
Common mistake: Duplicating materials for small color changes, which increases draw calls unnecessarily.
Concrete example
Use one base material M_Rock and vary Albedo with a material property block or GPU instancing rather than creating M_Rock_Variant1, M_Rock_Variant2, etc.
Visual checklist
  • Same shader and render state across objects
  • Identical material identity where possible
  • Use property blocks for per-instance tweaks
Key Takeaway

Use shared materials and instances to keep draw calls low; profile results with the frame debugger.
