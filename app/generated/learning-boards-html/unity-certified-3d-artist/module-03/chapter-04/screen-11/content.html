Module 3 › Chapter 3.4 › When to use Custom Shaders
Decision steps
  1. Do you need a non-PBR look? If yes, consider custom shaders.
  2. Do you need vertex manipulation or time-based procedural motion? Use Shader Graph.
  3. Can the required effect be approximated with maps or the Standard Shader? If so, prefer built-in shaders.
Examples
Use Standard Shader
Photorealistic metal, wood, and PBR surfaces where built-in lighting models suffice.
Use Custom Shader
Toon shading, outline effects, vertex wind, time-based distortions, and special transparency behaviors.
