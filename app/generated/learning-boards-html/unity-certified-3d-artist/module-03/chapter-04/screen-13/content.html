Material Instancing
Share a base material and vary properties to preserve batching and reduce draw calls.
Shader Graph
Node-based shader creation: nodes, connections, and properties compile to GPU code.
Texture Optimization
Right-size, compress, and atlas textures to save memory and reduce texture swaps.
Takeaway

Balance visual goals with performance: reuse materials, expose useful properties, optimize textures, and always profile to guide decisions.
