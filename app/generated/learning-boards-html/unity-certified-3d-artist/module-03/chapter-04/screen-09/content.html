Module 3 › Chapter 3.4 › Texture Optimization
Key texture strategies
Max size, compression, and atlasing are primary levers to reduce VRAM and binding overhead.
Max Size: Reduce resolution for distant or small objects; use tiled textures for repeating surfaces.
Compression: Choose formats like ETC2 or ASTC depending on platform to shrink memory use.
Atlas: Pack many small textures into one texture to reduce swaps and improve batching.
Concrete example
UI sprites: one atlas instead of many PNGs reduces texture bindings and memory overhead. Test the compressed build to verify visual trade-offs.
Common mistake

Using uncompressed PNG textures everywhere increases build size and VRAM dramatically. Use Unity compression for deployed builds.
