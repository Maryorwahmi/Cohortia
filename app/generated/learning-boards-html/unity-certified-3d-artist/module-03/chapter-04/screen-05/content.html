Module 3 › Chapter 3.4 › GPU vs Material Instancing
Side-by-side
GPU Instancing
Single draw call for many identical meshes; uses per-instance data for transforms and small parameters.
Material Instancing
Share material assets and vary properties through property blocks or exposed parameters to preserve batching.
Example:
A field of identical grass: use GPU instancing with per-instance sway. If you create many unique materials for color variation, you remove the benefit of GPU instancing.
Checklist to enable instancing
  • Shader must support instanced properties.
  • Render states (blend, culling) must match across instances.
  • Avoid unique material assets for each variation when possible.
Pro tip

Prefer passing color or small offsets as instanced properties rather than duplicating materials. Use property blocks for per-object tweaks when instancing is not enabled.
