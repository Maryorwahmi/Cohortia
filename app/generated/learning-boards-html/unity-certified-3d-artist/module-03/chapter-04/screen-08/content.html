Expose parameters for artists
Properties convert graph inputs into Inspector controls. Name and default values matter.
Example properties
OutlineWidth (Float, default 0.01), OutlineColor (Color), MainTex (Texture2D)
Enable GPU instancing
If per-object data is required, mark properties as instanced and enable GPU instancing on the material.
Workflow card
  1. Define property in Shader Graph
  2. Save graph and create a Material
  3. Adjust property from Material Inspector
Misconception

Exposing many parameters is not always better. Limit exposure to what artists will actually use and profile the shader when adding features.
