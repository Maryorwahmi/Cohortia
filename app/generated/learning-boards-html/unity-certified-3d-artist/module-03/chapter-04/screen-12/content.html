Module 3 › Chapter 3.4 › Pitfalls & Practices
Avoid
  • Duplicate materials for tiny color changes.
  • Use uncompressed textures for deployed builds.
  • Add expensive node chains without profiling.
Adopt
  • Test batches with the frame debugger.
  • Right-size and compress textures for target platforms.
  • Expose only necessary shader properties with good defaults.
Workflow tip
Keep a small profiling scene to measure real impact as you iterate on shaders and textures.
