Module 4 › Chapter 4.1 › Performance Strategies
Checklist

Optimize realtime lighting

  • Use culling masks to limit a light's affected layers.
  • Disable shadows for non-critical lights.
  • Bake static lighting and use probes for dynamic objects.
Concrete example
In a room with many lamps, allow only nearby lamps to cast realtime shadows; bake the rest to preserve fidelity at lower runtime cost.
Key Takeaway

Profile first, then apply culling masks and shadow limits to the lights that most affect performance while retaining visual priorities.

Optimization cards
Culling Mask
Assign layers to a light so it only affects essential objects, like the player or specific scene elements.
Shadow Casters
Mark only the lights that need to cast shadows; disable casting on decorative lights.
Bake vs Realtime
Bake static sources and reserve realtime lights for moving elements to reduce per-frame load.
