Learning Objectives

Progress from recognition to application to optimization.

Learn → Understand → Apply → Master
01
Identify realtime light types
Recognize Directional, Point, Spot, and Area lights and when each is appropriate. This prevents improper choices that hurt look or cost.
VERIFIED COMPETENCY MILESTONE
02
Configure light properties
Set color, intensity, range, and cone angles to achieve mood and realistic falloff across scenes.
VERIFIED COMPETENCY MILESTONE
03
Implement realtime shadows
Enable hard or soft shadows and adjust resolution and distance to balance fidelity and performance.
VERIFIED COMPETENCY MILESTONE
04
Optimize realtime lighting
Use culling masks and limit realtime shadow casters so scenes run smoothly while retaining key lighting effects.
VERIFIED COMPETENCY MILESTONE
