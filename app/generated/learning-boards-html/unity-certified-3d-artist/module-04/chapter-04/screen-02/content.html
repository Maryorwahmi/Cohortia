Shadow Cascades
Configure cascade count and split distances so near shadows have higher resolution. Verified competency milestone: visual test with near/far shadow comparison.

Bias Tuning
Adjust shadow bias and normal bias to remove acne while avoiding peter-panning. Milestone: remove acne on a test cube without detached shadows.
03
Lightmap Parameters
Create per-object parameters for resolution, padding and AO. Milestone: bake a scene with visible difference between high- and low-res objects.
04
Culling & Layers
Limit which lights affect objects using culling masks and light layers. Milestone: reduce per-frame light cost on test scene without visible regressions.
VERIFIED COMPETENCY MILESTONE
How we'll practice
  • Run cascade experiments and tune split values while moving the camera.
  • Tweak bias values on test geometry until acne is gone and shadows remain attached.
  • Create Lightmap Parameters assets and assign them to static meshes, then bake and inspect the lightmap density.
  • Apply culling masks or light layers to limit unnecessary light influence and measure improvements.
