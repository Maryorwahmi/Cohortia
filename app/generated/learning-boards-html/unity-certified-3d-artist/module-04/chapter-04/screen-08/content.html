Module 4 › Chapter 4.4 › Lightmap Parameters
Core properties
  • Scale In Lightmap: per-object resolution multiplier.
  • Padding: separation between UV charts to prevent bleeding.
  • Bake AO: toggle and intensity for per-object ambient occlusion.
  • Backface Tolerance: prevents light leaking through thin geometry.
  • Is Transparent: marks meshes whose materials allow light through during baking.
Why it matters

Per-object control lets you give hero assets crisp bakes without inflating the global lightmap size.

Practical example
Create a Lightmap Parameters asset named HighResProps and set Scale In Lightmap to 2.0. Make another named LowResBackground and set it to 0.5. Mark relevant objects static and assign each asset in the Mesh Renderer under Lightmap Settings. Bake and inspect the lightmap textures to confirm density differences.
Common mistake

Raising global resolution wastes memory. Prefer multiple parameter assets for targeted control.
