Troubleshooting checklist
  1. Identify expensive realtime lights and consider baking them for static geometry.
  2. Check shadow distance and cascade settings for directional lights to avoid wasted resolution.
  3. Inspect lightmap UVs for overlaps and adjust packing for efficient bake times.
  4. Set reflection probes to baked when realtime updates aren’t required.
Quick misconceptions
  • Raising global lightmap resolution fixes everything — false; prefer per-object scaling.
  • More cascades always equal better quality — false; too many cascades raise draw cost.
  • Bias only hides problems — partly true; proper bias tuning reduces artifacts but must be balanced to avoid detaching shadows.
