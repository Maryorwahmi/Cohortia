Culling Mask

Set the light's culling mask to exclude layers that should not be affected. This is a fast way to prevent unnecessary lighting calculations on unaffected objects.

Example
Lamp affects only Prop layer — deselect Player and Environment from culling mask.
Light Layers (URP/HDRP)

Light Layers require assigning matching layers to both lights and renderers. Use them to create groups like PlayerLights or FXLights so interactions remain explicit and efficient.

Common mistake

Assuming layers are only organizational loses optimization opportunities. Proper layer use can significantly lower per-frame light cost.
