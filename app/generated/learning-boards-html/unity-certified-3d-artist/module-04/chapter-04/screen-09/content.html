Module 4 › Chapter 4.4 › Lightmap Workflow
Step-by-step
  1. Create Lightmap Parameters assets: HighResProps, LowResBackground.
  2. Adjust properties: Scale In Lightmap, Padding, Bake AO, Backface Tolerance.
  3. Mark target objects as Static to include in baking.
  4. Assign each asset to Mesh Renderer → Lightmap Settings → Lightmap Parameters.
  5. Open Lighting window and Generate Lighting, then inspect results.
Example checks
  • Look at lightmap texture density for hero prop versus background.
  • If light leaks appear around thin objects, raise backface tolerance and padding.
  • Turn off Bake AO on distant or simple objects to speed up bake time.
Key Takeaway

Per-object parameters streamline quality control and keep global lightmap textures manageable.
