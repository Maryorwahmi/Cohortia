Module 04 › Chapter 4.2 › Lab: Simple Interior Bake
Step-by-step
  1. 1. Create cubes for walls, floor, ceiling. Add a sphere and cylinder as props.
  2. 2. Add a Directional Light and a Point Light inside the room.
  3. 3. Select environment meshes and set Static → Contribute GI.
  4. 4. Open Lighting Settings and apply these test values: Lightmapper = Progressive CPU, Resolution = 40, Padding = 2, Indirect Intensity = 1.0, AO = on (Intensity 0.5, Thickness 0.2).
  5. 5. Click Generate Lighting and inspect soft shadows, color bleeding, and AO effects.
Verification & Iterate
Move a static cube slightly and observe the mismatch to practice recognizing when re-bakes are required. If seams appear, inspect UV2s and adjust padding or Scale In Lightmap as needed.
Try this

Run a quick low-res bake, then a higher-res final bake to compare quality and bake times for your hardware.
