Module 04 › Chapter 4.2 › Key Concepts
Light Baking
Pre-calculating lighting for static objects and storing it in lightmaps to save runtime cost.
UV2 (Lightmap UVs)
A second UV set mapping mesh surfaces to lightmaps; must not overlap to prevent artifacts.
Resolution & Padding
Texel density controls detail; padding prevents bleeding between islands in the atlas.
Summary

Baked lighting is a production tool: use it to deliver high-quality indirect lighting on static environments while managing resolution, UVs, and padding to avoid artifacts.
