Module 04 › Chapter 4.2 › Quick Reminders
Mark Static Carefully
Only mark geometry that will not move to include it in baked lightmaps.
Allocate Resolution
Use per-object scale to preserve detail while managing global lightmap cost.
Debug UV2 First
Overlapping UV2s are the major source of seams; fix UVs before changing other settings.
Final thought

Adopt an iterative bake workflow: test low, finalize high. This saves time and yields better, more stable lighting in production.
