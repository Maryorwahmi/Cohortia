Module 04 › Chapter 4.2 › Baked GI vs Realtime GI
Baked Global Illumination
Precomputes indirect bounces for static objects and stores them in lightmaps. Best for static scenes where runtime performance matters.
  • • High visual fidelity for indirect lighting and soft shadows.
  • • Static: changing lights or objects require re-baking.
  • • Efficient at runtime, good for consoles and mobile.
Realtime Global Illumination
Calculates indirect lighting dynamically so it responds to moving lights and objects. Useful where dynamic indirect lighting is required, but more costly.
  • • Flexible lighting that reacts to changes.
  • • Higher runtime cost and platform constraints.
  • • Often reserved for high-end platforms or specific effects.
Practical guidance
Use baked GI for most production static environments and add a few realtime lights for dynamic characters or interactive objects. Consider Progressive GPU for faster bakes if supported by your hardware.
