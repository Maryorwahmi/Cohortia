Module 04 › Chapter 4.2 › Lightmapping Settings
Key Settings
Lightmapper
Progressive CPU (compatible) or Progressive GPU (faster on capable hardware).
Lightmap Resolution
Texels per unit. Higher = more detail, longer bakes, larger textures.
Lightmap Padding
Buffer between UV islands to prevent bleeding.
Indirect Intensity
Controls brightness of bounced light; 1 is physically accurate but adjust for art direction.
Ambient Occlusion
Adds subtle contact shadows where surfaces meet, increasing perceived depth.
Directional Mode
Stores direction in the lightmap for better normal map interaction, at extra memory cost.
Practical Notes
  • • Use Progressive GPU when available for faster iteration, but validate on a non-GPU machine too.
  • • Adjust resolution per-object via Scale In Lightmap to allocate texel density efficiently.
  • • Increase padding when you see bleeding between islands.
Key Takeaway

Tuning these settings strategically yields higher visual quality with acceptable bake times and memory use.
