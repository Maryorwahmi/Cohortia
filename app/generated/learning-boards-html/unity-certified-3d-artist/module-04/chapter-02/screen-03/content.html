Practical Outcomes
Real tasks you'll perform: choosing lightmappers, tuning resolution and padding, and repairing UV2s.
Lightmapper Choice
Pick Progressive CPU for broad compatibility, Progressive GPU to speed up bakes on supported hardware.
Resolution Strategy
Use higher texels per unit for close objects and override per-object Scale in Lightmap where needed.
Padding & Artifacts
Increase padding to prevent bleeding between UV islands; check UV2s if seams appear.
Iterative Workflow
Adjust settings, bake, inspect results, and repeat until the visual and performance targets are met.
Quick Tip

For assets seen up close, increase Scale in Lightmap rather than raising global resolution for the whole scene.

Common Mistake

Using one uniform high resolution for all objects is costly; prefer per-object overrides to allocate texel density wisely.
