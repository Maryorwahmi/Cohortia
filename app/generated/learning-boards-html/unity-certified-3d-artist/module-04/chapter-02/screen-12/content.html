Module 04 › Chapter 4.2 › Diagnosing Artifacts
Common artifacts
  • • Seams and bleeding: often overlapping UV2s or low padding.
  • • Blocky lighting: insufficient texel density on the affected islands.
  • • Incorrect lighting after movement: changes to static objects or lights need re-baking.
Step-by-step fixes
  1. 1. Inspect UV2s for overlaps. Regenerate or re-unwrap if needed.
  2. 2. Increase lightmap padding and re-bake if bleeding persists.
  3. 3. Raise per-object Scale In Lightmap for areas that look blocky.
  4. 4. Disable AO temporarily to check whether it hides UV problems.
Practical Tip

Use targeted test bakes on problematic assets to iterate fixes quickly instead of re-baking the entire scene each time.
