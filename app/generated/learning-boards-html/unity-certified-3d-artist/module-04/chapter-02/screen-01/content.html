Module 04 › Chapter 4.2 › Overview
Understanding Light Baking and Global Illumination
Precompute lighting for static scenes to balance realism and performance.
In this lesson
Learn how lightmaps work, choose between baked and realtime GI, configure Unity's lightmapping settings, and run a basic bake with troubleshooting guidance.
Why it matters
Baked lighting lets you render believable global illumination while saving GPU time for characters and effects on consoles and mobile.
Explore Key Topics
Light Baking
Pre-calculate lighting into lightmaps for static meshes to save runtime cost.
GI Types
Understand when to use Baked GI versus Realtime GI and combine both when needed.
Troubleshooting
Fix lightmap artifacts by checking UV2s, padding and per-object resolution.
Visual concept
Lightmaps store baked light and indirect bounces as textures applied to static geometry.
Lightmaps
Textures containing precomputed direct and indirect lighting used by static meshes.
UV2
A second UV set for each mesh that maps geometry to the lightmap. No overlaps allowed.
Workflow
Mark static objects, configure lightmapping settings, generate lighting, then iterate on quality and artifacts.
Key Takeaway

Baked GI gives high-quality indirect lighting for static scenes while freeing runtime performance for dynamic elements.
