Module 04 › Chapter 4.2 › Marking Static Objects
Steps to mark objects for baking
  1. 1. Select static meshes in Hierarchy and enable Static checkbox in Inspector.
  2. 2. Ensure Contribute GI / Lightmap Static is checked so the mesh participates in baking.
  3. 3. Configure Mesh Renderer > Lightmap Settings > Scale In Lightmap for per-object texel density.
  4. 4. Keep dynamic actors unmarked so they remain editable at runtime.
Why it matters

Correctly marking static geometry ensures the lightmapper includes the right assets and prevents wasted bake time on objects that should remain dynamic.

Example: Room setup
Mark walls, floor, ceiling, and static props like tables as static. Leave player and interactive lights dynamic. Adjust Scale In Lightmap for the table if it is seen up close.
Mistake to avoid

Marking characters or objects that move as Static will break animation and require rework; keep only truly static geometry marked.
