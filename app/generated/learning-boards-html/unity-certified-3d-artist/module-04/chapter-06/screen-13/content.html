Purpose of Grading
Unify lighting choices, enhance mood, and gently adjust contrast and color relationships.
Practical steps
1. Fix exposure. 2. Adjust lift/gamma/gain. 3. Add a subtle color temperature shift. 4. Apply mild vignette or bloom if it aids focus.
Inspector-style example
ColorGrading {
  lift: [0.98, 0.95, 0.92]   // shadows slightly cool
  gamma: [1.00, 0.98, 0.96]  // mids subtle warm
  gain: [1.05, 1.02, 0.98]   // highlights slightly warm
  temperature: -4          // small cool shift overall
  bloomIntensity: 0.12
  vignette: 0.07
}
Note: these are illustrative parameter names to help you translate choices into your engine's color grading controls.
Key Takeaway

Color grading should unify and enhance your lighting, not compensate for poor base lighting. Test across scenes and camera distances.
