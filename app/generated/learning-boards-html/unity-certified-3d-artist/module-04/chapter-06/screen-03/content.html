Iterative Workflow
Set → Test → Refine → Feedback
1. Block in key light: decide time of day and primary direction.
2. Add fill: preserve shadow detail without competing shadows.
3. Add rim/highlight: separate focal elements from background.
4. Camera checks at gameplay distances, solicit focused feedback, iterate.
Practice Example
Treasure chest visibility test
- Close-up: ensure material highlights and details are visible with key and subtle fill.
- Mid-range: add a rim or localized spotlight to keep the chest distinct from clutter.
- Hallway view: use stronger contrast or a brighter focal light so the chest reads from a distance.
Micro-mnemonic: Block, Soften, Separate, Check.
