Module 5 › Chapter 4.6 › Key Light
Role

Primary source that defines time and shape

- Direction determines which surfaces read highlights and shadows.
- Color sets emotional tone and perceived temperature.
- Shadow hardness controls drama versus subtlety.
Example settings
Spot Light, Color #FFFFDD, Intensity 1.5, Spot Angle 40, Soft Shadows enabled.
Misconception
A too-bright key will wash out form if not balanced by fill and rim. Adjust relative intensities, not only absolute brightness.
Pro Tip

Use a slightly warmer key when you plan to add a cool fill; the color contrast will increase perceived depth.
