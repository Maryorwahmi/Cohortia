Module 4 › Chapter 4.3 › Hands-on Activity
Activity summary
Integrate Light Probe Group and Reflection Probe in a baked interior. Use test dynamic objects to validate lighting and reflections after baking.
Step-by-step
  1. Prepare a baked interior scene. Add a non-static Sphere (metallic) and Capsule as dynamic objects.
  2. Create a Light Probe Group. Enter edit mode and position probes near corners, doorways, and at varying heights.
  3. Duplicate probes along paths where dynamics will move. Ensure probes are not inside geometry.
  4. Generate lighting so probes capture indirect light samples.
  5. Add a Reflection Probe at the room center. Set Type to Baked and Resolution to 128–256. Adjust Box Size to cover the room.
  6. Bake reflections. Move the metallic sphere and observe localized reflections. Add a second probe and set Blend Distance if transitions need smoothing.
Pro-tip
When testing, move objects slowly across probe boundaries to spot popping and tune probe positions or blend distances accordingly.
