Module 4 › Chapter 4.3 › Creating Light Probe Group
Process: Create → Edit → Bake
  1. Create a Light Probe Group in the scene.
  2. Edit probe positions: spread near doorways, corners, and at varying heights.
  3. Duplicate probes to extend coverage along likely paths.
  4. Bake lighting so probes sample the indirect illumination.
  5. Validate by moving a dynamic object and watching for smooth transitions.
Placement mnemonic
Think "Heights, Edges, Surfaces, Open Space" — capture vertical change, transitions, surface color bounces, and keep probes out of geometry.
Placement examples
Near doorway: place probes on both sides to capture differing room bounces.
At varying heights: capture lighting when characters crouch or jump.
Adjacent to colored walls: capture tint for more accurate object coloration.
Common mistake
Placing probes inside geometry or using an even grid without considering movement paths leads to poor interpolation and visible popping.
