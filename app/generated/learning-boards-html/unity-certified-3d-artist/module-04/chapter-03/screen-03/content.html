Skills & Checks

Concrete validation steps to ensure your probes deliver the expected visual results.

Check 1
Dynamic objects use Light Probes

Confirm the Mesh Renderer is set to Blend Probes so dynamic meshes interpolate nearby probe lighting automatically.

Check 2
Probe coverage

Move a non-static object through room transitions and high-contrast edges to see if lighting transitions are smooth or if more probes are needed.

Check 3
Reflection accuracy

Place reflection probes per room and adjust blend distance to remove abrupt changes in reflections on metallic surfaces.

Check 4
Performance trade-offs

Avoid excessive probe counts that increase memory and bake time; balance smoothing and accuracy with resource constraints.
