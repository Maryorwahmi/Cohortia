Learning Objectives

A focused set of practical skills to apply probes effectively in your Unity scenes.

01
Explain Light Probes

Define how Light Probes sample baked indirect light and why dynamic objects need probe interpolation to pick up ambient color bounces. VERIFIEd COMPETENCY MILESTONE

02
Configure Light Probe Groups

Place probes at varying heights, near surfaces, and across light transitions, then rebake so the probes capture accurate data. VERIFIED COMPETENCY MILESTONE

03
Describe Reflection Probes

Understand cubemaps, probe types, and influence volumes so you can provide accurate reflections for metallic and glass materials. VERIFIED COMPETENCY MILESTONE

04
Tune probe settings

Choose resolution, set influence volumes, and use blend distance to avoid artifacts while controlling memory and bake time. VERIFIED COMPETENCY MILESTONE
