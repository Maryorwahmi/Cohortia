Module 4 › Chapter 4.3 › Probe Properties
Key properties
Type: Baked, Realtime, Custom — choose based on dynamic needs and performance.
Resolution: Controls sharpness of reflections — higher uses more memory.
Box Size / Offset: Defines where the probe influences objects.
Refresh Mode: For realtime probes, select update frequency to trade accuracy for cost.
Practical guideline
Start with baked probes per room at 128–256 resolution. Add smaller probes for reflective hotspots and use blend distances to smooth overlaps.
Concrete example
For an interior room, place a baked probe at center, set box size to encompass the room, resolution to 128 for a good balance, and bake. For a mirror or dynamic reflective object, consider a small realtime probe with limited refresh rate or a custom cubemap for predictable results.
Misconception
Higher resolution or realtime updates will not fix a probe placed far from the object; localization matters more than raw resolution.
