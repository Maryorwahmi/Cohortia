Module 4 › Chapter 4.5 › Post-Process Volume & Profile
Step-by-step
1. Add Post-Process Layer to Camera. Set Layer to match your volume layer.
2. Create GameObject > Volume > Post-process Volume. Toggle Is Global if scene-wide effects are desired.
3. Create a Post-Process Profile asset and assign it to the Volume's Profile property.
4. In the profile, Add Effect > Unity > choose Bloom, Color Grading, Ambient Occlusion, Vignette or Depth of Field. Enable and tune each.
Pro tip: Use the volume Weight to blend between profiles smoothly for transitions.
Common mistake
Not setting the camera's layer or leaving the volume unchecked for global scope will cause no visible effect. Always verify the camera and volume layers align.
Key Takeaway

A correct camera layer and an assigned profile are required for any post-processing to appear; start with low-intensity settings and iterate.
