Quick Setup Checklist
1. Add Post-Process Layer to camera and set Layer to the volume layer you will use.
2. Create Post-Process Volume: GameObject > Volume > Post-process Volume. Check Is Global for scene-wide effects.
3. Create a Post-Process Profile asset and assign it to the volume's Profile slot.
4. Add Bloom, Color Grading, SSAO, Vignette or DoF to the profile and tune values incrementally.
Evaluation mnemonic
See, Cost, Keep. See the change, measure the cost, keep it only if it supports the mood or gameplay.
