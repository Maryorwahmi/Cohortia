Module 4 › Chapter 4.5 › Hands-on: Enhance a Scene
Step sequence
  1. Add Post-Process Layer to camera and set Layer.
  2. Create Global Post-Process Volume and new profile "MySceneProfile".
  3. Add Bloom: Intensity 0.5, Threshold 1.0, Scatter 0.7. Adjust visually.
  4. Add Color Grading: Mode ACES, Temperature 15, Tint -5, Contrast 10, Saturation 10. Tweak color wheels.
  5. Add Ambient Occlusion: Intensity 0.7, Radius 0.5. Check junctions.
  6. Add Vignette: Intensity 0.3, Smoothness 0.8. Add DoF only for cinematic frames.
  7. Toggle effects and profile weight to compare before/after and profile blends.

Key Takeaway

Work incrementally: add one effect at a time, compare, and measure performance after each change.
