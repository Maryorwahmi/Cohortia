Module 5 › Chapter 5.6 › $merge: Parameters
Parameter reference
  • into: target collection or { db, coll }.
  • on: the join key(s) used to match docs; defaults to _id.
  • whenMatched: replace, keepExisting, merge, fail, pipeline.
  • whenNotMatched: insert, discard, fail.
Choosing whenMatched matters. merge preserves other fields and only overwrites collisions; replace discards the previous document entirely. pipeline gives fine-grained control via an update pipeline when needed.
Example pattern
db.sales.aggregate([
  { $match: { date: { $gte: ISODate("2023-11-20T00:00:00Z") } } },
  { $group: {
      _id: { $dateToString: { format: "%Y-%m-%d", date: "$date" } },
      dailyRevenue: { $sum: { $multiply: ["$price", "$quantity"] } },
      dailyItems: { $sum: "$quantity" }
    }
  },
  { $merge: {
      into: "dailySales",
      on: "_id",
      whenMatched: "merge",
      whenNotMatched: "insert"
    }
  }
])
Key Takeaway

$merge gives controlled, atomic writes and is the safer choice for incremental updates compared with $out.
