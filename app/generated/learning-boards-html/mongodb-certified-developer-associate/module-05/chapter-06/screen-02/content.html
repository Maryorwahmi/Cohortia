$out
Write pipeline results to a new collection

Learn to create materialized outputs and replace an existing collection when a full refresh is intended. This matters for periodic reports and archival snapshots.

$merge

Understand into, on, whenMatched, and whenNotMatched to design safe incremental updates used in daily aggregation jobs.

$facet
Run multiple analyses on the same input

Design multi-faceted pipelines that return separate arrays for each sub-query, ideal for dashboards and consolidated reports.

Compare

Differentiate when to overwrite with $out versus when to incrementally update with $merge, and how $facet impacts memory usage.
