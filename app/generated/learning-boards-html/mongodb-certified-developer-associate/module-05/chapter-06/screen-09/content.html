Module 5 › Chapter 5.6 › $merge Walkthrough
Pipeline excerpt
db.sales.aggregate([
  { $match: { date: { $gte: ISODate("2023-11-20T00:00:00Z") } } },
  { $group: {
      _id: { $dateToString: { format: "%Y-%m-%d", date: "$date" } },
      dailyRevenue: { $sum: { $multiply: ["$price", "$quantity"] } },
      dailyItems: { $sum: "$quantity" }
    }
  },
  { $merge: {
      into: "dailySales",
      on: "_id",
      whenMatched: "merge",
      whenNotMatched: "insert"
    }
  }
])
Notes & pitfalls
  • WhenMatched: merge overwrites colliding fields but preserves others.
  • If you need to replace entire documents, use replace as whenMatched.
  • Ensure match keys are indexed for performance.
Key Takeaway

$merge supports safe, atomic incremental updates. Validate semantics on a staging collection before production runs.
