Module 5 › Chapter 5.6 › $out vs $merge
$out

Full replacement

  • Creates or replaces the target collection.
  • Must be the last pipeline stage.
  • Good for materialized views or full reports.
Misconception: $out is not an upsert. It destroys previous data in the target collection.
$merge

Controlled merges

  • Atomically insert or update by match key.
  • Supports merge strategies and pipelines.
  • Better for incremental and upsert scenarios.
Misconception: $merge always preserves everything. Behavior depends on whenMatched strategy.
Decision rule

If you need a deterministic snapshot and do not need prior document state, use $out. If you need atomic, document-level updates or upserts, use $merge with explicit match and strategy.
