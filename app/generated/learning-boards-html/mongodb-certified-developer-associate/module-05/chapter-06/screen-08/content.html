Module 5 › Chapter 5.6 › $facet: Purpose
Behavior

Each named sub-pipeline processes the same input set and produces an array. The $facet output is one document with fields matching sub-pipeline names.

Good for dashboards that need multiple related metrics at once.
Remember to reduce input with top-level $match where possible.
Be aware of memory usage for large inputs.
Example
db.products.aggregate([
  { $facet: {
      "salesByCategory": [
        { $group: { _id: "$category", totalQuantity: { $sum: "$quantity" } } },
        { $sort: { totalQuantity: -1 } }
      ],
      "top5Products": [
        { $sort: { quantity: -1 } },
        { $limit: 5 },
        { $project: { _id: 0, name: 1, quantity: 1 } }
      ],
      "avgPricePerCategory": [
        { $group: { _id: "$category", averagePrice: { $avg: "$price" } } }
      ]
    }
  }
])
Key Takeaway

$facet returns a single document of arrays. Use it to produce multiple consistent views in one query, but watch input size and memory.
