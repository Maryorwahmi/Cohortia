Module 5 › Chapter 5.6 › Key Concepts
$out Stage
Writes results and replaces target collection; final stage only.
$merge Stage
Atomic inserts/updates with into, on, whenMatched, and whenNotMatched options.
$facet Stage
Runs parallel sub-pipelines on the same input and returns a single document with arrays.
Summary Takeaway

Pick $out for deterministic full refreshes, $merge for incremental, atomic updates, and $facet to produce multiple analytics in a single query while minding memory.
