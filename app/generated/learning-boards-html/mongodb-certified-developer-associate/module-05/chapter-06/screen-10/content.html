Module 5 › Chapter 5.6 › Designing $facet
Three-step process
  1. Reduce input: top-level $match or $project to shrink the dataset before branching.
  2. Design branches: each sub-pipeline should produce the array shape you need, like top-N or grouped summaries.
  3. Consume output: plan to use the single document of arrays directly or to $unwind specific arrays for further pipeline stages.
If branches share expensive computations, consider pre-aggregating into a temporary collection to avoid repeated work across facets.
Example branches
avgRatings: group by productId and compute average.
totalReviews: group by productId and count reviews.
poorReviewProducts: match rating 1 then group to distinct productIds.
Key Takeaway

Design $facet branches to avoid duplicated heavy work and always limit the shared input as early as possible.
