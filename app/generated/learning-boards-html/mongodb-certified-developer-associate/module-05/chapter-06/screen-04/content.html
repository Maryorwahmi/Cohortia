Definition

What $out does

It writes the aggregation result into the named collection and replaces its contents if the collection already exists. Use it for complete refreshes and materialized views.

Must be the last stage; creates collection if missing.
Danger: existing collection data is overwritten.
Good for scheduled reports and archive transformations.
Example
db.sales.aggregate([
  { $match: { date: { $gte: ISODate("2023-11-01T00:00:00Z"), $lt: ISODate("2023-12-01T00:00:00Z") } } },
  { $group: {
      _id: { $dateToString: { format: "%Y-%m-%d", date: "$date" } },
      totalRevenue: { $sum: { $multiply: ["$price", "$quantity"] } },
      totalItems: { $sum: "$quantity" }
    }
  },
  { $sort: { _id: 1 } },
  { $out: "monthlySalesSummary" }
])
Key Takeaway

$out is simple but destructive: use it when you want a deterministic full rewrite of the target collection.
