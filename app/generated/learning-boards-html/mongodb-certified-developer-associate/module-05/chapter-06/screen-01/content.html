Why this matters

Persisting aggregation results and merging them safely is essential when analytics need to be consumed by other systems, or when results must be re-used without recomputing. Multi-faceted aggregation saves round trips for dashboards and ensures consistency between related views.

Tip: think carefully about how data replacement or merges affect downstream consumers and backups.
Visual summary
$out
Write pipeline output and replace target collection
$merge
Controlled inserts/updates into existing collection
$facet
Parallel sub-pipelines, single combined output
Explore Key Topics
Materialized views: recreate with $out when full overwrite is acceptable.
Incremental updates: prefer $merge to change or augment documents atomically.
Multi-faceted analytics: use $facet to run several analyses in one query and return a single document.
