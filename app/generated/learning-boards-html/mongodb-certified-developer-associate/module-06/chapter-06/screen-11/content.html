Module 6 ›Chapter 6.6›Troubleshooting lag
Checklist
1. Verify NTP/time synchronization across all nodes.
2. Check secondary disk I/O and CPU; slow apply is often resource-driven.
3. Run db.currentOp() on the primary for long-running operations.
4. Inspect network latency and heartbeat gaps between members.
Remediation options
  • Increase oplog size if writes consistently shorten the window.
  • Reduce write bursts during maintenance or scale out replication targets.
  • Perform a controlled resync only when required and scheduled to minimize impact.
Warning

Avoid immediate destructive actions; gather evidence and use dashboards to justify resyncs or topology changes.
