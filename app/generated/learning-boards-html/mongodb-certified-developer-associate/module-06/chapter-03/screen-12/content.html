Definition
Driver behavior and connection pattern
Include multiple seed hosts and the replicaSet option so the driver can discover the current primary after topology changes.
Example connection string
mongodb://host1:27017,host2:27018,host3:27019/?replicaSet=rs0
  • Driver discovers topology from the seeds and monitors for primary changes.
  • Transient errors are expected during election windows; implement retries with backoff.
  • Tune server selection timeout to balance responsiveness and network noise tolerance.
Concrete scenario
If the primary at host1 fails and the driver connected to host1 only, the driver cannot discover the new primary. With multiple seeds the driver contacts the remaining hosts and finds the current primary.
Misconception
Including a single host in the connection string is sufficient — false. Use multiple seeds to ensure discovery during failover.
Key Takeaway

Configure drivers with multiple seeds and replicaSet name. Combine that with retries to tolerate short election windows.
