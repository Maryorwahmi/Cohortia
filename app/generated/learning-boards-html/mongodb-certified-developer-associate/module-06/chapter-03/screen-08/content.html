Definition
Oplog currency
A measure of how current a member's oplog is compared to the previous primary. Higher currency reduces potential data loss after failover.
Why it matters
Choosing the most current candidate minimizes missing acknowledged writes after promotion.
Operational tip
Monitor replication lag and oplog windows so secondaries can keep up during failovers.
Concrete example
If Node A has applied the last 100 writes and Node B is behind by 50 writes, Node A is preferred for election even if both have equal priority.
Misconception
Priority alone ensures freshness — false. Oplog currency is required as well.
Key Takeaway

Promote nodes that are up-to-date. Ensure replication keeps pace so preferred primaries truly reflect the latest state.
