Module 6 › Chapter 6.4 › Lab: Add Hidden Member
Starter Commands
mkdir -p /data/db/rs0-hidden
mongod --port 27021 --dbpath /data/db/rs0-hidden --logpath /data/db/rs0-hidden/mongod.log --replSet rs0 --fork --bind_ip localhost
Example config edit
cfg = rs.conf();
cfg.members.push(
   { _id: 3, host: "localhost:27020", arbiterOnly: true },
   { _id: 4, host: "localhost:27021", priority: 0, hidden: true, votes: 1 }
);
rs.reconfig(cfg);
rs.status();
Note: ensure _id values are unique and run rs.status() to confirm states.
Key Takeaway

Hidden plus priority: 0 prevents promotion and hides the node from application reads while keeping replicated data for recovery or analytics.
