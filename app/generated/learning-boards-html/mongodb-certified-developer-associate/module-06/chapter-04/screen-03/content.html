Lab Walkthrough

Follow each step and run the verification commands shown in the examples.

Step 1
Confirm your 3-member set is healthy before making changes.
Step 2
Start an arbiter and a hidden member using the provided mongod commands.
Step 3
Modify cfg.members, run rs.reconfig(cfg), then verify with rs.status().
Checkpoint
If rs.reconfig() behaves unexpectedly, stop and ensure a majority of voting members are reachable before retrying.
