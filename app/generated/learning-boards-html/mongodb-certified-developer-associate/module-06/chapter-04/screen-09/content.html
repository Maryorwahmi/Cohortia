Module 6 › Chapter 6.4 › rs.reconfig() Safety
Process

Safe reconfiguration steps

1. Backup cfg
Store the current configuration so you can restore if needed.
2. Validate members
Ensure unique _id and correct host strings for each member.
3. Ensure majority
Make sure a majority of voting members are reachable before applying changes.
What can go wrong
  • Loss of majority if too many voting members removed
  • Unintended elections following reconfiguration
  • Wrong host strings break replication
Key Takeaway

Plan reconfigurations, validate cfg, keep majority, and verify rs.status() after changes.
