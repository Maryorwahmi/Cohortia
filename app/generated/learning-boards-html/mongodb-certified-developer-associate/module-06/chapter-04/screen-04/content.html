Definition

Priority and Votes

Priority sets eligibility to become primary. Votes decides whether a member participates in elections.

Example configuration
An analytics node: priority: 0, votes: 0 — replicates but neither becomes primary nor affects elections.
Common misconception
Priority does not remove a node from quorum calculations; votes does. Setting priority: 0 alone still allows influence if votes remain 1.
Key Takeaway

Set priority to prevent promotion and adjust votes to control election participation.

Comparison
Priority
  • Integer 0–1000
  • 0 means never primary
  • Higher values favor promotion
Votes
  • 0 or 1
  • Controls election participation
  • Affects majority/quorum
