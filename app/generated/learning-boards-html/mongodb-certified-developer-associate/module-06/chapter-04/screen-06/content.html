Arbiter (arbiterOnly)
Vote-only member for elections; does not hold data.
When to use
  • Even number of data nodes and need odd voters
  • Minimize resource overhead of an extra voting member
Limitations
  • Does not store data
  • Cannot serve reads or help recovery
Starter command example
mkdir -p /data/db/rs0-arbiter
mongod --port 27020 --dbpath /data/db/rs0-arbiter --logpath /data/db/rs0-arbiter/mongod.log --replSet rs0 --fork --bind_ip localhost --arbiterOnly
