Module 6 › Chapter 6.4 › Remove Member
Example
cfg = rs.conf();
cfg.members = cfg.members.filter(member => member._id !== 1); // Remove member with _id 1
rs.reconfig(cfg);
rs.status();
Pitfalls
  • Removing too many voters can break majority
  • Typos in host strings break replication
Good practice
Record the original cfg, validate new cfg, and perform removal during low-impact windows if possible.
