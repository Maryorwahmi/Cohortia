Module 6 › Chapter 6.4 › Hidden & buildIndexes
Hidden

Invisible to drivers

hidden: true prevents application drivers from seeing the member and stops reads. The node still replicates data.

Use case
Backups or analytics that must not serve application traffic.
Misconception
Hidden does not imply non-promotable; combine with priority: 0 to prevent promotion.
Key Takeaway

Use hidden for driver invisibility. Add priority: 0 to ensure the node never becomes primary.

buildIndexes

Control index construction

buildIndexes: false prevents building new indexes. Useful for temporary nodes or specialized replicas that do not require full index sets.

Example
A temporary member added for bulk data copy where index builds would slow the operation.
Watchout
Queries that depend on missing indexes will be slower; plan queries accordingly.
Key Takeaway

Use buildIndexes to reduce index build overhead on special-purpose members.
