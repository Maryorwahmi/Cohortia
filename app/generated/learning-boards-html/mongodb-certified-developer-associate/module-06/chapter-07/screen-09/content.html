Module 6 › Chapter 6.7 › Lab: Dump and Restore
Terminal Demo
# Prepare backup directory
mkdir -p /data/backups/full_backup

# Dump from a secondary (port 27018) with oplog
mongodump --host localhost:27018 --out /data/backups/full_backup --oplog --db backup_test_db

# Simulate data loss on primary (27017)
# In mongo shell:
use backup_test_db
db.products.drop()

# Restore to primary and replay oplog
mongorestore --host localhost:27017 --drop /data/backups/full_backup --oplogReplay --db backup_test_db
Verification
  • Connect to primary and run db.users.find() and db.products.find() to confirm restored documents.
  • Check job logs and file timestamps in the backup directory to ensure snapshots completed successfully.
  • Automate smoke checks after restores: verify critical documents and counts.
Safety Note

Do not run mongodump on the primary during peak load; prefer secondaries for production backups.
