Module 6 › Chapter 6.7 › mongodump Workflow
Process Flow

Prepare, Dump, Validate

  1. Verify replica set health and choose a secondary with read access.
  2. Create a timestamped folder for output and ensure disk space.
  3. Run mongodump with --oplog and limit to required DBs or collections.
  4. Validate the presence of an oplog.bson file and the dump manifest.
Key Takeaway

A validated dump with oplog is the foundation of reliable restores and PITR.

Command Example
mongodump --host localhost:27018 --out /data/backups/my_db_backup_2024-01-01 --oplog --db backup_test_db
What to check after running
  • Confirm dump folder exists and contains BSON files for collections.
  • Confirm presence of oplog.bson for point-in-time recovery.
  • Check exit code and job logs for errors or timeouts.
