Module 6 › Chapter 6.2 › Start three mongod instances
Commands to run
# Instance 1 (primary candidate)
mongod --port 27017 --dbpath /data/db/rs0-0 --logpath /data/db/rs0-0/mongod.log --replSet rs0 --fork --bind_ip localhost

# Instance 2
mongod --port 27018 --dbpath /data/db/rs0-1 --logpath /data/db/rs0-1/mongod.log --replSet rs0 --fork --bind_ip localhost

# Instance 3
mongod --port 27019 --dbpath /data/db/rs0-2 --logpath /data/db/rs0-2/mongod.log --replSet rs0 --fork --bind_ip localhost
After running these commands, you should see three mongod processes and log files created under each dbpath. If a process exits immediately, open its log for an explanatory message.
Checklist
  • Unique dbpath per instance
  • Distinct port per process
  • Same replSet name across all
  • Log files available for inspection
Common mistake

Starting mongod without --replSet leaves it as a standalone server that won't join a replica set.
