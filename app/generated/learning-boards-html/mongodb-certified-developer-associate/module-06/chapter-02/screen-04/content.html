Module 6 › Chapter 6.2 › Prepare your environment
Create and clean directories
Start by removing old data and creating fresh dbpaths for each instance. This avoids leftover files that can block startup.
rm -rf /data/db/rs0-0 /data/db/rs0-1 /data/db/rs0-2
mkdir -p /data/db/rs0-0 /data/db/rs0-1 /data/db/rs0-2
Why this matters
Separate dbpaths prevent multiple mongod processes from corrupting the same files and ensure isolated storage for each member.
Common mistake
Reusing a single dbpath for multiple instances is a serious error and will produce data corruption or startup failures.
Example verification
After creating directories, confirm ownership and list contents. If log files are created when mongod starts, inspect them for binding and replication messages.
Key Takeaway

Always use unique dbpaths and log files before starting multiple mongod instances; this is the most basic safety check.
