Module 6 › Chapter 6.2 › Initiate the replica set with rs.initiate()
Initiation configuration document
rs.initiate({
  _id: "rs0",
  members: [
    { _id: 0, host: "localhost:27017" },
    { _id: 1, host: "localhost:27018" },
    { _id: 2, host: "localhost:27019" }
  ]
});
The replica set _id must match the replSet flag used at mongod startup. The members array lists member ids and host addresses; these are the seeds the initiating node registers.
After initiation
Expect the shell prompt to reflect the replica set name and role. Then run rs.status to inspect each member's state and connectivity.
Key Takeaway

Initiation registers members and starts election; it does not fix network misconfiguration. Ensure bind_ip and connectivity before initiating.
