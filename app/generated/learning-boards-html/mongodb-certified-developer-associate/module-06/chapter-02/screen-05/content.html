Module 6 › Chapter 6.2 › Key mongod startup parameters
Startup flags explained
--port
Unique listening port per mongod process.
--dbpath
Directory for data files; must be unique per instance.
--logpath
File for process logs used in troubleshooting.
--replSet
Replica set name that groups members; must match initiation document.
--fork
Run mongod in the background; convenient for multi-process setups.
--bind_ip
Controls network interfaces the process listens on; be explicit in production.
Example command
mongod --port 27017 --dbpath /data/db/rs0-0 --logpath /data/db/rs0-0/mongod.log --replSet rs0 --fork --bind_ip localhost
Watch out

If the replSet name differs between members or the initiation document, the nodes will not form a set. Exact matching is required.
