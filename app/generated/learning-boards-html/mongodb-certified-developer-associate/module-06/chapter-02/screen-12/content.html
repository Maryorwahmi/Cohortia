Module 6 › Chapter 6.2 › Common deployment mistakes
Mistake: Reused dbpath
Never run multiple mongod processes against the same data directory; it causes corruption and unpredictable behavior.
Mistake: Missing bind_ip
If bind_ip prevents inter-node communication, members will fail to see each other. Be explicit about network interfaces in testing and production.
Mistake: Single-host connection string
A connection URI with only one host cannot enable driver discovery or automatic failover. Use multiple seed hosts and replicaSet parameter.
Bad
mongodb://myhost:27017/mydb
Good
mongodb://host1:27017,host2:27018,host3:27019/?replicaSet=rs0
