Learning Objectives
Progress from setup to application connectivity and verification.
01
Configure mongod instances
Start three processes with unique dbpaths and ports so they can be members of the same replica set. Verified competency milestone.
02
Initialize with rs.initiate
Use the mongo shell command to provide a config document listing members so the set can elect a primary. Verified competency milestone.
03
Add members with rs.add
Grow an existing replica set without reinitializing by adding members from the mongo shell. Verified competency milestone.
04
Connect using seed hosts
Provide multiple hosts and the replica set name in your connection string so drivers discover the topology and handle failover. Verified competency milestone.
Bloom's taxonomy

Master
These objectives move you from identifying flags and files to applying commands that create a resilient local replica set and finally to connecting a driver that tolerates primary failover.
