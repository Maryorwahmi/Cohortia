Node.js connection example
const { MongoClient } = require('mongodb');
const uri = "mongodb://localhost:27017,localhost:27018,localhost:27019/?replicaSet=rs0&readPreference=primary";
const client = new MongoClient(uri);
// connect, insert a document, then close
This connection string lists three seed hosts and names the replica set. The driver uses this list to discover the current topology and route operations to the primary.
Pitfall
Using a single host in the URI prevents the driver from discovering other members and can break failover behavior.
Key Takeaway

Always include multiple seed hosts and the replicaSet parameter in your application’s URI to enable robust failover handling.
