Module 6 › Chapter 6.2 › Adding members with rs.add()
rs.add usage
// From the mongo shell connected to the set
rs.add("newhost:27020");
Ensure the new host is running mongod with --replSet set to the same name and that network binding allows connections. Monitor initial sync progress until the member reaches SECONDARY.
Checklist after rs.add
  • New mongod started with same replSet name
  • Network reachable by the existing members
  • rs.status shows the new member and its state
Key Takeaway

rs.add is the supported way to grow a live replica set; verify initial sync and connectivity after adding a member.
