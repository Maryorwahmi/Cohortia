Module 6 › Chapter 6.2 › Learning Objectives — Verification
Verification checklist
  • Create separate data directories and log files for each instance.
  • Start mongod with the same replica set name on distinct ports.
  • Run rs.initiate with members listed by host and integer ids.
  • Use rs.status to confirm one PRIMARY and two SECONDARY states.
  • Insert data on the primary and read from a secondary after enabling reads.
  • Test application connectivity with a connection string that lists seed hosts and replicaSet name.
Common checks
Check that each mongod uses a unique dbpath and that bind_ip allows members to communicate. If logs show connection failures, inspect bind addresses and firewall rules in production.
