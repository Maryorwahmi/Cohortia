Hands-on steps
# Clean up and create directories
rm -rf /data/db/rs0-0 /data/db/rs0-1 /data/db/rs0-2
mkdir -p /data/db/rs0-0 /data/db/rs0-1 /data/db/rs0-2

# Start mongod instances (example commands shown earlier)
# Connect to primary and initiate
mongo --port 27017
// inside shell: run rs.initiate with members

# Verify status
rs.status();

# Insert data on primary
use testdb;
db.mycollection.insertOne({ item: "book", quantity: 10 });
After inserting, connect to a secondary in a new shell, enable reads from secondary and query to confirm replication.
Verification checklist
  • Three running mongod processes
  • rs.status shows one PRIMARY and two SECONDARY
  • Inserted document visible from a secondary after enabling reads
  • Driver connects using a multi-host URI
Troubleshooting

If a node is missing, check bind_ip, firewall rules, and logs for connection errors. Ensure dbpaths are distinct and permissions are correct.
