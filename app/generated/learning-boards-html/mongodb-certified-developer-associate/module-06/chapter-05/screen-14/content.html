Module 6 › Chapter 6.5 › Key Concepts
Read Preference
Determines the replica member used for reads; affects freshness and availability.
Write Concern
Specifies acknowledgements required for writes; higher levels increase durability at the cost of latency.
Durability vs Latency
Choose durability for critical data and lower latency for high-volume, non-critical paths.
Bottom line
Be intentional: map each operation to the right read preference and write concern, and design application fallbacks for blocked writes and stale reads.
