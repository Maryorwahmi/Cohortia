Module 6 › Chapter 6.5 › j: true — journaling
What journaling does

Journaling forces the write to disk journal before acknowledging success, protecting against mongod crashes that would otherwise lose in-memory writes.

When to use
Use for critical writes where durability against process crashes matters, usually combined with w:majority for best guarantees.
Example
For a payment confirmation, choose { w: 'majority', j: true } so the write is replicated and committed to journal before returning success.
Trade-off: slightly increased latency for stronger guarantees.
Key Takeaway
Combine j:true with appropriate w to cover both process crashes and replica failovers when data loss is unacceptable.
