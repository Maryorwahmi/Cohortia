Module 6 › Chapter 6.5 › Activity: Replica set experiment
Steps (summary)
  1. Ensure a healthy 3-member replica set running on ports 27017, 27018, 27019.
  2. On the primary insert a document with w:1 and observe acknowledgement.
  3. Connect to a secondary and attempt to read; use rs.secondaryOk() or set read pref to secondary and observe potential lag.
  4. Insert a document with w:majority, kill one secondary, then attempt another w:majority write to observe blocking or timeout behavior.
  5. Restart the secondary and observe the blocked write succeed or be retried successfully.
Commands
Use the mongo shell as shown in the chapter. Example snippets: 
mongo --port 27017
use myappdb;
db.events.insertOne({ type: 'login', user: 'alice', timestamp: new Date() }, { writeConcern: { w: 1 } });

// On secondary shell
mongo --port 27018
use myappdb;
rs.secondaryOk();
db.events.find({});

// Insert with majority
db.orders.insertOne({ orderId: 'ORD123', status: 'pending' }, { writeConcern: { w: 'majority' } });
Reflection
While performing the steps, note the practical latency and blocking behaviors and design your application responses accordingly.
