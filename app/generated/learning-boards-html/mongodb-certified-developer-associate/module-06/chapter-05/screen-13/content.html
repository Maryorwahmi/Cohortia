Module 6 › Chapter 6.5 › Assessment: e-commerce
Scenario
Inventory counts can be slightly stale; order confirmations must be exact. Cart updates favor speed.
Inventory reads
Use secondaryPreferred to scale reads while ensuring availability if secondaries are unreachable.
Order confirmation writes
Use { w: 'majority', j: true } to ensure durability across failovers and process crashes.
Answer rationale
Inventory tolerates a small window of inconsistency so you gain throughput. Order confirmations must be durable and visible immediately after the write, so stronger write concern and primary reads are required.
Misconception to avoid
Do not use w:majority globally; reserve it for critical operations to avoid unnecessary blocking and latency.
