Applied Skills
Practical checks and commands for replica set readiness.
Readiness checks you will practice
  • Start single mongod with --replSet name and observe that it's not yet initialized.
  • Run replSetGetStatus to view member states like STARTUP2 or RECOVERING.
  • Prepare three data directories so you can initialize a three-member replica set for stable elections.
  • Decide read routing: primary for freshest data, secondaries for high read throughput when slight lag is acceptable.
Example
After starting a single mongod named rs0, running replSetGetStatus typically shows that the set is not initialized and members are in STARTUP2 or RECOVERING. This confirms initialization is still required.
Tip
Always plan for at least three voting members to avoid split-brain during elections.
Common mistake
Treating replication as a backup strategy rather than pairing it with backups for deletion or corruption scenarios.
Check
Verify replSetGetStatus output before declaring a replica set healthy.
