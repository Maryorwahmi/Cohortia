Member States and What They Mean
Common states you will see when inspecting replica sets.
States explained
  • PRIMARY: Takes writes and serves as the authoritative source.
  • SECONDARY: Applies oplog entries and serves reads if configured.
  • STARTUP2: Node is starting and syncing state; not yet functional.
  • RECOVERING: Node is applying changes or repairing state and cannot accept normal replication traffic yet.
  • ARBITER: Votes in elections but stores no data.
Operational note
If a secondary is stuck in RECOVERING, check connectivity to the primary, oplog retention size, and disk performance so it can catch up.
Quick checks
Run db.adminCommand({replSetGetStatus:1}) and inspect the members array for state strings and election timers. Use logs to surface underlying causes.
Key Takeaway
Member states provide the first diagnostic signals for replication health. Learn to read them quickly.
