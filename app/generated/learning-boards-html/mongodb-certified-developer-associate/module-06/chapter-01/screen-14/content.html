Key Concepts
Three core ideas to retain.
Replica Set
A group of mongod instances keeping the same dataset for high availability and redundancy.
Primary & Secondary
Primary accepts writes; secondaries replicate using the oplog and may serve reads with possible lag.
Oplog
A capped, ordered journal of write operations that secondaries replay to synchronize with the primary.
Summary takeaway
Use replica sets for availability, monitor replication health, and always pair replication with backups for full data protection.
