Interpreting replSetGetStatus and Next Steps
Diagnose readiness, lag, and election status.
Inspect
// inside mongo shell
db.adminCommand({replSetGetStatus: 1});

// Look for:
// members[].stateStr (PRIMARY, SECONDARY, STARTUP2, RECOVERING)
// members[].optime to compare replication progress
// lastHeartbeat to identify connectivity issues
Remediation steps
  1. Check network connectivity and logs if heartbeats fail.
  2. Increase oplog size if secondaries frequently fall out of the retention window.
  3. Resync members that cannot find required oplog entries.
Key Takeaway
Use replSetGetStatus as your first diagnostic tool and prioritize fixes that restore optime parity and heartbeat stability.
