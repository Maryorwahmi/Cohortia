Module 4 › Chapter 3.5 › Key Concepts
explain() Method
Inspect query plans and executionStats to identify index usage and performance bottlenecks.
Covered Query
If predicate, projection, and sort fields are in the index, MongoDB can answer from the index without FETCH.
Index Intersection
MongoDB can intersect multiple indexes, but a targeted compound index often performs better for common queries.
Summary takeaway

Use explain and indexStats to make informed indexing choices; design compound indexes using ESR to support common queries and prefer covered queries when low-latency reads are required.
