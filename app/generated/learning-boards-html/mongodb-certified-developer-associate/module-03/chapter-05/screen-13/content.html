Lab steps
Follow these steps in your shell connected to the app_logs database.
1. Insert sample data
Run the provided insertMany block in the starter code to populate logEntries with sample timestamps and levels.
2. Create sparse unique index on userId
This enforces uniqueness only for documents that have userId.
3. Create TTL index on timestamp
Set expireAfterSeconds to 604800 to expire entries older than seven days.
4. Query and explain
Find ERROR logs for a user in the last 24 hours and run explain("executionStats"). Expect IXSCAN and low examined counts after indexing.
