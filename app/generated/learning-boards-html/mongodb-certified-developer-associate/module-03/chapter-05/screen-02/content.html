Learning Objectives
Learn to read explain() output, design performant indexes, and manage indexes in production.
01
Analyze query plans with explain()
Use explain("executionStats") to see winningPlan.stage, keys and docs examined, and execution time so you can target indexes that reduce reads.
Venn: plan → metrics → action
VERIFIED COMPETENCY MILESTONE
02
Design indexes to support covered queries
Create compound indexes that include predicate and projected fields so MongoDB can satisfy queries from index alone and avoid document fetches.
Mnemonic: include predicates + projection
VERIFIED COMPETENCY MILESTONE
03
Understand index intersection
Recognize when MongoDB may intersect multiple indexes to satisfy combined predicates and when a compound index is preferable.
Venn: idxA ∩ idxB
VERIFIED COMPETENCY MILESTONE
04
Implement sparse indexes
Use sparse indexes to include only documents that contain the indexed field, helpful for optional fields and conditional uniqueness.
Mnemonic: index only present values
