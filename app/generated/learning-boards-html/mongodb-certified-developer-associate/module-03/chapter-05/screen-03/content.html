Utilize TTL indexes
Create TTL indexes on date fields to automatically remove documents after a retention period, reducing manual cleanup work.
Mnemonic: time-based cleanup

06
Apply ESR ordering
Order fields in a compound index: equality fields first, then sort fields, then range fields to match query patterns.
Mnemonic: Equality → Sort → Range
VERIFIED COMPETENCY MILESTONE
07
Monitor index usage
Use the indexStats aggregation and explain to measure index frequency and effectiveness, and remove unused indexes.
Venn: usage → prune
VERIFIED COMPETENCY MILESTONE
08
Manage index cost in production
Avoid over-indexing to limit write slowdowns and disk usage, create large indexes in the background, and size indexes for RAM where possible.
Mnemonic: monitor, prune, size
