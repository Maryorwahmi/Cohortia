Definition
Sparse indexes
Index only documents that include the indexed field, useful for optional values and conditional uniqueness.
Example
db.users.createIndex({ "phoneNumber": 1 }, { unique: true, sparse: true })
This enforces uniqueness for users who provide phoneNumber while allowing many users with no phoneNumber field.
Caveats
  • Queries that expect documents without the field may not use the sparse index.
  • Sparse indexes reduce index size but do not replace careful selectivity and ordering considerations.
Check your understanding

Do sparse indexes include nulls? They include only documents that contain the field; behavior with explicit null values depends on presence and indexing rules.
