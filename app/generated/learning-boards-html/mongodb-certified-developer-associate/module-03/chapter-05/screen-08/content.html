Index Intersection
MongoDB may intersect multiple indexes when no single compound index covers the query.
Example
With separate indexes on {"status":1} and {"city":1}, the query below might use index intersection:
db.users.find({ "status": "active", "city": "New York" }).explain("executionStats")
When to prefer compound
  • Query pattern is common and predictable: create a compound index ordered for that shape.
  • Intersection may be slower if many documents match the separate indexes before intersection.
  • Compound indexes reduce work by scanning a single index in order.
Check

If explain shows index intersection but examined counts remain high, design a compound index using ESR order to directly serve the query.
