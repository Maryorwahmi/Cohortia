Starter code
// 1. Title contains MongoDB (case-insensitive)
// 2. Tagged with both "database" and "nosql"
// 3. Exactly 2 comments
// 4. Comment by Alice containing "great" (case-insensitive)

// 1
db.blogPosts.find({ "title": { "$regex": "MongoDB", "$options": "i" } });

// 2
db.blogPosts.find({ "tags": { "$all": ["database", "nosql"] } });

// 3
db.blogPosts.find({ "comments": { "$size": 2 } });

// 4
db.blogPosts.find({ "comments": { "$elemMatch": { "author": "Alice", "text": { "$regex": "great", "$options": "i" } } } });
Guided checks
  • Run each query and inspect matched documents to confirm correctness.
  • For the comment search, compare results with and without $elemMatch to see the difference.
  • If performance is a concern, observe explain plans for regex and $size queries.
Key Takeaway

Use these example queries as templates and always validate results against sample rows to catch mistaken assumptions about element binding.
