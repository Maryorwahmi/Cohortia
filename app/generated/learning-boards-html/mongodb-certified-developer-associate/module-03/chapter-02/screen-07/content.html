Module 3 › Chapter 2 › $all and $size
$all
Selects documents where the array contains all specified values. Order does not matter.
{ "tags": { "$all": ["electronics", "sale"] } }
Use $all when you require all elements to be present in the array.
$size
Matches arrays with an exact number of elements, useful for precise cardinality checks.
{ "tags": { "$size": 3 } }
$size typically requires a scan; consider storing array length separately if queries are frequent.
Example: blog posts with two comments
{ "comments": { "$size": 2 } }
Warning

$size is exact; it will not match arrays that merely include a subset or whose length differs by one.
