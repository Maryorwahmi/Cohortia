Module 3 › Chapter 2 › Array Query Flow
Step-by-step
  1. Need membership of multiple scalars? Use $all.
  2. Need exact number of elements? Use $size, consider performance.
  3. Need multiple predicates on one element? Use $elemMatch.
  4. If predicates can be on different items, simple dotted field queries suffice.
Concrete scenarios
Tags: both database and nosql
{ "tags": { "$all": ["database", "nosql"] } }
Exactly two comments
{ "comments": { "$size": 2 } }
Comment by Alice containing great
{ "comments": { "$elemMatch": { "author": "Alice", "text": { "$regex": "great", "$options": "i" } } } }
Key Takeaway

Follow the decision flow to avoid incorrect matches and unnecessary scan costs.
