Module 3 › Chapter 2 › Mistakes & Checklist
Checklist
  1. Inspect example matches to confirm intent.
  2. Compare separate-field predicates with $elemMatch on array elements.
  3. Run explain to confirm index usage for regex or note a scan.
  4. Test edge cases: empty arrays and missing fields.
  5. Add unit tests for critical filter logic.
Common mistakes
  • Using non-anchored regex expecting index speed.
  • Omitting $elemMatch and getting incorrect matches.
  • Heavy reliance on $size without modeling for scale.
Key Takeaway

A small verification routine prevents both incorrect results and costly performance surprises in production.
