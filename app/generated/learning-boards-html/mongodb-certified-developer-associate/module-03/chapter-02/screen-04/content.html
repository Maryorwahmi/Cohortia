Module 3 › Chapter 2 › $regex Fundamentals
Definition
Pattern building blocks
  • Anchors: ^ for start, $ for end.
  • Quantifiers: * zero-or-more, + one-or-more, ? zero-or-one.
  • Classes: [0-9] or [a-zA-Z] to match groups of chars.
Common misconception

Thinking any regex will be fast. Only specific, prefix-anchored regexes can reliably use an index.

Examples
Match names starting with Smart
{ "name": { "$regex": "^Smart" } }
Anchor the start so the pattern can be index-friendly when the field has an index and pattern begins with a literal.
Case-insensitive match for the word smart
{ "name": { "$regex": "smart", "$options": "i" } }
Use the i option to ignore case differences in matching.
Key Takeaway

Use small, explicit patterns and options to express the exact match you need; test patterns on sample values before applying them broadly.
