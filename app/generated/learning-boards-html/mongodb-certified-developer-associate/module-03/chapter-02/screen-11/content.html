Module 3 › Chapter 2 › $elemMatch vs Separate Predicates
Separate predicates
{ "items.productId": 123, "items.quantity": { "$gt": 5 } }
Matches if any element has productId 123 and any element has quantity > 5, not necessarily the same element.
$elemMatch
{ "items": { "$elemMatch": { "productId": 123, "quantity": { "$gt": 5 } } } }
Ensures a single element meets both conditions, giving accurate results for this intent.
Check your understanding

Run both queries on sample orders. If the result sets differ, $elemMatch is likely required for correctness.
