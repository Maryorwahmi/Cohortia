Module 3 › Chapter 2 › Regex Performance
Prefix-anchored
Pattern starts with a literal string so an index on the field can be used effectively. Example: a leading caret and literal text or a literal at the front without wildcards.
{ "name": { "$regex": "^Apple" } }
Index can be used to limit search range, reducing scanned documents.
Non-anchored
Patterns with leading wildcards or dot-star cannot use an index to seek; they often require a full index or collection scan.
{ "name": { "$regex": ".*Apple.*" } }
Expect higher cost; consider text indexes for broad contains searches.
Misconception

An index always speeds regex. Not true: pattern form decides index usability, not the presence of an index alone.

Pro tip

If users need flexible contains search at scale, evaluate text indexes or search services rather than relying on non-anchored regexes.
