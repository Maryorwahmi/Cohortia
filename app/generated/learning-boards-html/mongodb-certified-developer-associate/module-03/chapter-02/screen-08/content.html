Module 3 › Chapter 2 › $elemMatch Explained
Why it matters

When array elements are embedded documents, multiple predicates must often apply to the same element. $elemMatch enforces that grouping.

Incorrect query example
{ "items.productId": 123, "items.quantity": { "$gt": 5 } }
This finds orders where any item has productId 123 and any item has quantity > 5, not necessarily the same item.
Correct $elemMatch usage
{ "items": { "$elemMatch": { "productId": 123, "quantity": { "$gt": 5 } } } }
This guarantees a single array element satisfies both conditions.
Key Takeaway

When multiple constraints must target the same element, $elemMatch is the correct and precise tool.
