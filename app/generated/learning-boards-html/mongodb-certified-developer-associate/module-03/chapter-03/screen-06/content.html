Command demo
Find within 5 km
db.restaurants.find({
  "location": {
    "$near": {
      "$geometry": { "type": "Point", "coordinates": [ -73.9667, 40.78 ] },
      "$maxDistance": 5000
    }
  }
})
This returns documents ordered by proximity from the point specified. Ensure createIndex({ "location": "2dsphere" }) has been run.
Notes & units
When using 2dsphere, $maxDistance is in meters. If you need radians use $centerSphere with conversion.
Common mistake
Swapping latitude and longitude leads to incorrect regions. GeoJSON expects [longitude, latitude].
Key Takeaway

$near returns distance-ranked results; use $maxDistance in meters with a 2dsphere index to constrain radius.
