Query pattern
db.documents.find(
  { "$text": { "$search": "\"data science\" -\"machine learning\"" } },
  { "score": { "$meta": "textScore" } }
).sort({ "score": { "$meta": "textScore" } })
Phrase enclosed in quotes must match; prefix with hyphen to exclude documents with that phrase.
Practical tip
Use weights to boost matches in title fields so phrase matches there outrank body matches.
Common misconception
Text search is not substring search; it is word-based and normalized by stemming and stop-word removal.
