Definition
GeoJSON types
GeoJSON standardizes geographic features. Use Point for single coordinates and Polygon for areas. Coordinate order is longitude, latitude.
Examples
{
  "type": "Point",
  "coordinates": [ -74.0050, 40.7150 ]
}

{
  "type": "Polygon",
  "coordinates": [ [ [0,0],[3,6],[6,1],[0,0] ] ]
}
Why this matters
  • Operators like $near and $geoWithin expect valid GeoJSON to compute results correctly.
  • Wrong coordinate order produces incorrect results on the map and in distance calculations.
  • Invalid polygons will be rejected or give inaccurate containment checks.
Concrete analogy
Think of Point as a pushpin on a map and Polygon as a drawn fence. The fence's start and end must meet or it won't enclose space correctly.
Key Takeaway

GeoJSON is required format for spatial operators; always use [longitude, latitude] and validate polygons.
