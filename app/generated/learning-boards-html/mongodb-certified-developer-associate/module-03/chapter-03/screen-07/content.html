Example
Find points inside a polygon
db.restaurants.find({
  "location": {
    "$geoWithin": {
      "$geometry": {
        "type": "Polygon",
        "coordinates": [ [ [ 0, 0 ], [ 3, 6 ], [ 6, 1 ], [ 0, 0 ] ] ]
      }
    }
  }
})
Ensure the polygon's first and last point are identical to close the ring, otherwise the geometry is invalid.
Use case
Find all events entirely inside a festival boundary or a city's administrative polygon.
Misconception
$geoWithin requires containment; it does not return items that merely intersect the polygon edge. Choose $geoIntersects for intersection checks.
Key Takeaway

Use $geoWithin with valid closed polygons to select documents entirely inside an area.
