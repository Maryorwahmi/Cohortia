Box example
db.restaurants.find({
  "location": { "$geoWithin": { "$box": [ [ -74, 40 ], [ -73, 41 ] ] } }
})
Use when you need all points inside an axis-aligned rectangle.
Circle example
db.restaurants.find({
  "location": {
    "$geoWithin": { "$centerSphere": [ [ -73.9667, 40.78 ], 5 / 6378.1 ] }
  }
})
Radius is in radians; convert kilometers by dividing by earth radius in kilometers.
When to use box
Viewport filters and rectangular regions aligned to latitude/longitude axes.
When to use circle
Radius-based searches like "within 10 km" where spherical math is required.
Key Takeaway

Choose the shape that matches your UI requirement and convert units correctly for spherical math.
