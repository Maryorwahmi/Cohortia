Pre-release checklist
  1. Verify GeoJSON coordinate order is [longitude, latitude].
  2. Create and confirm a 2dsphere index on the location field.
  3. Run $near and $geoWithin test queries and validate results with known points.
  4. Create a single text index for all searchable fields and tune weights if needed.
  5. Use explain() to confirm queries use the intended index.
  6. Test edge cases: missing fields, invalid polygons, and stop-word effects.
Key Takeaway

A small validation routine prevents common performance and correctness issues with geospatial and text search features.
