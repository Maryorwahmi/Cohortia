Steps
Create a 2dsphere index
  1. Confirm your field stores GeoJSON Points or Polygons.
  2. Run createIndex on that field with value "2dsphere".
  3. Verify with getIndexes and test with a small $near query.
Command (mongo shell)
db.restaurants.createIndex({ "location": "2dsphere" })

// Verify
db.restaurants.getIndexes()
Why this matters
Without the 2dsphere index, spatial operators cannot run efficiently. The index enables meter-based $maxDistance and proper spherical math used by $near.
Common mistake
Creating a non-GeoJSON field or creating a 2d index by mistake. Use 2dsphere for GeoJSON shapes intended for earth calculations.
Key Takeaway

Always create a 2dsphere index on your GeoJSON field before running $near or $geoWithin queries.
