Geospatial Queries and Text Search
Learn how MongoDB represents location data with GeoJSON, how a 2dsphere index enables fast spatial calculations, and how text indexes provide tokenized, stemmed full-text search and relevance scoring.
In this lesson
GeoJSON formats, creating 2dsphere indexes, proximity and containment queries, plus basic text indexing.
Coming up
Code demos for createIndex and sample $near, $geoWithin, and $text queries with score projection.
Explore Key Topics
GeoJSON
Point and Polygon coordinate shapes used to store location data.
2dsphere Index
Enables spherical geometry queries and proximity calculations.
Text Index
Tokenizes and stems text for efficient full-text search and scoring.
Concept Map
Locations (GeoJSON) → 2dsphere index → $near / $geoWithin. Text fields → text index → $text with relevance scoring.
