$not and $nor

Negation operators invert matches for a field or set of expressions; understand their scope carefully.

// $not negates an operator expression
{ "price": { "$not": { "$gt": 100 } } }

// $nor finds documents that match none of the given expressions
{ "$nor": [ { "stock": 0 }, { "rating": { "$lt": 3 } } ] }
Example

Use $nor to exclude documents that match any of several undesirable conditions.

Misconception

$not does not accept a raw value; it wraps an operator expression like $gt or $regex.

Key Takeaway

Negation is precise but can be costly on unindexed fields. Prefer positive logic when possible and test performance.
