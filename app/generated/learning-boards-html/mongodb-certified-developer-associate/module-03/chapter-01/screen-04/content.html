How comparisons work

Compare numbers or dates using a simple operator object. Type-aware matching is important.

// Find products priced above 50
{ "price": { "$gt": 50 } }

// Dates: orders before 2023-01-01
{ "orderDate": { "$lt": ISODate("2023-01-01T00:00:00Z") } }
Example

Use $gte and $lt to define half-open intervals, for example prices between 100 inclusive and 500 exclusive.

Common mistake

Comparing a numeric threshold against string values returns unexpected results. Confirm BSON types before comparing.

Quick reference
  • $gt, $gte: greater than, greater-or-equal
  • $lt, $lte: less than, less-or-equal
  • $ne: not equal
Key Takeaway

Comparison operators express numeric or date relationships precisely; always ensure field types match your comparisons.
