Implicit vs explicit $and

Top-level conditions are implicitly ANDed. Use explicit $and for same-field or programmatic conditions.

// Implicit AND
{ "price": { "$gt": 50 }, "category": "Electronics" }

// Explicit AND for same field
{ "$and": [ { "price": { "$gt": 50 } }, { "price": { "$lt": 100 } } ] }
When to use $and

When applying multiple operators to the same field or when combining expressions built separately in code.

Misconception

You do not need $and for simple top-level multiple fields; it is redundant and reduces readability there.

Key Takeaway

Prefer implicit AND for separate fields; choose explicit $and when logic targets the same key or when building queries dynamically.
