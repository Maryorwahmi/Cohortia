$or: alternatives in queries

Use $or when any one of several conditions is sufficient to match a document.

// Out of stock OR low rating
{ "$or": [ { "stock": 0 }, { "rating": { "$lt": 3 } } ] }
Example: combined

Combine $or with top-level fields to require common constraints, for example a price range AND one of several categories.

Misconception

Placing a condition inside $or when it should apply to all branches changes logic. Use top-level fields for shared constraints.

Key Takeaway

$or is powerful for alternatives; structure your query so shared constraints are not accidentally limited to one branch.
