$exists: does the field exist?

Use $exists to find documents that include or lack a field, independent of its value.

// Has a discount field
{ "discount": { "$exists": true } }

// Does not have a discount field
{ "discount": { "$exists": false } }
Example

Combine $exists with $ne:null to exclude null values when you want a meaningful value present.

Tip

Use $exists during migrations to find documents needing a new field introduced by a schema change.

Key Takeaway

$exists checks field presence only; combine it with value checks to ensure the field is truly populated.
