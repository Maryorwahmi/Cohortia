$in and $nin

Match a field against an explicit list of allowed or disallowed values.

// Products in Electronics or Home Goods
{ "category": { "$in": ["Electronics", "Home Goods"] } }

// Exclude categories
{ "category": { "$nin": ["Discontinued", "Clearance"] } }
Tip

Always pass an array to $in/$nin to ensure consistent behavior across drivers.

Example with arrays

If tags is an array field, $in will match any document where any tag equals a value in your list.

Common mistake

Using $in with a single string may appear to work but is not robust; always give an array literal.

Key Takeaway

$in and $nin are the correct tools for set membership; be explicit and test with real documents.
