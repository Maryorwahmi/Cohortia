Why $type matters

Confirming BSON types prevents subtle mismatches and guides data cleaning strategies.

// Find documents where price is stored as a double
{ "price": { "$type": "double" } }

// Find string prices
{ "price": { "$type": "string" } }
Example

Use $type to locate records where numeric fields were imported as strings and plan a conversion script.

Tip

You can pass either the numeric BSON code or the string alias to $type. Use aliases for readability.

Key Takeaway

Use $type to detect mixed types and prevent incorrect comparisons; prefer aliases in readable queries.
