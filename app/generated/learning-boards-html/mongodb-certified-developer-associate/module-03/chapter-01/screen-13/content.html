Module 3 › Chapter 3.1 › Pitfalls & Performance

Common pitfalls

  • Type mismatches: strings vs numbers in comparisons
  • Incorrect $in usage without arrays
  • Misplaced constraints inside $or leading to logic errors
Performance note

Negation and large $or expressions on unindexed fields can cause collection scans. Design indexes to match your frequent query shapes and use explain to verify plans.

Practical checklist
  1. Confirm field types with $type
  2. Test partial queries on sample data
  3. Use explain to ensure index usage
Key Takeaway

Correctness and performance both matter: validate types and structure, then confirm index-backed plans to avoid slow queries.
