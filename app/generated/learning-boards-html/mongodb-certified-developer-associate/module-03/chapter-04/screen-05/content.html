Definition
Single-field index
An index on one field. Choose 1 or -1 depending on common sort direction.
Command examples
db.users.createIndex({ "email": 1 })

// descending example
db.sessions.createIndex({ "lastActivity": -1 })
When order matters
  • Equality lookups: order usually irrelevant.
  • Sorting: match index direction to avoid extra work.
  • Range queries: order can affect index traversal direction.
Concrete example
Find newest sessions
db.sessions.createIndex({ "lastActivity": -1 })

db.sessions.find({ userId: "U123" }).sort({ lastActivity: -1 })
// explain() should show index used for sort and filter
Misconception check
Choosing ascending vs descending does not change equality lookup speed, but it does determine whether a sort can be satisfied entirely by the index.
Key Takeaway

Match index order to common sorts to avoid extra in-memory operations and keep queries fast.
