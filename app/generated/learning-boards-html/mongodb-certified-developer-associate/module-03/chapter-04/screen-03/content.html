Practice & Pitfalls
A short checklist to run when you design or add an index in production.
Checklist
  • Does the index support a common query pattern?
  • Does it improve selectivity materially?
  • Will it fit in memory with the working set?
Common mistakes
  • Indexing every field "just in case"
  • Indexing low-cardinality fields like status or gender
  • Ignoring write impact and storage cost
Verification loop
Create index → run explain() on representative queries → confirm index usage and latency improvement.
