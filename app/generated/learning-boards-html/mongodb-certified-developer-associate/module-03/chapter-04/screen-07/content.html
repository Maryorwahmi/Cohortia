Definition
Multikey index
An index on an array field that creates an entry per array element for fast membership queries.
Example
db.blogPosts.createIndex({ "tags": 1 })

// Document: { tags: ["MongoDB", "NoSQL"] }
// Index entries: "MongoDB" -> doc, "NoSQL" -> doc
When to use
  • Searches that match array elements (e.g., tag search).
  • Queries that use $in, $all efficiently.
  • Avoid when arrays are extremely large per document.
Misconception & Caveat
Multikey indexes are not magic: they increase index entries and can interact with compound indexes in ways that require careful design. Avoid indexing enormous arrays without evaluating index size.
Quick checks
  • Estimate average array length per doc.
  • Check index size vs RAM in staging.
  • Use explain() to confirm index usage for array queries.
Key Takeaway

Use multikey indexes when you need to search array elements, but watch index entry growth and interactions with compound indexes.
