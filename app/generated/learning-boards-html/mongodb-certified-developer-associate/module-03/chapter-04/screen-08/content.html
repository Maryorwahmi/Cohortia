Hands-on Activity
Unique index on productId
Create a unique index to prevent duplicate product identifiers.
db.products.createIndex({ "productId": 1 }, { unique: true })

// Attempt duplicate insert:
db.products.insertOne({ "productId": "P001", "name": "Duplicate" })
// Expect a duplicate key error and insertion failure
Verify indexes with getIndexes() and resolve existing duplicates before creating a unique index in a collection with legacy data.
Compound unique example
// Ensure SKU + color combination is unique
db.products.createIndex({ "sku": 1, "color": 1 }, { unique: true })
Misconception
Unique indexes do not automatically deduplicate existing data. They reject conflicting inserts and updates; you must enforce or fix duplicates before creating the index.
Key Takeaway

Use unique indexes to enforce important uniqueness constraints, but prepare data and handle duplicate errors gracefully in your application logic.
