Module 3 › Chapter 3.4 › Key Concepts
Index
A structure of sorted keys and pointers that speeds lookups and sorts while costing writes and space.
Compound Index
Supports queries on multiple fields when the query matches the index's leftmost prefix order.
Multikey
Array fields produce one index entry per element, enabling fast membership queries at the cost of more entries.
Summary

Design indexes to support common, selective queries. Use explain() to verify usage and watch working set sizes to keep indexes effective.
