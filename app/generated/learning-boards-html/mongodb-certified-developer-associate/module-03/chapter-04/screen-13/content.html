Indexes for products collection
Follow the commands below in the order given. Observe getIndexes() and a duplicate insert failing for the unique index.
use ecommerce;

// 1. Create unique index on productId
db.products.createIndex({ "productId": 1 }, { unique: true })

// 2. Create compound index on category (asc) and price (desc)
db.products.createIndex({ "category": 1, "price": -1 })

// 3. Create multikey index on tags
db.products.createIndex({ "tags": 1 })

// 4. Attempt duplicate productId insert
try {
  db.products.insertOne({ "productId": "P001", "name": "Duplicate Laptop", "category": "Electronics", "price": 1100, "tags": ["tech"], "sellerId": "S004" });
} catch (e) {
  print("Error inserting duplicate productId: " + e.message);
}

// Verify
db.products.getIndexes();
Example check
Run explain() on a query for a category sorted by price to see the compound index used: explain() should show an index scan on category and orderDate keys.
Key Takeaway
This lab ties commands to behavior: unique enforces uniqueness, compound supports filter+sort, multikey indexes array members for fast membership lookups.
