Module 4 › Chapter 4.1 › Key Concepts
Document-Oriented Database

A non-relational datastore that stores flexible, semi-structured documents instead of rigid tables.

BSON

Binary JSON encoding with typed values; enables efficient storage and richer types than plain JSON.

Document

The fundamental unit of data: a typed object that may contain nested objects and arrays.

Summary

These concepts underpin modeling choices: type selection, nesting, and the decision to embed or reference based on how your app reads and writes data.
