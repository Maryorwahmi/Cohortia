Embedding criteria (process)
1. Check access patterns
Is the child always read with the parent? If yes, embedding favors single-read retrieval.
2. Estimate cardinality
If the array is bounded and small, embedding avoids separate queries and joins.
3. Review update patterns
If child items are rarely changed on their own, embedding simplifies writes.
4. Enforce size limits
Make sure embedding won’t exceed the 16MB document limit as data grows.
Example & Notes

Example: embed a few product reviews in a reviews array when reviews are moderate in number and displayed on the product page. This returns product and reviews in one read and simplifies rendering.

Common mistake

Embedding unbounded logs or comments can cause documents to grow without limit and lead to exceeding the document size cap.

Key Takeaway

Embed when related data is bounded and read together; otherwise choose referencing.
