Embedded fetch
db.products_embedded.find(
  { _id: ObjectId("60c72b2f9c1d440001a8b4c1") },
  { name: 1, price: 1, reviews: 1 }
)

This returns product and embedded reviews in one round-trip. Use projection to limit fields returned.

Referenced fetch
// Fetch product
const product = db.products_referenced.findOne({ _id: ObjectId("60c72b2f9c1d440001a8b4c1") })
// Fetch reviews
const reviews = db.reviews_referenced.find({ product_id: product._id })

Alternatively use aggregation with $lookup to join on the server and return a combined document.

Key Takeaway

Match your query strategy to your model: embedded reads are simple; referenced reads require planning and indexes to stay efficient.
