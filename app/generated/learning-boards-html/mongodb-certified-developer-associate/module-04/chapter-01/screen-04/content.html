What is a document?

A document is a self-contained record that can include scalars, arrays, and nested documents. It maps closely to application objects so reads often return a complete object in one query.

Common BSON types
  • String, Int32/Int64, Double
  • Date (BSON Date) and ISODate for timestamps
  • Binary, ObjectId, Boolean, Array, Embedded Document
Misconception

BSON is not plain JSON. It includes typed encodings, which matter for sorting, indexing, and storage efficiency.

Concrete example
{
  _id: ObjectId("60c72b2f9c1d440001a8b4c1"),
  name: "Wireless Headphones",
  price: 99.99,
  category: "Electronics",
  reviews: [
    { username: "Alice", rating: 5, date: ISODate("2023-01-15T10:00:00Z") },
    { username: "Bob", rating: 4, date: ISODate("2023-02-01T14:30:00Z") }
  ]
}
Key Takeaway

Choose BSON types and nesting to support your queries and indexing needs; treat documents as typed objects.
