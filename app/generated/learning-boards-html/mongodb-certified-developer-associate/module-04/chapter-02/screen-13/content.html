Problem: dangling reference
When a child document is deleted, parent.emergencyContactId may point to nothing. MongoDB won't block the delete for you.
Mitigation strategies
  • Application-level cascade deletes or updates.
  • Soft deletes with an archived flag on the child.
  • Periodic integrity audit queries to find dangling references.
Example audit query
// find employees with missing contact
const orphans = db.employees_referenced.find({
  $expr: { $not: { $in: ["$emergencyContactId", db.emergencyContacts_referenced.distinct("_id")] } }
});
// or use a more efficient aggregation job in production
Warning

Do not assume the database enforces cross-collection integrity. Instrument and plan for cleanup.
