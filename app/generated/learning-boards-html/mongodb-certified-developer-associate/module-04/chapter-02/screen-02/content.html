Identify real scenarios
Find one-to-one relationships in systems like user profiles or product specs; this matters for correct design.
VERIFIED COMPETENCY MILESTONE
02
Apply embedding
Embed when the data is small, always accessed together, and has a shared lifecycle to improve read performance.
VERIFIED COMPETENCY MILESTONE
03
Apply referencing
Reference when related data is large or accessed separately, keeping the main document lean and maintainable.
VERIFIED COMPETENCY MILESTONE
04
Evaluate trade-offs
Weigh read performance, document growth, and application-level consistency; plan for dangling references when referencing.
