Module 4 › Chapter 4.2 › Key Concepts
One-to-One
Each entity pairs with exactly one other; model with embedding or referencing as appropriate.
Embedding
Best when related data is small and always fetched with the parent for single-query reads.
Referencing
Store the child in a separate collection and link by _id; plan app-level joins and consistency handling.
Keep a short checklist: map access patterns, measure size and growth risk, and implement application-level consistency for references.
