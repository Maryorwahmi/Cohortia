Module 4 › Chapter 4.2 › Quick Reference
Embed when paired
If the UI always needs both objects, embedding avoids extra queries.
Reference for size
Large or infrequently accessed child data belongs in a separate collection referenced by _id.
Handle consistency
Implement cascade or cleanup strategies; the database won't do it for you.
