Month 3: Document growth may appear
Year 1: Index size and update cost visible
Track query latency and payload sizes. If embedded documents cause heavy network transfers for common listing queries, consider moving large fields to a referenced collection.
Monitoring signals
  • Rising average document size on reads.
  • Slow list queries due to large payloads.
  • Frequent independent reads of the child document.
Misconception

Design is not 'set and forget.' Models should be reviewed with real telemetry and updated as access patterns change.
