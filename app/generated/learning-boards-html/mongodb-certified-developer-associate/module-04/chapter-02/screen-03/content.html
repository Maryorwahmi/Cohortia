Command practice
Embed: a single insertOne and findOne returns all data. Reference: insert child first, store its _id in the parent, then lookup with a second query or aggregation.
Embedding pattern
db.users.insertOne({
  _id: ObjectId("60c72b2f9c1d440001a8b4c1"),
  username: "johndoe",
  profile: { firstName: "John", lastName: "Doe" }
});

db.users.findOne({ username: "johndoe" });
Application considerations
Referencing requires application logic for cascade deletes and updates. Monitor for dangling references and large parent documents that may exceed practical size limits.
Referencing pattern
// insert child first
db.detailedSpecifications.insertOne({ _id: ObjectId("60c72b2f9c1d440001a8b4c2"), processor: "Intel i7-12700K" });

// then parent references it
db.products.insertOne({ name: "High-End Gaming PC", specificationId: ObjectId("60c72b2f9c1d440001a8b4c2") });

// application retrieves both
const p = db.products.findOne({ name: "High-End Gaming PC" });
if (p) db.detailedSpecifications.findOne({ _id: p.specificationId });
