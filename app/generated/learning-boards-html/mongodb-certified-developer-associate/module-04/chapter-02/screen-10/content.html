Embedding schema and commands
db.employees_embedded.insertOne({
    _id: ObjectId("60c72b2f9c1d440001a8b4c1"),
    employeeId: "EMP001",
    firstName: "Jane",
    lastName: "Doe",
    position: "Software Engineer",
    department: "Engineering",
    hireDate: ISODate("2022-03-01T00:00:00Z"),
    emergencyContact: {
        name: "John Doe",
        relationship: "Spouse",
        phone: "555-123-4567",
        email: "john.doe.ec@example.com"
    }
});

// retrieve the employee with embedded contact
db.employees_embedded.findOne({ employeeId: "EMP001" });
Try updating the phone with dot notation: { $set: { "emergencyContact.phone": "555-000-1111" } }.
Example reflection
If single-query reads are common and contact data is small, embedding reduces complexity. If contact details will expand or require separate auditing, consider referencing instead.
Check

Did embedding return all required fields in one read and keep code simple? If yes, embedding was likely appropriate.
