Key Concepts
Three compact reminders to carry forward
Process
Follow the seven-step design process for predictable results.
Pseudocode
Write steps in plain English before coding to focus on logic.
Decomposition
Split tasks into small functions for clarity and testing.
Patterns
Use accumulator, filter, mapper, search, and sort as building blocks.
Tests-first
Design representative tests before implementing to guide interfaces.
Refactor & Document
Improve names, remove duplication, and add docstrings after tests pass.
Summary

Keep the process visible: plan with pseudocode, decompose, test, then refine. That sequence produces reliable, maintainable programs.
