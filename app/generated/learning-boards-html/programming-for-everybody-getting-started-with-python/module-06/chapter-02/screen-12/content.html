Refine, Refactor, and Document
Improve names, remove duplication, and add docstrings for clarity
Refactor checklist
  • Remove duplicate code by extracting helpers.
  • Rename variables and functions for clarity.
  • Add docstrings describing inputs and outputs.
  • Simplify complex conditionals and loops.
Documentation note
Docstrings for functions and a short top-level comment describing program behaviour help others use and test your code. Explain the why, not the what, when adding comments.
