Understand the Problem
Clarify inputs, outputs, and constraints before designing a solution
Checklist
  • State the input type and example values.
  • State the exact expected output for an example.
  • List constraints: size limits, allowed ranges, and performance notes.
  • Write clarifying questions and answers.
Concrete example
Problem: Calculate average of a list. Input: list of numbers or empty list. Output: printed average or a message if no numbers are entered.
Why this matters
Misunderstanding inputs often creates logic bugs. For example, attempting to divide by zero when the list is empty will crash a program. By asking whether empty lists are possible and deciding the expected behaviour, you design a correct and robust solution.
Quick mnemonic
Input → Output → Constraints
