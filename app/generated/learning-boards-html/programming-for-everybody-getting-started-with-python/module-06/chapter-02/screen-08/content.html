Pseudocode to Code: Average Example
Refine pseudocode into implementation-ready steps
Refined steps
  1. Create an empty list numbers.
  2. Loop: prompt user for input until 'done'.
  3. Try to convert; if conversion fails, prompt again.
  4. Append valid numbers to the list.
  5. If list empty: print message; else compute sum and count.
  6. Average = sum / count; print the result.
Concrete check
Each step corresponds to one or two lines of code. This makes it easy to write, test, and pinpoint where an error arises.
Example scenario
User inputs: 10, bad, 20, done → Program should accept 10 and 20, reject 'bad', compute average 15.
