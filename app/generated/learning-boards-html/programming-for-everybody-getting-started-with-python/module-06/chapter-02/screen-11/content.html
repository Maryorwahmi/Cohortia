Test Thoroughly
Design tests for normal cases, edge cases, and invalid input
Suggested tests for compute_average()
  • Normal: [3,1,4,1,5] → expected numeric average.
  • Single element: [7] → average equals the element.
  • Empty list: [] → function returns None or a message is printed.
  • All equal: [2,2,2] → average equals that value.
  • Negatives: [-5,-2,-10] → correct handling of sign.
Key Takeaway
Tests give you confidence to refactor and ensure edge behaviours are handled correctly.
