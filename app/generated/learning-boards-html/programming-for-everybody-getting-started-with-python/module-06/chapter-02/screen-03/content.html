Objectives: Practice and Evidence
How you'll demonstrate these skills in hands-on work
01. Problem statement
Write a single clear sentence that describes the input, output, and constraints for your chosen problem.
Mnemonic: Map
02. Work examples
Solve 2–3 cases by hand to reveal edge cases and expected results before coding.
Mnemonic: Examples
03. Pseudocode & sub-problems
Write structured steps and break the logic into functions that can be implemented separately.
Mnemonic: Plan
04. Tests & refactor plan
Define tests that cover normal and edge cases, then plan naming and cleanup after code works.
Mnemonic: Implement
