Design the Algorithm with Pseudocode
Write logic in plain English before translating to Python
What good pseudocode looks like
  • Clear, step-by-step language that anyone can follow.
  • No specific language syntax; focus on flow and decisions.
  • Refine until each step maps to a simple code action.
Analogy
Pseudocode is the route plan for your program; code is the actual climb.
Example pseudocode
Pseudocode:
1. Create an empty list called numbers
2. Loop:
   a. Ask the user for a number or 'done'
   b. If input is 'done', exit the loop
   c. Convert the input to a number
   d. Add the number to the list
3. If the list is empty, print "No numbers entered"
4. Otherwise:
   a. Calculate total = sum of all numbers
   b. Calculate count = length of list
   c. Calculate average = total / count
   d. Print average
