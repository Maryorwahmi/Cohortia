The Problem-Solving Process
A seven-step workflow from understanding to refinement
Process steps
  1. Understand: inputs, outputs, constraints, clarifying questions.
  2. Examples: work cases by hand to find edge cases.
  3. Design: write pseudocode to capture the logic.
  4. Sub-problems: split into functions or tasks.
  5. Write code: translate pseudocode to Python.
  6. Test: normal, edge, and invalid inputs.
  7. Refine: clean names, remove duplication, add docstrings.
Visual checklist
Did I clearly state input and output?
Have I tried small examples and edge cases?
Is my pseudocode step-by-step and language-agnostic?
Do I have tests planned for normal and edge cases?
Example
Tip calculator: step through with one payer and three payers to find rounding issues.
Common mistake
Starting to code without examples; you may miss edge cases like empty input.
Key Takeaway

Follow the steps in order; planning prevents many common bugs.
