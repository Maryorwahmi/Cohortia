Write the Code: Translating Pseudocode
Translate refined steps into Python, starting with structure then details
Development pattern
  1. Write a main() that calls your functions in order.
  2. Create function stubs with docstrings.
  3. Implement and test one function at a time.
  4. Refactor repeated code into helpers.
Naming tip
Choose names that reflect purpose: get_numbers, parse_number, compute_average are clearer than generic names.
Example stub layout

def main():
