Common Design Patterns
Recurring structures that simplify common tasks
Input → Process → Output
Read data, transform or compute results, then display or return them.
Accumulator
Build a result incrementally, like summing values or concatenating strings.
Filter & Mapper
Filter keeps items that match a condition; mapper transforms each item into something else.
Search
Find an item matching a condition or determine it doesn't exist.
Sort
Arrange items in a specific order; helps when order matters for output or processing.
Tip
Real problems often combine patterns, for example mapping values then filtering results.
