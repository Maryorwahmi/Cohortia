Work Through Examples
Solve the problem by hand to reveal edge cases and expected results
Manual examples to try
  • Normal case: [3, 5, 7] → expected average 5.
  • Single element: [7] → average 7.
  • Empty list: [] → decide whether to print a message or return None.
  • Negative values: [-3, 2] → check computation and sign handling.
From examples to tests
Record each example as a test case including input and expected output. These become automated checks later and reduce guesswork.
Pro tip
Prefer a few well-chosen examples that cover normal and boundary behaviour over many similar cases.
Key Takeaway

Examples become tests and guide your algorithm design — don't skip them.
