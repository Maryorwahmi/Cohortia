Module 6 › Chapter: Where to Go Next › Specialized Domains
Web Development
Build small web apps with Flask or FastAPI; focus on routes, forms, and templates.
Data Science
Learn NumPy, Pandas and Matplotlib; analyze datasets and tell a data story.
Automation
Script repetitive tasks, scrape sites, and work with APIs to save time and create utilities.
Machine Learning
Start with scikit-learn for supervised learning and small datasets before diving deeper.
Game Dev
Use Pygame to practice event loops, input handling, and simple animations.
Action

Pick one domain and complete a small demonstrable project. A finished project is stronger evidence of learning than many incomplete tutorials.
