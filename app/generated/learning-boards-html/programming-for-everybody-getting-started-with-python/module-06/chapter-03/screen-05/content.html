Data structures at a glance

Lists
Ordered, mutable sequences. Use for ordered collections you will modify—e.g., a user's to‑do list.
Dictionaries
Key-value mappings for fast lookup. Use for contact records keyed by username or id.
Tuples & Sets
Tuples for fixed records, sets for membership and uniqueness checks.

File I/O & OOP

File I/O
Read and write files to persist data. Practice reading CSV or JSON and handling missing or malformed lines.
Object-Oriented Programming
Model entities as classes with attributes and methods. Start with simple classes before using inheritance or patterns.
Starter projects
Contact manager (lists + dicts + file save), diary app (file I/O), or a small model class with serialization.
Example
A contact manager stores a list of contact dictionaries, reads from a JSON file at start, and writes back on exit.
Misconception
OOP is mandatory for every project. Reality: use OOP when it simplifies repeated behaviors; start simple.
Takeaway
Pick one small project that forces use of lists/dicts and file I/O; add classes when it simplifies the design.
