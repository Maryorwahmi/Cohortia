Module 6 › Chapter 6.3 › 3-Month Plan

Activity steps

  1. List three concrete skills you will learn. Example: 'Lists and dictionaries'.
  2. For each skill, choose one resource and one project idea.
  3. Decide weekly hours you can commit and a simple metric of success.
  4. Pick one community where you will post weekly updates and ask for feedback.
  5. Write a short script that prints this plan and run it—this becomes your tracker.
Key Takeaway

Turn intentions into artifacts: a printed plan, a repo, and a weekly update habit make progress visible and maintainable.

Concrete example

Skills: 1) Lists & dicts — Resource: Python tutorial — Project: Contact manager. 2) File I/O — Resource: Automate the Boring Stuff — Project: Diary app. 3) Web scraping — Resource: Real Python — Project: Weather fetcher. Commitment: 5 hours/week. Community: r/learnpython.
Misconception: Big goals without a schedule rarely get done. Fix by scheduling small weekly tasks and checking progress.
