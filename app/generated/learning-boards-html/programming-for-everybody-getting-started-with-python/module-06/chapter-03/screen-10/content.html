Why it matters

Uncaught errors make programs crash and frustrate users. Tests give you confidence that changes won't break existing behavior.

Common pattern
# safe input conversion
try:
  value = float(user_input)
except ValueError:
  print("Please enter a number")
  value = None

# simple unit test style check
def add(a, b):
  return a + b

assert add(2, 3) == 5  # basic check
Testing tips
  • Write tests for edge cases you expect to fail.
  • Start with plain assert statements; move to a test framework later.
  • Automate tests so you run them before changes.
Common mistake

Catching all exceptions broadly hides bugs. Catch specific exceptions and let unexpected errors surface during development so you can fix them.
