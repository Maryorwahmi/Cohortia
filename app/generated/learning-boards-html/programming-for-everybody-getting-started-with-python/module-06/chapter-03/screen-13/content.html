Project checklist
  • Design data structures and main program flow before coding.
  • Write small functions with single responsibilities.
  • Validate input and handle common errors.
  • Include at least one test and one example run in your README.
Example: Budget Tracker plan
Store transactions as dictionaries with keys: type, amount, description.
Functions: add_transaction, view_transactions, compute_balance, save_to_file.
Documentation

A short README with purpose, how to run, sample output, and stretch goals makes your project easy to evaluate.

Portfolio tip

One well-documented project with tests and source control history beats many incomplete examples. Record what you learned and what you'd do next.
