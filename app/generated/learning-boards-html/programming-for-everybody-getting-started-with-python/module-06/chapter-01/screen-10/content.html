Module 6 › Chapter 6.1 › Defensive Programming
Assertions

Use assert statements to document assumptions. Example: assert len(numbers) > 0, "Cannot calculate average of empty list".

Try-Except

Catch specific exceptions and handle them; avoid broad except blocks that silence errors and hide causes.

Input Validation

Check types and ranges before use. For user input, convert and validate with clear messages on failure.

Tests

Write small tests that exercise normal and boundary cases to detect regressions early.
