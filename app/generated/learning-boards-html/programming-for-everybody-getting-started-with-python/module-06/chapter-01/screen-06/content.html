Module 6 › Chapter 6.1 › Systematic Workflow
Steps
  1. Reproduce: Obtain inputs or conditions that trigger the bug consistently.
  2. Read: Interpret tracebacks and error types; read bottom-up for root cause.
  3. Trace: Walk through code mentally or with prints to track variable changes.
  4. Print: Place targeted prints to observe state at key points.
  5. Isolate: Reduce code to the smallest snippet that still fails.
  6. Check: Verify assumptions with assertions or checks.
  7. Test & Fix: Validate your fix with the failing case and additional tests.
Example: average function

If calculate_average raises ZeroDivisionError, reproduce with the same input, read the traceback to find the call, print the list and its length, and isolate by calling the function directly with a known list to confirm behavior.

Key Takeaway

A repeatable workflow turns debugging into a predictable investigation you can reuse across problems.
