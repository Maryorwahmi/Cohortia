def get_positive_numbers():
    numbers = []
    while True:
        value = input("Enter a number (or 'done'): ")
        if value == "done":
            break
        try:
            num = float(value)
        except ValueError:
            print("Please enter a valid number or 'done'.")
            continue
        if num > 0:
            numbers.append(num)
    return numbers

def calculate_average(numbers):
    assert len(numbers) > 0, "Cannot calculate average of empty list"
    total = 0.0
    for n in numbers:
        total = total + n
    return total / len(numbers)

numbers = get_positive_numbers()
average = calculate_average(numbers)
print(f"Average: {average}")
Bugs found
  1. Missing colon after if value == "done" caused a syntax error.
  2. Input was not converted to a number, so summing strings would fail or be incorrect.
  3. No validation for non-numeric input; added try-except to handle it gracefully.
  4. No filtering for positive numbers; added a check to append only values > 0.
  5. No guard against empty lists in calculate_average; added an assertion to avoid ZeroDivisionError.
Key Takeaway
