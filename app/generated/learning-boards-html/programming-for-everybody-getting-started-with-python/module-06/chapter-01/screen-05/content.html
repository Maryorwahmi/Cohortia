Module 6 › Chapter 6.1 › Types of Errors
Syntax Errors

Caught before the program runs. Examples include missing colon, unmatched parentheses, and bad indentation.

Fix by reading the interpreter message and correcting the grammar.
Runtime Errors

Happen during execution. The traceback shows the error type and where it occurred, such as ZeroDivisionError or ValueError.

Reproduce the error with the same inputs and inspect the failing operation.
Logic Errors

Program runs but results are incorrect. These require stepping through values and checking assumptions.

Use tracing and print statements to compare expected vs actual values.
Quick Example
Traceback (most recent call last):
  File "program.py", line 10, in <module>
    result = calculate_average(numbers)
  File "program.py", line 5, in calculate_average
    return sum(numbers) / len(numbers)
ZeroDivisionError: division by zero
Read this bottom-up: the error at the bottom is the actual exception; lines above show the call chain.
