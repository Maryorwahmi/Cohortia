Module 6 › Chapter 6.1 › Common Bugs
Off-by-one
Check loop bounds, inclusive vs exclusive ranges, and use small tests at boundaries like empty, one-element, and maximum index.
Variable Shadowing
Rename conflicting variables and add prints to verify which scope supplies the value at runtime.
Mutable Default Arguments
Avoid using a list as a default parameter. Use None and create the list inside the function to prevent shared state.
Modifying While Iterating
Iterate over a copy or build a new list to avoid skipping or double-processing elements.
