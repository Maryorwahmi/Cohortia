Module 6 › Chapter 6.1 › What is Debugging?
Core definition

Debugging is the process of finding and fixing errors in programs. It is a scientific workflow: observe the failure, form a hypothesis about its cause, test that hypothesis, and apply a fix that addresses the root cause.

Why it matters: saves time by targeting the cause, prevents repeated regressions, and improves confidence in code.
Common misconception: changing code until the error goes away often hides the real issue and introduces new bugs.
Analogy: detective work

Think of the program as a scene. Tracebacks and prints are clues. Use evidence to trace the chain of events back to the cause before applying the fix.

Example
If an average calculation returns an error, check the list length, check for non-numeric items, and compute intermediate sums to compare expected values.
Key Takeaway

Treat debugging as a testable investigation: hypothesize, test, and fix the root cause.
