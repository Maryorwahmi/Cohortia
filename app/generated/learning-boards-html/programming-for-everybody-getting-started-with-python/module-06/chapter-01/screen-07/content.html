Module 6 › Chapter 6.1 › Print Debugging
Code example
def calculate_average(numbers):
    print(f"DEBUG: numbers = {numbers}")
    print(f"DEBUG: len = {len(numbers)}")
    return sum(numbers) / len(numbers)

# Example run
nums = [1, 2, 3]
print(calculate_average(nums))
Include clear prefixes and minimal data to keep output readable. Use prints to disprove hypotheses quickly.
Practical tips
  • Print variable name and value together.
  • Print before and after key operations.
  • Summarize large structures instead of printing all values.
  • Remove or convert to logging after fixing the bug.
Common Mistake

Scattering prints everywhere makes output noisy. Place prints where they test a clear hypothesis.
