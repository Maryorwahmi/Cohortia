Module 6 › Chapter 6.1 › How you'll use these skills
Quick Diagnosis

Turn a traceback into a starting point: identify the error type and line, then inspect that area of code and its inputs.

ZeroDivisionError → check denominators
NameError → check variable names and scope
Reproduce & Isolate

Make the bug happen reliably and reduce the code to the minimal example that still fails.

Recreate inputs
Comment out unrelated code
Print & Trace

Add targeted prints to observe actual values and flow, then compare to expectations.

Defensive Checks

Use assertions and try-except to document assumptions and handle likely failures gracefully.
