Tracebacks
Read the last line for the error type and follow the call stack upward to find where the problem originated.
Prints
Use targeted debug prints to compare expected and actual values at key points in execution.
Isolate
Create the smallest reproducible example to make diagnosis and testing much easier.
Final takeaway
Debugging is a repeatable, scientific process. Use the tools and habits here to make it fast, clear, and reliable.
