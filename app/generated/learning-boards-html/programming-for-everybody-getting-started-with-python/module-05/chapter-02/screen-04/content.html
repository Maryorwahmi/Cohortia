Module 5 › Chapter 5.2 › What a for Loop Is
Definition

A for loop visits every element of a sequence and runs the loop body once per element. The loop variable is assigned each element in turn, so you usually don't need an index.

Analogy: conveyor belt delivering items to a processing station, each item is handled once.
Concrete example: iterate characters in a string to count or transform them.
Common mistake: expecting for to include the range end; remember the half-open rule for ranges.
Key Takeaway

Use for to move through every element of a collection without manual index management.

Illustrative snippet
for letter in "Python":
    print(letter)

# Output:
# P
# y
# t
# h
# o
# n
Example explained: the loop variable letter takes each character, and the print function runs six times. This pattern is identical whether the sequence is a string or a list of objects.
