Vowel counter — code
text = input("Enter a string: ").lower()
vowel_count = 0
for char in text:
    if char in "aeiou":
        vowel_count = vowel_count + 1
print(f"Number of vowels: {vowel_count}")
Explanation: lowercasing avoids case mismatches. The membership test uses the in operator, which reads clearly and avoids index arithmetic. The counter increments only when a vowel is found.
Notes and common mistakes
  • Do not modify the string while iterating. Build a new string or list instead.
  • Remember to normalize case to avoid missed matches.
  • Beware of accented vowels; this basic set counts only ASCII vowels.
