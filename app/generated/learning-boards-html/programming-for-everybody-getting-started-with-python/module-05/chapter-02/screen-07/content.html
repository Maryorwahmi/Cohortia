Module 5 › Chapter 5.2 › Start / Step
Even numbers example
for i in range(2, 21, 2):
    print(i)   # 2,4,6,...,20
Note: stop is 21 to include 20. If you wrote range(2,20,2) you would stop at 18.
Countdown example
for i in range(10, 0, -1):
    print(i)   # 10,9,8,...,1
Be careful: if start <= stop and step is negative, the range is empty. Match step sign to start/stop direction.
Pro tip

When in doubt, print the list(range(...)) to inspect the generated numbers during development.
