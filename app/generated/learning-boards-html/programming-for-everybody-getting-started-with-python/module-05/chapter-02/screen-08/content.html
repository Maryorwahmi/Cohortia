Module 5 › Chapter 5.2 › Lists & enumerate()
List iteration
fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(fruit)

# Using enumerate:
for index, fruit in enumerate(fruits):
    print(f"{index}: {fruit}")
Enumerate returns tuples of (index, value). Unpack them directly in the for header for concise and readable code.
When to use enumerate
  • When output needs line numbers or labels.
  • When you need to update a list by index in place.
  • When pairing values with their position simplifies downstream logic.
Key Takeaway

Enumerate avoids manual index management and produces clearer, safer loops.
