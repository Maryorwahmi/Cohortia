Module 5 › Chapter 5.2 › range()
Common forms
for i in range(5):
    print(i)   # 0,1,2,3,4

for i in range(2, 10):
    print(i)   # 2..9

for i in range(0, 10, 2):
    print(i)   # 0,2,4,6,8

for i in range(10, 0, -1):
    print(i)   # 10 down to 1
Half-open intervals make counting and indexing consistent. If you need inclusive behavior, adjust the stop value accordingly.
Practical tips
  • Use range(len(sequence)) to iterate by index safely.
  • Pick a step when you want to skip items or generate even/odd numbers.
  • Use negative step to count backwards; ensure start and stop are set correctly.
Misconception

Expecting range to include the stop causes off-by-one errors. Check stop-1 when you need the final value.
