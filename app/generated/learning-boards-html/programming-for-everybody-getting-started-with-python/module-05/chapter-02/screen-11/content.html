Prime detection example
for n in range(2, 10):
    for x in range(2, n):
        if n % x == 0:
            print(f"{n} = {x} * {n//x}")
            break
    else:
        print(f"{n} is prime")
Here the else is paired with the inner for. It runs only when the inner loop did not hit break, indicating the number is prime.
Misreading caution
  • Do not confuse for-else with try-else or if-else; the else condition depends on break usage inside the loop.
  • Use explicit comments when first learning for-else to clarify intent.
