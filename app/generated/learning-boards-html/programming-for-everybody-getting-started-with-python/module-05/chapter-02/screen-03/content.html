Practice tasks
  • Print even numbers from 2 to 20 using range with a step of 2.
  • Build a multiplication table using range for a fixed number of rows.
  • Count vowels by iterating characters in a lowercased string.
  • Draw a right-angled triangle by repeating asterisks in a growing loop.
Toolbox reminders
range(start, stop, step) — stop is excluded (half-open interval)
enumerate(sequence) — index and value together
zip(a, b) — iterate pairs until the shortest sequence ends
break and continue — alter normal loop flow
