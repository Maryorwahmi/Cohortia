Module 5 › Chapter 5.2 › zip()
Parallel iteration example
names = ["Alice", "Bob", "Charlie"]
ages = [25, 30, 35]
for name, age in zip(names, ages):
    print(f"{name} is {age} years old")
Zip pairs elements positionally. If ages had only two entries, Charlie would be ignored because zip stops with the shortest list.
When zip is not right
  • If you must keep all items from the longest list, zip will drop extras.
  • To pair by a matching key rather than position, use dictionaries or mapping logic.
Check

If lists differ in length, what happens to the extra items? Try it and inspect list(zip(...)).
