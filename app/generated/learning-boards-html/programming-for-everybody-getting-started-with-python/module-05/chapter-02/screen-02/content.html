Module 5 › Chapter 5.2 › Learning Objectives
01
Write for loops over strings, ranges, and lists

You will iterate through characters, numeric sequences, and collections to process each element. This skill is essential for transforming text, counting values, and processing lists without manual indexing.

VERIFIED COMPETENCY MILESTONE
02
Use range() to generate numbers

You will generate sequences of integers with range, understanding start, stop, and step. This reduces counter mistakes and makes counting loops explicit and concise.

VERIFIED COMPETENCY MILESTONE
03
Distinguish for versus while

You will learn when to use for when iterating known sequences and when to use while for condition-driven repetition, helping reduce bugs and simplify reasoning.

VERIFIED COMPETENCY MILESTONE
04
Iterate using the in operator

You will rely on the in operator to readably iterate sequences, preventing off-by-one errors and making code express the idea of membership and traversal directly.
