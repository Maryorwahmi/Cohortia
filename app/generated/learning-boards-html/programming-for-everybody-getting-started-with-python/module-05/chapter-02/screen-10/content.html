Module 5 › Chapter 5.2 › break & continue
Example: skip multiples of 3, stop after 10
for number in range(1, 20):
    if number % 3 == 0:
        continue  # Skip multiples of 3
    if number > 10:
        break     # Stop after 10
    print(number)

# Output: 1, 2, 4, 5, 7, 8, 10
Use continue to filter and break to end early when you've achieved the loop's purpose.
Readability advice
  • Keep loop bodies short; extract helpers for complex conditions.
  • Prefer for-else when you want to detect a normal completion versus an early break.
Gotcha

break prevents a for-else else block from running; use this intentionally to detect whether a search found a match.
