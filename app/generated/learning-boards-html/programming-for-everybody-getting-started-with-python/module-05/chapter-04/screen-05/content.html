Module 5 › Chapter 5.4 › Iterating with for
Code walkthrough
text = "Hello, World!"
result = ""
for char in text:
  if char.islower():
    result = result + char.upper()
  else:
    result = result + char

print(result)  # HELLO, WORLD!
This shows the empty-result pattern. The loop variable char holds each character in turn. The result is a new string built by concatenation.
Explanation
  • Create an empty result to collect output characters.
  • Iterate the input string; each iteration sees one character.
  • Decide what to append and build the final string.
Common mistake
Trying to assign to an index of the original string instead of building a new one; that raises a TypeError because strings are immutable.
Key Takeaway

The for-each-character pattern is simple, expressive, and the foundation for many text tasks.
