Module 5 › Chapter 5.4 › Build new string
Step-by-step cards
1. Initialize
result = empty string or list
2. Iterate
for char in text: examine each character
3. Decide
append original, transformed, or skip
4. Finalize
join if using a list or use result as-is
# Efficient variant
chars = []
for ch in text:
  if some_condition(ch):
    chars.append(transform(ch))
  else:
    chars.append(ch)
result = "".join(chars)
Example scenario
Remove all digits from a user string: iterate, test isdigit, and only append non-digit characters. This preserves original text where appropriate and removes unwanted parts.
Misconception
Students sometimes try to change characters by assignment. Remember: you must produce a new string instead.
