Manual count example
text = "Programming is fun and programming is powerful"
count = 0
for char in text:
  if char == "p":
    count = count + 1
print(f"The letter 'p' appears {count} times")

# Better: text.count('p')
The manual loop shows each step: initialize, check, increment. The count method hides the loop but returns the same result.
Substring search
text = "The quick brown fox jumps over the lazy dog"
target = "fox"
found = False
for i in range(len(text) - len(target) + 1):
  if text[i:i+len(target)] == target:
    found = True
    print(f"Found at position {i}")
    break
if not found:
  print("Not found")
This sliding window method is the basic technique behind the in operator and find method. Use it when you need custom matching behavior.
