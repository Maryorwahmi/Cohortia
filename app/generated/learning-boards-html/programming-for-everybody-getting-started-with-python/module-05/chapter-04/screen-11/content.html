Module 5 › Chapter 5.4 › Palindrome checker
Reference code
word = input("Enter a word: ").lower().replace(" ", "")
is_palindrome = True
for i in range(len(word) // 2):
  if word[i] != word[len(word) - 1 - i]:
    is_palindrome = False
    break
print(f"Is palindrome: {is_palindrome}")
This checks symmetric characters efficiently and exits early when a mismatch is found.
Notes
Normalization step removes spaces and uses lowercase to make comparisons fair. Decide how to handle punctuation depending on your requirements.
