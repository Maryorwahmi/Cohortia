Module 5 › Chapter 5.4 › ord and chr
Examples
print(ord('A'))  # 65
print(ord('a'))  # 97
print(chr(65))   # A
print(chr(97))   # a
These show the numeric code points for letters. Use them to perform shifts while preserving case.
Shift recipe
  • Check isalpha to limit to letters
  • Select base: base for uppercase or lowercase
  • Compute shifted = (ord(char) - base + shift) % 26 + base
  • Convert with chr(shifted)
Common mistake
Shifting non-letters without checks leads to unexpected characters. Always guard with an alphabetic test.
