Practice tasks
Palindrome checker
Compare characters from both ends moving inward; ignore case and spaces for a fair check.
Vowel counter
Scan and count membership for each vowel separately or together.
Character frequency
Iterate and build a dictionary of counts for alphabetic characters only.
Caesar cipher
Use ord and chr to shift letters while preserving case and non-letter characters.
Pro tip
For many transforms, collecting characters in a list and using join at the end is faster than repeated concatenation for long text. This preserves the same learning pattern while keeping performance in mind.
Why it matters
These skills are the building blocks for parsing, validating, and transforming user input in larger programs.
