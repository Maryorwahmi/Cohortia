Module 5 › Chapter 5.4 › Indexing vs iteration
Direct iteration
word = "Python"
for char in word:
  print(char)
Use this when you only need the characters and want simple, readable code.
Index-based iteration
text = "Python"
for i in range(len(text)):
  print(f"Character at index {i}: {text[i]}")
Use this when you need positions, slices, or symmetric comparisons for palindrome checks.
Example use
Finding substrings uses index-based slices. Palindrome checks compare text[i] to text[len(text)-1-i], which requires numeric positions.
