Module 5 › Chapter 5.4 › Strings as Sequences
Strings are sequences
An ordered collection of characters with indexing, slicing, and iteration.
Example
len, in, indexing, and for loops all work on strings like they do on lists
Why it matters
Character-level control enables validation, transformation, and simple ciphers.
In this lesson
You will see code examples for iterating, building new strings, counting letters, finding substrings, and using ord and chr for shifts.
Explore Key Topics
Iterating
Loop through characters with a for loop to inspect or transform text.
Building
Since strings are immutable, build a new result string one character at a time.
ord & chr
Convert characters to numeric code points and back for character arithmetic.
Visual concept
Character train
Imagine each character as a car in an ordered train. A for loop inspects each car; building a new string assembles a new train.
Step
Inspect each car, decide what to append, and add to the result train.
Constraint
You cannot edit the original train; you create a new one with the desired cars.
