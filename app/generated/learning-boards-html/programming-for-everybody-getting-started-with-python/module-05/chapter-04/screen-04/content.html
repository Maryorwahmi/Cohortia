Module 5 › Chapter 5.4 › Strings are sequences
What sequence means
Ordered positions, predictable indexing, and familiar sequence operations.
Common operations
  • len returns the number of characters
  • in checks membership of a character
  • Indexing with zero-based positions and negative indexes from the end
Misconception
Strings are not mutable. Attempts to assign to a character index will cause an error. Build a new string instead.
Key Takeaway

Treat strings like ordered, read-only lists of characters and use sequence tools to inspect and slice them.

Concrete example
word = "Python"
for i in range(len(word)):
  print(f"Character at index {i}: {word[i]}")
This demonstrates indexing, length, and a for loop visiting characters by position. Negative indexes also allow access from the end, which is helpful for palindrome checks.
