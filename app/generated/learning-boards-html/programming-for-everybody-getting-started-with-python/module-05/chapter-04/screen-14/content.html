Module 5 › Chapter 5.4 › Key Concepts
Strings are sequences
Ordered characters with indexing, slicing, and iteration.
Immutable
You must build a new string to represent changes; you cannot assign to indices.
ord & chr
Convert between characters and numeric code points to perform shifts and arithmetic.
Takeaway
Treat strings as ordered, immutable sequences and apply the iterate-and-build pattern; use ord and chr for controlled character arithmetic when needed.
