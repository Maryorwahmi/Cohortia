Module 5 › Chapter 5.4 › Hands-on
Starter tasks
  • Palindrome checker (ignore case and spaces)
  • Vowel counter (count each vowel separately)
  • Character frequency (case-insensitive, alphabetic only)
  • Caesar cipher (preserve case, non-letters unchanged)
Testing and edge cases
Use short inputs to validate logic and boundary letters to test wrapping. Confirm behavior on empty strings and strings with only punctuation or spaces.
Common pitfall
Trying to mutate a string directly or failing to handle case leads to runtime errors or incorrect results. Normalize inputs and build new strings instead.
