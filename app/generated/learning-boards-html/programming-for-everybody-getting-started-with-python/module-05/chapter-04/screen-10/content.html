Reference implementation
def caesar_cipher(text, shift):
  result = ""
  for char in text:
    if char.isalpha():
      base = ord('A') if char.isupper() else ord('a')
      shifted = (ord(char) - base + shift) % 26 + base
      result = result + chr(shifted)
    else:
      result = result + char
  return result

# Example: caesar_cipher("Hello", 3)  -> Khoor
This code preserves punctuation, wraps letters correctly, and maintains case. Test with edge letters to confirm wrapping behavior.
Walkthrough
  1. Iterate each character.
  2. Check isalpha to handle letters only.
  3. Choose base for uppercase or lowercase.
  4. Compute shift with modulo and convert back with chr.
Misconception
Forgetting to handle non-letter characters or failing to preserve case will change meaning and produce incorrect output.
