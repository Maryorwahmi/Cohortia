Module 5 › Chapter 5.3 › Breaking out of nested loops
Flag pattern
found = False
for i in range(10):
    for j in range(10):
        if i * j == 25:
            print('Found')
            found = True
            break
    if found:
        break
Set a flag to indicate the condition and break both loops explicitly. This pattern is readable and widely used.
Function return
Wrap the loops in a function and use return to exit both loops at once when the condition is met. This is concise and clear when returning a result is appropriate.
Misconception
Break only exits the inner loop; outer loops continue unless you take explicit action to stop them.
Key Takeaway

Choose a clear early-exit strategy: flag variables for explicit control or function returns for cleaner exits when appropriate.
