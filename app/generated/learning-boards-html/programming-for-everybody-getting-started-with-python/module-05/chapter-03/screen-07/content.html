Code (right-aligned triangle)
height = 5
for i in range(1, height + 1):
    spaces = " " * (height - i)
    stars = "*" * (2 * i - 1)
    print(spaces + stars)
Test small heights and print the first and last rows to confirm your space and star counts. String multiplication is a concise way to build repeated characters.
Hollow rectangle idea
Use nested loops and a conditional to print border characters when row or column is at an edge and spaces otherwise.
Chessboard trick
Alternate symbols by checking whether the sum of row and column is even or odd; that produces an alternating grid.
Key Takeaway

Break visual patterns into row and column formulas, test edges, and use string arithmetic for compact code.
