Module 5 › Chapter 5.3 › What is a nested loop?
Definition
A loop statement placed inside another loop so the inner loop runs completely for each outer step.
Example
for i in range(3):
    for j in range(3):
        print(f"i={i}, j={j}")
This prints nine lines because the inner loop runs three times for each outer value of i. Count the calls to the print function to confirm.
Why it matters
Nested loops let you work naturally with two-dimensional data, generate tables and visual patterns, and examine all pairs of items when necessary.
Common misconception
Don't assume inner loops run only once per outer step — they fully iterate each time. Counting iterations prevents this mistake.
