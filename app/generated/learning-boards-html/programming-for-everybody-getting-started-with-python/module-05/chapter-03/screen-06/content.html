Module 5 › Chapter 5.3 › Multiplication table
Code
for i in range(1, 6):
    for j in range(1, 6):
        print(f"{i*j:4}", end='')
    print()
Here the outer loop sets rows 1 through 5 and the inner loop prints five columns per row, producing 25 values total. Formatting '{'{i*j:4}'}' reserves space so columns align.
Example output
   1   2   3   4   5
   2   4   6   8  10
   3   6   9  12  15
   4   8  12  16  20
   5  10  15  20  25
Tip
If columns misalign as numbers grow, increase width padding in formatting to keep a neat grid.
Key Takeaway

Treat rows and columns as separate loop bounds; formatting keeps printed grids readable.
