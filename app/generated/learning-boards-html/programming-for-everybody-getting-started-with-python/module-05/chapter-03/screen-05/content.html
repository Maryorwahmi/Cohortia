Module 5 › Chapter 5.3 › Counting total iterations
Claim
Multiply outer loop count by inner loop count to get total iterations.
Walkthrough with counter
counter = 0
for i in range(10):
    for j in range(5):
        counter += 1
print(counter)  # expected 50
Counting in code gives you a testable prediction. Compare the printed total to your calculation to catch off-by-one errors.
Practical significance
Use this multiplication to decide whether nested loops are acceptable for your input sizes or if a more efficient algorithm is needed.
Misconception
Avoid adding iteration counts; the inner loop repeats fully for each outer iteration, making counts multiply rather than sum in a single pass.
Key Takeaway

Annotate and count iterations to confirm reasoning. Outer times inner predicts total work precisely.
