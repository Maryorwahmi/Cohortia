Module 5 › Chapter 5.3 › Mixing for & while
Example
row = 1
while row <= 5:
    for col in range(1, row + 1):
        print(col, end=' ')
    print()
    row = row + 1
This produces rows of increasing length. Notice the explicit row increment; forgetting it causes an infinite loop, which is the main risk with while loops.
Pitfall
Forgetting to update the while control variable creates an infinite loop. Always test with small bounds.
Clarification
An inner for loop restarts each outer iteration; it does not maintain state across outer loops.
Key Takeaway

Use mixed loops when the outer loop needs conditional or non-linear updates, and always verify loop control updates to avoid infinite repetition.
