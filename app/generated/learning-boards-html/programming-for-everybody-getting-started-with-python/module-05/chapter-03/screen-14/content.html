Unique pairs
Start inner loop at i + 1 to avoid duplicates and self-pairs when enumerating combinations.
Breaking out
Use flags or wrap loops in a function and return to stop multiple nested loops at once.
Performance watch
Always compute outer × inner and test with realistic inputs to detect costly n squared growth.
Final takeaway

Practice with small examples, count iterations, and use the right loop patterns to avoid duplicates and control flow errors.
