Module 5 › Chapter 5.3 › Performance
Principle
If both loops scale with n, total operations scale as n squared, written O(n²).
Concrete example
Two loops of 1,000 iterations produce 1,000,000 inner operations. That is often too slow; consider alternative strategies like using a set for lookups or reducing the number of comparisons.
Alternative strategies
Use hashing, sort-and-scan, or change the algorithm to avoid nested full scans when input sizes are large.
Exit patterns
To break out of multiple loops, use a flag checked by outer loops or place loops in a function and use return to exit immediately.
Warning

Do not assume nested loops are cheap. Always compute expected total iterations and test with representative input sizes.
