Learning Objectives
Build hands-on skills with nested loops and measure their cost.
01
Write nested loops
Practice placing one loop inside another to visit rows and columns. You'll learn how structure maps to data layout.
VERIFIED COMPETENCY MILESTONE
02
Understand inner-loop completion
Explain why the inner loop runs fully for each outer loop step and how that affects output order.
VERIFIED COMPETENCY MILESTONE
03
Apply to patterns and tables
Use nested loops to print multiplication tables, triangles, hollow rectangles, and alternating grids like a chessboard.
VERIFIED COMPETENCY MILESTONE
04
Calculate total iterations
Compute outer times inner to reason about runtime and know when nested loops cause quadratic growth.
VERIFIED COMPETENCY MILESTONE
