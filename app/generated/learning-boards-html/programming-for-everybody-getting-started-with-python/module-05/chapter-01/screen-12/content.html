Pro tips & debugging
Naming
Use clear names like count, total, attempts so the condition and update are obvious.
Small tests
Run loops with small limits during development to see behavior quickly and catch infinite loops early.
Trace & logs
Print key variable values for a few iterations, or add a guard counter to break on excessive runs.
Misreads
Watch out for off-by-one errors where the update overshoots or undershoots the termination condition.
Mental model
Think of a loop as a contract: start, check, do work, change state so the contract can complete.
Try this

Before running code, write the first three values of your loop variable by hand. If they look wrong, fix the update first.
