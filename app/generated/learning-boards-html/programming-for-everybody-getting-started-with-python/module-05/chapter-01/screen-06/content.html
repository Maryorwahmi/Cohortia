Module 5 › Chapter 5.1 › Execution Steps
Process
1. Initialize
Give the loop a starting state so the first condition check has meaningful values.
2. Check condition
Evaluate the boolean expression; if false, skip the loop body entirely.
3. Run body
Execute the statements that perform work, including any side effects like printing or input.
4. Update & repeat
Change loop state so the next condition check reflects progress; then return to step two.
Concrete example
If count starts at five and condition is count < 5, the loop body never runs because the check fails immediately. That demonstrates the pre-check behavior.
Misconception
Do not assume the loop body runs at least once. For guaranteed one-time execution consider other constructs or adjust initialization.
Check your understanding

Write down the state values for two iterations and confirm the update moves the condition toward false.
