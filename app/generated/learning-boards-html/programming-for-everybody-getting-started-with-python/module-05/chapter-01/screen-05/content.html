Module 5 › Chapter 5.1 › Loop Components
Definition

Initialization

Set the starting value. This ensures the loop variable exists and has a known value before the condition is checked.

Condition

A boolean expression evaluated before each iteration. Keep it simple and directly linked to your loop state.

Update

Change the loop state inside the loop so the condition can eventually become false. The update must affect the same variables used in the condition.

Quick checklist
  • Is the loop variable initialized before use?
  • Does the condition use that variable or state directly?
  • Does the update move the variable toward termination?
Misconception
Changing unrelated variables is not an update for the loop. Ensure the update affects what the condition checks.
Key Takeaway

Explicitly pair the condition and update so each loop makes progress toward stopping.
