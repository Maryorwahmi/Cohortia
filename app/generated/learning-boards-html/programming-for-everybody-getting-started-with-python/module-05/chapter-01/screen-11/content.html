Module 5 › Chapter 5.1 › Guessing Game
Starter code
import random

target = random.randint(1, 100)
guess = None
attempts = 0

while guess != target:
    try:
        guess = int(input("Guess a number between 1 and 100: "))
        attempts = attempts + 1
        if guess < target:
            print("Too low!")
        elif guess > target:
            print("Too high!")
    except ValueError:
        print("Please enter a valid number.")

print(f"Congratulations! You found it in {attempts} attempts.")
This code validates input, counts attempts, provides feedback, and stops when the guess matches the target. The loop condition controls repetition until success.
Testing checklist
  • Try correct guess on first try.
  • Enter invalid input and confirm it is handled.
  • Verify attempts match the number of valid guesses submitted.
Misconception
Do not trust user input; always validate and handle exceptions so the loop remains robust.
Key Takeaway

Interactive loops combine several patterns and are excellent practice for real programs that interact with users.
