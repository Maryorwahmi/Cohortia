Practice & Assessment

Concrete tasks and conceptual checks to cement understanding of while loops.

Task 1: Countdown
Print numbers 10 to 1 using a loop that decrements each iteration. Verify termination.
Task 2: Positive number validation
Keep asking until the user enters a positive integer. Use error handling to avoid crashes from bad input.
Task 3: Factorial
Use an accumulator variable to multiply values from one up to n and return the result.
Task 4: Guessing game
Pick a random target, prompt until guessed, and give feedback on each guess while counting attempts.
Assessment idea

Explain an infinite loop, list the top three beginner causes, and describe how to stop an infinite loop in the terminal.
