The while Loop

Repeat a block while a condition remains true.

Interactive 16:9 Masterclass
When to use
When a task must repeat until a changing condition ends it, such as waiting for valid input or counting items.
Key risk
Infinite loops occur if the loop never makes its condition false; learn simple checks to avoid that.
Patterns
Counting, accumulation, validation loops, and search loops all map to while loops.
In this lesson

You will learn how while loops check conditions, how to structure initialization, condition and updates, and practical patterns like validation and accumulation. Example code will appear in later slides for hands-on practice.

Visual concept
Loop components connected: init → condition → body → update
Mini flow
Initialize variables before the loop
Evaluate condition; if true run the body
Update state so the condition can change
Explore key topics
Counting loops — iterate a fixed number of times using an update that approaches the condition.
Validation loops — repeatedly ask for input until it meets rules, often with try/except handling.
Control statements — break exits early, continue skips to the next check, and else runs after normal completion.
