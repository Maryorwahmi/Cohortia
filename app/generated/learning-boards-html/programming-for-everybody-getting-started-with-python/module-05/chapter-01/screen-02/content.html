Learning Objectives

Understand, apply, and reason about while loops

Bloom: Learn → Understand → Apply → Master
01
Explain loops and iteration

Describe what a loop is, why repetition saves work, and give a short counting example that shows repeated execution.

Venn: repetition vs single-run
VERIFIED COMPETENCY MILESTONE
02
Write while loops that terminate

Practice initializing variables, writing clear conditions, and updating loop state so loops finish predictably.

Timeline: init → condition → update
VERIFIED COMPETENCY MILESTONE
03
Detect and avoid infinite loops

Identify common causes of infinite loops and learn quick checks to debug them, plus how to interrupt a running program.

Mnemonic: check init, check update, check direction
VERIFIED COMPETENCY MILESTONE
04
Use while loops for validation and accumulation

Apply loops to ensure valid input, compute sums, factorials, and implement small interactive programs like a guessing game.

Visual: piggy bank for accumulators
VERIFIED COMPETENCY MILESTONE
