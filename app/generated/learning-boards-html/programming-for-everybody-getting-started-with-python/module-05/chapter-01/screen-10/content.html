Module 5 › Chapter 5.1 › Accumulator Pattern
Sum example
# Sum of numbers from 1 to 10
total = 0
number = 1
while number <= 10:
    total = total + number
    number = number + 1

print(f"Sum: {total}")  # 55
Start total at zero for sums so additions accumulate correctly. For multiplication based accumulators, start at one.
Factorial example
n = int(input("Enter a number for factorial: "))
factorial = 1
i = 1
while i <= n:
    factorial = factorial * i
    i = i + 1
print(f"{n}! = {factorial}")
Misconception
Initializing a product accumulator to zero yields zero for every multiplication; choose the neutral element wisely.
Key Takeaway

Accumulators collect results across iterations; initialize them so they don't erase or nullify progress.
