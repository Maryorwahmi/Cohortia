Module 5 › Chapter 5.1 › Counting Example
Code example
count = 0
while count < 5:
    print(count)
    count = count + 1

# Output:
# 0
# 1
# 2
# 3
# 4
How it runs
  • Initialize count to zero before the loop begins.
  • Check if count is less than five; if true, run the body.
  • After printing, increment count so progress is made toward stopping.
Common mistake
Forgetting to increment count leaves the condition true forever and produces an infinite loop.
Trace walkthrough
Start: count = 0. Condition true, print zero, then set count to one. Repeat: condition true for one through four. When count becomes five, condition is false and the loop stops. Tracing each value verifies the loop's progress and helps locate missing updates.
Key Takeaway

Every while loop needs initialization, a clear condition, and an update that moves the state toward termination.
