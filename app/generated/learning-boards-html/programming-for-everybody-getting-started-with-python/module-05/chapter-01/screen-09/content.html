Module 5 › Chapter 5.1 › Validation Loop
Code walkthrough
age = -1
while age < 0:
    try:
        age = int(input("Enter your age (must be 0 or higher): "))
        if age < 0:
            print("Age cannot be negative. Try again.")
    except ValueError:
        print("That is not a valid number. Try again.")
        age = -1

print(f"Your age is {age}")
Why this works
The loop continues while the sentinel is invalid. On successful conversion the sentinel changes and the loop stops.
Misconception
Do not let exceptions crash the program; catch conversion errors and keep the loop running until valid data appears.
Concrete scenario
When asking for an age you must reject negative numbers and non-numeric entries. The loop enforces this until the user supplies a valid integer at or above zero.
Key Takeaway

Validation loops keep your program safe from bad input by refusing to proceed until data meets your rules.
