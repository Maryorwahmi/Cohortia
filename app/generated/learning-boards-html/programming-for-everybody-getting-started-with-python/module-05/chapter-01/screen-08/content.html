Module 5 › Chapter 5.1 › Loop Controls
Definition & examples
break — immediate exit
Use when a terminating condition is found inside the loop and no further iterations are needed.
continue — skip to next check
Skip the rest of the iteration and go straight to the next condition evaluation; useful when filtering items.
while ... else — finish vs interrupted
The else block runs only if the loop ended because the condition became false. If break ran, else is skipped.
When to prefer what
  • Use break for early exits when a search succeeds.
  • Use continue to ignore invalid items and keep processing the rest.
  • Use else to handle the case where the loop never found a break condition.
Common mistake
Heavy use of continue can hide control flow; prefer clear branching and simple updates when possible.
Key Takeaway

Small control statements change flow but should be used sparingly for clarity.
