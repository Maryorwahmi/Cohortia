Module 5 › Chapter 5.1 › Infinite Loops
Comparison — broken vs correct
Broken example
If a loop never updates the variable used in its condition, the condition's truth never changes and the loop runs forever.
Corrected example
Add an update that moves the variable toward the termination value, or add a guard counter that breaks after a maximum number of iterations.
Stop a running infinite loop
Press Ctrl+C in the terminal to send an interrupt signal. This is a standard way to halt runaway code during development.
Three common causes
  • Missing update of the loop variable.
  • Updating the variable in the wrong direction.
  • Using a condition that is always true without a break.
Debugging tips
Add prints of the key variable each iteration, trace values on paper, or add a safety counter that forces an exit after a large number of loops.
Pro tip
When testing, run loops with small limits so errors are visible quickly and do not run accidental long computations.
