Module 6 › Chapter 5.5 › Refactor inefficient code
Inefficient snippet 1 — indices
# Inefficient
for i in range(len(items)):
  print(items[i])

# Efficient
for item in items:
  print(item)
Inefficient snippet 2 — search
# Inefficient
found = False
for item in items:
  if item == target:
    found = True

# Efficient
found = target in items
Inefficient snippet 3 — manual sum
# Inefficient
total = 0
for i in range(len(numbers)):
  total = total + numbers[i]

# Efficient
total = sum(numbers)
Inefficient snippet 4 — nested loops
# Inefficient O(n^2)
count = 0
for i in range(len(items)):
  for j in range(len(items)):
    if i != j and items[i] == items[j]:
      count = count + 1

# Efficient approach hint
# Use a dictionary or Counter to count duplicates in O(n)
Key Takeaway

Refactoring common patterns to Pythonic forms reduces code and often improves performance. Test results remain the best verification.
