Module 6 › Chapter 5.5 › Loop best practices checklist
01 — Name the goal
Search, filter, transform, or accumulate?
02 — Exit early
Add break/return if a single result suffices.
03 — Hoist invariants
Compute once outside the loop.
04 — Iterate directly
Use enumerate when you need indexes.
05 — Built-ins
Replace manual loops with sum, in, min, max when applicable.
06 — Count vs collect
Choose minimal storage based on downstream needs.
07 — Keep body small
Extract helpers for complex logic to improve readability.
Pro tip
Measure before and after only when behavior is stable. Correctness trumps premature optimization.
Key Takeaway

Follow a small refactor checklist to safely simplify loops and improve performance without breaking behavior.
