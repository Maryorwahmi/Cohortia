Early exit with break
Stop as soon as the goal is met to avoid extra iterations.
Continue to skip
Use continue to bypass items that should not be processed.
Hoist invariants
Move repeated work out of loops or use direct iteration.
Takeaway

Small, consistent changes to loop structure make programs faster and easier to understand. Use them as a checklist when you refactor.
