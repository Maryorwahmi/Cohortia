Module 6 › Chapter 5.5 › Using continue to skip irrelevant items
Example: skipping comments
for line in lines:
  if line.startswith("#"):
    continue  # Skip comments
  process_line(line)
This keeps the processing code unindented by the comment check and clearly separates the filter from the action.
Misconception
Avoid using continue to hide complex logic. If skipping makes the flow confusing, prefer an explicit conditional structure or a helper function.
Refactor checklist
  • Identify filter conditions for items you want to skip.
  • Replace nested if blocks by continuing early when the filter matches.
  • Run tests to ensure skipped items produce no side effects.
Key Takeaway

Use continue to keep your loop body focused and reduce nesting. Only skip when it improves clarity.
