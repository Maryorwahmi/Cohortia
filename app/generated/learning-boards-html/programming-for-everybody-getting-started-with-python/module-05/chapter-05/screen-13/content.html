Module 6 › Chapter 5.5 › Common mistakes and pro-tips
Frequent mistakes
  • Using indices when direct iteration is clearer.
  • Recomputing invariant expressions inside the loop.
  • Leaving nested loops in place when better data structures exist.
  • Optimizing before confirming correctness with tests.
Practical pro-tips
  • Write the simplest correct loop first, then simplify or optimize incrementally.
  • Use enumerate when you need indexes; use zip for parallel iteration.
  • Prefer built-ins like sum and membership tests for clarity and speed.
Check your understanding
Given a nested loop over n items, what happens to runtime when n doubles? Why might a set or dict help?
Key Takeaway

Small style choices — direct iteration, hoisting invariants, using built-ins — compound into significantly better loops over time.
