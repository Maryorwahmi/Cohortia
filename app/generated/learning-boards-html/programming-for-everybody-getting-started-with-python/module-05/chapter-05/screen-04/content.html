Module 6 › Chapter 5.5 › Using break for early exit
Definition
Break exits the current loop immediately. Return exits the function and therefore the loop too.
Concrete example
def find_first_negative(numbers):
  for num in numbers:
    if num < 0:
      return num  # Exit immediately when found
  return None  # No negative number found
Misconception
Some think break is only about speed. It also isolates intent: when you break, you signal clearly that no further iterations are relevant. But remember break affects only the current loop level.
Process to refactor
  1. Find code that searches for a single match or checks a one-time condition.
  2. Add a return or break immediately when the condition is met.
  3. Confirm behavior with tests that include matches at start, middle, and end.
Key Takeaway

Stopping a loop early makes code faster and communicates intent. Use break or return when a single match satisfies the goal.
