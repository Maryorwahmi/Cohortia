Module 6 › Chapter 5.5 › Algorithmic complexity
O(1)
Constant time — example: list access
Accessing an element by index takes the same number of steps regardless of list length.
O(n)
Linear time — example: single loop
Processing each item once results in work proportional to n.
O(n²)
Quadratic time — example: nested loops
Two loops over the same list lead to roughly n × n operations and scale poorly as n grows.
Practical check
  1. Estimate work: count nested loops or repeated work.
  2. If you see nested loops, ask whether a set or dictionary can avoid inner scans.
  3. Prefer built-ins that reduce algorithmic cost when possible.
Key Takeaway

Think in how work grows with n. Small inputs hide inefficiencies; larger inputs expose them. Choose algorithms accordingly.
