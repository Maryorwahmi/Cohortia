Module 6 › Chapter 5.5 › Avoiding redundant calculations
Inefficient vs Better
Inefficient: len(text) computed on every iteration
for i in range(len(text)):
  print(text[i])
Better: iterate directly, or use enumerate when you need an index
for char in text:
  print(char)

for i, char in enumerate(text):
  print(f"{i}: {char}")
Why it helps
  • Fewer operations per iteration reduces total work.
  • Direct iteration expresses intent clearly — you are processing items, not indexes.
  • Enumerate gives both index and value without manual indexing mistakes.
Key Takeaway

Avoid recomputing invariant values inside a loop. Prefer direct iteration and enumerate to reduce work and errors.
