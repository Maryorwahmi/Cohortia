Module 6 › Chapter 5.5 › Prefer built-ins over manual loops
Manual sum (slow) vs built-in
# Slow: manual sum
total = 0
for num in numbers:
  total = total + num

# Fast: built-in
total = sum(numbers)
Manual search vs membership
# Slow: manual search
found = False
for item in items:
  if item == target:
    found = True
    break

# Fast: membership test
found = target in items
When built-ins aren't enough
If you need a customized aggregation or a special side effect per item, a loop is necessary. But prefer built-ins for common tasks like sum, min, max, and membership when they express your intent.
Key Takeaway

Built-ins are cleaner and usually faster. Use them to reduce code and improve performance.
