Learning Objectives
These four skills form the checklist you'll use while refactoring loops.
01
Use break & return for early exit
Stop a loop as soon as the goal is reached to avoid extra work and reduce runtime.
Mnemonic: Stop when found.
VERIFIED COMPETENCY MILESTONE
02
Use continue to skip irrelevant items
Skip items like comments or empty lines instead of nesting code blocks inside an if-statement.
Mnemonic: Bypass the noise.
VERIFIED COMPETENCY MILESTONE
03
Avoid redundant calculations
Move repeated expressions outside the loop and iterate directly over sequences when possible.
Mnemonic: Compute once.
VERIFIED COMPETENCY MILESTONE
04
Understand basic time complexity
Distinguish constant, linear, and quadratic growth to choose the right approach for your data size.
Mnemonic: Scale matters.
