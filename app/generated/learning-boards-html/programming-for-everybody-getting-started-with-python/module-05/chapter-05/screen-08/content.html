Module 6 › Chapter 5.5 › Counting vs collecting
Counting example
count = 0
for item in items:
  if condition(item):
    count = count + 1
Use this when you only need the number of matches.
Collecting example
matches = []
for item in items:
  if condition(item):
    matches.append(item)
Use this when you later need the matching items.
Memory consideration
Collectors store items and can grow large. Counters use constant memory and are safe for big datasets when the items themselves are not needed.
Key Takeaway

Prefer the minimal structure that supports your next step. Count when you only need counts; collect when you need items.
