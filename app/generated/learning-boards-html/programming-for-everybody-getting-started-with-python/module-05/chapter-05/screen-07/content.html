Module 6 › Chapter 5.5 › The accumulator pattern
Standard accumulator
total = 0
for number in numbers:
  total = total + number
# total now holds the sum
This pattern generalizes to counts, string joins, and building lists.
Counter vs Collector
Use a counter when only the number of matches matters; use a collector list when you need the items themselves.
Analogy
Think of the accumulator as a backpack you carry while walking the list: each time you find something useful, you add it to the bag.
Key Takeaway

The accumulator pattern clarifies loop intent for sums, counts, and collections — initialize, update, then use.
