Module 6 › Chapter 5.5 › Objectives — Practice
Practice exercises
  • Find-first-negative: return as soon as you find a negative number. Measure number of iterations on sample lists.
  • Skip comments: read lines and continue when a line starts with a comment character. Aim for flatter code.
  • Refactor repeated calls: move invariant calculations out of loops or use direct iteration over items.
  • Complexity check: run a simple loop and then a nested loop on increasing sizes to observe growth.
Success criteria
For each exercise, you should be able to explain why your change reduced work or improved clarity and to show a quick timing or iteration count that confirms it.
Mnemonic
Stop, Skip, Simplify, Summarize
Quick tip
When in doubt, write the simplest loop first, then ask if you can stop earlier, skip items, or use a built-in.
