Module 1 › Chapter 1.2 › Readable Syntax
Python example
for i in range(5):
    print(i)
This reads like a sentence: loop over a range, then print each value. No explicit types or braces are required.
C example
for (int i = 0; i < 5; i++) {
    printf("%d
", i);
}
C requires declarations and braces which increase visual elements that a new learner must parse. That can slow comprehension initially.
Concrete exercise
Type both loops and say aloud what each line does. Notice the extra punctuation in C versus the clearer flow in Python.
Misconception
Indentation is fragile only if you mix tabs and spaces. Use a consistent editor setting to avoid this issue.
Key Takeaway

Python's syntax reduces boilerplate so learners focus on logic rather than punctuation.
