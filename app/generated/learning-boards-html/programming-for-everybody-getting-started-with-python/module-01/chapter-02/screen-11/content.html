Module 1 › Chapter 1.2 › Python 2 vs 3
Key differences
  • • Text and Unicode handling improved in Python 3.
  • • Division semantics changed to be more intuitive in Python 3.
  • • Many modern libraries support only Python 3.
Practical advice
Always choose Python 3 for new projects and learning. If you find older code, look for notes about version compatibility before running it.
Misconception
Some think Python 2 is required for legacy systems; while true for a few old environments, modern development and libraries target Python 3.
Key Takeaway

Learn Python 3; it is the current, supported, and practical choice for beginners.
