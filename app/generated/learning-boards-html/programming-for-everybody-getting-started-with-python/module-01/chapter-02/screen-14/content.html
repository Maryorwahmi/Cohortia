Module 1 › Chapter 1.2 › Key Concepts
Origin
Guido van Rossum, 1991; a human-centered design intent symbolized by the name Python.
Zen of Python
Aphorisms like 'explicit is better than implicit' guide everyday code decisions.
Practical tools
REPL and standard library let you experiment quickly and build useful programs without extra setup.
Takeaway
Python's philosophy and tooling make it an excellent starting language. Focus on clarity, experiment often, and use Python 3.
