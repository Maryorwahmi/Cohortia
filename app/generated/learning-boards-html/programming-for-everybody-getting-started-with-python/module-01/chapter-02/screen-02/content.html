Module 1 › Chapter 1.2 › Learning Objectives
Bloom: Learn → Understand → Apply → Master
01
Describe Python's history
Identify Guido van Rossum, 1991, and the Monty Python naming origin.
Understanding the origin gives context to why Python emphasizes readability and developer happiness. This helps you remember its goals when you read or write code.
Verified Competency Milestone
02
Explain design philosophy
Summarize the Zen of Python: readability, explicitness, and simplicity.
Connecting aphorisms to code examples will help you adopt practices that reduce ambiguity and make debugging easier.
Verified Competency Milestone
03
Use the interactive interpreter
Run simple commands and observe immediate results to build confidence.
The REPL shortens the edit-run-debug loop so beginners learn by experimenting and observing consequences right away.
Verified Competency Milestone
04
Compare languages and versions
Contrast Python's syntax and learning curve with older languages and know why Python 3 is the standard.
Learning the differences helps avoid legacy pitfalls, and lets you explain why Python is a practical choice for many domains.
Verified Competency Milestone
