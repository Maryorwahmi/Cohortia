Module 1 › Chapter 1.2 › Learning Objectives
Bloom: Learn → Understand → Apply → Master
01
Perform interpreter tasks
Type print and arithmetic expressions and observe output.
Direct manipulation in the REPL teaches cause and effect, letting you test ideas quickly while learning syntax and behavior.
Verified Competency Milestone
02
Compare syntax
Explain how indentation replaces braces and why that improves readability.
Seeing both forms side-by-side helps you value consistent formatting and reduces visual clutter when reading code.
Verified Competency Milestone
03
Identify common mistakes
Know tab/space pitfalls and the need for explicit conversions.
Awareness of these errors makes debugging faster and prevents frustrating surprises for beginners.
Verified Competency Milestone
04
Explain libraries
Describe why 'batteries included' reduces setup for common tasks.
Knowing practical library examples helps you move quickly from toy code to real scripts that read files, fetch web pages, or handle dates.
Verified Competency Milestone
