Type each line and pause to read results. Notice how the REPL shows evaluation output immediately and preserves earlier definitions for later commands.
Learning notes
  • • Experiment: change a value and observe the result.
  • • Stateful: variables you define remain available until you exit.
  • • Move to scripts: once stable, save code to a file and run it as a script.
Common pitfall
Don't expect the REPL to automatically save your work; copy useful commands into a file to preserve progress.
Key Takeaway

Use the REPL to form quick hypotheses and build intuition before writing scripts.
