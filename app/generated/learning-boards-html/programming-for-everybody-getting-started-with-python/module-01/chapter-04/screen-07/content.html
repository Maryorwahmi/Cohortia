Architecture
Bytecode and Python Virtual Machine
Bytecode acts as an intermediate language that the PVM executes.
Source
Human-readable Python text you write.
Bytecode
A compact, intermediate representation produced by the interpreter.
PVM
Executes bytecode step by step, performing operations on values in memory.
Why this matters
Understanding these layers explains why parsing errors stop the run and why some runtime errors only appear during execution.
Example idea
Imagine translating a paragraph into short commands for a robot; bytecode is those short commands and the PVM is the robot following them.
Pro tip
You rarely need to view bytecode as a beginner, but knowing it exists prevents the misconception that Python skips compilation entirely.
