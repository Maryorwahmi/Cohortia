Core Concept
Statements and Lines
A statement is one instruction. The interpreter executes statements in sequence.
Definition
A statement is a single instruction that the interpreter executes, usually written on one line in Python.
Common mistake
Reordering assignments and uses leads to errors or wrong values. Always reason about what exists when a line runs.
Analogy
Think of a recipe: steps are followed in order. Skipping or reordering steps changes the result.
Key Takeaway

Order matters: read the program top to bottom and predict values at each step.

Example
print("Hello, world!")
name = "Alice"
print(name)
If you move the assignment above the first print, the first print still executes before the assignment. Predict before you run.
