Definition
Comments
Text that the interpreter ignores and humans use to explain intent.
Good practice
  • Explain why, not what.
  • Write clear, grammatical sentences.
  • Update comments when code changes.
Common mistake
Commenting every line or leaving outdated comments that contradict code.
Analogy
Comments are like footnotes that explain why a choice was made in a recipe.
Examples
# This is a helpful comment explaining a reason
# We subtract 1 because the API returns a 1-based count
count_from_api = get_count()
adjusted = count_from_api - 1  # adjust to zero-based index

# Bad comment: states the obvious
x = 5  # set x to five
Note how the first comment explains a rationale; the last comment repeats the line and is unnecessary.
