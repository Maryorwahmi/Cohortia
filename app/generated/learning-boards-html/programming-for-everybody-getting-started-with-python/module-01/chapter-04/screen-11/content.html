Core Concept
Variables and Memory
Names are bindings to values in memory. Changing a name later updates only that binding.
How assignment works
The interpreter evaluates the right-hand side, then assigns the resulting value to the name on the left.
Misconception
Variables are not containers that auto-update other variables; they are independent bindings unless you explicitly recompute relationships.
Key Takeaway

Remember: assignment takes a snapshot of a computed value at that moment.

Illustration
Imagine labels on boxes: when you print a label with a number, the label shows the number at that time. Changing the original object later does not change already printed labels.
Example
x = 10
y = x + 5  # y becomes 15
z = y * 2  # z becomes 30
x = x + 1  # x becomes 11, y and z unchanged
