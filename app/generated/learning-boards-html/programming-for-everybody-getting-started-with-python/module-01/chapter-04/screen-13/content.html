Beginner Debugging Checklist
A short routine you can follow whenever code doesn't work as expected.
1. Read the error message
It often tells you the line and the type of error.
2. Check for syntax issues
Missing quotes, parentheses, or incorrect indentation are common culprits.
3. Verify names and capitalization
Python is case-sensitive; ensure you spelled built-ins and variables correctly.
4. Hand trace values
Write down values after each line to find where results diverge from expectations.
5. Update comments and isolate changes
Keep comments accurate and make small edits to find the source of a bug.
Quick scenario
If a printed value is wrong, first hand-trace the lines that compute it. Often you'll find the incorrect operation or a missing recomputation.
Key Takeaway
A short checklist makes debugging predictable and much faster.
