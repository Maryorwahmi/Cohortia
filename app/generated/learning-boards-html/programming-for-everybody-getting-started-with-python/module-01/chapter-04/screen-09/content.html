Trace this program
Write down each variable's value after each line, then run the program to check.
# Trace this program
x = 10
y = x + 5
z = y * 2
print("z is", z)
x = x + 1
print("Now x is", x)
print("z is still", z)
Questions
  1. What is z after the fourth line?
  2. What is x after the fifth line?
  3. Why does z not change when x changes on line five?
Hint
When z is computed, it stores the result. Changing x later does not retroactively change z.
Scenario
Imagine z is a printed label. Changing the original carton later does not change already printed labels. You must recompute z to update it.
Try this
After tracing, run the program and compare outputs. Notice the printed lines reflect the state when the print happened.
