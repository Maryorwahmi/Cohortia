Common Mistake
Case Sensitivity & Name Errors
Python treats names with different capitalization as different identifiers.
Runtime NameError
Occurs when Python cannot find a definition for a referenced name at runtime. Check spelling and case first.
Quick fix
Use the correct lowercase built-in names or define your own variable using the intended capitalization.
Example scenario
A learner types Print instead of the built-in print. The parser accepts the line, but at runtime Python raises an error because Print is not defined. The remedy is to correct the capitalization.
Why this matters
Reading error messages and checking simple things like capitalization is often the fastest path to a quick fix.
