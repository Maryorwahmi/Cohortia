Process Example
Trace: Rectangle Area
Follow each assignment and write the state after the line runs.
Code to trace
# A simple program to calculate the area of a rectangle
width = 5     # width variable is assigned
height = 3    # height variable is assigned
area = width * height   # area computed
print("The area is", area)   # output
Trace notes
  1. Line 1: comment — ignored.
  2. Line 2: width becomes 5.
  3. Line 3: height becomes 3.
  4. Line 4: area becomes 15.
  5. Line 5: prints text and 15.
Why tracing helps
It builds an expectation so when output differs you can spot which line produced the wrong value.
Concrete scenario
If someone later changes width to a new value and forgets to recompute area, the printed area will still show the old computed value. Tracing helps you find that mismatch.
Check your understanding
What is the value of area after the multiplication line? What happens if width changes after that line?
