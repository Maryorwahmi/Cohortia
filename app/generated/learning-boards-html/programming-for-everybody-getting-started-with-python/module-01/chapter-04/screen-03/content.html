Practice activities
Trace by hand
Write the value of each variable after every line. Then run code to confirm.
Introduce a syntax error
Create a missing quote or parenthesis to observe parsing errors and messages.
Review comments
Ask whether each comment explains why a choice was made, not what the code literally does.
Compare outputs
Predict output before running, then compare to the actual result and note differences.
Common misconceptions
  • Comments change how code runs — false; they are ignored by the interpreter.
  • Changing a variable later updates earlier results — false; previous values remain unless recomputed.
