Process Flow
Python Interpreter Stages
Read → Parse → Compile → Execute. Each stage has a distinct role.
Read
Load script text from file into memory for parsing.
Parse
Check syntax and structure. Syntax errors are reported here and stop execution.
Compile
Translate to bytecode — an intermediate, efficient representation.
Execute
The Python virtual machine runs bytecode instruction by instruction.
Misconception check
Python does perform a compile step to bytecode; this is part of running the program and is not a manual compilation step you do yourself.
Visual Steps
Step 1: Read
Interpreter loads your script text.
Step 2: Parse
Syntax errors are detected here.
Step 3: Compile
Source becomes bytecode for the virtual machine.
Step 4: Execute
Bytecode runs on the Python virtual machine.
Knowing where an error appears tells you whether it is a syntax issue or a runtime/logic issue.
