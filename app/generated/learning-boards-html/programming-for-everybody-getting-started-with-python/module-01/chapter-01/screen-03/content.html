How we'll measure success

Practical, observable tasks that show you understand each objective.

Demonstrate: Explain a program
  • Give a daily example and say why it is a program.
  • Point out the instructions and the data it acts on.
VERIFIED COMPETENCY MILESTONE
Apply: Name automations
  • List two tasks you could automate and the benefit.
  • Estimate time saved or error reduction.
VERIFIED COMPETENCY MILESTONE
Explain: RAM vs Storage

Describe why RAM is temporary and fast while storage is permanent and slower, and give an example when both are used.

VERIFIED COMPETENCY MILESTONE
Practice: Write an algorithm

Create a step-by-step procedure in plain English for a simple task and have a partner follow it literally to find gaps.
