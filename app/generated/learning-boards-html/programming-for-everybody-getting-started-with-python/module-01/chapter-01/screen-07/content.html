Definition CPU — the literal worker

What the CPU does and why its literalness matters

The CPU performs the operations your program specifies: arithmetic, comparisons, and instruction control. It is extremely fast but requires exact instructions.
Concrete example
If you ask the CPU to sum numbers, it will do that reliably. If you ask it to divide by zero, it will cause an error because the instruction is undefined.
Why optimize
Fewer CPU steps mean faster programs. Clear algorithms reduce unnecessary work and speed up results.
Analogy
Think of the CPU as a worker who follows each instruction exactly as written — precise directions produce correct output.
Common mistake
Assuming the CPU will make smart choices for ambiguous instructions; it will not.
Key Takeaway
Write precise, testable instructions so the CPU can do useful work without errors.
