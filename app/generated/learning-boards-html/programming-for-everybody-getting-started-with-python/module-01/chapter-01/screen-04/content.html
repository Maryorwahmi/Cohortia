Core Concept What is a computer program?

A set of instructions written so a computer can follow them exactly

Core idea

Programs are literal. They run step-by-step and do not infer missing information. That makes them reliable and unforgiving.

Why it matters
  • Automate repetitive work reliably.
  • Reduce human error for large or precise tasks.
Common misconception
A program does not 'understand' intent. It manipulates data using explicit steps you provide.
Example: Renaming many files
Imagine you must rename 1,000 photos with a consistent prefix. A program can iterate over each filename, build the new name, and save it. The human alternative is slow and error-prone.
# Pseudocode example (plain steps)
for each file in folder:
  read file name
  create new name with prefix
  rename file to new name
Key Takeaway
Programs turn repeatable human actions into exact, fast machine steps.
