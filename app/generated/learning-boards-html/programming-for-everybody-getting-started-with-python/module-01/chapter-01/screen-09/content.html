Core Concept Input and Output (I/O)

How programs receive data and show results

Before coding, list the inputs your program needs and the outputs it should produce. That focus reduces guesswork and sets clear success criteria.
Example
A calculator app: inputs are numbers and operations; output is the computed result displayed on screen.
Design tip
Treat inputs as potentially invalid. Plan checks so your program handles unexpected data gracefully.
Considerations
Are inputs required or optional? Should output be saved to storage or shown temporarily?
Common mistake
Ignoring input validation and assuming perfect data will lead to runtime errors or wrong results.
Key Takeaway
Define inputs and outputs clearly to make the algorithm concrete and testable.
