Process Flow Input → Process → Output

The fundamental cycle of computing

Input
Process
Output
Example sequence: open a spreadsheet file (input from storage), load rows into memory, run calculations on each row in the CPU, and then save the summary back to a file or display it on screen (output).
# Pseudocode
file = open('data.csv')
rows = read_rows(file)   # input -> memory
summary = compute_summary(rows)  # CPU processes in memory
write_file('summary.txt', summary)  # output to storage
Why it matters
This cycle shows where performance matters and why you move data carefully between storage and memory.
Common misconception
Confusing storage and memory leads to wrong expectations about speed and data persistence.
Key Takeaway
Design programs by following the input-process-output pattern and be explicit about where data lives.
