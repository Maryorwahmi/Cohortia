Why We Program: The Power of Code

Understand what a computer program is, why programming is useful, and the hardware and algorithm ideas that make computing possible.

Concept Map
Input → Process → Output
Input
Keyboard, files, sensors — the data a program receives.
Process
CPU and memory execute precise instructions — the algorithm.
Output
Screen, files, and actuators show results or save data.
Algorithm
A precise recipe that the computer can follow step-by-step.
Explore Key Topics

Three important ideas you'll study in this chapter and how they show up in real work.

What is Code?
Code is a set of instructions written so a computer can act predictably and quickly.
Hardware Basics
CPU, memory, storage and I/O are the parts that run and store programs and data.
Algorithms
An algorithm is a detailed recipe; precision matters because computers cannot infer missing steps.
