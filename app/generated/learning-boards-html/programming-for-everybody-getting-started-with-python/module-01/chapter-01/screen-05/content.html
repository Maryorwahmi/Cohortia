Comparison Programming vs human instructions

Why algorithms for computers must be more precise than recipes for people

Human recipe example
  • “Spread peanut butter on bread until it looks right.”
  • Cook until golden.
A human fills in exact pressure, amount, and timing from experience.
Computer algorithm needs
  • Exact measures: grams, seconds, coordinates for grasping.
  • Clear condition checks: if jar is closed then turn clockwise 6 rotations.
This makes the algorithm exhaustive and testable for a machine.
Example
Write an algorithm to brush your teeth and hand it to a partner to find missing steps.
Common mistake
Assuming an instruction like “do the obvious” is sufficient for a computer.
Key Takeaway
Remove ambiguity: make every step explicit when designing algorithms for machines.
