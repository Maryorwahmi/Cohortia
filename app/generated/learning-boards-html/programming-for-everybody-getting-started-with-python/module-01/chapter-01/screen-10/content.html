Core Concept What is an algorithm?

A precise, step-by-step procedure for solving a problem

Write algorithms in plain language first. Clarity reveals ambiguity and helps you spot missing steps before translating to code.
Peanut butter algorithm (plain English)
  1. Place two slices of bread on a plate.
  2. Open the jar of peanut butter.
  3. Use a knife to spread peanut butter on one slice.
  4. Put the slices together.
  5. Cut in half if desired.
Practice
Write an algorithm for making tea or brushing teeth, then have someone follow it literally to find gaps.
Misconception
Assuming a high-level description is enough for a computer. You must add low-level actionable steps.
Key Takeaway
Start with plain-English algorithms to reveal ambiguity before coding.
