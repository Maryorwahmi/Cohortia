Windows installation steps
A clear sequence to make Python available from the Command Prompt.
  1. Download the latest Python 3 installer for Windows.
  2. Run the installer and check Add Python to PATH.
  3. Choose Install Now and complete the setup.
  4. Open Command Prompt and run python --version to verify.
Watch out
Not checking Add Python to PATH prevents the terminal from finding Python and causes the "not recognized" error.
Windows example
Open Command Prompt and run:
python --version
Expected: A Python 3 version string confirming the installation.
Quick fix
If the version command fails, rerun installer and enable PATH, or add Python to PATH in system environment variables.
