Module 1 › Chapter 1.3 › Demonstrations
How to demonstrate each objective
Verify Installation
Run the version command for your OS. Windows typically uses python --version; macOS/Linux commonly uses python3 --version. Expect a Python 3 version string.
Interpreter Check
Open the prompt, try a calculation, call the print function with a short string, and confirm outputs appear immediately.
Write a Script
Save a plain text file named myfirstprogram.py that prints several lines, then run it from the terminal to verify results.
Explain Modes
Describe when to use interactive mode for exploration and script mode for programs you want to keep and run again.
