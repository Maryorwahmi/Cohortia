Learning Objectives
Bloom targets: Learn → Understand → Apply → Master
Learn
Install and verify Python on your system.
Understand
How interactive and script modes differ and when to use each.
Apply
Write a .py file and run it from the terminal.
Master
Fix common installation mistakes and use an online playground if needed.
