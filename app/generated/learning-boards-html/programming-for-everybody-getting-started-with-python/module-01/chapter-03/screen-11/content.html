Interactive mode vs. script mode
Interactive mode
Type single expressions or statements and see immediate results at the prompt.
  • Best for experiments and debugging.
  • Immediate feedback but not saved by default.
  • Use python or python3 to open the prompt.
Script mode
Write a .py file, save it, and run the whole file at once from the terminal.
  • Best for programs you want to keep and reuse.
  • Allows editing, versioning, and sharing as files.
  • Run with python myfile.py or python3 myfile.py.
Try this
Type three lines in the interpreter and then save and run the same three lines in a .py file to compare behaviors and persistence.
