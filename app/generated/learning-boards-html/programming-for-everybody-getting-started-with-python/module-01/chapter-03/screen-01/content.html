Installing Python and Writing Your First Program
Quickly get Python 3 on your computer, test the interpreter, and create a saved script file you can run from the terminal.

In this lesson you’ll learn how to install Python 3 on each major operating system, how to use the interactive prompt to test ideas, and how to write and run a .py file. This foundation makes all future programming work possible.
