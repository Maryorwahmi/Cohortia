Installing Python 3
Download and install Python 3 and verify with the version command for your OS so your terminal can run Python.
Interactive Interpreter
Use the prompt to quickly try expressions and the print function. It’s transient and best for testing ideas.
Script Files (.py)
Save programs in plain text with a .py extension and run them from the terminal for repeatable results.
Key Takeaway

Confirm installation, practice in the interpreter, then save working code as .py files and run them from the terminal.
