Common installation mistakes and the Python Playground
PATH not set
If the terminal reports Python is not recognized, rerun the installer and check Add Python to PATH or update environment variables manually.
Wrong extension
Saving files as .txt prevents Python from recognizing them. Use Save As and type .py explicitly when saving.
Word processor formatting
Word processors add invisible characters that break code. Use plain text editors only.
Python 2 vs 3
If python invokes Python 2, use python3 to run Python 3, or update PATH to prefer Python 3.
Python Playground
Use the browser-based Playground when you cannot install locally. It replicates the interpreter for learning purposes, but it does not replace learning how to install and run local scripts.
Quick checks
After fixes, run the version command and a one-line print program to confirm success.
Hands-on reminder
If you cannot install Python, complete the exercises using the Playground and then repeat them locally when you have installation access.
