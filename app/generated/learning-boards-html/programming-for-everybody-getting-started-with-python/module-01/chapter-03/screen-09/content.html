Writing your first Python script
Create myfirstprogram.py using a plain text editor and include several print statements.
Editor guidance
  • Use a plain text editor: VS Code, Notepad, or TextEdit in plain text mode.
  • Do not use a word processor like Word or Google Docs.
  • Save the file with a .py extension explicitly.
Example file: myfirstprogram.py
# myfirstprogram.py
print("Hello, world!")
print("I am learning Python.")
name = "Alice"
print("My name is", name)
Practical note
Save in a known folder and open a terminal there to run the script reliably.
