macOS installation and verification
Install Python 3 and use the python3 command in Terminal to avoid the older system Python.
Steps
  • Download the macOS installer for Python 3 and run the package.
  • Open Terminal and run python3 --version to confirm.
  • Use python3 to enter the interactive interpreter or run scripts.
Terminal demo
Run in Terminal:
python3 --version
python3
>>> 2 + 3 # immediate result
Misconception
Typing plain python may open an older system interpreter. Use python3 for the newly installed runtime.
