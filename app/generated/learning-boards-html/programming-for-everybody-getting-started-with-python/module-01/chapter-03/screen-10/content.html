Running a script from the terminal
Change to the script folder then execute the file with the system Python command.
Steps to run
  1. Open Command Prompt or Terminal and change directory to your script folder.
  2. Run: python myfirstprogram.py on Windows, or python3 myfirstprogram.py on macOS/Linux.
  3. Observe printed output displayed in the terminal.
Terminal example
C:\Users\You> cd python-sandbox
C:\Users\You\python-sandbox> python myfirstprogram.py
Hello, world!
I am learning Python.
My name is Alice

# macOS / Linux
$ cd ~/python-sandbox
$ python3 myfirstprogram.py
Common mistake
Running from the wrong directory causes file-not-found errors. Use cd to enter the script folder first.
