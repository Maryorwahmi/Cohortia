Install Python 3: overview
Prepare your environment and pick the right installer or package for your operating system.
Step 1 — Choose Python 3
Always select the latest Python 3 installer. Python 2 is obsolete and should not be used.
Step 2 — Windows: Add to PATH
Enable the installer option to add Python to PATH so you can run python from Command Prompt without extra configuration.
Step 3 — Decide where to save scripts
Create a folder you can find easily and navigate to it from the terminal before running scripts.
Quick verification workflow
After installation, open your terminal and run the appropriate version command to confirm Python 3 is available.
Windows: python --version
macOS / Linux: python3 --version
Common misconception
Assuming installer automatically configures terminal access. On Windows you may need to check Add to PATH during installation.
