Linux package manager installation
Check for an existing Python 3, otherwise install via your distribution package manager.
Common commands
Ubuntu/Debian: sudo apt-get install python3
Fedora: sudo dnf install python3
Verification and example
Run:
python3 --version
python3
>>> print("Hello!") # should print Hello!
Practical note
If python3 is present, prefer it in commands and scripts to ensure you use Python 3 features.
