Using the interactive interpreter
A quick feedback loop to test expressions and inspect variables.
Key behaviors
  • Immediate evaluation of expressions.
  • Useful for experiments and debugging small snippets.
  • Does not permanently save code; move working code into files when ready.
Interactive demo (visual)
>>> 2 + 3
5
>>> print("Hello!")
Hello!
>>> name = "Alice"
>>> print(name)
Alice
Misconception
Interactive mode keeps code safe. It does not; you must save code in a .py file for permanence.
