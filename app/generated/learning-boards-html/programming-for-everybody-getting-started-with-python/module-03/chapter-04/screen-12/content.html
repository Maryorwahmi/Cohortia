Architecture

Checklist for robust programs

  • Identify external operations that might fail.
  • Wrap risky calls in try and catch specific exceptions.
  • Use loops for validation and retries where appropriate.
  • Use else for success-only logic and finally/with for cleanup.
  • Provide clear messages; avoid hiding bugs.
Example integrated flow

Ask input → try conversion → except on failure → retry loop → on success print result → cleanup.

Concrete exercise

Build the robust division program from the chapter. Keep prompting until both inputs are numeric and the denominator is not zero. Print the result and exit cleanly.

# Core loop sketch
while True:
    try:
        a = float(input("Numerator: "))
        b = float(input("Denominator: "))
        print(a / b)
        break
    except ValueError:
        print("Invalid input. Enter numbers.")
    except ZeroDivisionError:
        print("Cannot divide by zero.")
Key Takeaway

Combine validation, specific catches, and cleanup to build reliable small programs.
