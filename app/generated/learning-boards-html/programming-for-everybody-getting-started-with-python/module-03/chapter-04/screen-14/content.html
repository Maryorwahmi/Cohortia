Module 4 › Chapter 3.4 › Key Concepts
Exception = runtime error
Errors like ValueError occur while a program runs and can be caught.
Catch specific exceptions
Handle known failures like ValueError or ZeroDivisionError instead of using bare except.
Use else and finally
else runs on success; finally runs always for cleanup, though with is preferred for files.
Summary

Handle predictable runtime errors with specific except blocks, validate input with loops, and ensure resources are cleaned up so programs remain usable and debuggable.
