Practice Objectives — Focused Work

Turn concepts into working, tested examples you can reuse.

Bloom: Apply → Master
01
Build a validation loop

Keep asking for numeric input and handle ValueError and ZeroDivisionError until data is valid. This reinforces retry patterns and user-friendly messages.

VERIFIED COMPETENCY MILESTONE
02
File-reading with specific catches

Ask for a filename and handle FileNotFoundError and PermissionError with distinct messages. Use with when possible and finally when demonstrating cleanup explicitly.

VERIFIED COMPETENCY MILESTONE
03
Practice else and finally

Use else to run code only when no exception occurred, and finally to always run cleanup code, reinforcing reliable resource handling.

VERIFIED COMPETENCY MILESTONE
04
Avoid hiding bugs

Learn when a bare except hides programming errors and why specific catches are safer for debugging and code health.

VERIFIED COMPETENCY MILESTONE
