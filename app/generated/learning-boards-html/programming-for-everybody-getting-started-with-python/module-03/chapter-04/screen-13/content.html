Hands-on Activity

Robust division calculator

Write the loop and exception handlers, then test user mistakes until the program behaves correctly.

while True:
    try:
        numerator = float(input("Enter the numerator: "))
        denominator = float(input("Enter the denominator: "))
        result = numerator / denominator
        print(f"Result: {result}")
        break
    except ValueError:
        print("Invalid input. Please enter numeric values.")
    except ZeroDivisionError:
        print("Cannot divide by zero. Please enter a non-zero denominator.")
Test case 1

Enter "abc" for numerator to trigger ValueError and verify the prompt repeats.

Test case 2

Enter denominator 0 to trigger ZeroDivisionError and check the denial message.

Test case 3

Enter valid numbers and confirm the loop exits and prints the correct result.

Common pitfalls
  • Placing break in the wrong place so success is not detected.
  • Catching too many exceptions and masking bugs.
  • Forgetting to convert input to numeric types.
Key Takeaway

Test the program with invalid and valid inputs until it behaves predictably for users.
