Module 4 › Chapter 3.4 › File handling exceptions
Definition

FileNotFoundError and PermissionError

Handle these exceptions to explain why a file read failed and how to fix it.

filename = input("Enter filename: ")
try:
    with open(filename, 'r') as file:
        first_line = file.readline()
        print(f"First line: {first_line.strip()}")
except FileNotFoundError:
    print(f"Error: The file \"{filename}\" does not exist.")
except PermissionError:
    print(f"Error: You do not have permission to read \"{filename}\".")
Practical tip

Use with where possible. If you show finally for demonstration, remind learners that with automates cleanup for files.

Example scenario

If the user types a wrong filename, FileNotFoundError informs them to check the path. If access is denied, PermissionError tells them to adjust permissions or choose another file.

Misconception

Don't use a generic error for all file failures. Different problems need different guidance and solutions.

Key Takeaway

Report file errors specifically to help users correct the problem quickly.
