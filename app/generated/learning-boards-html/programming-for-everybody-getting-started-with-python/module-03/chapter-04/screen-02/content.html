Learning Objectives

Master the fundamentals of handling exceptions and validating input.

Bloom: Learn → Understand → Apply → Master
01
Understand why programs crash

Learn to identify runtime sources of failure like invalid input or missing files and why they stop execution. This awareness lets you plan which operations need guards.

VERIFIED COMPETENCY MILESTONE
02
Use try and except to handle errors

Practice writing try blocks that run risky code and except blocks that recover or explain the problem to the user. Handling known exceptions keeps programs running smoothly.

VERIFIED COMPETENCY MILESTONE
03
Distinguish syntax errors from exceptions

Recognize that syntax errors are fixed before the program runs and cannot be caught, while exceptions happen during execution and can be handled.

VERIFIED COMPETENCY MILESTONE
04
Write input-validation loops

Build loops that keep asking for valid input and handle specific exceptions like ValueError or ZeroDivisionError to avoid crashes.

VERIFIED COMPETENCY MILESTONE
