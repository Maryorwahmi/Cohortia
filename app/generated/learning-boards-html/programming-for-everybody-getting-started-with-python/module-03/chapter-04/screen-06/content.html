Comparison

Specific except blocks

Handle known cases separately so you can give tailored recovery or messages.

try:
    x = int(input("Enter a number: "))
    y = int(input("Enter another number: "))
    print(x / y)
except ValueError:
    print("Please enter valid numbers.")
except ZeroDivisionError:
    print("You cannot divide by zero.")
Why this is better
  • Tells the user exactly what went wrong.
  • Prevents masking underlying bugs.
Comparison

Bare except

Catches everything, including bugs and unexpected system errors. Use only with caution.

try:
    # risky code
except:
    print("Something went wrong")
Misconceptions

A bare except is sometimes used to keep a program running, but it also hides programming errors you want to fix.

Pro tip

If you must catch all exceptions for logging, re-raise the exception after logging so bugs remain visible.
