Core Concept

try / except flow

Place risky operations in try, handle specific exceptions in except, and keep program execution predictable.

try:
    age = int(input("Enter your age: "))
    print(f"You are {age} years old.")
except ValueError:
    print("That is not a valid number. Please try again.")
Bulleted notes
  • try runs code; except runs if a matching exception occurs.
  • Only matching except blocks are executed.
  • Uncaught exceptions still crash the program.
Example scenario

A user types letters when asked for age. The except prints a helpful message and the program continues instead of terminating.

Common-mistake

Using a bare except swallows all exceptions, including programming errors you should fix. Prefer specific exception names.

Check your understanding
  1. What happens if int() raises TypeError here?
  2. Would a different except catch it?
Key Takeaway

Catch the exceptions you expect; let unexpected ones remain visible so they can be fixed.
