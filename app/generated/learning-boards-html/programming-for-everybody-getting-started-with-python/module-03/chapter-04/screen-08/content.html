Process Flow

Keep prompting until input is valid

Combine a while loop with try-except to validate input and handle known exceptions.

while True:
    try:
        numerator = float(input("Enter the numerator: "))
        denominator = float(input("Enter the denominator: "))
        result = numerator / denominator
        print(f"Result: {result}")
        break
    except ValueError:
        print("Invalid input. Please enter numeric values.")
    except ZeroDivisionError:
        print("Cannot divide by zero. Please enter a non-zero denominator.")
Example walkthrough

If the user types "abc" for numerator, the ValueError except runs and the loop repeats. If denominator is zero, ZeroDivisionError triggers and the loop repeats until both are valid and non-zero.

Why this pattern helps
  • Prevents program termination on expected user mistakes.
  • Gives clear, actionable messages to users.
  • Keeps control flow simple and explicit.
Key Takeaway

Use loops with specific except clauses to create robust interactive programs.
