Module 4 › Chapter 3.4 › What is an exception?
Definition

Exception: runtime error

A brief definition and examples of common exceptions that occur while a program runs.

Common exceptions
  • ValueError — invalid conversion like int("abc").
  • ZeroDivisionError — dividing by zero.
  • TypeError — wrong type for an operation.
  • NameError — unknown variable name.
  • IndexError — index out of range in a sequence.
Analogy

Think of exceptions as alarm signals that let your program switch from normal work to recovery or reporting.

Key Takeaway

Exceptions happen during execution and can be anticipated with try and except.

Concrete example
# Attempting to convert user text to an integer
s = "abc"
try:
    n = int(s)
    print("Converted:", n)
except ValueError:
    print("That is not a valid number.")
Misconception

Exceptions are not always bugs. Many reflect unpredictable input or missing resources and should be handled deliberately.

Key Takeaway

Treat exceptions as signals you can catch and recover from when appropriate.
