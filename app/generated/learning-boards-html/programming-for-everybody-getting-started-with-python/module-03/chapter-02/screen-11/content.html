Starter code
Copy this into a Python editor and run with different inputs to observe behavior.
number = int(input("Enter a number: "))

if number > 0:
    print("The number is positive.")
    if number % 2 == 0:
        print("It is even.")
    else:
        print("It is odd.")
else:
    if number < 0:
        print("The number is negative.")
    else:
        print("The number is zero.")
Trace examples
  • Input 7 → outer test True → prints positive, inner test 7 % 2 == 1 → prints odd.
  • Input -3 → outer test False, inner else checks < 0 True → prints negative. No parity check.
  • Input 0 → outer test False, inner else checks < 0 False → prints zero.
Key Takeaway

Dependent tests inside the positive branch only run when the positive condition holds. This limits unnecessary checks and clarifies logic.
