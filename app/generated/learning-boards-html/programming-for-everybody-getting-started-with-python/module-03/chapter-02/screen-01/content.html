The if Statement: Making Decisions
Use conditional tests to control program flow and learn the role of indentation in Python.
In this lesson

You will read and write if and else statements, trace which branch runs, practice nested decisions, and fix common syntax and indentation errors.

Why it matters

Conditionals let programs respond to input, branch logic, and implement rules. They are the first step toward making programs behave differently in different situations.

Explore Key Topics
Basic if
Evaluate a condition and run the indented block if true.
else
Provide the alternate path when the condition is false.
Indentation
Whitespace defines blocks; 4 spaces is the standard. Mixing tabs causes errors.

Condition
A boolean expression that evaluates to True or False, like age >= 18.
If Block
Indented lines run only when the condition is True. Indentation groups statements into the block.
Else Block
Runs when the condition is False. Else creates an alternate path for program flow.
Connecting lines show flow: condition leads to either the if block or the else block. Nested blocks add depth via deeper indentation.
