Module 3 › Chapter 3.2 › Tracing Conditional Execution
Trace example
Work through each test and list executed statements.
x = 10
y = 5

if x > y:
    print("x is greater")
    difference = x - y
    print(f"Difference: {difference}")
else:
    print("y is greater or equal")
    difference = y - x
    print(f"Difference: {difference}")
Concrete Trace
Evaluate x > y → 10 > 5 is True, so execute the if block: print the message, compute difference = 5, print difference. The else block is skipped.
Tracing checklist
  • Evaluate the condition to True or False.
  • Mark which statements run and which are skipped.
  • Compute any assignments that occur on the executed path.
  • Confirm final printed outputs based on the path you traced.
Key Takeaway

Tracing helps you predict outputs and find logic errors before running the program.
