Module 3 › Chapter 3.2 › Basic if Statement
Definition
A conditional that executes its indented block only when its boolean condition is true.
age = 20
if age >= 18:
    print("You are an adult.")
Concrete Example
With age set to 20, the condition is True so the print function runs once and displays the message. Change age to 16 and observe no output from this block.
Common misconception
Do not assume the block runs on False — it is skipped. Also, remember the colon at the end of the if line; missing it causes a syntax error.
Trace this code
Evaluate the condition step by step to decide what runs.
Trace walk-through
  • Set age = 20. Evaluate age >= 18 → 20 >= 18 is True.
  • Since condition is True, execute the indented print and display the message.
  • No else branch here, so program continues after the if block.
Key Takeaway

The if statement directs execution only when a condition is True; colon and consistent indentation are required.
