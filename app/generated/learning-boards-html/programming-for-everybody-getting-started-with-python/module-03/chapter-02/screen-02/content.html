Learning Objectives
Skills you will practice and why they matter
Learn → Understand → Apply → Master
01
Write an if statement
Compose a condition and an indented block that runs only when the condition is true. Example: test whether age is at least 18 to allow access.
Mnemonic: If the sign is true, walk the path.
VERIFIED COMPETENCY MILESTONE
02
Use else for alternatives
Provide the alternate code path when a condition is false, so the program always responds predictably.
Mnemonic: If not, then else.
VERIFIED COMPETENCY MILESTONE
03
Understand indentation
Learn that leading spaces define blocks in Python; inconsistent indentation raises an IndentationError.
Mnemonic: Indent to belong.
VERIFIED COMPETENCY MILESTONE
04
Trace conditional branches
Evaluate conditions mentally or on paper to determine which branch runs and what output is produced; practice with simple examples.
Mnemonic: Evaluate, then follow the lit path.
VERIFIED COMPETENCY MILESTONE
