Module 3 › Chapter 3.2 › Indentation and Code Blocks
Why indentation matters
Python uses indentation rather than braces to mark the start and end of blocks. Keep it consistent.
if age >= 18:
    print("You are an adult.")
    print("You can vote.")
print("This prints regardless.")
Concrete Example
The two indented prints are part of the if block and run only when the condition is True. The final print is outside the block and runs always.
Common error
Mixing tabs and spaces or inconsistent indentation raises IndentationError. Configure your editor to insert spaces.
Practical tips
  • Use four spaces per indentation level as a standard.
  • Enable visible whitespace or an editor setting to convert tabs to spaces.
  • Use pass as a placeholder for an empty block while you develop logic.
Key Takeaway

Indentation groups statements into blocks. Be consistent: it controls control flow and avoids errors.
