Key Concepts
Three compact reminders to carry forward
If executes on True
A condition controls whether the indented block runs.
Else for the False path
Else runs only when the if condition is False.
Indentation defines blocks
Use consistent spaces; mixing tabs and spaces triggers errors.
Final takeaway
Master these basics now and you’ll spend less time debugging and more time building correct, readable programs.
