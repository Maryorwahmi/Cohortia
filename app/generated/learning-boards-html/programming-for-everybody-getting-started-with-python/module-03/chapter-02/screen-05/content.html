Module 3 › Chapter 3.2 › The else Clause
One-sentence rule
else runs when the if condition is False and requires a colon and an indented block.
age = 16
if age >= 18:
    print("You are an adult.")
else:
    print("You are a minor.")
Concrete Example
With age = 16, the initial condition is False so Python executes the else block and prints the minor message.
Misconception
Else is not a conditional and should not have a condition. It only pairs with a previous if and runs when that if fails.
Trace and compare
Decide which branch runs by evaluating the if test first.
Trace steps
  • Evaluate age >= 18 with the current value.
  • If True, run the if block; skip the else block entirely.
  • If False, run the else block; the if block is skipped.
Key Takeaway

Else ensures your program handles the False case explicitly, producing predictable alternative behavior.
