Module 3 › Chapter 3.2 › If/Else Structure
Canonical structure
Follow this template: if condition: indented statements; else: indented statements.
if condition:
    statement1
    statement2
else:
    statement3
    statement4

# placeholder example
if some_condition:
    pass  # TODO implement later
Concrete tip
Use pass to keep the block syntactically valid while you plan the code to go inside it.
Common mistakes
  • Missing colon after the if or else line → SyntaxError.
  • Using = instead of == inside a condition → SyntaxError; you must use a comparison operator.
  • Empty blocks without pass → SyntaxError because a block must contain at least one statement.
Pro Tip

When diagnosing SyntaxError messages, check for a missing colon or an accidental assignment in a condition first.
