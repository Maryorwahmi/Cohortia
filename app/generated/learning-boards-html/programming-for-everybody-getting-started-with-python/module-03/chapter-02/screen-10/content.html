Module 3 › Chapter 3.2 › Independent ifs vs Exclusive
Independent ifs (multiple true)
Each if is evaluated separately; more than one may run.
score = 85

if score >= 90:
    print("A")
if score >= 80:
    print("B")
if score >= 70:
    print("C")
With score 85 both the 80 and 70 checks are True, so this prints B and C. That may be unintended.
Exclusive branches (use elif)
An if/elif/else chain ensures only the first matching branch runs; see the next chapter for details.
Why it matters

Choosing independent ifs when you mean exclusive branches can cause duplicate messages, wrong logic, and confusing output for users.

For now, recognize the pattern and avoid stacking independent conditions when only one branch should happen.
