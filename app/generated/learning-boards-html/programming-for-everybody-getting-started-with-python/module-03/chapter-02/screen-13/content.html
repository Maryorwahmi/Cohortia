Prompt 1 — Trace
What prints for these values?
# Program
x = 5
y = 10
if x > y:
    print('A')
else:
    print('B')
Trace: 5 > 10 is False, so the else branch prints B. Change x to 15 and trace: 15 > 10 is True, so A prints.
Prompt 2 — Find the error
What is wrong and how does Python report it?
# Broken line
if x == 5 print('x is 5')
Error: missing colon after the condition. Python raises a SyntaxError like "expected ':'". Fix by adding the colon: if x == 5: print('x is 5').
