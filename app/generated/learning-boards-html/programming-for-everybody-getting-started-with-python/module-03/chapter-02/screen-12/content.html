Module 3 › Chapter 3.2 › Common Mistakes
Missing colon
If you forget the colon after the if line Python raises a SyntaxError like "expected ':'". Check the line ending first.
Example mistake
if x == 5 print("x is 5") <-- missing colon causes a SyntaxError and prevents the program from running.
Indentation errors
Inconsistent indentation or mixing tabs and spaces will raise an IndentationError. Fix your editor settings to use spaces consistently.
Assignment vs comparison
Using = instead of == in a condition produces a SyntaxError because assignment is not allowed in that context.
Practical debug flow
When you see an error, read the message, check the indicated line and the previous line for a missing colon or unmatched indentation. If an assignment was used in a condition, correct it to a comparison. Use pass for empty blocks while developing. Repeat until the interpreter runs the program successfully.
