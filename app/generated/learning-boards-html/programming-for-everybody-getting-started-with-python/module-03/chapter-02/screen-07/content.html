Nested example
An inner test runs only when its outer test succeeds.
age = 20
has_id = True

if age >= 18:
    if has_id:
        print("You may enter.")
    else:
        print("You need an ID.")
else:
    print("You are too young.")
Concrete walk-through
With age 20 and has_id True, outer test is True, inner test is True, so the program prints the enter message. Else blocks are used for both the inner and outer tests to clarify alternatives.
When to avoid deep nesting
Too many nested levels reduce readability and increase chance of indentation errors.
  • Trace outer conditions first; the inner code is unreachable until outer tests pass.
  • If you see three or more nested levels, consider flattening the logic or using separate functions.
  • Elif statements (next chapter) often replace nested ifs for mutually exclusive branches.
Key Takeaway

Use nested ifs for dependent tests, but keep nesting shallow and readable.
