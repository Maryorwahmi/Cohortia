Comparison
Mutually exclusive vs independent
Decide whether multiple labels can apply or whether only one should.
Independent if statements
Each condition is evaluated; multiple blocks may run. Use when several labels are valid simultaneously.
If-elif-else chains
Evaluation stops at the first true condition, giving a single result. Use for single-choice classification.
Misconception
Switching independent ifs to elifs without considering logic can silently remove needed labels.
Key Takeaway

Pick if-elif-else for exactly-one decisions; use independent ifs when multiple truths are acceptable.

Examples
Independent example
# Independent: multiple labels may apply
if age >= 18:
  print("Adult")
if age >= 65:
  print("Senior")  # both may print for age 70
Mutually exclusive example
# Mutually exclusive: at most one prints
if age >= 65:
  print("Senior")
elif age >= 18:
  print("Adult")
else:
  print("Minor")
