Code Walkthrough
Using elif without else
Decide whether silence or a fallback is needed and initialize state accordingly.
When to omit else
If it's acceptable that no branch runs or another mechanism handles defaults, you can leave else out.
Defensive pattern
Initialize a default value before the chain to avoid undefined variables if no branch runs.
Key Takeaway

Use else when a fallback is required; otherwise initialize defaults so later code remains safe.

Examples
No else example
x = 10
if x > 20:
  print("Big")
elif x > 15:
  print("Medium")
# Nothing prints because both conditions are false
Safe with default
default = "Unknown"
value = default
if x > 20:
  value = "Big"
elif x > 15:
  value = "Medium"
print(value)  # Always prints a defined value
