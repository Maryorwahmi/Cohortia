Assessment Idea
Independent ifs vs if-elif-else
Ask for explanation, a buggy example, and the corrected chain.
What to ask
Explain the difference and show a code example where independent ifs produce multiple outputs.
Expected answer
State that if-elif-else stops after the first true condition; provide buggy independent ifs and a fixed chain.
Key Takeaway

An assessment that mixes explanation and corrected code ensures students grasp both the concept and the practical fix.
