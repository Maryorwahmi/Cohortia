Practical Example
BMI classifier
A clear, concise chain for BMI categories that avoids repeated lower bounds.
Testing tip
Include boundary tests such as 18.5 and 25 to confirm category assignments at thresholds.
Misconception
You do not need explicit lower bounds in each elif; earlier falses provide them.
Code
bmi = float(input("Enter your BMI: "))

if bmi < 18.5:
  category = "Underweight"
elif bmi < 25:
  category = "Normal weight"
elif bmi < 30:
  category = "Overweight"
else:
  category = "Obese"

print(f"BMI category: {category}")
Notice how the second elif simply checks < 25 because the first check guaranteed bmi >= 18.5 when reached.
