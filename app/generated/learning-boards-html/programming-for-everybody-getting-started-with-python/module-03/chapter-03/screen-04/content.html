Core Concept
Basic if-elif-else structure
Execution flows in order. The first true condition runs and the rest are skipped.
Explanation
  • Python checks conditions from the top of the chain down.
  • When the first True is found, its block executes and evaluation stops.
  • Use else to handle any remaining unexpected inputs.
  • Later elif conditions can assume earlier ones were false, so they can be simpler.
Example
Grade classification: check highest ranges first so specific grades are not hidden by broader conditions.
Common mistake
Putting a broad condition first can cause specific cases to never run.
Key Takeaway

If-elif-else gives a single chosen outcome. Order your tests so the most specific or highest-value checks appear first.
