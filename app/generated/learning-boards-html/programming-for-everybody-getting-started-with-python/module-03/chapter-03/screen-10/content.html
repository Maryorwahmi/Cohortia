Hands-on Activity
Month → Season
Map month numbers 1–12 to seasons and catch invalid input with else.
Test values
Run with months 1, 4, 7, 10, and 13 to verify expected outputs and that invalid input is handled.
Grouping tip
Use or-conditions or membership checks to group month numbers for each season.
Starter code
month = int(input("Enter a month number (1-12): "))

if month == 12 or month == 1 or month == 2:
  season = "Winter"
elif month == 3 or month == 4 or month == 5:
  season = "Spring"
elif month == 6 or month == 7 or month == 8:
  season = "Summer"
elif month == 9 or month == 10 or month == 11:
  season = "Fall"
else:
  season = "Invalid month"

print(f"Season: {season}")
Try both explicit ORs and a membership check like if month in (12,1,2) for readability once you're comfortable.
