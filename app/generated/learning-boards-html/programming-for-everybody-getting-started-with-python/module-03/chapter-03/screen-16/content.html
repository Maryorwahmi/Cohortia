What to Remember
Three compact reminders and a guiding question for design.
1. Specific first
Order your tests from most specific to most general.
2. Mutually exclusive?
If only one label should apply use elif; otherwise use separate ifs.
3. Test edges
Always include boundary and invalid inputs in your tests.
Closing question
Can any input match more than one condition? Use that answer to choose your conditional style.
