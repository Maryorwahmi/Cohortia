Concept

When non-Boolean values act like True or False

Numbers
0 is False; any other number is True. Use bool(value) to check.
Strings
Empty string "" is False; non-empty strings are True.
Collections
Empty lists, tuples, sets, and dicts are False; non-empty are True.
None
None is always False in Boolean contexts.
Example
name = ""
if name:
    print("Name is provided")
else:
    print("Name is empty")
# Output: Name is empty
Key Takeaway

Truthiness is convenient but can hide distinctions. Use explicit checks for clarity when you need to differentiate values.

Practice

Hands-on hint
