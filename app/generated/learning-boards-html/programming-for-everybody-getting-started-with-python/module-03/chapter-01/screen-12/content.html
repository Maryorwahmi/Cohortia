Module 3 › Chapter 3.1 › Key Concepts
Boolean type
True and False are Python keywords and form the bool type.
Comparison operators
Use ==, !=, <, >, <=, >= to compare values and get True/False.
Logical operators
and, or, not combine or invert Boolean expressions.
Short-circuit
Python may skip evaluating parts of an expression once the result is decided.
Truthiness
0, empty strings/collections, and None are considered False in conditions.
Safe comparisons
Avoid assignment in conditions and use epsilon for float comparisons.
Takeaway

These tools let your program make clear, safe decisions. Practice the milestone script to combine them.
