Module 3 › Chapter 3.1 › Expression Evaluation
Worked example

5 > 3 and (2 < 1 or 4 == 4) and not False

Step 1: Parentheses
2 < 1 is False. 4 == 4 is True. False or True → True.
Step 2: not
not False → True.
Step 3: Remaining and
5 > 3 → True. True and True and True → True. Final result is True.
Why this helps
Breaking complex expressions into small steps makes it easy to follow operator precedence and to spot where short-circuiting might skip evaluation in other examples.
Common misconception
Assuming and/or have equal precedence; use parentheses or stepwise evaluation to be sure.
Try this
Change one part of the expression to False and re-evaluate the steps to see where short-circuiting would kick in.
