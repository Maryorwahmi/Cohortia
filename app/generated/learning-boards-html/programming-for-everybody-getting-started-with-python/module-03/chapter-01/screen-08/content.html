Module 3 › Chapter 3.1 › Store Boolean Expressions
Pattern

Assign expressions to variables

age = int(input("Enter your age: "))
is_adult = age >= 18
has_permit_input = input("Do you have a driving permit? (yes/no): ")
has_permit = has_permit_input.lower() == "yes"
can_drive = is_adult and has_permit
print(f"Can drive legally: {can_drive}")
Benefit
Reduces duplication and clarifies intent when used in multiple places.
Misconception
Don't name variables ambiguously. Names that read as questions help readability.
Key Takeaway

Store conditions in descriptively named Booleans to simplify conditional logic and maintenance.

Scenario

Can the user drive?

This scenario shows collecting input, deriving Booleans, and combining them for a final decision.

Try this
Change the age threshold or permit logic in one place, and all dependent checks update automatically.
