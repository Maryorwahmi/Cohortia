Common mistakes

Assignment vs Comparison and floats

Assignment vs comparison
Remember: x = 5 assigns. x == 5 compares. Using = in a condition causes a syntax error in Python.
Floating-point equality
0.1 + 0.2 == 0.3 evaluates to False due to floating-point imprecision. Use a small epsilon check like abs(a - b) < 0.0001 when needed.
Quick example
abs(0.1 + 0.2 - 0.3) < 0.0001  # True when treated with epsilon
