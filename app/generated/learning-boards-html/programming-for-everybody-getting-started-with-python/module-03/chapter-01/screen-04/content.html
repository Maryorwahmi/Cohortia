Definition

The bool type and its meaning

A Boolean answers a single yes/no question and stores True or False. Naming matters for readability.

Code example
is_valid = True
has_error = False
print(type(is_valid))  # <class 'bool'>
Example
Use is_adult = age >= 18 to store a condition and reuse it in multiple checks.
Common misconception
Treating True as a string or expecting more than two Boolean states — a Boolean is strictly True or False.
Key Takeaway

Booleans are explicit truth values. Name them as questions to make conditionals readable and robust.

Analogy

Light switch analogy

Think of True as a light turned on and False as off. A Boolean answers a single yes/no question for your program.

Try this
Create variables named has_ticket or can_enter so your if statements read like plain English.
