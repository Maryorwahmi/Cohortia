Module 3 › Chapter 3.1 › Floating-point comparison
Issue

0.1 + 0.2 == 0.3 may be False

print(0.1 + 0.2 == 0.3)  # Often False
print(0.1 + 0.2)          # Shows small rounding difference

# Use epsilon to compare
abs(0.1 + 0.2 - 0.3) < 0.0001  # True if difference is tiny
Why it matters
In equality checks, floating-point representation can mislead comparisons. Using epsilon avoids brittle conditions.
Key Takeaway

Treat float equality as approximate. Use an absolute difference check when exact equality is not reliable.

Example walkthrough
Run the code that prints the raw sum and the epsilon result. Observe that while direct equality may fail, the epsilon comparison recognizes near equality in practice.
Practice
Try different epsilon values to understand sensitivity. Larger epsilon tolerates bigger differences but may hide real errors.
