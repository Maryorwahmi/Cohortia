Concept

Short-circuit evaluation explained

and short-circuit
If the left expression is False, the right expression is not evaluated because the whole and is False.
or short-circuit
If the left expression is True, the right expression is not evaluated because the whole or is True.
Practical pattern
# Only divide if divisor is not zero
if divisor != 0 and dividend / divisor > 2:
    print("Result is greater than 2")
In this pattern the division is safe because the divisor check runs first and prevents division by zero.
Misuse risk
If the skipped expression had side effects, those side effects won't occur. Avoid relying on side effects inside conditions.
Pro tip
Place safety checks first when using and to guarantee safe evaluation of later expressions.
