Practice Targets and Milestones

Skill checks
Declare booleans
Create True and False variables and confirm their type with the print function.
Compare values
Try equality and order comparisons until results read as True or False.
Combine conditions
Use and, or, not to express real checks such as age and permit.
Milestone Script
age = int(input("Enter your age: "))
is_adult = age >= 18
has_permit_input = input("Do you have a driving permit? (yes/no): ")
has_permit = has_permit_input.lower() == "yes"
can_drive = is_adult and has_permit
print(f"Can drive legally: {can_drive}")
