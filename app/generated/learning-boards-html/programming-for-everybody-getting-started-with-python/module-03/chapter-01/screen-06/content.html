and, or, not with examples

age = 25
has_id = True
print(age >= 18 and has_id)  # True

is_weekend = True
is_holiday = False
print(is_weekend or is_holiday)  # True

is_raining = False
print(not is_raining)  # True
Why it matters
Compound conditions let you capture real-world business logic compactly and avoid nested if statements.
Misconception
Don't assume both sides always run. Short-circuiting can skip evaluation of the second expression in many cases.
Key Takeaway

Use logical operators to combine conditions clearly, and rely on parentheses to make precedence explicit.

Analogy

Gates and switches

Think of and as a gate that needs both green lights, or as a gate that accepts any green light, and not as a flip that turns green to red and vice versa.

Check your understanding
What is the result of True and (False or True)? Answer: True. Evaluate inner parentheses first.
