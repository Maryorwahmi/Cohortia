Learning Objectives

Learn, Understand, Apply, Master

Bloom: Learn → Understand → Apply → Master
01
Explain Boolean values
Describe the bool type and the keywords True and False, and why they are not strings.
Mnemonic: Light switch — on is True, off is False
VERIFIED COMPETENCY MILESTONE
02
Use comparison operators
Write conditions with ==, !=, <, >, <=, >= and predict their Boolean results.
Mnemonic: Scales for equality, seesaws for order
VERIFIED COMPETENCY MILESTONE
03
Combine with and/or/not
Form compound conditions and reason about short-circuiting and negation in real checks.
Mnemonic: Gates — and needs both, or needs one
VERIFIED COMPETENCY MILESTONE
04
Understand truthiness
Know which non-Boolean values act as False and why explicit checks are often clearer for beginners.
Mnemonic: Empty means False
VERIFIED COMPETENCY MILESTONE
