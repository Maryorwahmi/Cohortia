Module 3 › Chapter 2.5 › Order of operations
Precedence list
  1. Parentheses
  2. Exponentiation (right-to-left)
  3. Unary operators (+, -, bitwise NOT)
  4. Multiplication, division, integer division, modulo
  5. Addition, subtraction
  6. Comparison operators
  7. Logical operators: not, and, or
How to use it

Scan a compound expression, circle the highest-precedence operations, evaluate mentally or with parentheses, then proceed step by step.

Examples
2 + 3 * 4           # 14 (multiplication first)
(2 + 3) * 4         # 20 (parentheses force add first)
2 ** 3 ** 2         # 512 (right-to-left: 2 ** (3 ** 2))
10 - 5 - 2          # 3 (left-to-right grouping)
Common misconception
Assuming exponentiation groups left-to-right. Remember it groups right-to-left unless parentheses change it.
Check your understanding
Predict the result of 10 / 2 * 5 using left-to-right rules for equal-precedence operators.
