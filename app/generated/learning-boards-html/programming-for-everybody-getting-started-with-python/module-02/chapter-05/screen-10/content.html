Module 3 › Chapter 2.5 › Trapezoid area
Concise form
base1 = 10
base2 = 15
height = 8

area = (base1 + base2) / 2 * height
print(f"Area of trapezoid: {area}")
This single-line formula is correct but nests operations. Parentheses clarify grouping in the one-line version.
Refactored for readability
average_base = (base1 + base2) / 2
area = average_base * height
print(f"Area of trapezoid: {area}")
The second version names the intermediate value, which helps readers and debuggers identify problems faster.
Takeaway
Prefer clear intermediate names for multi-step calculations unless brevity is essential.
