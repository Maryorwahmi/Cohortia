Module 3 › Chapter 2.5 › Discount & Tax
Starter code
original_price = 100.00
discount_percent = 20
tax_percent = 8

final_price = (original_price * (1 - discount_percent / 100)) * (1 + tax_percent / 100)
print(f"Final price: {final_price:.2f}")
This uses parentheses to group the discount calculation and tax application, ensuring correct order and float results for currency.
Refactor with named steps
discount_factor = 1 - discount_percent / 100
tax_factor = 1 + tax_percent / 100
final_price = original_price * discount_factor * tax_factor
print(f"Final price: {final_price:.2f}")
Naming intermediate factors clarifies intent and makes debugging easier if results differ from expectation.
