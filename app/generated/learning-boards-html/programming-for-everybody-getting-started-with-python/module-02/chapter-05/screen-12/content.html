Module 3 › Chapter 2.5 › Key Concepts
Expression
A code fragment that evaluates to a value.
Precedence
Parentheses, exponent, unary, multiplicative, additive, comparison, logical.
Associativity
Most operators left-to-right; exponentiation is right-to-left.
Summary takeaway

Predict evaluation, use parentheses for clarity, and break complex expressions into named steps to avoid bugs.
