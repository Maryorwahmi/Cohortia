Module 3 › Chapter 2.5 › What is an expression?
Definition

An expression is any code fragment that evaluates to a value. It can be a literal, a variable, a call to a function, or a combination using operators.

Examples
5 + 3               # evaluates to 8
x * 2               # depends on x's current value
len("hello")        # evaluates to 5
int("42") + 10      # evaluates to 52
Analogy

Think of an expression as an assembly line where inputs are transformed by operator machines into a single output value.

Key takeaway

Every expression produces a value the program can use immediately or store in a variable.

Quick walk-through
  • Expressions can be nested: int of "42" plus ten nests a conversion call inside an addition.
  • Right side of assignment is an expression whose result becomes the variable's value.
  • Expressions appear in tests, function arguments, and anywhere a value is needed.
Common misconception
Not everything is an expression: statements perform actions but may contain expressions. Distinguish the two when reasoning about code.
