Module 3 › Chapter 2.5 › Exponentiation
Example walk-through
2 ** 3 ** 2       # = 2 ** (3 ** 2) = 2 ** 9 = 512
(2 ** 3) ** 2     # = 8 ** 2 = 64
Right-to-left associativity means evaluate the right exponent grouping first. This is different from most arithmetic operators, which group left-to-right.
Misconception
Assuming exponentiation groups left-to-right leads to wrong predictions. Check grouping explicitly with parentheses when uncertain.
Try this
Evaluate both forms in a REPL and confirm the different numeric results. Reflect on how grouping changed what was computed first.
