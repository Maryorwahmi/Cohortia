Module 3 › Chapter 2.5 › Parentheses
Correctness example
# Without parentheses: correct but ambiguous
total = price * quantity + tax * quantity - discount

# With parentheses: clearer intent
total = (price * quantity) + (tax * quantity) - discount

Parentheses did not change the numeric result in this case, but they make grouping explicit. When parentheses are required they change the calculation order and the result.

Readability pattern
Break complex formulas into named intermediate values for clarity. Use parentheses to show grouping in one-line versions.
Takeaway
When in doubt, add parentheses. They protect intent and reduce reader mistakes.
Check
Rewrite the average formula as a single-line expression and as intermediate steps to compare clarity.
