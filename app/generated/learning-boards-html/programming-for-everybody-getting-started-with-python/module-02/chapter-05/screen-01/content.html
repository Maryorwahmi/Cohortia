Expressions as Assembly Lines

Think of operators as stations that transform inputs. The final value is the output of the last station that runs.

Duration: 8m • Live coding style
In this lesson
What an expression is and how precedence controls evaluation.
Coming up
Examples: exponentiation, mixed-type, and the discount-tax calculator.
Why it matters
Correct results, readable formulas, and fewer bugs when combining operators.
Starter examples
5 + 3 evaluates to 8. len("hello") evaluates to 5. Use these small expressions to build larger computations.
Quick reference
Precedence:Parentheses, Exponent, Unary, */%//, +-, Comparison, not/and/or
Key takeaway

An expression always produces a value. Parentheses change order; associativity determines grouping for operators like exponentiation.
