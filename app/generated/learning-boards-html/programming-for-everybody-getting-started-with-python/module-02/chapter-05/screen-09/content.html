Module 3 › Chapter 2.5 › Mixed-type & Division
Examples
5 + 3.0     # 8.0 (int + float => float)
10 / 2      # 5.0 (division always returns float)
10 // 2     # 5   (integer division returns int)
Decide whether you need the fractional result. For display, format to the needed decimal places instead of truncating early in calculations.
Practical pattern
Do calculations using floats if fractional precision matters. Only convert to integers at the moment when integer behavior is required.
Common mistake
Using integer division when you expected a float causes silent accuracy loss. Check operators carefully.
