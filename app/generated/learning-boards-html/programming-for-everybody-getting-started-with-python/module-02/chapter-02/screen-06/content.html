Operator table
+ addition — 5 + 3 = 8
- subtraction — 5 - 3 = 2
* multiplication — 5 * 3 = 15
/ division — 5 / 2 = 2.5 (float)
// integer division — 5 // 2 = 2
% modulo — 5 % 2 = 1
** exponent — 2 ** 3 = 8
Pro tip

If you mix ints and floats, results are floats. Predict type promotion when writing expressions.

Code play
print(5 + 3)   # 8
print(5 / 2)   # 2.5 (float)
print(5 // 2)  # 2 (floor division)
print(5 % 2)   # 1 (remainder)
print(2 ** 3)  # 8 (exponentiation)
# Mixed types
print(5 + 2.0) # 7.0 (int promoted to float)
Check your understanding
Predict the type and value for 7 // 2 and 7 / 2 before running the code.
Key Takeaway

Learn operator meanings and type promotion to avoid surprises in results and types.
