Gotcha
2 ** 3 ** 2 is 2 ** (3 ** 2) = 512 because exponentiation is evaluated right-to-left.
Examples to run
print(2 + 3 * 4)     # 14
print((2 + 3) * 4)   # 20
print(2 ** 3 ** 2)   # 512 (2 ** (3 ** 2))
print(2 ** (3 ** 2)) # same as above
Key Takeaway

When in doubt, add parentheses. Explicit grouping prevents unexpected evaluation order and reduces bugs.
