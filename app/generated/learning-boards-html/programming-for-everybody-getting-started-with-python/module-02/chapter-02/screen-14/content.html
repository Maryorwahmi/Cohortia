int() truncates
int(3.7) gives 3; int(-3.7) gives -3. Use round() for rounding.
Test small examples
Run a one-line example before using a numeric expression in larger code to confirm behavior.
Money: cents or Decimal
Avoid floats for financial totals; use integer cents or the decimal module for exact arithmetic.
Final Summary

Numbers are simple but precise thinking matters. Choose types intentionally, test examples, and convert explicitly to avoid surprises.
