Concept

True division vs. floor division

True division always returns a float. Floor division returns the integer floor of the quotient, which rounds down toward negative infinity.

Positive example: 5 / 2 = 2.5, 5 // 2 = 2
Negative example: -5 / 2 = -2.5, -5 // 2 = -3
Code and scenario
print(4 / 2)    # 2.0
print(5 // 2)   # 2
print(-5 // 2)  # -3 (floor toward negative infinity)

# Use case: convert minutes to hours and leftover minutes
total_minutes = 1000
hours = total_minutes // 60
minutes = total_minutes % 60
print(hours, "hours and", minutes, "minutes")
Common mistake

Assuming // truncates toward zero. Test negative operands or use int() explicitly if truncation toward zero is desired.
