Module 2 › Chapter 2.2 › Floating-point
Definition

Floats use IEEE 754 and are approximations

A float stores sign, mantissa, and exponent. That design gives range but cannot represent many decimal fractions exactly, which leads to tiny errors in some calculations.

Classic example
0.1 plus 0.2 produces 0.30000000000000004 due to binary approximation of decimal fractions.
When to avoid floats
  • Financial calculations requiring exact cents
  • Equality comparisons that expect exact decimal matches
Interactive example
price = 19.99
print("price * 3 =", price * 3)
print("0.1 + 0.2 =", 0.1 + 0.2)
# For exact money, use cents or the decimal module
price_cents = 1999
print("total cents:", price_cents * 3)
Practical tip

If you need exact cents, store integers (cents) or use the decimal module instead of floats.
