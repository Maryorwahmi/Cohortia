Behavior

int, float, and round

int() truncates toward zero. float() converts integers to floating-point. round() rounds to the nearest integer or desired decimal places.

Misconception
int(3.7) does not return 4; it returns 3. For rounding, use round instead of int.
Examples
print(int(3.7))    # 3 (truncates)
print(int(-3.7))   # -3 (toward zero)
print(float(5))    # 5.0
print(round(3.7))  # 4 (rounds to nearest)
When to convert
Convert explicitly when an operation requires a particular numeric type, for example when preparing data for display or for integer indexing.
Key Takeaway

Know what conversion functions do and pick the one that matches your intent: truncate, promote, or round.
