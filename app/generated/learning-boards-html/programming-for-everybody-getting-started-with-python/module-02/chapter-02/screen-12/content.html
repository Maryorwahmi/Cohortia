Problem

Floating-point surprises with money

Because many decimals are not exactly representable in binary, floats can produce tiny errors that matter in financial calculations.

Example
19.99 * 3 might print as 59.96999999999999997 instead of 59.97.
Solutions
# Use integer cents
price_cents = 1999
total_cents = price_cents * 3
print("Total cents:", total_cents)
print("Total dollars:", total_cents / 100)

# Or use Decimal for exact decimal arithmetic
from decimal import Decimal
price = Decimal('19.99')
print(price * 3)
Key Takeaway

Prefer integer cents or the decimal module for exact financial work. Test calculations to catch errors early.
