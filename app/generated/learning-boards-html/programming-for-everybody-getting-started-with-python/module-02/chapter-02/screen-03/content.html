Module 2 › Chapter 2.2 › Practice Plan

01 — Identify types

Assign example values, print them and check their behavior in expressions. This verifies whether a value behaves like a whole number or a measurement.

Try: set age = 25 and price = 19.99; observe operations and printed types.

02 — Operators

Predict and then run arithmetic expressions. Note when results are ints or floats and how mixing types changes results.

Try: 5 * 3, 5 / 2, 5 // 2, 5 % 2.

03 — Division checks

Compute hours and remaining minutes from total minutes using // and % to confirm the slicing behavior.

Try: 1000 minutes to hours and minutes.

04 — Precision experiments

Add 0.1 and 0.2 and observe the tiny representation error. Then store amounts as integer cents and recompute to get exact results for money.

Try: compare 19.99 times 3 as a float and 1999 times 3 as cents.
