Numeric Types: Integers and Floating-Point Numbers

Understand how Python stores whole numbers and decimal numbers, and how that affects arithmetic in your code.

Duration estimate: ~9 minutes
In this lesson
Integers, floats, operators, division types, modulo, and precision guidance for money.
Hands-on
Practice scripts: area, averages, even/odd, minutes to hours, and the 0.1+0.2 exploration.
Why it matters
Correct numeric representation prevents subtle bugs in finance, time, and indexing logic.
Coming up
We'll begin with types and examples, then move into operators, division behaviors, modulo, precedence, type conversion, and practical money handling.
Visual concept
Integers (exact)
Whole blocks that stack without gaps — used for counts and fixed units like cents.
Floats (approximate)
Measured values with fractional parts—stored with limited precision using IEEE 754.
Common pitfall
0.1 plus 0.2 equals 0.30000000000000004 because of binary approximations.
Explore Key Topics
Arithmetic operators
Add, subtract, multiply, divide, modulo and exponentiation behave predictably once you know types.
Division types
True division always returns a float; floor division truncates toward negative infinity.
Precision & money
Use integers for cents or the decimal module for exact financial calculations.
