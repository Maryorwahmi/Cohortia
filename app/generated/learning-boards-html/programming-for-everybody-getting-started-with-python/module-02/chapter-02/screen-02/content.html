01

Distinguish int and float

Identify whole numbers and decimal numbers in code and know when exactness is required. This matters when a tiny difference can break financial or indexing logic.

02

Use arithmetic operators

Apply +, -, *, /, //, %, and ** with confidence and predict their outcomes based on operand types. This skill is essential for calculations, loops, and indexing tasks.

Mnemonic: PEMDAS pocket guide

03

Understand // and %

Know that // performs floor division and % returns remainder. Negative values can flip expectation, so test examples with negatives.

Mnemonic: Slice and Scraps

04

Recognize float limits

Learn why floats are approximations, how that leads to results like 0.1 plus 0.2 not equaling 0.3 exactly, and when to use integers or decimal arithmetic.
