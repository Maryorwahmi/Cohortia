Module 2 › Chapter 2.2 › Key Concepts
Integer (int)
Whole, exact numbers; safe for counts and cents when stored as smallest units.
Floating-point (float)
Represents real numbers approximately using IEEE 754; some decimals cannot be exact.
Operators & types
/ returns float; // floors toward negative infinity; % returns remainder; ** is exponentiation.
Summary

Pick ints for exact units, avoid floats for money, use // and % to split whole parts and leftovers, and verify behavior with short examples.
