Why it matters

Remainder arithmetic for everyday tasks

Parity checks, cycling ranges, and digit extraction are all simple with modulo. It's a compact tool with many practical patterns.

Even/odd test: n % 2 == 0 means n is even.
Clock math: 14 % 12 = 2 gives 2 PM for 14:00.
Last digit: 123 % 10 = 3.
Code examples
n = 127
print("Is even?", n % 2 == 0)
print("14 % 12 =", 14 % 12)
print("123 % 10 =", 123 % 10)

# Combine // and % for time conversions
total_minutes = 1000
hours = total_minutes // 60
minutes = total_minutes % 60
print(total_minutes, "minutes =", hours, "hours and", minutes, "minutes")
Key Takeaway

Modulo is a small operator with big use: parity, cycles, and digit extraction are simple and reliable when combined with integer division.
