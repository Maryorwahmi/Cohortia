Module 2 › Chapter 2.1 › Constants and ALL_CAPS
Convention example
PI = 3.14159
MAX_USERS = 100
DEFAULT_TIMEOUT = 30
Place constants near the top of files or in a config module so they are easy to locate and update when necessary.
Caveat
Because Python will allow reassignment, the ALL_CAPS pattern depends on team discipline. Use comments or documentation to reinforce why a constant should not change.
Check
Try reassigning a constant name and notice that Python allows it; then restore the original value and note the importance of convention.
