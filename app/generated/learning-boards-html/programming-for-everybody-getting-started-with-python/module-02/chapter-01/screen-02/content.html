Learning Objectives

Build the vocabulary and hands-on skills to name, store, and update values in Python safely and readably.

01
Explain what a variable is
Describe variables as names that refer to values and explain the label-on-box analogy. This helps you reason about where data lives and how names point to it.
Mnemonic: label-on-box Venn — name vs value
Verified Competency Milestone
02
Write assignment statements
Use the assignment operator, spoken as equals, to bind names to values. Practice with simple numbers and strings to build fluency.
Mnemonic: arrow shows action — binds name to value
Verified Competency Milestone
03
Name variables correctly
Follow Python rules and conventions: letters, digits, underscores, no leading digits, case-sensitive, and use snake_case for readability.
Mnemonic: snake_case visual — underscores connect words
Verified Competency Milestone
04
Understand references and reassignment
Know that reassigning a name makes it refer to a new object, and that multiple names can refer to the same object for mutable types.
Mnemonic: tag moving along a shelf
Verified Competency Milestone
