Module 2 › Chapter 2.1 › What is a variable?
Label-on-box analogy

Variables are tags or names attached to values. The values live as objects in memory; variable names point to them so you can reuse or update references without handling raw memory addresses.

Concrete example
# bind name x to number five
x = 5
print(x)  # prints 5

# later, reassign x to a new value
x = 10
print(x)  # prints 10
Common misconception
A variable is not a container that mutates. Reassignment binds the name to a new object instead of modifying the previous object.
Key takeaway
Think labels and references. That mental model avoids many confusion points later.
