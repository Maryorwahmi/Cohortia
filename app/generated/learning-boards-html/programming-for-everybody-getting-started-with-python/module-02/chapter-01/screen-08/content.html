When to use short names
Use i, j, k for short loop counters or well-known mathematical variables like x and y in small, clear contexts.
ALL_CAPS for constants
Use uppercase names to signal that a value is intended as a constant, for example PI or MAX_USERS. Python will not enforce immutability, but this communicates intent to other programmers.
