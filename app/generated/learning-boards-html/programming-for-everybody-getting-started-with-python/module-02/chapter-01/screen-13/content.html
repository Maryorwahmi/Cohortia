# 2. temperature and reassignment
temperature = 20
print(temperature)
temperature = 25
print(temperature)

# 3. swap a and b
a, b = 10, 20
a, b = b, a
print(a, b)

# 4. invalid name examples
# 2nd_place = 5    # error
# class = "math"   # error (reserved word)
What to observe
  • Printed values reflect the current binding of each name.
  • Swapping with tuple unpacking exchanges values without a temp variable.
  • Invalid names and reserved words produce syntax errors you can read and learn from.
