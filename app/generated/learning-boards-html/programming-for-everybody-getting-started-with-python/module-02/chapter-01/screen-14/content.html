Error checklist
  • Do not start names with a digit: causes SyntaxError.
  • Avoid reserved words as names: these have special meaning.
  • Remember assignment is an action; left side must be a name.
  • Prefer descriptive names to single-letter identifiers unless conventional.
  • Be aware of shared references when mutating objects; copy if needed.
Quick fixes
Rename a variable, rerun the snippet, and check the interpreter error messages to learn the exact cause and location of the problem.
