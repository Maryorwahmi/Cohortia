Module 2 › Chapter 2.1 › Reassignment & dynamic typing
Step-by-step
  1. Assign a name to a value.
  2. Evaluate a new expression and bind the name to its result.
  3. Use print to confirm the updated binding.
Code
x = 5
print(x)
x = 10
print(x)
x = "Hello"
print(x)
Practical tips
  • Prefer stable types within a short block of code.
  • Use descriptive names to signal role changes (for example, count vs count_str).
  • Add comments when a variable's purpose will change mid-function.
