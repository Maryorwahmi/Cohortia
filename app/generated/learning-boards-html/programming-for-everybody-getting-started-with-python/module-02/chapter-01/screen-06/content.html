Module 2 › Chapter 2.1 › Assignment vs Equality
Side-by-side
Mathematics: equals asserts both sides are the same value. It is a statement to be proven or used in algebra.
Programming: assignment is an action that stores the result of the right-hand expression under the left-hand name.
Code example to try in interpreter: assign a variable, then update it using an expression involving the same variable to observe state change.
Concrete example
count = 5
count = count + 1
print(count)  # prints 6

# invalid in Python:
# 5 = count  -> SyntaxError
Misconception
Treating assignment like an algebraic equality leads to invalid code and logic errors. Remember: assignment changes program state.
