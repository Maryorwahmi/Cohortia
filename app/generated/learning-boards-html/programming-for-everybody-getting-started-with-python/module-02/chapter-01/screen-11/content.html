Module 2 › Chapter 2.1 › Multiple assignment
Examples
a, b, c = 1, 2, 3
print(a, b, c)  # prints 1 2 3

# swapping
x = 10
y = 20
x, y = y, x
print(x, y)  # prints 20 10
Python evaluates the right-hand side tuple first, then unpacks values into the left-hand names. This eliminates the need for a temporary variable when swapping.
When to prefer
  • Use for brief, readable swaps or parallel assignments.
  • Avoid using overly complex expressions on the right-hand side that harm readability.
