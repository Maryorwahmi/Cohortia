Variables and Assignment: Naming Values

Understand how names refer to data, how assignment works in Python, and the naming rules and conventions that make code readable.

Interactive 16:9 Masterclass
In this lesson
What is a variable?
A name that refers to a value stored in memory. It helps you reuse and update data.
Assignment vs equality
The assignment operator stores a value under a name; it is an action, not a math statement.
Naming rules & conventions
Letters, digits and underscore allowed; use snake_case and descriptive names.
Reassignment & references
Variables refer to objects. Reassigning moves the name to a new object.
