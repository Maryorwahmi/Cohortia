Module 2 › Chapter 2.1 › Variables as references
Example with a list
list_a = [1, 2, 3]
list_b = list_a
list_b.append(4)
print(list_a)  # prints [1, 2, 3, 4]
print(list_b)  # prints [1, 2, 3, 4]
This demonstrates that list_a and list_b refer to the same object. Mutating the object through one name is visible to the other name because they both point to the same memory object.
Contrast
If you need an independent copy, explicitly copy the object rather than assign the name. Assignment alone does not make a separate object.
Check
Assign a list to two names, mutate one, and confirm both show the change. Then make a copy and confirm independent mutation.
