Rules checklist
  • Allowed: letters, digits, underscore.
  • Not allowed: start with a digit — 2nd_place is invalid.
  • Case-sensitive: Name and name are different.
  • Cannot use reserved words like if, for, while, class, def, print.
Try this
city = "Atlanta"
temperature1 = 72
# invalid: 2nd_place = 5  -> SyntaxError
# invalid: class = "math"  -> SyntaxError
Why rules matter

Following naming rules prevents syntax errors and ensures the interpreter can parse your code. They also make your code portable and consistent with the wider Python community.
