Explain the action of assignment

Assignment evaluates the right-hand expression, creates or locates the object, and binds the left-hand name to that object. It is an action performed by the interpreter.

Interactive code example
x = 5
print(x)    # prints 5
x = x + 1   # read current x, add 1, assign back
print(x)    # prints 6
x = "done"
print(x)    # prints done
Common mistake
Writing a literal on the left, for example five equals x, causes a syntax error because literals are not valid assignment targets.
Notes and rules
  • Left side must be a valid name or writable target.
  • Right side is evaluated first, then bound to the name on the left.
  • Assignment is not equality; it describes an action the interpreter performs.
Check your understanding
Try assigning a name to different types and printing results. Notice how the name's referent changes with each assignment.
