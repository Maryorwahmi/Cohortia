Module 02 › Chapter 2.4 › Convert to Numbers
Process

Steps to convert and compute

1.
Prompt the user with a clear message including expected format and units.
2.
Convert immediately using integer conversion for whole numbers or floating conversion for decimals.
3.
Compute using the numeric variables and then format results for display.
Example
age = int(input('How old are you? '))
next_year = age + 1
print('Next year you will be', next_year)
Key Takeaway

Convert user text to the numeric type you need right after input to avoid mixing types later.

When to use float

Use floating conversion for measurements and currency where decimals happen, such as temperature and bill amounts.

Example: temperature
temperature = float(input('Enter the temperature in Celsius: '))
fahrenheit = temperature * 9 / 5 + 32
print(f'That is {fahrenheit} degrees Fahrenheit.')
Misconception
Converting later in code can hide errors. Convert early so the rest of the program works with numbers, not text.
