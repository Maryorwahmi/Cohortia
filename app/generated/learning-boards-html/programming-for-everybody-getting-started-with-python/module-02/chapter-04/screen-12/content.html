Common Mistake

Why adding numbers to input fails

Problem
age = input('How old are you? ') print(age + 5) # TypeError
Fix
age = int(input('How old are you? ')) print(age + 5) # works
Explain the fix by showing that the type changed from string to integer. This check builds debugging skills: inspecting types often reveals the mismatch causing the error.
