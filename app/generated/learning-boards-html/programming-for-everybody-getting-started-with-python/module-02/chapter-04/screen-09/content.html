Embedding expressions and formatting

item = 'apple'
price = 0.75
quantity = 4
print(f'You bought {quantity} {item}s for ${price * quantity:.2f}')
# Output: You bought 4 apples for $3.00
The specifier after a colon controls display. For two decimal places, use a dot and the number of decimals. The raw numeric value stays unchanged; only the printed representation is rounded for display.
Common confusion
Formatting does not alter the stored number. If you need a rounded value for calculation, explicitly round the number in a separate step.
