BMI Calculator

# BMI Calculator (without conditionals yet)
print('=== BMI Calculator ===')
weight = float(input('Enter your weight in kg: '))
height = float(input('Enter your height in meters: '))
bmi = weight / (height ** 2)
print(f'Your BMI is: {bmi:.2f}')
Try different weight and height pairs to see how BMI changes. This reinforces converting input to floats and using formatted output for readability.
Key Takeaway

Practical lab: convert both inputs to float, compute using the formula, and format the BMI to two decimals for a clean result.
