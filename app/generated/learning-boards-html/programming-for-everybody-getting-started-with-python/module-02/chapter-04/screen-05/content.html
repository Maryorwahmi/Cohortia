Module 02 › Chapter 2.4 › Text vs Number
Definition

Why input returns text

Key point: keyboards produce characters. Input captures those characters as a string. Even digits are characters until you convert them.

Analogy
Think of input as handing you an envelope with characters inside. Conversion opens it and interprets the contents as a number.
Quick check
If you see a TypeError when adding, ask yourself: did I convert the input to a number?
Concrete example
name = input('What is your name? ')
print('Hello,', name)

age = input('How old are you? ')  # user types: 25
print(type(age))  # shows string

# Wrong: next_year = age + 1  # TypeError
This example shows the type check and the error when arithmetic is attempted on text.
