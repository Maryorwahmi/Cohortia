Practice & Common Mistakes

Example: greeting
Ask for a name and print a greeting. This shows how input returns text you can reuse directly for display.
Example: age mistake
If you ask for age and then add 1 without converting, you will get a type error. Always convert before arithmetic.
Mnemonic
Prompt clearly, parse immediately, then process. Prompt → Parse → Process.
Why it matters
Clear prompts and early conversion prevent runtime errors and make programs predictable for users.
