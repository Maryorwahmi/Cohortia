Multiple arguments and separators

name = 'Alice'
age = 25
print('Name:', name, 'Age:', age)
print('Name:', name, sep=' | ')
print('Loading', end='')
print('...', end='')
print('Done!')
Predict the printed lines: the first shows labels and values separated by spaces; the second uses a custom separator; the last three prints combine to form 'Loading...Done!'.
Why it matters

Small formatting choices make output easier to read. Use separators for quick labels and end to avoid unwanted newlines during progress indicators.

Pro tip
For polished numeric output, prefer formatted strings rather than manual concatenation of values.
Key Takeaway

Use print arguments, sep, and end to structure output; use f-strings when you need formatted numbers.
