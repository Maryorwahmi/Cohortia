ValueError

When conversion fails

If a user types non-numeric text where a number is expected, integer and floating conversions will raise an error. Recognize this failure mode and plan to address it later.

Example failure
age = int(input('How old are you? '))  # user types: abc
# raises ValueError
Practical tip
Write clear prompts that include units and format hints to reduce invalid responses.
Future skill
Later you will use try and except to catch conversion failures and ask the user again without crashing.
Key Takeaway

Expect conversions to be strict; until you add error handling, assume the user follows the prompt format.
