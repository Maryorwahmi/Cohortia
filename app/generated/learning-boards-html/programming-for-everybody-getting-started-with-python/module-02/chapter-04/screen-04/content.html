Module 02 › Chapter 2.4 › Input Function
Core Concept

input pauses and returns text

Use prompts to ask the user for data. The result is always a string, so plan to convert if you need numbers.

Concrete example
Ask for a name like first name only. The program stores the typed characters and you can print a greeting directly with that text.
Common mistake
Assuming numbers are numeric. If you try math on text, you will get a type error.
Prompt Design
A good prompt is specific and ends with a space so the cursor is not jammed. Include units when relevant, for example ask for weight in kilograms or temperature in Celsius.
Try this mentally
  • Imagine asking for a price. What hint would you include so the user types numbers and not words?
  • Think about acceptable formats: decimals, commas, or currency symbols.
Key Takeaway

The input function returns text; design prompts to guide the user and prepare for conversion.
