input returns string
Always treat the returned value as text and convert for math.
int and float
Use integer for whole numbers and float for decimals during conversion.
Format output
Use sep, end, and f-strings with precision specifiers for readable results.
Summary

These three practices—explicit conversion, correct numeric type choice, and clear output formatting—together produce reliable, user-friendly interactive programs.
