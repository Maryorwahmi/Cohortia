Prompt Best Practices

Be specific
Include units and examples: 'Enter your height in meters (e.g., 1.75): '
Trailing space
Add a space at the end so the cursor is visible and input looks natural.
Name clearly
Use variable names that describe both data and type, such as price_float or quantity_int.
Group prompts
Provide a short context line before related prompts so users understand what the program expects next.
Key Takeaway

Thoughtful prompts and early conversion make interactive programs reliable and reduce the need for corrective input handling.
