# Simple tip calculator
print('=== Tip Calculator ===')
bill = float(input('Enter the bill amount: $'))
tip_percent = float(input('Enter tip percentage (e.g., 15 for 15%): '))
tip = bill * tip_percent / 100
total = bill + tip
print(f'
Tip: ${tip:.2f}')
print(f'Total: ${total:.2f}')
This program reads two floats, computes a percentage, and prints both values formatted with two decimals for money.
Teaching notes
  • Convert immediately to float for money to include cents.
  • Use clear prompts with currency symbols and examples to guide input.
  • Format outputs to two decimals to present a friendly monetary value.
Key Takeaway

The tip calculator combines prompts, float conversion, arithmetic, and formatted output into a complete interactive flow.
