String = sequence
An ordered collection of characters you can index and slice.
Immutable
Operations return new strings; you cannot change characters in place.
Methods & formatting
Use methods and f-strings to transform and format text clearly and safely.
Summary takeaway
Strings are the primary way programs handle text. Learn to read, combine, inspect and transform them using the simple, repeatable patterns in this chapter.
