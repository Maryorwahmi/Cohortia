Module 2 › Chapter 2.3 › Indexing and slicing
Examples
s = "Python"
print(s[0])   # P
print(s[1])   # y
print(s[5])   # n
print(s[-1])  # n
print(s[0:2]) # Py
print(s[2:4]) # th
print(s[:4])  # Pyth
print(s[2:])  # thon
Use slicing to extract substrings without loops. Remember the end index is exclusive. Omitting bounds returns from the start or to the end.
Concrete example
Take the substring for a two-letter country code from the start of a string and use it to categorize data.
Common mistake
Expecting the end index to be included. When counting characters, subtract one from the end when needed.
