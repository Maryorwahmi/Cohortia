Module 2 › Chapter 2.3 › Common string methods
Examples
s = "  Hello, World!  "
print(s.upper())          # HELLO, WORLD!
print(s.lower())          # hello, world!
print(s.strip())          # Hello, World!
print(s.replace("World","Python"))
print(s.startswith("Hello"))  # False because of leading spaces
Use these methods to normalize and clean text before comparisons or display. Remember to capture the returned value if you need to reuse it.
Practical tip
Chain methods when appropriate, for example strip then lower for consistent comparisons.
Key Takeaway

String methods create new strings; use them to prepare and clean text safely.
