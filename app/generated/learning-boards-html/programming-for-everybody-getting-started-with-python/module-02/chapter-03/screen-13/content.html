Starter template
# Template
sentence = "Python is amazing"
print(sentence)
print("First:", sentence[0])
print("Last:", sentence[-1])
print("Length:", len(sentence))
print("Substring:", sentence[7:9])
new_sentence = sentence.replace("amazing", "powerful")
print(new_sentence)

name = input("Enter your name: ")
print(f"Hello, {name}! Welcome to Python.")

birth_year = input("Enter your birth year: ")
age = 2024 - int(birth_year)
print(f"You are approximately {age} years old.")
Run this script, try different names and birth years, and notice where conversions are required. Each printed result confirms a specific concept.
Checklist
  • Printed the original sentence
  • Accessed first and last characters
  • Sliced out a substring
  • Replaced a word and printed the new string
  • Converted birth year to int and calculated age
Key Takeaway

Small scripts tying these string concepts together build a dependable habit of validating and formatting text inputs and outputs.
