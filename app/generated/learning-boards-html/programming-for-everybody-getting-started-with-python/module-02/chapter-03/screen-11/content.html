Module 2 › Chapter 2.3 › String formatting with f-strings
Code example
name = "Alice"
age = 25
print(f"My name is {name} and I am {age} years old.")
# Output: My name is Alice and I am 25 years old.
F-strings keep templates readable. Use expressions inside braces when you need computed values shown directly.
Practical exercise
Build a greeting that shows the user's name and a computed age from their birth year. Print the formatted message.
Pro tip

F-strings are the preferred modern way to format text because they are concise and clear.
