Module 2 › Chapter 2.3 › len() and in
Examples
s = "Hello, world!"
print(len(s))        # 13
print("world" in s) # True
print("Python" in s) # False
Use these to validate input, branch logic, and avoid slicing errors by first checking length or membership.
Concrete example
If a text must contain a comma, check membership before splitting. If not present, handle the alternate case gracefully.
Common pitfall

Do not assume indexes exist without length checks. Slicing with safe bounds avoids runtime errors.
