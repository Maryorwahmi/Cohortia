Module 2 › Chapter 2.3 › String immutability
Why immutable?
Immutability prevents accidental changes and allows the interpreter to reuse string objects safely. It makes strings reliable as keys or shared values.
How to change text
Create a new string from parts. Example: build a new first character plus the sliced remainder to form the updated string.
Concrete example
s = "Python"
# s[0] = "J"  # would raise an error
s = "J" + s[1:]  # new string: Jython
print(s)
The original string remains unchanged; the variable now references a new string object.
