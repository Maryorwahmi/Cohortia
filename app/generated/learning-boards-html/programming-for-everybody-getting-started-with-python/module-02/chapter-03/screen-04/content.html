Module 2 › Chapter 2.3 › What is a string?
Definition
String = sequence of characters

Strings store text: letters, digits, punctuation and spaces. Positions start at zero, so each character has a fixed index you can read.

Concrete example
name = "Alice"
print("Hello, " + name)
Misconception
Strings are not numbers. Adding strings joins text: it does not perform arithmetic operations. Convert types before math.
Visual: Characters by position
"Python" → [P (0), y (1), t (2), h (3), o (4), n (5)]
Read the character by its index. Negative indexes count from the end: -1 is the last character.
Key takeaway
Think of a string as a row of labeled boxes you can read from but not alter in place.
