Module 2 › Chapter 2.3 › Key Concepts — Quick Reference
Choose quotes
Single/double are interchangeable; triple quotes are for multi-line text.
Immutable results
All operations return new strings. To update text, build and assign a new string.
Convert explicitly
Use str, int, or float before combining text and numbers to avoid errors.
One-line summary
Use quote styles and string operations to read and shape text, always creating new strings and converting types explicitly when needed.
