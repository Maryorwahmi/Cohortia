Module 2 › Chapter 2.3 › Writing strings with quotes
Examples
name = "Alice"
greeting = 'Hello'
multiline = """This is a
string that spans
multiple lines."""
print(name)
print(greeting)
print(multiline)
Try replacing the quotes and observe when escapes are needed. Triple quotes keep the newlines exactly as typed.
Misconception
Quotes are interchangeable, but they must match. Start and end with the same quote type.
Pro tip
Choose the quote style that avoids backslash escapes for clearer code.
Try this
Write a sentence containing an apostrophe using double quotes. Then write a three-line message using triple quotes and print it to see the preserved newlines.
