Module 2 › Chapter 2.3 › Concatenation and repetition
Code examples
first = "John"
last = "Doe"
full = first + " " + last
print(full)          # John Doe
print("Ha" * 3)     # HaHaHa
print("-" * 20)     # --------------------
If you try to add a number to a string you will get a TypeError. Convert the number with str() first to include it in a message.
Example scenario
Create a greeting from separate parts, then print a decorative line using repetition. These are typical tasks in user interfaces and simple reports.
Key Takeaway

Concatenation and repetition create new strings. Convert non-string values before combining.
