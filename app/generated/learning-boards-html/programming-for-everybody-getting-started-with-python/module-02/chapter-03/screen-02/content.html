Learning Objectives
Learn the core string skills and why they matter
Bloom's ladder
Learn

01
Create and quote strings
Write text with single, double and triple quotes, including multi-line strings used for long text or documentation.
Mnemonic: picture three quotation marks around text.
VERIFIED COMPETENCY MILESTONE
02
Concatenate, repeat, index and slice
Join strings with +, repeat with *, and access parts with indexes and slices to shape text efficiently.
Mnemonic: imagine building blocks and scissors for slicing.
VERIFIED COMPETENCY MILESTONE
03
Understand immutability
Recognize that strings cannot be changed in place; learn how to make edits by creating new strings from parts.
Mnemonic: think of copying a printed line and editing the copy.
VERIFIED COMPETENCY MILESTONE
04
Convert between types
Use str, int, and float when you need to combine numbers and text or accept numeric input from users.
Mnemonic: convert before you combine — say, convert the number then append it.
VERIFIED COMPETENCY MILESTONE
