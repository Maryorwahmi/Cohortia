Practice Focus
Small exercises that build reliable habits
Create & Quote
Write the same sentence using single and double quotes, then as a triple-quoted paragraph. Observe where escapes are needed.
Index & Slice
Extract the first, last, and a middle substring. Print them to confirm positions and lengths.
Convert Types
Read a numeric string, convert with int, do arithmetic, then format with an f-string for output.
Quick checklist
  • Does your string open and close with matching quotes?
  • Did you convert numbers before concatenation?
  • When you tried to change a character, did you create a new string instead?
