Common escapes
— newline
— tab
\\ — backslash
\' or \" — quote characters inside same-quoted literal
print("Line 1
Line 2")
print("Tab  here")
print("Backslash: \\")
Concrete tip
Use raw strings when writing many backslashes, for example in file paths, to avoid repeated escaping when appropriate.
Watch out

Escapes are interpreted at creation time. If you need the literal escape characters shown, double the backslashes.
