Strings: Text in Python
Representing and manipulating text using quotes, methods, and slicing

Strings let programs work with letters, numbers shown as text, punctuation and spaces. You'll learn how to write strings, join and repeat them, take slices, and use built-in methods that return new strings. These are everyday tools for building messages, parsing input, and formatting output.

Explore Key Topics
Quotes & Literals
Single, double, and triple quotes define strings and control multiline text.
Indexing & Slicing
Access characters and substrings with numeric positions and ranges.
Immutability
Strings cannot be changed in place; operations return new strings.
Visual Concept
Strings as sequences
Character positions start at zero. You can read a character, slice ranges, or build a new string.
Example visual: "Python" → [P, y, t, h, o, n]. Index 0 is P. Negative indexes count from the end. Slicing like 0:2 returns the first two characters.
Why this matters
Text is how programs communicate with humans. These techniques let you prepare messages, parse user input, and safely combine text with numbers.
