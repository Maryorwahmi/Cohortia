Module 5 › Chapter 4.5 › main() & Import Guard
Why main() helps

main() keeps your orchestration separate so helpers can be reused or tested without running program logic on import.

When to use

Always use the pattern if you expect others to import your file or if you will add tests later.

Pattern example
def get_input():
    return input("Enter something: ")

def process(data):
    return data.upper()

def display(result):
    print(result)

def main():
    data = get_input()
    result = process(data)
    display(result)

if __name__ == "__main__":
    main()
The guard prevents main from running when this file is imported as a module.
