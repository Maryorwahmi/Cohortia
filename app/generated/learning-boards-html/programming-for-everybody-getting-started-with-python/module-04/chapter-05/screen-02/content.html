Learning Objectives

Master design habits that make programs clear and maintainable.

Bloom: Learn → Understand → Apply → Master
01
Decompose a problem

Identify sub-tasks and represent each as a function that can be implemented and tested independently.

Mnemonic: puzzle pieces
VERIFIED COMPETENCY MILESTONE
02
Single responsibility

Design each function to do one job only so testing and reuse are straightforward.

Mnemonic: one tool per worker
VERIFIED COMPETENCY MILESTONE
03
Compose functions

Combine small functions to implement high-level behavior without duplicating logic.

Mnemonic: building blocks
VERIFIED COMPETENCY MILESTONE
04
Trace execution flow

Follow how functions call one another and how data moves through the call stack.

Mnemonic: breadcrumbs
