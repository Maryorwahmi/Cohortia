Module 5 › Chapter 4.5 › Single Responsibility
Refactor steps
  1. Identify distinct tasks inside the function.
  2. Extract each task into its own function with a clear name.
  3. Replace the original code with calls to the new helpers.
  4. Write small tests for each helper.
Pro tip

Small helpers often reveal edge cases and make error handling simpler.

Refactored example
def get_user_input():
    name = input("Enter name: ")
    age = int(input("Enter age: "))
    return name, age

def classify_age(age):
    if age >= 18:
        return "adult"
    return "minor"

def print_user_info(name, age, classification):
    print(f"{name} is a {classification}")
    print(f"Name length: {len(name)}")

# Main program
name, age = get_user_input()
classification = classify_age(age)
print_user_info(name, age, classification)
Now each helper can be replaced, tested, or reused independently.
