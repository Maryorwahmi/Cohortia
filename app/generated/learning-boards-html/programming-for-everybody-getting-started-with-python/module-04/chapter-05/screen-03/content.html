Practice & Milestones

Short exercises and checks mapped to each objective.

Learn → Apply → Verify
Decompose exercise

List sub-tasks for a script, write one function per sub-task, and run simple inputs to check behavior.

Single responsibility exercise

Refactor a mixed-purpose function into separate input, process, and output functions and rerun tests.

Composition exercise

Create a top-level function that calls two helpers. Verify output for sample inputs.

Trace & test

Add small prints or logging inside functions to trace calls and confirm the call stack order.

Key Takeaway

Practice small refactors and simple tests to build confidence. Verification beats guessing.
