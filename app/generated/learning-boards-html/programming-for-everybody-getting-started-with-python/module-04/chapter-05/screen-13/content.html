Trace example
def a():
    print('enter a')
    b()
    print('exit a')

def b():
    print('enter b')
    c()
    print('exit b')

def c():
    print('enter c')
    print('exit c')

a()

# Output shows enter a, enter b, enter c, exit c, exit b, exit a
The output order maps to the stack growth and shrinkage during calls and returns.
Practical uses
  • Place logging where it most quickly isolates a failing step.
  • Use return values to pass computed data back up the stack.
  • Ask: who should validate inputs — caller or callee?
Misconception

Thinking prints show internal state reliably. Prints help, but small unit tests are more precise.
