Testing checklist
  • Test pure functions with sample inputs and expected outputs.
  • Refactor to separate logic from I/O so logic is testable.
  • Use simple assertions for arithmetic and mapping functions.
  • Capture printed output only when necessary; prefer return values for formatting.
Example tests
# Example informal tests
assert get_price('small') == 8.0
assert get_price('large') == 12.0
assert calculate_subtotal(10.0, 3) == 30.0
assert abs(calculate_tax(100.0) - 8.0) < 1e-9
Small assertions like these prevent regressions when you refactor helpers.
