Example: composing helpers
def square(x):
    return x * x

def sum_of_squares(a, b):
    return square(a) + square(b)

def hypotenuse(a, b):
    return sum_of_squares(a, b) ** 0.5

print(hypotenuse(3, 4))  # 5.0
Each function expresses a level of abstraction. The final call is easy to read: hypotenuse(3, 4).
Call stack and behavior
  • When hypotenuse is called, it calls sum_of_squares and waits for a return value.
  • sum_of_squares calls square twice; each call completes then control returns.
  • After all returns, hypotenuse computes the square root and returns the result.
Key Takeaway

Composition yields readable, testable code where each helper can be validated separately.
