Module 5 › Chapter 4.5 › Mistakes & Tips
Common mistakes
  • Mixing input, processing, and printing in one function.
  • Using unclear names or clever shortcuts that hide behavior.
  • Skipping docstrings and tests for helpers.
Pro tips
  • Name functions as actions: calculate_tax, display_receipt.
  • Prefer return values to prints for logic-heavy helpers.
  • Use the import guard to keep modules importable without side effects.
Check your understanding

Identify one function in your codebase that violates single responsibility and describe a plan to extract helpers and tests for it.
