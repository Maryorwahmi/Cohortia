Module 4 › Chapter 4.3 › Return stops execution
Example showing skipped code
def early_exit(x):
    if x < 0:
        return "Negative"
    print("This only prints for non-negative numbers")
    return "Non-negative"

print(early_exit(-5))  # Negative (print skipped)
print(early_exit(3))   # prints then returns Non-negative
Notice that the print runs only when x is non-negative because the negative branch returns first and skips the print.
Design note
Place essential actions before return or structure code so required cleanup cannot be skipped by an early return.
