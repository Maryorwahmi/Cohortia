Module 4 › Chapter 4.3 › None and missing return
Example showing None
def greet(name):
    print(f"Hello, {name}!")

result = greet("Alice")
print(result)  # None
The function prints a greeting but returns None because there is no explicit return.
Misconception
Treating None like zero or an empty string can mask bugs. Check explicitly for None when appropriate.

Change greet to return the greeting string instead of printing it. How does the caller behave differently?
