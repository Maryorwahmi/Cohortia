Module 4 › Chapter 4.3 › Returns in expressions
Compose returns directly
def square(x):
    return x * x

def add(a, b):
    return a + b

result = add(square(3), square(4))  # add(9, 16)
print(result)  # 25

if square(5) > 20:
    print("Greater than 20")
Example: nested calls evaluate inner returns first and then use them in the outer expression. Use variables when readability suffers.
Readability tip
If nested expressions are hard to follow, capture intermediate results with descriptive variable names.
Debugging note
Avoid side effects inside functions you will use in expressions so tests remain deterministic.
