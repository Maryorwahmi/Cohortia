Module 4 › Chapter 4.3 › Debugging Returns
Mistake: printed result assumed to be returned
Fix: rewrite the function to return the computed result and move print statements to the caller so tests can capture the value.
Mistake: missing return in some branches
Fix: ensure every logical path returns a value or handle None explicitly where appropriate.
Testing strategy
Write small calls that capture function returns and compare them to expected values. This surfaces incorrect types, None returns, and logic errors quickly.
