Early return example
def absolute_value(x):
    if x < 0:
        return -x
    return x

print(absolute_value(-5))  # 5
print(absolute_value(3))   # 3
Why use it
Cleaner control flow and fewer temporary variables when the result is known early.
Watch out for side effects
If code must always run (cleanup, logging), early return can skip it. Use finally or restructure if needed.
