Module 4 › Chapter 4.3 › Print vs Return
Function that prints
def print_add(a, b):
    print(a + b)  # prints but returns None

print_add(5, 3)  # prints 8, nothing to store
Use when you only need to show information to the user. Not reusable in expressions.
Function that returns
def return_add(a, b):
    return a + b  # returns a value

x = return_add(5, 3)
print(x)  # prints 8, result stored in x
Use when the value will be reused, combined, or tested. Better for composition and unit testing.
Refactor tip: split compute and display into separate functions to keep logic testable.
Key Takeaway: Prefer return for computation, reserve print for presentation.
