Module 4 › Chapter 4.3 › Return multiple values
Example: quotient and remainder
def divide_and_remainder(a, b):
    quotient = a // b
    remainder = a % b
    return quotient, remainder

q, r = divide_and_remainder(17, 5)
print(f"Quotient: {q}, Remainder: {r}")  # Quotient: 3, Remainder: 2
Returning multiple values in a tuple keeps related results together while letting the caller access each part separately through unpacking.
Practice
Write calculate_stats to return sum, average, and maximum. Unpack and print each value.
Key Takeaway
Return multiple results as a single tuple then unpack. That maintains simplicity and flexibility.
