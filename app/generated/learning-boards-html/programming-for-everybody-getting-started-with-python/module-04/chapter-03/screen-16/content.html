Module 4 › Chapter 4.3 › Quick Reminders
Design for return
If a value will be reused, return it; keep printing separate.
Test returns
Capture results in variables and assert expected values to catch errors early.
Handle None
Check for None explicitly and avoid treating it as zero or an empty value.
Final Thought

Treat returns as your primary tool for composition, and keep presentation decisions separate so your functions remain flexible and testable.
