Module 4 › Chapter 4.3 › Key Concepts
Return sends a value
Use return to hand computed results back so other code can store or reuse them.
Print ≠ Return
Printing is for display only; it does not provide a value the program can use.
None is a sentinel
A missing return yields None; handle it explicitly and don't confuse it with falsy values.
Big Picture

Design functions to return useful values and keep printing for presentation. Test by capturing returns so you catch type and logic errors early.
