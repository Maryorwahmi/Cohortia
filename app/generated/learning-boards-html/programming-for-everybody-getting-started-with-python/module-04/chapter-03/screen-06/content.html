Code walkthrough
def square(x):
    return x * x

def add(a, b):
    return a + b

# Capture returns in variables
s1 = square(3)   # 9
s2 = square(4)   # 16
result = add(s1, s2)  # 25
print(result)  # 25

# Or nest calls directly
print(add(square(3), square(4)))  # 25
Example: both approaches give 25. Nesting is concise; intermediate variables can improve readability and help debugging.
Common mistake
Relying on printed output instead of stored values. Printed text cannot be used in calculations.
Pro Tip
Use intermediate variable names that describe the value to make nested calls easier to reason about.
