Module 4 › Chapter 4.3 › What return does
Definition and behavior
return evaluates an expression and sends that value back to the code that called the function. Execution leaves the function immediately.
def add(a, b):
    result = a + b
    return result

sum_value = add(5, 3)
print(sum_value)  # 8
Example: the call add(5, 3) returns 8, which the caller stores. Misconception: printing 8 is not the same as returning it.
Why it matters: returned values let you build larger computations from small functions.
Quick practice
Write a function that returns the length of a string. Then use that return value in an arithmetic expression.
Key Takeaway
Returning a value gives you a reusable result; printing only shows it to the user.
