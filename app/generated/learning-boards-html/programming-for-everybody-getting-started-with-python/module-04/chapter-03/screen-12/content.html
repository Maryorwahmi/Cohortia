Module 4 › Chapter 4.3 › Type annotations
Annotate return types for clarity
def add(a: int, b: int) -> int:
    return a + b

def calculate_stats(a: int, b: int, c: int) -> tuple:
    total = a + b + c
    average = total / 3
    maximum = max(a, b, c)
    return total, average, maximum
Annotations make intent explicit and assist linters and IDEs. They are optional but beneficial in larger projects.
