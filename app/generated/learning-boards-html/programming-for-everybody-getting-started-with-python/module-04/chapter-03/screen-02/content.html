Learning Objectives
Build, capture, and compose function results with confidence.
01
Use return to send a value back
Write functions that compute and return values so callers can store and reuse results. This matters because returned values are the foundation of composable code.
VERIFIED COMPETENCY MILESTONE
02
Distinguish print vs return
Recognize when a function only displays output and cannot be composed in expressions. This prevents logic errors where values disappear.
VERIFIED COMPETENCY MILESTONE
03
Store a function result in a variable
Capture returned values in variables, then use them in further calculations or conditions. This is how small functions combine into larger programs.
VERIFIED COMPETENCY MILESTONE
04
Understand None from missing return
Know that a function without return gives None, why None is not zero or False, and how to guard against it in logic and tests.
VERIFIED COMPETENCY MILESTONE
Bloom: Learn → Understand → Apply → Master
