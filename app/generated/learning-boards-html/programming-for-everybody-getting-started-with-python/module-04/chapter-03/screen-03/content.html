Skills and evidence
Small checks to prove you can return and use values safely.
Return a number and store it
Call a function that returns a number, assign it to a variable, and print the variable. This shows the result persisted beyond the function call.
Mnemonic: call → capture → use
VERIFIED COMPETENCY MILESTONE
Return multiple values
Return a tuple and unpack it into variables for separate use. This proves you can pass structured results between functions.
Mnemonic: pack → return → unpack
VERIFIED COMPETENCY MILESTONE
