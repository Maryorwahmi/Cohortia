Module 4 › Chapter 4.2 › Argument expressions
Examples to try
def double(x):
    print(x * 2)

n = 5
double(n)        # passes value of n
double(3 + 4)    # passes result of arithmetic
double(len("hi"))  # passes result of another function
Each argument expression is evaluated before the function receives its value.
Why this matters
  • It allows concise calls using calculations and other function results.
  • Understanding evaluation order helps avoid surprising side effects or stale values.
  • Use temporary variables if you need to reuse an evaluated result for clarity.
