Module 4 › Chapter 4.2 › Default ordering
Correct
def greet(name, greeting="Hello"):
    pass
Required name, optional greeting afterward: valid.
Incorrect (syntax error)
def greet(greeting="Hello", name):
    pass  # SyntaxError!
Python enforces ordering to keep semantics clear for positional calls.
Design tip
Order parameters from required to optional to make your API predictable and easy to call positionally.
