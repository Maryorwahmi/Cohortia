Module 4 › Chapter 4.2 › Parameter scope
Example: scope error
def show_length(text):
    print(f"Length: {len(text)}")

show_length("Hello")
print(text)  # NameError: text is not defined
The print outside the function fails because text only exists during the function call.
Implication for design
Because parameters are local, functions should return values when callers need results instead of depending on parameter names to persist.
Analogy: each call gets its own workspace; when the work finishes the workspace is cleared.
Key Takeaway

Parameters create temporary, local variables. They help keep functions self-contained and reduce accidental interactions.
