Module 4 › Chapter 4.2 › Default parameters
Example with default
def greet(name, greeting="Hello"):
    print(f"{greeting}, {name}!")

greet("Alice")                  # uses default greeting
greet("Bob", "Good morning")  # overrides default
Defaults make common usage concise while allowing callers to override.
Rules and tips
  • Parameters with defaults must come after required parameters.
  • Prefer immutable defaults (strings, numbers) to avoid shared-state bugs.
  • Document default semantics so callers understand expected behavior.
Check
Try calling a function with and without the optional argument and observe the difference in output.
