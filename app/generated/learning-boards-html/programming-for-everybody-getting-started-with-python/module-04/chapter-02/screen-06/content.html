Module 4 › Chapter 4.2 › Single-parameter example
Code example
def greet(name):
    print(f"Hello, {name}!")

# Calls with different arguments

greet("Alice")
greet("Bob")
Note: the string values Alice and Bob are arguments; name is the parameter created at each call.
Explanation and checks
  • When greet runs, Python sets the local variable name to the passed string.
  • Each call creates a fresh name variable; values from one call do not persist to the next.
  • Try printing name outside the function to observe a NameError and confirm scope rules.
Common mistake
Confusing parameter and argument names when both exist; prefer descriptive parameter names to avoid this.
