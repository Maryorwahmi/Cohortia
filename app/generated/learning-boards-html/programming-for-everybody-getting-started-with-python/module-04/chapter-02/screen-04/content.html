Module 4 › Chapter 4.2 › Why functions need input
Concept: parameters give flexibility
Identify what a function needs to do its work and declare parameters for those pieces of information.
Parameters are placeholders named in the function definition.
Arguments are the actual values supplied when calling the function.
Ask: what data does this function need? That becomes the parameter list.
Key Takeaway
Parameters let functions operate on different inputs, turning one routine into many useful behaviors.
Analogy
Think of a function as a recipe and parameters as blank ingredient slots. Arguments are the actual ingredients you add when cooking.
Example:
def greet(name):
    print(f"Hello, {name}!")

greet("Alice")
# Alice is the argument filling the name parameter
Misconception: parameters are not persistent globals; they exist only during the call.
