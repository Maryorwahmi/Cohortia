Starter code
def greet(name):
    print(f"Hello, {name}!")

def add(a, b):
    print(f"{a} + {b} = {a + b}")

def describe_rectangle(width, height):
    area = width * height
    perimeter = 2 * (width + height)
    print(f"Rectangle {width}x{height}: Area={area}, Perimeter={perimeter}")

def print_repeated(text, times=3):
    print(text * times)

# Test calls below
Use these functions with different argument styles to validate your understanding.
Testing checklist
  • Call greet with different names and with a variable holding a name.
  • Call add with literals and with an expression like 5 + 2.
  • Call describe_rectangle positionally and with keywords to compare results.
  • Call print_repeated with and without the times argument and with times passed by name.
Reflection: which calls were clearer with keywords? Which produced surprises when order was swapped?
Key Takeaway
Small, focused experiments with these functions make parameter and argument behavior concrete and memorable.
