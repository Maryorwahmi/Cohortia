Module 4 › Chapter 4.2 › Keyword arguments
Example with keywords
def describe_pet(animal, name, age):
    print(f"I have a {animal} named {name} who is {age} years old.")

# Calls using keywords
describe_pet(animal="dog", name="Rex", age=3)
describe_pet(name="Whiskers", age=2, animal="cat")
Keywords let you reorder arguments and keep calls readable.
When to use
  • Functions with many parameters or boolean flags.
  • When argument order is non-obvious or error-prone.
  • When calling a function with most defaults but overriding a few named options.
Pro tip
Use keywords to make code self-documenting, especially in collaborative projects where clarity matters.
