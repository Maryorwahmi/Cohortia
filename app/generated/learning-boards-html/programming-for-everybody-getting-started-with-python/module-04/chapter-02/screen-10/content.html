Module 4 › Chapter 4.2 › Value copying
Example: increment
def increment(x):
    x = x + 1
    print(f"Inside function: x = {x}")

a = 5
increment(a)
print(f"Outside function: a = {a}")
# Inside: x is 6
# Outside: a is still 5
Reassigning x inside the function does not change a outside the function for immutable types.
Points to notice
  • Parameters receive the evaluated value of the argument at call time.
  • For immutable types, operations that rebind the parameter create a new value local to the function.
  • This property helps you avoid unintended side effects when using numbers and strings.
Misconception

Do not assume all types behave like this. Mutable types behave differently; that topic appears later.
