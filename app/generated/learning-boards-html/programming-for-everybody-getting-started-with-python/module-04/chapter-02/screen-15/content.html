Module 4 › Chapter 4.2 › Key Concepts
Parameter
A placeholder named in the function definition that will hold an input value during the call.
Argument
The actual value passed when calling the function; it is evaluated before assignment to the parameter.
Positional vs Keyword
Positional matches by order. Keywords bind by name and remove order dependence.
Takeaway

Use clear parameter names, prefer keywords for complex calls, and test with small examples to build confidence.
