Module 4 › Chapter 4.2 › Positional arguments
Example signature
def greet(name, age):
    print(f"Hello, {name}! You are {age} years old.")

# Positional calls
greet("Alice", 25)
greet("Bob", 30)
Order: Alice→name, 25→age. Swapping changes meanings.
Common pitfall
Passing arguments in the wrong order can silently produce incorrect behavior, especially when parameters share the same type.
Mitigation
  • Use keyword arguments for clarity when order is not obvious.
  • Give descriptive parameter names and document the function.
Check your understanding
If you call greet(25, "Alice"), what will name and age contain? Try it to see how position affects values.
