Module 4 › Chapter 4.2 › Parameters vs Arguments
Parameter (definition)
Named in the function signature and acts as a local variable while the function runs.
Example label: name in def greet(name):
Mnemonic: think of a parameter as an empty labeled slot in the function.
Argument (call)
The actual value or expression you pass when invoking a function.
Example label: "Alice" in greet("Alice")
Mnemonic: think of an argument as the ingredient you add to a slot.
Quick practice
def greet(name): # name is parameter
greet("Alice") # "Alice" is argument
Misconception: parameters are not the same as arguments and do not hold values until a call assigns them.
