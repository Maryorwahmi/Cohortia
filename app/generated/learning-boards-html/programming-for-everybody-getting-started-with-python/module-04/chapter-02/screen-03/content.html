Hands-on activities
  • Write greet(name) to print a personalized greeting and call it with several names.
  • Write add(a, b) and call with literals and variables to confirm results.
  • Write describe_rectangle(width, height) to compute area and perimeter and test different sizes.
  • Write print_repeated(text, times=3) and call with and without the times argument.
Quick tip
When experimenting, print both inside and outside the function to observe parameter scope and confirm values are local to each call.
Try this
Call the same function twice with different arguments. Notice each call gets its own set of parameter values that do not interfere with each other.
