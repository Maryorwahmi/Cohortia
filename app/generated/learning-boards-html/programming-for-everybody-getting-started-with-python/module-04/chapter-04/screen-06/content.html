Example: read-only global
tax_rate = 0.08  # Global variable

def calculate_total(price):
    total = price + (price * tax_rate)  # Can access global tax_rate
    return total

print(calculate_total(100))  # 108.0
This pattern is fine when tax_rate is a constant. It requires no global declaration because the function only reads the value.
When to avoid
  • Don't use globals for frequently changing state shared across functions.
  • Prefer parameters for values that vary per call.
  • Use named constants for truly global fixed values like PI.
Pro tip

Mark global constants in all caps to signal intent, for example PI = 3.14159.
