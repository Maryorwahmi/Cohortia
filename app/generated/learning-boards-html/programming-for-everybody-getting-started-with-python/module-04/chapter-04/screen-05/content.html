Module 4 › Chapter 4.4 › Local Variables
Code walkthrough
def calculate_sum(a, b):
    result = a + b  # result is local to calculate_sum
    return result

calculate_sum(5, 3)
print(result)  # NameError! result is not defined outside the function
Run this to observe the NameError. The local name result exists only inside calculate_sum. To keep the value use return and assign it to a name in outer scope.
Explanation & example
  • Parameters a and b are local when calculate_sum runs.
  • result is created on assignment inside the function and destroyed on return.
  • To use the computed value outside, return result and save it to a variable.
Common mistake

Assuming a function's local name becomes global without returning it causes NameError and hidden bugs.
