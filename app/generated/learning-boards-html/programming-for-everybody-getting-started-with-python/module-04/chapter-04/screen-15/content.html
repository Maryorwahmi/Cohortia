Module 4 › Chapter 4.4 › Key Concepts
UnboundLocalError
Occurs when you assign to a name in a function but try to read it before assignment.
global keyword
Declare the name global inside a function to modify the module-level variable.
Side effects
Functions that modify external state are harder to test; prefer pure functions when possible.
Final takeaway

Think about where names belong, choose clear data flow, and use global only when its trade-offs are justified.
