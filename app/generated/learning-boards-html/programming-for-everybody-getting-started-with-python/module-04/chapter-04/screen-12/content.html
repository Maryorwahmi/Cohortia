Starter code to run and observe behaviors
message = "Hello from outside"

def show_message():
    print(message)  # Reads global

def change_message_wrong():
    # message = message + "!"  # Uncomment to see UnboundLocalError
    pass

def change_message():
    global message
    message = message + "!"
    print(message)

def shadow():
    message = "Hello from inside"
    print(message)

print("Global:", message)
show_message()
change_message()
print("After change:", message)
shadow()
print("After shadow:", message)
Run each step in order. Notice how the uncommented wrong change would error. The fixed version updates the global. Shadow prints a local message and leaves the global untouched.
