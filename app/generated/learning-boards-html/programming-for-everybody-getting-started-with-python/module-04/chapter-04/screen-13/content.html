Quick tasks
  1. Give one example of a local variable and one example of a global variable.
  2. Write a short function that returns a computed value instead of writing to a global.
  3. Produce the UnboundLocalError example and then fix it with global.
  4. Refactor one function from the hands-on program to eliminate global usage.
Self-check

If you can predict the error and show both the broken and fixed versions, you’ve mastered the practical use of scope.
