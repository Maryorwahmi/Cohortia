Module 4 › Chapter 4.4 › What is Scope?
Definition

Scope as visibility and lifetime

Scope answers two questions: can this code see the name, and how long does the value live? Local names exist only while the function runs; global names exist for the life of the module.

  • Local names: created when a function runs, destroyed on return.
  • Global names: module-level, readable anywhere in the module.
  • Reading a global is fine; assigning without declaring global makes a local.
Key Takeaway

Trace where a name is assigned first to determine whether it is local or global.

Concrete Example
tax_rate = 0.08  # Global variable

def calculate_total(price):
  total = price + (price * tax_rate)  # reads global
  return total

print(calculate_total(100))  # 108.0
Misconception
Many learners think reading a global requires a declaration. It does not. Only assignment changes how Python classifies the name.
