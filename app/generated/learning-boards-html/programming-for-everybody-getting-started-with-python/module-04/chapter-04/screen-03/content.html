Module 4 › Chapter 4.4 › Learning Objectives
Learn
Detect where a name lives
Follow assignments and reads to find the variable's scope and avoid NameError surprises.
VERIFIED COMPETENCY MILESTONE
Understand
Spot shadowing
If a local uses the same name as a global, it hides the global inside the function.
VERIFIED COMPETENCY MILESTONE
Apply
Use global intentionally
Declare global only when you really need to modify module-level state; otherwise use parameters and return values.
VERIFIED COMPETENCY MILESTONE
Master
Prefer self-contained functions
Functions that only use parameters and returns are easier to test and reason about because they have no hidden side effects.
