Variable Scope

Understand where names live, why assignment changes behavior, and how to avoid scope bugs.

In this lesson
Definitions, common errors, the global keyword, LEGB rule, and best practices.
Why it matters
Scope prevents accidental changes to shared data and clarifies where to look when a name is missing.
Explore Key Topics
Local variables
Created inside functions, temporary, not visible outside.
Global variables
Module-level names readable anywhere; writing needs care.
LEGB rule
How Python resolves names: Local, Enclosing, Global, Built‑in.
Visual Concept
Nested rooms metaphor
Imagine the program as nested rooms. The outermost room is the global scope. Each function call creates an inner room. Names declared inside an inner room are not visible outside. A special key called global lets an inner room modify items in the outer room.
Quick note
Prefer passing data and returning results instead of relying on global changes.
