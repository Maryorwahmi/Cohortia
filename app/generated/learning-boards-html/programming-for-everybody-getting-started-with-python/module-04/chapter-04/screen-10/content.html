Module 4 › Chapter 4.4 › Shadowing
Example
name = "Global Alice"

def show_name():
    name = "Local Bob"  # local shadows global
    print(name)

show_name()      # Local Bob
print(name)      # Global Alice
The function creates a separate local variable named name; it does not change the global binding.
Avoiding accidental shadowing
  • Use longer, descriptive names for global state.
  • Avoid reusing the same identifier in different scopes unless intentional.
  • Document functions that intentionally change global variables.
Pro tip

If you must use a global, name it clearly, for example GLOBAL_CONFIG, to reduce accidental reuse.
