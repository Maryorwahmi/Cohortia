LEGB name resolution
Local
Names inside the current function.
Enclosing
Names in any enclosing function for nested functions.
Global
Module-level names available across functions.
Built-in
Python's built-ins like print and len.
When a name is found in an earlier step, Python stops searching. This explains shadowing: a local name with the same identifier hides any global or built-in with the same name.
Key Takeaway

Use the LEGB checklist to trace where Python will look for a name when debugging.
