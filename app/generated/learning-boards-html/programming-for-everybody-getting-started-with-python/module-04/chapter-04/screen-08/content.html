Module 4 › Chapter 4.4 › global Keyword
Correct code
counter = 0

def increment():
    global counter
    counter = counter + 1
    print(counter)

increment()  # 1
increment()  # 2
print(counter)  # 2
This code intentionally modifies the module-level counter. The global declaration tells Python not to create a local counter.
When to prefer alternatives
  • For reusable functions, prefer returning the new value and assigning it where needed.
  • Use global for small scripts or clearly documented shared state.
Warning

Overusing global increases side effects and makes unit testing harder.
