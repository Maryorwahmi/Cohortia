Module 4 › Chapter 4.4 › UnboundLocalError
Failing code example
counter = 0

def increment():
    counter = counter + 1  # UnboundLocalError!
    print(counter)

increment()
Python sees the assignment to counter and treats it as a local name, so when evaluating counter + 1 the local counter does not yet exist.
Fix options
  • Declare global inside the function to modify the global variable.
  • Or refactor: accept the value as a parameter and return the new value.
Key Takeaway

If you see UnboundLocalError, inspect assignments in the function; they change name resolution.
