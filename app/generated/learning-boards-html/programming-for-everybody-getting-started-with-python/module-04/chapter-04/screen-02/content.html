Explain variable scope

Distinguish local vs global
Show how parameters and variables inside functions are local and how module-level names are global and readable from functions.

03
Use the global keyword correctly
Understand why Python raises UnboundLocalError on assignment and how declaring global resolves it when appropriate.

04
Prevent scope bugs
Adopt best practices: pass parameters, return results, avoid shadowing, and reserve globals for constants and configuration.
