A four-step checklist to prevent scope bugs
1. Trace assignments
Find where the name is written and read first.
2. Prefer parameters
Pass values into functions and return results.
3. Avoid shadowing
Choose distinct names for global state and locals.
4. Use globals sparingly
Reserve global for constants or well-documented shared state.
Why this matters

Following these steps reduces side effects and improves readability, which speeds debugging and testing.
