Why use functions

Practical benefits for real code

Reusability
Write once, call many places. Fix once, fix everywhere.
Organization
Names document intent and make programs readable at a glance.
Testing
Small units are easier to test and debug in isolation.
Real-world connection
When a project grows, early use of functions prevents messy, duplicated code and saves time during maintenance.
