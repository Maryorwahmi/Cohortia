Module 04 › Chapter 4.1 › Practice Plan
Step-by-step practice
  1. Define a small function that prints a message. Notice nothing prints until you call it.
  2. Call the function three times to produce repeated output without copying lines of code.
  3. Order check — try calling before defining to observe the NameError and learn why sequencing matters.
  4. Placeholder — create a function with pass so Python accepts an empty body while you return later to implement it.
  5. Scope check — define a variable inside a function and try to use it outside to see local scope in action.
Quick mnemonic
Remember: Recipe = Definition, Cooking = Call. Recipe alone is not a meal.
