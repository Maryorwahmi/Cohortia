Module 04 › Chapter 4.1 › Hands-on Activity
Activity steps
  1. Define say_hello to print a friendly message.
  2. Define say_goodbye to print a farewell message.
  3. Define print_dashed_line to print thirty dashes and reuse it for borders.
  4. Call print_dashed_line, call say_hello three times, call print_dashed_line, call say_goodbye, then print_dashed_line again.
Reflection
Count how many lines you avoided copying by using functions. That savings scales with program size.
Starter code
def say_hello():
  print("Hello, Python learner!")

def say_goodbye():
  print("Goodbye, see you next time!")

def print_dashed_line():
  print("-" * 30)

# Main program
print_dashed_line()
say_hello()
say_hello()
say_hello()
print_dashed_line()
say_goodbye()
print_dashed_line()
Run the script and then change the message inside say_hello to see the update reflected everywhere you call it.
