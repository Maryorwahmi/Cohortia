Why use pass

pass lets you declare a function body without implementing details yet, keeping the file syntactically valid while you iterate.

Important
pass does nothing at runtime. Calling a function that only contains pass produces no output.
When to replace
Replace pass with real logic once you decide the function's behavior. pass is a temporary scaffold.
Example
def future_function():
  pass  # TODO: implement later

future_function()  # No output; function exists but does nothing
Use pass to plan functions, then implement them when you are ready. It keeps your program runnable while you build features step by step.
