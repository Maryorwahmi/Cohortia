Module 04 › Chapter 4.1 › Key Concepts
Function
A named block of reusable code that performs a specific task when called.
def and call
Use def to define; use parentheses after the name to call and run the function.
Scope
Variables inside a function are local; return values explicitly share data with callers.
One-line summary
Define functions to encapsulate behavior, call them to run that behavior, and prefer clear names and small bodies to keep programs maintainable.
