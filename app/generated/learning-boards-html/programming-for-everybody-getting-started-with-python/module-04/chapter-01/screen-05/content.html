Module 04 › Chapter 4.1 › Defining a function
Code pattern

Header and body

Start with def, pick a descriptive name using letters, digits or underscores, then parentheses and a colon. Indent the block that forms the body.

Naming rules
  • Use letters, numbers, and underscores; don’t start with a digit.
  • Function names are case-sensitive.
  • Prefer snake_case for multiword names.
Common mistake
Missing colon or wrong indentation leads to a syntax error. Always keep the body indented consistently.
Code walkthrough
def greet():
  print("Hello, welcome to Python!")

# Definition above — no output yet

greet()  # Calling the function runs the print statement
Try renaming greet to print_welcome_message to describe the action. Short, readable names make code easier to understand later.
