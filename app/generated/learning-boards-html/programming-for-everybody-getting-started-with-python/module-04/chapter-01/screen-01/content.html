Defining and Calling Functions

Learn how to wrap logic in named blocks, invoke them when needed, and keep code organized and reusable.

In this lesson
Define functions with def, call them with parentheses, and see how local scope keeps variables inside the function.
Coming up
Examples of defining and calling functions, the pass placeholder, and a short hands-on pattern to practice repetition.
Explore Key Topics
What is a function?
A named block of code you run when you need it.
Definition vs call
Defining creates the recipe; calling executes it.
Local scope
Variables inside a function stay inside it.
Function as a machine
Definition builds the machine; calls press the button
Blueprint
def adds a named block that stores steps for later
Activation
Calling the name with parentheses runs the steps
Why this matters
Functions prevent copy-paste, let you test parts independently, and make code easier to read and maintain.
Quick example
def say_hello():
  print("Hello, Python learner!")

# The function above does nothing until it is called.
say_hello()
