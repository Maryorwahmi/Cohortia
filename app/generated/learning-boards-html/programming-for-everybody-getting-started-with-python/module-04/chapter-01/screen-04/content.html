Module 04 › Chapter 4.1 › What is a function?
Definition

Function as a recipe

A function groups statements under a name. You define it once and call it multiple times to reuse the grouped behavior.

Concrete example
A print_header function prints the same heading across many parts of a script so you never copy header lines.
Misconception
Defining a function does not execute it. The body runs only when you call the function.
Key Takeaway
Use functions to reduce repetition and communicate intent through names.
Analogy
Recipe vs cooking: the definition is the written recipe; calling the function is cooking the meal.
Example code
def print_header():
  print("=== Report Header ===")

# The function above is defined but not executed until called
print_header()
print_header()
Try renaming the function to describe the task. Clear names make code read like a sentence.
