Module 04 › Chapter 4.1 › Remember
Definition vs Call
Definition stores steps; call runs them. Order matters to avoid runtime errors.
pass
Use pass to keep an empty function body valid while you plan future work.
Local scope
Local variables live inside the function; return values when you need them elsewhere.
Final thought
As you practice, convert repeating patterns into small, well-named functions. That habit will make your code clearer and easier to change.
