Learning Objectives

Concrete skills and why they matter for readable, reusable code.

01
Explain a function

Describe a function as a named block of code and why naming helps structure programs. This matters because it turns repeated logic into a single, testable unit.

VERIFIED COMPETENCY MILESTONE
02
Define a function

Use the def keyword, a valid name, parentheses, and a colon to create a function. Writing clean definitions makes code easier to reuse and share.

VERIFIED COMPETENCY MILESTONE
03
Call a function

Invoke a function by writing its name followed by parentheses. Calling runs the code inside the function and produces the output you expect.

VERIFIED COMPETENCY MILESTONE
04
Definition vs call

Separate the creation of a function from when it runs. Calling a function before it exists leads to an error; order matters for correct execution.

VERIFIED COMPETENCY MILESTONE
