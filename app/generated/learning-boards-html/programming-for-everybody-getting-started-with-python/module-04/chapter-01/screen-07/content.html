Module 04 › Chapter 4.1 › Definition vs Call
Definition

Creates a function name and stores the body. No statements inside run at definition time.

Analogy
Writing a recipe does not make the dish; it prepares instructions for later.
Common error
Calling before defining produces a NameError because the name does not exist yet.
Call

Executes the code stored in the function. Parentheses are required to trigger execution.

Concrete example
# Wrong order causes NameError
farewell()

def farewell():
  print("Goodbye!")

# Correct order
def farewell():
  print("Goodbye!")

farewell()
A helpful check: always ensure the definition line has executed before any call to that name runs at runtime.
