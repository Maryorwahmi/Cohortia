Module 04 › Chapter 4.1 › Local scope
Scope model

Variables created inside a function are local. They exist only during the function call and cannot be accessed outside.

Concrete example
Compute a temporary variable inside a function and print it there. Outside the function this name will not exist.
Misconception
Local variables do not persist outside the function. To use results elsewhere, return them explicitly.
Illustration
def my_function():
  local_var = 10
  print(local_var)  # Works inside the function

my_function()

# print(local_var)  # Error: local_var is not defined here
If you need the value outside, return it and assign the return to a variable in the calling code.
