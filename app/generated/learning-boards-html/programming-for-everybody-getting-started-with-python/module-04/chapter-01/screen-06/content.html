Repeatable behavior

Define once, call many times. Calls run the function body and produce output or side effects each time.

Example scenario
Use a print_footer function at the end of several report sections instead of pasting footer lines each time.
Contrast
A variable holds data; a function holds behavior you must invoke to run.
Try this
Define a small function, call it repeatedly, then change the function body and observe updated behavior across calls.
Code example
def say_hello():
  print("Hello, Python learner!")

# Calls
say_hello()
say_hello()
say_hello()

# Change the function body and call again to update all usage
Remember: forget parentheses and you refer to the function object; include them to run it.
