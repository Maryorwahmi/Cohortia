Environment Setup

Installing Python and `pip`

Getting Your Development Toolkit Ready

Installation Steps

  • Download Python: Get a recent stable version (e.g., Python 3.9+) from python.org.
  • Run Installer: Follow the prompts, ensuring 'Add Python to PATH' is selected.
  • `pip` Included: The package installer `pip` comes bundled with Python 3.

Why a Recent Version?

Older Python versions might lack features or have security vulnerabilities. A modern Python 3 ensures compatibility with the latest networking libraries and best practices.

Key Takeaway

A properly installed Python 3 with `pip` is the foundation for any network automation project, enabling you to manage dependencies and run scripts effectively.

Terminal Commands
# Verify Python installation
python3 --version
# Expected Output: Python 3.x.x

# Verify pip installation
pip3 --version
# Expected Output: pip x.x.x from ... (python 3.x)

Use python3 and pip3 to ensure you're targeting Python 3, especially on systems with Python 2 installed.
