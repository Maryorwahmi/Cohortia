Control Flow: Iteration with `for` Loops

Automating Repetitive Tasks Across Multiple Elements

How `for` Loops Work

  • Iterate: Process each item in a sequence (e.g., list, string) one by one.
  • Automation: Execute the same block of code for multiple items.
  • Loop Variable: Temporarily holds the current item during each iteration.
  • Indentation: Defines the code block to be repeated.

Network Scenario

Use `for` loops to iterate through a list of device IPs to ping each one, apply a configuration template to multiple interfaces, or collect operational data from several network elements.

Key Takeaway

`for` loops are essential for automating repetitive tasks, allowing you to process collections of network data or devices efficiently with a single block of code.

Python Code Example: `for` Loop
network_devices = ["Router_HQ", "Switch_Branch1", "AP_Floor2"]

for device in network_devices:
    print(f"Processing device: {device}")
    # Imagine more complex automation tasks here, e.g.,
    # connect to device, get config, etc.

print("All devices processed.")

This loop iterates through each device in the list and prints a message.
