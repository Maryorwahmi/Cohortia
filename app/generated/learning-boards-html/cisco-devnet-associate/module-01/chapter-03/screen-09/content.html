Data Structures

Collection Data Type: Dictionaries

Structured Data with Key-Value Pairs

Dictionary Characteristics

  • Key-Value Pairs: Stores data as unique keys mapped to values.
  • Unordered: Elements do not maintain a specific insertion order (in Python 3.7+ insertion order is preserved, but conceptually they are unordered).
  • Mutable: Can add, remove, or change key-value pairs.
  • Keys must be unique: Each key identifies a unique value.

Network Automation Use Case

Dictionaries are perfect for representing device configurations (e.g., {"hostname": "CoreRouter", "ip": "10.0.0.1"}), API responses, or structured inventory data.

Key Takeaway

Dictionaries provide a powerful way to store and access structured data using descriptive key-value pairs, essential for managing complex network information and configurations.

Python Code Example: Dictionaries
device_config = {
    "hostname": "CoreRouter",
    "ip_address": "10.0.0.1",
    "ports": ["Gi0/1", "Gi0/2"] # Value can be a list!
}
print(f"Initial config: {device_config}")

# Accessing values by key
print(f"Hostname: {device_config["hostname"]}") # Output: CoreRouter

# Adding a new key-value pair
device_config["location"] = "Data Center"
print(f"After adding location: {device_config}")

Dictionaries are highly flexible for managing structured data, often nested with other data types.
