Control Flow: Conditional Statements

Making Decisions with `if/elif/else`

How `if/elif/else` Works

  • `if` statement: Executes code if its condition is `True`.
  • `elif` statement: Checked if `if` is `False`; executes if its condition is `True`.
  • `else` statement: Executes if all preceding `if` and `elif` conditions are `False`.
  • Indentation: Crucial for defining code blocks (use 4 spaces consistently).

Network Scenario

You can use `if/elif/else` to check an interface's operational status, apply different QoS policies based on traffic type, or determine device configuration based on its role in the network.

Key Takeaway

Conditional statements are vital for creating intelligent Python scripts that can adapt their behavior based on varying network conditions and data, enabling dynamic automation.

Python Code Example: `if/elif/else`
interface_status = "down"

if interface_status == "up":
    print("Interface is operational.")
elif interface_status == "down":
    print("Interface is administratively down or experiencing issues.")
else:
    print("Unknown interface status.")

# Try changing interface_status to "up" or "error"

This example demonstrates how to check an interface's status and print a corresponding message.
