Python Variables and Basic Data Types

Storing Data with Dynamic Typing

Understanding Variables

  • Named Storage: Variables hold values in memory.
  • Dynamic Typing: Python infers data type automatically.
  • Assignment: Use the = operator to assign values.

Data Type Examples

  • String (str): "Router1", 'GigabitEthernet0/1'
  • Integer (int): 10, 192
  • Float (float): 3.14 (decimal numbers)
  • Boolean (bool): True, False (logical states)
Key Takeaway

Variables are fundamental for storing and manipulating data in Python, with dynamic typing simplifying how you work with different data types like strings, integers, and booleans.

Python Code Example
device_name = "Router1"      # String
ip_address = "192.168.1.1"  # String
vlan_id = 10             # Integer
is_active = True         # Boolean
temperature = 25.5       # Float

print(f"Device: {device_name}, IP: {ip_address}")
print(f"VLAN ID: {vlan_id}, Active: {is_active}")

Python automatically assigns the correct data type based on the value provided.
