Script Execution

Executing Python Scripts

Running Your Code from the Command Line

Steps to Execute

  • Save Script: Save your Python code in a file with a .py extension (e.g., my_script.py).
  • Open Terminal: Navigate to the directory where your script is saved.
  • Run Command: Use python3 your_script_name.py to execute.
  • Interpret Output: Observe the results printed to the terminal.

Why Command Line?

Executing from the command line is the standard way to run Python scripts, especially for automation tasks. It provides direct control and immediate feedback, crucial for development and deployment.

Key Takeaway

Knowing how to execute Python scripts from the command line is a fundamental skill that allows you to test, run, and deploy your automation solutions effectively.

Terminal Example
# Create a simple Python script file (e.g., my_script.py)
echo 'print("Hello, Network Automation!")' > my_script.py

# Execute the Python script
python3 my_script.py

# Expected Output:
# Hello, Network Automation!

Ensure you are in the correct directory where my_script.py is saved.
