Software-Defined Networking (SDN)

SDN separates the network's control plane from the data plane, enabling centralized, programmatic control.

Key Principles

  • Control Plane Separation: Logic for forwarding decisions is centralized.
  • Data Plane: Handles actual packet forwarding on network devices.
  • Centralized Controller: Provides a global view and programmatic control over the network.
  • Policy-Driven: Network behavior is dictated by policies from the controller.

Example: Dynamic Provisioning

An SDN controller can dynamically provision network segments and apply security policies for new virtual machines, automatically adjusting traffic flows without manual switch configurations.

Key Takeaway

SDN centralizes network intelligence, enabling flexible, policy-driven control across the entire network infrastructure.
