REST Principles

Uniform Interface and Layered Systems

Simplifying interactions through consistent resource access and hidden intermediaries.

Uniform Interface Constraints

  • Resource Identification: Resources are identified in requests (e.g., via URIs).
  • Resource Manipulation: Clients can modify/delete resources using their representations.
  • Self-descriptive Messages: Each message contains enough info to process it.
Layered System: Clients don't need to know if they're connected directly to the server or through intermediaries (e.g., proxies, load balancers). This enhances scalability and security.
Key Takeaway

The Uniform Interface ensures consistent API interaction, while the Layered System provides abstraction and improves scalability by hiding network topology.

RESTful API Structure

Uniform Resource Identifier (URI)

`GET /api/v1/devices/router1` clearly identifies 'router1' as the resource.

Resource Representation

A JSON object representing a VLAN's current state allows you to update it.

Layered System

Your script interacts with the API, unaware if a load balancer is in between.
