Understanding API Responses: Success Codes (2xx)

Confirming successful requests and resource creation.

Common 2xx Status Codes

  • 200 OK: Standard response for successful HTTP requests. The request was processed, and the expected data is returned.
    Example: A GET request for device details returns the device's configuration.
  • 201 Created: The request has been fulfilled and resulted in a new resource being created.
    Example: A POST request successfully creates a new VLAN on a switch.
  • 204 No Content: The server successfully processed the request, but is not returning any content.
    Example: A DELETE request successfully removes a firewall rule.
Key Takeaway

2xx status codes confirm successful API interactions, indicating that your requests were correctly handled and the desired outcome was achieved.

Success Scenarios

Retrieve Device List

GET /devices returns a 200 OK with a list of devices.

Create New Interface

POST /interfaces returns a 201 Created after adding a new interface.

Delete Old Route

DELETE /routes/10.0.0.0 returns a 204 No Content.
