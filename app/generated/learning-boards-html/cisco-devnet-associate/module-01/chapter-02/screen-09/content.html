Structuring Data: JSON and XML

Choosing the right format for API communication.

JSON vs. XML Overview

  • JSON (JavaScript Object Notation): Lightweight, human-readable, uses key-value pairs and arrays. De facto standard for modern RESTful APIs due to conciseness and ease of parsing.
  • XML (Extensible Markup Language): Older, more verbose, uses tags to define elements. Still used in some legacy systems, offers strong validation capabilities with schemas.
Key Takeaway

JSON is the preferred data format for modern APIs due to its simplicity and efficiency, while XML remains relevant for legacy systems and strict validation needs.

Network Interface Representation

JSON Example
{
  "name": "GigabitEthernet1/0/1",
  "description": "Uplink to Core",
  "ip_address": "192.168.1.1",
  "status": "up"
}
XML Example
<interface>
  <name>GigabitEthernet1/0/1</name>
  <description>Uplink to Core</description>
  <ip_address>192.168.1.1</ip_address>
  <status>up</status>
</interface>
