API Response Anatomy

Decoding API Responses

Accessing status codes, headers, and body content.

Python Code: Inspecting Response
import requests

response = requests.get('https://jsonplaceholder.typicode.com/posts/1')

# 1. Status Code: Numeric HTTP status (e.g., 200 OK, 404 Not Found)
print(f"Status Code: {response.status_code}")

# 2. Headers: Dictionary of HTTP response headers
print(f"Content-Type: {response.headers.get('Content-Type')}")
print(f"Server: {response.headers.get('Server')}")

# 3. JSON Content: Deserializes JSON body to Python dict/list
if response.status_code == 200:
    data = response.json()
    print(f"Post Title: {data['title']}")

# 4. Raw Text Content: The entire response body as a string
else:
    print(f"Error Details: {response.text}")
Key Response Properties
  • •.status_code: Essential for checking success or failure.
  • •.headers: Provides metadata about the response.
  • •.json(): Parses JSON into Python objects.
  • •.text: Raw string content for non-JSON responses.
Common Misconception

Assuming .json() will always work. Always check Content-Type header or status_code before calling .json(), as it will raise an error if the response is not valid JSON.

Key Takeaway

The response object is your comprehensive guide to an API's reply, offering status, headers, and parsed content for effective data handling.
