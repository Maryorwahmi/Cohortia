Basic Authentication with requests

Sending credentials securely with each request.

Python Code: Basic Authentication
import requests

# Example: Basic Authentication (using httpbin.org for testing)
try:
    auth_response = requests.get('https://httpbin.org/basic-auth/user/passwd', auth=('user', 'passwd'))
    print(f"Basic Auth Status Code: {auth_response.status_code}")
    if auth_response.status_code == 200:
        print("Basic Auth successful!")
    else:
        print("Basic Auth failed.")
except requests.exceptions.RequestException as e:
    print(f"Error during basic auth request: {e}")
How it Works
  • •Credentials (username:password) are base64 encoded.
  • •Sent in the Authorization header: Basic <encoded_credentials>.
  • •requests handles encoding and header creation automatically.
Security Note

Always use Basic Authentication over HTTPS to encrypt credentials in transit. Never hardcode sensitive information directly into your scripts; use environment variables.

Key Takeaway

Basic Authentication is easily implemented with requests using the auth parameter, but always ensure HTTPS and secure credential storage.
