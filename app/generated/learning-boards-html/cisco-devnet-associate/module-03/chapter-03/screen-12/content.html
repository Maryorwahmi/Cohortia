Authentication Methods

Token-based Authentication

Using API keys and OAuth tokens for access.

Python Code: Token Authentication
import requests

# Replace 'YOUR_API_TOKEN' with an actual token
api_token = 'YOUR_API_TOKEN_HERE'
headers = {
    'Content-Type': 'application/json',
    'Accept': 'application/json',
    'X-Auth-Token': api_token # Common header for token authentication
    # Or 'Authorization': f'Bearer {api_token}' for OAuth 2.0
}

# Example with a hypothetical Cisco DNA Center API endpoint
dna_center_url = 'https://<dna-center-ip>/dna/intent/api/v1/network-device'
try:
    # verify=False for self-signed certs in labs, use True in production
    dna_response = requests.get(dna_center_url, headers=headers, verify=False)
    print(f"DNA Center Status Code: {dna_response.status_code}")
    if dna_response.status_code == 200:
        print("Successfully retrieved DNA Center devices.")
    else:
        print(f"Error: {dna_response.text}")
except requests.exceptions.RequestException as e:
    print(f"Error during DNA Center request: {e}")
How it Works
  • •Obtain a token (API key, OAuth).
  • •Include token in a custom HTTP header (e.g., X-Auth-Token).
  • •Server validates token for access.
Security Note

Never hardcode API tokens. Use environment variables or secure configuration management. Avoid verify=False in production as it disables SSL certificate validation.

Key Takeaway

Token-based authentication uses custom headers to send API keys or OAuth tokens, offering robust and flexible security for modern APIs.
