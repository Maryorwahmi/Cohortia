Removing Data with DELETE Requests

Eliminating resources from the server.

Python Code: DELETE Request
import requests

# Example: Delete a post
delete_response = requests.delete('https://jsonplaceholder.typicode.com/posts/1')

print(f"DELETE Status Code: {delete_response.status_code}")
if delete_response.status_code == 200 or delete_response.status_code == 204: # 200 OK or 204 No Content
    print("Post 1 deleted successfully.")
else:
    print(f"Error deleting post: {delete_response.text}")
Key Aspects of DELETE
  • •Idempotent: Deleting a resource multiple times has the same effect as deleting it once (it remains deleted).
  • •No Body: Typically, DELETE requests do not send a request body.
  • •Success Codes: Common success codes are 200 (OK) or 204 (No Content).
Example Scenario

An automation script removes an outdated firewall policy or de-provisions a virtual network interface using a DELETE request to the relevant API endpoint.

Key Takeaway

requests.delete() is used to remove resources from an API, identified by their unique URL, and typically returns a 200 or 204 status code upon success.
