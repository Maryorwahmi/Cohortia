Retrieving Data with GET Requests

Fetching information from API endpoints.

Python Code: GET Request
import requests

# Example: Get information from a public API
response = requests.get('https://jsonplaceholder.typicode.com/posts/1')

# Check the status code
print(f"Status Code: {response.status_code}")

# Access response headers
print(f"Content-Type: {response.headers['Content-Type']}")

# Access the response body as JSON
if response.status_code == 200:
    post_data = response.json()
    print(f"Post Title: {post_data['title']}")
else:
    print(f"Error: {response.text}")
Key Aspects of GET
  • •Idempotent: Multiple identical GET requests have the same effect as a single one.
  • •Safe: Should not cause side effects on the server (e.g., changing data).
  • •Query Parameters: Can include parameters in the URL (e.g., ?userId=1) to filter data.
Example Scenario

A network engineer uses a GET request to retrieve the current interface status of a router from its management API, ensuring no configuration changes are made.

Key Takeaway

requests.get() is your primary method for safely fetching data from APIs, returning a response object rich with information.
