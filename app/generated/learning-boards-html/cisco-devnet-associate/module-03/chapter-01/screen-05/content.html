Architectural Style

REST: Representational State Transfer

An architectural style for scalable, efficient, and stateless web services, built around the concept of resources.

The Resource Concept
Resource

Network Interface

GigabitEthernet1

Any data or service identified by a URI.
A resource could be a VLAN, a routing table, or a device's configuration.
Uniform Resource Identifier (URI)
URI

/api/v1/devices/router1/interfaces/GigabitEthernet1

Unique address for a resource.
This URI uniquely identifies the GigabitEthernet1 interface on router1.
REST is an Architectural Style

It's a set of guiding principles, not a strict protocol, for designing networked applications that are scalable and efficient.

Key Takeaway

REST treats everything as a 'resource' identified by a unique URI, leveraging standard HTTP for communication.
