HTTP Verbs

Creating New Resources with POST

Used to submit data to a specified resource, often resulting in a new resource creation.

Purpose: Create New

Sends data to the server to create a new resource, typically under a collection URI.

Not Safe, Not Idempotent

POST requests modify server state (not safe). Sending the same request multiple times creates multiple resources (not idempotent).

Key Takeaway

Use POST exclusively for creating new resources. Be aware that it changes server state and is not repeatable without new effects.

POST /api/v1/vlans HTTP/1.1
Host: api.example.com
Content-Type: application/json

{
  "id": 100,
  "name": "Sales_VLAN"
}

// Server Response (Status 201 Created)
{
  "message": "VLAN 100 created successfully"
}
Example: Create a New VLAN

A POST request to `/api/v1/vlans` with a JSON body containing VLAN ID 100 and name 'Sales_VLAN' would create this new VLAN on the network device.
