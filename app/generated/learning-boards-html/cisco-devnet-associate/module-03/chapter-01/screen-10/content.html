HTTP Verbs

Removing Resources with DELETE

Used to remove a specified resource from the server, making it permanently unavailable.

Purpose: Erase Resource

Instructs the server to delete the resource identified by the given URI.

Idempotent

Deleting a resource multiple times has the same effect as deleting it once (the resource remains deleted).

Key Takeaway

DELETE is for permanent resource removal. Its idempotency ensures consistent results even with repeated requests.

DELETE /api/v1/vlans/200 HTTP/1.1
Host: api.example.com

// Server Response (Status 204 No Content)
Example: Delete a VLAN

A DELETE request to `/api/v1/vlans/200` would remove VLAN 200 from the network device's configuration. Subsequent DELETE requests to the same URI would yield the same result.
