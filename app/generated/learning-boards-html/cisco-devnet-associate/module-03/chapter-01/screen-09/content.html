HTTP Verbs

Partially Modifying Resources with PATCH

Applies incremental, partial changes to an existing resource, rather than replacing it entirely.

Purpose: Partial Update

Sends only the data fields that need to be modified, leaving other fields untouched.

Not Idempotent

Repeated PATCH requests might not yield the same result as the first, especially for relative changes.

Key Takeaway

Use PATCH for making specific, incremental changes to a resource. It's more efficient than PUT for minor updates.

PATCH /api/v1/devices/router1/interfaces/GigabitEthernet1 HTTP/1.1
Host: api.example.com
Content-Type: application/json

{
  "description": "Uplink to Core Switch"
}

// Server Response (Status 200 OK)
Example: Update Interface Description

A PATCH request to `/api/v1/devices/router1/interfaces/GigabitEthernet1` with only a 'description' field in the JSON body would update just that specific property of the interface.
