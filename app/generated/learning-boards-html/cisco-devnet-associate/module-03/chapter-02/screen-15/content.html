Key Concepts

Review the fundamental terms and ideas from this chapter.

JSON

A lightweight, human-readable data interchange format based on key-value pairs and ordered lists.

XML

A markup language for encoding documents in a human and machine-readable format, using a tree-like structure with elements and attributes.

Serialization

The process of converting a data structure or object into a format that can be easily stored or transmitted.

Summary Takeaway

JSON and XML are the two most common data formats for network APIs, and serialization is the process of preparing data for exchange.
