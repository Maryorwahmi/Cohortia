JSON Structure: Objects

Collections of key-value pairs, enclosed in curly braces.

JSON Object Definition

A JSON object is an unordered collection of key-value pairs. Keys must be strings, and values can be various data types.

  • Enclosed by curly braces: `{}`
  • Keys are strings, double-quoted: "key"
  • Values can be: strings, numbers, booleans, null, arrays, or other objects.
  • Key-value pairs separated by commas: "key": value,
Example: Device Info
{
  "device_name": "CiscoRouter1",
  "location": "Datacenter A",
  "enabled": true,
  "admin_contact": null
}

Key Takeaway

JSON objects use curly braces to define key-value pairs, where keys are strings and values can be any valid JSON data type.
