JSON Fundamentals

JSON Structure: Arrays and Nested Data

Ordered lists of values and how they combine with objects.

JSON Array Definition

A JSON array is an ordered list of values. Values are separated by commas.

  • Enclosed by square brackets: `[]`
  • Values can be any valid JSON data type.
  • Order is preserved.
Visualizing Nested Data
{Device Object
"name":"GigabitEthernet1"
"vlans":[Array of VLANs
10,20,30
]
}End of Object
Full Example: Network Interface
{
  "name": "GigabitEthernet1",
  "description": "Uplink to Core Switch",
  "ip_address": "192.168.1.1",
  "subnet_mask": "255.255.255.0",
  "enabled": true,
  "vlans": [10, 20, 30]
}
Key Takeaway

JSON arrays are ordered lists, and their ability to nest within objects allows for complex, hierarchical data representation.
