Python for JSON

Serializing JSON with `json.dumps()`

Converting Python dictionaries or lists into JSON strings.

Function Overview
  • `json.dumps(python_obj)`: Converts a Python object (dict, list) to a JSON string.
  • `indent` parameter: Adds whitespace for pretty-printing (e.g., `indent=2`).
  • Essential for sending data to RESTful APIs.
Why it matters

When configuring devices or updating services via APIs, you need to send data in a JSON format. `json.dumps()` handles this conversion.

Python Code Example
import json

# Python dictionary to be sent to an API
new_interface_config = {
    "name": "Loopback0",
    "description": "Management interface",
    "ip_address": "10.0.0.1",
    "enabled": True
}

# Serializing Python dictionary to JSON string
json_output_string = json.dumps(new_interface_config, indent=2)

print("
New Interface JSON:")
print(json_output_string)
Output
New Interface JSON:
{
  "name": "Loopback0",
  "description": "Management interface",
  "ip_address": "10.0.0.1",
  "enabled": true
}
Key Takeaway

`json.dumps()` converts Python objects into JSON strings, enabling your application to send structured data to APIs.
