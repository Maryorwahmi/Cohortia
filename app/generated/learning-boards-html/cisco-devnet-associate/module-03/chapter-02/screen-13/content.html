Creating and Modifying XML with `ElementTree`

Building and updating XML documents programmatically in Python.

Key Functions
  • `ET.Element('tag')`: Creates a new XML element.
  • `ET.SubElement(parent, 'tag')`: Creates a child element for a given parent.
  • `element.text = 'content'`: Sets the text content of an element.
  • `ET.tostring(element, encoding='unicode')`: Converts an `ElementTree` object back to an XML string.
Python Code Example
import xml.etree.ElementTree as ET

# Creating new XML
new_root = ET.Element("configuration")
interface_elem = ET.SubElement(new_root, "interface")
ET.SubElement(interface_elem, "name").text = "Loopback0"
ET.SubElement(interface_elem, "description").text = "Management interface"
ET.SubElement(interface_elem, "ip_address").text = "10.0.0.1"

# Serializing ElementTree object to XML string
xml_output_string = ET.tostring(new_root, encoding='unicode')
print("
New Interface XML:")
print(xml_output_string)
Output
New Interface XML:
<configuration><interface><name>Loopback0</name><description>Management interface</description><ip_address>10.0.0.1</ip_address></interface></configuration>
Key Takeaway

`ElementTree` allows you to build XML structures with `ET.Element()` and `ET.SubElement()`, then convert them to strings with `ET.tostring()`.
