Parsing XML with `xml.etree.ElementTree`

Navigating XML documents as a tree of elements to extract data.

Module Overview
  • `import xml.etree.ElementTree as ET`: Standard import.
  • `ET.fromstring(xml_string)`: Parses an XML string, returns the root element.
  • `element.find('tag')`: Finds the first child element with the given tag.
  • `element.findall('tag')`: Finds all child elements with the given tag.
  • `element.text`: Accesses the text content of an element.
Python Code Example
import xml.etree.ElementTree as ET

xml_data_string = '''
<device>
  <name>CiscoRouter1</name>
  <interfaces>
    <interface><name>G1</name><status>up</status></interface>
    <interface><name>G2</name><status>down</status></interface>
  </interfaces>
</device>
'''

root = ET.fromstring(xml_data_string)
device_name = root.find('name').text
print(f"Device Name: {device_name}")

for iface in root.find('interfaces').findall('interface'):
    name = iface.find('name').text
    status = iface.find('status').text
    print(f"  Interface: {name}, Status: {status}")
Output
Device Name: CiscoRouter1
  Interface: G1, Status: up
  Interface: G2, Status: down
Key Takeaway

`ET.fromstring()` parses XML into a tree, allowing `find()`, `findall()`, and `.text` to extract specific data.
