Deserializing JSON with `json.loads()`

Converting JSON strings into Python dictionaries or lists.

Function Overview
  • `json.loads(json_string)`: Parses a JSON string.
  • Returns a Python dictionary if the JSON is an object.
  • Returns a Python list if the JSON is an array.
  • Essential for consuming data from RESTful APIs.
Why it matters

API responses are often JSON strings. `json.loads()` makes this data accessible and manipulable within your Python applications.

Python Code Example
import json

json_data_string = '''
{
  "device_name": "CiscoRouter1",
  "interfaces": [
    {"name": "GigabitEthernet1", "status": "up"}
  ]
}
'''

# Deserializing JSON string to Python dictionary
device_info = json.loads(json_data_string)

print(f"Device Name: {device_info['device_name']}")
print(f"Interface 1 Status: {device_info['interfaces'][0]['status']}")
Output
Device Name: CiscoRouter1
Interface 1 Status: up
Key Takeaway

`json.loads()` converts a JSON string into a Python dictionary or list, enabling programmatic access to API data.
