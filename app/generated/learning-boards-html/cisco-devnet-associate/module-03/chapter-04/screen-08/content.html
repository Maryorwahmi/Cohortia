NETCONF in Action: Retrieving Configuration

Using get-config to fetch interface details via XML

Understanding the Request

  • <rpc>: The root element for all NETCONF operations.
  • <get-config>: Specifies the operation to retrieve configuration.
  • <source><running/></source>: Targets the active configuration datastore.
  • <filter type="subtree">: Narrows the request to specific data.
  • <interface><name>GigabitEthernet1</name></interface>: Specifies the exact interface to retrieve.

Why Use a Filter?

Using a filter with get-config is crucial for efficiency. Instead of fetching the entire device configuration, which can be very large, a filter allows you to retrieve only the specific data you need, reducing network traffic and processing load on both the client and the device.

<rpc message-id="101" xmlns="urn:ietf:params:xml:ns:netconf:base:1.0"> <get-config> <source> <running/> </source> <filter type="subtree"> <interfaces xmlns="urn:ietf:params:xml:ns:yang:ietf-interfaces"> <interface> <name>GigabitEthernet1</name> </interface> </interfaces> </filter> </get-config></rpc>
Key Takeaway

NETCONF's get-config with XML filters provides a precise and efficient way to retrieve specific configuration data from network devices.
