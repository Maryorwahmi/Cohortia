RESTCONF in Action: Updating Configuration

Using HTTP PATCH to modify interface descriptions via JSON

Understanding the `PATCH` Request

  • PATCH: HTTP method for partial resource modification.
  • /restconf/data/...: Base URI for YANG data.
  • ietf-interfaces:interfaces/interface=GigabitEthernet1: YANG-derived path to the specific interface.
  • Content-Type: application/yang-data+json: Essential header indicating JSON payload conforms to YANG.
  • JSON Body: Contains only the fields to be updated (e.g., description).

Efficiency of PATCH

The PATCH method is highly efficient for updates because it only requires sending the specific fields that need to be changed, rather than the entire resource representation. This minimizes bandwidth usage and processing overhead, especially for frequent, small modifications.

PATCH /restconf/data/ietf-interfaces:interfaces/interface=GigabitEthernet1 HTTP/1.1 Host: network-device.example.com Content-Type: application/yang-data+json Accept: application/yang-data+json { "ietf-interfaces:interface": { "description": "Management Link" } }
Key Takeaway

RESTCONF's PATCH method provides a lightweight and efficient way to perform partial updates on network configurations using JSON over HTTP.
