YANG: The Universal Language for Network Data

Defining structure and semantics for consistent network configuration

What is YANG?

  • Yet Another Next Generation.
  • A data modeling language, not a protocol.
  • Defines structure and semantics of configuration and state data.
  • Acts as a blueprint for network device data.

Ensuring Consistency

YANG ensures that data exchanged between automation tools and network devices is always consistent and valid, regardless of the underlying protocol (NETCONF or RESTCONF) or device vendor. This is crucial for interoperability and reliable automation.

YANG Data Model

A schema that defines how network configuration and state data should be structured.

Data Structure

Defines hierarchy and types.

Semantics & Constraints

Ensures valid data values.

Example: A YANG model defines an interface's name as a string and its speed as an integer, ensuring all devices use these types.
