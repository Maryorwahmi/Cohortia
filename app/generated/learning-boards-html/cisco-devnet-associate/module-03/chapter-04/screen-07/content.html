NETCONF Operations

Transactional Control with NETCONF Datastores

Managing configuration states with explicit operations and datastores

Key NETCONF Operations

  • get-config: Retrieve configuration data.
  • edit-config: Modify configuration data.
  • commit: Apply changes from candidate to running.
  • rollback: Revert to a previous configuration state.

The Safety of Transactions

NETCONF's transactional model ensures that configuration changes are atomic. You can stage multiple changes, validate them, and then apply them as a single unit. If any part fails, the entire transaction can be rolled back, preventing partial or inconsistent configurations.
