Key Concepts

Essential terms to remember from this chapter

NETCONF

An IETF standard protocol for network device configuration management, typically over SSH, using XML-based RPCs.

RESTCONF

A REST-like protocol for network device configuration management, typically over HTTP/HTTPS, using HTTP methods and supporting JSON/XML.

YANG

A data modeling language used by NETCONF and RESTCONF to define the structure and constraints of configuration and state data.

Summary Takeaway

NETCONF and RESTCONF are the primary APIs for network automation, with YANG providing the essential data modeling foundation for both.
