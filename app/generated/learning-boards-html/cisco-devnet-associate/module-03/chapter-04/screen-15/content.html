Key Concepts Continued

Further essential terms for network automation

RPC

Remote Procedure Call: A software communication paradigm where a client causes a procedure to execute on a remote network device.

Datastore

In NETCONF/RESTCONF, a repository for configuration data (e.g., running, startup, candidate).

Commit (NETCONF)

An RPC operation to apply changes from the candidate datastore to the running datastore, making them active.

Summary Takeaway

Understanding RPCs, datastores, and the commit operation is crucial for mastering the transactional and state management capabilities of network APIs.
