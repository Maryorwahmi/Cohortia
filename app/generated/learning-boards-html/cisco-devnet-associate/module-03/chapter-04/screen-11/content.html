RESTCONF Operations

RESTCONF: URI Mapping and HTTP Methods

Interacting with network resources using a RESTful approach

Key RESTCONF Concepts

  • URI Structure: YANG models translate into hierarchical URIs.
  • HTTP Methods: Standard verbs for CRUD operations.
  • Resources: Network elements (interfaces, VLANs) exposed as addressable resources.
  • Stateless: Each request from client to server contains all necessary information.

YANG to URI Mapping

RESTCONF automatically maps YANG data models into a logical URI structure. For instance, a YANG container for 'interfaces' becomes a path segment, and a specific 'interface' identified by its name becomes a resource at the end of the URI, making it intuitive to navigate and address network elements.

RESTCONF Interaction Flow

1. YANG Model Defines Data

Structure of network elements

2. URI Maps to Resource

e.g., /restconf/data/ietf-interfaces:interfaces/interface=GigabitEthernet1

3. HTTP Method Interacts

GET, PUT, PATCH, DELETE

4. Device Responds

JSON/XML payload
