RESTCONF: RESTful Network Configuration

Bringing web service simplicity to network device management

Key Characteristics of RESTCONF

  • REST-like: Leverages principles of RESTful web services.
  • Transport: Uses HTTP or HTTPS for communication.
  • Data Encoding: Supports JSON (common) and XML.
  • Operational Model: Uses standard HTTP methods (GET, POST, PUT, PATCH, DELETE).

Web-Friendly Approach

RESTCONF's use of HTTP/HTTPS and JSON makes it highly compatible with existing web development toolchains and practices. This lowers the barrier to entry for developers familiar with web APIs, accelerating network automation adoption.
