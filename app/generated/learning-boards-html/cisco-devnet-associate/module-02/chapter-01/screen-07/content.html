Dictionaries: Key-Value Pairs
Representing Structured Network Data

Dictionaries store data as key-value pairs, offering a structured way to represent information.

Definition: An unordered, mutable collection of key-value pairs, defined using curly braces `{}`.

Use Cases in Networking:

  • Storing device attributes: `{'hostname': 'router1', 'ip': '192.168.1.1', 'model': 'ISR 4331'}`
  • Representing configuration parameters.
  • Processing data from APIs or JSON files.

Accessing Values: Use the key. `device['ip']` retrieves the IP address.

Mutability: Key-value pairs can be added, removed, or updated.

Dictionary Examples
# Device information dictionary
router_config = {
    'hostname': 'core-router-01',
    'ip_address': '10.0.0.1',
    'os': 'Cisco IOS XR',
    'uptime_days': 30
}

# Accessing values
hostname = router_config['hostname']  # 'core-router-01'
current_os = router_config['os']      # 'Cisco IOS XR'

# Adding a new key-value pair
router_config['location'] = 'Data Center A'

# Updating a value
router_config['uptime_days'] = 31
Dictionaries provide labeled access to structured network data.
