Conditional Statements
Making Decisions in Your Scripts

Conditional statements allow scripts to execute different code blocks based on whether conditions are true or false.

Structure:

  • if condition: - Executes if the condition is true.
  • elif another_condition: - Executes if the previous `if` or `elif` was false, and this condition is true.
  • else: - Executes if all preceding `if` and `elif` conditions were false.

Networking Example: Check interface status before configuration.

if status == 'up': print('Interface is operational.') else: print('Interface is down.')

These enable scripts to adapt to varying network states and device behaviors.

Conditional Logic Example
# Example: Checking device reachability

device_status = 'reachable'

if device_status == 'reachable':
    print('Device is online and accessible.')
elif device_status == 'unreachable':
    print('WARNING: Device is offline or unreachable!')
else:
    print('Device status is unknown.')

# Example: Checking interface speed
interface_speed = 1000 # Mbps

if interface_speed >= 1000:
    print('High-speed connection detected.')
elif interface_speed >= 100:
    print('Standard speed connection.')
else:
    print('Low-speed connection.')
Conditionals drive intelligent automation.
