Parsing Network Output
Extracting Information with Python

Parsing CLI output is a fundamental network automation task. Python excels at processing text data.

Process Overview:

  • Obtain device output (e.g., from `show ip interface brief`).
  • Split the output into individual lines using `.splitlines()` or `.split(' ')`.
  • Iterate through lines using a `for` loop.
  • Split each line into parts using `.split()` (whitespace delimited).
  • Extract relevant data (interface name, IP, status).
  • Store extracted data in structured formats like lists of dictionaries.

This enables automated inventory, health checks, and troubleshooting.

Parsing Example
# Simplified 'show ip interface brief' output
output = ""
Interface              IP-Address      OK? Method Status                Protocol
GigabitEthernet1       192.168.1.1     YES manual up                    up
GigabitEthernet2       unassigned      YES unset  administratively down down
Loopback0              10.0.0.1        YES manual up                    up
"

interfaces_data = []

# Split into lines and skip header
lines = output.strip().split('
')
for line in lines[1:]:
    parts = line.split()
    if len(parts) >= 6:
        name = parts[0]
        ip = parts[1]
        status = parts[4]
        protocol = parts[5]
        
        # Store active interfaces
        if status == 'up' and protocol == 'up':
            interfaces_data.append({
                'name': name,
                'ip_address': ip,
                'status': status
            })

print(interfaces_data)
# Output: [{'name': 'GigabitEthernet1', 'ip_address': '192.168.1.1', 'status': 'up'}, {'name': 'Loopback0', 'ip_address': '10.0.0.1', 'status': 'up'}]
