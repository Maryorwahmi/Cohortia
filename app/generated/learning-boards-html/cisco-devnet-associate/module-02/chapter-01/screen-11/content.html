Indentation and Type Errors
Avoiding Common Python Mistakes

Two common errors for beginners are incorrect indentation and type mismatches.

1. Indentation Errors (`IndentationError`):

  • Python uses whitespace (spaces/tabs) to define code blocks (e.g., inside `if`, `for`, functions).
  • Inconsistent or incorrect indentation will cause errors.
  • Best Practice: Use 4 spaces consistently per indentation level.

2. Type Mismatch Errors (`TypeError`):

  • Occurs when performing operations on incompatible data types (e.g., string + integer).
  • Fix: Explicitly convert types using `str()`, `int()`, `float()`, `bool()`.
  • Example: `print('Count: ' + str(5))` is correct.

Pay attention to these to write reliable scripts.

Code Snippet Examples
# Incorrect Indentation (will cause error)
# if True:
# print('This is indented incorrectly')

# Correct Indentation
if True:
    print('This is correctly indented')

# Type Mismatch (will cause error)
# device_count = 10
# print('Total devices: ' + device_count)

# Correct Type Conversion
device_count = 10
print('Total devices: ' + str(device_count))

# Another example
port_speed_str = '1000'
port_speed_int = int(port_speed_str) # Convert string to integer
print(f'Port speed is {port_speed_int} Mbps')
Consistent indentation and type awareness are key.
