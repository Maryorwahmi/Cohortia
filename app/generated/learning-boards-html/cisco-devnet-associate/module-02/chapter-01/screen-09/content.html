Loops: Iterating Over Data
Automating Repetitive Network Tasks

Loops automate repetitive actions, crucial for managing multiple network devices or data points.

`for` Loops: Iterate over sequences (lists, dictionaries). Ideal when the number of iterations is known or you need to process each item.

Example: `for device in devices: print(f'Processing {device}')`

`while` Loops: Execute code as long as a condition is true. Useful for polling or waiting for events.

Example: `while not service_is_up: time.sleep(5)`

Loops enable concise and powerful scripts for large-scale network operations.

Looping Examples
# For loop iterating over a list of IPs
ip_addresses = ['192.168.1.1', '192.168.1.2', '192.168.1.3']

print('Checking IP status:')
for ip in ip_addresses:
    # In a real script, you'd ping or check status here
    print(f' - Checking {ip}...')
