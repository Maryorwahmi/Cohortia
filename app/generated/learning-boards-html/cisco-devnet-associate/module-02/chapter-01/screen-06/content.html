Lists: Ordered Collections
Storing Sequences of Network Items

Lists are fundamental Python data structures for storing ordered collections of items.

Definition: An ordered, mutable sequence of elements, defined using square brackets `[]`.

Use Cases in Networking:

  • Storing a list of hostnames to configure: `devices = ['router1', 'switchA', 'firewallB']`
  • Keeping track of interface names: `interfaces = ['Gi0/1', 'Gi0/2', 'Fa0/1']`
  • Holding a sequence of commands to execute.

Accessing Elements: Use zero-based indexing. `devices[0]` retrieves the first item.

Mutability: Elements can be added, removed, or changed after creation (e.g., `devices.append('serverX')`).

List Examples
# List of device hostnames
network_devices = ['router1', 'switchA', 'firewallB', 'accesspointC']

# List of interface names
interface_names = ['GigabitEthernet0/1', 'GigabitEthernet0/2', 'FastEthernet0/1']

# Accessing an element (first device)
first_device = network_devices[0]  # 'router1'

# Adding an element
network_devices.append('serverX')

# Modifying an element
interface_names[2] = 'GigabitEthernet0/3' # Replaces 'FastEthernet0/1'
Lists are versatile for managing ordered network data.
