Fundamental Data Types
Building Blocks for Network Data

Python uses various data types to represent information. Understanding these is key for network automation.

Strings (`str`): Sequences of characters for hostnames, IPs, commands. Example: `hostname = 'router1'`.

Integers (`int`): Whole numbers for port numbers, counts. Example: `port_number = 22`.

Floats (`float`): Numbers with decimals for bandwidth, metrics. Example: `bandwidth_mbps = 1000.0`.

Booleans (`bool`): True/False values for states. Example: `is_interface_up = True`.

These types are the basic units for processing network data, like parsing interface status or device configurations.

Data Type Examples
# Strings
interface_name = "GigabitEthernet0/1"
management_ip = "192.168.1.1"

# Integers
port_speed_mbps = 1000
vlan_id = 10

# Floats
latency_ms = 5.75
utilization_percent = 75.5

# Booleans
is_up = True
is_enabled = False
Python infers types, but knowing them is vital for operations.
