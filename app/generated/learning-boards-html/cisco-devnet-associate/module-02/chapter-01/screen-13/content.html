Writing Your First Network Script
Putting Concepts into Practice

Let's combine core Python concepts into a practical network script to check device status.

Script Components:

  • List of Dictionaries: Store device info (hostname, IP, status).
  • Function (`check_device_status`): Takes device data, checks status using `if/else`.
  • `for` Loop: Iterates through the list, calling the function for each device.

This script demonstrates how lists, dictionaries, functions, and conditionals work together for automation.

Key Steps: Define data, create a checking function, loop and execute.

Sample Script Logic
# Sample device data
devices = [
    {'hostname': 'router1', 'ip': '192.168.1.1', 'status': 'reachable'},
    {'hostname': 'switchA', 'ip': '192.168.1.10', 'status': 'unreachable'},
    {'hostname': 'firewallB', 'ip': '192.168.1.20', 'status': 'reachable'}
]

# Function to check status
def check_device_status(device_data):
    hostname = device_data['hostname']
    status = device_data['status']
    
    if status == 'reachable':
        print(f"✅ Device {hostname} is UP.")
    else:
        print(f"❌ WARNING: Device {hostname} is DOWN!")

# Loop through devices and check status
print("--- Device Status Check ---")
for device in devices:
    check_device_status(device)
