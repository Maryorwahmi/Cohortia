Defining Functions
Writing Reusable and Modular Code

Functions are named blocks of code that perform specific tasks, promoting organization and reuse.

Definition: Use the `def` keyword, followed by a function name, parentheses `()`, and a colon `:`. Indent the code block.

Parameters: Functions can accept input values (e.g., `def my_func(param1, param2):`).

Return Values: Use `return` to send output back from the function.

Benefits:

  • Reusability: Write once, use many times.
  • Modularity: Break down complex tasks into smaller parts.
  • Readability: Clear function names improve code understanding.

Essential for building maintainable network automation scripts.

Function Definition Example
# Function to get device uptime
def get_device_uptime(device_hostname):
    # In a real scenario, this would involve SSH and command execution
    print(f"Fetching uptime for {device_hostname}...")
    # Simulate returning uptime data
    if device_hostname == 'router1':
        return "30 days, 5 hours"
    else:
        return "Unknown uptime"

# Calling the function
router1_uptime = get_device_uptime('router1')
print(f"Router1 uptime: {router1_uptime}")

other_device_uptime = get_device_uptime('switchA')
print(f"SwitchA uptime: {other_device_uptime}")
Functions make your code organized and efficient.
