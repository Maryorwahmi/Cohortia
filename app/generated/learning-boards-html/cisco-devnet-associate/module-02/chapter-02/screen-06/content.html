Persisting Data: Writing to Files

Saving Configuration and Report Data

File Write Modes

  • •'w' (Write): Creates a new file or overwrites an existing one. Use with caution!
  • •'a' (Append): Adds new content to the end of an existing file. Creates if not exists.
  • •'x' (Exclusive Creation): Creates a new file, but fails if the file already exists.
Warning

Using 'w' mode will erase existing file content. Always back up or confirm before overwriting critical data.

Code Example: Writing Configuration
config_data = "hostname Router1
interface GigabitEthernet0/1
 ip address 192.168.1.1 255.255.255.0"
with open('new_config.txt', 'w') as f:
    f.write(config_data)
Terminal Output (after `cat new_config.txt`)
hostname Router1
interface GigabitEthernet0/1
 ip address 192.168.1.1 255.255.255.0
Key Takeaway

Writing to files allows your scripts to generate dynamic configurations and reports, making them powerful tools for network management.
