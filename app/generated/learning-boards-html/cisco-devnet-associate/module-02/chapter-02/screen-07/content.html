Structured Data Format

JSON: The Language of APIs

Lightweight Data Interchange for Network Devices

Key Characteristics of JSON

  • •Lightweight: Minimal syntax for efficient data transfer.
  • •Human-Readable: Easy for developers to understand and write.
  • •Machine-Parsable: Simple for programs to generate and interpret.
  • •API Standard: The lingua franca for RESTful APIs in network controllers.
JSON Structure Example
{
  "device": "router1",
  "ip": "192.168.1.1",
  "interfaces": [
    "GigabitEthernet0/1",
    "Loopback0"
  ],
  "status": "active"
}
JSON Building Blocks

Objects

{ "key": "value" }
Name/value pairs (Python dicts)

Arrays

[ "value1", "value2" ]
Ordered lists (Python lists)

Key Takeaway

JSON is the standard for API communication, using simple object and array structures to facilitate data exchange between systems.
