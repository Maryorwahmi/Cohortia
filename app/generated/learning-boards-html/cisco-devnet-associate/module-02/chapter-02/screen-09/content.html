Saving Python Data as JSON

Converting Python Objects to JSON Strings and Files

Serialization Functions

  • •json.dump(python_object, file_object): Writes a Python object to a file as JSON.
  • •json.dumps(python_object): Converts a Python object to a JSON formatted string.
Pro Tip

Use indent=4 with json.dump() for human-readable, pretty-printed JSON output in files.

Code Example: Saving to a JSON File
import json

new_device = {
    'hostname': 'switchA',
    'location': 'Building A, Floor 2',
    'model': 'Cisco Catalyst 9300',
    'status': 'active'
}
with open('new_device.json', 'w') as f:
    json.dump(new_device, f, indent=4)
Terminal Output (after `cat new_device.json`)
{
    "hostname": "switchA",
    "location": "Building A, Floor 2",
    "model": "Cisco Catalyst 9300",
    "status": "active"
}
Key Takeaway

Use json.dump() to save Python objects to JSON files and json.dumps() to get a JSON string, often with indent=4 for readability.
