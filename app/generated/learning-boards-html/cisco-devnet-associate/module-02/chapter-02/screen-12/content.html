Saving Python Data as YAML

Converting Python Objects to YAML Files

Serialization with PyYAML

  • •yaml.dump(python_object, stream): Writes a Python object to a file or returns a YAML string.
  • •default_flow_style=False: Ensures block-style YAML output, which is more readable.
Pro Tip

Block-style YAML is generally preferred for configuration files due to its enhanced readability.

Code Example: Saving to a YAML File
import yaml

new_config = {
    'interface': 'GigabitEthernet0/1',
    'description': 'Uplink to Core',
    'ip_address': '10.0.0.1/24',
    'enabled': True
}
with open('interface_config.yaml', 'w') as f:
    yaml.dump(new_config, f, default_flow_style=False)
Terminal Output (after `cat interface_config.yaml`)
description: Uplink to Core
enabled: true
interface: GigabitEthernet0/1
ip_address: 10.0.0.1/24
Key Takeaway

Use yaml.dump() with default_flow_style=False to create readable, block-style YAML files from Python objects.
