Loading YAML Data into Python

Parsing YAML Files and Strings with PyYAML

Deserialization with PyYAML

  • •yaml.load(stream, Loader=yaml.FullLoader): Reads YAML data from a file-like object or string.
  • •yaml.FullLoader: A secure loader that prevents arbitrary code execution from untrusted YAML sources.
Security Alert

Always use Loader=yaml.FullLoader to mitigate security risks when loading YAML from untrusted sources.

Code Example: Loading YAML from a String
import yaml

yaml_string = """
devices:
  - hostname: router1
    ip: 192.168.1.1
    platform: ios
  - hostname: switchA
    ip: 192.168.1.10
    platform: nxos
"""
network_inventory = yaml.load(yaml_string, Loader=yaml.FullLoader)
print(f"First device hostname: {network_inventory['devices'][0]['hostname']}")
Terminal Output
First device hostname: router1
Key Takeaway

Use yaml.load() with Loader=yaml.FullLoader to safely convert YAML data into Python objects for processing.
