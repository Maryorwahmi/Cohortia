Loading JSON Data into Python

Converting JSON Strings and Files to Python Objects

Deserialization Functions

  • •json.load(file_object): Reads JSON data from a file and converts it to a Python object.
  • •json.loads(string): Parses a JSON formatted string and converts it to a Python object (the 's' is for string).
Pro Tip

Always import the json module at the beginning of your script: import json.

Code Example: Loading JSON from a String
import json

json_string = '{"device": "router1", "ip": "192.168.1.1", "interfaces": ["GigabitEthernet0/1", "Loopback0"]}'
device_data = json.loads(json_string)
print(f"Device hostname: {device_data['device']}")
Terminal Output
Device hostname: router1
Key Takeaway

Use json.loads() for JSON strings and json.load() for JSON files to convert external JSON data into usable Python objects.
