Requests: Interacting with RESTful APIs

The Standard for HTTP Communication

Seamless HTTP Communication for APIs

The Requests library simplifies sending HTTP requests, making it the go-to tool for interacting with RESTful APIs of modern network devices and controllers.

Key Takeaway

Requests is crucial for modern network automation, enabling programmatic interaction with API-driven network platforms.

Why Requests?

  • Simplifies HTTP requests (GET, POST, PUT, DELETE).
  • Handles complex aspects like authentication and sessions.
  • Widely adopted and well-documented.
  • Not network-specific, but essential for network APIs.

Network API Examples

Cisco DNA Center, Meraki, ACI, SD-WAN solutions all expose REST APIs that can be controlled with Requests.

Analogy

If network devices are like smart appliances, Requests is the universal remote control that lets you send commands to them via their digital interfaces.
