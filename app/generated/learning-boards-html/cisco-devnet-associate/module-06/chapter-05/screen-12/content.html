Simulating CI: Syntax and Dry Run Checks

Validate Ansible playbooks for syntax errors and preview changes without actual deployment.

Ansible Playbook: loopback_config.yml

---
- name: Configure Loopback0 on router
  hosts: my_router
  gather_facts: no
  connection: network_cli

  tasks:
    - name: Ensure Loopback0 interface is configured
      cisco.ios.ios_interfaces:
        config:
          - name: Loopback0
            description: "Management Interface"
            ipv4:
              - address: 10.0.0.1
                netmask: 255.255.255.0
        state: merged
Key Takeaway

Early syntax and dry run checks are critical for catching errors and understanding potential impacts before any changes are applied to the network.

Terminal Output

# Simulate CI Syntax Check

$ ansible-playbook -i inventory.ini loopback_config.yml --syntax-check
