Continuous Delivery: Automating Releases

Continuous Delivery extends CI by automating the release of validated code to production environments, making deployments faster and more reliable.

Automated Release Preparation

After successful integration and testing, changes are automatically prepared for deployment, creating artifacts or making code available for release.

One-Click Deployment

Validated code is ready for deployment to production at any time, often with a simple, manual trigger, reducing deployment friction.

Continuous Deployment (Advanced)

An extension where changes are automatically deployed to production without manual intervention, requiring high confidence in automation.

Process Flow
Code Commit (CI)
Automated Tests (CI)
Ready for Deployment (CD)
Key Takeaway

Continuous Delivery ensures that your network automation code is always in a deployable state, ready for rapid and reliable release to production, significantly accelerating change cycles.
