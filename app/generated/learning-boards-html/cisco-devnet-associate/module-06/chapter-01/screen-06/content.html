Idempotency in VLAN Configuration

Ensuring Desired State for Network Services

When automating VLAN creation, an idempotent script first checks if the VLAN exists and if its parameters match the desired state before making any changes.

  • Check Existence: Query the device to see if the VLAN ID is already present.
  • Verify Parameters: If the VLAN exists, compare its current name with the desired name.
  • Conditional Action: Only create the VLAN if it doesn't exist, or update its name if it's incorrect.
  • No Change if Match: If the VLAN exists and is correctly configured, the script takes no action.
Key Takeaway

Idempotent VLAN configuration prevents duplicate entries and ensures the network state is consistently aligned with the automation's intent, even with repeated runs.

Code Walkthrough: Idempotent VLAN
def configure_vlan(net_connect, vlan_id, vlan_name):
    # 1. Check current VLAN state
    output = net_connect.send_command(f"show vlan id {vlan_id} | json")
    vlan_data = json.loads(output)

    if str(vlan_id) in vlan_data.get('vlans', {}):
        current_vlan = vlan_data['vlans'][str(vlan_id)]
        # 2. Compare with desired state
        if current_vlan.get('name') == vlan_name:
            print(f"VLAN {vlan_id} already correct.")
        else:
            # 3. Apply minimal change if discrepancy
            print(f"Updating VLAN {vlan_id} name.")
            net_connect.send_config_set([f"vlan {vlan_id}", f"name {vlan_name}"])
    else:
        # 4. Create if not exists
        print(f"Creating VLAN {vlan_id}.")
        net_connect.send_config_set([f"vlan {vlan_id}", f"name {vlan_name}"])
