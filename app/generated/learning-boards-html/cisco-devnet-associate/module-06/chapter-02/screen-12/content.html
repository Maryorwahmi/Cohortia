Automating Interface Configuration with Ansible

Apply your knowledge to configure multiple interfaces on a Cisco IOS-XE router.

`ios_interfaces` Module

Used to configure interface properties like description and administrative state (enabled: true).

`state: merged`

Ensures that specified configurations are merged with existing ones, preventing unintended overwrites.

Saving Configuration

The `ios_config` module with `save_when: modified` ensures changes are persisted only if applied.

Key Takeaway

Automating interface configurations with Ansible provides a scalable, consistent, and error-resistant method for managing network device settings.

configure_interfaces.ymlYAML
---
- name: Configure interfaces on Cisco IOS-XE routers
  hosts: routers
  gather_facts: no
  connection: network_cli

  tasks:
    - name: Configure GigabitEthernet1
      cisco.ios.ios_interfaces:
        config:
          - name: GigabitEthernet1
            description: "Uplink to Core"
            enabled: true
        state: merged
      register: interface1_result

    - name: Configure GigabitEthernet2
      cisco.ios.ios_interfaces:
        config:
          - name: GigabitEthernet2
            description: "Connects to Servers"
            enabled: true
        state: merged
      register: interface2_result

    - name: Save configuration
      cisco.ios.ios_config:
        save_when: modified
