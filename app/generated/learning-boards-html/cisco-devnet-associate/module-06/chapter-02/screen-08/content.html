Configuring VLANs with an Ansible Playbook

Walk through a playbook that uses the ios_vlan module to manage VLANs on Cisco IOS-XE.

Targeting Hosts

The hosts: switches directive ensures the playbook runs only on devices in the 'switches' group.

Using `ios_vlan` Module

The cisco.ios.ios_vlan module is used to ensure VLAN 100 exists with the name 'Automation_VLAN' and state: present.

Key Takeaway

Ansible playbooks leverage specific network modules like ios_vlan to declaratively configure network devices, ensuring idempotency and simplifying complex tasks.

configure_vlan.ymlYAML
# configure_vlan.yml
---
- name: Configure VLAN on Cisco IOS-XE switches
  hosts: switches # Targets the 'switches' group from inventory.ini
  gather_facts: no # Not needed for simple config, speeds up execution
  connection: network_cli

  tasks:
    - name: Ensure VLAN 100 exists and is named 'Automation_VLAN'
      cisco.ios.ios_vlan:
        vlan_id: 100
        name: Automation_VLAN
        state: present # Ensures the VLAN exists
      register: vlan_result

    - name: Print VLAN configuration status
      debug:
        msg: "VLAN 100 configuration status: {{ vlan_result.changed }}"
