Crafting Your First Inventory File

Explore the structure of a basic inventory.ini file for network devices.

Groups & Hosts

Devices are organized into groups (e.g., [routers]) with individual host entries.

Host Variables

Each host can have specific variables like ansible_host, ansible_user, and ansible_network_os.

Global Variables

The [all:vars] section defines variables that apply to all managed nodes, such as connection type and privilege escalation.

Common Mistake

Hardcoding sensitive credentials directly in the inventory. Always use Ansible Vault for passwords and API keys.

inventory.iniYAML
# inventory.ini

[routers]
router1.example.com ansible_host=192.168.1.1 ansible_user=admin ansible_password=cisco ansible_network_os=ios
router2.example.com ansible_host=192.168.1.2 ansible_user=admin ansible_password=cisco ansible_network_os=ios

[switches]
switch1.example.com ansible_host=192.168.1.10 ansible_user=admin ansible_password=cisco ansible_network_os=ios
switch2.example.com ansible_host=192.168.1.11 ansible_user=admin ansible_password=cisco ansible_network_os=ios

[all:vars]
ansible_connection=network_cli
ansible_become=yes
ansible_become_method=enable
ansible_become_pass=cisco
