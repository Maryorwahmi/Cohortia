Encrypting Secrets with Ansible Vault

Protecting Sensitive Data in Your Automation Workflows

Step 1: Create Plain-Text Secrets File
# vars/secrets.yml
device_username: automation_user
device_password: SuperSecurePassword!
Step 2: Encrypt the Secrets File
# Terminal Command
ansible-vault encrypt vars/secrets.yml

# Output:
New Vault password: [Enter a strong password]
Confirm New Vault password: [Confirm password]
Encryption successful
Pro Tip

Always use a strong, unique password for your Ansible Vault. Consider using a password manager to store your vault password securely.

Key Takeaway

Use `ansible-vault encrypt` to secure sensitive variables, preventing plain-text exposure in your project files.
