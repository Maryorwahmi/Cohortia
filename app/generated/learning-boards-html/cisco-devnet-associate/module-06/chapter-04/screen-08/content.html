Running Playbooks with Vaulted Credentials

Securely Executing Automation Tasks with Encrypted Secrets

Terminal Command to Run Playbook
# Execute the playbook, prompting for vault password
ansible-playbook -i inventory.ini create_user.yml --ask-vault-pass
Expected Output (Password Prompt)
Vault password: [Enter your vault password here]

# ... Playbook execution output ...
PLAY [Create a new user on Cisco IOS-XE device] *******************************

TASK [Ensure new user exists with specified password] **************************
changed: [my_router]

TASK [Print user configuration status] *****************************************
ok: [my_router] => {
    "msg": "User automation_user configuration changed: True"
}

TASK [Save configuration] ******************************************************
changed: [my_router]

PLAY RECAP *********************************************************************
my_router                  : ok=4    changed=2    unreachable=0    failed=0    skipped=0    rescued=0    ignored=0
Important Note

The password is never displayed in plain text during execution, ensuring it remains confidential even in logs or screen recordings.

Key Takeaway

Use `--ask-vault-pass` to provide the vault password securely at runtime, preventing its exposure in command history.
