Practical Git Walkthrough
Initialize, add, commit, branch, and merge.

Let's put these concepts into practice with a hands-on walkthrough. We'll start by initializing a new Git repository in a directory. First, create a folder for your project, say `network-automation-repo`, and navigate into it using your terminal. Then, run `git init` to create the repository. Now, let's create a simple `README.md` file with some initial text and stage it using `git add README.md`. After that, commit it with a message like `"Initial commit: Add README file"`. Next, we'll simulate adding a new automation script, perhaps `snmp_config.yml`. Create this file, add some placeholder content, and then stage and commit it: `git add snmp_config.yml` followed by `git commit -m "Add SNMP config playbook"`. Now, let's practice branching. We'll create a new branch for a hypothetical change: `git checkout -b feature/qos-settings`. Make a small modification to one of the files, stage it, and commit it on this new branch. Finally, switch back to your main branch with `git checkout main` and merge your feature branch using `git merge feature/qos-settings`. This sequence demonstrates the core Git workflow from initialization to integrating changes, providing a solid foundation for managing your network automation projects.

Key Takeaway

Follow along to initialize, add, commit, branch, and merge changes in a practical demonstration.

Walkthrough Steps

1. Initialize: mkdir repo; cd repo; git init

2. Create & commit file: echo "..." > file.txt; git add file.txt; git commit -m "Initial"

3. Branch: git checkout -b new-feature

4. Modify & commit on branch: ...; git add .; git commit -m "Feature work"

5. Switch back & merge: git checkout main; git merge new-feature
