Hands-on Lab: Git for Network Automation
Apply Git commands to a practical scenario.

Now it's time for you to get hands-on experience with Git in the context of network automation. We'll simulate a common scenario: adding a new Ansible playbook for configuring SNMP settings to an existing automation repository. First, you'll initialize a local Git repository and make an initial commit with a README file. Then, you'll create a new branch specifically for this SNMP configuration feature. Inside this branch, you'll create a dummy `snmp_config.yml` playbook, add it to staging, and commit it with a descriptive message. After that, you'll switch back to the main branch and merge your feature branch into it. This exercise will reinforce the fundamental Git workflow: initializing, adding, committing, branching, and merging. Pay close attention to the commands and the expected output. Remember, the goal is to practice these commands in a way that mirrors real-world network automation development, ensuring you can manage your code effectively and collaboratively.

Key Takeaway

Apply Git commands to add a new playbook to a simulated network automation repository.

Lab Steps

1. Initialize repo: git init

2. Commit README: git add README.md; git commit -m "Initial"

3. Create branch: git checkout -b feature/snmp-config

4. Add & commit playbook: git add snmp_config.yml; git commit -m "Add SNMP playbook"

5. Merge branch: git checkout main; git merge feature/snmp-config

Safety Note

In a real-world scenario, avoid committing sensitive data like SNMP community strings directly. Use tools like Ansible Vault for encryption.
