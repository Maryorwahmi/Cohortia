Discovering Users: Listing Webex People

Programmatic Access to Organization Members

Key Features of /v1/people

  • List Users: Retrieve a collection of users in your organization.
  • User Details: Get display name, email, ID, and other profile information.
  • Filtering: Use query parameters like email or displayName to narrow results.
  • Pagination: Manage large result sets with max and start parameters.
Example Scenario

An onboarding script needs to find the new employee's Webex ID to add them to default team spaces. It uses GET /v1/people?email=new.employee@example.com.

API Call: Listing People (GET)

GET /v1/people?max=5
Content-Type: application/json
Authorization: Bearer <TOKEN>

This request retrieves up to 5 users from your Webex organization.
