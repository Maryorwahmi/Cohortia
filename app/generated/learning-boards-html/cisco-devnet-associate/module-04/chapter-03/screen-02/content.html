Learning Objectives

Skills You'll Master in This Chapter (Part 1)

LearnUnderstandApplyMaster
01

Understand Webex Capabilities

Grasp the full scope of the Cisco Webex platform, including its messaging, meetings, and calling features. Recognize its crucial role in modern collaboration environments and how APIs extend its functionality.

VERIFIED COMPETENCY MILESTONE
02

Authenticate with Webex API

Learn to securely access the Webex API using personal access tokens for quick scripting and understand the basics of OAuth 2.0 for robust, production-grade applications.

VERIFIED COMPETENCY MILESTONE
03

Utilize Webex APIs for Spaces

Programmatically create and manage Webex spaces (rooms) and send messages to them, enabling automated communication channels for various events and projects.

VERIFIED COMPETENCY MILESTONE
04

Automate User Management

Perform user management tasks such as listing users and adding them to specific Webex spaces, enabling dynamic team formation and communication.

VERIFIED COMPETENCY MILESTONE
