Creating and Listing Webex Spaces

Organizing Collaboration Hubs Programmatically

What are Webex Spaces?

  • Virtual collaboration areas for teams.
  • Used for messaging, file sharing, and meetings.
  • Identified by a unique id after creation.
  • Can be filtered when listing by type or team.
Example Scenario

A new IT project kicks off. An automation script creates a dedicated Webex space, names it after the project, and retrieves its id for future communication.

API Endpoints for Space Management

Create a Space (POST)
POST /v1/rooms
Content-Type: application/json

{
"title": "New Project Space"
}

Returns the new space's details, including its crucial id.

List Spaces (GET)
GET /v1/rooms?max=5
Content-Type: application/json

Retrieves a list of spaces, optionally filtered by parameters.

Key Takeaway

The /v1/rooms endpoint is central to managing Webex spaces, allowing programmatic creation and retrieval, with the returned id being vital for all subsequent interactions.
