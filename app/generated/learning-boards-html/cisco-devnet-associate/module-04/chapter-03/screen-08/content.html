Communication Automation

Automating Messages to Webex Spaces

Integrating Alerts and Updates into Collaboration Channels

Key Message Payload Fields

  • roomId (Required): The ID of the target Webex space.
  • text (Optional): Plain text content of the message.
  • markdown (Optional): Richly formatted message content using Markdown syntax.
  • files (Optional): Array of URLs to attach files.
  • mentions (Optional): Array of person IDs or emails to mention.
Real-World Use Case

A network monitoring system detects high CPU utilization on a router. An automation script sends a Webex message to the NOC team's space with a critical alert and a link to the device dashboard.

Sending a Message via API (POST)

POST /v1/messages
Content-Type: application/json
Authorization: Bearer <TOKEN>

{
"roomId": "Y2lzY29zcGFy...",
"markdown": "**Critical Alert:** Router R1 CPU utilization is at 95%! Please investigate. <@personEmail:noc_lead@example.com>"
}

This example sends a markdown-formatted message, mentioning a specific user, to a designated Webex space.

Key Takeaway

Automating messages to Webex spaces is crucial for integrating real-time alerts, status updates, and reports directly into team communication, enhancing responsiveness and awareness.
