Configuring Webhooks on Cisco Platforms

Setting up event notifications in Meraki and Webex.

01

Cisco Meraki Configuration

  • •Configure at the network level in the Meraki Dashboard.
  • •Specify the Payload URL (your receiver's public endpoint).
  • •Optionally, set a Shared Secret for payload verification.
  • •Receive alerts for device status, VPN issues, security events.
02

Cisco Webex Configuration

  • •Use the Webex API (e.g., /v1/webhooks endpoint).
  • •Specify the Target URL for your receiver.
  • •Define the Resource (e.g., messages) and Event (e.g., created).
  • •Receive notifications for new messages, memberships, meeting events.
Key Takeaway

Successful webhook configuration requires a publicly accessible receiver URL and careful definition of events and security parameters on the source platform.
