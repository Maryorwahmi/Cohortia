What is a Webhook? An Event-Driven Callback

User-defined HTTP callbacks for real-time notifications.

Webhook Definition

A webhook is a user-defined HTTP callback. It's a mechanism where a source system sends an HTTP POST request to a specified URL when a particular event occurs, enabling real-time, event-driven communication.

Key Takeaway

Webhooks are essential for building responsive automation by allowing systems to 'push' event data to your applications in real-time.

How it Works: The Push Mechanism

  • •An event occurs on the source system (e.g., device offline).
  • •The source system sends an HTTP POST request.
  • •This request is sent to a pre-configured 'payload URL'.
  • •The request body contains a 'payload' (usually JSON) with event details.
  • •Your 'webhook receiver' application processes this payload.
Analogy

The Smart Doorbell

Instead of constantly checking if someone is at your door (polling), a webhook is like a smart doorbell that rings your phone immediately when a visitor arrives (event-driven notification).
