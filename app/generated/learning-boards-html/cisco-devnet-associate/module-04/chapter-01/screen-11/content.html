Python Script: get_network_devices
def get_network_devices(token, dna_center_ip):
    """Retrieves the list of network devices from Cisco DNA Center."""
    devices_url = f"https://{dna_center_ip}/dna/intent/api/v1/network-device"
    headers = {
        'Content-Type': 'application/json',
        'X-Auth-Token': token
    }
    try:
        response = requests.get(devices_url, headers=headers, verify=False)
        response.raise_for_status()
        return response.json().get("response", [])
    except requests.exceptions.RequestException as e:
        print(f"Error retrieving devices: {e}")
        return []

Key Takeaway

The get_network_devices function demonstrates how to use the authentication token in the X-Auth-Token header to make authorized GET requests and retrieve network inventory.

Header Importance

The X-Auth-Token header is critical for every subsequent API call after authentication, acting as your digital passport for authorized access.

JSON Parsing

Always anticipate that API responses might wrap the actual data in a key like 'response' or 'data'; use .get("response", []) for safe extraction.
