Retrieving Network Inventory

Querying Devices with the Network Device API

Key Takeaway

The /network-device API endpoint is your gateway to programmatically accessing and filtering detailed information about all managed network devices.

Pro Tip

Utilize query parameters like ?type=Wireless Controller or ?series=Cisco Catalyst 9300 to filter results and retrieve only the specific devices you need.

Example Use Case

Automatically generate a report of all switches in your network, including their software versions and last updated times, for compliance checks.

Network Device API Overview
GET /dna/intent/api/v1/network-device
Headers:
  X-Auth-Token: <YOUR_JWT_TOKEN>
  Content-Type: application/json

Endpoint Purpose

Retrieves a list of all network devices managed by Cisco DNA Center, along with their detailed attributes.

Expected JSON Response

Returns a JSON array under the 'response' key, where each object represents a network device with fields like hostname, managementIpAddress, serialNumber, and overallHealth.
