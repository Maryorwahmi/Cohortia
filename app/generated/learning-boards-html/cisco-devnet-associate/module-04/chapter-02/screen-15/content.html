Python Script: Creating and Updating VLANs

Implement functions for creating new VLANs and modifying existing ones.

Create and Update Functions
def create_network_vlan(network_id, vlan_id, vlan_name, subnet, appliance_ip):
    """Creates a new VLAN in a specific network."""
    endpoint = f"/networks/{network_id}/vlans"
    payload = {
        "id": vlan_id,
        "name": vlan_name,
        "subnet": subnet,
        "applianceIp": appliance_ip
    }
    return meraki_api_call("POST", endpoint, payload)

def update_network_vlan(network_id, vlan_id, new_vlan_name):
    """Updates an existing VLAN's name in a specific network."""
    endpoint = f"/networks/{network_id}/vlans/{vlan_id}"
    payload = {
        "name": new_vlan_name
    }
    return meraki_api_call("PUT", endpoint, payload)

Creating VLANs

  • `create_network_vlan`: Uses a `POST` request to add a new VLAN.
  • Requires `vlan_id`, `name`, `subnet`, and `appliance_ip` in the payload.
  • Includes an idempotency check (`vlan_exists`) to prevent duplicate creations.

Updating VLANs

  • `update_network_vlan`: Uses a `PUT` request to modify an existing VLAN.
  • Targets a specific VLAN using `vlan_id` in the endpoint.
  • Payload contains the properties to be updated (e.g., `name`).
  • Verification step: Lists VLANs again to confirm the change.
Key Takeaway

These functions demonstrate practical application of POST and PUT requests for dynamic VLAN management, incorporating idempotency and verification for robust automation.
