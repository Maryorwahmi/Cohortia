Authentication

Secure API Key Authentication

Learn to generate and securely use your Meraki API key for programmatic access.

Generating Your API Key

  • Access your Meraki Dashboard.
  • Navigate to your profile settings.
  • Generate a unique API key.
  • Treat this key with utmost confidentiality, like a password.

Using the API Key

  • Include the API key in the `X-Cisco-Meraki-API-Key` HTTP header for every request.
  • Example: `headers = {'X-Cisco-Meraki-API-Key': 'YOUR_API_KEY'}`.
  • Keys typically do not expire unless revoked, simplifying script management.
Key Takeaway

Your Meraki API key is the primary credential for automation; secure handling and proper inclusion in HTTP headers are critical.

Security Best Practices

  • Secure Storage: Never hardcode API keys in scripts; use environment variables or secure vaults.
  • Access Control: Limit who has access to the API key.
  • Regular Review: Periodically review and revoke unused or compromised keys.
  • Least Privilege: Ensure the API key's associated user has only necessary permissions.

Alternative: OAuth 2.0

For larger deployments or complex integrations requiring delegated access and refresh tokens, Meraki also supports OAuth 2.0. While more complex to set up initially, it offers enhanced security features for enterprise-level applications.
