Python Script: Listing Networks and VLANs

Develop functions to retrieve organization networks and their associated VLANs.

Listing Functions
def get_organization_networks(org_id):
    """Retrieves all networks within a given organization."""
    endpoint = f"/organizations/{org_id}/networks"
    return meraki_api_call("GET", endpoint)

def get_network_vlans(network_id):
    """Retrieves VLANs for a specific network."""
    endpoint = f"/networks/{network_id}/vlans"
    return meraki_api_call("GET", endpoint)

if __name__ == "__main__":
    if not all([MERAKI_API_KEY, MERAKI_ORG_ID]):
        print("Please set MERAKI_API_KEY and MERAKI_ORG_ID environment variables.")
    else:
        print("Listing networks in organization...")
        networks = get_organization_networks(MERAKI_ORG_ID)
        if networks:
            print(f"Found {len(networks)} networks:")
            for net in networks:
                print(f"  Name: {net.get('name')}, ID: {net.get('id')}")
            
            target_network_name = "My_Test_Network" 
            target_network = next((net for net in networks if net.get('name') == target_network_name), None)

            if target_network:
                target_network_id = target_network['id']
                print(f"
Working with network: {target_network_name} (ID: {target_network_id})")

                print("
Listing existing VLANs...")
                existing_vlans = get_network_vlans(target_network_id)
                if existing_vlans:
                    for vlan in existing_vlans:
                        print(f"  VLAN ID: {vlan.get('id')}, Name: {vlan.get('name')}, Subnet: {vlan.get('subnet')}")
                else:
                    print("No VLANs found or error retrieving them.")
            else:
                print(f"Network '{target_network_name}' not found.")
        else:
            print("No networks found or an error occurred.")

Retrieving Networks

  • `get_organization_networks(org_id)`: Calls the API to list all networks.
  • Returns a list of network objects, each containing `id` and `name`.
  • Essential for identifying the `networkId` required for most Meraki API calls.

Retrieving VLANs

  • `get_network_vlans(network_id)`: Fetches all VLANs for a given `network_id`.
  • Returns a list of VLAN objects with details like `id`, `name`, and `subnet`.
  • Provides the current state of VLAN configurations, crucial for idempotent operations.
Key Takeaway

These listing functions are foundational for any Meraki automation script, allowing you to discover and inspect network resources before making any configuration changes.
