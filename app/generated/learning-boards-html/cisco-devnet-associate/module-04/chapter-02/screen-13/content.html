Python Script: Setup and Helper Function

Initialize your Python environment and create a reusable API call helper.

`meraki_api_call` Function
import requests
import json
import os

MERAKI_API_KEY = os.getenv("MERAKI_API_KEY", "YOUR_MERAKI_API_KEY")
MERAKI_ORG_ID = os.getenv("MERAKI_ORG_ID", "YOUR_MERAKI_ORGANIZATION_ID")
BASE_URL = "https://api.meraki.com/api/v1"

def meraki_api_call(method, endpoint, data=None):
    headers = {
        "X-Cisco-Meraki-API-Key": MERAKI_API_KEY,
        "Content-Type": "application/json"
    }
    url = f"{BASE_URL}{endpoint}"
    try:
        if method.upper() == "GET":
            response = requests.get(url, headers=headers)
        elif method.upper() == "POST":
            response = requests.post(url, headers=headers, data=json.dumps(data))
        elif method.upper() == "PUT":
            response = requests.put(url, headers=headers, data=json.dumps(data))
        elif method.upper() == "DELETE":
            response = requests.delete(url, headers=headers)
        else:
            raise ValueError(f"Unsupported HTTP method: {method}")

        response.raise_for_status() 
        return response.json() if response.content else {}
    except requests.exceptions.RequestException as e:
        print(f"Meraki API Error ({method} {endpoint}): {e}")
        if hasattr(e, 'response') and e.response is not None:
            print(f"Response content: {e.response.text}")
        return None

Configuration & Security

  • Environment Variables: `MERAKI_API_KEY` and `MERAKI_ORG_ID` are loaded from environment variables for security.
  • Base URL: Defines the common API endpoint prefix.
  • Imports: `requests` for HTTP, `json` for data, `os` for environment variables.

Helper Function Breakdown

  • `headers`: Includes the API key and `Content-Type` for JSON.
  • `url`: Constructs the full API endpoint.
  • HTTP Methods: Uses `requests.get`, `post`, `put`, `delete` based on the `method` parameter.
  • Error Handling: `response.raise_for_status()` checks for HTTP errors (4xx/5xx).
  • Return Value: Returns JSON response or an empty dictionary if no content.
Key Takeaway

A well-structured helper function centralizes API interaction logic, enhances security by using environment variables, and improves script reliability with built-in error handling.
