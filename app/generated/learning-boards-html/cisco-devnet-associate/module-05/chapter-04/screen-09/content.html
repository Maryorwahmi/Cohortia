Ad-Hoc Commands for Instant Actions

Perform single-task operations and gather information quickly.

Command Examples

Use the ansible command with -m for modules and -a for arguments.

# 1. Ping all devices in 'ios_routers' groupansible ios_routers -m ping# 2. Gather facts from router1ansible router1 -m ios_facts# 3. Run 'show ip interface brief' on all ios_routersansible ios_routers -m ios_command -a "commands='show ip interface brief'"

Key Uses of Ad-Hoc Commands

  • Connectivity Test: Verify SSH access and Ansible setup.
  • Information Gathering: Collect device facts or run specific show commands.
  • One-Off Tasks: Perform simple, non-repeatable configurations or checks.
  • Troubleshooting: Quickly diagnose issues on remote devices.
Pro Tip

Ad-hoc commands are great for quick checks, but for repeatable and complex tasks, always use playbooks.

Key Takeaway

Ad-hoc commands provide a fast way to interact with network devices for immediate feedback and simple operations, leveraging Ansible modules directly from the command line.
