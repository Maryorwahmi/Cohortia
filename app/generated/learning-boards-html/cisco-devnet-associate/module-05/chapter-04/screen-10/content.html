Configuring NTP with Your First Playbook

Automate network time protocol settings using a declarative playbook.

1. Create configure_ntp.yaml

Define tasks to ensure NTP server presence on IOS routers.

--- - name: Configure NTP server on IOS routers hosts: ios_routers gather_facts: no connection: network_cli tasks: - name: Ensure NTP server is configured ios_ntp: server: 172.16.1.100 state: present register: ntp_config_result - name: Display NTP configuration status debug: var: ntp_config_result

2. Execute the Playbook

Run the playbook using ansible-playbook command.

# Execute the NTP configuration playbookansible-playbook -i inventory.ini configure_ntp.yaml
Key Concept: Idempotency

The state: present parameter ensures the task only makes changes if the NTP server is not already configured, preventing unnecessary reconfigurations.

Key Takeaway

Ansible playbooks enable declarative, idempotent configuration of network services like NTP, ensuring consistent and predictable outcomes across devices.
