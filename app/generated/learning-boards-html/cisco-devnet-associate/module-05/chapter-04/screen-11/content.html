Managing VLANs with Ansible Playbooks

Declaratively create, modify, or remove VLANs on network devices.

Playbook: configure_vlan.yaml

Use ios_vlans module to manage VLAN presence.

--- - name: Configure VLANs on IOS switches hosts: ios_switches gather_facts: no connection: network_cli tasks: - name: Ensure VLAN 10 (Users) is present ios_vlans: vlan_id: 10 name: Users state: present - name: Ensure VLAN 20 (Servers) is present ios_vlans: vlan_id: 20 name: Servers state: present - name: Ensure VLAN 99 (Management) is absent ios_vlans: vlan_id: 99 state: absent

Declarative State Management

  • state: present: Ensures the VLAN exists; creates it if missing, does nothing if present.
  • state: absent: Ensures the VLAN does not exist; removes it if present, does nothing if absent.
  • Idempotency: Playbook can be run repeatedly without causing unintended changes.
  • Efficiency: Ansible determines the minimal set of operations needed.
Pro Tip: Dry Run

Always use ansible-playbook --check to see what changes Ansible *would* make without applying them, and --diff to see exact configuration differences.

Key Takeaway

The ios_vlans module, combined with state: present or state: absent, allows for powerful, idempotent, and declarative management of VLAN configurations, simplifying network changes.
