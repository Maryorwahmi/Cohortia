Inventory and Modules: The Building Blocks

Define your network and the actions Ansible can perform.

Ansible Inventory

  • Purpose: Lists managed nodes (devices) and organizes them.
  • Format: Typically INI or YAML files.
  • Structure: Defines hosts, groups, and host/group-specific variables.
  • Example: Grouping Cisco IOS routers for targeted automation.

Example: Inventory Snippet

[ios_routers]router1 ansible_host=192.168.10.1router2 ansible_host=192.168.10.2

Ansible Modules

  • Function: Small programs executed on managed nodes to perform tasks.
  • Idempotency: Run multiple times, only makes changes if desired state isn't met.
  • Variety: Vast collection, including many for network vendors (e.g., `ios_ntp`, `ios_vlans`).
  • Tasks: A call to a module with specific arguments.
Key Takeaway

The Inventory defines 'who' Ansible manages, while Modules define 'what' actions Ansible can perform, ensuring idempotent and targeted configurations.
