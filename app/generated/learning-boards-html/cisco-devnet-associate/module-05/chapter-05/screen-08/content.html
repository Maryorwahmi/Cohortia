A Sample Network Automation Script

Introducing get_hostname.py with Netmiko

Script Purpose

Connects to a network device using Netmiko and retrieves its hostname, demonstrating a common automation task.

Secure Credentials

Utilizes environment variables (os.environ.get) for device host, username, and password, avoiding hardcoding sensitive data.

Dependency

Relies on the netmiko library, which will need to be installed within the container environment.

Key Takeaway

Scripts designed with externalized credentials are ideal for containerization, enhancing security and flexibility.

# get_hostname.py
import os
from netmiko import ConnectHandler

device = {
    "device_type": "cisco_ios",
    "host": os.environ.get("DEVICE_HOST"),
    "username": os.environ.get("DEVICE_USERNAME"),
    "password": os.environ.get("DEVICE_PASSWORD"),
    "secret": os.environ.get("DEVICE_PASSWORD"), # For 'enable' mode
}

try:
    with ConnectHandler(**device) as net_connect:
        output = net_connect.send_command("show hostname")
        print(f"Hostname: {output.strip()}")
except Exception as e:
    print(f"Error connecting to device: {e}")
