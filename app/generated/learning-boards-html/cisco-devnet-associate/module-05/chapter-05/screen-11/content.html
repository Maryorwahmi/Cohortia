Executing Your Dockerized Script

Running Custom Images with Environment Variables

docker run for Custom Images

Use docker run with your custom image tag (e.g., my-net-script) to create and start a container from your built image.

Passing Environment Variables (-e)

The -e flag allows you to securely inject environment variables (like credentials) into the container at runtime, preventing hardcoding.

Security Best Practice

Never hardcode sensitive credentials directly into Dockerfiles or images. Always pass them at runtime via environment variables or Docker Secrets.

Key Takeaway

Running containers with runtime environment variables ensures secure and flexible execution of your containerized network automation scripts.

# Run your container, passing environment variables for credentials
docker run --rm \
-e DEVICE_HOST=YOUR_DEVICE_IP \
-e DEVICE_USERNAME=YOUR_USERNAME \
-e DEVICE_PASSWORD=YOUR_PASSWORD \
my-net-script
Output (example):
Attempting to connect to YOUR_DEVICE_IP...
Successfully connected. Hostname: MyCiscoRouter
