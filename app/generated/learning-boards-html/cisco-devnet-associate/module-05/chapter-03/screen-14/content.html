Key Concepts

Essential terms for CI/CD in networking

Continuous Integration (CI)

A practice where developers frequently merge code changes into a central repository, triggering automated builds and tests.

Continuous Delivery (CD)

An extension of CI ensuring all code changes are built, tested, and prepared for release to production, often with manual approval.

Continuous Deployment

An advanced form of CD where every change passing all pipeline stages is automatically deployed to production without human intervention.

Summary Takeaway

CI/CD practices automate the integration, testing, and deployment of network changes, with Continuous Delivery offering a human gate and Continuous Deployment fully automating the process to production.
