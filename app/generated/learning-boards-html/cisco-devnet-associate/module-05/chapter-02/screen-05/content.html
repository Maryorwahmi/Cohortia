Git Fundamentals

Installing and Configuring Git

Setting Up Your Local Development Environment

Installation Across OS

Use package managers (apt, yum, Homebrew) for Linux/macOS or the official installer for Windows to get Git.

Global User Configuration

Set your `user.name` and `user.email` globally to associate your identity with all future Git commits.

Key Takeaway

Proper Git installation and user configuration are essential first steps, ensuring your contributions are correctly attributed and your environment is ready for version control.

Configure Your Git Identity
# Configure user name
git config --global user.name "Your Name"

# Configure user email
git config --global user.email "your.email@example.com"
Why Global Configuration?

Using `--global` ensures these settings apply to all your Git repositories on the current system, saving you from configuring them for each new project.
