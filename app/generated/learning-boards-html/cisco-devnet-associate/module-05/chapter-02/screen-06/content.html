Initializing a Repository and Staging Changes

Starting to Track Your Network Project

`git init`: Create Repository

Transforms a directory into a Git repository by creating a hidden `.git` folder to store history.

`git add`: Stage Changes

Moves files from untracked/modified to the staging area, preparing them for the next commit.

Key Takeaway

`git init` establishes a new repository, and `git add` selectively stages changes, giving you precise control over what gets included in your next snapshot.

Example: Initializing and Staging
# Create project directory
mkdir network_configs
cd network_configs

# Initialize Git repository
git init

# Create a sample configuration file
echo "hostname R1" > r1_config.txt
echo "interface GigabitEthernet0/1" >> r1_config.txt

# Stage the file for commit
git add r1_config.txt

# Check status
git status
Understanding `git status` Output

`git status` will show `new file: r1_config.txt` under 'Changes to be committed', indicating it's staged and ready for the next snapshot.
