Understanding Git Branching

Independent Lines of Development

What is a Branch?

An independent line of development, allowing isolated work on features or fixes without affecting the main codebase.

Why Use Branches?

Keeps the `main` branch stable, enables parallel development, and simplifies testing of new features or changes.

Key Takeaway

Branches are fundamental for isolated development, allowing teams to work concurrently on different features without disrupting the stable main codebase.

Example: Creating and Switching Branches
# Create a new branch for OSPF feature
git branch feature/add_ospf

# Switch to the new branch
git checkout feature/add_ospf

# Output:
# Switched to branch 'feature/add_ospf'
The `main` Branch

The `main` branch is typically where the stable, production-ready code resides. Always create new branches for development work to keep `main` pristine.
