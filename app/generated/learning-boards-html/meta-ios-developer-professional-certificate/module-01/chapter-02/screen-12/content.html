Module 1 › Chapter 1.2 › Common Mistakes
Reassignment to let
Error occurs when changing a constant. Fix by using var or redesigning to avoid change.
Type mismatch
Combining incompatible types. Fix with explicit conversions or interpolation for display.
Truncation on conversion
Converting Double to Int removes the fractional part. Use rounding or keep Double if fractions matter.
Pro tip

Read compiler errors and convert only at boundaries. Keep internal math consistent to reduce conversion mistakes.
