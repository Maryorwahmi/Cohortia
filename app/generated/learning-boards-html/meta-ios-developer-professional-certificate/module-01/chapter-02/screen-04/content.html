Module 1 › Chapter 1.2 › var vs let
Definition
var is used for values you will change; let is used for values that remain constant. The compiler enforces immutability for let.
Why it matters
  • Immutability reduces accidental changes and helps reasoning.
  • Compiler errors surface mistakes early during development.
  • Refactoring is safer when values are declared immutable by default.
Key Takeaway

Choose let when you know the value won’t change; use var sparingly for changing state like scores or counters.

Concrete Example
// Declaring a variable and a constant
var currentScore: Int = 0  // can change during the game
let maxAttempts: Int = 3   // fixed rule, never changes

// Changing a variable is allowed
currentScore = 150

// Reassigning a let causes a compile-time error
// maxAttempts = 4  // ERROR: Cannot assign to let constant
Misconception: using var everywhere is not safer. Immutability documents intent and prevents accidental bugs.
