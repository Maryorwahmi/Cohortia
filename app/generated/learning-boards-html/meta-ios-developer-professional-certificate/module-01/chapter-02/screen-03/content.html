Playground Workflow
  • Declare a constant or variable and print its value.
  • Change a var value and observe the output updating.
  • Try reassigning a let to see the compiler error and correct it.

Common Errors to Watch
Type mismatch: trying to combine different types without conversion.
Forgetting to use let for values that never change.
Assuming inference picks the type you need; annotate when necessary.
