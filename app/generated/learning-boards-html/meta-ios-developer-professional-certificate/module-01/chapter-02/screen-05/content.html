Module 1 › Chapter 1.2 › Core Types
Int
Whole numbers
Use for counts, indices, and scores. Example: 10, -5, 0.
Double
Decimal numbers
Use for fractions or measured values. Example: 3.14, -0.5.
String
Text
Names, messages, labels. Example: "Alex".
Bool
True or false
Flags and conditions. Example: true, false.
Example scenario
In a game, a player's lives is an Int, the game version might be a Double, the player's name is a String, and whether the game is paused is a Bool. Use the type that best matches how the value will be used.
Common mistake

Trying to perform numeric math on a String that looks like a number. Convert types explicitly before combining them.
