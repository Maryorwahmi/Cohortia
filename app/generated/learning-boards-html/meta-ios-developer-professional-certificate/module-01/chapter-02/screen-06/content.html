Module 1 › Chapter 1.2 › Int vs Double
Int (whole numbers)
Use when values are counts or indices. Integer division truncates decimals.
Example
let lives: Int = 3 // whole number of lives
Double (decimal numbers)
Use when precision or fractions matter. Good for ratios, averages, version numbers.
Example
let accuracy: Double = 0.75 // 75% accuracy
Conversion example
let hits: Int = 75
let attempts: Int = 100
// Convert to Double for accurate ratio
let accuracy: Double = Double(hits) / Double(attempts) // 0.75
Misconception: dividing two Ints will give fractional expectations. Convert to Double when you want the fractional result.
