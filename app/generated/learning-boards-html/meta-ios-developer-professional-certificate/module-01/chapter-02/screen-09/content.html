Operators
  • + addition, - subtraction
  • * multiplication, / division
  • % remainder/modulo
Use parentheses to override precedence when needed.
Examples & tips
let total = 5 + 3 * 2 // 11 due to precedence
var score = 100
score += 50 // shorthand for score = score + 50
let remainder = 7 % 3 // 1
Convert Int to Double for fractional division: Double(a) / Double(b).
Key Takeaway

Operator precedence affects results; convert types when fractions are expected and use compound operators for updates.
