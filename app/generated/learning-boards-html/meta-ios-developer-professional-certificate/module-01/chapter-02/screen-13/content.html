Implementation example
let maxScore: Int = 1000
var currentScore: Int = 250
let playerName: String = "Sam"
let accuracy: Double = Double(currentScore) / Double(maxScore) * 100
let message = "\(playerName): \(currentScore)/\(maxScore) (\(accuracy)%)"
print(message)

If you accidentally declared maxScore with var and another part of the code changes it, how would that affect your calculations? Use let to prevent that possibility.
