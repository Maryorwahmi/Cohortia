Module 1 › Chapter 1.2 › Type Mismatch
Common error
Attempting operations across incompatible types causes compile-time errors. Swift wants explicit conversions so you choose the right behavior.
Example mistake
let name = "Alex"
let score = 150
// "Name: " + score   // ERROR: cannot add String and Int
Fix with conversion
let message = "Player \(name) scored \(score) points" // use interpolation
// or explicitly convert
let scoreText = String(score)
let message2 = "Player: " + scoreText
Choose conversion direction thoughtfully: converting Int to Double preserves fractions if you need fractional math; converting Double to Int truncates decimals.
