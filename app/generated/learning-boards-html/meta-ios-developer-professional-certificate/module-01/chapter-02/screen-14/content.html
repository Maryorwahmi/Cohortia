var / let
var for mutable state, let for immutable values to reduce bugs and simplify reasoning.
Core Types
Int, Double, String, Bool — pick the type that matches your data and operations.
Inference & Conversion
Let inference keep code concise; convert explicitly when types must interact or when precision matters.
Summary Takeaway

Small decisions at declaration time—mutability and type—prevent many future bugs. Practice with Playgrounds to build confidence.
