Module 1 › Chapter 1.2 › Quick Reference
Let by default
Declare constants when values don’t change to reduce accidental modification.
Pick the right type
Int, Double, String, Bool match different real-world concepts; use the one that fits.
Convert explicitly
When types mix, convert intentionally and prefer interpolation for building messages.
Short takeaway

Small choices at declaration time pay off: immutability, accurate types, and explicit conversion lead to safer, clearer Swift code.
