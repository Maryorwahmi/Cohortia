Type Inference
Swift infers types from initial values so you often omit explicit types for brevity.
var temperature = 25.5 // inferred as Double
let greeting = "Good morning" // inferred as String
var isActive = true // inferred as Bool
When to annotate
Annotate when intent matters or inference is ambiguous, for example when numeric types could be Int or Double.
var explicitAge: Int = 30
let explicitPi: Double = 3.14159
Misconception

Inference always chooses the best type. In practice, inference follows simple rules and can pick Double for numeric literals; annotate when you need a different type.
