Module 1 › Chapter 1.2 › String Interpolation
Why interpolation
  • Makes messages readable and concise.
  • Avoids type-mismatch attempts to add strings and numbers.
  • Allows expressions inside the string for inline computation.
Code example
let playerName: String = "Alex"
let score: Int = 150
let message = "Player \(playerName) scored \(score) points!"
print(message) // Player Alex scored 150 points!
Pro tip: include expressions like \(score + bonus) to compute values inside the string at the point of formatting.
