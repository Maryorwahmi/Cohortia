Practical tasks
  1. Create a new iOS App project using SwiftUI and Swift.
  2. Edit ContentView to update displayed text and add a second Text view.
  3. Add a print function call in an .onAppear or Playground to confirm runtime output.
  4. Run the app in an iOS Simulator and confirm the console messages.
VERIFIED COMPETENCY MILESTONE
Common checks
  • Confirm Interface set to SwiftUI in project setup.
  • Look for red errors in the Issue Navigator for syntax mistakes.
  • If the Simulator fails, try Clean Build Folder and restart Xcode.
