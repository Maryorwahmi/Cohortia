Module 1 › Chapter 1.1 › Common starter errors and fixes
Syntax errors
  • Missing closing brace or quote — Xcode marks the line and the Issue Navigator lists the error.
  • Forgot import SwiftUI — unresolved types like View or Text will appear until you import the module.
  • Placing code outside struct braces — compiler will indicate unexpected tokens or declarations.
Misconception

Errors are not permanent roadblocks; they are direct clues from the compiler about what to fix.

Environment & Simulator
  • Simulator does not launch — try Product > Clean Build Folder and restart Xcode.
  • App installs but doesn’t show expected UI — check console for runtime errors and verify .onAppear executed.
Quick fix sequence

Clean build, restart Xcode, relaunch simulator, check the Issue Navigator and Debug area for clues.
