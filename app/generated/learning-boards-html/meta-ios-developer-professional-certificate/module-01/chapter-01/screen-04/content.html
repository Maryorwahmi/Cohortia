Module 1 › Chapter 1.1 › What is Swift?
Definition

Swift is a modern language from Apple for building apps across iOS, iPadOS, macOS, watchOS, and tvOS. It favors clarity, safety, and performance.

Key traits
  • Type safety to reduce runtime errors.
  • Readable, expressive syntax for maintainable code.
  • Good performance for mobile apps.
Concrete example

Declaring a variable and a constant with explicit types prevents accidental assignment of incompatible values and helps the compiler catch errors early.

Common misconception

Swift is not only for experts. Its friendly syntax and helpful compiler messages are designed for learners too.

Key Takeaway

Swift’s type safety and readability reduce early bugs and pair naturally with SwiftUI for building interfaces.

Analogy

Think of Swift like a well-labeled toolbox: clear names and type labels help you grab the right tool and avoid mishaps when building features.

Why it matters

Because every line you write in an iOS app will typically be Swift, learning how Swift prevents errors and expresses intent will help you write stable apps faster.
