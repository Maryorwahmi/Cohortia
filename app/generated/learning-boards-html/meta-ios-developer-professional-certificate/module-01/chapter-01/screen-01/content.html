Get started with Swift and Xcode

Create your first SwiftUI app, send output to the console, and run it in the iOS Simulator.

Estimated time: 12 minutes
Orientation

This lesson builds a practical loop: edit Swift code, run in the Simulator, inspect console output, and repeat. You’ll use SwiftUI for the interface and the print function for quick checks.

What you will learn
  • Swift language role and core traits.
  • Xcode layout: navigator, editor, inspectors, debug area.
  • Create a SwiftUI project, update ContentView, and use print for console output.
Coming up

Hands-on steps and troubleshooting tips so you can recover from common syntax and simulator issues quickly.
