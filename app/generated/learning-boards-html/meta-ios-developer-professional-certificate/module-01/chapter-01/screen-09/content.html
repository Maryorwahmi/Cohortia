Module 1 › Chapter 1.1 › Run the app on the iOS Simulator
Run checklist
  • Select an iPhone simulator from the scheme menu.
  • Press Run to build and install the app.
  • Open the Debug area to view print output and logs.
Example result

If you added two print statements inside .onAppear, the Debug area will display each message in the order they ran when the view appeared.

Troubleshoot

If the Simulator hangs, try Product > Clean Build Folder and relaunch Xcode. Check the Issue Navigator for errors if the build fails.

Where console appears

The Debug area at the bottom of Xcode shows log messages and printed output while the app runs in the Simulator.

Misconception

A missing console message does not always mean the code didn’t run; confirm your print call is inside the lifecycle method that actually executed, such as .onAppear.
