Module 1 › Chapter 1.1 › Hands-on: MyGreetingApp walkthrough
Starter checklist
  1. Create project: iOS → App, Interface SwiftUI, Language Swift.
  2. Open ContentView.swift and edit Text strings.
  3. Add .onAppear and two print statements to verify launch.
  4. Select a simulator and press Run, then inspect the Debug area.
Check your output

Confirm the simulator shows your greeting and the Debug area contains both printed messages in order.

Scenario

You updated the UI and added console logs to verify state. If logs are missing, ensure the .onAppear executed by confirming the view appeared visually.

Key Takeaway

Small, repeatable edits with print checks are the fastest way to build confidence during your first app iterations.
