Bloom
Learn → Understand → Apply → Master
01
Explain Swift

Describe Swift as Apple’s language and name traits like safety and readability. Verified competency milestone.

02
Navigate Xcode

Find files, editors, inspectors, and the debug console; explain when to use each area. Verified competency milestone.

03
Create a SwiftUI project

Use the App template, choose SwiftUI and Swift, and inspect ContentView generated code. Verified competency milestone.

04
Use print for console output

Add a console message to confirm app launch and verify it appears in the Debug area. Verified competency milestone.

Why these skills matter
  • They form the baseline development loop: change code, run, inspect output, fix errors.
  • Understanding the IDE saves time and reduces context switching during debugging.
  • Using the console for small checks is faster than full UI tests for many early bugs.
