Playground example
// Playground quick test

print("This is a standalone message in a Playground.")
Developer tip

Playgrounds run code instantly and show output inline, making them perfect for learning and small experiments without creating a full app.

Console vs UI

Print statements appear in the console and help debug. They do not change the user interface shown on the simulator.

Misconception

Relying only on print for complex state inspection can be limiting. Use breakpoints and view debugging for deeper issues.
