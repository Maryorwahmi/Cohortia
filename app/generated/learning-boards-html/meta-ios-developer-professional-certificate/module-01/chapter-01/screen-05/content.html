IDE architecture
Navigator

Browse project files, assets, and issue lists to find where to edit and where errors are reported.

Editor

Write Swift and build SwiftUI views with code completion and inline previews where available.

Inspectors

Modify properties and modifiers for UI elements or file settings when you select an item.

Debug area

View print output, logs, breakpoints, and variable values while your app runs in the simulator.

Quick workflow
  1. Edit ContentView or a playground line.
  2. Run the project in a simulator.
  3. Inspect the Debug area for console output and issues.
Concrete example

After adding a print function inside .onAppear, run the app and open the Debug area to find the printed messages confirming the app launched.

Misconception

You don’t need to memorize every panel. Focus first on the edit-run-inspect loop; the panels support those actions.
