Module 1 › Chapter 1.1 › Create a new SwiftUI project
Step-by-step
1. Launch & New Project

Open Xcode and choose Create a new Xcode project.

2. Select App template

Under iOS pick the App template for a simple starter app.

3. Choose SwiftUI and Swift

Set Interface to SwiftUI and Language to Swift before continuing.

4. Name and save

Give a clear product name and save the project to a known folder.

5. Run on Simulator

Select a device scheme and press Run to build and launch the Simulator.

Key Takeaway

Project creation is a short, repeatable sequence; confirm SwiftUI at setup to get a ContentView scaffold.

Concrete example

Project name: MyGreetingApp. In ContentView change Text("Hello, world!") to Text("Welcome to Cohortia's iOS Course!") and add Text("Let's learn Swift!").

Misconception

If you accidentally choose UIKit, the starter files differ. Recreate the project with SwiftUI if you want the SwiftUI flow.
