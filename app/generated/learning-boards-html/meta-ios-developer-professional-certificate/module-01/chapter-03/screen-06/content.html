When to prefer switch
Switch is ideal when one variable has many possible values or patterns to match.
Benefits:
  • Readable grouping of cases and ranges.
  • Exhaustiveness helps catch unhandled states.
  • Value binding extracts variables directly from matched patterns.
Common pitfall
Expecting implicit fallthrough — Swift does not fall through automatically.
Code example
// Example of switch statement
let dayOfWeek = 3 // 1 = Monday, 7 = Sunday

switch dayOfWeek {
case 1:
  print("It's Monday, start of the week.")
case 2...6:
  print("It's a weekday.")
case 7:
  print("It's Sunday, time to relax!")
default:
  print("Invalid day number.")
}

let statusCode = 404
switch statusCode {
case 200:
  print("Success")
case 400..<500:
  print("Client error: \(statusCode)")
case 500..<600:
  print("Server error: \(statusCode)")
default:
  print("Unknown status")
}
