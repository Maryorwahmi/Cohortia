Module 2 › Chapter 1.3 › break & continue
Exit or skip
break leaves the loop entirely; continue moves to the next iteration.
  • break for early exit when a target is found.
  • continue to ignore the rest of the body for this iteration.
  • Only affects the innermost loop; nested loops need additional checks.
Example: loading sequence with break
print("--- Loading Sequence ---")
for itemNumber in 1...5 {
  print("Loading item \(itemNumber)...")
  if itemNumber == 3 {
    print("Item 3 loaded, stopping early.")
    break // Exit the loop
  }
}
Variant: continue
Use continue to skip processing when an item is invalid or out of stock instead of stopping the whole loop.
Readability note
If many breaks and continues appear, consider extracting logic into functions to clarify intent.
Key Takeaway

Use break to stop when done and continue to skip items, but keep loops readable.
