If, Else If, Else
Use sequential checks when conditions are related or mutually exclusive.
Key points:
  • Each condition is a boolean expression using comparison or logical operators.
  • Evaluation stops at the first true branch; later branches are not checked.
  • Use clear names for boolean expressions to make intent obvious.
Concrete example
Age-based messaging: test values around 12, 17, and 18 to confirm branches.
Code walkthrough
// Example of if, else if, else let temperature = 22 if temperature < 0 { print("It's freezing outside!") } else if temperature < 10 { print("It's quite cold.") } else if temperature < 25 { print("It's a pleasant day.") } else { print("It's hot!") }
Common mistake
Writing overlapping ranges without correct order, which causes earlier branches to capture values unexpectedly.
Pro tip
Test boundary values and name booleans, for example isTeenager, to make conditions self-documenting.
