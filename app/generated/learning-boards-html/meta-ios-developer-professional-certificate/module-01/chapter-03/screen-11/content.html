Module 2 › Chapter 1.3 › if vs switch
If-else: mixed conditions
Best when different variables and ranges are combined into decisions.
Example scenario: shipping cost depends on weight and destination, so an if-chain reads naturally.
Switch: single-value dispatch
Best when one value maps to many states, such as user roles or enum cases.
Switch helps you see every handled state and prevents missing a case with compiler checks.
Assessment idea
Read a function and decide which structure improves clarity; explain your choice in two sentences.
Misconception
Don't assume switch always replaces if; use the structure that matches the decision model for that code.
Key Takeaway

Pick tools by intent: mixed logic = if-else, single-value dispatch = switch.
