Operators you will use
Comparison operators form atomic checks; logical operators combine them.
Comparison
  • == equals
  • != not equals
  • < > <= >=
Logical
  • && AND (both true)
  • || OR (either true)
  • ! NOT (invert)
Short-circuiting
AND and OR stop evaluating once the result is known. Avoid side-effects in those expressions.
Pro tip
Extract complex checks into named booleans so if (isAuthorized && hasValidSession) reads clearly.
Example: combine checks
// Example of logical operators
let isLoggedIn = true
let hasPremium = false

if isLoggedIn && !hasPremium {
  print("Logged in, but no premium features.")
} else if isLoggedIn || hasPremium {
  print("Either logged in or has premium (or both).")
}
Misconception
Assuming OR checks both sides always; it may short-circuit and skip a later evaluation that has side effects.
Check your understanding
Rewrite a combined expression using intermediate named booleans and confirm behavior stays the same.
