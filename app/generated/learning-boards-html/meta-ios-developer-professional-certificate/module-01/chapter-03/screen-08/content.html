Module 2 › Chapter 1.3 › while vs repeat-while
while loop
Checks condition before each iteration. Use when work should only run if a precondition is true.
var countdown = 3
while countdown > 0 {
  print("T-minus \(countdown)...")
  countdown -= 1
}
print("Liftoff!")
repeat-while loop
Runs once, then checks the condition. Use when you need guaranteed at-least-one execution.
var input: String
repeat {
  print("Enter 'quit' to exit:")
  input = readLine() ?? ""
} while input != "quit"
print("Exited loop.")
Pitfall
Forgetting to change the condition inside the loop causes infinite loops.
Debug tip
Add a debug counter or timeout while testing to detect runaway loops quickly.
Quick exercise
Write both loops for a countdown that starts at zero and observe which one prints at least once.
