Iterating predictable sequences
Choose closed or half-open ranges depending on whether you include the end value.
Details:
  • Closed range uses three dots: 1...5 includes 5.
  • Half-open range uses <.: 0..<3 excludes 3.
  • Use reversed() for descending order.
Avoid mutation
Do not change a collection while iterating over it; collect results separately instead.
Code example
print("Counting up:")
for number in 1...3 { // Closed range: includes 1, 2, 3
  print(number)
}

print("Counting down:")
for i in (0..<3).reversed() { // Half-open range, then reversed
  print(i)
}
Example use
Iterate items to build table rows or compute totals from an array.
Check
If you don't need the loop variable, use underscore to show intent and avoid unused variable warnings.
