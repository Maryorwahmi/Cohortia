Module 6 › Chapter 6.5 › Key Concepts — Part 1
Continuous Integration
Frequent automated builds and tests to catch integration errors early.
Continuous Delivery
Automating packaging and distribution steps so builds are releasable at any time.
Xcode Cloud
Apple’s cloud CI/CD, integrated into Xcode for building and distributing Apple platform apps.
Summary Takeaway

Use CI to catch issues early, CD to prepare releases, and an integrated service like Xcode Cloud to streamline iOS delivery.
