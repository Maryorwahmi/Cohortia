Architecture cards
Source Code Management
Git hosts store branches and history; workflows start on commits or PRs.
CI/CD Server and Build Agents
Orchestrate tasks and provide macOS build machines capable of running Xcode.
Tests & Artifacts
Run unit/UI tests and store build artifacts like .xcarchive for later distribution.
Quick checklist
  • Host repo on supported provider
  • Choose CI server that runs macOS builds
  • Ensure tests run headless where possible
  • Store artifacts securely and set retention
Tip: macOS build capacity matters. If builds queue, optimize tests and cache dependencies.
