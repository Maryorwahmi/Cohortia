Module 6 › Chapter 6.5 › Builds, Tests, Artifacts
Top/bottom split: Build + Example
Build: xcodebuild or Xcode Cloud action produces .xcarchive then exports .ipa for TestFlight.
Unit tests: fast, run on each commit.
UI tests: slower, run on PRs or nightly schedules.
Example
A successful pipeline produces an .xcarchive labeled with branch and build number, uploaded to TestFlight for QA to test before release.
Checklist
  • Tag artifacts with build and branch
  • Use retention and storage for reproducibility
  • Separate fast and slow tests by trigger
Mistake to avoid: Running all UI tests on every commit, causing slow feedback and unhappy developers.
