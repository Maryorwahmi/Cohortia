Module 6 › Chapter 6.5 › Configuring Xcode Cloud Workflow
Step-by-step
  1. Connect repository to Xcode Cloud via Xcode's workflow onboarding.
  2. Choose start conditions: branch push, PR, or manual.
  3. Define actions: Build, Test, Archive, Analyze, Distribute.
  4. Configure environment variables securely.
Example policy: Run unit tests for every commit; run UI tests on PRs to avoid long-running commits.
