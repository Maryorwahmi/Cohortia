Module 6 › Chapter 6.5 › What is Continuous Integration?
Definition & Purpose

Continuous Integration runs automated builds and tests on frequent code integrations so problems are detected early.

Example: Push to main triggers a build that runs unit tests and reports failures to the team.
Common mistake: Running only slow UI tests on every commit. Prefer fast unit tests more frequently.
Key Takeaway

CI makes integration predictable by automating builds and tests for every meaningful code change.

Two-column diagram: Steps in a CI Run
1. Commit
Developer pushes code to branch.
2. Build
CI server compiles the app and reports build errors.
3. Test
Run unit tests, then UI tests as configured.
