Module 6 › Chapter 6.5 › Activity: Create Workflow
Lab Steps
  1. Open your Xcode project connected to a Git repo.
  2. Go to Product → Xcode Cloud → Create Workflow.
  3. Connect your Git provider and allow access.
  4. Set trigger to branch changes and choose main.
  5. Enable Build, Test, and Archive actions; create workflow.
  6. Push a small change to trigger a build and monitor in Report Navigator.
Hints & Checks
Check: Your Apple account must be linked for TestFlight distribution to work.
Hint: Start with minimal tests on commit, then expand test coverage in PR workflows.
If the build fails: examine logs, fix compilation or test failures, and re-run.
