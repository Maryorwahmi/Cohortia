Module 6 › Chapter 6.1 › What is an Architectural Pattern?
Definition

An architectural pattern provides a blueprint to organize code into responsibilities. It focuses effort on separation of concerns so teams can reason about and change code with confidence.

Why it matters: reduces coupling and improves testability.
Misconception: patterns are only for big apps — small apps gain clarity too.
Check: when the API response changes, which layers must adjust?
Key Takeaway

A pattern is a practical tool to make code resilient to future change.

Analogy

Think of an architecture like a building plan: load‑bearing structure, wiring, and finishes are separate so you can change paint without moving wiring.

Concrete scenario
If you store data locally during development and later replace it with a REST API, a clear Model layer makes this swap mostly invisible to the View and minimally invasive to the ViewModel.
