Module 6 › Chapter 6.1 › Counter Refactor
Starter Code
import SwiftUI struct CounterView: View { @State private var count: Int = 0 var body: some View { VStack { Text("Count: \(count)") .font(.largeTitle) .padding() HStack { Button("Decrement") { count -= 1 } Button("Increment") { count += 1 } } } } }
Refactor Steps
  1. Create CounterViewModel: ObservableObject with @Published var count
  2. Add increment() and decrement() methods
  3. In CounterView replace @State with @StateObject viewModel = CounterViewModel()
  4. Bind Text to viewModel.count and buttons to viewModel methods
Common mistake
Not marking count with @Published prevents the View from updating.
