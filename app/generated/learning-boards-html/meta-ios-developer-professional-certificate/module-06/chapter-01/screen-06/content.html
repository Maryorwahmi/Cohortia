View (excerpt)
The View displays tasks and invokes ViewModel methods for actions. Views bind to @Published properties so state changes re-render the UI.
<!-- View --> import SwiftUI struct TaskListView: View { @StateObject var viewModel = TaskListViewModel() @State private var newTaskTitle: String = "" var body: some View { NavigationView { VStack { HStack { /* input and Add button that calls viewModel.addTask */ } List { ForEach(viewModel.tasks) { task in HStack { Text(task.title) Spacer() Image(systemName: task.isCompleted ? "checkmark.circle.fill" : "circle") .onTapGesture { viewModel.toggleTaskCompletion(task: task) } } } } } } } }
Key Takeaway

ViewModels publish state, Views bind to it. Keep persistence and networking in Model or ViewModel, not in View rendering code.
