Module 6 › Chapter 6.1 › MVVM in SwiftUI
Model
Data & business logic

Persistence, networking, and core rules. Should be independent of UI types.

Example: Task struct with id, title, isCompleted
ViewModel
Presentation logic

Transforms model data for display, exposes @Published properties, and handles commands from the UI.

Uses ObservableObject and @Published to notify Views.
View
Declarative UI

Minimal logic. Binds to ViewModel properties and triggers ViewModel actions for user events.

Mistake: embedding persistence or network calls inside a View.
Key Takeaway

Use ObservableObject and @Published so Views react automatically while business logic stays in Model or ViewModel.
