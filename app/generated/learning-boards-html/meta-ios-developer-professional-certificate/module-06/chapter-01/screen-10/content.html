Reactive basics

ObservableObject is the publisher type. @Published marks individual properties that trigger updates to observing Views when they change.

ObservableObject: class-level change publisher
@Published: property-level emitter
Common mistakes
  • Forgetting @Published on properties you expect to update the UI
  • Using @ObservedObject where the View should own the ViewModel lifetime
Example flow
User taps a button → View calls ViewModel method → ViewModel updates @Published property → View re-renders automatically.
Key Takeaway
Reactive bindings are simple but require correct ownership annotations to work predictably.
