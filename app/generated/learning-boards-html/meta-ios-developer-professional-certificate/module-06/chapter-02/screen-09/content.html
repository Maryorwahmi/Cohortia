Test Navigator
Run tests selectively, inspect failures, and re-run just the failing tests. The navigator shows pass/fail state and links to assertions that failed.
Use the diamond run control to re-run individual tests as you debug failures.
Test Plans & Coverage
Test plans let you group and configure suites; code coverage shows which lines and functions your tests exercise so you can prioritize new tests.
Practical rule: aim for meaningful coverage in critical modules rather than a blanket 100% target.
When a coverage report shows gaps, write unit tests for the uncovered logic rather than adding incidental UI tests.
Key Takeaway

Use the Test Navigator for quick iterations, test plans for different suites, and coverage to find important gaps to test next.
