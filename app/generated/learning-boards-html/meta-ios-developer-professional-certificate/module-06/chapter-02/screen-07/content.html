Module 6 › Chapter 6.2 › UI Testing
Concept
UI tests use an application object to launch and interact with the app. Queries target elements by accessibility identifiers to avoid brittle tests that rely on labels or visual order.
Example: locate a text field by its accessibility identifier "New task title" then type and tap Add.
Pitfall: overly large UI test suites are slow and brittle; run a small set of critical flows instead.
Code snippet
import XCTest

final class YourAppNameUITests: XCTestCase {
  var app: XCUIApplication!

  override func setUpWithError() throws {
    continueAfterFailure = false
    app = XCUIApplication()
    app.launch()
  }

  func testAddTaskAndToggleCompletion() throws {
    let newTaskTextField = app.textFields["New task title"]
    newTaskTextField.tap()
    newTaskTextField.typeText("Buy Groceries")
    app.buttons["Add Task"].tap()
    XCTAssertTrue(app.staticTexts["Buy Groceries"].exists)
  }
}
Pro Tip

Assign explicit accessibility identifiers to interactive elements so UI tests remain stable when UI labels or layouts change.
