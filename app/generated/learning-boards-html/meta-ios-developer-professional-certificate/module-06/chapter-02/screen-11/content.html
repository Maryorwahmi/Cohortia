Test flow
Launch the app, locate the input using an accessibility identifier, enter text, tap Add, then assert the new item is visible. Next locate the completion toggle and tap it to verify the UI reflects completion.
Stability tip: use explicit identifiers like "addTaskButton" rather than visible labels to reduce brittleness.
Code snippet
func testAddTaskAndToggleCompletion() throws {
  let app = XCUIApplication()
  app.launch()

  let input = app.textFields["New task title"]
  XCTAssertTrue(input.exists)
  input.tap()
  input.typeText("Buy Groceries")
  app.buttons["Add Task"].tap()

  XCTAssertTrue(app.staticTexts["Buy Groceries"].exists)

  let completionCircle = app.images["circle"]
  XCTAssertTrue(completionCircle.exists)
  completionCircle.tap()

  let checkmark = app.images["checkmark.circle.fill"]
  XCTAssertTrue(checkmark.exists)
}
Common Mistake

Relying on text labels or cell indices makes tests fragile; prefer stable accessibility identifiers for elements you query.
