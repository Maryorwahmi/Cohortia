Module 6 › Chapter 6.2 › Arrange‑Act‑Assert
The pattern
Arrange: prepare the environment and inputs. Act: perform the operation under test. Assert: verify results using XCTest assertions.
Arrange: create a fresh TaskListViewModel and clear UserDefaults.
Act: call viewModel.addTask(title: "Test New Task").
Assert: XCTAssertEqual task count increased and the new task exists and is not completed.
Common mistake: relying on the global app state. Fix it by isolating state in setUpWithError and restoring in tearDownWithError.
Example checklist
  1. Use setUpWithError() to create fresh instances.
  2. Clear shared storage used by code under test.
  3. Call the method under test with representative inputs.
  4. Use XCTAssert helpers to express expected state.
Key Takeaway

Structure tests with AAA and isolate state to avoid flaky results and hidden dependencies.
