Hands-on Activity

Configure an App for Distribution

Follow these steps in your environment to practice preparing an app for submission without uploading the binary.

1
Verify Bundle ID
Open target > Signing & Capabilities and copy the exact identifier.
2
Enable Signing
Check automatically manage signing and select the enrolled team.
3
Add Capability
Add Push Notifications to see the App ID update in the portal.
4
Archive
Set destination to Any iOS Device and choose Product > Archive; validation is optional for the exercise.
5
Create App Record
In App Store Connect, My Apps > + > New App, select the exact Bundle ID and fill metadata.
Inspect
Open the new app record App Store tab to review sections for screenshots, description, and build association.
Key Takeaway

Practice the sequence, copy strings to avoid typos, and use Organizer validation to reveal issues before attempting an upload.
