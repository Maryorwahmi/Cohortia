Module 6 › Chapter 6.4 › Provisioning Profiles
Process

What a provisioning profile contains

Profiles link an App ID and a certificate and, when relevant, a list of test devices. They are essential for Xcode to produce signed binaries that run on devices or are valid for App Store submission.

App Store Profile

Contains the App ID and a distribution certificate. No device list is included because App Store builds target all devices via the store.

Development / Ad Hoc Profile

Includes registered device IDs and is used for testing on specific hardware during development or ad hoc distribution.

Practical Steps
  1. Create App ID with required capabilities.
  2. Create or select a distribution certificate.
  3. Create an App Store provisioning profile binding the two.
Common Mistake

Using a profile tied to the wrong certificate or expired identity will fail signing during archive or upload.

Key Takeaway

When signing fails, inspect the provisioning profile for the App ID and certificate it references and refresh it if needed.
