Comparison

What you enter when creating a new app

Key fields include the platform, app name, primary language, Bundle ID, and SKU. These fields connect your metadata and uploaded builds to the signed binary that Xcode produces.

Screenshots & Previews

High-quality images for each device size help reviewers and users understand your app.

App Review Info

Provide contact info, demo credentials if needed, and notes for the review team to reproduce flows that require login.

Step-by-step
  1. My Apps > + > New App
  2. Choose Platform and enter Name, Primary Language, Bundle ID, SKU
  3. Fill App Information and upload screenshots
Common Mistake

Selecting the wrong Bundle ID from the dropdown or entering a name that conflicts with an existing App Store listing can delay submission.

Key Takeaway

Create the app record with the exact Bundle ID and complete metadata so the uploaded build can be associated and reviewed without delays.
