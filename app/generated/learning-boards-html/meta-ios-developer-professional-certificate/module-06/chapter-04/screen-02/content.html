Learning Objectives

Skills you will practice in the hands-on lab and the release checklist you'll remember.

Bloom: Learn → Understand → Apply → Master
01
Enroll & Account Roles

Explain what the Apple Developer Program provides and set the correct team in Xcode so builds use the right account. This matters because signing and access to capabilities are account-linked.

VERIFIED COMPETENCY MILESTONE
02
Certificates & Profiles

Identify development vs distribution certificates and describe how provisioning profiles bind an App ID and certificate. Practice reviewing profiles in Xcode and the developer portal.

VERIFIED COMPETENCY MILESTONE
03
Xcode Signing & Capabilities

Configure bundle identifier, enable automatic signing, and add capabilities like Push Notifications. This prepares entitlements used at runtime and required by reviewers.

VERIFIED COMPETENCY MILESTONE
04
App Store Connect & Archive

Create an app record, fill metadata, and archive a build in Xcode ready for upload. Learn the Organizer workflow and how to associate a build with an app record.

VERIFIED COMPETENCY MILESTONE
