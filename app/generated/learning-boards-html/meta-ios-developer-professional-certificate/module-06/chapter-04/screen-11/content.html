Common Failure Modes

Bundle ID Mismatch

Cause: different string in Xcode vs App Store Connect. Fix: update either Xcode or App Store record to match exactly.

Expired Certificate

Cause: certificate expired. Fix: revoke and regenerate distribution certificate, then refresh provisioning profiles.

Invalid Binary

Cause: missing icons, wrong architectures, or malformed binary. Fix: validate archive, fix assets, rebuild and re-upload.

Missing Entitlements

Cause: capability not enabled in App ID or profile. Fix: enable capability in portal and regenerate the profile.

Troubleshooting Steps
  1. Read the exact error in Xcode/Organizer or App Store Connect.
  2. Confirm Bundle ID, team, and certificate presence.
  3. Validate archive and review logs for missing assets.
Pro Tip

Coordinate certificate changes with your team. Revoking certificates affects all profiles that reference them, so plan carefully.
