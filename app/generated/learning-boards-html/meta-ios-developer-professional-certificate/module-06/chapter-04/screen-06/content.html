Module 6 › Chapter 6.4 › App ID & Bundle Identifier
Definition

Unique identity for your app

The App ID identifies your app to Apple and is the authoritative name used for entitlements and matching profiles. The Bundle Identifier in Xcode is the local value that must match that App ID.

Example

If your app's bundle identifier is com.example.MyApp, register the App ID com.example.MyApp in the developer portal and select the exact same ID when creating the App Store Connect app record.

Wildcard vs Explicit

Wildcard App IDs allow multiple bundle IDs to match a single ID, but explicit App IDs are required for certain capabilities like Push Notifications.

Checklist
  • Copy bundle identifier from Xcode
  • Create App ID with same exact string
  • Enable required capabilities on App ID
Key Takeaway

Avoid typos and mismatches: the bundle identifier is the single source of truth that ties your code to provisioning and the App Store record.
