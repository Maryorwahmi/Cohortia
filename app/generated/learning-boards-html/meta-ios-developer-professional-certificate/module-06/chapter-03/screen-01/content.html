Managing Dependencies with Swift Package Manager
Add, update, and modularize Swift code reliably with SPM and Xcode
In this lesson

Learn how to add remote packages, create local packages for modular code, resolve versions to avoid conflicts, and use Xcode’s package UI to manage dependencies.

Add Packages
Add remote libraries by repository URL and choose version rules.
Local Packages
Create small modules like Analytics or UI Components for reuse and faster builds.
Resolve Versions
Prefer fixed versions or "Up to Next Major" to avoid unstable changes from main branches.
Why this matters

Good dependency management prevents version conflicts, reduces wasted debugging time, and keeps your app stable as third-party code evolves.

Visual concept
Remote packages, local packages, and version rules form a package graph that SPM resolves.
Remote
Add from Git URLs like https://github.com/Alamofire/Alamofire.git
Local
Create reusable modules inside your workspace with Package.swift
Versioning
Choose specific versions or "Up to Next Major" to avoid breaking changes
