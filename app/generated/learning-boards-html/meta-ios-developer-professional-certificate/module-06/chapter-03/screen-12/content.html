Module 6 › Chapter 6.3 › Common mistakes and safety notes
Common issues
  • Dependency Conflicts: Conflicting version requirements across packages.
  • Main branch reliance: Tracks unstable code; avoid for production.
  • Large graphs: More dependencies can increase build time and binary size.
  • Linking errors: Package added but not linked to target causes import failures.
Safety notes
Prefer pinned tags or version ranges that match your stability needs. Update packages incrementally and use CI to run tests after changes. Review the transitive dependency list before adding heavy libraries.
Tip
If a resolver error appears, inspect which package constraints conflict and either change the rule or replace the package with an alternative.
