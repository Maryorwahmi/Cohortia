Module 6 › Chapter 6.3 › Adding a remote package in Xcode
Step-by-step
  1. Open your Xcode project and choose File > Add Packages...
  2. Paste the package Git URL into the search bar and press Enter.
  3. Choose a version rule: specific version, up to next major, or branch.
  4. Select the product and the targets that will link to it.
  5. Click Add Package and confirm the package appears under Swift Package Dependencies.
Concrete example
Add Alamofire with its Git URL, choose "Up to Next Major" for stability, and link the networking target so you can import Alamofire in your files.
Versioning guidance
Prefer pinned versions or Up to Next Major over a branch name to avoid unexpected breaking changes. Branches like main can introduce unstable code into your build.
Tip
When you add a package, check the resolved version in Project Settings to confirm compatibility with your other dependencies.
Pitfall
Forgetting to link a product to your app target causes import errors even when the package is present in the project.
