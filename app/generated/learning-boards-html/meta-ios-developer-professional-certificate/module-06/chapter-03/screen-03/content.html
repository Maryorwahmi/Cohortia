Checklist for adding packages
Keep this sequence visible while you work through the lab steps.
  1. URL — paste the repository URL in File > Add Packages...
  2. Version — choose a specific tag or Up to Next Major for stability.
  3. Link — select which targets will use the package product.
  4. Import — import the package module in your Swift files and build.
Mnemonic
URL → Version → Link → Import
Troubleshooting quick tips
  • Read Xcode resolver messages to find conflicting version constraints.
  • Avoid depending on main or master for production stability.
  • Limit transitive dependencies to reduce binary size and build time.
Common mistake

Forgetting to link the package product to your app target will cause import errors even though the package is added to the project.
