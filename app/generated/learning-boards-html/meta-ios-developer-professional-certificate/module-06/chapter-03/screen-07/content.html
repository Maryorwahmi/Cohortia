Module 6 › Chapter 6.3 › Importing and using a package in code
Example usage
After linking the package product to your target, import the module and use its public API.
import Alamofire // Import the package

func fetchDataWithAlamofire() {
  AF.request("https://api.example.com/data")
    .validate(statusCode: 200..<300)
    .responseDecodable(of: MyDataModel.self) { response in
      switch response.result {
      case .success(let data):
        print("Fetched data: \(data)")
      case .failure(let error):
        print("Error fetching data: \(error)")
      }
    }
}

struct MyDataModel: Decodable {
  let message: String
}
Explanation
  • import Alamofire makes the package module available to your file.
  • AF.request is the library’s convenience API for HTTP requests.
  • Use responseDecodable to map JSON into your Decodable model directly.
Misconception

Repository names and import module names can differ; verify the product module name if imports fail.
