Transactable Protocol & Transfer Logic

A small transfer contract enforces safe fund movement between accounts.

Protocol
protocol Transactable {
  func transfer(amount: Double, to destinationAccount: BankAccount)
}
Both BankAccount and PremiumAccount will conform and implement transfer.
Implementation Notes
  • Try withdraw first and only deposit if it succeeds to avoid inconsistent state.
  • Respect the concrete rules of the source account (standard or premium) during withdraw.
  • Print messages describing the transaction success or failure for testing.
Example Test
Transfer 150 from Alice (BankAccount) to Bob (PremiumAccount) and verify both balances after operation.
Misconception
Don't deposit before confirming withdrawal success; this can leave destination funded without source deduction.
Check
Simulate scenarios including overdraft to ensure transfer semantics hold for all account types.
