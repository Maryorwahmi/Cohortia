Definition

Structs, Methods, and Mutating

Why the mutating keyword exists and how it preserves value semantics.

Protocol Example
protocol Authenticatable {
  var email: String { get }
  func login(password: String) -> Bool
  mutating func logout()
}

struct User: Authenticatable {
  let email: String
  var isLoggedIn: Bool = false

  func login(password: String) -> Bool { /* ... */ }
  mutating func logout() { isLoggedIn = false }
}
Because User is a struct, logout must be mutating to change isLoggedIn.
Contrast: Classes
Classes do not require mutating. Instance methods can modify stored properties directly because references point to the same object.
Practical Tip
Choose structs for small, copyable models; choose classes if shared identity and observation are needed.
Example
A user session may be a class; a display coordinate should be a struct.
Misconception
Mutating does not change other copies; it changes only that struct instance.
Check
If multiple references must reflect the same state, prefer a class over a struct.
