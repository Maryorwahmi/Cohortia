Definition

Access Control

Keep internal details hidden and expose a stable interface.

private / fileprivate
Hide implementation inside a declaration or file. Use for helper methods and internal state you don't want others to call.
internal
Default for app modules. Accessible throughout your target and appropriate for most code.
public / open
Use when exposing APIs from frameworks. Open additionally allows external subclassing and overriding.
Example
Mark internal helper methods private to keep a clean public API for a BankAccount class.
Misconception
Avoid defaulting to public for convenience — it increases your maintenance burden.
