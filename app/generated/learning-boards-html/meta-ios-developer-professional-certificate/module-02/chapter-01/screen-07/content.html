Protocols and Polymorphism

Contracts make code flexible and testable across types.

Protocol Definition
protocol Authenticatable {
  var email: String { get }
  func login(password: String) -> Bool
  mutating func logout()
}
This declares expectations for conforming types without prescribing how they implement them.
Conformance Example
struct User: Authenticatable {
  let email: String
  var isLoggedIn: Bool = false
  func login(password: String) -> Bool { /* ... */ }
  mutating func logout() { isLoggedIn = false }
}
Both structs and classes can conform and be used via the protocol type.
Use Case
Define a Persistable or Transactable protocol and implement it across varied account types.
Misconception
Protocols do not supply behavior unless you use protocol extensions to add defaults.
Check
Can two unrelated types implement the same protocol? Yes — that's polymorphism.
