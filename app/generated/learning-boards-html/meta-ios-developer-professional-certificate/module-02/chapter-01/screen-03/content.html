Practice Objectives

Concrete skill checks and small code tasks to reinforce design choices.

Properties & Methods
Declare stored properties, control access, and implement instance methods that change state safely.
Mutating for Structs
Understand and use the mutating keyword for value types when methods change internal data.
Protocol Design
Create clear contracts and prefer protocols for flexible, testable code.
Access Levels
Protect implementation with private/fileprivate and expose stable APIs with internal or public as needed.
