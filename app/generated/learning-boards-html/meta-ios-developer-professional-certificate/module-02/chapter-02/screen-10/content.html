ProfileCardView (excerpt)
struct ProfileCardView: View {
  var body: some View {
    VStack(alignment: .leading, spacing: 10) {
      Image(systemName: "person.crop.circle.fill")
        .resizable()
        .frame(width: 80, height: 80)
        .foregroundColor(.blue)

      Text("John Doe")
        .font(.largeTitle)
        .fontWeight(.bold)

      HStack {
        Image(systemName: "envelope.fill")
          .font(.caption)
        Text("john.doe@example.com")
          .font(.caption)
          .foregroundColor(.gray)
      }

      Spacer()
    }
    .padding()
    .background(Color.white)
    .cornerRadius(15)
    .shadow(radius:5)
  }
}
Explanation & tips
  • resizable() then frame() controls image size.
  • font and fontWeight apply to Text; use .foregroundColor for SF Symbols.
  • padding before background makes the padded area part of the card.
