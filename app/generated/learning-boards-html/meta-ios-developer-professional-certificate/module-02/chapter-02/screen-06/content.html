Core Views › Text, Image, Button
Text
Displays a string. Style with font, fontWeight, foregroundColor.
Example
Text("John Doe").font(.largeTitle).fontWeight(.bold)
Image & Button
Image(systemName:) for SF Symbols. Use resizable() and frame(). Button runs a closure when pressed.
Example
Image(systemName: "star.fill").resizable().frame(width:80,height:80).foregroundColor(.blue)
Concrete scenario
A profile card shows a resizable profile Image, the person’s name using Text, and a Button to follow or message. Use modifiers to style each element and combine them with stacks for layout.
