Hands-on Activity › Recipe Card
Requirements
  1. VStack for main layout.
  2. Resizable Image with fixed frame at the top.
  3. Title and two-line description Text.
  4. HStack with prep and cook time icon-text pairs.
  5. Apply padding, background, cornerRadius, and shadow.
Starter code hint
VStack(alignment: .leading, spacing: 8) {
  Image(systemName: "fork.knife.circle.fill")
    .resizable()
    .scaledToFit()
    .frame(width:100, height:100)
    .foregroundColor(.orange)

  Text("Delicious Pasta Bake").font(.title2).fontWeight(.bold)
  Text("A hearty and flavorful pasta bake...").font(.body).foregroundColor(.secondary).lineLimit(2)

  HStack(spacing:15){ /* Prep and Cook */ }
}
.padding()
.background(Color.white)
.cornerRadius(12)
.shadow(radius:8)
