Core Concept › Declarative UI
Definition & Why it matters

A declarative UI is a description of desired appearance given state. You change state, SwiftUI re-renders the necessary parts, reducing imperative update code.

  • Less boilerplate: no manual setNeedsDisplay or view property juggling.
  • Local reasoning: each view reads state and declares appearance.
  • Performance: SwiftUI diffs views and updates only changed parts.
Example
Toggle a boolean to switch between a profile display and a sign-in button. The view description changes and SwiftUI updates the UI automatically.
Common misconception
Declarative does not remove layout control. It removes manual update steps. You still choose containers, alignment, and modifier order to get the exact result.
Key Takeaway
Think in state, split large views into smaller state-driven components, and let SwiftUI handle diffing and updates.
