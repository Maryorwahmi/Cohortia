Comparison › Modifier Order
Padding then Background (includes padding)
Text("Hello")
  .padding(10)
  .background(Color.blue)
  .cornerRadius(5)
Result: blue pill that covers padded area.
Background then Padding (padding outside)
Text("Hello")
  .background(Color.blue)
  .padding(10)
  .cornerRadius(5)
Result: blue area tight to text, with transparent padding around it.
Key Takeaway
Modifier order controls whether effects apply inside or outside other visual changes. Use previews to confirm.
