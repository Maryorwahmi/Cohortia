View protocol

A View provides a body property that returns some View. The body is recomputed when state used inside it changes.

  • Return a single root view from body.
  • Use composition: factor UI into small View structs.
  • Use properties to pass state into child views.
Misconception & Fix
Error: "Function declares an opaque return type 'some View' but the return statements in its body do not have matching underlying types." Usually caused by returning different root view types conditional on state. Fix by wrapping options in an AnyView or keeping the same container structure.
Quick tip
Keep bodies predictable: return the same container type even when contents vary.
