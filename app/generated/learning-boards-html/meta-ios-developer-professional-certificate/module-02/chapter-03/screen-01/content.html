State Management in SwiftUI
Property wrappers express ownership and drive the view lifecycle.
Why it matters
A correct choice keeps your UI consistent, your model persistent across view updates, and your code easier to reason about.
What you'll build
A counter, a bound child control, a task store using ObservableObject, and a tip calculator that updates as inputs change.
Explore Key Topics
@State
Local, private state for a single view. Triggers view updates when changed.
@Binding
Two-way connection so a child can mutate a parent's source of truth.
ObservableObject & Environment
Shared models with @Published, observed or injected into the environment for broad access.
Visual concept
Local owner
@State — a view owns the data and updates its body when it changes.
Shared model
ObservableObject with @Published — changes broadcast to observers.
Environment
@EnvironmentObject injects a shared instance across many descendant views.
