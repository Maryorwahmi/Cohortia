Coding Challenge › ItemManager
Expected structure
Implement ItemManager as ObservableObject and wire parent and child views to demonstrate ownership.
class ItemManager: ObservableObject {
    @Published var items: [String] = ["Item 1", "Item 2"]

    func addItem(name: String) {
        items.append(name)
    }
}

struct ChildDisplayView: View {
    @ObservedObject var manager: ItemManager // Observes, but doesn't own

    var body: some View {
        Text("Total Items: \(manager.items.count)")
            .font(.headline)
    }
}

struct ParentDataView: View {
    @StateObject var itemManager = ItemManager() // Parent owns the ItemManager

    var body: some View {
        NavigationView {
            VStack {
                List { ForEach(itemManager.items, id: \.self) { item in Text(item) } }
                ChildDisplayView(manager: itemManager)
                Button("Add New Item") { itemManager.addItem(name: "New Item \(itemManager.items.count + 1)") }
                    .padding()
            }
            .navigationTitle("Item List")
        }
    }
}
Test
Toggle a parent @State to force re-creation and confirm the item list persists when using @StateObject.
Guidance
  • Implement @Published to notify observers of changes.
  • Parent should create and own the manager with @StateObject.
  • Pass the same instance to children and observe with @ObservedObject.
  • Verify lifecycle by forcing view re-creation and checking persistence.
Reflection

If the data persists, you chose the correct ownership. If not, reconsider whether @StateObject should own the instance.
