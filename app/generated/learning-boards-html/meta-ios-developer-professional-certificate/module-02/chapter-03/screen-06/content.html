Binding example
Parent owns the data, child mutates it via a binding.
<!-- Parent and Child binding example -->
struct ChildCounterView: View {
    @Binding var value: Int // A binding to an Int from a parent

    var body: some View {
        Stepper("Child Value: \(value)", value: $value)
            .padding()
    }
}

struct ParentView: View {
    @State private var parentCount: Int = 0

    var body: some View {
        VStack {
            Text("Parent Count: \(parentCount)")
                .font(.title)
            ChildCounterView(value: $parentCount) // Pass a binding to parentCount
        }
    }
}
Concrete Use
Custom form fields and controls commonly accept bindings so they remain reusable.
Pitfall
Bindings must refer to mutable storage; you cannot bind to a computed constant or derived value without a stored source.
Teaching bullets
  • The parent retains source of truth with @State.
  • Pass $state to a child's initializer to create a binding.
  • Child declares @Binding to read and write the value directly.
  • Use bindings for single values; prefer ObservableObject for complex shared models.
Key Takeaway

Use @Binding to give a child safe write access to a parent’s state while preserving a single source of truth.
