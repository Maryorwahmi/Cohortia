Practice map

Each objective connects to code and UI tasks you will implement in the hands-on activity.

Decode with JSONDecoder

Decode server Data into Post using JSONDecoder; use do-catch to surface decoding errors to the UI.

Compose URLRequest for POST

Create URLRequest, set httpMethod = "POST", and prepare it to carry encoded JSON in the body.

Encode with JSONEncoder

Encode Post to Data, optionally pretty-printed for logs, and set request.httpBody before sending.

Layered error handling

Check for network Error, then HTTP status codes, then decoding errors to provide specific user messages.
