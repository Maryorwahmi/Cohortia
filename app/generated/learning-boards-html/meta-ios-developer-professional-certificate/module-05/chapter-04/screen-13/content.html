Activity: Create a New Post

Step-by-step checklist to implement the feature in a SwiftUI app.

Steps
  1. Define Post struct with id: Int?.
  2. Implement PostCreator with @Published properties.
  3. Construct URLRequest, set method and headers.
  4. Encode post to JSON and set httpBody, send via URLSession.
  5. Handle error → HTTP status → decode, update UI on main thread.
UI integration

Use a Form with two TextFields and a Button. Disable the button while isLoading is true. Show ProgressView during requests and display createdPost or errorMessage after completion.

Pro tip: simulate server errors and malformed JSON to verify your error messages and decoding checks behave as expected.
