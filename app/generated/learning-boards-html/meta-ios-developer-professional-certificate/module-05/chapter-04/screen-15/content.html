Module 5 › Chapter 5.4 › Key Reminders
Content-Type
Always set Content-Type to application/json for JSON request bodies so the server parses the payload correctly.
Optional fields
Use optional properties like id: Int? for server-assigned values to avoid decoding errors during creation flows.
Centralize headers
Attach headers such as Authorization consistently via a request factory to avoid omission and simplify token refresh logic.
Final takeaway

Small structural choices in models and headers reduce decoding errors and make your networking robust and maintainable.
