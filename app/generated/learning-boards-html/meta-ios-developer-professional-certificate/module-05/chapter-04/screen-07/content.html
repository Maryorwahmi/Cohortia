Encoder Pattern

Encode a Post to Data

do {
  let encoder = JSONEncoder()
  encoder.outputFormatting = .prettyPrinted // helpful for logs
  let jsonData = try encoder.encode(newPost)
  request.httpBody = jsonData
} catch {
  // Handle encoding error and inform user
}
Tip: Convert jsonData to String to inspect the exact payload sent to the server for quick debugging.
Example output for debugging
{
  "userId": 1,
  "title": "My First Cohortia Post",
  "body": "This is a test post from my iOS app!"
}
Misconception check

Pretty printing is for logs and should not be relied on to change server parsing. Always set Content-Type so the server knows the data is JSON, regardless of formatting.
