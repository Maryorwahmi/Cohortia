Process

Build a POST request

  1. Create a URL and URLRequest(url:).
  2. Set request.httpMethod = "POST".
  3. Encode your Codable object with JSONEncoder.
  4. Assign encoded Data to request.httpBody.
  5. Set headers like Content-Type and Authorization as needed.
Common mistake

Using GET or leaving out Content-Type leads to server misinterpretation or rejection of the JSON body.

Compact code pattern
var request = URLRequest(url: apiURL)
request.httpMethod = "POST"
request.setValue("application/json", forHTTPHeaderField: "Content-Type")
let jsonData = try JSONEncoder().encode(post)
request.httpBody = jsonData
// then URLSession.shared.dataTask(with: request) ...
Scenario: When sending a new post, userId and title must match server expectations. Forgetting Content-Type often causes a 400 response because the server cannot parse the body.
