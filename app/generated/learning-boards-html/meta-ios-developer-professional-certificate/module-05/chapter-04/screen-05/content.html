Codable Model Best Practices

  • Use Int? for server-assigned IDs that are nil at creation.
  • Make fields optional if the API can omit them.
  • Use CodingKeys or keyDecodingStrategy to resolve naming differences.
Common mistake

Treat every JSON field as required. Missing keys cause decoding errors unless marked optional.

Example Post struct
struct Post: Codable, Identifiable {
  let id: Int? // nil when creating a new post
  let userId: Int
  var title: String
  var body: String
}
Scenario

When creating a post, id is nil locally. After POST, server returns a created post with an id. Make id optional to avoid decoding errors before creation.
