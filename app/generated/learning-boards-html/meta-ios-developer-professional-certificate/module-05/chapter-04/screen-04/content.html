Module 5 › Chapter 5.4 › JSONDecoder
Definition

JSONDecoder

A decoder that maps JSON Data to your Decodable or Codable Swift types. Use do-catch to surface and handle decoding errors.

Common configurations
  • dateDecodingStrategy to parse server date formats.
  • keyDecodingStrategy to convert snake_case to camelCase automatically.
  • Decode an array with decode([Post].self, from: data) when the payload is an array.
Key Takeaway

Decoding gives typed models and prevents fragile string parsing; configure strategies to match the API shape.

Code example
let decoder = JSONDecoder()
// Example: convert snake_case to camelCase
// decoder.keyDecodingStrategy = .convertFromSnakeCase

do {
  let post = try decoder.decode(Post.self, from: data)
  // Use post.title and post.body safely
} catch {
  // Inspect error to determine mismatch
}
Concrete example

If you receive {"user_id":1,"title":"Hi"}, use keyDecodingStrategy or CodingKeys to map user_id to userId. Missing this mapping causes keyNotFound errors.

Misconception: printing JSON as a String is enough. It helps debugging, but typed decoding is necessary for stable code and compile-time safety.
