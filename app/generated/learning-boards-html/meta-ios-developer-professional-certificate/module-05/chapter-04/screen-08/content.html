Module 5 › Chapter 5.4 › Error Handling
Compare failure types
Network Error

Connectivity problems and timeouts captured as Error?; suggest retry or check connection.

HTTP Status

Non-2xx status codes indicate server-level issues; handle 401, 403, 404, 500 with specific user messages.

Decoding Error

Occurs when JSONDecoder cannot map Data to your model; log payload and compare model shape to JSON.

Actionable pattern
// completion handler skeleton
if let error = error { /* network: show retry */; return }
guard let http = response as? HTTPURLResponse,
      (200...299).contains(http.statusCode) else { /* handle status code */; return }
guard let data = data else { /* no data */; return }
// then decode in do-catch
Misconception: treating any non-success as decoding error. Instead, inspect the status code first because a 4xx or 5xx response means the request itself failed.
