PostCreator roles
  • Manage isLoading, createdPost, errorMessage.
  • Encode Post, create request, run URLSession, decode response.
  • Dispatch UI updates on the main thread.
Key Takeaway

Keep networking code decoupled and update published state on the main thread so SwiftUI reacts correctly.

ContentView pattern
// Simplified usage pattern
Button("Create Post") {
  if !postTitle.isEmpty && !postBody.isEmpty {
    postCreator.createPost(title: postTitle, body: postBody)
  } else {
    postCreator.errorMessage = "Please enter both title and body."
  }
}
Misconception: calling networking code directly from view bodies. Use actions tied to buttons and centralize state in an ObservableObject for clarity and testability.
