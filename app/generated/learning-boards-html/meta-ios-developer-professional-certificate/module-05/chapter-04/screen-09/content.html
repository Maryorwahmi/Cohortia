Module 5 › Chapter 5.4 › HTTP Headers
Definition

Essential headers for JSON POSTs

  • Content-Type: application/json — tells the server how to parse httpBody.
  • Authorization: Bearer <token> — pass credentials for protected endpoints.
  • Other headers: Accept, custom API keys depending on the server contract.
Tip: centralize headers in a request builder so every request includes the same Content-Type and authorization behavior.
Code snippets
var request = URLRequest(url: apiURL)
request.httpMethod = "POST"
request.setValue("application/json", forHTTPHeaderField: "Content-Type")
request.setValue("Bearer ", forHTTPHeaderField: "Authorization")
// request.httpBody = jsonData
Misconception: storing tokens in plain text or logging them. Keep tokens secure and avoid printing them in logs for production builds.
