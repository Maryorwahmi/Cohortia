Learning Objectives

Bloom targets: Learn → Understand → Apply → Master

Bloom: Learn • Understand • Apply • Master
01
Use JSONDecoder

Parse Data into Decodable/Codable types to convert server JSON into usable models for your app. This replaces fragile manual string parsing with typed access.

Verified competency milestone
02
Build POST URLRequests

Create URLRequest, set httpMethod to POST, and prepare the request object so your encoded JSON can be delivered in the request body.

Verified competency milestone
03
Encode Codable to JSON

Use JSONEncoder to convert a Codable Swift object into Data, then assign it to httpBody so the server receives structured JSON.

Verified competency milestone
04
Handle network & decoding errors

Differentiate URLError, non-2xx HTTP status codes, and JSONDecoder errors to provide clear, actionable feedback in the UI.

Verified competency milestone
