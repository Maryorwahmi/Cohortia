Why these objectives matter

An app that freezes on a long task provides a poor user experience and risks termination by the system. These objectives teach both low-level control and modern, safer patterns so you can choose the right tool for the job and avoid common mistakes.

Concrete example: offload image processing to a global queue, then update the UI on the main queue or via a MainActor-view model.
Mnemonic: Background work then Main update — think "Compute, then present".
