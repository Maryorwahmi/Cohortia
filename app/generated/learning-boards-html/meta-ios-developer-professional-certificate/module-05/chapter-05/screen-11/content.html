Module 6 › Chapter 5.5 › Pitfalls & Safety
Common issues
  • Race conditions: avoid by isolating mutable state on one queue or using actors.
  • Deadlocks: avoid blocking waits and circular resource locks.
  • Retain cycles: use weak captures or structured tasks to prevent leaks.
  • Cancellation: design tasks to check cancellation and return early.
Quick remedies
Use @MainActor or a dedicated serial queue for shared state.
Prefer TaskGroup for related async jobs and use Task.cancel for cooperative cancellation.
Audit closure captures for retain cycles and use weak self inside long-lived closures.
Warning

Avoid moving heavy work onto the main actor; it defeats the purpose of concurrency and causes UI blocking.
