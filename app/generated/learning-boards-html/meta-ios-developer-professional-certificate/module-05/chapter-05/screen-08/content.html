Module 6 › Chapter 5.5 › Image Loader
Starter code overview
@MainActor
class ImageLoader: ObservableObject {
    @Published var loadedImages: [UIImage] = []
    @Published var isLoading: Bool = false
    @Published var errorMessage: String?

    func loadImages(from urls: [URL]) async {
        isLoading = true
        errorMessage = nil
        loadedImages = []

        await withThrowingTaskGroup(of: UIImage?.self) { group in
            for url in urls {
                group.addTask {
                    do {
                        let (data, _) = try await URLSession.shared.data(from: url)
                        return UIImage(data: data)
                    } catch {
                        return nil
                    }
                }
            }

            for await image in group {
                if let image = image {
                    self.loadedImages.append(image)
                }
            }
        }

        isLoading = false
    }
}
Note: because the class is @MainActor, appending images updates the published property safely on the main thread. If you removed MainActor, you would need explicit dispatching.
Also consider cancellation: wrap long downloads with checks for Task.isCancelled and use URLSession tasks that support cancellation.
Practical tips
  • Use TaskGroup to control concurrency and collect results.
  • Use async let for simpler concurrent awaits when ordering is predictable.
  • Mark view models with @MainActor to avoid explicit main dispatching for UI state.
Key Takeaway

Structured concurrency lets you fetch many items concurrently and update UI state safely when using MainActor.
