Module 6 › Chapter 5.5 › What is concurrency?
Short definition

Concurrency is interleaving or parallel execution of tasks so an app can remain responsive while work continues in the background.

Concrete example
Imagine filtering 200 images. Doing this on the main thread will freeze scrolling. Move filtering to a background queue and update visible images on the main thread.
Misconception
Starting work in onAppear does not move it off the main thread automatically. You must use a Task or a dispatch queue.
Visual mnemonic
Main Thread
UI events • animations • view updates
Background
Network • computation • file I/O
Key Takeaway

If a task can take noticeable time, run it off the main thread and then dispatch results back to the main thread for UI updates.
