Module 6 › Chapter 5.5 › MainActor
Why use MainActor
Marking a view model with @MainActor means all its methods and property access execute on the main actor, ensuring UI safety without boilerplate dispatching.
It reduces accidental UI updates from background threads and simplifies code that manipulates @Published properties.
Use MainActor for view models and small controllers; keep performance-sensitive work off the actor.
Example annotation
@MainActor
class DataFetcher: ObservableObject {
  @Published var data: String = ""
  func fetchData() async { ... }
}
Key Takeaway

Use @MainActor to keep UI state updates safe and free your code from repetitive main-queue dispatches.
