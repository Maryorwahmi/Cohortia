Module 6 › Chapter 5.5 › GCD Basics
Queues
Main Queue — serial, UI updates only. Access with DispatchQueue.main.
Global Queues — concurrent, use DispatchQueue.global(qos: .userInitiated) or other QoS levels.
QoS — choose priority that matches the user's expectation for that work.
Process
1. Dispatch background task
2. Do work
3. Dispatch to main for UI
When to prefer which QoS
  • .userInitiated — user waits for result, update UI quickly.
  • .utility — longer tasks that benefit the user but are not instantaneous.
  • .background — low-priority maintenance like syncing or prefetching.
Example code
// GCD pattern
DispatchQueue.global(qos: .userInitiated).async {
  // perform heavy work
  let result = performWork()
  DispatchQueue.main.async {
    // update UI with result
    updateViews(result)
  }
}
Key Takeaway

Pick an appropriate QoS for background tasks and always perform UI work on the main queue.
