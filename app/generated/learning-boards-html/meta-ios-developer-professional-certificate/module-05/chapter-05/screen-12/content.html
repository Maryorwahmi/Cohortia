Module 6 › Chapter 5.5 › Key Concepts
Concurrency
Run long tasks off the main thread to keep UI responsive.
GCD Queues
DispatchQueue.main for UI; DispatchQueue.global(...) for background work with QoS.
async/await & MainActor
Structured concurrency with Tasks and actors simplifies state and cancellation.
One-line takeaway

Keep heavy work off the main thread, choose the right concurrency tool, and protect shared state to build smooth, reliable apps.
