Module 6 › Chapter 5.5 › GCD vs Async
Grand Central Dispatch
Low-level queue control, serial or concurrent queues, QoS tuning.
Ideal for custom serial queues or precise scheduling.
Requires manual dispatch back to main for UI updates.
async/await
Structured concurrency, Tasks and TaskGroup simplify cancellation and error handling.
Use actors and @MainActor to manage isolated state safely.
Better readability and testability for many async flows.
Decision guide
Need explicit queue control or integrate C APIs? Use GCD.
Need structured cancellation, simpler composition, and better readability? Use async/await.
