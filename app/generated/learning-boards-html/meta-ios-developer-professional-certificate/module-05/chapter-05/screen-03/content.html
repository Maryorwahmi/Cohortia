Module 6 › Chapter 5.5 › Objectives: Practice
Practical targets
  • Write DispatchQueue.global().async to run heavy work and DispatchQueue.main.async to update UI.
  • Define async functions and call them with await inside Tasks from a view.
  • Mark a ViewModel with @MainActor to keep published properties safe for UI updates.
  • Use TaskGroup or async let to download multiple items concurrently.
Practice reminders
Misconception check: calling a network API from onAppear without async behavior will block the main thread. Use Task or GCD to prevent that. Also, avoid Task.detached unless you intentionally want an unstructured lifetime.
Example mnemonic: "Background compute, then Main present."
Small test: simulate a slow loop on a background queue and verify UI remains responsive.
