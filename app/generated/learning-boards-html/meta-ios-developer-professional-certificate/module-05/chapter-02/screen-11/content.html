Writing safely
Use .atomicWrite to reduce partial-file corruption.
try data.write(to: fileURL, options: [.atomicWrite])
This uses a temporary file and replaces the original on success. It is a simple and effective way to protect user files during unexpected interruptions.
Check list
  • Use .atomicWrite for important files.
  • Still handle errors in do-catch.
  • Confirm available disk space before large writes.
Key Takeaway

Atomic writes are a low-effort, high-value protection against partial saves.
