Encoder configuration
An example encoder setup used in the lesson.
let encoder = JSONEncoder()
encoder.outputFormatting = .prettyPrinted // human readable
encoder.dateEncodingStrategy = .iso8601
let data = try encoder.encode(todos)
Why prettyPrinted
Makes JSON readable for debugging and for inspecting the simulator file contents.
Date strategy
Pick a strategy like iso8601 to ensure decoders can parse dates reliably across devices.
Practical notes
  • Always match encoder and decoder strategies.
  • Pretty printing is only for readability; it does not change the decoded values.
  • Wrap encode calls in do-catch to handle failures.
Key Takeaway

Consistent encoder and decoder configuration prevents subtle decode errors and misinterpreted dates.
