TodoStore: responsibilities
Load on init, save on mutation, expose published todos for UI binding.
class TodoStore: ObservableObject {
  @Published var todos: [TodoItem] {
    didSet { saveTodos() }
  }

  init() {
    self.todos = []
    loadTodos()
  }

  // saveTodos and loadTodos implemented using FileManager and Codable
}
Use @StateObject in your root view to ensure the store lives across view updates and to maintain a single source of truth for persistence.
Performance note
If many changes occur rapidly, consider debouncing saves or batching updates rather than saving on every mutation.
Key Takeaway

Keep persistence inside a store so the UI code remains declarative and testable.
