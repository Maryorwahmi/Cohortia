Codable in practice
Use Codable to synthesize serialization behavior for your types.
// Example struct from the lesson struct TodoItem: Codable, Identifiable { let id: UUID var title: String var isComplete: Bool let createdAt: Date init(id: UUID = UUID(), title: String, isComplete: Bool = false, createdAt: Date = Date()) { self.id = id self.title = title self.isComplete = isComplete self.createdAt = createdAt } }
Why it matters
You can persist well-typed objects to files and restore them without manual parsing.
Common pitfall
If you change property names, decoding older data may fail unless you provide migration strategies.
Quick concept cards
Encodable
Type can be converted to an external representation.
Decodable
Type can be restored from Data into an instance.
Customization
Use CodingKeys or encoder/decoder strategies for special cases like dates.
Key Takeaway

Codable is the idiomatic, type-safe route to serialize Swift data with minimal boilerplate.
