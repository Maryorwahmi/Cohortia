Module 5 › Chapter 5.2 › Saving Data
Save flow
A disciplined sequence prevents corruption.
1. Get file URL in Documents.
2. Configure JSONEncoder (formatting and dates).
3. Encode the array into Data inside do-catch.
4. Write Data using .atomicWrite.
static func saveTodos(_ todos: [TodoItem]) throws {
  let encoder = JSONEncoder()
  encoder.outputFormatting = .prettyPrinted
  encoder.dateEncodingStrategy = .iso8601

  let data = try encoder.encode(todos)
  let fileURL = getFileURL()

  try data.write(to: fileURL, options: [.atomicWrite])
  print("Successfully saved todos to \(fileURL.lastPathComponent)")
}
Example card
Saving three todo items will create or replace todos.json in Documents atomically, reducing corruption risk.
Pro tip
Use .atomicWrite to ensure the file is either fully written or left unchanged on failure.
Key Takeaway

Encode and write atomically inside do-catch, and avoid writing on the main thread for large datasets.
