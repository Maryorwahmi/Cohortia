Module 5 › Chapter 5.2 › Loading Data
Load flow
Check for file, read Data, decode with matching strategy.
static func loadTodos() throws -> [TodoItem] {
  let fileURL = getFileURL()

  guard FileManager.default.fileExists(atPath: fileURL.path) else {
    print("No todos file found. Returning empty array.")
    return []
  }

  let data = try Data(contentsOf: fileURL)
  let decoder = JSONDecoder()
  decoder.dateDecodingStrategy = .iso8601

  let todos = try decoder.decode([TodoItem].self, from: data)
  print("Successfully loaded todos from \(fileURL.lastPathComponent)")
  return todos
}
Example
If todos.json is missing, your app should start with an empty list rather than crashing.
Common mistake
Attempting to decode without checking existence leads to thrown errors that must be caught and handled.
Key Takeaway

Guard for missing files and decode inside do-catch, providing a sensible default if something goes wrong.
