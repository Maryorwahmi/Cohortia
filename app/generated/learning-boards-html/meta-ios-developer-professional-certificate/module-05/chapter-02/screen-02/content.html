Learning Objectives
Skills you'll demonstrate after finishing this chapter
Bloom: Learn → Understand → Apply → Master
01
Use Codable for serialization
Make custom types Encodable and Decodable so they can be converted to and from external formats. This matters because it preserves type safety and structure when you save data.
VERIFIED COMPETENCY MILESTONE
02
Encode and decode JSON
Use JSONEncoder and JSONDecoder to produce Data from Codable objects and restore them back again. You will control formats like prettyPrinted and date strategies to match your needs.
VERIFIED COMPETENCY MILESTONE
03
Interact with FileManager
Obtain sandbox URLs for Documents, Caches, and Application Support. Choosing the right directory prevents unintended data loss and controls backup behavior.
VERIFIED COMPETENCY MILESTONE
04
Implement save and load reliably
Write Data atomically and decode inside do-catch blocks. Handle missing files and corrupted data gracefully to protect user state.
VERIFIED COMPETENCY MILESTONE
