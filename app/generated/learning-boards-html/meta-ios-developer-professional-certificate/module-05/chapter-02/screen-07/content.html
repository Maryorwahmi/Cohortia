Standard directories
How to get the Documents directory URL.
let documents = FileManager.default.urls(for: .documentDirectory, in: .userDomainMask).first!
Documents
User files that should persist and be backed up.
Caches
Temporary files that can be purged by the system.
Application Support
Persistent app-specific data not directly created by the user.
Concrete advice
Store images produced by the user in Documents. Use Caches for downloaded thumbnails. Use Application Support for internal databases or non-user state files.
Key Takeaway

Select directories intentionally to control backup behavior and file lifetime.
