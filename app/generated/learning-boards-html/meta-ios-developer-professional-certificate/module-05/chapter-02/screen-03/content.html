Practical Objectives
Best practices, queues, and UI integration
Error handling
Use do-catch for encode, decode, read, and write operations. Print or surface clear messages and provide a fallback empty dataset when decoding fails.
VERIFIED COMPETENCY MILESTONE
Threading
Dispatch file operations to a background queue to avoid UI freezes. Consider small files synchronously, large files always asynchronously.
VERIFIED COMPETENCY MILESTONE
Backup and directory choice
Documents is backed up. Use Caches for reconstructable data. Keep backups in mind when storing large files.
VERIFIED COMPETENCY MILESTONE
SwiftUI integration
Make a TodoStore ObservableObject, call load on init and save on changes so UI and persistence stay in sync.
