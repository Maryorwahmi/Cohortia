Module 5 › Chapter 5.2 › Hands-on Activity
Activity steps
Implement, run, and verify todos.json in the simulator.
Step 1
Add TodoItem and TodoStore to your project.
Step 2
Load todos on init and save in didSet or a dedicated save call.
Step 3
Run the app, add items, and inspect the simulator files to confirm persistence.
Starter code hint
Look for saveTodos() and loadTodos() in TodoStore.swift; these functions use JSONEncoder/Decoder and FileManager.
Key Takeaway

Hands-on practice cements how Codable and FileManager work together and surfaces real-world edge cases like missing files and decoding errors.
