Module 5 › Chapter 5.1 › Saving & Retrieving
Editor: example code
// Define safe keys
extension UserDefaults {
  enum Keys {
    static let welcomeMessage = "welcomeMessage"
    static let isDarkModeEnabled = "isDarkModeEnabled"
  }
}

// Saving values
UserDefaults.standard.set("Hello, Cohortia!", forKey: UserDefaults.Keys.welcomeMessage)
UserDefaults.standard.set(true, forKey: UserDefaults.Keys.isDarkModeEnabled)

// Retrieving values
let message = UserDefaults.standard.string(forKey: UserDefaults.Keys.welcomeMessage) ?? "Welcome"
let darkMode = UserDefaults.standard.bool(forKey: UserDefaults.Keys.isDarkModeEnabled)
Explanation
  • Define keys to avoid typos and make refactoring safer.
  • Use typed getters to receive correct Swift types. Strings return optional; booleans return false if missing.
  • Provide sensible defaults when reading optionals so UI remains predictable.
Example scenario
Save the user's welcome message after they edit it so it reappears on next launch.
Gotcha
Remember that bool(forKey:) returns false if the key is missing; if false is a valid unset value, track presence separately.
