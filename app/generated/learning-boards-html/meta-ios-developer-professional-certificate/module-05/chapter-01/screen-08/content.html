Module 5 › Chapter 5.1 › Getter Behavior

Primitive getters

Methods like bool(forKey:) and integer(forKey:) return a default primitive when the key is missing. This can hide whether the key was ever set.

// Example behavior
let seen = UserDefaults.standard.bool(forKey: "hasSeenTutorial")
// If hasSeenTutorial is missing, seen == false

Optional getters

Methods like string(forKey:) return optional values and yield nil when absent, which you must unwrap or coalesce.

let name = UserDefaults.standard.string(forKey: "username") ?? "Guest"
// name will be "Guest" if username is missing
Key Takeaway

Always design logic that distinguishes 'unset' from meaningful default values, especially for booleans and numbers.
