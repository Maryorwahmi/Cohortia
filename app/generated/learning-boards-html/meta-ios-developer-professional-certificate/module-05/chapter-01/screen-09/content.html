When not to use UserDefaults

  • Large binary blobs like images or audio.
  • Complex, relational data that needs querying (use Core Data or SwiftData).
  • Sensitive secrets or credentials — prefer Keychain.
Security note
UserDefaults persists to a plist file in the app sandbox. While other apps cannot access it directly, the data is not encrypted. Do not store passwords or API keys here.
Alternative

Use Keychain for secrets and Core Data or files for structured or large data sets.
