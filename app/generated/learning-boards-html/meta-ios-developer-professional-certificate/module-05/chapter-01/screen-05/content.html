Key-value basics

UserDefaults stores values under unique string keys. It supports primitives like String, Bool, Int, Double, Date, Data, Array and Dictionary.

Concrete example
Store 'isDarkModeEnabled' as a Bool so the app can choose the correct theme on next launch.
Common mistake
Avoid saving large binary data or complex object graphs to UserDefaults; it can slow down your app.
API notes
  • Use UserDefaults.standard to access the shared store.
  • Call set(value, forKey: key) to save. Read with corresponding typed getters like bool(forKey:) or string(forKey:).
  • Prefer static constants for keys to avoid typos and enable autocomplete.
Key Takeaway

Use UserDefaults for simple, non-sensitive preferences and state. Keep data small and keys consistent.
