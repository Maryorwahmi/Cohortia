Centralize keys

Put all UserDefaults keys in one location to avoid duplication and make refactors safe.

extension UserDefaults {
  enum Keys {
    static let username = "username"
    static let appLaunchCount = "appLaunchCount"
    static let lastLoginDate = "lastLoginDate"
    static let isPremiumUser = "isPremiumUser"
  }
}
Why this helps
Single source of truth, easier migration, fewer runtime bugs from typos.
Migration note
If key meaning changes, write migration code to translate old stored values rather than breaking expected behavior for users.
Key Takeaway

Make keys centralized constants to reduce bugs, enable team collaboration, and simplify future changes.
