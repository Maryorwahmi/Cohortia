Module 5 › Chapter 5.1 › What is Data Persistence?
Clear definition

Persistence stores data so it remains available after the app closes. This provides continuity: preferences, counters, and small user inputs reappear on next launch.

Concrete example
Save a welcome message string so the greeting shown on launch matches the user's last edit.
Misconception
Persistence does not imply complexity. Small key-value stores are persistence too; choose the simplest correct solution.
Key Takeaway

Pick a storage method that fits data size and sensitivity: small flags go in UserDefaults; complex data needs a database.

Persistence vs Memory
  • In-memory: fast, lost on close.
  • Persistent: slower to write, survives restarts.
  • Question: Is the data sensitive, large, or query-heavy? Use that to decide.
Analogy
Think of memory as a whiteboard that clears when the lights go out, and persistence as a note you stick to the wall.
