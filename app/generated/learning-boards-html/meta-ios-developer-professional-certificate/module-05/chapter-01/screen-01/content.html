Data Persistence with UserDefaults

Learn how to persist small preferences and simple state using UserDefaults, keep keys safe, and integrate with SwiftUI using @AppStorage so settings survive app restarts.

Duration: 10 minutes • Live coding
Sticky Notes

Think of UserDefaults as tiny sticky notes that persist between launches.

Key-Value

Store values by a unique string key, similar to a dictionary lookup.

SwiftUI Ready

Use @AppStorage to bind UI directly to UserDefaults keys.

Visual analogy
Digital Sticky Pad
Small notes saved inside the app sandbox
Sample keys
username: "Alice"
isPremiumUser: true
appLaunchCount: 3
Why it matters
Persistence lets apps feel continuous and personal. UserDefaults is the simple, common method for small preferences.
