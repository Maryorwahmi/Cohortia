Module 5 › Chapter 5.1 › @AppStorage
Code: SwiftUI binding
import SwiftUI

struct SettingsView: View {
  @AppStorage("isDarkModeEnabled") var isDarkModeEnabled: Bool = false
  @AppStorage("welcomeMessage") var welcomeMessage: String = ""

  var body: some View {
    Form {
      Toggle(isOn: $isDarkModeEnabled) {
        Text("Enable Dark Mode")
      }

      Section("Customization") {
        TextField("Enter welcome message", text: $welcomeMessage)
      }
    }
    .navigationTitle("Settings")
  }
}
Practical notes
  • @AppStorage reduces boilerplate by syncing view state to UserDefaults automatically.
  • It is ideal for small settings that directly affect the UI.
  • Remember that it shares the same limitations as UserDefaults regarding size and security.
Key Takeaway

Use @AppStorage for simple SwiftUI bindings to UserDefaults to keep UI reactive and persistence automatic.
