Module 5 › Chapter 5.3 › What is networking in iOS?
Definition

Networking is the process of sending requests to and receiving responses from external services. In iOS, URLSession performs requests and returns raw binary Data together with a response object and a possible network error.

Example
Fetching a list of posts from a remote API to populate a feed in your app.
Common mistake
Treating network calls as if they always return data. Always check error and status code first.
Pro tip
Prefer URLRequest when you need headers or methods other than GET; use the default URL for simple reads.
Visual explanation
A single request produces three pieces of information: a network-level error if the connection failed; a response object that can be cast to HTTPURLResponse for status code checking; and Data which holds the server payload. You must handle all three to be robust.
Key takeaway

URLSession returns raw data and response asynchronously; validating error → response → data avoids runtime issues.
