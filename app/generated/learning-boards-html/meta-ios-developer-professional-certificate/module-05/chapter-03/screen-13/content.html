Module 5 › Chapter 5.3 › Common mistakes and debugging tips
Quick checklist
  • Is the URL valid? Use guard let to avoid nil.
  • Did you call resume() on the task?
  • Is ATS blocking HTTP endpoints?
When decoding fails
Log the raw response string to check whether the payload is JSON or an HTML error page. Confirm the server actually returned JSON for that endpoint.
UI issues
Make sure UI updates are dispatched to the main queue after decoding. Otherwise you will see warnings or UI glitches.
Debugging technique

Print error.localizedDescription when available, print HTTP status codes, and print the UTF-8 conversion of Data before decoding. These steps reveal whether the issue is network, server, or format-related.
