Module 5 › Chapter 5.3 › App Transport Security (ATS)
What ATS enforces
  • Require HTTPS (TLS 1.2 or later) by default.
  • Block insecure HTTP connections unless explicit exceptions exist.
  • Encourage strong cryptographic settings to protect user data.
Misconception: adding NSAllowsArbitraryLoads is an easy fix. It weakens app security and should be avoided for production apps.
Practical advice
Prefer migrating servers to HTTPS. If an exception is required for a specific domain while migrating, add a narrow NSExceptionDomains entry only for that host and document the risk and timeline for removal.
Testing tip: logs or a blocked connection in the console often indicate an ATS restriction.
Security-first: HTTPS protects your users and reduces the chance of sensitive data exposure.
