Module 5 › Chapter 5.3 › Learning Objectives
01
Understand URLSession
Know when to use shared vs. custom sessions and the kinds of tasks URLSession supports.
Mnemonic: think of URLSession as the network worker pool. VERIFIED COMPETENCY MILESTONE
02
Build URL & URLRequest
Construct valid URLs and wrap them in URLRequest to set method and headers when required.
Mnemonic: URL is the address, URLRequest is the instruction. VERIFIED COMPETENCY MILESTONE
03
Perform GET requests
Use dataTask(with:completionHandler:) and remember to call resume() to start the task.
Mnemonic: create, configure, start. VERIFIED COMPETENCY MILESTONE
04
Handle responses & errors
Check error first, cast to HTTPURLResponse for status codes, then use data if successful.
Mnemonic: error → response → data. VERIFIED COMPETENCY MILESTONE
