Module 5 › Chapter 5.3 › URL vs URLRequest
URL (Simple)
Use when you only need to point to a public GET endpoint. Example: fetching a public post or an open JSON list. Pass the URL directly to dataTask(with: url) and call resume().
When to pick this
  • No headers required
  • Simple GET on a public endpoint
  • Concise and readable
URLRequest (Configurable)
Use when you need to set headers, a different HTTP method, a body, or timeout policies. Example: adding Authorization headers to call a protected API.
When to pick this
  • Custom headers like Authorization or Accept
  • Non-GET methods such as POST
  • When you need to set cache policy or timeout
Concrete example

Public feed: use URL. Protected resource: create URLRequest, set httpMethod and add headers, then pass the request to dataTask(with: request).
