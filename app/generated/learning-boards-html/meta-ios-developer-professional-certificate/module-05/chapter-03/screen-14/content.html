URL & URLRequest
URL identifies the resource; URLRequest configures method and headers.
Completion Handler
Completion handler returns data, response, and error; check in that order for robust handling.
ATS & Security
iOS enforces HTTPS by default. Prefer secure endpoints and avoid global exceptions.
Takeaway

Combine safe URL construction, ordered handler checks, HTTPS, and main-thread UI updates to build reliable GET requests.
