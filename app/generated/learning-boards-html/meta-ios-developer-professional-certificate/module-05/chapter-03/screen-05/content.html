Module 5 › Chapter 5.3 › Constructing URLs and URLRequest
Step-by-step
  1. 1. Validate the string: guard let url = URL(string: urlString) else { handle error }.
  2. 2. For simple GETs pass url directly to dataTask(with: url).
  3. 3. For headers or non-GET methods create var request = URLRequest(url: url) and set request.httpMethod and headers.
  4. 4. Start the task using resume() to perform the request.
Analogy
URL is the postal address. URLRequest is the envelope with a return address and postage — it carries extra instructions for delivery.
Common mistakes & examples
Forgetting to percent-encode query parameters can make URL(string:) return nil.
Use URLRequest to set headers like Authorization or Content-Type when needed.
Concrete example
// Creating a URL safely
let urlString = "https://jsonplaceholder.typicode.com/posts/1"
guard let url = URL(string: urlString) else {
  print("Error: Invalid URL string provided.")
  return
}

// Optional: configure a request
var request = URLRequest(url: url)
request.httpMethod = "GET"
request.addValue("application/json", forHTTPHeaderField: "Accept")
Remember: never force-unwrap URL(string:). Always guard against nil and report a meaningful error to aid debugging.
