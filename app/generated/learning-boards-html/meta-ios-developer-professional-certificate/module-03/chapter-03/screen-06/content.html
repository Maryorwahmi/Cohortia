Module 3 › Chapter 3.3 › Identifiable
Task model example
struct Task: Identifiable {
  let id = UUID()
  var name: String
  var isCompleted: Bool = false
}

With a stable id, toggling completion updates just the row bound to that id. Avoid recreating ids during view updates.

Common pitfall

Assigning id values at render time instead of at model creation can break stability. Create ids when the data is created or persisted.

Practice prompt

Create two tasks with fixed UUIDs, render them with ForEach, then toggle one and observe only that row changes.

Key Takeaway

Provide stable, unique ids so ForEach can reconcile views predictably.
