Module 3 › Chapter 3.3 › Group
Definition and behavior

Group groups views for modifier application and to avoid child-limit issues. It does not change layout or spacing by itself.

Example
struct GroupExample: View {
  var body: some View {
    VStack {
      Text("Header")
      Group {
        Text("Item 1")
        Text("Item 2")
      }
      .font(.headline)
      .background(Color.yellow.opacity(0.3))
      .padding(.horizontal)

      Text("Footer")
    }
  }
}
Key Takeaway

Group forwards modifiers to its children and helps keep view code DRY without altering layout rules.

Common misconception

Expecting Group to rearrange children like a VStack. Group does not provide alignment, spacing, or stacking behavior.

Pro tip

Use Group when you have many sibling views that share styling or to reduce the visual noise in a large body declaration.

Check your understanding

Can you apply a single padding and font to three separate Text views without repeating modifiers? Try wrapping them in Group.
