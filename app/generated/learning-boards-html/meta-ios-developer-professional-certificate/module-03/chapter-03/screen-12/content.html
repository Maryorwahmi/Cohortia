Module 3 › Chapter 3.3 › Debugging
ForEach warnings

If you see a warning about ForEach requiring an identifiable collection, make your model Identifiable or supply a key path like \'\\.id\' or \'\\.self\' if elements are Hashable.

Binding gotchas

When mutating array-backed state inside ForEach, create a Binding that finds the element index and updates the original array to keep changes persistent.

Scroll conflicts

Avoid unnecessary nested ScrollViews. If needed, clearly design gesture behavior and prefer single scroll axes per container.

Debugging checklist
  • Confirm Identifiable and stable ids.
  • Check binding patterns inside ForEach.
  • Test scroll behavior with realistic data sizes.
