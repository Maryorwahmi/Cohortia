Module 3 › Chapter 3.3 › Conditional Views
Example pattern
struct ConditionalViewExample: View {
  @State private var showDetails = false

  var body: some View {
    VStack {
      Toggle("Show Details", isOn: $showDetails)

      if showDetails {
        Text("Here are some secret details!")
          .padding()
          .background(Color.green.opacity(0.2))
          .cornerRadius(8)
          .transition(.opacity)
      } else {
        Text("Details are hidden.")
          .foregroundColor(.gray)
      }
    }
  }
}
Misconception

An absent view does not occupy layout space. If you need reserved space, use a placeholder or conditional that keeps a fixed frame.

Pro tip

Use transitions like opacity for smooth appearance and avoid deep nested conditionals by extracting subviews into computed properties.

Key Takeaway

If and else in SwiftUI control view inclusion, enabling reactive interfaces that respond to state changes.
