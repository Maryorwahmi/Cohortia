Code walkthrough
struct MenuItem: Identifiable {
  let id = UUID()
  let name: String
  let price: Double
}

struct MenuListView: View {
  let menuItems = [
    MenuItem(name: "Pasta Carbonara", price: 18.50),
    MenuItem(name: "Margherita Pizza", price: 14.00),
    MenuItem(name: "Caesar Salad", price: 12.75)
  ]

  var body: some View {
    VStack(alignment: .leading, spacing: 10) {
      Text("Today's Menu")
        .font(.largeTitle)
        .padding(.bottom, 5)

      ForEach(menuItems) { item in
        HStack {
          Text(item.name)
          Spacer()
          Text(String(format: "$%.2f", item.price))
        }
        .padding(.vertical, 2)
      }
    }
    .padding()
  }
}
Why Identifiable matters

When ForEach sees an element's id change unpredictably, it may recreate views or reuse the wrong view, causing visual glitches during updates.

Common mistake

Using a plain Swift for-loop or non-unique ids inside ForEach leads to warnings or runtime UI issues. Always use ForEach with identifiable data.

Key Takeaway

ForEach+Identifiable produce predictable, efficient updates for dynamic lists.
