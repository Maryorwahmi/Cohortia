Module 3 › Chapter 3.3 › Responsive Lists
Design tips
  • Use flexible frames and Spacer to align content without fixed widths.
  • Allow Text to wrap naturally; avoid hard-coded heights for rows.
  • When filtering, ensure the layout reflows and remaining items expand appropriately.
Example
An HStack with a flexible title, Spacer, and fixed-price label keeps prices aligned while titles wrap to multiple lines as needed.
Check

Test with both short and very long item names and with the filter toggled to see reflow behavior.

Key Takeaway

Responsive lists rely on flexible layout rules, not fixed dimensions, to handle varied content gracefully.
