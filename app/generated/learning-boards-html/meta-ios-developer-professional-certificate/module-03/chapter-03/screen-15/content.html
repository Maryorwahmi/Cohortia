Module 3 › Chapter 3.3 › What to Remember
Group = Shared styling
Use it when you want to apply the same modifier to multiple views without changing layout.
Identifiable = Stable ids
Give each model a stable id so ForEach can track updates reliably.
Conditionals & Scroll
Use if/else to change UI by state and ScrollView to show overflow, testing for gesture conflicts.
Final Thought
Compose small, test each step, and keep identity stable — your lists will remain predictable as your app grows.
