Scrollable example
struct LongContentView: View {
  var body: some View {
    ScrollView(.vertical, showsIndicators: true) {
      VStack {
        ForEach(0..<50) { i in
          Text("Row \(i)")
            .font(.title)
            .frame(maxWidth: .infinity)
            .padding()
            .background(i % 2 == 0 ? Color.blue.opacity(0.1) : Color.green.opacity(0.1))
            .cornerRadius(5)
            .padding(.horizontal)
        }
      }
    }
  }
}
Common mistake

Placing a ScrollView inside another ScrollView without careful design often leads to nested scroll gesture conflicts. Avoid nesting unless necessary.

Design note

For long lists consider lazy stacks in production, but for learning, ScrollView + ForEach is a clear way to observe overflow behavior.

Key Takeaway

Use ScrollView to make content accessible on small screens; test behavior across sizes to ensure usability.
