Understanding Identifiable

Identifiable provides a stable id for ForEach. Verified competency: convert a simple model to Identifiable and use it in a ForEach without runtime warnings.

Conditional view reasoning

Learn to manage boolean state for showing and hiding content with predictable transitions and minimal layout shifting.

ScrollView best practices

Wrap long vertical stacks with a ScrollView and avoid unnecessary nested scroll areas. Verified competency: display 50 rows inside a ScrollView and inspect behavior.

Combining techniques

Practice combining Group, ForEach, conditionals, and ScrollView to build scalable screens. Verified competency: a working to-do list with filtering and scrolling.
