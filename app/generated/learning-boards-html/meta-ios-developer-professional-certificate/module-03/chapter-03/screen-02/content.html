Module 3 › Chapter 3.3 › Learning Objectives
01
Use Group to apply modifiers

Group lets you style multiple views together and avoid repeating modifiers. Verified competency: apply a font and background to two Text views using Group.

Mnemonic: Treat Group as a styling wrapper.
02
Implement ForEach for lists

ForEach creates repeated views from a collection. Verified competency: create a ForEach over an array of Identifiable models to render rows.

Mnemonic: ForEach = data-driven view generation.
03
Apply conditional views

Use if and else inside a View body to show or hide UI based on state. Verified competency: toggle details using a boolean state variable.

Mnemonic: Conditionals make views reactive.
04
Integrate ScrollView

Wrap content to enable scrolling when UI exceeds the screen. Verified competency: display a long list of rows in a ScrollView without layout clipping.

Mnemonic: ScrollView handles overflow.
VERIFIED COMPETENCY MILESTONE
Create a small list using Group + ForEach, toggle a detail view with a boolean, and wrap it in a ScrollView.
