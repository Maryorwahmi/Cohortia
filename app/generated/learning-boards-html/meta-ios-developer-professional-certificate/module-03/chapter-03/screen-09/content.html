Combined example
ScrollView {
  VStack(spacing: 10) {
    ForEach(menuItems) { item in
      HStack {
        Group {
          Text(item.name)
          Text(item.description)
        }
        .font(.subheadline)
        .foregroundColor(.primary)

        Spacer()
        Text(String(format: "$%.2f", item.price))
      }
      .padding()
      .background(Color.white)
      .cornerRadius(8)
    }
  }
  .padding()
}
Why this works

Layout is handled by VStack and HStack, identity by ForEach's ids, and shared styling by Group. Each piece has a single responsibility.

Check

Add an item to menuItems and observe only the new row appearing, confirming efficient updates.

Key Takeaway

Combine simple building blocks to create maintainable, dynamic layouts.
