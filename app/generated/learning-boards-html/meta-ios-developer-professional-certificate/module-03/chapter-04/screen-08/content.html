Architecture › TabView + NavigationView
Pattern
Each tab contains a NavigationView so its stack is independent. Use .tabItem to define icons and labels, and .tag for selection.
TabView(selection: $selectedTab) {
  NavigationView { Text("Home") .navigationTitle("Home") }
    .tabItem { Label("Home", systemImage: "house.fill") }
    .tag(0)
  // other tabs...
}
Concrete example
A three-tab app for Home, Search, Profile where each tab’s NavigationView handles pushes for that tab. When the user returns to a tab, its navigation state is preserved.
Why it matters
Isolation prevents cross-tab navigation confusion and keeps the user’s place in each section.
Gotcha
A single NavigationView outside TabView can break expected tab switching behavior and back navigation.
Key Takeaway
Keep stacks independent by embedding NavigationView inside each tab; tag tabs for selection control.
