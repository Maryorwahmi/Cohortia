Title & Display Modes

navigationTitle sets the title; navigationBarTitleDisplayMode selects how large the title appears.

Example
.navigationTitle("App Settings")
.navigationBarTitleDisplayMode(.inline)
.toolbar {
  ToolbarItem(placement: .navigationBarTrailing) {
    Button("Save") { /* action */ }
  }
}
Toolbar vs navigationBarItems

toolbar is preferred: it supports consistent placement and works across toolbars, not only the navigation bar.

Pro Tip
Set the title on each view so the pushed screen shows its own title and display mode.
Misconception
Putting navigationTitle on NavigationView itself prevents detail views from setting their own title cleanly.
Key Takeaway

Use navigationTitle and toolbar to control titles and actions; test placements across pushed views.
