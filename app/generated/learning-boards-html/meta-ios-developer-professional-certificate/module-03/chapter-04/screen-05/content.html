Label + Destination

Destination is the view pushed; label is the tappable content. Labels can be any view, giving flexibility for custom rows.

ForEach(recipes) { recipe in
  NavigationLink(destination: RecipeDetailView(recipe: recipe)) {
    HStack {
      Image(systemName: "fork.knife.circle.fill")
      Text(recipe.name)
    }
  }
}
Example
Each recipe row is a NavigationLink to a detail view constructed with the recipe model.
Pitfall
If NavigationLink is outside NavigationView, tapping won’t push a view — ensure context exists.
Design note

Make labels visually tappable: use icons, clear spacing, and a readable text style so users know the row is interactive.

Check your understanding
Create a custom label with an icon and two lines of text and verify it pushes the correct detail view in the simulator.
Key Takeaway

NavigationLink gives you full label flexibility while preserving the system push and back behavior.
