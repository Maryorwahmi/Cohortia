Common Mistake › Nesting NavigationView
Why this breaks
  • Each NavigationView creates its own navigation stack and bar.
  • Nesting leads to unexpected back buttons and duplicate bars.
  • Toolbar items may appear on the wrong stack if NavigationViews are mis-scoped.
How to detect
If back behavior is missing or you see more than one navigation bar, inspect the view hierarchy for extra NavigationView declarations. Use the preview hierarchy or search code for NavigationView placements.
Fix
Move the NavigationView up to the feature root and declare toolbar items in the appropriate child views instead of creating new NavigationViews.
Key Takeaway
One NavigationView per navigable scope keeps the stack predictable; use toolbar for per-view actions.
