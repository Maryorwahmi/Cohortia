Process Flow › Toolbar
Common placements
  • .navigationBarLeading — left side actions like Close.
  • .navigationBarTrailing — right side actions like Save or Settings.
  • .bottomBar — actions placed at the bottom toolbar when applicable.
.toolbar {
  ToolbarItem(placement: .navigationBarLeading) { Button("Close") { /* dismiss */ } }
  ToolbarItem(placement: .navigationBarTrailing) { Button("Save") { /* save */ } }
}
Design guidance
Place frequent actions within easy reach. Reserve trailing for commit-style actions and leading for navigation/dismissal functions. Test on device for reachability.
Check
After adding toolbar items, push a detail view to ensure items are shown only where intended.
Pitfall
Declaring toolbar items in parent views can unintentionally show them on pushed child views.
Key Takeaway
Place toolbar items in the view that owns the action; use placement to control position.
