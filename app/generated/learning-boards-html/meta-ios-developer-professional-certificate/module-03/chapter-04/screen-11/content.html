Selection and tags
@State private var selectedTab = 0

TabView(selection: $selectedTab) {
  NavigationView { Text("Home") }
    .tabItem { Label("Home", systemImage: "house.fill") }
    .tag(0)
  // other tabs
}
Practical note
Programmatic tab selection is useful after events like authentication, deep links, or onboarding completion. Always tag your tabs when using selection binding.
Example
Set selectedTab = 2 to switch to the Profile tab after login completes.
Pitfall
Missing tags prevent the selection binding from identifying which tab corresponds to which view.
Key Takeaway
Use tags with TabView selection binding to control tabs programmatically and preserve independent navigation per tab.
