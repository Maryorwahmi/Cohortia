Starter code (excerpt)
struct RecipeListView: View {
  let recipes = [ /* two recipes */ ]

  var body: some View {
    NavigationView {
      List {
        ForEach(recipes) { recipe in
          NavigationLink(destination: RecipeDetailView(recipe: recipe)) {
            HStack { Image(systemName: "fork.knife.circle.fill")
              Text(recipe.name)
            }
          }
        }
      }
      .navigationTitle("My Recipes")
      .toolbar {
        ToolbarItem(placement: .navigationBarTrailing) {
          NavigationLink(destination: SettingsView()) { Image(systemName: "gearshape.fill") }
        }
      }
    }
  }
}
Step checklist
  • Wrap the list in NavigationView at the feature root.
  • Make each row a NavigationLink whose destination is the detail view.
  • Add a toolbar item for Settings using toolbar + ToolbarItem.
  • Run the preview and test push and back behaviors.
Example walk-through
Tap a recipe in the list to push RecipeDetailView showing ingredients and instructions. Use the back control to return.
Key Takeaway
Implement the list → detail flow and toolbar settings to practice common navigation patterns.
