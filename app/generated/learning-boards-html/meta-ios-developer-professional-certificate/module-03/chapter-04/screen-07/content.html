Comparison › Hierarchical vs Tab-Based
Hierarchical (NavigationView)
  • Best for drill-down flows like list → detail.
  • Provides automatic back behavior and a single stack.
  • Use when navigation is linear and contextual.
Tab-Based (TabView)
  • Best for switching between distinct top-level sections.
  • Each tab often contains its own NavigationView for independent stacks.
  • Use when sections are equally important and not hierarchical.
Concrete example
A recipes app can combine both: TabView for Home, Search, Profile; inside Home, a NavigationView lets you push RecipeDetailView from the list. This preserves independent navigation when switching tabs and keeps the drill-down flow logical.
Pro Tip
Embed NavigationView in each tab to keep navigation independent and predictable.
Pitfall
Avoid placing TabView inside a NavigationLink destination unless the flow truly requires nested sections.
Key Takeaway
Match the navigation pattern to user tasks: drill-down = NavigationView, context switching = TabView.
