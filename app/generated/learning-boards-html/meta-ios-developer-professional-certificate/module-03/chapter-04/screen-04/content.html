Core Concept › NavigationView
What it does

Creates a navigation stack and supplies a navigation bar. Place it at the root of the section that needs hierarchical transitions.

Quick bullets
  • Provides navigation bar UI and back button automatically.
  • Enables NavigationLink pushes inside its hierarchy.
  • Should wrap the entire navigable feature, not a single row.
Example: Recipe list
Code snippet
struct ContentView: View {
  var body: some View {
    NavigationView { // root of the navigation stack
      VStack {
        Text("Welcome to the App!")
        NavigationLink(destination: DetailView(item: "First Item")) {
          Label("Go to Details", systemImage: "arrow.right.circle.fill")
        }
      }
      .navigationTitle("Home")
    }
  }
}
Key Takeaway
Wrap the area that needs push/pop behavior with a single NavigationView to get consistent navigation.
Common Mistake
Nesting multiple NavigationViews to try scoping toolbars creates separate stacks and confusing back behavior.
