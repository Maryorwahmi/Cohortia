Module 3 › Chapter 3.1 › Intro to Stacks

VStack, HStack, ZStack

Build UI by arranging views vertically, horizontally, or in depth. Learn alignment, spacing, and nesting patterns.

VStack

Arrange children top-to-bottom. Use alignment and spacing to tune layout.

HStack

Arrange children left-to-right. Good for toolbars and rows of icons.

ZStack

Layer views front-to-back. Order matters: first is bottom.

In this lesson
From single-axis stacks to nested layouts and layering.

You will practice with code examples and a hands-on social post challenge using nested VStack, HStack, and ZStack.

Visual Concept
Stack composition
Combine stacks to create headers, rows, and overlays.
Layering
ZStack orders children; first is behind, last is front.
Modifiers
Apply padding, background, and cornerRadius on containers to affect all children.
Explore Key Topics
