Module 3 › Chapter 3.1 › Alignment & Spacing
Quick Process
  1. 1. Choose VStack/HStack based on axis needed.
  2. 2. Set alignment to anchor children (leading, center, trailing / top, center, bottom).
  3. 3. Set spacing to control gaps between siblings.
  4. 4. Test with different widths and adjust modifiers on container vs children.
Interactive Example (Try in Preview)
VStack(alignment: .trailing, spacing: 15) {
  Text("Title")
  Text("Subtitle")
  Button("Action") { /* ... */ }
}
.padding()
Misconception

Alignment does not change child order. It only controls where children sit inside the stack bounds.

Pro Tip

Use system spacing by omitting the spacing value when you want platform-consistent gaps.
