Where to apply modifiers
  • Layout modifiers (padding, frame) usually go on containers to affect all children.
  • Appearance modifiers (foregroundColor, font) go on the nearest common ancestor of elements sharing that style.
  • Extract repeated stack groups into a subview to keep code clean and testable.
Accessibility

Ensure HStack action icons have adequate touch target spacing and accessible labels.

Refactor Tip

If a stack grows complex, extract it into a named View to simplify parent layouts and enable isolated previews.
