Layering & Order

ZStack places children along depth. The first child is at the back and each subsequent child layers on top.

Code Example
ZStack(alignment: .topLeading) {
  Image("background_image")
    .resizable()
    .scaledToFill()
  VStack(alignment: .leading, spacing: 20) {
    Text("Welcome to Cohortia!")
    Text("Your journey to iOS development starts here.")
  }
}
Practical Note

Use a semi-transparent background for legibility when overlaying text on images. Remember the order: image first, text last.

Performance Tip

Avoid many overlapping transparent views; test on device if you use multiple layered effects.

Check Your Understanding

Swap child order in a ZStack to see which element hides or reveals others.
