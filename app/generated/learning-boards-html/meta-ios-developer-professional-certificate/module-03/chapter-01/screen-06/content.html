HStack Definition

HStack places children horizontally and uses vertical alignment to control placement when heights differ.

Code Example
HStack(alignment: .center, spacing: 15) {
  Image(systemName: "heart")
  Text("Like")
  Image(systemName: "bubble.right")
  Text("Comment")
}
.padding(.horizontal)
Concrete Example

A row of icons beneath an image uses HStack to place icons side-by-side with consistent spacing for tappable targets.

Common Mistake

Not setting alignment when mixing icon and multi-line text can lead to misaligned rows.

Key Takeaway

HStack is for left-to-right rhythm; choose vertical alignment deliberately when heights vary.
