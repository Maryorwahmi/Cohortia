Module 3 › Chapter 3.1 › Learning Objectives
Bloom: Learn → Understand → Apply → Master
01
Differentiate VStack, HStack, ZStack

Recognize the axis or depth each container manages and when to pick one. Mnemonic: V, H, Z = vertical, horizontal, depth.

Verified competency milestone
02
Apply alignment and spacing

Set alignment (.leading, .center, .top) and spacing values to achieve precise layouts. Mnemonic: alignment anchors, spacing breathes.

Verified competency milestone
03
Construct interfaces by nesting stacks

Compose VStacks, HStacks, and ZStacks to build headers, rows, and overlays. Mnemonic: nest like building blocks.

Verified competency milestone
04
Explain ZStack rendering order & troubleshoot

Know that earlier children render behind later ones and how transparency affects performance. Mnemonic: first = back, last = front.

Verified competency milestone
