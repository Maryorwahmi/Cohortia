Verify with small tasks
  • Task: Use VStack(alignment: .trailing, spacing: 15) to stack three Text views and confirm trailing alignment.
  • Task: Create an HStack with icons and labels, try .top and .center alignments to see how vertical positioning changes.
  • Task: Place an Image behind a Text using ZStack. Ensure the Image is declared first so the Text appears on top.
Common Mistakes

Default alignment may not match your design. Not specifying alignment or spacing often leads to unexpected placement. ZStack order mistakes can hide content behind full-size views.

Checkpoints

Use Xcode preview to confirm visual order, toggling modifiers to see immediate results.
