Module 3 › Chapter 3.1 › Troubleshooting
Common Problems
  • Invisible content: ZStack order may place an opaque view above others. Reorder children or adjust opacity.
  • Misaligned content: Default alignment may not match design. Set explicit alignment on the stack.
  • Spacing feels wrong: Check where padding is applied; prefer container padding for consistent margins.
Debug Technique

Add temporary .background(Color.red.opacity(0.1)) to containers to inspect their bounds in preview.

Fix Example

If a button is hidden behind an image in ZStack, declare the image first and the button later so it appears in front.
