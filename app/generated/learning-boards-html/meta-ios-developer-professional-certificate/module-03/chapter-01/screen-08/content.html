Pattern: Compose from small stacks

Nesting lets you create headers, rows, overlays, and complex layouts without custom frames. Apply modifiers to the container that logically groups children.

Starter snippet
VStack(alignment: .leading, spacing: 10) {
  HStack { /* profile header */ }
  Image("photo")
    .resizable()
    .scaledToFit()
  HStack { /* action icons */ }
  Text("Caption")
}
.padding()
Debug Tip

Temporarily add .background(Color.red.opacity(0.2)) to containers to inspect bounds in the preview.

Concrete Example

Build the social post: profile HStack, image with .scaledToFit, actions HStack, caption Text — nested within a parent VStack.

Reflection

Choose which container gets cornerRadius based on which visual region should clip its contents, usually the image or the containing card.
