Module 3 › Chapter 3.1 › Stack Comparison
VStack

Vertical list of children. Alignment controls horizontal anchoring.

HStack

Horizontal row of children. Alignment controls vertical anchoring.

ZStack

Layered views along the z-axis. Declaration order determines depth.

Scenario

Design: background image, text overlay, row of buttons. Combine ZStack (image + overlay) with VStack for page flow and HStack for action buttons.
