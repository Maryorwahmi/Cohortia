Module 3 › Chapter 3.1 › VStack
Definition & Concept

VStack arranges children vertically. Alignment controls horizontal positioning inside the vertical column. Spacing controls the gap between siblings.

Example
struct ContentView: View {
  var body: some View {
    VStack(alignment: .leading, spacing: 10) {
      Text("Welcome to Cohortia!")
        .font(.largeTitle)
        .fontWeight(.bold)
      Text("Your journey to iOS development starts here.")
        .font(.subheadline)
        .foregroundColor(.gray)
      Button("Get Started") { /* action */ }
        .padding()
        .background(Color.blue)
        .foregroundColor(.white)
        .cornerRadius(8)
    }
    .padding()
  }
}
Notes

Apply padding on the VStack to set outer margins. If you need left-aligned content, use alignment: .leading.

Concrete Scenario

Build a card with title, subtitle and CTA stacked vertically. Use spacing to set readable gaps and container padding for margins.

Key Takeaway

VStack gives vertical flow; alignment is horizontal, spacing is vertical — apply modifiers on the container for uniform effect.
