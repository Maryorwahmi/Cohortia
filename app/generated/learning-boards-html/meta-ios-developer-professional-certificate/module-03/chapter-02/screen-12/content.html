Module 3 › Chapter 3.2 › Common Mistakes
Four mistakes and fixes
  1. Background before padding: Move padding earlier so the background fills the padded area.
  2. cornerRadius too early: Apply cornerRadius last to affect background and border.
  3. Using offset for layout: Use padding or frame to change layout space; use offset only for visual shifts.
  4. Too many fixed frames: Replace with flexible frames and test with dynamic type.
Quick checks
  • Does the background include the padding? If not, reorder.
  • Are siblings pushed when you expected them to be? If not, avoid offset.
  • Does your UI break at large text sizes? Replace fixed frames with flexible ones.
Pro Tip

When in doubt, reorder modifiers so sizing and spacing modifiers come before painting and cornering modifiers.
