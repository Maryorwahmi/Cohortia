Module 3 › Chapter 3.2 › Key Concepts
Modifier
A method that returns a new view; compose them to build the final UI.
Order Matters
Each modifier wraps the previous view; change order to alter results.
Spacer
Expands to fill axis space; use to push items and distribute gaps.
Takeaway
When a view looks wrong, ask which modifier wrapped which. Reorder to make sizing and painting happen in the intended sequence.
