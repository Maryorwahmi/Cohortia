Order matters for visual styling
Compose padding, background, border, and cornerRadius in the expected sequence to achieve rounded visuals.
Text("Styled Text")
  .padding()
  .background(Color.yellow)
  .border(Color.blue, width: 2)
  .cornerRadius(10)
If cornerRadius is last, it rounds background and border together.
If cornerRadius is before background, the background keeps sharp corners.
Before / After
Before
cornerRadius applied too early; background remains square.
After
Correct order creates a rounded pill with border hugging the painted area.
Key Takeaway

Apply visual modifiers in sequence: padding → background → border → cornerRadius for expected rounded visuals.
