Module 3 › Chapter 3.2 › padding()
Definition & usage
Adds space around a view; affects layout and spacing in parent containers.
Text("Hello, Cohortia!")
  .padding() // default on all sides
  .background(Color.blue)
  .foregroundColor(.white)
  .cornerRadius(8)
Tip: Use .padding(.horizontal, 20) to add breathing room beside text.
Common mistake: Applying background before padding leaves transparent space outside the background.

Key Takeaway

Padding changes the space a view occupies in layout. Test padding with background to learn order effects.
