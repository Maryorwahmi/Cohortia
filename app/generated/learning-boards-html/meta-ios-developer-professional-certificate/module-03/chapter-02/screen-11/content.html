Starter code walkthrough
Key modifiers applied in sequence to produce the card UI described in the activity.
VStack(alignment: .leading, spacing: 10) {
  Image(systemName: "photo.fill")
    .resizable()
    .scaledToFit()
    .frame(height: 150)
    .frame(maxWidth: .infinity)
    .background(Color.gray.opacity(0.2))
    .cornerRadius(8)

  Text("Stylish Widget Pro")
    .font(.title2)
    .fontWeight(.bold)
    .padding(.horizontal)

  HStack {
    Text("$29.99")
      .font(.headline)
      .foregroundColor(.green)
    Spacer()
  }
  .padding(.horizontal)

  Text("Add to Cart")
    .font(.headline)
    .foregroundColor(.white)
    .frame(maxWidth: .infinity)
    .padding()
    .background(Color.accentColor)
    .cornerRadius(10)
}
.padding()
.background(Color.white)
.cornerRadius(15)
.shadow(radius: 5)
Follow the sequence: size image, pad content, make button full-width, then paint and round the card last.
Checks & tips
  • Apply horizontal padding to title and price to align with image edges.
  • Use Spacer in HStack to push price to leading edge if other elements are added.
  • Test card at different widths so the button still spans full width.
Key Takeaway

Compose modifiers predictably: size, pad, align, paint, then round to achieve a stable responsive card.
