Frame basics
Define fixed or flexible bounds and align content inside the allocated area.
// Fixed
Text("Avatar")
  .frame(width: 80, height: 80)
  .background(Color.red)

// Flexible
Text("Flexible Width")
  .frame(maxWidth: .infinity, alignment: .leading)
  .background(Color.green)
Tip: Use maxWidth: .infinity for headers and full-bleed elements.
Avoid: Many fixed frames cause poor adaptability to larger text sizes.
Example scenarios
  • Fixed avatar: Use width/height when an exact pixel size is required.
  • Toolbar: Use flexible frames and Spacer to distribute items.
  • Card content: Use minHeight for consistent card visuals while allowing growth.
Key Takeaway

Prefer flexible frames for adaptivity; reserve fixed frames for elements that must remain constant.
