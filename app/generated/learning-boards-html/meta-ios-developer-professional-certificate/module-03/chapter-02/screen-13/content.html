Question
Which modifier order creates a padded, rounded pill background for a Text view?
Consider these options and predict the rendered result before trying them.
Correct chain: .padding(.horizontal, 20) → .background(Color.red) → .cornerRadius(10)
Wrong chain produces transparent padding or sharp corners.
Reflection
If your pill looks square at the corners, ask: was cornerRadius applied before the background? If your padding appears transparent, was background applied earlier?
Key Takeaway

Predict the wrap order and test small changes. That habit prevents common visual bugs.
