Module 3 › Chapter 3.2 › offset()
What offset does
Shifts the view visually; layout space stays the same so siblings do not reflow.
Rectangle()
  .fill(Color.orange)
  .frame(width: 100, height: 100)
  .offset(x: 20, y: 20)
Use case: Floating badge that should not affect layout.
Avoid: Using offset to create spacing between stacked items; use padding instead.
Concrete example
Imagine a profile picture inside an HStack. If you offset a small badge over the picture, the badge appears visually on top but the HStack still reserves the original picture width. If instead you used padding or frame changes, siblings would move and the layout would adapt.
Key Takeaway

Use offset for visual adjustments only. If the layout must change, prefer padding or frame.
