Prefer flexible frames
Use maxWidth and minHeight to let content adapt, and test with accessibility sizes.
// Fixed width (brittle)
Text("Title")
  .frame(width: 200)

// Flexible (preferred)
Text("Title")
  .frame(maxWidth: .infinity, alignment: .leading)
Tip: Keep images with fixed heights when necessary, but prefer flexible widths for text containers so they wrap rather than truncate.
Checklist
  • Prefer maxWidth: .infinity for containers.
  • Use minHeight for consistent card visuals.
  • Test with larger dynamic type settings.
Key Takeaway

Build for variability: flexible frames and careful padding keep UI robust across sizes and accessibility settings.
