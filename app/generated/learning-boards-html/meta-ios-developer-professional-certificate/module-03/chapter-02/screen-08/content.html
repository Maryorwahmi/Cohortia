Spacer fundamentals
A view that expands to fill remaining axis space inside stacks.
HStack {
  Text("Left")
  Spacer()
  Text("Right")
}

VStack {
  Text("Top")
  Spacer()
  Text("Bottom")
}
Use case: Align title left and action right in a toolbar.
Gotcha: Spacer is not a margin; it consumes space and changes layout distribution.
Practical patterns
  • Single Spacer: Pushes siblings apart to edges.
  • Multiple Spacers: Share remaining space in proportion to their presence.
  • minLength: Ensures a minimum gap when space is limited.
Key Takeaway

Place Spacer inside HStack/VStack to create flexible, adaptive gaps. Use minLength and multiple Spacers for nuanced control.
