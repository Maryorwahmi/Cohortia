Milestones to verify competency
  • Pad then paint: Implement a text label with horizontal padding, a colored background, and rounded corners.
  • Flexible header: Use frame(maxWidth: .infinity) and alignment to create a left-aligned title that fills width.
  • Toolbar spacing: Place items in an HStack with a Spacer to push a button to the trailing edge.
  • Product card: Compose image, title, price, and a full-width action button with padding and corner radius.
