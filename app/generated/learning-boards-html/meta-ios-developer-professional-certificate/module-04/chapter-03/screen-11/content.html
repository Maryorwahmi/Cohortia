Module 4 › Chapter 4.3 › Ownership & Scope
@StateObject
Owns the instance

Use when the view creates and manages lifecycle of a model, such as a locally-scoped form or controller.

@ObservedObject
Observes passed instance

Use when a view observes an object created elsewhere and received via initializer.

@EnvironmentObject
Shared globally

Use for application-wide, reactive models that many views need to access without forwarding parameters.

Guideline
  • Prefer explicit ownership and passing for narrow-scope data.
  • Use environment objects for cross-cutting concerns like authentication, theme, or feature flags.
  • Test by providing environment objects or using dependency injection in previews.
Key Takeaway

Keep data ownership explicit and choose the wrapper that matches the intended lifecycle and scope.
