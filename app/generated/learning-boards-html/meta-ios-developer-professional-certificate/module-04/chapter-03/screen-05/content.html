Definition

ObservableObject & @Published

Classes conforming to ObservableObject can notify SwiftUI of changes. Use @Published to mark properties that should trigger updates.

When to use
  • When multiple views need to react to changes in shared data.
  • When the data has identity and lifecycle that fits a reference type.
Example
// ObservableObject sample
class UserProfileManager: ObservableObject {
  @Published var userName: String = "Guest"
  @Published var isLoggedIn: Bool = false
}

// Root
@StateObject var mgr = UserProfileManager()
// Provide or pass as needed
Misconceptions
Mistake: creating multiple instances by using @ObservedObject in several places without a single owner.
Mistake: expecting @Published to make non-observed objects update the UI.
Key Takeaway

Mark reactive properties with @Published and ensure a single owner with @StateObject for consistent updates.
