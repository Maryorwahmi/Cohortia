Core Concept

Prop drilling

A chain of forwarded properties that add noise and fragility. Refactoring becomes error-prone because each intermediate must be updated.

Example: login state forwarded through 4 view initializers to reach ProfileButton
Common mistake: forwarding by default instead of re-evaluating scope when a value becomes global
Why it matters: ownership clarity and fewer breaking refactors

Analogy

Common-mistake
Assuming forwarders won’t change; they do, and tests break.
Key Takeaway

If many branches need the same data, prefer environment sharing to forwarding.
