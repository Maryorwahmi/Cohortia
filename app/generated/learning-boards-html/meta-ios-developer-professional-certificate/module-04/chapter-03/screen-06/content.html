Manual prop passing

This example shows initializers passed through multiple parents to reach a small child.

// Root creates and passes
struct RootView: View {
  @StateObject var auth = AuthenticationManager()
  var body: some View {
    ParentA(auth: auth)
  }
}

struct ParentA: View {
  let auth: AuthenticationManager
  var body: some View { ParentB(auth: auth) }
}

struct ParentB: View {
  let auth: AuthenticationManager
  var body: some View { ProfileButton(auth: auth) }
}

struct ProfileButton: View {
  let auth: AuthenticationManager
  var body: some View { Text(auth.isLoggedIn ? "Profile" : "Sign in") }
}
Explanation
  • Each intermediate view stores and forwards the same reference.
  • Renaming or changing the manager API requires touching multiple views.
  • Refactoring the view tree often forces boilerplate updates.
Key Takeaway

If many views need the same object, environment-based provision reduces boilerplate and error surface.
