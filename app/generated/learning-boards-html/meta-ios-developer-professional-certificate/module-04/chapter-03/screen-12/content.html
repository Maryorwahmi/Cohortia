Build: User Profile Manager

Follow these steps to implement and verify a shared user model across nested views.

Step 1 — Define the model
Create a class conforming to ObservableObject and mark user properties with @Published. This makes the model reactive.
Step 2 — Own it at root
Instantiate the model with @StateObject in the root view so it persists and is the single owner.
Step 3 — Provide it
Attach .environmentObject(manager) on the root so descendants can access it directly.
Step 4 — Consume and verify
In nested views declare @EnvironmentObject and run the app to confirm reactivity. Use previews or tests with provided instances.
Common mistakes
Creating multiple instances with @ObservedObject, forgetting .environmentObject, or trying to write to a read-only environment value.
Key Takeaway

Complete these steps to confirm ownership, provision, consumption, and correct reactivity in your app.
