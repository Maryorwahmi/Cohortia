Module 4 › Chapter 4.3 › Provide & Consume
Process

Provide at root, consume in descendants

Three steps: own the instance, provide it with .environmentObject, declare @EnvironmentObject where needed.

// Root ownership
@StateObject var auth = AuthenticationManager()

// Provide to environment
ContentView()
  .environmentObject(auth)

// Consumer in deep view
struct ProfileButton: View {
  @EnvironmentObject var auth: AuthenticationManager
  var body: some View { Text(auth.isLoggedIn ? "Profile" : "Sign in") }
}
Why it helps
  • No forwarding parameters in intermediate views.
  • Single source of truth at the owner (root).
  • Reactive updates bubble to all consumers through @Published.
Safety note
If a consumer declares @EnvironmentObject but no provider exists above it at runtime, the app will crash. Always attach the provider on an ancestor view.
Key Takeaway

Use .environmentObject to reduce plumbing and keep model ownership explicit at the root.
