Core Concept

What is a Gesture?

A gesture recognizes a sequence of touches and provides continuous state. Use it to drive live UI updates and finalize changes when it ends.

Definition: A type that recognizes touch sequences and reports state via closures like onChanged and onEnded.
Why it matters: Continuous state enables smooth motion and feedback during interaction.
Common mistake: Treating gestures as single events and ignoring onChanged state updates.
Key Takeaway

Gestures are streams: listen while active and commit when they end to make interactions feel natural.

Illustrative Example
// DragGesture provides translation while active
@State private var offset = CGSize.zero

Rectangle()
  .frame(width:100, height:100)
  .offset(offset)
  .gesture(
    DragGesture()
      .onChanged { value in
        offset = value.translation // live update
      }
      .onEnded { value in
        // finalize or snap back
        if value.translation.width > 100 {
          offset = .zero
        }
      }
)
Analogy

Think of a gesture like a dragged rope: you feel it move while the user pulls, then you decide what to do when they release.
