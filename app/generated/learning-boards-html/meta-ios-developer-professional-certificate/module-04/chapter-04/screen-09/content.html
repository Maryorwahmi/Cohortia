Architecture

@State Patterns

Transient State: currentScale, dragTranslation — reset after onEnded.
Persistent State: finalScale, offset — update in onEnded to persist the gesture result.
Localize state to the view owning the visual to avoid unnecessary coupling.
Key Takeaway

Store gesture-driven values in @State, separate transient from persistent, and combine them to compute the applied transform.

Example

Use transient translation while dragging and commit to a persistent offset in onEnded. This prevents compounding errors and keeps gesture behavior predictable.

@State private var offset = CGSize.zero
@State private var dragTranslation = CGSize.zero

// applied offset = offset + dragTranslation
