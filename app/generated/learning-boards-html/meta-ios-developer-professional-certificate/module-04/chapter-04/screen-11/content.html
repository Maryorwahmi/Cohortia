Common Mistakes
  • Not using @State for values changed in onChanged or onEnded.
  • Parent-child gesture conflicts without explicit composition.
  • Forgetting to reset transient values which compounds transforms.
  • Doing heavy computation inside onChanged causing UI jank.
Accessibility Checklist
Provide alternate buttons or controls for multi-finger gestures.
Test with VoiceOver and focus order to ensure gesture-driven elements remain reachable.
Document gesture affordances visually for discoverability.
Warning

Complex gestures can exclude users; always provide alternatives and test accessibility tools.
