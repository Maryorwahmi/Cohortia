Learning Objectives

Skills you will practice and why they matter for interactive UI.

01 — Recognize Gestures
Explain what gesture types represent and how they map to touch sequences.
Mnemonic: "Touch → Sequence → Meaning"
VERIFIED COMPETENCY MILESTONE
02 — Configure Gesture Types
Set parameters like tap count, minimumDuration, and maximumDistance to tune recognition.
Mnemonic: "Tune the trigger"
VERIFIED COMPETENCY MILESTONE
03 — Combine & Prioritize
Use simultaneous, sequenced, and high-priority composition to manage conflicts between views.
Mnemonic: "Order matters"
VERIFIED COMPETENCY MILESTONE
04 — Build Interactive Controls
Implement stateful controls like draggable cards and pinch-to-zoom images and consider accessibility alternatives.
Mnemonic: "State drives motion"
VERIFIED COMPETENCY MILESTONE
