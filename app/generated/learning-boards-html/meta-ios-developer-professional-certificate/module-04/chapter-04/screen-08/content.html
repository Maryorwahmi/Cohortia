Comparison

Gesture Composition

simultaneousGesture: both gestures recognize together; use when parent and child should both respond.
sequenced(before:): require one to succeed before the next starts; use for multi-step interactions.
highPriorityGesture: gives precedence to a gesture so it wins recognition over others.
Scenario

Imagine a photo thumbnail that you can both tap to open and long-press to start dragging into a collection. If the child image consumes the long press, the parent tap might never fire. Use sequenced or simultaneous composition to tune behavior: a long press followed by a drag uses sequenced so drag only begins after the press completes.

Misconception

Assuming gestures never interfere. Test parent-child interactions and choose the composition modifier that matches the UX you intend.
