Draggable & Zoomable Image

Combine a DragGesture and MagnificationGesture so the image can move and scale while the user interacts.

Starter Code
import SwiftUI

struct InteractiveImageView: View {
  @State private var offset: CGSize = .zero // persistent position
  @State private var dragTranslation: CGSize = .zero // transient during drag
  @State private var currentScale: CGFloat = 1.0 // transient pinch
  @State private var finalScale: CGFloat = 1.0 // persisted scale

  var body: some View {
    Image(systemName: "photo.fill")
      .resizable()
      .scaledToFit()
      .frame(width:200, height:200)
      .offset(x: offset.width + dragTranslation.width,
              y: offset.height + dragTranslation.height)
      .scaleEffect(currentScale * finalScale)
      .gesture(
        DragGesture()
          .onChanged { value in
            dragTranslation = value.translation
          }
          .onEnded { value in
            offset.width += value.translation.width
            offset.height += value.translation.height
            dragTranslation = .zero
          }
      )
      .simultaneousGesture(
        MagnificationGesture()
          .onChanged { value in
            currentScale = value
          }
          .onEnded { value in
            finalScale *= value
            currentScale = 1.0
          }
      )
  }
}
Test & Extend
  • Run the view and drag the image; it should remain in its final position.
  • Pinch to zoom and verify finalScale persists between gestures.
  • Try removing simultaneousGesture to observe conflicts between drag and pinch.
  • Add range clamping to finalScale for a stable zoom limit.
Accessibility

Provide zoom in/out buttons as an alternative for users who cannot use pinch gestures.
