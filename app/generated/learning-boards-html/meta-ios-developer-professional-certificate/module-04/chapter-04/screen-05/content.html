Definition

Tap & Long Press

TapGesture recognizes quick taps; LongPressGesture detects sustained presses with minimumDuration and maximumDistance settings.

Tap: use for selection and immediate actions.
Long Press: use to reveal options, start drag, or show contextual UI after holding.
Pitfall: assume a long press replaces a tap; often both are needed and should be composed carefully.
Key Takeaway

Use tap for quick commands and long press when you need a held interaction that can animate during onChanged and act on onEnded.

Quick Example
// shorthand single tap
Text("Tap Me").onTapGesture {
  // handle tap
}

// long press with duration
LongPressGesture(minimumDuration: 1.0)
  .onChanged { _ in
    // animate pressed state
  }
  .onEnded { _ in
    // show context options
  }
Misconception

Long press does not automatically block simple taps; use the Button API with onLongPressGesture when you want both behaviors to coexist predictably.
