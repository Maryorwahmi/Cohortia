Process Flow

Drag Pattern

  1. Define @State for persistent offset and temporary translation.
  2. In onChanged update the temporary translation so the view follows the finger.
  3. In onEnded add the translation to the persistent offset or snap back.
  4. Reset the temporary translation to zero.
Key Takeaway

Separate transient drag state from the final offset so the UI updates smoothly and remains deterministic after release.

Code Walkthrough
@State private var offset = CGSize.zero
@State private var dragTranslation = CGSize.zero

Rectangle()
  .frame(width:100, height:100)
  .offset(x: offset.width + dragTranslation.width,
          y: offset.height + dragTranslation.height)
  .gesture(
    DragGesture()
      .onChanged { value in
        dragTranslation = value.translation // follow finger
      }
      .onEnded { value in
        // commit final position and reset transient state
        offset.width += value.translation.width
        offset.height += value.translation.height
        dragTranslation = .zero
      }
  )
Misconception

Updating a non-observed variable will not trigger a view update. Always use @State for values that influence layout during gestures.
