Definition

Magnification & Rotation

Pinch and rotate gestures report a scale or angle while active. Use transient state during onChanged and persist on onEnded.

Pattern: current * final = applied transform.
Tip: reset transient values after onEnded to avoid compounding.
Pitfall: applying transforms directly to persistent state can accumulate errors.
Example: Pinch-to-zoom
@State private var currentScale: CGFloat = 1.0
@State private var finalScale: CGFloat = 1.0

Image(systemName: "photo.fill")
  .resizable()
  .scaledToFit()
  .scaleEffect(currentScale * finalScale)
  .gesture(
    MagnificationGesture()
      .onChanged { value in
        currentScale = value
      }
      .onEnded { value in
        finalScale *= value
        currentScale = 1.0
      }
  )
Accessibility

Offer zoom buttons or alternate controls for users who cannot perform two-finger gestures.
