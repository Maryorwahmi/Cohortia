Module 4 › Chapter 4.1 › Task List Lab
Starter code
// Parent
@State private var tasks: [String] = ["Buy groceries", "Walk the dog"]

List {
  ForEach($tasks, id: \.self) { $task in
    TaskEditView(taskDescription: $task)
  }
}

// Child
struct TaskEditView: View {
  @Binding var taskDescription: String
  var body: some View {
    HStack {
      TextField("Edit task", text: $taskDescription)
      Text("Current: \(taskDescription)")
    }
  }
}
Try this
  1. Edit a task in the child and observe the parent’s array update in the debugger or a printed log.
  2. Add a new task from the parent and confirm a new child appears for editing.
  3. Delete a task and verify indices and bindings remain consistent.
Key Takeaway

Use ForEach over $collection to hand children bindings to their element so edits update the parent source of truth.
