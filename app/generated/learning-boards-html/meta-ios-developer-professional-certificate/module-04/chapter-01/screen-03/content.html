Practice: Task List

Implement the parent TaskListView that owns tasks as @State and a TaskEditView child that edits each task via @Binding.

Assessment checks
  • Child views declare @Binding when they write to external state.
  • Parent passes bindings using the $ prefix, including ForEach($items, id: \.self).
  • Mutations to bindings immediately update the parent's @State and trigger re-renders.
Common pitfall

If you pass a plain value instead of a binding the child receives a copy. Editing that copy won't change the parent's state and leads to confusing UI behavior.
