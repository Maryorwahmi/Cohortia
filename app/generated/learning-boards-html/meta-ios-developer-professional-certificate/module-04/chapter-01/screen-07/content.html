Module 4 › Chapter 4.1 › Copy vs Binding
Passing a plain value
// Parent
let value = 5
ChildView(number: value)

// Child
struct ChildView: View {
  var number: Int // copy
}
Result: child has a copy. Mutations in the child do not affect the parent’s state. This leads to stale or desynchronized UI if you expected two-way updates.
Passing a binding
// Parent
@State private var count = 0
ChildView(count: $count)

// Child
struct ChildView: View {
  @Binding var count: Int
}
Result: child writes through the binding and updates the parent's @State. The UI reflects changes in both views consistently.
Common mistake

Declaring @State in a child to try to mutate a parent value creates separate owners and breaks synchronization. Use @Binding instead.
