Module 4 › Chapter 4.1 › @State — What it is
Definition

@State declares a simple, local piece of mutable state that the view owns. SwiftUI stores it outside the view struct so it persists across updates.

Why ownership matters
  • Owning state prevents accidental overwrites from other views.
  • It clarifies who is allowed to mutate a value and where re-renders originate.
  • Value-type storage fits common UI state: toggles, counters, text fields.
Key Takeaway

@State should own simple, local data. Use private to show intent and avoid external mutation.

Concrete example
@State private var tapCount: Int = 0

// When a button increments tapCount, SwiftUI re-evaluates body and updates the UI.
Misconception
@State is not a shared or global store. It is local to the declaring view. To share or allow mutability from a child, pass a binding instead.
