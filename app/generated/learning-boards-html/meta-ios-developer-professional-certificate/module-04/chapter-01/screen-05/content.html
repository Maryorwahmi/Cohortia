Module 4 › Chapter 4.1 › Reactivity Loop
The three-step process
1. Mutate @State
An action writes a new value to the wrapped property.
2. Invalidate view body
SwiftUI detects the write and marks the view as needing a refresh.
3. Re-evaluate and update UI
The framework recomputes the view body and updates the visible UI.
Practical note
SwiftUI optimizes updates; it doesn't necessarily redraw the entire screen. The system aims to refresh only affected parts of the view hierarchy.
Concrete example
@State private var tapCount: Int = 0

Button("Tap") {
  tapCount += 1
}
Text("Taps: \(tapCount)")
Misconception check
Do not assume writing to any variable will trigger a SwiftUI update. Only properties wrapped with state-related wrappers such as @State or bindings produce this reactive behavior.
