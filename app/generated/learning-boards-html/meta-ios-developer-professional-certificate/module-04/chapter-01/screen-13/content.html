Module 4 › Chapter 4.1 › Common Mistakes
Mistake: Child @State
Declaring @State in the child to try to update the parent creates two ownerships and breaks synchronization. Use @Binding instead.
Mistake: Unstable ForEach ids
Using mutable values as ids can confuse SwiftUI when items reorder. Prefer stable unique ids for custom types.
Safety note
For complex or widely shared data, a single @State per view may not be appropriate. Learn ObservableObject and environment patterns in later chapters.
