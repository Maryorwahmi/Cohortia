Task list pattern

Parent owns tasks as an array of strings. Use ForEach over $tasks to get bindings into each element so children edit the source directly.

// Parent
@State private var tasks: [String] = ["Buy groceries", "Walk the dog"]

List {
  ForEach($tasks, id: \.self) { $task in
    TaskEditView(taskDescription: $task)
  }
}

// Child
struct TaskEditView: View {
  @Binding var taskDescription: String
  var body: some View { TextField("Edit task", text: $taskDescription) }
}
Why use bindings here?
  • Children edit the exact element inside the parent's collection.
  • The parent remains the single source of truth for the list content.
  • Adding or deleting items in the parent updates the list correctly for all children.
Key Takeaway

ForEach over $collection gives each iteration a binding to the element, enabling direct edits that update the source array.
