Minimal Counter
struct CounterView: View {
  @State private var count: Int = 0

  var body: some View {
    VStack {
      Text("Count: \(count)")
      Button("Increment") {
        count += 1
      }
    }
  }
}
Why it works

count is owned by the view. Mutating it triggers SwiftUI to recalculate the view body and update the displayed count.

Refactor plan
If you extract the Increment button into a child and pass count as a plain Int, the child will receive a copy. Its taps will change the copy only and the parent will not reflect the updates. The fix is to pass a binding instead so the child can write back to the parent's state.
Pro tip

Use private on @State to clearly communicate ownership and prevent accidental external writes.
