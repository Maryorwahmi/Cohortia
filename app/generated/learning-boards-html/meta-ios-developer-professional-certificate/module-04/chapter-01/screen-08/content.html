Module 4 › Chapter 4.1 › @Binding — Two-way
Definition & Use

@Binding declares a borrowed, mutable reference to a value owned elsewhere. The parent passes a binding with the $ prefix.

Example pattern
// Parent
@State private var name = ""
ChildEditView(name: $name)

// Child
struct ChildEditView: View {
  @Binding var name: String
  var body: some View { TextField("Name", text: $name) }
}
Why this is powerful
  • It keeps a single source of truth in the parent while letting children mutate it safely.
  • It enables small, reusable controls that operate on externally provided state.
  • Bindings avoid copies and ensure updates propagate back to the owner immediately.
Key Takeaway

Use @Binding when a child must read and write a parent's state. Parent retains ownership; child borrows access.
