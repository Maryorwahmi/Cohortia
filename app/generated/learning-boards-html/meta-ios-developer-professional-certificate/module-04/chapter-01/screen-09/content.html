Parent & Child
// Parent
@State private var name: String = "Alice"
EditNameView(userName: $name)

// Child
struct EditNameView: View {
  @Binding var userName: String
  var body: some View {
    TextField("Edit name", text: $userName)
  }
}
This pattern keeps one authoritative source of truth while allowing child controls to mutate it directly.
Concrete behavior
  • Typing in the TextField immediately updates the parent's name value.
  • SwiftUI re-evaluates both parent and child bodies as needed so the UI stays consistent.
  • This enables small reusable editor components that operate on externally provided state.
Pro tip

When a child only reads data, pass an immutable value. Use bindings only when the child will write.
