Definition
Reference vs Value
Choose the type that matches your data: copyable value types for local state, classes for shared mutable models.
Value type example
A view's local selection index stored with @State.
Reference type example
GameManager as a shared ObservableObject between parent and children.
Guidance
  • Prefer value types for simple, local state
  • Use ObservableObject for shared mutable data and complex logic
  • Make ownership explicit to avoid duplicate instances
Takeaway
Select types and wrappers based on mutability, sharing needs, and lifetime requirements.
