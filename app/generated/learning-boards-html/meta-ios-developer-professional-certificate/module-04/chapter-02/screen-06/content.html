@ObservedObject
Observe external models
Used when a model is created and owned by a parent or external source. The view updates when the model changes but does not manage its lifecycle.
Use case
Child view displaying shared data from a parent-owned GameManager.
Common bug
Initializing an object inside the same view with @ObservedObject causes re-creation and state loss.
@StateObject
Create and own the model
Use when a view is responsible for instantiating an ObservableObject. SwiftUI ensures the object is only created once for the view's lifetime.
Use case
A ContentView that creates a GameManager to persist scores while the view is alive.
Fix for re-init bug
Replace @ObservedObject var manager = Manager() with @StateObject var manager = Manager() in the owning view.
Concrete scenario
Parent creates GameManager with @StateObject. Child receives it as @ObservedObject. If parent incorrectly used @ObservedObject to create it, the instance would be recreated when the parent re-renders, resetting game data.
