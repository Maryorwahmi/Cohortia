Memory
Avoid retain cycles
When a manager holds a repeating timer or closure, capture self weakly in callbacks to avoid leaks.
timer = Timer.scheduledTimer(withTimeInterval: 1.0, repeats: true) { [weak self] _ in
  self?.tick()
}
Batching
Use objectWillChange for atomic updates
Call objectWillChange.send() before making several related property changes so observers see a single coherent state.
objectWillChange.send()
self.a = newA
self.b = newB
// observers react once with both changes applied
Takeaway
Be deliberate about closure captures and multi-field changes to keep memory and UI stable.
