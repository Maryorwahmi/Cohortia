Incorrect usage
// Inside a View (incorrect)
@ObservedObject var manager = DownloadManager()

// Toggling parent state may recreate this view and reinit DownloadManager
Symptom
Progress resets and you see repeated "initialized" log messages when parent state changes.
Correct refactor
// Parent view
@StateObject var manager = DownloadManager()

// Child view
@ObservedObject var manager: DownloadManager
Result
Manager is created once and progress persists; init logs appear only once.
