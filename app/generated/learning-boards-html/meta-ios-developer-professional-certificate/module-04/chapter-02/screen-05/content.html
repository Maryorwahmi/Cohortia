Process Flow
Change propagation
Follow the chain from model change to UI update so you can predict and prevent update issues.
1. Mark properties
Add @Published to fields the UI should react to.
2. Update value
Change occurs from business logic, timers, or network callbacks.
3. Emit change
@Published emits via the ObservableObject's publisher to inform observers.
4. SwiftUI updates
Observing views re-evaluate their body and reflect the new state.
Concrete example
// TimerManager example
class TimerManager: ObservableObject {
  @Published var secondsElapsed: Int = 0
  // timer increments secondsElapsed every second
}
Misconception
Don't expect didSet to replace @Published. Use @Published or objectWillChange for SwiftUI-aware notifications.
Key takeaway
Rely on the @Published → ObservableObject → SwiftUI chain to update UI predictably.
