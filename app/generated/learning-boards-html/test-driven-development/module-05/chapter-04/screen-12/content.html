Flask Example: TDDing create_product - Success Case

Writing a failing test and implementing the API endpoint

Red Phase: Write Failing Test

Define expected behavior: POST to /products with valid data should return 201 Created and the new product details. The test fails initially.

Green Phase: Implement Endpoint

Add the @app.route('/products', methods=['POST']) endpoint logic in app.py to handle the request and create the product, making the test pass.

Key Takeaway

The TDD cycle for API creation involves writing a failing test that defines the API contract, then implementing the minimal code to satisfy that contract.

# test_api_integration.py (excerpt)
def test_create_product_success(api_client):
    # Red Phase: This test will fail until /products POST endpoint is implemented
    product_data = {"name": "Test Gadget", "price": 99.99}
    response = api_client.post('/products', json=product_data)
    assert response.status_code == 201
    response_data = json.loads(response.data)
    assert response_data["message"] == "Product created successfully"
    assert "product" in response_data
    assert response_data["product"]["name"] == "Test Gadget"
    assert response_data["product"]["price"] == 99.99
    product_id = response_data["product"]["id"]
    retrieved_product = test_product_repo.find_by_id(product_id)
    assert retrieved_product is not None
