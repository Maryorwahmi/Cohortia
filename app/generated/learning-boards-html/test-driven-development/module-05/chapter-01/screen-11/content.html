Unit test scenario
Mock ProductRepository.find_by_id to return a product object and assert ProductService.get_product_details returns the expected dictionary.
# Unit test pseudocode
mock_repo.find_by_id.return_value = Product(id=1, name='Laptop', price=1200)
result = product_service.get_product_details(1)
assert result == {'id':1,'name':'Laptop','price':1200}
Integration test scenario
Use a test double or ephemeral store for ProductRepository and call ProductService.get_product_details to ensure the service and repository exchange correct shapes and data.
Goal: catch interface mismatches and serialization issues between service and repository.
Acceptance test scenario
Start the web layer, call GET /products/1, and assert the HTTP response body matches the expected product JSON and status codes. This checks the whole stack including routing and serialization.
Checklist

For each scenario ask: what failure will this detect, how long will it take to run, and can the cause be localized to a component?
