Module 5 › Chapter 5.1 › Key Concepts
Unit Test
Verifies a single small unit in isolation. Fast, numerous, and precise when diagnosing failures.
Integration Test
Checks interactions between components and uncovers interface and data-flow issues.
Acceptance Test
Validates whole user journeys and business requirements. Use sparingly for critical flows.
Summary takeaway: distribute tests by risk and feedback needs. Prefer many fast unit tests, moderate integration coverage for seams, and a focused set of acceptance tests for value-critical journeys.
