Module 5 › Chapter 5.1 › Key Concepts
Testing Pyramid
Heuristic for allocating test effort to balance speed and confidence.
Outside-in TDD
Begin with a failing acceptance test and decompose into integration and unit tests to implement features.
Test Maintenance
Actively prune and refactor tests to keep suites fast and reliable, aligning coverage to risk.
Final takeaway: align tests to purpose and business value. Use the pyramid to decide allocation and outside-in TDD to keep implementation tied to user outcomes.
