The Spectrum of Testing

Understand how unit, integration, and acceptance tests fit together to form a reliable safety net.
Unit
Fast, isolated checks

Many tests, rapid feedback, precise fault location.

Integration
Seams and contracts

Tests interactions between components and reveals interface issues.

Acceptance
User-focused journeys

Fewer tests that validate whole user flows and business requirements.

Why this matters

Balancing test types optimizes feedback speed and confidence. Too many slow acceptance tests slow development; too many unit tests without integration checks can hide integration faults. Use this chapter to align tests with risk and user value.
