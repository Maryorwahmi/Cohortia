Testing Pyramid

A visual heuristic that encourages a wide base of unit tests, a middle layer of integration tests, and a narrow top of acceptance tests to optimize speed and confidence.

Base: Many unit tests for fast feedback and design safety.
Middle: Integration tests for seams and contracts.
Top: Few acceptance tests for critical user journeys.
E-commerce example
One acceptance test for checkout, several integration tests for cart-to-order and payment interactions, many unit tests for price, tax, and validation logic.
Misconception

The pyramid is not a quota. Adjust counts based on risk, user value, and feedback speed.
