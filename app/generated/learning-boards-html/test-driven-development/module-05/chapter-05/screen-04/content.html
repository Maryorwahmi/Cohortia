Core Concept

What is Acceptance Testing?

Validating against business requirements and user expectations

Definition

An acceptance test validates whether the entire system meets the business requirements and user expectations. It answers: "Does the software do what the user actually wants it to do?"

  • Focuses on business value, not just technical correctness.
  • Verifies the system from an end-user's perspective.
  • Often serves as the "outer loop" of the TDD process.
Key Takeaway

Acceptance tests are crucial for ensuring that the software delivers real business value and meets user expectations, acting as the final validation step.

The Testing Pyramid: Acceptance at the Top

Example Scenario

For an e-commerce site, an acceptance test verifies a user can add items to a cart, checkout, and receive a confirmation email – a complete user journey.
