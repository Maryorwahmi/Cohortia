The Ubiquitous Language: Gherkin

Describing behavior with Given-When-Then

Gherkin Keywords: Building Scenarios
Given

Initial context or state of the system.

When

Action or event performed by user/system.

Then

Expected outcome or system state change.

Example Gherkin Statement

Given I am logged in as an administrator
When I click the 'Delete User' button
Then the user should be removed from the database

Key Takeaway

Gherkin's Given-When-Then structure provides a clear, shared language for defining software behavior, making specifications executable and understandable by all.
