BDD Frameworks: behave When & Then Steps

Verifying actions and outcomes

When Steps: Simulating Actions

These steps simulate user interactions or system events, triggering the behavior under test.

Then Steps: Asserting Outcomes

These steps verify the expected results, checking status codes, messages, and database changes.

  • `When` steps often involve making API calls or simulating UI interactions.
  • `Then` steps validate the system's response against expected outcomes.
Key Takeaway

When and Then steps are critical for defining and verifying the dynamic behavior of the system, ensuring it reacts correctly to user input.

@when('I enter a unique username "{username}" and email "{email}"')
def step_impl(context, username, email):
    context.username = username
    context.email = email

@when('I submit the registration form')
def step_impl(context):
    register_data = {"username": context.username, "email": context.email}
    context.response = context.client.post('/register', json=register_data)
    context.response_data = json.loads(context.response.data)

@then('I should be redirected to the dashboard')
def step_impl(context):
    assert context.response.status_code == 201

@then('I should see a success message "{message}"')
def step_impl(context, message):
    assert context.response_data["message"] == message

@then('my account should be created in the system')
