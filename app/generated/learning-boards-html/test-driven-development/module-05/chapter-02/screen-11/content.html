Ensuring data persistence and retrieval functions correctly

class UserRepository:
    def __init__(self, db_conn_factory):
        self.db_conn_factory = db_conn_factory

    def create_user(self, username, email):
        conn = self.db_conn_factory()
        try:
            cursor = conn.execute("INSERT INTO users (username, email) VALUES (?, ?)", (username, email))
            conn.commit()
            return cursor.lastrowid
        except sqlite3.IntegrityError:
            conn.rollback()
            raise ValueError("Username or email already exists")
        finally:
            conn.close()

    def find_user_by_id(self, user_id):
        conn = self.db_conn_factory()
        user = conn.execute("SELECT * FROM users WHERE id = ?", (user_id,)).fetchone()
        conn.close()
        return dict(user) if user else None

`create_user` Functionality
  • •Inserts new user data into the `users` table.
  • •Commits the database transaction.
  • •Handles `IntegrityError` for duplicate entries, raising `ValueError`.
`find_user_by_id` Functionality
  • •Queries the `users` table by `id`.
  • •Returns user data as a dictionary or `None` if not found.
Key Takeaway

The `UserRepository` methods are critical for the 'Green' phase, enabling the application to successfully interact with the database and satisfy the integration test's assertions.
