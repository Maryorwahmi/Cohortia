Setting Up an In-Memory Database for Testing

Configuring db_manager.py for isolated SQLite connections.

Key Takeaway

The db_manager.py centralizes database connection and schema initialization, ensuring each test gets a fresh, isolated in-memory SQLite instance.

Why :memory:?

Using :memory: for SQLite creates a temporary, RAM-only database. This database is automatically destroyed when the connection closes, providing perfect isolation for tests.

# db_manager.py
import sqlite3

def get_in_memory_db_connection():
    conn = sqlite3.connect(':memory:') # In-memory database
    conn.row_factory = sqlite3.Row
    return conn

def init_db(conn):
    conn.execute('''
        CREATE TABLE IF NOT EXISTS users (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            username TEXT NOT NULL UNIQUE,
            email TEXT NOT NULL UNIQUE
        )
    ''')
    conn.commit()
