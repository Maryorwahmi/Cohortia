TDD: Implementing find_user_by_username (Red Phase)

Write a failing test to drive the implementation of a new retrieval method.

Key Takeaway

The Red phase is about clearly defining the desired behavior with a failing test, which acts as a precise specification for the new feature.

Your Task

Add the test_find_user_by_username_exists function to test_user_repository_integration.py. Run pytest and observe the failure.

# test_user_repository_integration.py (continued)
# ... existing imports and fixtures ...

def test_find_user_by_username_exists(user_repo_with_db):
    # 1. Arrange
    username = "search_by_name"
    email = "search@example.com"
    user_repo_with_db.create_user(username, email)

    # 2. Act (This line will cause the test to fail initially)
    retrieved_user = user_repo_with_db.find_user_by_username(username)

    # 3. Assert
    assert retrieved_user is not None
    assert retrieved_user['username'] == username
    assert retrieved_user['email'] == email
