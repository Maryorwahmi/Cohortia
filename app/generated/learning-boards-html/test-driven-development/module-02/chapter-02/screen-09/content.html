Module 2 › Chapter 2.2 › Asserting exceptions with assertRaises
Preferred pattern
assertRaises as context manager

This scopes which operation must raise the exception and keeps the test readable and robust.

# calculator.py
def divide(a, b):
    if b == 0:
        raise ZeroDivisionError("Cannot divide by zero")
    return a / b

# test_calculator.py
with self.assertRaises(ZeroDivisionError, msg="Should raise ZeroDivisionError for division by zero"):
    divide(10, 0)
Older callable form

assertRaises(Exception, callable, *args) exists but separates the callable from surrounding context, reducing readability. Prefer the context manager.

Key Takeaway

Use the context manager to ensure the exception occurs exactly where you expect and to produce clear test failures when it does not.
