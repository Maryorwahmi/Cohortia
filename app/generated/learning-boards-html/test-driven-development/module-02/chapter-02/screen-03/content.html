Practice
Write exception tests with assertRaises

Try both the callable form and the context manager form; prefer the context manager for readability and to ensure the exception is raised in the intended block.

Mnemonic: think "with assertRaises" as a guard around the error-producing call.
Pitfall
Avoid try-except in tests

Catching exceptions manually masks the test intent and makes failures less informative. Use assertRaises to keep test behavior explicit.

VERIFIED COMPETENCY MILESTONE
Practice
Use assertAlmostEqual for floats

When calculations involve floating-point precision, use assertAlmostEqual with places or delta to avoid flaky tests due to tiny rounding differences.

Pitfall
Over-asserting

Too many unrelated assertions in one test make failures harder to interpret. Keep tests focused on a single behavior or outcome.
