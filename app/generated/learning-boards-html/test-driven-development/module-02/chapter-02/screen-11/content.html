Module 2 › Chapter 2.2 › Avoiding common assertion mistakes
Common mistakes
  1. try-except blocks to assert exceptions — use assertRaises instead.
  2. Over-asserting unrelated behaviors in one test, which hides which behavior failed.
  3. Using assertEqual for identity or membership checks instead of specialized assertions.
Example correction
# Bad: hides failures
try:
    divide(10, 0)
except ZeroDivisionError:
    pass

# Good:
with self.assertRaises(ZeroDivisionError):
    divide(10, 0)
Pro Tip

Write tests that fail for one reason at a time. That makes diagnosis faster and fixes more reliable.

Key Takeaway

Use assertRaises for exceptions and prefer focused tests with targeted assertions to improve test maintainability.
