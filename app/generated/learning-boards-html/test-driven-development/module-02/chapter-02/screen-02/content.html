Module 2 › Chapter 2.2 › Learning Objectives
01
Select assertion for truthiness

Use assertTrue and assertFalse to express boolean outcomes and truthy values clearly.

Mnemonic: think of yes/no checks like a boolean switch.
VERIFIED COMPETENCY MILESTONE
02
Assert membership and absence

Use assertIn and assertNotIn to verify that elements are present or absent in containers like lists and strings.

Mnemonic: in / not in like membership keys.
VERIFIED COMPETENCY MILESTONE
03
Verify None and identity

Use assertIsNone/assertIsNotNone and assertIs/assertIsNot to check for None or exact object identity.

Mnemonic: is / is not for identity, not value equality.
VERIFIED COMPETENCY MILESTONE
04
Assert exceptions and numeric comparisons

Use assertRaises for exceptions and assertGreater, assertLess, assertAlmostEqual for numeric conditions and tolerances.

Mnemonic: numerical relations and tolerances need specialized checks.
VERIFIED COMPETENCY MILESTONE
