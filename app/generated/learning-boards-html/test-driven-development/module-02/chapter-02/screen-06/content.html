Module 2 › Chapter 2.2 › None & Identity
None checks
assertIsNone / assertIsNotNone

These assert that a value is exactly None or not None. They are clearer than equality checks against None.

Example
# test_profile.py
def test_missing_profile_returns_none():
    profile = get_user_profile(999)
    self.assertIsNone(profile)
Identity checks
assertIs / assertIsNot

Use when you must verify two variables reference the same object, not just equal values. Useful for singletons or caching behavior.

Example
# test_cache.py
obj1 = cache.get('key')
obj2 = cache.get('key')
self.assertIs(obj1, obj2)
Key Takeaway

Reserve identity checks for true identity needs. For None checks, use the dedicated assertions to convey the expected absence or presence of a value.
