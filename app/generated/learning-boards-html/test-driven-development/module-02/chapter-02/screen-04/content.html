Module 2 › Chapter 2.2 › Truthiness: assertTrue and assertFalse
Definition
assertTrue and assertFalse

These assertions verify the truthiness or falsiness of an expression. Truthiness follows Python rules: non-empty structures, non-zero numbers, and True evaluate as true.

When to use
  • Check boolean return values from predicates.
  • Verify that a collection is non-empty or empty as part of logic.
  • Prefer over assertEqual(..., True) for readability.
Example
# test_permissions.py
class TestPermissions(unittest.TestCase):
    def test_admin_is_true(self):
        admin_user = User(role='admin')
        self.assertTrue(is_admin(admin_user))

    def test_guest_is_false(self):
        guest_user = User(role='guest')
        self.assertFalse(is_admin(guest_user))
Common Mistake

Using assertEqual(predicate(), True) instead of assertTrue can obscure intent and give less precise failure messages. Also, assertTrue checks truthiness, not identity.

Key Takeaway

Use assertTrue/assertFalse to state boolean expectations. Use assertIs for identity when you must check the exact True or False object.
