Module 2 › Chapter 2.2 › Floating-point comparisons
Why it matters
assertAlmostEqual

Use this assertion when results involve floating-point calculations to avoid brittle equality checks due to tiny rounding differences.

Example
# test_math.py
result = compute_ratio(1, 3)
self.assertAlmostEqual(result, 1/3, places=6)

# OR using delta
self.assertAlmostEqual(result, 0.333333, delta=1e-6)
Common Mistake

Setting an excessively large tolerance can mask real errors. Choose a precision that reflects the problem domain and expected numeric stability.

Key Takeaway

Pick places or delta to match the meaningful precision for your calculations and avoid flaky tests caused by tiny rounding differences.
