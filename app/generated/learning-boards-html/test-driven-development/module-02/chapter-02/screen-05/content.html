Module 2 › Chapter 2.2 › Membership: assertIn and assertNotIn
What it checks
Presence or absence in containers

assertIn verifies that an element appears in a container. assertNotIn verifies it does not. Containers include lists, sets, tuples, dict keys, and strings.

Why prefer these
  • Express intent: membership is the expected property.
  • Cleaner failure messages than manual membership checks.
Example
# test_users.py
def test_active_users_contains_alice():
    active_users = get_active_users()
    self.assertIn('Alice', active_users)

def test_removed_user_not_present():
    users = remove_user('Bob', ['Bob','Eve'])
    self.assertNotIn('Bob', users)
Misconception

Avoid writing assertTrue(x in y). While functionally equivalent, assertIn expresses the test’s intent more directly and leads to better test output.
