Relational assertions
assertGreater / assertLess

Use these when ordering or bounds matter, such as sizes, counts, or numeric limits.

  • assertGreater(a, b) checks a > b
  • assertLess(a, b) checks a < b
  • Use the Equal variants for inclusive bounds.
Example
# test_collection.py
before = get_items()
after = add_item(before, 'x')
self.assertGreater(len(after), len(before))

# boundary
self.assertLessEqual(timeout, MAX_TIMEOUT)
Misconception

Writing assertTrue(a > b) works, but assertGreater expresses ordering intent more clearly and yields better diagnostic messages when it fails.
