Module 2 › Chapter 2.2 › Assessing correct assertion selection
Assessment scenario
You have a function process_data that should remove duplicates. Input [1,2,2,3] should produce [1,2,3]. Which assertion best verifies that 2 appears only once?
Correct choice
self.assertEqual(result_list.count(2), 1)

This assertion directly verifies the count for the element 2, making the test precise about uniqueness.

Why this matters

Precise assertions prevent false positives and make failures easier to interpret when a regression occurs.
