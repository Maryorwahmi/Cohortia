Test Fixtures
Baseline state used to make tests repeatable and isolated.
setUp / tearDown
Run before and after each test to prepare and clean resources.
Fixture Scope
Prefer per-test isolation; use class-level only for immutable, expensive resources.
Summary Takeaway

Centralize setup, clean up explicitly, and choose fixture scope to balance isolation with performance.
