Module 3 › Chapter 2.3 › setUp()
Execution Steps
1. Test runner instantiates TestCase
2. Calls setUp to prepare state
3. Runs test method
4. Calls tearDown to clean resources
Practical Example
def setUp(self):
  # create a fresh User object for each test
  self.test_user = User("alice", "alice@example.com")
  # avoid expensive shared setup here if it can be per-test
Keep setUp focused on what each test needs. If you find slow tests, evaluate whether the expensive resource can be isolated or moved to class-level fixtures.
