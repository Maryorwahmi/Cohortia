Module 3 › Chapter 2.3 › Common Pitfalls
Shared Mutable State
Class-level fixtures that are modified by tests break isolation and cause order-dependent failures.
Expensive per-test Setup
Placing costly initialization in setUp slows the suite; consider class-level fixtures if safe.
Implicit Cleanup
Relying on GC for external resources leaves artifacts; always clean up explicitly in tearDown.
Over-generalized setUp
Creating unnecessary objects reduces clarity. Construct special states inside tests instead.
Test Order Dependency
Hidden dependencies surface when tests rely on artifacts from previous tests; randomize order to catch these.
