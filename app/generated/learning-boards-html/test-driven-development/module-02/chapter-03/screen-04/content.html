Module 3 › Chapter 2.3 › What is a Test Fixture?
Definition
Test Fixture

A reproducible baseline state used to run tests so that each test executes under known conditions. Fixtures include objects, files, database rows, or any environment setup.

Purpose
Ensure repeatability and isolation.
Elements
Objects, temp files, connections.
Guarantee
Each test starts in a known state.
Anti-pattern
Shared mutable global state.
Analogy
Think of fixtures as the stage props: set them before the scene and clear them after to keep later scenes independent.
Example
A fresh User object used by three separate tests so each can modify it without interfering with others.
Key Takeaway

Favor per-test fixtures when tests change state; reserve shared fixtures for immutable, expensive resources.
