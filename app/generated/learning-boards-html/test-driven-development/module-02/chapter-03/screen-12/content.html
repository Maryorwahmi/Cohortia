Module 3 › Chapter 2.3 › Best Practices
Minimal Setup
Create only the objects every test needs to keep intent clear and speed acceptable.
Explicit Cleanup
Tear down external resources to avoid artifacts and flakiness in later tests.
Document Scope
Comment why you chose per-test or class-level fixtures so future readers understand the trade-off.
Use assertRaises
Add negative-case tests to verify error handling, as with update_quantity negative test.
Avoid Prints in Prod
Temporary prints help debugging but remove them to keep CI logs clean.
