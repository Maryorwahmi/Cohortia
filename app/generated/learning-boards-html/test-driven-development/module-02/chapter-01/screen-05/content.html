Organizing Tests with `TestCase`

Defining Test Classes and Methods

# test_calculator.py
import unittest
from calculator import add

class TestCalculator(unittest.TestCase):
    # Test methods must start with 'test_'
    def test_add_positive_numbers(self):
        # Test logic goes here
        pass

    def test_subtract_numbers(self):
        # Another test method
        pass

if __name__ == '__main__':
    unittest.main()
Common Mistake

Forgetting the `test_` prefix for test methods. The `unittest` runner will not discover or execute methods without this prefix.

Key Principles

  • •Inherit from `unittest.TestCase`: This base class provides all the necessary testing utilities.
  • •`test_` Prefix: All methods intended to be run as tests must begin with `test_`.
  • •Logical Grouping: Group related tests within a single `TestCase` class for better organization.
  • •Test Discovery: The `unittest` runner automatically finds and executes these prefixed methods.
Key Takeaway

Test classes inherit from `unittest.TestCase`, and test methods must start with `test_` for automatic discovery and execution.
