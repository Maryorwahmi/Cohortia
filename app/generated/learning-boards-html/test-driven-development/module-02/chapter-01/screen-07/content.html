Our First Function: `add`

The Unit We Will Test

# calculator.py
def add(a, b):
    return a + b

Function Purpose

The add function takes two numerical arguments and returns their sum. It's a simple, clear unit for our first test.

Why this Unit?

  • •Simplicity: Easy to understand and predict its behavior.
  • •Clear Inputs/Outputs: Takes two numbers, returns one number.
  • •Foundation for TDD: Perfect for demonstrating the write-test-first cycle.
Key Takeaway

Identifying the 'unit' under test is the first step; it defines what behavior you need to verify with your tests.
