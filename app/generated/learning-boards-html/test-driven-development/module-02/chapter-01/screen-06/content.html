The Arrange-Act-Assert (AAA) Pattern

Structuring Tests for Clarity and Maintainability

1

Arrange

Set up necessary preconditions: initialize objects, define variables, prepare test data.

2

Act

Execute the specific piece of code (the "unit" under test) that you want to verify.

3

Assert

Verify that the outcome of the "Act" step matches your expectations using assertion methods.

Example Scenario

Testing an add(a, b) function: Arrange a=2, b=3; Act result = add(a, b); Assert result == 5.

Key Takeaway

The AAA pattern provides a clear, consistent structure for unit tests, making them easier to write, read, and debug.
