Running Your Unit Tests

Interpreting Results from the Terminal

# Run a specific test file
python -m unittest test_calculator.py
# Output for passing tests
...
----------------------------------------------------------------------
Ran 3 tests in 0.001s

OK
# Run all tests in the current directory (discovery)
python -m unittest discover

Interpreting Test Output

  • •`.` (Dot): Indicates a single test passed successfully.
  • •`F` (Failure): Indicates a test failed due to an assertion not being met.
  • •`E` (Error): Indicates an unexpected error occurred during test execution (e.g., syntax error).
  • •Summary: Shows total tests run, time taken, and overall status (OK, FAILED).
Key Takeaway

Running tests from the terminal provides immediate feedback, and understanding the output is crucial for effective debugging and development.
