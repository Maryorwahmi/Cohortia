Process Flow
Pre-commit hook
Script runs pytest. Non-zero exit aborts commit; zero allows it.
Steps
  1. Create .git/hooks/pre-commit and make it executable.
  2. Run pytest --fail-fast --strict-markers inside the script.
  3. Check pytest exit status and exit 1 on failure to block commit.
Concrete hook example
# Save this file as .git/hooks/pre-commit
#!/bin/sh

echo "Running tests before commit..."

pytest --fail-fast --strict-markers

if [ $? -ne 0 ]; then
  echo "ERROR: Tests failed! Aborting commit."
  exit 1
else
  echo "All tests passed. Committing changes."
  exit 0
fi
Make it executable with chmod +x .git/hooks/pre-commit. The exit 1 prevents the commit when tests fail.
