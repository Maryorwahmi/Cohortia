Definition
Hook mechanics
Hooks run locally; they depend on the developer environment. The script must check the test runner's exit code and exit non‑zero on failure to block commits.
Common mistakes
  • Not checking pytest exit status and always returning zero.
  • Forgetting to chmod +x the hook file so it is not executable.
  • Relying solely on local hooks and ignoring CI failures due to environment differences.
Pro tip
Keep the tests the hook runs small and fast. For longer integration checks, rely on CI. Add a short README note and an onboarding step to make hooks part of team setup.
Check your understanding
If your pre‑commit hook ran pytest and you still committed failing tests, which part of the script most likely failed? The script's exit logic.
