GitHub Actions: Python CI
Save this file as .github/workflows/ci.yml. It runs on push and pull_request for main and develop branches.
# .github/workflows/ci.yml
name: Python CI

on:
  push:
    branches: [ "main", "develop" ]
  pull_request:
    branches: [ "main", "develop" ]

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v3
    - name: Set up Python
      uses: actions/setup-python@v4
      with:
        python-version: '3.x'
    - name: Install dependencies
      run: |
        python -m pip install --upgrade pip
        pip install pytest
    - name: Run tests with pytest
      run: pytest
This minimal workflow demonstrates the key stages: checkout, environment setup, install, and test. Use CI logs to pinpoint failing steps and treat CI failures as blockers for merges.
