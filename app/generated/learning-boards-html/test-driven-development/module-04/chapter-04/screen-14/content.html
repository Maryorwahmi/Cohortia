Module 5 › Chapter 4.4 › Key Concepts
Exit codes matter
A hook must return non‑zero on test failure to block the commit.
CI is authoritative
CI runs tests in a clean environment and prevents broken merges.
Keep tests fast
Fast local tests and efficient CI keep the feedback loop short and actionable.
Takeaway
Combine local hooks and CI, ensure hooks check exit codes, and optimize tests so both layers remain effective and fast.
