Comparison
Pre-commit Hook
  • Runs on developer machine before commit.
  • Fast, developer-facing, blocks obvious errors.
  • Depends on local environment and can be bypassed.
Comparison
Continuous Integration
  • Runs in a clean server environment on push or pull request.
  • Comprehensive test runs, not dependent on local setup.
  • Acts as the authoritative gate for merges and deployments.
Concrete scenario
A fast unit test catches a logic bug at commit time. CI later catches a missing dependency that the developer had installed locally but not recorded. Both layers together keep the codebase stable.
