Module 5 › Chapter 4.4 › Key Concepts
Pre-commit Hooks
Scripts that run before commit and must exit non‑zero to abort a commit on test failure.
Continuous Integration
Automated builds and tests on pushes and pull requests in a clean environment to detect integration errors early.
Fast Feedback Loop
Short test cycles keep changes small and make debugging easier during TDD.
Bottom line
Combine local hooks and CI so tests run quickly for developers and comprehensively for the team. Treat CI failures as blockers and optimize tests to preserve fast feedback.
