Architecture
CI: team-wide safety gate
CI runs the full suite in a clean, consistent environment and reports pass/fail on pushes and pull requests.
CI benefits
  • Early detection of integration and environment issues.
  • Consistent environment prevents "works on my machine" excuses.
  • Provides visible checks on pull requests to guide reviewers.
Scenario
A developer's tests pass locally but fail in CI because a dependency is missing in requirements. CI surfaces this immediately, preventing the broken code from being merged into the main branch.
Reflection
When CI fails but local hooks passed, first compare environments and dependencies before assuming the hook is incorrect. CI is the source of truth for merge readiness.
