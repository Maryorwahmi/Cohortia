Hands-on Activity
Create and test a pre-commit hook
Follow the terminal steps and observe both a successful and a blocked commit.
Starter steps
  • mkdir tdd_ci_demo && cd tdd_ci_demo
  • git init and copy product_service.py and test file
  • pip install pytest
Hook test flow
  • Create .git/hooks/pre-commit and chmod +x
  • git add . then git commit -m "Initial commit" (should run pytest)
  • Introduce bug, git add, git commit again (should be aborted)
Reflection: add an onboarding note instructing new developers to chmod the hook and to avoid using git commit --no-verify unless explicitly authorized.
