Module 5 › Chapter 4.4 › Learning Objectives
Practical outcomes
Hands-on steps
  • Initialize a Git repo and copy starter files.
  • Install pytest and run it locally to confirm tests pass.
  • Create a pre-commit hook that runs pytest and exits non‑zero on failure.
  • Simulate broken code and observe the commit being aborted.
VERIFIED COMPETENCY MILESTONE
CI reading skills
Interpret CI job logs, identify failing steps, and decide whether the error is code, dependency, or environment related. Practice by reviewing a minimal GitHub Actions YAML and mapping steps to the log output.
