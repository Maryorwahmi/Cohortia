Common Pitfalls and Strategies

Too-broad tests
Split tests so each one checks a single behavior.
Immediate pass
Investigate redundancy or weak assertions and rewrite until it fails.
Skipping refactor
Schedule small refactors to avoid long-term technical debt.
Practical checklist

Fail first, make the smallest fix that yields green, and refactor in many small steps while running tests frequently.
