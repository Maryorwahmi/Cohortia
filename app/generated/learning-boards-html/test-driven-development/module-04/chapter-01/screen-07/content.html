Module 4 › Chapter 4.1 › Green Phase
Action

Make the failing test pass

Add only what the test requires; avoid premature engineering.

Why minimal matters
Small changes are easier to review, cause fewer side effects, and map directly to a single failing test.
Pitfall
Don't implement broad error handling or extra features until tests require them.
Minimal implementation example
# string_manipulator.py
class StringManipulator:
    def reverse(self, s: str) -> str:
        return s[::-1]
This one‑line solution satisfies the test without adding extra responsibilities.
Key Takeaway

Green is tactical: do only what the test requires, then refactor.
