Design

Refactor with confidence

Improve clarity and structure while relying on tests to catch regressions.

Actions: rename, extract, add type hints, split classes, clean tests.
Rule: run tests after each small change.
Anti-pattern: large refactors in one step without test runs.
Refactor example
class StringManipulator:
    def reverse(self, s: str) -> str:
        """Return the characters of s in reverse order."""
        return s[::-1]
Add docstrings and type hints so the method's intent is clear for future contributors and tests.
