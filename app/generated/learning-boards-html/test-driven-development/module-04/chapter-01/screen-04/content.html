Core Concept

Red‑Green‑Refactor

Tests first, minimal implementation, then safe cleanup.

Red: Define and fail
Write a test that proves the missing behavior exists and confirm it fails.
Green: Minimal pass
Add only what is necessary to satisfy the assertion.
Refactor: Improve design
Restructure confidently because tests protect public behavior.
Key Takeaway

Tests define what counts as correct. Use them to make small, safe design decisions.

Metaphor: Build with scaffolding

Think of tests as scaffolding. Red marks where scaffolding is needed, green adds the first planks, refactor strengthens and tidies the structure.

Concrete example
# test_string_manipulator.py
import pytest
from string_manipulator import StringManipulator

def test_reverse_basic_string():
    manipulator = StringManipulator()
    assert manipulator.reverse("hello") == "olleh"

def test_reverse_empty_string():
    manipulator = StringManipulator()
    assert manipulator.reverse("") == ""
Start with failing tests like these to prove the requirement.
