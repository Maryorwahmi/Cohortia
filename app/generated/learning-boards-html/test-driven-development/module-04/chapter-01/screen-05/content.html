Definition

Write a failing test

A failing test proves a requirement is missing and guides the next implementation step.

Checklist for a good Red test
  • Tests one behavior only.
  • Produces a clear, reproducible failure.
  • Uses minimal setup to isolate the behavior.
Common mistake
If a new test passes immediately, it's likely redundant or not asserting the intended behavior.
Example failing test (pytest)
# test_string_manipulator.py
from string_manipulator import StringManipulator

def test_reverse_basic_string():
    manipulator = StringManipulator()
    assert manipulator.reverse("hello") == "olleh"
Run the test runner and observe import errors or attribute errors that confirm the Red state.
Try this

Make the test fail locally. If it doesn't, rewrite the assertion to target a missing behavior.
