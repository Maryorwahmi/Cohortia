Learning Objectives

Four practiceable skills guided by Bloom's mini‑bar.

Bloom: Learn → Understand → Apply → Master
01
Explain each phase

Describe Red, Green, Refactor mechanics and why each exists for safe incremental design.

VERIFIED COMPETENCY MILESTONE
02
Apply the cycle to features

Use Red‑Green‑Refactor to iteratively implement features such as reverse or registration logic.

VERIFIED COMPETENCY MILESTONE
03
Avoid common pitfalls

Recognize tests that pass immediately, overly broad tests, and the danger of skipping refactor.

VERIFIED COMPETENCY MILESTONE
04
Refactor responsibly

Use passing tests to guide safe refactors: rename, extract, and simplify without changing behavior.

VERIFIED COMPETENCY MILESTONE
