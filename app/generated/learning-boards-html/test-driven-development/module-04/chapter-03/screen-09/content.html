Module 4 › Chapter 4.3 › Refactor Phase
Refactor opportunities
Domain object
Replace loose dictionaries with an Order class when multiple tests need structured access.
Transaction handling
If charge can succeed and stock deduction fail, tests will prompt a rollback or transaction manager.
Extract collaborator interfaces
Make clear interfaces for payment and inventory services to simplify testing and future implementations.
Refactor checklist
  • Does a repeated pattern appear in three or more places?
  • Are tests fragile because they inspect internals?
  • Can names be improved to make intent clearer?
Key Takeaway

Refactor after green; let tests guide extraction of domain types and transaction concerns so design improves incrementally.
