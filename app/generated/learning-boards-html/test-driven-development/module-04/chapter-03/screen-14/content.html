Module 4 › Chapter 4.3 › Key Concepts
Outside-In Design
Design from the client's perspective by writing tests that specify usage.
Emergent Design
Let tests reveal when to add classes and abstractions rather than predicting them up front.
Refactor for Design
Use tests to refactor confidently, extracting clearer responsibilities and types.
Summary takeaway
Treat tests as the first consumer. Design emerges as tests add requirements, and refactoring under test coverage turns small solutions into clear architecture.
