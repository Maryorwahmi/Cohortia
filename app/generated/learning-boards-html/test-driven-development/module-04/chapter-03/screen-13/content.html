Assessing TDD-driven design

Checklist
  • Do tests read like client examples?
  • Are collaborators injected and mockable?
  • Do tests avoid asserting private internals?
Practical assessment
Write one failing test for an edge case. If the test forces a new class or method, record that as emergent design in action.
Reflection prompt

Which small failing test could reveal a clearer responsibility boundary in your current project?
