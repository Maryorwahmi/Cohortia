Practice checklist
01 Mock external deps

Replace databases and remote APIs with mocks so tests run quickly and deterministically.

02 Split lifecycle tests

Break large tests into single-purpose tests following Arrange-Act-Assert.

03 Use behavior assertions

Assert on observable behavior or types rather than fragile strings or internals.

04 Clean tests in refactor

Apply the same clarity and DRY principles to tests as to production code; extract helpers when needed.
