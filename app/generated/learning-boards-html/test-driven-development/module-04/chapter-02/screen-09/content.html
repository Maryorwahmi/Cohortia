Module 4 › Chapter 4.2 › Arrange-Act-Assert
AAA pattern
Arrange: create fresh mocks and inputs. Act: perform a single behavior. Assert: check results and interactions. Keep each test focused to one behavior.
Arrange: mock_user_repository = Mock()
Act: result = user_service.register_user(username, password)
Assert: assert result is True and repository.add called once
Example test snippet
# Arrange
mock_repo = Mock()
user_service = UserService(mock_repo)
username = "bob"
password = "secure_password"

# Act
result = user_service.register_user(username, password)

# Assert
assert result is True
mock_repo.add.assert_called_once_with({"username": username, "password": password})
Key Takeaway

Write tests so Arrange, Act, and Assert are explicit and each test has one reason to fail.
