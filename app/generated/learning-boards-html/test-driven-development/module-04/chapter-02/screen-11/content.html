Module 4 › Chapter 4.2 › Brittle Tests
Signs of brittle tests
  • Assertions on exact message texts or formatting.
  • Dependence on internal data structures or ordering.
  • Tests that break after harmless refactors.
How to fix
Assert on types, returned values, or observable state. Split tests that check multiple behaviors. If a helper hides intent, inline the arrangement so the test remains explicit.
Key Takeaway

Make tests resilient to internal refactors by asserting contracts, not implementation details.
