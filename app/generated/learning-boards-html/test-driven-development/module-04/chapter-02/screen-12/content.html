When to mock
  • External services or databases that make tests slow or flaky.
  • Services whose failures you want to simulate deterministically.
  • Dependencies that are not under test but whose interactions matter.
How to mock
Dependency-inject a repository or client into your service, then in tests provide a fresh unittest.mock.Mock instance. Use return_value to simulate responses and assert_called_once_with to verify expected calls.
@pytest.fixture
def mock_product_repository():
    return Mock()

def test_create_product_success(mock_product_repository):
    service = ProductService(mock_product_repository)
    product_id = "P001"
    service.create_product(product_id, "Laptop", 1200.0)
    mock_product_repository.add.assert_called_once_with({"id": product_id, "name": "Laptop", "price": 1200.0})
Key Takeaway

Design for injection of dependencies so tests can supply mocks and stay fast and focused.
