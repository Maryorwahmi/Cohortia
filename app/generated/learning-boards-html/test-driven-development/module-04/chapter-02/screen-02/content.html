Identify FIRST

02
Use AAA

Structure tests as Arrange, Act, Assert so each test has a single reason to fail. Practice: rewrite a lifecycle test into three small tests.

VERIFIED COMPETENCY MILESTONE
03
Avoid brittleness

Focus tests on behavior, not fragile implementation details. Practice: replace exact string matches with type or behavior assertions.

VERIFIED COMPETENCY MILESTONE
04
Mock dependencies

Use mocks or stubs for databases and external APIs so tests remain fast and deterministic. Practice: refactor a session-scoped fixture into a mock fixture per test.

VERIFIED COMPETENCY MILESTONE
How to practice
  • Pick a slow or flaky test and identify which FIRST property it violates.
  • Refactor setup into a per-test mock or fixture to achieve isolation.
  • Split broad tests into single-purpose tests using AAA.
