Writing Good Tests: Characteristics and Best Practices

This chapter teaches how to write unit tests that are easy to run, diagnose, and maintain. We'll use FIRST and AAA as practical rules to make your test suite an asset rather than a liability.

In this lesson
Identify the FIRST principles and structure tests with AAA.
Coming up
Refactor a shared-test example into isolated unit tests using mocks.
Why it matters
Fast, reliable tests let you change code confidently and ship safely.
Explore Key Topics
FIRST principles
Fast, Isolated, Repeatable, Self-validating, Timely
Arrange-Act-Assert
Structure every test for clarity
Mocking & Fixtures
Replace slow dependencies for speed and isolation
Concept map
FIRST → AAA → Maintainability
Fast: keep tests small and avoid external IO
Isolated: use mocks or fresh fixtures
Timely: write tests before or alongside code
Quick start

We will inspect bad tests that use a shared repository, then refactor them into small, focused tests that use a mock repository. Follow the Arrange-Act-Assert pattern as a habit.
