Module 4 › Chapter 4.2 › Refactor Activity
Refactor steps
  1. Remove the session-scoped shared repository fixture.
  2. Introduce a pytest fixture that returns Mock() per test.
  3. Split lifecycle test into focused tests using AAA.
  4. Use mock assertions to verify repository interactions.
Starter refactor snippet
from unittest.mock import Mock
import pytest
from product_service import ProductService

@pytest.fixture
def mock_repository():
    return Mock()

@pytest.fixture
def product_service(mock_repository):
    return ProductService(mock_repository)

def test_create_product_success(product_service, mock_repository):
    # Arrange
    product_id = "P001"

    # Act
    result = product_service.create_product(product_id, "Laptop", 1200.00)

    # Assert
    assert result["id"] == product_id
    mock_repository.add.assert_called_once_with({"id": product_id, "name": "Laptop", "price": 1200.0})
Key Takeaway

Refactoring tests into small, mocked units improves speed and makes failures easier to act on.
