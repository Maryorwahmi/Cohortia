Comparison
Ice Cream Cone Anti-pattern
When the test suite is dominated by slow, brittle E2E checks and lacks a reliable base of unit tests.
Consequences
  • Slow CI and delayed feedback.
  • High flakiness and maintenance cost.
  • Difficulty isolating root causes.
Remediation Steps
1. Push logic down
Convert E2E scenarios that verify business logic into unit or API tests when possible.
2. Add integration checks
Introduce targeted integration tests for fragile contracts between services.
Key Takeaway

Balance matters: increasing fast unit checks and focused integration tests reduces the need for many brittle E2E tests.
