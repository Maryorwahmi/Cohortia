Practical Objectives
Apply audit, rebalancing, and mapping steps to real test suites.
Measure Composition
Count tests by type, measure run times, and track flakiness rates to spot bottlenecks.

Decide which E2E scenarios can be covered by API or unit tests, and plan targeted E2E coverage.
VERIFIED COMPETENCY MILESTONE
Map to Quadrants
Classify tests by purpose: support the team or critique the product, and by technology or business focus.

Mitigate Flakiness
Replace fragile UI interactions with API checks or add stable integration tests for contracts.
