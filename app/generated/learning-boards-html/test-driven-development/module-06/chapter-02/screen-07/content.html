Module 6 › Chapter 6.2 › End-to-End Tests: Value and Limits
Comparison
End-to-End Tests
Full-system scenarios that validate user value but require careful scope control.
When to use
Critical business flows and sanity checks for release readiness.
How to reduce brittleness
  • Keep E2E count small and focused.
  • Assert outcomes, not fragile UI selectors.
  • Use stable test environments and mocked external services when possible.
Concrete Example
Critical Path
User login and purchase confirmation: valuable to test end-to-end but keep the test minimal and stable.
Anti-pattern
Relying on hundreds of UI tests that make CI slow and debugging difficult.
Key Takeaway

Choose E2E tests for a few high-value journeys and keep them coarse and stable; push other checks down the stack.
