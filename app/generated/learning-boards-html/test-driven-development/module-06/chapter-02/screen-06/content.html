Module 6 › Chapter 6.2 › Integration Tests: Verifying Interactions
Process Flow
Integration Tests
Verify interactions and contracts between components using controlled real dependencies.
When to use
When faults are likely to arise from component interaction or contract changes.
Design tips
  • Use test databases or sandboxed services.
  • Seed deterministic data and clean state between runs.
  • Focus tests on contracts, schema, and side effects.
Example Interaction
Order Service ↔ Database
Test that order creation persists records and returns expected IDs under known input.
Service ↔ Message Queue
Ensure events are published with correct schema and routing keys.
Misconception

Integration tests are not a substitute for E2E tests; they validate contracts but not full user journeys or UI-level behavior.
