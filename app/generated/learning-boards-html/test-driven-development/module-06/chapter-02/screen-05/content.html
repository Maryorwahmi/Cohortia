Module 6 › Chapter 6.2 › Unit Tests: Goals and Best Practices
Definition
Unit Tests
Isolated, deterministic checks for single units of code.
Characteristics
  • Fast execution and deterministic outcomes.
  • Minimal setup; no network or DB I/O.
  • Pinpoint failures to a specific function or class.
Common Pitfall
Over-mocking integration points so you miss real contract failures later.
Code Example
// Unit test for order total calculation
function calculateTotal(items, taxRate) {
  // deterministic function without I/O
  const subtotal = items.reduce((s, i) => s + i.price * i.qty, 0);
  return Math.round((subtotal + subtotal * taxRate) * 100) / 100;
}

// Test
const items = [{price: 10, qty:1}, {price:5, qty:2}];
const total = calculateTotal(items, 0.1);
// expect total to equal 22.00
Key Takeaway

Keep unit tests small, fast, and focused on logic. Use other test types for contracts and integration behavior.
