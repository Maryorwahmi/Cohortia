Module 6 › Chapter 6.2 › Hands-on Activity: Analyze a Slow, Flaky Suite
Scenario
Current distribution
Unit: 150 tests (30s). Integration: 50 tests (5m). E2E: 100 tests (30m).
Visualize
This shape resembles an ice cream cone: too many slow E2E tests relative to the base.
Problems
  • Slow developer feedback.
  • Flaky UI tests causing noisy failures.
  • Integration tests may be overlapping or redundant.
Exercise
Pick 3 E2E scenarios that can be tested at lower levels and one integration test to simplify. Examples might include login flows, single-api logic, or checkout price calculations.
Action

Write a concrete plan to convert chosen E2E tests to API or unit tests and measure the expected CI time reduction.
