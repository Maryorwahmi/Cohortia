Core Concept
What is the Test Pyramid?
A volume-based heuristic that balances speed and scope for testing.
Unit Tests — Base
Many, fast, isolated checks that give precise failure locations.
Integration Tests — Middle
Fewer checks that ensure components and services collaborate correctly.
E2E Tests — Top
Small set of full-system scenarios validating real user flows.
Concrete Example
Consider an online checkout:
Unit
Test a function that computes order totals for discounts and taxes.
Integration
Verify order creation uses the payment service and writes to the orders database in a test environment.
E2E
Simulate a user completing checkout via the web UI and confirm they land on an order confirmation screen.
Key Takeaway

Use many fast unit tests to catch defects early; reserve E2E for high-value user journeys only.
