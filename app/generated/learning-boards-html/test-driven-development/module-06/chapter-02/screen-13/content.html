Module 6 › Chapter 6.2 › Propose a Rebalancing Strategy
Plan
Concrete Actions
1. Audit & Tag
Label each E2E by purpose so you can prioritize conversions.
2. Convert to API/Unit
Move logic checks like calculation or input validation into unit or API tests.
3. Split heavy integrations
Break large integration tests into focused contract tests with seeded data.
Example conversions
E2E login → API integration
Test the authentication endpoint directly for token issuance and error responses.
E2E checkout total → Unit test
Move price calculation and discount logic into focused unit tests with edge cases.
Expected result

Faster CI runs, fewer flaky failures, and clearer diagnostics for regressions.
