Reverse-List Example with Hypothesis
A minimal property test that exercises generators and shrinking.

Code
from hypothesis import given, strategies as st

def reverse_list(items):
    return items[::-1]  # Simple implementation

@given(st.lists(st.integers()))
def test_reverse_twice_is_original(original_list):
    # Property: reversing twice should return the original
    assert reverse_list(reverse_list(original_list)) == original_list

Property
reverse twice equals identity on lists.
Outcome
