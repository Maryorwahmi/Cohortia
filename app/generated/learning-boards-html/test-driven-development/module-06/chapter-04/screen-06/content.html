Definition
Properties (Invariants)
State what must hold across all valid inputs. Focus on observable behavior.
Kinds of useful properties
  • • Structural invariants (length, membership, types).
  • • Idempotence (applying twice equals applying once).
  • • Round-trip or inverse properties (decrypt(encrypt(x)) == x).
Common mistake
Writing properties too tied to a specific implementation leads to brittle tests during refactor.
Concrete property examples
• Reverse property: reverse(reverse(list)) == list
• Normalize property: normalize_text(normalize_text(s)) == normalize_text(s)
Example: reverse list
def reverse_list(items):
    return items[::-1]
