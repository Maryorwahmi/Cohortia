Learning Objectives
These four objectives will guide practice and assessment. Each card includes a small mnemonic to help you recall the skill.
Learn
Understand
Apply
Master
01
Differentiate PBT from example-based testing
You will explain why properties test invariants across many inputs, unlike single examples. This matters because it reveals unknown edge cases your examples may miss.
Mnemonic: lock-and-keys visual — many keys vs one key.
VERIFIED COMPETENCY MILESTONE
02
Explain generators, properties, and shrinking
You will describe how strategies produce inputs, how properties assert invariants, and how shrinking simplifies failures for debugging.
Mnemonic: three stacked cards labeled G, P, S.
VERIFIED COMPETENCY MILESTONE
03
Use a PBT framework to write tests
You will write Hypothesis-style tests that generate diverse inputs and assert meaningful properties for pure functions and transformations.
Mnemonic: terminal prompt icon + test file name.
VERIFIED COMPETENCY MILESTONE
04
Identify PBT-suitable scenarios and limits
You will select cases like pure functions, data transforms, and idempotent operations, and recognize when side effects make PBT less appropriate.
Mnemonic: filter funnel icon — pick the right use cases.
