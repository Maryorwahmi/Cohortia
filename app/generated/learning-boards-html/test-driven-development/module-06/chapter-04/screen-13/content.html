What to Remember
Key Concepts
Property-Based Testing
Define invariants and test them across many generated inputs.
Generator (Strategy)
A component that produces arbitrary values shaped to your domain.
Shrinking
Reduce a failing input to the smallest example that still fails for easier debugging.
Summary Takeaway

Combine PBT and example-based tests: use PBT to explore and find surprises, and use example tests to document and guard fixes discovered by shrinking.
