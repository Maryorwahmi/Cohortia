Example-Based vs Property-Based Testing
Analogy: one key versus many keys — exploration vs specification.
Eyebrow: Comparison
Example-Based Testing
  • • You choose inputs and assert exact outputs.
  • • Great for documenting expected behavior and regression tests.
  • • Coverage depends on chosen examples; blind spots are possible.
Misconception
Example tests suffice for exploration. They do not automatically explore the full input space.
Property-Based Testing
  • • You declare properties and let generators create many inputs.
  • • Useful for revealing unknown edge cases and structural invariants.
  • • Includes shrinking to simplify failing cases for debugging.
Key Takeaway
PBT broadens test coverage by exploring inputs; it complements example-based tests rather than replacing them.
