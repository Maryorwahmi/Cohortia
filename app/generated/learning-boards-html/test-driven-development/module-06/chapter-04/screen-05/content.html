Definition
Generators (Strategies)
Compose simple strategies to build realistic input spaces and include edge cases deliberately.
What a generator does
  • • Produces arbitrary values of a given type or shape.
  • • Can be composed to produce lists, tuples, and nested structures.
  • • Should reflect domain constraints to avoid irrelevant failures.
Pro tip
Sample a few generated values before asserting properties to verify the generator yields meaningful cases.
Example generator patterns
Items you should include when testing a text normalizer:
  • • Empty string and whitespace-only strings
  • • Long strings and short strings
  • • Strings with tabs, multiple spaces, and special Unicode characters
Concrete example
from hypothesis import strategies as st
# lists of integers
st.lists(st.integers())
# text including unicode
st.text()
# constrained: non-empty ascii strings
st.text(min_size=1, alphabet=st.characters(whitelist_categories=("Lu","Ll","Nd")))
