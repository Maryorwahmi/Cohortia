Process Flow
PBT Workflow: From Generator to Shrunk Failure
A repeatable loop that produces discovery and actionable minimal failures.
1. Generate
Sample many inputs via strategies.
2. Execute
Run the property assertion on each input.
3. Fail
Record failing input when assertion breaks.
4. Shrink
Reduce to a minimal counterexample for debugging.
Tip
Run focused strategies locally and broader exploration in scheduled CI to balance cost and discovery.
Action
After a shrunk failure, add an example test documenting the minimal case and fix code or property.
Misconception
If shrinking yields a small case, it is not necessarily the only failing pattern; it is the simplest the framework found.
