Definition
Shrinking
Automatically reduce failing inputs to their simplest form to aid debugging.
How shrinking helps
  • • Converts a large random failing input into a minimal counterexample.
  • • Makes the failure easier to inspect and reason about.
  • • Distinguishes between code bugs and incorrect properties by clarifying the failing pattern.
Before
[1, 0, -5, 100, 2, 0, 7]
After shrinking
[0, -5]
Practical step
Use the shrunk example to write a concrete example-based test that documents the bug and guards the fix.
