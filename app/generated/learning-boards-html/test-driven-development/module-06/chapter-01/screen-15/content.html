Module 6 › Chapter 6.1 › Key Concepts
Refactoring
Restructure code without changing its external behavior to improve clarity and testability.
Code Smells
Surface clues like long methods and large classes that suggest extraction and simplification.
Dependency Injection
Pass collaborators to enable substitution with test doubles and reduce tight coupling.
Summary
Use tests as a safety net, extract responsibilities into focused units, and inject dependencies to keep tests simple and reliable.
