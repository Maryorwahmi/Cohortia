Example pytest tests
def test_successful_payment():
    processor = PaymentProcessor(MockGatewayService())
    result = processor.process_payment(1, 100, {"card_number": "1111222233334444", "cvv": "123", "expiry_year": 2025})
    assert result["status"] == "success"
    assert "transaction_id" in result


def test_invalid_card():
    processor = PaymentProcessor(MockGatewayService())
    result = processor.process_payment(1, 100, {"card_number": "123", "cvv": "x", "expiry_year": 2020})
    assert result["status"] == "failed"
    assert result["message"] == "Invalid card details"
Guidance
Keep characterization tests stable and focused on outcomes you want to preserve. They do not replace the small unit tests you will write for extracted components.
Pro Tip

Write these tests first, then refactor in tiny steps, running the suite often.
