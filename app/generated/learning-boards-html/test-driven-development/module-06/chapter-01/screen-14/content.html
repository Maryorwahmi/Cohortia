Module 6 › Chapter 6.1 › Pitfalls & Safety
Big risks
  • Refactoring with failing tests
  • One large rewrite instead of incremental steps
  • Refactoring for performance before clarity
Practical safety checklist
  1. Ensure tests pass right now.
  2. Make a single small change and run tests.
  3. Commit and repeat.
Keep changes narrow. If a change requires adjusting many tests, split it into smaller refactors until each test only needs local updates.
