Module 6 › Chapter 6.1 › UserBalanceService
Design
UserBalanceService.update_balance(user_id, amount) should encapsulate all persistence concerns and return True on success or False on failure. Tests can provide a fake repository to simulate failures without touching the real database.
Test plan
  • Unit test success path with fake repo returning success.
  • Unit test failure path with fake repo raising or returning failure.
  • Integration check: PaymentProcessor uses the service and reflects failures in result.
Result: simpler mocks, clearer assertions, and a PaymentProcessor free of database code.
