Module 6 › Chapter 6.1 › Dependency Injection
What to inject
  • External APIs or gateway clients
  • Database or persistence services
  • Loggers and time providers
Small change: pass gateway_service into the constructor instead of creating it inside the class. Tests can then provide a mock.
Concrete example
Constructor injection: def __init__(self, gateway_service, logger): self.gateway_service = gateway_service. In tests, supply a MockGatewayService that returns a known transaction id or raises a controlled error.
Key Takeaway

Dependency injection converts hard-to-test internals into swappable collaborators that tests control.
