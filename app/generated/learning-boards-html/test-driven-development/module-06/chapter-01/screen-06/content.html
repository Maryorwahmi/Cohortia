Module 6 › Chapter 6.1 › Code Smells
Typical smells
  • Long method: does many tasks and resists a single unit test.
  • Large class: multiple reasons to change and many dependencies to mock.
  • Duplicate code: scattering logic increases test surface area.
  • Hard-coded dependencies: instantiation inside methods prevents mocking.
Common Pitfall

Ignoring smells because tests exist increases future maintenance cost and test brittleness.

Concrete contrast
Before: PaymentProcessor handles validation, gateway calls, logging, and persistence.
After: Extract CardValidator, GatewayClient, Logger, and UserBalanceService — each tested separately.
