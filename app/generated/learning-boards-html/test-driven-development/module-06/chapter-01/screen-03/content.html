Characterization Tests
Write integration-level tests that record current behavior so you can refactor confidently.
When to use: Before refactor
What they protect: existing behavior
Extract & Inject
Break responsibilities into small services and accept them via constructor or parameters for easy mocking.
Commit often
Make one small, test-safe change, run tests, commit; repeat until the full refactor is complete.
Quick checklist
  • Tests pass before refactor
  • One small change at a time
  • Run tests immediately after
