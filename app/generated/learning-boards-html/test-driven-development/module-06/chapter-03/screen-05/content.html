Module 6 › Chapter 6.3 › Characterization tests
Process: Write, run, protect
  1. Choose a small behavior to capture with concrete inputs and outputs.
  2. Write an integration test asserting current outputs for those inputs.
  3. Run tests and record results; commit them as your safety net.
  4. Refactor to create seams, run tests to confirm no regression.
Common mistake

Writing brittle tests that replicate implementation details rather than observable outcomes. Characterization tests should assert behavior, not internal calls.

Concrete example
def test_calculate_final_price_us_customer_without_discount():
    calculator = PriceCalculator()
    assert calculator.calculate_final_price(100, 1, "US") == 108.00

def test_calculate_final_price_us_even_customer_with_discount():
    calculator = PriceCalculator()
    assert calculator.calculate_final_price(100, 2, "US") == 97.20
Key Takeaway

Characterization tests protect your refactors by asserting observable outcomes for representative cases.
