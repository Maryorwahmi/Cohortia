Module 6 › Chapter 6.3 › What is a seam?
Seam patterns
  • Constructor injection: accept dependencies via constructor arguments.
  • Interface or protocol extraction: depend on an abstract contract, not a concrete class.
  • Method extraction or wrapper function: call through a separable function you can override in tests.
Why seams matter

They let you isolate logic, substitute test doubles, and write fast, focused unit tests during refactoring.

Refactor example
class PriceCalculator:
    def __init__(self, tax_service=None, discount_service=None):
        self.tax_service = tax_service or TaxService()
        self.discount_service = discount_service or DiscountService()

    def calculate_final_price(self, base_price, customer_id, country_code):
        tax_rate = self.tax_service.get_tax_rate(country_code)
        discount_percentage = self.discount_service.get_discount_percentage(customer_id)
        price_after_discount = base_price * (1 - discount_percentage)
        return round(price_after_discount * (1 + tax_rate), 2)
This constructor refactor creates seams so tests can supply mocks.
