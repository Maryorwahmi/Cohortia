Module 6 › Chapter 6.3 › Mikado Method
Steps
  1. Identify the goal: a feature or refactor you want to complete.
  2. Try it and observe blockers that prevent completion.
  3. Rollback and record each blocker as a prerequisite.
  4. Work the prerequisites one by one with tests until the goal is achievable.
Goal: Add new feature to LegacyService
Prereq A: Add tests to OldUtilityClass
Prereq B: Extract a small method from OldUtilityClass
Working the graph topologically — implement and test prerequisites first — makes the final change small and safe. Misconception: the Mikado Method is not indecision; it is disciplined sequencing to reduce risk.
