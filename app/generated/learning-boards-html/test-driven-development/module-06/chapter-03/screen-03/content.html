Module 6 › Chapter 6.3 › Skills and assessment
Demonstrable skills
  1. Write stable characterization tests for concrete inputs.
  2. Refactor to create seams and keep tests green.
  3. Write unit tests with controlled mocks for injected services.
  4. Plan changes using the Mikado Method and verify each prerequisite.
Misconception check

A common mistake is to treat characterization tests as permanent correctness assertions. Remember: they capture existing behavior to enable safe refactoring, not to prove the code is correct. When you intentionally change behavior, update tests to the new expected behavior after careful verification.
