Module 6 › Chapter 6.3 › Write characterization tests
Example pytest file: test_price_calculator.py
from legacy_calculator import PriceCalculator

def test_price_us_customer_no_discount():
    calculator = PriceCalculator()
    assert calculator.calculate_final_price(100, 1, "US") == 108.00

def test_price_us_customer_with_discount():
    calculator = PriceCalculator()
    assert calculator.calculate_final_price(100, 2, "US") == 97.20

def test_price_ca_customer_no_discount():
    calculator = PriceCalculator()
    assert calculator.calculate_final_price(100, 1, "CA") == 112.00
Run: pytest -q. Expect green results if code matches earlier samples. If external calls make the tests flaky, substitute deterministic returns in the services temporarily, commit, then proceed to refactor.
