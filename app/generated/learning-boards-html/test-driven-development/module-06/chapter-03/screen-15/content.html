Module 6 › Chapter 6.3 › Key Concepts
Legacy Code
Code lacking automated tests; treat it as risky to change until you add a safety net.
Characterization Tests
Tests that capture existing behavior to prevent regressions during refactor.
Seam
A substitution point that allows injecting mocks and testing units in isolation.
Takeaway

Start small: pick one behavior, write a characterization test, create a seam to enable a mock, and then evolve the code with the Mikado Method.
