Key Concepts: The TDD Cycle

Essential terms and ideas from Red, Green, Refactor

Red Phase

The initial step where a new, failing test is written to define a new piece of functionality.

Green Phase

The second step where the minimal amount of production code is written to make the failing test pass.

Refactor Phase

The final step where the production code is improved in terms of design, without changing its external behavior.

Chapter Summary

The Red, Green, Refactor cycle is the disciplined, iterative heartbeat of TDD, guiding developers to write failing tests, implement minimal code to pass them, and then improve the code's design with confidence, all while maintaining a robust safety net against regressions.
