Phase 2: Green

Write Just Enough Code

Implement the absolute minimum production code to make the failing test pass.

Sole Focus: Turn the red test green, nothing more.

Avoid Over-engineering: Don't worry about perfect design or future requirements yet.

Run Tests Immediately: Verify that all tests pass after implementation.

Key Takeaway

The Green phase is about achieving functionality, not perfection. Simplicity and passing the current test are paramount.
