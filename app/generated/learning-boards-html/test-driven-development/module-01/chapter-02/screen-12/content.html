Hands-on Activity

Implement `max_of_two_numbers`

Follow the TDD cycle to create a function that returns the larger of two numbers.

Red Phase: Write `test_max_of_two_positive_numbers` expecting `max_of_two_numbers(5, 3) == 5`. Observe failure.

Green Phase: Implement `max_of_two_numbers` minimally (e.g., `if a > b: return a else: return b`). Observe pass.

Refactor Phase: Review and improve code (e.g., use `max(a, b)`), ensuring tests still pass.

Key Takeaway

Applying the TDD cycle to a new problem reinforces the disciplined approach to feature development and code quality.
