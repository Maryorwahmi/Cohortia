Phase 1: Red

Write a Failing Test

Your goal is to write a new unit test for a small piece of functionality that *must fail*.

Confirm Absence: A failing test proves the feature doesn't exist or is broken.

Validate Test: Ensures your test is correctly written and can detect a failure.

Clear Objective: A failing test provides a clear, measurable goal for the next phase.

Key Takeaway

A failing test is not a bug; it's a deliberate signal that guides your development and validates your test's effectiveness.

The Red Phase: Executable Specification
# test_example.py

import pytest
from my_module import new_feature # This will cause an ImportError

def test_new_feature_works():
    # Arrange
    input_data = "test"
    expected_output = "result"

    # Act
    actual_output = new_feature(input_data)

    # Assert
    assert actual_output == expected_output
