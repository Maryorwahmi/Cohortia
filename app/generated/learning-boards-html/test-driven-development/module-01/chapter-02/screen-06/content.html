Test for `reverse_string`

Create a test that expects a function to reverse a string, knowing the function doesn't exist yet.

Define Behavior: The test specifies what `reverse_string` should do: turn "hello" into "olleh".

Expect Failure: The test will fail because `string_utils.py` and `reverse_string` don't exist yet.

Key Takeaway

The initial failure confirms the test's validity and provides a clear, actionable goal for implementation.

Common Mistake

Don't write too much test code or try to test multiple scenarios at once. Keep it minimal and focused.

`test_string_utils.py`
# test_string_utils.py
import pytest
from string_utils import reverse_string # This will initially cause an ImportError

def test_reverse_simple_string():
    # Arrange
    input_string = "hello"
    expected_output = "olleh"

    # Act
    actual_output = reverse_string(input_string)

    # Assert
    assert actual_output == expected_output
