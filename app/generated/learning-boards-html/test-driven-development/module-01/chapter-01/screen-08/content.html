The Red-Green-Refactor Cycle

A continuous feedback loop for disciplined development.

R
1. Red: Write a Failing Test

Define new behavior with a test that fails.

G
2. Green: Write Minimal Code

Implement just enough code to make the test pass.

R
3. Refactor: Improve Code

Clean up and optimize code while keeping tests green.

Example: Adding a Feature

You want to add a 'subtract' function. First, write a test for subtract(5, 2) == 3 (Red). Then, implement subtract (Green). Finally, clean up the code (Refactor).

Key Takeaway

The Red-Green-Refactor cycle is a continuous, iterative process that ensures every new feature is well-tested, functional, and integrated into a clean codebase.
