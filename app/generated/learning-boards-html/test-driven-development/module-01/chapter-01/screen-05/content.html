The 'Test-First' Approach in Action

Writing a failing test before any functional code exists.

1. Write a Failing Test

Define desired behavior.

2. Write Minimal Code

Make the test pass.

3. Refactor & Repeat

Improve code while tests stay green.

Example Scenario

Before writing an add(a, b) function, you'd write a test like assert add(2, 3) == 5. This test would fail initially, guiding your implementation.

Key Takeaway

The 'test-first' approach ensures that every line of functional code is written to satisfy a specific, pre-defined requirement, making development highly intentional.
