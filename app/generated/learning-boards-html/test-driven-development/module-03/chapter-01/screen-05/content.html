Definition
Stub — returns controlled data
Use when the test needs a specific return value from a dependency.
When to use
Fetching a user record to build a profile, simulating an error response, or providing a fixed timestamp.
Misconception
Stubs do not verify interactions. If you need to assert that a method was called, use a mock instead.
Key Takeaway

Choose a stub when you only need specific return values to drive the unit under test.

Concrete stub example
A repository stub returns a fixed user object so get_user_profile returns predictable data.
# Example pseudo-code for a stubbed repository
class UserRepositoryStub:
  def get_user_by_id(self, user_id):
    return {"id": user_id, "username": "alice", "email": "alice@example.com"}

# Test uses the stub rather than a real database
repo = UserRepositoryStub()
service = UserService(repo, DummyEmailService())
profile = service.get_user_profile(1)
assert profile['username'] == 'alice'
Note: the stub returns canned data and does not record calls.
