Common MagicMock Assertions
Pick the assertion that matches the behavioral contract
assert_called_once_with()
Use when exactly one call is required with specific args.
assert_called_with()
Verifies the most recent call's args; doesn't enforce count.
assert_any_call()
Checks that at least one call matched the provided args.
assert_not_called()
Asserts the mock was never invoked; use for negative paths.
Common mistake
Using assert_called_with when multiple calls are possible will not catch extra unwanted calls.
Pro tip
Combine call assertions with checks on return_value when the SUT consumes a mock's return.
