Practice & Assessment
Concrete tasks and how you'll be validated
Set up mocks
Create MagicMock objects with spec to catch incorrect attribute access and document expected interactions.
Write assertions
Choose assert_called_once_with, assert_not_called, or assert_any_call depending on the scenario and the required strictness.
Avoid over-mocking
Limit verification to external side effects and collaborators that represent meaningful behavior boundaries.
