Key Concepts
Three compact reminders
Behavior Verification
Asserting that important methods were called with expected arguments.
Mocks vs Stubs
Stubs supply data; mocks record calls and allow assertions on interactions.
Avoid Over-mocking
Mock only what matters to avoid brittle tests tied to implementation details.
Summary

Use mocks as witnesses to important interactions, configure them sensibly, and prefer assertions that protect public behavior.
