Exceptions & Side Effects on Mocks
Simulate failures to verify robust error handling
Raise an exception
mock.save_user.side_effect = Exception('db error') to test how the SUT handles failures.
Multiple call responses
Set side_effect to a list to return different values per call or a callable for dynamic behavior.
Pitfall
Reusing mocks across tests with side_effect set can leak behavior; create fresh mocks per test.
Key Takeaway

Simulate errors with side_effect to validate that the unit responds correctly and important side effects are not performed when failures occur.
