Learning Objectives
Skills and competencies to practice
Bloom: Learn → Understand → Apply → Master
01
Differentiate stub vs mock
Explain the role of stubs and mocks and why mocks are used for interaction verification. VERIFIED COMPETENCY MILESTONE
Mnemonic: two overlapping circles — data vs behavior
02
Implement mocks with unittest.mock
Set up MagicMock objects, specify specs, and use assertion helpers to verify calls. VERIFIED COMPETENCY MILESTONE
Mnemonic: small mock icon plus checklist
03
Assert specific calls and arguments
Use assert_called_once_with, assert_not_called, and assert_any_call to make precise verifications. VERIFIED COMPETENCY MILESTONE
Mnemonic: target icon + arrow
04
Recognize and avoid over-mocking
Identify when mocking internal calls creates brittle tests and prefer verifying external behavior. VERIFIED COMPETENCY MILESTONE
Mnemonic: stop sign icon for caution
