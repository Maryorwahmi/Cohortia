Module 3 › Chapter 3.2 › Practical Reminders
Dependency Injection
Design classes to accept dependencies so tests can substitute stubs easily.
Use spec
Limit mocks to the real interface to make tests safer and clearer.
Know the limits
If tests require varied internal behavior or thorough interaction verification, choose fakes or mocks appropriately.
Final takeaway
Stubs keep unit tests fast and focused. Use them when you only need to control dependency outputs, and switch to fakes or mocks when the test's goals require more than simple data control.
