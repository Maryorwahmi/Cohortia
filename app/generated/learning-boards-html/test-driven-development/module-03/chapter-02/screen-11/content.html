Why spec helps
Spec restricts the mock to the attributes and methods of the real class. This converts silent mistakes into immediate, test-time errors and serves as executable documentation for the expected interface.
Example
mock = MagicMock(spec=WeatherService)
mock.get_current_temperature.return_value = 20.0
Practical tip
Prefer spec when stubbing concrete classes or interfaces. If you need a flexible ad-hoc stub, be deliberate about why you skip spec and document the trade-off.
Key Takeaway
Spec keeps tests honest: it prevents tests from silently calling methods that don't exist on the real object.
