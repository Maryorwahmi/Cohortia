Stubbing
Replace a dependency with predefined responses so tests focus on logic.
unittest.mock.MagicMock
A versatile class for creating stubs and mocks in Python tests.
return_value
The attribute used to specify what a stubbed method returns when called.
Quick takeaway
Stubs simplify unit tests by making inputs predictable. Use MagicMock with spec and return_value to create safe, readable stubs.
