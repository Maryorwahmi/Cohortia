Practice timeline
Plan
Decide if a stub is the right double for the test's intent.
Write
Create MagicMock(spec=...), set return_value per test, and inject.
Verify
Assert outcomes and optional interaction sanity checks.
Refine
If stub logic grows, move to a fake or simplify tests.
Quick checklist
  • Per-test explicit configuration
  • Use spec for safety
  • Prefer output assertions over excessive call checks
  • Keep tests independent and fast
