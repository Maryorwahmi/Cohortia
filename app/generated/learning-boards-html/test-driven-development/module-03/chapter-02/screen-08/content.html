Module 3 › Chapter 3.2 › Dependency Injection
Pattern
Provide dependencies from outside (constructor, setter, or factory). This allows tests to pass in stubs and keeps production wiring separate from test wiring.
Example
class UserService:
  def __init__(self, user_repo):
    self.user_repo = user_repo
Why it matters
  • Makes injecting MagicMock or fake implementations trivial in tests.
  • Prevents accidental use of real I/O inside unit tests.
  • Tends to produce clearer, more maintainable code boundaries.
Refactor hint
If a class instantiates a dependency, consider passing it in via the constructor for testability.
