Module 3 › Chapter 3.2 › Creating a Stub
Step-by-step
1.
Accept dependencies by injection so they can be replaced in tests.
2.
Create MagicMock(spec=RealClass) for interface safety.
3.
Set stubbed_method.return_value to the desired test data.
4.
Inject stub, run the unit, and assert outcomes and optional interaction checks.
Example (code)
Below is a concise test snippet demonstrating the pattern. The code configures return_value and asserts the freezing check.
from unittest.mock import MagicMock
from temperature_converter import TemperatureConverter, WeatherService

mock_weather = MagicMock(spec=WeatherService)
mock_weather.get_current_temperature.return_value = 20.0  # Fahrenheit
converter = TemperatureConverter(mock_weather)
assert converter.is_freezing("AnyCity") is True
Common mistake
Forgetting spec allows calls to nonexistent methods, which hides typos and breaks safety.
