Module 3 › Chapter 3.2 › Configuring return_value
Static return_value
mock_repo.get_user_by_id.return_value = { 'id': 1, 'name': 'Alice' }
Every call to get_user_by_id returns the same object until reconfigured.
Argument-sensitive (side_effect)
def stub_get(user_id):
  if user_id == 1:
    return {'id':1, 'name':'Alice'}
  return None

mock_repo.get_user_by_id.side_effect = stub_get
Use side_effect for small argument-dependent mappings. Move to fakes if logic grows.
Rule of thumb
Prefer clarity: explicit return values per test are easiest to read. Side effects are powerful but increase cognitive load. Fakes are for realistic behavior that supports multiple tests without complex stub code.
