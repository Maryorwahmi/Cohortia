Implementing Stubs for Controlled Test Behavior
Use simple test doubles to return predictable values and keep unit tests fast and isolated.
Why stubs matter
They remove external variability so tests run quickly and consistently every time.
Example in this chapter
TemperatureConverter uses a stubbed WeatherService. UserService tests stub the UserRepository.
Explore Key Topics
Creating a stub
Use MagicMock with return_value to supply predictable outputs for methods.
Safety with spec
Use spec to prevent typos and ensure the stub matches the real dependency's interface.
When not to stub
If dependency requires behavior, consider a fake; if verifying calls is primary, consider a mock.
Interactive Concept
Stub flow
Call dependency → stub returns configured value → unit processes value → assert outcome
Visual summary
Stubs are simplest test doubles: configurable, fast, and focused on supplying data rather than behavior verification.
