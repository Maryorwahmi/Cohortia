Starter fake
This fake stores orders and returns a saved order with a simple unique id. It’s deterministic and lightweight for tests.
# fake_order_repository.py
class FakeOrderRepository:
  def __init__(self):
    self._orders = {}
    self._next_id = 1

  def save_order(self, order_data: dict) -> dict:
    order_id = f"ORD_{self._next_id}"
    self._next_id += 1
    saved_order = {"id": order_id, **order_data}
    self._orders[order_id] = saved_order
    print(f"Fake: Saved order {order_id}")
    return saved_order
How to use in tests
Instantiate the fake, pass it to OrderService, call place_order with valid data, then assert the returned order has an id and the fake's internal _orders contains the saved order.
Tip: Keep internal structures private. Prefer assertions against public returns, and use internal state only when necessary for test observability.
