Module 4 › Chapter 3.4 › Choosing a Double
Comparison grid
Stub — provides fixed outputs. Use when you only need controlled data for a single call.
Mock — replaces object and asserts interactions. Use for strict call ordering or counts.
Fake — implements simplified behavior and state. Use for multi-call stateful flows.
Spy — wraps real method to record calls while letting logic run. Use for focused internal verification.
Trade-offs
Mocks increase coupling to implementation and can be brittle.
Fakes may diverge from production semantics; validate with integration tests.
Spies inspect internal behavior and can encourage testing private details; use them sparingly.
Guideline

Pick the simplest double that achieves clarity and reliability for the test scenario.
