Module 4 › Chapter 3.4 › Key Concepts
Fake
A simplified, working implementation used for stateful, realistic tests.
Spy
Wraps a real object to record calls while the original methods execute.
Choice rule
Start simple and escalate: stub → mock → fake → spy as complexity demands.
Takeaway
Use focused fakes for stateful flows and spies for essential internal verification; always prefer clarity and speed in tests.
