Module 4 › Chapter 3.4 › Best Practices
Checklist
Prefer the simplest double — start with stub.
Keep fakes minimal and focused on test scenarios.
Use spies only for essential internal verification.
Document fake limitations and intended uses.
Pair fakes with integration tests for real fidelity checks.
Assert on public outcomes when possible to avoid brittle tests.
Final Reflection

Which part of your current test suite would benefit from a small fake or a focused spy? Try refactoring one test and observe the difference in speed and clarity.
