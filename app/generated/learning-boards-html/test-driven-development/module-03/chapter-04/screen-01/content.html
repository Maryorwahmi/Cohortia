Fakes and Spies: Advanced Test Double Techniques
Balance realism and speed: implement simplified dependencies or watch real methods run.
In this lesson
Fakes, spies, code examples, and a hands-on activity implementing a fake repo and spy in Python.
Why it matters
Faster tests with realistic behavior; less flaky integration overhead while keeping good verification.
Outcome
You will identify when to use each double and write effective fakes and spies in tests.
