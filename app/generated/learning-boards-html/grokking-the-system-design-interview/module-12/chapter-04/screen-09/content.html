Module 12 › Chapter 12.4 › Scaling to Petabytes
Capacity vs Throughput

Capacity grows managed by object stores; throughput grows with request QPS and metadata operations. Both need attention at petabyte scale.

Controls
  • Lifecycle rules: transition cold objects to cheaper tiers automatically.
  • Distribute object keys to avoid hot prefixes and high API load on particular partitions.
  • Use CDN and caching to absorb user-facing reads.
Example policy

Move objects not accessed in 90 days to cold storage, archive in 365 days, delete after 5 years — tune windows to usage patterns to balance availability and cost.

Monitoring metrics
  • Total storage size per bucket over time.
  • Read and write requests per second by prefix or prefix groups.
  • Cache hit ratio across CDNs and edge nodes.
Key Takeaway

At scale, requests and operations can dominate costs and limits. Manage both storage tiers and request distribution to keep performance predictable.
