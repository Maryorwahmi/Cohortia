Module 12 › Chapter 12.4 › Key Concepts — Part 1
Object Storage
Cloud-based storage for immutable video files with high durability and tiering.
Content Metadata
Structured information about videos suited to relational storage and SQL queries.
User Metadata
Per-user data such as watch history and playback positions stored for low-latency access.
Summary

Ask what shape the data is and how it's accessed. Use that to pick object storage, relational databases, or NoSQL accordingly.
