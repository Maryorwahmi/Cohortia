Module 12 › Chapter 12.8 › Storing & Serving with CDN
Origin + CDN flow
Client GET /tiles/{style}/{z}/{x}/{y}.mvt
→ CDN edge cache hit? return tile
→ on miss: CDN fetch from origin storage s3://tiles-bucket/{style}/{z}/{x}/{y}.mvt
→ CDN caches tile with configured TTL
Set cache-control headers and version tile paths to invalidate safely when styles or data change.
Practical advice
Use long TTLs for static base tiles, shorter TTLs for overlays. Consider cache warming for hotspots like city centers.
Security & cost
Protect origin with permissions and use signed URLs or edge rules to prevent hotlinking and unexpected egress costs.
Key Takeaway

Design origin paths, TTLs, and access controls so CDN caching reduces latency and limits origin egress.
