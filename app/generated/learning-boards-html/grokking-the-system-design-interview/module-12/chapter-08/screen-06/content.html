Module 12 › Chapter 12.8 › Tile Generation Pipeline
Numbered Steps
1
Ingest raw data
Collect vector features and raster imagery as canonical sources.
2
Project & preprocess
Normalize to Web Mercator and clean attributes.
3
Render or extract
Raster: render pixels with Mapnik. Vector: extract & simplify features then encode as MVT.
4
Package & store
Write tiles to an origin storage path keyed by z/x/y for deterministic retrieval.
5
Distribute via CDN
Edge caches reduce latency and origin load; prime popular tiles where useful.
Concrete scenario
A nightly batch job renders raster tiles for zooms 0–10 while a parallel vector pipeline creates MVT tiles for zooms where interaction and styling are required.
Common mistake
Skipping simplification raises vector tile sizes at high zooms and hurts delivery performance.
Key Takeaway

Tune projection, simplification, and rendered zoom coverage to balance size, quality, and compute.
