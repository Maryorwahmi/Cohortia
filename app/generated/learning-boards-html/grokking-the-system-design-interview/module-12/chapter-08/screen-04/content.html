Module 12 › Chapter 12.8 › What is a Map Tile?
Definition

A tile is a small square asset that represents map content at a fixed zoom level. It can be an image or a chunk of vector data.

Why tiles?
They make maps cacheable, reduce rendering work, and allow partial updates when panning and zooming.
Common misconception
Tiles are only images. In fact vector tiles carry feature data and let clients re-style maps without re-rendering pixels.
Key Takeaway

Tiles turn global rendering into many small, cacheable requests so interactive maps stay fast.

Practical check
When estimating storage, remember tile counts grow exponentially with zoom. Pick zoom coverage to balance detail versus cost.
