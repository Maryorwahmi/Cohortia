How zoom scales tiles
At zoom z the tile grid is 2^z along each axis. That exponential growth drives storage and processing decisions for tiling pipelines.
z=0 → 1 tile
z=1 → 4 tiles
z=2 → 16 tiles
z=10 → 1,048,576 tiles
Projection notes
Web Mercator is convenient for tiling but distorts polar areas. Most web maps accept that trade-off for tile simplicity.
Practical planning
Decide zoom coverage from user behavior. Avoid pre-generating rarely requested extreme zooms to save cost.
Key Takeaway

Tile counts scale as 2^z per axis—plan zoom limits to optimize cost and usefulness.
