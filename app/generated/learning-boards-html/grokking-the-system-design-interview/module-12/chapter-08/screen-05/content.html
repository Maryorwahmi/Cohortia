Module 12 › Chapter 12.8 › Raster vs Vector
Raster Tiles
Pre-rendered images like PNG or JPEG. Easy to serve as static files, predictable rendering.
  • Advantages: Simple serving, consistent look across clients.
  • Disadvantages: Large file sizes, inflexible styling, poor for frequently changing overlays.
When to prefer
Photo-based tiles or when client rendering capability is limited.
Vector Tiles
Geometry and attributes packaged per tile. Rendering and styling happen client-side for flexibility and compact size.
  • Advantages: Small payloads, dynamic styling, infinite scaling for high-DPI displays.
  • Disadvantages: More client CPU, requires a capable rendering library on the client.
When to prefer
Interactive, styleable layers and frequent overlay updates like traffic lines.
Concrete Example
Satellite imagery: raster. A themable city-street map with dynamic traffic: vector tiles with streamed overlays.
