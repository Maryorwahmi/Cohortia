Module 12 › Chapter 12.8 › Dynamic Overlays
Raster overlay approach
Serve transparent image tiles for the overlay on top of the base map. Simple but costly for frequent updates.
When used
Infrequent changes or when client rendering capabilities are limited.
Vector overlay approach
Stream or fetch vector features and render client-side. Efficient for frequent updates and styling.
When used
Real-time traffic, transit vehicle locations, or live annotations.
Concrete example
Traffic as a geo-feed: client requests only current viewport features and updates colors by speed. This avoids re-downloading entire overlay tiles each time traffic changes.
