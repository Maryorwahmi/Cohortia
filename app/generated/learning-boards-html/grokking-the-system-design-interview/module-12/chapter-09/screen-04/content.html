Core Concept
Graph Representation
Nodes, edges, and weights align to real-world roads and constraints.
  • Define nodes for intersections or decision points.
  • Edges represent traversable segments; choose directed edges for one-way streets.
  • Weights capture travel time, distance, or cost; pick the unit that matches routing goals.
Example

A downtown block network uses nodes at every intersection. One-way streets are edges in one direction; left-turn penalties can be additional edge weights to discourage costly turns.

Key Takeaway

Model with the routing objective in mind: unit of weight and topology choices directly affect results and performance.

Analogy

Common mistake
Using distance when fastest-time is required, causing incorrect route choices under variable traffic.
