Dijkstra’s Algorithm
Expand nodes by shortest-known distance until the goal or all nodes are settled.
1. Initialize distances: start node 0, others infinity.
2. Use a priority queue keyed by current distance.
3. Extract the smallest, relax outgoing edges, and update neighbors.
4. Repeat until destination is popped or queue is empty.
Concrete example

Start at A; set dist(A)=0. Relax A→B and A→C producing 5 and 10. Pop B next, relax B→D, and so on. The queue order drives exploration.

Common mistake

Assuming Dijkstra is fast enough for global, live queries; in practice it may explore too much of the graph.

Pseudo-code
function dijkstra(graph, start):
  dist = map from node to infinity
  dist[start] = 0
  pq = priority queue with (start, 0)
  while pq not empty:
    node, d = pq.pop_min()
    if d > dist[node]:
      continue
    for (neighbor, weight) in graph[node]:
      nd = d + weight
      if nd < dist[neighbor]:
        dist[neighbor] = nd
        pq.push((neighbor, nd))
  return dist
Note: < and > are escaped for HTML. This version assumes non-negative weights.
