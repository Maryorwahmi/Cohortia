Definition
Contraction Hierarchies
Remove low-importance nodes, add shortcuts, and query the reduced graph rapidly.
Select nodes to contract in an order minimizing shortcuts.
Add shortcut edges so that shortest path distances remain representable.
At query time, perform bidirectional search on contracted graph and meet in the middle.
Concrete example

Contract residential intersections and add shortcuts so highway-to-highway connectivity is immediate in the contracted graph.

Pitfall

Frequent topology changes make reprocessing expensive; treat dynamic traffic as overlays rather than re-contracting constantly.

CH components
Node ordering heuristic and contraction engine
Shortcut insertion logic to preserve shortest-paths
Query: bidirectional, order-respecting search for microsecond responses
