Process Flow
Transit Node Routing
Select transit nodes and precompute inter-transit distances for very fast long trips.
Choose a small set of transit nodes likely used by long trips.
Precompute distances between all transit nodes and from nodes to nearby transit nodes.
Assemble long routes from origin→transit, transit→transit, and transit→destination segments.
Example

For inter-city travel, most routes use a handful of highway interchanges as transit nodes; precomputing inter-transit distances speeds answers.

Trade-off

TNR requires storage for transit tables and careful selection of nodes to maximize coverage of long trips.

Composition steps
Local search: origin to nearby transit nodes
Lookup: precomputed transit-node to transit-node distances
Local search: transit nodes to destination
