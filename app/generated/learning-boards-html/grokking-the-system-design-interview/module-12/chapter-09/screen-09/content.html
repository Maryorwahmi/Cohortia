Definition
Real-time Traffic
Traffic data changes edge weights and must be integrated safely and quickly.
Ingest sensor and probe data via a stream system to produce weight updates.
Validate and smooth noisy inputs to avoid thrashing route answers.
Apply updates as deltas over a stable base graph to preserve consistency.
Scenario

A sudden accident increases travel time on a segment. The system broadcasts a delta and routing engines compute alternate paths or update ETA calculations accordingly.

Common mistake

Directly mutating base weights without versioning can create inconsistent query results and make rollbacks difficult.

Streaming update pipeline
Ingest: probes, sensors, crowd reports
Process: validate, aggregate, predict future congestion
Apply: update dynamic deltas or time-indexed weights used by routing engines
