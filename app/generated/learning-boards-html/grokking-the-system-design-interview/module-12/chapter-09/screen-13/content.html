Architecture
Real-time Routing Service
A pipeline that integrates base graph data, stream processing, and fast query serving.
Graph Storage: distributed, sharded, holds base weights and topology
Traffic Ingest: streaming capture of probes and sensors
Traffic Processing: validate, aggregate, predict deltas
Routing Engine: CH/TNR/A* cluster applying deltas
API Gateway: stateless front that routes requests to engines
Caching: store hot routes or fragments in low-latency store
Operational notes
Version graph updates and apply atomically to avoid inconsistent reads
Validate traffic feeds to avoid corrupting edge weights
Cache invalidation: evict or refresh cached routes when deltas make them stale
