Interactive features and services
Maps combine visual layers with backend services like geocoding, routing, and search to form the user experience.
Base geometry
Roads, building footprints, and topology used by search and routing.
Imagery & tiles
Raster or vector tiles for visual rendering at multiple zoom levels.
Dynamic overlays
Traffic, transit, and user reports that must be processed in near real time.
Illustrative flow
Example: a directions request
Step 1: Client geocodes start and end addresses into coordinates.
Step 2: Routing engine queries road graph and applies traffic adjustments.
Step 3: Server returns route geometry and ETA; client displays route overlay on tiles.
Key Takeaway

A mapping platform is an integrated set of layers and services; both must scale and update continuously.
