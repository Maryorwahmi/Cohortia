Tile concepts
Raster tiles
Pre-rendered images at discrete zoom levels for fast display.
Vector tiles
Compact geometry that clients style and render, useful for overlays and flexible visuals.
CDN caching
Store tiles at the edge to serve users worldwide with low latency and reduced origin load.
Client interaction example
When a user pans, the client requests tiles in the new viewport. The CDN returns cached tiles instantly; if a tile is missing the origin generates it and the CDN caches it for future requests.
Key Takeaway

Tiles and CDNs are the practical pattern to scale map delivery while keeping client bandwidth and CPU usage low.
