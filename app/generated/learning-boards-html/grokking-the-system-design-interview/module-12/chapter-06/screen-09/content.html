Module 12 › Chapter 12.6 › Architecture
Routing building blocks
Graph model
Nodes and edges represent intersections and road segments with associated weights.
Algorithms & optimizations
Shortest-path algorithms plus caching, hierarchical routing, and precomputation for common queries.
Traffic integration
Edge weights are adjusted using live traffic ingestion to update ETAs in near real time.
Example scenario
A delivery app requests a route; the routing engine consults the road graph, applies current traffic speeds to edge weights, computes the fastest path, and returns turn-by-turn directions and an ETA.
Key Takeaway

Routing requires both algorithmic efficiency and the ability to incorporate frequently changing edge weights from traffic feeds.
