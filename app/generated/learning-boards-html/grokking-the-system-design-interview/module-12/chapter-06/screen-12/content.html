Module 12 › Chapter 12.6 › System Concern
Latency strategies
CDN edges
Cache tiles and vector blobs close to users for fast fetch times.
Regional services
Replicate search and routing services to reduce regional latency and improve resiliency.
Consistency patterns
Differentiate which data can be eventually consistent vs. requiring stronger guarantees.
Operational question
Decide TTLs per layer: long for stable base tiles, short for traffic overlays. Use regional replication for low-latency services but plan for propagation and rollback paths for authoritative corrections.
Key Takeaway

Global distribution requires careful TTLs and replication choices; not every data type needs the same consistency level.
