Storage types
Object storage
Stores large raster imagery and tiles; optimized for throughput and capacity.
Spatial databases
Contain geometric types and support spatial joins and queries for precise features.
Search indices
Enable full-text POI queries combined with spatial filters for rapid lookups.
Retrieval example
Responding to "coffee shops near me": a search index finds matching POIs; spatial DB filters and ranks by distance; tile store supplies images for map rendering.
Key Takeaway

Use specialized storage for different data classes and orchestrate them to produce fast, coherent responses.
