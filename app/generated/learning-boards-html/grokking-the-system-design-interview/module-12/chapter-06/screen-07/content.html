Index types
Quadtrees
Recursive spatial partitioning that pairs well with tile grids and raster data.
R-trees
Bounding-box based structure that adapts to arbitrary vector geometries and densities.
Geohashes
String encodings of coordinates that preserve locality for range queries in key-value stores.
Practical example
To find nearby restaurants, compute the covering set of index cells for the search radius, fetch candidates from those cells, then apply an exact distance check to rank and return results.
Key Takeaway

Pick an index technique that matches your data shape: tiles for imagery, R-trees for arbitrary vectors, geohash for simple key-based locality.

Common Pitfall
Skipping spatial indexing or using a mismatched index will cause poor query performance at scale.
