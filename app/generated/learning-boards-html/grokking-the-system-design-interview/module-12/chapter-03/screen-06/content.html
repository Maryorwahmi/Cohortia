Comparison
VOD (On-Demand)
Static transcoded segments after upload.
  • • Use longer TTLs to maximize cache hit ratio.
  • • Invalidate explicitly when an asset changes.
  • • Efficient for cost reduction and playback predictability.
Example
A trimmed edit of a movie requires a targeted invalidation to ensure all PoPs serve the new file.
Comparison
Live Streaming
Segments are generated continuously and freshness is critical.
  • • Use short TTLs or push invalidation to ensure freshness.
  • • Aggressive caching reduces latency but risks serving older segments if misconfigured.
  • • Monitor segment staleness and error rates carefully.
Pitfall
Long TTLs for live cause viewers to see stale content; short TTLs for VOD waste cache opportunities.
Key Takeaway

Match invalidation policies to content type: favor hit ratio for stable VOD, favor freshness for live, and avoid TTL mistakes that push origin traffic or serve stale segments.
