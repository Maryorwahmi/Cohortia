Security
Signed URLs / Tokens
Cryptographic, time-limited URLs prevent scraping and unauthorized sharing.
• Include Expires timestamp and a signature HMAC-SHA256 over path and parameters.
• Edge validates signature and expiry before serving.
• Optionally include IP restrictions to narrow allowed clients.
Practical Note
Sign only necessary parts of the URL to preserve cacheability of identical paths across users.
Key Misconceptions
  • • Signed URLs are not a replacement for HTTPS; they work together.
  • • Overly broad signing breaks caching because each user gets unique URLs.
  • • Key rotation is necessary to limit blast radius from compromises.
Key Takeaway

Use signed URLs with expirations and measured parameter choices to secure access while preserving caching effectiveness.
