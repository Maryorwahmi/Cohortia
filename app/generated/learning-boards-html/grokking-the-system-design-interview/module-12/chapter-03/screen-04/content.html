Core Concept
CDN and Edge PoP
A cache layer that stores and serves transcoded video segments close to viewers.
Key elements:
  • • Edge PoP: a geographically located cache optimized for local traffic.
  • • Origin: authoritative storage where new segments are uploaded or fetched from on cache misses.
  • • Cache hit ratio: percentage of requests served from edge rather than origin.
Example
A viewer in Paris gets a segment from a Frankfurt PoP instead of an origin in the US, reducing latency and avoiding cross-continent egress.
Common Mistake
Assuming the CDN removes the need for an origin. The origin is still required for updates and cache misses.

Key Takeaway

Treat the CDN as a scalable cache layer; the origin remains the authoritative source but will serve far fewer requests when caching is effective.
