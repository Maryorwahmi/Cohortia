Module 12 › Chapter 12.7 › Geohashing fundamentals
Core Idea

Encode coordinates to strings with locality

Nearby coordinates share longer geohash prefixes, which makes prefix queries an efficient coarse filter for proximity searches.

How to use

Generate a geohash for the query point, search for records with the same prefix and nearby neighbor prefixes, then apply accurate distance calculations to candidates.

Operational role

Perfect for approximate nearest-neighbor and partitioning when exact topology is not required at the first stage.

Concrete example

For Los Angeles coordinates a five-character geohash yields a prefix that represents a few-kilometer square; query that prefix to gather candidates then filter by exact distance for precise results.

Takeaway
Geohash is fast and simple for coarse proximity and sharding. Always follow up with precise checks when accuracy matters.
