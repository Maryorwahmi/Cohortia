What PostGIS provides

Geometry types and spatial functions

PostGIS adds native geometry types and a library of spatial functions that let SQL express geometric and topological queries.

Common functions
  • ST_Contains - whether one geometry fully contains another
  • ST_Intersects - whether geometries overlap
  • ST_Distance - compute distance between geometries
Operational note

Indexes must be maintained as writes occur. High write rates can fragment indexes and require reindexing or tuned maintenance windows.

Example Query Flow
  1. Select candidate geometries whose bounding rectangles overlap the query area via an R-tree index.
  2. Run precise ST_Intersects or ST_Contains on candidates to compute exact results.
  3. Return geometries that pass the exact check.
Takeaway
Use PostGIS when you need topological operations or exact geometry correctness; pair with lightweight filters when necessary to scale.
