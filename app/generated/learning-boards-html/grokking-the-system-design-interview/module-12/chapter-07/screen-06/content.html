Module 12 › Chapter 12.7 › R-tree indexing and MBRs
Core Concept

Hierarchical MBR grouping

MBRs summarize spatial objects. R-tree organizes MBRs into a tree so queries prune large regions quickly.

Query workflow
  1. Traverse nodes whose MBR overlaps the query area.
  2. Collect leaf candidates whose MBRs overlap.
  3. Run exact geometry checks on candidates to confirm matches.
Practical note

R-trees are ideal when polygon and line operations are common and exactness matters.

Concrete example

Searching for intersecting roads: an R-tree prunes out distant map tiles quickly by rejecting MBRs before checking road geometry intersections only in candidate tiles.

Common misconception
An overlapping MBR is not a definite match; it is a candidate that must be verified with exact geometry checks.
Takeaway
Use R-trees for exact geometric queries; monitor update costs and schedule index maintenance for heavy-write workloads.
