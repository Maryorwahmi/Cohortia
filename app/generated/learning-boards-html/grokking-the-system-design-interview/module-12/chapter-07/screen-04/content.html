Definition

Spatial primitives and queries

Geospatial systems operate on points, lines, and polygons and support spatial relationships such as contains, intersects, and distance.

Why indexing is needed
  • Exact geometry checks are compute-heavy for large sets.
  • Indexes provide fast coarse pruning using bounding shapes.
  • Most queries benefit from a two-stage filter-then-verify approach.
Concrete example

A '5km radius' query first selects candidate bounding boxes that overlap the circle, then computes exact distances only for those candidates to return precise results.

Common mistake

Treating lat and lon as independent columns and relying on full scans ignores topology and leads to slow queries at scale.

Visual: layered filtering
Imagine many complex polygons each represented by a simple minimum bounding rectangle. A spatial index stores those rectangles so a search can quickly reject non-overlapping MBRs and only run exact polygon checks on the remainder.
Takeaway
Plan queries as filter then verify. Indexes reduce geometry work dramatically.
