Module 12 › Chapter 12.7 › Hands-on: Geohashing for proximity search
Example

Generate a geohash and filter

Use a geohash library to encode coordinates at precision five for a few-kilometer radius, then use prefix matching as the first-stage filter.

Workflow
  1. Encode query coordinates at chosen precision.
  2. Query records with that prefix and neighbor prefixes.
  3. Run exact distance calculations to return true neighbors.
Starter code (Python)
import geohash

lat = 34.0522
lon = -118.2437
precision = 5  # for a few-kilometer radius

la_geohash = geohash.encode(lat, lon, precision)
print("Geohash for LA:", la_geohash)
Run this to get a five-character geohash for Los Angeles. Use that prefix and its neighbors in a prefix-matching query, then compute exact distances on candidates.
Takeaway
The code shows the initial encoding step; the rest of the pipeline involves neighbor prefix selection and exact distance filtering.
