Module 12 › Chapter 12.5 › VOD vs Live
VOD
Pre-recorded, optimized offline
  • Transcoding is a batch process; many renditions generated once.
  • Latency is not a hard constraint; caching offers large efficiency gains.
  • Infrastructure can prioritize storage and transfer cost efficiency.
Example
Movie streaming where multiple bitrate files are stored and delivered on demand.
Live Streaming
Real-time, latency-sensitive
  • Ingest, real-time transcoding, and delivery must meet a latency budget.
  • Segments are short; manifests update continuously and CDNs must handle frequently changing content.
  • Operational concerns include redundancy, monitoring, and rapid scaling.
Misconception
Treating live like VOD by using long segments can make interactive experiences unusable.
