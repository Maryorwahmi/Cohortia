Latency vs Efficiency
  • Long segments: efficient CDN caching, but add seconds of latency.
  • Short segments/parts: low latency and quicker ABR response, but higher request rates.
Example
Switching from 6s to 1s parts reduces latency but increases origin and CDN load; plan for more frequent requests.
Operational note
Ensure keyframe alignment across renditions so ABR switches cleanly; monitor CDN request per second and cache hit ratios as parts are introduced.
