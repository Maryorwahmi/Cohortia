Module 12 › Chapter 12.5 › RTMP Ingest Demo
FFmpeg command (example)
ffmpeg -re -i sample.mp4 -c:v libx264 -preset veryfast -g 48 -keyint_min 48 -b:v 3000k -maxrate 3500k -bufsize 6000k -c:a aac -ar 44100 -b:a 128k -f flv rtmp://localhost/live/stream
Notes: -g and keyint_min set keyframe interval; use -re to read at real-time for testing.
Terminal output to expect
Input #0, mov,mp4,m4a,3gp,3g2,mj2, from 'sample.mp4':   Stream mapping: Stream #0:0 -> #0:0 (h264 (native) -> h264 (libx264)) Press [q] to stop, [?] for help frame= 123 fps=25 q=23.0 size= 1024ktime=00:00:04.92 bitrate=1701.3kbits/s speed=0.975x
Watch for connection errors, dropped frames, and bitrate changes. Automate reconnects where possible.
Concrete guidance
Use small keyframe intervals and tune encoder bitrate to match upstream links. Capture FFmpeg stderr stream to detect failures and switch to a backup ingest if needed.
