Module 12 › Chapter 12.5 › Live Transcoding
Transcode pipeline
  1. Ingest receives a source feed and normalizes packets.
  2. Demux and decode to raw frames.
  3. Encode into multiple renditions (ABR).
  4. Segment and push parts to the origin for delivery.
Example
A 4K live feed is converted to 1080p@4Mbps, 720p@2Mbps, and 360p@500kbps. Each rendition uses aligned keyframes every two seconds so players can switch without visual glitches.
Pro tip
Allocate extra transcoding workers for warm failover and monitor encode queue depth to trigger auto-scaling before queues grow.
