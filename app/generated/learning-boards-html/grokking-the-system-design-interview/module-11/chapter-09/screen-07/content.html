Definition
Message Queue: Partitions & Consumer Groups
Use partitions to scale throughput and consumer groups to parallelize processing.
Partitions
A topic is split into multiple partitions. Each partition is an ordered sequence. Producers write to partitions, and ordering is guaranteed within a partition.
Analogy: conveyor belts; add belts to increase throughput.
Consumer Groups
A consumer group distributes partitions among its consumers so partitions are processed in parallel but only by one consumer at a time.
Note: consumers ≤ partitions for effective scaling.
Example
If you need to process 1M messages per minute, increase partitions to allow more consumers to work in parallel and ensure replication to handle broker failures without data loss.
Key Takeaway
Match partitions to expected parallelism and replicate partitions for durability.
Pitfall
Too few partitions prevents scaling even if you add more consumers.
