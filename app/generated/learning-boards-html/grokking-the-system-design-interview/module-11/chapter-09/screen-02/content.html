Scale chat servers horizontally
Add servers and use stateless design to allow dynamic scaling and fast failover. VERIFIED COMPETENCY MILESTONE
Mnemonic: many small boxes rather than one big box.
02
Partition the message pipeline
Use partitions and consumer groups to parallelize processing and ensure durability. VERIFIED COMPETENCY MILESTONE
Mnemonic: lanes on a highway for messages.
03
Shard message and user data
Choose chat_id for messages and user_id for user data to keep lookups local. VERIFIED COMPETENCY MILESTONE
Mnemonic: group related items in the same box.
04
Design geo distribution & replication
Route clients to nearby regions and decide active-active or active-passive replication. VERIFIED COMPETENCY MILESTONE
Mnemonic: place servers near users for speed.
