Key Concepts
Horizontal Scaling
Add instances and externalize server state for elasticity and resilience.
Sharding (chat_id)
Use chat_id to co-locate conversation messages and optimize history reads.
Hot Shard
A shard overwhelmed by traffic; mitigate with sub-partitioning, buffering, or caching.
Partitions & Consumer Groups
Partitions enable parallelism; consumer groups distribute partitions to consumers.
Geo Distribution
Deploy regions close to users and choose replication mode thoughtfully.
Replication Modes
Active-active lowers latency but requires conflict handling; active-passive simplifies consistency.
Summary

Align sharding keys with query patterns, externalize server state, and plan replication and hotspot mitigations early in your design.
