Core Concept
What is a Chat System?
Persistent, low-latency messaging with guarantees around delivery and durability.
Definition & Guarantees
  • Bidirectional, near-instant message exchange between participants.
  • Requires low-latency delivery, durable storage, and presence management.
  • Often uses persistent connections and message brokers for routing and durability.
Misconception
Polling for messages is simple but does not meet latency or resource efficiency needs; choose persistent connections for scale-sensitive chat.
Concrete Example
In a team chat, messages must arrive quickly and persist. Use a broker for delivery, durable storage for history, and connection routing to reach users connected across multiple servers.
Presence & Routing
Track which server each user is connected to for efficient message routing.
Durability
Persist messages to durable storage to survive server failures and allow history retrieval.
Key Takeaway

Design for persistent connections, durable message storage, and routing that scales with concurrent connections.
