Fanout Strategies for News Feeds
Push, pull, and hybrid approaches and when to use them.
Step-by-step
  1. Push: On write, replicate post into follower timelines for low-latency reads. High write amplification.
  2. Pull: Store posts centrally and assemble feed on read. Lower write cost, higher read latency.
  3. Hybrid: Use heuristics: push for low-fanout authors, pull for high-fanout authors, and cache recently read content.
Practical heuristic: if follower_count < threshold then push, else pull and cache hot reads.
Concrete Scenario
A microblogging service sees many users with few followers and a few celebrities with millions. Use push for the majority to make reads instant; use pull for celebrities to avoid enormous replication work.
Pro Tip
Combine push, pull, and cache warm-up for hot feeds to balance latency and cost.
Key Takeaway

Fanout strategies are a cost-versus-latency trade. Use hybrid heuristics to scale efficiently.
