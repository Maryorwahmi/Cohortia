Scalability Techniques
Sharding, replication, balancing, and hotspot mitigation practices.
Key Patterns
  • Sharding: partition by user id or conversation id to distribute storage and compute.
  • Replication: use replicas for reads and regional availability, with controlled replication lag.
  • Load Balancing: distribute connections and HTTP requests across gateways and application servers.
  • Hotspot Mitigation: isolate high-traffic keys, cache hot items, or apply rate limiting and batching.
Concrete Example
Shard messages by conversation id so group chats are concentrated in a shard; if a group becomes extremely active, move it to a dedicated shard or replicate it across more nodes.
Pro Tip
Monitor per-shard metrics and set automated rebalancing triggers for sustained imbalance.
Key Takeaway

Partition and replicate thoughtfully, and plan hotspot mitigation rather than assuming uniform load distribution.
