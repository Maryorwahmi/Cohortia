Common Failures
A side-by-side comparison of symptoms and first actions.
Packaging fails immediately
Check Output Log for red errors: missing maps, Blueprint compile errors, or missing SDKs. Fix the earliest error and try again.
Packaged exe crashes on launch
Open Saved/Logs in the packaged folder to inspect runtime logs and stack traces for missing assets or runtime exceptions.
Large package size
Review assets for high-resolution textures or uncompressed audio; confirm you enabled pak files and did not accidentally include large editor-only files.
Quick Recovery Steps
  1. Open Output Log; locate the first red error and resolve it in the editor.
  2. Run a Development build to gather richer logs or reproduce the crash locally.
  3. If assets appear corrupted, enable Full Rebuild and repackage to regenerate cooked content.
  4. For missing maps, add them to the packaging list and re-run the package.
Example Troubleshoot
Output Log shows a failed Blueprint compile during cooking. Open the Blueprint, compile, fix errors, and repackage. If the packaged game still crashes, check the packaged Saved/Logs for runtime stack traces.
A systematic approach—fix the first error, repackage, and repeat—saves time and avoids chasing misleading symptoms.
