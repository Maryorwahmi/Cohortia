Packaging Steps
A compact step-by-step checklist to follow during a package run.
1. Select File → Package Project → Platform
Pick the target platform such as Windows (64-bit).
2. Choose output directory
Create a dedicated folder like MyGame_Packaged to keep outputs organized.
3. Monitor cooking and compile steps
Open Window → Developer Tools → Output Log to follow detailed messages.
Pro Tip

Run a short test package of a small map first to validate settings before a full project package.

What the Output Log reveals
  • Red errors indicate failures that must be resolved before a successful package.
  • Warnings can point to missing references or deprecated assets to review.
  • Success messages confirm cooked assets and compiled binaries were produced.
Example
If Output Log shows 'Missing map' during cooking, add the map to the packaging list and re-run packaging. If packaging completes but exe crashes, open the packaged Saved/Logs folder to read the runtime log.
