Module 6 › Chapter 6.5 › Configure Project Settings
Project Settings to check
Walk these settings before you package to avoid common omissions.
Maps & Modes
Set Editor Startup Map, Game Default Map, Transition Map, and ensure all runtime maps are listed under packaging.
Packaging
Set Build Configuration, Full Rebuild, Cook options, For Distribution, Use Pak File, and Generate Chunks if needed for large projects.
Platforms
Enable target platforms and set SDK/signing paths for mobile platforms as required.
Practical Example
For a Windows test package, set Build Configuration to Development, ensure maps are listed, enable Use Pak File, and choose an output folder when packaging.
Pro Tip
Use a small test map and Development build to validate settings quickly before committing to a full package.
Common Mistake
Forgetting to include maps in the packaging list leads to crashes when the packaged build tries to load them.
Check Your Work
After packaging, inspect the output folder to confirm a .pak file exists and that expected binaries and content folders are present.
This checklist minimizes surprises and narrows where to look if packaging fails.
