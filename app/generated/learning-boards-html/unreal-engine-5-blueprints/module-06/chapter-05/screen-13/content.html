Module 6 › Chapter 6.5 › Packaging Checklist
Pre-package checklist
  • Verify Default Maps and 'List of maps to include' contains your levels.
  • Set Build Configuration (Development for tests, Shipping for release).
  • Enable Use Pak File and optionally Full Rebuild if you suspect cache issues.
During packaging
  1. File → Package Project → choose platform and 64-bit target.
  2. Select an empty output folder for the package to avoid mixing builds.
  3. Open the Output Log window to watch cook and compile steps.
Post-package test
Run the .exe from Binaries/Win64, check Saved/Logs if it fails, and iterate with a Development build to capture detailed diagnostics.
Quick answers
Where to check first when exe crashes: Saved/Logs/MyGame.log. Five folders safe to delete before archiving: Binaries, Build, DerivedDataCache, Intermediate, Saved.
Key Takeaway

A short, repeatable checklist lets you ship reliably and create compact, restorable archives for long-term storage.
