Module 6 › Chapter 6.5 › Key Concepts
Output Log
Logs in Saved/Logs are your first stop for runtime crash diagnosis in packaged builds.
Clean Before Archive
Remove regenerable folders to save space: Binaries, Build, DerivedDataCache, Intermediate, Saved.
Version Control + Archives
Use Git for day-to-day work; keep full archives for milestones and long-term restore points.
Summary: Rely on logs to debug, clean before archiving to reduce size, and combine version control with periodic archives for safe, restorable releases.
