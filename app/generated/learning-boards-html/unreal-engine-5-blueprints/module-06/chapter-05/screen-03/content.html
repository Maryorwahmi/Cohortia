Practical Objectives
Each card describes the action and its verification step.
01 — Verify Default Maps
Ensure Editor Startup Map and Game Default Map are set; package and confirm the correct level loads.
VERIFIED COMPETENCY MILESTONE
02 — Build Configuration
Switch between Development and Shipping to test debugging vs optimized release builds.
VERIFIED COMPETENCY MILESTONE
03 — Use Pak File
Enable pak to bundle assets; verify packaged folder contains a single .pak file for content.
VERIFIED COMPETENCY MILESTONE
04 — Read Logs
Open Output Log during packaging and check the Saved/Logs folder in the packaged build if a crash occurs.
VERIFIED COMPETENCY MILESTONE
Mnemonic
Think M-P-B-L: Maps, Packaging options, Build config, Logs. Run each change and confirm results to avoid surprises.
Quick Tip
Use Development builds first when diagnosing crashes because they include more debug info.
