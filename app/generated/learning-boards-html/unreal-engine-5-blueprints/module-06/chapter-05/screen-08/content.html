Module 6 › Chapter 6.5 › Deployment Considerations
Target Platform Differences
Understand how output format and signing affect deployment.
Windows
Produces an exe and content folder. Zip for distribution and test on a clean machine to confirm dependencies.
Android / iOS
Produces APK or IPA and requires SDK/NDK paths, signing credentials, and store-specific upload steps.
Build Type
Use Development to debug on device, Shipping for optimized release builds that must be signed before submission.
Practical Checklist
  • Verify platform SDKs and signing settings are configured in Project Settings.
  • Package a Development build to test on device; gather logs if crashes occur.
  • For distribution, switch to Shipping and follow store signing requirements.
Example
Android packaging will fail without Android SDK paths. Confirm paths and test the resulting APK on a physical device before submitting to testers or stores.
Remember: packaging prepares the build; deployment requires additional platform steps such as signing, zipping, or uploading to stores.
