Module 6 › Chapter 6.5 › Key Concepts
Packaging
Create a standalone executable by bundling assets, Blueprints, and compiled code for a target platform.
Cooking
Prepare and convert assets into platform-ready formats as part of packaging to avoid runtime errors.
Pak File
A single archive that contains game content for efficient distribution and organized loading at runtime.
Summary: When you package, ensure cooking completes, maps are listed, and using a Pak file simplifies distribution and reduces missing-asset issues.
