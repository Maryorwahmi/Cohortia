Packaging, Cooking, and Pak Files
A precise definition and the practical effects you must check before shipping.
What packaging does
Compiles code, gathers and cooks assets, strips editor files, and produces a runnable folder or package for the platform.
What cooking means
Converting assets into platform-specific formats so they load correctly in the packaged runtime.
Pak files
Single-file content archives that improve distribution and often loading performance.
Key Takeaway

Treat packaging as a conversion step: if something works only in the editor, expect to test the packaged build and check cooked assets and included maps.

Illustrative Example
A map that is playable in the editor but not listed under packaging will be omitted and can cause a crash when loaded by the packaged game.
Concrete Scenario
You test a level in the editor, forget to add it to the packaging map list, package, and the packaged exe crashes on level load. The fix is to add the map then repackage or include it in the cooking list.
Common Misconception
Believing Development and Shipping builds behave identically. Development builds include debug info and may hide some shipping-only runtime failures.
Check
Verify cooked assets and pak file contents after packaging to ensure critical content is present.
