Module 6 › Chapter 6.5 › Packaged Build Logs
Typical log location
MyGame/Windows/MyGame/Saved/Logs/MyGame.log
Open the most recent file and search for keywords: Error, Exception, Failed to load.
Investigation checklist
  • Check for missing maps/assets referenced at startup.
  • Look for plugin or module load failures.
  • Compare log entries between Development and Shipping builds.
  • Test on target hardware to reproduce the issue.
Example log excerpt
[2026.09.26-12.00.00:000][  0]LogLoad: Warning: Failed to load '/Game/Levels/LevelX.LevelX'
[2026.09.26-12.00.01:123][  0]LogInit: Error: Missing asset referenced by default map
[2026.09.26-12.00.01:456][  0]LogWindows: Error: Exception: AccessViolation at 0x...
The 'Failed to load' line often points to the root cause of a crash on launch.
Takeaway

Logs tell the story of engine startup. Start there, reproduce with Development builds, and then fix the missing asset or runtime error.
