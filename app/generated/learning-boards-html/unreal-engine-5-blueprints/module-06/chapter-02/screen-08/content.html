Implement a repeating timer

Move your per-frame logic into a custom event and trigger it with Set Timer by Event.

// BeginPlay -> Set Timer by Event (Event: CheckForPlayers, Time: 0.2, Loop: True)
// Custom Event: CheckForPlayers
//   -> Sphere Overlap Actors
//   -> For Each Loop on Out Actors
//     -> Cast To BP_PlayerCharacter
//     -> Apply Damage
Adjust the timer interval to balance responsiveness and CPU usage. For many use cases 0.2–0.5 seconds is a good starting point.
Before & After
Before: Sphere overlap checks run every frame on Tick. After: checks run 5 times a second on a timer. Observe 'Game' time drop in 'stat unit'.
Pro tip
Use a slightly higher timer value if many actors use the same timer. The human perception cost of 0.2s vs 0.5s is often negligible.
