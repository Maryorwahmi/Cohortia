Assessment Idea

Sample question 1

'stat unit' shows Game time high and GPU low. Which optimization is most relevant and why?

Expected answer: minimize Event Tick, replace per-frame logic with timers or events because high Game time indicates CPU-side cost.

Sample question 2

Many AI actors recalculate paths every frame and the frame rate drops. What to change?

Expected answer: use Set Timer by Event or event-driven path updates so expensive pathfinding runs periodically or only when needed.
Evaluator tip
Look for answers that reference profiling evidence and a re-measure step to confirm impact.
