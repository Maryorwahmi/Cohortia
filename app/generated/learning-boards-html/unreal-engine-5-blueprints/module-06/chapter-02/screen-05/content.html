Process Flow

Run these in the console

Practical commands you will use immediately while debugging performance.

stat fps             // shows current frames per second
stat unit            // shows Game / Draw / GPU / Frame times
stat game            // breakdown of CPU game thread, incl. Blueprints
stat rhi             // rendering hardware interface stats
stat gpu             // detailed GPU timing for render passes
Use these commands while asking a single focused question: "Is my issue from game logic or rendering?" The commands let you answer that quickly.
Practical example
Play the level, open console, run 'stat unit'. Jump or spawn enemies to provoke load. If 'Game' rises, focus Blueprints. If 'GPU' rises, focus materials, meshes, and effects.
Pro tip
Run one stat at a time and observe changes. Record values before and after a change for comparison.
