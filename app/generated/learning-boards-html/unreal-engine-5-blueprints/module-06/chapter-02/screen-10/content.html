Definition

When GPU time is high

Run 'stat rhi' and 'stat gpu' to get rendering and GPU pass details you can act on.

stat rhi   // low-level render statistics
stat gpu   // GPU pass timing and per-pass costs
If GPU dominates, focus on materials, shader complexity, and draw calls instead of Blueprint code.
Example
A high-cost material used on many objects can push GPU time up. Simplifying the shader or reducing instances can lower GPU time significantly.
Key Takeaway
Match your fix to the bottleneck: GPU signals need rendering fixes; CPU signals need logic fixes.
