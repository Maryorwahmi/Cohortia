Definition

Open Session Frontend

Window → Developer Tools → Session Frontend → Profiler tab → Record while reproducing the issue.
Use the Profiler to select a frame and expand the CPU tree to see per-function and per-node timings. Filter by Blueprint to isolate Blueprint cost.
Why it helps
  • Records cost over time so you can inspect spikes.
  • Shows hierarchical breakdown to single nodes.
  • Helps verify whether a change actually reduced cost across frames.
Try this
Record a trace, find a frame with a spike, then expand the CPU tree and search for 'Blueprint' to find expensive nodes.
