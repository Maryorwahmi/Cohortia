Key Concepts
Performance
How efficiently the game uses CPU/GPU to maintain smooth FPS.
Frame Rate (FPS)
Primary visual indicator of smoothness; drives the need to profile.
CPU / GPU Bottlenecks
Use stat unit to tell which subsystem is the limiting factor.
stat Commands
stat fps, stat unit, stat game, stat rhi, and stat gpu for quick diagnostics.
Event Tick
Runs every frame; avoid heavy per-frame operations across many actors.
Session Frontend
Record traces and drill down to individual frame and Blueprint node timings.
Final takeaway
Use a fast-then-deep approach: quick stats to form a hypothesis, targeted fixes, then trace-level profiling to verify results.
