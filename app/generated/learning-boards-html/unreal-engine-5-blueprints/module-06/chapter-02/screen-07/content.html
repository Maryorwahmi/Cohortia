Definition

Event Tick behavior

Tick runs every frame. That causes per-frame logic to run frequently and can multiply cost across many actors.

Concrete example
Five environmental actors each run a sphere overlap check on Tick. At 60 FPS, that’s 300 overlap checks per second — expensive and unnecessary if checks can be less frequent.
Misconception
Tick is the simplest solution, but simple is not always efficient when scaled to many actors or expensive operations.
Alternatives
  • Use timers for periodic checks.
  • Use event-driven updates (overlap events, custom triggers).
  • Use Do Once or Do N to limit executions where appropriate.
Key Takeaway

Prefer timers or events for repeated work; reserve Tick for true per-frame needs like precise motion updates.
