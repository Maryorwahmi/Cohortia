Learning Objectives

Practical, verifiable skills: profile, diagnose, and reduce Blueprint cost.

01
Read frame rate and bottlenecks
Interpret FPS and the Game/Draw/GPU split to decide whether to inspect Blueprints or rendering.
VERIFIED COMPETENCY MILESTONE
02
Use console 'stat' commands
Run 'stat fps', 'stat unit', and 'stat game' while in PIE to gather immediate metrics.
VERIFIED COMPETENCY MILESTONE
03
Identify Blueprint hotspots
Spot patterns like frequent Event Tick work and expensive per-frame loops that inflate Game time.
VERIFIED COMPETENCY MILESTONE
04
Apply timers and loop optimizations
Replace per-frame checks with timers or events and reduce unnecessary loop iterations to lower CPU cost.
VERIFIED COMPETENCY MILESTONE
