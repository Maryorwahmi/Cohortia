Module 6 › Chapter 6.1 › AddScore Walkthrough
Pseudocode
Function AddScore(Amount:int)
{
  // Read current value
  NewScore = Score + Amount
  // Persist the change
  Set Score = NewScore
}
Watch Amount, Score before Set, and Score after Set while paused to see the exact change and confirm which node writes the new value.
Checklist while paused
  • Is Amount the expected value?
  • Does Score change at the Set node as expected?
  • Is AddScore invoked on the player's instance or a different actor?
Misconception
Seeing Score change in the Watch window proves the function ran, but does not prove the change persists if later nodes overwrite it.
