How to use it
Read from top to bottom to see the most recent call and the chain that preceded it. If the wrong event called your function, the call stack reveals that source. Combine this with Watch values to confirm parameter values at each level.
Multiple instances
Pick the correct Debug Object when many actors are present to match the stack to the right instance.
Recursion or repeats
Repeated function names in the stack indicate recursion or rapid calls — inspect parameters at each level.
