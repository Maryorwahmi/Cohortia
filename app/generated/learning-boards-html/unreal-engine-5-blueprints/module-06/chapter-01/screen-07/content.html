Module 6 › Chapter 6.1 › Stepping
Step modes
Step Into
Enter function internals to inspect node-by-node execution.
Step Over
Execute the node and skip into called functions, treating them as single steps.
Continue
Resume execution until the next breakpoint or the end of play.
Example walkthrough
// When paused at Cast node
Step Over -> executes the cast and moves to next node
Step Into -> if next node is a function call, enters that function so you can inspect internal nodes
Continue -> resumes runtime until another breakpoint
Watch the Score variable while you step. If it changes inside a function you Step Into, that tells you where the modification occurs and whether the calculation is correct.
