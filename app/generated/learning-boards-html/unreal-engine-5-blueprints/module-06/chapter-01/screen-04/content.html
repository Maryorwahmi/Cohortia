Module 6 › Chapter 6.1 › Print String
Definition
Print String outputs a message to the screen and Output Log when its execution pin fires. It is ideal for fast verification of event flow and variable values.
Concrete example
Print: "Overlap Detected: " + OtherActor->GetName()
Shows which actor overlapped so you can confirm the right actor triggers the logic.
Common mistake
Leaving Print String calls in shipped builds or using vague messages like "hit" that lack context.
Pro tip
Include the event name and key variable in the message so it is meaningful when it appears during playtests.
Code example
PrintString("Overlap Detected: " + OtherActor->GetName());
PrintString("Player Health: " + ToString(PlayerHealth));
These lines demonstrate concise messages that include context and values so you can tell when and why code ran.
Key Takeaway

Use Print String for targeted checks, but keep messages clear and remove them before shipping.
