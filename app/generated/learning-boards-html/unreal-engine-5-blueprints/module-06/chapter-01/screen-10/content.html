Module 6 › Chapter 6.1 › Scoring System Activity
Setup recap
  • Create BP_CollectableItem with Static Mesh and Sphere Collision set to OverlapAllDynamic.
  • Event ActorBeginOverlap -> Cast to BP_PlayerCharacter -> Call AddScore -> Destroy Actor.
  • BP_PlayerCharacter has integer Score and AddScore increments Score by Amount.
Debug steps
  1. Add Print String after overlap: "Overlap Detected: " + OtherActor->GetName().
  2. Toggle breakpoint on Cast To BP_PlayerCharacter and play.
  3. When paused, Step Over or Step Into AddScore and watch Score change in Watch window.
Scenario check
If Print String shows an AI pawn, your cast will fail. The fix is to check collision filters or compare class types before casting.
Reflection
Which node would you breakpoint first if the item never destroys after a successful cast? Consider where control might skip the Destroy Actor call.
