Module 6 › Chapter 6.1 › Key Concepts
Print String
Quick on-screen messages to confirm events and variable values during runtime.
Breakpoint
A marker that pauses execution at the chosen node so you can inspect state and step through logic.
Watch Window
Displays live values of variables and pins while the debugger is paused for precise inspection.
Summary

Combine these concepts into a repeatable loop: use Print String to narrow, break where suspected, step to inspect, and watch variables to confirm fixes.
