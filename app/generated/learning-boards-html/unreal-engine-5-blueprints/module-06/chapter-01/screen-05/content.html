Module 6 › Chapter 6.1 › Blueprint Debugger
Debugger panels
  • Call Stack: Sequence of active functions and events leading to the current node.
  • Watch Window: Live variable and pin values for the selected debug object.
  • Graph view: The Blueprint with the currently executing node highlighted when paused.
Using Debug Object
When multiple actors are present, select the instance to inspect from the Debug Object dropdown so your Watch values and graph context match the running instance.
Step sequence
Step Into
Enter a function or macro to inspect internal nodes line-by-line.
Step Over
Execute the node and treat called functions as a single step to move quickly.
Continue
Resume normal execution until the next breakpoint or end of play.
Misconception

The debugger is only for engine-level problems. In fact it is your primary tool for everyday Blueprint logic inspection.
