Module 6 › Chapter 6.4 › Initialize Git
Terminal steps
cd C:\UnrealProjects\MyAwesomeGame
git init
# create .gitignore with Unreal entries
git add .
git commit -m "Initial project setup and basic level created"
  • Confirm location: check that your .uproject file is in the current directory before running git init.
  • Create .gitignore before adding files so generated files remain untracked.
  • Use clear commit messages describing the snapshot.
Example
You initialize in MyAwesomeGame, add a minimal .gitignore, then commit. Running git log shows your initial commit and commit message. If you later create a new Blueprint and commit it, you'll see both snapshots in the history.
Key Takeaway

Initialize at the .uproject root, create .gitignore, then add and commit to capture a clean baseline.
