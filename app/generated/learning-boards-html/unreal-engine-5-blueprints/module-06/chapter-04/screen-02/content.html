How you'll practice
A terminal-first walkthrough will guide you through initializing a repo, adding a .gitignore, making two commits — initial and adding a Blueprint — and viewing the commit history. You'll simulate collaboration by pulling changes and practicing a simple branch/merge flow.
Terminal Demo: git init, git add, git commit
.gitignore: exclude Binaries, DerivedDataCache, Saved
Branching: feature branches and merging back
