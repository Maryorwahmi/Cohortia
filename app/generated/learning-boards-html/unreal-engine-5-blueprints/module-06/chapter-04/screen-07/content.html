If you added generated files before creating .gitignore, remove them from tracking with git rm --cached and commit that removal. The file keeps your repository fast and reduces conflict frequency.
Common mistake
Committing Binaries or Intermediate folders before ignoring them. This bloat is hard to undo and slows clones and operations.
Action
Create .gitignore first, then git add and git commit. If you must remove tracked generated files, use git rm --cached <file> and commit the removal.
