Module 6 › Chapter 6.4 › Staging & Committing
Terminal example
git status
# see new file: Content/Blueprints/BP_Door.uasset

git add Content/Blueprints/BP_Door.uasset

git commit -m "Add BP_Door actor with StaticMesh component"

git log --oneline
  • Run git status frequently to review what will be committed.
  • Prefer staging specific files to keep commits focused and reversible.
  • Close Unreal Editor before committing .uasset files to avoid partial writes.
Example card
You add a door Blueprint and commit it. Later, if the door breaks, check git log to find the commit and use git revert or checkout to restore a working version.
Key Takeaway

Stage intentionally and commit small, descriptive changes to maintain a useful history.
