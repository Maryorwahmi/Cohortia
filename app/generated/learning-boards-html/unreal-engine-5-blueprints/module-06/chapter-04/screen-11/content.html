Module 6 › Chapter 6.4 › Branch & Merge
Commands example
git branch feature/new-ability
git checkout feature/new-ability
# do work, commit frequently
git checkout master
git merge feature/new-ability
  • Keep feature branches focused and short-lived.
  • Use descriptive branch names related to the task or ticket.
  • Resolve conflicts deliberately and communicate when binaries are involved.
Conflict note
Binary merges are not automatic. If two people edit the same .uasset, you will typically choose one version and potentially lose the other unless external merging tools are applied.
Why it matters

Branches enable safe experimentation and code review without destabilizing the main branch.
