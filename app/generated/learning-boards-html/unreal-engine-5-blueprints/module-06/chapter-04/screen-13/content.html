Module 6 › Chapter 6.4 › Hands-on Activity
Terminal walkthrough
# in project root
git init
# create .gitignore with Unreal entries
git add .
git commit -m "Initial project setup and basic level created"

# after creating BP_Door and closing editor
git status
git add Content/Blueprints/BP_Door.uasset
git commit -m "Added BP_Door actor"

git log --oneline
This hands-on sequence helps you confirm that commits appear in history and that your .gitignore prevented generated files from being tracked.
Checkpoints
  • Confirm .gitignore is present and working with git status.
  • Commit messages describe intent clearly.
  • git log shows both the initial and the Blueprint commits.
Key Takeaway

A reproducible terminal workflow builds confidence and a reliable project history.
