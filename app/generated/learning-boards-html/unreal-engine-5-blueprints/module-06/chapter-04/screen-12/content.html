Why merges fail for binaries

Text can merge because differences can be combined line by line. Binary formats are opaque, so automatic merging is impossible. When Git flags a conflict on a .uasset, you will typically pick one version: "take theirs" or "take yours." That choice can lose work if not coordinated.

  • Coordinate edits via tasks or communication to avoid overlapping work on binaries.
  • Use file locking where available to prevent simultaneous edits.
  • Before resolving, export or copy any unique data you want to preserve if possible.
Practical options
Use Git LFS locking, switch to Perforce for enterprise locking, or simply organize tasks so only one person edits a given binary at a time.
Common mistake

Attempting to auto-merge binaries or editing .uasset files while the editor is open can create corrupt or partial files.
