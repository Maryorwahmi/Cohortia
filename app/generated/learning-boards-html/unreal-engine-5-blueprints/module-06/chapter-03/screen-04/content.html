Module 6 › Chapter 6.3 › Data Structures
Definition
Arrays
Ordered list, efficient indexed access and iteration. Good for sequential processing and maintaining order-sensitive collections.
Common mistake
Using an Array to find elements by ID every frame instead of using a Map.
Key Takeaway

Arrays are fast for indexing and iteration; avoid repeated full scans for key lookups.

Maps (Key-Value)
Store items by unique ID for constant-time lookups. Ideal for inventory systems or lookup tables accessed directly by key.
Example Blueprint pseudocode
// MyItemDataMap (Map<FName, FMyItemStruct>) // Get (Key: ItemID_To_Find) // -> Returns FMyItemStruct (very fast lookup) // Array usage: // ForEachLoop (InventoryArray) // -> Branch (If Item.ID == ItemID_To_Find) // -> Return Item (linear scan)
