BP_Projectile: ReturnToPool
Replace Destroy Actor with a custom event that hides, disables collision and tick, deactivates movement, and resets state values like velocity and damage.
Pseudo-Blueprint
// Custom Event: ReturnToPool // Set Actor Hidden In Game (True) // Set Actor Enable Collision (False) // Set Actor Tick Enabled (False) // Deactivate Projectile Movement // Reset state variables (Damage, OwnerID, Velocity)
Spawner changes
In BP_PlayerCharacter, call GetPooledProjectile from the pool manager instead of Spawn Actor From Class. Then set location/rotation and activate movement.
Test checklist
  • Log actor pointers to confirm reuse.
  • Observe profiler for reduced spikes.
  • Verify no lingering visual or gameplay state between uses.
