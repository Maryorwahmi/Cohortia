Common Pitfalls › Event & Update Misuse
Unnecessary Per-frame Work
Only run logic each frame when absolutely required. Use events or OnRep notifications for state-driven updates.
Example
UI health should update on health change notifications, not every tick.
Overused Event Dispatchers
Many listeners on a frequently fired event multiply CPU usage. Unbind listeners and batch events when possible.
Mitigation
Use a manager to emit aggregated updates or throttle event frequency to reduce listener invocations.
