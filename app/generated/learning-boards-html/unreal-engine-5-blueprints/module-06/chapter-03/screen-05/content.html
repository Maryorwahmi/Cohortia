Module 6 › Chapter 6.3 › Arrays vs Maps
Array Scenario
Ordered UI lists or frame-by-frame iteration
  • Fast indexed access and iteration with For Each Loop.
  • Inserts/removals can be costly in large arrays due to shifting.
  • Use swap-remove patterns if order is not required.
Example: scrolling inventory UI backed by an Array for stable order.
Map Scenario
Keyed lookups like ItemID retrieval
  • Constant-time lookup by key — ideal for per-event retrievals.
  • Keep keys stable and simple, such as FName IDs.
  • Combine with Data Tables to populate Map data at load time.
Example: Map<FName, FItemDataStruct> to get item properties immediately when an ID is known.
