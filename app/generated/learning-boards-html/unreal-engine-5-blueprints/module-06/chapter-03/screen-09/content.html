Core Decision › C++ Integration
When to consider C++
  • Identified hotspot that consumes significant CPU time.
  • Heavy numerical computations or tight loops.
  • Repeated allocations from Blueprint that cannot be avoided.
Expose focused native functions to Blueprints and keep designer-facing APIs simple.
Pitfalls & Misconceptions
Avoid porting without profiling, and avoid rewriting high-level orchestration code that benefits from Blueprint iteration speed.
Practical approach
Profile, isolate the inner loop, implement a small native function, expose it, and validate improvement with before-and-after traces.
