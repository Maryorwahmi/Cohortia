01 Implement & Compare
Build an Array and a Map
Practice: Create an inventory stored as a Map keyed by ItemID. Compare iteration cost by simulating 1,000 lookups and observing profiler trends. Mnemonic: Venn shows lookup vs order.
02 Pooling Lab
Pre-populate and reuse projectiles
Practice: Create BP_ProjectilePoolManager, pre-spawn 10 projectiles on BeginPlay, and implement GetPooledProjectile and ReturnToPool events. Mnemonic: timeline shows allocate once, reuse many.
03 Profiling & Porting
Measure before you port to C++
Practice: Use stat game to find hot Blueprint functions, and if justified, implement the heavy computation in C++ and expose a wrapper to Blueprints. Mnemonic: profiler icon = evidence-based decisions.
04 Architecture Checks
Make updates event-driven
Practice: Move per-frame logic into components and trigger updates via events. Unbind event dispatchers when actors destroy to avoid leaks. Mnemonic: stacked blocks = modular components.
