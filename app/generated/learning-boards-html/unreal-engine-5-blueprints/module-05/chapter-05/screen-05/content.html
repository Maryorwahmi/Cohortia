Create Blackboard & Keys

A few quick steps produce a reusable memory asset for your AI.

Steps
  1. Create a Blackboard asset in Content Browser and name it BB_EnemyAI.
  2. Add keys: Vector TargetLocation, Object TargetActor (Base Class: Character), optional Boolean IsPlayerDetected.
  3. Open Behavior Tree, select Root, set Blackboard Asset to BB_EnemyAI in Details.
  4. Verify keys appear in decorator and task property dropdowns.
Pro tip

Use descriptive names and set Base Class for Object keys to minimize casting and runtime checks.

Example key configuration
TargetActor — Object (Base: Character)
Holds the player reference for Move To (TargetActor).
TargetLocation — Vector
Holds a world position for Move To tasks that use coordinates instead of actor refs.
Why it matters

Correct keys let tasks and decorators read the precise type they expect, reducing runtime errors and simplifying behavior logic.
