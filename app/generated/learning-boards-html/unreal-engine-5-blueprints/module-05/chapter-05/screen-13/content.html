Assessment Idea

Remember Last Known Location

Design a Blackboard key and a task to persist where the player was last seen, then use it to investigate.

Implementation outline
  1. Add Vector key: LastKnownPlayerLocation to BB_EnemyAI.
  2. Create BTT_UpdateLastKnownPlayerLocation: Get Player Character → Get Actor Location → Set Blackboard Value as Vector → Finish Execute.
  3. Run this task when the player is visible; when not visible check LastKnownPlayerLocation Is Set and Move To that vector.
Evaluation

Test a scenario where the player appears and then hides. Confirm the AI uses LastKnownPlayerLocation to investigate, then clears the key or resumes patrol when nothing is found.

Key Takeaway

Persisting last known vectors makes behavior realistic and gives you a clear hook for investigation logic.
