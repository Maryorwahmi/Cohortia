Finish Execute and stalls

Why tasks hang and how to fix them.

Problem

A custom task runs but the Behavior Tree never moves on because Finish Execute was not called or execution took too long synchronously.

Diagnosis steps
  • Add print or log at the start and before Finish Execute.
  • Check for branches that skip Finish Execute on error conditions.
  • Ensure no blocking loops or waits are performed synchronously.
Solution patterns
  1. Use timers or Delays and call Finish Execute when the timer fires.
  2. Use a running state and handle completion in Event Tick or callbacks.
  3. Keep short, synchronous tasks simple and call Finish Execute immediately after updates.
Key Takeaway

Every BTTask must explicitly call Finish Execute to allow the tree to progress; plan for long work using timers or running-state patterns.
