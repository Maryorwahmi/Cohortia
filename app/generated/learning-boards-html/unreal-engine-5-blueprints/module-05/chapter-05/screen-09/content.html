Hands-on Activity

Extend Patrol to Chase

Step-by-step instructions you can follow in the Editor.

Setup
  1. Create BB_EnemyAI with TargetLocation (Vector) and TargetActor (Object).
  2. Set BB_EnemyAI in BT_ThreePointPatrol Root Blackboard Asset.
Custom Task
  1. Create Blueprint class BTTask_BlueprintBase → BTT_FindPlayerAndSetBlackboard.
  2. Override Receive Execute AI and set the Blackboard keys, then Finish Execute.
Behavior Tree
  1. Add chase Sequence as first child of Selector with Blackboard decorator TargetActor Is Set.
  2. Insert BTT_FindPlayerAndSetBlackboard and Move To(TargetActor) inside that Sequence.
Quick test steps
  • In AI Controller Event BeginPlay, after Run Behavior Tree add Delay(2s), then Set Blackboard Value as Object to Get Player Character for testing.
  • Play in Editor and open the Behavior Tree debugger to watch keys update.
If the AI doesn't chase

Check that BB_EnemyAI is attached to the Behavior Tree, confirm TargetActor is being set, and ensure Finish Execute runs in your task.

Key Takeaway

Break the problem into asset setup, task logic, and Behavior Tree wiring, testing each piece in PIE to isolate errors quickly.
