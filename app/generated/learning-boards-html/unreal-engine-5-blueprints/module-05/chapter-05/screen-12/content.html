Testing & Debugging

Inspect Blackboard in PIE

Use the Behavior Tree and Blackboard debugger and simple logs to confirm runtime behavior.

Verify steps
  • Run PIE and open the Behavior Tree debugger.
  • Observe Blackboard keys for the AI instance to see values change.
  • Add prints at the start and end of Receive Execute AI to confirm Finish Execute.
Temporary test trick

In AI Controller Event BeginPlay add Delay(2s) and then Set Blackboard Value as Object to Get Player Character so you can see chase immediately for debugging.

Key Takeaway

The Blackboard debugger reveals the exact values your tasks set. Use it early and often to narrow where a behavioral bug originates.
