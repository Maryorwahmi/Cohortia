Architecture

Selector → Sequence pattern

Use a selector to choose chase first and patrol second, gated by a Blackboard decorator.

Structure
  1. Root → Selector
  2. Selector child 1 → Sequence (Chase)
    • Blackboard Decorator: TargetActor Is Set
    • Task: BTT_FindPlayer (updates keys)
    • Task: Move To (TargetActor)
  3. Selector child 2 → Sequence (Patrol) — original patrol logic
Decorator details

Use a Blackboard decorator on the chase Sequence with Key Query set to Is Set. This ensures the whole chase pipeline runs only when there is a valid TargetActor.

Why gate the sequence

Gating the sequence avoids partially executing chase logic and ensures Move To always has the data it needs.

Key Takeaway

Selectors plus Blackboard decorators provide a clear, testable priority system for AI behaviors.
