Core Concept What is the Blackboard?

Blackboard as shared memory

An asset with typed keys that Behavior Trees and Blueprints use to share state.

Definition

A Blackboard is an asset containing keys. It is intended for transient, per-controller memory used during decision making, not for permanent game state.

Example
Create BB_EnemyAI with TargetActor (Object) and TargetLocation (Vector). The perception system sets TargetActor; a custom task writes TargetLocation so Move To can use it.
Misconception

Do not use the Blackboard as a global variable store for game state. Keep it scoped and typed to avoid coupling and debugging headaches.

Key Takeaway

Blackboards let separate systems communicate with typed facts, making AI modular and testable.

Blackboard Keys (snapshot)
TargetActor — Object
Holds a reference to the player or other actors. Use an Object key with an appropriate Base Class such as Character to avoid cast errors.
TargetLocation — Vector
Stores a world position that Move To tasks can consume. Vectors are for positions and directions.
Try this
Create the Blackboard asset in the Content Browser and add the two keys above. Attach it to your Behavior Tree's Root node to make keys available.
