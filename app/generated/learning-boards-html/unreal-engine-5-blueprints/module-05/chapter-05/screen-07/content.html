Blackboard Key Types

Select types to match the data you will read or write.

Vector

Use for positions like TargetLocation or LastKnownPlayerLocation. Move To can consume this directly.

Object

Use for actor references like TargetActor. When you need to call functions on the actor, use Object keys and cast appropriately.

Boolean

Use for flags like IsPlayerDetected to gate Behavior Tree sequences using Blackboard decorators.

Name

Use for small labels such as CurrentState when you need simple named states without an enum.

Example

Move To (TargetActor) expects an object actor ref; Move To (TargetLocation) expects a vector. Pick the node that matches your key type.

Quick test

Attempting Set Blackboard Value as Vector on an Object key will fail or be ignored. Match types in the editor dropdowns.
