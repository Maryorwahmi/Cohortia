Module 5 › Chapter 5.3 › Declare & Call Dispatcher
Blueprint pseudocode
// In Player Character Blueprint
Variable: CurrentHealth : Float = 100.0
Variable: MaxHealth : Float = 100.0
Event Dispatcher: OnHealthChanged(NewHealth : Float)

Custom Event: TakeDamage(DamageAmount : Float)
  NewHealth = CurrentHealth - DamageAmount
  NewHealth = FMax(NewHealth, 0.0)
  Set CurrentHealth = NewHealth
  // Notify listeners
  Call OnHealthChanged(NewHealth)
Note: FMax ensures health doesn’t go below zero.
Implementation tips
  • Keep the dispatcher parameter and bound event parameter types identical.
  • Call the dispatcher from every code path that changes health.
  • For debugging, connect Cast Failed or binding mismatches to a Print String during development.
