Module 5 › Chapter 5.3 › Key Concepts
Event Dispatchers
Broadcast changes so any number of widgets can update without modifying the source.
Blueprint Interfaces
Define a shared contract so widgets can call functions on many actor types without casting to each one.
Direct Reference
Fast setup for single-class uses, but beware tight coupling and cast failures.
Summary takeaway
Prefer event-driven updates and design for listeners. This keeps your UI flexible and easy to extend.
