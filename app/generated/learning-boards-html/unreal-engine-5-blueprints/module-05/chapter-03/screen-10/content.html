Module 5 › Chapter 5.3 › Damage → UI update
Sequence
  1. TakeDamage reduces CurrentHealth and clamps to 0.
  2. Call OnHealthChanged(NewHealth) on the Player Character.
  3. All bound widgets receive NewHealth and run their Update event.
  4. Widgets compute percent and set ProgressBar and Text.
This structure makes adding new listeners trivial. The character doesn’t change when the number of widgets grows.
Check your assumptions
  • Are all health changes calling the dispatcher?
  • Is the widget bound in Event Construct and initialized once?
  • Have you handled cases where Cast Failed occurs?
