Module 5 › Chapter 5.3 › Blueprint Interfaces
How it works
Define an interface with functions like GetHealth. Implement it on actors. Call interface functions without casting to specific classes.
Example: BPI_Damageable exposes GetHealth. Both player and enemy implement it so the same widget can query either.
When to use
  • When many actor types share behavior.
  • When you need function calls rather than broadcast notifications.
  • To reduce class-specific casts and centralize contracts.
