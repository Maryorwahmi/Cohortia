Module 5 › Chapter 5.3 › Bind Dispatcher in Widget
Widget layout
Progress Bar: HealthProgressBar. Text Block: HealthValueText. Bind in Event Construct so listeners are active as soon as the widget appears.
// In WBP_HealthBar Event Graph
Event Construct
  Get Player Character
  Cast To YourPlayerCharacter (As CharacterRef)
  Bind Event to OnHealthChanged (Target: As CharacterRef)
    Event: Create Custom Event -> UpdateHealthBar(NewHealth : Float)

Custom Event: UpdateHealthBar(NewHealth : Float)
  Percent = NewHealth / CharacterRef.MaxHealth
  HealthProgressBar.SetPercent(Percent)
  HealthValueText.SetText( "Health: " + NewHealth ToText + "/" + CharacterRef.MaxHealth ToText )

// After binding, call UpdateHealthBar(CharacterRef.CurrentHealth) to initialize
Pitfalls & fixes
  • Divide by MaxHealth to convert to 0–1 percent.
  • Always call the update once after binding to prevent initial stale UI.
  • Handle Cast Failed to avoid runtime silence in different game contexts.
