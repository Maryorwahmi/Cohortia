Module 5 › Chapter 5.3 › Event Dispatchers — how they work
Three steps
  1. Declare dispatcher on the data owner, e.g. OnHealthChanged(Float NewHealth).
  2. Call the dispatcher after changing state: Call OnHealthChanged(NewHealth).
  3. Bind listener in widgets: Bind Event to OnHealthChanged → custom event updates UI.
Tip: After binding, call the update once to ensure the UI is initialized with current values rather than waiting for the next change.
Concrete example
Player Character defines OnHealthChanged(CurrentHealth: Float). On TakeDamage, Set CurrentHealth then Call OnHealthChanged(CurrentHealth). Any bound widget receives CurrentHealth and updates percent and text.
