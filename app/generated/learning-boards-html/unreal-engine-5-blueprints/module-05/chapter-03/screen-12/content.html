Module 5 › Chapter 5.3 › Choosing the right method
Direct Reference
Use for simple single-class widgets. Fast but tightly coupled.
Blueprint Interface
Use when many types implement the same behavior. Promotes reusability and loose coupling.
Event Dispatcher
Use for broadcast updates from a state owner to many listeners with minimal dependencies.
Decision checklist
  • Will multiple actor classes provide the same data? Use Interfaces.
  • Will many widgets listen to one source? Use Dispatchers.
  • Is this a one-off prototype? Direct reference may be fine short term.
