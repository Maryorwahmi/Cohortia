Module 5 › Chapter 5.3 › Create & Display Widget
BeginPlay flow
Event BeginPlay → Create Widget (WBP_HealthBar) → Add to Viewport. Widgets bind in their own Event Construct handlers.
Recommendation: avoid storing widget references unless the character must call widget methods. Let the dispatcher deliver updates instead.
Visibility & multiplayer
Ensure Create Widget and Add to Viewport run on the owning client. Creating UI on server or wrong client can lead to invisible or wrong behavior.
Pro tip

Call the widget’s update once after binding so any UI built later shows the correct starting state.
