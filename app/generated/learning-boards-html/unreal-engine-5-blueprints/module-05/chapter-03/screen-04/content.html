Module 5 › Chapter 5.3 › Why dynamic UI matters
What dynamic UI is
A system where widgets update in response to game state changes, keeping visuals accurate and responsive without unnecessary polling.
Example: Health bar updates when damage is applied, not by reading health every frame.
Misconception: Events are harder than polling. Truth: Events reduce repeated wiring and improve maintainability.
Why it matters: Performance, clarity, and easier addition of new listeners later.
Key Takeaway

Choose events for infrequent or important changes; avoid Event Tick when events suffice.

Scenario
Imagine you have a score that increases only when an enemy is defeated. Using a dispatcher from Game Mode to broadcast the new score lets any score widget update without modifying Game Mode for each new widget.
