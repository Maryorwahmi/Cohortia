Module 5 › Chapter 5.3 › Common mistakes
Frequent issues
  • Uncaught Cast Failed: add debug prints and fallbacks.
  • Using Event Tick instead of events: leads to wasted CPU and complex logic.
  • Forgetting an initial update after binding: UI shows old values until next change.
  • Parameter signature mismatches between dispatcher and listener.
Debugging tips
Use Print String during development, test all paths that change state, and add safe guards so widgets gracefully handle missing references.
Common mistake

Not clamping health or dividing by MaxHealth before calling Set Percent will produce incorrect progress values.
