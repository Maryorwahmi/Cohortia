Module 5 › Chapter 5.3 › Direct References and Casting
Pattern
Get Player Character → Cast To YourCharacter → Access variable or function.
Example
In Event Construct, cast to ThirdPersonCharacter and Get CurrentHealth to set ProgressBar value.
Common mistake
Using Event Tick to poll health with repeated casts. This wastes CPU and is unnecessary when health changes are event-driven.
Pros vs Cons
Pros
  • Simple to set up
  • Good for one-off widgets
Cons
  • Tight coupling
  • Breaks with class/variable renames
Safety tip: Always wire Cast Failed to a Print or fallback so you can detect mismatches during testing.
