Practical milestones

Use these checks as you implement Blueprints and Behavior Trees.

01
Controller assignment
Verify the Pawn's AI Controller Class is set so it will be automatically possessed by your AI Controller Blueprint.
VERIFIED COMPETENCY MILESTONE
02
Nav Mesh coverage
Ensure Nav Mesh Bounds Volume covers patrol points so Move To can find valid paths; press P to visualize in-editor.
VERIFIED COMPETENCY MILESTONE
03
Behavior Tree debug
Use the Behavior Tree editor's debug dropdown and AI debug drawing to see active nodes and failures in real time.
VERIFIED COMPETENCY MILESTONE
04
Start simple
Build a two-point patrol first. Confirm Run Behavior Tree runs from Event BeginPlay before adding complexity like chase or combat.
VERIFIED COMPETENCY MILESTONE
