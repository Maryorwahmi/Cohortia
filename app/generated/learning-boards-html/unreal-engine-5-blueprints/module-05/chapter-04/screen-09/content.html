Code Walkthrough

Event BeginPlay → Run Behavior Tree

This wiring ensures the controller starts the Behavior Tree as soon as the Pawn is in play. It is the runtime bridge between Blueprint and behavior asset.

Checks
  • Run Behavior Tree node has the correct Behavior Tree asset selected.
  • Event BeginPlay executes — use a short print string to confirm.
  • Pawn's AI Controller Class matches the controller you edited.
Pseudo visual
Event BeginPlay
  -> Run Behavior Tree (BT_Patrol)
Troubleshooting
If the pawn is idle, check controller assignment, confirm the behavior tree has a Root and children, and verify Nav Mesh coverage for Move To tasks.
Key Takeaway

Run Behavior Tree from BeginPlay so behaviors start automatically. Verify assignment and in-editor debug if it does not run.
