Definition

Move To and Wait tasks

Tasks are leaf nodes that perform actions. Move To navigates via Nav Mesh, Wait pauses execution for a duration.

Configuration tips
  • Set Move To's Blackboard Key to Target Actor for reusable points.
  • Use Use Target Location and a Vector for quick tests.
  • Set Wait Time short during iteration, then tune for gameplay.
Concrete scenario
A patrol sequence: Move To PatrolPoint_A (Blackboard Target) → Wait 3s → Move To PatrolPoint_B → Wait 3s. Verify Nav Mesh covers points so Move To can compute a path.
Common mistake
Expecting Move To to teleport or ignoring Nav Mesh coverage. Move To uses pathfinding and will fail when navigation isn't available.
Key Takeaway

Tasks perform real-world actions. Configure Move To targets and ensure navigation exists; use Wait to space actions over time.
