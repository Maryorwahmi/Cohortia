Process Flow

Create AI Controller and Pawn

Follow these concrete steps so each part can be tested independently before wiring behavior.

Step 1 — New AIController
Create Blueprint Class → AIController. Name it BP_PatrolController. This will run the Behavior Tree.
Step 2 — New Character Pawn
Create Blueprint Class → Character. Name it BP_PatrolBot. Add a Static Mesh for visibility and ensure a movement component exists.
Step 3 — Assign Controller
In the Pawn's Details under Pawn → AI Controller Class, select BP_PatrolController so placed Pawns are possessed automatically.
Example
Create BP_PatrolController and BP_PatrolBot, place the bot in the level, and confirm it shows the chosen Static Mesh and that movement components are present.
Common mistake
Forgetting to add a movement component or leaving AI Controller Class unset are the most frequent causes of an idle Pawn.
Key Takeaway

Create controller and pawn separately, assign the controller on the pawn, and test the pawn's visibility and movement before adding behavior logic.
