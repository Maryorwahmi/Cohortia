Process Flow

Three-point patrol activity

Place three TargetPoint actors and reference them via a Blackboard key in Move To tasks to create a reusable patrol Behavior Tree.

Steps
  1. Create PatrolPoint_A/B/C in the level.
  2. Use Move To tasks with Blackboard Key Target Actor and assign each TargetPoint.
  3. Run Behavior Tree from the controller's BeginPlay and verify Nav Mesh coverage.
Example sequence
Sequence:
  Move To (TargetActor = PatrolPoint_A)
  Wait 2.0s
  Move To (TargetActor = PatrolPoint_B)
  Wait 2.0s
  Move To (TargetActor = PatrolPoint_C)
  Wait 2.0s
Checks
Confirm each Move To has the intended TargetPoint assigned and that Nav Mesh covers the entire path.
Key Takeaway

Blackboards let behavior trees reference level actors so the same tree can be reused with different patrol points per level.
