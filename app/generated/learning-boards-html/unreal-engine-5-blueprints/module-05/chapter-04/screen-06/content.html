Comparison

Selector vs Sequence

Selector picks the first child that succeeds. Sequence requires each child to succeed in order. Use accordingly for priority or ordered actions.

Selector example
Try chase player; if not, try flee; otherwise patrol. As soon as chase works, selector stops further checks.
Sequence example
Move To patrol point A → Wait 3s → Move To patrol point B → Wait 3s. Failure of Move To aborts the rest.
Visual mnemonic
Selector: a funnel that accepts the first successful flow. Sequence: a chain where each link must hold or the chain breaks.
Design tip
Order children intentionally: highest priority leftmost for Selectors, required order left-to-right for Sequences. Test long-running tasks for interruption behavior.
Misconception check

Selector does not try later children after one succeeds; it short-circuits. Design priorities accordingly.
