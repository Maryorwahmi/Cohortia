Process Flow

Author BT_Patrol

Create Root, add Selector, add Sequence, chain Move To and Wait tasks for each patrol point. Use TargetPoint actors or fixed vectors while testing.

Design notes
  • Use Selector to reserve space for alternate behaviors later.
  • Prefer TargetPoint actors for reusable patrol points across levels.
  • Keep Wait durations short for quicker iteration.
Quick visual outline
[Root]
  |
  V
[Selector]
  |
  V
[Sequence]
  |--> Move To (Point A)
  |--> Wait (3.0s)
  |--> Move To (Point B)
  |--> Wait (3.0s)
Example detail
Set Move To's Blackboard Key to Target Actor when using TargetPoint actors. For quick tests, check Use Target Location and enter a Vector coordinate.
Pro tip

Start with two points then add a third; this helps spot pathfinding issues early.
