Process Flow

Debugging checklist

Follow a consistent checklist when AI doesn't behave: controller, BeginPlay, Nav Mesh, movement components, and simplified tests.

Checklist
  • AI Controller Class assigned on the Pawn.
  • Run Behavior Tree selected in BeginPlay.
  • Nav Mesh Bounds Volume covers movement area (press P to view).
  • Pawn has Character Movement or similar component.
Simplify to isolate
Test a single Move To with a fixed vector to see if pathfinding and movement work before restoring complex sequences.
Editor tools
Use Behavior Tree debug and AI debug drawing in the viewport to follow node execution and see why a branch failed in real time.
Common fixes
Assign controller, select Behavior Tree in Run Behavior Tree, scale Nav Mesh Bounds, or add a movement component. Each fix addresses a frequent root cause.
Key Takeaway

A reliable checklist and the Behavior Tree debug tools are your fastest path to finding why an AI is not running its behavior.
