Definition

Decorators as guards

Decorators test conditions and allow or prevent branches from running. They can abort running tasks when conditions change which makes behavior reactive.

Examples
  • Has Line of Sight decorator prevents attack when the player isn’t visible.
  • Blackboard check decorator ensures a Target Actor is set before Move To runs.
  • Health threshold decorator chooses flee when below a value.
Behavior note
Decorators can be set to abort running branches, so design them with the possibility of mid-task interruptions in mind.
Design tip
Keep decorator checks cheap and clear. Use blackboard-driven decorators for flexible, level-specific conditions.
Misconception check

Decorators do more than one-time checks; many continuously evaluate and can interrupt tasks when their condition changes.
