Core Concept

Slider properties explained

Min, Max, Step Size and Default Value determine the slider’s numeric behavior. Align these to the system that consumes the value.

Example: SpeedSlider

Min: 100.0, Max: 1000.0, Default: 500.0. These values map directly to Set Max Walk Speed without further scaling.

Step Size choice

Choose integer steps for coarse control, or small fractional steps for smooth adjustments like audio volume.

Pitfall

OnValueChanged fires continuously. If your handler does expensive work each tick, you may see performance issues; consider throttling updates.

Key Takeaway

Match slider ranges to the consumer so values pass directly without risky conversions; test for performance when OnValueChanged fires rapidly.
