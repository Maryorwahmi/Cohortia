Module 5 › Chapter 5.2 › Events vs Bindings

Events

OnClicked and OnValueChanged execute blueprint logic. Use them for actions that change gameplay state or require control flow.

When to use
  • Start or quit gameplay
  • Apply slider values to actors or systems
  • Run heavy logic but consider debouncing

Bindings

Bindings return values used directly by widget properties. Use them for displaying values, visibility flags, or color states.

When to use
  • Show slider values as text
  • Bind visibility to game state
  • Avoid heavy work inside bindings
Key Takeaway

Events change state; bindings reflect state. Keep responsibilities separate for maintainability.
