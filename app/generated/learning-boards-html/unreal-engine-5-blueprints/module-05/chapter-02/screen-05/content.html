Process

OnClicked event flow

Create the OnClicked node, attach a Print String for verification, then chain to the action you require, like Open Level.

Quick code-style walkthrough (visual pseudocode)
// In WBP_MainMenu's Event Graph
// OnClicked (StartGameButton)
// |
// V
// Print String (In String: "Start Game button clicked!")
// |
// V
// Open Level (Level Name: "YourGameLevel")
Example

StartGameButton uses OnClicked to Print String and then Open Level. Print String confirms wiring before potentially destructive actions.

Safety tip

For quitting or restarting, show a confirmation dialog widget instead of immediately calling Open Level or Quit Game.

Key Takeaway

Always verify OnClicked with a Print String before chaining to level loads or irreversible actions.
