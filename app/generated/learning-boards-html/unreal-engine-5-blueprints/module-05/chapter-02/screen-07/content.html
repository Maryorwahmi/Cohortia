Process Flow

Apply Slider Value to Gameplay

OnValueChanged gives you the float Value to pass to any actor property such as light Intensity or character speed.

Step-by-step
  1. Create OnValueChanged for SpeedSlider.
  2. Get Player Character and cast if needed.
  3. From Character Movement call Set Max Walk Speed and plug in Value.
  4. Play and verify handling of continuous events.
Concrete example

If Value is 600, Set Max Walk Speed receives 600 and the character moves with that max speed. No conversion needed if ranges were chosen correctly.

Pro tip

If updates are expensive, stage the value in a variable and apply it on a short timer or on release to prevent stutter.
