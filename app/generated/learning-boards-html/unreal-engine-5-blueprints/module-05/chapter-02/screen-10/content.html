Architecture

Patterns for widget to game communication

Direct call, custom event, or controller mediated messaging each have trade-offs between simplicity and decoupling.

Direct mapping

Widget gets Player Character → cast to MyCharacter → Get Character Movement → Set Max Walk Speed(Value). Straightforward for single-player setups.

Event-based

Widget fires a custom event or calls a controller function. The character subscribes or the controller forwards the value. Better for decoupling and tests.

Key Takeaway

Keep UI logic in widgets and gameplay logic in actors/controllers. Use events for cleaner separation.
