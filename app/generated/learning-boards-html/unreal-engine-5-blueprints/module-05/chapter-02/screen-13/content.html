Build WBP_InGameMenu

Stepwise instructions to assemble and test the menu widget with a Quit button and a speed slider.

Design
  1. Create WBP_InGameMenu, add Canvas Panel.
  2. Add QuitButton with Text Block child labeled "Quit Game".
  3. Add SpeedSlider; set Min 100, Max 1000, Default 500.
  4. Add SpeedValueText above SpeedSlider.
Implementation
  1. OnClicked(QuitButton) → Print String("Quit button pressed!") → Quit Game (optional).
  2. OnValueChanged(SpeedSlider) → Get Player Character → Get Character Movement → Set Max Walk Speed(Value).
  3. Bind SpeedValueText.Text to return "Speed: " + ToText(Get Value).
Test checklist
  • Confirm Print String appears on button press.
  • Confirm player speed updates as you move the slider.
  • Confirm SpeedValueText updates live and cursor is visible.
