Interactive UI Elements

Buttons, Sliders, Event Graph wiring, and binding strategies for responsive HUDs.

Interactive 16:9 Masterclass
Buttons
Trigger actions with OnClicked events. Example: Start or Quit.
Sliders
Adjust continuous values like volume or speed using OnValueChanged.
Binding
Keep UI elements synced to variables without manual events.
In this lesson

You will build a simple menu widget, wire OnClicked and OnValueChanged events, bind a text block to a slider value, and test with the player character.
