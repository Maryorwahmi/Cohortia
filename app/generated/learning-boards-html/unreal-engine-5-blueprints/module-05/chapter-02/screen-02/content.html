Learning Objectives

Practical skills and competency milestones for interactive widgets.

Bloom: Learn → Understand → Apply → Master
01
Add Buttons & Sliders

Place interactive widgets in a Widget Blueprint and name them descriptively so you can reference them in the Event Graph. Verified Competency Milestone

02
Wire Events

Create OnClicked and OnValueChanged event nodes in the Widget Event Graph and connect them to gameplay logic. Verified Competency Milestone

03
Bind Properties

Use bindings for automatic UI updates when a widget is purely a display of a value, like showing a slider’s current number. Verified Competency Milestone

04
Avoid Pitfalls

Name widgets, match types when binding, and avoid expensive operations on every slider tick. Verified Competency Milestone
