Skills Breakdown

Concrete verification steps for each objective.

Verify Button

Add QuitButton, create OnClicked, connect a Print String. Play and press to see the message.

Verify Slider

Add SpeedSlider with sensible Min/Max, wire OnValueChanged to Set Max Walk Speed on the player character.

Verify Binding

Create a binding for SpeedValueText. Use Get Value then ToText and Append to format the result as 'Speed: 500'.
