Core Concept

Button anatomy

A Button is an interactive widget that requires an OnClicked event to do anything. It should contain a Text Block child for the label and a descriptive asset name.

Common setup checklist
  • Drag Button into Canvas Panel and anchor appropriately.
  • Add a Text Block as a child and set readable label text.
  • Rename the Button to a meaningful identifier.
  • Click the green plus next to OnClicked to create the event node.
Example
QuitButton with a child Text Block labeled "Quit Game". OnClicked leads to a Print String for verification, then to a Quit Game node in a real project.
Common mistake
Placing the label outside the Button hierarchy or forgetting to name the widget, which makes wiring hard and clicks may be unreliable.

Key Takeaway

Name the widget, use a child text block, and always test with a Print String before adding game-changing logic.
