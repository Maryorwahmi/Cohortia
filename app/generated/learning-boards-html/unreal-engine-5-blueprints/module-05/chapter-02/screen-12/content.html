Common mistakes

Naming & hierarchy

Use clear widget names and ensure Text Blocks are children of their Button to preserve hit testing.

Type mismatch

Convert floats to text in bindings; the compiler will warn, but checking types early prevents runtime surprises.

Continuous events

OnValueChanged fires frequently. Debounce or commit on release for heavy updates.

Cursor & input

Remember to Set Show Mouse Cursor for the Player Controller when showing UI, and test gamepad navigation where appropriate.

Debug tip

Use Print String to confirm events fire, then inspect binding functions and the Output Log for type and reference errors.
