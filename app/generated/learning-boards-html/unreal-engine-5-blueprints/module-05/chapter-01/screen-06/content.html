Comparison

Widgets and Panels

Text Block
Lightweight label for static or dynamic text like "Score: 0".
Image
Displays textures for icons and backgrounds; set SizeX/SizeY to control pixel dimensions.
Canvas Panel
Absolute positioning and anchors; best for HUD elements that attach to screen edges.
Vertical/Horizontal Box
Flow-based layout; items stack and resize together — ideal for menus and lists.
Concrete example
HUD: Canvas root → ScoreText (Text Block) anchored top-right → CoinImage (Image) anchored top-right with offsets. Menu: Vertical Box with buttons so adding new menu items keeps layout consistent.
Common mistake

Overusing Canvas leads to brittle menus. Prefer Box panels for lists and content-driven layouts.
