Skills & Why They Matter

Clear, testable outcomes for your HUD workflow.

Practical checks
Design a HUD

Use Canvas Panel, add Text Block as ScoreText and an Image for the coin icon. Rename and set default values so testing is immediate.

Anchor for responsiveness

Pick preset anchors like top-right. Use offsets instead of absolute coordinates so the layout scales across screen sizes.

Show at runtime

In Event BeginPlay create your Widget and Add to Viewport. If it doesn't appear, check the Add to Viewport step first.

Test on multiple aspect ratios

Run PIE and change the viewport size or test on multiple devices to confirm anchors keep the HUD visible.
