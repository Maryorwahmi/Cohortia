Core Concept

UMG: Visual UI design in Unreal

UMG enables you to assemble interactive interfaces in the Designer and connect behavior in Blueprints, avoiding C++ for most UI work.

Definition
UMG is Unreal's system for creating UI using widgets and Widget Blueprints.
Concrete example
Create a UserWidget, add a Text Block named HealthText, set default to "Health: 100" and preview in Designer.
Common misconception
UMG is not only for static overlays; it supports bindings, animations, and Blueprint-driven updates, but be mindful of performance.

Key Takeaway

UMG lets you build interactive, visually-driven UI quickly with Widget Blueprints; use it to prototype and ship in-game interfaces without engine code.
