Module 5 › Chapter 5.1 › Create Widget & Add to Viewport
Process Flow

Event BeginPlay → Create Widget → Add to Viewport

// Blueprint flow (visual nodes represented as pseudocode)
Event BeginPlay
  → Create Widget (Class: WBP_PlayerHUD, Owning Player: Get Player Controller)
      (Return Value: WBP_PlayerHUD Reference)
  → Add to Viewport (Target: WBP_PlayerHUD Reference)
Ownership
Set Owning Player to Get Player Controller so input focus and multiplayer behavior are correct.
Debug tip
Print a message after Add to Viewport to confirm the flow executed in PIE.
Common mistake
Forgetting Add to Viewport is the most common reason a created widget is invisible. Check the Create→Add chain first when a UI doesn't appear.
Key Takeaway

Create Widget returns an instance; Add to Viewport is required to render that instance on the player's screen.
