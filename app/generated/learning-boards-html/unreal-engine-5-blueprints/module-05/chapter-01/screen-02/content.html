Learning Objectives

Learn, Understand, Apply, Master — the practical UMG workflow.

Bloom: Learn → Understand → Apply → Master
01
Describe UMG and its role

Explain what UMG is, why it is preferred for UI tasks, and how it enables visual design without C++.

VERIFIED COMPETENCY MILESTONE
02
Create a Widget Blueprint

Make a new UserWidget asset, open the Designer, and add Text and Image widgets to a Canvas Panel.

VERIFIED COMPETENCY MILESTONE
03
Use anchors for responsive UI

Set anchor presets and offsets so elements keep their relative positions across resolutions instead of fixed pixels.

VERIFIED COMPETENCY MILESTONE
04
Display widgets at runtime

Use Event BeginPlay, Create Widget, and Add to Viewport to instantiate and show your UI to the player.
