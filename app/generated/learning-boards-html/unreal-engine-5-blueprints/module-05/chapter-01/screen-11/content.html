Hands-on Activity

Create a Score HUD

Step 1 — Create Widget Blueprint
Content Browser → User Interface → Widget Blueprint → name WBP_GameHUD.
Step 2 — Design
Add Canvas Panel, add Text Block named ScoreText with "Score: 0" and an Image for the coin.
Step 3 — Anchor & Offset
Set top-right anchor for both widgets and adjust Position X/Y offsets for alignment.
Step 4 — Display in Blueprint
Event BeginPlay → Create Widget (WBP_GameHUD) → Add to Viewport. Compile and Play.
Example offsets
ScoreText: PositionX -150, PositionY 20 · CoinImage: PositionX -200, PositionY 15 · Image size 32x32 recommended for clarity.
Key Takeaway

Follow the Create→Add flow and test anchors by resizing the PIE viewport to validate responsive placement.
