Module 5 › Chapter 5.1 › ZOrder & stacking
Definition

ZOrder: control drawing order

Assign integer ZOrder values to children so higher numbers appear above lower ones when overlapping occurs.

Example
Background panel ZOrder 0 · ScoreText ZOrder 1 · CoinImage ZOrder 2 ensures icon sits above text and background.
Pitfall
Moving widgets between panels changes the stacking context; ZOrder is relative to the parent panel.
Quick check
If a widget is hidden behind another, increase its ZOrder or check parent hierarchy. Use ZOrder intentionally for popups, tooltips, and HUD icons.
Key Takeaway

ZOrder decides draw order; higher values render last and appear on top of lower ones.
