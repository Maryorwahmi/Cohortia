Module 5 › Chapter 5.1 › Key Concepts
UMG
Visual editor for in-game UI built with Widget Blueprints.
Widget Blueprint
Container for widgets and Blueprint graph for UI behavior.
Anchoring
Defines where a child sticks to the parent and keeps UI responsive.
Create Widget
Instantiates a Widget Blueprint at runtime.
Add to Viewport
Makes the created widget visible on the player's screen.
ZOrder
Controls which widgets draw on top when overlapping.
Summary
Design in Widget Blueprints, anchor for responsiveness, create and then Add to Viewport to show UI, and optimize for performance.
