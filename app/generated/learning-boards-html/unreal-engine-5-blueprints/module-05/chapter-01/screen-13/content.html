Assessment Idea

Troubleshooting checklist

1. Check execution
Did Event BeginPlay run? Add a Print String or breakpoint.
2. Add to Viewport
Ensure the Create Widget return value is passed to Add to Viewport.
3. Anchors & Offsets
Confirm the widget isn't off-screen due to incorrect anchors or extreme offsets.
4. ZOrder & Ownership
Check ZOrder for occlusion and Owning Player for focus/input correctness.
Key Takeaway

A short, ordered checklist quickly identifies why a widget is not visible: execution, Add to Viewport, anchors, ZOrder, and ownership.
