Module 5 › Chapter 5.1 › Widget Blueprint explained
Definition

Widget Blueprint

A reusable UserWidget asset that contains both visual widgets and a Blueprint graph for behavior.

Designer vs Graph
Designer: place and configure widgets. Graph: add events, bindings, and functions that change the UI at runtime.
Naming convention
Use descriptive names like ScoreText, IconImage so graph references are clear and maintainable.
Concrete scenario
WBP_PlayerHUD exposes UpdateHealth(int NewHP) in its Graph. When the player takes damage, the Character calls that function and the widget updates HealthText to reflect the new value.
Key Takeaway

Widget Blueprints bundle UI visuals and behavior in one asset, making interfaces modular and easy to reuse.
