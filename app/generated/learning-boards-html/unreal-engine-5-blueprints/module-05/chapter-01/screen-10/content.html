Code Walkthrough

Readable Blueprint pseudocode

// Player Character or Player Controller Event Graph
Event BeginPlay
  → Create Widget
      • Class: WBP_GameHUD
      • Owning Player: Get Player Controller
      → Return Value: HUDWidget (UserWidget reference)
  → Add to Viewport (Target: HUDWidget)

// Optional: store HUDWidget in a variable for later calls like HUDWidget→SetScore(newScore)
Practical note
If you need to update HUD values, keep the widget reference in a variable on the owner so you can call custom functions on the widget later.
Pitfall

Event BeginPlay must run in the correct Blueprint for the player's instance; placing the flow in a non-player actor will not show the HUD to the player.
