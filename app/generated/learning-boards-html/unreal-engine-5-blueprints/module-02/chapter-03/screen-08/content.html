Module 3 › Chapter 2.3 › Pure vs Impure
Pure Function

Computes a value from inputs and returns it without changing game state. No execution pins appear in the graph.

Example: CalculateDistance(VectorA, VectorB) -> Float
Benefit: easier testing and fewer unintended side effects.
Impure Function

Has execution pins and performs actions that alter state or trigger effects. Use when you must set variables, spawn actors, or play sounds.

Example: ApplyDamage(DamageAmount) -> sets CurrentHealth, prints a message.
Note: Marking a function incorrectly will confuse callers and hide side effects.
