Execution Concepts

Entry exposes inputs and starts the sequence. Wire your nodes so side effects occur before you connect to Return. For impure functions, connect execution pins; for pure functions, connect data wires only.

Impure Functions

Contain execution pins and perform actions that change game state, like Set Variable or Play Sound.

Pure Functions

No execution pins. They take inputs, compute, and return values with no side effects.

Practical Notes
  • Connect execution pins through nodes that must run in order.
  • Set member variables when changes must persist beyond the function call.
  • Use local variables for temporary steps and intermediate values.
Common Mistake

Assuming Return cuts execution automatically. Always wire the final execution path into the Return node so it executes after your actions.
