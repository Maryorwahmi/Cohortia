Question 1

If a function only computes TotalScore from PlayerScore and BonusPoints without changing any variables, mark it Pure. Pure functions are side-effect free and easier to use in expressions.

Question 2

For ActivateItem that plays an animation and updates a variable, define ActivationStrength as an input and Success as an output. This function is impure because it triggers actions and sets state; return Success to let the caller react.

Try implementing both in a workspace and use Print String to confirm expected values during Play testing.
