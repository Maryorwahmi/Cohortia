Pure Function

Side-effect free computations that return values only.

Impure Function

Performs actions and uses execution flow; required when changing game state or playing effects.

Local Variable

Temporary storage that only exists during the function's execution.

Final Takeaway

Design functions for single responsibility, pass data with parameters, and test behavior with focused calls. This discipline keeps Blueprints scalable and easier to maintain.
