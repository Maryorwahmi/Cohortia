Module 3 › Chapter 2.3 › Key Concepts — Part 1
Function

A named, reusable block of Blueprint logic designed for a single task.

Function Graph

The dedicated graph area where Entry, logic, and Return live for a function.

Parameters

Inputs and outputs that pass data into and out of a function for isolation and testing.

Summary

Use functions, parameters, and the Function Graph together to write modular Blueprints. Clear names and small scopes improve long-term maintainability.
