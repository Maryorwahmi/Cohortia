Module 3 › Chapter 2.3 › Call From Event Graph
Typical Call Sequence
  1. Right-click in Event Graph and search for the function by name.
  2. Connect an event's execution pin to the function call's execution input (if impure).
  3. Provide input values via literals, variables, or calculations.
  4. Use returned outputs from the call node to update state or trigger responses.
Example Wiring
// Event Graph pseudocode
Event KeyboardSpacebar.Pressed
  -> Call ApplyDamage(DamageAmount=10.0, DamageType="Blunt Force")
  -> Receive NewHealthValue
  -> Use NewHealthValue to update UI or check for death
Testing Tips
  • Set clear input values when testing to avoid default behavior.
  • Add Print String after the call to confirm returned values at runtime.
  • Keep the call site simple; heavy logic belongs inside functions or helper calls.
Key Takeaway

Explicitly wire inputs and outputs at call sites to make function effects visible and testable.
