Module 3 › Chapter 2.3 › Local Variables
Why Use Locals

Locals keep temporary state inside the function, preventing unnecessary class variables and reducing coupling across the Blueprint.

When to Promote a Pin

If a node yields a value you need only inside this function, promote its pin to a local instead of creating a new member variable.

Example

Use a local named Result to hold CurrentHealth minus DamageAmount, then set CurrentHealth and return Result.

Do and Don't
  • Do use locals for intermediate steps.
  • Don't use locals to conceal persistent state changes—use member variables when persistence is required.
Gotcha

Remember locals vanish after the function returns. If you need the value later, return it or set a member variable explicitly.
