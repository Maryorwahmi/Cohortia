Common Mistakes
  • Giant functions doing multiple responsibilities.
  • Relying on member variables instead of parameters.
  • Marking impure functions as pure or vice versa.
Best Practices
  1. Single responsibility: one function, one clear task.
  2. Pass data via parameters; return results explicitly.
  3. Use locals for temporary calculations and Print String for temporary debugging.
Refactor Tip

When you spot similar node sequences, extract them into a function to reduce duplication and future bugs.
