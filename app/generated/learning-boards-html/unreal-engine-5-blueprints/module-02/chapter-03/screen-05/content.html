Module 3 › Chapter 2.3 › Create a Function
Step-by-step
  1. Open My Blueprint and click + under Functions.
  2. Name the function with a verb phrase like ApplyDamage.
  3. Open Function Graph to place nodes between Entry and Return.
  4. Add parameters in Details: Inputs and Outputs.
  5. Compile and save after wiring logic and testing.
Pro Tip

Use descriptive, action-oriented names and keep functions focused on one task to make graphs easier to read.

Visual Checklist
Entry Node

Exposes inputs you added and begins the function execution sequence.

Return Node

Exposes outputs and ends the function execution, returning values to the caller.
