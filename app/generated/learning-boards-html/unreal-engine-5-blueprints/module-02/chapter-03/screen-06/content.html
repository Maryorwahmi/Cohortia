Parameter Contract

Define inputs in the function Details panel to appear on Entry. Define outputs on Return. Wire them so callers provide inputs and receive results.

Example Signature
// Pseudocode representation of the ApplyDamage function
Function ApplyDamage(DamageAmount: Float, DamageType: String) -> NewHealthValue: Float
  Entry:
    Get CurrentHealth
    Result = CurrentHealth - DamageAmount
    Set CurrentHealth = Result
    Print String "Took " + DamageAmount + " damage (" + DamageType + "). New Health: " + Result
  Return NewHealthValue = Result
Best Practices
  • Prefer parameters over reading member variables when possible.
  • Mark a function Pure when it only computes and returns values.
  • Use structs if multiple outputs form a logical group.
Key Takeaway

Parameters make functions predictable and easier to reuse; they also reveal whether a function is pure or impure by intent.
