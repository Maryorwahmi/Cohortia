Module 3 › Chapter 2.3 › What Is a Function?
Definition & Benefits

A function packages nodes into a named unit. It accepts inputs, runs logic from Entry to Return, and can return outputs. Use functions to avoid duplication and make Blueprints easier to navigate.

Reusability: Use one logic block across many event triggers.
Maintainability: Change logic in one place and propagate updates.
Organization: Replace node clutter with descriptive call sites.
Key Takeaway

Prefer small, named functions for repeated logic. Even simple calculations benefit when shared across a Blueprint.

Concrete Example
ApplyDamage(DamageAmount: Float, DamageType: String) -> NewHealth: Float

This function subtracts DamageAmount from CurrentHealth, sets the updated CurrentHealth, prints a message that includes the damage type, and returns the new health value.

Common Misconception

Some learners try to keep everything in the Event Graph to avoid learning functions. That creates duplicate nodes and fragile code. Moving repeated sequences into functions reduces errors and simplifies debugging.
