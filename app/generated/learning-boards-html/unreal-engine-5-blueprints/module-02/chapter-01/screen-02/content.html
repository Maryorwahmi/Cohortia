Learning Objectives
Skill targets and why they matter for interactive gameplay
Bloom: Learn → Understand → Apply → Master
01
Identify variable purpose
Choose which game state needs memory and why a variable fits that role. This matters when multiple events must reference the same state.
VERIFIED COMPETENCY MILESTONE
02
Create and type variables
Add variables in the My Blueprint panel and select primitive or complex types from the Details panel. Correct typing prevents runtime errors.
VERIFIED COMPETENCY MILESTONE
03
Scope and defaults
Set default values and understand member versus local scope so variables are accessible where and when you expect them to be.
VERIFIED COMPETENCY MILESTONE
04
Get and Set nodes
Use Get to read and Set to update variables in response to events. Wiring types correctly avoids compile warnings and logic bugs.
VERIFIED COMPETENCY MILESTONE
