Get and Set — read and write
Get outputs the current value. Set requires execution and an input value.
Typical flow
Event → Get current value → Compute → Set new value (execution pin from event).
Type check
Ensure the value plugged into Set has the same type as the variable to avoid warnings or errors.
Concrete example
// Blueprint-like pseudocode
Event EnemyDies
  Get PlayerScore
  Add PlayerScore + 10 -> Result
  Set PlayerScore = Result
This sequence reads the current score, adds a reward, and writes the updated score back using the Set node triggered by the EnemyDies event.
