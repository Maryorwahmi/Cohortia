Primitive Types at a Glance
Pick the type that best matches how the data will be used in gameplay.
Boolean
True/False. Use for binary states like bIsOpen or HasKey.
Integer
Whole numbers for counts like PlayerScore or EnemyCount.
Float
Decimal numbers for speed, time, and fine-grained values like PlayerSpeed.
String
Text for names, dialogue, and descriptions—avoid using for numeric math.
Example Scenarios
Door state
bIsOpen: Boolean. Only needs true or false to control opening logic.
Score
PlayerScore: Integer. Whole numbers ensure simple counting and comparisons.
Speed
PlayerSpeed: Float. Fractions matter for smooth movement and physics.
Key Takeaway

Match type to use. Choosing the right primitive reduces conversion work and prevents logic errors.
