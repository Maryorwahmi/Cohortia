Module 2 › Chapter 2.1 › Object References
What an Object Reference does
Stores a link to an Actor or Component instance so you can interact with that specific object.
Example
TargetDoor: BP_Door_C — allows calling an Open function or setting bIsOpen on the referenced door.
Assignment
Assign in the editor for level-placed references, or Set at runtime, for example during BeginPlay by finding actor instances.
Best practices
  • Expose references as editable when a designer should assign them in the level.
  • Cache references at BeginPlay if you need repeated access to avoid costly lookups.
  • Check validity before accessing a reference to avoid errors when the object is destroyed.
Key Takeaway

Use object references to connect actors for direct interaction, and guard access with validity checks if the target may be destroyed or nil.
