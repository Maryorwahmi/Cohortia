Spatial & Reference Types
Choose structured types that match the data you need to pass between systems.
Vector
Three floats for X, Y, Z. Represents position or direction, used for SpawnPoint or MovementDirection.
Rotator
Roll, Pitch, Yaw. Use for rotations like CameraRotation or DoorOrientation.
Transform
Location + Rotation + Scale. Use when you need the full spatial state of an object.
Object Reference
Stores a reference to an Actor or Component instance so you can call functions or change properties on that object.
Scenario
BP_InteractiveDoor
Use a Vector for a specific spawn offset, a Rotator for door orientation, and an Object Reference to link the door to the player or an unlockable item so the door can check the player's inventory.
Pro tip
Pro Tip

Prefer structured types like Transform when the Editor offers nodes tailored for them; it simplifies wiring and reduces conversion work.
