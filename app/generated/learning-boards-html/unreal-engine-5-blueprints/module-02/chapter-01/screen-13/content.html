Common mistakes and fixes
Two quick checks will solve most problems.
1. Forgot to Compile
If the variable won’t appear in the graph, click Compile and Save so the Editor updates available nodes and menus.
2. Type mismatch
Ensure the value you connect matches the variable’s type. If you need decimals use Float instead of Integer.
Debug tip
Use Print String or on-screen debug messages after setting a variable to verify runtime values and trace where incorrect values may be coming from.
