Understanding Variables
Store game state with typed, named containers so your Blueprints can react to change.
Variables are the building blocks of interactive scripts. They give your Actor memory and let you read or change that memory at runtime with Get and Set nodes. Throughout this chapter you’ll see how to choose types, set defaults, manage scope, and avoid common mistakes like forgetting to compile or mismatching types.
In this lesson
You’ll learn variable types, how to add and name variables in the Blueprint Editor, set defaults, distinguish scope, and use Get/Set to change values during gameplay.

Quick tip
Compile after creating or changing variables so the Editor recognizes them in the Event Graph. If a variable doesn’t appear, compiling is the first thing to check.
