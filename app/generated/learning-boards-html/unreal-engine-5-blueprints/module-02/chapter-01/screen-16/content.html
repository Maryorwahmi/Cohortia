Module 2 › Chapter 2.1 › What to Remember
Type Intent
Choose the type that matches how the value will be used to avoid conversion issues later.
Naming & Defaults
Use PascalCase, b-prefixes for Booleans, and set defaults so the actor behaves sensibly at spawn.
Get → Compute → Set
Read values, compute results, and write back using Set on an execution path; compile often.
Final takeaway

Small habits—correct types, clear names, sensible defaults, and regular compiles—make Blueprints robust and easier to scale.
