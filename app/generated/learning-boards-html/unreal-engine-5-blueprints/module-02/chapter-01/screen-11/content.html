Module 2 › Chapter 2.1 › Increase PlayerSpeed
Wiring steps
A precise sequence for a Float increment using Get and Set.
// Pseudocode blueprint steps
Event PowerUpPickup
  Get PlayerSpeed         // current Float
  Add PlayerSpeed + 5.0   // Float + Float
  Set PlayerSpeed = Result  // update variable (execution pin from event)
  Print String("Speed: " + ToString(Result))  // optional debug
This pattern reads the current value, computes a new value with the Add node, and writes it back using Set, triggered by the pickup event.
Checklist
  • Ensure PlayerSpeed is a Float if you need decimals.
  • Connect execution pin from the event to the Set node.
  • Optionally print the new value to confirm at runtime.
Key Takeaway

Follow Get → Compute → Set to change values predictably and verify with debug prints while testing.
