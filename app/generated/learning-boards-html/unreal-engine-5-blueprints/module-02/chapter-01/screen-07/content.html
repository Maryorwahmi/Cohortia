Add a variable — quick process
Follow these steps every time you add a variable to keep your Blueprints consistent.
1
+ Variable in My Blueprint
Click the + Variable button to create a member variable.
2
Name it clearly
Use PascalCase and prefixes like b for Booleans to improve readability.
3
Choose type in Details
Pick primitive or complex types depending on the data you will store.
4
Set default and Compile
Enter a starting value and click Compile so the changes take effect in the graph.
Example
Create PlayerHealth
Add variable PlayerHealth, set type to Float, default 100.0, then Compile. Drag into the Event Graph to Get or Set it.
