Module 2 › Chapter 2.1 › Variable Scope
Member Variables
Accessible anywhere in the Blueprint and persist with the actor.
When to use
Shared state like bIsOpen, PlayerHealth, or references to other actors.
Persistence
Remains until the actor is destroyed or the value is changed by Set nodes.
Local Variables
Scoped to a single function; used for temporary calculations.
When to use
Intermediate values inside a function that do not need to persist between events.
Common mistake
Trying to access a local variable outside its function. The Editor enforces scope and will not expose it.
Key Takeaway

Design variables with scope in mind: prefer member variables for shared state and locals for transient computations.
