Module 2 › Chapter 2.1 › BP_InteractiveDoor
Activity: Create an interactive door
Follow these numbered steps in the Editor to build and test the actor.
1. Create Actor
Content Browser → Right-click → Blueprint Class → Actor → name BP_InteractiveDoor.
2. Add components
Add Static Mesh (set to Shape_Cube) and Text Render to show state text.
3. Create variables
bIsOpen (Boolean, False), DoorOpenSpeed (Float, 2.0), RequiredKeys (Integer, 1). Compile.
4. Place in level
Drag an instance into the level to test defaults and visibility.
5. Wire interaction
In Event Graph, use an Interact event that checks RequiredKeys and then Sets bIsOpen to True to trigger the open animation.
6. Challenge
Add an Object Reference for the player to check inventory, or show the remaining keys in the Text Render component.
