Module 2 › Chapter 2.2 › Input Events
Action (Discrete)
Fires on a button press or release. Great for toggles, jumps, or single interactions.
Example
Keyboard E triggers a FlipFlop that sets the door open or closed positions when pressed.
Axis (Continuous)
Sends a value each frame while the control is active; ideal for movement axes and analog input.
Example
InputAxis MoveForward sends -1 to 1 values for smooth forward/back motion when combined with movement logic.
Decision Guide
If the action is a single event, use an action event. If you need a continuous value per frame, use an axis event and consider where the value is applied.
