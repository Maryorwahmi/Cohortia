Module 2 › Chapter 2.2 › Execution Flow
Core Mechanic
Execution pins move control from node to node. Data pins supply values but don't dictate sequence.
Keyboard E (Pressed)
-> Branch (IsPlayerInRange AND not bIsOpen?)
-> True -> Set Relative Location (Open)
-> Set bIsOpen = true
-> Print String "Door Opened"
Debugging Tip
Attach a Print String to branches and key nodes to see which paths ran during gameplay. This clarifies unexpected flow.
Misconception
Don't assume data pins change execution order. Always follow execution pins to understand timing.
