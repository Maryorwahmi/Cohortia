Module 2 › Chapter 2.2 › Event Graph Architecture
Layout Pattern
Place initialization near BeginPlay, input handlers near input events, and timers/delegates in a dedicated area. Use short custom events to keep flows focused.
Initialization
BeginPlay sets variables, spawns components, or registers delegates.
Input Handlers
Keyboard or action events that respond to player controls.
Practical Example
BP_EnemySpawner uses BeginPlay to set a repeating timer that calls a custom SpawnWave event. SpawnWave performs the actual spawn work so you can reuse it when needed.
  • Custom events let you call the same logic from multiple places without duplicating wires.
  • Separating concerns helps you turn off or profile specific systems easily.
  • Label and color-code sections for teammates and future-you.
Pro Tip
Use comments and reroute nodes to keep long chains readable. Chunk logic into named custom events where a single responsibility is clear.
