Module 2 › Chapter 2.2 › Event BeginPlay
Behavior
Fires once per actor instance when it enters the world. Ideal for initializing variables, starting timers, or spawning components.
Verification
Event BeginPlay
-> Print String "Door Initialized!"
-> Set Variable: bIsOpen = false
-> Set Timer by Event: SpawnWave every 10s
Concrete Example
In BP_InteractiveDoor, use BeginPlay to set the door's starting closed position and initialize interaction ranges. This ensures the door begins in a known state.
Common Mistake
Putting repeated checks inside BeginPlay is ineffective because it runs once. For repeated behavior, prefer Tick or timers.
