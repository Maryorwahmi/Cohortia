Module 2 › Chapter 2.2 › What is an Event?
Definition
An event is a trigger from the engine or player that initiates Blueprint execution through an execution pin. It represents the cause that your Blueprint responds to.
Analogy
Imagine a doorbell: the press is the event, and the house reaction is the connected logic. Events decouple the press from the response.
Key Takeaway

Events start logic in response to occurrences; they are not functions you call directly.

Concrete Example
Event BeginPlay fires the moment an actor exists in the level. Use it to set initial variables or spawn child actors.
  • Events are created by right-clicking in the Event Graph and searching for the event name.
  • When an event fires, its execution pin activates connected nodes in order.
  • Events help you write reactive, not linear, gameplay code.
Common Misconception
Don't treat events as callable functions. They are triggered by the engine or input, not invoked like a function unless you explicitly call a custom event.
