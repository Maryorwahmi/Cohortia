Module 2 › Chapter 2.2 › Key Concepts
Event
A trigger that initiates Blueprint behavior in response to engine or player actions.
Event Tick
Fires every frame; useful for continuous updates but can hurt performance if overused.
Event Graph
The visual canvas where events, execution pins, and nodes are organized to form behavior.
Summary

Pick the right event for the job, avoid unnecessary per-frame work, and keep your Event Graph organized with small, named events and clear labels.
