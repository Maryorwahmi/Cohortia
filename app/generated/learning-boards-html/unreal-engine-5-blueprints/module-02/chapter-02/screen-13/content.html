Module 2 › Chapter 2.2 › Best Practices
Practices
  • Group nodes by purpose: Initialization, Input, Timers, etc.
  • Use custom events to encapsulate single tasks and call them from multiple places.
  • Label important nodes and explain why Tick is needed when used.
  • Profile often; Print String is a quick sanity check.
Concrete Example
Replace a repeated Tick-based health check with a custom OnDamage event that fires only when damage occurs, updating UI and triggering effects on demand.
Reflective Question
When would you definitely use Tick, and when would you prefer an event or timer?
