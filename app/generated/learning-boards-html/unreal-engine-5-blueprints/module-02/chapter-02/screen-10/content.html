Module 2 › Chapter 2.2 › Door Interaction
Step-by-step
1. Event BeginPlay
   -> Print String "Door Initialized!"
   -> Set bIsOpen = false
2. Keyboard E (Pressed)
   -> FlipFlop
   -> A -> Set Relative Location (X=0,Y=100,Z=0) ; Set bIsOpen = true
   -> B -> Set Relative Location (X=0,Y=0,Z=0)   ; Set bIsOpen = false
Checks & Tips
Make sure the input mapping exists or use Keyboard E node. Verify the door mesh component is targeted by the Set Relative Location nodes. Test while near the door to confirm range checks if present.
