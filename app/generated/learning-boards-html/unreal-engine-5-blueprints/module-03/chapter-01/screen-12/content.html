Event-Driven Programming
Flow controlled by occurrences so logic runs only when needed.
Event BeginPlay
Fires once when the Actor exists in play — good for runtime setup and binding.
Event Tick
Runs every frame with Delta Seconds — use for continuous motion but sparingly.
Summary: Choose BeginPlay for one-time start logic, Tick for true per-frame needs, and lean on event triggers for reactive gameplay to keep performance healthy.
