Custom Event: ToggleLight
Create ToggleLight with input bOn (Boolean). Inside: Set Intensity to 5000 if true, 0 if false.
Testing tips
Add a Print String inside ToggleLight to confirm calls during Play. Confirm the Light component reference is correct on the Set Intensity node.
Mini Code Panel
Custom Event ToggleLight(bOn : bool)
  if bOn
    PointLight.SetIntensity(5000)
  else
    PointLight.SetIntensity(0)
  PrintString("ToggleLight called: " + (bOn ? "On" : "Off"))
Key Takeaway

Isolate behavior in a Custom Event so the light can be controlled by many systems without duplication.
