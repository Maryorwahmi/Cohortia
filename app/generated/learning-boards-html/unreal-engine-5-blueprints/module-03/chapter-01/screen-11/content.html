Module 3 › Chapter 3.1 › Hands-on: Create BP_LightSwitch and Bind
Switch Blueprint steps
  • Add Static Mesh and Box Collision sized for interaction.
  • Create Event Dispatcher OnSwitchToggled(bool bIsOn).
  • OnComponentBeginOverlap → Call dispatcher with true. OnComponentEndOverlap → Call with false.
Binding in BP_Light
In BeginPlay get a reference to BP_LightSwitch, call Bind Event to OnSwitchToggled and create HandleSwitchToggle to forward bIsOn to ToggleLight.
Testing checklist
  1. Place one Light and one Switch in the level.
  2. Bind at BeginPlay, then Play and walk into the switch box — light should turn on.
  3. Walk out — light should turn off. Use Print String to trace messaging.
Key Takeaway

Bind event handlers early and validate with prints and breakpoints to ensure dispatchers reach their listeners.
