Module 3 › Chapter 3.1 › BeginPlay — Initialize with certainty
When to use BeginPlay
Initialize variables, bind dispatchers, and perform runtime-only setup.
Example: Door setup
Set state to closed, determine key requirements, and expose a reference for external binders.
Reference acquisition
Prefer exposing a variable for editor assignment; Get All Actors Of Class is acceptable for demos but less efficient.
Checklist
  • Set initial component and variable states you rely on at runtime.
  • Bind to Event Dispatchers so listeners are ready when broadcasters fire.
  • Avoid editor-only initialization that should run only during play.
Key Takeaway

BeginPlay is the right place for runtime bindings and one-time setup. Use editor variables for direct references when possible.
