Module 3 › Chapter 3.1 › Event Tick — When continuous updates are appropriate
Tick essentials
Fires every frame. Use Delta Seconds for consistent motion across varying frame rates.
Appropriate uses
  • Smooth interpolation of position or rotation.
  • Real-time input processing that requires per-frame response.
  • Continuous physics adjustments not handled by engine physics directly.
Alternatives & pitfalls
  • Use OnComponentBeginOverlap for pickups instead of checking distances every frame.
  • Use timers for periodic checks rather than Tick when high frequency is unnecessary.
  • Disable Tick when the actor is idle to save CPU cycles.
Mini Example
// Pseudocode for Tick-based movement
CurrentLocation += Direction * Speed * DeltaSeconds;
SetActorLocation(CurrentLocation);
Key Takeaway

Tick is powerful but costly. Prefer targeted events, timers, or enabling Tick only when necessary.
