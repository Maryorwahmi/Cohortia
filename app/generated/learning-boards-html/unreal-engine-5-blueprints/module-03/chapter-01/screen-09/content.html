Module 3 › Chapter 3.1 › Event Dispatchers — Broadcast without coupling
Dispatcher pattern
Broadcaster defines dispatcher; listeners bind to it and receive calls when it's invoked.
Creation steps
  1. Add Event Dispatcher in My Blueprint and name it.
  2. Add parameters to pass data if needed.
  3. Call the dispatcher where appropriate to broadcast.
Binding on another Blueprint
Obtain a reference to the broadcaster, call Bind Event to register a Custom Event, usually during BeginPlay.
Design note
Use descriptive dispatcher names and parameter types so listeners can easily consume the broadcast without guessing what data is sent.
Key Takeaway

Event Dispatchers allow many listeners to react to a single broadcast while keeping the broadcaster ignorant of who listens.
