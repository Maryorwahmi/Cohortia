Module 3 › Chapter 3.1 › Collision Events — Overlap and Hit
Overlap example: pickup
Use a Sphere Collision with OnComponentBeginOverlap to detect players entering pickup range.
Typical flow
  1. Overlap fires when player enters sphere.
  2. Cast Other Actor to PlayerCharacter to confirm.
  3. Call Custom Event AddToInventory and then Destroy Actor.
Hit example: physics impact
Event Hit provides impulse, normal, and hit location useful for effects and damage calculations.
Checks & tips
  • Ensure collision presets allow the event type (Overlap vs Block).
  • Use Print String while iterating to confirm Other Actor values during testing.
  • Use Hit data for realistic responses like bounce direction or damage from impulse.
Key Takeaway

Choose overlap for proximity triggers and hit for physics-based collisions. Test with prints to ensure events fire as expected.
