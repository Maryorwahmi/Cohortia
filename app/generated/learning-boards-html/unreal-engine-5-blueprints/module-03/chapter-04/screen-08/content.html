Example Implementation › BP_Door: OnInteract
Implementation Outline
  • Event OnInteract(Interactor)
  • FlipFlop: A → Timeline Play; B → Timeline Reverse
  • Update door state variable (IsOpen) and Play animation.
  • Print String "Door Interacted by " + Get Display Name(Interactor)
Key Takeaway
Actor implementations own state and behavior; the interface simply triggers the event.
Concrete Scenario
Place BP_Door in the level, ensure its Timeline moves the door mesh along the desired axis, and test by calling OnInteract from the player. The door should open and close with successive interactions.
Common Mistake
Neglecting to update an IsOpen flag can cause animations to play incorrectly or to get out of sync with state. Keep state and animation consistent.
