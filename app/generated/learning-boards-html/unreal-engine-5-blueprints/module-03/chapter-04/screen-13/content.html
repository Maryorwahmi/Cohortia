Hands-on Activity › Universal Interactable System
Step Sequence
  1. Create BPI_Interactable with OnInteract(Interactor : Actor Reference) and save.
  2. BP_Door: add components, add interface, Implement Event OnInteract, FlipFlop + Timeline, Print String.
  3. BP_Light: add Point Light, add interface, Implement Event OnInteract, Toggle Visibility, Print String.
  4. ThirdPersonCharacter: add InteractionSphere, BeginOverlap → Does Implement Interface → set CurrentInteractable; EndOverlap → clear if same.
  5. Input E: if IsValid(CurrentInteractable) call OnInteract (Message) Target=CurrentInteractable Interactor=Self.
  6. Place actors in level and test interactions.
Key Takeaway
Following this sequence yields a robust, extensible interaction system where adding new interactables requires no change to player code.
Example Test
Run the level, approach the door and press E to open. Approach the light and press E to toggle. Confirm Print Strings show the Interactor name each time.
Extension Idea
Create BPI_Damageable with OnTakeDamage to apply this pattern to combat systems, letting any enemy Blueprint respond to damage differently.
