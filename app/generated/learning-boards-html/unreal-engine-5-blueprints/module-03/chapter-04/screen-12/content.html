Troubleshooting › Common Issues & Fixes
Checklist to run through
  1. Is the interface added in Class Settings on the Actor?
  2. Did you Implement Event for the interface function?
  3. Are you using the Message node instead of a direct function call?
  4. Do you guard with Does Implement Interface before calling?
  5. Are actor state variables updated consistently when animations run?
  6. Did you compile and save all related Blueprints?
Debug Strategy
Add Print String messages at begin and end of implementations and after Does Implement Interface checks to trace execution in the log.
Example Failure
If OnInteract does nothing, confirm the Actor class lists BPI_Interactable in Class Settings and that Implement Event was used to add logic to the Event Graph.
Final Tip
Treat the interface as a contract; verify both sides: the caller uses the Message node and the receiver implements the Event and compiles successfully.
