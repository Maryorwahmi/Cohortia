Code Walkthrough › Calling Interface Messages Safely
Pattern
Obtain Actor reference → Does Implement Interface(Target: actor, Interface: BPI_Interactable) → Branch → OnInteract (Message) (Target: actor, Interactor: Self).
Common Mistake
Calling a function directly on the actor via cast instead of using the Message node reduces flexibility and adds coupling.
Key Takeaway
Guard calls with Does Implement Interface and use OnInteract (Message) so the correct implementation runs at runtime for any class.
Pseudo-Blueprint Pseudocode
OnOverlap(Event OtherActor)
  if DoesImplementInterface(OtherActor, BPI_Interactable) == True
    CurrentInteractable = OtherActor
    Print String "Can Interact with: " + GetDisplayName(CurrentInteractable)
  else
    CurrentInteractable = None

OnInteractKeyPressed()
  if IsValid(CurrentInteractable)
    Call OnInteract (Message) Target=CurrentInteractable Interactor=Self
  else
    Print String "Nothing to interact with."
Example
When the player presses E, the message is sent only if CurrentInteractable implements BPI_Interactable, preventing null calls and ensuring predictable behavior.
