Example Implementation › BP_Light: OnInteract
Implementation Outline
  • Event OnInteract(Interactor)
  • Toggle Visibility on Point Light component
  • Print String "Light Toggled by " + Get Display Name(Interactor)
Concrete Scenario
Place BP_Light in the level with initial intensity at zero. When OnInteract runs, the point light turns on or off and you see the print string in the log.
Why this helps
Different objects with different implementations can be interacted with through the same player code. That means one interaction system scales to many object types.
Common Mistake
Assuming toggling is instantaneous in complex setups; if you use timelines or delays, ensure state remains consistent before the next interaction.
