Introducing Blueprint Interfaces & Communication

Design generic messages that different Blueprints can implement. Build systems where the caller asks "Can you interact?" and any implementer responds in its own way.

In this lesson

Create BPI_Interactable, implement OnInteract in actors, wire a player overlap with a Does Implement Interface safety check, and call the Message node to trigger implementations.

Why it matters

Interfaces let you add new interactable objects without changing player code. They reduce bugs and make gameplay systems extensible.

Key Takeaway

Interfaces are contracts: they say what an object can do, not how it does it. Use them to achieve loose coupling and polymorphic interactions.

Concept Map
