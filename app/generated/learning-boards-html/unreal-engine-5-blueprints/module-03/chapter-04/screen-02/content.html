Module 4 › Chapter 3.4 › Learning Objectives
01
Explain Interfaces
Describe why interfaces enable decoupled communication.

You will state how an interface is a contract and give an example like OnInteract used by doors and lights. Verified Competency Milestone: Describe interface benefits in a short plan.

02
Create & Define Messages
Add functions and parameters to a Blueprint Interface.

You will add OnInteract with an Interactor parameter and save. Verified Competency Milestone: Create BPI_Interactable with a parameter and compile it.

03
Implement in Actors
Add the interface to an Actor and implement the event.

You will implement Event OnInteract in BP_Door and BP_Light. Verified Competency Milestone: Each Actor responds when called.

04
Call Safely
Use Does Implement Interface and Message nodes correctly.

You will wire a sphere overlap and check implementation before calling OnInteract. Verified Competency Milestone: Player code calls OnInteract only when valid.
