Process Flow › Implementing an Interface
Step-by-step
  • Open Actor Blueprint (e.g., BP_Door).
  • Class Settings → Interfaces → Add BPI_Interactable.
  • In My Blueprint under Interfaces, right-click OnInteract → Implement Event.
  • Wire actor-specific logic to the Event OnInteract node and compile.
Example Implementation
BP_Door: Event OnInteract → FlipFlop → Timeline for door movement; Print String "Door Interacted by " + Get Display Name of Interactor.
Debugging tip
If your Message call does nothing, confirm the Actor has the interface added and that Event OnInteract was implemented and compiled.
Pro Tip
Add a Print String in each implementation to confirm which implementation runs during testing. This accelerates troubleshooting.
