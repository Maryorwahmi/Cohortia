Process Flow › Create a Blueprint Interface
Steps
  1. Right-click in Content Browser → Blueprints → Blueprint Interface. Name it BPI_Interactable.
  2. Open the asset and click + New Function. Name the function OnInteract.
  3. Add an input parameter Interactor : Actor Reference to pass the caller's reference.
  4. Compile and save. Remember: no implementation inside the interface asset.
Visual mnemonic
Think of the interface as a simple header file: it exposes function signatures so other Blueprints can implement them.
Example
Create BPI_Interactable with function OnInteract(Interactor : Actor Reference). Save and close. Later, add this interface to BP_Door and BP_Light and implement Event OnInteract.
Key Takeaway
Define message signatures once and reuse them. Interfaces hold only signatures, not logic.
