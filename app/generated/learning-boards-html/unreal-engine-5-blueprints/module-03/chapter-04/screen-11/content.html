Comparison › Interfaces vs Casting vs Event Dispatchers
Casting
Best when you know the exact class and need class-specific fields or functions. Creates tight coupling.
Use case
Calling HealPlayer on BP_HealthPack which only exists on that class.
Event Dispatcher
Broadcast pattern. Useful when one sender triggers many independent listeners without knowing them.
Use case
A lever broadcasts an OnLeverActivated event that multiple systems bind to.
Blueprint Interface
Defines a contract for targeted polymorphic behavior. Ideal when many different classes should respond to the same command.
Use case
Player calls OnInteract and doors, chests, and lights each implement it differently.
Decision Rule
If you need a shared behavior across types, use an interface. If you need broadcasting, use a dispatcher. If you need class-specific access, cast.
Pitfall
Overusing casts causes brittle code. Overusing dispatchers for one-to-one interactions can hide intent. Choose the pattern that matches the relationship.
