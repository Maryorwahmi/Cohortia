Chapter 3.4 › Key Concepts
Blueprint Interface
A contract of functions that many Blueprints can implement to respond polymorphically.
Message
A function declared in the interface and invoked at runtime via the Message node to reach the implementation.
Does Implement Interface
A guard node that confirms an actor supports the interface before you call a message.
Summary Takeaway
Design behavior contracts with interfaces, implement them per actor, and always guard and call messages using the proper nodes to keep your Blueprints flexible and maintainable.
