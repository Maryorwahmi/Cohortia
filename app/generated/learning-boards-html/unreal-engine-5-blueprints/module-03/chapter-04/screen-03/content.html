Activity: Universal Interactable System
Follow the guided steps: create the interface, add OnInteract with Interactor parameter, build BP_Door and BP_Light implementations, and wire player overlap and input to call the message.
Verification
Place door and light, play, walk up and press the interact key. You should see toggles and print strings.
Debug Tip
Use Print String after implementing OnInteract to confirm which actor received the message and who the Interactor was.
Assessment idea
Design an OnTakeDamage interface for enemies, implement it in multiple enemy Blueprints, and call it from player attack logic using Does Implement Interface.
Mnemonic
Contract → Implement → Call. Always check the contract before you call.
Common Mistake
Forgetting Implement Event in the Actor or using a direct function call instead of the Message node can cause the message not to run. Always use the Message node and a Does Implement Interface guard.
