Hands-on: Quest Log using an Array
Pseudo Blueprint flow to practice array operations and iteration.
Blueprint pseudo-code
// Variable: ActiveQuests : Array of Text
// Custom Event: AddQuest(QuestName : Text)
Add(ActiveQuests, QuestName)
PrintString("Quest Added: " + QuestName)

// Custom Event: CompleteQuest(QuestName : Text)
RemoveItem(ActiveQuests, QuestName)
PrintString("Quest Completed: " + QuestName)

// Custom Event: DisplayQuests()

// Event BeginPlay
AddQuest("Find the Lost Relic")

Explanation & checks
  • Use Add to append quests and Print String to confirm for debugging during development.
  • RemoveItem deletes the first matching quest name; if duplicates are possible consider additional logic.
  • DisplayQuests uses For Each Loop to safely access each element without index arithmetic.
  • On BeginPlay adding example quests lets you verify the flow immediately in the output log.
Common check
If RemoveItem seems not to remove anything, call Contains first to confirm presence, or print ActiveQuests.Length to ensure your array contains entries.
Key Takeaway

The quest log demonstrates declaring an Array, adding and removing items, and safe iteration with For Each Loop to display or process entries.
