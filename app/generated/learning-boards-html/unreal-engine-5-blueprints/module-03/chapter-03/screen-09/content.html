Iteration patterns: For Each Loop and safe mutation
How to iterate and mutate collections without introducing bugs.
Safe patterns
  • Use For Each Loop for Arrays and Sets to avoid manual index checks.
  • Collect changes in a temporary collection and apply them after the loop.
  • Alternatively, for arrays you can iterate backwards by index when removing items by index.
  • Check Contains and Length before removals to avoid no-op or errors.
Example
// Remove completed quests without mutating during loop
TempRemove = []
ForEachLoop(ActiveQuests) {
  if (IsQuestComplete(ArrayElement)) {
    Add(TempRemove, ArrayElement)
  }
}
ForEachLoop(TempRemove) {
  RemoveItem(ActiveQuests, ArrayElement)
}
Common mistake
Removing items directly inside the same For Each Loop leads to skipped elements or invalid indices. This especially shows up when you remove the current element — the loop’s internal index shifts and future elements can be missed.
Pro Tip
If you must mutate during iteration, iterate from the end to the start using indices and remove by index to avoid reindexing issues.
Key Takeaway

Iterate with For Each Loop for safety. Defer structural changes to after the loop or iterate backwards when removing by index.
