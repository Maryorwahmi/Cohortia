What to Remember
Key Concepts
Three concise cards you can recall during development.
Array
Ordered list with indices. Validate Index < Length or use For Each Loop.
Set
Unordered, unique elements. Best for deduplication and fast Contains checks.
Map
Key-value pairs. Use Find and branch on IsValid before using values.
Summary
Match the collection to the requirement: order, uniqueness, or keyed lookup. Apply defensive checks to prevent runtime errors and keep Blueprints predictable.
