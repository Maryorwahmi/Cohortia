Core Concept Definition
Maps — key-value associations
Fast, keyed lookup and storage for heterogenous data.
Explanation
  • Each key in a Map must be unique and maps to a single value.
  • Find returns a value and an IsValid boolean. Always branch on IsValid.
  • Add or Set will insert or update a key-value pair.
  • Use Keys and Values to extract arrays of keys or values when needed.
Concrete example
PlayerStats : Map(String -> Float). On BeginPlay Add "Strength":10.0, "Intelligence":8.0, "Agility":12.0. Use Find with IsValid to query safely.
Blueprint pattern: Safe Find
// Pseudo-Blueprint flow
FoundValue, IsValid = Find(PlayerStats, StatName)
if (IsValid) {
  StatValue = FoundValue
  PrintString(StatName + ": " + StatValue)
} else {
  // Initialize with default
  Add(PlayerStats, StatName, 0.0)
  PrintString(StatName + " not found!")
}
Use this branch to either use the found value or add a sensible default to keep state consistent.
Key Takeaway

Maps are for keyed lookups. Use Find and check IsValid before using values, and initialize defaults when keys are missing.
