Hands-on Activity: Build and test your collections
Step-by-step checklist to implement and validate your Array and Map examples.
Quest Log checklist
  1. Declare ActiveQuests : Array of Text.
  2. Create AddQuest(QuestName) -> Add + PrintString confirmation.
  3. Create CompleteQuest(QuestName) -> RemoveItem + PrintString.
  4. Create DisplayQuests() -> For Each Loop + Print each element.
  5. On BeginPlay add two quests and call DisplayQuests to confirm output.
Player Stats checklist
  1. Declare PlayerStats : Map(String -> Float).
  2. On BeginPlay Add initial stats and PrintString confirmation.
  3. Create GetPlayerStat(StatName) -> Find + Branch on IsValid.
  4. For missing keys print not found, set StatValue to 0.0, and optionally Add default to the Map.
  5. Test both found and not-found cases and inspect the output log.
Developer tip
Use Print String to confirm each operation during development. If you must change a collection while iterating, gather changes then apply them afterward to keep behavior predictable.
