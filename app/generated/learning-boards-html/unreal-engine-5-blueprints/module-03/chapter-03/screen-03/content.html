Learning Objectives — Continued
Practical design choices and defensive patterns to avoid runtime errors.
01
Choose Array, Set, or Map
Match order, uniqueness, and lookup needs to choose the right collection for gameplay data like inventories, discovered items, or settings. Verified Competency Milestone
Mnemonic: Order vs Unique vs Keyed.
02
Avoid index out of bounds
Check Length or use For Each Loop to guard array access and prevent crashes. Verified Competency Milestone
Mnemonic: Check before you Get.
03
Safe modification during iteration
Collect changes separately and apply them after a For Each Loop to avoid unpredictable behavior. Verified Competency Milestone
Mnemonic: Defer modifications.
04
Use Contains and Length checks
Before Remove or Get operations, verify the collection contains the item or has enough elements. Verified Competency Milestone
Mnemonic: Verify, then mutate.
