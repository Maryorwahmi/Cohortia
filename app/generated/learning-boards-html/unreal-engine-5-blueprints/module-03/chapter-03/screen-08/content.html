Choosing between Arrays, Sets, and Maps
Match order, uniqueness, or keyed lookup to select the best collection for gameplay needs.
Array
Ordered list, indexed access, duplicates allowed.
  • Use for hotbars, waypoints, or scripted sequences.
  • Operations: Add, Remove Index, Get, Set, Length.
  • Guard indices or use For Each Loop to iterate safely.
Set
Unordered, unique elements, fast Contains checks.
  • Use for discovered items, unique IDs, membership lists.
  • Operations: Add, Remove, Contains, To Array, Length.
  • Converting to Array gives you an ordered list if needed.
Map
Key-value pairs; keys are unique and map to values.
  • Use for settings, player stats, or lookups by ID.
  • Operations: Add/Set, Find (with IsValid), Remove, Keys, Values.
  • Always check Find.IsValid before using the returned value.
Quick decision
Ask: Do I need order, uniqueness, or keyed lookup? Then pick Array, Set, or Map respectively. Convert collections only when necessary and maintain defensive checks during access and mutation.
