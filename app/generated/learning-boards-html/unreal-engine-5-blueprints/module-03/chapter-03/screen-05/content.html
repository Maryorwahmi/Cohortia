Array operations — Add, Remove, Get, Set
Step-by-step use and safety checks for common array tasks.
1
Declare and Add
Create the Array variable and use Add to append new elements at runtime, like picking up items into inventory.
2
Remove Index / Remove Item
Remove Index deletes by position; Remove Item deletes the first matching value. Use Contains to guard removal when necessary.
3
Get / Set
Get returns a copy at an index; Set Array Elem updates the value at a valid index. Check Index < Length first.
Common mistake
Attempting to Get index 5 on an array with only 3 elements causes an index out of bounds crash. Always guard indices.
Concrete scenario: Quest removal
Suppose ActiveQuests is an Array of Text. When the player completes "Find the Lost Relic", call Remove Item(ActiveQuests, "Find the Lost Relic"). Then Print String "Quest Completed: Find the Lost Relic". If duplicates exist, Remove Item removes the first match; to clear all duplicates loop with Contains and Remove Item until Contains returns false, but be cautious when modifying during iteration.
Check your understanding
Why prefer For Each Loop for display? Because it guarantees valid access to each element and provides the index without manual bounds checks.
Key Takeaway

Manage additions and removals carefully, always validate indices, and avoid mutating the collection while iterating.
