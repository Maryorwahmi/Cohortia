Core Concept Definition
Arrays — ordered lists with indices
Access by numeric index. Use when order and position matter.
Explanation
  • Arrays store elements of the same type in a defined order and use 0-based indices.
  • Get returns a copy; Set Array Elem updates a specific index if valid.
  • Length returns the number of elements — always check Length before indexing.
  • For Each Loop is the preferred safe iteration method to avoid index errors.
  • Contains checks membership but may be slower than Set membership checks for large arrays.
Concrete example
A hotbar array of Text names: Add to append a new item, Set to update a slot, Remove Index to clear a specific slot.
Key Takeaway

Arrays give indexed access and ordered behavior. Validate indices or use For Each Loop to avoid crashes.

Common Array operations (visual)
Add
Appends an element to the end of the array.
Remove Index / Remove Item
Remove by position or by value; Remove Item deletes the first occurrence.
Get / Set Array Elem
Get returns a copy at index; Set replaces a value at index if Index < Length.
