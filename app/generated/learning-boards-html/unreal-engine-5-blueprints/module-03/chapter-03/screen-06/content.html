Core Concept Definition
Sets — unique, unordered collections
Use for membership tests and deduplication.
Explanation
  • Sets automatically ensure each element appears only once.
  • Contains is efficient for checking membership in large Sets.
  • You cannot access Set elements by index; iterate with For Each Loop or convert to Array.
  • Adding a duplicate element is a no-op — the Set remains unchanged.
Concrete example
Use a Set named DiscoveredItems (Text) to record unique quest IDs so each discovery only appears once, no matter how many times the player finds it.
Operations and patterns
Add / Remove
Add inserts if not present; Remove deletes a specific element.
Contains / Length / To Array
Use Contains for fast membership checks. Convert to Array when order or indexed access is required.
Common misconception
Do not assume a Set preserves insertion order. If you need ordered uniqueness, collect additions then copy into a sorted Array.
Key Takeaway

Use Sets for deduplication and fast membership checks; convert to Arrays if you must iterate in a specific order.
