Common mistakes and defensive checks
Small guards prevent the most common runtime errors.
Index Out Of Bounds
Check Index < Length or use For Each Loop. Attempting to access a missing index can crash your game.
Missing Map keys
Branch on Find.IsValid before using returned values. Initialize defaults when appropriate to keep state consistent.
Mutating during iteration
Collect removals or additions separately and apply them after the loop, or iterate backwards when removing by index.
Checklist
  • Before Get/Set: ensure Index < Length.
  • Before Remove: check Contains or Length > 0.
  • Before using a Map value: check Find.IsValid.
  • When iterating: avoid in-loop structural changes; apply changes afterwards.
