Learning Objectives
These skills will guide the hands-on activity and assessments.
01
Declare & initialize collections
Set variable type to Text, Integer, Actor Reference, then switch the type icon to Array, Set, or Map to create the collection variable. Verified Competency Milestone
Mnemonic: Type then Collection — "Pick the kind, then pick the container."
02
Perform common Array operations
Use Add, Remove Item/Index, Get, Set Array Elem, Length, and Clear to manage ordered lists. Verified Competency Milestone
Mnemonic: Add, Check, Use, and Clear — "ACUC" for array hygiene.
03
Iterate safely with For Each Loop
Use For Each Loop for arrays and sets to avoid manual index errors and to ensure every element is handled. Verified Competency Milestone
Mnemonic: For Each = Safety first.
04
Use Map.Find and check IsValid
Always branch on the IsValid output of Find before using the returned value to prevent missing-key errors. Verified Competency Milestone
Mnemonic: Find then Validate.
