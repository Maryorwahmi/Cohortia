Module 3 › Chapter 3.2 › Sequence Node
Definition & Example

Sequence fires multiple Then outputs in order. Use it to restore state or perform ordered but independent tasks from a single event.

Example
On Load -> Sequence: Then 0 restore health, Then 1 restore inventory, Then 2 refresh UI, Then 3 play sound.
Contrast: Sequence orders execution, it does not run tasks in parallel. For parallel or async work, use async nodes or delayed events.
Key Takeaway

Sequence organizes multiple post-event tasks into readable, ordered chains. Name tasks for clarity.

Pro-tip: Use small custom events connected to Then pins to keep the main graph tidy.
