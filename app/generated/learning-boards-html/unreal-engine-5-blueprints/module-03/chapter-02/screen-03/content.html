Module 3 › Chapter 3.2 › Objectives: Practice

Hands-on targets

  • Implement a TakeDamage event that reduces Health and uses a Branch to check Health ≤ 0.
  • Create an Inventory array and AddItem and DisplayInventory custom events using For Each Loop.
  • Place Print String nodes on Branch outputs and loop bodies to trace execution counts.
  • Set breakpoints on suspect nodes to inspect variables mid-execution.

Common checks

When a loop doesn't end, confirm a counter or flag changes inside the loop body. When a Branch goes the unexpected way, print the Condition value before the Branch so you can see what evaluated to true or false at runtime.
Danger: While Loops can freeze the game if unbounded
Pro-tip: Prefer For / For Each for predictable iteration
