Module 3 › Chapter 3.2 › Key Concepts
Branch Node
Executes True or False based on a Boolean condition for simple decisions.
For Loop
Iterates a fixed numeric range using First and Last indices; returns an Index each iteration.
For Each Loop
Iterates every element in an array; returns Array Element and Array Index. Do not mutate the array during iteration.
Summary

Branch chooses, For counts, For Each processes collections. Debug with Print Strings and breakpoints; guard While loops to prevent infinite loops.
