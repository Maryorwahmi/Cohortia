Module 3 › Chapter 3.2 › Loop Comparison
For Loop
Fixed iteration count, provides Index. Good for spawning a known number of actors or running a fixed number of ticks.
For Each Loop
Iterates arrays safely by element. Ideal for inventory displays, applying effects to a list of enemies. Do not mutate the array during iteration.
While Loop
Runs until a boolean becomes false. Use cautiously with guaranteed termination logic to avoid infinite loops.
Decision checklist
  • If you know the number of repeats, pick For Loop.
  • If you are processing an array, pick For Each Loop.
  • If you must run until a changing condition, pick While Loop and guard it.
