Module 3 › Chapter 3.2 › Health System
Step-by-step
  1. Create Float variable Health = 100.0.
  2. Add Custom Event TakeDamage(DamageAmount).
  3. Health = Health - DamageAmount; Print new Health.
  4. Branch: Condition Health ≤ 0.0 → True: Print "Player Died!" and Destroy Actor; False: Print "Player still alive!".
  5. Test using a BP_DamageVolume that calls TakeDamage on overlap.
Debugging
Place Print Strings and use breakpoints on the Branch to inspect Health values when testing. This shows exactly which path executed and why.
Concrete pseudo-Blueprint
[BP_DamageVolume OnOverlap]
  Cast To ThirdPersonCharacter
    -> Call TakeDamage(DamageAmount=25.0)

TakeDamage(DamageAmount)
  Health = Health - DamageAmount
  Print String "Current Health: " + Health
  Branch(Health <= 0.0)
    True -> Print String "Player Died!" -> Destroy Actor
    False -> Print String "Player still alive!"
This example ties editor actions to runtime behavior so you can iterate quickly during testing.
