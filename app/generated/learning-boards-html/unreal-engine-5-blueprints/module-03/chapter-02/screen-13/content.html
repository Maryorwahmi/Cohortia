Pseudo-Blueprint snippet
[Event or Custom Event]
  -> Get All Actors Of Class (Enemy_BP)
  -> Set EnemiesArray (local variable)
  -> For Each Loop (Input: EnemiesArray)
      Loop Body:
        Get Array Element (Enemy reference)
        Get Health (from Enemy reference)
        Branch (Condition: Health > 50.0)
          True -> Call ApplySlowEffect on Enemy
      Completed -> Print String "Slow effect application complete."
This structure shows both the wiring and the design reason: For Each is direct, readable, and avoids manual index handling.
Key Takeaway

Match your loop type to your data. For Each is ideal for collections; use Branch to filter inside the loop.
