Flow Control: Branches, Loops, and Sequences

Learn to guide execution in Blueprint graphs so your game can decide, repeat, and sequence behaviors reliably. We focus on Branch, For/While loops, For Each, Sequence, and debugging common flow errors.

Branch
If/Else on Booleans. Use for simple checks like player death.
Loops
Repeat actions with For, For Each, or While loops. Avoid modifying arrays while iterating.
Sequence
Run independent tasks in order, keeping your graph tidy and predictable.
