Module 3 › Chapter 3.2 › For Each Loop
What it provides
  • Array Element — the current item reference or value.
  • Array Index — the integer index of the current item.
  • Loop Body and Completed pins to structure follow-up work.
Use case: DisplayInventory prints each Array Element then prints "Inventory display complete." on Completed.
Key Takeaway

For Each simplifies arrays. Do not mutate the iterated array inside Loop Body; collect changes and apply them after Completed.

Concrete Example: Inventory display
DisplayInventory()
  For Each Loop (Input: Inventory Array)
    Loop Body -> Print String Array Element
  Completed -> Print String "Inventory display complete."
Safety note: If you must remove items, append them to a temp array and remove them after Completed fires.
Debug tip: Print the Array Index to see which positions are processed if items seem skipped.
