Bloom: Learn → Master

Learn the nodes, understand trade-offs, apply patterns, and master debugging
Learn → Understand → Apply → Master
01
Implement Branch logic
Use Branch nodes to split execution based on a Boolean. This lets gameplay respond to simple true/false checks, like player death.
VERIFIED COMPETENCY MILESTONE
02
Use For & For Each loops
For Loop repeats a set number of times; For Each walks every array element. Use them to spawn entities or display inventory reliably.
VERIFIED COMPETENCY MILESTONE
03
Understand While loop risks
While Loops run until a condition is false. They are powerful but can create infinite loops if not carefully controlled.
VERIFIED COMPETENCY MILESTONE
04
Sequence & Debugging
Use Sequence for ordered independent tasks and Print String / breakpoints to trace execution and locate flow bugs.
VERIFIED COMPETENCY MILESTONE

Mnemonic: Flow Patterns

Think of Branch as a fork in a path, For/For Each as loops around a track, While as a conditional treadmill, and Sequence as a checklist. These metaphors help choose the right node when designing gameplay systems.
Branch = decision fork
For = fixed-count loop
For Each = iterate collection
