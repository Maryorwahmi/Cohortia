Module 3 › Chapter 3.2 › Branch Node
Definition

A Branch node evaluates a Boolean Condition and fires either the True or False execution pin, directing the flow through one of two paths.

Example: Check player Health ≤ 0 to decide death.
Why it matters
Branch nodes let gameplay respond immediately to state changes so you can play sounds, destroy actors, or update UI based on conditions.
Common mistake: deeply nested branches make graphs hard to read and debug.
Key Takeaway

Keep Branch conditions simple; add Print String nodes on both outputs to confirm which path runs.

Concrete Example: TakeDamage event
TakeDamage(DamageAmount: float)
  Health = Health - DamageAmount
  Print String "Current Health: " + Health
  Branch (Condition: Health <= 0.0)
    True -> Print String "Player Died!" -> Destroy Actor
    False -> Print String "Player still alive!"
Debug
Place Print Strings on both outputs to see which path executes at runtime.
Pro tip
If a condition is complex, move it into a function that returns a boolean for clarity.
