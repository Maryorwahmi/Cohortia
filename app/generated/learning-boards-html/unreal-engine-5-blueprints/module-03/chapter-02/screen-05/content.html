Module 3 › Chapter 3.2 › For Loop
How it works
  1. First Index: starting integer.
  2. Last Index: ending integer (inclusive).
  3. Loop Body: executes each iteration with current Index.
  4. Completed: fires after loop ends.
Use case: Spawn five particle effects with positions based on Index.
Key Takeaway

For Loops are deterministic. Use them when you know the exact count and need an index for variation.

Concrete Example
ForLoop(FirstIndex=0, LastIndex=4)
  Loop Body (Index provided each iteration)
    Spawn Particle at Location + Index * Offset
Completed -> Print String "Spawn complete"
Misconception: For Loops are always better than For Each. Use For Each for arrays where index isn't known or safe indexing is needed.
Pro tip: Use Completed pin to run cleanup or to trigger a follow-up sequence.
