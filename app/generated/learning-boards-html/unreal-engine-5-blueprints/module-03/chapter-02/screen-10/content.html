Add & Display events
AddItemToInventory(ItemName: Text)
  Add ItemName to Inventory array
  Print String "Added " + ItemName + " to inventory."

DisplayInventory()
  For Each Loop (Input: Inventory)
    Loop Body -> Print String Array Element
  Completed -> Print String "Inventory display complete."
This approach gives immediate verification and is easy to extend to UI listing instead of print statements later.
Pickup actor test
Create BP_PickupItem with OnOverlap: cast to player, call AddItemToInventory("Health Potion"), call DisplayInventory, then Destroy Actor. Use this to confirm Inventory grows and For Each lists items.
Safety reminder
If you must remove entries while iterating, collect indices or items into a temp array and remove them after Completed to avoid skipped elements.
