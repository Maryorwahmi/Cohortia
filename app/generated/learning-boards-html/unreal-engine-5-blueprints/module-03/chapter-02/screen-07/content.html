Behavior & Risk

While Loops repeat until a boolean becomes false. They are dynamic but must include logic that will change the condition; otherwise you get an infinite loop and a locked game.

Danger: Infinite Loop! If your Condition never flips, gameplay will freeze or crash.
Mitigation: Decrement a counter or set a boolean flag inside the Loop Body so the Condition will eventually become false.
Recommendation: Prefer For / For Each when possible; use While in functions or when you truly need unknown-length repetition.
Practical guard

Add a max-iterations guard inside the loop to break out if something unexpected prevents the Condition from changing.

Concrete pattern
Counter = 10
While (Counter > 0)
  Do work
  Counter = Counter - 1
Completed -> Print String "While finished"
This pattern guarantees termination because the counter decreases each iteration.
