Trace steps
  1. Insert Print String on both outputs of a Branch to confirm which side runs.
  2. Print the Array Index or current value inside loops to count iterations.
  3. Use breakpoints to pause and inspect variable values mid-execution.
  4. If you suspect an infinite loop, add a temporary max-iteration counter to force termination and observe behavior.
Tip: Temporarily simplify complex conditions to isolate which sub-check is failing.
When stuck, test with small arrays or lower counts to make iteration issues obvious.
Key Takeaway

Combine prints and breakpoints to see execution order and variable changes. Prevent infinite loops with explicit guards.
