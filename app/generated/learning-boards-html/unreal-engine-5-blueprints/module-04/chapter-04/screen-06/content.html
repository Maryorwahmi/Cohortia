Process Flow

FItemProperties → BP_ItemDataAsset → Instances

1
Create Struct
Right-click → Blueprints → Structure. Name it FItemProperties and add ItemName, ItemIcon, BaseDamage, Weight, Description.
2
Make DataAsset class
Right-click → Blueprint Class → parent DataAsset. Name BP_ItemDataAsset and add a public variable of type FItemProperties.
3
Create instances
Right-click BP_ItemDataAsset → Create Data Asset. Fill fields for DA_Sword, DA_Shield, etc.
Visual checklist
  • Struct fields present and typed correctly (Texture2D, Float, Text).
  • BP_ItemDataAsset variable marked Instance Editable if you want in-editor overrides.
  • Instance DA_Sword shows filled values.
Common mistake & fix
If instance fields are missing, open BP_ItemDataAsset and make sure the Struct variable is public and of the correct Struct type; then recreate the instance.
Pro Tip

Name your instances clearly (DA_Sword, DA_Shield) so designers can find them quickly in the Content Browser.
