Retrieve rows with Get Data Table Row

Example: DT_Enemies → Goblin
// Event BeginPlay
-> Get Data Table Row (Data Table: DT_Enemies, Row Name: "Goblin")
// Out Row -> FEnemyStats struct, Return Value -> Found?
-> Branch (Condition: Found?)
    -> True:
        -> Break FEnemyStats (Health: GoblinHealth, Damage: GoblinDamage)
        -> Set Health on BP_Enemy instance
        -> Print String ("Goblin Health: " + GoblinHealth + ", Damage: " + GoblinDamage)
    -> False:
        -> Print String ("Row not found: Goblin")
Do this
Always Branch on the node's success boolean before breaking the struct.
Avoid this
Don't assume the row exists or pass a String instead of a Name for Row Name.
