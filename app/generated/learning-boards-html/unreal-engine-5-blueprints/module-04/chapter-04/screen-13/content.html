Module 5 › Chapter 4.4 › Key Concepts
FTableRowBase
Make your Struct inherit from FTableRowBase to use it as a Data Table row structure.
Get Data Table Row
Provides an Out Row struct and a success boolean; always branch on success before breaking the struct.
Row Name & Break Struct
Supply a Name literal for Row Name and Break Struct to access fields like Health and Damage.
Summary
Follow the checklist: inherit FTableRowBase, use Get Data Table Row with a Name and Branch, then Break Struct to use fields safely.
