Comparison

Data Asset

Best for single object configs, rich fields, and designer instances that include textures or nested data.
  • Good for: weapons, items, character class definitions.
  • Authoring: create instances in Content Browser.

Data Table

Best for many uniform rows that need keyed lookup and spreadsheet editing, like enemy stats.
  • Good for: DT_Enemies with Goblin, Orc, Dragon rows.
  • Authoring: fill rows in the table editor and access via Get Data Table Row.
Practical rule
If entries are many and uniform, prefer a Data Table. If entries are rich and designer-authored individually, prefer Data Assets. Combining both is common and powerful.
