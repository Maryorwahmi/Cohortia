Definition

Data Tables — spreadsheet-like collections

Data Tables store many entries in rows. Each row uses a Struct that must inherit from FTableRowBase so the editor can treat it as table rows.

  • Ideal for enemy stats, quests, or any list of similar entries.
  • Rows are accessed by a unique Row Name of type Name.
  • Designer-friendly spreadsheet interface for bulk editing.
Create a table
  1. Create Struct FEnemyStats and set its parent to FTableRowBase, then add Health, Damage, Speed.
  2. Right-click → Miscellaneous → Data Table and pick FEnemyStats as the row structure.
  3. Open DT_Enemies and add rows: Goblin, Orc, Dragon with appropriate values.
Common mistake

Using a String instead of a Name for Row Name in Get Data Table Row causes failed lookups. Use a Name literal.
