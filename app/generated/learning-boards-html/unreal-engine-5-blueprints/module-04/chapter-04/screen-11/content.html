Hands-on Activity

Build DA_Sword, DT_Enemies, and BP_DataDisplay

Item Data Asset
  1. Create Struct FItemDetails with DisplayName, Description, Icon, Value.
  2. Create BP_ItemDataAsset and add ItemDetails variable.
  3. Create DA_Sword and DA_Shield and fill their fields.
Enemy Data Table
  1. Create FEnemyStats inheriting FTableRowBase with Health, Damage, Speed.
  2. Create DT_Enemies and add rows Goblin, Orc, Dragon with values.
BP_DataDisplay template
// Variable: MyItemData (BP_ItemDataAsset Object Reference, Instance Editable)

Event BeginPlay
// --- Display Item ---
-> Get MyItemData
-> Get ItemDetails
-> Break FItemDetails (DisplayName, Value)
-> Print String ("Item: " + DisplayName + ", Value: " + Value)
-> Set Text (Text Render, DisplayName)

// --- Display Enemy ---
-> Get Data Table Row (DT_Enemies, Row Name: "Goblin")
-> Branch on Found?
    -> True: Break FEnemyStats (Health, Damage)
            Print String ("Goblin Health: " + Health + ", Damage: " + Damage)
