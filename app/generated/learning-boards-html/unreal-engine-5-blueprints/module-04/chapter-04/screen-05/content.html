Definition

Data Assets — what and when

Data Assets are reusable asset instances that hold structured data defined by a Struct. They are ideal for items, abilities, or class definitions that are unique but repeated across actors.

  • When to use: single objects with many fields or designer-authored variants.
  • Advantage: one place to edit an object's properties without touching actor Blueprints.
Key Takeaway

Use Data Assets for unique object definitions that multiple Blueprints can reference.

Creation steps
  1. Create a Struct (e.g., FItemProperties) with fields like ItemName, ItemIcon, BaseDamage.
  2. Create a Blueprint class with parent DataAsset named BP_ItemDataAsset.
  3. Add a variable of type FItemProperties and create instances via Content Browser.
Concrete example
DA_SwordOfPower with DisplayName "Excalibur", BaseDamage 42, Weight 5.0 set once and referenced by multiple BP_Item actors.
