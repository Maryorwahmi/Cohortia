Module 5 › Chapter 4.4 › Key Concepts
Data Asset
An asset that stores structured data for a single object instance, ideal for items and complex configs.
Data Table
A spreadsheet-style asset that stores rows keyed by Row Name and uses an FTableRowBase Struct.
Struct (Structure)
A schema grouping related variables; used by both Data Assets and Data Tables to define fields.
Summary
Structs define your data shape; choose Data Assets for single object instances and Data Tables for many keyed entries.
