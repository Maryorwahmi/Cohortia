Implementing an interface on Actors and Components
Add the interface in Class Settings and create the implementation event
Steps to implement
  1. Open the target Blueprint and go to Class Settings.
  2. Under Interfaces click Add and select your BPI asset.
  3. In My Blueprint find Interfaces and right-click the function → Implement Event.
  4. Write the event graph logic to respond to the message for this specific Blueprint.
Example: BP_Light
Add BPI_LightSwitch, implement ToggleLight to toggle the Point Light component's visibility or intensity. The event executes when the player calls ToggleLight on the actor.
Common mistake
If you don't see the functions under My Blueprint, confirm the interface is added to Class Settings. Implementing without adding it is not possible.
Key Takeaway

Interfaces are added in Class Settings; implementing the event is how the Blueprint supplies its unique behavior.
