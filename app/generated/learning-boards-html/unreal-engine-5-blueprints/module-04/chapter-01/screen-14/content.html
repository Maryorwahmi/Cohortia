Key Concepts
Three compact reminders to carry forward
Blueprint Interface
A contract defining messages any Blueprint may implement to respond to commands.
Interface Message
A declared function like Interact or ToggleLight that implementers define behavior for.
Decoupled Communication
Objects interact without knowing each other's concrete classes, improving modularity.
Summary
Use interfaces for targeted commands, check with Does Implement Interface, and add interfaces via Class Settings to implement behavior cleanly.
