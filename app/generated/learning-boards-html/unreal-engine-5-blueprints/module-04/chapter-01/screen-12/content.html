Hands-on: Build the light switch interactable
Follow the chapter's light switch example step-by-step
Blueprint template (visual pseudocode)
// BP_Light: Event ToggleLight (from BPI_LightSwitch)
Event ToggleLight
-> Get Point Light Component
-> Is Visible (Point Light)
-> NOT Boolean
-> Set Visibility (Point Light, New Visibility: [NOT Boolean result])

// Player: Input Action Interact
Input Action Interact (Pressed)
-> Sphere Overlap Actors (Radius 200)
-> ForEachLoop (TargetActor)
   -> Does Implement Interface (Object: TargetActor, Interface: BPI_LightSwitch)
   -> Branch (True) -> ToggleLight (Message) (Target: TargetActor)
Copy this structure into your graphs. The pre block is a readable blueprint-style template to implement node-for-node.
Practical checks
  • Ensure the Point Light intensity is 0.0 at start if you want it off by default.
  • Confirm the interface appears under My Blueprint before implementing ToggleLight.
  • Use print statements in ToggleLight to verify the event is called at runtime.
