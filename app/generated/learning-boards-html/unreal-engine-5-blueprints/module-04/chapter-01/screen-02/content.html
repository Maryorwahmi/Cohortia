Module 4 › Chapter 4.1 › Learning Objectives
Bloom: Learn → Understand → Apply → Master
01
Explain Blueprint Interfaces
Describe how an interface declares messages and allows multiple types to respond without casting. Knowing this reduces coupling across Blueprints.
VERIFIED COMPETENCY MILESTONE
02
Create Interface Assets
Add functions to a new Blueprint Interface asset to define the messages other Blueprints can implement, such as Interact or ToggleLight.
VERIFIED COMPETENCY MILESTONE
03
Implement on Actors & Components
Use Class Settings to add an interface and implement the declared functions so each Blueprint handles the message in its own way.
VERIFIED COMPETENCY MILESTONE
04
Call Messages Safely
Use Does Implement Interface before calling a message so you only send it to objects that can respond, avoiding silent failures and unclear logic.
VERIFIED COMPETENCY MILESTONE
