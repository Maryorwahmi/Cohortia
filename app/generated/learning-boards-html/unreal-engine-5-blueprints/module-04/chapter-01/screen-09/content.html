Player interact flow: Trace → Check → Call
Implement a robust player's Interact that works with many interactables
Example blueprint flow
// Input Action Interact (Pressed)
Input Action Interact (Pressed)
-> Sphere Overlap Actors (
   World Context: Self,
   Sphere Pos: GetActorLocation,
   Radius: 200.0,
   Out Actors: ForEachLoop)
-> ForEachLoop (Array Element: TargetActor)
   -> Does Implement Interface (Object: TargetActor, Interface: BPI_LightSwitch)
   -> Branch (Condition: Result)
       True: ToggleLight (Message) (Target: TargetActor)
       False: continue
This pattern keeps the player graph short and expressive. Use a break after calling if you only want a single target to respond.
Design choices
  • Use Sphere Overlap for short-range, multi-target interactions.
  • Use Line Trace for precise, aimed interactions.
  • Decide whether one or multiple targets should respond; use ForEach with optional break.
Key Takeaway

A short trace/check/call pattern keeps player logic stable while enabling any new implementer to respond without changes to the player blueprint.
