Create a Blueprint Interface asset
Step-by-step: declare messages that will be implemented later
Steps
  1. In Content Browser: right-click → Blueprints → Blueprint Interface. Give it a clear prefix like BPI_.
  2. Open the interface asset and Add New Function for each message you need.
  3. Design the function signature: add inputs for context, outputs for results. Keep them minimal.
  4. Save the asset. It now serves as a message contract other Blueprints can implement.
Design tip & example
Example: Create BPI_LightSwitch. Add ToggleLight with no inputs. For Interact patterns, include a PlayerController reference input so implementers know who asked for the interaction.
Misstep to avoid
Do not place implementation logic inside the interface asset. If you need shared helper code, use a shared function library or component, not the interface itself.
Mnemonic

Inputs carry context. Outputs return results. Interfaces only declare these pins.
