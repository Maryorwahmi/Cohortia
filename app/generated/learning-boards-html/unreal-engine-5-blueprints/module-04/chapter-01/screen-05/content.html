What is a Blueprint Interface?
A contract of messages that any Blueprint may implement
Definition & behavior
  • Contains function declarations only, no implementation.
  • Functions are called messages; they accept inputs and outputs like regular functions.
  • Any Blueprint can implement the interface and supply its own behavior for each message.
Concrete example
Create BPI_Interactable with Interact(PlayerController). BP_Door implements Interact to open; BP_Pickup implements Interact to add itself to inventory. The player only calls Interact and remains agnostic to the target's class.
When interfaces matter
Use interfaces when you want objects from different class hierarchies to respond to the same command. Interfaces are ideal for one-to-one or one-to-few commands where the caller wants to invoke behavior on a specific target.
Misconception check
Interfaces are not a replacement for all casts. If the caller needs proprietary data or methods only present on a single class, casting or a dedicated API may still be appropriate.
Key Takeaway

Interfaces declare messages so any implementing Blueprint can respond, keeping callers decoupled and flexible.
