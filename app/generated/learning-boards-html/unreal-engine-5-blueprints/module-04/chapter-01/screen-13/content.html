Debugging and common mistakes
Checks and tips when interface messages don't run as expected
Checklist
  • Interface added to Class Settings on target Blueprint.
  • Function implemented under My Blueprint (Implement Event).
  • Does Implement Interface returned true at runtime.
Runtime checks
  • Add prints in the implemented event to confirm execution.
  • Visualize traces/overlap radii while debugging.
  • Verify component names and targets inside implementation logic.
Common pitfalls
  • Forgetting to add the interface to Class Settings.
  • Calling the message without checking the interface first.
  • Expecting returned behavior without confirming the correct component is targeted.
Pro Tip

Add a small print string in every implemented event that includes the actor's name. That single line often reveals whether the message reached the intended target.
