Call Interface Messages safely
Use Does Implement Interface before sending messages
Pattern
Trace / Overlap → ForEach Actor → Does Implement Interface(BPI_X) → Branch → Call Message
This ensures that you only send the message to capable objects. The Does Implement Interface node acts like a capability check rather than an expensive cast chain.
Debug tip
Place a print string in the implemented event to see when the target responds. If the print doesn't appear, confirm the interface is added in Class Settings and the Does Implement Interface condition returned true.
Concrete example
Player performs Sphere Overlap Actors, loops results, uses Does Implement Interface with BPI_LightSwitch. If true, call ToggleLight on the actor to flip the light's visibility.
Key Takeaway

Always check Does Implement Interface before calling a message to avoid silent, hard-to-find failures.
