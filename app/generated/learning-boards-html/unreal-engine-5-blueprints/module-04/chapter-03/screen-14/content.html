Key Concepts — Nodes & Rules
Operational nodes and validation reminders
Create SaveGame Object
Instantiates the SaveGame class you will populate and save.
Save Game to Slot
Writes the populated SaveGame object to disk under the provided slot and user index.
Load Game from Slot
Reads the file and returns a SaveGame object you must cast to access your fields.
Final takeaway
Design SaveGame data deliberately, centralize slot naming, validate loads, and avoid saving direct actor references. These practices keep saves reliable and maintainable.
