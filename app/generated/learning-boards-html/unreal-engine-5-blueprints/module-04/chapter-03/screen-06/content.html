Load workflow
Does Save Game Exist → Load Game → Cast → Apply
1. Does Save Game Exist
Check for a save file before attempting to load to avoid None returns.
2. Load Game from Slot
Load the generic SaveGame object from disk using the same slot name and user index.
3. Cast and apply
Cast to your BP class, then set Health, Teleport player, and apply inventory contents with validation.
Key Takeaway

Always guard loads with existence checks and casting. Validate actors before applying saved state to avoid runtime errors.

Concrete scenario
On game start: if Does Save Game Exist returns true, Load Game from Slot, cast to BP_PlayerSaveGame, set player Health and Set Actor Location to SavedLocation. If false, initialize defaults like full health and spawn at start location.
Misconception
Assuming Load Game from Slot always returns your custom class. It returns a generic SaveGame; you must cast to access custom variables.
