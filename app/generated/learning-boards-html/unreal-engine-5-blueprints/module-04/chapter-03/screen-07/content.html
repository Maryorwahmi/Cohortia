Slot Names vs. User Index
Organize saves with consistent naming and explicit user indices.
Single-slot (auto-save)
Use one slot like "AutoSave" for periodic autosaves. Simple but risk overwriting progress if user expects multiple slots.
Multiple slots (manual saves)
Generate names like SaveSlot_0, SaveSlot_1 to let players choose where to save. Requires UI to select and manage slots.
User index
Use user index to separate local player saves. For single-player projects, use 0 consistently to avoid ambiguity.
Naming best practice
Centralize slot name creation in a small utility to avoid typos and accidental overwrites across blueprints.
