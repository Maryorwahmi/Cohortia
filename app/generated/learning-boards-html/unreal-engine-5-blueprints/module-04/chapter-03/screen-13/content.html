Key Concepts
Three compact cards to remember
SaveGame Blueprint
A BP inheriting from USaveGame used to declare saved variables.
Serialization
Converting SaveGame variables into storable data on disk.
Slot Name & User Index
A string and integer pair that uniquely identify save files for load/save operations.
Summary takeaway
Design SaveGame structures deliberately, centralize slot naming, and guard loads with existence checks to keep saves robust and debuggable.
