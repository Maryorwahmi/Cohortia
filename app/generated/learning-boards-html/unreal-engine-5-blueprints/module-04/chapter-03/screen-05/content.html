Save workflow
Create → Populate → Save
1. Create SaveGame Object
Instantiate BP_PlayerSaveGame using Create SaveGame Object.
2. Populate variables
Set SavedHealth, SavedLocation, inventory arrays and other fields from current game state.
3. Save Game to Slot
Call Save Game to Slot with the filled SaveGame object, slot name string, and user index.
Key Takeaway

Always populate the SaveGame object with current values before invoking Save Game to Slot. Use explicit slot names and user index for clarity.

Concrete scenario
Save on key press: Create SaveGame Object, cast to BP_MyPlayerSaveGame, Set SavedHealth = Health, Set SavedLocation = GetActorLocation, Save Game to Slot "PlayerSlot", User Index 0.
Common mistake
Saving without setting variables will write an empty snapshot. Always set fields on the SaveGame object instance first.
