Learning Objectives
A stepwise roadmap to reliable save and load behavior
Learn → Understand → Apply → Master
01
Explain SaveGame architecture
Describe USaveGame, custom SaveGame Blueprints, and how serialization works when saving to disk. This matters because it defines what is persisted.
VERIFIED COMPETENCY MILESTONE
02
Create SaveGame Blueprints
Define variables like health, location, and arrays in a BP that inherits from SaveGame so they are serialized automatically.
VERIFIED COMPETENCY MILESTONE
03
Implement save logic
Use Create SaveGame Object, set the variables, then call Save Game to Slot with an explicit slot name and user index.
VERIFIED COMPETENCY MILESTONE
04
Implement load logic and safety
Check for existence, load the slot, cast to your BP class, and apply the saved values; handle missing slots gracefully.
VERIFIED COMPETENCY MILESTONE
