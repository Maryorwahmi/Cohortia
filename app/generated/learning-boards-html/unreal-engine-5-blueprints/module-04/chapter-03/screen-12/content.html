Troubleshooting & Validation
Fix common mistakes that break saves or loads.
Forgot to populate
Always set SaveGame fields before calling Save Game to Slot. Verify by printing values before saving.
Wrong slot name or index
Centralize slot generation to avoid typos and mismatched names between save and load.
No existence check
Always call Does Save Game Exist before Load Game from Slot to prevent None returns and failed casts.
Actor references
Save actor identifiers instead of direct references, then rebind on load.
Separate saves
Use separate SaveGame BPs for settings and progress to avoid accidental overwrites.
Debugging tip
Print the populated SaveGame object's fields before saving and after loading to ensure data integrity.
