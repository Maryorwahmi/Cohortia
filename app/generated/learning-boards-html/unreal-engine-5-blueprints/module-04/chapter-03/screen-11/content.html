Lab: Save and Load Health & Location
A short checklist to produce a working save system in your character blueprint.
1. Create SaveGame BP
Right-click → Blueprints → SaveGame → BP_MyPlayerSaveGame. Add SavedHealth, SavedLocation, SavedPlayerName.
2. Character variables
Add Health variable to ThirdPersonCharacter and input actions for Save and Load keys.
3. Save sequence
Create SaveGame Object → Cast → Set fields → Save Game to Slot("PlayerSlot",0) → Print "Game Saved!"
4. Load sequence
Does Save Game Exist → Load Game from Slot → Cast → Apply fields → Print "Game Loaded!"; else Print "No Save Game Found!"
5. Test
Move and take damage, Save, change state, Load, and confirm health and location return to saved values.
6. Reflect
Consider how to extend to inventory, multiple slots, or actor state restoration using identifiers.
Key Takeaway

Follow the lab checklist and test using consistent slot names. Debug by printing saved values to ensure your SaveGame object has been populated before writing.
