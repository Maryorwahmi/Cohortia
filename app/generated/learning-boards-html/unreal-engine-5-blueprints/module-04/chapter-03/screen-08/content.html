Module 04 › Chapter 4.3 › Actor State
Actor state persistence
Persist identifiers and minimal fields, then rebind actors on load.
Save format
Create structs with ActorName (string) and state fields like IsOpen boolean or CurrentHealth.
Restore routine
After loading, for each saved actor entry find actor by name and set its properties. If not found, handle gracefully.
Design tradeoffs
Choosing the minimal set of fields reduces save size and simplifies restoration logic.
Example
To save a door: store DoorName (string) and IsOpen (bool). On load: Find Actor by DoorName and call SetIsOpen(IsOpen).
Common mistake
Attempting to save Actor references directly. Those references won't be meaningful after restarting the level or the editor.
