Module 04 › Chapter 4.3 › ThirdPersonCharacter Save/Load
Blueprint pseudocode
// Input Action Save (Pressed)
Create SaveGame Object (SaveGame Class: BP_MyPlayerSaveGame)
→ Cast To BP_MyPlayerSaveGame (As SaveRef)
  → Set SaveRef.SavedHealth = Self.Health
  → Set SaveRef.SavedLocation = Self.GetActorLocation()
  → Set SaveRef.SavedPlayerName = "Hero"
  → Save Game to Slot (SaveRef, "PlayerSlot", 0)
  → Print String "Game Saved!"

// Input Action Load (Pressed)
Does Save Game Exist ("PlayerSlot", 0)
→ Branch (If True)
  → Load Game from Slot ("PlayerSlot", 0)
  → Cast To BP_MyPlayerSaveGame (As LoadedRef)
    → Self.Health = LoadedRef.SavedHealth
    → Set Actor Location (Self, LoadedRef.SavedLocation, Teleport: True)
    → Print String "Game Loaded!"
→ Branch (If False)
  → Print String "No Save Game Found!"
Example test plan
Place player in level, take damage or move, press Save, then change position or damage, press Load and confirm health and position revert to saved values.
Pro Tip
Use descriptive saved player names in the SaveGame to help debug which save file is loaded during tests.
Key Takeaway

Follow the exact sequence: create, populate, save; check existence, load, cast, apply. Test by saving and restoring to confirm persistence.
