Blueprint template (visual)
// Event Dispatcher: OnBombExploded (Input: ExplosionLocation (Vector))

// Custom Event: ExplodeBomb
Event ExplodeBomb
-> Print String (In String: "Bomb Exploded!")
-> Apply Radial Damage (Damage: 100.0, Origin: GetActorLocation, Radius: 500.0)
-> Call OnBombExploded (ExplosionLocation: GetActorLocation)
-> Destroy Actor (Target: Self)

// Event BeginPlay
Event BeginPlay
-> Delay (Duration: 3.0)
-> ExplodeBomb
Explanation
  • The dispatcher carries the explosion location so listeners can react spatially.
  • Apply Radial Damage handles gameplay effects; other systems subscribe for visuals and audio.
  • Destroy Actor removes the bomb; listeners must bind to that specific bomb instance before it explodes.
Takeaway

Use dispatchers to notify multiple systems while keeping explosion logic localized.
