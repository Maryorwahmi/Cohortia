Module 4 › Chapter 4.2 › Bind and Unbind
Typical listener flow
  1. Obtain a reference to the broadcaster instance.
  2. In Event BeginPlay, call Bind Event To and Create Custom Event to handle broadcasts.
  3. Implement response logic in the custom event (turn on light, update HUD).
  4. In Event EndPlay, call Unbind Event From to remove registration.
Example: BP_Light
Bind Event To OnPressurePlateActivated

Create HandlePressurePlateActivated and in it call Set Intensity on the point light component.

Safety note

If BP_Light is destroyed while still bound, a later broadcast could call a missing function. Unbind in EndPlay to prevent this.
