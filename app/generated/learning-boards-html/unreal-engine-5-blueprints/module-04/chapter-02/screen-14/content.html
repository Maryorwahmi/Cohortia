Module 4 › Chapter 4.2 › Key Concepts
Event Dispatcher
A Blueprint delegate for one-to-many notifications.
Bind / Unbind
Register listeners in BeginPlay and remove them in EndPlay to avoid errors.
Dispatch vs Interface
Use dispatchers for notifications; use interfaces to command specific objects.
Summary takeaway

Design events that carry only the context listeners need, bind and unbind with actor lifecycles, and choose dispatchers when you want flexible, decoupled notifications.
