Common parameter types
  • Actor reference (who triggered the event)
  • PlayerCharacter reference (which player interacted)
  • Vector location (where an explosion or pickup occurred)
Design rule

Keep inputs minimal and strongly typed so listeners can use them without casting and you avoid unnecessary coupling.

Example
OnBombExploded(Vector ExplosionLocation)

Listeners use ExplosionLocation to display HUD text, spawn decals, or compute damage falloff.
