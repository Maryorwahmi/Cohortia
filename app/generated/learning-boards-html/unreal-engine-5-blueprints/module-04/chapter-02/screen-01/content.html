Event Dispatchers

Broadcast events to many listeners with optional parameters. Decouple the broadcaster from its reactions.

In this lesson

Create, call, bind, and unbind Event Dispatchers. Use inputs to pass context and safely clean up listeners.

Why it matters

Allows multiple systems — UI, audio, gameplay — to respond to a single event without tight coupling or hard references.

Quick example

A key Blueprint broadcasts OnKeyPickedUp with a player reference. The UI, a door, and a sound effect bind to that dispatcher and react independently.
