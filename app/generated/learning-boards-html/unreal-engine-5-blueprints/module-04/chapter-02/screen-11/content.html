Module 4 › Chapter 4.2 › Guided Lab: TriggerVolume
Lab steps
  1. Create BP_TriggerVolume and add Event Dispatcher OnActorEntered(Actor).
  2. In OnActorBeginOverlap check for player and Call OnActorEntered(OtherActor).
  3. Create BP_Light: bind in BeginPlay, HandleTriggerEnter sets point light intensity.
  4. Create BP_Alarm: bind in BeginPlay, HandleTriggerEnter plays alarm sound.
  5. Unbind in EndPlay for both listeners.
Checkpoints
  • Does the trigger broadcast when player enters?
  • Do both light and alarm react without direct references?
  • Are bindings removed when actors end play?
