Module 4 › Chapter 4.2 › Dispatchers vs Interfaces
Event Dispatcher

Best for broadcasting notifications without expecting a response. Decouples broadcaster and listeners.

  • One-to-many
  • No return values
  • Listeners bind at runtime
Blueprint Interface

Best for commanding a specific actor to perform a known action. Caller expects the target to implement the contract.

  • One-to-one or one-to-few
  • Defines function signatures
  • Requires target reference or casting
Decision rule

If you want to notify many systems with no direct response, use a dispatcher. If you want to command a particular object to do something and possibly receive a result, use a Blueprint Interface.
