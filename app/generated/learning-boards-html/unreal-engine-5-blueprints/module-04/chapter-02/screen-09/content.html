Event Construct
-> Get All Actors Of Class (BP_Bomb)
-> ForEachLoop (BombRef)
   -> Bind Event To OnBombExploded (Target: BombRef)
   -> Create Custom Event HandleBombExplosion (ExplosionLocation: Vector)
       -> Format Text: "Bomb Exploded at: {Location}"
       -> Set Text (YourTextBlock, FormattedText)
Notes & pitfalls
  • Binding applies to the instance; newly spawned bombs aren't auto-bound unless handled.
  • Unbind when the widget is destroyed or when bombs are removed to avoid stale references.
  • If many bombs exist, consider performance when calling Get All Actors Of Class frequently.
Practical tip

If bombs spawn dynamically, expose a register function on the HUD or emit a global registration event that the HUD listens to.
