Module 4 › Chapter 4.2 › What is an Event Dispatcher?
Core definition

An Event Dispatcher is a Blueprint delegate that allows a Blueprint to broadcast an event to many listeners. It can include input parameters so each listener gets context for the event.

Analogy

Think of a public announcement system: the speaker announces "Fire drill" and anyone tuned in reacts; the speaker doesn't need to know each listener.

Key takeaway

Dispatchers are for notifications; they transmit information to listeners, not commands to a single actor.

Concrete example
OnKeyPickedUp(PlayerCharacter)

When the key is collected, broadcast the dispatcher with the player reference. Any UI, door, or sound listener receives that player reference.

Common misconception

Dispatchers are not interfaces and don't guarantee execution order. Avoid relying on listener sequence or expecting a return value from listeners.
