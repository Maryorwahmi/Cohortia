Module 4 › Chapter 4.2 › Create an Event Dispatcher
Step-by-step
  1. Open origin Blueprint and locate My Blueprint > Event Dispatchers.
  2. Click +, name the dispatcher clearly, e.g. OnBombExploded.
  3. Add inputs if listeners need context (Actor, Vector, Player reference).
  4. Place a Call node where the gameplay event occurs to broadcast the dispatcher.
Dispatcher nodes
Call / Broadcast

Triggers the dispatcher and sends parameters to all bound listeners.

Bind Event To

Used by listeners to register a custom event or function to the dispatcher.

Unbind Event From

Remove a binding to prevent calls after the listener is destroyed.

Example

OnBombExploded(ExplosionLocation: Vector) lets UI and nearby actors know where the explosion occurred so they can respond appropriately.
