Checklist
  • Did you Call the dispatcher where the event occurs?
  • Are listeners bound to the correct actor instance?
  • Are listeners unbound when destroyed?
  • Are dispatcher input types correct and expected by listeners?
Debug tip

Add simple Print String nodes on the Call path and inside listener custom events to verify the entire chain executes.

Common errors
  • Binding to a CDO instead of an instance
  • Forgetting Unbind in EndPlay
  • Relying on listener execution order
