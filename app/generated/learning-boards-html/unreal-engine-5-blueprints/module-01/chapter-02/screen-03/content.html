Module 1 › Chapter 1.2 › Objectives — Practice
Tasks
  1. Create and place three Actors: a light, a static prop, an Empty Actor.
  2. Add a StaticMeshComponent to one Actor and assign SM_Cube or a starter mesh.
  3. Add a PointLightComponent and tweak intensity and color, then move the Actor to observe behavior.
  4. Create a folder in the World Outliner and drag Actors into it; use search to filter by type.
Assessment Ideas
Short quiz: identify which Component you need for a given feature. Practical check: show the nested Components under an Actor in the Outliner.
Common Mistake

Placing separate Actors for visuals and collision instead of composing them as Components on one Actor. This creates maintenance overhead.
