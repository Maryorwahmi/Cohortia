Module 1 › Chapter 1.2 › What are Components?
Definition
Components: focused, attachable modules

Components add visuals, collision, movement, perception, or audio to an Actor. They expose properties that you edit in the Details Panel.

StaticMeshComponent
Gives a visible 3D mesh.
PointLightComponent
Emits light from a point.
CameraComponent
Provides a view for the player.
CharacterMovementComponent
Supplies movement logic.
Common Mistake

Adding multiple Components that overlap in purpose rather than configuring a single appropriate Component leads to confusion and bugs.

Example: Lamp Actor
Attach a StaticMeshComponent for the lamp model and a PointLightComponent for illumination. Adjust the light intensity and move the Actor to see both components update together.
Pro Tip
Name Components clearly in the Details Panel so you can find them quickly in larger Blueprints.
Key Takeaway

Use Components to compose functionality. They keep features modular and reusable across Actors and Blueprints.
