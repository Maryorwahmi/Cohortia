Module 1 › Chapter 1.2 › Build BP_InteractiveLight
Lab Steps
  1. Create Empty Actor and name it BP_InteractiveLight.
  2. In Details Panel click + Add → Static Mesh → assign SM_Cube.
  3. Scale StaticMeshComponent to (0.2,0.2,0.2).
  4. Add PointLightComponent, set Intensity ≈ 5000 and pick a color.
  5. Expand outliner to see components nested, move root Actor to verify both move together.
  6. Create folder MyProps and drag the Actor into it, then save.
