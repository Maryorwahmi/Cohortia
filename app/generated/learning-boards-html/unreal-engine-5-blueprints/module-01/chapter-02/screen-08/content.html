Module 1 › Chapter 1.2 › Add & Remove Components
Step-by-step
  1. Select Actor in Viewport or Outliner.
  2. Open Details Panel and click green "+ Add".
  3. Search for "Static Mesh" and add StaticMeshComponent; assign SM_Cube.
  4. Click "+ Add" again and choose PointLightComponent; set intensity/color.
  5. Select a Component and press Delete to remove it.
Example Settings
StaticMeshComponent: assign SM_Cube and set Scale to (0.2,0.2,0.2).
PointLightComponent: set Intensity to 5000 and pick a color.
Pro Tip
Search the component list by typing part of the name to quickly find it instead of scrolling.
Key Takeaway

The Details Panel and the + Add flow are the canonical way to compose an Actor’s capabilities via Components.
