Module 1 › Chapter 1.2 › Key Concepts
Actor
Placeable object with transform.
Component
Reusable piece of functionality attached to an Actor.
World Outliner
Search and organize Actors at scale.
Summary Takeaway
Actors, Components, and Outliner workflows together provide a scalable pattern for building and managing game worlds in UE5. Practice composing components and organizing the Outliner early.
