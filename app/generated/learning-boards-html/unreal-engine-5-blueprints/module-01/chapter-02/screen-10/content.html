Module 1 › Chapter 1.2 › Common Components Compared
Comparison Table
StaticMeshComponent
Use for visible, non-animated geometry like props and level pieces.
PointLightComponent
Use to emit light from a single point; good for lamps and flares.
CameraComponent
Provides a viewpoint; attach to player or cinematic Actor.
CharacterMovementComponent
Handles character locomotion and physics-specific movement rules.
Scenarios
Static Lamp
StaticMeshComponent + PointLightComponent.
Camera Drone
CameraComponent + a movement component for flying behavior.
Animated Character
SkeletalMeshComponent + CharacterMovementComponent + collision component.
Key Takeaway

Choose components by responsibility and compose them to achieve complex Actor behaviors.
