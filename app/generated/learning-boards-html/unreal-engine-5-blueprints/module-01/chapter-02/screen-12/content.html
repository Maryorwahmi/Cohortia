Mini-Quiz
  1. Enemy character needs mesh, collision, movement — choose Components over separate Actors.
  2. Find all PointLight Actors — use Outliner search for "PointLight".
Correct Answer Hint
Compose a single Actor with StaticMeshComponent, CapsuleComponent, and CharacterMovementComponent.
Common Pitfalls
  • Leaving the Outliner unorganized.
  • Adding Components but not selecting them to configure properties.
  • Using separate Actors instead of composing Components, which splits behavior.
Practical Check
After adding Components, move the root Actor to verify children follow; if not, re-check attachment and parenting.
