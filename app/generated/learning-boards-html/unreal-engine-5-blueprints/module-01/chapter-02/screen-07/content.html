Key Actions
  • Search by name or type to filter Actors.
  • Drag to create parent-child attachments or reorder items.
  • Toggle visibility with the eye icon; lock selection with the padlock icon.
  • Create folders to group related Actors and reduce clutter.
Example
Type "PointLight" into the Outliner search to surface only light Actors, select them, and adjust intensity in the Details Panel.
