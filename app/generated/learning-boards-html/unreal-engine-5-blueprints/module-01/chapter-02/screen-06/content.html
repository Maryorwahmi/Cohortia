Claim
Parent transforms drive children

When a Component or Actor is attached to a parent Actor, it inherits location, rotation, and scale. This makes assemblies behave as a single unit when moved.

Example: Player Actor
CapsuleComponent + SkeletalMeshComponent + CameraComponent + MovementComponent.
Scenario: Light on Platform
Attach light to platform Actor so it travels with the platform during gameplay.
Visual: Tree View
ActorName
- Root: BP_Player
- CapsuleComponent (collision)
- SkeletalMeshComponent (mesh)
- CameraComponent (view)
Key Takeaway

Use attachment to build assemblies. Test by moving the parent — children should follow. If not, check attachment bindings.
