Module 1 › Chapter 1.1 › Editor Overview
Definition
A modular environment of panels for creating and managing real-time 3D content.
Project Browser
Start or open projects and select templates like Blank or Third Person.
Viewport
The real-time 3D window where you place and preview Actors.
World Outliner
A hierarchical list of Actors to find and select scene elements quickly.
Example
Create a project, drag a chair from the Content Browser into the Viewport, select it in the Outliner, then frame it with F.
Takeaway
Focus on repeated loops: create → place → select → adjust. Master the loop before exploring deeper menus.
Common misconceptions
  • Believing you must memorize all menus first. Instead, learn core stations and common actions.
  • Assuming the Content Browser auto-organizes assets. You must maintain folder structure for clarity.
  • Thinking the Viewport camera is limited; camera controls allow fast navigation with practice.
Key Takeaway

Adopt the stations metaphor and practice a simple create-place-adjust loop to build confidence fast.
