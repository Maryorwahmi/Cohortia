Module 1 › Chapter 1.1 › Details Panel
What you'll see
Transform values and component properties for the active selection.
Transform: Location, Rotation, Scale numeric fields for exact adjustments.
Static Mesh: which mesh the Actor uses and quick access to its asset.
Materials and Physics: change material slots or enable physics properties here.
Example
Select a cube, set Scale X/Y/Z to 0.5 for uniform shrink, then observe the change immediately in the Viewport.
Workflow tip
Use gizmos for quick alignment and numeric edits in Details for accuracy. After numeric edits, re-check the Viewport for visual confirmation.
Pro tip
When adjusting physics, tweak gravity and collision properties in Details and test using Play to confirm behavior.
Key Takeaway

The Details Panel turns selection into explicit control. Use it to move from imprecise dragging to intentional edits.
