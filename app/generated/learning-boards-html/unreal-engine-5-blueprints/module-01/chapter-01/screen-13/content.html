Module 1 › Chapter 1.1 › Mistakes & Practices
Common mistakes
  • Saving with vague project names or in hidden folders.
  • Dumping assets into the root Content folder and never organizing.
  • Relying only on dragging instead of using numeric precision in Details.
  • Not saving custom layouts, leading to repeated panel arrangement work.
Best practices
  • Make a small initial folder structure and stick to it.
  • Use the Outliner search + F to avoid getting lost in big scenes.
  • Combine gizmos for speed with numeric edits for precision.
  • Customize and save your layout and use Save All frequently.
Key Takeaway

Small, consistent habits prevent the biggest sources of friction: naming, organizing, framing, and saving.
