Module 1 › Chapter 1.1 › Hands-on Activity
Activity steps
1. Open Project Browser → Games → Third Person → Name MyFirstUE5Project → Create
2. Use RMB + WASD to move, Q/E to move vertically, Alt+mouse for orbit/pan
3. Select a cube in the Viewport and observe properties in Details
4. Use W/E/R to Move/Rotate/Scale; type numeric values for precision
5. In Content Browser: Content/StarterContent/Props → drag SM_Chair into Viewport
6. In Outliner: search for Chair and press F to frame → Save All
Reflection prompts
  • Which camera control felt natural, and which needs practice?
  • Did numeric edits in Details give better precision than dragging?
  • How did naming and folders help when you searched in the Outliner?
Common mistake
Forgetting to save layouts or using generic project names can cost time later. Save often and name sensibly.
Key Takeaway

Run this activity until the sequence becomes second nature; it's the foundation for faster scene building and Blueprints work later.
