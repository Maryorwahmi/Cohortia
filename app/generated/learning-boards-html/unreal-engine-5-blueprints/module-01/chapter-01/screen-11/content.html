Toolbar essentials
Save, Play, Build, and other frequently used editor commands for workflow speed.
Save All: keep assets and levels committed to disk frequently.
Play: test your level in the editor to verify interactions and physics.
Build Lighting: finalize static lighting for accurate visuals.
Modes Panel
Switch between Select, Landscape, Foliage, and Mesh Paint modes to change available tools.
Select mode: place and transform Actors.
Foliage mode: scatter plants and props using brushes.
Landscape mode: sculpt terrain and paint materials.
Example
Prototype level layout in Select mode, then switch to Foliage to quickly add vegetation for a more realistic scene.
Key Takeaway

Modes simplify the UI by exposing only relevant tools. Configure the Toolbar to include your most-used actions and save layouts to keep them handy.
