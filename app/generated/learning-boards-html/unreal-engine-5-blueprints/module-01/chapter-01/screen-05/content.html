Module 1 › Chapter 1.1 › Create Project
Step-by-step
1. Open Project Browser and choose a template such as Third Person.
2. Give the project a clear name like MyFirstUE5Project and choose a dedicated folder.
3. Click Create and wait for the Editor to load the default level and Content folder.
4. Immediately create top-level folders: Blueprints, Meshes, Materials to keep assets tidy.
Example scenario
You choose Third Person so the starter character and controller are in place. This lets you test movement immediately while you build the level.
Why it matters
Templates save setup time and provide functional examples to learn from. Naming and folders prevent confusion as projects grow.
Common mistake
Saving with names like Project1 or leaving assets in the root Content folder makes collaboration and debugging harder later.
