Module 1 › Chapter 1.1 › World Outliner
What it does
Lists all Actors in the level and shows hierarchical relationships for grouping and selection.
Search actors by name to find instances quickly in large levels.
Expand parent nodes to reveal child components for fine-grained selection.
Rename Actors with descriptive labels so the Outliner becomes a reliable index.
Example
Find "PlayerStart" by typing it into the Outliner search, select it, and press F to frame it in the Viewport.
Best practices
  • Name placed instances clearly (e.g., Chair_Lobby, Light_Main) for quick searches.
  • Use parent-child relationships to move groups together instead of each child separately.
  • Toggle visibility or lock Actors when editing crowded areas to avoid accidental selection.
Common mistake
Leaving Actors with default names makes searching unreliable; rename them as you add them to the scene.
Key Takeaway

Treat the Outliner as the definitive index of placed objects. Use search, naming, and parenting to keep scenes navigable.
