Tool mapping
W = Move, E = Rotate, R = Scale. Combine as needed for precise placement.
Move: drag the colored arrows or type Location in Details.
Rotate: use rings for orientation; numeric degrees give exact rotation.
Scale: use handles for quick size changes; type uniform values for consistent scaling.
Concrete example
Place a chair, press E, rotate 90 degrees to face the table, then press R and set uniform scale to 0.95 in Details to make it visually proportional.
Pitfall to avoid
Non-uniform scaling on parent objects can distort child components and break collision shapes. Prefer uniform scaling when consistency is needed.
Practice prompt
Select a mesh, use W to align, E to orient, and R with numeric edits to fine-tune size. Repeat until the placement looks natural.
Key Takeaway

Combine visual gizmos for speed and numeric fields for accuracy. Keep scale uniform when necessary to avoid component issues.
