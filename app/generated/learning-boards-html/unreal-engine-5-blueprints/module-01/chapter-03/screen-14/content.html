Module 2 › Chapter 1.3 › Key Concepts
Blueprint Visual Scripting
Create gameplay without text-based code by connecting nodes that represent events, actions, and data.
Event Graph
The central area where events like BeginPlay or ActorBeginOverlap are wired to actions such as Print String.
Compile & Save
Compile translates and validates the graph; save persists the asset so you can place and test it in the level.
One-line takeaway

Start small, compile often, and use event-driven logic for efficient, testable Blueprints.
