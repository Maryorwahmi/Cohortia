Module 2 › Chapter 1.3 › Create a Blueprint Class
Step-by-step
  1. In Content Browser, right-click → Blueprint Class.
  2. In Pick Parent Class, select Actor for props.
  3. Name asset like BP_MyFirstInteractiveObject.
  4. Double-click to open the Blueprint Editor.
Add a Component
Click Add > StaticMeshComponent, then assign SM_Cylinder and set scale to 0.5, 0.5, 0.5 if using StarterContent.
Key Takeaway

Choose the right parent class and give meaningful names to make iteration and collaboration faster.

Concrete Example
BP_WelcomeMessage: Actor parent, StaticMeshComponent with SM_Cylinder, event logic added in the Event Graph.
Common Mistake

Picking Character when you just need a prop adds unnecessary components and may confuse movement or collision expectations.
