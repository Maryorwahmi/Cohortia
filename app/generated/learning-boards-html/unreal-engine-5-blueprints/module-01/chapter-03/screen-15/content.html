Module 2 › Chapter 1.3 › Key Concepts
Blueprint Class
An asset that bundles components and visual logic; instantiate it in the level to test.
Execution vs Data Pins
White pins control flow; colored pins pass typed values. Match types when wiring.
Print String & Toggle
Print String for visible feedback; Toggle Visibility needs an explicit component Target reference.
Final takeaway

Small, testable Blueprints let you iterate quickly: build, compile, test, and repeat with clear naming and explicit references.
