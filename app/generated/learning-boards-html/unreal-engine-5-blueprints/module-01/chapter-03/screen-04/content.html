Module 2 › Chapter 1.3 › What is a Blueprint?
Definition

Blueprints are node-based assets that package components, variables, and event graphs into a reusable class. They can be placed in a level or instantiated at runtime.

Event: Event BeginPlay — fires once when the Actor spawns or the game starts.
Action: Print String — displays a text message on screen for debugging or feedback.
Data pins — carry values like text, numbers, or object references between nodes.
Key Takeaway

Blueprints expose logic visually and compile to executable code for safe, fast iteration.

Analogy

Imagine wiring small appliances: an event supplies power, action nodes are devices that perform a task, and data pins are the cords carrying values. The graph shows the wiring at a glance.

Common Misconception

Blueprints are not only for prototypes. They can be production-grade, but very low-level systems sometimes remain in C++ for optimization.

Example
Event BeginPlay → Print String("Hello from my first Blueprint!")
