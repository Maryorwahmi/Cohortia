Why Compile?
  • Validates connections and types.
  • Converts the graph into executable code for runtime.
  • Surfaces warnings and errors in the message log.
Common Errors & Fixes
Forgot to Compile — changes won't run until compiled.
Type mismatch — connect compatible data pin types or convert values explicitly.
Broken references — reassign components or variables if the asset was renamed or moved.
Procedure: edit graph → Compile (confirm green) → Save asset → Place in level → Play.
