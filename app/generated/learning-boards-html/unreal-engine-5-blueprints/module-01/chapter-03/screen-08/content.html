Execution vs Data
Execution pins (white) form the order; data pins (colored) pass values. Connect execution to execution, and match data pin types when wiring values.
Example: Event BeginPlay → Print String
Example: Drag StaticMeshComponent into graph → connect its reference to Toggle Visibility Target.
Checklist for wiring
  • Ensure execution wires end at a node that performs work.
  • Confirm data pin types match expected input types.
  • Provide explicit targets to avoid ambiguous references.
  • Compile to surface type or connection errors early.
Pro-tip: Pull component references into the graph rather than relying on implicit defaults — explicit targets reduce bugs.
