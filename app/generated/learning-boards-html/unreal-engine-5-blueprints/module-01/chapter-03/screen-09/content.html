Module 2 › Chapter 1.3 › Print String Walkthrough
Quick steps
  1. Find or add Event BeginPlay in Event Graph.
  2. Drag from the white execution pin and add Print String.
  3. Enter message: "Welcome to the game!" and set Duration to 5.0.
  4. Compile, then Save, place the Blueprint, and Play.
Debug tip: use Print String to confirm that a path executes, then replace with game feedback like sound or animation.
Pseudo-code representation
Event BeginPlay -> Print String(In String: "Hello from my first Blueprint!", Duration: 5.0)
If you see no output, check that the Blueprint instance is present in the level and that you compiled the Blueprint after editing.
