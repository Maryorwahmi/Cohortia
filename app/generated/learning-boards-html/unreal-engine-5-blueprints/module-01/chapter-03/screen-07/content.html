Default Events
  • Event BeginPlay — runs once at start, ideal for setup.
  • Event Tick — runs each frame, use sparingly for continuous updates.
  • Event ActorBeginOverlap — runs when something overlaps this Actor’s collision.
Misconception

Tick is not a substitute for event-driven logic. Many behaviors are efficient when driven by overlap or custom events instead of per-frame checks.

Visual Walkthrough (pseudo graph)
Event BeginPlay -> Print String("Welcome to the game!") Event ActorBeginOverlap -> Toggle Visibility(StaticMeshComponent) Event Tick -> (optional) UpdatePosition(DeltaTime)
Tip: Inspect the pins — execution pins are white and control flow, data pins carry parameters like strings or actor references.
