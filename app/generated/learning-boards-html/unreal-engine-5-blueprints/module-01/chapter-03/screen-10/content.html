Module 2 › Chapter 1.3 › Simple Toggle
Steps
  1. Add StaticMeshComponent and assign SM_Cylinder.
  2. Add Event ActorBeginOverlap in Event Graph.
  3. Drag StaticMeshComponent into graph and connect to Toggle Visibility Target.
  4. Compile, Save, place the Blueprint, and Play to test overlap.
Example Card
Event ActorBeginOverlap → Toggle Visibility(Target: StaticMeshComponent)
Common Mistake

Not specifying the Target lets the node operate ambiguously. Always drag the component reference into the graph and connect it explicitly.
