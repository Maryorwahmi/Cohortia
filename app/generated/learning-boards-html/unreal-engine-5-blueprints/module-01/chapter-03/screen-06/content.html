Module 2 › Chapter 1.3 › Blueprint Editor Panels
Components
Lists the Blueprint’s Components. Add StaticMeshComponent, Collision, or Audio components here. Drag a component into the graph to get a reference.
My Blueprint
Contains variables, functions, and event graphs. Use variables to store state like a boolean toggle for visibility.
Details
Shows editable properties of the selected object. Set default values, change meshes, or adjust collision settings here.
Event Graph (center canvas)
Events: triggers like Event BeginPlay, Tick, or ActorBeginOverlap.
Actions: Print String, Toggle Visibility, Set Location.
Pins: white execution pins, colored data pins passing values.
