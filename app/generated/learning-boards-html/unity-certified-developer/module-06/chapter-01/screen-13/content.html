Practical optimizations
  • Use Animator culling modes to stop updates for invisible objects.
  • Disable Animator components on distant actors that don't need animation.
  • Prefer simple scripted motion for background pieces instead of full state graphs.
Shared controllers
Sharing the same Animator Controller asset across many instances reduces asset duplication and helps consistent behavior. Use parameters to vary small differences.
Misconception
Assuming Mecanim is cost-free; it still consumes CPU when updating many animators or complex blend trees.
