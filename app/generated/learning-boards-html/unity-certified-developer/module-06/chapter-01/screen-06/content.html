Module 6 › Chapter 6.1 › Component vs Controller
Roles explained
Controller: an asset in Project that declares states and parameters. Animator: a component added to a GameObject that executes the controller.
Controller (Recipe)
Defines states, transitions, and parameters for animation logic.
Animator (Oven)
Attached to a GameObject; runs the controller and applies animation to transforms, renderers, or other properties.
Misconception check: Creating a controller without assigning it to the Animator component produces no playback. Always verify the Controller field in the Inspector for the object you expect to animate.

Common Mistake

Assigning the controller to a parent or another object unintentionally. Confirm the controller is on the intended GameObject.
