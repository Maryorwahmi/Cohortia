Module 6 › Chapter 6.1 › Debugging Tips
Checklist
  • Animator component exists and Controller is assigned.
  • Animator window shows an active state at runtime.
  • Parameter names match exactly between code and controller.
  • Transition settings like Has Exit Time align with expected responsiveness.
  • Imported clip rig matches your model and clips are saved in Assets.
Common scenarios
Scenario: Default state set but no animation plays. Likely causes: controller not assigned, clip missing, or Animator disabled. Scenario: Input feels unresponsive. Likely cause: Has Exit Time is checked on transitions.
Pro Tip
Watch the Animator window at runtime to see parameter values and active transitions in real time; this reveals whether your conditions are firing as intended.
