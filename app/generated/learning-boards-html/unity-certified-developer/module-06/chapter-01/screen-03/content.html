Module 6 › Chapter 6.1 › Objectives: Verify
01 Create & Assign Controller
Right-click Project > Create > Animator Controller. Select GameObject, add Animator component, then assign the controller in Inspector.
Verification: GameObject plays a default clip when you press Play if it has a default state.
02 Create Clips
Open Window > Animation > Animation, then Create. Record movement keyframes and save the clip in Assets.
Verification: Clip appears in Project and can be dragged into Animator to form a state.
03 Parameters & Code
Add float, bool, int, or trigger parameters in the Animator window. Use Animator.SetBool or SetFloat in C# to change them at runtime.
Verification: Toggling a parameter causes transitions when conditions are met.
04 Debugging Checks
Confirm Animator component exists, controller assigned, parameter names match code, and transitions have expected settings like Has Exit Time.
Verification: Use Animator window to watch states at runtime and check current state and parameter values.
VERIFIED COMPETENCY MILESTONE
Complete the hands-on platform activity and the debugging checklist to confirm these objectives.
