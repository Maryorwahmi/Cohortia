Module 6 › Chapter 6.1 › Create & Assign Controller
Editor steps
  1. 1. Right-click in Project > Create > Animator Controller. Name it clearly.
  2. 2. Select GameObject; add an Animator component in the Inspector if missing.
  3. 3. Drag the Animator Controller into the Animator component's Controller field.
  4. 4. Open the Animator window to inspect states and default state.
Verification: Press Play. If the default state is set and a clip is present, the GameObject should animate. If not, re-check the Controller field and the Animator component presence.
Visual checklist
Animator component
Must be on the GameObject that holds the model, sprite, or UI element.
Controller assigned
Controller asset must be placed into the Controller field in Inspector.
Default state
At least one state should be present and marked as the default state (orange).
Key Takeaway

A controller must be assigned to an Animator component on the GameObject; without that link, animations won't play.
