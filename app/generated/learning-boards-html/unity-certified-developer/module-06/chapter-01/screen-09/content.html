Module 6 › Chapter 6.1 › Driving Parameters
Pattern overview
Get or assign the Animator, then call SetBool, SetFloat, SetInteger, or SetTrigger in response to events or input.
Best practices
  • Cache Animator reference in Start for performance.
  • Guard against null references to avoid runtime errors.
  • Match parameter names exactly between code and controller.
Example script (visual only)
// Example: toggle a door open and closed public class DoorController : MonoBehaviour { public Animator doorAnimator; // assign in Inspector void OpenDoor() { if (doorAnimator != null) doorAnimator.SetBool("isOpen", true); } void CloseDoor() { if (doorAnimator != null) doorAnimator.SetBool("isOpen", false); } }
Key Takeaway

Keep animation control in the controller. Use scripts only to change parameters; this preserves blending and timing settings in the Animator.
