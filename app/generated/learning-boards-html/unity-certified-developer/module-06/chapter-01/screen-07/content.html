States and Default
Each state holds a clip or a blend tree. One state is the default and plays when the controller starts.
Example
Idle is default; when Speed > 0.1 transition to Walk.
Blend Tree (overview)
Blend Trees let a state blend multiple clips, driven by parameters like speed or direction.
Misconception
Assuming blend trees are separate from states. A blend tree is stored inside a state as the state's motion.
Animator window preview
Nodes: Idle (orange default), Walk, Run. Arrows: transitions. Parameters: Speed, Grounded.
Watch the orange highlight during Play to see which state is active; this is the fastest way to confirm a default state is working.
Key Takeaway

Name states clearly and set a meaningful default. Use parameters to choose between states at runtime.
