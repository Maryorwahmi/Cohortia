Module 6 › Chapter 6.1 › PlatformMover Lab
Setup summary
  • Create a Cube and add an Animator component.
  • Create PlatformAnimator and assign it to the Animator component.
  • Use Animation window to create PlatformUp and PlatformDown clips and save to Assets.
  • Add isMovingUp (bool) parameter and configure transitions with Has Exit Time unchecked and duration 0.2.
PlatformMover script (visual)
public class PlatformMover : MonoBehaviour { private Animator platformAnimator; private bool movingUp = true; void Start() { platformAnimator = GetComponent(); InvokeRepeating("ToggleMovement", 2f, 2f); } void ToggleMovement() { movingUp = !movingUp; if(platformAnimator != null) platformAnimator.SetBool("isMovingUp", movingUp); } }
Tip: If you used a public Animator field instead of GetComponent, assign it in Inspector. If clips don't animate, check that the clips are saved in the Assets folder and appear in the Animator window.
