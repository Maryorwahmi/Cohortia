Module 6 › Chapter 6.1 › Clips: Import vs Author
Imported clips
Models imported from 3D tools often contain animation clips which Unity extracts. Drag them into the Animator window to create states.
When to use
Use imported clips for complex character motion created in external tools.
Authoring in Animation window
Create a clip, press record, modify properties at keyframes, stop recording, and save the clip into Assets. Good for platforms, doors, and UI.
Common mistake
Forgetting to save a newly recorded clip into the Assets folder; unsaved clips can be lost.
Key Takeaway

Choose imported clips for rich character motion and the Animation window for quick, editable object or UI animations. Always save clips in Assets.
