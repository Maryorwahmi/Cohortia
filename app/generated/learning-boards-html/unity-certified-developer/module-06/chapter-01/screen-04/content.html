Module 6 › Chapter 6.1 › What is Mecanim?
Mecanim defined
A state machine system where an Animator Controller defines states and transitions, and an Animator component executes them on a GameObject.
Definition
States represent clips; transitions define when to change states.
Practical Example
Door controlled by a boolean parameter isOpen toggles between DoorOpen and DoorClose clips.
Common Mistake
Playing clips directly in scripts instead of using parameters prevents smooth blending and centralized control.
State machine sketch
Idle
Default state plays at start
Open
Triggered by parameter
How it connects
  • Parameter: isOpen (bool)
  • Transition condition: isOpen == true
  • Transition settings: Has Exit Time optional
Key Takeaway

Think in states and parameters. Use the Animator Controller to centralize behavior so code only changes parameters, not clips directly.
