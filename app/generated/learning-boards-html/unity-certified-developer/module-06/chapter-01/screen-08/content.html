Module 6 › Chapter 6.1 › Transitions & Parameters
Transition anatomy
Each transition can have conditions using parameters. Tweak Has Exit Time and Duration to trade off responsiveness and blend smoothness.
Parameter types
float, int, bool, trigger. Use the right type for comparisons and triggers for one-shot actions.
Timing settings
Has Exit Time, Transition Duration, Transition Offset control when and how blending occurs.
Common mistake
Leaving Has Exit Time checked yields delayed transitions when you expect immediate input response.
Example configuration
Idle → Walk condition: Speed > 0.1. Has Exit Time unchecked. Transition Duration: 0.2. Walk → Idle: Speed <= 0.1, same timing. This gives responsive, smooth blending.
Key Takeaway

Transitions are where gameplay meets animation. Tune Has Exit Time and duration for the feel you want, and always verify parameter values at runtime.
