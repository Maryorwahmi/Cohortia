Controller pattern
Instantiate, Play, Destroy
Raycast on input, Instantiate a particle prefab at hit point, Play or Emit, then Destroy after main.duration plus the maximum start lifetime to ensure full playback and cleanup.
Inspector: assign the ImpactDust prefab field to the prefab from the Project window, not a scene instance.
Common mistake: scheduling Destroy using hard-coded values instead of reading the system's main.duration and lifetime.
Starter code (concept)
// Conceptual snippet shown visually; use Inspector fields for prefabs.
public ParticleSystem impactDustPrefab;

void Update() {
  if (Input.GetMouseButtonDown(0)) {
    Ray ray = Camera.main.ScreenPointToRay(Input.mousePosition);
    if (Physics.Raycast(ray, out RaycastHit hit)) {
      var ps = Instantiate(impactDustPrefab, hit.point, Quaternion.LookRotation(hit.normal));
      ps.Play();
      Destroy(ps.gameObject, ps.main.duration + ps.main.startLifetime.constantMax);
    }
  }
}
Use this pattern and then test clicking on the Ground plane. Verify sparks from the sub-emitter appear at impact points and the instantiated objects are removed after playback.
Key Takeaway

Instantiate and destroy particle prefabs safely by computing lifetimes from the particle system settings to avoid leaks and truncated effects.
