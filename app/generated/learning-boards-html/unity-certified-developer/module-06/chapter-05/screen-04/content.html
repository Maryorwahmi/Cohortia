Module 6 › Chapter 6.5 › Sub-Emitters
Core Concept
What are Sub-Emitters?
A sub-emitter is a child particle system that a parent can spawn on specific particle events such as Birth, Collision, or Death. They let you compose multi-stage effects without coupling every behavior into a single system.
How to configure
Enable the Sub Emitters module on the parent and drag child systems into the event slots, then set an Emit Probability to control spawn rate.
Practical example
Explosion primary particles spawn smoke on Death; sparks spawn On Collision to mark impact points.
Common mistake
Forgetting to set Emit Probability or Max Particles, which can create far more children than intended.
Visual: Layered effect cards

Emit Probability
Lower probabilities limit spawned children so you can keep costs predictable.
Key Takeaway

Break complex VFX into event-driven child systems. Control spawn rates and particle caps to avoid runaway cost.
