Module 6 › Chapter 6.5 › Collision Module
Definition
Particles that react to colliders
Enable collisions so particles can bounce, stick, or be removed when they hit colliders. Choose World to hit all colliders or Planes for targeted surfaces.
Dampen
Reduces particle speed after impact to simulate energy loss.
Bounce
Fraction of speed retained for bouncing; higher values produce livelier ricochets.
Lifetime Loss
Shortens particle lifetime after collision so particles don't persist unexpectedly.
Practical setup & example
Example: For rain, set Dampen high and Bounce low so droplets disappear on impact. For sparks, set Bounce medium, Dampen low, and add a short Lifetime Loss so they fade after ricocheting.
Common mistake
Particles not colliding because the target collider is on a layer excluded from the Collision module. Verify layer masks and collider presence.
Tip
Use Planes for ground or simple surfaces to reduce per-particle collision math, improving performance.
Key Takeaway

Tune dampen, bounce, and lifetime loss to match the material impact and ensure colliders and layers are correctly set.
