Module 6 › Chapter 6.5 › Optimization
Primary controls
Limit, shorten, and simplify
Max Particles and Start Lifetime have the largest influence on simulation cost. Small textures and batching help rendering cost. Use culling and distance stop logic to reduce active systems.
1. Limit Particle Count — set Max Particles.
2. Short Lifetimes — fewer particles alive at once.
3. Small Textures — prefer 64/128 sizes.
Renderer & runtime tips
Batch materials, enable GPU instancing where supported, and use Culling Mode to avoid rendering off-screen systems unnecessarily. For non-visible heavy effects, Stop or Clear them based on distance checks.
4. Batching & Materials — fewer materials, fewer draw calls.
5. GPU Instancing — reduces draw calls for identical particles.
6. Prewarm — use for looping effects to avoid cold start, but only when needed.
Key Takeaway

Optimize iteratively: cap particles first, then reduce texture size and material count, and profile to confirm improvements.
