Module 6 › Chapter 6.5 › Lab Setup
Step-by-step
Create ImpactSparks
1) New Particle System → ImpactSparks. 2) Main: Looping off, Start Lifetime 0.5–1.0, Start Speed 5–10, Start Size 0.1–0.2. 3) Emission: add Burst count 10–20. 4) Shape: Sphere radius 0.05. 5) Renderer: assign SparkParticleMat (additive).
Ensure Color/Size over Lifetime for natural fade.
Set Gravity Modifier ~1 for believable falloff.
Step-by-step
Create ImpactDust and connect
1) New Particle System → ImpactDust. 2) Main: Looping off, Start Lifetime 1–1.5, Start Speed 2–4, Start Size 0.5–1.0, Max Particles 50. 3) Enable Texture Sheet Animation: Mode Grid, Tiles X=4, Y=4, Animation Random Row, Frame over Lifetime 0→1. 4) Enable Collision: Type World, Dampen 0.5, Bounce 0.2, Lifetime Loss 0.5. 5) Sub Emitters: add On Collision slot and assign ImpactSparks.
Key Takeaway

Follow the sequence: create sparks, create dust with sheet animation, enable collision, then assign sparks as an On Collision sub-emitter.
