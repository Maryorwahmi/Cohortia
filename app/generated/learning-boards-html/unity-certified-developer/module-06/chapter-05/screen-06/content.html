Module 6 › Chapter 6.5 › Triggers
Definition
Spatial event responses
Use triggers to run actions when a particle enters, exits, overlaps, or is inside a collider volume. Actions can change color, emit sub-effects, or stop particles.
Example
A water trigger turns sparks into muted splash particles and emits a splash sub-emitter on Enter.
Inspector setup
Enable Triggers, add collider references to Colliders list, and define actions for Enter/Exit.
Practical notes
Triggers do not produce physical bounce. Use them when you need logical changes or to spawn events that don't require per-particle physics calculations.
Common mistake
Expecting triggers to replace collisions. Use collisions for physics; triggers for state changes and event-driven spawns.
Tip
Combine triggers with minimal scripting for complex behaviors, like only spawning a sub-emitter once per particle group.
Key Takeaway

Use triggers for logical, low-cost changes in particle behavior; reserve collision for physics-based responses.
