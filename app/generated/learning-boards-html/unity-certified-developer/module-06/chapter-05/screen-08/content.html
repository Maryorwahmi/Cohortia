Methods
Play, Stop, Emit, Clear, IsAlive
Use these API calls to start and stop emissions in response to input or game events. Emit is useful for instant bursts, while Play/Stop suit looped systems.
Example pattern
Instantiate prefab at hit point, Play, then Destroy object after duration + lifetime to clean up.
Common mistake
Assuming Play creates a new instance; Play operates on the referenced system instance, so assign prefabs correctly in the Inspector.
