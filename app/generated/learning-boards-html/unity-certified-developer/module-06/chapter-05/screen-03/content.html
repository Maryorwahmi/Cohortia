Lab Objectives
Checkpoint style tasks to validate each skill during the interactive lab.
01
Projectile Trail
Create a continuous emitter used as a projectile trail. Verify it can be instantiated and plays on demand.
02
Collision Reaction
Enable collision and tune dampen and bounce so the effect looks correct when hitting surfaces.
03
Sub-Emitters
Attach a sparks system under On Collision to produce secondary effects at impact points.
04
Optimization
Set max particles, use small textures, and clear or stop off-screen systems to reduce runtime cost.
