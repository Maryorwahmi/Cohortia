Module 6 › Chapter 6.5 › Texture Sheet Animation
How it works
Sampling frames from a sprite sheet
Set Mode to Grid, specify Tiles X and Y, then select an Animation mode. Frame over Lifetime maps animation progress to particle life so frames advance predictably.
Modes
Random Row chooses a random horizontal row per particle; Whole Sheet steps through all frames across the grid.
Example
Dust set to Tiles X=4, Y=4 with Random Row and Frame over Lifetime from 0 to 1 completes a 16-frame cycle across a particle lifespan.
Common mistakes & tips
Mismatched Tiles X/Y cause wrong frames. Large textures increase memory; prefer 64x64 or 128x128 tiles when possible.
Tip
Coordinate Start Lifetime and frame speed so animation completes before particle ends, or use looping for continuous trails.
Optimization
Use small power-of-two textures to reduce memory and improve sampling speed on mobile and desktop.
Key Takeaway

Sprite-sheet animation gives rich motion at low material cost when tiles and timing are matched to the particle lifetime.
