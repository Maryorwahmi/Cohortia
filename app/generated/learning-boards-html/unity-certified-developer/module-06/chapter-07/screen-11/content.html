Module 7 › Chapter 6.7 › Lab Walkthrough
Starter scene checklist
  1. Create a Plane, add Cubes and a Sphere, add a Point Light or emissive material to a cube.
  2. Confirm URP is assigned in Project Settings > Graphics.
  3. Enable Post-processing in UniversalRenderPipelineAsset.
Example values: Bloom Intensity 0.6, Threshold 1.0; Vignette Intensity 0.35; Color Grading Post-exposure -0.2, Saturation -5.
Execution steps
Add Post Process Layer to camera and set Volume Layer to PostProcessing.
Create Global Volume, assign Layer, click New to make a Profile, then Add Override > Post-processing.
Tune Bloom, Vignette, and Color Grading while in Play mode to preview changes live.
Key Takeaway

Iterate in Play mode, verify the Global Volume is assigned, and use measured adjustments to reach the desired look without overloading performance.
