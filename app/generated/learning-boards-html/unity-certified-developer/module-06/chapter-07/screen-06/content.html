Module 7 › Chapter 6.7 › Bloom Details
Parameters
  • Intensity: amount of glow applied.
  • Threshold: minimum brightness to trigger bloom.
  • Scatter: spread radius of the glow.
Example: set Threshold to 1.0 so only emissive and very bright pixels bloom. Try Intensity between 0.5 and 1.0 as a starting point for stylized scenes.
Misconception: high intensity always improves visuals — instead it often flattens mid-tones and conceals detail.
Practical checklist
Test on emissive objects
Add an emissive material and tune Threshold until only the intended highlights bloom.
Balance with Color Grading
Reduce scene exposure or adjust post-exposure so Bloom doesn't dominate the frame.
Performance note
Bloom can be expensive; lower its resolution or intensity on low-end devices.
Key Takeaway

Bloom is powerful for drawing attention to bright sources. Use threshold and moderate intensity to preserve scene contrast and test performance impact.
