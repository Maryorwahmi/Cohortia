Module 7 › Chapter 6.7 › URP Setup Steps
Step-by-step checklist
  1. 1. Enable Post-processing in your UniversalRenderPipelineAsset.
  2. 2. Add a Post Process Layer component to Main Camera and create a layer named "PostProcessing".
  3. 3. Create a Global Volume, set its Layer to PostProcessing, and click New to make a Volume Profile.
  4. 4. Open the Volume Profile and add effect overrides such as Bloom and Color Grading.
Common mistake: forgetting the pipeline-level toggle or having mismatched Volume Layer assignments.
Live example to try
Create a small scene with a ground plane and an emissive cube. Add a GlobalPostProcessVolume, enable Bloom with intensity 0.8 and threshold 1.0. Enter Play mode and adjust intensity to see the glow in real time.
Check
Is the Bloom visible? If not, re-check URP asset and Volume Layer settings.
Tip
Edit the Volume Profile while Play mode is running to preview real-time changes.
Key Takeaway

Follow the setup order and verify each step: pipeline, camera, layer, volume, profile. Mismatches at any stage prevent effects from appearing.
