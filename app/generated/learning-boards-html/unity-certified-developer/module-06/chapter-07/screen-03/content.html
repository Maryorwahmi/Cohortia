Practice Task: Diagnose Visual Problems
List and fix two visual issues in a test scene using one post-process effect each.
Example: add an emissive cube and tune Bloom until glowing elements read at distance. Misconception: larger intensities always help — they can reduce contrast and hide details.
VERIFIED COMPETENCY MILESTONE
Practice Task: URP Post-process Setup
Enable post-processing flag in URP Asset and assign the Post Process Layer to Main Camera.
Why it matters: the pipeline-level switch is required; forgetting it is a frequent blocker. Milestone: toggled pipeline flag and visible effect in Play mode.
VERIFIED COMPETENCY MILESTONE
Practice Task: Add Key Effects
Add Bloom, Vignette, and Color Grading to a global Volume and preview changes in Play mode.
Example: desaturate colors slightly to create a gritty tone. Misconception: more saturation equals better visuals — not always; it can distract from gameplay clarity.
VERIFIED COMPETENCY MILESTONE
Practice Task: Profile and Optimize
Use Unity Profiler to measure GPU cost before and after toggling expensive effects.
Tip: reduce sample counts or resolutions for Depth of Field and Ambient Occlusion to trade quality for performance. Milestone: recorded a frame and identified post-processing cost.
