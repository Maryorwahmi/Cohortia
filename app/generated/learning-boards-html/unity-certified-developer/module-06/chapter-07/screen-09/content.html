Module 7 › Chapter 6.7 › Global vs Local Volumes
Global Volume
When Is Global is checked, the Volume's Profile applies to the entire scene unconditionally. Use it for base look and overall color grading.
Example: A GlobalPostProcessVolume sets default Bloom and Color Grading for the whole level.
Misconception: local volumes override global ones completely — they blend based on blending parameters and priority.
Local Volume
Local Volumes need a Collider and apply only when the camera is inside. Use them for environment-specific looks like caves or interiors.
Example: a cave interior local Volume lowers exposure, increases Vignette, and adds cool color grading.
Common mistake: forgetting to set the Volume's Layer to the camera's Volume Layer or omitting the collider entirely.
Blend and priority
Volumes blend by weight and respect priority. Use priorities to control which volume dominates overlapping areas.
Collider requirement
Local volumes require a collider to define bounds. Use triggers for smooth entry and exit.
Key Takeaway
Use Global Volumes for base looks and Local Volumes to provide contextual, area-specific visual changes that enhance immersion.
