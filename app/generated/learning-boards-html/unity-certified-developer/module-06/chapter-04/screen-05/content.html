Module 6 › Chapter 6.4 › Create a Particle System GameObject
Process

Quick setup steps

  1. Create: Hierarchy › Effects › Particle System. Name it clearly.
  2. Preview: use the Particle System preview to play and pause the simulation.
  3. Main: toggle Looping, set Start Lifetime, Start Speed, and Start Size.
  4. Emission: set Rate over Time or add Bursts for one-shot effects.
  5. Shape: choose Cone, Sphere, Box, or Edge and adjust size properties.
  6. Renderer: assign a particle material so particles are visible.
Common mistake

Using high rates and lifetimes before testing makes it hard to iterate and can hide shader problems or performance bottlenecks.

Example

Create a looping smoke: Looping on, Start Lifetime 3, Start Speed 0.5, Rate over Time 12, Shape = Cone with small angle.

Checklist
  • Named GameObject
  • Assigned material
  • Preview is readable
Why it matters

A disciplined creation workflow prevents wasted time and reduces trial-and-error when tuning visual parameters.
