Core Module

Main Module Properties

Duration / Looping
Controls how the system repeats over time.
Start Lifetime
How long each particle lives; longer life increases overlap and density.
Start Speed
Initial velocity that can be combined with gravity to shape motion.
Start Size
Initial size; often paired with Size over Lifetime for growth or shrinkage.
Start Color
Single color, gradient, or random between two to add variety.
Gravity Modifier
Simulates gravity influence; small positive values make particles fall or sink.
Key Takeaway

Main is the single place to set lifecycle and baseline physics for particles; tune here first, then refine with other modules.

Concrete example

Flame: Start Lifetime 1–2s, Start Speed 1–2, Start Size 0.5–1, Gravity Modifier 0.1. Smoke: Lifetime 3–5s, Speed 0.2–0.6, Size larger.

Misconception

Changing material shaders does not alter particle lifetimes or speeds; those are set in the Main module.

Check

Adjust Max Particles to cap worst-case cost and watch the preview to ensure visual fidelity remains acceptable.
