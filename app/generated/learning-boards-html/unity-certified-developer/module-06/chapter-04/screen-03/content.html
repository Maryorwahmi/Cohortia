Learning Objectives — Practical Steps

Concrete verification steps to prove each skill.

Bloom: Apply → Master
01 Create & Preview

Make a Particle System GameObject and use the preview controls to play, pause, and restart the simulation until the motion reads correctly.

Visual mnemonic: small play icon = preview
02 Adjust Main & Emission

Change Start Lifetime, Start Speed, and Rate over Time; confirm continuous vs burst behavior visually.

Visual mnemonic: timeline strip = lifetime
03 Assign Materials

Create or assign a particle material with Additive or Alpha Blended shader and a soft texture to validate transparency and glow.

Visual mnemonic: layered circle = texture
04 Optimize & Measure

Set Max Particles, reduce rates, and use culling for off-screen systems. Iterate until performance targets are met.

Visual mnemonic: speedometer = performance
Tip: verify one visual goal at a time. First get the look right, then reduce the particle budget while keeping the effect readable.
