Learning Objectives

Concrete skills to build and optimize particle effects in Unity.

Bloom: Learn → Understand → Apply → Master
01
Identify core modules

Recognize Main, Emission, Shape, Color over Lifetime, Size over Lifetime, and Renderer and describe their purposes in two sentences.

VERIFIED COMPETENCY MILESTONE
02
Create a basic effect

From the Hierarchy create a Particle System and iterate using the preview to reach a simple smoke or fire look.

VERIFIED COMPETENCY MILESTONE
03
Assign correct materials

Choose additive or alpha blended particle shaders and apply soft textures to get correct transparency and glow.

VERIFIED COMPETENCY MILESTONE
04
Optimize for performance

Limit particle counts, set Max Particles, use simple textures, and cull off-screen systems to avoid frame drops.

VERIFIED COMPETENCY MILESTONE
Practice tip: start with visually correct settings, then progressively reduce rate and lifetime until performance goals are met.
