Module 6 › Chapter 6.4 › Color & Size over Lifetime
Definition

Color over Lifetime & Size over Lifetime

Color over Lifetime uses a gradient to map color and alpha across a particle's life. Use it to fade particles to transparent or change hue as they age.

Size over Lifetime uses a curve so particles can grow then shrink, or follow any size envelope you design.

Together they allow the same particle to look different at spawn and at death, adding realism.

Concrete example

Explosion: Color gradient yellow → orange → red → transparent black. Size curve: start at 0.1, grow to 1.0 at 25% life, then shrink to 0.

Common mistake

Relying on a static Start Color hides temporal changes; gradients are needed to represent fading or hue shifts properly.

Key Takeaway

Use gradients and curves to animate particle color and size over time; this is how motion and depth are sold to the eye.
