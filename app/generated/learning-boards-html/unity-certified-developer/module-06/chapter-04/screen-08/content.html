Comparison

Shape choices

Cone: Directional emission for flames, jets. Adjust angle and radius for spread.
Sphere: Radial bursts like explosions. Particles radiate outward equally.
Box: Area-based emission for rain or fog that fills a rectangular volume.
Edge: Line emitters for trails or effects along a border.
Practical tip

Swap shapes while keeping other settings identical to quickly see which origin best matches your visual intent.

Example

Torch flame: Cone with small angle and radius 0.1–0.2. Snowfall: Box with large Y extent spread over scene area.

Misconception

Shape scale changes emission origin, not sprite size. Use Start Size or Size over Lifetime to change particle scale.

Check

Confirm behavior by toggling Shape and reusing the same Start Speed and Lifetime to focus evaluation on origin differences.
