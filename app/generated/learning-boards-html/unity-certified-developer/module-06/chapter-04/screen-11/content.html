Configure ExplosionEffect

Main
Looping off, Start Lifetime 1.5, Start Speed 5, Start Size 0.5, Max Particles 100.
Emission
Rate over Time = 0, add Burst at time 0 Count = 50.
Shape
Sphere, Radius 0.1 for tight origin.
Over Lifetime
Color gradient yellow→orange→transparent black; Size curve quick grow then shrink.
Trigger Script (attach to ExplosionTrigger)
using UnityEngine;

public class ExplosionTrigger : MonoBehaviour
{
    public ParticleSystem explosionParticleSystem; // Drag ExplosionEffect here
    private bool hasExploded = false;

    void Start()
    {
        if (explosionParticleSystem != null)
            explosionParticleSystem.Stop();
    }

    void Update()
    {
        if (Input.GetKeyDown(KeyCode.E) && !hasExploded)
        {
            TriggerExplosion();
            hasExploded = true;
        }
    }

    void TriggerExplosion()
    {
        if (explosionParticleSystem != null)
            explosionParticleSystem.Play();
    }
}
Common setup mistake

Ensure Looping is unchecked for one-shot explosions and that the ParticleSystem field is assigned in the inspector.

Why it matters

On-demand one-shot effects save performance compared to continuously looping systems and are ideal for impact events.

Testing tip

Press the trigger key and watch the preview while adjusting burst count and lifetime until the blast timing feels right.

Try this

After the explosion plays, experiment with Gravity Modifier to add downward motion to debris-like particles.
