Process

Rate vs Bursts

Rate over Time: controls a continuous emitter. Start low and increase until density looks right.

Rate over Distance: useful for trails generated by moving objects.

Bursts: schedule instant emissions — perfect for explosions and impact bursts.

Example

Explosion: Rate over Time = 0, add a Burst at time 0 with Count = 50, then set Start Speed high and Lifetime short for an expanding cloud.

Tuning tip

When using bursts, temporarily reduce Max Particles to see immediate effects without performance spikes during iteration.

Common mistake

Combining large Rate over Time with large bursts can create orders-of-magnitude more particles than intended.

Check

Verify the visible result by toggling Looping and playing the preview to ensure continuous and burst behaviors read correctly.
