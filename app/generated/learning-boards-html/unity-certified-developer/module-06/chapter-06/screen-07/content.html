Math Nodes

Transform inputs into the shapes and ranges you need for blending and animation.

Sine
Oscillates between -1 and 1
Multiply
Scales values
Remap
Convert ranges
Lerp
Linear blend between A and B by T
Concrete example

Create a pulsing intensity: Time × speed → Sine → Remap (-1..1 to 0..1) → use as T in Lerp between two colors or multiply a color by intensity.

Type compatibility

Ensure you connect Vector1 outputs to float inputs and Vector3/4 to vector inputs. Some nodes accept multiple types but others are strict.

Common Mistake

Expecting Lerp to ease results. Lerp is linear; add Smoothstep or custom curves for eased blends.

Key Takeaway

Combine a few math nodes to convert Time into usable blend factors and expose speed for designer control.
