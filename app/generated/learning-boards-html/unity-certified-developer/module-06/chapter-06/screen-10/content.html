Module 6 › Chapter 6.6 › Hands-on Activity
Setup checklist
  • Create URP project or enable URP in your project.
  • Create PulsingGlowShader (Unlit) and PulsingGlowMat.
  • Create PulsingSphere and assign the material.
Runtime tuning

While the scene runs, open the Material Inspector and change _GlowColor and _PulseSpeed. Observe how the pulse frequency and brightness respond immediately, allowing rapid visual iteration.

Try this
  • Set _PulseSpeed to 0.1 for a slow breath and 4.0 for a fast strobe.
  • Change _GlowColor HDR intensity to test emission visibility in bright scenes.
Debug checklist
  • Did you save the Shader Graph after edits?
  • Is your project using URP or HDRP?
  • Are the expected properties visible in the Material Inspector?
Key Takeaway

Testing in play mode with exposed properties encourages fast, designer-friendly iteration and reveals tuning that static previews can miss.
