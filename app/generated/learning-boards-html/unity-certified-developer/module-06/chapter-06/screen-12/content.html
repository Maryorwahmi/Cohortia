Color Nodes

Blend, Gradient Sample and Color properties let you craft palettes and transitions. Gradient Sample maps a scalar to a color ramp for creative control.

Example

Use a remapped Time scalar as input to Gradient Sample to sweep colors across a plane over time.

Utility Nodes

Split and Combine extract and rebuild vector components. One Minus inverts values for masks. Use these to create precise masks and compositing control.

Performance note

Every additional texture or gradient sample increases GPU work. Cache results in intermediate nodes rather than sampling repeatedly.

Key Takeaway

Use color and utility nodes to create flexible, tweakable effects. Minimize redundant texture sampling for better performance.
