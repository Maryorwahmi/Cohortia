Practical skills

These objectives map to tangible editor steps and debugging checks you will use when authoring effects.

Pipeline setup
  • Ensure project uses URP or HDRP before creating Shader Graph assets.
  • Upgrade materials or create a new URP project when necessary.
Expose and test properties
  • Create Color and Vector1 properties to let designers tweak results through the Material Inspector.
  • Adjust values in play mode to confirm live response.
Animation with Time
  • Use Time → Sine → Remap to produce a 0–1 oscillation and feed into Lerp or Multiply.
  • Control speed using an exposed Vector1 property.
Debug & optimize
  • Check Master Node type, node connections, and save the graph to apply changes.
  • Minimize texture samples and avoid redundant math to keep GPU cost low.
