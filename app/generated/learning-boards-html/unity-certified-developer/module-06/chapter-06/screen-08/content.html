Module 6 › Chapter 6.6 › Color-Transition Shader
Quick steps
1. Create Unlit Graph
2. Add Color props
3. Time × Speed → Sine
4. Remap -1..1 → 0..1
5. Lerp → Master Color
Explanation
  • Time provides a continuously increasing value used as the animation driver.
  • Sine produces a smooth oscillation which we remap to a 0–1 range for blending.
  • Lerp blends between two color properties using the remapped oscillation as the blend factor.
Example material properties
_ColorA: neon blue (HDR), _ColorB: hot pink, _Speed: 2.0
Concrete test

Create a sphere named PulsingSphere, assign the Material that uses the graph, and run the scene. Tweak _Speed to make the transition faster or slower.

Common Mistake

Not saving the graph or not using URP/HDRP will make the material appear black or unchanged.

Key Takeaway

A small chain of nodes transforms Time into a designer-friendly blend between colors; expose speed and color for easy tuning.
