URP / HDRP Required
Shader Graph assets need Universal or High Definition Render Pipeline to render correctly.
Save and Test
Save graphs, create materials, and test in play mode to iterate quickly and catch errors.
Profile GPU Cost
Watch texture samples and expensive math. Optimize before shipping to target devices.
Final Takeaway

Shader Graph lets you produce expressive, performant VFX without hand-writing shaders. Follow the pipeline rules, expose designer properties, and profile early.
