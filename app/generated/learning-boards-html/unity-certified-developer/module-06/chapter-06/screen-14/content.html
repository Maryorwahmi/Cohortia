Module 6 › Chapter 6.6 › Key Concepts
Shader
A GPU program that computes each pixel's color and alpha.
Shader Graph
A node-based editor to create shaders visually without coding.
Master Node
The final output node defining which properties the render pipeline uses.
Takeaway

Use inputs and math to create animations, match Master Node type to your goal, expose properties for iteration, and profile performance on target hardware.
