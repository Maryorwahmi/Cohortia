Module 6 › Chapter 6.6 › PulsingGlow Shader
Node network summary
_GlowColor (Color HDR) × (Remapped Sine(Time × _PulseSpeed)) → Color on Unlit Master. _PulseSpeed is a Vector1 property exposed to the Material Inspector.
Material setup
  1. Create Material PulsingGlowMat.
  2. Select Shader Graphs/PulsingGlowShader as its shader.
  3. Assign to a 3D object and adjust properties at runtime.
Example defaults

_GlowColor: neon blue HDR, _PulseSpeed: 2.0, Remap Out range: 0.5–1.5 to avoid full darkness.

Common mistakes & checks
  • Forgot to set project to URP/HDRP — shader may render black.
  • Not saving the graph after edits — scene won't update.
  • Alpha unintentionally set to 0 — object appears invisible.
Key Takeaway

Expose the color and speed you want artists to tweak. Test in the Material Inspector for fast iteration.
