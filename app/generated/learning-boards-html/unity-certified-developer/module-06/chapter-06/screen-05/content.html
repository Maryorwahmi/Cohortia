Editor anatomy

Canvas, nodes, and the Master Node

Assemble input, math, color and utility nodes on the canvas and feed their result to the Master Node, which defines the final shader outputs used by the render pipeline.

Example connection

Connect Color → Multiply (intensity) → Master Color. Without the final connection, the Multiply node produces no visible effect in the scene.

Master Node types
Unlit Master
Color, Alpha, Alpha Clip
Lit Master
Base Color, Normal, Metallic, Smoothness, Emission
Misconception check

If you choose a Lit Master but don't provide normals or metallic inputs, the engine will still calculate lighting using defaults. This can change your expected appearance.

Key Takeaway

Match Master Node type to your visual goal and ensure final outputs are connected to see changes in the scene.
