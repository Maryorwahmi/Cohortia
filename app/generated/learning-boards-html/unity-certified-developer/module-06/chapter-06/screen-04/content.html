Module 6 › Chapter 6.6 › What is a Shader?
Definition

Shader — the per-pixel program

Shaders run on the GPU and compute each pixel's final color and transparency. They are compact, parallel programs used for both realistic materials and stylized effects.

Unlit Shader
No lighting
Lit Shader
Includes lighting parameters
Concrete example

A simple lit shader uses Base Color, Normal, Metallic and Smoothness inputs to compute shaded pixels, while an Unlit shader simply outputs a color or texture that ignores scene lights.

Common misconception

People often think shaders must be hand-coded. Shader Graph lets you construct shader logic with nodes, making shader design accessible to artists while still compiling to GPU-friendly code.

Why performance matters
  • Shaders run per pixel each frame. Extra math or texture samples increase GPU cost.
  • Prefer simple node networks for mobile or dense scenes to keep frame rates stable.
Key Takeaway

Think of shaders as the final word on a pixel's appearance. Choose Unlit for stylized emission and keep calculations minimal.
