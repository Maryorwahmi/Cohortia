Hands-on Activity
Implement Blend Tree + UpperBody Layer
Setup
  1. Import humanoid with Idle, Walk, Run, Wave.
  2. Create Animator Controller and assign to character.
  3. Drag Idle into Animator as default state.
Blend Tree
  1. Create Locomotion Blend Tree (1D). Add Speed parameter.
  2. Add Idle(0), Walk(2), Run(5). Preview and adjust thresholds.
UpperBody Layer
  1. Add new layer named UpperBody, set Weight to 1 and Blending to Override.
  2. Create UpperBodyMask and include spine, chest, arms, hands.
Script & Test
  1. Attach CharacterAnimatorController, verify Animator reference.
  2. Run scene. Use movement keys to change Speed. Press Space to toggle the wave layer weight.
Key Takeaway

Follow the steps and verify in both the Animator preview and Game view to ensure blends and mask boundaries behave as expected.
