Definition
Animation Layers

Separate state machines that can play concurrently. Each has a Weight and Blending mode to control influence over final poses.

  • Weight: 0–1 influence value.
  • Blending: Override replaces, Additive adds to lower layers.
  • Use: gestures, facial animations, or upper-body actions independent of base locomotion.
Practical scenario
Create an UpperBody layer, set Weight to 1, set Blending to Override, assign a mask that includes spine and arms, and place a Wave clip in that layer's state machine. Toggle Weight at runtime to control visibility.
Pro Tip

Use Additive for subtle facial or breathing adjustments and Override for full pose replacement on masked bones.
