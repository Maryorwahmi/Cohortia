Common Mistakes
Troubleshooting checklist
  • Threshold mismatch: Lower or raise thresholds to match actual runtime ranges.
  • Unlooped clips: Enable Loop Time for continuous locomotion clips.
  • Mask errors: Verify Avatar Mask bone toggles to exclude legs if needed.
  • Layer weight: Ensure the layer weight is set above zero when you expect it to act.
  • Parameter jitter: Smooth values with interpolation to avoid abrupt visual changes.
Quick fixes
Use Animator preview, small transition durations, and runtime toggles to isolate the root cause of visual artifacts.
