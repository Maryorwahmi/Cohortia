Core Concept
Blend Tree — definition

A parameter-driven state that mixes multiple animation clips together so transitions are continuous rather than discrete.

Why this matters
  • Reduces state explosion in the Animator by consolidating related motions.
  • Creates smoother visual transitions controlled by runtime parameters.
  • Makes tuning locomotion faster because thresholds can be previewed and adjusted.
Common misconception
Blend Trees do not fix poorly looped clips. Ensure clips loop cleanly for good blends.

Key Takeaway

Use Blend Trees when several clips represent the same conceptual state and should be mixed by a parameter.
