Architecture
Base Layer + UpperBody Layer
  • Base Layer: Locomotion Blend Tree driven by Speed, full-body or root motion.
  • UpperBody Layer: Gesture state machine, Masked to spine and arms, Blending = Override.
  • Control: Layer Weight toggled via script to enable or disable gestures at runtime.
Runtime control
Use GetLayerIndex and SetLayerWeight to toggle the UpperBody layer from script when an input is detected, enabling gestures without stopping locomotion.
Key Takeaway

Modularity makes animation systems scalable: add or tune layers independently of the base locomotion blend.
