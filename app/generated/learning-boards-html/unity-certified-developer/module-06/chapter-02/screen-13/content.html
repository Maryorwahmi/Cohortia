Assessment scenarios
Scenario 1
Need locomotion + punch without affecting legs. Recommended: 1D Blend Tree on Base, separate UpperBody layer with an Avatar Mask for the arm.
Scenario 2
Walk pops inside a blend. Inspect clip loops and start/end poses; enable Loop Time or correct frames.
Scenario 3
Gesture layer never appears. Check layer Weight, mask assignment, and that layer index is correct when using SetLayerWeight in script.
Reflection

When debugging, isolate whether the issue is the authored clip, the mask configuration, or runtime parameter control before applying a fix.
