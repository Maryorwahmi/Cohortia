Process Flow
Create 1D Blend Tree
  1. 1. Right-click in Animator → Create State → From New Blend Tree. Name it Locomotion.
  2. 2. Add a float parameter named Speed and select it as the Blend Tree parameter.
  3. 3. Add motion fields: Idle (0), Walk (2), Run (5) and set Thresholds accordingly.
  4. 4. Create transitions: Idle → Locomotion when Speed > 0.1 and back when Speed <= 0.1. Uncheck Has Exit Time.
  5. 5. Preview blend by scrubbing Speed and adjust thresholds to match runtime input ranges.

Example check
If Run never appears in playtest, lower its threshold or raise the input mapping so Speed reaches that value.
Key Takeaway

Thresholds must reflect the actual range of your runtime parameter, and clips should loop if intended for continuous motion.
