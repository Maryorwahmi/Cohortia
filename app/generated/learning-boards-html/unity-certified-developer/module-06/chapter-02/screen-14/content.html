Module 6 › Chapter 6.2 › Key Concepts
Blend Tree
A state that blends clips by parameter values for smooth transitions.
Animation Layer
A separate state machine that can play at the same time as the base layer.
Avatar Mask
Select which body parts a layer will affect so animations remain isolated.
Takeaway: Compose modular animation by blending locomotion with Blend Trees, isolating gestures with layers, and targeting bones with Avatar Masks. Verify thresholds, loop settings, and mask configuration when debugging.
