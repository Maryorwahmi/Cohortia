Practical checks
  • Blend Preview: Use the Blend Tree preview to scrub the parameter and ensure clips crossfade naturally.
  • Loop Settings: Confirm animation clips have Loop Time if they should repeat in locomotion.
  • Layer Weight: Toggle layer weight in runtime to verify independent playback.
  • Mask Validation: Inspect Avatar Mask bone toggles to ensure only desired bones are selected.
