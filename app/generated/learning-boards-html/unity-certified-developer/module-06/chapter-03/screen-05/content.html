Animation Evaluation Flow
1. Animator evaluates states and blends, producing a base pose.
2. Unity calls OnAnimatorIK on MonoBehaviours attached to the same GameObject so you can apply IK overrides.
3. The final pose, including your IK adjustments, is applied to the skeleton and rendered.
// Example skeleton for OnAnimatorIK
void OnAnimatorIK(int layerIndex)
{
    if (animator == null) return;
    // Set IK weights and positions here so the Animator applies them
}
Explanation
  • • Placing IK calls in Update will not be applied correctly.
  • • Null-check your Animator reference to avoid runtime errors.
  • • Consider root motion: IK offsets are applied to the final skeleton after root movement.
Common Mistake

Calling SetIKPosition outside OnAnimatorIK results in no visible IK effect.
