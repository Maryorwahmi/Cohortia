Common IK calls
animator.SetIKPosition(AvatarIKGoal.RightHand, target.position);
animator.SetIKRotation(AvatarIKGoal.RightHand, target.rotation);
animator.SetIKPositionWeight(AvatarIKGoal.RightHand, ikWeight);
animator.SetIKRotationWeight(AvatarIKGoal.RightHand, ikWeight);

animator.SetLookAtWeight(weight, body, head, eyes, clamp);
animator.SetLookAtPosition(lookAtTarget.position);
Note: always set weights to control influence. For hints use SetIKHintPosition and SetIKHintPositionWeight to improve elbow and knee solutions.
Explanation
  • • Set the world-space target before the Animator applies the final pose.
  • • Weights blend the solver output with base animation to avoid abrupt changes.
  • • Hints guide the solver to choose a natural joint bend direction.
Common Mistake

Not setting weights or calling the methods outside OnAnimatorIK causes no visible IK effect.
