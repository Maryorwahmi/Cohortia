Setup Steps
  1. 1. Import humanoid model and set Rig to Humanoid.
  2. 2. Add Animator and simple idle state.
  3. 3. Create IKTargetSphere and RightElbowHint and place them in the scene.
  4. 4. Attach HandIKController and assign references in Inspector.
  5. 5. Start Play and increase ikWeight to observe the hand following.
Optional: moving sphere
// Optional simple vertical oscillation
void Update() {
    if (ikTargetSphere != null) {
        ikTargetSphere.position = new Vector3(ikTargetSphere.position.x,
            Mathf.Sin(Time.time * 2f) * 0.5f + 1.5f,
            ikTargetSphere.position.z);
    }
}
This makes the target move up and down so you can observe dynamic IK responses.
