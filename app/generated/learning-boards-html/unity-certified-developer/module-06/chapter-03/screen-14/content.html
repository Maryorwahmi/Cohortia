Module 6 › Chapter 6.3 › Key Concepts
Forward Kinematics
Animate by rotating joints; end effector is the result.
Inverse Kinematics
Give a target for an end effector and let the solver compute joint rotations.
OnAnimatorIK
The Animator callback where IK methods must be called for correct final poses.
Summary

These concepts guide practical IK usage: choose IK for runtime accuracy, place code in the IK callback, and blend weights to preserve animation quality.
