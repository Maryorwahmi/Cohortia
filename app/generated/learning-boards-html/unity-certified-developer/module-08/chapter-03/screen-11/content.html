Module 8 › Chapter 8.3 › Challenges & Mitigations
Problems
  • Latency: Causes delayed reactions; use client-side prediction and reconcile with server state.
  • Bandwidth: Limit how often and how much you send; pack data tightly.
  • Jitter: Smooth variable delays with buffering and interpolation.
  • Packet loss: Rely on reliable messages for critical events or design idempotent actions.
Mitigations
Prediction & Reconcile

Make controls responsive on clients, then correct with server state to prevent drift.

Efficient updates

Send deltas, pack values, and reduce frequency for non-critical data.

Security

Keep validation and authoritative logic on the server to minimize cheating risks.

Example

Interpolate remote player positions between NetworkVariable updates to hide jitter.

Pro tip

Prioritize reliable transport for gameplay decisions, and unreliable for frequent cosmetic updates.

Key Takeaway

Combine prediction, reconciliation, and efficient messaging to keep gameplay smooth and fair on real networks.
