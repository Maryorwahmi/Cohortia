Common Pitfall
Unregistered prefabs

If a prefab isn't listed in NetworkManager, clients cannot spawn it. Always register your NetworkObject prefabs before testing clients.

Verified Competency Milestone
Permission
NetworkVariable write rules

Choose ServerOnly for authoritative stats, OwnerOnly for owner-controlled values like position, and read permissions to let clients observe state.

Verified Competency Milestone
Testing
Host/editor and build client

Run a host in the Editor and a standalone build as client to exercise the full RPC and NetworkVariable flow under real conditions.

Verified Competency Milestone
Misconception
Clients can’t call ClientRpc

Only the server invokes ClientRpc; clients call ServerRpc to request server actions. Rely on this flow for consistent notifications.

Verified Competency Milestone
