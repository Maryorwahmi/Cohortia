Architecture

What NetworkObject provides

  • Spawn and Despawn across clients
  • Ownership assignment (IsOwner true/false)
  • Hook points for NetworkBehaviour lifecycle callbacks like OnNetworkSpawn
Practical guidance
Register prefabs

Add the prefab asset to NetworkManager's Network Prefabs so clients can spawn copies when the server requests it.

IsOwner checks

Use IsOwner to enable input and owner-only writes, and disable local-only systems for non-owners.

Prefab vs Scene object

Modify the prefab asset and register that; editing a scene instance won't propagate to spawned clients.

Example

Assign a Cube prefab with NetworkObject as the Player Prefab so each client gets an owned cube when they connect.

Check your setup

When a client connects, does their instance log OnNetworkSpawn with IsOwner true? If not, review prefab registration.

Key Takeaway

NetworkObject and correct prefab registration are prerequisites for any synchronized multiplayer logic.
