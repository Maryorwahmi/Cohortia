Module 8 › Chapter 8.3 › NetworkVariable<T>
Concept

Synchronized values

NetworkVariables automatically send updated values to clients when the server (or permitted owner) writes them. They support primitive and struct types such as int, Vector3, and string.

OnValueChanged

Subscribe to changes to update UIs or trigger local effects when values change.

Permissions

Set NetworkVariableWritePermission to ServerOnly or OwnerOnly to control who can write.

Example
PlayerScore

Declare PlayerScore as ServerOnly write so only the server increments and synchronizes it to clients. Use OnValueChanged to update ScoreText UI.

Position

Use NetworkVariable<Vector3> with OwnerOnly write for owner-driven movement, with server reconciliation if needed.

Misconception

NetworkVariables are not ideal for streams of independent events like chat messages.

Pro tip

Keep payloads small and choose efficient types to reduce bandwidth use.

Key Takeaway

Treat NetworkVariables as synchronized shared state with controlled writers and callback-based updates for UIs.
