Module 8 › Chapter 8.3 › Install & Configure
Process

Quick setup checklist

  1. Open Package Manager and install Netcode for GameObjects.
  2. Create an empty GameObject named NetworkManager and add the NetworkManager component.
  3. Add UnityTransport as the transport layer on the NetworkManager.
  4. Create a Player Prefab with a NetworkObject component and register it in NetworkManager's Network Prefabs.
  5. Assign the Player Prefab slot and test by starting Host and connecting a Client build.
Common mistakes
Forgot NetworkObject

Without NetworkObject on the prefab, spawning and ownership won't work. Add it before creating a prefab asset.

Unregistered prefab

Register the prefab in NetworkManager's list so clients can spawn it when connecting.

Transport missing

Attach UnityTransport or another supported transport to allow connections between instances.

Example check

Start Host in Editor and run a built executable as a client to verify the Player Prefab spawns on connect.

Pro tip

Use descriptive prefab names and tags to find UI elements like ScoreText for runtime updates.

Key Takeaway

A reproducible setup sequence prevents confusing spawn and permission bugs later.
