Module 8 › Chapter 8.3 › Hands-on Activity
Setup steps
  1. Install Netcode for GameObjects via Package Manager.
  2. Create NetworkManager + attach UnityTransport.
  3. Create NetworkPlayer prefab with NetworkObject and NetworkPlayer script.
  4. Register prefab in NetworkManager and assign Player Prefab slot.
  5. Create ScoreText UI and assign to prefab's scoreText field.
  6. Start Host in Editor and run build as Client to test movement and score.
Validation checklist
  • Does OnNetworkSpawn log OwnerClientId for local player?
  • Does pressing the action key call a ServerRpc and update PlayerScore on server?
  • Does ScoreText update on both host and client via OnValueChanged?
  • Do remote players interpolate toward Position.NetworkVariable?
Example outcome

Two players move independently; pressing the action key on either increments the shared score visible on both UIs.

Troubleshoot

If prefabs don't spawn, re-check NetworkManager registration and that the prefab asset has NetworkObject attached.

Key Takeaway

A small end-to-end test verifies your entire networking flow and reveals permission or registration errors early.
