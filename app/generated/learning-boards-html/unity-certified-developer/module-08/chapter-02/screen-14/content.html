Module 8 › Chapter 8.2 › Key Concepts
Editor-only
Place scripts in an Editor folder so they compile only for the editor and not the build.
Serialized properties
Use serializedObject.Update and ApplyModifiedProperties for safe serialization and prefab support.
Undo & Persist
Record undo and call EditorUtility.SetDirty for reversible, saved changes.
Summary

Follow these three core practices to make editor tools that are safe, discoverable, and useful to your team.
