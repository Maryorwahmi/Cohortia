Module 8 › Chapter 8.2 › Designer-friendly Inspectors
Layout patterns
  • Group fields by purpose with foldouts or BeginVertical blocks.
  • Use sliders for ranges, PropertyField for serialized properties, and custom draws for complex data.
  • Provide action buttons with clear labels and optional confirmation for destructive operations.
Example
Group Combat Stats and Ammo, display a HelpBox if fireRate exceeds a safe threshold, and provide a Test Fire button that runs a safe validation method.
HelpBox examples
Use EditorGUILayout.HelpBox("Message", MessageType.Warning) to surface issues clearly. Include suggested fixes where possible.
Key Takeaway

Make inspectors clear and safe. Designers should understand the impact of each control without asking a programmer.
