Module 8 › Chapter 8.2 › Compilation & Safety
Editor folder and assemblies
Scripts inside a folder named Editor compile only for the Unity Editor. This prevents UnityEditor APIs from being included in runtime builds and avoids missing-type errors. Because editor code compiles into separate assemblies, runtime code cannot depend on editor-only assemblies.
Undo and persistence
  • Use Undo.RecordObject before changing scene objects.
  • Call EditorUtility.SetDirty after modifying objects so changes are saved.
  • Test Undo and persistence by performing actions and using undo, then restarting the editor.
Performance
OnGUI is called frequently. Avoid expensive operations there. Use event-driven patterns or schedule heavy tasks on demand.
Misconception
Putting an editor script outside an Editor folder will not magically exclude UnityEditor types from the build; it causes compilation issues.
