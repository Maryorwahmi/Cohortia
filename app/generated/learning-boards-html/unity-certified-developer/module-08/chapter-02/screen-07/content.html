Module 8 › Chapter 8.2 › EditorWindow
Essential pattern
Define a public class inheriting EditorWindow. Add a static ShowWindow method with MenuItem to open it. Implement OnGUI to draw the UI with EditorGUILayout and GUILayout calls.
Use OnEnable for initialization and avoid costly work inside OnGUI. For actions that create objects, use Undo.RegisterCreatedObjectUndo so creations are undoable.
Example use case
A Level Builder window that places prefab instances in a grid based on parameters, all created with Undo support.
MyCustomWindow snippet
[MenuItem("Cohortia Tools/My Custom Window")]
public static void ShowWindow() { GetWindow("Cohortia Tools"); }
void OnGUI() { GUILayout.Label("Settings", EditorStyles.boldLabel); myString = EditorGUILayout.TextField("Text Field", myString); if (GUILayout.Button("Perform Action")) { Debug.Log("Action performed"); } }
Mini-check: open the window from the menu, change parameters, press the action button, and confirm Undo works if the action creates scene objects.
