Module 8 › Chapter 8.2 › CollectibleItem Inspector
Starter tasks
  • Draw type and value with PropertyField or specific controls.
  • Add a 'Duplicate Item' button that Instantiates and registers undo.
  • Add a 'Randomize Value' button that records undo and marks the object dirty.
  • Show a warning HelpBox if itemMeshRenderer is null.
Starter snippet (visual)
if (GUILayout.Button("Duplicate Item")) { var duplicate = Instantiate(item.gameObject, item.transform.position + Vector3.right, item.transform.rotation); Undo.RegisterCreatedObjectUndo(duplicate, "Duplicate Collectible Item"); Selection.activeGameObject = duplicate; }
if (GUILayout.Button("Randomize Value")) { Undo.RecordObject(item, "Randomize Collectible Value"); item.value = Random.Range(1, 101); EditorUtility.SetDirty(item); }
Warning handling
If itemMeshRenderer is null, draw a help box using EditorGUILayout.HelpBox to alert the designer that the item might not be visible in-scene.
Key Takeaway

Always combine Undo calls with EditorUtility.SetDirty when changing scene object properties so actions are undoable and persist.
