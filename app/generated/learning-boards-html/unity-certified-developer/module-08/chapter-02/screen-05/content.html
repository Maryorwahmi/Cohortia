Module 8 › Chapter 8.2 › Custom Inspectors
Step-by-step
  1. Create a C# script inside an Editor folder and inherit from UnityEditor.Editor.
  2. Add [CustomEditor(typeof(YourType))] and override OnInspectorGUI.
  3. Call serializedObject.Update(), draw PropertyFields or controls, and then serializedObject.ApplyModifiedProperties().
Quick rule
Always use serializedObject for editable properties to keep undo and prefab overrides working.
PlayerStats (visual)
// Inside PlayerStatsEditor.cs (Editor folder)
[CustomEditor(typeof(PlayerStats))]
public override void OnInspectorGUI() {
  serializedObject.Update();
  EditorGUILayout.IntSlider(...); // health/mana
  EditorGUILayout.PropertyField(serializedObject.FindProperty("experience"));
  if (GUILayout.Button("Grant 100 XP")) { player.GainExperience(100f); }
  serializedObject.ApplyModifiedProperties();
}
Example check: change experience, click ApplyModifiedProperties, and confirm the value persists after exiting play mode. If it doesn’t persist, inspect whether ApplyModifiedProperties was called or whether the property was modified directly on the target without serialization.
