Verification checklist
  • Custom Inspector updates serialized properties and calls ApplyModifiedProperties.
  • EditorWindow is reachable via a MenuItem and performs a simple task.
  • Undo.RecordObject and EditorUtility.SetDirty are used for scene or asset changes.
  • Editor scripts are in an Editor folder so they are excluded from runtime builds.

Build a CollectibleItem inspector with Duplicate and Randomize Value buttons and verify undo works.
