Module 8 › Chapter 8.2 › PlayerStats Inspector
Key lines explained
serializedObject.Update() — reads current serialized state so PropertyField shows accurate values.
EditorGUILayout.PropertyField — draws the property while keeping prefab and serialization behavior intact.
GUILayout.Button("Grant 100 XP") — triggers an editor-time action on the target; use with care for scene changes.
serializedObject.ApplyModifiedProperties() — writes changes back and ensures Unity serializes them and records them for undo.
Pro tip
Use PropertyField when you want to preserve prefab overrides; use direct access only for derived or editor-only fields.
Annotated snippet
serializedObject.Update();
// draw sliders
player.health = EditorGUILayout.IntSlider("Health", player.health, 0, 200);
EditorGUILayout.PropertyField(serializedObject.FindProperty("experience"));
if (GUILayout.Button("Grant 100 XP")) { player.GainExperience(100f); }
serializedObject.ApplyModifiedProperties();
Mini-check: after calling ApplyModifiedProperties, modify a value and use Undo to verify undo entry exists.
