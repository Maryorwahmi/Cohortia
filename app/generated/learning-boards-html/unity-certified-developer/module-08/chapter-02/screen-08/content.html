Module 8 › Chapter 8.2 › MenuItem vs ContextMenu
MenuItem (global)
Add a MenuItem to expose EditorWindows and global utilities. Ideal for tools that operate across the project.
Example: [MenuItem("Cohortia Tools/My Custom Window")] opens an EditorWindow accessible from the top menu.
ContextMenu (instance)
Add per-component right-click actions. Use for instance-specific helpers like 'Duplicate Item' or 'Reset Settings'.
Example: a ContextMenu on a CollectibleItem could add 'Randomize Value' to the Inspector's context menu for the selected item.
Decision guide
  • If many assets or scenes need the tool, prefer MenuItem.
  • If the action applies only to a specific component instance, prefer ContextMenu.
  • Keep heavy operations behind confirmation and avoid firing them accidentally from a context click.
