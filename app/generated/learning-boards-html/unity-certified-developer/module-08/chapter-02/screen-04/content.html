Module 8 › Chapter 8.2 › What is Editor Scripting?
Definition
Editor scripting is writing C# that extends the Unity Editor UI and behavior. It uses UnityEditor APIs and runs only in the editor when stored in an Editor folder.
Why it matters
  • Automate repetitive tasks so designers iterate faster.
  • Enforce project standards and reduce human error.
  • Build bespoke workflows that match your game’s needs.
Common misconception
Editor scripts are not runtime code. Mixing editor-only assemblies with runtime code can create build errors because UnityEditor types are not available in players.
Concrete example
An EditorWindow that scans assets for missing references and displays a list for designers to fix. This window runs in the editor and is opened via a MenuItem.
Check your understanding
Name one repetitive workflow you do now and imagine a Button or EditorWindow that reduces it to one click. That idea is a valid first editor script.
Key Takeaway

Editor scripts are safe, powerful, and should be used to eliminate repetitive manual steps during development.
