Module 8 › Chapter 8.8 › Addressables
Pattern

Load, instantiate, release

var handle = Addressables.LoadAssetAsync<GameObject>(assetRef); await handle.Task; var prefab = handle.Result; var instance = Instantiate(prefab); // later Addressables.Release(handle);
Practical tip: keep AsyncOperationHandles when you plan to release later. If you pool, consider preloading frequent assets during a start phase to avoid per-spawn loads.
Example uses
  • Player prefab: load on connect, assign to NetworkManager spawn slot.
  • Enemy prefab: EnemySpawner requests LoadAssetAsync per wave or uses a pooled preloaded list.
  • Boss VFX: load on phase enter and release on exit to conserve memory.
Misconception
Loading once means no memory cost. In fact you must Release handles when done to free memory.
Check
Run a profiler snapshot before and after loads to confirm there are no lasting spikes or leaks.
