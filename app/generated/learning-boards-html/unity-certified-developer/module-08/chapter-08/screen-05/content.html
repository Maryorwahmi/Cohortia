Module 8 › Chapter 8.8 › GameManager (Singleton)
Definition

A minimal authoritative hub

Provide a global Instance and narrow, well-documented methods for wave control and global events. Use events to inform subsystems rather than direct method calls when possible.

Example snippet (conceptual)
public static GameManager Instance;\nvoid Awake(){ if(Instance==null){Instance=this; DontDestroyOnLoad(gameObject);} else Destroy(gameObject);} \nvoid StartWave(){ OnWaveStarted?.Invoke(); }
Common mistake
Packing UI and input into GameManager makes it hard to test and replace systems.
Pro tip
Expose events like OnWaveStarted so spawners and UI subscribe rather than depend on direct references.
Architecture
Use GameManager for orchestration: wave counters, spawn requests, score aggregation, and event broadcasting. Keep instantiation details in an EnemySpawner component which can be swapped between Addressables or pooled prefabs.
Concrete scenario
When a wave starts, GameManager increments wave number, raises OnWaveStarted, and the EnemySpawner loads enemy prefabs via Addressables and instantiates them.
