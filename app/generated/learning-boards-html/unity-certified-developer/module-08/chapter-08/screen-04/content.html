Module 8 › Chapter 8.8 › Integration Strategy
Process Flow

Iterative steps

  1. 1
    Minimal loop: networked players move and see each other.
  2. 2
    Singleton GameManager: wave control and global events.
  3. 3
    Addressables: load player and enemy prefabs asynchronously.
  4. 4
    AI & Sync: add State Machine AI and NetworkVariables for health.
Key Takeaway

Short iterations with smoke tests and profiler checks prevent cascading integration failures.

Example Plan
A concrete walkthrough: implement host-client movement first, then create a basic GameManager that calls StartWave on a key press in the Editor. Replace static player prefabs with an Addressable reference and verify loading works on host and client. Add EnemySpawner that uses Addressables.LoadAssetAsync and instantiate enemies. Attach a simple State Machine to enemies for chasing and test transitions. Finally wire health with NetworkVariable and a ServerRpc for shooting. After each step record a profiler snapshot.
Common mistake
Adding all systems at once obscures bug origins.
Pro tip
Write small unit tests or play-mode checks for critical functions like spawning and health updates.
