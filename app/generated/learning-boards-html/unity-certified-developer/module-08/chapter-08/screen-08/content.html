Module 8 › Chapter 8.8 › Networked Spawning
Pattern

Load player prefab, then spawn

OnClientConnected -> await Addressables.LoadAssetAsync<GameObject>(playerRef); NetworkManager.SpawnManager.PlayerPrefab = loadedPrefab; NetworkManager.SpawnManager.SpawnPlayerForClient(...)
Ensure the prefab includes NetworkObject, NetworkTransform or equivalent, and a script that uses IsOwner to accept input only on the owning client.
Validation & RPCs
Client actions that change game state should be ServerRpc calls. The server performs authority checks and modifies NetworkVariables. Use ClientRpc for purely visual effects after server validation.
Misconception
Using client-side physics results for authoritative decisions. Instead, the server should validate and resolve outcomes.
Concrete test
Host in Editor and run a Client build to confirm spawned players and movement sync without state drift.
