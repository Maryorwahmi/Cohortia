Module 8 › Chapter 8.8 › EnemyAI State Machine
Definition

State Machine basics

  • Idle: wait for a target within detection radius.
  • Chase: move toward nearest player using simple steering or navmesh.
  • Attack: apply damage when within attack range.
  • Dead: play death VFX and notify GameManager, then release resources.
Example behavior
if(Health<=0) ChangeState(new DeadState()); else if(TargetInRange) ChangeState(new AttackState());
Testing & pitfalls
Test transitions by forcing health changes and teleporting players to simulate edge cases. Watch out for network latency causing the client and host to disagree about whether Attack conditions were met; use server validation when necessary.
Misconception
Putting all checks in Update is acceptable. In reality it makes states fragile and transitions opaque.
Concrete example
On entering Dead, load a death VFX Addressable, play it, and call Addressables.Release when the effect is cleaned up.
