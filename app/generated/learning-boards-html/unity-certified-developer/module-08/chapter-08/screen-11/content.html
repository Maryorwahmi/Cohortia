Module 8 › Chapter 8.8 › Build & Test
Hands-on checklist
  1. Install Netcode and Addressables packages and initialize Addressables.
  2. Create NetworkPlayer prefab, mark Addressable, and load it at runtime.
  3. Implement GameManager Singleton and EnemySpawner using Addressables.
  4. Add NetworkVariables for health and test ServerRpc flow for shooting.
  5. Profile during waves and address spikes.
Debugging workflow
Run Editor as Host and a standalone build as Client. If the client misses loads, confirm Addressables build content was generated and AssetReferences match the runtime catalog. If health only changes on host, ensure enemy health is a NetworkVariable with server write permission.
Pro tip
Add minimal server-side logging for NetworkVariable writes to trace authority during tests; remove verbose logs after debugging.
