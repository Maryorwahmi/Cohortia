Module 8 › Chapter 8.8 › Health & Sync
Definition

NetworkVariable for health

public NetworkVariable<int> Health = new NetworkVariable<int>(100, writePerm: NetworkVariableWritePermission.Server); Health.OnValueChanged += OnHealthChanged;
Only the server should call Health.Value -= damage. Clients should never directly mutate authoritative NetworkVariables.
Practical flow
  1. Client: request shoot via ServerRpc.
  2. Server: validate hit, decrement NetworkVariable Health.
  3. Clients: OnValueChanged updates health bar and triggers EnemyAI state transitions.
Misconception
Setting health locally on the client will propagate. It will not; only server writes replicate.
Test
Run host and client, shoot an enemy and confirm only server write logs appear and health changes on both machines.
