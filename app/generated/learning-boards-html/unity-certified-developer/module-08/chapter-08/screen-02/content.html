What you'll be able to do

Each objective pairs an advanced Unity feature with a concrete verification step you can test in your prototype.

01
Apply advanced scripting patterns

Use a Singleton GameManager and State Machine-driven EnemyAI so logic is centralized and modular. Verified by a functioning wave start and state transitions during play.

VERIFIED COMPETENCY MILESTONE
02
Utilize Addressables

Load and release player, enemy, and VFX prefabs asynchronously to avoid frame stalls and control memory use. Verified by dynamic spawn without hiccups.

VERIFIED COMPETENCY MILESTONE
03
Implement basic networking

Enable host and client connections, spawn players, and synchronize movement and shared state with NetworkVariables and RPCs. Verified by two-player tests showing consistent enemy health updates.

VERIFIED COMPETENCY MILESTONE
04
Profile and optimize

Use the Unity Profiler to find spikes, GC allocations, and draw-call excess. Verified by meeting a local performance target during a 30-second wave.

VERIFIED COMPETENCY MILESTONE
