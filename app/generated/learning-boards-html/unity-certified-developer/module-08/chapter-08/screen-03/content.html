Design and multiplayer principles

These goals ensure the prototype is not just functional, but maintainable and robust when networked.

01
Holistic understanding

Be able to explain why Addressables, networking, and state machines interact and where ownership crosses boundaries.

VERIFIED COMPETENCY MILESTONE
02
Iterative development

Ship a minimal loop and incrementally add systems. Each stage must pass a smoke test before proceeding.

VERIFIED COMPETENCY MILESTONE
03
Decoupling

Favor events and references via interfaces, so systems like AI or UI can be swapped without wide changes.

VERIFIED COMPETENCY MILESTONE
04
Server authority

Treat the host as the source of truth for damage, scores, and enemy states. Clients request, server validates.
