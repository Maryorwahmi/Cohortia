Module 8 › Chapter 8.5 › Hands-on Lab: Baseline
Steps
  1. Create Cube prefab and simple materials to break batching.
  2. Add SpawnCubes script and set numCubesToSpawn = 1000.
  3. Run scene in Editor and open Profiler; note CPU, Rendering, Memory graphs.
  4. Record baseline metrics: frame time, draw calls, GC Alloc.
Note
For GPU and memory accuracy, use a development build on the target device and profile remotely when possible.
Starter checklist
  • Cube prefab assigned to SpawnCubes.
  • Multiple materials to intentionally break batching.
  • Profiler open and recording while running the scene.
Common mistake: Not documenting baseline values before changes. Always capture numbers or screenshots for comparison.
