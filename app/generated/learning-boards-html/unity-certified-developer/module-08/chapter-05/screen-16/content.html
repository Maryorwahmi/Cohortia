Module 8 › Chapter 8.5 › More Key Concepts
Bottleneck
The component or process that limits overall performance—identify it with the profiler.
Draw Call
A CPU-issued command to the GPU to render geometry. Fewer draw calls often mean better render performance.
Addressables
A system for dynamic loading/unloading of assets to control memory footprint at runtime.
Quick takeaway

Use profiler vocabulary to communicate bottlenecks, apply the right optimization pattern, and validate improvements on target hardware.
