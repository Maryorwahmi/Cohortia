Before vs After
List baseline numbers and then each post-change snapshot. Note reductions in GC Alloc, draw calls, and average frame time with percentages where possible.
Result: Concrete evidence of improvement turns subjective smoothness into engineering metrics.
If results are mixed
Isolate changes, revert if needed, and profile further. Some optimizations trade memory for CPU or vice versa; document those trade-offs.
Final question to ask: did the dominant profiler consumer change? If not, you targeted the wrong subsystem and should return to profiling.
