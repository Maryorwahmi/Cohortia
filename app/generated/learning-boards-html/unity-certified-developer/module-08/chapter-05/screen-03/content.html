01 Diagnose
Differentiate CPU vs GPU bottlenecks
Run a development build on target hardware to see realistic profiler data and learn where the frame time is being spent.
Verified Competency Milestone
02 Reduce GC
Avoid allocations in hot paths
Cache components and replace frequent string concatenation to lower GC Alloc spikes in the profiler.
Verified Competency Milestone
03 Batching
Cut draw calls with batching and instancing
Make materials shareable and group static geometry to benefit static batching or GPU instancing for identical meshes.
Verified Competency Milestone
04 Platform
Apply mobile & VR settings
Lower graphics settings, enable single-pass stereo for VR, and target a consistent frame rate for constrained devices.
