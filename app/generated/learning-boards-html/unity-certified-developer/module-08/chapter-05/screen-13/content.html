Module 8 › Chapter 8.5 › Apply Fixes
Step 1: Pooling
Pre-instantiate and reuse cubes to eliminate frequent allocations. Expect GC Alloc to decrease.
Step 2: Cache components
GetComponent in Start and store references to avoid per-frame lookups and scripting cost.
Step 3: Batching
Make materials shared and mark static where appropriate to reduce draw calls via batching or instancing.
Measure changes
After each step, re-profile and record frame time, GC Alloc, and draw calls. Compare against baseline and attribute improvements to the change made.
