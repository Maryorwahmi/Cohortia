Module 8 › Chapter 8.5 › Memory Optimization & Addressables
Asset memory
Use texture compression formats appropriate to platform, enable mipmaps, and reduce resolutions where possible to save RAM and VRAM.
Addressables
Load and unload assets dynamically so only needed content occupies memory. This reduces startup memory pressure and allows large scenes on constrained devices.
Managed heap
Monitor GC Alloc and reduce per-frame allocations. Avoid long-lived static references that block unloading. Use structs when appropriate and pre-allocate collections.
Concrete: Stream textures for distant areas and use Addressables to release them when no longer needed.
