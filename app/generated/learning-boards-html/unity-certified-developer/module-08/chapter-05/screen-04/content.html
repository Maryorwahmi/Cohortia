Module 8 › Chapter 8.5 › What is Performance Profiling?
Definition
Measure CPU, GPU, and memory usage to find bottlenecks. Use concrete profiler graphs to direct optimization work rather than guesswork.
Why it matters
  • Prevents wasted optimization effort.
  • Shows whether the game is CPU-bound, GPU-bound, or memory-limited.
  • Supports an iterative, measurable workflow.
Concrete example
A scene with many Instantiate calls shows GC Alloc spikes and high scripting time in the profiler. Pooling those objects reduces GC Alloc and smooths frame time.
Key Takeaway

Always measure first. Optimize one thing at a time and re-profile to verify impact.

Profile-Optimize-Reprofile
Profile: Run a development build or the Editor and capture CPU/GPU/Memory graphs.
Identify: Find the largest contributor in the Hierarchy or Timeline view.
Change: Implement a single targeted optimization, e.g., pooling or batching.
Reprofile: Confirm the change reduced the dominant cost.
