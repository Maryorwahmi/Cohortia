Module 8 › Chapter 8.5 › Learning Objectives
Bloom: Learn → Understand → Apply → Master
01
Master the Unity Profiler
Read CPU, GPU, and memory timelines to pinpoint spikes. This skill stops guesswork and focuses fixes where they matter.
Mnemonic: graph → hot spot
Verified Competency Milestone
02
Optimize CPU-bound code
Apply object pooling, batching, and efficient loops to reduce scripting time and GC pressure in hot paths.
Mnemonic: reuse → reduce allocations
Verified Competency Milestone
03
Reduce GPU cost
Use batching, GPU instancing, LODs, and texture compression to lower draw calls and overdraw on constrained GPUs.
Mnemonic: batch → fewer draw calls
Verified Competency Milestone
04
Manage memory and assets
Track managed heap and assets, employ Addressables, and compress textures to prevent OOMs and reduce load times.
Mnemonic: load smart, unload faster
Verified Competency Milestone
