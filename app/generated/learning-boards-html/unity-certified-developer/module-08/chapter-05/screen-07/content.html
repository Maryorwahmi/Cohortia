Module 8 › Chapter 8.5 › Batching & GPU Instancing
Static vs Dynamic vs Instancing
Static Batching: combine non-moving objects sharing materials at build time. Fewer draw calls, higher memory.
Dynamic Batching: runtime combining for small moving meshes subject to vertex limits.
GPU Instancing: single draw call for many identical meshes using instanced shader support.
Example
1,000 identical meshes become tractable with GPU instancing. With separate draw calls they overwhelm CPU submit cost; instancing sends one or few draws.
When to choose each
  • Static batching: many static, material-sharing objects.
  • Dynamic batching: many small moving objects that meet Unity limits.
  • GPU instancing: many identical meshes with the same material that supports instancing.
Common mistake
Assuming static batching always wins. It can inflate build size and memory; profile to confirm trade-offs.
