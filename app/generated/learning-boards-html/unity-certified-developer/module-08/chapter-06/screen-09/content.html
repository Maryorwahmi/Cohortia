LoadAssetAsync & AsyncOperationHandle
// Pattern: load, await, check, use, release
AsyncOperationHandle<GameObject> handle = Addressables.LoadAssetAsync<GameObject>(address);
await handle.Task;
if (handle.Status == AsyncOperationStatus.Succeeded) {
  GameObject go = Instantiate(handle.Result);
  // decide whether to keep or release handle
}
Addressables.Release(handle);
Concrete example
Load a player prefab by AssetReference, wait for the task, instantiate it at spawn, and release the handle if you won't spawn more players from it.
Misconception
Instantiating a prefab does not remove the need to manage the original asset handle; they are separate lifetimes.
Key Takeaway

Use the AsyncOperationHandle lifecycle to reliably load and release assets; treat instantiated objects and asset handles as independent ownerships.
