Build Configuration
Profiles & Catalogs
Profiles determine where bundles are written. Catalogs map addresses to those bundles.
Local Hosted: Useful for development and quick iteration.
Remote Hosted: Upload bundles and catalogs to a server for live updates and DLC.
Catalog updates: Clients must check and apply new catalogs to discover new or changed assets.
DLC flow
Rebuild changed groups, upload bundles and the updated content catalog, then clients update catalogs and load new assets on demand.
Common oversight
Not testing catalog updates can lead to missing assets or mismatched bundle versions on clients; validate update paths early.
Key Takeaway

Use build profiles to control hosting, and treat the content catalog as the single source of truth for resolving addresses at runtime.
