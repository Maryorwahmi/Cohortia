Three ways to make assets Addressable
Inspector checkbox: Select asset and enable Addressable to give it a default address.
Drag into a Group: Use the Addressables Groups window to drop assets directly into a group for packaging rules.
Labels: Add labels to group assets across groups for query-based loading at runtime.
Example
Make MyCube.prefab and MySphere.prefab addressable and add them to a group named "CharacterPrefabs" to test loading and releasing.
Label pattern
Use labels like "Characters", "Environments", "DLC_Pack_1" to group by purpose rather than folder.
Common pitfall
Relying on default addresses can make remote updates harder to track—use readable addresses for assets you plan to update remotely.
Key Takeaway

Choose a method that matches your workflow: checkbox for quick changes, groups for packaging, labels for bulk operations.
