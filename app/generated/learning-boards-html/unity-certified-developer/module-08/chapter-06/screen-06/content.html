Process Flow
Install & Initialize
  1. Open Package Manager and install Addressables from Unity Registry.
  2. Open Addressables Groups and select "Create Addressables Settings" to initialize.
  3. Create Addressable Groups such as Characters, Materials, UI_Icons.
  4. Drag assets into groups and add labels for bulk operations.
  5. Build & inspect bundles with Build → New Build → Default Build Script.
Why it matters
Initialization produces the settings asset and enables build profiles plus the content catalog needed for runtime resolution of addresses.
Concrete example: After initialization, create a "CharacterPrefabs" group and move two prefabs there to test on-demand loading in Play mode.
Key Takeaway

Initialization is the gateway: without settings, groups, builds, and catalogs you cannot resolve addressable assets at runtime.
