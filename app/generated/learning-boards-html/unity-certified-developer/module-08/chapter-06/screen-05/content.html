Definition
What Addressables provide
A unified API to load, host, and update assets by address rather than direct references.
Addresses & Labels
Stable strings or labels that point to assets and support grouping and lookup.
Addressable Groups
Group assets by update cadence or packaging requirements for independent builds.
Content Catalog
A manifest that maps addresses to the physical location of bundles, local or remote.
Async API & Handles
LoadAssetAsync returns an AsyncOperationHandle you await and later release to free memory.
Concrete scenario
Tag character models with a "Characters" label and host that group remotely to update new character packs without a client update.
Common mistake
Assuming Addressables automatically unload unused assets; you must call Release on handles when done.
Key Takeaway

Addressables give you addressable references and catalogs so you can load assets on demand and update them remotely.
