Hands-on Example
AddressableSceneLoader pattern
public AssetReferenceGameObject cubeReference;
private AsyncOperationHandle<GameObject> _playerLoadHandle;
async void LoadPlayerPrefabAsync() {
  _playerLoadHandle = Addressables.LoadAssetAsync<GameObject>(cubeReference);
  await _playerLoadHandle.Task;
  if (_playerLoadHandle.Status == AsyncOperationStatus.Succeeded) {
    Instantiate(_playerLoadHandle.Result);
  }
}
void OnDestroy() {
  if (_playerLoadHandle.IsValid()) Addressables.Release(_playerLoadHandle);
}
Concrete guidance
Store handles in fields if you plan to release later. Release immediately if you only need a one-off load.
Common mistake
Not checking IsValid before calling Release can be safe-guarded; always check to avoid runtime errors.
Key Takeaway

The loader script pattern makes ownership explicit: store handles, await success, use results, and release when safe to free memory.
