Comparison
Addressables vs Resources
Resources: Name-based loading, all assets in Resources included in build, coarse unloading.
Addressables: Address-based loading, groups define packaging, explicit release with handles enables deterministic unloading.
Practical example
Loading a character from Resources cannot be trimmed at build time. Loading via Addressables and releasing allows you to free its memory when it is no longer needed.
Leak scenario
Instantiate a prefab then forget to Addressables.Release the load handle; the asset stays loaded even after destroying the instance.
Best practice
Track handles in a list or fields, release each valid handle once you no longer need the asset or further instantiation.
Key Takeaway

Addressables gives precise control; consistent handle release is the single most important habit to prevent memory leaks.
