Module 8 › Chapter 8.7 › Physics: Rigidbody, Colliders, Triggers
Core Definitions
  • Collider: a shape used for overlap and collision detection.
  • Trigger: collider set to trigger to detect overlaps without physics response.
  • Rigidbody: enables physics simulation, dynamic or kinematic behavior.
Common Mistake
Confusing trigger callbacks with collision callbacks. Read the collider settings in any exam prompt to choose the correct handler.
Key Takeaway

Match the callback to the collider configuration. Test with debug logs to make this intuition automatic.

Scenario Card
Player collider: trigger. PowerUp collider: not trigger. PowerUp is kinematic. Which callback in the Player script detects entry? OnTriggerEnter — because the Player's collider is a trigger even if the other has a rigidbody.
