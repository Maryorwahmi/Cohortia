Module 8 › Chapter 8.7 › Asset Management & Serialization
Comparison: Text vs Binary Serialization
Force Text serialization makes asset metadata readable and diffable for version control. Binary serialization is smaller but hides changes and complicates merges.
Texture Inspector Trade-offs
Max Size: reduces memory; Compression: balances quality and size. Use platform overrides for device-specific tuning.
Key Takeaway

Manage assets with version control in mind and tune imports per platform to optimize performance without unnecessary quality loss.

Assessment Example
Problem: importing a 4K texture spikes memory. Correct mitigations are reducing Max Size and applying appropriate Compression, possibly with platform overrides. These two settings directly reduce memory footprint while retaining acceptable visual quality.
Quick Hands-on
Import an FBX and a texture, examine their .meta files, switch the project to Force Text, and observe the differences in how Unity serializes transforms and materials on disk.
