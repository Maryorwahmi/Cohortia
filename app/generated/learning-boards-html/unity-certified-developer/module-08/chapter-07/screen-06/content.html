Lifecycle Summary
  • Awake: initialization before Start; good for references.
  • Start: first frame initialization.
  • Update: per-frame, variable timing — avoid physics here.
  • FixedUpdate: fixed-interval physics updates; use for forces.
  • LateUpdate: post-update work like camera follow.
Best Practice
Cache component references in Awake or Start to avoid costly GetComponent calls every frame.
Key Takeaway

Place physics in FixedUpdate, heavy logic outside Update, and cache components to avoid performance penalties.
