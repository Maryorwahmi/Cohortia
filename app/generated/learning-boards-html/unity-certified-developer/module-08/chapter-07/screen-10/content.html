Module 8 › Chapter 8.7 › Lighting, Rendering & Optimization
Performance Targets
  • Draw calls: reduce by batching and using shared materials.
  • Memory: texture sizes and compression affect VRAM.
  • GC: avoid per-frame allocations and frequent string concatenation.
Practice
Run the Profiler, identify the top CPU or rendering cost, and apply a single optimization to measure change.
Optimization Workflow
  1. Measure with the Profiler to find hotspots.
  2. Address expensive allocations and frequent instantiation.
  3. Reduce draw calls via batching or shared materials.
  4. Use object pooling for repeated spawns.
Key Takeaway

Optimization starts with measurement. Improve one hotspot at a time and verify with the Profiler to build reliable answers for the exam.
