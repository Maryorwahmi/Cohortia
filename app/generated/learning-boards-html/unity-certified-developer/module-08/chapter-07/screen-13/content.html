Module 8 › Chapter 8.7 › Common Mistakes & Exam Tactics
Read Carefully and Spot Keywords
Watch for words that change intent: best, most efficient, only, never. These guide which answer aligns with exam priorities.
Distractor Example
A prompt may offer OnCollisionEnter when the actual setup uses a trigger; choosing the trigger callback is correct.
Timing Tactic
If stuck, guess, flag, and move on. Return with saved time to reason about flagged items.
Reflection Practice

After each practice test, record three takeaways and one remediation task to sharpen your next study session.
