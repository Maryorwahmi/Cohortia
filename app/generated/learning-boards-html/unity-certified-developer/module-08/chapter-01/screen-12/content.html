Module 8 › Chapter 8.1 › AudioManager + SettingsManager
Architecture
Managers live under a single _Managers GameObject. AudioManager is a Singleton and subscribes to volume changes from SettingsManager.
AudioManager (Singleton)
Persists across scenes, exposes PlaySound, subscribes to OnMasterVolumeChanged.
SettingsManager (Observer)
Publishes MasterVolume changes via a static event.
Hands-on steps
  1. Create _Managers GameObject and attach both scripts.
  2. Make AudioManager a Singleton and ensure an AudioSource is present.
  3. In SettingsManager, define OnMasterVolumeChanged and invoke it when MasterVolume is set.
  4. Subscribe in AudioManager.OnEnable and unsubscribe in OnDisable to update volume.
Concrete example
Move the slider, check console logs for the volume event, and watch AudioSource.volume update. If no change appears, verify subscriptions and that the Singleton is initialized.
Key Takeaway

This small integration demonstrates how patterns compose: Singletons for access, Observers for notifications, resulting in flexible, testable behavior.
