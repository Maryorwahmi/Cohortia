Publish-Subscribe
Publish events when state changes and let subscribers react independently.
• Use static events or delegate fields for cross-component updates.
• Subscribe in OnEnable and unsubscribe in OnDisable to avoid leaks.
• Pass concise, relevant data in the event so subscribers don’t query the publisher.
Concrete example
PlayerHealth publishes OnHealthChanged with an int value. HealthUI subscribes and updates visuals when the event fires.
Common pitfalls
  • Not unsubscribing leads to callbacks on destroyed objects.
  • Overusing global events increases implicit coupling across your project.
  • Using events without clear payloads forces subscribers to reach back into publishers for data.
Key Takeaway
Observers decouple systems but require disciplined subscription management and clear event design.
