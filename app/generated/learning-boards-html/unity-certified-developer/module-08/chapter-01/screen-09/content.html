Module 8 › Chapter 8.1 › Observer pitfalls
When events shine
  • Multiple systems react to the same state change.
  • Loose coupling improves reuse and independent modification.
  • Event-driven UI updates without tight scene wiring.
Alternatives
Direct method calls or references for local interactions, or a broker for complex lifetimes.
Pitfalls & fixes
• Forgetting to unsubscribe keeps dead references alive. Unsubscribe in OnDisable. • Overuse spreads logic and makes debugging harder. Use events for cross-cutting concerns only. • Sending large objects couples publishers and subscribers. Send minimal payloads.
Quick fix

If you see repeated callbacks, check subscription points, prefer OnEnable/OnDisable, and add clear logging to trace the publisher.
