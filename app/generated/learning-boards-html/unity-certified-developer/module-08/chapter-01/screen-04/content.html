Module 8 › Chapter 8.1 › What is a design pattern?
Definition
A reusable solution to a common problem in software design that captures intent and structure.
• Patterns make code predictable and easier to read across a team.
• They help you identify where responsibilities belong and how systems communicate.
• Misuse can hide dependencies or add unnecessary boilerplate.
Analogy
Patterns are like recipes: follow steps for a reliable result, but substitute only when you understand the trade-offs.
Key Takeaway

Apply patterns when they reduce cognitive load and make testing or collaboration simpler; avoid them when they mask dependencies.
