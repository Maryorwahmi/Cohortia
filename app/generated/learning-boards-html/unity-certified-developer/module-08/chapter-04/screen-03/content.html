Module 08 › Chapter 8.4 › Learning Objectives — Action Steps
01 — Verify version recovery

Create a small scene change, commit, then intentionally break it and revert using git log and git checkout of the previous commit. Confirm scene state restores.

VERIFIED COMPETENCY MILESTONE
02 — Fix .gitignore tracking

If Library or Temp are tracked, run git rm --cached -r Library/ and add them to .gitignore. Run git status to confirm they are ignored.

VERIFIED COMPETENCY MILESTONE
03 — Execute core Git commands

Practice git init, git add, git commit, git branch, git checkout, and git push. Observe how switching branches changes the workspace.

VERIFIED COMPETENCY MILESTONE
04 — Demonstrate Git LFS

Run git lfs install, git lfs track for common types, commit .gitattributes, and verify that cloning then requires git lfs pull to retrieve actual binaries.

VERIFIED COMPETENCY MILESTONE
