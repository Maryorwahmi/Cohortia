Module 08 › Chapter 8.4 › What is Git LFS and Why Use It
How it works

LFS replaces large binary blobs with small text pointers in Git and stores the binaries on an LFS server, keeping repository history small.

$ git lfs install
$ git lfs track "*.png"
$ git add .gitattributes
$ git commit -m "Track images with Git LFS"
Example

A 50 MB texture tracked with LFS appears as a small pointer in git log, while the binary is served from LFS storage.

Practical notes
  • Commit .gitattributes after running git lfs track so teammates get the same rules.
  • When cloning a repo with LFS, run git lfs pull if binaries are missing after git pull.
  • Use git lfs migrate import to convert previously committed large files into LFS if needed.
Key Takeaway
Key Takeaway

Use Git LFS for large binary types and commit .gitattributes so the team retrieves the actual assets correctly.
