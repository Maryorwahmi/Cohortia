Module 08 › Chapter 8.4 › Initialize Git and Configure .gitignore
Terminal steps
$ git init
$ echo "Library/\nTemp/\nBuild/\n*.csproj\n*.sln\n.DS_Store" > .gitignore
$ git add .gitignore
$ git commit -m "Add Unity .gitignore"
Tip: If generated files were already committed, run git rm --cached -r Library/ and commit the removal to keep history clean.
Common mistake

Adding .gitignore after committing generated folders leaves them in history. Use git rm --cached and a corrective commit.

What to include in .gitignore
  • Library/ — local cache and imported asset data.
  • Temp/, obj/ — temporary build and compilation files.
  • Build/, Builds/ — compiled game outputs.
  • IDE folders — .vs/, .vscode/ and user-specific files.
  • OS files — .DS_Store, Thumbs.db.
Key Takeaway
Key Takeaway

Create and verify .gitignore before large commits; untrack generated files already in Git to avoid long-term bloat.
