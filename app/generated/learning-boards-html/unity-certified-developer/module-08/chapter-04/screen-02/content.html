Why these objectives matter
  • They prevent lost work and allow safe collaboration across artists and programmers.
  • They keep repository size manageable, so clones and CI remain fast.
  • They make scene and prefab merges predictable by using text serialization and visible meta files.
Assessment readout

You will demonstrate competency by initializing a Git repo, committing tracked folders, configuring Git LFS for common asset types, and successfully pushing to a remote without accidentally committing Library or Temp folders.
