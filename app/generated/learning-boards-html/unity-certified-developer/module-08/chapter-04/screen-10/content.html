Module 08 › Chapter 8.4 › Common Git Operations — Terminal Demo
Starter sequence
$ git init
$ git add .
$ git commit -m "Initial Unity project setup"
$ git remote add origin <repository_url>
$ git push -u origin main
Use clear commit messages that describe what changed and why.
Branching workflow
$ git checkout -b feature/new-level
# make changes
$ git add .
$ git commit -m "Start new level"
$ git push origin feature/new-level
# switch and merge
$ git checkout main
$ git pull origin main
$ git merge feature/new-level
$ git push
Always pull before creating a branch and before merging to reduce avoidable conflicts.
Check your understanding

After creating a branch and pushing it, switch back to main and verify the new scene disappears, then merge the branch to bring it back. This demonstrates isolated work and merging behavior.
