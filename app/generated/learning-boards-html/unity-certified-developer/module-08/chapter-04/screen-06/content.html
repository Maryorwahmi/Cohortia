Module 08 › Chapter 8.4 › What Unity Files to Track and What to Ignore
Files to track
  • Assets/ — scripts, scenes, prefabs, art that define the game.
  • ProjectSettings/ — project configuration shared across team.
  • Packages/ — manifest of Unity packages used by the project.
  • .meta files — maintain GUIDs and references; never ignore.
Example

When you add a material or script to Assets, commit it so everyone receives the same authoritative content.

Files to ignore
  • Library/ — local imported cache, regenerates per machine.
  • Temp/, obj/ — intermediate build and compile data.
  • Build/, Builds/ — game output folders that bloat repos.
  • .vs/, .vscode/ — IDE settings and user files.
Common mistake
Warning

Tracking Library/ causes merge noise and large history; never commit generated caches.
