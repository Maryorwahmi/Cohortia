Module 08 › Chapter 8.4 › Unity Editor Settings for Source Control
Visible Meta Files

This setting causes Unity to generate .meta files for every asset. These files store GUIDs and import settings that keep references stable across machines.

Practical step

Set Version Control Mode to Visible Meta Files under Edit > Project Settings > Editor, then commit ProjectSettings so the team shares the setting.

Example

With .meta files tracked, moving or renaming assets does not break scene links because GUIDs remain consistent.

Force Text serialization

Set Asset Serialization Mode to Force Text so scenes, prefabs, and other assets serialize as readable text. This makes diffs and merges possible.

Why it helps
  • Merges show line-level differences instead of opaque binaries.
  • Conflict resolution becomes a human process rather than restoring from backups.
Key Takeaway
Key Takeaway

Enable both settings and commit ProjectSettings to make assets and scenes merge-friendly across your team.
