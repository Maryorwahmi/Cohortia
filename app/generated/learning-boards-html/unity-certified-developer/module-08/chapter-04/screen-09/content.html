Module 08 › Chapter 8.4 › Git LFS — Setup and Common Commands
Quick command list
$ git lfs install
$ git lfs track "*.psd" "*.fbx" "*.png"
$ git add .gitattributes
$ git commit -m "Track large assets with Git LFS"
$ git lfs migrate import --include="*.png"  # rewrite history if needed
Commit .gitattributes so everyone clones with the same LFS rules. Use migrate sparingly and coordinate when rewriting history.
Checks and troubleshooting
  • After clone, run git lfs pull if binaries are missing.
  • Confirm tracked patterns with git lfs track --list.
  • If large files were pushed before tracking, plan a migrate import to move them into LFS.
Key Takeaway
Key Takeaway

Define LFS patterns early and commit .gitattributes. If large files are already in history, use migrate import carefully and coordinate with your team.
