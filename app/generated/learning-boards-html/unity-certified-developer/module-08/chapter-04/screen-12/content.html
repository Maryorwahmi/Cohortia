Module 08 › Chapter 8.4 › Common Mistakes and Safety Practices
Top mistakes
  • Committing Library/ or build outputs.
  • Ignoring .meta files that store GUIDs.
  • Adding large assets without Git LFS.
  • Working directly on main without feature branches.
Safety practices
  • Set Visible Meta Files and Force Text in Editor and commit ProjectSettings.
  • Create a robust .gitignore and commit it before large commits.
  • Run git lfs track early and commit .gitattributes.
  • Use branch workflows with PRs and small incremental commits.
Key Takeaway

Set up repository hygiene once and follow it consistently: you’ll avoid repeated conflicts and huge repo sizes later.
