Module 08 › Chapter 8.4 › Lab Walkthrough: Initialize a Unity Project with Git & LFS
Step-by-step checklist
  1. Create project, set Visible Meta Files and Force Text, save scene.
  2. git init at project root.
  3. Create and commit .gitignore.
  4. git lfs install; git lfs track for common asset types; commit .gitattributes.
  5. git add .; git commit -m "Initial Unity project setup with Git LFS"; git remote add origin; git push -u origin main.
Practice actions
  • Add a script, material, and LFS-tracked PNG, then commit and push.
  • Create a feature branch, add a scene, push the branch, then switch back to main and merge after review.
  • After clone, run git lfs pull if assets appear as pointers.
Key Takeaway

Completing this lab shows your repository is clean, LFS-managed, and ready for collaborative work with predictable merges.
