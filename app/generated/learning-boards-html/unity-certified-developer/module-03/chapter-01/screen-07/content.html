Collider choices and guidance
BoxCollider
Best for rectangular objects and ground platforms.
SphereCollider
Ideal for balls and smooth collisions in any direction.
CapsuleCollider
Common for characters—smooth sliding and fewer snag points.
MeshCollider: use with caution
High-fidelity but expensive. Non-convex mesh colliders are unsuitable for dynamic objects. Prefer convex or primitive approximations for moving bodies.
Key Takeaway

Start with primitives. Use mesh colliders only when necessary and prefer convex for dynamic usage.

Concrete example
A character: one CapsuleCollider for the main body, SphereColliders for hands. A car: multiple BoxColliders for the chassis and SphereColliders for wheels approximation, instead of a full mesh collider.
Misconception
Believing mesh colliders always improve realism. Often approximations with primitives are visually indistinguishable in gameplay and far cheaper.
