Learning Objectives
Learn, Understand, Apply, Master — a short Bloom progression to measure competency.
01
Rigidbody types
Differentiate static, kinematic, and dynamic Rigidbodies and choose appropriate use cases.
Mnemonic: think of static as scenery, kinematic as scripted motion, dynamic as physics-driven. VERIFIED COMPETENCY MILESTONE
02
Colliders
Configure Box, Sphere, Capsule, and Mesh colliders and understand collision cost.
Mnemonic: primitives first, mesh only when necessary. VERIFIED COMPETENCY MILESTONE
03
Collision vs Trigger
Implement OnCollision and OnTrigger callbacks in C# and know the Rigidbody requirement.
Mnemonic: trigger = detect, collision = block. VERIFIED COMPETENCY MILESTONE
04
Materials & Forces
Apply PhysicMaterials and AddForce with the correct ForceMode inside FixedUpdate for reliable motion.
Mnemonic: impulse for jumps, force for steady pushes. VERIFIED COMPETENCY MILESTONE
