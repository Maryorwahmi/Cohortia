Collision handler sample
void OnCollisionEnter(Collision collision)
{
    // collision.contacts contains contact points
    // collision.rigidbody references the other Rigidbody if present
    // Apply impulse to other object if it has a Rigidbody
}
Use Collision.contacts to get the impact normal and position. This is essential when you need to apply a reaction such as pushing another object away at the contact point.
Trigger handler sample
void OnTriggerEnter(Collider other)
{
    // other is the overlapping collider
    // Typical pattern: if (other.CompareTag("Player")) { Destroy(gameObject); }
}
Triggers are ideal for pickups and zones. They don't block motion and do not provide collision contact info.
Common Mistake

Expecting OnTriggerEnter to include impact points. Use collisions for contact data and triggers for detection only.
