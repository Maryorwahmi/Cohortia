Module 3 › Chapter 3.1 › Rigidbody Types
Mode comparison cards
Static (no Rigidbody)
Used for environment geometry. Cheapest for collisions. Does not move under physics.
Kinematic
Driven by code (MovePosition/MoveRotation). Can push dynamic bodies but ignores forces itself.
Dynamic
Fully simulated: affected by gravity, forces, and collision responses.
Key Takeaway

Pick the simplest mode that achieves your gameplay: static for scenery, kinematic for scripted motion, dynamic for physical interaction.

Concrete scenario
A moving platform that follows a path should be kinematic so it reliably moves along a curve and still pushes a dynamic player. Avoid making everyday static walls dynamic unless they must react to forces.
Misconception check
Some learners assume kinematic Rigidbodies are unaffected by collisions. In fact they collide, but they do not receive forces; they can push dynamics but remain under script control.
Question to reflect
Which mode would you choose for a destructible crate that should topple when hit, and why?
