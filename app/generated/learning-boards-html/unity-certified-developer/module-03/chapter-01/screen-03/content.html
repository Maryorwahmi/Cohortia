Module 3 › Chapter 3.1 › Implementation Focus
Objective: Rigidbody Properties

Adjust mass, drag, and angular drag, then apply AddForce to observe acceleration and damping. Verify by watching displacement over a few seconds and by toggling gravity.

Validation
  • Play the scene and apply AddForce; heavier mass responds slower.
  • Increase drag to slow steady movement; angular drag reduces rotation over time.
Objective: Colliders & Materials

Assign primitive colliders and PhysicMaterials. Test a bouncy ball on different surfaces and compare bounce height to validate material settings.

Validation
  • Use primitive colliders for moving objects and confirm stable collisions.
  • Check logs from OnTriggerEnter when picking up items in-game.
Objective: Callbacks

Implement OnCollisionEnter and OnTriggerEnter to respond to events using CompareTag and to apply impulses to other Rigidbodies.

Validation
  • Confirm event logs appear and that push behavior uses ForceMode.Impulse.
Objective: FixedUpdate

Move all physics code into FixedUpdate to remove jitter and frame-rate dependent behavior. Verify stability on fluctuating frame rates.

Validation
  • Compare Update-driven movement with FixedUpdate: FixedUpdate yields stable collisions and impulses.
