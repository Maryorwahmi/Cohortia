What this chapter covers

You will learn the building blocks of Unity physics: Rigidbody roles, common collider types, triggers versus collisions, physics materials, and how to apply forces reliably.

In this lesson
Set up a player cube with Rigidbody and use AddForce for jumping. Detect pickups with a trigger collider.
Performance
Prefer primitive colliders for moving objects and avoid non-convex MeshColliders on dynamic bodies.
Forces
ForceMode controls whether a force is instantaneous or continuous — choose Impulse for jumps and Force for steady pushes.
Triggers
Use trigger colliders for detection zones that should not block motion, but ensure at least one object has a Rigidbody.
Explore Key Topics
Rigidbody types, Collider selection, Force application — the essential decisions that shape movement and collision behavior.
