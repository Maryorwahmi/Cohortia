Starter script pattern
// Pseudocode summary of the pattern
void Start() {
  rb = GetComponent<Rigidbody>();
  if (rb == null) { enabled = false; }
}
void FixedUpdate() {
  // read cached input, apply movement via rb.AddForce(...)
  // on jump input: rb.AddForce(up * jumpForce, ForceMode.Impulse)
}
void OnCollisionEnter(Collision c) { if (c.gameObject.CompareTag("Ground")) isGrounded = true; }
void OnTriggerEnter(Collider other) { if (other.CompareTag("Pickup")) Destroy(other.gameObject); }
This pattern reduces runtime errors, keeps physics deterministic, and cleanly separates detection from game logic. Test by toggling isKinematic on the other objects to observe different interactions.
Pro tip

Capture input in Update, then apply it in FixedUpdate. This avoids input being missed when FixedUpdate skips frames between updates.
