SphereCast
Sweeps a sphere along a direction and returns the first hit. Good for simulating projectile radius or forgiving aim.
When to use
  • Wide fast-moving bullets that could otherwise miss with a line.
  • Player capsule checks when moving through narrow gaps.
Example
Use SphereCast to detect enemies near the ray path for wider projectiles; adjust radius to control spread.
OverlapSphere / OverlapBox
Return all colliders inside a defined volume at a point in time. Use for area-of-effect damage, proximity triggers, and detection zones.
Performance notes
  • Limit layers to avoid large result sets.
  • Prefer non-alloc variants and reuse arrays to avoid GC spikes.
Analogy
SphereCast is like rolling a ball along a path; Overlap checks who is inside a room when you open the door.
