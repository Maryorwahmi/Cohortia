Module 3 › Chapter 3.4 › Collision Callbacks
What they provide
  • Other collider and GameObject reference.
  • Contact points and surface normals.
  • Relative velocity between objects.
Example: bounce
Use the first contact normal to reflect the incoming direction and apply an impulse to the Rigidbody to simulate a bounce.
Patterns
OnCollisionEnter: one-off reactions. OnCollisionStay: continuous effects. OnCollisionExit: cleanup and state reset.
Common mistake
No callbacks fire because neither object has a Rigidbody. Add a Rigidbody to one object to ensure events occur.
Key Takeaway

Collision callbacks expose contact data and run in the physics loop—use them for physical interactions and continuous effects, caching components for efficiency.
