Module 3 › Chapter 3.4 › FixedUpdate
Process: Input → Apply in FixedUpdate
  1. Update: Read player input and store it in a field (e.g., moveDirection).
  2. FixedUpdate: Use the stored input to call Rigidbody.AddForce or set velocity.
  3. Physics engine resolves movement and calls collision/trigger callbacks during the same fixed step.
  4. LateUpdate/Render: visuals update to reflect the resolved physics state; enable Rigidbody interpolation for smoothness.
Misconception
Putting Rigidbody.AddForce in Update guarantees smooth movement. (It can cause inconsistent physics because Update timing varies.)
Key Takeaway

Keep physics writes in FixedUpdate and read inputs in Update. Use interpolation for rendered smoothness between physics ticks.
