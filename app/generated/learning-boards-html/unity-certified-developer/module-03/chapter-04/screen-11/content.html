Module 3 › Chapter 3.4 › LayerMask & Performance
Practical checklist
  • Create focused physics layers (e.g., TargetLayer, Environment, Player).
  • Expose public LayerMask to the Inspector and assign it to scripts that cast rays.
  • Set a sensible max distance for each query.
  • Use non-alloc APIs and reuse arrays for many simultaneous checks.
Pro tip
If you must check many rays, do fewer per frame or spread them across frames and interpolate results.
Inspector example
Expose public LayerMask shootableLayers; then assign the TargetLayer in the Inspector to avoid hitting environmental geometry.
