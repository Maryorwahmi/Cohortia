Module 3 › Chapter 3.4 › Common Mistakes
Mistake checklist
  • No Rigidbody on either object — callbacks won’t fire.
  • Forgetting Is Trigger — you intended an overlap but created a collider.
  • Physics changes in Update — leads to inconsistent behavior.
  • Unfiltered raycasts every frame — high CPU cost.
  • Repeated GetComponent calls in Stay — avoid allocation and slowdown.
Profiling tips
Use the profiler to find expensive-ray hotspots. Limit layers, reduce cast frequency, and use non-alloc variants to cut CPU and GC load.
Key Takeaway

Run through a short inspection routine: Rigidbody presence, trigger flags, LayerMasks, and cached components to avoid most common physics issues.
