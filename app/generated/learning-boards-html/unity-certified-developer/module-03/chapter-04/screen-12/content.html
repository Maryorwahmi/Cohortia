Module 3 › Chapter 3.4 › Hands-on Activity
Step-by-step
  1. Create Ground, Player (Cube) with kinematic Rigidbody, Target (Sphere) with collider and TargetHealth script.
  2. Create Collectible with Is Trigger checked and a CollectibleItem script that checks for the player's tag.
  3. In PlayerShooting, on mouse click, cast a ray from Camera.main center with a public LayerMask for TargetLayer.
  4. On hit, call TakeDamage on TargetHealth; on collectible trigger, destroy the collectible and award score.
Test checklist
Verify Debug.DrawRay visuals, confirm Target health decreases, and ensure collectible disappears on player overlap.
Starter code hints
Expose public LayerMask shootableLayers in PlayerShooting. Implement TargetHealth.TakeDamage and CollectibleItem.OnTriggerEnter to check other.CompareTag("Player"). Add Debug.DrawRay for hit and miss visualization.
Reflection prompt
