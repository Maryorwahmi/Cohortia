Module 3 › Chapter 3.4 › Raycasting
Definition & result
A directed query returning a RaycastHit containing the collider, hit point, and surface normal.
Common uses
  • Gun fire and instant-hit weapons.
  • Ground checks for jumping and stepping.
  • Line-of-sight for AI detection.
Example
Cast from the camera center and if a hit has a TargetHealth component, call its TakeDamage method. Use Debug.DrawRay to visualize hits versus misses.
Key Takeaway

Raycasts are lightweight single-hit queries—filter and visualize them while debugging.

Code panel (visual)
// Pseudocode representation for clarity
Ray ray = Camera.main.ViewportPointToRay(new Vector3(0.5f,0.5f,0));
RaycastHit hit;
if (Physics.Raycast(ray, out hit, maxDistance, layerMask)) {
  // Debug: draw red ray to hit point
  // Try to get health component and call TakeDamage
} else {
  // Debug: draw green ray to max distance
}
Misconception
Raycasts return all nearby colliders. (They return only the first hit unless you use a different query.)
Pro tip
Use LayerMask and a reasonable maxDistance to reduce cost. Use non-alloc variants when casting many rays.
