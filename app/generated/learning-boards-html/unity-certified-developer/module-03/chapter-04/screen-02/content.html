Learning Objectives
Progress from detection to event-driven responses
Learn → Understand → Apply → Master
01
Perform Raycasts & SphereCasts
Cast a line or sphere to detect objects and read hit information. This lets you check line-of-sight or simulate a wider projectile.
Mnemonic: Laser (ray) vs Bubble (sphere)
Verified Competency Milestone
02
Filter Results with LayerMask & Distance
Keep physics queries fast by selecting relevant layers and limiting distance. This reduces wasted checks and improves performance.
Mnemonic: Cone of Interest
Verified Competency Milestone
03
Implement Collision Callbacks
React to physical contacts using OnCollisionEnter, Stay, and Exit. Use the Collision object for contact points and relative velocity.
Mnemonic: Touch, Hold, Leave
Verified Competency Milestone
04
Implement Trigger Callbacks & FixedUpdate
Use OnTrigger callbacks for overlap zones and run physics changes in FixedUpdate for consistent behavior across machines.
Mnemonic: Zone, Persist, Predict
Verified Competency Milestone
