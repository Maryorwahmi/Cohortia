Practical considerations
  • Cache GetComponent results in Start or Awake to avoid repeated cost in Stay callbacks.
  • Mark colliders as Is Trigger for overlap-only detection; otherwise use collision callbacks.
  • At least one object must have a Rigidbody for collision/trigger callbacks to fire.
  • Place physics changes and Rigidbody.AddForce calls inside FixedUpdate for determinism.
Event-driven example
A projectile calls TakeDamage on a target when its collision occurs. The projectile does not assume how the target stores health; it simply looks for a Health-like component and calls a method if present.
Benefit: loose coupling and single responsibility.
