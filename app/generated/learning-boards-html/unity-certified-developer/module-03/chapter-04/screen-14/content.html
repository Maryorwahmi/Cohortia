Module 3 › Chapter 3.4 › Key Concepts
Raycasting
Line queries that return the first hit and metadata; filter with LayerMask and distance.
Collision Callbacks
OnCollisionEnter/Stay/Exit provide contact data and run during physics when a Rigidbody is present.
Trigger Callbacks
Non-physical overlap detection for pickups and zones; ensure Is Trigger and Rigidbody setup.
Summary takeaway: filter, cache, and run physics in FixedUpdate for reliable, modular interaction handling.
