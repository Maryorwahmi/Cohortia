Module 3 › Chapter 3.4 › Player Shooting
Pattern overview
  1. On input, construct a ray from Camera.main through the screen center.
  2. Call Physics.Raycast with an out RaycastHit, a max distance, and a LayerMask.
  3. Draw a debug ray for hit or miss to verify direction and filters.
  4. If the RaycastHit has a target component, call TakeDamage and destroy the projectile if applicable.
Scenario
A click triggers a shooter that should only hit objects on the TargetLayer. The shooter must not penalize performance while the player looks around.
Code (visual)
// Simplified pseudocode
void Shoot() {
  Ray ray = Camera.main.ViewportPointToRay(0.5,0.5);
  if (Physics.Raycast(ray, out hit, distance, shootableLayers)) {
    Debug.DrawRay(ray.origin, ray.direction * hit.distance, Color.red, 1f);
    var target = hit.collider.GetComponent<TargetHealth>();
    if (target != null) target.TakeDamage(10);
  } else {
    Debug.DrawRay(ray.origin, ray.direction * distance, Color.green, 1f);
  }
}
