Module 3 › Chapter 3.4 › Event-driven Communication
Pattern description
Producer detects an interaction and requests a behavior from the consumer via a known component or event, rather than modifying consumer internals.
Example
Projectile OnCollisionEnter tries GetComponent<Health> on the hit object and calls TakeDamage if available. The Health script handles death and score differently per object.
Design benefits
  • Loose coupling
  • Single responsibility
  • Flexible behavior swapping
Refactor prompt
If a projectile directly changes an enemy's score field, refactor so it calls a public method on a score manager or the enemy's public method to handle scoring internally.
