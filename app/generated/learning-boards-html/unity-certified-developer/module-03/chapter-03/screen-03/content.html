Implementation Checklist
Four validation checks to complete during your lab.
Rigidbody checks
  • Call MovePosition or set velocity in FixedUpdate to avoid jitter.
  • Preserve vertical velocity when setting rb.velocity to keep gravity working.
  • Adjust drag or PhysicMaterial to prevent sliding.
CharacterController checks
  • Use controller.isGrounded and reset vertical velocity when grounded.
  • Apply manual gravity every Update and move the controller with Move().
  • Implement OnControllerColliderHit to push rigidbodies if needed.
Gameplay checks
  • Compare feel: responsiveness, collision response, and external force reaction.
  • Test jumping across different frame rates for consistency.
Debug targets
  • Fix sliding with drag or PhysicMaterial adjustments.
  • Fix floating with explicit gravity application for CharacterController.
