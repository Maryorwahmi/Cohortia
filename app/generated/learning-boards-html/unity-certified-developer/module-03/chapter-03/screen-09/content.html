Jump implementations
Two patterns depending on controller type.
Rigidbody jump
Apply AddForce upward with impulse mode. Keep horizontal velocity untouched to preserve momentum.
CharacterController jump
Calculate initial vertical velocity from desired height and gravity, add to playerVelocity.y, then apply gravity each Update.
Ground checks
Use controller.isGrounded for CharacterController and collision or raycast checks for Rigidbody to prevent double jumps.
Dashing
Short bursts of speed applied horizontally.
Rigidbody dash
Apply a quick AddForce with ForceMode.VelocityChange or set velocity for a single frame to achieve a crisp dash.
CharacterController dash
Temporarily add a strong horizontal displacement to the Move call for a brief duration; clamp collisions as necessary.
Common mistake
Allowing dash and jump without proper state gating causes unintended movement stacks; gate actions behind grounded or cooldown checks.
