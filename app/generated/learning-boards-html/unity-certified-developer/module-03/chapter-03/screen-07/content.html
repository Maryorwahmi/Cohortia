How CharacterController works
It handles collisions and sliding but not physics forces; you drive motion directly.
Move() API
Pass a displacement vector to Move. The controller attempts to move, slides along colliders, and updates isGrounded for you.
Vertical motion
Maintain playerVelocity.y and apply gravity each Update. Reset the vertical velocity when isGrounded and the value is negative.
Collision callbacks
Use OnControllerColliderHit for controller-specific collision events; OnCollisionEnter will not fire for the controller itself.
Key Takeaway

CharacterController is ideal for responsive, collision-aware player movement when you do not need physics forces.

Example: manual gravity flow
Compute horizontal movement from input, call controller.Move(horizontal * speed * deltaTime), update playerVelocity.y with gravity, and call controller.Move(playerVelocity * deltaTime) for vertical displacement.
Common mistake
Forgetting to reset playerVelocity.y when grounded causes accumulating negative velocity or inconsistent jumps.
Pro tip
Use controller.isGrounded for a quick ground check, and add a small downward offset when necessary for steeper slopes.
