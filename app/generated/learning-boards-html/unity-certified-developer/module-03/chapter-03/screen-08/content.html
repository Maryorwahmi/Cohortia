Rigidbody pattern
Compute target velocity and lerp rb.velocity in FixedUpdate.
Steps
  1. Get normalized input direction.
  2. targetVelocity = direction * moveSpeed; targetVelocity.y = rb.velocity.y
  3. Lerp rb.velocity towards targetVelocity using acceleration * Time.fixedDeltaTime.
Tuning
Adjust accelerationFactor for responsiveness and drag for natural slow-down.
CharacterController pattern
Compute horizontal move and call Move() with Time.deltaTime scaling.
Steps
  1. Read input and build horizontal move vector relative to facing.
  2. controller.Move(move * moveSpeed * Time.deltaTime).
  3. Apply playerVelocity.y vertical motion with controller.Move(playerVelocity * Time.deltaTime).
Tuning
Use run multipliers, and clamp maximum horizontal speed to keep consistent feel.
Common misconception
Assuming physics will make movement feel better; sometimes deterministic control gives clearer, more responsive gameplay.
