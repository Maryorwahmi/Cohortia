Rigidbody movement explained
For characters that should respond to forces and push other physics bodies.
Primary APIs
Apply AddForce for impulses, set rb.velocity for direct control, or use MovePosition for interpolation that still respects collisions.
Bulleted tips
  • Call physics changes in FixedUpdate to match the physics timestep.
  • Preserve rb.velocity.y when modifying velocity so gravity keeps working.
  • Adjust drag or PhysicMaterial to control sliding on surfaces.
Example scenario
A player uses an impulse to jump and later is pushed by a moving crate; both interactions use rigidbody forces for natural motion.
Key Takeaway

Rigidbody movement integrates with the physics engine—use it when forces and realistic interactions matter.

Common mistake
Setting transform.position on a Rigidbody causes unstable physics and jitter.
