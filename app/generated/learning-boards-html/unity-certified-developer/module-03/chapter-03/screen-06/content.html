Direct transform motion
Fast and simple but not physics-aware.
Use cases
Background scrolling, UI panels, or tightly scripted cinematic movement without physics.
Limitations
Transform updates ignore physics collisions and will not trigger OnCollisionEnter or natural responses from physics objects.
Developer check
If your moving object must push or be pushed, prefer Rigidbody or implement raycasts and overlap checks in your script.
Key Takeaway

Transform motion is efficient but bypasses collision physics—choose it only when you control interactions explicitly.

Example scenario
A cinematic camera dolly that follows a spline should use Transform updates for exact positioning. If that dolly needs to push physics objects, redesign it as a kinematic Rigidbody and use MovePosition instead.
Common mistake
Expecting OnCollisionEnter callbacks from transform-controlled motion; they won't happen without explicit physics queries.
Pro tip
If you need both precise position and collision response, consider a kinematic Rigidbody and MovePosition called in FixedUpdate.
