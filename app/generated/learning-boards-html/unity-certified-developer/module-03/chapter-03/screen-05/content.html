Module 3 › Chapter 3.3 › Rigidbody methods
When to use each method
Practical patterns and a pseudo-code walkthrough to show timing and data flow.
AddForce
Use for impulses and continuous forces where physics should determine acceleration and collisions.
Velocity control
Set or lerp rb.velocity for precise horizontal speeds. Preserve vertical component to keep gravity intact.
MovePosition
Interpolate the Rigidbody smoothly while still allowing collision resolution; call from FixedUpdate.
Key Takeaway

Synchronize Rigidbody work with FixedUpdate and select the method that balances realism and control for your game feel.

Common mistake
Calling MovePosition or velocity changes in Update can produce inconsistent collision responses across frame rates.
Pro tip
Use small drag values and PhysicMaterials on surfaces to tune how quickly a body stops instead of forcing velocity to zero abruptly.
