Learning Objectives
From physics-driven motion to manual gravity: build, test, and tune movement.
Bloom: Learn → Understand → Apply → Master
01
Rigidbody Movement
Implement AddForce, MovePosition, and velocity control to let characters participate in physics. This matters when interacting with crates, forces, and other bodies.
Mnemonic: force ↔ motion
VERIFIED COMPETENCY MILESTONE
02
Transform-based Motion
Use direct transform updates for non-physics objects and cinematics. Know this prevents collision responses and requires raycasts if collisions are needed.
Mnemonic: direct position
VERIFIED COMPETENCY MILESTONE
03
CharacterController Usage
Control collisions without a Rigidbody and implement manual gravity and jumps. Useful for tight, responsive player controls.
Mnemonic: move + gravity
VERIFIED COMPETENCY MILESTONE
04
Movement Patterns & Debugging
Implement walking, running, jumping and dashing; fix sliding, floaty jumps, and mixing controller types. These skills improve feel and reduce bugs.
Mnemonic: test & tune
VERIFIED COMPETENCY MILESTONE
