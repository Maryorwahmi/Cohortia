Module 4 › Chapter 3.5 › RagdollActivator
Core pattern
Keep arrays of rigidbodies and colliders, initialize ragdoll disabled, and toggle state on Die().
Sample outline
Start: populate ragdollRigidbodies with GetComponentsInChildren.\nSetRagdollState(false).\nOn Die: animator.enabled = false; SetRagdollState(true); optional AddForce impulse.
Common mistake
Forgetting to enable detectCollisions or leaving one Rigidbody as kinematic will cause visual gaps or stuck limbs.
Concrete scenario
Initialization
If arrays are empty, populate them with GetComponentsInChildren in Start to avoid null references.
Die action
Disable Animator, set all rigidbodies isKinematic=false and colliders enabled, then optionally apply a one-time impulse.
Misconception
Calling AddForce repeatedly to simulate collapse creates instability; prefer a single impulse and let physics resolve motion.
Key Takeaway

Switch control cleanly from animator to physics once, ensure all parts are enabled, and avoid per-frame manual velocity writes.
