Module 4 › Chapter 3.5 › Lab Walkthrough
Checklist
  1. Create Torso cube, add Rigidbody and BoxCollider.
  2. Add limb cubes as children; give each Rigidbody and BoxCollider.
  3. Set torso mass higher, limbs lower.
  4. Add ConfigurableJoint on parent, ConnectedBody = child Rigidbody.
  5. Lock linear motions, set angular limits for joints.
  6. Create RagdollActivator, populate arrays, toggle ragdoll on input.
  7. Create Ragdoll layer and edit Layer Collision Matrix as needed.
Troubleshooting
Jitter fix
Ensure colliders don't start overlapping, check for missing rigidbodies, and reduce spring strength if oscillation occurs.
No collapse
Confirm animator is disabled when ragdoll is active and rigidbodies are non-kinematic with colliders enabled.
Layer issues
If parts pass through each other or ground, check Layer Collision Matrix entries and collider enable states.
Key Takeaway

Follow the steps, then iterate on limits, masses, and colliders until the ragdoll behaves naturally and performs well.
