Module 4 › Chapter 3.5 › Layer Collision Matrix
Definition
A matrix in Project Settings that defines which layers perform collision checks. Unchecking boxes prevents those layer pairs from colliding at all.
Example configuration
  • Projectile vs Projectile = disabled
  • Projectile vs Player = disabled (if friendly fire off)
  • Ragdoll vs Ragdoll = disabled (optional for smoother limbs)
Concrete scenario
Reducing checks
If 1,000 projectiles are spawned, disabling Projectile vs Projectile stops O(n^2) checks between them and lowers CPU load.
Gameplay control
Preventing projectiles from hitting the player or friendly projectiles creates predictable interactions without per-object checks.
Misconception
Do not rely solely on the matrix for fine-grained per-object filtering; it is a coarse and efficient filter best combined with masks and checks.
Key Takeaway

Plan layers to express interaction categories, then disable unnecessary pairs to save CPU and avoid unintended collisions.
