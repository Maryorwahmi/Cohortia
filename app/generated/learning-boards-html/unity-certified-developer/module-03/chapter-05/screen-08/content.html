Module 4 › Chapter 3.5 › Colliders & Rigidbodies
Comparison

Primitive vs MeshCollider

Primitive colliders
Fast and predictable. Combine boxes/capsules for complex shapes.
MeshColliders
Use for static, complex geometry. Avoid non-convex mesh colliders on moving rigidbodies.
Concrete example
Replace many meshes
Swap multiple small mesh colliders on a moving crate for one box collider and a single Rigidbody to lower cost.
Rigidbody count
Only add rigidbodies to objects that need to move or respond to forces. Mark static objects as Static.
Misconception
Turning many parts into rigidbodies for realism can easily overwhelm the physics system; prioritize key interactive items.
Key Takeaway

Accuracy is valuable, but performance matters. Prefer primitives and keep the number of active rigidbodies under control.
