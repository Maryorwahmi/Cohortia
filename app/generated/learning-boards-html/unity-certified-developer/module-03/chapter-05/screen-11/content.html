Module 4 › Chapter 3.5 › Tuning Joints
Tuning steps
  1. Lock linear motion if limb length should remain constant.
  2. Set angular limits to match biological ranges for elbows and knees.
  3. Add limit springs and damper to control stiffness and oscillation.
  4. Test with final masses and colliders, then iterate.
Example
Elbow values
Lock Y/Z rotation, Angular X limit = -90 to 0. Limit Spring: Spring = 50, Damper = 7 for gentle return.
Avoid
Huge springs on very light limbs; this creates snapping and instability.
Misconception
Expecting limits alone to look natural; springs shape movement between limits and control energy dissipation.
Key Takeaway

Tune limits first, then add springs and damper to sculpt natural joint motion; always test with final masses and colliders.
