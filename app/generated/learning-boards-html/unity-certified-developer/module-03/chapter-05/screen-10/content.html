Module 4 › Chapter 3.5 › Manual Simulation
Definition

Physics.autoSimulation

Toggle auto-simulation in Project Settings and manually call Physics.Simulate(Time.fixedDeltaTime) when you need explicit control.
Example call
In your game loop: Physics.Simulate(Time.fixedDeltaTime); // once per physics tick
When to use it
Network servers
Run physics at a fixed tick independent of frame-rate for deterministic behavior.
Batched updates
Control when heavy physics updates occur to avoid spikes during gameplay peaks.
Misconception
Manual simulation is not a cure-all; incorrect timing or missed calls breaks physics entirely.
Key Takeaway

Only disable auto-simulation if you will reliably manage physics ticks; otherwise prefer built-in timing for correctness.
