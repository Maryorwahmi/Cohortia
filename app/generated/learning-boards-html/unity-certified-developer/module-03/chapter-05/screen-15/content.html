Module 4 › Chapter 3.5 › Optimization
Layer Matrix

Disable unnecessary layer collisions to cut down the number of pair checks the physics engine performs.

Sleeping

Allow objects to sleep naturally and wake them only for meaningful events to reduce per-step cost.

Collider Complexity

Prefer primitive colliders for dynamic objects; reserve complex meshes for static geometry only.

Final summary: profile first, then apply primitives, layer filters, sleeping, and managed simulation to keep physics performant and predictable.
