Module 3 › Chapter 3.2 › Axes & GetAxis
Concept
Named axes unify multiple bindings
An axis like Horizontal can map to keys and to a gamepad stick. GetAxis returns a smoothed float; GetAxisRaw returns the unsmoothed value.
• Use GetAxis when you want smoothing for natural movement.
• Use GetAxisRaw for responsive, immediate control.
• Tune sensitivity and dead zones in Project Settings to match expected device behavior.
Quick example
float h = Input.GetAxis("Horizontal");
float v = Input.GetAxisRaw("Vertical");
Vector3 move = new Vector3(h, 0, v);
transform.Translate(move * speed * Time.deltaTime);
Why this matters
Choosing the right axis method affects feel. For platformers or tight movement, prefer raw values; for smooth camera or character acceleration, prefer smoothed axis values.
Try it
Switch between GetAxis and GetAxisRaw and observe how acceleration and instant stops differ while walking and stopping with keyboard keys.
