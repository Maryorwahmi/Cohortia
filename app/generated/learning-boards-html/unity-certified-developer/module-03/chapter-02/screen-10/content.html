Module 3 › Chapter 3.2 › PlayerInput Component
Setup
Add PlayerInput to your player object, assign the Input Actions asset, and select Behavior. Use Invoke Unity Events to attach actions to inspector methods without writing subscription code.
• Drag PlayerControls into Actions field.
• Set Behavior to Invoke Unity Events for Inspector wiring.
• Expand your Action Map and connect Move, Jump, and Fire to methods on your player script.
Practical note
PlayerInput automatically enables the assigned action map, reducing manual calls to Enable and Disable.
Multi-player
PlayerInput can be instantiated per player and associated with a specific device, which helps route separate gamepads to different characters in local multiplayer setups.
Misconception
PlayerInput does not remove the need to write handlers; it only simplifies how actions are invoked. You still implement the methods that act on the inputs.
