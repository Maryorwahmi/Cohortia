Module 3 › Chapter 3.2 › Input Action Architecture
Hierarchy
Asset → Action Maps → Actions → Bindings
This layered structure lets you encapsulate controls and switch contexts at runtime without changing code. Keep maps aligned with states like Gameplay, UI, or Driving.
Input Action Asset
Scriptable object holding all maps and bindings.
Action Map
Contextual collection like Gameplay or UI.
Binding
Connects an Action to a key, button, or device control.
Design example
Create a Player map; add Move (Vector2) with WASD and left stick, Jump (Button) with Space and gamepad A, Fire (Button) with left mouse and right trigger. This keeps gameplay bindings grouped and easy to enable or disable.
