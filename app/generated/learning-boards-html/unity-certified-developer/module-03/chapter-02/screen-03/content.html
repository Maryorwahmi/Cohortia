Objective checklists
  • Use GetKeyDown and GetButtonDown for single-frame actions; use GetAxis for continuous values.
  • Create Input Actions assets and accept backend change when prompted to use the new system.
  • Group actions into Action Maps like Gameplay and UI to switch contexts cleanly at runtime.
  • Test inputs with keyboard and a gamepad to validate bindings and device routing.
