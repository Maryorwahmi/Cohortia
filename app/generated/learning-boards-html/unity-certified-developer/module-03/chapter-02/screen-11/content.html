Example callbacks
public void OnMove(InputAction.CallbackContext context)
{
    currentMovementInput = context.ReadValue();
}

public void OnJump(InputAction.CallbackContext context)
{
    if (context.performed && isGrounded)
    {
        rb.AddForce(Vector3.up * jumpForce, ForceMode.Impulse);
        isGrounded = false;
    }
}
Read the Vector2 in the callback and apply it during physics updates for consistent movement. Use context.performed when reacting to button presses.
Patterns
Store input values in fields inside callbacks, then in FixedUpdate compute a movement vector and call rb.MovePosition with Time.fixedDeltaTime to move the player reliably.
Misconception
Callbacks do not imply instantaneous physics application. Applying forces in callbacks can cause non-deterministic behavior; centralize physics in FixedUpdate.
