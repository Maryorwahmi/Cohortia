Module 3 › Chapter 3.2 › Input Timing & Physics
Rule
Read input timing, apply physics later
Read button presses and axes in Update or capture them via Input System callbacks. Apply movement forces and position changes in FixedUpdate to keep physics deterministic.
1. Read frame inputs with GetKeyDown or Input System callbacks.
2. Store the intent (vector or button press) in a field.
3. In FixedUpdate, use stored values to call rb.MovePosition or AddForce.
Example pattern
// capture in Update or callback
currentMovement = ReadMovement();

// apply in FixedUpdate
rb.MovePosition(rb.position + move * Time.fixedDeltaTime);
Pitfall
Reading GetKeyDown in FixedUpdate can miss single-frame presses because FixedUpdate may not execute every frame. Store intent in Update instead.
Pro tip
For the new Input System, set callbacks to update fields and use those fields during physics updates. This keeps event handling and physics consistent.
