Module 3 › Chapter 3.2 › Legacy Input Manager
Definition
Polling API for keys, buttons, and axes
You query the API each frame for input state using Input class methods. It's straightforward but less flexible for remapping and multi-device setups.
• Use GetKeyDown and GetButtonDown to detect presses that occur in a single frame.
• Use GetAxis for named axes such as Horizontal and Vertical; smoothing is applied unless you use GetAxisRaw.
• Read frame-based calls inside Update to avoid missed input events.
Concrete example
Input.GetButtonDown("Jump") triggers a jump the frame the player presses space when Jump is configured in Project Settings.
Common misconception
GetAxis is not always raw input; it can be smoothed. Use GetAxisRaw for immediate values.
Key Takeaway

Legacy input is simple and reliable for small projects, but plan for migration if you need remapping or robust multi-device support.

Quick reference
// Polling example
if (Input.GetButtonDown("Jump")){
  // trigger jump
}
float h = Input.GetAxis("Horizontal");
float v = Input.GetAxisRaw("Vertical");
Why this matters
Understanding the legacy API helps you read older projects and prototype quickly. It also establishes the timing rules you'll need when migrating to event-driven callbacks.
