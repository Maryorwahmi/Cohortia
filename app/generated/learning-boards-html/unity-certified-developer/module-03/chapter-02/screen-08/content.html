Module 3 › Chapter 3.2 › New Input System Setup
Steps
  1. Open Window → Package Manager and install Input System from the Unity Registry.
  2. Accept Unity's prompt to enable the new input backend and restart the editor if required.
  3. Right-click in Project window → Create → Input Actions to make an Input Action asset.
  4. Open the asset and add an Action Map named Gameplay or Player.
  5. Add Actions: Move (Value, Vector2), Jump (Button), Fire (Button). Add WASD composite and gamepad bindings for Move.
Key Takeaway
The asset is the canonical definition of your controls; treat it like configuration rather than code.
Bindings example
Move action: add a 2D Vector composite with Up=W, Down=S, Left=A, Right=D. Then add a binding for Gamepad Left Stick. Jump action: add Space and Gamepad A. Fire: Left Mouse Button and Gamepad Right Trigger.
Misconception
Installing the package without enabling the backend leaves the project on the legacy pipeline. Always accept the switch when prompted for new projects.
