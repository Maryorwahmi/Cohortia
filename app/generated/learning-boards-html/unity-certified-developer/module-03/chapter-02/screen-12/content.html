Module 3 › Chapter 3.2 › Legacy vs New Input System
Legacy Input Manager
  • Quick setup for simple projects.
  • Polling API using Input class and named axes.
  • Requires manual glue for remapping and multiple controllers.
When to use
Small prototypes, simple demos, or maintaining older projects.
New Input System
  • Data-driven Input Actions and Action Maps.
  • Better multi-device and multi-player support.
  • Cleaner remapping and runtime device pairing.
When to use
Games that need remapping, controller support, or local multi-player device routing.
Migration note
Avoid using both systems for the same actions. If you install the new package, follow Unity's prompt to switch the backend to avoid conflicts.
