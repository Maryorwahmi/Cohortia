Module 3 › Chapter 3.2 › Key Concepts
Don't mix systems
Using both for the same action can deliver duplicate or conflicting input events.
Use Action Maps
Group controls by context so switching between gameplay and UI is simple and deterministic.
Enable actions
If you manage assets in code, call Enable on action maps or ensure PlayerInput is active to receive events.
Final thought

Small design choices at the input layer determine how easy it is to add controllers, remap keys, or support local multiplayer. Design actions and maps deliberately.
