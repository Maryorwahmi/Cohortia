Module 02 › Chapter 2.2 › Debug.Log Use
Pattern
Debug.Log("Health after damage: " + currentHealth);
Debug.Log("Coins per player: " + coinsPerPlayer);
Include context text so you know what value you are looking at in a busy Console. Use concatenation or string interpolation when appropriate.
When to log
  • At Start or Awake to confirm initialization.
  • After critical calculations or type conversions.
  • When entering or exiting important branches for flow tracing.
Performance note
Logs have a runtime cost. Use them for development and remove or gate them behind debug flags for builds.
Key Takeaway

Debug.Log is a fast way to validate assumptions. Log meaningful messages with values to reduce debugging time.
