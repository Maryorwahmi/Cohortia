Module 02 › Chapter 2.2 › Common C# Data Types
Primitive Types
int
Whole numbers. Use for score, lives, indices. Example: int score = 0;
float
Decimal numbers. Use for speed and physics. Example: float speed = 5.5f;
bool
True/false state. Example: bool isAlive = true;
string
Text values. Example: string name = "Hero";
Unity-specific Structs
Vector2 and Vector3 combine float components for positions and directions. They are used by transforms, physics, and movement code. Example: Vector3 pos = new Vector3(0f, 1f, 0f);
Pitfall
Numeric literals without the float suffix are treated as double; append f to make them floats. Also beware integer division which truncates decimals.
Example
Use float for position and movement so you can express fractional values like 0.5 units per frame, and Vector3 to combine three floats into a position vector.
Key Takeaway

Match the type to the concept: counts use int, measures use float, positions use Vector3, and states use bool.
