Module 02 › Chapter 2.2 › Common Mistakes
Mistake: = vs ==
if (a = 5) { } // wrong in intent; use == to compare
Always use equality for comparisons. Assignment changes state and does not evaluate as a boolean comparison.
Mistake: integer division
float result = (float)7 / 2; // correct to get 3.5
If both operands are ints, the fraction is lost. Cast one operand to float to preserve decimals.
Mistake: exposing everything
Making all fields public increases coupling and hides the source of changes. Use [SerializeField] when you need Editor access but not public API exposure.
Debugging tip
Add targeted Debug.Log statements that include context text so you can quickly find which operation produced an unexpected value.
