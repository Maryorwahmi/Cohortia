Implicit vs Explicit
int a = 7; float b = a; // implicit
float x = 7.5f; int y = (int)x; // explicit cast truncates to 7
float result = (float)7 / 2; // 3.5f
When you explicitly cast, you accept the possibility of losing the fractional part. Use rounding functions when you need specific rounding behavior instead of silent truncation.
Example Scenario
Distributing coins among players: cast the total to float before dividing so you can display fractional results or compute percentages accurately.
Misconception
Casting always preserves value. It does not; float to int truncates and can silently drop important data if not handled intentionally.
Key Takeaway

Explicitly cast when you need more precision or to avoid truncation surprises. Verify with Console outputs.
