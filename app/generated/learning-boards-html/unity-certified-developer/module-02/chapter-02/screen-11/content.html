This example demonstrates declaration, Inspector exposure, arithmetic, shorthand assignment, comparisons, logical combinations, casting, and Console output in a compact script you can attach to a GameObject and run.
How to use it
  1. Create the script named GameStatsManager and paste the sample fields and Start logic.
  2. Attach it to any GameObject in the scene so Unity calls Start at play.
  3. Adjust public values in the Inspector, press Play, and open the Console to inspect Debug.Log messages.
Check
Change currentHealth to a low value and observe the isLowHealth log to confirm comparison logic.
Key Takeaway

Run variations in the Inspector and confirm that logs match your expectations. This loop reveals wrong assumptions quickly.
