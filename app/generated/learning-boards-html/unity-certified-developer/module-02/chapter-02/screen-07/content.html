Operators & Examples
int a = 10, b = 3;
sum = a + b; // 13
result = (float)a / b; // 3.333... cast to float for precision
remainder = a % b; // 1
Shorthand
health -= damage; is equivalent to health = health - damage and keeps code concise.
Misconception
Using / between ints truncates. It does not yield fractions unless you cast properly.
Practical Scenarios
  • Score update: score += pointsCollected;
  • Speed scaling: speed *= accelerationFactor;
  • Wrapping value: if (index % count == 0) { /* wrap to start */ }
Key Takeaway

Arithmetic operators are simple but require attention to operand types. Cast intentionally to preserve fractions.
