Module 02 › Chapter 2.2 › Comparison & Logic
Comparison Examples
bool canAttack = (playerLevel >= 3);
bool isLowHealth = (currentHealth < 30);
Comparison operators return booleans that you can use directly in if statements and ternary operations. They are the building blocks of decision-making.
Logical Combinations
bool canOpenDoor = isAlive && hasKey;
bool needsHelp = !hasShield || isLowHealth;
Practical check
Use parentheses to group complex expressions and keep the logic readable.
Gotcha
Do not use assignment inside conditionals. Use == to compare values; = assigns a value.
Key Takeaway

Combine simple comparisons with logical operators to define clear game rules. Keep expressions explicit.
