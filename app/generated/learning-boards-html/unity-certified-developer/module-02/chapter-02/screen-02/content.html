Learning Objectives

Clear, actionable goals to practice in the editor and Console.

Bloom: Learn → Understand → Apply → Master
01
Declare and initialize variables
Write declarations for int, float, bool, and string and assign starting values so code runs predictably. Verified competency milestone
Mnemonic: box label — name and type
02
Use C# operators
Apply arithmetic, comparison, and logical operators to implement game rules and checks. Verified competency milestone
Mnemonic: toolbox — compute and compare
03
Perform type conversions
Convert between compatible types and avoid precision loss using explicit casts when needed. Verified competency milestone
Mnemonic: adapter — convert safely
04
Debug with Console prints
Use Debug.Log to inspect values and program flow, helping you spot type and logic errors. Verified competency milestone
Mnemonic: magnifier — inspect state
