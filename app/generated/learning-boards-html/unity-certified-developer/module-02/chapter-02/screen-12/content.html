Activity Steps
  1. Create GameStatsManager with public and serialized private fields as shown in the lesson.
  2. Implement Start logic that modifies variables and prints results using Debug.Log.
  3. Attach the script to a GameObject, run the scene, and open the Console to inspect messages.
  4. Adjust Inspector values and repeat to observe how outputs change.
Casting check
int totalCoins = 15; int players = 4; float coinsPerPlayer = (float)totalCoins / players; // 3.75f
Pro Tip

Change one Inspector value at a time. That isolates cause and makes logs easy to interpret.

Common mistake

Forgetting the float suffix or the explicit cast when dividing leads to unintuitive integer results.
