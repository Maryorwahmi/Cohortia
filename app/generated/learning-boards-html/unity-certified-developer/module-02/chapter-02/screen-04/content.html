Module 02 › Chapter 2.2 › What is a Variable?
Definition & Example
int score = 0;
float playerSpeed = 5.5f;
string playerName = "Hero";
Think of the type as the shape of the container, and the name as its label. Initialize values to avoid relying on defaults.
Example
Use an int for a score counter so it cannot become fractional by mistake.
Common mistake
Leaving variables uninitialized or using the wrong type leads to runtime logic errors or compilation failures.
Inspector and Access
Mark variables public to expose them in the Inspector for tuning, or keep them private to protect internal state. Use the serialize attribute when you want visibility without public access.
Scenario
A designer needs to tweak enemy speed. Make speed public or use [SerializeField] on a private float so the designer can adjust it without changing code.
Key Takeaway

Declare the correct type and initialize explicitly. Use access modifiers to balance safety and flexibility.
