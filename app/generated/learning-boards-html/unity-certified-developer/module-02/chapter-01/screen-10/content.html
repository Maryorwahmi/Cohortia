Module 2 › Chapter 2.1 › Inspector & Console
Code Example
public class PlayerController : MonoBehaviour
{
    public float moveSpeed = 5.0f;

    void Start()
    {
        Debug.Log("PlayerController script started! Move speed is: " + moveSpeed);
    }

    void Update() {}
}
This example prints the value visible in the Inspector when Play starts, confirming script attachment and variable exposure.
Example Scenario
Set moveSpeed to 8 in the Inspector, press Play, verify the Console message shows 8. This proves Inspector values are passed into the running script.
Common Mistake
Not opening the Console or filtering log types can make it seem like your Debug.Log didn’t run. Always check Console filters.
Pro Tip
Use concise, unique log messages that include variable names so you can search the Console quickly.
