Definition

What are using directives?

They let the compiler resolve type names from a namespace without requiring fully qualified names. UnityEngine is the core namespace for the engine's types and services.

using System.Collections;
using System.Collections.Generic;
using UnityEngine;
Concrete Benefits
  • Simpler code: write Transform instead of a long path.
  • Fewer errors: the compiler recognizes common engine types.
  • Clear intent: other developers see which libraries you rely on.
Misconception: Removing a using directive changes behavior. It only affects compilation names; runtime behavior is unchanged if references are resolved.
