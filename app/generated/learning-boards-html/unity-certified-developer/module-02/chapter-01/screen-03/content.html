Verified Actions
01
Configure External Editor

Open Preferences > External Tools and choose Visual Studio or VS Code so code opens directly and debugging works.

02
Create Script

Create a new C# Script, name it clearly, double-click to open and inspect its skeleton code.

03
Attach to GameObject

Drag the script onto a Cube, then press Play and check the Console for expected messages.

04
Inspector Tuning

Change a public variable in the Inspector and rerun to confirm the new value prints to the Console.

Quick Mnemonic
Think: Configure → Create → Attach → Observe. This sequence prevents common setup mistakes and ensures scripts run as expected.
