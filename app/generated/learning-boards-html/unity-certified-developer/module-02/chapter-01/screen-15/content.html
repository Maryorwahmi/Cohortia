Pattern
Use private fields for internal state. When you need Inspector exposure without public access, use SerializeField on a private field. Provide sensible defaults in code.
[SerializeField]
private int maxHealth = 5;

public float moveSpeed = 5.0f; // for designers to tune
Team Tip
Document why a field is exposed, and prefer descriptive names so the Inspector is a readable tuning surface for non-programmers.
Example: Name a field playerSpeed rather than s to avoid confusion during tuning and testing.
