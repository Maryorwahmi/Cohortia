Core Concept

Script skeleton explained

using UnityEngine;

public class PlayerController : MonoBehaviour
{
    void Start()
    {
        // called before the first frame update
    }

    void Update()
    {
        // called once per frame
    }
}
using directives let you reference engine types. The class line declares a component you can attach. Start and Update are lifecycle hooks Unity calls at predictable times.
Misconception: code runs by being present. Reality: the component must be attached on a GameObject to run lifecycle methods.
Concrete Example
Create PlayerController, attach to a Cube, press Play, and see Start run once. That confirms the script attached and lifecycle callbacks are active.
Key Takeaway
Recognize the skeleton so you can add variables and logic in the correct places without breaking Unity's expectations.
Try This
Rename the class to match the file name. If they mismatch, Unity may show a compile error and the script won't attach correctly.
