Question 1
Which method should you use to set up references that other scripts' Start methods depend on, and why?
Answer: Awake — it runs when the instance loads and before Start, guaranteeing early initialization.
Question 2
You attached a script and pressed Play but see no Console output. List quick troubleshooting steps.
Checklist: fix compile errors, ensure attachment and enabled state, match file/class name, open Console and check filters.
