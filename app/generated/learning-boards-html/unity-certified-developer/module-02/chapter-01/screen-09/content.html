Core Concept

Typed variables

public float moveSpeed = 5.0f; // exposed in Inspector
private int currentLives = 3;     // internal state
[SerializeField]
private string playerName = "Hero"; // visible in Inspector but not public
Use public for designer-tunable values. Use SerializeField to keep a field private but still show it in the Inspector when needed.
Why it matters
Proper typing prevents runtime surprises and makes the Inspector a powerful tuning surface for designers and rapid prototyping.
Misconception
Making every field public is convenient but leads to maintenance problems. Prefer minimal exposure.
Example
Set moveSpeed in the Inspector while testing to tune movement without recompiling code.
