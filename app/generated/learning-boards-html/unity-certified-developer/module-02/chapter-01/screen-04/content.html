Module 2 › Chapter 2.1 › Editor Setup
Step 1
Open Preferences > External Tools

Find the External Script Editor dropdown and choose Visual Studio or Visual Studio Code to integrate with Unity.

Step 2
Verify tooling

Open a script from the Project window. Confirm IntelliSense, syntax highlighting, and that Visual Studio can attach to the Unity process for debugging.

Tip
Restart Unity after installing the IDE to ensure packages connect correctly.
Common Mistake
Selecting an editor but not installing required debugging components prevents breakpoints from working.
