Module 2 › Chapter 2.1 › Attach & Run
Step-by-step
  1. Create 3D Object > Cube in Hierarchy.
  2. Create > C# Script and name it GreetingScript.
  3. Drag the script onto the Cube. Confirm it shows in the Inspector.
  4. Press Play and open the Console to verify Awake and Start output.
Example Output
Awake() called: Script is loading. Start() called: Hello, Unity World! Your lucky number is: 7
Troubleshoot
If no messages appear, check for compile errors in the Console and ensure the component is enabled on the GameObject.
Pro Tip
Use unique log prefixes to filter Console results quickly while testing multiple scripts.
