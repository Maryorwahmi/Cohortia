Intro to C# & Visual Studio

Set up your editor, open a new script, and watch Unity call lifecycle methods when the scene runs.

16:9 HD Classroom

You'll configure Unity to use Visual Studio for features like IntelliSense and debugging. Then we'll inspect the default script structure, add a public variable, attach the script to a Cube, and confirm Awake and Start messages in the Console. These steps turn an editor into an active development environment for rapid iteration.

Remember: scripts must be attached to GameObjects to run lifecycle methods. Check the Console if nothing happens.
