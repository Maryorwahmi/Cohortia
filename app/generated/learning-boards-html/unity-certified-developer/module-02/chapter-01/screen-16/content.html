Module 2 › Chapter 2.1 › Key Concepts
Editor Integration
Use Visual Studio or VS Code to gain code completion and debugging capabilities that speed development.
MonoBehaviour Structure
A class that inherits MonoBehaviour can be attached to GameObjects and receives Awake, Start, and Update callbacks.
Inspector & Debugging
Expose tunable parameters with public or SerializeField, and verify behavior with Debug.Log in the Console.
Summary Takeaway

These fundamentals let you attach behavior to GameObjects, control initialization order, tune parameters in the Editor, and observe runtime behavior through the Console. Master them before building interactive mechanics.
