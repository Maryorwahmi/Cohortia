Module 2 › Chapter 2.1 › Troubleshooting
Compile Errors
Open the Console, fix the first error, then recompile. Many issues cascade from a single syntax mistake.
Attachment Issues
Confirm the component is on a GameObject and enabled. Scripts not attached won't get Awake or Start calls.
Console Visibility
Ensure log filters are not hiding messages and that the Console window is open while running the scene.
Quick Fix Flow
  1. Open Console; resolve first compile error.
  2. Verify script is attached and enabled on a GameObject.
  3. Confirm class name matches file name.
  4. Run and check Console filters for logs.
