Starter Code
using UnityEngine;

public class GreetingScript : MonoBehaviour
{
    public string greetingMessage = "Hello, Unity World!";
    public int luckyNumber = 7;

    void Awake()
    {
        Debug.Log("Awake() called: Script is loading.");
    }

    void Start()
    {
        Debug.Log("Start() called: " + greetingMessage + " Your lucky number is: " + luckyNumber);
    }
}
Lab Steps
  1. Create Cube in Hierarchy.
  2. Create GreetingScript and paste starter code.
  3. Attach script to Cube and press Play.
  4. Open Console to confirm Awake and Start messages.
Troubleshoot: If you see compile errors, open the Console and fix the first error; subsequent errors often cascade.
