Module 2 › Chapter 2.1 › Awake vs Start
Definition

Awake

Called when the script instance is loaded. Runs before Start on all objects and executes whether the component is enabled or not. Use for early initialization.

Example: cache internal references to components on the same GameObject so other scripts can rely on those references in Start.
Definition

Start

Called once before the first frame update, only if the component is enabled. Use Start for initialization that depends on other objects' Awake methods having completed.

Common mistake: placing dependency setup in Start when that dependency is initialized later. Prefer Awake for binding your own internal components.
Check Your Understanding
If two objects both use Awake and Start, Awake runs on all objects first, then Start runs on all enabled objects.
Analogy
Think of Awake as loading the actors and Start as telling them to begin the scene once everyone is on stage.
Key Takeaway
Choose Awake for guaranteed early setup; choose Start when initialization requires other objects to be ready.
