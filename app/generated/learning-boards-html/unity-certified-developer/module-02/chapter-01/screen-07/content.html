Concept

MonoBehaviour as a bridge

Inheriting from MonoBehaviour lets Unity treat the class as a component, enabling Inspector display and lifecycle callbacks.

Design tip: separate data classes from components. Use plain classes for pure data, MonoBehaviour for things that need engine callbacks.
