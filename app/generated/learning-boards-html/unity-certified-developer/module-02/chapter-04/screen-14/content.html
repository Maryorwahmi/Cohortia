Module 2 › Chapter 2.4 › Key Concepts
Method (Function)
A named block for a single, reusable behavior.
Parameters & Return
Parameters accept inputs; return types give back computed results to the caller.
Scope & Static
Fields persist across methods; locals are temporary. Static methods have no instance context.
Summary
Design methods for clear inputs, predictable outputs, and minimal side-effects. Favor small, testable methods to keep your Unity scripts maintainable.
