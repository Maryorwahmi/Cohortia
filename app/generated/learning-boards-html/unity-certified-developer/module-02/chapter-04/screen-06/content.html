Parameter mapping
A parameter declares a type and name. When you call the method, the argument’s value is assigned to that parameter for the duration of the call.
Example calls
TakeDamage(attackDamage);
TakeDamage(5.0f);
float crit = CalculateTotalDamage(attackDamage, 1.5f);
Misconception
Passing a variable name means the method receives its current value — not a magic link. Unless you use reference types intentionally, methods receive copies of the values for primitives.
Quick checklist
  • Match argument types to parameter types to avoid compiler errors.
  • Use literals for quick tests and variables for dynamic behavior.
  • Remember that return values must be stored if you need them later.
Key Takeaway

Arguments control runtime behavior; parameters define what a method accepts. Choose types and names that make intent clear.
