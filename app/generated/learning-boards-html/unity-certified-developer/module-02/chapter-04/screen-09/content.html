Module 2 › Chapter 2.4 › Static vs Instance
Static examples
float absoluteValue = Mathf.Abs(-10.5f);
float clampedValue = Mathf.Clamp(15f, 0f, 10f);

Mathf methods are static utilities. You don’t create a Mathf instance to use them.

When to use static
Use static for pure utilities that don’t need object state, like math helpers or conversion functions.
Instance examples
public void TakeDamage(float damage)
{
    playerHealth -= damage; // uses this instance's field
}

Instance methods can access fields and modify the specific component they belong to.

Mistake to avoid

Don’t call instance members from a static method. If you need instance state, make the method an instance method instead.
