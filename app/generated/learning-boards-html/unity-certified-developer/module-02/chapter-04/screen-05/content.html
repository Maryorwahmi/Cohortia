Module 2 › Chapter 2.4 › Anatomy of a Method
Parts explained
  • Return type: What type the method gives back, or void for none.
  • Name: The identifier others use to call the behavior.
  • Parameters: Typed names the method expects when called.
  • Body: The statements that perform the work.
Common misconception

You cannot overload methods by only changing the return type. The compiler needs different parameter lists to choose an overload.

Code walkthrough
public float CalculateTotalDamage(float baseDamage, float criticalMultiplier)
{
    float totalDamage = baseDamage * criticalMultiplier;
    return totalDamage;
}
This method returns a computed float. The caller stores that return value to use in further calculations or to pass to another method.
Example use
float criticalHit = CalculateTotalDamage(10f, 1.5f); Debug.Log("A critical hit would deal: " + criticalHit);
