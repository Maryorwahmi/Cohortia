Visual concept
Interactive 16:9 Masterclass
Method

A named block that performs a task and can be reused any time that task is needed.

Inputs via parameters. Optional output via return.
Parameters

Placeholders that receive data when a method is called. They make methods flexible.

Called with arguments.
Return

A method can send a result back using a return type. Use this when the caller needs a value.

Use return carefully to avoid side effects.
Scope

Where a variable can be accessed. Member fields are accessible to methods; local variables are not.

Avoid referencing out-of-scope variables.
