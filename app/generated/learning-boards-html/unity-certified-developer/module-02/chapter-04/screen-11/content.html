Example code snippet
// Method that returns a value
public float CalculateFinalDamage(float baseVal, float multiplier)
{
    float finalDamage = baseVal * multiplier;
    return finalDamage; // local variable returned
}
Notice how finalDamage exists only inside the method. The caller stores the return to use it later. This shows local scope and clear return semantics in practice.
