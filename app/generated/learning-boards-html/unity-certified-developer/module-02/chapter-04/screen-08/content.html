Scope explained

Fields declared at class level persist across method calls. Local variables are temporary and exist only during the method execution.

Example
public int classLevelVariable = 10;

void MyMethod1()
{
    int methodLevelVariable = 5;
    Debug.Log(classLevelVariable);
}

void MyMethod2()
{
    Debug.Log(classLevelVariable);
    // methodLevelVariable is not accessible here
}
Common error

Trying to use a method-local variable outside its method will fail at compile time. Move it to a field if multiple methods need it.

Design guidance
  • Use local variables for temporary calculations.
  • Use fields for state that must persist across calls or be visible in the Inspector.
  • Avoid name shadowing; it confuses both you and the compiler.
Check your understanding
If a value must be preserved between frames, where should it be declared? (Answer: as a field.)
