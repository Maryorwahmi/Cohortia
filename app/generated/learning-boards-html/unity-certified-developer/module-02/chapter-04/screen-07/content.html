Module 2 › Chapter 2.4 › Method Overloading
Why overload?

Overloading gives callers convenience while keeping the conceptual action name consistent. Each overload handles different input requirements.

Example overloads
public void SpawnItem(Vector3 position)
public void SpawnItem(GameObject itemPrefab, Vector3 position)
public void SpawnItem(GameObject itemPrefab, Vector3 position, Quaternion rotation)
Gotcha
You cannot create two methods that only differ by return type. The signatures must be different in parameters.
Call resolution

The compiler selects the overload that matches the types and number of arguments you pass. If multiple overloads could match, choose the most specific one to avoid ambiguity.

Key Takeaway

Use overloading to offer convenient, related ways to perform the same action without duplicating names or intent.
