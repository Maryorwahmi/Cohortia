Module 3 › Chapter 2.5 › Fields & Methods
Fields
Store the object's data: name, id, current health, stack size. Decide which fields are public or private.
Make read-only properties or public getters for values that others need to read but not change directly.
Methods
Encapsulate actions like TakeDamage, UseItem, Heal. Methods should enforce rules like clamping ranges or emitting events when thresholds are reached.
Example
TakeDamage reduces health and logs defeat when health drops to zero or below; Heal increases health up to a maximum set by the constructor.
