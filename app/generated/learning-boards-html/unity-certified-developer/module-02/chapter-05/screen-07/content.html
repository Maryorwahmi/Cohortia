Module 3 › Chapter 2.5 › Public vs Private
Side-by-side
Direct access (bad)
public int health; // anyone can change this and create inconsistent states
Encapsulated (good)
private int health; public void TakeDamage(int amount) { /* clamp and react */ }
Encapsulation lets you change the internals later without breaking other systems. It makes invariants explicit and simplifies debugging.
Concrete example
EnemyStats keeps _isBoss private and exposes IsBoss method. External code can learn about boss status without being able to toggle it arbitrarily.
