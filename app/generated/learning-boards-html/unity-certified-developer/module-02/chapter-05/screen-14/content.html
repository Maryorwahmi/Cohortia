Module 3 › Chapter 2.5 › Key Concepts
Class = Blueprint
Defines fields and methods reused across objects.
Object = Instance
Created with new and contains its own state.
Encapsulation
Use private fields and public methods to protect object integrity.
Takeaway: Keep data models engine-agnostic and use MonoBehaviour as the bridge to scene behavior. This separation improves reuse, testing, and maintainability.
