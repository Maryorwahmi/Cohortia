InventoryManager example
Use List InventoryItem to hold items. Add items after creating them and iterate to show their names and counts in the console or UI.
// conceptual loop
foreach (InventoryItem item in playerInventory) {
    Debug.Log(item.itemName + " (" + item.stackSize + ")");
}
Practical tips
  • Remove items carefully during iteration; use a separate list of items to remove or iterate by index backward.
  • Keep UI updates efficient by batching updates after collection changes.
  • For large numbers of objects, consider pooling or more efficient data structures.
