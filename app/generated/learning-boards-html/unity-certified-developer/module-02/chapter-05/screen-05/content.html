Constructor pattern
A constructor gives each object a valid initial state and documents required data.
// EnemyStats constructor (visual example)
public EnemyStats(string name, int initialHealth, float power, bool isBossEnemy) {
    enemyName = name;
    health = initialHealth;
    attackPower = power;
    _isBoss = isBossEnemy;
    Debug.Log("New enemy created: " + enemyName);
}
Key Takeaway

Constructors simplify creating valid objects and reduce runtime errors from missing initialization.

Practical notes
  • Prefer constructors for non-MonoBehaviour classes that need immediate, consistent state.
  • For MonoBehaviour, Unity calls Awake and Start; avoid using new to create MonoBehaviours.
  • Changing constructor parameters may require updating all instantiation sites—use defaults when appropriate.
Common mistake
Relying on default field values that leave an object in an invalid state when used before initialization.
