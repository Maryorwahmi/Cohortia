Module 3 › Chapter 2.5 › What is a Class?
Class structure
Fields hold data. Methods hold behavior. Constructors initialize an instance's starting state.
Example: InventoryItem
public class InventoryItem { public string itemName; public int stackSize; private bool isConsumable; public InventoryItem(string name, int stack, bool consumable) { /*...*/ } public void UseItem() { /*...*/ } }
Concrete exercise
Write a class for a quest or item. Make fields public for read access, and keep internal counters private.
Key Takeaway

Design classes for one responsibility: data models should not manage scene lifecycle.

Common misconception
Students sometimes attach all data to MonoBehaviour hoping Unity will serialize it. Use plain C# classes when you need lightweight models and control over construction.
Annotated example
EnemyStats defines state and behavior but has no Awake or Update. It logs creation through Unity's debug when convenient, but remains a plain data object.
