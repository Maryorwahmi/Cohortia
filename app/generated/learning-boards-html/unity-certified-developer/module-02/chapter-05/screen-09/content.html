PlayerStats (non-MonoBehaviour)
// conceptual snippet
public class PlayerStats {
    public string playerName;
    private int health;
    public PlayerStats(string name, int hp) { /* set fields */ }
    public void TakeDamage(int amount) { /* reduce health safely */ }
}
PlayerController (MonoBehaviour)
Awake creates PlayerStats instances and Update triggers behavior. Controller bridges scene events to model updates and UI.
Pro tip
Keep input and presentation in the controller; put business rules like damage calculation in the model class for easier testing.
