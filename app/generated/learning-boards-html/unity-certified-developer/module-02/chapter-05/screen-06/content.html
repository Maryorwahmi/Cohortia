Module 3 › Chapter 2.5 › Creating Objects
Step-by-step
  1. Define the class with fields, constructor, methods.
  2. Instantiate with new and pass constructor arguments.
  3. Store references in variables or collections like List.
  4. Invoke methods to change the instance's state safely.
// InventoryManager.Start example (conceptual)
InventoryItem potion = new InventoryItem("Health Potion", "Restores health", 101, 3, true);
playerInventory.Add(potion);
potion.UseItem();
Example card
Create goblin and ogre as EnemyStats instances. Call TakeDamage on goblin. Observe goblin health change but ogre remains unchanged.
Common pitfall
Passing object references around without understanding that they point to the same instance can cause unexpected shared state changes.
