Module 3 › Chapter 2.5 › Common Mistakes
Compile-time errors
Private member access error: make a public getter or method instead of exposing the field directly.
Engine-specific mistake
Do not use new to create MonoBehaviours. Use AddComponent on a GameObject or attach in the editor.
Runtime debugging
Log constructor calls and key method invocations. Track ownership of object references to avoid unintended shared mutation.
Quick fix checklist
1. Does this class need Unity calls? 2. Are fields initialized? 3. Are private fields mutated externally?
