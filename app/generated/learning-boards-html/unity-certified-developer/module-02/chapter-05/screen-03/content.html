Module 3 › Chapter 2.5 › Learning Objectives
Hands-on activity
Create InventoryItem as a non-MonoBehaviour C# class. Instantiate several items in InventoryManager. Use List to store them and call methods to use consumables.
What you will see
  • Console logs showing item creation and use.
  • Items in the list with different stack sizes.
  • Attempted direct access to a private field causes a compile error—then fix by using a public method.
Why this activity
It teaches safe state management, constructors, and how MonoBehaviour acts as the bridge to the Unity runtime.
Mini mnemonic
Think: Class = recipe, Object = baked item. The recipe belongs in code; the baked item exists at runtime.
