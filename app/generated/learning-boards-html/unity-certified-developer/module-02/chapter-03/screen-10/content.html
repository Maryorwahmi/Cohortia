Starter script (excerpt)
public int playerCurrentHealth = 70;
public enum Difficulty { Easy, Medium, Hard, Extreme }
public Difficulty gameDifficulty = Difficulty.Medium;
public GameObject coinPrefab;
public Transform spawnOrigin;

void Start() {
  Debug.Log("--- Game Logic Checks ---");
  CheckPlayerHealthStatus();
  ApplyDifficultySettings();
  if (coinPrefab != null && spawnOrigin != null) { SpawnCoinsBasedOnDifficulty(); }
  else { Debug.LogError("Assign Coin Prefab and Spawn Origin in the Inspector!"); }
}
What to test
  • Change playerCurrentHealth to verify each health message.
  • Swap gameDifficulty to see different spawn counts.
  • Remove the prefab to trigger the inspector error message and practice debugging.
Key Takeaway

Integrate checks and loops in a manager script. Test interactions via the Inspector and Console to confirm expected runtime behavior.
