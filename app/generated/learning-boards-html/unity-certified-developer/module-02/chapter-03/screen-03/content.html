How you'll apply these skills
Small, testable tasks you can run in a scene.
Health status check
Use if chains to map health ranges to messages or events. Try toggling the value in the Inspector.
Difficulty switch
Create an enum, switch over it, and change spawn counts or enemy behavior per case.
Spawn loop
Use a for loop to instantiate prefabs. Watch for off-by-one mistakes when indexing.
