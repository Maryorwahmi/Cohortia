Learning Objectives
From concept to application: decide, select, repeat, and control.
Bloom: Learn → Understand → Apply → Master

Use if / else if / else
Write ordered conditional chains to classify states like health ranges and trigger appropriate responses.
Mnemonic: tiered checkpoints (Venn-like thresholds)

Construct loops
