Code walkthrough
void SpawnEnemies(int count) {
  for (int i = 0; i < count; i++) {
    Instantiate(enemyPrefab, spawnPoint.position + new Vector3(i * 2, 0, 0), Quaternion.identity);
    Debug.Log("Spawned enemy #" + (i + 1));
  }
}
Confirm that if count is 5, loop runs five times. Change < to <= to observe the off-by-one error.
Safety checklist
  • Start counters at zero when indexing arrays from zero.
  • Use < length to avoid index out of range errors.
  • Log iteration counts during testing to confirm behavior.
  • Consider pooling for many instantiations to avoid spikes.
Common mistake

Using i <= count when starting at zero will run one extra iteration. Check boundaries carefully.
