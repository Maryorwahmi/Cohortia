Module 2 › Chapter 2.3 › Key Concepts
Control Flow
The order in which statements execute. Branch and repeat to build interactivity.
Conditionals
if, else if, else and switch. Decide which code path runs based on values or conditions.
Loops
for, while, do-while, foreach. Repeat actions; choose the form that matches your needs.
Summary
Use clear ordering, prefer modular methods, test with inspector values, and guard loops to prevent freezes.
