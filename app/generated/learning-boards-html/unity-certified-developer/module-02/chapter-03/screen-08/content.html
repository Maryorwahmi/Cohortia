Example: greet players
public string[] playerNames = { "Alice", "Bob", "Charlie" };
void GreetPlayers() {
  foreach (string name in playerNames) {
    Debug.Log("Hello, " + name + "!");
  }
}
Foreach visits each element. If you need to remove items during iteration, collect them and remove after the loop to avoid errors.
When to use

Reading or applying a function to each element where indices are not required.

When to avoid

Modifying the collection structure while iterating. Use a for loop instead for safe removals.
