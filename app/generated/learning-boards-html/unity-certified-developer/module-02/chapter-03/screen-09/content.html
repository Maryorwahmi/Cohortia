Module 2 › Chapter 2.3 › break & continue
Example: skipping and exiting
for (int i = 0; i < 10; i++) {
  if (i == 3) { continue; }
  if (i == 7) { break; }
  Debug.Log("Loop iteration: " + i);
}
// Output: 0,1,2,4,5,6
Continue skipped printing at index three. Break stopped the loop when index seven was reached.
When to break
Stop searching once a target is found to save work.
When to continue
Skip invalid or irrelevant items but keep scanning the rest.
