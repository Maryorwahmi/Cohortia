while loop example
while (timer > 0) {
  Debug.Log("Time remaining: " + timer);
  timer -= Time.deltaTime;
  if (timer <= 0) { Debug.Log("Time's up!"); }
}
If timer is never reduced, the loop will never end. In Unity, avoid blocking the main thread with long while loops.
Do-while and safety checks
Do-while runs at least once. Use it when the loop body must execute before the condition is checked, but still include limits and guard conditions to prevent runaway execution.
