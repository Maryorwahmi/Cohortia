Switch example (enum)
public enum Difficulty { Easy, Medium, Hard, Extreme } switch (gameDifficulty) { case Difficulty.Easy: coinsToSpawn = 5; break; case Difficulty.Medium: coinsToSpawn = 10; break; case Difficulty.Hard: coinsToSpawn = 15; break; case Difficulty.Extreme: coinsToSpawn = 20; break; default: coinsToSpawn = 10; break; }
Each case maps a constant value to a behavior. Use default to handle unexpected values.
Comparison: when to choose
  • Switch: many fixed values, clearer case labels, easier to read and maintain.
  • If-Else: ranges, compound boolean logic, or checks involving comparisons.
  • Performance: readability is primary; compiler optimizations vary by language.
Pro Tip

Prefer switch for enums and discrete types. Reserve if-else for ranges and complex predicates.
