Module 2 › Chapter 2.3 › If Chains
Definition
If / Else If / Else
Execute one branch based on the first true condition. Order affects which branch runs.
// Health status example if (playerCurrentHealth <= 0) { Debug.Log("Player is defeated! Game Over."); } else if (playerCurrentHealth <= 25) { Debug.Log("Player health is critical! Seek cover!"); } else if (playerCurrentHealth <= 75) { Debug.Log("Player health is stable. Keep fighting!"); } else { Debug.Log("Player is at full health. Ready for action!"); }
Key points
  • Chains run in order; the first true condition stops the chain.
  • Place narrow, high-priority checks before broader ranges.
  • Avoid overlapping ranges that make branches unreachable.
  • Keep heavy calculations out of condition checks for clarity and performance.
Key Takeaway

Order your conditions from most specific to most general. Test thresholds with example values to confirm behavior.
