Create Scenes and Import a Model

Follow these guided steps to practice the workflow end to end.

Scene steps
  1. Create _Scenes folder in Project window.
  2. Save current scene as MainMenu into _Scenes.
  3. Create new scene and save as Level01 into _Scenes.
  4. Open both to confirm they load.
Import steps
  1. Create _Models and _Textures folders.
  2. Drag model into _Models and texture into _Textures.
  3. Inspect model Scale Factor and texture Compression in Inspector.
  4. Drag model into Level01 to validate appearance and scale.
Checkpoint

If your imported model looks wrong, adjust scale and material links in the Inspector and test again. Save a prefab for reuse.
