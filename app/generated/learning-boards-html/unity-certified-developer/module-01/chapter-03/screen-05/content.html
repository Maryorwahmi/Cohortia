Process Flow

Create, save, and open scenes

  1. Create folder: right-click Assets → Create → Folder, name it _Scenes.
  2. New scene: File → New Scene. Unity may prompt to save current changes — save them.
  3. Save: File → Save Scene or Ctrl+S. Name scene MainMenu and place it in _Scenes.
  4. Create another: File → New Scene, Save as Level01 into _Scenes.
  5. Open scene: double-click scene asset or drag into Hierarchy to load.
Common mistake
Not saving before creating a new scene leads to lost changes.
Example workflow
Create _Scenes, save MainMenu, open MainMenu, add UI, save. Create Level01, save, add test cube, open Level01 to verify.
Key Takeaway

A consistent save and naming process prevents lost work and makes scenes easy to find.
