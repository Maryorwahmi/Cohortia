Practical milestones

Complete each small task to prove competency and avoid later rework.

Save Scenes
  • Create _Scenes folder and save MainMenu and Level01.
  • Reopen both scenes to confirm they load without errors.
Organize Folders
  • Create _Models, _Textures, _Audio, _Materials, _Scripts.
  • Move a sample file to its matching folder.
Import Files
  • Drag a model and a texture into the Project window and confirm they appear.
  • Open the Inspector to check default import values.
Adjust Settings
  • Change a model's scale factor and a texture's compression setting and observe the effects.
  • Record the before-and-after build size to see impact.
