Module 1 › Chapter 1.3 › Audio Import
Definition

Audio Import Settings

  • Load Type: Decompress On Load, Compressed In Memory, Streaming.
  • Compression Format & Quality: adjust to balance clarity and size.
  • Sample Rate: reduce for savings when high fidelity is unnecessary.
Concrete example
Use Streaming for a 90-second background track to avoid loading it fully into memory. Use Compressed In Memory for short UI clicks to reduce size while keeping latency low.
Common mistake

Importing long music as Decompress On Load greatly increases memory and can harm performance.
