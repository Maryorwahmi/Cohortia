Module 1 › Chapter 1.3 › What is a Scene?
Definition

Scene

A container for GameObjects, lighting, cameras, and environment settings representing a specific part of your game.

Metaphor: Stage
Actors, props, and lighting on a stage correspond to GameObjects, assets, and scene settings.
Common mistake
Keeping everything in one large scene causes slow saves, large memory use, and team conflicts.
Key Takeaway

Use separate scenes for distinct gameplay sections and save them in a dedicated _Scenes folder.

Concrete example
Example: MainMenu and Level01
Save MainMenu.scene hosting UI elements and Level01.scene hosting gameplay objects. Load only the scene you need to reduce memory usage.

  • When might multi-scene editing be useful?
Misconception: splitting scenes harms performance — in fact it lets you control what loads and therefore helps performance.
