Two Quick Questions

Question 1
How would you organize a main menu, three levels, and a cinematic for efficient loading and team work?
Correct: separate scenes for each section; this modularity improves loading and collaboration.
Question 2
A high-resolution PNG used as a small UI icon bloats your build. Which import setting will you adjust first to reduce size?
Correct: texture compression. Scale and type do not directly reduce file size as effectively.
Use these checks after practice to confirm you understand both the architecture and the performance trade-offs.
