Manage scenes. Import assets. Ship efficiently.

This module teaches the practical steps to create and save multiple scenes, build a tidy folder structure in the Project window, import models, textures, and audio, and tune the import settings that affect memory and build size.

In this lesson
Create MainMenu and Level01 scenes, import a model and texture, and inspect settings.
Why it matters
Organized assets and proper import settings save time and prevent performance regressions.
Visual Concept
Scenes are containers for GameObjects and settings.
_Scenes
Save each screen or level as its own scene file to load only what's needed.
_Models
Store imported 3D files like .fbx and .obj here.
Import Settings
Adjust scale, compression, and load type to optimize performance.
Quick Guide
  1. Create a dedicated _Scenes folder and save scenes there.
  2. Create top-level folders for models, textures, audio, scripts, and prefabs.
  3. Drag-and-drop assets into the Project window, then inspect import settings.
