Comparison

Quality vs Size

UI Icons
Use higher compression and smaller resolutions; artifacts are less noticeable at small sizes.
Character Textures
Prefer lower compression and keep higher resolution for faces and key details.
Environment Textures
Use mipmaps and medium compression to maintain quality across distances.
Concrete example
A high-resolution terrain albedo should have mipmaps enabled and medium compression; a small UI icon can use aggressive compression to save size without visible loss.
Key Takeaway

Choose texture type and compression based on intended on-screen size and importance to visual fidelity.
