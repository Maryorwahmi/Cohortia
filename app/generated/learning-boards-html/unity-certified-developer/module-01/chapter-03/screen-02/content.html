Learning Objectives

Learn, Understand, Apply, Master

Bloom: Learn → Understand → Apply → Master
01
Create, save, and load scenes
Practice saving scenes into a _Scenes folder and opening them reliably to avoid data loss.
VERIFIED COMPETENCY MILESTONE
02
Organize assets in the Project window
Build a folder hierarchy such as _Models, _Textures, _Audio so team members can find files quickly.
VERIFIED COMPETENCY MILESTONE
03
Import 3D models, textures, and audio
Drag and drop files into the Project window and confirm Unity recognizes their formats.
VERIFIED COMPETENCY MILESTONE
04
Adjust basic import settings
Change model scale, texture type/compression, and audio load type to balance quality and build size.
VERIFIED COMPETENCY MILESTONE
