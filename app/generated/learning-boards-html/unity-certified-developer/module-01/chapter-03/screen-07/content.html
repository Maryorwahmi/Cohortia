Module 1 › Chapter 1.3 › Import: Drag & Drop
Process

Drag, inspect, and test

  1. Create or select the target folder, e.g., _Models.
  2. Drag the model or texture file from the OS into the Project window.
  3. Select the imported asset and open the Inspector to review import settings.
  4. Drag the asset into a test scene to verify scale, material links, and appearance.
Quick tip
Move new imports into the correct folder immediately to keep the Project window tidy.
Example
Drag hero.fbx into _Models, hero_diffuse.png into _Textures, then select hero.fbx and check its Scale Factor in the Inspector. If it appears too large or small in the test scene, adjust scale and reapply.
Key Takeaway

Importing is fast, but inspecting settings and testing the asset prevents later surprises.
