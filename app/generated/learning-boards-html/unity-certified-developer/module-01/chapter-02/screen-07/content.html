Collider types
Box Collider
A rectangular prism. Fast and good for crates, platforms.
Sphere Collider
A perfect sphere. Useful for balls and simple round objects.
Capsule Collider
Cylinder with rounded ends. Common for characters.
Mesh Collider
Matches mesh shape. Use for static environment geometry only when needed.
Examples & Tips
Performance tip
Prefer primitive colliders. Combine multiple simple colliders to approximate a complex shape.
Trigger vs Collision
Set a collider as a trigger when you only need overlap events without physical response.
Common mistake
Relying on Mesh Collider for dynamic moving objects; this can be expensive and unstable.
Key takeaway
Choose collider shapes deliberately to balance accuracy and performance.
