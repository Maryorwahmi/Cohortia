Module 1 › Chapter 1.2 › Key Concepts
GameObject
An empty container that holds Components to add capabilities.
Transform
Defines position, rotation, and scale and is required on every GameObject.
Mesh & Renderer
Mesh Filter stores geometry; Mesh Renderer applies materials so the object is visible.
Summary takeaway

Start troubleshooting by checking Transform, required visual components, and colliders. Components are your first stop when adjusting behavior.
