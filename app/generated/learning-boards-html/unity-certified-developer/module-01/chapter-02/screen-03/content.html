Practical outcomes

Hands-on tasks and debugging checks

Hands-on activity
  1. Create a Plane and set Transform to (0,0,0) and Scale to (5,1,5).
  2. Create a Cube, set its position to (0,5,0), add a Rigidbody, and ensure both objects have Colliders.
  3. Enter Play mode and observe the Cube falling onto the Plane. Tune mass or collider size and retry.
Debug checklist
  • Does the falling object have a Rigidbody?
  • Do both objects have colliders?
  • Is the collider shape appropriate for performance?
Tip

Prefer simple colliders for physics; use mesh colliders sparingly and only when necessary for accurate collisions.
