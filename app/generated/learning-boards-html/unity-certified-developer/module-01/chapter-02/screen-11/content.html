Module 1 › Chapter 1.2 › Component Composition
Design pattern
Visual
Mesh Filter + Mesh Renderer hold geometry and materials.
Physics
Collider defines shape; Rigidbody enables simulation.
Scripts
Custom behavior. Keep them focused and access Transform or Rigidbody as needed.
Practical layout
Use child GameObjects to separate concerns, such as placing colliders on children to adjust offsets independently from the visual mesh.
Common mistake
Tight coupling between components without clear dependency management. Test component swaps and removals to avoid hidden breaks.
