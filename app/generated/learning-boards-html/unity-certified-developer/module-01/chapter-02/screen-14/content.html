Quick checklist
Collision failures
  • Both objects must have Colliders.
  • Moving object should usually have a Rigidbody.
  • Avoid moving dynamic Rigidbodies by Transform each frame.
Performance pitfalls
  • Avoid Mesh Colliders on dynamic objects.
  • Prefer primitives and combine them for complex shapes.
Visibility checks
Confirm Mesh Renderer is enabled and materials are assigned. Check layers and camera culling masks if invisible.
Coding safety
Add null checks when accessing components so missing components produce clear messages rather than silent failures.
