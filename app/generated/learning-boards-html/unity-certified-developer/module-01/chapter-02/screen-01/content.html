GameObject + Components

Assemble small components to create objects that render, collide, and behave in predictable ways.

GameObject

A lightweight container. Holds Components that supply data and behavior.

Components

Attach modular pieces like Transform, Mesh Renderer, Collider, or Rigidbody to define the object.

Why it matters

Modularity encourages reuse and makes it easy to combine visual, physical, and scripted behaviors without monolithic objects.

Common mistake

Expecting a GameObject to act by itself. It needs components to do anything visible or interactive.

Explore Key Topics
Transform

Position, rotation, and scale: always present and essential for other components.

Visual Components

Mesh Filter provides geometry; Mesh Renderer displays it with materials.

Physics

Colliders define boundaries and Rigidbody makes objects respond to forces.
