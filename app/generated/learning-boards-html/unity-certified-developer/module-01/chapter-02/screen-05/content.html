Core Component

Transform

Stores position, rotation, and scale. Always present on every GameObject and used by renderers, physics, and scripts.

Position
Coordinates in world or parent space.
Rotation
Orientation on X, Y, Z axes.
Scale
Size multiplier per axis.
Practical note
Manipulate static placement with Transform. For physics-driven motion, prefer Rigidbody methods to avoid conflicts.
Try this
Example
Set a cube's transform to position (0,5,0). Add a child object and move the parent. Children follow local Transform changes, demonstrating hierarchy behavior.
Misconception
Directly setting Transform while a Rigidbody is active can bypass physics and create unrealistic results. Use physics methods for dynamic motion.
Key takeaway
Transform is the foundational reference for all component behavior; respect parent-child relationships and choose the correct method for motion.
