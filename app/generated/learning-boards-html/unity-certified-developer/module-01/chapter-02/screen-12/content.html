Module 1 › Chapter 1.2 › Transform vs Rigidbody
Transform movement
Directly change position or rotation. Best for editor placement or parent-driven motion outside physics simulation.
When not to use
Avoid for dynamic objects controlled by physics; it can cause tunneling and missed collisions.
Rigidbody movement
Apply forces, set velocity, or call MovePosition/MoveRotation for predictable physics-driven motion.
Example
Use AddForce to simulate pushing an object, and use MovePosition for smooth kinematic translations that still generate collisions with dynamic objects.
