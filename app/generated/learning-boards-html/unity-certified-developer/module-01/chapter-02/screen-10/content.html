Module 1 › Chapter 1.2 › Mesh vs Collider
Visual Mesh (Mesh Filter + Renderer)

High detail geometry and materials. Controls visual fidelity but does not define physical interaction by itself.

Use case
Detailed models for render quality like props and characters.
Collider

Defines physical boundary for collisions. Can be primitive shapes for performance or mesh colliders for exactness.

Use case
Simplified collision for gameplay and performance, like a capsule for characters.
Key takeaway
Separate visual fidelity from collision complexity to balance performance and gameplay accuracy.
