Definition

GameObject

A minimal scene entity that serves as a container for components and a node in the Hierarchy.

Always present: Transform
Stores position, rotation, and scale. Everything else references it for placement and orientation.
Parenting and hierarchy
A GameObject can be a parent to others. Use empty GameObjects to group and move sets of child objects together.
Key takeaway
GameObjects are labels and holders; components give them capabilities.
Analogy & Example
Analogy
Treat a GameObject like an empty box that you label and then put tools into.
Concrete Example
An empty GameObject used as a parent for a vehicle groups wheels and body so you can move the whole vehicle by changing one Transform.
Common mistake
Adding heavy components to every GameObject. Only attach what the object actually needs.
