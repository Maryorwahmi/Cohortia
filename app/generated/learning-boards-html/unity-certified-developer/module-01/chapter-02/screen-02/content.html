Learning Objectives

Learn, Understand, Apply, Master

Bloom: Learn → Understand → Apply → Master
01
Explain GameObject-Component model

Describe how GameObjects act as containers and how Components provide functionality. This matters because it shapes how you design game entities.

VERIFIED COMPETENCY MILESTONE
02
Identify essential components

Recognize Transform, Mesh Filter, Mesh Renderer, Colliders, and Rigidbody and explain their roles in the scene.

VERIFIED COMPETENCY MILESTONE
03
Add and remove Components

Use the Inspector to attach or remove components cleanly and understand search and gear options for configuration.

VERIFIED COMPETENCY MILESTONE
04
Modify component properties

Change values like position, mass, or collider size to affect appearance and physics. Understand consequences of each change.

VERIFIED COMPETENCY MILESTONE
