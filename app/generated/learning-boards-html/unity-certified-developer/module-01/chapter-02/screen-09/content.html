Module 1 › Chapter 1.2 › Add & Remove Components
Step-by-step
1. Select GameObject
Click the object in the Hierarchy to show it in the Inspector where components are listed.
2. Add Component
Use the Add Component button, search for the component name, and attach it.
3. Remove Component
Use the gear icon and select Remove Component to detach functionality you no longer need.
Example workflow
Create a cube, add Box Collider, add Rigidbody, press Play to confirm falling behavior, then tune mass and collider size if needed.
Pitfall
Removing a component used by a script can break behavior. Check script dependencies before removal.
Key takeaway
Use the Inspector for incremental composition and frequent testing to isolate issues quickly.
