Visual Components

Mesh Filter

Holds geometry data such as vertices and triangles. It is the raw shape asset referenced by the GameObject.

Mesh Renderer
Applies materials and shaders to the mesh so it appears in the scene. Controls casting and receiving shadows and material lists.
Practical tip
Share mesh assets across GameObjects and reuse materials when identical surfaces appear to reduce memory and draw calls.
Concrete example
Example
A rock model: Mesh Filter holds the geometry, Mesh Renderer assigns a stone material. To make the rock invisible but still collide, remove or disable the Mesh Renderer while keeping the Collider and Mesh Filter if needed for reference.
Common mistake
Expecting different materials to automatically change the mesh geometry. Materials only change appearance, not the shape stored in the Mesh Filter.
Key takeaway
Separate geometry from appearance: Mesh Filter for shape, Mesh Renderer for visuals.
