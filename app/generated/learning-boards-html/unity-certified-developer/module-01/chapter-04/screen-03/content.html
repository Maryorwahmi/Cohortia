Module 2 › Chapter 1.4 › Learning Objectives
Practical Checks
Create & Name
Name your file to match the public class; mismatches cause compilation or attachment issues.
Attach & Inspect
Drag the script onto a GameObject and confirm it appears as a Component in the Inspector.
Console Output
Place a log in Start and verify the message appears once when Play begins.
Frame Independence
Multiply movement by the frame time to prevent speed from varying across machines.
Follow this short checklist as you code: save, return to Unity, check the Console for compile errors, attach the script, press Play, and observe behavior. This loop is faster than guessing why something failed.
Quick Mnemonic
Save → Attach → Play → Inspect Console. Repeat until behavior matches expectation.
