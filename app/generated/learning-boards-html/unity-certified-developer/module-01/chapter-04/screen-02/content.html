Role of C# Scripts
Explain scripts as Components and why MonoBehaviour inheritance is required to attach logic to GameObjects. This allows access to engine callbacks and the transform shortcut.

02
Create & Attach Scripts
Create a C# file in _Scripts, name class to match file, open the template in your editor, then attach the script to a Cube to run behavior.
VERIFIED COMPETENCY MILESTONE
03
Lifecycle Methods
Use Start for one-time initialization and Update for per-frame work like movement or input checks. Learn when to pick each method.
VERIFIED COMPETENCY MILESTONE
04
Debugging & Frame Time
Use Debug.Log to verify flow and multiply motion by the frame time value to keep movement consistent across different frame rates.
VERIFIED COMPETENCY MILESTONE
