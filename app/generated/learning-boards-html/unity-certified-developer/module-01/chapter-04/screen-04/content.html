Module 2 › Chapter 1.4 › What a C# script is
Definition

Script as a Component

A C# file with a public class that inherits from the engine base becomes a Component that can be attached to GameObjects to add logic and state.

  • Gains lifecycle callbacks like Start and Update.
  • Has automatic access to the GameObject's Transform via a transform shortcut.
  • Exposes public fields to the Inspector for quick tuning.
Analogy
Think of a script like a behavior module you plug into a toy: the module defines what the toy can do, and you can swap modules to change behavior while keeping the same body.
Example
Rotator.cs with a public speed value rotates a cube when attached and run in Play mode. Adjusting speed in the Inspector changes rotation immediately.
Common Mistake
Renaming the file without renaming the public class breaks Unity's expectation and can prevent the script from compiling or attaching properly. Always keep file and class names matched.
Pro Tip
Use meaningful names like PlayerMovement or CubeRotator so the purpose is clear when you attach the component.
Key Takeaway

Scripts are attachable components; inheritance grants access to engine hooks and shorthand properties like transform.
