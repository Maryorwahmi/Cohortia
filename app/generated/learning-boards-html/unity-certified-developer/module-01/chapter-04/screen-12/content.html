Module 2 › Chapter 1.4 › Common Mistakes
Mistake vs Fix
Mismatched File/Class
Rename the public class to match the file or rename the file to match the class.
Unsaved Changes
Save the script before switching to the Editor; unsaved edits are not compiled.
No Attachment
Drag the script onto the GameObject and confirm it appears in the Inspector.
Missing frame-time
Multiply movement or rotation by the frame-time value for consistent speed across devices.
Pre-Play Checklist
  1. Save your script in the editor.
  2. Check the Console for compile errors and address them.
  3. Confirm the script appears in the GameObject's Inspector.
  4. Press Play and confirm expected Console messages and movement behavior.
Pro Tip
Use descriptive log messages and reduce logging frequency during performance tests to keep the Console useful.
