Module 2 › Chapter 1.4 › Start Method
When to use Start
One-time initialization tasks that should run when the component first becomes enabled.
  • Cache references like GetComponent calls.
  • Initialize default values and public fields if needed.
  • Log a startup message to verify the component enabled.
Example
Debug.Log("Rotator started on: " + gameObject.name) will print one line per active Rotator when Play begins, confirming correct attachment.
Misconception
Start is not a constructor. Avoid heavy synchronous work here that could stall loading; prefer short initializations or deferred loading strategies.
If you need physics setup that depends on the physics engine's fixed update timing, consider a fixed-timestep callback instead of Start.
Key Takeaway
Keep Start concise: set up references, default values, and a single log for verification.
