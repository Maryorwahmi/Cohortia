Module 2 › Chapter 1.4 › Hands-on Activity
Activity Steps
  1. Create and save a new Scene named ScriptingScene.
  2. Create a Cube in the Hierarchy.
  3. Create a _Scripts folder and add Rotator.cs.
  4. Edit Rotator: add public float rotationSpeed, Debug.Log in Start, and rotate using rotationSpeed * Time.deltaTime in Update.
  5. Save, attach Rotator to the Cube, set rotationSpeed, press Play, and check the Console for the startup log.
Expected Result
The cube rotates continuously and the Console shows one startup message naming the Cube. Tweak rotationSpeed in the Inspector during Play to see immediate effect.
Common Mistakes
  • Forgetting to save the script before returning to the Editor.
  • Renaming file without renaming the class.
  • Not attaching the script to the Cube in the Hierarchy.
Pro Tip
Use Console filters and pausing to capture and inspect startup logs if too many messages appear during tests.
