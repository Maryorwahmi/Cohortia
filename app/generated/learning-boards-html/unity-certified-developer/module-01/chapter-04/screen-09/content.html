Module 2 › Chapter 1.4 › Debug.Log & Console
Why Log
Quickly verify that a script ran and inspect runtime values without attaching a debugger.
// Example message in Start
Debug.Log("Rotator started on: " + gameObject.name);
Include the component name and a short label so messages are useful when multiple objects log similar lines.
Console Tips
  • Check Console filters if you don’t see messages.
  • Avoid logging every frame during profiling; it can affect performance.
  • Use logs for quick checks and a debugger for complex state introspection.
Key Takeaway

Use informative Console messages for startup verification, then remove or reduce frequency before performance tests.
