Module 2 › Chapter 1.4 › transform & Time.deltaTime
Concept
transform provides direct control over an object’s position and rotation. Time.deltaTime represents the seconds since the last frame.
// Rotate Y-axis at 'speed' degrees per second
transform.Rotate(0, speed * Time.deltaTime, 0);
Example
Set public float speed to 50. In Play mode the cube should rotate smoothly at 50 degrees per second, even if fps changes.
Misconception
Applying motion without the frame-time value causes speed to scale with frame rate. Test under different frame rates to confirm stability.
Pro tip: expose speed as a public field so you can tune it in the Inspector at runtime for quick iteration.
Key Takeaway
Always scale per-frame motion by the frame-time value to ensure consistent behavior across devices.
