Module 2 › Chapter 1.4 › Update Method
What Update does
Update executes once per frame and is suited for continuous behaviors like input checks and transform changes.
  • Handle input polling and timers.
  • Apply object motion and rotations.
  • Avoid allocations and repeated lookups inside Update for performance.
Example
Applying rotation each frame with a speed multiplied by the frame-time value produces frame-rate independent motion and smooth animation.
Misconception
Update is not fixed-rate. Using it for physics that require a fixed timestep can cause jitter. Use the engine's fixed-timestep callback for physics operations.
To improve performance, cache references in Start and avoid allocating memory inside Update, such as string concatenations or new object creation on every frame.
Key Takeaway
Keep Update lean, scale by frame time, and reserve heavy work for less frequent callbacks.
