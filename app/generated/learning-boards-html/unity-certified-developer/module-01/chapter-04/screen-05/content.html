Module 2 › Chapter 1.4 › Create & Open Script
Steps
  1. Create a _Scripts folder in the Project window to stay organized.
  2. Right-click > Create > C# Script and name it descriptively (e.g., Rotator).
  3. Double-click the asset to open it in your code editor and inspect the MonoBehaviour template.
  4. Make sure the public class name matches the file name and save changes before returning to Unity.
This process ensures your asset compiles and appears as a Component you can attach immediately. If the Console shows compile errors, it typically points to a naming or syntax issue that needs fixing in the editor.
Code Template (visual)
using UnityEngine;

public class Rotator : MonoBehaviour
{
    void Start()
    {
        Debug.Log("Rotator started on: " + gameObject.name);
    }

    void Update()
    {
        // per-frame logic goes here
    }
}
Save after editing so Unity compiles the latest version.
Common Pitfall
Renaming the file without renaming the public class causes compile errors and prevents attachment.
