Create behaviors with C# scripts

You will create a script asset, attach it as a Component, and use lifecycle methods to control initialization and continuous behavior. Practicing this will let you prototype movement, logging, and simple game mechanics.

Orientation

Start by creating a C# script in your _Scripts folder, open it, and observe the MonoBehaviour template. Then attach it to a Cube to see behavior in Play mode.

In this lesson
Create scripts, use Start and Update, and rotate an object reliably.
Why it matters
Scripting unlocks behaviors and lets you prototype mechanics quickly.
Coming up
Debugging tips, frame-rate independent motion, and Inspector tuning.
Visual Concept
Script Asset
A C# file saved in the Project acts as a Component when attached to a GameObject.
MonoBehaviour
Inherit from this base class to access lifecycle callbacks and the transform shortcut.
Explore Key Topics
Lifecycle Methods
Start for init, Update for per-frame logic.
Debugging
Use Debug.Log and the Console to verify behavior.
Frame Independence
Multiply by the frame time so movement is steady across devices.
