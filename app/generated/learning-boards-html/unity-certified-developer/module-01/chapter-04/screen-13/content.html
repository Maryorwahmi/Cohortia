Module 2 › Chapter 1.4 › Inspector Tuning
Pattern
Declare public fields for tunable parameters like rotationSpeed. Use private fields for internal state.
public float rotationSpeed = 50f; // editable in Inspector
Example workflow
Tune rotationSpeed while in Play to find a satisfying value, then copy it back into the script if you want to persist it outside Play mode.
Misconception
Don't assume Inspector edits during Play persist. They are temporary unless explicitly applied after exiting Play mode.
Design tip: prefer explanatory default values and clear field names so teammates can tune behavior without reading code.
Key Takeaway
Expose tuning parameters for rapid iteration and keep core state private to avoid accidental changes.
