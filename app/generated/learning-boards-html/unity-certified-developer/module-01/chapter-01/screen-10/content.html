Module 1 › Chapter 1.1 › Customize and Save Editor Layouts
Why layouts matter
A tailored layout reduces friction between tasks and keeps your most-used windows visible and large enough to be useful.
Create a layout
Drag window tabs to new positions to split or stack, resize panels to prioritize the Scene or Game view, then use Save Layout to persist your arrangement.
Example layouts
Level Design: large Scene. Scripting: Project and Inspector plus code editor. Animation: Timeline visible and Scene focused.
Practical steps
  1. Arrange windows using drag-and-drop.
  2. Resize panels for the primary task.
  3. Save the layout with a descriptive name so you can restore it later.
Misconception
Layouts are fixed. In fact you can edit and resave them as your workflow evolves.
Key Takeaway

Save a layout for each common task to reduce interruptions and keep the right tools close at hand.
