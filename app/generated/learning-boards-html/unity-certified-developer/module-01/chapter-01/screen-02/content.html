01 • Identify Windows
Name and describe Scene, Game, Hierarchy, Project, and Inspector so you can find tools fast. This matters because knowing where things live reduces time lost hunting UI elements and helps you teach others or follow tutorials accurately.
VERIFIED COMPETENCY MILESTONE
02 • Navigate the Scene
Practice orbit, pan, zoom, and frame selected objects with keys and mouse. Fluid camera control makes level design faster and avoids losing objects in large scenes.
VERIFIED COMPETENCY MILESTONE
03 • Customize Layouts
Dock and save an editor layout tailored to a task such as level design or scripting. A saved layout restores your workflow and minimizes context switching.
VERIFIED COMPETENCY MILESTONE
04 • Manipulate GameObjects
Create objects, edit Transform properties, and understand parent-child relationships so your scene hierarchy behaves predictably during animation and gameplay.
VERIFIED COMPETENCY MILESTONE
Mnemonic
Think S-G-H-P-I: Scene, Game, Hierarchy, Project, Inspector — a sequence to check when you look for tools or assets.
How to verify
  • Open a new 3D project and locate each core window.
  • Create a Cube in Hierarchy and frame it with the F key.
  • Save a custom layout and reopen it to confirm persistence.
