Practical shortcuts and safe testing
Camera Controls
Learn W,A,S,D for strafing, Q/E for vertical moves, Shift to speed up, middle mouse or Alt+left to pan, and right mouse to orbit. Mastery of these keeps you precise in complex scenes.
Frame Selected
Use the F key to frame a selection and recover from lost or distant camera positions; this is a fast recovery habit for large levels.
Edit vs Play Mode
Recognize that changes made in Play Mode are temporary. Always switch to Edit Mode to make persistent adjustments or save needed values before stopping Play.
Project Organization
Create folders like Models, Textures, Scripts at project start. A tidy Project window scales with team size and prevents duplicated assets.
How to practice
  1. Create a Cube, move the camera around it, press F to frame, then switch to Play and make a temporary change to see it revert.
  2. Import a placeholder file into Project and place it into a Models folder.
