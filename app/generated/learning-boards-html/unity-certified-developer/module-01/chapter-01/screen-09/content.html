Module 1 › Chapter 1.1 › Create and Manipulate a GameObject
Step-by-step
  1. Create a Cube via Hierarchy.
  2. Select it and edit Transform values to position it.
  3. Use gizmos to fine-tune move/rotate/scale.
  4. Press F to frame selected objects if you lose them.
  5. Drag to Project to make a prefab for reuse.
Concrete Example
Scale a Cube to 10x0.5x10 to create a platform and raise it on Y to 1. Use the Rigidbody component to test physics interactions in Play Mode, remembering to stop Play to save permanent changes.
Common Mistake
Forgetting to make prefabs for repeated objects. Manual duplication increases maintenance work later.
Key Takeaway

Follow create, configure, and prefab patterns to build reusable content quickly and consistently.
