Module 1 › Chapter 1.1 › Scene View vs. Game View
Side-by-side comparison
Scene View
Editable camera, gizmos, and handles. Use this to arrange GameObjects, set transforms, and prepare lighting before playtesting.
Game View
Runtime preview from the active camera including player UI and render effects. Use this to validate the player's visual experience.
Concrete Scenario
Imagine adjusting a light color for atmosphere. In Scene it looks correct, but in Game with post-processing the intensity or color balance may differ. Validate in Game View and then apply final tweaks in Edit Mode.
Common Mistake
Editing while in Play Mode and expecting changes to persist. They will not. Learn to copy values or note changes to reapply in Edit Mode.
Key Takeaway

Use Scene to edit, Game to validate. Always switch out of Play Mode before making permanent changes.
