Component-based overview
Components attach modular behavior and appearance to GameObjects. The Inspector reveals component fields for tuning and configuration.
Typical Components
  • Transform: position, rotation, scale.
  • Mesh Renderer: controls material and visibility.
  • Collider: enables physics interactions.
  • Script components: expose public fields in Inspector for tuning behavior.
Practical Example
Select a Light and change color and intensity in the Inspector to see immediate effects. Scripts with public variables will appear here for rapid iteration.
Example: Cube components
A Cube typically has a Transform, Mesh Filter, Mesh Renderer, and optionally a Box Collider. Change the scale values in the Transform to resize, change material on the Mesh Renderer to alter appearance, and test collisions by adding a Rigidbody.
Common Misconception
Thinking a GameObject alone has behavior. Behavior comes from attached components; remove a component and behavior disappears.
Key Takeaway

Use the Inspector to tune public fields and compose components for predictable object behavior.
