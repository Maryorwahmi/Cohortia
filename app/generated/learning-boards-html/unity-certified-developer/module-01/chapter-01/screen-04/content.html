Module 1 › Chapter 1.1 › Scene View: Your 3D Canvas
Definition
The Scene View is the editor window for arranging GameObjects in 3D. It shows gizmos, guides, and handles for direct manipulation.
Controls Cheat Sheet
  • Orbit: Hold right mouse button + move mouse.
  • Pan: Middle mouse button drag or Alt + left drag.
  • Move: W, A, S, D; Up/Down: Q, E; Hold Shift to speed up.
  • Frame selected: Select object and press F.
Common Mistake
Confusing Scene camera movement with the player's camera. Scene camera is for editing only and does not change gameplay unless you move the active Camera GameObject itself.
Example Walkthrough
Create → Select → Frame
Create a 3D Cube from the Hierarchy, select it and press F. Use the right mouse button to orbit and W to move forward until the Cube sits where you want it. This small loop trains three controls that you will use repeatedly.
Key Takeaway

Scene navigation is foundational. Build muscle memory for orbit, pan, zoom, and framing to speed level assembly.

Try this
Place three Cubes in the Scene, use F on each, then practice panning between them without changing zoom. Did your view stay oriented?
