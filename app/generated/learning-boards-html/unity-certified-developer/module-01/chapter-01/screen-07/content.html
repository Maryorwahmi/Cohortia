Module 1 › Chapter 1.1 › Project Window: Your Asset Library
What it holds
All imported and created assets for your project. Files in the Project Window are the canonical copies used to populate scenes.
Importing Example
Drag a model file into the Project Window to import it. Then move it into a Models folder so it is easy to find and reuse across scenes.
Organizational Tip
Create consistent top-level folders: Models, Textures, Scripts, Prefabs, Scenes. Keep naming conventions simple and predictable.
Practical steps
  1. Create folders: Models, Textures, Scripts.
  2. Import a sample asset and move it to Models.
  3. Use search and filters to confirm the asset type and preview it.
Key Takeaway

Start with a clear folder structure to save time and avoid duplicate assets as the project grows.
