Process Flow
Using the Unity Memory Profiler
A repeatable measurement workflow to validate memory optimizations.
  1. Run the app on the target device and open the Memory profiler.
  2. Capture a baseline snapshot during a representative scenario.
  3. Change one import setting or optimization at a time.
  4. Capture a second snapshot and compare categories like Textures and Audio.
  5. Repeat until the largest consumers are within your budget.
Example
After reducing texture Max Size from 4096 to 1024, compare snapshots to see the Textures category drop and free memory for other systems.
Misconception
A single snapshot is not enough; compare before and after to prove impact and avoid chasing invisible changes.
Snapshot tips
Capture representative states
Take snapshots during loading, mid-play, and after level setup to see peak usage.
Compare categories
Look at Textures, Audio, Meshes, and Scripting allocations to prioritize work.
Watch for GC spikes
Frequent garbage collection indicates runtime allocation churn you should eliminate.
