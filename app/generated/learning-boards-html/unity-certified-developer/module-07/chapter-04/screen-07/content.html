Optimizing audio assets
Follow these steps to minimize audio memory while keeping acceptable quality.
  1. Inspect the audio clip and note its length and current memory cost in the profiler snapshot.
  2. Compression — choose Vorbis for music or ADPCM for small sfx where size matters more than fidelity.
  3. Load Type — set Streaming for long tracks, Decompress On Load for short sfx, Compressed In Memory for medium clips.
  4. Sample Rate — lower to 22 kHz for distant/ambient sounds to save memory with modest quality loss.
  5. Re-measure in the Memory profiler on device and compare before/after snapshots.
Example
A 5-minute WAV set to Decompress On Load consumes large RAM. Switching to Streaming and Vorbis reduces peak memory dramatically.
Common mistake
Leaving long music as decompressed audio increases load times and memory; streaming is usually the safer choice for long clips.
Audio import quick cards
Decompress On Load
Best for short sound effects; places full uncompressed data in RAM.
Compressed In Memory
Keeps compressed data in RAM and decodes during playback; good for medium clips.
Streaming
Reads audio from disk in small chunks, ideal for long music and dialogue to minimize RAM.
