Common mistakes and verification checklist
What to avoid and how to prove your optimizations worked.
Common mistakes
  • Relying on disk size instead of runtime memory measurements.
  • Loading all assets at startup instead of on demand.
  • Leaving long audio as decompressed in memory.
  • Allocating in hot paths, causing GC spikes.
Verification checklist
  1. Capture baseline snapshot on target device.
  2. Change one import setting and re-run same scenario.
  3. Compare snapshots and inspect Textures/Audio/Mesh categories.
  4. Observe GC frequency and frame-time stability during a full playthrough.
Example confirmation
After reducing texture max size and switching audio to Streaming, both categories should show lower memory in the second snapshot and frame-time should be more stable.
Key Takeaway

Avoid these common mistakes and always verify with before/after profiler snapshots on the target hardware.
