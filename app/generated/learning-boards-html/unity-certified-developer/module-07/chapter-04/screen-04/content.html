Core Concept
Why memory matters in Unity
Symptoms, causes, and an actionable checklist for measurement.
Quick checklist
  • Open Memory profiler and take a snapshot.
  • Identify largest categories: Textures, Audio, Meshes, Scripting.
  • Test on the target device, not only in editor.
Common misconception
Compressed file size does not equal runtime memory. Uncompressed representations and mip maps determine RAM cost.
Example
A 4096 texture may look fine on desktop but can push a mobile device over its memory limit. Reducing Max Size to 1024 or 512 often yields big savings with little perceptible quality loss for distant or small objects.
Key Takeaway

Measure first. Optimize the biggest categories first, and re-measure on device to confirm improvements.

Annotated memory map
Textures
Often the largest category; check Max Size, format, and mip maps.
Audio
Long music should stream; effects can decompress on load.
Meshes & Animations
Reduce vertex count, enable mesh optimization, and apply animation compression.
Why test on device?
Editor memory uses host machine resources; a profiler snapshot on target hardware reveals the true peak memory constraints.
