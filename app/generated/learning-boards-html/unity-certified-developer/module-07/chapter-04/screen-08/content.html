Definition
Mesh and animation data optimization
Reduce vertex data and animation keyframes to lower memory usage.
Mesh tips
Use LODs to swap to simpler meshes at distance and enable Optimize Mesh in import settings to improve GPU cache locality.
Animation compression
Choose Optimal or Keyframe Reduction to remove redundant data and shrink animation memory cost.
Example
Removing unused blend shapes from a character and applying animation keyframe reduction noticeably lowers memory while keeping motion fidelity.
Key Takeaway

Optimize mesh complexity and animation data at import time, and use LODs to hide complexity when appropriate.

Checklist
Enable Optimize Mesh
Reorder vertices for GPU efficiency in Model Import Settings.
Remove unused blend shapes
Eliminate morph targets you don't animate to save memory.
Apply animation compression
Choose keyframe reduction or Optimal to shrink animation size.
