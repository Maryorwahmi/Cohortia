Lab Walkthrough
Hands-on activity: texture and audio optimization
A step-by-step lab to measure and reduce memory for textures and audio.
Step 1 — Baseline
Import a 4096 texture and 5-minute audio. Place in scene and capture Memory snapshot on device.
Step 2 — Texture
Change Max Size to 1024 or 512, pick platform format (ETC2/PVRTC/DXT), and toggle mip maps appropriately. Apply and re-run snapshot.
Step 3 — Audio
Set Load Type to Streaming, Compression to Vorbis at ~70–80% quality, and lower sample rate if acceptable. Re-run snapshot.
Compare snapshots
Look at Textures and Audio categories to quantify memory reductions. Capture screenshots for documentation.
Repeatability
Change one setting at a time to know which action produced the improvement.
Key Takeaway

The profiler proves results. Measure before and after each import change on the target device to confirm real memory savings.
