Resolution vs Compression
Choose an appropriate Max Size and format per platform to balance memory and quality.
Resolution
Lower Max Size when the texture is not viewed full-screen. 512 or 256 may be enough for small or distant items.
Compression formats
Choose DXT for desktop, ETC/ETC2 for Android, PVRTC for iOS. These use GPU-friendly formats and reduce memory footprint.
Mip maps
Enable for textures seen at variable distances. Cost ~33% more memory but improves sampling and reduces aliasing.
Example
A background rock texture set to 4096 can be reduced to 1024 or 512 with ETC2 on Android to save memory while keeping acceptable visual fidelity.
Common mistake
Using uncompressed 32-bit textures for everything because they look best in the editor. This causes large runtime memory use on devices.
Platform format quick guide
Desktop - DXT
Good balance of quality and size for PC builds.
Android - ETC/ETC2
Use ETC/ETC2 to match mobile GPU expectations and save memory.
iOS - PVRTC
PVRTC is optimized for iOS devices but has different artifact characteristics; test visually.
Key Takeaway

Match texture resolution to on-screen size and use the GPU-native compression format for your target platform.
