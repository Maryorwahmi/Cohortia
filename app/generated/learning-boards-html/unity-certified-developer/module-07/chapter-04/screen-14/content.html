Key Concepts — What to Remember
Texture Compression
Use DXT, ETC, or PVRTC to reduce texture memory and match GPU formats.
Mip Maps
Smaller precomputed texture levels that improve sampling but increase memory by ~33%.
Audio Load Type
Choose Streaming for long music, Decompress On Load for short effects, or Compressed In Memory for mid-size clips.
Summary
These settings are the primary levers for reducing runtime memory. Always verify with the Memory profiler on the target hardware.
