Module 07 › Chapter 7.5 › IDE Setup
Quick setup steps
  1. Open Unity → Edit → Preferences → External Tools and choose your IDE.
  2. Open your script in the IDE and set a breakpoint by clicking the margin at a line number.
  3. In the IDE, choose Attach to Unity Editor or use the Attach Unity Debugger command.
  4. Enter Play Mode in Unity; the IDE will pause when a breakpoint is hit.
Misconception: attaching the debugger will always be slow. In practice, attaching is fast and invaluable for inspecting object graphs and variable states you cannot infer from logs alone.
What you gain
  • Inspect variables: Hover or use Locals/Watch windows to see live values.
  • Call stack: Trace the sequence of calls that led to the breakpoint.
  • Step commands: Use Step Over, Step Into, and Step Out to navigate execution precisely.
Key Takeaway

A correct IDE attach gives you full runtime visibility—use it when logs are not enough to explain behavior.
