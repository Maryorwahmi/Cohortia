Module 07 › Chapter 7.5 › Debug.Log Levels
Definition

Informational, warning, and error log levels let you prioritize and filter diagnostic output.

Debug.Log — general messages and variable values.
Debug.LogWarning — indicates potential problems that still allow continuation.
Debug.LogError — critical failures, shown in red with stack traces.
Key Takeaway

Choose a log level that communicates severity; use errors for failures you need to fix immediately.

Concrete example
// Example calls shown for clarity
Debug.Log("Player health: " + playerHealth);
Debug.LogWarning("Missing component on " + gameObject.name);
Debug.LogError("Failed to load asset: " + assetPath);
Misconception
Some developers print everything unfiltered. That creates noise and hides important errors. Use targeted logs and change levels rather than flooding the Console.
Visual mnemonic: color-coded urgency — blue for info, amber for warnings, red for errors.
