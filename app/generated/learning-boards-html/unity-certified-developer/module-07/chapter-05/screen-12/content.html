Module 07 › Chapter 7.5 › Lab: BuggyCounter
Starter instructions
Create a new C# script named BuggyCounter and paste the provided code.
Set your IDE as Unity's external script editor and attach the IDE debugger.
Set a breakpoint on currentCount++ and test stepping, then add a conditional breakpoint currentCount == 6 and retest.
Reflection: After pausing at the conditional breakpoint, inspect the Locals window and call stack. Which earlier function call influenced the value that became null?
Common pitfalls
  • Not attaching the debugger before Play Mode.
  • Setting conditions that reference variables out of scope.
  • Leaving too many logs active and slowing Play Mode.
Key Takeaway

This lab practices the cycle of reproduce, pause, inspect, and fix — use conditional breakpoints to reach the problematic state efficiently.
