Module 07 › Chapter 7.5 › Conditional Breakpoints
Example code
void Update() { for (int i = 0; i < 1000; i++) { // Place breakpoint here with condition: i == 499 ProcessData(i); } }
How to set it
  1. Set a breakpoint on the target line.
  2. Right-click the breakpoint → Conditions…
  3. Enter the condition expression, e.g. i == 499, and save.
Tips & pitfalls
Keep conditions simple: avoid function calls or heavy expressions inside the condition.
Check variable scope: ensure the variable referenced is visible at that breakpoint location.
Performance: many condition checks are cheap but complex conditions can slow execution; keep them minimal.
Key Takeaway

Use conditional breakpoints to pause exactly when the event you care about happens, saving time on repeated iterations.
