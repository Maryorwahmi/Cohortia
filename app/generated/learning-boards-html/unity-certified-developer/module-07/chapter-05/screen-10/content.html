Module 07 › Chapter 7.5 › Try-Catch
Example from chapter
try { string data = File.ReadAllText(filePath); Debug.Log("Data loaded: " + data); } catch (FileNotFoundException ex) { Debug.LogError("File not found at " + filePath + ": " + ex.Message); } catch (IOException ex) { Debug.LogError("An I/O error occurred: " + ex.Message); } catch (System.Exception ex) { Debug.LogError("An unexpected error occurred: " + ex.Message); }
This pattern logs helpful context and preserves application stability instead of letting an unhandled exception crash the game without explanation.
Guidelines
  • Catch specific exceptions where possible.
  • Log meaningful context such as file names and variable values.
  • Avoid empty catches that swallow errors silently.
Key Takeaway

Use try-catch to capture and log exceptions with context; prefer specific catches and avoid masking real defects.
