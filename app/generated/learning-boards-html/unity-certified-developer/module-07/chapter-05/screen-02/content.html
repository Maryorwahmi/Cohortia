Learning Objectives

Progress: Learn → Understand → Apply → Master

Learn • Understand • Apply • Master
01
Master log levels

Use Debug.Log, Debug.LogWarning, and Debug.LogError correctly so messages are prioritized and searchable.

Verified Competency Milestone
02
Use the Unity Console

Filter by type, collapse repeats, clear on play, and jump to the exact file line from errors.

Verified Competency Milestone
03
Set breakpoints

Place breakpoints in Visual Studio or Rider to pause execution and inspect variables and the call stack.

Verified Competency Milestone
04
Step-through debugging

Use Step Over, Step Into and Step Out to follow execution and isolate logic errors line by line.

Verified Competency Milestone
05
Conditional breakpoints

Pause execution only when a logical condition is true, saving time when bugs appear intermittently.

Verified Competency Milestone
06
Remote debugging

Attach the IDE debugger to a running build on a device by enabling script debugging and waiting for a managed debugger.

Verified Competency Milestone
07
Try-catch basics

Use try-catch blocks to log informative errors and prevent crashes from common runtime exceptions.

Verified Competency Milestone
08
Inspect Call Stack

Understand the sequence of function calls that led to the current execution point to trace root causes quickly.

Verified Competency Milestone
