Diagnostic Rituals

Small routines reduce wasted time and avoid chasing misleading symptoms.

  • Hypothesis first
    Predict the behavior before you run to make observations meaningful.
  • Precise logs
    Include names and values so console search and collapse are effective.
  • Clear on Play
    Start each run with a clean console to avoid stale messages.
  • Device builds
    Use development builds with script debugging to reproduce device-only bugs.

Common pitfalls

Ignoring warnings: Warnings often point to fragile code paths that lead to runtime errors later.
Over-logging: Too many logs slow down Play Mode and make the console noisy; prefer targeted logs.
Assuming editor parity: Editor behavior can differ from device builds; always test on target hardware when possible.
Key Takeaway

Adopt a short, repeatable debugging ritual: hypothesize, instrument, observe, and refine.
