Module 8 › Chapter 7.7 › Enable Analytics
Turn Analytics on
Open Services, enable Analytics, and accept terms. Analytics will begin collecting default metrics and any custom events you send.
Pre-built reports you'll see:
  • Daily active users and retention curves.
  • Session length and average sessions per user.
  • Simple funnels and progression if you define events.
Why this matters

Pre-built reports provide a quick pulse on engagement; custom events make those reports actionable for design decisions.

Common misuse
A mistake is sending too many low-value events, which floods dashboards and increases cost. Design a small set of high-value events first.
Design checklist for events:
  • Will this event answer a specific design question?
  • What parameters provide context for the event?
  • Can the event be triggered frequently without over-reporting?
Example
Track LevelCompleted with parameters for level name and time taken so you can analyze completion rates and speed across segments.
