Module 8 › Chapter 7.7 › Enable Cloud Diagnostics
Enablement process
Follow these steps inside the Unity Editor to activate crash and exception reporting.
1
Open Window → General → Services to open the Services window and sign in if necessary.
2
Link your project to a Unity organization if it is not already linked, so services can attach to the project.
3
Enable Cloud Diagnostics and ensure Enable Crash and Exception Reporting is checked in the Cloud Diagnostics options.
4
Build and run a development build with networking enabled to confirm reports arrive on the Dashboard.
Common mistake

Assuming reports will appear immediately. Allow processing time and verify your build settings and network access.

Dashboard expectations
Once enabled, the dashboard will show grouped crash reports, exceptions, device info, and error trend graphs.
What to look for:
  • Crash groups with stack traces and frequency.
  • Device model and OS breakdown for each group.
  • Error trends over time to spot regressions after updates.
Quick verification
Trigger a safe simulated error in a development build and confirm it appears in Cloud Diagnostics within minutes.
