Module 8 › Chapter 7.7 › Build & Verify
Build checklist
Development build
Enable Development Build in Build Settings to preserve diagnostic info.
Network access
Ensure the test machine can reach the reporting endpoints and is not blocked by a firewall.
Reproduce steps
Perform the exact actions that send events or cause the simulated exception.
Wait and verify
Allow several minutes for the Dashboard to show events and crash groups.
Troubleshooting
  • No data: check service toggles and that the build has internet access.
  • Only partial data: confirm development build retains necessary symbols and logging.
  • Many unrelated events: review event design to remove noisy, low-value events.
Common pitfall

Using production builds for verification without proper symbols may hide useful stack trace detail; prefer development builds for initial validation.
