Module 8 › Chapter 7.7 › Crash vs Analytics
Crash Data (Cloud Diagnostics)
Stability-focused, includes stack traces, device metadata, and grouped errors for triage.
  • Use for pinpointing failing code and platform-specific bugs.
  • Prioritize by frequency and affected user base.
Analytics Events (Unity Analytics)
Behavior-focused, records actions and parameters so you can analyze progression and funnels.
  • Use for understanding player paths and measuring the impact of design changes.
  • Segment by parameters to find which players see high crash rates or drop off.
Combined workflow
When a crash spikes, check recent analytics funnels to see what players were doing, then use stack traces to fix the code. This reduces guesswork and speeds resolution.
