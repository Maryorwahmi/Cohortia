Understanding Performance Bottlenecks in Unity

Learn to spot CPU, GPU, and memory limits, use the Profiler to gather evidence, and run quick tests that point to the correct subsystem.

In this lesson
Where bottlenecks occur

CPU, GPU, and memory are primary suspects; each has distinct signs in the Profiler.

Coming up
Profiler basics

Open Window > Analysis > Profiler, observe CPU/GPU/Memory graphs while playing.

Hands-on
Add objects and watch spikes

Try duplicating many cubes and observe how frame time and draw calls change.

Visual Concept
Cards show CPU · GPU · Memory with connections
CPU
Logic, physics, Update loops. Example: many AI agents running pathfinding.
GPU
Rendering, shaders, draw calls. Example: many unique materials and post-processing.
Memory
Assets and allocations. Example: high-resolution textures causing high RAM use and stutters.
Connections: CPU issues can increase draw calls, GPU pressure can hide script problems, and memory problems can cause stutters even if CPU/GPU look OK.
Key Takeaway

Start profiling early. Learn to read CPU, GPU, and memory signals so you can ask the right diagnostic question quickly.
