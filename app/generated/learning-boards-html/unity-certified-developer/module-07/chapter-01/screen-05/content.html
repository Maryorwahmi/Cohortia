Architecture

What the CPU handles

Scripts, physics, AI, animation setup, and issuing draw calls. These tasks add up per frame.

Common CPU culprits
  • Heavy Update loops on many GameObjects.
  • Repeated GetComponent lookups inside hot loops.
  • Complex physics with many colliders or iterations.
Concrete fix examples

Cache component references, move costly work to less frequent ticks, simplify AI, and profile small blocks to locate hotspots.

Quick code panel (illustration)
// Pseudo C# illustration // Avoid calling GetComponent each frame private Rigidbody rb; void Awake(){ rb = GetComponent<Rigidbody>(); } void Update(){ rb.AddForce(...); }
Common mistake

Leaving heavy logic in Update for convenience. That multiplies cost by the number of active objects every frame.

Key Takeaway

Measure script cost and reduce frequency or cache expensive operations instead of assuming they are cheap.
