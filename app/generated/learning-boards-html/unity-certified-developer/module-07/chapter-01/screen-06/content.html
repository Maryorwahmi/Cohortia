Module 07 › Chapter 7.1 › GPU Rendering
Definition

GPU-bound performance

GPU-bound means the graphics pipeline or rendering workload limits frame rate rather than script execution.

What increases GPU work?
  • Many unique materials or meshes.
  • High-resolution textures and complex shaders.
  • Expensive post-processing and many lights.
Draw calls explained

Each draw call is a render instruction; many small, distinct objects produce more draw calls than batched geometry.

Diagnostic

Lower resolution or quality settings. A big improvement suggests GPU-bound work was limiting frame rate.

Mitigation examples
  • Combine meshes and reduce material variants.
  • Use simpler shaders and lower texture sizes where possible.
  • Trim expensive post-processing effects on constrained devices.
Key Takeaway

If rendering dominates frame time, use quality reduction tests and draw call analysis to confirm GPU-bound behavior.
