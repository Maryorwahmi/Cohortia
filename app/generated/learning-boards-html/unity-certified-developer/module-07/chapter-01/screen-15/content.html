Module 07 › Chapter 7.1 › Key Concepts
Performance Bottleneck
A subsystem that limits overall performance.
CPU-bound
When CPU work like scripting or physics limits frame rate.
GPU-bound
When rendering work like draw calls or shaders limits frame rate.
Unity Profiler
Tool to monitor CPU, GPU, and Memory in real time and capture frames for analysis.
Frame Rate (FPS)
Frames rendered per second; a primary measure of smoothness.
Draw Call
A CPU instruction to the GPU to render geometry; many draw calls increase rendering cost.
Summary

Use these terms as a checklist when you profile: name the bottleneck, measure the metric, and pick a focused fix.
