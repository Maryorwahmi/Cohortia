Profile at milestones

Use scheduled profiling to keep performance predictable and fixes affordable.

Baseline
Capture an initial Profiler snapshot when core mechanics run.
Feature checks
After major features, compare traces to see added costs and decide small fixes.
Platform pass
Run platform-specific profiling late in the cycle to catch memory and draw call limits on target devices.
Key Takeaway

Schedule profiling milestones and require before/after traces for changes that could affect performance.
