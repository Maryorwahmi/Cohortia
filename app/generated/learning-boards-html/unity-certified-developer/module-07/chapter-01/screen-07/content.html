Process Flow

How a draw call travels from CPU to GPU

1. CPU prepares objects
Gather visible objects and their material/shader states.
→
2. State changes
Set shader, textures, and render states required by the object.
→
3. Issue draw call
CPU sends render command to GPU to draw triangles with the chosen state.
Why many small objects hurt

Each small object may require its own state change and draw call; that increases CPU overhead and GPU workload.

Mitigation

Batch objects sharing materials, use atlases, combine meshes, or use GPU instancing where appropriate.

Key Takeaway

Reducing draw calls often reduces both CPU and GPU pressure; measure draw call counts before and after changes.
