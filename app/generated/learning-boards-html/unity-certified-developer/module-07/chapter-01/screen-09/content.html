Code Walkthrough

Open Profiler and capture a spike

Start Play Mode, provoke a performance spike, pause and inspect the frame in the Profiler hierarchy to find the costly module or function.

Step example
  1. Open Window → Analysis → Profiler and enter Play Mode.
  2. Create a spike (duplicate many cubes or trigger heavy AI).
  3. Pause, select the spiking frame, and expand the CPU or Rendering sections to drill into subcalls.
What to record

Take a screenshot of the Profiler showing a clear spike and note which top-level module increased: Scripts, Rendering, or Memory.

// Profiler checklist 1. CPU Usage: Scripts, Physics, Rendering 2. GPU Usage: Render passes, draw calls 3. Memory: managed/native, allocations // Capture a frame and drill down
Key Takeaway

Use the Profiler to collect evidence before changing systems; sample multiple frames to avoid chasing a transient spike.
