Module 7 › Chapter 7.3 › GPU Instancing
Definition
How instancing works
A single draw call can tell the GPU to render the same mesh many times with per-instance transform or parameter data. This reduces CPU overhead and avoids duplicating mesh data.
When to use
  • Large numbers of identical meshes that differ only by transform or simple parameters.
  • Materials that support instancing — enable the checkbox on the material.
Key Takeaway

GPU instancing is ideal for many identical objects and often yields better scaling than CPU-side batching for large counts.

Concrete Example
A meadow filled with thousands of identical grass meshes can be drawn as a small number of instanced draw calls, with transform arrays providing position and rotation per instance.
Checklist
  • Confirm shader supports instancing.
  • Enable 'Enable Instancing' on the material.
  • Batch similar instances into one instanced draw when possible.
Contrast
Instancing excels with high instance counts of identical meshes. For a few unique objects, batching or none at all may be simpler.
