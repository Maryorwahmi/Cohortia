01
Reduce Draw Calls
Apply static and dynamic batching and enable GPU instancing where appropriate to lower CPU-to-GPU overhead. Reducing draw calls lowers CPU overhead and lets the GPU focus on geometry and shading work.
VERIFIED COMPETENCY MILESTONE
02
Implement LODs
Create LOD groups to swap lower-polygon meshes as distance increases. This reduces triangle cost while preserving perceived detail at range.
VERIFIED COMPETENCY MILESTONE
03
Occlusion Culling
Bake occlusion so Unity avoids rendering objects fully hidden by other geometry. This is essential for complex indoor and urban scenes.
VERIFIED COMPETENCY MILESTONE
04
Textures & Shaders
Use atlasing, compression, and simpler shaders for non-critical objects to reduce memory bandwidth and shader cost on the GPU.
VERIFIED COMPETENCY MILESTONE
