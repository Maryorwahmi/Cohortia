Module 7 › Chapter 7.3 › Hands-on: LOD Groups & Static Batching Lab
Lab Steps
  1. Create three mesh variants: MyObject_LOD0 (high), _LOD1 (medium), _LOD2 (low).
  2. Create an empty GameObject named LOD_Group_Object and add an LOD Group component.
  3. Assign the mesh renderers for each LOD slot and tune transition percentages.
  4. Duplicate the LOD_Group_Object 50–100 times to populate the scene.
  5. Select all duplicates and mark them Static > Batching Static in the Inspector.
  6. Run Play mode, open Window > Analysis > Frame Debugger, and step through draw calls to confirm batching and LOD switching.
Verification
Observe draw-call reduction and LOD swaps. Also check memory for increased combined mesh buffers when using static batching.

Expected Result
Triangle count drops as LODs switch and draw calls fall drastically when static batching combines geometry.
Common Mistake
Using different materials per instance prevents batching. Ensure shared materials when batching is intended.
