Module 7 › Chapter 7.3 › Key Concepts
Draw Call
A CPU command to render geometry. Reduce count to lower render-thread overhead.
Batching & Instancing
Static batching for immobile objects, dynamic batching for small runtime objects, and instancing for many identical meshes.
LOD Groups
Swap lower-detail meshes by distance to reduce triangles without harming distant visual quality.
Takeaway
Combine these techniques thoughtfully and always measure with the Frame Debugger and Profiler to ensure each change helps your target platform.
