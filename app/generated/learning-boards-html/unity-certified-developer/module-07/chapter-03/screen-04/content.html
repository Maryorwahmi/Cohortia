Module 7 › Chapter 7.3 › What is a Draw Call?
Definition
Draw call explained

A draw call is the command from CPU to GPU that binds geometry, materials, and issues the render. Each call has fixed CPU cost for state changes and dispatch. High counts increase CPU frame time.

Bullets
  • Includes mesh, material, shader, and transform data.
  • Has CPU overhead for state changes and buffer bindings.
  • Thousands of small draw calls often mean CPU-bound rendering.
Key Takeaway

If the render thread is heavy in the profiler, focus first on reducing draw calls before more costly GPU-side changes.

Concrete Example
Imagine a scene with 2,000 identical rocks, each with its own mesh and material. Without batching, that's 2,000 draw calls. With instancing or batching, you can render them with a handful of draw calls, greatly reducing CPU overhead.
Common misconception
Many assume reducing triangles is always the best fix. In practice, if the CPU spends most time issuing draw calls, reducing draw calls yields larger gains than modest triangle cuts.
