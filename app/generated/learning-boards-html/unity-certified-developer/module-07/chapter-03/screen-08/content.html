Module 7 › Chapter 7.3 › LOD Groups
Definition
What LOD groups do
LOD groups swap mesh complexity based on screen percentage or camera distance, lowering vertex and triangle workload as objects get smaller on screen.
Implementation steps
  1. Create multiple mesh versions for an object.
  2. Add an LOD Group component to the parent GameObject.
  3. Assign mesh renderers for each LOD slot and set transition percentages.
Key Takeaway

LOD groups are essential for complex models in open worlds. Good transition thresholds keep visuals consistent while reducing GPU load.

Concrete Example
Create MyTree_LOD0, _LOD1, and _LOD2. Add them to an LOD Group and duplicate the tree across the landscape. As you move the camera, watch the triangle count drop in the profiler as LODs switch.
Pro tip
Use simple primitives as placeholder LODs while iterating. Tune transition percentages to hide popping and limit the number of LOD levels to what you need.
Misconception
Thinking LODs always reduce draw calls. LODs reduce triangles, but draw-call count depends on material usage and batching. Combine LODs with batching for best results.
