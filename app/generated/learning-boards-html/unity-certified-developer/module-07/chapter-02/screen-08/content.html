Reduce physics workload

Prune simulated objects and prevent unnecessary collision tests with layers.

Checklist to reduce physics cost
  • Only add Rigidbody to objects that require simulation; static colliders are cheaper.
  • Define collision layers to prevent irrelevant pairs from being tested.
  • Move Rigidbodies with MovePosition/MoveRotation in FixedUpdate to keep physics deterministic.
  • Adjust fixed timestep only if needed; a smaller timestep increases physics load.
Example: collision layers
If projectiles should not interact with each other, create a Projectile layer and disable collisions between Projectile and Projectile in Project Settings → Physics. That removes O(n^2) checks among projectiles.
Concrete step
Open Physics settings and uncheck unwanted layer interactions to reduce the number of collision pairs evaluated.
Pitfall
Blindly disabling collisions can break gameplay; test interactions after changes.
Key Takeaway

Reduce simulated rigidbodies and configure collision layers to avoid unnecessary physics work.

Check

Use the Profiler to inspect physics CPU cost before and after removing Rigidbody or changing layers.

Warning

Changing layer collisions can have unintended gameplay side effects; validate interactions carefully.
