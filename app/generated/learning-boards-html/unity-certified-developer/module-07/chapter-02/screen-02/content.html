Learning Objectives

From readable, frame-friendly scripts to object reuse and physics configuration.

Bloom: Learn → Understand → Apply → Master
01
Efficient callbacks

Decide when code must run every frame versus once or on a timer. This reduces cumulative per-frame CPU load across many objects.

Mnemonic: timeline with removed ticks
VERIFIED COMPETENCY MILESTONE
02
Object pooling

Create and reuse instances for frequent items to avoid repeated allocation and garbage collection spikes during gameplay.

Mnemonic: recycle bin for bullets
VERIFIED COMPETENCY MILESTONE
03
Physics tuning

Use collision layers, minimize rigidbodies, and move physics objects in FixedUpdate with MovePosition for better CPU scaling.

Mnemonic: filter collisions early
VERIFIED COMPETENCY MILESTONE
04
Low-allocation code

Cache GetComponent results, avoid repeated string concatenation in hot loops, and use StringBuilder when building complex strings.

Mnemonic: hold references, avoid new strings
