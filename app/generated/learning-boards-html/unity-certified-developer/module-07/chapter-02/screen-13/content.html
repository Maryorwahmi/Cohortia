Three quick rules

Short reminders to guide day-to-day development choices.

Reduce allocations
Pool frequent objects and use StringBuilder for heavy string work.
Minimize physics pairs
Use collision layers and remove unnecessary rigidbodies.
Profile before/after
Measure CPU and GC Alloc to confirm improvements instead of guessing.
Summary strip

Small, consistent optimizations applied early keep your game scalable and reduce runtime hiccups. Test and measure every change.
