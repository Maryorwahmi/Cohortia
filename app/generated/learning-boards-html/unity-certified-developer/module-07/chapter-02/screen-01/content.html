Efficient Scripting
Decide which code must run each frame and which can be done on timers or at startup. This reduces CPU per-frame work.
Object Pooling
Pre-allocate reusable objects to avoid frequent instantiate/destroy cycles that trigger garbage collection.
Physics
Use collision layers, fewer rigidbodies, and MovePosition in fixed updates to limit physics calculations.
