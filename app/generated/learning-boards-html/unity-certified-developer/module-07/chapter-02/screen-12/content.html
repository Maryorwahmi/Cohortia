What to Remember

Three compact cards capture the most impactful practices.

Object Pooling
Reuse pre-instantiated objects to avoid repeated allocation and garbage collection spikes.
Callbacks & Physics
Use Awake/Start for setup, FixedUpdate for physics with MovePosition, and minimize expensive per-frame work in Update.
Low-allocation code
Cache GetComponent results, avoid string allocations in hot paths, and measure with the Profiler.
Final takeaway

Small, disciplined changes across scripting, pooling, and physics compound into big CPU improvements when measured with the Profiler.
