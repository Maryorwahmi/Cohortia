Module 07 › Chapter 7.6 › Objectives — Skill breakdown
Objective cards
01
Platform selection
Select and switch the target platform in Build Settings. This avoids wasted builds and surfaces platform-specific compatibility early.
02
Player identity
Set company, product, version, and icons so stores and devices present your game correctly and consistently.
03
Build types
Understand Development vs Release builds and when to enable script debugging and profiler connections for testing.
04
Testing & signing
Create signed packages for mobile and test on real devices; a missing keystore or wrong bundle id will block deployment.
Visual mnemonic
Remember: Select platform, Configure player, Build, Test. Repeat until stable.
Verification
Produce a working executable and run it on a machine or device outside the editor to confirm success.
Common pitfall
Forgetting to uncheck Development Build before distribution yields larger files and visible debug info.
