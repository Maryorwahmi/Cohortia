Module 07 › Chapter 7.6 › Platform-specific Player Settings
Android publishing
Bundle identifier and keystore are required to sign APKs. Use the Keystore Manager to create or select a keystore and key alias.
Keystore steps
  1. Create or browse to a keystore file.
  2. Create a key alias with password and validity if new.
  3. Configure Publishing Settings to use the keystore for builds.
Scripting backend & API level
Choose IL2CPP for better compatibility on many platforms; API compatibility controls available .NET APIs and may affect compilation.
iOS publishing
Set bundle identifier and the signing team to produce an Xcode-compatible package ready for signing and upload.
Common failure
Missing keystore or incorrect bundle id will cause build or store upload failures. Configure these before building for device testing.
Key Takeaway

Set signing and platform-specific options early to avoid blocked builds and store rejections.
