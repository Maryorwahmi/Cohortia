Module 07 › Chapter 7.6 › Build Settings
What it is
A window where you pick the target platform, choose scenes, and enable build-time testing options.
Key controls
  • Select platform and click "Switch Platform" to activate it.
  • Check scenes to include in the build; unchecked scenes are excluded.
  • Toggle Development Build, Script Debugging, and Autoconnect Profiler for testing.
Concrete example
To build a PC standalone, select the PC platform, ensure your main scenes are checked, switch platform if required, then hit Build and choose a destination folder.
Common mistake
Forgetting to include a scene in the Build Settings scene list will cause that scene to be missing at runtime in the built game.
Key Takeaway

Confirm active platform and scene list before building to avoid missing content and unnecessary reimports.

Visual: Build Settings cards

Why this matters
Selecting the correct platform and scenes prevents runtime surprises and speeds iteration by avoiding unnecessary asset reimports when possible.
