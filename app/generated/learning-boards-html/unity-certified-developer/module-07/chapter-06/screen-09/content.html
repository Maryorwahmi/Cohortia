Module 07 › Chapter 7.6 › Running a Build
Build steps
1. Verify Build Settings and Player Settings for the active platform.
2. Click Build and select a destination folder, preferably empty.
3. Wait for compilation and asset processing; check the Console for errors.
Concrete example
Build a Windows executable to MyOptimizedGame_PC_Build and then open the folder to run the .exe and verify startup behavior.
Expected outputs
PC: .exe + Data folder
Android: .apk or .aab file
iOS: Xcode project or .ipa after export
WebGL: HTML + data folder
If the Console shows script compilation errors, fix them before building—builds fail on script errors.
