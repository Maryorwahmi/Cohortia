Module 07 › Chapter 7.6 › Dev Build vs Release Build
Development Build
Includes debug symbols, script debugging, and profiler hooks for testing on devices.
Useful for diagnosing crashes and measuring performance on actual hardware.
Larger file size and slower runtime due to debugging overhead.
Not recommended for public distribution.
Pro tip
Enable Autoconnect Profiler only when you need live profiling to avoid accidental profiling overhead.
Release Build
Optimized and stripped of debug info; smaller and faster; intended for players and stores.
Use for final distribution and store submissions.
Test on release builds too; some issues only appear without debug hooks.
Misconception
Believing development and release builds match performance exactly is wrong; profiling hooks and unstripped symbols change runtime behavior.
