Module 07 › Chapter 7.6 › Testing Deployed Builds
Testing checklist
Build a Development Build and enable Script Debugging when you need to attach a debugger to the running app.
Use Autoconnect Profiler to capture device performance data during real runs.
Produce a Release Build to confirm performance without debug overhead.
Device testing notes
Test installation, resolution modes, permissions, and low-end hardware to ensure robustness.
Concrete example
Enable Autoconnect Profiler while running a Development Build on your phone to capture frame spikes and then fix the most costly draw calls or scripts.
Misconception
Passing Play Mode tests does not guarantee builds will run identically on devices; always test on the target hardware.
