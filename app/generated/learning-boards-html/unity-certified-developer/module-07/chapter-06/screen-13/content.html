Module 07 › Chapter 7.6 › Activity: PC Standalone
Step-by-step activity
1. Open File > Build Settings and select "PC, Mac & Linux Standalone".
2. Click Switch Platform if needed and wait for reimport to complete.
3. Open Player Settings and set Company: Cohortia, Product: MyOptimizedGame, resolution 1280x720 windowed.
4. Ensure Development Build is unchecked and click Build, choose an empty destination folder.
5. After the build finishes, run the executable to validate the game outside the Editor.
Common error
If build fails, check the Console for script errors and fix them before rebuilding.
Concrete goal
Produce a working executable in a dedicated folder and confirm the game launches correctly on your machine.
Key Takeaway

A clean build folder and confirming no Console errors are the two best practices to ensure a successful standalone build.
