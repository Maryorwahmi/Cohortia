Module 07 › Chapter 7.6 › Platform-Specific Directives
What it is
Preprocessor directives conditionally include code at compile time based on the active platform.
// Example: platform-specific log on Start\nvoid Start()\n{\n #if UNITY_STANDALONE_WIN\n Debug.Log("Running on Windows PC.");\n #elif UNITY_ANDROID\n Debug.Log("Running on Android device.");\n #elif UNITY_IOS\n Debug.Log("Running on iOS device.");\n #elif UNITY_WEBGL\n Debug.Log("Running in WebGL browser.");\n #else\n Debug.Log("Running on an unknown platform.");\n #endif\n}
Key note
Directives are resolved at compile time; non-matching blocks are excluded from the final build.
Concrete example
If a plugin is PC-only, wrap its usage in a WINDOWS directive so mobile builds won't try to compile it and fail.
Misconception
They are not runtime conditionals; they change which code is compiled into the build itself.
Key Takeaway

Use preprocessor directives to protect platform-specific code and test on target hardware to confirm behavior.
