Module 4 › Chapter 4.3 › Hands-on Workflow
Step checklist
  1. Create folders: Assets/Audio/SFX and Assets/Audio/Music.
  2. Import SFX: set Load Type = Decompress On Load, Compression = ADPCM.
  3. Import Music: set Load Type = Streaming, Compression = Vorbis.
  4. Create GameMixer and add Music and SFX groups.
  5. Set AudioSource Output to appropriate group and test in play mode.
Test scenario
Place MusicPlayer with looped music. Place a Cube with AudioSource for SFX and a simple collision script that plays the clip on impact. Play scene and move camera to verify 3D attenuation and group volume adjustments in the AudioMixer.
Key Takeaway
Follow a checklist: organize folders, set load types by role, route to mixer groups, then profile in a build.
