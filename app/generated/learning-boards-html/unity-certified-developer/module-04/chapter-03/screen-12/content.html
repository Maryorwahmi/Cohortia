Module 4 › Chapter 4.3 › Testing & Profiling
Editor checks
  • Play scenes and verify routing and spatialization.
  • Use the Audio window and Profiler to measure sample counts, memory, and CPU.
  • Confirm no multiple AudioListener warnings appear in console.
Build checks
Create a development build for target platforms and verify streaming behavior, latency, and whether audio stutters under load. Adjust compression quality or load type if needed.
Key Takeaway
Profile both in-editor and on target devices; optimize the assets that show the largest memory or CPU impact first.
