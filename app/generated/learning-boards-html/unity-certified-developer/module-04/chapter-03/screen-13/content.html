Module 4 › Chapter 4.3 › Activity: Implement 2D & 3D Audio
Quick steps
  • Create folders and import SFX and Music.
  • Configure import settings: SFX = Decompress On Load + ADPCM; Music = Streaming + Vorbis.
  • Create GameMixer and add Music and SFX groups.
  • Set up MusicPlayer and a 3D Cube with AudioSources and route outputs.
  • Test and profile, then iterate.
Common checklist failures
No sound when group volume changes — check Output routing; audio warnings — search for multiple AudioListeners; stuttering in builds — profile streaming and reduce bitrate or change load type.
Key Takeaway
Follow the lab steps in order, validate each component, and profile on target devices for final tuning.
