Module 4 › Chapter 4.3 › Audio Formats
Formats at a glance
WAV (PCM)
Uncompressed. Best for tiny UI cues when absolute fidelity and predictable latency are required.
MP3
Compressed, widely supported. Good for general audio but can have compression artifacts.
OGG Vorbis
Open format with better quality-to-size tradeoff. Common choice in game builds.
Example
A two-minute music track: WAV uses much more memory and should be streamed, Vorbis reduces size while maintaining quality and is also typically streamed.
Decision guide
  • Short, frequent SFX: Decompress On Load or ADPCM to minimize playback latency.
  • Medium clips: Compressed In Memory to balance memory and CPU.
  • Long music/dialogue: Streaming to avoid loading entire file into memory.
Common misconception
Compression always saves CPU. In truth, streaming saves memory but may increase CPU during decompression. Choose based on your runtime profile.
Key Takeaway

Pick format by clip role: prioritize low-latency memory for SFX and streaming for long music.
