Module 4 › Chapter 4.3 › Load Types
Step-by-step decision process
  1. Identify clip role. Is it UI, SFX, dialogue, or music?
  2. Measure length. Under a few seconds favors decompressed; minutes favors streaming.
  3. Estimate frequency. If played many times per second, prefer in-memory decompression.
  4. Test and profile. Run memory and CPU checks in the target build.
Concrete example
A ten-second explanatory voiceover used occasionally: Compressed In Memory. A five-minute looped ambience: Streaming.
Quick reference
Decompress On Load
Fast playback, high memory. Use for short, critical SFX.
Compressed In Memory
Medium memory and CPU tradeoff. Good for medium-length clips.
Streaming
Low memory, higher I/O and CPU during playback. Ideal for long music and dialogue.
Key Takeaway

Use a short decision checklist: role → length → frequency → profile to choose load type safely.
