Module 4 › Chapter 4.3 › PlaySoundOnCollision.cs
Purpose
Ensure an AudioSource exists, then play a sound when a collision occurs. Guard against missing components and overlapping playback if desired.
Practical tips
  • Set Spatial Blend to 1 for a 3D SFX.
  • Use audioSource.isPlaying to avoid stacked audio in high-frequency collisions.
  • Log errors in Start if the AudioSource is missing to speed debugging.
Code (visual)
using UnityEngine;

public class PlaySoundOnCollision : MonoBehaviour
{
    private AudioSource audioSource;

    void Start()
    {
        audioSource = GetComponent();
        if (audioSource == null)
        {
            Debug.LogError("AudioSource component not found on this GameObject!");
        }
    }

    void OnCollisionEnter(Collision collision)
    {
        if (audioSource != null && !audioSource.isPlaying)
        {
            audioSource.Play();
            Debug.Log("Playing SFX!");
        }
    }
}
Key Takeaway
Validate components in Start and avoid repeated Play calls when not desired to ensure robust SFX behavior.
