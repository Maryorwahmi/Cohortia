Module 4 › Chapter 4.3 › AudioSource
Core properties
  • AudioClip — the audio asset to play.
  • Play On Awake — plays when object activates.
  • Loop — repeats the clip.
  • Volume & Pitch — loudness and playback speed.
  • Spatial Blend — 0 = 2D, 1 = 3D.
  • Min/Max Distance — attenuation range for 3D sounds.
  • Output — route to an AudioMixer group.
Example
MusicPlayer uses Play On Awake, Loop, Spatial Blend 0, and Output set to the Music mixer group. A chest SFX uses Spatial Blend 1 and short Min/Max Distance.
Common mistakes
Leaving Spatial Blend between 0 and 1 for sounds meant to be purely UI or purely 3D, forgetting to route to an AudioMixer group so you can't adjust group volume, and attaching multiple AudioListeners to prefabs which breaks audio playback are frequent issues.
Key Takeaway

Use AudioSource settings to match the sound role: instant UI, looped music, or spatial SFX with tuned distances.
