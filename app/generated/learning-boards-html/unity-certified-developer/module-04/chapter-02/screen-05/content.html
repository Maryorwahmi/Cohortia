Module 4 › Chapter 4.2 › Model Import Workflow
Step-by-step
  1. Create folders: Assets/Models/Props and Assets/Textures/Props.
  2. Import model and textures into matching folders.
  3. Open Inspector: adjust Scale Factor, Normals, Tangents.
  4. Configure Rig: set Animation Type and avatar if needed.
  5. Adjust Animations tab: split clips and set playback options.
Common-mistake
Not checking Scale Factor or leaving Read/Write enabled unnecessarily. Wrong scale breaks physics; Read/Write increases memory if unused.

Pro tip

If a model appears too large or small, change Scale Factor first. Confirm units with the model author when possible.
