Import FBX & OBJ
Import common 3D formats. FBX carries meshes, materials, animations; OBJ usually carries geometry and UVs only.
Mnemonic: File → Project
VERIFIED COMPETENCY MILESTONE
02
Configure Import Settings
Adjust Scale Factor, Normals, Tangents, and Mesh Compression to ensure correct size and lighting while saving memory.
Mnemonic: Size → Surface → Storage
VERIFIED COMPETENCY MILESTONE
03
Create & Apply Materials
Use the Standard Shader and place Albedo, Normal, Metallic, and Smoothness textures into their correct slots to define surface behavior.
Mnemonic: Color → Detail → Metal → Smooth
VERIFIED COMPETENCY MILESTONE
04
Optimize Textures & Meshes
Set texture Max Size and Compression; adjust Mesh Compression and disable Read/Write if not needed to reduce memory and load times.
Mnemonic: Right-size for distance
