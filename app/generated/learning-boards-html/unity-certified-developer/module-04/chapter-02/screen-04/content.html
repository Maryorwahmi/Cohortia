Module 4 › Chapter 4.2 › FBX vs OBJ
Format Definition
Understand what Unity receives when you import each file type.
FBX (recommended)
  • Meshes, UVs, vertex normals
  • Materials and embedded textures in some exporters
  • Rigs, avatars, and animation clips
OBJ (geometry-focused)
  • Geometry, normals, UVs
  • Separate material files; textures imported separately
  • No animation or rig data
Key Takeaway

Select FBX when you need animations or embedded rig data; use OBJ for simple geometry imports and bring textures separately.

Concrete Example & Common Mistake
Example: exporting a crate with a simple texture. OBJ will give you the crate mesh and UVs; you'll still need to copy the Albedo and Normal textures into Unity's textures folder and create a material. Common mistake: assuming OBJ contains animation—this leads to confusion when clips are missing. Always check the asset source and export settings in the modeling tool if animation is required.
