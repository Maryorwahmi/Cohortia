Module 4 › Chapter 4.2 › Troubleshooting Visual Problems
Symptoms & fixes
Flat shading
Ensure Normals are correct and smoothing groups are intended.
Normal Map has no effect
Set texture type to Normal Map and verify Tangents are calculated.
Baked lighting in Albedo
Replace Albedo with diffuse-only texture; use Ambient Occlusion map for crevice shading.
Performance issues
If load times or memory use are high, increase Mesh Compression, reduce texture Max Size, and uncheck Read/Write on meshes unless runtime access is needed.
Quick checklist
  • Verify Normal Map type
  • Check Tangent calculation
  • Inspect Albedo for baked lighting
  • Adjust Max Size and Compression
