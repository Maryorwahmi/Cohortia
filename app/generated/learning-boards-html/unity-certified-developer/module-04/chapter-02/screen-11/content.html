Module 4 › Chapter 4.2 › Hands-on Activity
Activity steps
1. Prepare folders
Assets/Models/Props and Assets/Textures/Props
2. Import files
Drag FBX into Models and textures into Textures.
3. Configure Model
Adjust Scale Factor, Normals, Mesh Compression, and disable Read/Write unless needed.
4. Create & assign material
Create Prop_Material, set Shader to Standard, assign maps, and drag material onto the model.
Validation & tips
Lighting check
Add a Directional Light and rotate it to inspect Normal and Metallic behavior under different angles.
Texture check
Ensure Normal textures are set to Normal Map type and that Albedo contains no baked lighting.
Optimization choice
Decide Max Size per texture: close-up assets keep higher sizes; distant props can be scaled down.
