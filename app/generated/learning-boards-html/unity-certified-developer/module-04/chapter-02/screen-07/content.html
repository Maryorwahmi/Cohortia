Texture map roles
Learn the purpose of each common texture in the Standard Shader workflow.
Albedo
Base color only. Do not include baked lighting.
Normal
Adds bump detail without geometry. Must be set to Normal Map type.
Metallic
Defines metal vs dielectric areas for reflection behavior.
Smoothness
Controls roughness; often packed into Metallic alpha channel.
Occlusion
Adds soft ambient shadowing in crevices.
Height
Used for parallax or displacement effects to fake depth.
Concrete analogy
Think of Albedo as paint, Normal as embossed texture, Metallic as plated metal parts, and Smoothness as how polished the paint is. Each contributes a specific visual cue.
Misconception
Avoid baking shadows into Albedo. That makes lighting inconsistent when scene lights change.
