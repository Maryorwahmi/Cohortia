Material creation walkthrough
Follow these visual steps to produce a PBR-ready material.
// Create material
Assets/Materials > Right-click > Create > Material · Name: Prop_Material
Shader: Standard
Albedo: drag Albedo.png
Normal Map: drag Normal.png   (click "Fix Now" to convert)
Metallic: drag MetallicSmooth.png or use slider
Apply: drag Prop_Material onto model in Scene or Project
Key Takeaway

Assign textures to the correct slots and ensure Normal textures are set to Normal Map type so Unity interprets them as surface detail.

Concrete example
Prop_Material with Albedo, Normal, and Metallic/Smoothness maps applied to a crate. Observe how Normal adds perceived bump detail while Metallic/Smoothness control reflectivity and highlight sharpness.
Misconception
Dragging a diffuse image into the Normal slot will not create real normal data. Convert or import a proper Normal map.
Pro tip
If Unity prompts to Fix the Normal texture, accept it so the texture format is correct for normal mapping.
