Standard Shader
Use for PBR; supports Albedo, Normal, Metallic, Smoothness, AO, and Height.
Normal Map
Mark as Normal Map type so Unity interprets tangent-space data and fakes surface detail.
Optimization
Adjust Mesh Compression, texture Max Size, and disable Read/Write unless runtime access is needed.
Final summary

Correct import settings, material assignments, and texture optimization are the foundation of good visuals and performance in Unity projects.
