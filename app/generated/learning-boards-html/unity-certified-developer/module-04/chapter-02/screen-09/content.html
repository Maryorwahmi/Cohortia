Module 4 › Chapter 4.2 › Material Application Patterns
Shared (per-asset)
Assign material to the model asset so every scene instance uses the same material.
Benefits
Easy global edits; fewer materials to manage.
When to use
Repeated props like crates, barrels, or environment tiles.
Per-instance variation
Duplicate or assign a different material to a scene instance to create variations without affecting the original asset.
Benefits
Unique looks per instance; control over local properties.
Trade-offs
More materials can increase draw calls and asset count.
Pro tip
For many similar objects, prefer shared materials and use texture atlases or material property blocks for lightweight variations.
