Module 4 › Chapter 4.2 › Learning Objectives
Activity Checklist
  • Create folders: Assets/Models/Props and Assets/Textures/Props
  • Import FBX and texture files into matching folders
  • Adjust Scale Factor, Normals, Mesh Compression in Model tab
  • Create Standard Material and assign maps
  • Place model in Scene, add Directional Light, observe changes
Success Criteria
Visual
Model displays expected bump and specular response from Normal and Metallic/Smoothness maps.
Performance
Textures use appropriate Max Size and Compression to reduce VRAM for distant or small objects.
Common pitfall
Using baked lighting in Albedo or neglecting to mark a Normal texture as Normal Map will produce flat or incorrect shading. Fix these to let Unity's lighting work correctly.
