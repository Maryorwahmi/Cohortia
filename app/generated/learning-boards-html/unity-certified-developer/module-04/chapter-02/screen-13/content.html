Assessment questions
  1. Normal Map not working: check texture type and Tangents.
  2. High memory: reduce texture Max Size and increase Mesh Compression.
  3. Missing animation: verify Rig settings and Animation Type.
Best-practice checklist
  • Keep originals outside Unity and import optimized copies.
  • Organize Models and Textures into clear folders.
  • Verify Scale Factor immediately after import.
  • Use Normal Map type conversion when prompted.
  • Adjust Max Size and Compression for each texture based on usage.
Final takeaway

A small set of checks on import prevents most visual and performance problems: scale, normals/tangents, normal-map type, and texture sizes.
