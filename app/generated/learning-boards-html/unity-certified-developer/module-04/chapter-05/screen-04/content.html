Module 4 › Chapter 4.5 › What is a Sprite
Definition

A Sprite is a 2D graphic asset configured in Unity for rendering with the 2D pipeline.

Import checklist
  • Set Texture Type to Sprite (2D and UI).
  • Choose Sprite Mode: Single or Multiple.
  • Set Pixels Per Unit to match your art scale.
  • For pixel art, set Filter Mode to Point (no filter).
Key Takeaway

Correct import settings enable slicing, rendering, and animation workflows downstream.

Concrete Example
Import a character PNG, set Texture Type to Sprite, set Pixels Per Unit to 32, and click Apply. Confirm you can open the Sprite Editor.
Common mistake
Leaving Texture Type as Default prevents use of SpriteEditor and stops you from creating slices and animations.
Pro tip
Decide Pixels Per Unit based on how many world units the sprite should occupy so your scale is consistent across assets.
