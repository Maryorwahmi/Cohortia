Module 4 › Chapter 4.5 › Guided Activity
Activity steps
  1. Create Assets/Sprites/Player and import sprite sheet.
  2. Inspector: Texture Type = Sprite, Sprite Mode = Multiple, set Pixels Per Unit.
  3. Open Sprite Editor, slice by grid size, click Apply.
  4. Drag first frame to Scene, set Sorting Layer to Player.
  5. Create Player_Walk animation, drag frames, set Samples to 10–12, play scene.
Checks & Tips
Confirm the sliced frames appear under the sheet. If the animation doesn't play, check that the Animator component exists and the clip is assigned in the Animator Controller.
Organize
Save animation clips in an Animations folder and pack frequently used sprites into a Sprite Atlas for performance.
Key Takeaway

This activity connects import, slice, render, ordering, and animation—repeat it until it becomes a predictable pipeline for your 2D assets.
