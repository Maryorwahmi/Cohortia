Module 4 › Chapter 4.5 › Ordering Mistakes
Problem: Integer-only ordering
Using Order in Layer as the only system leads to lots of manual tracking and fragile numbering when many assets are added.
Fix: Use Sorting Layers for categories and keep integers small and local.
Problem: Mixing z-position and sorting
Using z-axis position to influence draw order conflicts with the intended 2D renderer and makes behavior inconsistent across cameras and renderers.
Fix: Keep ordering in Sorting Layers and Order in Layer, reserve z-position for real depth when using specialized renderers that rely on world coordinates.
Key Takeaway

Consistency prevents surprises. Establish a small, clear sorting scheme early and apply it project-wide.
