Animator Controller role
Contains animation states, transitions, and parameters. Acts as a state machine to pick which clip plays based on runtime values.
Example parameter
Create a float parameter 'Speed' and transition between Idle and Walk based on a threshold value.
Script control
You can trigger animations from C# by setting parameters or calling animator.Play with the clip name to force playback in response to gameplay events.
Common misconception
Thinking the Animation window alone runs logic. The Animator plus scripting allow interactive, conditional behavior.
Key Takeaway

Design controllers with clear parameters or call animator methods from scripts to coordinate animations with gameplay.
