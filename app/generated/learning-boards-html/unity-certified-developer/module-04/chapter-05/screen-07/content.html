Sorting Layers
Create named layers like Background, Player, Foreground via Project Settings. Layers define coarse ordering across the scene and make intent explicit.
When to use
  • Group elements by role (background, player, UI).
  • Ensure consistent layering across many objects.
Order in Layer
An integer used to sort sprites inside the same Sorting Layer. Use small ranges to adjust visual overlap for objects that share a layer.
Example
Two Player sprites on Player layer: set Order in Layer 0 and 1 to place one in front of the other while keeping both above Background.
Key Takeaway

Use Sorting Layers for broad categories and Order in Layer for local ordering; avoid using only integers for large projects.
