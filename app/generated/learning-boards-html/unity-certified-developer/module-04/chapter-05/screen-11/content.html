Module 4 › Chapter 4.5 › Sprite Atlas
When to use a Sprite Atlas
  • Many small UI icons shown together.
  • Multiple frames used by the same character or object.
  • Mobile or constrained GPU environments where draw calls matter.
Create via Create > Sprite Atlas and add related sprites to Objects for Packing; use Pack Preview to inspect the atlas layout.
Concrete example
Pack a folder of player frames and weapons used in the same scene into a PlayerAtlas. Unity will use the atlas to render those sprites, reducing draw calls when both appear together.
Common misconception
Assuming atlases always reduce memory; they can increase texture memory but reduce CPU/GPU overhead from draw calls.
Key Takeaway

Use Sprite Atlases for grouped assets that render together to improve rendering performance; monitor VRAM and pack thoughtfully.
