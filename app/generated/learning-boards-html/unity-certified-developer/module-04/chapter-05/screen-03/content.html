This progression guides how you practice: start by setting import options, then slice assets, then place and order them in a scene, and finally produce an animation and consider a Sprite Atlas for optimization.
Verification
Import: Texture Type set to Sprite (2D and UI) and Sprite Mode set appropriately.
Slice: Individual sprites appear nested under the asset after clicking Apply in Sprite Editor.
Scene: GameObject with SpriteRenderer shows the sprite and respects Sorting Layer.
Animation: A clip plays and the Animator Controller contains your clip.
