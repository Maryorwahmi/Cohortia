Inspector: SpriteRenderer properties
  • Sprite: choose the current sprite frame.
  • Color: multiply the sprite pixels to tint.
  • Flip X / Flip Y: mirror the image horizontally or vertically.
  • Sorting Layer & Order in Layer: control draw order.
Note
Use Transform for position and other components for physics or collision; keep responsibilities separated.
Concrete steps
Drag a sliced sprite into Scene → Unity creates a GameObject with SpriteRenderer → rename to Player → set Sorting Layer to Player → adjust Color or flip as needed.
Check your understanding
If the sprite isn't visible, verify the GameObject's Transform position, camera view, and Sorting Layer assignment.
Key Takeaway

Create visual objects via drag-and-drop and use SpriteRenderer settings to control how they appear without changing asset files.
