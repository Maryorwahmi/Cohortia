Module 4 › Chapter 4.5 › 2D Animation
Timeline: Quick steps
1. Select GameObject
2. Window → Animation → Create clip
3. Drag sprites into Dopesheet
4. Adjust Samples and save
Concrete Example
Create Player_Walk clip, drag four walk frames into the Dopesheet, set Samples to 12, and play the scene to confirm a smooth loop.
Common misconception
Assuming the Animator is optional; Unity automatically creates an Animator and controller when you make a clip, and controlling clips at runtime requires the Animator component.
Key Takeaway

Use the Animation window to sequence frame sprites; the resulting Animator allows runtime control and switching between clips.
