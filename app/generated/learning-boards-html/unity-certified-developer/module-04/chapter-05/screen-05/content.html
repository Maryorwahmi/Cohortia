Module 4 › Chapter 4.5 › Slicing Sprite Sheets
Step-by-step
  1. Select the sprite sheet in Project window.
  2. Set Texture Type to Sprite and Sprite Mode to Multiple, then Apply.
  3. Open Sprite Editor and choose Slice.
  4. Pick Automatic, Grid By Cell Size, or Grid By Cell Count; adjust values.
  5. Click Apply and expand the asset to view slices.
Check
Verify that each expected frame appears under the original asset and can be dragged into the scene individually.
Concrete Example
Given a 128x32 sprite strip with four 32x32 frames, use Grid By Cell Size with 32x32. Slice, Apply, then confirm four sliced sprites appear.
Common mistake
Forgetting to set Sprite Mode to Multiple will keep the sheet as one sprite and prevent slicing.
Key Takeaway

Match the slicing method to your sheet layout to produce clean, ready-to-use frames for animation.
