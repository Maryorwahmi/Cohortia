Module 4 › Chapter 4.5 › Learning Objectives
01
Import & Configure Sprites
Set Texture Type to Sprite and Sprite Mode to Multiple when needed.
You will practice setting Texture Type and Sprite Mode in the Inspector and see why incorrect settings break the pipeline. Mnemonic: think "Sprite = 2D".
VERIFIED COMPETENCY MILESTONE
02
Slice Sprite Sheets
Use the Sprite Editor to slice by grid or automatically.
You'll learn grid cell sizes and automatic slicing. Mnemonic: think of the sheet as a grid of stamps you cut out.
VERIFIED COMPETENCY MILESTONE
03
Render with SpriteRenderer
Display sprites and adjust color, flip, and ordering.
You will create a GameObject from a sprite and inspect the SpriteRenderer properties. Mnemonic: renderer equals visible image.
VERIFIED COMPETENCY MILESTONE
04
Sorting & Animate
Use Sorting Layers and the Animation window to animate sprites.
You'll define Sorting Layers and make a short walk clip. Mnemonic: layers stack like paper stacks.
VERIFIED COMPETENCY MILESTONE
