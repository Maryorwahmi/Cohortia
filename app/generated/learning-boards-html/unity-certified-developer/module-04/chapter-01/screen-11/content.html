Commit everything Unity needs
Small files can have large impact on project integrity.
Rule
Always include .meta files in commits and avoid moving assets using the OS. Use the Editor to move or rename to keep GUIDs stable.
Git tips
Keep Assets/** and ProjectSettings/** under source control; exclude only OS or user-specific temp files in .gitignore.
Example
A prefab added by one developer references a material. If the material's .meta wasn't committed, the prefab will show missing references for other team members.
Key Takeaway
Treat .meta files as integral to assets. Including them in VCS prevents broken references and saves debugging time.
