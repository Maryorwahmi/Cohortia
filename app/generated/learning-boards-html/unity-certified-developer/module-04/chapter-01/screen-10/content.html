Model import architecture
Decisions that affect rendering and physics.
Scale Factor
Match model units to your scene to avoid non-uniform scaling later.
Colliders & Mesh Compression
Auto-generate colliders for simple geometry; prefer simplified colliders for complex shapes. Use mesh compression where detail loss is acceptable.
Lightmap UVs
Generate second UVs for objects participating in baked lighting to improve bake results.
Concrete scenario
An environment building: scale set correctly, lightmap UVs generated, mesh compression low, colliders simplified to boxes for physics performance.
Key Takeaway
Choose model settings based on whether the asset is static or dynamic, near or distant, and how it will be used in physics and lighting.
