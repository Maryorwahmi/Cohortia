Inspector checklist for audio
Decide based on clip length and how frequently it plays.
Load Type
Streaming for long music, Decompress On Load for short SFX, Compressed In Memory when you need lower memory but can accept decompression cost on playback.
Compression Format
Use compressed formats like Vorbis to lower disk size. Choose compression quality that balances size and audible fidelity.
Example
Short SFX: Vorbis compression, Decompress On Load. Background music: Vorbis, Streaming. This reduces memory use and keeps playback responsive.
Key Takeaway
Pick load type by clip length and playback needs. Compress to save disk and build size, but test latency on target hardware.
