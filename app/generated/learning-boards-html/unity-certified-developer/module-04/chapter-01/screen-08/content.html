Inspector steps for PNG
Follow these settings based on use case.
  1. Texture Type: choose Sprite for UI or Default for in-world textures.
  2. Max Size: reduce to the smallest acceptable size for the target display.
  3. Compression: pick a quality vs size trade-off suitable for the platform.
  4. Normal Map flag: mark if the texture is a normal map so lighting is correct.
  5. Apply and test: always verify visual quality and memory impact in a running scene.
Concrete example
UI button icon: Texture Type = Sprite, Max Size = 256, Compression = high. This preserves clarity and keeps memory low for many icons.
Key Takeaway
Match size and compression to the asset role. Avoid keeping unneeded full-resolution textures in the build.
