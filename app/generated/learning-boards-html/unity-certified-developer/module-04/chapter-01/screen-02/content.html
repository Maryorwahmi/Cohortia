Learning Objectives

Practical skills you'll demonstrate in this chapter
Bloom: Learn → Understand → Apply → Master
01
Explain the Asset Pipeline
Describe how Unity processes imported files, converts formats, and generates metadata. This matters because processing affects performance and references.
VERIFIED COMPETENCY MILESTONE
02
Identify asset types
Recognize textures, models, audio, prefabs, scenes, and scripts to apply appropriate import settings and optimization strategies.
VERIFIED COMPETENCY MILESTONE
03
Organize the Project window
Create and maintain a consistent folder hierarchy by type or by feature to avoid messy roots and speed collaboration.
VERIFIED COMPETENCY MILESTONE
04
Manage .meta files and import settings
Inspect .meta files, keep them in version control, and tune import settings like compression and load types to control build size and memory use.
VERIFIED COMPETENCY MILESTONE
