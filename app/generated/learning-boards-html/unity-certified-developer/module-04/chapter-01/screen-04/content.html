Module 4 › Chapter 4.1 › What is the Asset Pipeline?
Definition and role
How Unity converts source files into engine-ready data.
Process steps
  • Detect file in Assets folder and determine type.
  • Run importers that convert/compress the file and generate runtime assets.
  • Create a .meta file storing GUID and import settings.
  • Cache processed data optimized for the target platform.
Example
A PNG imported as a Sprite will be resized, compressed, and presented to the engine as a GPU texture configured for UI rendering.
Common mistake
Deleting .meta files or moving files outside Unity breaks GUID references, causing scenes and prefabs to lose links.
Visual summary
Incoming file
Source types: .png, .fbx, .wav, .cs, .prefab, .unity
Processing
Importer converts, compresses, and bakes the asset for runtime needs.
Key Takeaway

Treat import and metadata as part of your development process — they determine runtime behavior and reference stability.
