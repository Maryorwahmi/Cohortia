Module 4 › Chapter 4.1 › Activity: Import & Inspect
Step-by-step activity
Follow this checklist to practice imports and metadata inspection.
1. Create folders
Scenes, Scripts, Models/Props, Materials, Textures, Audio, Prefabs.
2. Import files
Drag a PNG to Textures and a WAV/MP3 to Audio; wait for import to finish.
3. Tune settings
Set Texture Type, Max Size, Audio Load Type, and Compression Format.
4. Inspect .meta
Open the OS explorer and confirm .meta files appear beside the imported assets.
5. Reflect
Why did you pick these settings? How do they affect memory and build size?
Key Takeaway

Practice the import flow now so it becomes a habit: create structure, import, tune, inspect .meta, and commit everything to version control.
