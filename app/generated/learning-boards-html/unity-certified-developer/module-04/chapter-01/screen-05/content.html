Type-by-type checklist
Textures
Check Texture Type (Sprite vs Default), Max Size, and Compression. Use Sprite for UI and reduce max size for icons.
Audio
Set Load Type (Streaming, Decompress On Load), Compression Format (Vorbis recommended for music). Avoid uncompressed large WAVs for short SFX.
Models
Adjust Scale Factor, generate colliders and lightmap UVs, and consider mesh compression for static props.
Comparison: Common mistakes vs good practice
Wrong
Import everything uncompressed and use defaults; leads to big builds and high memory use.
Right
Choose compression and load type based on asset role: streaming for long music, compressed for texture atlases, appropriate mesh compression for static geometry.
Example
A short walking sound should be compressed and likely set to Decompress On Load — this keeps playback responsive without bloating memory.
Key Takeaway

Match import settings to intended use. Inspect textures, audio, and model options immediately after import to avoid costly changes later.
