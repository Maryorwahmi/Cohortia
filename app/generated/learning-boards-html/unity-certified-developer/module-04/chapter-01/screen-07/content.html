What .meta files store
Import settings, GUID, and internal references used by Unity Editor and engine.
Important fields
  • GUID — unique identifier used internally to reference the asset.
  • Inspector import settings — compression, type, scale, etc.
  • Other engine-specific flags used during build and runtime.
Common mistake
Not committing .meta files or moving assets outside the Editor will change GUIDs and break references in scenes and prefabs.
Example
A model's .meta stores whether colliders are generated and which materials are assigned; losing it can reset those choices.
Version control rule
Always include .meta files in commits. They are small but critical for keeping references consistent across machines.
Key Takeaway
.meta files contain GUIDs. Preserve them and use the Editor to move assets so references remain stable for all collaborators.
