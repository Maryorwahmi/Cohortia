Hands-on Activity
StreamingAssets Workflow & Local Testing
Practical steps to validate your loader without a network.
  1. Build bundles into Assets/AssetBundles using your editor script.
  2. Copy the bundle files and their .manifest files into Assets/StreamingAssets.
  3. Attach your AssetBundleLoader to a GameObject and set bundle and asset names in the Inspector.
  4. Play the scene and verify instantiation and console logs; check the Profiler for memory changes.
Automation tip
Add a post-build step to copy bundles into StreamingAssets automatically to avoid manual mistakes.
Common mistakes & fixes
Forgetting manifests or leaving stale files leads to load failures. Clear StreamingAssets before copying new bundles, and verify file names match the bundleName used by your loader.
Check
Confirm Application.streamingAssetsPath combined with your bundle name points to an existing file at runtime when testing.
Profiler step
Record a session before and after load/unload to verify native memory and managed memory trends match expectations.
