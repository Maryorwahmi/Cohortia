Learning Objectives
Learn the practical skills to use Asset Bundles and manage runtime memory.
01
Explain purpose & benefits
Describe how bundles reduce build size and enable on-demand delivery. Knowing this helps you choose the right strategy for scaling content.
VERIFIED COMPETENCY MILESTONE
02
Create & configure bundles
Assign names in the Inspector and prepare an output path for BuildAssetBundles. This is the step that turns assets into runtime packages.
VERIFIED COMPETENCY MILESTONE
03
Write runtime loaders
Implement LoadFromFileAsync or UnityWebRequest.GetAssetBundle and use LoadAssetAsync to instantiate content safely during play.
VERIFIED COMPETENCY MILESTONE
04
Memory management practices
Learn when to call Unload(false) vs Unload(true), destroy instantiated objects, and use Resources.UnloadUnusedAssets to reclaim memory.
VERIFIED COMPETENCY MILESTONE
