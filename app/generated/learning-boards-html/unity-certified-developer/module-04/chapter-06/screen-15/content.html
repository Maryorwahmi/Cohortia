Module 5 › Chapter 4.6 › Key Concepts
Unload semantics
Pick Unload(false) to keep instanced objects, Unload(true) to remove all assets but only when safe.
StreamingAssets
Use it to store built bundles for local file-based testing with LoadFromFileAsync.
Profiler validation
Confirm that memory counters drop after destruction and unload to ensure no leaks remain.
Final takeaway

Adopt a repeatable build-and-test routine: build bundles, copy to StreamingAssets, test loaders, destroy instances, unload, and verify with the Profiler.
