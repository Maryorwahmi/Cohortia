Comparison
Asset Bundles vs Resources Folder
Understand trade-offs for build size and unload behavior.
Resources folder
Assets inside Resources are always included in the build and accessible via Resources.Load, but they are hard to unload selectively and increase build size.
Asset Bundles
Bundles are built into separate files that you load and unload explicitly, enabling on-demand delivery and better memory control.
Misconception
Resources is not a lightweight shortcut for large projects; it increases bundle size and makes memory management difficult.
Decision guide
Use Resources for tiny, global, frequently used assets. Use Asset Bundles for optional content, platform-specific assets, or downloadable DLC. If you need precise memory control, bundles are the correct choice.
Practical example
A UI sprite used everywhere might live in Resources. Large environment packs should be bundles to avoid shipping them by default.
