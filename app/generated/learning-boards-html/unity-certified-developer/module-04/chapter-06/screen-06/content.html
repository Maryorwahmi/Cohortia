BuildAssetBundles Editor Script
A small Editor script compiles named assignments into bundle files.
Place the script inside an Editor folder and run the menu command. The script creates an output folder if missing and calls BuildPipeline.BuildAssetBundles with the active build target so the bundles match the platform you intend to run.
Practical tip
Add logging and verify the output folder contains a .manifest file for each bundle to ensure a successful build.
Example Editor Script
using UnityEditor;
using System.IO;

public class BuildAssetBundles
{
    [MenuItem("Assets/Build AssetBundles")]
    static void BuildAllAssetBundles()
    {
        string assetBundleDirectory = "Assets/AssetBundles";
        if (!Directory.Exists(assetBundleDirectory))
        {
            Directory.CreateDirectory(assetBundleDirectory);
        }
        BuildPipeline.BuildAssetBundles(assetBundleDirectory,
                                        BuildAssetBundleOptions.None,
                                        EditorUserBuildSettings.activeBuildTarget);
    }
}
This simple script shows the essential elements. It is common to expand this with options for compression or per-platform folders. Always verify you build using the correct active build target.
Common mistake
Not building for the target platform leads to incompatible bundles and runtime load failures on the device.
