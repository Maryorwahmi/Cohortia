Process Flow
Assigning Assets to Bundles
Steps to reliably group and name assets.
  1. Select asset or folder in the Project window.
  2. Open the Inspector and locate the Asset Bundle dropdown.
  3. Choose an existing bundle or select New... and enter a clear name.
  4. Group related files (textures, prefabs, audio) under one bundle when they will be used together.
  5. Review assignments before building bundles to avoid omissions or excessive fragmentation.
Example
A RedCubePrefab and its material both assigned to 'mycubeassets' ensures the prefab can be instantiated at runtime with correct visuals.
Naming & Grouping Guidance
Good names make builds and debugging straightforward. Prefer logical categories and optional qualifiers like platform or DLC id.
When to group
If assets are always used together—pack them into one bundle to simplify loading.
When to separate
Separate optional or large assets that may be downloaded independently, like DLC skins or big audio packs.
Common mistake
Naming assets but never running the build script means no bundle files are generated; the assignment alone does nothing at runtime.
