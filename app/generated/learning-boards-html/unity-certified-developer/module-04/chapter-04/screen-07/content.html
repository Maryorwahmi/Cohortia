What anchors do

Anchors set how a child’s rectangle relates to its parent. They can be fixed corners or a stretch that scales with parent size.

Common presets
Top-Left, Stretch-Left-Right, Center, Full Stretch
Example
Set a health bar to stretch horizontally by anchoring left and right and setting left/right offsets to zero. The fill Image then adjusts width as the parent changes.
Pivot explained
Pivot is the local point for rotation and scaling, expressed in normalized coordinates. Use pivot to control the origin of animations and scale transitions.
Debug checklist
  • Inspect anchor presets in the Rect Transform tool.
  • Check offsets and width/height are intended values.
  • Play and resize Game view to validate behavior.
