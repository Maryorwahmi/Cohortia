Health bar setup
  1. Create Background Image and set anchors to Top-Right.
  2. Parent a Fill Image and set anchors to stretch inside parent.
  3. Set Fill Image Type to Filled and Fill Method to Horizontal.
  4. Control fillAmount in script from 0 to 1.
Concrete example

HealthBar_Fill.fillAmount = currentHealth; where currentHealth is normalized between 0 and 1. This avoids distortions and respects sprite slicing.

Key Takeaway

Use Filled Image for progress indicators; anchors must make the fill cover the parent properly.
