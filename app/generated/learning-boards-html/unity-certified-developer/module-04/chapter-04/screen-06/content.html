Module 4 › Chapter 4.4 › Create UI Elements
Quick process
1. Add Canvas + EventSystem
2. Add Text (TMP)
3. Add Image / HealthBar
4. Add Button / Slider
Concrete example

Create Text - TextMeshPro, rename to ScoreText, set anchors to Top-Left, Pos X 10, Pos Y -10, Width 200, Height 50. Set text to Score: 0 and Font Size to 36. This keeps the score visible across window sizes.

Use Filled Image for bars
Import TMP Essentials when prompted
Common mistake
Forgetting to set anchors correctly so elements snap to a corner or stretch as expected. Also forget to assign public fields in scripts, causing null reference errors at runtime.
Key Takeaway

Follow the add-configure-test cycle for reliable UI creation.
