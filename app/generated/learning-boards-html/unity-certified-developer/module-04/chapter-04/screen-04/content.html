What is the Canvas?

A Canvas is the GameObject that all UI elements must be children of. It controls rendering space and interacts with a Canvas Scaler when set to scale with screen size.

  • Creates drawing surface for UI elements.
  • Works with Canvas Scaler to adapt to resolutions.
  • Can be set to Overlay, Camera, or World Space render modes.
Key Takeaway

No Canvas, no UI rendering. Confirm Canvas existence before debugging missing UI.

EventSystem role

EventSystem receives input and forwards it to selectable UI components. Without it, OnClick and drag events do not reach targets.

EventSystem exists
Concrete example
Create GameObject→UI→Button. Unity adds Canvas and EventSystem automatically. The Button receives clicks via the EventSystem and renders inside the Canvas bounds.
Common mistake: assuming the EventSystem will appear in a prefab or under a different scene root. Always check the Hierarchy when input doesn’t register.
