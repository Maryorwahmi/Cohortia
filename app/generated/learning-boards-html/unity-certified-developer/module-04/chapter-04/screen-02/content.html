Learning Objectives

Skill goals aligned to practice and assessment
Bloom: Learn → Understand → Apply → Master
01
Explain Canvas & EventSystem
Describe the Canvas and EventSystem and how they enable UI rendering and input. This understanding ensures correct scene setup and predictable input handling.
VERIFIED COMPETENCY MILESTONE
02
Create common UI elements
Add and configure TextMeshPro, Image, Button, and Slider elements so they present data and accept input reliably in a scene.
VERIFIED COMPETENCY MILESTONE
03
Master Rect Transform
Use anchors and pivot to make UI respond across resolutions and avoid elements drifting off-screen during gameplay.
VERIFIED COMPETENCY MILESTONE
04
Hook UI to scripts
Write simple C# listeners for OnClick and OnValueChanged and assign references in the Inspector to make UI interactive.
VERIFIED COMPETENCY MILESTONE
