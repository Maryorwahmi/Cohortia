Module 4 › Chapter 4.4 › Debugging UI
Quick checklist
  • Canvas & EventSystem present?
  • Inspector references assigned?
  • Anchors/pivots set correctly?
  • Correct Canvas render mode for the use case?
  • TMP Essentials imported?
Concrete scenario

If clicking a button does nothing: confirm EventSystem and Standalone Input Module exist, check the target method is public and assigned, and inspect the Console for null reference messages that point to unassigned fields.

Common mistake

Relying on Find calls in Update is fragile and inefficient. Assign references in the Inspector or cache them in Start.

Testing tip

Resize the Game view in Play while watching Rect Transform values change. Observing offsets and anchor movement in real time quickly reveals layout issues.
