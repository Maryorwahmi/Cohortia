Module 4 › Chapter 4.4 › Key Concepts
Canvas & EventSystem
Canvas renders UI; EventSystem forwards input. Both are required for interactive UI.
Render Modes
Overlay for HUDs, Camera for camera-tied UI, World Space for in-world panels.
Anchors & Pivot
Anchor presets and pivot points control responsive behaviour and scaling origin.
Summary Takeaway

Choose render mode deliberately, set anchors and pivots intentionally, and wire UI to scripts with assigned references for reliable, testable interfaces.
