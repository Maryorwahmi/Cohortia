Why TMP?

TextMeshPro produces crisper text, supports rich text, and improves layout control. It handles quality at small font sizes better than legacy UI Text.

Setup example

Create UI→Text - TextMeshPro. Rename ScoreText. Set anchors to Top-Left. Pos X 10, Pos Y -10. Font Size 36. Align left.

Code reference (visual)
using TMPro;

public class ExampleUI : MonoBehaviour
{
    public TextMeshProUGUI scoreText;

    void UpdateScore(int score)
    {
        if (scoreText != null)
            scoreText.text = "Score: " + score.ToString();
    }
}
Visual only: in Unity assign ScoreText in the Inspector. Do not forget this step to avoid null references.
