Hands-on Activity › Main Menu
Step-by-step
  1. Create Canvas and set Canvas Scaler to Scale With Screen Size, Reference 1920x1080, Match 0.5.
  2. Add Image child, set anchors to stretch and offsets to zero for full-screen background.
  3. Add Text - TextMeshPro named TitleText, anchors Top-Center, Pos Y -100, Width 800, Height 150.
  4. Add Button - TextMeshPro named PlayButton, anchors Center-Center, Pos Y -100, Width 200, Height 60.
  5. Test in Game view at multiple resolutions and confirm placement and scaling.
Example checklist
Canvas exists, Scaler set, Background stretches, Title anchored Top-Center, Play Button anchored Center-Center, TextMeshPro imported.
Troubleshoot
If text or buttons shift, re-check anchors and ensure the PlayButton label is a child of the Button object.
Key Takeaway

Follow the steps and validate in multiple Game view resolutions to build a robust main menu quickly.
