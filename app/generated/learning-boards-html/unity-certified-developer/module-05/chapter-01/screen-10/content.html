Comparison › Canvas Scaler Modes
Constant Pixel Size
Elements keep exact pixel dimensions. Good for fixed-resolution or pixel-art projects but risky for multi-resolution targets.
Scale With Screen Size
Scales UI based on Reference Resolution. Use Match Width Or Height to prioritize an axis and keep proportions consistent.
Concrete test
Set Reference Resolution to 1920x1080 and Match slider to 0.5. Resize the Game view to 1280x720 and 1024x768 to compare scaling behavior.
Common mistake
Not configuring Canvas Scaler early forces later rework of positions, sizes, and text readability when supporting multiple resolutions.
Key Takeaway

Set Scale With Screen Size and a practical reference resolution early to avoid layout surprises across devices.
