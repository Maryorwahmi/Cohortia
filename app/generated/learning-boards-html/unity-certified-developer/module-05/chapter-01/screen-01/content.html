Introduction to Unity UI (uGUI)
Build responsive menus and HUDs by understanding Canvas modes, Rect Transform, Anchors, Pivots, and Canvas Scaler.
In this lesson
Learn how the Canvas renders UI, why Rect Transform matters for 2D layout, and how anchors and pivots control responsiveness.
Why it matters
A solid UI foundation prevents layout breakage across resolutions and saves time when iterating on menus or HUD elements.
Explore Key Topics
Canvas
The drawing surface and render mode for UI elements.
Rect Transform
Position, anchors, size, and pivot for UI geometry.
Canvas Scaler
Controls how UI scales with resolution.
Concept snapshot
Canvas Render Modes
Overlay, Camera, World Space — choose based on whether UI should be screen-fixed or part of the world.
Responsive rule
Use Anchors and Canvas Scaler (Scale With Screen Size) to keep layouts consistent across resolutions.
