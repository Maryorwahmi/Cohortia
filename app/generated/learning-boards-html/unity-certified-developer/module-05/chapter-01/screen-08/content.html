Process › Image & Button
Adding an Image
Right-click Canvas → UI → Image. Drag a sprite into Source Image. Use stretch anchors for full-screen backgrounds with zero offsets.
Creating a Button
Right-click Canvas → UI → Button - TextMeshPro. Ensure the TextMeshPro label is a child of the button and assign a sprite or color to the Image component.
Concrete example
PlayButton: Anchor Center-Center, Pos Y -100, Width 200, Height 60, child text "Play Game". Assign a rounded sprite to the Image for better visuals.
Common mistake
Putting the label outside the button's hierarchy or forgetting the button Image sprite makes the button invisible or non-interactive.
Key Takeaway

Buttons require both an Image background and a properly nested label; anchors determine placement and stretching.
