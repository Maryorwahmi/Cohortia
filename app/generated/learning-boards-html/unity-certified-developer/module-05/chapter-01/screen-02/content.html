Module 05 › Chapter 5.1 › Learning Objectives
01
Configure Canvas
Choose render mode and create a stable drawing surface for UI.
Understand Overlay vs Camera vs World Space and why Overlay is typically easiest for menus. Visual mnemonic: three stacked layers icon representing modes.
Verified competency milestone
02
Create UI elements
Add TextMeshPro, Image, and Button with correct components and assets.
Practice: import TextMeshPro essentials, add a TextMeshPro title, and assign a sprite to an Image. This produces reliable, high-quality text and visuals.
Verified competency milestone
03
Master Anchors & Pivots
Pin elements to corners, edges, or stretch them across parents for responsive layouts.
Mnemonic: think of anchors as table clamps and pivot as the rotation hinge point. Test by snapping a health bar to top-left and resizing the Game view.
Verified competency milestone
04
Implement responsive layout
Set Canvas Scaler to Scale With Screen Size and choose a reference resolution.
Practical tip: set Reference Resolution to your target resolution, and use Match Width Or Height to prioritize which axis scales first.
Verified competency milestone
