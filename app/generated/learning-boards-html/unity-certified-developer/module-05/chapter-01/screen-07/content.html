Process › Text & TextMeshPro
Steps to add high-quality UI text
  1. Right-click Hierarchy → UI → Text - TextMeshPro and import essentials when prompted.
  2. Set Anchor preset to Top-Center for titles and adjust Pos Y to position vertically.
  3. Set Width and Height in Rect Transform to control wrapping and alignment.
  4. Adjust font size, color, and alignment in the Inspector; prefer TextMeshPro for clarity across scales.
Concrete example
Create TitleText, anchors Top-Center, Pos Y -100, Width 800, Height 150. Set text to "My Awesome Game" and check in 1920x1080 and 1280x720 Game views.
Misconception
Relying on legacy UI Text causes blurry scaling. Use TextMeshPro and Canvas Scaler instead.
Key Takeaway

Import TextMeshPro essentials, anchor titles appropriately, and confirm readability across resolutions.
