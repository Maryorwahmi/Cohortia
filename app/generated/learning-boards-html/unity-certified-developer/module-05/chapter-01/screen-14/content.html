Summary › Key Concepts
Canvas
Surface that renders all UI; pick the proper render mode for your use case.
Rect Transform
Defines rectangle, anchors, offsets, and pivot for UI layout and behavior.
Canvas Scaler
Use Scale With Screen Size and a reasonable reference resolution for responsive UI.
Final takeaway
Focus on these three areas while building UI: Canvas mode, anchors/pivot on Rect Transform, and Canvas Scaler configuration. Test early and often in the Game view to catch layout issues before they become expensive to fix.
