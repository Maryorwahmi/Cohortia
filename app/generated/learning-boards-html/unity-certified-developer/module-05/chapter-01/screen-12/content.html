Common Pitfalls › Fixes
Missing TextMeshPro assets
Import essentials when prompted to avoid missing fonts and warnings.
Wrong Canvas Scaler
Switch to Scale With Screen Size and set a Reference Resolution to maintain proportional UI across devices.
Incorrect anchors
Set anchors to corners or stretch presets rather than leaving center anchors after repositioning elements.
Quick diagnostic
Canvas exists → Canvas Scaler mode → Anchors and offsets → Hierarchy draw order → Test resolutions. This sequence finds most UI problems quickly.
