Canvas and render modes
The Canvas controls how child UI is drawn and interacts with cameras or the world.
Screen Space - Overlay
Renders UI on top of the scene. Use for menus and HUDs; scales with Canvas Scaler.
Screen Space - Camera
Renders through a camera. Useful for applying camera effects to UI or matching perspective.
World Space
Makes UI a 3D object in the scene. Good for in-world panels and indicators.
Example
A pause menu uses Screen Space - Overlay so it always appears above game content regardless of camera position.
Common mistake
Adding world UI but leaving Canvas in Overlay means your UI will not behave like a 3D object. Always verify Canvas mode after creating UI elements.
Key Takeaway

Choose Canvas render mode based on whether UI should be screen-fixed or part of the game world.
