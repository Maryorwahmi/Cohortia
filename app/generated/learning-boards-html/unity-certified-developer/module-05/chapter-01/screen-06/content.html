Process Flow › Anchors & Pivots
Workflow
  1. Choose anchor preset. Corner, edge, or stretch expresses layout intent.
  2. Set offsets. Use Pos or Left/Right/Top/Bottom to apply margins relative to anchors.
  3. Adjust pivot. Decide how the element will rotate or scale by picking its pivot point.
  4. Test. Resize the Game view to confirm behavior across resolutions.
Concrete example
To pin a menu button to bottom-right, set both Anchor Min and Anchor Max to (1,0), then set Pos X to -50 and Pos Y to 50 so it offsets inward from the corner.
Common mistake
Moving elements while anchors remain centered. This causes elements to shift unexpectedly when the parent changes size.
Key Takeaway

Set anchors first to express relationship, then use offsets; pivot controls rotation and scale origin.
