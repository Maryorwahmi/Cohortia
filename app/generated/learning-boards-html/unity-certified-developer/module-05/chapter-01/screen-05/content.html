Rect Transform properties
Keys: Width, Height, Anchor Min/Max, Left/Right/Top/Bottom offsets, and Pivot.
Anchors
Define reference points on the parent. Use corners or stretch presets to control how a child resizes.
Offsets
Left/Right/Top/Bottom are margins that take effect once anchors are set.
Pivot
Normalized point inside the rectangle used as the rotation and scale origin.
Quick exercise
Create an Image, set anchors to Top-Left, then resize the Game view. Observe how Pos X, Pos Y, and offsets change while the element stays in the corner.
Misconception
Treating Rect Transform like a regular Transform. Remember it encodes layout relationships not only a position vector.
Key Takeaway

Use anchors to declare layout behavior and offsets for margins; pivot affects rotation and scaling origin.
