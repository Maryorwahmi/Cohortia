Hierarchy › Draw Order & Groups
Draw order behavior
Siblings later in the Hierarchy render on top of earlier siblings. Use this to ensure labels appear above images.
Grouping strategy
Group related elements under an empty parent to share anchors and transforms. Example: MainMenuPanel or PlayerHUD.
Concrete example
Place Background Image, then TitleText, then PlayButton in that order. The PlayButton will render on top if it appears later in the Hierarchy.
Tip
Use parent panels to move or animate multiple UI elements together rather than adjusting each child individually.
Key Takeaway

Hierarchy order controls rendering; group UI logically to simplify layout adjustments and scaling.
