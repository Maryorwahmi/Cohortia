Process › Responsive Layouts
Iteration workflow
  1. Group related UI into parent panels and set anchors for the panel.
  2. Set Canvas Scaler to Scale With Screen Size with a Reference Resolution.
  3. Test in the Game view at multiple resolutions and aspect ratios.
  4. Adjust anchors, offsets, and panel organization until behavior is stable.
Concrete example
PlayerHUD anchored to top, health bar anchored left in the panel, score anchored right. Changing resolution keeps elements in place because the panel keeps its anchor relationship.
Testing tip
Use at least three resolutions: reference, a narrower width, and a taller height. This quickly reveals anchor and scaling problems.
Key Takeaway

Design by panels and test iteratively; anchors plus Canvas Scaler are your main tools for responsive UI.
