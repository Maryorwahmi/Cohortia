Hands-on Activity
Create a responsive main menu
  • Set Canvas Scaler to Scale With Screen Size with Reference 1920x1080.
  • Add an Image child stretched to full screen for background.
  • Add a TextMeshPro title anchored Top-Center and a Play Button anchored Center-Center.
Common pitfalls
Forgetting to configure anchors, using legacy UI Text, or leaving Canvas Scaler on Constant Pixel Size often breaks layout across resolutions.
Misconception
Assuming center anchors work for every layout. In reality, corner or stretch anchors are usually required for predictable behavior.
Verification checklist
Canvas exists
Canvas Scaler set
Anchors validated
