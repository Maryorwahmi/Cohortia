Definition

Inspector signature constraints

UI events expose a controlled set of method signatures. Design handler methods to match or adapt to these signatures.

Examples
  • Button.OnClick → public void StartGame()
  • Toggle.OnValueChanged(Boolean) → public void SetMusicEnabled(bool isOn)
  • Slider.OnValueChanged(Single) → public void SetVolume(float value)
  • InputField.OnEndEdit(String) → public void OnPlayerNameEntered(string name)
Misconception
Not all method types are available in the Inspector; static or private methods won't appear.
Adapter pattern

When your game logic needs more arguments or complex state, expose a simple public adapter method for inspector wiring and delegate to richer internal methods.

public void ApplySettings()
{
    // adapter that reads fields and calls complex logic
    ApplySettingsInternal(currentQuality, currentVolume, playerName);
}
Key Takeaway
Keep inspector-exposed methods simple; use adapters to call richer logic within your codebase.
