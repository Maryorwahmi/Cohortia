Core Concept

Toggle state and events

Toggles fire On Value Changed(Boolean) with the new state. Use it to toggle game options and keep UI state synchronized.

Practical example
Implement SetMusicEnabled(bool isEnabled) to set AudioListener.pause = !isEnabled and update status text. Initialize toggle.isOn = !AudioListener.pause in Start so visuals match audio state on load.
Common mistake
Not initializing the toggle to match saved game state, causing confusing toggles that don't reflect actual behavior.
Toggle Group quick guide
Add a Toggle Group component to a parent GameObject and assign each Toggle's Group property so only one in the group is active at a time, useful for difficulty settings or mutually exclusive options.
Key Takeaway
Use toggles for booleans and Toggle Group for radio-like choices; always initialize their state from current settings.
