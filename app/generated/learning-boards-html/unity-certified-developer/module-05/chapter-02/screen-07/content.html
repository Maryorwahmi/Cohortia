Process Flow

Configure and initialize Slider

1. Set Min/Max
Choose a range that matches your parameter semantics, e.g., 0 to 1 for audio.
2. Choose Whole Numbers
Enable for discrete steps like levels; keep floats for fine control.
3. Wire OnValueChanged
Bind to a public void SetVolume(float) or add a listener in code.
4. Initialize value in Start
Set slider.value to the current game setting to avoid mismatch.
Concrete example
public void Start()
{
    if (volumeSlider != null)
    {
        volumeSlider.onValueChanged.AddListener(SetVolume);
        volumeSlider.value = AudioListener.volume; // sync at start
    }
}

public void SetVolume(float volume)
{
    AudioListener.volume = volume;
    // update UI percent label: (volume * 100).ToString("F0") + "%"
}
Key Takeaway
Sliders must be initialized and have appropriate ranges; decide precision based on UX expectations.
