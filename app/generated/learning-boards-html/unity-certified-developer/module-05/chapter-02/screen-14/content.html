Module 5 › Chapter 5.2 › Key Concepts
Button
Triggers public void methods through OnClick or AddListener for dynamic UI.
Toggle
Represents a boolean; use Toggle Group for exclusive selections.
Slider
Continuous input; set range and initialize value from game settings.
Input Field
Use On Value Changed for live validation and On End Edit for commits; validate in code.
AddListener / RemoveListener
Attach in Start and remove in OnDestroy to avoid leaked callbacks.
Validation & Init
Always validate input and initialize UI from saved or current game state to avoid surprises.
Final takeaway
Consistent wiring, initialization, validation, and listener cleanup make interactive UI predictable and reliable.
