Validation Patterns

Filter and sanitize input to avoid invalid characters, enforce length, and present helpful feedback to players.

  • Use On Value Changed to remove invalid characters in real time for names.
  • Trim and validate again on On End Edit before saving to PlayerPrefs.
  • For sensitive data, use Password content type and treat it carefully in code.
Example rule
public void OnPlayerNameEntered(string name)
{
    if (string.IsNullOrWhiteSpace(name)) name = "Guest";
    PlayerPrefs.SetString("PlayerName", name);
}
UX tip
Provide clear error messages or auto-correction to help players fix invalid input rather than silently changing it.
