Module 5 › Chapter 5.2 › Inspector vs Programmatic
Inspector Wiring
  • Easy visual mapping for static UI and designer workflows.
  • Requires public void method signatures.
  • Less flexible for runtime-generated elements.
Programmatic Listeners
  • AddListener/RemoveListener gives precise lifecycle control.
  • Essential for dynamic menus, prefab instantiation, and conditional behavior.
  • Prefer named handlers to ensure RemoveListener works correctly.
Hybrid recommendation
Use Inspector wiring for stable root UI and AddListener for elements created or modified at runtime. This balances clarity and control.
