Module 5 › Chapter 5.2 › Hands-on Activity
Activity steps
1. Create OptionsPanel
Canvas → create child GameObject OptionsPanel, set size 400x300, add Image as background.
2. Add controls
Add Toggle (MusicToggle), Slider (VolumeSlider, min 0 max 1), TMP Input Field (PlayerNameInput).
3. Create UIManager
Attach UIManager to GameManager GameObject and drag the UI elements into its public fields.
4. Initialize & Test
In Start, set toggle and slider values from AudioListener and PlayerPrefs. Run scene and verify behavior.
Expected results
  • Toggle reflects audio pause state and toggles AudioListener.pause when changed.
  • Slider updates AudioListener.volume and shows percent feedback.
  • Input field saves the name to PlayerPrefs on end edit and updates status text.
Try this
Start the scene with audio muted and verify the toggle shows Off. Change the name, stop play mode, then restart to verify persistence.
