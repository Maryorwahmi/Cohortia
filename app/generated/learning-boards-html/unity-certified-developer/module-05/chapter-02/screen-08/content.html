Definition

Text entry and events

Use On Value Changed(String) for live feedback and On End Edit(String) for final submission or saving.

Inspector options
  • Character Limit — prevent overly long names
  • Content Type — choose Password, Alphanumeric, Integer when appropriate
  • Line Type — Single Line for names, Multi Line for chat
Validation example
public void ValidatePlayerName(string currentText)
{
    string validated = "";
    foreach (char c in currentText)
    {
        if (char.IsLetter(c) || char.IsWhiteSpace(c)) validated += c;
    }
    if (playerNameInputField.text != validated)
        playerNameInputField.text = validated; // enforce letters and spaces only
}
Key Takeaway
Do not rely on Inspector alone for strict validation — implement checks in code and initialize saved text in Start.
