Module 5 › Chapter 5.2 › What to Remember
Signatures
Use public void and supported parameter types for Inspector wiring; otherwise use AddListener.
Initialize
Set toggle.isOn and slider.value from AudioListener and saved settings in Start.
Lifecycle
Add listeners in Start, remove in OnDestroy, and validate input in code before saving.
Closing thought
These small, consistent practices drastically reduce bugs and improve the player's experience with your game settings UI.
