Definition

UI Rebuilds and Debugging Tools

Frequent changes to layout or text can trigger expensive UI.Canvas.Build calls. Use tools to find and fix them.
Profiler
Look for UI.Canvas.Build spikes and tie them to user actions or scripts.
Frame Debugger
Step through draw calls to find overdraw and material switches that break batching.
Fixes & Patterns
Move frequently changing elements to their own Canvas. Use CanvasGroup to fade panels. Reduce per-element animations that change RectTransforms. Consider virtualization for long lists to avoid instantiating everything at once.
