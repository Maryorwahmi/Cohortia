Module 6 › Chapter 5.6 › Rect Mask 2D vs Mask
Definition

Masking options for clipping

Understand stencil-based Mask vs the more efficient Rect Mask 2D for rectangular clipping.

Mask
Stencil-based, supports complex shapes but can break batching and increase draw calls.
Rect Mask 2D
Lightweight rectangular clipping that usually preserves batching and reduces overhead.
Practical Advice
If your Scroll View template uses Mask and you only need a rectangular clip, replace it with Rect Mask 2D. Profile before and after using the Profiler and Frame Debugger to confirm reduced draw calls. Remember that masks applied to many elements can multiply the cost; prefer Rect Mask 2D for common scroll windows.
Key Takeaway

Choose Rect Mask 2D when clipping is rectangular to maintain batching and reduce GPU work.
