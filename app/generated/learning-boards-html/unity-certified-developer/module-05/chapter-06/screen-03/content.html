Detailed Skill Breakdown

Concrete checkpoints and verifications help you measure mastery.

Scroll View Setup
  • Create UI > Scroll View so hierarchy is correct.
  • Add Vertical Layout Group and Content Size Fitter to Content.
  • Ensure Vertical Fit = Preferred Size so content expands.
Visual mnemonic: box that grows inside a window.
Dropdown & Runtime Wiring
  • Create Dropdown - TextMeshPro and clear/add options in Start.
  • Use onValueChanged to call a method that accepts an int index.
  • Persist selection with PlayerPrefs when appropriate.
Mnemonic: populate, listen, persist.
Optimization Quick Wins
  • Use shared atlases and fonts to maximize batching.
  • Prefer Rect Mask 2D for simple clipping to preserve batching.
  • Uncheck Raycast Target on decorative images to reduce unnecessary work.
Mnemonic: batch, clip, uncheck.
Debug & Verify
  • Use Profiler to inspect UI.Canvas.Build spikes.
  • Use Frame Debugger to view draw calls and overdraw.
  • Use CanvasGroup to fade entire panels instead of many elements.
Mnemonic: profile, inspect, change.
VERIFIED COMPETENCY MILESTONE: Complete the hands-on quest log and dropdown exercise and confirm improved profiler readings after optimization changes.
