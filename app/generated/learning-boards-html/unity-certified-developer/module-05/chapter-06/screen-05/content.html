Module 6 › Chapter 5.6 › Setting up a Scroll View
Process Flow

Create → Configure → Populate

  1. Create UI > Scroll View so the standard hierarchy is present.
  2. Select Content: Add Vertical Layout Group and Content Size Fitter (Vertical Fit = Preferred Size).
  3. Create a TextMeshProUGUI prefab sized to Content width and fixed height.
  4. Instantiate prefab children under Content in Start or via a manager; then rebuild layout or wait a frame before adjusting ScrollRect position.
  5. Optionally add and wire a Scrollbar to the Scroll Rect for direct control.
Example Scenario
Populate 20 quest entries in Start, then call Canvas.ForceUpdateCanvases() or use a coroutine that yields a frame before setting ScrollRect.verticalNormalizedPosition = 0 to show newest messages at the bottom.
Common Mistake

Instantiating items without a Content Size Fitter means the Content won't grow and scrolling will not occur.

Visual Steps
Hierarchy visual: Scroll View (Scroll Rect) → Viewport (Mask) → Content (Layout + Size Fitter) → Item Prefab
Sizing tip: Prefab width should be slightly less than Content width to avoid horizontal overflow; fix height to stabilize layout calculations.
