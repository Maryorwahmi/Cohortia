Core Concept

Batching & Overdraw

Reduce unique materials and atlases to allow Unity to combine draw calls. Reduce overlapping transparent areas to reduce GPU pixel work.
Batching tips
  • Use a single UI sprite atlas when possible.
  • Share the same TextMeshPro font atlas across UI elements.
  • Avoid changing material properties frequently.
Overdraw reduction
  • Uncheck Raycast Target on non-interactive decorative images.
  • Prefer opaque elements and smaller transparent regions when possible.
  • Replace Mask with Rect Mask 2D for rectangular clipping.
Quick repairs
If you see many small draw calls in Frame Debugger, look for different materials or fonts. Consolidate and retest. If GPU time is high, inspect overlapping transparent panels and reduce or flatten them when possible.
