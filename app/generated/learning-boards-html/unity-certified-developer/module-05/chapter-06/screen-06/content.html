Definition

Content Size Fitter & Layout Groups

These components work together to make Content report its true size so scrolling works.

Vertical Layout Group
Stacks children, controls spacing and alignment. Use fixed child heights to stabilize layout calculations.
Content Size Fitter
Adjusts the Content RectTransform to match children's preferred sizes. Set Vertical Fit = Preferred Size for vertical lists.
Example
A prefab with 50px height added 20 times results in Content height ~ 1000px plus spacing, enabling the Scroll Rect to move the content inside the Viewport.
Misconception

Believing Content Size Fitter handles spacing — spacing is a Layout Group responsibility.

Practical Cards
Prefab sizing tip
Give a fixed height to prefabs to reduce layout churn. Avoid dynamic content that changes measured size frequently.
When to force rebuild
Use Canvas.ForceUpdateCanvases or a coroutine that yields a frame after instantiation before changing scroll position to ensure layout is updated.
