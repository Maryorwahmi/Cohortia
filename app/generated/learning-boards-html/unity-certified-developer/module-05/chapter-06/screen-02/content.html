Learning Objectives

Learn, understand, apply, and master core UI techniques.

Learn → Understand → Apply → Master
01
Implement Scroll Views
Set up Viewport, Content, and Scroll Rect to present long lists cleanly and predictably. Verified Competency Milestone: place 20 items and scroll to bottom.
Mnemonic: Window (Viewport), Content grows, Scroll moves.
02
Configure Dropdowns
Populate a TMP_Dropdown at runtime and handle index events to drive game settings. Verified Competency Milestone: dropdown persists selection to PlayerPrefs.
Mnemonic: Populate, Listen, Persist.
03
Optimize UI Rendering
Use batching, reduce overdraw, and prefer Rect Mask 2D to keep draw and build costs low. Verified Competency Milestone: reduce draw calls for a menu by combining atlases.
Mnemonic: Batch, Clip, Simplify.
04
Debug Rebuilds & Modes
Use Profiler and Frame Debugger to find UI.Canvas.Build spikes. Understand Canvas render modes and use CanvasGroup to reduce rebuilds. Verified Competency Milestone: identify and fix a rebuild source using the Frame Debugger.
Mnemonic: Profile, Inspect, Fix.
