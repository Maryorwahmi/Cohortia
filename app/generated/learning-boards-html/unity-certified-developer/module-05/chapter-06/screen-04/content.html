Core Concept

Scroll View Anatomy

Understand how Viewport, Content, and Scroll Rect cooperate to display long lists.

Hierarchy (example)
Scroll View (Scroll Rect) → Viewport (Mask/Rect Mask 2D) → Content (Layout Group + Content Size Fitter) → Item Prefabs
Layout Roles
  • Viewport clips overflow so only visible items render within the window.
  • Content expands to fit children when Content Size Fitter is set correctly.
  • Scroll Rect translates input into Content movement and exposes scroll settings.
Common Mistake
Forgetting Content Size Fitter prevents Content from growing, so the Scroll Rect has nothing to move. Also, Mask vs Rect Mask 2D affects performance and batching.
Key Takeaway

The Scroll View works only when Viewport clips and Content grows; the Scroll Rect provides the motion.

Annotated Diagram
Visual: a window (Viewport) showing a vertical list whose parent Content expands. Items below the fold are clipped. Scrolling moves the Content RectTransform.
Example card
A quest log with 30 entries. After instantiation, set ScrollRect.verticalNormalizedPosition to 0 to show newest entries at bottom.
Misconception
Believing the Scroll Rect handles clipping — it does not. The Viewport mask performs clipping.
