Process Flow

Optimization Checklist

  1. Profile to find UI.Canvas.Build or UI.Render hotspots.
  2. Isolate frequently changing elements to their own Canvas or use CanvasGroup for panel fades.
  3. Consolidate sprites and fonts to improve batching.
  4. Uncheck Raycast Target on decorative images and swap Mask for Rect Mask 2D where possible.
  5. Consider virtualization for very large dynamic lists to render only visible items.
Verification
After applying changes, re-run the Profiler and check for reductions in UI.Canvas.Build and UI.Render times and a smaller number of draw calls in the Frame Debugger.
