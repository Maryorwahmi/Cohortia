Module 5 › Chapter 5.3 › Horizontal Layout Group
Properties

Padding, Spacing, Alignment

  • Padding: inward margin inside the container.
  • Spacing: uniform gap between children.
  • Control Child Size: lets the group set child width/height.
  • Child Force Expand: forces children to fill spare space.
Key Takeaway

Horizontal layouts give consistent rows; use child hints to combine fixed and flexible columns.

Checklist
