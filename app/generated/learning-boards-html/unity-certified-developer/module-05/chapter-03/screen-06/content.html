Module 5 › Chapter 5.3 › Vertical Layout Group
Key controls
Stack children, manage spacing and define how each child grows in height.
Preferred Height: give buttons a comfortable minimum height via Layout Element.
Child Force Expand Height: share remaining vertical space among children.
Content Size Fitter: use inside a child to let its content determine size before the layout group positions it.
Key Takeaway

For vertical lists, prefer Layout Element for heights and place Content Size Fitter on content elements that determine the required vertical space.

Example: Options Menu
Button A — Preferred Height 50
Button B — Preferred Height 50
Button C — Content Size Fitter on label
Mistake to avoid
Do not set both a hard Rect Transform height and expect the group to resize it; prefer Layout Element hints instead.
