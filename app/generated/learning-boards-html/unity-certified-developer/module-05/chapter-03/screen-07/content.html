Module 5 › Chapter 5.3 › Grid Layout Group
Grid properties
  • Cell Size: width and height for each grid cell.
  • Constraint: Fixed Column/Row Count or Flexible placement rules.
  • Start Corner / Axis: decide where filling begins and whether rows or columns fill first.
Inventory example
Cell Size: 70x70. Constraint: Fixed Column Count = 4. Grid arranges up to 4 columns per row and continues to next row as items are added.
When to compute cell size
If your inventory panel must stretch to arbitrary widths, calculate a cell size in code using parent Rect width minus padding and spacing, then set Grid Layout Group cell size at runtime.
Key Takeaway

Grid Layout Group is perfect for uniform slot-based UIs; choose fixed counts for visual predictability or compute sizes when container width varies.
