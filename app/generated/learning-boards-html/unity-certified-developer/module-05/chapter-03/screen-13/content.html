Module 5 › Chapter 5.3 › Quest Log Pattern
Prefab design
QuestEntry contains an icon and a wrapping TextMeshPro label. Add Content Size Fitter to the label and Min Height on the entry if desired.
Why place fitter on the label?
Placing the fitter on inner content prevents the entry GameObject from fighting the Vertical Layout Group for height control and avoids update loops.
Runtime test
Instantiate 3–5 entries with varying text lengths. Observe the Vertical Layout Group reflowing entries and preserving spacing and alignment.
Key Takeaway

Place content-driven fitters on inner elements and let the container stack entries for correct dynamic sizing.
