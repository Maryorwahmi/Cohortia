Module 5 › Chapter 5.3 › Common Mistakes & Debugging
Mistake vs Fix
Wrong: Layout Group on a child. Fix: Move it to parent container.
Wrong: Hard Rect sizes on children. Fix: Use Layout Element hints.
Wrong: Fitter on same object as layout group. Fix: Put fitter on inner content element.
Debug Routine
  1. Toggle the layout component to see children positions reset.
  2. Inspect Layout Element values on children for conflicting hints.
  3. Test with varying text length and different screen sizes.
Final tip

Think hierarchy and responsibilities: Canvas scales, anchors position, containers arrange, and child components provide size hints.
