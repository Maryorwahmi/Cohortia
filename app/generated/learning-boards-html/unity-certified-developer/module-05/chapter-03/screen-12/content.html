Module 5 › Chapter 5.3 › Inventory Grid Setup
Step checklist
  1. Create InventoryPanel and set anchors to Bottom-Right.
  2. Add Grid Layout Group: Cell Size 70x70, Constraint Count 4.
  3. Create InventorySlot prefab and set size to 60x60.
  4. Instantiate 16 slots under the panel at Start().
Runtime sizing tip
If the panel width varies, calculate cell width = (parentWidth - paddingLeft - paddingRight - spacing*(columns-1)) / columns and set Grid Layout Group cell size at runtime.
Key Takeaway

Populate grids by instantiation; compute cell size only if the container must adapt to many widths.
