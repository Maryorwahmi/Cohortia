Module 5 › Chapter 5.3 › What is a Layout Group?
Definition

Container-driven arrangement

Layout Groups (Horizontal, Vertical, Grid) let a parent manage how children are laid out so you do less manual work and support dynamic content.
When to use
Lists, menus, inventory panels, and anywhere children can be added or removed at runtime.
Common misconception
Layout Groups do not replace layout hints on children; use Layout Element for min/preferred sizing.
Key Takeaway

Place layout groups on parents, give children hints with Layout Element, and avoid manual pixel placement.

Concrete example
A Vertical Layout Group for the main menu ensures any number of buttons stack with consistent spacing and alignment. Add a new button and the container recalculates positions automatically.
Explanation bullets
  • Padding: space between container edges and children.
  • Spacing: gap between successive children.
  • Child Alignment: controls where children sit inside the available area.
Analogy
Think of a layout group as a bookshelf: the shelf holds the books and decides their order and spacing; each book may still be different size.
