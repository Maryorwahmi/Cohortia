Module 5 › Chapter 5.3 › Canvas Scaler & Anchors
Canvas Scaler
Set Mode to Scale With Screen Size and choose a reference resolution to maintain consistent sizing across devices.
Rect Transform anchors
Anchors define where the container stretches or pins. For a left panel, set anchors to the left edge and stretch vertically so children get proper height from the parent.
Practical checks
  • Test multiple aspect ratios after setting Canvas Scaler.
  • Ensure container anchors match intended pin/stretch behavior.
  • Let layout groups fill the anchored rectangle rather than hard-coding offsets.
Key Takeaway

Think: scale the canvas, anchor the container, then let layout groups arrange inside that anchored area.
