Module 5 › Chapter 5.3 › Layout Element
What it does
Provide child-specific size hints: Min, Preferred, and Flexible dimensions used by parent layout groups when calculating final sizes.
Example configuration
  • Left field: Min Width = 150, Flexible Width = 0.
  • Middle field: Flexible Width = 2.
  • Right field: Flexible Width = 1.
Common pitfalls
Avoid mixing hard Rect Transform sizes with Layout Element hints; let the layout group resolve sizes from child hints to keep behavior consistent across screen sizes.
Pro Tip

Use Flexible values to express proportional sharing of leftover space rather than absolute pixel widths.
