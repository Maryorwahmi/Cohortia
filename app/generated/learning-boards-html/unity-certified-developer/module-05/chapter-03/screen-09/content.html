Module 5 › Chapter 5.3 › Content Size Fitter
How it works
Set Horizontal Fit and Vertical Fit to Preferred Size to resize to content, or Unconstrained to disable resizing along an axis.
Example: Chat message
A TextMeshPro child with Content Size Fitter set to Preferred Size will grow vertically as text wraps, and its parent Vertical Layout Group will reflow other messages.
Warning
Placing Content Size Fitter on the same GameObject a Layout Group manages can create continuous layout recalculations. Prefer placing fitters on inner content elements.
Key Takeaway

Use Content Size Fitter to make individual items content-driven while keeping the container responsible for arrangement.
