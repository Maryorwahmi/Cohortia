Module 5 › Chapter 5.3 › Key Concepts
Layout Group
Parent component that arranges children automatically in rows, columns, or grids.
Content Size Fitter
Resizes elements to match content; place on content to avoid layout conflicts.
Layout Element
Child-level hints for min, preferred and flexible sizes used by layout groups.
Summary
Combine Canvas Scaler, anchors, layout groups, and sizing components to build predictable, responsive UI that adapts to content and screens.
