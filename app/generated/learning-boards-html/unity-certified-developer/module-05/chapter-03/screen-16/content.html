Module 5 › Chapter 5.3 › Key Concepts
Parent-first
Layout Groups belong on parents. They arrange direct children automatically.
Sizing hints
Use Layout Element for hints; use Content Size Fitter on content to let text drive size.
Canvas & anchors
Scale the UI with Canvas Scaler and pin containers with anchors before arranging children.
Parting thought
Encapsulate sizing in prefabs, parent to layout groups at runtime, and test with different content lengths and screen sizes.
