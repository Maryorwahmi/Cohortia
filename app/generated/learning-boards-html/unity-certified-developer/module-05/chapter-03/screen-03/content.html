Core Tasks
  1. Set Grid Layout Group for inventory slots and test cell size and constraints.
  2. Create Vertical Layout Group menu and attach Content Size Fitter.
  3. Use Layout Element to enforce minimum or flexible widths.
  4. Adjust Rect Transform anchors so containers stay where you expect.
Debug Checklist
  • Is the Layout Group on the parent container or accidentally on a child?
  • Are fixed widths fighting flexible expansion?
  • Is Canvas Scaler set to Scale With Screen Size for consistent results?
Tip: Use small content changes to see how the layout responds in play mode.
