IEnumerator AnimatePanel(Vector2 from, Vector2 to, float duration)
{
  float t = 0f;
  while (t < duration)
  {
    t += Time.deltaTime;
    float p = Mathf.Clamp01(t / duration);
    float eased = 1f - Mathf.Pow(1f - p, 2);
    rect.anchoredPosition = Vector2.Lerp(from, to, eased);
    canvasGroup.alpha = Mathf.Lerp(0f, 1f, p);
    yield return null;
  }
  rect.anchoredPosition = to;
  canvasGroup.alpha = 1f;
}
Ensure you set interactable and blocksRaycasts on the CanvasGroup when fully visible or hidden to control input.
Practical notes
  • Use a duration of 0.5–0.75s for panel slides to balance clarity and responsiveness.
  • Apply easing to position, and linear interpolation for alpha to avoid visible lag.
  • Stop existing coroutines before starting new ones to avoid conflicting motion.
Key Takeaway

Combine position and alpha in a coroutine, finalize values, and manage interaction via CanvasGroup for smooth panel transitions.
