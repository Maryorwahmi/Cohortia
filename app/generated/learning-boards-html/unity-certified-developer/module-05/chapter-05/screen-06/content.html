Example script
// Sketch: MoveUIElement coroutine
IEnumerator MoveUIElement(Vector3 currentPos, Vector3 targetPos, float duration)
{
  float timer = 0f;
  while (timer < duration)
  {
    timer += Time.deltaTime;
    float progress = timer / duration;
    float eased = 1f - Mathf.Pow(1f - progress, 2); // EaseOutQuad
    targetRect.anchoredPosition = Vector3.Lerp(currentPos, targetPos, eased);
    yield return null;
  }
  targetRect.anchoredPosition = targetPos;
}
Stop conflicting animations with StopAllCoroutines or by tracking a running Coroutine reference to Stop it, then start the new one.
Pattern notes
  • Compute progress = timer / duration and apply an easing function for natural motion.
  • Set final value explicitly after loop to avoid floating point drift.
  • Use CanvasGroup to fade and toggle interactability while animating.
Scenario
Slide a settings panel in from the right over 0.75 seconds. If Open is called while closing, stop the close coroutine and start the open coroutine to avoid visual conflicts.
Key Takeaway

Coroutines provide readable, sequential animation logic and are ideal for panel control and interruptible sequences.
