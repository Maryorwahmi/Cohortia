Step-by-step
  1. Create Button - TextMeshPro and set label.
  2. Set Button Transition to Animation and Auto Generate Animation.
  3. Edit Highlighted clip: scale 1 → 1.1 at 0.05s.
  4. Edit Pressed clip: scale 1 → 0.9 at 0.05s.
  5. Test in Play mode and adjust duration or easing.
Example checks
  • Are clip names exactly Normal, Highlighted, Pressed? If not, rename.
  • Does the scale change feel snappy? Reduce keyframe time if not.
  • Is animation blocking input? Keep durations short to preserve responsiveness.
Key Takeaway

Small, named clips let Unity drive state changes with little code and clear designer control.
