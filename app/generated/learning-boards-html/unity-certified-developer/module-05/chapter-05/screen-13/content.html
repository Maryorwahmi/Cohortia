Why CanvasGroup

Animating a single CanvasGroup.alpha is often cheaper than animating many child elements. It centralizes visibility and input control.

Practical example
Animate alpha 0→1 while anchoredPosition slides in. At end set interactable = true and blocksRaycasts = true.
Checklist
  • Use CanvasGroup for group fades.
  • Avoid simultaneous RectTransform animations on many children.
  • Toggle interactable and blocksRaycasts to manage input state.
Key Takeaway

CanvasGroup simplifies fades and input control for grouped UI, helping performance when used appropriately.
