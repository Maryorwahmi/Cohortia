Transition types
Color Tint
Fast, low-cost color changes for hover and press. Good for many elements.
Sprite Swap
Replace sprites per state for distinct visuals without keyframes.
Animation
Use Animator Controller for scale, rotation, text change or complex clips.
Decision checklist
  • Do you only need color change? Use Color Tint.
  • Do you need a different image per state? Use Sprite Swap.
  • Do you need scale, multiple properties, or text changes? Use Animation.
Example scenario
A HUD icon that needs to flash and scale on selection should use Animation; a menu item that only desaturates on disable can use Color Tint.
