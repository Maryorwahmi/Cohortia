Definition

UI animation as communication

Motion confirms actions, highlights changes, and establishes visual priority. Timing and consistency determine if motion helps or hinders.

Example
A button grows 10% on hover and shrinks briefly on press to signal input.
Common mistake
Long, decorative animations that delay the user's next action.
Key Takeaway

Keep feedback short and consistent so players learn the language of motion quickly.

Metaphor
Think of animation like a nod in human conversation: short and clear signals keep the dialog flowing.
Timing Checklist
  • Keep response animations under 0.1–0.25 seconds when possible.
  • Use easing to avoid sudden starts and stops.
  • Test on target hardware for perceived responsiveness.
Try this
Create a hover highlight and measure if the interaction feels immediate. Reduce duration first if it feels sluggish.
