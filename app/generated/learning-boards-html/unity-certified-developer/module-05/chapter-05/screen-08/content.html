Animator Controller
Best for named states and designer editing. Easy to hook to Button when Transition = Animation.
Coroutines
Clear for sequential tasks, easy to reason about and control mid-flight.
DOTween
Concise calls, built-in easing and sequences. Good for many concurrent simple motions.
Comparison example
Sliding settings panel: coroutine if you want explicit control and easy read-through; DOTween if you prefer one-liners and chaining; Animator if the panel is tied to state and authored by designers.
Key Takeaway

Match the technique to the problem: state editing, scripted sequences, or optimized tweens.
