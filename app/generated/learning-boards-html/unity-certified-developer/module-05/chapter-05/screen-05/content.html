Workflow
  1. Select the UI GameObject and open Window > Animation > Animation.
  2. Click Create to add an Animator and controller asset.
  3. Record clips for Normal, Highlighted, Pressed using Rect Transform or Image color keyframes.
  4. Set the Button's Transition to Animation so Unity triggers the clips by name.
Concrete example
Highlighted: at 0 seconds scale 1, at 0.05s scale 1.1. Pressed: at 0 seconds scale 1, at 0.05s scale 0.9.
Common-mistake
Forgetting to name clips exactly as Button expects will prevent automatic state switching. Verify names and test in Play mode.
Visual
Normal
Scale 1, default color
Highlighted
Scale 1.1, tint
Pressed
Scale 0.9 briefly
Key Takeaway

Animator Controllers are excellent for state-based UI when clips are named and sized for quick feedback.
