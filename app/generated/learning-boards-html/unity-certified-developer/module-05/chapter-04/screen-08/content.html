Module 5 › Chapter 5.4 › Drag-and-Drop Lifecycle
Interface responsibilities

IBeginDragHandler: create ghost, set canvasGroup.alpha, blocksRaycasts = false, and reparent to Canvas.

IDragHandler: update rectTransform.anchoredPosition using eventData.delta divided by canvas.scaleFactor to keep motion consistent across resolutions.

IEndDragHandler: restore alpha and blocksRaycasts, check eventData.pointerCurrentRaycast.gameObject for valid drop location and finalize parent or revert.

Analogy
Think of begin as lifting an object, drag as carrying, and end as placing it down in a slot.
Practical checklist
  • Ensure Canvas reference is the parent Canvas for scaleFactor.
  • Add or require a CanvasGroup component to control alpha and blocksRaycasts.
  • Set transform.SetAsLastSibling() to render on top while dragging.
  • Log eventData.pointerCurrentRaycast to verify drop targets at OnEndDrag.
Key Takeaway

Handle parenting, transparency, and canvas scale to make drag feel correct and to ensure drop detection works.
