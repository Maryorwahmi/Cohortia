Key code excerpt
using UnityEngine;
using UnityEngine.EventSystems;
using UnityEngine.UI;

public class HoverEffect : MonoBehaviour, IPointerEnterHandler, IPointerExitHandler, IPointerClickHandler
{
    private Image targetImage;
    private Color originalColor;
    public Color hoverColor = Color.yellow;
    public Color clickColor = Color.red;

    void Awake()
    {
        targetImage = GetComponent<Image>();
        if (targetImage != null) originalColor = targetImage.color;
    }

    public void OnPointerEnter(PointerEventData eventData) { /* set hover color and log */ }
    public void OnPointerExit(PointerEventData eventData) { /* revert to original color and log */ }
    public void OnPointerClick(PointerEventData eventData) { /* set click color, log, and revert after delay */ }
}
This excerpt shows the structure: cache the Image, expose colors, and implement three handlers. Add Debug.Log lines to confirm entry points while testing.
Supporting tips
  • Guard GetComponent calls to avoid null references.
  • Use Invoke or a coroutine to revert color after a short delay.
  • Consider selection checks via EventSystem to decide revert color.
Common mistake

Changing color without setting Raycast Target or without Debug.Log hides whether events fired. Always validate the EventSystem and raycasters when behavior is missing.
