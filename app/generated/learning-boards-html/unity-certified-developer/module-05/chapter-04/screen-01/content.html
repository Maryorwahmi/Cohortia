Why the EventSystem matters
A single manager that processes input, performs raycasts, and routes events so UI elements receive pointer data.
Role
Processes input from mouse, touch, keyboard, and controllers and dispatches events to UI elements that implement handlers.
Raycasting
Works with Graphic Raycaster or Physics Raycaster to determine which element is under the pointer before calling handlers.
Focus & Selection
Manages which UI element is selected so keyboard and controller input reach the expected target.
What Breaks
No EventSystem or missing raycasters means UI elements won't respond; images with Raycast Target enabled can unintentionally block events.
In this lesson
You'll implement pointer handlers, build a drag flow that respects Canvas scale, and create UnityEvent publishers and subscribers for decoupled communication.
