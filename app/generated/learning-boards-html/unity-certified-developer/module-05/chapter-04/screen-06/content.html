Common pointer interfaces
IPointerClickHandler
OnPointerClick receives click events when press and release happen on the same element.
IPointerEnterHandler / IPointerExitHandler
OnPointerEnter and OnPointerExit support hover effects and tooltips.
IPointerDownHandler / IPointerUpHandler
For press-and-hold or separate down/up logic, use these handlers.
Concrete example

Use OnPointerEnter to show a tooltip at eventData.position and OnPointerExit to hide it. For mobile, pointer IDs help you track multiple touches.

PointerEventData highlights
  • position: screen point of the pointer.
  • pointerId: useful for multi-touch tracking.
  • button: which mouse button if applicable.
  • pointerCurrentRaycast: which GameObject was hit by raycast.
Misconception: relying only on OnClick misses press-and-hold and hover-driven flows. Use the right interface for the interaction.
