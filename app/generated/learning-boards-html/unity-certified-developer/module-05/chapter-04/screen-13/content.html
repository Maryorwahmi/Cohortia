Module 5 › Chapter 5.4 › Debugging Events
Problem vs Fix
Missing EventSystem → Add EventSystem GameObject to scene.
Blocked raycasts → Uncheck Raycast Target on decorative graphics.
Uninitialized UnityEvent → Initialize in Awake before invoking.
Wrong transform API → Use RectTransform.anchoredPosition for UI movement.
Diagnostic checks
  • Run and watch Debug.Log messages in handlers to confirm they execute.
  • Print eventData.pointerCurrentRaycast.gameObject in handlers to inspect hits.
  • Temporarily disable suspected blocking graphics and test again.
  • Ensure AddListener/RemoveListener pairs are present and balanced.
Key Takeaway

Start with EventSystem and raycast checks, then verify handler invocation and UnityEvent lifecycle to resolve most UI event bugs.
