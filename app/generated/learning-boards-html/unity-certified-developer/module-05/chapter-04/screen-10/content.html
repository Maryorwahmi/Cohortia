Module 5 › Chapter 5.4 › Canvas & Reparenting
Layer & input control
Reparenting to Canvas root ensures top rendering. CanvasGroup.alpha yields a ghost effect. CanvasGroup.blocksRaycasts=false lets raycasts reach underlying targets while dragging.
Mini-code
transform.SetParent(canvas.transform); transform.SetAsLastSibling(); canvasGroup.alpha = 0.6f; canvasGroup.blocksRaycasts = false;
Scale factor detail
When updating anchoredPosition, use eventData.delta divided by canvas.scaleFactor to convert screen pixels into canvas-local movement. This keeps drag speed consistent when Canvas uses different scaling settings.
Key Takeaway

Reparenting, alpha change, and blocksRaycasts together give a reliable visual and interaction experience for dragged UI elements.
