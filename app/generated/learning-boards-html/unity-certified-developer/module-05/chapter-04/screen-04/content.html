Module 5 › Chapter 5.4 › EventSystem Definition
Runtime responsibilities
  • Collect input across devices and normalize pointer data.
  • Execute raycasts using the Canvas's Graphic Raycaster or a Physics Raycaster.
  • Track selection and focus so keyboard/controller input targets the right element.
Concrete example
If your buttons don't respond in a new scene, confirm there is an EventSystem GameObject and that the Canvas includes a Graphic Raycaster. This fixes many silent failures.
Supporting cards
Graphic Raycaster
Used for screen-space Canvas to detect UI under pointer.
Physics Raycaster
Used with world-space UI and 3D colliders for pointer hits.
Raycast Target
Graphic components can block events; disable when decorative.
Key Takeaway

Always verify the EventSystem and proper raycaster before changing UI scripts during debugging.
