Verification steps
  • Confirm EventSystem exists in scene and Canvas has appropriate Raycaster.
  • Attach HoverEffect and observe color changes and Debug.Log messages during pointer enter/exit/click.
  • Drag the item and verify canvasGroup.blocksRaycasts is toggled to allow drop targets to receive events.
  • Publish a UnityEvent and ensure subscribers update UI without direct GameManager references.
Common misconception
Students often assume a missing script causes no events. More often it's the EventSystem or Raycast Target settings. Always inspect the Canvas and the images' Raycast Target before rewriting scripts.
Quick task
Run the scene, hover over the button and click. If nothing happens, check EventSystem and Graphic Raycaster first.
