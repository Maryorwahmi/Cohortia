Module 5 › Chapter 5.4 › Raycasting Flow
Numbered raycast steps
1. Input captured: pointer position and button.
2. Raycaster executes hit test against UI elements and colliders.
3. Hits are sorted by depth; top hit is chosen for dispatch.
4. EventSystem dispatches PointerDown/Click or drag handlers using PointerEventData.
Debugging and example
During a drag-and-drop attempt, log eventData.pointerCurrentRaycast.gameObject in OnEndDrag. If it returns a panel you didn't expect, that panel likely has Raycast Target enabled and is blocking the intended drop target.
Check
Toggle Raycast Target on decorative images to allow clicks to pass through to interactive elements beneath.
Key Takeaway

Raycast order and Raycast Target settings determine which element receives events — examine hits to debug unexpected behavior.
