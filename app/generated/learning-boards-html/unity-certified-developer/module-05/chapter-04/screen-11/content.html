Module 5 › Chapter 5.4 › UnityEvent Basics
Publisher pattern
public class GameManager : MonoBehaviour
{
    public UnityEvent OnGameStarted;
    public UnityEvent OnScoreUpdated;

    void Awake()
    {
        OnGameStarted = new UnityEvent();
        OnScoreUpdated = new UnityEvent();
    }

    public void UpdateScore(int newScore) { OnScoreUpdated.Invoke(newScore); }
}
Initialize UnityEvent fields before invoking to avoid null reference errors. Keeping events public lets designers wire listeners in the Inspector as well.
Subscriber pattern
public class UIMessageDisplay : MonoBehaviour
{
    public GameManager gameManager;
    void Start() { gameManager.OnScoreUpdated.AddListener(DisplayScoreMessage); }
    void OnDestroy() { gameManager.OnScoreUpdated.RemoveListener(DisplayScoreMessage); }
    void DisplayScoreMessage(int score) { /* update UI */ }
}
Key Takeaway

UnityEvent gives a simple, inspector-friendly publish/subscribe mechanism — remember to remove listeners to prevent memory leaks.
