Module 5 › Chapter 5.4 › Subscribe & Lifecycle
Best-practice steps
  1. Declare and initialize the UnityEvent in Awake or Start.
  2. Add listeners in Start or OnEnable so subscribers are ready.
  3. Remove listeners in OnDestroy or OnDisable to prevent leaks.
  4. Guard against double subscriptions by pairing enable/disable methods.
Debugging tip
If callbacks execute after objects are destroyed, search for missing RemoveListener calls or double subscriptions added in both Awake and Start.
Example lifecycle
void Start() { gameManager.OnScoreUpdated.AddListener(UpdateDisplay); }
void OnDestroy() { gameManager.OnScoreUpdated.RemoveListener(UpdateDisplay); }
Pitfall

Adding a listener in Awake and again in Start will register duplicates. Ensure subscription happens once or remove previous listeners first.
