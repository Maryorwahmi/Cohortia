Resolution steps
  1. Check predefined symbol table (R0–R15, SCREEN, KBD, SP, LCL, ARG, THIS, THAT).
  2. If not predefined, check labels recorded in pass one.
  3. If still unresolved, allocate a new RAM address starting at 16 and add it to the table as a variable.
This predictable ordering prevents ambiguity between labels and variables and supports forward label references.
Example decision
If symbol LOOP appears and labels include LOOP, use that address; if not and LOOP is new, assign it RAM address 16.
