Module 4 › Chapter 4.2 › Assessment Targets
Practical tasks
  • Max of two numbers: compare RAM[0] and RAM[1], store max in RAM[2].
  • Sum 1 to n: loop using a counter and accumulator, store in RAM[1].
  • Count negatives: check RAM[0]..RAM[9], store count in RAM[10].
Evaluation checklist
  • Label addresses recorded correctly by first pass.
  • Variables allocated starting at address 16.
  • C-instructions translated with correct comp/dest/jump bits.
Mnemonic reminder
Think: A-instruction sets an address, C-instruction computes and optionally jumps.
Common misconception
Labels define ROM addresses; variables map to RAM starting at 16. They are not interchangeable.
