Code Walkthrough › Translating C-instructions
Step-by-step
  1. Determine comp expression and choose the correct comp bit pattern (watch for M vs A).
  2. Set dest bits: three-bit mask for A, D, M targets.
  3. Set jump bits according to the condition mnemonic; no jump = 000.
  4. Concatenate fields into the 16-bit C-instruction pattern.
Example conversion (conceptual): D=D+M;JGT converts comp for D+M, dest bits for D, and jump bits for greater-than, producing the final binary instruction.
Concrete hint
If comp includes M, choose the comp pattern with the a-bit set to indicate memory access. If comp includes only A or constants, use the a-bit cleared patterns.
Key Takeaway

Carefully pick comp patterns and dest/jump bits; most translation errors come from choosing the wrong comp variant or dest mask.
