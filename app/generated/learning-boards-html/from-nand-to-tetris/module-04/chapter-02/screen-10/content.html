Process Flow › Two-pass assembler
Pass One — Label collection
Scan lines, ignore label pseudo-ops for ROM counting, and record each label with the address of the next real instruction.
Checklist
  • Increment ROM address only for A- and C-instructions.
  • Record label names with the current ROM address.
  • Build initial symbol table entries from labels.
Pass Two — Translate & allocate
Translate each instruction, resolve symbols using predefined and recorded labels, and allocate new variables starting at address 16 when needed.
Key Takeaway

Two passes allow forward references and a clean separation between label discovery and instruction encoding.
