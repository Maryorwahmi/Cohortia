Summary › Key Concepts
Assembly = symbolic machine code
Mnemonics and symbols replace raw binary to aid readability and maintenance.
A- and C-instructions
A-instructions load addresses; C-instructions compute, store results, and control jumps.
Symbol resolution & two-pass assembly
First pass records labels, second pass translates instructions and allocates variables starting at 16.
Takeaway
Practice building symbol tables and translating short programs to internalize mapping from names to numeric addresses.
