Definition › Labels
Label form
(LABEL_NAME) records the ROM address of the next instruction. It is not translated into machine code but used by the assembler to resolve symbol references.
Example
(END)
@END
0;JMP
Here, END maps to the ROM address of the unconditional jump instruction that follows.
Label vs variable
Labels map ROM addresses for control flow; variables allocate RAM addresses (starting at 16). Confusing them can break both address resolution and memory layout.
Pro tip

When labeling loops, pick descriptive names so the symbol table acts as a readable legend for your program flow.
