Process Flow › Variable allocation
Allocation rule
First free RAM address for user variables is 16. Each new variable name gets the next free address during the assembler’s second pass.
Example allocation
First new symbol: i  → 16
Next new symbol: sum → 17
Next: temp       → 18
Why this matters
Reserved registers at low addresses support fast temporary storage and standard conventions used by compilers and the VM translation stages.
Warning

Allocating too many variables may approach the stack area starting at address 256 on the Hack machine; manage variable use carefully.
