Core Concept › C-instructions
Syntax: dest=comp;jump
comp
Computation expressions such as D+A, M-1, !D, 0.
dest
Targets: A, D, M or combinations like MD, AMD.
jump
Conditions: JGT, JEQ, JGE, JLT, JNE, JLE, JMP.
Example
D=A         // copy A into D
D=D+A       // add A to D, keep in D
M=D;JGT     // store D into memory at A, jump if result > 0
Quick checklist
  • Is comp referencing M? If so, A must point to the RAM address.
  • Dest lists outputs, not inputs.
  • Jump appears only if you want to change control flow.
Common mistake

Confusing dest with comp inputs leads to incorrect register usage. Read comp as the expression and dest as where to store the result.
