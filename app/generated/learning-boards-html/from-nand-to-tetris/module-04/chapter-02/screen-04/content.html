What assembly gives you
  • Human-readable mnemonics instead of raw 0s and 1s.
  • Symbolic addresses and labels that make code navigable.
  • Variables with meaningful names that document intent.
  • Portability of names: assembler resolves numeric addresses.
Analogy
Think of mnemonics as street names and labels as landmarks; the assembler maps them into numeric coordinates the machine understands.
Concrete example
// add R0 and R1, store in R2
@R0
D=M
@R1
D=D+M
@R2
M=D
This sequence directly states the programmer’s intent: fetch, add, and store. The assembler converts the mnemonic operations to bits.
Key Takeaway

Assembly reduces cognitive load: you work with names and computations, not raw binary patterns.
