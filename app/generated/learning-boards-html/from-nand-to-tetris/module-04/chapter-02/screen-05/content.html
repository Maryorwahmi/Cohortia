A-instruction form
Starts with an at sign followed by either a decimal number (0–32767) or a symbol. If number, A gets that value; if symbol, assembler resolves it to an address.
Examples
@21    // loads 21 into A
@R0    // predefined: loads address 0 into A
@LOOP  // symbol: address found in symbol table
Common mistake
Assuming a symbol is immediately a variable. If symbol is a label recorded during the first pass, it maps to a ROM address; if not, it may become a variable allocated at the next free RAM address starting at 16.
Translate to bits
A-instruction binary starts with a zero bit then fifteen bits representing the value. Practicing conversion by hand helps you verify assembler output.
Try this
Convert @2 to its 16-bit representation: zero plus fifteen-bit binary for 2.
Key Takeaway

A-instructions either embed a literal number or carry a symbol the assembler resolves into a numeric address.
