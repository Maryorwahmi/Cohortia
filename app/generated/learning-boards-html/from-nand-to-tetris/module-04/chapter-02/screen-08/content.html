Core Concept › Symbols
Predefined symbols
R0–R15 → addresses 0–15
SCREEN → 16384, KBD → 24576
These are immediate mappings the assembler already knows.
Labels
(NAME) records the ROM address of the next instruction; used for branching and references.
Labels are resolved during the assembler's first pass.
Variables
Any non-predefined, non-label symbol becomes a variable assigned from address 16 up.
Variables occupy RAM on translation; be mindful of address space limits.
Key Takeaway

Symbols follow a clear resolution order: predefined → label → variable; variables are assigned starting at RAM address 16.
