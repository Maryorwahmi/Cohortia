Module 4 › Chapter 4.3 › Checkerboard Activity
Activity
Fill screen with a checkerboard pattern
Use parity toggles while iterating over the SCREEN address range to alternate words or rows.
Implementation steps
  1. Set pointer = SCREEN and words = small test count (e.g., 32).
  2. Use a parity variable that toggles each word or each row.
  3. In the loop write M = -1 when parity true, otherwise M = 0, then increment pointer and toggle parity.
  4. Test visually in the CPU Emulator and expand to full screen when correct.
Key Takeaway

Start small, verify address-to-pixel mapping, then scale to the full screen.

Debug hint
If the pattern looks shifted, re-check how your parity toggles across row boundaries and whether you increment the address exactly one word per step.
