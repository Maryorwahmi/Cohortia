Module 4 › Chapter 4.3 › Debugging
Process
Find logic errors with targeted stepping
Work with small test cases, step instructions, set breakpoints, and watch the values that matter.
Step-by-step
  1. Run first few instructions to warm state.
  2. Set breakpoint at loop entry or conditional jump.
  3. Step and watch counter and PC at each iteration.
Watch list
  • Registers: A, D, PC
  • Memory: counter, address pointer, SCREEN range
Key Takeaway

Combine small test inputs with breakpoints at control checks to quickly isolate incorrect instructions or data updates.

Common pitfall
Watching only high-level symptoms without stepping can miss the exact instruction where a register or memory location is wrong.
