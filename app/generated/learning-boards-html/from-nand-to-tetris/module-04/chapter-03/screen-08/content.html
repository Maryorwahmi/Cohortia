Module 4 › Chapter 4.3 › Subroutines
Architecture
Call and return without hardware support
Use a saved return address or a software stack to preserve the caller's continuation point before jumping to the subroutine.
Caller pattern (conceptual)
  1. Store address of next instruction into a RAM slot or push it to a stack.
  2. Jump to subroutine label.
  3. After return, continue execution from saved address.
Concrete practice
Implement a single call: have the caller write the next instruction address to RAM[savedReturn], jump to DO_WORK, and at the end of DO_WORK jump to the address stored in RAM[savedReturn]. Verify in the emulator that the PC returns as expected.
Misconception

Do not assume the PC auto-restores. Without a saved address, returns cannot resume at the caller's next instruction.

Why it matters
Understanding manual calls prepares you for the VM module where an abstract stack will formalize this pattern and support nested calls and local frames.
