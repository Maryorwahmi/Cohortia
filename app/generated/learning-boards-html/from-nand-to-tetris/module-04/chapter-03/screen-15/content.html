Module 4 › Chapter 4.3 › What to Remember
Assembly Control
Create loops and branches using labels and conditional or unconditional jumps.
Memory-mapped I/O
Write to SCREEN to draw; read KBD to get the ASCII code of a pressed key.
Debugging
Use the CPU Emulator for stepping, breakpoints, and watching registers and memory to validate program behavior.
Takeaway
Master small patterns—init, loop, conditional, I/O—and test them incrementally in the CPU Emulator to build correct assembly programs.
