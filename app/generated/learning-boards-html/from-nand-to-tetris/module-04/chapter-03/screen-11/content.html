Module 4 › Chapter 4.3 › Multiplication
Core Concept
Multiply via repeated addition
Copy operands to working RAM, loop adding multiplicand into result while decrementing multiplier.
@R0
D=M
@a
M=D
@R1
D=M
@b
M=D
@result
M=0

(LOOP)
@b
D=M
@END
D;JEQ    // If b == 0, done

@a
D=M
@result
M=M+D    // result = result + a

@b
M=M-1    // b = b - 1
@LOOP
0;JMP

(END)
@result
D=M
@R2
M=D
Complexity
This algorithm is linear in the multiplier value. For small inputs it is simple and reliable; for large inputs it is slow.
Practical tip

Test with small numbers like 3 and 4, step through the loop, and confirm result increments match the multiplier count.

Analogy
Think of multiplication as adding a pile repeatedly: you add the same pile as many times as the multiplier says.
