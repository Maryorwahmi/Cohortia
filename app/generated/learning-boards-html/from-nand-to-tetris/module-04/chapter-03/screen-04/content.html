Core Concept
Countdown loop example
This code initializes a counter and loops until it reaches zero.
@10
D=A
@counter
M=D

(LOOP)
@counter
D=M
@END
D;JEQ    // If counter == 0, jump to END

@counter
D=M-1
M=D
@LOOP
0;JMP    // Unconditional jump back to LOOP

(END)
@END
0;JMP    // Infinite loop at END
How it works
  • Initialize counter in RAM with an A-instruction and M=D store.
  • At LOOP read counter into D and jump to END when equal to zero.
  • Decrement then unconditionally jump back to continue iterating.
Concrete example
Use this pattern to count down seconds, iterate over memory addresses for screen drawing, or implement repeated addition for multiplication.
Key Takeaway

Position your conditional check deliberately: before the body to avoid extra iterations, or after to guarantee one execution.

Common mistake
Decrementing after the jump check can yield an extra iteration. Step the first two loops in the CPU Emulator to verify.
