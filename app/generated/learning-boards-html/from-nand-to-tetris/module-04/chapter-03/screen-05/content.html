Module 4 › Chapter 4.3 › Conditionals
Definition
If x > y then z = x else z = y
Translate comparisons into ALU results and use conditional jumps to route execution.
@x
D=M
@y
D=D-M   // D = x - y
@IF_TRUE
D;JGT   // If x > y, jump to IF_TRUE

@y      // else: z = y
D=M
@z
M=D
@END
0;JMP

(IF_TRUE)
@x      // z = x
D=M
@z
M=D

(END)
@END
0;JMP
Explanation
  • Compute x minus y in D. Sign of D determines comparison result.
  • Use D;JGT to jump when x is greater; otherwise fall through to else code.
  • After executing one branch, unconditionally jump to END to avoid executing the other branch.
Concrete example
Use this pattern to choose a maximum value, to clamp results, or to route input handling depending on a key code range.
Pro tip

Write small unit tests: set known values for x and y, step to the compare, and confirm the jump decision matches the expected relation.
