Module 4 › Chapter 4.3 › Patterns
Initialization
Set counters, address pointers, and temporary variables before entering loops.
Loop Body
Perform the core operation each iteration: add, write to screen, copy, or test conditions.
Conditional Checks
Use ALU results and conditional jump instructions to branch and exit loops.
I/O Actions
Write to SCREEN or read KBD as part of the loop body to interact with users.
Subroutines
Encapsulate repeated sequences by saving return addresses and jumping to named labels.
Testing
Verify each pattern in the CPU Emulator before composing them into larger programs.
