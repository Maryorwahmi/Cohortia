Module 4 › Chapter 4.3 › Applied Milestones
01 — Factorial in assembly
Write an assembly program that computes n! for small n and stores the result in RAM[0]. Verify each iteration and boundary conditions.
Success check
  • Walk the first two iterations by hand.
  • Set breakpoints at loop entry and verify the counter update.
02 — Keyboard echo
Continuously read the keyboard memory address and display the ASCII code or character on the screen. Test by pressing keys and observing the update.
Success check
  • Confirm D=M at keyboard returns zero when idle.
  • Ensure screen writes refresh after each key press.
03 — Subroutine convention
Implement a caller that stores a return address on a software stack, jumps to a routine, and restores the return address to return correctly.
Success check
  • Trace call and return addresses in memory.
  • Confirm program counter returns to caller after the routine ends.
04 — Debug an off-by-one
Use the CPU Emulator to find why a loop runs one extra time by stepping to the conditional jump and inspecting the counter and its updates.
Success check
  • Break at the jump and inspect the counter value each iteration.
  • Try moving the decrement before or after the check to observe effects.
