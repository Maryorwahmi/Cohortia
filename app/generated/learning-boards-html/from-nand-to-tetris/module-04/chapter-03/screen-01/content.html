Writing Assembly Programs
Learn loops, conditionals, subroutines, and memory-mapped I/O in Hack assembly.
Orientation

You will convert high-level control structures into labels, explicit jump checks, and register/memory operations. The chapter shows canonical patterns and debugging steps.

In this lesson
Patterns for loops and conditionals, memory-mapped screen and keyboard I/O, subroutine call patterns, and CPU Emulator debugging practices.
Explore Key Topics
Loops
Label + conditional jump create iterative loops and countdowns.
I/O
Screen writes and keyboard reads use specific RAM addresses for memory-mapped I/O.
Debugging
The CPU Emulator lets you step, inspect registers and set breakpoints to validate loop behavior.

Assembly Patterns
