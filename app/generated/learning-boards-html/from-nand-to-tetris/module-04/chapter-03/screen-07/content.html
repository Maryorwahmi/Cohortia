Module 4 › Chapter 4.3 › Keyboard I/O
Definition
Read a key with a single memory access
Use @KBD and D=M to poll for a key press. Nonzero D means a key was pressed.
Polling snippet
@KBD
D=M     // D = ASCII code of pressed key (0 if none)
Use case — Keyboard echo
Continuously read KBD; when D is nonzero, write the code to the screen buffer or convert it to a displayed symbol. Test by pressing keys while stepping the emulator.
Misconception

Keyboard reads do not return strings. They deliver a single code per read and your program must assemble sequences if you need full input lines.

Practical check
In the CPU Emulator watch the KBD memory address as you press keys; verify D becomes the expected ASCII code before you write it out.
