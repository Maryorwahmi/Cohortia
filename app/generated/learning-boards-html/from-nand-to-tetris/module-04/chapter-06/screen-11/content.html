Assessment Idea › Two-stage compilation
Why use VM as an intermediate?
Four practical advantages you can test and argue for.
Modularity
Develop and test compiler and VM translator independently to reduce debugging scope.
Portability
Retargeting to new hardware only requires a new VM translator, not a rewrite of the compiler.
Simplicity
The compiler emits a cleaner semantic representation without low-level machine concerns.
Optimization
The VM translator can apply machine-specific optimizations after the compiler has ensured semantic correctness.
Assessment prompt
Explain why, if hardware changes, only the VM translator must be rewritten under the two-stage design. Provide a concrete example of what would change in the assembly output.
