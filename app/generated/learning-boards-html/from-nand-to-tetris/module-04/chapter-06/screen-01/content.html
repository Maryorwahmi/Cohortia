From Jack to Hardware
A guided overview of the full translation pipeline

You will use Jack as the high-level source, build a compiler that emits VM code, translate VM into assembly, then assemble into machine code. Each step simplifies the responsibilities of the previous step so tools remain modular and testable.

Why high-level languages help, the cost of abstraction, and how compilation stages divide the work.
