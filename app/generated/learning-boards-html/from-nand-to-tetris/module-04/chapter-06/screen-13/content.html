Common Mistakes › Tracing errors
Where students commonly stumble
Four frequent issues and how to detect them early.
Label resolution
Ensure labels in assembly match those referenced by translated VM code or are emitted as relocations for the linker.
Segment mapping
Check that local, argument, this, and that segments map to the correct base addresses in assembly.
Stack pointer errors
Small off-by-one mistakes in SP updates cause corrupted values; test push/pop sequences explicitly.
Calling conventions
Verify how return addresses and frames are set up so function returns restore state correctly.
Practical tip
Start with the smallest possible test: a single function that returns a constant. If that works, incrementally add complexity until the bug appears.
