Compilation pipeline
A stable, testable sequence from Jack source to execution.
Compact pipeline diagram
Jack source code (.jack)
  → Compiler (Module 7) → VM code (.vm)
  → VM Translator (Modules 5-6) → Assembly code (.asm)
  → Assembler (Module 4) → Machine code (.hack)
  → Computer (Modules 1-3) → Execution
Use this as a checklist when you compile and run a sample program through each stage.
Concrete example
A small Jack routine that reads two numbers and prints their sum will appear in VM code as explicit push and call commands. The VM translator maps those commands to assembly that manages memory segments and the stack pointer. The assembler turns that assembly into numeric opcodes the simulator executes.
Key Takeaway
Two-stage compilation increases modularity and portability: change only the VM translator for a new target.
