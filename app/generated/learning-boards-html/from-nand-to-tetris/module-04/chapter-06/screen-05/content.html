Process Flow › Toolchain stages
Toolchain steps
1. High-level source
Human-readable Jack programs with classes, methods, and variables.
2. Compiler
Generates VM code that captures program semantics but remains machine-independent.
3. VM translator
Converts VM code to assembly for the target hardware.
4. Assembler
Encodes assembly into machine code object files.
Final stages and roles
5. Linker
Combines object files, resolves external references, and produces an executable image.
6. Loader
Loads the executable into memory, sets the initial state, and starts execution on the computer simulator.
Why stage separation matters
Separation simplifies each tool's implementation and testing. It also supports portability because only parts tied to the hardware need changes when the target changes.
