Module 4 — Assembler
Turn assembly into machine code and produce object files for testing.

Implement stack arithmetic and translate VM code into assembly for the assembler to consume.
Module 7 — Compiler

Key Takeaway
Build small, test often, and use each completed stage as a foundation for the next to reduce complexity and speed debugging.
