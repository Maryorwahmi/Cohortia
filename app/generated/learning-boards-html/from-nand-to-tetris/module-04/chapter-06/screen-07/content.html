Definition › Why high-level languages help
Key abstractions
Variables and types
Name data and rely on the type system to catch mismatches instead of manual address arithmetic.
Control structures
Express loops and conditions directly, improving clarity and reducing errors.
Functions and modularity
Encapsulate behavior and permit reuse, testing, and clearer APIs within the program.
Practical example
Building Tetris in Jack, you model pieces as objects with methods to move and rotate. The compiler and VM handle how that logic maps to stack operations and machine instructions.
Key Takeaway
Abstractions let you focus on problem-solving. Compiler layers then turn those abstractions into efficient machine operations.
Misconception check
Abstractions do not prevent optimization; they let optimizers work on representations that capture intent more clearly than assembly does.
