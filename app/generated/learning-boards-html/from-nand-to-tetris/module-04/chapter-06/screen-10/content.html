Hands-on walkthrough
Follow these steps and observe the outputs at every stage.
Step 1: Jack source
Write the program that reads two integers and prints their sum. Keep the code minimal so you can trace it easily.
Step 2: Compile to VM
Run the Jack compiler to produce VM code and inspect push, pop, call, and arithmetic commands.
Step 3: Translate VM → Assembly
Observe how stack pointer and segment references become explicit in the assembly sequences.
Step 4: Assemble and run
Assemble to machine code and run in the simulator. Compare runtime behavior and outputs.
Reflection
Record what changed between VM and assembly: memory segment names, explicit pointer arithmetic, and label naming conventions are common points of interest.
