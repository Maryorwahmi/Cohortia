Architecture › Jack language features
Language surface
Designed to be small, clear, and mappable to VM primitives.
Classes and methods
Support modularity and object-oriented organization for games and OS code.
Types and arrays
Integers, booleans, and array constructs with predictable runtime representations.
Control flow
If, while, and for constructs map to combinations of labels, comparisons, and jumps at lower levels.
Compiler mapping
How Jack constructs become VM operations.
Example mapping
A Jack method call generates VM call and function-frame management. A local variable maps to the local segment; array access becomes pointer arithmetic plus indirect memory references.
Key Takeaway
Jack's feature set is intentionally chosen so a student compiler can generate correct VM code while still enabling real projects like games.
