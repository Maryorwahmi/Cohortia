Comparison › Assembly vs High-Level
High-Level Languages
Features that help developers: variables, functions, control structures, and data types.
Productivity
Less code and clearer intent make development and maintenance faster.
Portability
Compiler and VM layers allow the same source to run on different hardware.
Assembly
Low-level representation mapping closely to machine instructions and addresses.
Control and efficiency
Precise register use and instruction order can produce tight, efficient code when needed.
Complexity cost
Manual management of registers and addresses increases the chance of bugs and reduces maintainability.
Concrete example
A loop in Jack uses a simple while construct; the equivalent assembly requires counters, explicit jumps, and careful register allocation.
Key Takeaway
Prefer high-level languages for complex programs; reserve assembly for targeted optimizations or hardware control.
