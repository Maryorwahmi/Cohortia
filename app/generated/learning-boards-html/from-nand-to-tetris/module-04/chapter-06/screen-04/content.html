Definition › What is the assembler?
Assembler defined
A translator that turns assembly mnemonics and labels into machine code and relocation data.
Core responsibilities
  • Encode instructions into the machine's binary format.
  • Resolve labels into addresses or emit relocation entries for the linker.
  • Produce object files that the linker can combine.
Common misconception
Assemblers are often thought to optimize code; in reality, they usually perform straightforward translation, leaving optimizations to compilers and later tools.
Key Takeaway

The assembler's predictability makes it a reliable last step before linking and loading; errors are usually encoding or address-resolution mistakes.

Illustrative example
Assembly snippet (conceptual)
LOOP_START:
  // decrement counter and jump if not zero
  DEC R0
  JNZ LOOP_START
The assembler replaces LOOP_START with a numeric address and encodes DEC and JNZ into opcode bits.
Scenario to try
Compile a small assembly loop with labels, run your assembler, and inspect the object file for correct address offsets and encodings.
