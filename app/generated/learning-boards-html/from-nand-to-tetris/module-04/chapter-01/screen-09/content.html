ALU flags
The ALU sets zero (zr) and negative (ng) flags after computing. Jump bits evaluate these flags to choose control transfer.
  • 000 — null (no jump)
  • 001 — JGT (out > 0)
  • 010 — JEQ (out = 0)
  • 011 — JGE (out >= 0)
  • 100 — JLT (out < 0)
  • 111 — JMP (always)
Scenario check
Suppose ALU output is -1 (negative): JLT and JNE will be true. If output is 0, JEQ and JGE and JLE are true depending on bit patterns. Use A as the target address and ensure it contains the intended destination before the jump check.
Key Takeaway

Jump bits do not compute; they inspect ALU flags and conditionally update the program counter from A.
