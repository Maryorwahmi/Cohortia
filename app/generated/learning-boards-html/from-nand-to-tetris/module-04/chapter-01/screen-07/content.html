What comp does
Selects the ALU operation. Often these are small arithmetic and logical primitives used in programs.
Common comp codes
  • 101010 — 0
  • 111111 — 1
  • 001100 — D
  • 110000 — A (or M when a = 1)
  • 000010 — D + A
  • 010101 — D | A
Practice example
Translate operation: D = A - 1
Find comp code for A-1 -> 110010
Set a = 0 (uses A), comp = 110010, dest for D -> 010, jump -> 000
Full bits: 111 0 110010 010 000
Common mistake

Confusing A with M when a is wrong. Always set a correctly before choosing comp that references M.
