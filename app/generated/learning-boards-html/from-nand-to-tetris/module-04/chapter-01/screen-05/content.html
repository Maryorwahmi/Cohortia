Module 4 › Chapter 4.1 › A-instruction format
Structure
Leading 0 then 15 bits encoding a numeric value. CPU loads the 15-bit value into A.
Use: load constant or set address for RAM access
Padding rule: always write the value in binary and pad with leading zeros to reach 15 bits.
Example translations
@5   -> 0000000000000101
@42  -> 000000000101010
@0   -> 0000000000000000
@32767 -> 0111111111111111
Errors to avoid
  • Forgetting to pad to 15 bits produces the wrong binary length.
  • Setting the first bit to one turns the word into a C-instruction.
  • Using a value > 32767 exceeds the A-instruction range.
Pro tip

Write the decimal value, convert to binary, then pad to 15 bits before adding the leading zero.
