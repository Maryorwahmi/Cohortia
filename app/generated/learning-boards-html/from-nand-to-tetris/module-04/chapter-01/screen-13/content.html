Module 4 › Chapter 4.1 › Key Concepts
Machine language
Binary 16-bit words are the CPU’s input; type bits determine interpretation.
A vs C instructions
A: 0 + 15-bit value. C: 111 + a + comp + dest + jump.
Fields and decoding
Comp selects ALU op; dest stores; jump tests flags to change PC.
Summary
Use the instruction type first, then parse or construct a, comp, dest, and jump to map between assembly and machine code reliably.
