Module 4 › Chapter 4.1 › Machine language as bits
What an instruction is
A 16-bit word in memory. The CPU reads it and uses fixed bit positions to decide actions.
Type bit: first bit decides A vs C
Fields: value or control words follow the type bits
Hardware mapping: bits map directly to signals for registers, ALU, and PC
Common misconception
Bits are not arbitrary labels; moving a bit changes meaning. Treat each position as part of the instruction’s grammar.
Concrete examples
A-instruction example:
0000000000000101  // @5  -> load value 5 into A

C-instruction start:
111 a cccccc ddd jjj  // compute, store, jump
Key Takeaway

The instruction type bit(s) determine the decoding path; remaining bits have strictly assigned roles.
