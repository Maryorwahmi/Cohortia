Dest bit meanings
Three bits select A, D, and M as destinations. Use combinations to write to multiple places in one instruction.
000 — null (discard ALU output)
001 — M
010 — D
111 — AMD (all destinations)
Example scenarios
If you want to copy D into memory at address A, use dest 001 and ensure A contains the target address. To increment a value and keep both A and D updated, use dest 101 or 111 depending on which registers you need.
Key Takeaway

Dest bits are simple but powerful for combining storage actions with computation in a single instruction.
