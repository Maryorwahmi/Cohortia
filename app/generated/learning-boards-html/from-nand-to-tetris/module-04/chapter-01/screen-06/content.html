Module 4 › Chapter 4.1 › C-instruction structure
Bit fields and roles
111 — identify C-instruction
a — ALU y input selector (0: A, 1: M)
comp (6 bits) — ALU operation control word
dest (3 bits) — where ALU output is stored
jump (3 bits) — PC update condition based on ALU flags
Quick reference
Format:
111 a cccccc ddd jjj

Example fields:
a = 1  // use M as ALU input
comp = 110111  // M+1
dest = 010  // write to D
jump = 000  // no jump
Key Takeaway

C-instructions pack ALU control, destinations, and jump logic into a single 16-bit word so the CPU can compute and update state in one cycle.
