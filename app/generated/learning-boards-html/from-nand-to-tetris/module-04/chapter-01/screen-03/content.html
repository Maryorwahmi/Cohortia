01 • Envelope
Bits are the CPU's envelope
Every instruction is a sealed pattern. Practice opening that envelope by identifying the type bit first, then reading remaining fields.

02 • Flag
Remember the a bit flags memory usage
If a equals one, the ALU reads memory at A instead of register A. That single bit flips the ALU input source.

03 • Map
Map comp bits to ALU operations
Use the comp table to translate operations like D+1 or A-1 into 6-bit codes and test your mapping with one example each time.

04 • Decoder
Decoder routes bits to action
The CPU inspects leading bits to decide whether to treat the instruction as an address load or as ALU control signals and jumps.
