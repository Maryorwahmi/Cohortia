Module 4 › Chapter 4.1 › CPU decoding & trade-offs
Decoder principle
Check reserved bits to choose a decoding path. Simple checks reduce hardware complexity and latency.
Implementation blocks
  • Type detector (leading bits)
  • ALU control generator (comp and a)
  • Register write gating (dest)
  • PC update logic (jump + flags)
Design trade-off
Reserving bits keeps decoding cheap but reduces immediate width. Hack uses 15-bit immediates to match its memory size.
Key Takeaway

Simple decoders favor reserved type bits; the resulting immediate limits are an acceptable trade-off in small architectures like Hack.
