Module 4 › Chapter 4.1 › Binary to Assembly
Parsing steps
  1. Check leading bits: 0 -> A-instruction, 111 -> C-instruction.
  2. If A-instruction: convert the remaining 15 bits to decimal for @value.
  3. If C-instruction: read a (1), comp (6), dest (3), jump (3).
  4. Map comp bits to operation, dest bits to destinations, jump bits to condition names.
Worked example
Binary: 1110110000010000
Split: 111 0 110000 010 000
Interpret: a=0, comp=110000 -> A, dest=010 -> D, jump=000 -> null
Assembly: D=A
