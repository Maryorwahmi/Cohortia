A-instruction
0 + 15-bit value — loads A register
C-instruction
111 + a + comp(6) + dest(3) + jump(3)
You will translate assembly to binary and back, and see how the CPU decodes fields to perform actions. Practice will show why the leading bits are reserved and how limited bit widths shape memory and instruction design.

Instruction Type
A vs C
A-instruction uses a zero prefix. C-instruction uses three ones and separates control bits.
Fields
comp, dest, jump
Comp determines ALU operation; dest chooses registers; jump uses ALU flags.
A-instruction example:
@5  ->  0000000000000101

C-instruction example:
D=M+1 -> 1111 110111 010 000
