Module 4 › Chapter 4.1 › Translate D=M+1
Step-by-step
  1. Instruction type: C-instruction — start with 111.
  2. Set a = 1 because comp uses M.
  3. Lookup comp: M+1 -> 110111.
  4. dest = D -> 010. jump = null -> 000.
  5. Concatenate: 111 1 110111 010 000.
Result
Machine code:
1111110111010000

Grouped:
111 1 110111 010 000
