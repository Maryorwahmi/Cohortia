Parsing steps
  1. Open and read the input .asm file into lines.
  2. Strip comments (text after //) and trim whitespace.
  3. Skip empty lines.
  4. Classify instructions and extract fields with accessor methods.
def advance():
  line = next_raw_line()
  line = remove_comment(line).strip()
  if not line: continue
  if line.startswith('('): type = 'L_INSTRUCTION'
  elif line.startswith('@'): type = 'A_INSTRUCTION'
  else: type = 'C_INSTRUCTION'
Examples to test
  • • Leading tabs and spaces mixed with code.
  • • Lines like "D=M // comment" that include inline comments.
  • • Label lines such as "(LOOP)" that must not increment ROM address.
Misconception
Skipping comment removal is easy to miss and leads to wrong ROM addresses because labels are recorded for the next actual instruction.
