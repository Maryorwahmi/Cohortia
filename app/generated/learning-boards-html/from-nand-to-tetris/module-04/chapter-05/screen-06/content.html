Module 4 › Architecture › Modules
Module responsibilities
Parser
Cleans lines, identifies instruction type, extracts symbol or dest/comp/jump fields for each instruction.
SymbolTable
Stores symbol → address mappings, preloads predefined symbols, supports add and contains operations.
Code
Holds comp/dest/jump translation tables and returns fixed-width bit strings for each mnemonic.
Testing strategy
  • Unit-test Code mappings to ensure each mnemonic maps to the correct bits.
  • Feed sample lines to Parser to verify whitespace and comment handling.
  • Verify SymbolTable add/get semantics and initial predefined entries.
Design tip
Keep symbol resolution logic in SymbolTable and keep Parser focused on structure. This reduces bugs where addressing is accidentally computed twice.
Why this helps
Modular code simplifies debugging and allows isolated unit tests for each concern.
