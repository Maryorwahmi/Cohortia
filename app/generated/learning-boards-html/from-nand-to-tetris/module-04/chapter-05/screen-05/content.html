Command-line contract
Program receives a single .asm filename and writes a .hack file with 16-bit lines.
  1. Accept single command-line argument: input .asm file.
  2. Produce output file with .hack extension, same base name.
  3. Write one 16-character string of 0s and 1s per instruction line.
  4. Handle A-instructions, C-instructions, labels, and variables.
Check
Run: assembler Prog.asm → produces Prog.hack; inspect file length and a few sample lines to confirm format.
Common CLI mistakes
  • • Not trimming comments and blank lines, shifting ROM addresses.
  • • Writing binary lines with wrong width or missing leading zeros.
  • • Failing to create output file if path handling is incorrect.
