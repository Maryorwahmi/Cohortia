Symbol categories
  • • Predefined symbols: constants and memory-mapped I/O addresses supplied by the spec.
  • • Labels: declared with parentheses; give a ROM address for the next instruction.
  • • Variables: user-defined names assigned RAM addresses starting at 16 on first use.
Rule
First pass records label → ROM address. Second pass assigns variables when encountered, starting from 16.
Concrete scenario
If the code uses a symbol @count before you see a label (LOOP), two-pass ensures count is either a predefined symbol, a previously allocated variable, or assigned now. If you used a single pass, forward label references could not be resolved without complex backpatching.
Common bug
Off-by-one when recording label addresses: labels label the next instruction, not the line containing the label itself.
