Suggested test progression
Add.asm — basic opcodes
Max.asm — labels and jumps
Rect.asm — variables & screen memory
Pong.asm — full program stress test
When a diff appears
Decode the binary line and trace it back to the assembly instruction and symbol resolution that produced it.
Debug checklist
  • Check parser output for that instruction.
  • Dump symbol table and confirm symbol addresses.
  • Verify Code mappings for comp/dest/jump.
Key Takeaway

Automate line-by-line comparisons and unit-tests; escalate tests from Add to Pong to uncover subtle bugs.
