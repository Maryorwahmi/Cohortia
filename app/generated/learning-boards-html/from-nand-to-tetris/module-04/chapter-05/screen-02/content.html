Learning Objectives
Skills to show by finishing the assembler
Bloom: Learn → Understand → Apply → Master
01
Complete the Assembler
Build a CLI that reads a .asm file and writes a .hack file of 16-bit instructions. Verified competency milestone: run Add and produce identical .hack output.
02
Test on Multiple Programs
Validate behavior on Add, Max, Rect, and Pong. This proves correctness across small and large inputs. Verified competency milestone: Pong runs without assembler differences.
03
Explain Assembly vs Machine
Describe how A- and C-instructions map to bit fields, and why labels and symbols exist. Verified competency milestone: explain a sample A-instruction translation.
04
Reflect on Tool-Building
Articulate why a program that writes programs matters and how cross-assembly works. Verified competency milestone: one-page reflection submitted.
