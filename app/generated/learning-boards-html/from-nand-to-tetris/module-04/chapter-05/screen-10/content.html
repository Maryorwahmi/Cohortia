First pass: label collection
Scan cleaned instructions, increment ROM addresses for concrete instructions, and add label symbols without incrementing.
Algorithm
  1. rom_address = 0
  2. For each line: if label → add_entry(symbol, rom_address)
  3. Else → rom_address += 1
Quick test
Write a short program with two labels and three instructions; assert recorded addresses match indices of the instructions that follow the labels.
Key Takeaway

The first pass does not emit code; it only records label addresses so forward references are resolvable in the second pass.
