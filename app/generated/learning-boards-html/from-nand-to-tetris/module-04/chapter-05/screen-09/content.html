Module 4 › Translation › C-instructions
Encoding pattern
C-instruction → 111 comp(7) dest(3) jump(3)
Example walkthrough
Assembly: D=M
111 [compBits for M] [010] [000]
Testing tips
  • • Unit-test Code.comp on each mnemonic, including A vs M variants.
  • • Unit-test Code.dest for all dest combinations like MD, AM, AMD.
  • • Test jump encodings for JEQ, JGT, JLE, etc., and empty jump equals 000.
Misconception
Swapping dest and jump fields or forgetting the 111 prefix will produce invalid machine instructions that the Hack CPU will not execute as intended.
