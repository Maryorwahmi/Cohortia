Module 4 › Emission › Second Pass
Second pass steps
  1. Reset parser; set ram_address = 16.
  2. For each A-instruction: if numeric → write binary; else lookup/allocate symbol then write address in binary.
  3. For each C-instruction: compute comp/dest/jump bits and write 111 + bits.
# writing an A-instruction
if symbol.isdigit(): address = int(symbol)
else:
  if not symbol_table.contains(symbol):
    symbol_table.add_entry(symbol, ram_address)
    ram_address += 1
  address = symbol_table.get_address(symbol)
out.write(f"{address:016b}
")
Pitfall and check
Ensure ram_address begins at 16 and that predefined symbols are present to avoid collisions. After writing the file, check total lines equal the number of non-label instructions encountered in the first pass.
Misconception
Allocating variables in the first pass or including labels as instructions will produce wrong addresses; separation of passes prevents this.
