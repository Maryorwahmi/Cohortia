Build the Hack Assembler
A lab walkthrough that takes you from spec to tested tool.

You will implement a command-line assembler that accepts a .asm file and emits a .hack file. The project teaches parsing, symbol management, bit-level encoding, and robust testing. This tool is the first program you write in this course that manipulates other programs as data.

In this lesson
Walk through the assembler spec, module structure, two-pass algorithm, code mapping, and practical testing on Add, Max, Rect, and Pong.
Spec
Input .asm → output .hack; 16-bit lines; handle labels and variables.
Implementation
Parser, SymbolTable, and Code modules. Python recommended for concise handling.
Testing
Start with Add, then Max, Rect, and finish with Pong as a stress test.
Tool flow
Assembler (your program) → .hack file → Hack CPU executes.
Implement this flow repeatedly as you test on small then large programs. Each successful run demonstrates that your assembler maps textual instructions to the exact 16-bit encodings the Hack hardware expects.
Explore Key Topics
Parsing
Split lines, ignore comments, classify A/C/L instructions.
Symbol Table
Remember label addresses and allocate variables starting at RAM[16].
Testing
Compare your .hack output with reference files; use Pong to pressure-test correctness.
