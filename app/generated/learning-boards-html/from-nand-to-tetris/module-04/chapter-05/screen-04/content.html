Module 4 › Assembler Concept › Definition
Definition and claim
An assembler translates assembly into machine code; it parses, resolves symbols, and encodes instructions.
  • • A-instruction: address value encoded as 16-bit binary with high bit 0.
  • • C-instruction: encoded with 111 prefix + comp + dest + jump bits.
  • • Labels allocate ROM addresses during the first pass, variables during the second pass starting at RAM[16].
Analogy
Think of the assembler as a translator that knows both languages: human mnemonics and machine bit patterns.
Concrete example
Assembly: @17 → Machine: 0000000000010001
Misconception
It is not enough to replace names with numbers. The assembler must parse instruction fields, handle whitespace, ignore comments, and perform two passes to handle forward label references.
Key Takeaway
An assembler must both understand structure and produce exact bits; build tests that check both parsing and encoding.
