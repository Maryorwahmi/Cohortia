Implementation quick reference

Labels vs variables
Labels recorded in pass one map to ROM addresses; variables allocated from RAM address 16 in pass two.
A-instruction rule
Numeric @value → prefix 0 + 15-bit binary. Symbolic @value → lookup address in symbol table.
C-instruction rule
Parse dest, comp, jump. Use Code tables and assemble 111 + a + comp + dest + jump.
Final takeaway

Work incrementally, test with the provided programs, and use symbol-table dumps to debug address-related errors efficiently.
