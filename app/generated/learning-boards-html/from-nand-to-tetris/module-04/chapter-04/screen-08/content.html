C-instruction parse & encode

Parsing rules
Split on '=' for dest and on ';' for jump. If '=' missing, dest is empty. If ';' missing, jump is empty. The remaining middle part is comp. Use the Code module to map each fragment to bits.
Assembly example
D=A
dest→D, comp→A, jump→(none). Lookup comp bits for A, dest bits for D, then assemble 111 + a + comp + dest + jump.
Combining bits
The output layout is fixed. Start with the 3-bit opcode 111, then the a bit, then the 6-bit comp field, the 3-bit dest, and the 3-bit jump. Test individual table entries frequently to ensure correctness.
Misconception check: comp, dest, and jump are not variable-length fields; the assembler must always produce the exact bit widths required by the Hack machine.
Pro tip

Separate parsing from code lookup: return a structured instruction (dest, comp, jump) and then translate with your Code module for easier testing.
