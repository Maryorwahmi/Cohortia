A-instruction translation

Rules
  • If @value is numeric: convert to 15-bit binary, prefix with 0.
  • If @value is a symbol: look up in the symbol table and emit its address as binary.
  • If a new variable symbol appears in the second pass: allocate next RAM address starting at 16.
Common mistake: forgetting to left-pad the binary to 15 bits. Always format numbers to 15 bits before prefixing with 0.
Example conversion (conceptual)
# Conceptual Python-style pseudocode for conversion
value = 2
binary15 = format(value, '015b')  # yields '000000000000010'
instruction = '0' + binary15     # full 16-bit word
print(instruction)                # '0000000000000010'
Test with @0, @1, and a symbol @i. If i is new, during the second pass assign i → 16 and then emit 0000000000010000.
