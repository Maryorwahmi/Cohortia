File I/O and passes

High-level steps
  1. Read .asm, remove comments/whitespace, collect instruction lines.
  2. First pass: use Parser to add labels to SymbolTable with ROM addresses.
  3. Second pass: translate instructions, allocate variables from 16, emit binary lines.
  4. Write each 16-bit word as a separate line to a .hack file.
Example: cleaning input
// comment line
   @2   // set A to 2
D = A

(LOOP)
@LOOP
0;JMP
After cleaning: lines become meaningful tokens only. This prevents address miscounts in the first pass.
Debugging tip
Print the cleaned line list and the symbol table after pass one. If your produced .hack differs from reference, compare binary lines and inspect which instruction caused the discrepancy; then check symbol addresses and code lookup results.
