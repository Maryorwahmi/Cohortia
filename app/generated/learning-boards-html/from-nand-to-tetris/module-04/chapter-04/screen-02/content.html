Learning Objectives

Master the assembler pipeline, symbol handling, and translation rules so your assembler produces verified .hack files for test programs.

01
Explain the two-pass architecture
You will explain why one pass discovers labels and a second pass emits machine code, ensuring forward references are resolved. This understanding prevents incorrect single-pass assumptions that miss forward-label addresses.
VERIFIED COMPETENCY MILESTONE
02
Implement A- and C-instruction translation
You will map numeric values and mnemonics to binary fields, producing correct 16-bit instructions using the specified comp, dest, and jump tables.
VERIFIED COMPETENCY MILESTONE
03
Build and manage the symbol table
You will initialize predefined symbols, record label addresses during the first pass, and allocate variable addresses starting at 16 during the second pass.
VERIFIED COMPETENCY MILESTONE
04
Structure the assembler modularly
You will separate Parser, Code, SymbolTable, and Main so each component is testable and reusable in future compiler work.
VERIFIED COMPETENCY MILESTONE
