Module responsibilities

Parser
Reads lines, strips comments/whitespace, and returns structured instruction objects: type, symbol/value, dest, comp, jump. Keep parsing deterministic to simplify the passes.
SymbolTable
Dictionary with methods: addEntry(symbol, address), contains(symbol), getAddress(symbol). Initialize with predefined symbols before pass one.
Code module
Lookup tables for comp, dest, and jump. Each lookup returns a fixed-width bit string used to construct the final C-instruction word.
Main
Runs pass one with Parser to fill SymbolTable with labels. Then runs pass two to translate each instruction using Code and SymbolTable and write the .hack file.
Practical layout
This separation helps you unit-test the Code module entries and print Parser outputs. If your binary output differs from reference, inspect the symbol table and parser output to isolate whether the bug is in parsing, symbol resolution, or code lookup.
