Symbol table contents

Predefined symbols
R0 → 0, R1 → 1, …, R15 → 15
SP → 0, LCL → 1, ARG → 2, THIS → 3, THAT → 4
SCREEN → 16384, KBD → 24576
Labels (first pass)
During pass one, when the assembler sees (LOOP) it sets LOOP → current ROM address. Example: (LOOP) at ROM address 4 adds LOOP → 4.
Variables (second pass)
When encountering @i where i is not in the table, assign i → next free RAM address starting at 16. Example: first @i → 16; first @sum → 17.
Misconception check: labels map to ROM addresses (instruction locations). Variables map to RAM addresses and should be allocated only in the second pass.
Practical tip

After the first pass, print the symbol table to confirm your labels and predefined symbols before running the translation pass.
