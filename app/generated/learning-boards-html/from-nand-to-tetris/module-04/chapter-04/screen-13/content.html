What to remember

Two-pass architecture
First pass: labels and predefined symbols. Second pass: translate and allocate variables.
Symbol table
Contains predefined symbols, label→ROM entries from pass one, and variables assigned from RAM address 16 in pass two.
Modular pipeline
Parser, Code, SymbolTable, Main — keep responsibilities separate for easier testing and reuse.
Summary takeaway

Two passes plus a clear symbol lifecycle and modular design make the assembler reliable and easy to debug.
