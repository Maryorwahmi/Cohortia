Testing and common errors

Common mistakes
  • Counting comment lines as instructions during pass one.
  • Allocating variables in the first pass instead of the second.
  • Incorrect or missing predefined symbols in the initial table.
  • Not zero-padding numeric A-instruction binaries to 15 bits.
Testing approach
Run your assembler on the provided programs and compare your .hack output to the references. When mismatches occur, print the cleaned instruction list, the symbol table after the first pass, and the parsed instruction that led to the differing binary.
Platform note
Variables allocate from RAM address 16 upward. In typical use you can expect roughly 240 simple variable slots before colliding with conventional stack starting areas; plan tests accordingly if your assembler will be run on very large programs.
