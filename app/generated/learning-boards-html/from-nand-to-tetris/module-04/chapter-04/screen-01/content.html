The Assembler: Design and Implementation

Translate Hack assembly into 16-bit machine code using a two-pass design. Learn symbol management, parser structure, and how to produce correct .hack output for testing and debugging.

In this lesson

What you'll build

An assembler that reads .asm, creates a symbol table, and writes a .hack file of 16-bit binaries. You will practice parsing, mapping mnemonics to bits, and handling symbols and variables.

Two-pass architecture
First pass finds labels; second pass emits code.
Symbol table
Predefined symbols, labels, then variables from address 16.
