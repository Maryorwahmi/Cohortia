Assembler responsibilities

Formal definition

Translate assembly text into 16-bit binary instructions, resolve symbols to addresses, and write one binary instruction per line to a .hack file.

Why it matters
  • Validates the CPU and instruction set you built.
  • Introduces parsing and code generation concepts used in compilers.
  • Teaches symbol management and memory allocation strategies.
Key Takeaway

An assembler is more than text replacement: it must resolve addresses, manage names, and generate bit-accurate output for the CPU to run.

Concrete example
@2
D=A
@3
D=D+A
@0
M=D
This assembly becomes these machine-code lines:
0000000000000010
1110110000010000
0000000000000011
1110000010000000
0000000000000000
1110001100001000
Misconception check: numeric @values map directly to addresses; symbols require lookup. If you replace every symbol by an immediate number you will produce incorrect code when labels are referenced before definition.
