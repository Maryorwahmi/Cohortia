Core Concept Computer Chip
Computer: ROM + CPU + Memory
Top-level wiring creates a working stored-program machine.
Specification (HDL)
CHIP Computer {
  IN reset;

  PARTS:
  ROM32K(address=pc, out=instruction);
  CPU(inM=inM, instruction=instruction, reset=reset,
      outM=outM, writeM=writeM, addressM=addressM, pc=pc);
  Memory(in=outM, load=writeM, address=addressM, out=inM);
}
This HDL snippet shows the exact signal names used to connect the three chips.
Checks to run
  • Load a simple add program into ROM and step through a few cycles.
  • Verify pc advances unless a jump occurs; check instruction matches ROM output.
  • When writeM is 1, confirm Memory stores outM at addressM.
Key takeaway: composition + signal naming accuracy yields a functioning system.
