Process Flow Testing the Computer
Using the Hardware Simulator
Typical test scripts
  • Add two numbers and verify RAM[2] contains the sum.
  • Conditional jumps: verify PC changes when a jump condition is true.
  • Screen writes: check that screen memory words are written.
Debugging steps
  1. Run emulator on the machine code to confirm program logic.
  2. Run hardware test script and trace the instruction and signals.
  3. Inspect writeM, addressM and outM for failed writes.
