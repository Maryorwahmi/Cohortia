Definition Memory mapping
Memory: RAM16K, Screen, Keyboard
Address ranges
  • 0..16383 → RAM16K
  • 16384..24575 → Screen (8K)
  • 24576 → Keyboard (single address)
Use dmux to route load and mux to select out depending on address.
Testing tips
Write unique values to sample RAM and screen addresses, then read them back. Confirm keyboard address reads reflect simulated key state and is not writable.
Common mistake: off-by-one address checks or wrong bit-width in address decoding.
