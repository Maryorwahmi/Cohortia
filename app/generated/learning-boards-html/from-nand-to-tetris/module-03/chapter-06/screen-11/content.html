Add 2 + 3 and Loop forever
Add program (assembly)
// Add 2 + 3
@2
D=A
@3
D=D+A
@0
M=D

// Loop forever
(END)
@END
0;JMP
Run this first in the emulator; then load into ROM and step through the hardware simulator to watch memory update.
What to observe
  • After D=D+A, D holds the sum; after @0 followed by M=D, RAM[0] stores the result.
  • After jump to END, pc holds the label address and remains there in the infinite loop.
