Core Concept ALU Input Selection
Selecting A or M for the ALU
Mux control
A C-instruction bit selects ALU input: when set, use M (inM); otherwise use A register. This implements memory-based operations.
Test sequences: D=D+M and D=D+A should produce different results if RAM[addr] differs from A.
Routing ALU output
  • Destination bits decide whether ALU output goes to A, D, M (outM) or any combination.
  • When outM is written, Memory must update addressM with the correct address for the write.
Common mistake: forgetting to connect ALU output to outM when M is a destination, causing writes to be stale or zero.
