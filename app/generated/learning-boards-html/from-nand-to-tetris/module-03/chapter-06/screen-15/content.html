Key Concepts What to Remember
System Composition
ROM + CPU + Memory wired together create the stored-program computer.
CPU Complexity
Instruction decode, register loads, ALU selection and PC logic must be correct.
Memory Mapping
Use address ranges to route loads and outputs to RAM, screen, or keyboard.
