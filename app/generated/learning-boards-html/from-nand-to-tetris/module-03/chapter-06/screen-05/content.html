Architecture CPU Interface
CPU Inputs & Outputs
Formal interface
<!-- Representation for clarity -->
CHIP CPU {
  IN inM[16], instruction[16], reset;
  OUT outM[16], writeM, addressM[15], pc[15];
}
inM and outM carry 16-bit data; addressM chooses which memory word the CPU accesses.
Why each signal matters
  • writeM: when high, causes Memory to store outM at addressM; check this to validate writes.
  • pc: selects the next ROM address; control logic chooses increment, load, or reset.
  • inM: the only way the CPU reads memory contents; stale inM yields incorrect ALU inputs.
Common-mistake
Confusing addressM bit-width or miswiring writeM can silently prevent writes without other visible errors. Always observe these signals in early tests.
