Process Flow Instruction Types & Registers
A vs C Instructions and Register Loads
Instruction type detection
  • If bit 15 = 0 → A-instruction: A ← instruction[0..14].
  • If bit 15 = 1 → C-instruction: decode ALU controls, destinations, jumps.
Test: fetch an A-instruction and check A's new value equals the immediate.
Register load logic
  • A register: loads immediate (A-instruction) or ALU output (C-instruction with A as destination).
  • D register: loads ALU output when C-instruction destination includes D.
  • PC: increment, load A for jump, or reset to zero.
Common mistake: not multiplexing ALU vs immediate for A-register loads.
Example
Run sequence: @5 (A←5), D=A, @10 (A←10), A=D. Watch A change both from immediate and from ALU result when destination bits target A.
