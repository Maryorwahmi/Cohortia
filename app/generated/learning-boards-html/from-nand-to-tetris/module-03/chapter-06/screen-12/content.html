Hands-on Activity Multiply & Fill
Multiply by repeated addition; Fill screen on key
Multiply outline
  1. Load RAM[0] multiplicand into D.
  2. Load RAM[1] multiplier into A or temp register.
  3. Loop: add multiplicand to accumulator, decrement multiplier, jump until zero.
  4. Store result into RAM[2].
Fill program behavior
Continuously read keyboard (address 24576). If non-zero, write 0xFFFF to addresses 16384..24575; otherwise write 0x0000. Runs in an infinite loop.
Debug tip
Simulate a key press and step through the program to see repeated writes to the screen addresses; watch writeM and addressM change as the loop iterates.
