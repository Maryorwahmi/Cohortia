Module 3 › Chapter 3.1 › The Hack Computer

A teaching example of von Neumann

A simple practical machine that exposes the core ideas for tracing and design exercises.

Memory layout
  • Data RAM: 16K words
  • Instruction ROM: 32K words
  • Screen and keyboard are memory-mapped
Registers
A register: holds addresses or values. D register: holds data used by the ALU. PC: points to the next instruction.
Practical teaching notes
Although instruction memory and data memory are presented separately, the logical programming model treats instructions as words you can reason about like data.
Memory-mapped I/O simplifies device interaction for exercises and tracing.
Key Takeaway

The Hack computer is a didactic von Neumann CPU with small memory regions and memory-mapped I/O, ideal for tracing the fetch-execute cycle and register states.
