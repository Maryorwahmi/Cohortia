Module 3 › Chapter 3.1 › Common Misconceptions

Clarify common confusions

Recognize and correct frequent misunderstandings to build reliable mental models.

Misconception: Instructions ≠ Data
Reality: In von Neumann both are memory words. Distinguish the instruction word from the resulting runtime values when tracing programs.
Misconception: One instruction does everything
Reality: Instructions are deliberately small; complex behavior emerges from instruction sequences executed rapidly.
Misconception: Hack split memory breaks von Neumann
Reality: The split is a teaching simplification. The logical model treats instructions as words and the Hack demonstrates von Neumann principles plainly.
Fix: Trace small examples
Write or step through short instruction sequences and record PC, register, and memory state after each execution to build confidence.
Pro Tip

Annotate each instruction with its address and expected register changes before running a trace. Predicting state forces precise reasoning and exposes gaps.
