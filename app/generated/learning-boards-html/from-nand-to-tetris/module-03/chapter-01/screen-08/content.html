Programs are stored like data

This single idea is responsible for reprogrammable, general-purpose machines and the software industry that followed.

What it enables
  • Programs can be saved, copied, and transmitted like data.
  • One machine can run many different programs over time.
  • Programs can be generated or transformed by other programs, enabling compilers.
Constraints and safety
Although self-modifying code is possible because programs are data, modern practice favors immutable code regions and controlled loading for security and maintainability.
Key Takeaway

Storing instructions as data is the single most important idea behind general-purpose computing and software portability.
