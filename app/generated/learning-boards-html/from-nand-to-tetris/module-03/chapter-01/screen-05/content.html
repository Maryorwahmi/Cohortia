ALU, Control Unit, and Registers

How the CPU computes and how it decides what to compute next.

Component roles
ALU
Performs arithmetic and logical operations requested by instructions.
Control Unit
Fetches, decodes, and issues control signals to coordinate CPU, memory, and I/O.
Registers
Small fast storage that holds operands, addresses, and intermediate results.
Concrete example
In Hack: A holds an address or value, D holds a data value. An addition instruction uses D and A as inputs to the ALU, and the sum is stored back into D or memory as directed.
Register vs memory
Registers are fast and few. Memory is larger and slower. Misusing registers or treating them like abundant storage hurts performance and complicates instruction design.
Quick checklist
  • Identify which registers hold addresses and which hold data.
  • Recognize that control signals enable ALU operations and memory access.
  • Remember that register pressure affects how compilers allocate variables.
Key Takeaway

The CPU's ALU does the math, the control unit orchestrates instruction flow, and registers give the CPU immediate working storage.
