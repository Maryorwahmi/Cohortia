The von Neumann Architecture

A conceptual model where a single addressable memory holds both program instructions and the data they operate on. This simple idea enables general-purpose, reprogrammable computers.

In this lesson
  • Identify CPU, memory, I/O and bus and how they interact.
  • Understand the stored-program concept and why programs are data.
  • Trace the fetch-execute cycle for a simple instruction sequence.

Components
CPU, memory, I/O and bus roles.
Stored Program
Programs live in memory as data.
Fetch-Execute
The CPU loop that runs instructions.
Architecture snapshot
Memory
Addressable store for instructions and data
Each memory location has a unique address. Programs are stored here as words.
CPU
ALU, control unit, registers
Performs arithmetic and controls instruction sequencing.
I/O
Screen, keyboard, disk, network
Interfaces for external communication; often memory-mapped on simple designs.
Bus
Communication pathway
Carries addresses, data, and control signals between components.
Why this matters
Because storing programs as data lets the same hardware run any software, it enabled modern software engineering, distribution, and universal machines. Later screens will show the fetch-execute loop and a hands-on trace for a short program.
