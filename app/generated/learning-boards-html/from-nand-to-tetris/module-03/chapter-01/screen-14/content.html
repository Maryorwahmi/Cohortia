Key Concepts

Three concise concept cards to keep top of mind.

von Neumann architecture
Memory, CPU, I/O and a bus form the basic structure of most general-purpose computers.
Stored-program concept
Programs are stored in memory as data, enabling reprogrammability and persistence.
Fetch-execute cycle
The CPU repeatedly fetches, decodes, executes an instruction, then updates the program counter.
Summary: Use these three ideas to explain how a program runs and why memory design and CPU structure influence performance and flexibility.
