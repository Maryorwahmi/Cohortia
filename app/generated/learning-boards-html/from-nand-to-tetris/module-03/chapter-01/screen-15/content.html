Practical reminders

Three final compact cards and a reflective prompt.

CPU roles
ALU computes, control unit sequences, registers hold working values used by instructions.
Hack specifics
Remember A, D, PC, 16K RAM, 32K ROM, and memory-mapped screen/keyboard as a practice platform.
Hybrid processors
Modern CPUs mix unified memory with separate instruction and data caches to reduce contention while preserving programmability.
Reflection: Given a workload that alternates heavy instruction fetches with large data transfers, which mitigation would you choose and why? Consider instruction caches, wider memory buses, or prefetching as options.
