Module 3 › Chapter 3.1 › The Fetch–Execute Cycle

The CPU's recurring loop

Small instructions are fetched and executed in a tight loop under control of the program counter.

1
Fetch
CPU reads the instruction from the address in the program counter. This supplies the raw instruction bits for decoding.
2
Decode
The control unit interprets the instruction opcode and prepares control signals for ALU and memory.
3
Execute
ALU performs arithmetic or logical operations; memory reads or writes occur; branches are evaluated.
4
Update PC
PC is incremented or set to a new address for jumps so the next fetch reads the correct instruction.
Trace example
If instruction at address 10 loads a constant into A: fetch reads word at 10; decode recognizes 'load immediate'; execute writes the value into A; update PC sets PC to 11. During that cycle memory, A register, and PC change predictably.
Misconception check
Don't assume instructions perform large complex tasks. Complex behavior arises from many small instructions executed rapidly.
Key Takeaway

Every instruction follows fetch, decode, execute, and PC update; tracing these steps reveals how the CPU changes state during a program.
