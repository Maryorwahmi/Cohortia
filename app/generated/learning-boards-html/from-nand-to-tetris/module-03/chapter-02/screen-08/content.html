Hierarchy

RAM and special regions

  • RAM[0..15]: predefined R0..R15
  • RAM[16..255]: general-purpose variables
  • RAM[256..2047]: stack
  • RAM[2048..16383]: heap
Why this matters

Knowing these ranges helps you place variables correctly and avoid corrupting the stack or heap when writing low-level code.

Screen & Keyboard

I/O as memory

Screen: addresses 16384–24575 (8K words) map to a 256×512 bitmap. Keyboard: address 24576 holds the ASCII code of the pressed key.
Screen calculation
256 rows × 32 words/row × 16 bits/word = 8,192 words covering 256×512 bits.
Misconception

Don’t assume writing to screen memory changes ROM; ROM remains read-only. Screen writes are plain RAM stores in the reserved range.
