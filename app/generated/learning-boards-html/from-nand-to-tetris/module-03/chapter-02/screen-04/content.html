Definition

A, D, and M explained

A is a 16-bit register used for addresses or values. D is a 16-bit data register for arithmetic. M stands for the memory cell at address A, i.e., RAM[A].

A register
Address or immediate value, 16 bits.
D register
Data workspace for ALU operations.
M (RAM[A])
Shorthand: the memory cell pointed to by A.
Common mistake

Treating A as persistent data after using it to point at memory. Save A to D when you must keep its value across an address change.

Example
// Load 5 into A, copy to D, then store D into RAM[0]
@5      // A = 5
D=A     // D = 5
@0      // A = 0
M=D     // RAM[0] = 5
Why it matters

This small set of registers makes the hardware simple and teaches how software must manage limited state explicitly.

Key Takeaway

Use A when you need an address. Use D to save values across address changes. M reads or writes RAM at A.
