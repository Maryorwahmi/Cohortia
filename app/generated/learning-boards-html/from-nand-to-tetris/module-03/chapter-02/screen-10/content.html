Module 3 › Chapter 3.2 › A vs C instructions
A-instruction

0 followed by 15-bit value

Used to load a value into A. Example: @3 → 0000000000000011.

Behavior
Sets A to the given value. Does not change D or write memory by itself.
Check

Can you write the 16-bit word for @10? Convert 10 to 15-bit binary and prefix a zero.

C-instruction

111 a cccccc ddd jjj

Performs computation, writes results, and optionally jumps. The fields control ALU inputs, outputs, and branching.

Example

D=D+A → 111 a comp dest jump with a=0, comp bits for add, dest set for D, jump=000.

Misconception

Not every C-instruction performs a jump. Jump bits can be all zeros meaning no jump; dest bits control storage separately.
