The Hack Computer Architecture

Explore a purposely minimal computer: two programmer-visible registers, a small ALU, a clear memory map with memory-mapped I/O, and two 16-bit instruction formats that encode data and control.

In this lesson
Registers, memory map, and instruction format
You will trace code, translate assembly to machine code, and reason about jumps using ALU flags.
Why it matters
Minimal hardware reveals core design trade-offs
Fewer registers means a simpler CPU but more careful programming.
Coming up
Example: add two constants and write to RAM
We will translate the assembly to binary and run a mental trace of the PC and registers.
Explore Key Topics
Registers and ALU
How A, D, and the ALU work together to compute and select results.
Memory map
RAM ranges, ROM for instructions, and memory-mapped screen and keyboard.
Instruction formats
A-instruction for addresses/values and C-instruction for computation, destinations, and jumps.
Visual concept
A register
Holds address or value (16 bits)
D register
Dedicated data register used by the ALU for computations.
M = RAM[A]
A convenient shorthand meaning: the memory word located at the address stored in A.
This simplified model shows how a reduced set of registers and a predictable memory map make machine-level behavior easier to reason about while teaching the same principles used in larger architectures.
