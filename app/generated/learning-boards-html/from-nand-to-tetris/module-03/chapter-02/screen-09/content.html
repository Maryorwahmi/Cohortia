Instruction memory

ROM: 32K words

ROM holds the program code at addresses 0..32767. The CPU fetches instructions from ROM using the program counter.

Program Counter (PC)
PC contains the ROM address of the next instruction. Normal flow increments PC; jumps load PC from A.
Flags used for jumps

The ALU sets zr and ng flags. The jump field uses these flags to decide whether to load PC from A.

Example flow
  1. Fetch instruction at ROM[PC].
  2. Decode and execute it.
  3. If a jump condition holds, PC := A; otherwise PC := PC + 1.
Check

Only C-instructions with jump bits set can change PC directly. A-instructions simply set A.

Key Takeaway

PC and ROM implement program sequencing; jumps change PC by loading it from A when the ALU flags meet the jump condition.
