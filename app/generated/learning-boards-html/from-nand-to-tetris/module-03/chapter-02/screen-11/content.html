ALU flags

zr and ng

zr is true when ALU output equals zero. ng is true when the output is negative. Positive is represented by neither flag set.

JEQ → zr
JGT → not ng and not zr
JGE → not ng
JLT → ng
JNE → not zr
JLE → ng or zr
JMP → unconditional
Implementation note

A small combinational logic block maps the three jump bits and the two flags to a PC-load signal. No extra comparator hardware is required.

Example

To jump when two values are unequal, compute their difference in the ALU and set jump bits for JNE. If the result is nonzero, zr will be false and JNE triggers because it is the "not zero" condition.

Check

When encoding jumps, always choose a comp that produces a value whose sign or zero-ness matches the condition you want to test.

Key Takeaway

Two ALU flags plus three jump bits let the machine express seven conditional jumps and no-jump with very little hardware.
