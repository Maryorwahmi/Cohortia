Module 3 › Chapter 3.2 › A-instruction
Format

0vvvvvvvvvvvvvvv

The leading 0 bit marks an A-instruction. The remaining 15 bits form the value loaded into A. This is an immediate load.

Example encoding
// @5 becomes: 0 00000000000101
0000000000000101
Misconception

An A-instruction does not write to RAM. It only changes A. Memory writes require a C-instruction that sets M as a destination.

Practical pattern

Common sequence: use @address to set A, then use a C-instruction to read or write M or to compute using A and D. For example, @10; D=M reads RAM[10] into D.

Check your understanding
  • Does @X change RAM? No, it sets A only.
  • How do you write a value into RAM[A]? Use a C-instruction with dest including M.
Key Takeaway

A-instructions load an immediate 15-bit value into A. Use C-instructions to move values from registers into memory.
