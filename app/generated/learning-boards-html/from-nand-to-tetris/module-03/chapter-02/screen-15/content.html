A vs C
A: 0+value. C: 111 + fields. Decide format first when encoding.
Registers reminder
A holds address/value. D is data. M = RAM[A]. Save A to D if you need it later.
Jump logic
Use zr and ng flags with the 3-bit jump field to implement conditional branching.
Final takeaway

The Hack architecture shows how a small set of bits and registers implements all key behaviors of a computer. Master the small tables, and larger architectures become easier to understand.
