Module 3 › Chapter 3.2 › Example: add 2 + 3
Assembly
// Add 2 + 3 and store the result in RAM[0]
@2      // A = 2
D=A     // D = A (D = 2)
@3      // A = 3
D=D+A   // D = D + A (D = 5)
@0      // A = 0
M=D     // RAM[0] = D (RAM[0] = 5)
Machine words (example encoding)
0000000000000010  // @2
1110110000010000  // D=A  (example comp/dest/jump bits)
0000000000000011  // @3
1110000010010000  // D=D+A
0000000000000000  // @0
1110001100001000  // M=D
Trace
  • After D=A: D = 2, A = 2.
  • After @3 and D=D+A: D = 5, A = 3.
  • After @0 and M=D: RAM[0] = 5.
Concrete check

Confirm each A-instruction binary begins with 0 and C-instructions begin with 111. Verify only M=D writes to RAM.

Reflection

This simple program demonstrates how immediate loads and ALU operations combine to compute and persist a result to memory.
