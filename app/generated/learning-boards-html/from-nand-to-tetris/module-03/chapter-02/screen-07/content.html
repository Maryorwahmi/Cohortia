Dest bits

Which targets receive the ALU output?

Three bits correspond to A, D, and M. Any combination can be selected to store the ALU result into those targets in a single instruction.

A
Overwrite A (changes pointer).
D
Save value for future ALU use.
M
Write RAM[A] with ALU output.
Pitfall

Overwriting A and expecting the old A to be used simultaneously. The ALU output is computed, then stored according to the dest bits in that cycle; plan writes accordingly.

Example combinations
  • DEST=010 — write to D only.
  • DEST=001 — write to M only (store to RAM[A]).
  • DEST=111 — write to A, D, and M simultaneously.
Scenario

If you need to compute an address and persist the value while keeping it in D for more math, choose dest bits to write both D and M, or AMD to mirror results.

Key Takeaway

Dest bits give you flexible storage: pick which of A, D, and M should receive the ALU result in a single, compact instruction.
