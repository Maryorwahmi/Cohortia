Module 3 › Chapter 3.2 › C-instruction: comp field
Format reminder

111 a cccccc ddd jjj

The leading triple ones mark a C-instruction. The a bit selects A versus M for the ALU input. The comp bits choose the operation.

a = 0
ALU uses A as second input.
a = 1
ALU uses M (RAM[A]) as second input.
Pro tip

When you encode arithmetic by hand, first pick the desired operation, then find the comp bits and set a accordingly. Keep a clear list of comp patterns.

Example operations
  • D+A — add D and A (a=0, comp bits for add)
  • D-M — subtract M from D (a=1, comp bits for subtract)
  • !D — bitwise not of D (comp bits for not)
Check
Remember: same comp bits with different a bit mean the ALU uses a different source for the second operand.
Key Takeaway

C-instructions encode both what the ALU computes and which operand to use via the a and comp bits. Learn the comp table to hand-encode operations reliably.
