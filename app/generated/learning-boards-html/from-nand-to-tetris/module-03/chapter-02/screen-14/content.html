Module 3 › Chapter 3.2 › Key Concepts
Registers (A, D, M)
A holds an address or value; D is the data register; M denotes RAM[A].
Memory map
RAM 0–16383; screen 16384–24575; keyboard 24576; ROM holds instructions.
Instruction formats
A: 0 + 15-bit value. C: 111 + a + comp + dest + jump.
Summary takeaway

The Hack architecture uses a minimal set of registers and compact instruction fields to teach the mapping from bits to computation and control. Master the small tables and practice hand-encoding to internalize the model.
