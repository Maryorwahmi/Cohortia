Module 3 › Chapter 3.2 › Hands-on Activity
Swap two values

Use RAM[2] as temporary storage. Steps: D=M (with A=0), @2; M=D, then load RAM[1] and write to RAM[0], finally restore RAM[1] from RAM[2]. Translate each step to machine words and verify.

Countdown

Initialize RAM[0]=10. Loop: write counter to RAM[i], decrement counter, increment i, and branch until zero. Implement loop control with jumps based on ALU flags.

Find max

Load RAM[0] and RAM[1], compute difference, and use a conditional jump to choose which value to store into RAM[2]. Translate each instruction to bits and simulate PC, A, D updates.

Verification strategy

Step through each instruction and record A, D, and RAM snapshots. Confirm A-instructions begin with 0 and that only C-instructions with M in dest write to RAM. Hand-encoding and tracing are the fastest path to finding mistakes.
