Fetch: PC → ROM

The ROM returns the instruction addressed by PC and that instruction is used for decode and execute in the same cycle.

Mechanics
PC drives ROM address
Address lines carry PC to ROM; ROM output is the fetched instruction.
Instruction stable for cycle
ROM output is available at the cycle start and used for decode and execute.
One memory access per cycle
Hack cannot fetch and access RAM simultaneously; this is a key simplification.
Example fetch
// PC = 0
ROM[0] → @5   // instruction read at cycle start
// decode sees A-instruction
Common misconception

Believing the CPU can fetch an instruction and perform an unrelated RAM read in the same cycle. In Hack only one memory access occurs per cycle.

Key Takeaway

Treat ROM output at cycle start as the committed instruction for that entire cycle.
