Key Concepts — Part 2

Three compact operational reminders for reliable tracing.

Read vs Write
Reads occur before update; writes occur at the clock edge.
Jump sequence
Load A, then execute a jump C-instruction that uses ALU flags.
von Neumann
Instruction and data share paths; no simultaneous ROM fetch and RAM access in Hack.
Final takeaway

When you trace, record pre-update inputs, compute ALU outputs and flags, then commit updates to get a correct per-cycle history.
