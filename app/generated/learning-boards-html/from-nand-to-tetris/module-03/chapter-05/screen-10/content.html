Step-by-step trace

A concrete program trace illustrating state updates across four cycles.

Program
@5     // Address 0
D=A    // Address 1
@10    // Address 2
D=D+A  // Address 3
We will record PC, instruction, A, D, and ALU output each cycle.
Cycle snapshots
Cycle 1: PC=0, fetch @5 → execute sets A=5, update PC=1
Cycle 2: PC=1, fetch D=A → ALU forwards A(5) to D, update D=5, PC=2
Cycle 3: PC=2, fetch @10 → execute sets A=10, update PC=3
Cycle 4: PC=3, fetch D=D+A → ALU computes 5+10=15, update D=15, PC=4
Key Takeaway

Record the fetched instruction and the update results per cycle to avoid mixing pre-update and post-update values.
