Chapter 3.5 › A-instruction

A-instruction execution

Load a 15-bit value into A and advance the PC.

Example
// Address 0
@5     // A-instruction, value=5
// Execute result at update: A = 5, PC = 1
Key Takeaway

A-instructions update only the A register and the PC; they are not ALU operations.

When A is used

The newly loaded A value may serve as an address for M, as an ALU input, or as the target for a later jump instruction.

Common misconception

Expecting the A-instruction to alter D or M directly. It only sets A; other instructions perform writes to D or M.
