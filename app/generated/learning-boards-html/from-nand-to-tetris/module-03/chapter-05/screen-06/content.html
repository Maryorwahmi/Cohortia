Decoding A vs C

Check bit 15 to choose the instruction format and then extract control fields for C-instructions.

Decode rule
A-instruction (bit15 = 0)
Remaining 15 bits are a literal value to load into A.
C-instruction (bit15 = 1)
Contains a-bit, comp bits, dest bits, and jump bits used during execute.
C-instruction fields
a-bit
Selects ALU second input: A or M.
comp
ALU operation to perform.
dest
Where to store ALU result: A, D, and/or M.
jump
Condition for loading PC from A using ALU flags.
Common mistake

Mixing up a-bit and jump bits; remember the a-bit chooses ALU input, jump bits use flags to decide PC behavior.

Key Takeaway

Write decoded fields next to a C-instruction to clarify what will execute and which destinations will be affected.
