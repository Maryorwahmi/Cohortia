Definition

I/O as memory locations

The CPU accesses devices by reading and writing addresses in the same memory space. No special opcodes are required.

Advantages
  • Simple CPU design: reuse load/store logic.
  • Uniform addressing: same modes for memory and devices.
  • Flexible expansion: add devices by reserving addresses.
Key Takeaway

Memory-mapped I/O trades a bit of programmer arithmetic for much simpler hardware; devices behave like memory words.

Concrete example and misconception
Example:
Writing M = D to address 16384 sets 16 pixels controlled by that word. The same instruction that writes a variable in RAM now updates the screen.
Misconception:
Memory-mapped I/O does not remove the need for address math. You still compute which word and which bit represent a single pixel; the difference is the access mechanism.
Why this matters:
Uniformity reduces CPU complexity and makes device access part of the normal programming model, enabling flexible device additions and straightforward simulation.
