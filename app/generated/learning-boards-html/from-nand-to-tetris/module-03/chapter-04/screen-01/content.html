Memory and I/O: Screen and Keyboard

Explore how the Hack computer maps a 256×512 monochrome screen and a keyboard into RAM, and how the complete Computer chip lets programs draw and read input using ordinary memory operations.

In this lesson
Understand memory-mapped I/O, compute screen addresses and bits, read keyboard codes, and assemble the CPU+Memory+ROM wiring.
Why it matters
You will directly control pixels and sense key presses using the same instructions used for RAM. This reduces hardware complexity.
Coming up
Examples: pixel address math, a program to draw a middle line, and reading the keyboard register.
Explore Key Topics
Screen Map
16384–24575: 8K words, each word controls 16 pixels.
Keyboard
Address 24576. Reads return ASCII or 0 if no key.
Computer Chip
CPU + Memory + ROM wired so programs can fetch and read/write memory-mapped devices.
Visual Concept
Memory City: Screen billboard and Keyboard sensor
Imagine the 16K memory as a city. The screen district occupies a continuous block of addresses; each word is a short billboard controlling 16 lights. The keyboard is a single sensor reporting the last pressed key. Programs are painters and couriers that write to these addresses.
Key Takeaway
Memory-mapped I/O lets the CPU use ordinary memory instructions to update the screen and read keyboard input, keeping the hardware simple and the programming model uniform.
