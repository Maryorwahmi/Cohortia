Hands-on Tasks
  • Compute base address for row 128: add 16384 + 128*32, then write 0xFFFF to 32 consecutive words to make a black horizontal line.
  • Poll the keyboard register at address 24576; when non-zero, display the ASCII code on the screen.
  • Use read-modify-write when changing individual pixels so you preserve other bits in the same word.
Quick example
To set the first pixel at row 0, col 0: address = 16384; bit = 0; write a word with bit 0 set. To set col 17: address = 16384 + 1; bit = 1.
Why these tasks?
They combine address arithmetic, bit masking, and simple control flow — core skills for low-level programming and hardware understanding.
