Module 3 › Chapter 3.4 › Key Concepts
Memory-mapped I/O
Devices are memory addresses and use the same load/store instructions as RAM.
Screen mapping
16384–24575: 8K words, 256×512 pixels, 1 word per 16 pixels.
Keyboard register
Address 24576 returns ASCII code or 0 when no key is pressed.
Summary
Use address math and read-modify-write to control pixels, and poll the keyboard register to detect input. The Computer chip wires ROM, CPU, and Memory so these operations become ordinary memory accesses.
