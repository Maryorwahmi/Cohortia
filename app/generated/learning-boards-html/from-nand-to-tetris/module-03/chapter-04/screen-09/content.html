Module 3 › Pixel Update › Process
Steps to change one pixel
  1. Compute wordIndex = row*32 + (col/16) and address = 16384 + wordIndex.
  2. Read M at that address into D.
  3. Create mask = 1 << (col % 16).
  4. Set: D = D | mask. Clear: D = D & ~mask.
  5. Write D back: M = D.
This preserves the other 15 bits controlled by the same memory word.
Analogy
Think of a word as a row of 16 light switches in a single box. To flip one switch you open the box, change the single switch, and close it again. Replacing the whole box would change all switches.
Common Mistake
Writing a mask directly to a screen address overwrites 15 neighboring pixels; always merge with the current word.
