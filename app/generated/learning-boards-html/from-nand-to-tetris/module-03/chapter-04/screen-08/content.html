Algorithm
  1. Compute base = 16384 + 128 * 32.
  2. Set D = 0xFFFF (all bits 1).
  3. Repeat 32 times: M = D; A = A + 1.
The loop writes full words so adjacent pixels join to form a continuous line.
Conceptual assembly outline
// compute base address for row 128
@16384
D = A
@128
D = D + A*32  // conceptual: compute 16384 + 128*32
@SCREEN_BASE
A = D
// set all bits
D = -1         // D = 0xFFFF
@COUNT
M = 32         // conceptual counter
(WRITE_LOOP)
M = D           // write 0xFFFF
@NEXT
A = A + 1       // advance to next word
...             // decrement counter and loop
Note: This outline is conceptual; the simulator uses standard Hack assembly instructions to implement arithmetic and looping.
