Module 3 › Design Trade-offs › Comparison
Memory-mapped I/O
  • Pros: simple CPU, uniform addressing, easy device addition.
  • Cons: software must do address and bit math; single register semantics may require polling.
Separate I/O instructions
  • Pros: concise software for device ops, potential performance gains.
  • Cons: more complex CPU, new opcodes per device, less flexible expansion.
In the Hack design, the educational value of seeing memory and I/O unified outweighs the added software arithmetic complexity.
