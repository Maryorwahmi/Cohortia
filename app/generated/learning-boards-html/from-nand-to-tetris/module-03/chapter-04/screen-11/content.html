Module 3 › Computer Chip › Architecture
Components
  • ROM32K: instruction memory, addressed by PC.
  • CPU: executes instructions, outputs addressM, outM, writeM, and accepts inM.
  • Memory: RAM16K plus screen and keyboard memory-mapped ranges.
Reset initializes the PC so the ROM fetch begins at the program's start address.
HDL snippet
CHIP Computer {
    IN reset;

    PARTS:
    ROM32K(address=pc, out=instruction);
    CPU(inM=inM, instruction=instruction, reset=reset, outM=outM, writeM=writeM, addressM=addressM, pc=pc);
    Memory(in=outM, load=writeM, address=addressM, out=inM);
}
This HDL shows the direct wiring: the CPU drives the Memory using the same address and write signals used for ordinary RAM operations, which makes the screen and keyboard accessible through the same path.
