Address math
word = 16384 + row*32 + column/16; bit = column % 16.
Read-modify-write
Read the word, update one bit, write it back to preserve other pixels.
Keyboard polling
Read address 24576 repeatedly; on non-zero value handle the key, then wait for zero to detect a new press.
Final takeaway
These simple rules let you draw and respond to user input using ordinary memory operations in the Hack computer.
