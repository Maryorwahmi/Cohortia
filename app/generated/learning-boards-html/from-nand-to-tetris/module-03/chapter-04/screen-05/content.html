Module 3 › Screen Map › Process
Specs

256 × 512 pixels

Total pixels: 131,072. Memory words: 8,192. Relationship: 1 word controls 16 pixels, so each row uses 32 words.

Address range
16384 — 24575 (inclusive) — exactly 8,192 words reserved for the screen.
Step-by-step: compute pixel word and bit
Step 1 — Word address
wordIndex = row * 32 + (column / 16)
Step 2 — Bit position
bit = column % 16
Final address
address = 16384 + wordIndex
Example
Row 0, Col 17 → wordIndex = 0*32 + 1 = 1 → address = 16385. Bit = 1. Writing bit 1 to that word sets the pixel at column 17.
Common Mistake
Using column/16 without integer division or using 16-bit index offsets incorrectly will place pixels in the wrong word.
