Keyboard register behavior
Address
24576 — read-only. Returns ASCII code of the currently pressed key or 0 if none.
Printable and special codes
Printable characters return standard ASCII values. Special keys occupy extended codes: newline 128, backspace 129, left arrow 130, up arrow 131, right arrow 132, down arrow 133, and further control codes up to function keys.
Common pattern
Poll address 24576 in a loop. When read value != 0, act on it. If you need a single-press detection, wait for the value to return to 0 before resuming detection.
Example
A program can repeatedly read the keyboard register; when the value is non-zero, it copies the ASCII code to a known screen location so the character becomes visible.
Misconception
Treating the keyboard as a FIFO stream is wrong. It is a live snapshot; your code must poll and implement buffering if desired.
