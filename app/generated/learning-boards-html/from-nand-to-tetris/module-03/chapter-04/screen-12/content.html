Module 3 › Memory Layout › Hierarchy
Address map
0 — 16383: general-purpose RAM (8K words).
16384 — 24575: screen memory (8K words).
24576: keyboard register (single word).
Capacity math
Total screen pixels = 256 × 512 = 131,072.
Screen words = 8,192. Ratio = 8,192 words / 131,072 pixels = 1 word per 16 pixels.
Why this matters
Reserve addresses and avoid accidental overwrites. Plan where data and graphics live to prevent corruption of the display area.
