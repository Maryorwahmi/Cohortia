Polling pattern
// conceptual loop
(READ_KEY)
@24576
D = M         // D contains keyboard code or 0
@READ_KEY
D; JEQ         // if zero, jump back and keep polling
// D != 0: handle key
@DISPLAY_ADDR
M = D         // store code for display routine
// optionally wait for release
(WAIT_RELEASE)
@24576
D = M
@WAIT_RELEASE
D; JNE        // loop until keyboard returns 0
This outline shows the polling loop and a simple debounce that waits for the key to be released before continuing detection.
Display strategies
Display the raw ASCII as a number by converting digits and drawing them to the screen.
Or map printable ASCII to a bitmap font and draw the character pixels at a chosen screen location.
Key Takeaway
Polling is simple and works for small programs. For more complex input handling you would add buffering or interrupts, but those are beyond the Hack design used here.
