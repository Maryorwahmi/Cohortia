Formulas
// Compute the word and bit for a pixel
wordIndex = row * 32 + (column / 16)
bit      = column % 16
address  = 16384 + wordIndex

// Example: row 0, col 17
// wordIndex = 0*32 + 1 = 1
// bit = 1
// address = 16384 + 1 = 16385
Run these calculations with integer division for column/16 and use modulo for the bit.
Write pattern example
To draw an entire row with black pixels, set each of the 32 words in that row to 0xFFFF. Below is a conceptual loop you can implement in Hack assembly using the A register and M destination.
// Conceptual assembly outline
@SCREEN_BASE   // A = 16384 + row*32
D = -1         // D = 0xFFFF (all bits 1)
(LOOP)
@i
D; JGT?         // loop control omitted - conceptual
M = D           // write 0xFFFF to memory[address]
@ADDRESS+1
...              // increment address and repeat 32 times
Pro tip
Use a simple loop counter set to 32 to write exactly the words that form one row.
