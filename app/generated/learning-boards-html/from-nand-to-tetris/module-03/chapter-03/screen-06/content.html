Module 3 › Chapter 3.3 › A vs C Instruction
A-instruction (type 0)

Format: 0 v v v ... (15-bit value). Action: load A with the 15-bit value, increment PC. Use case: set A to a constant address or data value.

Example: load A with 5, so subsequent M or A references use address 5.
C-instruction (type 1)

Format: 1 a cccc cc ddd jjj. Action: comp controls ALU, a selects ALU y input (A or M), dest bits choose where ALU output goes, jump bits decide PC update.

Example: a=0, comp=D+1, dest=D will compute D+1 and store it back in D.
Why timing matters
For a C-instruction that writes to M, the A register must already contain the correct RAM address from a prior A-instruction. Otherwise addressM would be wrong and the memory write would affect the wrong location. That sequencing is central to correct program behavior.
