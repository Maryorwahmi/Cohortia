Module 3 › Chapter 3.3 › Instruction Decode
Control signals produced
  • loadA for loading A (A-instruction or ALU->A destination)
  • loadD for loading D from ALU output
  • outM and writeM for writing ALU output to memory
  • ALU control bits derived from comp field
  • PC control: increment or load from A if jump condition is true
Concrete example
For a C-instruction with a=0, comp=D-1, dest=A and D, the decoder sets ALU to compute D-1, enables loadA and loadD so both registers capture the ALU result, and evaluates jump bits separately to decide PC behavior.
Misconception
Decoder with memory would make behavior path-dependent. Combinational logic ensures the same instruction yields the same outputs, independent of prior instructions.
Key Takeaway

Control logic is a straight mapping from instruction fields to control signals; no internal state is required or allowed.
