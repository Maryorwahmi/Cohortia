CPU HDL Signature
CHIP CPU {
    IN inM[16],         // Value from data memory (M)
       instruction[16], // Instruction from ROM
       reset;           // Reset signal
    OUT outM[16],       // Value to write to data memory
        writeM,         // Write to data memory?
        addressM[15],   // Address in data memory
        pc[15];         // Address of next instruction
}
This spec is your contract. Your HDL must wire internal chips to satisfy these inputs and outputs for every cycle.
Implementation notes
  • Use A and D registers, ALU, PC, muxes, and logic gates you already built.
  • Route inM to ALU y when a=1; otherwise use the A register.
  • Produce writeM and outM only when dest includes M.
Pro tip
Implement and test the datapath wiring first, then plug in the control logic. That isolates wiring bugs from decoding bugs.
