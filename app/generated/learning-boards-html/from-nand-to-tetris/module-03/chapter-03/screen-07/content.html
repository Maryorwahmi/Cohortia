Input selection

The D register always provides one ALU input. The instruction's a-bit selects whether the other ALU input is A or M. This selection controls whether the ALU operates on a register value or a memory value referenced by A.

Example: a=1 makes ALU inputs D and RAM[A]; a=0 makes them D and A.

Destinations and data flow
The ALU output can be routed to A, D, M, or combinations. When M is a destination, the CPU sets outM to the ALU output and asserts writeM. The external memory writes the value at addressM on that cycle.
Practical check
Trace the instruction that computes RAM[A] = D + RAM[A]. Confirm A contains the address and a-bit is 1 so the ALU reads RAM[A].
Key Takeaway

The a-bit chooses ALU input; dest bits decide where the ALU result is captured. Both are essential for correct operation.
