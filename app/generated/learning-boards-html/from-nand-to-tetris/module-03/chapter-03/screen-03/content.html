Module 3 › Chapter 3.3 › Skills
Core Tasks
  • Draw the full datapath showing A, D, ALU, PC, and memory buses; label where values come from and go to.
  • Derive the control signals from instruction bits: a, comp, dest, jump, and instruction type.
  • Write the CPU HDL using existing chips and the specified CPU interface.
  • Run the CPU Emulator tests with basic and then more complex programs that exercise jumps and memory writes.
Why these tasks matter

Drawing makes the flow of data explicit so you can reason about hazards and destinations. Combinational control logic keeps instruction decoding fast and predictable. HDL assembly reinforces modular design: the CPU is built from registers, the ALU, PC, and muxes you already implemented. Testing proves correctness and reveals edge cases such as jump conditions and multi-destination writes.
