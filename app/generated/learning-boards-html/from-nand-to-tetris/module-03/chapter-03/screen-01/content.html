The CPU: Datapath and Control Logic
Understand how instructions travel through registers, how the ALU is controlled, and how the PC advances or jumps.

We will map the physical datapath: A register, D register, ALU, PC, and memory connections. Then we will derive the combinational control logic that reads instruction bits and produces load, select, write, and jump signals. The goal is to build the CPU in HDL from the chips you already made and verify it with scripted tests.

Each topic here is practical: you will draw the datapath, write the HDL chip called CPU with the supplied interface, and run the CPU Emulator tests that step the machine cycle by cycle.

Datapath Overview
A register
Holds an address or data value; can load from instruction or ALU.
D register
Holds a data value that feeds the ALU as one input.
ALU
Performs arithmetic/logical operations controlled by comp bits.
PC & Memory
PC selects ROM address; A register selects RAM address.
Why this matters
A clear datapath and combinational control logic make the CPU deterministic and easy to test. Each instruction maps to explicit signals that drive one clock cycle of behavior.
