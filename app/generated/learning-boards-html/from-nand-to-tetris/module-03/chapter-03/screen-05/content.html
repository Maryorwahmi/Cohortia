Module 3 › Chapter 3.3 › Instruction Fetch
Fetch Steps
1
PC selects ROM
The 15-bit pc value addresses ROM.
2
ROM returns 16-bit instruction
Instruction bits become input to the control logic.
3
Control logic decodes
A vs C, and the fields a, comp, dest, jump are extracted.
Concrete example
If PC = 7 and ROM[7] contains a C-instruction, that instruction's bits immediately inform the ALU selection and destination enables for the same cycle. The PC will later be updated either by increment or by loading A if a jump occurs.
Misconception
Fetch is often mistaken for a multi-cycle operation; in this design the ROM read provides the full instruction in that cycle and decoding is combinational.
Key Takeaway

The fetched 16-bit instruction is the single source of control signals for that cycle; its top bit identifies A versus C type.
