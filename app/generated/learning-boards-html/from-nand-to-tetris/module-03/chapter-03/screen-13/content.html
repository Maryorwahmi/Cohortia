Module 3 › Chapter 3.3 › Testing: M = D
Per-cycle trace

Cycle 1: fetch A-instruction; decode and load A with immediate; PC increments.

Cycle 2: fetch C-instruction that writes M; decoder selects ALU operation and dest=M; ALU output becomes outM; writeM is asserted; addressM equals A; memory writes RAM[addressM] = outM.

Use the emulator's assertions to check after each cycle that the A, D, PC, outM, writeM, and addressM values match expected values.

Common failure modes
Wrong addressM routing, missing writeM during a store, ALU reading the wrong input because a-bit is wired incorrectly.
Key Takeaway

Emulator tests that check CPU state each cycle are the fastest way to find wiring or decoding errors.
