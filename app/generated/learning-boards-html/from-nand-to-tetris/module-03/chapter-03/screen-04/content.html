Module 3 › Chapter 3.3 › Datapath Components
Definitions
A register
Holds a 15-bit value that is used as an address for RAM or as a data value loaded from an A-instruction or from ALU output.
D register
Holds a data value that is one input to the ALU for computations.
ALU
Performs arithmetic and logical operations on D and either A or M, producing an output used by destinations and flags for jumps.
PC & Memory
PC selects ROM for instructions; A selects RAM address for data reads/writes. The CPU presents outM, addressM, and writeM to the memory system.
Concrete Example: M = D
Sequence to store D into RAM: A was previously loaded with the target address by an A-instruction; a C-instruction with dest=M causes the ALU to place the computed D value on outM; addressM carries A; writeM is asserted. The memory system performs the write on the following memory cycle.
Key Takeaway

Datapath components are modular: registers hold values, the ALU computes, and memory operations require the address, data, and write signal produced by the CPU.

Common misconception
The CPU does not directly write memory cells; it outputs address and data and sets writeM. The memory system completes the store.
