PC Behaviors
  • Increment by 1 for normal flow.
  • Load from A when a C-instruction's jump condition is satisfied.
  • Reset to 0 when reset is asserted.
Concrete example
A loop can be created by loading A with the loop address, then using a C-instruction that computes a value and sets jump bits so that when the condition is true, PC = A. If the condition is false, PC increments and execution continues.
Common oversight
For conditional jumps the ALU must compute a value that yields the correct flags in the same cycle; otherwise jump evaluation will be incorrect.
Key Takeaway

PC updates depend on jump evaluation using ALU flags. A must contain the jump target before a jump can succeed.
