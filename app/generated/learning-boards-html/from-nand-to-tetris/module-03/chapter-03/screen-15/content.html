Module 3 › Chapter 3.3 › Quick Reference
Wire clearly
Make buses and muxes explicit so ALU inputs and addressM/outM are unambiguous.
Decode combinationally
Map instruction bits directly to control outputs; avoid latching state in the decoder.
Test incrementally
Start with small programs and use per-cycle emulator checks to localize errors.
Keep these reminders visible while you design and test; they will shorten debugging and make the CPU design process systematic.
