Module 3 › Chapter 3.3 › Combinational Control
Why combinational?
Combinational logic ensures determinism, immediate response to instruction bits, and stable control signals during a clock cycle. Implement it using logic gates and muxes. The ALU flags (zero, negative) provide the extra inputs needed to evaluate jump conditions without adding state.
Contrast
A stateful controller would make control outputs depend on previous instructions, complicating reasoning and tests. The Hack CPU uses a combinational decoder to keep each instruction self-contained.
Concrete example
Given the same C-instruction presented twice under identical register and memory inputs, the decoder must generate identical control signals both times.
Key Takeaway

Combinational control keeps CPU behavior predictable and simple to verify; do not add state to the decoder.
