Module 3 › Chapter 3.3 › Build the CPU
Step-by-step
  1. Draw datapath and label all buses: ALU inputs, outM, addressM.
  2. Wire A and D registers to ALU and to destination load signals.
  3. Use muxes to select ALU y input (A vs inM) based on a-bit.
  4. Wire PC: increment or load from A depending on jump evaluation.
  5. Implement combinational decoder into control outputs and test with emulator scripts.
Starter program
Load A with 5; set D = A; set M = D. Verify outM and writeM when M is destination and that addressM equals A.
Pro tip
Test after each wiring change. The emulator's per-cycle checks make it easy to localize errors to decoding or wiring mistakes.
