Definition
String module structure
Fields of a String object
  • length — current number of stored characters.
  • maxLength — allocated capacity of the charArray.
  • charArray — pointer to a block allocated by Memory.alloc(maxLength).
Example
String.new(32) allocates a new object and calls Memory.alloc(32) for the character storage.
Memory implications
Because the charArray is a separate allocation, strings incur two allocations: one for the object header and one for the buffer. This is why explicit allocation and deallocation are required in the Jack OS.
Common Pitfall
Forgetting to set maxLength properly can lead to buffer overflows when appending characters.
Key Takeaway

Treat strings as objects with explicit allocation and predictable layout: length, capacity, and a char array pointer.
