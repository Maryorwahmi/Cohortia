readChar — Poll until press and release
Annotated code walkthrough. The code blocks below show the polling pattern described in the chapter. Note the explicit storage of c and the second loop waiting for release.
function char readChar() {
  var char c;
  // Wait for a key press
  while (Keyboard.keyPressed() = 0) {}
  let c = Keyboard.keyPressed();
  // Wait for key release
  while (~(Keyboard.keyPressed() = 0)) {}
  return c;
}
Why store immediately
Storing on press avoids missing fast presses that could occur between poll cycles.
Release detection
Waiting for release prevents repeated returns while a key is held down.
Step-by-step example
  1. Loop until keyPressed() != 0 — that is, detect the press.
  2. Read and store the ASCII code into local variable c.
  3. Loop until keyPressed() == 0 — detect the release.
  4. Return c so the caller receives one character per press.
Common Mistake
If you skip release detection, holding a key outputs the same character repeatedly.
Key Takeaway

The press-then-release polling pattern creates atomic key events on simple hardware.
