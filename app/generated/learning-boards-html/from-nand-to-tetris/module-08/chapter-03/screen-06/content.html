Definition
readLine and readInt
How readLine works (process)
  1. Display the prompt message to the output.
  2. Create a new String object with a maxLength.
  3. Call readChar repeatedly to append characters until Enter is detected.
  4. Return the constructed String to the caller.
Example
Call readLine("Name: ") and expect a String containing the user's typed name after Enter.
How readInt works (process)
  1. Display the prompt message.
  2. Read characters forming an integer, allowing an optional leading minus sign.
  3. Append digits into a String and then convert with intValue, or parse on the fly.
  4. Return the integer numeric value to the caller.
Practical note
Implementations often reuse String operations for collection and then call intValue to parse the result.
Check Your Understanding
Why prefer readInt to manual parsing when requesting a number?
Misconception
Assuming readLine always trims input; it returns exactly the collected characters up to Enter.
Key Takeaway

Use readLine/readInt for full user responses; implement validation if input may be malformed.
