Integer ↔ String conversions
setInt (integer to string)
  1. Handle sign: if negative, remember to prepend '-'.
  2. For positive absolute value, repeat: digit = value % 10; push digit as character; value = value / 10.
  3. Reverse collected digits to produce correct order and write into charArray.
Example: setInt(-123) builds characters '1','2','3' in reverse, then produces "-123" after reversal.
intValue (string to integer)
  1. Check for a leading minus to set sign.
  2. Initialize total = 0 and for each digit character do total = total * 10 + (digitValue).
  3. Return sign * total at the end.
Example: parsing "456" yields 4 then 45 then 456 by accumulation.
Key Takeaway

setInt and intValue are mirror algorithms: one extracts digits via division, the other accumulates via multiplication by ten.
