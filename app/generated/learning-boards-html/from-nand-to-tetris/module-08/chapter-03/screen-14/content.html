Key Concepts
Keyboard calls
keyPressed, readChar, readLine, readInt — choose based on blocking needs.
String layout
Strings: length, maxLength, charArray allocated with Memory.alloc.
Numeric conversions
setInt uses division and reverse; intValue uses multiplication and accumulation.
Keep these concepts in mind as you implement and test: release detection for readChar, explicit Memory.alloc for string buffers, and correct digit algorithms for conversions.
