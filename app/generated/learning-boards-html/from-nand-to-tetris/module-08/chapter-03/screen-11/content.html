Process Flow
Hands‑on: prompt, greet, add
Step sequence
  1. name = Keyboard.readLine("Name: ")
  2. Output.printString("Hello, "); Output.printString(name); Output.printString("!")
  3. a = Keyboard.readInt("First number: "); b = Keyboard.readInt("Second number: ")
  4. sum = a + b; s = String.new(12); s.setInt(sum); Output.printString(s)
Tip: choose a String buffer large enough for expected numeric ranges and remember to deallocate if your environment requires it.
Example scenario
User types "Ada" then presses Enter; the program prints "Hello, Ada!". Then user types "12" and "30"; the program prints "42" as the sum after converting and printing the result.
Common mistake
Not allocating a string large enough for setInt can truncate the printed result or cause buffer issues.
Key Takeaway

Combining keyboard helpers and string conversions creates concise interactive programs; validate buffer sizes and input assumptions.
