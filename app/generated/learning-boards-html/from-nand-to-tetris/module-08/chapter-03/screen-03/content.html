Objectives — Skills and Verification
Implement, test, and confirm
Keyboard implementation checks
  • Test keyPressed returns 0 when idle and ASCII code when pressed.
  • Test readChar returns a single char even if the key is held down.
  • Observe behavior to confirm release detection prevents repeats.
String implementation checks
  • Create a string with maxLength, append characters, and verify length increments.
  • Call eraseLastChar and ensure length decrements and char is removed.
  • Convert integers to strings and back to validate setInt and intValue.
Integration check
Write the prompt program: readLine for a name, print greeting, readInt twice, compute and print sum. Confirm correct parsing and output.
Why manual memory matters
Because the Jack OS has no garbage collector, you must allocate and deallocate explicitly; tests help reveal leaks or early frees.
