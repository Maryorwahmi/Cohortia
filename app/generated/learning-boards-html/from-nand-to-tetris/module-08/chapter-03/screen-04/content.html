Core Concept
Definition
What the Keyboard module offers
A compact API to check and read keystrokes: keyPressed, readChar, readLine, readInt.
keyPressed(): non-blocking — returns ASCII or 0 immediately.
readChar(): blocking — waits for press and release to return a single char.
readLine(message): prompt and return a line ending with Enter.
readInt(message): prompt and parse an integer from typed text.
Example
A game loop polls keyPressed to move characters without stopping the simulation.
Common mistake
Using readChar in a tight loop when you needed non‑blocking checks causes the program to freeze until a key is pressed.
Quick reference: behavior and use
  • keyPressed returns 0 when idle. Use it to poll for input without pausing your program.
  • readChar waits for a press and a release to ensure one character per physical press.
  • readLine combines prompts and collection of a sequence of characters until Enter.
  • readInt reads characters, parses an integer, and returns its numeric value.
Key Takeaway

Match your read method to whether the program must wait. Polling keeps things running; blocking reads are for direct interaction.
