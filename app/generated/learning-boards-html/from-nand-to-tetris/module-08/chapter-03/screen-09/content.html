Memory allocation pattern
Allocation sketch
// pseudo-code sketch
function String new(maxLength) {
  var String s;
  let s = Memory.alloc(OBJECT_SIZE);
  let s.length = 0;
  let s.maxLength = maxLength;
  let s.charArray = Memory.alloc(maxLength);
  return s;
}

function void disposeString(String s) {
  Memory.deAlloc(s.charArray);
  Memory.deAlloc(s);
}
This shows the two allocations: one for the object header and one for the character buffer returned by Memory.alloc.
Practical implications
  • Every new string consumes heap space twice: header and buffer.
  • Manual deallocation is mandatory to avoid memory leaks.
  • Reusing buffers or reserving a larger maxLength can improve performance.
Why it matters

Allocations are explicit in Jack; mindful allocation and deallocation are essential to robust programs.
