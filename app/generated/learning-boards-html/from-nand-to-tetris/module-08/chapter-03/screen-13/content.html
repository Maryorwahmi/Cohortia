Practice
Debugging strategies
Keyboard checks
  • Test keyPressed returns 0 when idle and non-zero when pressed.
  • Implement a press-and-hold test to confirm readChar yields one event per press.
  • Log intermediate values to verify press and release timing.
String checks
  • Append until full and check that further appends are rejected.
  • Verify charAt(i) matches expected characters after operations.
  • Test intValue and setInt with positive, negative, and zero values.
Practical Tip
Run small unit-style programs that exercise single functions. Isolate keyboard timing bugs first, then move to string allocation and conversion tests. This staged approach narrows down where the bug originates.
