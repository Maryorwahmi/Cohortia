What to Remember
Release detection
Always wait for the key to be released after reading it so a held key doesn't produce repeated characters.
Manage string memory
Use Memory.alloc for char arrays and deallocate when appropriate to avoid leaks.
Test boundaries
Check empty and full strings, negative numbers, and press-and-hold behavior to find edge-case bugs early.
Final takeaway
Combining careful keyboard handling with explicit string memory management gives you the foundation to build predictable interactive programs on the Jack platform.
