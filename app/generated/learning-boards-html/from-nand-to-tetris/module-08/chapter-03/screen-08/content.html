Process Flow
String operations
Append and index behavior
appendChar: if (length < maxLength) write charArray[length] = c; length++.
charAt(i): if (0 ≤ i && i < length) return charArray[i]; otherwise handle error.
Example
String.new(4); append 'a','b','c' results in length 3 and indices 0..2 filled.
Edge case
Appending when length == maxLength should be rejected or cause a controlled failure.
Erase and set operations
eraseLastChar: if length > 0 then length--. Optionally clear charArray[length] = 0 for safety. setCharAt(i,c): write only if 0 ≤ i < length or you may expand to i < maxLength depending on your design.
Misconception
Assuming setCharAt can increase length automatically. In Jack, changing length should be explicit to avoid silent buffer changes.
Key Takeaway

Implement bounds checks for every operation; do not rely on implicit buffer growth.
