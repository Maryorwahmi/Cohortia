Layer map
  • Logic → CPU → Memory

Reflection prompts
  1. How long did implementing the OS take?
  2. Which module was most challenging and why?
  3. How does it feel to run Tetris on your own computer?
Extension ideas

Consider adding a hardware multiplier, more memory, interrupts, or a floating-point unit. Each improves capability but increases complexity — reflect on trade-offs.

Key Takeaway

Turn your implementation experience into a written reflection that links practical challenges to system-level principles; this consolidates learning.
