Process › Testing Workflow
Testing sequence
  1. Run unit tests: MemoryTest, MathTest, StringTest.
  2. Fix unit failures using simulator traces.
  3. Run I/O tests: ScreenTest, KeyboardTest, OutputTest.
  4. Run integration games: Pong, then Tetris.
Example debugging loop
  1. Reproduce failing test and record trace.
  2. Inspect stack and memory to find mismatch.
  3. Make minimal code change and rerun tests.
  4. Document the failure and fix for future reference.
Key Takeaway

Good testing narrows the fault domain quickly. Use small reproducible cases and keep a change log for each fix.
