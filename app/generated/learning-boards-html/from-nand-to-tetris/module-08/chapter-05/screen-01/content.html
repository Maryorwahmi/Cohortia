Project 9 — OS & Integration

Complete the Jack OS modules and run the full stack so the Hack computer can boot and execute Tetris. This is the final integration: hardware, toolchain, compiler, and OS working together.

In this lesson: finish OS modules, run tests, bootstrap Sys.init, and play Tetris as proof of a working stack.
Explore Key Topics
OS modules: Memory, Array, Math, String, Output, Screen, Keyboard, Sys — implement and test each service.
Boot sequence: bootstrap initializes the stack pointer and transfers control to Sys.init, which initializes services and calls Main.main.
Testing & verification: run MemoryTest, MathTest, ScreenTest, Pong and Tetris to validate the full system.
