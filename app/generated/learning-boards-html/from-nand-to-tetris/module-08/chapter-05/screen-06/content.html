Definition › Memory Module
What Memory provides
  • Allocate(size): reserve a contiguous block of words and return its base address.
  • Free(address): release a previously allocated block so it can be reused.
  • Stability: addresses remain valid until freed; freed memory must not be used.
Test: run MemoryTest and then a stress loop that allocates and frees repeatedly to reveal leaks.
Concrete example

When the game allocates a board: Array calls Memory.allocate(size). Memory returns pointer X. The compiled code stores and manipulates data at X. If Memory.free(X) is later called, any subsequent read at X is undefined. Reproduce such errors by looping allocate/free and then checking the board contents after re-allocation.

Common mistake
Treating freed memory as implicitly zeroed or preserved. Memory reuses blocks; do not rely on prior contents after allocation.
