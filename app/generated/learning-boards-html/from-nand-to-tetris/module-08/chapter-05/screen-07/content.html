Array layout
  1. Array.allocate(n) calls Memory.allocate(n + metadata) and returns base pointer.
  2. Element i is stored at base + metadata + i.
  3. Array.free(base) calls Memory.free with the original block address.
Example scenario

A Tetris piece list might be stored in an array. The game allocates the array, updates positions frequently, and finally frees it between levels. If indexing is wrong, pieces corrupt the board state; reproduce with short sequences of allocations and element writes.

Key Takeaway

Keep layout contracts explicit between Array and Memory and test both unit and integration behavior under repeated allocations.
