Core Concept › OS Modules
Module Definitions
  • Memory — allocation and deallocation primitives for the heap.
  • Array — constructs and disposes variable-length arrays using Memory.
  • Math & String — helper functions used by higher-level code.
  • Output, Screen, Keyboard — I/O primitives for text, graphics, and input.
  • Sys — bootstrap and system-level services that initialize the OS.
Concrete example
When Tetris needs a board, Main.main calls Array to allocate the board. Array uses Memory to reserve space and returns a pointer. Later, when a level ends, Array calls Memory to free the space. The OS modules coordinate to make this safe and predictable.
Common misconception
Students sometimes treat OS modules as independent libraries. In practice, they form a small ecosystem. If Memory semantics change, Array and Sys must adapt. Treat module interfaces as contracts and test them in isolation and in integration.
Key Takeaway

Design clear module contracts and verify both unit behavior and system integration to ensure Tetris runs on your stack.
