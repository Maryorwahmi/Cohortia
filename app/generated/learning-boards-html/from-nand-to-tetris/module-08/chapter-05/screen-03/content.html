Test Suite
  • MemoryTest — allocation and deallocation checks.
  • MathTest & StringTest — library routines and edge cases.
  • KeyboardTest & ScreenTest — I/O and display correctness.
  • Pong & Tetris — final system-level integration and performance checks.
Troubleshooting Pattern
  1. Run the failing test and capture the simulator trace.
  2. Identify whether the bug is in an OS service or earlier toolchain output.
  3. Reproduce with a minimal input and inspect memory and register state.
  4. Apply a focused fix, re-run tests, and document the change.
Tip: keep small, reproducible test cases to avoid chasing unrelated failures.
