Architecture › I/O Modules
Screen
Provides drawing primitives used by games to render shapes and the board. Implementations map drawing calls to simulator display memory or output routines. Test with ScreenTest and verify refresh behavior during gameplay.
Keyboard

Supplies input events or key states. The game queries Keyboard.read to process moves. Test with KeyboardTest and under Pong/Tetris to check input responsiveness.

Key Takeaway

I/O modules must present simple, reliable primitives; test them in the context of real user interaction to catch timing and buffering issues.
