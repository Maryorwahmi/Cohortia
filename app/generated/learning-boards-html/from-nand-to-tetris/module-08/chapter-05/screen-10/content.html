Process Flow › Boot & Stack
Stack steps
  1. Simulator loads machine code for the program into ROM.
  2. Bootstrap initializes SP and calls Sys.init.
  3. Sys.init initializes OS services: Memory, Math, Output, Screen, Keyboard.
  4. Sys.init calls Main.main; the program runs using OS services.
Bootstrap example (pseudo)
// Bootstrap pseudo-code
// initialize stack pointer
set SP to initialAddress
// transfer control to OS
call Sys.init
// Sys.init starts services and calls Main.main

Key Takeaway

Confirm each transition point: ROM load, SP init, Sys.init, and Main.main. Failures map to these handoff boundaries.
