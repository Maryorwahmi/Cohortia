Module 8 › Project 9 › Learning Objectives
01
Complete the Jack OS

Implement each OS module so higher-level programs can use memory, I/O and services reliably. Verified competency: module-level tests pass.

Mnemonic: think of modules as service endpoints in a small standard library.
VERIFIED COMPETENCY MILESTONE
02
Test the OS with provided programs

Run MemoryTest, MathTest, ScreenTest, Pong and Tetris to validate functionality and integration. Debug until behaviors match expectations.

Mnemonic: unit tests then system tests — build confidence bottom-up.
VERIFIED COMPETENCY MILESTONE
03
Run the complete computing stack

Boot the simulator, let the bootstrap code initialize SP, let Sys.init configure services, and observe Main.main running Tetris as an end-to-end proof.

Mnemonic: follow the call stack from bootstrap to Main.main.
VERIFIED COMPETENCY MILESTONE
04
Reflect on the Nand2Tetris journey

Explain how abstraction managed complexity, what hardware-software trade-offs you made, and what you learned from building every layer yourself.

Mnemonic: map a lesson from each layer — logic, CPU, assembler, VM, compiler, OS.
VERIFIED COMPETENCY MILESTONE
