Module 8 › Chapter 8.2 › Midpoint circle algorithm
Core idea
Use integer decision variable and symmetry of circle octants to reduce computation.
Octant mirroring
Each (x,y) in the first octant yields eight pixels across reflections and swaps: mirror across axes and swap x/y.
Step loop
  1. Initialize x=0, y=r, d=1-r (decision variable)
  2. Plot eight mirrors of (x,y)
  3. Increment x; if d < 0 then d += 2*x + 1 else y-- and d += 2*(x - y) + 1
  4. Repeat until x > y
Concrete example
r = 5: start (0,5). Plot all eight symmetric pixels for each computed pair until x passes y, producing a closed, symmetric circle of pixels.
Common mistake
Plotting only one octant without mirroring yields an eighth of the circle. Remember sign swaps and axis swaps for full coverage.
