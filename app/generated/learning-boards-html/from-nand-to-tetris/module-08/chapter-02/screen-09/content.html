Module 8 › Chapter 8.2 › Output module and bitmap fonts
Key facts
  • Each character is 11 rows × 8 columns of pixels.
  • Characters are stored as arrays of 11 integers (one per row).
  • Printing copies these rows into the screen at the cursor position.
Rendering steps
For each glyph row compute the destination word addresses and masks and write bits using read-modify-write or aligned full-word writes when possible.
Analogy
Think of each character as a rubber stamp with 11 horizontal stripes; stamping copies the black dots into the canvas row by row.
Concrete example
// glyph for 'A' stored as 11 integers
glyphA = [0x18,0x24,0x24,0x24,0x3C,0x24,0x24,0x24,0x24,0x00,0x00]
// copy each integer row into the screen at cursor position
Common trade-off
Bitmap fonts are memory-specific and fixed size. They are fast but cannot be scaled without new bitmaps for each size.
