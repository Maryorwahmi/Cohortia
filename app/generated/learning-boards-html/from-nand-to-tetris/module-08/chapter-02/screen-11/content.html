Module 8 › Chapter 8.2 › Implementing and testing primitives
Step sequence
  1. Implement drawPixel and test boundary pixels.
  2. Add Bresenham drawLine and test common slopes.
  3. Create rectangle routines and test filled vs outline.
  4. Implement midpoint circle and test symmetry.
  5. Build Output module and print sample strings.
Example test
Draw a checkerboard of 8×8 tiles using filled rectangles and then print a label. If the label aligns with tiles, pixel math is correct.
Scenario: draw a house
Use a filled rectangle for the body, a triangle made from three lines for the roof, and print a title below. Visual inspection makes it easy to detect off-by-one addressing bugs.
Common debugging tips
Log computed addresses for a few pixels, test multiples of 16, and simplify tests to single-row draws to isolate masking errors.
