Module 8 › Chapter 8.2 › Algorithm trade-offs and assessment
Compare
Integer-only algorithms vs naive floating-point approaches; bitmap fonts vs vector rendering.
Why integers win on Hack
Hack lacks floating-point hardware. Integer algorithms avoid software-emulated floats and keep code and runtime smaller and faster.
Font trade-offs
Bitmap: fast, simple, fixed-size. Vector: scalable but requires complex rasterization and more CPU time.
Assessment idea
Describe why Bresenham’s integer-only steps are essential on Hack and compare the runtime cost of a floating-point naive line algorithm versus Bresenham.
Misconception
Assuming floating-point algorithms are required for quality. On pixel grids, integer algorithms give precise, efficient results.
