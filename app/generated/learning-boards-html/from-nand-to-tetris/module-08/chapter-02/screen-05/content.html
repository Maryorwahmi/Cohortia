Module 8 › Chapter 8.2 › Drawing a single pixel
Goal
Set or clear one pixel without disturbing neighboring pixels in the same word.
Step-by-step
  1. wordIndex = x / 16; bit = x % 16
  2. address = 16384 + y * 32 + wordIndex
  3. mask = 1 << bit
  4. value = read(address); write(address, value | mask) to set, or value & ~mask to clear
Common mistake

Using column instead of column modulo 16 when shifting will overflow the mask and affect wrong bits.

Code example (Jack-style pseudocode)
// drawPixel(x, y)
wordIndex = x / 16
bit = x % 16
addr = 16384 + y * 32 + wordIndex
mask = 1 << bit
value = Memory[addr]
// set pixel to black
Memory[addr] = value | mask
// to clear pixel: Memory[addr] = value & ~mask
Analogy
Think of each 16-bit word as a row of 16 lamps; you switch one lamp without resetting the rest by using a stencil (mask).
