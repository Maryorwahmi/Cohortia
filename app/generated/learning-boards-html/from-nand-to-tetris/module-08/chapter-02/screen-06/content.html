Module 8 › Chapter 8.2 › Drawing lines with Bresenham
Algorithm overview
Compute dx, dy, choose major axis, and iterate while maintaining an integer error term to know when to step the minor axis.
Steps
  1. dx = abs(x2 - x1), dy = abs(y2 - y1)
  2. Decide if line is steep: if dy > dx swap axes
  3. Set error = 2*dy - dx (scaled integer accumulator)
  4. For i from 0 to dx: plot pixel; error += 2*dy; if error > 0 then y += step; error -= 2*dx
Check your understanding
Why is axis-swapping used for steep lines? Think about which coordinate should be incremented each loop to keep the loop count low and arithmetic simple.
Concrete example
Line from (2,3) to (10,7)
dx=8, dy=4; iterate 8 steps across x, increment y on error threshold crossings. Call drawPixel at each computed (x,y).
Common misconception
Bresenham isn’t about approximating lines poorly — it chooses the best pixel each step using simple integer arithmetic, yielding visually straight lines at low cost.
Pro tip

Test with steep and shallow slopes to validate axis swapping and sign handling for negative slopes.
