Module 8 › Chapter 8.2 › Cursor management and printing utilities
Text geometry
23 text rows (11 px tall) × 64 columns (8 px wide). Cursor tracks row and column; pixel offset = row*11, col*8.
Printing helpers
  • printChar(c): copy glyph at cursor, advance cursor
  • printString(s): iterate characters and call printChar
  • printInt(i): convert integer to characters then print
  • println(): move cursor to next line, possibly scroll
Edge cases
Clipping glyphs at screen edges and implementing smooth scrolling are common implementation details you must handle for a robust Output module.
Concrete example
To print '42' convert 42 to the characters '4' and '2', call printChar for each, and ensure the cursor advances correctly between characters and lines.
Common pitfall
Mixing pixel and text coordinates leads to misaligned text. Always convert using the 11×8 character cell size before writing bitmaps.
