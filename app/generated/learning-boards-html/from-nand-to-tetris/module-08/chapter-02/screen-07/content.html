Module 8 › Chapter 8.2 › Rectangles and filling strategies
Outline vs filled
Outlines: four lines. Filled: scanlines that write masks and full words where possible for speed.
Scanline fill pattern
  1. For each row y between y1 and y2 compute leftX and rightX.
  2. leftWord = leftX / 16, rightWord = rightX / 16
  3. Write partial masks to edge words; write 0xFFFF to full words between them.
Example
Fill rectangle from x=10 to x=70 on row y: leftWord=0, rightWord=4, set masks for word 0 and 4, write full words for 1..3.
Performance note
Per-pixel loops are simpler but slow. Word-level writes reduce memory operations and are recommended for large fills on Hack.
Common mistake
Ignoring word alignment causes excessive read-modify-write calls and can produce visual seams on edges. Plan edge masks explicitly.
