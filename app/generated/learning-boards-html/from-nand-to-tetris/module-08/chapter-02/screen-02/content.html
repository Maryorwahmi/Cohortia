Learning Objectives

These objectives guide the code you'll write and the tests you'll run to verify the Screen and Output modules.

Learn → Understand → Apply → Master
01
Address pixels precisely
Compute row/word/bit math to map a pixel to memory. This skill is necessary to set or clear pixels reliably.
VERIFIED COMPETENCY MILESTONE
02
Draw integer-only lines
Implement Bresenham’s approach to draw straight lines without floating point arithmetic, which matches the Hack CPU’s constraints.
VERIFIED COMPETENCY MILESTONE
03
Render shapes and circles
Use line primitives for rectangles and the midpoint algorithm plus symmetry for circles to keep work minimal.
VERIFIED COMPETENCY MILESTONE
04
Print text with a bitmap font
Manage a cursor, copy 11×8 bitmaps into screen memory, and implement basic printing utilities for strings and integers.
VERIFIED COMPETENCY MILESTONE
