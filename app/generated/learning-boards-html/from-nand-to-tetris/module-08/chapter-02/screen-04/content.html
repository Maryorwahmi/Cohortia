Module 8 › Chapter 8.2 › Screen memory map
Definition

256 rows × 512 columns

The screen memory block is contiguous. Each row is stored as thirty-two 16-bit words. Use the address formula to locate any pixel's word.

Address formulas
Word address: 16384 + row * 32 + wordIndex
Bit position: col % 16
Key Takeaway

Correct pixel addressing avoids drawing corruption and is the basis for all other primitives.

Annotated example
Example: pixel (col=30, row=10)
wordIndex = 30 / 16 = 1, bit = 30 % 16 = 14
// compute word address for (30,10)
address = 16384 + 10 * 32 + 1
// mask for bit 14: 1 << 14
Visual mnemonic
Think of each row as a shelf holding 32 boxes; each box contains 16 paint dots. Choose the shelf, box, then dot index.
Common mistake
Off-by-one errors in dividing columns by 16 or incorrect modulo operations often place the mask in the wrong word. Always test with several columns including multiples of 16.
