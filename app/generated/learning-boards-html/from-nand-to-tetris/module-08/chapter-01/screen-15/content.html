Module 8 › Chapter 8.1 › Key Concepts
OS as abstraction

The OS hides hardware details and exposes clear services that applications call reliably.

Best-fit allocator

Scans the free list to find the smallest block that fits and splits blocks as needed.

Arrays as contiguous blocks

Array.new uses Memory.alloc so the compiler can index elements with pointer arithmetic efficiently.

Summary Takeaway

Design OS services to be simple, well-documented, and testable; implement Memory and Array carefully so higher-level modules can rely on consistent behavior.
