Functions
  • Math.abs(x), Math.max(x,y), Math.min(x,y)
  • Math.multiply(x,y) — implement with shift-and-add
  • Math.divide(x,y) — integer division via long division
  • Math.sqrt(x) — integer square root (Newton or binary search)
Shift-and-add (idea)
result = 0
while b > 0:
  if (b & 1) == 1:
    result = result + a
  a = a << 1
  b = b >> 1
return result
Testing notes
Check multiply and divide with zero, negatives, and values near the word-size limit. Decide and document the behavior for overflow and divide-by-zero cases so higher-level code can rely on consistent semantics.
