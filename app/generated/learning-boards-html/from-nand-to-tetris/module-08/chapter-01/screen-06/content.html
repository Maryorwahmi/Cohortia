Module 8 › Chapter 8.1 › Memory API
API summary
  • Memory.init() — initialize heap and free list.
  • Memory.peek(address) / Memory.poke(address, value) — direct access.
  • Memory.alloc(size) — allocate a block of words.
  • Memory.deAlloc(object) — return a block to the free list.
Common mistake
Forgetting to call Memory.init before allocations. Without initialization the free list is undefined and alloc will fail or corrupt memory.
Behavioral expectations
  1. alloc returns a pointer or zero on failure, with allocated words contiguous.
  2. deAlloc returns the block to the free list; coalescing may be required to avoid fragmentation.
  3. peek/poke operate on raw words and must be used with care to avoid violating invariants.
Key Takeaway

Define clear postconditions for alloc/deAlloc and ensure Memory.init reliably establishes initial free list state.
