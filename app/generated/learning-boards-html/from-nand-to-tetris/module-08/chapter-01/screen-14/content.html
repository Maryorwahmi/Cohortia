Module 8 › Chapter 8.1 › Hands-on: Memory & Array
Steps
  1. Implement Memory.init to set freeListHead to one big block.
  2. Implement Memory.alloc with best-fit search and splitting.
  3. Implement Memory.deAlloc with insertion and coalescing.
  4. Implement Array.new and Array.dispose on top of Memory functions.
Sample test sequence
// test pattern
addr1 = Memory.alloc(10)
addr2 = Memory.alloc(5)
Memory.deAlloc(addr1)
addr3 = Memory.alloc(6) // should reuse freed space if best-fit
ArrayA = Array.new(4)
// set ArrayA[2] and read back
Debugging tips
  • Print free-list contents after each operation to verify invariants.
  • Use small heaps and simple patterns to make errors easy to spot.
  • Guard against double-free and invalid-free in early testing stages.
