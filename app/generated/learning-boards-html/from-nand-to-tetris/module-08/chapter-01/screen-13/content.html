Sys functions
  • Sys.init() — initialize modules and call Main.main
  • Sys.halt() — stop execution
  • Sys.error(code) — report an error
  • Sys.wait(duration) — simple delay primitive
Why it matters
Sys.init enforces a known starting state. If omitted, any module call could read undefined structures and cause subtle failures that are hard to debug.
Testing the bootstrap
Verify VM translator output calls Sys.init first. Write a small program that uses Memory.alloc and Output.printString; if Sys.init is missing the program will likely crash or behave unpredictably.
Key Takeaway

Sys.init is the safety gate that prepares OS services. Always ensure correct bootstrap order before running application code.
