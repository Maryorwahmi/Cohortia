Module 8 › Chapter 8.1 › Learning Objectives
Skill
Implement Memory.alloc and Memory.deAlloc using a best-fit free list and test allocations of varying sizes.
Skill
Implement Array.new and Array.dispose and validate contiguous layout with simple index checks.
Skill
Implement Math routines: abs, max, min, multiply, divide, sqrt, and validate with edge inputs.
Test examples
  • Allocate then deallocate blocks in different orders to reveal fragmentation.
  • Create arrays, set values, and read them back to confirm pointer arithmetic works.
  • Test multiply with zero and negative operands and divide with non-exact quotients.
