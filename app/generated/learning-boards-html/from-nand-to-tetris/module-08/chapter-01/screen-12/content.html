Module 8 › Chapter 8.1 › I/O Modules
Output
Functions: init, moveCursor, printChar, printString, printInt, println, backSpace. Use these instead of writing to console memory locations directly.
Screen
Functions: init, clearScreen, setColor, drawPixel, drawLine, drawRectangle, drawCircle. These abstract pixel addressing and color control.
Keyboard
Functions: init, keyPressed, readChar, readLine, readInt. They provide blocking and non-blocking input helpers that are easier to use than raw register reads.
Example tests
  • Print a string and check cursor advances and newline behavior.
  • Draw a rectangle and confirm pixel counts and positions visually.
  • Use readLine to accept input and echo it back to confirm correctness.
