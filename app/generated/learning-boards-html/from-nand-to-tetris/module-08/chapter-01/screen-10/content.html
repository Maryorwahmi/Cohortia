Module 8 › Chapter 8.1 › Array Implementation
How it works
Array.new(size) calls Memory.alloc(size) and returns a base pointer. Element i is accessed at base + i (plus header offset if allocator stores metadata). Array.dispose calls Memory.deAlloc to return the region.
Compiler role
The compiler generates code that uses the 'that' segment to point at the base of an array and accesses elements by indexing into that segment.
Example
If Array.new(4) returns base = 100, then element 2 is at address 102 (or 102 + headerOffset if headers are present). Test by writing values and reading them back with peek/poke or using high-level code that sets and gets elements.
Key Takeaway

Ensure your allocator and array interface agree on header layout and that element indexing accounts for any metadata words placed before element zero.
