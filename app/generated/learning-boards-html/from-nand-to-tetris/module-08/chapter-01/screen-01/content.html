Operating System Fundamentals

Explore the Jack OS: the modules it offers, how it manages memory, and how it simplifies program design.

In this lesson
What an OS does, Jack OS modules, memory allocation, arrays, and runtime services.
Coming up
Implement Memory.alloc and Array.new during the hands-on activity.
Why it matters
Abstractions reduce bugs and make porting an application between hardware simpler.
Overview

Jack OS provides Memory, Array, Math, String, Output, Screen, Keyboard, and Sys modules as stable services for programs.

Memory
Allocates and frees heap blocks.
Screen
High-level graphics routines (drawPixel, drawLine).
Sys
Bootstrap and system services like halt and error.
Concept Map
OS: hardware abstraction
Jack OS: 8 modules
Services: alloc, draw, input
Explore Key Topics
Memory Management — best-fit free-list allocator for heap tracking.
Array Implementation — contiguous blocks allocated via Memory.alloc.
Sys & Bootstrap — Sys.init sets up modules and calls Main.main.
Tip: As you study each module, map the service names to the higher-level concept they represent — allocation, I/O, math, or control.
