Module 8 › Chapter 8.1 › What an Operating System Is
Definition

OS: manager of resources and services

An OS provides a stable interface and services so application code does not need to manipulate hardware directly. These services make code simpler and more portable.

Abstraction: hide memory and device details
Service: provide allocation, I/O, math utilities
Stability: consistent behavior across programs
Bootstrap: Sys.init prepares OS state
Analogy
Hotel manager analogy: Memory allocates rooms, Array groups adjacent rooms, Screen decorates walls, and Sys opens the hotel. Analogies help map abstract services to concrete expectations when you design APIs.
Common misconceptions
  • Misconception: an OS is only an advanced concept. Reality: even minimal services provide strong benefits.
  • Misconception: abstraction always costs too much. Reality: tradeoffs exist; the Jack OS chooses simplicity and clarity for learning.
Key Takeaway

The OS is the final abstraction layer that simplifies program development by turning hardware actions into well-defined services.
