Linked-list free list
Each free block stores its size and next pointer. Initialize one block covering the heap, then maintain the list as allocations and deallocations occur.
Init: free list = [block(start, size = heap_size)]
Alloc request: search for smallest block with size >= request.
If block bigger than needed, split; return pointer to allocated area.
DeAlloc: add block back and coalesce adjacent free blocks when possible.
Tradeoffs
  • Best-fit reduces wasted space but requires full search time.
  • First-fit is faster on average but may leave larger holes.
  • Worst-fit tends to split big blocks and can create unusable fragments.
Example scenario
Request sequence: alloc(5), alloc(3), deAlloc(first), alloc(4). Best-fit will select smallest sufficient blocks, which can reduce leftover fragments and may allow the second allocation to use previously freed space if sizes match.
Key Takeaway

Choose a strategy that balances run-time cost and space efficiency; the Hack platform favors simplicity and reasonable space use, which is why best-fit is chosen here.
