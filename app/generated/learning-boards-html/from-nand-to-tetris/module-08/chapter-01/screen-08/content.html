Pseudocode
// Memory.alloc(size)
Memory.alloc(size):
  if size == 0: return 0
  best = null
  prevBest = null
  prev = null
  cur = freeListHead
  while cur != 0:
    if cur.size >= size:
      if best == null or cur.size < best.size:
        best = cur
        prevBest = prev
    prev = cur
    cur = cur.next
  if best == null: return 0  // allocation failure
  if best.size == size:
    remove best from list (use prevBest)
    return best.startAddress
  else:
    // split: allocated = best.start; remainder = best.start + size + header
    allocate front portion and update best entry to point to remainder
    return allocated.startAddress
Pitfalls
  • Forgetting to update prevBest when removing the head node.
  • Creating zero-sized remainder when sizes match closely; avoid split if remainder would be too small.
Concrete example
Heap: [20][15][30] request alloc(12). Best-fit chooses 15, split into 12 and remainder 3 (if header overhead considered). The allocator updates links so free list becomes [20][3][30] or coalesces as required.
Key Takeaway

Write clear code for list traversal, carefully maintain prev pointers, and test boundary sizes to ensure safe splits and correct head updates.
