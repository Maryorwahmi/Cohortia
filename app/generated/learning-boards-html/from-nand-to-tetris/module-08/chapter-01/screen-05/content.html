Memory & Array
Memory: Memory.init(), peek(address), poke(address,value), alloc(size), deAlloc(object). Array: Array.new(size), Array.dispose(). Arrays use Memory.alloc to obtain contiguous regions.
Example: Memory.alloc(10)
Example: Array.new(5)
Math & String
Math exposes abs, multiply, divide, sqrt, max, min. String supports new, length, charAt, appendChar, appendString, intValue, setInt, and editing helpers.
Multiply using shift-and-add
String.intValue converts text to numeric value
Output & Screen
Output.printString and printInt for text. Screen.drawPixel, drawLine, drawRectangle, drawCircle for graphics. These avoid direct writes to memory-mapped display addresses.
Keyboard & Sys
Keyboard.readChar and readLine for input. Sys.init bootstraps modules and calls Main.main; Sys.halt and Sys.error provide control and diagnostics.
