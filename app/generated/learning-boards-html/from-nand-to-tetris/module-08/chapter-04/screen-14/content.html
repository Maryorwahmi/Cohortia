Assessment › Explain complexity & justify choices

Sample question

"The shift-and-add multiplication algorithm has time complexity O(n) where n is number of bits. For 16-bit integers this requires up to 16 iterations. Why is this acceptable for the Hack computer, and what would be a faster algorithm for larger integers?"

Answer should mention small constant factor for 16 bits, simplicity and clear testability, and alternatives such as Karatsuba or FFT-based multiplication for very large integers.

Reflection prompt

"What hardware features would make the Jack OS more efficient? Describe at least two and how they change the software design."

Expect answers about hardware timers for precise waits and multiplier/divider instructions to remove the need for software routines, plus interrupts for preemptive multitasking.
