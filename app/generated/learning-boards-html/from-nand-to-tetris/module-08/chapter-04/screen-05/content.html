Process › Implementing multiply safely

Sign handling pattern

1) Record sign = (x < 0) XOR (y < 0). 2) Convert x and y to absolute values. 3) Run shift-and-add on positives. 4) If sign, negate the product before returning.

Explicitly converting to absolute values avoids scanning sign-extended bits and simplifies logic on small platforms.

Example
-3 * 4: abs(-3) = 3; compute 3*4 = 12; apply negative sign -> -12.

Testing matrix

Base cases
0*x, 1*x, x*1, -1*x
Sign combos
(+,+), (+,-), (-,+), (-,-)
Bounds
Large magnitude near 16-bit limits to observe wrap or overflow.
Regression
Add tests to catch accidental sign-loss after refactors.
Common mistake

Scanning bits of two's-complement values without converting to absolute can yield incorrect partial products when sign bits are set.
