Process Flow › Sys.init and startup sequence

Sequence

  1. Memory.init()
  2. Math.init()
  3. Output.init(), Screen.init(), Keyboard.init()
  4. Main.main()
  5. Sys.halt()
Analogy
A startup checklist that ensures each subsystem is ready before the main program runs.

Canonical init code

function void init() {
  do Memory.init();
  do Math.init();
  do Output.init();
  do Screen.init();
  do Keyboard.init();
  do Main.main();
  do Sys.halt();
}
Why Sys.halt?
Guarantees the program stops in a controlled infinite loop; avoids executing invalid addresses after main returns.
Dependency note
Order matters: Memory.init should precede modules that allocate or store state.
