How to show competency

Run unit tests for multiply, divide, and sqrt using edge-case inputs, and build a small program that prints a sequence like the first 20 Fibonacci numbers to exercise Math routines.

Document performance observations: count iterations for multiply, verify division handles sign combinations, and time Sys.wait to see approximate delays.

Verified competency milestone

Submit code that passes a test suite for correctness and includes short notes on complexity and trade-offs.
