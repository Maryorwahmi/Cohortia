Module 8 › Chapter 8.4 › Learning Objectives
Test set

Multiply: 0, 1, -1, large positives, sign combinations, overflow checks.

Divide: test divisor = 0 triggers Sys.error; test all sign pairs; test remainder behavior.

Sqrt: perfect squares, non-perfect squares, negative input triggers Sys.error.

Performance checks

Count loop iterations for multiply (up to 16). Measure divide iterations and binary search iterations for sqrt. Compare recursive and iterative Fibonacci runtimes.

Why this matters

On 16-bit Hack, simple algorithms win for clarity; measuring shows whether costs are acceptable.

Deliverables

Working Math and Sys modules; test logs for edge cases; a short report that states complexity and any observed timing values for Sys.wait.

Verified competency milestone

Provide runnable Jack code and a few sample outputs to prove correctness.
