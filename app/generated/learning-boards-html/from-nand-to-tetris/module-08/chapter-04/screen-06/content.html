Core Concept › Math.divide — long division

Algorithm steps

  1. Check divisor = 0 -> call Sys.error(3).
  2. Normalize signs and work with absolute values.
  3. For i from highest bit down to 0: set temp = divisor << i; if temp <= dividend then set quotient bit and subtract temp from dividend.
  4. Apply recorded sign to quotient and return.
Concrete example
77 / 5: shift 5 up to 64 (5<<3), subtract 64 -> remainder 13, set bit 3, then handle lower bits to form quotient 15 with remainder 2.

Code snippet

function int divide(int x, int y) {
  var int q, i, temp;
  if (y = 0) {
    do Sys.error(3);
  }
  if ((x < 0) & (y > 0)) { return -Math.divide(-x, y); }
  if ((x > 0) & (y < 0)) { return -Math.divide(x, -y); }
  if ((x < 0) & (y < 0)) { return Math.divide(-x, -y); }

  let q = 0;
  let i = 15;
  while (~(i < 0)) {
    let temp = (y << i);
    if (temp < (x + 1)) {
      let q = q + (1 << i);
      let x = x - temp;
    }
    let i = i - 1;
  }
  return q;
}
Common mistake
Using repeated subtraction by original divisor is too slow for large dividends.
Pro tip
Handle division-by-zero early and standardize sign handling to reuse the positive-case algorithm.
