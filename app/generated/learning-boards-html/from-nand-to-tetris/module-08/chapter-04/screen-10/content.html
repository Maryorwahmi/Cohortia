Definition › Sys.halt and Sys.error

Sys.error workflow

Sys.error(code) should print or expose the error code and then call Sys.halt to stop execution. Use distinct codes for different fatal conditions so tests can verify the exact cause.

Example codes from the chapter: 3 for division by zero, 4 for negative sqrt input.

Key Takeaway

Fatal errors are handled deterministically: report then halt so behavior is testable on Hack.

Sys.halt

Sys.halt simply enters an infinite loop. It is the canonical termination mechanism on Hack. Tests should expect execution to stop and not return to caller code.

Test idea
Trigger Sys.error and assert the reported code and that execution does not continue.
Misconception
Assuming a halted machine can resume — on Hack halt is final until reset.
