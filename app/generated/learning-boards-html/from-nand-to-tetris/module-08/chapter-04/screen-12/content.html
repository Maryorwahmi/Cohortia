Core Concept › Memory allocator choices

Simple linked-list allocator

Maintain a linked list of free blocks. On allocation, walk the list to find a suitable block and split if necessary. On free, add the block back to the list and optionally coalesce with neighbors.

Advantages: small code size, easy to reason about. Disadvantages: potential fragmentation and linear allocation time.

Segregated lists and coalescing

Segregated lists hold free blocks by size class to speed allocation. Coalescing merges adjacent free blocks to reduce fragmentation. Both reduce long-term fragmentation at the cost of metadata and complexity.

For Hack the chapter recommends starting simple and optimizing only if real workloads show fragmentation or performance issues.

Test idea
Allocate and free various sizes in patterns that mimic your programs and measure free memory over time to detect fragmentation.
