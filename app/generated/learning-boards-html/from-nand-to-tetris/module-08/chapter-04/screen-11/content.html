Process Flow › Sys.wait — busy-loop timing

Implementation pattern

function void wait(int duration) {
  var int i, j;
  let i = 0;
  while (i < duration) {
    let j = 0;
    while (j < 100) {
      let j = j + 1;
    }
    let i = i + 1;
  }
  return;
}

Inner loop bound (100 above) sets granularity. Increase or decrease to adjust per-iteration cost when calibrating on actual hardware.

Pros and cons

Pros
Portable, simple to implement, no hardware dependencies.
Cons
Consumes full CPU, imprecise timing, unsuitable for multitasking.
Test idea
Run wait with durations 1, 2, 5 and measure relative pauses to confirm scaling.
