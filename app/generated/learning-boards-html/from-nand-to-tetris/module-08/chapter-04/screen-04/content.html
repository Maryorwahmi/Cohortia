Core Concept › Math.multiply — shift-and-add

Definition and steps

  1. Initialize sum = 0, shiftedX = x, i = 0.
  2. Repeat for each bit i up to 15: if bit i of y is set, add shiftedX to sum; then set shiftedX = shiftedX + shiftedX; i++.
  3. Return sum as the product.
Key Takeaway

Uses only addition and bit tests, simple to implement on Hack and predictable in iteration count.

Code walkthrough: the canonical Jack implementation is shown for clarity and testing. The comparisons and bit tests use only operations available on Hack.
function int multiply(int x, int y) {
  var int sum, shiftedX, i;
  let sum = 0;
  let shiftedX = x;
  let i = 0;
  while (i < 16) {
    if (y & (1 << i)) {
      let sum = sum + shiftedX;
    }
    let shiftedX = shiftedX + shiftedX;
    let i = i + 1;
  }
  return sum;
}
Concrete example
13 * 6 -> bits 110 -> add 13*2 and 13*4 -> 78
Common mistake
Forgetting to handle signed values or overflow; add explicit tests for negatives and limits.
Pro tip
Use bit tests rather than divisions; doubling by addition stays within core Hack ops.
