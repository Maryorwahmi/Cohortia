Complexity quick guide

  • Multiply (shift-and-add): O(n) additions and bit checks.
  • Divide (long division): O(n) bit iterations with compares and subtractions.
  • Sqrt (binary search): O(log range) iterations; predictable and safe.
When to optimize
Only consider advanced multiply algorithms when word sizes are large and profiling shows a need. For Hack's 16-bit domain, simplicity is a stronger value than micro-optimization.

Example comparison

Simple
Shift-and-add: easy to implement, test, and reason about for 16 bits.
Complex
Karatsuba/FFT: asymptotically faster but requires more memory and complex transforms.
Misconception

Faster asymptotic complexity always wins — false for small fixed word sizes where constant factors and code complexity matter more.
