What to Remember
Multiply: shift-and-add
Add shifted copies of x when bits of y are set; O(n) for n bits.
Divide: long division
Shift divisor, subtract when it fits, accumulate quotient bits; check divisor = 0.
Sqrt: binary search
Binary search is simple for integer roots; check negatives and return floor value.
Sys.init sequences subsystem inits and launches the main program; Sys.error reports a code then halts; Sys.wait is a busy-wait suitable only for simple timing on hardware without timers. Prefer simple, testable algorithms on Hack and justify any complexity with profiling data.
