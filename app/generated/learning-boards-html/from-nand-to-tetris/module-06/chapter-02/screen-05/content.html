Code walkthrough

Assembly template for function

(functionName)     // Function entry label
// Push nLocals zeros onto the stack
@nLocals
D=A
(LOOP)
@END_LOCALS
D;JEQ
@SP
A=M
M=0
@SP
M=M+1
D=D-1
@LOOP
0;JMP
(END_LOCALS)
This sequence creates a label, sets D to nLocals, then loops writing zero at RAM[SP] and incrementing SP until D reaches zero. If nLocals is zero the loop exits immediately.
Explanation
  • • The label is the function entry point used by calls to jump into this code.
  • • Initializing locals to zero makes variable behavior deterministic across runs.
  • • The loop uses D as a counter so the implementation avoids extra temporary memory if nLocals is small.
  • • Edge case: emit only the label when nLocals is 0; no loop code is needed.
Common mistake

Forgetting to update SP after storing zero leaves the stack pointer stale and corrupts future pushes and frame math.
