Module 06 › Chapter 6.2 › Debugging tips

Common pitfalls

  • • ARG off-by-five: ensure ARG = SP - nArgs - 5.
  • • Missing SP increment after pushing locals.
  • • Return address overwritten during callee execution.
  • • Duplicate bootstrap emitted per file.
  • • Static names colliding across files.

Fixes & checks

• Add assertions in the translator for ARG calculation and SP updates.
• Emit translator-level comments around prologue/epilogue for easy emulator stepping.
• Keep a global counter for return labels and never reset per file.
• Qualify static names with file name to avoid collisions.
Key Takeaway

Systematic checks on SP movement and saved frame values catch most implementation errors quickly during emulator runs.
