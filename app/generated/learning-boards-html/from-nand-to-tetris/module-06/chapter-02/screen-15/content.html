Module 06 › Chapter 6.2 › Key Concepts
Call & Save
Push return address and save LCL, ARG, THIS, THAT so the caller's context is preserved.
Prologue & Return
Function label + push n locals; on return restore frame and place return value at ARG.
Bootstrap & Files
Emit SP=256, call Sys.init once, and qualify static symbols across concatenated files.
Summary: correct push/pop ordering, ARG math, returning the value to ARG, and globally-unique labels are the pieces that make the VM translator's function calling reliable.
