Translate function
Implement the function command to create a label and allocate n local zeros so each activation has local storage. This ensures locals are deterministic and addressable within the function.

02
Translate call
Push return address and caller context, compute ARG = SP - nArgs - 5, set LCL = SP, and jump. This sets the callee's argument base reliably.
VERIFIED COMPETENCY MILESTONE
03
Translate return
Restore THAT, THIS, ARG, LCL from the saved frame, move return value to ARG, set SP = ARG + 1, and jump to return address so the caller resumes correctly.
VERIFIED COMPETENCY MILESTONE
04
Bootstrap & files
Emit bootstrap code to set SP = 256 and call Sys.init, and concatenate translations of multiple VM files ensuring global static allocation across the output assembly file.
