Module 06 › Chapter 6.2 › Unique labels

Strategies for return labels

• Global counter: RET.0, RET.1, RET.2 — incremented each call, never reset per-file.
• Contextual labels: FileName$RET0 or FunctionName$RET0 — embeds caller context for readability.
• Combined approach: FileName$RET0 where RET0 is global counter ensures both uniqueness and traceability.
Pitfall

Resetting a counter for each file will create duplicate labels after concatenation. Keep counters at translator scope, not file scope.

Example
@RET_42 D=A @SP A=M M=D @SP M=M+1
This shows a call pushing a uniquely named return label. The translator should ensure @RET_42 is unique by using a global counter.
Key Takeaway

Use a translator-global counter or include file context so every call site gets a distinct return label across concatenated files.
