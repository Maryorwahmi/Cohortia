Module 06 › Chapter 6.2 › Implementing the return command
Code walkthrough
// Save return value in temp
@SP
A=M-1
D=M
@R14
M=D

// Restore THAT, THIS, ARG, LCL
@LCL
D=M
@R13
M=D
// ... (restore segment pointers from the saved frame)

// Set SP = ARG + 1
@ARG
D=M+1
@SP
M=D

// Push return value
@R14
D=M
@SP
A=M-1
M=D

// Jump to return address
@R13
A=M
0;JMP
The pattern uses temporary registers for the frame and return value. Restoring pointers uses offsets from the saved frame address so each pointer returns to its caller value.
Explanation & checklist
  • • Save return value before modifying SP or restoring pointers.
  • • Compute frame = LCL and use frame offsets to restore THAT, THIS, ARG, LCL.
  • • Set SP = ARG + 1 so the caller's stack layout is correct.
  • • Place return value at RAM[ARG] and jump to saved return address.
Debug hint

If returns land at the wrong place, verify the return-label generation and that the saved return address wasn't overwritten during the callee's execution.
