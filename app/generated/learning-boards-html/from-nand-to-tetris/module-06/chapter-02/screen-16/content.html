Module 06 › Chapter 6.2 › Quick Reference
ARG math
Always compute ARG = SP - nArgs - 5 to position callee arguments correctly.
Save & restore
Push return address, then LCL, ARG, THIS, THAT and restore them using frame offsets on return.
Global naming
Qualify static names by file and use a global counter for return labels to avoid collisions.
These three reminders quickly pinpoint the usual causes of incorrect behavior when translating function calls and preparing programs for emulator testing.
