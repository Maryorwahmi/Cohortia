Use frame = LCL to access saved pointers with fixed negative offsets. Restoring THEM in order is what returns the VM to the caller's context.
Practical checklist
  • • Confirm the push order when emitting call code matches the expected restore offsets.
  • • Save frame = LCL into a temp register before restoring values.
  • • Restore pointers from frame - 1, frame - 2, etc., according to the template you implement.
  • • After restoring, reset SP = ARG + 1 so caller's stack area is intact.
Why ordering matters

A different push order would require different offsets on restore. The standard chosen ordering makes ARG calculation and restore code straightforward and consistent across calls.
