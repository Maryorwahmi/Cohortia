Module 06 › Chapter 6.2 › What function calling means
Definition

Frame-based call semantics

A frame is the caller's saved context plus the callee's locals and arguments. The translator implements this by pushing values onto the stack and updating pointer registers so both caller and callee find their data reliably.

Analogy: hotel rooms
Caller packs its state, leaves a return address, and the callee sets up its room with zeroed locals. On return the caller's room is restored.
Common misconception
Only saving the return address is insufficient; local pointers must be preserved too or the caller loses its address bases.
Visual
Stack frame layout
Top of stack: caller pushes return address, then LCL, ARG, THIS, THAT. After that the callee will set ARG and LCL and push its locals. On return the saved frame is used to restore pointers and to retrieve the return address.
Key Takeaway

Successful calls require both a saved return address and saved frame pointers to preserve caller context across nested and recursive calls.
