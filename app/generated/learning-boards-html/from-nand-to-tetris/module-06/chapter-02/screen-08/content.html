Module 06 › Chapter 6.2 › Bootstrap code
Assembly
// Initialize SP = 256
@256
D=A
@SP
M=D

// Call Sys.init (the OS entry point)
@Sys.init
0;JMP
Place this code once at the top of the generated assembly file. It sets up a consistent stack base and transfers control to the OS initializer.
Why Sys.init
Sys.init performs system initialization such as allocator and device setup, then calls user code. Calling it ensures the environment is ready before Main.main executes. Emitting bootstrap more than once or in the wrong place leads to duplicate initialization and unexpected behavior.
Key Takeaway

Bootstrap sets SP and invokes Sys.init exactly once; do not emit it per input file when translating a directory of VM files.
