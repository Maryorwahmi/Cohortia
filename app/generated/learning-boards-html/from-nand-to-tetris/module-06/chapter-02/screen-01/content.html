Function calling mechanics

This slide introduces the pieces you will implement: the function command that creates locals, the call and return sequences that save and restore frames, and the bootstrap that starts the VM. Understanding these pieces is essential to translating higher-level VM programs into working assembly.

In this lesson

Implement function, call, and return; generate bootstrap; support multiple files and test with recursive programs.

Coming up

Concrete assembly templates, stack-frame layout, ARG calculation, restoring frame pointers, and debugging tips for recursive calls.

Concept Map

Function
Create label, push n locals as zeros.
Bootstrap
Set SP = 256 and call Sys.init.
