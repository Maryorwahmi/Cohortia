Module 06 › Chapter 6.2 › Multiple VM files

Symbol scoping

• Qualify static symbols with the file name: FileName.0, FileName.1, etc.
• Treat the concatenated assembly as a single program; avoid per-file bootstrap emission.
• Maintain translator-global counters for unique labels across all input files.
Example check

In StaticsTest, a static variable set in A.vm should be visible when read in B.vm because both reference A.index as the same assembly symbol.

Concatenation order

Translate files in a deterministic order (for example, alphabetical) so the output is reproducible. But correctness depends on symbol naming and label uniqueness, not the specific file order.

Key Takeaway

Use file-qualified static names and translator-level unique label generation to keep the assembled program correct when merging multiple VM translations.
