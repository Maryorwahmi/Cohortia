Module 06 › Chapter 6.2 › Implementing the call command
Process

Step-by-step call prologue

  1. Push a unique return address and increment SP.
  2. Push LCL, ARG, THIS, THAT in that order, each time incrementing SP.
  3. Compute ARG = SP - nArgs - 5 and store it in ARG.
  4. Set LCL = SP.
  5. Jump to functionName and place the return label after the jump.
Example
If SP=300 and nArgs=2 then ARG becomes 293, so the callee finds its two arguments beginning at RAM[293] and a clean region for local allocation above SP.
Assembly pattern
// Push return address
@RET_LABEL
D=A
@SP
A=M
M=D
@SP
M=M+1

// Push LCL, ARG, THIS, THAT
@LCL
D=M
@SP
A=M
M=D
@SP
M=M+1
// (repeat for ARG, THIS, THAT)

// ARG = SP - nArgs - 5
@SP
D=M
@nArgs
D=D-A
@5
D=D-A
@ARG
M=D

// LCL = SP
@SP
D=M
@LCL
M=D

// Jump to function
@functionName
0;JMP

(RET_LABEL)
Ensure RET_LABEL is unique per call. A translator typically generates labels with an increasing counter to avoid collisions across files and calls.
