Validation checklist

  • • Unique return labels for each call to avoid collisions.
  • • ARG = SP - nArgs - 5 calculation yields the correct argument base inside callee.
  • • LCL updated to SP after pushing saved context and return address.
  • • On return, THAT, THIS, ARG, LCL restored from the saved frame in the correct order.
  • • Static variables emitted with global names and not reallocated per file.
Key Testing Tip

Step through the generated assembly in the CPU Emulator to watch SP and pointer changes at each call and return.
