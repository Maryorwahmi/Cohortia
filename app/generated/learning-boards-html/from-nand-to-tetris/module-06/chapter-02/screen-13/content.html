Module 06 › Chapter 6.2 › Tracing Fibonacci

Tracing steps

  1. Translate fib VM into assembly with unique return labels per call site.
  2. Run in CPU Emulator and watch SP at each call to record maximum value.
  3. Count call events to measure how many frames were created during execution.
  4. Use the emulator's instruction counter to measure executed instructions for the whole run.
Practical hint

Annotate the VM code with comments where calls occur so the generated assembly contains identifiable call-site labels to search and count emitted call prologues and epilogues.

Example question

• How many stack frames are created when computing fib(5)? Trace calls to count frames in the emulator.
• What is the maximum stack depth? Record SP and subtract base SP to compute depth.
• How many assembly instructions are executed? Use the emulator's cycle/instruction counter.
Reflection

Comparing measured counts with your theoretical call-tree counts helps you understand the cost of recursion and validates that your translator emits prologues and epilogues correctly for every call.
