Why ARG = SP - nArgs - 5

At call time SP points after the pushed arguments. The call then pushes five values, so the first argument is located at SP - nArgs - 5. Setting ARG to this expression makes argument 0 addressable by the callee.

Common misconception

Some think saved pointers are only for optimization. They are required; without them the return command cannot restore the caller's LCL and ARG, breaking nested calls and recursion.

Key Takeaway

Exact placement of saved values and arguments is what lets the callee compute ARG and LCL reliably and the return command restore the caller.
