Module 6 › Chapter 6.1 › Key Concepts
Stack frame
Arguments, locals, return address, and saved LCL/ARG/THIS/THAT form each frame.
Call / Return symmetry
Call saves the caller and sets up ARG/LCL; return restores and passes back the result.
Calling convention
Caller pushes args; call saves return and pointers; ARG = SP − nArgs − 5; callee initializes locals.
Final takeaway

Follow the call and return protocol exactly. Correct ordering of pushes, ARG/LCL computation, and FRAME-based restores is what makes function calls reliable.
