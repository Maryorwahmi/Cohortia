Module 6 › Chapter 6.1 › function
Specification

VM: function functionName nLocals — declare label and push nLocals zeros.

Translator pattern
  1. Emit label (functionName).
  2. Repeat nLocals times: push constant 0; push to stack.
Example output (assembly-like)
(Main.add)
@0
D=A
@SP
A=M
M=D
@SP
M=M+1
@0
D=A
@SP
A=M
M=D
@SP
M=M+1
Pitfall

Initializing locals incorrectly shifts LCL and ARG calculations for subsequent calls and breaks argument addressing. Always allocate exactly nLocals zeros right after the function label.
