Return sequence
  1. FRAME = LCL
  2. RET = *(FRAME - 5)
  3. *ARG = pop() (place return value)
  4. SP = ARG + 1
  5. Restore THAT, THIS, ARG, LCL from FRAME-1..FRAME-4
  6. goto RET
Example (conceptual)
// FRAME = LCL // RET = *(FRAME - 5) // *ARG = pop() // SP = ARG + 1 // restore THAT, THIS, ARG, LCL // goto RET
Misconception

Don't assume the return value remains at the top of the callee's stack. It must be moved to the caller's ARG slot so the caller finds it predictably.

Key Takeaway

Return uses FRAME offsets to restore the caller and places the return value at ARG for the caller to consume.
