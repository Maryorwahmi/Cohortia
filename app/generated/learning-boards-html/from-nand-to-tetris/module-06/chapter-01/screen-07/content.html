Module 6 › Chapter 6.1 › call
Step-by-step call sequence
1. push return-address (unique label)
2. push LCL
3. push ARG
4. push THIS
5. push THAT
6. ARG = SP - nArgs - 5
7. LCL = SP
8. goto functionName
Example: call Foo 2
@RETURN_LABEL
D=A
@SP
A=M
M=D
@SP
M=M+1
// push LCL
@LCL
D=M
@SP
A=M
M=D
@SP
M=M+1
// push ARG, THIS, THAT ...
// compute ARG = SP - 2 - 5
Pitfall

Do not compute ARG before pushing the five saved values. SP must reflect the pushes so ARG points to the correct argument base.
