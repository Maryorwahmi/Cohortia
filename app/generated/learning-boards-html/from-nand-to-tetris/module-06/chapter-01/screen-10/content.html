Module 6 › Chapter 6.1 › Example: add
VM code
// In main:
push constant 3
push constant 5
call Main.add 2
pop local 0

// In add:
function Main.add 0
push argument 0
push argument 1
add
return
Stack snapshot (conceptual)

After pushing 3 and 5: top = 5, next = 3. After call: return address and saved pointers are pushed above them, ARG points at 3, and LCL points to top-of-stack. After add returns, the result 8 is placed at the caller's ARG slot for main to pop into local 0.

Translator checklist
  • Emit unique return label for each call.
  • Push saved pointers before computing ARG.
  • Ensure function pushes nLocals zeros.
  • Return moves value to *ARG and restores frame.
Key Takeaway

Trace concrete VM sequences to validate SP, ARG, and LCL values at each step; this prevents off-by-one frame errors.
