What happens each call
  • A new frame is pushed with arguments and saved pointers.
  • The callee initializes its locals independently of other frames.
  • On return, the frame is popped and the caller's frame is restored.
Practical note

Trace depth to ensure base cases terminate recursion; otherwise stack frames grow until memory is exhausted on the Hack platform.

Example: factorial(3)
Calls: factorial(3) → factorial(2) → factorial(1) → factorial(0). Frames active at deepest point: 4. Each frame holds its argument n and a return address to multiply by the caller.
Misconception

Locals are not shared across recursive calls. Each activation has its own set; treating them as shared leads to incorrect reasoning about state and bugs.

Trace a recursive call by writing out each frame's ARG, LCL, and return address; check how values combine on the way back.
