Module 6 › Chapter 6.1 › Calling Convention
Caller duties
  • Push arguments.
  • Push return address, LCL, ARG, THIS, THAT.
  • Compute ARG = SP - nArgs - 5 and set LCL = SP.
Callee duties
  • Declare label and push nLocals zeros.
  • Use argument and local segments to access data.
  • On return, move result to *ARG and restore saved pointers.
Quick check

Who saves the return address? The caller. Who initializes locals? The callee. Keep these roles straight when you write the translator.
