Definition

Stack frame components

  • Arguments: values pushed by caller before call.
  • Local variables: initialized by the function command as zeros.
  • Return address: a label telling where to resume in the caller.
  • Saved pointers: previous LCL, ARG, THIS, THAT to restore state.
Analogy
Think of each frame as a tray that carries a function's inputs, private items, and a sticky note telling the caller where to continue.
Example: add(3,5)
// In main:
push constant 3
push constant 5
call Main.add 2
pop local 0

// In add:
function Main.add 0
push argument 0
push argument 1
add
return
Key Takeaway

Frames isolate each call's data and store the return address so nested calls and recursion work predictably.
