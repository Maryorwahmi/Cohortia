Implementation steps
  1. function: emit (functionName) and push nLocals zeros.
  2. call: emit return label, push saved pointers, compute ARG/LCL, goto function.
  3. return: FRAME=LCL, RET=*(FRAME-5), *ARG=pop(), restore and goto RET.

Common bugs & fixes
  • Off-by-one ARG computation — recompute using SP after pushes.
  • Not using a unique return label — create one per call site.
  • Restoring pointers in wrong order — follow FRAME offsets exactly.
Pro tip

Instrument generated assembly with comments and SP/LCL/ARG printouts during early debugging to validate frame structure.
