Function Calling: The Call Stack

Understand stack frames, the function/call/return trio, and how the calling convention maps to stack operations in Hack assembly.

Why this matters

Correct function calls let separate parts of a program run without corrupting each other's local data. The call stack makes recursion possible and ensures return addresses and saved pointers are restored precisely.

What you'll practice
  • Trace stack frames for nested and recursive calls
  • Translate function/call/return to Hack assembly
  • Implement and test the VM translator's function support
Explore Key Topics
Stack Frame
Arguments, locals, return address, saved pointers.
Call Sequence
Return address, save segments, set ARG and LCL, jump.
Return Behaviour
Restore frame, push return value, jump to caller.
Visual metaphor

Think of the call stack as a stack of trays. Each tray carries arguments and a note with the return address. When a function returns, its tray is removed and the note tells the caller where to resume.
