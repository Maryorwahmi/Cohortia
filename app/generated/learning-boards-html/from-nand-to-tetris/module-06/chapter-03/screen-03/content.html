Testing workflow
Follow this sequence for each test directory:
  1. Run the VM translator on the directory to produce a single .asm file.
  2. Assemble the .asm file into a .hack binary.
  3. Load the .hack file into the Computer Simulator and execute the program.
  4. Observe the call stack, stack pointer, and memory segments during execution.
Measurement checklist
  • Record translation time for Pong and Tetris.
  • Count lines of generated assembly.
  • Measure run time steps or frames in the simulator.
Key Takeaway

Concrete measurements help you reason about abstraction cost and identify hotspots for optimization or debugging.
