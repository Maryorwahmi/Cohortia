Case Study › Pong
Why Pong matters
  • Exercises object calls and instance fields.
  • Requires correct static naming and segment accesses.
  • Depends on program flow for animation and collision logic.
Runtime check

Watch writes to screen memory while the game updates. If the ball does not move visually, check drawing routines and memory addresses used for the frame buffer.

Troubleshooting guide
  1. Confirm static variables are namespaced and unique per file.
  2. Step through a frame update to see where expected writes stop.
  3. Test keyboard input handlers with minimal VM snippets to ensure reads work.
Key Takeaway

Pong gives immediate visual feedback that many translator features interact correctly; use it to find integration-level bugs.
