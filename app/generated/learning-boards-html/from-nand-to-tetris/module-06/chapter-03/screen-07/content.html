Definition › Memory Segments
Segment reference
  • local — relative to LCL, per-function locals.
  • argument — relative to ARG, where parameters live.
  • this / that — object or OS memory regions.
  • temp — fixed small area in RAM, limited indexes.
  • pointer — directly sets THIS or THAT.
  • constant — immediate values; no memory access.
  • static — file-scoped variables mapped to named symbols.
Example

push static 3 in file Foo.vm → access Foo.static.3. This preserves independence between Foo and other files.

Concrete code example
// VM: push static 3 (in Foo.vm)
@Foo.static.3
D=M
@SP
A=M
M=D
@SP
M=M+1
Check StaticsTest: write into Foo.static.3 and read it back after calling functions from another file. If values clash, static naming is incorrect.
