Architecture › Testing Workflow
Repeatable process
1. Translate
2. Assemble
3. Run & observe
For debugging: reproduce the error with a minimal VM example, compare your assembly to a reference, and iterate on fixes. Log unique label generation and static naming to confirm scoping rules.
Small experiment

If a function return value is wrong in NestedCall, write a two-line VM program that calls the same nested sequence and step through only that translated assembly to observe where the value is lost.

Measurement cards
Translation time

Record how long translation takes for Pong and Tetris to compare stages.

Assembly size

Count lines of generated .asm; large counts are expected but useful for reflection.

Key Takeaway

Measure and isolate. Small tests beat blind changes when debugging complex program failures.
