Process Flow › Bootstrap & Files
Process steps
  1. Emit bootstrap: set SP and call Sys.init if required.
  2. Iterate VM files: translate and append to a single .asm output.
  3. Namespace statics: prefix static symbols with file name.
  4. Generate unique labels using function names and counters.
  5. Assemble and run the resulting .asm in the simulator.
Example naming

File A's static variable number 3 → A.static.3. File B's static 3 → B.static.3. This prevents cross-file collisions when both are linked into one assembly file.

Pitfall

Appending files without namespacing statics or labels causes subtle runtime errors when games depend on isolated static storage.

Top/bottom example
A minimal bootstrap sequence in conceptual assembly form:
// bootstrap
@256
D=A
@SP
M=D
// call Sys.init
@Sys.init.return.0
D=A
@SP
A=M
M=D
@SP
M=M+1
@Sys.init
0;JMP
(Sys.init.return.0)
