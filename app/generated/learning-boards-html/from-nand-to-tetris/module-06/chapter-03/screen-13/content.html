Assessment › Abstraction Layers
Layer hierarchy
Jack
High-level language with classes and methods. Shields programmers from manual stack management.
VM
Stack-based intermediate code that abstracts hardware details and enables portability.
Assembly
Symbolic instructions and labels, one step away from machine code.
Machine code
Binary instructions executed by the CPU.
CPU Microarchitecture
ALU, registers, and control logic that implement machine instructions.
Logic Gates
Nand-based circuits that implement the CPU primitives.
Assessment prompt

Describe each layer's purpose and give one concrete example of what it hides from the layer above. Explain why these abstractions are essential for building complex systems.
