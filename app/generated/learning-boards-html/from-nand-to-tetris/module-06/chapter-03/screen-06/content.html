Concrete check

When a callee returns, the translator must move the return value to the caller's stack location and restore saved pointers in the right order to recover the caller environment.

Debugging tips
  • Inspect SP and LCL values before and after calls to ensure correct updates.
  • Set temporary labels for return addresses with unique counters to avoid collisions.
  • Use small test programs with known return values to validate behavior before running large games.
Pitfall

Miscalculating ARG (for example off by one) is the most common mistake in call/return implementation.
