Checklist
  1. Implement all VM commands and bootstrap.
  2. Handle multiple files and namespace statics.
  3. Run unit tests and fix issues incrementally.
  4. Translate Pong and Tetris, assemble, and run in simulator.
  5. Record timings, assembly sizes, and runtime observations.
  6. Write a two-page reflection tying practice to abstraction theory.
Reflection prompts
  • How long did translation take for Pong and Tetris?
  • How many assembly lines were produced for each game?
  • What runtime behavior or memory trace surprised you most?
  • How did this project change your understanding of abstraction layers?
Key Takeaway

A disciplined hands-on plan plus reflection turns a working translator into demonstrable understanding of the toolchain and abstractions.
