Module 1 › Chapter 1.3 › Mux vs DMux
Mux

Select a source

Choose which input feeds a shared consumer using selection bits.

Use case
Selecting register value to drive an ALU input.
Testing
Verify every sel value and that out equals the selected input for all bits in multi-bit versions.
DMux

Route to a destination

Take one input and send it to exactly one chosen output line based on selection bits.

Use case
Send a write-enable to a single register when writing data to register file.
Testing
Confirm exactly one output equals the input for each selection vector; others must be zero.
Reflection
Scan a simple CPU datapath and mark where source selection and destination routing are required. Those are the places Muxes and DMuxes live.
