Module 1 › Chapter 1.3 › Mux16
Concept

Parallel 1-bit Muxes

Broadcast the same sel to 16 1-bit Mux instances so each bit is selected independently but at the same time.

Why parallelism helps
Parallel replication is straightforward, aligns with hardware fanout, and makes testing simple.
Common bug
Indexing errors: wiring a[1] to out[0] or accidentally creating mismatched bit connections.
HDL Pattern
CHIP Mux16 {
    IN a[16], b[16], sel;
    OUT out[16];

    PARTS:
    Mux(a=a[0], b=b[0], sel=sel, out=out[0]);
    Mux(a=a[1], b=b[1], sel=sel, out=out[1]);
    ...
    Mux(a=a[15], b=b[15], sel=sel, out=out[15]);
}
Key Takeaway

Broadcast the selection bit to all 1-bit Muxes and verify with test vectors that check all bits under both selection values.
