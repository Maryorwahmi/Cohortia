Build list

Complete these HDL chips and tests in order to build confidence progressively.

Stage 1
  • Mux (2-to-1)
  • DMux (1-to-2)
Stage 2
  • Mux16 and DMux16
  • Test broadcast selection and mixed-bit patterns
Stage 3
  • Mux4Way16, Mux8Way16
  • DMux4Way, DMux8Way
Testing tips
  • Cover all selection vectors
  • Check intermediate outputs when a test fails
Key Takeaway

Progressively build from small to large chips and use systematic tests that exercise both selection and data to ensure correctness.
