Practice & Verification

What to build and how to confirm correctness

Learn → Understand → Apply → Master
01
Draw block diagrams
Use smaller Mux/DMux blocks to assemble wider chips so design follows composition rules and is easy to verify.
VERIFIED COMPETENCY MILESTONE
02
Instantiate in HDL
Write Mux16 and Mux4Way16 by instantiating 1-bit components in parallel and broadcast selection bits.
VERIFIED COMPETENCY MILESTONE
03
Run systematic tests
Cover all selection values and all bus bits to confirm each output matches the expected routed input.
VERIFIED COMPETENCY MILESTONE
04
Debug selection vs data
Check selection bits are correct and data lines carry expected values so you can isolate routing faults quickly.
VERIFIED COMPETENCY MILESTONE
Keep these objectives visible while building: they will guide how you sketch diagrams, write HDL, and create tests.
