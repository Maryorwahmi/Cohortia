Module 1 › Chapter 1.3 › Combinational Logic
Definition

Combinational circuits

Outputs depend only on current inputs. No storage or state appears in the function.

Concrete example
If a=1, b=0, sel=0, then Mux output=1 by the equation: (a AND NOT sel) OR (b AND sel). This result is deterministic for that input combination.
Misconception
Selection is not computation. It routes a chosen signal; it does not modify the routed data bits.
Why this matters
Determinism makes testing straightforward: one input vector maps to one output vector—ideal for automated test scripts.
Teaching Visual
Boolean form
Mux(a, b, sel) = (a && !sel) || (b && sel)
Implementation uses Not, And, and Or gates. For the Mux16 you replicate this 16 times with the same sel broadcast to every bit.
Key Takeaway

Because each bit is independent, multi-bit selectors are parallel replications of the 1-bit boolean function.
