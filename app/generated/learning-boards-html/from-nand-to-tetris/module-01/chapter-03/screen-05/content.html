Module 1 › Chapter 1.3 › 2-to-1 Mux
Function

Select between a and b

If sel=0, out=a; if sel=1, out=b. This routing is stateless and deterministic.

Boolean
Mux(a, b, sel) = (a && !sel) || (b && sel)
Example
Selecting which register value feeds the ALU based on a control signal. The Mux forwards the chosen register bits unchanged.
Common mistake
Mixing selection logic into data expressions. Keep selection as gating signals that control which data path is active.
HDL Walkthrough
The HDL uses Not, And, And, Or parts to implement the expression. Below is the reference implementation you will create and test in the simulator.
CHIP Mux {
    IN a, b, sel;
    OUT out;

    PARTS:
    Not(in=sel, out=notSel);
    And(a=a, b=notSel, out=aAndNotSel);
    And(a=b, b=sel, out=bAndSel);
    Or(a=aAndNotSel, b=bAndSel, out=out);
}
Key Takeaway

Implement Mux using explicit gates and test both sel=0 and sel=1 with varied data to confirm routing.
