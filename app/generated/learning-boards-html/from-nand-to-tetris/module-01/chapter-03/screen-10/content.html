Module 1 › Chapter 1.3 › DMux Tree
Pattern

1-to-4 from 1-to-2 parts

Split the input, then split each branch again. Selection bits choose the branch hierarchy.

Step example
Top: DMux(in, sel1) → left, right. Then DMux(left, sel0) → out0,out1; DMux(right, sel0) → out2,out3.
Verification
For each sel pair, exactly one out should equal in and all others must be zero.
Practical note

DMux trees drive control lines to many modules. Ensure fanout and signal integrity when routing enables in actual hardware designs.

Key Takeaway

DMux composition mirrors Mux recursion in reverse; build larger routers by reusing tested 1-to-2 DMux units.
