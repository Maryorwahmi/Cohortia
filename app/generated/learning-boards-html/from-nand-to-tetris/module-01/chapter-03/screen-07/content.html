Module 1 › Chapter 1.3 › Demultiplexer
Definition

1-to-2 DMux

Route one input to exactly one of two outputs based on a selection bit.

Boolean
a = in && !sel
b = in && sel
Example
Send a control pulse to exactly one of two devices. If in=1 and sel=1, then b=1 and a=0.
Pitfall
Ensure inactive outputs are driven low. Floating outputs lead to indeterminate hardware behavior.
Composition
You can build 1-to-4 DMux by combining three 1-to-2 DMuxes in a similar hierarchical pattern used for Muxes; this recursively expands routing to more outputs.
Key Takeaway

DMux duplicates the selection logic on the input and gates it to exclusive outputs; composition gives wider routing trees.
