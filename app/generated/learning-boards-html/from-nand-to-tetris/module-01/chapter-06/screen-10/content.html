Module 1 › Chapter 1.6 › Design methodology
Five-step loop
  1. Understand: Read the spec and truth table.
  2. Design: Derive boolean expressions and decomposition.
  3. Write: Implement HDL with precise pin names.
  4. Test: Run simulator scripts and inspect internal values.
  5. Verify: Confirm all tests pass and document decisions.
Example: Mux4Way16
Decide to use two Mux4Way16 stages or combine Mux16 and Mux components into a tree. Write HDL reflecting that tree, test with various selection patterns, and fix wiring or pin naming issues revealed by failing cases.
Pro tip
Document the decomposition in one paragraph. When you revisit the chip months later, the log speeds up understanding and maintenance.
