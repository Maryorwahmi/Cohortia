Module 1 › Chapter 1.6 › Not and And
Step sequence
1
Write truth table
List input combinations and expected outputs for Not and And.
2
Derive boolean form
Not(x) = Nand(x,x). And(a,b) = Not(Nand(a,b)).
3
Write HDL and test
Name pins exactly, connect internal wires, run the test script, and debug failures.
Key Takeaway
Small compositions such as compute-then-invert are the reusable patterns you will apply repeatedly.
Concrete example
// And.hdl (conceptual)
CHIP And {
  IN a, b;
  OUT out;
  PARTS:
  Nand(a=a, b=b, out=n1);
  Nand(a=n1, b=n1, out=out);
}
Use the simulator to ensure that for all four input combinations the resulting out matches a and b conjunction. If a test fails, check internal wire n1 for expected values.
