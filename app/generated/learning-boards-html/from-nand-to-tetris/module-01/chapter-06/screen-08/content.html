Module 1 › Chapter 1.6 › Multi-bit chips
Design pattern
Replicate a 1-bit chip across 16 wires. Use consistent names like in[0]..in[15] or a[0]..a[15] as the project requires, and reuse the 1-bit HDL pattern inside a 16-bit wrapper.
Testing guidance
Test single-bit cases and full-word patterns (all zeros, all ones, alternating bits) to ensure per-bit wiring is correct.
Concrete example
Not16 is sixteen Not components. Mux16 is sixteen Mux components, each with the same selector. If one bit fails, inspect that bit's internal Mux instance and its input wiring immediately.
Key Takeaway
Scaling logic is mechanical once the 1-bit case is correct; verification of each parallel instance is what prevents subtle multi-bit bugs.
