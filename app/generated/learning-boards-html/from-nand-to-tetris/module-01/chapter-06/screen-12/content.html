Module 1 › Chapter 1.6 › Pitfalls & Debugging
Top pitfalls
  • Wrong pin names: check case and spelling.
  • Missing connections: every input must be connected to exactly one source.
  • Floating wires: undefined values indicate unconnected nets.
  • Circularity: avoid feedback loops in combinational chips.
Debugging checklist
Run leaf-level tests first.
Use descriptive internal names for easier simulator reads.
Keep a short log of fixes and decisions for each chip.
When a top-level chip fails, re-run lower-level component tests to isolate the fault.
