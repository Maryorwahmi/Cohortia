Module 1 › Chapter 1.6 › Mux vs DMux
1-bit routing patterns
Mux: out = (a AND NOT(sel)) OR (b AND sel). DMux: route in to either a or b depending on sel, leaving the other output zero. Implement gating with Nand-based And and use Not where needed.
Common pitfall
For 16-bit variants, forgetting to apply the selection signal to every parallel gate causes word-level failures.
Concrete example
When building Mux16, instantiate sixteen Mux chips in parallel, each with the same sel input. Name wires like in[0]..in[15], out[0]..out[15], and use the exact pin names the simulator expects.
Key Takeaway
Routing logic is repetitive: design once for 1-bit, then parallelize carefully for multi-bit versions.
