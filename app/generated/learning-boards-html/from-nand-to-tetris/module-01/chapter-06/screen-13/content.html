Module 1 › Chapter 1.6 › Hands-on Activity
Task list
  • Implement the 15 chips in the specification using only Nand and your already-built chips.
  • Run the provided Hardware Simulator test scripts for each chip.
  • Keep a one-paragraph log entry per chip documenting design choices and debugging steps.
  • Time yourself and note which chips took the most effort.
Reflection prompts
Which chips were hardest and why?
How did building simple chips first make larger chips easier?
Which debugging techniques saved the most time?
How does this project change your mental model of a computer?
