Module 1 › Chapter 1.6 › Or and Xor
Or via De Morgan
a OR b = NOT( NOT(a) AND NOT(b) ). Build NOT(a) and NOT(b) from Nand, then compose an And and invert it.
Why decompose
Decomposing into named internal wires makes it easy to inspect each step in the Hardware Simulator and fix wiring or naming errors quickly.
Concrete tip
When debugging Xor, check intermediate terms like aAndNotB and notAAndB; the final Or of those internals should match expected exclusivity.
Example sketch
// Or.hdl (conceptual)
CHIP Or {
  IN a, b;
  OUT out;
  PARTS:
  Nand(a=a, b=a, out=na);
  Nand(a=b, b=b, out=nb);
  Nand(a=na, b=nb, out=n1);
  Nand(a=n1, b=n1, out=out);
}
Test for all input pairs. If a case fails, check na and nb values first to see if Not operations are correct.
