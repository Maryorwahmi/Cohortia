Project 1: Elementary Gates
Create 15 chips from a single Nand primitive and verify each with the Hardware Simulator.
Why it matters
Verified components reduce bugs as complexity grows. These chips become the course's standard library.
How you'll work
Design boolean logic, write HDL, run simulator tests, and debug until each chip passes.
In this lesson
A walkthrough of the 15 chips, the compositional hierarchy, and the verification steps you'll use repeatedly.
Coming up
Hands-on: pick one chip, write HDL, run its test script, and note debugging steps.
