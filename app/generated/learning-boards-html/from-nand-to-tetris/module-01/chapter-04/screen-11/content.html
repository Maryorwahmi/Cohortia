Representative test vectors
  • 0x0000 — all zeros
  • 0xFFFF — all ones
  • 0xAAAA / 0x5555 — alternating patterns
  • Single bit high — check each output position
Debug workflow
  1. Test 1‑bit gates exhaustively.
  2. Run representative multi‑bit vectors.
  3. When a test fails, inspect which output bits differ to localize the faulty instance.
  4. Add targeted single‑bit tests to confirm fixes.
