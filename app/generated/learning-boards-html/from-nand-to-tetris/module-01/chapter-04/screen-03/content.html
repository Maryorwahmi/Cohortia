Test vectors to try
  • All zeros (0x0000) — checks identity wiring and inversion mistakes.
  • All ones (0xFFFF) — ensures gates react to full ones across the bus.
  • Alternating patterns (0xAAAA / 0x5555) — expose bit-order or indexing faults.
  • Single bit high — verifies each output bit position separately.
Reasoning checkpoints
  • Confirm each bit is handled independently by checking several single‑bit cases.
  • Count primitive gates to validate your internal structure.
  • Verify Or8Way composition by testing a half with one high bit and the other half zeros.
