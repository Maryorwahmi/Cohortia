Basic Logic Gates and Their Multi‑bit Versions
How to build 1‑bit gates from Nand, replicate them for buses, and use Or8Way for zero detection.
What you'll understand

How Not, And, Or, and Xor come from Nand; how to implement Not16/And16/Or16/Xor16 by replication; how Or8Way is composed as a tree; and how to verify these chips with test scripts.

Why it matters

Multi‑bit gates let hardware operate on full words in parallel. These primitives are reused throughout the ALU, registers, and memory systems you will build next.

Explore Key Topics
Gate from Nand
Every 1‑bit gate can be expressed with Nand. This keeps the design minimal and instructive.
Bus replication
Replicate a 1‑bit gate 16 times to operate on 16‑bit words in parallel.
Or8Way & Zero detect
Use a tree of Ors to detect any high bit in a group and compose for zero detection.
Visual concept
Imagine two 16‑bit trains passing through 16 paired gates, producing a 16‑car output train.

// Or(x,y) = Nand(Not(x), Not(y))
// Xor(x,y)= (x && !y) || (!x && y)
Key Takeaway

Build complex word operations by composing simple, tested 1‑bit gates across a bus. The hardware cost scales linearly with the number of bits because each bit is processed independently.
