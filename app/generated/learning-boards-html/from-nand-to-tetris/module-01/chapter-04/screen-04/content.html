Module 1 › Chapter 1.4 › 1‑Bit Gates
Not

Definition: output is the logical complement of input. Identity used: Not(x) = Nand(x, x).

Concrete example: if input = 1, Not = 0. If input = 0, Not = 1.
And

Definition: output is 1 only if both inputs are 1. Implemented as Not(Nand(x,y)).

Common misconception: And is not the same as multiplication on multi‑bit words unless you apply it bitwise.
Or and Xor

Or returns 1 if at least one input is 1; Or(x,y) = Nand(Not(x), Not(y)). Xor returns 1 when inputs differ: Xor(x,y) = (x && !y) || (!x && y).

Concrete check: x=1,y=0 gives Or=1 and Xor=1; x=1,y=1 gives Or=1 but Xor=0.
Truth examples and quick table
Inputs: x=1,y=0
Results: Not(x)=0, And=0, Or=1, Xor=1
Inputs: x=1,y=1
Results: Not(x)=0, And=1, Or=1, Xor=0
Common mistake

Treating Xor as simply an adder without carry. Xor is bitwise difference but it does not propagate carry bits; addition requires separate carry logic.
