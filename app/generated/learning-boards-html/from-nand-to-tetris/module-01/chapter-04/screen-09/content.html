Or8Way composition
Use a balanced tree of Or gates. This minimizes levels of logic and keeps the detector fast.
// Expression form:
// Or8Way(a,b,c,d,e,f,g,h) = Or(Or(Or(a,b), Or(c,d)), Or(Or(e,f), Or(g,h)))

// HDL style: instantiate intermediate Or parts and combine.
Concrete test

Set input g high and all others low; Or8Way should return 1, verifying that the subtree containing g is wired correctly.

Pitfall

A linear chain of Ors increases depth unnecessarily; prefer balanced pairing for minimal levels.
