Module 1 › Chapter 1.4 › Lab Plan
Stepwise tasks
  1. Implement and test 1‑bit gates exhaustively.
  2. Implement Not16 and test with 0x0000/0xFFFF.
  3. Implement And16/Or16/Xor16 and run representative vectors.
  4. Implement Or8Way and test single‑input highs.
  5. Compose zero detection with two Or8Way + Or + Not and verify.
  6. Document gate counts and draw internal structure.
Practical hints
  • Test single bits at both low and high indices to catch indexing errors.
  • Use the simulator log to see which outputs differ and localize failures.
  • Record expected gate counts as a cross‑check on your PARTS list.
