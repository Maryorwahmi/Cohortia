Replicate Or and Xor
Pattern for Or16 and Xor16 is identical to And16: repeat the 1‑bit gate across indices 0..15. Use representative test vectors to confirm correctness.
// Example test expectations
// Or16(0xAAAA, 0x5555) => 0xFFFF
// Xor16(0xFFFF, 0xFFFF) => 0x0000
Check

If your Xor16 returns 0xFFFF for 0xAAAA ^ 0x5555, indexing is likely correct. If not, inspect bit wiring and test vectors.

Pitfall

Confusing endianness: ensure tests and HDL use the same bit numbering so bit 0 corresponds to the expected least significant position.
