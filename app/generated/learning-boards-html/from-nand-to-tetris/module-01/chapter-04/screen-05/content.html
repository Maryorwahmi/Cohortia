HDL examples (1‑bit)
CHIP Not {
  IN in;
  OUT out;

  PARTS:
  Nand(a=in, b=in, out=out);
}

CHIP And {
  IN a, b;
  OUT out;

  PARTS:
  Nand(a=a, b=b, out=tmp);
  Nand(a=tmp, b=tmp, out=out); // Not(tmp)
}

CHIP Or {
  IN a, b;
  OUT out;

  PARTS:
  Nand(a=a, b=a, out=na);
  Nand(a=b, b=b, out=nb);
  Nand(a=na, b=nb, out=out);
}
Example

Writing Not as a single Nand shows why Nand is a complete primitive: every other gate is composed from it.

Common mistake

Confusing temporary signals across gates. Keep intermediate nets local and test 1‑bit behavior first to avoid scaling errors.
