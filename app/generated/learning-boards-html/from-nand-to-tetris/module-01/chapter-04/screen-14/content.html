Module 1 › Chapter 1.4 › Key Concepts
Nand completeness
All basic gates are expressible using Nand identities.
Multi‑bit replication
Implement 16‑bit gates by repeating the 1‑bit gate for each index.
Or8Way & zero detect
Use a balanced Or tree and combine halves to detect if a word is zero.
Takeaway

Simple primitives plus replication and composition give the multi‑bit building blocks used in the ALU; test thoroughly to ensure correctness before composing larger systems.
