Step-by-step
(x ∧ y) ∨ (x ∧ ¬y)
= x ∧ (y ∨ ¬y)      (factor x)
= x ∧ 1             (y ∨ ¬y = 1)
= x                 (identity: x ∧ 1 = x)

Longer example:
(x ∧ y) ∨ (x ∧ ¬y) ∨ (¬x ∧ y)
= x ∨ y  (after distributive and absorption steps)
Each line follows a named law. If a step seems unclear, re-evaluate affected truth-table rows to confirm equivalence.
Concrete example
Simplifying the expression reduced two product terms into a single literal x. This saves gates when implementing the function in hardware.
Misconception

Algebraic expansion can sometimes increase apparent term count temporarily; do not judge until absorption and further reductions are applied.

Key Takeaway
