Collect rows where output = 1 and form minterms by using each input or its negation.
Concrete check
After writing the SOP, re-evaluate all eight input rows to confirm the SOP produces the same outputs — this verifies correctness before simplification.
Tip

Use the truth table as the canonical source when you suspect simplification introduced an error; truth tables reveal incorrect reductions immediately.
