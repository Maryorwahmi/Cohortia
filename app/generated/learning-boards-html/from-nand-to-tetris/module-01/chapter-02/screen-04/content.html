Definition and truth tables
Variables are 0 or 1. And requires all inputs true; Or requires at least one true; Not flips a value.
a b a ∧ b a ∨ b
0000
0101
1001
1111
Example
Two switches controlling a lamp via And require both to be on; Or lights the lamp if either is on.
Common mistake
Don't confuse inclusive Or with exclusive Or; both-true still yields true for standard Or.
Concrete mapping
These truth tables are the definitive description you will use when creating canonical forms or testing simplified expressions; they define the function fully, independent of gate layout.
Try this
Write the single-input Not table and verify that Not(0)=1 and Not(1)=0. Then combine with And to see how negation changes a compound expression.
Key Takeaway

These three operations and their truth tables form the atomic, unambiguous descriptions used in every later transformation and circuit implementation.
