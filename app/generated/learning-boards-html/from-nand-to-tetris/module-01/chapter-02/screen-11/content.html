Module 1 › Chapter 1.2 › Hands-on Functions: Mux and DMux
Multiplexer (2-to-1)
Behavior: sel chooses whether output follows a or b.
Mux(a,b,sel) = (a ∧ ¬sel) ∨ (b ∧ sel)
Verify this by writing a truth table with a,b,sel and confirming outputs match selector behavior.
Demultiplexer (1-to-2)
Behavior: a single input is routed to one of two outputs based on sel.
DMux(in,sel) = (a = in ∧ ¬sel,  b = in ∧ sel)
Use truth tables for both output lines to confirm routing behavior and to derive canonical expressions.
Key Takeaway

These components show direct use of truth tables and SOP forms in hardware design. Always test derived expressions with a truth table before mapping to gates.
