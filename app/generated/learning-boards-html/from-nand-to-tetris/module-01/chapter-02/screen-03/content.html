Objective practice cards
Truth tables
Enumerate 2^n rows; verify majority function outputs for all eight rows.
Canonical forms
List minterms for SOP and maxterms for POS based on truth table rows.
Simplification
Apply algebraic laws to reduce gate count; check with truth tables.
Nand implementation
Rewrite using De Morgan so Or operations become Nand-friendly and Not(x)=Nand(x,x).
Verification milestones
  1. Produce a truth table for a 3-input function and label minterms and maxterms.
  2. Write the SOP form from the minterms and algebraically simplify one term using identities.
  3. Transform an Or into Nand form using De Morgan and implement Not with a Nand gate.
  4. Compare a canonical gate network vs the simplified network and explain the savings.
