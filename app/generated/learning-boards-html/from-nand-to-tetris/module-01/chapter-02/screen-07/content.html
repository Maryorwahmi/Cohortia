Module 1 › Chapter 1.2 › Boolean Identities and Laws
Law summary
  • Identity: x ∧ 1 = x, x ∨ 0 = x
  • Null: x ∧ 0 = 0, x ∨ 1 = 1
  • Idempotent: x ∧ x = x, x ∨ x = x
  • Complement: x ∧ ¬x = 0, x ∨ ¬x = 1
Algebraic tools
  • Commutative, associative: reorder and regroup without changing meaning.
  • Distributive: x ∧ (y ∨ z) = (x ∧ y) ∨ (x ∧ z)
  • Absorption: x ∨ (x ∧ y) = x
Applying the laws — workflow
  1. Locate repeated terms and potential factorizations.
  2. Use distributive law to factor shared literals.
  3. Apply absorption to remove redundant grouped terms.
  4. Remove any double negations to finish simplification.
Worked hint
(x ∧ y) ∨ (x ∧ ¬y) = x ∧ (y ∨ ¬y) = x ∧ 1 = x
Factor x, then use complement to simplify inside parentheses.
