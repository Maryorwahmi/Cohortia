Module 1 › Chapter 1.5 › Test Scripts
Template
load ChipName.hdl,
output-file ChipName.out,
compare-to ChipName.cmp,
output-list a%B3.1.3 b%B3.1.3 sel%B3.1.3 out%B3.1.3;

set a 0, set b 0, set sel 0, eval, output;
set a 0, set b 0, set sel 1, eval, output;
...
Checklist
  • Include eval after set commands so outputs update.
  • Use compare-to for automated verification.
  • Cover all combinations for small chips, edge and random patterns for buses.
  • Keep ordering of outputs consistent with .cmp files.
Key Takeaway

Automation via compare-to is essential; exhaustive tests give confidence for small components before they are reused.
