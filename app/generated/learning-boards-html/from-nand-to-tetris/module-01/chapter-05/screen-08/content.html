Passing sub-ranges into parts

Use a[i..j] to hand a contiguous subset of bits to a part that expects a bus of the same width.

Example call
Mux4Way16(a=a[0..15], b=b[0..15], c=c[0..15], d=d[0..15], sel=sel[0..1], out=out[0..15]);
Notes
Width matching
The sliced range must have the same width the part expects, otherwise connections fail.
Reuse and abstraction
Design and test N-bit components, then pass sub-ranges to use them in larger designs.
Key Takeaway

Sub-busing simplifies wiring when parts accept whole vectors; ensure ranges line up with expected widths.
