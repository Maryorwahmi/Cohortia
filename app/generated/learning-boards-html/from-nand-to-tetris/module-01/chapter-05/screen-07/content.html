Module 1 › Chapter 1.5 › Multi-bit Buses
Definition

Bus declaration and per-bit wiring

Declare inputs like a[16] and instantiate 1-bit parts for each index to implement bitwise operations.

And16 pattern
CHIP And16 {
  IN a[16], b[16];
  OUT out[16];

  PARTS:
  And(a=a[0], b=b[0], out=out[0]);
  ...
  And(a=a[15], b=b[15], out=out[15]);
}
Practical notes
Parallelism
Each bit is independent, so you can reason about correctness per index and run tests with representative patterns.
Reuse
If you have a tested 1-bit component, instantiate it across indices to build a wide component predictably.
Key Takeaway

Buses group bits by name and width; you still wire each bit explicitly when composing from 1-bit parts.
