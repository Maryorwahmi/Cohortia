Module 1 › Chapter 1.5 › Mux Walkthrough
Code
CHIP Mux {
  IN a, b, sel;
  OUT out;

  PARTS:
  Not(in=sel, out=notSel);
  And(a=a, b=notSel, out=aAndNotSel);
  And(a=b, b=sel, out=bAndSel);
  Or(a=aAndNotSel, b=bAndSel, out=out);
}
Annotations
notSel
Produced by Not(in=sel) and used as input to the first And.
aAndNotSel / bAndSel
Intermediate signals that represent the gated contributions of a and b based on sel.
Check

When sel is 0, aAndNotSel should carry a to out; when sel is 1, bAndSel should carry b. The simulator lets you confirm these signals step by step.
