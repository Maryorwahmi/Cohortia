Module 1 › Chapter 1.5 › Hardware Simulator
Test Script Steps
1. load ChipName.hdl
2. output-file ChipName.out
3. compare-to ChipName.cmp
4. set inputs, eval, output for each test case
Example commands
set a 0, set b 1, set sel 0, eval, output;
Debugging with the GUI
• When a test fails, the simulator reports the mismatching line and shows values for internal wires.
• Use stepping to observe how each part's outputs evolve across test cases.
• Confirm every internal wire is driven and connected as intended.
Key Takeaway

Automated compare-to is the fastest feedback loop. Always include eval and use exhaustive tests for small chips.
