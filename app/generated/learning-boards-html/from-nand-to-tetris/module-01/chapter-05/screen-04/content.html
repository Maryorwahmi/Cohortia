Module 1 › Chapter 1.5 › HDL file structure
Definition

CHIP, IN, OUT, PARTS

Each HDL file declares a single chip and maps its internal parts into a network of named wires. This structure mirrors hardware and supports modular composition.

CHIP declaration
Names the chip. Example: CHIP Mux { ... }
IN and OUT
Lists the external pins that form the chip's interface.
PARTS
Instantiates other chips; connections name inputs and outputs to form internal wiring.
Concrete Example
CHIP Mux {
  IN a, b, sel;
  OUT out;

  PARTS:
  Not(in=sel, out=notSel);
  And(a=a, b=notSel, out=aAndNotSel);
  And(a=b, b=sel, out=bAndSel);
  Or(a=aAndNotSel, b=bAndSel, out=out);
}
Key Takeaway

Think of the file as a circuit blueprint: inputs and outputs are ports, PARTS are devices, and matching names create wires between them.

Common Mistake

Expecting nested expressions instead of instantiating parts. HDL requires each operation to be a chip instance with a named output.
