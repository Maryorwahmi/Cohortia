Common Errors
  • Swapped connections (a=sel instead of a=a).
  • Missing or misnamed internal wires.
  • Wrong internal chip used in PARTS.
  • Bus width mismatches when slicing ranges.
Debug Sequence
1. Reproduce the failing test case from the script.
2. Read the simulator's discrepancy line to see which output differs.
3. Inspect internal wires and part outputs in the GUI to trace the incorrect signal.
4. Fix swapped pins, missing outputs, or wrong part names and re-run tests.
Pro tip

Label intermediate names clearly and avoid reusing identifiers, which makes tracing in the simulator much faster.
