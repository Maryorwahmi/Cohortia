Module 1 › Chapter 1.5 › Hands-on Activity
Sequence
  1. Implement Not using only Nand gates; test both inputs.
  2. Implement And using Nand and Not; test exhaustively.
  3. Implement Or via De Morgan using Nand and Not; verify.
  4. Implement Xor from And, Or, Not and test all combos.
  5. Implement Mux and DMux from And/Or/Not; write full tests.
Testing Tips
• Run each chip's test script until it passes before composing.
• Use exhaustive tests for 1-3 input chips to catch all logic faults.
• When composing into buses, test edge cases like all zeros/ones and alternating patterns.
Key Takeaway

Small verified components are the most reliable path to larger, correct chips; practice disciplined test-driven development.
