Objective to Task

Practical steps to practice HDL and simulation

Follow small, test-driven increments
Read and Identify

Open sample HDL files and mark the CHIP name, each IN/OUT pin, and the PARTS lines to understand structure.

Implement 1-bit chips

Write Not, And, Or, Xor using Nand and Not as required. Each PARTS line must name outputs used by later parts.

Write test scripts

Create scripts that set every combination of small inputs, eval, output, and compare-to an expected file for automation.

Compose and reuse

Use tested chips as black boxes inside PARTS to build wider or more complex chips without re-implementing internals.

VERIFIED COMPETENCY MILESTONE — Complete one 1-bit chip with a passing test script.
