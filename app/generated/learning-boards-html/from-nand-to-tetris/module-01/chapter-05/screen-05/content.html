Process Flow

How connections create signals

1. Write PARTS lines where each chip instance lists pinName=value pairs.
2. When a part outputs to a name, that name becomes an internal wire if not declared as an input or output.
3. Reuse that name as a value in another PARTS connection to connect the devices.
4. Verify every used name is either a top-level input/output or produced by some part.
Example trace
Not(in=sel, out=notSel);
And(a=a, b=notSel, out=aAndNotSel);
And(a=b, b=sel, out=bAndSel);
Or(a=aAndNotSel, b=bAndSel, out=out);
Cards
Internal wire
A name assigned as out in one PARTS line and used elsewhere becomes a wire, e.g. notSel.
Declared input
Top-level inputs like sel are sources provided from outside the chip.
Common mistake
Trying to pass an expression instead of naming the output of a part; HDL requires explicit instances.
Key Takeaway

Treat every PARTS out= name as a signal provider and trace it through subsequent PARTS lines to verify connectivity.
