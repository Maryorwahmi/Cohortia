HDL: the chip blueprint

Specify a chip's interface, list internal parts, and wire them explicitly. HDL mirrors real hardware connectivity so your designs are testable and modular.

Structure
CHIP ChipName {
  IN a, b, ...;
  OUT out, ...;

  PARTS:
  // internal chip instances
}
Why it matters

HDL forces explicit wires and component instances. That maps directly to physical gates and fosters reliable, testable designs that can be composed into larger systems.

Simulator link

The Hardware Simulator loads HDL, runs test scripts, evaluates outputs, and compares results to expected files for automated verification.

Common pitfall

Forgetting to name an internal wire or swapping connections will make tests fail. HDL does not allow nested expressions; every component must have named outputs.

Starter Example
CHIP Mux {
  IN a, b, sel;
  OUT out;

  PARTS:
  Not(in=sel, out=notSel);
  And(a=a, b=notSel, out=aAndNotSel);
  And(a=b, b=sel, out=bAndSel);
  Or(a=aAndNotSel, b=bAndSel, out=out);
}
