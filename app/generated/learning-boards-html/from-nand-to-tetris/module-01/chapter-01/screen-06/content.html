Module 1 › Chapter 1.1 › Not from Nand
Definition

Not(x) = Nand(x, x)

Tie the same signal to both inputs of a Nand gate to obtain logical inversion with one primitive.

Why this works
  • Nand computes NOT(A AND B). If A and B are the same, it computes NOT(A).
  • The truth table reduces to a simple inverter mapping: 0→1, 1→0.
  • This wiring pattern is the canonical inversion primitive in Nand-only designs.
Common mistake

Do not leave the second input unconnected or tied to a different signal; both inputs must receive the same defined signal for the inverter to work reliably.

HDL example
<!-- Not.hdl -->
CHIP Not {
  IN in;
  OUT out;

  PARTS:
  Nand(a=in, b=in, out=out);
}
Key Takeaway

A single Nand wired with both inputs tied is a reliable inverter both in logic and in HDL implementations.
