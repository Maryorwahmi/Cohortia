Skills to practice

How the course will evaluate your understanding and what to focus on.

Write HDL
Translate a logical construction into the course HDL and wire primitives correctly.
Simulate & verify
Run supplied tests to confirm truth tables match expected outputs for all input combinations.
Measure cost
Count Nand gates per implementation and compare designs for efficiency and delay implications.
Key Takeaway

Learning is verified by implementing HDL, running simulator tests, and reasoning about gate counts and trade-offs.
