Module 1 › Chapter 1.1 › Xor from Nand
Comparison

Two constructions, different costs

Compare the expansion through And/Or/Not versus the optimized 4-Nand pattern and measure gate counts and clarity.

Naïve expansion

Translate Xor = Or(And(a,Not(b)), And(Not(a),b)) and replace each operator by Nand constructions. Correct but uses many gates.

Optimized 4-Nand

t = Nand(a,b); u = Nand(a,t); v = Nand(b,t); Xor = Nand(u,v). This uses four Nands and is the common compact pattern.

Practical check

Verify both against the four-row truth table and compare gate counts. The optimized pattern shows why choosing the right decomposition matters for area and delay.

Concrete example
Evaluate optimized pattern for inputs (1,0)

t = Nand(1,0) = 1; u = Nand(1,1) = 0; v = Nand(0,1) = 1; final = Nand(0,1) = 1. The result is 1 as expected for Xor(1,0).

Key Takeaway

Different correct implementations differ in cost; prefer the four-Nand Xor when minimizing gate count is the goal.
