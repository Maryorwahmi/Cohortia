Not.hdl — a minimal HDL chip

This file shows the exact wiring to build an inverter from one Nand primitive. The simulator will test all inputs and compare outputs to the truth table.

<!-- Not.hdl -->
CHIP Not {
  IN in;
  OUT out;

  PARTS:
  Nand(a=in, b=in, out=out);
}
Simulator checklist
  • Save the HDL file using the correct filename expected by the tests.
  • Load the chip in the hardware simulator and run the supplied test script.
  • Compare observed outputs to expected truth table and correct wiring if mismatches appear.
Concrete guidance
Example simulation

Run the test script: it applies in=0 and in=1 and compares the out values to 1 and 0 respectively. A mismatch means check the PARTS wiring and primitive names.

Key Takeaway

Translate wiring patterns into HDL carefully; simulation validates logical correctness and reveals wiring mistakes early.
