Activity: Build Not, And, Or, Xor using only Nand

Follow this step-by-step workflow to design, implement, and verify each chip in the simulator.

Step 1 — Define

Write the truth table for the chip you plan to build and confirm expected outputs for all inputs.

Step 2 — Derive

Use Nand constructions: Not(x)=Nand(x,x), And via inversion, Or via De Morgan, and Xor via the 4-Nand pattern.

Step 3 — Implement

Translate wiring into the HDL PARTS block and save the file under the expected chip name.

Step 4 — Simulate

Load the HDL into the hardware simulator and run the supplied test script to check every input combination.

Step 5 — Debug

Use simulator mismatches to trace wiring mistakes; test intermediate chips to isolate faults.

Measure

Count Nand gates for each implementation and try alternatives to reduce count and delay.

Reflect

Ask which decomposition best balances correctness, gate count, and timing for your target chip.

Key Takeaway

A disciplined design-simulate-verify-debug loop is the practical way to turn Nand wiring into reliable chips you can reuse in larger systems.
