Module 5 › Chapter 5.3 › Push constant
Assembly pattern
The translator emits a short, fixed instruction sequence for push constant.
@value
D=A
@SP
A=M
M=D
@SP
M=M+1
This loads the literal value into D, stores it where SP points, and increments SP so the stack has the new top.
Explanation bullets
  • Load immediate value: @value then D=A places the constant in D.
  • Store at stack top: set A to RAM[SP] (A=M) and write M=D.
  • Advance SP: increment RAM[0] so the top moves up.
  • Why virtual: no RAM lookup is required for the constant segment.
Key Takeaway

Constants are embedded values; push constant requires only immediate load and stack write.
