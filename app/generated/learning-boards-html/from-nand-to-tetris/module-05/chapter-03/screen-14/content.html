Module 5 › Chapter 5.3 › Key Concepts
Segment mapping
Local/argument/this/that base-plus-index; pointer/temp fixed; static at 16; constant virtual.
Special registers
SP, LCL, ARG, THIS, THAT are key to push/pop address computations and stack updates.
Push vs Pop
Push is simpler; pop requires computing and saving the destination address first, usually in R13.
Takeaway

Address mapping and the pop save pattern are the two pieces you will use repeatedly when translating VM memory access commands.
