Module 5 › Chapter 5.3 › Translator Strategy
Step-by-step plan
  1. Implement push constant and verify in simulator.
  2. Add push for base-plus-index segments using a reusable address computation helper.
  3. Implement pop for local using R13 to save the computed destination address.
  4. Generalize pop to argument, this, and that; add pointer and temp handlers.
  5. Implement static allocation mapping starting at RAM[16] with class-scoped names.
  6. Create small VM tests and iterate until the simulator shows correct RAM values.
Debug checklist
  • Does push write to RAM[SP] and increment SP?
  • Does pop compute and save the destination before popping?
  • Are static variables uniquely named per class?
  • Do pointer updates reflect in subsequent this/that accesses?
Key Takeaway

Implement incrementally and test often; address computation and temporary saving are the two places bugs hide.
