Fixed addresses for temp
Temp saves translator-temporary values in fixed RAM slots.
temp 0 → RAM[5]
temp 1 → RAM[6]
...
temp 7 → RAM[12]
Access is implemented by using the fixed RAM address; no base register arithmetic is necessary.
Practical note
Because temp addresses are global and fixed, use them only for short-lived intermediate values produced by the translator, not for function-local persistent state.
Check

To verify, pop into temp 2 and inspect RAM[7] in the simulator to see the stored value.
