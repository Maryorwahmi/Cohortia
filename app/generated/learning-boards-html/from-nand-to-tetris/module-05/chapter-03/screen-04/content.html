Module 5 › Chapter 5.3 › Segments & Mapping
Segment definitions
Each segment has a clear role and a concrete RAM mapping that your translator must use.
local
Mapped to RAM[LCL + index]. Stores function local variables.
argument
Mapped to RAM[ARG + index]. Holds parameters passed to the current function.
this / that
Base addresses for object fields or arrays: RAM[THIS + index], RAM[THAT + index].
pointer / temp
pointer → RAM[3 + i] (this/that); temp → RAM[5 + i] fixed slots.
static and constant
static → RAM[16 + index], class-scoped; constant is virtual — values embedded in instructions.
Hardware registers
Special registers are stored at fixed RAM locations and are central to address computation.
SP = RAM[0]
LCL = RAM[1]
ARG = RAM[2]
THIS = RAM[3], THAT = RAM[4]
Analogy
Think of base-plus-index segments as drawers in a filing cabinet that move when the base register changes. Temp and pointer are fixed cubbyholes, and static are labeled shelves starting at a fixed address.
