Learning Objectives
Learn the skills needed to translate VM memory access commands.
Learn → Understand → Apply → Master
01
Implement push and pop
Translate VM push and pop for all segments so your VM translator moves values correctly between stack and memory.
VERIFIED COMPETENCY MILESTONE
02
Map segments to RAM
Use the fixed and base-plus-offset mappings like RAM[5 + i] for temp and RAM[LCL + i] for local variables.
VERIFIED COMPETENCY MILESTONE
03
Handle pointer and temp
Translate pointer to RAM[3 + i] and temp to RAM[5 + i] so base addresses for this and that are adjustable.
VERIFIED COMPETENCY MILESTONE
04
Translate static and constant
Treat constant as virtual; allocate static starting at RAM[16] with class-scoped naming to avoid collisions.
VERIFIED COMPETENCY MILESTONE
