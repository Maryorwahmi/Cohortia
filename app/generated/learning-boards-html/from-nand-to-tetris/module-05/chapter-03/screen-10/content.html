Module 5 › Chapter 5.3 › Static Segment
Statics start at RAM[16]
Each class's static variables are assigned unique addresses starting from 16 to implement class-level storage.
Naming convention
Use ClassName.index to distinguish static variables in different classes so addresses do not collide.
Persistence
Static variables live for the entire program and are shared across instances of a class.
Implementation note
The translator must coordinate static allocation across VM files to prevent different classes from using the same RAM addresses.
Key Takeaway

Treat static as globally allocated per-class slots beginning at address 16 and maintain a consistent mapping in the translator.
