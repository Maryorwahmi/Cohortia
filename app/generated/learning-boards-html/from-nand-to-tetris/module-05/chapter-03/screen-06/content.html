Module 5 › Chapter 5.3 › Push local/argument/this/that
Standard push sequence
Compute base plus index, read value, push to stack.
@LCL
D=M      // D = base address of local
@index
A=D+A    // A = LCL + index
D=M      // D = value at local[index]
@SP
A=M
M=D
@SP
M=M+1
This template works for argument (use ARG), this (THIS), and that (THAT) by substituting the base register symbol.
Explanation bullet list
  • Load the base address register into D so we can add the index.
  • Add the index to compute the target address, then read M at that address.
  • Write the read value to RAM[SP] and increment SP to grow the stack.
  • Apply identical pattern for argument, this, and that with their respective base registers.
Common mistake

Mixing up D and A during address computation can point to the wrong RAM location; preserve the base correctly before adding the index.
