Pointer mapping
Pointer indexes 0 and 1 control the THIS and THAT base addresses respectively.
push pointer 0
Read RAM[3] (THIS) and push to stack.
pop pointer 1
Pop top of stack and write it to RAM[4] (THAT), changing THAT's base address.
Why this matters
Pointer updates are how code adjusts object or array base addresses at runtime. They are essential for field access after a constructor or pointer arithmetic.
