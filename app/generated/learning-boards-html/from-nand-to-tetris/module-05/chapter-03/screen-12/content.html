Test program 1: push/pop locals and add
push constant 10
push constant 20
pop local 0
pop local 1
push local 0
push local 1
add
This sequence verifies pushing constants, popping into local slots, reading back locals, and performing arithmetic on the stack.
Test program 2: pointer manipulation
push constant 3000
pop pointer 0
push constant 4000
pop pointer 1
push this 0
push that 0
add
This checks that popping into pointer updates THIS and THAT, and that subsequent this/that accesses use the new bases.
