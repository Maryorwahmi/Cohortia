Canonical pop sequence
Compute destination, save it, pop the stack, then store the popped value.
@index
D=A
@LCL
D=M+D    // D = LCL + index
@R13
M=D      // save target address in R13
@SP
AM=M-1
D=M      // D = popped value
@R13
A=M
M=D      // store value at target
R13 is a temporary register used to preserve the computed address while we pop the value into D.
Explanation bullets
  • Compute the target address and store it in R13 to avoid losing it during the pop.
  • Decrement SP and read the top value into D.
  • Use the saved address to write D into the desired memory location.
  • Pop requires more instructions because you must preserve an address across the pop operation.
Misconception check

Trying to compute the address after popping can overwrite registers and produce incorrect writes. Save the address first.
