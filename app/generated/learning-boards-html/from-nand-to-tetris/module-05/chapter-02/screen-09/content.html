Push and pop sequences

Push: D contains value, store at RAM[SP], then SP = SP + 1. Pop: SP = SP - 1, then read RAM[SP]. When popping into a segment, compute the target address first, then overwrite it with the popped value. Keeping these orders prevents accidental overwrite and maintains the SP invariant for subsequent operations.
Concrete example
push constant 3; push constant 5; pop temp 0 → temp 0 receives 5; the stack top becomes 3.
Bug pattern
Incrementing SP before writing during push will leave a zero at the old top and write the value to the next slot, shifting stack contents unexpectedly.
Cards
Push pattern
D = value; @SP; A=M; M=D; @SP; M=M+1
Pop pattern
@SP; AM=M-1; D=M; // D now has popped value
Key takeaway
Always reason about where SP points before and after each stack operation to avoid off-by-one errors.
