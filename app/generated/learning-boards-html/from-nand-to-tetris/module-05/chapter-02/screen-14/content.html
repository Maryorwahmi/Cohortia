Stack arithmetic
Pop operands, compute, push result; SP drives all stack access.
Boolean encoding
Comparisons push -1 for true and 0 for false; this choice simplifies bitwise use of boolean values.
Translator duties
Map VM commands to assembly templates, manage SP, and generate unique labels for comparisons.
Summary takeaway

Implement deterministic assembly patterns for arithmetic and comparisons, keep SP correct in RAM[0], and ensure label uniqueness to produce correct .asm output.
