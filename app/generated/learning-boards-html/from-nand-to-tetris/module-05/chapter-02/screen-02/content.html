Learning Objectives

Learn, understand, apply, and master the VM arithmetic concepts.

Bloom: Learn → Understand → Apply → Master
01
Implement add, sub, neg
Write assembly sequences that pop operands, perform ALU work, and push the numeric result. This ensures expression evaluation succeeds on real hardware.
VERIFIED COMPETENCY MILESTONE
02
Implement eq, gt, lt
Learn to use subtraction plus conditional jumps and push -1 or 0. This teaches conditional code generation without native compare instructions.
VERIFIED COMPETENCY MILESTONE
03
Translate VM commands to Hack assembly
Generate precise instruction sequences for each VM command and maintain SP correctly so the produced .asm runs on the simulator.
VERIFIED COMPETENCY MILESTONE
04
Understand SP and push/pop semantics
Manage RAM[0] as SP, know push/pop ordering, and ensure the stack grows correctly from address 256.
VERIFIED COMPETENCY MILESTONE
