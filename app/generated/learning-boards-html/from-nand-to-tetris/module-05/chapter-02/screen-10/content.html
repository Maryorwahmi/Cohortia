Architecture

Responsibilities of the translator

  • - Emit correct assembly templates for each VM command (arithmetic, comparison, push, pop).
  • - Maintain SP in RAM[0] and ensure the produced assembly preserves stack invariants.
  • - Generate unique labels for comparisons using a global counter.
  • - Map VM segments to the proper hardware locations when translating push/pop.
Practical design tip

Implement small generator functions per VM command and a centralized label generator. This isolates responsibility, makes templates testable, and reduces bugs across generated code.

Cards
Mapping rule
Each VM command → fixed assembly sequence. Keep templates deterministic.
Label generator
Central counter: increment for each comparison and append to label names.
Key takeaway
Modular code generation produces clearer .asm and simplifies verification in the simulator.
