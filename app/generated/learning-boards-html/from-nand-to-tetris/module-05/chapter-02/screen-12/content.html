Why unique labels matter

If the translator emits identical label names for multiple comparisons, either the assembler will report duplicate definitions or control flow will jump to the wrong target. Ambiguous jumps can result in incorrect boolean values on the stack or runtime faults.

Detect duplicates by searching the generated .asm for repeated label names.
Fix by centralizing label generation and incrementing a counter each time you emit comparison code.
Test with multiple comparisons in one file to ensure label suffixes increase.
Cards
Symptom: assembler reports duplicate label definition or wrong jumps occur.
Resolution: maintain a global counter and append it to labels used by comparisons.
Key takeaway: label generation is a core translator responsibility to ensure correct control flow.
