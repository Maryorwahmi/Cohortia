Code Walkthrough

Standard add sequence

<!-- Assembly implementation for add --> @SP AM=M-1 // SP = SP - 1, A = SP (point to y) D=M // D = y @SP AM=M-1 // SP = SP - 1, A = SP (point to x) D=D+M // D = x + y M=D // Push result @SP M=M+1 // SP = SP + 1
Concrete example

If the stack contains [..., 3, 5], after add it contains [..., 8]. Try this sequence in the simulator to confirm SP ends at the expected value and no data is lost.

Common mistake

If you increment SP before storing the result you will write to the wrong cell and the next command will use an incorrect top-of-stack value. Keep the store-before-increment order.

Supporting cards
Example card
push constant 3; push constant 5; add → 8 on stack.
Why order matters
x is the value below the top; y is the top. For subtraction, x - y must respect that order.
Key takeaway
Memorize the SP decrement, compute, store, increment pattern for binary arithmetic commands.
