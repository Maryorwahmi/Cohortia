Comparison semantics

eq, gt, lt push boolean values

Compute x - y and use the ALU’s result to decide between -1 (true) and 0 (false). The translator emits jump logic that writes the chosen value and then increments SP.

Concrete example
push constant 5; push constant 3; gt → stack top is -1 (true) because 5 > 3.
Why -1?
-1 is all ones in two's complement; it composes naturally with bitwise operations and can be produced directly by the ALU.
Misconception
Do not use 1 for true. Some operations expect a mask of all ones to propagate truth in bitwise logic.
Example sequence
push constant 5
push constant 3
gt  // pushes -1
push constant 5
push constant 5
eq  // pushes -1
Key takeaway
Always ensure the translator writes -1 or 0 explicitly in your generated assembly. When testing, check the simulator’s RAM at the stack address to verify the exact bit pattern.
