Segments & Roles
Stack — working area for pushes/pops
Local — local variables for current function
Argument — parameters passed to function
This — base address for current object
That — base address for arrays/other objects
Constant — virtual source of immediate values
Static — file-level static variables
Pointer — holds addresses for this and that
Temp — temporary variables for translator use
Mapping to RAM
The translator maps segments to RAM addresses and registers. For example the stack often begins at a fixed RAM address and local/argument segments use base registers so indexed access becomes a base plus offset operation.
Gotcha
Constant is not stored in RAM; it supplies immediate values. Confusing it with a RAM segment causes incorrect translations when generating push constant code.
Key Takeaway

Understanding segments and mappings is required to translate memory-access commands correctly.
