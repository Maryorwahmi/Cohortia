Arithmetic commands
add, sub, neg, eq, gt, lt, and, or, not — each consumes or inspects top-of-stack values. Their semantics are simple and predictable, which simplifies compiler emission.
Example
push constant 3
push constant 5
add  // result 8 on stack
Pro tip

Test each arithmetic command by pushing known values and checking the resulting top-of-stack value after the operation.

Memory access commands
push segment i reads from a segment at index i and pushes the value; pop segment i writes the top-of-stack value into the segment at index i. Implementation requires computing a base address plus the index when the segment is backed by RAM.
Common mistake
Off-by-one errors when computing base plus offset are frequent. Establish clear helpers and unit tests for address computation to avoid subtle bugs.
Key Takeaway

Push/pop and arithmetic are the minimal primitives the compiler needs to emit; correctness depends on accurate address arithmetic for segments.
