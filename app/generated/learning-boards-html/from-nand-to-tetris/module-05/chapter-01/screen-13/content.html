Module 5 › Chapter 5.1 › Implementing a Translator
Step-by-step plan
  1. Write helpers to compute base + index addresses for segments.
  2. Implement push and pop primitives that update the stack pointer correctly.
  3. Implement arithmetic commands using the primitives or by operating on loaded values.
  4. Create unit tests that push and pop known values and verify memory contents.
Testing checklist
  • Push constant then pop into static/local and read back.
  • Perform sequences of arithmetic and confirm final top-of-stack value.
  • Test pointer and temp segments for correct address handling.
Key Takeaway

Start with correctness through simple helpers and tests. Only then add translator optimizations that preserve VM semantics.
