Module 5 › Chapter 5.1 › What is a Virtual Machine?
Definition
A software abstraction of a computer

The VM defines behavior for a small instruction set and memory model. The compiler targets the VM; the translator maps VM instructions to hardware. This separation reduces per-platform compiler complexity and centralizes platform-specific optimization in the translator.

Simpler compiler: fewer target choices
Centralized optimization: translator can tune for each machine
Misconception
A VM is more than an emulator. It is a defined intermediary that shapes how compilers and translators share responsibility for correctness and performance.
Analogy: Theater Stage
The VM is the stage manager
Imagine a play script written once. The VM translator is the stage manager who adapts the script to actors on different stages. The script stays the same; the manager arranges props and timing per stage. Portability is the play running on many stages without rewriting the script.
Example
// VM snippet
push constant 3
push constant 5
add
This small VM program expresses the computation independent of specific registers or RAM addresses.
Key Takeaway

A VM formalizes an execution model the compiler targets, enabling portability and separate optimization phases.
