Module 5 › Chapter 5.1 › VM vs Direct Compilation
VM pipeline
  • Compiler emits VM code — simple, uniform sequences.
  • Translator maps VM to machine — platform-specific optimizations can be applied here.
  • Multiple languages can target the same VM for interoperability.
Direct compilation
  • Compiler emits machine code tailored to registers and calling conventions.
  • Requires complex back ends and register allocation algorithms.
  • May yield higher raw performance but duplicates effort per platform.
Misconception check
Targeting a VM is not an admission of poor performance — it is an architectural choice that centralizes complexity. Translators and JITs often recover the majority of performance while keeping compilers simpler.
Key Takeaway

Choose a VM when portability and reuse of toolchains outweigh the cost of a more complex translator; choose direct compilation when per-platform performance is paramount.
