Module 5 › Chapter 5.1 › Benefits
Key Benefits
Portability: target one VM instead of many ABIs
Simplicity: smaller instruction set and memory model
Optimization: translators tune code for hardware
Security: runtime checks enforce safety
Examples & Misconceptions
  • The same VM code runs on any machine with a translator, so one compiler supports many targets.
  • Compilers avoid hardware-specific register allocation when targeting a stack VM.
  • Performance need not be sacrificed if the translator performs optimizations like register mapping.
Concrete scenario
If you add a new language front end, you can emit the VM code and reuse existing translators for each platform rather than building a new compiler for every target.
Key Takeaway

Designing a VM lets you trade per-platform compiler complexity for a single translator that can be optimized independently.
