Test workflow
  1. Run translator on a test VM to produce .asm.
  2. Diff your .asm against the reference assembly.
  3. Assemble and run on the Computer Simulator.
  4. Inspect memory/stack to validate runtime behavior.
  5. Fix CodeWriter patterns and repeat.
Provided test programs
  • SimpleAdd.vm — push constant, add.
  • StackTest.vm — arithmetic and comparisons.
  • BasicTest.vm — push/pop across segments.
  • PointerTest.vm — pointer behavior for THIS/THAT.
  • StaticTest.vm — static vars across files.
Debug tip
When an assembly diff is large, isolate a single command sequence and unit-test the CodeWriter output for that command until it matches the reference exactly.
