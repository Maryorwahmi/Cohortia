Project 6: VM Translator I
Translate VM stack arithmetic and memory access commands into Hack assembly. Prepare a Parser, CodeWriter, and Main to produce a single .asm output for testing.
Interactive 16:9 Masterclass
What you will build
Parser
Tokenizes VM source, identifies command type and arguments so the translator can generate code.
CodeWriter
Emits assembly sequences for arithmetic, logical, push, pop, and flow commands following the specification.
Main
Orchestrates file I/O, handles directories, and produces a single .asm file for the assembler and simulator.
Visual Summary
VM commands expand into multiple assembly instructions to implement stack semantics.
Testing with reference outputs ensures correctness across provided examples.
