Checklist — concrete tests
  • Parser: produces commandType, arg1, arg2 for every non-comment line.
  • CodeWriter: emits assembly for add, sub, neg, eq, gt, lt, and, or, not, push, and pop.
  • File handling: accepts file or directory and writes one .asm file.
  • Testing: compare outputs for SimpleAdd, StackTest, BasicTest, PointerTest, StaticTest.
Tip
When comparing reference assembly, ignore comments and spacing first; focus on instruction sequences and labels for control flow and comparisons.
Mnemonic
Parser → CodeWriter → Main. Think of it as a translation pipeline: parse, translate, write.
