Why the VM exists
The VM is a compact intermediate representation that hides hardware details from higher-level code generators. The translator implements those abstractions with explicit instructions.
Why expansion happens
VM operations like push/pop require multiple primitive instructions to implement stack semantics on hardware that lacks them.
Stack pointer initialization
SP is initialized to 256 so addresses below are reserved for special pointers and temp registers. This deterministic layout simplifies translation and testing.
Assessment idea from the chapter: explain why the assembly expansion is necessary and whether the VM approach is inefficient. The answer: expansion is required because higher-level VM abstractions do not have direct hardware support; efficiency can be regained through optimizations or JITs in more advanced systems, but the VM’s value is portability and simplicity for compiler front-ends.
