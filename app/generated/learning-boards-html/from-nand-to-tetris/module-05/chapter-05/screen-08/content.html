Comparison translation pattern
1. Pop y into D.
2. Decrement SP and refer to x in M, compute D = x - y.
3. Use conditional jump (JEQ/JGT/JLT) to a unique true-label.
4. Write 0 for false, jump to end-label. At true-label write -1, then continue.
Implementation tip
Maintain an internal counter like compareCount and append it to label names so that each eq/gt/lt emits distinct labels.
Quick analogy
Think of each comparison as a mini subroutine that needs its own local labels. Without unique labels, one comparison could jump into another’s code and break logic.
Common pitfall

Reusing 'TRUE' or 'END' labels globally causes incorrect branching when multiple comparisons exist.
