Component responsibilities
Parser
Tokenizes commands, removes comments, returns type, arg1, arg2.
CodeWriter
Emits assembly sequences for each parsed command, maintains label counters for comparisons.
Main
Traverses files, uses Parser and CodeWriter, writes the final .asm file.
Testing tip: feed the Parser controlled strings with comments and whitespace to ensure it returns the correct command type and arguments. Then feed those parsed objects into the CodeWriter and compare the emitted assembly with reference snippets.
Example interface
// Parser returns an object like
{ commandType: 'C_PUSH', arg1: 'constant', arg2: 7 }

// CodeWriter provides methods
writePushPop(commandType, segment, index)
writeArithmetic(command)
