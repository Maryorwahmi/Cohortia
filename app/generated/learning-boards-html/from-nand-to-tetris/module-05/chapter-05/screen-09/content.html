Segment address patterns
Constant
Immediate value loaded into D, then pushed to *SP.
Local / Argument / This / That
Compute address: base pointer + index, then read or write via that address.
Temp / Pointer
Fixed RAM addresses: temp is 5..12, pointer maps to THIS or THAT base pointers.
Static
File-scoped symbol like FileName.index to avoid collisions across files in one directory translation.
Testing strategy: instrument translations to show computed addresses for a sample index and compare against expected addresses in BasicTest. For static variables, confirm symbols are unique per file and persist across operations.
