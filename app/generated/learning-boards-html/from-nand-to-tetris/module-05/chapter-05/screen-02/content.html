Learning Objectives — details and verification
Learn, Understand, Apply, Master
01
Complete the translator program
Write a program that reads a .vm file or a directory and writes a single .asm file. This milestone proves you can handle file I/O and integration across multiple VM sources.
Verified competency milestone
02
Implement arithmetic and memory commands
Support add, sub, neg, eq, gt, lt, and, or, not and push/pop for all segments. This shows you can translate VM semantics into concrete sequences of assembly instructions.
Verified competency milestone
03
Test with provided VM programs
Use SimpleAdd, StackTest, BasicTest, PointerTest, and StaticTest. Compare your output to the reference assembly and run it in the simulator to confirm behavior.
Verified competency milestone
04
Explain the VM as a backend
Describe how VM commands map to hardware primitives, why translation expands instruction count, and how this relates to real compiler backends.
Verified competency milestone
