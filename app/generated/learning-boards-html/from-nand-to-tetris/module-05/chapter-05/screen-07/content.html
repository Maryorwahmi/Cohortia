Segment categories
constant — immediate value loaded into D, then pushed
local/argument/this/that — use base pointer (LCL/ARG/THIS/THAT) + index
pointer/temp — fixed RAM addresses (pointer maps to THIS/THAT base, temp is 5..12)
static — file-scoped symbols, one variable per index
Remember: computing addresses correctly for base-pointer segments is the most common source of bugs. Use temporary registers only when needed and ensure SP is adjusted exactly once per push or pop.
Concrete example: SimpleAdd
Input VM:
push constant 7
push constant 8
add
Reference assembly excerpt (must match your output):
// push constant 7
@7
D=A
@SP
A=M
M=D
@SP
M=M+1

// push constant 8
@8
D=A
@SP
A=M
M=D
@SP
M=M+1

// add
@SP
AM=M-1
D=M
@SP
AM=M-1
D=D+M
M=D
@SP
M=M+1
