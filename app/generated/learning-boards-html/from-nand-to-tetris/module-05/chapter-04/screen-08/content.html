Building an if-then
Translate the VM pattern and observe how jumps control flow.
VM pattern
push local 0
push local 1
gt
if-goto IF_TRUE
// else block
... 
goto IF_END
label IF_TRUE
// if block
...
label IF_END
Step 1: Evaluate condition and leave 0/1 on stack.
Step 2: if-goto consumes the result and branches if true.
Step 3: Use goto to skip the else portion after executing the then block.
Step 4: Declare matching IF_END and IF_TRUE labels with function prefixing.
Concrete check
Translate and step through both branches in the simulator. Confirm that the then-block executes only when the comparison produced a non-zero value and that the stack is balanced afterwards.
Key Takeaway

An if-then is a short composition of evaluation, a conditional pop-and-jump, and label declarations — keep the stack discipline to avoid bugs.
