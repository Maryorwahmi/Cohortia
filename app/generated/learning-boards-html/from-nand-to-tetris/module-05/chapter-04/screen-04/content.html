Core Concept
The three VM flow commands
Precise semantics and a short example to ground meaning.
Label
Declares a position in code to target with jumps; no stack effect.
Goto
Unconditional transfer: subsequent execution continues at the label.
If-Goto
Pops the top-of-stack; if non-zero, it jumps to the label; otherwise it falls through.
Concrete example
push local 0    // x
push local 1    // y
gt              // x > y?
if-goto IF_TRUE
// else block
push local 1
push local 0
sub
pop local 1
goto IF_END
label IF_TRUE
// if block
push local 0
push local 1
sub
pop local 0
label IF_END
Misconception
If-goto does not keep the condition on the stack; it consumes it. Forgetting this leads to extra values that break later stack-based ops.
Key Takeaway

These three simple commands — mark, unconditional jump, conditional pop-and-jump — compose to produce all higher-level branching and loops.
