Translating if-goto
Pop and conditionally jump when the value is non-zero.
@SP
AM=M-1
D=M      // D = top value (popped)
@FunctionName$LABEL
D;JNE    // Jump if D != 0
This sequence both updates SP and ensures the popped value is used as the branch condition. A translator emits the function-prefixed label name in the final two lines so the jump and the label declaration match globally.
Example scenario
Use if-goto after a comparison op like gt. The comparison leaves 0 or 1 on the stack; if-goto will pop that result and branch only when the comparison was true.
Pitfall

Not popping before testing duplicates the condition and changes stack positions for following instructions. Always consume the predicate with if-goto.
