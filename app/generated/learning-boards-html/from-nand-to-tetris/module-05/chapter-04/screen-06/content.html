Translating goto
Unconditional transfer is mapped to a direct assembly jump.
// VM: goto LOOP
// Assembly (inside function F):
@F$LOOP
0;JMP
Because 0;JMP does not examine registers or the stack, it is the simplest way to force the program counter to a new label. Ensure symbol prefixing is applied to all goto targets so the @ instruction refers to the same global symbol declared by label emissions.
Test scenario
Translate a VM sequence that uses goto to skip a block. Step the assembly and observe that program counter jumps to the label location and resumes subsequent instructions from there.
Common mistake

Using a conditional jump by mistake or forgetting to prefix label symbols leads to unexpected fall-through behavior or assembly errors.
