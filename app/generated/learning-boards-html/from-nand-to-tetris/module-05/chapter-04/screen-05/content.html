Translating VM label
Make label declarations the assembler understands while preserving uniqueness.
Pattern
VM: label LOOP
Assembly: (FunctionName$LOOP)
Example: label LOOP inside Main.main becomes (Main.main$LOOP) so goto Main.main$LOOP and if-goto Main.main$LOOP match the symbol.
Validation
Translate two functions that both declare label LOOP. The assembler should accept the output because names are distinct after prefixing.
Common mistakes
  • Emitting the VM label verbatim so duplicate names collide at assembly time.
  • Using inconsistent separators so goto targets don't match label declarations.
  • Forgetting to update current-function context while translating nested code fragments.
Key Takeaway

Always mangle VM labels with the current function name when emitting assembly declarations to avoid global name collisions.
