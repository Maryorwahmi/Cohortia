Module 5 › Chapter 5.4 › Key Concepts
VM Flow Commands
label, goto, if-goto — the VM's control primitives.
Assembly Translation
Labels become (Name), goto emits @Name and 0;JMP, if-goto pops then D;JNE.
Label Uniqueness
Prefix VM labels with the function name so assembly symbols don't collide.
Summary
Three simple VM commands translate to assembly patterns that let compilers express all higher-level control structures. Implement them carefully and verify behavior in the simulator.
