While loop implementation
Loop structure that repeats while the condition holds.
VM example (chapter)
label WHILE_START
push local 0    // i
push local 1    // n
lt
if-goto WHILE_END
push local 2    // sum
push local 0    // i
add
pop local 2
push local 0
push constant 1
add
pop local 0
goto WHILE_START
label WHILE_END
Translate step-by-step: declare (F$WHILE_START), translate the comparison and if-goto to pop-and-test with @F$WHILE_END and D;JNE (or D;JE Q depending on which sense is used), emit the body, then emit @F$WHILE_START and 0;JMP to loop. Run the generated assembly with small inputs to confirm iteration counts match expectations.
Testing tip
Use simple initial values so you can easily count loop iterations in the simulator. If the loop doesn't terminate, inspect whether the loop variable is updated or whether the comparison was emitted with the wrong sense.
Key Takeaway

A while loop is a small composition of label, conditional test that may jump to the end, body, and an unconditional jump back to the start; translate and test each part carefully.
