If-then-else pattern
Translate the structure so only one branch runs.
VM pattern (chapter example)
push local 0
push local 1
gt
if-goto IF_TRUE
// else block
push local 1
push local 0
sub
pop local 1
goto IF_END
label IF_TRUE
// if block
push local 0
push local 1
sub
pop local 0
label IF_END
When you translate, ensure the conditional jump consumes the comparison result and that the unconditional goto jumps past the else-block so the then-block does not fall through into else. Run both true and false cases in the simulator to validate behavior and stack cleanliness.
Pitfalls & checks
  • Swapping ELSE and END names by accident.
  • Omitting the goto that skips the else-block.
  • Not prefixing labels consistently across the translator output.
Key Takeaway

If-then-else requires clear control transfers: conditional branch into one label, an unconditional skip over the alternate, and consistent label declarations.
