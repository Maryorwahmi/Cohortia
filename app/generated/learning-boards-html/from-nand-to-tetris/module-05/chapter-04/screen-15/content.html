Module 5 › Chapter 5.4 › Quick Reference
Label emission
Emit (Function$Label) so assembly symbols are unique.
Goto
Emit @Function$Label then 0;JMP for unconditional jumps.
If-goto
Pop top-of-stack into D and emit D;JNE with the prefixed label.
Final tip
Run translated assembly in the simulator and trace both true and false paths to ensure labels and jumps behave as intended.
