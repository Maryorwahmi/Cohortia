For loops and counters
Init, condition, body, update — built from VM primitives.
VM pattern
push constant N
pop local 0     // initialize counter
label LOOP
push local 0
push constant LIMIT
lt
if-goto LOOP_END
// body
... 
// update counter
push local 0
push constant 1
add
pop local 0
goto LOOP
label LOOP_END
When translating, pay attention to which comparison operator the high-level language expects. Off-by-one errors often come from using lt versus le. Test with small bounds and check that the number of iterations matches the intended semantics.
Practical tip
Start with limits like 0,1,2 to validate corner cases. Use the simulator to check whether the loop runs the expected number of times and whether counter updates are applied correctly.
Key Takeaway

For loops are implemented by the same three VM primitives. Accurate tests and careful comparison choices avoid off-by-one bugs.
