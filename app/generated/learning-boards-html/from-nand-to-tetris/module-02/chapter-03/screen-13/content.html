Module 2 › Chapter 2.3 › Pitfalls & Practices
Top mistakes
  • Attempting clock gating instead of using a Mux for load control.
  • Forgetting DMux routing and writing multiple registers unintentionally.
  • Using inconsistent clock sources across parallel bits.
Best practices
  1. Use Mux+feedback for loadable registers; avoid clock gating.
  2. Build and test small components before composing them hierarchically.
  3. Run write/read sequences across addresses to verify isolation.
Checklists
When corruption appears: check DMux wiring, shared clock source, and Mux selection logic.
