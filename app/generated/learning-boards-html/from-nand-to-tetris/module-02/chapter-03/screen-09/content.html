RAM behavior

Address selects a register. Load=1 writes the provided data into that register on the next clock edge. Load=0 reads the stored value at the addressed register onto the data output.

Library analogy
Think of addresses as labels for photo albums; the librarian (DMux) routes a new photo to the specified album and the retrieval system (Mux) fetches the right album to display.
Scaling pattern
  • RAM8: 8 Registers + DMux8Way + Mux8Way16.
  • RAM64: 8 × RAM8; RAM512: 8 × RAM64; RAM4K: 8 × RAM512; RAM16K: 4 × RAM4K.
  • Use hierarchical addressing: split address bits into groups selecting subbanks at each level.
Key Takeaway

Use recursive bank composition to build large memories with manageable 8‑way multiplexers and demultiplexers at each level.
