Module 2 › Chapter 2.3 › Key Concepts
Clock & Time
Discrete cycles synchronize updates and avoid ambiguous propagation timing.
DFF
Edge‑triggered storage: out(t) = in(t−1); used as the only memory primitive in HDL.
Registers & RAM
Registers are parallel Bits; RAM is addressable registers built hierarchically using DMuxes and Muxes.
Final takeaway
Sequential logic converts a static combinational design into a machine that can remember and step through computation. Master the DFF, Mux/DMux patterns, and hierarchical thinking to scale from a single bit to full memory systems.
