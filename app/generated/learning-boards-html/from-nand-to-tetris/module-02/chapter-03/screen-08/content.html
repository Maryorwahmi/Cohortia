Module 2 › Chapter 2.3 › Register
Composition pattern

Create N parallel Bit chips, wire each Bit's input to the corresponding bit of the N‑bit input vector, and share a single load signal so the whole word loads together on the clock edge.

Concrete HDL sketch
Register uses 16 Bit parts: Bit(in=in[0], load=load, out=out[0]) ... Bit(in=in[15], load=load, out=out[15]).
Misconception
Do not assume asynchronous wiring will preserve atomic updates; if bits use the same clock they behave as a single word at the logical level.
Example (structure)
<!-- Register HDL sketch -->
CHIP Register {
    IN in[16], load;
    OUT out[16];

    PARTS:
    Bit(in=in[0], load=load, out=out[0]);
    Bit(in=in[1], load=load, out=out[1]);
    ...
    Bit(in=in[15], load=load, out=out[15]);
}
Key Takeaway

Build wide registers by parallelizing Bit primitives and sharing control signals so word updates are consistent and atomic.
