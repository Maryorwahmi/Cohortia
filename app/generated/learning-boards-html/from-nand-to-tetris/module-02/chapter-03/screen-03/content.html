Module 2 › Chapter 2.3 › Learning Objectives
Practical tasks
  1. Implement Bit and test load vs retain behavior in the Hardware Simulator.
  2. Compose Register from 16 Bits and verify parallel writes.
  3. Build RAM8 and scale to RAM16K; test address isolation.
  4. Create PC and validate inc, load, reset scenarios.
Assessment pointers
  • Show simulator waveforms that update only on clock edges.
  • Demonstrate that writing to one RAM address does not clobber others.
  • Explain why a Mux+feedback is necessary instead of clock gating.
