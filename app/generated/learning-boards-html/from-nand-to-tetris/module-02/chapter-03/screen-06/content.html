Module 2 › Chapter 2.3 › Data Flip‑Flop
Behavior

A DFF samples its input on the clock edge and holds that value to its output until the next sampling event. It provides edge‑synchronized memory with no internal enable control.

Photographer metaphor
On each tick the photographer captures the current scene. The captured photo is displayed until the next tick replaces it.
Misconception
DFFs do not decide when to load new data; they always sample. Load behavior is implemented by routing the desired signal to the DFF input with a Mux before sampling.
Simulator check
  • Observe that outputs change only at edges when driving inputs through combinational logic.
  • Chain DFFs to form pipelines and watch values shift one stage per cycle.
  • Use DFFs as the only persistent elements when constructing registers and RAM.
Key Takeaway

Treat the DFF as an atomic, edge‑triggered snapshot device; build load behavior outside it using Muxes and feedback.
