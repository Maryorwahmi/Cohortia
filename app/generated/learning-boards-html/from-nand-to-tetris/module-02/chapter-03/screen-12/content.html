Control signals
  • inc: advance PC by one using an incrementer.
  • load: present an external value to be loaded into PC.
  • reset: force PC to zero.
Design note
Priority between signals matters: typically reset overrides load, and load overrides increment. Define clear precedence to avoid ambiguous updates.
Practical test

Simulate sequences: normal increment cycles, then assert load for a jump, then reset. Verify the PC increments only when inc is active and loads/resets take effect on the next clock edge.

Key Takeaway

Combine combinational selection (incrementer and Muxes) with a clocked register to implement a flexible PC with well‑defined control precedence.
