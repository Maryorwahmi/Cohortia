Module 2 › Chapter 2.3 › Bit (1‑bit register)
How it works
  1. The Mux selects feedback or external input based on load.
  2. The selected value is fed to the DFF input.
  3. On the clock edge the DFF updates, making the new stored value available on out.
Simulator activity
Toggle load and observe that when load=0 the out remains stable across edges, and when load=1 the new input appears after the next edge.
HDL Example
<!-- Bit HDL example -->
CHIP Bit {
    IN in, load;
    OUT out;

    PARTS:
    Mux(a=feedback, b=in, sel=load, out=muxOut);
    DFF(in=muxOut, out=out, out=feedback);
}
Key Takeaway

Feedback plus selection is the canonical technique to make a DFF loadable; never assume the DFF provides an internal enable.
