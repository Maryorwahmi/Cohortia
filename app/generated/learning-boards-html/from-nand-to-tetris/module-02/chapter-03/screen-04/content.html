Module 2 › Chapter 2.3 › Combinational vs Sequential
Definition

Combinational logic: outputs depend only on current inputs. Sequential logic: outputs depend on current inputs and stored state that reflects past inputs.

Concrete example
An accumulator uses sequential logic: each cycle it adds a new input to the previously stored sum. A plain adder without state cannot accumulate over time.
Common misconception
Holding a value briefly in a gate is not reliable state; only clocked elements like DFFs provide predictable, edge‑synchronized storage at this level.
Why it matters
  • State enables programs to keep variables, program counters, and memory.
  • Synchronous clocks prevent ambiguous timing and race conditions across the system.
  • Design choices here affect testability in the Hardware Simulator.
Key Takeaway

Decide early whether a circuit needs state; if it does, design DFF placement and clocking first before adding combinational logic.
