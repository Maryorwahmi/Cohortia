Module 2 › Chapter 2.3 › Recursive RAM
Hierarchy steps
  1. RAM8: base unit with 8 registers.
  2. RAM64: 8 × RAM8 grouped by a higher DMux/Mux.
  3. RAM512 → RAM4K → RAM16K: repeat the 8× pattern until desired size.
Why this helps
It avoids monumental Muxes and DMuxes by breaking selection into manageable 8‑way steps and aligns directly with binary address decomposition.
Practical notes
  • Split the address bits across levels so each stage selects among 8 subbanks.
  • Reuse the same DMux and Mux components to keep the design modular.
  • Test each level before composing to a larger RAM to catch routing errors early.
Key Takeaway

Recursive construction reduces complexity: build reliable small banks, then combine them predictably to form large memory chips.
