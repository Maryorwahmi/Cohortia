Module 2 › Chapter 2.3 › RAM8 internals
Write path

DMux8Way takes load and address, producing one active load line so only the targeted register writes on the next clock. This prevents unintended updates elsewhere.

Test to run
Write value A to address 3, write value B to address 5, then read address 3 and 5 separately to confirm each returns its last written value.
Read path

Mux8Way16 selects which register's 16‑bit output is forwarded to RAM's output based on the address lines. Reads are combinational: they reflect stored data until the next sampled write occurs.

Common error
Failing to isolate load with a DMux can cause multiple registers to be written in one cycle, corrupting memory contents.
