Core Concept Hack ALU Overview
ALU signature
Inputs: x[15..0], y[15..0], zx, nx, zy, ny, f, no. Outputs: out[15..0], zr, ng.
Operation stages
  1. Preprocessing: apply zx/nx to x, zy/ny to y.
  2. Function stage: if f=1 compute add, else compute bitwise AND.
  3. Postprocessing: apply no to negate the result if requested.
Concrete example
To compute x + y, leave zx/zy and nx/ny cleared, set f=1, and no=0. The function stage performs the addition, and flags reflect the result.
Design advice
Implement and test each stage separately: preprocessing units, add/and blocks, and the final negation, then compute flags from the final output.
Key Takeaway

The ALU uses simple control bits to combine small operations into many useful functions; staging simplifies implementation and testing.
