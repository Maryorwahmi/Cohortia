Process Flow Examples: x+y and x-y
x + y control bits
Set zx=0 nx=0 zy=0 ny=0 f=1 no=0 so x and y pass unchanged and are added.
x - y concept
Subtraction uses x + (-y). The ALU implements negation and addition combination internally; you must ensure the two's complement behavior (~y + 1) is realized by the control sequence described in the specification.
Test case
// Example check
x = 0000 0000 0000 0010 (2)
y = 0000 0000 0000 0001 (1)
Expect x - y = 1, sign bit 0, zr = 0
Misconception
Negating y alone gives bitwise NOT, not arithmetic negative. Two's complement requires adding one after inversion to get -y.
Key Takeaway

Follow the ALU specification to realize subtraction; test with signed values and inspect flags to confirm correct two's complement behavior.
