Definition ALU Control Bits
Control bits behavior
  • zx: if 1, set x = 0
  • nx: if 1, set x = NOT(x)
  • zy: if 1, set y = 0
  • ny: if 1, set y = NOT(y)
  • f: if 1 compute x+y, else compute x&y
  • no: if 1, set out = NOT(out)
Sequencing matters
Apply zx/zy, then nx/ny, then function f, then no. Incorrect order yields wrong results for many combinations.
Concrete examples
x+y: zx=0 nx=0 zy=0 ny=0 f=1 no=0. To compute constants, zero and manipulate inputs before function selection.
Common error
Treating control bits as a function code. Instead, they should be seen as independent switches that change intermediate signals.
Key Takeaway

Control bits are stage switches. Combine preprocessing, function selection, and postprocessing to produce many useful ALU functions.
