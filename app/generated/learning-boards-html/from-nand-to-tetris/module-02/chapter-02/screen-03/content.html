Module 2 › Chapter 2.2 › Verification Plan
Test patterns
  • Exhaustive 1-bit truth tables for HalfAdder and FullAdder.
  • Edge vectors for Add16: all zeros, all ones, alternating bits, and carry ripple through MSB.
  • ALU control combinations for add, and, negation, and constants.
Failure debugging checklist
Check preprocessing: are zx/zy zeroing inputs? Check negation bits. Confirm the function stage selects add vs. and. Verify post-processing. Inspect carry propagation for Add16 errors.
