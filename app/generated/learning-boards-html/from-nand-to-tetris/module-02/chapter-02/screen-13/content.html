Core Concept ALU Flags
Zero detection (zr)
Compute OR across all sixteen output bits. If the OR is 0, invert it to produce zr=1. Common implementation uses Or8Way on both halves, then OR and NOT to finalize zr.
Negative detection (ng)
In two's complement, negative numbers have MSB = 1. Set ng equal to out[15] to signal negativity.
Concrete example
If out = 0000 0000 0000 0000 then OR = 0 → NOT → zr = 1. If out[15] = 1, ng = 1 indicating a negative result.
Common pitfall
Computing flags before final negation or postprocessing leads to wrong branch behavior. Always compute flags from the final out value.
Key Takeaway

Reliable zero and negative flags are essential for correct control flow. Derive them from the final output after all ALU stages.
