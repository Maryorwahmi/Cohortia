Comparison Delay: Ripple vs Faster Adders
Ripple-carry characteristics
  • Simple to implement by chaining full adders.
  • Delay grows linearly with bit width (O(n)).
  • Easy to verify and suitable for educational CPUs.
Faster alternatives (summary)
  • Carry-lookahead: compute carry signals in parallel using generate/propagate.
  • Carry-select: precompute sums for both carry-in values and select result.
  • Prefix adders: parallel prefix networks compute carries quickly.
Concrete performance point
If each full adder has delay D, Add16 can take up to 16·D in ripple form. Faster adders aim to reduce that to O(log n) depths at the cost of more gates.
Design trade-off
Accept ripple-carry for clarity and area, or invest in complex logic for speed. The Hack CPU chooses simplicity for learning.
Key Takeaway

Understand the carry-delay trade-off: simplicity versus speed guides adder selection in CPU design.
