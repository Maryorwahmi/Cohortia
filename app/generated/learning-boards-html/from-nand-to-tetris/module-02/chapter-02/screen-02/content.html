Module 2 › Chapter 2.2 › Learning Objectives
01
Design a Half Adder
Implement sum = a XOR b and carry = a AND b. This skill grounds single-bit arithmetic and Boolean reasoning.
VERIFIED COMPETENCY MILESTONE
02
Build a Full Adder
Compose two half adders and an OR to accept a carry-in. This teaches composition and signal routing for addition with carry propagation.
VERIFIED COMPETENCY MILESTONE
03
Assemble a 16-bit Add16
Chain 16 full adders in a ripple. Validate carry ripple behavior and observe the performance implications for multi-bit addition.
VERIFIED COMPETENCY MILESTONE
04
Implement the Hack ALU
Understand zx, nx, zy, ny, f, no, compute out, and test zr and ng. This connects arithmetic logic to control flow in the CPU.
VERIFIED COMPETENCY MILESTONE
