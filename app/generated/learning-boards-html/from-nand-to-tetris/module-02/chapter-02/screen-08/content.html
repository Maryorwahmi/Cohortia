Architecture Add16 — Ripple-Carry
Chain layout
Add16(a[0..15], b[0..15]) produces out[0..15]. FullAdder at bit 0 takes carry-in 0. Each FullAdder(i) produces out[i] and carry[i], which feeds FullAdder(i+1).
FullAdder(a[0], b[0], 0) → out[0], carry[0]
FullAdder(a[1], b[1], carry[0]) → out[1], carry[1]
...
FullAdder(a[15], b[15], carry[14]) → out[15], carry[15]
Concrete scenario
If lower bits produce carries, the carry must propagate through each subsequent full adder, possibly changing many outputs before the MSB settles.
Verification note
Test patterns that force long carry chains to expose ripple behavior and timing issues in simulation.
Key Takeaway

Add16 is straightforward to implement and reason about, but carries cause sequential delay that impacts performance.
