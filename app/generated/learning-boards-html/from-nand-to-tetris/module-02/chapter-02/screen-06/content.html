Core Concept Full Adder
Full Adder formulas
Sum   = a XOR b XOR c
Carry = (a AND b) OR (c AND (a XOR b))
Truth table highlights
Eight input combinations determine sum and carry-out. For example, a=1, b=1, c=1 produces sum 1 and carry-out 1.
Concrete example
Add a=1, b=0, carry-in c=1. XORing gives sum = 0, and carry-out = 1 if either a&b or c&(a XOR b) is true. Here, c&(a XOR b) = 1, so carry-out = 1.
Misconception
Thinking carry-out is simply whether two or more inputs are 1 is numerically correct, but the standard implementation uses XOR and AND to reuse intermediate signals efficiently in hardware.
Key Takeaway

Full adders accept carry-in and produce carry-out, enabling multi-bit addition when chained.
