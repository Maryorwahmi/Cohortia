Module 2 › Chapter 2.1 › Binary place values
Place-value table
Bits : 1 0 1 1 0 1 Places: 2^5 2^4 2^3 2^2 2^1 2^0 Values: 32 + 0 + 8 + 4 + 0 + 1 = 45
Technique: mark the positions that are 1, write corresponding powers of two, compute each power, then sum. This mental algorithm scales to any bit width.
Key Takeaway

Read bits as weighted positions. The highest set bit gives the magnitude class of the number.

Worked example
Binary: 101101 (6 bits) Compute: 2^5 + 2^3 + 2^2 + 2^0 = 32 + 8 + 4 + 1 = 45
Common mistake: forgetting to index places starting at zero. Always label the least significant bit as 2^0.
