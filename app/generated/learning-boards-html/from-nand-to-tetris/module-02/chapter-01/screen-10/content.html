Module 2 › Chapter 2.1 › Binary addition
Single-bit rules
0 + 0 = 0, c=0
0 + 1 = 1, c=0
1 + 1 = 0, c=1
1 + 1 + 1 = 1, c=1
A full adder composes these rules for a, b, and carry-in to produce sum and carry-out; chaining them creates multi-bit adders.
Worked addition
00001101 (13) + 00000111 (7) = 00010100 (20)
Overflow note
When adding signed numbers, check the sign bits and carries into the sign bit to detect overflow. For example, 01111111 + 00000001 gives 10000000 which indicates signed overflow.
