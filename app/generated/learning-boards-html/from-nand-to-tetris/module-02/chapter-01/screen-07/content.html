Module 2 › Chapter 2.1 › Unsigned range
Range formula
An n-bit unsigned integer encodes values from 0 to 2^n - 1 because there are 2^n distinct bit patterns.
16-bit max unsigned = 2^16 - 1 = 65,535
Practical check: a 32-bit unsigned counter wraps at 4,294,967,295. Choose types so counters don't overflow in normal use.
Example mapping
Bit pattern 1111111111111111 interpreted unsigned = 65,535. The same pattern interpreted as 16-bit two's complement equals -1. Interpretation matters.
Why it matters
When reading memory, always note whether a value is signed or unsigned to avoid logic errors in comparisons and arithmetic.
