Python-style verifier (visual only)
def to_16bit(n):
  masked = n & 0xFFFF
  b = format(masked, '016b')
  h = format(masked, '04X')
  # signed interpretation
  if b[0] == '1':
    signed = masked - (1 << 16)
  else:
    signed = masked
  print(n, '→', b, h, 'signed:', signed)

# Example checks
to_16bit(45)
to_16bit(-5)
to_16bit(32767)
to_16bit(-32768)
Masking ensures we view values as fixed 16-bit words. The signed interpretation subtracts 2^16 when the sign bit is set to obtain the negative value.
