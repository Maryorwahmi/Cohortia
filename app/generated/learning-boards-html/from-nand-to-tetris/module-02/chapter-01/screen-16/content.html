Module 2 › Chapter 2.1 › Quick Reference
Bits
Each bit has weight 2^k. Sum weights for set bits to decode numbers.
Hex
Group bits by four: each group maps to one hex digit for compact display.
Two's complement
Negate with invert + 1; use same adder for subtraction; expect asymmetric ranges.
Final thought
Before you act on a bit pattern, decide if it is signed or unsigned. That decision changes its numeric meaning dramatically.
