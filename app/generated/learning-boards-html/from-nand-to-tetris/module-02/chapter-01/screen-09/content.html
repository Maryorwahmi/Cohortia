Module 2 › Chapter 2.1 › Negation walkthrough
Step 1 — Start
+5 = 00000101
Step 2 — Invert
~(+5) = 11111010
Step 3 — Add one
11111010 + 1 = 11111011 (-5)
Hardware note
An adder can perform subtraction by inverting the second operand and setting carry-in to one, computing a + (~b + 1) which equals a - b. This reuses hardware efficiently.
