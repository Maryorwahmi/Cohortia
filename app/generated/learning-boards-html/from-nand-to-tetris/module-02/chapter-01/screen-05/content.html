Module 2 › Chapter 2.1 › Decimal → Binary
Step-by-step
Steps:
  1. List powers of two until the largest ≤ number.
  2. For each power, write 1 if it fits, subtract it; otherwise write 0.
  3. Continue to 2^0; the bit string is the binary result.
Example: 45
Powers: 32 16 8 4 2 1 Bits: 1 0 1 1 0 1 Result: 101101
Alternate: repeated division
Divide by two, record remainders, then read them bottom to top. This gives the same bits but weights tie directly to place value.
Pro tip
For powers of two, conversion is immediate: 1024 is 1 followed by ten zeros; 255 is eight ones because 2^8 - 1 = 255.
Try converting 1024 and 255 to reinforce pattern recognition.
