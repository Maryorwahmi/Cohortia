Module 2 › Chapter 2.1 › Subtraction
Mechanics
a - b = a + (-b) = a + (~b + 1) Invert b, add one, then add to a.
Hardware reuse: a control line inverts b and sets carry-in to one, letting a single adder compute subtraction without a separate subtractor circuit.
Worked example
15 = 00001111 7 = 00000111 ~7 = 11111000 ~7 + 1 = 11111001 Sum: 00001111 + 11111001 = 00001000 (8)
Check
Try -5 - 3 in 8-bit by computing -5 as 11111011, then adding 00000011 and interpreting the result.
