Module 2 › Chapter 2.4 › x - y via addition

Two's complement trick

Use bitwise complement and addition to compute subtraction with the same adder hardware.

Mathematical identity
x - y = x + (~y + 1). Flip all bits of y and add one to get -y in two's complement.
ALU control example
One documented control combination for x - y is: zx=0 nx=0 zy=0 ny=1 f=1 no=0. This flips y and uses addition.
Test vector
// Example test for x - y
x = 0b0000000000000100 // 4
y = 0b0000000000000011 // 3
controls: zx=0 nx=0 zy=0 ny=1 f=1 no=0
// expected out = 0b0000000000000001 (1), zr=false, ng=false
Misconception

You do not need a dedicated subtractor. The ALU implements subtraction by transforming inputs and reusing the adder.

Key Takeaway

Verify subtraction with positive, negative and boundary cases to confirm both output and flag correctness.
