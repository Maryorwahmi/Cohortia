Pre-processing

Zero and negate inputs

Apply zx/zy and nx/ny to produce modified operands used by the function stage.

Zeroing (zx / zy)
Replaces an entire operand with zero, enabling constants and simpler downstream logic.
Negation (nx / ny)
Bitwise complement flips bits; used to form two's complement operations when combined with addition.
Worked example
Suppose x = 5 and y = 2. To compute x - y via two's complement, set ny=1 to produce ~y, then use addition in the function stage. The pre-processing turns y into ~2 so the function stage can add x and ~y. Correct post-processing then yields the expected negative or positive result depending on the carry conventions of the ALU.
Misconception

Pre-processing is not optional cosmetic wiring; incorrect input transforms are the most common source of functional errors in the ALU.

Check your implementation
  • Unit-test zeroing and negation individually.
  • Verify combinations that produce constants like 0, 1, -1.
Key Takeaway

Correct preprocessing enables many ALU functions with a single function unit; test it thoroughly before moving on.
