Milestones and Tests

Concrete checkpoints to confirm each chip behaves correctly.

Checkpoint plan
Combinational
HalfAdder → FullAdder → Add16 → Inc16 → ALU. Verify carry propagation and all ALU functions.
Sequential
Bit → Register → RAM8 → RAM64 → RAM512 → RAM4K → RAM16K. Verify read/write isolation and defaults.
PC
Check increment, load, and reset behaviors under the simulator test scripts.
Key Takeaway

Turn large projects into small passing tests. Each passing primitive reduces debugging scope.
