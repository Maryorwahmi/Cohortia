Arithmetic chips
HalfAdder
Sum two bits and produce carry. Fundamental building block.
FullAdder
Adds three bits: two inputs and a carry-in; chainable to create Add16.
Add16 / Inc16
16-bit ripple-carry adder and incrementer built from FullAdders.
ALU
Most complex combinational chip. Implements 18 functions from 6 control bits and returns zero/negative flags.
Sequential chips
Bit / Register
A Bit stores one value across clock ticks; 16 Bits form a Register with load control.
RAM hierarchy
RAM8 built from Registers, repeated to form larger RAMs up to RAM16K in a tree-like composition.
PC
Program counter with increment, load, and reset behaviors to control instruction flow.
Concrete example

Write the value 3 to address 3 in RAM8 and then read it back. Confirm other addresses remain zero. This verifies address decoding and write isolation.

Key Takeaway

Build primitives first; their correctness ensures larger modules work predictably.
