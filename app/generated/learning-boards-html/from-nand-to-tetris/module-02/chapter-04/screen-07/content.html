Function stage

Add vs AND, then final negation

Function select (f)

f=0 selects bitwise AND; f=1 selects addition. The inputs are already transformed by the pre-processing stage, so these operations cover many logical and arithmetic behaviors.

Post-processing (no) & flags

If no=1 the output is negated. Compute zr if final out==0 and ng if most significant bit is 1. Flags must reflect the post-processed value used by the CPU for control decisions.

Example test
// Test for logical AND
x = 0b1010101010101010
y = 0b1100110011001100
// controls: zx=0 nx=0 zy=0 ny=0 f=0 no=0
// expected out = bitwise AND of x and y
// flags: zr=false if result nonzero, ng depends on MSB
Pitfall

Calculating flags before applying no yields incorrect flag values. Always compute flags from the final output.

Key Takeaway

Ensure the function unit and post-processing feed the flag logic; test both output values and flags together.
