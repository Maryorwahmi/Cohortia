ALU

Six control bits define 18 functions

Understand how zx, nx, zy, ny, f and no are combined to produce output and flags.

Status: produce zr and ng
Pre-/Post-processing
  • zx, zy: replace operand with zero when set.
  • nx, ny: bitwise negate the operand when set.
  • no: negate the final output when set.
Function select
f chooses between bitwise AND (f=0) and arithmetic addition (f=1). Combined with preprocessing, this yields the full set of specified functions.
Specification example
// One test vector example
x = 0b0000000000000010
y = 0b0000000000000001
// control bits to compute x + y
zx=0 nx=0 zy=0 ny=0 f=1 no=0
// expected out = 0b0000000000000011
Common misconception

The ALU is not a collection of many independent circuits; it reuses preprocessing and a small function unit to cover many behaviors.

Key Takeaway

Implement and verify each table row in the simulator. Each passing row confirms correct preprocessing and function selection.
