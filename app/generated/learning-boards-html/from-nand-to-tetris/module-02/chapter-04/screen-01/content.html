Project 2 — The ALU and Memory

Build arithmetic units and a recursive memory tree that together form the Hack computer's working core.

Interactive 16:9 Masterclass
In this lesson

You will design the ALU and all memory chips, test every ALU function, and verify RAM read/write isolation. Expect combinational and sequential challenges and a final reflection comparing them.

Why it matters

These components turn logic into computation and storage. They are the pieces that let programs compute, remember state, and control flow.

Concept map
ALU
Six control bits choose among arithmetic and logic functions and produce zero/negative flags.
Memory
Built recursively from a single bit up to RAM16K; supports controlled reads and writes.
PC
A sequential counter with load and reset that sequences program execution.
Complete the HDL, run the hardware simulator tests, keep a debugging log, and prepare a reflection on combinational vs sequential design.
