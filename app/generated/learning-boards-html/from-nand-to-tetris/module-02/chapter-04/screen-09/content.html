Module 2 › Chapter 2.4 › Memory Hierarchy

Bit → Register → RAM8 → ... → RAM16K

Grow memory by composing tested modules and partitioning address bits between block select and internal addressing.

Bit
1-bit storage with load control. Unit-test the hold and load behaviors.
Register
16 Bits wired together with a common load signal to form a word register.
RAM8
Eight Registers plus decoder logic to route load signals to a single selected register.
Address partitioning
Low bits index within a block; high bits select which block is active. For RAM64, low 3 bits pick a register and the next 3 bits pick the RAM8 block.
Concrete test

Write to an address in block 2 of RAM64 and confirm other blocks still read zero. This proves isolation and correct decoding.

Key Takeaway

Recursive composition keeps complexity manageable and testing localized to one level at a time.
