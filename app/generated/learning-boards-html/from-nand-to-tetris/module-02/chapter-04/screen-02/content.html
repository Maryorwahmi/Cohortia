Learning Objectives

Learn, understand, apply, and master Project 2 concepts and tests.

Learn → Understand → Apply → Master
01
Implement ALU functions

Write HDL for the ALU, implement the pre-/post-processing stages, and ensure its six control bits produce the expected operations. VERIFIED COMPETENCY MILESTONE

02
Build memory hierarchy

Compose Bit → Register → RAM8 → ... → RAM16K, demonstrating recursive construction and testability. VERIFIED COMPETENCY MILESTONE

03
Test and verify behavior

Run the Hardware Simulator tests for ALU functions and RAM read/write isolation; log failures and fixes. VERIFIED COMPETENCY MILESTONE

04
Reason about sequential design

Explain how feedback in registers and RAM changes design and verification compared to combinational chips. VERIFIED COMPETENCY MILESTONE

Keep a one-page reflection comparing the complexity of combinational vs sequential chips and note debugging strategies that worked.
