PC: increment, load, reset

Design a register that selects among increment, load input, and reset value under clear priorities.

Increment behavior
When neither load nor reset is asserted, the PC increments by one each tick.
Load and reset
Load forces the PC to accept an external value; reset forces zero. Tests must verify these override increment when asserted.
Test cases
  • Sequence of increments from 0 to N.
  • Load a new value and then increment to confirm the new base.
  • Assert reset mid-sequence and confirm it returns to zero immediately.
Pitfall

Ambiguous signal priority can cause nondeterministic PC behavior. Explicitly define and test priorities in HDL.

Key Takeaway

Treat the PC as a small state machine; its correctness is required for reliable program flow and meaningful simulator runs.
