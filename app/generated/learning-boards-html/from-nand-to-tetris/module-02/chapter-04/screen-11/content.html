Testing strategy

Systematically exercise functions, flags, and address isolation with clear sentinel values and a debugging log.

ALU tests
Cover all 18 control combinations and check both output and zr/ng flags, including zero and negative edge cases.
RAM tests
Check uninitialized reads, write-then-read, and cross-address isolation with sentinel values across sub-blocks.
PC tests
Verify increment sequences, load-to-value behavior, and reset during sequences for deterministic control flow.
Debugging log sample
// Example log entry
Test: RAM64 write isolation
Failure: address 8 changed when writing to address 9
Hypothesis: decoder incorrectly gating load across blocks
Fix: adjust address bit split and gate load with high select
Result: pass
Common error

Not isolating load signals during composition causes writes to propagate to multiple registers. Ensure decoders gate the load to a single unit.

Key Takeaway

A short, well-structured test suite and a clear log reduce debugging time dramatically when composing larger chips.
