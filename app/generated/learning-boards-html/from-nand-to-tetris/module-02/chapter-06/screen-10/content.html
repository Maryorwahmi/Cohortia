RAM16K (data) vs ROM32K (instructions)

Understand the separate roles each memory plays and how the CPU addresses them.

Data memory — RAM16K
Mutable storage built from RAM chips you implement. Tests expect uninitialized values to read as zero and writes to affect only the targeted address.
Instruction memory — ROM32K
Read-only program storage provided by the simulator; the PC addresses this space to fetch instructions.
Integration note
Ensure bus control routes writes only to RAM16K. Instruction fetches read from ROM32K via the PC; writes to ROM are not part of the Hack CPU operation.
Example check
Run a simple program that writes to RAM, then read the same address: RAM should reflect the written value while ROM remains unchanged.
