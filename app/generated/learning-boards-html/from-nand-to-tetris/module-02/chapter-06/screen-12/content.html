Build, draw, reflect

Follow the bottom-up sequence: Bit → Register → RAM8 → RAM64 → ... → RAM16K, then implement the PC and run tests.

Step checklist
  1. Implement and test Bit and Register.
  2. Build RAM8 and pass RAM8 tests.
  3. Compose RAM64, test, and repeat up to RAM16K.
  4. Assemble PC and verify priority behavior.
Reflection prompt
Why is recursion a powerful way to build memory hardware? Compare drawing a hardware hierarchy to building nested arrays in software.
Milestone
All RAM chips and the PC pass their respective test scripts; a one-page reflection is written and saved.
