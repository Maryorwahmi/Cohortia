Process

Build RAM8

RAM8 uses eight 16-bit registers, 3-bit addressing, DMux for write routing, and Mux for read selection.

Step 1 — Instantiate registers
Create eight 16-bit registers, each with load input driven by a DMux of the RAM load and the 3-bit address.
Step 2 — Route writes with DMux
Use address bits to DMux the single load signal so only the selected register receives load=1.
Step 3 — Aggregate reads with Mux
Combine the eight register outputs with a 8-way Mux controlled by the address to produce the RAM output bus.
Example
Address 010 and load=1: DMux routes load to register 2, that register latches the input value on the clock. All other registers hold their previous values.
Key takeaway
The same DMux/Mux pattern that routes write and read signals at RAM8 will be reused at larger scales.
Misconception
Muxes do not duplicate data; they select which register's output appears on the bus. Only the selected register's data is visible externally.
