PC selection chain

Implement the Mux16 chain so reset overrides load and load overrides inc.

// pseudo-structure for PC next value
// hold is current PC output
incResult = Add16(hold, 1)
next = Mux16(a=hold, b=incResult, sel=inc)
next = Mux16(a=next, b=in, sel=load)
next = Mux16(a=next, b=0, sel=reset)
// Register receives next on clock
Register(in=next, load=true)
Test scenario
Set inc=1, load=1, reset=0. Expect the PC to load the external input, not increment. Then set reset=1 and confirm PC becomes 0.
Concepts to watch
  • Compute inc result from current PC via Add16 or Inc16.
  • Chain Mux16 operations so higher-priority control is applied last.
  • Register feedback provides the hold input for the next cycle.
