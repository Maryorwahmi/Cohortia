Module 3 › Chapter 2.6 › Program Counter
Definition

PC: inc, load, reset

The PC is a register with logic to choose its next input: increment, explicit load, or reset to zero.

inc
When asserted, the PC increments by one on the next clock cycle.
load
When asserted, the PC loads the supplied input value on the next clock cycle.
reset
When asserted, the PC resets to zero regardless of other controls.
Example
Jump case: load=1 and inc=1. Because load outranks inc, the PC will load the target address instead of incrementing. Reset case: if reset=1, PC becomes 0 regardless of load or inc.
Key takeaway
Priority ordering is essential. Treat reset as emergency override, load as deliberate control, and inc as default progression.
Common mistake
If priorities are implemented incorrectly, jumps or resets may be ignored under concurrent signals.
