What the RAM tests check

Follow a disciplined test plan: unit-test modules before composing them and use the provided scripts to confirm behavior.

Uninitialized reads
Check that reads from never-written addresses return zero.
Write isolation
Write to one address and ensure other addresses keep their values.
Sequential behavior
Verify reads and writes across consecutive clock cycles behave as specified by the tests.
Debug tip
If a composed RAM fails, isolate the error by testing the smaller RAM submodules (RAM8, RAM64) and verifying DMux/Mux trees separately.
Common mistake
Not zeroing outputs on uninitialized registers or incorrectly distributing the load signal so multiple registers write simultaneously.
