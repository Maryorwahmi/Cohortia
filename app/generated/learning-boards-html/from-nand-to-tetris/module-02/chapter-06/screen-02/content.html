Learning Objectives

Four verified milestones that prepare you for the CPU and memory integration.

Bloom: Learn → Understand → Apply → Master
01
Build sequential chips
Implement Bit and 16-bit Register; control writing with load signals and clocked DFFs.
Mnemonic: tiny flip-flop icon clustered into a register.
VERIFIED COMPETENCY MILESTONE
02
Assemble RAM hierarchy
Compose RAM8 nodes into RAM64, RAM512, RAM4K and RAM16K using Mux/DMux address routing.
Mnemonic: nested boxes showing recursion depth.
VERIFIED COMPETENCY MILESTONE
03
Design the PC
Implement reset, load, inc with priority reset > load > inc using Mux16 and Register feedback.
Mnemonic: traffic-light priority strip.
VERIFIED COMPETENCY MILESTONE
04
Test memory correctly
Verify uninitialized reads return 0, writes don't corrupt other addresses, and sequential reads/writes behave correctly.
Mnemonic: checklist and census-taker.
VERIFIED COMPETENCY MILESTONE
