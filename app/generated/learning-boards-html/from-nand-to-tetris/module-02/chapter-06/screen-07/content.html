From RAM512 to RAM16K

Each new level composes eight copies of the previous RAM chip and consumes an extra 3 address bits to expand capacity eightfold.

RAM512
Built from eight RAM64 chips. Uses 9-bit addresses: 3 lower, 6 upper splitting across levels.
RAM4K
Built from eight RAM512 chips. Address width grows accordingly to select the correct subblock and inner register.
RAM16K
Final data memory for Hack: 16K words. Each higher-level DMux/Mux layer routes signals across blocks predictably.
Debugging strategy
Test each module individually. If a top-level read is wrong, isolate by checking outputs at every intermediate Mux level to find the failing submodule.
Misconception
Don't assume the address is a single opaque value; treat it as partitions consumed at each recursion layer for clear wiring and testing.
