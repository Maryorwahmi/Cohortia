From objective to test

Each objective maps to a simulator script and a green pass criterion. Use these checks as you implement and debug.

Sequential chips
Run bit and register tests that toggle load and clock to confirm stored values update only when load is asserted.
Recursive RAM
Implement RAM8 then compose larger chips. Verify addressing uses lower bits for intra-chip selection and upper bits for chip selection.
Program Counter
Assemble Mux16 and Add16 with a Register and run PC tests for reset, load, and increment behavior.
Testing checklist
  • Uninitialized reads return 0
  • Writes do not modify other addresses
  • Sequential read/write across cycles behaves correctly
Milestone
All RAM and PC tests pass in the simulator. Reflect on why recursion simplifies the design.
