Project 3: Memory & PC

Complete the sequential chips that form data memory and build the Program Counter that advances and controls instruction flow. Learn the recursive RAM structure and the PC's prioritized selection chain.

Lab walkthrough style: steps, checks, and tests
In this lesson
Build Bit→Register→RAM hierarchy; assemble the PC; pass RAM tests ensuring isolation and correct uninitialized reads.
Why it matters
Memory and the program counter are the heart of sequential execution. Without correct memory, programs cannot store variables or jump reliably.
Coming up

Recursive RAM
Assemble RAM8→RAM64→...→RAM16K with Mux/DMux trees.
Program Counter
Implement inc, load, reset with correct priority.

Key takeaway
Small, tested sequential chips combine predictably into large memories. The PC enforces safe control flow by prioritizing reset and load over increment.
