RAM64 and the recursive pattern

Compose eight RAM8 chips to make RAM64. Split the 6-bit address into upper and lower halves for inter- and intra-chip selection.

Pattern repeats for RAM512, RAM4K, RAM16K
Address split
Lower 3 bits: index inside RAM8. Upper 3 bits: choose which RAM8 block is active in RAM64.
Write flow
Upper bits DMux the write enable to one RAM8; inside that block lower bits select the register to write.
Read flow
Lower bits select outputs from each RAM8; upper bits select which of those outputs becomes the RAM64 output.
Concrete example
Address 0b001011: upper 001 selects the second RAM8; lower 011 selects the fourth register inside that RAM8. Only that register receives the write enable and later drives the output when read.
Tip
When wiring, label address bits clearly and draw upper vs lower partitions to avoid misrouting signals between levels.
