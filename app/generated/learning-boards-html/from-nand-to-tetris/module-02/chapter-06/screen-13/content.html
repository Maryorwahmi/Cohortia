Module 3 › Chapter 2.6 › Assessment: PC Priority

Question walkthrough

Explain why reset > load > inc and show a concrete failure if the order changes.

Rationale
Reset ensures known starting state. Load implements deliberate control transfers. Inc is the default progression.
Failing scenario
If inc outranks load, a jump with load=1 and inc=1 would be ignored and the PC would increment, skipping the jump target.
Answer tip
When writing your answer, include the priority rule, the rationale for each rank, and a concrete example demonstrating the failure mode.
