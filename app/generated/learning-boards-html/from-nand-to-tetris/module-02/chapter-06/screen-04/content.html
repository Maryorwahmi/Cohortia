Definition

Bit primitive and 16-bit Register

A Bit is a D flip-flop with a Mux controlled by load. Sixteen Bits wired in parallel form a 16-bit Register.

Implementation notes
  • Each Bit has inputs: in, load, clock and output: out.
  • Register shares load and clock across 16 Bits to update synchronously.
  • When load is 0, the feedback path holds the previous value.
Visual: parallel bits
Bit chip
DFF + Mux. Inputs: in, load. Output: out.
16-bit Register
16 Bits with shared load/clock. Writes occur simultaneously across bits when load=1.
Example
To store the address 123, place its 16-bit pattern on the input bus and assert load for one clock tick. After the tick the register returns that value on its output until the next write.
Common mistake
Assuming individual bits can be loaded independently; here the whole 16-bit register updates together under one load control.
