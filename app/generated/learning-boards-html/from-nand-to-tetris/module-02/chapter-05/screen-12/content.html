Module 2 › Chapter 2.5 › Pitfalls & Fixes
Common mistakes
  • Ignoring hold-time paths and only checking setup.
  • Trusting simulator results without timing analysis.
  • Using single-stage synchronizers on multi-bit signals.
  • Missing rare control paths that dominate worst-case delay.
Practical fixes
  • Add balanced delays or buffering to fix hold violations.
  • Insert two-stage synchronizers for async single-bit inputs and handshake protocols for buses.
  • Run timing checks across different operating corners and clock skew assumptions.
Key Takeaway
Turn timing theory into a checklist: verify long and short paths, treat async inputs carefully, and test under worst-case conditions.
