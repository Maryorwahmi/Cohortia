Module 2 › Chapter 2.5 › 4-bit Counter
Given delays
  • DFF t_cq = 1 ns
  • Mux delay = 2 ns
  • Full adder delay = 3 ns
  • Setup time = 1 ns
Worst-case path
t_cq + (full adder chain) + Mux + t_setup
Calculation
Assume carry ripples through three adders in the worst case: combinational = 3 * 3 ns = 9 ns. Add Mux 2 ns = 11 ns. Add t_cq 1 ns and t_setup 1 ns gives 13 ns.
T ≥ t_cq + t_comb + t_setup
T ≥ 1 ns + 11 ns + 1 ns = 13 ns
If clock were halved
Setting T ≈ 6.5 ns would leave carries incomplete when sampled, producing incorrect counts and unpredictable state transitions.
