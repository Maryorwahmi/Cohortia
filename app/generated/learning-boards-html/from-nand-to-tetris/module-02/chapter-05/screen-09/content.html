Feedback with DFF
A DFF stores the previous step's output and only updates on the clock edge. That breaks an instantaneous combinational loop into discrete steps across clock cycles.
Bit chip example
The Bit chip's Mux selects between input and stored output; the DFF holds the stored output and updates each clock, so the loop does not compute continuously.
Why this helps
  • Predictable state updates occur only on clock edges.
  • Combinational logic reads stable inputs between edges and produces stable outputs before the next edge.
  • Designers analyze one clock cycle at a time, simplifying proofs of correctness.
Key Takeaway
The DFF creates the discrete-time semantics that make sequential circuits stable and analyzable.
