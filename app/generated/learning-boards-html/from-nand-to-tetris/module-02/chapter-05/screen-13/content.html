Module 2 › Chapter 2.5 › Design Timeline
Workflow
  1. Estimate delays and set an initial clock period budget.
  2. Map design to gates, compute exact register-to-register delays.
  3. Identify critical paths and apply pipelining or optimization.
  4. Check for hold violations and add small buffers if needed.
  5. Run corner timing simulations and verify clock distribution/skew.
Key Takeaway
Plan timing checks early and iterate. Early budgets reduce expensive changes later in the design cycle.
