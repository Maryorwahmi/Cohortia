Module 2 › Chapter 2.5 › Clock Period
Period inequality
T ≥ t_cq + t_combinational + t_setup
Procedure: for each pair of sequential elements, compute the sum on the right-hand side. The maximum of these sums across the design is the minimum safe clock period.
Misconception
The formula gives a lower bound for correct sampling. It does not predict performance beyond frequency; it only constrains correctness.
Example paths
Path A: t_cq=1 ns + comb=3 ns + t_setup=1 ns → T ≥ 5 ns
Path B: t_cq=1 ns + comb=6 ns + t_setup=1 ns → T ≥ 8 ns
Slowest path is Path B, thus T ≥ 8 ns
Key Takeaway
Find the worst-case register-to-register delay; that defines the clock period.
