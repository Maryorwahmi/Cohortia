Clock-to-Q delay (t_cq)
Time for the flip-flop output to reflect the new stored bit after the clock edge.
Why it matters
t_cq sets the earliest valid start time for the subsequent combinational logic. It therefore appears directly in the clock period inequality.
Quick example
If t_cq = 1 ns and the downstream adder delay is 3 ns, the earliest valid adder output is at 4 ns after the source clock edge. If the destination setup is 1 ns, the clock period must be at least 5 ns.
T ≥ t_cq + t_combinational + t_setup
T ≥ 1 ns + 3 ns + 1 ns = 5 ns
Key Takeaway
Always include t_cq when summing delays across flip-flop boundaries.
