Module 2 › Chapter 2.5 › Metastability
What is metastability?
A temporary uncertain output state when a flip-flop samples a changing input at the clock transition.
Real-world example
A human-pressed button changes asynchronously; if it toggles near the clock edge, the sampled bit may be metastable.
Mitigation pattern
Use a two-stage synchronizer: the first flip-flop captures the asynchronous input and may go metastable; the second stage samples the first after an additional clock period, allowing metastability to resolve with high probability.
Stage 1: Asynchronous input → DFF1
Stage 2: DFF1 output → DFF2 → Stable domain
Key Takeaway
Treat asynchronous inputs through synchronizers; accept that you only reduce the probability of failure, not eliminate it.
