Checklists and edge cases to pass the reference tests.
Checklist
  • Remove all line and block comments without emitting tokens.
  • Skip whitespace and only split tokens where required.
  • Identify keywords vs. identifiers by lookup.
  • Ensure integer values stay within 0–32767.

Edge cases
Nested comment delimiters, strings containing symbols, and identifiers with underscores are common traps. Use explicit rules and tests to avoid them.
