Process Lexer state machine
Common lexer states
start, identifier/keyword, integer, string, symbol, comment-skipper. Each state knows when to emit and which state to enter next.
State transition sketch
start:
  if letter -> identifier
  if digit  -> integer
  if '"'   -> string
  if '/'    -> comment or symbol
  if symbol -> emit symbol

identifier:
  read letters/digits/_ until delimiter, then check keyword table
Implementation tips
  • Keep a small token buffer per state.
  • Use lookahead only when necessary, e.g., slash handling.
  • Write unit tests per state.
Pro tip
Emitting tokens as soon as they complete keeps memory low and simplifies streaming large files.
Key Takeaway

Modeling the lexer as states clarifies logic and isolates edge cases for testing.
