Comparison Keywords vs Identifiers
Workflow
  1. Read characters while they are letters, digits, or underscore.
  2. Form the candidate token string.
  3. Check the reserved-keyword table.
  4. Emit either a keyword token or an identifier token.
Mnemonic
Form the word first, then ask "Is it reserved?"
Concrete examples
class → keyword Main → identifier let → keyword getX2 → identifier
Common mistake
Using a single-character test for letters only and forgetting underscores or digits leads to incorrect identifiers.
Key Takeaway

Always form the full name then decide whether it's reserved; this keeps keyword detection reliable.
