Code Walkthrough Tokenizer XML
Required XML format
Wrap tokens in an outer <tokens> element. Use the precise tag names the project expects for each token type.
Example
<tokens>
  <keyword> let </keyword>
  <identifier> x </identifier>
  <symbol> = </symbol>
  <integerConstant> 5 </integerConstant>
  <symbol> ; </symbol>
</tokens>
Common mistake
Mismatched tag names or extra whitespace causes failing comparisons. Match the reference formatting exactly when tests require byte-wise checks.
Key Takeaway

XML output is a test artifact; produce tokens in order and format them to match the course reference files.
