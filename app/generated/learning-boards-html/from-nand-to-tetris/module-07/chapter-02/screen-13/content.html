Comparison Testing & Debugging
Testing workflow
  1. Run tokenizer on a small sample file and generate XML.
  2. Compare your XML to the reference using a diff tool.
  3. Isolate the first mismatch and inspect the corresponding code path.
  4. Write focused unit tests for that lexer state.
Common failures
Extra tokens from comments, misclassified keywords, missing string termination, or wrong XML tag formatting.
Key Takeaway

Turn tokenization correctness into simple file comparisons, then fix the small logic that causes the mismatch.
