Definition Why comments are removed
Separation of concerns
Removing comments keeps the parser's grammar small and focused on structure instead of handling non-semantic tokens everywhere.
If comments were tokens, every grammar rule would need optional comment handling which increases complexity and risk of bugs. Removing them at the lexical stage reduces these issues and makes testing easier because the token stream only contains meaningful elements.
Analogy
Like stripping comments from a draft before grammar checking, cleaning text early simplifies the next step.
Key Takeaway

Remove comments in the lexer to keep parsing rules compact and robust.
