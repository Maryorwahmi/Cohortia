Core Concept What is lexical analysis?
Definition
Lexical analysis reads characters and groups them into tokens, removing comments and whitespace.
Example
let x = 5;

Tokens produced:
KEYWORD(let)
IDENTIFIER(x)
SYMBOL(=)
INT_CONST(5)
SYMBOL(;)
Why this matters
By emitting a clear token stream, the lexer reduces parser complexity and avoids grammar rules that must accept comments or arbitrary whitespace.
Analogy
The lexer is like a typesetter who first separates words and punctuation so the editor can check sentence structure later.
Common mistake
Treating comments as tokens forces the parser to accept them everywhere. Remove comments in the lexer instead.
Key Takeaway

Keep tokenization and parsing separate: lexer handles text, parser handles structure.
