Definition Identifiers & Integers
Identifier rules
Start with a letter; then allow letters, digits, or underscores. Do not accept a name starting with a digit.
Examples
x, sum, Main, getX, x1
Integer constraints
Decimal numbers between 0 and 32767. Example: 0, 123, 32767. Validate and report out-of-range values.
Common mistake
Allowing an identifier to start with a digit or accepting spaces in numbers will cause incorrect token boundaries and parsing errors.
Key Takeaway

Enforce first-character rules for identifiers and validate integer bounds early in the lexer.
