Token Types Five types
Keywords
Reserved words that control structure, e.g., class, function, let, return, if, while.
Symbols
Operators and punctuation such as { } ( ) [ ] . , ; + - * / & | < > = ~.
Identifiers
Names made of letters, digits, and underscores, not starting with a digit. Examples: x, sum, getX, x1.
Integer constants
Decimal numbers in range 0 to 32767. Examples: 0, 123, 32767.
String constants
Text surrounded by double quotes, e.g., "Hello". The lexer reads until the closing quote and emits the contained characters as one token.
Key Takeaway

The five token types are the building blocks; their correct identification is essential for a correct parse.
