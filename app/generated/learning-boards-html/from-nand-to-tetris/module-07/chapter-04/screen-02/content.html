Learning Objectives
Concrete milestones to verify your code generator works.
01
Expression VM Code
Emit stack operations for arithmetic, logical, and comparison expressions. Practice with x + y * 2 to verify precedence is preserved.
VERIFIED COMPETENCY MILESTONE
02
Statement Templates
Generate correct VM patterns for let, if, while, do, and return, including labels and jumps for control flow.
VERIFIED COMPETENCY MILESTONE
03
Symbol Table Mastery
Map identifiers to kind, segment, and index. Differentiate class-level and subroutine-level scopes when resolving names.
VERIFIED COMPETENCY MILESTONE
04
Visitor Pattern
Implement a traversal that compiles classes and subroutines by initializing symbol tables and emitting code per node.
VERIFIED COMPETENCY MILESTONE
