Symbol Table Record
Each identifier stores four fields which guide code generation.
Name
The identifier string used in lookups.
Type
Primitive or class name used for size and semantic checks.
Kind
One of static, field, local, or parameter — selects VM segment.
Index
Offset within the chosen segment; assigned when defined.
Usage Patterns
  • Lookup yields kind and index for push/pop instructions.
  • Subroutine table is reinitialized for each subroutine.
  • Class table persists for static and field entries across subroutines.
Common Mistake
Assigning indices in multiple places leads to inconsistent addresses; centralize index counters per kind.
