Module 7 › Chapter 7.4 › Expression Code Generation
Pattern
Each term leaves one value on the stack. Operators consume top values and push results.
// x + y * 2
push local 0    // x
push local 1    // y
push constant 2
mult
add
Checklist
  • Follow parse-tree grouping to respect precedence.
  • Ensure compile_term leaves exactly one stack value.
  • Emit correct VM opcode for each operator mapping.
Common Mistake
Emitting operator commands before pushing all operand values breaks stack ordering.
