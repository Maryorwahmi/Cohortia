Module 7 › Chapter 7.4 › What the Code Generator Does
Definition
A visitor that walks parse-tree nodes and emits VM commands, consulting the symbol table for addressing details.
def compile_subroutine(node):
  # init symbol table for params and locals
  for var_dec in node.var_decs:
    symbol_table.define(var_dec.name, var_dec.type, 'local')
  for statement in node.statements:
    compile_statement(statement)
Explanation
  • Visitor pattern provides a clear entry point per node type.
  • The symbol table is initialized per subroutine for locals and parameters.
  • Emitted VM code relies on symbol-table indices for segment selection.
Key Takeaway
Separation of concerns keeps parse trees small and symbol resolution centralized.
