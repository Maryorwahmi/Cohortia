Module 7 › Chapter 7.4 › If Statement Pattern
Pattern Example
// if (expression) { statements1 } else { statements2 }
// generate expression
if-goto ELSE
// statements1
goto END
label ELSE
// statements2
label END
Tips
  • Generate a fresh unique label for ELSE and END per if instance.
  • Remember if-goto jumps when the condition is true; invert logic accordingly.
  • Test both branches and edge cases where the condition is false immediately.
Common Mistake
Reusing labels across different ifs causes incorrect jumps; ensure uniqueness.
