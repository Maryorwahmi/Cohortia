Module 7 › Chapter 7.4 › Mistakes & Debugging
Symbol indices
Verify index assignment per kind and print the table at subroutine entry for tests.
Operator order
Use parse-tree-driven compilation to avoid precedence bugs.
Label collisions
Always generate unique labels for ifs and loops to avoid jump conflicts.
Quick debug strategy
Map each VM instruction to the parse-tree node and the symbol-table lookup that produced it. That mapping makes bugs local and fixable.
