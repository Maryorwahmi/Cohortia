Module 7 › Chapter 7.4 › While Loop Pattern
Canonical Sequence
// while (expression) { statements }
label LOOP
// generate expression
if-goto END
// generate statements
goto LOOP
label END
Practice Points
  • Labels must be unique per loop instance.
  • Ensure the condition evaluation pushes a boolean before if-goto.
  • Test zero-iteration cases to confirm correct branching to END.
