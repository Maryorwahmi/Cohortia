Method Call
Push object reference first, then explicit arguments, then call.
// for obj.method(arg1)
push  
push 
call ClassName.method 2
Constructor
Allocate memory with Memory.alloc, push the returned object reference, then call constructor to initialize fields.
// new ClassName(nFields)
push constant nFields
call Memory.alloc 1
// returned reference on stack
call ClassName.new nArgs
