Module 7 › Chapter 7.4 › Let Statement Template
Pattern
Compute expression → pop to variable's segment/index.
// let x = expression;
// generate code for expression
pop local i   // i is index of x in symbol table
Notes & Example
Before pop, confirm the symbol table kind: static, field, local, or parameter. Using wrong segment leads to runtime errors or wrong data reads.
Pro Tip
Always query symbol_table.kind and symbol_table.index once just before emitting the pop to avoid stale state.
