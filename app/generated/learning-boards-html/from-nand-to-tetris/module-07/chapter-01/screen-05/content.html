Primitive types
  • int: 16-bit signed integer used for arithmetic and indexing.
  • boolean: true or false, used for conditionals.
  • char: single ASCII character.
Complex types
Arrays and objects are reference types. Use Array.new to allocate arrays. Objects are instances of classes and are addressed by their base address.
Example
Array a = Array.new(10); // allocate an array of ten ints and store its reference in a
Practice
// create and sum an array
var Array arr;
let arr = Array.new(10);
let arr[0] = 1;
let arr[1] = 2;
// ... fill and sum
Remember: arrays require allocation via the OS; they are not raw contiguous stack storage like local variables. This affects how the compiler emits code for access and updates.
