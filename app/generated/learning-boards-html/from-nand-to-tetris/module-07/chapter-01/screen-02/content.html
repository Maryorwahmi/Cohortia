Module 7 › Chapter 7.1 › Learning Objectives
01
Describe syntax and semantics
Explain the structure of a .jack file and what declarations mean. Verified competency: identify fields and methods in a class file.
02
Understand Jack's type system
Know int, boolean, char, arrays, and objects and why the set is small. Verified competency: describe where each type is stored at runtime.
03
Write simple Jack programs
Use variables, expressions, control constructs, and calls. Verified competency: produce a working Main.jack printing a computed value.
04
Explain OOP features
Describe classes, objects, methods, constructors, and this. Verified competency: explain why constructors return this and how this maps to the VM.
