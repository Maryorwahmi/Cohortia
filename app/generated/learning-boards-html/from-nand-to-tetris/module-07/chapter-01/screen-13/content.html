Starter programs
  1. Hello World — print a string using Output routines.
  2. Calculator — read two numbers, add, print result.
  3. Array sum — allocate an array, fill, and sum values in a loop.
  4. Point class — build objects, call methods, and print coordinates.
Checklist
  • Write Jack source for each task.
  • Compile to VM and inspect generated commands.
  • Compare numbers of VM commands per Jack statement.
  • Fix constructor to end with return this if missing.
Pro tip
Counting VM commands for each high-level statement exposes the translation cost and clarifies how stack-based VM primitives implement language features.
