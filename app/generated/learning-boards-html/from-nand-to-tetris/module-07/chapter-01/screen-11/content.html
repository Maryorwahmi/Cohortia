Module 7 › Chapter 7.1 › Jack OS
OS components
  • Memory: allocation and deallocation.
  • Array: creation and access helper routines.
  • Math, String, Output, Screen, Keyboard, Sys: utility and IO routines.
Practical note
Because the OS is written in Jack, you will compile and inspect it too. This reveals exactly how library calls become VM operations and how high-level utilities are built from lower-level primitives.
Activity
Call Output.printInt and inspect the VM call sequence. Note how arguments are pushed and how the OS routine expects and handles them.
