Module 7 › Chapter 7.1 › Routines & this
Kinds of routines
function: class-level, no implicit this.
method: operates on an instance; this points to the object's base.
constructor: allocates an object, initializes fields, and returns this.
Misconception
Constructors do not magically create objects; allocation and initialization appear in VM code and must return the object's address explicitly.
Concrete pattern
Constructor steps you will see in VM output: call Memory.alloc(n), set pointer to base, initialize fields by popping into this offsets, then push this and return.
Key Takeaway
Constructors must return this so the caller receives the object's base address and can use it for further calls and field access.
