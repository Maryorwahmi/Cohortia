Example Jack code
// Main.jack
class Main {
    function void main() {
        var int a, b, sum;
        let a = 3;
        let b = 5;
        let sum = Main.add(a, b);
        do Output.printInt(sum);
        return;
    }
    function int add(int x, int y) {
        return x + y;
    }
}
Translate to VM (conceptual)
  • var declarations → allocate local slots in function frame.
  • let a = 3 → push constant 3; pop local a.
  • call Main.add → push arguments, call label, manage return address.
  • do Output.printInt(sum) → push argument, call OS routine, discard return value.
