The Jack Programming Language
A compact, Java-like language used as the high-level input to the course toolchain.
Jack keeps syntax and features minimal so you can implement a working compiler and explore how classes, objects, and methods become VM commands. We will use Jack programs, the Jack OS, and the VM to understand compilation end-to-end.

Types, objects, and the small OS that make Jack both teachable and capable.
Classes as blueprints
Think of each class as a building blueprint. Fields are the rooms, methods are the actions you can perform, and a constructor builds the house and returns its address.
Objects as houses
Each object is a contiguous memory block whose base address is passed as this. The OS provides utilities like Output and Memory for working with programs.
Key Takeaway

Jack is intentionally small so you can trace every language feature through a student-built compiler to the VM and hardware.
