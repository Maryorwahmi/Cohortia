Module 7 › Chapter 7.1 › Learning Objectives
01
Describe syntax and semantics
Translate a small class to a description of its fields and methods. Verified: label each declaration in a .jack file.
02
Understand Jack's type system
Explain at compile time which variables are ints, booleans, chars, arrays or objects. Verified: annotate declarations with storage class.
03
Write simple Jack programs
Implement Hello World, a calculator, and a small class. Verified: compile and run these programs and inspect VM output.
04
Explain OOP features
Construct classes and objects and explain how constructors return this. Verified: trace constructor allocation to VM code.
