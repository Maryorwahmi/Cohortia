Module 7 › Chapter 7.1 › Point.jack Example
Point.jack source
// Point.jack
class Point {
    field int x, y;
    constructor Point new(int ax, int ay) {
        let x = ax;
        let y = ay;
        return this;
    }
    method int getX() { return x; }
    method int getY() { return y; }
    method void setX(int ax) { let x = ax; return; }
}
Memory model insight
Objects are contiguous memory blocks. The object's base address is passed as this; methods use this plus field offsets. The compiled code for methods is shared across instances; the only per-instance data is the this address and the object's fields.
Practice
Create two objects, call setX on each, and inspect VM output to see identical method code but different this pointers in calls.
