Module 7 › Chapter 7.1 › Control Structures
Statements
  • let: assignment — evaluate expression then pop into a target segment.
  • do: call a function and discard its return value.
  • if: evaluate condition, jump to then/else labels.
  • while: evaluate and jump back to loop label until false.
  • return: return a value or void from a routine.
Process example
To sum an array: initialize index and sum with let, loop with while, access elements by computing base+index, and use let to update sum. The compiler emits pushes and pops and labels for the loop control.
Common mistake
Expecting do to preserve a return value. do discards returns, so use let to capture a returned value if you need it.
