Module 7 › Chapter 7.1 › Classes & Variables
Class components
  • fields — object-level variables, accessed via this.
  • static — class-level shared variables.
  • methods/functions/constructors — behavior attached to the class or instances.
Variable kinds inside methods
local: var declarations; parameter: method arguments; both map to the stack frame and the VM local and argument segments.
Example: Point class storage
field int x,y; // stored in the object's memory block, accessed through this segment
Practice
Take a class with a constructor and list each declared variable with its runtime segment: static, this, local, or argument. Then match those to VM segments.
