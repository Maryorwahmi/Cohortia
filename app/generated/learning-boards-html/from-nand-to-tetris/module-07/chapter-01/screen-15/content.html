Module 7 › Chapter 7.1 › Key Concepts
Routines
Functions, methods, constructors — constructors must return this so callers get the new object's base address.
Jack OS
OS routines are Jack code compiled to VM; services like Memory and Output are not magical primitives but implemented libraries.
Compilation
Every Jack statement expands into VM push/pop, call, arithmetic, and jump primitives. Inspecting that mapping is central to learning compilers.
Final Takeaway
Jack's simplicity exposes the mapping from language design to implementation. Use the hands-on tasks to see that mapping in action.
