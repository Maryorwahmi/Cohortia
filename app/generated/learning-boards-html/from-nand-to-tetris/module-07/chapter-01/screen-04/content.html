Module 7 › Chapter 7.1 › Jack language overview
Definition
Jack is a teaching language that is simple enough for a student-built compiler yet expressive enough to write games and utilities. It separates program structure into classes and methods and relies on a small OS for I/O and memory support.
Why this design
Simplifies compiler construction while preserving expressive power; you see how each construct compiles down to VM commands.
Common misconception
Small languages are not weak; Jack omits complexity to make compilation tractable for a course, yet it remains Turing-complete.
Analogy
Think of Jack as a blueprint language for programs: compact plans that a compiler translates into construction steps the VM executes.
Try this
Open a tiny .jack file and label each declaration as static, field, var, or parameter. Predict where each will live at runtime and check after compiling.
