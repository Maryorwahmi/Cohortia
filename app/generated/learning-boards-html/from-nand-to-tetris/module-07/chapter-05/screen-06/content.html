Module 7 › Chapter 7.5 › Point.new walkthrough
Full example
function Point.new 0
push constant 2      // 2 fields: x,y
call Memory.alloc 1  // returns base
pop pointer 0        // this = base
push argument 0
pop this 0           // x = ax
push argument 1
pop this 1           // y = ay
push pointer 0
return
Trace the stack during Memory.alloc: after the call the returned base is on the stack; pop pointer 0 removes it from the stack and stores it in the this register. Field initialization uses argument values transferred into this offsets.
Pro tip
When testing, look for the push constant n and call Memory.alloc sequence as the constructor signature.
Common mistake
Confusing pointer 0 with a RAM address write. pop pointer 0 sets the pointer register, it does not write the base into RAM cells directly.
