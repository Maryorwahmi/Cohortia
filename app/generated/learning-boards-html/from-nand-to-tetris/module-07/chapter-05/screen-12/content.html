Module 7 › Chapter 7.5 › Compiler responsibilities
During parsing

Collect field declarations into the class symbol table, assign each field an index, and count total fields for allocation.

During code gen

Emit push constant nFields; call Memory.alloc 1; pop pointer 0; then use indices from the symbol table for push/pop this i.

Debugging tip

If field reads return wrong values, inspect symbol table indices and the constructor's allocation count. Off-by-one errors are the usual cause.
