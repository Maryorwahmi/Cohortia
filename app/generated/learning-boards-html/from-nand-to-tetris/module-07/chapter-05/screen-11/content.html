Module 7 › Chapter 7.5 › this vs that
this

Holds the object's base address for the whole method. Used with push/pop this i to access fields.

that

Used temporarily to point at an array element address computed as base + index. Set per access using pop pointer 1.

Example scenario

A method needs to read an object's field and then an array element. With separate segments you can keep this unchanged while pointing that at the array element for the single access.
