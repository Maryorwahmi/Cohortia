Module 7 › Chapter 7.5 › Key Concepts
Objects as blocks
Fields are stored in consecutive RAM words indexed from a base address.
Constructors allocate
push constant n; call Memory.alloc; pop pointer 0 to set this.
Methods set this
Caller passes object as argument 0; method sets this from argument 0 before field access.
Quick takeaway

Spotting a few VM patterns lets you verify object and array behavior quickly: allocation, pointer setup, and index-based access are the signals you need.
