Definition

Object layout

An object's fields occupy consecutive RAM words. The object's base address is used as the this segment value for field access.

RAM[base + 0] = x
RAM[base + 1] = y
// access field 0: push this 0
// access field 1: push this 1
Analogy

Think of the base as a house entrance and fields as numbered rooms. An offset picks the correct room.

Example
Point object with two fields. Methods and constructors use the field indices from the class symbol table to read and write these words.
Key takeaway

Field accesses are offset computations from a stable base held in the this segment; the layout is predictable and index-driven.

Common mistake

Mistakenly treating field addresses as independent pointers. Remember: fields are offsets from one base address.
