Module 7 › Chapter 7.5 › Field access
Canonical form

Reads and writes are always expressed relative to the this pointer using small integer indices from the symbol table.

// read field i
push this i
// write field i
pop this i
Example mismatch

If the symbol table assigns x index 0 and y index 1, using push this 1 when you mean x will access y. Verify indices during compilation.

Key Takeaway

Field access is index-based; maintain accurate symbol tables so generated push/pop indices match the intended fields.
