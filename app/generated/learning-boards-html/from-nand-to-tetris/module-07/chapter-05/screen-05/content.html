Module 7 › Chapter 7.5 › Constructor code generation
Steps
  1. push constant nFields
  2. call Memory.alloc 1 (returns base address)
  3. pop pointer 0 (set this to base)
  4. initialize fields via pop this i or push argument j; pop this i
  5. push pointer 0; return
Why it matters

This sequence ensures the object has space, this points to its base for the rest of the constructor and for callers who receive the reference, and fields are explicitly initialized by the constructor code.

function Point.new 0
push constant 2      // allocate 2 words
call Memory.alloc 1
pop pointer 0        // this = base
push argument 0
pop this 0           // x = ax
push argument 1
pop this 1           // y = ay
push pointer 0
return
