Module 7 › Chapter 7.5 › Array element access
Sequence
push local 0    // arr base
push local 1    // index i
add             // base + i
pop pointer 1   // that = base + i
push that 0     // read arr[i]
Notes
  • pointer 1 corresponds to the that segment; it stores an address.
  • push that 0 dereferences the computed address to return the element value.
  • Use pop that 0 to write a value into the element.
