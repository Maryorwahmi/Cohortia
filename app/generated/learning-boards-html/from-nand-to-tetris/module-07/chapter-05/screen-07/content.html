Module 7 › Chapter 7.5 › Method code generation
Pattern
  1. Caller pushes object reference as argument 0.
  2. Method sets this = argument 0 via pop pointer 0.
  3. Access fields with push/pop this i.
  4. Return value or void as needed.
Example
function Point.getX 0
push argument 0
pop pointer 0        // this = object reference
push this 0          // return x
return
Note that the caller must have pushed the object reference before calling. Without that, the method cannot access fields correctly.
