Object-Oriented Code Generation

Translate classes, constructors, methods and arrays in Jack into VM sequences that allocate memory, set the this and that segments, and access fields and elements reliably.

Objects

Contiguous memory blocks with fields indexed from base.

Constructors

Call Memory.alloc, set this, and initialize fields.

Arrays

Allocate via the OS; access elements by computing base + index and using that.

Visual concept
House (object) vs Apartment (array)
House = object base (this). Apartment units = array indices (that).
RAM[base + 0] = x
RAM[base + 1] = y
// this points at base
push this 0  // read x
push this 1  // read y
