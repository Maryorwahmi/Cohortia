Module 7 › Chapter 7.5 › Arrays and Array.new
How it works

Array.new(size) requests a block from the OS. The returned base is used with index arithmetic to reach elements.

// allocate array of length n
push constant n
call Array.new 1   // returns base address
Why that

Using that for array access lets the compiler temporarily point to an element without disturbing this, which remains set for object field access.

Common pitfall

Overwriting this to access an array will break subsequent field accesses in a method. Use that for transient element addressing.
