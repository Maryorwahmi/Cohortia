Module 7 › Chapter 7.5 › Hands-on Activity
Point class

Expect push constant 2, call Memory.alloc 1, pop pointer 0, pop this 0/pop this 1, push pointer 0, return. Methods set this from argument 0.

Array sum

Look for push constant 10, call Array.new 1. In loops, compute base+index, pop pointer 1, push that 0 to read elements.

Object array

Array cells hold object references; constructors allocate each object and its base is stored in the array. Calls to element methods must pass that reference as argument 0.

Validation steps
  1. Find push constant n and call Memory.alloc / Array.new.
  2. Confirm pop pointer 0 sets this in constructors and methods set this from argument 0.
  3. Confirm array element access uses add then pop pointer 1 and push/pop that 0.
