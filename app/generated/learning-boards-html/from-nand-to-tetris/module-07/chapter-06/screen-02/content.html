Learning Objectives
Learn, understand, apply, and master the compiler pipeline
Bloom: Learn → Understand → Apply → Master
01
Complete the Jack compiler
Implement all modules so a directory of .jack files produces .vm outputs. This skill shows you can build a multi-module translator and integrate its parts.
VERIFIED COMPETENCY MILESTONE
02
Test on provided programs
Run Seven, ConvertToBin, Square, Average, Pong and Tetris through the full pipeline to confirm complete language support and runtime behavior.
VERIFIED COMPETENCY MILESTONE
03
Understand the pipeline
Explain how Jack maps to VM, how VM becomes assembly, and how assembly becomes machine code that runs on the Hack hardware.
VERIFIED COMPETENCY MILESTONE
04
Reflect on meta-programming
Articulate how a compiler is a program that manipulates programs, and why abstraction is the crucial principle behind the whole stack.
VERIFIED COMPETENCY MILESTONE
