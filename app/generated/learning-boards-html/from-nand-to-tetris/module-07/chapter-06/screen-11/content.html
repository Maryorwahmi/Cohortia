Module 8 › Chapter 7.6 › Testing Pipeline
End-to-end testing steps
Compile each .jack file to .vm, run the VM translator to produce assembly, assemble to machine code, and execute on the Computer Simulator. Verify output and behavior for each supplied program.
Small test
Seven — confirms basic compilation path for trivial returns.
Intermediate tests
ConvertToBin, Square, Average — checks loops, arrays and object features.
Full programs
Pong and Tetris exercise the entire language and runtime; they are the final integration checks.
If an error appears, inspect the VM output first. That tells you whether the bug is in the CompilationEngine/Writer or later in translation and assembly.
