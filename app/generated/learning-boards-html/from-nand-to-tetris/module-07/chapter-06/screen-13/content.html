Module 8 › Chapter 7.6 › Hands-on Activity & Assessment
Project checklist
  1. Implement JackTokenizer, CompilationEngine, SymbolTable, VMWriter.
  2. Compile a directory of .jack files to .vm and run the full translation pipeline.
  3. Test with Seven, ConvertToBin, Square, Average, Pong, Tetris and record results.
  4. Answer reflective prompts and write a two-page project reflection.
Assessment idea
Discuss whether a single-pass Jack compiler is feasible and what trade-offs would appear in complexity, forward reference handling and error messages.
Reflection prompts
Which module was hardest and why? How did implementing each layer change your view of abstraction?
