Module 8 › Chapter 7.6 › Symbol Table
Symbol table roles
Manage class-level and subroutine-level scopes. For each name, the table records type, kind and index so the CompilationEngine can emit correct memory access commands.
Class scope
Holds static and field declarations and their running indices.
Subroutine scope
Holds argument and local declarations; reset at each subroutine start.
Implementation checklist
  • Define(name,type,kind) assigns index using counter for kind
  • varCount(kind) returns the number of entries of that kind
  • kindOf(name), typeOf(name), indexOf(name) provide lookup for code generation
Common bug

Failing to reset subroutine-level counters causes index collisions between subroutines and incorrect memory references in generated VM code.

Key Takeaway

Maintain separate counters and clear subroutine scope at each subroutine start to ensure consistent indices.
