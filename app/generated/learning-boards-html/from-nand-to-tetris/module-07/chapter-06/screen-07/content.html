Module 8 › Chapter 7.6 › CompilationEngine
Grammar-driven methods
Each grammar rule in Jack corresponds to a CompilationEngine method. As the engine visits constructs it emits VM commands that implement their semantics, which keeps parsing and generation tightly aligned.
Statement methods
compileLet, compileIf, compileWhile, compileDo, compileReturn — each must emit the VM fragment that implements the statement's effect.
Expression methods
compileExpression, compileTerm, compileExpressionList handle operator precedence and subroutine call semantics during emission.
Concrete example
When compiling an if statement, the engine must evaluate the condition, emit a conditional jump to the else label if false, and place labels for true and false branches so the VM code preserves the original control flow.
Misconception

Assuming the parser only builds a tree and another pass always generates code is not required here; the CompilationEngine emits VM code as it parses to simplify the student implementation.

Key Takeaway

Implement grammar methods stepwise and test the emitted VM fragments to verify both parsing and generation logic.
