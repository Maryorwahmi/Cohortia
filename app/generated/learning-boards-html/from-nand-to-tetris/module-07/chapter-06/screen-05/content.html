Module 8 › Chapter 7.6 › Four core modules
Module interactions
Tokenizer → CompilationEngine → VMWriter, with SymbolTable consulted by the engine during parsing and code emission. Each piece has a single responsibility and a narrow interface to the next module.
JackTokenizer
Lexical analysis of source text into tokens.
CompilationEngine
Parses tokens and emits VM code for language constructs.
SymbolTable
Tracks name, type, kind, index for scopes.
VMWriter
Serializes VM commands to files.
Interface checklist
  • Tokenizer: nextToken(), tokenType(), tokenValue()
  • CompilationEngine: compileClass(), compileSubroutine() and grammar methods that emit VM
  • SymbolTable: define(name,type,kind), varCount(kind), kindOf(name), indexOf(name)
  • VMWriter: writeArithmetic(), writePushPop(), writeCall(), writeReturn()
Keep APIs minimal so unit tests can exercise each module in isolation before full integration.
Key Takeaway

Design clear module contracts and test them individually to simplify debugging and integration.
