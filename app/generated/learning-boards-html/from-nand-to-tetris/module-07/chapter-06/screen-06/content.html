Module 8 › Chapter 7.6 › JackTokenizer responsibilities
Tokenization process
The tokenizer reads characters and emits a deterministic token stream. It must correctly filter comments and preserve string constants. Robust tokenization simplifies parsing and isolates lexical errors early.
Token types
Keywords, identifiers, symbols, integer constants, string constants.
Edge cases
Comments, quoted strings, and adjacent symbols must be handled precisely to avoid mis-tokenization.
Testing tip
Write unit tests that assert token sequences for small source snippets before integrating with the parser.
Practice scenario
Feed the tokenizer a short method declaration and assert that keywords, identifiers, symbols, and constants appear in the expected order. This isolates lexical errors quickly.
Common mistake

Neglecting comment stripping causes later parsing to fail because comment characters can look like symbols or break token boundaries.

Key Takeaway

Validate token sequences with focused unit tests; a correct tokenizer makes parsing reliable.
