Module 8 › Chapter 7.6 › VMWriter
VMWriter responsibilities
Provide a small API to emit all VM command types used by the engine, and guarantee deterministic formatting so the VM translator can convert files to assembly reliably.
API surface
writeArithmetic(), writePushPop(), writeLabel(), writeGoto(), writeIf(), writeFunction(), writeCall(), writeReturn()
Design tip
Mock the writer for early engine tests. Later, implement file I/O and compare emitted VM strings against expected fragments in integration tests.
Practical scenario
Have the CompilationEngine call the writer to produce the VM code for a small function and test the produced file by passing it to the VM translator and verifying the final machine behavior.
Key Takeaway

Design a minimal, testable writer API and validate emitted VM fragments as part of your integration tests.
