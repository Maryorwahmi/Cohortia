Module 8 › Chapter 7.6 › Method List Deep Dive
CompilationEngine methods
compileClass()
Start class parsing and compile class-level declarations and subroutines.
compileSubroutine()
Reset subroutine scope and compile parameters and body, emitting the function signature and local setup code.
compileStatements()
Dispatch to specific statement handlers and stitch the emitted VM fragments together.
Expression & term methods
Manage operator precedence, evaluate subroutine calls, and push intermediate values for higher-level constructs.
compileVarDec() & SymbolTable
Define local variables with correct kinds and indices so the generated VM code references the right segments and offsets.
Work method-by-method and write small tests that check the VM output for each compileX method. This approach isolates logic errors and makes debugging manageable.
