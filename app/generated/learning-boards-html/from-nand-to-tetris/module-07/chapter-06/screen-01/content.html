The Complete Jack Compiler
Assemble tokenizer, parser, symbol table, and VM writer into a translator you can run on real programs.

In this lesson you will implement the four core modules: JackTokenizer, CompilationEngine, SymbolTable, and VMWriter. Those pieces combine to accept a folder of .jack files and emit .vm files that the VM translator can translate into assembly and machine code.

Testing focuses on small unit programs and the supplied suite: Seven, ConvertToBin, Square, Average, Pong, and Tetris. Passing these confirms full language support across classes, methods, arrays, and control flow.
