Concrete requirements

Accept a directory of .jack files and produce a .vm file for each input file. Support all language constructs so programs such as Pong and Tetris run correctly after the full toolchain.

  • Classes, subroutines (methods, functions, constructors)
  • Parameter lists, local variable declarations
  • Statements: let, if, while, do, return
  • Expressions and terms, including subroutine calls and array access

Incremental development strategy: implement minimal functionality, pass Seven, then add expressions, then arrays, then object features, finally full integration with larger tests.

Concrete example
Start by compiling the Seven program. If the output VM yields the expected behavior after translation and assembly, your basic pipeline works and you can add more features.
Common mistake

Skipping early tests and implementing all features at once leads to long debugging cycles. Build and test in small increments.

Key Takeaway

A precise, test-driven checklist keeps the project manageable and ensures progress toward running complex supplied programs.
