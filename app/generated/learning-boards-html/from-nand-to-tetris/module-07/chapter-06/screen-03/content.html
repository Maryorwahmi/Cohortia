Module 8 › Chapter 7.6 › Objectives — Implementation Details
Module responsibilities
JackTokenizer
Produce a clean token stream. Correctly classify keywords, identifiers, symbols, constants and strings so the parser can unambiguously consume input.
CompilationEngine
Implement grammar methods that both parse and emit VM code. The engine must handle classes, subroutines, statements, expressions and terms.
SymbolTable
Maintain class-level and subroutine-level scopes with name, type, kind and index. Indices are essential for consistent memory allocation in generated code.
VMWriter
Serialize VM commands into .vm files. The writer should present a stable API for emitting arithmetic, memory, call and return commands used by the CompilationEngine.
Each module should include unit tests where possible and be exercised by the full-program tests to ensure integration correctness.
