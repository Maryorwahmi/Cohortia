Module 7 › Chapter 7.3 › Parameters & Var Declarations
Parameter list

Can be empty or a comma-separated list of type and name pairs. Implement parse_parameter_list to accept a first parameter when present and then loop for additional parameters separated by commas.

parameterList:
  ( type varName (',' type varName)* )?
Subroutine body

Starts with '{', then zero or more var declarations, a statements block, then '}'. Use parse_var_dec repeatedly then call parse_statements to handle the required statement sequence.

Helper functions

Create expect_type, parse_var_dec, and parse_parameter_list to keep code modular and test each small unit.

Key Takeaway

Optional lists use loops; required sequences like statements must be parsed after locals, and helper functions make the parser readable and testable.
