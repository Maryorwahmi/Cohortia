Module 7 › Chapter 7.3 › Expressions & Terms
Expression pattern
expression:
  term ( op term )*
Operators are binary tokens such as plus, minus, etc. The parser accepts one term, then loops while an operator appears, consuming the next term each time.
Term forms
  • integerConstant, stringConstant, keywordConstant
  • varName or varName '[' expression ']'
  • subroutineCall
  • '(' expression ')' or unaryOp term
Lookahead note
When seeing an identifier, peek at the next token to decide between array access, subroutine call, or simple variable.
Example
x + y * ( z - 1 ) will be parsed as a term, then op term pairs; grouping for precedence is left to later stages in full compilers, but the project uses the grammar's structure.
Key Takeaway

Implement parse_term with careful token inspection and parse_expression by consuming a term then looping over operator-term pairs.
