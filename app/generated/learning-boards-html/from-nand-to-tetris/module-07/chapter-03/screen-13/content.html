Match element order, token wrappers, and text formatting to the reference to pass automated comparisons.
Streaming vs in-memory
Streaming emits tags during parsing and uses less memory. Building a tree first allows more manipulation but requires serialization that matches the reference exactly.
Testing tips
Run the provided test files and diff your XML against the references. Focus on token wrappers and element ordering when resolving differences.
Key Takeaway

Produce XML with the same structure and ordering as the reference; streaming during parsing is natural for recursive descent.
