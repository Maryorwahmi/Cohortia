Learning Objectives

Progress from understanding to verified competence.

Bloom: Learn → Understand → Apply → Master
01
Role of the parser

Explain why the parser organizes tokens into structure and how that structure is used later in compilation.

VERIFIED COMPETENCY MILESTONE
02
Recursive descent parser

Implement grammar rules as functions that call each other and consume tokens deterministically.

VERIFIED COMPETENCY MILESTONE
03
Build the parse tree

Produce a hierarchical tree that mirrors grammar productions and contains tokens where appropriate.

VERIFIED COMPETENCY MILESTONE
04
Emit XML and report errors

Write the tree to XML for automated testing and give helpful syntax error messages with line numbers.

VERIFIED COMPETENCY MILESTONE
