Module 7 › Chapter 7.3 › Subroutine calls & args
Call forms
subroutineName(expressionList) | (className | varName).subroutineName(expressionList). Use lookahead after an identifier to decide whether a '(' or '.' follows.
Example

foo(3, x + 2) → subroutineCall with expressionList [3, x + 2]

Expression list
expressionList:
  ( expression (',' expression)* )?
Allow zero arguments. When parsing, check whether the next token begins an expression; if not, close the call immediately.
Pitfall

For qualified calls, ensure the dot is followed by an identifier; do not assume a dot implies validity without checking the next token.
