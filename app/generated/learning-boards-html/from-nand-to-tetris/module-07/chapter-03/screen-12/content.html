Tree node roles

Internal nodes correspond to grammar productions like letStatement or expression; leaves correspond to tokens such as keywords, identifiers, symbols, integers, and strings.

Why verbose trees?

They preserve every grammatical choice, which makes automated XML comparisons straightforward and educationally valuable.

AST vs parse tree

ASTs simplify by removing punctuation and intermediate nodes. The Nand2Tetris project uses full parse trees because they are easier to generate and test against reference XML.

Key Takeaway

Construct the parse tree so every production and token is represented; this explicitness simplifies testing and learning.
