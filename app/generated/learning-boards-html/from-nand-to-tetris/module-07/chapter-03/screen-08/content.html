Module 7 › Chapter 7.3 › Statements
Let statement
Pattern: let varName ( '[' expression ']' )? '=' expression ';'. Parsing must accept the optional indexing part and then the expression on the right.
If & While
If: 'if' '(' expression ')' '{' statements '}' ( 'else' '{' statements '}' )?. While: 'while' '(' expression ')' '{' statements '}'. Note the optional else block for if.
Do & Return
Do: a subroutine call followed by ';'. Return: 'return' expression? ';'. Ensure the optional expression is handled correctly.
Example body
Consider a body with a let, an if with else, and a return. The parser will call parse_let_statement, parse_if_statement, and parse_return_statement in sequence while building subtrees for each.
Common pitfall
Missing semicolons or mis-parsed optional segments can shift subsequent parsing and cause cascading errors. Report the original location when possible.
Key Takeaway

Dispatch on the initial keyword, then handle each statement's specific optional pieces carefully to avoid downstream errors.
