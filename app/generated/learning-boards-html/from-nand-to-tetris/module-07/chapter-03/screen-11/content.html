Helper expectations
def expect_keyword(kw):
  if current_token == kw: advance()
  else: error("expected keyword", line)

def expect_symbol(sym):
  if current_token == sym: advance()
  else: error("expected symbol", line)
Centralizing token checks produces consistent error messages and keeps parsing functions focused on grammar structure.
Lookahead example
When parse_term sees an identifier, peek at the next token: '[' means array access, '(' or '.' means a call, otherwise it's a variable. This tiny lookahead resolves ambiguity without backtracking.
Misconception
Don't add backtracking to handle conflicts. If the grammar is LL(1) and you use lookahead correctly, the parser remains simple and deterministic.
Key Takeaway

Implement grammar rules as focused functions, centralize expectations, and use small lookahead to disambiguate forms without backtracking.
