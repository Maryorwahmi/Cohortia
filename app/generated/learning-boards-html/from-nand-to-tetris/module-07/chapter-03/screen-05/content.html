Context-free grammar

A set of rules where nonterminals expand into terminals and other nonterminals. Jack's grammar is written as clear productions that a recursive descent parser can implement directly.

Selected productions
  • class: class ClassName { classVarDec* subroutineDec* }
  • subroutine declaration: constructor|function|method void|type name ( parameterList ) subroutineBody
  • statement: let | if | while | do | return
Analogy

Think of grammar as the librarian's classification system: categories, subcategories, then items.

Why LL(1) matters

An LL(1) grammar lets the parser pick a single rule by looking at the next token. This determinism makes recursive descent simple to implement and reason about.

Misconception

Not every grammar fits recursive descent. If multiple rules could match the same token sequence without more lookahead, you would need a different technique.
