Module 7 › Chapter 7.3 › What is a parser
Definition
A parser organizes a stream of tokens into a tree that follows the grammar's productions so the compiler can reason about program structure.
Why it matters
  • Provides a clear structure for later stages of the compiler.
  • Makes automated testing possible via XML output.
  • Separates lexical concerns from syntactic structure for clarity.
Concrete example
Tokens for "let x = 5 ;" produce a letStatement node with children for keyword, identifier, symbol, expression, and symbol.
Parse tree snapshot
<letStatement>
  <keyword> let </keyword>
  <identifier> x </identifier>
  <symbol> = </symbol>
  <expression>
    <term>
      <integerConstant> 5 </integerConstant>
    </term>
  </expression>
  <symbol> ; </symbol>
</letStatement>
Misconception
The parser is not just a validator. It produces the structure that later passes directly into code generation or further transformation.
Key Takeaway

Parsing converts flat tokens into a structural tree that preserves every grammar decision for testing and learning.
