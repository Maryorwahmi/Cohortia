Module 7 › Chapter 7.3 › Objectives — What success looks like

Verification checklist

Use these checks against the reference XML and test files supplied by the project.

Parser acceptance

All valid Jack constructs are parsed; no silent failures or infinite loops.

XML match

Structure and tokens line up with the reference XML files.

Error reporting

Clear messages and line numbers for syntax errors.

Readable code

Each grammar rule maps to a function with clear preconditions and postconditions.
