parse_class (concept)
def parse_class():
  expect_keyword('class')
  class_name = expect_identifier()
  expect_symbol('{')
  while current_token in ['static', 'field']:
    parse_class_var_dec()
  while current_token in ['constructor', 'function', 'method']:
    parse_subroutine_dec()
  expect_symbol('}')
This code pattern — expect, loop for optional repeats, parse subrules, expect close — is the backbone of top-level parsing.
classVarDec pattern
Kind (static|field), type, one or more variable names separated by commas, semicolon. Implement by parsing the kind, then the type, then a loop for comma-separated identifiers, then expect ';'.
Common mistake
Treating a repeated group as required. Remember the star '*' in the grammar means zero or more occurrences.
Key Takeaway

Map each grammar production to a function and handle repetition by looping while the next token indicates the repeated production.
