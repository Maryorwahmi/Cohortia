Task 1 — Responsive panel
Create MainPanel centered with Size = UDim2.new(0.9,0,0.7,0) and AnchorPoint = Vector2.new(0.5,0.5). Add a TitleLabel with TextScaled enabled.
Why
This ensures the panel scales on phones and desktops without clipping or misalignment.
Task 2 — Animated health bar
Animate HealthBarFill.Size.X.Scale to the new health percentage using TweenService with TweenInfo duration ~0.5s and easing Quad Out for smooth feedback.
Validation
Ensure the server authoritatively updates health to prevent client spoofing and that client-side animation responds to server confirmations or rejections.
Grading checklist

Panel is centered at various sizes, TitleLabel uses TextScaled, health bar animates smoothly, and server validation protects game state. Include a clear UI message when an action is rejected by the server.
