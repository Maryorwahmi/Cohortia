Module 4 › Chapter 4.2 › UIListLayout
Use case: shop inventory
UIListLayout arranges list entries for scrolling content. Combine with a hidden item template you clone at runtime.
Checklist
  • Place UIListLayout inside a ScrollingFrame.
  • Set Padding to control gaps between items.
  • Use a hidden ItemTemplate and clone it for each item.
  • Set Width with Scale so items adapt horizontally.
Concrete snippet
-- Clone an item template and populate
local newItem = itemTemplate:Clone()
newItem.Name = itemData.Name
newItem.Visible = true
newItem.Parent = itemScrollFrame
newItem.ItemIcon.Image = itemData.Icon
newItem.ItemName.Text = itemData.Name .. " (" .. itemData.Price .. " Coins)"
Pitfall
Don’t expect UIListLayout to control child sizes. It sets position order and spacing; set child Size with Scale for responsiveness.
