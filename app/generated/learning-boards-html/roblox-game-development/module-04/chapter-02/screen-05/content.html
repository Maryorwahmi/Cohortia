Module 4 › Chapter 4.2 › Scale vs Offset
Scale (responsive)
Scale is a fraction of the parent's size. Use it for widths, heights and positions that must adapt.
Example
UDim2.new(0.8, 0, 0.6, 0) — 80% width, 60% height of the parent. Combine with AnchorPoint for centering.
Tip
Use Offset only for small spacing like borders or padding. Large offsets break responsiveness.
Offset (fixed)
Offset is pixel-based. It’s useful for precise padding or when you need a fixed gap regardless of screen size.
Misuse example
Using UDim2.new(500, 0, 300, 0) will appear fine on one screen but may overflow on small devices.
Quick check
If you resize your game window and elements move unpredictably, check for Offset values used for primary sizes or positions.
AnchorPoint example
To center: set Size = UDim2.new(0.9, 0, 0.7, 0), Position = UDim2.new(0.5, 0, 0.5, 0), AnchorPoint = Vector2.new(0.5, 0.5).
