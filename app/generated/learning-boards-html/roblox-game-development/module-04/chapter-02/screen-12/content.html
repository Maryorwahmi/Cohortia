Module 4 › Chapter 4.2 › Common Mistakes
1. Using Offset for layout
Convert to Scale for primary sizes and positions to avoid breakage on different devices.
2. Ignoring AnchorPoint
AnchorPoint defines the origin for Position. Use center anchors for centered panels to keep them stable.
3. Poor readability
Enable TextScaled and test colors and contrast. Keep tap targets large.
4. No feedback
Give visual or auditory feedback on interaction. Use TweenService for subtle motion.
5. Client-only game logic
Validate purchases and state changes on the server using RemoteEvents or RemoteFunctions.
6. Overlapping UI
Use UIListLayout or UIGridLayout to keep children arranged and avoid manual positioning errors.
Action plan

When testing, emulate narrow screens, check text scaling, verify tap targets, and ensure server-side validation is implemented for all critical actions.
