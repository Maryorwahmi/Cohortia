Module 4 › Chapter 4.2 › Key Concepts
ScreenGui & Elements
ScreenGui holds per-player UI; use Frames, TextLabels, and Buttons as building blocks.
Scale & AnchorPoint
Use Scale for responsive sizes and AnchorPoint to control alignment origins.
Layout Containers
UIListLayout, UIGridLayout, and UIPageLayout automate child arrangement for consistency.
TextScaled & Aspect
Keep text legible and icons undistorted as elements resize.
TweenService
Animate properties with TweenInfo to add polish and feedback.
Server Validation
Protect game state by validating critical actions on the server using RemoteEvents.
Takeaway

Responsive sizing, clear feedback, and server-side checks make UIs both pleasant and secure for players.
