Learning Objectives
Progress from concept to lab-ready skills
Bloom: Learn → Understand → Apply → Master
01
Responsive UI design
Use ScreenGui, Frames and UDim2 Scale to make interfaces adapt to different screens. Learn to center and size panels so they stay consistent.
VERIFIED COMPETENCY MILESTONE
02
Interactive scripting
Connect UI events like MouseButton1Click and FocusLost, and use RemoteEvents for server-side actions to avoid client-only exploits.
VERIFIED COMPETENCY MILESTONE
03
Tweened animation
Use TweenService with TweenInfo to create smooth entrance and feedback animations. Choose duration and easing to match gameplay pacing.
VERIFIED COMPETENCY MILESTONE
04
Readability & scaling
Apply TextScaled and UIAspectRatioConstraint to avoid distorted or unreadable elements. Fix common layout mistakes and test across devices.
VERIFIED COMPETENCY MILESTONE
