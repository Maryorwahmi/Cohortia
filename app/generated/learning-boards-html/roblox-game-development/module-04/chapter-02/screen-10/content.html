LocalScripts for UI
LocalScripts handle immediate UI response: cloning templates, updating labels, animating elements, and firing events to the server.
Event example
buyButton.MouseButton1Click:Connect(function() BuyItemEvent:FireServer(itemName) end)
Server-side validation
Check currency and inventory on the server and apply changes there. The server is authoritative and prevents client exploitation.
Danger
Updating game state only on the client can be exploited. Always validate purchases on the server.
UX pattern
Show a temporary loading state or animation after a purchase click. If the server rejects the request, revert the UI and show a clear reason so the player is not confused.
