Slide-in example
Set the frame's start Position off-screen, then tween to the center. Use easing for a polished feel.
local TweenService = game:GetService("TweenService")

local function slideInFrame(frame)
    frame.Position = UDim2.new(0.5, 0, -0.5, 0) -- start off-screen above
    frame.Visible = true

    local tweenInfo = TweenInfo.new(
        1, -- duration seconds
        Enum.EasingStyle.Quint,
        Enum.EasingDirection.Out
    )

    local target = { Position = UDim2.new(0.5, 0, 0.5, 0) }
    local tween = TweenService:Create(frame, tweenInfo, target)
    tween:Play()
end
Hover feedback
Use a short tween for hover, e.g., 0.12 seconds with EasingStyle.Quad and EasingDirection.Out so the button feels snappy.
Pro tip
Keep motion purposeful: entrance and meaningful feedback are worth animating; repetitive or decorative motion can distract players.
