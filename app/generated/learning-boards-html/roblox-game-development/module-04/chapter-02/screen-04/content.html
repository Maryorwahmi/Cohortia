Module 4 › Chapter 4.2 › ScreenGui and UI elements
What a ScreenGui does
A ScreenGui contains UI for a single player. It is copied into PlayerGui when a player joins, keeping UI instances private.
Frame
Group elements and create backgrounds for panels.
TextLabel
Display static, readable text with TextScaled option.
TextButton
A clickable label that fires events on the client.
Example pattern
Create a centered MainFrame inside ScreenGui, put a TitleLabel at the top and a close TextButton anchored to the top-right. This pattern isolates a single panel you can show or hide with animation.
Concrete example
local screenGui = Instance.new("ScreenGui")
screenGui.Name = "ResponsiveUI"
screenGui.Parent = player:WaitForChild("PlayerGui")

local mainFrame = Instance.new("Frame")
mainFrame.Name = "MainFrame"
mainFrame.Size = UDim2.new(0.8, 0, 0.6, 0)
mainFrame.Position = UDim2.new(0.5, 0, 0.5, 0)
mainFrame.AnchorPoint = Vector2.new(0.5, 0.5)
mainFrame.Parent = screenGui
Common misconception
UI in StarterGui is global. It is not — each player receives a private copy in PlayerGui, so treat UI state as player-local unless you explicitly communicate with the server.
Key takeaway
Design UI as local, composable panels and avoid mixing client UI state with server game state.
