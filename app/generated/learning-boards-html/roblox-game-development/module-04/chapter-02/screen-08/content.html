Module 4 › Chapter 4.2 › TextScaled & Aspect Ratio
TextScaled
Automatically scale fonts to fit the control’s bounds. Useful for buttons and labels whose text changes or when controls resize.
Note
TextScaled does not remove the need for good padding and line-height; set those for readable results.
UIAspectRatioConstraint
Keeps an element's width-to-height ratio fixed. Use it to keep icons square or prevent banner image distortion.
Example
Set AspectRatio = 1 to keep an icon square as its parent resizes. Combine with Scale-based sizing for adaptive grids.
Key Takeaway

TextScaled and UIAspectRatioConstraint preserve legibility and shape. Use them as part of overall layout decisions, not as fixes for bad spacing.
