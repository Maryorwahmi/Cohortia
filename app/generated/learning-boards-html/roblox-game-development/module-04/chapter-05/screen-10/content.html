Common Mistakes
Debugging OOP mistakes in Lua
A focused checklist to resolve runtime issues.
Step-by-step Checks
  1. Confirm class.__index = class is set.
  2. Confirm constructor uses setmetatable(instance, class) and returns instance.
  3. Ensure methods needing instance state use colon in definition and call.
  4. Keep class and module local, return the class, and require it cleanly.
  5. When testing, confirm instance exists before invoking methods after waits.
Debugging tip
Add short print statements in the constructor and method entry to verify order of operations and parameter values. For example, print the instance name and current health at constructor return and at method start.
Misconception
Programs that crash at runtime are not always caused by complex logic; often a missing return or misapplied metatable is the culprit.
Common Error

Attempt to call a nil value usually means methods aren't linked. Check __index and setmetatable first.
