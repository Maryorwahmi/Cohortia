Core Concept
What is OOP and why use it in Roblox?
Encapsulation, abstraction, inheritance, and reusability for game entities.
Definition
OOP treats game elements as objects that bundle data and behavior so you can manage complexity as the project grows.
Key benefits
  • Modularity: related code lives together.
  • Reusability: instantiate many objects from a single blueprint.
  • Maintainability: change a method once to affect all instances.
Key Takeaway

Model repeated game entities as objects so you write less code and reduce bugs when features change.

Analogy & Example
Think of a class as a cookie cutter and objects as cookies. The cutter defines shape and features; each cookie holds its own frosting and size. For a game, a class defines default health and methods like take damage, while each enemy has its own current health.
Class (table)

Instance
