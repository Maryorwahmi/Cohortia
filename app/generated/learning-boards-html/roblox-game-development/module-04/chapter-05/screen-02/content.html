Learning Objectives
Skills you'll practice and why they matter
01
Explain core OOP principles
Describe encapsulation, abstraction, inheritance, and polymorphism and why they reduce complexity in game code.
Mnemonic: cookie cutter and cookies — class as a cutter, objects as cookies.
VERIFIED COMPETENCY MILESTONE
02
Build classes with tables and metatables
Create a class table, set __index, and use setmetatable to link instances so methods are shared.
Mnemonic: prototype chain as a lookup path.
VERIFIED COMPETENCY MILESTONE
03
Implement constructors and methods
Write a new function that initializes properties, uses setmetatable, and exposes methods using the colon syntax.
Mnemonic: new as a factory stamp.
VERIFIED COMPETENCY MILESTONE
04
Apply OOP in game systems
Use ModuleScripts for entities and a GameManager to create, store, and clean up instances for players and NPCs.
Mnemonic: registry map for active instances.
