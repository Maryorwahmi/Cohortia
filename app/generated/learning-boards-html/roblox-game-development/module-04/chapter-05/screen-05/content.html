Definition
Tables as classes and metatables as inheritance
Using __index and setmetatable to link instances to blueprints.
Pattern Overview
  1. Define a class table to hold methods and defaults.
  2. Set class.__index = class so lookups fallback to it.
  3. In the constructor, call setmetatable(instance, class) to link instance to class.
  4. Return the instance so callers can use instance:method()
Misconception check
If methods are nil on your instance, verify that __index assignment and setmetatable are present and that your constructor returns the instance table.
