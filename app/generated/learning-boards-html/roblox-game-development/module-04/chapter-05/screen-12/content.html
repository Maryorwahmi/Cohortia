What to Remember
Key Concepts
Three short cards you can recall while coding.
Class & Instance
Class tables hold methods and defaults; instances hold per-object state and link back via metatable.
Colon & self
Define and call methods with colon so the instance is passed automatically as self.
Lifecycle & Registry
Keep a registry of active instances and remove them on player leave to manage memory and behavior predictably.
Summary
These patterns let you design scalable, maintainable game systems with clear rules for ownership, behavior, and cleanup.
