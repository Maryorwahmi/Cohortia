Constructor pattern and an Enemy example
ModuleScript layout that you can reuse for many entities.
Enemy.lua (ModuleScript)
local Enemy = {} -- This table represents our 'class'
Enemy.__index = Enemy

function Enemy.new(name, health, damage)
  local self = setmetatable({}, Enemy)
  self.Name = name or "Goblin"
  self.Health = health or 100
  self.MaxHealth = self.Health
  self.Damage = damage or 10
  self.IsAlive = true
  print(self.Name .. " has spawned with " .. self.Health .. " health.")
  return self
end

function Enemy:TakeDamage(amount)
  if not self.IsAlive then return end
  self.Health = self.Health - amount
  print(self.Name .. " took " .. amount .. " damage. Health: " .. self.Health .. "/" .. self.MaxHealth)
  if self.Health <= 0 then
    self:Die()
  end
end

function Enemy:Die()
  if not self.IsAlive then return end
  self.IsAlive = false
  self.Health = 0
  print(self.Name .. " has been defeated!")
end

function Enemy:Heal(amount)
  if not self.IsAlive then return end
  self.Health = math.min(self.MaxHealth, self.Health + amount)
  print(self.Name .. " healed " .. amount .. ". Health: " .. self.Health .. "/" .. self.MaxHealth)
end

return Enemy
Explanation & Walkthrough
  • Enemy.__index = Enemy connects missing key lookups to the class table.
  • Enemy.new creates an instance, sets its metatable, initializes fields, and prints spawn info.
  • Methods use colon syntax so self refers to the instance automatically.
  • Heal uses math.min to cap health at MaxHealth, preventing overflow.
Concrete example
Creating two enemies from this module gives two tables with separate Health values but a shared TakeDamage method, so adjusting TakeDamage updates behavior across all enemies.
Key Takeaway

Follow the constructor pattern: setmetatable, initialize fields, return the instance so methods are usable.
