Common Mistakes Troubleshooting
Top causes of missing grants
  • Returning PurchaseGranted before DataStore persistence.
  • Not handling offline players during ProcessReceipt.
  • Not wrapping DataStore calls with pcall.
  • Failing to record PurchaseIds for idempotency.
Debugging checklist
  1. Log receiptInfo.PurchaseId and ProductId when ProcessReceipt runs.
  2. Check processed receipts DataStore for that PurchaseId.
  3. Re-run test purchases and observe retry behavior.
  4. Fix code to pcall and persist before returning PurchaseGranted.
