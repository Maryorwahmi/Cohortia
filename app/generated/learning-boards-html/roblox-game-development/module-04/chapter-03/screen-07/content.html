MarketplaceService.ProcessReceipt = function(receiptInfo)
  local player = Players:GetPlayerByUserId(receiptInfo.PlayerId)
  if not player then
    -- Save receipt for later and ask Roblox to retry
    return Enum.ProductPurchaseDecision.NotProcessedYet
  end

      -- Persist coins using your DataStore add function
      -- addCoins(player, amountToAdd)
    end)

    if success then
      return Enum.ProductPurchaseDecision.PurchaseGranted
    else
      return Enum.ProductPurchaseDecision.NotProcessedYet
    end
  end

  return Enum.ProductPurchaseDecision.NotProcessedYet
end
Annotations and best practices
  • Check player presence: if offline, save receipt and return NotProcessedYet.
  • Wrap DataStore operations in pcall to avoid unhandled errors.
  • Record processed PurchaseIds to guarantee idempotency.
  • Return PurchaseGranted only when persistent state has been updated.
Common mistake
Granting items in memory without persisting, then returning PurchaseGranted, leads to lost items on server restart.
Key Takeaway

Process receipts on the server, persist grants atomically, and return PurchaseGranted only after persistence succeeds.
