Core Concept Developer Products vs Game Passes
Quick comparison
Use this reference when designing store items.
Developer Product
Consumable, multiple purchases allowed. Processed via ProcessReceipt and requires server granting.
Game Pass
Non-consumable, owned once. Check ownership with UserOwnsGamePassAsync on the server.
Concrete example
Selling a "500 Coins" item: Developer Product. Selling "VIP Room Access": Game Pass.
Common mistake
Selling a temporary boost as a Game Pass because it's easier to check; this prevents repeat purchases and breaks expected player behavior.
Decision flow
Ask two questions: Is this benefit permanent? If yes, create a Game Pass. Is it repeatable or time-limited? If yes, create a Developer Product.
Checklist before release
  • Confirm item permanence and intended repeat purchases.
  • Create item in Creator Dashboard and copy ID.
  • Implement server-side checks and granting logic.
Key Takeaway

Match item type to player expectations: consumables are repeatable; passes are permanent. This prevents design and support issues later.
