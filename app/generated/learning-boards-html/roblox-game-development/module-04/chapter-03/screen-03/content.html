Objective 1: Creator Dashboard setup
Create Developer Products and Game Passes, set prices, and copy their IDs. These numeric IDs are required in your server scripts to reference items safely.

Objective 2: Server-side prompting
Implement RemoteEvents and a ShopHandler server script that calls MarketplaceService:PromptProductPurchase and PromptGamePassPurchase as appropriate.
VERIFIED COMPETENCY MILESTONE
Objective 3: Receipt processing
Implement MarketplaceService.ProcessReceipt to validate receipts, grant items via DataStore-safe functions, and return PurchaseGranted when done.
VERIFIED COMPETENCY MILESTONE
Objective 4: Testing & idempotency
Record PurchaseIds and use pcall around DataStore calls so repeated ProcessReceipt calls do not duplicate grants and failures trigger retries.
