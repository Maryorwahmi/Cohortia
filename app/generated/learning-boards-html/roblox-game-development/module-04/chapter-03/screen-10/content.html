Security Server-side Validation
Server-side checks
  • Validate incoming itemId against an allowlist of product IDs.
  • Use pcall for DataStore writes inside ProcessReceipt.
  • Record PurchaseIds to avoid duplicate grants.
Practical example: allowlist
local ALLOWED_PRODUCTS = { [123456789] = true }
if not ALLOWED_PRODUCTS[itemId] then
  warn("Attempt to purchase unknown product: " .. tostring(itemId))
  return
end
MarketplaceService:PromptProductPurchase(player, itemId)
This stops clients from asking to purchase arbitrary product IDs you didn't create or intend to sell.
