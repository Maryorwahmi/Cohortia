Definition Prompting Purchases
Server-side listener pattern
local MarketplaceService = game:GetService("MarketplaceService")
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local RequestPurchaseEvent = ReplicatedStorage:WaitForChild("RequestPurchaseEvent")

RequestPurchaseEvent.OnServerEvent:Connect(function(player, itemId, itemType)
  if itemType == "Product" then
    MarketplaceService:PromptProductPurchase(player, itemId)
  elseif itemType == "GamePass" then
    MarketplaceService:PromptGamePassPurchase(player, itemId)
  else
    warn("Invalid itemType requested: " .. tostring(itemType))
  end
end)
This pattern validates itemType server-side and calls the correct Prompt method for the player. Using a RemoteEvent lets the client request the prompt while keeping the server authoritative.
Example scenario
Player clicks "Buy 500 Coins" → LocalScript fires RequestPurchaseEvent with itemId and "Product" → Server receives it and calls PromptProductPurchase for that player.
Misconception
Do not call prompt functions from the client or trust the client to authorize purchases; the server must be authoritative.
Key Takeaway

Route purchase requests through the server and call MarketplaceService prompt methods there to keep purchase initiation secure.
