Process Flow Creator Dashboard Setup
Step-by-step
1. Create Developer Product or Game Pass
Enter name, description, and price.
2. Copy the numeric ID
Store it in a server script constant like COINS_PRODUCT_ID or VIP_GAMEPASS_ID.
3. Document and test
Verify IDs in a test environment before releasing.
Mnemonic
Think of the ID as the SKU: the dashboard assigns it and your server uses it as the authoritative reference.
Common pitfalls and checks
  • Don't hardcode IDs on the client; keep them on the server to avoid tampering.
  • Ensure the ID matches the intended environment (staging vs production).
  • Give descriptive names and document expected behavior for each item.
Example constant (server)
local COINS_PRODUCT_ID = 123456789 -- Developer Product ID for 500 coins
local VIP_GAMEPASS_ID = 987654321 -- Game Pass ID for VIP Access
Key Takeaway

Always copy the numeric ID from the Creator Dashboard and store it as a server constant; this keeps purchases consistent and secure.
