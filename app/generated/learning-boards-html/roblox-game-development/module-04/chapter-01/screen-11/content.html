Client UI

A simple ScreenGui with a CoinCountLabel and EarnCoinsButton. The client fires AddCoinsEvent to request coins; the server responds with updated totals.

Common mistake

Saving from LocalScripts or trusting client-provided values for authoritative state. Always validate and save on the server.

Key Takeaway

Wire server and client via RemoteEvent. Server remains authoritative for persistence and sends updates to the client UI.
