Module 4 › Chapter 4.1 › Get DataStoreService
Code
local DataStoreService = game:GetService("DataStoreService")
local playerDataStore = DataStoreService:GetDataStore("PlayerCoins")

-- Use playerDataStore for GetAsync, SetAsync, UpdateAsync
Why this matters

Getting a named DataStore gives you a stable handle for all persistent operations. Names separate concerns and avoid accidental collisions.

Example

Use "PlayerCoins" for currency and a different store like "PlayerInventory" for items. This keeps saves small and focused.

Common mistake

Calling GetDataStore from a LocalScript. The DataStore API is server-side only and must run in a Script under ServerScriptService.

Key Takeaway

Initialize DataStoreService on the server and choose clear DataStore names to organize saved data.
