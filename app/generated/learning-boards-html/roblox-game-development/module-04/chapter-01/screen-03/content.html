Module 4 › Chapter 4.1 › Learning Objectives
Outcome

Save & verify in server logs

You will produce server messages confirming loads and saves. Use these logs to validate default data and successful writes.

Check

Test UpdateAsync under load

Simulate concurrent updates. Confirm that an atomic transform keeps both increments instead of one overwriting the other.

Practice

Implement a coin system

Follow the hands-on activity: server coin handler, RemoteEvent for earn requests, and a simple client UI to fire events.

Safety

Wrap calls in pcall

On failure, log the error and retry with exponential or fixed backoff. Avoid blind SetAsync writes per event.
