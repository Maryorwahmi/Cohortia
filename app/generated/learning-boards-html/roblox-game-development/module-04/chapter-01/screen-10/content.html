Serializable inventory example
-- Good: IDs and counts
local inventory = {
  sword_01 = 1,
  potion_small = 5,
}

-- Bad: Roblox objects or functions cannot be saved
local badInventory = {
  slot1 = workspace.SomeItem, -- not serializable
  onUse = function() end,     -- not serializable
}
Keep payloads compact. Normalizing data makes updates and storage cheap and reliable.
Practical tip

Store references (IDs) rather than full object data. Reconstruct objects at runtime from ID definitions.

Misconception

Assuming complex tables with metatables or userdata serialize correctly. They do not; keep it primitive.

Key Takeaway

Design a compact, serializable schema and document it so transforms remain simple and safe.
