Module 4 › Chapter 4.1 › Key Concepts
Data Persistence
Save and restore player progress so players keep their rewards across sessions.
DataStoreService
Roblox’s server-side API for saving and loading cloud data; call from server scripts only.
UpdateAsync
Atomic updates via a transform function to prevent race conditions during concurrent writes.
Summary Takeaway
Always design for server-side saving, small serializable payloads, and defensive error handling. Prefer atomic transforms for updates and cache during play.
