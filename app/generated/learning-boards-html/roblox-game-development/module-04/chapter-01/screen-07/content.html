Atomic update example
local function addCoins(player, amount)
  local success, newCoins = pcall(function()
    return playerDataStore:UpdateAsync(player.UserId, function(oldData)
      local data = oldData or {Coins = 0, Level = 1, Inventory = {}}
      data.Coins = (data.Coins or 0) + amount
      return data
    end)
  end)

  if success then
    print(player.Name .. " now has " .. newCoins.Coins .. " coins.")
    playerCache[player.UserId] = newCoins
  else
    warn("Error adding coins for " .. player.Name .. ": " .. newCoins)
  end
end
Concrete scenario

Two servers both call addCoins at the same time. UpdateAsync ensures both increments apply instead of one overwriting the other.

Misconception

UpdateAsync removes need for error handling. You still must wrap it in pcall and handle failures or service limits.

Key Takeaway

Use UpdateAsync for safe modifications; design transform functions to return full, serializable tables.
