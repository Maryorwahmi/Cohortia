Server cache example
local playerCoinCache = {}
local DATA_SAVE_INTERVAL = 60 -- seconds

Players.PlayerAdded:Connect(function(player)
  local data = getPlayerData(player)
  playerCoinCache[player.UserId] = data
end)

Players.PlayerRemoving:Connect(function(player)
  local coinsToSave = playerCoinCache[player.UserId]
  if coinsToSave ~= nil then
    savePlayerCoins(player, coinsToSave)
  end
  playerCoinCache[player.UserId] = nil
end)
Why batching helps

Fewer DataStore calls reduce the chance of hitting request budgets and improve overall game stability.

Design note

Store concise data. For large inventories, record item IDs and counts instead of full item objects to stay under size limits.

Key Takeaway

Use a server-side cache and periodic saves to balance durability with DataStore limits.
