Module 4 › Chapter 4.1 › GetAsync
Function example
local function getPlayerData(player)
  local success, data = pcall(function()
    return playerDataStore:GetAsync(player.UserId)
  end)

  if success then
    if data then
      print("Loaded data for " .. player.Name)
      return data
    else
      print("No data found for " .. player.Name .. ", creating new.")
      return { Coins = 100, Level = 1, Inventory = {} }
    end
  else
    warn("Error loading data for " .. player.Name .. ": " .. data)
    return { Coins = 100, Level = 1, Inventory = {} }
  end
end
Concrete example

Return a default table when no data exists so the rest of your game code can assume fields exist and avoid runtime errors.

Misconception

Nil always means error. In reality nil often means the key has never been saved and you should initialize defaults, not crash.

Key Takeaway

Differentiate between 'no data' and 'call failure'. Initialize defaults for new players and log errors when pcall fails.
