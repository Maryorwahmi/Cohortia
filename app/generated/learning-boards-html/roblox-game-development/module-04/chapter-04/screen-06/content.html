Comparison

CFrame vs Position + Orientation

CFrame keeps translation and rotation together for coherent transforms.

Tweens on Position + Orientation
  • Can lead to unsynchronized updates between translation and rotation.
  • May produce unnatural motion when both properties change simultaneously.
  • Separate tweens can end up fighting if timing differs slightly.
Tweens on CFrame
  • Provides a single target for both position and rotation.
  • Produces coherent, smooth transforms and predictable easing behavior.
  • Prefer explicit target CFrames for looping to avoid drift.
Example target: CFrame.new(part.Position + Vector3.new(0,5,10)) * CFrame.Angles(0, math.rad(90), 0) — this combines translation and rotation into one target value.
