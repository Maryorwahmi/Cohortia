Core Concept

What is Tweening?

Interpolation of properties so objects move and change smoothly.

Concept cards
  • Interpolation: generating intermediate values between start and target.
  • TweenService automates interpolation, removing manual frame updates.
  • Not all properties can be tweened; change non-tweenables directly before/after.
Example
Move a part from A to B over two seconds using a tween instead of a loop. The result is smooth and CPU-friendly.
Key Takeaway

Use TweenService to reduce complexity and get engine-optimized interpolation rather than manual updates.

Analogy

Think of tweening like telling a camera to move from point A to point B; the system figures out every frame between, so you only specify the end state and how it should feel.

Common mistake
Tweens fighting: starting multiple tweens on the same property without cancelling the previous can cause unpredictable behavior. Cancel or wait for completion before creating a new tween on the same property.
