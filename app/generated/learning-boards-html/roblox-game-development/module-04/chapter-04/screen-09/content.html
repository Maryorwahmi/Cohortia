Rotating Door Controller

Toggle door open/closed using target CFrames and a ClickDetector.

Starter Script (ServerScriptService/DoorController)
local TweenService = game:GetService("TweenService")
local Door = workspace:WaitForChild("Door")
local ClickDetector = Door:WaitForChild("ClickDetector")

Door.Anchored = true
Door.CanCollide = true

local isDoorOpen = false
local openRotationAngle = math.rad(90)

local closedCFrame = Door.CFrame
local openCFrame = closedCFrame * CFrame.Angles(0, openRotationAngle, 0)

local tweenInfo = TweenInfo.new(1, Enum.EasingStyle.Quad, Enum.EasingDirection.Out)

ClickDetector.MouseClick:Connect(function()
    ClickDetector.MaxActivationDistance = 0
    local targetCFrame = isDoorOpen and closedCFrame or openCFrame
    local tween = TweenService:Create(Door, tweenInfo, {CFrame = targetCFrame})
    tween:Play()
    tween.Completed:Wait()
    isDoorOpen = not isDoorOpen
    ClickDetector.MaxActivationDistance = 32
end)

print("DoorController loaded.")
Notes & Pitfalls
  • Compute open and closed CFrames once from the initial state to avoid cumulative rotation errors.
  • Temporarily disable the ClickDetector during animation to prevent spam and state conflicts.
  • Use server-side code for doors that affect gameplay; clients cannot enforce authoritative physics or collisions.
If your door pivot is different, adjust the CFrame multiplication to rotate around the correct hinge by translating, rotating, and translating back as needed.
