Moving Platform Implementation

Two tweens alternate to shuttle an anchored platform between two waypoints.

Starter Script (ServerScriptService/PlatformMover)
local TweenService = game:GetService("TweenService")
local MovingPlatform = workspace:WaitForChild("MovingPlatform")
local Waypoint1 = workspace:WaitForChild("Waypoint1")
local Waypoint2 = workspace:WaitForChild("Waypoint2")

MovingPlatform.Anchored = true
MovingPlatform.CanCollide = true

Waypoint1.Transparency = 1
Waypoint1.CanCollide = false
Waypoint2.Transparency = 1
Waypoint2.CanCollide = false

local tweenInfo = TweenInfo.new(
    3,
    Enum.EasingStyle.Sine,
    Enum.EasingDirection.InOut,
    0,
    false,
    0
)

local tweenToWaypoint2 = TweenService:Create(MovingPlatform, tweenInfo, {CFrame = Waypoint2.CFrame})
local tweenToWaypoint1 = TweenService:Create(MovingPlatform, tweenInfo, {CFrame = Waypoint1.CFrame})

local function startTween(tween)
    tween:Play()
    tween.Completed:Wait()
end

while true do
    startTween(tweenToWaypoint2)
    startTween(tweenToWaypoint1)
    task.wait(0.1)
end
Explanation
  • Two explicit tweens prevent drift and make the loop precise.
  • Make Waypoints invisible and non-collidable to avoid interference with players.
  • Run on the server so the platform's motion is authoritative across clients.
Try this
Adjust tween duration and easing to change the platform's feel. Test with players standing on the platform to ensure collision and anchoring are correct.
