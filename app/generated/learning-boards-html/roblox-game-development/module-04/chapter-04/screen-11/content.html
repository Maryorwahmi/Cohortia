Client vs Server Decisions

Authority matters: choose server for gameplay-critical tweens and client for visual-only effects.

Server-side responsibilities
  • Platform movement players stand on
  • Door states that gate player access
  • Synchronized transforms that affect gameplay
Client-side responsibilities
  • Particle and UI fades
  • Local trails, glows, and cosmetic scaling
  • Distributed visual effects to reduce server CPU
Pattern: server sends a small event confirming authoritative motion; clients play extra cosmetic tweens in response for better visual richness without affecting game rules.
