TweenInfo Parameters

Duration, easing style and direction, repeats, reversing, and delay shape how motions feel.

Parameter cards
time: number of seconds for the tween.
easingStyle: Linear, Sine, Quad, Cubic, Quint, Elastic, Bounce; pick for motion character.
easingDirection: In, Out, InOut — controls where easing applies.
repeatCount: 0 for no repeats, -1 for infinite loops, or a positive count.
reverses: true to auto-play backwards; convenient but can accumulate drift over many cycles.
delayTime: wait before the tween starts; useful for staging multiple animations.
Concrete example
A platform uses TweenInfo.new(3, Enum.EasingStyle.Sine, Enum.EasingDirection.InOut, -1, true, 0) to shuttle smoothly. If you notice drift after many cycles, replace reversing with two explicit tweens and alternate them in code.
Check
  • Does the easing style match the intended motion?
  • Will reversing accumulate floating-point error over time?
  • Should this be server-driven for all players to see it consistently?
