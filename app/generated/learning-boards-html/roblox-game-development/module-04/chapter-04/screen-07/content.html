Basic Tween Example

A complete tween that moves, recolors, and partially fades a part.

Starter Lua
local TweenService = game:GetService("TweenService")
local part = workspace:WaitForChild("MyMovingPart")

part.Anchored = true

local targetCFrame = CFrame.new(part.Position + Vector3.new(0, 5, 10)) * CFrame.Angles(0, math.rad(90), 0)

local tweenInfo = TweenInfo.new(
  3, -- seconds
  Enum.EasingStyle.Quad,
  Enum.EasingDirection.InOut,
  -1,
  true,
  0
)

local propertiesToTween = {
  CFrame = targetCFrame,
  Color = Color3.fromRGB(0, 255, 0),
  Transparency = 0.5
}

local tween = TweenService:Create(part, tweenInfo, propertiesToTween)
tween:Play()

tween.Completed:Connect(function(playbackState)
  if playbackState == Enum.PlaybackState.Completed then
    print("Tween completed!")
  elseif playbackState == Enum.PlaybackState.Cancelled then
    print("Tween cancelled!")
  end
end)
Explanation & Notes
  • Use WaitForChild to safely reference parts in Workspace.
  • Make the part Anchored when controlled by scripts to prevent physics from interfering.
  • Grouping multiple properties into one tween ensures they animate together.
  • Listen to Completed to chain behavior or clean up after animation.
Pro tip
For models, tween the PrimaryPart's CFrame or create twen targets per part to avoid inconsistent transforms across children.
