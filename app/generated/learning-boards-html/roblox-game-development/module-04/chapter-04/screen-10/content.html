Warning Common Mistakes & Performance
Anchoring

Set Anchored = true for parts moved by scripts to avoid physics-based jitter. Re-enable simulated physics only when needed.

Overlapping Tweens

Cancel previous tweens or wait for completion before creating new tweens on the same property to prevent conflicts.

Floating-point Drift

Avoid relying on reversing for infinite loops. Alternate explicit tweens between exact target CFrames to maintain precision.

Performance at Scale

Thousands of concurrent tweens can still cost CPU. Batch, stagger, or move visual-only effects to clients to spread the load.

Client vs Server

Run gameplay-critical tweens on the server so all players see the same authoritative movement. Use client tweens for cosmetic polish only.

Quick checklist
  • Anchored when scripted
  • Cancel overlapping tweens
  • Use explicit CFrame targets for loops
  • Keep cosmetic effects client-side
