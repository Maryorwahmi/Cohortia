Starter Code Template
-- PlayerInteractionSystem
local playerInventory = {}

local function AddItemToInventory(itemName, quantity)
  print("Attempting to add " .. quantity .. "x " .. itemName .. " to inventory.")
  table.insert(playerInventory, {Name = itemName, Quantity = quantity})
  print(quantity .. "x " .. itemName .. " added successfully!")
  return true
end

local function CheckInventorySpace(itemCount)
  print("Checking inventory space for " .. itemCount .. " items...")
  if #playerInventory + itemCount <= 5 then
    print("Enough space available.")
    return true
  else
    print("Not enough space! Inventory full.")
    return false
  end
end

-- Demonstration
local itemsToGet = 2
if CheckInventorySpace(itemsToGet) then
  AddItemToInventory("Sword", itemsToGet)
end

-- Anonymous event simulation
local giveItemPart = Instance.new("Part")
giveItemPart.Name = "GiveItemPart"

giveItemPart.Touched:Connect(function(otherPart)
  local playerCharacter = otherPart.Parent
  local player = game.Players:GetPlayerFromCharacter(playerCharacter)
  if player then
    if CheckInventorySpace(1) then
      AddItemToInventory("Health Potion", 1)
    end
  end
end)
This template simulates inventory logic and demonstrates event-driven invocation of helper functions. Replace prints with real inventory updates in a real project.
Exercise

Modify the CheckInventorySpace limit, then call AddItemToInventory several times and observe when adding fails. This helps you understand guard conditions.

Key Takeaway

Keep event handlers thin: validate inputs there and delegate logic to local functions that return clear results.
