Module 2 › Chapter 2.3 › Local vs Global
Local Function
Declared with local, accessible only inside the defining script or block. Limits accidental overwrites and supports encapsulation.
local function UpdateScore(points)
  playerScore = playerScore + points
end
Global Function
No local keyword means other scripts can access it. Risky if not intentionally shared because of silent overwrites.
function UpdateScore(points)
  playerScore = playerScore + points
end
Common problem

Two scripts defining the same global function name can silently overwrite behavior. Prefer ModuleScripts or local functions instead.
