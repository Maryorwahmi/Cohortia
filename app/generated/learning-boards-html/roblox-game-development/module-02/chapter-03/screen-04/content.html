Module 2 › Chapter 2.3 › What is a function?
Core concept

Function — reusable block

A function encapsulates a single task so it can be called many times without copying code. This reduces bugs and centralizes changes.

Metaphor
Think of a function like a vending machine: you provide input, it performs a job, and you get a predictable result.
Common mistake
Making god functions that do too much. Prefer many small functions instead of one large one doing unrelated tasks.
Example
Replace repeated coin-award lines with a function like GiveCoin(player, value) so you change the logic in one place.
Key Takeaway

Group repeated behavior into named functions that do a single job; this simplifies testing and reuse.

Check your understanding
  • Can you name one repeated block in your project that could be a function?
  • Is that block doing only one clear job?
