Module 2 › Chapter 2.3 › Defining & calling
Code Example
-- Define a local function
local function GreetPlayer(name)
  print("Welcome, " .. name .. " to our Roblox world!")
end

-- Call the function with different arguments
GreetPlayer("RobloxianBuilder")
GreetPlayer("GameDevJunior")
This example shows a local function named GreetPlayer with a single parameter. The calls pass different arguments to change the output.
Key points
  • Use local function to limit scope unless you intentionally need a global.
  • Choose descriptive parameter names so the purpose is obvious to callers.
  • Lua doesn't require type declarations—document expected types in comments or names.
Common misconception
Missing or mismatched parameters won't always raise a clear error. Verify the values you pass and use checks when needed.
Check your understanding

Try renaming the parameter to playerName and call the function with a simulated player string to see the output change.
