Module 2 › Chapter 2.3 › Multiple returns
Code Example
local function GetPlayerStats(playerID)
  if playerID == 1 then
    return "Alice", 120, true, "Warrior"
  elseif playerID == 2 then
    return "Bob", 80, false, "Mage"
  else
    return "Unknown", 0, false, "NoClass"
  end
end

local p1Name, p1Health, p1IsOnline, p1Class = GetPlayerStats(1)
print(p1Name .. " (Class: " .. p1Class .. ") - Health: " .. p1Health .. ", Online: " .. tostring(p1IsOnline))
Capture values in order. Use clear variable names that match the returned values to avoid confusion about which value is which.
Best practice

When returning multiple values, document their order in comments or in the function name so callers know what to expect.

When not to use

If a function returns many unrelated values or more than a handful, prefer returning a table with named fields for clarity.
