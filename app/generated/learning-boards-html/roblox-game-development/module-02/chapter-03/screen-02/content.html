Learning Objectives

Skills and competencies you'll achieve

Learn → Understand → Apply → Master
01
Define & Call Functions

Write a function with parameters and invoke it with arguments. This helps you reuse logic instead of copying code.

VERIFIED COMPETENCY MILESTONE
02
Parameters & Return Values

Pass data into functions and receive results back with return. This separates calculation from side effects like printing or modifying globals.

VERIFIED COMPETENCY MILESTONE
03
Local vs Global Scope

Prefer local functions to prevent naming collisions. Use globals only when intentional and documented for cross-script utilities.

VERIFIED COMPETENCY MILESTONE
04
Anonymous Functions & Events

Create unnamed functions to handle events like part.Touched. This keeps event logic close to the event source and readable.

VERIFIED COMPETENCY MILESTONE
