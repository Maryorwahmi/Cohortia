Functions: Reusable Code Blocks

Encapsulate logic, pass data with parameters, return results, and connect behavior to events with anonymous functions.

Why functions

Avoid repeating code like damage calculations, UI updates, or inventory checks. Functions make changes in one place.

When to use

Whenever a task is repeated, conceptually separate, or benefits from testing. Small, focused functions are easier to reason about.

Concrete example

Replace repeated lines that compute damage with a CalculateDamage function that takes base and multiplier and returns a value you can reuse across enemy types.

In this lesson
Define and call functions, use parameters and returns, prefer local functions, and connect anonymous functions to events.
DRY Principle
Group repeated logic into functions to avoid duplication and reduce bugs.
Scope Safety
Prefer local functions to prevent accidental overwrites across scripts.
