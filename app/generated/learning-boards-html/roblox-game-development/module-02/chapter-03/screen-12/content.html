Module 2 › Chapter 2.3 › Key Concepts
Function
A reusable block of code that performs a single task, reducing duplication and centralizing changes.
Local vs Global
Prefer local functions to avoid collisions and keep code modular; use ModuleScripts for shared utilities.
Anonymous Functions
Use unnamed functions for concise event callbacks, but validate input and extract logic when needed.
Final takeaway

Small, well-named functions plus careful scope choices are the foundations of maintainable Roblox code. Practice by refactoring one repeated block now.
