Module 3 › Chapter 2.4 › Create & Initialize
Code: constructors and examples
-- Empty table
local emptyTable = {}
print("Empty table created. Type: " .. type(emptyTable))

-- Array-like initialization
local playerNames = {"Alice", "Bob", "Charlie"}
print("First player: " .. playerNames[1])
print("Number of players: " .. #playerNames)

-- Dictionary-like initialization
local playerStats = {Name = "Alice", Health = 100}
print("Player Name: " .. playerStats.Name)
Example

Use playerNames for ordered lists like leaderboards or spawn queues.

Misconception

Lua arrays begin at 1. Expecting zero-based indexing causes off-by-one errors.

Why this matters

Choosing the right constructor makes iterating predictable and helps other developers understand your data layout.

Try this in Studio
  1. Create the tables shown and run prints.
  2. Change playerNames[1] and observe the output.
  3. Use # on mixed or sparse tables and note behavior.
Key Takeaway

Initialize tables to match your access and iteration needs; arrays for sequences and key-value for labeled data.
