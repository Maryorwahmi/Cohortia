Prompt

Use the following structure to implement the tasks and run prints in Studio to verify results.

local playerInventory = {
  {Name = "Health Potion", Quantity = 3, ID = 101},
  {Name = "Mana Potion", Quantity = 1, ID = 102},
  {Name = "Iron Sword", Quantity = 1, ID = 201}
}

-- a) Print Name of second item
-- b) Increase Quantity of first item by 2
-- c) Add Wooden Shield
-- d) Iterate and print Name and Quantity
Solution hints
  • Access the second item with playerInventory[2].Name.
  • Update first item with playerInventory[1].Quantity = playerInventory[1].Quantity + 2.
  • Add an item with table.insert(playerInventory, {Name = "Wooden Shield", Quantity = 1, ID = 202}).
  • Iterate with ipairs to print ordered results.
Key Takeaway

This assessment practices direct table manipulation patterns used in inventories and simple in-game data flows. Validate outputs in Studio to confirm expected behavior.
