Module 3 › Chapter 2.4 › ipairs vs pairs
ipairs example
local t = {10, 20, nil, 40}
for i, v in ipairs(t) do
  print(i, v) -- prints 1 = 10, 2 = 20 and then stops
end
Because of the nil at index 3, ipairs stops and never reaches index 4.
pairs example
local t = {10, 20, nil, 40, Name = "Test"}
for k, v in pairs(t) do
  print(k, v) -- may print 1=10,2=20,4=40,Name=Test in unspecified order
end
pairs covers sparse and named keys but does not guarantee order. Use it for dictionaries and mixed tables.
When to use

ipairs: dense sequences. pairs: dictionaries and general traversal.

Pitfall

Using ipairs on sparse arrays silently hides later elements — debug with prints to confirm expected output.

Key Takeaway

Pick the iterator for the table shape: ordered or general. When order matters, explicitly maintain it.
