Module 3 › Chapter 2.4 › Nested Tables
Nested example
local player = {
  Name = "Hero",
  Health = 100,
  Inventory = {
    {Name = "Sword", Damage = 15},
    {Name = "Shield", Defense = 10}
  }
}
print(player.Inventory[1].Name) -- "Sword"
Initialize Inventory = {} before pushing items; otherwise indexing will fail.
Practical notes
  • Chain access to reach nested values and check for nil at each step.
  • Keep nested tables shallow when possible to simplify access and saving.
  • Use arrays inside objects for ordered collections and dictionaries for properties.
Key Takeaway

Nested tables model complex objects, but you must create nested containers and guard access with nil checks to avoid runtime errors.
