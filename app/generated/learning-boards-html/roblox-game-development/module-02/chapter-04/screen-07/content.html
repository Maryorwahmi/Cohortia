Module 3 › Chapter 2.4 › Add / Modify / Remove
Step-by-step
  1. Create or reference the table.
  2. Add by assignment or table.insert.
  3. Modify by assigning a new value to the key.
  4. Remove by setting the key to nil. Consider rebuilding arrays to avoid holes.
Code
local playerNames = {"Alice","Bob"}
-- Add
playerNames[3] = "Charlie"
-- Modify
playerNames[1] = "Alicia"
-- Remove
playerNames[2] = nil

-- Safer remove pattern
local keep = {}
for i, v in ipairs(playerNames) do
  if v ~= "Bob" then table.insert(keep, v) end
end
playerNames = keep
Examples and pitfalls
Removing items directly may create holes that break ipairs. If order matters, rebuild the array or use a dictionary keyed by ID for stable lookups.
Common mistake

Mutating the same table while iterating can skip items or corrupt the loop state.

Pro tip

When you need both stable lookup and order, maintain an id->item map and a separate array of ids for ordering.

Key Takeaway

Assign to add or change, set to nil to remove, and avoid direct mutation of a table inside an active iteration.
