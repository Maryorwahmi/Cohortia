Module 3 › Chapter 2.4 › What is a Table?
Core definition

A table is a collection of key-value pairs. Keys can be numbers or strings. Values can be any Lua value, including other tables.

Example code
-- Empty table
local emptyTable = {}

-- Array-like
local playerNames = {"Alice", "Bob", "Charlie"}

-- Dictionary-like
local playerStats = {Name = "Alice", Health = 100}
Key takeaway

Tables are universal—pick a consistent shape for clarity.

Common mistake

Mixing styles without reason leads to confusing access patterns and harder-to-maintain code.

Analogy & quick checks

Think of a table like a flexible filing cabinet: numbered drawers for ordered lists and named folders for properties. You can store anything in a folder, including another filing cabinet (nested tables).

Check your understanding
  • Is the table for an ordered list or key-value properties?
  • Are keys valid identifiers for dot notation?
  • Will iteration require ordered output?
Key Takeaway

Start with { } and choose array-like or dictionary-like use, then keep that pattern consistent for each table.
