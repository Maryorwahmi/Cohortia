Module 3 › Chapter 2.4 › Key Concepts
Table

The primary data structure in Lua used as arrays, dictionaries, and objects.

ipairs vs pairs

Use ipairs for dense sequences; pairs for general key-value traversal or mixed tables.

Nested Tables

Compose tables within tables to model complex game data like inventories and settings.

Summary

Choose the right table shape, guard against nils, and prefer safe mutation patterns to build reliable game systems.
