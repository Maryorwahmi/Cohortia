Module 3 › Chapter 2.4 › Game Item Database
Starter code (visual)
local gameItems = {
  {Name = "Iron Sword", Type = "Weapon", Value = 50, Description = "A basic iron sword."},
  {Name = "Healing Potion", Type = "Potion", Value = 25, Description = "Restores health."}
}

-- Iterate with ipairs to list name and type
for i, item in ipairs(gameItems) do
  print(i .. ": " .. item.Name .. " (" .. item.Type .. ")")
end

-- Add a new item
table.insert(gameItems, {Name = "Golden Key", Type = "Quest Item", Value = 0, Description = "A mysterious key."})
Practical checks
  • Use ipairs for ordered item lists in UIs.
  • Use pairs when inspecting all properties of one item for debugging.
  • After table.insert, re-run iteration to verify the new entry appears.
Key Takeaway

This pattern is ideal for item registries, shops, and spawn tables. Keep items as tables so you can expand properties later without changing code that iterates them.
