Module 3 › Chapter 2.4 › Debugging Tables
Checklist
  • Are you using index 1 as the first element?
  • Do you check for nil before concatenating or indexing nested tables?
  • Did you choose the correct iterator for the table shape?
  • Are you mutating the table while iterating?
Common symptom

Missing elements in output often mean ipairs hit a nil or the loop mutated the table mid-iteration.

Debug tips
  1. Print indices and values while looping to see exact behavior.
  2. Test small, controlled tables to understand iterator behavior.
  3. Use helper guards like if table and table[key] then...
Key Takeaway

Pinpoint errors with concise prints and choose iteration and mutation strategies that avoid surprises.
