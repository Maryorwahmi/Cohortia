Tables: shape matters

Decide if a table is an ordered list or a map and keep that convention consistent.

Iterators

ipairs for ordered sequences; pairs for dictionaries and mixed tables.

Mutation safety

Avoid changing a table while iterating; collect changes then apply them after the loop.

Final tip

When starting a new feature, sketch the table shapes you need first. That sketch guides access, iteration, and mutation choices as you code.
