Module 3 › Chapter 2.4 › Array vs Dictionary
Array-like (ordered)
local playerNames = {"Alice", "Bob", "Charlie"}
-- Use ipairs to iterate
for i, name in ipairs(playerNames) do
  print(i .. ": " .. name)
end
Best for ordered lists where position matters. Remember: Lua indexing begins at 1.
Dictionary-like (labeled)
local playerStats = {Name = "Alice", Health = 100}
-- Use pairs to iterate properties
for k, v in pairs(playerStats) do
  print(k .. ": " .. tostring(v))
end
Best for objects with named attributes. Use bracket notation when keys are not valid identifiers.
Common mistake

Running ipairs on a sparse array stops at the first nil and may skip later items.

Pro tip

If you need both fast lookups and ordered lists, maintain both a dictionary keyed by ID and an array of IDs for order.

Key Takeaway

Pick array for sequences and dictionary for properties; mixing is allowed but choose consistency for clarity.
