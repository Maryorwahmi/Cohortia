Syntax & Pattern

if .. elseif .. else

Chain checks in order from most specific to least specific. Close every block with end to avoid syntax errors.

-- Player status example
if playerHealth <= 0 then
  print(playerName .. " has been defeated!")
elseif playerHealth < 50 then
  print(playerName .. " is critically wounded! Health: " .. playerHealth)
else
  print(playerName .. " is in good shape. Health: " .. playerHealth)
end
Common Mistake

Using = instead of == or misordering elseif checks so broader conditions mask specific ones.

Pro Tip

Write the most specific elseif first, then broader fallbacks last.

Example Scenario

Grant a special item if the player has both enough coins and completed quests, otherwise give a quest boost if only coins are sufficient, otherwise nothing.

local playerCoins = 120
local questsCompleted = 4

if playerCoins >= 100 and questsCompleted >= 5 then
  print("Player receives a Special Item!")
elseif playerCoins >= 100 then
  print("Player receives a Quest Boost Item!")
else
  print("Player receives nothing.")
end
Check yourself

Ask whether each path is reachable and whether earlier conditions prevent later ones from running unintentionally.
