Learning Objectives

Master decision-making and repetition to build interactive systems.

Bloom: Learn → Understand → Apply → Master
01
Write conditional blocks

Compose if, elseif, and else statements to run different behaviors based on game state, such as granting items or showing messages.

Mnemonic: a branching map shows your possible outcomes.
VERIFIED COMPETENCY MILESTONE
02
Use comparisons and logic

Combine ==, ~=, <, >, and operators and/or/not to build clear, correct conditions like "has key and door locked".

Mnemonic: Venn overlap for and, separate sets for or.
VERIFIED COMPETENCY MILESTONE
03
Manage while loops safely

Write while loops that change state and include wait pauses to avoid infinite loops that freeze Studio.

Mnemonic: conveyor belt with a stop switch.
VERIFIED COMPETENCY MILESTONE
04
Use for loops and loop control

Create numeric for loops for definite repetition, use break to exit early, and simulate continue with conditional guards.

Mnemonic: numbered steps with an exit door.
VERIFIED COMPETENCY MILESTONE
