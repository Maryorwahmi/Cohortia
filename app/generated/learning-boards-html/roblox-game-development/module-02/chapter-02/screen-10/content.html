Break

Exit a loop immediately

Use break when further iterations are unnecessary. It exits only the innermost loop.

for i = 1, #searchLocations do
  if searchLocations[i] == targetLocation then
    print("Treasure found in " .. targetLocation)
    treasureFound = true
    break
  end
end
Simulate Continue

Skip remaining loop steps

Use an if to guard the rest of the body so invalid items are skipped without further processing.

for playerName, score in pairs(playerScores) do
  if score < 0 then
    print("Skipping " .. playerName)
  else
    -- further processing for valid scores
    print("Processing " .. playerName .. ": " .. score)
  end
end
Pro tip: set a flag if you need an outer loop to stop as a result of an inner-loop break.
