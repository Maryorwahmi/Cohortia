Module 2 › Chapter 2.2 › While Loops
Structure

while condition do ... end

Use while when you don't know the exact number of iterations. Always change the condition inside the loop.

local countdown = 5
while countdown > 0 do
  print("T-minus " .. countdown .. " seconds...")
  countdown = countdown - 1 -- move toward stopping
  wait(1) -- yield to prevent freezing
end
print("Blast off!")
Danger

Infinite loops freeze Studio. Always ensure loop state changes or include a break condition.

Practice

Test loops with small counters then increase complexity once safe.

Concrete Scenario

Simulate player progress until they run out of lives or finish obstacles. Use a while that checks both conditions and break on game over.

Safety checklist
  • • Will the loop change state each iteration?
  • • Is there a wait where loops run often?
  • • Is there a break path for terminal conditions?
Reflection

Before running a while loop, describe how the condition will move toward false in plain words. That prevents infinite loops.
