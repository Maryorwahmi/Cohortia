Module 2 › Chapter 2.2 › What is Control Flow?
Definition

Control flow explained

Control flow determines which statements run and how often. Branches make choices, loops repeat work. In games both are used together to react to players and maintain ongoing behavior.

  • • Branching: choose one path using if / elseif / else.
  • • Repetition: repeat with while or for loops until a condition changes.
  • • Safety: ensure loop conditions become false and include pauses in frequent loops.
Key Takeaway

Design conditions and state changes before coding to avoid infinite loops and logic bugs.

Analogy

Branching is like a fork in the road; loops are like a conveyor belt that repeats until you stop it.

Concrete Example
Checking lives then repeating obstacles
-- Example concept
local playerLives = 3
if playerLives <= 0 then
  print("Game Over")
else
  print("Continue playing")
end

-- Repeat until course finished
while playerLives > 0 and currentObstacle <= totalObstacles do
  -- attempt obstacle, change state so loop will end
end
Misconception

Control flow is not just syntax; it is about choosing clear stopping conditions and understanding how state changes across iterations.
