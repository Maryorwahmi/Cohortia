Module 2 › Chapter 2.2 › Numeric For Loops
Syntax

for i = start, finish, step do ... end

Use numeric for loops when you know how many times to run code. The counter increments automatically, reducing loop-control errors.

-- Spawn enemies example
local numberOfEnemiesToSpawn = 3
for enemyNum = 1, numberOfEnemiesToSpawn do
  print("Spawning Enemy #" .. enemyNum)
  -- clone and parent model here
  wait(0.5)
end

-- Count down by twos
for i = 10, 0, -2 do
  print(i)
  wait(0.2)
end
When to use

Spawning fixed numbers, iterating numeric indices, and stepping through frames.

Misconception

Don't use while when a for loop with fixed bounds is clearer and less error-prone.

Practical Note

When creating many objects inside a for loop, add a small wait to allow the engine to process each creation and avoid lagging the client or server.

Check your loop

Does the counter reach the finish value as you expect? If not, inspect start, finish, and step for off-by-one errors.
