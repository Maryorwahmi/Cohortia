Module 2 › Chapter 2.2 › Generic For Loops
Pattern

for key, value in pairs(table) do

Use pairs for general tables, ipairs for array-like tables where order matters. Use conditional guards to skip unwanted entries.

local playerScores = {
  ["Alice"] = 150,
  ["Bob"] = 200,
  ["Charlie"] = -50, -- invalid
  ["David"] = 120
}

for playerName, score in pairs(playerScores) do
  if score < 0 then
    print("Skipping " .. playerName .. " due to invalid score.")
  else
    print("Processing " .. playerName .. "'s score: " .. score)
  end
  wait(0.1)
end
Notes
  • • pairs may iterate in arbitrary key order for non-array tables.
  • • Use ipairs for array-style lists to guarantee index order.
  • • Avoid resizing a table mid-iteration unless you manage indices carefully.
Simulate continue

Use an if guard at the top of the loop to skip processing remaining steps for this iteration.
