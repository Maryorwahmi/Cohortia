Local vs Global scope
Why scope matters in Roblox scripts.
Local variables
-- local scope inside a function
local function announce()
  local playerName = "Robloxian"
  print(playerName)
end
Local variables live where they are declared and disappear when the block ends.
Global variables
-- global variable example
score = 10 -- accessible from other code, may cause conflicts
Globals are accessible anywhere but can overwrite values and are harder to maintain in larger projects.
When to use
Use local for most variables. Use global only for truly shared constants intentionally designed to be accessed across scripts.
Common mistake
Forgetting local and causing silent conflicts where unrelated code changes behavior unexpectedly.
Key Takeaway
Default to local to keep functions and scripts self-contained and predictable.
