Player Statistics Tracker — step-by-step
Follow this guided starter and run the script in Studio.
Starter code template
-- PlayerStatsScript
-- This script tracks basic player statistics.

local playerName = "YourPlayerName"
local playerHealth = 100
local playerScore = 0
local isAlive = true

print("--- Initial Player Stats ---")
print("Player Name: " .. playerName)
print("Health: " .. playerHealth)
print("Score: " .. playerScore)
print("Is Alive: " .. tostring(isAlive))
Edit the variables and run the script to see output in Studio. Use tostring for non-string types when printing combined messages.
Step checklist
  1. Declare local variables with clear names and default values.
  2. Print initial values to confirm correct initialization.
  3. Simulate damage and update health, then print again.
  4. Simulate score gain and print final stats in one message.
Debug tip
If the output shows nil, check that the variable was declared and not misspelled or in a different scope.
Key Takeaway
Small, testable scripts teach you how syntax, scope, and types interact in real runs.
