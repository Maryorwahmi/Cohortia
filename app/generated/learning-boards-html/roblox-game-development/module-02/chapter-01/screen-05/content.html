Definition
Comments in Lua
Single-line and multi-line examples you will use to document scripts.
Single-line comments
-- This is a single-line comment
local playerScore = 0 -- explains the purpose of this variable
Use them inline to annotate a line or above a short block.
Multi-line comments
--[[
  This is a multi-line comment.
  Use this to describe the script's purpose
  or a complex algorithm.
]]
Great for headers or longer explanations you want to keep with a script.
Example: documenting a health update
-- Reduce player health when hit
local playerHealth = 100
local damageTaken = 25
playerHealth = playerHealth - damageTaken -- apply damage
Common mistake
Leaving large commented blocks that are outdated. Update or remove stale comments.
Key Takeaway
Comments should make code easier to maintain and debug, not noisier.
