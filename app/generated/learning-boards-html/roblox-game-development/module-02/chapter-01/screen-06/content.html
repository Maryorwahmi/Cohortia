Variables: declaring and initializing
How to create variables and choose names that communicate purpose.
Declaration examples
-- Preferred: local variables
local playerScore = 0
local playerName = "ExplorerBot"
local isAlive = true
local lastPlayerJoined = nil
Initialize with values that match the intended type to avoid nil or type errors later.
Naming conventions & best practice
  • Use descriptive camelCase names: playerScore, playerHealth.
  • Declare variables as local unless you intentionally need global scope.
  • Initialize variables where their purpose is clear to readers.
Avoid this mistake
Defining variables without local at top level can create globals that conflict across scripts.
Key Takeaway
Local, descriptive, and initialized variables are easier to read and less error-prone.
