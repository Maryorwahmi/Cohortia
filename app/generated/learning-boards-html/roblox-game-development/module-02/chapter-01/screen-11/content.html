Common Mistake
Type mismatch and runtime errors
How to interpret errors and apply quick fixes.
Error example
local itemPrice = 15
local itemCount = "5"
local totalCost = itemPrice * itemCount
print(totalCost)

-- Studio will report: attempt to perform arithmetic on string
This indicates itemCount is a string; use tonumber to convert it to a number.
Fix patterns
  • Confirm variable spelling and case.
  • Check if the variable is local or was overwritten globally.
  • Convert types explicitly with tonumber or tostring when needed.
Key Takeaway
Use the output window to find the line, then check name, scope, and type in that order.
