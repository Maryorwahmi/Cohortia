Core Concept
Lua syntax basics
Case sensitivity, optional semicolons, and how comments help.
Definition & examples
-- Case sensitivity example
local myScore = 10
print(myScore)   -- valid
-- print(MyScore) -- error: MyScore is different

-- Semicolons are optional
local x = 1
local y = 2; local z = x + y
Notes: Check variable names for exact spelling. Use comments to explain why values are used.
Common misconceptions
  • Thinking semicolons are required — they're optional in Lua.
  • Assuming capitalized variants of a name are the same — they are not.
  • Believing comments change execution — they do not; they only document intent.
Pro tip
Keep a consistent naming scheme like camelCase for variables used throughout your script.
Key Takeaway
Small syntax habits—consistent case and clear comments—save hours of debugging later.
