Core Concept
Lua data types
Number, string, boolean, and nil — choose the right type for the right job.
Type examples
local score = 100           -- number
local playerName = "Alex"  -- string
local isAlive = true         -- boolean
local unseen = nil           -- nil

print(type(score)) -- "number"
Use type() to confirm what Lua sees at runtime.
Why types matter
  • Operators behave differently by type. Arithmetic requires numbers.
  • Concatenation requires strings or explicit conversion.
  • Nil signals the absence of data and can cause errors if not handled.
Misconception
Relying on implicit conversion is risky. Convert explicitly with tostring or tonumber when unsure.
Key Takeaway
Pick and check types deliberately—this is the foundation for bug-free operations.
