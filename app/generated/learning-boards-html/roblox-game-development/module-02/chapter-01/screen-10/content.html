Definition
String concatenation and type conversion
How to build readable messages and avoid type errors.
Code examples
local playerName = "Robloxian123"
local playerScore = 42
local greeting = "Welcome, " .. playerName .. "!"
print(greeting)

-- Explicit conversion for safe concatenation
local message = "Your score is: " .. tostring(playerScore)
print(message)
Use tostring to make it clear you intend text output, and include punctuation inside literals for readability.
Common errors
Using + to join strings or concatenating raw numbers without conversion can lead to confusing output or errors.
Practice
Print a combined player message and force conversion with tostring to see the difference.
Key Takeaway
Always convert non-strings before concatenation to keep outputs predictable.
