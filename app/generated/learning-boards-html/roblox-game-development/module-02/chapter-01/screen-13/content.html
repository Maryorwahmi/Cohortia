Using type, tostring, and tonumber
Small utility functions that prevent runtime errors.
Code patterns
-- check type before arithmetic
local itemPrice = 15
local itemCount = "5"
print("Type of itemCount: " .. type(itemCount))
local numericCount = tonumber(itemCount)
if numericCount then
  local totalCost = itemPrice * numericCount
  print(totalCost)
else
  print("Cannot compute total: itemCount is not a number")
end

-- safe conversion with default
local safeCount = tonumber(itemCount) or 0
Handle nil from tonumber and prefer explicit checks to avoid crashing arithmetic operations.
Quick rules
  • Use type() to inspect runtime type.
  • Use tonumber() to convert strings to numbers; check for nil.
  • Use tostring() for safe concatenation to text.
Debug exercise
Intentionally set a variable to a string and practice converting it safely then printing results.
Key Takeaway
Explicit conversion and checks make small scripts robust and debugging faster.
