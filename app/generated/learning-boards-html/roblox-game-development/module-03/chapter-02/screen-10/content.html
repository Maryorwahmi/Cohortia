Common Mistakes and Debugging Tips
Practical checks to avoid runtime errors and UX problems.
Missing ClickDetector
Use FindFirstChild and warn or return if nil. This avoids nil indexing and confusing errors during playtesting.
Incorrect parent
ClickDetector must be a child of a BasePart. For models, add a transparent part as the clickable area.
Activation distance surprises
Test MaxActivationDistance in play to ensure it matches your interaction intent and prevents accidental clicks.
Debug tip

Print player.Name and state transitions in the Output to confirm handler behavior quickly.

Design check

Decide whether the interaction should affect everyone or only the clicking player and code accordingly.
