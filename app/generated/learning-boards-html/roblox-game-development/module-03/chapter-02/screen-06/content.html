Key Properties of ClickDetector
Control who can click and how the cursor looks.
MaxActivationDistance
Distance in studs a player may be to click. Smaller values require proximity; larger values allow remote activation.
Design examples: 5–10 studs for control panels, 50+ for large displays.
MouseHoverCursor
Icon shown while hovering; can use asset IDs to customize cursors that communicate intent.
Use subtle changes to avoid confusing players.
CursorIcon
Icon shown when the mouse is over the object and ready to click. Tweak to show active or disabled states.
Change at runtime to reflect state changes.
Misconception

Bigger MaxActivationDistance is not always better. Balance reach against accidental activations.

Try this

Temporarily set MaxActivationDistance to 0 to disable clicks without removing the ClickDetector.
