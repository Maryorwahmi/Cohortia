How you'll apply these skills
Practice tasks to confirm understanding and readiness.
Task checklist • No runtime surprises
Task 1: Insert & Test
Add a ClickDetector to a part and enter Play mode. Look for the hand cursor on hover.
Task 2: Adjust Range
Change MaxActivationDistance and observe when clicks register from different distances.
Task 3: Script Reaction
Connect MouseClick to a function that uses the player argument to print a message and change a part’s properties.
Verified outcome

You can add a clickable part, detect who clicked it, and make state changes safely while avoiding missing-object errors.
