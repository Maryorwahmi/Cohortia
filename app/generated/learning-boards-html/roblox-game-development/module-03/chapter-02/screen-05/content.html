Add a ClickDetector to a Part
Insert, verify, and guard your code against missing instances.
Step-by-step
  1. Select the Part in Explorer and click + to add ClickDetector.
  2. Open Properties to review MaxActivationDistance and cursor fields.
  3. Place your script as a child of the same Part for easy script.Parent references.
  4. Test in Play mode to see the hand cursor on hover.
Sanity check (pattern)
-- Script placed inside a clickable Part local part = script.Parent local clickDetector = part:FindFirstChildOfClass("ClickDetector") if not clickDetector then warn("Missing ClickDetector on part") return end clickDetector.MouseClick:Connect(function(player) print(player.Name .. " clicked") end)
Common mistake

Parenting ClickDetector to a Model will not work; it must be child of a BasePart. Use a covering Part for models.

Pro tip

Keep your script inside the same Part so script.Parent makes referencing simple and robust during testing.
