Collectible Coin: Disappear on Click
Implement a coin that prints who collected it and then removes itself.
Code template (place in CollectibleCoin)
-- Script placed inside the "CollectibleCoin" Part
local coin = script.Parent
local clickDetector = coin:FindFirstChildOfClass("ClickDetector")
if not clickDetector then
    warn("CollectibleCoin is missing a ClickDetector!")
    return
end
local function onCoinClicked(player)
    if not coin.CanCollide then return end
    print(player.Name .. " collected the coin!")
    coin.Transparency = 1
    coin.CanCollide = false
    task.wait(0.5)
    coin:Destroy()
end
clickDetector.MouseClick:Connect(onCoinClicked)
print("CollectibleCoin script initialized!")
Notes & best practices
  • Disable CanCollide immediately to prevent multiple clicks.
  • Use a short delay before Destroy to allow visual feedback to finish.
  • Consider server-side bookkeeping for awarding points or inventory.
Testing tip: click during Play mode and verify the Output prints the correct player name.
Key takeaway

Use simple state guards and the player argument to make collectibles reliable and clearly attributable to the clicking player.
