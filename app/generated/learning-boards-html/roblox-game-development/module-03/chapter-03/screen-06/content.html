Why debounce matters
Touched can fire many times per second while parts remain in contact. Without debounce, you get runaway effects.
  • Per-player timestamp table avoids cross-player interference.
  • os.time avoids sleeping the script and is server-safe.
  • Use UserId as the key so the table survives player name changes.
Damage zone pattern (excerpt)
-- Script inside "DamageZone"
local DAMAGE_AMOUNT = 10
local COOLDOWN_TIME = 1
local playersInZone = {}

local function onDamageZoneTouched(otherPart)
  local character = otherPart.Parent
  if not character then return end
  local humanoid = character:FindFirstChildOfClass("Humanoid")
  if not humanoid then return end
  local player = game.Players:GetPlayerFromCharacter(character)
  if not player then return end

  local lastDamageTime = playersInZone[player.UserId] or 0
  if os.time() - lastDamageTime < COOLDOWN_TIME then
    return
  end

  humanoid:TakeDamage(DAMAGE_AMOUNT)
  playersInZone[player.UserId] = os.time()
end

damageZone.Touched:Connect(onDamageZoneTouched)
Pro tip: Use os.time() for server-wide consistent cooldowns.
Don't: Use task.wait inside the handler—this blocks the thread.
