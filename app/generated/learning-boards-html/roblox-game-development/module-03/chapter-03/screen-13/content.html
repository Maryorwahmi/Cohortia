Module 3 › Chapter 3.3 › Best Practices
State management
Use per-player tables and UserId keys.
This prevents collisions between players and keeps behaviour consistent.
Avoid blocking
Don’t task.wait in high-frequency handlers.
Use timestamps or background tasks for longer work.
Event cleanup
Disconnect when appropriate.
Match connection lifetime to object lifetime to prevent stray callbacks.
Quick checklist
Per-player state, early returns, no blocking waits, visible feedback, and prompt disabling during actions.
