Locked chest script
-- Script placed inside a Part named "LockedChest"
local chest = script.Parent
local prompt = chest:FindFirstChildOfClass("ProximityPrompt")

if not prompt then
    warn("LockedChest is missing a ProximityPrompt!")
    return
end

prompt.ActionText = "Open"
prompt.ObjectText = "Chest"
prompt.HoldDuration = 0.5
prompt.KeyboardKeyCode = Enum.KeyCode.E

local isOpen = false

local function onPromptTriggered(player)
    if isOpen then
        print("Chest is already open!")
        return
    end

    print(player.Name .. " opened the chest!")
    isOpen = true
    chest.BrickColor = BrickColor.new("Dark green")
    prompt.Enabled = false

    -- spawn loot or perform other actions
end

prompt.Triggered:Connect(onPromptTriggered)
Explanation & tips
  • Triggered gives you the Player, so no hit validation is needed.
  • Use a state variable to prevent duplicate handling while the action executes.
  • Disable the prompt for one-time interactions, or re-enable after reset if needed.
Pro tip: Use HoldDuration to reduce accidental activations for important actions.
