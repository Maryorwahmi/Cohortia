What ProximityPrompt provides
  • A visual prompt above the part when a player is nearby.
  • Configurable action and object text for clarity.
  • Optional hold duration to require a deliberate action.
  • Triggered event supplies the Player who activated it.
Important properties
ActionText: Instructional verb like "Open" or "Talk".
ObjectText: Object name shown to player, like "Chest".
HoldDuration: Seconds the key must be held before activation.
KeyboardKeyCode / GamepadKeyCode: Input bindings for activation.
RequiresLineOfSight: If true, the player must see the prompt target.
When to use:
Use ProximityPrompt when you want player agency and clear instructions for interaction.
