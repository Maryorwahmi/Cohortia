Comparison

Boolean vs Per-player Cooldown

Boolean
Single flag like isAnimating or isDoorOpen. Best for global object state and quick debouncing.
Per-player cooldown
Use a table keyed by UserId to track last action times so each player has independent cooldowns.
Examples
  • Use isTrapActive for object-level activation.
  • Use launchCooldowns[player.UserId] for a per-player launch pad cooldown.
  • Avoid global booleans when multiple players must act independently.
Key Takeaway

Match the scope of the state to the scope of the interaction: object-level state for objects, per-player state for player-specific controls.
