Process

Debounce and Animation Flow

1. On trigger, check isAnimating. If true, return immediately.
2. Set isAnimating = true and start the tween.
3. In tween.Completed, toggle the relevant state and set isAnimating = false.
4. For chained motion, create the next tween inside Completed or use TweenInfo delay fields.
Trap Example (concept)
A spike lowers immediately, then a raise tween is created with TweenInfo that includes a RESET_TIME delay so the trap raises after that delay. Only when the raise tween completes should isTrapActive be set to true again.
Common Mistake

Relying on task.wait to time logical state changes without handling animation interruptions or tween failures can cause mismatch between visuals and logic.
