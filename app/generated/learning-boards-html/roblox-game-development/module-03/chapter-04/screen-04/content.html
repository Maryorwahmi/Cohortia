Core Concept

What makes an interactive door reliable

An interactive door listens to a ProximityPrompt, animates with TweenService, and uses boolean flags to prevent overlapping animations.

Definition
A door object that opens or closes in response to a player interaction while preventing conflicting triggers.
Concrete example
A ProximityPrompt set to ActionText "Open" moves the door up 10 studs using a one-second tween, then sets ActionText to "Close" on completion.
Key Takeaway

Coordinate event triggers with a debounce and listen to tween.Completed before toggling state.

Analogy

Think of the door as an elevator that must finish its ride before taking new passengers. The button is the trigger, the elevator's motion is the tween, and the closed/open flags are the safety lock.

Common mistake
Toggling state before the tween completes. That allows repeated triggers and can leave the door between positions. Use an isAnimating boolean instead.
