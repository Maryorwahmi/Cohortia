Process Flow

Parts and Prompt Setup

  1. Create a Part named "Door" and set Anchored = true.
  2. Create a child Part named "DoorTrigger" and parent it to the Door.
  3. Add a ProximityPrompt to DoorTrigger and set ActionText = "Open" and HoldDuration = 0.2.
  4. Record originalPosition and calculate openPosition = originalPosition + Vector3.new(0, 10, 0).
Key Takeaway

Consistent part parenting and anchored motion prevent physics conflicts and simplify script logic.
