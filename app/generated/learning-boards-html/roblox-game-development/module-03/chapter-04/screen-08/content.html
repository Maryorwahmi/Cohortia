Definition

Collectible behavior

A collectible should only be collected once, provide visual feedback, update player data safely, and then be removed.

Checklist
  • Use a collected boolean for a debounce.
  • Set Transparency and CanCollide to disable further interaction.
  • Create leaderstats and IntValue if missing before incrementing.
  • Destroy the object after a short delay.
Analogy & Example

Think of a collectible like a coupon: once redeemed it should be marked used, hidden, and removed from circulation to prevent reuse.

Key Takeaway

Guard collection with a flag and update player data only after validating leaderstats exist or creating them safely.
