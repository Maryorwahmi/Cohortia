Door Script (annotated)

This script belongs inside the Door Part. It finds the prompt, creates a tween, and toggles the door with debounce.

Important lines to note
  • Caching originalPosition and computing openPosition keeps motion predictable.
  • isAnimating prevents starting another tween while one runs.
  • Using tween.Completed to toggle isDoorOpen is more reliable than waiting a fixed delay.
Key Takeaway

Let tween.Completed signal logical state changes; do not rely on guessed timing.

Example Script
-- Script placed inside the "Door" Part
local door = script.Parent
local doorTrigger = door:FindFirstChild("DoorTrigger")
local prompt = doorTrigger and doorTrigger:FindFirstChildOfClass("ProximityPrompt")

if not doorTrigger or not prompt then
  warn("Door is missing its 'DoorTrigger' or 'ProximityPrompt'!")
  return
end

prompt.ActionText = "Open"
prompt.ObjectText = "Door"
prompt.KeyboardKeyCode = Enum.KeyCode.E
prompt.HoldDuration = 0.2

local tweenService = game:GetService("TweenService")
local originalPosition = door.Position
local openPosition = originalPosition + Vector3.new(0, 10, 0) -- Door moves up 10 studs
local tweenInfo = TweenInfo.new(1, Enum.EasingStyle.Quad, Enum.EasingDirection.Out, 0, false, 0)

local isDoorOpen = false
local isAnimating = false -- Debounce for animation

local function toggleDoor(player)
  if isAnimating then return end
  isAnimating = true

  local targetPosition = isDoorOpen and originalPosition or openPosition
  local tween = tweenService:Create(door, tweenInfo, {Position = targetPosition})
  tween:Play()

  tween.Completed:Connect(function()
    isDoorOpen = not isDoorOpen
    isAnimating = false
    prompt.ActionText = isDoorOpen and "Close" or "Open"
  end)
end

prompt.Triggered:Connect(toggleDoor)
print("Interactive Door script initialized!")
