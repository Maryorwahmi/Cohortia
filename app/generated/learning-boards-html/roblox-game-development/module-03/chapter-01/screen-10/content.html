Defensive Event Handling and Error Prevention

Validation pattern
local function onTouched(otherPart)
  local character = otherPart and otherPart.Parent
  if not character then return end
  local humanoid = character:FindFirstChildOfClass("Humanoid")
  if not humanoid then return end
  -- Safe to change humanoid properties now
end
Connection management
For one-time triggers, store the connection and call Disconnect after the action to prevent repeated firing and to allow garbage collection of the object when removed.
Example: local conn = part.Touched:Connect(handler); inside handler: conn:Disconnect() after the action.
