Testing and Debugging Event Handlers

Starter debug steps
  1. Attach a handler that prints the event arguments.
  2. Run Play and trigger the event; observe output.
  3. Replace prints with the intended behavior once confirmed.
If a handler never runs, verify you used Event:Connect(functionRef) and that the script is enabled and parented correctly.
Example prints
print("Touched part:", otherPart.Name); print("Parent:", otherPart.Parent.Name) — useful to confirm a limb or object triggered the event.
Tip: Clear and descriptive print messages speed debugging when multiple scripts run in the same session.
