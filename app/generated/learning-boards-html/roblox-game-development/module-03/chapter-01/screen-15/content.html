Key Concepts

Events signal actions
An event is a notification. Your handler performs the reaction you design.
Connect with function reference
Use Event:Connect(handler) and avoid passing handler() which calls it immediately.
Validate arguments
Check for Humanoid and other expected objects before changing state to prevent errors.
Summary: Connect, validate, manage, test. These four practices make your event-driven code robust and maintainable.
