Connecting a Handler with Connect()

Live code example
-- Script placed inside a Part named "HealingPad"
local healingPad = script.Parent
local HEAL_AMOUNT = 25

local function onHealingPadTouched(otherPart)
  local character = otherPart.Parent
  local humanoid = character and character:FindFirstChildOfClass("Humanoid")
  if humanoid and humanoid.Health < humanoid.MaxHealth then
    humanoid.Health = math.min(humanoid.MaxHealth, humanoid.Health + HEAL_AMOUNT)
  end
end

healingPad.Touched:Connect(onHealingPadTouched)
print("Healing pad script initialized!")
Explanation and checks
  • Define the handler and pass its reference to Connect, not the result of calling it.
  • Use FindFirstChildOfClass("Humanoid") to ensure the touching object is a character before modifying Health.
  • Store the connection if you might later call Disconnect to stop listening.
Pro tip: Use named functions when you'll need to Disconnect or reuse the handler.
