What is an Event in Roblox?

A precise definition and why handlers matter for interactive games.

Definition & analogy

An event is a signal that something occurred, like a doorbell. The handler is the action you take in response, like playing a sound or changing health.

Analogy: Doorbell pressed → bell rings. In code: Event fires → handler runs.
Misconception: Events do not automatically change game state. Only handlers perform state changes.
Concrete example
Use Touched on a part to detect collisions. The handler receives the touching part, enabling you to find the character and modify its Humanoid properties safely.
Key Takeaway
Events notify; handlers implement the response. Always inspect supplied arguments before acting.
