Other Useful Roblox Events

PlayerAdded
Fires when a player joins. Handler receives the Player object. Use to set up player data or UI.
Workspace.ChildAdded
Fires when a new instance appears in the workspace. Handler receives the new instance for dynamic behavior.
ProximityPrompt.Triggered
Passes the Player who triggered the prompt. Useful for proximity-based interactions that require intent.
