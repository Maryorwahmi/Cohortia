Mini Quiz and Reflection

Quiz question 1
Which snippet correctly connects a handler so the part prints a message when touched? Answer: part.Touched:Connect(function(hit) print("Touched by", hit.Parent.Name) end)
Quiz question 2
How to check if otherPart belongs to a player's character? Use otherPart.Parent and FindFirstChildOfClass("Humanoid"). If Humanoid exists, proceed safely.
Reflection
Run small tests, print argument values, and iterate. This confirms your mental model and reduces runtime surprises.
