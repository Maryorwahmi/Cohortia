Build: Color Changer (Step-by-step)

Starter code template
-- Script placed inside the "ColorChanger" Part
local colorChangerPart = script.Parent

local function onPartTouched(otherPart)
  local character = otherPart.Parent
  local humanoid = character and character:FindFirstChildOfClass("Humanoid")
  if humanoid then
    local randomColor = Color3.new(math.random(), math.random(), math.random())
    colorChangerPart.Color = randomColor
    print("ColorChanger touched by " .. character.Name .. ". New color: " .. tostring(randomColor))
  end
end

colorChangerPart.Touched:Connect(onPartTouched)
print("ColorChanger script initialized. Touch me!")
Checks and testing
  • Confirm the Part is Anchored if you don't want it to move.
  • Print character.Name and randomColor during testing to verify inputs and outputs.
  • If color doesn't change, ensure you set Color, not BrickColor, or convert appropriately.
Why this helps: You practice connecting an event, handling arguments, and changing object properties safely.
