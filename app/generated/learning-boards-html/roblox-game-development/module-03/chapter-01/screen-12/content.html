Managing Connections and Script Scope

Connection example
local conn
local function handler(otherPart)
  -- do action once
  conn:Disconnect()
  conn = nil
end
conn = part.Touched:Connect(handler)
Scope and cleanup
  • Keep handlers local to the script unless a broader API is needed.
  • Disconnect and nil references after finishing to allow garbage collection.
  • Use BindableEvents for intra-server communication instead of exposing functions globally.
