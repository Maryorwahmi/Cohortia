Event Handler Arguments

Common arguments
  • otherPart / hit — the Part that triggered a Touched event.
  • player — the Player who clicked or triggered a ProximityPrompt or ClickDetector.
  • newChild — the instance passed by Workspace.ChildAdded.
Testing tip: Print argument values during development to ensure you understand the runtime behavior.
Validation pattern
Example: local character = otherPart.Parent; local humanoid = character and character:FindFirstChildOfClass("Humanoid"); if not humanoid then return end — this prevents errors when non-player parts touch your object.
Key takeaway: Never assume the argument is the exact type you want; always check before acting.
