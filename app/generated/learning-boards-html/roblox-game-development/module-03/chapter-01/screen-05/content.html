The Event-Response Cycle

Step-by-step
1
Action occurs
Example: player touches a Part or clicks a ClickDetector.
2
Event fires
Roblox emits Touched or MouseClick with arguments describing the cause.
3
Handler runs
Your function receives arguments, validates data, and updates state like Health or Color.
4
Manage connection
Optionally disconnect to stop listening or leave connected for repeated responses.
Concrete scenario
Healing pad: when Touched fires, handler receives otherPart, find character and Humanoid, add health up to MaxHealth, then optionally disconnect if the pad should trigger only once.
Common mistake
Passing myFunction() to Connect executes the function immediately and hands its return value to Connect. Always pass the function reference: Event:Connect(myFunction).
