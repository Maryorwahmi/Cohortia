Steps
  1. Create ScreenGui named "GameHUD" in StarterGui.
  2. Add Frame "InfoPanel" with Size = UDim2.new(0.2,0,0.15,0) and Position = UDim2.new(0.01,0,0.01,0).
  3. Add PlayerNameLabel inside with TextScaled = true.
  4. Add SettingsButton at top-right and a ButtonClickSound in StarterGui.
  5. Add background music Sound to SoundService, Looped = true, Volume = 0.2.
LocalScript Example
-- LocalScript inside SettingsButton
local button = script.Parent
local clickSound = game.StarterGui:WaitForChild("ButtonClickSound") -- Ensure this sound exists

button.MouseButton1Click:Connect(function()
  print("Settings opened!")
  if clickSound then
    clickSound:Play()
  end
end)
Use the emulator to confirm behavior on different devices. Keep volumes balanced so SFX are audible but not dominant.
