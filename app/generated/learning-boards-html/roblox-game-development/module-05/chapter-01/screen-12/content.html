Profiler Workflow
Run the MicroProfiler to identify expensive categories such as Physics or Scripts. Correlate a spike with recent changes to find the cause.
Quick Debug Checklist
  • Check Output for errors and warnings.
  • Add print statements to validate assumptions.
  • Set breakpoints to inspect variables and flow.
  • Use pcall for risky calls while diagnosing.
Hands-on Lab Summary
Create a deliberately laggy scenario with 1000 unanchored parts, observe MicroProfiler, then refactor by anchoring static parts and adding task.wait in loops to see improvements. Introduce a runtime error, set a breakpoint, inspect variables, and fix the bug.
Key Takeaway

Repeat measure → change → measure until targeted profiler categories show improvement.
