Issue
High part count and many unanchored parts increase physics and render workload.
Actions
  • Anchor static parts.
  • Set CanCollide = false for decorative elements.
  • Replace clusters with MeshParts or optimized models.
  • Consider StreamingEnabled for large worlds.
Concrete Practice
Insert 1000 small unanchored parts and observe MicroProfiler. Then anchor static ones and reduce dynamic ones to see the physics time drop. This hands-on comparison teaches how each change affects performance.
Key Takeaway

Anchoring and reducing active part count are often the fastest wins for physics-related lag.
