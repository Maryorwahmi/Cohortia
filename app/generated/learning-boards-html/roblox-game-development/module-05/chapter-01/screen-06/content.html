BloomEffect
Creates a glow around bright pixels to emphasize light sources. Best for collectibles and lights. Keep intensity low for subtlety.
When to use
Highlight pickups or torches.
DepthOfFieldEffect
Adds cinematic blur outside the focus distance. Use for cutscenes, avoid during precise gameplay where interactables must be clear.
Misuse risk
Can blur interactive objects and frustrate players.
Color Correction
Shifts the game's overall color balance to set tone. Use it to unify a scene's palette but avoid breaking UI contrast.
Performance note
Altering many color properties can increase render cost if overused.
Testing Checklist
  • Toggle effects to compare visuals and profiler impact.
  • Verify UI remains readable with effects enabled.
  • Prefer subtle values and single-effect focus per scene.
