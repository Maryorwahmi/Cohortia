Process
Lighting & Post-Processing Steps
1
Set base Brightness and OutdoorAmbient
Ensure visibility and contrast first; avoid extreme values that clip detail.
2
Add one post-effect
Try BloomEffect or DepthOfFieldEffect and test its impact across scenes.
3
Tune conservatively and test
Small values often provide the best clarity and least performance cost.
4
Validate interactivity
Make sure UI and interactable objects stay readable when effects are applied.
Explanation
Post-processing affects the entire rendered frame; Bloom creates glow, Depth of Field blurs distant or close areas to emphasize focus, and Color tools shift overall tones. Use these tools to guide attention and support the game's visual hierarchy.
Concrete Example
Add a BloomEffect with low intensity so lights around pickups glow slightly; test that pickups become more noticeable without washing UI contrast.
Misconception
More effect always equals better visuals. In practice, subtlety preserves clarity and reduces render cost.
