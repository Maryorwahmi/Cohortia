Core Concept
Sound object & SoundService
Sound objects play audio files; SoundService manages global audio settings. Use Looped for background music and Volume to balance ambiance vs effects.
Concrete Example
Insert background music into SoundService, set Looped = true, and Volume = 0.2 to 0.3.
Common Mistake
Making music too loud, hiding SFX that provide gameplay feedback.
Code Template
-- Insert a Sound into SoundService for background music
local music = Instance.new("Sound")
music.Name = "BackgroundMusic"
music.Looped = true
music.Volume = 0.25
music.SoundId = "rbxassetid://YOUR_ASSET_ID"
music.Parent = game:GetService("SoundService")

-- LocalScript example for a button SFX
local button = script.Parent
local clickSound = game.StarterGui:WaitForChild("ButtonClickSound")

button.MouseButton1Click:Connect(function()
  print("Settings opened!")
  if clickSound then
    clickSound:Play()
  end
end)
Replace YOUR_ASSET_ID with the audio asset. Adjust Volume to balance with SFX.
