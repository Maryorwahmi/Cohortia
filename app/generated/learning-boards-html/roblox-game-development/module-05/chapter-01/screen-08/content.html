ScreenGui & UDim2

UDim2 has Scale and Offset. Use Scale for proportional sizing, Offset for pixel tweaks. Anchor, TextScaled, and UI layout objects create consistent spacing and alignment across devices.

Concrete Example
InfoPanel: Size = UDim2.new(0.2, 0, 0.15, 0), Position = UDim2.new(0.01, 0, 0.01, 0). TextLabel size UDim2.new(0.9, 0, 0.3, 0) with TextScaled true.
Testing Tip
Use Emulate Device to preview Phone, Tablet, and Desktop layouts before publishing.
