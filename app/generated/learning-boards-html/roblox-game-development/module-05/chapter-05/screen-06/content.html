Process: increment safely
  1. Call UpdateAsync with the player key and a transformFunction.
  2. The transformFunction receives old value (or nil) and returns the new value.
  3. UpdateAsync applies the transform atomically and returns the final stored value.
  4. Update player's in-game attribute with the returned new value.
-- Using UpdateAsync to add coins
local function addCoins(player, amount)
  local success, newCoins = pcall(function()
    return playerDataStore:UpdateAsync(player.UserId, function(oldCoins)
      oldCoins = oldCoins or 0
      return oldCoins + amount
    end)
  end)

  if success then
    player:SetAttribute("Coins", newCoins)
    print(player.Name .. " gained " .. amount .. " coins. New total: " .. newCoins)
  else
    warn("Error updating coins for " .. player.Name .. ": " .. newCoins)
  end
end
Misconception

Don't read-modify-write outside UpdateAsync; that pattern is vulnerable to race conditions.

Analogy

Think of UpdateAsync as asking the server to open, modify, and safely close the value for you atomically.

Example scenario

Player picks up coins on multiple servers or during handoffs. Use UpdateAsync so each increment merges correctly into the stored total.

Key Takeaway

Use UpdateAsync with a transform function when changing counters or merging stored tables to avoid overwriting concurrent changes.
