Walkthrough: load and save

Follow this server-side pattern: pcall(GetAsync) on join, set defaults if nil, pcall(SetAsync) on leave. Always log failures.

-- Save and load pattern
local DataStoreService = game:GetService("DataStoreService")
local Players = game:GetService("Players")
local playerDataStore = DataStoreService:GetDataStore("PlayerCoinsData")

local function saveData(player)
  local success, err = pcall(function()
    playerDataStore:SetAsync(player.UserId, player:GetAttribute("Coins"))
  end)
  if success then
    print("Data saved for " .. player.Name .. ". Coins: " .. player:GetAttribute("Coins"))
  else
    warn("Error saving data for " .. player.Name .. ": " .. err)
  end
end

local function loadData(player)
  local success, savedCoins = pcall(function()
    return playerDataStore:GetAsync(player.UserId)
  end)

  if success then
    if savedCoins ~= nil then
      player:SetAttribute("Coins", savedCoins)
    else
      player:SetAttribute("Coins", 0)
    end
  else
    warn("Error loading data for " .. player.Name .. ": " .. savedCoins)
    player:SetAttribute("Coins", 0)
  end
end

Players.PlayerAdded:Connect(loadData)
Players.PlayerRemoving:Connect(saveData)
Example

Load coins with GetAsync on PlayerAdded, save with SetAsync on PlayerRemoving as shown above.

Misconception

Don't assume SetAsync never fails; handle errors and consider queuing or retrying.

Checklist
  • Wrap GetAsync/SetAsync in pcall
  • Handle nil returns for new players
  • Validate values before saving
Key Takeaway

Always protect Data Store calls with pcall and plan a fallback when network saves fail.
