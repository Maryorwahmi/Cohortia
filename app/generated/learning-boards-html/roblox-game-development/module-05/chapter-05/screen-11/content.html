Operational checklist
Autosave strategy

Save on major events and periodically (e.g., every few minutes), not every action.

Enable API Services

Turn on Studio Access to API Services under Game Settings → Security for testing Data Store calls.

Validate before saving

Ensure OrderedDataStore scores are non-negative integers and that tables are well-formed.

Testing tip

Use multiple Studio server instances to simulate concurrent UpdateAsync calls and check behavior.

Fallback

Add autosaves so PlayerRemoving is not the only moment data is persisted; crashing servers may skip it.

Key Takeaway

Respect rate limits by batching saves and validating data; enable API Services for Studio testing.
