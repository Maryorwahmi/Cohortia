Activity: Build Player Saving & Top 10

Follow these steps to implement and test the full persistence and leaderboard flow.

1 Enable API Services

Turn on Studio Access to API Services under Game Settings → Security before testing.

2 ServerScript: load/save

Implement loadData with GetAsync and saveData with SetAsync, both wrapped in pcall.

3 Use UpdateAsync

Change coin increments to use UpdateAsync with a transform function for safety.

4 OrderedDataStore

Push final coin totals to an OrderedDataStore on PlayerRemoving.

5 RemoteFunction

Create GetLeaderboardData to fetch GetSortedAsync results and return a table of rows.

6 Client UI

LocalScript invokes the RemoteFunction periodically and renders TextLabels in a Frame.

Key Takeaway

This activity builds a safe, testable save/load lifecycle and a server-mediated leaderboard UI.
