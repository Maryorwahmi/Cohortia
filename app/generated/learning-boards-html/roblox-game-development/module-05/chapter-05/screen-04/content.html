Module 5 › Chapter 5.5 › What are Data Stores?
Definition
Data Stores hold persistent player-specific values on Roblox servers. They let you save coins, inventory, and preferences so players return to progress they expect.
Example: Coins

Save a player's coin total under a key like their UserId and load it on join; default to zero if none exists.

Why it matters

Persistent saves enable meaningful progression and fair competition on leaderboards.

Key Takeaway

Treat Data Stores as authoritative server storage for game state that must persist across sessions.

Concrete code example
-- Server-side: load player coins
local DataStoreService = game:GetService("DataStoreService")
local Players = game:GetService("Players")

local playerDataStore = DataStoreService:GetDataStore("PlayerCoinsData")

local function loadData(player)
  local success, savedCoins = pcall(function()
    return playerDataStore:GetAsync(player.UserId)
  end)

  if success then
    if savedCoins ~= nil then
      player:SetAttribute("Coins", savedCoins)
    else
      player:SetAttribute("Coins", 0)
    end
  else
    warn("Error loading data for " .. player.Name .. ": " .. savedCoins)
    player:SetAttribute("Coins", 0)
  end
end

Players.PlayerAdded:Connect(loadData)
Common mistake

Relying on client saves or not handling nil from GetAsync for new players.

Pro tip

Always choose a clear default (e.g., 0 coins) so new players have consistent behavior.
