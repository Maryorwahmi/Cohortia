Module 5 › Chapter 5.5 › What to Remember
Data Stores
Server storage for persistent player data like coins and inventory.
DataStoreService
API used to get named stores via GetDataStore or GetOrderedDataStore.
GetAsync / SetAsync
Read and write values by key; handle nil and wrap calls in pcall.
UpdateAsync
Apply an atomic transform function to safely modify stored values.
pcall
Wrap Data Store calls to capture errors and handle them without crashing.
Rate Limits
Limit request volume by batching saves and choosing sensible update intervals.
Summary

Use DataStoreService methods with pcall and UpdateAsync, validate data, and design a server-mediated leaderboard flow to keep player progress reliable and fair.
