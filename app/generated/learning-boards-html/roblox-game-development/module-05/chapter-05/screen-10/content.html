Module 5 › Chapter 5.5 › Client-server leaderboard
Server: OnServerInvoke handler
getLeaderboardData.OnServerInvoke = function(player)
  local success, pages = pcall(function()
    return leaderboardStore:GetSortedAsync(false, 10)
  end)

  if success then
    local topPlayers = pages:GetCurrentPage()
    local leaderboardTable = {}
    for rank, entry in ipairs(topPlayers) do
      local userId = entry.key
      local score = entry.value
      local playerName = Players:GetNameFromUserIdAsync(userId)
      table.insert(leaderboardTable, {Rank = rank, Name = playerName, Score = score})
    end
    return leaderboardTable
  else
    warn("Error getting leaderboard data for " .. player.Name .. ": " .. pages)
    return {}
  end
end
Client: LocalScript summary

Invoke the server periodically, clear existing UI entries, and create a TextLabel per returned row showing rank, name, and score.

UI behavior & rate limits
  • Request leaderboard data every 15–30 seconds to avoid excessive Data Store calls.
  • Show a placeholder or message when the server returns an empty table.
  • Keep client rendering lightweight—server should resolve names and pack the data.
Key Takeaway

Server mediates Data Store access; clients request compact, ready-to-render leaderboard tables via RemoteFunction.
