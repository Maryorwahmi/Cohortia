01
Differentiate Game Pass vs Product

Learn when to use a Game Pass for permanent ownership and when to use Developer Products for consumables. This matters for player expectations and technical handling.

VERIFIED COMPETENCY MILESTONE
02
Implement Game Pass flow

Prompt purchases on the client and verify ownership on the server with MarketplaceService:UserOwnsGamePassAsync to grant lasting benefits safely.

VERIFIED COMPETENCY MILESTONE
03
Process Developer Products

Use MarketplaceService.ProcessReceipt on the server to grant consumables and return PurchaseGranted when done to avoid retries and duplicates.

VERIFIED COMPETENCY MILESTONE
04
Build idempotent receipts

Record processed PurchaseId values and use pcall for DataStore operations so repeated ProcessReceipt calls don’t grant items twice.
