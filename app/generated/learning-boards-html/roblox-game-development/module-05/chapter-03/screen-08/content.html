Developer Products — concept

Consumable items or one-time benefits that can be purchased multiple times and require server receipt processing.

Use cases: coin packs, temporary boosts, single-use items
Server hook: MarketplaceService.ProcessReceipt
Handle offline players and retries
Example
A Small Coin Pack grants 1000 coins when ProcessReceipt validates the ProductId and grants the coins to the player, returning PurchaseGranted.
Important note

If the player is not found when ProcessReceipt runs, return NotProcessedYet and persist the receipt so you can grant it later when the player joins.

Idempotency reminder

Record PurchaseId values to ensure the same purchase isn't granted twice if the receipt is retried.

Key Takeaway

Developer Products require ProcessReceipt and idempotent processing to be reliable and secure.
