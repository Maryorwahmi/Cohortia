Module 5 › Chapter 5.3 › Prompt Game Pass
Client prompt pattern

Use a LocalScript in StarterGui to call MarketplaceService:PromptGamePassPurchase with the local player and your Game Pass ID.

Code (client)
-- Client-side LocalScript for prompting Game Pass purchase
local MarketplaceService = game:GetService("MarketplaceService")
local Players = game:GetService("Players")
local LocalPlayer = Players.LocalPlayer

local GAME_PASS_ID = 123456789 -- Replace with your actual Game Pass ID

local purchaseButton = script.Parent -- Assuming this script is inside a TextButton

purchaseButton.MouseButton1Click:Connect(function()
  MarketplaceService:PromptGamePassPurchase(LocalPlayer, GAME_PASS_ID)
end)
This code only opens Roblox's purchase dialog. It does not and must not grant any item directly from the client.
Example scenario

A player clicks Buy Double XP. The dialog appears. After purchase, Roblox records ownership so a server check returns true next time the server asks.

Common mistake

Granting the pass on MouseButton1Click after the prompt is insecure; the client can be modified. Always grant server-side after verification.

Key Takeaway

Client scripts initiate purchases. Let the server confirm and apply ownership changes.
