Applied Outcomes

Actionable tasks that turn the concepts into a working monetization flow.

Create assets

Add a Game Pass and a Developer Product in Game Settings and note their IDs for code.

Client UI

Create buttons in StarterGui and attach LocalScripts to call the marketplace prompts.

Server handling

Initialize player attributes and use server-side checks and ProcessReceipt to grant items.

Testing

Use Studio's test purchase system to simulate buys and verify persistence and grants.

Security

Never rely on the client to grant items; always verify on the server and handle retries safely.
