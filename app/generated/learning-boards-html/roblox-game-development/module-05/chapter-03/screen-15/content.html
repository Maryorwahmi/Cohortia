Module 5 › Chapter 5.3 › Key Concepts
Game Pass

Permanent, one-time purchases that grant lasting benefits. Verify ownership server-side.

Developer Product

Consumable items bought multiple times; process with ProcessReceipt and return PurchaseGranted.

Idempotency

Record PurchaseId values and check them to prevent duplicate grants when receipts are retried.

Takeaway

Server authority + idempotent receipts + fair design = reliable monetization.
