Game Passes — concept

Permanent, one-time purchases that grant players lasting benefits across sessions for a single game.

Use cases: VIP areas, permanent boosts, cosmetics
Server check: MarketplaceService.UserOwnsGamePassAsync
Wrap calls in pcall to handle network errors
Example
When a player joins, call UserOwnsGamePassAsync and set player:SetAttribute("HasDoubleXP", true) if they own the pass.
Misconception

Don't trust a client claim of ownership; a player could spoof the client. The server must confirm via MarketplaceService.

Check your understanding

Name one feature in your game that should be a Game Pass and explain how you'd check ownership on player join.

Key Takeaway

Game Passes are permanent; verify on the server and set persistent attributes to apply benefits.
