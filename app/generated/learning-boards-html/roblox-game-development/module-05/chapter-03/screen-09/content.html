Client prompt for Developer Product

Use PromptProductPurchase in a LocalScript to initiate a consumable purchase. The server processes the result.

Code (client)
-- Client-side LocalScript for prompting Developer Product purchase
local MarketplaceService = game:GetService("MarketplaceService")
local Players = game:GetService("Players")
local LocalPlayer = Players.LocalPlayer

local PRODUCT_ID_COINS = 987654321 -- Replace with your actual Developer Product ID

local buyCoinsButton = script.Parent

buyCoinsButton.MouseButton1Click:Connect(function()
  MarketplaceService:PromptProductPurchase(LocalPlayer, PRODUCT_ID_COINS)
end)
Give the player clear feedback that the purchase was initiated, but wait for server confirmation of the grant.
Example

When buying a Small Coin Pack, the dialog confirms the purchase and Roblox triggers ProcessReceipt on the server to grant coins.

Tester tip

Use Studio's test purchase system so you don't spend real Robux while validating flows.

Key Takeaway

PromptProductPurchase starts the purchase; do the granting in ProcessReceipt on the server.
