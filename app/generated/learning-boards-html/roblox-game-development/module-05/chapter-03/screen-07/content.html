Module 5 › Chapter 5.3 › Verify Ownership
Server-side verification

Use a PlayerAdded handler to check ownership with MarketplaceService.UserOwnsGamePassAsync and set persistent attributes like HasDoubleXP.

Code (server)
-- Server-side Script for checking Game Pass ownership and granting benefits
local MarketplaceService = game:GetService("MarketplaceService")
local Players = game:GetService("Players")

local GAME_PASS_ID = 123456789 -- Replace with your actual Game Pass ID

Players.PlayerAdded:Connect(function(player)
  -- Check ownership when player joins
  local success, ownsPass = pcall(MarketplaceService.UserOwnsGamePassAsync, MarketplaceService, player.UserId, GAME_PASS_ID)

  if success and ownsPass then
    print(player.Name .. " owns the Double XP Game Pass!")
    player:SetAttribute("HasDoubleXP", true)
  elseif not success then
    warn("Error checking Game Pass ownership for " .. player.Name .. ": " .. tostring(ownsPass))
  end
end)
This pattern initializes attributes safely and leaves granting decisions to server systems that use those attributes.
Practical guidance
  • Wrap MarketplaceService calls in pcall to handle outages.
  • Set attributes or datastore flags on verified ownership.
  • Log failures for later retries rather than assuming ownership.
Key Takeaway

Server verification is the source of truth. Use attributes to communicate ownership to game systems.
