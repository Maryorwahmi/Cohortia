Activity: Double XP & Coin Pack

Follow these steps in Studio to implement both monetization flows and test them safely.

Step 1 — Create assets
  1. Create Game Pass 'Double XP Pass' and note ID.
  2. Create Developer Product 'Small Coin Pack' and note ProductId.
Step 2 — Client UI

Add two buttons to StarterGui and attach LocalScripts that call PromptGamePassPurchase and PromptProductPurchase.

Step 3 — Server setup

Initialize attributes on PlayerAdded, check Game Pass ownership, and implement ProcessReceipt to grant coins.

Step 4 — Test

Use Studio's test purchase system to simulate buys and confirm persistence and single grants.

Key Takeaway

Complete the steps and then intentionally test edge cases like offline purchases and ProcessReceipt retries.
