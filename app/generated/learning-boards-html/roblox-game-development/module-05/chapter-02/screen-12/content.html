Responsive formula

Scale + Offset + AnchorPoint

Use percentage-based Scale for main sizing and a small pixel Offset to keep minimum readable sizes. AnchorPoint controls the pivot so position stays predictable across size changes.

<!-- Example properties -->
TopBarFrame.AnchorPoint = Vector2.new(0.5, 0)
TopBarFrame.Position = UDim2.new(0.5, 0, 0, 0)
TopBarFrame.Size = UDim2.new(0.8, 40, 0.1, 12) -- scale with minimum offset

-- Wait for PlayerGui and RemoteEvent robustly
local rep = game:GetService("ReplicatedStorage")
local addScore = rep:WaitForChild("AddScoreEvent", 5) -- optional timeout
Device test
Use Emulated Device to test narrow, square, and wide aspect ratios frequently.
Fallback
If WaitForChild times out, show a minimal placeholder UI so the player still has essential info.
Misconception
Offset alone makes fixed-size UIs; on mobiles this causes tiny elements. Prefer Scale for main sizing.
Quick checklist
  • Use Scale for primary sizing.
  • Combine small Offset for minimum sizes.
  • Set AnchorPoint to control pivot.
  • Use WaitForChild for PlayerGui and events.
  • Test multiple Emulated Devices in Studio.
