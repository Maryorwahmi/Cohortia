Verification checklist
  • 1. Add ScreenGui to StarterGui and confirm PlayerGui cloning on play-test.
  • 2. Create TopBarFrame with AnchorPoint (0.5,0) and Size using Scale for width and height percentages.
  • 3. Set HealthLabel and ScoreLabel alignment using TextXAlignment and AnchorPoint patterns.
  • 4. Add ShopButton with a LocalScript toggling ShopPanel via MouseButton1Click and test visibility toggles locally.
Common mistakes
Placing interactive UI logic on the server, over-relying on Offset for layout, and failing to use Frames to group related elements are frequent issues. Use this checklist to catch them early.
