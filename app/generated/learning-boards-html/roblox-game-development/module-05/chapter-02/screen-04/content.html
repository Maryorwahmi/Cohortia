Module 5 › Chapter 5.2 › UI vs UX
Definition and practical test
User Interface = visual elements and controls. User Experience = how intuitively players use those elements. Use quick tests to validate which is which.
Concrete example: a health indicator. UI: a bar and number. UX: placement, contrast, and timing of updates so players react correctly under pressure.
Common misconception
Polish alone doesn't equal good UX. Fancy visuals without clarity still confuse new players. Performance and responsiveness are UX concerns too.
Key Takeaway

Design UI elements that communicate purpose instantly; evaluate them for speed, contrast, and predictability to improve UX.

Analogy
Think of UI as the instrument panel and UX as how easily the pilot reads it under turbulence. Clear grouping and readable labels matter more than decorative elements.
Check your understanding
  • • Can a new player find primary controls within three seconds?
  • • Are interactive elements visually distinct from static text?
  • • Does the UI maintain legibility across small screens?
