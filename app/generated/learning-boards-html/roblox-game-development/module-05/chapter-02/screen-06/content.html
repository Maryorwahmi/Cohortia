Frame as a container
Frames let you group related UI and apply a single transform, size, or visibility toggle to the entire group. This reduces script complexity and helps keep the Explorer organized.
Example TopBarFrame
AnchorPoint = (0.5, 0), Position = UDim2.new(0.5, 0, 0, 0), Size = UDim2.new(0.8, 0, 0.1, 0). Inside: HealthLabel, ScoreLabel.
Use layout objects
UIListLayout and UIPadding help maintain spacing when the parent frame resizes, avoiding manual repositioning of every child element.
Key Takeaway

Frames make UI modular. Group any elements that change together and leverage layout objects to scale gracefully across screens.

Practical scenario
If you want to show a ShopPanel, put the shop's header, item list, and close button in one Frame and toggle that Frame's Visible property. This avoids searching for scattered children in scripts.
Layout snippet (UIListLayout)
-- Inside a Frame named ItemList
local layout = Instance.new("UIListLayout")
layout.Padding = UDim.new(0, 8)
layout.FillDirection = Enum.FillDirection.Vertical
layout.Parent = script.Parent
