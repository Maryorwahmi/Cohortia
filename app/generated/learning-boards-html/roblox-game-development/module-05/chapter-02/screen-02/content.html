Module 5 › Chapter 5.2 › Learning Objectives
01
Understand UI & UX
Define what UI and UX do in a Roblox game and why readable, consistent interfaces keep players engaged. Example: a clearly labeled health bar prevents accidental deaths by signaling low health early.
VERIFIED COMPETENCY MILESTONE
02
Identify core UI elements
Learn ScreenGui, Frame, TextLabel, TextButton, and ImageLabel. Practice placing a ScreenGui under StarterGui and observe how it appears in PlayerGui for each user.
VERIFIED COMPETENCY MILESTONE
03
Responsive layouts with UDim2
Use Scale and Offset in UDim2 to make UI elements adapt to screens. Best practice: Scale for main sizing and Offset for minimum pixel padding.
VERIFIED COMPETENCY MILESTONE
04
Interactive UI & event handling
Wire buttons to LocalScripts using MouseButton1Click to toggle panels or update local displays. Use LocalScripts for per-player UI actions and servers for authoritative state.
VERIFIED COMPETENCY MILESTONE
