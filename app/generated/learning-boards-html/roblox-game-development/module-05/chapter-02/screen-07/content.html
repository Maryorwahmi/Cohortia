Module 5 › Chapter 5.2 › Labels & Buttons
Element roles
TextLabel — display only
Use for non-interactive text like instructions, player names, and labels. Set TextScaled and choose readable fonts for small screens.
TextButton & ImageButton — interactive
Use MouseButton1Click events to trigger LocalScript actions. Provide visual feedback so players know the element is clickable.
Design rule
Keep interactive elements consistent: same corner radius, padding, and color family. Use contrast to separate foreground from background.
Example: Shop button script (LocalScript)
local shopButton = script.Parent
local playerGui = shopButton.Parent
local shopPanel = playerGui:WaitForChild("ShopPanel")

shopButton.MouseButton1Click:Connect(function()
  shopPanel.Visible = not shopPanel.Visible
end)
