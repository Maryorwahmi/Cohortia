Scale vs Offset
Scale is proportional and device-agnostic; Offset is fixed pixels. Prefer Scale for primary sizing so UI adapts across phones and monitors.
UDim2 example
-- Centered Play button
button.AnchorPoint = Vector2.new(0.5, 0.5)
button.Position = UDim2.new(0.5, 0, 0.5, 0)
button.Size = UDim2.new(0.8, 0, 0.2, 0) -- 80% width, 20% height of parent
Common mistake
Using only Offset makes UIs break on different aspect ratios. Test across emulated devices to catch layout breakage early.
Practical checks
  • • Does the element remain readable on the smallest target device?
  • • Does centering remain accurate when the element changes size? If not, adjust AnchorPoint.
  • • Use Offset only to enforce minimum pixel sizes for touch targets.
Key Takeaway

Combine Scale for adaptability with AnchorPoint for reliable pivots; reserve Offset for minor pixel corrections or minimum sizes.
