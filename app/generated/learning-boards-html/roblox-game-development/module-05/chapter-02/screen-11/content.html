Process

Create PlayerHUD in StarterGui

  1. Add ScreenGui named PlayerHUD to StarterGui.
  2. Add Frame named TopBarFrame and set AnchorPoint to (0.5, 0) and Position to UDim2.new(0.5, 0, 0, 0).
  3. Set Size to UDim2.new(0.8, 0, 0.1, 0) so it scales across screens.
  4. Add TextLabels for Health and Score; set TextScaled = true for automatic font scaling.
  5. Add TextButton ShopButton with AnchorPoint (0.5,1) and Position UDim2.new(0.5,0,1,-10).
LocalScript (Shop toggle)
<!-- LocalScript placed inside ShopButton -->
local shopButton = script.Parent
local playerGui = shopButton.Parent
local shopPanel = playerGui:WaitForChild("ShopPanel") -- create this Frame under PlayerHUD

shopButton.MouseButton1Click:Connect(function()
  shopPanel.Visible = not shopPanel.Visible
end)
