Client-side

LocalScript Example

This LocalScript sits inside the TextButton and fires a RemoteEvent to request an action.

<!-- LocalScript inside TextButton -->
local button = script.Parent
local rep = game:GetService("ReplicatedStorage")
local addScore = rep:WaitForChild("AddScoreEvent")

button.MouseButton1Click:Connect(function()
  -- Prevent spam
  button.AutoButtonColor = false
  addScore:FireServer() -- request server to add points
  task.delay(0.2, function() button.AutoButtonColor = true end)
end)
Tip
Debounce clicks to avoid duplicate server events.
Mnemonic
Client requests, server checks, server acts.
Server-side

Server validation

OnServerEvent receives the player as first arg. Validate everything and update server state or leaderstats.

<!-- Script in ServerScriptService -->
local rep = game:GetService("ReplicatedStorage")
local addScore = rep:WaitForChild("AddScoreEvent")

addScore.OnServerEvent:Connect(function(player)
  -- Validate and apply change
  if not player or not player:IsA("Player") then return end
  -- Example: add 10 points to leaderstats safely
  local stats = player:FindFirstChild("leaderstats")
  if stats and stats:FindFirstChild("Score") then
    stats.Score.Value = stats.Score.Value + 10
  end
end)
Common mistake
Trusting client-sent values as-is instead of validating on the server.
Check your work
Log received requests during development to confirm expected arguments and sender identity.
