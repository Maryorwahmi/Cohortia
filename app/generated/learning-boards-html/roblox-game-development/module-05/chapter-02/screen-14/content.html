Module 5 › Chapter 5.2 › Key Concepts
Presentation
LocalScripts handle visual updates and player-specific UI interactions.
Authority
Server Scripts make authoritative changes; always validate client requests there.
Responsive
Use UDim2 Scale for main sizing, AnchorPoint to pivot, and a small Offset for minimum sizes.
Takeaway

Design UI that is responsive, secure, and split correctly between client presentation and server authority.
