Security settings
Which toggles enable platform features and why testing is essential.
API Services
Enables DataStoreService, remote events, and other server APIs. Disable only if you intentionally avoid these services.
Allow HTTP Requests
Allows HttpService to reach external APIs. Only enable when needed and secure endpoints properly.
Third-party teleports
Control whether players can be teleported to other experiences. Set according to cross-game design.
Example: DataStore failure
A save system that appears to work locally but doesn't persist across sessions when API Services are disabled.
-- Pseudocode: Save a player's high score
local DataStoreService = game:GetService("DataStoreService")
local highScore = DataStoreService:GetDataStore("HighScores")

local function saveScore(player, score)
  local key = "score_" .. player.UserId
  highScore:SetAsync(key, score)
end

-- If API Services are off, SetAsync will fail silently or error at runtime.
Key Takeaway

Enable necessary APIs before launch and run a test account to verify save and server features actually work in the live environment.
