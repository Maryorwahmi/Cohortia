Objectives — Skills and Verification
Complete tasks and confirm outcomes with simple milestones.
Publish & Metadata
Create new game, set name, description, and genre.
Verification: Your game appears in Studio's My Games and opens in browser when Access is Public.
Game Settings Config
Enable Premium Payouts, confirm Developer Products, and check Security toggles.
Verification: API Services enabled and developer product IDs are set as intended.
Promotion Plan
Draft organic outreach and at least one thumbnail idea.
Verification: Post a short announcement in a Group or on the Developer Forum.
Community Welcome Script
Implement the provided RemoteEvent welcome flow.
Verification: A joining player receives the welcome message and group invite notice.
Verified Competency Milestone
Complete one publish action, configure Access to Public, and run the welcome-message flow to validate live behavior.
