Publish process
A reliable sequence to make your place available.
1. Save and prepare metadata
Give a clear name, description, and choose a genre so players know what to expect.
2. File → Publish to Roblox As...
Select Create New Game for first publish. Watch for the confirmation dialog.
3. Verify Access and visuals
New games are Private by default. Change to Public and confirm icon/thumbnail.
Common mistake: assuming publish automatically makes the game joinable. Always check Access.
Example: First publish
A short scenario showing the effect of metadata and privacy on discovery.
Game title: My Cozy Puzzle
Description: A calm tile-matching puzzle with daily challenges.
Outcome: With a clear icon and Public access the game saw more clicks than a generic listing.
Key takeaway
Key Takeaway

Publishing uploads your place, but only changing Access to Public and checking visuals makes it discoverable and playable.
