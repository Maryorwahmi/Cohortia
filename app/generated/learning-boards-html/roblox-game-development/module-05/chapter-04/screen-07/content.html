Module 5 › Chapter 5.4 › Monetization Options
Monetization at a glance
Match the revenue model to the gameplay feature.
Premium Payouts
Enable to earn from Premium players' engagement. Useful for long-play games.
Developer Products
Consumable items that players can buy repeatedly, like boosts or consumables.
Game Passes
One-time purchases that grant persistent perks or access to areas.
Practical example
A seasonal cosmetic sold as a Game Pass vs a Developer Product decision.
Scenario: holiday hat
If the hat should be bought once and kept, use a Game Pass. If it’s a consumable token exchanged repeatedly, use a Developer Product.
Key Takeaway

Enable the monetization options that suit your game and implement product IDs correctly in scripts. Monetization requires both settings and in-game implementation.
