Module 5 › Chapter 5.4 › Learning Objectives
Learning Objectives
Master the publish flow, settings, promotion, and community upkeep.
01
Publish a game
Create a new game in Studio and adjust name and description.
You will publish a project and verify that it’s discoverable. milestone: change Access to Public and save settings.
02
Configure Game Settings
Permissions, Monetization, Security, Avatar options.
You’ll learn which toggles enable APIs and monetization. milestone: enable Premium Payouts or verify API access.
03
Promote your game
Paid ads and organic discovery strategies.
You’ll plan at least two organic promotion channels. milestone: draft a short trailer idea or thumbnail concept.
04
Engage the community
Feedback loops, updates, and events.
You’ll prepare a brief outreach plan and an update cadence. milestone: write a 1-paragraph outreach plan.
Bloom: Learn → Understand → Apply → Master
