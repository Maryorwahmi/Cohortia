Module 1 › Chapter 1.1 › Publish to Roblox
Publish Steps
1. Choose File → Publish to Roblox As.
2. Click Create New Game and enter a name and description.
3. Set Privacy to Private for development, then click Create Game.
4. Confirm the place appears under My Games in Studio after reopening.
Example: Create My First Cohortia Project as Private. Reopen Studio and see it listed under My Games to confirm the upload succeeded.
Common Mistake
Accidentally publishing as Public exposes unfinished work. Always verify the Privacy dropdown before creating the game.
Key Takeaway
Publishing privately preserves your development state in the cloud and enables testing across devices while keeping the place hidden from the public.
