Learning Objectives
Practical skills to install, navigate, create, and publish your first Roblox place.
01
Install & Launch
Download Roblox Studio and sign in to your Roblox account so Studio links to your profile.
VERIFIED COMPETENCY MILESTONE
02
Identify Core Panels
Know Viewport, Explorer, Properties and Toolbox and why each matters while building.
VERIFIED COMPETENCY MILESTONE
03
Create Baseplate Project
Start with the Baseplate template for a simple, clean workspace to learn building basics.
VERIFIED COMPETENCY MILESTONE
04
Save & Publish
Save to .rbxl locally and publish the place privately to access it from other devices.
VERIFIED COMPETENCY MILESTONE
Bloom's taxonomy

Each objective is paired with a hands-on check: install Studio, create a Baseplate, inspect the Properties of a part, then save and publish privately so you can open the same place later.
Tip: If you can complete all milestones in order, you’ve established a solid workflow to continue building.
