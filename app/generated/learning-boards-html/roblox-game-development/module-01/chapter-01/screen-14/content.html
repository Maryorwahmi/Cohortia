Module 1 › Chapter 1.1 › Key Concepts
Roblox Studio
The integrated environment for building, scripting, testing, and publishing games.
Explorer & Properties
Explorer shows object hierarchy; Properties lets you edit attributes of the selected object.
Save (.rbxl) vs Publish
Save locally as .rbxl for backups; publish to Roblox to store your place in the cloud and enable testing across devices.
Summary

Mastering installation, the core panels, Baseplate workflow, and the save/publish distinction will let you start building and testing your first Roblox place confidently.
