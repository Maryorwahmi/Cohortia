Verify Your Setup
Quick tests to confirm each objective is complete.
  • Install: Launch Studio and see the home screen. If Studio fails, check internet or your Roblox account status.
  • Panels: Select Baseplate in Explorer and confirm Properties changes, proving you can locate and edit objects.
  • Project: Create Baseplate and confirm empty world with a flat ground part — ideal for learning to build.
  • Save & Publish: Save locally to an .rbxl file then publish as Private and verify it appears in My Games.
Checklist
If Studio won’t open
Common causes: missing internet, not signed in, or blocked installer. Try restarting and signing in again.
If publish fails
Ensure you are signed in and choose Create New Game with Privacy set to Private, then try again.
Use these checks every time you start Studio to avoid losing work and to maintain a stable development workflow.
