Create Project: Step Sequence
1. From Home click New and choose Baseplate.
2. Wait for Studio to load the workspace and render the Viewport.
3. Open Explorer and locate Workspace → Baseplate.
4. Select Baseplate and observe Properties: size, color, and material fields.
Example
Selecting Baseplate updates Properties so you can change color or scale; this confirms object selection works end-to-end.
Why Baseplate first
A minimal environment reduces cognitive load. You can intentionally add parts and scripts while knowing the default state.
Key Takeaway
Follow the New → Baseplate sequence and confirm object selection by checking Properties for the Baseplate part.
