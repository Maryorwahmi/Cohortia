Module 1 › Chapter 1.1 › Templates Comparison
Baseplate
A single flat ground part that gives you a neutral canvas for building.
Simplicity: minimal objects, easy to inspect Explorer and Properties.
Ideal for: learning placement, parts, and basic scripting without distractions.
Example: Select the Baseplate in Explorer to see its size and color in Properties.
Pre-built Templates
Classic Obby, Village, and others contain models and scripts to demonstrate game types.
Benefit: see finished examples of gameplay and structure.
Pitfall: hidden scripts or crowded Explorer can confuse beginners.
When to use: explore after you understand basic panels and object relationships.
Key Takeaway
Start with Baseplate to learn the environment clearly. Use templates later to study real project structure.
