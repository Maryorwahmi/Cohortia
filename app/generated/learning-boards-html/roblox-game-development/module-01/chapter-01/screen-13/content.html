Module 1 › Chapter 1.1 › Setup Challenges
Installer Issues
Blocked by security or incomplete download.
Fix: temporarily allow installer in security settings and re-run.
Sign-in Problems
Incorrect credentials or network connectivity.
Fix: verify credentials, check internet, complete two-step verification if required.
Publish Failures
Privacy or account linking issues can block publish.
Fix: ensure Privacy is set to Private and re-sign-in before publishing.
Mini Checklist
Before saving or publishing, confirm: 1) active internet connection, 2) Studio shows your signed-in account, 3) Privacy is set to Private when creating the game.
