Module 2 › Chapter 1.3 › Inspecting Model Contents
Walkthrough: Explorer Check
  1. Insert the model into the Viewport.
  2. Open Explorer and find the inserted model under Workspace.
  3. Expand the model and scan for Script or LocalScript objects.
  4. If a script is unexpected or suspicious, delete it or remove the whole model.
  5. Rename the model descriptively after inspection.
Explorer Example Structure
Workspace
  OakTree1 (Model)
    Trunk (Part)
    Leaves (MeshPart)
    Script (Script)  -- <-- unexpected script: inspect or delete
If you find a script like the example above and you didn't expect any runtime logic, delete it immediately. Testing in a new place is a safe isolation step.
