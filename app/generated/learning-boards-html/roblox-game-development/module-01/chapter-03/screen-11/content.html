Module 2 › Chapter 1.3 › Organizing the Explorer
Organizer Steps
  1. Right-click Workspace > Insert Object > Folder.
  2. Name the folder (e.g., 'Scenery', 'Furniture', 'Buildings').
  3. Drag related models into the appropriate folders.
  4. Rename models to descriptive names after inspection.
Concrete Example
Create 'Scenery' folder and move 'OakTree1' and 'RockA' into it. Create 'Furniture' and move 'Bench_Plaza' there. This makes the Explorer readable and scripting access predictable.
Key Takeaway

Organize assets immediately; it prevents a cluttered workspace and saves time when you or a teammate return later.
