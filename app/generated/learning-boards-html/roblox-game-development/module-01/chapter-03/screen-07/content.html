Module 2 › Chapter 1.3 › Asset Safety
What to Watch For
  • Unexpected Script objects inside a Model’s hierarchy.
  • Scripts with suspicious names like promises of free currency or admin bypasses.
  • Scripts located inside parts that should only contain geometry.
Immediate Action
Delete suspicious scripts. If unsure, delete the entire model or test it in a new empty place first.
Concrete Example
Insert an 'Admin' model that adds a Script called 'VirusDetectorBypass' deep in its hierarchy. Delete that script and consider removing the model entirely; it’s almost certainly malicious.
Misconception check: Popular models are not always safe—popularity may mask scripts that benefit the uploader or exploit games.
