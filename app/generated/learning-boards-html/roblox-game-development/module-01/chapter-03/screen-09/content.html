Why Test Separately?
Testing in a new place isolates potential side effects and prevents malicious scripts from altering your main project. It’s a low-cost practice that reduces risk.
Steps
  1. Create a new empty place in Studio.
  2. Insert the asset and expand its Explorer structure.
  3. Run the place and observe runtime behavior.
  4. If safe, copy or reinsert into your main project and rename it.
Concrete Scenario
You find a sophisticated vehicle model. Insert it into an empty place, run the game, and check that no unexpected scripts spawn objects or modify services. Only after inspection should you add it to your city project.
