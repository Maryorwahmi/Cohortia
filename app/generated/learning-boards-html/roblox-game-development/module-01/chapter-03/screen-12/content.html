Module 2 › Chapter 1.3 › Guided Lab
Step Checklist
  • Open Toolbox and search 'tree' — insert 2 models.
  • Search 'bench' and insert one bench; search 'rock' and insert a few rocks.
  • Expand each model in Explorer and delete unexpected Script objects.
  • Create 'Scenery' and 'Furniture' folders under Workspace and drag models into them.
  • Apply a Decal to a Block Part and insert a short Audio asset to observe their Explorer entries.
  • Save locally and publish privately.
Safety Reminder
If a model promises admin tools or currency, delete it. Test unfamiliar assets in a new place before adding to your main project.
Reflection
After completing this lab, ask yourself whether each inserted model was inspected and renamed, and whether folder organization makes sense for future editing.
