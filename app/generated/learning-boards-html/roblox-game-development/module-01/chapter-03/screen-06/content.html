Module 2 › Chapter 1.3 › Asset Types Compared
Models
Grouped parts useful for scenery and props. May include scripts—inspect after insertion.
Use it when you need multiple parts to act together and be easy to edit.
Decals
2D images applied to Parts. Good for signs, textures, or art where geometry is unchanged.
Example: a 'No Swimming' sign applied to a wall Part.
Audio
Sound files that appear as Audio objects in Explorer. Use for effects and background music.
Example: insert a chime sound for level completion.
Meshes
Imported detailed geometry from external software. Offers fidelity but may need optimization.
Misconception: meshes always improve performance; sometimes a grouped parts model is lighter.
Plugins
Studio extensions that add editor capabilities. Not runtime game objects.
Use for custom tooling, not for in-game content.
Key Example
Decal for a billboard image, Model for a bus, Audio for a horn, Mesh for a sculpted statue, Plugin for batch-renaming parts.
