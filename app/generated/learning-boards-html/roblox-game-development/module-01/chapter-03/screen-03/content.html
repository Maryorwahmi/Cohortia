Module 2 › Chapter 1.3 › Learning Objectives
Quick Verification
  • Open Toolbox from the View tab and find at least two model thumbnails for a search term.
  • Insert models and use Move, Scale, Rotate to position them naturally.
  • Expand each model in Explorer and scan for unexpected Script objects; delete if suspicious.
  • Create 'Scenery' and 'Furniture' folders and drag models into the correct folders.
Why These Checks Matter
These steps protect your project from malicious code and keep the Workspace navigable so changes are easy to find later. Make them part of your insertion routine every time.
Practice Tip
When in doubt about a model, test it in a new empty place first. This isolates potential problems without risking your main project.
