Module 1 › Chapter 1.2 › Learning Objectives
Transformation Tools
Select — Ctrl/Cmd + 1
Pick objects and confirm selection via a bounding box in the Viewport.
Move — Ctrl/Cmd + 2
Reposition along X, Y, Z using colored arrows or the center for planar movement.
Scale & Rotate
Scale — Ctrl/Cmd + 3
Adjust dimensions per-axis or uniformly with spheres on faces and corners.
Rotate — Ctrl/Cmd + 4
Spin parts around X, Y, Z axes using colored rotation rings; orientation is in degrees.
Properties & Grouping
Name, Position, Size, Orientation, Color, Material, Transparency, Anchored
Set Anchored true for static structures; group parts into a Model to move them together. Verify by running the game.
VERIFIED COMPETENCY MILESTONE
Practical Habit
Always confirm the active tool in the ribbon, name parts clearly in Explorer, and check Anchored before testing. These habits cut debugging time.
