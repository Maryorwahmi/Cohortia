Hands-on Activity

Build a Simple Anchored Structure

Follow steps to insert a Block, Cylinder and Sphere, manipulate them, group into a Model and run Play to verify behavior.

Step 1 — Insert & Name
Insert Block, Cylinder, Sphere. Rename FloorTile, Pillar, Orb in Explorer to stay organized.
Step 2 — Transform & Material
Scale the block to be a floor tile, set Material to Concrete, pillar to Wood, orb to Neon. Adjust colors as described.
Step 3 — Anchor & Group
Set Anchored=true on each part, group them into a Model, then press Play to test. If it falls, check Anchored again.
Checkpoints
Camera
Use F to focus each part and orbit to confirm placement.
Selection & Tools
Ensure the correct tool is active before transforming — Select, Move, Scale, Rotate.
Run Test
Press Play. If parts fall, stop and verify the Anchored property for each part; fix and re-test.
Learning Check

If your assembled Model stays intact during Play, you have confirmed tool fluency and property control.
