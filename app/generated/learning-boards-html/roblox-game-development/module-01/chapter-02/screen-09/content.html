Core Concept

Coordinate System

Red = X (left-right), Green = Y (up-down), Blue = Z (forward-backward). Gizmos use these colors to guide precise transforms.

Orientation Values
Orientation lists degrees rotated around X, Y, Z. Small angle changes often produce the desired visual effect.
Camera & Screen
Camera rotation changes screen directions; rely on gizmo color coding, not screen left-right, for accurate transforms.
