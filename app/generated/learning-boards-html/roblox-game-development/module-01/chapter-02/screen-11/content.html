Core Concept

Anchored

Anchored = true fixes a part; Anchored = false allows physics to move it. This determines whether structures remain in place during Play.

Failure Example
A tower built of Blocks collapses during Play because Anchored=false. Fix: set Anchored=true for static pieces.
When Not to Anchor
Vehicles, physics toys and falling props should remain unanchored so the physics engine can move them naturally.
Pro Tip
If a structure falls, first inspect Anchored for all its parts before deep debugging. It often fixes the problem instantly.
Actionable Steps
Select All Parts
Hold Ctrl/Cmd and click each part or drag a selection box.
Set Anchored
In Properties, toggle Anchored to true for static pieces.
Group If Needed
Group parts into a Model to move them together; the group's composition retains each child's Anchored value.
Common Mistake

Anchoring everything prevents intended physics behaviors. Decide per-object whether it should be static or dynamic.
