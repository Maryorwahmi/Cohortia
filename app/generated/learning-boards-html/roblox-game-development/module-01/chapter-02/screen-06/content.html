Definition

Select Tool

Select highlights parts and shows a bounding box and available gizmos. Use Explorer or Viewport clicks. Shortcut: Ctrl/Cmd + 1.

Visual Confirmation
The bounding box and gizmos tell you precisely which part(s) are selected. If it’s wrong, deselect and pick again.
Multiple Selection
Hold Ctrl/Cmd and click parts or drag a selection box to select many. Transforms affect the combined selection.
Common Mistake
Assuming Explorer selection is visible; hidden children may be selected. Use F to focus and confirm.
Example Workflow
Step A — Select via Explorer
Click a part name in Explorer, then press F. The Viewport will frame the part so you can verify selection visually.
Step B — Select in Viewport
Click directly on a part in the Viewport. Look for the bounding box, then confirm before moving or rotating.
Step C — Multi-select
Hold Ctrl/Cmd to pick multiple parts, or drag to draw a selection box around many parts, then group if needed.
Check Before Transforming
Look for gizmo arrows or rings — these appear only when selection is active and the correct tool is chosen.
