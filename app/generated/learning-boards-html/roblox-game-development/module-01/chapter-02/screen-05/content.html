Definition

Parts — the building blocks

Parts are the atomic 3D objects used to build every static and interactive element. Each part has properties that control appearance and behavior.

Common Shapes
Block, Sphere, Cylinder, Wedge and CornerWedge. Insert via the Model tab.
Naming Best Practice
Give parts descriptive names like FloorTile, MainWall or Pillar so you can find and focus them quickly with the Explorer.
Concrete Example
Insert a Block, rename it FloorTile, set Material to Concrete, color to dark grey, scale it wide and flat. This becomes a reusable floor element.
Visual: Part Types
Block
Default rectangular prism used for floors and walls.
Sphere
Smooth round object for decorative elements or indicators.
Cylinder
Good for pillars and rounded supports.
Wedge / CornerWedge
Use for ramps, slopes and trimmed corners.
Common Mistake
Assuming one complex Part replaces a group of simple parts. Complex shapes are usually groups of simple parts arranged together.
