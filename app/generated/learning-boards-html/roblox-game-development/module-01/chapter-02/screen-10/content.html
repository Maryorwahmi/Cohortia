Definition

Properties Window

Edit attributes to control appearance and behavior. Numeric fields enable precise, repeatable values for size and position.

Name & Position
Name parts clearly; use Position to place objects precisely by X, Y, Z coordinates.
Size & Orientation
Size is width/height/depth; Orientation is rotation in degrees around each axis.
Visual & Physics
Color and Material affect look; Anchored toggles physics participation. Transparency controls visibility.
Practical Example
Create a Stable Floor Tile
Insert a Block, set Size to 4 × 0.25 × 4, Material to Concrete, Color to dark grey, Anchored to true. This prevents it from falling during Play.
Check Anchored
Before pressing Play, confirm Anchored=true for static structures; forgetting this causes collapses and wasted debugging time.
Numeric Precision
Enter exact Position and Size values in Properties to reuse placements across parts and scenes.
Key Takeaway

Properties let you control both what a part looks like and how it behaves. Anchored is crucial for static pieces.
