Module 3 › Chapter 3.3 › Animator Integration
Script hooks
private Animator animator;

void Start()
{
  rb = GetComponent();
  animator = GetComponent();
}

void FixedUpdate()
{
  animator.SetFloat("Speed", Mathf.Abs(moveInput));
  animator.SetBool("IsGrounded", isGrounded);
}
Animator tips
  • Use absolute speed to avoid negative thresholds.
  • Set small transition thresholds (e.g., 0.1) to prevent rapid flicker between states.
  • Use IsGrounded to separate jump/fall from run/idle.
Takeaway
Keep animation parameters simple; treat animation as a reflection of movement state, not the source of truth.
