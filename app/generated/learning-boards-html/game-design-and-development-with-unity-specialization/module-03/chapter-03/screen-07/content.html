Ground check code
public Transform groundCheck;
public LayerMask groundLayer;
private bool isGrounded;

void FixedUpdate()
{
  isGrounded = Physics2D.OverlapCircle(groundCheck.position, 0.2f, groundLayer);
}

void Update()
{
  if (Input.GetButtonDown("Jump") && isGrounded)
  {
    rb.velocity = new Vector2(rb.velocity.x, jumpForce);
  }
}
Practical notes
  • Position groundCheck at the feet; a Y offset like -0.5 often works.
  • Use a small radius (e.g., 0.2) to avoid detecting walls or nearby objects.
  • Set groundLayer in the Inspector to include only ground colliders.
Common mistake
Forgetting to assign groundLayer causes isGrounded to always be false, so the player can never jump.
