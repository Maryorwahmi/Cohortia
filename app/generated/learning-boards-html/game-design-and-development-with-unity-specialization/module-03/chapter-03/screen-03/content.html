Objective: Scene Setup
Create a GroundCheck child, assign it near the player's feet, and set the groundLayer mask to include only your ground objects. This prevents missed ground detections and accidental triggers from non-ground colliders.
Inspector Tip
Expose moveSpeed and jumpForce as public variables so designers can tune feel without code changes.
Objective: Avoid Physics Bugs
Freeze Z rotation to stop tumbling, and avoid setting transform.position directly on physics objects. Use Rigidbody2D methods and properties for consistent, solver-friendly updates.
Common Pitfall
Using the wrong layer or an incorrect OverlapCircle radius often makes isGrounded always false. Verify both in the Inspector and Scene view.
