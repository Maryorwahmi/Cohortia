Why freeze rotation?

In a 2D platformer, uncontrolled rotation makes collisions unpredictable and the player sprite visually disorienting. Freezing Z rotation keeps the character upright and simplifies collision responses.

How to set
Inspector: Rigidbody2D → Constraints → Freeze Rotation Z. In code: rb.constraints = RigidbodyConstraints2D.FreezeRotation;
Notes
  • Use constraints to protect desired degrees of freedom.
  • If rotation is part of gameplay, separate rotating visuals from main collider or body.
Takeaway
A single checkbox can prevent many physics-related control bugs in a 2D player character.
