Module 3 › Chapter 3.3 › Key Concepts
Input.GetAxis
Continuous values from -1 to 1 for smooth horizontal control.
Input.GetButtonDown
Detects a one-shot press; sample in Update and queue for FixedUpdate.
Rigidbody2D.velocity
Directly set linear velocity for precise movement while keeping physics interactions.
Summary Takeaway
Keep input polling and physics updates separated, use a small, well-placed ground check with a LayerMask, and prefer velocity for tight platformer control unless you need emergent physics.
