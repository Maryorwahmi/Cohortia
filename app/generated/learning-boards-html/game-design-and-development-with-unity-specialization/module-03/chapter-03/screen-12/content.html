Quick diagnosis checklist
  • Are you setting transform.position anywhere? Remove it for physics objects.
  • Is GetButtonDown read only in FixedUpdate? Move it to Update and queue the request.
  • Is the Ground layer correctly set on ground colliders and groundLayer mask in Inspector?
  • Is Z rotation frozen to prevent tumbling?
Debugging tools
Use OnDrawGizmos to draw the OverlapCircle and visually confirm ground detection. Add debug logs for isGrounded and moveInput when testing tricky scenarios.
Pro tip
Temporarily expose isGrounded in the Inspector for live testing to see when the script considers the player grounded.
