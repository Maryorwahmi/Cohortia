Module 3 › Chapter 3.3 › velocity vs AddForce
Direct Velocity
Immediate control and easier tuning for platformer jumps and precise horizontal speeds.
// Immediate jump
rb.velocity = new Vector2(rb.velocity.x, jumpForce);

// Precise horizontal speed
rb.velocity = new Vector2(moveInput * moveSpeed, rb.velocity.y);
AddForce
Impulse-based interaction where forces accumulate. Best for explosions, knockback, or physicsy movement.
// Impulse jump or knockback
rb.AddForce(Vector2.up * force, ForceMode2D.Impulse);
Design choice
Pick velocity when you need consistent, frame-aligned motion; pick AddForce when interactions should feel emergent.
