Flip logic
if (moveInput > 0)
{
  transform.localScale = new Vector3(Mathf.Abs(transform.localScale.x), transform.localScale.y, transform.localScale.z);
}
else if (moveInput < 0)
{
  transform.localScale = new Vector3(-Mathf.Abs(transform.localScale.x), transform.localScale.y, transform.localScale.z);
}
Notes
Flipping localScale mirrors sprites and colliders. If certain children should not flip, handle them separately or adjust their localScale after flipping.
Tip
Use absolute values when flipping to avoid multiplying negative scales over time.
