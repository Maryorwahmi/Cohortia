Module 3 › Chapter 3.3 › GroundCheck Setup
Step-by-step
  1. Create empty child named GroundCheck under Player.
  2. Position it around the player feet, e.g., Y = -0.5 relative.
  3. Create a Ground layer and assign it to floor objects.
  4. Drag GroundCheck into the script slot and set groundLayer in Inspector.
  5. Test with small OverlapCircle radius and adjust if needed.
Verification
Use OnDrawGizmos to visualize the check in the Editor. If ground overlaps are inconsistent, verify that other colliders or triggers are not interfering and confirm the layer assignment.
Takeaway
Scene and layer setup are as important as code. The correct Ground layer plus a properly placed GroundCheck yields stable jump gating.
