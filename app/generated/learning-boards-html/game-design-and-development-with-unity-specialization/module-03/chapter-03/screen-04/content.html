Module 3 › Chapter 3.3 › Input & Movement
Definition

Axis → Velocity

Use Input.GetAxis("Horizontal") to read direction and scale that value by moveSpeed, then set the Rigidbody2D velocity on the physics tick.

Key points
  • Axis returns -1..1 for left/right input sources.
  • Multiply by moveSpeed to compute horizontal velocity.
  • Apply in FixedUpdate to keep physics consistent.
Example
If axis=0.8 and moveSpeed=5, set velocity.x to 4 so the body moves right with that linear speed.
Readable Code Snippet
void FixedUpdate()
{
  float moveInput = Input.GetAxis("Horizontal");
  rb.velocity = new Vector2(moveInput * moveSpeed, rb.velocity.y);
}
Misconception
Setting transform.position appears simple, but it bypasses the physics solver and can cause clipping or tunneling when collisions occur.
Takeaway
Use axis→velocity in FixedUpdate and preserve rb.velocity.y so gravity and jumps remain intact.
