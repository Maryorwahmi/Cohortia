Learning Objectives
Learn the components and skills to implement 2D physics and collisions.
Bloom: Learn → Understand → Apply → Master
01
Configure Rigidbody2D
Set body type, mass, drag and gravity scale for motion control.
Mnemonic: think "weight and response" — mass affects inertia, gravity scale affects fall speed.
VERIFIED COMPETENCY MILESTONE
02
Choose Collider2D types
Use box, circle, polygon, or edge colliders according to shape and performance needs.
Mnemonic: simple shapes first; polygon only when outline precision matters.
VERIFIED COMPETENCY MILESTONE
03
Apply Physics Material 2D
Adjust friction and bounciness to shape surface interactions.
Mnemonic: ice = low friction, trampoline = high bounciness.
VERIFIED COMPETENCY MILESTONE
04
Handle collision and trigger callbacks
Implement OnCollisionEnter2D and OnTriggerEnter2D correctly and know the Rigidbody requirement.
Mnemonic: collisions = physics response; triggers = detection only.
VERIFIED COMPETENCY MILESTONE
