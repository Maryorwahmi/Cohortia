Collision callbacks
Use these for physical responses like landing, bouncing, or taking damage on impact.
  • OnCollisionEnter2D fires on contact start.
  • OnCollisionStay2D while contact persists.
  • OnCollisionExit2D when contact ends.
Key Takeaway

Collisions are for physical interaction. Use the Collision2D data to inspect contact points and the other GameObject.

Example script snippet
// OnCollisionEnter2D example
void OnCollisionEnter2D(Collision2D collision)
{
  Debug.Log("Collided with: " + collision.gameObject.name);
  if (collision.gameObject.CompareTag("Ground"))
  {
    Debug.Log("Player landed on ground!");
  }
}
Use collision.gameObject to check tags or components. Inspect collision.contacts for normals if you need directional responses.
Misconception
Collision callbacks will not fire if both colliders are static or if layer settings prevent the collision. Ensure at least one Rigidbody2D exists.
