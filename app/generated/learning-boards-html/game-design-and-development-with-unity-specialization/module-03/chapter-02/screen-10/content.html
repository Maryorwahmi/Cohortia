Which objects need a Rigidbody2D?
The presence of a Rigidbody2D determines whether Unity treats colliders as dynamic or static for events.
Both static colliders
No Rigidbody2D on either -> no collision callbacks; objects just overlap visually.
One with Rigidbody2D
Callbacks fire; common for player vs ground.
Both with Rigidbody2D
Both simulated; collisions cause physical response on both bodies.
If you see missing events, check the Rigidbody presence and the layer collision matrix in Project Settings > Physics 2D. Temporarily adding a Rigidbody2D to the suspected static object is a fast way to isolate the issue.
Debugging Tip

Add Rigidbody2D temporarily or toggle layer collisions to verify why an expected event didn't fire.
