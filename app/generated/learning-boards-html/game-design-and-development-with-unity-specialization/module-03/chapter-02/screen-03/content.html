Hands-on steps
Editor and scripting tasks to complete in your project.
Create Ground
  • Add GameObject, BoxCollider2D, optional Rigidbody2D set to Static.
  • Tag as "Ground" for collision checks.
Player Physics
  • Add Rigidbody2D, set Gravity Scale, freeze Z rotation, add BoxCollider2D.
  • Tune mass and drag for desired feel.
Collectible
  • Use CircleCollider2D with Is Trigger checked and a script using OnTriggerEnter2D to collect.
Material & Layers
  • Create Physics Material 2D assets for ice or trampolines and verify layer collision matrix to avoid unwanted contacts.
