Trigger detection
Use triggers to detect overlaps like pickups and zones without physical blocking.
  • Enable "Is Trigger" on a Collider2D to make it a sensor.
  • OnTriggerEnter2D is called when overlap begins; OnTriggerExit2D when it ends.
  • At least one collider must have a Rigidbody2D for events to fire.
Key Takeaway

Triggers are detection-only and do not produce physical responses; use them for pickups and sensors.

Example script
// OnTriggerEnter2D example
void OnTriggerEnter2D(Collider2D other)
{
  Debug.Log("Triggered by: " + other.gameObject.name);
  if (other.gameObject.CompareTag("Coin"))
  {
    Debug.Log("Coin collected!");
    Destroy(other.gameObject);
  }
}
Attach this to the player. Ensure the coin has Is Trigger checked and that either coin or player has a Rigidbody2D.
Pitfall
If no Rigidbody2D is present on either object, trigger events will not fire. Add a Rigidbody2D to at least one object.
