Physics Material 2D
Paint surface behavior using friction and bounciness.
Friction
Controls sliding resistance. Low values create slippery surfaces; high values prevent sliding.
Bounciness
Controls rebound energy. Values near 1 keep energy; near 0 absorb energy.
Creation & application
Create a Physics Material 2D asset in the Project window and assign it to any Collider2D component in the Inspector.
Example
Create a bouncy platform material and apply it to a platform to see the player rebound on landing.
Warning
High bounciness with low mass can cause unstable behavior. Tune mass and bounciness together.
Key Takeaway

Materials let you craft sliding and springy surfaces. Adjust gradually and test interactions between colliders.
