Choose components for scenarios
Three short scenario prompts to reason about Rigidbody and collider selection.
1) Crates pushed by player
Answer: both player and crates need Rigidbody2D + Collider2D; Dynamic body type allows pushing and realistic response.
2) Scripted moving platform
Answer: platform uses Kinematic Rigidbody2D moved in FixedUpdate with MovePosition; player remains Dynamic to be affected by collisions.
3) Decorative background objects
Answer: leave them as static colliders or remove colliders entirely if no physics needed to save performance.
Reflect

When you choose a body type, consider both gameplay behavior and CPU cost. Ask: will this object be moved by physics or by script?
