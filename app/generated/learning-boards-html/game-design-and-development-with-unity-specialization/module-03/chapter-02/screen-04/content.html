Rigidbody2D overview
Gives objects physical properties like mass, gravity, and velocity.
Body Types
  • Dynamic: affected by forces and collisions — use for players and movable objects.
  • Kinematic: moved by script, not by forces — use for moving platforms.
  • Static: immovable, best for ground and walls.
Important properties
Mass, Linear Drag, Gravity Scale and Constraints (freeze rotation Z to prevent spin).
Common mistake
Moving a Rigidbody by setting transform.position causes jitter and breaks the physics solver. Use Rigidbody2D velocity, AddForce, or MovePosition in FixedUpdate instead.
Concrete example
Player object: add Rigidbody2D, set Body Type to Dynamic, set Gravity Scale to 3 for snappier falls, and freeze Z rotation. Use BoxCollider2D sized slightly smaller than sprite for forgiving collisions.
Key Takeaway

Rigidbody2D enables realistic motion and collision callbacks; choose body type to match intended behavior and update physics properties in FixedUpdate.

Try this
Add Rigidbody2D to your player and increase Gravity Scale from 1 to 3. Observe fall speed change.
Check
If the player spins on impact, enable Freeze Rotation Z in Constraints.
