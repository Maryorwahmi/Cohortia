Module 3 › Chapter 3.2 › Platformer Activity
Activity steps
Follow these editor actions and test in Play mode.
1) Create Ground
Empty GameObject → BoxCollider2D → optional Sprite Renderer. Tag as Ground.
2) Player setup
Add Rigidbody2D (Dynamic), Gravity Scale=3, BoxCollider2D, Freeze Rotation Z.
3) Coin
Add CircleCollider2D set as Is Trigger, add Rigidbody2D if needed (Kinematic or Dynamic).
Starter script
using UnityEngine;

public class PlayerController2D : MonoBehaviour
{
    void OnTriggerEnter2D(Collider2D other)
    {
        if (other.CompareTag("Coin"))
        {
            Debug.Log("Coin collected!");
            Destroy(other.gameObject);
        }
    }
}
Attach this script to the Player. Run and verify coins disappear and console logs appear when collecting.
Debugging hint

If the coin doesn't trigger, confirm layer collisions and that at least one object has a Rigidbody2D. Also check tags match exactly.
