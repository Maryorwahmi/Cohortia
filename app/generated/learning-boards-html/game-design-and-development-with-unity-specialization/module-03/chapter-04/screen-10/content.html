How Rule Tiles work
Define rules based on neighbor presence to automatically pick the correct sprite — edges, corners, and transitions.
Example: grass tile shows an edge sprite when there is no grass to the left.
When to use
Use Rule Tiles for terrain that must connect consistently and for large areas where manual edge management is tedious.
Practical steps
Create → Create → 2D → Tiles → Rule Tile. Define rules with neighbor positions and assign sprites for each case. Paint from the Tile Palette as usual.
Key Takeaway

Rule Tiles save time and avoid visual seams by automatically choosing edge and corner sprites based on neighbors.
