Module 4 › Chapter 3.4 › TilemapCollider2D
How it works
  • TilemapCollider2D examines painted tiles and generates colliders per tile.
  • For large contiguous tiles this can create many colliders and slow physics.
  • Enable Used By Composite on TilemapCollider2D and add CompositeCollider2D to merge colliders.
  • CompositeCollider2D typically requires a Rigidbody2D set to Static for proper behavior.
Practical check
If physics is slow on a large level, check how many separate colliders are present and add a CompositeCollider2D to optimize.
Example setup
Inspector steps:
  1. Add TilemapCollider2D to GroundTilemap.
  2. Check Used By Composite on TilemapCollider2D.
  3. Add CompositeCollider2D to GroundTilemap and add a Rigidbody2D set to Static when prompted.
Key Takeaway

Use CompositeCollider2D with Used By Composite to convert many per-tile colliders into a single efficient shape for performance.
