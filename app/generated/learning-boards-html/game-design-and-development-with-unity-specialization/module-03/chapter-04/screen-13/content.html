Module 4 › Chapter 3.4 › Hands-on Activity
Lab steps
  1. Create Grid and Tilemap. Rename to GroundTilemap.
  2. Add BackgroundTilemap child and set Sorting Layers accordingly.
  3. Create Tile Palette and drag sliced sprites into it, saving Tile assets.
  4. Paint ground and platforms on GroundTilemap using brush and fill.
  5. Add TilemapCollider2D, enable Used By Composite, add CompositeCollider2D and Static Rigidbody2D.
  6. Paint background elements on BackgroundTilemap and play to test collisions.
Checkpoints
  • Pixels Per Unit match Grid cell size.
  • Active Tilemap selected before painting.
  • Player can stand on painted ground after adding colliders.
Scenario card
You are building a small single-screen platformer level. Keep the GroundTilemap optimized with CompositeCollider2D to ensure smooth player movement and physics.
Key Takeaway

Follow the lab steps and validate colliders and PPU to avoid common painting and physics errors.
