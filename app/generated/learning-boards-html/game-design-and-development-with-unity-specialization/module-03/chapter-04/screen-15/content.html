Module 4 › Chapter 3.4 › Key Concepts — Advanced
Rule Tile
Automatically swaps sprites based on neighbors for clean terrain connections.
Animated Tile
Cycles a sprite sequence at a set speed for water, fire, or effects.
Scriptable Tile
Custom C# tile behavior via TileBase; powerful but use only when necessary.
Takeaway: combine these tools where appropriate — Rule and Animated Tiles speed art and flow, Scriptable Tiles add bespoke behaviors when needed.
