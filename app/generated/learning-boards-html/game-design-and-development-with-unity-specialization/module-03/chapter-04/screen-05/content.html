Module 4 › Chapter 3.4 › Creating a Grid and Tilemap Children
Steps
  1. Create Grid: GameObject → 2D Object → Tilemap. Unity makes a Grid with a Tilemap child.
  2. Rename layers: Rename child to GroundTilemap; add another child for BackgroundTilemap.
  3. Match cell size: Set Grid cell size and verify Pixels Per Unit on sprites for clean snapping.
  4. Set Sorting Layers: Assign Background and Platforms layers on each Tilemap Renderer.
  5. Select active Tilemap: Always choose the Tilemap in Hierarchy before painting in Scene.
Scenario
In a platformer, GroundTilemap holds colliders and platforms while BackgroundTilemap holds distant parallax art using the same Grid to keep alignment.
Visual checklist
Grid cell size
Confirm cell size equals sprite PPU mapping for predictable placement.
Layers named
Use clear names like GroundTilemap, BackgroundTilemap for easy editing.
Select active Tilemap
If painting does nothing, re-select the Tilemap in the Hierarchy and try again.
Key Takeaway

A disciplined Grid + named Tilemap children workflow prevents alignment and ordering errors as your level scales.
