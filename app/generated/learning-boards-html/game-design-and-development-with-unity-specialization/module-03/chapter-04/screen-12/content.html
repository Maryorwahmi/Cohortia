Module 4 › Chapter 3.4 › Scriptable Tiles
When to use
Use Scriptable Tiles when you need custom placement logic or a tile that triggers behavior on interaction, beyond Rule or Animated Tiles.
Example: a pressure-plate tile that raises a gate when walked on.
Safety checklist
  • Keep tile logic small; raise events rather than embed heavy state machines.
  • Test placement and removal in editor frequently.
  • Document tile behaviors for team members.
Minimal class example
using UnityEngine;
using UnityEngine.Tilemaps;

public class CustomTile : TileBase
{
  // Implement the minimal overrides you need,
  // such as GetTileData to provide the sprite and properties.
}
Pro tip

Prefer using built-in Tile types until you have a clear need for custom behavior; custom tiles increase maintenance cost.
