Module 4 › Chapter 3.4 › Creating a Tile Palette
Quick steps
  1. Create Palette: Window → 2D → Tile Palette → Create New Palette → Save as asset.
  2. Import tileset: Set Sprite Mode to Multiple and slice using Sprite Editor with the correct cell size.
  3. Drag slices into Palette: Save each generated Tile asset when prompted.
  4. Organize: Group tiles by function in the palette for faster painting.
Editor checklist
  • Pixels Per Unit matches Grid cell size.
  • Palette asset is saved inside Assets.
  • Slices are named consistently for ease of lookup.
Example: Slicing
If your tiles are 16x16 pixels and you want one Unity unit per tile, set Pixels Per Unit to 16 before slicing.
