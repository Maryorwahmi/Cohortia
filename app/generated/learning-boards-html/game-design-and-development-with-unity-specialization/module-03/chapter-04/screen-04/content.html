Definition

Tilemap System

A workflow in Unity that uses a parent Grid and child Tilemaps to paint grid-based environments. Tilemaps hold tiles, while the Grid defines alignment and size.

Example
Use a single Grid with GroundTilemap for collision and BackgroundTilemap for art so everything lines up automatically.
Common misconception
Tilemaps are not just tiled sprites. They are data containers that can include colliders, animations, and script-driven behavior.
Why it matters
Painting tiles is faster, more consistent, and easier to maintain than placing individual sprites for large or repeating environments.
Visual: Layered cards
Grid
Defines cell size and alignment for child Tilemaps.
Tilemap
Child GameObject that holds tile data for a specific layer.
Tile Palette
Editor window where Tile assets are created and selected for painting.
Key Takeaway

Think of Tilemaps as paintable data layers that combine visuals, physics, and behaviors for fast level creation.
