Module 5 › Chapter 5.1 › Learning Objectives
01
Importance of Performance
Understand how frame stability influences player experience and retention.
Knowing why performance matters helps you prioritize fixes that preserve responsiveness and immersion. For example, consistent 60 frames per second prevents perceived input lag during fast actions. VERIFIED COMPETENCY MILESTONE
02
Use the Unity Profiler
Collect real-time data, drill into frames, and isolate CPU, GPU, and memory hotspots.
The Profiler lets you find which subsystem dominates a frame and which function or render call caused a spike. Practice by capturing before-and-after profiles. VERIFIED COMPETENCY MILESTONE
03
Batching and Culling
Reduce draw calls and prevent rendering of unseen geometry to lower CPU/GPU load.
Static batching, dynamic batching, frustum culling, and occlusion culling each attack different parts of rendering cost. Apply the correct one depending on object behavior. VERIFIED COMPETENCY MILESTONE
04
Object Pooling
Reuse instances to prevent allocation spikes and expensive runtime creation/destruction.
Pool frequently spawned objects like bullets and effects to avoid GC spikes. Pre-instantiate and toggle active state rather than destroy. VERIFIED COMPETENCY MILESTONE
