Module 5 › Chapter 5.1 › CPU-bound vs GPU-bound
CPU-bound
High Main Thread usage from scripting, physics, or many draw calls submitted by the CPU.
Symptoms: High Main Thread bar, low GPU usage, frame time dominated by script or rendering submission.
Fixes: Reduce draw calls (batching), optimize scripts, cache components, reduce expensive physics checks.
Misconception: Lowering shader quality won’t help a CPU-bound issue caused by excessive draw calls.
GPU-bound
High Rendering or GPU bars, often caused by heavy shaders, high triangle counts, or large overdraw.
Symptoms: GPU bar is the limiting factor; reducing polycount or shader complexity lowers frame time.
Fixes: Optimize shaders, reduce polygons, enable occlusion culling or lower render resolution.
Tip: Use a GPU profiler when available for per-pass shader costs; in the Editor, Rendering and GPU bars help narrow the cause.
Quick diagnostic checklist
Check Main Thread
Check Rendering/GPU
Check Memory/GC
