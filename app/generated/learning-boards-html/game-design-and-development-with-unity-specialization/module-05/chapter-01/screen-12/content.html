Module 5 › Chapter 5.1 › Hands-on: Optimize a Cube Scene
Step 1 — Baseline
Create cube prefab, spawn 500–1,000 instances, run and record a profile. Note draw calls, Main Thread, and GC spikes.
Step 2 — Static batching
Ensure the same Material, mark objects Static or set isStatic in code, then rerun and compare draw calls.
Step 3 — Object pooling
Replace Instantiate/Destroy with GetPooledObject and ReturnPooledObject. Pre-warm the pool to expected peak.
Common mistakes & checks
  • Not sharing Material references prevents batching.
  • Expanding pools at runtime creates allocations; pre-warm pools for steady performance.
  • For occlusion culling, remember to bake and test; it won’t help open outdoor scenes much.
Key Takeaway

Measure first, make one targeted change, then re-measure to confirm the impact; repeat until performance goals are met.
