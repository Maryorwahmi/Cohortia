Module 5 › Chapter 5.1 › Draw Calls and Batching
What is a draw call?
An instruction from CPU to GPU to render a set of triangles. Each call has overhead on the CPU side.
Static batching: Combine stationary meshes sharing a material at build time. Best for level geometry.
Dynamic batching: Runtime combination for small moving objects that meet vertex and transform constraints.
Common mistake: Marking animated objects as Static — doing so prevents movement and can break gameplay.
Concrete example
Spawn 1,000 identical cubes with the same material. Without batching, CPU must issue many draw calls. With static batching, Unity merges meshes and reduces draw calls substantially, lowering CPU time on the Main Thread.
Key Takeaway
Batching reduces CPU overhead. Use static for stationary objects and dynamic only when objects are small and moving.
