Performance Optimization Fundamentals
Diagnose bottlenecks, reduce overhead, and stabilize frame rate across target platforms.
In this lesson
Learn profiler reading, batching, culling, and pooling with concrete Unity editor and scripting examples.
Why it matters
Stable frame rate keeps players immersed and prevents input lag and perceived bugs that break player trust.
Explore Key Topics
Profiling
Open the Unity Profiler and learn to read CPU, GPU and memory graphs to find the hot path.
Batches & Draw Calls
Reduce the number of draw calls using static or dynamic batching to lower CPU overhead.
Object Pooling
Pre-instantiate and reuse objects to avoid allocation spikes and smooth frame time.
Visual concept
How profiler insight maps to fixes
Profiler
Shows CPU/GPU, Memory, and detailed per-frame breakdowns. Look for Main Thread and GarbageCollector spikes.
Use frame detail to find the offending function or render call.
Rendering
Many small draw calls raise CPU work. Batching and shared materials reduce this overhead.
Static batching combines meshes at build time for stationary objects.
Runtime
Frequent Instantiate/Destroy creates garbage. Pool objects to reuse and avoid GC spikes.
Pre-warm pools in Awake or Start.
