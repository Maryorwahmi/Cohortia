Module 5 › Chapter 5.1 › Static Batching in Practice
Step-by-step
  1. Make sure objects share the exact same Material asset.
  2. Mark objects as Static in the Inspector or set newCube.isStatic = true in code.
  3. Run the scene and measure draw calls in the Profiler before and after.
Example verification
Before: 1,000 draw calls. After: significantly fewer draw calls and lower Main Thread time for rendering submission.
Caveats
  • Static batching increases build time and memory for combined meshes.
  • Animated or moving objects cannot be static; doing so will break motion.
  • Materials must be identical references; duplicated instances prevent batching.
Key Takeaway

Static batching pays off for stationary, material-shared geometry. Confirm the material references and reprofile to measure benefit.
