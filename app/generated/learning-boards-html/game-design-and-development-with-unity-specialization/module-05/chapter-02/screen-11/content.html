Module 5 › Chapter 5.2 › Convert to URP
Step-by-step
  1. Install Universal RP from Package Manager, then create a URP Asset and assign it in Project Settings → Graphics.
  2. Upgrade project materials to URP-compatible versions to avoid shader errors.
  3. Create a simple scene: Plane (ground), Cubes (static walls), Sphere (dynamic character).
  4. Add Directional Light and set Mode to Baked; mark static geometry as Static.
  5. Create a Global Volume with a Volume Profile; add Bloom and Color Grading overrides and tune them.
  6. Open Lighting window, enable Baked Global Illumination, and Generate Lighting.
  7. Add a Light Probe Group around travel areas and set the Sphere to use Light Probes for GI sampling.
  8. Place Reflection Probes near glossy surfaces and bake or capture them to provide reflections.
Why it matters

Following these steps yields consistent visuals and better performance by offloading lighting work to the bake process and using probes for dynamic objects.

Tip

Profile before and after enabling post-processing. Some settings are decorative but expensive; tune for your target device.
