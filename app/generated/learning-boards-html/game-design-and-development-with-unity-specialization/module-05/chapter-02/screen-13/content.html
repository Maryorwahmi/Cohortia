Concept check

Example question: Which pipeline is best for high-fidelity desktop visualization and why? (Expect HDRP with explanation about advanced lighting and features.)

Hands-on task
  1. Convert a small scene to URP and validate material conversion.
  2. Add a Global Volume with Bloom and Color Grading; note visual change and frame time.
  3. Bake lighting, add light probes, and measure the frame time difference in Play Mode.
Reflective prompt

Describe one case where HDRP's features are unnecessary and URP would be a more practical choice. Include performance considerations.
