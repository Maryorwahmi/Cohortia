Process

Bake workflow

  1. Mark static meshes as Static in the Inspector to include them in baked lightmaps.
  2. Set lights that should be baked to Baked mode and configure intensity and color.
  3. Open Window > Rendering > Lighting and enable Baked Global Illumination.
  4. Choose Lightmap resolution and other bake parameters carefully to balance quality and memory.
  5. Click Generate Lighting and inspect lightmaps and shadows in Play Mode.
Key Takeaway

Baking reduces runtime cost of complex lighting — choose resolutions that fit your memory and visual needs.

Why bake?
Precomputing replaces per-frame lighting math with texture lookups, letting you keep high-quality shadows without real-time expense.
Example
A static room can have soft indirect light baked to a lightmap, freeing the GPU for character animation and physics at runtime.
Pitfall

Oversized lightmaps increase build time and memory. Use conservative resolutions and iterate.
