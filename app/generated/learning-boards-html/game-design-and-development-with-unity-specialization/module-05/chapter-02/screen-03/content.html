Practical Skills

Step-by-step tasks you'll complete to apply the concepts.

Convert to URP
Install Universal RP, create a URP Asset, assign it in Graphics settings, and upgrade materials to avoid render errors.
Create Post-Processing Volume
Make a Global Volume with a Volume Profile and add Bloom and Color Grading to shape atmosphere.
Bake Lighting
Set static objects to Static, switch lights to Baked, and generate lightmaps to lower runtime cost.
Place Probes & Build Shader
Add Light Probe Groups, Reflection Probes, then prototype a shader in Shader Graph for a material effect.
Verified competency milestone

Complete the hands-on activity: convert a scene to URP, add a Global Volume with two effects, bake lighting, and place probes.
