Module 1 › Chapter 1.1 › Mechanics
Definition

Mechanics are explicit rules and actions

Designers implement mechanics directly. They are the parts you can tweak in the editor to change how the game behaves.

Design tip
Keep mechanics visible and learnable. Hidden complexity weakens player trust and slows learning.
Example: Platformer mechanics
  • • Movement: walk, run
  • • Jumping: height, double jump
  • • Collectibles: coins, power-ups
Common mistake

Adding many mechanics at once creates cognitive overload. Introduce core mechanics first and layer complexity later.

Concrete example
A card game's draw, shuffle, and play actions define what players can do each turn and set strategic constraints.
Practice exercise

List three core mechanics for a simple game idea and test each in isolation: does it support a clear decision and outcome?

Check
  • • Can a player learn the mechanic in one to two attempts?
  • • Does the mechanic enable or limit interesting choices?
