What is a Prefab?
A reusable GameObject asset that keeps instances synchronized with the source.
• Turn a Hierarchy object into a Prefab by dragging it to a Prefabs folder.
• Instances reference the Prefab asset and show a blue link in the Hierarchy.
• Apply Overrides to commit instance edits back to the Prefab asset, or revert to reset to the Prefab state.
Scenario
Make WallPrefab from a wall mesh. Place many copies in the room. Later change the material in the prefab to update all walls at once.
Prefab Controls
Instances show overrides in the Inspector. Use the Overrides dropdown to apply or revert changes. Remember: accidental overrides can desynchronize instances, so review before applying broadly.
Key Takeaway

Prefabs reduce repetitive edits and keep repeated objects consistent across your project.
