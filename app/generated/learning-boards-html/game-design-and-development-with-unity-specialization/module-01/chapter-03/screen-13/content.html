Guided Steps
1. Create folders: Models, Textures, Materials, Prefabs
2. Import model.fbx → Models and texture.png → Textures
3. Create Material in Materials, set Albedo to texture.png
4. Drag model into Scene, position and scale with Transform
5. Apply Material by dragging onto model or Mesh Renderer slot
6. Drag the GameObject into Prefabs to create a Prefab asset
7. Instantiate multiple Prefab copies to build structure
8. Select Directional Light, rotate for shadow direction, tweak intensity/color
9. Save scene and project regularly
This code-style checklist is a repeatable script for your lab video. Follow each step and test changes after creating Prefabs or updating materials.
Tips During the Lab
  • Name assets descriptively so teammates can locate them quickly.
  • Preview textures and models in the Inspector to catch import issues early.
  • Use prefab overrides when you intentionally vary an instance.
  • Test lighting after building geometry to ensure readability.
Key Takeaway

Follow a repeatable sequence and save often; this reduces errors and keeps your project collaborate-ready.
