Module 2 › Chapter 1.3 › Build a Simple Room
Step Checklist
  • Create folders: Models, Textures, Materials, Prefabs.
  • Import wall.fbx into Models and brick.png into Textures.
  • Create BrickMaterial and assign brick.png to Albedo.
  • Apply material to wall model, position and scale in Scene.
  • Drag wall GameObject to Prefabs folder to make WallPrefab.
  • Instantiate multiple WallPrefab copies to form a room perimeter.
  • Adjust Directional Light rotation and intensity.
Concrete Example
Use a single wall mesh and a single brick material to build four walls. If you update the BrickMaterial texture later, all walls update automatically. If you need a different corner wall, create a nested prefab or override a single instance.
Key Takeaway

A small, disciplined workflow lets you iterate quickly: change one material or prefab and see the room update.
