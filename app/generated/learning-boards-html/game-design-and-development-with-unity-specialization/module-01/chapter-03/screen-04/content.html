Module 2 › Chapter 1.3 › What is an Asset?
Definition
Files used by Unity to create scene content and behavior
• 3D models (.fbx, .obj) provide mesh geometry.
• Textures (.png, .jpg) add surface detail to materials.
• Audio (.wav, .mp3) and scripts (.cs) add sound and behavior.
• Unity must import and process files before they appear as usable assets.
Example
A crate.fbx mesh combined with wood.png becomes a textured object when a material is created and applied.
Key Takeaway

Treat assets as managed resources inside Unity and organize them before the project grows.
