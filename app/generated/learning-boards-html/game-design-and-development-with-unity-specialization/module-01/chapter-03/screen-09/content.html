Best Practices
• Keep a dedicated Prefabs folder with clear names.
• Favor nested prefabs for composable parts.
• Use overrides sparingly and apply only when intentional.
• Test prefab updates in scenes with instances.
Example & Pitfall
Example: CratePrefab with default material. If one crate should look different, override that instance's material instead of duplicating the prefab. Pitfall: unreviewed mass applies can break scenes; use version control and review prefab changes.
Nested Prefab Tip
Group shared parts as child prefabs so updates to a part propagate while unique children remain editable per instance.
