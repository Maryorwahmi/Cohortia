Module 2 › Chapter 1.3 › Importing Assets
Import Process
Follow these numbered steps to import and verify assets.
1
Create folders
Make Models, Textures, Materials, Prefabs before importing.
2
Drag or Import
Drag files into the correct folder or use Import New Asset.
3
Verify in Inspector
Check mesh preview, normals, texture import settings, and scale.
Concrete Example
Step: drag crate.fbx into Models and wood.png into Textures. Select crate.fbx and in the Inspector confirm the mesh and set Scale Factor if needed so the object fits your scene.
Key Takeaway

Verification at import prevents scaling and texture problems later when assembling scenes.

Common Mistake
Importing into the root Assets folder makes assets hard to find and slows team workflows.
