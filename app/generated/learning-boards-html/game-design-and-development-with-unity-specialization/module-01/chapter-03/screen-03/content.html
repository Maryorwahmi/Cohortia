Practice & Workflow
A short checklist to guide your lab work
Folder Structure
Create Models, Textures, Materials, Prefabs, Scripts, Audio.
Import
Drag files into their folders or use Import New Asset for single files.
Material
Create materials, set Albedo, drop textures into the slot.
Prefab
Drag a Hierarchy object into Prefabs to make a reusable blueprint.
Lighting
Adjust Directional Light rotation, intensity, and color to sculpt shadows and mood.
Save
Save scene and project regularly to avoid data loss.
