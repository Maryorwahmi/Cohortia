Module 1 › Chapter 1.2 › Install Unity Hub
Step-by-step
1. Install Unity Hub
Run the Hub installer for your operating system and sign in if needed. Hub manages versions and projects centrally.
2. Add an Editor
Use Hub's Installs panel to add a recommended Editor release for this course.
3. Select Modules
Choose desktop build support for your OS, Android, WebGL, and Documentation for offline help.
4. Verify Install
Confirm the Editor appears in Hub and can be launched.
Why modules matter
Build support modules add platform-specific tooling and SDKs. Without them, export attempts will fail with missing platform tools.
Concrete Example
If you plan to publish to Android but skip Android Build Support, the Editor will not find the Android SDK and the Android build will fail until you add the module.
Common Mistake
Assuming an Editor install includes every target platform. Always verify and add modules now to avoid later build errors.
