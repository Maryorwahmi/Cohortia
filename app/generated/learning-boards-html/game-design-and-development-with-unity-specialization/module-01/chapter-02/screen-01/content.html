Getting Started with the Unity Editor

Install Unity Hub, pick the right Editor modules, create a 3D project, and learn the five primary Editor windows plus the GameObject–Component model.

Install
Get Unity Hub, then use it to install the Editor with needed build modules.
Create
Start a new 3D or 2D Core project with a clear name and folder location.
Explore
Open Scene, Game, Hierarchy, Project and Inspector to learn their roles.
In this lesson
Install Hub and an Editor version with modules, create a 3D Core project, add primitives, practice transform tools, and save your first scene.
Concept Map
Hub → Editor → Project → Scene (GameObjects + Components)
Unity Hub: central manager for Editor versions and projects
Editor windows: Scene, Game, Hierarchy, Project, Inspector
GameObject + Component: the composition model for behavior and visuals
Quick Tip
Install common build modules now — skipping build support often stops later deployment. Use descriptive project names to keep work organized.
