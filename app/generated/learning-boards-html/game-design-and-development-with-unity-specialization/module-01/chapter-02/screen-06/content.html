Editor relationships
Scene View
Arrange GameObjects and build levels interactively; navigation uses orbit, pan, and zoom.
Game View
Preview the active camera output to check what players will see at runtime.
Hierarchy
Lists scene GameObjects and their parent-child relationships for organization.
Project
Asset browser containing models, textures, scripts, and audio for your project.
Inspector
Edit selected object's Components and properties. Add or remove Components here to change behavior and appearance.
Concrete Example
Drag a model from Project into Scene, group it under a parent in Hierarchy, select it and edit materials or Rigidbody settings in the Inspector, and then test in Game view to confirm the player camera frames the object as intended.
Misconception
Scene edits are not the final output. Always validate changes in the Game view because camera and player experience may differ from the Scene perspective.
