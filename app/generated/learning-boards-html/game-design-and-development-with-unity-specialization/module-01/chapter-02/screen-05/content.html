Module 1 › Chapter 1.2 › 2D vs 3D Templates
3D Core
Perspective camera, 3D lighting, 3D physics
Ideal when depth, perspective, and 3D modeling are central. Includes default camera and lighting tuned for three-dimensional scenes.
Example
A first-person or third-person game that relies on depth and 3D collisions should use 3D Core.
2D Core
Orthographic camera, sprite renderer, 2D physics
Use when your game is built from sprites and 2D colliders, such as tile-based or side-scrolling games where orthographic projection is desired.
Example
A pixel-art platformer benefits from the 2D template because colliders and camera behavior match 2D expectations.
Misconception
Templates are not irreversible, but changing major settings later requires extra configuration. Choose to save time and reduce friction.
