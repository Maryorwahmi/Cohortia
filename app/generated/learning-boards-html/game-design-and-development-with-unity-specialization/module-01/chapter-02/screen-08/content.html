Module 1 › Chapter 1.2 › GameObjects & Components
Definition
A GameObject is an entity with a Transform; Components are attachable modules that add behavior and visuals.
Core Components on a Cube
  • Transform — position, rotation, scale (required)
  • Mesh Filter — defines the mesh geometry
  • Mesh Renderer — makes the mesh visible
  • Box Collider — collision shape for physics and overlaps
Concrete Scenario
Create a Cube, add a Rigidbody to enable gravity. Without Rigidbody the cube's collider will detect collisions but it will not move under physics.
Takeaway
Components give GameObjects functionality. Attach only what you need and inspect values in the Inspector to tune behavior.
