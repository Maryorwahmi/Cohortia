Module 1 › Chapter 1.2 › Save & Organize
Checklist
  • Save scene early: use descriptive names like MyFirstScene.
  • Create folders in Project for Models, Textures, Scripts, Audio.
  • Confirm Editor has required build modules in Unity Hub.
  • Check Hierarchy to avoid unintended parenting and inherited transforms.
  • Use Undo and numeric Inspector edits to correct misplaced transforms.
Example
After arranging primitives into a small structure, save the scene and create folders for future imported assets so your project stays navigable.
