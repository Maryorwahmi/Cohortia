Navigation Controls
  • Orbit scene camera: right-click + drag to change view angle.
  • Pan: middle-click + drag to move the camera without rotating.
  • Zoom: scroll wheel to approach or retreat from an object.
Transform Tools
  • Move Tool (W): drag axis handles to move objects along X, Y, Z.
  • Rotate Tool (E): rotate by angle and watch rotation values in Inspector.
  • Scale Tool (R): change object size uniformly or per axis.
Guided Exercise
Create a Cube, press W, drag the X handle while watching the Transform X value in the Inspector. Press E to rotate and R to scale. Practice resetting transforms when needed by zeroing position values.
Mistake to avoid
Accidentally moving objects far from the origin. Use the Inspector to set precise numbers or undo to revert unexpected changes.
