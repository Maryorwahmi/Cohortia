Module 1 › Chapter 1.2 › Inspector & Components
Inspector Basics
Select a GameObject to view and edit attached Components. Fields update in real time and control behavior and appearance.
Add a Component
Click Add Component, search for the desired module, and set its properties.
Edit Fields
Tune numbers, assign assets, or enable features directly in the Inspector.
Example
Add Rigidbody to a Cube to enable gravity. Add Box Collider to let it collide with other objects. Configure mass and drag in the Inspector.
Misconception
Components do not auto-create dependent components. Add each necessary component explicitly and verify their settings.
