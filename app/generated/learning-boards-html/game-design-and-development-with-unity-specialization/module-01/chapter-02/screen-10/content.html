Assets and Instances
Project Role
Stores all assets used across scenes. Treat it as the canonical source for models, textures, scripts, and audio.
Instance Behavior
Dragging an asset into Scene creates an instance that references the asset file; reusing assets saves disk space and maintains consistency.
Example
Import a tree model into Project, then drag it into the Scene multiple times to create copies that reference the original asset.
Pitfall
Changing a component value on one instance does not alter the original asset unless you apply changes intentionally; be mindful when editing.
