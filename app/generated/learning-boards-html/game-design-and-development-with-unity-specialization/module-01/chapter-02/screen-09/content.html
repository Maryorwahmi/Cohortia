Module 1 › Chapter 1.2 › Create & Manipulate
Steps
  1. Create a Cube (Hierarchy → 3D Object → Cube).
  2. Create a Sphere and Cylinder the same way.
  3. Use Move (W), Rotate (E), Scale (R) to position objects into a simple structure.
  4. Save scene as MyFirstScene in the Assets folder.
Scenario
Arrange Sphere atop Cylinder and place Cube as a hat. Use numeric values in the Inspector to align objects precisely when snapping visually is difficult.
Common Mistake
Accidentally parenting objects under another object. Check the Hierarchy to confirm intended parent-child relationships.
