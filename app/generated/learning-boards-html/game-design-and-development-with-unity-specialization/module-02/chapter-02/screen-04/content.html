Module 2 › Chapter 2.2 › Finding GameObjects
Definition

Lookup methods and uses

Different find methods match different patterns: names for unique objects, component searches for typed access, and tags for grouped objects. Choose based on frequency and required results.

GameObject.Find
Search by name across the scene. Fine for setup code, not per-frame loops.
FindObject(s)OfType<T>
Find by component type. Useful for singletons or bulk operations; returns components, not GameObjects.
FindWithTag / FindGameObjectsWithTag
Optimized for grouped objects when you assign tags in the Inspector first.
Example
// Find all collectibles by tag and destroy them
GameObject[] collectibles = GameObject.FindGameObjectsWithTag("Collectible");
foreach (GameObject c in collectibles)
{
  Destroy(c);
}
Common mistake
Calling Find methods inside Update causes slowdowns. Cache results if you use them repeatedly.
Key takeaway
Pick the lookup that matches frequency and expected count, and cache arrays or references when possible.
