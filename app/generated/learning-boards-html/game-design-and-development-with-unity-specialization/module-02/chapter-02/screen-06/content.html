Module 2 › Chapter 2.2 › GetComponent & Caching
Definition

GetComponent<T>()

Retrieve a component on the same GameObject so your script can interact with it. If absent, the call returns null, so defensive checks are required.

// Cache in Awake
private Rigidbody rb;
void Awake()
{
  rb = GetComponent<Rigidbody>();
  if (rb == null)
  {
    Debug.LogWarning("Rigidbody not found!");
  }
}
Practical notes
  • Use RequireComponent to ensure essential components are present when attaching scripts.
  • Cache references in Awake or Start to avoid repeated GetComponent calls in Update.
  • Always check for null to prevent NullReferenceException at runtime.
Pro tip
If your script assumes another component exists, add [RequireComponent(typeof(TheComponent))] above the class declaration so Unity enforces it on attach.
Common mistake
Calling GetComponent inside tight loops for many objects. Cache once and reuse the reference.
