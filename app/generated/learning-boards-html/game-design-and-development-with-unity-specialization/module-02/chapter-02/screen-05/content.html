Module 2 › Chapter 2.2 › Lookup Comparison
By Name

GameObject.Find("Name")

Simple one-off lookups for unique objects in setup code. Avoid in Update.

Pros: readable, direct. Cons: scene-wide search, slower for frequent use.
By Type

FindObject(s)OfType<T>

Use when you need a component's API. Single variant returns the first match; plural returns all matches.

Pros: typed access. Cons: may not be appropriate for many objects unless plural method used.
By Tag

FindWithTag / FindGameObjectsWithTag

Optimized grouping for many similar objects like collectibles or enemies. Assign tags in the Inspector first.

Pros: fast for grouped lookups. Cons: string labels must be managed carefully.
Example
// Clear all coins efficiently
GameObject[] coins = GameObject.FindGameObjectsWithTag("Coin");
foreach (GameObject c in coins)
{
  Destroy(c);
}
Misconception
Assuming FindObjectOfType returns every instance. Use the plural form for all matches.
Takeaway
Match your lookup to whether you need a single anchor, typed API access, or many grouped objects.
