Module 2 › Chapter 2.2 › Player Input
Single-press

Input.GetKeyDown / GetMouseButtonDown

Fires for a single frame when pressed. Good for discrete actions like firing, jumping, or toggling states.

Held input

Input.GetKey

Returns true while a key is held. Use it for continuous movement or charging mechanics.

Release

Input.GetKeyUp

Detect when a key is released to trigger end-of-action behaviors.

Smooth axes

Input.GetAxis("Horizontal")

Use axis values for smooth movement. Returns floats between -1 and 1 and supports joystick input too.

Example
// In Update
if (Input.GetMouseButtonDown(0))
{
  // spawn bullet
}

float h = Input.GetAxis("Horizontal");
transform.Translate(Vector3.right * h * Time.deltaTime * speed);
