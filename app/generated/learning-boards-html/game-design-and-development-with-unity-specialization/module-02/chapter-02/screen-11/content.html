Script excerpt
void Start()
{
    GameObject enemy = GameObject.FindWithTag("Enemy");
    if (enemy != null)
    {
        enemyHealthScript = enemy.GetComponent<EnemyHealth>();
        if (enemyHealthScript != null)
        {
            Debug.Log("Found Enemy and its Health script.");
        }
    }
}

void Update()
{
    if (Input.GetMouseButtonDown(0))
    {
        Instantiate(projectilePrefab, spawnPoint.position, spawnPoint.rotation);
    }
}
Explanation
  • The Start method performs a tag lookup and then calls GetComponent on the found object.
  • Null checks after each lookup prevent NullReferenceException and provide helpful Debug.Log messages.
  • Update handles input for spawning, and the prefab is instantiated at a spawn point with a rotation.
Common mistake
Not checking prefab or spawnPoint for null before Instantiate — always validate Inspector-assigned fields.
