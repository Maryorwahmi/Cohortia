Module 2 › Chapter 2.2 › Destroy
Definition

Destroy(object) and Destroy(object, delay)

Destroy schedules the object for removal rather than instantly nullifying references. Use a delay for timed lifetimes and plan for end-of-frame behavior.

// Destroy after a delay
Destroy(gameObject, 2f);

// Destroy immediately in logic terms, but removal is at frame end
Destroy(otherGameObject);
Practice
When you spawn bullets, set Destroy(bullet, lifetime) so they are cleaned up. For frequent bullets, pool objects instead to reduce allocations.
Common pitfall
Assuming Destroy makes references null immediately. Use null checks and ordering to avoid accessing destroyed objects next frame.
