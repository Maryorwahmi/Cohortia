Tags

Identity for gameplay

Tags are used for quick checks like CompareTag("Collectible") inside collision handlers. Assign tags in the Inspector before using them in code.

Example: In OnTriggerEnter, call if(other.gameObject.CompareTag("Collectible")) Destroy(other.gameObject);
Layers

Filtering for systems

Layers control collision matrices, raycast masks, and camera culling. Use them to prevent unwanted collisions or to optimize rendering.

Example: Put Player on "Player" layer and set physics so Player and Enemy layers do or do not collide as desired.
Best practice
Use tags for logic checks and layers to configure rendering and physics. This separation reduces coupling and makes intent clearer when reading code and project settings.
