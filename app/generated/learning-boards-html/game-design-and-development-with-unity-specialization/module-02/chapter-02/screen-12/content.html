Module 2 › Chapter 2.2 › PlayerCollector Activity
Scene Setup
  1. Create a Player capsule with a Rigidbody and a child empty named SpawnPoint.
  2. Create a Sphere, tag it "Collectible", make it a prefab and remove it from the Hierarchy.
  3. Attach PlayerCollector, assign collectiblePrefab and spawnPoint in Inspector.
Behavior checks
Ensure colliders and Is Trigger are configured so OnTriggerEnter is called when the player meets the collectible.
Starter code
void Update()
{
  if (Input.GetKeyDown(KeyCode.Space))
  {
    Instantiate(collectiblePrefab, spawnPoint.position, spawnPoint.rotation);
  }

  if (Input.GetKeyDown(KeyCode.R))
  {
    GameObject[] collectibles = GameObject.FindGameObjectsWithTag("Collectible");
    foreach (GameObject c in collectibles) Destroy(c);
  }
}

void OnTriggerEnter(Collider other)
{
  if (other.gameObject.CompareTag("Collectible")) Destroy(other.gameObject);
}
Test
Press Space to spawn, touch collectibles to collect, press R to clear the scene. If nothing happens, check tags and collider trigger settings.
