Spawn a prefab and initialize

Instantiate returns the created object. Use that reference to set properties or call initialization methods immediately after creation.

// Example: Fire a projectile on mouse click
if (Input.GetMouseButtonDown(0))
{
  GameObject bullet = Instantiate(projectilePrefab, spawnPoint.position, spawnPoint.rotation);
  // Example initialization: give it velocity or set owner
  Rigidbody rb = bullet.GetComponent<Rigidbody>();
  if (rb != null) rb.velocity = transform.forward * 20f;
  Destroy(bullet, 5f); // remove after 5 seconds
}
Quick tips
  • Capture the returned instance for configuration.
  • Use Destroy with a delay or implement pooling for frequent spawns.
  • Check prefab scripts for required references and initialize them after instantiation.
