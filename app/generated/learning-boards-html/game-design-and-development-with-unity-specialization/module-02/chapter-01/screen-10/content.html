Module 2 › Chapter 2.1 › Debug.Log
Code Examples
// In Start()
Debug.Log("Bouncing Cube Initialized!");

// Conditional log in Update()
if (Input.GetKeyDown(KeyCode.Space))
{
    Debug.Log("Current Cube Y Position: " + transform.position.y);
}

// Avoid logging every frame unless throttled
// Debug.Log("Position: " + transform.position); // expensive if left unchecked
Guidelines
  • Log startup messages to confirm script activity.
  • Log variables conditionally to avoid Console spam.
  • Use warnings and errors for higher severity messages.
Performance note
Excessive logging in Update can slow the editor. Gate logs behind user input or thresholds during testing.
