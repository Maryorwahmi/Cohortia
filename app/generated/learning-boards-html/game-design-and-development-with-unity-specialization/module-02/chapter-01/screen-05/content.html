How to attach
  • Drag the script asset onto a GameObject in the Hierarchy.
  • Or select the GameObject and click Add Component, then choose the script.
  • Confirm the component appears and is enabled in the Inspector.
Manage components
Use multiple focused scripts rather than one large monolithic script. Reuse the same script asset across many objects for consistent behavior.
Common issue: Component missing because of a compile error or a filename/class mismatch. Check the Console first.

Key takeaway
Key Takeaway

Attaching scripts as components composes behaviour and enables reuse; verify compilation and naming if the component does not appear.
