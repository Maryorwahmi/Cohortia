Module 2 › Chapter 2.1 › Best Practices
Hierarchy of habits
Save Often
Unity compiles saved files only; unsaved edits cause mystery failures.
Cache Components
Use GetComponent in Awake to store references and avoid repeated lookups.
Prefer APIs
Use Rigidbody methods in FixedUpdate for physics rather than changing transform directly.
Example cache
private Rigidbody rb;

void Awake()
{
    rb = GetComponent<Rigidbody>();
}
Key Takeaway

Small consistent habits like saving, caching, and choosing the correct update method reduce bugs and speed iteration.
