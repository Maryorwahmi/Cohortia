Learning Objectives

Skills to practice and verify as you work through the examples and activity.

01
Role of C# and GameObjects

Explain how C# scripts act as components that give behaviour to GameObjects, and why this separation supports modular design.

Verified competency milestone
02
Create, name, attach scripts

Create a C# script, ensure the filename matches the class, and attach it to a GameObject. This removes common compile and attachment errors.

Verified competency milestone
03
MonoBehaviour lifecycle methods

Use Awake for early initialization, Start for first-frame setup, Update for per-frame logic, and FixedUpdate for physics. Knowing each prevents timing bugs.

Verified competency milestone
04
Variables & Debugging

Declare typed variables, expose public fields to the Inspector, and use Debug.Log to trace execution and inspect values at runtime.

Verified competency milestone
