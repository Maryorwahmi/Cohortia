Module 2 › Chapter 2.1 › What to Remember
Name Match
Keep file names and class names identical to avoid compile errors.
Lifecycle
Use Awake, Start, Update, FixedUpdate for correct timing of initialization and physics.
Inspector & Logs
Expose tuneable fields and use Debug.Log selectively to verify behaviour while testing.
Final Tip

Before playtesting, save scripts, clear the Console, and ensure noisy logs are gated to keep iteration smooth.
