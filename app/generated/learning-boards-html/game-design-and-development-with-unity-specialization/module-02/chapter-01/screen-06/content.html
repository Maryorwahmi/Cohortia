Module 2 › Chapter 2.1 › MonoBehaviour & Lifecycle
Definition

What MonoBehaviour gives you

  • Automatic method calls at defined moments (Awake, Start, Update, FixedUpdate).
  • Access to Unity API like transform, GetComponent, and Time.deltaTime.
  • Ability to be added as a component to GameObjects in the Inspector.
Quick reference
Awake() — earliest initialization
Start() — first enabled frame
Update() — per-frame work
FixedUpdate() — physics timestep
Example & Misconception
Example: Use Awake to cache a Rigidbody reference using GetComponent<Rigidbody>(). Use Start to set the initial position. If you apply AddForce to a Rigidbody, do so in FixedUpdate to avoid varying results across different frame rates.
Misconception
Putting physics AddForce calls in Update will yield inconsistent physics because Update timing varies with frame rate.
