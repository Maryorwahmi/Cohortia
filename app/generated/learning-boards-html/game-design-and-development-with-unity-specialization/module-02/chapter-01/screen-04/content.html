Module 2 › Chapter 2.1 › Creating and Naming Scripts
Process

Create → Name → Save

  1. Create a new C# Script in the Project window via Create > C# Script.
  2. Name the script meaningfully, e.g. PlayerController or BouncingCube.
  3. Open in your code editor and ensure the public class name matches the filename exactly.
  4. Save the file so Unity recompiles and the script becomes attachable.
Common mistake
Renaming only the file or only the class; this causes compile errors and prevents attachment.
Pro tip
Use your editor's refactor->rename to change both at once, and save immediately so Unity recompiles.
Code Template
using UnityEngine;

public class PlayerController : MonoBehaviour
{
    void Start()
    {
        // Initialization
    }

    void Update()
    {
        // Per-frame logic
    }
}
Try This
Create PlayerController.cs, open it, confirm the class name, save, and attach it to a Cube.
Why It Matters
File-class mismatches are the single most common early frustration; fixing this speeds iteration.
