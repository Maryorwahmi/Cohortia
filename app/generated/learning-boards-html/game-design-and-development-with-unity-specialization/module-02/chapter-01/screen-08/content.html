Module 2 › Chapter 2.1 › Update vs FixedUpdate
Update
Frame-dependent. Use for input, animations, and transform changes. Apply Time.deltaTime to keep movement frame-rate independent.
Code hint
// Move forward smoothly
transform.Translate(Vector3.forward * moveSpeed * Time.deltaTime);
FixedUpdate
Fixed timestep. Use for applying forces or other Rigidbody-based physics so simulation remains consistent.
Code hint
// Apply physics force in FixedUpdate
rb.AddForce(Vector3.up * jumpStrength);
Example Scenario
You have a player that should move responsively when a key is pressed and also be affected by gravity. Read input in Update and apply physics-based movement in FixedUpdate to keep responsiveness and stable collisions.
