Types
  • int — whole numbers
  • float — decimals; use 5.0f suffix
  • string — text
  • bool — true/false
  • Vector3 — 3D position or direction
Public vs Private
Public fields show in the Inspector for quick tuning; private fields keep implementation details hidden. Use public for parameters and private for state like counters.
Example
public float bounceHeight = 1.0f;
public float bounceSpeed = 2.0f;

private float originalY; // internal state, not shown in Inspector
Try
Change bounceHeight in the Inspector while the game is running to see instant effects without recompiling.
Why private?
Keep counters and runtime state private so designers don't accidentally change them from the Inspector.
