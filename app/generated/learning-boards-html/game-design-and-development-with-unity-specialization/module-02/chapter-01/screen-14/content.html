Module 2 › Chapter 2.1 › Key Concepts
Scripts & Components
Scripts are components you attach to GameObjects to add behavior; reuse and compose them for complex actions.
Lifecycle Methods
Awake, Start, Update, FixedUpdate define when code runs; choose appropriately for initialization and physics.
Inspector & Debugging
Expose public fields for tuning and use Debug.Log to inspect execution and values when testing.
Summary Takeaway

Master the file-class match, lifecycle timing, and inspector-driven iteration to move from concept to playable behaviours quickly.
