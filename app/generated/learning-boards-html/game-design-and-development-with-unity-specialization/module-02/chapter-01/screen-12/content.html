Module 2 › Chapter 2.1 › Bouncing Cube Activity
Steps
  1. Create a Cube at (0, 0.5, 0).
  2. Create BouncingCube.cs and attach to the Cube.
  3. Declare public float bounceHeight and bounceSpeed; store originalY in Start.
  4. In Update set newY = originalY + Mathf.Sin(Time.time * bounceSpeed) * bounceHeight and assign transform.position.
  5. Add Debug.Log in Start and conditional Debug.Log on Space in Update.
Test
Run Play, watch the Cube bounce, press Space to see current Y in the Console, and tweak bounceHeight and bounceSpeed in the Inspector.
Starter Code
using UnityEngine;

public class BouncingCube : MonoBehaviour
{
    public float bounceHeight = 1.0f;
    public float bounceSpeed = 2.0f;

    private float originalY;

    void Start()
    {
        Debug.Log("Bouncing Cube Initialized!");
        originalY = transform.position.y;
    }

    void Update()
    {
        float newY = originalY + (Mathf.Sin(Time.time * bounceSpeed) * bounceHeight);
        transform.position = new Vector3(transform.position.x, newY, transform.position.z);

        if (Input.GetKeyDown(KeyCode.Space))
        {
            Debug.Log("Current Cube Y Position: " + transform.position.y);
        }
    }
}
Adjust the public fields in Play mode to iterate without recompiling. This is the fastest loop for small gameplay tweaks.
