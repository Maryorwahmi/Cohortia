Module 3 › Chapter 2.3 › Hands-on Activity
Scene Setup Steps
  1. Create a Plane, tag it Ground, ensure collider is not a trigger.
  2. Create a Capsule named Player, add Rigidbody and CapsuleCollider.
  3. Create a Sphere named Collectible, add SphereCollider and check Is Trigger, tag Collectible.
  4. Attach PlayerMovement.cs to Player and set moveSpeed and jumpForce in Inspector.
Test & Refine
  • Run. Use WASD/arrow keys to move; press Space to jump.
  • Collectible should fire OnTriggerEnter and be destroyed on contact.
  • If player falls through ground, check colliders and Rigidbody presence.
Debugging checklist
Confirm: Player has Rigidbody, Plane has Collider and IsTrigger unchecked, Collectible has Is Trigger checked, and movement code runs in FixedUpdate. Use Debug.Log messages to verify callback flow.
