Module 3 › Chapter 2.3 › Assessment Idea
Task A: Damage Zone
Create a lava cube, mark its collider Is Trigger, give it the tag DeathZone, and in player OnTriggerEnter check the tag and apply damage or respawn. This keeps the player from being physically blocked while still triggering game logic.
Task B: Spring Boost
On spring contact set rb.velocity = new Vector3(0, rb.velocity.y, 0) to stop horizontal movement, then call rb.AddForce(Vector3.up * springBoost, ForceMode.Impulse) to launch upward. This creates a crisp bounce effect.
Assessment check
Confirm: Lava triggers OnTriggerEnter and does not block player. Confirm: Spring stops horizontal motion and applies an instant upward impulse. Use Debug.Log to validate events.
