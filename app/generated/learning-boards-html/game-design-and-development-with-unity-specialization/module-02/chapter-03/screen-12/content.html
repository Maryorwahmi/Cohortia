Module 3 › Chapter 2.3 › Troubleshooting
Quick checklist
  • Is at least one object using a Rigidbody?
  • Is the collider marked Is Trigger correctly?
  • Are tag names and layer masks correct?
  • Are colliders aligned and sized to match the visual mesh?
Debug step
Add Debug.Log to OnCollisionEnter and OnTriggerEnter to see if callbacks fire. Use logs to narrow down whether the issue is physics, tags, or collider alignment.
Common error

Mixing transform.position updates with Rigidbody motion can cause missed collisions and jitter. Use Rigidbody APIs for physics objects.

Concrete fix
If player doesn't collect pickups, verify Collectible has Is Trigger checked and Player has Rigidbody. If not, set them accordingly and re-run the test.
