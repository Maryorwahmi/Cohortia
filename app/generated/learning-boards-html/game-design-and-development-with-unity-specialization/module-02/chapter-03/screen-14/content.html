Module 3 › Chapter 2.3 › Key Concepts
Rigidbody
Gives objects physical behavior; use Rigidbody2D for 2D projects and Rigidbody for 3D.
Collider & Is Trigger
Colliders define shapes. Is Trigger turns a collider into a sensor for detection without physical blocking.
Input & FixedUpdate
Use Input.GetAxis for smoothed movement values and apply them in FixedUpdate to modify Rigidbody for stable physics.
Summary Takeaway

Combine Rigidbody, correct colliders, and FixedUpdate-driven input handling to create predictable, testable gameplay movement and interactions.
