Basic Physics, Collision Detection, and User Input
Understand Rigidbody, Colliders, triggers, and the legacy input axes to build a reliable player controller.
In this lesson
Why Rigidbody matters, how forces and velocity differ, collision vs trigger events, and how to use Input.GetAxis with FixedUpdate for player motion.
Practical outcome
A working PlayerMovement script using Rigidbody, grounded checks, collectibles via triggers, and guidance for common debugging steps.
Physics stack
Rigidbody → Collider → Callbacks → Input
Attach a Rigidbody to let Unity move the object with gravity and forces. Add a Collider to detect contact. Use callbacks for events, and read Input axes to drive forces or velocity.
Quick tip
Never move physics objects by setting transform.position; use Rigidbody methods in FixedUpdate for stable collisions.
Common mistake
Forgetting a Rigidbody on either object prevents collision callbacks. If collisions don't fire, check for missing Rigidbodies or wrongly set Is Trigger flags.
