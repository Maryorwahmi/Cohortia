Module 3 › Chapter 2.3 › Applying Forces and Velocity
Step-by-step: AddForce
  1. Call rb.AddForce(Vector3.up * jumpForce, ForceMode.Impulse) to jump.
  2. Use ForceMode.Force for continuous pushes like wind.
  3. Tune mass and drag to shape acceleration and damping.
Step-by-step: velocity
  1. Compute movement vector from input and orientation.
  2. Normalize to avoid diagonal speed spikes.
  3. Set rb.velocity = new Vector3(move.x, rb.velocity.y, move.z) for direct control.
Common mistake

Using AddForce for tight character control without tuning can make movement feel slippery; consider direct velocity for arcade-like responses.

Concrete example
Inside FixedUpdate compute horizontal and vertical Input.GetAxis, build movement using transform.right and transform.forward, normalize, multiply by moveSpeed, then set rb.velocity while preserving current Y for gravity and jumps.
Key takeaway
Pick AddForce for emergent physics and velocity for deterministic movement. Tune mass, drag, and ForceMode to match the game's feel.
