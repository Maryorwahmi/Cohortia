Module 3 › Chapter 2.3 › Grounded Checks
Simple collision-based check
Set isGrounded true in OnCollisionEnter when you detect the Ground tag. Use this for straightforward platforms and flat surfaces.
Robust alternatives
  • Raycast down to check distance to ground and confirm contact normal.
  • Use Physics.OverlapSphere with a layer mask for ground detection.
  • Check contact normals in Collision.contacts to avoid walls setting grounded true.
Concrete example
OnCollisionEnter checks collision.gameObject.CompareTag("Ground"); set isGrounded = true. On jump, call AddForce with ForceMode.Impulse and set isGrounded = false to avoid double-apply.
Common mistake

Treating any collision as ground can allow wall-jumping. Filter by tag, layer, or contact normal to ensure correct behavior.
