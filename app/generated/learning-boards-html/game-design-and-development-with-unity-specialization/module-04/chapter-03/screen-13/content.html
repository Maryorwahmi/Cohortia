Module 4 › Chapter 4.3 › Hands-on Scene Setup
Step list
  1. Create Plane as ground.
  2. Create Player capsule, add Rigidbody, set Tag to Player.
  3. Create Coin sphere, enable Is Trigger, attach CollectibleItem script, duplicate.
  4. Create BouncyPlatform cube, make Physics Material Bouncy, assign to BoxCollider.
  5. Create Door, assign Interactable layer, attach Door script, add to PlayerInteraction LayerMask.
Quick checks
  • Player has Rigidbody and Collider.
  • Coins use Is Trigger and optional pooling for performance.
  • Bouncy platform uses 3D Physics Material with Bounce Combine set appropriately.
Key Takeaway

Assemble and test each mechanic in isolation, then combine them to validate interactions and performance.
