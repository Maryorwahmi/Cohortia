Module 4 › Chapter 4.3 › Collider Types & Use Cases
BoxCollider

Fast and stable for rectangular objects like crates, platforms, and simple environment blocks.

Use when: geometric simplicity and performance matter.
SphereCollider

Ideal for round objects and quick overlap checks such as pickups and projectiles.

Use when: radial symmetry and cheap checks are needed.
CapsuleCollider

Great for characters because it slides smoothly and reduces snagging on edges.

Use when: approximating humanoid bodies.
MeshCollider

Offers mesh-accurate collisions but is heavier. Non-convex mesh colliders are limited in interactions with dynamic rigidbodies and should be used mostly for static environments.

Best practice: use compound primitives first, fall back to MeshCollider for static complex shapes only.
