Module 4 › Chapter 4.3 › Tuning Rigidbody Properties
Step-by-step tuning
  1. Set reasonable defaults: mass 1, drag 0, angularDrag 0.05.
  2. Apply expected force in Play mode and observe acceleration.
  3. If object moves too easily, increase mass or reduce applied force.
  4. To reduce sliding after collision, increase drag.
  5. For scripted movers, enable isKinematic and move via Transform/Velocity in code.
Example scenario

You have a crate and a player push force of 5 units. If the crate mass is 0.5 it will fly away; raising mass to 5 makes the push feel realistic. If the crate keeps sliding after the push, increase drag to 1 to simulate friction-like damping.

Misconception check

Drag is not surface friction. Use Physics Materials on colliders to affect how surfaces slide against each other. Drag is global motion damping in the physics solver.

Key Takeaway

Tune Rigidbody values iteratively in Play mode; use isKinematic for script-driven movers that still need collision interaction.
