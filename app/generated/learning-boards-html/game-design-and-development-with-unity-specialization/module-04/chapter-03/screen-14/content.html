Debug Common Mistakes & Fixes
Fast checks
  • Is there a Rigidbody on at least one object?
  • Is the collider set to Is Trigger when expecting trigger callbacks?
  • Are you using a 3D Physics Material, not a 2D one?
  • Is the LayerMask configured for raycasts?
Debugging tools
  • Debug.DrawRay for visualizing raycasts in the editor.
  • Log collision.relativeVelocity to tune bounce thresholds.
  • Use the Physics Debug window to see colliders and contacts.
Pro Tip

When destroying objects on trigger, play effects first or use pooling to avoid frame hitches from allocations.
