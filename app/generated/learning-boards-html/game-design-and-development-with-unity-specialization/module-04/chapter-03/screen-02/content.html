Learning Objectives

Learn, understand, apply, and reach verified competency in Unity physics concepts.

01
Explain Rigidbody & Collider

Describe how a Rigidbody enables physics response while a Collider defines physical shape. Knowing this tells you which component to add when an object should move or only be detected.

VERIFIED COMPETENCY MILESTONE
02
Differentiate Collider types

Choose Box, Sphere, or Capsule for efficient collision checks and MeshColliders when you need mesh-accurate, static collisions. This choice impacts performance directly.

VERIFIED COMPETENCY MILESTONE
03
Implement collision & triggers

Write OnCollisionEnter/OnTriggerEnter handlers to create gameplay events like bouncing or collecting items. You'll check tags or interfaces to target logic safely.

VERIFIED COMPETENCY MILESTONE
04
Tune Physics Materials & Raycasts

Adjust friction and bounciness, and use raycasts with LayerMasks for selection and line-of-sight. These let you polish feel and precision in scenes.
