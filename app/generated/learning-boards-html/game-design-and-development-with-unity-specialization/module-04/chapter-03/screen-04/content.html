Module 4 › Chapter 4.3 › Rigidbody Fundamentals
Definition
Rigidbody

A component that hands motion control to Unity's physics engine so gravity, forces, and collisions affect an object. It is required for realistic physical response.

Key Properties
  • mass — affects acceleration from applied forces.
  • drag / angularDrag — reduce linear and rotational motion over time.
  • isKinematic — disable physics-driven motion while still allowing collision interactions with dynamic bodies.
Concrete example

A ball needs a Rigidbody so gravity pulls it down, friction slows it, and collisions with the ground produce a bounce. A door you animate should be kinematic so it doesn't react to physics pushes yet still collides with other objects.

Common mistakes & checks
  • Assuming a Collider alone allows physics movement — it doesn't. Add a Rigidbody for simulated response.
  • Making everything non-kinematic can cause unstable stacks; use isKinematic for scripted movers.
  • Incorrect mass values can make forces feel sluggish or too strong; tune incrementally.
Key Takeaway

Add a Rigidbody when you want physics-driven motion; set isKinematic when moving an object by script but still needing collisions with others.
