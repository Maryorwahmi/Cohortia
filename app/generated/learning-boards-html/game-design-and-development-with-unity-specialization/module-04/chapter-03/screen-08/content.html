Module 4 › Chapter 4.3 › CollectibleItem Script
Pattern explained
  • OnTriggerEnter receives a Collider for the entering object.
  • CompareTag guards logic so only the player triggers collection.
  • Perform UI/sound feedback before Destroy to ensure effects play.
Key Takeaway

Validate the collider's identity, play feedback, then remove or pool the item. This keeps gameplay responsive and maintainable.

Example code
using UnityEngine;

public class CollectibleItem : MonoBehaviour
{
  public string playerTag = "Player"; // Ensure your player GameObject has this tag

  void OnTriggerEnter(Collider other)
  {
    // Check if the collider entering the trigger belongs to the player
    if (other.CompareTag(playerTag))
    {
      Debug.Log("Player collected " + gameObject.name);
      // Here you would add logic for what happens when collected:
      // e.g., give points, play sound, update UI, destroy item
      Destroy(gameObject);
    }
  }

  void OnTriggerStay(Collider other)
  {
    // Optional: for visual feedback or other continuous effects
    // Debug.Log(other.name + " is still in the trigger area.");
  }
}
