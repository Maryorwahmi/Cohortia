Module 5 › Chapter 4.4 › Key Concepts
Match light to source
Directional, Point, Spot, Area each model real-world sources and scale differently in cost.
PBR maps matter
Albedo, Metallic, Smoothness, Normal, Occlusion define how surfaces react to light; import them correctly.
Bake first
Bake static lights for performance, add probes for dynamic objects, and use few real-time lights for interaction.
Summary

These principles provide a repeatable workflow: choose the right lights, author correct PBR maps, bake static lighting, and tune post-processing to support—not hide—your work.
