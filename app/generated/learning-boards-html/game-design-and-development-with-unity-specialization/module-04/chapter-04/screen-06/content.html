Module 5 › Chapter 4.4 › Point vs Spot
Comparison
Point Light
Omnidirectional emission. Best for bulbs and small local sources. Intensity decreases with distance.
Spot Light
Cone-shaped emission. Controls angle and range. Ideal for flashlights and directional effects.
Practical placement
Place point lights near sources of ambient glow. Use spot lights sparingly where you need focused visibility or drama.
Example & Takeaway
Example: In a dungeon passage mark ceiling torches static and bake them as Point Lights. Keep the player torch as a real-time Spot Light to illuminate moving objects. Takeaway: match light permanence to real-time requirement.
Key Takeaway

Prefer baked points for static scene fill; use a single moving spot for interactive focus to preserve performance.
