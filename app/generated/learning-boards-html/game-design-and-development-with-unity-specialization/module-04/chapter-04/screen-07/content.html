Module 5 › Chapter 4.4 › Real-time vs Baked
Define
Real-time lighting updates each frame and supports movement and animated effects. Baked lighting precomputes light interactions for static objects and stores results in lightmaps for runtime efficiency.
Pros of Real-time
Dynamic shadows and moving lights; required for flickering or mobile lights.
Pros of Baked
Complex indirect illumination, low per-frame cost, higher visual fidelity for static scenes.
Example & Guidance
Example: An interior level bakes room lighting and places Light Probes so moving characters sample indirect light. A torch on the player remains real-time and adds local shadows to dynamic objects. Guidance: bake everything that is static; reserve real-time lights for movement and interactivity.
Common mistake
Using too many real-time lights to try to achieve realism. Bake first, then add minimal real-time lights for behavior.
Key Takeaway

Pick baked for static geometry, real-time for dynamic elements. Use Light Probes to bridge the two.
