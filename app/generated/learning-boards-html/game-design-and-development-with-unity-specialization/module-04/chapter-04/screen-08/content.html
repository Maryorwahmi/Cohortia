Module 5 › Chapter 4.4 › Light Baking Workflow
Step-by-step
  1. Mark static geometry as Static in the Inspector.
  2. Open Window → Rendering → Lighting and set Environment and Skybox.
  3. Set lights that will be baked to Baked in their light Inspector.
  4. Adjust lightmap resolution and sample settings for quality vs memory.
  5. Click Generate Lighting and inspect the resulting lightmaps.
Key Takeaway

Follow the baking cycle and adjust lightmap settings to tradeoff quality and memory for your target platform.

Concrete example
Create a small room, add floor and walls, mark them Static, add a Point Light set to Baked, then generate lighting. Observe baked shadows and indirect color bleed. If lightmaps look blotchy, increase samples or tweak lightmap resolution, but measure memory impact.
Common mistakes
Forgetting to mark Static and using extremely high lightmap resolution unnecessarily.
Pro tip
Place Light Probes to carry baked indirect light to dynamic characters and moving objects.
