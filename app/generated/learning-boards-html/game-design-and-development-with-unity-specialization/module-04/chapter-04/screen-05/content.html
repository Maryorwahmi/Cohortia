Module 5 › Chapter 4.4 › Directional Light
Definition

Directional light behavior

Parallel rays, uniform illumination, rotation controls shadow angle, position ignored.

Visual effect
Creates consistent outdoor lighting and crisp shadows useful for sunlit scenes.
Practical tip
Rotate to change time of day. Do not rely on multiple directional lights to add contrast; use localized lights or post-processing for mood.
Key Takeaway

Directional lights are your global sun. Rotate for mood, bake for performance, and add local lights for variety.

Example & Misconception
Example: An outdoor plaza uses one Directional Light as the sun. Lamps around the plaza use baked Point Lights so they don’t add per-frame cost. Misconception: Multiple Directional Lights make the scene look brighter; in practice they create conflicting shadows and unrealistic lighting. Use localized lights instead for highlights.
Check
If shadow angles change when rotating, and position changes have no effect, the Directional Light is working as expected.
