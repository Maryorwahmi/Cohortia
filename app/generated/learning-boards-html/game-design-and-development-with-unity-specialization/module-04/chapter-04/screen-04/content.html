Definition

Common Unity light types

Each light type models a physical source and has trade-offs in range, shadowing, and performance.

Directional
Parallel rays, good for sun and global light. Rotation matters, position does not.
Point
Omnidirectional emission with distance falloff; ideal for bulbs and local lights.
Spot
Cone-shaped emission with angle and range controls; used for flashlights and focused beams.
Area
Rectangular emitters for soft light—typically baked due to cost.
Key Takeaway

Pick the light that models the physical source and scale its use by whether it must update at runtime.

Example & Common Mistake
Example: an outdoor scene uses a Directional Light for sun, Point Lights for lamps marked Baked, and a real-time Spot for a player flashlight. Common mistake: placing many small real-time point lights for decorative bulbs. This increases per-frame lighting cost and shadows. Instead, bake decorative bulbs into lightmaps or use emissive materials and a baked light for the overall glow.
Scenario
Indoor room with static lamps: mark lamps and walls Static and bake lights to get soft indirect bounces in lightmaps.
Check your understanding
If a light must flicker or move, it must be real-time. If it is purely decorative and static, prefer baking.
