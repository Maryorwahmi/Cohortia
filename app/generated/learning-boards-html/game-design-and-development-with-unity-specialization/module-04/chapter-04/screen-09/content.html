Definition

PBR in Unity

PBR aims for consistent, physically plausible material responses under different lighting conditions.

Albedo
Base color texture; set to sRGB color space.
Metallic
Defines metal vs non-metal behavior; metals reflect environment color.
Smoothness
Controls sharpness of specular reflections; high is glossy, low is matte.
Example
Robot (polished): Metallic near 1, Smoothness high, Albedo sets tint. Dungeon stone: Metallic 0, Smoothness low, Normal map for rough detail. Adjust maps and sliders to see immediate effect under your scene lights.
Common mistake
Using metallic values on inherently non-metal surfaces or importing textures in the wrong color space.
Key Takeaway

Tune Metallic and Smoothness first to define material family, then add Normal and Occlusion maps for detail.
