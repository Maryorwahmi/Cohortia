Module 5 › Chapter 4.4 › Post-Processing Stack
Setup steps
  1. Install Post-Processing from Package Manager.
  2. Add Post-process Layer to Main Camera and assign the PostProcessing layer.
  3. Create PostProcessVolume, check Is Global, and assign a Post-process Profile.
  4. Add and tune Ambient Occlusion, Bloom, and Color Grading effects.
Tuning tip
Compare before/after toggles to ensure effects enhance rather than hide lighting problems.
Effect roles
Bloom
Creates glow from bright areas and emissive surfaces.
Ambient Occlusion
Adds subtle contact shadows in crevices to improve depth perception.
Color Grading
Adjusts exposure, contrast, and saturation to set visual mood.
Key Takeaway

Use post-processing to enhance final appearance, but tune effects to support correct lighting and materials rather than obscure issues.
