Module 4 › Chapter 4.1 › Key Concepts
ProBuilder
In-editor mesh creation for rapid blockouts and modular assets.
Selection Modes
Vertex, Edge, Face, and Object control targeted mesh edits.
Extrude / Bevel / Inset
Core operations to add volume, detail, and softened edges.
Takeaway
Use the right tool for the right stage: ProBuilder for iteration, external modelers for production detail, and Terrain for organic landscapes. Optimize vegetation and textures as you populate the scene.
