UV basics

Unwrap faces onto 2D space so textures tile and align correctly.

Check for stretching on long or skewed faces; adjust scale or seams.

Example — wall texture
  1. Unwrap the wall faces in ProBuilder's UV editor.
  2. Set tiling so the brick texture repeats evenly across the surface.
  3. Preview in Scene view and adjust if seams or stretching appear.
When to export
If you need complex seam control or specialized lightmap UVs, export the mesh to a dedicated modeler for precise unwrapping.
Pro tip
For runtime tiling, use material tiling properties to reduce unique texture usage on many similar surfaces.
