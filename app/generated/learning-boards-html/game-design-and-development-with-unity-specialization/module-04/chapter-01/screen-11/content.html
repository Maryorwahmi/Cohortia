Module 4 › Chapter 4.1 › Terrain System overview
Core concepts
Heightmap: grayscale data representing elevation across the terrain.
Brushes: raise, lower, smooth, flatten to shape topography.
Layers & Splatmaps: paint and blend textures like grass and rock.
Concrete sculpting flow
  1. Add a Terrain object from the GameObject menu.
  2. Use Raise/Lower brush to shape hills and valleys.
  3. Use Smooth to remove harsh peaks and Flatten for paths.
  4. Paint textures using the Paint Texture tool and add layers as needed.
Key Takeaway
Sculpt terrain with gameplay in mind: ensure walkable slopes and clear sightlines for player movement and encounters.
