Module 4 › Chapter 4.1 › Blocking out with primitives
Step-by-step blockout

Create core primitives: floor, walls, columns. Keep scale consistent with player height.

Use extrude on faces to form walls from a floor cube. Inset then extrude to create openings like windows.

Duplicate and arrange primitives to block out larger spaces. Save scenes frequently as you iterate.

Example check
Walk the blockout in Play mode to ensure player fits and navigation works before detailing.
Visuals & common mistakes
Keep topology simple
Avoid extra subdivisions during early iteration. Simpler meshes are faster to edit and test.
Mistake: wrong unit scale
Using inconsistent scaling makes navigation testing inaccurate. Set a convention for player height and door widths first.
Pro tip
Label and group ProBuilder objects for easier positioning when you combine with terrain later.
