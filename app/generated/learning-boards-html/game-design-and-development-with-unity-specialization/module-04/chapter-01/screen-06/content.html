Module 4 › Chapter 4.1 › Selection Modes
Mode comparison
Vertex
Fine control of corners; use for precise alignment and curvature adjustments.
Edge
Modify outlines and loops; prepare for bevels and outline edits.
Face
Extrude, inset, or delete faces to create walls, windows, and openings.
Object
Move, rotate, and scale whole mesh objects in the scene.
Example & gotchas

Try making a window: select a wall face, inset to create a smaller rectangle, then extrude inward to produce the opening. If you remain in Vertex mode, you will only move corner points and not create new geometry.

When using Edge mode for a loop cut, ensure edges form a continuous loop; otherwise the operation may not behave as expected.

Common mistake:

Performing global transforms in Object mode when you intended to alter local faces leads to lost detail and extra fixes.
