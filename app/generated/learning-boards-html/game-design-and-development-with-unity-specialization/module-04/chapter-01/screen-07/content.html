Module 4 › Chapter 4.1 › Extrude, Inset, Bevel
Operation definitions
Extrude: creates new faces by pushing selected geometry to add volume.
Inset: makes a smaller face inside a face to prepare paneling or windows.
Bevel: chamfers edges to smooth transitions and improve shading.
Key Takeaway
Combine inset and extrude to create openings, then bevel to soften corners for a cleaner result.
Concrete example — window recess
  1. Select the wall face you want to open.
  2. Use Inset Faces to create a smaller rectangle inside that face.
  3. Extrude Faces inward to carve the window recess.
  4. Select edges around the opening and Bevel to soften the silhouettes.
Common pitfall
Extruding without supporting edge loops can create stretched faces and poor UVs. Add loops where needed.
Pro tip
Use the bevel operation sparingly on gameplay collision meshes to keep collision simple but visually pleasing.
