Module 04 › Chapter 4.2 › Controller Setup
Step-by-step
  1. Create a Capsule and rename to Player. Add CharacterController and match height/radius to model.
  2. Create PlayerMovement script and attach it. In Start, cache controller reference and disable if missing.
  3. In Update read Move input, compute camera-relative forward and right, zero out y, normalize, apply moveSpeed.
  4. Handle grounding via controller.isGrounded, apply manual gravity each frame, and set jump impulse when requested.
  5. Combine horizontal and vertical motion, call controller.Move(movement * Time.deltaTime).
Pro tip
Use a small negative vertical velocity when grounded to keep the controller snapped to slopes and avoid floating.

Pitfall
Calling controller.Move with incorrect delta scaling can produce inconsistent speeds across frame rates; multiply by Time.deltaTime.
