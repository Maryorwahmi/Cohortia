Module 04 › Chapter 4.2 › Input: Legacy vs New
Legacy Input
Uses Input.GetAxis and Input.GetButton. Simple but harder to remap and support multiple devices cleanly.
Example use:
float h = Input.GetAxis("Horizontal");
float v = Input.GetAxis("Vertical");
if (Input.GetButtonDown("Jump")) { /* jump */ }
New Input System
Define Input Actions like Move and Jump and bind them to multiple devices. Use callbacks or poll action values in Update.
Example mapping:
Move → WASD, Left Stick | Jump → Space, Gamepad South
Why it matters
Input Actions let you change bindings without touching movement code and make cross-device support straightforward.
Tip
Start with actions named for intent, not keys: Move, Jump, Look, Sprint.
Pitfall
Binding inconsistent dead zones for gamepad sticks can make movement feel different across controllers.
Check
Does pressing a key and moving the stick produce similar move magnitudes? Tune sensitivity if not.
