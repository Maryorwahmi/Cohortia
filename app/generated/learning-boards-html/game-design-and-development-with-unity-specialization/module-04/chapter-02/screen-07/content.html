// Example: Basic PlayerMovement
using UnityEngine;

public class PlayerMovement : MonoBehaviour
{
    public float moveSpeed = 5f;
    public float jumpForce = 8f;
    public float gravity = -20f; // Custom gravity for CharacterController

    private CharacterController controller;
    private Vector3 moveDirection;
    private float verticalVelocity;
    private bool isGrounded;

    void Start()
    {
        controller = GetComponent<CharacterController>();
        if (controller == null)
        {
            Debug.LogError("CharacterController not found on this GameObject.");
            enabled = false; // Disable script if no controller
        }
    }

    void Update()
    {
        // Movement, gravity, and controller.Move called here
    }
}
The snippet above shows the structure: public tuning fields, cached controller, and space for Update logic. Keep physics state like verticalVelocity inside the script so jumps behave consistently.
Explanation cards
Gravity handling
Accumulate gravity into verticalVelocity each frame and include it in the movement vector so the controller falls naturally.
Camera-relative movement
Compute forward and right from the main camera with y=0 so forward input moves toward where the player is looking horizontally.
Grounding trick
When grounded and verticalVelocity is negative, set it to a small negative value to keep contact with uneven terrain.
