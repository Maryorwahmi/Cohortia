Module 04 › Chapter 4.2 › Learning Objectives — Implementation Focus
Implementation Focus
Concrete actions to perform in your scene and the tests to verify success.
Set up CharacterController scene
Create a Capsule named Player, add CharacterController, attach PlayerMovement script. Verify the player walks, climbs small steps, and doesn't float after jump.
Create Rigidbody scene
Attach a Rigidbody to the player, control velocity or apply forces in FixedUpdate, and test interactions with moving objects like rolling boulders.
Implement Input Actions
Define Move, Jump, and Look actions and bind them to keyboard and gamepad so the same code responds to multiple devices.
CameraTarget and smoothing
Parent a CameraTarget to the player, script the camera to follow it in LateUpdate, and clamp vertical rotation to avoid awkward angles.
Testing checklist
Ground check passes, jump returns to ground, camera doesn't clip, Rigidbody reacts to forces.
Common pitfall
Updating Rigidbody velocity in Update may cause inconsistent physics; use FixedUpdate for forces and velocity changes.
