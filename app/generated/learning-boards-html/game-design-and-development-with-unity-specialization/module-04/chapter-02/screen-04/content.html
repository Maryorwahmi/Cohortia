Module 04 › Chapter 4.2 › CharacterController: definition
Core Concept
CharacterController behavior
A non-physics-driven mover that handles collisions and sliding. You supply movement vectors; it prevents penetration and steps over small obstacles when tuned.
Key properties
  • slopeLimit: controls maximum climbable incline.
  • stepOffset: allows automatic stepping up small ledges.
  • isGrounded: reports whether controller touches ground.
Common mistake
Forgetting manual gravity makes the character float after jump. Always add a vertical velocity term to movement before Move().
Walkthrough: how movement works
The script computes a desired horizontal vector relative to camera orientation, normalizes it, scales by speed, then combines it with verticalVelocity and calls controller.Move(delta).
<!-- Example pseudocode flow, not exact code --> desired = normalized(camera.forward * v + camera.right * h) * speed if grounded and jumpPressed: verticalVelocity = jumpForce else: verticalVelocity += gravity * deltaTime movement = desired + Vector3.up * verticalVelocity controller.Move(movement * deltaTime)
Example
A platformer uses CharacterController for tight, non-slippery movement and well-controlled jumps.
Takeaway
CharacterController = deterministic control, manual gravity, adjustable slope/step tuning.
