Module 1 › Chapter 1.1 › Database vs Instance
Definition

Database: physical files

The database is the collection of files stored on disk that contain data and transactional logs.

Example
Data files and redo logs remain on disk when an instance is stopped for maintenance.
Definition

Instance: memory and processes

An instance consists of memory structures like the SGA and the background processes that operate on the database files.

Contrast
Multiple instances may access a single database in clustered configurations; instance-level tuning affects memory and processes, not file layout.
Key Takeaway

Use precise terminology: manage files at the database level and resources at the instance level to avoid misdiagnosis.
