Module 1 › Chapter 1.1 › Schema & User
Hierarchy

Schema = logical collection

A schema is a namespace of database objects that is owned by a user. Objects include tables, views, indexes, and procedures.

Concrete practice
Create a user for an application and store its tables in that user's schema for clear ownership and privilege boundaries.
Practical security

Users and privileges

Grant only needed privileges to users, and avoid broadly granting access across schemas. This supports least-privilege and reduces risk.

Misconception check
Schemas are not separate databases; they are logical namespaces inside the same physical database files.
Key Takeaway

Use schema ownership and targeted privileges to manage access and simplify administration.
