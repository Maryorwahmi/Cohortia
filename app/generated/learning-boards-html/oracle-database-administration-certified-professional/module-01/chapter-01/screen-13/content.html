Module 1 › Chapter 1.1 › Key Concepts
Oracle Database
A robust RDBMS for high concurrency, durability, and enterprise workloads.
Editions
EE: full features; SE2: core features with limits; XE: free with resource caps.
Database vs Instance
Database = files on disk. Instance = in-memory processes that manage the files.
Takeaway
Use edition-aware design, precise terminology, and a requirements-first approach to avoid costly migrations and operational mistakes.
