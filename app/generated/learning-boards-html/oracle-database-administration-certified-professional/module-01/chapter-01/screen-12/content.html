Hands-on activity

Attempt to create a partitioned table in XE

Run the SQL shown below in SQL*Plus or SQL Developer connected to an XE instance and observe the error returned by the database.

-- Connect as a user with CREATE TABLE privilege
CREATE TABLE sales_data (
  sale_id      NUMBER PRIMARY KEY,
  product_id   NUMBER,
  sale_date    DATE,
  amount       NUMBER(10,2)
)
PARTITION BY RANGE (sale_date) (
  PARTITION p_q1_2023 VALUES LESS THAN (TO_DATE('01-APR-2023','DD-MON-YYYY')),
  PARTITION p_q2_2023 VALUES LESS THAN (TO_DATE('01-JUL-2023','DD-MON-YYYY'))
);
Expected result
ORA-00439: feature not enabled: Partitioning — this indicates partitioning is an EE-only feature and not available in XE.
Guided reflection
If you encounter ORA-00439, record it and either remove the partition clause for XE development or plan an upgrade to Enterprise Edition for production.
Common mistake
Assuming the error is a privilege or syntax issue. Edition limits are explicit and require a feature or edition change.
Key Takeaway

Edition-aware development prevents later surprises: test feature availability early and plan migrations when needed.
