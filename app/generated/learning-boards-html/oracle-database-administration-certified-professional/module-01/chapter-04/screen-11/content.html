Module 1 › Chapter 1.4 › Lab: Configure & Connect
Steps
  1. Create or open ORACLE_HOME/network/admin/tnsnames.ora.
  2. Add MYDB_CONNECTION with ADDRESS (PROTOCOL=TCP)(HOST=localhost)(PORT=1521) and CONNECT_DATA (SERVICE_NAME=ORCLPDB).
  3. Save file and ensure permissions allow reading by your client.
  4. In a terminal, run sqlplus hr/hr_password@MYDB_CONNECTION and verify with SELECT SYSDATE FROM DUAL.
  5. If connection fails, run lsnrctl status on the server and check for advertised services or start the listener.
Example tnsnames entry
MYDB_CONNECTION = (DESCRIPTION = (ADDRESS = (PROTOCOL = TCP)(HOST = localhost)(PORT = 1521)) (CONNECT_DATA = (SERVER = DEDICATED) (SERVICE_NAME = ORCLPDB)))
Example outcome
Successful result: sqlplus shows Connected. and SELECT SYSDATE FROM DUAL returns a date. Failure modes point you to listener problems or tnsnames typos.
Key Takeaway

This lab ties the text file, the listener, and the client together: correct entries plus a running Listener equal a successful connection.
