Module 1 › Chapter 1.4 › SQL*Plus Basics
Connection pattern
sqlplus username/password@NetServiceAlias
Example
-- Connect as normal user sqlplus hr/hr_password@MYDB_CONNECTION -- Check the session and time SHOW USER; SELECT SYSDATE FROM DUAL;
Useful SQL*Plus commands
  • SET LINESIZE 150 to format output
  • DESCRIBE table_name to inspect columns
  • @/path/to/script.sql to run a script
Admin checks
When you need instance-level information, connect AS SYSDBA (with care) and run queries like SELECT INSTANCE_NAME, STATUS FROM V$INSTANCE; and SELECT FILE_NAME FROM DBA_DATA_FILES; to inspect files and status.
Caution

SYSDBA grants full control. Use least privilege and avoid routine tasks with SYSDBA unless necessary for startup, shutdown, or critical maintenance.
