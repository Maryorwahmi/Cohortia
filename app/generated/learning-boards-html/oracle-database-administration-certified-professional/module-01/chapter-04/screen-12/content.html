Module 1 › Chapter 1.4 › Key Concepts
Oracle Net
Networking layer that carries client requests to the database over TCP.
Oracle Net Listener
Process that accepts connections and routes them to the instance; managed with lsnrctl.
tnsnames.ora / Net Service Name
Client-side file mapping an alias to host, port and service name for connections.
Takeaway

Master the listener check, tnsnames entry composition, and SQL*Plus basics to be effective at first-line connectivity troubleshooting and basic administration.
