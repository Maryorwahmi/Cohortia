Module 1 › Chapter 1.4 › Learning Objectives
01
Explain Oracle Net and the Listener
Describe how the Listener accepts client requests and hands them to the instance. This is essential to know where to start diagnosing connectivity problems.
Mnemonic: network socket → Listener → server process
Verified Competency Milestone
02
Manage the Listener with lsnrctl
Use lsnrctl status, start, and stop to confirm listener availability and which services it advertises. This is usually your first troubleshooting step.
Mnemonic: status first, then start/stop
Verified Competency Milestone
03
Configure tnsnames.ora Net Service Names
Create or edit entries mapping an alias to host, port and service name so clients can connect using a short identifier.
Mnemonic: alias → address → connect_data
Verified Competency Milestone
04
Use SQL*Plus and SQL Developer for checks
Connect via SQL*Plus to run queries like selecting the current date or checking V$INSTANCE, and use SQL Developer for visual browsing when available.
Mnemonic: command-line checks then GUI for exploration
Verified Competency Milestone
