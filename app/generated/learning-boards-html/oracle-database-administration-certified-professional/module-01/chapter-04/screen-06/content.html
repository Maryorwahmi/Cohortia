Structure
Net Service Name entry
MYDB_CONNECTION = (DESCRIPTION = (ADDRESS = (PROTOCOL = TCP)(HOST = localhost)(PORT = 1521)) (CONNECT_DATA = (SERVER = DEDICATED) (SERVICE_NAME = ORCLPDB) ) ) )
  • ADDRESS gives protocol, host and port used by the Listener.
  • CONNECT_DATA identifies the target service name or SID.
  • Put the file in ORACLE_HOME/network/admin or the TNS_ADMIN location.
Checks & Pitfalls
Common mistakes
  • Using SID instead of SERVICE_NAME for a pluggable database.
  • Typos in host, port, or alias.
  • Wrong file location so the client cannot find the entry.
Try this

After saving an entry, test by connecting with sqlplus user/password@MYDB_CONNECTION and run SELECT SYSDATE FROM DUAL to confirm the session works.
