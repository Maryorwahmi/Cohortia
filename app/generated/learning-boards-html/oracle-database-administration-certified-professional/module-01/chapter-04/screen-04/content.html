Module 1 › Chapter 1.4 › Oracle Net and Listener
Definition
Oracle Net and Listener
Oracle Net provides the transport; the Listener accepts and hands connections to the instance.
Listener responsibilities
  • Accept incoming client requests on configured port.
  • Determine target instance/service and hand off the connection.
  • Report status when queried with lsnrctl.
Misconception
The Listener does not host database state. A running instance can be healthy while the Listener is stopped; remote clients would still be blocked from creating new sessions.
Key Takeaway

The Listener is the first component to check when clients cannot connect; use lsnrctl to confirm it is up and listening on the expected port and service.

Analogy & Example
Analogy: view the Listener as a receptionist who takes incoming calls and routes them to staff in different departments. If the receptionist is absent, callers cannot reach staff.
Connection sequence (example)
1) Client resolves Net Service alias. 2) Client opens TCP to host:1521. 3) Listener accepts and checks CONNECT_DATA. 4) Listener hands session to server process.
Check this command
lsnrctl status
Shows whether the Listener is running and which services it advertises.
