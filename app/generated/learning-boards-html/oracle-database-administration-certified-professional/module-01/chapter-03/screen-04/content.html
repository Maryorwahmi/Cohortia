Core Concept
Data Files (.dbf)
Files that store tables, indexes, and metadata blocks. They define tablespace capacity.
Database blocks inside data files are the smallest I/O unit defined by DB_BLOCK_SIZE at creation.
Each data file belongs to one tablespace. The tablespace may have multiple files.
Segment allocations use extents, which are contiguous blocks inside these files.
Key Takeaway
Treat data files as physical containers for tablespaces and monitor their size and status closely.

Concrete example
A table in Tablespace A will have its blocks stored inside datafile_a01 or a02. The tablespace capacity is the sum of those files.
Common mistake
Assuming a tablespace equals a single file. In reality it can span multiple files across disks.
