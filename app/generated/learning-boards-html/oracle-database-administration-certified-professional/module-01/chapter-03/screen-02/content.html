Learning Objectives
These skills will let you inspect files and explain storage relationships for safe operation.
01 Identify files
Locate and describe data files, redo logs, control files, parameter files, and the password file; know their purpose and why each must be protected.
VERIFIED COMPETENCY MILESTONE
02 Logical hierarchy
Explain blocks, extents, segments, and tablespaces and how they combine to store table and index data inside data files.
VERIFIED COMPETENCY MILESTONE
03 Map logical to physical
Use queries and file listings to map a tablespace to its data files and interpret file sizes and statuses.
VERIFIED COMPETENCY MILESTONE
04 Protect metadata
Recognize the role of control files and redo logs in recovery, and the best practices of multiplexing and disk separation.
VERIFIED COMPETENCY MILESTONE
