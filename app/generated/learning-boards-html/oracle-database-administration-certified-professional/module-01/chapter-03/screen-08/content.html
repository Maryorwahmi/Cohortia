Password File (orapwd)
Encrypted file that enables SYSDBA and SYSOPER connections when the database is not open.
Purpose
Allow privileged remote connections prior to database open.
Security
Protect with strict OS permissions; loss or exposure risks administrative control.
Practical tip
Keep a backup copy and ensure only authorized operators can read or write it.
Concrete example
Use orapwd to create a file and verify that SYS connections at mount time succeed without opening the database.
Common mistake
Leaving the password file accessible to more than the DBA group increases risk of unauthorized SYS access.
