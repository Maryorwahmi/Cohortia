Module 1 › Chapter 1.3 › Logical Hierarchy
Blocks → Extents → Segments → Tablespaces
A hierarchical view that explains how logical objects map into physical space.
Block
Smallest I/O unit defined by DB_BLOCK_SIZE.
Extent
Contiguous blocks allocated to a segment.
Segment
Set of extents for a table, index, or rollback segment.
Tablespace
Logical container composed of one or more data files.
Concrete example
A growing table receives new extents in the tablespace's data files. That growth is visible as increased file usage on disk.
Misconception
Segments are not the same as files; they may span many files via extents inside a tablespace.
