Module 1 › Chapter 1.2 › CKPT, ARCH, RECO
CKPT — Checkpoint

CKPT updates data file headers and control files with checkpoint information and signals DBWn to flush dirty blocks to reach that consistent point.

ARCH — Archiver

ARCH copies filled online redo log files to an archive destination in ARCHIVELOG mode so redo history is preserved for media recovery.

RECO — Recoverer

RECO resolves distributed transaction failures by connecting to other databases and attempting to complete or rollback the involved transactions.

Example

Before a hot backup CKPT creates a checkpoint so DBWn can write dirty buffers, ensuring the backup represents a consistent point in time. ARCH ensures redo from earlier work is kept for recovery.

Key Takeaway

These processes reduce recovery time and preserve redo history. Monitor them during backups and distributed operations.
