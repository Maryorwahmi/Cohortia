Module 1 › Chapter 1.2 › Bottlenecks & Responses
Symptom → Cause → Action
Log file sync waits
Cause: LGWR blocked by slow redo I/O or many small commits. Action: move redo logs to faster storage, reduce commit frequency.
High DBWn I/O
Cause: Buffer cache churn due to small DB_CACHE_SIZE or heavy writes. Action: increase cache or improve data file storage throughput.
Excessive parsing
Cause: No bind variables or undersized Shared Pool. Action: fix SQL and size Shared Pool after measuring.
Checklist
  • Collect V$SGAINFO and V$SGASTAT outputs.
  • Correlate waits with OS I/O and process activity.
  • Apply targeted changes and measure the effect.
Key Takeaway

Diagnose before tuning: match symptoms to specific actions rather than sweeping changes.
