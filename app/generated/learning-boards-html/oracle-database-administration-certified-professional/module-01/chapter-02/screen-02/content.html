Learning Objectives

These objectives focus on description, explanation, interaction, and diagnosis—skills you will practice with V$ views.

01
Describe SGA memory areas

Explain Shared Pool, Buffer Cache, Redo Log Buffer and optional pools and their role in avoiding disk I/O.

Verified competency milestone
02
Explain background processes

Name PMON, SMON, DBWn, LGWR, CKPT, ARCH, RECO and state what each does and when it runs.

Verified competency milestone
03
Illustrate SGA & process interaction

Trace a transaction from parsing to redo and eventual disk writes to see where latency arises.

Verified competency milestone
04
Diagnose SGA and process bottlenecks

Use V$ views and parameter checks to identify undersized caches or redo I/O problems and propose actions.

Verified competency milestone
