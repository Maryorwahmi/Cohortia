Module 1 › Chapter 1.2 › Buffer Cache & DBWn
Behavior

The buffer cache holds data blocks in memory. Modified blocks are marked dirty and DBWn writes them to data files to ensure persistence.

Cache hits vs misses
Higher hit ratios mean fewer disk reads and faster queries.
Dirty blocks and eviction
Evicting dirty blocks forces DBWn to write them first, increasing I/O.
Monitoring
  • Use V$ views to measure buffer cache hit ratios and DBWn write counts.
  • Correlate high DBWn activity with I/O metrics to decide between resizing or storage tuning.
Example scenario

A reporting job scans many rows, filling the cache with new blocks and pushing out dirty blocks. DBWn writes increase and disk I/O saturates, causing user queries to slow.

Key Takeaway

Measure cache usage first. If DBWn I/O is high, consider larger DB_CACHE_SIZE or faster storage for data files.
