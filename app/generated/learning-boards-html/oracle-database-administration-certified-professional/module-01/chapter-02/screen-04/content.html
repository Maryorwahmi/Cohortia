Module 1 › Chapter 1.2 › SGA
Definition

SGA is the shared memory pool used by the instance to cache data, parsed SQL, and control information for performance and recovery.

Key areas
  • Shared Pool: parsed SQL, data dictionary cache.
  • Database Buffer Cache: data blocks for reads and writes.
  • Redo Log Buffer: change records for recovery.
  • Optional pools: Large Pool, Java Pool, Streams Pool.
Common mistake
Treating SGA as one setting and resizing randomly can cause fragmentation or swapping.
Illustration: SGA as caches
Shared Pool
Stores library cache and dictionary cache to avoid reparsing and repeated object lookups.
Database Buffer Cache
Holds data blocks read from data files; cache hits speed queries and reduce disk I/O.
Redo Log Buffer
A circular buffer of redo entries that LGWR flushes to the online redo logs for durability.
Example

A SELECT finds a block in the buffer cache and returns results without disk I/O. A DML marks a block dirty and LGWR writes redo before commit.

Key Takeaway

Measure SGA components before tuning; each area serves a distinct purpose.
