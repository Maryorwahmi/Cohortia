Module 1 › Chapter 1.2 › Key Concepts
System Global Area

A shared memory region containing the Shared Pool, Buffer Cache, Redo Log Buffer and optional pools.

Background Processes

PMON, SMON, DBWn, LGWR, CKPT, ARCH, and RECO perform cleanup, recovery, writes, and archiving duties.

Monitoring & Diagnosis

Use V$SGAINFO, V$SGASTAT and process/session joins to collect evidence before tuning.

Summary Takeaway

Memory components and processes are distinct but tightly coupled; measure interactions and tune with evidence.
