Detection Method

Anomaly-Based Detection

Detecting Deviations from Normal Behavior

How it Works

Establish Baseline

Learns normal network/system behavior over time.

Continuous Monitoring

Compares current activity against the established baseline.

Anomaly Flagging

Deviations from baseline are flagged as potential intrusions.

Key Characteristics

  • •Detects Zero-Days: Can identify novel or unknown attacks.
  • •Higher False Positives: Legitimate unusual activity can trigger alerts.
  • •Requires Tuning: Needs significant effort to reduce false alarms.
Example Scenario

A server suddenly transmits 500GB of data to an external IP, far exceeding its normal 10GB daily average, triggering an anomaly alert.

Key Takeaway

Anomaly-based detection excels at finding new threats but demands careful tuning to manage its higher rate of false positives.
