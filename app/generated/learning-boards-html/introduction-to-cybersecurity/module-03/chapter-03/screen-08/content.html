Deployment Type

Host-based IDPS (HIDS/HIPS)

Granular Protection for Individual Systems

Host View

Individual Host

Runs as software on servers or workstations.

Internal Activities

Monitors system calls, file changes, logs, processes.

Granular Protection

Detects host-specific attacks like rootkits or privilege escalation.

Key Considerations

  • •Resource Consumption: Uses host CPU and memory.
  • •Per-Host Management: Requires installation and configuration on each endpoint.
  • •Complements NIDS: Catches threats NIDS might miss.
Example Scenario

A HIDS detects an unauthorized modification to a critical system file on a web server, indicating a potential rootkit installation.

Key Takeaway

HIDS/HIPS provides deep, internal visibility and protection for individual systems, essential for detecting host-specific compromises.
