Detection Method

Signature-Based Detection

Identifying Threats by Known Patterns

How it Works

Signature Database

Collection of known attack patterns (e.g., malware hashes, exploit strings).

Traffic Analysis

IDPS inspects network packets and system logs.

Pattern Matching

If activity matches a signature, an alert is triggered or action is taken.

Key Characteristics

  • •High Accuracy: Very effective at detecting known threats.
  • •Low False Positives: Typically generates fewer false alarms.
  • •Requires Updates: Database must be regularly updated to stay effective.
Limitation Highlight

Cannot detect zero-day attacks or novel threats for which no signature exists. It's reactive to known vulnerabilities.

Key Takeaway

Signature-based detection is reliable for known threats but requires constant updates and is blind to new, unknown attack vectors.
