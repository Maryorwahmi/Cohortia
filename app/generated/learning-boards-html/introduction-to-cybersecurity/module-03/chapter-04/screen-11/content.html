SSH: Secure Remote Command-Line Access
Encrypting your terminal sessions for server management
Definition

A cryptographic network protocol for secure remote command-line access to computers, providing an encrypted channel over an unsecured network.

Primary Use Case

System administrators managing remote Linux/Unix servers, executing commands, and transferring files securely (e.g., via SCP).

Key Takeaway

SSH provides a secure, encrypted channel for remote command-line access, essential for system administrators managing servers and ensuring data confidentiality.

# Connect to a remote server via SSH
ssh user@remote_ip

# Example: Connect as 'admin' to 192.168.1.100
ssh admin@192.168.1.100

# Securely copy a file using SCP (Secure Copy Protocol)
scp local_file.txt user@remote_ip:/path/to/destination/

# Example: Copy 'report.pdf' to remote server's home directory
scp report.pdf admin@192.168.1.100:/home/admin/
