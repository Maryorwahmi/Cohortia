Network Models: OSI vs. TCP/IP

Frameworks for Understanding Communication Layers

OSI Model (7 Layers)

  • •
    Theoretical Framework: A conceptual model for understanding network communication.
  • •
    Seven Layers: Physical, Data Link, Network, Transport, Session, Presentation, Application.
  • •
    Security Implication: Helps categorize where different security controls (e.g., firewalls, encryption) operate.
Common Misconception

The OSI model is rarely implemented directly, but it's a valuable teaching tool for understanding network functions.

TCP/IP Model (4/5 Layers)

  • •
    Practical Implementation: Directly maps to how the internet works.
  • •
    Four/Five Layers: Network Access, Internet, Transport, Application (sometimes Presentation/Session are combined into Application).
  • •
    Security Implication: More practical for understanding real-world attack surfaces and defense mechanisms.
Key Takeaway

Both models help visualize network communication, but TCP/IP is more relevant for practical internet security.
