Port Numbers: Doors to Services

Specific Entry Points on Networked Devices

What are Port Numbers?

A 16-bit number that identifies a specific process or service running on a network device. It allows multiple services to run on a single IP address.

  • •
    Function: Directs incoming network traffic to the correct application.
  • •
    Analogy: An apartment number in a building (IP address).
Security Risk

Every open port is a potential entry point for attackers. Unsecured services on open ports are major attack vectors.

Common Well-Known Ports

  • •
    Port 80: HTTP (unsecure web traffic)
  • •
    Port 443: HTTPS (secure web traffic)
  • •
    Port 22: SSH (secure remote access)
  • •
    Port 53: DNS (domain name resolution)
Key Takeaway

Monitor open ports and secure services to minimize attack surface.
