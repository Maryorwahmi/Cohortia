Network Reconnaissance with Command-Line Tools

Using Basic Utilities to Gather Information

Key Command-Line Tools

  • •
    ipconfig / ifconfig: Display network interface configuration (IP address, subnet mask, gateway).
  • •
    ping: Test connectivity to a host and measure latency.
  • •
    traceroute / tracert: Map the route data packets take to a destination.
  • •
    netstat: Show active network connections, listening ports, and associated processes.
Common Use

Attackers use these same tools for initial reconnaissance to find targets and vulnerabilities.

Terminal Demo: netstat

C:\> netstat -ano

Active Connections

  Proto Local Address          Foreign Address        State           PID
  TCP   0.0.0.0:22             0.0.0.0:0              LISTENING       1234
  TCP   0.0.0.0:80             0.0.0.0:0              LISTENING       5678
  TCP   192.168.1.100:49152    172.217.160.142:443    ESTABLISHED     9012
  UDP   0.0.0.0:53             *:*                                    3456
  • •
    Identify: Open ports (22, 80, 53) and active connections.
  • •
    Investigate: Research unfamiliar PIDs or listening ports for suspicious activity.
