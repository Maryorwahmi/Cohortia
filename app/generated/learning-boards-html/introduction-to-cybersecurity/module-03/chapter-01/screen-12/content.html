Data Protection

Common Mistakes: Unencrypted Traffic and Exposure

Encrypting Sensitive Data and Controlling Network Access

Unencrypted Traffic

  • •
    Vulnerability: Data sent over HTTP or plain FTP is easily intercepted.
  • •
    Risk: Passwords and sensitive information can be read by attackers.
Example

Sending login credentials over an HTTP connection, allowing them to be captured by network sniffers.

Best Practice

Always use encrypted protocols like HTTPS, SFTP, and SSH for all sensitive communications.

Exposing Internal Services

  • •
    Increased Risk: Internal services are often less secure by design.
  • •
    Attack Vector: Direct exposure to the internet creates an easy target.
Key Takeaway

Never expose internal services to the internet unless absolutely necessary and with robust security.
