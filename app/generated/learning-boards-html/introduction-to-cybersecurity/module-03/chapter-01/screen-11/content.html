Configuration Pitfalls

Common Mistakes: Default Configurations and Unnecessary Services

Eliminating Easy Entry Points for Attackers

Default Configurations

  • •
    Publicly Known: Default usernames/passwords are often easily found online.
  • •
    Easy Exploitation: Attackers can use these to gain unauthorized access.
Example

Leaving a router with its default 'admin/password' credentials, making it vulnerable to takeover.

Pro-Tip

Always change default credentials immediately after device setup and use strong, unique passwords.

Unnecessary Services

  • •
    Increased Attack Surface: Each running service is a potential vulnerability.
  • •
    Resource Consumption: Unneeded services use system resources.
Key Takeaway

Disable all services not explicitly required for a system's function to reduce risk.
