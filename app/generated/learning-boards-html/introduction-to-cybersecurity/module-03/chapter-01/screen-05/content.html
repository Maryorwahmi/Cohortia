IP Addresses: The Network's Street Address

Unique Identifiers for Digital Communication

What is an IP Address?

A unique numerical label assigned to each device connected to a computer network. It enables devices to locate and communicate with each other.

Versions: IPv4 & IPv6

  • •
    IPv4: e.g., 192.168.1.1 (32-bit, limited addresses)
  • •
    IPv6: e.g., 2001:0db8:... (128-bit, vast address space)

Role in Cybersecurity

  • •
    Target Identification: First step in network reconnaissance.
  • •
    Access Control: Used in firewall rules to allow or block traffic.
  • •
    Logging & Forensics: Track source and destination of network activity.
Key Takeaway

IP addresses are fundamental for network communication and a critical component in both attack and defense strategies.
