Network Segmentation: Limiting the Blast Radius

Dividing networks into isolated, secure subnetworks

What is it?

The practice of dividing a large computer network into multiple smaller, isolated segments or subnetworks.

  • Each segment can have its own security policies.
  • Communication between segments is controlled by firewalls or routers.
Key Benefit

Limits the "blast radius" of an attack. If one segment is breached, the attacker is contained, preventing lateral movement to other critical parts of the network.

Key Takeaway
