Virtual Local Area Networks (VLANs): Logical Isolation

Segmenting networks using switches for enhanced control

What are VLANs?

Logically segment a network using switches, allowing devices to be grouped regardless of physical location.

  • Devices on different physical ports can be on the same logical network.
  • Devices on the same physical switch can be on different logical networks.

Key Takeaway
