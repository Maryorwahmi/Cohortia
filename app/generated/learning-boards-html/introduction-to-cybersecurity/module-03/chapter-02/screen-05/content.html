Packet-Filtering Firewalls: Basic Traffic Inspection

Decisions based solely on packet headers

How it Works

Inspects individual data packets as they pass through, checking specific fields in the packet header.

  • Examines Source/Destination IP addresses.
  • Checks Port Numbers (e.g., 80 for HTTP, 443 for HTTPS).
  • Identifies Protocol Types (e.g., TCP, UDP, ICMP).
  • Makes decisions based *only* on header information.
Key Characteristic

Packet-filtering firewalls are stateless; they do not remember past packets or the context of an ongoing connection, making them vulnerable to certain attacks.

Key Takeaway

Packet-filtering firewalls are fast but limited, making decisions based only on packet headers without understanding the broader context of a network connection.
