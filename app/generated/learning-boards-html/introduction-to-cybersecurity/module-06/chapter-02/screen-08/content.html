Automating Log Analysis with Python

Extracting Insights from Security Logs

Script Breakdown

  • Import re: For regular expression operations.
  • Define IP Pattern: A regex to match standard IPv4 addresses.
  • File Handling: Opens and reads the log file line by line.
  • Extract IPs: Uses findall to get all IPs, stores unique ones in a set.
Key Takeaway

Python scripts significantly reduce manual effort in log analysis, enabling faster incident detection.

Python Log Parsing Script

import re

def extract_ips_from_log(log_file_path):
    ip_pattern = re.compile(r'\b(?:\d{1,3}\.){3}\d{1,3}\b')
    found_ips = set() # Use a set to store unique IPs

    try:
        with open(log_file_path, 'r') as f:
            for line in f:
                ips = ip_pattern.findall(line)
                for ip in ips:
                    found_ips.add(ip)
    except FileNotFoundError:
        print(f"Error: Log file not found at {log_file_path}")
    return list(found_ips)

if __name__ == "__main__":
    log_file = "sample_access.log" # Replace with your log file path
    # Create a dummy log file for demonstration
    with open(log_file, 'w') as f:
        f.write("192.168.1.100 - GET /index.html
")
        f.write("Failed login from 203.0.113.45
")
        f.write("Request from 10.0.0.1 and 172.16.0.255
")
        f.write("Another entry with 192.168.1.100
")

    ips = extract_ips_from_log(log_file)
    print(f"Found IP addresses: {ips}")
