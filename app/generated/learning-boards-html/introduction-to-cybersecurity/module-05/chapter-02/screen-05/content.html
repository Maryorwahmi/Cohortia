Access Control Model

Discretionary Access Control (DAC)

Owner-Centric Permission Management

Key Characteristics of DAC

  • •Resource owner determines access rights.
  • •High flexibility in assigning permissions (read, write, execute).
  • •Common in personal computing and collaborative cloud environments.
  • •Can lead to inconsistent permissions in large-scale systems.
Key Takeaway

DAC offers granular control to resource owners but requires careful management to prevent security gaps in complex environments.
