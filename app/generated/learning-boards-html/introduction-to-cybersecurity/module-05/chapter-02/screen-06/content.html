Access Control Model

Mandatory Access Control (MAC)

Rigid, Policy-Driven Security for High-Risk Environments

Key Characteristics of MAC

  • •Access decisions based on security labels (e.g., 'Top Secret').
  • •Central authority enforces all access rules; users cannot override.
  • •Used in high-security environments (government, military).
  • •Offers strong protection against unauthorized data disclosure.
Key Takeaway

MAC provides the highest level of security through strict, centrally enforced policies, making it ideal for highly sensitive data.

MAC in Action: Classified Information System

User (Subject)

Assigned Clearance: Confidential

Document (Object)

Assigned Classification: Top Secret

Access Denied

User's clearance (Confidential) is lower than document's classification (Top Secret). Access is automatically blocked by the system, regardless of owner intent.
