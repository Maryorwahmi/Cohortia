NIST Phase 2

Identification: Detecting and Verifying Incidents

Spotting anomalies and confirming security breaches to initiate response.

Key Activities

  • •Monitor systems and networks for anomalies.
  • •Analyze logs from various sources (servers, firewalls, applications).
  • •Correlate security alerts to identify patterns and potential threats.
  • •Verify the scope and nature of the suspected incident.

Example: Brute-Force Detection

A SIEM system detects 50 failed login attempts to a critical server from a single external IP address within 5 minutes, followed by a successful login. This pattern triggers an incident alert.

Critical Tools

  • •**SIEM (Security Information and Event Management):** Centralizes and analyzes security logs.
  • •**IDS (Intrusion Detection Systems):** Monitors network traffic for suspicious activity.
  • •**Antivirus/Endpoint Detection & Response (EDR):** Detects malware and suspicious behavior on endpoints.
Key Takeaway

Effective identification relies on a combination of automated monitoring tools and skilled human analysis to accurately detect and confirm cybersecurity incidents.
