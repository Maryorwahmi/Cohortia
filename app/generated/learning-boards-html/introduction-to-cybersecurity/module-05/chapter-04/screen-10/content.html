NIST Phase 4

Eradication: Eliminating the Root Cause

Removing threats and patching vulnerabilities to prevent recurrence.

Key Eradication Activities

  • •Remove all traces of malware and malicious files.
  • •Patch exploited vulnerabilities in software and systems.
  • •Reconfigure systems to close security gaps and harden defenses.
  • •Rebuild compromised systems from trusted, clean backups if necessary.

Example: Web Server Compromise

After containing a web server defacement, the IRT identifies and patches the SQL injection vulnerability, removes the malicious code, and hardens the web application firewall rules before bringing the server back online.

Primary Goals of Eradication

  • •Completely eliminate the threat from the environment.
  • •Address the root cause to prevent immediate recurrence.
  • •Ensure the environment is clean and secure for recovery.
Key Takeaway

Eradication is about thoroughness: completely removing the threat and fixing the underlying vulnerabilities to ensure the incident does not immediately reoccur.
