Practical Triage: Investigating a Linux System

Using netstat, ps aux, and last for Initial Assessment

# Simulate checking active network connections
echo "--- Simulating netstat -tulnp output for suspicious activity ---"
echo "Active Internet connections (only servers)"
echo "Proto Recv-Q Send-Q Local Address           Foreign Address         State       PID/Program name"
echo "tcp        0      0 0.0.0.0:22              0.0.0.0:*               LISTEN      123/sshd"

echo "Observation: User 'hacker' logged in from a suspicious external IP (203.0.113.50)."

Interpreting Observations

  • •netstat: Look for unknown established connections to external IPs, especially on unusual ports.
  • •ps aux: Identify processes with high resource usage, suspicious names, or running under unexpected user accounts.
  • •last: Check for unauthorized logins, especially from external or unfamiliar IP addresses.
Key Takeaway

These commands provide immediate, actionable intelligence to confirm a compromise and guide initial containment efforts without altering the system significantly.
