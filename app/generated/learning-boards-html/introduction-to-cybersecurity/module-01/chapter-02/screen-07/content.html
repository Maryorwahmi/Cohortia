Malware Types

Spyware and Trojan Horses: Deception and Surveillance

Hidden Threats That Monitor and Mislead

Spyware

  • •Covert Monitoring: Secretly collects user information.
  • •Data Collected: Keystrokes, browsing history, screenshots, personal data.
  • •Purpose: Identity theft, targeted advertising, espionage.
Example

A program installed with free software that tracks your online shopping habits and sends data to advertisers.

Trojan Horse

  • •Deceptive Appearance: Disguised as legitimate software.
  • •No Self-Replication: Relies on user to install it.
  • •Malicious Payload: Opens backdoors, steals data, or installs other malware.
Example

A fake software update that, once installed, creates a backdoor for an attacker to access your system.

Key Takeaway

Spyware secretly monitors user activity, while Trojan horses deceive users into installing malicious software that then performs harmful functions.
