Attack Types

DoS and DDoS: Overwhelming the Target

Making Resources Unavailable to Legitimate Users

Denial-of-Service (DoS)

  • •Single Source: Attack traffic originates from one computer system.
  • •Goal: Overwhelm a target system's resources (bandwidth, CPU, memory).
  • •Impact: Prevents legitimate users from accessing services.
Example

A single attacker repeatedly sending requests to a web server until it crashes or becomes unresponsive.

Distributed Denial-of-Service (DDoS)

  • •Multiple Sources: Attack traffic from many compromised systems (botnet).
  • •Scale: Much larger volume of traffic, harder to block.
  • •Impact: Can bring down large-scale services and infrastructure.
Example

A botnet of thousands of infected computers simultaneously flooding a popular e-commerce website with requests, making it inaccessible.

Key Takeaway

DoS attacks make resources unavailable from a single source, while DDoS attacks achieve the same from multiple distributed sources, making them more potent.
