Core Concept

Vulnerabilities: Weaknesses Attackers Exploit

Identifying Gaps in Systems and Human Behavior

What is a Vulnerability?

A vulnerability is a weakness or flaw in a system, design, or implementation that can be exploited by an attacker to compromise security. These weaknesses can be technical or human-related.

  • •Definition: An exploitable flaw or weakness.
  • •Scope: Can exist in software, hardware, configurations, or human processes.
  • •Impact: Allows attackers to bypass controls and achieve malicious goals.
Concrete Example

Leaving default administrative passwords on network routers is a configuration vulnerability that attackers can easily exploit.

Types of Vulnerabilities

System: Unpatched software, misconfigurations, weak encryption.

Human: Lack of awareness, susceptibility to manipulation, negligence.

Attackers exploit both technical and human weaknesses to gain access.
Key Takeaway

Vulnerabilities are exploitable weaknesses in systems or human behavior that attackers actively seek to compromise security.
