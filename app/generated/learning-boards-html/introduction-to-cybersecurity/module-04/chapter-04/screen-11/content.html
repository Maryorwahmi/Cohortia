Principle 3

Input Validation

Rigorously checking all user input to prevent common attacks like SQL injection or cross-site scripting (XSS). Never trust user input; always validate and sanitize it.

  • Prevents malicious code injection.
  • Ensures data conforms to expected formats.
  • Defends against SQL injection and XSS.
Key Takeaway

Validating all input and enforcing least privilege are critical for preventing attacks and limiting the scope of potential breaches.

Principle 4

Least Privilege

Software components should run with the absolute minimum necessary permissions to perform their intended function. This limits the potential damage if a component is compromised.

  • Minimizes attack surface.
  • Contains breaches to specific components.
  • Reduces the impact of successful exploits.
Example: Web Server Permissions

Restricted File Access

A web server process should only have read access to web content files and write access only to specific log directories. It should not have administrative privileges or write access to critical system files. This prevents an attacker from defacing the entire server if they compromise the web application.
