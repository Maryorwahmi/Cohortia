Definition

What is a Patch?

A patch is a piece of software designed to update a computer program or its supporting data to fix or improve it. This includes fixing security vulnerabilities, bugs, and sometimes adding new features.

  • Targets specific flaws or bugs.
  • Often addresses critical security vulnerabilities.
  • Can also improve performance or add minor features.
  • Released by software vendors.
Key Takeaway

Patches are essential software updates that fix security flaws and improve system stability, making them vital for ongoing protection.

Process

What is Patch Management?

Patch management is the systematic process of acquiring, testing, and installing these patches across all systems and applications within an organization. It's a continuous, cyclical process.

  • **Acquisition:** Obtaining patches from trusted vendors.
  • **Testing:** Verifying compatibility and stability in a non-production environment.
  • **Deployment:** Installing patches across all target systems.
  • **Verification:** Confirming successful application and vulnerability mitigation.
Risk Alert

The 'Patch Gap'

This is the critical time between a patch being released and it being applied. During this window, systems are highly vulnerable to exploitation by attackers who are constantly scanning for unpatched systems. Minimizing this gap is crucial.
