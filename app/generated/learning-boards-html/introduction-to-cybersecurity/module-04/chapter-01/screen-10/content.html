Configuring Host-Based Firewalls: Tools and Basic Rules

Implementing Device-Specific Network Policies

Key Takeaway

Use tools like `ufw` to configure basic firewall rules, such as allowing SSH, but always exercise caution to prevent accidental lockouts.

Safety Note

Always test new firewall rules cautiously, especially in production environments, to ensure you don't block essential management access.

Linux Firewall: UFW Example
# 1. Enable ufw and set default deny incoming policy
sudo ufw enable
sudo ufw default deny incoming
sudo ufw default allow outgoing

# 2. Allow SSH access (port 22)
sudo ufw allow ssh
# Or by port number: sudo ufw allow 22/tcp

# 3. Verify firewall status
sudo ufw status verbose

These commands set a secure default policy and open only the necessary SSH port.
