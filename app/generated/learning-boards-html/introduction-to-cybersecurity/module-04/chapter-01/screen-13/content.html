Key Concepts

Essential Terms to Remember

Zero-day Exploit

A cyberattack targeting an unknown software vulnerability with no available patch.

EDR (Endpoint Detection and Response)

Continuously monitors endpoints for suspicious activities, detecting and responding to threats.

Host-based Firewall

Software that controls network traffic to and from a single computer, enforcing security policies.

Summary Takeaway

EDR systems are crucial for detecting zero-day exploits through behavioral monitoring, while host-based firewalls provide essential device-level network traffic control.
