Key Concepts: Web & Network Vulnerabilities

Essential Terms to Remember

SQL Injection

A web app vulnerability allowing malicious SQL code insertion, leading to unauthorized database access.

Cross-Site Scripting (XSS)

A web app vulnerability allowing injection of client-side scripts into web pages, executing in victim's browser.

Port Scanning

A technique to identify open ports and services on a network host, used for both auditing and reconnaissance.

Summary Insight

Securing web applications and networks requires understanding vulnerabilities like SQL Injection and XSS, and recognizing the dual nature of tools like port scanners.
