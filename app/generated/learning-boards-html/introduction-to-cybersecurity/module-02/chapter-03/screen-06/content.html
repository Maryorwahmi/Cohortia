APT Lifecycle: Expanding Control
Elevating Privileges and Moving Through the Network
Phase 3

Privilege Escalation

Attackers gain higher levels of access or permissions within the compromised network. This allows them to bypass security controls and access more sensitive resources.

  • Exploiting software vulnerabilities
  • Leveraging misconfigured systems
  • Cracking or stealing credentials
Phase 4

Lateral Movement

Attackers spread across the network from an initially compromised system to other systems, identifying and accessing critical assets and data. This expands their control and reach.

  • Using stolen credentials for remote access
  • Exploiting network service vulnerabilities
  • Leveraging legitimate remote administration tools
Key Takeaway

Privilege escalation grants attackers deeper control, while lateral movement allows them to spread across the network, seeking out and accessing high-value targets.
