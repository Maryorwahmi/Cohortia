Module 2 › Chapter 2.2 › Relational & Logical
Relational operators
==, !=, >, <, >=, <= — compare values and return 1 (true) or 0 (false).
Example
age == 18 evaluates to 1 if age equals 18, otherwise 0. Beware of using = instead of ==.
Common mistake
Using assignment in place of comparison often compiles but yields unintended truthiness. Use == for equality checks.
Logical operators
&& (AND), || (OR), ! (NOT). Combine relational results to form compound conditions.
Scenario
(age > 18 && hasLicense) is true only when both are true. Use short-circuiting to protect code: pointer && pointer->field.
Key Takeaway

Use relational operators to compare and logical operators to combine; watch for assignment vs comparison mistakes and use short-circuit to guard evaluations.
