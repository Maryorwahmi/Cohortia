Module 2 › Chapter 2.2 › Prefix vs Postfix
Behavior
Prefix: perform the change, then use the new value. Postfix: use the current value, then perform the change.
Concrete example
int x = 5;
int y = ++x; // x==6, y==6
int z = x++; // z==6, x==7
Pitfall
Using ++ in complex expressions can lead to ambiguous intent and bugs. Prefer separate statements for clarity.
When to use which
In tight loops, either form is acceptable if only used for counting. When value is used immediately for computation, choose the form that matches the desired timing.
Try this
Run the chapter's counter example and predict val1 and val2 before executing. This reveals the timing difference clearly.
Key Takeaway

Prefix modifies before use; postfix modifies after. Avoid embedding these in larger expressions to prevent surprises.
