Module 2 › Chapter 2.2 › Safe Expressions
Checks to add
  • Verify divisor != 0 before division or modulus
  • Guard pointer dereferences with null checks before using fields
  • Avoid side effects inside complex expressions; separate into statements
Example guard
if (count != 0) { average = (double)total / count; } else { /* handle zero count */ }
Why it matters
These checks prevent crashes and undefined behavior, making your programs safe on unexpected inputs.
