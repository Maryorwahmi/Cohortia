Module 2 › Chapter 2.2 › Arithmetic Operators
Operators
  • + addition, - subtraction, * multiplication
  • / division — integer division truncates when both operands are int
  • % modulus — remainder of integer division, useful for parity checks
Concrete example
int a = 7 / 3;    // a == 2
double b = (double)7 / 3; // b == 2.333...
Common mistake
Assigning integer division to a double after the fact still loses precision. Cast before dividing.
Practical uses
Use modulus for even/odd or wrapping indices, and use floating-point division for averages and ratios.
Scenario
Compute items per box: cast total count to double first to avoid truncated average.
Key Takeaway

Integer division truncates; cast when you need fractional results and always check divisors for zero.
