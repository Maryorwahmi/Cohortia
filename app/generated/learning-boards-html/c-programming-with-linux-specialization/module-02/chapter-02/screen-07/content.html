Module 2 › Chapter 2.2 › Assignment Operators
Forms
  • = simple assignment
  • +=, -=, *=, /=, %= compound assignments combine operation and store
Example
int sum = 0; sum += value; // adds and assigns in one step
Practical note
If left-hand side has side-effects, be careful with evaluation order. Compound assignment evaluates the left expression once.
Type interactions
Assignments apply conversions. Assigning a double result into an int will truncate unless you cast explicitly. Be intentional with types.
Scenario
Use += to accumulate scores. If score is int and addition yields double, cast or change type to avoid truncation.
Key Takeaway

Compound assignments combine operation and store; they improve clarity and may avoid recomputing complex left-hand expressions.
