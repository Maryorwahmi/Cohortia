Given snippet
int x = 10;
int y = 3;
double z = 2.5;

int result1 = x / y;
double result2 = x / z;
int result3 = x % y;
int result4 = (x > 5 && y < 5);
int result5 = x++ + --y;
result1 -> 3 (integer division)
result2 -> 4.0 (x promoted to double)
result3 -> 1 (10 % 3)
result4 -> 1 (both comparisons true)
result5 -> 12, final x = 11, y = 2
Key Takeaway
Work out effects of promotions and update timing to compute final values precisely.
