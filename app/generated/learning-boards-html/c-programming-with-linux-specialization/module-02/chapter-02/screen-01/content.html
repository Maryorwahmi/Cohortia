Operators and Expressions
Perform calculations, make comparisons, and change state safely and predictably.
In this lesson

Learn arithmetic, relational, logical, assignment, increment/decrement, bitwise operators, precedence, and casting. See concrete examples and a hands-on demo pattern to explore behaviors.

Why it matters

Operators drive every computation in a C program. Predicting results avoids bugs such as wrong averages or unexpected side-effects from postfix increments.

Explore Key Topics
Arithmetic & Modulus
Integer vs floating-point division and using % to test parity.
Prefix vs Postfix
Order of update matters; prefix updates before use, postfix after.
Precedence & Casting
Control evaluation with parentheses and use casts to get precise results.
Visual Concept
Cards show operator groups. Use them like a toolbox: arithmetic for math, relational for comparisons, logical to combine conditions, and bitwise for per-bit control.
Quick Example
int a = 7/3;   // integer division -> 2
double b = (double)7/3; // floating-point -> 2.333...
