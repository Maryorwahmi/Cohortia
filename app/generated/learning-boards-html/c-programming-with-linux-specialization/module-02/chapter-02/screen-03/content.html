Practice & Safety Objectives
Check divisors
Always validate denominators before division to avoid runtime errors.
Use explicit casts
Cast to double when you expect fractional results instead of integer truncation.
Avoid = in conditionals
Use == to compare values; = assigns and can create logic bugs.
Try this
Before running a snippet, write down the expected outputs for integer division, postfix vs prefix increments, and a casted average. Then compile and compare results.
