Module 2 › Chapter 2.1 › Constants: const vs #define
const (typed)
Declaration example: const float PI = 3.14159;. The compiler enforces immutability and the identifier has a type and scope.
#define (preprocessor)
Example: #define MAX_USERS 100. The preprocessor replaces occurrences before compilation; no type and no debugger address.
When to use which

Use const for safe, typed constants. Use #define for conditional compilation or simple textual macros when necessary.

Examples and checks

const double PI = 3.14159; // typed, scoped

#define PROGRAM_VERSION "1.0.0" // textual substitution

Key Takeaway

Prefer const for readability and type checking; know that #define happens before the compiler and is purely textual.
