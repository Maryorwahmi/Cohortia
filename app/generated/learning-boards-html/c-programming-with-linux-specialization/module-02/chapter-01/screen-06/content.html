Module 2 › Chapter 2.1 › Declare and Initialize Variables
Step-by-step
1. Declare
Example: int count; reserves memory but does not set a value.
2. Initialize
Example: int count = 0; assigns a known starting value.
3. Use safely
Read and modify the variable only after initialization to avoid undefined behavior.
Common mistake
Assuming local variables are zeroed by default. They are not; initialize them explicitly.
Concrete example
If you write int attempts; printf("%d", attempts); you may see arbitrary numbers. Replace with int attempts = 0; to produce deterministic output.
Key Takeaway

Initialize variables immediately and choose the narrowest scope that fits the need.

Pro tip
Give variables meaningful initial values to make code self-documenting and easier to debug.
