Module 2 › Chapter 2.1 › What is a Variable?
Core idea

A variable reserves memory and lets you refer to it by name. The data type determines how much memory is reserved and what operations make sense.

Examples
int score = 0;
Reserves an integer box and initializes it to zero to avoid garbage values.
double temperature = 25.5;
Reserves a higher-precision box for decimal numbers.
Key Takeaway

Always initialize variables to avoid unpredictable behavior from leftover memory.

Common mistake

Using an uninitialized variable can produce different results on different systems; do not rely on default values.

Memory analogy
Imagine a warehouse of boxes. Declaring a variable places a labeled box on a shelf sized for the type you selected. Initializing the variable puts the first item into that box. sizeof lets you measure the box width and depth on the actual machine.
Check your understanding
  • Why should you initialize a variable? — To avoid garbage values left in memory.
  • Is a variable the same as its value? — No; a variable is the labeled storage location that holds values.
