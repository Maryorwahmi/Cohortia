Module 2 › Chapter 2.1 › Using sizeof to Inspect Memory
Example code
#include <stdio.h>

int main() {
  int score = 100;
  double temp = 25.5;
  char letter = 'A';
  printf("Size of int: %zu bytes
", sizeof(int));
  printf("Size of score: %zu bytes
", sizeof(score));
  printf("Size of double: %zu bytes
", sizeof(double));
  printf("Size of char: %zu bytes
", sizeof(letter));
  return 0;
}
Run this program to see how many bytes each type occupies on your machine. Use these results to make informed type choices.
Notes and gotchas
  • sizeof(type) returns size in bytes of the type on the target architecture.
  • sizeof(variable) returns the same size as sizeof(type) for that variable.
  • When arrays decay to pointers, sizeof no longer reports element count — be mindful when using sizeof in functions.
Key Takeaway

Verify sizes with sizeof rather than assuming; it prevents subtle bugs and portability issues.
