Module 2 › Chapter 2.1 › Practical Example
Sample program
#include <stdio.h>

// Define constants
#define MAX_ATTEMPTS 3
#define PROGRAM_VERSION "1.0.0"

int main() {
  int score = 100;
  double temperature = 25.5;
  char grade = 'A';
  unsigned int user_count = 1500;
  const float PI = 3.14159f;

  printf("--- Variable Information ---
");
  printf("Score: %d (Size: %zu bytes)
", score, sizeof(score));
  printf("Temperature: %.2f (Size: %zu bytes)
", temperature, sizeof(temperature));
  printf("Grade: %c (Size: %zu bytes)
", grade, sizeof(grade));
  printf("User Count: %u (Size: %zu bytes)
", user_count, sizeof(user_count));

  printf("
--- Constant Information ---
");
  printf("PI constant: %.5f (Size: %zu bytes, if stored as a variable)
", PI, sizeof(PI));
  printf("Max Attempts (from #define): %d
", MAX_ATTEMPTS);
  printf("Program Version (from #define): %s
", PROGRAM_VERSION);

  return 0;
}
Compile with your compiler and observe the printed sizes. Then try uncommenting a line that assigns to PI to see the compile-time error demonstrating const immutability.
What to observe
  • The sizes printed by sizeof for each type on your target system.
  • That #define values are substituted and don't have a type at compile-time.
  • That const prevents reassignment and leads to a compiler error when modified.
Key Takeaway

Run the program and treat the outputs as a reality check for assumptions about sizes and constant behavior on your platform.
