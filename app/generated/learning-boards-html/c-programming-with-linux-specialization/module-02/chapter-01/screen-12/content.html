Module 2 › Chapter 2.1 › Common Mistakes and How to Spot Them
Errors to watch
  • Uninitialized variables — always initialize.
  • char vs string confusion — check quotes and terminators.
  • Signed/unsigned comparisons — watch implicit promotions.
  • Literal overflow — add suffixes like UL when needed.
Debug checklist
  1. Enable compiler warnings and fix them.
  2. Print values and sizeof results during testing.
  3. Use explicit initialization and narrow scope.
  4. Add comments describing expected ranges to catch anomalies.
Key Takeaway

Treat compiler warnings as allies; initialize and check sizes to prevent subtle bugs.
