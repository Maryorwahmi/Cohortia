Type snapshots
int
Whole numbers, typically 4 bytes. Use it for counters and indices. Example: int attempts = 3;
double
Decimal numbers with higher precision, typically 8 bytes. Prefer for calculations needing accuracy.
char
Single character, 1 byte, stores ASCII value. Example: char letter = 'A';
Common misconception
Float and double are sometimes used interchangeably, but double provides more precision and reduces rounding error for most applications.
Concrete example
A game stores player score as int score = 100; because scores are whole numbers. A physics calculation uses double velocity = 9.80665; to preserve decimal precision. A user's initial is stored as char initial = 'J';.
Key Takeaway

Pick types by meaning and precision needs: prefer double for decimal accuracy and char for single characters.
