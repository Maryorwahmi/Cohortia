Quick orientation

We will inspect types' sizes with sizeof, practice safe initialization, refine integer ranges with modifiers, and compare const with #define so you can pick the right tool for each need.

Visual concept
int
Box size: typically 4 bytes. Use for whole numbers. Example: int score = 0;
double / float
Decimal numbers. Prefer double for precision. Example: double temperature = 25.5;
char
Single character, 1 byte, holds ASCII code. Example: char grade = 'A';
