Module 2 › Chapter 2.1 › Type Modifiers
Modifier table
signed int
Default int; can store negative and positive numbers. Example: int delta = -5;
unsigned int
Stores only non-negative values, doubling the positive range. Example: unsigned int count = 1000;
short / long
Adjust storage width: short for smaller range; long for larger range when needed.
Examples and pitfalls
  • Use unsigned for sizes and counts to avoid negative values that don't make sense semantically.
  • Be careful comparing signed and unsigned values; implicit conversions can produce unexpected large positive numbers.
  • Large literals should include suffixes like UL to ensure the literal matches the intended unsigned long type.
