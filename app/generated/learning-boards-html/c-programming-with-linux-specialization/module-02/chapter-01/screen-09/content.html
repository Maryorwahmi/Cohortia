Module 2 › Chapter 2.1 › char vs String
Single char
A char holds one character, for example char c = 'A';. It stores an integer value corresponding to ASCII, so arithmetic is possible.
String literal
A string like "Hi" is an array of char that includes a terminating null character. char s[] = "A" results in two elements: 'A' and '\0'.
Common mistake
Assigning a string literal to a single char variable or treating a char as a string will cause type or runtime issues.
Concrete examples

char initial = 'J'; // single byte

char name[] = "J"; // two bytes: 'J' and '\0'

Key Takeaway

Be intentional: choose char for single characters and arrays for textual data requiring termination.
