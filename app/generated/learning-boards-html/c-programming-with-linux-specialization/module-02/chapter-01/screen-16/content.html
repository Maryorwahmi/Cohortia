Initialize
Always give variables an initial value to avoid unpredictability.
Verify sizes
Use sizeof to remove assumptions about type widths on different systems.
Use const
Prefer typed const for immutability and clearer compiler errors.
Final takeaway

Small habits — initialization, verifying sizes, and proper use of constants and modifiers — make C programs robust and portable.
