Module 2 › Chapter 2.1 › Key Concepts
Variable
A named storage location in memory whose value can change during execution.
Data Type
Specifies the kind of data and how much memory the compiler reserves for the variable.
const / #define
const gives typed, scoped immutability; #define performs textual substitution before compilation.
Takeaway

Choosing the right type, initializing variables, and using constants correctly prevents subtle bugs and improves portability.
