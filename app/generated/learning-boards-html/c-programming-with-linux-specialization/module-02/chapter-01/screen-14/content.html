Module 2 › Chapter 2.1 › Scope and Lifetime of Variables
Scope levels
Block / Local
Declared inside a block or function; visible only there and lifetime ends when the block exits.
Global
Declared outside functions; visible across the program and exist for the program lifetime.
Best practice

Keep scope narrow. Use globals sparingly and document why they are needed.

Concrete example
Inside a function use int temp = 0; for short calculations. If many functions need the same configuration, consider a well-documented global const or pass the value explicitly.
Key Takeaway

Use local variables for temporary work and globals for truly shared, stable configuration; prefer const globals if immutability is desired.
