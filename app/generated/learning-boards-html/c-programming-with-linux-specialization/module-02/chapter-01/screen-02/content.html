These objectives build from recognition to correct application so you can write reliable C code.

01
Differentiate data types
Name each fundamental type and explain when to use it. Example: choose double for precise decimal calculations.
Verified Competency Milestone
02
Declare and initialize safely
Write declarations with initialization to avoid garbage values, and explain scope and memory reservation.
Verified Competency Milestone
03
Define constants
Use const for typed, scoped constants and #define for textual substitution when appropriate.
Verified Competency Milestone
04
Apply type modifiers
Choose short, long, signed, or unsigned to match data ranges and avoid overflow; know when unsigned is appropriate for counts.
Verified Competency Milestone
