Specifier comparison
Integers
%d or %i → int
Floating point
%f → float/double for printf. Use %lf with scanf for double.
Character
%c → char (use a leading space in scanf to skip whitespace: " %c")
Strings
%s → char array; supply a max width like %9s to avoid overflow.
Practical tip

If your program prints garbage or crashes, the first check is whether the format specifier matches the variable type passed. A mismatched pair often explains strange output or runtime errors.

Mini exercise
int n = 42;
printf("as int: %d
", n);
printf("mistake as float: %f
", n);
Run this to observe the wrong output and understand why mapping matters.
