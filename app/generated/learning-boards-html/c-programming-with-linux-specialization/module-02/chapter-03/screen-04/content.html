Module 2 › Chapter 2.3 › printf()
Code examples (try these in a C file)
#include <stdio.h>

int main() {
  int score = 95;
  double price = 12.5;
  printf("Hello, %s! Your score is %d.
", "Alice", score);
  printf("Price: $%.2f
", price);
  printf("Literal percent: 50%% complete
");
  return 0;
}
Explanation & tips
  • %d prints integers; use %i interchangeably for decimal integers.
  • Use %.2f to show two decimal places for floats or doubles when printing money or precise values.
  • %s expects a null-terminated character array; do not pass non-string pointers or uninitialized arrays.
  • To print a percent sign, include %% in the format string.
Key Takeaway

Match specifiers to types and use precision to communicate values correctly to users.
