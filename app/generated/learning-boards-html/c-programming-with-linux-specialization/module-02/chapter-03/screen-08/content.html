Module 2 › Chapter 2.3 › if Statement
Syntax example
if (score >= 60) {
  printf("You passed!
");
}
The condition must evaluate to nonzero for the block to run. Use braces to include multiple statements safely.
Common mistake demo
if (x > 5)
  printf("A
");
  printf("B
");
// The second printf always runs; use braces to fix.
Pro tip

Always add braces. It prevents logical mistakes when adding statements later.
