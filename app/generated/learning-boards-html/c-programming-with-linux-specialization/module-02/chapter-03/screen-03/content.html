Safety checklist
  • Always pass &variable to scanf for non-array variables so input is written into your variable's memory.
  • When using %s, limit width: use %9s for a 10-byte buffer to leave space for the null terminator.
  • Check scanf's return value; it tells how many items were successfully read.
  • Consume leftover newline characters before reading a char using scanf(" %c", &ch) or using getchar loops.
  • Always use { } even for single-line if blocks to avoid misplaced else and readability problems.
Quick mnemonic
Ampersand → Address. Braces → Block. Return value → Verify.
Try this in the shell: compile small programs and test invalid inputs to see how scanf behaves; observing failure helps you understand why checks matter.
