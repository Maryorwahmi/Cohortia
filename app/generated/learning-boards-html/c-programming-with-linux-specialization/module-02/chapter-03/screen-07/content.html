Module 2 › Chapter 2.3 › scanf() Pitfalls
Buffer overflow example
char name[10];
// Unsafe:
// scanf("%s", name);
// Safer with width:
scanf("%9s", name);
Always leave space for the null terminator and restrict input width for fixed buffers.
Trailing newline and char reads
After reading a number, the newline stays in the buffer. Use a leading space in the format: scanf(" %c", &ch) to skip whitespace, including newlines, before reading a character.
Input mismatch

If scanf expects a number and receives letters, it returns 0 and leaves the invalid input in the buffer. Check the return value to detect this case early.
