Basic I/O & Control Flow

In this chapter you will learn to format output, read input safely, and control program flow with conditionals.

Interactive 16:9 Masterclass
Why I/O matters

Programs talk to users through formatted text and react to typed input; that opens them to real-world tasks like calculators, quizzes, and utilities.

Why conditionals matter

Conditionals let your program branch based on input and state, enabling different behavior for different users or data ranges.

What we'll cover
  • Formatted printing with printf and common format specifiers.
  • Reading input with scanf, the address-of operator, and safety notes.
  • Conditional constructs: if, else if, else, nested if, and the ternary operator.
Visual Concept
Keyboard → scanf() → variable memory (address)
printf() formats values → Console output
if / else → choose which message to print
