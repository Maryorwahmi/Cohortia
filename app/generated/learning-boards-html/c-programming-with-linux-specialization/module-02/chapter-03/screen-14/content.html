Module 2 › Chapter 2.3 › Key Concepts
printf()
Formatted output; use precision and width to present values clearly.
scanf()
Reads input into addresses; pass & for scalars and limit string widths.
Conditionals
Use if, else if, else, and ternary to branch. Order and braces matter for correctness.
Takeaway

Combining correct formatting, safe input practices, and clear conditional structure produces interactive programs that behave predictably and are easier to maintain.
