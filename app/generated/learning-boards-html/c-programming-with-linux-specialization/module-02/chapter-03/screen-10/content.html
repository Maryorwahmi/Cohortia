Module 2 › Chapter 2.3 › Nested if & Operators
Nested example
if (user_logged_in) {
  if (user_is_admin) {
    printf("Welcome, Admin!
");
  } else {
    printf("Welcome, User!
");
  }
}
Flattened with logical AND
if (user_logged_in && user_is_admin) {
  printf("Welcome, Admin!
");
} else if (user_logged_in) {
  printf("Welcome, User!
");
} else {
  printf("Please log in.
");
}
Flattening reduces indentation and often improves clarity; ensure expressions are safe when short-circuiting is relied upon.
