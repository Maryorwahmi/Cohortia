Module 2 › Chapter 2.3 › Activity: Run & Test
Save, compile, run
// Save as grade_calculator.c
// Compile:
gcc grade_calculator.c -o grade_calculator
// Run:
./grade_calculator
Try inputs: 95 → A, 82 → B, 70 → C, 55 → F, -5 or 105 → Error, text → Invalid input.
Testing checklist
  • Does the program compile without warnings? Fix format specifier mismatches if warnings appear.
  • Does invalid input trigger the error message as expected?
  • Do edge scores (89, 90) map to the correct grades according to your thresholds?
  • Can you add a loop to reprompt on invalid input as an enhancement?
