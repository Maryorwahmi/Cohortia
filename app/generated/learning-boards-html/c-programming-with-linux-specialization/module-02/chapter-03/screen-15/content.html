Module 2 › Chapter 2.3 › Final Reminders
Match specifiers
%d/%i → int, %f → float for printing, %lf → double in scanf, %c → char, %s → string.
Use & for scalars
Pass addresses to scanf and limit %s widths or use safer input functions to avoid overflow.
Structure conditionals
Order else if carefully, always use braces, and prefer clarity over compactness with ternary operators.
Reflect

Identify one input your future program will receive and write one validation check you will enforce before processing it. This small habit improves program reliability immediately.
