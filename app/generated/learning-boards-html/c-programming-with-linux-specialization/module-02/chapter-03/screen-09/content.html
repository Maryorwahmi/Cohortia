Module 2 › Chapter 2.3 › else if Chains
Grade mapping example
if (score < 0 || score > 100) {
  printf("Error
");
} else if (score >= 90) {
  printf("Grade: A
");
} else if (score >= 80) {
  printf("Grade: B
");
} else if (score >= 70) {
  printf("Grade: C
");
} else if (score >= 60) {
  printf("Grade: D
");
} else {
  printf("Grade: F
");
}
Key points
  • The chain evaluates top to bottom and stops at the first true branch.
  • Order thresholds from most specific (highest) to least to prevent accidental matches.
  • Use an else as the final catch-all for unexpected values.
