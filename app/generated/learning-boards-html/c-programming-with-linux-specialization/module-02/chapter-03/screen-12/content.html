Ternary example
const char* status = (score >= 60 && score <= 100) ? "Pass" : "Fail";
printf("Overall Status: %s
", status);
The ternary returns one of the two string literals based on the condition, making the code compact and expressive for simple choices.
When not to use it

Avoid nested ternaries and long expressions inside the ternary; prefer a clear if-else when the logic involves multiple steps or side effects.

Check your clarity

If the ternary requires comments to explain, rewrite it as a short if-else.
