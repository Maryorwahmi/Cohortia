Module 2 › Chapter 2.3 › scanf() & Address
Example: read an integer
#include <stdio.h>

int main() {
  int age;
  printf("Enter your age: ");
  if (scanf("%d", &age) != 1) {
    printf("Invalid input.
");
    return 1;
  }
  printf("You entered: %d
", age);
  return 0;
}
Explanation
  • The ampersand gives scanf the variable's memory address so it can write the input value there.
  • Arrays decay to pointers, so for char name[10] you call scanf("%9s", name) without & because name already refers to an address.
  • Always check the return value to verify that scanf read the expected number of items.
Common mistake

Omitting & for scalars is a runtime error; test simple reads to internalize the address rule.
