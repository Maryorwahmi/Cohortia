Module 4 › Chapter 3.4 › Key Concepts
Array-Pointer Equivalence
An array name often decays to a pointer to its first element, enabling pointer usage.
Pointer Arithmetic
Adding n to a pointer advances by n elements; the compiler scales by sizeof(type).
Pass-by-Pointer
Functions receive a pointer to the first element; pass lengths explicitly for safe loops.
Summary Takeaway

Master decay, arithmetic, and explicit lengths to write efficient and safe array code in C.
