Module 4 › Chapter 3.4 › array[i] vs *(array + i)
Side-by-side example
#include <stdio.h>

int main() {
  int a[] = {10, 20, 30};
  printf("a[1] = %d
", a[1]);
  printf("*(a + 1) = %d
", *(a + 1));
  return 0;
}
Both print the same value. Use the form that best clarifies pointer intent.
Practical note
  • When you already have a pointer, *(ptr + i) is explicit.
  • Indexing is clearer for most loops: arr[i] is idiomatic.
  • Pointer increments allow one-pass traversal without an index variable.
Check: p[i] is valid if p points into a contiguous block; it does not require the original array declaration.
