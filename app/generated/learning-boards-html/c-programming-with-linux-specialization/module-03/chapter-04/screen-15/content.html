Module 4 › Chapter 3.4 › What to Remember
Pass lengths
Functions see pointers; pass length explicitly to enable safe iteration.
Array name is fixed
You cannot reassign the array identifier. Use pointer variables when a movable reference is needed.
Validate bounds
Always ensure pointer arithmetic stays within 0..N-1 to prevent undefined behavior.
Final takeaway

Pointer-array knowledge gives power and responsibility: use explicit sizes and bounds checks to keep C programs safe and efficient.
