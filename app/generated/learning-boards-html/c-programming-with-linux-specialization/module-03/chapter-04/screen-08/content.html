Module 4 › Chapter 3.4 › Passing arrays to functions
Parameter forms
Both declarations below are equivalent in a function parameter list because arr decays to a pointer:
void printArray(int arr[], int length);
void printArray(int *arr, int length);
Pass the length explicitly so the function can bound its loop safely.
Example: modify in-place
void doubleArrayElements(int *arr, int length) {
  for (int i = 0; i < length; i++) {
    *(arr + i) *= 2;
  }
}
This function modifies the caller's array directly because it operates on the same memory.
