Module 4 › Chapter 3.4 › Pointer arithmetic
Step-by-step
1. Start with int *ptr pointing to element 0.
2. Compute ptr + i: compiler adds i * sizeof(int) to ptr.
3. Dereference *(ptr + i) to access the i-th element.
Misconception: ptr + 1 does not add one byte; it adds one element-size.
Key Takeaway

Pointer arithmetic moves in element steps. Use it consciously and keep indices bounded.
