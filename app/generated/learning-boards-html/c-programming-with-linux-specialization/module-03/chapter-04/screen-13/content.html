Sample question
Which is NOT equivalent to data[2]?
A) *(data + 2)
B) p[2] where p = data
C) *(p + 2)
D) *data + 2 <- NOT equivalent (it adds 2 to first element)
Debug checklist
  • Compute length where array type is visible and pass it along.
  • Check loops use i < length, not i <= length.
  • Validate pointer parameters before dereferencing.
