Module 4 › Chapter 3.4 › sizeof with arrays vs pointers
Example to try
#include <stdio.h>

void f(int *arr) {
  printf("inside f: sizeof(arr) = %zu
", sizeof(arr));
}

int main() {
  int a[10];
  printf("in main: sizeof(a) = %zu
", sizeof(a));
  f(a);
  return 0;
}
The program prints different values because the function sees a pointer type.
Practical guidance
  • Compute lengths where the array's type is visible, then pass the length.
  • Do not rely on sizeof inside functions to determine array length.
