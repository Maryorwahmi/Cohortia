Module 4 › Chapter 3.4 › Array name decays to a pointer
What this means

An array name used in an expression becomes a pointer to the first element. This allows pointer assignment and pointer arithmetic to access array elements.

Analogy: the array name is an anchored flag at the start of a row of boxes. You can move a pointer along the boxes, but the anchored flag stays put.
Example
#include <stdio.h>

int main() {
  int numbers[3] = {1, 2, 3};
  int *p = numbers;      // numbers decays to &numbers[0]
  printf("first = %d
", *p);
  return 0;
}
Common misconception
People expect to reassign the array name like a normal pointer. That is illegal — the identifier represents fixed storage.
Key Takeaway

Array names are anchored pointers to element zero; use pointer variables for reassignable references.
