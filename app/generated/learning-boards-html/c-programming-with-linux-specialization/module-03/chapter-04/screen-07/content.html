Module 4 › Chapter 3.4 › Iterating with a pointer variable
Code example
#include <stdio.h>

int main() {
  int numbers[] = {5, 10, 15, 20};
  int len = sizeof(numbers) / sizeof(numbers[0]);
  int *cur = numbers;      // points to first element

  for (int i = 0; i < len; i++) {
    printf("Element %d: %d
", i, *cur);
    cur++; // move to next element
  }
  return 0;
}
This loop uses both a counter and pointer increment to ensure safe termination and concise access.
Notes & best practices
  • Store the original base if you need to reuse it after the loop.
  • Always pair pointer increments with explicit bounds or an end pointer to avoid overruns.
  • Pointer loops are handy for streaming or when passing the moving pointer to functions.
