Module 4 › Chapter 3.4 › Array name vs pointer variable
Hierarchy: fixed vs variable
Array: fixed base address reserved by declaration. Pointer: an ordinary variable holding an address you can change.
int arr[3]; // arr is a fixed base address
int *p = arr; p = someOtherArray; // p can be reassigned
Practical implications
  • Design APIs to accept pointers if you expect the function to work on arbitrary buffers.
  • Use array declarations when you need a local fixed buffer with automatic storage.
  • Be careful about pointer lifetime when returning pointers to stack arrays — avoid returning pointers to local arrays.
