Safety steps
  1. Declare pointer with the appropriate pointee type.
  2. Initialize immediately: assign a valid address or set to NULL.
  3. Check pointer against NULL before dereferencing if not certain.
  4. Keep ownership and lifetime of pointed memory clear in your design.
  5. Avoid unchecked casts; document any intentional reinterpretation.
