Module 3 › Chapter 3.3 › Uninitialized vs NULL
Uninitialized pointer

Declared but not set. Contains garbage. Dereferencing causes undefined behavior and likely a crash.

Example danger
int *p; *p = 50; // invalid — p has no defined address
NULL pointer

Explicitly set to indicate no target. Safe to check before use and prevents accidental dereference when handled properly.

Safe pattern
int *p = NULL; if (p != NULL) { *p = 50; } else { handle missing target }
Takeaway

Always initialize pointers. Use NULL as a clear sentinel and check pointers before dereferencing to avoid undefined behavior.
