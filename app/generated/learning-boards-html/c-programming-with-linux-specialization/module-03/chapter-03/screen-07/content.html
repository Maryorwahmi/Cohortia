Module 3 › Chapter 3.3 › Dereferencing
Example and walkthrough
#include <stdio.h>

int main() {
  int value = 42;
  int *p = &value;            // p holds address of value
  printf("Before: value = %d
", value);

  *p = 100;                   // write through pointer
  printf("After: value = %d
", value);

  return 0;
}
Result
Writing to *p changed value itself because p pointed at value's address.
Danger
If p were NULL or uninitialized, assigning to *p would cause a crash or undefined behavior.
Swap activity preview
A swap function takes two int pointers and uses a temporary local variable to exchange values using dereference. This shows pass-by-reference in action.
void swap(int *a, int *b) {
  int tmp = *a;
  *a = *b;
  *b = tmp;
}
