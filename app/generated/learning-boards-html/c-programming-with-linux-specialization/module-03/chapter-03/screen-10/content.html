Module 3 › Chapter 3.3 › Type Mismatch
Why it matters
  • Pointer type determines how many bytes and what interpretation to apply when reading memory.
  • Pointing the wrong type reads incorrect bytes and yields garbage values.
  • Some architectures require aligned access; mismatches can crash the program.
Practical guidance
Keep pointer types consistent with the data they point to.
Only cast when you intentionally reinterpret memory and document why.
Use explicit checks and test prints to validate assumptions about layout.
