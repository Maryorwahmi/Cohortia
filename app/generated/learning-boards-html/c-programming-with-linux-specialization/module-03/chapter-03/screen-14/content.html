Module 3 › Chapter 3.3 › Key Concepts — Quick Reference
& gives address
Use & to obtain a variable's address so pointers can reference it.
* accesses value
Dereference to read or write the value at the stored address.
Initialize & check
Set pointers to a valid address or NULL and check before dereferencing.
Final takeaway
Use the address-of and dereference operators intentionally, and make initialization and checks a habit for reliable pointer code.
