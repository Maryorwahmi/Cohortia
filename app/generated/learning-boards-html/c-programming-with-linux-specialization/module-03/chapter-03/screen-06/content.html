Module 3 › Chapter 3.3 › Declare & Initialize
Step-by-step
  1. Declare with a pointer type: int *p;
  2. Declare target variable: int x = 10;
  3. Assign address: p = &x; or int *p = &x;
  4. Or initialize to NULL if no target yet: int *p = NULL;
Best practice
Initialize pointers close to declaration and prefer explicitly assigning a valid address as soon as possible.
Code example
int x = 10;
int *p;        // declaration
p = &x;        // initialization with address-of operator
// or
int *q = &x;   // combined declaration and initialization

int *r = NULL; // safe default when no target is available
Misconception
Declaring int *p; does not allocate storage for an int at that address. It only reserves space for the pointer itself.
