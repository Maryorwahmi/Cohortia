Module 3 › Chapter 3.3 › What Is a Pointer?
Core claim

A pointer is a variable that holds the address of another variable. It gives indirect access to memory.

Quick example
int value = 42;
int *p = &value;
// *p reads or writes the value at value's address
Note
Pointer variables occupy memory themselves and may be pointed to by other pointers, enabling layered indirection.
Why pointer types matter
  • Pointer types tell how many bytes to interpret when reading memory.
  • A type mismatch can cause incorrect data interpretation and subtle bugs.
  • Always keep pointer and pointee types consistent unless you cast with clear intent.
Misconception check
The pointer does not hold the value itself. Assigning pointer to another pointer copies the address, not the pointed value.
