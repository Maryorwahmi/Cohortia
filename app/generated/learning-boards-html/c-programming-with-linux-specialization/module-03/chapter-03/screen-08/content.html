Module 3 › Chapter 3.3 › Printing Addresses
Code example
#include <stdio.h>

int main() {
  int x = 10;
  int *p = &x;

  printf("Address of x: %p
", (void*)&x);
  printf("Value of p (address it holds): %p
", (void*)p);

  return 0;
}
Notes
  • Cast to a generic pointer type for portable printing.
  • Addresses are useful for debugging aliasing and pointer initialization.
Misconception
Do not rely on addresses being stable across program runs or different machines. They reflect the process memory layout at runtime and can change.
Quick tip
Use address prints sparingly while debugging and remove them from final code to avoid clutter and platform-specific assumptions.
