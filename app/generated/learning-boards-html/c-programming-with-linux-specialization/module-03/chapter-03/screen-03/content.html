Four practice checkpoints
  • Print addresses with the pointer format and cast to a generic pointer type for safety when required.
  • Initialize pointers to NULL if they have no immediate target, then set them before use.
  • Check pointers against NULL before dereferencing to avoid crashes.
  • Keep pointer types consistent; pointing an int pointer at a double leads to incorrect reads.
