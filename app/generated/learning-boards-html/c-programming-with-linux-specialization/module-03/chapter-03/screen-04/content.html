Module 3 › Chapter 3.3 › Memory Addresses
Definition & analogy

Imagine memory as a sequence of mailboxes indexed by numbers. A variable's address is the mailbox number assigned when space is reserved.

Common mistake
Treating addresses like ordinary integers and performing unchecked arithmetic can misalign data and cause incorrect reads.
Key Takeaway

Addresses identify where bytes live; pointers carry these identifiers so code can reference stored values indirectly.

Inspecting addresses
#include <stdio.h>

int main() {
  int x = 10;
  printf("Address of x: %p
", (void*)&x);
  return 0;
}
Why cast to void*
The pointer format expects a generic pointer type, so casting makes the intent portable.
Practical example
Seeing addresses helps you confirm storage locations when debugging pointer behavior.
