Understanding Pointers

Learn how addresses, the address-of operator, and dereference let your code access and change memory directly.

Explore Key Topics
Memory Addresses
Unique numeric locations for bytes where variables live.
Pointers
Variables storing addresses that point to other variables.
Safety
Initialize pointers and check for NULL to prevent crashes.
Concept sketch
Variable cell
int x = 10; stored at address 0x100
Pointer
int *p = &x; p holds 0x100
Dereference
*p reads or writes the value at 0x100
Quick quiz
If p holds the address of x, what does *p change? Answer: the value stored where x lives — so x itself is modified.
Why start here?
Pointers are the foundation for dynamic memory, efficient array handling, and passing values by reference. Getting addresses right prevents crashes later.
