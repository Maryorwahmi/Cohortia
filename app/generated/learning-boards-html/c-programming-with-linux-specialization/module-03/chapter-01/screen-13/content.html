Concept

Abstraction enables reuse

By hiding details and exposing a stable signature, functions let many callers use the same logic safely.

Practice: move a calculation into a utility function and call it from multiple places.
Misconception: Copying code to reuse it increases maintenance burden; prefer a single shared function.
Scenario
Imagine a circle area calculation used in several programs. A single calculateCircleArea function can be placed in a utility module and reused rather than copy-pasting the formula in each file.
Key Takeaway

Design functions with clear signatures and single responsibilities to maximize reuse across your projects.
