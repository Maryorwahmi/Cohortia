Symptom

A compiler warning about an implicit declaration usually means a call preceded any prototype or definition for that function.

// call without prototype or prior definition
int main(void) {
  sayHello(); // compiler may warn here
  return 0;
}

void sayHello(void) {
  printf("Hi
");
}
Fix
Add a matching prototype before main or move the definition above main.
// add prototype
void sayHello(void);

int main(void) {
  sayHello();
  return 0;
}

void sayHello(void) {
  printf("Hi
");
}
Key Takeaway

Prototypes prevent implicit declarations and give the compiler the information it needs to check calls.
