Starter Template
#include <stdio.h>

// Prototypes
void welcomeMessage(void);
void farewellMessage(void);

int main(void) {
  welcomeMessage();
  printf("Performing main program tasks...
");
  farewellMessage();
  return 0;
}

// Definitions
void welcomeMessage(void) {
  printf("Welcome!
");
}

void farewellMessage(void) {
  printf("Farewell!
");
}
Explanation
  • Prototypes declare function signatures so calls in main are validated by the compiler.
  • The void return type indicates no value is returned to the caller.
  • Using void in parameter lists explicitly shows no parameters are accepted.
  • Control moves from main to a function and returns when the function ends.
Common Mistake: Omitting the prototype when definitions are below main leads to implicit declaration warnings.
Check: After compiling, confirm output order matches the expected sequence of calls.
