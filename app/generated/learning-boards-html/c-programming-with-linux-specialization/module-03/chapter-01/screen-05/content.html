Process

Prototype → Call → Definition

  1. Declare: write the prototype so the compiler knows the signature.
  2. Call: invoke the function from main or another function.
  3. Define: implement the function body so calls execute the intended logic.
Pro Tip: Put prototypes in a header when multiple source files use the function.
Common Mistake: Forgetting a prototype when definition comes after main, causing implicit declaration warnings.
Example Walkthrough
Consider a function that prints a farewell. The prototype appears before main, main calls the function, and the definition is after main. This order prevents compiler confusion and keeps main focused on program flow.
// Prototype
void farewell(void);

int main(void) {
  // call farewell
  farewell();
  return 0;
}

// Definition
void farewell(void) {
  printf("Goodbye!
");
}
Key Takeaway

Use prototypes to declare a function signature before calling it; definitions provide the implementation later.
