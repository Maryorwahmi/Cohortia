Pattern
Header contains the prototype; implementation file contains the definition; caller files include the header.
example.h: void util(void);
example.c: include "example.h" and define util
main.c: include "example.h" and call util
Code Layout
// example.h
void sharedTask(void);

// example.c
#include "example.h"
#include <stdio.h>
void sharedTask(void) {
  printf("Shared task
");
}

// main.c
#include "example.h"
int main(void) {
  sharedTask();
  return 0;
}
Misconception: Putting definitions in headers causes multiple-definition errors; instead keep only prototypes in headers and definitions in a single .c file.
