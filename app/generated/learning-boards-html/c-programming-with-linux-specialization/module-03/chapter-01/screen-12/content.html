Activity Template
#include <stdio.h>

// --- Function Prototypes ---
void welcomeMessage(void);
void farewellMessage(void);

int main(void) {
  welcomeMessage();
  printf("Performing main program tasks...
");
  farewellMessage();
  return 0;
}

// --- Function Definitions ---
void welcomeMessage(void) {
  printf("Welcome to the program!
");
}

void farewellMessage(void) {
  printf("Thank you, goodbye!
");
}
Checks
  • Compile and ensure no implicit declaration warnings.
  • Confirm output order matches expected sequence of calls.
  • Try a deliberate signature mismatch to observe the compiler message.
Key Takeaway

Practice the prototype → call → definition cycle until it becomes second nature.
