Hierarchy

main as orchestrator

main should call focused helper functions and remain readable as a high-level program outline.

setup()
performTask()
cleanup()
Example Outline
int main(void) {
  setup();
  performTask();
  cleanup();
  return 0;
}

void setup(void) { /* initialize */ }
void performTask(void) { /* core work */ }
void cleanup(void) { /* release resources */ }
Misconception: main must contain all logic. Reality: small, named helpers improve clarity and make unit testing easier.
