Learn → Understand → Apply → Master

Use the four stages to build confidence: read examples, explain key differences, write and test simple functions, then check signatures and prototypes.

Learn
See a prototype, a definition, and a call in a small example.
Understand
Explain why prototypes are placed before main and how definitions implement behavior.
Apply
Write void functions, call them from main, and check program output.
Master
Identify mismatches between prototype, definition, and calls; fix compiler warnings.
