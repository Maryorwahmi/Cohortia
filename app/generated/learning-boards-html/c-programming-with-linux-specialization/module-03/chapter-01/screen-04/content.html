Core Concept

What a function is

A named, reusable block of code that performs a single responsibility. Use it to avoid repeating logic and to make code easier to test.

  • Declaration: tells the compiler the function's signature exists.
  • Definition: provides the implementation with statements inside braces.
  • Call: invokes the function so its statements run and then control returns.
Example: a void greet function that prints a message and is called from main.
Misconception: Functions primarily speed up execution. Correct: they improve structure and reuse.
Key Takeaway: Extract one repeated task into a function to reduce duplication and localize fixes.
Concrete Example
#include <stdio.h>

// Prototype
void greet(void);

int main(void) {
  printf("Program starting...
");
  // call the greet function
  greet();
  printf("Program finished.
");
  return 0;
}

// Definition
void greet(void) {
  printf("Hello from greet function!
");
}
