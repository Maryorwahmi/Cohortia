Principle

Single Responsibility

Each function should have one clear reason to change. This keeps logic easy to test and reuse.

Split computeResult() and printResult() instead of combining both.
Pro Tip: Name functions by their action to clarify intent.
Example
int computeSum(int a, int b) {
  return a + b;
}

void showSum(int a, int b) {
  int s = computeSum(a, b);
  printf("Sum is %d
", s);
}
Benefit: computeSum can be tested independently of printing logic in showSum.
