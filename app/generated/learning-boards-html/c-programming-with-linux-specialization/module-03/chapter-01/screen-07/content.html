Without Functions
Repeated statements increase chance of inconsistent edits.
printf("Task start
");
printf("Do step A
");
printf("Do step B
");
printf("Task finish
");

// repeated elsewhere
printf("Task start
");
printf("Do step A
");
With Functions
One function encapsulates the sequence, simplifying calls and edits.
void doTask(void) {
  printf("Task start
");
  printf("Do step A
");
  printf("Do step B
");
  printf("Task finish
");
}

// use it everywhere
doTask();

doTask();
Benefit: One change updates all calls.
Pro Tip: Keep functions short and focused on one responsibility.
Mistake: Overly small functions can fragment logic; balance is key.
