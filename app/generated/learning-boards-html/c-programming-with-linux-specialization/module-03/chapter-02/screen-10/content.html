Module 3 › Chapter 3.2 › Common Mistakes
Ignoring return values
If a function returns data and you don't store or use it, the result is discarded. Assign important results to preserve them.
Type mismatch and truncation
Assigning a double return to an int truncates decimals. Match types or cast explicitly with awareness of possible data loss.
Pass-by-value expectation
Expecting a parameter change to alter the caller's variable is a logical error in C's pass-by-value model.
Debugging checklist
  1. Verify function prototype and definition types match.
  2. Ensure the caller captures the return value when needed.
  3. Use prints inside and outside the function to observe which variables change.
Key Takeaway
Follow a checklist: prototype, capture return, print to observe, and reason about pass-by-value.
