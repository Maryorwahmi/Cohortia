Variable scope and lifetime
Understand why locals are destroyed at function exit and the implications for program design.
Why scope matters
Isolation prevents accidental modification and supports modular reasoning. Return values transfer only the needed data back to the caller.
Key Takeaway
Do not rely on local variables to persist beyond the function call; return values or use other mechanisms when persistence is required.
Example diagnostic
If you print a local inside the function you will see its current value. After the function ends, the local no longer exists and cannot be accessed or inspected from the caller.
