Module 3 › Chapter 3.2 › addNumbers Walkthrough
Code example
Study how arguments become parameters and how the return is used.
#include <stdio.h>

// Prototype: takes two integers, returns an integer
int addNumbers(int a, int b);

int main() {
  int num1 = 10;
  int num2 = 5;
  int sum;

  // Call addNumbers, passing copies of num1 and num2
  sum = addNumbers(num1, num2);

  printf("The sum of %d and %d is %d
", num1, num2, sum);
  return 0;
}

int addNumbers(int a, int b) {
  int result = a + b; // 'a' and 'b' are copies
  return result;      // Return the calculated sum
}
Takeaway
Assign the returned value to a variable if you need to reuse it; otherwise the result is lost.
Annotations
  • Prototype declares the expected parameter types and return type.
  • The call copies num1 and num2 into a and b.
  • result is local to addNumbers and cannot be accessed from main.
  • The returned int is stored in sum in main to preserve the value.
