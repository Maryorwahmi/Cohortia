Learning Objectives
Demonstrable skills to write safe, parameterized functions and use returns correctly.
01
Explain pass-by-value
Describe how C copies argument values into parameters and why callers are unaffected by parameter changes.
VERIFIED COMPETENCY MILESTONE
02
Use return values
Choose and return the correct type, and capture results in the caller to avoid discarding data.
VERIFIED COMPETENCY MILESTONE
03
Write multi-parameter functions
Accept mixed data types safely and understand implicit conversions that may promote or truncate values.
VERIFIED COMPETENCY MILESTONE
04
Understand local scope
Explain lifetime of local variables and why a function's internals don't leak into the caller's scope.
VERIFIED COMPETENCY MILESTONE
Bloom's Path
Learn → Understand → Apply → Master
You will first learn concepts, then apply them in code, and finally demonstrate mastery through verified milestones.
