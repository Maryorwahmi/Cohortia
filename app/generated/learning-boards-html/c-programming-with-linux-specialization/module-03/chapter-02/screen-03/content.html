Practice and Pitfalls
Short diagnostics to spot typical mistakes when using parameters and returns.
Common mistake
Calling a function and ignoring its return value discards results. Always assign or use the returned value when it matters.
VERIFIED COMPETENCY MILESTONE
Type compatibility
Passing a double into an int parameter truncates decimals. Check types to avoid unintended loss of precision.
VERIFIED COMPETENCY MILESTONE
Mnemonic
Copy in, compute locally, return out. Remember: copy in, no surprise out.
