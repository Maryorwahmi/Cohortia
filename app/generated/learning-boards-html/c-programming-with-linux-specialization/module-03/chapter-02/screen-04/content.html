Module 3 › Chapter 3.2 › Parameters and Return Values
Term definitions
Clear, concise definitions and a mnemonic to remember them.
Parameter (Argument)
A named local variable in a function that receives a copy of the caller's value at the time of the call.
Return Value
A typed value sent back to the caller with return. The caller must capture it to reuse the result; otherwise it is discarded.
Key Takeaway

Parameters form the input side of the contract; returns form the output. Treat them as separate names and separate storage.

Analogy: Vending Machine
Insert coins and choose a selection (caller provides arguments). Internal mechanisms use those inputs and dispense a product or receipt (the return value). Your coins outside the machine remain unchanged by internal processing.
Examples
Prototype: int addNumbers(int a, int b); — parameters a and b, return type int.
Prototype: void printHello(void); — no parameters, no return value.
