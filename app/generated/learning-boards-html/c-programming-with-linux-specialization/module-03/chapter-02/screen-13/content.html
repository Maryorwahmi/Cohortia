Module 3 › Chapter 3.2 › Key Concepts
Parameter (Argument)
A named input that allows the function to operate on specific data.
Pass by Value
Arguments are copied into parameters; internal changes do not affect the caller.
Return Value
A typed value sent back; the caller must capture it to reuse the result.
Takeaway
Treat function signatures as contracts: inputs, local processing, and explicit outputs. This model helps prevent bugs and clarifies ownership of data.
