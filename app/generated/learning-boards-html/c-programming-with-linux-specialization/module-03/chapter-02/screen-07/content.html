Return vs Void
Decide whether your function should produce data or just perform an action.
Return a value
Use when the caller needs the computed result, e.g., calculating area or converting temperatures. Capture the returned value in the caller.
Use void
Use when the function performs a side effect only, such as printing or modifying global state. Do not expect data back.
Examples & Pitfalls
  • Returning double but storing in int truncates decimals — be explicit about types.
  • A void function cannot produce a result; attempting to return a value violates the declaration.
  • Calling a non-void function without capturing the return discards the value.
Key Takeaway
Match return types to the information the caller needs and always capture important results.
