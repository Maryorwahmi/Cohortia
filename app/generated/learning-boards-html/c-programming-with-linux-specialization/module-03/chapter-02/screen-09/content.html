calculateRectangleArea example
Observe the types to avoid truncation.
#include <stdio.h>

// Prototype: takes two doubles (length, width), returns a double (area)
double calculateRectangleArea(double length, double width);

int main() {
  double rectLength = 10.5;
  double rectWidth = 7.2;
  double area;

  area = calculateRectangleArea(rectLength, rectWidth);
  printf("The area of a rectangle with length %.2f and width %.2f is %.2f
",
         rectLength, rectWidth, area);
  return 0;
}

// Definition
double calculateRectangleArea(double length, double width) {
  return length * width;
}
Notes
  • Parameters are doubles, preserving fractional input values.
  • The returned double keeps decimal precision for area calculations.
  • If you stored the return in an int, fractional data would be lost.
Key Takeaway
Match parameter and return types to the precision your computation requires; document the contract in the prototype.
