Hints
Use the formula Fahrenheit = (Celsius * 9.0 / 5.0) + 32. Return 1 for freezing when Celsius is 0.0 or below, otherwise return 0.
Testing tips
  • Test with 25.0, 0.0, and -5.5 to cover normal, edge, and below-freezing cases.
  • Print with two decimal places to confirm precision is preserved.
