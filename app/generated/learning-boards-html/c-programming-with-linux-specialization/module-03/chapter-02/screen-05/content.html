Module 3 › Chapter 3.2 › Pass by Value
Pass-by-value steps
A clear numbered process to reason about copying behavior.
1. Evaluate arguments
Compute the values used as arguments in the caller before the call begins.
2. Copy into parameters
Allocate local parameter slots and copy the evaluated values into them.
3. Execute function body
All modifications affect the local copies only; the original caller values are unchanged.
4. Return and destroy locals
Return sends a value back; local parameter slots are freed at function exit.
Key Takeaway

Pass by value isolates behavior and avoids accidental side effects, but it does not allow functions to modify caller variables directly.

Concrete Example
#include <stdio.h>

void modify(int v) {
  v = v * 2; // modifies local copy only
  printf("Inside modify, v = %d
", v);
}

int main() {
  int original = 10;
  modify(original);
  printf("After modify, original = %d
", original);
  return 0;
}
This prints 20 inside the function and 10 after, illustrating the copy behavior.
