Snapshots across a call
Use a four-snapshot trace to track where values live and when they change.
Snapshot 1 — Before call: caller variables hold original values.
Snapshot 2 — At function entry: parameters are local copies initialized from caller values.
Snapshot 3 — During execution: parameters and other locals may change, but changes are local.
Snapshot 4 — After return: the caller receives the returned value and function locals are freed.
Practice
Apply this trace to an example call and use prints to confirm each snapshot in actual runs.
Quick checklist
  • Identify parameter copies at entry.
  • Note any conversions during copying.
  • Confirm returned value is assigned by caller.
