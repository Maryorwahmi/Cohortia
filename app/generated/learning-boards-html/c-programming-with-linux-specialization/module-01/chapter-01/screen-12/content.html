Module 1 › Chapter 1.1 › Manual Pages
Definition

Using man to read documentation

Man pages are authoritative and reflect the installed commands on your system. Learn to scan SYNOPSIS and OPTIONS sections.

How to open

Run man followed by the command name to open its manual page and press q to quit.

What to look for

SYNOPSIS shows usage patterns; OPTIONS explain flags and their effects.

Practical use

Consult man before using unfamiliar flags, especially for commands that modify files.

Key Takeaway

Man pages save time by providing exact, system-specific documentation for commands and options.

Example
# Open the manual for ls
man ls

# Quit the manual with q

# Look under SYNOPSIS and OPTIONS for usage and flags
Man pages are especially useful when flags differ across versions of a tool; use them rather than assuming web examples apply to your system.
