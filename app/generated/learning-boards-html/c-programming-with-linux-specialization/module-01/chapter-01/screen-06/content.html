pwd, absolute and relative paths

Confirm where you are and choose the appropriate path style for your task.

The print working directory command

Run pwd to show the full path of the current directory; use it as a quick verification step.

Absolute paths

Start with slash and always refer to the same location regardless of where you run the command.

Relative paths

Depend on the current directory and are convenient for interactive work, but require awareness of where you are.

Key Takeaway

Verify your working directory before running commands that modify or delete files; use absolute paths in scripts for clarity.

Concrete Example
Example scenario
/home/user/projects$ pwd
/home/user/projects
# Relative path resolution
ls chapter1_code/hello.c
# Absolute path equivalent
ls /home/user/projects/chapter1_code/hello.c
Notice how the relative path depends on the printed working directory. If you were in a different folder, the relative path would point elsewhere or fail.
Mistake to avoid: running a remove command like rm -r target without first confirming pwd and the target path. Confirm first, then act.
