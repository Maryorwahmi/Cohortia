Learning Objectives

Practical skills you'll apply while building C projects on Linux.

Bloom: Learn → Understand → Apply → Master
01
Explain Linux's role

Describe why Linux is a common platform for C development and how it supports compilers and system tools.

VERIFIED COMPETENCY MILESTONE
02
Differentiate shell components

Identify terminal, shell, and prompt roles so you know where to type and how commands are parsed and executed.

VERIFIED COMPETENCY MILESTONE
03
File and directory operations

Use ls, cd, pwd, mkdir, rmdir, rm, cp, and mv to manage project files and avoid destructive mistakes.

VERIFIED COMPETENCY MILESTONE
04
Paths and manual pages

Distinguish absolute vs relative paths and use the man command to inspect options for any tool you use.

VERIFIED COMPETENCY MILESTONE
Each objective will be demonstrated with concrete commands and a short practical activity so you can reproduce the workflow on your machine.
