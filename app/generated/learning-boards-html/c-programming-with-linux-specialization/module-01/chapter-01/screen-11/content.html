Hierarchy

Key directories and their purpose

A simple mental map helps you find compilers, libraries, and your working files quickly.

/ (root)

The single top-level of the filesystem tree; everything lives under it.

/bin and /usr/bin

Essential user binaries and system-installed programs like compilers and utilities.

/etc

System configuration files that affect programs and services.

/home

User home directories where your source code and personal config live.

Pro Tip

Use which or whereis to locate installed binaries when setting up build scripts or diagnosing missing tools.

Quick Map
  • / — root
  • /bin — essential binaries
  • /usr — user programs & libraries
  • /etc — system configs
  • /home — user files and projects
When troubleshooting include checks of system library paths and your project's include paths to resolve missing headers or linker errors.
