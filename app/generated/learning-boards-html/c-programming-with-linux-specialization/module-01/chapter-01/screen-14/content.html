Module 1 › Chapter 1.1 › Key Concepts
Command Line Basics
Terminal, shell, and prompt form the interactive environment for running tools and scripts.
File Operations
Use ls, cd, pwd, mkdir, rmdir, rm, cp, and mv to manage project files and directories.
Filesystem Layout
Understand root, /bin, /usr, /etc, and /home to locate tools and your code.
Summary Takeaway

Practice the sequence of create, copy, move, verify, and remove until these commands become second nature. Consult man for authoritative help.
