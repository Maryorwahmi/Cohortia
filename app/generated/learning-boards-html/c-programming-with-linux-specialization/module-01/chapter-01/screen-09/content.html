Process

mkdir, rmdir, touch, and rm

Create structure and files for your C projects and practice safe deletion patterns.

mkdir

Create one or more directories; use it to build your project layout.

rmdir

Remove empty directories only; safer than recursive remove when appropriate.

touch

Create an empty file or update an existing file's timestamp; useful for placeholders.

Warning

rm -rf will remove directories and their contents without confirmation. Verify the path and list the target before running it.

Walkthrough
# Create project and chapters
mkdir c_projects
cd c_projects
mkdir chapter1_code chapter2_code

# Create a starter file
touch chapter1_code/hello.c

# Verify before remove
ls -la chapter2_code

# Safely remove a directory after verifying contents
rm -r chapter2_code
Always run a listing to inspect a directory before deleting it. In scripts, consider an interactive or backup step rather than force deletion.
Practice: create, list, and remove a test directory until you are comfortable confirming targets every time.
