Definition

Terminal, Shell, and Prompt

Recognize how these layers interact so you can script and debug reliably.

Terminal

The window or emulator that displays text input and program output.

Shell

The interpreter that parses commands, expands wildcards, and runs programs or built-ins like the change directory command.

Prompt

A visual cue that the shell is ready. Do not copy prompt characters into commands when following examples.

Pro Tip

If a script fails, check which shell it expects and whether your environment uses the same shell and configuration files.

Illustration
Analogy
Think of the terminal as a stage, the shell as the actor interpreting lines, and the prompt as the stage light signaling the actor to speak. When you script, you write the actor's lines; when you type, you cue the actor live.
Check your understanding

When a command behaves differently in a script versus your terminal, verify the script's shebang or default shell and compare environments.
