Module 1 › Chapter 1.1 › ls Command
Definition

ls and its options

Learn to read listings and check file details before acting on files.

ls -l

Long listing format: permissions, links, owner, group, size, and timestamp.

ls -a

Show hidden files whose names begin with a dot.

ls -la

Combine flags for a detailed view including hidden files.

Practical tip

Inspect permissions in the long listing before editing. If a file is read-only, you’ll see that quickly.

Code Examples
# Basic listing
ls

# Long listing with hidden files
ls -la

# Example long listing output (truncated)
-rw-r--r-- 1 user user  234 Aug 12 10:15 hello.c
drwxr-xr-x 2 user user 4096 Aug 12 10:12 chapter1_code
.rw-r--r-- 1 user user   52 Aug 10 09:00 .gitignore
Read the permission column to see owner and group rights. This helps prevent permission-related errors when compiling or editing files.
