Module 1 › Chapter 1.1 › Learning Objectives

Skills & Safety

Build habits that protect your work and system while you learn.

Practice → Verify → Execute
A1
Verify working directory

Use the print working directory command before file operations to avoid accidental changes in the wrong folder.

VERIFIED COMPETENCY MILESTONE
A2
Prefer non-destructive steps

List and copy first; confirm results before using remove commands with recursive or force flags.

VERIFIED COMPETENCY MILESTONE
A3
Use manual pages

Open man pages to confirm correct options for commands like ls, rm, cp, and mv.

VERIFIED COMPETENCY MILESTONE
A4
Organize project folders

Create a predictable structure for C projects to simplify compiling and versioning.

VERIFIED COMPETENCY MILESTONE
These objectives will be demonstrated step-by-step and reinforced with a hands-on activity so the skills become muscle memory.
