cd, home, and parent shortcuts

Move around your project tree quickly using standard shortcuts and confirm your location after each move.

cd with no argument

Returns you to your home directory; useful when you need a known starting point.

Tilde shortcut

Use tilde as a shorthand for your home directory in paths.

Parent directory

Two dots move up one level. You can chain them to move multiple levels up.

Common mistake

Typing path names with typos will fail silently; verify the path exists or use tab completion where available.

Examples
# Go home
cd

# Go to a project folder
cd ~/c_projects/chapter1_code

# Move up one level
cd ..

# Confirm location
pwd
Use the print working directory command after cd to ensure subsequent commands act on the intended files.
Tip: when writing scripts, use absolute paths or set and print the working directory at the start to make behavior predictable.
