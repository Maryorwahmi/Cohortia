Activity

Organize a C projects folder

Follow these commands in order. Verify after each step.

Step-by-step
# 1. Create and enter the project folder
mkdir c_projects
cd c_projects

# 2. Make two chapter directories
mkdir chapter1_code
mkdir chapter2_code

# 3. Create an empty starter file
touch chapter1_code/hello.c

# 4. Copy the starter file to chapter2
cp chapter1_code/hello.c chapter2_code/

# 5. Rename the copied file
mv chapter2_code/hello.c chapter2_code/first_program.c

# 6. Verify and then remove the original
ls chapter1_code
rm chapter1_code/hello.c

# 7. Clean up after verifying
ls
rm -r chapter2_code
Checks and safety
  • Run pwd before starting to ensure you're in the intended parent directory.
  • Use ls -la to inspect hidden files or permissions before editing.
  • Before rm -r, list the directory contents to confirm what will be deleted.
Takeaway

Perform verification steps between actions and prefer copying when you need a reversible step.

Repeat this activity until you can perform it smoothly. These operations are the daily motions of a C developer managing source files and builds.
