Module 2 › Chapter 1.3 › Diagnostics
Useful compilation stops
  • • Preprocessing output shows header-expanded source for diagnosing missing declarations.
  • • Assembly output shows how high-level code maps to architecture-specific instructions.
  • • Object files show machine code before linking so you can detect unresolved dependencies.
Recommended flags
Enable warnings to catch suspicious constructs and enable debug information when you plan to step through execution with a debugger; these options greatly improve the feedback you get from the toolchain.
Key Takeaway
Treat compiler flags as diagnostic tools. Stopping the pipeline at different places reveals where a problem originates.
