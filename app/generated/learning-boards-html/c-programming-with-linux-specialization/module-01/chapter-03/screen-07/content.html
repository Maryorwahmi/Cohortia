Compile step explained
Invoke the compiler with your source file and an option to name the output executable. If you omit the name, the compiler chooses a default like a.out. The compile step produces an executable only after linking completes successfully.
/* Terminal example (visual only) */
$ gcc hello.c -o hello
/* If there are no errors, an executable named 'hello' appears in the directory */
$ ./hello
Hello, Cohortia C Programmers!
Why ./ is required
The shell searches directories listed in the PATH environment variable for commands. The current directory is usually not in PATH for safety reasons, so you must explicitly reference it when running a local program.
Pro tip
Use a descriptive name for your executable. This avoids confusion when you have multiple small test programs in the same folder.
