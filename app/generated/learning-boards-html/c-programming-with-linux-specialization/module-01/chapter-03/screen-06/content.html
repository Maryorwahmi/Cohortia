Module 2 › Chapter 1.3 › Hello World Walkthrough
Source file to type
#include <stdio.h> // Include the standard input/output library

int main() { // The main function, where program execution begins
    printf("Hello, Cohortia C Programmers!
"); // Print a string to the console
    return 0; // Indicate successful program execution
}
Save the file with a .c extension, for example hello.c. Use nano or another editor, then close and prepare to compile.
Line-by-line meaning
  • • The include directive makes declarations for the print function visible at compile time.
  • • A main function is required; it is the program’s entry point and returns an integer status.
  • • The print function prints the literal string; the escape for newline moves output to the next line.
Example activity
Open a terminal, create hello.c, paste this code, save, and then compile with the compiler. Observe that the program prints the message and returns success.
