Modified source example
#include <stdio.h>

int main() {
    int year = 2023; // Declare an integer variable and initialize it
    printf("Hello, Cohortia C Programmers!
");
    printf("This course starts in %d.
", year); // Print the value of year
    return 0;
}
After saving, re-run the compiler to create a new executable. Re-running without recompilation will not show the updated message.
Checklist
  1. Edit and save the source file with the new variable.
  2. Compile the source into a newly named executable.
  3. Run the executable and verify both lines print as expected.
Common oversight
Forgetting to recompile is a frequent cause of confusion. Always rebuild after changes to see them reflected at run time.
