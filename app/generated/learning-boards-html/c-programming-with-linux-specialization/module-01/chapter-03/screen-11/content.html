Module 2 › Chapter 1.3 › GCC Messages
Message anatomy
  • • Filename and line number show where to look.
  • • The message type (error or warning) tells you whether compilation stops.
  • • A brief description suggests the class of problem to check.
Key Takeaway
Use the file and line numbers from gcc to jump directly to the problematic code. Fix the small syntax issue and recompile.
Practical steps
  1. Open the file at the reported line number.
  2. Check the current line and the line above for a missing semicolon or mismatched braces.
  3. If the message mentions an undeclared function, verify the correct header is included.
