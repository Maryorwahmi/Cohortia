Module 2 › Chapter 1.3 › Best Practices
Use warnings
Enable common warnings during development so the compiler flags suspicious constructs early. Warnings help you catch mismatched format specifiers and other risky code that compiles but may behave unexpectedly.
Include debug info
Compile with debug information during development so you can use a debugger to inspect variables and step through code with meaningful line numbers and symbols.
Developer workflow suggestion
During active development, add diagnostic flags to the compiler. Remove or adjust them for release builds where size and optimization matter more.
