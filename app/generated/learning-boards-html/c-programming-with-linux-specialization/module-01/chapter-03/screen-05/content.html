What the preprocessor does
  • • Expands include directives so header declarations are visible to the compiler.
  • • Expands macro definitions defined with the hash define directive.
  • • Produces an expanded source file useful for debugging missing declarations.
Why this matters
If you forget the standard input/output header, the compiler will not know about the print function and will report an implicit or undeclared identifier. Preprocessing is the place to check that the header content is present.
Terminal example
Request the preprocessor output to inspect what the compiler sees after includes are expanded.
/* Example source */
#include <stdio.h>

int main() {
  printf("Hello, Cohortia C Programmers!
");
  return 0;
}
If you run the preprocessing step you will see many declarations from the included header in the expanded output. That expanded file explains why the print function is known to the compiler.
