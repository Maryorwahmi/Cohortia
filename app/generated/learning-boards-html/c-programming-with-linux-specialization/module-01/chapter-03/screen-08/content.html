Error types
  • • Missing semicolon at the end of a statement — fix by adding the semicolon at the end of the line.
  • • Missing header for standard functions — include the appropriate header so the compiler knows declarations.
  • • Case-sensitivity mistakes — correct capitalization to match function and variable names exactly.
  • • Wrong file extension — save files with .c so the compiler treats them as C source files.
Example: missing semicolon
/* Incorrect: missing semicolon */
int main() {
  printf("My first C program")
  return 0;
}

/* Fix: add the missing semicolon after the print call */
After fixing the syntax, re-run the compiler. The error message will typically show where it got confused; check that line and the one above it for missing terminators or mismatched braces.
