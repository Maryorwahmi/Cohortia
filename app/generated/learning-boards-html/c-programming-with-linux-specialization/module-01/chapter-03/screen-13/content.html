Module 2 › Chapter 1.3 › Key Concepts
Compiled Language
Source must be translated to machine code before execution.
GCC
The GNU compiler used to preprocess, compile, assemble and link C programs on Linux.
Compilation Stages
Preprocess → Compile → Assemble → Link. Inspect intermediates to isolate problems.
Takeaway
Use the pipeline as a diagnostic map: when an error occurs, stop at the stage that produces the symptom and inspect the outputs there.
