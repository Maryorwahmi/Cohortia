Module 2 › Chapter 1.3 › Learning Objectives
Terminal workflow
Create files with a terminal editor, compile using the compiler with an explicit output name, and run the executable from the current directory to avoid path issues.
Compiler options
Learn the -o option to name outputs, -Wall to enable common warnings, and -g to include debugging symbols for later tools.
Edit, recompile, rerun
Every source change requires recompilation so the executable reflects current code. Rebuild after edits to see updated behavior.
Error diagnosis
Read compiler messages to find the file and line where a syntactic problem exists, and learn the quick fixes for common beginner mistakes.
