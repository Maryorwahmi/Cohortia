Learning Objectives
Learn, Understand, Apply, Master
01
Explain the compilation stages
Describe preprocessing, compilation, assembly and linking and why each stage exists. This helps you interpret compiler output and intermediate files.
VERIFIED COMPETENCY MILESTONE
02
Write and save a C source file
Use a terminal editor to create a .c file and ensure it is saved with the correct extension so gcc recognizes it.
VERIFIED COMPETENCY MILESTONE
03
Compile and run with GCC
Invoke the compiler to produce an executable and run it from the current directory, understanding the role of the -o option and the need for explicit pathing.
VERIFIED COMPETENCY MILESTONE
04
Diagnose common syntax errors
Recognize errors like missing statement terminators or missing includes and apply straightforward fixes to recompile successfully.
VERIFIED COMPETENCY MILESTONE
