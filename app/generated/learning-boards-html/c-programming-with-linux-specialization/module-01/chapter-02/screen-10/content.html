Process Flow
Guest Additions
Optional tools to improve display resolution, clipboard sharing, and shared folders between host and guest.
Steps
  1. From VirtualBox menu choose "Insert Guest Additions CD Image".
  2. Mount the image in Ubuntu, open terminal and run the installer as root.
  3. Restart the VM to apply integration features.
When to skip
Skip on server-only or headless setups where GUI features are unnecessary.
Concrete tip
Guest Additions make copy-and-paste and shared folders work smoothly; this reduces friction when moving starter code into the VM for labs.
Key Takeaway

Install Guest Additions if you want a friendlier VM desktop; skip them for minimal, terminal-only development environments.
