Definition
WSL2
A lightweight Linux environment on Windows with a real Linux kernel for compatibility and performance.
Pros
Fast startup, low overhead, integration with Windows editors and filesystems.
Cons
Requires compatible Windows versions and is terminal-first without extra GUI setup.
Concrete example
Install Ubuntu from the Microsoft Store, launch the app, create a Unix user, then run apt commands to prepare your development environment.
Key Takeaway

WSL2 gives a near-native Linux experience with minimal resource overhead and strong Windows integration for most development workflows.
