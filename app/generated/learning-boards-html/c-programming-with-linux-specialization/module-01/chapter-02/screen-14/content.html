Troubleshooting
Installation issues & fixes
A short checklist for common problems during VM or WSL setup.
Virtualization not enabled
Enable Intel VT-x or AMD-V in BIOS/UEFI; VM startup errors related to 64-bit guests often point to this.
Insufficient disk space
Allocate at least 25–30 GB and ensure the host has enough free storage for the dynamic disk file.
Network connectivity
Use NAT for basic internet or bridged mode if you need the VM on the same LAN as the host.
WSL specific
Ensure Windows is updated, run the DISM feature enable commands in admin PowerShell, and restart when prompted to resolve many WSL errors.
Common mistake

Trying to debug complex errors before checking these basic settings often wastes time. Always run the checklist first.
