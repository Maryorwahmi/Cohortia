Setting Up Your Linux Development Environment
VM or WSL2 — pick the flow that fits your host and workflow.
This lesson prepares a working Linux workspace for C programming. You will see practical steps, key decisions, and commands to get Ubuntu running either in a VirtualBox virtual machine or inside Windows via WSL2. Expect step checks for RAM, disk sizing, and the initial package update that keeps your toolchain reliable.
In this lesson: install, configure, and troubleshoot your Linux environment for C development.

VM Setup
Download VirtualBox, create a 30 GB VDI, allocate RAM, and boot the Ubuntu ISO to install.
WSL2
Enable WSL and Virtual Machine Platform via PowerShell, set default to version 2, and install Ubuntu from the Store.
Post-Install
Run sudo apt update and sudo apt upgrade -y to refresh packages and keep your toolchain current.
