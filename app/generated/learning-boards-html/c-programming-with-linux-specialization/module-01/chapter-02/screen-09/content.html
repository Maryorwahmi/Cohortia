Process
Initial update and upgrade
Run the standard apt commands to bring the system up-to-date after installation.
Open a terminal and run the following commands exactly. These refresh package lists and then apply upgrades. The -y flag confirms prompts automatically so the upgrade runs without manual acceptance.
sudo apt update
sudo apt upgrade -y
If you see prompts or held packages, read the terminal messages and allow the upgrade to complete. A reboot can follow large kernel or system library upgrades.
Concrete example
After Ubuntu finishes installing, open the terminal and run the two commands above to ensure package managers and dependencies are current before installing gcc or editors.
Key Takeaway

Always update a fresh install before adding development tools to avoid stale packages and dependency errors.
