Process Flow
Create VM & allocate resources
Set RAM, CPU, and disk to match your host capacity and the needs of a development environment.
Memory
4 GB recommended if host ≥ 8 GB; 2 GB minimum otherwise.
Disk
30 GB dynamically allocated VDI/VMDK to hold OS and development packages.
CPU
1–2 cores; avoid allocating all host cores to the VM.
Example configuration
Host: 16 GB RAM → VM: 4 GB RAM, 2 CPU cores, 30 GB VDI; this provides comfortable performance for compiling and testing C code.
Avoid

Assigning nearly all host RAM or CPUs to the VM. That can make both host and guest sluggish.
