Definition
Virtual Machine
An isolated guest OS running on top of a host via a hypervisor like VirtualBox.
Concrete scenario
Install Ubuntu in VirtualBox and practice system programming without changing your host system settings.
Misconception
VMs are unacceptably slow: with adequate RAM and CPU allocation, they are performant for development work.
VM Components
Hypervisor
VirtualBox or VMware — manages the guest lifecycle.
Virtual Disk
A file on the host representing the guest’s disk (VDI or VMDK).
Guest OS
Ubuntu Desktop installed from an ISO image to run tools and compile C programs.
Consideration

Allocate at least 2–4 GB RAM and 25–30 GB disk for a comfortable Ubuntu development VM experience.
