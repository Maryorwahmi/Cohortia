Definition
Enable WSL2 via PowerShell
Run the following commands in PowerShell as Administrator, then restart your machine and set WSL2 as default.
dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart
dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart

# After restart
wsl --set-default-version 2
Concrete notes
Use an elevated PowerShell session. Install Ubuntu from the Microsoft Store after you set the default WSL version. Then launch Ubuntu and create your Unix user.
Common trap

If you skip the restart after enabling features, WSL may fail to launch correctly. Restart when prompted.
