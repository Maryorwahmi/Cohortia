Module 1 › Chapter 1.2 › What to Remember
Virtualization
Enable Intel VT-x or AMD-V in BIOS/UEFI to run 64-bit guests or WSL2 utility VM features.
Resources
Aim for 25–30 GB disk and 2–4 GB RAM for a smooth Ubuntu development environment.
Storage
Keep active projects in the Linux filesystem for faster builds; use mounts for sharing files only.
Final thought

A short pre-install checklist eliminates most setup problems: check virtualization, disk, RAM, and where you will store your code.
