Module 06 › Chapter 6.3 › Key Concepts
NavMesh
A precomputed set of walkable polygons used for efficient path planning.
Baking
The process of generating NavMesh data from scene geometry and bake parameters.
NavMeshAgent
Component that computes paths and handles steering, avoidance, and movement at runtime.
Takeaway
Tune both baking parameters and agent properties. Visualize the NavMesh, sample patrol points, and inspect agent state to diagnose navigation problems quickly.
