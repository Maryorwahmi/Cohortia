Module 06 › Chapter 6.3 › NavMeshAgent: The Runtime Bridge
Core role

NavMeshAgent computes a path on the NavMesh and drives movement and steering to follow it while avoiding obstacles dynamically.

Important properties
  • speed — maximum movement speed.
  • acceleration — how quickly the agent reaches speed.
  • stoppingDistance — how close the agent gets before slowing.
  • autoBraking — whether the agent slows automatically on approach.
Example

During a chase, increase speed and keep stoppingDistance > 0 to avoid collision while maintaining pressure on the player.

Code call
// Example usage in a script
// agent.SetDestination(targetPosition);
// Check agent.remainingDistance and agent.pathPending to track progress
Remember: SetDestination initiates a path; the agent follows it subject to its movement properties. Use remainingDistance and isStopped to monitor and control behavior.
