Module 06 › Chapter 6.3 › Baking a NavMesh
Key Bake Parameters
Agent Radius
Defines the agent’s clearance; affects narrow passages.
Agent Height
Minimum agent height to detect ceilings and low obstacles.
Max Slope
Highest climbable angle included as walkable.
Step Height
Maximum vertical step the agent can step over during navigation.
Bake checklist
  • Mark ground as Navigation Static (Walkable).
  • Mark obstacles as Navigation Static (Not Walkable).
  • Adjust parameters and click Bake; inspect the resulting overlay.
Example

Doorway width 0.8m: agent radius 0.5m allows passage. If agents get stuck at the doorway, try reducing radius instead of changing runtime steering first.

Visualization
Inspect the blue overlay to ensure walkable areas match your intended level flow. If not, adjust bake parameters and re-bake.
