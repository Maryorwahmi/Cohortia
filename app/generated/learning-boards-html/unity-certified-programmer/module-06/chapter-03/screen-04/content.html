Module 06 › Chapter 6.3 › What is a NavMesh?
Definition

A collection of connected polygons representing walkable surfaces. The NavMesh replaces detailed collision geometry for planning and produces a graph agents use for pathfinding.

Bullets
  • Speeds up path calculation by working on polygons rather than mesh triangles.
  • Automatically excludes obstacles so agents route around them.
  • Depends on baking parameters and object settings for accuracy.
Example

A level with pillars: the NavMesh will leave holes where pillars stand so an agent navigates around them without per-frame collision checking.

Key Takeaway

NavMesh is the precomputed map agents use for planning; tune baking to match agent footprint for accurate paths.

Analogy
Think of it as a city sidewalk map: streets and sidewalks are kept, buildings are removed, so routing becomes a simple search across passable polygons.
