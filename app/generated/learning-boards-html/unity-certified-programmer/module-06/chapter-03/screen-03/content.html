Module 06 › Chapter 6.3 › Learning Objectives
Practical skills
  • Adjust baking parameters and validate the blue overlay in the Scene view.
  • Add and configure NavMeshAgent, then command movement with SetDestination.
  • Create patrols by sampling the NavMesh for random valid points and verifying agents reach them.
  • Trace and fix stuck agents by inspecting remainingDistance, isStopped, and scene paths.
Quick checks
- Visualize NavMesh after every bake.
- Verify Navigation Static settings for ground and obstacles.
- If corridor is blocked, test with a smaller agent radius value.
