Module 06 › Chapter 6.3 › Using NavMesh.SamplePosition
Sampling pattern
Vector3 randomPoint = origin + Random.insideUnitSphere * patrolRadius;
NavMeshHit hit;
if (NavMesh.SamplePosition(randomPoint, out hit, searchRadius, NavMesh.AllAreas)) {
    agent.SetDestination(hit.position);
} else {
    // fallback or retry
}
Make searchRadius equal or a bit larger than your patrolRadius to increase chance of finding a valid polygon. If sampling fails repeatedly, increase radius, count attempts, or pick a known safe point.
Concrete tip
Limit sampling attempts per frame to avoid CPU spikes. Retry over multiple frames or expand search radius on failure.
Misconception
Random points are valid by default. They are not; you must sample the NavMesh before using them as destinations.
Key Takeaway

Always validate random patrol points with NavMesh.SamplePosition and handle failure by retrying or falling back to safe patrol points.
