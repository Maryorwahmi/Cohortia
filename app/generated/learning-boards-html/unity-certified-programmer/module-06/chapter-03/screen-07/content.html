Module 06 › Chapter 6.3 › Agent Parameters
Agent Radius
Controls clearance. Larger radius closes narrow paths during baking.
Agent Height
Used to detect ceilings and determine if an agent fits under obstacles.
Max Slope
Highest angle allowed for walkable surfaces.
Step Height
Maximum step the agent can walk over without requiring a ramp.
Scenario comparison
Small enemy
Use smaller radius and height so it can pass through tighter spaces and under low obstacles.
Large boss
Bake with larger radius to prevent it from squeezing through tight corridors you don’t want it to use.
If both sizes need to navigate the same level, consider multi-layer NavMesh or separate areas per agent footprint to avoid compromising one agent type for another.
