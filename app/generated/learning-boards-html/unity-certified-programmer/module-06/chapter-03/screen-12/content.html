Module 06 › Chapter 6.3 › Common Baking & Navigation Issues
Checklist to debug
  1. Visualize NavMesh overlay after baking.
  2. Verify Navigation Static flags for ground and obstacles.
  3. Check Agent Radius, Max Slope, and Step Height for excluded areas.
  4. Inspect agent.remainingDistance, pathPending, and isStopped at runtime.
Common causes
Oversized Agent Radius, incorrect Navigation Static settings, Max Slope or Step Height too restrictive, or agent properties like stoppingDistance and isStopped misconfigured.
Gizmos tip
Use OnDrawGizmosSelected to draw chase ranges, patrol radii, and the agent.path corners so you can see the exact route Unity computed at runtime.
Key Takeaway

Systematically visualize and inspect bake and runtime states; most navigation bugs are fixed by adjusting bake parameters or correcting object static flags.
