Patrol pattern
// Structure shown for clarity
Start(): get NavMeshAgent, set speed and stoppingDistance, SetNewPatrolDestination();
Update(): if player in chaseRange -> agent.SetDestination(player.pos); else if reached patrol -> SetNewPatrolDestination();
SetNewPatrolDestination(): choose random point, use NavMesh.SamplePosition, agent.SetDestination(hit.position);
// Use remainingDistance and pathPending to validate reach
This code pattern separates concerns: sampling keeps patrols valid, agent properties tune motion, and the simple state switch controls behavior changes between patrol and chase.
Concrete example
Patrol radius 10, patrol interval 5 seconds, chase range 15. When player enters 15 units, agent speeds up and chases; when out of range, it resumes patrolling.
Misconception
Random points are not guaranteed valid NavMesh positions—always sample the NavMesh before setting a destination.
Key Takeaway

Use NavMesh.SamplePosition to ensure patrol points are valid and rely on agent properties to tune approach and chase behavior.
