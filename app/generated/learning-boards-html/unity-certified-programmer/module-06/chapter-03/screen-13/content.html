Module 06 › Chapter 6.3 › Lab: Build a Patrolling Agent
Lab steps
  1. Create a ground plane and obstacles; mark Navigation Static appropriately.
  2. Open Navigation → Bake, set Agent Radius and Max Slope, then Bake.
  3. Create capsule, add NavMeshAgent, and attach PatrolAI script.
  4. Implement patrol using NavMesh.SamplePosition and SetDestination, then test chase behavior.
Starter code template
// In Start: agent = GetComponent<NavMeshAgent>(); agent.speed = 3.5f; SetNewPatrolDestination();
// In Update: if (!agent.pathPending && agent.remainingDistance <= agent.stoppingDistance) SetNewPatrolDestination();
// SetNewPatrolDestination uses NavMesh.SamplePosition to validate random points
Follow these steps, run the scene, and iteratively adjust bake and agent settings until behavior matches your design goals.
