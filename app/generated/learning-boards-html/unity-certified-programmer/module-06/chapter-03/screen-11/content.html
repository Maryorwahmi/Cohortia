Module 06 › Chapter 6.3 › Tuning Runtime Properties
Motion properties
speed
Max velocity.
acceleration
How fast agent reaches speed.
angular speed
How fast agent rotates.
stoppingDistance
Distance to target before slowing.
Tuning examples

Nimble scout: speed 5, acceleration 10, angular speed high, stoppingDistance small.

Heavy guard: speed 2.5, acceleration 4, angular speed lower, stoppingDistance larger to avoid overlap.

Key Takeaway

Tune motion properties together: speed, acceleration and angular speed interact; stoppingDistance prevents collisions and should be set intentionally.
