Module 6 › Chapter 6.2 › Frame-Rate Independence
Step-by-Step
1. Compute direction
target minus agent, zero y if needed, normalize.
2. Scale speed
Multiply unit direction by speed measured in units per second.
3. Apply delta time
Multiply by Time.deltaTime to compute per-frame displacement.
4. Update position
Add displacement to transform.position or use MoveTowards for clamping.
Concrete Example
If speed is five units per second and Time.deltaTime equals 0.02 seconds, the agent moves 0.1 units this frame. If the frame time changes to 0.0167, the per-frame step adapts so the per-second distance remains near five. This makes behavior predictable when testing on different machines or when game load spikes.
Key Takeaway

Always treat speed as units per second and multiply by Time.deltaTime for each frame update to keep motion consistent.

Common Mistake
Using Time.deltaTime in FixedUpdate incorrectly or omitting it entirely causes inconsistent speeds; choose the right loop for your implementation.
