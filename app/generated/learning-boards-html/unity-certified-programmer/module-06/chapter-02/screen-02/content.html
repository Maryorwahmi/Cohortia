Vector Mathematics

Seeking & Fleeing

03
Obstacle Avoidance
Use forward raycasts and optional side rays to detect obstacles. Rotate the desired movement direction when a hit occurs to steer around blockers.

Frame-Rate Independence & Debugging

These objectives scaffold practice: first gain vocabulary and math, then implement movement, then add avoidance and polish rotation. By practicing in the Scene view you link code to visible agent behavior.

Key Takeaway

Mastering vectors and delta time prevents inconsistent movement and lays the groundwork for reliable seeking, fleeing, and avoidance.
