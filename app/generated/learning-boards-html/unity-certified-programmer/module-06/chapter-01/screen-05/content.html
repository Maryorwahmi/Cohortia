Types of Game AI
Match each category to a concrete gameplay use
Pathfinding
Moves an agent from its current location to a target while avoiding obstacles. Example: an enemy uses a navigation mesh to reach the player.
Perception
Determines whether the player is seen or heard. Example: a ray or distance check triggers the Chase state.
Decision
Selects which behavior to run. Example: an FSM chooses idle, patrol, or chase based on timers and detection.
Utility
Scores multiple possible actions to pick the most desirable. Useful for varied NPCs but requires tuning.
Practical Tip

Keep perception and pathfinding separate from decision logic so you can test each system independently.

Quick Map
Use Pathfinding for movement
Use Perception to trigger states
Use Decision logic to choose action
