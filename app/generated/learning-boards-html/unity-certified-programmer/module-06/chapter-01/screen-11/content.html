Common Pitfalls & Misconceptions
Troubleshooting the usual problems
Micro-states
Too many similar states create maintenance overhead. Merge or use HFSMs for reuse.
Frame-rate dependent movement
Always multiply speeds by Time.deltaTime to ensure consistent movement across machines.
Null references
Cache and verify references like playerTransform in Start to avoid runtime errors.
No hysteresis
Add buffers to detection thresholds to prevent rapid state flipping.
Fix Pattern

Draw, test, and refactor: clear diagrams and editor Gizmos help you find and fix these issues fast.

Quick Checklist
  • Use Time.deltaTime on all movement
  • Cache transforms in Start
  • Draw Gizmos to validate ranges
  • Add buffers to detection thresholds
