Idle, Patrol, and Chase
Concrete execution and safety checks
Idle
Increment idleTimer by Time.deltaTime. If idleTimer >= idleDuration then TransitionToState(Patrol). Also check detection each frame to allow interruption.
Patrol
If no patrol points, transition to Idle. Move toward patrolPoints[currentIndex] using Vector3.MoveTowards with patrolSpeed * Time.deltaTime. When within 0.1 units, advance index modulo length.
Chase
If playerTransform is null, TransitionToState(Patrol). Otherwise move toward playerTransform.position with chaseSpeed * Time.deltaTime and check distance to determine when to drop chase.
