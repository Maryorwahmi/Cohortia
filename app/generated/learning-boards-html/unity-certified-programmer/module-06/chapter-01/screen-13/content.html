Hands-on: Build GuardAI
Implement, assign, and test Idle, Patrol, and Alert states
Starter Checklist
  • Create GuardAI script and enum GuardState { Idle, Patrol, Alert }.
  • Public vars: playerTransform, patrolPoints, detectionRange, patrolSpeed, alertSpeed, idleDuration.
  • In Start, cache playerTransform or find by tag and warn if missing.
  • Use switch in Update to call state handlers.
Testing
Create guard cube, player sphere, and empty GameObjects as patrol points. Assign in Inspector and run. Use Gizmos to draw detectionRange.
Outcome

A working guard that idles, patrols, and chases the player, with visible ranges for tuning.
