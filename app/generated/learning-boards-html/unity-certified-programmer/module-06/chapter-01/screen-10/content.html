Enter / Execute / Exit Structure
A pattern for readable state code
Enter()
Run once on state change to initialize timers, set animations, or prepare targets.
Execute()
Run every frame to perform movement, checks, and possibly call TransitionToState when conditions are met.
Exit()
Cleanup when leaving the state; stop sounds, reset flags, or cancel coroutines.
When to HFSM

Use a hierarchical FSM only when you see repeated logic that a parent state can provide without adding confusing depth.

HFSM Example
Parent: Combat
Shared targeting and attack timers.
Child: Melee / Ranged
Specific attack execution and ranges.
