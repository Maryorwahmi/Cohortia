Action Reminders
Practical habits to apply immediately
Sketch First
Draw states and transitions before writing code to catch errors early.
Expose Tunables
Make detectionRange, speeds, and durations editable in the Inspector for quick iteration.
Refactor When Needed
Move to HFSMs or behavior trees only when duplication or complexity justifies it.
Final Thought

Start simple, test visually, and refactor intentionally. Those steps produce reliable gameplay faster.
