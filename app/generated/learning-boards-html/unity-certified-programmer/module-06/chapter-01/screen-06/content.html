Finite State Machine (FSM)
Single-state clarity for predictable behavior
Key parts of an FSM include the list of states, the current state, transition rules, and optional entry and exit hooks for each state. When you implement in code, these translate to an enum of states and a state dispatcher that runs the logic for the active state each frame.
Entry
Setup values or play animations when a state starts.
Execute
Per-frame logic while in a state, such as movement or checks.
Exit
Cleanup or reset before a new state begins.
Key Takeaway

FSMs make behavior explicit: draw states and transitions, then implement each state's entry, execute, and exit to keep code readable.

Example FSM
States: Idle, Patrol, Chase
Transitions: Idle → Patrol after timer, Patrol → Chase on detection, Chase → Patrol when player lost.
