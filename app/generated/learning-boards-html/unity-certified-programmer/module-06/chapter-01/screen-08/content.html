FSM Implementation Pattern
Enums, switch dispatch, and centralized transitions
using UnityEngine;

public enum EnemyState { Idle, Patrol, Chase }

void Update()
{
    switch (currentState)
    {
        case EnemyState.Idle: IdleState(); break;
        case EnemyState.Patrol: PatrolState(); break;
        case EnemyState.Chase: ChaseState(); break;
    }
}
Important
Cache player transform in Start; check for null before using. Use Time.deltaTime for movement to remain frame-rate independent.
Transition function
Centralize state changes in TransitionToState to run exit and entry hooks consistently.
Common Mistake

Failing to multiply movement by Time.deltaTime causes inconsistent speed across machines.
