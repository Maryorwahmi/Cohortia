Module 6 › Chapter 6.6 › Utility AI — Core Idea
Term
Utility
A numerical value representing how useful an action is given current game state. Compare utilities across options and execute the highest.
Action
Attack, Heal, Flee
Behaviors available to the agent.
Consideration
MyHealth, DistanceToTarget
Small functions mapping state to 0–1 scores.
Key Takeaway

Utility is relative. Tune considerations and combination rules with all actions in view to shape behavior predictably.

How it works
  1. Compute each Consideration score from agent state.
  2. Combine consideration scores to form an action utility.
  3. Compare utilities for all available actions.
  4. Execute the action with the highest utility.
Concrete example
If MyHealth gives 0.9 for Heal and DistanceToTarget gives 0.8 for Attack, multiplication might yield Heal:0.9 and Attack:0.8; the agent heals when health is critical.
Misconception: Multiplying always works. In fact, multiplication punishes any low consideration; choose combination methods that match your design goals.
