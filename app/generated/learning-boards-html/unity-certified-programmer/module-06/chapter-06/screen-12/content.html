Key fields
  • Transform target, currentHealth, maxHealth, moveSpeed.
  • List<AIAction> availableActions assigned in the Inspector.
  • decisionInterval and a timer to control evaluation frequency.
Runtime wiring: in Start() map action names to local methods so actions call agent behaviors when selected.
Snippet (conceptual)
void Update() { decisionTimer += Time.deltaTime; if (decisionTimer >= decisionInterval) { MakeDecision(); decisionTimer = 0; } if (currentBestAction != null) currentBestAction.ExecuteAction(this); } void MakeDecision() { /* evaluate utilities and pick highest */ }
Design tip: Separating decision timing from execution keeps evaluation cheap and behavior smooth between decision ticks.
