Module 6 › Chapter 6.6 › Decision Maker
Core responsibilities
  • Hold a list of AIAction assets available to the agent.
  • On a fixed interval, compute utilities for each action.
  • Select and execute the highest utility action.
  • Log decisions for debugging and visualization.
Execution decoupling
Actions should expose a delegate or method the Decision Maker calls; scoring must not directly move the agent.
Snippet (conceptual)
// Pseudocode concept: Evaluate actions every decisionInterval float highest = -1; AIAction best = null; foreach action in actions: float u = action.GetUtility(agent); if u > highest: highest = u; best = action; if best != current: switch to best and log utility;
Debug tip: Print actionName and utility with two decimal places so you can correlate curve adjustments with runtime choices.
