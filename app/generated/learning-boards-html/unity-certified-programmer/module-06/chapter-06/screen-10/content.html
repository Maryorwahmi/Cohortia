Module 6 › Chapter 6.6 › Consideration ScriptableObjects
Pattern benefits
  • Editable curves and parameters in the Inspector.
  • Reuse the same Consideration across actions or agents.
  • Designer-friendly iteration without code changes.
Implementation note: add safe guards like returning 0 when target is null or max values are zero to avoid runtime errors.
Conceptual code
public class MyHealthConsideration : Consideration { public AnimationCurve scoreCurve; public override float Score(AIAgent agent) { if (agent.maxHealth == 0) return 0; float healthNormalized = agent.currentHealth / agent.maxHealth; return scoreCurve.Evaluate(healthNormalized); } }
