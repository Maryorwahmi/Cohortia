Module 6 › Chapter 6.6 › Performance
Decision Interval
Evaluate utilities every 0.3–0.6s instead of each frame for many agents to reduce CPU cost while maintaining responsiveness.
Relevance checks
Skip actions whose preconditions are not met, e.g., actions that require a target when none exists.
Gating & caching
Compute cheap checks first, cache normalized inputs, and avoid recalculating expensive values across considerations.
Scaling tip
Stagger decision ticks across agents and profile to find hotspots before optimizing. Maintain readable debug hooks for tuning after optimizations.
