Module 6 › Chapter 6.6 › Learning Objectives — Practice & Tuning
01 Create Considerations
Design Consideration classes and curves that map agent state variables to normalized scores you can tune in the Inspector.
Visual mnemonic: curve icon
02 Assemble Actions
Compose AIAction assets from considerations and attach execution logic via delegates or agent methods.
Visual mnemonic: stack of cards
03 Decision Loop
Implement MakeDecision to evaluate utilities every fixed interval and switch behavior when a higher utility appears.
Visual mnemonic: clock and check
04 Debug & Tune
Log scores, display curves, and run iterative playtests to adjust curves and weighting so behavior is stable and expressive.
Visual mnemonic: magnifier and graph
