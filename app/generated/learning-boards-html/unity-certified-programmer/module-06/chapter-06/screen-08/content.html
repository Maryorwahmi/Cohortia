Module 6 › Chapter 6.6 › Combining Scores
Multiply
Product of consideration scores. Use when all considerations must be reasonably true.
Effect: conservative, punishes any low score.
Weighted sum / Average
Combine with weights so important considerations carry more influence.
Effect: flexible, allows compensation between considerations.
Additive
Sum raw scores or scaled values. Simple but requires normalization so totals are comparable between actions.
Effect: intuitive but sensitive to scale.
Concrete example
Heal action: multiply(MyHealthScore, IsSafeToHealScore). If safety is zero, healing won't be chosen even with low health.
Misconception
Assuming multiplication always yields best results. It creates brittle decision boundaries if some considerations are noisy or intermittent.
