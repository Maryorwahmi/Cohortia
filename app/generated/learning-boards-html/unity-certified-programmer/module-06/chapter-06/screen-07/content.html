Common curve types
  • Linear: predictable ramp, simple thresholding.
  • Sigmoid: smooth threshold, avoids sharp jumps.
  • Exponential: emphasizes extremes, very sensitive near one end.
Normalization matters: scale raw values into a known range (for example, distance / maxDistance) so the curve behaves consistently across agents.
Concrete example
Set MyHealth curve to produce high scores when healthNormalized is near zero for an aggressive Heal action. Use different curve shapes for Attack and Flee to create distinct decision boundaries.
