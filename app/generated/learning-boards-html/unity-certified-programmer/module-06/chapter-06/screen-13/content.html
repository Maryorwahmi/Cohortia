Module 6 › Chapter 6.6 › Attack / Heal / Flee
Attack
Considerations: DistanceToTarget (high when close), EnemyHealth (high when enemy is weak). Combination: weighted sum to allow strong proximity to dominate.
Heal
Considerations: MyHealth (high when low), IsSafeToHeal (reduces healing if enemies are near). Combination: multiply so safety gates healing.
Flee
Considerations: MyHealth (high when low), DistanceToTarget (high when close). Combination: multiply for a decisive flee when both are true.
Practical step
Create three AIAction ScriptableObjects, set their consideration lists and curves, then assign them to the NPC's availableActions list in the Inspector.
Tuning prompt
Adjust one curve at a time, run short playtests, and log utilities to understand each change's effect before modifying another parameter.
