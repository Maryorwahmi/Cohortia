Module 6 › Chapter 6.6 › Components
Action
Executes behavior
Contains a list of considerations and a method or delegate to run when selected.
Example: Attack action contains DistanceToTarget and EnemyHealth considerations.
Consideration
Maps state to score
A pure scoring function taking the agent as input and returning 0–1. Keep logic separate from execution.
Example: MyHealthConsideration evaluates currentHealth / maxHealth then applies a curve.
Scoring Function
Curve or math
Use AnimationCurve or a math function to shape sensitivity, threshold, and scaling for a consideration.
Tip: store curves as assets so designers can iterate without code changes.
Analogy
Considerations are sensors, scoring functions are calibrations, and actions are tools the agent can use.
Common mistake
Putting movement or execution code inside considerations. Keep them pure to simplify testing and reuse.
