Module 6 › Chapter 6.6 › AIAction
What an AIAction contains
  • actionName for identification.
  • List of Consideration ScriptableObjects.
  • ExecuteAction delegate or reference to an agent method.
Design tip: Provide descriptive action names so wiring code can map names to agent methods clearly and safely.
Conceptual code
public class AIAction : ScriptableObject { public string actionName; public List<Consideration> considerations; public Action<AIAgent> ExecuteAction; public float GetUtility(AIAgent agent) { float score = 1f; foreach(var c in considerations) score *= c.Score(agent); return score; } }
Ensure GetUtility has predictable defaults and that ExecuteAction is assigned at runtime by the agent that owns the actions.
