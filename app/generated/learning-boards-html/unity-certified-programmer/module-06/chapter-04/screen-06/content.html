Module 6 › Chapter 6.4 › Manual Off-Mesh Traversal
Step-by-step
  1. Set agent.autoTraverseOffMeshLink to false in Start.
  2. Detect agent.isOnOffMeshLink and stop the agent's pathing.
  3. Read agent.currentOffMeshLinkData.startPos and endPos.
  4. Run a coroutine to move the transform with a parabolic Y offset.
  5. Call agent.CompleteOffMeshLink and resume movement.
Common pitfall
Forgetting to call CompleteOffMeshLink leaves the agent unable to resume pathfinding.

Concrete example
Use a one-second jump duration and add Mathf.Sin on the normalized time for a clean arc. Trigger an Animator jump and land triggers around the coroutine.
