Module 6 › Chapter 6.4 › Auto vs Manual Traversal
Auto traversal
Pros: simple, low code, smooth movement. Cons: cannot play custom animations or control timing.
When to use
Small transitions or when visual fidelity is not required.
Misuse to avoid
Don't enable autoTraverse if you intend to animate the agent manually; they will fight for control.
Manual traversal
Pros: full control over animation and timing. Cons: more code and responsibility to resume pathing correctly.
When to use
When you need a jump, climb, or landing animation synchronized with movement.
Key Takeaway

Pick automatic for low-friction movement and manual for animation fidelity; never mix both at once for the same traversal.
