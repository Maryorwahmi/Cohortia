Module 6 › Chapter 6.4 › Key Concepts
NavMeshObstacle
A component that carves runtime holes, allowing dynamic re-pathing.
Off-Mesh Link
Connects two non-walkable points so agents can jump or climb.
Traversal Control
Use autoTraverse for simple moves; disable it to run custom animation and call CompleteOffMeshLink.
Takeaway
Combine selective carving with link placement and controlled traversal to build believable, scalable navigation behaviors.
