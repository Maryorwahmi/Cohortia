Module 6 › Chapter 6.4 › Off-Mesh Links
What is an Off-Mesh Link?
A connection between two NavMesh points that lets agents traverse discontinuous geometry.
Manual placement
Place an Off-Mesh Link object and assign start and end transforms on valid NavMesh positions.
Auto-generation
Enable OffMeshLinkGeneration in the Bake settings to auto-create links for jumps and drops based on parameters.
Common misconception
Off-Mesh Links do not automatically play animations; automatic traversal only handles movement. To play a custom animation you must disable auto traversal and control the movement yourself.
Key Takeaway

Off-Mesh Links let agents perform actions off the baked walkable surface. Use them to model jumps, ladders, and teleports without changing the NavMesh topology.

Concrete scenario
Two isolated platforms separated by a small chasm. Add an Off-Mesh Link between them so an agent heading to a target on the far side can cross without a bridge.
Pro tip
When auto-generating links, inspect endpoints to ensure they lie on suitable NavMesh surfaces; adjust generation thresholds if links are missing or misplaced.
