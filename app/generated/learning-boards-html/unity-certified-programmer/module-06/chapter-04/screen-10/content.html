Module 6 › Chapter 6.4 › Debugging NavMesh
Path status meanings
  • Complete: Full path to destination.
  • Partial: Reached closest reachable point; destination unreachable.
  • Invalid: No path computed.
Checks to run
  1. Open Navigation debug and inspect Areas and Obstacles.
  2. Verify Off-Mesh Link endpoints lie on NavMesh polygons.
  3. See if runtime carving removed needed NavMesh polygons.
Scene debugging aids
Use an OnDrawGizmos method to draw agent.path.corners lines and spheres at each corner to visualize the found path and where it stops. Toggle obstacle carve to watch NavMesh holes appear and disappear.
Key Takeaway

Combine programmatic pathStatus checks with the Navigation debug view and path gizmos to find whether the problem is bake-time or runtime behavior.
