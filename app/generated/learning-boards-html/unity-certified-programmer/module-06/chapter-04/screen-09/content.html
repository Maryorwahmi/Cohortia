Module 6 › Chapter 6.4 › Agent Parameters
Key properties
Speed & Acceleration
Control movement responsiveness and maximum walk speed.
Stopping Distance
How close the agent gets before it stops, useful for cover or formation spacing.
Radius (runtime)
Defines local avoidance collision size; affects how agents steer around each other.
Avoidance & Performance
Obstacle Avoidance Type trades CPU for quality. Use high quality for a small number of agents near the player, and lower quality for many background agents.
Practical strategy
Categorize AI by role and assign avoidance quality accordingly. Profile with realistic agent counts to confirm performance impact.
Misconception
Do not assume baked agent radius solves runtime steering; adjust runtime radius and avoidance settings for desired behavior.
