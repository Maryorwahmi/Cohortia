Safety checks to include
  • Verify agent is not null and disable the script if missing.
  • Use a boolean guard so the coroutine cannot start multiple times.
  • Ensure you set transform.position precisely at end to avoid small offsets.
Concrete example
Set jumpDuration to about one second and a jumpHeight around one to two units for a visible arc. Tune the values to match animation timing if you play one.
Common misconception
Moving the agent while its NavMeshAgent remains uncontrolled can cause collisions. Stop the agent and move transform or use agent.nextPosition carefully depending on your setup.
