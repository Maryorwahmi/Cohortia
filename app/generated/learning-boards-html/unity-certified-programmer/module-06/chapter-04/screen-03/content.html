Module 6 › Chapter 6.4 › Learning Objectives
How you'll demonstrate each objective
01 — Dynamic carving demo
Task: Add NavMeshObstacle to a moving cube. Enable carve only while it blocks the path. Validation: Agents re-path instead of trying to cross the cube.
Milestone: Demonstrate agents detouring around the moving cube.
02 — Off-Mesh Link placement
Task: Create a gap and place an Off-Mesh Link between platforms. Validation: Agent reaches destination using the link.
Milestone: Verify link endpoints are on valid NavMesh regions.
03 — Manual traversal coroutine
Task: Set autoTraverseOffMeshLink to false and write a coroutine that lerps the agent between start and end positions with a parabolic offset. Validation: Call CompleteOffMeshLink after movement.
Milestone: Agent plays a jump arc and resumes pathfinding.
04 — Tuning and debugging
Task: Adjust speed, acceleration, radius, and avoidance type. Use pathStatus and the Navigation debug view to diagnose Partial or Invalid paths. Validation: Agent path is Complete or you identify cause for Partial.
Milestone: You can justify a change for gameplay or performance reasons.
