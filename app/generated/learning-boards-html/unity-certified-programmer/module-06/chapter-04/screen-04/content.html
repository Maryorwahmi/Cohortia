Module 6 › Chapter 6.4 › NavMeshObstacle & Carving
Definition
NavMeshObstacle lets a GameObject carve out a portion of the NavMesh so agents will avoid that area at runtime.
Shapes & settings
Choose Box or Capsule, set Size and Center, and enable Carve to remove the NavMesh beneath the object.
When to carve
Use carve for persistent, significant dynamic blockers like doors and large crates. Disable carve for small props to save CPU.
Common mistake
Adding carve to all moving objects causes high CPU cost and frequent NavMesh updates.
Key Takeaway

Carve selectively. Toggle Carve during state changes like door close/open to maintain correct paths without continuous cost.

Concrete example
Create a cube with NavMeshObstacle. Add a small script to move it left and right. With Carve enabled the NavMesh recomputes around the cube at runtime and agents will re-path to avoid it.
Debug checks
  • Confirm the obstacle is on the NavMesh layer.
  • Match shape size to the physical collider.
  • Toggle Carve to observe NavMesh holes appear and disappear.
Pro tip
If performance suffers, disable Carve when the obstacle is off-screen or when many obstacles are active; consider alternative avoidance for small props.
