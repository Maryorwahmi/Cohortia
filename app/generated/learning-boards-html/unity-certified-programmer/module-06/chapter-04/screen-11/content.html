Module 6 › Chapter 6.4 › Hands-on Activity
Lab Steps
  1. Add a cube with NavMeshObstacle and enable Carve. Move it with a sine-based script so it crosses agent routes.
  2. Create two platforms and an Off-Mesh Link connecting valid NavMesh points on each platform.
  3. Add a NavMeshAgent to your character and set autoTraverseOffMeshLink to false.
  4. Implement a coroutine to lerp the agent between link start and end with a parabolic offset and call CompleteOffMeshLink at the end.
  5. Run and observe: the agent should avoid the moving cube and perform the jump across the link.
Validation checklist
  • Agent re-paths around cube when it blocks the way.
  • Agent performs jump arc and lands on the target platform.
  • agent.CompleteOffMeshLink is called and movement resumes.
Troubleshoot
If the agent doesn't move, check pathStatus for Partial or Invalid and verify Off-Mesh Link endpoints and Carve toggles are correct.
