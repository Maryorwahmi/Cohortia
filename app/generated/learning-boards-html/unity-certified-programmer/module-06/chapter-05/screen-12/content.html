Node and composite patterns
Implement NodeState enum and an abstract Node with Evaluate. Sequence and Selector iterate children and update nodeState accordingly.
// NodeState { Running, Success, Failure }
public abstract class Node { protected NodeState nodeState; public abstract NodeState Evaluate(); }

public class Sequence : Node {
  private List children;
  public Sequence(List children){ this.children = children; }
  public override NodeState Evaluate(){ bool anyRunning=false; foreach(var node in children){ switch(node.Evaluate()){ case NodeState.Running: anyRunning=true; break; case NodeState.Success: continue; case NodeState.Failure: nodeState=NodeState.Failure; return nodeState; } } nodeState = anyRunning? NodeState.Running : NodeState.Success; return nodeState; }
}

public class Selector : Node { /* similar pattern: return Success on first Success */ }
Supporting bullets
  • Keep Evaluate side-effect free except at leaf nodes.
  • Store minimal state in composites to resume Running children.
  • Use Debug.Log in leaves to trace behavior flow during play.
Common mistake

Not setting nodeState before return. Always set nodeState so debugging output matches runtime behavior.

Key Takeaway

Follow the Evaluate contract strictly and log leaf execution to verify flow in Unity.
