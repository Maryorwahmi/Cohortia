Module 6 › Chapter 6.5 › Decorator Nodes
Decorators modify a single child
Use them to invert results, repeat execution, or gate a child with a timeout or condition.
Inverter

Flips Success to Failure and Failure to Success. Useful to negate a condition.

Repeater

Runs a child multiple times or indefinitely. Useful to loop patrols or animations.

Design tip

Keep modifiers outside actions so the same action can be reused with different decorators.

Concrete example

Wrap a MoveTo leaf with a Repeater to continuously patrol waypoints. If an Attack sequence succeeds, the selector will choose attack and interrupt the patrol repeater.

Common mistake

Embedding inversion or looping inside actions duplicates code and reduces reusability across the tree.

Key Takeaway

Use decorators to adapt child behavior without changing the child implementation.
