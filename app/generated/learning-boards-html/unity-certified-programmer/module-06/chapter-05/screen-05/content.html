Behavior Tree fundamentals
Nodes evaluate to Success, Failure, or Running. This contract is the foundation of predictable composition.
Root

Entry point that ticks its child. The root initiates evaluation each frame or tick interval.

Composite

Holds multiple children and controls how they are ticked, e.g., Sequence or Selector.

Decorator

Modifies a single child's result or execution, such as inverting success or repeating execution.

Leaf

Action or condition that performs work or checks game state and returns a NodeState.

Concrete example

MoveTo action: while moving it returns Running; when close enough it returns Success. That Running state keeps the agent moving across frames without restarting the action each tick.

Misconception

Treating Running as Success leads to premature branch changes. Running only indicates an incomplete task.

Key Takeaway

Design leaf actions to manage their own progression and return Running until complete.
