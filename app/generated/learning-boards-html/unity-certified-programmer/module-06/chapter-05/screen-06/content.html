Sequence: ordered execution
Think "Do A, and then B, and then C." Use when every step must succeed for the whole task to succeed.
Example Sequence
  1. Check: Is player in attack range?
  2. Check: Is weapon loaded?
  3. Action: Perform attack
Pro tip

Place cheap conditions first so the sequence fails fast and avoids running expensive actions unnecessarily.

Supporting bullets
  • Executes children left to right.
  • Returns Failure immediately if any child fails.
  • Returns Running if a child is running and resumes from that child next tick.
  • Succeeds only when all children have succeeded.
Key Takeaway

Use Sequence for guarded tasks where prerequisites must pass before acting.
