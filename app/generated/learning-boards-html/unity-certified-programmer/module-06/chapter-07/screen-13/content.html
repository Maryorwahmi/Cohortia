Comparison Mistakes & Trade-offs
A direct comparison of common optimization choices and their downsides.
Premature Optimization
Optimizing without profiling can waste effort and introduce bugs. Always measure first with the Profiler to find the hot path.
Over-simplification
Removing decision branches or sensory checks may make AI cheap but predictable and dull. Preserve emergent behavior where it matters.
Rule: Profile → Target → Change → Validate.
Pooling vs Memory
Pooling uses more memory for a pre-created pool but avoids spikes from allocations. Choose pool sizes that match peak concurrency.
Avoidance Quality vs Accuracy
Lower avoidance reduces CPU but can create collisions or unnatural movement. Dynamically scale quality by importance.
Check: After each change, run the Profiler and a player-facing playtest to confirm both performance and experience.
