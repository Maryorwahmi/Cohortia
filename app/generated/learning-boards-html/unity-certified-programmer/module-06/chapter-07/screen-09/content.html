Architecture AI LOD Pipeline
A three-tier approach makes scaling predictable and maintainable.
High Fidelity
Frequent updates, precise avoidance, full decision trees. Use for player-facing adversaries.
Medium Fidelity
Moderate update intervals and reduced sensory checks. Use for nearby but non-critical agents.
Low Fidelity
Long intervals, simple patrol logic, low avoidance quality. Use for distant background agents.
Implementation Notes
Attach an LOD manager that updates agents as they change distance or priority. Profile cost difference to set thresholds.
