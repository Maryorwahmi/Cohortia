Process Flow Profiler Workflow
A step-by-step approach to find and verify AI performance issues.
Steps to Diagnose
  1. Reproduce the problem with realistic agent counts and behaviors.
  2. Record a Profiler capture covering the spike period.
  3. Inspect CPU Hierarchy and Timeline to find hot functions like NavMeshAgent.Update or your scripts.
  4. Pinpoint the code block and propose a targeted fix.
  5. Implement and re-run the profiler to measure improvement.
Practical Tips
  • Use Profiler.BeginSample and EndSample around suspect code to get finer granularity.
  • Compare before/after captures to confirm CPU savings and removed spikes.
  • Check Garbage Collection frequency when measuring pooling benefits.
Try: Record two captures, one without pooling and one with pooling. Compare CPU frame timing and GC frequency to validate the improvement.
