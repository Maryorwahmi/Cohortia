Bloom: Learn → Understand → Apply → Master
01
Identify AI performance bottlenecks
Recognize causes like instantiation spikes, frequent path recalculation, and heavy per-frame decisions so you know where to profile first.
Venn: Code · Cost · Frequency
VERIFIED COMPETENCY MILESTONE
02
Apply object pooling
Implement a pool for frequently spawned agents to reduce allocation and destruction costs. Proper pooling prevents GC spikes during waves.
Mnemonic: Prepare, Borrow, Return
VERIFIED COMPETENCY MILESTONE
03
Throttle pathfinding and decisions
Use intervals like targetUpdateInterval and decisionInterval so agents update only when needed or at scheduled times to spread CPU work.
Timeline: Frequent → Periodic → Event
VERIFIED COMPETENCY MILESTONE
04
Use the Unity Profiler and visual debugging
Find spikes with the Profiler and inspect behavior with Gizmos and debug rays to understand what the AI is doing and why.
Mnemonic: Measure → Visualize → Fix
