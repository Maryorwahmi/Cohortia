Definition Visual Debugging
Turn runtime data into scene visuals to understand agent perception and planning.
Common Visuals
  • Gizmos.DrawWireSphere for detection ranges and sight radii.
  • Gizmos.DrawLine or Debug.DrawLine for agent path corners.
  • Debug.DrawRay for sensor rays and line-of-sight checks.
  • Custom editor overlays for Behavior Tree or Utility AI scores.
Concrete Example
In OnDrawGizmosSelected the example draws a blue wire sphere for chaseRange and yellow lines for path corners. This quickly shows whether the player is within detection and whether the path is valid.
Checklist
- Add visuals for any invisible sensing or planning step.
- Toggle visuals with a debug flag to avoid runtime cost in builds.
- Use logs alongside visuals for state dumps when necessary.
Pro-tip: Only draw gizmos in editor builds or when a debug flag is set to avoid runtime performance cost in production.
