Module 08 › Chapter 8.1 › PlayerNetworkController Walkthrough
Code Walkthrough

Key behaviors

  • Declare NetworkVariables for replicated state like position and health.
  • Use OnNetworkSpawn to set initial values and subscribe to changes.
  • In Update, owners handle input and request server changes via ServerRpc.
  • ServerRpc methods execute on server and update NetworkVariables; ClientRpc triggers client visuals.
Misconception
Clients calling ServerRpc does not mean data is trusted; server must still validate requests.
Annotated snippet
// NetworkVariable Position, NetworkVariable Health
// OnNetworkSpawn subscribes to Health.OnValueChanged
// Update: if IsOwner -> HandleOwnerMovement and SubmitPositionServerRpc
// ServerRpc applies changes and may call PlayDamageEffectClientRpc
Key Takeaway

Follow the owner → ServerRpc → server-validation → NetworkVariable update pattern for safe synchronization.
