Prediction and reconciliation flow

Balance client responsiveness with server authority using prediction and reconciliation.

Client-side prediction
Client simulates movement immediately for responsiveness and queues the input for server validation.
Server validation
Server checks the requested state and updates authoritative NetworkVariables accordingly.
Reconciliation
Client applies server-provided state and smooths corrections to avoid abrupt visual snaps.
Concrete example
Owner moves locally and sends position updates. Server validates and corrects impossible movement; client reconciles to the server position.
Key Takeaway

Use prediction for responsiveness but always reconcile with server authority to avoid exploits and divergent state.
