Definition

Netcode for GameObjects

Installable via Package Manager
Core primitives
  • NetworkObject — marks a GameObject for replication.
  • NetworkVariable<T> — replicates simple state from server to clients.
  • ServerRpc / ClientRpc — methods to call server or clients remotely.
Practical example
A player prefab with NetworkObject and a NetworkVariable for health ensures consistent health displays across all players when the server updates the value.
Pitfall
Assuming NetworkVariables replace all validation. They replicate values but you must decide who writes them.
Pro tip
Use ServerRpc for player inputs requiring validation, and ClientRpc for broadcast visuals.
Check
Verify initial NetworkVariable values are set on spawn and that clients receive updates.
