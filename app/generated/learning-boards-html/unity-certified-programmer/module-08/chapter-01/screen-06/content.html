Module 08 › Chapter 8.1 › NetworkObject & NetworkVariable
Process Flow

Mark and replicate

A simple lifecycle: spawn, update NetworkVariables, replicate to clients.

Spawn
Attach NetworkObject to prefabs so NetworkManager can spawn them across all peers.
Replicate
Update NetworkVariable on server; NGO sends changes to clients automatically.
Key Takeaway

Use NetworkObject to mark replicated prefabs and NetworkVariable for simple server-driven state replication.

Concrete example
Player prefab includes:
  • - NetworkObject component to spawn across clients
  • - NetworkVariable<Vector3> for position updates
  • - NetworkVariable<int> for health replicated from server
Misconception
NetworkVariables automatically secure state. In reality, write permissions and validation are design decisions you control.
