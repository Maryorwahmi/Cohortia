Hands-on Activity

Synchronized Player Movement & Health

Follow these configuration steps to run a host and a client instance and observe replication.

Setup steps
  1. Install Netcode for GameObjects via Package Manager.
  2. Create NetworkManager GameObject and add NetworkManager component.
  3. Create PlayerPrefab, add NetworkObject and PlayerNetworkController, and make a prefab.
  4. Assign PlayerPrefab to NetworkManager and add NetworkManagerHUD for testing.
  5. Build and run two instances: one Host, one Client to test replication.
Checks and common errors
  • Missing NetworkObject on the prefab keeps it local.
  • Forgetting to set initial NetworkVariable values can cause visual gaps.
  • Check debug logs for ServerRpc and ClientRpc execution.
Test
Host and client should see matching player movement and synchronized health changes.
Reflection
If positions differ, how will the server correct unrealistic movement?
Key Takeaway
Follow the lab steps carefully; verify NetworkObject and prefab assignments first.
