Module 8 › Chapter 8.6 › Memory & Release
Release patterns
Always pair load operations with a corresponding release when the asset or instance is no longer needed.
Load with handle
var handle = Addressables.LoadAssetAsync; store handle; use result; Addressables.Release(handle) when done.
Instantiate
Use AssetReference.InstantiateAsync and call Addressables.ReleaseInstance when destroying the instance.
Profiler verification
Check memory usage before and after release to ensure native memory is freed.
Common error
Assuming scene unloads automatically release Addressables-managed memory. They may not; explicit releases are required.
Key Takeaway

Treat Addressables loads like any native allocation: store references and release them deterministically, and verify with the Profiler.
