Module 8 › Chapter 8.6 › Building Asset Bundles
Build steps
Follow these steps each time you prepare a new content release.
  1. Install Addressables in Package Manager and create Addressables Settings.
  2. Assign Addressable flags or drag assets into Addressables Groups.
  3. Configure build paths and remote/local settings per group.
  4. Run Build > New Build > Default Build Script to generate bundles and catalog.
  5. Deploy generated bundles and catalog to your remote host if needed.
Common mistake
Not matching the build target to the platform leads to incompatible bundle formats. Always verify target and compression settings before uploading.
Example: Remote Seasonal Skins
Create a 'SeasonalSkins' group with remote build path. After building, upload the generated bundle files and host the catalog so the game can locate these addresses at runtime.
