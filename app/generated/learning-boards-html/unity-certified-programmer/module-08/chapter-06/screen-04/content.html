Module 8 › Chapter 8.6 › What is an Asset Bundle?
Asset Bundle — definition
An archive of assets built per platform for runtime loading.
Purpose
Separate optional content from the main build to minimize initial download size and enable updates.
Example
Download a character skin bundle when the player selects a seasonal event skin.
What it contains
  • Textures, models, audio, animations
  • Dependency files required by those assets
  • Platform-specific compression variants
Common misconception
Bundles do not automatically free memory when unused; loading still allocates memory that you must manage.
Concrete analogy
Think of a bundle as a downloadable expansion pack. It contains all files needed for that expansion and arrives separately from the base game.
Key Takeaway

Use bundles to reduce install size and enable content updates, but plan load and unload logic to manage memory.
