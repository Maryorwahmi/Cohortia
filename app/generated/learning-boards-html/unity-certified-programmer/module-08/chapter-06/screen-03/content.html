Practical lab outcomes
A checklist for the hands-on Addressables walkthrough.
Install & Initialize
Install Addressables in the Package Manager and create Addressables Settings so groups are available.
Mark Assets
Make prefab, texture, and audio Addressable. Rename addresses for clarity.
Build & Test
Build groups, run the scene, load assets, and verify instantiation and texture/audio application.
Release & Profile
Call Release and ReleaseInstance and observe memory drop in the Profiler to confirm cleanup.
Catalog & Remote Update
Inspect the generated catalog and understand how it maps addresses to bundle locations for remote updates.
Deliverables
A working AddressablesLoader, a built Addressables output, and a Profiler trace showing proper release behavior.
