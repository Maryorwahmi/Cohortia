Module 8 › Chapter 8.6 › Addressables architecture
Components
Addresses, Groups, Bundles, and Catalog are the primary parts to understand.
Address / AssetReference
A stable name you use to request an asset at runtime.
Addressables Group
Organizes assets for packing, compression, and remote settings.
Asset Bundles
Generated archives for each platform containing the grouped assets.
Catalog
A lookup table that maps addresses to the bundle or local path the runtime should load.
Runtime resolution
At runtime, Addressables consults the catalog to resolve an address to its physical bundle or file. This allows your code to remain unchanged when you move assets between bundles or hosts.
Misconception
Addressables replaces platform configuration. It simplifies resolution but you still set platform-specific build settings in groups for correct compression and compatibility.
Key Takeaway

The catalog is the indirection that decouples code from storage location, enabling remote updates and safer refactoring.
