Key Concepts
Three compact cards to recall the most important ideas.
Asset Bundle
An archive of platform-specific assets prepared for runtime delivery.
Addressables
A name-based system with automatic dependency handling and a runtime catalog.
Release APIs
Addressables.Release and ReleaseInstance must be called to free loaded asset memory.
Summary

Use bundles to deliver content, Addressables to resolve it by address and manage dependencies, and explicit release calls to keep memory under control.
