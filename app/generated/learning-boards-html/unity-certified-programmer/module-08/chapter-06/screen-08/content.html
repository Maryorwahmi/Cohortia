Module 8 › Chapter 8.6 › Marking & Grouping
Authoring best practices
Consistent addresses and group strategies reduce runtime errors and simplify deployment.
Naming addresses
Use readable tokens like 'Player/PlayerCube' or 'UI/Backgrounds/MainMenu' rather than long paths.
Group by deployment
Separate groups for local core content and remote downloadable content for clearer build settings.
Set build paths
Configure remote build and load paths for groups you will host externally.
Avoid collisions
Ensure addresses are unique across groups to prevent catalog lookup ambiguity.
Concrete Scenario
Create 'LocalCore' for essential UI, 'RemoteDLC' for optional skins, and 'AudioStreaming' for background music you host remotely.
Common Pitfall
Using inconsistent address names across team members leads to runtime lookup failures; use a short naming guide for everyone.
