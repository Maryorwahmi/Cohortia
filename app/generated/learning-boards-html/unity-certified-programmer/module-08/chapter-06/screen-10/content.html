Module 8 › Chapter 8.6 › AsyncOperationHandle
Pattern: load, check, use, release
A robust runtime loader always checks handle status and releases handles when finished.
// Load and await
var handle = Addressables.LoadAssetAsync<Texture2D>(address);
await handle.Task;
if (handle.Status == AsyncOperationStatus.Succeeded) {
    var tex = handle.Result;
    // Apply texture to UI or material
}
// Later, release to free memory
Addressables.Release(handle);
Failure handling
If the handle fails, check OperationException for details and provide user feedback such as retry or fallback content.
Key Takeaway

Keep handles alive while using results, inspect status after awaiting, and always release to prevent leaks.
