Module 8 › Chapter 8.6 › Build & Deploy Timeline
Timeline steps
A repeatable sequence for safe content delivery.
1. Author & mark
Create assets and mark Addressable with meaningful addresses.
2. Group & configure
Set local vs remote paths and compression per group.
3. Build & verify
Run Default Build Script and test loads in a staging client.
4. Deploy catalog + bundles
Upload generated files to your host and ensure the catalog is accessible.
5. Monitor & profile
Use the Profiler to confirm assets are released and memory stabilizes after updates.
Pitfall to avoid
Deploying bundles without updating the hosted catalog or verifying the build target will break runtime resolution on clients.
