Quick Reference
Three last-minute reminders before the hands-on lab.
Install
Open Package Manager, install Addressables, and create Addressables Settings.
Mark Assets
Select a prefab, texture, and audio, check Addressable or drag to a Group, and set clear addresses.
Test & Release
Build Addressables, run the scene, store handles, and call Release or ReleaseInstance when done.
Final Tip

Always verify build target and catalog mapping in staging before rolling updates to players.
