Automatic dependency handling
Addressables ensures that when you request an asset, its dependencies are also available.
How it works
Dependency data is included in the build so the runtime can load all required items in the right order.
Versioning via catalog
Replace the catalog on your server and clients will resolve addresses to new bundle locations after updating the catalog.
Concrete example
A material address triggers the texture dependency to load automatically so you only request the material address in code.
Misconception
Uploading new bundle files without updating the hosted catalog means clients keep referencing old bundle locations and won't fetch updates.
