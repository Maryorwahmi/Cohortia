Batching & culling

  1. Enable static batching for non-moving geometry to merge draw calls.
  2. Use GPU instancing for many identical moving objects to lower draw calls efficiently.
  3. Configure occlusion culling to skip rendering hidden objects behind occluders.
Concrete example
A forest scene with thousands of trees uses GPU instancing to render many trees with a single draw call per LOD, while static rocks are statically batched to minimize calls.
Misconception
Thinking batching solves expensive shader cost; batching lowers draw call overhead but doesn't reduce per-pixel shader cost.
Key Takeaway

Batching reduces CPU overhead; instancing scales identical objects efficiently; occlusion culling prevents unnecessary rendering.
