Definition

Platform constraints

Limits on CPU, GPU, and memory that shape feasible rendering and runtime behavior.

  • CPU: simulation, AI, and physics cost.
  • GPU: shaders, draw calls, overdraw.
  • Memory: texture size, loaded assets, GC pressure.
Concrete example
A mobile build targets 30 FPS to reduce battery usage and uses compressed 1K textures with ASTC where supported. A desktop build uses higher-res textures and targets 60 FPS with more complex post-processing.
Practical checklist
Memory budget
Estimate texture memory and limit resident assets for lower-memory devices.
Batching & draw calls
Use atlases, static batching, and GPU instancing to reduce CPU-to-GPU overhead.
GC & allocations
Avoid per-frame allocations; use object pooling for frequently created objects.
Shader complexity
Prefer simpler mobile shaders; avoid expensive sampling and branching where possible.
Key Takeaway

Find the single largest bottleneck on your target device and focus first on reducing its cost.
