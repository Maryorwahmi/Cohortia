Workflow

Profile → identify → optimize → validate

Connect profiler
Attach to device via USB or Wi-Fi to capture real metrics.
Capture scenario
Recreate heavy gameplay to measure realistic peaks.
Analyze hotspots
Check CPU, GPU, memory, and GC timelines to find the largest cost.
Target fix
Apply a focused optimization and rebuild to validate impact.
Concrete example
If profiling shows frequent small allocations, implement object pooling for the offending systems and re-profile to compare GC frequency and frame-time stability.
Pitfall
Relying solely on editor profiling results; always confirm on physical hardware to see true performance behavior.
Key Takeaway

Profiling on device reveals the real hotspots; optimize the largest cost first, then measure the result.
