Definition

Garbage Collection impacts

Frequent runtime allocations trigger GC cycles that can pause the main thread, causing frame drops.

  • Pool frequently instantiated objects to avoid allocations.
  • Avoid per-frame string concatenation and temporary collections.
  • Cache component references to avoid repeated GetComponent calls.
Concrete example
A bullet pool that pre-instantiates 50 bullets and reuses them prevents hundreds of allocations during gameplay and reduces GC pressure.
Misconception
Assuming GC spikes only happen with large assets; many small allocations can produce frequent GC activity with visible stutter.
Key Takeaway

Use object pooling and reduce temporary allocations to keep GC cycles predictable and gameplay smooth on mobile.
