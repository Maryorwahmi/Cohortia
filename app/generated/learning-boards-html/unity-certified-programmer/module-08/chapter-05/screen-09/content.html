Architecture pattern

Atlases, LODs, and mesh combines

Group and reduce: atlases cut material changes, LODs reduce GPU work at distance, and static combines reduce draw calls.

Atlas
Combine sprites and UI textures to reduce material swaps.
LOD
Swap meshes at distance to lower vertex and pixel cost.
Combine meshes
Static batching groups static geometry to reduce draw calls.
Concrete example
Create a UI atlas for inventory icons and combine small decorative props into a single static mesh to reduce CPU draw call overhead on mobile.
Misconception
Assuming every object benefits from combining: dynamic objects and frequently animated meshes can lose flexibility if combined incorrectly.
Key Takeaway

Prioritize atlasing for UI and repeated props, add LODs for large meshes, and combine static geometry to lower draw calls.
