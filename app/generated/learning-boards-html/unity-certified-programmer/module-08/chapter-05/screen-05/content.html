Process Flow

Configure and apply build settings

  1. Select target platform in File > Build Settings and click Switch Platform to make platform-specific options available.
  2. Open Player Settings to adjust Graphics APIs, Scripting Backend, Target Architectures, and Resolution options.
  3. Set asset overrides such as texture compression formats per platform and enable batching features.
  4. Rebuild and profile on device to confirm changes actually improved performance.
Example settings
Android: IL2CPP, ARM64, ASTC textures, target 30 FPS. Windows: IL2CPP or Mono, higher quality, target 60 FPS.
Common mistake
Changing Player Settings but not rebuilding or switching platform; many options require a rebuild to take effect.
Key Takeaway

Always switch platform, set platform-specific overrides, then rebuild and profile on real hardware.
