Code example
// Example: platform-specific startup
#if UNITY_ANDROID || UNITY_IOS
    // Mobile: lower quality, target 30 FPS
    QualitySettings.SetQualityLevel(0);
    Application.targetFrameRate = 30;
#elif UNITY_STANDALONE_WIN
    // Desktop: higher quality, 60 FPS
    QualitySettings.SetQualityLevel(2);
    Application.targetFrameRate = 60;
#endif

#if ENABLE_DEBUG_OVERLAY
    // Development-only: debug overlay enabled via scripting define
    ShowDebugOverlay();
#endif
Concrete example
Wrap advertising SDK initialization with #if UNITY_IOS || UNITY_ANDROID to avoid compilation errors on other platforms.
Common mistake
Using runtime platform checks instead of compile-time guards when the API isn't available on the build target will still cause compiler errors.
Key Takeaway

Use preprocessor directives for compile-time control and scripting defines for build-configuration flags like debug overlays.
