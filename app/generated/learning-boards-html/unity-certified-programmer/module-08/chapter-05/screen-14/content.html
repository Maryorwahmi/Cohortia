Priorities

Which optimizations to start with

Draw calls
Atlas, batch, or instance to cut CPU overhead.
GC & allocations
Pool objects and reduce per-frame allocations.
Texture memory
Compress and lower resolution where acceptable.
Quick wins
Enable static batching for static geometry, atlas UI, and implement a bullet or particle pool to reduce allocations.
When not to optimize
Don't spend time on shader micro-optimizations until profiling shows the GPU fragment stage is the bottleneck.
Key Takeaway

Target the biggest measured bottleneck first. Use platform-specific settings to adapt content and code per target.
