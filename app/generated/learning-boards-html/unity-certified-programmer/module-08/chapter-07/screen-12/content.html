Module 8 › Chapter 8.7 › Inventory Activity
Implementation hints
  • Store items in a Dictionary with encapsulation.
  • Return copies for public accessors to avoid external mutation.
  • Ignore invalid names or quantities in AddItem and RemoveItem.
Test list
AddItem adds new items, AddItem increases existing counts, RemoveItem returns false when not enough quantity, negative inputs do nothing.
Edit Mode test tips
// Pseudo-test flow: // [SetUp] create Inventory // [Test] AddItem("Potion", 5) -> Assert GetItemQuantity("Potion") == 5 // [Test] RemoveItem("Potion", 3) -> Assert true and quantity == 2
Key Takeaway
Keep tests deterministic and small so they run fast in the Test Runner.
