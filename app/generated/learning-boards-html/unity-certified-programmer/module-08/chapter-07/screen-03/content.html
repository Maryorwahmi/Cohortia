Module 8 › Chapter 8.7 › Practice Focus
What to build
  • Implement Inventory class with a backing dictionary and safe add/remove semantics.
  • Create Edit Mode tests that validate edge cases: negative quantities, removal to zero, missing keys.
  • Create a Play Mode movement test that verifies position change after movement method calls.
Why it matters

Fast, deterministic tests accelerate development. Regression tests keep fixes from breaking later changes. Playtests catch UX issues automated checks miss.

Hands-on Activity
Build Inventory, add Edit Mode tests, run in Unity Test Runner until green. Capture one bug, write a regression test, and verify the fix.
