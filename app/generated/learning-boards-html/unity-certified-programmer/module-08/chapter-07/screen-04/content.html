Module 8 › Chapter 8.7 › Why QA Matters
Definition & value

QA is the set of practices that verify a product meets quality standards. In games, QA reduces user-facing bugs, preserves reputation, and lowers long-term maintenance cost.

Key benefit
Confidence when refactoring and faster iteration cycles.
Misconception
Automated tests don't replace playtesting; they complement it by ensuring technical correctness.
Concrete example
PlayerStats
Unit tests verify TakeDamage, Heal, and IsDead. This prevents simple bugs like health going negative after refactors.
Playtest scenario
Observe a player struggling with a level. Automated tests may not reveal frustration; structured playtests will, guiding design fixes.
Key Takeaway

Combine unit, integration, and playtesting to cover technical correctness and player experience; tests give you safe change windows.

Try this

Pick one class you change often and add a single unit test that would fail if a key assumption breaks.
