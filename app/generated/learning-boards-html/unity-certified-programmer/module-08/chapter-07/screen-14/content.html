Module 8 › Chapter 8.7 › Key Concepts
Unity Test Runner
Use Window › General › Test Runner to author and run tests in Edit and Play contexts.
Test Types
Unit tests for logic, integration/Play Mode tests for runtime interactions, playtesting for UX.
Regression
Capture bugs with failing tests so fixes are protected by automated checks.
Takeaway
A combined testing and playtesting workflow reduces regressions and improves player satisfaction. Convert important bugs into tests and integrate checks into your pipeline.
