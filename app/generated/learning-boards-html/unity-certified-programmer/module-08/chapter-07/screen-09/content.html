Module 8 › Chapter 8.7 › Testing Types
Unit Tests

Fast and deterministic checks of single methods or classes. Best for pure logic and edge cases.

Example: Verifying PlayerStats.TakeDamage clamps health to zero.
Integration Tests

Validate that systems work together: movement, physics, UI, and combat flows.

Example: Simulate an attack and assert enemy health and damage text display.
Playtesting

Human players reveal UX, balance, and performance concerns that code tests cannot judge.

Example: Players repeatedly miss a jump because camera timing feels off.
When to choose
Unit for logic, integration for interactions, playtesting for experience.
Workflow
Run unit tests frequently, integration tests on PRs, playtests during design checkpoints.
Key Takeaway
Use all three methods to cover technical correctness and player experience.
