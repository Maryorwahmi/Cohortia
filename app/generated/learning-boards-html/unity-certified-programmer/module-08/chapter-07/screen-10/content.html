Bug report essentials
  • Steps to reproduce with precise input and state.
  • Expected vs actual behavior.
  • Environment details: platform, editor version, and scene if relevant.
  • Attach logs or screenshots if available.
Regression workflow
  1. Reproduce and write a failing test when possible.
  2. Implement minimal fix.
  3. Run full test suite and verify green.
  4. Close the bug with the regression test in place.
Tip
Automate running regression tests in CI so fixes remain verified across branches.
Common mistake
Fixing without a regression test leaves the bug likely to return after refactors.
Key Takeaway
Turn bugs into tests whenever possible to prevent future regressions and speed debugging.
