Yield & Assert
Arrange required GameObjects and components in the test, act by invoking methods or simulating input, yield a few frames, then assert the expected outcome such as a position change or an animation state.
Concrete example
PlayerMovesForward
Instantiate a cube with Rigidbody and PlayerMovement, set speed, call Move(forward), yield for a short time, assert Z increased.
Cleanup
Destroy created objects at test end to avoid interfering with other tests.
Misconception
Long waits in tests are acceptable — they make suites slow and fragile across machines.
Pro tip
Yield small frame counts and verify specific state changes to keep Play Mode tests fast on CI.
Key Takeaway
Use Play Mode tests for multi-system interactions, but instantiate and cleanup explicitly so tests are deterministic.
