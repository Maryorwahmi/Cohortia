Module 8 › Chapter 8.7 › Edit vs Play Mode
Contexts
Edit Mode Tests
Fast, run without play; ideal for pure C# classes and deterministic asserts.
Play Mode Tests
Run while the Editor plays; necessary for GameObjects, physics, coroutines, and frame-based checks.
Best practice
Keep Edit Mode broad coverage; reserve Play Mode for interaction tests to keep CI fast.
Concrete scenario
PlayerStats

Test TakeDamage and Heal in Edit Mode because they operate on values and have no GameObject dependencies.

PlayerMovement

Verify forward movement in Play Mode by instantiating a GameObject with a Rigidbody and advancing frames; this checks physics and component interaction.

Common mistake
Placing heavy integration checks in Edit Mode or writing brittle Play Mode tests that rely on long delays.
Pro tip
Mock or separate pure logic so you can test it in Edit Mode and keep Play Mode focused on integration points.
Check
If a test needs a scene, physics, or component updates, use Play Mode; otherwise prefer Edit Mode.
