Quick validation checklist
  • Inspector warnings for null prefabs or missing icons.
  • Range checks for numeric fields to avoid invalid configurations.
  • Mark assets dirty after programmatic changes so they persist.
  • Confirm Editor scripts are inside Editor folders to prevent build inclusion.
  • Simple integration test: assign WeaponData to PlayerWeapon and confirm expected debug output or instantiation.
Outcome: fewer runtime surprises and faster designer iteration.
Tip: small tests that simulate designer workflows catch integration issues early.
