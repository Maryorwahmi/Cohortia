Checklist for safe editor code
  • Place scripts in an Editor folder to keep them out of builds.
  • Use SerializedObject and SerializedProperty for undo and prefab support.
  • Call EditorUtility.SetDirty after programmatic changes to assets.
  • Keep long-running tasks out of OnGUI; use update callbacks when needed.
  • Split complex UI into Editor Windows for clarity and reuse.
Pro-tip: small validation reduces designer mistakes early.
Common error: forgetting Editor folder placement causes build-time issues.
