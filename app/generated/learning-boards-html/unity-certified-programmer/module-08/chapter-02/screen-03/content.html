Skills and Outcomes

Apply what you learn in a short lab and demos
Practical
Author Data Assets
Define fields and enums, use CreateAssetMenu, and produce designer-editable assets for game content.
Create Runtime Consumers
Reference assets from MonoBehaviours to drive behavior like firing or spawning thanks to centralized data.
Build Custom Inspectors
Use Editor classes and EditorGUILayout to surface buttons and validation for designers.
Pack Editor Code Properly
Place scripts inside an Editor folder to keep editor-only code out of builds and CI pipelines.
