Module 08 › Chapter 8.2 › Editor Scripting
Key Rules
  • Place editor code in an Editor folder to exclude it from builds.
  • Custom inspectors inherit from Editor and use [CustomEditor(typeof(...))].
  • EditorWindows inherit from EditorWindow and use [MenuItem] to add menu entries.
Benefit: tailored UIs reduce data entry errors.
Warning: mixing runtime APIs in editor scripts can cause errors during build.
Small Example
// Custom inspector signature
[CustomEditor(typeof(ItemData))]
public class ItemDataEditor : Editor
{
    public override void OnInspectorGUI()
    {
        // Use EditorGUILayout to draw fields and buttons
    }
}
Editor scripting gives you access to property drawers, serialized object handling, and handy UI primitives to validate and manipulate assets safely within the Editor context.
