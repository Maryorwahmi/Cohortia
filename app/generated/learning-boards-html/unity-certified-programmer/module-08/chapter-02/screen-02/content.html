Learning Objectives

Learn → Understand → Apply → Master
Bloom: four levels
01
Design ScriptableObject assets
Create reusable data assets for items, weapons, quests, and settings so designers can author content without code.
VERIFIED COMPETENCY MILESTONE
02
Extend the Inspector
Build custom editors to validate assets, add buttons, reorder fields, and surface warnings for designers during iteration.
VERIFIED COMPETENCY MILESTONE
03
Create Editor Windows
Design standalone windows for complex tools like dialogue editors or level builders to automate multi-step workflows.
VERIFIED COMPETENCY MILESTONE
04
Apply Editor scripting best practices
Understand lifecycle, where to place scripts, and how to avoid leaking editor-only code into builds while building reusable utilities.
VERIFIED COMPETENCY MILESTONE
