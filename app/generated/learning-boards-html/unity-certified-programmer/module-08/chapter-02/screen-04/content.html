Module 08 › Chapter 8.2 › What is a ScriptableObject?
Definition

ScriptableObject as a data asset

A persistent, shareable asset for configuration and content templates. Not tied to a scene object.

Best fit: item definitions, weapon templates, quest data.
Misuse to avoid: storing temporary runtime state.
Benefit: single source of truth reduces duplicated memory.
Key Takeaway

Treat ScriptableObjects as templates and configuration that multiple runtime objects can reference.

Example
// WeaponData: a ScriptableObject that stores weapon configuration
[CreateAssetMenu(fileName = "NewWeaponData", menuName = "Game Data/Weapon Data")]
public class WeaponData : ScriptableObject
{
    public string weaponName = "Default Weapon";
    public float damage = 10f;
    public float fireRate = 0.5f;
    public float range = 100f;
    public GameObject projectilePrefab;
    public Sprite icon;
}
Why this helps
  • Designers create many WeaponData assets without editing code.
  • MonoBehaviours reference the asset for behavior values at runtime.
  • Avoids copying the same variables onto many GameObjects.
