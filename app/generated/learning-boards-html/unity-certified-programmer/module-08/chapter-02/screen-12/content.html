Module 08 › Chapter 8.2 › ItemData Lab
Step-by-step
  1. Create ItemData : ScriptableObject with CreateAssetMenu.
  2. Add fields: itemName, description with TextArea, icon, value, itemType enum.
  3. Create an Editor folder and an ItemDataEditor class inheriting from Editor.
  4. Use EditorGUILayout to draw fields and add a simulate button that calls UseItem().
  5. Mark the asset dirty when GUI.changed so edits persist.
Starter code
 // ItemData (Assets)
[CreateAssetMenu(fileName = "NewItemData", menuName = "Game Data/Item Data")]
public class ItemData : ScriptableObject
{
    public string itemName = "New Item";
    [TextArea(3,5)] public string description = "A generic item.";
    public Sprite icon;
    public int value = 1;
    public ItemType itemType = ItemType.Consumable;

    public enum ItemType { Consumable, Equipment, QuestItem }
    public void UseItem() { Debug.Log($"Using {itemName}!"); }
}
Test
Create the asset in Project, assign an icon, change values, and click the simulate button to confirm the debug output. Observe color or layout changes for different item types in your custom inspector.
