Window Sketch
Key pieces: a MenuItem method to open the window, persistent window state across focus changes, and an OnGUI method that draws the UI using EditorGUILayout. Use EditorWindow for tools that manage many assets or require custom layouts and interactions.
Use case: a Dialogue Editor or Level Builder that places prefabs and serializes results.
Minimal pattern
public class MyToolWindow : EditorWindow
{
    [MenuItem("Window/My Tool")]
    public static void ShowWindow() => GetWindow("My Tool");

    void OnGUI()
    {
        // Draw GUI with EditorGUILayout
    }
}
Design windows for repeatable tasks. Extract complex interactions into helper classes and keep OnGUI focused on drawing and responding to user input.
