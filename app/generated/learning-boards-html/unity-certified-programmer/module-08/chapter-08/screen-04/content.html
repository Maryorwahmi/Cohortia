Definition

Player Settings Explained

Player Settings control identity (company and product), versioning, icons, bundle id, signing, and platform capabilities required before a store submission.

Company & Product Name
Used by stores and device UIs to label your app.
Bundle Identifier
Unique app id (example format: com.yourcompany.yourgametitle). Mismatches block updates.
Signing Keys & Capabilities
Android signing keys and iOS capabilities determine installation and permission behavior.
Concrete Example & Checklist
Example: Mobile Identity
Set Company: Cohortia, Product: MyAwesomeGame, Bundle ID: com.cohortia.myawesomegame, Version: 1.0.0, ensure icons sized for target store.
Common Mistake
Leaving Development Build active or incorrect bundle id prevents proper store updates or leads to larger builds with debug symbols.
Pro Tip
Use a versioning convention and update the version number with each release to track patches in the wild.
Key Takeaway

Player Settings are the single configuration surface that prevents many common submission failures. Verify them early and in CI if possible.
