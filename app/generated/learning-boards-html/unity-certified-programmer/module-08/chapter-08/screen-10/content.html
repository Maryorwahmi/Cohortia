Module 8 › Chapter 8.8 › Certification & QA
Process Flow
Pre-submission QA steps
Smoke Tests

Core gameplay, menus, save/load, and startup must work without crashes.

Automate where possible
Performance Sampling

Measure memory, frame time, and loading on target devices under load.

Collect traces for reviewer questions
Platform Checks

Permissions, entitlements, controller mapping, and certification rules must be followed.

Document compliance evidence
Submission Prep
  • Reproduce steps for known bugs.
  • Capture device logs and screenshots for each test.
  • Confirm minimum required OS and APIs.
Misconception

Passing in the editor is not proof of certification readiness. Reviewers run the built package on real hardware with store policies in mind.

Key Takeaway

Build a repeatable QA checklist mapped to store guidelines to reduce rejections and speed approvals.
