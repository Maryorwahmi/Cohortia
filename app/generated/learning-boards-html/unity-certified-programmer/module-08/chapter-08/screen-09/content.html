Process
How signing fits into your pipeline
  1. Generate platform release key (keystore, provisioning, vendor cert).
  2. Store in secure vault or CI secrets; never commit to repo.
  3. Use release key when producing a Release Build; use dev keys only for testing.
  4. Keep key rotation and backup plans documented for updates.
Common Pitfall

Treating a debug key as final. If you lose the release key you cannot update the store entry. Backups and secure storage are essential.

Example Checklist
  • Android keystore + alias + password recorded securely.
  • iOS provisioning profile matched to bundle identifier.
  • Vendor certs and test accounts for console submission.
