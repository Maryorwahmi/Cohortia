Recognize coroutine limits

Explain why coroutines do not return values directly and why try-catch across yields is awkward. This matters because hidden exceptions and missing cancellations cause leaks.

Implement async with UniTask

Write async UniTask methods, await UniTask.Delay and AsyncOperation.ToUniTask, and return values safely for downstream logic.

03
Manage concurrency and race conditions

Use UniTask.WhenAll and WhenAny, and reason about ordering and shared state to avoid races that corrupt game state.

Verified Competency Milestone
04
Handle errors and cancellations

Integrate CancellationToken and try-catch-finally to stop work safely and free resources when objects are destroyed.
