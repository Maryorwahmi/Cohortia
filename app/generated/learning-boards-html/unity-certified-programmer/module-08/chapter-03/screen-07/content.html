Scene loading flow

Delay, create progress reporter, await SceneManager.LoadSceneAsync().ToUniTask(progress, token), handle cancels and errors.

progressText.text = "Loading..."; var progress = Progress.Create<float>(p => progressText.text = $"Loading Game Scene: {p:P0}"); await SceneManager.LoadSceneAsync("GameScene").ToUniTask(progress, cancellationToken);
Null guard
Check progressText is assigned and log an error if not. This avoids runtime exceptions during load.
Cancellation point
Call ThrowIfCancellationRequested after delays and before heavy work to abort quickly.
Check your understanding
Why prefer ToUniTask over a coroutine for scene loading? Answer: cleaner progress reporting, direct awaits, and structured try-catch with cancellation support.
