Async lifecycle pattern
Start → run async sequence → handle errors → finally cleanup on destroy.

Key steps: create a CancellationTokenSource in Start or Awake, pass its Token into every awaited call, check cancellation with ThrowIfCancellationRequested, and cancel in OnDestroy followed by Dispose. Use try-catch-finally in the async method so cleanup code runs even on error or cancel.

Misconception
Calling Cancel without Dispose leaves resources; forgetting to pass the token prevents nested tasks from cancelling.
Code walkthrough (excerpt)
_cancellationTokenSource = new CancellationTokenSource();
StartGameSequenceAsync(_cancellationTokenSource.Token).Forget();
...
async UniTask StartGameSequenceAsync(CancellationToken cancellationToken)
{
  try { await LoadAssetsAsync(cancellationToken); }
  catch (OperationCanceledException) { /* handle */ }
  finally { /* cleanup */ }
}
