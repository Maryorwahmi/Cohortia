Explicit main-thread switching

After background computation, call UniTask.SwitchToMainThread before touching any Unity API objects to avoid runtime errors.

Pattern
await UniTask.RunOnThreadPool(() => HeavyComputation()); await UniTask.SwitchToMainThread(); UpdateUI();
Pitfall
Assuming await resumes on the main thread can cause crashes. Be explicit and test cross-thread flows on device.
