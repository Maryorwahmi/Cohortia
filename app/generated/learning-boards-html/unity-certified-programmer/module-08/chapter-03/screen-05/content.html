Module 8 › Chapter 8.3 › UniTask Basics
What UniTask gives you

Awaitable UniTask structs, low-allocation patterns, ToUniTask conversions for AsyncOperation, and a clear integration with Unity's main thread.

Return values
UniTask can return results directly, removing the need for callback state.
Error handling
try-catch-finally works across awaits, so cleanup code is reliable.
Cancellation support
Pass CancellationToken to UniTask methods to stop work cleanly when necessary.
Concrete code pattern
await UniTask.Delay(TimeSpan.FromSeconds(1));
await SceneManager.LoadSceneAsync("GameScene").ToUniTask(progress, cancellationToken);
Use Progress to update UI and pass a CancellationToken to stop loading if needed.
