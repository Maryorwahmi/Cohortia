Module 8 › Chapter 8.3 › Key Concepts
Prefer UniTask
Use async/await for readability, return values, and better error handling than complex coroutines.
Cancel cleanly
Create CancellationTokenSource, pass tokens through awaits, cancel and dispose in OnDestroy.
Compose & return
Use WhenAll/WhenAny and return UniTask<T> for clearer composition and results handling.
Final takeaway

Adopt UniTask patterns to write asynchronous Unity code that is readable, testable, and safe for the main thread.
