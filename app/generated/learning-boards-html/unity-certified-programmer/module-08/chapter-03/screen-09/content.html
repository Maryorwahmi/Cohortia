try-catch-finally with awaits

Wrap awaited calls in try blocks, handle OperationCanceledException separately, and tidy up in finally blocks to ensure predictable resource release.

Practical rule
Return UniTask or UniTask from async methods. Avoid async void except for event handlers, because async void swallows exceptions from callers' perspective.
Concrete example
Try loading assets and a scene inside try. Catch OperationCanceledException to update UI to "Cancelled". In finally call Dispose on token sources and clear temporary state.
