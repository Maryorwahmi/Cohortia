Practical Skills Checklist
Use this checklist when refactoring coroutine flows.
  • Refactor a wait-load-activate coroutine to a single async UniTask method that returns a status.
  • Integrate CancellationTokenSource in Awake or Start and cancel in OnDestroy.
  • Report progress with Progress during scene load and update UI safely on the main thread.
  • Use WhenAll to run independent tasks in parallel and WhenAny when the first completion matters.
Learning mnemonic
Think: Convert, Compose, Cancel, Check. This order guides refactor work and test cases.
Verified Competency Milestone

Deliver a cancelable scene loader that updates UI progress and handles errors.
