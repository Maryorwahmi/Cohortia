Module 8 › Chapter 8.4 › Resolving Merge Conflicts
Strategies
  • Configure UnityYAMLMerge as Git's merge tool when possible.
  • If a conflict appears, avoid manual YAML merges unless you understand GUIDs and references.
  • Prefer restoring one branch's scene and reapplying the other branch's changes inside Unity.
Example resolution flow
  1. Merge feature branch; detect conflict in Assets/Scenes/MyScene.unity.
  2. Choose main's scene as base, open in Unity to confirm.
  3. Recreate or reapply the other branch's additions in the editor and save.
  4. Commit the resolved scene from Unity.
Common mistakes
Editing YAML conflict markers without understanding GUIDs can break references and produce corrupted scenes. Always verify in Unity.
Key Takeaway

Resolve scene conflicts using Unity-aware tools or editor reapplication. Validate the scene in Unity before committing.
