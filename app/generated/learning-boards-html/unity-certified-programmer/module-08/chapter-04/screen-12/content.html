Commit Hygiene
Treat each commit as a single logical step. Use messages that explain why, include brief testing notes, and keep related changes grouped together.
Good
Add jump script + update jump prefab + unit test. Message explains behavior and test steps.
Bad
Commit dozens of unrelated asset imports with a vague message like 'update project'.
Recovery note
If you must remove large files from history, coordinate a history rewrite and inform the team to rebase or reclone.
Key Takeaway

Clear, small commits make review, bisecting, and merges far easier — plan commits around intent, not file count.
