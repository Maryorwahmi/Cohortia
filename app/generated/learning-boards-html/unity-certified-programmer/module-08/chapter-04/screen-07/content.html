Module 8 › Chapter 8.4 › Git LFS for Large Unity Assets
How Git LFS works
Git LFS stores pointers in the Git history and keeps the actual binary content on a remote LFS server; clones fetch only the needed binary versions for the checkout.
Common file patterns to track
git lfs track "*.psd"
git lfs track "*.fbx"
git lfs track "*.png"
git lfs track "*.unity"
Checklist
  • Install Git LFS and run git lfs install.
  • Track patterns with git lfs track and commit .gitattributes.
  • Ensure team members pull LFS objects after cloning.
Common pitfall
Adding LFS after large files were committed doesn't retroactively shrink history. Plan LFS early.
Key Takeaway

Add Git LFS before large files arrive, commit .gitattributes, and coordinate LFS use across the team to avoid bloat.
