Version Control with Git and Unity
Key practices to avoid bloat, enable safe merges, and collaborate on scenes and assets.
This chapter focuses on three technical changes you must make and a workflow to keep your team productive: configure Unity to serialize assets as text, set up a Unity-aware .gitignore, and use Git LFS for large binary assets. It also covers branch workflows and conflict resolution strategies for scene and prefab files. The content is practical and based on common Unity team problems.
