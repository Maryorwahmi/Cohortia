Module 8 › Chapter 8.4 › Editor Settings
Visible Meta Files
When enabled, Unity creates .meta files for assets with GUIDs and import settings. These files are required to maintain references across machines.
Force Text Serialization
Force Text writes scenes and prefabs as YAML. This makes diffs readable and helps Git merge non-overlapping changes.
Verify
Change a GameObject and open the .unity file to confirm YAML content.
Misconception
Force Text improves merges but doesn't remove the need for coordination on complex scene edits.
Quick steps
  1. Open Edit → Project Settings → Editor.
  2. Set Version Control Mode to Visible Meta Files.
  3. Set Asset Serialization to Force Text.
Key Takeaway

These settings are small to change and have outsized impact on mergeability and project integrity across a team.
