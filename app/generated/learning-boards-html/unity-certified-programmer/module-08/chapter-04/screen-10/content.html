Module 8 › Chapter 8.4 › Simulating a Merge Conflict
Activity Steps (Terminal-first)
Init & Settings
git init → add .gitignore → commit. Set Visible Meta Files and Force Text in Unity.
Configure LFS (optional)
git lfs install → git lfs track "*.png" "*.fbx" → commit .gitattributes
Branch A
git checkout -b feature-A → add GameObject at (1,0,0) → commit
Branch B
git checkout main → git checkout -b feature-B → add GameObject at (-1,0,0) → commit
Merge and Resolve
Merge feature-A then feature-B into main. If conflict occurs, open the scene in Unity, choose the correct camera transform, reapply missing objects, save, and commit the resolved scene.
Try this
After resolution, open the scene and confirm Feature A and Feature B GameObjects are present and camera is correct.
