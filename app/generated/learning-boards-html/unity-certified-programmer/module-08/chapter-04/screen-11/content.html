Module 8 › Chapter 8.4 › Common Mistakes vs Best Practices
Common Mistakes
  • Committing Library/ or Temp/ and inflating repo size.
  • Leaving serialization in Binary, preventing meaningful diffs.
  • Adding LFS after large files already exist in history.
Best Practices
  • Create .gitignore and commit it before adding assets.
  • Enable Visible Meta Files and Force Text immediately.
  • Plan Git LFS rules and commit .gitattributes early.
  • Use feature branches and small commits for scene edits.
Key Takeaway

Preventive configuration and communication save time. Fixing tracked binaries later is expensive.
