# Do not ignore .meta files
These entries remove generated files and IDE cruft from the commit history. Always verify with git status before initial commit.
Explanation and checklist
  • Add .gitignore before the initial commit to avoid tracking generated content.
  • Never ignore *.meta — Unity uses them to track GUIDs and references.
  • Exclude platform build outputs such as *.apk and *.exe to keep history lean.
  • Check for accidentally staged large files and remove them before commit.
Common mistake
Committing Library/ causes huge repo size and inconsistent states across developers.
Key Takeaway

Create and commit .gitignore immediately; exclude generated folders and track .meta files to preserve asset links.
