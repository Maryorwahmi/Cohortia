Objective Details
Concrete verification steps and common checks
Verify .gitignore
  • Initialize Git and ensure Library/ is excluded.
  • Confirm untracked file list no longer shows Temp/ or Builds/.
Mnemonic: filter icon
Verify Force Text
  • Change a scene object and open the .unity file to see YAML entries.
  • Confirm prefabs serialize as text.
Mnemonic: small text sheet
Verify Git LFS
  • Run git lfs track and commit .gitattributes.
  • Push and inspect that large files are pointers in Git history.
Mnemonic: pointer file icon
