Module 04 › Chapter 4.5 › Key Concepts
Layout Group
Automatically positions and optionally sizes child elements in horizontal, vertical, or grid patterns.
Content Size Fitter
Adjusts a Rect Transform to fit its content using Min or Preferred size settings per axis.
Aspect Ratio Fitter
Enforces a width-to-height ratio so images and slots do not distort across resolutions.
Anchors
Reference points on the parent's rect that determine how a child stretches or offsets.
Pivots
Element's local origin used for scaling and rotation; crucial for predictable animation directions.
Responsive UI
Interfaces that adapt layout and appearance gracefully across screen sizes and aspect ratios.
Summary
Assign a single owner for each axis, minimize nested layout passes, and validate with resize checks to keep UI predictable and performant.
