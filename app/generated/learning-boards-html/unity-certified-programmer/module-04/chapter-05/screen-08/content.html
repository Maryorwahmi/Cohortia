Anchors

Anchors define how a child is positioned relative to its parent rect. Use stretch anchors for backgrounds and top/bottom presets for headers or footers.

Stretch example
Background Image uses stretch-stretch anchors so it always fills the parent canvas or panel.
Header example
Header uses stretch-top anchors, fixed height, and stretches across the width regardless of aspect ratio.
Pivots

Pivots define the local origin for running transforms. Set a pivot to the right for bars that should shrink from right to left or to the left for the opposite behavior.

Health bar example
Set pivot X to 1 (right edge) so scaling the width appears to empty the bar toward the left rather than shifting its origin.
Tooltip example
A tooltip that grows downward uses a top-left pivot so the top-left corner remains fixed as the box expands.
Key Takeaway

Set anchors to control stretch and offsets; set pivots to control animation and scaling origins. Both must be checked when responsive behavior breaks.
