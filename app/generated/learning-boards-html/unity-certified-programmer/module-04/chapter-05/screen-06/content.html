Module 04 › Chapter 4.5 › Content Size Fitter
How it works

Content Size Fitter measures a content component (like TextMeshProUGUI) and sets the Rect Transform size to match either the minimum or preferred content size depending on your settings.

Fit Modes
  • Unconstrained — no automatic sizing
  • Min Size — ensures at least content size
  • Preferred Size — match content preferred size
Example
A description text set to Vertical Fit: Preferred Size expands the text box vertically to contain long paragraphs, avoiding clipping without manual height adjustments.
Warnings & tips
Conflict example
A Content Size Fitter on a child inside a Horizontal Layout Group may fight with the group's control child width setting. Resolve by using a Layout Element or disabling control width on the group.
Parent space
Ensure parent Rect Transform can expand. Otherwise the child may overflow outside visible bounds.
Performance
Limit cascading fitters and nested recalculations to avoid costly layout passes each frame.
Key Takeaway

Use Content Size Fitter where content length varies, and coordinate with parent layout rules to avoid conflicts and overflow.
