Learning Objectives

Targeted competencies for building adaptive UI in Unity.

Bloom: Learn → Understand → Apply → Master
01
Use Layout Groups

Arrange UI elements automatically with Horizontal, Vertical, or Grid Layout Group to reduce manual positioning and keep alignment consistent.

Mnemonic: Row/Column/Grid tiles
VERIFY COMPETENCY MILESTONE
02
Content Size Fitter

Make UI elements expand to fit text or images, preventing clipping and ensuring labels are readable when content changes at runtime.

Mnemonic: Grow-to-fit
VERIFY COMPETENCY MILESTONE
03
Aspect Ratio Fitter

Keep images and video elements at fixed ratios so they don’t stretch or squash across different viewports.

Mnemonic: Lock width-to-height
VERIFY COMPETENCY MILESTONE
04
Anchors & Pivots

Control how elements scale and where they originate when resized so animations and fill behaviors behave as intended.

Mnemonic: Reference point + origin
