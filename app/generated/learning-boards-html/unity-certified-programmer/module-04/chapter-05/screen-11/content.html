Module 04 › Chapter 4.5 › Live Coding Outline
Editor Steps (annotated)
Step 1
Create InventoryPanel; set anchors to middle-center and choose an initial width/height to work with.
Step 2
Add CategoriesContainer with Vertical Layout Group: padding 10, spacing 5, Child Force Expand Width = true.
Step 3
Add ItemGridContainer with Grid Layout Group: Cell Size 100x100, Spacing 5, Constraint = Fixed Column Count (4).
Step 4
Create ItemSlot with Image + Aspect Ratio Fitter (WidthControlsHeight, ratio 1). Duplicate to fill the grid.
Step 5
Create ItemDescription text and add Content Size Fitter (Vertical Fit: Preferred Size). Validate by pasting long text.
Runtime checks
  • Resize Game view to confirm layout adapts.
  • Paste long description to verify growth without clipping.
  • Toggle grid cell size and confirm slots remain square.
Performance advice
When instantiating many children, disable layout rebuilds, add children, then re-enable and force a rebuild to avoid layout thrash.
