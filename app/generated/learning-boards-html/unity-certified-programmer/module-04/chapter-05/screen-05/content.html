Module 04 › Chapter 4.5 › Horizontal & Vertical Groups
Step-by-step
  1. Add parent GameObject and the Layout Group component that matches the layout need.
  2. Adjust padding and spacing to set the visual rhythm and avoid crowding.
  3. Decide on Child Force Expand or per-child Layout Elements for size control.
  4. Drop children into the parent and avoid manual repositioning; use Layout Element to change a child's width or height when necessary.
  5. Validate by resizing the Game view and looking for clipping or overlap.
Example
A five-button ability bar uses a Horizontal Layout Group with spacing 8. Make a central button wider by adding a Layout Element and increasing preferred width.
Visual checks
Child Force Expand: ON
Children share available space evenly. Use when you want uniform elements.
Child Force Expand: OFF + Layout Element
Give selected children preferred sizes for precise control while others remain flexible.
Common Mistake
Manually setting child positions then using a Layout Group — the group will override your manual placement.
Key Takeaway

Decide whether to give all children equal space or specialized sizes, then configure the group accordingly.
