Module 04 › Chapter 4.5 › Inventory Workflow
Step-by-step Build
  1. Create InventoryPanel parent and set anchors to middle-center.
  2. Add CategoriesContainer on the left; attach Vertical Layout Group with padding and spacing, enable Child Force Expand Width.
  3. Add ItemGridContainer on the right; attach Grid Layout Group with fixed column count and chosen cell size.
  4. Create ItemSlot with Image + Aspect Ratio Fitter (WidthControlsHeight, ratio 1) and duplicate into grid cells.
  5. Add ItemDescription text with Content Size Fitter (Vertical Fit: Preferred Size) so the background grows with text.
Validation Checklist
  • Resize Game view and confirm layout reflows.
  • Paste long description and confirm expansion without clipping.
  • Ensure item slots remain square when cell size changes.
Common fixes
Fix: Content Size Fitter conflict
If a child fitter conflicts with grid sizing, use a Layout Element or move the content into an unconstrained area.
Fix: Pixel offsets
Replace hard-coded offsets with anchor presets and relative offsets so the panel adapts to different aspect ratios.
Key Takeaway

Combine layout groups and fitters with clear ownership per axis, then validate by resizing and adding dynamic content.
