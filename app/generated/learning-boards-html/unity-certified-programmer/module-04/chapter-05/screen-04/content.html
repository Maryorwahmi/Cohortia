Module 04 › Chapter 4.5 › Layout Groups
Definition

Layout Groups are Unity components that automatically arrange and optionally control size of their child Rect Transforms, reducing manual layout work across varying screen sizes.

Horizontal Layout Group
Best for toolbars and rows. Children are placed left-to-right and spacing/padding controls gaps.
Vertical Layout Group
Best for lists and menus. Children stack top-to-bottom and can force expand or preserve sizes.
Grid Layout Group
Arranges children into cells with configurable cell size, spacing, and constraints for columns or rows.
Common mistake
Manually moving children inside a Layout Group will be overridden. Use Layout Element to influence a child's size.
Pro tip
Adjust padding and spacing on the Layout Group or add Layout Elements to children for min/preferred sizes.
