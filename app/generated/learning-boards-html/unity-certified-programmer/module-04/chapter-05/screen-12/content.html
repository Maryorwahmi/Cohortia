Diagnosis Steps
  1. Find the axis owner: which component controls width/height?
  2. Inspect parent anchors and pivot to ensure they allow the intended movement or stretch.
  3. Look for Layout Elements that set min or preferred sizes on children.
  4. Toggle Layout Group control flags to test which configuration yields expected behavior.
Assessment example 1
3x3 equipment grid: use Grid Layout Group (Fixed Column Count 3) and Aspect Ratio Fitter on each slot set to 1 with WidthControlsHeight.
Assessment example 2
Expandable quest text: add Content Size Fitter to the TextMeshPro object and set Vertical Fit to Preferred Size so the background grows with content.
Key Takeaway

Use the stepwise routine to reduce layout bugs: find the owner, inspect parent constraints, test controls, and verify by resizing.
