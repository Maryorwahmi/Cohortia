Module 04 › Chapter 4.5 › Conflicts & Performance
Common Conflicts
  • Content Size Fitter on a child inside a Layout Group trying to control the same axis.
  • Nested Layout Groups causing repeated layout calculations and lag.
  • Fixed pixel sizes that prevent elements from reflowing across aspect ratios.
Resolution pattern
Decide which component owns each axis, simplify group nesting, use Layout Element to expose child sizing preferences, and validate by resizing the Game view.
Performance tips
Minimize nested groups
Flatten the structure where possible. Group related items under a single Layout Group instead of multiple levels.
Batch updates
When adding many children at runtime, disable layout rebuilds, add children, then re-enable to avoid repeated recalculations.
Validation
Use the profiler and test with many children to detect layout costs early.
Common Mistake

Applying both the Layout Group and a Content Size Fitter to the same axis without a clear owner causes unpredictable sizing or layout thrashing.
