Module 04 › Chapter 4.5 › Aspect Ratio Fitter
What it controls

Aspect Ratio Fitter enforces a numerical width-to-height ratio and offers different modes for how the child relates to the parent or its own width/height.

Modes
  • FitInParent — scale to fit inside parent
  • EnvelopeParent — cover parent, may overflow
  • WidthControlsHeight — compute height from width
  • HeightControlsWidth — compute width from height
Example
Item slot: set WidthControlsHeight with Aspect Ratio 1 so width determines height and each slot stays square when the grid cell size changes.
Integration tips
With Grid Layout Group
Set cell size to a target width; use WidthControlsHeight so height follows and slots remain proportional to the cell width.
Common Mistake
Assuming the fitter overrides parent sizing—if the parent cell size is constrained, adjust the parent or use a different mode.
Validation
Resize the Game view and ensure images or slots do not distort or clip; adjust mode if necessary.
Key Takeaway

Use Aspect Ratio Fitter to guarantee assets remain undistorted, and choose the mode that matches parent constraints.
