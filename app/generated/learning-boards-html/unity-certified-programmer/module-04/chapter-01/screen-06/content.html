Core idea
Actions and Action Maps
Define abstract actions, then bind physical controls. Group actions into maps to manage contexts like Gameplay or UI.
Example
Move as Vector2 bound to WASD, arrows, and left stick. Jump as Button bound to Space and gamepad A.
Why it matters
Your gameplay code subscribes to actions, so input wiring changes without touching gameplay logic. This simplifies remapping and multi-device support.
Key Takeaway

Abstracting input as actions centralizes control mapping and reduces conditional branching in gameplay code.
