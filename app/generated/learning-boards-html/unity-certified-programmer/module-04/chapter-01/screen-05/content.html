Module 4 › Chapter 4.1 › Legacy Shortcomings
Comparison: Legacy limits
  • Remapping requires manual edits or custom runtime systems.
  • Context switching needs conditional polling logic in Update.
  • Supporting many device types needs bespoke bridging code.
Common mistake
Attempting to layer many conditional checks on top of Input.GetAxis instead of centralizing input logic.
Concrete scenario
You want WASD, arrow keys, left stick, and a touchscreen gesture to control movement. With the legacy manager, you must configure multiple axes or write per-device logic, increasing maintenance cost.
Key Takeaway

If you anticipate remapping, multiple device types, or different input contexts, the legacy manager will slow development and increase bugs.
