Input Manager (Legacy)
Configured axes and polling with Input.GetAxis and Input.GetButton.
Input System Package
Action-based, event-driven, and device-agnostic input architecture.
Input Action Asset
The central asset that defines action maps, actions, bindings, processors, and interactions.
Summary takeaway
These terms form the vocabulary you’ll use when designing and migrating input systems: know them and use them to plan work.
