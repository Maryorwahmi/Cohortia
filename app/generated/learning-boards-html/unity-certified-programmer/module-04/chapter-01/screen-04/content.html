Module 4 › Chapter 4.1 › Legacy Input Manager
Definition
Input.GetAxis and configured axes
Axes and buttons are defined in Project Settings. Scripts poll values every frame using Input calls.
Example
A single axis named Horizontal can combine A/D keys, arrow keys, and joystick X, returning a float used for character movement.
Common misconception
People assume the legacy manager auto-handles all controllers. In fact it is limited and requires manual axis setup for each mapping.
Key Takeaway

Good for simple projects, but becomes brittle when you need remapping, multiple control schemes, or extensive device support.

Scenario
