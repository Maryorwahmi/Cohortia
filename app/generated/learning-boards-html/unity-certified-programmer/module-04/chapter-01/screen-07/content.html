Module 4 › Chapter 4.1 › Install & Create Asset
Step-by-step
  1. Open Window → Package Manager and select Unity Registry, then install Input System.
  2. Accept editor restart when prompted to enable the new backend.
  3. In Project window: Create → Input Actions and name it PlayerControls.
  4. Open asset, add Action Map named Gameplay, add Move (Vector2) and Jump (Button).
  5. Add bindings: Gamepad left stick and 2D Vector composite for WASD; Space and gamepad A for Jump.
  6. Click Save Asset in the Input Actions editor.
Example bindings
Move: Path <Gamepad>/leftStick and 2D Vector composite WASD. Jump: Path <Keyboard>/space and <Gamepad>/aButton.
Key Takeaway

Follow the install and author workflow once; the Input Action Asset is your single source of truth for controls.
