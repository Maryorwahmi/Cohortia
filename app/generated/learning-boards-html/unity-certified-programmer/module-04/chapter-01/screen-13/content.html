Module 4 › Chapter 4.1 › Hands-on Activity
Activity steps
  1. Install Input System and restart editor if prompted.
  2. Create PlayerControls Input Action Asset and add Gameplay map.
  3. Add Move (Vector2) and Jump (Button) actions.
  4. Add Gamepad left stick and 2D Vector WASD bindings for Move. Add Space and A button for Jump.
  5. Save Asset. In a script subscribe to performed events and test both keyboard and gamepad in a scene.
Check your work
  • Does Move deliver Vector2 from both WASD and left stick?
  • Does Jump fire from Space and gamepad A?
  • Are processors or interactions applied as needed?
Key Takeaway
Test early and often. Verifying behavior with both devices prevents subtle regressions later.
