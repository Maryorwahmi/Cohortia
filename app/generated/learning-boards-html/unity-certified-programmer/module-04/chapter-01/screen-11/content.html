Module 4 › Chapter 4.1 › Migration Pitfalls
Common issues
  • Input.GetAxis stops working after enabling the new backend.
  • Using Both active backends long-term causes maintenance confusion.
  • Porting polling logic verbatim misses the advantages of actions and callbacks.
Migration checklist
  1. Install Input System and create PlayerControls asset.
  2. Migrate a single action and update its script to subscribe to events.
  3. Test device support and interactions, then remove legacy calls once stable.
Pro tip
Keep a migration log noting which actions have been moved to the Input System to avoid missed functionality.
