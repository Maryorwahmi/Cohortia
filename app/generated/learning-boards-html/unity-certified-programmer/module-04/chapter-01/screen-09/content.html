Module 4 › Chapter 4.1 › Processors & Interactions
Processors
Modify values: deadzone, normalize, scale. Use them to correct device behavior before gameplay sees the input.
Interactions
Define how an input is interpreted: Press, Hold, Tap, and combinations to match gameplay needs.
Concrete scenario
For a charged jump, use a Hold interaction on Jump and a deadzone processor on left stick to avoid accidental triggers while idle.
Key Takeaway

Use processors and interactions to centralize input tuning and keep gameplay code clean and consistent.
