Control types
Vector2 for directional movement, Button for discrete actions like Jump or Fire.
Composite example
Create a 2D Vector composite named WASD and map Up to W, Down to S, Left to A, Right to D.
Concrete example
Move action: Vector2 produced by either the WASD composite or <Gamepad>/leftStick binding. Jump action: Button produced by <Keyboard>/space and <Gamepad>/aButton.
Key Takeaway

Pick the control type that matches the semantic input. Composites simplify multi-key mappings into a single coherent value.
