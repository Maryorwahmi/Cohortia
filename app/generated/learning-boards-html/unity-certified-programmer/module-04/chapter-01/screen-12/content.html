Action Map pattern
Group actions by context. Enable or disable maps to change input behavior when game state changes.
Example
Gameplay map: Move, Jump. UI map: Navigate, Submit. Toggle maps on menu open/close to switch contexts cleanly.
Practical notes
  • Use maps to avoid ad-hoc checks for whether input should be handled.
  • Switch maps atomically when game state changes for predictable behavior.
Key Takeaway

Action maps make context switches explicit and maintainable. Toggle maps instead of scattering conditional logic across scripts.
