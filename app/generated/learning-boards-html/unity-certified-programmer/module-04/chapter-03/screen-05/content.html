Canvas Render Modes
Choose based on layering, camera effects, and whether UI sits in the world.
Screen Space - Overlay
Always-on HUDs and menus
Renders on top of scene, auto-scales to screen, simple and common for menus.
Misconception: overlay blocks interaction with scene objects—UI only receives input if you set up events.
Screen Space - Camera
Camera-specific UI
Rendered by a chosen camera; useful for multi-camera setups or when camera post-processing should affect UI.
Practical note: assign the Render Camera in the Canvas to control which camera draws the UI.
World Space
In-scene UI objects
UI behaves like a 3D object and can be occluded or moved with GameObjects in the scene.
Misconception: world-space UI does not auto-scale for resolution; you must design for physical size and distance.
Concrete example
Attach a small world-space Canvas to an enemy for a health bar so it moves and can be occluded. Use overlay for your main HUD and camera mode for a picture-in-picture camera with its own UI.
