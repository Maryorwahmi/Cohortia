Rect Transform: anchors, pivots, and offsets
Understand how UI elements maintain placement and scale across screen sizes.
Core pieces
  • Anchors: reference points on the parent rect that determine how the child positions or stretches.
  • Pivot: local origin for rotation and scale, expressed in normalized coordinates.
  • Offsets/Pos: positional values that change meaning when anchors are set to stretch.
Tip: use the anchor presets in the Inspector to quickly apply corner or stretch behavior.
Concrete example
Centered Title
Set anchors to middle-center and pivot to (0.5,0.5). Pos X and Pos Y become offsets from the center, keeping the title centered on different screens.
Full-screen Background
Set anchors to stretch-stretch and set Left/Right/Top/Bottom to zero to fill the parent rect.
Common mistake: changing Pos values with stretch anchors active rather than adjusting padding; understand which properties control what under each anchor mode.
