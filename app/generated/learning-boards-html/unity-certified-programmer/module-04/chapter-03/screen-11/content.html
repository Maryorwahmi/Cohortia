Hierarchy and rendering order
Understand sibling index, Canvas nesting, and common visibility issues.
Sibling order rules
Elements render top-to-bottom in Hierarchy. Move a child above another to bring it forward. Use reorder commands or drag in Hierarchy to change drawing order.
Multiple Canvas effects
Separate canvases allow independent sorting and can improve batching performance when changing only parts of the UI. Use them when you need separate sorting layers or frequent updates limited to a region.
Troubleshoot example
If your button is hidden, check that no full-screen Image is above it in the Hierarchy. Also ensure the Event System exists for click events and that world-space Canvas has an Event Camera assigned for input to work.
