TextMeshPro and Image fundamentals
Ensure TMP resources are imported and use sliced images for scalable panels.
TextMeshPro essentials
  • Import TMP essential resources when prompted.
  • Set font size, alignment, and rich text tags for emphasis.
  • Use middle-center anchors for centered titles that respond to resize.
Image component tips
  • Assign a Sprite to Source Image.
  • Use Sliced type for panels that must scale without distorting corners.
  • Fill type is useful for bars and progress indicators.
Concrete example
Create a TextMeshPro GameTitle with font size 72 and center it. Add an Image named Background set to stretch-stretch; use a sliced sprite so it fills screens without corner distortion.
