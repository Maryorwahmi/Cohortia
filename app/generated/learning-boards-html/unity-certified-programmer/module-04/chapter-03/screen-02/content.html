Learning Objectives
Skills to practice in the lab: choose Canvas mode, use anchors and pivots, create UI elements, and solve hierarchy issues.
01
Choose Canvas Render Mode
Explain when to use overlay, camera, or world space and how that affects layering and input. Verified competency milestone: select the correct mode for a HUD vs. in-world label.
Mnemonic: three stacked cards labeled Overlay, Camera, World.
VERIFIED COMPETENCY MILESTONE
02
Position with Rect Transform
Set anchors, pivots, and offsets so UI adapts across resolutions. Verified milestone: make a title remain centered when resizing the Game view.
Mnemonic: crosshair for center anchor.
VERIFIED COMPETENCY MILESTONE
03
Create Text, Image, Button
Use TextMeshPro for crisp text, Image for sprites, and Button for actions. Verified milestone: build a menu title, background, and Start button.
Mnemonic: three stacked icons.
VERIFIED COMPETENCY MILESTONE
04
Diagnose Hierarchy & Rendering
Understand sibling index and draw order; import TMP resources to avoid render errors. Verified milestone: fix a hidden button by reordering hierarchy.
Mnemonic: stacked layers showing higher layers above lower.
VERIFIED COMPETENCY MILESTONE
Bloom: Learn → Understand → Apply → Master
