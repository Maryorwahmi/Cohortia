Build a responsive main menu
Step-by-step lab: create title, background, and Start button; validate using Game view resize.
Steps
  1. Create Text - TextMeshPro, rename GameTitle, set text and font size, anchors to middle-center.
  2. Right-click Canvas → UI → Image, rename Background, anchors stretch-stretch, zero offsets to fill parent.
  3. Add Button - TextMeshPro, rename StartButton, position under title, edit child Text to "Start Game".
  4. Wire a public StartGame method to the StartButton.OnClick and test in Play mode.
  5. Resize Game view to verify responsiveness and adjust anchors/pivots as needed.
Check: TMP resources imported, Event System present, and no element occludes the button.
Example values
GameTitle font size: 72. StartButton Pos Y: -150. Background anchors: stretch-stretch with zero padding.
Key Takeaway
Testing the Game view size is the fastest way to confirm your anchors and responsiveness.
