Button basics and wiring OnClick
Combine visuals and event binding to create interactive UI.
Create and configure
  • Add Button - TextMeshPro and rename to StartButton.
  • Edit child Text (TMP) to "Start Game" and set anchors to middle-center.
  • Position with Pos Y to sit under title and adjust visual Image color and sprite.
Wire OnClick
Add a public method like StartGame on a MonoBehaviour. In the Button component, add an OnClick entry, drag the GameObject, and select the method from the dropdown. Test in Play mode.
Common issue: non-public methods do not appear in OnClick. Make methods public to expose them.
Concrete check
If a button doesn't receive clicks, confirm no transparent Image covers it, check sibling order, and ensure an Event System exists in the scene for UI input events.
