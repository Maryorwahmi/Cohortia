Pivots, Position and Size explained
Pivot determines the rotation and scaling origin; size fields are contextual to anchors.
Pivot as hinge
Pivot (0.5,0.5) centers rotation. Pivot (0,1) rotates around top-left. Always check pivot before animating transforms.
Analogy: pivot is the hinge of a door, not the whole door itself.
Size and offsets
With point anchors: Pos X/Pos Y are offsets. With stretch anchors: Left/Right/Top/Bottom control padding from edges and size changes with parent.

Switch a background Image to stretch-stretch anchors and set padding to zero to fill its parent. Observe how size fields update automatically.
