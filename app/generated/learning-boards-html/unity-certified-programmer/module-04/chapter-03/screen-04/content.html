Canvas: the UI drawing surface
The required root GameObject for all UGUI elements and the place render mode is set.
Definition & role
  • Manages draw order, scaling, and event routing for child UI.
  • Automatically created when adding your first UI element.
  • Render Mode controls overlay, camera rendering, or world placement.
Key Takeaway
Configure the Canvas render mode to match your use case; it directly affects how UI is drawn and interacted with.
Example scenarios
HUD or Pause Menu
Use Screen Space - Overlay so UI always appears above gameplay.
Camera-specific UI
Use Screen Space - Camera when you want to apply camera effects to UI or target one camera.
In-world UI (health bar)
Use World Space when UI must occupy a position in 3D space and be occluded by objects.
Common mistake: treating Canvas as just a container. It controls rendering and input behavior.
