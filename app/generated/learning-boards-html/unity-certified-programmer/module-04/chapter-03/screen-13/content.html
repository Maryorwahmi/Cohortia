Key Concepts
Three compact reminders to guide your UI work.
Canvas
Root drawing surface; pick Overlay, Camera, or World based on use case.
Rect Transform
Anchors, pivots, and offsets control responsive layout and rotation origin.
UI Elements
Use TextMeshPro for text, Image for sprites, and Button for actions; import TMP essentials.
Final takeaway
Verify Canvas mode, test anchors via Game view resize, import TMP resources, and check sibling order to ensure UI displays and responds as intended.
