Module 4 › Chapter 4.4 › Key Concepts
Event System
GameObject that processes all UI input and dispatches events to components like Button and Slider.
Button.onClick
Event triggered on click; wire to public void methods via Inspector or AddListener.
Slider & Toggle
Slider.onValueChanged passes float; Toggle.onValueChanged passes bool. Match handlers and initialize values from state.
Summary

Keep the EventSystem present, wire events to correctly-typed listeners, initialize UI from game state, and avoid heavy per-keystroke work.
