Module 4 › Chapter 4.4 › Learning Objectives
01
Implement Interactive Elements
Add Buttons, Sliders, Toggles, and TMP Input Fields to your Canvas and configure their basic properties in the Inspector. This gives players controls to change game state.
VERIFIED COMPETENCY MILESTONE
02
Wire Events to C# Methods
Use onClick, onValueChanged, and onEndEdit to call public methods. Learn both inspector wiring and programmatic AddListener usage in Start.
VERIFIED COMPETENCY MILESTONE
03
Understand the EventSystem
Know that an EventSystem GameObject is required to process pointer and navigation events, and what happens when it's missing or misconfigured.
VERIFIED COMPETENCY MILESTONE
04
Initialize and Update UI
Set slider.value and toggle.isOn from game state on Start, and update back when the player changes values to keep UI and game consistent.
VERIFIED COMPETENCY MILESTONE
Bloom's Progression
Learn → Understand → Apply → Master
These objectives take you from identifying UI elements to programmatically wiring and initializing them so they work reliably in a running game.
