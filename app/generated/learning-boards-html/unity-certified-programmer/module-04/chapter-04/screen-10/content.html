Hierarchy Pattern
Public fields and Inspector assignment
Declare public fields for each UI component and assign the corresponding GameObject from the Canvas. This is explicit, designer-friendly, and avoids repeated find calls at runtime.
Lifetime tips
If UI is instantiated later or on a different scene, assign references after creation or use registration methods rather than relying only on Inspector links.
Checklist
  • Assign slider, toggle, and input field in the UIManager Inspector.
  • Null-check in Start before adding listeners.
  • Handle object creation and scene changes explicitly to avoid dangling references.
Common Mistake

Assuming Inspector links remain valid across scene loads — verify manager and UI lifecycles to avoid null references.
