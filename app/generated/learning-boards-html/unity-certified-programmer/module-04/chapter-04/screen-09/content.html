Module 4 › Chapter 4.4 › Input Architecture
Architecture
Input flow overview
Raw Input
Mouse, Touch, Keyboard, Gamepad events emitted by the platform.
EventSystem
Consumes raw input, performs raycasts, manages selection and dispatch.
UI Component
Receives event and triggers listeners like onClick or onValueChanged.
Debug checklist
  • Is there exactly one EventSystem present and enabled?
  • Does the EventSystem use an input module matching your device types?
  • Are UI elements enabled and within raycastable layers?
Example
Clicking a slider thumb triggers the EventSystem raycast which then routes onValueChanged to your listener as the thumb moves.
Key Takeaway

Treat the EventSystem as the mandatory bridge between device input and UI events; verify it first when debugging unresponsive controls.
