Interactive UI Elements & Event Systems
Make UI respond: connect Buttons, Sliders, Toggles and TMP Input Fields to C# listeners and rely on the EventSystem to dispatch input.
In this lesson
Learn wiring, initialization, and common pitfalls with a hands-on options menu example that uses volume, music toggle, and name entry.
Why it matters
Interactive UI maps player intent to game state. Correct event wiring and initialization prevents confusing or broken controls.
Explore Key Topics
Event System
Central dispatcher that processes mouse, keyboard, touch, and gamepad input for UI.
Listeners
Attach methods to onClick and onValueChanged so UI changes affect game logic.
Initialization
Set slider.value and toggle.isOn from game state so the UI reflects current settings.
