Module 4 › Chapter 4.4 › TMP Input Field
Definition
TMP Input Field events
OnValueChanged
Fires each character change; use for lightweight live feedback.
OnEndEdit
Fires when editing finishes; ideal for final capture like player name submission.
OnSelect / OnDeselect
Notify focus changes for guiding UI behavior or keyboard navigation.
Practical settings
Adjust Character Limit, Content Type (Alphanumeric, Integer Number, Password), and Line Type in the Inspector to reduce validation code. Example: use onEndEdit.AddListener(SetPlayerName) to capture final name and log it with Debug.Log.
Performance note
Avoid heavy processing in OnValueChanged because it fires per keystroke. Prefer OnEndEdit for costly operations.
Key Takeaway

Select the TMP event based on whether you need continuous feedback or only the final submitted value.
