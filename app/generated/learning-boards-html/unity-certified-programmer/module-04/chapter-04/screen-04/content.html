Module 4 › Chapter 4.4 › EventSystem
Core Concept
EventSystem defined
A GameObject that processes input, performs UI raycasts, manages selection, and dispatches events to components like Button, Slider, Toggle, and TMP Input Field.
Example
If you delete the EventSystem, Buttons with OnClick entries will not respond during play. Restoring the EventSystem or its Input Module fixes this.
Common misconception
UI elements do not individually detect raw input; they rely on the EventSystem to perform raycasts and route events.
Key Takeaway

Keep one correct EventSystem in the scene; verify the input module if controls stop responding.
