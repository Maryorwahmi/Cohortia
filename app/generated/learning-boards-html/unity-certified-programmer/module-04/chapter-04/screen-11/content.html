Module 4 › Chapter 4.4 › Initialization
Process
Set values from game state
Example initializations: volumeSlider.value = AudioListener.volume; musicToggle.isOn = AudioListener.volume > 0; playerNameInputField.text = savedName.
Order considerations
If your listeners perform actions on change, set values first then add listeners, or temporarily suppress handlers to avoid unintended calls during startup.
Why this matters
Players expect the UI to represent the current settings. Initialization prevents surprises and ensures adjustments reflect meaningful changes.
Key Takeaway

Always set UI control values from a canonical source on Start to keep appearance and behavior consistent.
