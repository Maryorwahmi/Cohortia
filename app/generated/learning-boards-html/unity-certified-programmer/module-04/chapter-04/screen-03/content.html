Module 4 › Chapter 4.4 › Learning Objectives
Lab Deliverable
Create a Canvas with a Volume Slider, Music Toggle, and Player Name TMP Input. Attach a UIManager script, add listeners in Start, and verify with Debug.Log output that events fire and state updates take place.
Success Criteria
  • Slider changes call SetVolume and reflect AudioListener.volume
  • Toggle changes call ToggleMusic and set volume on/off
  • Input field onEndEdit captures the final name string
Common Mistake
Deleting the EventSystem prevents UI from receiving clicks. Recreate it to restore interaction.
Bloom Progress
Apply — wiring and testing in a live scene.
