Module 4 › Chapter 4.4 › Pitfalls
Warning
OnValueChanged cost
OnValueChanged fires every character typed. Do not perform heavy operations here. Use OnEndEdit for final input processing to avoid lag and wasted work.
Debug steps for unresponsive UI
  1. Confirm EventSystem GameObject exists and is enabled.
  2. Check Standalone Input Module settings match your device.
  3. Ensure UI elements are not obstructed and are on raycastable layers.
  4. Verify listener signatures and null-check references in Start.
Concrete example
Instead of making a network call on every character typed, use OnEndEdit to send the completed text or perform a lightweight debounce for live validation.
Key Takeaway

Choose the right event for the work you perform and always verify the EventSystem when input stops working.
