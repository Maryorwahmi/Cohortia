Module 4 › Chapter 4.4 › Button Wiring
Process
Add OnClick via Inspector
  1. Create Button under Canvas and open the Button component.
  2. Drag the GameObject containing the target script into the OnClick object slot.
  3. Select a public void method from the dropdown; optional single parameter types allowed.
  4. Enter any string/int/float/bool parameter if the method accepts it.
  5. Test in Play mode and verify the expected behavior.
Concrete example
Drag GameManager into OnClick and choose LoadLevelOne. The method must be public void LoadLevelOne().
