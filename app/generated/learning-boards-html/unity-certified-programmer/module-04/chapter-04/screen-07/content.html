Module 4 › Chapter 4.4 › Slider vs Toggle
Comparison
Float vs Bool
Slider
onValueChanged passes a float. Use for volume, difficulty, or any ranged value. Set min/max and Whole Numbers if needed.
Toggle
onValueChanged passes a bool. Use for on/off settings like enabling music or inverting axis.
Concrete examples
volumeSlider.onValueChanged.AddListener(SetVolume); // SetVolume(float)
musicToggle.onValueChanged.AddListener(ToggleMusic); // ToggleMusic(bool)
Initialization reminder: set slider.value and toggle.isOn in Start so the UI accurately reflects the game's saved or current state.
Misconception

Handlers must match the event parameter types. If signatures differ, the listener won’t work as expected.
