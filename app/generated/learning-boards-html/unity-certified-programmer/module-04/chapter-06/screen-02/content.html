Module 5 › Chapter 4.6 › Learning Objectives
01
Display Dynamic Data
Keep health, score and ammo visually accurate.

You will bind game values to UI elements and update them when changes happen. For example, when the player takes damage, the health slider and text show the new value. This prevents stale or misleading displays during gameplay.

Verified Competency Milestone
02
Pause & Menus
Pause time and switch input cleanly.

You will create a pause menu that stops time via Time.timeScale, shows a UI panel, and switches the input map so players can navigate menus without moving the character accidentally.

Verified Competency Milestone
03
Efficient UI Updates
Avoid frame-costly work and reduce allocations.

You will adopt event-driven updates and object pooling so UI changes occur only when needed. This lowers CPU and GC pressure, especially for inventories and frequently toggled prompts.

Verified Competency Milestone
04
Visual Feedback
Communicate events with clear cues.

You will create damage flashes, interaction prompts, and quest markers that respond to events. These cues must be timely and unobtrusive so players understand what happened and where to look next.

Verified Competency Milestone
