Module 5 › Chapter 4.6 › Pause Menu Flow
Toggle Pause Sequence
1. Pause Input
Call TogglePause from an Input action when performed.
2. Time.timeScale
Set to 0 to stop time-dependent behaviour, and back to 1 when resuming.
3. Input Map
Switch the PlayerInput action map to UI so menus receive navigation input.
Example
When paused, Resume button calls ResumeGame which sets Time.timeScale to 1 and switches action map back to Gameplay.
Pitfall
Leaving Time.timeScale at zero after a crash or exception; always ensure resume paths run in cleanup logic where possible.
Quick Reference
  • TogglePause → if paused call ResumeGame else PauseGame.
  • PauseGame: Time.timeScale = 0; pausePanel.SetActive(true); playerInput.SwitchCurrentActionMap("UI");
  • ResumeGame: Time.timeScale = 1; pausePanel.SetActive(false); playerInput.SwitchCurrentActionMap("Gameplay");
Pro Tip

Guard ResumeGame with try/finally when doing multiple state changes to ensure Time.timeScale always resets on errors.
