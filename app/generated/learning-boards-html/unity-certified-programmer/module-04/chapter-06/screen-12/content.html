Module 5 › Chapter 4.6 › Game Over Challenge
Implementation Steps
  1. Add OnPlayerDied event in PlayerHealth and invoke it in Die().
  2. Subscribe a UI or GameManager to OnPlayerDied and enable GameOverPanel.
  3. Restart button calls SceneManager.LoadScene(SceneManager.GetActiveScene().name) and resets any paused Time.timeScale to 1.
  4. Disable player controls on death and enable them after restart to avoid input leaks.
Test Cases
  • Verify Game Over shows when health is zero.
  • Press Restart and confirm scene reloads and Time.timeScale is 1.
  • Ensure no lingering subscriptions remain after restart.
Reflection

This challenge combines events, pause semantics, and scene control—core skills for robust UI workflows.
