Module 5 › Chapter 4.6 › Inventory UI
Design

Separate the inventory data and the UI. InventoryManager raises events when items are added or removed. UI listens and reflects changes by taking ItemSlot objects from a pool or returning them when empty.

Pooling
Pre-instantiate a set of ItemSlot prefabs. Reuse by setting their data and activating them.
Layout Groups
Use Horizontal or Grid Layout Group but batch changes to avoid repeated rebuilds.
Example Slot Pool
Pool Behavior
On inventory open, request N slots from pool, fill with item data. On close, return slots to pool and disable them.
Performance Check
Rapid add/remove tests should show fewer spikes with a pool versus repeated Instantiate and Destroy calls.
Key Takeaway

UI pooling reduces GC and frame spikes for inventories and frequently toggled lists.
