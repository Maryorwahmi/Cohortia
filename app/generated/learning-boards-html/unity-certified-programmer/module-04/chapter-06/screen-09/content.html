Module 5 › Chapter 4.6 › Visual Feedback Patterns
Patterns & Examples
Damage Indicator
Flash a red overlay with a quick fade-out or show a directional arrow indicating hit source.
Interaction Prompt
Enable prompt on trigger enter, disable on exit; animate alpha for polish.
Quest Markers
Show icon or arrow to guide players; update position if objective moves.
Implementation Tips
  • Use events to trigger feedback (OnDamage, OnEnterTrigger).
  • Animate alpha or scale rather than toggling heavy elements when possible.
  • Keep overlays short and test stacked feedback scenarios to avoid confusion.
Key Takeaway

Trigger visual feedback from events, animate properties, and ensure cues stay brief and clear.
