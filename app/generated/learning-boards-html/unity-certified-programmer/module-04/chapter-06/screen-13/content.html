Module 5 › Chapter 4.6 › Key Concepts
Dynamic UI Update
Change UI element properties at runtime when game state changes.
Event-driven UI
Use events or delegates so UI updates only when notified by game systems.
Pause Menu
Set Time.timeScale and switch input action maps to enable UI navigation.
Summary
These three concepts—dynamic updates, events, and safe pause flow—work together to create responsive and maintainable in-game UI that improves player experience.
