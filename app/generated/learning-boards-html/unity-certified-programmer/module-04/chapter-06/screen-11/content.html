Module 5 › Chapter 4.6 › Polling vs Events
Polling (Update)
  • Runs every frame regardless of change.
  • Can cause unnecessary CPU and allocations.
  • Simpler to prototype but scales poorly.
Event-driven
  • Updates only when values change.
  • Lower CPU and GC pressure, easier to test.
  • Requires careful subscription and unsubscription.
Migration Checklist
Identify rarely changing values
Add change events to data scripts
Subscribe in Start and unsubscribe in OnDestroy
