Module 4 › Chapter 4.2 › Subscribing to events
Event phases
Understand started, performed, and canceled so your logic runs at the right moment and you can track hold states.
Started
Triggered when the control first changes. Useful for starting animations or charging.
Performed
Fired when the action's interaction completes. Good for discrete triggers like jump.
Canceled
Fired when input ends. Useful to zero movement or stop charging.
Subscription pattern
// Move
playerControls.Gameplay.Move.performed += ctx => currentMovementInput = ctx.ReadValue();
playerControls.Gameplay.Move.canceled += ctx => currentMovementInput = Vector2.zero;
// Jump
playerControls.Gameplay.Jump.performed += OnJump;
Pro tip

Use lambdas for trivial captures and full methods when you need to inspect the CallbackContext or add diagnostics.
