OnJump handler
Use Jump.performed to run jump logic and avoid using per-frame polling for a single press.
void OnJump(InputAction.CallbackContext context) {
 if (!isGrounded) return;
 rb.AddForce(Vector3.up * jumpForce, ForceMode.Impulse);
 Debug.Log("Jump performed!");
}
Grounding & animation
Validate grounded state before impulse and then update animation state after physics to keep visuals consistent.
Common mistake
Applying AddForce without grounding checks results in unintended double jumps.
Scenario
Spacebar or gamepad A triggers Jump.performed and runs the handler once per press.
