Module 4 › Chapter 4.2 › Movement handling
Capture intent
Subscribe to Move.performed and Move.canceled to set currentMovementInput.
// Move callbacks
playerControls.Gameplay.Move.performed += ctx => currentMovementInput = ctx.ReadValue();
playerControls.Gameplay.Move.canceled += ctx => currentMovementInput = Vector2.zero;
Apply in FixedUpdate
Convert to Vector3 and use MovePosition to keep movement in the physics step.
void FixedUpdate() {
 Vector3 movement = new Vector3(currentMovementInput.x, 0, currentMovementInput.y) * moveSpeed * Time.fixedDeltaTime;
 rb.MovePosition(rb.position + movement);
}
Key Takeaway

Separate intent capture from physics application to avoid jitter and inconsistent input timing.
