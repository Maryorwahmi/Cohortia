Module 4 › Chapter 4.2 › Action Map Management
Typical maps
Design separate maps for Gameplay and UI to make responsibility explicit.
Gameplay
Movement, jump, combat actions.
UI
Menu navigation, submit/cancel for UI elements.
Switching example
// Open pause menu
playerControls.Gameplay.Disable();
playerControls.UI.Enable();
// Close pause menu
playerControls.UI.Disable();
playerControls.Gameplay.Enable();
Common mistake

Enabling both maps causes the same input to trigger multiple systems; enable only the map you need.
