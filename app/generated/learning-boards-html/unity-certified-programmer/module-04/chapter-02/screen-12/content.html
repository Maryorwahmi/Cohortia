Module 4 › Chapter 4.2 › Hands-on Activity
Starter steps
  1. Create a Cube, add Rigidbody, freeze rotations.
  2. Add PlayerController script and instantiate PlayerControls in Awake.
  3. Subscribe to Move.performed/.canceled and Jump.performed.
  4. Enable Gameplay in OnEnable and disable in OnDisable.
  5. Apply movement in FixedUpdate and AddForce in OnJump after checking grounded.
Starter code snippet
void Awake() {
 playerControls = new PlayerControls();
 playerControls.Gameplay.Move.performed += ctx => currentMovementInput = ctx.ReadValue();
 playerControls.Gameplay.Move.canceled += ctx => currentMovementInput = Vector2.zero;
 playerControls.Gameplay.Jump.performed += OnJump;
}
