Module 4 › Chapter 4.2 › Polling techniques
When to poll
Holding actions, continuous fire, or charging mechanics benefit from polling.
Example
if (playerControls.Gameplay.Fire.IsPressed()) { /* sustain fire */ }
Best practice
Sample in Update for input-only logic; for physics, set flags and apply in FixedUpdate.
Avoid over-polling
Polling every action defeats the performance and clarity benefits of event-driven code.
Check

Only poll when continuous state is required; otherwise prefer event callbacks.
