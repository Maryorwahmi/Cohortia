Task 1: Interact
Subscribe to Interact.performed in Awake and implement OnInteractPerformed to trigger the interaction.
playerControls.Gameplay.Interact.performed += OnInteractPerformed;
void OnInteractPerformed(InputAction.CallbackContext ctx) {
 Debug.Log("Interact action performed! Opening door...");
}
Task 2: Pause menu
Toggle Gameplay and UI maps when opening and closing the pause menu to prevent input conflicts.
Common pitfall

Leaving both Gameplay and UI enabled allows the same stick to control both gameplay and UI, creating confusing behavior.
