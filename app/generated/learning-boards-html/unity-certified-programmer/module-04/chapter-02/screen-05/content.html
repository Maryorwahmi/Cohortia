Module 4 › Chapter 4.2 › PlayerControls class
Pattern overview
Hold one instance per component, construct early, enable maps when the component becomes active, and disable when it stops.
Awake
playerControls = new PlayerControls();
OnEnable
playerControls.Gameplay.Enable();
OnDisable
playerControls.Gameplay.Disable();
Code snapshot
// Awake
playerControls = new PlayerControls();
// OnEnable
playerControls.Gameplay.Enable();
// OnDisable
playerControls.Gameplay.Disable();
Common mistake

Instantiating inside Update or leaving maps enabled across contexts leads to duplicates or unintended input handling.
