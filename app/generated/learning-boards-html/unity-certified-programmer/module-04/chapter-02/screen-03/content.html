Practical tasks
  • Wire Move — Subscribe to Move.performed and Move.canceled, storing a Vector2 for FixedUpdate.
  • Jump method — Use a dedicated OnJump handler that accepts the CallbackContext and applies AddForce.
  • Toggle maps — Enable Gameplay when playing, Disable when paused and Enable UI for menus.
  • Poll selectively — Use IsPressed or ReadValue inside Update only when continuous state is required.
Mental models
Think of input as events that describe intent, and physics as deterministic updates that apply that intent safely each fixed frame. Separating them improves clarity and prevents jitter or missed inputs.
Check
Avoid enabling multiple maps for the same controls at once.
Tip
Use lambda for simple value capture, named methods when you need to read context or debug.
