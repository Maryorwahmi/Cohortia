Module 4 › Chapter 4.2 › CallbackContext
What it provides
  • ReadValue() — Returns the input value typed to T, e.g., Vector2 for movement.
  • phase info — Know whether the event is started, performed, or canceled.
  • device metadata — Identify which device triggered the action if needed.
Examples
Vector2 moveInput = context.ReadValue<Vector2>(); float pressure = context.ReadValue<float>();
Key Takeaway

Match ReadValue's type to the action's expected control type and use phase checks for nuanced behavior.
