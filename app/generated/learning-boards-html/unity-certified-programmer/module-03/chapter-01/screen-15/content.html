Attach Rigidbody
Only objects with Rigidbodies are simulated by Unity's 3D physics engine.
Use physics APIs
Avoid direct transform writes on dynamic objects; prefer AddForce, MovePosition, and AddTorque.
Script safely
Null-check components, normalize directions, and choose the suitable ForceMode for your action.
Closing thought

Physics feel comes from tuning a few properties and using the Rigidbody API correctly. Practice by iterating values and observing results.
