Module 3 › Chapter 3.1 › Safe Rigidbody Pattern
Step-by-step checklist
1. Cache and null-check
GetComponent<Rigidbody> in Start and disable the script if missing to avoid crashes.
2. Normalize direction
Normalize vectors to keep force magnitude consistent across directions.
3. Choose ForceMode
Impulse for single bursts; Force for continuous pushes; VelocityChange to ignore mass.
4. Use the right update loop
Use FixedUpdate for repeated physics changes; one-off impulses can be placed in Start or on input events.
5. Avoid transform writes on dynamic Rigidbodies
Use Rigidbody.MovePosition or AddForce instead to keep physics stable.
Key Takeaway

A few disciplined checks and correct force choices avoid most common physics scripting bugs.
