Module 3 › Chapter 3.1 › Hands-on Activity
Activity steps
  1. Create a Plane at position 0,0,0 and a Sphere at 0,5,0.
  2. Select Sphere and Add Component → Rigidbody.
  3. Run the scene and confirm the sphere falls and rests on the plane.
  4. Adjust Mass and Drag while running to observe effects.
  5. Attach SphereLauncher script, set launchForce and direction, then run to see the launch.
Experiment ideas
  • Try mass values of 0.1 and 10 to compare responsiveness.
  • Set Drag to 5 to see rapid slowing of linear motion.
  • Toggle Is Kinematic and confirm the sphere no longer responds to pushes.
Key Takeaway

Hands-on tweaking is the fastest way to learn how Rigidbody properties shape gameplay feel.
