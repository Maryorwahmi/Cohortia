Module 3 › Chapter 3.1 › Key Concepts
Rigidbody
Component that enables physics simulation for a GameObject, giving it mass and response to forces.
Object types
Static, dynamic, and kinematic types determine simulation behavior and performance tradeoffs.
Forces & properties
Mass, drag, angular drag, Use Gravity, and ForceMode shape motion and collisions; tune them in play mode.
Final takeaway

Small, disciplined changes and safe scripting patterns produce predictable physics and satisfying gameplay feel.
