Module 3 › Chapter 3.1 › Drag & Angular Drag
Linear Drag

Linear drag simulates air resistance and slows linear velocity over time. Use it to control how quickly an object loses speed after being pushed.

Example
Set drag higher for slow-moving projectiles or floating objects to make motion more controllable.
Angular Drag
Controls how rapidly rotational velocity decays. Higher values stop spin faster.
Common mistake

Using extremely high drag to fake stopping can feel unnatural. Combine moderate drag with mass tuning instead.

Tuning tips
  • Adjust values while the scene is running to observe continuous damping effects.
  • Lower drag for fast projectiles; increase for objects that should slow quickly.
  • Pair angular drag with constraints if you need to lock rotation on specific axes.
Analogy
Think of drag as wind resistance and angular drag as rotational friction that brakes spin.
