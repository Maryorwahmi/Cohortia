Code walkthrough
using UnityEngine;

public class Cannonball : MonoBehaviour
{
    public float launchForce = 100f; // Force to apply
    private Rigidbody rb; // Reference to the Rigidbody component

    void Start()
    {
        rb = GetComponent<Rigidbody>();
        if (rb == null)
        {
            Debug.LogError("Rigidbody component not found on this GameObject!", this);
            return;
        }

        rb.AddForce(transform.forward * launchForce, ForceMode.Impulse);
    }
}
Explanation & checklist
  • GetComponent<Rigidbody> caches the component and prevents repeated lookups.
  • Null-check prevents runtime exceptions and gives a helpful log if setup is missing.
  • ForceMode.Impulse applies a single instantaneous push suitable for launches.
Concrete example
A cannon with a forward-facing muzzle launches a cannonball with a single impulse, with magnitude set by launchForce.
Misconception

Applying continuous forces in Update can desynchronize physics; use FixedUpdate for repeated force application.
