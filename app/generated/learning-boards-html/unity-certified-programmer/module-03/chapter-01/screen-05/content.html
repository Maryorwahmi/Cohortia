Module 3 › Chapter 3.1 › Static vs Dynamic vs Kinematic
Comparison table
Static Collider
No Rigidbody, collidable, immovable. Use for floors and walls for better performance.
Dynamic Rigidbody
Responds to gravity and forces. Use for objects that should behave physically.
Kinematic Rigidbody
Script-driven movement, detects collisions, does not respond to forces.
Concrete scenario
A moving platform should be kinematic so it is positioned by code but still interacts with the player. A thrown rock should be dynamic to react naturally.
Common pitfalls & tips
  • Do not mix 2D and 3D physics components on the same GameObject.
  • Enabling Is Kinematic prevents being pushed by other Rigidbodies.
  • Static colliders should not be moved at runtime; treat them as true static geometry.
Pro tip

When performance matters, keep most world geometry static and only simulate what needs to move.
