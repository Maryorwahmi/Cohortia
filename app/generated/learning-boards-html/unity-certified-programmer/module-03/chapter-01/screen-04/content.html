Rigidbody — the physics body

Attach this component when you want the physics engine to control movement, collisions, and responses to forces. It gives the object mass and other properties.

Static collider: no Rigidbody. Efficient for immovable geometry.
Dynamic Rigidbody: simulated object affected by gravity and forces.
Kinematic Rigidbody: controlled by script, not physics forces.
Concrete example
Add a Rigidbody to a sphere at position Y=5. When you run the scene the sphere will fall and collide with the plane because it is now simulated.
Common mistake
Expecting colliders to move objects. Colliders alone block but do not move unless a Rigidbody is present.
Key Takeaway

Use Rigidbody to enable simulation; use static colliders for immovable level geometry.

Visual: Role comparison

Dynamic Rigidbody
