MouseSelector logic
Reset previous highlight, cast a ray from Camera.ScreenPointToRay, check Raycast result, store original color, and change to highlight color.
// Visual excerpt for reference Ray ray = Camera.main.ScreenPointToRay(Input.mousePosition); RaycastHit hit; if (Physics.Raycast(ray, out hit, maxSelectionDistance, selectableLayers)) { currentSelection = hit.transform; Renderer r = currentSelection.GetComponent(); if (r != null) { originalColor = r.material.color; r.material.color = Color.yellow; } }
Misconception

Highlighting modifies a material; consider material instancing if multiple objects share one material to avoid changing all instances.

Testing steps
  • Assign objects to SelectableObjects layer.
  • Attach script to Camera and set selectableLayers in Inspector.
  • Run, hover to see yellow highlight, click to log the object name and hit point.
Example card
If the ray hits the top face of a cube, hit.point provides the world coordinate where an effect or tooltip should appear.
