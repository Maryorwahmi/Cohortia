Module 3 › Chapter 3.4 › Physics.Raycast
Call pattern
Origin, direction, out RaycastHit, maxDistance, and LayerMask. Normalize direction and guard access with the returned boolean.
Steps
  1. Create origin and direction vectors and normalize direction.
  2. Declare RaycastHit hit; call Physics.Raycast and check the bool result.
  3. If true, read hit.point, hit.normal, hit.collider, or hit.transform.
Common mistakes
  • Forgetting the out keyword when declaring RaycastHit.
  • Using an unnormalized direction and misinterpreting maxDistance.
  • Attempting to access hit fields when the ray returned false.
Code example (visual only)
// Create a ray from the camera through the mouse Ray ray = Camera.main.ScreenPointToRay(Input.mousePosition); RaycastHit hit; if (Physics.Raycast(ray, out hit, maxSelectionDistance, selectableLayers)) { // Use hit.transform, hit.point, hit.normal } // Debug.DrawRay(ray.origin, ray.direction * maxSelectionDistance, Color.red);
Pro tip

Prefer specifying maxDistance and LayerMask to reduce unnecessary checks and improve performance in dense scenes.
