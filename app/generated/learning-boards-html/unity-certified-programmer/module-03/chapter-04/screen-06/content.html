Ray: origin and direction
Construct a Ray with an origin and a direction. Normalize the direction for predictable distance checks.
origin
World position where the ray starts.
direction
Unit vector describing the ray's path.
RaycastHit fields
Use these values only when Physics.Raycast returns true.
point
Exact world position of impact; spawn effects here.
normal
Surface orientation at the hit; useful for reflection or decals.
collider / transform / rigidbody
References to the hit object's components for identification or physics interaction.
distance
Distance from origin to impact; useful for range-limited effects.
Example use

Spawn an impact decal at hit.point and orient it with hit.normal so it sits flush with the surface.
