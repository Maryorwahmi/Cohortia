Module 3 › Chapter 3.4 › Key Concepts
Raycasting
Instant, non-physical queries that return hit info when intersecting colliders.
RaycastHit
Contains collider, transform, point, normal, and distance — use only after a successful cast.
LayerMask
Bitmask that filters which layers a cast will hit; set in Inspector for clarity.
Summary takeaway

Use raycasts as efficient queries, read hit data only after success, and filter results with LayerMask. Visualize rays when verifying behavior.
