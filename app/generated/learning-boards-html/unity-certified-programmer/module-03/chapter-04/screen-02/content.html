Learning Objectives
Skills to practice and verify

01
Describe raycasting
Explain raycasting as a non-physical query and why it requires colliders. This matters because it clarifies when to use raycasts instead of physical projectiles.
Mnemonic: Laser beam crossing a collider
VERIFIED COMPETENCY MILESTONE
02
Use Physics.Raycast
Implement raycasts with origin, normalized direction, a RaycastHit out, and a max distance to detect targets reliably.
Mnemonic: Origin arrow with distance line
VERIFIED COMPETENCY MILESTONE
03
Read RaycastHit
Extract hit point, normal, collider, transform, and distance for game logic like damage, placement, and physics responses.
Mnemonic: Pin on map = hit point
VERIFIED COMPETENCY MILESTONE
04
Filter with LayerMask
Configure bitmasks to include or exclude layers, improving accuracy and performance for targeted queries.
Mnemonic: Layer filter grid
VERIFIED COMPETENCY MILESTONE
