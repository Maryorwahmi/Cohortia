Bitmask basics
Build masks by shifting 1 by a layer index and combining with bitwise OR. Invert masks with bitwise NOT to exclude layers.
int playerLayer = LayerMask.NameToLayer("Player"); int enemyLayer = LayerMask.NameToLayer("Enemy"); int mask = (1 << playerLayer) | (1 << enemyLayer); // Exclude a layer: int ignore = LayerMask.NameToLayer("IgnoreRaycast"); int allExcept = ~(1 << ignore);
Practical tip

Expose LayerMask fields in the Inspector and select layers visually to avoid bit-shift errors in code.

Example scenario
A mouse selector should only hit objects on a SelectableObjects layer. Assign scene objects to that layer and set the selectableLayers mask on the MouseSelector component so clicks ignore everything else.
Debug checklist
  • Confirm object layer assignments in the Inspector.
  • Temporarily widen the mask to include all layers for testing.
  • Then tighten the mask to the intended layers only.
