Lab: Selection and Ground Check
Scene setup
  1. Add a Plane and several primitives at different positions.
  2. Create layer SelectableObjects and assign it to your primitives.
  3. Add a Camera and attach the MouseSelector script.
MouseSelector config
  • Set selectableLayers to SelectableObjects in the Inspector.
  • Set maxSelectionDistance to a practical value (e.g., 100).
  • Run and hover to see highlights and click to log hits.
GroundChecker setup
  • Add a character capsule and assign the Ground layer to the plane.
  • Attach GroundChecker, set groundLayer mask and groundCheckDistance.
  • Run and observe isGrounded and Debug.DrawRay color changes.
Mini challenge
Implement jump input gated by isGrounded and verify it only triggers when grounded.
