Module 3 › Chapter 3.3 › ForceMode.Force and Continuous Forces
Behavior
ForceMode.Force applies a force each physics step and is scaled by mass. It's ideal for sustained acceleration like engines or wind pushes. Over multiple FixedUpdates, velocity increases gradually.
Tip: tune thrust magnitudes conservatively and observe solver stability. Use damping if motion feels too floaty.
Concrete example
// In FixedUpdate
if (thrusting) rb.AddForce(transform.forward * rocketThrust, ForceMode.Force);
Hold the thrust key and watch the cube steadily pick up speed. Heavier mass -> slower acceleration under the same rocketThrust value.
Key Takeaway

Use ForceMode.Force for continuous, mass-sensitive acceleration. Keep input capture separate from physics application.
