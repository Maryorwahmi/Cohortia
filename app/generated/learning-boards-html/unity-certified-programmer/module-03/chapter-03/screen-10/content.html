Module 3 › Chapter 3.3 › ForceMode.Impulse and Instant Forces
Behavior
Impulse changes momentum instantly and depends on mass. Use it for discrete events like jumps or sudden pushes from explosions.
Pattern: detect button press in Update, set a request flag, then apply AddForce with ForceMode.Impulse in FixedUpdate and clear the flag.
Example snippet
// Update
if (Input.GetKeyDown(KeyCode.Space)) jumpRequested = true;

// FixedUpdate
if (jumpRequested) { rb.AddForce(Vector3.up * jumpImpulse, ForceMode.Impulse); jumpRequested = false; }
Misconception

Using default ForceMode for an instant action will not produce the immediate velocity change you expect. Choose Impulse for crisp responses.
