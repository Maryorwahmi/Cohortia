Module 3 › Chapter 3.3 › Create and Apply a Physics Material
Step-by-step
1. Create: Project → Create → Physics Material.
2. Configure: set dynamic/static friction and bounciness; pick combine modes.
3. Assign: drag the material into the Collider's Material slot.
4. Test: Play and observe; iterate values for desired feel.
Common mistake
Changing a material asset does not affect colliders if the asset isn't assigned. Also avoid starting objects with overlapping colliders.
Concrete scenario
Create 'SlipperyMaterial' with both frictions at 0.1 and Friction Combine set to Minimum. Assign it to the plane. Drop a sphere and observe extended sliding and reduced deceleration.
Key Takeaway

Follow the create-configure-assign-test loop. Combine modes are critical when mixed materials meet.
