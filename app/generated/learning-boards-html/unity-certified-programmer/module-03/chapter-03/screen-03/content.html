Practice & Safety Objectives
What to do and what to watch for while building scenes and scripts
Make two sample materials
Create 'BouncyMaterial' and 'SlipperyMaterial' and set bounciness and friction accordingly. Test in Play mode and verify expected behavior.
VERIFIED COMPETENCY MILESTONE
Use the Update → Flag → FixedUpdate pattern
Detect instant input in Update, set a flag, then read and reset the flag in FixedUpdate when applying forces.
VERIFIED COMPETENCY MILESTONE
Select ForceMode correctly
Match ForceMode to the effect: continuous vs instant and mass-dependent vs mass-independent.
VERIFIED COMPETENCY MILESTONE
Avoid overlapping colliders and excessive forces
Ensure initial placements do not overlap. Use debug logs to confirm when forces fire, helping diagnose erratic behavior.
