Module 3 › Chapter 3.3 › Force Application Methods
Core methods
  • AddForce: linear force to move a Rigidbody.
  • AddTorque: rotational force to spin a Rigidbody.
Best practice: detect input in Update, set flags, then apply forces in FixedUpdate. This pattern prevents frame-rate-dependent physics differences.
Concrete code pattern (conceptual)
// Update: capture input
if (Input.GetKeyDown(KeyCode.Space)) jumpRequested = true;

// FixedUpdate: apply physics
if (jumpRequested) { rb.AddForce(Vector3.up * jumpImpulse, ForceMode.Impulse); jumpRequested = false; }
Common Mistake

Applying forces in Update can make physics inconsistent across frame rates. Use FixedUpdate for physics calls and Update for input detection.
