Module 3 › Chapter 3.3 › ForceApplier Example Pattern
Conceptual code view
public class ForceApplier : MonoBehaviour
{
    public float jumpImpulse = 10f;
    public float rocketThrust = 5f;
    public float spinTorque = 2f;

    private Rigidbody rb;
    private bool jumpRequested = false;

    void Start() { rb = GetComponent<Rigidbody>(); }

    void Update() { if (Input.GetKeyDown(KeyCode.Space)) jumpRequested = true; }

    void FixedUpdate()
    {
        if (Input.GetKey(KeyCode.W)) rb.AddForce(transform.forward * rocketThrust, ForceMode.Force);
        if (jumpRequested) { rb.AddForce(Vector3.up * jumpImpulse, ForceMode.Impulse); jumpRequested = false; }
        if (Input.GetKey(KeyCode.E)) rb.AddTorque(Vector3.up * spinTorque, ForceMode.Force);
    }
}
Adjust parameters in the Inspector and watch debug logs when forces are applied to confirm behavior.
Concrete scenario
Attach this script to the Rocket cube. Hold 'W' for thrust, press 'Space' for an impulse jump, and hold 'E' to spin. Observe different motion patterns and tune magnitudes.
Pro Tip

Use small debug logs to indicate when each force is applied so you can verify the Update-to-FixedUpdate interaction.
