Module 3 › Chapter 3.3 › Friction: Dynamic vs Static
Concept & impact
Static friction resists starting motion; dynamic friction slows sliding. These two coefficients control how objects begin moving and how they slow down once in motion. Adjust both to tune whether a surface feels sticky, normal, or slippery.
Tip
If an object won’t start sliding, reduce static friction or increase the applied force instead of only modifying dynamic friction.
Example scenario
A crate on a ramp stays put. Increasing dynamic friction will not help; static friction is preventing motion. Lower static friction or increase incline to see sliding begin.

Key Takeaway

Tune static friction to control motion start and dynamic friction to control sliding feel. Combine modes decide the final result when two materials meet.
