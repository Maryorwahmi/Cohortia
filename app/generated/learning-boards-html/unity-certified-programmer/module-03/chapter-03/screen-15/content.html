Quick Reference
Three compact reminders you can use while tuning physics
Materials
Set dynamic/static friction and bounciness; test combine modes.
Force Modes
Force/Impulse respect mass; VelocityChange/Acceleration ignore mass.
Update/FixedUpdate
Capture input in Update, apply forces in FixedUpdate for stable physics.
Final Takeaway

When tuning, ask: should mass matter? Should the effect be instant or continuous? Those questions map to ForceMode choices and material settings.
