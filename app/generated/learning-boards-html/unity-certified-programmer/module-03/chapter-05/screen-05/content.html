Module 4 › Chapter 3.5 › Timestep Tuning
Safe tuning process
1. Measure
Open Profiler and inspect Physics.Simulate baseline.
2. Test
Run scenes with fast-moving objects to reproduce tunneling.
3. Adjust
Change timestep incrementally and re-profile each step.
Example decision
If your projectile tunnels at 0.02 but CPU is tight, enable continuous collision detection on that projectile and keep the global timestep. Only reduce the global timestep if many objects need higher precision.
Misconception
Assuming lower timestep is always better. It can double or triple CPU work for marginal gains.
Key Takeaway

Profile first, prefer targeted continuous collision detection, and only lower timestep if necessary and measured.
