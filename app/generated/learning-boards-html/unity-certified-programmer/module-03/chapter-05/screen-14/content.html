Module 4 › Chapter 3.5 › Key Concepts
Fixed Timestep
Defines physics update frequency for consistent simulation.
Layer Collision Matrix
Prevent checks between layers that don't need to interact.
Profiler
Measure Physics.Simulate and use the Physics Debugger to diagnose problems.
Collider Hygiene
Prefer primitives and compounds; reserve mesh colliders for static geometry.
Sleeping Rigidbodies
Avoid patterns that continuously wake bodies; let sleep save CPU.
Rigidbody Modes
Dynamic for physics-driven objects; kinematic for script-driven movers.
One-line takeaway
Measure with the Profiler, design layers to avoid unnecessary work, and use the proper Rigidbody and collider patterns to keep physics fast and stable.
