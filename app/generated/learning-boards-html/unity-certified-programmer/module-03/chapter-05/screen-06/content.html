Module 4 › Chapter 3.5 › Layer Collision Matrix
Design steps
  1. Inventory object types and their interaction needs.
  2. Create layers for groups with similar collision needs.
  3. Open Project Settings → Physics and uncheck unwanted intersections.
  4. Profile before and after to measure savings.
Concrete example
Make EnemyLayer not collide with EnemyLayer and ObstacleLayer not collide with ObstacleLayer. Ensure PlayerLayer still collides with necessary layers like Environment and Enemies.
Why it helps
Disabling pairs removes collision tests entirely. This reduces broadphase and narrowphase work for many objects, especially when you have hundreds of colliders.
Misconception
Filtering collisions in script after detection still costs the full collision check. Use the matrix to prevent checks in the first place.
Key Takeaway

Plan layers by interaction needs and uncheck irrelevant intersections to cut physics work at the source.
