Module 4 › Chapter 3.5 › Rigidbody Modes
Dynamic Rigidbody
Fully simulated: responds to gravity, forces, and collisions. Best for objects that require realistic physics interaction.
When to use
Player characters, projectiles, and items that should be physically reactive.
Kinematic Rigidbody
Controlled by animation or scripts. It won't be pushed by physics but can push dynamic bodies and detect triggers.
Key Takeaway

Use kinematic for scripted movers like platforms; use dynamic for objects that need to be simulated by physics.
