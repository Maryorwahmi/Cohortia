Module 4 › Chapter 3.5 › Motion Patterns
Bad pattern
Using Update to set transform.position on dynamic Rigidbodies causes physics inconsistencies and can prevent sleep.
BadMover (illustrative)
// Pseudocode showing the problematic pattern
void Update() {
  transform.position += forward * Time.deltaTime * 0.1f;
}
Correct pattern
Capture input in Update, apply movement in FixedUpdate using Rigidbody.MovePosition, MoveRotation, or set rb.velocity.
Key Takeaway

Let the physics engine move dynamic bodies through Rigidbody APIs within FixedUpdate so collisions and integration remain stable.
