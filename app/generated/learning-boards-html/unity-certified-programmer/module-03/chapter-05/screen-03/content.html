Practice Checks
Small habits that prevent common physics pitfalls
Timestep Tuning
Check the project's Fixed Timestep and only lower it for fast, precision-dependent objects. The mnemonic: "Measure first, reduce seldom."
VERIFIED COMPETENCY MILESTONE
Collider Hygiene
Prefer primitive or compound colliders for dynamic objects. Use Mesh Collider only for static geometry or convex dynamic needs.
VERIFIED COMPETENCY MILESTONE
Avoid Transform Abuse
Use MovePosition/MoveRotation or set velocity in FixedUpdate. Never set transform.position on dynamic bodies every frame.
VERIFIED COMPETENCY MILESTONE
Sleeping Behavior
Let resting bodies sleep: avoid tiny per-frame forces that keep them awake unnecessarily.
