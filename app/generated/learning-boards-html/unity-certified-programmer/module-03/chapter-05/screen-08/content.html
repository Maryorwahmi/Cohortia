Module 4 › Chapter 3.5 › Colliders
Primitive Colliders
Boxes, spheres, and capsules are cheap and should be used whenever possible for dynamic objects.
Compound Collider
Combine multiple primitives as children of the Rigidbody to approximate complex shapes with low cost.
Mesh Colliders
Use for static level geometry. For dynamic objects only use convex mesh colliders and only when primitives cannot approximate the shape.
Common mistake
Assigning expensive non-convex mesh colliders to many moving objects because they match art perfectly.
Key Takeaway

Approximate with primitives or compound colliders for dynamic objects. Reserve mesh colliders for static world geometry or convex dynamic cases.
