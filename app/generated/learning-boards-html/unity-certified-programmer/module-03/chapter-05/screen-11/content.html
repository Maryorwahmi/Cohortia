Module 4 › Chapter 3.5 › Query Optimization
Limit physics queries
Pass LayerMask arguments to raycasts and overlap checks so they only consider relevant layers. Combine this with layer matrix pruning for maximum effect.
Example
A projectile's raycast should only test EnemyLayer and EnvironmentLayer, not UI or other projectiles.
Batching & Spreading
For non-critical checks, spread queries across frames or reuse cached results to lower per-frame cost.
Misconception
Assuming raycasts are always cheap. When many colliders exist, broad queries can become expensive unless limited by layers.
