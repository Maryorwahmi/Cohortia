Module 4 › Chapter 3.5 › Rigidbodies vs Static
Dynamic Rigidbody (When to use)
  • Player characters and AI actors that respond to forces.
  • Projectiles and falling objects that need realistic collisions.
  • Objects that require continuous interaction and impulses.
Example
A grenade requires a Rigidbody because it rolls, collides, and bounces.
Static Collider (When to prefer)
  • Level geometry like floors, walls, and static scenery.
  • Many small debris pieces that never move.
  • Performance-critical surfaces that only need collisions from moving objects.
Key Takeaway

Static colliders are far cheaper. Only add Rigidbodies to objects that actually require physics simulation.
