Module 4 › Chapter 3.5 › Sleeping Rigidbodies
How sleeping helps
Sleeping objects are excluded from most simulation work until an event wakes them, saving CPU especially in dense scenes.
Problem pattern
Constantly applying tiny forces or resetting velocity every frame prevents sleep and wastes CPU.
Mitigation
  • Stop unnecessary per-frame nudges on resting objects.
  • Use kinematic for scripted movers that should not be simulated.
  • Wake objects only when a meaningful interaction occurs.
Key Takeaway

Let objects rest; avoid patterns that continuously wake them without benefit.
