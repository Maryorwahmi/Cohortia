Module 03 › Chapter 3.2 › Collider vs Trigger
Solid Collider (Is Trigger unchecked)
Produces physical contact. Unity sends OnCollisionEnter, OnCollisionStay, OnCollisionExit to appropriate scripts. Use for walls, floors, and objects that should block or push.
Mistake: Expecting a trigger to stop movement. Triggers do not block; they only detect.
Trigger (Is Trigger checked)
Becomes a detection volume. Unity sends OnTriggerEnter, OnTriggerStay, OnTriggerExit. Use for pickups, detection zones, damage fields, and entering areas that should not impede motion.
Example: Speed boost pad should be a trigger to avoid physically impeding the vehicle.
Remember: triggers still require a Rigidbody on at least one interacting object to receive event callbacks.
