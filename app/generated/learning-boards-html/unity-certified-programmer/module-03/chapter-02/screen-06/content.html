Mesh Collider (detailed)
Accurate collision using the model's geometry. Best for static level pieces where visual accuracy matters and the object does not move.
When to use
Rocks, complex architecture, or props that remain static in the scene.
Is Convex option
Convex simplifies the mesh to a convex hull which is safe for dynamic rigidbodies but loses concave detail. Use when you need a moving object's mesh-based collision but can accept simplification.
Mistake: Using non-convex mesh colliders on moving objects can produce errors or be unsupported by the physics engine.
Practical recommendation
For dynamic objects approximate complex shape with multiple primitive colliders. Reserve mesh colliders for static scene geometry and enable Is Convex only when dynamic behavior requires mesh-based approximation.
