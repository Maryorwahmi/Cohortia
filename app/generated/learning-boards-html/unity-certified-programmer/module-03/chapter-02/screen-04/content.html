Module 03 › Chapter 3.2 › What is a Collider?
Collider — core idea
  • Defines the shape used by the physics engine for contact and overlap checks.
  • Is separate from the visual mesh; simpler shapes are faster to compute.
  • Required for objects that should produce collision or trigger events.
Example: Use a Box Collider for crates instead of a detailed mesh to save CPU time.
Key Takeaway

Pick the simplest collider that preserves gameplay; colliders are the physics skin, not the render mesh.

Common mistakes & tips
Mistake
Using a Mesh Collider for dynamic objects without convex enabled.
Result: poor performance and unexpected physics.
Tip
Approximate complex shapes with multiple primitives for both accuracy and speed.
Analogy
Skin vs Sculpture
Collider is the skin the engine sees; the render mesh is the sculpture players see.
