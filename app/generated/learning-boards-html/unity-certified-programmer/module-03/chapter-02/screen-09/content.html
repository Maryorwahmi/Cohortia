Module 03 › Chapter 3.2 › OnTriggerEnter / Stay / Exit
Trigger code (visual)
void OnTriggerEnter(Collider other)
{
    Debug.Log("Entered trigger: " + other.gameObject.name);
    if (other.gameObject.CompareTag("Pickup"))
    {
        Debug.Log("Player picked up an item!");
        Destroy(other.gameObject);
    }
}

void OnTriggerStay(Collider other) { /* ... */ }

void OnTriggerExit(Collider other) { /* ... */ }
Key points
  • Collider parameter is simpler than Collision and points to the other collider.
  • Best for pickups, area triggers, and non-blocking detection.
  • Remember Rigidbody requirement: at least one interacting object must have a Rigidbody.
Lab example: Pickup sphere destroys itself when the player enters its trigger, giving immediate feedback in the Console.
