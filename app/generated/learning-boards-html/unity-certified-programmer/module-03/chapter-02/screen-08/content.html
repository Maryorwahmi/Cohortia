Module 03 › Chapter 3.2 › OnCollisionEnter / Stay / Exit
Code excerpt (visual)
// Inside PlayerInteraction
void OnCollisionEnter(Collision collision)
{
    Debug.Log("Collided with: " + collision.gameObject.name);
    if (collision.gameObject.CompareTag("Enemy"))
    {
        Debug.Log("Player hit an enemy!");
        // e.g., take damage, play sound
    }
}

void OnCollisionStay(Collision collision) { /* ... */ }

void OnCollisionExit(Collision collision)
{
    Debug.Log("Stopped colliding with: " + collision.gameObject.name);
}
Explanation
  • The Collision parameter includes gameObject, collider, contacts, and relativeVelocity.
  • Use CompareTag to check for categories such as "Enemy" instead of string equality with name.
  • Events go to the Rigidbody owner when only one object has a Rigidbody.
Example scenario: Player collides with an enemy capsule, detect collision in OnCollisionEnter and apply damage based on relativeVelocity.
Check: did you remember to add a Rigidbody to at least one interacting object? If not, no collision events will fire.
