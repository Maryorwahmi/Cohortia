Layer workflow
  1. Create layers: e.g., PlayerLayer, EnemyLayer, PickupLayer in Tags and Layers settings.
  2. Assign GameObjects to those layers in the Inspector.
  3. Open Project Settings → Physics and edit the Layer Collision Matrix by unchecking pairs you want to exclude.
Example
Disable Enemy vs Enemy collisions to avoid enemies pushing each other.
Tip
Keep pickups on their own layer and use triggers so you can disable physical collisions while preserving detection.
Experiment
Uncheck PlayerLayer vs EnemyLayer and observe the Player no longer collides physically; scripts still run if event routing conditions are met.
