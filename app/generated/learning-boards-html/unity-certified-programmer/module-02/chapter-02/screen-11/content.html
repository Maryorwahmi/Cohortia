Module 2 › Chapter 2.2 › Adding and Removing Components
Step-by-step
  1. Select GameObject in the Hierarchy.
  2. Open the Inspector and click Add Component.
  3. Search for and select the desired component.
  4. To remove: click the gear icon on the component and choose Remove Component.
Tip: Toggle enabled state to trial behavior without deleting the component. Reorder components for organization; only some custom scripts depend on order.
Key Takeaway

Make permanent property changes outside Play Mode. Use toggles to experiment safely.

Example: add Rigidbody
Create a Sphere, select it, Add Component → Rigidbody. Enter Play Mode to see it fall. Exit Play Mode and reapply permanent property values outside Play Mode.
Gotcha
Editing properties in Play Mode is useful for experimentation but will not persist after you stop playing.
