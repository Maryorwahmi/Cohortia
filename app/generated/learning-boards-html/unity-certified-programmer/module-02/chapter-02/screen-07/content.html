Comparison

Local (Parent) vs World

Local coordinates
Relative to parent. Use when an object must keep an offset from its parent, such as held items or UI attached to characters.
World coordinates
Absolute position in the scene. Use for spawning objects at fixed locations or teleporting characters.
Example & Gotcha
Scenario
Attach a lantern to a moving cart using local transform so it follows the cart. If you set world position after parenting, the lantern will jump because its local position differs.
Misconception
Using world rotation when you expect local rotation can rotate children around unexpected axes. Always confirm which space your code or transform tool uses.
Key Takeaway

Decide if an object should follow a parent; choose local for attachments and world for fixed positions.
