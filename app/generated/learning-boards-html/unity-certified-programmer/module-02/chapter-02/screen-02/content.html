Learning Objectives

Bloom targets: learn, understand, apply, master

Learn → Understand → Apply → Master
01
Define GameObject
Explain GameObject as a named container with a Transform, and why it does not do anything until given components.
Mnemonic: an empty LEGO plate
VERIFIED COMPETENCY MILESTONE
02
Understand Components
Describe how components like Mesh Renderer, Colliders, and Scripts add visuals, collisions, and behavior to GameObjects.
Mnemonic: LEGO pieces that attach
VERIFIED COMPETENCY MILESTONE
03
Master Transform
Identify Position, Rotation, and Scale and explain parent-child Transform relationships and local vs global space.
Mnemonic: anchor + orientation + size
VERIFIED COMPETENCY MILESTONE
04
Attach & Configure Components
Add and remove built-in components and adjust properties like Rigidbody mass and Collider triggers to shape behavior.
Mnemonic: Inspector is your toolbox
VERIFIED COMPETENCY MILESTONE
