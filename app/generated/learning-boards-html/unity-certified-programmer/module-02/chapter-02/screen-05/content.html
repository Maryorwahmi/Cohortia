Module 2 › Chapter 2.2 › What are Components?
Core idea

Components add functionality

Each component handles a single concern: rendering, collision, physics, or custom logic. Combine them to create complete in-game objects.

Example
Player = Mesh Filter + Mesh Renderer + Capsule Collider + Rigidbody + PlayerController script.
Misconception
A Collider alone does not enable physics motion — you need a Rigidbody for gravity and forces.
Key Takeaway

Design components to be single-purpose and reusable across GameObjects.

Common Built-ins
Mesh Filter / Mesh Renderer
Hold model data and draw it with materials.
Colliders
Box, Sphere, Capsule — for collision detection or triggers.
Rigidbody
Enables physics: gravity, forces, mass and drag.
