Trigger vs Solid
Trigger detects overlaps without blocking; solid colliders block physics when paired with Rigidbodies.
Key Takeaway

Use triggers for detection logic and solid colliders for physical boundaries; include Rigidbody when you want physics simulation.

Example scenarios
Door sensor: Box Collider set as Is Trigger to detect proximity and play an animation without blocking the player.
Wall: Box Collider not set as trigger so it physically blocks a player with a Rigidbody.
Gotcha
Making a collider a trigger disables its blocking behavior — objects will pass through unless you handle overlaps in code.
