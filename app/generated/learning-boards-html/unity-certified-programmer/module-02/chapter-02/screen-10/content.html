Rigidbody essentials
Mass
Controls inertia; heavier objects accelerate less under the same force.
Drag
Simulates air resistance, reducing velocity over time.
How to move
Use AddForce, AddTorque, MovePosition in FixedUpdate, or set Rigidbody.velocity for direct control. Avoid changing transform.position every frame on non-kinematic Rigidbodies.
Key Takeaway

Respect the physics pipeline: move Rigidbodies through physics methods to ensure stable, realistic interactions.

Example & Common Mistake
Example: apply Rigidbody.AddForce(Vector3.up * 10) to make an object jump. Adjust Mass and Drag to tune feel.
Common mistake
Setting transform.position every frame for a falling object breaks collision detection and produces jitter. Use physics methods instead.
