Module 2 › Chapter 2.2 › Transform: Position, Rotation, Scale
Transform properties
Position
Vector3 (X, Y, Z) — object location in space.
Rotation
Quaternion stored, Euler shown — object orientation.
Scale
Vector3 — size along axes.
Parenting behavior
Children store local transforms relative to the parent. Moving or rotating a parent affects children predictably by maintaining relative offsets.
Key Takeaway

Use local transforms for attachments and world transforms for absolute placement; remember rotation affects child axes.

Example: weapon mount
Scenario
Attach a Sword as a child of Hand. Set Sword local position so it sits correctly. When the Hand moves or rotates, the Sword follows because of the parent-child Transform relationship.
Gotcha
If you reset parent rotation unexpectedly, child local axes will change and attached objects may flip. Check both local and global values when debugging.
