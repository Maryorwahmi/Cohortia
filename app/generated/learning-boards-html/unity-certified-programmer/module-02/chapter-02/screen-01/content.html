Why this matters
The GameObject-Component pattern is the organizing principle for scene structure, asset wiring, and gameplay. It defines how you attach visuals, physics, and scripts to produce interactive content. Getting fluent with this model speeds up prototyping and reduces brittle class hierarchies.
Reusable
Attach the same Health script to many objects.
Modular
Swap renderers or colliders without changing behavior scripts.
Predictable
Parenting and Transform rules give clear spatial relationships.
