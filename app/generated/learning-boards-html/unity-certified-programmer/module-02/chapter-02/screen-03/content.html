How you'll demonstrate mastery

Complete hands-on tasks and explain choices. Avoid common pitfalls.

Learn → Apply → Verify
Task: Make a visible object
Add a Mesh Filter and Mesh Renderer to a GameObject. Observe how the object remains invisible without a renderer and how materials change appearance.
Task: Add physics
Attach a Rigidbody and a Collider. Test different mass and drag values and record the effect on bounce and fall speed.
Task: Parent transforms
Create a parent object, move it, and note how children move relative to the parent. Try rotating the parent and observe local versus global axes.
Reflection: Composition
Describe an example where you reuse a Health script across prefabs instead of creating several subclasses. Explain the benefits and a potential trade-off.
