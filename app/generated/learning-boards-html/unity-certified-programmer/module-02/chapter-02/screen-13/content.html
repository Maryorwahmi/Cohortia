Module 2 › Chapter 2.2 › Build a Physics-Enabled Ball
Step sequence
  1. Create a new Scene and save it.
  2. GameObject → 3D Object → Plane. Set Transform to (0,0,0) and Scale to (5,1,5).
  3. GameObject → 3D Object → Sphere. Rename to BouncingBall and set Position to (0,5,0).
  4. Inspect components: add Rigidbody to the Sphere.
  5. Enter Play Mode and observe the ball fall. Adjust Mass and Drag to feel differences, then exit Play Mode and reapply permanent values.
  6. Optional: mark Plane collider as Is Trigger to observe the ball falling through, then undo to restore solid ground.
Concrete tips
Always stop Play Mode before saving permanent Rigidbody properties; Play Mode edits revert.
Use lightweight Mass values like 1 or 0.1 to test sensitivity; increase Drag to reduce sliding.
Debug
If the ball falls through, check whether the ground collider is set as a trigger or if the Rigidbody is incorrectly configured.
