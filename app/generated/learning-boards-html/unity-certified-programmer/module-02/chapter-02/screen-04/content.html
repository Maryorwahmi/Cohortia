Definition

GameObject as container

A GameObject holds a Transform and a list of Components. It represents an entity in the Hierarchy but only does what its components provide.

Concrete example
Create a Sphere: you get a GameObject plus Mesh Filter, Mesh Renderer, and Sphere Collider by default.
Common misconception
A GameObject is not 'the object' until it has components. Removing a renderer hides it, but the GameObject still exists.
Key Takeaway

Treat GameObjects as flexible holders; add components to give them visuals, physics, or behavior.
