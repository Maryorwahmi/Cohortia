Module 2 › Chapter 2.2 › Mesh Filter vs Mesh Renderer
Mesh Filter
Holds the mesh data: vertices, indices, normals. It is the model's geometry source.
Mesh Renderer
References Materials and shaders to draw the Mesh Filter on screen with lighting and textures.
Key Takeaway

Geometry and rendering are separate responsibilities; you usually need both for a visible model.

Example
Import a model, assign it to the Mesh Filter, then create a material and assign it to the Mesh Renderer. The object becomes visible with the chosen appearance.
Misconception
Removing the Mesh Renderer hides the mesh but does not delete mesh data from the Mesh Filter.
