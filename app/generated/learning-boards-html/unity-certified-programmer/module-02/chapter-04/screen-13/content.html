Module 2 › Chapter 2.4 › Pitfalls & Debugging
Physics in Update

Symptom: jitter or teleporting interactions. Solution: move physics calls to FixedUpdate and use Time.fixedDeltaTime.

Awake ordering issues

Symptom: null refs in Start. Solution: perform cross-object setup in Start or guarantee Awake ordering through design.

Dangling callbacks

Symptom: exceptions after object destroyed. Solution: unsubscribe from events in OnDestroy.

Input & physics mismatch

Symptom: delayed or unresponsive control. Solution: sample input in Update, apply in FixedUpdate.

Debugging tip

Log lifecycle callbacks in the Console to verify order and timing. Vary Time Scale to reveal timing bugs.

Key Takeaway

When in doubt, ask: should this run every render, on a fixed timestep, or only once? Place it accordingly to avoid bugs.
