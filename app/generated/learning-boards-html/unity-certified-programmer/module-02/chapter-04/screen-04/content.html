Definition

MonoBehaviour as component

A class that inherits MonoBehaviour becomes a component you can attach to a GameObject. It holds per-object state and receives lifecycle callbacks from Unity.

Concrete example: PlayerController attached to a Capsule accesses its Rigidbody with GetComponent in Awake.
Misconception: A script is not a global static library — each attached instance stores state for the GameObject.
Key Takeaway

Treat scripts as components: design them to encapsulate behavior and state for a single GameObject, and initialize references early.

Analogy
Think of a MonoBehaviour as a module snapped onto an entity. It provides behavior that runs with that entity and can talk to sibling components on the same entity via GetComponent.
