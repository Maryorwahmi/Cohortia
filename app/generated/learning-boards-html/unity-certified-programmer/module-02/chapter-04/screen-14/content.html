Module 2 › Chapter 2.4 › Key Concepts
MonoBehaviour

Base class for scripts that become components attached to GameObjects, receiving lifecycle callbacks.

Update vs FixedUpdate

Update for frame-dependent input and visuals; FixedUpdate for physics with Time.fixedDeltaTime for consistency.

LateUpdate & OnDestroy

LateUpdate is for final transform updates like camera follow. OnDestroy is for cleanup and unsubscribing to avoid dangling callbacks.

Summary: Put code where Unity expects it to run. This yields stable, predictable gameplay across different frame rates and platforms.
