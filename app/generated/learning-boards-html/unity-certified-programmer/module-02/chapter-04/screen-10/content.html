Module 2 › Chapter 2.4 › Execution Order
Typical frame timeline
Awake()
OnEnable()
Start()
FixedUpdate() xN
Update()
LateUpdate()
OnDisable()
OnDestroy()
Note: Awake runs before any Start across components so cross-object ordering can rely on Awake completion.
FixedUpdate can run multiple times or zero times between frames depending on time accumulation.
Start only runs when the component becomes enabled for the first time.
