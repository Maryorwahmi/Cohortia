Module 2 › Chapter 2.4 › Hands-on Activity
Setup steps
  1. Create scene "LifecycleMovementScene" and add a Plane at 0,0,0 tagged as Ground.
  2. Add a Capsule at 0,1,0 named Player and add Rigidbody (freeze rotation).
  3. Create PlayerController, attach it, implement Awake, Start, Update, FixedUpdate, OnCollisionEnter/Exit, OnDestroy.
  4. Run Play Mode and inspect Console logs for lifecycle order and physics behavior.
Checks and variants
Check that Awake logs before Start and that FixedUpdate runs at a steady interval.
Variant: replace MovePosition with AddForce and compare movement feel and stability.
Gotcha: forgetting to tag Plane as Ground causes OnCollision checks to never set isGrounded.
Why it matters

This lab shows how separating responsibilities across lifecycle methods leads to predictable runtime behavior and easier debugging.
