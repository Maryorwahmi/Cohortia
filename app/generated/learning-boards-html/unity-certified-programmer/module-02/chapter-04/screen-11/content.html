Module 2 › Chapter 2.4 › PlayerMovement Walkthrough
Code structure (visual)
// Awake: rb = GetComponent<Rigidbody>()
// Update: read Horizontal/Vertical, detect Jump, store inputs
// FixedUpdate: rb.MovePosition(rb.position + dir * speed * Time.fixedDeltaTime)
// OnCollisionEnter/Exit: manage isGrounded
// OnDestroy: cleanup subscriptions
Explanation
  • Awake ensures component references exist before physics steps.
  • Store input in Update to capture player actions reliably every rendered frame.
  • Apply movement in FixedUpdate with Time.fixedDeltaTime for consistent physics results.
  • Use OnDestroy to remove external event listeners and avoid dangling callbacks.
Key Takeaway

This separation keeps input responsive and physics simulation stable across different frame rates.
