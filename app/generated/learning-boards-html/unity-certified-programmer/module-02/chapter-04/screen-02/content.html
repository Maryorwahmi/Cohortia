Bloom's Taxonomy
Learn → Understand → Apply → Master

These objectives progress from comprehension to applied scripting patterns you can reuse.

01
MonoBehaviour fundamentals

Recognize MonoBehaviour as the base component type and how scripts attach to GameObjects. This matters because components are how behavior is composed in Unity.

VERIFIED COMPETENCY MILESTONE
02
Awake vs Start

Explain when to gather references in Awake and when to run first-frame initialization in Start. Use Awake for GetComponent calls so they're ready for FixedUpdate.

VERIFIED COMPETENCY MILESTONE
03
Update vs FixedUpdate

Identify which logic belongs in Update for frame input and which belongs in FixedUpdate for physics to avoid jitter and inconsistent collisions.

VERIFIED COMPETENCY MILESTONE
04
Lifecycle sequencing

Describe the typical execution order and why ordering across multiple scripts matters when initializing shared state.

VERIFIED COMPETENCY MILESTONE
