Module 2 › Chapter 2.4 › FixedUpdate
Step-by-step
  1. Sample input in Update and store values in private fields.
  2. In FixedUpdate, construct moveDirection from stored inputs and normalize it.
  3. Apply movement using rb.MovePosition(rb.position + dir * speed * Time.fixedDeltaTime).
  4. Use AddForce for acceleration-based behaviors and respect ForceMode choices.
Concrete example
Store axes in Update; move Rigidbody in FixedUpdate using Time.fixedDeltaTime so movement is consistent across frame rates.
Common mistake: calling rb.AddForce inside Update—this can produce uneven physics behavior when frame rates fluctuate.
Key Takeaway

FixedUpdate is your physics loop. Sample in Update, apply in FixedUpdate using Time.fixedDeltaTime for deterministic and smooth results.
