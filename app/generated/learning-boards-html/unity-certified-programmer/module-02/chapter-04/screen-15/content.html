Module 2 › Chapter 2.4 › Quick Reference
Awake / Start

Awake: cache components. Start: interact with scene-level systems after Awake completes.

Update / FixedUpdate

Sample input in Update, apply physics in FixedUpdate with Time.fixedDeltaTime for consistent motion.

LateUpdate / OnDestroy

Use LateUpdate for camera finalization and OnDestroy to unregister and clean up resources safely.

Closing takeaway: match your code to the lifecycle timing and you'll avoid many runtime surprises.
