Module 3 › Chapter 2.5 › Key Concepts
Input Manager
Map physical controls to named axes and buttons for device-agnostic code.
Update vs FixedUpdate
Read input in Update; apply movement and forces in FixedUpdate for stability.
Method choices
Use axis methods for continuous control and Down variants for single-frame events.
Summary
These three ideas form the basis for responsive, predictable player control in Unity projects.
