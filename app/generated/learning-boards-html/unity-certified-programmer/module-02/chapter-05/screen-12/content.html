Module 3 › Chapter 2.5 › Common Mistakes & Best Practices
Mistake: Physics in Update
Leads to frame-rate dependent motion and inconsistent collisions.
Mistake: Not normalizing movement
Diagonal movement becomes faster than cardinal directions, breaking gameplay balance.
Mistake: Using hold checks for single actions
Allows repeated triggers when you expected one per press, such as multiple jumps.
Practical fixes
  • Read input in Update, apply movement in FixedUpdate, and use flags to request actions.
  • Normalize direction vectors before scaling by speed to keep consistent velocity.
  • Use Down checks for single events and verify grounded status before jumping.
