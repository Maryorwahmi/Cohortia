Module 3 › Chapter 2.5 › New Input System (Brief)
What it offers
Action maps, control schemes, event driven callbacks, and simplified remapping across devices.
When to use it
Choose it for projects requiring many device types, runtime remapping, or complex input flows across platforms.
Concrete comparison
Legacy Input Manager is quick and well suited to simple setups. The new system is more flexible but requires setup through the Package Manager and action maps.
Key Takeaway
Know both systems: legacy for quick work and exam relevance, new system for advanced device support and remapping.
