Module 3 › Chapter 2.5 › Button and Key Methods
Continuous checks
Use GetButton or GetKey to know if an input remains held. Good for sprinting while a key is pressed.
Single-press checks
Use the Down variants to trigger an action only once at the initial press moment.
Concrete example
To implement a sprint toggle, use GetKey for Left Shift so the player runs while the key is held. For a jump, use GetButtonDown or GetKeyDown to ensure one jump per press.
Common mistake
Checking GetButton every frame without a grounded guard can allow repeated jumps. Use a flag and process the jump in FixedUpdate.
Key Takeaway

Choose hold checks for continuous input and Down checks for single, immediate triggers.
