Module 3 › Chapter 2.5 › GetAxis vs GetAxisRaw
GetAxis (smoothed)
Provides interpolated floats useful for natural transitions and eased movement.
Example
Use it for camera orbit or smooth character acceleration where instant stops feel abrupt.
Pro tip: smoothing is cosmetic for input; physics must still be handled in FixedUpdate.
GetAxisRaw (immediate)
Returns -1, 0, or 1 for exact controller or key states, without interpolation.
Example
Choose raw input for precise movement or grid based controls where latency matters.
Check
If movement feels slippery, try the raw axis or normalize and control acceleration explicitly.
Key Takeaway
Pick smoothing based on game feel. GetAxis for eased motion; GetAxisRaw for immediate response.
