Module 3 › Chapter 2.5 › Activity: Mouse Look
Setup
  • Create a Plane and a Capsule named Player with a Rigidbody.
  • Tag the Plane as Ground and child the Main Camera to Player.
  • Attach the PlayerController script and expose mouseSensitivity and playerCamera.
Test
  • Enter Play Mode. Use W A S D to move and Space to jump.
  • Move the mouse to rotate and pitch the camera; press Esc to unlock the cursor if needed.
Checks & Troubleshooting
Is the camera pitch clamped? If you can flip upside down, clamp angles.
Is diagonal movement faster? Ensure move vector is normalized before scaling by speed.
Are jumps repeated? Use GetButtonDown and a grounded flag processed in FixedUpdate.
Key Takeaway
This lab combines input mapping, mouse look, and physics-safe movement to create a playable controller you can iterate on.
