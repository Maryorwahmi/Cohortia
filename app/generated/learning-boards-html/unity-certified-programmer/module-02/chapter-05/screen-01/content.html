Input Management & Basic Player Control
Understand named axes and buttons, frame vs physics timing, and build a PlayerController that moves and jumps.
In this lesson
  • Input Manager basics: axes vs buttons and mapping.
  • Use Update to read input and FixedUpdate to apply physics.
  • Practical PlayerController: movement, jump, mouse look.
Coming up
  • GetAxis, GetAxisRaw, GetButtonDown and GetKey usage.
  • Ground checks, cursor lock, and common mistakes to avoid.
What's important
Input polling frequency and where you apply movement determine feel and stability for player control.
Visual Concept
Axes (continuous)
Horizontal, Vertical, Mouse X/Y — return a float between -1 and 1
Buttons (discrete)
Jump or Fire actions that trigger on press or release
Pattern
Read input in Update, apply forces or MovePosition in FixedUpdate for stability
