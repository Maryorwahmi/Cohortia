Module 3 › Chapter 2.5 › Update vs FixedUpdate
Step 1 — Gather Input
In Update read axes and button presses. Store results in private variables for later use.
Step 2 — Apply Physics
In FixedUpdate use stored input values to call MovePosition or AddForce on the Rigidbody.
Analogy: Update is the sensor, FixedUpdate is the actuator that runs on a steady beat.
Example flow
  1. Read Horizontal and Vertical into a move vector in Update.
  2. If Jump is pressed set jumpRequested true in Update.
  3. In FixedUpdate MovePosition using the stored vector.
  4. If jumpRequested then AddForce up and clear the flag.
Common mistake
Applying physics in Update causes frame-rate dependent movement and inconsistent collisions.
