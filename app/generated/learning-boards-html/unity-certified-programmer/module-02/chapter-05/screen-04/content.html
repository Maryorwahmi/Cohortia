Module 3 › Chapter 2.5 › Axes and Buttons
What is an Axis?
An axis returns a float value often from minus one to one. Use it for continuous motion and analog input like joystick sticks or mouse delta.
What is a Button?
A button yields a boolean. It's ideal for single events such as jumping, firing, or opening a menu.
Example
Map Horizontal to keys and sticks. Use the Input GetAxis method and multiply the value by speed to move the player smoothly.
Misconception
Treating an axis like a button causes logic errors. Don't compare an axis to true; compare its numeric value instead.
Visual
Axis: Horizontal
Value range: -1 .. 0 .. 1
Button: Jump
State: pressed or not pressed
Key Takeaway

Pick axis methods for analog values and button methods for single events to match gameplay intent.
