Module 2 › Chapter 2.3 › Prefab Variants
What it does

Specialize without duplication

Variants inherit all properties from a base Prefab but may override specific fields. They keep a link back to the parent so shared changes propagate.

When to use
  • Multiple similar enemies with small differences.
  • Item families where base stats are shared but visuals differ.
  • UI elements that share layout but differ in text or icons.
Concrete example
BaseEnemy → MeleeEnemy, RangedEnemy

The base contains movement and health. Variants swap weapons and tweak damage. Updating the base movement affects both variants automatically.

Common mistake

Overriding too many fields in variants defeats the purpose of inheritance. Keep variants focused on small differences.

Key Takeaway

Use Prefab Variants to maintain a central source of truth while allowing controlled specialization for variants.
