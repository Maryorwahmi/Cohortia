Module 2 › Chapter 2.3 › What is a Prefab?
Definition

Prefab = Template

A Prefab asset stores a GameObject configuration so you can reuse it as many times as needed across scenes and builds.

Primary benefits
  • Reusability: author once, use many times.
  • Consistency: instances share the same base properties.
  • Efficiency: change the asset to update all instances.
Key Takeaway

Use Prefabs whenever you need multiple similar objects. They save time and keep behavior consistent across scenes.

Concrete example
Coin collectible

Create a small cylinder, set scale and rotation, add Rigidbody and trigger collider, apply a yellow material, then drag it into Prefabs to make a reusable coin asset.

Overrides explained

When you change one instance, the inspector shows overridden fields in bold. These overrides are local until you Apply All to push them to the Prefab asset.

Common mistake

Assuming an instance change creates a new Prefab. It only creates an override unless you apply it to the asset.

Pro tip

Keep a single Prefabs folder per project section to stay organized and avoid duplicate assets.
