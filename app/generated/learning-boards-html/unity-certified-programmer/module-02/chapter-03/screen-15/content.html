Module 2 › Chapter 2.3 › Key Concepts — Part 2
Prefab
An asset template in Project used to create consistent GameObjects across scenes.
Overrides
Local instance changes that differ from the Prefab asset; shown in bold in the Inspector.
Prefab Variant
A specialized Prefab that inherits from a base Prefab and can override specific fields while keeping shared updates.
Final takeaway

Decide deliberately whether a change belongs on the asset (global) or an instance (local). That choice keeps collaboration and iteration predictable and reduces bugs.
