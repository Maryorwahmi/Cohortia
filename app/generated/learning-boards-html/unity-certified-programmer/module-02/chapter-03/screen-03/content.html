05
Save scene & Build Settings

Ensure any scene you want packaged is saved as a .unity file and added to Scenes In Build so it appears in the final build.

06
Create a Prefab

Drag a configured Hierarchy object into a Prefabs folder; the Hierarchy instance becomes linked to an asset in the Project window.

VERIFIED COMPETENCY MILESTONE
07
Overrides & Apply/Revert

Make local changes to an instance, then apply them to the asset or revert to restore base values. This controls global vs local edits.

VERIFIED COMPETENCY MILESTONE
08
Prefab Variants

Create specialized Prefabs that inherit from a base Prefab, keeping shared updates while allowing differences in variants.

VERIFIED COMPETENCY MILESTONE
Mnemonic
Scene = Stage. Prefab = Template. Variant = Specialized Template. Overrides = local edits.
Use this mental model when planning levels: stage your layout, then populate with templates that you can tweak per instance.
