Module 2 › Chapter 2.3 › Prefab Instances vs Prefab Asset
Comparison
Prefab Asset (Project)

The stored template in Project. Editing this updates all instances unless they have an override for that field.

Prefab Instance (Hierarchy)

A placed copy in a scene. It links to the asset but can have local overrides visible in bold in the Inspector.

Use Apply All to promote an instance change to the asset. Use Revert All to discard instance changes and restore the asset's values on that instance.
Example
Changing collider radius

Change the collider radius on the Prefab asset and observe how all scene instances update. Change the Y-position on a single instance and decide if that override should be applied globally or reverted.

Common mistake

Applying an accidental local tweak globally can overwrite deliberate variations. Review overrides before using Apply All.

Checkpoint

Pick one instance, change a property, then practice Apply All and Revert All to observe the difference in behavior.
