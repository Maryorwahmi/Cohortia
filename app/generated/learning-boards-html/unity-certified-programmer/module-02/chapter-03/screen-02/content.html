01
Explain Scenes

Describe how Scenes group GameObjects and represent levels or UI states. This skill helps you plan game flow and modularize content.

VERIFIED COMPETENCY MILESTONE
02
Create & Load Scenes

Save scenes as .unity files, add them to Build Settings, and load them with SceneManager.LoadScene when transitioning between levels.

VERIFIED COMPETENCY MILESTONE
03
Author Prefabs

Turn a configured GameObject into a reusable Prefab asset and place instances across scenes to ensure consistency and speed up iteration.

VERIFIED COMPETENCY MILESTONE
04
Manage Instances & Variants

Create overrides, use Apply All or Revert All, and build Prefab Variants for controlled specialization without duplication.
