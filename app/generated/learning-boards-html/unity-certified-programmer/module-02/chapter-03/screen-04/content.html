Module 2 › Chapter 2.3 › What is a Scene?
Definition

Scene = Stage

A Scene groups the objects that exist together at a particular moment. It’s saved as a .unity file and represents a single level or UI state.

Why it matters
  • Limits memory usage by loading only needed content.
  • Makes iteration faster by focusing on smaller units.
  • Enables structured level design and transitions.
Key Takeaway

Scenes scope which objects exist together; plan scenes to isolate unrelated functionality for performance and clarity.

Example
Main Menu Scene

Contains UI canvas, menu scripts, and a camera. No level geometry or enemies.

Level1 Scene

Contains terrain, player spawn, enemies, and lighting relevant to the first level.

Common mistakes
  • Forgetting to add a developed scene to Build Settings so it’s omitted from the final build.
  • Keeping unrelated systems in the same scene, making iteration slower.
