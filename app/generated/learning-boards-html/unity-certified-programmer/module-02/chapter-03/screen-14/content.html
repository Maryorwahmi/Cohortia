Module 2 › Chapter 2.3 › Key Concepts — Part 1
Scene
A .unity file that contains all objects for a level or UI state.
SceneManager
API used to load and unload scenes programmatically at runtime.
Build Settings
Window where you add scenes to include them in the final build packaging.
Summary

These four concepts form the structural backbone of scene and build management. Keep them in mind when organizing levels and code-driven transitions.
