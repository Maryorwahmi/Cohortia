Module 2 › Chapter 2.3 › Create a Prefab: Step-by-step
Step-by-step
  1. Configure GameObject in Hierarchy (children, components, material).
  2. Create Prefabs folder in Project window.
  3. Drag GameObject from Hierarchy into Prefabs folder to create the asset.
  4. Place instances in scenes by dragging the Prefab asset into the Scene view.
Editor indicators

After making a Prefab, hierarchy entries show a blue icon and bold inspector fields for overrides. This visual feedback helps track links between instances and the asset.

Concrete scenario
Coin prefab lab

Make a cylinder named Coin, set Transform to (0,0.5,0), rotate to lay flat, scale to coin size, add Rigidbody and trigger collider, then drag into Prefabs. Place several coins in the scene to create a collectible spread.

Apply change

Select the Prefab asset and change a property, then see all placed instances update immediately.

Misconception

Don't duplicate objects for mass placement. Use Prefabs to preserve a single source of truth.
