Module 2 › Chapter 2.3 › Create, Save, and Load Scenes
Steps
  1. Create a new scene: File → New Scene.
  2. Save the scene: File → Save Scene As... and name it, e.g., CollectibleScene.unity.
  3. Open File → Build Settings and add scenes to Scenes In Build to include them in builds.
  4. Load scenes at runtime using SceneManager.LoadScene with the scene name or index.
Additive loading note

Load multiple scenes together when you want persistent UI or separate lighting/environment layers without merging everything into one scene.

Example code (visual)
// Example usage: load scene by name
using UnityEngine.SceneManagement;
...
SceneManager.LoadScene("Level1");
// Or load additive
SceneManager.LoadScene("UI_Scene", LoadSceneMode.Additive);
Try this

Create CollectibleScene, save it, and add it to Build Settings. Then call LoadScene by name from a simple UI button script to switch to it.

Misconception

Saving a file does not automatically include it in builds; Build Settings is the gatekeeper for packaging scenes.
