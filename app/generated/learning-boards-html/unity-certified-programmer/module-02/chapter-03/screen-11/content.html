Module 2 › Chapter 2.3 › Lab: Create and Manage a Collectible Prefab
Lab steps
  1. Create a new scene and save as CollectibleScene.unity.
  2. GameObject → 3D Object → Cylinder, rename to Coin, set Transform and scale.
  3. Add Rigidbody: Use Gravity unchecked, Is Kinematic checked. Set collider Is Trigger.
  4. Create a Prefabs folder, drag Coin into it to create the Prefab asset.
  5. Drag multiple Prefab assets into the scene to place instances.
  6. Modify the Prefab asset and observe instances updating. Change an instance and practice Apply All or Revert All.
Working through the lab makes the relationship between asset and instance concrete. Take time to observe inspector indicators and the Overrides dropdown so you know how to push or discard changes correctly.
Checkpoint
Test scenario

Change collider radius on the Prefab asset, then change the Y-position of one instance and use Apply All. Observe which properties change across all instances and which remain unique.

Troubleshooting

If instances don't update after editing the asset, confirm you edited the asset in the Project window and not a duplicate asset with a similar name.

Lab takeaway

This lab builds confidence with Prefab lifecycle: author, create asset, place instances, and manage overrides deliberately.
