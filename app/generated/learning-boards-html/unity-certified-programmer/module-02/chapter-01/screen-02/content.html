How to practice
  • Create a cube, move it with W, rotate with E, scale with R, and confirm the Transform values in the Inspector.
  • Frame the Main Camera with the F key and observe how its view differs from the Game view when played.
  • Drag Console into a new dock and save the layout as a named preset to recall later.
Practical Note

Practice these objectives in order: identify windows, navigate, manipulate objects, then save a layout for repeatable work.
