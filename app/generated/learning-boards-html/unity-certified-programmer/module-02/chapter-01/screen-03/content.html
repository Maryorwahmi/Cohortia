Module 2 › Chapter 2.1 › Practice Steps
Starter checklist
  1. Open a new 3D Core project and locate the six core windows visually.
  2. Create a Cube and watch the Transform component change as you edit.
  3. Practice camera controls: orbit, pan, zoom, WASD movement, and frame selection.
  4. Dock Console next to Project, move Game to sit beside Scene, and save layout as "MyCustomLayout".
Quick visual mnemonics
Scene = sandbox. Game = final camera view.
Hierarchy = parent-child structure; children inherit transforms.
Key Takeaway

Do the short checklist twice: first to observe, second to internalize the keybindings and window roles.
