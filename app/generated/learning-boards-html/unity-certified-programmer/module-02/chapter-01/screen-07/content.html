Parent-Child Model
The Hierarchy displays GameObjects as a nested tree. Parents provide a coordinate frame for children. Use empty GameObjects as organizational roots and to control groups of objects together.
Example: Vehicle
VehicleRoot (parent) with WheelFL, WheelFR, Body as children. Moving VehicleRoot moves all wheels and body together.
Local vs World
Children show local Transform values in the Inspector; world position changes when the parent moves even if local values stay the same.
Practice
Step
Create an empty GameObject named VehicleRoot and a Cube as child. Move VehicleRoot and observe child's world movement while its local values remain.
Tip
Use clear naming and folder-like grouping to avoid selection mistakes and accidental parenting.
Common Mistake

Scaling a parent can unexpectedly distort children; check child geometry after large parent scale changes.
