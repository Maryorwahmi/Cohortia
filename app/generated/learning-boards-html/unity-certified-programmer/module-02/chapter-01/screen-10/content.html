Edit vs Preview
Scene View
Editing canvas for arranging and tuning objects. Edits here persist when not in Play Mode.
Game View
Runtime preview showing camera output and runtime effects; use it to validate player experience.
Practical Rule
Treat Play Mode as a sandbox. Note desirable changes during Play, then stop and apply them in Edit Mode to make them permanent.
Example
Increase a jumpForce in Play Mode to test feel. Record the value and then set it in the Inspector after exiting Play Mode so the change persists.
Common Frustration

Many learners lose edits after testing because they forget to reapply changes made in Play Mode. Use a quick note or copy values before exiting.
