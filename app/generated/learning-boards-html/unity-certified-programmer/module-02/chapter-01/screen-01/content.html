Navigating the Unity Editor Interface
Quick orientation to the windows and controls you'll use every day.
What you'll practice
Scene navigation, transform tools, asset organization, and saving a custom layout for efficient work.
Why it matters
Good navigation and window use prevents wasted time and accidental loss of edits while testing in Play Mode.
Explore Key Topics
Scene & Game Views
Design in Scene, preview in Game to see camera output and post-processing effects.
Inspector & Hierarchy
Use Hierarchy to structure objects and Inspector to tune components and transforms.
Project & Console
Organize assets in Project and watch Console for logs, warnings, and errors while testing.
Concept Snapshot
Scene: interactive 3D workspace for arranging objects and composing levels.
Game: the runtime camera output used for testing the player's view and final rendering.
Play Mode: temporary runtime state; changes made while running are not saved after you stop.
Key Takeaway

Treat the Editor as a workspace: learn windows, practice navigation, and avoid editing permanent values during Play Mode.
