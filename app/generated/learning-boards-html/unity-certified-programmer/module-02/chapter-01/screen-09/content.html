Module 2 › Chapter 2.1 › Inspector
Components & Properties
Inspect and edit components attached to GameObjects. Components encapsulate behavior and data; the Transform is always present. Adding or removing components changes the GameObject's capabilities.
Script Variables
Public or serialized fields in scripts show up in the Inspector for tuning without code changes.
Asset Import Settings
Selecting an asset shows import options such as texture compression or model scale which affect how it appears at runtime.
Concrete Example
Add a Rigidbody
Select Cube, click Add Component > Physics > Rigidbody, then adjust mass and drag. Test behaviour in Play Mode to see physics react to forces.
Warning

Avoid relying on Play Mode edits. Use Inspector edits outside Play Mode for changes you want to keep.
