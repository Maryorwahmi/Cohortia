Layout Actions
Dock & Float
Drag window tabs to dock them in different positions or float them as separate windows for multi-monitor setups.
Save Layout
Use Window > Layouts > Save Layout to record your arrangement with a descriptive name for reuse.
Use Cases
Level Design
Scene + Game side-by-side with Inspector and Hierarchy visible for rapid placement and testing.
Scripting
Project, Console, and Inspector prominent so you can edit scripts and see errors quickly.
Key Takeaway

Save several named layouts for common tasks to reduce context switching and setup time.
