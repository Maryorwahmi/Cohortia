Asset Management
Treat the Project window as the repository for all source files. Create clear top-level folders for Scripts, Models, Materials, Audio, and Scenes. Avoid long, deep folder trees that make items hard to locate.
Importing
Drag files from your OS into Project to import. Then drag assets into Scene or Hierarchy to instantiate them.
Prefabs
Use prefabs for reusable objects so you can update the original and propagate changes to instances.
Concrete Example
Import & Place Model
1) Drag a model into Project. 2) Drag model from Project into Scene. 3) Select instance and inspect material and scale settings in Inspector.
Common Pitfall

Deleting assets from Project removes the source file and can break scenes that reference it. Use version control and a clear folder policy.
