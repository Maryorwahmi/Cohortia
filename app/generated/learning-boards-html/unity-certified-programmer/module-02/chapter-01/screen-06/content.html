Module 2 › Chapter 2.1 › Transform Tools
Tool Definitions
Move (W)
Drag axis handles to adjust position. Use the Inspector for exact coordinates.
Rotate (E)
Rotate around axes with circular gizmos; watch rotation values update in the Inspector.
Scale (R)
Resize uniformly or per-axis; remember parent scaling affects children.
Concrete Example
Create a Cube
1) GameObject > 3D Object > Cube. 2) Press W, drag Y handle up. 3) Verify Y value in Inspector changed. 4) Press E, rotate 45 degrees around Y and confirm.
Common Mistake

Editing transforms in Play Mode seems to work but will be lost when you stop. Make permanent edits outside Play Mode.
