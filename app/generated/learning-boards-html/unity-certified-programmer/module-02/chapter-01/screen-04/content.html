Module 2 › Chapter 2.1 › Core Windows
Window Roles
Scene View
Interactive 3D workspace for arranging objects and composing levels.
Game View
Player's camera output used to preview rendering and UI at runtime.
Hierarchy
Lists scene GameObjects and parent-child relationships that determine transform inheritance.
Inspector, Project & Console
Inspector
Shows components and properties of selected object; edit values to change behavior or appearance.
Project
Asset browser reflecting the Assets folder. Drag assets into Scene or Hierarchy to instantiate.
Console
Displays Debug.Log information, warnings, and errors. Use it to trace and fix issues as you test.
Key Takeaway

Each window has a single strong purpose; combine them in sequence to build, test, and debug efficiently.
