Module 7 › Chapter 7.6 › Debug Strategies
Reproduce
Make the bug occur consistently; vary input or timing until it is repeatable.
Isolate
Remove unrelated systems and create a minimal scene that still shows the bug.
Divide & Conquer
Comment out code blocks until the bug disappears, then reintroduce sections to find the exact cause.
Inspect & Verify
Use logs and breakpoints to confirm variable values and execution order, and validate assumptions explicitly.
Document
Record the root cause and the chosen fix so the same issue is easier to avoid in the future.
