Module 7 › Chapter 7.6 › Index & Argument Errors
IndexOutOfRangeException
Occurs when accessing an index outside a collection's bounds. Validate counts and prefer safe loops.
Prevention:
  • Check index < collection.Count before access.
  • Use foreach when you don't need an index.
  • Log collection sizes when unexpected indices occur.
Argument exceptions
Throw or log clear messages when methods receive invalid arguments so callers know what's wrong.
if (index < 0 || index >= myList.Count) {
  Debug.LogError("Invalid index " + index + " for list of size " + myList.Count);
  return;
}
Key Takeaway

Validate indices and arguments at method entry. Clear logs make reproducing errors faster.
