Debug.Log family
Clear levels: info, warning, error, and assertions for failed assumptions.
IDE Debugger
Attach, breakpoint, step, and inspect to observe exact runtime state and call stacks.
Conditional Compilation
Use #if UNITY_EDITOR to keep editor-only debug code out of release builds.
Takeaway
Combine targeted logging, editor-only compilation, and IDE breakpoints within a repeatable debugging process to find and fix issues reliably.
