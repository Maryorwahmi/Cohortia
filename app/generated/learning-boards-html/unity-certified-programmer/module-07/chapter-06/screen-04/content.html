Module 7 › Chapter 7.6 › Why debugging matters
What debugging is
Locate, understand, and fix runtime errors so your game behaves as intended before you optimize.
• Reproduce the failure consistently so you can test fixes.
• Isolate the smallest scene or code path that demonstrates the bug.
• Use assertions and targeted logs instead of noisy prints in Update loops.
Key Takeaway

Correctness first. Fix the bug before spending time on performance.

Analogy: medical diagnosis
You wouldn't treat symptoms without identifying the disease. Debugging finds the cause, not just the symptom.
Common mistake
Overlogging everywhere, especially in Update, which can hide the error and reduce performance.
Try this
Reproduce a bug, then remove unrelated systems until the failure remains — that minimal reproduction is what you debug.
