Module 7 › Chapter 7.6 › NullReferenceException
What causes an NRE
Accessing a member on a reference that is null. Common when inspector fields are not assigned or runtime finds fail.
Prevention tips:
  • Check for null before using a reference and log a clear message.
  • Use Debug.Assert to fail fast in the Editor when an invariant is violated.
  • Initialize references where possible and verify Inspector assignments.
Example scenario
public Rigidbody playerRigidbody; // left unassigned
void Update() {
  // This will throw a NullReferenceException if playerRigidbody is null
  playerRigidbody.AddForce(Vector3.up * jumpForce, ForceMode.Impulse);
}

// Safer:
void Update() {
  if (playerRigidbody == null) {
    Debug.LogWarning("Player Rigidbody is not assigned!");
    return;
  }
  playerRigidbody.AddForce(Vector3.up * jumpForce, ForceMode.Impulse);
}
Key Takeaway

Guard references and prefer clear logs or assertions to catch missing assignments early.
