Module 7 › Chapter 7.6 › Message logging
Debug.Log family
Informational, warning, error, and assertions for runtime visibility.
• Debug.Log: general info and variable prints used for quick checks.
• Debug.LogWarning: highlight suspicious conditions that deserve attention but don't stop execution.
• Debug.LogError: show critical failures that often cause incorrect behavior or crashes.
• Debug.Assert: validate assumptions and pause the Editor when an important condition is false.
Common mistake
Leaving many logs in Update loops, which produces high-volume output and potential performance impact.
Code examples
// Informational
Debug.Log("Informational message.");

// Warning
Debug.LogWarning("Potential issue here!");

// Error
Debug.LogError("Critical error!");

// Assertion
Debug.Assert(playerRigidbody != null, "Player Rigidbody must be assigned");
Key Takeaway

Use the right level for clarity. Assertions help catch broken assumptions early in development.
