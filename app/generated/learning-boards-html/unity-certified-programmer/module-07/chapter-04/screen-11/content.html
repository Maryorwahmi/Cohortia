Module 07 › Chapter 7.4 › Lighting & Shadows
Core idea

Bake static light, probe dynamic light

Use lightmaps for static geometry to eliminate real-time lighting cost. Use light probes and reflection probes to give dynamic objects plausible lighting and reflections without per-frame expensive calculations.

Concrete example

Bake all static buildings and street fixtures. Place light probes along paths where players and NPCs move so they receive interpolated baked lighting during gameplay.

Performance tips
  • Reduce shadow distance and resolution for less GPU cost.
  • Limit real-time shadow casters to key moving objects.
  • Use reflection probes for static reflection capture where possible.
Pitfall
Failing to mark objects static prevents them from benefiting from light baking and wastes runtime resources.
