Module 07 › Chapter 7.4 › Learning Objectives — Apply
Measure draw calls

Open the Profiler or Stats window, record a short run, and note batched draw counts. Apply batching or instancing and re-run to compare.

Example: 500 trees reduced to 2–5 batches
Pitfall: Different materials block batching
VERIFIED COMPETENCY MILESTONE
Validate texture savings

Compare GPU memory and load times after compression and mipmaps. Check distant textures for acceptable quality.

Example: Use ASTC or ETC2 for mobile
Pitfall: Over-compressing causes visible artifacts
VERIFIED COMPETENCY MILESTONE
Check lighting and probes

Bake lightmaps, place light probes, and move dynamic objects to check that lighting remains plausible without costly real-time lights.

Example: Baked shadow for static architecture
Pitfall: Forgetting to mark objects static blocks baking benefits
VERIFIED COMPETENCY MILESTONE
Audit shaders and overdraw

Profile fragment cost, simplify expensive shader calculations, and replace alpha-blended geometry with alpha-clipping where practical.

Example: Replace blended leaves with clipped cards
Pitfall: Blindly reducing quality without measuring
VERIFIED COMPETENCY MILESTONE
