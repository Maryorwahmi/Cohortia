Module 07 › Chapter 7.4 › Sprite Atlases
Problem

Many sprite draw calls

Multiple sprites using separate textures lead to material switches and many draw calls. Atlases reduce those material swaps.

Concrete example

A UI composed of dozens of icons from one atlas can render with a single material and far fewer draw calls compared to separate textures for each icon.

Pitfall: Oversized atlases may be inefficient to compress on some platforms; balance packing with platform constraints.
How to approach
  • Group sprites that render together into the same atlas.
  • Ensure the sprites use the same material so batching can occur.
  • Test on target platforms to confirm compression and memory are acceptable.
Good

UI icons and frequently co-rendered sprites.

Avoid

Packing rarely used sprites into the same atlas as high-frequency ones without need.

Check
Use the Sprite Atlas system and test draw call counts in the Profiler.
