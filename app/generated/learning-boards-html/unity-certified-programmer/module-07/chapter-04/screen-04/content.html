Module 07 › Chapter 7.4 › Draw Calls
Definition

What is a draw call?

A CPU-issued command to the GPU to render a set of geometry with a specific material and state. Each call adds submission cost regardless of triangle count.

Quick bullets
  • Every separate material or mesh can cause a new draw call.
  • CPU overhead often limits draw call scalability before the GPU is saturated.
  • Grouping similar objects reduces submissions and improves steady frame rates.
Key Takeaway

Measure draw calls first; then group and batch where it reduces CPU overhead without harming visuals.

Visual analogy & guided example
Analogy

Many small dishes = many draw calls. One combined pot = fewer calls with lower overhead.

Concrete example

500 separate trees with unique materials produce far more draw calls than the same trees using a shared material and instancing or batching.

Common misconception

It’s easy to assume the GPU is the only bottleneck. Often the CPU’s draw call submission is the limiting factor — measure both sides before optimizing.
