How static batching works

Static batching

Combine non-moving GameObjects sharing the same material into large meshes at build time. This reduces per-frame draw calls for static geometry with zero runtime merge cost.

Steps
  1. Mark GameObjects as Static in the Inspector.
  2. Ensure shared materials across objects.
  3. Bake lighting and generate to finalize build-time combining.
Common mistake: marking many objects static without checking light bake or load-time impact.
Dynamic batching

When dynamic batching applies

Unity can combine many small moving meshes at runtime if they meet vertex and shader restrictions. It’s automatic when conditions are met but has strict limits on vertex count and shader variants.

Good for

Small props like bullets, small debris, or simple enemies.

Bad for

Skinned meshes, large vertex-count objects, or complex shaders.

Try
Group small dynamic props under a shared material.
Pitfall
Assuming dynamic batching removes the need for instancing for many moving copies.
