Module 07 › Chapter 7.4 › Occlusion Culling
What it does

Skip hidden objects

Occlusion culling precomputes which objects are visible from different parts of the scene so Unity doesn’t render objects fully hidden behind occluders.

Bake steps
  1. Open Occlusion Culling window and mark occluders/occludees.
  2. Adjust cell size and smallest occluder settings.
  3. Run Bake and test in Play mode while surveying hidden object counts.
Practical impact

In a crowded urban scene, large building facades occlude distant streets. With occlusion culling baked, those distant objects aren’t submitted to the GPU, saving both CPU and GPU time.

Good to know

Only fully hidden objects are culled; partial visibility still renders normally.

Dynamic objects

Dynamic objects may need scripts or disabled/ enabled flags to interact with baked occlusion correctly.

Check
After baking, observe the Renderer counts in the Profiler and ensure previously hidden objects no longer appear in the rendered set.
