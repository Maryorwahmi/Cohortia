Module 07 › Chapter 7.4 › Key Concepts — Part 1
Draw Call
A CPU command to render geometry. Lower counts reduce CPU overhead.
Static Batching
Combine static meshes with the same material at build time to lower draw calls.
GPU Instancing
Render many identical meshes in one draw call with per-instance data like transform or tint.
Summary

Use these concepts as first checks when a scene’s render performance drops: measure, group, and re-measure.
