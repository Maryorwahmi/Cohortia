Module 07 › Chapter 7.4 › GPU Instancing
Definition

What instancing does

Instancing issues a single draw command to render many copies of the same mesh while supplying per-instance data. It minimizes CPU-to-GPU overhead for repeated geometry.

Concrete example

A field of identical grass blades can render with dramatically fewer draw calls when instanced, while each blade still gets its own position and slight color variation.

Misconception: Instancing always wins. It only helps when meshes and materials are the same and shader supports instancing.
How to enable
  • Use a shader that supports GPU instancing (many Standard/URP/HDRP shaders do).
  • On the material inspector, check "Enable GPU Instancing."
  • Provide per-instance data where needed, such as color or transform matrices.
Good fit

Many moving copies with identical material.

Not fit

Unique materials or heavy per-instance shader variants.

Check
After enabling instancing, observe batch counts in the Profiler to confirm fewer draw calls.
