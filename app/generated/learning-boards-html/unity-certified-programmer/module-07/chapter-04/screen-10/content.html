Module 07 › Chapter 7.4 › Texture Optimization
Key techniques
  • Compression: choose formats that target your platform to lower GPU memory.
  • Resolution: reduce textures that aren’t seen close-up.
  • Mipmaps: enable for 3D textures to reduce aliasing and bandwidth at distance.
  • Power-of-two: prefer sizes like 256, 512, 1024 for efficient compression.
Example
Change a distant environment texture from 2048 to 512, enable mipmaps, and set platform compression to reduce memory and maintain visual quality at distance.
Checklist
Measure

Check GPU memory usage before and after changes.

Visual test

Inspect textures at multiple distances to spot artifacts.

Pitfall
Don’t overcompress critical close-up textures; balance memory and fidelity per asset use.
