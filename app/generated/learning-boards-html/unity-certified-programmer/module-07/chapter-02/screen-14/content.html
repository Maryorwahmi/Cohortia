Module 07 › Chapter 7.2 › Interpreting GarbageCollector spikes
Common allocation patterns
  • New collections or objects inside Update()
  • Per-frame string concatenations or ToString calls
  • LINQ queries that allocate temporaries
Fixes include object pooling, caching results, using non-allocating APIs, and reusing lists. Measure before and after to confirm reduced GC frequency and smoother frames.
Warning
Blindly removing allocations without profiling can add complexity without resolving the real bottleneck.
Key Takeaway

Target and remove per-frame allocations in hot paths to reduce GC frequency and avoid frame hitches.
