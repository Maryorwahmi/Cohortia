Unity Profiler Deep Dive
Use recorded runtime data to identify CPU, GPU and memory bottlenecks, and verify fixes on target hardware.
In this lesson
Open the Profiler, interpret CPU and GPU graphs, inspect memory snapshots, and attach to a running player for accurate device data.
CPU Usage
Find script and physics hotspots per frame and expand call timelines to find costly methods.
GPU Usage
Diagnose draw calls, shader cost, and overdraw to relieve GPU pressure.
Memory
Track textures, meshes, audio, managed heap, and snapshots to find leaks and GC causes.
Visual overview
Profiler window
Timeline graphs for time and memory, with a detailed frame view below.
Deep Profiling
Enables per-method sampling for precise CPU hotspots; expect heavy overhead while enabled.
Key Takeaway

Use the Profiler data to choose the right optimization: fix the heavy sub-system, not where it only appears to be slow.
