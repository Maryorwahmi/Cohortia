Module 07 › Chapter 7.2 › Profiling Audio, Physics, and UI
Audio
Watch for expensive DSP chains or too many simultaneous audio sources that drive CPU time.
Physics
Large numbers of active rigid bodies, complex colliders, or continuous collision detection can be costly.
UI
Frequent Canvas rebuilds or dynamic layout changes can unexpectedly consume CPU.
Practical examples
  • Batch audio sources or reduce effects to lower DSP cost.
  • Use simpler colliders or deactivate off-screen physics objects.
  • Minimize per-frame UI element changes and cache computed values.
Key Takeaway

Don't assume CPU/GPU alone; check Audio, Physics, and UI modules for expensive behavior that affects frame time.
