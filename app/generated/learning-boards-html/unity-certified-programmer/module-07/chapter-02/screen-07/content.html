Module 07 › Chapter 7.2 › Deep Profiling vs. Sampling
Sampling
Low-overhead mode that gives you enough data to find which subsystem or frame needs attention.
  • Fast, minimal distortion of runtime.
  • Good for iterative tuning and spotting large spikes.
Deep Profiling
Records per-method call data for C# to identify exact call sites and allocations.
  • High overhead; changes timings while active.
  • Use only to inspect difficult call chains after sampling points you to them.
Decision checklist
Start with sampling
Enable deep profiling if sampling can't isolate a method
Disable deep profiling before final validation
