Module 07 › Chapter 7.2 › GPU Usage module
GPU categories
Draw Calls — number of separate rendering commands.
Shader — per-pixel calculations and lighting cost.
Shadows — shadow map rendering cost.
PostProcessing — screen-space effects that add cost.
Optimization approaches
  • Combine meshes and materials to reduce draw calls.
  • Simplify or LOD shaders to lower per-pixel cost.
  • Reduce overdraw by minimizing transparent layers.
Why this matters
GPU-limited frames can't be fixed by changing C# code alone — you must address draw calls and shader complexity.
Key Takeaway

Identify whether draw calls, shaders, or overdraw drive GPU time, and then apply targeted rendering optimizations.
