Frame budget concept
Match frame processing time to the target framerate's budget. For 60 FPS aim for <= 16.7 ms per frame; for 30 FPS <= 33.3 ms.

Memory and GC pauses
Interpretation rule: find the subsystem whose time exceeds the budget or is closest to it. If GPU time is dominant, focus on draw calls and shaders. If CPU scripting spends most time, drill into Update and physics. If GC spikes align with hitches, address allocations.
Key Takeaway

Use frame budgets as the decision criterion: optimize the subsystem that prevents your frames from meeting the target time.
