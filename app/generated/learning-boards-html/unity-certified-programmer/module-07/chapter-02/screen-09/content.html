Module 07 › Chapter 7.2 › Memory module fundamentals
What you can inspect
  • Breakdown by asset type: Textures, Meshes, AudioClips.
  • Managed heap size and GC-related allocations.
  • Native allocations and engine memory usage.
Snapshot workflow
Take a snapshot, perform actions that might allocate memory, take another snapshot, and compare to see which objects were allocated and not released.
Practical checks
  • Look for objects with unexpectedly long lifetimes.
  • Search for allocations in Update or frequent object creation.
Key Takeaway

Snapshots and comparisons reveal retained references and leaks; correlate GC spikes with managed heap growth for root cause.
