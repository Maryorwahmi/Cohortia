Module 07 › Chapter 7.2 › Attach the Profiler to a running player
Build settings checklist
  • Enable Development Build so profiling data is included.
  • Enable Autoconnect Profiler to allow the Editor to connect automatically.
  • Run the build on your target device and select it from the Active Profiler list.
Once connected, record scenarios that reproduce issues on the device. Compare these recordings to Editor captures and note differences in CPU, GPU, and memory patterns.
Why this matters
Hardware, drivers, and platform services change performance characteristics. Device profiling reveals true bottlenecks.
Key Takeaway

Always validate critical performance fixes on the target hardware using a Development Build with Autoconnect Profiler.
