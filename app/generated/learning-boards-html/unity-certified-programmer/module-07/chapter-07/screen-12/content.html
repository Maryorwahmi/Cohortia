Module 8 › Chapter 7.7 › Activity: Build & Analyze
Step-by-step lab
  1. Make a baseline non-development build and open the Build Report.
  2. Record total size and top assets by size.
  3. Change Player Settings for mobile: IL2CPP, .NET Standard 2.1, Managed Stripping = Medium.
  4. Prefer modern Graphics APIs and set ASTC where applicable.
  5. Create a low mobile quality preset and rebuild.
  6. Compare reports and iterate on big assets.
Scenario
You find a 500MB audio clip in the baseline. Recompress or trim it and check how much the total build decreased in the second report.
Key Takeaway

Measure the effect of each setting change by comparing Build Reports — data guides decisions.
