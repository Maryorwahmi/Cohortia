Reading the Build Report
Open the Editor log after a build and find the Build Report section showing Used Assets and sizes.
Sort by size and inspect the top entries for textures, audio, and large meshes.
Compare two reports to measure the effect of optimizations.
Concrete example
If a texture shows as 1GB, check platform compression, mipmap settings, and whether multiple variants are included unintentionally.
Quick walkthrough
// Build report steps (visual)
1. Build (non-development)
2. Open Editor.log
3. Find 'Build Report' section
4. Sort 'Used Assets' by size
5. Address top entries
Key Takeaway

Use the Build Report to find real savings. Measure before and after changes to confirm impact.
