Module 8 › Chapter 7.7 › Graphics APIs & Compression
API choices by platform
Windows: DirectX 11/12 preferred.
iOS: Metal is the modern API of choice.
Android: Vulkan offers modern performance; OpenGL ES remains for older devices.
Texture compression
Use ASTC on modern mobile devices for better quality per byte. Use DXT/BC formats for desktop where appropriate. Provide fallbacks for older hardware.
Concrete example
On Android, remove OpenGL ES from the Graphics APIs list if you target modern devices with Vulkan. Rebuild and verify no missing shader or runtime errors.
Common mistake
Keeping legacy APIs and all texture variants inflates build size and memory usage. Remove unused entries selectively.
Key Takeaway

Choose modern APIs and platform-specific compression, then verify quality and compatibility on target devices.
