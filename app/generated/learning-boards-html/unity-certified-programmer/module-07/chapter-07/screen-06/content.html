Module 8 › Chapter 7.7 › Stripping & API Level
What to change and why
API Compatibility Level: Narrower levels exclude unused assemblies and reduce binary surface area.
Managed Stripping Level: Remove unused managed code. Start with Medium and test; aggressive levels require careful checks.
Example workflow
  1. Set API Compatibility to .NET Standard 2.1 and build.
  2. Compare the Build Report for managed sizes.
  3. Increase stripping to Medium and re-test reflective code paths.
Common mistake
Enabling High or Aggressive stripping without tests may break plugins or reflection-based systems.
Key Takeaway
Treat stripping and API choices as iterative: measure, adjust, and verify important code paths.
