Module 8 › Chapter 7.7 › Objective Checks
Verification Steps
  1. Scripting backend: Change to IL2CPP, build, and note managed size in the Build Report.
  2. Managed stripping: Increase from Low to Medium, rebuild, and check for missing functionality due to reflection.
  3. Graphics APIs: Remove legacy APIs, rebuild, and confirm runtime stability on target devices.
  4. Texture compression: Recompress suspect textures and verify memory and size reduction.
Quick mnemonic
Change → Build → Inspect → Test on device.
Milestone
A verified reduction in total build size after safe stripping and asset tweaks.
