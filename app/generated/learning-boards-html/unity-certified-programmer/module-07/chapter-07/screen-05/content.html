IL2CPP vs Mono
IL2CPP
  • Converts managed code to C++ and native binaries.
  • Enables managed stripping to reduce included assemblies.
  • Better for production builds on mobile for size and security.
Mono
  • Runs managed assemblies on a Mono runtime.
  • Faster iteration and fewer build pipeline steps.
  • May include more managed overhead in final builds.
Concrete example
Switch Android to IL2CPP, enable Medium stripping, build, and check the Build Report for decreased managed size. Then test reflection-heavy features.
Misconception
IL2CPP automatically fixes performance problems. In truth, it changes how code is built and can help size and security, but profiling and optimizations are still required.
Pro tip
When testing IL2CPP builds, enable a development build once to autoconnect the profiler, then disable development flags for release.
