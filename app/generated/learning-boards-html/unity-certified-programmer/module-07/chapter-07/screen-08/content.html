Module 8 › Chapter 7.7 › Mobile Optimization
Checklist for mobile
  1. Reduce draw calls via batching and atlasing.
  2. Lower texture resolutions and use ASTC where available.
  3. Keep meshes simple and use LODs.
  4. Minimize overdraw and transparent layers.
  5. Avoid frequent allocations in Update; pool objects.
  6. Simplify physics where possible to reduce CPU cost.
Concrete example
Create a mobile quality level with low texture quality, disabled shadows, and reduced post-processing, then set it as default for your mobile platform.
Mistake to avoid
Assuming the Editor's performance equals device performance. Always profile on real hardware.
Try this
Set a frame-rate cap or quality switch to balance battery and performance on mobile devices.
