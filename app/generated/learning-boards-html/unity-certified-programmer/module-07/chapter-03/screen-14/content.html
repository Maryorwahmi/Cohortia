What to Remember › Key Concepts
Object Pooling
Pre-allocate and reuse objects to cut allocations and GC overhead.
Garbage Collection
Automatic memory reclamation that can cause noticeable pauses when it runs frequently.
Memory Allocation
Reserve memory for objects. Minimize allocations in hot paths to reduce GC runs.
Summary

Use pooling, reduce per-frame allocations, and cache expensive API calls to stabilize frame time and improve runtime experience.
