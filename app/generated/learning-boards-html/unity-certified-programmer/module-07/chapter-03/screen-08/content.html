Core Concept › Minimizing GC
Common pitfalls
  • String concatenation every frame instead of reusing builders.
  • Boxing when value types are passed to object parameters, including some Debug calls.
  • LINQ queries and closures generating temporary allocations in hot paths.
  • Allocating new collections or arrays inside Update loops.
  • Creating new WaitForSeconds instances per coroutine yield.
Quick remedies
  • Cache StringBuilder and reuse it.
  • Use overloads that avoid object parameters and boxing.
  • Cache LINQ results or avoid LINQ in Update.
  • Reuse lists/arrays and clear them instead of creating new ones.
  • Cache WaitForSeconds instances for repeated yields.
Key Takeaway

Find allocation hotspots with the Profiler and apply targeted refactors: caching, pooling, or replacing allocation-heavy APIs.
