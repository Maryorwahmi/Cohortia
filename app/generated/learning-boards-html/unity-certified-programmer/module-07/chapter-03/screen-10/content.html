Process Flow › Update / FixedUpdate
Practical rules
  • Cache GetComponent results in Awake or Start.
  • Use early return patterns to skip work when not needed.
  • Reduce frequency with timers or coroutines for noncritical tasks.
  • Move heavy work off Update; use events to trigger work only when necessary.
Example refactor
// BAD
void Update()
{
    Rigidbody rb = GetComponent<Rigidbody>();
    rb.AddForce(Vector3.forward);
}

// GOOD
private Rigidbody _rb;
void Awake() { _rb = GetComponent<Rigidbody>(); }
void Update()
{
    if (!_isActive) return; // early exit
    _rb.AddForce(Vector3.forward);
}
Why it matters

Small per-frame costs add up. Caching and frequency reduction are simple changes that produce large runtime savings.
