Hierarchy › Data Structures
Arrays
Best for fixed-size collections and fastest indexed access. Low overhead and cache-friendly.
List<T>
Flexible, good for iteration. Avoid creating new lists in Update; clear and reuse existing lists instead.
Dictionary<K,V>
Use for constant-time lookups when repeated queries by key occur each frame.
Tip
Avoid per-frame sorting and LINQ queries in hot paths. Maintain order when possible or run heavy operations on changes only.
Why it matters
Algorithmic complexity directly affects frame cost when operations run every frame. Choose structures to limit per-frame work.
