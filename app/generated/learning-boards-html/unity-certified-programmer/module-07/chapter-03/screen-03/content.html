Module 7 › Chapter 7.3 › Learning Objectives
Apply & Verify
Each objective maps to a concrete validation step in the Profiler.
Pool Implementation Milestone
Swap Instantiate/Destroy for Get/Return and record Profiler traces. Expect fewer Instantiate calls and lower GC spikes during heavy spawn periods.
VERIFIED COMPETENCY MILESTONE
Allocation Reduction Milestone
Refactor known allocators and compare GC allocations per frame. Confirm fewer allocations during the same gameplay scenario.
VERIFIED COMPETENCY MILESTONE
Update Loop Milestone
Cache components, remove per-frame lookups, and record Scripts time in the Profiler. Expect lower CPU time in Update/FixedUpdate.
VERIFIED COMPETENCY MILESTONE
API Call Milestone
Replace repeated Find/GetComponent calls with cached fields and serialized references. Verify fewer expensive API calls in the Profiler.
