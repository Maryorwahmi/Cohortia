Architecture › Unity API Efficiency
Expensive calls to avoid in hot paths
  • Camera.main (cache in Awake if used often)
  • GetComponent<T> inside Update (cache once)
  • GameObject.Find and FindObjectOfType (expensive scene-wide searches)
  • Debug.Log with value types in tight loops (boxing + string allocations)
  • API overloads that return new arrays/lists each call
Architectural patterns
  • Use SerializeField to assign references in the Inspector.
  • Centralize frequently accessed objects in managers and cache them.
  • Prefer API overloads that accept preallocated collections.
Action

Audit your project for repeated API calls in Update and replace them with cached references or inspector-assigned fields.
