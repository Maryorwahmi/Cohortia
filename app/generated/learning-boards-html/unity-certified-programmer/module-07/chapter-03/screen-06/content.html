Step-by-step
  1. Create Bullet prefab with Rigidbody and Bullet script.
  2. Add BulletSpawner GameObject and implement pool in Awake.
  3. Make BulletSpawner a singleton for easy access.
  4. Replace Instantiate with GetBullet and Destroy with ReturnBullet.
  5. Test rapid fire and compare Profiler traces.
Example: Return in Bullet
void Update()
{
    transform.Translate(Vector3.forward * speed * Time.deltaTime);
    _currentLifetime -= Time.deltaTime;
    if (_currentLifetime <= 0)
    {
        BulletSpawner.Instance.ReturnBullet(gameObject); // Instead of Destroy
    }
}
Tip: Reset Rigidbody velocity and local position in OnEnable to avoid residual state when reusing a bullet.
