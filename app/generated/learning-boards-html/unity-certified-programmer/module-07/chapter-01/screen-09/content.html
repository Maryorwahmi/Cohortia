Code Walkthrough

Avoid per-frame allocations and repeated lookups

// Bad: allocates each frame and calls GetComponent
void Update() {
  var temp = new List<int>();
  var comp = GetComponent<Rigidbody>();
  // work...
}

// Better: cache references and reuse buffers
Rigidbody cachedRb;
List<int> buffer = new List<int>(64);
void Awake() { cachedRb = GetComponent<Rigidbody>(); }
void Update() {
  buffer.Clear();
  // reuse buffer and cachedRb
}
Practical Tips
  • Cache component references in Awake or Start.
  • Use object pools for frequently spawned objects.
  • Prefer Clear() and reuse buffers instead of new allocations.
Common misconception

Tiny allocations are harmless unless they occur in tight loops; profile hot paths to decide what to optimize.
