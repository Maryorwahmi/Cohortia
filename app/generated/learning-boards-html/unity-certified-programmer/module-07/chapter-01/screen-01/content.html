Understanding Performance Bottlenecks in Unity

Find the component that actually limits your frame rate, learn the evidence you will see in the Profiler, and choose efficient fixes that preserve gameplay and memory budgets.

Concept Map
CPU
AI, Physics, Scripting
GPU
Rendering, Shaders, Textures

Explore Key Topics
Draw Calls & Batching
High draw call counts create overhead. Batching and instancing reduce CPU/GPU work.
Physics & Simulation
Many active rigid bodies and complex colliders drive CPU time. Simplify shapes or switch simulation modes.
Memory & Loading
Asset loading and retention affect memory and load times. Use addressables and unload unused assets.
