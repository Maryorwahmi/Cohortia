Key Concepts

CPU

Runs scripts, physics, and prepares rendering commands; heavy logic and many rigidbodies cost CPU time.

GPU

Responsible for drawing triangles and shaders; many unique materials or complex post-processing push GPU costs.

Draw Call

A CPU-issued command to render geometry. Reducing draw calls via batching or instancing lowers overhead.

Summary: Always profile before optimizing. That habit ensures you spend effort where it actually improves player experience.
