Quick Reference

Overdraw

Rendering the same pixel multiple times; reduce transparent layers or merge effects.

Physics Simulation

Active rigidbodies and complex colliders increase solver cost; simplify where possible.

Garbage Collection

Automatic memory cleanup that can cause hitches; reduce frequent allocations and use pooling.

Remember: frame time is the core metric. Reduce it by identifying and fixing the real bottleneck through profiling and isolated tests.
