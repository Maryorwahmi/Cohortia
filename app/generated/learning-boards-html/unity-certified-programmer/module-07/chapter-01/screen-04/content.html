Module 7 › Chapter 7.1 › CPU vs GPU
Definition

CPU and GPU responsibilities

The CPU runs logic, physics setup, and prepares rendering commands. The GPU executes rendering, shaders, and pixel work.

Look for high script or physics times in the Profiler for CPU bottlenecks.
Look for high rendering or shader times for GPU bottlenecks.
Key Takeaway

Use profiler signals to name the limiting component before optimizing.

Concrete Example
Many AI agents doing pathfinding

If each agent calculates paths every frame, CPU time rises and the profiler shows heavy script times. The GPU may appear idle while the CPU queues work too slowly.

Dense scene with unique materials

Thousands of objects with distinct materials can cause many draw calls and high GPU rendering time, even if scripts are light.
