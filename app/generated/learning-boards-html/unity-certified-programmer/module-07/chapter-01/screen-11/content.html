Module 7 › Chapter 7.1 › CPU Scenario
Activity

Create a CPU-bound test and observe the profiler

Steps
  1. Attach a heavy calculation script to multiple GameObjects.
  2. Run profiler and record script/main thread times.
  3. Disable logic or reduce agents to isolate cost.
Quick fixes to try
  • Cache references and avoid allocations.
  • Throttle work with coroutines or timers.
  • Consider job system or reducing agent frequency.
Reflection

If disabling logic reduces frame time while render cost stays steady, the CPU is the bottleneck. Plan targeted refactors accordingly.
