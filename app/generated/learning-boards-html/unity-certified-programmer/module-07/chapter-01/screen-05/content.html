Module 7 › Chapter 7.1 › Profiling Workflow
Process Flow

Profile → Isolate → Fix → Measure

01 Profile

Capture baseline frame time and profiler samples for a reproducible scenario.

02 Isolate

Disable systems one by one to see which system most reduces frame time.

03 Fix

Apply a focused change such as batching, pooling, or simplifying colliders.

04 Measure

Re-run the profiler, compare frame time, and record the result for future decisions.

Concrete example

Duplicate cubes cause a frame drop. Profile, disable rendering, then disable AI to identify whether draw calls or scripting is responsible. Fix with shared materials and instancing, then measure.

Common mistake

Changing several systems before measuring makes it impossible to know which change mattered.
