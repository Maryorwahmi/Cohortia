Architecture

Asset loading strategies and memory budgets

Key concerns
  • Initial load size and scene load times.
  • Peak memory usage and platform constraints.
  • Unloading unused assets and streaming new content.
Concrete example

Use addressables to load large character models only when entering a level, and unload them on exit to keep RAM low.

Quick checklist
  1. Compress textures for target platform.
  2. Use atlases for UI.
  3. Unload unused assets and scenes.
Key Takeaway

Plan loading and unloading to stay within memory budgets for your target platforms.
