Module 7 › Chapter 7.5 › Texture, Mesh, and Audio Optimization
Textures
  • Use platform-appropriate compression formats.
  • Enable mipmaps for 3D textures.
  • Use sprite atlases for UI elements.
Meshes
  • Reduce polygon count and use LOD groups.
  • Turn off Read/Write unless runtime modification is required.
  • Use import optimization for vertex cache efficiency.
Audio
  • Use compressed formats for most audio assets.
  • Set long music tracks to Streaming to avoid full memory load.
  • Choose Decompress On Load for short, frequently played effects when runtime CPU cost matters more than memory.
Concrete example
Switching a large background track to Streaming reduced initial memory spikes. Switching off Read/Write on static meshes lowered CPU-side duplication and reduced resident memory in snapshots.
Key Takeaway
Import settings dictate runtime costs; always validate changes with profiler snapshots.
Misconception
Disk compression does not guarantee small runtime memory; textures and audio can expand when loaded.
