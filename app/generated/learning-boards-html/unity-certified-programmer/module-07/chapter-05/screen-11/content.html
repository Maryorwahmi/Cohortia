Module 7 › Chapter 7.5 › Managed vs Unmanaged Memory
Managed Memory

C# heap and GC

The garbage collector reclaims objects with no references. Clear collections and unsubscribe events to make objects collectible.

Example
A growing List<T> that never removes entries prevents the GC from collecting the objects those entries reference.
Unmanaged Memory

Engine-owned resources

Textures, meshes and audio are allocated by the native engine. You must release or unload them and ensure no managed reference keeps them alive.

Concrete example
Resources.Load increases engine references. If you never call Resources.UnloadAsset or clear references, the unmanaged buffers persist until the engine releases them.
Key Takeaway

Design release patterns for both managed and unmanaged objects. Clear references, destroy engine objects when appropriate, then verify with profiler snapshots.
