Module 7 › Chapter 7.5 › Lab: Memory Profiler Walkthrough
Timeline

15-minute guided procedure

Step 1
Install Memory Profiler
Open Package Manager, find Memory Profiler in the registry, and install the package.
Step 2
Create leaky scene
Add LeakyManager that instantiates prefabs and appends strings on key press to simulate leaks.
Step 3
Capture snapshots
Take baseline, perform actions, capture comparison snapshot to find growth.
Step 4
Trace and fix
Inspect reference paths, clear lists/unsubscribe events, destroy objects, then capture final snapshot.
Lab challenge
Identify the exact root object in the final snapshot that was preventing collection. That identification proves you can trace ownership and apply the correct fix.
