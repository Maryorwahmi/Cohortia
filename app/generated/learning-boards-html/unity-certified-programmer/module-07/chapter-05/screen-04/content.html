Module 7 › Chapter 7.5 › Understanding the Memory Profiler
Definition

What a snapshot contains

A snapshot lists managed heap objects and unmanaged engine allocations, plus reference paths that reveal why objects remain alive.

Managed Memory
C# objects, strings and collections tracked by the garbage collector.
Unmanaged Memory
Textures, mesh buffers, audio data allocated by the engine.
Reference Paths
Shows which root object or GC handle is keeping an allocation alive.
Walkthrough
Example: capture snapshot A, instantiate objects by pressing play actions, capture snapshot B, compare. Look for new GameObject and String counts. Inspect reference chain to find a list or event root that still points to the allocated objects.
Concrete example
A list in a manager kept references to instantiated enemies. Snapshots showed growing managed heap and the list as the root—clearing the list freed memory.
Common misconception
Calling UnloadUnusedAssets alone is not a fix if references exist. You must remove references so the assets become eligible for unloading.
Key Takeaway

Use snapshots to track changes, inspect reference paths, and clear the actual roots keeping memory alive before calling unload operations.
