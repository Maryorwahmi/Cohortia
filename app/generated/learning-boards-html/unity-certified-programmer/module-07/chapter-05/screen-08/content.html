Module 7 › Chapter 7.5 › AssetBundles & Addressables
Concept

Package and load on demand

Package assets into bundles or use Addressables so the runtime only loads assets that are necessary for the current context.

Dependency handling
Addressables resolves dependencies for you and provides memory-safe handles for release.
Remote delivery
Bundles can be downloaded on demand and cached to reduce initial install size.
Practical test
Create a small bundle containing a prefab and texture, load via Addressables, instantiate, then release and verify the unmanaged memory drops in the Memory Profiler.
Concrete example
Load a level's heavy assets via Addressables only when the player reaches that area to avoid keeping them in memory for the full session.
Pitfall
Not releasing Addressables handles or leaving references to loaded assets prevents memory from being freed.
