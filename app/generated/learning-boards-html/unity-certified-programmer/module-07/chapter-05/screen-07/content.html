Module 7 › Chapter 7.5 › Resources.UnloadUnusedAssets
Definition

What UnloadUnusedAssets does

It triggers engine-side cleanup of assets with no remaining references, freeing unmanaged memory like texture and mesh buffers.

When to call
After clearing large caches or during a big scene swap when a temporary pause is acceptable.
Why not always
The operation is expensive and may cause hitches if invoked frequently at runtime.
Concrete example
After clearing a texture atlas cache on a level unload, call UnloadUnusedAssets once to ensure GPU and engine buffers are released before loading the next level.
Key Takeaway
Unload is a global cleanup tool—clear references first and use it sparingly.
Alternative
Prefer Addressables or AssetBundle-based unloading for fine-grained control in large projects.
