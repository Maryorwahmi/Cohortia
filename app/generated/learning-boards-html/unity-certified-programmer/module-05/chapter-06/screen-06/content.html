Module 6 › Chapter 5.6 › Audio Mixer Effects
Common Effects
  • Reverb — simulates room reflections and decay.
  • Echo / Delay — creates repeats and slapback for depth.
  • Distortion / Chorus / Flange — alter timbre for special moments.
  • Lowpass / Highpass Filters — sculpt frequency ranges for occlusion or underwater.
Design approach
Organize groups like Music, SFX, Dialogue and attach appropriate effects to each so global changes are manageable.
Example
To make the whole game sound muffled underwater, add a Lowpass filter to Master or SFX group, expose the cutoff frequency, and animate it down to about 500Hz in the underwater snapshot. This changes all routed clips without altering source assets.
Expose Parameters
Right-click a parameter in the mixer and expose it to script so your code can set cutoff or wet/dry values at runtime.
Key Takeaway

Applying effects on mixer groups and exposing parameters to script is the most scalable way to change audio behavior at runtime.
