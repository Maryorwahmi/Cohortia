Module 6 › Chapter 5.6 › PlayOneShot() vs Play()
PlayOneShot()

Ideal for overlapping short effects. It does not stop the currently playing clip on the Audio Source, allowing multiple instances to mix together.

Use when
Multiple quick events like rapid gunfire or footsteps that should overlap.
Play()

Stops the source's current clip and starts the assigned clip. Use when the logical emitter should only produce one sound at a time.

Use when
Single-shot emitters like a radio that should not layer multiple audio events.
Key Takeaway

Match your playback API to overlap requirements: PlayOneShot for overlap, Play for exclusive playback, and pools or multiple sources when you need many simultaneous voices from one logical emitter.
