Module 6 › Chapter 5.6 › Audio Clip Settings & Import Choices
Options
  • Streaming: Stream long clips from disk to save memory.
  • Vorbis compression: Good balance of size and quality for most files.
  • Decompress On Load (PCM): Lower runtime CPU for short, frequent sounds at memory cost.
Decision checklist
Consider clip length, play frequency, memory budget, and platform I/O when choosing import settings.
Example
A 3-minute ambient track should be Streaming. Short footstep sounds should be Decompress On Load if they play many times per second and your memory allows it. If you must optimize further, convert true mono sources to mono in the import settings.
Key Takeaway

Balance memory and CPU: streaming for long files, decompressed short assets for minimal runtime cost, and compressed medium files to save storage.
