Module 6 › Chapter 5.6 › Snapshots & TransitionToSnapshot
Code Example
using UnityEngine;
using UnityEngine.Audio;

public class AudioStateController : MonoBehaviour
{
    public AudioMixer mainMixer;
    public AudioMixerSnapshot normalSnapshot;
    public AudioMixerSnapshot underwaterSnapshot;
    public float transitionTime = 1.0f;

    void Start()
    {
        if (normalSnapshot != null) normalSnapshot.TransitionTo(0.01f);
    }

    public void EnterUnderwater()
    {
        if (underwaterSnapshot != null) underwaterSnapshot.TransitionTo(transitionTime);
    }

    public void ExitUnderwater()
    {
        if (normalSnapshot != null) normalSnapshot.TransitionTo(transitionTime);
    }
}
This pattern centralizes state transitions and keeps runtime calls simple and declarative.
Example Usage
Assign snapshots in the Inspector, place trigger volumes, and call EnterUnderwater from OnTriggerEnter. The entire mix transitions smoothly without modifying individual sources.
Pro-tip
Use short transition times for UI changes and longer times for environmental shifts to maintain immersion.
Key Takeaway

Snapshots let you change the whole audio mix atomically, which is efficient and consistent for gameplay-driven transitions.
