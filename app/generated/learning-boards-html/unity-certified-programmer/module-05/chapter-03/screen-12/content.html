Module 5 › Chapter 5.3 › Explosion Lab
Step-by-step
  1. Create ExplosionManager and an ExplosionEffect particle system.
  2. Main: Duration 1.0, Looping unchecked, Start Lifetime 0.5–1.0, Start Speed 5–10, Start Size 0.5–1.5, Max Particles 500.
  3. Emission: Rate over Time 0, add Burst Time 0 Count 100.
  4. Shape: Sphere, Radius 0.1.
  5. Color over Lifetime: fiery gradient to transparent. Size over Lifetime: quick grow then slight shrink.
  6. Renderer: Billboard, assign simple particle material. Uncheck Play On Awake.
  7. Make ExplosionEffect a prefab by dragging to Project.
Example inspector snippet
Main: Duration=1.0, Loop=false
Emission: Burst[0]=100
Shape: Sphere r=0.1
Color over Lifetime: red→orange→yellow→transparent
Size over Lifetime: 0.2→1.2→0.8
Checkpoints
  • Play On Awake is unchecked.
  • Prefab exists in Project window.
  • Effect plays correctly when instantiated and called Play.
Troubleshooting

If the effect is too heavy drop Max Particles and simplify the particle texture. If particles clip into geometry, slightly increase Shape radius or offset spawn position.

Key Takeaway

Concrete inspector values make it easy to reproduce an explosion that looks good and is manageable at runtime.
