Collision

Particles can collide with scene geometry. Useful for sparks and debris. Expect higher CPU cost; restrict to important particles.

Example
Sparks

Enable Collision for a small number of visible sparks so they bounce off surfaces and add realism.

Lights & Trails

Lights let particles illuminate nearby objects; use sparingly. Trails generate geometry behind moving particles for striking streaks.

  • Use a single light following the emitter as a cheaper approximation to many particle lights.
  • Limit trail length and resolution to reduce cost.
Design advice

Enable these modules only where the interaction or lighting creates meaningful player impact; otherwise keep them off to save performance.
