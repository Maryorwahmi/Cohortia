Module 5 › Chapter 5.3 › Shape Module
Available shapes
  • Sphere — omnidirectional bursts like explosions
  • Cone — directional beams like fire or magic spells
  • Box — planar or volumetric emission sources
  • Edge — line sources for trails or laser-like effects
  • Hemisphere — half-sphere spreads for ground-originating effects
Example
Sparks from a surface

Use Edge or a Cone with a narrow angle and small start radius to keep sparks close to the surface and moving outward.

Practical tips
  1. Start with a small radius for concentrated effects; increase for softer starts.
  2. Align the shape transform to the source object to maintain consistency when moving the source.
  3. Combine multiple shapes for layered effects: a tight core and a wider secondary puff.
Misconception

Some assume Shape only affects visuals. It also controls initial collision placement and influences velocity patterns when particles spawn inside a volume.

Key Takeaway

Choose a shape that matches the physical source and layer shapes for richer effects.
