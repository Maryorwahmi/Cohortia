Module 5 › Chapter 5.3 › Color & Size over Lifetime
Color over Lifetime

Define a color gradient that maps the particle life from birth to death. Use alpha to fade out particles smoothly to avoid hard pop-out.

Example gradient
Opaque orange → yellow → transparent
Tip
Small alpha at end reduces visible overdraw.
Size over Lifetime

Define a scale curve to grow, shrink, or pulse particles. A rapid grow then slow shrink works well for explosions; steady growth suits smoke.

Example curve
0.2 → 1.4 → 0.8 across life for a pop-and-settle effect.
Misconception

Relying only on start size and color makes effects static. Use over-lifetime modules to add motion and storytelling.

Key Takeaway

Over-lifetime modules add evolving behavior and make fewer particles look richer.
