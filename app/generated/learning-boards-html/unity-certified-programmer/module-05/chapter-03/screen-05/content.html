Main module essentials

Main sets lifecycle and defaults. Duration and Looping control repetition. Start Lifetime and Start Speed shape motion. Max Particles caps runtime cost.

Duration
System runtime length; pair with Looping for continuous effects.
Max Particles
Limit active particles to control CPU/GPU work.
Concrete example
Explosion defaults

Duration 1.0, Looping off, Start Lifetime random between 0.5 and 1.0, Start Speed between 5 and 10, Max Particles 500.

Emission patterns

Rate over Time is steady emission. Bursts produce sudden groups. Combine them for layered effects.

Rate over Time
Good for smoke, rain, or flames.
Burst
Use a Time 0 burst for explosions or sparks.
Misconception

Many beginners leave Max Particles high. That lets extreme concurrent emission spike cost unexpectedly. Limit it conservatively.

Key Takeaway

Choose burst for one-shots, rate for continuous; set Max Particles to the minimum needed.
