Module 5 › Chapter 5.3 › What is a Particle System?
Concept

A particle system is a set of short-lived elements emitted over time that together create complex visual effects. Shuriken separates control into modules so you can tune emission, shape, lifetime, motion, and appearance independently.

Main
Duration, Looping, Start Lifetime, Start Speed, Max Particles
Emission
Rate over Time, Bursts
Shape
Sphere, Cone, Box, Edge
Color & Size
Color over Lifetime, Size over Lifetime
Example
Puff of smoke

Looping system, moderate Rate over Time, Color over Lifetime fades alpha to zero, Size over Lifetime grows slightly.

Why this matters

Understanding the modular structure lets you isolate changes: tweak the Shape to move emission origin without changing motion, or change Color over Lifetime to alter appearance without touching emission rates. That separation improves iteration speed and reuse.

  • Misconception: more particles always look better. Often fewer well-tuned particles deliver better clarity.
  • Misconception: particle systems don't need lifecycle management; one-shots can leak if not destroyed.
Key Takeaway

Think modularly: Main, Emission, Shape, Color, Size. Those five control most visual decisions.
