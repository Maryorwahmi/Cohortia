Hands-on Lab Setup

Music + Coin Lab

Follow these steps in the Unity Editor to build and test the example scene.

Import & Mixer
  1. Import background track (Streaming, Vorbis) and coin SFX (Decompress On Load).
  2. Create MainAudioMixer with Music and SFX groups; expose MusicVolume and SFXVolume.
GameObjects & Sources
  • MusicPlayer: Audio Source, assign background clip, Loop = true, Play On Awake, Output → Music.
  • Coin: Sphere Collider trigger, Rigidbody kinematic, Audio Source with coin clip, Spatial Blend = 1, Output → SFX.
Script & Test
Attach CoinPickup script that plays the coin clip on trigger and then disables the coin. Ensure Camera has Audio Listener. Play the scene and approach the coin to validate spatialization.
Check: if coin is too quiet nearby, reduce Min Distance or increase source volume.
