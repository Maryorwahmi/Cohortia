2D vs 3D Sound

Choose the spatial model that matches the sound's role and the player's expectations.

2D (Spatial Blend = 0)
  • Position-independent. Always audible at set volume.
  • Ideal for UI clicks, background music, voice-over, HUD sounds.
  • Example: a menu click should play at full volume regardless of camera.
Misconception: 2D sounds are not 'stereo effects' — they bypass spatial attenuation.
3D (Spatial Blend = 1)
  • Spatialized by distance and stereo panning relative to the listener.
  • Use for footsteps, weapon sounds, ambient world sources.
  • Example: a distant enemy growl increases in volume and pans as the player moves.
Misconception: 3D alone does not guarantee audibility — tune Min/Max Distance and volume.
Practical tip
When in doubt, prototype both modes to test player perception and adjust Blend value for mixed effects.
Example
Coin pickup: Source set to 3D so the chime localizes to the coin position and gets louder as the player nears.
Check
If UI sounds disappear, ensure Spatial Blend = 0 and that the Audio Source is not mistakenly positioned far from the listener.
