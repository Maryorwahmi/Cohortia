Expose Mixer Parameters

Make group volumes adjustable from UI or game logic by exposing parameters and setting them in script.

Editor steps
  1. Right-click a group's Volume in the Mixer and choose 'Expose to script'.
  2. Rename the parameter to a friendly name like 'SFXVolume'.
  3. Assign the AudioMixer asset to your AudioManager script.
Runtime steps
Convert linear slider value to decibels and call AudioMixer.SetFloat(parameterName, dbValue).
Clamp or min-check the linear value to prevent log of zero errors.
Key Takeaway

Expose only the parameters you need, convert slider values to dB, and use smooth fades for better player experience.
