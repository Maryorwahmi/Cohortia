AudioManager Pattern

Centralize music and SFX control and interact with AudioMixer parameters from script.

Core responsibilities
  • Manage background music playback and looping.
  • Play SFX via PlayOneShot to allow overlapping clips.
  • Expose and set Mixer parameters like MusicVolume and SFXVolume.
Runtime considerations
Convert linear volume values to decibels with a log conversion before setting the mixer parameter.
Clamp inputs to avoid negative infinity when converting zero volume.
Example methods
Start: assign music clip, set loop, play.
PlaySFX: call PlayOneShot on SFX source to play a clip without stopping others.
