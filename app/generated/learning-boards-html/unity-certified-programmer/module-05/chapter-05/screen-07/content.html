Audio Clip Import Settings

Understand the three main load types and compression formats to balance memory and quality.

Load Type
  • Decompress On Load: low latency, large memory cost, good for short SFX.
  • Compressed In Memory: trade-off between memory and CPU decompression.
  • Streaming: best for long music tracks to save memory.
Compression Format
  • PCM: highest quality, largest size.
  • Vorbis: lossy compression, smaller files — common for music.
  • Select based on acceptable quality vs file size.
Practical guidance
Long background music: Streaming + Vorbis.
Short SFX that require instant playback: Decompress On Load.
Test in a build and monitor memory to validate choices.
Common mistake
Using Decompress On Load for long tracks increases memory; prefer streaming for long music.
Example
A 5-minute background track should be set to Streaming with Vorbis to reduce build size and memory usage.
