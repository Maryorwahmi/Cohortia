Final Checklist

Quick Ship Checklist

Three short reminders to run through before shipping your scene.

01 Listener
One active Audio Listener in the scene on Main Camera or player.
02 Routing
Audio Sources routed to appropriate Mixer groups with exposed parameters set if needed.
03 Import & Balance
Use streaming for long music, decompress short SFX, and balance levels across groups.
Final Note

A short validation pass with these checks will catch the majority of audio issues before shipping.
