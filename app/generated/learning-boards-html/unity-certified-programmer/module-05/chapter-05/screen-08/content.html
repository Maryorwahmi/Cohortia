Audio Mixer & Groups

Route Audio Sources into groups to control categories like music, SFX, and dialogue.

Typical hierarchy
  • Master
  • ├─ Music (apply reverb/ducking)
  • ├─ SFX (apply limiter, expose SFXVolume)
  • └─ Dialogue (voice processing)
Routing
Set each Audio Source's Output to the appropriate group so the group-level settings affect all routed sources.
Exposed parameters
Expose a group's volume to script to change it in runtime, for example to fade music or mute SFX.
Example
Create MainAudioMixer with Music and SFX groups. Route the MusicPlayer Audio Source output to Music and coin Audio Sources to SFX.
Practical tip
Expose only the parameters you will control at runtime to avoid clutter and unnecessary overhead.
