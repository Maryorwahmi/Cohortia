Module 5 › Chapter 5.1 › Troubleshooting
Freeze on last frame
Cause: Loop Time unchecked. Fix: Enable Loop Time in clip import settings.
Delayed transitions
Cause: Has Exit Time checked. Fix: Uncheck Has Exit Time for movement transitions and tune duration.
Parameters not changing
Cause: wrong name/type or script not updating. Fix: Verify parameter names and that the Animator reference is valid in the script.
Performance issues
Compress long clips, reduce keyframes, and avoid updating Animator parameters unnecessarily. Profile if many animators are active simultaneously.
Key Takeaway

Start troubleshooting with Loop Time and Has Exit Time, then inspect parameter names and script updates. Use the Animator window in Play Mode to observe behavior live.
