Objective: Configure Transitions
Set conditions like IsWalking==true and tune transition duration for smooth blends.
Mnemonic: Condition → Transition Duration → Test in Play Mode.
VERIFIED COMPETENCY MILESTONE
Objective: Troubleshoot & Optimize
Check Loop Time, parameter updates, and clip compression to avoid freezes and performance issues.
Mnemonic: Loop, Params, Compress — verify each in Play Mode.
VERIFIED COMPETENCY MILESTONE
Quick debug checklist
  • Is the parameter name in script identical to the Animator parameter?
  • Are Loop Time and transition duration set for repeating cycles?
  • Is Has Exit Time unchecked for movement transitions that must respond immediately?
