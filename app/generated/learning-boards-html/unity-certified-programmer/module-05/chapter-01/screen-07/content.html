Parameter types
  • Float: continuous numbers like speed for blend trees.
  • Int: discrete indices or state IDs.
  • Bool: on/off toggles like IsWalking.
  • Trigger: a one-time event for attacks or reactions.
Best practices
Name parameters clearly, update them only when values change, and use triggers for single events to avoid persistent conditions. Debugging tip: watch the Animator window during Play Mode to see parameter values change live.
Misconception

Using a Bool instead of a Trigger for transient actions can lead to stuck behavior because the Bool stays true until explicitly set false.

Key Takeaway

Match parameter types to their intended use: continuous values use floats, momentary events use triggers, and toggles use bools.
