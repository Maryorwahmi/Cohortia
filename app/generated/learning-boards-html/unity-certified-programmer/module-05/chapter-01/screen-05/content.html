Module 5 › Chapter 5.1 › Animation Clips
Import vs Author
Imported clips come from external tools; authored clips are created in Unity's Animation window for quick edits or UI motion.
  • Imported clips appear under the model in the Project window.
  • Author clips by selecting a GameObject and opening Window > Animation > Animation.
  • Unity may add an Animator component automatically when authoring.
Important clip settings
Loop Time must be checked for repeating cycles. Compression reduces memory and CPU cost.
Common mistake

Forgetting Loop Time causes a walk or idle cycle to stop on the last frame. Always verify loop settings for repeating animations.

Concrete example
Import a Mixamo character with Idle and Walk clips. In the Project window inspect each clip and enable Loop Time for Idle and Walk. If you want to tweak a foot plant, open the Animation window, add a keyframe, and save a new clip.
Key Takeaway

Check Loop Time for repeating cycles and compress clips when appropriate to avoid performance and memory issues.
