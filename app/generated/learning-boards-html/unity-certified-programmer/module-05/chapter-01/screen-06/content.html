Module 5 › Chapter 5.1 › States & Entry
Step-by-step
  1. Import clips and create an Animator Controller.
  2. Drag Idle and Walk clips into the Animator to form states.
  3. Create a Bool parameter named IsWalking.
  4. Make transitions: Idle → Walk (IsWalking == true), Walk → Idle (IsWalking == false).
  5. Uncheck Has Exit Time for movement transitions and set Transition Duration to ~0.2.
Example configuration
Idle → Walk: IsWalking == true, Has Exit Time unchecked, Duration 0.2. Walk → Idle: IsWalking == false, Has Exit Time unchecked.
Pitfall

If Has Exit Time remains checked, you’ll see delayed responses because transitions wait for the current clip to finish.

Key Takeaway

Set Entry → Idle, create clear parameters, and uncheck Has Exit Time for responsive movement blending.
