Module 5 › Chapter 5.1 › Key Concepts
Animator Controller
A state machine that links states and transitions to control animation flow.
Animation Clip
A single motion segment. Enable Loop Time for repeating cycles such as Idle or Walk.
Animation State
A node in the Animator that holds a clip or blend tree and participates in transitions.
Takeaway
Use clear names, verify loop and entry settings, and validate parameters in Play Mode to ensure animation systems behave as expected.
