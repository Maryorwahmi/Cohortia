Module 5 › Chapter 5.1 › Hands-on: Idle & Walk
Step-by-step lab
  1. Import a character model with Idle and Walk clips and drag into the scene.
  2. Create PlayerAnimatorController if prompted and open the Animator window.
  3. Drag Idle into Animator to become default, then add Walk.
  4. Add a Bool parameter named IsWalking in Parameters tab.
  5. Make Idle → Walk transition with IsWalking == true; uncheck Has Exit Time and set Duration 0.2.
  6. Make Walk → Idle transition with IsWalking == false; similar duration.
  7. Confirm Loop Time is enabled on Idle and Walk clips.
  8. Attach the PlayerAnimationHandler script and test in Play Mode with movement keys.
Debug tip
If the clip plays once, check Loop Time in the clip import settings.
Responsiveness tip
If transitions feel delayed, ensure Has Exit Time is unchecked for movement transitions.
Key Takeaway

Follow the lab steps sequentially, test in Play Mode, and use the Animator window to observe parameter values changing in real time.
