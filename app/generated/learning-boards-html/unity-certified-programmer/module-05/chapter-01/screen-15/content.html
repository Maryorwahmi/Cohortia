Module 5 › Chapter 5.1 › Key Concepts
Transition
Arrows that move the Animator from one state to another based on conditions and durations.
Parameter
Variables like Float, Int, Bool, Trigger that scripts set to control transitions.
Has Exit Time
When enabled, transitions wait for the current clip to reach its exit point before changing states; use for uninterruptible actions.
Final takeaway
Use transitions and parameters as the primary control surface for animation. Verify Has Exit Time only where necessary and test behaviours in Play Mode to ensure responsiveness.
