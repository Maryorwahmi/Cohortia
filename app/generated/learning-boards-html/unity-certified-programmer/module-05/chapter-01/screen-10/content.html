Loop Time
Enable Loop Time in the clip import settings for repeating cycles like Idle and Walk to prevent the clip from stopping on its last frame.
Performance tips
  • Use clip compression and keyframe reduction in import settings.
  • Keep clips concise; avoid unnecessarily long animations.
  • Update Animator parameters only when values change.
Concrete scenario
If your walk freezes after one cycle, open the clip in the Project window and verify Loop Time is checked. If performance dips when many characters animate, try compressing clips and reducing keyframes.
Key Takeaway

Loop repeating cycles and compress or shorten clips where possible. Update parameters sparingly to reduce overhead.
