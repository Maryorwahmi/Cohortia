Definition

Blend Tree

A state that blends multiple clips according to parameter values, producing smooth motion across a range.

Why it matters
  • Removes abrupt cuts between related motion clips.
  • Matches player-driven parameters like speed or direction.
  • Simplifies Animator graphs for movement systems.
Example
1D: Idle@0 → Walk@2 → Run@5 driven by Speed float.
Key Takeaway

Blend Trees map parameters to a smooth continuum of motion; align clips to avoid sliding.

Visual
1D Blend Graph
Parameter: Speed. Thresholds at 0, 2, 5. Unity interpolates clip weights automatically.
Common misconception
Blend Trees don't fix mismatched foot timing; synchronize gait cycles across clips before blending.
Try this
In Play mode, scrub Speed from 0 to 5 and watch the combined motion—adjust thresholds to tune transition feel.
