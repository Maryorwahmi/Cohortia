Definition

Inverse Kinematics (IK)

Specify an end effector position and let the solver calculate intermediate joint rotations to reach that point.

Example: animator.SetIKPosition(AvatarIKGoal.RightHand, target.position) and set the IK weights to control influence.
Notes
  • Tune position and rotation weights so IK blends naturally with authored animation.
  • Use pole vectors or additional constraints to avoid unnatural elbow or knee twisting.
  • Disable or reduce IK on distant characters to save CPU.
Misconception: IK is a magic fix for bad animation. It helps placement but does not replace good posing and joint limit setup.
