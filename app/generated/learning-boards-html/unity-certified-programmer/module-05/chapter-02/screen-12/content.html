Mistakes
  • Forgetting to set IK weights makes the solver appear inactive.
  • Incorrect avatar masks cause unintended overrides or missing joints.
  • Misaligned gait cycles produce foot sliding in Blend Trees.
Tip: verify masks and weights visually before profiling performance; many bugs are configuration errors.
Performance Checklist
Profile animation update cost in the Profiler.
Use lower-cost blends or fewer clips for distant LODs.
Limit IK passes per-frame or disable on non-interactive actors.
Avoid per-frame state forcing; prefer parameter updates and CrossFade.
