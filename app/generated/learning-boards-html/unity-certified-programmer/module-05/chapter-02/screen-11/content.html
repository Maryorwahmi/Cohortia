Definition

Animation Events

Timeline markers that call a public method when the animation reaches the frame, perfect for synchronized audio or particle triggers.

Example: Add event to call PlayFootstep() on the frame where the foot contacts the ground to align sound precisely.
Practical note
  • Events require a public method on the same GameObject for simple calls.
  • Only pass supported parameter types; prefer no-argument calls when in doubt.
  • Keep handlers light; set flags or call audio managers rather than heavy logic directly.
Key Takeaway

Events give precise synchronization between motion and gameplay; use them for timing, not heavy processing.
