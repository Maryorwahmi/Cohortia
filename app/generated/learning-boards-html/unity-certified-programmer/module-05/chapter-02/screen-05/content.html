Process

Build a 1D Blend Tree

  1. Create State → From New Blend Tree, name it Movement.
  2. Set Blend Type to 1D and parameter to Speed (Float).
  3. Add motions: Idle (0), Walk (2), Run (5). Adjust thresholds to match clip pacing.
  4. Connect Entry and remove redundant transitions. Test by changing Speed at runtime.
Pro tip

Align gait cycles across clips and use root motion or matching locomotion speeds to reduce sliding when blending.

Example Code
// Pseudocode-style snippet for driving Speed
void Update() {
float inputSpeed = currentVelocity.magnitude;
animator.SetFloat("Speed", inputSpeed);
}
Testing: in Play mode,手 change the Speed parameter and watch the seamless interpolation between Idle, Walk, Run.
