Animator Scripting Patterns

Use SetFloat("Speed", value) to drive Blend Trees.
Use CrossFade("State", 0.2f) to transition smoothly to a named state.
Use Play for immediate, non-blended state switching when intentional.
Example
// Drive Blend Tree
float speed = rb.velocity.magnitude;
animator.SetFloat("Speed", speed);
// Smoothly start reload
animator.CrossFade("Reload", 0.2f);
Design rule: update parameter values from your movement system, not every UI event, to preserve consistent animation logic.
