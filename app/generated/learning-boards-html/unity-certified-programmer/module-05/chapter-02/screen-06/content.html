1D Blend Tree
Parameter: Speed. Good for idle→walk→run. Fewer clips, simpler thresholds.
2D Blend Tree
Parameters: ForwardSpeed + SidewaysSpeed. Good for directional blends like strafing and diagonal motion.
Example: A top-down shooter might use 2D blending to combine aim direction and movement speed so animations match both direction and speed.
Pitfall
Overcomplicating a tree adds tuning cost and runtime weight; prefer 1D unless direction matters.
Key Takeaway

Match tree dimensionality to gameplay requirements and sample the space with representative clips.
