Step-by-step
  1. Create Movement Blend Tree (1D) and Speed parameter.
  2. Add Idle@0, Walk@2, Run@5 motions and connect Entry.
  3. Create IKTarget GameObject and assign to script.
  4. Attach PlayerAnimationHandler, set ikTarget, and enable Apply Avatar IK in Animator.
  5. Run scene, press movement keys, and move IKTarget to observe hand tracking.
Debug checklist

If IK doesn't move the hand, confirm IK weights are set and that animator.SetFloat("Speed") is updating the parameter.
