Module 5 › Chapter 5.2 › Milestones & Checks
Blend Tree Check

Set Speed thresholds and play in editor. Expect smooth interpolation and no frame jumps.

IK Check

Move the IK target; confirm the hand follows. Toggle weights to ensure enabling/disabling works.

Layer Check

Apply an avatar mask to upper body and play a shooting animation while walking.

Common issues: incorrect mask coverage, zero IK weights, expensive per-frame IK on many characters. Keep testing small changes and profile when scaling to many actors.
