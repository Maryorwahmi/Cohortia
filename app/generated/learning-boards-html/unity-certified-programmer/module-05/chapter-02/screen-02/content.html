01
Blend Trees
Create and tune 1D and 2D blends

You will build Blend Trees driven by float parameters so idle, walk, and run blend smoothly. This matters because parameter-driven animation removes hard cuts and matches player input more naturally.

VERIFIED COMPETENCY MILESTONE
02
Inverse Kinematics
Implement OnAnimatorIK for dynamic limbs

You'll use OnAnimatorIK and SetIKPosition to make a hand reach for a target. This creates believable interactions with the environment, like grabbing or steady aiming.

VERIFIED COMPETENCY MILESTONE
03
Animation Layers
Isolate upper and lower body actions

You will configure layers and avatar masks so aiming or gestures do not disrupt locomotion, preserving realistic motion composition.

VERIFIED COMPETENCY MILESTONE
04
Scripting & Events
Control states and trigger frame callbacks

You will set Animator parameters, crossfade states, and place animation events to call methods precisely when an animation reaches a frame.
