Definition

Animation Layers

Parallel animation tracks with weights that blend and override lower layers for specified bones via Avatar Masks.

Example: base locomotion layer + upper-body layer with avatar mask affects only arms and torso so aiming animation does not stop walking.
Practical tips
  • Always preview Avatar Masks in the Inspector to confirm bone selection.
  • Use layer weights to smoothly blend an action in and out, avoiding pops.
  • Keep layer graphs limited to necessary actions to reduce runtime overhead.
Mistake: setting weight to 1 but forgetting to mask out lower-body bones, leading to conflicting motion between layers.
