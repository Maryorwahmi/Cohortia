Module 05 › Chapter 5.4 › What is Post-Processing?
Definition

Full-screen image effects applied after rendering

These effects run on the final frame buffer so they can modify the entire image consistently. They are perfect for mood, focus, and polish without changing individual assets.

Why use it?
  • Set consistent scene color and contrast quickly.
  • Guide player attention with blur and vignettes.
  • Add cinematic effects like motion blur and bloom.
Common misconception

Post-processing is not a substitute for good art and lighting. Overuse can obscure detail and confuse depth cues.

Key Takeaway

Use post-processing to unify and accentuate visuals, but keep values subtle and test across displays.

Analogy
Think of post-processing like photographic filters applied after a photo is taken. You don’t move the objects; you change how the final picture looks. This is efficient for global mood shifts.
Concrete Example
To give a scene a warm evening tone, add modest color grading instead of adjusting every light’s color and intensity. The grading affects shadows, midtones, and highlights uniformly.
