Module 05 › Chapter 5.4 › Hands-on Activity
Step-by-step
  1. Create an empty GameObject and add a Post Process Volume. Check Is Global.
  2. Create a new Post Process Profile asset and assign it to the volume.
  3. Add Bloom: Intensity 0.5–1.0, Threshold ~1.0, Soft Knee ~0.5.
  4. Add Depth of Field: Focus Distance to target object, Aperture ~5.6, Focal Length ~50.
  5. Add Color Grading: Mode HDR, Temperature ±10, Saturation +10–20, Contrast +10–20.
  6. Run, iterate, and create lower-quality clones for constrained platforms.
This sequence gives you an editable profile you can refine. Small combined tweaks produce the most natural results; avoid extreme single-parameter jumps.
Concrete Example
For a cozy indoor scene, try Temperature -10, Saturation +15, Bloom Intensity 0.7, and a soft DoF focusing on the foreground actor. Iterate until lighting and materials read well together.
Quick checklist
  • Camera has Post Process Layer with correct Layer.
  • Volume references the new profile.
  • Start subtle, then increase if needed.
Key Takeaway

A small set of modest values applied consistently will improve cohesion far more than heavy-handed single settings.
