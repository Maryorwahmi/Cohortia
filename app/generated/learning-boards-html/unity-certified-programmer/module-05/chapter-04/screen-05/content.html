Module 05 › Chapter 5.4 › Install & Configure
Process Flow

Install package → Add Post Process Layer → Assign Layer → Test

1. Install
Open Window > Package Manager, choose Unity Registry, search 'Post Processing', and install. The package supplies the needed components and profiles.
2. Add Layer
Select Main Camera, add component Post Process Layer. Create a new Layer like 'PostProcessing' and assign it to the camera and volumes.
3. Test
Create an empty GameObject, add a Post Process Volume, set Is Global and add a simple Bloom to confirm the pipeline is active.
Common pitfall
Forgetting to set the same Layer on both the camera Post Process Layer and the Post Process Volume causes no visible effect despite correct components.
Pro tip
Start with one global volume for testing, then split into local volumes as you iterate to keep control manageable.
