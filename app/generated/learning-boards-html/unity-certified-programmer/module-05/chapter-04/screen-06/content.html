Module 05 › Chapter 5.4 › Layer → Volume → Profile
Post Process Layer
Camera component
Assign a Layer to tell the camera which volumes to read. It performs blending and applies the active profile values to the rendered frame.
Post Process Volume
Scene object
Holds a reference to a Profile. Check Is Global to apply everywhere, or leave unchecked to use collider-based influence.
Post Process Profile
Asset storage
Add effects and use property overrides so only intended values change when the profile is active.
Concrete scenario

Create a global profile with gentle color grading for overall tone. Then add a local collider volume in a cave that references another profile with stronger vignette and warm tint. As the player enters the cave, Unity blends the profiles based on volume weight, producing a smooth visual transition.
