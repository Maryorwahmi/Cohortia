Module 05 › Chapter 5.4 › Bloom
Definition

Bloom: glow from bright areas

Use bloom to sell brightness and make highlights feel luminous. Tune Intensity for strength, Threshold for which pixels bloom, and Soft Knee to smooth the onset.

Intensity
Overall strength of the glow effect.
Threshold
Minimum brightness for a pixel to contribute to bloom.
Soft Knee
Smooths transitions near the threshold to avoid harsh clipping.
Common mistake
Excessive intensity or too low a threshold makes details disappear and flattens contrast. Start with subtle values and iterate while observing foreground detail.
Concrete example
For a nighttime street scene, set Threshold high enough that only lamps and emissive signs contribute, and Intensity between 0.5 and 1.0 to create a believable glow without losing facade detail.
Optimization
Lower bloom resolution or use a cheaper quality preset on mobile platforms. Remove bloom where it adds little to composition.
Key Takeaway

Bloom adds perceived brightness; tune threshold and intensity carefully to preserve detail and contrast.
