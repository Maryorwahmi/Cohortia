Module 05 › Chapter 5.4 › Key Concepts
Post-processing is post-render
Apply global adjustments after the scene is drawn to control mood and polish.
Layer → Volume → Profile
Camera reads volumes on selected layers; volumes reference profiles that store effect overrides.
Tune and optimize
Use subtle values, localize expensive effects with volumes, and test on target hardware.
Final takeaway

Post-processing is a high-leverage way to shape visuals. Apply it with intention, organize profiles, and always validate across devices.
