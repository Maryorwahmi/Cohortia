Learning Objectives

A clear, testable checklist so you can practice and verify each skill.

Learn → Understand → Apply → Master
01 Understand Post-Processing
Define full-screen effects and why they run after rendering. This matters because ordering affects both appearance and performance. Visual mnemonic: a layered photo with filter applied.
Verified Competency Milestone
02 Install & Configure Stack v2
Use the Package Manager to install Post Processing and add a Post Process Layer to the camera. This ensures your camera will apply volumes. Mnemonic: package box + camera icon.
Verified Competency Milestone
03 Create Volumes & Profiles
Make global volumes or local colliders and create a profile to store effects and overrides. Mnemonic: globe vs boundary box.
Verified Competency Milestone
04 Apply & Optimize Effects
Add Bloom, Depth of Field, Color Grading and Vignette with careful parameter choices, and use quality settings and selective volumes to optimize. Mnemonic: dial knobs with check mark.
Verified Competency Milestone
