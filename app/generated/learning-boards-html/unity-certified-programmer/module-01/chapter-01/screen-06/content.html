Module 1 › Chapter 1.1 › Filename & Class
Rule

Filename must match public class name

This mapping allows Unity to resolve serialized components and compile scripts predictably. A mismatch causes compile errors or missing components at runtime.

Concrete example
If the file is HelloWorldLogger.cs then the script must declare public class HelloWorldLogger to compile and attach properly.
Error symptom

You will see compile errors in the Console or the script will not appear as a selectable component in the Inspector. Fix the name mismatch to resolve the issue.

Quick fix

Rename either the file in the Editor or the public class inside the file so both match exactly, including capitalization.

Check

After renaming, let Unity recompile and verify there are no Console errors that reference class or filename mismatches.
