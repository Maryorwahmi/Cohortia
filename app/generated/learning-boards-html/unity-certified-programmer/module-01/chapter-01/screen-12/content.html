Module 1 › Chapter 1.1 › Create & Attach
Step-by-step
  1. 1. New Unity project — pick 3D Core and open the Scene.
  2. 2. Create Empty GameObject in Hierarchy and rename to GameManager.
  3. 3. In Project window create C# Script, name HelloWorldLogger, open it in your editor.
  4. 4. Add Debug.Log messages to Awake and Start, save the file so Unity recompiles.
  5. 5. Drag the script onto GameManager to attach it as a component and ensure the GameObject is active.
  6. 6. Press Play and observe Console messages for Awake and Start confirmations.
Troubleshooting
No logs? Check that the script compiles, that the class name matches the file, and that the GameObject is active and the component enabled.
Try This

Disable the GameObject and re-run. Observe which messages appear to validate Awake vs Start behaviors.
