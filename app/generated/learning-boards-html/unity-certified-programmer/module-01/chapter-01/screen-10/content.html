Module 1 › Chapter 1.1 › Update()
Definition

Update: the per-frame hook

Called every frame. Best for input handling, animations, and small per-frame updates that are cheap and predictable.

Concrete example
Read Input and apply movement: check input axes and call transform.Translate or a controller method inside Update.
Performance caution
Avoid calling GameObject.Find or allocating new objects inside Update. Cache references and reuse objects to prevent frame drops and garbage collection spikes.
Alternatives
Use FixedUpdate for physics and LateUpdate for camera follow logic. Use coroutines for operations that can run over time without every-frame checks.
Throttle pattern
If a check can be less frequent, measure elapsed time and run it every N seconds instead of each frame to reduce load.
Key Takeaway

Keep Update minimal, cache everything you need, and move expensive logic out of the per-frame loop.
