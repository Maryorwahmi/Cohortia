Challenge
Add a timer in Update to log once every two seconds instead of every frame.
When implementing the timer, use a float elapsed variable and add Time.deltaTime each frame. When elapsed >= 2.0f, log and subtract or reset the elapsed time. This pattern prevents Console spam and demonstrates controlled per-frame logic.
Misconception
Avoid using GameObject.Find inside Update. Cache references in Awake or Start for performance and reliability.
Key Takeaway

Timed logs teach controlling per-frame work. Use deltaTime to schedule periodic tasks without harming performance.
