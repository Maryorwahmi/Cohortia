Quick verification steps
  1. Open the generated script and confirm the using UnityEngine line and class header exist.
  2. Ensure the filename equals the public class name to avoid compile errors.
  3. Attach the script to an empty GameObject and enable Play to see Start and Awake messages.
  4. Add a Debug.Log inside Update for a live trace, then remove or comment it before shipping to avoid performance issues.
Common misconception
A common mistake is assuming a script in the Project window runs automatically. Only scripts attached to active GameObjects will receive Start and Update calls. Another is changing the file name without updating the class name; Unity will not compile such a script and it will not run.
Tip

When testing, add short, focused Debug.Log messages to confirm order, then remove them when performance matters.
