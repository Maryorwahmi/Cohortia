Process

Awake → Start → Update

Awake()
Called when the instance is loaded. Use this to cache references and set up internal state that other objects may rely on later.
Start()
Called once before the first frame if the script is enabled. Use this for setup that depends on other components being initialized.
Update()
Called every frame. Use for input handling, continuous checks, and frame-dependent behavior.
Concrete example
Use Awake to store a reference to a Rigidbody, Start to set initial velocity based on other objects, and Update to read player input and call Move.
Misconception check
Awake will run even if the GameObject is disabled at load; Start only runs if the component and GameObject are enabled at runtime. They are not interchangeable.
Key Takeaway

Choose Awake for reliable early setup, Start for enabled initialization, and Update for frame-by-frame logic to avoid race conditions.
