Module 1 › Chapter 1.1 › Learning Objectives
01
Understand C# role
Learn why C# is the primary scripting language in Unity and how it integrates with the engine and tools.
Mnemonic: Think of C# as the language that talks to the Editor and engine APIs.
Verified Competency Milestone
02
Identify script structure
Recognize class definitions and MonoBehaviour inheritance so your script can be attached as a component.
Mnemonic: Class name equals file name; MonoBehaviour equals attachable component.
Verified Competency Milestone
03
Explain lifecycle order
Describe when Awake, Start, and Update run and why you choose one for certain initializations or per-frame logic.
Mnemonic: Awake early, Start once when active, Update every frame.
Verified Competency Milestone
04
Create, attach & debug
Write a C# script, attach it to a GameObject, run the scene, and verify behavior in the Unity Console with Debug.Log.
Mnemonic: Create, attach, run, observe.
Verified Competency Milestone
