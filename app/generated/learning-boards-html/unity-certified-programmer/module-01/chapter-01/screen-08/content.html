Module 1 › Chapter 1.1 › Awake()
Definition

Awake: load-time initialization

Called when the instance is loaded; runs regardless of the GameObject's enabled state. Use it to cache components and set quick internal state.

Concrete example
In Awake call GetComponent<Rigidbody> and store the result in a private field so Update can use it without searching each frame.
When not to use Awake
Avoid expensive computations, network calls, or heavy allocations in Awake that could slow scene loading. Reserve those for managed initialization sequences.
Coordination tip
If multiple objects must initialize in a known order, use a manager that calls explicit setup methods after Awake has completed on all objects.
Key Takeaway

Awake is your reliable time to cache references and prepare a component for later Start and Update work.
