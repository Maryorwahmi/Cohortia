C#
The language used for gameplay scripting and Editor tooling with strong typing and integration.
MonoBehaviour
The base class that makes a script an attachable component and enables lifecycle callbacks.
Lifecycle
Awake for load-time cache, Start for enabled one-time setup, Update for lean per-frame work.
Takeaway

Master these basics to avoid common errors: name matching, attachment, appropriate lifecycle use, and careful logging during development.
