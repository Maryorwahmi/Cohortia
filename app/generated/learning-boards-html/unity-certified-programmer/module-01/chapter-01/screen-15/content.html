Module 1 › Chapter 1.1 › Practical Reminders
Name match
Keep file and public class names identical to avoid compile errors and missing components.
Attach & enable
Attach scripts to active GameObjects to allow Start and Update to run; verify with Console messages.
Lean Update
Cache references early and avoid heavy operations in Update to keep frames smooth.
Final Takeaway

Small, consistent practices—correct naming, proper attachment, and mindful Update usage—lead to faster debugging and more stable gameplay code.
