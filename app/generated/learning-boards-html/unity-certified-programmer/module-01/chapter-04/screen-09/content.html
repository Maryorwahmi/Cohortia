Pattern

GetComponent & null checks

Cache components early and guard usage with a null check to keep your game from crashing at runtime.

void Awake()
{
    playerRigidbody = GetComponent();
    if (playerRigidbody == null)
    {
        Debug.LogError("Rigidbody component not found on this GameObject!");
    }
}

void OnTriggerEnter(Collider other)
{
    PlayerHealth ph = other.GetComponent();
    if (ph != null) ph.TakeDamage(damageAmount);
}
Example: DamageDealer

When a collider enters the damage zone, attempt to get PlayerHealth. If null, do nothing. If present, call TakeDamage so only valid players are affected.

Common mistake
Skipping null checks leads to NullReferenceException and often a confusing crash in the console. Add early checks and helpful error logs.
