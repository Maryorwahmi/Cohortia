Definition

Parameters & return values

Parameters accept data; returns produce computed results. Use them to separate computation from side effects.

public float CalculateDistance(Vector3 point1, Vector3 point2)
{
    return Vector3.Distance(point1, point2);
}

// Usage
float distance = CalculateDistance(transform.position, enemyPosition);
if (distance < attackRange) { Debug.Log("Enemy is within attack range!"); }
Pro tip
Return small types for predictability; use out or tuples sparingly for grouped returns.
Common mistake
Forgetting to return a value on every path causes a compile error for non-void methods.
Example scenario

Use CalculateDistance in enemy AI to decide when to switch from wandering to attacking. Keep the distance check separate from the attack method.

Key Takeaway

Separate calculation (returns) from actions (void methods) to keep code predictable and testable.
