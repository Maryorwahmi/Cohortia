Definition

Class vs Object

A class is a template; an object is a concrete instance created when the script is attached to a GameObject.

  • Class defines fields and methods.
  • Each instance has its own field values and lifecycle.
  • Use static only when a value should be shared across all instances.
Example: PlayerCombat class
Attach PlayerCombat to multiple GameObjects and each will maintain separate playerHealth values and behavior.
Key Takeaway

Design whether state is per instance or shared. Use instances to keep per-GameObject behavior isolated and predictable.
