Process

Refactor Update()

  1. 1. Identify logical blocks inside Update (input, movement, health).
  2. 2. Extract each block into a named method like HandleInput().
  3. 3. Move physics to FixedUpdate if appropriate and test behavior.
Concrete example
Before: a single Update handling input, damage keys, and animation. After: Update calls HandleInput(), UpdateMovement(), and SyncAnimation(). Each method is short and self-documenting.
Key Takeaway

Small methods reveal intent and make it safe to change behavior without introducing regressions.
