Core Concept

Method definition

A method encapsulates a single task and can accept parameters or return a value. Small methods make code easier to read and maintain.

  • Return type: void or a data type like int/float/Vector3.
  • Parameters: inputs that change behavior without editing the method body.
  • Call sites: methods are invoked where the behavior is needed, reducing duplication.
Key Takeaway

One responsibility per method makes intent clear and prevents duplicated logic across your scripts.

// Example from PlayerCombat
public void TakeDamage(int damageAmount)
{
    playerHealth -= damageAmount;
    if (playerHealth < 0) playerHealth = 0;
    Debug.Log("Player took " + damageAmount + " damage. Current Health: " + playerHealth);

    if (playerHealth == 0)
    {
        Die();
    }
}

private void Die()
{
    Debug.Log("Player has died!");
    gameObject.SetActive(false);
}
Concrete example
Call TakeDamage from an input event, an enemy script, or a trigger to centralize death logic and health clamping.
Common mistake: forgetting to clamp health or to call Die consistently when health reaches zero. Moving that logic into one method prevents the bug.
