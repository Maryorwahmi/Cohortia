Objectives — Practical Focus
Small code examples and Inspector checks you will perform.
Declare
Create public fields on PlayerManager and save the script to view them in the Inspector.
Types
Assign playerHealth as int, moveSpeed as float, and playerName as string for appropriate behavior.
Unity Types
Store position as Vector3 and color as Color so Unity systems can use them directly.
Operators
Apply arithmetic and logical operators inside Start() to update values and log results.
Pitfalls
Watch integer division and the difference between assignment and comparison in conditions.
Inspector Check
Verify public fields appear on GameManager and change values to test runtime effects.
