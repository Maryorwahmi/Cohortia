Public vs Private and the Inspector
Decide which fields designers should edit and which should remain internal.
Process
  1. Declare public field in the script: public float moveSpeed = 5.0f;
  2. Save and attach the script to a GameObject.
  3. Select the GameObject and edit the field in the Inspector to tune values.
Example
Make playerColor public to allow designers to change color per instance in the Inspector.
Notes & Pitfalls
Public exposes to other classes and the Inspector, but it does not make a value global. Use [SerializeField] for private fields you still want visible in the Inspector.
Key Takeaway

Expose only the fields you want designers to tune and keep implementation details private to prevent misuse.
