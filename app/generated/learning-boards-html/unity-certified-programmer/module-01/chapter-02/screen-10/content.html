Arithmetic Operators and Modulo
Common numeric operations and when to use modulo.
Code Walkthrough
int health = 100;
int attackDamage = 20;
health = health - attackDamage; // health is now 80

float distance = 15.0f;
float time = 3.0f;
float calculatedSpeed = distance / time; // 5.0f

int remainder = 5 % 2; // 1
Guidance
  • Use subtraction to apply damage and addition to give rewards.
  • Use multiplication to scale speed or apply power-ups.
  • Use modulo to trigger periodic events or test parity.
