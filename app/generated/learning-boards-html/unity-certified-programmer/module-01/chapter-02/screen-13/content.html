Scope: Local vs Member Variables
Decide where variables should live so you can access them where needed.
Member Variable
Declared on the class. Example: public int playerScore = 0; Accessible to all methods in the class and persists across frames.
Local Variable
Declared inside a method. Example: int enemiesDefeated = 0; Exists only while the method runs.
Best Practices
  • Make persistent state member variables.
  • Use local variables for temporary calculations.
  • Avoid reusing names that hide member variables to prevent shadowing bugs.
