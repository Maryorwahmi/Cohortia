Primitive Data Types
Choose the appropriate primitive for your value and operations.
Type Reference
Examples
int — whole numbers (playerHealth = 100)
float — decimals (moveSpeed = 5.5f)
bool — true/false (canMove = true)
string — text (playerName = "Hero")
Practice & Pitfalls
Try these in Start():
int result = 5 / 2; // result is 2
float precise = 5f / 2; // precise is 2.5
bool alive = true;
string name = "PlayerOne";
Gotcha
Integer division truncates decimals. Use float literals when you need precision.
