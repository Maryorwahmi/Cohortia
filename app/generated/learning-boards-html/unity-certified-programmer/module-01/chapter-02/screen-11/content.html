Assignment Operators and Shorthand
Use compound operators to update variables clearly and concisely.
Examples
playerScore = playerScore + 10; // long form playerScore += 10; // shorthand playerHealth -= 20; // apply damage playerSpeed *= 1.2f; // speed boost
Tip
Prefer compound assignments when you update the same variable using a simple expression to reduce errors.
Warnings
  • Watch type compatibility when mixing ints and floats.
  • Remember that compound operators modify the original variable in place.
Key Takeaway

Use shorthand assignments to express intent and reduce duplicate variable names, but check type compatibility.
