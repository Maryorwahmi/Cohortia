Declaring and Initializing Variables
Member fields versus local variables and why initialization matters.
Code Example
using UnityEngine;

public class PlayerManager : MonoBehaviour
{
    public string playerName = "New Player";
    public int playerHealth = 100;
    public float moveSpeed = 5.0f;
    public bool canMove = true;
    public Vector3 currentPosition;

    void Start()
    {
        currentPosition = new Vector3(0, 0, 0);
        int bonus = 50; // local variable
        playerHealth += bonus;
        Debug.Log("Health: " + playerHealth);
    }
}
Notes & Example
  • Member fields are defined on the class and persist across methods and frames.
  • Local variables live only inside a method and are useful for temporary calculations.
  • Initialize currentPosition to a defined Vector3 so movement code has a known start point.
Common Mistake
Expecting a local variable to persist across frames or methods can cause incorrect state assumptions.
Key Takeaway

Use member fields for persistent state and initialize values to avoid undefined behavior.
