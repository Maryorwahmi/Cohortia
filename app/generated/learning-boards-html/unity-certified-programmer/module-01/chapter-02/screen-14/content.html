Key Concepts
A compact reminder of the chapter essentials.
Variables
Named storage with a declared type used to hold game state.
Unity Types
Vector3, Quaternion and Color encapsulate common multi-value data.
Operators & Scope
Arithmetic, assignment, comparison and logical operators, and scope rules determine behavior.
Summary
Pick types that match your data, prefer Unity structs for spatial values, and use operators and scope intentionally to avoid bugs and make code maintainable.
