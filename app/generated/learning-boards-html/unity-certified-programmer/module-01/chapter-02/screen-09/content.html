Operators Overview
How operators let you compute, store, compare and combine values.
Arithmetic
+, -, *, /, %
Assignment
=, +=, -=, *=
Comparison
==, !=, <, >, <=, >=
Logical
&&, ||, !
Concrete Examples
playerScore += 10; // shorthand assignment float calculatedSpeed = distance / time; // arithmetic if (playerScore >= 100) { ... } // comparison bool canMove = isAlive && (health > 0); // logical
Common Mistake
Using = inside a conditional when you meant == changes the variable instead of comparing it.
