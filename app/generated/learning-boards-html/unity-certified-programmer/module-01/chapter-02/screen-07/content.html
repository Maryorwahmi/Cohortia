Unity-Specific Types
Vector3, Quaternion and Color let Unity APIs handle complex values.
Vector3
Represents x, y, z floats. Use for positions and directions. Example: new Vector3(0,1,0).
Quaternion
Represents rotation without gimbal lock. Prefer for smooth rotation math and many transform APIs.
Color
Stores r, g, b, a floats in range 0 to 1. Example: Color.green or new Color(1f, 0f, 0f, 1f).
Practical Note
Using these structures lets you pass a single value into engine methods. For instance, transform.position accepts a Vector3, so keeping position as a Vector3 avoids conversions and keeps intent clear.
