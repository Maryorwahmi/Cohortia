What is a Variable?
A named storage location that holds a value of a defined type.
Definition & Analogy
A variable is like a labeled box where you put a value. The label is the name and the type is the label on the box telling you what can go inside. Using clear names and the right type reduces confusion and prevents errors when you manipulate values later.
Example
public int playerHealth = 100; creates a member variable that stores a whole number representing health.
Misconception
Names do not change behavior; the declared data type and used operators determine what a variable can do.
Key Takeaway
Declare variables with clear names and correct types to make code intentional and safe.
Concrete Scenario
Imagine a scoreboard: score, highScore, and playerName. Choosing int for score and string for playerName ensures you can run arithmetic on score and display playerName as text. If you used string for score you would need to convert types before arithmetic, which is error-prone.
