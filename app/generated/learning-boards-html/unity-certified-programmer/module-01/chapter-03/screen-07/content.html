Health System Example
Understand ordering, edge cases, and event-driven alternatives.
Checks to verify
  • Threshold ordering from smallest to largest where appropriate.
  • Handling exact boundaries like zero or threshold values.
  • Use events rather than Update polling when damage is discrete.
Check Yourself
Try damage values that land exactly on thresholds and confirm only one branch runs.
Code (illustrative)
using UnityEngine;

public class HealthSystem : MonoBehaviour {
    public int currentHealth = 100;

    void Update() {
        if (currentHealth <= 0) {
            Debug.Log("Player is defeated! Game Over.");
        } else if (currentHealth < 30) {
            Debug.Log("Warning: Low health!");
        } else if (currentHealth < 70) {
            Debug.Log("Player is moderately injured.");
        } else {
            Debug.Log("Player health is good.");
        }

        if (Input.GetKeyDown(KeyCode.Space)) {
            TakeDamage(10);
        }
    }

    public void TakeDamage(int damageAmount) {
        currentHealth -= damageAmount;
        Debug.Log("Took " + damageAmount + " damage. Current Health: " + currentHealth);
    }
}
Use the code as a lab starting point, but in real projects prefer event-based damage handlers to avoid per-frame polling of state.
