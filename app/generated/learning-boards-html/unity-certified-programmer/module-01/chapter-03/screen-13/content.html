Module 1 › Chapter 1.3 › Key Concepts
Control Flow
Order of execution and decision logic that makes scripts interactive.
Conditionals
If, else if, else, and switch let you choose code paths based on conditions or state.
Loops
For, foreach, while and do-while repeat tasks; always ensure a safe exit condition.
Takeaway

Use the right control flow construct for clarity and performance; test edge cases and avoid patterns that can freeze the game.
