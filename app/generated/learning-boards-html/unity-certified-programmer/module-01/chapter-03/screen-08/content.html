Core Concept
Loops Overview
Repeat tasks with control over iteration and exit conditions.
for
Best for known counts like spawning N enemies; manage indexes carefully to avoid off-by-one errors.
foreach
Iterate collections without manual index handling; safer and more readable when index is not needed.
while
Run until a condition becomes false; ensure the condition will change to avoid infinite loops.
do-while
Guarantees at least one execution; useful for retry loops or prompts that must run once.
Key Takeaway

Match the loop type to the task: use bounded loops for counts and foreach for safe traversal; always validate exit conditions.

Example: Inventory with foreach
public string[] itemNames = { "Sword", "Shield", "Potion" };

void DisplayInventory() {
    foreach (string item in itemNames) {
        Debug.Log("Inventory item: " + item);
    }
}
This example is concise and avoids index math, which reduces off-by-one risks. Foreach is ideal when you only need the element, not its position.
Warning
Using while without a guaranteed exit or validation can create infinite loops and freeze the Editor.
