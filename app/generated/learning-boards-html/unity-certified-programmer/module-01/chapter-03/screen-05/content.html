Definition
If, Else If, Else
Create exclusive paths based on boolean expressions.
Process: Typical if-chain
  1. Evaluate the first boolean condition.
  2. If true, execute its block and skip the rest.
  3. If false, evaluate the next else if condition, if present.
  4. If none match, run the else fallback if provided.
Pro Tip
Keep each condition focused on a single concept, avoid complex combined logic inside one condition.
Common Mistake
Omitting braces or using separate ifs when exclusivity is required causes logic errors.
Example: Health evaluation
// Evaluate player health
if (currentHealth <= 0) {
    Debug.Log("Player is defeated!");
} else if (currentHealth < 30) {
    Debug.Log("Warning: Low health!");
} else if (currentHealth < 70) {
    Debug.Log("Player is moderately injured.");
} else {
    Debug.Log("Player health is good.");
}
This chain ensures exactly one message runs per evaluation. It avoids multiple conflicting actions and communicates intent clearly.
Key Takeaway

Use else if chains for mutually exclusive checks and add braces even for single-line blocks to prevent later errors.
