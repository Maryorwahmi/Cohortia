Spawning with for
Instantiate a known number of enemies safely and predictably.
Spawner checklist
  • Validate enemyPrefab is assigned before looping.
  • Use i < count for zero-based arrays to avoid off-by-one.
  • Keep expensive calculations outside the loop if possible.
Analogy
Think of a for loop as a conveyor belt that runs a fixed number of items through the same steps.
Example: EnemySpawner
public GameObject enemyPrefab;
public int numberOfEnemiesToSpawn = 5;
public float spawnRadius = 10f;

void Start() {
    if (enemyPrefab == null) {
        Debug.LogError("Enemy Prefab is not assigned to EnemySpawner!");
        return;
    }

    for (int i = 0; i < numberOfEnemiesToSpawn; i++) {
        Vector3 randomPos = transform.position + Random.insideUnitSphere * spawnRadius;
        randomPos.y = transform.position.y;
        Instantiate(enemyPrefab, randomPos, Quaternion.identity);
        Debug.Log("Spawned enemy #" + (i + 1) + " at " + randomPos);
    }
}
This pattern is clear and bounded. Replace Instantiate with pool retrieval for heavy spawn scenarios to avoid allocation spikes.
