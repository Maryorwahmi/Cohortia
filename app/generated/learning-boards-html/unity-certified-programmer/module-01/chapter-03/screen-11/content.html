Definition
While & Do-While
Use for condition-driven repetition; always ensure termination.
Safety checklist
  • Ensure the condition can change and become false.
  • Add max iteration counters for retries to avoid infinite loops.
  • Offload long waits to coroutines or async tasks to avoid blocking frames.
Example: Safe retry
int attempts = 0;
const int maxAttempts = 5;
bool success = false;

while (!success && attempts < maxAttempts) {
    success = TryAction();
    attempts++;
}

if (!success) Debug.Log("Action failed after retries");
This pattern prevents infinite loops by bounding attempts. In Unity, consider using a coroutine with yields between retries to avoid blocking the main thread.
Warning
Never run potentially long while loops directly inside Update; they can freeze the Editor.
