Definition
Switch & Enums
Map named discrete values to specific behavior branches.
When to choose switch
  • When decisions depend on a single variable with multiple known values.
  • When you want readable, maintainable mappings between states and actions.
  • When you want a default fallback for unexpected values.
Example: GameState handling
public enum GameState { StartMenu, Playing, Paused, GameOver }

void HandleGameState(GameState state) {
    switch (state) {
        case GameState.StartMenu:
            ShowStartMenu();
            break;
        case GameState.Playing:
            EnableGameplay();
            break;
        case GameState.Paused:
            PauseGame();
            break;
        case GameState.GameOver:
            ShowGameOver();
            break;
        default:
            Debug.LogWarning("Unknown game state!");
            break;
    }
}
Each case executes exclusively. The default branch protects against unexpected enum values, which is especially useful during refactors.
Pro Tip
Use enums to document allowed states and make switch exhaustive when possible.
Common Mistake
Forgetting break can cause unintentional fall-through. Use comments if fall-through is intentional.
