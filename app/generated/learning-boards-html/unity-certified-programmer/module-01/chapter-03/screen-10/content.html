Comparison
Foreach vs For
Readability versus index control and modification power.
foreach example
foreach (string item in itemNames) {
    Debug.Log("Inventory item: " + item);
}
for example (when index needed)
for (int i = 0; i < items.Count; i++) {
    Debug.Log("Item " + i + ": " + items[i]);
}
When to prefer each
  • Foreach: simple read-only traversal, reduced off-by-one risk.
  • For: need index, remove items safely by iterating backward, or micro-opt when profiling shows benefit.
  • Never modify the collection structure inside a foreach; use a safe pattern instead.
Pro Tip
If you must remove items, iterate from the end toward zero using a for loop to preserve correctness.
