Control Flow: Conditionals and Loops
Decide what runs and when. Build reactive and repeatable gameplay logic.

Control flow determines the path and repetition of execution. In Unity this means responding to input, managing states, and iterating collections. We'll map each construct to common gameplay tasks so you can select the right tool when designing systems like health, spawning, and inventory.
