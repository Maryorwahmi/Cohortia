Module 6 › Chapter 6.1 › Key Concepts
shared_preferences
Platform-backed key-value storage for small primitives and string lists.
Asynchronous API
getInstance and set methods return Futures — await them to avoid timing bugs.
Typed methods & defaults
Use setInt/getInt, setBool/getBool, setStringList/getStringList and handle nulls with defaults.
Remember: centralize keys, avoid storing secrets here, and test startup behavior after saving values.
