Module 6 › Chapter 6.1 › Add & initialize
Step 1
Add dependency
Include shared_preferences in pubspec.yaml and run the package fetch command so the plugin is available.
Step 2
Import and get instance
Call the getInstance method on SharedPreferences from an async helper function and await the returned Future to receive the ready instance.
Pitfall
Calling getInstance without awaiting it often causes null or timing errors. Always await or await returns before using prefs.
