Module 6 › Chapter 6.1 › Settings Screen
Starter checklist
  • Load preferences in an async helper from initState.
  • Provide defaults for missing keys.
  • Use descriptive keys like 'settings_isDarkMode' and 'user_username'.
Example save flow
When the toggle changes, call setBool and update state. When username is submitted, call setString and update the UI text.
Scenario
A user enables dark mode, sets their name to 'Alex', and chooses number 3. After closing and reopening the app, those values should be read and applied automatically.
Default values
isDarkMode → false; username → 'Guest'; favoriteNumber → null or a chosen default.
Key naming
Prefix keys by feature, e.g., 'settings_' or 'user_' to avoid collisions across the app.
Try this: implement each save method and restart the app to verify persistence works as expected.
