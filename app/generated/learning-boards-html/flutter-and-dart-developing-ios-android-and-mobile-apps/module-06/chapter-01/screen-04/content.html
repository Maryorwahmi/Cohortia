Module 6 › Chapter 6.1 › What shared_preferences is
Definition
A platform-backed key-value store
Stores primitive types locally so values survive app restarts without a database.
Use cases
  • Theme or appearance preferences
  • Remember-me flags and last-opened screens
  • Small user settings like a preferred username
Key Takeaway

Use shared preferences for small, non-sensitive, frequently accessed values to improve startup UX.

Analogy
Think of shared preferences as a small, persistent dictionary stored on the device. It keeps simple entries so your app can look up user choices quickly when launching.
Concrete example
Save a boolean called 'isDarkMode' and read it during initialization to set the app theme immediately.
Common misconception
It's sometimes mistaken for secure storage. It is not encrypted and should not hold secrets.
