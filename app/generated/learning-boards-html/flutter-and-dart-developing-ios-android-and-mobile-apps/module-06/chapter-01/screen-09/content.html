Module 6 › Chapter 6.1 › Async Pitfalls
Race condition example
Saving without awaiting then immediately reading can return stale values. Await writes when order matters.
Late initialization
Store the awaited instance in a late variable in init so UI callbacks can safely use it later.
Checklist to avoid issues
  • Await getInstance before using prefs.
  • Await set methods if a subsequent read depends on the write.
  • Use descriptive keys to avoid accidental overwrites.
  • Reuse one prefs instance instead of repeatedly calling getInstance.
Debug tip
Temporarily log the return values of set calls to confirm the platform write succeeded during testing.
