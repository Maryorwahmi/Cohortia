SimpleStorage: Structure and Meaning

Key elements
  • Pragma directive pins the compiler range for reproducible builds.
  • Contract declaration groups state and behavior into a deployable unit.
  • State variables are persisted on-chain in storage slots.
  • Functions modify or read state; view functions indicate no state modification.
Example snippet
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract SimpleStorage {
  uint256 public myNumber;

  function setNumber(uint256 _newNumber) public {
    myNumber = _newNumber;
  }

  function getNumber() public view returns (uint256) {
    return myNumber;
  }
}
Explanation & checks
The setNumber function performs a storage write and therefore consumes gas when called in a transaction. The getNumber function is view and can be called without gas when used by off-chain readers. If another contract calls getNumber during its own transaction, the call costs gas because it runs inside that transaction.
Misconception

View functions are free only for external read calls. In-contract or transactional calls still consume gas.
