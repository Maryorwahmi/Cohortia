State Variables vs. Local Variables

Quick comparison
State Variable
Persists on-chain, stored in storage slots, expensive to write.
Local Variable
Ephemeral during execution, kept in memory or stack, cheaper to use.
Example
Compute a sum in local variables and return it instead of writing it to a state variable when persistence is not needed.
Design tips
  • Avoid unnecessary state writes in frequently called functions.
  • Batch updates to reduce multiple costly storage operations.
  • Use events to publish data off-chain when persistent on-chain state is not required.
Misconception

Local variables do cost some gas; they are not free but are far cheaper than persistent storage writes.
