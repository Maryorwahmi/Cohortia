Counter Contract — Hands-on

Starter code
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract Counter {
    uint256 public count; // State variable to store the counter value

    constructor() {
        count = 0; // Initialize count to 0 when the contract is deployed
    }

    function increment() public {
        count = count + 1; // Increment the counter
    }

    function decrement() public {
        if (count > 0) {
            count = count - 1; // Decrement the counter
        }
    }

    function getCount() public view returns (uint256) {
        return count; // Return the current count
    }
}
Activity steps & checks
  1. Create Counter.sol in Remix and paste the code.
  2. Select a compiler matching the pragma, compile until no warnings remain.
  3. Deploy to a test environment and call increment; observe gas used on the transaction receipt.
  4. Call decrement at zero to confirm the guard prevents underflow.
Key Takeaway

Testing contracts in a safe environment helps you observe gas costs for storage writes and verify basic correctness before deployment.
