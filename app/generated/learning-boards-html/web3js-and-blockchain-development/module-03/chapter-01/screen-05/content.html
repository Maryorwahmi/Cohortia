Ethereum Virtual Machine (EVM)

A sandboxed, deterministic stack machine that runs compiled bytecode on every node.

Architecture Overview
The EVM executes instructions that manipulate a stack, memory, and persistent storage. Every node applies the same rules so that given identical inputs the resulting state is identical across the network.
  • Stack-based execution: operations push and pop values on a stack.
  • Memory vs. storage: memory is ephemeral during execution; storage persists on-chain.
  • Gas enforces limits and compensates validators for work.
Practical note
Because the EVM executes low-level bytecode, high-level constructs that look simple can generate many instructions and cost gas. Keep critical paths efficient.
Concrete Walkthrough
Imagine calling a setter function that updates a state variable. The compiler turns the function into bytecode that reads the input, writes to storage slots, and emits any events. Each low-level step consumes gas, and if the transaction exhausts its gas limit before completion, the EVM reverts state changes while miners keep the gas payment up to that point.
Misconception
The EVM is not a single server. It is a specification implemented by many nodes so determinism and consensus matter for correctness.
