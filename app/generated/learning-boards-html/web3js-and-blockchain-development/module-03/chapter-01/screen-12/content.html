Visibility and Function Modifiers

Common keywords
  • public: callable externally and internally; for state variables it creates a getter.
  • view: promises not to modify state; off-chain reads can be gas-free.
  • private/internal: restrict access inside the contract or inheritance tree.
Example question
If a function is marked view but called by another contract inside a transaction, will it consume gas? Yes — it runs as part of the caller's transaction and consumes gas.
Access control tip
For functions that should be restricted, add explicit checks such as verifying the caller address or using well-defined modifiers. Do not rely solely on 'private' to secure sensitive logic that depends on external conditions.
Misconception

Visibility keywords change accessibility but do not substitute for explicit authorization checks when sensitive actions are involved.
