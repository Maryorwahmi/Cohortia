Gas: The EVM's Fuel

Gas measures computational steps, limits execution, and determines transaction cost in Ether.

How gas works
  • Each EVM opcode has a fixed gas cost; storage writes are among the most costly operations.
  • Callers set a gas limit to bound execution; if the limit is exceeded, execution reverts.
  • Gas price sets the Ether-per-gas unit and is determined by network demand.
Concrete example
Calling a function that updates a state variable consumes gas for reading inputs, computing, and writing to storage. If you hit the gas limit, the EVM reverts state changes but consumes the paid gas.
Common mistakes & tips
  • Underestimating gas for loops or storage-heavy patterns can lead to reverts and lost fees.
  • Assume view functions cost no gas only when called off-chain by a read provider; in-contract calls may cost gas.
  • Measure and profile expensive paths in a testnet before mainnet deployment.
Key Takeaway

Treat gas as both a fee and a safety budget; design contracts to minimize expensive operations.
