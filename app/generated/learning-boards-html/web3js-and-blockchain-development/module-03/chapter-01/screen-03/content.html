Learning Objectives — Practice and Safety

Practice Steps
  1. Match the compiler version to the pragma and compile the sample contract until there are no warnings.
  2. Run a read-only call to a view function to observe that no gas is consumed by the caller when using a read provider.
  3. Deploy the counter contract and call increment to observe gas usage for state changes.
  4. Test edge cases such as decrement at zero to see safe guards in practice.
Safety Notes
  • Treat deployed contracts as immutable — plan upgrades or use proxy patterns later.
  • Do not store secrets in state variables; anyone can read on-chain data.
  • Think about gas costs when designing frequently executed paths.
