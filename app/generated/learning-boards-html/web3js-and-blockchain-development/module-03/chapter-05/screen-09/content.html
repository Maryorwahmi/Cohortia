SimpleStorage contract
Use this contract to observe view and transaction behavior in Remix JavaScript VM.
contract SimpleStorage {
    uint256 public myNumber;

    function setNumber(uint256 _newNumber) public {
        myNumber = _newNumber;
    }

    function getNumber() public view returns (uint256) {
        return myNumber;
    }
}
Steps in Remix
  1. Paste code and select the compiler version.
  2. Compile and switch to JavaScript VM.
  3. Deploy SimpleStorage and note the deployed contract instance.
  4. Call getNumber (view) then transact setNumber(42) and confirm getNumber returns 42.
Verification tip
After deploying, copy the ABI and deployed address if you want to test from Web3.js or a separate script.
