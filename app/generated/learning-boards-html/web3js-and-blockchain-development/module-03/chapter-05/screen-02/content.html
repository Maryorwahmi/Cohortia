Learning Objectives
These objectives guide the hands-on steps you will practice.
01
Compile Solidity

Produce bytecode and ABI using Remix or solc so your contract is ready for deployment and external calls.

VERIFIED COMPETENCY MILESTONE
02
Deploy to local network

Use JavaScript VM, Ganache, or Hardhat Network to deploy contracts for fast, safe testing.

VERIFIED COMPETENCY MILESTONE
03
Interact with contract functions

Call view functions locally and send transactions for state changes, observing gas costs and events.

VERIFIED COMPETENCY MILESTONE
04
Use ABI with Web3.js

Provide ABI and contract address to Web3.js so your frontend can encode calls and decode results and events.

VERIFIED COMPETENCY MILESTONE

How to use these objectives

Follow the objectives in order: compile examples, deploy locally, run read and write calls, then wire ABI and address into a Web3.js frontend for tests.
