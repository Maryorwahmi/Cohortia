Verification tasks
Use these tasks as a checklist while you code and deploy.
Extract ABI and bytecode
Save the ABI JSON and bytecode binary to files or variables for your Web3.js app.
Deploy locally and confirm
Deploy to JavaScript VM, call view methods, then send a transaction and observe the state change.
Wire ABI + address into Web3.js
Instantiate a contract object, run a read call and a state-changing send to validate behavior.
Checkpoints
  • Compiled ABI matches current source.
  • Deployed address recorded for frontend tests.
  • Events appear in logs after a transaction.
