Module 4 › Chapter 3.5 › Compilation
Bytecode
Low-level EVM code produced by the compiler. This is what is stored on-chain during deployment and executed by nodes.
Example (truncated)
0x608060405234801561001057600080fd5b5060...
Key Takeaway

Bytecode is required to create the on-chain contract; ABI is required to call it correctly.

ABI (Application Binary Interface)
A JSON array that lists functions, inputs, outputs, state mutability, and events. Web3.js reads this to know how to encode and decode.
ABI snippet
[
  {
    "inputs":[],
    "name":"getNumber",
    "outputs":[{"internalType":"uint256","name":"","type":"uint256"}],
    "stateMutability":"view",
    "type":"function"
  }
]
Common misconception
The ABI is not executable code. It is required by clients to format calls correctly; omitting it causes incorrect encoding or failed decodes.
Practical tip
Store ABI with version control alongside source to prevent ABI-contract mismatches after redeploys.
