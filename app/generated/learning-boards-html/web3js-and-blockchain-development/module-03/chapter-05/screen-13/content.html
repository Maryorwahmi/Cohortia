Module 4 › Chapter 3.5 › Assessment
Assessment steps
Follow these steps and collect evidence: ABI file, deployed address, console output showing call results and transaction receipt.
Deliverable
A short script that instantiates the contract with ABI and address, calls a view method, sends a transaction to modify state, and prints the receipt and updated value.
Grading hints
  • Script shows initial call output.
  • Transaction receipt is logged.
  • Follow-up read shows changed state.
Key Takeaway

The simplest evidence of mastery is a working ABI plus address used by Web3.js to read and modify contract state with logged receipts and results.
