Module 4 › Chapter 3.5 › Overview
Smart Contract Deployment and Interaction Basics
Understand compilation outputs, deployment targets, and how Web3.js interacts with a contract at runtime.
In this lesson
Compile → Deploy → Interact

Follow the path from .sol source to runtime bytecode, learn ABI usage, and practice calls and transactions using Remix and local networks.

Why it matters
Bridge frontend and blockchain

You need ABI and address to let Web3.js format calls and decode results; deployment makes your contract addressable on-chain.

Practical tools
Remix, solc, Ganache, Hardhat

Use Remix for quick testing, solc or Hardhat for automated pipelines, and Ganache or Hardhat Network for local testing.

Safety note
Protect keys, test gas

Never hard-code private keys. Test gas usage locally before public deployment to avoid costly failures.

Explore Key Topics
Compilation
Solidity builds bytecode and an ABI — both are required for deployment and runtime calls.
Local Networks
Use JavaScript VM, Ganache, or Hardhat Network to test without spending real Ether.
Interacting with Contracts
View calls are free; transactions change state and consume gas. ABI + address let Web3.js make calls.
