Module 4 › Chapter 3.5 › Local Deployment
Deploy flow
Compile, pick environment, supply constructor args, send deploy transaction, record contract address and ABI.
Remix JavaScript VM
Instant mining, ephemeral state. Use for quick checks and immediate feedback.
Ganache
Persistent local chain with pre-funded accounts. Better for longer tests and scripts.
Hardhat Network
Integrated debugging and configuration. Useful for tracing and advanced testing scenarios.
What is deployed
The deploy transaction sends the compiled bytecode and runs the constructor. After mining, the runtime bytecode remains at the new contract address.
Deployment checklist
  • Compiler version matches pragma.
  • Constructor args supplied if required.
  • Record deployed address and ABI.
