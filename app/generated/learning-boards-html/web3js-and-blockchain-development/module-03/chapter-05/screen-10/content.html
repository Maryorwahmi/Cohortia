Instantiate a contract
Web3.js needs ABI and address to create a contract object you can call or send transactions to.
Conceptual code
// Pseudocode example
const contract = new web3.eth.Contract(ABI_JSON, '0xDeployedAddress');
const value = await contract.methods.getNumber().call();
await contract.methods.setNumber(42).send({from: deployerAddress});
Event decoding
Web3.js uses ABI to decode logs and events emitted by transactions so you can react to them in your app.
Common mistakes
  • Using an ABI that doesn’t match the deployed bytecode.
  • Forgetting to record the deployed address after each deployment.
  • Assuming transactions return function values synchronously — they return receipts.
Key Takeaway

ABI plus address form the contract handle Web3.js uses to encode calls and decode results; keep them synchronized with your source and deployments.
