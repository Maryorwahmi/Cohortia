One-time constructor execution
Constructor code runs during deployment to initialize state, then is discarded from the stored runtime bytecode.
Example
A constructor that sets totalSupply and mints to msg.sender will run once. After deployment, totalSupply is stored and accessible via view functions.
Misconception
The constructor cannot be called later. Any further changes must be performed by public/state-changing functions you include separately.
What the transaction contains
  • Contract bytecode plus constructor arguments encoded in the data field.
  • Sender pays gas for deployment; deployment consumes more gas than typical calls due to storage writes.
  • After mining, the network returns the new contract address for use by clients.
Developer tip

Test constructor behavior on a local network before deploying to shared testnets or mainnet to confirm initialization logic and gas costs.
