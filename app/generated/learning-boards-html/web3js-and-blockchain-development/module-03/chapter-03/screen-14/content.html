Module 3 › Chapter 3.3 › What to Remember
Plan visibility
Use the least permissive visibility required and mark mutability explicitly.
Use modifiers
Centralize access and validation checks, and always include _; in modifiers.
Emit events
Log meaningful events for UIs and monitoring; index fields you will filter by.
Parting question
Which function in your next contract should be public, which internal, and what event would you emit to keep your UI informed?
