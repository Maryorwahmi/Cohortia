Control who calls your code, when it runs, and how your dApp learns about changes.
In this lesson

Explore Key Topics
Function Types
Visibility and mutability determine where and how a function runs.
Modifiers
Reusable pre-conditions like access checks and validation logic.
Events
Efficient logs for off-chain listeners and UI updates.
Visual Overview
Functions are gates, modifiers are guards, events are signals.
Function: named logic with parameters and return types. Controlled by visibility and mutability.
Modifier: pre-execution check that inserts the function body at the placeholder.
Event: emitted log used by off-chain tools and dApp UIs.
