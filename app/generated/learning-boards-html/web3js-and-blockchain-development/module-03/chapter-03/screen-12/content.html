Voting snippet (minimal)
mapping(address => bool) private voters;
uint256 public totalVotes;

// Event to log votes
event VoteCast(address indexed _voter, uint256 _timestamp);

// Modifier to ensure a user hasn't voted yet
modifier hasNotVoted() {
    require(!voters[msg.sender], "You have already voted.");
    _;
}

function castVote() public hasNotVoted {
    voters[msg.sender] = true; // Mark voter as voted
    totalVotes++; // Increment total votes
    emit VoteCast(msg.sender, block.timestamp); // Log the vote
}
Check: apply the modifier and verify the mapping and event after each call to confirm the guard and the log behavior.
Payable pitfall
If a function that should accept Ether is not marked payable, transactions that include value will revert. Solidity enforces payable as a safety measure to avoid accidental transfers.
Test
Attempt to send value to a non-payable function in Remix and observe the immediate revert to reinforce the rule.
