Modifier anatomy
A modifier includes checks and the special underscore placeholder. When applied, execution jumps into the modifier, runs its code, then continues at the underscore location where the function body runs.
Declare modifier
Perform require checks
Include _; where function executes
Common mistake
Omitting the underscore stops the function body from running. Always verify modifiers contain _; and that modifier order matches your desired control flow.
Concrete example
modifier onlyOwner() {
    require(msg.sender == owner, "Only the contract owner can call this function.");
    _;
}

function changeOwner(address _newOwner) public onlyOwner {
    owner = _newOwner;
}
Action: remove the underscore, compile, and watch that changeOwner no longer executes its body — then restore _; to see normal behavior again.
