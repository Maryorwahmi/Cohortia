Type Detail

address · address payable

A 20-byte identifier for EOAs and contracts. Use payable when the address must receive Ether.

address owner = 0xAbc1230000000000000000000000000000000000;
address payable recipient = payable(0xDef4560000000000000000000000000000000000);

// To transfer:
// recipient.transfer(amount);
Misconception

Not every contract can accept Ether. Ensure the recipient is payable and has a fallback or receive function if needed.

Practical advice
  • Declare payable only when receiving value is required.
  • Use call with gas controls and check return values to avoid unexpected failures.
  • Document which addresses are expected to be EOAs or contracts.
Key Takeaway

Make intent explicit: only mark addresses payable when the account must receive Ether.
