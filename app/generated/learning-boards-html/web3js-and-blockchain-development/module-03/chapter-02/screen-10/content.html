Reference Types

Structs

Group related variables into a named composite type for clearer state modeling.

struct User {
  address userAddress;
  string name;
  uint256 score;
  bool isActive;
}

User public admin; // state variable of type User
Mutation rules
  • Use storage to obtain a reference and persist changes.
  • Use memory for a temporary copy that won’t persist.
  • Always be explicit when assigning structs to avoid unintended non-persistent edits.
Misconception

Modifying a struct loaded into memory does not change storage. Use a storage reference for persisting updates.
