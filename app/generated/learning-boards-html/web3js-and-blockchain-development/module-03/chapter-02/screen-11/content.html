Reference Types

Mappings

Key-value stores for O(1) checks and direct access; not iterable by design.

mapping(address => uint256) public balances;

function updateBalance(address _user, uint256 _amount) public {
  balances[_user] = _amount;
}
Patterns
  • Use mapping for O(1) existence checks like mapping(address => bool) contributors.
  • If iteration is required, maintain an auxiliary array of keys and accept extra gas.
  • Consider emitting events for off-chain indexing rather than on-chain iteration.
Key Takeaway

Mappings are efficient but non-iterable. Use them for membership and lookups; move aggregation off-chain when possible.
