Learning Objectives

Four measurable skills to confirm while you code and test.

01
Differentiate Value vs Reference

Explain the copy semantics of value types vs the pointer semantics of reference types and why gas differs.

Venn: cost vs behavior
VERIFIED COMPETENCY MILESTONE
02
Declare Common Value Types

Write and initialize uint, int, bool, address, bytes, and string safely and understand fixed-size bytes tradeoffs.

Mnemonic: type → size → intent
VERIFIED COMPETENCY MILESTONE
03
Use Reference Types

Model complex data with arrays, structs and mappings and know when to store in memory, storage, or calldata.

Mnemonic: structure → access → cost
VERIFIED COMPETENCY MILESTONE
04
Apply Visibility Safely

Choose public, private, internal or external to expose only the functions and variables required by your contract interface.

Mnemonic: least privilege
