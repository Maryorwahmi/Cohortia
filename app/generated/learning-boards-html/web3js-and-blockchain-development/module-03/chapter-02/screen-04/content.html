Core Concept

Value vs Reference Types

A precise definition and practical implications for storage and gas.

Value types copy data: integer, bool, address.
Reference types copy pointers: arrays, structs, mappings.
Storage location matters: storage, memory, calldata.
Key Takeaway

Pick value types for independent small data. Use reference types intentionally and avoid copying large structures.

Example
// Storage reference vs memory copy
uint[] public storageArray;

function addThenCopy() public {
  storageArray.push(1); // modifies storage
  uint[] memory copyArray = storageArray; // copies values into memory -- gas cost
  // modifying copyArray does not change storageArray
}
Misconception

Assuming a reference assignment makes an independent snapshot. In reality you still reference the same storage unless you explicitly copy to memory.
