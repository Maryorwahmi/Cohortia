Value Types

bool · uint · int · address · bytes · string · enum

bool — flags, true or false.
uint / int — numeric types; default to 256 bits if unspecified.
address — 20-byte account or contract reference; cast to payable to send Ether.
bytes / string — binary and text; prefer bytes1..bytes32 if fixed length known.
enum — named integer states for readability.
Examples
bool isActive = true;
uint256 balance = 1000;
int256 temperature = -5;
address owner = 0xAbc1230000000000000000000000000000000000;
bytes32 myHash = keccak256("hello");
enum State { Pending, Approved, Rejected }

      

        
Misconception

        
Smaller bit widths always save gas—this is not always true. Choose types for clarity and safety; optimize only after measuring gas usage in context.
