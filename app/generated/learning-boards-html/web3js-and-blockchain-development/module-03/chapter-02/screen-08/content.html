Type Detail

bytes · string

Prefer fixed-size bytes when length is known; avoid storing long strings directly on-chain.

bytes32 myHash = keccak256("hello");
string name = "Cohortia Course";
// Storing a large string is costly; consider storing only the hash on-chain.
Practical guideline
  • Use bytes1..bytes32 for fixed-size binary data.
  • Store hashes on-chain and larger payloads off-chain (for example, IPFS).
  • Accept strings via calldata in external functions to reduce copies.
Why it matters

Gas costs scale with stored bytes. Minimize on-chain payloads for lower deploy and transaction costs.
