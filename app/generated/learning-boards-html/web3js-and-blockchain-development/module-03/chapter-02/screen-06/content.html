Warning

Integer overflow and underflow

Understand default safety behavior and when explicit checks are necessary.

uint8 count = 255;
// In Solidity 0.8+, this will revert:
// count++;
Practical guidance
  • Rely on Solidity 0.8+ default checks for standard arithmetic.
  • Use require for domain-specific bounds and clear error messages.
  • Use unchecked blocks only when you fully audit and document the math operations to be safe.
Misconception

Assuming arithmetic always wraps silently. In modern Solidity, standard arithmetic reverts on overflow; wrapping must be intentionally used within unchecked blocks.

Pro Tip

Prefer uint256 for counters and token values unless you need a smaller type for packed storage. Test edge cases.
