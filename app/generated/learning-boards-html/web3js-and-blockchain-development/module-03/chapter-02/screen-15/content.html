What to Remember

Restrict Visibility
Use least privilege: make functions and variables as private as possible.
Minimize On-Chain Data
Store hashes or pointers, not large files or lengthy text, to control gas.
Be Explicit About Storage
Use storage for persistent changes and memory for temporary copies to avoid surprises.
Final reflection

Before you deploy, map data location, visibility, and gas cost for each state element. That planning prevents many common issues.
