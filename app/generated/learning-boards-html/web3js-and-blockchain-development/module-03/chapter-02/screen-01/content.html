Solidity Data Types and Variables

Understand how values and references behave, and why visibility and storage choices matter for security and gas.

16:9 HD Classroom
In this lesson

Compare value vs reference types, declare common types, manage arrays/structs/mappings, and apply visibility for secure contracts.

Why it matters

Type choices affect storage cost, gas, and correctness. Visibility limits attack surface and unintended reads or calls.

Quick orientation
  • Value types: copied on assignment and cheap for small data.
  • Reference types: point to memory/storage and can be costly to copy.
  • Visibility: public/private/internal/external determine access and generated getters.
Concept visual
A value stores the data; a reference points to storage or memory.
