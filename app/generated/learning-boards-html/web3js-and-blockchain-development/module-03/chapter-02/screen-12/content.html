Access Control

public · private · internal · external

Choose visibility to limit exposure and manage inheritance behavior.

contract VisibilityExample {
  uint256 public publicVar = 10;
  uint256 private privateVar = 20;
  uint256 internal internalVar = 30;

  function externalFunction() external pure returns (string memory) {
    return "Called externally";
  }
}
Practical rules
  • Default state variable visibility is internal; make variables private when external access isn’t needed.
  • Use external for functions that are part of the contract's public interface and will be called from outside.
  • Document why a function is public to reduce accidental exposure during maintenance.
Common mistake

Leaving functions public by accident increases the attack surface. Prefer restrictive visibility by default.
