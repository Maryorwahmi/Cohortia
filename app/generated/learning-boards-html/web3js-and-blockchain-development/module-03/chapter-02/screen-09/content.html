Reference Types

Arrays

Fixed-size vs dynamic, and the three storage locations: storage, memory, calldata.

uint[] public ages; // dynamic storage array

function addAge(uint _age) public {
  ages.push(_age);
}
Common mistake

Iterating through a very large storage array in a single transaction can exhaust gas. Design APIs to read pages or use mappings for direct lookup.

Practical patterns
  • Use calldata for external read-only arrays to avoid copies.
  • Use memory for local, temporary transformations.
  • Combine mapping for O(1) lookups with arrays if you need iteration and membership checks.
Key Takeaway

Memory and calldata provide cheaper, temporary storage. Minimize expensive storage loops.
