Lab Steps
1. Create & Deploy

Add Whitelist.sol, compile with 0.8.x, deploy with _maxAddresses = 3 in the JavaScript VM.

2. Test Add/Remove

As owner add three addresses, attempt a fourth, and remove one. Observe reverts and counts.

3. Provocations

Switch accounts to trigger NotOwner and NotWhitelisted errors to confirm modifier and guard behavior.

4. Assess & Reflect

Answer: Use require for expected checks like preventing double-mint. Do not use assert for input validation because it consumes gas on failure.
