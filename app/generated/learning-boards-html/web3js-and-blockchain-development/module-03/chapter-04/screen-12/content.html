Module 3 › Chapter 3.4 › assert()
Definition

Use assert for invariants only

Example check
// After increment
numWhitelistedAddresses++;
assert(numWhitelistedAddresses <= maxWhitelistedAddresses);
Why it's different

An assert failure consumes remaining gas and signals a bug; treat such failures as critical and rare.

Checklist
  • Use require/revert for user or state validation.
  • Reserve assert for invariants proven by tests.
  • When assert fires in production, perform an immediate investigation.
