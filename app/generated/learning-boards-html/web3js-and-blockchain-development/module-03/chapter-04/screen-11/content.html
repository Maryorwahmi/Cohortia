Custom Error Example
error MaxAddressesReached(uint256 maxAllowed, uint256 currentCount);

if (numWhitelistedAddresses >= maxWhitelistedAddresses) {
  revert MaxAddressesReached(maxWhitelistedAddresses, numWhitelistedAddresses);
}
Explanation
  • Custom errors encode typed data and are more gas-efficient than long strings.
  • Revert behaves like require with respect to gas refunds, but supports custom errors and conditional patterns.
  • Use revert when you need flexibility or detailed error diagnostics for callers.
Pro tip

Declare and reuse custom errors for common failure modes to keep revert sites concise and informative.
