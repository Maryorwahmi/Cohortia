Module 3 › Chapter 3.4 › Gas Limit & Loops
Problem

Unbounded iteration can exceed gas limits

Off-chain processing

Collect and compute results off-chain, then submit only final state or proofs to the contract to avoid heavy on-chain loops.

Batching

Process a fixed number of elements per transaction. Allow users to call multiple times to finish processing large sets.

Mappings vs Arrays

Use mappings for direct lookup to avoid global iteration. Use arrays only when ordered enumeration is essential.

Common Mistake

Assuming a small array stays small in production. Growth over time turns safe loops into failures.

Key Takeaway

Design for predictable gas: prefer patterns that bound on-chain work or offload it entirely.
