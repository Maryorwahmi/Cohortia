Module 3 › Chapter 3.4 › require()
Usage

Check inputs and permissions

function withdraw(uint256 _amount) public {
  require(balances[msg.sender] >= _amount, "Insufficient balance.");
  balances[msg.sender] -= _amount;
  payable(msg.sender).transfer(_amount);
}
Explanation
  • Validate preconditions first so you never mutate state when the call should fail.
  • Require refunds remaining gas, making it suitable for user-facing checks.
  • Use concise messages or custom errors to save deployment gas if needed.
Key Takeaway

Require is the right tool for expected, recoverable errors where the user should get gas refunds and a clear message.
