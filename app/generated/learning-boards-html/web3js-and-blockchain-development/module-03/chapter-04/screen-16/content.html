Module 3 › Chapter 3.4 › Key Concepts — Part 2
require()
For input and permission checks; refunds remaining gas on failure.
revert()
Explicit early exit; supports custom errors and refunds gas.
assert()
For internal invariants only; consumes remaining gas when it fails.
Final Takeaway

Prefer require/revert for user-facing checks so failures refund gas. Use assert only to catch invariants that signal a bug.
