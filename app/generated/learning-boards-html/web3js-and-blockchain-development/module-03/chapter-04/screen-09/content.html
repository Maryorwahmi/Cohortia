Definition

require, revert, assert — purpose and behavior

require(condition, message)

Validate user input and external conditions. If false, revert and refund remaining gas.

revert(message)

Explicitly revert with a message or custom error. Also refunds remaining gas. Useful for complex logic.

assert(condition)

Check internal invariants. If false, revert and consume all remaining gas — indicates a bug.

Practical rule

Require/revert for external-facing validation; assert for invariants that should never fail if code is correct.
