Summing an array with for

contract LoopExample {
  uint256[] public numbers;
  constructor() {
    numbers.push(1);
    numbers.push(2);
    numbers.push(3);
    numbers.push(4);
    numbers.push(5);
  }
  function sumArray() public view returns (uint256) {
    uint256 total = 0;
    for (uint256 i = 0; i < numbers.length; i++) {
      total += numbers[i];
    }
    return total;
  }
}
Explanation
  • The loop increments i from 0 up to numbers.length - 1 and accumulates total.
  • Because sumArray is view, it can be called off-chain without gas in many contexts.
  • If numbers were large and sumArray modified state, you could hit gas limits; keep arrays bounded.
When to use

Use for loops for deterministic, bounded iteration, especially in view or pure functions. For unbounded data, rework the pattern.

Common Mistake

Running full-array loops in state-changing functions where the array can grow creates a gas limit risk.
