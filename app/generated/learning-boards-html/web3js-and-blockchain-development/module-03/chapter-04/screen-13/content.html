Architecture

Whitelist: mapping + checks + custom errors

Core state
  • owner address
  • maxWhitelistedAddresses (uint256)
  • numWhitelistedAddresses (uint256)
  • whitelistedAddresses mapping(address => bool)
Error design

Custom errors like MaxAddressesReached and AlreadyWhitelisted are declared for gas efficiency and clearer diagnostics when reverting.

Key Methods (summary)
constructor: validate max, set owner
addAddressToWhitelist: checks, map update, count++, assert
removeAddressFromWhitelist: check presence, unset, count--
