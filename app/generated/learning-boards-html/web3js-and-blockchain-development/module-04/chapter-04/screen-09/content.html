Module 4 › Chapter 4.4 › Signing Securely
Development: Local signing
Use web3.eth.accounts.signTransaction with a private key from Ganache for debugging and logs.
Example
signed = await web3.eth.accounts.signTransaction(rawTransaction, senderPrivateKey)
Danger
Never commit or deploy code with private keys embedded. Use vaults or HSMs for backend signing.
Production: Wallet signing
Use window.ethereum or provider methods so the user's wallet manages keys, gas, and nonce when appropriate.
Example
window.ethereum.request({ method: 'eth_sendTransaction', params: [transactionObject] }) — wallet handles signing.
Key Takeaway

Prefer wallet-based signing for applications and secure key storage for backend needs. Confirm nonce and from address before broadcast.
