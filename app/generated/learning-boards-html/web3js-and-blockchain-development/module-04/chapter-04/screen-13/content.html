Module 4 › Chapter 4.4 › Production Best Practices
Protect keys
Delegate signing to user wallets; for backend signing use secure vaults and HSMs with tight access controls.
Observability
Log nonce, estimatedGas, gasPrice, and balances before sending to make debugging fast when errors occur.
Retry & monitoring
Implement retries for transient failures, detect stuck nonces, and alert when many out-of-gas failures occur.
Defaults
  • Estimate gas + 10–20% buffer
  • Use pending nonce for ordering
  • Let wallets set nonce/gas for user-submitted tx
Key Takeaway

Use secure signing, sensible defaults, and robust logging to minimize production issues and enable fast diagnosis.
