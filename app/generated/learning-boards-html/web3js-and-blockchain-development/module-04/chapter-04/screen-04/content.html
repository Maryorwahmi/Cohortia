What is a transaction?

A signed message that requests a state change on the blockchain. It includes fields such as to, value, data, nonce, gasPrice, and gasLimit.

Concrete example
Send 0.1 Ether from one Ganache account to another, sign with the sender's private key, and broadcast the raw transaction.
Common misconception
Transactions are not ephemeral calls; they are ordered, persistent, and once mined can never be rolled back except by a hard fork.
Why it matters
Understanding that transactions change state helps you design idempotent interactions and detect failures by reading receipts.
Key Takeaway

A signed transaction causes a deterministic state change and consumes gas. Verify success with the transaction receipt.

Annotated Transaction Fields
to
Recipient address; omit for contract creation.
value
Amount of Ether in Wei to transfer.
data
ABI-encoded call data for contracts; optional for simple transfers.
nonce
Sequential counter ensuring unique ordering per sender.
gasPrice
Wei-per-unit you pay to miners for execution.
gasLimit
Maximum gas you're willing to spend to run the transaction.
