Module 4 › Chapter 4.4 › Construct Transaction
Checklist to build a safe raw transaction
  1. Get pending nonce: web3.eth.getTransactionCount(sender, 'pending').
  2. Estimate gas: web3.eth.estimateGas({...}).
  3. Get gas price: web3.eth.getGasPrice().
  4. Buffer gas limit by 10–20% and assemble the tx object.
Practical tip
Log the transaction object before signing so you can review nonce and gas settings.
Code example
const nonce = await web3.eth.getTransactionCount(senderAddress, 'pending');
const estimatedGas = await web3.eth.estimateGas({ from: senderAddress, to: receiverAddress, value: amountInWei });
const gasLimit = Math.round(estimatedGas * 1.1);
const gasPrice = await web3.eth.getGasPrice();

const rawTransaction = {
  from: senderAddress,
  to: receiverAddress,
  value: amountInWei,
  gasPrice: gasPrice,
  gasLimit: gasLimit,
  nonce: nonce
};
Key Takeaway

Follow the checklist: pending nonce, estimateGas, buffer, then sign. This reduces ordering and out-of-gas failures.
