Module 4 › Chapter 4.4 › Nonce Handling
Nonce: sequential transaction counter
Ensures each outgoing transaction is unique and preserves the send order.
Too low nonce
Rejected because that nonce was already processed.
Too high nonce
Held pending until earlier nonces are mined; may be dropped if gap persists.
Practical tip
Use web3.eth.getTransactionCount(address, 'pending') to include unmined transactions and get the next valid nonce.
Check your understanding
If two transactions are signed with the same nonce, only the one with the higher gasPrice is likely to be mined first; the other will be dropped or replace it depending on node policies.
Key Takeaway

Always fetch the pending transaction count before signing to prevent nonce collisions and ordering errors.
