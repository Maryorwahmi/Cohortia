Script flow
  1. Get accounts and check there are at least two.
  2. Compute amountInWei and read initial balances.
  3. Fetch pending nonce and estimate gas.
  4. Buffer gas, get gasPrice, assemble and sign transaction.
  5. Send signed transaction and inspect receipt and final balances.
Starter code snippet
// TODO: Replace '0x...' with your Ganache private key
const nonce = await web3.eth.getTransactionCount(senderAddress, 'pending');
const estimatedGas = await web3.eth.estimateGas({ from: senderAddress, to: receiverAddress, value: amountInWei });
const gasLimit = Math.round(estimatedGas * 1.1);
const gasPrice = await web3.eth.getGasPrice();

const txObject = { from: senderAddress, to: receiverAddress, value: amountInWei, gasPrice, gasLimit, nonce };
const signedTx = await web3.eth.accounts.signTransaction(txObject, senderPrivateKey);
const receipt = await web3.eth.sendSignedTransaction(signedTx.rawTransaction);
Key Takeaway

Follow the flow and verify balances and receipt fields to confirm the transfer and fee deduction.
