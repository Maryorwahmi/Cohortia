Module 4 › Chapter 4.4 › Broadcast & Receipt
Broadcast flow
Send the signed raw transaction to the node and wait for a receipt when the transaction is mined.
Send example
const receipt = await web3.eth.sendSignedTransaction(signed.rawTransaction)
Receipt fields to inspect
  • transactionHash — useful for linking and tracking.
  • blockNumber — which block included the transaction.
  • gasUsed — actual gas consumed by this execution.
  • status — success (0x1) or failure (0x0) for contract calls.
UX and monitoring
Show a transaction hash immediately and update UI when receipt returns. For higher guarantees, wait for multiple confirmations on public networks.
Misconception
A broadcasted transaction hash does not guarantee success; only the mined receipt and status do.
Key Takeaway

Use the transaction receipt to confirm final state changes and to surface gasUsed and status to users for transparency.
