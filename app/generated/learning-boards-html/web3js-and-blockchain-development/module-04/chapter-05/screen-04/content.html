Core Concept › Read Operations
Definition and Cost Model
View reads state, pure computes without state. Both are executed locally and cost no gas.
When to use .call()
  • Fetch balances, owner addresses, or stored values.
  • Preview calculations performed by pure functions.
  • Populate UI elements without prompting a transaction.
Misconceptions
  • .call() will not persist state changes. Use .send() for transactions.
  • A wrong ABI or address will cause function-not-found errors.
  • Node sync state can affect read results on non-finalized chains.
Concrete Examples
Example: Read a stored value
Contract method getData().call() returns a number without a transaction.
Example: ERC-20 balance
Call balanceOf(address).call() and convert from token units with fromWei to show user balance.
Key Takeaway
Reads are fast and free. Use them for UIs and queries. Reserve transactions for state updates.
