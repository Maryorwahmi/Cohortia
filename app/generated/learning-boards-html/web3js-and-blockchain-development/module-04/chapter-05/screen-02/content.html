Learning Objectives
Concrete skills you will practice and verify.
01
Instantiate a Contract
Create a web3.eth.Contract using the contract ABI and deployed address. This object encodes methods and events for calls.
Verified Competency Milestone
02
Call view and pure functions
Use contract.methods.fn(...).call() to read state or compute values locally without sending a transaction.
Verified Competency Milestone
03
Retrieve Past Events
Query getPastEvents with fromBlock/toBlock and read each event's returnValues, blockNumber, and transactionHash.
Verified Competency Milestone
04
Apply to Token Queries
Use these reads to fetch token name, symbol, totalSupply, and account balances for UIs and analytics.
Verified Competency Milestone
