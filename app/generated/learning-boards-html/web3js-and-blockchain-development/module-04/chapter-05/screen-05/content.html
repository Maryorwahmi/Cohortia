Process Flow › Instantiate Contract
Step-by-step
  1. Obtain ABI from your compiled artifact.
  2. Get deployed contract address from deployment logs or Ganache.
  3. Create a Web3 provider, then new web3.eth.Contract(abi, address).
  4. Call view functions with .call() or query events with getPastEvents.
Quick note
ABI must match the deployed bytecode. An ABI mismatch leads to function-not-found errors.
Code snippet
const Web3 = require('web3');
const web3 = new Web3('http://127.0.0.1:7545');

const simpleStorageABI = [ /* ABI JSON */ ];
const simpleStorageAddress = '0x...';

const simpleStorage = new web3.eth.Contract(simpleStorageABI, simpleStorageAddress);
const value = await simpleStorage.methods.getData().call();
console.log('Value:', value);
