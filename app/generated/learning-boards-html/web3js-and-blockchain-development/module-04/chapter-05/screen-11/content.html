Process Flow › Event Performance
Practical strategies
  • Narrow your fromBlock and toBlock range.
  • Use indexed event filters to reduce returned results.
  • Paginate large histories into smaller ranges.
  • Cache frequent queries in your backend where appropriate.
Example filter
const events = await myToken.getPastEvents('Transfer', {
  fromBlock: 100,
  toBlock: 200,
  filter: { from: '0xabc...' }
});
Key Takeaway
Be deliberate with blocks and filters. Performance depends on careful query design and provider limits.
