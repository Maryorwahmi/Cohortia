Module 4 › Chapter 4.5 › Learning Objectives
Verify Contract Instantiation
Task: Create a contract instance for SimpleStorage on Ganache and call owner(). Confirm the returned address matches the deployer.
Verify .call() Reads
Task: Run a script that calls getData().call(), then setData and call getData() again locally to see the changed value when reading the deployed state.
Verify Event Retrieval
Task: Emit DataChanged events via setData in a transaction, then use getPastEvents('DataChanged', {fromBlock: 0, toBlock: 'latest'}) to read logs.
Verify Token Queries
Task: Deploy an ERC-20 locally, then run readToken.js to fetch name, symbol, totalSupply, and a balanceOf result for a Ganache account.
