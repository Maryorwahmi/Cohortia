Definition › Public State Variables
Automatic getter behavior
Declare a variable public in Solidity and the compiler exposes a view function with the same name.
Example call
simpleStorage.methods.data().call() returns the stored integer as a string.
Type handling
Numeric outputs are strings; token values often require unit conversion with web3.utils.fromWei.
Analogy
Think of public variables as auto-generated read-only endpoints on the contract API. Your UI queries these endpoints without submitting a transaction.
Key Takeaway
Use the generated getters for simple reads and remember to convert units for display.
