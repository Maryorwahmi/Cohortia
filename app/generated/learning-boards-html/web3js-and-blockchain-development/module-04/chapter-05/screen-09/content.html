Comparison › .call() vs .send()
.call()
Executes locally on node. No gas. Use for view/pure functions and UI queries.
Example
const v = await contract.methods.getData().call();
.send()
Creates a transaction, costs gas, must be signed. Use for state-changing functions.
Example
await contract.methods.setData(42).send({ from: userAddress });
Key Takeaway

Decide by intent: reads use .call(); state changes require .send(). Mistaking one for the other leads to wasted gas or no state update.
