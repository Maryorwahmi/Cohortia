Process Flow › getPastEvents
How to query
Call getPastEvents with the event name and an options object. Read returnValues for emitted data.
const pastEvents = await simpleStorage.getPastEvents('DataChanged', {
  fromBlock: 0,
  toBlock: 'latest'
});

pastEvents.forEach((event) => {
  console.log(event.returnValues.changer, event.returnValues.oldValue, event.returnValues.newValue);
});
Best practices
  • Limit fromBlock/toBlock to avoid heavy queries on public nodes.
  • Use indexed parameters and the filter option to narrow results.
  • Paginate or run range queries if you need large histories.
Example event object
Each event includes returnValues, blockNumber, transactionHash, and event name for easy consumption.
