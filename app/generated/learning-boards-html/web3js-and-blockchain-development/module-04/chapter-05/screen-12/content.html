Architecture › React Integration
Recommended pattern
  • Instantiate contract once in a service module.
  • Expose read functions that return promises from .call().
  • Call reads in useEffect and manage loading and error states.
UX tips: show loading states, convert units, and avoid instantiating contracts on every render.
Component flow
  1. Mount component → call service to fetch metadata and balance.
  2. Show loading; display result when promise resolves.
  3. On account change, re-fetch the balance.
Key Takeaway

Design reads as predictable async services and manage UI state to keep user experience smooth.
