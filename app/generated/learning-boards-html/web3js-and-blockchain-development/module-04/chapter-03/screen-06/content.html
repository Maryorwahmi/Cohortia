Definition
Transaction
A signed message that changes state. Use getTransaction to read its fields and determine mining status.
Fields to inspect
  • from, to — who sent and who receives
  • value — amount transferred (in Wei)
  • gasPrice — execution cost per unit
  • blockNumber — null means pending or not found
Example workflow
Subscribe to pending transactions, show a pending badge in the UI when you detect the hash, then poll getTransaction until blockNumber is set and you can mark it confirmed. If getTransaction returns null repeatedly, treat it as not found and inform the user.
Common mistake
Interpreting null as failure. Null usually means unmined or unknown; verify by polling or waiting for a new block header to include the transaction.
