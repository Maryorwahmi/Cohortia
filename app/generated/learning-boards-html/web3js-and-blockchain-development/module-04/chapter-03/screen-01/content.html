Reading Blockchain Data
Query blocks and transactions, and set up subscriptions to stay in sync with chain activity.
In this lesson: Blocks & transactions
Coming up: Subscriptions & events

Why it matters
Efficient reads let UIs show accurate balances, analytics, and activity feeds while subscriptions enable live updates for reactive dApps.
Common pitfall
Using HTTP for subscriptions will fail; use a WebSocket provider for persistent subscriptions.
Visual concept
Blocks contain transactions
Each block includes metadata, a timestamp, and an array of transaction hashes or full transaction objects.
