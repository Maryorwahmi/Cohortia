Event anatomy
Topics: indexed parameters optimized for filtering. Data: non-indexed parameters stored in the log's data field and not efficient to filter on-chain.
Design guidance
Index the fields you expect front-ends to filter by, such as user addresses for transfer or change events. Avoid indexing large dynamic types.
Example
ValueChanged(address indexed user, uint oldValue, uint newValue)
Subscribe with the indexed user address to receive only events for that user.
Key Takeaway

Filter using indexed parameters for efficient server-side filtering. Plan indexes early when writing contracts.
