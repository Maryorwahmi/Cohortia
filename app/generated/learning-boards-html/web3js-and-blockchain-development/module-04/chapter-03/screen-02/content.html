Learning Objectives
Follow these steps to read and monitor Ethereum data with Web3.js.
Bloom: Learn → Understand → Apply → Master
01
Fetch blocks and metadata
Learn the getBlockNumber and getBlock calls and when to request full transactions. This saves bandwidth and time when building explorers.
VERIFIED COMPETENCY MILESTONE
02
Inspect transactions
Use getTransaction to read sender, recipient, value, gas price and block inclusion. Understand null results for unmined transactions.
VERIFIED COMPETENCY MILESTONE
03
Set up subscriptions
Subscribe to newBlockHeaders and pendingTransactions using a WebSocket provider for live updates in your dApp.
VERIFIED COMPETENCY MILESTONE
04
Subscribe to contract events
Bind to contract events with an ABI and address, and filter by indexed parameters to receive only relevant logs.
VERIFIED COMPETENCY MILESTONE
