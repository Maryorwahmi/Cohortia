Steps to subscribe
  1. Initialize Web3 with a WebSocket provider URL.
  2. Call web3.eth.subscribe with 'newBlockHeaders'.
  3. Attach handlers: on connected, on data, on error.
  4. Optionally fetch full block data after receiving the header.
Concrete example
Connect to ws://127.0.0.1:7545 in Ganache, subscribe to newBlockHeaders, and log block numbers as they arrive. This immediately powers live block counters and explorer updates.
Visual: subscription events
Connected → Data → Error
Handle network events, fetch block details when needed, and clear subscriptions on exit.
Pro tip

Keep subscriptions light: use headers as triggers and fetch heavy details only when required to keep your app responsive.
