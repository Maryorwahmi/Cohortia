Common mistakes
  • Using HTTP for subscriptions.
  • Always requesting full transactions for each block list item.
  • Interpreting null transaction results as permanent failure.
  • Using wrong ABI or address for event subscriptions.
Debug tips
Reproduce with Ganache, add connected/error logging, implement retries, and clear subscriptions at shutdown. Add reconnection backoff for production WebSocket endpoints.
Example error
Attempting web3.eth.subscribe with an HTTP provider typically throws a network or unsupported error. Switch to a WebSocket provider to fix this.
