Setup
Create a Web3 instance with WebsocketProvider, then create a contract object with the ABI and address. Use contract.events.EventName or contract.getPastEvents and contract.events to subscribe to live events.
Filtering with indexed params
Solidity allows marking event parameters as indexed to enable efficient filtering. Set the event filter options to listen only for matching indexed values, which reduces client-side processing and network traffic.
Example event
ValueChanged(address indexed user, uint oldValue, uint newValue)
Subscribe with filter { user: '0x...' } to receive only events for that user.
Key Takeaway
Correct ABI, address, and topic filters are required for reliable event subscriptions. Use indexed parameters to stay efficient.
