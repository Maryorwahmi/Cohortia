Code: Read latest block
<!-- Node script example --> const Web3 = require('web3'); const web3 = new Web3('http://127.0.0.1:7545'); async function readLatest() { const latest = await web3.eth.getBlockNumber(); const block = await web3.eth.getBlock(latest, false); // false = hashes only console.log('Block:', block.number); console.log('Hash:', block.hash); console.log('Timestamp:', new Date(block.timestamp * 1000).toLocaleString()); console.log('Miner:', block.miner); console.log('Tx count:', block.transactions.length); } readLatest();
Explanation
  • getBlockNumber returns the latest block index quickly for navigation or polling.
  • getBlock with fullTransactions=false is efficient for counts and metadata-only displays.
  • Convert the Unix timestamp to a local date string before presenting to users.
Concrete scenario
Your explorer shows the last 20 blocks. Fetch only hashes to populate the list quickly, then load transaction details when the user opens a block detail view.
Key Takeaway

Choose lightweight reads for lists and fetch full transaction objects only when the UI requires them.
