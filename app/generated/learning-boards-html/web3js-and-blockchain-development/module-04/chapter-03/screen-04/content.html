Definition
Block
A block is a batch of transactions plus a timestamp and a link to the previous block. It is the basis for confirmations and block-level analytics.
When to request full transactions
  • Request full objects when you need fields like from, to, value, or input data immediately.
  • Use hashes-only to get transaction counts or when you will lazily fetch details per item.
  • Balance the cost: full objects increase RPC payload size and parsing time.
Example
Use getBlockNumber to retrieve the latest index, then call getBlock(latestNumber, false) to get lightweight info and count transactions. Fetch full transactions on demand.
