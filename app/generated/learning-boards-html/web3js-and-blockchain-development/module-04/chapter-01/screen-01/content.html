Introduction to Web3.js
A practical orientation to connecting dApps to Ethereum nodes and why the provider matters.

Web3.js translates your JavaScript code into remote procedure calls that an Ethereum node understands. It helps you read blockchain state, request accounts, and submit transactions without composing raw RPC payloads.

Choosing between a local node, a hosted API, or an in-browser wallet provider changes where trust and security live. We’ll practice with Ganache and discuss hosted services and MetaMask.
