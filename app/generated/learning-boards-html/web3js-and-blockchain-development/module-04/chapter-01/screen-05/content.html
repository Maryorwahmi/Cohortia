Ethereum Node Overview
Responsibilities: validation, storage, and providing RPC endpoints.

Nodes synchronize blocks, validate transactions, and expose APIs for querying state. They do not sign transactions on behalf of users; signed transactions are submitted to the node to be propagated and mined.

Local vs Hosted
Local nodes like Ganache are ideal for fast development and deterministic testing. Hosted providers run full infrastructure so you don’t have to maintain it.
Why this matters
Your choice affects latency, trust, operational overhead, and how you handle secrets for signing transactions.

RPC endpoints

Common misconception

You do not need to run a full node to build dApps; many developers use hosted node providers during production and local nodes for development.
