Module 4 › Chapter 4.1 › Provider Types
Local — Ganache
Personal blockchain for development. Fast, resettable, deterministic accounts.
  • Typical URL: http://127.0.0.1:7545
  • Use for contract development and tests
Hosted — Infura / Alchemy
Managed node infrastructure for public testnets and mainnet. Highly available but third-party trust required.
  • Use HTTPS endpoints with a project ID
  • Good for production dApps that need scale
In-browser — MetaMask
Injected provider that enables user account access and signing within the browser environment.
  • Requires explicit user permission via eth_requestAccounts
  • Essential for end-user transaction signing
Decision checklist
Development speed → Ganache
Production scale → Hosted
User signing → In-browser
