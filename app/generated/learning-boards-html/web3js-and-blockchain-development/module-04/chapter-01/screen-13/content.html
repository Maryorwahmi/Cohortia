Module 4 › Chapter 4.1 › Async & Await
Incorrect pattern
const block = web3.eth.getBlockNumber();
console.log(block); // Promise {  }
This happens because the call returns a Promise. The value is not yet available synchronously.
Correct pattern
async function showBlock() {
  const block = await web3.eth.getBlockNumber();
  console.log(block); // 12345
}
Key takeaway

Await Promise-returning methods and use try...catch to gracefully handle failures.
