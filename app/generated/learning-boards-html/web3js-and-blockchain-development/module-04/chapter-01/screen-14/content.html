Module 4 › Chapter 4.1 › Key Concepts
Web3.js
A library that abstracts JSON-RPC for dApps.
Ethereum Node
Runs client software, validates transactions, and stores the chain.
Provider
The connection point Web3.js uses to contact a node.
Summary takeaway

Practice creating Web3 instances with local and hosted providers, confirm connectivity, and handle async calls correctly. These are the minimum skills needed for reliable dApp development.
