Step-by-step setup
Install, import, create instance, verify listening and network ID.
// First, install web3: npm install web3
const Web3 = require('web3');

const providerUrl = 'http://127.0.0.1:7545';
const web3 = new Web3(providerUrl);

async function verify() {
  try {
    const isListening = await web3.eth.net.isListening();
    console.log('Connected:', isListening);
    if (isListening) {
      const networkId = await web3.eth.net.getId();
      const blockNumber = await web3.eth.getBlockNumber();
      console.log('Network ID:', networkId, 'Block:', blockNumber);
    }
  } catch (err) {
    console.error('Connection error:', err.message);
  }
}

verify();
Explanation & tips
  • Use await because these methods return Promises; otherwise you’ll see pending results.
  • Wrap calls in try...catch to handle unreachable providers or timeouts gracefully.
  • Log the provider URL in error messages to help debugging.
Common mistake

Printing the Promise instead of awaiting it. Always await asynchronous web3 calls inside an async function.
