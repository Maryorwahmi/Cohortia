Transaction lifecycle for a contract write

Step-by-step actions needed to execute and confirm a write.

1
Instantiate contract
Use new web3.eth.Contract(abi, address) to create a contract instance you can call methods on.
2
Prepare txObject
  • • from, to, data (encodeABI), optional value, gasPrice, gasLimit, nonce
3
Estimate, sign, send
Call method.estimateGas, sign with private key or wallet, then sendSignedTransaction or let wallet handle signing and broadcasting.
Confirmations & receipts
When a receipt is returned, check receipt.status. If true, query the contract again to read updated state. If false, treat it as a revert: state unchanged, gas spent.
Example
Estimate gas for setData(42), add 10% buffer, sign and send, then verify receipt.status is true before reading getData.
Common mistake
Re-using a single gasLimit for different methods — always estimate per-method and per-parameter set.
Key Takeaway

Follow the lifecycle strictly: build, estimate, sign, send, check receipt, then refresh state.
