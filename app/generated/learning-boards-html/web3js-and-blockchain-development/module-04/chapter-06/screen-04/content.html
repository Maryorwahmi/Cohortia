What is a Write Operation?

A precise definition and a real example using SimpleStorage.setData.

Definition & mechanics
  • • Write operations require a signed transaction that is mined into a block.
  • • The transaction carries encoded function data created by encodeABI.
  • • Execution consumes gas; reverts still consume gas used until failure.
Concrete example
Calling SimpleStorage.setData(42), signing the tx, and reading getData after receipt.status confirms success.
Key Takeaway
Only update UI after a confirmed receipt; reverts do not change state but consume gas.
Common misconception

A revert does not restore gas or free the user from cost. The EVM undoes state changes, but the gas used to reach that point is paid. Treat a false receipt.status as a full failure and re-query state before assuming anything changed.
