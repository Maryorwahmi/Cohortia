Demonstrating a successful write and a revert

Step-by-step tasks to run on Ganache and observe both outcomes.

Steps
  1. Deploy modified SimpleStorage with require(_data < 1000) in setData.
  2. Update ABI and address in writeToContract script; set senderPrivateKey from Ganache.
  3. Run with newData = 42; confirm receipt.status true and getData shows 42.
  4. Run with newData = 1500; observe revert, receipt.status false or thrown error, and getData unchanged.
Tips & checks
  • • Verify private key is correct; placeholders halt the script.
  • • Use nonce = getTransactionCount(sender, 'pending') to prevent collisions.
  • • Capture gasUsed from receipt to show cost even on revert.
Key Takeaway

Reproducing both success and revert scenarios is the fastest way to learn how to respond correctly in your dApp and to craft helpful user messages.
