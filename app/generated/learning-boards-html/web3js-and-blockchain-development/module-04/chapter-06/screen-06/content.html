Signing and sending a transaction

Terminal-style script that signs locally and broadcasts a transaction to Ganache.

Core code excerpt
const Web3 = require('web3');
const web3 = new Web3('http://127.0.0.1:7545');

const simpleStorageABI = [ /* ... ABI ... */ ];
const simpleStorageAddress = '0x...';

async function writeToContract() {
  const simpleStorage = new web3.eth.Contract(simpleStorageABI, simpleStorageAddress);
  const accounts = await web3.eth.getAccounts();
  const senderAddress = accounts[0];
  const senderPrivateKey = '0x...';

  const initialData = await simpleStorage.methods.getData().call();
  const newData = 42;
  const nonce = await web3.eth.getTransactionCount(senderAddress, 'pending');
  const estimatedGas = await simpleStorage.methods.setData(newData).estimateGas({ from: senderAddress });
  const gasLimit = Math.round(estimatedGas * 1.1);
  const gasPrice = await web3.eth.getGasPrice();

  const txObject = {
    from: senderAddress,
    to: simpleStorageAddress,
    data: simpleStorage.methods.setData(newData).encodeABI(),
    gasPrice: gasPrice,
    gasLimit: gasLimit,
    nonce: nonce,
  };

  const signedTx = await web3.eth.accounts.signTransaction(txObject, senderPrivateKey);
  const receipt = await web3.eth.sendSignedTransaction(signedTx.rawTransaction);
  console.log('Status:', receipt.status);
}

writeToContract();
Explanation bullets
  • • Use getTransactionCount(sender, 'pending') to calculate nonce when multiple transactions may be pending.
  • • estimateGas on the method gives a tailored gas figure for that call and parameters.
  • • Always sign with the correct private key; placeholders will cause the script to abort.
Concrete example
Run with newData = 42 to succeed, then set newData = 1500 to trigger a require(_data < 1000) and observe a revert.
Pro tip

Log nonce and gas values during development to verify they match expectations before broadcasting.
