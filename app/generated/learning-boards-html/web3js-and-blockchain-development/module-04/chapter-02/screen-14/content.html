Module 4 › Chapter 4.2 › What to Remember
Do not expose private keys
Treat keys as secrets and avoid client-side storage or commits.
Use wallets for signing
Integrate MetaMask and use eth_requestAccounts for consented access.
Segregate test keys
Use Web3.js account tools only in local test environments and never in production.
Keep these rules visible when you design features that require signing. The architecture you choose today determines how safely users' assets are protected tomorrow.
