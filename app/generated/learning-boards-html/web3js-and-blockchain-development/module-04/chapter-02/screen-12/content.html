Module 4 › Chapter 4.2 › Common Mistakes
Mistakes and fixes
Missing 0x
Normalize keys to include 0x before importing.
Unhandled rejection
Catch error code 4001 and show a recovery path in the UI.
Confusing account sources
Document when to use node accounts vs wallet accounts in your app.
Leaked keys
Use pre-commit hooks and secrets scanning to prevent commits of keys.
Debugging tips
  • Compare generate and recover outputs to ensure deterministic behavior.
  • Inspect provider type to confirm you're calling wallet APIs or node APIs as intended.
Key Takeaway
Small checks and clear separation of environments avoid the biggest risks when working with keys.
