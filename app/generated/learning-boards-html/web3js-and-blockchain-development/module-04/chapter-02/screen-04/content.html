Module 4 › Chapter 4.2 › What is an Ethereum Account?
Account components
Private key

A secret number granting full control over the account. Keep it private; losing it loses access. Sharing it grants control to others.

Public address

Derived from the private key and safe to share. It is the identifier you publish to receive tokens.

Concrete example
// Example concept: new random private key produces new address // web3.eth.accounts.create() will return an object with address and privateKey { address: '0x0123...abcd', privateKey: '0xabc123...'} // Key point: change the private key and the address changes deterministically
Misconception check
  • Address is not a secret; it cannot prevent access — only the private key can.
  • Do not store private keys in client-side storage or version control.
Key Takeaway

Private key equals control. Treat it like cash in a locked safe: accessible only by the owner and never baked into public code.
