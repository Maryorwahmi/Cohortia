Starter code core
const connectWallet = async () => {
  if (window.ethereum) {
    try {
      await window.ethereum.request({ method: 'eth_requestAccounts' });
      const web3Instance = new Web3(window.ethereum);
      setWeb3(web3Instance);
      const accounts = await web3Instance.eth.getAccounts();
      if (accounts.length > 0) setAccount(accounts[0]);
    } catch (err) {
      if (err.code === 4001) setError('User rejected the connection request.');
      else setError('Error connecting: ' + err.message);
    }
  } else setError('MetaMask is not installed.');
};
Behavior expectations
  • Prompt the wallet; do not assume success.
  • Store only the connected address in state, not the private key.
  • On account change, refresh address and permissions.
Key Takeaway
This pattern delegates signing to the wallet and keeps private keys isolated from your app.
