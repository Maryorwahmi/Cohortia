Module 4 › Chapter 4.2 › Signing & Recovering
Sign and verify
const message = 'Hello Cohortia, this is a signed message.';
const signature = web3.eth.accounts.sign(message, newAccount.privateKey);
console.log('Signature:', signature.signature);

const recovered = web3.eth.accounts.recover(message, signature.signature);
console.log('Recovered Address:', recovered);
// Recovered should match newAccount.address
Practical note

Use signed messages for login challenges, signed approvals, or off-chain proofs of account control. Always sign fresh nonces to avoid replay attacks and never ask users to sign raw transactions for trivial UI actions.

Common mistake
Treating a signature as proof without checking the recovered address against the claimed identity. Always compare addresses and validate nonces.
