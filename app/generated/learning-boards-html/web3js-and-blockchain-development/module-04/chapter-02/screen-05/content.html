Module 4 › Chapter 4.2 › Create & Manage Local Accounts
Typical steps
  1. Generate a new account with web3.eth.accounts.create(). Record its privateKey only in secure local logs.
  2. To reuse a key, call web3.eth.accounts.privateKeyToAccount(privateKey) and then web3.eth.accounts.wallet.add(account).
  3. Fetch node accounts with web3.eth.getAccounts() to inspect Ganache-provided test accounts.
  4. Never add production private keys to client-side wallet instances; do imports only in Node.js test contexts.
Example Node snippet
const newAccount = web3.eth.accounts.create();
console.log(newAccount.address);
console.log(newAccount.privateKey);

const account = web3.eth.accounts.privateKeyToAccount('0xabcdef...');
web3.eth.accounts.wallet.add(account);
const nodeAccounts = await web3.eth.getAccounts();
console.log(nodeAccounts);
Common mistakes
  • Forgetting the 0x prefix on private keys when importing.
  • Using test keys in production or committing keys to version control.
  • Confusing node-managed accounts with injected wallet accounts for user interactions.
Key Takeaway

Local account creation is for testing. Keep test keys isolated and never expose real private keys in client code.
