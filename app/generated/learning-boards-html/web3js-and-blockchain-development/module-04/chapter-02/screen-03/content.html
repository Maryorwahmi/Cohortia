Module 4 › Chapter 4.2 › Bloom Objectives
Learn & Understand
  • Explain private-to-public derivation and uniqueness; test by generating two accounts.
  • Describe the role of private keys as exclusive control of assets.
Apply & Master
  • Create/import accounts with Web3.js for local testing and add them to web3.eth.accounts.wallet.
  • Integrate MetaMask using eth_requestAccounts and handle user denials with try...catch.
Practical Checks
Run the following small tests: generate two accounts to confirm different addresses; sign a message and recover the signer; import a Ganache key and inspect wallet contents; connect MetaMask and display the selected account.
Why this matters
These practices separate development testing from production security and reduce exposure to irreversible asset loss.
