Module 4 › Chapter 4.2 › Security Risks & Mitigations
Top risks
  • Exposing private keys in client code or version control.
  • Theft via cross-site scripting or malicious browser extensions.
  • Replay attacks if nonces or challenges are not used for message signing.
Mitigations
  • Delegate signing to browser wallets or hardware wallets for user keys.
  • Use HSMs or secure vaults for server-side automated keys.
  • Use ephemeral test keys locally and segregate environments.
Developer checklist
Audit where keys live, add runtime checks to prevent accidental commits, and educate users about signature prompts.
