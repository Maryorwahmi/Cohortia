Module 4 › Chapter 4.2 › Node vs Wallet Accounts
Node-managed accounts (Ganache)
  • Returned by web3.eth.getAccounts() when connected to a node that exposes keys.
  • Useful for automated tests and pre-funded development scripts.
  • Signing can be performed by the node if it manages unlocked accounts.
Browser wallet accounts (MetaMask)
  • Exposed via window.ethereum.request({ method: 'eth_requestAccounts' }).
  • Require user consent; keys stay in the wallet and never leave the extension.
  • Recommended for production-facing dApps because of stronger user-controlled security.
Developer check
In a dev console run both web3.eth.getAccounts() and window.ethereum.request to compare outputs. If you expect user accounts, make sure you prompt eth_requestAccounts and handle the user rejecting the prompt with proper try...catch logic.
