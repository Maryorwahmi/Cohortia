What is Blockchain?

A shared ledger built from cryptographically linked blocks that many participants maintain together. This architecture creates verifiable, tamper-resistant records without a central authority.

Resilience
Multiple nodes keep copies so the system survives failures.
Verifiability
Cryptographic links let anyone check integrity.
Censorship Resistance
No single party can unilaterally change records.
In this lesson
We will examine blocks and hashes, decentralization vs centralized systems, consensus basics, and the immutable chain activity that exposes tampering.

Concept Map
Blocks → Hash → Chain → Network
Block
Batch of validated transactions plus metadata and previous-hash pointer.
Hash
A cryptographic fingerprint; any change breaks the link.
Ledger
Many nodes hold copies and verify updates by consensus.
Immutability
Tampering invalidates later blocks and is detected by the network.
