Module 1 › Chapter 1.3 › Key Concepts — Part 1
Web1
Read-only era of static content and server-hosted pages.
Web2
Read-write web dominated by centralized platforms that own data and identity.
Web3
Read-write-own web emphasizing user ownership, decentralization, and interoperability.
Takeaway
Use these concise definitions as a checklist when deciding where to place state, how to represent identity, and when to use on-chain guarantees.
