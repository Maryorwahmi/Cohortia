Process Flow

Compile → Deploy → Interact

A step-by-step progression from human-readable code to on-chain execution; each step affects cost and behavior.

1
Write & Test
Author contracts in Solidity and run unit tests locally to catch logic errors before deployment.
2
Compile
Compiler turns code into EVM bytecode and ABI; both are needed for deployment and interaction.
3
Deploy
A deployment transaction writes bytecode to-chain and assigns an address; this is gas-costly and immutable.
4
Interact
Send transactions for state changes or call view functions for reads; transactions consume gas and require signing by an EOA.
Concrete example
Deploy a token contract to a testnet then call transfer; the deploy and transfer both consume gas but the read balance call does not if executed off-chain.
Common mistake
Underestimating gas for deployment or testing only on mainnet without testnet runs leads to high cost and errors.
Key takeaway

Use testnets to validate logic and estimate gas before mainnet deployment to avoid permanent mistakes.
