Definition

Ethereum Virtual Machine (EVM)

A sandboxed runtime ensuring deterministic execution of smart contract bytecode on every node.

Role
Execute bytecode, update state, and enforce gas accounting consistently.
Input
Contract bytecode and transaction data.
Output
Deterministic state changes and logs visible on-chain.
Analogy

Sandboxed CPU for blockchain programs

Like a CPU that runs a program and changes memory, the EVM runs bytecode and updates the blockchain state. Because every node runs the same program, consensus is preserved.

Concrete example
A token transfer function reduces the sender balance and increases the receiver balance; the EVM enforces both changes identically on all nodes.
Common misconception
The EVM is not a fast distributed computer; it's a deterministic runtime where every instruction costs gas and must be chosen carefully.
Key takeaway

Design efficient, deterministic contract logic because the EVM executes every step and charges gas for it.
