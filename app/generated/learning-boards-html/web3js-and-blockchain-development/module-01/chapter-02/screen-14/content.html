Module 1 › Chapter 1.2 › Key Concepts
Cryptography
The study of techniques for secure communication and verification used in blockchains.
Hash Function
An algorithm mapping arbitrary data to a fixed-size digest for integrity checks.
SHA-256
A widely used cryptographic hash function producing a 256-bit digest used in many blockchains.
Summary
Keep these terms handy: hashing secures integrity, signatures prove authorization, and private keys must be protected.
