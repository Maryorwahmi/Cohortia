Core Concept
What is cryptographic hashing?
A fixed-size fingerprint for arbitrary data
Definition & properties
  • Deterministic: same input → same hash every time.
  • One-way: cannot reconstruct input from the hash.
  • Collision resistance: finding two inputs with same hash is infeasible.
  • Avalanche effect: tiny input changes produce radically different hashes.
Example
Hashing the string "Hello" with SHA-256 yields a specific 64-character hex digest. Change a letter and the digest changes entirely.
Key Takeaway
Hashes let you verify integrity quickly without revealing the original data.
Analogy
A hash is like a fingerprint for data: it uniquely identifies content but cannot be reversed into the original content.
Quick example (visual)
Input:  "Hello Cohortia"
SHA-256: a3b1c9... (64 hex characters)

Change: "Hello cohortia"
SHA-256: 5f0d2b... (completely different)
Common mistake
Do not confuse hashing with encryption. Hashing is one-way and used for integrity; encryption is reversible with keys and used for confidentiality.
