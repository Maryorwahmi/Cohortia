Hashing vs Encryption
Clarify the difference and when to use each
Hashing (one-way)
  • Purpose: integrity, fingerprinting.
  • Reversibility: one-way; original cannot be recovered.
  • Use in blockchain: block digests and transaction checks.
Example: Calculating SHA-256 on a block and storing it as a reference for later verification.
Encryption (two-way)
  • Purpose: confidentiality, access control.
  • Reversibility: reversible with the correct decryption key.
  • Use in blockchain: encrypting off-chain data or backups.
Example: Encrypting a wallet backup file with a passphrase so only the holder can decrypt it.
Misconception
Hashing hides data. It does not; it only provides a fingerprint and can be used to verify guesses.
When to use
If you need to detect tampering, use hashing. If you need to keep data secret, use encryption.
Key Takeaway
Hashing verifies content; encryption protects content.
