Objective → Check
Hashing & Integrity
Check: Recompute a transaction or block hash and compare to stored previous-hash values.
SHA-256 Properties
Check: Change one character and recompute the hash to observe the avalanche effect.
Keys
Check: Generate a key pair and verify the public key is derived from the private key.
Signatures
Check: Sign a message and verify the signature with the public key to confirm authenticity.
Helpful reminders
Mnemonic: Fingerprint = hash, Lock = private key
Practice: Keep a test wallet for signature experiments, never use a real private key.
Warning: If a private key is leaked, signatures can be forged and funds stolen.
