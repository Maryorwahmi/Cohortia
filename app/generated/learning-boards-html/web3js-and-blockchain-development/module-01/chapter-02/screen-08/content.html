Definition
Asymmetric cryptography: public and private keys
A key pair for secure identity and verification
Private Key
Secret; used to sign transactions and prove ownership.
Keep it offline and backed up. If lost or leaked, control of assets is lost. Wallets often manage this key for you so you don't handle raw material in production.
Public Key
Derived from the private key; used to verify signatures and derive addresses.
Share freely. Verification does not reveal the private key. Public keys let anyone check that a signature matches a particular owner.
Example
Signing a token transfer with your private key and having network nodes verify the signature with your public key.
Misconception
Public key reveals private key. It does not; it only provides a verifier function for signatures.
Key Takeaway
Private key signs; public key verifies. Protect the private key like a physical key to your funds.
