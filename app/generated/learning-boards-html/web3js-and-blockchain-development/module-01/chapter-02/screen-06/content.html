Hands-on Activity
Observe the avalanche effect
Run a short SHA-256 experiment in Python
Script example
import hashlib

def calculate_sha256(text):
  return hashlib.sha256(text.encode('utf-8')).hexdigest()

original_text = "Hello Cohortia learners! This is a test message."
print("Original Text:", original_text)
print("Original Hash:", calculate_sha256(original_text))

modified_text = "Hello Cohortia learners! This is a test message"
print("Modified Text:", modified_text)
print("Modified Hash:", calculate_sha256(modified_text))
When you execute this, compare the two printed digests. They will look entirely different even though the inputs differ by one character.
Expected observation
A single character change produces a digest that bears no visible relation to the original. This is the avalanche effect in action.
Common misconception
Do not expect a few bits to change; the output changes across the entire digest unpredictably.
Try this
Change case, punctuation, or whitespace and rerun. Each edit yields a wholly different hash; that difference is what blockchains detect.
