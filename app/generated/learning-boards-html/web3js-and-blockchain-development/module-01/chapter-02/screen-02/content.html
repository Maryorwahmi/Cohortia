How to use these objectives
Each milestone is evidence: compute a hash, explain a property, map keys to actions, and verify a signature. These are practical skills you'll use when working with wallets and when signing transactions through Web3.js.
Mnemonic: Fingerprint + Lock
Try: Recompute a block hash after a small edit to see the mismatch.
Safety: Never share a private key; treat it like a physical key to your funds.
