Module 2 › Chapter 2.1 › Key Concepts
Ethereum Virtual Machine (EVM)
A deterministic, sandboxed runtime that executes smart contract bytecode and produces state transitions.
Account-Based Model
State is a mapping of addresses to account objects with nonce, balance, storageRoot, and codeHash.
State Root (Merkle Root)
A cryptographic commitment to the entire world state after a block's transactions are applied.
Summary takeaway
EVM executes, account model stores, and stateRoot commits — together they let Ethereum function as a predictable, verifiable global computer.
