Module 2 › Chapter 2.1 › Ethereum Virtual Machine
What is the EVM?
A deterministic runtime that executes compiled smart contract bytecode on every node. It simulates a virtual CPU and applies state changes that become part of the world state.
Properties
  • Deterministic execution
  • Sandboxed environment
  • Executes contract bytecode (Solidity/Vyper)
Implication
Correctness matters: the EVM enforces that code behaves the same everywhere, so bugs cause identical effects across the network.
Analogy
Think of the EVM as a virtual CPU each node runs to process the same program instructions and arrive at the same result.
Example
A token transfer call executes code that adjusts storage values and emits events; the EVM runs that code and the resulting storage changes become part of the new world state.
Misconception
The EVM is not one physical CPU — it's the same virtual machine simulated by every node, which is why identical inputs produce identical state transitions.
Key Takeaway

Design contracts mindful of deterministic execution and sandboxing so behavior is predictable and secure across nodes.
