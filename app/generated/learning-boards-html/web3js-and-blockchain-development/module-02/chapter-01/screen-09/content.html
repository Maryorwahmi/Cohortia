Module 2 › Chapter 2.1 › Account Types
Externally Owned Account (EOA)
Controlled by a private key, can sign and send transactions, has nonce and balance but no code or storage.
Example
A MetaMask wallet creates a signed transaction from your EOA to call a contract function or send Ether.
Contract Account
Controlled by code deployed at the address, can hold balance and storage, but only executes when called.
Pitfall
Sending Ether directly to a contract without a payable fallback may lock funds. Always confirm the contract accepts direct transfers.
Check your understanding
Who creates and signs transactions? Who executes code in response?
Pro tip
Inspect contract ABI and fallback functions before sending native Ether transfers.
Key Takeaway
EOAs initiate; contracts respond. This separation defines how on-chain interactions flow.
