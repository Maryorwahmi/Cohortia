Module 2 › Chapter 2.3 › maxFee & maxPriorityFee
Three-step calculation
  1. Network sets baseFee for the block.
  2. actualPriorityFee = min(maxPriorityFeePerGas, maxFeePerGas - baseFee).
  3. Actual per-unit cost = baseFee + actualPriorityFee; refund any unused portion of maxFeePerGas.
Concrete example
Numbers in Gwei

If baseFee=50, maxPriorityFee=3, maxFee=60, actual per-unit = 50 + 3 = 53 Gwei; remainder refunded.

Practical advice
  • Pick maxFeePerGas slightly above expected baseFee to allow headroom for fluctuations.
  • Choose maxPriorityFeePerGas to reflect how urgently you need inclusion.
  • Rely on oracles or real-time estimates to set defaults in a wallet UI.
Misconception check: A large maxFeePerGas does not mean validators get more—they only receive the tip; the base fee is burned.
