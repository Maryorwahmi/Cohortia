Module 2 › Chapter 2.3 › Common Pitfalls
Pitfall: Out-of-gas

If gasLimit is too low, the transaction reverts and consumed gas is not refunded. Use estimateGas and add a margin for complexity.

Pitfall: Unit conversion

Always convert between Wei, Gwei, and Ether explicitly. Use web3.utils.toWei and fromWei to avoid large mismatches.

Pitfall: Overpaying tips

Setting overly-large maxPriorityFee or maxFee can cause large temporary reservations; explain refunds in UI and set sensible defaults.

Quick checks
  • Read gasUsed in the receipt.
  • Compare baseFeePerGas across blocks.
  • Use estimateGas and show ranges in the UI.
