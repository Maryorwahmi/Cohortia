Module 2 › Chapter 2.3 › gasLimit, gasPrice, transactionFee
Terminology
  • gasLimit: Maximum gas units a sender permits for the transaction.
  • gasPrice: Wei-per-gas offered (pre-EIP-1559 model).
  • transactionFee: gasUsed multiplied by the per-unit price.
Concrete example
Simple transfer

If gasUsed = 21,000 and gasPrice = 20 Gwei, the total fee is 21,000 times 20 Gwei, converted to Ether.

Visual process
1. Set gasLimit
Choose a cap based on function complexity and an estimate buffer.
2. Price the gas
Pre-EIP-1559 use gasPrice; after EIP-1559 use maxFee and priority fee.
3. Pay for gasUsed
You are charged for the gas actually consumed, up to the gasLimit.
Misconception check: Unused gas within gasLimit is not charged; only gasUsed is paid. However, if the transaction runs out of gas, the transaction reverts but the gas consumed before revert is still lost.
