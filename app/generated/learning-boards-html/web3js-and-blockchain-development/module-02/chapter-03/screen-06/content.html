Module 2 › Chapter 2.3 › Ether Units
Unit table
  • Wei: smallest unit, 1 Ether = 10^18 Wei.
  • Gwei: 1 Gwei = 10^9 Wei, common for gas prices.
  • Ether: user-facing currency, convert for display.
Example calculation
Convert and compute

Multiply gasUsed by priceInWei, then convert the resulting Wei to Ether for display with web3.utils.fromWei.

Quick code pattern
// Example pattern (pseudocode)
const gasUsed = 21000n;
const priceGwei = '20';
const priceWei = web3.utils.toWei(priceGwei, 'gwei');
const totalWei = gasUsed * BigInt(priceWei);
const totalEth = web3.utils.fromWei(totalWei.toString(), 'ether');
// display totalEth to user
Misconception: Treating Gwei or Ether as interchangeable without explicit conversion will break cost displays. Always use toWei/fromWei for arithmetic and UI formatting.
