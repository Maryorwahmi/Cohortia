Module 2 › Chapter 2.4 › Data Types
Primitives
uint / int — integers for counters and numeric values.
address — 20-byte account identifier used for ownership and transfers.
bool — true/false flags for simple conditions.
string / bytes — text and raw data; use sparingly for gas reasons.
Composite Types
mapping — key-value store for fast lookups (not iterable).
struct — group related fields into a single type.
enum — define a limited set of state values for clarity.
Design notes
Large or complex data increases gas cost for storage and updates.
Mappings are not iterable — plan additional indexing via events if you need enumeration.
Choose types that map naturally to how off‑chain code reads and displays contract state.
