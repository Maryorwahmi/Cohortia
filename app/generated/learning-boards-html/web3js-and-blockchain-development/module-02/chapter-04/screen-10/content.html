Module 2 › Chapter 2.4 › Visibility & Mutability
Visibility
public — accessible from anywhere, including external callers.
private — accessible only inside the contract that defines it.
internal — accessible inside the contract and derived contracts.
external — callable from external transactions and other contracts; optimized for calldata.
Mutability
view — reads state only; no state modification.
pure — does not read or modify state; deterministic computation only.
payable — allows the function to receive Ether; missing payable causes reversion if Ether is sent.
Common mistake
Marking a function public does not provide access control. Use explicit checks and modifiers to prevent unauthorized state changes.
