Module 2 › Chapter 2.4 › Events & Logs
What events do
Emit logs to record occurrences for off‑chain systems.
Allow listeners to react without constantly querying contract state.
Contain optional indexed fields for efficient filtering by clients.
Design notes
Do not rely on events as the canonical on‑chain state for security decisions.
Use events for user interfaces, notifications, and audit trails that complement on‑chain storage.
Include relevant indexed fields to help listeners find events quickly.
