Module 2 › Chapter 2.4 › What is a Smart Contract?
Definition
Smart Contract
A program stored on the blockchain that executes rules automatically and deterministically.
Immutability
Code cannot be changed after deployment; choose and test carefully before publishing.
Deterministic Execution
Given the same inputs, the contract yields the same outputs on every node.
Transparency
Transactions and state changes are publicly verifiable and auditable.
Analogy & Example
Analogy: A vending machine is a simple way to think about a smart contract. You provide the correct input, the machine executes a fixed set of rules, and you receive the result without intermediaries.
Common misconception
People sometimes think immutability prevents all changes. In fact, immutability applies to the program code; the contract’s state can still change through transactions that call its functions if the contract allows it.
Key Takeaway

Smart contracts replace intermediaries with code, so correctness and testing are essential before deployment.
