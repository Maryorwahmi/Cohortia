Module 2 › Chapter 2.4 › Compilation & Deployment
Step-by-step
1. Author (pragma & contract)
Write Solidity with a pragma version to ensure compiler compatibility.
2. Compile (ABI + Bytecode)
Compiler emits ABI and bytecode. ABI is for callers; bytecode is the executable on the EVM.
3. Deploy (contract account)
Publishing bytecode creates a contract account with a unique address that holds the immutable code.
Concrete example
In Remix, compile a contract and open Compilation Details. Copy the ABI JSON to use in Web3.js. Copy bytecode if you need to deploy programmatically. If you later find a bug in the bytecode at that address, you must deploy a new contract with corrected code.
Key Takeaway

ABI describes the interface; bytecode is the executable. Deployment makes code permanent.
