Step-by-step
  1. Create MyFirstContract.sol and paste the example code provided in the chapter.
  2. Select a compiler version that matches the pragma and compile until green.
  3. Open Compilation Details and copy the ABI and bytecode artifacts.
  4. Deploy to a test network or the JS VM, call view functions and send state-changing transactions, and observe events in the logs.
Reflection prompts
  • How does the ABI represent function arguments and return types?
  • What would you change in the contract to make future migrations easier if a bug appears?
  • Which functions should be restricted by access control and why?
Key Takeaway

Treat compilation and deployment as guarded steps: verify compiler versions, inspect ABI/bytecode, and test on a network before publishing immutable code.
