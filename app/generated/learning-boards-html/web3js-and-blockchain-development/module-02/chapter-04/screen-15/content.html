Module 2 › Chapter 2.4 › Key Concepts
Smart Contract
A self-executing program stored and run on a blockchain.
Immutability
Deployed code cannot be changed; fixes require new deployments and migration.
Deterministic Execution
Same inputs produce the same outputs across all nodes, enabling trustless behavior.
Summary takeaway
Design smart contracts with immutability in mind: test thoroughly, document ABI and bytecode artifacts for integrations, and plan migration strategies before deployment.
