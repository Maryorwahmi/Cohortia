Troubleshooting
Why transactions fail and how to debug
Checklist for failures
  • Confirm the from address is correct and unlocked in your provider.
  • Increase gas limit if you hit out-of-gas errors.
  • Verify ABI and deployed bytecode come from the same compilation.
  • Check receipt.status; zero means revert.
Using Ganache and receipts
Ganache shows transactions with gas used and revert traces. Use the transaction receipt in your script to examine gasUsed, blockNumber, and logs for emitted events.
Example fix
If a .send() fails due to gas, increase the gas value in the send call, re-run on Ganache, and confirm the receipt shows status true and updated state.
Developer habit
Log values before sending, then inspect the receipt and Ganache UI to match console outputs with chain events.
Misconception
Assuming a thrown error always means the contract code is wrong; often it's a configuration or gas issue in the client code.
Key Takeaway

Diagnose by checking receipts, Ganache traces, ABI versions, and from/gas settings; fix the client configuration first.
