Learning Objectives — Practical Interactions
These objectives map to the hands-on activity you'll run against Ganache using Node.js and web3.js.
05
Use .call() for read-only data
Execute view functions locally without gas. Useful for getters like getGreeting or public state variables.
Mnemonic: call = read-only
VERIFIED COMPETENCY MILESTONE
06
Use .send() for state changes
Submit transactions that cost gas, must be signed, and include a from address and sufficient gas limit.
Mnemonic: send = write and pay gas
VERIFIED COMPETENCY MILESTONE
07
Listen for events
React to emitted events like GreetingUpdated to surface on-chain changes in your app or logs in the console.
Mnemonic: events = emitted logs
VERIFIED COMPETENCY MILESTONE
08
Verify in Ganache
Use Ganache's transactions and accounts to confirm deployment addresses, gas used, and receipts for send operations.
Mnemonic: local chain = safe testbed
VERIFIED COMPETENCY MILESTONE
