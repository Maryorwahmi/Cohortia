Process Flow
Contract Deployment — step by step
  1. Compile: produce ABI and bytecode with Remix or solc.
  2. Prepare deploy tx: set data to bytecode, include constructor args if needed.
  3. Sign & send: send from an EOA; for local testing use a Ganache account.
  4. EVM execution: runs initialization and stores code at new address.
  5. Receipt: inspect the receipt for contractAddress and gasUsed.
Scenario
When you deploy MyFirstContract locally, Ganache will show a deploy transaction. Use the receipt to instantiate the contract object for subsequent calls and sends.
Checks and tips
  • Always include 0x prefix on bytecode strings in scripts.
  • Provide a gas or gasLimit estimate; underestimates cause failures.
  • Verify constructor args are encoded when present.
  • Confirm the returned contract address and update your front-end configuration.
Key Takeaway

Deployment is a transaction with bytecode that produces a new contract address and a receipt you must inspect.
