Definition
Contract Bytecode
Low-level instructions generated by the compiler that the EVM executes and stores on-chain.
  • Deployment sends bytecode in a transaction's data field to create a new contract account.
  • The EVM stores and later executes this(bytecode) immutably at the contract address.
  • Bytecode differs across compilations and includes constructor logic executed during deployment.
Practical note
When using deploy scripts, provide the bytecode as a 0x-prefixed hex string and set an adequate gas limit for deployment.
Deployment mechanics
A deploy transaction has an empty to field. The network executes the bytecode, runs the constructor, and assigns an address where the bytecode lives.
Example
In a Node.js deploy script you pass the bytecode to MyContract.deploy({data: myContractBytecode}) and send the transaction from a local Ganache account.
Common mistake
Forgetting to include 0x before the hex bytecode or underestimating gas for deployment causes immediate failure.
Key Takeaway

Bytecode is immutable machine code stored at the contract address and is what the EVM runs.
