Definition
Instantiate web3.eth.Contract
Create a JS contract object using the ABI and address to call, send, and listen.
Example instantiation:
// Example from the chapter
const myContractABI = [ /* ABI array copied from compilation */ ];
const contractAddress = '0xYourDeployedContractAddressHere';
const myContract = new web3.eth.Contract(myContractABI, contractAddress);
Tip
Keep ABI bundled with your frontend and configure addresses per environment to avoid mismatches between local and remote deployments.
What the contract object exposes
  • .methods — call or send contract functions.
  • .events — subscribe to or query emitted events.
  • .options — contains the address you instantiated with.
Concrete scenario
After deployment, use the receipt's contractAddress to instantiate the object and immediately call a view to display initial state.
Key Takeaway

Instantiation creates a local API to an on-chain contract; it does not deploy or change code.
