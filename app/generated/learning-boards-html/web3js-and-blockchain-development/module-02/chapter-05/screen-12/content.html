Application Binary Interface (ABI)
A JSON array that defines functions, inputs, outputs, and events so external applications can encode and decode interactions.
Bytecode
Low-level machine instructions generated by the compiler and stored at the contract address for the EVM to execute.
Contract Deployment
Sending a transaction with bytecode and an empty to field creates a new contract account and runs constructor logic.
Summary
Keep ABI, bytecode, and deployment distinct: ABI for interface, bytecode for runtime code, and deployment for instantiating on-chain identity. Matching ABI to deployed bytecode is critical for correct interactions.
