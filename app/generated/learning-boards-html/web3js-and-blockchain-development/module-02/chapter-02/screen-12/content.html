Nonce: order and safety
A per-account increasing counter that prevents replay and maintains transaction sequence.
Role
Ensures transactions execute in sender-specified order and prevents reusing an old signed transaction to re-execute actions.
Example
If your account nonce is 0, your first transaction must use nonce 0. Sending two transactions with nonce 0 and 1 preserves sequence; sending both with nonce 0 causes conflict.
Misconception
Assuming nonces are globally unique. Nonces are per-sender and increment only for that account.
Practical tip
When replacing a stuck transaction, send a new transaction with the same nonce and higher gas price to replace the prior one.
Key Takeaway

Track nonces accurately in code and tooling to ensure correct ordering and avoid accidental transaction replacement.
