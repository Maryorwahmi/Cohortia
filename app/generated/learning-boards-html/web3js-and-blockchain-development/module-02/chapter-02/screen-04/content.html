What is an Ethereum account?
A deterministic identity defined by a private and public key; the address is used to receive value and interact with contracts.
  • • Private key: 256-bit secret; signing authority; never share.
  • • Public key: derived from the private key using secp256k1.
  • • Address: hashed public key, shown as 0x... and used in transactions.
Analogy
Private key is a mailbox key; address is the mailbox label others can use.
Common mistake
Assuming addresses are secret. They are public identifiers only.
Key Takeaway

Control of an account equals possession of the private key; protect the private key to protect funds.

Derivation flow
Private key (secret)
Random 256-bit number
Elliptic curve secp256k1 → public key
Public key hashed
Keccak-256 hash, truncated to produce the 42-character address
Example
A private key deterministically produces an address such as 0x followed by 40 hex characters used in transactions.
