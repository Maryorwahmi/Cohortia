Safe signing example
A local signing flow shows how the tx is constructed, signed, and serialized without broadcasting to mainnet.
Code template
const txParams = { nonce: '0x0', gasPrice: '0x4a817c800', gasLimit: '0x5208', to: '0xAb5801a7D398351b8bE11d439e05C5B3259aeC9B', value: '0x2386f26fc10000', data: '0x' } // Sign locally with a dummy private key and inspect serialized hex and v,r,s
Concrete result
You will obtain a raw signed transaction hex and a transaction hash, along with signature components v, r, s for inspection.
Misconception
Never use real private keys in sample scripts. Use clearly labeled test keys and keep them offline.
Hands-on steps
  1. Prepare tx fields and dummy private key.
  2. Create chain Common object and Transaction instance.
  3. Sign locally, serialize, and inspect v/r/s and raw hex.
Key Takeaway

Local signing lets you explore transaction internals safely. Only broadcast when using secured keys and intended networks.
