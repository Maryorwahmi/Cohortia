Transaction object fields
Each field carries intent, cost boundaries, or authorization data required to process a transaction on the network.
nonce
Sequential sender counter to prevent replay and enforce order.
gasPrice
Price per gas unit the sender pays; affects inclusion priority.
gasLimit
Max gas units the sender permits for this transaction.
to / value
Recipient address and amount of Wei to transfer.
data
Optional input for contract calls or contract creation bytecode.
v, r, s
Signature components proving authorization without revealing the private key.
Example
A transfer with nonce 0, gasPrice 20 Gwei, gasLimit 21000, to an address, and value of 0.01 Ether has predictable cost and ordering.
Misconception
Mixing up gasPrice and gasLimit can lead to paying more than intended or having transactions run out of gas.
Key Takeaway

Reading transaction fields before signing helps avoid accidental high fees and detects incorrect recipients or data payloads.
