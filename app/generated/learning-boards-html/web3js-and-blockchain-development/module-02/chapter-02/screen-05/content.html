Module 2 › Chapter 2.2 › Private Key Security
Private key properties
Random 256-bit secret used to sign transactions; never shared or stored online.
  • • Authority: private key proves ownership and creates signatures.
  • • Deterministic: same private key always yields same public key and address.
  • • Irreversible: you cannot derive the private key from the address.
Example risk
If a developer pushes a private key to a public repository, attackers can immediately drain funds by broadcasting signed transactions.
Common mistake
Using screenshots or cloud backups for seed phrases, which exposes them to malware and phishing.
Wallet types
Hardware wallet
Keeps private keys inside a device and signs without exposing the key material. Recommended for large balances.
Software wallet
Convenient for development and smaller amounts; keys are stored encrypted on device and should be protected.
Key Takeaway

Use hardware wallets for high-value keys and always back up seed phrases offline to recover keys safely.
