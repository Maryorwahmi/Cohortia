Module 2 › Chapter 2.2 › Objective Checkpoints
Inspect and simulate transactions
Practice constructing a transaction object, setting nonce and gas, signing locally, and reading v, r, s components in the result.
Example task
Create an unsigned transfer with nonce zero, set a 20 Gwei gas price, and sign it with a dummy private key in a safe environment.
Misconception check
A mined transaction is not always final. Multiple confirmations reduce reorg risk.
Seed phrase safety

Write seed phrases on paper, store in separate secure locations, never screenshot or save to cloud. If someone gets your phrase they control your accounts.
