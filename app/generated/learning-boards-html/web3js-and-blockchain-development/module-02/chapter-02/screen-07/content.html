Module 2 › Chapter 2.2 › Wallets
What a wallet does
Manages keys, prompts for confirmations, signs transactions, and helps derive accounts from a seed phrase.
Software wallet
Stores encrypted keys on device; convenient for development; protect the device.
Hardware wallet
Keeps keys inside hardware and only exposes signatures, reducing theft risk.
Example
When you approve a MetaMask send, MetaMask signs with the private key it controls and sends the signed transaction to a node. With a hardware wallet, the device signs and returns the signature without revealing the key.
Misconception
Believing that wallets store Ether. The blockchain stores balances; wallets store the keys that allow you to change those balances.
Key Takeaway

Choose wallet type based on risk: hardware for high value, software for convenience, always back up seed phrases offline.
