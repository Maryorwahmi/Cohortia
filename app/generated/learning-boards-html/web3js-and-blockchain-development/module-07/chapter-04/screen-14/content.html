Terminal demo setup
Use Ganache or a local test node. Deploy VulnerableBank, deploy Attack with the bank address, then call the attack function to send test Ether and start the exploit.
// Example Web3.js call to run attack
const value = web3.utils.toWei('1', 'ether');
await attack.methods.attack().send({ from: attackerAccount, value });
console.log('Bank balance:', await web3.eth.getBalance(vulnerableBank.address));
console.log('Attack balance:', await web3.eth.getBalance(attack.address));
Record balances before and after to confirm the exploit succeeded or failed.
Verification steps
  1. Deploy vulnerable bank and attacker, run the attack, and observe drain.
  2. Implement Checks-Effects-Interactions and nonReentrant, redeploy SecureBank.
  3. Re-run the same attack script and observe attack failure and funds preserved.
Pro tip
Run tests and automation that include the exploit script so regressions are caught in CI.
