Module 7 › Chapter 7.4 › Key Concepts
Reentrancy
External calls before state updates allow repeated entry; fix with ordering and guards.
Front-running
Mempool observers can reorder transactions; use commit-reveal, batching, or time-locks to reduce risk.
Integer Overflow
Use Solidity 0.8+ or safe math libraries and test boundary cases to prevent wraparound errors.
Use these three checks as a first pass on any contract review: ordering of operations, order-dependence sensitivity, and arithmetic safety.
