Module 7 › Chapter 7.4 › Dependencies & Phishing
Dependency Hygiene
Run automated audits, limit direct dependencies, and apply timely updates for known CVEs.
Tools
Use package auditors and continuous scans to detect vulnerable versions in your dependency tree.
Phishing defenses
Use HTTPS, clearly display network and domain information, and educate users not to share seed phrases.
Combine technical supply-chain checks with ongoing user outreach and clear UI to reduce both code and social attack vectors.
