Module 7 › Chapter 7.4 › Client-side Security
Cross-Site Scripting (XSS)
Sanitize or avoid rendering raw HTML. Treat any user content as untrusted.
Concrete example
An attacker injects a script that modifies displayed transaction amounts or triggers a malicious signing request in the UI.
Protecting Private Keys
Never prompt for or store private keys. Use wallet providers to sign transactions so keys remain client-controlled.
Misconception
Encrypting then storing keys in local storage is not a substitute for using a wallet provider because XSS can expose the decrypted key.
User education is essential: tell users never to paste seed phrases into a site and to verify transaction details inside their wallet app.
