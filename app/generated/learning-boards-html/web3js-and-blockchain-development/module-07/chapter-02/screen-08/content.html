Module 7 › Chapter 7.2 › Signing Multiple TXs
Starter snippet
// Example pattern from the chapter
const currentNonce = await web3.eth.getTransactionCount(account, 'pending');

// First transaction
const tx1 = contract.methods.myFunction1().encodeABI();
const signedTx1 = await web3.eth.accounts.signTransaction({
  from: account,
  to: contractAddress,
  data: tx1,
  gas: estimatedGas1,
  gasPrice: currentGasPrice,
  nonce: currentNonce
}, privateKey);
web3.eth.sendSignedTransaction(signedTx1.rawTransaction);

// Second transaction: increment nonce
const tx2 = contract.methods.myFunction2().encodeABI();
const signedTx2 = await web3.eth.accounts.signTransaction({
  from: account,
  to: contractAddress,
  data: tx2,
  gas: estimatedGas2,
  gasPrice: currentGasPrice,
  nonce: currentNonce + 1
}, privateKey);
web3.eth.sendSignedTransaction(signedTx2.rawTransaction);
Checklist
  • Fetch pending nonce once before a batch.
  • Sign each tx with explicit nonce and gas parameters.
  • Monitor pending status and allow replacements if stuck.
Key Takeaway

Explicit nonces and signed transactions give deterministic ordering and clear recovery paths for pending transactions.
