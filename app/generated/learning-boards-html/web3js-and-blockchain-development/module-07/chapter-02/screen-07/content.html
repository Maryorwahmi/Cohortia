Module 7 › Chapter 7.2 › Nonce Management
Definition
Nonce = transaction sequence number
  • Use web3.eth.getTransactionCount(address, 'pending') to include unmined transactions.
  • When sending multiple txs, sign each with an explicitly incremented nonce to avoid race conditions.
  • If a lower-nonce tx is pending, higher-nonce txs will remain pending until the lower one clears or is replaced.
Practical pattern
Fetch the pending nonce, then explicitly set nonce: currentNonce, currentNonce + 1, and so on for each signed transaction you send in a batch.
Visual
Think of nonces as numbered tickets at a queue. If ticket 5 is stuck, tickets 6 and 7 wait in line until 5 is processed or replaced.
