Module 7 › Chapter 7.2 › Pitfalls & Fixes
Mistake
Hardcoding gas limits

Fix: use estimateGas and add a modest buffer instead of static constants.

Mistake
Ignoring nonces

Fix: fetch pending nonce and explicitly set nonces for batches to prevent blocking.

Mistake
Poor user feedback

Fix: show pending/confirm/fail states and provide a speed-up or cancel option when pending for long.

Mistake
Leaving heavy logic on-chain

Fix: perform computation off-chain and batch when possible to reduce repeated on-chain costs.
