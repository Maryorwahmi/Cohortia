Module 7 › Chapter 7.2 › Estimate Gas
Step-by-step
  1. Call estimateGas with the same call payload and the sender address.
  2. Add a 10–20% buffer to the returned estimate to protect against slight variations.
  3. Fetch current gasPrice and present estimated fee to the user before sending.
  4. Re-estimate just before submission if there is delay in UI interaction.
Quick example
const gas = await contract.methods.increment().estimateGas({ from: account }); const gasLimit = Math.floor(gas * 1.2); // 20% buffer
Common pitfall
Blindly hardcoding gas limits can break when contract logic changes. Rely on estimateGas and a small buffer instead of arbitrary constants.
Example scenario
If estimateGas returns 45,000, setting gas to 54,000 provides room for small state-dependent differences without wasting much Ether.
