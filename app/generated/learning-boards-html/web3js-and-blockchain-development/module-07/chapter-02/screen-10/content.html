Module 7 › Chapter 7.2 › Contract Optimization
Top techniques
  • Minimize storage writes (SSTORE) and combine values into single slots when safe.
  • Use calldata for external function arguments that are read-only to avoid memory copies.
  • Replace strings with bytes when human readability is not required.
  • Avoid unnecessary loops; prefer indexed events and off-chain processing.
  • Use lazy initialization for rarely used state to save initial gas.
Example tip
If you store three small integers, pack them into one 32-byte slot rather than three separate slots to save on SSTORE costs.
Takeaway
Measure gasUsed before and after changes; optimizations should be data-driven, not guessed.
