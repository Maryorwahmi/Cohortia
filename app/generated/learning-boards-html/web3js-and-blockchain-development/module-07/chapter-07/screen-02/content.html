Mnemonic
Think of testing like a layered shield: unit tests are inner armor, integration tests connect the plates, and E2E tests are the outer inspection that ensures everything moves together.
Quick checklist
  • Assert events and return values in contract unit tests.
  • Run E2E with a local chain and automate wallet confirmations for critical flows.
  • Mock Web3 for UI unit tests to stay fast and deterministic.
  • Separate tests by layer and include edge cases in CI.
