Module 8 › Chapter 7.7 › E2E activity: Test a token mint flow
Activity checklist
  1. Initialize Hardhat and add MyToken.sol to contracts.
  2. Run npx hardhat node and deploy with the provided deploy.js script.
  3. Start your React dApp pointed at http://localhost:8545 and confirm contract address is configured.
  4. Write a Cypress test that connects MetaMask, clicks Mint, confirms the transaction, and asserts the UI balance updates to 100 MTK.
  5. Optionally verify contract balance via web3 call in the test to confirm on-chain state.
Remember to seed accounts and include a before hook in tests that deploys contracts so runs are repeatable in CI.
Starter deploy script
const { ethers } = require("hardhat");

async function main() {
  const [deployer] = await ethers.getSigners();
  const MyToken = await ethers.getContractFactory("MyToken");
  const myToken = await MyToken.deploy();
  await myToken.waitForDeployment();
  console.log("MyToken deployed to:", await myToken.getAddress());
}

main();
Common pitfall

Forgetting to update the dApp's token address after redeploying locally will make tests fail; always wire deployment address into your test setup.
