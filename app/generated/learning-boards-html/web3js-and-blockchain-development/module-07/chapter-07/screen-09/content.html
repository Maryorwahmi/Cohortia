Module 8 › Chapter 7.7 › Mocking Web3.js for fast frontend tests
Mock structure
  • Mock provider methods: getAccounts, getChainId, and helpers like toWei/fromWei if used.
  • Mock Contract: implement a methods object whose functions return objects with call or send that resolve test values.
  • Mock events: provide an events object that allows on('data', cb) to trigger callbacks with simulated payloads.
Test both normal and failure responses so UI handles errors gracefully, for example when call() rejects or send() fails.
Mock example
const mockWeb3 = {
  eth: {
    getAccounts: jest.fn(() => Promise.resolve(['0xMockAccount'])),
    getChainId: jest.fn(() => Promise.resolve(1337)),
    Contract: jest.fn(() => ({
      methods: {
        myViewFunction: jest.fn(() => ({ call: jest.fn(() => Promise.resolve('Mocked View Data')) })),
        myMutateFunction: jest.fn(() => ({ send: jest.fn(() => Promise.resolve({ transactionHash: '0xMockTxHash' })) })),
      },
      events: {
        MyEvent: jest.fn(() => ({ on: jest.fn((event, callback) => { if (event === 'data') { setTimeout(() => callback({ event: 'MyEvent', returnValues: { arg1: 'mockValue' }, transactionHash: '0xmockEventTx' }), 100); } return { unsubscribe: jest.fn() }; }) })),
    })),
  },
  utils: { fromWei: jest.fn((val) => val), toWei: jest.fn((val) => val) },
};

jest.mock('web3', () => jest.fn(() => mockWeb3));
Takeaway

Mocks speed tests and let you simulate on-event behavior; pair them with integration tests to be confident about real chain interactions.
