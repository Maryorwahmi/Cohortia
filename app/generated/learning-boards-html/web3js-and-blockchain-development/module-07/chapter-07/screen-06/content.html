Module 8 › Chapter 7.7 › Setting up E2E tests with a local blockchain
E2E Setup Steps
1. Start a local node: run Ganache or npx hardhat node to provide predictable RPC and funded accounts for testing.
2. Deploy contracts: run your deployment script against the local chain so contract addresses are stable during the test run.
3. Seed accounts: fund test wallets with ETH and any tokens needed for flows like deposit or mint.
4. Point your app: configure the dApp to use http://localhost:8545 so UI communicates with the test node.
5. Automate browser actions: use Cypress or Playwright plus wallet automation to confirm transactions and assert final UI state.
Misconception: local nodes are only for development. In fact, they are essential for reliable E2E testing because they give you deterministic, isolated test runs that can be reproduced in CI.
Concrete example

Start Hardhat node, deploy MyToken, visit the app at localhost, then script a mint transaction and verify the displayed balance updates to the minted amount.
