Module 8 › Chapter 7.7 › Mocks vs. Local Chain vs. Mainnet testing
Comparison table
Mocks
Speed: Very fast. Realism: Low. Isolation: High. Best for: Component unit tests and CI quick feedback.
Local Chain
Speed: Medium. Realism: High. Isolation: Medium. Best for: Integration and E2E tests in CI.
Mainnet/Testnet
Speed: Slow. Realism: Very high. Isolation: Low. Best for: Final staging and production verification.
Plan tests so fast feedback runs often and heavier integration tests run before merging critical changes.
Concrete workflow
  1. Run unit and mock-based UI tests on every commit.
  2. Run contract unit tests and short integration checks on PRs.
  3. Run full E2E against a local chain nightly or on protected branches.
