Module 8 › Chapter 7.7 › Automating wallet interactions during E2E tests
Automation approaches
Extension automation
Use plugins or browser automation to accept wallet permissions and confirm transactions, preserving the user experience during tests.
Programmatic signer
Use privateKey-based accounts for test-only RPC signing to avoid UI prompts and speed up scripts.
Important
Never use programmatic signing in production. Always isolate keys and guard test-only logic behind configuration that cannot run in live deployments.
Concrete example

Using a Cypress MetaMask plugin, a test clicks connect, the plugin accepts the extension permission, then confirms the mint transaction so the test can assert the balance updated.
