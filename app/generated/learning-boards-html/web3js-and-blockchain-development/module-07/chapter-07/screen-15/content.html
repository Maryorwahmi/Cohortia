Module 8 › Chapter 7.7 › Key Concepts — Quick Reference
Assert events
Events are the off-chain contract API—verify payloads, not just state.
Local-chain E2E
Use Ganache or Hardhat Network to script and verify full user flows reliably.
Mock Web3
Mock provider and contract calls for fast unit tests and deterministic CI feedback.
Final Thought

Start by adding an event assertion to a critical contract function and an E2E test that confirms the same behavior in the UI; the combination will quickly raise confidence in your release process.
