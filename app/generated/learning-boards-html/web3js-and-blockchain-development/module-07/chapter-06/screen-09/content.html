Contract configuration pattern

const CONTRACT_ADDRESSES = {
  1: '0x...MainnetContract...',
  137: '0x...PolygonContract...',
  42161: '0x...ArbitrumContract...'
};

function getContractAddress(chainId) {
  return CONTRACT_ADDRESSES[chainId];
}
Reinitialize after chain changes: const contract = new web3.eth.Contract(ABI, getContractAddress(chainId));
Practical guidance
  • Keep the ABI constant but the address dynamic per chain.
  • If a contract isn't deployed on a chain, show clear UI and disable that feature.
  • Store the contract map in a single module and import where needed to avoid duplication.
Key Takeaway

Contracts are chain‑specific. Load the correct address for the active chain and reinstantiate contract objects after every chain change.
