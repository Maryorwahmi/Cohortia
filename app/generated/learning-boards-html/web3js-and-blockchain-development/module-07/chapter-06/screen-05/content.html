Process

Establishing a WalletConnect session

  1. Configure provider with Infura ID and RPC map for supported chains.
  2. Call provider.enable() to trigger QR or deep link flow and complete handshake.
  3. Create a Web3 instance: const web3 = new Web3(provider).
  4. Read accounts and chainId, then subscribe to accountsChanged, chainChanged, disconnect.
Example code
import WalletConnectProvider from '@walletconnect/web3-provider';
import Web3 from 'web3';

const provider = new WalletConnectProvider({
  infuraId: 'YOUR_INFURA_PROJECT_ID',
  rpc: { 1: 'https://mainnet.infura.io/v3/YOUR_INFURA_PROJECT_ID', 137: 'https://polygon-rpc.com' }
});

await provider.enable();
const web3 = new Web3(provider);
const accounts = await web3.eth.getAccounts();
What to watch for
  • Make sure the Infura ID is configured; without it WalletConnect cannot reach nodes for some chains.
  • Always register event listeners to keep UI state in sync when accounts or chain change.
  • Clear session and reset state on disconnect; don’t rely on the provider to auto‑reconnect.
Key Takeaway

The enable() handshake creates an encrypted provider; treat it like any provider and listen for lifecycle events.
