Module 7 › Chapter 7.6 › Switch Networks
RPC Methods
Use wallet_switchEthereumChain to request switching. If error code 4902 appears, the wallet lacks the chain and you should call wallet_addEthereumChain with the network object and then retry.
Example flow
try {
  await provider.request({ method: 'wallet_switchEthereumChain', params: [{ chainId: '0x13881' }] });
} catch (switchError) {
  if (switchError.code === 4902) {
    await provider.request({ method: 'wallet_addEthereumChain', params: [{ /* network params */ }] });
    // retry switch
  }
}
UX and error handling
  • Inform users why the network change is necessary before prompting the wallet.
  • Handle user rejection of add or switch gracefully, with a clear recovery path.
  • After switching, reload contracts and refresh network‑dependent UI elements.
Common mistake

Treating chain switch as guaranteed; always handle 4902 and rejection flows and do not proceed until chainChanged confirms the new chain.
