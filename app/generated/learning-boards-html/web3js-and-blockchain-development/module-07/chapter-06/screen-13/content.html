Module 7 › Chapter 7.6 › Key Concepts
WalletConnect
Open protocol for encrypted sessions enabling remote signing via QR or deep link.
Multi‑chain dApp
An application designed to operate and interact with contracts across multiple chains.
@walletconnect/web3-provider
A library that exposes WalletConnect sessions as a Web3 provider for Web3.js integration.
Summary

Keep a single chainId-driven configuration and treat WalletConnect as a remote signer provider to enable cross-device, multi-network interactions.
