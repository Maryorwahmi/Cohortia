Module 7 › Chapter 7.6 › Common Mistakes
Top mistakes
  • Hardcoding chain assumptions instead of reading chainId.
  • Not handling chainChanged or not converting hex chain IDs.
  • Ignoring disconnect events from WalletConnect.
  • Poorly worded error messages for failed network switches.
Debugging tips
Log provider events and request/response payloads during development so you can trace failures.
Unit test the network configuration mapping to reduce runtime misconfiguration.
Test both connection flows: MetaMask desktop and a mobile wallet via WalletConnect.
Pro tip

Provide a status strip in your app that shows provider, account, chainId, and last provider event to aid troubleshooting during testing and support.
