Module 7 › Chapter 7.6 › Detect chainId
Definition

chainId is authoritative

Use web3.eth.getChainId() or subscribe to chainChanged events to determine the network. Map the numeric chainId to your network configuration to select RPC, explorer, and contract addresses.

Configuration pattern
const NETWORKS = {
  11155111: { name: 'Sepolia Testnet', rpcUrl: 'https://sepolia.infura.io/v3/ID' },
  80001: { name: 'Polygon Mumbai', rpcUrl: 'https://rpc-mumbai.maticvigil.com' }
};
UX guidance
  • Always show the current network name derived from chainId so users know where transactions will run.
  • If a required contract is not deployed on the active chain, show a clear message and offer a network switch option.
  • Do not assume a particular chain — make your logic chainId-driven.
Key Takeaway

Use chainId as the single source of truth and reload chain‑specific resources when it changes.
