Verification tasks

Provider connectivity
Install @walletconnect/web3-provider and verify enable() returns accounts. Keep Infura ID ready.
Event handling
Listen for accountsChanged, chainChanged, and disconnect to update dApp state and reset UI.
Network switcher
Call wallet_switchEthereumChain and handle error code 4902 by invoking wallet_addEthereumChain with network params.
Contract mapping
Maintain a configuration object mapping chainId to contract addresses and reinstantiate contract instances after chain changes.
