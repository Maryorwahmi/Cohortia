Code Walkthrough

Provider setup and enable

// Provider config
import WalletConnectProvider from '@walletconnect/web3-provider';
import Web3 from 'web3';

const provider = new WalletConnectProvider({
  infuraId: 'YOUR_INFURA_PROJECT_ID',
  rpc: {
    11155111: 'https://sepolia.infura.io/v3/YOUR_INFURA_PROJECT_ID',
    80001: 'https://rpc-mumbai.maticvigil.com'
  }
});

// Enable and create web3
try {
  await provider.enable();
  const web3 = new Web3(provider);
  const accounts = await web3.eth.getAccounts();
  const chainId = await web3.eth.getChainId();
} catch (err) {
  console.error('Connection failed:', err);
}
Event wiring
  • provider.on('accountsChanged', handler) — update account state or disconnect if none.
  • provider.on('chainChanged', handler) — parse hex or decimal, update chainId, reload contracts.
  • provider.on('disconnect', handler) — cleanup and clear session.
Common mistake

Not removing event listeners or not handling promise rejections from enable() causes stale UI and confusing errors.

Key Takeaway

Normalize provider behavior across MetaMask and WalletConnect so the rest of the app consumes a single account and chain state.
