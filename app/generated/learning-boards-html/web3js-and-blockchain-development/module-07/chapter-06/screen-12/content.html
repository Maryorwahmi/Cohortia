Module 7 › Chapter 7.6 › Hands‑on Activity

Activity steps (high level)

Setup
Create React app, install web3 and @walletconnect/web3-provider, define NETWORKS with Sepolia and Mumbai.
Connect
Implement connectMetaMask and connectWalletConnect, call enable() for WalletConnect, read accounts and chainId.
Switch & Verify
Add network switcher using wallet_switchEthereumChain and fall back to wallet_addEthereumChain when necessary.
Test: connect a mobile wallet via WalletConnect QR or deep link, switch networks, and confirm account and chain state change and contract instances reload.
Key Takeaway

This lab ties together configuration, provider enablement, event handling, chain switching, and contract mapping — the core concerns of multi‑chain wallet integration.
