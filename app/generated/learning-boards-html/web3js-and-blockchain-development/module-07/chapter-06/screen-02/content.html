Learning Objectives

Skills to build a WalletConnect-enabled, multi‑chain dApp.

Bloom
Learn → Understand → Apply → Master
01
WalletConnect Purpose
Explain the session model and why private keys never leave wallets.
Mnemonic: QR code → secure channel → signatures.
VERIFIED COMPETENCY MILESTONE
02
Implement Provider
Install and configure @walletconnect/web3-provider and integrate with Web3.js in React.
Mnemonic: Provider config → enable() → web3 instance.
VERIFIED COMPETENCY MILESTONE
03
Detect & Switch Chains
Read chainId, display network info, and request wallet_switchEthereumChain or add a chain when missing.
Mnemonic: chainId → RPC map → contract map.
VERIFIED COMPETENCY MILESTONE
04
Manage Contracts per Chain
Map contract addresses to chainId, reload ABI instances, and handle chain-specific logic like gas tokens or bridges.
Mnemonic: contractMap[chainId] → new web3.eth.Contract(...)
VERIFIED COMPETENCY MILESTONE
