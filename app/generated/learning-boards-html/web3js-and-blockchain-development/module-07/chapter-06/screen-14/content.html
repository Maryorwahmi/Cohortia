Module 7 › Chapter 7.6 › APIs & Identifiers
chainId
Unique numeric ID for a blockchain network; use it to select RPCs and contract addresses.
wallet_switchEthereumChain
RPC method to request wallet network changes; pass chainId in hex.
wallet_addEthereumChain
RPC method to prompt the wallet to add a new custom network when not present.
Final summary

Combine chainId-driven configuration, provider methods for switching/adding networks, and robust event handling to build reliable multi‑chain user flows.
