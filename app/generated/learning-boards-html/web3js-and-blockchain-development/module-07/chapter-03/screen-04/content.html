Module 7 › Chapter 7.3 › What is IPFS?
Content-addressed storage
Files are identified by a cryptographic hash. The CID changes if the content changes.
Why this matters
  • Immutability: a CID guarantees the exact bytes of a file.
  • Resilience: multiple peers can serve the same content.
  • Separation of concerns: blockchain stores CIDs, not large files.
Analogy
Think of a CID like a fingerprint for a file: show the fingerprint and anyone can verify the file matches it.
Common misconception
IPFS is not private by default. Public content must be encrypted off-chain if confidentiality is required.
Concrete example
An NFT metadata file uploaded to IPFS returns a CID. The smart contract stores ipfs://CID. Anyone who reads tokenURI can construct a gateway URL to fetch the metadata JSON and verify the CID matches the returned file.
Key takeaway: CIDs let you verify content integrity while keeping on-chain storage minimal and affordable.
Key Takeaway

CIDs are the cryptographic link between on-chain references and off-chain content.
