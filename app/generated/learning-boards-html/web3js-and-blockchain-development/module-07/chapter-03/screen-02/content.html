Learning Objectives
Move from concept to hands-on IPFS integration.
Bloom: Learn → Understand → Apply → Master
01
Explain IPFS fundamentals
Describe content-addressing, CIDs and why blockchains should store CIDs instead of large files.
VERIFIED COMPETENCY MILESTONE
02
Add and retrieve files
Use ipfs-http-client or gateways to upload files and fetch content by CID with reliable code patterns.
VERIFIED COMPETENCY MILESTONE
03
Integrate with React
Implement a file input, upload to IPFS, capture the CID, and render media via an IPFS gateway in your UI.
VERIFIED COMPETENCY MILESTONE
04
Link CIDs to contracts
Store ipfs://CIDs in contract state to create small, verifiable pointers to off-chain content.
VERIFIED COMPETENCY MILESTONE
Each objective pairs a definition with a concrete example so you can practice adding a file, retrieving it, storing its CID on-chain, and displaying the content securely through a gateway.
