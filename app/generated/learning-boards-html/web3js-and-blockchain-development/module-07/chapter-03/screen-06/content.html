Module 7 › Chapter 7.3 › IPFS Gateways
Gateways provide HTTP access
Request ipfs://CIDs through a gateway URL like https://ipfs.io/ipfs/CID to receive content in a browser.
Notes
  • Gateways are convenience proxies, not persistence guarantees.
  • Run your own gateway for production to reduce external dependency.
  • Use gateway URLs in image tags to present IPFS-hosted media in dApps.
Concrete example
If tokenURI returns ipfs://Qm... you can display the image using https://ipfs.io/ipfs/Qm... in an img src attribute, or your own gateway URL.
Misconception to avoid: assuming public gateway uptime equals data persistence. Gateways fetch and serve content, but only nodes pinning the CID make the data persist long-term.
Key Takeaway

Use gateways for browser access but ensure pinning and multi-node availability for durability.
