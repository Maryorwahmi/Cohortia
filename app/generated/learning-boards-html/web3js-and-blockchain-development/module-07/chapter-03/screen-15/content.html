Module 7 › Chapter 7.3 › Key Concepts
IPFS
A peer-to-peer file system using content addressing.
CID
A cryptographic hash that uniquely identifies file content.
Gateways
HTTP proxies that let browsers fetch IPFS content via URL.
ipfs-http-client
A JS client to add and fetch files programmatically.
Pinning
Tell nodes to retain content so it remains available.
Privacy
Encrypt sensitive files before adding; keys must be managed off-chain.
Summary

Use IPFS to host large media, store the CID on-chain for verification, and plan for pinning and privacy to ensure availability and security.
