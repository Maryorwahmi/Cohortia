Privacy: encrypt before adding
IPFS exposes content to anyone who has the CID. Encrypt off-chain for private data and manage keys securely.
Practical checklist:
  • Encrypt private files before ipfs.add.
  • Store decryption keys in a secure key manager off-chain.
  • Consider access proxies that decrypt content only for authorized users.
Mutable data patterns
Publish new CIDs for each version and update the stored CID in your contract to point to the latest version; this preserves history and keeps on-chain state small.
Example
A user updates their profile → upload new JSON → get new CID → update contract tokenURI or a registry to reference the new CID.
Key Takeaway

IPFS is immutable; handle mutation by versioning CIDs or using pointer systems and encrypt sensitive content before adding.
