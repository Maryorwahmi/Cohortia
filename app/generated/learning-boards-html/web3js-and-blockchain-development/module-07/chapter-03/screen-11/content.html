Module 7 › Chapter 7.3 › Image Gallery Lab
Step-by-step lab
1. Contract
Deploy ImageGallery with uploadImage and getImages functions to store CIDs.
2. React setup
Init Web3, request accounts, and create ipfs-http-client instance for uploads.
3. Upload flow
FileReader → ipfs.add → get CID → contract.methods.uploadImage(cid).send(...)
4. Fetch & display
Call getImages, map CIDs to gateway URLs, render images with fallback handling.
5. Pinning
Pin uploaded CIDs via a service to ensure persistent availability for the gallery.
6. UX polish
Show statuses for connection, upload, transaction, and provide retry/fallback strategies for slow gateways.
This step sequence mirrors the chapter's hands-on activity and prepares you to demonstrate a working gallery that stores only small, verifiable CIDs on-chain while serving media through IPFS gateways.
