Production checklist
CID validation
Verify ipfs.add returns a CID and include checks before storing it on-chain.
Pinning & redundancy
Pin critical CIDs on multiple nodes or via a pinning service for persistence.
On-chain pointers
Store ipfs://CID instead of absolute gateway URLs to avoid vendor lock-in.
Privacy
Encrypt sensitive data prior to adding and manage decryption keys off-chain.
UX & error handling
Provide clear statuses for wallet connection, IPFS upload, transactions, and gateway fetches.
Versioning
Publish new CIDs for updates and update the on-chain pointer to refer to the latest version when needed.
Follow this checklist during design and testing to create dependable IPFS-backed dApps that are verifiable, resilient, and respectful of user privacy.
