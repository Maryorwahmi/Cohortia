Module 7 › Chapter 7.3 › CIDs in Contracts
Smart contract pointer pattern
Store ipfs://CID strings in contract variables or tokenURI so on-chain records reference immutable off-chain files.
Solidity example snippet
string public tokenURI;

function setTokenURI(string memory _tokenURI) public onlyOwner {
  tokenURI = _tokenURI;
}
Frontend flow
  1. Upload file via ipfs.add → get CID.
  2. Call contract.setTokenURI(`ipfs://${cid}`) in a transaction.
  3. Later, read tokenURI, extract the CID, and fetch via gateway.
Why store CID not gateway URL
A bare CID keeps the reference decentralized and avoids locking your dApp to a particular gateway provider.
Key Takeaway

Store ipfs://CIDs on-chain and construct gateway URLs in the frontend to display content without coupling contracts to URLs.
