What is a reorg?

A reorg replaces a previously accepted block with a different block when a longer chain appears. Events in the orphaned block no longer exist in the canonical chain.

Symptoms for dApps
Transactions or events shown as confirmed disappear later, causing UI inconsistencies.
Mitigations
  • Wait for N confirmations before marking events final.
  • Record block hashes and re-verify chain inclusion if needed.
  • Run periodic reconciliation comparing stored state with on-chain queries.
Key Takeaway

Design for provisional updates and reconciliation so reorgs do not leave your application in an incorrect state.
