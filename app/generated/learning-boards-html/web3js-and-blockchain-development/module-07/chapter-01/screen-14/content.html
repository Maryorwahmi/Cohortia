Module 7 › Chapter 7.1 › Key Concepts
Events
Log entries emitted by contracts used as efficient off-chain signals.
Subscriptions
Persistent WebSocket connections that deliver new logs as they appear.
Topics
Event signature and indexed parameters used to filter logs efficiently.
Summary
Combine historical queries with live subscriptions, decode logs with an ABI, filter by topics, and implement confirmation and reconnection strategies to build reliable real-time dApps.
