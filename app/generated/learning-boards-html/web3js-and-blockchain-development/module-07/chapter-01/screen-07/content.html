Module 7 › Chapter 7.1 › Subscribing to Transfer events
Starter code
import Web3 from 'web3'

const web3 = new Web3(new Web3.providers.WebsocketProvider('wss://...'))
const tokenAbi = [ /* Transfer event ABI inputs */ ]
const tokenAddress = '0x...'
const sig = web3.utils.sha3('Transfer(address,address,uint256)')

web3.eth.subscribe('logs', { address: tokenAddress, topics: [sig] })
  .on('data', (log) => {
    const decoded = web3.eth.abi.decodeLog(tokenAbi[0].inputs, log.data, log.topics.slice(1))
    // decoded.from, decoded.to, decoded.value
  })
  .on('error', (err) => console.error('Subscription error', err))

Keep the code readable, convert values using token decimals, and store blockNumber for confirmation checks.

Explanation
  • sig is topic[0] and filters to Transfer events only.
  • decodeLog maps raw data to named fields using the ABI inputs.
  • log.topics.slice(1) are indexed parameters like from and to when marked indexed.
Example
When a Transfer arrives, decode and push a short object {from,to,value,blockNumber} into UI state to render immedately.
Pitfall
Assuming value uses 18 decimals. Always confirm token decimals before converting raw units.
