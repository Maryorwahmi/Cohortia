Module 7 › Chapter 7.1 › Event signature & topics
Core idea

topic[0] = keccak(event declaration)

The event name and parameter types are hashed to form the event signature that appears as the first topic in logs.

Indexed params → topics
Parameters declared indexed appear in topics and can be used as subscription filters without decoding the data payload.
Practical filter examples
Filter for all Transfer events: topics: [sig]
Filter for transfers to a specific address: topics: [sig, null, fromAddressHash]
Cannot filter by non-indexed value at subscription time — decode first, then filter in app logic.
Key Takeaway

Plan indexes during contract design and use topics to minimize the volume of logs your app processes.
