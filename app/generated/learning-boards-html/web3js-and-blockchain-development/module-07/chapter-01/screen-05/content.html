Module 7 › Chapter 7.1 › web3.eth.subscribe basics
Quick pattern

Create provider → subscribe → handle → cleanup

Use a WebSocket provider with web3. Then call web3.eth.subscribe with type and filters. Attach .on('data') and .on('error') handlers to process incoming events.

Subscription types
  • newBlockHeaders: new blocks as they are mined.
  • pendingTransactions: mempool activity, high volume.
  • logs: contract events, filterable by address/topics.
Example
In a component, initialize the provider and subscribe in useEffect, and unsubscribe in the cleanup function to avoid dangling sockets.
Operational notes

Resilience and filtering

  • Filter subscriptions by contract address and topics to reduce noise.
  • Guard against high-volume streams like pendingTransactions unless you have batching.
  • Implement reconnect attempts and exponential backoff when the WS disconnects.
Key Takeaway

Subscriptions give live data; lifecycle and filtering are essential for a robust implementation.
