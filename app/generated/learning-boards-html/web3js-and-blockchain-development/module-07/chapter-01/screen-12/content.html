Module 7 › Chapter 7.1 › TokenMonitor walkthrough
Starter steps
  1. Call getPastEvents to fetch recent transfers and set state.
  2. Record lastBlock = highest blockNumber from the results.
  3. Init WebSocket provider and subscribe from lastBlock + 1.
UI tips
Keep only the most recent 10–20 transfers, use concise keys like txHash+logIndex, and show provisional state until confirmations complete.
Edge cases
  • Handle decode failures gracefully and log for later inspection.
  • On reconnect, use getPastEvents to backfill block gaps.
  • Convert values with correct token decimals for display.
Key Takeaway

A robust TokenMonitor seeds history, listens live, handles reconnects, and treats new events as provisional until confirmed.
