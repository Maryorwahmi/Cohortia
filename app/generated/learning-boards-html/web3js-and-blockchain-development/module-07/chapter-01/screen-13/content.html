Module 7 › Chapter 7.1 › Filtering pitfalls

Common errors

  • Subscribing to broad topics like pendingTransactions without a filter.
  • Expecting to filter by non-indexed data at subscription time.
  • Not handling ABI mismatches which break decode logic.
Performance tip
Batch or debounce UI updates when many events arrive quickly to reduce re-renders.

Failure handling

When decoding fails or an unexpected log arrives, log the raw payload and continue. Crashing the handler will stop receiving future events.

Key Takeaway

Filter down to what you need, handle decode errors gracefully, and avoid rendering storms for large volumes.
