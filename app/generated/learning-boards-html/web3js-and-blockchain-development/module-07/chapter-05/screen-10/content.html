Module 7 › Chapter 7.5 › Virtualization and lazy loading
Virtualize long lists
Render only visible items and recycle DOM nodes to keep the UI responsive for large datasets like transaction histories or NFT galleries.
Lazy loading
Load routes and heavy components only when users navigate to them to reduce initial bundle size.
Debounce network calls
When virtualization triggers data fetches as the user scrolls, debounce or batch these requests to avoid flood against your node provider.
