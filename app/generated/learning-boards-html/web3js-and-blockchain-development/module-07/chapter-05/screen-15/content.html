Module 7 › Chapter 7.5 › What to Remember
Measure first
Record request counts and timings before changing code so improvements are verifiable.
Apply one change at a time
Refactor to Multicall, then add caching, then optimize rendering to attribute gains accurately.
Prioritize user perception
Small UX improvements like optimistic updates or loading skeletons often have outsized impact on perceived speed.
Final takeaway
Combine caching, batching, reliable providers, and React optimizations to deliver fast, reliable dApps.
