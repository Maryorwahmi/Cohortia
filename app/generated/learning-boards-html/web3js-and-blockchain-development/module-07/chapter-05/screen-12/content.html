Module 7 › Chapter 7.5 › Efficient data retrieval and state management
Three-step sync
  1. Initial fetch: seed state with getPastEvents or batched view calls.
  2. Subscribe: open a WebSocket subscription to receive new events.
  3. Update cache: apply event changes to local cache and only update affected components.
Example
Seed a transfer list with recent events, then append new events from subscription rather than reloading the whole list.
Misconception
Subscriptions alone are not enough; always start from a known historical snapshot.
