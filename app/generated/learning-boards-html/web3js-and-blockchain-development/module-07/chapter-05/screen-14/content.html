Module 7 › Chapter 7.5 › Key Concepts
Caching
Store frequently accessed immutable data locally and validate freshness with TTLs or block numbers.
Multicall
Batch multiple view calls into a single RPC request to reduce round trips and overhead.
Node Providers
Infura and Alchemy add caching, load balancing, and WebSocket support to improve reliability and speed.
Summary takeaway
Combine caching, batching, subscriptions, and frontend optimizations for the best perceived performance in a dApp.
