Module 7 › Chapter 7.5 › React performance: state management and memoization
Patterns to reduce re-renders
  • Use React.memo for stable components
  • useCallback for function stability
  • useMemo for expensive derived data
  • Keep local UI state local
Example structure
Store balances as an object keyed by token address. When a single balance updates, setState with a new object that preserves other keys to keep unaffected components stable.
Pro tip
Profile with React DevTools and only memoize hot paths that show measurable re-render cost.
