Module 7 › Chapter 7.5 › Implementing Multicall
Code pattern
Create call objects, call aggregate, decode results, and map to tokens.
// Build calls
const calls = TOKEN_CONFIG.map(token => ({
  target: token.address,
  callData: web3.eth.abi.encodeFunctionCall(ERC20_ABI.find(m => m.name === 'balanceOf'), [account])
}));

// Single aggregate RPC
const { returnData } = await multicallContract.methods.aggregate(calls).call();

// Decode results
returnData.forEach((result, i) => {
  if (result.success) {
    const decoded = web3.eth.abi.decodeParameters(['uint256'], result.returnData);
    balances[TOKEN_CONFIG[i].name] = web3.utils.fromWei(decoded[0], 'ether');
  } else {
    balances[TOKEN_CONFIG[i].name] = 'Error';
  }
});
Example result
When fetching five balances, the Multicall approach yields one network request and a single latency bound, often faster than parallel or sequential individual RPCs.
Pro tip
When tokens have different decimals, decode raw numbers first then apply token-specific decimals before formatting for display.
Edge case
If a Multicall returns empty bytes or fails, handle it gracefully by showing an error state for that token rather than breaking the entire UI.
