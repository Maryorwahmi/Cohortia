Module 8 › Chapter 8.5 › The Graph
What it does
The Graph runs indexing nodes that process blockchain events into entities defined by subgraphs, then serves those entities via a GraphQL API. This removes repeated block scans from your dApp and provides a standardized query interface.
When to choose it
  • - Multiple consumers need the same indexed view.
  • - You require complex filtering or joins across events.
  • - You prefer a managed, decentralized indexing service.
When a custom store is enough
  • - Single application with simple history needs.
  • - You want full control over schema, retention, or transformations.
  • - You expect to handle reorgs and reconciliation yourself.
Design prompt
Sketch the entities you would store for a transfer feed: transfer entity fields, indexing keys, and which relations you want to query quickly.
