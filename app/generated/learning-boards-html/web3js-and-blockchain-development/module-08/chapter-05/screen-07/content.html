Code walkthrough (visual)
// Example of Web3.js BatchRequest
const web3 = new Web3(window.ethereum);
const batch = new web3.BatchRequest();

batch.add(web3.eth.getBalance.request('0xabc...', 'latest', (err, balance) => {
  if (err) console.error(err);
  else console.log('Balance:', balance);
}));

batch.add(myContract.methods.getTokenSupply().call.request((err, supply) => {
  if (err) console.error(err);
  else console.log('Token Supply:', supply);
}));

batch.execute(); // sends both requests in a single HTTP call
Notice how each request is added to the batch and the batch executes once, reducing multiple HTTP round trips into one. Handle callbacks and update UI after execution completes.
Supporting points
  • - BatchRequest lowers HTTP overhead and reduces visible waiting time for multiple reads.
  • - Keep callbacks tidy: collect results then set state once to avoid multiple renders.
  • - Test with dev tools to confirm reduced number of requests.
Key Takeaway

Batch reads to lower RPC calls, then update state once with the aggregated response.
