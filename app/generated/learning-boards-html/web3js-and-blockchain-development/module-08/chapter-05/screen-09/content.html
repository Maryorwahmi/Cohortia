Module 8 › Chapter 8.5 › Caching Strategies
Where to cache
  • - React state for in-session caching.
  • - localStorage for small persisted values like token metadata.
  • - Global store (Redux / Zustand) for app-wide shared values.
Invalidation patterns
  • - Invalidate on transaction confirmations that change the cached value.
  • - Use a time-to-live (TTL) for dynamic numeric fields.
  • - Provide manual refresh triggers for users.
Concrete example
Cache token name and symbol indefinitely. Cache user balance with a 30-second TTL and refresh after transactions that affect that balance. If a transaction fails, revert the optimistic update and refresh the cached balance.
Key Takeaway

Pick a cache layer, define invalidation rules tied to transactions, and avoid silent staleness by offering refresh options.
