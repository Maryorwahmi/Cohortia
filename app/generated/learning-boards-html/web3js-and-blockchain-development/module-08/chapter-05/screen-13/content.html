Module 8 › Chapter 8.5 › Hands-on Activity
Step-by-step plan
  1. Measure current sequential reads in the browser network panel.
  2. Refactor to use web3.BatchRequest to fetch name, symbol, and balance together.
  3. Cache name and symbol in localStorage; cache balance with a short TTL.
  4. On transaction events, invalidate balance cache and re-fetch.
Checks and pitfalls
  • - Confirm batch reduces RPC calls in the network tab.
  • - Ensure batch callbacks populate state once to avoid extra renders.
  • - Invalidate balance cache on successful or failed transactions appropriately.
