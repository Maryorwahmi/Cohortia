Module 8 › Chapter 8.5 › BatchRequest vs Multicall
BatchRequest (client-side)
  • - Bundles RPC calls into a single HTTP request.
  • - Easy to add in existing Web3.js clients.
  • - Dependent on provider support for batch RPC.
Example Benefit
Reduces HTTP overhead and prevents rate-limits when fetching multiple view values for a single render.
Multicall (contract-side)
  • - Executes multiple view calls inside a single contract call.
  • - Works across different contracts without separate HTTP requests.
  • - Useful when you need atomic multi-read behavior.
Example Benefit
A single call to Multicall returns all encoded results, lowering the number of RPC interactions and simplifying client logic.
Decision checklist
Provider supports batch RPC?
Need cross-contract reads?
Prefer on-chain bundling?
