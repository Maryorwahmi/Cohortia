Definition

Non-Fungible Tokens

A unique token whose ownership and provenance are recorded on-chain. Metadata often lives off-chain and is referenced from the token contract.

Properties
Unique ID, owner address, tokenURI metadata pointer.
Typical Methods
balanceOf, ownerOf, tokenURI, transferFrom, approve.
Concrete Example
A concert ticket minted as an NFT: the tokenURI contains seat and access details. Transfers update on-chain ownership while metadata proves the ticket's authenticity.
Design Notes for Developers
  • Always handle missing or mutable metadata gracefully.
  • Display provenance: contract address, token ID, and transaction history.
  • Use Web3.js to call tokenURI and fetch JSON metadata for display.
Misconception

The NFT itself rarely stores large media on-chain. Relying on third-party hosting without backups risks loss of the referenced asset.
