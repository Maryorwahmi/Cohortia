Core Concept

Connecting UIs with Web3.js

Web3.js lets you call view functions, send transactions for votes or transfers, and subscribe to events for live updates. Implement clear feedback for transaction lifecycle so users know whether their action succeeded.
Read: proposal and token state with .call()
Write: send signed vote or transfer transactions with .send()
Subscribe: use event listeners for vote updates and proposal changes.
Practical UI components
Proposal list with metadata and status badges.
Ownership gallery showing images fetched from tokenURI and provenance details.
Transaction status strip showing pending, confirmed, or failed, with tx hash for verification.
Concrete Example
A governance portal uses Web3.js to call governance.methods.getProposal(id).call(), displays votes, and sends governance.methods.castVote(id, choice).send({from: user}) when the user confirms.
