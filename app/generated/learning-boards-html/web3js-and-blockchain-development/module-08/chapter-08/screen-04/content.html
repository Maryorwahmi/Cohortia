Core Concept

Decentralized Autonomous Organizations

An organization governed by rules encoded in smart contracts, with decisions made collectively by token holders.

Members vote using governance tokens to change protocol parameters or treasury spending.
Rules live on-chain as smart contracts; actions execute when proposals pass and are enacted.
Web3.js frontends fetch proposals, display voting options, and send vote transactions.
Key Takeaway

DAOs combine on-chain rules and off-chain collaboration; clear UI for voting and treasury helps community trust.

How a DAO Vote Works
1. Proposal
A member submits a proposal, with parameters and rationale.
2. Voting
Token holders cast votes; weight depends on token balance or delegation.
3. Enact
If quorum and thresholds are met, the proposal is executed against contracts.
Concrete Example
A DAO treasury holds funds. Members propose allocating X tokens to hire a developer for a new feature. Token holders vote; if passed, a contract call transfers funds to a payment address.
Common Mistake
Assuming votes are instantaneous: transactions must be mined and may be delayed. Also, off-chain discussion and proposal quality matter for effective governance.
