Verification checklist

Hands-on checks you can run immediately to confirm security behavior.

1. Chain mismatch test

Connect MetaMask to Mainnet while your dApp expects Sepolia and ensure the UI blocks risky actions and triggers wallet_switchEthereumChain.

2. Input validation test

Enter invalid addresses or negative amounts and verify clear errors prevent submission and conversion to Wei is correct for valid amounts.

3. Secret exposure check

Inspect network calls and source code to confirm provider keys are absent and backend proxy endpoints are used instead.

4. Rate limit and audit

Run package audit and simulate repeated backend calls to confirm rate limiting preserves service availability.
