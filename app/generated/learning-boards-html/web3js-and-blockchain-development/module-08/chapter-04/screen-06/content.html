Module 8 › Chapter 8.4 › Network Switching
Pattern

Request switch with fallback

Call wallet_switchEthereumChain and handle the 4902 error by showing add-network instructions.

User flow
  1. Detect wrong chain
  2. Request wallet_switchEthereumChain
  3. If code 4902: show add-network guidance
  4. If other error: show helpful message and logging
Example Code
const targetChainId = '0xaa36a7';

async function switchNetwork() {
  try {
    await window.ethereum.request({
      method: 'wallet_switchEthereumChain',
      params: [{ chainId: targetChainId }],
    });
  } catch (switchError) {
    if (switchError.code === 4902) {
      // Network not added to wallet. Provide instructions to user.
      console.error('Network not found. Please add it to your wallet.');
    } else {
      console.error('Failed to switch network:', switchError);
    }
  }
}
Gotcha

Do not assume switch requests always succeed. Provide a clear fallback and message for the user to add the network manually.
