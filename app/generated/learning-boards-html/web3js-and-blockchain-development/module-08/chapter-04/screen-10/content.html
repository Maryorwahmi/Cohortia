Dependency hygiene

Audit and update

Run package audits, review reported vulnerabilities, and apply updates or pin safe versions before release.

Quick checklist
  • Run npm audit or yarn audit periodically
  • Review transitive dependencies for wallet-related packages
  • Test after upgrades to confirm behavior
Rate limiting

Protect provider usage

Limit calls per IP or per user token, and log anomalies so you can rotate keys when abuse is detected.

Example
Add a simple bucket limiter on your /api/blockchain endpoint to cap requests over a short window and return a clear error when the limit is reached.
