Module 8 › Chapter 8.4 › API Key Management
Architecture

Frontend → Backend → Provider

Move all provider API keys to a backend process and let the backend make authenticated calls.

Benefits
  • Hide keys from users and crawlers
  • Apply rate limiting and logging
  • Validate requests server-side before forwarding
Proxy example
Frontend calls your /api/blockchain endpoint. Backend reads API key from environment and calls provider. Return only necessary data to the frontend.
Deployment note
Store API keys in environment variables, never check them into version control, and rotate keys if suspect abuse is detected.
Misconception

Putting keys in client code is safe if you obfuscate. In reality obfuscation is reversible and keys will leak.
