Checks

Address and amount validation

  • Use web3.utils.isAddress to reject malformed addresses.
  • Require numeric, positive amounts and convert to Wei with web3.utils.toWei.
  • Show formatted values back to the user for confirmation before signing.
Concrete example
If web3.utils.isAddress returns false, present an inline error and disable submit. For amount '0.5', convert to Wei to build the transaction value.
Example Form
Transfer form pseudo-UI
Recipient address input, amount input, inline errors, and a disabled transfer button until checks pass. Convert to Wei and display both human and machine values for confirmation.
// Validation steps
if (!web3.utils.isAddress(recipientAddress)) {
  setError('Invalid Ethereum address.');
  return;
}
const parsed = parseFloat(amount);
if (isNaN(parsed) || parsed <= 0) {
  setError('Amount must be a positive number.');
  return;
}
const amountInWei = web3.utils.toWei(amount, 'ether');
// proceed with transaction using amountInWei
Key Takeaway

Validate format and convert units before sending. Always present values back to the user for confirmation.
