Module 8 › Chapter 8.2 › Arweave: permanent storage versus pinning
Definition

Permanent storage model

Arweave charges a one-time fee to store data permanently. This suits archives and assets that must remain unchanged and available forever.

Considerations
  • Pay once for archival permanence.
  • Uploads are immutable snapshots; updates create new data entries.
  • Best for regulatory archives, historical records, and high-value immutable assets.
Key Takeaway

Use Arweave when you need a permanent, paid guarantee that your dApp assets will remain available indefinitely.

Concrete example
Archive a release binary or signed UI snapshot to Arweave when you need to ensure it will never be altered or removed.
Misconception
Arweave is not a convenience replacement for frequent updates; because stored data is permanent, you will create new uploads for each version.
