Module 8 › Chapter 8.2 › Run the deployment and verify the CID
Terminal Demo
Commands
# Build your app and run the deploy script
npm run build
npm install @pinata/sdk dotenv
node scripts/deploy-ipfs.js
Expected output
  • Pinata authentication successful.
  • DApp successfully pinned to IPFS!
  • IPFS CID: Qm... or bafy... (a CID string you can paste into gateways)
Key Takeaway

Run, read the CID, and then validate by opening it in a gateway. Test deep routes and asset loading.

Common errors
Missing API keys, incorrect build path, or network timeouts are frequent. Check .env, paths, and try re-running the script after confirming build/ contents.
Pro tip
Keep a copy of the CID in project deployment notes and consider pinning to multiple services or archiving to Arweave for redundancy.
