Troubleshooting

Quick fixes

  • Build artifacts missing? Run npm run build and re-deploy.
  • Authentication failing? Check .env and API keys for typos and permissions.
  • Intermittent availability? Try another gateway and confirm the pin is intact.
  • Routing 404s? Add "homepage": "." to package.json, rebuild, and repin.
Key Takeaway

A short checklist resolves most deployment problems: build, authenticate, repin, and test across gateways.

Pro tip
Keep a small deployment log recording the CID and build commit hash so you can correlate user reports to the exact snapshot deployed.
Assessment idea
Simulate a broken route and fix it with the homepage change, rebuild, repin, and verify that the CID now serves working navigation.
