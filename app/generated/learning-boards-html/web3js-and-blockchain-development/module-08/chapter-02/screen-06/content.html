Module 8 › Chapter 8.2 › Build your React app for IPFS
Process

Build steps

  1. Run npm run build or yarn build to produce a build/ folder.
  2. Confirm index.html and static asset directories exist inside build/.
  3. Set package.json homepage to "." when using client-side routing.
  4. Serve the build locally to test routes and assets before uploading.
Concrete check
Open index.html from the build folder on a static server. Navigate to a sub-route and refresh to ensure no 404s. If you see missing assets, check the homepage configuration.
Routing pitfall
Client-side routing expects index.html to be served for all paths. Without relative asset paths, gateways may try to fetch absolute paths that don't exist, causing 404s. The package.json homepage set to "." prevents this.
Key Takeaway

Always build and test the static output locally. Fix asset paths and routing before uploading to decentralized storage.
