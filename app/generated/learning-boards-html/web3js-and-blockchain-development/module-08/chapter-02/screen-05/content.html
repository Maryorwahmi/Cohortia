Definition

Content-addressing and CIDs

CIDs are cryptographic hashes of file content. They let anyone verify that the bytes they received match what the publisher intended.

What to remember
  • A CID identifies exact content; it is immutable.
  • Changing content changes the CID, so versions get different addresses.
  • Gateways translate CIDs into HTTP access for browsers.
Key Takeaway

Use CIDs to verify asset integrity and to reference immutable builds when you publish a dApp frontend.

Concrete example
Pinning the React build folder produces an IPFS root CID. That CID references the exact index.html and asset files the browser will load.
Common misconception
IPFS is not a permanent host by default: content must be kept by nodes. Pinning services provide persistent hosting guarantees at a cost.
Why it matters
Immutable CIDs increase trust: anyone can verify the build hasn’t been tampered with, which is critical for distributed applications.
