Hands-on Activity

Deployment checklist

  1. Run npm run build and verify build/ has index.html and static assets.
  2. Create a Pinata account and get API key and secret.
  3. Add keys to a .env file and install @pinata/sdk dotenv.
  4. Set correct buildFolderPath in scripts/deploy-ipfs.js and run the script.
  5. Copy returned CID into a gateway URL and validate the live dApp, including deep routes.
Key Takeaway

Follow the checklist and re-run builds when fixing routing or asset path issues to ensure the CID reflects the corrected snapshot.

Concrete note
After each meaningful change, rebuild and repin to publish the new snapshot under a new CID. Keep records of CIDs for releases.
Common mistake
Uploading source files instead of the build output is incorrect; only static built files will render correctly in browsers via gateways.
