Architecture

Gateway bridge

Gateways translate HTTP requests into IPFS content resolution by CID so browsers can load files without native IPFS support.

Checklist to prevent 404s
  • Add "homepage": "." to package.json when using react-router.
  • Build and verify index.html exists in build/.
  • Open the gateway URL with a subpath to test deep-route behavior.
Key Takeaway

Gateways enable browser access but do not rewrite routes; build with relative paths and test deep links after deployment.

Concrete test
Open https://gateway.pinata.cloud/ipfs/<CID>/dashboard and refresh. If you see index.html content and react-router renders the page, routing is configured correctly.
Common misconception
Believing gateways will automatically serve index.html for all paths; adjust build settings instead.
