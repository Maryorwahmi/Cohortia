Definition

Integer Overflow / Underflow

Understand arithmetic safety and historical mitigations.

What happens
  • Overflow: value exceeds max type and wraps to low values.
  • Underflow: subtracting more than current unsigned value wraps to a large number.
  • Effect: logic relying on numeric bounds can be broken, leading to asset misallocation.
Example: an 8-bit value at 255 plus 1 wrapped to 0 on older runtimes; modern Solidity reverts instead.
Mitigations
Use Solidity version 0.8 or later, which reverts on out-of-range arithmetic. When working with legacy code, apply SafeMath-like checks or rewrite logic to include explicit bounds verification.
Pro tip: enforce numeric sanity checks before writing state.
Common mistake: assuming libraries using older compilers inherit safe arithmetic automatically.
Key Takeaway

Prefer built-in arithmetic checks from modern compilers and validate or patch legacy contracts that rely on wrapping behavior.
