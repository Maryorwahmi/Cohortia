Typical deploy script (pattern)
async function main() { const [deployer] = await ethers.getSigners(); console.log("Deploying contracts with the account:", deployer.address); const initialSupply = 1000000; // Example constructor argument const MyToken = await ethers.getContractFactory("MyToken"); const myToken = await MyToken.deploy(initialSupply); await myToken.deployed(); console.log("MyToken deployed to:", myToken.address); } main() .then(() => process.exit(0)) .catch((error) => { console.error(error); process.exit(1); });
Note: await the deployed call to ensure the transaction is mined and the address is available for immediate use.
Post-deploy verification
  • Log the deployer address and contract address.
  • Call a view function such as get() or balanceOf to check initial state.
  • Record the address and ABI for your frontend or dApp configuration.
Key Takeaway

Make the deploy script the single source of truth for creating and validating the contract on the target network.
