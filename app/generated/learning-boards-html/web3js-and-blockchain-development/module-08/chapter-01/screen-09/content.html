Module 8 › Chapter 8.1 › Run & Interpret
Typical command
npx hardhat run scripts/deploy.js --network sepolia
Watch the console for a printed deployer address, the deployed contract address, and any returned initial state from view calls done in the script.
Misreadings to avoid

A missing contract address usually means await myContract.deployed() did not resolve; ensure the script awaits confirmation and prints the result.

Debug checklist
  • Confirm RPC URL and API key are set in .env.
  • Check the deployer account balance for sufficient test ETH.
  • Review constructor arguments for type and order.
  • Inspect transaction hash on the block explorer for status and gas used.
