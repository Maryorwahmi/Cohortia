Recommended hardhat.config.js
require("@nomicfoundation/hardhat-toolbox"); require("dotenv").config(); // Load environment variables const SEPOLIA_RPC_URL = process.env.SEPOLIA_RPC_URL; const PRIVATE_KEY = process.env.PRIVATE_KEY; module.exports = { solidity: "0.8.20", networks: { sepolia: { url: SEPOLIA_RPC_URL, accounts: [PRIVATE_KEY] } } };
This setup lets Hardhat use the provided RPC and signing account without exposing secrets in your repo.
.env file (local)
SEPOLIA_RPC_URL="https://sepolia.infura.io/v3/YOUR_INFURA_PROJECT_ID" PRIVATE_KEY="YOUR_ACTUAL_PRIVATE_KEY_HERE"
Remember to add .env to .gitignore. Test connectivity with a simple run of a Hardhat task to ensure the RPC URL and key are correct.
Common Mistake

Do not commit a .env file or hardcode keys — an exposed private key can drain funds on mainnet.
