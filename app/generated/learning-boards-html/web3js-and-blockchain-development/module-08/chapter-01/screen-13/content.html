Deploy SimpleStorage — terminal steps
  1. Initialize Hardhat project and install @nomicfoundation/hardhat-toolbox and dotenv.
  2. Create a .env with SEPOLIA_RPC_URL and PRIVATE_KEY; add .env to .gitignore.
  3. Add SimpleStorage.sol to contracts and write scripts/deploy.js with an initial value like 42.
  4. Fund the deployer address with Sepolia ETH from a faucet and confirm the balance.
  5. Run npx hardhat compile, then npx hardhat run scripts/deploy.js --network sepolia and inspect output for the contract address.
  6. Use the ABI and contract address to call get() and confirm storedData equals the initial value.
Example terminal
You will see the deployer address, a transaction hash while mining, and a confirmed contract address on completion.
Check
If anything fails, verify .env entries, RPC reachability, and that the deployer has enough ETH.
