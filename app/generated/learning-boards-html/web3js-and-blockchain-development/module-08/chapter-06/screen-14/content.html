Process Flow › Upgrade Workflow
Checklist
  1. Write unit tests and upgrade-path tests that deploy V1, initialize via proxy, then upgrade to V2 and verify state and new APIs.
  2. Run OpenZeppelin storage-layout checks in CI to detect incompatible changes.
  3. Use multisig or governance for upgrade approvals; prepare a deploy plan and changelog.
  4. Deploy implementation, run upgrade in a controlled window, then execute smoke tests and monitoring scripts.
  5. Have rollback or mitigation steps documented before any mainnet upgrade.
Test
Simulate upgrade paths in CI and local networks.
Approve
Use multisig or governance for production upgrades.
Monitor
Run smoke tests and watch for anomalies post-upgrade.
