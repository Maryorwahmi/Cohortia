Definition › Storage Compatibility
Rules you must follow
  • Do not reorder existing state variables.
  • Do not change the type of existing variables.
  • Append new variables at the end of the storage layout.
Example of a breaking change
Changing uint256 value to string value in a new version will likely break storage interpretation and is rejected by the plugin.
Safe migration pattern
If you must alter representation, add new slots and write migration code in a controlled upgrade that copies old values to the new layout, and include tests to verify correctness.
Key Takeaway

Plan storage early and append fields only. Use plugin checks and tests to catch layout problems before upgrading live contracts.
