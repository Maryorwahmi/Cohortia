Comparison › UUPS Pattern
How it works

Implementation exposes an upgrade function; the proxy delegates all calls. Implementation enforces authorization for upgrades.

Benefits
  • Lower gas for user calls due to thinner proxy fallback.
  • Simpler proxy reduces on-chain complexity.
Risks and considerations
  • Upgrade authorization lives in implementation; bugs can brick upgrade path or enable unauthorized upgrades.
  • Audit focus shifts to _authorizeUpgrade and related hooks.
Concrete practice
Implement _authorizeUpgrade with strong access control, often using Ownable or a multisig guard, and include tests that try unauthorized upgrades.
