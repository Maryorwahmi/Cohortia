Proxy Architecture Overview
State held at fixed address • Logic swapped via implementation pointer
Proxy
Holds storage and a pointer to implementation. Receives user calls and uses delegatecall to run logic.
Implementation
Deployable logic contracts. New versions can be swapped in without moving storage.
Quick flow
  1. Deploy proxy at a fixed address and initial implementation.
  2. Proxy delegates calls with delegatecall, keeping storage in proxy.
  3. When ready, deploy new implementation and update proxy pointer.
Key Takeaway

Upgrades preserve address and state by swapping implementation logic while proxy storage remains unchanged.
