Tooling › OpenZeppelin Upgrades for Hardhat
Install and require
npm install @openzeppelin/hardhat-upgrades @openzeppelin/contracts-upgradeable
      
// hardhat.config.js
require("@nomicfoundation/hardhat-toolbox");
require("@openzeppelin/hardhat-upgrades");
These steps wire the plugin into Hardhat so its high-level API is available in scripts and tasks.
Important practices
  • Use deployProxy and upgradeProxy from the upgrades object.
  • Verify implementation addresses with upgrades.erc1967.getImplementationAddress.
  • Disable initializers in implementation constructors to avoid direct initialization.
Tip

Run the plugin's storage-layout checks as part of CI to detect incompatible changes early.
