Web3.js → Optimism RPC
The code below shows a simple Web3 initialization against an Optimism RPC and a contract call.
// Example: Connecting Web3.js to Optimism (an L2)
const Web3 = require('web3');

// Replace with the L2 RPC URL
const web3Optimism = new Web3('https://mainnet.optimism.io');

// ABI and contract address on the L2
const MY_ABI = [ /* ... ABI ... */ ];
const MY_OPTIMISM_CONTRACT_ADDRESS = '0xYourContractAddressHere';

const myOptimismContract = new web3Optimism.eth.Contract(MY_ABI, MY_OPTIMISM_CONTRACT_ADDRESS);

// Call a read-only method
myOptimismContract.methods.getData().call().then(console.log).catch(console.error);
Notes
• Ensure the RPC URL matches the target L2 testnet or mainnet.
• Verify chain ID to avoid sending transactions to the wrong network.
• For bridge transfers, use the L2 provider's deposit/withdrawal contracts or SDK for safe flows.
Key Takeaway

Connecting Web3.js to an L2 is the same pattern as L1 but requires correct RPC and chain checks plus bridge contract awareness for cross-chain moves.
