Definition
Lock-and-mint bridge
One chain locks the original asset while a representative is minted on the other chain, keeping asset supply consistent across networks.
Example
Lock an ERC-20 on Ethereum and mint an equivalent token on Polygon to enable fast, low-fee transfers on Polygon.
• Lock step: source contract holds tokens in escrow.
• Mint step: destination issues wrapped tokens that track the locked supply.
• Burn/unlock: wrapped tokens are burned to unlock originals when moving back.
Security concerns
Validators or custodians, contract bugs, and cross-chain finality differences all create attack surfaces. Bridges have historically been high-value targets due to locked funds.
Common mistake

Assuming a wrapped token is as secure as the original without validating the bridge's trust model and code security.

Checklist for bridge use
Check validator decentralization, audit history, and whether the bridge uses on-chain verification or trusted signers.
