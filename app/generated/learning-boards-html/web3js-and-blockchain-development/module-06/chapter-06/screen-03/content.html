Verification steps
  1. Address validation: check 0x prefix and 42 chars; consider checksum validation.
  2. Numeric validation: ensure positive integers and block-safe ranges where reasonable.
  3. State control: disable form while transaction is pending to prevent duplicates.
  4. Consistent feedback: show hash and a short error message when available.
