Module 6 › Chapter 6.6 › Refine Transaction Form and Feedback — Steps
Step-by-step
  1. Create TransactionFeedback(status, hash, error) that returns null when no status.
  2. Pass status and hash from your transaction hook or context into the component.
  3. Disable the form and submit control when isSendingTransaction is true.
  4. Validate address and amount inputs, blocking submit until valid.
  5. Test success, failure, and cancelled flows and refresh relevant UI on success.
Testing note
Simulate wallet rejection and contract revert paths to ensure messages are clear and inputs re-enable correctly.
Example check
After a confirmed transaction, verify the balance or list refresh occurs automatically without requiring a full page reload.
Key Takeaway

Small, repeatable tests for each state prevent user confusion and hidden failures in a dApp flow.
