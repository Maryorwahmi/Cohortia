Module 6 › Chapter 6.6 › Transaction States and User Feedback
State Model
Initial
Inputs enabled, clear action label, ready to start.
Pending
Disable form, show "Transaction Pending..." and transaction hash for tracking.
Success
Confirm to user, refresh related data (balances, lists).
Error
Show concise error. Offer retry path and do not expose long raw traces.
Process Steps
1. Click action. Button labeled for intent.
2. Wallet prompt. Show 'Waiting for wallet'.
3. Pending. Disable inputs and show hash text for tracking.
4. Confirm / Error. Update UI and show short message.
Example message formats
Transaction Pending... Hash: 0x1234...abcd (copy visible as text)
Transaction Confirmed! Balance updated.
Transaction Failed: out of gas. Please retry with higher gas limit.
