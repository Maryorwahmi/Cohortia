Integration pattern
Keep transaction state in a hook or context and feed it to UI components. Disable form controls while sending to prevent duplicates.

Practical tip
Do not clear inputs until after a transaction is successfully broadcast. That preserves data for retry if the send fails.
UX checklist
  • Disable form & button when isSendingTransaction is true.
  • Show a clear "Waiting for wallet" prompt before pending state.
  • Render transaction hash as text and show concise success or error messages.
  • Categorize wallet rejection as a cancellable state so users can retry.
Key Takeaway

Wire transaction state into form controls and feedback components for a coherent user experience.
