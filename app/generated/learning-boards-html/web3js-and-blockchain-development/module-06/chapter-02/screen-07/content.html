Module 6 › Chapter 6.2 › Web3Provider Architecture
Context value
Provide an object containing web3, accounts, chainId, isMetaMaskInstalled, isLoading, connectWallet, and currentAccount so consumers can read and act on connection state without prop drilling.
Why centralize?
  • Single place to initialize web3 and attach listeners.
  • Avoid repeated Web3 instances and duplicated event handlers.
  • Test and maintain connection logic in one component.
Example shape
const contextValue = { web3, accounts, chainId, isMetaMaskInstalled, isLoading, connectWallet, currentAccount: accounts.length > 0 ? accounts[0] : null, };
Key Takeaway

Keep a single provider component to manage detection, connection, and events so all components share a reliable web3 state.
