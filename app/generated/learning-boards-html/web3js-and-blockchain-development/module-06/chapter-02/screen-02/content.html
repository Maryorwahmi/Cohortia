Module 6 › Chapter 6.2 › Learning Objectives
01 — Detect Provider
Confirm window.ethereum exists. This tells you a compatible wallet is installed.
VERIFIED COMPETENCY MILESTONE
Mnemonic: think of detection as checking for a front door before knocking. If there's no door, guide the user to install the wallet.
02 — Request Accounts
Use eth_requestAccounts after user intent to prompt MetaMask approval.
VERIFIED COMPETENCY MILESTONE
Why it matters: permission is explicit and user-driven. Example: a Connect Wallet control calls eth_requestAccounts and sets the returned account list in state on success.
03 — Handle Changes
Listen for accountsChanged and chainChanged to keep UI accurate.
VERIFIED COMPETENCY MILESTONE
Small timeline mnemonic: detect → request → subscribe. Misconception: the account never changes — users often switch accounts or networks, so listen and update.
04 — Use React Context
Wrap your app in a Web3Provider to avoid prop drilling.
VERIFIED COMPETENCY MILESTONE
Concrete benefit: any child component can call useWeb3 to get web3, accounts, and chainId. This simplifies state management and keeps connection logic in one place.
