Module 6 › Chapter 6.2 › What is window.ethereum
Claim

window.ethereum is an injected provider object from MetaMask that exposes methods your dApp uses to read accounts and send RPC requests to the wallet.

Concrete example
// Check provider in useEffect if (window.ethereum) { // provider exists — show connect option } else { // prompt user to install MetaMask }
Common misconception

Presence of window.ethereum does not mean your dApp has account access. You must call eth_requestAccounts to obtain permission to view or use accounts.

Why this matters

Detecting window.ethereum determines whether your dApp can move beyond public reads and start requesting user signatures and transactions. If you skip this step you cannot prompt for account access, and your app stays read-only.

Quick checks
  • Open console and type window.ethereum — should not be undefined when MetaMask is installed.
  • Use eth_accounts to check whether any accounts are currently connected without prompting the user.
Key Takeaway

Detect window.ethereum on load, but always request accounts before attempting account-based actions.
