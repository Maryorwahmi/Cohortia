Module 6 › Chapter 6.2 › eth_accounts vs eth_requestAccounts
eth_accounts
Non-intrusive. Returns currently-connected accounts without prompting. Good for initialization checks to see if a user previously granted access.
const accounts = await window.ethereum.request({ method: 'eth_accounts' });
eth_requestAccounts
Prompting. Opens MetaMask to request account access. Should be called on user action to avoid unwanted prompts.
const accounts = await window.ethereum.request({ method: 'eth_requestAccounts' });
Best practice
Call eth_accounts on load; only call eth_requestAccounts after an explicit user action such as clicking Connect Wallet.
Misconception
Do not expect eth_requestAccounts to be silent or suitable for silent checks; it prompts the user and should be used sparingly.
