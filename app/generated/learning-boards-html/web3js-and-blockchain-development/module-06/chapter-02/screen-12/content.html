Module 6 › Chapter 6.2 › Key Concepts
MetaMask
A wallet extension that injects a provider and lets users approve transactions and account access.
window.ethereum
The injected provider object exposing RPC methods and events for dApp-wallet communication.
eth_requestAccounts
RPC method that prompts the user to grant account access; must be invoked via window.ethereum.request.
Remember: detect first, check existing connections, then request permission on user intent.
