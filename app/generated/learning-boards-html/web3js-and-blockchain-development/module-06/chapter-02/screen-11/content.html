Module 6 › Chapter 6.2 › Implement Wallet Connection
Steps
  1. Create src/contexts/Web3Provider.jsx and implement detection, connectWallet, and listeners.
  2. Wrap your App with Web3Provider in main.jsx.
  3. Use useWeb3 in App.jsx to conditionally render connect state and a connect affordance that calls connectWallet.
  4. Test: open console to inspect window.ethereum, click connect, switch accounts and networks, and observe UI updates.
Starter snippet
// Inside Web3Provider's useEffect
const accounts = await window.ethereum.request({ method: 'eth_accounts' });
if (accounts.length > 0) { setAccounts(accounts); setWeb3(new Web3(window.ethereum)); }

window.ethereum.on('accountsChanged', handler);
window.ethereum.on('chainChanged', handler);

// Cleanup:
if (window.ethereum.removeListener) {
  window.ethereum.removeListener('accountsChanged', () => {});
  window.ethereum.removeListener('chainChanged', () => {});
}
Checks & debugging
  • Confirm window.ethereum exists when MetaMask is installed.
  • Verify eth_requestAccounts resolves to an array on approval.
  • Ensure listeners update state and that cleanup removes them.
Key Takeaway

Follow the steps in order: detect, check existing accounts, expose connectWallet, subscribe to events, and test thoroughly across account and network changes.
