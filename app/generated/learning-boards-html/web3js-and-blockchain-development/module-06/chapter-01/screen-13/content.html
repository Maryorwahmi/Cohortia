Module 6 › Chapter 6.1 › Activity: Initialize and configure your dApp
Activity steps (top)
  1. Scaffold a Vite React project and install dependencies.
  2. Install web3 and add console logs to App.jsx to verify installation.
  3. Create .env with VITE_ placeholders and add .env to .gitignore.
Activity steps (bottom)
  1. Create folders: src/components, src/hooks, src/utils, src/contracts.
  2. Add an ABI JSON and a createContract helper to instantiate the contract using import.meta.env address.
  3. Start the dev server and verify logs; fix any issues per the troubleshooting slide.
Key Takeaway

Completing this checklist gives you a repeatable and secure starting point for all future dApp features and tests.
