Module 6 › Chapter 6.1 › Environment variables and the VITE_ prefix
What to put in .env
  • Project IDs for remote nodes (Infura, Alchemy) as VITE_INFURA_PROJECT_ID.
  • Deployed contract addresses as VITE_CONTRACT_ADDRESS.
  • Network identifiers or feature flags you want available client-side.
Security reminder

Add .env to .gitignore. Use different values for development and production and manage production secrets with your deployment platform.

Accessing variables
<!-- visual only -->
console.log(import.meta.env.VITE_INFURA_PROJECT_ID)
console.log(import.meta.env.VITE_CONTRACT_ADDRESS)
Common mistake

Forgetting the VITE_ prefix or committing .env exposes sensitive keys in the deployed bundle.
