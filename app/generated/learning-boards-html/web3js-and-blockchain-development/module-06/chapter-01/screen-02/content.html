Learning Objectives

Each objective is paired with a brief verification milestone to confirm your competency.

01
Initialize a new React project
Create a Vite-based React app for fast cold starts and HMR. This accelerates iteration when you test contracts.
VERIFIED COMPETENCY MILESTONE
02
Install and configure Web3.js
Add Web3.js and verify access from a component so your frontend can query accounts and call contracts.
VERIFIED COMPETENCY MILESTONE
03
Use environment variables securely
Place secrets in .env with a VITE_ prefix and add .env to .gitignore to prevent leaks in the client bundle.
VERIFIED COMPETENCY MILESTONE
04
Structure a maintainable project
Create folders for components, hooks, utils, and contracts to keep Web3 logic and UI separate and reusable.
VERIFIED COMPETENCY MILESTONE
