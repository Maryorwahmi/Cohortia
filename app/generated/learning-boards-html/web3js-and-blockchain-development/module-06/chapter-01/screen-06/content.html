What Web3.js provides
  • Provider management to talk to nodes over HTTP, WebSocket, or injected wallets.
  • Contract interaction helpers that encode calls using an ABI and address.
  • Account and transaction utilities for signing and sending transactions.
Concrete example

Import Web3 in a component and log the object while the dev server is running to verify the library is available to the bundle.

Common mistake

Logging Web3 confirms the library loaded but does not verify a provider or network connection.
