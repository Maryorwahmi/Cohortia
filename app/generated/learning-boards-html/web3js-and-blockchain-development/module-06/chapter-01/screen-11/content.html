Module 6 › Chapter 6.1 › Testing Web3.js and import.meta.env in App.jsx
What to verify
  • Web3 object logs to the console, confirming the package is bundled.
  • import.meta.env.VITE_* keys print the placeholder values, confirming exposure.
  • If values are missing, restart the dev server and check .env and prefixes.

<!-- src/App.jsx -->
import React from 'react'
import Web3 from 'web3'

function App(){
  console.log('Web3 object:', Web3)
  console.log('Infura ID:', import.meta.env.VITE_INFURA_PROJECT_ID)
  return (<div>Starter app</div>)
}

export default App
Pro tip

If you don't see values, try restarting the dev server; Vite may not hot-reload .env changes.
