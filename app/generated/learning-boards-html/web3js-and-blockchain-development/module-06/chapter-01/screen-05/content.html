Module 6 › Chapter 6.1 › Scaffold a Vite React project
Step-by-step
  1. Create a new project with the Vite initializer using the template for React or React-TS.
  2. Change into the new project directory.
  3. Run the package manager install command to fetch dependencies.
  4. Start the dev server and verify hot module reload by editing a visible component.
Verification
Edit a heading in the starter app and save. Observe the browser updates without a full reload and check the console for dev server messages.
Terminal snippets (visual only)
npm create vite@latest my-dapp -- --template react
cd my-dapp
npm install
npm run dev
Pro tip

Pick TypeScript if you want stronger compile-time checks for contract interfaces and ABIs later on.
