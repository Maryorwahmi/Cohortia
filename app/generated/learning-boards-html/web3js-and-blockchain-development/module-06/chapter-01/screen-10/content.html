Module 6 › Chapter 6.1 › Using ABI and contract address with Web3.js
How it works
  • ABI defines a contract's callable functions and event signatures.
  • Contract address tells Web3 which deployed instance to target.
  • Create a Web3 contract using new web3.eth.Contract(ABI, address) and call methods.
Misconception

The ABI is not secret. It is a public interface description required for interaction and safe to commit to the repository.

Code preview (visual)
<!-- src/hooks/useContract.js -->
import Web3 from 'web3'
import TokenABI from '../contracts/TokenABI.json'

export function createContract(){
  const web3 = new Web3(Web3.givenProvider || 'https://mainnet.example')
  const address = import.meta.env.VITE_CONTRACT_ADDRESS
  const contract = new web3.eth.Contract(TokenABI, address)
  return contract
}

// Usage: const contract = createContract(); contract.methods.name().call().then(...)
Key Takeaway

Keep ABIs in contracts/ and addresses in env vars; create contract instances in hooks for reuse.
