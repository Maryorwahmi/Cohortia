Common issues and fixes
  • Missing Web3 object: run npm install and restart the dev server.
  • Env vars undefined: ensure VITE_ prefix and that .env lives at the project root. Restart if needed.
  • Accidental .env commit: remove from history and rotate keys; add .env to .gitignore immediately.
  • Provider errors: detect injected providers, then fall back to remote RPC; handle user-denied requests cleanly.
Check your console

Log Web3, import.meta.env, and provider presence. These logs tell you whether the issue is bundling, configuration, or runtime connectivity.

Warning

If env keys were leaked, rotate them. Treat leaked RPC keys as compromised credentials.
