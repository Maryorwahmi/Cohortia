Module 6 › Chapter 6.1 › Organizing your React dApp folders
Suggested structure
src/
  components/    # reusable UI pieces
  hooks/         # useWeb3, useContract, etc.
  utils/         # formatters and converters
  contracts/     # ABI files and metadata
  App.jsx
  main.jsx
useContract example
A hook imports an ABI and address to return a contract instance that components can call.
contracts folder
Store TokenABI.json and other ABIs to keep interfaces centralized and versioned.
Concrete scenario

A transaction button component calls a useContract hook which returns methods to send transactions. The UI remains simple while all Web3 complexity sits in the hook.

Key Takeaway

Encapsulate Web3 logic in hooks, keep ABIs in contracts, and put UI in components to scale smoothly.
