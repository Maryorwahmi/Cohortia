Steps
  1. Modify SimpleStorage to emit DataChanged and recompile/redeploy.
  2. Update ABI and VITE_SIMPLE_STORAGE_CONTRACT_ADDRESS in your frontend and restart.
  3. Add subscription in useSimpleStorage useEffect to setStoredData from returnValues.
  4. Return cleanup that calls subscription.unsubscribe() to avoid leaks.
  5. Test using a second browser or wallet, trigger setData and observe real-time update.
Checks & Troubleshooting
If updates don't appear, verify ABI, contract address, console logs for decoding errors, and that subscription.unsubscribe wasn't called prematurely. Also check network connectivity and MetaMask confirmations.
Key Takeaway

This activity ties changes on-chain to instant UI feedback, demonstrating the efficiency of events over polling.
