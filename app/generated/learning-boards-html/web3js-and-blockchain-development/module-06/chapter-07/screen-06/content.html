getPastEvents
Fetch historical events to build initial lists or to audit past activity.
const past = await myContract.getPastEvents('DataChanged', { fromBlock: 0, toBlock: 'latest' });
past.forEach(e => process(e.returnValues));
Notes:
  • Good for initial population and rebuilding UI state.
  • Can be expensive; restrict block range or paginate.
Comparison
Live Subscriptions
Receive new events as they are mined and update UI in real time without polling.
const sub = myContract.events.DataChanged()
  .on('data', e => handle(e.returnValues))
  .on('error', err => console.error(err));
Notes:
  • Good for low-latency UI updates and feeds.
  • Remember to unsubscribe in cleanup to avoid duplicated handlers.
Key Takeaway

Use getPastEvents for a complete starting picture and a live subscription to receive incremental updates. Combining both gives a robust, responsive dApp experience while controlling cost and complexity.
