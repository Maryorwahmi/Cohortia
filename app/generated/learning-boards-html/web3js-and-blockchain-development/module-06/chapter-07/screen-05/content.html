Subscribe and attach handlers
The data callback receives the event object; update state with values from returnValues.

const subscription = simpleStorageContract.events.DataChanged()
  .on('data', event => {
    console.log('DataChanged', event);
    setStoredData(event.returnValues.newData);
  })
  .on('error', error => {
    console.error('Event error', error);
  });
Example
A DataChanged event emitted by any transaction will be delivered and can update the primary dApp's storedData immediately.
Pro tip
Make handlers idempotent and guard against undefined returnValues before updating state to avoid errors on malformed events.
Supporting explanation
  • event.returnValues maps parameter names to values emitted by emit.
  • .on('data') receives events from current and past blocks depending on subscription options.
  • .on('error') captures transport or decoding errors and should update user-facing diagnostics.
Key Takeaway

Use the subscription object to manage lifetime and ensure your UI only updates when returnValues are validated.
