Learning Objectives — Practical View
Concrete mappings so you know what code to write and how to test it.
Test plan
Deploy DataChanged event, run dApp, send setData from another wallet, confirm real-time UI update.
Subscribe
Call myContract.events.EventName().on('data', handler). Keep a reference to the returned subscription so you can unsubscribe later.
Update state
In the data handler use setStoredData(event.returnValues.newData) or merge values into arrays when building lists.
Process returnValues
Read fields by name; these names come from the Solidity emit statement. Validate types if needed before updating UI.
Cleanup
Return a cleanup function in useEffect and call subscription.unsubscribe() to remove the listener when dependencies change or the component unmounts.
