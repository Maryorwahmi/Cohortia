useSimpleStorage: add subscription
useEffect(() => {
  if (simpleStorageContract) {
    const subscription = simpleStorageContract.events.DataChanged()
      .on('data', event => {
        setStoredData(event.returnValues.newData);
      })
      .on('error', error => {
        setError('Error listening to contract events.');
      });

    return () => {
      if (subscription && subscription.unsubscribe) {
        subscription.unsubscribe();
      }
    };
  }
}, [simpleStorageContract]);
Notes: place this inside the same hook that manages storedData so any consumer benefits automatically.
Testing tip
Open a second browser and a different wallet. Trigger setData from the other wallet and verify the primary UI updates without refresh. This proves cross-client event delivery.
Common mistake
Forgetting to update the hook's dependencies or leaving unstable callbacks in the array leads to repeated subscriptions. Stabilize functions with useCallback.
