Module 6 › Chapter 6.3 › Common Pitfalls
Pitfall: Wei treated as number
Fix: use web3.utils.fromWei or big-number libraries for math to avoid precision loss.
Pitfall: no loading state
Fix: initialize to null and show "Fetching balance..." to avoid flicker and errors.
Pitfall: leaking intervals
Fix: clearInterval in useEffect cleanup and avoid creating multiple intervals when dependencies change.
Pitfall: updating on unconfirmed tx
Fix: wait for confirmed receipts before refreshing balances to avoid confusing the user.
Pitfall: address UX
Fix: truncate for readability but provide a copy option and a clear label so users can verify identity.
Pitfall: polling cost
Fix: balance polling frequency should account for node quotas; prefer confirm-driven fetch where possible.
