// useEffect triggers fetch when web3 or account changes and sets up polling
Centralize polling and fetch logic here so only one timer and one source of truth exist in the app.
Benefits
  • Single source of truth for balance data across components.
  • Avoids duplicate network requests from multiple components.
  • Simplifies testing and maintenance by localizing side effects.
Key Takeaway

Expose a fetch function and balance state from the provider so UI components remain simple and consistent.
