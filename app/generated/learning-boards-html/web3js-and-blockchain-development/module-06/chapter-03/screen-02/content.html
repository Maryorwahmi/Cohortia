01
Retrieve connected address
Read currentAccount from your Web3Provider and display it where users expect. This makes identity explicit and avoids accidental actions from the wrong account.
VERIFIED COMPETENCY MILESTONE
02
Fetch ETH balance in Wei
Use web3.eth.getBalance(account) and remember the returned value is a string representing Wei. Handle as string until conversion.
VERIFIED COMPETENCY MILESTONE
03
Convert Wei to Ether
Use web3.utils.fromWei(weiString, 'ether') to produce a human-friendly value and then format decimals for display.
VERIFIED COMPETENCY MILESTONE
04
Keep balances current
Implement polling or trigger a re-fetch after transactions so the displayed balance matches on-chain state. Always clear intervals in cleanup.
VERIFIED COMPETENCY MILESTONE
