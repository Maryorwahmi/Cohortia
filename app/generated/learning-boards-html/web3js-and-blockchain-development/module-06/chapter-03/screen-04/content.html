Module 6 › Chapter 6.3 › Account Address
Definition
An account address is a 42-character hex string that uniquely identifies a wallet on Ethereum. It is used as the source and destination for transactions.
Formatting patterns
  • Truncate display: keep first 6 and last 4 characters (e.g., 0x1234...abcd).
  • Provide a copy-to-clipboard affordance for the full address.
  • Label clearly as "Connected Wallet" and show chain if relevant.
Key Takeaway

Readable address format plus a copy option balances usability with precision.

Example
Connected Wallet: 0x123456...9abc
Scenario: The user has multiple wallets. Displaying a truncated address with a clear label and a copy action prevents the user from performing transactions from the wrong account. If addresses look similar, provide additional confirmation such as ENS names where available or a balance snapshot next to the address.
Common mistake
Showing the raw 42-char string without copy or truncation overwhelms the UI and increases user error.
Pro tip
Expose a full address view on click or via a copy button so power users can access the exact value when needed.
