Module 6 › Chapter 6.3 › Polling for updates
Safe polling pattern
useEffect(() => {
  let intervalId;
  if (web3 && accounts.length) {
    fetchEthBalance(accounts[0]);
    intervalId = setInterval(() => fetchEthBalance(accounts[0]), 10000);
  }
  return () => clearInterval(intervalId);
}, [web3, accounts, fetchEthBalance]);
Key: clearInterval in cleanup and avoid creating multiple overlapping intervals when inputs change.
Trade-offs and tips
  • Short intervals give fresher data but increase network load and node costs.
  • If using a paid provider, choose an interval that balances responsiveness and request quotas.
  • Throttle or debounce to avoid overlapping requests if a fetch is still running.
Concrete example
Poll every 10 seconds for a general UI and re-fetch immediately after a confirmed transaction that affects the account balance.
