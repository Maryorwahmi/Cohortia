Module 6 › Chapter 6.3 › Fetch ETH balance
Code example (provider)
// inside Web3Provider
const [ethBalance, setEthBalance] = useState(null);

const fetchEthBalance = useCallback(async (account) => {
  if (web3 && account) {
    try {
      const balanceWei = await web3.eth.getBalance(account);
      const balanceEth = web3.utils.fromWei(balanceWei, 'ether');
      setEthBalance(balanceEth);
    } catch (error) {
      console.error('Error fetching ETH balance:', error);
      setEthBalance(null);
    }
  }
}, [web3]);

useEffect(() => {
  if (web3 && accounts.length) fetchEthBalance(accounts[0]);
}, [web3, accounts, fetchEthBalance]);
Explanation
  • getBalance returns a Wei string; do not treat it as a number directly.
  • Convert with web3.utils.fromWei before showing or formatting decimals.
  • Wrap calls in try-catch and handle loading with initial null state.
  • Expose fetchEthBalance so other components or actions can trigger updates.
Concrete example
If getBalance returns "1000000000000000000", converting with fromWei yields "1" which you then render as "1.0000 ETH" after formatting.
Key Takeaway

Always fetch in async effects, handle errors and loading, and convert Wei to Ether before display.
