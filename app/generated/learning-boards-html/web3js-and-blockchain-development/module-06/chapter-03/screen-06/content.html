Module 6 › Chapter 6.3 › Wei → Ether
Conversion example
const balanceWei = await web3.eth.getBalance(account);
const balanceEthString = web3.utils.fromWei(balanceWei, 'ether');
// Format to 4 decimals for display
const display = parseFloat(balanceEthString).toFixed(4) + ' ETH';
Note: fromWei returns a string. Use parseFloat or a safe numeric formatter for display, but use big-number libraries for precise arithmetic.
Guidance and edge cases
  • Very small Ether values may round to zero; consider a "< 0.0001 ETH" display.
  • Do not perform arithmetic on raw Wei strings with Number; convert to BigNumber first or use fromWei.
  • Keep the ETH label visible to prevent confusion with token balances or fiat values.
Concrete example
If getBalance returns "1000000000000000", fromWei yields "0.001" and showing "0.0010 ETH" communicates a clear, rounded value.
Key Takeaway

Always convert Wei using web3.utils.fromWei, then format for readability; avoid native number math on Wei strings.
