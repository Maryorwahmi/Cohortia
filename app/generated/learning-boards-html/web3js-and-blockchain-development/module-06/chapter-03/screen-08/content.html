Module 6 › Chapter 6.3 › Post-transaction update
Implementation sketch
// after sending a tx
const receipt = await web3.eth.sendTransaction(txParams);
if (receipt && receipt.status) {
  // Transaction confirmed — re-fetch balance
  fetchEthBalance(currentAccount);
}
Use the transaction receipt status or a confirmation event to determine when to re-fetch. This gives instant feedback for your user's action.
Why this helps
  • Reduces unnecessary node requests compared to aggressive polling.
  • Provides immediate, relevant feedback after user actions initiated in your dApp.
  • Combine with light polling to catch external transfers.
Common Mistake

Updating the UI on an unconfirmed transaction can mislead users. Wait for confirmed receipts for balance updates.
