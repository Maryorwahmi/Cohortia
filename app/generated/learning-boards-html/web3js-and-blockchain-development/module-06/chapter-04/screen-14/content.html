Module 6 › Chapter 6.4 › Key Concepts
ABI (Interface)
JSON that describes functions and events, required for encoding and decoding calls.
Contract Address
The deployed contract's unique network location; store per-network in env variables.
web3.eth.Contract
A local object created with ABI and address that exposes contract methods to call from JS.
view & pure
Read-only functions that do not consume gas and can be executed with .call().
.call()
Execute view/pure functions locally via a node and return a Promise with the result.
useEffect
React hook to fetch contract data on mount and when web3 or contract dependencies change.
Summary
Combine ABI, address, and web3.eth.Contract with .call() inside useEffect to read and render contract state reliably.
