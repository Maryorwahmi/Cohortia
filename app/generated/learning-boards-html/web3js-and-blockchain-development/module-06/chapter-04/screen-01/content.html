Interacting with Smart Contract Data
Read-only interactions with deployed contracts using the ABI and address. Learn the patterns to fetch values safely and display them in React.
In this lesson
Create a contract instance, call view/pure functions, and wire results into React state.
Key pattern
ABI + address → web3.eth.Contract → .call() inside useEffect
Why it matters
Read-only calls are free and let your UI reflect on-chain state instantly without transactions.
Explore Key Topics
Instantiating Contracts
Supply ABI and address to create a web3 contract object you can call.
Calling .call()
Execute view and pure functions locally and receive return values via Promises.
React Integration
Use useEffect and state hooks to fetch and show contract data reliably.
Visual Concept
ABI + Address form a contract instance; .call() reads values; useEffect keeps UI updated.
Key Takeaway

Read operations do not cost gas and should be fetched with .call() after the contract instance exists.

Common Mistake

Attempting method calls before web3 or the contract instance is initialized causes TypeError: methods is undefined.

Ready to start?
We'll begin by creating a contract instance and examining a SimpleStorage example that returns a string and a pure number.
