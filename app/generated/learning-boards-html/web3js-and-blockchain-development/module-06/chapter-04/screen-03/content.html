Module 6 › Chapter 6.4 › Practice Overview
Hands-on Practice
Step-by-step tasks to validate the learning objectives with the SimpleStorage example.
1. Add ABI & Address
Place compiled SimpleStorage.json in src/contracts and set VITE_SIMPLE_STORAGE_CONTRACT_ADDRESS in .env.
2. Create useSimpleStorage Hook
Instantiate the contract, fetch getData and getNumber with .call(), manage loading and errors, and export a refetch function.
3. Render in App.jsx
Consume the hook, display Stored Data and Contract Number, and show loading states and errors.
4. Test & Debug
Verify behavior when web3 is missing, when address is wrong, and when network changes, adding guards and try/catch handlers.
