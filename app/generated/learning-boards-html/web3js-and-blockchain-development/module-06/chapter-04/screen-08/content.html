Module 6 › Chapter 6.4 › useSimpleStorage Hook
Hook responsibilities
  • Create and store the contract instance when web3 is ready.
  • Expose storedData and contractNumber as stateful values.
  • Provide isLoading and error for UI feedback.
  • Offer fetchContractData as a refetch mechanism.
Example code excerpt
useEffect(() => {
  if (web3 && contractAddress) {
    try {
      const instance = new web3.eth.Contract(SimpleStorageABI, contractAddress);
      setSimpleStorageContract(instance);
    } catch (err) {
      setError('Failed to load contract.');
    }
  }
}, [web3, chainId]);

const fetchContractData = useCallback(async () => {
  if (!simpleStorageContract) return;
  setIsLoadingContractData(true);
  try {
    const data = await simpleStorageContract.methods.getData().call();
    const number = await simpleStorageContract.methods.getNumber().call();
    setStoredData(data);
    setContractNumber(number);
  } catch (err) {
    setError('Failed to fetch data.');
  } finally {
    setIsLoadingContractData(false);
  }
}, [simpleStorageContract]);
Guidance
Expose a fetch function so consumers can refresh on user action or on network/account change. Keep loading and error state to guide UI decisions.
Testing idea
Mock web3 and the contract instance to assert that fetchContractData updates state correctly and handles rejection paths.
Key Takeaway

A hook centralizes contract logic, making components simpler and network behavior testable and consistent.
