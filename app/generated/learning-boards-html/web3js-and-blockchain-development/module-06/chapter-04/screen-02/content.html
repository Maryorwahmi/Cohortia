Learning Objectives
Skills to verify: instantiate contract, call read-only functions, fetch in useEffect, display state.
Bloom: Learn → Understand → Apply → Master
01
Instantiate a Contract
Create web3.eth.Contract with ABI and deployed address to get a usable contract object.
Mnemonic: Blueprint (ABI) + Location (address)

Call view & pure Functions
Use .call() to execute read-only functions that do not use gas or change state.
Mnemonic: Read-only = Free read
VERIFIED COMPETENCY MILESTONE

Fetch & Update in React
Use useEffect to fetch on mount and when web3 or contract changes, updating component state.
Mnemonic: Effect watches web3
VERIFIED COMPETENCY MILESTONE
04
Display & Format State
Render stored values in JSX, truncate addresses, and format big numbers for readability.
Mnemonic: Make chain data human-friendly
