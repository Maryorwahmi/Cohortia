Module 6 › Chapter 6.4 › Activity: SimpleStorage
Lab steps
  1. Add src/contracts/SimpleStorage.json and set the env address variable.
  2. Create useSimpleStorage.js that instantiates the contract and exports storedData, contractNumber, isLoadingContractData, error, and fetchContractData.
  3. Use useEffect to instantiate and to call fetchContractData when the contract instance becomes available.
  4. Import the hook into App.jsx and render the values with loading/error text and a manual refresh option.
  5. Test error paths by removing the address or disconnecting the provider and confirm user-facing messages.
Expected result
You should see Stored Data and Contract Number displayed, a loading state while fetching, and clear errors when the call fails.
Reflection

Which guard or error message saved you time during debugging? Consider adding that as a reusable utility in your project.
