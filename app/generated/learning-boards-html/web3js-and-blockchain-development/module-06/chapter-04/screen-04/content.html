Module 6 › Chapter 6.4 › Creating a Contract
Core definition
A contract instance is a web3 object created with an ABI and deployed address; it exposes methods that map to the contract's public functions and events.
Code example
// Import ABI (JSON) and read address from env
import SimpleStorageABI from '../contracts/SimpleStorage.json';
const address = import.meta.env.VITE_SIMPLE_STORAGE_CONTRACT_ADDRESS;

// Create contract instance (guard web3 existence)
if (web3 && address) {
  try {
    const simpleStorage = new web3.eth.Contract(SimpleStorageABI, address);
    // use simpleStorage.methods.someFunction()...
  } catch (err) {
    console.error('Failed to create contract instance:', err);
  }
}
Why it matters
Without the ABI you can't call functions; without the address the instance cannot target the deployed contract.
Misconception
The contract object is not on-chain; it's a local API wrapper that encodes calls and sends them to your provider.
Practical checklist
  • Keep ABI in src/contracts and load via import to avoid string errors.
  • Store address in an env variable so it can change per network.
  • Guard instantiation with if (web3 && address) and try/catch to surface ABI/address errors.
  • Log the created instance to confirm methods exist before calling.
Key Takeaway

Instantiate only after web3 is ready and address is present. Treat the ABI as the contract's API spec.
