ABI (Application Binary Interface)
A JSON array describing public functions, their inputs, and outputs so web3 can encode and decode calls.
Example snippet
[
  {
    "inputs": [],
    "name": "getData",
    "outputs": [{ "type": "string" }],
    "stateMutability": "view",
    "type": "function"
  },
  {
    "name": "getNumber",
    "outputs": [{ "type": "uint256" }],
    "stateMutability": "pure",
    "type": "function"
  }
]
Tip
Keep ABI files in src/contracts and import them to avoid manual JSON parsing errors.
Contract Address
A hexadecimal identifier where the contract is deployed on a particular network. Store it in an env var per network.
Env example
VITE_SIMPLE_STORAGE_CONTRACT_ADDRESS=0xYourDeployedContractAddressHere
Common mistake
Using an address from a different network or forgetting to replace a placeholder address causes call failures.
