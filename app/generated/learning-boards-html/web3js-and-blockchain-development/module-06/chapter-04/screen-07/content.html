Module 6 › Chapter 6.4 › useEffect Integration
Common pattern
Run an async fetch in useEffect, guard web3 and contract, set loading, and update state on success or set error on failure.
useEffect(() => {
  const fetchContractName = async () => {
    if (web3 && contractInstance) {
      try {
        const name = await contractInstance.methods.getName().call();
        setContractName(name);
      } catch (error) {
        console.error('Error fetching contract name:', error);
      }
    }
  };
  fetchContractName();
}, [web3, contractInstance]);
Misconception
Don't return an async function directly from useEffect; define and invoke it inside the effect.
Dependency choices
Include web3, contractInstance, currentAccount, or chainId as dependencies so data refreshes when the environment changes.
Pro tip
Use useCallback for fetch functions if you export them from a hook to avoid unnecessary effect reruns.
