Module 6 › Chapter 6.4 › Re-fetch Strategies
When to fetch
On mount, when web3/provider or contract instance changes, when account or chainId changes, or on explicit user request.
Memoize
Wrap fetch functions in useCallback so they only change when needed.
Expose refetch
Return a fetch function from your hook so the UI triggers refresh on actions like retry buttons.
Throttle & Poll
If polling, choose a sensible interval and show a loading indicator; avoid sub-second polling unless necessary.
Key Takeaway

Balance freshness with cost: prefer event subscriptions or on-demand refetches over constant polling when possible.
