Module 6 › Chapter 6.4 › fetchContractData Walkthrough
fetchContractData structure
Guard existence → set loading → try to call methods → update state → handle error → finalize loading.
const fetchContractData = async () => {
  if (!simpleStorageContract) return;
  setIsLoadingContractData(true);
  try {
    const data = await simpleStorageContract.methods.getData().call();
    setStoredData(data);
    const number = await simpleStorageContract.methods.getNumber().call();
    setContractNumber(number);
  } catch (err) {
    setError('Failed to fetch data from SimpleStorage contract.');
  } finally {
    setIsLoadingContractData(false);
  }
};
Success path
Update state quickly and clear loading to reflect fresh on-chain data.
Failure path
Surface an error message and keep the UI stable; allow a retry action.
UI mapping
Use isLoading to show a spinner and error to show a friendly message; display storedData and contractNumber when available.
Example UI

Stored Data: {storedData || 'N/A'} — Contract Number: {contractNumber}
