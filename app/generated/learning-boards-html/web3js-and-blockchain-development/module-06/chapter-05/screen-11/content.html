Safety
Network mismatch
Validate chainId with your Web3Provider and prevent users from sending transactions to a contract that isn't deployed on their current network.
If chainId !== expectedChainId, pause send and instruct the user to switch networks.
Check ethBalance to ensure the user can afford gas + value prior to sending.
Concrete UI guidance
Show a clear warning like 'Connected to wrong network — switch to Sepolia to continue' and prevent the send button from triggering until the chain matches.
Common misconception

Assuming MetaMask will auto-switch without user action can lead to silent failures or confusing prompts.

Key Takeaway

Validate chainId and balance before sending to avoid failed transactions and improve user trust.
