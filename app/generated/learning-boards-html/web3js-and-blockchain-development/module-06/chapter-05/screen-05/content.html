Initiating send()
Use the from option and convert Ether values to Wei. Handle errors with try/catch and update UI state flags.
Bulleted checklist
  • Ensure currentAccount is available.
  • For payable functions, call web3.utils.toWei(amount, 'ether').
  • Consider gasLimit only when automatic estimation fails.
Common mistake
Passing Ether as a plain string into value without toWei causes wrong unit and often failure.
Example code
const amountInWei = web3.utils.toWei('0.1', 'ether');
try {
  await simpleStorageContract.methods.setData(newData)
    .send({ from: currentAccount, value: amountInWei })
    .on('transactionHash', hash => console.log('hash', hash))
    .on('receipt', receipt => console.log('receipt', receipt))
    .on('error', err => console.error('error', err));
} catch (err) {
  console.error('send failed', err);
}
Example explained
We first convert 0.1 Ether to Wei, call setData and chain event listeners to react to lifecycle events. The try/catch catches rejections before or after the wallet prompt.
