Comparison
Payable vs Nonpayable
Payable: accepts Ether. Include value: web3.utils.toWei(...) when you want to send funds.
Nonpayable: does not accept Ether. Do not include a value or the call will revert.
UI guidance: show amount input only for payable actions and validate amount format.
Concrete scenario
If your contract has deposit() payable and setData(string) nonpayable, a deposit should include value in Wei; setData should only send a string. Sending value to setData will likely fail and waste gas in a failed transaction.
Misconception
Some developers assume value is in Ether. Always convert with toWei to avoid sending 0.1 wei instead of 0.1 Ether.
Key Takeaway

Match function mutability to the presence of value; always convert human values to Wei.
