Common Mistake
Gas estimation
Use estimateGas to measure expected consumption and add a margin instead of guessing a huge gas limit.
Use: await contract.methods.foo().estimateGas({ from, value })
Then: .send({ from, gas: estimated + buffer })
Scenario
A complex loop in a contract might require more gas than MetaMask estimated. Use a local test run to measure gas for typical inputs and set a reasonable gasLimit based on that.
Pitfall

Increasing gasLimit without understanding contract logic can waste funds if transactions fail for reasons other than gas.

Key Takeaway

Estimate gas programmatically and add a margin; test on a testnet to choose safe limits.
