Definition
TransactionReceipt
Key receipt fields let you confirm finality and inspect execution details.
blockNumber: which block included the transaction.
gasUsed: amount of gas consumed.
status: boolean indicating on-chain success or revert.
logs: event emissions you can parse to update app state.
Concrete example
After receipt arrives, check receipt.status. If true, call fetchContractData to refresh values. If false, show an error indicating a revert and suggest checking input values or gas settings.
Common pitfall

Treating a mined transaction as success without checking receipt.status can hide on-chain reverts.

Key Takeaway

Use receipt.status and logs to confirm success and update your dApp state reliably.
