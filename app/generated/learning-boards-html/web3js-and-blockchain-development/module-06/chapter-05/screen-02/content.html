Learning Objectives
Learn the steps to send and monitor write operations and handle errors safely.
01
Initiate Transactions
Use contract.methods.func(...).send({ from, value }) to start a state-changing call. This matters because sends require signing and gas and will change on-chain state when mined.
VERIFIED COMPETENCY MILESTONE
02
Sign with MetaMask
Let the wallet prompt users for confirmation. The wallet signs and broadcasts; your dApp should not ask for private keys directly.
VERIFIED COMPETENCY MILESTONE
03
Monitor Lifecycle
Use transactionHash, receipt, and error events to update UI states: pending, confirmed, and failed. Display the hash so users can verify on a block explorer.
VERIFIED COMPETENCY MILESTONE
04
Handle Errors & Safety
Anticipate reverts, out-of-gas, chain mismatches, and user rejection. Validate inputs, check chainId, and avoid asking for private keys.
VERIFIED COMPETENCY MILESTONE
