Module 5 › Chapter 5.2 › Hands-on: getCount & getBalance
Starter code (excerpt)
try {
  const currentCount = await counterContract.methods.getCount().call();
  console.log('Current count:', parseInt(currentCount));
} catch (error) {
  console.error('Error calling getCount:', error.message);
}

const accounts = await web3.eth.getAccounts();
const balanceWei = await web3.eth.getBalance(accounts[0]);
console.log('Balance (ETH):', web3.utils.fromWei(balanceWei,'ether'));
This demonstrates mixing contract call() with direct web3 methods for node-level data like balances.
Execution notes
  • Start Ganache and ensure CONTRACT_ADDRESS is correct.
  • Use async/await top-level or an init function to run the script.
  • Expect immediate console output; there is no gas cost for call().
Key Takeaway

Combining contract call() and web3.eth methods provides a complete read-only snapshot for UI rendering.
