Module 5 › Chapter 5.2 › Common mistakes
Frequent errors
  • Using send() for a view — wastes gas and may revert
  • Omitting await — returns a Promise instead of the value
  • Mishandling BigNumber — precision loss in arithmetic
Resilience tips
  • Wrap call() in try/catch and surface clear errors
  • Use caching or polling cadence to avoid excessive RPC calls
  • Test on both local and public nodes to detect latency and rate limits
Mistake alert

If you see a Promise object in your console instead of a value, you likely forgot to await a call(). Fix by adding await inside an async function and adding try/catch for errors.
