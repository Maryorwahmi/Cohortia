Module 5 › Chapter 5.2 › Learning Objectives

Skills to practice

Error handling, BigNumber conversion, and deciding between call and send for each contract function.

Error handling

Use try/catch around await calls and provide clear fallback messages for RPC latency or node errors.

Number safety

Convert values with parseInt only when safe; otherwise use a robust BigNumber library for math.

Method selection

Reserve send for state changes and call for all view/pure reads; mixing them will waste gas or cause reverts.

Verified micro-skills

Milestone

You can run a script that logs getCount and the first account balance from Ganache with robust error handling.

Mnemonic

Think: Read fast, Convert carefully, Catch errors.
