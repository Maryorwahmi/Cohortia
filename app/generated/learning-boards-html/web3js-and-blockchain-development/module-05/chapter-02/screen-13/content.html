Task

Call getUserData(address) and log name and age; convert age safely.

async function fetchUserData(userAddress) {
  try {
    const userData = await myContract.methods.getUserData(userAddress).call();
    console.log('User Name:', userData.name);
    console.log('User Age:', parseInt(userData.age));
  } catch (error) {
    console.error('Failed to fetch user data:', error.message);
  }
}
Explanation

Because getUserData is view, we use call(). Solidity numeric outputs arrive as strings; convert carefully before arithmetic.
