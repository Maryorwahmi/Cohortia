Awaiting a call with try/catch

async function readValue(contract) {
  try {
    const raw = await contract.methods.retrieve().call();
    console.log('raw:', raw);
    const value = parseInt(raw);
    return value;
  } catch (err) {
    console.error('call failed:', err.message);
    return null;
  }
}
Note: parseInt is safe only when the number is within JavaScript's safe integer range. Otherwise use a BigNumber library.
Options

You can pass an optional call context like .call({ from: someAddress }) to simulate the call using that account's context on the node.

Example
const result = await contract.methods.getCount().call({ from: accounts[0] });
Pro tip

Always handle unexpected RPC errors and display a loading state while awaiting call() to avoid confusing the user.
