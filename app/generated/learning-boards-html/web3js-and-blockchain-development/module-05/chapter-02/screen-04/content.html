Module 5 › Chapter 5.2 › What makes a function read-only?
Definition

view vs pure

A concise claim: view reads contract state, pure does not even read state; both are safe to call without gas.

Examples
  • view: function retrieve() public view returns (uint256)
  • pure: function add(uint a, uint b) public pure returns (uint)
Common misconception

Calling a view function does not lock or alter blockchain state; it is a private local read on the node and returns the node's current state snapshot.

Analogy

Think of call() as asking a librarian for a copy of a page: you get the information without changing the book. send() is like submitting a new edition for the library — that changes the collection and costs resources.

When to use

Any time you only need to read data for display or decision-making in the frontend.

When not to

If your action must change storage, emit events, or transfer tokens, you must send a transaction.

Key Takeaway

Confirm function visibility and mutability in Solidity: view or pure means it's safe to call() without gas.
