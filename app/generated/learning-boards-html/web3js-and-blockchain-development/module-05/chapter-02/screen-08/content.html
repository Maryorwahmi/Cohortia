Module 5 › Chapter 5.2 › Storage.retrieve() example
Solidity snippet
// Storage contract
function retrieve() public view returns (uint256) {
    return data;
}
This function reads a stored uint256 and returns it — perfect for call().
JS usage
const result = await storageContract.methods.retrieve().call();
console.log('Stored data:', result);
console.log('As number:', parseInt(result));
If the stored value may be large, replace parseInt with a BigNumber conversion before arithmetic.
Key Takeaway

A simple retrieve() is ideal for call(); always confirm expected value ranges before converting to native Numbers.
