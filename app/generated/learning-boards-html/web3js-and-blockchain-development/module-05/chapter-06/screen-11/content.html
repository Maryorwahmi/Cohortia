Module 6 › Chapter 5.6 › Security
Input Validation

Validate addresses, numeric ranges, and required fields before sending transactions to avoid reverts and wasted gas.

Sanitization

Escape or sanitize any user-generated on-chain content before rendering to prevent XSS.

Private Keys

Never ask for or store private keys in the frontend; use injected wallets like MetaMask for signing.

Network & Gas

Verify chainId and estimate gas with a buffer. Warn users if they're on the wrong network or gas looks abnormal.

Key Takeaway

Combine frontend validation, sanitization, and network checks to protect users and improve UX. Contracts still validate, but the frontend prevents many avoidable errors.
