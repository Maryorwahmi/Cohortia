Module 6 › Chapter 5.6 › Mistakes & Practices
Mistake: Set state in callbacks
Aggregate then set once to avoid multiple re-renders and race conditions.
Mistake: Missing deps
Include web3, contract, and accounts in effects to avoid stale data.
Mistake: No rollback
If you optimistically change UI, always save prior state so you can revert on a failed tx.
Practice: Centralize error parsing
A single utility that maps raw errors to user-friendly messages keeps components clean.
Practice: Gas buffers
Estimate gas and add a buffer to reduce out-of-gas failures caused by dynamic execution costs.
Practice: Sanitize data
Treat on-chain strings as untrusted and escape before rendering.
