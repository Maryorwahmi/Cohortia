When to batch

Batch reads that are required together for a single render to reduce latency and re-renders.

Pattern
  1. Create new web3.BatchRequest()
  2. Add .call.request() items with callbacks
  3. await batch.execute(); then update state
Batch example
const batch = new web3.BatchRequest();
let results = {};

batch.add(myContract.methods.getCount().call.request({}, (err, data) => {
  if (!err) results.count = parseInt(data);
  else console.error('Error fetching count:', err);
}));

batch.add(myContract.methods.getOwner().call.request({}, (err, data) => {
  if (!err) results.owner = data;
  else console.error('Error fetching owner:', err);
}));

await batch.execute();
setCount(results.count);
setOwner(results.owner);
Note: add error handling per-callback and update state only after execute to keep UI consistent.
