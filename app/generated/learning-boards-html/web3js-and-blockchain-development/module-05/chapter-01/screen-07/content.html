Module 5 › Chapter 5.1 › Configuring a Provider
Provider Types
  • Injected (Web3.givenProvider): user wallet integration in the browser.
  • HttpProvider: direct RPC calls to Ganache or hosted endpoints.
  • WebsocketProvider: needed for subscriptions and real-time events.
Example Initialization
// For a local node (Ganache)
const provider = new Web3.providers.HttpProvider("http://127.0.0.1:8545");
const web3 = new Web3(provider);

// Or: prefer an injected provider with fallback
const web3 = new Web3(Web3.givenProvider || provider);
Diagnostics
Immediately call web3.eth.net.getId() and compare to your expected network ID. If they differ, do not send transactions until resolved.
Key Takeaway

Initialize a provider appropriate to your environment, then verify network identity before proceeding to create contract instances or send transactions.
