Module 5 › Chapter 5.1 › Events & Subscriptions
Event Basics
Events are logged by transactions and decoded via ABI. Indexed fields appear in topics and are efficient filters.
Example Event
DataStored(uint256 newData, address indexed sender) — newData is in data, sender is indexed for quick filtering.
Provider Choice
WebSocket providers allow storageContract.events.EventName() subscriptions. HTTP providers allow getPastEvents queries but not push-based subscriptions.
Practical Tip

Filter by indexed parameters and limit block ranges when querying historical logs to avoid heavy responses and timeouts.
