Module 5 › Chapter 5.1 › Call vs Transaction
Read-only Call
Use for view or pure functions. Quick, no gas, returns decoded result.
// Example: retrieve
const value = await storageContract.methods.retrieve().call();
console.log('Stored value:', value);
State-changing Transaction
Use .send() with gas and a from address. Requires signing and consumes gas.
// Example: store
await storageContract.methods.store(100).send({ from: userAddress });
// Wait for receipt to confirm state change
When to Call
For diagnostics and UI reads without side effects.
When to Send
When you intend to change state and accept gas costs.
Tip
Always test with call before send to validate ABI and address.
