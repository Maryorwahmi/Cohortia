Structure
Function & Event Entries

Key fields you will see in most ABI entries:

  • name: the function or event name.
  • inputs: ordered array of parameter objects with type and name.
  • outputs: ordered array for return types.
  • stateMutability: view, pure, nonpayable, payable.
  • indexed (events): marks fields placed in topics for fast searching.
Example
{
  "type": "function",
  "name": "store",
  "inputs": [{"name":"_data","type":"uint256"}],
  "stateMutability":"nonpayable",
  "outputs":[]
}
Practical Notes
  • Parameter order matters; encoding is positional.
  • Indexed event parameters allow efficient log filtering.
  • Mutability tells you whether a call costs gas or can be read-only.
Key Takeaway

Read ABI entries to confirm function names, parameter order, and mutability before invoking calls to avoid encoding and runtime errors.
