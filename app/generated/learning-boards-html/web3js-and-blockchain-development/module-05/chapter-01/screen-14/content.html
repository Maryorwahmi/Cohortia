Module 5 › Chapter 5.1 › Key Concepts
ABI
JSON describing functions and events for encoding and decoding.
Contract Address
Network-specific 0x... address that locates the deployed contract.
Provider
Defines the node and network context used for calls and transactions.
Summary

Keep ABI, address, and provider in sync; validate with read-only calls; and guard against network or account changes to avoid accidental transactions.
