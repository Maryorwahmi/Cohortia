Connecting to a Smart Contract: ABI & Address
Bridge your JavaScript app to a deployed contract so you can call functions, send transactions, and listen for events.
ABI
The JSON interface that describes functions, events, and parameter types so Web3.js can encode and decode calls.
Contract Address
A 42-character hexadecimal address that locates the deployed contract on a specific network.
Provider
Connects Web3.js to an Ethereum node via HTTP, WebSocket, or injected providers like MetaMask.
Contract Instance
Created with web3.eth.Contract(ABI, address), this object exposes the contract's methods and events.

Key Takeaway
The ABI translates calls, the address locates the contract, and the provider sends requests — together they create your contract gateway.
