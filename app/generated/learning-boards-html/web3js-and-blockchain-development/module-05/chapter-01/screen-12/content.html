Starter Script
import Web3 from 'web3';
const COUNTER_ABI = /* paste ABI JSON array here */;
const CONTRACT_ADDRESS = 'YOUR_DEPLOYED_CONTRACT_ADDRESS';

async function initContract(){
  const provider = new Web3.providers.HttpProvider('http://127.0.0.1:8545');
  const web3 = new Web3(provider);

  const networkId = await web3.eth.net.getId();
  console.log('Connected network ID:', networkId);

  const counterContract = new web3.eth.Contract(COUNTER_ABI, CONTRACT_ADDRESS);
  console.log('Contract Address:', counterContract.options.address);
  console.log('ABI (first 2):', counterContract.options.jsonInterface.slice(0,2));

  // Optional check:
  // const c = await counterContract.methods.getCount().call();
  // console.log('Initial count:', c);
}

initContract();
Expected Output
Network ID log, contract address printed, and the first ABI entries. If any of these are missing, re-check provider URL and ABI insertion.
Key Takeaway

Use this starter script as a diagnostic template for any network: change only the provider URL and contract address, then validate with a view call.
