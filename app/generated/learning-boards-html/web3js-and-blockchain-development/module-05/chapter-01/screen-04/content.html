Module 5 › Chapter 5.1 › What is an ABI?
Definition
Application Binary Interface (ABI)
The ABI is a JSON array generated by the compiler that describes the contract's external interface. Web3 uses it to encode method selectors and parameters.
Why it matters
  • Enables Web3.js to construct the correct calldata for function calls.
  • Allows decoding of returned values into JavaScript types.
  • Describes events so you can subscribe and parse logs.
Concrete Example
[
  {
    "inputs":[],
    "name":"retrieve",
    "outputs":[{"internalType":"uint256","name":"","type":"uint256"}],
    "stateMutability":"view",
    "type":"function"
  }
]
This snippet shows a view function named retrieve that returns a uint256.
Common Misconception
Some developers assume ABI changes are backward compatible. In reality, changing function signatures or types changes the encoded selector and can break existing callers. Always update the ABI after redeploying.
Key Takeaway

Treat the ABI as the contract's calling contract: keep it in sync with deployed bytecode and use it to validate calls before sending transactions.
