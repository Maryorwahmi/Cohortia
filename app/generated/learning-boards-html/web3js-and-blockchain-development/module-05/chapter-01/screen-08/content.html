Instantiation
Create the JavaScript contract wrapper
import Web3 from 'web3';
import storageAbi from './storageAbi.json';

const provider = new Web3.providers.HttpProvider('http://127.0.0.1:8545');
const web3 = new Web3(provider);
const contractAddress = '0xYourDeployedContractAddress';
const storageContract = new web3.eth.Contract(storageAbi, contractAddress);

console.log('Contract Address:', storageContract.options.address);
console.log('ABI entries:', storageContract.options.jsonInterface.slice(0,2));
Verify with a View Call
Call retrieve().call() to fetch a value without consuming gas and confirm correct decoding.
Key Takeaway

Instantiating the Contract object binds ABI and address into methods and events; always verify with a read-only call before sending transactions.
