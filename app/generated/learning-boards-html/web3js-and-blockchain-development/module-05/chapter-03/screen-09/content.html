Starter code
import Web3 from 'web3';
import storageAbi from './storageAbi.json';
const provider = new Web3.providers.HttpProvider('http://localhost:8545');
const web3 = new Web3(provider);
const storageContract = new web3.eth.Contract(storageAbi, CONTRACT_ADDRESS);

async function sendStore() {
  const accounts = await web3.eth.getAccounts();
  const sender = accounts[0];
  const valueToStore = 42;
  const gasEstimate = await storageContract.methods.store(valueToStore).estimateGas({ from: sender });
  const receipt = await storageContract.methods.store(valueToStore).send({ from: sender, gas: gasEstimate + 10000 });
  console.log('Transaction Hash:', receipt.transactionHash);
  console.log('Gas Used:', receipt.gasUsed);
  const updated = await storageContract.methods.retrieve().call();
  console.log('Updated stored data:', parseInt(updated));
}
Explanation
  • estimateGas simulates execution to predict gas usage.
  • send returns a receipt after mining; read it to confirm success.
  • Call retrieve after receipt to verify state change.
Key Takeaway

Always verify the new state after the receipt to ensure your business logic executed as intended.
