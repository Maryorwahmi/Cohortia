Module 5 › Chapter 5.3 › Estimate Gas
Pattern
const accounts = await web3.eth.getAccounts();
const sender = accounts[0];
const gasEstimate = await storageContract.methods.store(42).estimateGas({ from: sender });
const receipt = await storageContract.methods.store(42).send({
  from: sender,
  gas: gasEstimate + 10000
});
console.log('Receipt:', receipt);
Always estimate with the same from address you will use to send. Add a buffer like 10,000 or 10-20% depending on function complexity. Log the estimate for debugging and consider surfacing it to advanced users.
Remember: estimateGas simulates execution and can be slightly lower than final gas used if the state changes between estimation and mining.
Common mistake
Omitting the from field in estimateGas can produce incorrect estimates. Always provide the same sender for accurate results.
Pro tip

Log estimates and actual gasUsed to refine your buffer over time for each contract function.
