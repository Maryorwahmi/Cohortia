Module 5 › Chapter 5.3 › Pending Transaction UX
Process
Submitted
Show immediate acknowledgement and spinner. If available, surface transaction hash with copy affordance in your UI.
Pending
Display that the transaction is pending and estimated confirmation time if possible.
Confirmed
When receipt arrives, show block number, gas used, and update application state using emitted events.
Key takeaway

Keep users informed at each stage: submitted, pending, and confirmed. Provide clear guidance on failures.
