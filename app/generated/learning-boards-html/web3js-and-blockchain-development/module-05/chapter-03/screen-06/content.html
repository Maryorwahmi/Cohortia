Module 5 › Chapter 5.3 › Signing: MetaMask vs Node.js
MetaMask (Browser)
  • Wallet prompts user to approve and sign the transaction.
  • Private keys remain local to the extension, improving security.
  • Good UX for direct user-driven transactions.
Misconception: Signing happens automatically — it requires explicit wallet approval.
Node.js (Server)
  • Sign programmatically using web3.eth.accounts.signTransaction and your private key.
  • Useful for automated tasks, but you must secure keys on the server.
  • Test nodes like Ganache may provide unlocked accounts for development.
Tip: Use server signing only with strict key management.
Practical note

Design UI flows so users know when a MetaMask pop-up will appear, and always display the transaction hash and pending status until the receipt confirms the action.
