Module 5 › Chapter 5.3 › Transaction Lifecycle
Process Flow

Create → Sign → Broadcast → Mine → Confirm

1. Create
2. Sign
3. Broadcast
4. Mine
5. Receipt
Creating encodes the function call and sets gas and value. Signing authenticates the sender. Broadcasting delivers the signed transaction to nodes. Mining includes it in a block. The receipt confirms execution and returns gasUsed and events.
Remember: a transaction hash indicates broadcast; only the mined receipt guarantees state change and returned events.
Example
// After send()
receipt.transactionHash
receipt.blockNumber
receipt.gasUsed
receipt.events
Key Takeaway

Wait for the receipt to confirm the on-chain state change, and read events to update your UI.
