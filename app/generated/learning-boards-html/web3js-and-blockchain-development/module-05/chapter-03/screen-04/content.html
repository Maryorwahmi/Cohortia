Module 5 › Chapter 5.3 › What send() Does
Definition

send() creates and submits transactions

send() is required for any function that modifies contract state or sends Ether. It prepares a transaction object containing to, data, from, gas, gasPrice, and value, then signs and broadcasts it.

Transaction snapshot
{ to: contractAddress,
  data: encodedCall,
  from: senderAccount,
  gas: gasLimit,
  gasPrice: gasPrice,
  value: weiValue }
Supporting points
  • send() modifies on-chain state and therefore consumes gas measured in units paid in Ether.
  • The transaction must be signed by the sender; in browser flows a wallet handles signing, in Node.js you sign directly.
  • Once mined, a receipt is returned containing transactionHash, blockNumber, gasUsed, and events.
Key takeaway
Use send() when your function changes state; always provide a signed from and sensible gas settings.
