Subscription handlers
Register these handlers on your subscription:
  • • on('data'): receives confirmed events; update UI or trigger tasks here.
  • • on('changed'): handles events removed by chain reorganizations; re-sync state.
  • • on('error'): handle provider or subscription errors and reconnect if needed.
Lifecycle
Create on mount, unsubscribe on unmount to prevent memory leaks in UIs.
Example pattern
storageContract.events.DataStored()
  .on('data', event => { /* parse event.returnValues and update UI */ })
  .on('changed', changed => { /* handle reorg: re-fetch authoritative state */ })
  .on('error', err => { /* reconnect or log error */ });
Remember to prefer a WebSocket provider for low-latency live subscriptions when available.
