Handling Events from Smart Contracts
Learn how events let your frontend and services react to on-chain activity with efficiency and history.
In this lesson

Understand event logs, subscribe to live events with Web3.js, query historical events, and parse indexed parameters for efficient filtering.

Why it matters

Events decouple UI updates from heavy polling. They reduce network traffic, provide near real-time updates, and give a verifiable history of contract activity.

Quick preview

We will add a CounterChanged event to a Counter contract, read historical events with getPastEvents, and listen for real-time events with contract.events.
