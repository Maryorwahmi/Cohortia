Choose provider
WebSocketProvider is preferred for stable, low-latency subscriptions. HttpProvider can work but may rely on long polling.
Handle reorganizations
Listen for on('changed') to detect when an event is removed because of a chain reorg and re-sync state if needed.
Unsubscribe and lifecycle
Detach listeners when components unmount to avoid memory leaks in UIs that mount and unmount frequently.
Use indexed filters
Filters in getPastEvents operate on indexed event parameters; non-indexed fields must be filtered client-side.
Combine history and live
Fetch past events to build initial UI state, then subscribe for live events to keep the view current without polling.
Common mistake

Setting fromBlock too high or omitting it can cause you to miss important historical events.
