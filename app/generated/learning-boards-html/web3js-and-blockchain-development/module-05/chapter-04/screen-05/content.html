Module 5 › Chapter 5.4 › Emitting events
Solidity example
Event declaration and emit inside a function.
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract Storage {
    uint256 public data;
    event DataStored(uint256 newData, address indexed sender);

    function store(uint256 _data) public {
        data = _data;
        emit DataStored(_data, msg.sender);
    }
}
Notes & parsing
  • • The indexed keyword marks parameters stored in topics enabling node-side filtering.
  • • Non-indexed parameters are placed into the event's data blob and must be read from returnValues.
  • • When consumed via Web3.js numeric types may be stringified and require parsing or BigNumber handling.
Misconception
Emitting an event does not change contract storage; it records an off-chain-friendly log entry.
Example takeaway

Use indexed where you expect to filter often, otherwise include data for full context in the event payload.
