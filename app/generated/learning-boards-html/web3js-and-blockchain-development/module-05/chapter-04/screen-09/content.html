Module 5 › Chapter 5.4 › Provider & Reliability
Provider types
WebSocketProvider: persistent and low-latency. HttpProvider: may use polling and introduce latency.
Handle reorgs
on('changed') notifies you if an event is removed. Re-fetch authoritative state when that happens.
Memory management
Unsubscribe listeners on unmount to prevent growing handler counts and memory leaks in long-lived apps.
Example cleanup pattern
Save the subscription and call unsubscribe during teardown. Reconnect logic should back off to avoid tight retry loops on failures.
