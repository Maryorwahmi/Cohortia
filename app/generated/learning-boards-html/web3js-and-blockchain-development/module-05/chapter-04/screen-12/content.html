Module 5 › Chapter 5.4 › Observe event
Terminal steps
  1. Run node connectContract.js to start the script.
  2. Use web3.eth.getAccounts() to choose an account and call increment().
  3. Watch the console for the listener's data message showing newCount and sender.
Check
Confirm the same event appears in the transaction receipt and in getPastEvents results.
Troubleshooting
  • • If no event appears, verify ABI and contract address are current.
  • • If the listener never receives events, prefer a WebSocket provider for subscriptions and check connectivity.
  • • If on('changed') fires, re-fetch state to correct potential inconsistencies caused by a reorg.
