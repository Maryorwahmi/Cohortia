Smart Contract Event
An on-chain log entry emitted with the emit keyword for off-chain consumption.
Indexed Parameter
Marked with indexed to allow efficient node-side filtering via topics.
contract.getPastEvents()
Query historical events across a block range; use filters for indexed fields.
Summary Takeaway

Design events for the queries you need, use getPastEvents to bootstrap state, subscribe for live updates, and include handlers for reorgs and lifecycle cleanup to keep your dApp correct and efficient.
