Module 5 › Chapter 5.4 › getPastEvents
JavaScript example
const past = await storageContract.getPastEvents('DataStored', {
  fromBlock: 0,
  toBlock: 'latest',
  // filter: { sender: "0x..." } // indexes only
});

past.forEach(ev => {
  console.log(ev.blockNumber, ev.returnValues.newData, ev.returnValues.sender);
});
Filter only accepts indexed parameters efficiently. Use fromBlock carefully to avoid missing events.
Practical steps
  • • Choose a fromBlock for the earliest relevant event (0 or deployment block).
  • • Use indexed filters for addresses or IDs whenever possible.
  • • Parse numeric return values; they may be strings in Web3.js.
Pitfall

Filtering by non-indexed fields requires fetching many events and filtering locally — this can be slow.
