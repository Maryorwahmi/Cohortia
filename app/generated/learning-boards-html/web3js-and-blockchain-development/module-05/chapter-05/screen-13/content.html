Hands-on Activity Build the Counter DApp
Step-by-step
1. Scaffold
Create a React project with your preferred tool and install web3.
2. Add ABI
Copy CounterABI.json to src and set CONTRACT_ADDRESS to your deployed contract.
3. Wire CounterApp
Paste the CounterApp component, initialize web3 on mount, and fetch the count.
4. Connect MetaMask
Start Ganache, import a private key to MetaMask, and switch MetaMask to the local RPC.
Run & verify
  1. npm run dev and open the app URL.
  2. Approve account access in MetaMask when prompted.
  3. Observe the initial count and confirm increment transactions in MetaMask.
  4. If something is wrong, check network configuration and the contract address environment variable.
Challenge: Add a Decrement button and implement gas estimation and error handling for it as the next exercise.
