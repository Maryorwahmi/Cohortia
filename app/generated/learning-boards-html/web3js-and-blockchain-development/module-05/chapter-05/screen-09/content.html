Process Flow Sending transactions
incrementCount example
const incrementCount = useCallback(async () => {
  if (contract && accounts.length > 0) {
    try {
      setLoading(true);
      const gasEstimate = await contract.methods.increment().estimateGas({ from: accounts[0] });
      await contract.methods.increment().send({
        from: accounts[0],
        gas: gasEstimate + 10000
      });
      await fetchCount();
    } catch (err) {
      setError(`Error incrementing count: ${err.message}`);
    } finally {
      setLoading(false);
    }
  } else {
    setError('Web3 not initialized or no account connected.');
  }
}, [contract, accounts, fetchCount]);
UX & mistakes
  • Disable action controls while loading to prevent duplicate transactions.
  • Show a friendly confirmation message after the transaction is mined.
  • Handle user rejection of MetaMask prompts clearly rather than treating it as an unknown error.
