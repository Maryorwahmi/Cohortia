Definition Reading contract state
fetchCount example
const fetchCount = useCallback(async () => {
  if (contract) {
    try {
      const currentCount = await contract.methods.getCount().call();
      setCount(parseInt(currentCount));
      setError('');
    } catch (err) {
      setError(`Error fetching count: ${err.message}`);
    }
  }
}, [contract]);
Note: parseInt is used to convert the returned string into a number for display and arithmetic in the UI.
Practical notes
  • Guard calls with if (contract) so the method exists.
  • Use try/catch to surface readable errors to the user.
  • Avoid polling too frequently; refresh after transactions or wallet events.
