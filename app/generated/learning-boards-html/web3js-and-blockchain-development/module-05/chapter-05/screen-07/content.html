Code Walkthrough State Management with Hooks
State variables
const [web3, setWeb3] = useState(null);
const [accounts, setAccounts] = useState([]);
const [contract, setContract] = useState(null);
const [count, setCount] = useState(0);
const [loading, setLoading] = useState(true);
const [error, setError] = useState('');
Use separate state fields so each piece can update independently and trigger minimal re-renders.
Effect to fetch data
useEffect(() => {
  if (contract && accounts.length > 0) {
    fetchCount();
  }
}, [contract, accounts, fetchCount]);
This effect ensures the UI shows the current count whenever the contract or account context becomes available or changes.
