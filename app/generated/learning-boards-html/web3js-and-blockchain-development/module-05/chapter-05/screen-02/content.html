Module 05 › Chapter 5.5 › Learning Objectives
01
Connect to an Ethereum provider
Detect window.ethereum or Web3.givenProvider and request account access so the user can sign transactions.
Mnemonic: Provider → Request → Approve
VERIFIED COMPETENCY MILESTONE
02
Manage Web3 state with Hooks
Use useState and useEffect to hold web3, accounts, the contract, and derived UI state like loading and error.
Mnemonic: Hook into provider lifecycle
VERIFIED COMPETENCY MILESTONE
03
Display contract data
Call view functions like getCount using contract.methods.getCount().call() and show the result in the component.
Mnemonic: Read-only calls are free
VERIFIED COMPETENCY MILESTONE
04
Trigger transactions from UI
Estimate gas, send transactions with contract.methods.send(), and handle confirmations and errors for good UX.
Mnemonic: Estimate → Send → Confirm
