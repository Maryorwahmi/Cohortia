Key Concepts What to remember
window.ethereum
Injected wallet provider used to request accounts and send transactions.
eth_requestAccounts
JSON-RPC call that prompts the user to approve account access for your dApp.
React Hooks
useState/useEffect/useCallback manage lifecycle, state, and stable handlers for web3 interactions.
Summary takeaway

Provider detection, explicit account permission, hook-based state, gas estimation, and wallet event handling are the minimal building blocks for a robust React dApp.
