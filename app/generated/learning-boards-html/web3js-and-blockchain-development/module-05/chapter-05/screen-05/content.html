Definition Detecting the Ethereum provider
Quick code pattern
<!-- detection snippet --> if (window.ethereum) { const web3Instance = new Web3(window.ethereum); // ask the user to connect await window.ethereum.request({ method: 'eth_requestAccounts' }); } else { // fallback or show message }
This pattern ensures the wallet is present and the user explicitly approves account access before you call web3 methods that require accounts.
Tips & caution
  • Prefer window.ethereum and Web3.givenProvider for modern wallets.
  • Support a fallback message instructing users to install MetaMask if missing.
  • Avoid assuming accounts are available until eth_requestAccounts resolves.
Misconception: Detection equals permission. Detection only finds the wallet; you still must request accounts using the RPC method.
