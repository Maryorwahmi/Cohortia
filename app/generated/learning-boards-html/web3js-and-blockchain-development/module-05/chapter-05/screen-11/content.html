Comparison Loading vs Error UX
Loading state
Use a single loading flag for initialization and separate flags for transactions. Show spinners and disable action controls during pending operations to avoid duplicates.
Example: setLoading(true) before estimateGas and send; setLoading(false) in finally to re-enable the UI.
Error handling
  • Show clear, actionable messages rather than raw error objects.
  • If wallet not detected, instruct to install MetaMask.
  • If network mismatch, suggest switching networks or refreshing.
Misconception: Hiding errors improves UX. In reality, actionable errors prevent user confusion and reduce support requests.
