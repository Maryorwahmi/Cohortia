Troubleshooting checklist
Begin with wiring and hardware before changing software logic.
  • Missing resistor or wrong driver: verify component ratings and connections.
  • Floating ground: ensure all grounds are connected to the same reference.
  • Using wrong pin: confirm PWM pins on the board before using analogWrite for fading.
  • Timer conflicts: tone() can use timers that affect PWM on some pins; test separately.
Debug step
Measure average voltage with a multimeter and verify it scales with analogWrite values; that tells you whether PWM and wiring are correct.
Quick fixes
If LED flickers, add averaging or RC filtering. If motor hums, try a different PWM pin or a higher-frequency driver.
Key Takeaway

Start with hardware checks: resistors, grounds, drivers, and correct pins. Many problems disappear before you change code.
