Practice checklist
Follow these checks when building circuits that use PWM outputs.
  • Use a current-limiting resistor with LEDs to avoid overcurrent.
  • Never drive a motor directly from a pin; use a transistor or motor driver and include a flyback diode.
  • Connect all grounds together so sensors, actuators, and the Arduino share a reference.
  • For audible PWM on speakers, be aware that frequency and duty cycle both affect timbre and volume.
Quick safety tips
Verify pin capability and use rated components. If unsure about current draw, measure or use a driver.
Key Takeaway

Safety and proper drivers matter as much as code when controlling power with PWM.
