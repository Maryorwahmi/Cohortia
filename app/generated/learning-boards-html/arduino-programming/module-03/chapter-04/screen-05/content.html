Fading process
Stepwise mapping from analog input to PWM output for smooth LED fades.
1
Read potentiometer
Get the analog value and prepare to scale it.
2
Map to 0–255
Convert ADC range to PWM range so analogWrite receives valid values.
3
Call analogWrite
Apply mapped value to a PWM pin connected to the LED through a resistor.
4
Tune timing
Choose step size and delay to balance responsiveness and smoothness.

Key Takeaway

Map inputs into the PWM range and use safe wiring; fading is a timed sequence of analogWrite values.

Concrete scenario
A wall-mounted lamp uses a potentiometer to set brightness. Map the knob reading to PWM and update the LED in real time, ensuring the transistor or MOSFET used can handle lamp current.
Common mistake
Expecting instant change with large delay values. Large delays make the interface sluggish; small delays give smoother visual transitions.
Pro tip
Use direct mapping for live knob control and step sweeps for demos. Tune step and delay to match your LED and perception.
