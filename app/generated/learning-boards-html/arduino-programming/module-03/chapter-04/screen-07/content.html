Module 4 › Chapter 3.4 › PWM Pins on the Arduino Uno
PWM-capable pins
Pins marked with a tilde: 3, 5, 6, 9, 10, 11.
Hardware PWM
Provides stable frequency and timing for analogWrite.
Marked pins
Look for the tilde near the pin label on the board silkscreen.
Key Takeaway

Use the pins 3, 5, 6, 9, 10, and 11 for reliable PWM via analogWrite on the Uno.

Concrete example
A tutorial referencing pin nine will fade an LED reliably because pin nine is PWM-capable. Using a non-PWM pin would only switch the LED fully on or off.
Common mistake
Assuming analogWrite behaves identically on all digital pins. Make sure the pin is marked for PWM.
