Use analogWrite on PWM pins
Set values from zero to two hundred fifty-five to produce off-to-full average outputs on PWM-capable pins.
Verified Competency Milestone
03
Control LEDs and motors safely
Drive LEDs directly with a resistor; use transistors or drivers for motors to avoid board damage.
Verified Competency Milestone
04
Generate tones with tone()
Play simple frequencies on a buzzer and stop them with noTone; know that this is a square wave output.
Verified Competency Milestone
Mnemonic
Think: Duty cycle = fraction of time on; analogWrite sets that fraction; tone makes a steady square wave for sound.
