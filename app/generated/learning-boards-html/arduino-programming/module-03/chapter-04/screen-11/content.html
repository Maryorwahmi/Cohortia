Module 4 › Chapter 3.4 › Potentiometer to LED: Real-time Control
Activity outline
Read a potentiometer, map the value to the PWM range, write to an LED, and trigger a buzzer when brightness exceeds eighty percent.
// Steps // 1. Read analog input (potentiometer) // 2. map reading to 0-255 // 3. analogWrite to a PWM pin for the LED // 4. if mapped value > 0.8*255 then tone on buzzer pin else noTone
Safety checks
Ensure shared ground, correct resistor for LED, and transistor if device draws more current than a pin can supply.
Common issue
Noisy analog readings can cause flicker. Use small smoothing or averaging to stabilise perceived brightness.
Key Takeaway

This activity demonstrates input mapping, PWM output, and conditional audio feedback — the essential control loop in many projects.

Concrete scenario
A desk lamp with a knob and soft beep when set very bright. The same pattern scales to motor speed control with different hardware.
Pro tip
Use analog smoothing and small step changes for pleasing fades, and consider mapping with an exponential curve for perceptual linearity.
