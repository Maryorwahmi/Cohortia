Assessment tasks
Practice the calculation and explain the physical meaning of the result.
  1. Compute average voltage for value 64 on a five volt board and explain the steps.
  2. List the PWM pins on the Uno and say how they are labeled on the board.
  3. Describe what happens if analogWrite is used on a non-PWM pin to dim an LED.
// Example solution hint // averageVoltage ≈ (value / 255) × 5V // for value 64 → ≈ 64/255 × 5V ≈ 1.25V
Key Takeaway

Being able to compute and explain shows you grasp PWM's effect and when hardware matters more than code.
