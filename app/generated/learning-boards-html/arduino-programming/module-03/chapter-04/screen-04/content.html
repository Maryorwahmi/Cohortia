Module 4 › Chapter 3.4 › What is PWM and Duty Cycle?
Pulse Width Modulation
Time-domain technique that creates an average voltage by turning a pin on and off rapidly.
Core idea
Duty cycle is percent on. Higher duty cycle means higher average voltage. Frequency controls how quickly the cycles repeat.
Example
A fifty percent duty cycle at five volts gives roughly two point five volts average; visible as half brightness on an LED.
Common mistake
Thinking analogWrite outputs a steady voltage. It sets pulse timing instead; the device senses the average.
Key Takeaway

PWM uses time to change effective voltage. Duty cycle is the control knob you use.

Quick reference
Terms: Duty cycle, frequency, average voltage.
