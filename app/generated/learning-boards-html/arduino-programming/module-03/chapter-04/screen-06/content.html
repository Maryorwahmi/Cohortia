Module 4 › Chapter 3.4 › PWM vs True DAC
When PWM is enough
LED dimming, motor speed control, and hobby servos usually work well with PWM because they react to average power.
  • Simple brightness control for LEDs
  • DC motor speed control when using a transistor or driver
  • Positioning hobby servos that accept pulse widths
When you need a DAC
Audio playback, precision analog sensors, or low-ripple control loops require steady voltages a DAC provides.
Example
A music player needs a DAC to avoid the switching noise and harmonic content that PWM introduces.
Common misconception
Believing higher PWM values increase actual pin voltage. They change the on-time only; the instantaneous voltage is still rail when on and zero when off.
Key Takeaway

Choose PWM for actuators; choose a DAC when stable, low-noise analog voltages are required.
