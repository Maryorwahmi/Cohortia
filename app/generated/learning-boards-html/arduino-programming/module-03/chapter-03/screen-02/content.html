Learning Objectives

Progress from concept to practice: learn, understand, apply, and master analog input tasks.

Learn
Understand
Apply
Master
01
Explain ADC operation

Describe 10‑bit resolution and the 0–1023 range and why resolution matters for precision. The ADC is the bridge from voltage to integer values.

VERIFIED COMPETENCY MILESTONE
02
Read analog inputs

Use analogRead() with pins A0–A5 to capture sensor voltages as integer readings. Practice printing raw values to the Serial Monitor for inspection.

VERIFIED COMPETENCY MILESTONE
03
Convert to volts & units

Apply the conversion formula to get voltage, then apply sensor-specific conversions such as millivolts per degree for temperature sensors.

VERIFIED COMPETENCY MILESTONE
04
Calibrate and map ranges

Collect reference readings and use the map function to scale readings to a meaningful range. Verify that reference values are ordered correctly to avoid reversed outputs.
