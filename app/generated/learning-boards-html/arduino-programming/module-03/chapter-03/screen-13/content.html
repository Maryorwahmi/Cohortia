Quick Reference

Short checklist you can use every time you read an analog sensor.

Counts
AnalogRead returns 0–1023. Remember the ADC is discrete.
Convert
volts = (raw / 1023.0) * Vref. Use floats.
Calibrate
Record reference readings and map ranges with correct ordering.
Cheat: print raw, print volts, then compute units. If numbers don't match expectations, this sequence quickly shows where the problem lies.
