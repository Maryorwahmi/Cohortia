Where things typically fail

  • Wiring: misconnected pot pins or missing common ground.
  • Reference mismatch: using the wrong Vref in conversion.
  • Integer math: accidental truncation instead of float math.
  • Divider selection: fixed resistor choice moves sensitivity.
  • Quantization: small signals below one ADC step won't show.
Debug routine
  1. Print raw ADC reading to Serial.
  2. Print converted voltage using the formula.
  3. Compare the computed unit (e.g., °C) to expected values and check sensor datasheet.
  4. Adjust wiring or calibration as needed and repeat.
Key Takeaway

A short print-and-compare routine isolates whether a problem is wiring, math, or calibration—start there before changing hardware or code significantly.
