Definition

ADC to voltage formula

Apply the fraction of full scale and multiply by the reference voltage. Use floating math to keep precision.

Formula
voltage = (raw / 1023.0) * Vref
With Vref = 5.0: voltage = (raw / 1023.0) * 5.0
Notes
  • Result is in volts. Multiply by 1000 for millivolts.
  • Replace 5.0 with your actual reference if different.
  • Use 1023.0 to avoid integer division truncation.
Worked example

Given raw = 143 and Vref = 5.0: 143 / 1023.0 = 0.1398; multiply by 5 gives about 0.699 volts. If a sensor outputs 10 mV per degree, 0.699 V equals approximately 69.9 degrees.

Common misconception

Do not interpret the raw ADC number as a unit of temperature or percent. Convert to the sensor's physical unit using the sensor's scale after converting to volts.

Key Takeaway

Always convert raw counts to volts first, then apply sensor-specific conversion factors. Check your math with a concrete example to build confidence.
