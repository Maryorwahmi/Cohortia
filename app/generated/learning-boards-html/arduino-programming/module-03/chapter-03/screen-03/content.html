Skills & Examples

Each objective includes a short, hands-on activity so you assess competence as you learn.

Serial validation

Print raw ADC values and converted voltage to confirm the sensor and wiring are working before using values in control logic.

Potentiometer control

Use a potentiometer on A0 to control blink rate or brightness so you can see analog input driving outputs in real time.

Temperature conversion

Convert ADC to voltage, then apply sensor-scale factors, for example ten millivolts per degree for LM35, to compute temperature.

Two-point calibration

Capture dark and bright readings and use the map function to rescale a light sensor reading to 0–100 percent. Verify the ordering of reference values to avoid inversion.
