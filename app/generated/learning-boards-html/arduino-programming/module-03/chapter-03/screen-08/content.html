Sensor types and conversion steps

Voltage-output sensor (LM35)
Read ADC → convert to volts → apply 10 mV/°C to compute temperature.
Resistive sensor (LDR, flex)
Use a voltage divider with a fixed resistor → read ADC → convert to volts → map to desired scale.
Worked conversion

Example: raw = 143 → voltage ≈ 0.699 V. For LM35 with 10 mV/°C, temperature ≈ 0.699 / 0.01 = 69.9 °C. Use the sensor's datasheet to confirm offsets and linearity.

Common misconception

Resistive sensors need proper divider design. Swapping the fixed resistor can shift the voltage range and sensitivity; choose values so the ADC sees the sensor's useful range.

Key Takeaway

Always consult the sensor datasheet for scaling and offsets, and design your divider so the sensor output maps well onto the ADC's 0–1023 range.
