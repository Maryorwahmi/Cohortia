Potentiometer → Serial → LED

Read the pot, convert to volts, print values, then map the raw reading to control an LED blink delay or brightness.

// setup
Serial.begin(9600); pinMode(9, OUTPUT);
// loop
int raw = analogRead(A0); float v = (raw / 1023.0) * 5.0;
Serial.print(raw); Serial.print(" \t"); Serial.println(v);
int delayMs = map(raw, 0, 1023, 50, 1000); digitalWrite(9, HIGH); delay(delayMs); digitalWrite(9, LOW); delay(delayMs);
Misconception to avoid

Using map with wrong reference endpoints can produce non-intuitive control ranges. Always confirm the mapping endpoints by observing Serial output first.

Scenario and tweaks

If you want smooth brightness, map raw to 0–255 and write to a PWM pin with analogWrite. If the pot seems insensitive around the center, consider a non-linear mapping or different fixed resistor values for greater sensitivity where you need it.

Key Takeaway

This single project demonstrates reading, conversion, mapping, and output control—core skills for sensor-driven projects.
