Core Concept

10‑bit resolution and quantization

The ADC divides the reference voltage into 1024 discrete steps. Each sample returns the index of the closest step, not the exact analog voltage.

Ruler analogy
Imagine a ruler with marks from 0 to 1023 stretched across 5 volts. The reading finds the nearest mark to your input voltage.
Quick bullets
  • 0 equals 0 volts, 1023 equals the reference voltage (default 5V).
  • Resolution step size = reference / 1023; on 5V that is about 4.887 mV per step.
  • Quantization means small voltage changes smaller than one step may be invisible.
Key Takeaway

Understand the ADC as a discrete ruler. If your sensor output moves less than a single ADC step, you must amplify or change the measurement strategy.

Concrete example

With a 5V reference each ADC step is about 4.887 millivolts. A signal that swings 2 mV will not change the ADC reading; a 10 mV swing will usually change it by about two counts. Keep step size in mind when selecting sensors.

Common misconception

Do not assume analogRead directly gives a voltage. It gives a count that must be converted. Treat the raw number as an index on the ADC ruler, not as the physical unit itself.
