pinMode: declare pin behavior
Call pinMode once in setup to make a pin an OUTPUT before you use digitalWrite on it.
// Example
void setup() {
  pinMode(13, OUTPUT);
}

void loop() {
  digitalWrite(13, HIGH);
  delay(1000);
  digitalWrite(13, LOW);
  delay(1000);
}
This code configures pin 13 once, then alternates its state in loop. For many pins, use a for loop in setup to call pinMode on each pin in an array.
Why setup?
  • setup runs once at start and establishes hardware roles.
  • Putting configuration there avoids repeated calls and keeps loop focused on behavior.
  • Missing pinMode often causes pins to act unpredictably.
Concrete pattern
Use an array of pin numbers and a for loop in setup to set many pins to OUTPUT cleanly and readably.
Key Takeaway

Declare pin roles in setup with pinMode so subsequent writes behave predictably and safely.
