Module 3 › Chapter 3.1 › What is a digital output?
Digital output: simple binary control
Set a pin HIGH to place voltage, LOW to connect to ground. That change controls current flow through connected components.
How it works
When HIGH, the pin sources voltage at the board's logic level. When LOW, it provides ground. Current flows only when a path exists between pin and ground through a load like an LED and resistor.
Concrete example
Pin 13 set HIGH with digitalWrite lights an LED connected through a 220Ω resistor; setting it LOW turns the LED off.
Common misconception
A pin is not a power supply. It can only provide limited current. Expect to use resistors or drivers for higher loads.
Key Takeaway

Digital output toggles voltage on a pin; it is the software-controlled bridge between code and simple electrical actions like lighting an LED.

Annotated example circuit
Parts list
  • Arduino board
  • LED (note polarity: long leg = anode)
  • 220Ω resistor
  • Breadboard and jumper wires
Wiring note
Connect the LED anode to the Arduino pin through the resistor. Connect the LED cathode to GND. Verify orientation before powering.
Check your understanding
What happens if you set a pin HIGH while the LED is reversed? The LED won’t light, and the circuit may not behave as expected.
