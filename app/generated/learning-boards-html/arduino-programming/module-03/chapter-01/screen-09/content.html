Array + loop = scalable patterns
List pin numbers in an array and loop over them to produce a chase effect.
int leds[] = {3, 4, 5, 6, 7};

void setup() {
  for (int i = 0; i < 5; i++) {
    pinMode(leds[i], OUTPUT);
  }
}

void loop() {
  for (int i = 0; i < 5; i++) {
    digitalWrite(leds[i], HIGH);
    delay(200);
    digitalWrite(leds[i], LOW);
  }
}
This pattern is easy to modify: change delay for speed, add pins to the array, or change traversal order for reverse or bounce effects.
Why arrays help
  • Keep code compact and readable.
  • Scale by changing data, not logic.
  • Reduce copy-paste bugs from repeated digitalWrite calls.
Variation idea
To bounce, iterate forward then backward, or manage an index that increments and reverses when it hits ends.
Key Takeaway

Use data-driven code: keep pin lists in arrays and reuse the same loop for maintainable multi-LED patterns.
