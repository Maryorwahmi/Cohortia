Module 3 › Chapter 3.1 › Patterns
Blink
Alternates a single LED HIGH and LOW with a delay. Good for status or heartbeat indicators.
Example: digitalWrite HIGH, delay 1000, digitalWrite LOW, delay 1000.
Chase
Lights a sequence of LEDs using an array and loop to create motion. Good for progress bars or decorative effects.
Example: iterate through an array of pins, setting each HIGH briefly then LOW.
Toggle
Switches between two complementary states, like even vs odd LEDs, for alternating signals or patterns.
Example: flip a boolean and set pins accordingly each loop iteration.
Timing trade-offs
Blocking delay is simple but prevents handling other tasks. Use delay for demos; use millis for concurrent tasks and responsiveness.
Key Takeaway

Pick the pattern to match the message: blink for simple signals, chase for motion, toggle for alternation; choose timing methods for the required responsiveness.
