Module 3 › Chapter 3.1 › LED wiring
LED wiring fundamentals
Anode (long) → resistor → Arduino pin. Cathode (short) → GND.
Resistor role
Limits current so LED and pin remain within safe operating conditions. 220Ω is a common starter value for indicator LEDs.
Polarity
If reversed the LED will not light. Always orient the long leg toward the pin side (through the resistor).
What can go wrong
No resistor: excessive current. Wrong orientation: no light. Missing ground: open circuit, no current flow.
Breadboard checklist
  • Confirm resistor is in series with the LED anode.
  • Verify LED long leg connected toward the Arduino pin path.
  • Confirm LED cathode is connected to the same ground as the Arduino GND pin.
Concrete example
Pin 13 → 220Ω resistor → LED long leg. LED short leg → GND. Upload blink sketch and observe steady blinking. If it flickers or is dim, recheck connections and resistor value.
Key Takeaway

Always include a current‑limiting resistor when connecting an LED to an Arduino pin to prevent damage and unpredictable behavior.
