Learning Objectives
Learn → Understand → Apply → Master
Bloom: Learn • Understand • Apply • Master
01
Use pinMode()
Set a pin as OUTPUT inside setup. This tells the microcontroller which pins will drive voltage so they behave predictably.
VERIFIED COMPETENCY MILESTONE
02
Use digitalWrite()
Drive a pin HIGH or LOW to switch LEDs or signal other components. digitalWrite is the runtime command that changes pin state.
VERIFIED COMPETENCY MILESTONE
03
Wire LEDs with resistors
Always add a current‑limiting resistor, typically 220 ohms, between the pin and the LED anode to protect hardware.
VERIFIED COMPETENCY MILESTONE
04
Create LED patterns
Use arrays and loops to scale effects: blink, chase, and toggle patterns that repeat reliably.
VERIFIED COMPETENCY MILESTONE
