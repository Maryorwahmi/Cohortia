Practical milestones
Four small tests you can run on hardware.
Verified Competency
01 Configure pin
Write setup that calls pinMode(pin, OUTPUT). Plug an LED and confirm it can be driven. This proves the pin is set as an output.
Mnemonic: switch label
02 Toggle state
Create a loop that calls digitalWrite HIGH, delay, then LOW, delay. The LED should blink at the chosen interval.
Mnemonic: heartbeat
03 Safe wiring
Place a 220 ohm resistor between the pin and LED anode. Confirm polarity: long leg to pin, short leg to ground.
Mnemonic: long leg → resistor → pin
04 Build a pattern
Use an array of pin numbers and a for loop to light LEDs in sequence. Adjust delay to change speed.
Mnemonic: array → loop → pattern
