digitalWrite and loop
Use digitalWrite to change a pin's state. Combine it with timing to create visible effects.
void loop() {
  digitalWrite(13, HIGH);
  delay(1000);
  digitalWrite(13, LOW);
  delay(1000);
}
digitalWrite acts immediately. delay pauses the program, holding the current output. For simple blinking and timing this blocking pattern is easy and clear.
Tips and contrasts
  • digitalWrite is not timed—combine it with delay or millis-based timing to control duration.
  • Blocking delays are fine for simple demos but limit responsiveness to other inputs.
  • Remember to call pinMode in setup so digitalWrite changes take effect predictably.
Concrete exercise
Modify the delay values and observe how blink speed changes. Try 200 ms for a fast blink or 2000 ms for a slow pulse.
Key Takeaway

digitalWrite sets state instantly; use timing functions to control how long a state persists and choose patterns accordingly.
