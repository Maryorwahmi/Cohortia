Common mistakes
  • Leaving the pin as plain INPUT with no resistor causes floating readings.
  • Using delay()-based debounce stops other processing and reduces responsiveness.
  • Wiring the switch to 5V while using INPUT_PULLUP creates a short when pressed.
  • Using too short a debounce window that still lets bounce through.
Pro tips
Enable INPUT_PULLUP for quick builds and minimal components, but invert logic in code.
Log raw readings to observe bounce before tuning debounceDelay.
Handle actions on debounced transitions so your code responds once per press.
Why it matters
Correct handling prevents false triggers and enables reliable human interaction with your device.
