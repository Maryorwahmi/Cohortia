Module 3 › Chapter 3.2 › What is a digital input?
Concept and code
An input is high-impedance so it senses voltage. You configure it once and read inside loop().
// Configure pin 2 as input
pinMode(2, INPUT);

// Later, in loop:
int buttonState = digitalRead(2);
Example
A button connects pin 2 to 5V when pressed; reading that pin returns HIGH during press.
Explanation bullets
  • Inputs do not source or sink significant current; they measure voltage.
  • A pin must have a defined voltage otherwise readings may be unreliable.
  • digitalRead returns discrete HIGH or LOW values representing voltage thresholds.
  • Use pinMode to set the pin before you attempt to read it.
Key takeaway
Always define a default reference for inputs to avoid random readings.
Common misconception
Assuming pinMode alone ensures stable readings; you still need a pull resistor if nothing else drives the pin.
