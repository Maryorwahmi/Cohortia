Module 3 › Chapter 3.2 › Floating vs Defined
Floating input
Without a resistor the pin has no reference and can randomly read as HIGH or LOW. This creates false triggers.
Symptom
Unstable readings, spurious button events, erratic behavior.
Test
Leave the pin unconnected and observe logged values; they will fluctuate.
Defined input with pull resistor
Attach a 10kΩ resistor to ground or 5V so the pin defaults to a known state when the switch is open.
Symptom
Stable readings; button press reliably produces a single change.
Best practice
Use ~10kΩ for external pull resistors. Reserve very low values to avoid current waste.
Example wiring notes
Pull-down: resistor between pin and ground; button connects pin to 5V when pressed. Pull-up: resistor between pin and 5V; button connects pin to ground when pressed.
