Module 3 › Chapter 3.2 › Pull-down vs Pull-up
Pull-down (external resistor)
Resistor from pin to ground. Unpressed state reads LOW. Press connects pin to 5V and reads HIGH.
Wiring
Pin → resistor → ground. Button connects pin to 5V when pressed.
Note
Requires external resistor; common in circuits where you prefer pressed=HIGH logic.
Pull-up (external or internal)
Resistor from pin to 5V. Unpressed reads HIGH. Press connects pin to ground and reads LOW.
Wiring
Pin → resistor → 5V. Button connects pin to ground when pressed. Internal pull-up avoids external resistor.
Note
When using INPUT_PULLUP, code must treat LOW as the active pressed state.
Quick test
Try both and log values. Confirm whether pressed yields HIGH or LOW and adjust your condition checks accordingly.
