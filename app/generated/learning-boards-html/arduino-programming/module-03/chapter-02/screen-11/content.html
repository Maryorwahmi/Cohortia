Wiring checklist
  • Button: one side to digital pin 2, other side to ground.
  • LED: longer leg to pin 13, shorter leg to ground (with current-limiting resistor if external LED).
  • Enable internal pull-up in setup: pinMode(2, INPUT_PULLUP);
Starter sketch
// Setup
pinMode(13, OUTPUT);
pinMode(2, INPUT_PULLUP);

// Loop: read, debounce, toggle LED on confirmed press
Testing and troubleshooting
If the LED toggles multiple times, increase debounceDelay to around 50 ms.
If the LED never toggles, verify the button is wired to ground and the pin mode uses pull-up.
If response feels slow, reduce debounceDelay cautiously and retest for false triggers.
Try this
Log raw readings to the serial monitor to observe bounce and then observe stable state after debounce.
