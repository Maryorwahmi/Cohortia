Default defined
Use a pull resistor or INPUT_PULLUP so the pin has a known state when open.
INPUT_PULLUP
Internal pull-up saves parts; pressed reads LOW, so invert logic in code.
Debounce
Use millis() timing threshold to accept only stable changes and avoid delay().
Final tip
When debugging, log raw values to the serial monitor to see bounce and confirm your debounce window.
