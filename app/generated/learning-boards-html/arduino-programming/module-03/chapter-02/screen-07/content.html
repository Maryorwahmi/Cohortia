Module 3 › Chapter 3.2 › Internal Pull-up
Enable the internal pull-up
pinMode(2, INPUT_PULLUP);
With this setting the pin reads HIGH when the button is open, and reads LOW when the button connects the pin to ground.
Example wiring
Connect one side of the button to the digital pin and the other side to ground. No external resistor needed.
Why use internal pull-up
  • Reduces parts; convenient for simple button inputs.
  • Prevents floating without extra components.
  • Requires you to invert logic in code because pressed equals LOW.
Common mistake
Connecting the button to 5V instead of ground while using INPUT_PULLUP creates a direct short when pressed. Always wire to ground.
