Module 7 › Chapter 6.4 › Sensor testing routine
Step-by-step test sequence
1. Single-sensor power-up
Connect only the sensor and check Serial for stable outputs before adding other modules.
2. Collect sample readings
Record multiple values in dry and wet or dim and bright conditions to choose calibration points.
3. Average and smooth
Compute a simple average of several reads to reduce noise before displaying or comparing to thresholds.
4. Full-system check
Reconnect all sensors, then verify that individual readings remain consistent with earlier samples.
Concrete example
Measure soil analog value in an empty pot (dry) and with a known wet sample. Record five reads each, compute the mean, and store those as your dry and wet calibration references. Use those to calculate a normalized moisture percentage in code.
Common mistake

Using a single instantaneous read as a threshold can produce false alerts. Average samples and retest after wiring all modules.
