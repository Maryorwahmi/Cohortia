Four outcome cards
Stable sensor reads
Show Serial outputs and handle analog variability with averaging or smoothing.
Readable display
Format labels so moisture, temperature, and light are clear at a glance.
Calibration routine
Let the user set dry and wet references for reliable thresholds.
Non-blocking alerts
Use millis to keep readings updating while alarms or pump cycles run.
Verified Milestone
Document your test results, wiring, and code organization so assessors can reproduce your work.
