Module 7 › Chapter 6.4 › Assessment & Presentation
Grading criteria mapped
Sensors: readable values and documented test logs.
Display: clear formatting and no flicker.
Alerts: correct thresholds and documented calibration.
Code: functions, comments, and modular structure.
Docs: wiring diagram, README, and overview video.
Presentation outline
  1. Block diagram and wiring overview.
  2. Live demo of sensor readings and calibration.
  3. Show code structure and key functions.
  4. Trigger alert and, if present, pump control, and explain safety choices.
