Alert design patterns
  • Use calibrated percent values for moisture thresholds.
  • Add hysteresis or a short persistence timer so alerts only occur for sustained conditions.
  • Present clear text states on the display: OK, DRY, LOW LIGHT.
  • For actuators, document safety power separation and limit pump on-time to a few seconds.
Example scenario
If moisture percent drops below the calibrated dry threshold and stays below for ten seconds, light an LED and show "DRY". If pump control is enabled, run the pump for a short, documented burst and then wait a cooldown period before allowing another automatic cycle.
Common mistake

Triggering alerts on every small fluctuation will frustrate users and reduce trust in the system. Use persistence checks to avoid this.
