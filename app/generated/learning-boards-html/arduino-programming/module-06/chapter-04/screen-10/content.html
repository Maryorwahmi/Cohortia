Module 7 › Chapter 6.4 › Non-blocking Timing
Timing pattern
now = millis()
if (now - lastSensor >= 200) { readSensors(); lastSensor = now; }
if (now - lastDisplay >= 800) { updateDisplay(); lastDisplay = now; }
if (pumpActive && now - pumpStart >= pumpDuration) { stopPump(); startCooldown = now; }
Design tips
  • Keep timers independent so updating one function doesn't block others.
  • Use small helper functions to keep loop logic readable and testable.
  • When using millis, watch for long-running variables and handle rollover conceptually if needed.
Common mistake

Using delay for timing will pause all tasks and make your display and alerts unresponsive during long actions like pump runs.
