Interactive 16:9 Masterclass

Smart Plant Monitoring System

A modular capstone: sense soil moisture, light, and temperature; display values; alert when conditions need attention; optionally water automatically.

Why this matters
You will combine sensing, display, and control into a reliable, documented device that demonstrates applied embedded skills.
How you'll work
Test sensors first, then integrate display and alerts, then add calibration and optional pump control.
Explore Key Topics
Sensors & Tests
Verify each sensor on Serial before integration.
Display & UI
Format clear labels and avoid flicker using I2C or OLED buffering.
Alerts & Control
Use thresholds, calibration, and non-blocking timing for reliable alerts or pump activation.
Visual concept
Cards represent sensors, display, calibration, and optional pump. Connect them in sequence for a clear build plan.
