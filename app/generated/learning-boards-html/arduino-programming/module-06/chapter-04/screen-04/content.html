Module 7 › Chapter 6.4 › Components & Roles
Component cards
Arduino Uno
Controller: reads sensors, updates display, and drives alerts or a relay.
Soil moisture sensor
Analog source for moisture level; requires calibration for dry and wet references.
DHT11/DHT22
Temperature and humidity sensor; choose DHT22 if you need better accuracy.
LDR / Light sensor
Monitors ambient light to decide if lighting is adequate for the plant.
Display, alerts, and optional pump
Use an I2C LCD or small OLED to show moist, temp, and light values. For alerts use a buzzer or LED triggered when soil is below the calibrated dry threshold. If you add a relay and pump, ensure the pump draws power from a separate supply and that the relay is rated for the pump's current. Document your wiring and safety choices in the README to meet assessment criteria.
Key Takeaway

Match each physical component to a clear software responsibility before wiring or coding.
