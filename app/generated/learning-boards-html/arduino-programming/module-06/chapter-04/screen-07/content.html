Module 7 › Chapter 6.4 › Calibration Routine
Calibration steps
  1. Record 5–10 analog samples in dry soil; compute the mean as dryRef.
  2. Record 5–10 samples in wet soil; compute the mean as wetRef.
  3. Map current analogValue using those refs to a 0–100 scale for display.
  4. Save refs in EEPROM or note them in README if non-volatile storage isn't used.
Example mapping
Normalized percent = (analog - dryRef) / (wetRef - dryRef) * 100. Clamp to 0–100 and use this value to decide alerts. Keep the raw references in documentation so others can reproduce your thresholds.
Pro tip

Take samples at different depths and average if your sensor placement varies. Note the exact pot and soil in your README.
