Module 6 › Chapter 6.1 › millis() pattern
Pattern
Store unsigned long previousMillis. In loop get unsigned long currentMillis = millis(); If currentMillis - previousMillis >= interval, perform action and set previousMillis = currentMillis.
Concrete benefit
Using millis lets interrupts fire at any time and keeps loop available to check flags and perform background tasks without being blocked by delay.
Common mistake

Using multiple nested delays hides missed interrupts and hides timing issues. Replace them with the millis pattern for clarity and responsiveness.

Key takeaway

millis enables cooperative multitasking: periodic tasks run while interrupts still capture urgent events.
