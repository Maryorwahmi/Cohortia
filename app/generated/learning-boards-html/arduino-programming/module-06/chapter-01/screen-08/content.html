Module 6 › Chapter 6.1 › ISR best practices
Rule list
  1. Keep the ISR body extremely short.
  2. Avoid delay and Serial.print inside the ISR.
  3. Set flags or increment counters in the ISR.
  4. Perform heavier work in loop when the flag is seen.
Example pattern
ISR: flag = true; loop: if flag then flag = false; Serial.print and update LED. This keeps interrupt context fast and predictable.
Common mistake

Putting delay or serial I/O inside the ISR may appear to work but will break under load and delay other interrupts.

Key takeaway

Keep ISRs minimal. Use flags to hand off work so the sketch stays responsive and reliable.
