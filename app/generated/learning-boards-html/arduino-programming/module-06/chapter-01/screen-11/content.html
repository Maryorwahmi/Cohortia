Module 6 › Chapter 6.1 › Polling vs Interrupts
Polling sketch
loop checks the button state with digitalRead and updates counter. If loop contains delay or long processing, quick presses may be missed.
Interrupt sketch
attachInterrupt triggers ISR on pin change and increments a volatile counter. The main loop reads the counter and logs it without risk of missing quick presses.
Experiment

Run both versions and press quickly. Observe that the polling version misses some counts when loop is busy, while the interrupt version records each press.

Key takeaway

Use interrupts for event-driven detection and polling with millis for periodic checks that do not need instant response.
