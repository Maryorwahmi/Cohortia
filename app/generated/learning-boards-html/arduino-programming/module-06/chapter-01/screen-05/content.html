Module 6 › Chapter 6.1 › attachInterrupt()
Code walkthrough
const int buttonPin = 2;
volatile int buttonCount = 0;

void setup() {
  pinMode(buttonPin, INPUT_PULLUP);
  attachInterrupt(digitalPinToInterrupt(buttonPin), countPress, FALLING);
  Serial.begin(9600);
}

void loop() {
  Serial.println(buttonCount);
  delay(500);
}

void countPress() {
  buttonCount++;
}
Explanation
  • pinMode: Uses INPUT_PULLUP so the button pulls the pin LOW when pressed.
  • attachInterrupt: Binds countPress to the pin using FALLING to detect the press.
  • ISR: countPress only increments the volatile counter to stay short and safe.
Concrete scenario
Press the button rapidly while the main loop calls delay. The interrupt-based sketch captures every press, showing how interrupts solve missed events in polling designs.
Common mistake

Putting Serial.print or delay inside the ISR will block execution and may miss other events. Keep ISRs minimal.

Key takeaway

attachInterrupt plus a tiny ISR gives reliable immediate reactions for short events like button presses.
