Module 6 › Chapter 6.1 › Interrupt modes
Mode table
FALLING — triggers when signal goes HIGH to LOW. Good for pull-up buttons.
RISING — triggers when signal goes LOW to HIGH. Good for pull-down wiring.
CHANGE — triggers on both edges. Use when both press and release matter.
LOW — triggers while pin is low. Use cautiously for level detection.
Concrete example
With INPUT_PULLUP, the idle state is HIGH. Pressing the button brings the pin LOW, so FALLING detects the press. If you used CHANGE, you would get both the press and the release events.
Misconception check
Don't assume CHANGE is harmless. It doubles calls if you only care about presses. LOW can cause repeated triggers while the pin remains held low, which may be unwanted.
Key takeaway

Match the mode to wiring and requirements: FALLING with pull-up buttons is the common safe default for presses.
