Module 6 › Chapter 6.1 › What is an interrupt?
Definition
An interrupt temporarily stops the main program to run a short interrupt service routine, then control returns to the main code.
Analogy
Think of loop as checking the mailbox. An interrupt is a phone call that demands immediate attention and then you resume checking.
Key takeaway

Use interrupts when events are short or urgent and cannot wait for the next loop iteration.

Concrete example
A button press that lasts a few milliseconds can be missed by a slow polling loop. Attaching an ISR to the button pin ensures each press increments a counter immediately.
Common misconception
Interrupts are not magic; they are a tool that introduces concurrency-like behavior. Misusing them can create subtle bugs, so prefer short ISRs and clear handoff patterns.
