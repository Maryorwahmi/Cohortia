Module 6 › Chapter 6.1 › Learning Objectives
Objective checks
  • External interrupt: Demonstrate that a counter increases on a fast press while loop uses delay.
  • attachInterrupt: Show code bound to pin 2 or 3 using FALLING and observe ISR runs.
  • ISR safety: Replace long work in ISR with a flag and process it in loop without blocking.
  • millis(): Replace delay with elapsed-time checks and prove interrupts still fire reliably.
Evidence examples
Use simple indicators like serial prints from loop, LED flashes on timed intervals, and a visible counter that increases when the button is pressed quickly. These are repeatable, observable proofs of competency.
