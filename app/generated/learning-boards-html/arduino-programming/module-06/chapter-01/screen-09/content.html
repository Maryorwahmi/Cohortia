Module 6 › Chapter 6.1 › Flag handoff pattern
Sequence
  1. ISR sets eventFlag = true or increments a volatile counter.
  2. ISR returns immediately.
  3. Main loop checks eventFlag, clears it, and performs heavier work.
Example code sketch
ISR: eventFlag = true; loop: if(eventFlag){ eventFlag = false; Serial.println("Event"); }
Why it matters

This pattern keeps interrupt handling predictable and prevents the ISR from becoming a source of blocking or timing glitches.

Check
Refactor any ISR that does I/O into the flag pattern and observe improved responsiveness under load.
