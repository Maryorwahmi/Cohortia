Learning Objectives
Build interrupt-driven reactions and non-blocking timing into your Arduino sketches.
01
Use external interrupts
Attach handlers to pins so events are caught instantly. This matters when a press or sensor change must not be missed.
VERIFIED COMPETENCY MILESTONE
02
Attach ISRs with attachInterrupt()
Learn the function signature and trigger modes to ensure the ISR fires when you expect it to.
VERIFIED COMPETENCY MILESTONE
03
Avoid ISR pitfalls
Keep ISRs short, avoid blocking calls, and use flags to move heavy work into the main loop.
VERIFIED COMPETENCY MILESTONE
04
Use millis() for timing
Check elapsed time without stopping the program, and combine this with interrupts to stay responsive.
VERIFIED COMPETENCY MILESTONE

Each objective is paired with a small, verifiable task: attach an ISR, observe a volatile variable change, refactor an ISR to set a flag, and replace a delay with millis checks.
