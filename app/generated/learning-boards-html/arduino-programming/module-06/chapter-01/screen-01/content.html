Interrupts and Timers
Respond instantly to events and keep your main code non-blocking.
In this lesson
You will learn attachInterrupt(), ISR rules, volatile variables, and using millis as a non-blocking timer. Practical examples show a button counter before and after using interrupts.
Why this matters
Projects that must react instantly, like safety stops, button counters, or event logging, require interrupts. They let your board handle urgent signals without blocking the rest of the sketch.
Explore key topics
attachInterrupt()
Bind an ISR to an external pin and choose the trigger mode.
volatile
Tell the compiler a variable may change at any time so the main code sees updates.
millis()
Use elapsed-time checking to avoid blocking with delay.
