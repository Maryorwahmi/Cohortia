Module 6 › Chapter 6.1 › volatile variables
Why volatile matters
The compiler often caches values or optimizes repeated reads. volatile forces the compiler to reload the variable from memory each time so updates done by an ISR are visible to the main program.
Practical example
Declare volatile int buttonCount so that when the ISR increments it, loop reads the new value and prints it. Without volatile the printed value might never change due to compiler optimizations.
Misconception
volatile is not a lock. It does not make multi-byte accesses atomic. It simply prevents the compiler from caching the variable value.
Key takeaway

Always mark variables modified in an ISR as volatile so the main program sees updates reliably.
