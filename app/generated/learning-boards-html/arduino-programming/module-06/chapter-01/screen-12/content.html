Module 6 › Chapter 6.1 › Hands-on Activity
Steps
  1. Start from the polling counter sketch that uses digitalRead in loop.
  2. Declare the counter volatile and remove polling code from loop.
  3. In setup use attachInterrupt(digitalPinToInterrupt(pin), ISR, FALLING) for a pull-up button.
  4. Make the ISR increment the volatile counter and return immediately.
  5. Use millis in loop for any periodic tasks and print the counter there.
What to observe
Check that rapid presses increment the counter reliably and that other timed tasks continue to run. Confirm no Serial or delay calls are inside the ISR.
Common pitfalls

Forgetting volatile, using the wrong trigger mode, or leaving blocking code in the ISR are the usual causes of missed counts.

Reflection

After completing the task, ask: did interrupts let the system stay responsive while capturing every event? That confirms success.
