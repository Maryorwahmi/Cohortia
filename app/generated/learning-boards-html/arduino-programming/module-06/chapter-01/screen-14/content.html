Tiny ISRs
Keep interrupt handlers minimal. Set a flag or increment a counter and return fast.
Use volatile
Mark variables modified by an ISR as volatile so loop reads the correct value.
Prefer millis
Replace delay with millis checks to keep the sketch responsive to interrupts.
