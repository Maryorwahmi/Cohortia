Module 6 › Chapter 6.2 › Measuring Current
Step-by-step
  1. Turn off power and set meter to the expected range.
  2. Disconnect the positive lead from the board's supply input.
  3. Connect the meter red lead to battery + and meter black lead to board + so current flows through the meter.
  4. Restore power and record the reading. If it spikes or is zero, check range and fuse.
Practical checks
Measure the baseline, then disable an LED or enter sleep and measure again. The difference shows real savings. If you expect microamps use the microamp jack if your meter has one.
Safety note
A blown meter fuse gives zero current readings. If you see zero unexpectedly, inspect the meter first.
Key Takeaway

Always place the meter in series and compare before/after changes to validate power improvements.
