Responsiveness vs Battery
Decide the acceptable wake latency. Sleep is excellent when reactions can be delayed. Continuous mode when instant reaction is required.
Example: logger
A temperature logger that wakes every few minutes can sleep between samples and save large amounts of energy.
Example: alarm
An alarm that must trigger instantly may need continuous sensing or dedicated wake hardware.
Hybrid patterns
Use low-power peripherals or interrupts to wake the MCU only for meaningful events. Combine periodic timer wake and event-based wake for flexibility.
Key Takeaway

Pick sleep when latency allows it. Use hybrid approaches to balance responsiveness and battery life.
