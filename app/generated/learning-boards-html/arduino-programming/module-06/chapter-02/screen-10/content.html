Module 6 › Chapter 6.2 › Hands-on Activity
Activity steps
  1. Run a simple sketch that keeps the board active (blink or sensor poll).
  2. Measure current in series and record the baseline.
  3. Add a sleep call or switch off a peripheral.
  4. Measure again and compare the results.
Example protocol
Baseline: measure with USB or battery connected. Change: call LowPower.powerDown with ADC_OFF and BOD_OFF and wake on a button interrupt. Re-measure to see sleep current.
Note
If you see no change, check for always-on modules and regulator losses first.
Key Takeaway

One controlled change plus measurement proves whether an optimization actually helps.
