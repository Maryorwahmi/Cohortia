Concept
Sleep until an interrupt

The MCU halts most clocks and enters a low-power state. It wakes when a configured interrupt occurs. Combine with peripheral shutdown for best results.

Misconception
Sleep alone may leave ADC or brown-out detector active. Disable them via library options for deepest sleep.
Minimal example (visual only)
#include <LowPower.h>

void setup() {
  pinMode(2, INPUT_PULLUP);
}

void loop() {
  // Sleep until pin 2 triggers
  LowPower.powerDown(SLEEP_FOREVER, ADC_OFF, BOD_OFF);
  // Wakeup handling here
}
Use this template to sleep until a pin event. Test wake behavior and measure idle current before integration.
Key Takeaway

Sleep calls are powerful, but pair them with peripheral shutdown and measurement to confirm savings.
