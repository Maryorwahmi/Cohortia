Process Flow

A short debugging session: find a sensor stuck at zero

A stepwise sequence reduces wasted effort. Confirm liveness, inspect raw reads, then inspect processing.

Step 1
Add heartbeat and run to confirm the loop executes.
Step 2
Print the raw sensor value immediately after reading it.
Step 3
If raw value is zero, check wiring and initialization. If not, print the processed result and inspect logic.
Step 4
After fix, remove extra prints and keep or remove the heartbeat as needed.
Example trace
Observed output: heartbeat visible, raw sensor prints zero. Action: verify wiring and sensor power. Result: corrected wiring restores nonzero readings and processing yields expected values.
Check your understanding
If the heartbeat stops and prints vanish, what is the most likely next step? Look for blocking code paths or long delays introduced since the previous working version.
