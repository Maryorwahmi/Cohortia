Definition

Heartbeat LED: a silent runtime monitor

A single periodic blink indicates loop activity and quickly shows if execution is blocked.

Why it helps
When the LED stops blinking, you know execution reached a blocking condition; this narrows the search space dramatically.
Common mistake
Placing heartbeat after long waits. Put it early in loop so it signals general liveness.
Example
Add a simple blink in loop. If the LED halts while Serial shows no prints, focus on code paths that might block before the heartbeat toggle.
Visualization
LED
Blink once per loop to confirm cycles without altering timing drastically.
Key Takeaway

A heartbeat LED gives an immediate liveness signal and helps you separate timing and logic errors quickly.
