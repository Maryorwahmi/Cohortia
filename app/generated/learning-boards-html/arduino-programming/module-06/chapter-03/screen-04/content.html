Core Concept

Why debugging is a normal part of programming

On embedded systems, inexpensive observation techniques replace a full graphical debugger. These are fast, low-risk, and reversible.

Print statements
Add prints that show values at key steps to trace where data diverges from expectation. Keep them focused.
Heartbeat LED
A blink inside loop confirms the sketch is running and helps detect blocking operations.
Common mistake
Printing every variable by default. This floods the monitor and hides the real signal. Prefer selective prints near suspected failure points.
Pro tip
Keep prints short and descriptive. Use a label then the value so you can match output to code locations quickly.
Example: observation checklist
  • Add a single print where the sensor value is read.
  • Blink an LED once per loop to confirm activity.
  • Run and watch for a steady blink and changing printed values.
  • If printed values are constant, inspect wiring and sampling code.
Key Takeaway

Observe program behavior with prints and a heartbeat before making large changes; then clean up debug prints after you fix the issue.
