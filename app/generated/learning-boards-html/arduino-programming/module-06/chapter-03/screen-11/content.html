Process

Version control and documenting projects

Small commits and a clear README preserve your work and make it reproducible and shareable.

Commit habit
Make concise commits after logical changes and include a message that explains the why, not just the what.
README essentials
  • Description of the project
  • Wiring diagram or parts list
  • Required libraries and installation steps
  • How to run or use the project
Example: small commit
After fixing a sensor initialization bug, make a commit that records the fix and the test you ran. This creates a clear history entry that you can return to if future changes reintroduce the issue.
Key Takeaway

Version control and a short README provide traceability and reproducibility, which reduce debugging time and ease collaboration.
