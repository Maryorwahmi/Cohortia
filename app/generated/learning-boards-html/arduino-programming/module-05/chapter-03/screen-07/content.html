Module 6 › Chapter 5.3 › Pairing and command flow from a smartphone
Process Flow
Pair → Open Terminal → Send Commands
Simple controlled sequence for turning an LED on and off from a smartphone terminal app.
Step 1
Power and make module discoverable, then pair from the phone using the default PIN if required.
Step 2
Open a Bluetooth terminal app and connect to the module's virtual serial port.
Step 3
Send "1" to set LED high and "0" to set it low. Confirm action is immediate and reliable.
Concrete example
Send the character 1 from the phone. Your parsing code treats that character as a command to set the LED pin HIGH and returns an acknowledgment if your sketch sends one.
Security note
Paired devices can send commands freely. For sensitive controls, plan authentication or limit access by keeping devices in private environments.
Key Takeaway

Pairing is convenient for control but does not replace secure authentication; start with short commands and verify behavior.
