ESP8266 web server skeleton
Key areas: libraries, credentials, connection loop, handler registration, server loop.
#include <ESP8266WiFi.h>
#include <WiFiClient.h>
#include <ESP8266WebServer.h>

const char* ssid = "YourNetwork";
const char* password = "YourPassword";
ESP8266WebServer server(80);

void setup() {
  pinMode(LED_BUILTIN, OUTPUT);
  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
  }
  server.on("/", handleRoot);
  server.begin();
}

void loop() {
  server.handleClient();
}
Practical note
This sketch demonstrates the bare essentials. Expand the root handler to include on/off controls that write to the LED pin when links or buttons are clicked.
Concrete scenario
After connecting to Wi‑Fi, browse to the board's IP and click an on/off link that your handler maps to digital writes for the LED.
Security reminder
Hard‑coded credentials are fine for experiments; avoid publishing such sketches for deployed devices and consider authentication if opening endpoints.
Key Takeaway

The ESP8266 can host a simple web server with a few library calls, making browser‑based control straightforward for prototyping.
