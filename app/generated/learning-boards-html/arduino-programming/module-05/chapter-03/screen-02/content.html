Learning Objectives
Learn, understand, apply, and verify wireless features for Arduino projects.
Bloom: Learn → Understand → Apply → Master
01
Use HC‑05/HC‑06 with Arduino
Wire the module, treat it as a serial device, and send commands from a phone to control outputs. Verified competency milestone: wiring and basic serial command working.
02
Apply SoftwareSerial
Use alternate Arduino pins for Bluetooth when USB programming uses hardware serial. Verified competency milestone: working SoftwareSerial command exchange.
03
Identify ESP options
Choose NodeMCU, Wemos D1 Mini, or ESP32 for built‑in Wi‑Fi and extra resources. Verified competency milestone: board selection and basic sketch upload.
04
Apply IoT security basics
Avoid exposing unauthenticated interfaces, protect credentials, and plan updates. Verified competency milestone: checklist for secure deployment.
