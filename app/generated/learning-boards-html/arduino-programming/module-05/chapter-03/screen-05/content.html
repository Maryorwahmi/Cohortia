Pin roles and wiring checklist
A concise wiring checklist and protection tips to avoid common hardware mistakes.
VCC & GND
Power the module with the correct voltage. Many setups use 5V supply but check datasheet if unsure.
TXD / RXD
TXD goes to Arduino RX; RXD goes to Arduino TX. Use a level shifter or voltage divider if the logic levels differ.
EN
Optional enable pin to turn the module on or off in power sensitive projects.
STATE
Status output that can tell you if the module is paired or connected.
Pro tip
If you plan to upload sketches frequently, wire TX/RX to SoftwareSerial pins so hardware serial remains free for the bootloader and USB programming.
Wiring Example
A common safe wiring pattern and a quick checklist to run before power up.
Checklist
  • Confirm module VCC rating before applying power.
  • Place a voltage divider on Arduino TX if module is 3.3V only.
  • Swap TX/RX for correct direction of data flow.
  • Test pairing with a phone app before wiring outputs.
Analogy
Think of TX as someone talking and RX as someone listening; flipping them stops the conversation.
Key Takeaway

Correct pin mapping and level protection prevent damage and make development smoother.
