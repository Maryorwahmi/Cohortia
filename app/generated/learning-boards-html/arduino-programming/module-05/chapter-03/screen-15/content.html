Use these short notes to jog your memory during builds.
Bluetooth = Serial
Use the same parsing code; check voltage and avoid serial pin conflicts when uploading.
ESP boards
Built‑in Wi‑Fi and more memory: best choice for web servers and heavier network tasks.
Security
Hard‑code for learning only. Add authentication and update plans for deployed devices.
Keep these three rules in mind as you prototype and before you publish a device.
