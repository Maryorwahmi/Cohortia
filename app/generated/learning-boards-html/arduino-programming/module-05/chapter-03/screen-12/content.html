Module 6 › Chapter 5.3 › Build a Bluetooth‑controlled LED
Hands‑On Activity
Pair HC‑06 and send 1/0
A short checklist to complete the activity and confirm the LED toggles reliably.
Steps
  1. Wire VCC, GND, and TXD/RXD; use SoftwareSerial pins if needed.
  2. Upload a sketch that parses incoming bytes and sets LED HIGH for '1' and LOW for '0'.
  3. Pair the module with a phone and use a terminal app to send the characters.
  4. Debug with the Serial Monitor if the LED does not respond.
Success check
LED toggles on '1' and off on '0'. Uploads are still possible if you used SoftwareSerial.
Troubleshooting
If nothing happens, confirm RX/TX are not swapped, check the module's baud rate, and ensure power is present.
Extension
After success, add acknowledgments from the Arduino or extend commands to control multiple outputs.
Key Takeaway

This activity verifies wiring, serial parsing, pairing, and basic troubleshooting in a single loop.
