Key Concepts
Remember these compact, actionable ideas when building wireless projects.
Bluetooth = Serial
HC‑05/HC‑06 forward bytes like a wired serial link; reuse parsing logic and mind pin voltages.
ESP = Integrated Wi‑Fi
NodeMCU, Wemos, and ESP32 include Wi‑Fi and more memory, making web servers and network logic easier.
Security first
For learning, hard‑coding is OK. For deployment, add authentication, remove published credentials, and plan updates.
Summary
Bluetooth gives simple mobile control via serial. ESP boards provide full network hosting. Secure before you publish.
