Uno pins
I2C: A4 (SDA), A5 (SCL). SPI: D11 (MOSI), D12 (MISO), D13 (SCK), SS default D10.
I2C scanner
Run the scanner to list addresses like 0x27 or 0x68 and resolve duplicates before coding.
SPI checks
Ensure only one SS is low at a time and match clock polarity/phase to device specs.
Final thought

These quick checks will make integrating multiple peripherals predictable and reliable.
