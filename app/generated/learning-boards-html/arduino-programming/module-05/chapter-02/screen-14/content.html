Module 5 › Chapter 5.2 › Key Concepts
I2C: SDA, SCL, addresses
Two-wire bus using 7-bit addresses to share devices on the same lines.
SPI: MOSI, MISO, SCK, SS
Four-wire full-duplex bus with separate slave selects for each device.
Libraries & tools
Use Wire, device libraries, SPI, and an I2C scanner to simplify development and debug addresses early.
Summary takeaway

Pick I2C when pin count matters and devices are low-speed. Choose SPI when you need higher throughput and can allocate select lines.
