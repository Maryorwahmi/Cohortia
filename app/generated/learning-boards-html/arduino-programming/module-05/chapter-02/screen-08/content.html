Module 5 › Chapter 5.2 › SPI basics
Signal names
MOSI: master transmits to slaves. MISO: slaves send data to master. SCK: clock from master. SS: individual select lines for each slave.
Arduino Uno pins
MOSI = D11, MISO = D12, SCK = D13, default SS = D10. Use other pins for additional SS lines as needed.
Example scenario
An SD card and an SPI display share MOSI/MISO/SCK. The master pulls the SD card's SS low to read files, then raises it before selecting the display with its SS line. Proper SS handling prevents bus contention.
Misconception
Sharing SS lines will cause devices to respond at the same time unless each device has its own dedicated SS pin toggled correctly.
