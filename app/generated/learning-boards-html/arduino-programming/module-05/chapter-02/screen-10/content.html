Module 5 › Chapter 5.2 › SPI.transfer()
Typical pattern
  1. Call SPI.begin() and set SPI settings for speed and mode.
  2. Pull the device's SS line LOW to select it.
  3. Call SPI.transfer to send a byte and read a byte back.
  4. Pull SS HIGH to finish the transaction.
Practical note
Set the right clock polarity and phase for each device. Mismatched modes are a frequent source of data corruption.
Example
Read a status by asserting SS, transfer a command byte, then transfer a zero to clock the status back from the device.
