Hands-on activity
Connect an I2C LCD and an I2C RTC to the same SDA/SCL bus and display time. Run a scanner to find addresses and resolve conflicts if they occur.
Why this helps
This activity teaches addressing, bus sharing, and basic library usage so you can combine multiple I2C parts safely.
Assessment idea
If you must connect three sensors and a display with few pins, prefer I2C and explain the choice based on two-wire sharing and 7-bit addresses.
Common pitfalls
  • Forgetting pull-ups on SDA and SCL, causing noisy or absent signals.
  • Using the same SS pin for multiple SPI devices and not toggling it correctly.
  • Assuming every device uses the same default I2C address — always scan first.
