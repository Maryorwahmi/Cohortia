Module 5 › Chapter 5.2 › I2C vs SPI
Feature table
Pin count: two shared lines
Pin count: four shared + SS per device
Addressing: 7-bit addresses
Addressing: individual SS lines
Speed: generally slower
Speed: generally faster, full duplex
Use-case examples
I2C: many sensors, RTC modules, LCDs and small OLEDs where pins are limited. SPI: SD cards, high-speed displays, shift registers, and radio modules where throughput or simple framing is required.
Designer question
If you need both speed and few pins, check if the device supports both protocols and pick based on the rest of the system's constraints.
