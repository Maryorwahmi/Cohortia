Module 5 › Chapter 5.2 › Lab: I2C LCD + RTC
Wiring steps
  1. Power both modules at the correct voltage.
  2. Connect SDA to Arduino SDA (A4) and SCL to Arduino SCL (A5).
  3. Confirm pull-up resistors on SDA and SCL.
  4. Run an I2C scanner to list device addresses.
Coding steps
  1. Include Wire and device libraries and instantiate objects with scanned addresses.
  2. Initialize devices in setup and read the RTC in loop.
  3. Update the LCD once per second with the time to avoid flicker.
  4. Test and resolve any address conflicts before proceeding.
Why this matters
Confirming addresses and wiring first ensures your sketches run reliably and helps you find hardware issues quickly.
