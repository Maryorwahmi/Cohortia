Module 5 › Chapter 5.2 › I2C Scanner
What the scanner does
It probes each possible 7-bit address and prints the addresses that respond. Example output commonly shows hex addresses like 0x27 and 0x68.
Interpreter note
The scanner reports presence only; it does not identify device type. Use documentation to map address to part.
Conflict resolution
  • Check if the device allows changing its address via solder pads or jumpers.
  • Use an I2C multiplexer to isolate identical-address modules.
  • Switch one device to SPI if it supports both protocols.
Common mistake
Assuming a detected address equals device type; always cross-check with the module documentation.
