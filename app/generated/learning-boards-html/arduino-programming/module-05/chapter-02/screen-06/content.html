Key code
#include <Wire.h>
#include <LiquidCrystal_I2C.h>
LiquidCrystal_I2C lcd(0x27, 16, 2);
This constructor creates a display object at address 0x27 with 16 columns and 2 rows. The library uses Wire behind the scenes to send bytes.
Example workflow
Initialize the display in setup, then use a print method inside loop to update text from a sensor or RTC. Libraries simplify cursor management and buffering.
Pro tip
Run the I2C scanner before relying on an address found in examples; many breakouts use different defaults.
