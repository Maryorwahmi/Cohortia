Verified Competency Milestone
01
Start serial and print

Use Serial.begin and the print functions to stream debug and sensor values to the Serial Monitor.

VERIFIED COMPETENCY MILESTONE
02
Read incoming bytes

Check Serial.available and use Serial.read to capture incoming data for commands or logging.

VERIFIED COMPETENCY MILESTONE
03
Parse text commands

Buffer characters until a newline and then compare the command to known strings to act on them.

VERIFIED COMPETENCY MILESTONE
04
Use SoftwareSerial

Create an extra software-driven serial port to communicate with another board or serial module when TX/RX are in use.
