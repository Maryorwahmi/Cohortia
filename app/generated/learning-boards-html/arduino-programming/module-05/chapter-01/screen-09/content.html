Module 5 › Chapter 5.1 › Hands-on Activity
Activity steps
  1. Wire the potentiometer to 5V, GND, and the wiper to A0.
  2. Call Serial.begin(9600) in setup and print a ready string.
  3. In loop read analogRead(A0), compute voltage = raw * (5.0 / 1023.0), and print both values.
  4. Implement the command parser to accept "on"/"off" and control pin 13.
Starter code
void setup() {
  Serial.begin(9600);
  pinMode(13, OUTPUT);
}

void loop() {
  int raw = analogRead(A0);
  float voltage = raw * (5.0 / 1023.0);
  Serial.print("Raw: "); Serial.print(raw);
  Serial.print(" Voltage: "); Serial.println(voltage);
  delay(250);
}
Adjust the delay to avoid flooding the monitor. Then add the command parsing loop from earlier so you can type commands while sensor output continues.
