Module 5 › Chapter 5.1 › What is Serial Communication?
Definition

Serial communication is byte-wise data transfer

It uses transmit and receive lines to stream bytes. Arduino’s UART exposes this via Serial and related libraries.

Why it matters
Debugging, remote commands, and communicating with serial modules all rely on serial I/O.
Concrete example
Start Serial at 9600 and print a potentiometer value each second to verify wiring and conversion math.
Common misconception
Serial isn’t only for the computer. Modules and other Arduinos use the same text streams to exchange data.
Key Takeaway

Serial is the simplest universal channel for human-readable debugging and for connecting text-based modules or another board.

Quick reference
void setup() {
  Serial.begin(9600); // start serial at 9600 baud
}

void loop() {
  int raw = analogRead(A0);
  Serial.print("Sensor: ");
  Serial.println(raw);
  delay(1000);
}
Try this example in the IDE’s Serial Monitor and notice how values update. If text looks garbled, check the baud setting.
