Module 5 › Chapter 5.1 › SoftwareSerial Architecture
Core steps
  • Include the SoftwareSerial header.
  • Instantiate with RX, TX pins: SoftwareSerial otherBoard(10, 11);
  • Call otherBoard.begin(9600) in setup to match baud.
  • Cross-wire TX-to-RX, RX-to-TX, and connect grounds.
Wiring reminder
TX of board A → RX of board B, RX of A ← TX of B, and a common ground is required.
Example snippet
#include <SoftwareSerial.h>
SoftwareSerial otherBoard(10, 11); // RX, TX

void setup() {
  otherBoard.begin(9600);
}

void loop() {
  // use otherBoard.print / otherBoard.read
}
SoftwareSerial is convenient for moderate-speed links to modules or another Arduino when pins zero and one are occupied by USB.
