Module 5 › Chapter 5.1 › Learning Objectives

Hands-on Outcomes

Each objective maps to a small working feature you can test in the IDE.

Start serial and print

Outcome: a sketch that prints a potentiometer reading and a labelled voltage to the Serial Monitor.

Read and assemble input

Outcome: a reliable loop that buffers characters until a newline is received.

Parse text commands

Outcome: typed commands like "on" and "off" trigger hardware actions immediately.

SoftwareSerial link

Outcome: two Arduinos exchange messages over user-selected digital pins while USB remains available for the Serial Monitor.
