Sender sketch idea
#include <SoftwareSerial.h>
SoftwareSerial other(10, 11);

void setup(){ other.begin(9600); }
void loop(){
  other.println("temp:23");
  delay(1000);
}
Wire TX of sender to RX of receiver and share ground. Keep messages short and line-terminated for easy parsing.
Receiver sketch idea
#include <SoftwareSerial.h>
SoftwareSerial other(10, 11);
String buffer = "";

void setup(){ Serial.begin(9600); other.begin(9600); }
void loop(){
  while(other.available()){
    char c = other.read();
    if(c == '\n'){
      Serial.println(buffer);
      buffer = "";
    } else buffer += c;
  }
}
The receiver forwards the message to its USB Serial Monitor for inspection. If nothing appears, re-check cross-wiring and baud settings.
