Serial.begin & Baud

Choose and match baud to avoid unreadable output.

Serial.available & read

Use availability checks and buffer bytes until a newline for complete messages.

SoftwareSerial

Create extra ports on any pins and cross-wire TX/RX with shared ground.

Summary

Initialize serial correctly, read safely by buffering until a delimiter, and add software ports when hardware UART is already used.
