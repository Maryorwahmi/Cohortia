Module 5 › Chapter 5.1 › Read Serial Data
Pattern
  1. Initialize an empty command string.
  2. Poll while Serial.available() is true.
  3. Read each byte with Serial.read() and append to buffer.
  4. On newline call handleCommand and clear the buffer.
Common mistake
Blocking reads or assuming read returns a full string. Always treat read as single-byte and use availability checks.
Concrete example
String command = "";

void loop() {
  while (Serial.available()) {
    char c = Serial.read();
    if (c == '\n') {
      handleCommand(command);
      command = "";
    } else {
      command += c;
    }
  }
}
The handler compares the completed string to known commands like "on" or "off" and toggles an LED accordingly.
