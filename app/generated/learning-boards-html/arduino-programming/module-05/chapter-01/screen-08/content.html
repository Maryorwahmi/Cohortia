Starter sketch (visual)
String command = "";

void setup() {
  pinMode(13, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  while (Serial.available()) {
    char c = Serial.read();
    if (c == '\n') {
      handleCommand(command);
      command = "";
    } else {
      command += c;
    }
  }
}

void handleCommand(String cmd) {
  if (cmd == "on") {
    digitalWrite(13, HIGH);
  } else if (cmd == "off") {
    digitalWrite(13, LOW);
  }
}
Explanation and tips
  • Non-blocking: the loop checks Serial.available and proceeds without waiting indefinitely.
  • Exact matching: the handler compares the full string; trim or normalize if your input varies.
  • Monitor settings: ensure the Serial Monitor sends a newline on Enter to match the delimiter used here.
