Module 5 › Chapter 5.1 › Start Serial & Baud
Step-by-step
  1. Choose a baud: common values are 9600 or 115200 depending on speed needs.
  2. Call Serial.begin() in setup with the chosen baud.
  3. Open Serial Monitor and select the same baud to view readable output.
  4. Verify by printing a short confirmation string after begin.
Key Takeaway

Pick a baud and make sure the Serial Monitor matches it before trusting printed data.

Quick code and checks
void setup() {
  Serial.begin(9600); // start at 9600 baud
  Serial.println("ready"); // confirmation string
}

void loop() {
  // send data here
}
If the monitor shows strange characters, stop the sketch, select the sketch baud, and reopen the monitor. Don’t assume faster is always better; choose a rate both your hardware and modules can support reliably.
