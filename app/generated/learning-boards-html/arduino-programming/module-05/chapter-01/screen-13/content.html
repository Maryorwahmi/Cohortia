Module 5 › Chapter 5.1 › Serial & Modules
Concept

Treat many modules as serial endpoints. SoftwareSerial or hardware UART can connect to these modules so you send and receive textual commands and responses.

Bluetooth
Use serial to accept text from a phone app and parse commands just like the Serial Monitor.
GSM / Modems
Send AT commands and read responses through a serial link to the module.
Wi‑Fi modules
Many present a text-based serial API for network requests and status messages.
Next step

After mastering serial I/O, try attaching a Bluetooth module and sending commands from a phone to control outputs and see the same parsing pattern at work.
