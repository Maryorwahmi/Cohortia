Digital pins 0–13
Binary I/O usable for switches, LEDs, and modules at five volts.
Pin count
Fourteen pins labeled 0 through 13 provide digital input or output functionality.
Serial pins caution
Pins 0 and 1 are used for serial communication; avoid reusing them if you plan to monitor serial output or upload frequently.
Practical example
Use any available digital pin to blink an LED, but prefer other pins if you need serial debugging on the USB connection.
Common mistakes
  • Connecting a sensor that requires analog sensing to a digital-only pin expecting 0 or 5V.
  • Using pins 0 or 1 for an output while expecting serial data to arrive reliably.
Check
Before wiring, decide whether you'll use serial. If yes, leave 0 and 1 unused.
