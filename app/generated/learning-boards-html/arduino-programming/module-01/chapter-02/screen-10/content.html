Serial communication basics
Hardware serial uses pins 0 (RX) and 1 (TX); these are tied to the USB interface.
If you attach external devices to pins 0 and 1 while using the serial monitor, you may see conflicts or upload failures.
Software serial can emulate ports on other pins but hardware serial remains on 0 and 1.
Practical example
If you plan to read debug messages with the serial monitor during development, reserve pins 0 and 1 so uploads and monitoring remain reliable.
Check

Before wiring, ask whether you'll need serial debugging. If so, avoid using pins 0 and 1 for other connections.
