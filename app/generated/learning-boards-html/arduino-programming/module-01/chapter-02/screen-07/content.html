Analog inputs A0–A5 and ADC
Measure voltages with a 10-bit converter producing values 0–1023.
ADC details
Ten-bit resolution maps 0–5V to 0–1023 discrete steps.
Example
A sensor reading of about 512 corresponds to roughly 2.5 volts; use that value in code to set thresholds or scaling.
Practical notes
  • Analog pins accept 0–5V. Never expose them to higher voltages.
  • They can double as digital I/O when analog input is not required.
  • Remember discrete steps: sensor noise or small changes may not move the ADC value if they are below one step.
Key Takeaway

Use A0–A5 to read sensors as 0–1023 values; convert back to volts when you need real-world units and protect pins from over-voltage.
