How PWM works
Digital pulses vary duty cycle to produce analog-like results.
PWM pins: ~3,5,6,9,10,11
Duty cycle: percent of time signal is HIGH
Use case: LED dimming or controlling perceived motor speed with drivers
Example
Write increasing duty cycles to a PWM pin to make an LED appear to ramp brighter. Include a resistor and respect per-pin current limits.
Misconception
PWM is not a steady analog voltage; components or filters average the pulses into an effective level.
Step-by-step: dim an LED
  1. Choose a PWM-capable pin marked with a tilde.
  2. Place the LED with a series resistor to the pin and ground.
  3. Set up the sketch to write varying duty cycles and upload.
  4. Observe brightness change and avoid exceeding 20 milliamps for safety.
Key Takeaway

PWM lets digital pins emulate analog outputs by changing duty cycle; always respect current limits and use correct pins.
