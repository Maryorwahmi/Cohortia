Module 1 › Chapter 1.2 › Onboard peripherals
Built-in components you will use
LED on pin 13, reset button, power LED, and ICSP headers each serve a distinct role.
Onboard LED for quick tests: upload a blink sketch to verify programming and basic operation.
Reset button restarts the loaded program and is useful when experimenting with new sketches.
ICSP headers are for advanced programming and for programming the microcontroller externally.
Practical troubleshooting
If your circuit doesn't respond, check the power LED first to confirm the board has power, then test the onboard LED with a known blink sketch to ensure programming and basic I/O work.
Key Takeaway

Use onboard indicators and reset to diagnose power and programming issues quickly before debugging external wiring.
