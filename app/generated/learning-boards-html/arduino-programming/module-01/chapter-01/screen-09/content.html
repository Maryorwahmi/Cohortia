Code walkthrough

// Setup runs once
void setup() {
  pinMode(13, OUTPUT); // configure pin 13 as output
}

// Loop runs forever
void loop() {
  digitalWrite(13, HIGH); // turn LED on
  delay(500);             // wait 500 ms
  digitalWrite(13, LOW);  // turn LED off
  delay(500);             // wait 500 ms
}

Explanation & safety

  • setup() configures hardware once; loop() repeats indefinitely.
  • digitalWrite controls on/off pins; delay pauses execution for testing.
  • Always use a resistor with an LED and confirm the correct pin number for your board.
Misconception
Delay blocks execution; for responsive projects you will later use timers or non-blocking patterns.
Key Takeaway

Blink shows initialization and continuous control: a foundation you will reuse for sensors and actuators.
