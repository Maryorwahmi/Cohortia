Research activity

Find three Arduino projects and write one paragraph each describing inputs, outputs, board choice, and power considerations.

Example A — Weather station
Inputs: temperature and humidity sensors. Outputs: display or network update. Board choice: Uno for basics or a board with Wi‑Fi for direct uploads.
Example B — Smart garden
Inputs: soil moisture, light sensor. Outputs: pump control, status LED. Power: separate supply for pump and common ground.
Example C — Simple robot
Inputs: distance sensors, encoders. Outputs: motor drivers, LEDs. Consider motor drivers and battery capacity early.
Assessment idea
Match five short application descriptions to categories: education, prototyping, art, IoT, automation to test understanding of use cases.
Pro tip
When researching, copy wiring diagrams and list required libraries to speed setup when you build the project.
Key Takeaway

Writing small project summaries trains you to plan components, power, and testing before building.
