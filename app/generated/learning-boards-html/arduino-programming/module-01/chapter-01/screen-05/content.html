Microcontroller

A small computer on one chip designed to run a single embedded program that reads inputs and drives outputs.

Typical components
  • Processor core, flash memory, RAM
  • GPIO pins for inputs/outputs
  • Analog-to-digital converters and timers
Concrete example
Read a temperature sensor, decide to switch a fan, and repeat the check every few hundred milliseconds.
Common misconception
Microcontrollers are not meant to run many desktop-style applications; they are optimized for single-purpose, timely control.
Analogy

Think of a microcontroller as a dedicated traffic light controller that runs the same program to manage signals reliably, while a laptop is like a city manager juggling many tasks.

Check your understanding
Name one project where predictable, repeated behavior is more important than heavy computation, and explain why a microcontroller fits that use.
Key Takeaway

Microcontrollers trade generality for efficiency and predictability, making them ideal for sensors and actuators in embedded systems.
