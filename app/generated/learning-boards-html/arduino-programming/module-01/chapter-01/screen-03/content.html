Evidence & Practice

Short tasks that demonstrate each objective and remove common confusions.

Bloom: Apply
Task 1 — Define Arduino
Draw and label a board, identify a microcontroller, USB, power, and pins. Explain open-source meaning in two sentences.
Task 2 — Microcontroller vs Processor
Write a one-paragraph comparison and give a traffic-light style analogy: a simple controller for signals versus a multi-app computer.
Task 3 — Applications
List three projects and map inputs and outputs for each, for example: temperature sensor → display and fan.
Task 4 — Ecosystem benefits
Find a library and show how it shortens code required to read a sensor or drive a motor.
