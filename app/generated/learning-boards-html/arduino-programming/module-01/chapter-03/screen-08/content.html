What Verify does
Verify runs the preprocessor, compiler, and linker locally to produce a binary. It reports errors if compilation fails.
  • Preprocessor: adds a main function and includes Arduino core headers.
  • Compiler: turns C/C++ into object files.
  • Linker: combines objects with core and library code into the final binary.
Misconception: Verify uploads code — it does not. Upload is a separate transfer step.
