Module 1 › Chapter 1.3 › Select Board & Port
Board selection
Choose Arduino Uno under Boards so the compiler targets the right microcontroller settings.
  • Sets CPU model and clock frequency used by the compiler.
  • Determines which core libraries are linked during build.
  • Wrong board can cause incompatible binaries.
Port selection
Select the serial port that corresponds to the board so the IDE can communicate for uploads.
  • Use disconnect/reconnect to identify the correct COM or /dev entry.
  • If the port is missing, check driver installation and cable quality.
  • When multiple serial devices exist, pick the one that appears after plugging in the board.
Example checklist
Open Tools → Board → select Arduino Uno
Open Tools → Port → pick the new COM or /dev entry
If upload fails, re-check board and port selections
