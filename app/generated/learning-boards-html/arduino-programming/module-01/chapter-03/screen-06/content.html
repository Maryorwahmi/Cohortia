Module 1 › Chapter 1.3 › Connect the Uno
Physical connection
Use a USB A-to-B cable that supports data. A power-only cable will light the board but not allow uploads.
Check the green power LED to confirm power.
If LED is off, try another USB port or cable.
Avoid charging-only cables; they often don't carry data lines.
Identifying the serial port
Use the disconnect-reconnect trick to spot the new port in the IDE's Tools menu.
  • Windows: port appears as COM number.
  • macOS/Linux: port appears as /dev/tty or /dev/cu device path.
  • If no port appears, check drivers or try a different cable.
Example: On Linux the Uno often shows as /dev/ttyACM0; unplugging and plugging helps identify the correct entry.
