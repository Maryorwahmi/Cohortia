Module 1 › Chapter 1.3 › Modify Blink
Change timing to 200 ms
Edit both delay calls to a lower number, verify compile, then upload to the board.
  • Open File → Examples → 01.Basics → Blink.
  • Replace delay(1000) with delay(200) in both places.
  • Click Verify. If successful, click Upload and watch the LED.
Exercise: Try delay(250) and delay(250) for a different rhythm as a hands-on check.
Edited sketch preview
void loop() {
  digitalWrite(LED_BUILTIN, HIGH);
  delay(200);
  digitalWrite(LED_BUILTIN, LOW);
  delay(200);
}
After upload the LED will blink faster. If nothing changes, check port and upload log messages for errors.
