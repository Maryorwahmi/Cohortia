Learning Objectives
Learn the setup and upload workflow so you can move from code to hardware with confidence.
Learn
Understand
Apply
Master
01
Install the Arduino IDE

Download and run the installer for Windows, macOS, or Linux. On some systems accept the USB driver that enables serial communication.

VERIFIED COMPETENCY MILESTONE
02
Connect and identify the board

Plug the Uno with a USB cable. Confirm the green power LED. Identify the serial port by disconnecting and reconnecting if unsure.

VERIFIED COMPETENCY MILESTONE
03
Select board and port in the IDE

Choose Arduino Uno under Boards and choose the matching COM or /dev port so uploads target the correct device.

VERIFIED COMPETENCY MILESTONE
04
Verify and upload Blink

Open the Blink example, verify to compile, upload to transfer the binary, and then modify timing to see immediate hardware feedback.
