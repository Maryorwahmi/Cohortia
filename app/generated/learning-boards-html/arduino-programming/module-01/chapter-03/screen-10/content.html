Key functions
setup runs once to configure pins. loop runs repeatedly to perform the timed behavior.
  • setup: pinMode for the LED pin.
  • loop: digitalWrite to turn LED on and off with delay for timing.
  • delay values are given in milliseconds and control blink speed.
Example sketch (visual)
void setup() {
  pinMode(LED_BUILTIN, OUTPUT);
}

void loop() {
  digitalWrite(LED_BUILTIN, HIGH);   // turn the LED on
  delay(1000);                       // wait 1 second
  digitalWrite(LED_BUILTIN, LOW);    // turn the LED off
  delay(1000);                       // wait 1 second
}
