Build and transfer steps
The IDE runs several tools: preprocessor, compiler, linker, then avrdude for transfer to the bootloader.
Preprocessor: adds main and includes Arduino core.
Compiler: source to object files.
Linker: combine objects and libraries into a binary.
avrdude: sends the binary to the bootloader over serial.
Concrete example

When you press Upload, the IDE may run verify again, then avrdude transfers the binary. If avrdude reports a connection error check the port and that the bootloader is present on the ATmega328P.

Misconception: IDE writes flash directly. Instead, avrdude and the bootloader perform the write.
Takeaway: Understanding the chain helps locate failures to either build or transfer stages.
