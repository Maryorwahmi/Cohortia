Calculation
I = V / R = 5V / 330Ω ≈ 0.01515 A, or 15.2 mA. This is a practical LED current value when a forward drop has been accounted for.
Why use a resistor?
The resistor limits current so the LED and microcontroller pin do not exceed their safe current ratings. Without it a short-like condition can occur.
Explain in one sentence
A resistor is required to set the current through the LED to a level that both the LED and Arduino pin can safely handle.
Extension
