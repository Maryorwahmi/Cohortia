Module 2 › Chapter 1.4 › Resistor sizing
Process

Five steps to choose a resistor

1
Know supply and LED forward voltage.
2
Compute resistor voltage: Vdrop = Vsupply − Vled.
3
Choose a target current (e.g., 10–20 mA).
4
Compute R = Vdrop / I (use amps).
5
Pick the nearest equal or larger standard resistor.
Example
With 5V supply and a 2V LED drop, Vdrop is 3V. For 15 mA target current, R = 3V / 0.015 A = 200 ohms. Choose 220 ohms as the nearest common value.
Try it
Start with 220 ohms, observe brightness, then swap to 1k to see the brightness decrease, confirming the current dropped.
