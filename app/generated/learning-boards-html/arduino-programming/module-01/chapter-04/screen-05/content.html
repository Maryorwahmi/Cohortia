Module 2 › Chapter 1.4 › Ohm's Law
Definition

V = I × R

Learn the rearrangements and unit consistency to compute current or resistance accurately in LED circuits.

I = V / R
Current in amps when voltage across the resistor and resistance are known.
R = V / I
Choose resistor value to obtain a target current.
Worked example
Suppose a 5V pin drives a red LED with a 2V forward drop and you want safe LED current. The resistor sees 3V. For a 220-ohm resistor, current is I = 3V / 220Ω ≈ 0.0136 A, or 13.6 milliamps. This is within a typical safe range for an LED and an Arduino output pin.
Common mistake
Do not use the supply voltage directly when an LED or other device has a significant forward voltage. Subtract the device drop first before computing resistor current.
