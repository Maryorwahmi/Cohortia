Troubleshooting steps
  • Check wiring of Trig and Echo pins and ensure correct pinMode settings.
  • Use microsecond timing for trigger pulses and brief pauses between measurements.
  • Average multiple readings and discard zeros before using distance values.
  • Tune PIR sensitivity and hold time to reduce false positives.
Assessment idea
If Echo pulse = 1000 microseconds, distance = 1000 × 0.034 ÷ 2 ≈ 17 cm. This verifies you can apply the conversion correctly.
Concrete example
If readings fluctuate, log several values to the serial monitor, compute the average of valid samples, and use that averaged value to decide buzzer behavior. This reduces flicker and false alarms.
Key Takeaway
Measure carefully, validate readings, and tune hardware settings. Clear tests with known distances help confirm expected sensor behavior.
