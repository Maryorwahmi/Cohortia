Module 4 › Chapter 4.2 › Parking Sensor Activity
Activity steps
  1. Wire ultrasonic sensor and buzzer to Arduino.
  2. Trigger sensor, read echo duration, convert to cm.
  3. Map distance ranges to buzzer intervals.
  4. Validate readings and test with moving objects.
Validation rules
Discard zero or out-of-range values. Average multiple reads for smoother beep transitions.
Concrete mapping example
Distance < 20 cm → 100 ms beep interval. 20–50 cm → 400 ms interval. > 50 cm → silent. Tune ranges to match your vehicle and environment.
Key Takeaway
Map measured distance to a clear, perceivable behavior and validate readings to reduce false alerts.
