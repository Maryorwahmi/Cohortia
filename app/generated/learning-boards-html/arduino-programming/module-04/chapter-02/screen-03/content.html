Module 4 › Chapter 4.2 › Objective Milestones
01 — HC-SR04 stopwatch
Mnemonic: trigger pulse then stopwatch on echo. Milestone: consistent serial output in centimeters.
02 — PIR tripwire
Mnemonic: infrared pattern change toggles output. Milestone: LED lights on motion.
03 — Combine gate
Mnemonic: motion opens gate for distance checks. Milestone: beeping only when motion is present and object is close.
04 — Timing conversion
Mnemonic: travel time equals distance times the speed of sound; remember to divide by two for return trip. Milestone: compute distances from example durations.
Verified Competency Milestone
Complete the parking sensor: HC-SR04 gives distance, PIR gates measurements, buzzer speed changes with proximity. This confirms wiring, timing, and integration skills.
