Practical debugging checklist

  • Is Echo connected to the input pin and returning HIGH pulses?
  • Are you using microsecond timing for the trigger pulse?
Concrete example
If pulseIn returns 1000 microseconds and you apply the factor, you get roughly 17 cm. If readings jump wildly, average several successive measurements before displaying them.
Key Takeaway
pulseIn gives duration; convert and validate with the serial monitor. Add pauses and averaging to improve stability.
