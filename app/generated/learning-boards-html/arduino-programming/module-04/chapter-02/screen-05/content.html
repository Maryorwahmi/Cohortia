Module 4 › Chapter 4.2 › Wiring & Trigger Sequence
Wiring
  • VCC → 5V, GND → GND
  • Trig → Digital output (e.g., pin 9)
  • Echo → Digital input (e.g., pin 10) to measure pulse duration
Use stable power and short wiring to reduce noise.
Trigger sequence
Stabilize LOW, pulse HIGH for 10 microseconds, then measure Echo pulse duration in microseconds.
Process steps
1. Ensure sensor has power and ground. 2. Set trigger LOW then HIGH for ten microseconds. 3. Read the echo duration with a pulse measurement. 4. Convert to centimeters using the conversion factor.
Example wiring note
If the echo pin remains LOW, confirm the Trig pulse timing and that Echo is connected to the input pin able to be read by your timing function.
Pitfall
Using long delays around the trigger can distort timing precision. Use microsecond delays for trigger timing.
