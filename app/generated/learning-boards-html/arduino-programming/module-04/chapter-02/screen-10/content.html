Module 4 › Chapter 4.2 › Design: Combine Sensors
Flow outline
1. Read PIR output. 2. If PIR LOW, do nothing (sleep or wait). 3. If PIR HIGH, trigger ultrasonic sensor. 4. Read echo duration and convert to distance. 5. Map distance to output (buzzer rate, LED intensity).
Example mapping
Distance < 20 cm → fast beeps; 20–50 cm → slower beeps; >50 cm → silence.
Timing trade-offs
Short intervals make the system responsive but increase noise and power use. Use the PIR hold time to avoid unnecessary frequent distance reads.
Concrete scenario
A parking sensor runs only when the PIR sees motion near the vehicle. While enabled, the ultrasonic sensor measures distance and adjusts beep frequency as the car approaches a barrier.
Key Takeaway
Gating measurements with PIR reduces unnecessary work and improves reliability; map distance readings to clear output behaviors for the user to interpret.
