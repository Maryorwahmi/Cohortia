Module 4 › Chapter 4.2 › Add PIR Gate
Integration steps
  • Wire PIR OUT to a digital input.
  • In the loop, read PIR first and skip ultrasonic if LOW.
  • When PIR HIGH, perform distance measurement and act.
Tuning
Adjust the PIR hold time to decide how long the ultrasonic sensor keeps measuring after the last detected motion.
Concrete example
PIR LOW → idle. PIR HIGH → measure distance; if distance < 20 cm, sound fast buzzer. Use an LED to indicate the PIR-gated active state for debugging and user feedback.
Key Takeaway
Gating distance reads with PIR improves responsiveness and reduces unnecessary sensing when the area is empty.
