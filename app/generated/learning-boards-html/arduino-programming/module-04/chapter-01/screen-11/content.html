Module 4 › Chapter 4.1 › Hands-on Activity
Steps
  1. Install the DHT library via Library Manager and open the example.
  2. Wire the DHT11 power, ground, and data pin to the designated digital pin.
  3. Verify Serial Monitor prints humidity and temperature every two seconds.
  4. Add an LED on a digital output and write a threshold comparison to switch it on when temperature exceeds your set point.
Example scenario
Set the LED threshold to 28°C for a simple alert. Observe how the Serial Monitor confirms the measured temperature before the LED changes state.
Checkpoints
  • Serial prints sensible values.
  • LED responds when the measured temperature crosses the threshold.
  • Document how placement changed your results.
Assessment idea
Given a TMP36 voltage of 0.73 volts, calculate the temperature. Use the TMP36 formula to show steps and final answer.
