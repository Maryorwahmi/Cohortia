Module 4 › Chapter 4.1 › DHT11 / DHT22
Protocol Flow
  1. Install the DHT library via the Arduino Library Manager.
  2. Include the library and create a sensor object with the pin and type.
  3. Call the library’s begin method in setup to initialize timing.
  4. In loop, call readHumidity and readTemperature and check for valid values.
Model note
DHT22 generally offers better accuracy and range than DHT11; consult the datasheet before choosing.
Example Wiring & Check
Power the sensor, connect data to a digital pin with a pull-up when required, and run the library example. If the Serial Monitor shows sensible humidity and temperature every two seconds, wiring and code are likely correct.
Common mistake
Skipping the library leads to fragile timing code and unreliable readings under different CPU loads.
