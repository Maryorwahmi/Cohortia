Module 4 › Chapter 4.1 › Analog vs Digital
Definition

Analog outputs

A sensor that varies its voltage with the measured condition. The Arduino reads the voltage with analogRead and converts the ADC value to a voltage using the board reference.

Key formula
Voltage = (reading / 1023.0) × Vref
Concrete example
TMP36 gives 750 mV at 25°C; scale is 10 mV per °C with a 500 mV offset.
Common mistake
Reading a digital sensor with analogRead will return meaningless voltages or floating values; use the correct protocol.
Definition

Digital outputs

A sensor that communicates using a defined protocol over one or more wires. DHT sensors send timed pulses representing humidity and temperature values; you normally use a library to parse them.

Why libraries help
Libraries implement precise timing and parsing, avoiding fragile manual implementations that often fail under load.
Takeaway
Match your read method to the sensor type: analogRead for voltages, library calls for timed digital protocols.
