How it works
Place the LDR and a resistor in series between Vcc and ground. Read the mid-point voltage with analogRead. The midpoint voltage varies with light because the LDR’s resistance changes.
Calibration steps
Record ADC values in bright and dark conditions, then map range to 0–100% or choose a working threshold for your project.
Concrete example
If your ADC reads 900 in bright light and 120 in darkness, you can compute a percentage using linear mapping or set a threshold, for example below 300 as 'dark'.
Common mistake
Using the wrong fixed resistor can make the voltage range too small. Choose the resistor to produce a useful voltage span across expected lighting conditions.
