Module 4 › Chapter 4.1 › DHT Example
Sketch (visual excerpt)
#include "DHT.h"
#define DHTPIN 2
#define DHTTYPE DHT11
DHT dht(DHTPIN, DHTTYPE);

void setup() {
  Serial.begin(9600);
  dht.begin();
}

void loop() {
  float h = dht.readHumidity();
  float t = dht.readTemperature();
  Serial.print("Humidity: ");
  Serial.print(h);
  Serial.print("%  Temperature: ");
  Serial.print(t);
  Serial.println("C");
  delay(2000);
}
Guide & Troubleshooting
  • Install the DHT library via Library Manager then open the example sketch to test.
  • Ensure the correct sensor type constant matches your sensor (DHT11 or DHT22).
  • If you see NaN or invalid readings, check wiring, power, and pin assignments before debugging code timing.
Practical tip
Run the example to verify the library and Serial Monitor output, then integrate the calls into your main loop and add error checks.
