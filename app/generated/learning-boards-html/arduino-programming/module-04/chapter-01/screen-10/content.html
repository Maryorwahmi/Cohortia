Module 4 › Chapter 4.1 › MQ-2
How to use
Connect Vcc, GND, and the analog output to an ADC pin. After power-up, wait the datasheet-recommended warm-up time before taking important measurements.
Practical use
Use MQ-2 for alarms or relative air-quality measurements, then choose thresholds based on observed baseline readings after warm-up.
Common issues
  • Not allowing warm-up time produces unstable or drifting values.
  • Expecting calibrated gas concentration without a calibration curve is unrealistic for many MQ modules.
  • Use relative thresholds and test in the target environment to set alarm points.
Takeaway
Treat MQ outputs as analog indicators. Warm-up, calibrate to baseline, then set thresholds for alarms or logging.
