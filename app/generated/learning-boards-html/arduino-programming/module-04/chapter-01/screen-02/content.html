Learning Objectives

Understand and apply sensor reading techniques across analog and digital sensors.

Bloom: Learn → Understand → Apply → Master
01
Read analog temperature
Convert TMP36 or LM35 voltage into Celsius using the sensor formula from its datasheet. This ensures correct calibration.
VERIFIED COMPETENCY MILESTONE
02
Use DHT11/DHT22
Install and call the DHT library to read humidity and temperature reliably without manual timing.
VERIFIED COMPETENCY MILESTONE
03
Read light with an LDR
Use an LDR in a voltage divider and convert the ADC reading into a percentage or threshold for light/dark detection.
VERIFIED COMPETENCY MILESTONE
04
Use datasheets & libraries
Find conversion formulas and wiring notes in datasheets, and install libraries to handle complex protocols safely.
VERIFIED COMPETENCY MILESTONE
