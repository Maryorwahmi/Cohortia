From learning to doing

Each objective below links to a short, verifiable task so you can confirm the skill on your board.

01 • I2C Wiring Check
Scan for device addresses, power the display, and confirm the backlight comes on when initialized in code.
Mnemonic: scan → power → init
02 • Labeled Values
Print a label and a numeric value with units. Confirm the value updates without trailing characters.
Mnemonic: label + units
03 • OLED Pixel Test
Draw a rectangle or line and update a numeric readout to confirm buffer updates and contrast.
Mnemonic: pixels = freedom
04 • Formatting & Refresh
Format decimals to a readable length and limit refresh to avoid flicker; use overwrite or clear methods when needed.
Mnemonic: trim and pace
