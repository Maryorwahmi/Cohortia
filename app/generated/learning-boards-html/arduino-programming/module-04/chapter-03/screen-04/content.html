Definition

How character LCDs render text

A character LCD maps characters to fixed cells. Each cell displays a glyph from the module's character set.

Key properties
  • Fixed grid: columns × rows (for example 16×2)
  • Predefined glyphs for letters/digits
  • Simple APIs: setCursor, print, clear
Common-mistake
Expecting automatic erasure when new text is shorter; remember to clear or overwrite.
Example
lcd.setCursor(0,0) // position
lcd.print("Temp:") // label
lcd.setCursor(0,1) // second row
lcd.print("23 C") // value
Takeaway
Use character LCDs for clear text readouts and labeled values.
Pro tip
When updating values, either clear line or print fixed-width fields to avoid leftovers.
