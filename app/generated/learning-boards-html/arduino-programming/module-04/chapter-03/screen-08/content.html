Module 4 › Chapter 4.3 › OLED vs LCD
OLED (SSD1306)
Pixel-addressable, supports text and shapes, high contrast, draws graphics such as icons and small plots.
Use case
Status bar with icons and a tiny graph next to a numeric readout.
Library
Use Adafruit SSD1306 to draw pixels, lines, and text buffers.
Character LCD
Grid of characters, simpler API for text, excellent for labeled readings and menus where fixed-width columns matter.
Use case
Show two labeled values like "Temp" and "Humidity" with units on separate rows.
Library
LiquidCrystal_I2C gives setCursor and print primitives for easy text placement.
Key Takeaway

Both use I2C and share wiring simplicity. Pick OLED for graphics and fine layout, LCD for simple, readable text labels.
