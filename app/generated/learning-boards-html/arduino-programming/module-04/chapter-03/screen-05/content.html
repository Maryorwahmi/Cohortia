Module 4 › Chapter 4.3 › I2C Wiring
Process

Steps to wire and verify an I2C display

1
Attach power
Connect VCC to 5V (or 3.3V if appropriate) and GND to ground.
2
Connect data lines
Wire SDA to the board's SDA pin and SCL to SCL. Use pull-ups if your board lacks them.
3
Scan the bus
Run an I2C scanner sketch to find the device address, commonly 0x27 or 0x3F.
4
Initialize in code
Use the detected address when creating your display object so commands reach the device.
Why it matters

Fewer pins and simpler wiring make prototypes neater and free up microcontroller GPIO for sensors and controls. Multiple displays or sensors can share the same bus when addresses don't collide.

Common-mistake
Assuming address conflicts are resolved automatically; if two devices share an address you'll need an addressable module or multiplexer.
Check your understanding
After wiring, does the display power LED light and does an I2C scan return an address? If not, re-check SDA/SCL and power pins.
