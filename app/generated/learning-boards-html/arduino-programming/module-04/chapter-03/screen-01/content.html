Displays: Character LCD and OLED

Wire via I2C, install the right library, and format sensor output so the screen stays clear and readable.

Duration: ~10 minutes • Beginner
Character LCD
Text using character blocks. Common: 16x2, 20x4.
OLED SSD1306
Monochrome pixels. Draw text, shapes, and simple graphics.
Formatting
Control decimals, clear old text, and refresh at a moderate rate.
Explore Key Topics
I2C Wiring
VCC, GND, SDA, SCL reduce pins and simplify wiring.
Libraries
LiquidCrystal_I2C for LCD, SSD1306 for OLED rendering.
Best Practices
Clear unused characters, limit refresh rate, and format decimals.
Visual Concept
I2C Backpack
Converts many parallel pins into SDA and SCL for simpler wiring.
Common addresses: 0x27 or 0x3F for many backpacks.
Quick Start Example
#include <LiquidCrystal_I2C.h>
LiquidCrystal_I2C lcd(0x27, 16, 2);

void setup() {
  lcd.init();
  lcd.backlight();
  lcd.setCursor(0, 0);
  lcd.print("Hello, Arduino!");
}

void loop() {
  lcd.setCursor(0, 1);
  lcd.print(millis() / 1000);
  lcd.print(" sec");
}
