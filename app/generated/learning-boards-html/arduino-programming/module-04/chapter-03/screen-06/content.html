Code Pattern
#include <LiquidCrystal_I2C.h>
LiquidCrystal_I2C lcd(0x27, 16, 2);

void setup() {
  lcd.init();
  lcd.backlight();
  lcd.setCursor(0,0);
  lcd.print("Temp:");
}

void loop() {
  lcd.setCursor(0,1);
  lcd.print(millis() / 1000);
  // clear or overwrite shorter text to avoid leftover chars
}
Explanation
  • lcd(0x27,16,2) — creates the object using the detected I2C address and dimensions.
  • lcd.init() — initializes the controller; required before commands.
  • lcd.backlight() — turns on backlight if supported by the backpack.
  • setCursor() — positions where subsequent prints will appear.
Example Scenario
Show elapsed seconds updating every two seconds with a fixed-width field to avoid residue.
Misconception
Assuming lcd.print replaces the entire line; shorter strings can leave old characters.
