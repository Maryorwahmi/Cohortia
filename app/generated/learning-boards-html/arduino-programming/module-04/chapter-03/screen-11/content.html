Wiring & Setup
  1. Power: connect VCC and GND for both display and DHT11.
  2. I2C: wire SDA and SCL from the display to the SDA/SCL pins of the board.
  3. Sensor: connect the DHT11 data pin to a digital input and a pull-up if needed.
  4. Code: run I2C scanner, then use the found address in your LiquidCrystal_I2C constructor.
Example Labels
Row 0: "T: 23.4 C" Row 1: "H: 46.8 %" — include units for clarity.
Loop Strategy
Read sensor every two seconds. Format values, compare with previous readings, and update the display only when changed or on the timer to avoid flicker and bus congestion.
Assessment Idea
Ask: Why is I2C preferred over parallel wiring for LCDs? Expected answer: It uses fewer pins and simplifies wiring while supporting multiple devices on the same bus.
