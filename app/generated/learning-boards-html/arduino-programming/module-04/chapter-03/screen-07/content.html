Module 4 › Chapter 4.3 › Clearing & Updating
Approaches
Clear display
Call clear before printing. Simple but can flicker if used frequently.
Overwrite with fixed width
Format values to fixed length or pad with spaces to fully overwrite previous text.
Conditional refresh
Only update when the value changes beyond a threshold or at a controlled interval to reduce flicker.
Concrete Example
Show temperature to one decimal place and update only when it changes by 0.1 degrees. If new text shorter than previous, write trailing spaces to erase remnants.
Check your understanding
If the previous value was "100.00" and the new value is "99.9", what will you see unless you clear or pad? There will be leftover characters like a hanging "0" at the end.
