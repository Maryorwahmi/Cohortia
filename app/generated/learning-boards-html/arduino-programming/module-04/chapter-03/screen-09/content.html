Explanation & Tips
  • Buffered updates — draw everything to memory and call display once per frame.
  • Drawing helpers — use drawPixel, drawLine, drawRect, and setTextSize for layout.
  • No backlight — OLEDs are emissive; contrast is typically high without a backlight.
Example Scenario
Draw a progress bar by filling a rectangle proportionally, then print a number above it. Update the buffer less frequently to save power.
