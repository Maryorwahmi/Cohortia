Module 5 › Chapter 4.4 › Servo Comparison
Standard servo
Designed for discrete angle positioning with internal feedback and limited rotation range.
  • Moves to an angle and holds position.
  • Useful for robot joints, control surfaces, and actuated linkages.
  • Command with write(angle) where angle is 0–180 degrees.
Example
A robotic gripper rotates to 45 degrees to pick an object and holds there until released.
Continuous-rotation servo
Mechanically modified to rotate freely; interprets angle commands as speed and direction rather than absolute position.
  • Maps center command to stop; other values control rotation speed and direction.
  • Useful for small wheeled robots and simple drive mechanisms.
  • Treat as a compact motor with integrated controller rather than a positional servo.
Example
A toy car uses two continuous servos for left and right wheel drive, controlled by PWM-like angle values mapped to speed.
