Module 5 › Chapter 4.4 › PWM Speed Control
How PWM works
The microcontroller outputs a fixed-amplitude square wave and the duty cycle determines average power to the motor.
Use analogWrite on PWM pins to vary duty cycle. For safe operation, gate the PWM through a MOSFET or driver; the Arduino pin only provides the gate signal, not motor current.
Practical tip
Ramp PWM gradually when starting motors to reduce inrush current and mechanical stress.
Example
Connect PWM pin → MOSFET gate, MOSFET drain → motor negative, motor positive → external supply positive. Call analogWrite with values from 0 to 255 and observe proportional speed change.
Common mistake
Driving motor current directly from a PWM pin will overload the pin and cause resets or damage.
