Module 5 › Chapter 4.4 › Servo Code
Code walkthrough
Include the library, attach to a pin, then write angles. Map analog input to angles for manual control.
#include <Servo.h>
Servo myServo;

void setup() {
  myServo.attach(9);
}

void loop() {
  myServo.write(0);
  delay(1000);
  myServo.write(90);
  delay(1000);
  myServo.write(180);
  delay(1000);
}
Extension: potentiometer control
Read analog input, map to 0–180, and write that value to the servo for manual positioning.
Common pitfalls
  • Not providing enough current: servo stalls or causes Arduino resets.
  • Missing common ground: signal reference floats and servo behaves erratically.
  • Calling write in very tight loops without travel time makes motion look noisy.
Key Takeaway
The Servo library hides timing details so you can command angles directly; ensure power and grounding match the hardware's needs.
