Servo motor — definition and parts
Power, ground, and signal; internal motor, gears, potentiometer, and control board provide closed-loop position control.
Typical wiring
Red: Vcc (usually 5V), Brown/black: GND, Yellow/orange: signal to PWM-capable pin.
Internal behavior
Servo electronics convert signal timing into a target angle and drive the motor until the feedback potentiometer matches the target.
Common misconception
Unlike a bare DC motor, a standard servo holds a commanded angle without continuous external feedback circuits — the feedback is built in.
Concrete example
Use the Servo library on Arduino: attach the servo to pin 9 and write angles like 0, 90, and 180 to sweep an arm. The library abstracts pulse timing so you simply command angles.
Example code
#include <Servo.h>
Servo myServo;

void setup() {
  myServo.attach(9);
}

void loop() {
  myServo.write(0);
  delay(1000);
  myServo.write(90);
  delay(1000);
  myServo.write(180);
  delay(1000);
}
Key Takeaway
Servos make angle control simple but pick standard versus continuous based on whether you need absolute position or continuous rotation.
