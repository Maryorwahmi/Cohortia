Module 2 › Chapter 2.1 › Final Reminders
Setup = init
One-time hardware and state configuration belongs here.
Loop = repeat
Continuous checks and updates run here as long as the board is powered.
Timing choice
Delay is easy but blocking; switch to non-blocking timing when responsiveness matters.
Final Takeaway

Practice with a blink sketch and an input check to make the lifecycle concrete and to learn when to use blocking or non-blocking timing.
