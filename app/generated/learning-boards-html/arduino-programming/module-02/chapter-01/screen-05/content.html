Module 2 › Chapter 2.1 › setup() Details
Process

Place one-time initialization here

  • Configure hardware: pinMode, attach devices.
  • Start services: Serial.begin or library initialization.
  • Load persistent configuration such as EEPROM reads.
Checklist
If the action must happen once at start-up, it belongs in setup. If repeating it has no added benefit, keep it in setup.
Concrete scenario
Reading calibration from EEPROM belongs in setup so you configure sensors once and then use calibrated readings every loop. Re-reading EEPROM each cycle both wastes time and shortens EEPROM life.
Common misconception
People sometimes place pinMode inside loop thinking it is harmless; repeated calls are redundant and make the loop do unnecessary work.
Key Takeaway
Keep initialization in setup to avoid repeated configuration and to ensure predictable startup behavior.
