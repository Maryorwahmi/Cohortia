Module 2 › Chapter 2.1 › Timing
Definition

delay pauses execution

Use milliseconds to pause; simple but blocking. Good for demos, not for multi-tasking.

A one-thousand millisecond pause equals one second.
During delay the CPU does nothing else; inputs are not checked until the pause ends.
Example and alternatives
If a button must be handled quickly, avoid long delays. Instead store the current time and check elapsed milliseconds each pass so other checks run while waiting.
Common mistake
Using long blocking delays in interactive projects leads to poor responsiveness and missed events.
Key Takeaway
Use delay for simple timing but switch to non-blocking timing techniques for responsive multi-tasking sketches.
