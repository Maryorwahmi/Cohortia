Module 2 › Chapter 2.1 › Sketch Minimalism
Definition

Two functions form every sketch

Setup runs once at power-up. Loop runs repeatedly. The core connects them via an automatic main entry point.

When to use setup
One-time configuration such as pin settings and initializing serial communication.
When to use loop
Continuous tasks: sensor reads, button checks, and updating outputs repeatedly.
Concrete example
Setup: configure the built-in LED pin as an output. Loop: turn the LED on, wait, turn it off, wait, repeat.
Common mistake
Placing initialization inside loop causes repeated setup and wasted cycles.
Pro tip
Keep loop focused on checks and updates; move heavy or one-time tasks into setup.
Key Takeaway

Treat setup as preparation and loop as the ongoing control cycle; that discipline keeps sketches clear and efficient.
