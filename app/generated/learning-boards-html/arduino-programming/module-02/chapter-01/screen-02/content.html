Learning Objectives

What you will learn and why it matters

Bloom: Learn → Understand → Apply → Master
01
Identify setup and loop

Explain the two required functions and give examples of typical code found in each, so you can structure sketches correctly.

Verified competency milestone
02
Separate init vs repeat

Describe initialization tasks like pin setup versus repeated checks such as sensor reads, so your code stays efficient and predictable.

Verified competency milestone
03
Understand hidden main()

Understand that the Arduino core adds a main entry point which calls your setup once and then repeatedly calls loop, clarifying program flow.

Verified competency milestone
04
Write a simple sketch

Create a blink program that initializes a pin and toggles the LED, then modify timing values to observe effects on behavior.

Verified competency milestone
