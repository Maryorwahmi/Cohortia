Check how often code runs

Small experiments reveal whether an action belongs in setup or loop.

Assessment question
If a print is in setup it prints once; in loop it prints every cycle. Use this to prove placement.
Debug tip
Add temporary prints, timestamps, or LED toggles to measure loop timing and spot repeated initializations.
Reflective question

What single state must your device set at startup for it to behave predictably? Answering that guides correct placement.
