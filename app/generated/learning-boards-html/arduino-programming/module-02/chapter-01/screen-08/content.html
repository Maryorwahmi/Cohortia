Module 2 › Chapter 2.1 › Blink Example
Example Code
void setup() {
  pinMode(LED_BUILTIN, OUTPUT);
}

void loop() {
  digitalWrite(LED_BUILTIN, HIGH);
  delay(1000);
  digitalWrite(LED_BUILTIN, LOW);
  delay(1000);
}
This code configures the built-in LED pin once, then toggles the LED with one-second pauses.
Explanation cards
Initialization
pinMode sets the LED pin as an output so digital writes control the LED.
Repeating action
digitalWrite combined with delay produces the visible blink pattern each cycle.
Blocking note
While delay is active the microcontroller does not perform any other code, which affects responsiveness.
Try this

Change the pause values to see how the blink speed and responsiveness change, and observe behavior when you place pinMode inside loop.
