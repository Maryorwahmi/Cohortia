Apply and Check

Concrete checks and common misconceptions to watch for.

Hands-on
Write a blink that toggles the built-in LED on and off. Change timings and observe behavior.
Quiz
If you print in setup, it prints once; in loop it prints repeatedly. Explain why.
Misconception
Don't place initialization inside loop or the device will reconfigure every cycle and waste time.
Key Takeaway

Test your sketch structure by moving one action between setup and loop and observing how often it runs; that confirms understanding.
