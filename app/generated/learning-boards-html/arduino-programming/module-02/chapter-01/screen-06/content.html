Module 2 › Chapter 2.1 › loop() Details
Definition

Repeat tasks continuously

  1. Read sensors and user inputs.
  2. Update internal state and decide actions.
  3. Write outputs to LEDs, motors, or displays.
Design note
Keep each loop pass short. If you block for long periods, other checks will be delayed.
Concrete example
A loop that toggles an LED and calls a one-second pause will produce a visible blink, but during each pause the microcontroller does not check buttons or sensors.
Misconception
Assuming loop runs at a fixed rate. It runs as fast as the contained code allows and slows when heavy or blocking tasks are present.
Pro tip
Favor splitting long work across multiple passes or use non-blocking checks so other tasks remain responsive.
Key Takeaway

Design loop so repeated checks are quick and non-blocking when you need multiple inputs or outputs handled simultaneously.
