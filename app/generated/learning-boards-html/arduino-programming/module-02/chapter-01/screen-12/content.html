Module 2 › Chapter 2.1 › Hands-on

Change blink durations and observe

A small lab to compare blocking delay with non-blocking timing.

Step 1
Run a blink with 500 ms on and 500 ms off. Observe LED speed.
Step 2
Modify to 2000 ms on and 250 ms off. Observe perceived brightness and responsiveness.
Step 3
Add a button check that prints when pressed. Notice delayed prints if delays are long.
Step 4
Optionally replace delay with non-blocking timing so the loop can still check the button between toggles.
Key Takeaway

Try both blocking and non-blocking timing to decide which fits your project needs: simplicity versus responsiveness.
