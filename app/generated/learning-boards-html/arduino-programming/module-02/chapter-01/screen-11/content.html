Comparison

Initialization vs repeating logic

Initialization (setup)
Pin modes, Serial begin, persistent reads. Execute once for efficiency and correctness.
Repeating (loop)
Sensor reads, button checks, output updates. Execute every cycle to react to changes.
Concrete test
Move a pinMode or print call between setup and loop and observe how often it executes to confirm correct placement.
Key Takeaway

Separating responsibilities reduces bugs and keeps your sketch efficient and predictable as it grows.
