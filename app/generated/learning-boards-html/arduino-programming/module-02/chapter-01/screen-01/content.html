Setup & Loop: the program shape

Learn how initialization and repeating logic partition a sketch, and why that pattern suits embedded systems that run indefinitely.

Orientation
The board runs setup once then loop forever; design your code with that lifecycle in mind.
Practical focus
You will write a blink sketch and then change timings to see how blocking delays change behavior.
Explore Key Topics
Initialization
What you set once at start-up.
Repeating Logic
Behavior checked and updated continuously.
Timing & Delay
How pauses affect responsiveness.
Visual Concept
Setup
Run once at start. Configure pins and communication.
Loop
Run repeatedly. Read sensors, update outputs continuously.
A hidden main function calls setup once, then drives loop in a continuous cycle.
Key Takeaway

Design your sketch by placing initialization in setup and ongoing checks and updates in loop so the device runs reliably over time.
