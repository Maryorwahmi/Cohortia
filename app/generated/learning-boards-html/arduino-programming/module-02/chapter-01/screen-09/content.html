Comparison

setup vs loop for pinMode

Call pin configuration once in setup to place the pin into the correct mode. Calling it in every loop is redundant and inefficient.
setup placement
Runs once; efficient and predictable.
loop placement
Repeated reconfiguration wastes cycles and provides no practical benefit.
Concrete usage
Use the built-in LED name when available to avoid guessing board pin numbers. Set it as an output in setup and toggle it in loop for a blink.
Common mistake
Believing reconfiguring a pin fixes a wiring mistake; configuration only defines behavior, it does not change wiring errors.
Key Takeaway

Configure pins once in setup and use clear constants for common pins to write readable and efficient sketches.
