LED fading with for loops
Iterate PWM values for a smooth brightness transition.
Code sketch (concept)
for (int i = 0; i <= 255; i++) {
  analogWrite(LED_PIN, i);
  delay(5); // short pause for visible fade
}
for (int i = 255; i >= 0; i--) {
  analogWrite(LED_PIN, i);
  delay(5);
}
This counted approach gives smooth, repeatable fades. Replace delay with time checks for non-blocking behavior when reading sensors concurrently.
Why it matters

Shows a concrete hardware effect and reinforces choosing for when counts are known.

Common mistake

Using long delays inside fade loops prevents the sketch from reading sensors or responding to inputs while fading.

Key Takeaway

Use for for known ranges; refactor into timed steps if you need concurrent responsiveness.
