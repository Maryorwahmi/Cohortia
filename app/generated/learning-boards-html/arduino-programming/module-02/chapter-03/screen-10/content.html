Loops compared
Choose the loop that matches count and control needs.
for
Best when the number of iterations is known. Example: iterate PWM values 0 to 255 to fade an LED.
while
Best when waiting for an external condition. Example: wait until a sensor reading exceeds a threshold.
do-while
Run once then test. Example: perform an initial calibration step, then repeat if needed.
Practical tip

Avoid blocking operations inside loops when the device must remain responsive. Use elapsed-time checks and state updates instead of long delays.
