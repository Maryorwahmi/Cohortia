Module 2 › Chapter 2.3 › Practice Roadmap
Coding Activities
Implement threshold detection, blink and fade LEDs with loops, trace nested loops, and build a menu with switch.
Assessment Ideas
Trace output of nested loops, write a non-blocking 10-blink loop, and implement sensor thresholds with actions.
Instructor Tips
  • Start with flow examples: traffic light for conditionals, conveyor belt for counted loops.
  • Highlight off-by-one and infinite loop risks early.
  • Encourage testing with serial prints before wiring hardware.
Mini Challenge
Read a light sensor and print Daytime/Evening/Night; turn an LED on only at night.
