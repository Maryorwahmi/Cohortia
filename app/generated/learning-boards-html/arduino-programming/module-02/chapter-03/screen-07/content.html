Process Flow
for loops — conveyor-belt counting
Initialization, test, increment — repeat a known number of times.
Code example
for (int i = 0; i < 5; i++) {
  Serial.println(i);
}
Explanation
  • Initialization: set counter to start value.
  • Condition: loop continues while the test is true.
  • Increment: advance the counter after each pass.
Conveyor-belt analogy

Each pass moves an item. Stop when the belt is empty. Decide whether counters start at zero or one and keep bounds consistent to avoid off-by-one errors.

Hardware usage

Common: fading LEDs by iterating PWM values from 0 to 255, or processing a fixed array of samples.

Key Takeaway

For loops are for counted, deterministic repetitions; check bounds to avoid off-by-one problems.
