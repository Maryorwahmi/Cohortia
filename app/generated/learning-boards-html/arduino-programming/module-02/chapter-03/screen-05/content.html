Definition
if, else if, else — traffic-light decision
Order your checks from specific to general to avoid overlaps.
Code example
int reading = analogRead(A0);
if (reading > 800) {
  Serial.println("Bright");
} else if (reading > 400) {
  Serial.println("Medium");
} else {
  Serial.println("Dark");
}
Explanation
  • Check highest threshold first to capture the strongest case.
  • Else if prevents multiple outputs for the same reading.
  • Use else as a safe fallback when no prior tests match.
Traffic-light analogy

Imagine checking whether the light is green first, then yellow, otherwise red. That ordering keeps the decision exclusive and predictable.

Misconception check

Avoid separate if statements for the same variable unless you intentionally want multiple actions; separate ifs may lead to conflicting behavior.

Key Takeaway

Order tests from specific to general; use else if for exclusive branches.
