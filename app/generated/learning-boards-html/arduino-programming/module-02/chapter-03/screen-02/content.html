Learning Objectives
Learn, Understand, Apply, Master
Learn
Understand

Master
01
Use if, else if, else
Write branching code to choose actions based on a condition. Example: classify a light reading into bright, medium, or dark.
Mnemonic: Traffic light — decide which color to show.
VERIFIED COMPETENCY MILESTONE
02
Write for, while, do-while
Select counted loops for known iterations and conditional loops when the stop time is unknown. Example: fade an LED across 0 to 255 using a for loop.
Mnemonic: Conveyor belt — items counted or processed until empty.
VERIFIED COMPETENCY MILESTONE
03
Combine conditions with &&, ||, !
Require multiple criteria before acting. Example: turn on a fan only if temperature is high AND motion is detected.
Mnemonic: Two keys to open a door — both must be present.
VERIFIED COMPETENCY MILESTONE
04
Apply to Arduino scenarios
Map control structures to sensor thresholds, button presses, and LED control. Example task: print Daytime/Evening/Night and light an LED only at night.
Mnemonic: Real-world checks — decide and act on sensor data.
VERIFIED COMPETENCY MILESTONE
