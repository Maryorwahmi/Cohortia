Core Concept What are control structures?
Definition and role
Decisions and repetition that make Arduino projects interactive.
Key idea

Control structures let your code respond to changing inputs and repeat work reliably. Use conditionals to choose and loops to repeat.

Common misconception

Loops are not only for delays. Blocking a loop with delay calls prevents responsive behavior; prefer condition checks or non-blocking patterns for interactivity.

Concrete example

A light sensor reading decides whether to turn on an LED at night. A loop can sample the sensor until the reading stabilizes before making a decision.

Visual: cards as roles

Key Takeaway

Pick conditionals for branching, loops for repetition, and logical operators to combine checks.
