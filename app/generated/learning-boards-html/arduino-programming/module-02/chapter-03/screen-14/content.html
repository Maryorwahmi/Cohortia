Key Concepts — Part 1
Three compact concept cards to remember.
if / else if / else

Exclusive branching. Order checks from most specific to least specific.

for / while / do-while

Select for counted loops, while for waits, do-while to guarantee one run.

Logical operators

Use &&, ||, and ! to combine tests and make robust decisions.

Summary takeaway
Control structures let you transform sensor inputs into safe, predictable hardware actions. Practice on boundary values and keep loops predictable.
