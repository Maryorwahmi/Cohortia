Core Concept
Logical operators
Combine multiple tests to require stronger conditions.
Common operators
  • AND (&&): both must be true.
  • OR (||): at least one must be true.
  • NOT (!): inverts a condition.
Concrete example

If temperature is above 30 and motion is detected then enable the fan. Named booleans improve readability: highTemp and motionDetected.

Readability tip

Break complex expressions into well-named boolean variables and use parentheses to make evaluation order explicit.

Key Takeaway

Combine conditions to express safety or precision requirements; prefer clarity with named booleans.
