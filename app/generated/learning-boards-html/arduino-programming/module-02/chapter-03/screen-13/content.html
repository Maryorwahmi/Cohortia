Practical Tips
Common mistakes and debugging
Patterns to avoid and how to find errors.
Infinite loops

Ensure loop conditions can change; add timeouts if waiting on external events to avoid locking the device.

Off-by-one

Confirm whether loops should include the end value. Test boundary inputs to verify behavior around thresholds like 400 and 800.

Blocking code

Long delays inside loops stop the sketch from handling inputs. Use timed steps or split work across the main loop for responsiveness.

Debugging checklist
  • Add Serial prints to show which branch or loop runs.
  • Test boundary values and counters explicitly.
  • Refactor complex conditions into named booleans for clarity.
