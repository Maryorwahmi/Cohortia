Definition
do-while loops
Run once, then continue while the condition holds.
Pattern
do {
  // run at least once
} while (condition);
Good for initial actions like a calibration step before checking if more iterations are needed.
Misconception

Don’t use do-while when you might not want the body to run at all; choose while instead in those cases.

Key Takeaway

Use do-while when a single, guaranteed execution is required before testing continuation.
