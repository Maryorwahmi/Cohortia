Code examples
A conversion function and a void action routine.
float toVoltage(int reading) {
  // map 0-1023 to 0.0-5.0
  return (reading / 1023.0) * 5.0;
}

void blinkLED(int pin, int duration) {
  digitalWrite(pin, HIGH);
  delay(duration);
  digitalWrite(pin, LOW);
  delay(duration);
}
Use when toVoltage
You need the numeric voltage for display or math; so return it.
Use when blinkLED
It performs an action on hardware and doesn't need to return a value, so void is appropriate.
Concrete example
Call toVoltage with a sensor reading, store the returned value, and print it. Call blinkLED with different durations to vary blink speed.
Common mistake
Choosing void because it's simple prevents you from returning useful computed results. If a result is needed later, return it instead of writing it to a global variable.
Key Takeaway

Decide whether a function should return a value based on whether callers need that result to proceed.
