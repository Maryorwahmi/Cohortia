Module 2 › Chapter 2.4 › Learning Objectives
Practice & Assessment
Concrete tasks to try during the hands-on activity.
Refactor a long loop
Extract readSensor, printValue, blinkLED and call them from loop to improve clarity.
Write a conversion function
Convert analog reading to voltage and return a floating value for display or calculation.
Identify scope
Mark variables as local where possible and justify when globals are needed for hardware objects.
Assessment idea
Show a short function and identify its return type and parameters. Then implement the conversion from reading to voltage as a standalone function and call it from loop.
Key Takeaway

Practice small, testable functions that you can reason about independently.
