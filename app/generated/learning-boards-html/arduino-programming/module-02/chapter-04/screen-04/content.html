Module 2 › Chapter 2.4 › What is a function?
Function anatomy
Return type • Name • Parameters • Body
int add(int a, int b) {
  return a + b;
}
This simple add function takes two integer ingredients and returns their sum. It demonstrates the four parts clearly and is fully reusable wherever integer addition is needed.
Local variable
Exists only during the function call.
Global variable
Declared outside functions and visible everywhere.
Analogy — kitchen cook
Think of a function as a cook who receives ingredients, follows a recipe, and returns a dish. The cook's workspace and utensils are local; other cooks do not see them unless the finished dish is shared.
Example
A conversion function that maps analog readings to voltage is a focused function: it takes a reading and returns a numeric voltage.
Key Takeaway

Keep functions focused. Short, single-purpose functions are easier to reuse and test.
