Learning Objectives
Progress from understanding to applying modular design in sketches.
01
Define and call functions
Write declarations and invoke functions to run specific tasks. This reduces repeated code and clarifies intent.
VERIFIED COMPETENCY MILESTONE
02
Understand parameters & returns
Pass inputs into functions and return computed values when needed. This keeps data flow explicit and testable.
VERIFIED COMPETENCY MILESTONE
03
Organize code into reusable blocks
Split responsibilities so each function does one job. That makes maintenance and testing simpler.
VERIFIED COMPETENCY MILESTONE
04
Explain local vs global variables
Recognize where variables live and choose scope that minimizes unexpected interactions.
VERIFIED COMPETENCY MILESTONE
Bloom progress
Learn → Understand → Apply → Master
Use the milestones to guide practice: start by writing simple functions, then refactor a loop, then explain scope in your refactored sketch.
