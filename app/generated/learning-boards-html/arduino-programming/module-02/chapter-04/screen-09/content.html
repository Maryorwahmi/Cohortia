Module 2 › Chapter 2.4 › Refactor: before & after
Before (inline loop)
void loop() {
  int reading = analogRead(A0);
  float v = (reading / 1023.0) * 5.0;
  Serial.println(v);
  digitalWrite(13, HIGH);
  delay(500);
  digitalWrite(13, LOW);
  delay(500);
}
All steps are mixed, which makes small changes risky.
After (refactored)
int readSensor() { return analogRead(A0); }
float toVoltage(int r) { return (r / 1023.0) * 5.0; }
void printValue(float v) { Serial.println(v); }
void blinkLED(int pin, int d) { digitalWrite(pin, HIGH); delay(d); digitalWrite(pin, LOW); delay(d); }

void loop() {
  int r = readSensor();
  float v = toVoltage(r);
  printValue(v);
  blinkLED(13, 500);
}
Each function has a single role and is easier to test and reuse.
Key Takeaway

Refactoring does not change behavior when done carefully, but it makes code easier to understand and extend. Prefer explicit parameters and return values over hidden globals.
