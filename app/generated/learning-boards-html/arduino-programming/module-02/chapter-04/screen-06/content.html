Module 2 › Chapter 2.4 › Local vs Global Variables
Local variables
Declared inside functions; lifetime is the function call.
void example(){ int temp = analogRead(A0); // temp exists only here }
Local variables keep functions independent. When you test a function, you only need to supply its inputs and observe its outputs, not the whole program state.
Global variables
Declared outside functions and available everywhere in the sketch.
const int LED_PIN = 13; // hardware pin constant int sharedState = 0; // mutable global
Use globals for hardware constants or objects, but minimize mutable globals to avoid hard-to-find bugs.
Pro tip
Pass values as parameters and return results instead of relying on globals. That keeps functions portable and easier to reuse in different sketches.
Key Takeaway

Favor local scope and explicit data flow; use globals sparingly for shared hardware and constants.
