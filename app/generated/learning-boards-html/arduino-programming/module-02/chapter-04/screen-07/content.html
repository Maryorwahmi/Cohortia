Module 2 › Chapter 2.4 › Void action routines
Design steps
1. Identify the single action the routine must perform.
2. Decide what inputs are required (parameters).
3. Avoid returning values; keep side effects explicit and limited.
4. Keep the routine short and avoid long blocking times when possible.
void blinkLED(int pin, int duration) { digitalWrite(pin, HIGH); delay(duration); digitalWrite(pin, LOW); delay(duration); }
Concrete scenario
You have two status LEDs. Call blinkLED with different pins and durations to indicate different states without duplicating code.
Common mistake: embedding global state changes deep inside many void routines. If an action changes many globals, it becomes harder to find the source of bugs.
Key Takeaway

Parameterize void routines so one implementation serves many cases and avoids duplicated code.
