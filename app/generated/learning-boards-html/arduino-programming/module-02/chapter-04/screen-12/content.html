Module 2 › Chapter 2.4 › Key Concepts
Function structure
Return type, name, parameters, body — the parts you always declare.
Parameters & returns
Pass inputs for flexibility; return values when callers need results instead of using globals.
Scope
Favor local variables and parameter passing; use globals for shared hardware or constants only.
Takeaway

Design functions around a single responsibility and keep data flow explicit to make Arduino projects easier to read, test, and maintain.
