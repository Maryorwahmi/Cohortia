Module 2 › Chapter 2.4 › Assessment: conversion
Task
Implement a function that converts an analog reading to voltage and returns it.
float toVoltage(int reading) { return (reading / 1023.0) * 5.0; }
What to submit
Function code, an example call from loop, and a short explanation of why the function returns a value rather than using a global.
Common pitfall
Using integer division instead of floating arithmetic will produce incorrect voltages. Ensure at least one operand is a float.
Key Takeaway

This small function validates your understanding of parameters, return types, and the importance of explicit data flow.
