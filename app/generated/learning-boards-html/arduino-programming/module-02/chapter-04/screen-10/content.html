Kitchen refactor steps
Extract three functions and call them from loop.
readSensor()
Return an integer analog reading so callers can convert or log it.
printValue()
Accept a numeric value, format it, and print to the serial console.
blinkLED()
Accept pin and duration to blink different LEDs at different rates.
Test each cook independently. When they work on their own, combining them in loop is straightforward and safe.
Scenario card
Refactor a sketch that reads a temperature sensor, prints the value, and blinks a status LED. After refactor, change print formatting without modifying sensor reading code.
Key Takeaway

Treat functions as independent cooks. Give them clear inputs and outputs so they remain interchangeable and testable.
