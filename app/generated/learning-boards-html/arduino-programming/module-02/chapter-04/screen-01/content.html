Functions and Modular Programming
Design reusable code blocks that accept inputs, perform a task, and optionally return results.
Why this matters: small, focused functions make sketches easier to read, easier to test, and safer to change. When each function has one responsibility, you can reason locally and reduce bugs that span the whole program.

Coming up

Example preview
int add(int a, int b) {
  return a + b;
}

void blinkLED(int pin, int duration) {
  digitalWrite(pin, HIGH);
  delay(duration);
  digitalWrite(pin, LOW);
  delay(duration);
}
Key Takeaway

Start small: give each function a single job and prefer parameters over globals to keep behavior predictable.
