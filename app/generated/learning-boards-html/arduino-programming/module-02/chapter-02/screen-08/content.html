Module 2 › Chapter 2.2 › Constants
const keyword
Typed constant that the compiler can use for checks and optimizations.
const int BUTTON_PIN = 2;
const float VOLTAGE_REF = 5.0;
#define
Preprocessor symbol replaced at compile time. Useful for compile-time flags and conditional compilation.
#define LED_PIN 13
// used by preprocessor
Why this matters
  • Single source of truth for hardware constants.
  • Easier refactoring when pins or calibration values change.
  • Better readability for other developers and your future self.
Key Takeaway

Declare fixed values as constants to reduce errors and simplify updates when hardware or calibration changes.
