Sketch pattern
int reading1 = 0;
int reading2 = 0;
int reading3 = 0;
float average = 0.0;
int threshold = 500;

// read three values
reading1 = analogRead(A0);
reading2 = analogRead(A1);
reading3 = analogRead(A2);

// compute average as float
average = (reading1 + reading2 + reading3) / 3.0;

// compare to threshold
if (average > threshold) {
  // take action
}

Serial.println(average);
Explanation
  • Use float division to keep fractional average.
  • Threshold type should match comparison precision.
  • Print results to inspect and verify behavior.
Common mistake
Using integer division reduces the average to an integer; make one operand a float to preserve decimals.
Key Takeaway

Run the sketch and compare predicted results to actual output to learn how type choices affect calculations.
