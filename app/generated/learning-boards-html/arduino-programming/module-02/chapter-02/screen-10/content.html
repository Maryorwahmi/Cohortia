Comparison operators
  • == equal to
  • != not equal to
  • < > <= >= for ordering
if (temp > 20) { /* warm */ }
if (mode == 1) { /* mode A */ }
Logical operators
Combine booleans with AND, OR, and NOT to express compound conditions.
if ((temp > 10) && (temp < 30)) { /* in range */ }
if (!buttonPressed) { /* not pressed */ }
Pitfalls
  • Don't use assignment where you mean comparison; it changes the variable instead of testing it.
  • Be explicit with parentheses when combining many conditions to avoid ambiguous precedence.
Key Takeaway

Write clear comparisons and combine them with logical operators to express conditions safely and readably.
