When to use float

Floats store fractional values like voltage, temperature, or averaged readings. Use them when fractional precision is required for display or control decisions.

Code example
float temperature = 23.5;
float average = (a + b + c) / 3.0;
Misconception
Floats are exact. In reality they are approximations and require tolerance checks for equality.
Alternative: scaled integers
If you need exact fixed precision and faster math, store values scaled by a factor, for example store hundredths as integers and divide when printing.
Example scenario
To keep two decimal places for currency-like values, store cents in an int instead of using float to avoid subtle rounding errors.
Key Takeaway

Use float for decimals when convenient, but prefer scaled integers for exactness and speed when appropriate.
