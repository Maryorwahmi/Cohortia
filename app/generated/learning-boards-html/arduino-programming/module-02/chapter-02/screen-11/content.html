Module 2 › Chapter 2.2 › Division & Modulo
Integer division
When both operands are integers, the result is truncated to an integer. To get decimals, use a float operand or cast.
int r = 7 / 2; // r becomes 3
float f = 7.0 / 2; // f becomes 3.5
Modulo
Returns remainder. Useful for wrapping counters and timed events.
int r = 10 % 3; // r is 1
if (counter % 10 == 0) { /* every tenth loop */ }
Pitfall
Modulo with negative numbers can be surprising; prefer nonnegative counters for periodic checks.
Key Takeaway

Make operand types explicit to control whether division yields integer or decimal results and use modulo to implement periodic behavior and wrapping safely.
