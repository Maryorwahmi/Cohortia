Module 2 › Chapter 2.2 › What is a variable?
Definition & Why it matters

Variables let your sketch hold sensor values, counters, and state that change over time. Declaring a type reserves appropriate memory and enforces valid operations.

Concrete example
int sensorValue = 0;
sensorValue = analogRead(A0);
Common misconception
Variables are permanent storage. They are not preserved across power cycles unless explicitly saved to persistent memory.
Pro tip
Give descriptive names and initialize variables to avoid undefined values on first use.
Visual: variable role
Name
A readable identifier, e.g., sensorValue.
Type
Declares storage size and valid operations.
Value
The current data stored and used by the program.
Key Takeaway

Declare variables with a suitable type so code stores and updates necessary values reliably.
