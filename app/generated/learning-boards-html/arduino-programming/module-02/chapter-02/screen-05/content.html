Module 2 › Chapter 2.2 › Integer Types
Type comparison
int
2 bytes on Uno; range −32,768 to 32,767. Good for typical sensor values and counters within that range.
long
4 bytes; used when values must exceed int range, such as millisecond timestamps over long runtimes.
byte
1 byte; holds 0–255. Ideal for small positive indices, pin numbers, and compact storage.
Concrete scenarios
  • LED pin: byte ledPin = 13; small and nonnegative.
  • ADC reading: int sensorValue = analogRead(A0); stays within int range.
  • Uptime in ms: long uptime = millis(); may exceed int and needs long.
Key Takeaway

Match integer type to expected range to prevent overflow and conserve memory.
