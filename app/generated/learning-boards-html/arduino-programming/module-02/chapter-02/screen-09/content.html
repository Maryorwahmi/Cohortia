Module 2 › Chapter 2.2 › Arithmetic Operators
Operators list
  • + addition for sums and offsets
  • - subtraction for differences and correction
  • * multiplication for scaling
  • / division; watch integer division vs float
  • % modulo for remainders and periodic checks
Examples
int sum = a + b + c;
float avg = (a + b + c) / 3.0;
int wrap = counter % 256; // keeps values 0–255
Common pitfall
Integer division discards decimals. Make one operand a float to get a decimal result.
Key Takeaway

Control types of operands to ensure the intended numeric result; use modulo for wrapping and periodic checks.
