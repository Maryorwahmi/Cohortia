Module 2 › Chapter 2.2 › Conversion & Overflow
Implicit conversion
Mixing types in expressions may convert operands automatically, possibly losing precision or changing sign.
int x = (int) someFloat; // fractional part truncated
Overflow example
An int at its max plus one wraps to the minimum negative value on typical Arduino Uno settings.
// if x == 32767 x = x + 1; // x becomes -32768 (wrap)
How to avoid
  • Choose a larger type when the range might exceed limits.
  • Check before arithmetic to prevent wrap-around.
  • Consider unsigned types if negative values are impossible and you need extra positive range.
Key Takeaway

Understand conversions and plan types so values don't silently change or wrap during runtime.
