Choose by range
Use byte for 0–255, int for typical signed ranges, long for larger counts.
Decimal control
Force float operands for decimal results; cast when necessary.
Avoid overflow
Check ranges or choose larger types to prevent silent wrap-around bugs.
Final takeaway

Small, deliberate type choices plus testing will save you time debugging arithmetic and sensor errors on Arduino.
