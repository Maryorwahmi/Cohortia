Module 2 › Chapter 2.2 › Bool & Char
bool / boolean
Store true/false values like buttonPressed or isRunning. Useful for conditionals and state machines.
Example
bool isRunning = true;
if (isRunning) {
  // do work
}
char
Holds a single character. Use for concise labels or protocol markers where full strings are unnecessary.
Example
char grade = 'A';
Serial.print(grade);
Misconceptions & Tips
  • Don’t use full strings when a char or boolean suffices; memory matters on microcontrollers.
  • Be explicit in comparisons to avoid accidental integer promotion or ambiguous truthiness.
Key Takeaway

Use bool for flags and char for single characters to keep code clear and memory use small.
