Module 3 › Chapter 2.5 › C-strings vs String
C-strings
Fixed-size character arrays with a terminator. Low SRAM use and predictable allocation. Best for short constant messages and tight memory budgets.
Pros
  • Predictable memory usage
  • No heap fragmentation
  • Good for constant or short messages
Arduino String
A higher-level class that makes text manipulation easier by allocating memory on demand. Convenient but risky on low-RAM boards due to fragmentation over time.
Cons
  • Dynamic allocation can fragment SRAM
  • Not recommended for repeated small boards or long-running sketches with many allocations
Guideline
Prefer C-strings for fixed messages. Use String only when board memory and lifetime behavior are acceptable.
