Module 3 › Chapter 2.5 › What is an Array?
Definition

Typed collection with indexed elements

Arrays store values of the same type in contiguous memory slots. Each slot is accessed with a zero-based index. They are ideal for lists such as pin numbers or a short history of sensor readings.

Example Declaration
int ledPins[] = {3, 5, 6, 9, 10, 11};
ledPins[0] = 255;  // set first element
Common Mistake
Assuming arrays auto-resize. They are fixed unless you use dynamic allocation, which is discouraged on small microcontrollers.
Key Takeaway
Use arrays to reduce repetitive code and keep related values together. Always check bounds.

Out-of-bounds access reads or writes memory outside the array and can crash the program. Confirm loop bounds carefully.
