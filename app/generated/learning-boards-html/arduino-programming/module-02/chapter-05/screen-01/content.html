Memory Rooms
Flash — program storage: large and read-only while running.
SRAM — working memory: small, holds variables and arrays at runtime.
EEPROM — persistent notebook: small, keeps data across power cycles.
Common Patterns
Use arrays for lists of pins or sensor readings to avoid repetitive code.
Prefer C-style strings for short fixed messages to save SRAM.
Avoid heavy use of the Arduino String class on low-RAM boards to prevent fragmentation.
