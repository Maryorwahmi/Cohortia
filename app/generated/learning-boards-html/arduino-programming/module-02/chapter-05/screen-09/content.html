Module 3 › Chapter 2.5 › Memory on Arduino
Flash
Holds the program and constant data. Large relative to SRAM and read-only at runtime. Use for constant strings and code.
SRAM
Working memory for variables, arrays, and dynamic allocations. Very limited on many boards; avoid large buffers.
EEPROM
Small persistent storage for calibration or configuration that must survive power cycles.
Practical Sizes (example)
A classic Uno-like board often has limited SRAM measured in a few kilobytes, larger flash for program space, and about one kilobyte of EEPROM. Plan accordingly.
Using F to save SRAM
Wrap constant text with the flash macro when printing to avoid copying the string into SRAM. This keeps runtime memory lower and more reliable.
