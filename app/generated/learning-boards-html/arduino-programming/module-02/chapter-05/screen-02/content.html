Learning Objectives

What you'll be able to do after this chapter

Learn → Understand → Apply → Master
01 Declare & Access
Declare arrays of integers and characters

Write typed arrays, use zero-based indexes to read and set elements, and rely on compiler inference for static initializers.

Mnemonic: boxes in a row
VERIFIED COMPETENCY MILESTONE
02 Process with Loops
Use loops to process sensor arrays

Accumulate readings, compute averages, and traverse arrays without duplicating code. Learn loop bounds and off-by-one care.

Mnemonic: running index
VERIFIED COMPETENCY MILESTONE
03 Strings
Know C-strings vs. String objects

Choose C-style character arrays for small fixed text and prefer caution with the dynamic String class on limited RAM boards.

Mnemonic: stack vs heap
VERIFIED COMPETENCY MILESTONE
04 Memory Safety
Avoid common SRAM problems

Understand that SRAM is small; keep large data out of RAM, use flash for constants, and limit dynamic allocations.

Mnemonic: three rooms
VERIFIED COMPETENCY MILESTONE
