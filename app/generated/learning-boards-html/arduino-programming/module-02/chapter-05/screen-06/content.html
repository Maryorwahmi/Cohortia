Module 3 › Chapter 2.5 › Average & Min/Max Walkthrough
Starter Code
int readings[5] = {100, 102, 98, 105, 101};
int sum = 0;
int minVal = readings[0];
int maxVal = readings[0];
for (int i = 0; i < 5; i++) {
  int v = readings[i];
  sum += v;
  if (v < minVal) minVal = v;
  if (v > maxVal) maxVal = v;
}
float average = sum / 5.0;
This code computes sum, updates min and max, and then computes a floating-point average to avoid truncation.
Checks & Pitfalls
  • Confirm the array length in the loop condition matches the declared size.
  • Initialize min and max sensibly; using the first element is often simplest.
  • Decide integer versus float division for average to match precision needs.
  • Test with edge cases: identical values, increasing or decreasing sequences.
