Module 3 › Chapter 2.5 › Learning Objectives — Practice

Guided Practice Steps

Small exercises to verify each objective quickly in your sketch editor.

Step A — Declare & Read

Create an integer array of LED pin numbers, let the compiler infer size, then assign the first element and print it to serial.

Checkpoint: No out-of-bounds access.
Step B — Average Readings

Make an array of five sensor readings, write a for loop to sum them, and divide by five to print the mean.

Checkpoint: Use integer or float as needed to avoid truncation.
Step C — Min & Max

Extend the sum loop to track the highest and lowest values, initialize properly, and test with sample data.

Checkpoint: Avoid initializing min with zero when values may be positive only.
Step D — Strings & Flash

Print a short C-style character array and then print a constant wrapped with the F macro to keep it in flash. Compare memory behavior when using dynamic String objects.

Checkpoint: Watch for heap fragmentation with many String operations.
