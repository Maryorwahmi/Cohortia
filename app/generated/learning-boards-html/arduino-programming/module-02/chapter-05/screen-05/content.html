Module 3 › Chapter 2.5 › Iterating Arrays
Pattern

for loop traversal

Use an index starting at zero and loop while it is less than the number of elements. This pattern works both for configuring pins and for aggregating sensor values.

Configuration Example
for (int i = 0; i < 6; i++) {
  pinMode(ledPins[i], OUTPUT);
}
Pro Tip
When counting elements, prefer constants or computed sizes so loops remain correct when the array changes.
Common Mistake
Using i <= size uses one index past the array end. Always use less-than with zero-based arrays.
Walkthrough
Summing readings and tracking min and max in one pass keeps code efficient and easy to test.
What to initialize
  • Set an accumulator to zero before the loop.
  • Initialize min to a very large value or the first element.
  • Initialize max to a very small value or the first element.
Example Scenario
A loop that reads five sensor values can compute sum, mean, min and max in one pass, minimizing SRAM and CPU time.
