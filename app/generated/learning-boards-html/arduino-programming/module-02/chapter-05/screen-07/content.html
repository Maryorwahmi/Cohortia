Module 3 › Chapter 2.5 › C-strings
Definition

Character arrays with terminator

C-strings are arrays holding characters plus a null terminator at the end. They avoid runtime allocation and are predictable in memory use, making them preferred for small fixed messages.

Practical note
Always leave one extra slot for the terminator when declaring buffers and check lengths before copying or concatenating strings.
Concrete Example
Store a small message for repeated Serial prints without using heap memory. This keeps SRAM usage low and predictable.
Misconception Check
Don't assume C functions will guard your buffers. Always ensure destination size is sufficient before copying characters.
Key Takeaway
Use C-strings for small fixed messages to avoid dynamic memory overhead and fragmentation.
