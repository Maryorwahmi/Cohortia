Practical Rules to Avoid Memory Problems

Prefer static buffers
Re-use pre-allocated character arrays rather than allocating temporaries. This reduces heap churn and avoids fragmentation.
Use flash for constants
Wrap constant text with the flash macro to keep it out of SRAM during runtime.
Limit local large arrays
Large arrays inside functions consume stack space; prefer globals or smaller chunks to avoid stack/heap collision.
Test with realistic inputs
Run long-duration tests to reveal fragmentation and allocation failures that short tests might hide.
