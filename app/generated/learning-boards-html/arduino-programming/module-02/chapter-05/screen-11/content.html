Activity Steps

Step 1 — Declare
Create int readings[5] and set sample values to test variation.
Step 2 — Sum & Average
Write a for loop to accumulate and then compute the mean. Choose float if you need decimals.
Step 3 — Min & Max
Update min and max inside the same loop to avoid a second pass. Initialize correctly.
Scenario Card
Imagine a temperature sensor array where you need the average and extremes for a control decision. Small arrays and single-pass loops keep CPU and memory use minimal.
Try this extension
Ignore invalid readings by adding a threshold check inside the loop before summing, and track the count of valid samples for averaging.
