Module 07 › Chapter 7.2 › Install and enable group_replication
Installation process
  1. Verify prerequisites are set on the instance.
  2. Run the INSTALL PLUGIN command in the SQL client.
  3. Set group variables (group_name, local_address, group_seeds).
  4. Start group replication when ready.
SQL example
-- In the mysql client on each server
INSTALL PLUGIN group_replication SONAME 'group_replication.so';
Common mistakes & tips
  • Don't skip installing the plugin on every node.
  • Confirm install succeeds by checking SHOW PLUGINS output.
  • If install fails, check the error log for missing library or permission errors.
Pro tip

Optionally set group_replication_start_on_boot in my.cnf for production so the plugin auto-starts with the server, but for exercises start manually.
