Monitor membership
Use SELECT * FROM performance_schema.replication_group_members to read ONLINE, RECOVERING, or ERROR states and identify PRIMARY/SECONDARY roles.
VERIFIED COMPETENCY MILESTONE
Inspect logs
Check the MySQL error log for messages during plugin install and group startup; it often shows why a join fails.
VERIFIED COMPETENCY MILESTONE
Prevent divergence
Provision new members with an empty data directory or a recent backup to avoid conflicting GTIDs and join failures.
VERIFIED COMPETENCY MILESTONE
Quick checklist
  • Match group_replication_group_name UUID on all members
  • Open group communication port (default 33061) between members
  • Use performance_schema tables and the error log to diagnose failures
