Module 07 › Chapter 7.2 › Monitor cluster health
Key queries
SELECT * FROM performance_schema.replication_group_members;
SELECT * FROM performance_schema.replication_group_member_stats;
Use the first to see role and status, and the second for transaction and conflict statistics. Combine these with the error log for full diagnostics.
Interpretation
  • ONLINE means the member is active and participating.
  • RECOVERING indicates State Transfer in progress.
  • ERROR suggests recent failures; check logs immediately.
Key Takeaway

Regularly query performance_schema tables and review error logs to maintain a healthy cluster and speed troubleshooting.
