Module 07 › Chapter 7.2 › Add new members to the cluster
Joining sequence (example)
-- On mysql2
INSTALL PLUGIN group_replication SONAME 'group_replication.so';
SET GLOBAL group_replication_group_name = "7a1b2c3d-4e5f-...";
SET GLOBAL group_replication_local_address = "192.168.1.11:33061";
SET GLOBAL group_replication_group_seeds = "192.168.1.10:33061,192.168.1.11:33061,192.168.1.12:33061";
SET GLOBAL group_replication_mode = "single-primary";
START GROUP_REPLICATION;
After START, observe State Transfer and then check performance_schema.replication_group_members to confirm role and ONLINE status.
State Transfer notes
  • New members receive data via State Transfer to match group state.
  • If the joining node has conflicting GTIDs, the transfer or join may fail.
  • Provisioning with a recent backup avoids conflicts and speeds joins.
Key Takeaway

Ensure at least one reachable seed, matching group UUID, and open ports to allow discovery and State Transfer.
