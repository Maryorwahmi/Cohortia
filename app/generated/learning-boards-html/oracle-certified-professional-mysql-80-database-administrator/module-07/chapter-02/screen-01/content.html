Implementing MySQL Group Replication
Configure prerequisites, install the plugin, bootstrap a cluster, add members, and monitor health.

You will practice the exact SQL and configuration steps used to bring a three‑node cluster online and learn how to verify membership with the Performance Schema.

Why this matters: correct setup prevents split‑brain, avoids failed joins, and ensures consistent GTID replication across nodes.
