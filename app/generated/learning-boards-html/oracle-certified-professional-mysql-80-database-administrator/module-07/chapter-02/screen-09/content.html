Module 07 › Chapter 7.2 › State Transfer
What happens during State Transfer
  • A joining node connects to a donor and negotiates what transactions it lacks.
  • The donor sends a snapshot or the missing transaction stream to update the joiner's GTID set.
  • The joiner applies transactions locally until its GTID set matches the group's state.
Practical example

If mysql2 has an empty data directory, State Transfer can be faster and safer because there are no conflicting GTIDs. If mysql2 has an unrelated dataset, the join will likely fail due to divergence.

Operational tips
  • Provision new members with a recent backup from an existing group node when possible.
  • Monitor disk and I/O during large State Transfers to avoid overload.
  • Check error logs for transfer failures or transaction conflicts.
Key Takeaway

Prepare joining nodes to minimize conflicts; State Transfer syncs the GTID state rather than blindly copying directories.
