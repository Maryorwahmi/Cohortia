Module 07 › Chapter 7.2 › What to Remember
Prerequisites
InnoDB, GTID, log_bin, log_slave_updates, unique server_id.
Bootstrap safely
Set bootstrap_group=ON only for initial START, then set it OFF immediately.
Monitor often
Query performance_schema.replication_group_members and inspect error logs for troubleshooting.
Final takeaway
Accurate configuration and immediate verification are the fastest path to a stable Group Replication cluster.
