INSTALL PLUGIN group_replication
Load the plugin on every instance so group features are available.
group_replication_group_name
A UUID that must match across all members to identify the cluster.
group_replication_local_address & seeds
Local address is unique per member; seeds let joins discover the group.
Summary takeaway
Accurate prerequisites, identical group configuration, safe bootstrap, and careful preparation for State Transfer are the foundation of a reliable Group Replication deployment.
