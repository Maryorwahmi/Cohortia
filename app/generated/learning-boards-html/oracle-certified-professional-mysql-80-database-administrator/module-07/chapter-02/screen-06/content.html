Step-by-step bootstrap (example)
-- On mysql1 (bootstrap server)
INSTALL PLUGIN group_replication SONAME 'group_replication.so';
SET GLOBAL group_replication_group_name = "7a1b2c3d-4e5f-6a7b-8c9d-0e1f2a3b4c5d";
SET GLOBAL group_replication_local_address = "192.168.1.10:33061";
SET GLOBAL group_replication_group_seeds = "192.168.1.10:33061,192.168.1.11:33061,192.168.1.12:33061";
SET GLOBAL group_replication_mode = "single-primary";
SET GLOBAL group_replication_bootstrap_group = ON;
START GROUP_REPLICATION;
SET GLOBAL group_replication_bootstrap_group = OFF;
Verify with SELECT * FROM performance_schema.replication_group_members; expecting mysql1 as PRIMARY and ONLINE.
Warnings and checks
  • Do not leave bootstrap_group=ON in my.cnf or persistent session variables.
  • Check the error log if START GROUP_REPLICATION fails for plugin issues or network errors.
  • Confirm the UUID used for group_name is unique to this cluster.
Common mistake

Forgetting to set bootstrap_group OFF after startup can cause split‑brain on restart. Turn it off immediately.
