Module 07 › Chapter 7.2 › Bootstrapping lab
Lab steps (terminal-first)
  1. On all nodes: INSTALL PLUGIN group_replication SONAME 'group_replication.so';
  2. On mysql1: set group_name UUID, local_address, group_seeds, mode, then bootstrap ON → START → bootstrap OFF.
  3. On mysql2 and mysql3: set group_name, local_address, group_seeds and START GROUP_REPLICATION.
  4. Verify membership with SELECT * FROM performance_schema.replication_group_members;
  5. Test replication by writing on the primary and reading from a secondary.
Terminal snippet (example)
-- verify membership
SELECT * FROM performance_schema.replication_group_members;
-- write test on primary
INSERT INTO test.t1 (id, name) VALUES (1, 'replicate');
-- read test on secondary
SELECT * FROM test.t1 WHERE id = 1;
Safety tips
  • Run lab in staging, not production.
  • Turn off bootstrap_group immediately after initial START.
  • Use backups or empty data dirs for joiners to avoid divergence.
Key Takeaway

Follow the exact sequence, verify membership after each step, and test replication by writing to the primary and reading from a secondary.
