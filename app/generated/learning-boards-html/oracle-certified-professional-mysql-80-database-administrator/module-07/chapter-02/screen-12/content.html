Module 07 › Chapter 7.2 › Common mistakes and fixes
Top causes of failed joins
  • Blocked group port (default 33061) by firewall rules.
  • Incorrect or incomplete group_replication_group_seeds.
  • Leaving group_replication_bootstrap_group=ON after bootstrap.
  • Data divergence on the joining node (conflicting GTIDs).
Quick fixes
  1. Open or allow port 33061 between members.
  2. Correct the seeds list and retry START GROUP_REPLICATION.
  3. If bootstrap was left ON, set it OFF immediately and rejoin remaining nodes from a healthy member.
  4. Restore a backup or provision a clean data directory if GTIDs diverge.
Assessment idea

Given a failed join showing "failed to connect to group seeds", identify two likely causes and the order of checks you would run to resolve it.

Key Takeaway

Start troubleshooting with network connectivity and seeds, then verify group_name parity and data consistency to resolve most join failures.
