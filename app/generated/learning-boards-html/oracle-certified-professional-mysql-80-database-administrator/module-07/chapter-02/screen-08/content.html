Module 07 › Chapter 7.2 › Group addresses and seeds explained
Terms and meaning
local_address: the IP:port a member advertises for internal group traffic.
group_seeds: comma-separated seed addresses used by joins to discover the group.
group_name: UUID that uniquely identifies the cluster; must match on all members.
Example configuration
SET GLOBAL group_replication_local_address = "192.168.1.11:33061";
SET GLOBAL group_replication_group_seeds = "192.168.1.10:33061,192.168.1.11:33061,192.168.1.12:33061";
Network checks
  • Verify the port (default 33061) is open and reachable from each member.
  • Use ping and telnet or equivalent to confirm connectivity to each seed address.
  • Remember seeds should include at least one reachable, active member for discovery.
Common mistake

Firewall rules blocking the group port are the most frequent cause of "failed to connect to group seeds" errors.
