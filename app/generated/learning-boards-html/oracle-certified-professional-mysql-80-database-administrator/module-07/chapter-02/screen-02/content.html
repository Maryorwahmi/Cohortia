Learning Objectives
Practiceable skills to configure, bootstrap, expand, monitor, and troubleshoot Group Replication.
01
Configure prerequisites
Enable GTID, binary logging, InnoDB, log_slave_updates, and set unique server_id. These ensure consistent transaction replication and identification.
VERIFIED COMPETENCY MILESTONE
02
Install the plugin
Use INSTALL PLUGIN group_replication to load replication capability. Plugin must be present on every instance joining the group.
VERIFIED COMPETENCY MILESTONE
03
Bootstrap a cluster
Temporarily set group_replication_bootstrap_group=ON on a single node and START GROUP_REPLICATION, then immediately disable bootstrap to avoid split‑brain.
VERIFIED COMPETENCY MILESTONE
04
Add and monitor members
Start additional nodes with matching group_name and seeds, verify state transfer, and inspect performance_schema.replication_group_members for status and roles.
VERIFIED COMPETENCY MILESTONE
