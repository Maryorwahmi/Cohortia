Module 7 › Chapter 7.6 › Migration strategies
Logical migration

Use export/import utilities. Suitable for small databases or long maintenance windows.

Physical migration

Copying data files directly. Complex and often incompatible with managed services.

Replication-based migration

Set the cloud instance as a replica, let it catch up, cut over with minimal downtime. Preferred for large production systems.

Cloud migration services

Provider tools can automate migration and support continuous replication to simplify cutovers.

Example
A 5TB production database with strict downtime constraints should use replication-based migration or a provider migration service to minimize disruption.
