Module 7 › Chapter 7.6 › Shared Responsibility Model
Provider responsibilities
  • Physical servers, network, and patching
  • Service-level availability features like automated backups and failover
  • Managed database runtime maintenance
Customer responsibilities
  • Schema design and query performance
  • Access management and application-level security
  • Data encryption configuration and retention policy
Example
If a slow query degrades service, you must optimize the query and index strategy; the provider manages the underlying host availability and backups.
