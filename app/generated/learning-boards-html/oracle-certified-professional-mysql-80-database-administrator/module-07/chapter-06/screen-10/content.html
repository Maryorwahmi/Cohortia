Module 7 › Chapter 7.6 › Read scaling and replica management
Replica types
  • Asynchronous replicas: common, can lag
  • Shared-storage replicas: lower-latency reads, less replication overhead
Operational checklist
  1. Monitor replication lag and I/O rates.
  2. Test promotion process and validate recent transactions.
  3. Plan read routing to avoid stale reads for consistency-sensitive operations.
Example: migration use

Set the cloud instance as a replica, allow it to catch up, then switch the application to the replica after validation. This minimizes downtime compared to a full dump and restore.

Common mistake
Failing to validate that replicas have applied all transactions prior to promotion leads to data loss or inconsistency after cutover.
