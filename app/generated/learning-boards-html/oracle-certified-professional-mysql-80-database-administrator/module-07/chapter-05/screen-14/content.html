Key Concepts
Three concise cards to memorize the chapters main ideas.
Partitioning
Split a table into partitions on the same server to improve pruning and maintenance.
Sharding
Horizontal distribution across servers; requires routing, directory, or proxy logic and adds operational overhead.
Sharding Key & Strategies
The sharding key and method (range, list, hash, directory) determine distribution, query cost, and rebalancing complexity.
Takeaway

Match partitioning and sharding choices to real query patterns; measure pruning and distribution before committing to scale-out.
