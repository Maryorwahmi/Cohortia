Introduction to MySQL Group Replication
Strong consistency, automatic failover, and group membership for MySQL 8.0
Interactive 16:9 Masterclass
MySQL Group Replication forms a coordinated group of servers that agree on transaction order using a consensus protocol. It handles member failure automatically, elects primaries when configured, and detects conflicting writes in multi-primary setups. This chapter teaches you architecture, operation modes, prerequisites, and practical checks you must perform before deploying MGR.
In this lesson
Understand how MGR orders transactions and keeps members consistent.
Coming up
Compare single-primary and multi-primary trade-offs with examples.
Why it matters
Reduce manual failover steps and avoid data divergence in critical systems.
Concept Sketch
Group of MySQL instances
Members broadcast committed transactions for consensus ordering
Consensus ordering
A Paxos-like mechanism ensures identical transaction sequences
Automatic membership
Failing members are removed and the group continues operating
