Module 7 › Chapter 7.1 › Common mistakes
Missing GTIDs or enforce_gtid_consistency prevents plugin start.
log_slave_updates disabled breaks state transfer and forwarding logic.
Non-InnoDB tables are incompatible with MGR's transactional apply requirements.
Firewall rules blocking port 33061 stop the messaging layer.
Excessive group size increases communication overhead and consensus latency.
Operational check: inspect error log, SHOW VARIABLES, and test connectivity before enabling plugin.
