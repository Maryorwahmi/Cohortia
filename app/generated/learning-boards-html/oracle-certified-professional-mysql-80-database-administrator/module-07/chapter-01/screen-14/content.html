Module 7 › Chapter 7.1 › Key Concepts
MySQL Group Replication
A plugin enabling a coordinated group for fault tolerance and consistency.
Single-Primary Mode
One writer, automatic election on failure, simpler conflict model.
Multi-Primary Mode
All members accept writes; conflict detection may abort transactions.
Summary: Use MGR for strong consistency and automated failover, but prepare GTIDs, InnoDB, binary logging, and network connectivity before enabling it.
