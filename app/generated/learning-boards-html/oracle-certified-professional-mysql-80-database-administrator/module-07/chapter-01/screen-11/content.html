Module 7 › Chapter 7.1 › Preparing three instances
Step-by-step conceptual activity
  1. Start three MySQL 8.0 instances on separate hosts or containers.
  2. Edit my.cnf for each: unique server_id, enable log_bin, enforce_gtid_consistency, gtid_mode=ON, log_slave_updates=ON, binlog_format=ROW.
  3. Restart each server to apply changes.
  4. Run SHOW VARIABLES queries to verify settings are active on each instance.
  5. Plan group_replication_local_address and seed list, and ensure port 33061 is open between nodes.
Verification SQL
SHOW VARIABLES LIKE 'server_id';
SHOW VARIABLES LIKE 'log_bin';
SHOW VARIABLES LIKE 'gtid_mode';
SHOW VARIABLES LIKE 'enforce_gtid_consistency';
Common mistakes & fixes
Forgetting to restart after my.cnf changes — restart and re-verify.
Firewall blocking port 33061 — open the port between members.
Using MyISAM or non-InnoDB tables — convert to InnoDB before enabling MGR.
