Module 7 › Chapter 7.1 › Multi-Primary Mode
Behavior and conflict detection
Any member can accept writes. When the consensus order exposes conflicts, Group Replication aborts the conflicting transaction to preserve a single consistent state. Applications must detect these aborts and implement retry or conflict-resolution strategies.
Example: concurrent updates to the same customer row across two nodes may cause one write to be aborted.
Misconception: multi-primary removes need for conflict-aware design — it requires it.
When to choose
Use multi-primary only if your application tolerates aborts or writes are naturally partitioned by keys or shards. Otherwise, single-primary reduces application complexity.
Takeaway: confirm your conflict-handling strategy before enabling multi-primary.
