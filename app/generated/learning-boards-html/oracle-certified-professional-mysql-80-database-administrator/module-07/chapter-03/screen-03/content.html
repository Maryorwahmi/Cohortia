Module 7 › Chapter: Managing MySQL InnoDB Cluster › Objectives — Tasks & Risks
4 Objectives — Cards
01
Prepare instances
Run dba.configureInstance to set GTID, server_id, and required privileges. This avoids manual errors during cluster join.
02
Bootstrap cluster
Use dba.createCluster to initialize Group Replication and mark the initial primary.
03
Add and remove members
Use cluster.addInstance and cluster.removeInstance to change membership while preserving cluster safety.
04
Configure Router
Bootstrap MySQL Router to provide a stable application endpoint and automatic failover handling.
Common Risk Checks
  • Verify GTID is enabled on every instance; missing GTID prevents safe group replication.
  • Ensure each server_id is unique; duplicate IDs break topology assumptions.
  • Confirm MySQL Shell user has administrative privileges for dba operations to succeed.
  • Open Router's listening ports on app servers so routing works post-bootstrap.
