Core dba commands
These commands perform validation and automation steps so you don't run individual SQL statements on each server. They create users, set required variables, and orchestrate group membership.
mysqlsh root@192.168.1.10:3306 --sql

# Prepare an instance
# dba.configureInstance('user@host:port')
dba.configureInstance('root@192.168.1.10:3306')

# Bootstrap a cluster
# dba.createCluster('mycluster')
dba.createCluster('mycluster')

# Add a prepared instance
# cluster.addInstance('user@host:port')
cluster.addInstance('root@192.168.1.11:3306')

# Check status
cluster.status()
Explanation & example
  • dba.configureInstance: validates prerequisites, sets GTID and replication variables, and creates required accounts.
  • dba.createCluster: bootstraps Group Replication using the prepared instance as the initial primary.
  • cluster.addInstance: performs state transfer and joins the instance to the group safely.
  • cluster.status: returns topology, roles, and status so you can confirm the cluster health.
Common mistake
Attempting to add an unprepared instance is a frequent error. dba.configureInstance prevents this by checking GTID, server_id, and required privileges before the join.
