Bootstrap steps
Select one prepared instance and run dba.createCluster. This sets group variables and makes that instance the primary. The command returns a cluster object for management.
# Example in MySQL Shell
# Assuming node prepared
dba.createCluster('MyCluster')

# Shell returns a cluster object used for management:
# mycluster = dba.getCluster('MyCluster')
# Then add other nodes with mycluster.addInstance(...)
Notes & checks
  • Bootstrap only one time per cluster; do not run createCluster from multiple nodes.
  • After bootstrapping, use the cluster object to add members and manage health.
  • Common mistake: assuming other prepared nodes join automatically; explicit addInstance calls are required.
Key Takeaway

Bootstrap once from a validated instance, then add others. Validate cluster.status immediately after bootstrapping to confirm topology.
