Preparation steps
1. Check GTID and binary logging
GTID must be enabled for Group Replication to work smoothly and for state transfer to function.
2. Ensure unique server_id
Duplicate identifiers break membership assumptions; dba.configureInstance verifies uniqueness.
3. Validate network reachability and ports
Nodes and the Shell must communicate over the appropriate network ports for safe joins and routing discovery.
4. Create required users
The function can create internal accounts needed for group replication and for Shell operations.

Pitfall
Skipping configuration means state transfer or join may fail later. Always resolve configureInstance warnings before proceeding.
