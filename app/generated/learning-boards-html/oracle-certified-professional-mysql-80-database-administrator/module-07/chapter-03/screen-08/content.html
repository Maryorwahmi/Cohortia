Module 7 › Chapter: Managing MySQL InnoDB Cluster › MySQL Router
Responsibilities
  • Provide a stable connection endpoint for applications.
  • Route write (read-write) traffic to the current primary.
  • Load-balance read-only traffic across secondaries.
  • Automatically adapt routing after primary failover.
Bootstrap example
mysqlrouter --bootstrap root@192.168.1.10:3306 --cluster-type=gr
Validation checklist
Check Router config file points to cluster
Verify Router listening ports are open to applications
Simulate primary failover and confirm write routing follows new primary
Common misconception
Router does not translate queries or change transaction behavior. It only directs connections based on cluster topology and configured routing policies.
