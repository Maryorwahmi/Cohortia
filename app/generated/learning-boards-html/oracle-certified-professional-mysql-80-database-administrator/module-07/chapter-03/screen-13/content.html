Module 7 › Chapter: Managing MySQL InnoDB Cluster › Commands & Checklist
dba.configureInstance()
Prepare a node by validating and applying recommended server settings and creating required accounts.
dba.createCluster()
Bootstrap Group Replication using the prepared instance as the initial primary.
mysqlrouter --bootstrap
Bootstrap Router to automatically generate configuration pointing to the cluster topology.
Final takeaway

Automate prepare → bootstrap → add → verify, and use Router to give applications a resilient endpoint. Automating the prepare and verify steps yields the best reliability gains.
