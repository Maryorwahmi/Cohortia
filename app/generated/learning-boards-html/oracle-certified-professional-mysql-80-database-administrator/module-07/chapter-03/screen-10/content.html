Module 7 › Chapter: Managing MySQL InnoDB Cluster › Add & Remove Instances
Add instance workflow
  1. Run dba.configureInstance on the target node and resolve warnings.
  2. Call mycluster.addInstance('user@host:port') from Shell connected to a cluster member.
  3. Monitor state transfer and confirm member shows ONLINE in cluster.status.
Example: mycluster.addInstance('root@192.168.1.13:3306')
Remove instance workflow
  1. Ensure the member is not the current primary. If it is, promote or allow failover first.
  2. Call mycluster.removeInstance('user@host:port') to remove gracefully.
  3. Confirm cluster.status no longer lists the removed member.
Pitfall: Forced removal without a graceful removeInstance can lead to split-brain scenarios or require manual cleanup.
