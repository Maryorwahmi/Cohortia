Managing MySQL InnoDB Cluster
Provision, operate, and route client traffic for a robust MySQL HA solution.
Interactive 16:9 Masterclass
This module teaches the operational workflow: prepare instances with MySQL Shell's dba utilities, bootstrap a Group Replication cluster with dba.createCluster, add and remove members safely, and configure MySQL Router for transparent client routing and automatic failover. Along the way we call out common pitfalls and the configuration checks that dba.configureInstance performs.

Routing

Concept Map
Group Replication
Provides the group protocol, replication, and automated failover that the cluster uses to keep data consistent.
MySQL Shell
Acts as the control plane with dba utilities that automate configuration, bootstrap, and membership operations.
MySQL Router
Provides an application-facing endpoint that routes writes to the PRIMARY and reads to SECONDARY nodes, and adapts automatically after failover.
