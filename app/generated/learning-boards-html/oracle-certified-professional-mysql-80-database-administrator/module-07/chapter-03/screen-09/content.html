Sample status output
{
  "clusterName": "mycluster",
  "defaultReplicaSet": {
    "name": "default",
    "primary": "192.168.1.10:3306",
    "status": "OK",
    "statusText": "Cluster is ONLINE and can tolerate up to 1 failure.",
    "topology": {
      "192.168.1.10:3306": { "role": "PRIMARY", "status": "ONLINE" },
      "192.168.1.11:3306": { "role": "SECONDARY", "status": "ONLINE" }
    }
  }
}
How to read it
  • Check statusText for overall cluster readiness and tolerable failures.
  • Confirm which host is primary and that it reports R/W mode.
  • Verify each member's status is ONLINE before relying on it for reads.
Pro Tip
Automate a status check after every administrative change and alert if any member reports OFFLINE or if the statusText indicates reduced fault tolerance.
