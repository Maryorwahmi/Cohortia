Module 7 › Chapter 7.4 › ProxySQL vs Router
ProxySQL
  • Query inspection and rewrite capabilities.
  • Connection pooling and caching options.
  • Flexible hostgroups for complex topologies.
MySQL Router
  • Lightweight proxy focused on InnoDB Cluster integration.
  • Simpler configuration and topology awareness.
  • Less fine-grained query routing.
Practical rule
Pick the tool that matches your requirements: advanced routing and pooling → ProxySQL; minimal cluster-aware routing → MySQL Router.
