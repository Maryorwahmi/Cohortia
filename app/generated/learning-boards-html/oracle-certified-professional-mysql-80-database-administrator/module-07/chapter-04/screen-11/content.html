Query digest example
SELECT * FROM stats_mysql_query_digest ORDER BY cnt DESC LIMIT 10;
SELECT * FROM stats_mysql_connection_pool WHERE hostgroup=20;
These queries show top queries and connection pool usage per hostgroup.
Verification checklist
  • Confirm SELECTs appear in stats_mysql_query_digest routed to replica hostgroup.
  • Confirm INSERTs go to primary hostgroup in runtime_mysql_servers.
  • Check stats_mysql_connection_pool for free vs used connections.
Key Takeaway
Use runtime stats to verify that query rules behave as expected and that pools do not become a bottleneck.
