Module 7 › Chapter 7.4 › What is ProxySQL
Definition and capabilities
  • Parses SQL and applies user-defined query rules to route or rewrite queries.
  • Maintains connection pools to backend MySQL servers to lower connection overhead.
  • Groups backend servers into hostgroups for logical routing of reads and writes.
  • Provides an admin interface for runtime inspection and persistent configuration.
Analogy
Think of ProxySQL as a traffic controller that inspects each SQL request and sends it to the correct lane.
Concrete example
A high-traffic API uses ProxySQL to route SELECTs to replicas. The primary handles INSERT and UPDATE. As read queries increase, Replica CPU is utilized instead of overloading the primary.
Key Takeaway

ProxySQL is a control layer for routing and pooling, not a replacement for MySQL clustering features.

Common mistake
Assuming rule order is irrelevant. Specific rules like matching SELECT must be evaluated before general patterns.
