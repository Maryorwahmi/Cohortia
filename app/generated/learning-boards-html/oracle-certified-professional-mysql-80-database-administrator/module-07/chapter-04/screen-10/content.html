Dynamic hostgroup mapping
ProxySQL can use group replication metadata to assign primaries to write hostgroups and replicas to read hostgroups, enabling automated routing when roles change.
Test failover behavior: confirm ProxySQL updates runtime_mysql_servers and that client traffic follows the new primary.
Practical caution
Multi-primary setups change consistency expectations. Decide whether certain transactions should always go to a designated primary to avoid conflicts.
Why it matters
Combining ProxySQL with MGR provides resilience and routing flexibility without replacing the cluster’s replication behavior.
