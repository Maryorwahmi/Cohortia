Module 7 › Chapter 7.4 › ProxySQL Components
Key tables
  • mysql_users — application credentials and default hostgroup.
  • mysql_servers — backend host entries with hostgroup_id and weight.
  • mysql_query_rules — pattern matching, destination hostgroup, and apply flag.
  • Admin interface — runtime inspection on port 6032 and client port typically 6033.
Load to runtime and save to disk are separate steps: make changes, LOAD ... TO RUNTIME; then SAVE ... TO DISK.
Architecture visual (cards)

Key Takeaway

ProxySQL’s tables are the source of truth for routing; always validate changes with runtime stats before saving.
