Module 7 › Chapter 7.4 › Troubleshooting
Top causes
  • Incorrect regex order in mysql_query_rules.
  • Backend credential mismatch preventing pooled connections.
  • Firewall blocking ProxySQL client port.
  • Mixing reads and writes in transactions without routing to primary.
Step-by-step debug
  1. Check runtime_mysql_servers for expected backends.
  2. Inspect stats_mysql_connection_pool for pool anomalies.
  3. Query stats_mysql_query_digest to see which rules matched.
  4. Test app-level queries to reproduce the issue and verify routing.
Common mistake
Assuming backend health implies client connectivity — always check the client-facing port and firewall rules first when facing connection failures.
