Module 7 › Chapter 7.4 › Connection Pooling
How pooling works
  1. ProxySQL maintains persistent connections to backends.
  2. Client sessions are mapped onto these persistent backend connections.
  3. When a client finishes, the backend connection returns to the free pool.
Pro Tip
Watch stats_mysql_connection_pool to tune min and max connections per host to match workload.
Concrete scenario
A REST API with many short-lived requests reduces load on MySQL by using ProxySQL pools. Instead of 10,000 new backend connections per minute, ProxySQL reuses 200 persistent connections.
Key Takeaway

Pooling reduces connection overhead, but test pool size to avoid becoming the bottleneck.
