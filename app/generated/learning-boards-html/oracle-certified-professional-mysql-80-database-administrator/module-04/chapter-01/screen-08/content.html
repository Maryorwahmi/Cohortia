Module 4 › Chapter 4.1 › Physical backups
Definition

Physical backups

Copy raw data files at the filesystem level; often much faster for large, active systems.

Advantages
  • Fast backup and restore for large datasets.
  • Tools support hot backups while the server runs.
Caveats
  • Less portable across MySQL versions and file formats.
  • Requires careful prepare/recovery steps to ensure consistency.
Key Takeaway

Choose physical backups for speed and minimal downtime, and account for prepare steps and version compatibility during restores.

Tools & process
Percona XtraBackup
Hot physical backups for InnoDB with prepare step to apply redo logs.
MySQL Enterprise Backup
Vendor-supported physical backup tool with similar prepare/restore workflow.
Restore pattern
Copy files back, run the prepare step to apply committed transactions, then start the server to complete recovery.
