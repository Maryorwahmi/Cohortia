Definition

Logical backups with mysqldump

Exports data as SQL statements that can be inspected, edited, and applied on restore.

Advantages
  • Highly portable and human-readable.
  • Useful for schema migrations and targeted restores.
Disadvantages
  • Slow for very large databases, both export and restore.
  • Can impose heavy load on a live server during export.
Key Takeaway

Use logical backups when portability and readability matter; avoid them for multi-terabyte active systems unless downtime is acceptable.

Example export preview
-- CREATE TABLE users (...) ;
INSERT INTO users (id, name, email) VALUES (1, 'Alice', 'a@example.com');
-- Many INSERT statements follow for each row
When to pick this
Small to medium datasets, migrations, or when human-readable recovery is required.
