Backup families and restore implications

Understand how each backup type is created and the exact sequence needed for restores.

Full backup
Complete snapshot at a point in time. Needed as the base for incremental and differential restores.
Incremental backup
Captures changes since the last backup of any type. Restores require applying every incremental after the full backup.
Differential backup
Captures changes since the last full backup. Restore needs only the full plus the latest differential.
Key Takeaway

Balance restore complexity against storage: incrementals save space but add restore steps; differentials simplify restore at the cost of larger backups over time.

When documenting your strategy, include exact restore ordering and estimate the time needed to apply every incremental or the latest differential so you can validate RTO targets.
