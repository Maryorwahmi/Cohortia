Architecture

Binary logs and continuous archiving

Combine base backups with archived binary logs to replay transactions and achieve point-in-time recovery.

How it works
  • Take a base backup (full or physical).
  • Archive binary logs continuously to offsite storage.
  • On restore, apply the base backup then replay binary logs to the desired point in time.
Key Takeaway

Binary log archiving bridges the gap between backups and tight RPOs by allowing transaction replay up to a precise moment.

Operational checklist
  • Enable binary logging and set secure retention policies.
  • Continuously ship logs to offsite or separate storage.
  • Document which log files and positions correspond to each base backup.
  • Test replaying logs after restoring a base backup to confirm point-in-time recovery.
Including log archiving in your plan is often the difference between hours of data loss and minutes or even seconds.
