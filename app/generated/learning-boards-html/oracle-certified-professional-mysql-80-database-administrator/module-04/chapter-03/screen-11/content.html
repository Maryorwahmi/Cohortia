Module 04 › Chapter 4.3 › Permissions & LSNs
Datadir
Confirm --datadir points to the live MySQL data directory when running backups or copy-back operations.
Permissions
After copy-back set ownership to mysql:mysql and secure permissions so MySQL can read and write files.
LSN & Binlog
Inspect prepare output for final LSNs and review xtrabackup_binlog_info for binlog coordinates used in point-in-time recovery.
Practical check
Before restoring, document the current my.cnf innodb settings and compare them to those used during backup. Restore first to a test server when possible to validate settings and data integrity.
