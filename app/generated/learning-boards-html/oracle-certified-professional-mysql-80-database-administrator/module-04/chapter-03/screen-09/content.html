Module 04 › Chapter 4.3 › Prepare Step
What prepare does
  • Reads redo logs saved during backup and applies committed transactions.
  • Rolls back any uncommitted transactions to produce a crash-consistent image.
  • Records final LSNs indicating the point to which logs were applied.
If you skip it

MySQL may fail to start or report corruption because the copied files are not consistent without applying redo.

Command
sudo xtrabackup --prepare --target-dir=/data/backups/full_backup_YYYYMMDD_HHMMSS
Review output for LSN processed lines and a final confirmation that the backup is prepared.
Check

After prepare, the files in the target directory are ready for copy-back; confirm the final LSN and absence of errors in the prepare output.
