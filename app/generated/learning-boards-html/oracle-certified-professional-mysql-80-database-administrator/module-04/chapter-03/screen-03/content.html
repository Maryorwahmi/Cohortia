Practical skills and safety checks
Actions you will perform and verify in a lab environment.
Restore Execution
Stop MySQL, copy prepared files back, chown mysql:mysql, set permissions, and start the server.

VERIFIED COMPETENCY MILESTONE
Permissions & Disk Space
Ensure destination has sufficient free space and set ownership to mysql:mysql after copy-back.
