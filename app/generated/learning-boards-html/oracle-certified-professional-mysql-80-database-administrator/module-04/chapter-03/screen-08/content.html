Module 04 › Chapter 4.3 › xtrabackup --backup
Starter commands (example)
# Create directory
mkdir -p /data/backups/full_backup_$(date +%Y%m%d_%H%M%S)

# Perform the backup
xtrabackup --backup --target-dir=/data/backups/full_backup_20220101_120000 \
  --user=backup_user --password=StrongPassword123! --datadir=/var/lib/mysql
Watch for progress, LSN values, and the creation of xtrabackup_binlog_info in the target directory.
What to check after backup
  • xtrabackup_binlog_info exists and contains binlog coordinates.
  • Backup finished without errors and reported final LSN.
  • Target directory has expected files and sufficient free space remained.
Danger

Do not attempt to restore from these raw files until you run xtrabackup --prepare.
