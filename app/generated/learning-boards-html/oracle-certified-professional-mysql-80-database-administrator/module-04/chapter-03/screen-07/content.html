Installation and user grants
  1. Install percona-xtrabackup-80 via your package manager on the MySQL host.
  2. Create a backup user and grant RELOAD, PROCESS, LOCK TABLES, REPLICATION CLIENT, BINLOG ADMIN, BACKUP_ADMIN.
  3. Verify connectivity and privilege checks by running a test command with that user.
Mnemonic: install, grant, verify.
Target directory & capacity
Create a timestamped directory for each backup and ensure free space equals at least the live data size plus headroom for prepare. For example, mkdir -p /data/backups/full_backup_$(date +%Y%m%d_%H%M%S).
Common mistake

Using an undersized or slow backup target prolongs backups and can cause prepare to fail due to insufficient temp space.
