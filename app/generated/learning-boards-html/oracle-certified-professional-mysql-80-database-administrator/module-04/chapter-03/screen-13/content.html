Module 04 › Chapter 4.3 › Key Concepts
Physical Backup
Copy raw .ibd and redo logs for faster backup and restore on large datasets.
Hot Backup
Backup while server runs by capturing LSN and redo logs to allow later prepare.
Prepare & Restore
Run xtrabackup --prepare, then xtrabackup --copy-back, fix ownership, and start MySQL.
Summary

Physical hot backups plus prepare give speed and low downtime, but require careful configuration, permissions, and validation to be reliable in production.
