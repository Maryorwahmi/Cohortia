Module 04 › Chapter 4.3 › Checklist
Check metadata
Confirm xtrabackup_binlog_info and LSN values are present in the backup directory.
Run prepare
Execute xtrabackup --prepare and verify it applied redo logs successfully.
Fix permissions
After copy-back run chown -R mysql:mysql and set secure directory permissions.
Final thought

Make these three checks routine to turn backups into dependable recoveries rather than hopeful guesses.
