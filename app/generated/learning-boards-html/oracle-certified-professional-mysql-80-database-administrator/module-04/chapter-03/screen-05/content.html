Module 04 › Chapter 4.3 › Hot InnoDB Backup
Definition
A hot InnoDB backup copies raw files while the server is online, capturing the LSN and redo logs needed for later prepare.
Key points:
  • InnoDB transactions use redo logs to record committed changes.
  • A hot backup records the LSN and redo metadata alongside the copied files.
  • The prepare step uses those logs to make the copied files consistent.
Misconception

Hot means zero impact. In practice, hot backups still consume disk and CPU and require correct privileges; plan accordingly.

Annotated workflow
Snapshot files
xtrabackup copies table space files and .frm metadata while server writes concurrently.
Record LSN
The tool records the LSN and creates xtrabackup_binlog_info for binlog coordinates.
Prepare
Applying redo rolls forward committed transactions and removes uncommitted changes.
Restore
After copy-back and permission fixes, MySQL starts and performs normal crash recovery if needed.
