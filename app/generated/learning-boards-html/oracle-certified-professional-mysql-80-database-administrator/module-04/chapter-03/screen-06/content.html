Module 04 › Chapter 4.3 › Percona XtraBackup
Capabilities
  • Full, incremental, and differential physical backups for InnoDB and MyISAM.
  • Hot backup support via LSN capture and recording of binlog coordinates.
  • Prepare step to apply redo logs and produce a consistent image.
Required privileges
RELOAD, PROCESS, LOCK TABLES, REPLICATION CLIENT, BINLOG ADMIN, BACKUP_ADMIN. These let XtraBackup read server state and report binlog positions safely.
Architecture summary
XtraBackup copies files while querying the server for LSN and binlog positions, writing both files and metadata into the target directory for later prepare and restore.
Pro tip

Confirm --datadir matches the live MySQL data directory. A mismatch produces incomplete backups.
