Module 04 › Chapter 4.3 › Mistakes & Practices
Common mistakes
  • Forgetting to run xtrabackup --prepare before restore.
  • Copying prepared files but not fixing ownership; MySQL cannot start.
  • Insufficient disk space for backup or prepare steps.
Best practices
  • Use timestamped backup directories and keep xtrabackup_binlog_info for recovery planning.
  • Restore to a test server first to validate the backup before touching production.
  • Document and compare my.cnf settings to ensure compatibility on restore.
Key Takeaway

A working backup process includes preparation, validation, and regular restore testing. These steps transform a backup from a file copy into a reliable recovery asset.
