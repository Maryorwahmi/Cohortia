Module 04 › Chapter 4.3 › Restore Procedure
Step-by-step commands
# Stop MySQL
sudo systemctl stop mysql

# (Optional) Clear existing data - destructive
# sudo rm -rf /var/lib/mysql/*

# Copy prepared files back
sudo xtrabackup --copy-back --target-dir=/data/backups/full_backup_YYYYMMDD_HHMMSS --datadir=/var/lib/mysql

# Fix permissions
sudo chown -R mysql:mysql /var/lib/mysql
sudo chmod -R 750 /var/lib/mysql

# Start MySQL
sudo systemctl start mysql
Verification checklist
  • MySQL process starts without corruption errors.
  • Expected tables and data are present; run SELECT checks.
  • Confirm xtrabackup_binlog_info if point-in-time recovery is needed.
Caution

Double-check you are restoring prepared files and not overwriting a live production directory unintentionally.
