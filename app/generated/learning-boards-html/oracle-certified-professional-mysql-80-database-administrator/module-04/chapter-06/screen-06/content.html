What is GFS?

Grandfather-Father-Son is a rotation scheme: daily (son), weekly (father), monthly (grandfather). It reduces storage while keeping history.

  • Example: 7 daily, 4 weekly, 12 monthly and 1 yearly copy.
  • Adjust counts for compliance and restore needs.
Common mistake

Retaining everything without purging. This leads to failed backups when targets run out of space.

Implementation

Use automated scripts and server settings. For binary logs, consider expire_logs_days. For files, use find with mtime to delete older backups.
