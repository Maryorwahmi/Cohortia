Module 4 › Chapter 4.6 › Encrypt & Upload
Command Example
# Encrypting a mysqldump backup with GPG
mysqldump -u root -p mydatabase | gzip | gpg --encrypt --recipient "backup_key_id" > mydatabase_backup.sql.gz.gpg

# Uploading to S3 (AWS CLI)
aws s3 cp mydatabase_backup.sql.gz.gpg s3://my-cohortia-backup-bucket/
Note: the operator needs the private key to decrypt before restore. Never store keys with the backups.
Verification
  • Confirm exit code was zero.
  • Check file size and a checksum if available.
  • Verify upload by checking the cloud object's presence and size.
Pro tip
Use recipient keys managed in a keyring and rotate keys on schedule. Test decryption regularly in a safe environment.
