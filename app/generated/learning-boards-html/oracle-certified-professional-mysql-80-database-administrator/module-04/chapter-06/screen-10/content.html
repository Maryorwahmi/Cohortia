Module 4 › Chapter 4.6 › Offsite & Encryption
Pipeline
  1. Create backup and verify success.
  2. Encrypt backup file before transfer.
  3. Upload using secure protocol and verify upload.
  4. Only then purge local copies per retention policy.
Misconception

Assuming cloud storage alone is sufficient. You still must manage encryption keys and retention policies.

Example Tools
  • Encrypt: GPG before transfer.
  • Transfer: SFTP, SCP, or HTTPS-based uploads to object storage.
  • Cloud: object storage buckets with server-side encryption enabled.
