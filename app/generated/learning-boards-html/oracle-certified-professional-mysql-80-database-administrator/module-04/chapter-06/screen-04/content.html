Module 4 › Chapter 4.6 › DR Plan Defined
Definition

Disaster Recovery Plan

A documented, tested sequence of actions, roles, and tools to restore service after a disaster.

  • RTO/RPO targets and how they translate to backups
  • Roles: incident owner, recovery operator, communications lead
  • Recovery verification steps and test schedule
Key Takeaway

Document the who, what, where, and how for restores; pair documentation with offsite backups.

Example

Example scenario: The primary DB host is lost. The DR plan lists the latest full backup and binary log range, the dry-run restore host, the verification queries to run, and the communication checklist to inform stakeholders.

Common misconception

A backup file alone is sufficient. It is not unless the restore steps, credentials, and verification process are known and tested.

Pro tip

Store a copy of the runbook in the same offsite location as your backups so it survives site failures.
