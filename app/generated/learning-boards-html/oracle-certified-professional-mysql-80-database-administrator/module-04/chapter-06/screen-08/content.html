Module 4 › Chapter 4.6 › Monitoring Backups
Essential Checks
  • Backup job exit status and log parsing for errors.
  • Backup file presence, readable integrity, and expected size.
  • Binary log retention and growth monitoring.
  • Disk space on backup targets and upload destinations.
  • Replication status if used for DR.
Alerting Strategy

Send alerts on non-zero exit codes, missing files, small file sizes, or rapid log growth. Tie alerts to on-call rotations and escalation policies.

Misconception

Relying only on timestamps. A job can run and still produce corrupted or incomplete backups.
