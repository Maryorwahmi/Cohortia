Module 4 › Chapter 4.6 › Retention Automation
Automation Pattern
  1. Run backup script on schedule.
  2. Verify success via exit code and file size.
  3. Transfer to offsite target and confirm upload.
  4. Only then purge local files older than retention window.
Pitfall

Deleting local files before a successful offsite copy can leave you without any recoverable copy.

Checks to implement
  • Monitor exit codes and scan logs for error keywords.
  • Check file sizes and ensure they are within expected range.
  • Validate offsite upload completion before deleting local copies.
