Module 04 › Chapter 4.2 › Permissions & Privileges
Minimum privileges
  • SELECT on exported objects
  • SHOW VIEW to dump views
  • PROCESS for some status reads
  • RELOAD for --flush-logs
  • REPLICATION CLIENT for --master-data
Misconception: using root is required. In practice, a dedicated backup user with narrowly scoped privileges is safer and sufficient when configured correctly.
Practical safeguard
Create a dedicated backup user, grant only the needed privileges, and store credentials in a secured my.cnf file with restricted file permissions.
Key Takeaway

A properly-privileged backup user prevents silent omissions and supports automation without exposing full administrative credentials.
