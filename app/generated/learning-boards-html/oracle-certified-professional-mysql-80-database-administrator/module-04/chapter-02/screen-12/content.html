Module 04 › Chapter 4.2 › Large Files & Compression
Compression pattern
mysqldump -u root -p mydatabase | gzip > backup.sql.gz gunzip < backup.sql.gz | mysql -u root -p mydatabase
Benefits: smaller storage and network use. Tradeoff: CPU for compression and additional time for decompression during restore.
Performance considerations
  • Logical restores rebuild indexes and replay many statements, which can be slow.
  • Physical backups are faster to restore for very large data volumes.
Key Takeaway

Compress dumps to save space; accept decompression and import time. For massive data sets, evaluate physical backups.
