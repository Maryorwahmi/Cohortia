Module 04 › Chapter 4.2 › Key Concepts
mysqldump
Command-line tool that exports schema and data as SQL statements.
--single-transaction
Provides a consistent InnoDB snapshot via a transaction.
--master-data / --flush-logs
Record binary log position and rotate logs for replication and PITR.
Summary takeaway

Use mysqldump with the right options to produce consistent, complete, and recoverable logical backups; verify by restoring and inspecting objects.
