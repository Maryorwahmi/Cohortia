Module 04 › Chapter 4.2 › Basic mysqldump Commands
Command examples
mysqldump -u root -p mydatabase > mydatabase_backup.sql

mysqldump -u root -p --databases db1 db2 > multiple_databases_backup.sql

mysqldump -u root -p --all-databases > all_databases_backup.sql
Notes
  • Single database dumps do not include CREATE DATABASE unless you used --databases.
  • Verify the dump file size and sample the top to confirm CREATE TABLE statements exist.
Key Takeaway

Pick the right mode: single DB for portability, --databases for multiple DBs, --all-databases for full exports.

What to check in the dump
Presence of CREATE TABLE and INSERT statements
For --databases, check for CREATE DATABASE and USE statements
Inspect top of file for comments and metadata
Example scenario
You need to copy a development schema to another host. Run a single-database dump and restore on the target with the mysql client, then verify tables and sample rows.
