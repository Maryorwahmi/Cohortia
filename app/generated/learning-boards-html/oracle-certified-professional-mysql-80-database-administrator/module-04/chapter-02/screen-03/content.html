Options and Troubleshooting

Practical flags and how to avoid common operational mistakes.

--master-data
Embeds binary log filename and position so you can resume replication or perform point-in-time recovery.
--flush-logs
Rotates binary logs before the dump so the recorded position is at the start of a new file.
--routines, --triggers, --events
Include stored procedures, triggers, and scheduled events; these are not dumped by default.
Common mistakes
Character set mismatches, insufficient privileges, and huge uncompressed files are frequent causes of backup failure.
