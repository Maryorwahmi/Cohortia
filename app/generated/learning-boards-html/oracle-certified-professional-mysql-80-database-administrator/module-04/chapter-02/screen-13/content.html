Starter commands and hints
# Create sample DB and objects (run in mysql client)
CREATE DATABASE IF NOT EXISTS cohortia_app;
-- create tables, insert sample data, create procedure and trigger

# Dump with routines and master-data
mysqldump -u root -p --single-transaction --master-data=2 --routines --triggers cohortia_app > cohortia_app_full_backup.sql

# Simulate loss
# DROP TABLE orders; DROP PROCEDURE get_user_orders;

# Restore
mysql -u root -p cohortia_app < cohortia_app_full_backup.sql
Verification hints
  • SHOW TABLES; expect users, products, orders.
  • SELECT * FROM orders; check sample rows and timestamps.
  • SHOW PROCEDURE STATUS to confirm get_user_orders exists.
Key Takeaway

Follow the dump, simulate failure, restore, and verify both data and programmatic objects to ensure a complete recovery.
