Module 04 › Chapter 4.2 › Mistakes & Safety
Missing --single-transaction
Leads to inconsistent InnoDB dumps when concurrent writes occur.
Omitted routines/triggers
Application logic missing after restore unless --routines and --triggers are used.
Charset mismatches
Use --default-character-set to avoid corrupted text.
Permissions and automation
Grant the required privileges to a dedicated backup user and avoid exposing root credentials in scripts.
Large-file handling
Compress streams and consider physical backups when logical restores are too slow.
Pro tip

Always run a test restore periodically to ensure backup integrity and to exercise restore procedures.
