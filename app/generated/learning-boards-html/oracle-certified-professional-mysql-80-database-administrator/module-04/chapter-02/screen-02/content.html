Learning Objectives

Practical skills you will demonstrate after this chapter.

Bloom: Learn → Understand → Apply → Master
01
Create full database dumps
Run mysqldump to export a database into an SQL file for transfer or archival. Practice matters because it creates a portable snapshot you can restore elsewhere.
VERIFIED COMPETENCY MILESTONE
02
Selective dumps: tables, schema, or data-only
Use options like --no-data and listing tables to control what is exported. This helps when moving schema separately from large data sets.
VERIFIED COMPETENCY MILESTONE
03
Ensure consistency for InnoDB
Apply --single-transaction and understand its snapshot semantics to avoid inconsistent dumps from concurrent writes.
VERIFIED COMPETENCY MILESTONE
04
Restore and verify dumps
Use the mysql client to restore dumps and verify the presence of tables, procedures, and triggers. Verification prevents surprises in recovery.
VERIFIED COMPETENCY MILESTONE
