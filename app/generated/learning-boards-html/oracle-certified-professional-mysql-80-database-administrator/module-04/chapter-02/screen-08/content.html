Module 04 › Chapter 4.2 › Schema vs Data
Schema-only: --no-data
Exports CREATE TABLE, indexes, and constraints without any row data. Useful for versioning DDL or preparing empty schemas on new hosts.
mysqldump -u root -p --no-data mydatabase > schema_only.sql
Data-only: --no-create-info
Exports INSERT statements only. Use when the target schema already exists and you need to populate or migrate rows.
mysqldump -u root -p --no-create-info mydatabase > data_only.sql
Key Takeaway

Split schema and data when you need separate lifecycles for DDL and row data, or to reduce restore time for large datasets.
