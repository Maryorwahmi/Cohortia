Process Flow
Restore from Snapshot
Merging reverts the origin to the snapshot moment. Stop MySQL first, then run the merge, then restart and verify.
Step 1 — Stop MySQL
Ensure the server is stopped so files are not in use during merge.
Step 2 — Merge the snapshot
Run the merge operation to restore the origin LV to the snapshot state. The snapshot LV is removed automatically after merge.
Step 3 — Restart and verify
Start MySQL and run queries to confirm the expected records are present and no extra writes occurred after the snapshot.
Common restore issue

After merge MySQL may fail to start due to ownership or permission mismatches. Fix ownership to mysql:mysql and set directory permissions appropriately before starting.

Concrete example

Stop service, run the merge, chown -R mysql:mysql /var/lib/mysql if needed, then start and validate the recovered table contents.
