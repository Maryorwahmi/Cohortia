Process Flow
Create an LVM Snapshot
Step A — Confirm LV location
Ensure /var/lib/mysql resides on an LV like /dev/vg_mysql/lv_mysql_data.
Step B — Acquire FLUSH TABLES WITH READ LOCK
Keep this session open until snapshot creation completes.
Step C — Create snapshot
Use lvcreate -s with a snapshot name and size sized for write volume.
Step D — Release lock and copy snapshot data
Mount the snapshot and copy to your backup target, then remove the snapshot.
Sizing guideline

Start with roughly 10–20% of origin volume size as a snapshot allocation and adjust based on observed write activity during retention.

Operational tip

Automate cleanup and monitoring so snapshots do not accumulate or let the copy-on-write area fill, which would lead to failed snapshots or performance impact.

Concrete example

Create a 10G snapshot of /dev/vg_mysql/lv_mysql_data, mount it to /mnt/mysql_snapshot, copy files to your backup store, then unmount and lvremove the snapshot.
