Process Flow
Mount, Copy, Clean
Make a reliable copy from the mounted snapshot and remove the snapshot when finished to reclaim space and avoid performance impacts.
Mount the snapshot
Create /mnt/mysql_snapshot and mount the snapshot LV there for read access.
Copy with verification
Copy files using a reliable tool and run integrity checks before deleting the snapshot.
Unmount and remove
Unmount the snapshot and run lvremove to delete the snapshot LV and free space.
Concrete scenario

Mount at /mnt/mysql_snapshot, rsync the data directory to a network backup, verify file checksums, then unmount and remove the snapshot LV.

Warning

Do not treat the snapshot mount as a place to perform live writes or schema migrations — it represents a frozen point-in-time copy for backup or recovery.
