Module 04 › Chapter 4.5 › Key Concepts
Filesystem Snapshot
A copy-on-write point-in-time image of a volume created almost instantaneously.
LVM Snapshot
A snapshot LV that references an origin LV and tracks changes for copy-on-write.
FLUSH TABLES WITH READ LOCK
Ensures on-disk consistency by flushing dirty pages and preventing writes during snapshot creation.
Takeaway

Snapshots are a fast and practical backup method when combined with log retention and offsite copies; plan sizing and lifecycle carefully.
