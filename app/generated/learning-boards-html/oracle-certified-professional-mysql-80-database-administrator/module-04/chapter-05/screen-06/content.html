Process Flow
Prepare MySQL
Acquire a global read lock to flush dirty pages and prevent writes before snapshot creation.
Step 1 — Acquire lock
Run the flush-and-lock command and keep that session open until the snapshot creation completes.
Step 2 — Create snapshot in separate terminal
Use your LVM snapshot command while the lock is still held, then immediately unlock.
Why keep the session open?

Closing the session releases the global read lock. If you close it before snapshot creation completes, the snapshot may capture an inconsistent mix of old and new writes.

Concrete example

Open Terminal A: run the flush-and-lock command and keep it open. Open Terminal B: run the lvcreate snapshot command. After lvcreate finishes, return to Terminal A and run unlock tables.

Common mistake

Do not run the lock and then close the session before creating the snapshot. Closing releases the lock and breaks consistency.
