Definition
LVM Layers
Physical Volume (PV)
A disk or partition added to LVM's pool.
Volume Group (VG)
A storage pool combining one or more PVs.
Logical Volume (LV)
A block device carved from a VG for filesystems or applications.
Snapshot LV

A snapshot LV references an origin LV and stores changed blocks in a separate area using copy-on-write.

Verify your layout
Run the standard LVM listing commands to confirm that /var/lib/mysql is on an LV you can snapshot. If it is not on an LV, snapshots are not available without migration.
Concrete example

If your data LV is /dev/vg_mysql/lv_mysql_data you will create a snapshot LV referencing that origin. The snapshot consumes separate space for changed blocks while the origin continues serving IO.
