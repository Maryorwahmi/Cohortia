Command Panel (illustrative)
# Terminal 1: hold lock
mysql -u root -p -e "FLUSH TABLES WITH READ LOCK;" -- keep session open
# Terminal 2: create snapshot
sudo lvcreate -L 10G -s /dev/vg_mysql/lv_mysql_data -n mysql_data_snapshot_YYYYMMDD_HHMMSS
# After lvcreate completes
mysql -u root -p -e "UNLOCK TABLES;"
# Mount snapshot and copy
sudo mount /dev/vg_mysql/mysql_data_snapshot_YYYYMMDD_HHMMSS /mnt/mysql_snapshot
Safe practices
  • Keep the lock session open until lvcreate confirms.
  • Pick snapshot names with timestamps and remove them when done.
  • Monitor snapshot LV usage; avoid letting it fill.
Common mistake

Assuming snapshot creation copies files immediately; it is metadata-fast but the copy-on-write area grows as writes occur.
