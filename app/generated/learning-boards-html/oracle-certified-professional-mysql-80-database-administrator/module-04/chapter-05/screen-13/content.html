Hands-on Activity
Perform and Restore an LVM Snapshot
Follow the sequence in a controlled environment that has LVM configured and /var/lib/mysql on an LV.
Step 1 — Prepare
Create a test database and insert an initial record to mark the snapshot time.
Step 2 — Snapshot
From Terminal A, hold a global read lock. From Terminal B, create the snapshot LV. Confirm snapshot exists, then unlock.
Step 3 — Simulate and restore
Add rows, then simulate loss. Stop MySQL, merge the snapshot, start MySQL, and verify only initial rows remain.
Verification

Log into MySQL and query the test table. The table should reflect state at the snapshot moment, demonstrating the snapshot's consistency.

Lab question

Which step would fail your recovery if you forgot to verify snapshot presence before unlocking? Consider the consequence and how you'd detect it in logs.
