Sizing & monitoring

Estimate snapshot size using a 10–20% guideline and watch the copy-on-write area while snapshots are active. Overfill can break snapshots.

Mnemonic
⚑
Snapshot = Fast copy, small guard space
When to choose snapshots

Snapshot when the volume supports it and you need quick backups with minimal application interruption. Combine with binlogs for finer recovery points.
