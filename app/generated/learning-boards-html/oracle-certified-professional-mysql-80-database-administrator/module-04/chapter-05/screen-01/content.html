Snapshot Backups and Filesystem-Level Approaches
Fast, point-in-time copies for MySQL data using LVM, ZFS, Btrfs or storage snapshots.
Why this matters

Snapshots let you capture the entire data volume instantly and minimize the time you hold MySQL locks. That reduces application downtime and meets tight recovery objectives.
