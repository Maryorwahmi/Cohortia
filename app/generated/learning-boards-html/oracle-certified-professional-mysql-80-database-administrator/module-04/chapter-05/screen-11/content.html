Comparison
ZFS & Btrfs vs Arrays & Cloud
ZFS / Btrfs
Native filesystem snapshots with copy-on-write semantics and fine control on host.
Storage array snapshots
Hardware-level snapshots that offload work and can be the fastest option in enterprise systems.
Cloud disk snapshots
Provider-managed block snapshots that are convenient for cloud-hosted MySQL instances.
Practical note

Regardless of storage technology, acquire database consistency before triggering a snapshot. The exact API or command varies by system but the principle stays the same.

Misconception check

Don’t assume cloud snapshots automatically provide offsite long-term retention. They still need lifecycle and export planning for disaster recovery.

Concrete decision example

If you need minimal server CPU impact, prefer array or cloud snapshots; if you want full filesystem features locally, prefer ZFS or Btrfs.
