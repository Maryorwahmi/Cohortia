Module 04 › Chapter 4.4 › PITR Example
High-level steps
  1. Restore the full backup dump to a test or recovery server.
  2. Identify the backup's binlog file and position recorded in the dump.
  3. Run mysqlbinlog from that position up to the stop-datetime and pipe to mysql.
  4. Confirm recovered rows are present and the incident is excluded.
Example command (visual only)
mysql -u root -p < full_backup_0800.sql
mysqlbinlog --start-position=1234 --stop-datetime="2023-10-27 10:29:59" \
  /var/log/mysql/mysql-bin.000005 /var/log/mysql/mysql-bin.000006 | mysql -u root -p
Review the extracted SQL before applying to avoid unintended side effects.
