Code Walkthrough

View and filter binlogs

Common commands
mysqlbinlog /var/log/mysql/mysql-bin.000001
mysqlbinlog --start-datetime="2023-10-27 08:00:00" --stop-datetime="2023-10-27 10:29:59" /var/log/mysql/mysql-bin.000005 | mysql -u root -p
Use datetime or position filters and include all files spanning your desired range.
Start/Stop datetime
Select events in a clock range when timestamps are known.
Start/Stop position
Use byte positions recorded with your backup for precise starts.
Key Takeaway

Practice extracting small time slices first, then expand to multiple files when you confirm the event order.

Practical tip

Always examine the binlog stream for transactions that affect multiple tables or include non-obvious side effects before piping to mysql.

Example workflow
Dump the binlog to a file first for review, then pipe to mysql after you confirm the stop point.
