Module 04 › Chapter 4.4 › PITR Steps
Process
  1. Restore the most recent full backup to the target server.
  2. Find the backup's starting binary log file and position (from master data or xtrabackup info).
  3. Choose the stop point just before the incident (timestamp or position).
  4. Use mysqlbinlog with start-position and --stop-datetime or similar to extract events.
  5. Pipe the output into mysql to apply the events to the restored database.
Verification
After replaying events, query the affected tables to ensure expected rows and timestamps exist and that the erroneous change was not applied.
Key Takeaway

Follow the restore, extract, and apply checklist precisely; the start position from the backup is critical to avoid duplication or missing events.
