Module 04 › Chapter 4.4 › Configure binlog
Process Flow

Enable and verify

  1. Add log_bin, server_id, and other options to my.cnf.
  2. Restart MySQL so configuration takes effect.
  3. Verify with SHOW VARIABLES LIKE 'log_bin'; and SHOW BINARY LOGS;
  4. Adjust expire_logs_days and max_binlog_size for retention and rotation.
Key Takeaway

Configuration plus verification prevents surprises; always check server_id uniqueness and confirm binlogs appear after restart.

Example my.cnf snippet
[mysqld]
log_bin = /var/log/mysql/mysql-bin.log
server_id = 1
binlog_format = ROW
expire_logs_days = 7
max_binlog_size = 100M
Restart the server after editing /etc/my.cnf or your distribution's mysqld configuration file, then run verification commands to confirm binlogs are active.
