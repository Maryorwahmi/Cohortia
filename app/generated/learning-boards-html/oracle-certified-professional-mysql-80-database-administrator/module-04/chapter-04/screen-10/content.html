Module 04 › Chapter 4.4 › Rotation & Retention
Rotation

max_binlog_size determines when MySQL rotates to a new binary log file. Combine rotation with a sensible naming and monitoring policy so you can locate events quickly.

Auto purge option
expire_logs_days removes binlogs older than the set number of days. Choose this value based on the maximum period you may need to recover.
Manual purge
PURGE BINARY LOGS TO 'mysql-bin.000008';
PURGE BINARY LOGS BEFORE '2023-10-20 10:00:00';
Use manual purge for immediate space recovery, but confirm that replicas do not need the files and that you have offsite copies if required.
Operational Tip

Monitor disk usage and align expire_logs_days with your RPO; archive necessary binlogs before MySQL purges them.
