Module 04 › Chapter 4.4 › Verify PITR
Verification checklist
  • Query known primary keys and created_at ranges to ensure expected rows exist.
  • Compare row counts for affected tables against pre-incident snapshots.
  • Check foreign key integrity and any application-level invariants.
  • Review binlog filenames and positions used for the operation and record them.
Key Takeaway

Run multiple, targeted checks after PITR so you have confidence the state is correct and reproducible.

Example checks
SELECT count(*) FROM important_data WHERE created_at <= '2023-10-27 10:29:59'; and specific SELECTs for rows added after backup.
