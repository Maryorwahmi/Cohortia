Module 04 › Chapter 4.4 › Binlog Format Comparison
Comparison
STATEMENT
Logs SQL statements. Smaller but can be non-deterministic for some functions and lead to inconsistent replicas.
ROW
Logs row-level changes. Larger files but safer and recommended for MySQL 8.0 for accurate replication and PITR.
MIXED
Uses statement-based logging by default and switches to row-based when necessary to avoid unsafe behavior.
Concrete scenario
If your application uses non-deterministic SQL like functions that read the system time or random generators, STATEMENT can cause replicas to diverge. ROW records the exact changed rows and avoids this pitfall.
When to prefer ROW
Production systems that require reliable replication and precise PITR should use ROW even if it increases storage usage.
Misconception
Choosing STATEMENT purely for space savings exposes you to harder-to-diagnose replication or recovery failures.
Key Takeaway

Prefer ROW for MySQL 8.0 to ensure deterministic replication and reliable PITR.
