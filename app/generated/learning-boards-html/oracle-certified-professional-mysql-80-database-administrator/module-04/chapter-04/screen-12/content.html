Starter SQL
CREATE DATABASE IF NOT EXISTS pitr_test;
USE pitr_test;
CREATE TABLE important_data (
  id INT AUTO_INCREMENT PRIMARY KEY,
  value VARCHAR(100),
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
INSERT INTO important_data (value) VALUES ('Initial record A'), ('Initial record B');
Take a mysqldump with --single-transaction --master-data=2 and note MASTER_LOG_FILE and MASTER_LOG_POS.
Recovery hints
After restoring the dump, apply binary logs from the recorded position up to the stop-datetime you noted before the accidental DELETE. Verify the table contains expected rows but not the deletion.
