Scope comparison

Privilege levels

Global
Applies to the entire server — use only for true administrative needs.
Database
Applies to all objects within a specific database.
Table
Narrower scope for application tables or service accounts.
Column
Limit access to specific fields when required for privacy or compliance.
Administrative privileges

High risk privileges

SUPER
Can terminate connections and change global variables; grant only to trusted DBAs.
FILE
Allows server host file operations; this can expose host filesystem if misused.
RELOAD / SHUTDOWN
Server maintenance commands that can disrupt production if applied widely.
PROCESS
Inspect running threads; useful but not necessarily administrative in all environments.
Key Takeaway

Prefer the narrowest privilege scope and restrict administrative privileges to a small, audited set of administrator accounts.
