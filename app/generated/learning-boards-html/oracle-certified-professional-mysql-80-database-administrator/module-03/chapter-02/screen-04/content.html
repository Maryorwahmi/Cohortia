Definition

WITH GRANT OPTION

A grant modifier that permits a user to grant the same privilege to others. Delegation simplifies administration but increases the number of accounts that can receive that privilege.

Risk

Privilege propagation can create uncontrolled privilege chains if applied to non-administrative users.

Tip

If delegation is required, limit scope to the smallest database or table and document the reason and review schedule.

Concrete example
Scenario: Senior DBA delegates SELECT on sales database to helper account for onboarding queries. The helper can then grant SELECT on sales to temporary accounts, which speeds setup but must be audited.
Common mistake

Granting WITH GRANT OPTION to application accounts that do not need delegation.

Verification

List users with grant option and review downstream grants to ensure no unexpected propagation.

Key Takeaway

Grant the least necessary scope and avoid give-away privileges. Reserve WITH GRANT OPTION for trusted administrators only.
