Practical Tasks

Precise GRANTs

Write grants with minimum required scope to limit blast radius.

Role creation

Group privileges into named roles for consistency.

Activation & defaults

Use session activation and default roles to ensure predictable access.

Common mistake
Applying WITH GRANT OPTION to application accounts, which can lead to uncontrolled privilege propagation.
Good practice
Use roles for job functions and run regular privilege audits to detect drift.
