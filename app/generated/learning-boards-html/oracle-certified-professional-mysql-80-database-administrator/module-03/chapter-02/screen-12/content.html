Verification workflow
1. Inspect role privileges
Confirm the exact privileges granted to a role before assigning it.
2. Confirm user role grants
List roles assigned to a user to ensure membership was applied correctly.
3. Check active session roles
Verify the current role(s) active in a user's session and effective privileges.
4. Audit grant-option holders
Find accounts that can delegate privileges and validate each case.
Example check
After changing a role, connect as a user with that role, run the show grants and current role checks, then document the results. If anything is unexpected, investigate direct grants and host matching issues.
Key Takeaway

Verification is an essential final step after any privilege or role change. It prevents surprises and supports audits.
