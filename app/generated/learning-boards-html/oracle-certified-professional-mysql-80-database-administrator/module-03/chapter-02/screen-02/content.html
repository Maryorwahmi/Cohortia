Learning Objectives

Skills and competencies you'll demonstrate when managing privileges and roles in MySQL 8.0.

Learn
Understand
Apply
Master
01
Explain WITH GRANT OPTION

Describe how delegation works and why granting that option increases risk. Use case: delegating SELECT to a trusted DBA for onboarding.

VERIFIED COMPETENCY MILESTONE
02
Differentiate privilege levels

Identify global, database, table, column and administrative privileges and choose the correct scope for the task.

VERIFIED COMPETENCY MILESTONE
03
Create and grant roles

Author a role, assign privileges to it, and grant the role to users to simplify permissions for teams or apps.

VERIFIED COMPETENCY MILESTONE
04
Activate and audit roles

Use SET ROLE and ALTER USER DEFAULT ROLE for session activation, and perform regular audits to enforce least privilege.
