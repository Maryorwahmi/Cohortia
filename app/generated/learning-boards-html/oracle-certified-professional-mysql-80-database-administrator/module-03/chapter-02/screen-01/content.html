Managing User Privileges and Roles

Advanced GRANT options and MySQL 8.0 roles let you enforce least privilege at scale, simplify audits, and reduce human error in privilege propagation.

In this lesson
Understand WITH GRANT OPTION risks and when to use delegation.
Coming up
Create and assign roles, activate with SET ROLE, and set default roles.
Why it matters
Reduce repetitive grants, improve consistency, and simplify audits as your user base grows.
Concept map
Roles bind privileges → users activate roles
Role: web_app_role
SELECT, INSERT, UPDATE, DELETE on products
Admin Privilege Warning
Reserve SUPER, FILE for administrators only.
Activation
SET ROLE or DEFAULT ROLE controls session activation.
Explore Key Topics
Delegation
WITH GRANT OPTION lets users pass on specific privileges; use sparingly.
Privilege Levels
Global, database, table, column and administrative privileges have different impact scopes.
Roles
Create roles, grant privileges to them, then assign roles to users for consistency and scale.
