Quick Reference

CREATE ROLE
Define a named set of privileges for reuse across users.
GRANT role TO user
Assign the role to one or more accounts so they inherit its privileges.
SET ROLE / ALTER USER DEFAULT ROLE
Activate roles for sessions or make roles active by default at login.
Final takeaway
Use roles and narrow grants, avoid risky delegation, and verify effective privileges after every change.
