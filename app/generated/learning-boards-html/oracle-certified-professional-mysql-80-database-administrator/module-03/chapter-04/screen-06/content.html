Module 3 › Chapter 3.4 › Configuring MySQL
my.cnf example
[mysqld]
ssl_ca=/etc/mysql/ssl/ca.pem
ssl_cert=/etc/mysql/ssl/server-cert.pem
ssl_key=/etc/mysql/ssl/server-key.pem
# Optional but recommended in production
require_secure_transport = ON
After saving changes, restart the MySQL service and verify that the server reports have_ssl = YES and that Ssl_cipher is populated when a client connects with TLS.
Common Mistake

Placing key files with incorrect ownership or forgetting to restart the server are frequent causes of SSL not being enabled.

Verify commands
Connect to MySQL as root and run:
SHOW VARIABLES LIKE 'have_ssl';
SHOW STATUS LIKE 'Ssl_cipher';
have_ssl should be YES and Ssl_cipher should list the negotiated cipher after a TLS client session.
Operational checklist
  • Place certs in /etc/mysql/ssl or an accessible directory.
  • Set server-key.pem permissions to 0400 or 0600 owned by mysql user.
  • Restart MySQL and confirm SSL variables and status.
