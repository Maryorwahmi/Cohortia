Module 3 › Chapter 3.4 › Lab: SSL Install
Terminal steps (summary)
sudo mkdir -p /etc/mysql/ssl
# Copy your generated files here
sudo cp ca.pem server-cert.pem server-key.pem /etc/mysql/ssl/
sudo chown mysql:mysql /etc/mysql/ssl/*
sudo chmod 400 /etc/mysql/ssl/server-key.pem
# Edit my.cnf then restart
sudo systemctl restart mysql

# Verify inside mysql
SHOW VARIABLES LIKE 'have_ssl';
SHOW STATUS LIKE 'Ssl_cipher';
Example verification
A successful TLS session will show Ssl_cipher with a value. If have_ssl is NO, check file permissions and my.cnf paths.
Connecting with client certs
mysql -u root -p \
  --ssl-ca=/etc/mysql/ssl/ca.pem \
  --ssl-cert=/etc/mysql/ssl/client-cert.pem \
  --ssl-key=/etc/mysql/ssl/client-key.pem
If require_secure_transport is ON, connections without these parameters should fail. Test both to observe the difference.
Key Takeaway

Automate file placement and permission settings to prevent accidental exposure and ensure repeatable deployments.
