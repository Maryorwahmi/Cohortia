Module 3 › Chapter 3.4 › Why TLS/SSL matters
Definition
TLS is a cryptographic protocol that provides confidentiality, message integrity, and authentication for networked applications.
Common misconception
Encrypting traffic without verifying server identity can still allow man-in-the-middle attacks if clients accept any certificate or use VERIFY_NONE modes.
Concrete example
A web app connections over a public network must use TLS so an attacker cannot read login credentials or alter query payloads in transit.
Key Takeaway

TLS must provide encryption plus certificate verification to prevent eavesdropping and impersonation.

Annotated flow
Client hello & server cert
Client requests TLS; server presents server-cert signed by a CA. Verification ensures the server identity is trusted before exchanging session keys.
After handshake
Symmetric keys are used for the session. All subsequent queries and results are encrypted and integrity-checked until the session ends.
