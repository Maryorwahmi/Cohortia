Module 3 › Chapter 3.4 › Client-side Connections
mysql CLI example
mysql -u myuser -p \
  --ssl-ca=/etc/mysql/ssl/ca.pem \
  --ssl-cert=/etc/mysql/ssl/client-cert.pem \
  --ssl-key=/etc/mysql/ssl/client-key.pem
This supplies a CA and client certs. If server enforces require_secure_transport, connections without these will fail.
Connector example (Python)
config = {
  'user':'myuser','password':'mypw','host':'localhost','database':'mydb',
  'ssl_ca':'/path/to/ca.pem','ssl_cert':'/path/to/client-cert.pem',
  'ssl_key':'/path/to/client-key.pem','ssl_verify_identity': True
}
cnx = mysql.connector.connect(**config)
Setting ssl_verify_identity prevents connecting to servers whose certificate names do not match.
Mode comparison
VERIFY_IDENTITY or ssl_verify_identity: strong. VERIFY_CA: checks CA but may not verify host name in some clients. VERIFY_NONE: encryption without verification — not recommended.
Warning

Using VERIFY_NONE or disabling verification may encrypt traffic but still leave you vulnerable to server impersonation.

Check
Ensure clients supply the CA and verify identity to prevent man-in-the-middle attacks. Test by attempting a connection without TLS parameters when require_secure_transport is ON to observe failure.
