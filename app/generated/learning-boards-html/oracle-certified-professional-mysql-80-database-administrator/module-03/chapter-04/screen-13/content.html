Module 3 › Chapter 3.4 › Assessment Scenario
Server configuration (correct)
[mysqld]
ssl_ca=/etc/mysql/ssl/ca.pem
ssl_cert=/etc/mysql/ssl/server-cert.pem
ssl_key=/etc/mysql/ssl/server-key.pem
require_secure_transport = ON
This enforces TLS and provides a CA for client verification.
Client verification (correct)
mysql -u user -p --ssl-ca=/etc/mysql/ssl/ca.pem \
  --ssl-cert=/etc/mysql/ssl/client-cert.pem \
  --ssl-key=/etc/mysql/ssl/client-key.pem \
  --ssl-verify-server-cert
This explicitly uses the CA and requests server certificate verification.
Test

Try connecting without TLS to confirm require_secure_transport blocks that attempt, then connect with the CA to confirm success.
