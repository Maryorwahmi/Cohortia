Module 3 › Chapter 3.4 › Generating Certificates
Step-by-step
  1. Create CA private key and self-signed certificate.
  2. Generate server private key and CSR, then sign with CA.
  3. Optionally create client key and sign for mutual authentication.
  4. Securely copy files to /etc/mysql/ssl and set restrictive permissions.
Permissions and naming
Private keys must be readable only by the MySQL user. Use CN or SAN fields that match server hostnames to avoid verification failures.
Common Mistake

Using self-signed certs in production without a trust path or allowing clients to skip verification leaves you vulnerable to impersonation.

Reference commands (OpenSSL)
# Create CA key and cert
openssl genrsa 2048 > ca-key.pem
openssl req -new -x509 -nodes -days 3650 -key ca-key.pem -out ca.pem -subj "/CN=MySQL Test CA"

# Server key and CSR
openssl req -newkey rsa:2048 -days 3650 -nodes -keyout server-key.pem -out server-req.pem -subj "/CN=MySQL Server"

# Sign server certificate
openssl x509 -req -in server-req.pem -days 3650 -CA ca.pem -CAkey ca-key.pem -set_serial 01 -out server-cert.pem
Example scenario
For a test lab, a local CA is fine. For production, request certificates signed by your internal or external PKI and track expiration dates for renewal.
