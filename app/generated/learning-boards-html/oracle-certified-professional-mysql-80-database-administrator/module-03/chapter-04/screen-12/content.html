Module 3 › Chapter 3.4 › Common Mistakes
Top mistakes
  • Using self-signed certs in production without trust management.
  • Incorrect file permissions for private keys.
  • Disabling server verification on clients.
  • Storing master key with encrypted data.
Mitigations
Adopt CA-signed certs, enforce require_secure_transport, apply least privilege to key files, and centralize keys in a secure keyring or KMS with backups.
Operational checklist
  1. Use CA-signed certs for production.
  2. Set server-key.pem to 0400 or 0600 owned by mysql.
  3. Enable require_secure_transport in production.
  4. Back up and rotate master keys for TDE.
Key Takeaway

Encryption must be paired with secure operations: permissions, verification, key storage, and recovery planning.
