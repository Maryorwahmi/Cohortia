Module 3 › Chapter 3.3 › Locking and unlocking accounts
Locking commands
-- Lock an account
ALTER USER 'compromised_user'@'localhost' ACCOUNT LOCK;
-- Unlock an account
ALTER USER 'compromised_user'@'localhost' ACCOUNT UNLOCK;
Locking is immediate and prevents connections. Keep the user record to retain grants and metadata for investigation.
Incident playbook
  1. Lock the suspected account to stop access immediately.
  2. Audit recent connections and queries for evidence of misuse.
  3. Expire the password to require a reset before reactivation.
  4. Unlock after rotation and verification.
Example test
Lock a test account, attempt a client connection to confirm rejection, then unlock and test again after reset.
