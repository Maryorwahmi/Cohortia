Module 3 › Chapter 3.3 › Secure password storage and hashing
Concept

MySQL stores a one-way hash of the password. On login, the supplied password is hashed and compared to the stored value. Matching hashes mean authentication succeeds without ever storing the plain password.

Practical note
Do not attempt to store readable passwords or implement custom weak hashing. Rely on MySQL's secure defaults and keep the server patched.
Operational controls
  • Treat the mysql.user table as sensitive; limit access to it.
  • Combine hashed storage with policy enforcement to reduce the chance of successful offline attacks.
  • Rotate high-privilege credentials regularly and monitor for suspicious password change attempts.
Key takeaway

Hashing protects stored credentials but must be part of a layered approach including policy, rotation, and monitoring.
