Module 3 › Chapter 3.3 › Service accounts vs human accounts
Human accounts
Expire regularly, require interactive password changes, and educate users about generation of unique, strong passwords. Enforce STRONG policy for interactive users where possible.
Example
Set a 60 to 90 day expiry for human users to reduce exposure while balancing workload.
Service accounts
Consider PASSWORD EXPIRE NEVER only when you implement automated rotation, restrict privileges, and monitor access closely.
Best practice
Rotate programmatically via your secret manager and restrict the account's host and privilege scope tightly.
