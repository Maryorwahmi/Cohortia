Module 3 › Chapter 3.3 › Audit, monitoring, and two-factor considerations
Monitoring checklist
  • Log password changes and failed authentication attempts.
  • Create alerts for spikes in failed logins or unexpected password resets.
  • Retain logs long enough to support incident investigation and correlation.
Two-factor options
Enforce TFA outside MySQL: SSH jump hosts, proxies, or an LDAP gateway that requires TFA before allowing database connections.
Incident scenario
If you detect failed logins followed by a password change, lock the user, expire the password, and gather logs from the client and server for correlation before unlocking.
Why this matters

Detection plus containment reduces attacker dwell time and prevents misuse of rotated credentials.
