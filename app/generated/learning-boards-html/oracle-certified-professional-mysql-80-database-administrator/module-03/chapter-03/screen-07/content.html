Module 3 › Chapter 3.3 › Demonstrate password rejection and creation
Terminal: weak password attempt
Attempt create with an intentionally weak password
CREATE USER 'dev_test_user'@'localhost' IDENTIFIED BY 'short';
-- Expected: error rejecting due to policy
Observe the rejection message. Learn which variable caused the failure and adjust the password rather than lowering policy in production.
Terminal: compliant creation
Create user with a compliant password
CREATE USER 'dev_test_user'@'localhost' IDENTIFIED BY 'DevTestSecurePass!14';
-- Expected: user created successfully
Verification
Query mysql.user or use SHOW GRANTS to confirm the account and its host restrictions.
Pro tip
Use a secrets manager to generate and store complex service passwords instead of embedding them in scripts.
