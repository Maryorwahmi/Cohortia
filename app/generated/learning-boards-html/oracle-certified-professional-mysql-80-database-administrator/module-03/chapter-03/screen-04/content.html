Module 3 › Chapter 3.3 › Why password management matters
Definition

Passwords as risk controls

Passwords limit who can authenticate. Enforcing complexity and rotation makes guessing and credential reuse harder, and locking provides immediate containment when you suspect an account is compromised.

Concrete example
If a developer reports odd behavior, lock the user account and force password expiry. This stops access and requires a new password before use resumes.
Common mistake
Relying on default or weak policy levels because they are easier to manage increases exposure across all users.
Key takeaway
Treat password policy and lifecycle as active security controls, not administrative chores.
Operational scenario
Scenario: suspected credential leak
-- immediate steps
ALTER USER 'suspicious_user'@'%' ACCOUNT LOCK;
ALTER USER 'suspicious_user'@'%' PASSWORD EXPIRE;
-- follow up: rotate credentials and audit access logs
