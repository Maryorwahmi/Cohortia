Module 3 › Chapter 3.3 › Inspect and change validate_password settings
Common commands
Check current variables
SHOW VARIABLES LIKE 'validate_password%';
Set strong policy and length at runtime
SET GLOBAL validate_password.policy = 2; -- STRONG
SET GLOBAL validate_password.length = 14;
Remember to persist in my.cnf
# my.cnf
validate_password.policy=2
validate_password.length=14
Explanation and example
  • SHOW VARIABLES reveals the active settings so you can confirm enforcement before creating users.
  • SET GLOBAL changes are immediate for new password checks but are lost on restart unless persisted.
  • Update my.cnf and restart to maintain a consistent configuration across restarts.
  • After applying, attempt to create a user with a weak password as a test to confirm behavior.
Takeaway

Always verify active settings and persist changes to avoid configuration drift.
