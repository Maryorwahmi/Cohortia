Module 3 › Chapter 3.3 › Password expiration and rotation
Expiration examples
ALTER USER 'app_user'@'localhost' PASSWORD EXPIRE INTERVAL 90 DAY; -- expires after 90 days
ALTER USER 'admin_user'@'localhost' PASSWORD EXPIRE; -- expires immediately at next login
ALTER USER 'service_account'@'%' PASSWORD EXPIRE NEVER; -- no expiration (use with caution)
Example
Set dev users to 30 days to encourage frequent rotation during development cycles.
Common mistake
Applying NEVER for many accounts for convenience increases long-term risk.
Takeaway

Use expiry intervals for human accounts and reserve non-expiring passwords for tightly controlled service accounts with programmatic rotation and strict privilege limits.
