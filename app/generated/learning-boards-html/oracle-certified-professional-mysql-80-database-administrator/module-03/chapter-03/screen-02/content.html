Expanded objectives
Plugin variables
Use variables like policy, length, number_count, special_char_count, and mixed_case_count to tune enforcement.
Operational auditing
Monitor password change attempts and failed operations for signs of brute force or misuse.
Service account strategy
Treat long-lived service accounts carefully: restrict privileges and rotate programmatically.
External TFA
Plan two-factor mechanisms outside MySQL for admin accesses where needed.
