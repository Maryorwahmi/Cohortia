Module 4 › Chapter 3.5 › Slow Query Log
Definition
Slow Query Log
Logs queries slower than long_query_time. Useful for tuning and for spotting suspicious, heavy queries used in abuse scenarios.
Config example
slow_query_log = 1, slow_query_log_file = /var/log/mysql/mysql-slow.log, and long_query_time = 1 log queries longer than one second.
Security use
High volume of slow queries by a single user may indicate attempted data extraction or resource abuse.
Concrete example
Lower long_query_time to 0.5 seconds in a controlled window and run SELECT SLEEP to generate a slow-log entry. Then check the slow log for entries listing execution time and query text.
Check your understanding
If a slow query is caused by a missing index, it may look similar to a malicious heavy query. Correlate user, frequency, and intent before escalating.
