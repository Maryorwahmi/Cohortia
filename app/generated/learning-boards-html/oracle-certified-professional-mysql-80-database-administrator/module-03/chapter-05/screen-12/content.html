Logrotate Example
A concise logrotate snippet automates rotation, compression, and postrotate reloads if MySQL is running.
/var/log/mysql/*.log {
  daily
  rotate 7
  compress
  delaycompress
  missingok
  notifempty
  create 640 mysql adm
  sharedscripts
  postrotate
    if test -x /usr/bin/mysqladmin && /usr/bin/mysqladmin ping >/dev/null
    then
      /usr/bin/mysqladmin reload >/dev/null 2>&1
    fi
  endscript
}
Rotate by size or time. For audit logs with compliance needs, retain and archive to off-host storage rather than deleting.
Retention guidance
  • Match retention to compliance demands.
  • Archive critical logs off-host and protect access.
  • Ensure rotation scripts do not interrupt logging integrity.
Key takeaway
Automate rotation, then archive and secure rotated logs to maintain evidence while managing storage.
