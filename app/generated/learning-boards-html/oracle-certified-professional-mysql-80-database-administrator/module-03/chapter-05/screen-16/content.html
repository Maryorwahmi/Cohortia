Quick Configuration Reference
Remember these variables and what they control.
log_error
Path for the error log file.
general_log / general_log_file
Enable and set file for full statement capture; use temporarily.
slow_query_log / long_query_time
Controls slow-log activation and threshold for capturing heavy queries.
log_bin
Enables binary logging for replication and forensic reconstruction.
audit_log plugin
Enterprise plugin; use audit_log_policy and audit_log_format for compliance needs.
Rotation & Retention
Use logrotate and archive critical logs off-host to meet retention and preserve evidence.
Final takeaway

Select logs by their diagnostic value and operational cost. Monitor, rotate, and secure them so they serve both detection and investigation needs.
