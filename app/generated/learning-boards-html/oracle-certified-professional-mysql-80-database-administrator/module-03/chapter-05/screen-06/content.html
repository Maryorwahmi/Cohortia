General Query Log
Complete statement capture
Records every statement, connection, and disconnection. Use only as a temporary forensic capture because of its performance and storage cost.
Runtime control
You can enable and disable the general log at runtime for targeted captures, then secure and analyze the log file.
Performance warning
Do not leave the general query log enabled on production servers where latency and disk are concerns.
Example runtime commands
SET GLOBAL general_log = 'ON';
SET GLOBAL general_log_file = '/var/log/mysql/mysql.log';
-- Perform forensic activity
SET GLOBAL general_log = 'OFF';
Enable the log, perform targeted actions or replay suspected malicious steps, then turn it off and collect the file for analysis.
Key takeaway
Plan and limit forensic captures. Secure the generated log files and remove them from high-volume production disks if necessary.
