Code Walkthrough
Enable, verify, and disable logs at runtime
-- Enable general log temporarily
SET GLOBAL general_log = 'ON';
SET GLOBAL general_log_file = '/var/log/mysql/mysql.log';
-- Verify
SHOW VARIABLES LIKE 'general_log%';
-- After capture, disable
SET GLOBAL general_log = 'OFF';
Visualize: run the capture, perform the suspect actions, then disable and collect the file for analysis. Always confirm the variables with SHOW VARIABLES before trusting the capture.
Practical tips
  • Limit capture window to reduce noise and performance impact.
  • Secure produced log files immediately after capture.
  • Document why and when captures were taken for audit trails.
Common mistake
Assuming runtime settings persist. If you need persistence, add the settings to my.cnf and restart.
