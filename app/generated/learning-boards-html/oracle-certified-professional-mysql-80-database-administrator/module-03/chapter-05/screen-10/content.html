Module 4 › Chapter 3.5 › Configuring Logs
Process
Add persistent settings to my.cnf
Edit the [mysqld] section and add log paths and flags. Restart MySQL to apply the changes permanently.
Example my.cnf snippet
[mysqld]
log_error=/var/log/mysql/error.log
slow_query_log=1
slow_query_log_file=/var/log/mysql/mysql-slow.log
long_query_time=0.5
log_bin=/var/lib/mysql/mysql-bin
Checklist
  • Place settings under [mysqld].
  • Use secure, writable file locations and correct permissions.
  • Restart the server to apply changes.
  • Document changes for incident readiness.
Key takeaway
Make long-term logging choices in my.cnf and verify after restart so audit capability survives reboots and restarts.
