Module 4 › Chapter 3.5 › Key Concepts
Error Log
Records server events and failed logins; use as an early-warning sensor and alert source.
Binary Log
Immutable record of data changes used for replication and forensic reconstruction.
General Query Log
Full statement capture — powerful for forensics but expensive; enable only temporarily.
Summary
Combine these logs with rotation, retention, and monitoring to create an effective security feedback loop that supports detection and post-incident investigation.
