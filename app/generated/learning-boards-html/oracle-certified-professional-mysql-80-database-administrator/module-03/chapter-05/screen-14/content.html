Module 4 › Chapter 3.5 › Lab Walkthrough
Step-by-step
Enable slow log, run a slow query, and verify
1. Configure or enable
Ensure slow_query_log and slow_query_log_file are set, and set long_query_time to 0.5 for testing.
-- Verify runtime variables
SHOW VARIABLES LIKE 'slow_query_log%';
SHOW VARIABLES LIKE 'long_query_time';
2. Simulate
Run a delay-producing query such as SELECT SLEEP(0.6); which should exceed the 0.5 second threshold and produce a slow-log entry.
3. Inspect
Exit the client and tail the slow log file to find the entry that lists the execution time and query text.
Analyst notes
Confirm entries include enough context — timestamp, execution time, and the query — then archive the tested log for evidence. Reset long_query_time when finished.
Key takeaway
Controlled tests validate your logging pipeline and ensure evidence will be available during a real incident.
