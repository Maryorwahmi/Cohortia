Module 4 › Chapter 3.5 › Error Log
Core Concept
Error Log
Records startup, shutdown, warnings, crashes, and authentication errors that are vital for security monitoring.
Config example
log_error=/var/log/mysql/error.log in my.cnf directs error output to a secure file path.
Security signals
Failed login bursts, access denied errors, and SSL loading problems should generate alerts and prompt investigation.
Common mistake
Ignoring permissions on the log file. Ensure only privileged accounts can read or alter logs to preserve evidence.
Example scenario
If the error log shows many 'Access denied' lines from the same client IP, treat that as a potential brute-force attack and block or rate-limit the source while you investigate.
Key takeaway
Keep the error log enabled in production and feed its alerts into your monitoring stack as an early-warning sensor.
