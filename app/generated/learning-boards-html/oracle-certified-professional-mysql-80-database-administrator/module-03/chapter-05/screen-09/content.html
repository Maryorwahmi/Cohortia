Module 4 › Chapter 3.5 › Enterprise Audit Log
Definition
MySQL Enterprise Audit Log
A plugin-based audit solution that records detailed events, supports filtering, and writes structured output suitable for compliance and ingestion.
Enable example
INSTALL PLUGIN audit_log SONAME 'audit_log.so';
SET GLOBAL audit_log_policy = 'ALL';
SET GLOBAL audit_log_format = 'JSON';
SET GLOBAL audit_log_file = '/var/log/mysql/audit.log';
Why choose Enterprise audit
It gives tamper-resistant trails, fine-grained event filtering, and structured formats needed for regulatory evidence and forensic attribution.
Practical caveat
Audit logging requires planning: decide which events you must retain, and configure rotation and secure storage to meet compliance retention windows.
