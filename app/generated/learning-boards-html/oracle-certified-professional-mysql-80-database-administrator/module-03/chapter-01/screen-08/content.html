Module 3 › Chapter 3.1 › GRANT Examples
Examples
GRANT SELECT ON *.* TO 'read_all'@'localhost';
GRANT SELECT, INSERT, UPDATE, DELETE ON `mydb`.* TO 'app_user'@'localhost';
GRANT SELECT ON `mydb`.`users` TO 'report_user'@'localhost';
GRANT UPDATE (email) ON `mydb`.`users` TO 'email_updater'@'localhost';
Guidance & Test

After granting, open a new client connection as the target user and attempt an allowed operation and a denied operation. For example, try SELECT then try INSERT if the account should be read-only.

Key Takeaway

Grant only what is required. Prefer database or table grants over global rights to limit exposure.

Common mistake
Using ALL PRIVILEGES for convenience. Avoid it and revoke it immediately if used temporarily for admin tasks.
