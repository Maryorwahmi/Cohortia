Module 3 › Chapter 3.1 › Hands-on: Reporting User
Step 1 — Create
CREATE USER 'report_reader'@'%' IDENTIFIED BY 'SecureReportPass!1';
Step 2 — Grant
GRANT SELECT ON `sales_data`.* TO 'report_reader'@'%';
Step 3 — Verify
SHOW GRANTS FOR 'report_reader'@'%';
Testing
Connect as report_reader from an allowed host, run SELECT queries to confirm access, then attempt INSERT or UPDATE to ensure writes are denied. If INSERT succeeds, revoke and re-check grants.
Gotcha
Using '%' allows any host but does not bypass network or server bind settings. Test connectivity from the intended client host.
Key Takeaway

Follow create → grant → verify → test. Document account purpose and owner to support future audits.
