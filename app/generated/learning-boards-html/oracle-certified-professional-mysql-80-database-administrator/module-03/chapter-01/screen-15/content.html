Module 3 › Chapter 3.1 › Quick Reference
CREATE USER
Creates an account and sets authentication; no privileges by default.
GRANT
Assign specific privileges at global, database, table, or column scope.
SHOW GRANTS / REVOKE
Use SHOW GRANTS to inspect and REVOKE to remove excess privileges; test changes after revocation.
Final takeaway

Document every account, grant only what is needed, verify with SHOW GRANTS, and test to ensure correct behavior.
