Module 3 › Chapter 3.1 › Inspect Privileges
Command
SHOW GRANTS FOR 'app_user'@'localhost';
The output lists GRANT statements. Use it to confirm that privileges align with policy. If the output shows excess privileges, plan a revoke and re-test.
Audit workflow
  1. Run SHOW GRANTS for relevant users.
  2. Compare grants to documented required privileges.
  3. Revoke excess rights and retest application behavior.
Misconception
Assuming SHOW GRANTS is unnecessary because you created the user. Regular audits catch drift and accidental privilege escalation.
