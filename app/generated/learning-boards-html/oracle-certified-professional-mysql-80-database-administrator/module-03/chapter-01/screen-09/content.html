Module 3 › Chapter 3.1 › Revoke & Flush
Commands
REVOKE DELETE ON `mydb`.* FROM 'app_user'@'localhost';
FLUSH PRIVILEGES; -- reload privilege tables if required
Use REVOKE to remove specific rights. If a session holds cached privileges, that session may need to reconnect. FLUSH PRIVILEGES forces the server to reload the grant tables, though in many modern versions this is seldom required for new connections.
Checklist & Tests
  • Run REVOKE with the exact scope you intend to remove.
  • Test by connecting as the user and attempting the revoked action.
  • Coordinate with application owners to avoid breaking workflows.
Key Takeaway

Revoke precisely and validate by testing. Prefer reconnects for simplicity, use FLUSH PRIVILEGES when necessary.
