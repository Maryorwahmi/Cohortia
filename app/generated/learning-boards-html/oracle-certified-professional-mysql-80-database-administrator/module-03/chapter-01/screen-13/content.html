Question Example
Create and grant for inventory_db
CREATE USER 'app_backend'@'192.168.1.100' IDENTIFIED BY 'AppSecurePass#456'; GRANT SELECT, INSERT, UPDATE, DELETE ON inventory_db.* TO 'app_backend'@'192.168.1.100';
Explain host specificity and why these privileges match the application's needs without granting global access.
Column-level revoke
REVOKE SELECT (credit_card_number) ON analytics.customer_data FROM 'data_analyst'@'localhost';
This removes the select right for a sensitive column while keeping other select privileges intact.
Key Takeaway

Answer assessments by giving exact SQL, scope rationale, and a verification plan using SHOW GRANTS and test queries.
