Learning Objectives

These skills are practical and verifiable in a lab or production review.

Learn → Understand → Apply → Master
01
Explain authentication and authorization
Define verification versus permission checks and why both are required for secure systems.
Mnemonic: Lock (auth) + Keycards (authz)
VERIFIED COMPETENCY MILESTONE
02
Create MySQL users securely
Use CREATE USER with IDENTIFIED BY and choose an authentication plugin appropriate to the environment.
Mnemonic: Separate admin and app accounts
VERIFIED COMPETENCY MILESTONE
03
Grant and revoke privileges by scope
Assign only the privileges required at global, database, table, or column scope to follow least privilege.
Mnemonic: Big to small — global → column
VERIFIED COMPETENCY MILESTONE
04
Inspect and audit privileges
Use SHOW GRANTS to verify what a user can actually do and detect excess permissions.
Mnemonic: Read the grant list
VERIFIED COMPETENCY MILESTONE
