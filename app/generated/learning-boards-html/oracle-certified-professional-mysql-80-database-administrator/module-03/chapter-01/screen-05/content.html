Module 3 › Chapter 3.1 › Authentication Plugins
Comparison
caching_sha2_password
Default and recommended: strong hashing plus client-side caching for performance on repeated connections.
sha256_password
Strong cryptography without caching. Use where caching is undesirable or when compatibility requires it.
auth_socket
Maps client OS user to MySQL user. Useful for local administration without passwords.
LDAP (enterprise)
Integrate MySQL authentication with directory services for centralized identity management.
Guidance

Match plugin to the client environment and threat model. For remote application connections, prefer caching_sha2_password; for local OS-integrated administration, auth_socket avoids password handling.

Quick test
mysql -u app_user -p

Attempt a connection with incorrect credentials to confirm the plugin rejects unauthorized access.

Misconception
Default plugin is suitable for everything. Always confirm client support and document the reason for your choice.
