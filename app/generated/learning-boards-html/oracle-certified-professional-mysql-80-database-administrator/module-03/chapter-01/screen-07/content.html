Module 3 › Chapter 3.1 › Privilege Scopes
Hierarchy
Global (ON *.*)
Affects the whole server. Use only for administrative roles. Example: GRANT SELECT ON *.* TO 'read_all'@'localhost';
Database (ON db_name.*)
Applies to all objects in a database. Example: GRANT SELECT, INSERT ON `mydb`.* TO 'app_user'@'localhost';
Table (ON db.table)
Restricts operations to a single table. Example: GRANT SELECT ON `mydb`.`users` TO 'report_user'@'localhost';
Column (ON column list)
Fine-grained rights for sensitive columns. Example: GRANT UPDATE (email) ON `mydb`.`users` TO 'email_updater'@'localhost';
Practical notes
Prefer the narrowest scope that supports your application. Narrow scopes reduce blast radius on compromise.
Common mistake: granting global rights because it is faster. That introduces unnecessary risk and should be avoided.
Key Takeaway

Design privileges from broad to narrow and choose the smallest scope that enables required functionality.
