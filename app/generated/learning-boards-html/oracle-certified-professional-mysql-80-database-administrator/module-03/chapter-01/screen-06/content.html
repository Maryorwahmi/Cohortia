Module 3 › Chapter 3.1 › Create User
Code Walkthrough
CREATE USER 'app_user'@'localhost' IDENTIFIED BY 'MyStrongPassword123!';

This creates a local user using a password. If you need a different plugin, use IDENTIFIED WITH plugin_name AS '...' to set it explicitly.

Remember: creation alone does not permit any operations. Grant privileges next, constrained to the minimum needed.

Key Takeaway

Create users deliberately; do not assume they can access data until you grant permissions.

Checklist
  • Choose host pattern ('localhost', specific IP, or '%') based on where the user connects from.
  • Use a strong password and prefer the default secure plugin or explicitly select one.
  • Document the account purpose and lifecycle, and avoid creating users without a clear owner.
Common mistake
Creating users with '%' host in production without network controls exposes accounts to broader attack surfaces.
