Module 3 › Chapter 3.1 › Least Privilege
Why it matters

Least privilege reduces the blast radius of compromised credentials and limits accidental misuse. It also simplifies audits because each account has a clear, narrow role.

Practice
Create role-specific accounts and assign only the required privileges. Document purpose and test immediately.
Common mistakes
  • Using root for applications.
  • Granting ALL PRIVILEGES by habit.
  • Not testing after revocation or role changes.
Remediation
Audit users, revoke excess rights, create narrow-scoped accounts, and require reconnects or restarts where necessary.
