Practical Tasks

Hands-on checks you should perform during setup and audits.

Verify → Test → Remediate
01
Inspect with SHOW GRANTS
Read explicit grants for a user to confirm exact scopes and avoid privilege creep.
Mnemonic: List to see who has keys
VERIFIED COMPETENCY MILESTONE
02
Revoke and confirm effect
Use REVOKE to remove permissions and understand when sessions require reconnects or a FLUSH PRIVILEGES.
Mnemonic: Undo only what was granted
VERIFIED COMPETENCY MILESTONE
03
Create scoped reporting users
Practice creating a read-only user for a specific database and test connectivity and restrictions.
Mnemonic: Read-only, restrict host when possible
VERIFIED COMPETENCY MILESTONE
04
Identify and mitigate mistakes
Detect common misconfigurations like weak passwords, overbroad grants, or using root for apps and correct them promptly.
Mnemonic: Check for root-level use
