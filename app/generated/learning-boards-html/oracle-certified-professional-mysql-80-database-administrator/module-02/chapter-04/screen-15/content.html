Transactional dictionary
MySQL 8.0 stores metadata in InnoDB for atomic DDL and improved recovery.
Right tool for the job
INFORMATION_SCHEMA for structure; performance_schema and sys for performance analysis.
Safe practice
Query system schemas; never write to them. Monitor metadata locks during DDL.
Reflection prompt
Which schema would you query to find a table’s column types, and where would you look to find which statement has the highest I/O wait time?
