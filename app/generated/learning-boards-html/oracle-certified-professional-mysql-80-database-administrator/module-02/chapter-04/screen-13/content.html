Module 2 › Chapter 2.4 › Hands-on activity
Step 1 — Inventory schemas
SELECT SCHEMA_NAME FROM INFORMATION_SCHEMA.SCHEMATA;
Step 2 — Find non-InnoDB system tables
SELECT TABLE_NAME, ENGINE FROM INFORMATION_SCHEMA.TABLES WHERE TABLE_SCHEMA = 'mysql' AND ENGINE != 'InnoDB';
Step 3 — Generate activity
Run test SELECT statements on a sample database to create measurable events in performance_schema.
Step 4 — Inspect recent statements
SELECT EVENT_ID, SQL_TEXT, TIMER_WAIT, LOCK_TIME FROM performance_schema.events_statements_history_long ORDER BY EVENT_ID DESC LIMIT 5;
Step 5 — Summarize with sys
SELECT statement, total_latency, exec_count, avg_latency FROM sys.statements_with_runtimes_in_95th_percentile ORDER BY total_latency DESC LIMIT 5;
Key Takeaway

Combine metadata and runtime data for actionable insights. Prefer replicas for heavy scans and capture snapshots from performance_schema when needed.
