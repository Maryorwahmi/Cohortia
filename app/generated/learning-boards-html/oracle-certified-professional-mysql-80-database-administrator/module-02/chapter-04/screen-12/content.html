Module 2 › Chapter 2.4 › Metadata Locks (MDL)
What MDLs do

MDLs ensure dictionary consistency during DDL by blocking incompatible concurrent operations on the same objects.

Troubleshooting
-- Inspect metadata locks
SELECT * FROM performance_schema.metadata_locks
ORDER BY EVENT_ID DESC
LIMIT 20;
Use this to find sessions holding or waiting on MDLs and identify blockers.
Common scenario
A long-running SELECT inside a transaction can block an ALTER TABLE. Either finish or kill the transaction, or perform ALTER on a replica to avoid production impact.
Prevention
Design transactions to be short-lived, schedule schema changes for maintenance windows, and use replicas for disruptive DDL when possible.
Key Takeaway

MDLs are necessary for safe DDL. Monitor metadata_locks and plan around locking to avoid blocking production workloads.
