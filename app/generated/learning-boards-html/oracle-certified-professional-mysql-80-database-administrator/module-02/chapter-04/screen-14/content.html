Data Dictionary
Transactional, InnoDB-based metadata store in 8.0.
INFORMATION_SCHEMA
Read-only virtual tables for object metadata; use for audits.
performance_schema / sys
Instrumentation for live events and user-friendly summaries for analysis.
Takeaway
Combine schema metadata and runtime metrics for effective administration. Avoid direct edits to system schemas and plan around metadata locks.
