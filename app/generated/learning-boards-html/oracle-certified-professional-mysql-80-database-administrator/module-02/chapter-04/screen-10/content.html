Module 2 › Chapter 2.4 › Schema comparison
INFORMATION_SCHEMA
Read-only virtual tables for object metadata. Best for audits and schema verification.
Misuse: frequent performance checks
performance_schema
Instrumentation for live events and counters. Low-overhead and volatile.
Misuse: enabling unnecessary instruments
sys
Aggregated views built on performance_schema for readable reports and quick triage.
Misuse: expecting raw event detail
Key Takeaway

Pick INFORMATION_SCHEMA for metadata, performance_schema for live telemetry, and sys when you want readable summaries quickly.
