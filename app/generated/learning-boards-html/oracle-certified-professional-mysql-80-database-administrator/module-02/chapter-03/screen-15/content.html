Module 2 › Chapter 2.3 › Key Concepts
MyISAM

Non-transactional, table-level locking, fast reads and full-text capabilities; stored in .MYD and .MYI files.

Memory (HEAP)

Stores rows in RAM for speed but loses data on server restart; supports HASH and BTREE indexes.

CSV

Plain-text CSV files for easy import/export and inspection; lacks indexes and transaction support.

Summary

Match engine choice to workload needs: durability, concurrency, indexability, and rebuildability guide the selection.
