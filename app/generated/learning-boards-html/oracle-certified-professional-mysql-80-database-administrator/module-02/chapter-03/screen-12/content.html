Engine-specific DDL

MyISAM example
CREATE TABLE zipcode_lookup (
  zipcode VARCHAR(10) PRIMARY KEY,
  city VARCHAR(100),
  state_abbr CHAR(2)
) ENGINE=MyISAM;
Memory example
CREATE TABLE user_session_data (
  session_id VARCHAR(64) PRIMARY KEY,
  user_id INT,
  last_activity DATETIME
) ENGINE=Memory;
CSV example
CREATE TABLE external_data_feed (
  record_id INT,
  product_code VARCHAR(20),
  quantity INT,
  delivery_date DATE
) ENGINE=CSV;
Archive example
CREATE TABLE system_logs (
  log_id INT PRIMARY KEY AUTO_INCREMENT,
  event_timestamp DATETIME,
  event_message TEXT
) ENGINE=ARCHIVE;
Guidance
  • Always include ENGINE explicitly in migrations to avoid surprises.
  • Annotate why a non-default engine is used, including rebuild and recovery steps.
  • Test edge cases: restarts for Memory, concurrent writes for MyISAM, imports for CSV.
