Comparison

HASH vs BTREE

HASH: best for equality lookups; constant-time access for exact keys.
BTREE: supports range queries and ordered scans; needed for ORDER BY or BETWEEN.
Misconception

HASH is not a universal speed win. For range and ordering, BTREE is necessary and will perform better.

Example
Session lookup

Query pattern: SELECT * FROM user_session_data WHERE session_id = 'abc'. Use HASH for fastest equality lookup.

Time window

Query pattern: SELECT * FROM user_session_data WHERE last_activity > '2024-01-01'. Use BTREE for efficient range scans.

Takeaway
Key Takeaway

Match index type to query shape: equality -> HASH; ranges and ordering -> BTREE.
