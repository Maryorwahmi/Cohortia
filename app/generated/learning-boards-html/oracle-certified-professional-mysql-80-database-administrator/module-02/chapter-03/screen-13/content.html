Activity steps

Setup
CREATE DATABASE IF NOT EXISTS storage_engine_test;
USE storage_engine_test;
MyISAM test
CREATE TABLE myisam_log (
  id INT AUTO_INCREMENT PRIMARY KEY,
  message VARCHAR(255),
  timestamp DATETIME DEFAULT CURRENT_TIMESTAMP
) ENGINE=MyISAM;
Memory test
CREATE TABLE temp_cache (
  key_id VARCHAR(50) PRIMARY KEY,
  value TEXT
) ENGINE=Memory;
CSV and Archive
CREATE TABLE sales_import (... ) ENGINE=CSV;
CREATE TABLE system_logs (... ) ENGINE=ARCHIVE;
Notes
  • Observe locking by running a long write on MyISAM and trying concurrent reads.
  • Restart MySQL after inserting into Memory table to confirm volatility.
  • Open the generated .csv file to inspect CSV engine output.
  • Insert many rows into Archive and time queries to notice decompression overhead.
