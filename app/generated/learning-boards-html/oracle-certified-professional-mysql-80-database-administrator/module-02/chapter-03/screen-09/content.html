Core Concept

CSV: plain-text tables

  • Data is stored in a .csv file; easy to open and exchange.
  • Non-transactional and no indexing; unsuitable for large, query-intensive tables.
  • Great for staging, import/export, and quick manual inspection.
Example
Creating a CSV table
CREATE TABLE external_data_feed (
  record_id INT,
  product_code VARCHAR(20),
  quantity INT,
  delivery_date DATE
) ENGINE=CSV;
After inserting, inspect the generated .csv file in the data directory with a text editor or spreadsheet tool.
Takeaway
Key Takeaway

CSV is excellent for interoperability and staging, but not for indexed queries or transactional data.
