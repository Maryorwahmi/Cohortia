Module 2 › Chapter 2.3 › Key Concepts
Table-level locking

A write can block other writes and readers, reducing concurrency for write-heavy workloads.

Non-transactional

No ACID guarantees means no rollback; plan backups and recovery accordingly.

Volatile

Memory tables lose contents on restart; acceptability depends on whether the data is reconstructable.

Parting thought

Always match engine guarantees to application requirements: durability, concurrency, and recoverability come first; specialized engines come second.
