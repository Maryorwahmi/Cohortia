Module 2 › Chapter 2.1 › Inspecting Connections and Server Variables
Essential commands
SHOW PROCESSLIST;
SHOW GLOBAL STATUS LIKE 'Threads_connected';
SHOW GLOBAL STATUS LIKE 'Max_used_connections';
SHOW VARIABLES LIKE 'max_connections';
Run them together to compare current usage, historical peak, and configured limits. Watch for many sleeping connections from the same Host value.
Scenario
Connections begin to be refused. You check Threads_connected and find it's close to max_connections. SHOW PROCESSLIST reveals many idle sessions from a single app server. The fix is to examine application pooling or raise max_connections after assessing resource impact.
Misconception
Raising max_connections solves scaling forever. Without addressing root causes, it only delays the problem.
Pro tip
Correlate processlist entries with application logs and host addresses to identify the offending client quickly.
