Module 2 › Chapter 2.1 › The Optimizer: Choosing an Execution Plan
Definition

Cost-based decision maker

The optimizer evaluates plan alternatives and chooses the one with the lowest estimated cost. It uses indexes, statistics, and join strategies in this evaluation.

What it considers
  • Available indexes and their selectivity.
  • Table statistics and estimated row counts.
  • Join order and possible join algorithms.
Example & check
If EXPLAIN shows a full table scan where an index exists, consider whether the predicate matches many rows, whether statistics are out of date, or whether functions on the column prevent index use. Use EXPLAIN to inspect chosen plans and estimated rows.
Common mistake
Assuming an index is always faster; the optimizer may choose a scan for lower estimated cost.
Pro tip
Keep statistics current and create indexes that match common WHERE and JOIN patterns to guide the optimizer.
