Layered Architecture
Use the layer model to isolate performance, security, and storage issues quickly.
Parser & Optimizer
Parsing creates a tree; the optimizer picks a plan using indexes and statistics.
Storage Engines
Engines are pluggable subsystems; choose based on transactions, locking, and storage needs.
Summary Takeaway

When diagnosing issues, map symptoms to a specific layer and apply targeted tools: processlist for connections, EXPLAIN for optimization, and engine inspection for storage behavior.
