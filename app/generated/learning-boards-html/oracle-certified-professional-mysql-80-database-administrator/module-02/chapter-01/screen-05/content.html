Architecture

Authentication, sockets, threads

Connections establish session state and are represented by server threads. The layer supports TCP/IP and Unix sockets and enforces user authentication and initial privileges.

Inspecting sessions
SHOW PROCESSLIST;
-- Observe Id, User, Host, Command, Time, State, Info
Tip: run SHOW PROCESSLIST before and after opening a second client to compare entries.
Example walkthrough
Open terminal A: connect as root. Open terminal B: connect and run SELECT SLEEP(10). In terminal A run SHOW PROCESSLIST and locate the sleeping command. Watch Time increase as the query sleeps, showing a live state change.
Common mistake
Assuming idle sessions consume no resources; many threads hold memory or locks that affect overall capacity.
Pro tip
Use connection pooling at the application level to reduce thread churn and authentication overhead.
