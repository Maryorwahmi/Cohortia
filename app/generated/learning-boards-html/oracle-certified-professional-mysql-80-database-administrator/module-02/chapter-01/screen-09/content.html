Buffer Pool & Caches

InnoDB's Buffer Pool keeps table and index pages in memory to avoid disk reads. Statement-level caches and internal caches reduce repeated parsing and planning work. Query Cache is deprecated and not recommended for modern installations.

Buffer Pool
Holds pages for InnoDB to speed reads and writes by avoiding disk.
Statement caches
Reduce overhead from repeated parsing and planning.
Logging
Logs record server events and data changes. Slow query logs point to expensive statements. Binary logs capture data-modifying events for replication or recovery. Maintain log rotation and monitoring to avoid disk issues.
Key Takeaway

Tune buffer pools to reduce I/O and keep logging configured for observability and recovery.
