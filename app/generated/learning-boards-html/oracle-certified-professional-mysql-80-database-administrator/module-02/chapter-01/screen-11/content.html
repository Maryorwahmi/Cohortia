Module 2 › Chapter 2.1 › Storage Engines: Pluggable Persistence
InnoDB
Default engine for transactional workloads. Supports transactions, row-level locking, and uses a Buffer Pool for caching pages.
MyISAM
A non-transactional engine historically used for read-heavy tables; differences include locking and recovery behavior.
ARCHIVE
Designed for compressed, append-only storage where transactional integrity is less important and space efficiency matters.
Misconception
Treating engines as mere table labels leads to wrong assumptions about locking, transactions, and recovery. Engines are full subsystems with distinct behaviors.
