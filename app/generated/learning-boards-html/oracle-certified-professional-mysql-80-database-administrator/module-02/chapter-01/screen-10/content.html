Privileges

Access control in the SQL Layer

MySQL checks user privileges to control which databases, tables, or columns a client can access. This check happens before execution so unauthorized statements are rejected early.

Logging

Why logs matter

  • Error log: server events and startup errors.
  • General query log: raw statements for auditing.
  • Slow query log: identify statements for optimization.
  • Binary log: record data changes for replication and recovery.
Scenario
To investigate a data change, use the binary log to reconstruct actions and the general query log to see which user issued statements.
Common mistake
Disabling logs to save disk without planning retention and rotation, losing essential audit data.
