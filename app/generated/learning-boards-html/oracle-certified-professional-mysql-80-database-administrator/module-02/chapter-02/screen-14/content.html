Module 2 › Chapter 2.2 › Inspecting InnoDB status
Starter commands
CREATE DATABASE my_innodb_test;
USE my_innodb_test;
CREATE TABLE accounts (id INT PRIMARY KEY AUTO_INCREMENT, username VARCHAR(50) UNIQUE, balance DECIMAL(10,2)) ENGINE=InnoDB;
INSERT INTO accounts (username,balance) VALUES ('alice',100.00),('bob',50.00);

SHOW ENGINE INNODB STATUS\G
Observation checklist
  • Look for BUFFER POOL AND MEMORY to evaluate cache usage.
  • Check LOG section for redo activity and pending flushes.
  • Inspect TRANSACTIONS to identify active transactions and undo space.
Reflection
After the MVCC simulation, ask which STATUS sections change and why, linking observed counters to transactional behavior.
