Module 2 › Chapter 2.2 › Atomicity and the Undo Log
What the Undo Log stores
Previous versions of modified rows and the information needed to reverse operations for rollback.
Rollback support
If a transaction fails, InnoDB replays Undo records to restore prior values.
MVCC snapshots
Older row versions are reconstructed from Undo records for consistent reads.
Concrete scenario
Transaction A updates a row and then an error triggers a rollback. The Undo Log contains the row image before A's update, allowing InnoDB to restore that image exactly and leave the database consistent.
Misconception
Undo is not only for rollbacks. Its data is consulted to serve consistent reads to other transactions under MVCC.
Watch for

Long-running transactions keep old Undo records alive. That delays purge and can increase disk usage and overhead.
