Module 3 › Chapter 2.5 › Tuning Workflow
Step-by-step
  1. Collect baseline: status variables and OS memory usage.
  2. Identify candidate parameter (size, instances, old_blocks_time, io_capacity).
  3. Change one parameter conservatively.
  4. Run representative load and collect the same metrics.
  5. Compare and revert if negative impact appears.
Checklist
  • Has the hit ratio improved?
  • Is there any OS swap activity?
  • Did dirty pages rise dangerously?
Key takeaway
Use a repeatable process: baseline, change, validate, and iterate. That is how you tune safely in production.
