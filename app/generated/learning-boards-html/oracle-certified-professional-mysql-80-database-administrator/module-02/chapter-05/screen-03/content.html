Objective Cards
05
Understand old blocks time
Use innodb_old_blocks_time to make the Buffer Pool resistant to one-off scans by controlling when pages move to the hot list.
VERIFIED COMPETENCY MILESTONE
06
Interpret dirty pages
Check Innodb_buffer_pool_pages_dirty and innodb_io_capacity to know if flushing is keeping up with writes.
VERIFIED COMPETENCY MILESTONE
07
Avoid swapping
Allocate memory carefully; too large a pool may force OS swapping and hurt performance more than a slightly smaller pool.
VERIFIED COMPETENCY MILESTONE
08
Follow a safe tuning workflow
Measure, change one parameter, observe, and revert if you see regressions. Small steps reduce risk.
VERIFIED COMPETENCY MILESTONE
Quick mnemonic
Think: Size, Instances, Scan resistance, Monitor. These four guide most tuning actions.
