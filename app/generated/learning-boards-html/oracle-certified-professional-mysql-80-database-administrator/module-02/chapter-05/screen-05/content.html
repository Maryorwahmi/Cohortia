Module 3 › Chapter 2.5 › Buffer Pool Sizing
Sizing trade-offs
Balance cache coverage with OS and process memory needs to avoid swapping.
When to increase
If hit ratio is low and working set > current pool, increase cautiously and monitor.
When to avoid increase
If OS memory pressure or swapping occurs, reduce allocation and address other processes.
Example
On 32GB RAM dedicated server, start around 24GB–28GB and measure hit ratio and swap activity before further changes.
Visual comparison
Too small
High disk reads, thrashing, low hit ratio.
Too large
Possible OS swapping if no headroom, harming performance.
Just right
Holds working set, low disk I/O, and leaves system headroom.
Pro tip
Measure working set size with access patterns instead of assuming dataset size equals working set.
