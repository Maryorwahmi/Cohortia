Module 3 › Chapter 2.5 › Buffer Pool Definition
What it is
A memory region caching data and index pages for fast access.
Quick bullets
  • Serves reads from RAM when pages are present (cache hits).
  • On miss, reads page from disk and inserts into the Buffer Pool.
  • Proper sizing reduces disk I/O and transaction latency.
  • Avoid allocating so much that the OS swaps MySQL memory.
Example
On a dedicated 16GB server, 8GB is a common starting point, but adjust to fit your active working set.
Common mistake
Allocating most RAM to the pool without leaving OS headroom, causing swapping and worse performance.
Analogy
Think of the Buffer Pool as a refrigerator for frequently used ingredients. If the fridge holds what you need, cooking is fast. If it can't, you run to the market — analogous to slow disk reads.
Key takeaway
Measure working set size and allocate enough Buffer Pool to hold it while avoiding OS swapping.
