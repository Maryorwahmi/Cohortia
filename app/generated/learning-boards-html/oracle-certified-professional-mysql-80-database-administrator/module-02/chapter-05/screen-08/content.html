Module 3 › Chapter 2.5 › Monitoring & Hit Ratio
Commands you will use
Run the following in a MySQL client to gather Buffer Pool stats and compute hit ratio.
SHOW GLOBAL STATUS LIKE 'Innodb_buffer_pool%';

-- Hit ratio = (read_requests - reads) / read_requests
Important variables
  • Innodb_buffer_pool_read_requests — logical read attempts
  • Innodb_buffer_pool_reads — logical reads that required disk I/O
  • Innodb_buffer_pool_pages_dirty — modified pages waiting to be flushed
Workflow
  1. Capture baseline status variables.
  2. Run representative workload to warm the pool.
  3. Capture status again and compute hit ratio.
  4. Decide whether to resize or adjust other parameters.
Pro tip
Collect metrics over time; a single sample can be misleading. Automate periodic sampling for trend analysis.
