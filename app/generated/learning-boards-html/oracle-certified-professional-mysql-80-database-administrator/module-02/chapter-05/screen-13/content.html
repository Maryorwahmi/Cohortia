Module 3 › Chapter 2.5 › Quick Reference
Hit Ratio
Compute (read_requests - reads) / read_requests to see how often reads are served from memory.
Swapping risk
Avoid giving the Buffer Pool so much memory that the OS begins to swap MySQL pages to disk.
Flush & I/O
Adjust innodb_io_capacity and max_dirty_pages_pct if flushers fall behind and dirty pages accumulate.
Final thought
Use measurement-driven changes and conservative steps to keep your database responsive and durable.
