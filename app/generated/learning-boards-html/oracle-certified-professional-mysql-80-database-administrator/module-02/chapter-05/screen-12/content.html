Module 3 › Chapter 2.5 › Key Concepts
InnoDB Buffer Pool
A RAM cache for data and index pages that reduces disk reads and improves latency.
innodb_buffer_pool_instances
Divides the pool to reduce contention and improve concurrency on multi-core systems.
Scan resistance
Midpoint insertion and innodb_old_blocks_time protect hot pages from one-off full-table scans.
Summary takeaway
Measure first, change one parameter at a time, and monitor hit ratio and OS memory to keep systems stable.
