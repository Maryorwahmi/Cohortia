Module 3 › Chapter 2.5 › Buffer Pool Instances
Why instances exist
Reduce locking contention by splitting Buffer Pool into multiple managers.
Guidance
  • Use multiple instances when pool > 1GB.
  • Choose a number that reflects CPU cores or a power of two.
  • Avoid too many tiny instances to prevent overhead.
Example
On an 8-core server with a large pool, try innodb_buffer_pool_instances = 8 and measure contention and latency.

Common misconception
More instances always faster — false. Measure and avoid excessive fragmentation from too many instances.
Key takeaway
Tune instances to match concurrency and measure the effect rather than assuming a static value.
