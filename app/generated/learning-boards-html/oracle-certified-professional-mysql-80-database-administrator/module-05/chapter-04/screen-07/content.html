Module 5 › Chapter 5.4 › Enable semi‑sync on Replica
Terminal: replica commands
-- On the replica server:
INSTALL PLUGIN rpl_semi_sync_replica SONAME 'mysql_semi_sync_replica.so';
SET GLOBAL rpl_semi_sync_replica_enabled = ON;

-- Verify:
SHOW STATUS LIKE 'Rpl_semi_sync%'; -- expect Rpl_semi_sync_replica_status: ON
Persistence in my.cnf (replica)
[mysqld]
plugin_load_add = 'mysql_semi_sync_replica.so'
rpl_semi_sync_replica_enabled = ON
Confirm that the replica reports its semi‑sync status as ON and that the source sees a client count of at least one.
