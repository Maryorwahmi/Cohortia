Module 5 › Chapter 5.4 › Pitfalls & Troubleshooting
Semi‑sync mistake
Forgetting to install/enable the replica plugin results in no acknowledgements and frequent fallbacks.
Timeout mistake
Setting rpl_semi_sync_source_timeout too low causes many fallbacks; set it to match network and replica performance.
GTID mistake
Enabling gtid_mode without enforce_gtid_consistency or forgetting log_slave_updates on replicas can break replication during failover.
Quick pro‑tip

Always validate plugin persistence across restarts, and run status commands after changes to confirm the topology behaves as expected.
