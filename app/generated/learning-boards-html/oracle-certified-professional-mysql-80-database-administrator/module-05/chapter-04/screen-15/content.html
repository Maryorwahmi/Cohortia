gtid_mode, enforce_gtid_consistency, log_slave_updates.
Key commands
SHOW STATUS LIKE 'Rpl_semi_sync%'; SHOW MASTER STATUS; CHANGE REPLICATION SOURCE TO ... SOURCE_AUTO_POSITION=1;
Final takeaway

Semi‑sync narrows the data loss window by requiring receipt; GTIDs let replication operate on transactions rather than file positions. Configure, persist, and verify before relying on them in production.
