Module 5 › Chapter 5.4 › Enable GTID
my.cnf example
[mysqld]
gtid_mode = ON
enforce_gtid_consistency = ON
log_slave_updates = ON
Restart MySQL after changing my.cnf and verify the variables are set.
Verification commands
SHOW VARIABLES LIKE 'gtid_mode';
SHOW VARIABLES LIKE 'enforce_gtid_consistency';
SHOW MASTER STATUS; -- check Executed_Gtid_Set
SHOW REPLICA STATUS; -- check Retrieved_Gtid_Set and Executed_Gtid_Set
