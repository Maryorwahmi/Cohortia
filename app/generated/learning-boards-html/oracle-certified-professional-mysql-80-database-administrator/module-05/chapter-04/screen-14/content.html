Module 5 › Chapter 5.4 › Key Concepts
Semi‑Synchronous Replication
Source waits for a replica receipt before confirming a commit, reducing potential data loss.
GTID
A global ID for each transaction in the format source_uuid:transaction_id to track processed transactions.
rpl_semi_sync_source_timeout
Milliseconds the source waits for acknowledgement before reverting to async; tune for your network and replica load.
Summary takeaway

Combine semi‑sync for improved durability and GTIDs for deterministic replication management, but plan changes, persist configuration, and validate using the provided SHOW commands.
