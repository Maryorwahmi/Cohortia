Module 5 › Chapter 5.4 › Position vs GTID
File/Position style
CHANGE REPLICATION SOURCE TO SOURCE_HOST='source_ip', SOURCE_USER='repl_user', SOURCE_PASSWORD='pwd', SOURCE_LOG_FILE='mysql-bin.000123', SOURCE_LOG_POS=456789;
This requires accurate binlog coordinates which can be error prone during failover.
GTID style
CHANGE REPLICATION SOURCE TO SOURCE_HOST='source_ip', SOURCE_USER='repl_user', SOURCE_PASSWORD='pwd', SOURCE_AUTO_POSITION=1; START REPLICA;
GTIDs let the replica and source negotiate which transactions are missing automatically.
Key takeaway

Prefer GTID-based provisioning when possible: it simplifies failover and reduces manual errors, but ensure consistency settings are enabled.
