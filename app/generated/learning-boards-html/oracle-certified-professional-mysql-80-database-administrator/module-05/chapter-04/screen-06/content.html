Module 5 › Chapter 5.4 › Enable semi‑sync on Source
Terminal: source commands
-- On the source server:
INSTALL PLUGIN rpl_semi_sync_source SONAME 'mysql_semi_sync_source.so';
SET GLOBAL rpl_semi_sync_source_enabled = ON;
SET GLOBAL rpl_semi_sync_source_timeout = 5000; -- milliseconds
Tip: Choose a timeout that fits your network; 5000ms is a common starting point.
Persisting in my.cnf
[mysqld]
plugin_load_add = 'mysql_semi_sync_source.so'
rpl_semi_sync_source_enabled = ON
rpl_semi_sync_source_timeout = 5000
If you only run INSTALL PLUGIN without adding to my.cnf, the plugin may not be available after a restart. Always restart and verify with SHOW STATUS.
