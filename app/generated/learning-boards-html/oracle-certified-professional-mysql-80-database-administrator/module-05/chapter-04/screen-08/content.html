Module 5 › Chapter 5.4 › Monitoring semi‑sync
Sample status output
SHOW STATUS LIKE 'Rpl_semi_sync%';
-- sample rows:
Rpl_semi_sync_source_status | ON
Rpl_semi_sync_source_clients | 1
Rpl_semi_sync_source_no_times_no_slaves | 0
The expected clients value after a successful setup with a single semi‑sync replica is 1.
Interpretation
• Rpl_semi_sync_source_clients = 0 means no semi‑sync replicas acknowledged; check replica plugin and connectivity.
• Increasing Rpl_semi_sync_source_no_times_no_slaves indicates frequent fallbacks; consider raising timeout or checking replica load.
• Rpl_semi_sync_source_status = OFF means semi‑sync is not enabled on the source; verify plugin installation and my.cnf persistence.
