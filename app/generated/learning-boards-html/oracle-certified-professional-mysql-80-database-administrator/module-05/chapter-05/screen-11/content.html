Module 5 › Chapter 5.5 › Replication Filtering
Common my.cnf entries
[mysqld]
replicate_do_db = sales_app_db
replicate_ignore_table = analytics_db.temp_logs
# Or use wildcards
replicate_wild_do_table = app_%
Place these on the replica and restart MySQL. Test that both DDL and DML behavior meets expectations.
Concrete example
To replicate only the inventory table: use replicate_do_table = warehouse_db.inventory and avoid combining it with replicate_do_db which can create conflicting evaluation order.
Misconception
A common mistake is combining database-level and table-level rules in ways that exclude intended events. Use the narrowest rule needed and test on a staging replica.
Safety Note

Filtering can lead to missing CREATE TABLE events. Prefer row-based replication when filters are active and validate DDL propagation.
