Module 5 › Chapter 5.5 › Multi-Source Configuration
Terminal-style configuration (run on ReplicaC)
-- Configure channel for SourceA
CHANGE REPLICATION SOURCE TO
  SOURCE_HOST='192.168.1.10',
  SOURCE_USER='repl_user_a',
  SOURCE_PASSWORD='passA',
  SOURCE_AUTO_POSITION=1
  FOR CHANNEL 'channel_a';

-- Configure channel for SourceB
CHANGE REPLICATION SOURCE TO
  SOURCE_HOST='192.168.1.20',
  SOURCE_USER='repl_user_b',
  SOURCE_PASSWORD='passB',
  SOURCE_AUTO_POSITION=1
  FOR CHANNEL 'channel_b';

-- Start replication for each channel
START REPLICA FOR CHANNEL 'channel_a';
START REPLICA FOR CHANNEL 'channel_b';

-- Verify status per channel
SHOW REPLICA STATUS FOR CHANNEL 'channel_a';
SHOW REPLICA STATUS FOR CHANNEL 'channel_b';
Note: SOURCE_AUTO_POSITION assumes GTID is enabled on the sources. Choose distinct channel names and test connectivity before starting.
