log_slave_updates
Set to ON on any replica that must act as a source to downstream replicas.
Channels
Use unique channel names and monitor each with SHOW REPLICA STATUS FOR CHANNEL.
Parallel apply
Increase replica_parallel_workers to reduce SQL apply lag; preserve commit order when using GTID if needed.
Final takeaway
Combine careful topology selection, channel-level monitoring, and conservative filtering/testing to operate MySQL replication reliably at scale.
