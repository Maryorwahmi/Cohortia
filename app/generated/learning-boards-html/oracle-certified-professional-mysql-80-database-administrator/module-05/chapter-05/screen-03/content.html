Learning Objectives — Practical Outcomes
Apply commands, edit my.cnf safely, and monitor channel health in production.
Hands-on: Multi-source commands
Write the CHANGE REPLICATION SOURCE TO statements with distinct channel names and start replication for each channel.
Milestone: replica accepts two channels
my.cnf filtering
Add replicate_do_table or replicate_wild_do_table entries and test the effects on a staging replica before production.
Milestone: targeted data only
Monitoring & channels
Use SHOW REPLICA STATUS FOR CHANNEL and interpret Seconds_Behind_Source for each channel separately.
Milestone: channel-level visibility
Mitigation steps
Apply replica_parallel_workers, hardware tuning, or reinitialization when lag persists, following safety checks.
Milestone: lag reduced or reset
