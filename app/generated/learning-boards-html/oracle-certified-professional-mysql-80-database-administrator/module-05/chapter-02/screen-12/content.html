Module 5 › Chapter 5.2 › Activity: Initialize a Replica from a Source with mysqldump
Scenario
Source: 192.168.1.100, Replica: 192.168.1.101. Assume source has log_bin and server_id=1 and a replication user exists.
Step 1 — Dump on source
mysqldump -u root -p --all-databases --single-transaction --flush-logs --master-data=2 > /tmp/full_backup.sql
Open /tmp/full_backup.sql and extract the commented CHANGE REPLICATION SOURCE TO line to get SOURCE_LOG_FILE and SOURCE_LOG_POS.
Step 2 — Import and configure replica
Transfer the dump to the replica and import:
mysql -u root -p < /path/to/full_backup.sql
Construct CHANGE REPLICATION SOURCE TO using the extracted SOURCE_LOG_FILE and SOURCE_LOG_POS, then START REPLICA and run SHOW REPLICA STATUS to confirm success.
