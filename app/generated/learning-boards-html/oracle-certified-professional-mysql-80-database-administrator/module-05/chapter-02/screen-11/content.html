Module 5 › Chapter 5.2 › Common Setup Issues and How to Troubleshoot
Can't connect
Replica_IO_Running No with Last_IO_Error about connection. Likely firewall or wrong SOURCE_HOST. Verify network reachability and security group rules.
Bad coordinates
Supplying SOURCE_LOG_FILE/POS that don't match the imported snapshot causes replication to fail. Re-extract from dump or take a new snapshot.
Credential or host restriction
Incorrect replication user or wrong host restriction prevents authentication. Check GRANTs and test connection from the replica host.
server_id conflicts
Duplicate server_id values disrupt event attribution. Ensure each server has a distinct integer server_id.
Logs tell the story
Consult the MySQL error log on the source and replica for precise failure messages before making changes.
Safe procedures
Stop replication before major changes using STOP REPLICA; then correct configuration and restart the threads.
