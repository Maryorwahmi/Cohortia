Module 5 › Chapter 5.2 › Configure and Start the Replica
Replica configuration template
CHANGE REPLICATION SOURCE TO
  SOURCE_HOST='source_ip_address',
  SOURCE_USER='repl_user',
  SOURCE_PASSWORD='YourStrongPassword!',
  SOURCE_LOG_FILE='mysql-bin.00000X',
  SOURCE_LOG_POS=YYYY;

START REPLICA;
Replace the host, user, password, and the binlog file and position you extracted from the dump. Then run START REPLICA to begin replication.
What to watch for
  • Replica_IO_Running: Yes — IO thread can connect and read events.
  • Replica_SQL_Running: Yes — SQL thread is applying events.
  • Empty Last_IO_Error and Last_SQL_Error indicate no immediate failures.
Quick check
If either thread is No, inspect the connection details, credentials, and the binlog file/position you supplied.
