Module 5 › Chapter 5.2 › Taking a Consistent Snapshot with mysqldump
mysqldump command
mysqldump -u root -p --all-databases --single-transaction --flush-logs --master-data=2 > /tmp/full_backup.sql
Key options: --single-transaction for InnoDB consistency, --flush-logs to rotate binlogs, and --master-data=2 to capture the binlog file and position in the dump output.
After the dump
Open /tmp/full_backup.sql and find the commented CHANGE REPLICATION SOURCE TO line to extract SOURCE_LOG_FILE and SOURCE_LOG_POS.
Explanation cards
Consistent snapshot without locks for InnoDB using single-transaction.
Flush logs creates a new binary log so the dump records a clean start point.
Master-data=2 writes commented replica-start coordinates you will later use verbatim.
