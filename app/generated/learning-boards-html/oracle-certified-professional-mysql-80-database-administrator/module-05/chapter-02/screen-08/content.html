Module 5 › Chapter 5.2 › Transfer and Import the Snapshot on the Replica
Import command (on the replica)
mysql -u root -p < /path/to/full_backup.sql
This command loads the database state captured by the dump so the replica starts with the same data as the source at the dump time.
Key Takeaway

Always import the dump before configuring replication so the replica's data aligns with the binlog coordinates you will supply.

Transfer considerations & checklist
  • Use a secure transport method to move the dump to the replica (the chapter recommends secure transfer without prescribing a tool).
  • Confirm file integrity on the replica before import.
  • Do not start replication until the import completes and you have the dump's SOURCE_LOG_FILE and SOURCE_LOG_POS.
