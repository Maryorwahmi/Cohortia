Module 5 › Chapter 5.2 › Key Concepts — Core Settings
server_id
Unique integer identifying each server to prevent replication loops.
log_bin
Enables binary logging on the server; required on the source for replication to work.
binlog_format = ROW
Recommended format that records row changes for more consistent replication results.
Summary
These three settings are the minimal configuration you must verify before taking a dump and starting a replica.
