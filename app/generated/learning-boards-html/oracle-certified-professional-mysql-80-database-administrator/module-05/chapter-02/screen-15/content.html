Replication User
A REPLICATION SLAVE account restricted by replica IP provides the required, minimal access for replication.
mysqldump options
--single-transaction, --flush-logs, --master-data=2 capture a consistent state and the replica start coordinates.
SHOW REPLICA STATUS
Primary verification for replication threads, errors, and lag metrics after starting the replica.
Summary
Use the replication user, mysqldump with coordinates, and SHOW REPLICA STATUS together to initialize and validate your replica reliably.
