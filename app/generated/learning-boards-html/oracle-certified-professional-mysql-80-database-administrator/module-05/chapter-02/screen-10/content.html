Module 5 › Chapter 5.2 › Verifying Replication Status
Example fields to inspect
SHOW REPLICA STATUS\G
# Look for:
#   Replica_IO_Running: Yes
#   Replica_SQL_Running: Yes
#   Last_IO_Error:
#   Last_SQL_Error:
#   Seconds_Behind_Source: 0
If either thread is No or errors are non-empty, use the error messages and logs to guide troubleshooting.
Interpreting issues
  • Replica_IO_Running No & Last_IO_Error about connection: check firewall and SOURCE_HOST.
  • Replica_SQL_Running No & Last_SQL_Error: likely an SQL application error or mismatch; stop replication before repairing.
  • Seconds_Behind_Source nonzero under load can be normal; investigate only if it grows unbounded.
