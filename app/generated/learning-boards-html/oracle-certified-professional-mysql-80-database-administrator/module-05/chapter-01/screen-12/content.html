Module 5 › Chapter 5.1 › Hands-on Verification
Steps to perform
-- Connect to your MySQL server using the command line client:
-- mysql -u root -p

-- Step 1: Check if binary logging is enabled
SHOW VARIABLES LIKE 'log_bin';

-- Step 2: Check the server ID
SHOW VARIABLES LIKE 'server_id';

-- Step 3: Check the binary log format
SHOW VARIABLES LIKE 'binlog_format';
Inspect the result values to verify preconditions. If log_bin is OFF or server_id is 0, you will need to change my.cnf and restart.
What to look for
  • If log_bin = ON, binary logging is enabled.
  • If server_id is nonzero and unique, the server can participate in replication.
  • binlog_format = ROW is common for safer row-level replication, but choose based on application needs.
Misconception
Do not assume default installations have these settings; always verify before proceeding with replication setup.
