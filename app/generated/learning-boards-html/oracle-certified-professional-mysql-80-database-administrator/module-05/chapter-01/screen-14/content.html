Module 5 › Chapter 5.1 › Key Concepts
Replication
Copying data-modifying events from a source to replicas to reproduce changes.
Source
Primary server where writes originate and whose binlog drives replication.
Replica
Secondary server that receives events, stores them in a relay log, and applies them to its data.
Summary Takeaway
Replication provides availability and read scaling; always verify binlog and server_id, monitor threads and lag, and keep backups to complement replication.
