Question 1
A DBA chooses asynchronous replication for a critical app. What is the primary risk and when would it manifest?
Answer
Potential data loss if the source crashes after committing transactions but before those events have been transmitted and received by a replica.
Question 2
Explain the relay log and which thread fills it on the replica.
Answer
The relay log is a temporary local file where the replica stores events received from the source; the replica's I/O (receiver) thread writes those events into the relay log.
Reflection
Being able to explain these failure modes and components means you can design replication with appropriate safeguards and diagnose where a problem is occurring when replication misbehaves.
