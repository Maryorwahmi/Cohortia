Module 5 › Chapter 5.1 › Configuration checks
Commands to run
-- Connect to your MySQL server using the command line client:
-- mysql -u root -p

SHOW VARIABLES LIKE 'log_bin';
SHOW VARIABLES LIKE 'server_id';
SHOW VARIABLES LIKE 'binlog_format';
Run these to confirm binary logging, server identity, and binlog format before attempting replication setup.
Sample my.cnf changes
[mysqld]
log_bin = mysql-bin
server_id = 1
binlog_format = ROW
If these variables are not set, you typically add them to my.cnf and restart the server to enable replication support.
Key Takeaway
Perform these quick checks to avoid common initial failures when starting replication.
