Module 6 › Chapter 5.6 › Reading SHOW REPLICA STATUS
Key fields explained
Replica_IO_Running: Yes/No for I/O thread; No implies connection or fetch issues.
Replica_SQL_Running: Yes/No for SQL thread; No implies an apply-time error.
Last_IO_Error / Last_SQL_Error: Exact error messages for threads useful for root cause.
Seconds_Behind_Source: Lag metric; correlate with thread status, not in isolation.
Example
Replica_IO_Running: Yes, Replica_SQL_Running: No, Last_SQL_Error: Duplicate entry '1' — focus on SQL thread remediation.
