GTID next
Use gtid_next to mark a transaction as executed when skipping to preserve GTID consistency.
mysql_upgrade coordination
Run on source first, wait for replicas to apply upgrade events, then run on replicas.
Operational best practices
Enable read_only, prefer ROW and GTID, monitor actively, test failover, and keep independent backups.
Final takeaway
Treat replication as an active operational responsibility: monitor, harden configuration, practice recovery, and document everything.
