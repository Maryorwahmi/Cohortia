Module 6 › Chapter 5.6 › IO thread vs SQL thread failures
I/O thread failure signs
  • Replica_IO_Running: No
  • Last_IO_Error: connection timed out, lost connection, or authentication failed
  • Typical causes: network, firewall, source down, replication user revoked
First steps: verify source MySQL, test connectivity, confirm user privileges.
Example
Replica_IO_Running: No, Last_IO_Error: Lost connection — check network and source service.
SQL thread failure signs
  • Replica_SQL_Running: No
  • Last_SQL_Error: duplicate key 1062 or missing row 1032
  • Typical causes: accidental replica writes, inconsistent initial snapshot, STATEMENT-based issues
First steps: capture Last_SQL_Error, find GTID or binlog position, decide skip or reinitialize.
Key Takeaway
Read the error text before restarting threads so you target the true cause, not the symptom.
