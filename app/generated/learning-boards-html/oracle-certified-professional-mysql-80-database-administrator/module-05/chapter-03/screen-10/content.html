Module 5 › Chapter 5.3 › Terminal demo: Set binlog_format and verify
my.cnf snippet
[mysqld]
binlog_format = ROW
log_bin = mysql-bin
expire_logs_days = 7
max_binlog_size = 100M
Restart the server after editing to apply changes. Verify with the next commands.
Verify active file
-- On MySQL prompt
SHOW MASTER STATUS;

-- Note the File value, e.g. mysql-bin.000001, for use with mysqlbinlog and backups.
If SHOW MASTER STATUS returns empty, check that log_bin is enabled and the server has been restarted successfully.
