Module 5 › Chapter 5.3 › Inspecting a generated binlog
Workflow
  1. Run SHOW MASTER STATUS and note the file name.
  2. Execute mysqlbinlog with decode and verbose on that file.
  3. Search output for INSERT, UPDATE and DELETE events and inspect row images.
mysqlbinlog --base64-output=decode-rows -v mysql-bin.00000X | less
What to look for
BEGIN and COMMIT markers, table and schema names, and for updates the before-and-after column values. These let you reconstruct exactly what changed and when.
Exercise

Locate the INSERT, then the UPDATE and confirm that the UPDATE includes both old and new values when binlog_format is ROW.
