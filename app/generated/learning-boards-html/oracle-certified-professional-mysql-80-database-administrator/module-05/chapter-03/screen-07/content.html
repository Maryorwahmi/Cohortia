Module 5 › Chapter 5.3 › Using mysqlbinlog to inspect events
Common mysqlbinlog workflows
Use these commands to read and filter events.
# View an entire binary log
mysqlbinlog mysql-bin.000001

# View events from specific positions
mysqlbinlog --start-position=1234 --stop-position=5678 mysql-bin.000001

# Decode row-based events for readability
mysqlbinlog --base64-output=decode-rows -v mysql-bin.000001
Reading results
Look for BEGIN and COMMIT to identify transactions. For row events, verify table identifiers and the before/after column values to reconstruct exactly what changed.
Pro tip

Pipe mysqlbinlog output to less for easier navigation, and decode rows when inspecting ROW-format logs to avoid misinterpreting binary data.

Exercise card
