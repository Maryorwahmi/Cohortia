Module 5 › Chapter 5.3 › Common mistakes and safety considerations
Frequent issues
  • Purging without checking all replicas causes irreversible replication failure.
  • expire_logs_days set lower than expected replica downtime risks data loss for replicas.
  • STATEMENT format hides nondeterministic behavior that breaks replicas.
  • Not enabling log_bin on a future source restricts failover options.
Safe practices
Check all replicas, prefer ROW for consistency, set expire_logs_days slightly longer than the longest backup or downtime window, and document the file and position used for any snapshot.
Key Takeaway

Cautious retention and verification practices protect replication and simplify recovery.
