Module 5 › Chapter 5.3 › Hands-on: Inspect binlog events for a test table
Starter SQL
CREATE DATABASE IF NOT EXISTS binlog_test;
USE binlog_test;
CREATE TABLE IF NOT EXISTS users (
  id INT AUTO_INCREMENT PRIMARY KEY,
  name VARCHAR(100),
  email VARCHAR(100) UNIQUE
);

INSERT INTO users (name, email) VALUES ('Alice', 'alice@example.com');
INSERT INTO users (name, email) VALUES ('Bob', 'bob@example.com');
UPDATE users SET email = 'alice_new@example.com' WHERE name = 'Alice';
DELETE FROM users WHERE name = 'Bob';
Inspection steps
  1. Run SHOW MASTER STATUS and note the File name.
  2. Exit the client and run mysqlbinlog with decode and verbose on that file.
  3. Find INSERT, UPDATE and DELETE events for binlog_test.users and describe the row images.
Exercise outcome

You should be able to identify old and new values in the UPDATE event and locate the INSERT and DELETE events for the test table using mysqlbinlog.
