Binary Log Format
STATEMENT, ROW, MIXED — choose by determinism and size trade-offs.
Configuration
Set log_bin, binlog_format, expire_logs_days, and max_binlog_size in my.cnf.
Inspection
Use mysqlbinlog with decode-rows and verbose to read events and row images.
Takeaway: prefer ROW for consistency, verify replica state before purging, and use mysqlbinlog to audit and debug exact changes.
