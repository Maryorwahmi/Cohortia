Module 5 › Chapter 5.3 › Purging binary logs safely
Automatic expiry
expire_logs_days removes files older than the configured number of days unless needed by replicas.
Manual purge commands
PURGE BINARY LOGS TO 'mysql-bin.000005';
PURGE BINARY LOGS BEFORE '2023-10-27 10:00:00';
Safety checklist
  • Check SHOW REPLICA STATUS on all replicas for required file and position.
  • Confirm backups and retention windows are satisfied.
  • Use a conservative expire_logs_days based on longest downtime.
Warning

Purging logs that replicas still need forces a full re-initialization of those replicas.
