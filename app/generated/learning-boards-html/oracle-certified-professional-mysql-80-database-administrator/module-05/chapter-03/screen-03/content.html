Practical Tasks
Concrete steps to verify configuration and logs
Enable and verify
Edit my.cnf to set binlog_format and log_bin, restart and confirm with SHOW MASTER STATUS.
Inspect events
Use mysqlbinlog with decode-rows and verbose to read row images and transaction boundaries.
Purge safely
Check replica status and only purge files older than the oldest needed by any replica.
Mnemonic
Remember A.R.C.: Configure (A), Read (R) with mysqlbinlog, Confirm (C) replica positions before purge.
VERIFIED COMPETENCY MILESTONE

Show that mysqlbinlog output contains before and after row images when binlog_format is ROW and that SHOW MASTER STATUS reports the active file.
