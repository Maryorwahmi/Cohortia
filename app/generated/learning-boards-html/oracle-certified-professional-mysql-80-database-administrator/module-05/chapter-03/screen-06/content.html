Module 5 › Chapter 5.3 › Configuring binlog parameters in my.cnf
my.cnf example
Edit these settings and restart MySQL to apply.
[mysqld]
binlog_format = ROW
log_bin = mysql-bin
expire_logs_days = 7
max_binlog_size = 100M
After restart, verify with SHOW MASTER STATUS to record the current file and position for replication tracking.
Notes and cautions
  • expire_logs_days should exceed the longest expected replica downtime.
  • max_binlog_size controls rotation; smaller sizes create more files but simplify transfers.
  • log_bin sets the base name; MySQL appends sequence numbers on rotation.
Common mistake

Setting expire_logs_days too low without checking replica lag can force full re-initialization of replicas when required logs are deleted.
