Module 1 › Chapter 1.2 › Installation Methods
Options
RPM/DEB packages: service integration, automatic updates, recommended for production.
Tarball: flexible install locations; manual service setup required.
Source: highest customization, longest maintenance effort.
Containers & Cloud
Containers are great for dev and portability but need persistent storage and orchestration design for production. Managed cloud services remove installation overhead but reduce low-level control.
Concrete example: Use official DEB packages on Ubuntu production servers to manage security updates via the OS package manager; use Docker images for developer environments to replicate the service quickly.
Pro Tip

Document update processes and service management for your chosen install method to avoid surprises during maintenance windows.
