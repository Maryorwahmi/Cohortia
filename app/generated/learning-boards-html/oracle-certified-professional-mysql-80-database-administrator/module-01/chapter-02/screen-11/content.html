Module 1 › Chapter 1.2 › Pre-install Checklist
Checklist items
  • Hardware specs: CPU, RAM, storage type, RAID and capacity with growth plan.
  • OS & file system: distribution, version, and filesystem selection.
  • Network config: IPs, firewall rules, and segmentation.
  • User accounts: dedicated OS user for MySQL and admin access plan.
  • Install method & version: chosen method and MySQL 8.0.x target.
  • Backup & monitoring: tools, schedules, and retention.
Verification steps
Add concrete tests: verify firewall rules, confirm buffer pool size in runtime config, and run a connectivity test from approved hosts.
Example entry: "Buffer pool target: 10 GB. Verify by checking innodb_buffer_pool_size after startup and observe hit rate within 24 hours."
Key Takeaway

Make each checklist item verifiable with a concrete test and owner to avoid ambiguity during provisioning.
