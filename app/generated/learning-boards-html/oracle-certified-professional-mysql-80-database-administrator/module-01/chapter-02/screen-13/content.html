Module 1 › Chapter 1.2 › Planning Activity
Scenario summary
E-commerce app, 100 concurrent users initially, scale to 500 within a year, integrity and performance critical, team uses Ubuntu.
Hardware: Initial 4 cores, 16 GB RAM, NVMe RAID 10 500 GB; scale plan to 8–16 cores, 64 GB RAM, 2 TB storage.
OS & FS: Ubuntu LTS with XFS and kernel tuning notes.
Install method: Official DEB packages for stability and updates.
Security & Post-install
Private subnet with firewall rules for app servers and admin CIDR; dedicated mysql OS user; disk encryption if required. Post-install: run security hardening, create application user, configure backups and monitoring.
Verification: test connectivity from allowed hosts, validate innodb_buffer_pool_size, and confirm backups write to the planned storage.
Deliverable

A one-page planning document that can be handed to operations containing specs, security rules, install method, and verification steps.
