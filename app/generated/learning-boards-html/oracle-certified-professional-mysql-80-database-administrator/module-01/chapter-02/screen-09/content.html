Module 1 › Chapter 1.2 › Security Checklist
Network and access
Design private network segments and firewall rules. Only allow the application tier and admin hosts to reach the database port.
Define IP allow lists for port 3306 and enforce least privilege.
Plan an admin bastion host for maintenance with MFA.
Document backup storage locations and encryption requirements.
Process & accounts
Run MySQL under a dedicated OS user and plan immediate password hardening after install. Include plans for key rotation and secrets management.
Concrete example: For e-commerce, restrict DB access to app subnet and admin CIDR, enable disk encryption and require a strong root password changed at first boot.
Warning

Exposing MySQL to the public internet or running as root are common and serious security mistakes.
