Module 1 › Chapter 1.2 › Planning Process
Steps
1
Define workload
Concurrent users, query patterns, growth projection.
2
Translate to hardware
CPU cores, RAM for buffer pool, storage type and capacity.
3
OS & file system
Pick stable distribution and file system suited to I/O needs.
4
Security
Network segmentation, firewall, and dedicated OS user.
5
Choose install method
Packages, tarball, container, or managed service.
Example: E-commerce initial plan
CPU: 4 cores initial, plan to 8-16 for scaling.
RAM: 16 GB initial; plan buffer pool sizing and roadmap to 64 GB.
Storage: NVMe on RAID 10, 500 GB initial with growth plan.
OS & FS: Ubuntu LTS with XFS for larger volumes.
Install: Official DEB packages for service integration and updates.
Key Takeaway

Make decisions traceable. Each planning step should map to a configuration or checklist item.
