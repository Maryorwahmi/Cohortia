Module 1 › Chapter 1.2 › Common Mistakes
Frequent errors
Under-provisioning RAM, exposing ports, running as root, and failing to leave storage headroom for logs are common issues that planning prevents.
Under-provisioning RAM leads to disk I/O and slow performance.
Open ports expose the server to unauthorized access.
Running MySQL as root increases the blast radius of a compromise.
Mitigations
Include verification steps for each checklist item, add monitoring and alerts, and assign owners for post-install checks.
Concrete test: verify firewall rules block unauthorized IPs and confirm the MySQL process runs as a non-root OS user before accepting traffic.
Warning

Skipping verification steps is the usual path to production incidents. Test early and document ownership.
