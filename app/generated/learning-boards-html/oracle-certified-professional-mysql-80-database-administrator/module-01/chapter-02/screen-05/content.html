CPU: Definition & impact
Modern multi-core CPUs help when many concurrent connections or parallelizable tasks exist. For single-threaded heavy queries, core count alone may not reduce latency.
Assess concurrency: estimate peak simultaneous connections and transaction rates.
Measure query complexity: joins, sorts, and functions increase CPU needs.
Consider virtualization effects and CPU steal in cloud environments.
Concrete example
An OLTP app with 200 concurrent users benefits from additional cores; document expected concurrency and initial core allocation.
Common misconception
More cores always means faster queries. Reality: cores increase throughput under concurrency but do not speed up a single CPU-bound query.
Pro tip
Document a monitoring plan to track CPU saturation and average queue length so you can scale cores before performance degrades.
Key Takeaway

Match CPU cores to expected concurrency and measure after deployment to guide scaling.
