Module 1 › Chapter 1.1 › Server Status Activity
Objective

Connect and inspect runtime variables

Run SHOW GLOBAL STATUS and SHOW VARIABLES to reveal Innodb_buffer_pool_reads, Innodb_buffer_pool_read_requests, Connections, Uptime, innodb_buffer_pool_size, default_storage_engine, and version.

Concrete steps
Start a Docker instance if needed, connect, and run the listed commands. Observe differences before and after workload or tuning.
Common mistake
Tuning without baseline measurements leads to guesswork. Always collect metrics first.
Example output
Innodb_buffer_pool_reads: number of reads from disk
Innodb_buffer_pool_read_requests: number of logical read requests
Connections: count of connection attempts
Key Takeaway

Measure first, tune second. Use the shown variables to validate buffer pool behavior and connection patterns before changing configuration.
