Definition

ACID and MVCC explained

Atomicity, Consistency, Isolation, Durability and MVCC work together so concurrent operations remain correct and committed changes persist after crashes.

Concrete example
Two transactions read the same row; one updates it. MVCC ensures the reader sees the snapshot it began with while the updater commits safely.
Misconception
Thinking MVCC removes all locks is incorrect; some operations still require locks and long transactions can retain old versions.
Operational notes
  • InnoDB uses a redo log for durability and crash recovery.
  • MVCC reduces reader-writer contention but requires purge to reclaim old versions.
  • Monitor long-running transactions to prevent undo growth.
Key Takeaway

Use InnoDB for data integrity and concurrency, and watch long transactions that delay purge and increase storage use.
