Module 1 › Chapter 1.1 › Key Concepts
Client-Server Model
Clients send queries; the server authenticates, parses, optimizes, and executes them.
Storage Engine
A pluggable component that controls storage, indexing, and recovery behavior.
InnoDB
Default transactional engine offering ACID, MVCC, redo logs, and crash recovery.
Takeaway
These concepts determine performance, recoverability, and how you design backups and monitoring for production systems.
