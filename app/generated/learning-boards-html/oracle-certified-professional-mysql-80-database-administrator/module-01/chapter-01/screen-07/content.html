Comparison

Engine trade-offs

InnoDB
Transactional, ACID, MVCC, durability via redo logs, default for integrity and concurrency.
MyISAM
Non-transactional, suitable for simple read-heavy tables historically, but lacks crash-safe recovery.
Memory
Stores table contents in memory for fast temporary lookups; data is not durable across restarts.
Scenarios
E-commerce orders
Use InnoDB for transactional safety and crash recovery guarantees.
Session caches
Memory engine works for fast ephemeral storage where persistence is not required.
Key Takeaway

Match engine capabilities to durability, concurrency, and recovery needs rather than choosing based on raw speed alone.
