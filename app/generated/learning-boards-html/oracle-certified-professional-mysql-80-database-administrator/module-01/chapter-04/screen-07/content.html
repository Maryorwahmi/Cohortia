Definition
Anonymous users & test DB
Defaults intended for testing, but risky if left in production because they enable unauthenticated actions or writable example data.
Why remove them
They simplify access for attackers and obscure which accounts should be used in production.
Verification
Run queries to confirm removals and test that application accounts still work. Example checks:
SELECT User, Host FROM mysql.user WHERE User='';
SHOW DATABASES LIKE 'test';
Misconception
Some administrators think anonymous accounts help monitoring. They do not; create explicit monitoring users with restricted rights instead.
