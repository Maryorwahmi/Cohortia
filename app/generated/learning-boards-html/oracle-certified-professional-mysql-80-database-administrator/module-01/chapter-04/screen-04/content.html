Core Concept
Run mysql_secure_installation
This script leads you through a small set of decisions that close common default vulnerabilities on a new server.
Step 1: Execute
sudo mysql_secure_installation
Step 2: Answer prompts
Choose to enable password validation, remove anonymous users, disallow remote root, remove test database, and reload privileges.
Step 3: Verify
Confirm removal of anonymous accounts and that root remote access is denied if you selected that option.
Key Takeaway

The script simplifies essential hardening but does not replace a full security plan. Use it as the first step and then create proper users and network controls.

Process flow
1
Enable password policy
2
Change root password
3
Remove anonymous & test
Misconception
Running the script is not sufficient security. It fixes defaults but does not configure users, logs, or network rules for ongoing defense.
Pro tip
Record the choices you make for repeatable deployment scripts or configuration management tools.
