Process
Audit checklist
Accounts
Check for anonymous users and unexpected accounts.
Privileges
Validate SHOW GRANTS for service and admin accounts.
Logging
Confirm slow and error logs exist and general log is off unless debugging.
Remediation examples
-- Remove anonymous users
DELETE FROM mysql.user WHERE User='';
FLUSH PRIVILEGES;

-- Restrict root to localhost
UPDATE mysql.user SET Host='localhost' WHERE User='root';
FLUSH PRIVILEGES;
