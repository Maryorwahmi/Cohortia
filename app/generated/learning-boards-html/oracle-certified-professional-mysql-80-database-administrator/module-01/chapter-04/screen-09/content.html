Core Concept
Create admin and application users
Use precise GRANT statements and always test via login and SHOW GRANTS.
-- Admin user (restricted host)
CREATE USER 'admin_cohortia'@'localhost' IDENTIFIED BY 'YourAdminPassword!';
GRANT ALL PRIVILEGES ON *.* TO 'admin_cohortia'@'localhost' WITH GRANT OPTION;
FLUSH PRIVILEGES;

-- App user and DB
CREATE DATABASE my_ecommerce_db;
CREATE USER 'app_user'@'localhost' IDENTIFIED BY 'YourAppPassword!';
GRANT SELECT, INSERT, UPDATE, DELETE ON my_ecommerce_db.* TO 'app_user'@'localhost';
FLUSH PRIVILEGES;
Explanation & checks
  • Grant only the privileges an account needs to perform its role.
  • Use host qualifiers to limit where an account can connect from.
  • Verify with SHOW GRANTS FOR 'user'@'host'; and by attempting restricted actions.
Common Mistake
Granting ALL PRIVILEGES to application users. This grants far more authority than required and increases risk.
