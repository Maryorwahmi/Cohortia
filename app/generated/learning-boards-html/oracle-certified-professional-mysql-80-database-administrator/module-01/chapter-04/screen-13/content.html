Core Concept
Firewall rules
Limit which hosts can reach MySQL on port 3306 and verify by testing from authorized systems.
CentOS/RHEL example
sudo firewall-cmd --permanent --add-port=3306/tcp
# restrict to subnet
sudo firewall-cmd --permanent --add-rich-rule='rule family="ipv4" source address="192.168.1.0/24" port port=3306 protocol="tcp" accept'
sudo firewall-cmd --reload
Ubuntu/Debian example
sudo ufw allow from 192.168.1.0/24 to any port 3306
sudo ufw enable
sudo ufw status
Safety note
Always test connectivity from a trusted host before removing your own access. Keep a failsafe administrative channel available during changes.
