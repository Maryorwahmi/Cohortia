Quick Reference
Secure Script
Run mysql_secure_installation and enable at least MEDIUM password validation.
Users & Grants
Create admin and app users with minimal privileges and test SHOW GRANTS for each.
Logging & Firewall
Enable slow query and error logs and restrict port 3306 to trusted hosts.
Final Takeaway
Treat post-install hardening as a required checklist: automate it, verify each step, and include periodic reviews so your secure baseline endures.
