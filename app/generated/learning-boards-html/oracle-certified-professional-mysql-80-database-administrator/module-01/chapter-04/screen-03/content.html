Module 2 › Chapter 1.4 › Verification & Safety
Checklist cards
Test account
Log in as the new user, run SHOW GRANTS FOR the account, and attempt to access other databases to confirm least privilege.
Restart & log check
After editing my.cnf, restart MySQL and verify error and slow query logs exist and are writable.
Firewall dry run
Apply a permissive rule first or test from a secondary session to avoid locking out administrative access.
Controlled slow query
Run a short sleep query to confirm slow query logging without impacting production traffic.
