Definition
Logging in my.cnf
Configure log types and file locations under the [mysqld] section and restart MySQL after changes.
[mysqld]
log_error = /var/log/mysql/error.log
# general_log = 1
# general_log_file = /var/log/mysql/mysql.log
slow_query_log = 1
slow_query_log_file = /var/log/mysql/mysql-slow.log
long_query_time = 1
log_queries_not_using_indexes = 1
Safety and verification
  • Restart MySQL after edits and check file ownership and rotation.
  • Avoid enabling the general query log long term; it can fill disks quickly.
  • Use controlled tests like SELECT SLEEP(3); to confirm slow query logging.
