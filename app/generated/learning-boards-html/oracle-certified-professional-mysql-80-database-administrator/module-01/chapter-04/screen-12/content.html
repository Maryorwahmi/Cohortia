Process Flow
Restart and verify
Use the correct restart command, then check logs and run a controlled test to confirm behavior.
# RPM systems
sudo systemctl restart mysqld
# DEB systems
sudo systemctl restart mysql

# Controlled test
mysql -u root -p -e "SELECT SLEEP(3);"
# Inspect slow log
sudo tail -n 50 /var/log/mysql/mysql-slow.log
Troubleshooting tips
  • Check ownership and permissions of log files if nothing is written.
  • Keep a second session open while restarting to avoid lockouts.
  • Disable general log immediately after finishing debugging.
