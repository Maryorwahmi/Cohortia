Definition
VALIDATE PASSWORD Component
A plugin that enforces password complexity at account creation or change time.
LOW
Minimum length, typically 8 characters.
MEDIUM
Length plus numbers, mixed case, and special characters.
STRONG
Adds dictionary checks to MEDIUM requirements.
Practical example
-- Policy will reject weak passwords when creating users or changing them.
CREATE USER 'svc'@'localhost' IDENTIFIED BY 'Admin_Pass1!';
Misconception
Strong passwords are necessary but not sufficient. Combine policies with monitoring, rotation, and least privilege.
