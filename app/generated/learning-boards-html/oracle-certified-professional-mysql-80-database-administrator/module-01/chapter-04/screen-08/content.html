Comparison
Remote root vs restricted admin user
Remote root
Highly privileged, exposed on network, attractive target for brute-force attacks.
Restricted admin user
Create with specific host/IP restriction, strong password, and audit its usage separately.
Example commands
CREATE USER 'admin_cohortia'@'192.168.1.100' IDENTIFIED BY 'StrongAdminPassword_123!';
GRANT ALL PRIVILEGES ON *.* TO 'admin_cohortia'@'192.168.1.100' WITH GRANT OPTION;
FLUSH PRIVILEGES;
Misconception
Some assume remote root is acceptable behind a firewall. If that account is breached, a firewall misconfiguration or lateral movement can still lead to compromise.
