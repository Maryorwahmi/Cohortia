RPM: Temporary Password

sudo grep 'temporary password' /var/log/mysqld.log
mysql -u root -p
ALTER USER 'root'@'localhost' IDENTIFIED BY 'NewStrongPassword!';

Retrieve the temporary password from the error log, log in, and change it immediately for security.

DEB: Interactive Prompt

DEB-based installers typically prompt for a root password during setup. If you forget it, follow the safe-mode reset flow to change it.

Reset flow (DEB):
Stop mysql, start safe mode without grant tables, connect, change root password, restart normally.
Key Takeaway

Treat initial root credentials as sensitive. Find or set the password during installation and change it to a strong secret immediately.
