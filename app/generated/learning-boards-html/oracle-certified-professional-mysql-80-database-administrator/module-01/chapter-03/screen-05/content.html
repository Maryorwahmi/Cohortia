Install

Install mysql-community-server

Use dnf or yum to install the server package and let the manager handle dependencies.

sudo dnf install mysql-community-server
sudo systemctl start mysqld
sudo systemctl enable mysqld
sudo systemctl status mysqld
What to watch

If the server does not stay active, consult /var/log/mysqld.log for temporary root passwords or errors preventing startup.

Explain & Example
  • The package manager ensures required shared libraries are installed automatically.
  • On RPM systems the service name is usually mysqld. Using mysql here will often return an error for systemctl commands.
  • Look for a temporary root password line in the error log after an RPM install and change it immediately.
Key Takeaway

Use the system package manager to install the server, then manage the mysqld service and check logs for initial credentials or errors.
