Install

Install mysql-server with apt

Run apt install after adding the APT config package and updating package lists.

sudo apt install mysql-server
sudo systemctl start mysql
sudo systemctl enable mysql
mysql -u root -p
Notes
  • The installer usually prompts to set a MySQL root password; record it securely.
  • Choose caching_sha2_password for modern security unless older clients require compatibility.
  • If you forget the password, DEB systems require a root password reset procedure involving safe mode and FLUSH PRIVILEGES.
Key Takeaway

DEB installs are interactive. Set a strong root password during installation and verify by connecting to the server and running a simple query.
