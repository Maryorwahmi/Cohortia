Module 1 › Chapter 1.3 › Service Names & systemctl
RPM

Service: mysqld

sudo systemctl start mysqld
sudo systemctl enable mysqld
sudo systemctl status mysqld

If mysqld fails to start, check /var/log/mysqld.log for startup errors and temporary root password notifications.

DEB

Service: mysql

sudo systemctl start mysql
sudo systemctl enable mysql
sudo systemctl status mysql

DEB-based installs typically prompt for a root password; check /var/log/mysql/error.log for errors rather than a temporary password line.

Key Takeaway

Remember the service name difference. Using the correct name with systemctl avoids false negatives when checking status and logs.
