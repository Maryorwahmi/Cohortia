Module 1 › Chapter 1.3 › Verify & Test

Command checks

mysql --version
mysql -u root -p
SHOW DATABASES;
SELECT VERSION();

Successful queries indicate the server is running and accepting connections from the client on the chosen socket or network port.

Troubleshoot
  • If login fails, verify the password used during DEB install or the temporary password from the RPM error log.
  • Check systemctl status for the correct service name and inspect the error log for startup failures.
  • For local failures, confirm the client and server agree on the socket path configured in my.cnf.
Key Takeaway

A working mysql client plus a live SQL query is the most reliable confirmation that installation succeeded and the server operates correctly.
