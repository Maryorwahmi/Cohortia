Step-by-step

Install the MySQL Yum repo

Download the repo package appropriate for your RHEL/CentOS/Fedora release, then install it with rpm.

1. Download repo package
wget https://dev.mysql.com/get/mysql80-community-release-el7-3.noarch.rpm
2. Install the package
sudo rpm -ivh mysql80-community-release-el7-3.noarch.rpm
3. Verify repo availability
sudo dnf repolist | grep mysql
Explanation & Checks
  • Installing the RPM places a repo file under /etc/yum.repos.d so dnf or yum can use MySQL packages.
  • Always use the package matching your distribution version; el7 vs el8 vs el9 differences matter.
  • If multiple MySQL repos exist, set enabled=0 for ones you don't want in /etc/yum.repos.d/mysql-community.repo to avoid version conflicts.
Common mistake

Installing a repo for the wrong OS release leads to missing packages or incompatible metadata. Confirm your distro version first.

Key Takeaway

Add the vendor repo that matches your OS release and verify it appears in the package manager's repo list before installing MySQL.
