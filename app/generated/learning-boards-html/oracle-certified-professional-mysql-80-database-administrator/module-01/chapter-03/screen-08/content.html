Common File Locations

Configuration
RPM: /etc/my.cnf • DEB: /etc/mysql/mysql.conf.d/mysqld.cnf
Data Directory
/var/lib/mysql — contains physical database files. Do not edit directly.
Error Log
RPM: /var/log/mysqld.log • DEB: /var/log/mysql/error.log
Socket File
/var/run/mysqld/mysqld.sock or /var/run/mysql/mysqld.sock depending on distro.
Practical checks
  • If the server fails to start, check the error log for messages and temporary root password notices.
  • Verify the socket path when a localhost client can't connect; mismatched sockets cause silent failures.
  • Never modify files in /var/lib/mysql directly; use SQL commands, backup, or fs-level snapshots instead.
Misconception

Editing database files in the data directory or moving files manually risks corruption. Use supported tools and configuration changes instead.
