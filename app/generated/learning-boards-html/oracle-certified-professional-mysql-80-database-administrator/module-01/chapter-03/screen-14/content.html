Module 1 › Chapter 1.3 › Key Concepts
Official Repository

Use vendor repos so packages, dependencies, and updates are consistent.

Service Name

Use mysqld on RPM systems and mysql on DEB systems for systemctl commands.

Initial Credentials

RPM may write a temporary root password to the error log; DEB usually prompts during the install.

Summary Takeaway

Follow distribution-specific repository and install steps, verify the running service and file locations, and consult logs when problems occur.
