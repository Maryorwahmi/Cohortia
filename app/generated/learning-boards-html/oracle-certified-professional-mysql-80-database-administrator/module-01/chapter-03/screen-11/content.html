Problem checks

Repository issues
Run dnf/apt repolist and confirm the MySQL repo for your OS release is enabled.
Dependencies
Read package manager error output to identify missing libraries and add required repos.
Port conflicts
Use sudo netstat -tulnp | grep 3306 to find a conflicting PID and stop or reconfigure it.
Disk space
Ensure free space on partitions used by /var/lib/mysql and /var/log before installing or starting the server.
Diagnostic flow
  1. Confirm repository configuration and re-run package index updates.
  2. Install or fix missing dependencies reported by the package manager.
  3. Start the service and inspect the MySQL error log for startup messages.
  4. Use netstat and check disk usage if problems persist.
Misconception

Logs are your best friend. Avoid guessing fixes before you confirm the exact error message in the log files and package manager output.
