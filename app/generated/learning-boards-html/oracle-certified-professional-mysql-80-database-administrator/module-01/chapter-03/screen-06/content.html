Module 1 › Chapter 1.3 › Add APT Repo
Steps

Install mysql-apt-config

Add the official MySQL APT configuration package and update your package index.

wget https://dev.mysql.com/get/mysql-apt-config_0.8.29-1_all.deb
sudo dpkg -i mysql-apt-config_0.8.29-1_all.deb
sudo apt update
Interactive note

During dpkg install you'll be prompted to choose 'MySQL Server & Cluster' and select mysql-8.0. Accept the default for standard installs.

Checks & Tips
  • Run sudo apt update after installing the APT config package so the new repository is recognized.
  • Choose caching_sha2_password unless you must support older clients requiring mysql_native_password.
  • If you make a mistaken selection during the dpkg prompt, re-run the package or edit the APT sources file to correct it.
Key Takeaway

Installing the MySQL APT config package is a small interactive step that ensures apt installs the official MySQL 8.0 packages on Debian and Ubuntu.
