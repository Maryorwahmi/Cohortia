Module 6 › Chapter 6.5 › Learning Objectives — Practice
Type Verification
Measure row size and buffer effect
  • Compare bytes per column for candidate types.
  • Estimate how many rows fit in the InnoDB buffer pool.
  • Prefer smaller types when they cover all values reliably.
Denorm Safety
Plan update and reconciliation
  • Only denormalize for hot read paths.
  • Design triggers or application logic to keep duplicates consistent.
  • Document where redundancy exists and why.
Partition Tests
Confirm pruning with EXPLAIN
  • Run INFORMATION_SCHEMA.PARTITIONS to observe distribution.
  • Use EXPLAIN to check the partitions column for pruning.
  • Add partitions before MAXVALUE to avoid blocking reorganizations.
Safe Changes
Stage and estimate downtime
  • Test ALTER TABLE on staging with similar data volume.
  • Schedule large changes in maintenance windows.
  • Consider copying data into a new table and swapping if needed.
