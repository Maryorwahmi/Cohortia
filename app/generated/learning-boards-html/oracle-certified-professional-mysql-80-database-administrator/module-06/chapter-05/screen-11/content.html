Code Walkthrough Range Partitioning Example
Schema example
CREATE DATABASE IF NOT EXISTS iot_data;
USE iot_data;

CREATE TABLE sensor_data (
  id INT AUTO_INCREMENT,
  device_id INT NOT NULL,
  reading_time DATETIME NOT NULL,
  temperature DECIMAL(5,2),
  humidity DECIMAL(5,2),
  PRIMARY KEY (id, reading_time)
)
PARTITION BY RANGE (YEAR(reading_time)) (
  PARTITION p2022 VALUES LESS THAN (2023),
  PARTITION p2023 VALUES LESS THAN (2024),
  PARTITION p2024 VALUES LESS THAN (2025),
  PARTITION p_future VALUES LESS THAN MAXVALUE
);
Note: primary key includes the partition column as shown to satisfy uniqueness requirements in some partition setups.
Verification steps
  1. Inspect partitions: SELECT PARTITION_NAME,TABLE_ROWS FROM INFORMATION_SCHEMA.PARTITIONS WHERE TABLE_SCHEMA='iot_data' AND TABLE_NAME='sensor_data';
  2. EXPLAIN without pruning: EXPLAIN SELECT COUNT(*) FROM sensor_data WHERE device_id = 1; (partitions will list all partitions)
  3. EXPLAIN with pruning: EXPLAIN SELECT COUNT(*) FROM sensor_data WHERE reading_time BETWEEN '2023-01-01' AND '2023-12-31'; (partitions should list p2023)
Key Takeaway

Use EXPLAIN and INFORMATION_SCHEMA to confirm partition pruning before relying on partition performance gains.
