Safe migration timeline
  1. Replicate production volume in staging and test changes end-to-end.
  2. Measure blocking behavior and estimate downtime.
  3. Consider copy-and-swap strategy for large tables to avoid long locks.
  4. Schedule maintenance and communicate with stakeholders.
Partition operation notes
Adding partitions: generally safe but plan for reorganizing MAXVALUE partitions.
Repartitioning: can be resource-intensive; prefer maintenance windows and staging tests.
Backups: ensure backups and a rollback plan before structural changes.
Pro tip
For very large tables, copy data to a new partitioned table in batches, then swap names once up-to-date to minimize write impact.
