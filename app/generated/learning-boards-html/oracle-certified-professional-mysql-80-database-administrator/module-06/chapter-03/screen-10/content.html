Module 06 › Chapter 6.3 › Practical example
Problematic query
SELECT * FROM products WHERE category_id = 5 ORDER BY price DESC;
EXPLAIN shows type: ALL and Extra: Using filesort, indicating a full scan and sort. This is the classic sign to consider a composite index.
Index to add
CREATE INDEX idx_category_price ON products (category_id, price DESC);
Expected EXPLAIN after
type becomes ref or range, key shows idx_category_price, and Extra no longer shows Using filesort — possibly Using index if the index covers selected columns.
Note
If SELECT * is used, the index may not be fully covering; consider selecting only needed columns or extending the index if queries rely on additional columns.
