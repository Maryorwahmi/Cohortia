Module 06 › Chapter 6.3 › Indexes in EXPLAIN
Which indexes were considered and used
possible_keys: idx_city, idx_name key: idx_city key_len: 12 ref: const
If key is NULL, MySQL did not use an index for that table. If possible_keys is empty, create an index aligned to the query pattern.
Composite index hint
key_len helps you see whether a composite index’s leading columns were used. If key_len is shorter than expected, reorder or split the index to match WHERE and ORDER BY.
Misconception
possible_keys alone does not mean the optimizer will use those indexes; key shows the final choice and reveals missed opportunities.
Action
When key is NULL and possible_keys is empty, create an index that matches filtering and ordering columns, then re-run EXPLAIN to validate key changes.
