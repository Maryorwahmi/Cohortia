Module 06 › Chapter 6.3 › Optimization workflow
Diagnose → Index → Validate → Measure
1
Diagnose
Run EXPLAIN, capture type,key,rows,Extra.
2
Index
Design composite index for WHERE and ORDER BY.
3
Validate
Re-run EXPLAIN in staging to confirm plan changes.
4
Measure
Execute query to confirm latency and I/O improvements.
Keep a changelog of EXPLAIN snapshots and measured timings for each optimization so you can roll back if necessary.
Pitfall
Changing indexes in production without staging and measurement risks regressions; always validate first.
Pro tip
If SELECT * prevents a covering index, either restrict selected columns or extend the index to include frequently used fields.
