Module 06 › Chapter 6.3 › Extra column flags
Common Extra values
  • Using filesort: indicates an extra sort pass; often fixed by an index that matches ORDER BY.
  • Using temporary: temporary table was required; review GROUP BY, DISTINCT, or derived-table usage.
  • Using index: covering index used; efficient when SELECT list is satisfied by the index.
  • Using where: WHERE applied; combined with ALL suggests filtering after scanning.
  • Using index condition: predicate pushed to storage engine; good for selective index filtering.
Example diagnosis
If you see type=ALL and Extra=Using filesort, create or reorder an index to cover WHERE and ORDER BY to avoid the filesort and reduce scanned rows.
Misconception
Using index means no row lookups for those columns, but the overall query may still scan other tables or invoke temporary tables elsewhere in the plan.
Practical tip
When Extra shows filesort or temporary, design a composite index that covers filtering and sorting columns, then re-run EXPLAIN and validate that the Extra flags change or disappear.
