Module 06 › Chapter 6.3 › Hands-on Activity
Activity steps
  1. Run EXPLAIN on the slow query and note type, key, rows, Extra.
  2. Create index: CREATE INDEX idx_city_lastname ON customers (city, last_name).
  3. Re-run EXPLAIN and compare changes in type, key, and Extra.
  4. Execute the query to measure actual latency and resource usage.
  5. Reflect and document the before/after EXPLAIN and timing results.
Example template
EXPLAIN SELECT customer_id, first_name, last_name, email FROM customers WHERE city = 'New York' ORDER BY last_name LIMIT 10;
Create index: CREATE INDEX idx_city_lastname ON customers (city, last_name); then re-run EXPLAIN to confirm key changes and removal of filesort.
Reflection prompt
Which EXPLAIN column changed most after adding the index, and how did that correlate to measured runtime?
