Module 06 › Chapter 6.3 › What EXPLAIN shows
Definition and safety

EXPLAIN returns the optimizer’s plan for a SELECT statement without executing the full query. It lists operations per table and supplies estimates and flags you can act on.

How to run
EXPLAIN SELECT ...
Misconception
EXPLAIN shows planned work and estimates, not actual execution time. Always validate after optimization by running the query.
EXPLAIN output example
id | select_type | table | type | possible_keys | key | rows | Extra
1 | SIMPLE | customers | ALL | NULL | NULL | 1000000 | Using filesort
Practice tip
Run EXPLAIN first, then change indexes, then re-run to see the plan change before you update production schema.
