Process Flow
Enable Performance Schema Safely
Step 1: Check status
Run SHOW VARIABLES LIKE 'performance_schema' to see current state.
Step 2: Edit my.cnf
Set performance_schema = ON and enable specific instruments only.
Step 3: Restart & validate
Restart server and run a short workload to confirm event rows appear.
Validate with queries such as SELECT * FROM performance_schema.events_waits_summary_by_instance WHERE SUM_TIMER_WAIT > 0 LIMIT 10; Capture a baseline before enabling more instruments.
Quick checklist
  • Confirm OFF/ON state
  • Enable minimal instruments
  • Restart carefully in maintenance windows
  • Measure overhead on staging
Example
SHOW VARIABLES LIKE 'performance_schema';
-- then set performance_schema = ON in my.cnf and restart
Key Takeaway

Enable only what you need, test overhead, and revert or reduce instrumentation after analysis.
