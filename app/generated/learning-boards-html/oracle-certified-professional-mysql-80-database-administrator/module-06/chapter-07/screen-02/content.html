Module 7 › Chapter 6.7 › Learning Objectives
01
Use Performance Schema
Collect event-level statistics to pinpoint I/O waits and contention.
You will enable and configure Performance Schema consumers and instruments, learn what event types are available, and practice retrieving statements that show the heaviest waits. Mnemonic: think of Performance Schema as a fine-grained profiler for server events.
VERIFIED COMPETENCY MILESTONE
02
Leverage sys schema views
Translate raw events into ready-to-use insights with built-in views.
Practice queries such as statements_with_full_table_scans and schema_table_statistics to rapidly find slow queries and busy tables. Visual mnemonic: imagine sys as a readable layer over a dense log table.
VERIFIED COMPETENCY MILESTONE
03
Understand Enterprise Monitor
Use alerts and historical trends for proactive tuning.
You'll recognize when a commercial monitoring solution makes sense, what types of advisor recommendations to trust, and how to use historical graphs to spot regressions. Think: alerts before users notice a problem.
VERIFIED COMPETENCY MILESTONE
04
Apply safe tuning techniques
Use query rewrites, optimizer hints, and pooling as targeted fixes.
You will practice rewriting queries and adding hints like FORCE INDEX only after measuring impact, and design a pooling approach to reduce max_connections pressure. Safety note: hints are last-resort tools.
VERIFIED COMPETENCY MILESTONE
