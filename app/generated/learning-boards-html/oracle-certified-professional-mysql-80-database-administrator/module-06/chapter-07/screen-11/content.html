Hints Compared
USE INDEX — recommend an index without forcing it; safer but advisory.
FORCE INDEX — force use of a specific index; useful when optimizer ignores a correct index but risky long-term.
STRAIGHT_JOIN — enforce join order; can fix pathological ordering but bypasses optimizer choices.
Example usage note
If repeated testing shows the optimizer picks a full table scan despite a correct index, apply FORCE INDEX temporarily and compare avg_latency and rows_examined to confirm improvement.
Safety checklist
  • Document why the hint is used
  • Add tests comparing latency and rows examined
  • Plan removal criteria for when data changes
Key Takeaway

Hints can fix specific problems but are tactical and must be tested, documented, and reversible.
