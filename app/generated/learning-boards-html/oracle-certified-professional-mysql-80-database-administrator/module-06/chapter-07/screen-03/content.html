Module 7 › Chapter 6.7 › Applied Objectives
01
Enable selectively
Turn on only the instruments and consumers you need to limit overhead.
Practice checking SHOW VARIABLES for performance_schema and editing my.cnf, then restart to apply. Confirm with small, targeted workloads rather than enabling everything in production.
VERIFIED COMPETENCY MILESTONE
02
Use sys views for quick wins
Query built-in views to find full scans and runtime hotspots fast.
Run the statements_with_runtimes_in_host and statements_with_full_table_scans views, and capture the top N results for follow-up tuning.
VERIFIED COMPETENCY MILESTONE
03
Test rewrites and hints
Make changes, measure latency, and roll back if there is no benefit.
Compare total_latency and avg_latency before and after, and avoid permanent hints unless proven across representative loads.
VERIFIED COMPETENCY MILESTONE
04
Design pooling
Choose pool sizes to reduce connection churn while respecting max_connections.
Measure connection create time and server load, then size a pool that balances latency and server capacity.
