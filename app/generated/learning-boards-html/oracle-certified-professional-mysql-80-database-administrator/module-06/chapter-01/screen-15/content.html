Module 6 › Chapter 6.1 › Quick Reference
Capture baseline
Timestamp STATUS, GLOBAL STATUS, and process lists for later comparison.
Prioritize fixes
Query/schema changes first, configuration in staging, then hardware if necessary.
Watch for contention
Repeated lock waits or many sessions in locked states often point to concurrency or transaction design problems.
Final takeaway

Collect evidence first, prefer small reversible changes, and verify impact with the same metrics you used to diagnose the issue.
