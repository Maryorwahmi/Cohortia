Definition

Key performance metrics to watch

Understand what each metric signals about system health and which ones you should chart.

Queries Per Second (QPS)
Volume of queries processed per second; pair with latency to find bottlenecks.
Transactions Per Second (TPS)
Number of transactions committed per second; useful for transactional workloads.
Latency
Time for queries or transactions to complete; sustained high latency is an urgent signal.
InnoDB buffer pool hit ratio

Percentage of reads satisfied from memory. A low ratio often leads to more disk I/O and higher latency.

Lock waits
When sessions are blocked waiting for locks, concurrency is reduced and throughput drops.
Correlation example
High QPS + rising latency + increasing physical reads suggests cache pressure; consider buffer pool sizing or query tuning.
Common mistake

Treating one-off spikes as chronic problems instead of comparing to baseline trends and load patterns.
