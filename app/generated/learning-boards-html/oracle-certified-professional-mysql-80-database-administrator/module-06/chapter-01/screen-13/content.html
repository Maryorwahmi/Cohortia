Hierarchy

When to tune queries, indexes, or configuration

Use a simple decision hierarchy to choose the least intrusive, most effective action.

Level 1 — Query and schema
Rewrite queries or add indexes when EXPLAIN shows inefficient access patterns.
Level 2 — Configuration
Adjust buffer pool or other server parameters in staging if metrics show systemic resource pressure.
Level 3 — Hardware
Consider CPU, memory, or disk upgrades only after software-level remedies are evaluated.
Concrete example

If multiple queries show high physical reads, test an index or query rewrite first. If many queries still read from disk, then consider increasing innodb_buffer_pool_size in staging.

Key Takeaway

Start small and reversible, measure results, and escalate only when evidence shows broader changes are required.
