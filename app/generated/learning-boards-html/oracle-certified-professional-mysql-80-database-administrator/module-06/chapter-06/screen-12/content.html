Process Flow › Change workflow
Step-by-step
  1. Backup my.cnf.
  2. Use SET GLOBAL to test changes at runtime.
  3. Verify with SHOW GLOBAL VARIABLES.
  4. Edit my.cnf and restart for persistence.
Example commands (visual only)
SHOW GLOBAL VARIABLES LIKE 'innodb_buffer_pool_size';
SET GLOBAL innodb_buffer_pool_size = 6442450944;
SHOW GLOBAL VARIABLES LIKE 'innodb_buffer_pool_size';
Misconception
SET GLOBAL does not persist across restarts; always update my.cnf and restart to keep changes.
Key Takeaway

Follow test, verify, persist pattern and perform all steps in a staging mirror before production deployment.
