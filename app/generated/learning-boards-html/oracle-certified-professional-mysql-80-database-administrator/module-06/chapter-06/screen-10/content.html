Process › sort_buffer_size & join_buffer_size
When these buffers are used

Filesort operations and non-indexed joins allocate these buffers. Check EXPLAIN output for Using filesort or full join patterns.

Practical step
Optimize indexes first, then tune buffers modestly if needed under load testing.
Memory planning
Because allocation is per connection, calculate the worst-case concurrent allocation before raising these values.
Misconception
Large global buffer values are not free and can cause memory exhaustion under high concurrency.
Key Takeaway

Prefer indexing; tune per-operation buffers only when indexes are not feasible and after capacity planning.
