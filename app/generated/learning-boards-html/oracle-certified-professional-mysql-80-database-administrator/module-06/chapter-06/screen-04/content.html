Core Concept › Locate and read my.cnf
File structure and common locations

my.cnf and my.ini use bracketed sections. [mysqld] is where server parameters live. Common Unix paths include /etc/my.cnf and /etc/mysql/my.cnf; Windows uses my.ini in the MySQL installation directory.

Quick commands (visual)
SHOW VARIABLES LIKE 'datadir';
mysql --help | grep "Default options"
Example
Add settings under [mysqld] to make them affect the server at startup.
Common mistake
Editing the wrong my.cnf path or modifying [client] instead of [mysqld] prevents changes from applying to the server.
Annotated snippet
[mysqld]
innodb_buffer_pool_size = 6G
max_connections = 300
# comments explain intent
Check your work
  • Backup my.cnf before editing.
  • Use SHOW VARIABLES to confirm current runtime values.
  • Restart server to apply persistent changes.
Key Takeaway

Persistent configuration is managed in my.cnf under [mysqld]. Confirm path and backup the file before edits.
