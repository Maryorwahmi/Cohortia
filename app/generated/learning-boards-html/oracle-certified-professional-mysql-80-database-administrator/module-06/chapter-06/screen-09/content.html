Definition › tmp_table_size & max_heap_table_size
When temporary tables spill

Spilling to disk adds latency. Monitor queries that cause temporary table creation and identify root causes with EXPLAIN.

Optimization path
Prefer indexing or rewriting queries before raising sizes; increase sizes incrementally when needed.
Memory considerations
These limits apply per session. Multiply worst-case session memory by connection counts to estimate server impact.
Misconception
Raising global sizes without considering concurrency can lead to memory exhaustion.
Key Takeaway

Address query design first, then increase in-memory temporary sizes carefully while monitoring concurrency.
