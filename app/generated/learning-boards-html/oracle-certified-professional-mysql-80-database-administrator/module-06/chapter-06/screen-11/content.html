Comparison › Query Cache removal
Why removal improves scalability

Table-wide invalidation on writes caused contention. Removing the Query Cache eliminates that bottleneck in 8.0.

Alternatives
Use InnoDB buffer pool for page caching; use external caches or proxies for result caching.
Practical approach
Push caching to the application or proxy layer where invalidation can be selective and distributed.
Misconception
Assuming an internal query cache can scale with writes undercuts the need for application-aware caching strategies.
Key Takeaway

Use external caching for result sets and rely on the buffer pool for data caching; this scales better with writes.
