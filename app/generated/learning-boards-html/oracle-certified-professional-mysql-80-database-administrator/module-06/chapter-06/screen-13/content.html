Hands-on Activity › Tuning example
Step checklist
  1. SHOW GLOBAL VARIABLES to capture current values.
  2. Calculate buffer pool using RAM × 0.75.
  3. SET GLOBAL to test runtime changes.
  4. Verify with SHOW GLOBAL VARIABLES and monitoring.
  5. Edit my.cnf and restart to persist after validation.
Visual code template
-- Check values
SHOW GLOBAL VARIABLES LIKE 'innodb_buffer_pool_size';
SHOW GLOBAL VARIABLES LIKE 'max_connections';

-- Dynamically test
SET GLOBAL innodb_buffer_pool_size = 6442450944; -- 6GB
SET GLOBAL max_connections = 300;

-- Verify
SHOW GLOBAL VARIABLES LIKE 'innodb_buffer_pool_size';
SHOW GLOBAL VARIABLES LIKE 'max_connections';

-- Conceptual my.cnf lines (persist after testing)
-- [mysqld]
-- innodb_buffer_pool_size = 6G
-- max_connections = 300
Do this first in staging and backup my.cnf before any persistent edits.
