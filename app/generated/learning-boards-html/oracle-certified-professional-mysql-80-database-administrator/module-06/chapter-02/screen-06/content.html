Module 6 › Chapter 6.2 › DML Counters
What each counter means
  • Com_select: counts SELECT statements executed.
  • Com_insert: counts INSERT statements executed.
  • Com_update: counts UPDATE statements executed.
  • Com_delete: counts DELETE statements executed.
Example
A sudden spike in Com_update with rising Innodb_row_lock_waits indicates concurrent writers causing contention.
Interpretation cards
Read-heavy
High Com_select delta, low Com_update delta. Consider cache sizing and query efficiency.
Write-heavy
High Com_update and Com_insert deltas. Watch redo/undo activity and buffer pool flushing.
Mixed
Balanced deltas. Tune both memory and concurrency settings and avoid single-metric decisions.
Key Takeaway

Compare deltas of DML counters to classify workload type and cross-check with lock, I/O, and thread metrics for full context.
