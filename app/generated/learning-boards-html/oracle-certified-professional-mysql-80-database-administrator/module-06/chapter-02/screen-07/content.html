Module 6 › Chapter 6.2 › Threads
What they reveal
Threads_connected shows open connections. Threads_running shows active, non-sleeping threads. Together they show whether connection pressure is due to many idle sessions or many active workers.
Example
If Threads_connected ≈ max_connections and clients cannot connect, consider pooling or safely increasing max_connections after verifying memory.
Warning
Increasing max_connections without memory headroom risks instability because each connection consumes buffers.
Diagnostic cards
Idle-heavy
Many connected but few running. Look for connection pooling issues or idle clients holding resources.
Active-heavy
Many running threads. Investigate long-running queries, lock waits, and I/O waits.
Key Takeaway

Use both counters to choose a safe remediation: connection pooling and code fixes for idle churn; query tuning or hardware for many active threads.
