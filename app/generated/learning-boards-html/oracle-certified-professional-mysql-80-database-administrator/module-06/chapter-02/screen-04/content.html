Module 6 › Chapter 6.2 › Global vs Session
Definition
Global: server-wide counters and defaults since startup. Session: connection-specific settings and statistics.
Example
SHOW GLOBAL STATUS shows aggregate counts, whereas SHOW SESSION STATUS limits output to your client.
Misconception
SET GLOBAL always persisting is false; SET GLOBAL changes the running instance but does not update my.cnf.
Pro tip
Test changes with a session variable or a controlled client before altering global defaults.
Practical checklist
  • 1. Identify the metric or variable and its scope.
  • 2. If testing, change only session scope or use an isolated client.
  • 3. Observe for a representative interval and collect SHOW GLOBAL STATUS for baselines.
  • 4. If validated, change globally and update my.cnf for persistence.
Key Takeaway

Scope determines impact. Choose session tests for safety, global changes for system-wide tuning, and my.cnf to keep them across restarts.
