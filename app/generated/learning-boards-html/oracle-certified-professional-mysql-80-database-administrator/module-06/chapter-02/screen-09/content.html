Module 6 › Chapter 6.2 › InnoDB Counters
I/O counters
Innodb_data_reads and Innodb_data_writes measure physical reads and writes. High values mean disk activity and potential bottlenecks.
Row activity
Innodb_rows_read, _inserted, _updated, _deleted show DML volume and help connect user queries to storage activity.
Locking
Innodb_row_lock_waits and Innodb_row_lock_time_avg expose contention for row-level locks under concurrent writes.
Diagnosis pattern
1. If physical reads are high, check buffer pool hit ratio and query plans. 2. If row lock waits increase, inspect write-heavy queries and transaction boundaries. 3. Correlate with Com_* counters and Threads_running.
Misconception
Assuming high I/O always means small buffer pool; sometimes inefficient queries or missing indexes cause reads.
Key Takeaway

Use InnoDB counters with query analysis to determine whether tuning memory, queries, or schema will reduce disk I/O and contention.
