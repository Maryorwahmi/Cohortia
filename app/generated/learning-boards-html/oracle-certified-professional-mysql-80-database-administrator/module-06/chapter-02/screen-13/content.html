Module 6 › Chapter 6.2 › Activity
Step-by-step
  1. 1. In client A: SHOW GLOBAL STATUS LIKE 'Innodb_buffer_pool_read%'; record values.
  2. 2. In client B: run representative SELECT queries multiple times to exercise the working set.
  3. 3. Back in client A: re-run SHOW GLOBAL STATUS LIKE 'Innodb_buffer_pool_read%'; record values.
  4. 4. Compute deltas and apply Hit Ratio = (1 - reads/read_requests) * 100.
Example template
-- baseline
SHOW GLOBAL STATUS LIKE 'Innodb_buffer_pool_read%';
-- run workload in another client
-- measurement
SHOW GLOBAL STATUS LIKE 'Innodb_buffer_pool_read%';
-- compute deltas and hit ratio
Pitfall
Using a single quick query that hits cached pages will hide the need for more cache.
Takeaway
Test with realistic patterns, compute deltas, and use the hit ratio to guide safe tuning of innodb_buffer_pool_size.
