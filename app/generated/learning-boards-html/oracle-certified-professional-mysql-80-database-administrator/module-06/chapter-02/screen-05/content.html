Module 6 › Chapter 6.2 › SHOW GLOBAL STATUS
Workflow
  1. 1. Run SHOW GLOBAL STATUS and save counters as a baseline.
  2. 2. Execute representative workload or test queries.
  3. 3. Run SHOW GLOBAL STATUS again and compute deltas.
  4. 4. Interpret deltas for read/write balance, connection pressure, and InnoDB I/O.
Key counters
Com_select, Com_insert, Com_update, Com_delete, Threads_connected, Threads_running
InnoDB counters
Innodb_buffer_pool_read_requests, Innodb_buffer_pool_reads, Innodb_row_lock_waits
Concrete example
Baseline: Com_select = 1000. After test: Com_select = 5000. Delta = 4000 selects in the test window. If Innodb_buffer_pool_reads rose sharply, you likely forced physical reads.
Common mistake
Interpreting a single cumulative snapshot without comparing before and after values leads to wrong conclusions.
Key Takeaway

Counters are cumulative. Use deltas over a controlled window to infer actual activity and troubleshoot effectively.
