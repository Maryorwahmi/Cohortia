Question

Which composite index is best?

Query: SELECT product_name, price FROM products WHERE category_id = 5 AND manufacturer_id = 10 ORDER BY price ASC;
Best answer
CREATE INDEX idx_cat_man_price ON products (category_id, manufacturer_id, price); — this order supports filtering on category_id and manufacturer_id and then sorting by price.
Why not the others?
An index starting with price does not help filtering by category and manufacturer; an index ordering columns wrongly fails to support both filtering and ORDER BY efficiently.
Practice steps
  1. Create the suggested index.
  2. Run EXPLAIN and confirm the index is used and filesort is removed.
  3. Optionally extend the index to include product_name to make it covering, then re-check EXPLAIN for Using index.
Key Takeaway
Design composite indexes to satisfy both filters and sort order; validate with EXPLAIN and measurements.
