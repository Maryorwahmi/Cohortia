Module 6 › Chapter 6.4 › EXPLAIN Diagnostics
EXPLAIN indicators
  • type shows join method and scan type; lower is typically better.
  • key shows which index is chosen for the query.
  • Extra shows notes like Using filesort or Using index.
Strategy to remove filesort
Create a composite index whose left-to-right columns match WHERE and ORDER BY. Re-run EXPLAIN to confirm filesort disappears.
Example EXPLAIN
-- Before index: EXPLAIN shows Using filesort
EXPLAIN SELECT * FROM sales_orders WHERE customer_id = 101 ORDER BY order_date DESC;

-- After: composite index created
CREATE INDEX idx_cust_date ON sales_orders (customer_id, order_date DESC);
EXPLAIN SELECT * FROM sales_orders WHERE customer_id = 101 ORDER BY order_date DESC; -- filesort removed
Key Takeaway
EXPLAIN helps diagnose why a query is slow. Use it with index design changes and verify with timing measurements.
