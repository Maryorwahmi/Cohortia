Module 6 › Chapter 6.4 › Covering Indexes
Definition

Covering indexes: avoid table access

A covering index includes every column needed by a query so the engine can return results from the index leaves alone.

Example
Query: SELECT product_name, price FROM products WHERE category_id = 5. Index: (category_id, product_name, price). EXPLAIN shows Extra: Using index.
When to use
Apply covering indexes selectively to high-traffic queries that benefit from avoiding table reads.
Warning
Avoid adding all columns to many indexes in an attempt to make everything covering. This creates large indexes, increases write cost, and consumes space. Instead, measure and add covering indexes only for critical queries.
Key Takeaway
Covering indexes can dramatically reduce I/O for targeted queries. Use them judiciously.
