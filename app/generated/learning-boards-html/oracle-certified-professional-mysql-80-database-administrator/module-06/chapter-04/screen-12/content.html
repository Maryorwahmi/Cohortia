Setup & SQL Template

Create table and sample data

CREATE TABLE sales_orders (
  order_id INT AUTO_INCREMENT PRIMARY KEY,
  customer_id INT NOT NULL,
  order_date DATE NOT NULL,
  total_amount DECIMAL(10,2) NOT NULL,
  status VARCHAR(20) DEFAULT 'pending',
  shipping_address VARCHAR(255),
  INDEX (customer_id)
);

Index steps

Create composite and covering indexes

-- Composite index to avoid filesort
CREATE INDEX idx_cust_date ON sales_orders (customer_id, order_date DESC);

-- Covering index for order_date queries
CREATE INDEX idx_orderdate_cover ON sales_orders (order_date, order_id, total_amount);

-- Re-run EXPLAIN after each change
EXPLAIN SELECT * FROM sales_orders WHERE customer_id = 101 ORDER BY order_date DESC;
EXPLAIN SELECT order_id, total_amount FROM sales_orders WHERE order_date = '2023-01-15';
Key Takeaway
Create targeted composite and covering indexes, then validate with EXPLAIN and timing measurements.
