Composite Index
An index on multiple columns where order dictates usability by queries.
Covering Index
Contains all columns a query needs, enabling index-only scans.
Over-indexing
Too many or inefficient indexes that increase write cost and storage use.
Final takeaway

Balance index benefits against write cost and storage, design indexes to match query patterns, and validate with EXPLAIN and updated statistics.
