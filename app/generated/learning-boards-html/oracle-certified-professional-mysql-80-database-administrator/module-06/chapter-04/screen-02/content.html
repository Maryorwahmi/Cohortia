Learning Objectives

Learn, understand, apply, and measure indexing decisions in MySQL.

Bloom: Learn → Understand → Apply → Master
01
Explain indexes and B-tree behavior
Describe how a B-tree stores sorted keys and pointers and why that matters for equality, range and ORDER BY queries.
VERIFIED COMPETENCY MILESTONE
02
Differentiate MySQL index types
Identify where primary, unique, non-unique, full-text, and spatial indexes are appropriate for your data and queries.
VERIFIED COMPETENCY MILESTONE
03
Choose index candidates using cardinality
Use query patterns and column cardinality to prioritize indexes that actually reduce row access costs.
VERIFIED COMPETENCY MILESTONE
04
Design composite indexes correctly
Apply the left-to-right rule so indexes serve filters and ORDER BY clauses, and recognize when to create covering indexes.
VERIFIED COMPETENCY MILESTONE
