Comparison

Over-indexing vs Correct Indexing

Over-indexing
Many indexes increase write cost and consume space; they reduce buffer pool efficiency.
Correct indexing
A small set of well-designed indexes targeted at frequent queries gives the best trade-off between read speed and write cost.
Common mistakes
  • Indexing low-cardinality columns alone.
  • Wrong column order in composite indexes.
  • Using functions on columns in WHERE clauses, preventing index use.
  • Adding indexes without EXPLAIN validation and timing tests.
Operational tip
Alter and analyze indexes during maintenance windows. Use ALGORITHM=INPLACE and LOCK=NONE when supported to reduce downtime.
