Learning Objectives — Continued

Practice index design and validate results safely.

Bloom: Apply → Master
01
Interpret EXPLAIN output
Read type, key, and Extra to determine whether queries use indexes or perform filesort or table access.
VERIFIED COMPETENCY MILESTONE
02
Create composite and covering indexes
Design indexes that eliminate filesort and let the optimizer use Using index when possible.
VERIFIED COMPETENCY MILESTONE
03
Avoid over-indexing
Understand write and storage costs and make index changes during safe windows or with non-blocking alter options.
VERIFIED COMPETENCY MILESTONE
04
Update index statistics
Run ANALYZE TABLE after large data changes so the optimizer chooses the best plans based on current statistics.
VERIFIED COMPETENCY MILESTONE
