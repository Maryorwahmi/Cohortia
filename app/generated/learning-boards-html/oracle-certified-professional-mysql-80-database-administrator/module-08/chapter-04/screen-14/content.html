Module 8 › Chapter 8.4 › Key Concepts
Error Log (log_error)
Primary source for server errors, warnings, and diagnostic messages.
Slow Query Log
Records queries above long_query_time for performance analysis.
EXPLAIN / EXPLAIN ANALYZE
Reveal execution plans and guide index and query optimization choices.
Summary takeaway
When incidents occur, collect logs first, run targeted diagnostics like SHOW PROCESSLIST and SHOW ENGINE INNODB STATUS, apply safe temporary mitigations, then implement and test permanent fixes with backups and staging verification.
