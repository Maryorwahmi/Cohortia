Module 8 › Chapter 8.4 › Slow Query Log
Enable slow query logging
# my.cnf
slow_query_log = 1
long_query_time = 1
slow_query_log_file = /var/log/mysql/mysql-slow.log
After enabling, use mysqldumpslow or pt-query-digest to summarize and rank queries by frequency or time.
Concrete example
A query searching users by email without an index shows up repeatedly. The slow log shows the execution time and query text, which you then EXPLAIN to determine a full table scan.
Key Takeaway

Use the slow query log to find recurring cost-heavy queries and prioritize fixes with EXPLAIN and indexing.
