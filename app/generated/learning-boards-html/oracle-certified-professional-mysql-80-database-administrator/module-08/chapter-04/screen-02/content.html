01
Systematic troubleshooting
Practice gathering symptoms, checking recent changes, and collecting logs to form hypotheses and test them.
Verified competency milestone
02
Diagnose connection issues
Use service checks, telnet, SHOW PROCESSLIST, and status variables to find connectivity and pooling problems.
Verified competency milestone
03
Identify slow queries
Enable and parse the slow query log and run EXPLAIN to detect full table scans and missing indexes.
Verified competency milestone
04
Resolve deadlocks & disk issues
Use SHOW ENGINE INNODB STATUS for deadlocks and inspect binary logs and tablespaces when disk fills up.
Verified competency milestone
