Module 8 › Chapter 8.4 › Disk Space & Logs
Diagnostic commands
df -h
du -sh /var/lib/mysql/*
# Check binary log usage and files
ls -lh /var/lib/mysql/mysql-bin.*
Identify large tablespaces (.ibd), binary logs, or rotated logs consuming space and back them up before removal.
Safe purging
Purge binary logs with PURGE BINARY LOGS TO 'mysql-bin.000123'; after confirming backups and replication safety.
Concrete example
A server ran out of space due to accumulated binary logs. After backing up and purging old binary logs and restarting, writes resumed. Deleting files directly from the data directory was avoided to prevent corruption.
Key Takeaway

Back up first. Use MySQL commands to purge logs. Do not delete data files directly. Plan retention to prevent recurrence.
