Module 8 › Chapter 8.4 › Objectives — Sub-skills
Configure and capture logs
Set log_error and slow_query_log in my.cnf and know the file locations. Rotate and back up logs before purging.
Service & network checks
Verify mysqld status and network reachability. These steps confirm whether the server is down or inaccessible.
Process inspection
Use SHOW PROCESSLIST and sys.processlist to find idle connections, long-running queries, and candidates for KILL.
Disk recovery steps
Identify large binary logs and tablespaces, purge or expire logs after backups, and add space if necessary.
