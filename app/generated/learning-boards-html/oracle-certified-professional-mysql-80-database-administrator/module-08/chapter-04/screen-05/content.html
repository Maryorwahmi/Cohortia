Module 8 › Chapter 8.4 › Connection Errors
Definition & verification steps
  • Confirm mysqld is running using systemctl or service status commands.
  • Verify TCP reachability with telnet hostname port or a simple socket check.
  • Check error log for authentication or startup messages tied to the timestamp.
Example command checks
systemctl status mysqld
# or
service mysqld status

# Test network reachability
telnet db-host.example.com 3306
Concrete example
An application reports connection failures after a deploy. systemctl shows mysqld active, but telnet times out. The deploy changed firewall rules. Reopening the port restored connections. The error log showed no authentication failures, which helped rule out grants as the cause.
Pro tip
Check service and network reachability before making user or privilege changes. That reduces unnecessary permission edits.
Key Takeaway

Confirm server process and TCP connectivity first; then analyze logs and grants for authentication issues.
