Module 8 › Chapter 8.4 › EXPLAIN & Indexes
EXPLAIN example
EXPLAIN SELECT * FROM users WHERE email = 'user50000@example.com';
If the plan shows type = ALL and large rows, the query scans the whole table. Adding an index on email usually changes type to ref or const.
Index command
CREATE INDEX idx_email ON users (email);
Concrete result
After creating idx_email, EXPLAIN should show fewer estimated rows and a better type. Execution time for the query will drop and the slow log entry should disappear for that pattern.
Key Takeaway

Let EXPLAIN guide indexing. Confirm changes by re-running EXPLAIN and checking the slow query log for improvement.
