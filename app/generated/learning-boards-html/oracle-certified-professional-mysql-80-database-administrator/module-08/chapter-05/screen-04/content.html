Module 8 › Chapter 8.5 › What does a replication failure mean?
Definition

A replication failure happens when the slave stops applying events from the master's binary log. The slave's I/O thread or SQL thread reports an error and halts progress.

Common causes
  • SQL errors applying an event (duplicate key, missing row)
  • Network connectivity loss for the I/O thread
  • Manual, unsynchronized changes on the slave causing divergence
Misconception
Seconds_Behind_Master is not always an error; it estimates lag but does not identify the failing thread or an error code.
Key Takeaway

Use SHOW SLAVE STATUS to locate which thread failed and read Last_SQL_Error or Last_IO_Error before taking action.

Analogy
Think of the master as a publisher and the slave as a subscriber. If the subscriber's network disconnects, it stops receiving updates. If the subscriber cannot apply an update because it conflicts with local data, it stops applying further updates.
Quick checklist
  • Run SHOW SLAVE STATUS\G
  • Confirm Slave_IO_Running and Slave_SQL_Running
  • Read Last_IO_Error and Last_SQL_Error for specifics
Example
SHOW SLAVE STATUS\G
-- look for: Slave_IO_Running, Slave_SQL_Running, Last_SQL_Error, Exec_Master_Log_Pos
