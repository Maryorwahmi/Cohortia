Module 8 › Chapter 8.5 › Diagnosing I/O thread and network issues
Typical Last_IO_Error messages
  • "Lost connection to MySQL server during query"
  • "Error connecting to master 'master_host:3306' (errno: 110 'Connection timed out')"
Diagnosis checklist
  1. Ensure master MySQL process is running.
  2. From slave, ping master and test TCP to port 3306.
  3. Check firewall and master max_connections or resource limits.
Resolution actions
If transient, try restarting I/O thread only:
STOP SLAVE IO_THREAD;
START SLAVE IO_THREAD;
SHOW SLAVE STATUS\G
When to escalate
If the slave repeatedly fails to connect, fix network/firewall or increase master's connection limits. Persisting failures may require coordinated maintenance windows.
Key Takeaway

Capture Last_IO_Error and act on the network or resource cause. Restarting the IO thread can recover from transient glitches.
