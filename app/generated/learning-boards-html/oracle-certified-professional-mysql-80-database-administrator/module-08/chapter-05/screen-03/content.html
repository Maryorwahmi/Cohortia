Practical tasks

Tasks emphasize safe commands and verification after each change.

Interpret status
Find Slave_IO_Running, Slave_SQL_Running, Last_SQL_Error and positions to pinpoint the failure.
Apply safe fixes
Execute STOP SLAVE; make changes; START SLAVE; then verify Slave_SQL_Running is Yes.
Network checks
Use ping and port checks to find connectivity issues referenced in Last_IO_Error.
Decision points
Decide between skipping events, re-pointing, or performing a full resync based on risk of divergence.
