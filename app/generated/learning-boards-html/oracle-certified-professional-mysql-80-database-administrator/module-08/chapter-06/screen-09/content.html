Module 08 › Chapter 8.6 › Error, Slow, and General Logs
Rotate logs
Use logrotate or similar to archive and compress logs and keep file sizes manageable.
• Rotate daily for busy servers or weekly for quieter systems.
• Compress older logs and keep a retention window aligned with troubleshooting needs.
• Avoid enabling general log in production; use it briefly for troubleshooting and then disable it.
Inspecting logs
Search for repeated errors, slow queries affecting the same tables, and signs of resource exhaustion.
Interpretation tips
  • • Multiple identical error entries usually indicate a systemic issue that needs configuration or code fixes.
  • • Slow query patterns linked to specific tables or joins suggest missing or ineffective indexes.
  • • Correlate log times with system metrics to find resource-related problems like spikes in I/O or memory.
Key Takeaway

Rotate logs and review them regularly. Automate rotation and keep a short archive so logs help troubleshooting without risking disk space.
