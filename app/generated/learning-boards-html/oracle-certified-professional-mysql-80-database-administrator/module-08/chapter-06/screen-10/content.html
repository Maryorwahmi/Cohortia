Module 08 › Chapter 8.6 › CHECK & REPAIR TABLE
Integrity commands
CHECK TABLE my_database.my_table;
REPAIR TABLE my_database.my_table;
• CHECK TABLE reports corruption or structural problems.
• REPAIR TABLE attempts to fix MyISAM tables; not recommended for InnoDB.
• For InnoDB corruption, prefer restore from backup and evaluate causes.
Practical guidance
Always take a backup before repair actions. If possible test repair flow on a copy in staging. If REPAIR succeeds, validate data integrity and run ANALYZE to refresh statistics.
Common misconception
Assuming REPAIR is safe for all storage engines. InnoDB requires different recovery approaches.
Key Takeaway

Use check and repair appropriately by engine. For InnoDB, rely on backups and crash recovery; for MyISAM use repair carefully with backups and tests.
