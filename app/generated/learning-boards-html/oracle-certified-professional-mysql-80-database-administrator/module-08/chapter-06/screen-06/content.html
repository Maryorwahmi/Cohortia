Module 08 › Chapter 8.6 › ANALYZE TABLE vs OPTIMIZE TABLE
ANALYZE TABLE
Collects index distribution statistics used by the optimizer.
ANALYZE TABLE my_database.my_table;
  • Fast and less intrusive than optimize.
  • Useful immediately after large imports, deletes, or updates.
  • Helps the optimizer choose better plans without rebuilding storage.
When to use
After major data changes that affect index selectivity.
OPTIMIZE TABLE
Rebuilds table to defragment and reclaim space.
OPTIMIZE TABLE my_database.my_table;
  • Resource intensive and may lock the table for its duration.
  • Reclaims disk space and compacts indexes after heavy deletes or updates.
  • Prefer running under maintenance windows or via online alternatives.
When to use
When physical fragmentation significantly affects storage and I/O and you can accept the cost.
Checklist before you run
Verify backups are current.
Check replication slaves for required binary logs.
Schedule during low-traffic windows.
