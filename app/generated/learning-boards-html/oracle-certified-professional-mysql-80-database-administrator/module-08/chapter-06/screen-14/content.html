Module 08 › Chapter 8.6 › Assessment & Common Pitfalls
Sample assessment questions
  • • Disk filling with many mysql-bin files: what config change and immediate command relieve it?
  • • After a large InnoDB import you see poor plans: which maintenance command helps immediately?
  • • Describe the verification steps before you purge binary logs in a replicated environment.
Common pitfalls
  • • Purging logs required by slaves without checking replication positions.
  • • Running OPTIMIZE during peak traffic without a maintenance window.
  • • Leaving general logging enabled in production for long periods.
Pro tip

Require learners to submit command outputs and notes on safety checks as evidence of competency, not just command names.
