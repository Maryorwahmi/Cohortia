Module 08 › Chapter 8.6 › What is Routine Maintenance?
Definition & planning
Regular operations to preserve performance, integrity, and security.
  • Define a cadence: daily checks, weekly refreshes, monthly reclamation.
  • Assign ownership and verification steps to prevent drift.
  • Balance impact: avoid running heavy tasks during peak traffic.
  • Automate repeatable tasks and keep critical decisions manual with review.
Analogy
Like scheduled car service: small, routine checks prevent big failures.
Common mistake
Running expensive operations without maintenance windows or backups.
Recommended cadence example
Daily
Rotate logs, check disk usage, review error log entries and slow query summaries.
Weekly
Run ANALYZE TABLE after imports or large modifications to refresh optimizer statistics.
Monthly
Consider OPTIMIZE TABLE on heavily fragmented tables during maintenance windows; review user privileges.
Key Takeaway
Key Takeaway

Schedule tasks by impact and duration. Automate safe tasks and reserve heavy operations for maintenance windows.
