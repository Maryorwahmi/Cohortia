Module 08 › Chapter 8.6 › Log File Management
Log types
Binary Log (log_bin)
Used for replication and point-in-time recovery. Can grow large and must be purged carefully.
Error Log (log_error)
Contains server messages and errors. Rotate regularly and inspect for recurring issues.
Slow Query Log
Helps identify inefficient queries and should be rotated to avoid disk bloat.
General Query Log
High overhead; rarely enabled in production. If enabled, rotate strictly.
Retention pattern
Decide retention based on replication and recovery needs. Configure automatic expiry for binary logs and use system rotation for other logs.
Checklist before purge
  • • Confirm no slave requires the logs you intend to remove.
  • • Verify backups and point-in-time recovery windows.
  • • Automate retention rules to avoid manual mistakes.
Quick config
Set binary log expiry in my.cnf for automatic purging.
# my.cnf example
expire_logs_days = 7
Common mistake
Purging binary logs without checking slave replication positions; always verify slave status first.
Key Takeaway

Adopt retention policies that match your recovery needs and automate them so logs never silently exhaust disk space.
