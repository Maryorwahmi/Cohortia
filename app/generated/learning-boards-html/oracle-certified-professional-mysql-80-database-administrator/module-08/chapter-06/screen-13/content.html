Module 08 › Chapter 8.6 › Activity: Log Management and Table Analysis
Step-by-step terminal demo
1) Configure expiry
# my.cnf: set in [mysqld]
expire_logs_days = 3
# Restart MySQL then verify
SHOW VARIABLES LIKE 'expire_logs_days';
2) Generate logs and inspect
USE test_db;
INSERT INTO products (id, name) VALUES (3, 'Monitor');
UPDATE products SET name = 'Gaming Monitor' WHERE id = 3;
DELETE FROM products WHERE id = 1;
SHOW BINARY LOGS;
3) Simulate purge
-- Verify slaves before running
-- Then run a purge (simulated)
PURGE BINARY LOGS TO 'mysql-bin.000001';
SHOW BINARY LOGS;
4) Analyze and optimize
ANALYZE TABLE troubleshooting_db.users;
OPTIMIZE TABLE troubleshooting_db.users;
Key Takeaway

Practice the verification steps first. Observe outputs and measure impact before automating or scheduling the operation in production.
