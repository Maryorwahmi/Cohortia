Module 08 › Chapter 8.3 › Common mistakes
Mistake 1 — Missing instruments

If Performance Schema instruments are disabled, sys views will return empty or partial results. Always verify instrumentation before relying on sys output.

Mistake 2 — Misreading latency

High time may indicate waits, not CPU. Correlate state and other metrics before taking action like killing threads.

Mistake 3 — Over-tuning history

Increasing history size can help post-mortem but may increase memory usage. Test and monitor before applying widely.

Mistake 4 — Stopping at sys

If sys aggregates hide important detail, drill into Performance Schema raw tables for per-event information.

Quick troubleshooting checklist
  1. Confirm Performance Schema instruments are enabled.
  2. Run relevant sys views for a quick triage.
  3. Correlate results with EXPLAIN and raw Performance Schema when needed.
  4. Document and test any sys variable changes in staging.
