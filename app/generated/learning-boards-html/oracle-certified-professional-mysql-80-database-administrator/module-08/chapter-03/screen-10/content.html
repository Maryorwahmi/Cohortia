Module 08 › Chapter 8.3 › Configuring sys
Common variables
ps_setup_size_statements_history — controls how much statement history is retained
ps_thread_account_for_background_threads — include background threads in some aggregations
Change pattern
  1. Plan and document desired setting changes.
  2. Test in a staging environment with similar load.
  3. Monitor Performance Schema overhead and memory.
  4. Apply to production during a maintenance window if safe.
Example command
-- Increase statement history size SET GLOBAL sys.ps_setup_size_statements_history = 10000;
After this change, sys views that rely on statement history will have more retained entries. Monitor memory use closely.
Common mistake

Changing history size without enabling the required Performance Schema instruments yields no extra data but may consume memory when instruments are active.
