Memory query
SELECT
    event_name,
    current_alloc_bytes / 1024 / 1024 AS current_alloc_mb,
    high_alloc_bytes / 1024 / 1024 AS high_alloc_mb
FROM
    sys.memory_global_by_current_bytes
ORDER BY
    current_alloc_bytes DESC
LIMIT 10;
How to use
  • Spot the largest current allocators to guide tuning.
  • Compare high_alloc to current_alloc for burst behavior.
  • Correlate with workload patterns and configuration settings.
Example interpretation
A component with high_alloc_mb 1024 but current_alloc_mb 128 indicates occasional peaks. If current_alloc_mb stays high across sampling windows, that may justify raising memory limits or changing buffer sizes.
-- Practical steps 1. Run the memory query during normal and peak times 2. Identify components with sustained high current_alloc 3. Tune related configuration or reduce workload intensity 4. Re-run and verify reductions
Misconception

These allocations reflect tracked internal allocations in Performance Schema, not the entire process RSS. Always cross-check with OS tools for total memory usage.
