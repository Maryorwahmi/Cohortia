Module 08 › Chapter 8.3 › What is the sys schema?
Formal definition

A collection of views, functions, and procedures built on Performance Schema to present aggregated, human-readable performance metrics.

Analogy

Performance Schema is raw instrumentation; sys provides report templates that summarize and format that instrumentation for quick answers.

When to use sys
  • Daily checks for slow queries and active sessions.
  • Quick I/O and memory hotspot identification.
  • Initial triage before deeper Performance Schema analysis.
Example
-- Find top statements by average latency
SELECT
  query,
  db,
  full_scan,
  exec_count,
  total_latency,
  avg_latency,
  max_latency
FROM
  sys.statements_with_runtimes_in_host
ORDER BY
  avg_latency DESC
LIMIT 10;
This view already exposes avg_latency and exec_count so you can rank problem statements without manual joins.
Misconception

Do not assume sys creates additional instrumentation. If Performance Schema instruments are disabled, sys views return empty or incomplete results.

Key Takeaway

Use sys for fast, high-level diagnostics. Drop into Performance Schema for the most granular investigation.
