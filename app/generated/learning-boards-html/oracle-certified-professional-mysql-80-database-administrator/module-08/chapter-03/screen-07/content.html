Full-table scan query
SELECT
  query,
  db,
  exec_count,
  full_scan_count,
  total_latency,
  avg_latency
FROM
  sys.statements_with_full_table_scans
ORDER BY
  full_scan_count DESC
LIMIT 5;
When to use

Run this when you suspect missing indexes or queries scanning large tables frequently, especially during load spikes.

Errors or warnings query
SELECT
  query,
  db,
  count_star AS occurrences,
  last_error
FROM
  sys.statements_with_errors_or_warnings
ORDER BY
  occurrences DESC
LIMIT 10;
Misconception

These views show what was recorded. If Performance Schema filters or instruments are off, statements may be missing from these summaries.

Example action

For a query with high full_scan_count, run EXPLAIN, add indexes, or rewrite the query, then re-check the sys view for improvement.
