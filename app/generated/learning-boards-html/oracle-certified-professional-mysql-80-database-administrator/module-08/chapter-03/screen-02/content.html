01
Explain sys purpose

Describe how sys aggregates and formats Performance Schema data and why that reduces query complexity for DBAs.

VERIFIED COMPETENCY MILESTONE
02
Identify key views

Recognize processlist, statements_with_runtimes_in_host, io and memory views used frequently for monitoring tasks.

VERIFIED COMPETENCY MILESTONE
03
Analyze sessions & I/O

Use the views to spot long-running statements, file-level I/O hot spots, and potential disk bottlenecks.

VERIFIED COMPETENCY MILESTONE
04
Find slow statements

Query runtime views to rank queries by avg_latency, and use full-table-scan reports to prioritize tuning.

VERIFIED COMPETENCY MILESTONE
Quick mnemonic
Think: Observe → Rank → Investigate → Configure. Observe active sessions, rank slow statements, investigate I/O and memory, then configure sys variables as needed.
Assessment hint

The most useful quick check for connection timeouts is sys.processlist; prioritize conn_id, user, state, and time.
