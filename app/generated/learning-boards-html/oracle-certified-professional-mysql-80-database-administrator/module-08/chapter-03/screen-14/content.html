Module 08 › Chapter 8.3 › Key Concepts
sys schema
A collection of views and helpers that present Performance Schema data in readable, aggregated form.
Key views
processlist, statements_with_runtimes_in_host, io_global_by_file_by_latency, memory_global_by_current_bytes are the most-used for triage.
Triage vs deep dive
Use sys for quick diagnostics. If you need event-level detail, query Performance Schema raw tables directly.
Takeaway
sys speeds diagnosis by presenting ready-to-query summaries, but it depends on Performance Schema instrumentation and has limits when granular event tracing is required.
