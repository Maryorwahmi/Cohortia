Learning Objectives

Master targeted troubleshooting skills and practical monitoring habits.

Bloom: Learn → Understand → Apply → Master
01
Advanced Performance Schema Queries
Combine event tables and sys views to isolate I/O and lock hot spots.

You will learn to join Performance Schema tables and use sys schema views like io_by_thread_by_latency to find users or hosts causing high latency. This skill matters because it reveals the exact thread or query that drives resource usage.

VERIFIED COMPETENCY MILESTONE
02
EXPLAIN ANALYZE Proficiency
Interpret actual execution timing to prioritize optimizations.

You will practice running EXPLAIN ANALYZE and reading actual time and row counts to find where a query spends most of its time. This prevents chasing low-impact changes.

VERIFIED COMPETENCY MILESTONE
03
OS-Level Diagnostics
Use iostat, vmstat, strace, and tcpdump to correlate host signals with MySQL behavior.

You will practice running iostat and vmstat while executing heavy queries to observe disk and memory pressure. You will also learn safe uses of strace with strong caution for production servers.

VERIFIED COMPETENCY MILESTONE
04
Proactive Monitoring & Baselines
Establish baselines, alerts, and trend analysis to prevent regressions.

You will design baseline metrics and alert thresholds so that deviations are detected early. The skill reduces firefighting and supports capacity planning.

VERIFIED COMPETENCY MILESTONE
