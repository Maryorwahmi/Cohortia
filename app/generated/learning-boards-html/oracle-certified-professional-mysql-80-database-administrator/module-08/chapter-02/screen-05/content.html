Definition
Instruments and Events
Instruments are points in server code where event data can be recorded. Events represent the runtime occurrence, such as statement execution or waiting for I/O.
Statement Events
Record SQL text, timer_wait, lock_time, rows sent, and context.
Wait Events
Capture waits for locks, file I/O, or network; helpful to find non-CPU bottlenecks.
Stage Events
Mark phases such as parsing, executing, or committing within a statement lifecycle.
Consumers
Where data lands
Consumers control which tables receive records: events_statements_current, events_statements_history, events_waits_history, and long history tables. Enable only what you need.
Key Takeaway

Instruments + Consumers = the data you can capture. Configure both carefully to capture the right events at minimal cost.
