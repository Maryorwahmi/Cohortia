Module 8 › Chapter 8.2 › Key Concepts — Additional
events_statements_history
Stores recent statement events including sql_text, timer_wait, and lock_time for analysis.
events_waits_history
Captures wait events for locks and I/O that reveal blocked or stalled activity.
setup_instruments / setup_consumers
Configuration tables used to enable or disable specific instruments and consumers, and to set TIMED values.
Final Takeaway
Use focused instrumentation, then query and interpret the event tables to drive targeted tuning actions. Export results for long-term trending when needed.
