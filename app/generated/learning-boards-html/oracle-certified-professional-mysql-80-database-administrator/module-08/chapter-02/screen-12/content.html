Best Practice
Minimize Monitoring Overhead
Targeted Enablement
Enable only the instruments and consumers you need for a specific investigation.
Test in Staging
Measure memory and CPU impact before enabling broad instrumentation in production.
Persist Carefully
Store only necessary settings in my.cnf for restarts; otherwise use on-demand enablement.
Warning

Enabling all instruments and consumers indiscriminately can lead to increased overhead and larger runtime state. Be surgical and measure impact.
