Process Flow
Enable, Capture, Analyze, Disable
1. Identify symptom
Decide if you need statements, waits, or other instrumentation.
2. Map to instruments
Use patterns like 'statement/%' or 'wait/io/file/%'.
3. Enable TIMED and ENABLED
Update setup_instruments with TIMED='YES' to capture durations.
4. Enable consumers
Enable events_statements_history or events_waits_history as needed.
Configuration examples
UPDATE performance_schema.setup_instruments
SET ENABLED = 'YES', TIMED = 'YES'
WHERE NAME LIKE 'statement/%';

UPDATE performance_schema.setup_consumers
SET ENABLED = 'YES'
WHERE NAME = 'events_statements_history';

-- When finished, disable to reduce overhead
UPDATE performance_schema.setup_instruments
SET ENABLED = 'NO'
WHERE NAME LIKE 'statement/%';
Common Mistake

Leaving broad instrumentation enabled in production can add measurable overhead; enable on-demand and disable after analysis.
