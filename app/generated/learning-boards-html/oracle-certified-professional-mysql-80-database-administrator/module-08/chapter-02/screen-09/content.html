Inspect wait events
UPDATE performance_schema.setup_instruments
SET ENABLED = 'YES', TIMED = 'YES'
WHERE NAME LIKE 'wait/%';

UPDATE performance_schema.setup_consumers
SET ENABLED = 'YES'
WHERE NAME = 'events_waits_history';

SELECT
  event_id,
  event_name,
  object_schema,
  object_name,
  index_name,
  operation,
  timer_wait / 1000000000 AS duration_ms
FROM
  performance_schema.events_waits_history
WHERE
  event_name LIKE 'wait/io/file/%' OR event_name LIKE 'wait/lock/%'
ORDER BY
  timer_wait DESC
LIMIT 10;
I/O Waits
Look for repeated large duration_ms on file I/O operations; this points to disk or query design problems.
Lock Waits
Identify the locking object and consider shorter transactions, row-level locks, or resolving DDL timing.
Key Takeaway

Differentiate I/O and lock waits and act accordingly: improve storage, change queries, or reduce transaction scope depending on the root cause.
