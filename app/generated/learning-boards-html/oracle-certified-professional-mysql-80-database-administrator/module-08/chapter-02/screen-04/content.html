Core Concept
SHOW STATUS
Aggregated counters describing totals and rates across the server lifecycle.
Strengths
  • Lightweight snapshot of counters and rates
  • Good for ongoing health checks and dashboards
Limitations
Does not record individual event timing or SQL text, so root causes can be hidden.
Common Mistake
Relying on aggregated counters alone when you need to know which statements or waits caused a spike.
Core Concept
Performance Schema
Event-driven instrumentation that records individual statements, waits, and timing with context.
Strengths
  • Records SQL text, timer_wait, lock_time, schema, user, and host
  • Enables targeted diagnosis and precise tuning actions
Use Pattern
Detect an anomaly with SHOW STATUS, then enable specific instruments and consumers to capture related events for a short time window.
Key Takeaway

Combine both: use aggregated counters to spot issues and Performance Schema to investigate root cause with precise event data.
