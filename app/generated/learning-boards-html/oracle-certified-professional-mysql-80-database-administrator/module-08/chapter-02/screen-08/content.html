Code Walkthrough
Find slow statements
SELECT
  event_id,
  event_name,
  sql_text,
  timer_wait / 1000000000 AS duration_ms,
  lock_time / 1000000000 AS lock_ms,
  rows_affected,
  rows_sent,
  current_schema
FROM
  performance_schema.events_statements_history
ORDER BY
  timer_wait DESC
LIMIT 10;
What to look for
High duration_ms, significant lock_ms, and SQL text matching your suspect queries.
Misconception
Timer_wait is not always the total transaction time; inspect stages and waits to see where time was spent.
Key Takeaway

Convert timer_wait, inspect lock_time and SQL text, and map results to remediation steps such as adding an index or fixing a join.
