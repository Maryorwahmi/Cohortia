Using Performance Schema for Detailed Monitoring
Collect event-level timing for statements and waits to identify root causes of slow queries and contention.
Performance Schema instruments server internals and stores events in consumers. You will selectively enable instruments and consumers, query event tables, and interpret timer_wait and lock metrics to focus tuning efforts where they matter most.
Instruments
Points in server code that record events such as statement or wait events.
Consumers
Where the collected events are stored: history, current, or long history tables.
Key Tables
events_statements_history, events_waits_history and related tables you will query.
Interactive 16:9 Masterclass
Enable instruments
UPDATE performance_schema.setup_instruments SET ENABLED='YES', TIMED='YES' WHERE NAME LIKE 'statement/%';
Capture statements
UPDATE performance_schema.setup_consumers SET ENABLED='YES' WHERE NAME='events_statements_history';
Inspect waits
Query events_waits_history for lock and IO waits.
