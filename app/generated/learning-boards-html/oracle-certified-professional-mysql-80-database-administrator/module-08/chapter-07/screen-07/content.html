Definition my.cnf review
Checklist for my.cnf
  • Back up the current my.cnf file before edits.
  • Search release notes for removed system variables.
  • Comment out options flagged as removed, such as query_cache settings.
  • Test server startup in staging and inspect the error log for unknown-variable errors.
Examples & hints
Example: query_cache_size and query_cache_type are removed in 8.0 and should be removed from my.cnf.
Authentication: note differences in default authentication plugins and test client logins.
Common mistake
Assuming the old config will be accepted unchanged. The server may fail on startup if it encounters removed options.
