Key Concepts Quick Reference
Backups first
Logical dumps and physical snapshots provide complementary recovery paths.
Run checks and finalize
Use mysqlcheck --check-upgrade and run mysql_upgrade after startup to update system tables.
Replication order
Upgrade slaves first, then the master, to preserve fallback and continuity.
Final thought

Keep a clear pre-upgrade checklist and a tested rollback plan. Upgrades succeed when preparation is thorough.
