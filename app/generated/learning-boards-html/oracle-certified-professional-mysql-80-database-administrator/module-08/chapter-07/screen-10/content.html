Definition mysql_upgrade purpose
What mysql_upgrade does
  • Checks all tables for incompatibilities and attempts repairs.
  • Updates system tables in the mysql schema to the new server format.
  • Helps resolve warnings about table definitions reported in the error log.
Example command
mysql_upgrade -u root -p
# Then restart the server
systemctl restart mysqld
Running the utility and restarting ensures system tables and table metadata are fully compatible with 8.0 behavior.
Key Takeaway

mysql_upgrade is not optional. It finalizes upgrades by checking, repairing, and updating tables to the expected format for MySQL 8.0.
