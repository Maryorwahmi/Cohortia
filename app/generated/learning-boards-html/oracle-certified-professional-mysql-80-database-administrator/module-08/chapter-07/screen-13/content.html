Hands-on Activity Simulate Pre-Upgrade Checks
Activity steps
  1. Run the mysqldump command to create a full backup file.
  2. Run mysqlcheck --all-databases --check-upgrade and capture the output.
  3. Review my.cnf for deprecated options and comment them out in staging.
  4. Document at least two parameters needing attention and how to fix them.
Starter commands
mysqldump --all-databases --single-transaction --routines --triggers --events > full_backup_5_7.sql -u root -p
mysqlcheck --all-databases --check-upgrade -u root -p
# Inspect /etc/my.cnf or /etc/mysql/my.cnf for deprecated settings
Treat this as a dry run for production; the goal is to find and fix issues in staging before performing the real upgrade.
