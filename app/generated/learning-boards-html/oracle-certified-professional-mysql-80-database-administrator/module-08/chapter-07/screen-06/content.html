Definition mysqlcheck --check-upgrade
Command to run
# On the old server (for example 5.7)
mysqlcheck --all-databases --check-upgrade -u root -p
Authenticate as a privileged user and carefully read warnings about deprecated features or table definitions that require attention.
Interpreting output
  • Deprecated options: note any my.cnf settings that will be removed in 8.0.
  • Table warnings: fix incompatible column types or indexes before upgrade.
  • Character set issues: address mismatches that could corrupt data on import.
Pro tip
Run mysqlcheck early in staging so you can iterate on fixes and re-run checks until the output shows no blocking warnings.
