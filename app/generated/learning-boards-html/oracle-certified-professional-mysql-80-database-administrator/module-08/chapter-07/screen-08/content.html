Process Flow In-place upgrade steps
Step-by-step
  1. If replication: STOP SLAVE on each slave; on master FLUSH TABLES WITH READ LOCK and SHOW MASTER STATUS to record position.
  2. Stop MySQL: systemctl stop mysqld (or distro equivalent).
  3. Install new binaries: use apt-get or yum to install mysql-server-8.0 packages.
  4. Start server: systemctl start mysqld; watch the error log for data dictionary migration messages.
  5. Run mysql_upgrade: mysql_upgrade -u root -p to check/repair tables and update system tables.
  6. Restart server: systemctl restart mysqld and re-check logs and status.
  7. Replication: start slaves and monitor SHOW SLAVE STATUS for replication health.
Command examples
# On master
FLUSH TABLES WITH READ LOCK;
SHOW MASTER STATUS;
# On slaves
STOP SLAVE;
# Stop server
systemctl stop mysqld
# Install packages (example)
apt-get install mysql-server-8.0
# Start and finalize
systemctl start mysqld
mysql_upgrade -u root -p
systemctl restart mysqld
Always check the error log immediately after starting the new server; it contains critical migration messages.
