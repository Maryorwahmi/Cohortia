Starter health-check commands
Terminal-style command examples and expected intent
Commands to run
SHOW GLOBAL STATUS LIKE 'Uptime';
SHOW GLOBAL STATUS LIKE 'Threads_connected';
SHOW GLOBAL STATUS LIKE 'Threads_running';
SHOW GLOBAL STATUS LIKE 'Questions';
SHOW GLOBAL STATUS LIKE 'Bytes_received';
SHOW GLOBAL STATUS LIKE 'Bytes_sent';
SHOW GLOBAL STATUS LIKE 'Innodb_buffer_pool_reads';
SHOW GLOBAL STATUS LIKE 'Innodb_buffer_pool_read_requests';
SHOW ENGINE INNODB STATUS\G
What each command tells you
  • Uptime: how long the server has run—important because counters start at server start.
  • Threads_connected and Threads_running: connection counts and active execution.
  • Questions: total statements executed, useful for workload estimates.
  • Bytes_received/sent: network I/O volume between clients and server.
Example interpretation
If Innodb_buffer_pool_read_requests jumps but Innodb_buffer_pool_reads also increases proportionally, many reads hit disk. That suggests increasing the buffer pool or tuning queries.
Pro tip
Use SHOW ENGINE INNODB STATUS\G with the vertical format for easier reading. Look for TRANSACTIONS and SEMAPHORES sections first when troubleshooting locks and contention.
Key Takeaway

Practice a short command set, collect two snapshots, and compute deltas. That workflow gives reliable, actionable insight without sophisticated tooling.
