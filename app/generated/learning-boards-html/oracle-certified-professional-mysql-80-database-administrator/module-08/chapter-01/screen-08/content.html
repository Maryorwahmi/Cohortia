Module 8 › Chapter 8.1 › Key status variables to watch
Status variable watchlist
A compact set of counters that reveal workload and resource behavior.
Threads_connected / Threads_running
Use to spot many idle connections versus active queries. High connected with low running often means connection pooling issues.
Questions
Total statements executed. Sample over time to determine queries per second and workload spikes.
Bytes_received / Bytes_sent
Network I/O volume. Use to detect heavy data transfer or unexpected traffic patterns.
InnoDB row counters
Innodb_rows_read/inserted/updated/deleted show how many rows InnoDB processes and help identify heavy scans or writes.
Concrete example
If Questions rises while Innodb_rows_read rises faster than expected, you may have inefficient queries that read many rows per statement. Investigate slow query logs or explain plans next.
Misconception
Assuming high Connections equals high load. Many open connections can be idle; check Threads_running to understand active execution.
Key Takeaway

Combine counters—threads, questions, bytes, and InnoDB rows—to triangulate workload characteristics before changing configuration.
