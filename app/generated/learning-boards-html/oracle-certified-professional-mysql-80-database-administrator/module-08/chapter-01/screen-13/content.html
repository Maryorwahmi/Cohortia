Practical rules and next steps
A compact checklist to guide monitoring decisions.
Sample for rates
Always collect two readings to compute rates from cumulative counters.
Trust the server
SHOW STATUS and InnoDB reports are authoritative; use external tools for history and alerts, not as the only source.
Escalate to Performance Schema
Use sys schema first for friendly summaries, then Performance Schema for custom, high-resolution queries when needed.
Final takeaway

Start with simple, repeatable checks, know which counters to watch, and use the advanced schemas when counters and InnoDB reports point to deeper questions.
