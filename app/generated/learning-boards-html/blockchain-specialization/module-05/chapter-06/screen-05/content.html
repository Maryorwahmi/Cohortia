Pattern comparison
React Context

Simple API, good for small apps or single-purpose providers. Less tooling for selective re-renders.

Redux

Predictable state, middleware, and dev tools. Best when you need strict change flows and complex selectors.

Zustand / Jotai

Lightweight stores with minimal boilerplate. Easy to integrate with event listeners and wallet hooks for DApps.

Best practices
  • Keep a single source for contract reads and update subscribers after events.
  • Use optimistic updates sparingly; roll back if a transaction fails.
  • Cache read-only calls and invalidate on relevant events.
Analogy

Think of the global store as a newsroom: reporters (components) rely on a single editor (store) to publish verified updates pulled from the chain.
