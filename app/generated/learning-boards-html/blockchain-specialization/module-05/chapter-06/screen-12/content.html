Module 6 › Chapter 5.6 › Deployment
Smart contract steps
  1. Deploy to testnet using a scripted deployment tool like Hardhat or Truffle.
  2. Verify the contract source on a block explorer after deployment.
  3. Keep deployment scripts and migrations in version control for reproducibility.
Frontend steps
Build the frontend with your framework's production build command, inject network-specific config via environment variables, and host on a CDN or pin to IPFS for decentralized availability.
Why verify

Verifying source on explorers like Etherscan increases transparency and allows public audits against deployed bytecode.
