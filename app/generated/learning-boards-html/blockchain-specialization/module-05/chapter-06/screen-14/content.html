Module 6 › Chapter 5.6 › CI/CD Pipeline
Pipeline architecture
CI
  1. Run unit and integration tests
  2. Static analysis and linting
  3. Dependency vulnerability scan
CD — Contracts
  1. Deploy to staging testnet
  2. Verify source on explorer
CD — Frontend
  1. Build production bundle
  2. Pin assets to IPFS via secured keys
  3. Publish CID or update staging hostname
Pro tip

Store secrets in the CI provider, keep scripts idempotent, and include manual approvals for production mainnet releases.
