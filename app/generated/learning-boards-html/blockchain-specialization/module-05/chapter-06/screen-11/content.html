Module 6 › Chapter 5.6 › Frontend Security
Practical rules
  • Never include write-capable API keys in client bundles; keep them on a server.
  • Use .env for build-time config and exclude secrets from source control.
  • Limit the scope and lifespan of any public-facing credentials.
User education

Warn users about phishing pages and advise them to verify contract addresses and gateways. Remove debug logs and test keys from production builds.

Checklist
  1. Move writes to server endpoints when possible.
  2. Pin API keys in a secrets manager for CI deployments.
  3. Scan dependencies in CI for vulnerabilities.
