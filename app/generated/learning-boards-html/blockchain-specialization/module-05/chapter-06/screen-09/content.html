// Estimate gas with ethers.js
const estimate = await contractWithSigner.estimateGas.myFunction(arg1, arg2);
console.log('Estimated gas:', estimate.toString());

// Use read-only for fetching
const profile = await contract.viewProfile(address);
Use the estimate to present cost and avoid surprising users. Read-only calls cost no gas and should be used to bootstrap UI state.
Supporting guidance
  • Batch updates when possible to reduce per-transaction overhead.
  • Debounce user actions that trigger writes to avoid duplicate transactions.
  • Show the estimated gas and an explanation before final confirmation.
Common mistake

Relying on a single high gas limit instead of estimating leads to unpredictable costs for your users.
