Architecture
Adopt a provider layer that exposes signer, network, and contract hooks. Let the provider handle reconnection, accounts, and network switching logic so the rest of the app uses stable primitives.
Concrete snippet

Use a hook from wagmi or web3modal to get a contract instance and call read-only functions without managing the signer in every component.

Why it matters

Centralizing connection state reduces bugs related to multiple providers and simplifies testing and mocking in unit tests.

Supporting advice
  • Wrap your app in a provider that rehydrates network and account state on load.
  • Expose a single signed contract instance per network to avoid mismatched calls.
  • Listen for account or network changes and prompt users to switch networks as needed.
