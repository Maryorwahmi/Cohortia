Concept map
Provider

Signer
Signs transactions via wallet (MetaMask)
Quick example
const provider = new ethers.BrowserProvider(window.ethereum);
await provider.send('eth_requestAccounts', []);
const signer = await provider.getSigner();
Key Takeaway

Choose the correct provider for your needs: use BrowserProvider for signed transactions in the browser and JsonRpcProvider for read-only access from services.
