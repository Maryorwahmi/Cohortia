Module 5 › Chapter 5.2 › Listening for account and chain changes
accountsChanged handling

When accounts change, update current account state and clear signer if no accounts remain to avoid sending unsigned requests.

Code pattern
window.ethereum.on('accountsChanged', (newAccounts) => {
  setAccount(newAccounts[0] || null);
  if (!newAccounts.length) setSigner(null);
});
chainChanged handling

On chain change, reload or reinitialize to ensure network-specific settings and contract addresses are accurate.

Practical tip
A full reload is the simplest safe option for basic apps; for advanced apps, reinitialize provider and re-fetch network state.
Mistake to avoid

Failing to remove listeners on unmount can create duplicated handlers and unexpected behavior when components remount during navigation.
