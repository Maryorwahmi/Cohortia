Module 5 › Chapter 5.2 › Signer: who signs and why
What a Signer does

Signs messages and transactions using the account's private key. In browser flows, wallets do this for you securely.

Concrete example
Calling contract.connect(signer).functionName(...) sends a signed transaction that modifies chain state.
Misconception
A Provider alone cannot sign transactions unless combined with a Signer object that has access to private keys.
Security note

Never ask users for their private key in the frontend. Use the wallet to sign and keep private keys secured by the extension or hardware wallet.

Key Takeaway

Signers authorize state changes; obtain them via wallet BrowserProvider.getSigner or keep keys server-side for backend signing where appropriate.
