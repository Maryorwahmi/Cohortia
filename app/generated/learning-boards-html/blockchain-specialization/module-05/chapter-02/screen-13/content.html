Module 5 › Chapter 5.2 › Integrate ConnectWallet into App.jsx
Integration steps
  1. Install ethers in your project folder with npm install ethers.
  2. Create src/components/ConnectWallet.jsx and paste the provided code example.
  3. Import ConnectWallet into src/App.jsx and render it inside your app layout.
  4. Run npm run dev and open the local site; ensure MetaMask is installed.
Test checklist
Connect wallet, confirm account appears, verify network name, and validate current block number updates.
Expected outcome

Your DApp shows the connected account address, the active network name, and the latest block number after approval from the wallet.

Reflection

If any step fails, revisit provider detection, the eth_requestAccounts call, and listener cleanup on unmount.
