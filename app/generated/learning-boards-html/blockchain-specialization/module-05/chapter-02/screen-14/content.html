Module 5 › Chapter 5.2 › Key Concepts
Provider
Connects library to a node (BrowserProvider, JsonRpcProvider).
Signer
Represents an account that can sign messages and transactions.
Library
web3.js or ethers.js wrap RPC and provide contract helpers.
Summary

Pick providers to match read or write requirements, obtain a signer for any state change, and always keep private keys out of the frontend.
