Module 5 › Chapter 5.2 › What is a Provider?
Provider types
  • BrowserProvider: Wraps window.ethereum from wallets like MetaMask and enables signing via the wallet.
  • JsonRpcProvider: Connects to a node endpoint for read-only operations, such as Infura or a local Hardhat node.
  • Specialized providers: Convenience constructors for providers targeting popular services.
Concrete scenario

Use JsonRpcProvider when you want to fetch many blocks or logs from a reliable endpoint without asking the user to sign.

Misconception
A provider alone may not sign transactions. You need a Signer from a BrowserProvider or an explicit Wallet signer for signing.
Why this matters

Selecting the correct provider determines whether your DApp can initiate transactions, rely on user wallets for signing, or only read blockchain state reliably from a node service.
