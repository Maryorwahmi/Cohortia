Module 5 › Chapter 5.2 › BrowserProvider and injected wallets
Step-by-step
  1. Check for window.ethereum. If absent, prompt user to install a wallet.
  2. Wrap with new ethers.BrowserProvider(window.ethereum).
  3. Call provider.send('eth_requestAccounts', []) to request permission.
  4. Obtain signer via provider.getSigner() for signing transactions.
  5. Listen for accountsChanged and chainChanged to update your UI.
Concrete code pattern
if (window.ethereum) {
  const provider = new ethers.BrowserProvider(window.ethereum);
  await provider.send('eth_requestAccounts', []);
  const signer = await provider.getSigner();
} else {
  // prompt to install a wallet
}
Mistake to avoid
Do not assume provider existence; always check window.ethereum and handle user denials gracefully.
Key Takeaway

BrowserProvider ties your DApp to the user's wallet for signing while keeping private keys out of your frontend code.
