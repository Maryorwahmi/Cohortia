Module 5 › Chapter 5.2 › Key Concepts — Quick Reference
Detect wallet
Check for window.ethereum and present a clear install prompt if missing.
Choose provider
BrowserProvider for signing flows; JsonRpcProvider for read-only endpoints.
Keep keys safe
Never request private keys in the frontend; use wallet-based signing or server-side secure signers.
Final takeaway

These practical checks and patterns ensure your DApp connects reliably and securely to Ethereum and provides a predictable UX when users sign transactions.
