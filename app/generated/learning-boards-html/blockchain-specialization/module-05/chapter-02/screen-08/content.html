Module 5 › Chapter 5.2 › JsonRpcProvider and specialized providers
When to use JsonRpcProvider

Choose this provider for dashboards, analytics, and any read-only work that needs a reliable node endpoint.

Specialized constructors

AlchemyProvider and InfuraProvider wrap JsonRpcProvider to reduce configuration friction with those services.

Practical note

If you need to submit transactions from the backend, use a Wallet signer with a private key on a secure server. Never place private keys in frontend code.
