Module 5 › Chapter 5.2 › What web3.js and ethers.js do
Definition

These libraries act as wrappers for the node JSON‑RPC API, converting developer calls into RPC requests and returning parsed responses.

Concrete example
Calling provider.getBlockNumber returns the latest block index, freeing you from manual RPC request handling.
Common misconception
These libraries do not change network capabilities; they provide ergonomics, encoding helpers, and contract bindings.
Why it matters
Using a well‑designed library reduces bugs and helps you focus on app logic rather than low-level RPC calls.
Analogy

Think of the library as a driver: the browser app speaks a friendly language and the library translates it into the node's RPC dialect.

Quick call examples
// ethers.js style
const provider = new ethers.JsonRpcProvider('https://...');
const block = await provider.getBlockNumber();
Key Takeaway

Pick the library that matches your ergonomics and type needs; both wrap the node API and provide contract helpers.
