Using a CID to fetch files and handle missing content

// Retrieval pseudocode
const res = await client.get(cid)
if(!res.ok){
  // handle HTTP-like status and inform user
}
const files = await res.files()
if(files.length === 0){
  // no files for this CID — ask user to pin or re-upload
}
const file = files[0]
const content = await file.text() // or blob/stream for binary
Best practices
  • Report clear status: fetching, not found, failed, or success.
  • Offer recovery: re-upload, check pinning provider, or use alternative gateway.
  • Log attempts for debugging and audits.
Concrete example
After receiving a CID, attempt retrieval and display the result. If missing, guide the user to re-pin or re-upload.
