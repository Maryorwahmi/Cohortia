Activity

Upload and retrieve files using web3.storage

Step-by-step checklist
  1. Sign up for the provider and create an API token.
  2. Install the client library into your DApp project.
  3. Create the DecentralizedStorage component and wire environment tokens.
  4. Upload a small test file and copy the returned CID.
  5. Retrieve the file using the CID and verify content.
Common pitfalls
  • Do not commit API tokens to source control.
  • Remember to pin important content or use Filecoin for long-term needs.
  • Encrypt private data before uploading.
Expected outcome

Your DApp will upload a file, display a CID, and retrieve the exact content using that CID, demonstrating basic decentralized file management.
