Learning Objectives — Practical outcomes

These outcomes align with a develop-test-deploy loop for decentralized apps that need off-chain assets.

01 Decide
Choose which data must be on-chain and which should be referenced by CID. Example: NFT ownership on-chain, artwork off-chain.
VERIFIED COMPETENCY MILESTONE
02 Upload & CID
Use a client library to upload files, receive a CID, and verify that the returned CID matches the expected hash algorithm.
VERIFIED COMPETENCY MILESTONE
03 Pin or pay
Decide between using a pinning provider or Filecoin contracts when you need guaranteed long-term availability.
VERIFIED COMPETENCY MILESTONE
04 Secure
Encrypt private data before uploading, and remember that anyone with a CID can fetch the content unless protected.
VERIFIED COMPETENCY MILESTONE
