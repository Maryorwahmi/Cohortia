Module 5 › Chapter 5.5 › What is IPFS
Definition

Content-based addressing, CIDs, and immutability

IPFS stores and retrieves content by its cryptographic hash. The resulting CID is a self-describing identifier for the exact bytes you added.

  • CIDs change if any byte of the content changes.
  • Multiple nodes can serve the same CID; the network finds peers that have the content.
  • IPFS supports chunking large files into content-addressed blocks for efficient distribution.
Concrete example
Upload a small text file and receive a CID. Later anyone can verify the file's integrity by matching its bytes to the CID.
Misconception
IPFS alone doesn't promise permanence; content must be pinned or placed on an incentive network for long-term availability.
How CIDs help
  1. Integrity: CID ties to exact bytes.
  2. Deduplication: identical content shares a CID across the network.
  3. Censorship resistance: any peer with the content can respond to requests.
