Code Walkthrough

Client setup, token handling, and upload flow

Initialize a web3.storage client with a secret token stored in environment configuration. Use the client's put method to upload files and receive a root CID.

// Pseudocode inspired by the example
const client = new Web3Storage({ token: process.env.WEB3_STORAGE_TOKEN })
const rootCid = await client.put([file], { name: file.name, maxRetries: 3 })
// rootCid is a CID string you can store on-chain
Practical notes
  • Keep the API token secret; prefer server-side storage or ephemeral upload endpoints.
  • Use retries and show clear status messages to the user during uploads.
  • Validate file sizes and types before attempting an upload.
Example flow
User selects file → app calls upload endpoint → server or client library returns CID → store CID in smart contract or database.
