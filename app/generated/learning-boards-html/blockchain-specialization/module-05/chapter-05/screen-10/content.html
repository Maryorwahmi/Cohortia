File selection, client.put, and returned CID

// Simplified upload pattern
const client = new Web3Storage({ token: process.env.WEB3_STORAGE_TOKEN })
async function uploadFile(file){
  if(!file) throw new Error('no file')
  const rootCid = await client.put([file], { name: file.name, maxRetries: 3 })
  // rootCid.toString() is the CID to store or share
  return rootCid.toString()
}
Notes & checklist
  • Validate file size and type before calling upload.
  • Show upload progress and final CID to the user.
  • Handle exceptions and implement retries for transient errors.
Security reminder
Do not embed long-lived API tokens in client shipping code. Use short-lived tokens or server uploads when possible.
