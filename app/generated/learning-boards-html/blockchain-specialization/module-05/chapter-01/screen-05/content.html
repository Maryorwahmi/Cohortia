Core Concept

Smart Contract, Provider, Frontend

These three layers form the DApp architecture. Each has distinct responsibilities and constraints that shape how you build interactions.

Smart Contract Layer

Holds business logic and authoritative state on chain. Deployable via tools you already used in Solidity.

Web3 Provider Layer

Exposes RPC and signing capability. Without it, the browser cannot send transactions or access accounts.

Frontend Layer

Presents data, collects input, and initiates interactions via the provider to the smart contracts.

Example Flow
Action: User submits a transfer
  • Frontend composes transaction data for the token contract.
  • Provider prompts the user to sign and sends the transaction to the network.
  • Smart contract updates balances when the transaction is mined.
Misconception

The provider is optional — it is not. It is required to access accounts and sign transactions.

Pro tip

Keep blockchain calls isolated behind a small provider interface to simplify testing and switching providers.
