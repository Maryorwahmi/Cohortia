Module 5 › Chapter 5.1 › Activity: Scaffold & Verify
Terminal Demo

Commands to run

npm create vite@latest my-first-dapp -- --template react
cd my-first-dapp
npm install
npm run dev

Confirm the dev server prints a local URL. Open that URL and check the Vite welcome page is visible.

Verification

Add a console log in the main entry file and confirm it appears in the browser console to prove you can modify the running app.

Common mistakes
  • Skipping dependency installation and expecting the dev server to run.
  • Assuming the dev server provides blockchain connectivity; you still need a provider.
  • Not checking where to insert provider initialization in the app entry file.
Key Takeaway

A running local app is the first milestone; use it as a canvas to add provider detection and contract interactions next.
