Definition

Providers and wallets

A provider exposes RPC methods and signing capability. Wallets commonly inject a provider into the browser to manage accounts and signatures.

Concrete example

MetaMask injects a provider object; the frontend can call it to prompt the user to sign a transaction and broadcast it to the network.

Misconception

Assuming the browser can sign transactions without a wallet is incorrect; a provider is mandatory for signing from client code.

Integration patterns
  • Detect an injected provider and prompt users to connect their wallet.
  • Use the provider for signing and consider hosted RPC services for read-only queries if needed.
  • Centralize blockchain calls behind a small provider interface to simplify testing.
Key takeaway

Plan for provider detection and connection flows before attempting transaction flows in your UI.
