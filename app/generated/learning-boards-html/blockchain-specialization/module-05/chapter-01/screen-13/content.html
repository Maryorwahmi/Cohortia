Module 5 › Chapter 5.1 › Transaction UX
Best Practice

Explicit transaction flows

Model installation and connection states; always request explicit user approval before sending transactions and present clear pending and final confirmation states.

State: No provider

Prompt installation guidance and do not attempt blockchain calls.

State: Disconnected

Ask the user to connect their wallet and select an account.

State: Connected

Allow reads and signed writes through the provider wrapper.

Concrete example

When submitting a transfer, show an immediate pending indicator, display transaction details and estimated gas, and then update status on confirmation or show an error on failure.

Misconception

Optimistic updates without clear pending labels can mislead users about finality; always reconcile with on‑chain receipts.
