Module 5 › Chapter 5.1 › Set up React + Vite
Process Flow

Scaffold and run

Run three terminal steps to create and run a React project with Vite. This is the base you will extend with Web3 libraries.

npm create vite@latest my-first-dapp -- --template react
cd my-first-dapp
npm install
npm run dev
The dev server typically prints a local URL such as http://localhost:5173 where you can confirm the Vite welcome page.
Misconception

The dev server does not provide blockchain nodes. You still need a wallet or provider to interact with contracts.

Pro tip

Open src/main.jsx and plan where you will initialize provider detection and the Web3 library for global use.

Concrete outcome
A running React development server and a project structure with package.json, src directory, and public assets ready for Web3 integration.
Key Takeaway

Use Vite for a fast, lightweight React scaffold. Confirm the app runs before adding Web3 calls.
