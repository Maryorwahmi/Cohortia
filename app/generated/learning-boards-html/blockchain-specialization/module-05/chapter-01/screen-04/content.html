Module 5 › Chapter 5.1 › What is a DApp?
Definition

Decentralized Application explained

A DApp’s authoritative logic and data live in smart contracts on a blockchain. The frontend acts as the user's interface to request state changes and display on‑chain data.

Concrete example

A token wallet reads balances from a token contract and submits signed transfer transactions to update those balances on chain.

Common misconception

Calling a blockchain is not enough; a DApp’s backend logic must be enforced by on‑chain contracts, not only mirrored off‑chain.

Design implication

Design UIs to request signed transactions and clearly indicate pending on‑chain confirmations to users.

Key takeaway

Treat on‑chain state as authoritative and design transaction flows accordingly.

Analogy
Smart contracts are the rules referee

Think of the blockchain as a public rulebook and contracts as referees enforcing actions everyone can verify.
