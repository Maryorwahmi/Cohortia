Step-by-step
  1. Add state: messageToSign, signedMessage, signatureVerified.
  2. Ensure initializeProvider sets provider and signer via BrowserProvider.
  3. Create signMessage to call signer.signMessage and save the signature.
  4. Implement verifySignature using ethers.verifyMessage and compare addresses.
  5. Test connect, sign, verify, then change accounts to confirm listeners work.
Key Takeaway

Work through the full cycle: connect, sign, verify, and react to account or chain changes to build confidence in the flow.

Example test checklist
Install ethers
npm install ethers, then run your dev server and open the DApp in a browser with MetaMask installed.
Run test flow
Connect, sign the welcome message, confirm Signed Message displays, and check Signature Verified state.
Troubleshooting
If verification fails after switching accounts, clear signedMessage and require a new signature for the new account.
