State and lifecycle
State variables
provider, signer, account, network, blockNumber, messageToSign, signedMessage, signatureVerified, error.
initializeProvider
Creates BrowserProvider, lists accounts, sets signer, fetches network and block number, and registers listeners.
useEffect & cleanup
Call initializeProvider on mount and remove listeners on unmount to avoid duplicated handlers.
Key Takeaway

Organize provider init, event registration, and cleanup to keep component state accurate and avoid leaks during development.

Code highlights
// memoized init
const initializeProvider = useCallback(async () => { ... }, [messageToSign, signedMessage]);

useEffect(() => {
  initializeProvider();
  return () => { remove listeners };
}, [initializeProvider]);
Concrete example
After a successful connection setBlockNumber to inform the UI of the current chain state.
Common mistake
Forgetting to remove listeners causes duplicate console logs and state updates on hot reloads.
