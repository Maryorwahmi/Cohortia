Module 05 › Chapter 5.4 › Assessment & Pitfalls
Assessment items
Practice tasks:
  • Implement message signing and verification and demonstrate successful verification.
  • Handle accountsChanged, chainChanged, and disconnect to keep state accurate.
  • Extend the flow to send signatures to a backend that re-verifies and issues a time-limited token.
Common pitfalls
Treating address as secret
Remember the address is public; ownership is what signing proves.
Skipping server verification
Client verification is not authoritative for critical actions.
No nonce
Without unique challenges signatures can be replayed across sessions.
