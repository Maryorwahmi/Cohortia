Module 05 › Chapter 5.4 › Signing & Verification
Code: signMessage
const signature = await signer.signMessage(messageToSign);
setSignedMessage(signature);
verifySignature(messageToSign, signature, account);

// verification
const recoveredAddress = ethers.verifyMessage(message, signature);
const isVerified = recoveredAddress.toLowerCase() === address.toLowerCase();
setSignatureVerified(isVerified);
Concrete example
User signs 'Welcome to Cohortia DApp!' and the DApp compares recovered address to the connected account to confirm ownership.
Misconception
Do not treat a client-side verification as final for critical permissions; backends should re-verify important signatures.
UX and security notes
Clear prompts
Always make it clear what the user is signing and why. This reduces accidental approvals.
Replay protection
Include nonces or session-specific data in messages when verifying sensitive actions to prevent reuse of signatures.
Key Takeaway
Signing plus verification gives ownership proof without exposing private keys; pair it with backend checks for critical flows.
