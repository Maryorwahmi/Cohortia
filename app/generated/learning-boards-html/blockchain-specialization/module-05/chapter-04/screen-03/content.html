Module 05 › Chapter 5.4 › Bloom Levels
Bloom Progression
Learn → Understand → Apply → Master
Learn
Identify provider patterns and MetaMask responsibilities.
Understand
Explain signing and why private keys never leave the wallet.
Apply
Build ConnectWallet with listeners and signing logic.
Master
Verify signatures on the backend for secure authorization.
Example
A component calls listAccounts on mount to auto-detect previous approval and updates UI accordingly.
Misconception
Signature verified client-side is helpful but not always sufficient for critical authorization without server checks.
Why it matters
Users remain in control of private keys and you avoid central credential risk.
