Definition

Robust Error Handling

Translate raw errors into clear user actions and avoid exposing diagnostics to end users.

Common errors
  • User rejected transaction (wallet error code 4001).
  • Insufficient funds to cover gas fees.
  • Missing signer when attempting a write.
  • Incorrect ABI or contract address leading to decoding errors.
Handling pattern
try {
  const tx = await contractWithSigner.setGreeting(value);
  await tx.wait();
} catch (err) {
  if (err.code === 4001) setStatus('Transaction rejected by user.');
  else setStatus('Transaction failed: ' + (err.message || 'Unknown error'));
}
Map known codes to friendly messages, log for developers, and provide retry instructions when appropriate.
