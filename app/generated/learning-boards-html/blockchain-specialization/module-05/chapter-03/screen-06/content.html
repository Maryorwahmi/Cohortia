Process Flow

Instantiate ethers.Contract

Use the address, ABI, and a provider or signer to make a callable contract object.

Code pattern
import GreeterJson from '../abi/Greeter.json';
const address = GreeterJson.address;
const abi = GreeterJson.abi;
const contract = new ethers.Contract(address, abi, provider);
// Later, to send a transaction:
const contractWithSigner = contract.connect(signer);
const tx = await contractWithSigner.setGreeting(value);
await tx.wait();
Practical checks
  • Confirm the contract address matches the network.
  • Use the ABI produced by the same compiler output as the deployed bytecode.
  • Reuse the base contract and call connect for different signers instead of recreating objects repeatedly.
Concrete example
Place Greeter.json in src/abi, import it, then instantiate with provider to fetch the greeting immediately on page load.
Key Takeaway

Address + ABI + Provider/Signer = a usable Contract. Keep ABI and address in sync with deployed code.
