Deploying Greeter and Saving ABI

Deploy locally with Hardhat and copy ABI and address into src/abi for the frontend to import.

Deployment script pattern
// after deploying
fs.writeFileSync('src/abi/Greeter.json', JSON.stringify({ address: greeter.target, abi: JSON.parse(greeter.interface.formatJson()) }, null, 2));
This keeps address and ABI together for straightforward import into your React app.
Checklist
  • Confirm Hardhat node is running when deploying locally.
  • Copy the deployed address into the frontend artifact.
  • Ensure the frontend and wallet use the same network.
