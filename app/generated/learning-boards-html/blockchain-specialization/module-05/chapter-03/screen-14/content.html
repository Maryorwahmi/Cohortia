What to Remember

Key Concepts

ABI
JSON description of functions and events used to encode and decode calls.
ethers.Contract
An object representing the deployed contract, instantiated with address, ABI, and provider or signer.
Read vs Write
Use a provider for view functions; connect a signer for state-changing transactions and await confirmation.
Summary Takeaway

These pieces together enable a predictable, user-friendly DApp that reads on-chain data, submits transactions securely, and updates in real time.
