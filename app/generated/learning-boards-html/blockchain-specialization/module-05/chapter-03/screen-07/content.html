Definition

Calling Read-Only Functions

Use a Provider to call view or pure functions without sending a transaction.

Example: fetch greeting
const contract = new ethers.Contract(address, abi, provider);
const greeting = await contract.greet();
setCurrentGreeting(greeting);
No wallet prompt appears and no gas is used. This call reads the node's state and returns a decoded string because the ABI describes the output.
Best practices & pitfalls
  • Wrap reads in try-catch to surface friendly errors if the node is unreachable.
  • Provide a loading state and sensible defaults if data is temporarily unavailable.
  • Be mindful of provider rate limits when polling; rely on events when possible.
Concrete scenario
In Greeter, show the current greeting using a provider so visitors see the value immediately without connecting a wallet. Offer a connect button only for writes.
