Core Concept

Listening for Events

Attach listeners to react to contract-emitted events for a responsive UI.

Example handler
contract.on('NewGreeting', (setter, newText, event) => {
  setStatusMessage(`New greeting "${newText}" set by ${setter}`);
  setCurrentGreeting(newText);
});
// cleanup: contract.off('NewGreeting')
Update the UI immediately when the event arrives and clean up the listener when the component unmounts.
Practical notes
  • Use events to avoid frequent polling.
  • Always off-load listeners on cleanup to prevent duplicates.
  • Design handlers to be idempotent in case of replays or duplicate events.
Concrete example
When NewGreeting fires, update the displayed greeting and show a status message indicating who set it. The event gives the setter address and the newText argument.
