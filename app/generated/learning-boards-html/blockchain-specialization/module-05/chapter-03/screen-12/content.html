Process Flow

Integrating Contract Interaction into React

Use effects to create contracts, fetch data, register listeners, and clean up on unmount.

Pattern summary
  1. Create provider and contract in an effect when provider exists.
  2. Fetch initial data and set state.
  3. Register event listeners and return cleanup to remove them.
  4. Connect signer only when sending transactions.
Concrete example notes
In the GreeterInteraction component, the effect checks for provider and ABI, creates a contract, fetches the greeting, and sets up a NewGreeting listener. The cleanup detaches the listener to avoid duplicate updates when the component unmounts or the provider changes.
Developer tip
Keep contracts in a shared context if multiple components need access. This centralizes listeners and reduces re-instantiation overhead.
