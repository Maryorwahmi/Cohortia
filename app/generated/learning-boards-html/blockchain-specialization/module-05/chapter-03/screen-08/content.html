Sending State-Changing Transactions

Connect signer, send the transaction, and wait for the receipt to ensure the on-chain change succeeded.

Typical sequence
  1. Request wallet connection to get signer.
  2. const contractWithSigner = contract.connect(signer).
  3. const tx = await contractWithSigner.setGreeting(value).
  4. Show tx.hash and await tx.wait() for confirmation.
User experience guidance
  • Inform the user when MetaMask opens and what they are signing.
  • Show the transaction hash so users can verify status externally if desired.
  • Disable repeated submissions while waiting for confirmation.
Common mistake
Assuming a transaction is final as soon as it's sent. Always await confirmation to ensure on-chain state matches your UI.
