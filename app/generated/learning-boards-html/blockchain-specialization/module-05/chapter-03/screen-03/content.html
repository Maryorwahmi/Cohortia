How you'll practice

A repeatable local workflow to build confidence and debug the full lifecycle of contract interaction.

Deploy
Compile and deploy Greeter on a local node. Save the generated ABI and deployed address for the frontend.
Integrate
Instantiate ethers.Contract with address and ABI, use a provider for reads and a signer for writes.
Observe
Listen for emitted events to update UI instantly and await transaction confirmations to ensure on-chain consistency.
