Module 6 › Chapter 6.4 › Formal Verification
Definition
What Formal Verification Proves
State precise properties as logic statements, then use a prover to guarantee the code satisfies them for all inputs and paths. Examples include supply invariants and withdrawal bounds.
Example property
"After any transfer operation, the total supply of tokens remains constant." This is expressed formally and proved against the code paths.
Limits and trade-offs
Formal proofs require precise specs and expertise. They are expensive and usually reserved for the most critical contracts.
Tools & examples
Certora Prover, K Framework, and similar systems map proofs to code. The process: write properties, model code behavior, run the prover, and inspect counterexamples if proofs fail.
Key Takeaway
Formal verification gives the strongest assurance, but only for precisely stated properties. Be deliberate about what you prove.
