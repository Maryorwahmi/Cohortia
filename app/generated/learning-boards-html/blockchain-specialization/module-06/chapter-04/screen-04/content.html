Core Concept
What is a Security Audit?
Manual review stages and why human judgment adds value beyond tools.
Audit stages
  • Initial review: understand architecture and threat surface.
  • Code review: identify vulnerabilities and logic flaws.
  • Remediation: recommend fixes and design changes.
  • Re-audit: confirm remediation and update report.
Why human review matters
Humans detect complex interactions and attacker intent that pattern-based tools may miss, such as combined function misuse or unexpected state transitions.
Concrete example
Imagine two harmless-looking functions: one updates a ledger, the other increments an allowance without checking a precondition. Together they could enable a user to obtain funds improperly. An auditor maps how functions compose to find such logic flaws.
Common misconception
Automated tools make audits unnecessary. In reality, tools accelerate discovery, but audits reveal subtle design or business-logic issues that tools often miss.
Key Takeaway

Treat audits as expert reasoning about misuse and design, not just a code checklist.
