Cryptographic Hash Functions
Fixed-size digests that provide integrity and tamper evidence.
Properties
  • Determinism: same input → same output.
  • Pre-image resistance: cannot reverse the hash.
  • Second pre-image resistance: hard to find alternate inputs for a given hash.
  • Collision resistance: hard to find any two inputs with same hash.
Common uses
Block linking, Merkle trees, address generation, and proof-of-work hashing loops.
Key Takeaway
A secure hash acts as a compact, public fingerprint that makes tampering visible and supports efficient verification.
Misconception
Hashes are not encryption. They do not hide original data; they produce a digest for integrity checks only.
Example: small change, big effect
Input A
"Hello Cohortia Blockchain!"
Input B (one character changed)
"Hello Cohortia Blockchain."
Result
Two completely different digest strings, illustrating the avalanche effect and why small differences break links.
