Module 06 › Chapter 6.6 › Public-Key Cryptography
Private and public keys
A key pair enables signing and verification without sharing secrets.
Private key
A secret number used to create signatures. If exposed, control of associated assets is lost.
Public key
Derived from the private key and used to verify signatures and derive addresses for transactions.
Misconception
Public verification does not imply confidentiality; it only proves origin and integrity.
Concrete example
Sign a transaction with your private key. The network uses the public key to confirm the signature matches the sender, proving the sender authorized the transaction.
Key Takeaway
The separation of private signing and public verification is what lets decentralized systems verify actions without exposing secrets.
