Module 06 › Chapter 6.6 › Merkle Trees
Merkle tree hierarchy
Leaf hashes combine pairwise to form parent hashes, culminating in a Merkle root that commits to all leaves.
Leaves
Hash each transaction individually. These are the leaves of the tree.
Parents
Hash pairs of leaves to form parents; repeat until a single root remains.
Verification benefit
To prove inclusion, provide a path of sibling hashes up to the root. Light clients need only that path, not every transaction.
Concrete example
Transactions A, B, C, D produce leaf hashes. Hash(A)+Hash(B) → parent1. Hash(C)+Hash(D) → parent2. Hash(parent1)+Hash(parent2) → Merkle root.
Key Takeaway
Merkle root is a compact commitment to many transactions and enables efficient inclusion proofs for light clients.
