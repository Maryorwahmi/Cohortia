Generate and inspect a wallet
Run the snippet in Node.js or a dev console to observe wallet outputs and hash digests.
Example code (visual only)
// createRandom() → address, privateKey, mnemonic
const wallet = ethers.Wallet.createRandom();
console.log(wallet.address, wallet.privateKey, wallet.mnemonic.phrase);

// deterministic derivation
const derived = ethers.Wallet.fromMnemonic(mnemonic);

// keccak256 hash
const bytes = ethers.utils.toUtf8Bytes('Hello Cohortia Blockchain!');
const h = ethers.utils.keccak256(bytes);
console.log(h);
Common mistake
Using public or weak mnemonics in real wallets exposes funds; never reuse test mnemonics for production.
Pro tip
Run the code offline in an isolated environment to avoid leaking private keys during experimentation.
Concrete observation
When you run fromMnemonic with a fixed mnemonic, the derived address and private key match the deterministic outputs for that phrase. createRandom uses high-entropy randomness to produce a fresh key. Observing both patterns clarifies determinism and recovery mechanics.
Key Takeaway
Practice in a safe environment: examine address, private key and mnemonic, and confirm that the same mnemonic reproduces the same wallet.
