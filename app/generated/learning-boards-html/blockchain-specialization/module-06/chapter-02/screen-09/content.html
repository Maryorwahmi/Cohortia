Module 6 › Chapter 6.2 › Denial-of-Service (DoS)
Gas-based DoS
Loops over dynamic data structures that can be grown by external users may eventually cost more gas than a block permits, making the function unusable.
  • Identify loops that iterate over arrays or maps without bounds.
  • Ask who can add items to those arrays; if anyone can, treat the loop as high risk.
  • Consider alternatives: pagination, batching, or pushing processing to users.
Vulnerable pattern
address[] public userList;
function addUser(address _user) public { userList.push(_user); }
function processAllUsers() public {
  for (uint i = 0; i < userList.length; i++) {
    // expensive work per user
  }
}
If one or more attackers append many addresses, processAllUsers will eventually require more gas than fits in a block, preventing its execution.
Key Takeaway

Avoid unbounded on-chain loops and design operations that can be performed incrementally or by the users themselves.
