Module 6 › Chapter 6.2 › Access Control
Access control failures
Missing or incorrect checks allow any address to perform privileged actions intended for an owner or admin.
  • Look for functions that change contract configuration, pause, or transfer funds.
  • Check whether require(msg.sender == owner) or role checks exist; absence is a red flag.
  • Ensure constructor sets owner correctly and modifiers are applied consistently.
Common consequence

An attacker can change ownership or important parameters, often enabling theft or disabling protections.

Vulnerable pattern
// Vulnerable access control
address public owner;
function setOwner(address _newOwner) public {
    // Missing require(msg.sender == owner)
    owner = _newOwner;
}
Without a check on msg.sender, any external caller can set themselves as owner. That single missing line escalates privileges immediately.
