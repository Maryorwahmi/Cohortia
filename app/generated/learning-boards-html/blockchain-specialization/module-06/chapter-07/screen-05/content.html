Process Flow

Plan for post-quantum migration

  1. Inventory cryptographic uses across wallet, node, and consensus.
  2. Evaluate candidate PQC algorithms for signatures and key exchange.
  3. Prototype hybrid verification to measure costs and compatibility.
  4. Stage consensus or protocol upgrades with testing and governance.
Concrete example

A hybrid signature scheme accepts both ECDSA and a PQC signature during transition. Measure gas, client changes, and storage trade-offs before finalizing migration.

Trade-offs to evaluate
  • Signature and key sizes affecting storage and bandwidth.
  • Verification cost impacting node CPU and transaction fees.
  • Compatibility with existing wallets and libraries.
  • Governance and upgrade coordination across participants.
Key takeaway

PQC migration is a staged engineering program: evaluate, prototype, hybridize, and upgrade with clear testing gates.
