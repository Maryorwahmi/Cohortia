Module 7 › Chapter 6.7 › Zero-Knowledge Proofs
Definition

Prove without revealing

A prover convinces a verifier of a statement's truth while keeping underlying data private.

  • Use case: prove token-holding threshold without publishing balances.
  • Systems: zk-SNARKs and zk-STARKs with different proof and trust properties.
  • Application: zk-Rollups bundle transactions and post a succinct proof to the main chain.
Example and trade-offs
Generating a proof can be computationally expensive for a user device, so some designs use trusted provers or batch proofs on servers. Proof sizes and verification costs determine where ZKPs fit: client-side privacy proofs need lightweight provers or helper services; rollups can centralize proving for throughput.
Concrete Scenario

A private voting DApp uses ZKPs to verify eligibility without publishing voter lists, preserving ballot secrecy while ensuring integrity.

Key takeaway

ZKPs enable confidentiality and scalable verification, but choose constructions based on prover cost and proof size constraints.
