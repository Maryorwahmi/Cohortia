Module 7 › Chapter 6.7 › Privacy vs Auditability
Comparison

Meeting rules without exposing everything

  • Regulatory need: traceability and evidence for suspicious activity.
  • Privacy goal: minimize personal data on the public ledger.
  • Technique: off-chain attestations, verifiable credentials, or ZKPs for selective disclosure.
Practical patterns
Use off-chain KYC providers to issue attestations that a user can present as proof. Alternatively, use ZKPs so a user proves compliance properties while keeping personal data private. Each has trade-offs for trust, auditability, and integration complexity.
Example

A DApp requires a KYC attestation held off-chain; the smart contract checks a proof or token confirming the attestation rather than the raw identity.

Takeaway

Design systems to minimize on-chain identity while providing verifiable evidence to auditors when needed.
