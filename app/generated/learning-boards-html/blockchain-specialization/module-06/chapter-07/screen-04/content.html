Core Concept

Shor's and Grover's impact

Shor's threatens public-key signatures; Grover's reduces hash strength. Both change cryptographic assumptions blockchains rely on.

Bullet points
  • Shor's algorithm can target schemes like ECDSA by solving discrete logarithms.
  • Grover's algorithm speeds up search, lowering effective hash security but not outright breaking hashes.
  • Addresses that reveal public keys are higher risk if quantum advances arrive.
  • Immediate defense is planning upgradeable cryptography and monitoring PQC standards.
Concrete example

If a public key is known from a prior transaction, a future quantum attack could derive the private key and sign transactions to drain funds.

Key takeaway

Begin planning upgrade paths now; replacement is easier with forethought than emergency migration later.

Common misconception

Quantum attacks are not a near-term reality for most projects, but ignoring them entirely risks technical debt and emergency fixes later.

Practical checklist
  1. Inventory where public keys are published or reused.
  2. Track PQC standards and candidate algorithms.
  3. Design upgradeable verification logic or consensus upgrade plans.
  4. Consider short-term mitigations like key rotation and minimizing revealed keys.
