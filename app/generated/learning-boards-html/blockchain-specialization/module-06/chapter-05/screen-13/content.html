Pre-deployment checklist
  1. Set a strict Content Security Policy: disallow inline scripts and restrict external script sources.
  2. Sanitize and validate every user input that reaches the DOM or is sent to the backend.
  3. Require explicit transaction previews and verify the connected network before writes.
  4. Pin dependencies and run automated vulnerability scans on packages.
  5. Encrypt sensitive off-chain data and plan key rotation and revocation.
  6. Publish official security channels and short user guidance about phishing and hardware wallets.
Key Takeaway
A short, repeatable checklist prevents many deployment-time mistakes and should be enforced by CI or code review.
