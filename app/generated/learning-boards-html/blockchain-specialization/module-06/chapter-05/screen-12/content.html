Common misses in the sample script
  • Missing network check: ensure the wallet is on the expected network before sending transactions.
  • Blind signing risk: always display a readable transaction summary to the user and match it to the wallet prompt.
  • Function validation: verify function existence and argument shapes before calling contract methods.
  • Web hygiene: add CSP headers, update dependencies, and secure hosting to reduce supply-chain tampering.
Key Takeaway
A quick checklist addressing network, preview, validation, and hosting catches many high-risk issues early.
Review task
Given a sample snippet that connects to a wallet and sends transactions, identify where to add: a network detection step, an explicit transaction preview UI, validation of contract calls, and CSP and hosting checks. Mark each as a required pre-merge item.
Example checklist items
  • Require network equality check before any write action.
  • Require user-visible transaction summary with recipient and amount.
  • Reject unknown function names or malformed arguments before calling contract methods.
  • Ensure CSP and secure hosting are applied to production builds.
