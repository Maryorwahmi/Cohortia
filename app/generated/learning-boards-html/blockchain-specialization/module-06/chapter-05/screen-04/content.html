Module X › Chapter Y › DApp Front-end Security
Definition
Front-end security

Protecting the web-based user interface of a DApp from injection, tampering, and supply-chain risks so users aren’t tricked into harmful actions.

Example
An XSS payload that modifies the visible recipient address in a transfer form, while the wallet receives a different underlying address to sign.
Common mistake
Assuming the blockchain alone secures the user; ignoring the front-end allows attacker-controlled UI to mislead users.
Key defenses
Sanitize inputs
Reject or escape untrusted HTML, remove scripts from user content, and validate input formats strictly.
Content Security Policy
Restrict script sources, disallow inline script, and reduce attack surface for injected scripts.
Dependency hygiene
Keep libraries updated and monitor supply-chain risks from third-party packages.
Hosting integrity
Use tamper-resistant hosting when feasible to reduce server-side compromises, but still defend the client.
Key Takeaway

Protect the UI with sanitization and CSP; never assume the front-end cannot be tampered with.

Check
Can a user submit HTML that renders in the DApp? If yes, stop and sanitize.
