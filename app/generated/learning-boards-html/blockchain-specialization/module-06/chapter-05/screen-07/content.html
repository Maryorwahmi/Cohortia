Common failure scenarios
Wrong network
Explain required chain and provide a safe prompt to switch networks.
Transaction rejected
Show clear reason and suggest next steps like check balance, gas limit, or contact support.
Timeouts or node errors
Recommend retry policies and show safe defaults to avoid repeated risky attempts.
Example guidance
If a transfer fails because the user is on a test network, display: "Network mismatch: switch to Ethereum Mainnet to complete this transfer." Provide a single-step explanation and link to official instructions for switching networks.
Pro tip
Design errors to reduce panic: give exact corrective actions, not raw logs.
