Module X › Chapter Y › Web Vulnerabilities That Matter to DApps
Vulnerability cards
Cross-site scripting (XSS)
Attacker-run scripts can alter the DApp UI or inject fake prompts that cause users to sign harmful transactions.
Cross-site request forgery (CSRF)
An attacker can cause the DApp to perform actions using a user’s session, affecting off-chain state or API-driven behavior.
Injection (e.g., SQL)
When the DApp persists off-chain data, injection can corrupt or expose that data, leading to incorrect DApp decisions.
Mitigations
XSS defenses
Escape output, avoid innerHTML, enforce CSP, and treat any user content as untrusted.
CSRF defenses
Use anti-CSRF tokens, same-site cookies, and require explicit wallet interactions for sensitive actions.
Injection defenses
Always use parameterized queries or safe storage APIs for off-chain databases and validate inputs server-side.
Key Takeaway
Treat web vulnerabilities as direct threats to user funds and permissions; mitigate them with standard web best practices adapted for DApp flows.
