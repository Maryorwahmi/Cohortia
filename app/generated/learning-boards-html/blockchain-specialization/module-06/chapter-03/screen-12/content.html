Module 6 › Chapter 6.3 › Pull Payments
Pattern Overview
Credit recipients in a mapping and provide a claim function so each recipient pulls their funds when ready.
Benefits
  • Avoids unbounded loops and gas spikes.
  • Makes retries and partial failures manageable.
  • Aligns with CEI when claims update state before calls.
Example Implementation
mapping(address => uint) public owed;

default function credit(address user, uint amount) internal {
  owed[user] += amount;
  emit Credited(user, amount);
}

function claim() public {
  uint amount = owed[msg.sender];
  require(amount > 0, "Nothing to claim");
  owed[msg.sender] = 0; // Effect before interaction
  (bool success, ) = msg.sender.call{value: amount}("");
  require(success, "Claim failed");
  emit Withdrawal(msg.sender, amount);
}
Key Takeaway
Pull payments increase reliability and align with CEI by isolating interactions per user.
