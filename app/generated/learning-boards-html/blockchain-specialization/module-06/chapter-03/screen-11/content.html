Module 6 › Chapter 6.3 › Hands-on Refactor
Starter: VulnerableToken issues
  • No arithmetic safety; pragma ^0.7.0.
  • setTotalSupply lacks access control.
  • withdrawAllFunds makes an external call without state updates or events.
Step-by-step edits
  1. Update pragma to ^0.8.0 and recompile.
  2. Add owner and onlyOwner modifier; protect setTotalSupply.
  3. Apply CEI to withdrawals and check call success.
  4. Add events for Transfer, Withdrawal, ConfigUpdated and emit them after state changes.
  5. Write tests for edge cases: overflow, non-owner calls, failing external calls.
Testing & Validation
Create unit tests that verify arithmetic reverts on overflow, that onlyOwner prevents unauthorized changes, that withdrawals cannot be re-entered, and that events are emitted with expected indexed fields.
Key Takeaway
A small set of edits plus focused tests convert an easily exploitable contract into a defensible one.
