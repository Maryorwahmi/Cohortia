Module 6 › Chapter 6.3 › External Calls
Call Semantics Comparison
transfer / send
Forward limited gas (2300). Can fail if recipient logic needs more gas; historically used to limit reentrancy surface.
call
Forwards all available gas and returns (bool, data). Must check the boolean and handle failure paths explicitly.
Practical guideline
Use call with a require(success) after updating state, or use pull patterns to avoid complex push logic.
Concrete Example
(bool success, ) = recipient.call{value: amount}("");
require(success, "Transfer failed");

// Prefer this after state is updated to follow CEI
Key Takeaway
Checking call success is non-negotiable; design push vs pull carefully.
Misconception
Assuming transfer always succeeds hides cases where recipient fallback requires more gas.
