Testing checklist for security
Arithmetic Edge Cases
Tests that push numbers to max uint and expect reverts.
Access Control
Ensure only authorized roles can call privileged functions.
Reentrancy Scenarios
Deploy malicious reentrant contract and verify CEI prevents duplication.
External Call Failures
Simulate failed call booleans and ensure correct failure handling.
Gas & Large Datasets
Run stress tests with big arrays to check for DoS by gas exhaustion.
Event Assertions
Verify events are emitted with expected indexed fields after successful operations.
Key Takeaway
Security testing should include failure scenarios, not just happy-path cases, to provide real assurance before deployment.
