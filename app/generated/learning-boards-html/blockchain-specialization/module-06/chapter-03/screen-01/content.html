Secure Smart Contract Development Practices
Design, code, and log defensively to reduce attack surface and operational risk.
Orientation

We cover the Checks-Effects-Interactions pattern, integer safety using Solidity 0.8.0, access control patterns, safe external calls, gas-aware design, and consistent event logging.

In this lesson
Refactor a vulnerable token, apply CEI, use modern arithmetic safety, and enforce owner-only controls with events for auditability.
Coming up: concrete code refactors, patterns you will reuse, and a short hands-on activity to practice the refactor.

CEI Pattern
A simple order: Checks, Effects, Interactions. Use it as a default for external calls.
Arithmetic Safety
Prefer Solidity 0.8.0+ to get automatic overflow checks; use SafeMath for legacy code.
Access Control
Implement onlyOwner and consider role-based controls for complex permission models.
