Module 6 › Chapter 6.3 › Event Logging
Why events?
Events are an append-only audit trail used by off-chain services to monitor contract behavior and reconstruct actions without reading internal storage directly.
Good event practices
  • Emit after state changes to keep logs consistent.
  • Index frequently-filtered fields like user addresses.
  • Include meaningful payloads to aid debugging.
Example events
event Withdrawal(address indexed user, uint amount);
event ConfigUpdated(address indexed setter, uint newValue);

// Emit after successful operations
emit Withdrawal(msg.sender, _amount);
emit ConfigUpdated(msg.sender, _value);
Key Takeaway
Events are essential for monitoring and post-incident analysis; emit them consistently.
Try this
Add event assertions to your unit tests so a successful action also verifies the emitted event contents.
