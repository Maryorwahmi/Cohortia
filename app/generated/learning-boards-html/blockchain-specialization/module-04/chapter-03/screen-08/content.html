Module 4 › Chapter 4.3 › require / revert / assert
Comparison Table
require(condition, message): validate inputs, refunds remaining gas when false.
revert(message): explicit failure inside logic branches; also refunds remaining gas.
assert(condition): internal invariant checks; consumes all remaining gas when false.
Common mistake

Do not use assert to validate user-provided inputs. Use require or revert so callers get refunds and messages.

Example
function setValue(uint256 _newValue) public {
    require(msg.sender == owner, "Caller is not the owner");
    require(_newValue <= 1000, "New value exceeds maximum limit of 1000");
    value = _newValue;
}

function criticalInvariantCheck() public view {
    assert(value >= 0); // internal invariant for demonstration
}
Pro tip: error messages improve developer UX when debugging.
Audit note: assert failures should be rare and signal urgent fixes.
