01
Implement if/else
Write conditional logic to gate actions and return value-based status. This prevents unauthorized state changes and encodes business rules.

02
Use for loops safely
Iterate over small or fixed collections while understanding gas implications. Favor bounded loops or batching to avoid DoS.
VERIFIED COMPETENCY MILESTONE
03
Apply require and revert
Enforce preconditions and return informative failures that refund remaining gas to callers. This improves UX and safety.
VERIFIED COMPETENCY MILESTONE
04
Use assert for invariants
Reserve assert for internal conditions that should never be false, signaling a serious contract bug when triggered.
