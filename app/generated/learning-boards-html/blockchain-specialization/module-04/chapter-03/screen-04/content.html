Module 4 › Chapter 4.3 › If / Else
Definition
Conditional branching
Evaluate booleans to choose execution paths, often used for access checks and state-based responses.
Example: only owner can set value using if-check plus an explicit revert if unauthorized.
Common mistake: silently failing when a condition is false. Prefer explicit errors.
Key Takeaway

Always pair conditional decisions with clear failure behavior so callers understand outcomes and gas is handled predictably.

Code Example
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract ConditionalExample {
    uint256 public value;
    address public owner;

    constructor() {
        owner = msg.sender;
        value = 100;
    }

    function setValue(uint256 _newValue) public {
        if (msg.sender == owner) {
            value = _newValue;
        } else {
            // prefer explicit errors like require or revert instead of silent failure
            revert("Caller is not the owner");
        }
    }
}
Pro tip: prefer require for simple preconditions.
Check your assumptions: who can call this function?
