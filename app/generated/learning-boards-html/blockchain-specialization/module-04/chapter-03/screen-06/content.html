Module 4 › Chapter 4.3 › For Loops & Gas
Pattern
Bounded iteration
Use for loops for small fixed-size collections or batch processing with explicit limits to control gas usage.
Example: constructor populates a small array with five numbers using a for loop.
Warning: iterating over a dynamic, growing array in one transaction risks hitting the block gas limit.
Real-world connection

When writing payouts or mass updates, design for users to pull funds or employ paginated batches to avoid failures as collections grow.

Code Example
uint256[] public numbers;

constructor() {
    for (uint256 i = 0; i < 5; i++) {
        numbers.push(i + 1); // numbers will be [1,2,3,4,5]
    }
}

function sumNumbers() public view returns (uint256 total) {
    total = 0;
    for (uint256 i = 0; i < numbers.length; i++) {
        total += numbers[i];
    }
}
Pro tip: cap lengths or require limits for on-chain loops.
Alternative: use events to record items and process them off-chain.
