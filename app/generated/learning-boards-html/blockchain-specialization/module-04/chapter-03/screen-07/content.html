Module 4 › Chapter 4.3 › While Loops
Use Case
Deterministic pure computations
While loops can implement countdowns or algorithmic steps when the iteration count is predictable and small.
Example: a pure function that decrements a counter until zero and returns the result.
Misuse: never drive a while loop with a dynamic user list or external calls that could grow unbounded.
Code
function countdown(uint256 start) public pure returns (uint256) {
    uint256 current = start;
    while (current > 0) {
        current--;
        // pure calculation, safe when start is small
    }
    return current; // will return 0
}
Pro tip

Prefer while for off-chain computations or small pure functions; avoid on-chain loops with unpredictable length.
