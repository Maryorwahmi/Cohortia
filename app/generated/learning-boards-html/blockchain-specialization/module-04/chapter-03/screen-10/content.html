Module 4 › Chapter 4.3 › Custom Errors
Why use custom errors?
Gas efficiency and structure
Custom errors let you revert with typed, parameterized error types rather than long strings, saving gas.
Example: error InvalidAmount(uint256 provided, uint256 required) gives precise context with lower gas cost.
Compiler note

Custom errors require Solidity 0.8.4 or newer. They are best used where revert messages are frequent or parameterized.

Code
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.4;

contract CustomErrorExample {
    address public owner;

    error NotOwner();
    error InvalidAmount(uint256 provided, uint256 required);

    constructor() { owner = msg.sender; }

    function doSomethingOnlyOwnerCan(uint256 _amount) public {
        if (msg.sender != owner) revert NotOwner();
        if (_amount == 0) revert InvalidAmount({provided: _amount, required: 1});
        // logic
    }
}
Pro tip: custom errors make logs easier to parse in indexers and testing frameworks.
