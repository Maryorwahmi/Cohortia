Module 4 › Chapter 4.3 › Integer Safety
Behavior
Automatic checks in modern Solidity
Solidity 0.8+ reverts on overflow and underflow. This prevents many common errors automatically.
Use default checked arithmetic unless you need micro-optimized loops.
If using unchecked blocks, document why and add tests for boundary values.
Practical check
For counters, balances, and critical arithmetic, prefer checked operations. Only profile and then opt into unchecked when you can prove it’s safe and beneficial.
Quiz question: Why would an unchecked block be dangerous in a token transfer function? Consider wrap-around risk if amounts are attacker-controlled.
