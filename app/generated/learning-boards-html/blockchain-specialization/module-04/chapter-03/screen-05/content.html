Pattern
Multi-way decisions
Use else if to test descending thresholds so only one branch runs and outcomes are predictable.
Example: return status text from a view function based on numeric ranges.
Misconception: Strings in require are costly in storage; prefer compact errors when reverting state.
Check your understanding

Why would you test the highest threshold first rather than the lowest? Think about matching precedence.

Code
function checkValueStatus() public view returns (string memory) {
    if (value > 200) {
        return "Value is high";
    } else if (value > 100) {
        return "Value is medium";
    } else {
        return "Value is low";
    }
}
Pro tip: keep thresholds clear and document units.
Real example: fee tiers based on numeric thresholds use the same structure.
