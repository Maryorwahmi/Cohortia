Module 4 › Chapter 4.1 › Data Types
Type Reference
uint / uint256 — unsigned integer for balances and counts.
int / int256 — signed integer when negative values are required.
bool — true or false flags for logic branches.
address — 20-byte Ethereum address for accounts and contracts.
bytes / bytes32 — binary data, fixed or dynamic.
string — UTF-8 text, costly to store on-chain.
Comparison: When to use which
Balances: uint256 — never negative.
Flags: bool — simple true/false checks.
Identity: address — for ownership and transfers.
Data blobs: bytes32 or bytes for binary; string only if user-facing text is necessary.
Common misconception: Using int for balances avoids negatives — actually it allows negatives and can introduce logic errors. Use uint for non-negative quantities.
Key Takeaway

Choose types by intent: correctness first, gas efficiency second. Prefer uint256 for balances and address for accounts.
