Module 4 › Chapter 4.1 › Contract Structure
Typical .sol anatomy
Pragma: selects compiler versions.
Contract: declares state and functions.
Constructor: runs once at deployment for initialization.
Functions: view reads are gas-free off-chain; setters write state and cost gas.
Misconception: Constructor can be called later — false. It only executes during deployment.
Key Takeaway

Map file sections to lifecycle: deploy-time initialization, read-only observations, and transactional updates.

Concrete example: Greeter
State:
string public greeting;
Constructor:
constructor(string memory initialGreeting) { greeting = initialGreeting; }
Functions:
getGreeting() public view returns (string memory)
setGreeting(string memory newGreeting) public
