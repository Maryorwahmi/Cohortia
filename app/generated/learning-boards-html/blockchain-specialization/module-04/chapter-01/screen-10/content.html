// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract Greeter {
    string public greeting;

    constructor(string memory _initialGreeting) {
        greeting = _initialGreeting;
    }

    function getGreeting() public view returns (string memory) {
        return greeting;
    }

    function setGreeting(string memory _newGreeting) public {
        greeting = _newGreeting;
    }
}
Example

Deploy with constructor argument "Hello Cohortia Learners!" Then call getGreeting and setGreeting to observe differences between off-chain reads and state-changing transactions.

Remix steps
  1. Create Greeter.sol in File Explorer.
  2. Paste code and set pragma if needed.
  3. Open Solidity Compiler plugin and select matching version.
  4. Compile, then open Deploy & Run Transactions and choose JavaScript VM.
  5. Pass initial greeting as constructor argument and click deploy.
Common misconception: Calling getGreeting from the UI always costs gas. It does not when invoked as a view off-chain; only state-mutating calls cost gas.
Key Takeaway

Hands-on compilation, deployment, and interaction reveal how contract initialization and state changes actually behave on-chain.
