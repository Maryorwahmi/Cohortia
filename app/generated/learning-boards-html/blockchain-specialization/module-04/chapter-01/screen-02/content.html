Learning Objectives
Progress from comprehension to applied deployment
Bloom: Learn → Understand → Apply → Master
01
Explain Solidity & EVM

Describe how Solidity compiles to EVM bytecode and why gas matters for execution and costs. Knowing the runtime model helps you design efficient contracts.

VERIFIED COMPETENCY MILESTONE
02
Use Remix IDE

Set up a file, select a compiler that matches your pragma, deploy to the JavaScript VM, and interact with contract functions to observe state and transactions.

VERIFIED COMPETENCY MILESTONE
03
Identify data types

Recognize when to use uint, int, bool, address, bytes, and string. Choose types that minimize cost and avoid negative-value risks for balances.

VERIFIED COMPETENCY MILESTONE
04
Variable scope

Differentiate state variables that persist and cost gas when changed from local variables that are temporary and cheaper to use for calculations.
