Module 4 › Chapter 4.1 › Compilation & Gas
Compilation Steps
  1. Source code is parsed and type-checked by the compiler.
  2. Compiler emits EVM bytecode and an ABI for function calls.
  3. Deployment stores bytecode on-chain; constructors run during deployment.
Why gas differs
  • Memory reads are cheap; storage writes are expensive.
  • Loops with storage writes compound cost per iteration.
  • Contract size increases deployment gas.
Concrete example
Compare: Setting state variable balance = balance + 1 costs storage write gas. Computing temp = balance + 1 and returning it without writing is cheaper.
Common mistake
Assuming compiler will remove redundant writes. Always review and avoid unnecessary assignments to state.
Key Takeaway

Measure gas for common operations and refactor to reduce storage writes and heavy loops.
