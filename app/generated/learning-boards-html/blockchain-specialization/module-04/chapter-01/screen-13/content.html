Step-by-step
  1. Create Greeter.sol and paste the sample contract.
  2. Set pragma and compile in Solidity Compiler until green check.
  3. Open Deploy & Run Transactions, set Environment to JavaScript VM.
  4. Enter constructor argument in quotes and deploy.
  5. Call getGreeting to read the message, then call setGreeting to update state and observe a transaction.
Tip: Always include quotes for string constructor args in Remix to avoid type errors.
Verification checklist
  • Did the constructor initialize greeting correctly?
  • Does getGreeting return the initial value without a transaction?
  • Does setGreeting create a transaction and update the stored value?
Key Takeaway

Follow the checklist and confirm behavior. This hands-on loop solidifies how Solidity, compiler choice, and Remix interact during development.
