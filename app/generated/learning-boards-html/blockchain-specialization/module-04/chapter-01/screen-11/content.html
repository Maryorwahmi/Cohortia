Deploying to JavaScript VM
Step 1: Create Greeter.sol in File Explorer and paste code.
Step 2: Open Solidity Compiler, select version matching pragma, and compile.
Step 3: Open Deploy & Run Transactions, set Environment to JavaScript VM, pass constructor args, and deploy.
Step 4: Inspect deployed contract, call view functions, and send transactions to setters while observing the console output.
Notes & Mistakes
JavaScript VM is ephemeral — state resets on page refresh.
Constructor args must match types and be entered with correct syntax in the deploy field.
Deployment gas depends on contract size and constructor logic.
Key Takeaway

Use JavaScript VM for fast iteration, but validate on a testnet to approximate network behavior before production deployment.
