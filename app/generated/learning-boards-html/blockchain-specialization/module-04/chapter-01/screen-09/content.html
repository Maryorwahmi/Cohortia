Module 4 › Chapter 4.1 › State vs Local
State variables

Declared at the contract level and stored on-chain. Example: uint256 public counter; Changing it triggers a transaction and storage write.

Cost note: Storage writes are among the most expensive EVM operations.
Local variables

Declared inside functions and exist only during execution. Use memory and stack to compute values without persisting them.

Practice: Compute tempValue = counter + 1 and return it instead of assigning back to counter to avoid storage cost.
Check your understanding
Example A: increment() writes to state — requires gas.
Example B: calculate() returns a value without writing — cheaper for callers.
Key Takeaway

Avoid unnecessary state updates. Use local variables for temporary computations and view functions for free reads.
