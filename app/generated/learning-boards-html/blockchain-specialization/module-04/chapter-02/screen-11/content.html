Module 4›Chapter 4.2›Remix Lab

Step-by-step

  1. Paste SimpleWallet.sol into Remix and compile with 0.8.x.
  2. Deploy using JavaScript VM; note the deployer address assigned to owner.
  3. With owner account selected, set VALUE to 1 Ether and call deposit. Inspect event logs.
  4. Switch account and call withdrawAll to observe a revert due to require(msg.sender == owner).
  5. Switch back and withdraw as owner; observe success and transfer success check.
Hints
Check the console for revert reason strings and gas used. Use getMyBalance as an off-chain call to see gas-free reads.
