Comparison

Who can call or read?

public

Accessible internally, externally, and by inheriting contracts. State variables get an automatic getter.

private

Only visible inside the defining contract. Use for sensitive helpers and internal-only data.

internal

Visible in the contract and by inheritors. Good for shared internal logic across a family of contracts.

external

Callable only from outside the contract. More efficient for large calldata arrays but cannot be invoked by internal calls.

Misconception check: external functions are not interchangeable with public for internal calls. If you try to call an external function as if it were internal, the compiler or runtime will not behave as expected.
Concrete example
uint256 private secretValue;
uint256 public publicValue;
uint256 internal internalValue;
function externalOnly(uint256 x) external pure returns (uint256) { return x * 2; }
Check your understanding

Which visibility prevents inheriting contracts from accessing a state variable? Answer: private. Why? Because only the defining contract has access.
