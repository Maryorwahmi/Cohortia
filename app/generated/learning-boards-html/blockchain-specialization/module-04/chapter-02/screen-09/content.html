Key functions

constructor() { owner = msg.sender; }

function deposit() public payable {
  require(msg.value > 0, "Deposit amount must be greater than zero");
  balances[msg.sender] += msg.value;
  emit Deposit(msg.sender, msg.value, block.timestamp);
}

function withdrawAll() public {
  require(msg.sender == owner, "Only the owner can withdraw");
  uint256 amountToWithdraw = address(this).balance;
  (bool success, ) = payable(owner).call{value: amountToWithdraw}("");
  require(success, "Withdrawal failed");
}
Explanation bullets
  • Constructor assigns owner via msg.sender — the deployer becomes the owner.
  • deposit is payable and updates balances[msg.sender] using msg.value.
  • withdrawAll restricts access and checks the low-level call success to avoid silent failures.
Key Takeaway

Always validate msg.value, attribute funds to msg.sender, and check transfer success to avoid lost funds.
