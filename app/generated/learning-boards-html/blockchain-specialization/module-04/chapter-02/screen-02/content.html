Learning Objectives

Learn → Understand → Apply → Master
VERIFIED PATH
01
Define functions

Write functions with typed parameters and return values to encapsulate logic and enable reuse. This improves readability and testability.

Mnemonic: clean signatures
VERIFIED COMPETENCY MILESTONE
02
Apply visibility

Choose public, private, internal or external to control who can call a function or read a variable. Minimizing exposure reduces risk.

Mnemonic: least privilege
VERIFIED COMPETENCY MILESTONE
03
Understand view vs pure

Know when a function reads state only or uses only inputs. Off-chain calls to view or pure are gas-free, which matters for UX and cost.

Mnemonic: read vs stateless
VERIFIED COMPETENCY MILESTONE
04
Use global variables

Work with msg.sender, msg.value and block.timestamp for access, payments and time logic. These are the runtime inputs your contract receives with each call.

Mnemonic: who, value, when
