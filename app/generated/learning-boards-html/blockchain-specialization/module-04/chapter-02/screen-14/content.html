Module 4›Chapter 4.2›Key Concepts
Function signatures
Typed inputs and clear returns make your API safe and testable.
Visibility
Use least privilege: private/internal for helpers, public/external for API.
Globals
msg.sender, msg.value and block.timestamp are essential runtime inputs; validate and use them carefully.
Final takeaway

Design functions as clear APIs, limit visibility, and treat global variables as inputs that must be validated to ensure correct and safe behavior.
