Module 4›Chapter 4.2›view & pure
Definition

Read-only and stateless functions

view

Can read state but must not modify it. Useful for queries like returning balances.

pure

Cannot read or modify state; operates only on inputs. Ideal for math helpers.

Misconception check: view does not imply zero gas in all contexts; only off-chain calls are gas-free. When included inside a transaction, these functions still consume gas as part of execution.
Examples
function getBalance() public view returns (uint256) {
  return balances[msg.sender];
}
function multiply(uint256 a, uint256 b) public pure returns (uint256) {
  return a * b;
}
Pro tip

Prefer pure for deterministic helpers; prefer view for reads. This signals intent to callers and auditors.
