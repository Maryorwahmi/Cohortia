Process Flow

Decide external vs internal

Step 1 — Identify callers

Will the function be called from other contracts or accounts? If yes, external/public is needed.

Step 2 — Inspect data size

Large arrays favor external for calldata efficiency; small arguments may not benefit.

Step 3 — Plan reuse

If internal reuse is required, implement logic in an internal function and expose an external wrapper if needed.

Example pattern
function doWorkExternal(uint256[] calldata items) external {
  require(items.length > 0);
  _doWorkInternal(items);
}
function _doWorkInternal(uint256[] memory items) internal {
  // shared implementation
}
Misconception: calling an external function from inside the same contract by using its name is not allowed; an explicit external call is needed and that adds overhead.
