Practice activities

Short verifiable steps you can perform in Remix to confirm each skill.

Function declaration test

Write a function that adds two unsigned integers and returns the sum. Compile and call it with sample inputs to confirm the return value.

Verification
Call the function in Remix and assert the returned value matches the expected total.
Visibility experiment

Change a helper function to private and attempt an external call. Observe compile-time or runtime failures.

Verification
A failed external call or missing getter confirms restricted access.
View / Pure check

Call a view or pure function from the UI and note that no gas is charged. Then call it in a transaction and note gas is consumed as part of the transaction.

Verification
Off-chain call shows no gas; on-chain transaction includes gas cost.
Globals & access

Deploy SimpleWallet, deposit funds from one account, then attempt withdrawal from another to observe the require guard.

Verification
A reverted withdrawal demonstrates msg.sender-based access control.
