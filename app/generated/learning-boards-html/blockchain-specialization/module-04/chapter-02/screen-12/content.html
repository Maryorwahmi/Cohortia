Design Pattern

Guard then delegate

  • Public/external entrypoint performs require(msg.sender == owner) or similar role checks.
  • Internal/private function contains the actual state changes and can be reused by inheritors.
  • Keep privileged state private when possible and expose controlled getters if needed.
Misconception: making everything internal is not a substitute for explicit permission checks on public APIs. Both patterns are complementary.
Pattern snippet
function withdrawAll() public {
  require(msg.sender == owner, 'Only owner');
  _withdrawInternal();
}
function _withdrawInternal() internal {
  // transfer logic and checks
}
Key Takeaway

Separate permission checks from implementation to make audits and reuse straightforward.
