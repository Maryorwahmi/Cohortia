Architecture

Transaction and block context

msg.sender
Who called the function

Use for ownership checks and per-caller state like balances.

msg.value
Amount sent with the call

Essential for payable functions and recording deposits.

block.timestamp
When the block was mined

Use for deadlines and vesting. Remember potential minor miner manipulation.

Concrete wallet snippet
constructor() {
  owner = msg.sender; // deployer becomes owner
}
function deposit() public payable {
  require(msg.value > 0, "Deposit must be > 0");
  balances[msg.sender] += msg.value;
}
Misconception check: block.timestamp should not be used for secure randomness. Small shifts can be introduced by miners so avoid relying on it for critical entropy.
