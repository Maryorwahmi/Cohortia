Core Concept

Inheritance via is

Derived contracts adopt public and internal members from base contracts. Use inheritance to centralize logic like ownership and modifiers.

// Base
contract Ownable {
  address public owner;
  constructor() { owner = msg.sender; }
  modifier onlyOwner() { require(msg.sender == owner, "Caller is not the owner"); _; }
}

// Derived
contract MyContract is Ownable {
  uint256 public value;
  constructor(uint256 _initialValue) { value = _initialValue; }
  function setValue(uint256 _newValue) public onlyOwner { value = _newValue; }
}
How it works
  • Derived contracts gain public and internal state and functions from the base.
  • Private members are not inherited; use internal when children need access.
  • Modifiers like onlyOwner standardize access control across many contracts.
  • Multiple inheritance is supported, but follow the linearization rules to avoid ambiguity.
Concrete example
MyContract is Ownable inherits owner and onlyOwner. Calling setValue by a non-owner will revert because onlyOwner requires the caller to match owner.
Key Takeaway

is enables safe reuse; design visibility and modifiers in the base to keep derived contracts small and auditable.
