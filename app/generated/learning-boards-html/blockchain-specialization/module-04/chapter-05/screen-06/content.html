Definition

Constructor chaining

When deploying a derived contract, base constructors must be executed so base state is initialized. Call bases explicitly when they accept parameters; otherwise the implicit call will apply only if there are no arguments.
contract Base { constructor(uint n) { /* set base */ } }
contract Derived is Base {
  constructor(uint n) Base(n) { /* derived init */ }
}
Why it matters

Missing a base constructor call can leave critical state like owner unset and break access control, tests, and security assumptions.

Common mistake

Assuming base constructors with parameters will be called implicitly. Always forward required arguments explicitly in the derived constructor signature.
