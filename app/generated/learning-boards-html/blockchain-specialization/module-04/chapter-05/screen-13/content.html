Question analysis
Which feature defines only the external functions needed to interact with an existing contract?
Answer: An interface
Reason: interfaces declare external function signatures without state or constructors, enabling safe calls to deployed contracts.
Constructor bug
If a base has a constructor with arguments and the derived does not forward them, base state remains defaults (e.g., zero for uint) and tests reveal incorrect initialization.
Fix: call Base(arg) in the derived constructor header so baseValue is set properly.
Common mistakes recap
  • Forgetting override when implementing or modifying base functions.
  • Expecting private members to be inherited; prefer internal for inherited access.
  • Trying to put state or constructors in interfaces.
