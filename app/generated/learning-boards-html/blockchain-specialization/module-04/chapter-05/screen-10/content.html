Module 4 › Chapter 4.5 › Libraries (brief)
Definition

Libraries

Libraries are for reusable, stateless functions that can be linked into or called by other contracts. They reduce duplication and centralize audited utilities.

Common pattern: using LibraryName for Type; to attach library functions to a type.
When to use
  • Stateless utility functions shared across many contracts.
  • Complex math or parsing logic that benefits from central auditing.
  • Cases where library linking reduces duplicate bytecode and gas.
Misconception
Libraries are not for managing shared mutable state; use base contracts when storage or ownership needs to be shared.
Key Takeaway

Favor libraries for stateless, audited utilities to improve reusability and reduce duplication across contracts.
