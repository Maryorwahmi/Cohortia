Lab Walkthrough

Deploy and test ManagedToken

Step checklist
  1. Create ManagedToken.sol and paste AccessControl + ManagedToken code.
  2. Compile with pragma ^0.8.0 and verify no errors.
  3. Deploy ManagedToken to JavaScript VM with args "MyToken","MTK"; note deployer address as owner.
  4. As deployer: call mint(deployer, 1000). Confirm balances(deployer) == 1000 and totalSupply() == 1000.
  5. Call transferOwnership(newOwner). Switch account and call owner() to verify change.
  6. As new owner: call mint(newOwner, 500). As old owner: calling mint should revert.
Testing tips
Use console logs or events to trace behavior, check the selected account in Remix before calling functions, and ensure constructor args match the deploy step.
Key Takeaway

This lab ties constructor chaining, inheritance, and modifiers to observable runtime outcomes: correct initialization and controlled access to minting.
