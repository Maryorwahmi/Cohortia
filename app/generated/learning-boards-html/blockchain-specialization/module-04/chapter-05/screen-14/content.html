Module 4 › Chapter 4.5 › Key Concepts
Inheritance (is)
Derived contracts adopt public and internal members from a base, enabling reuse and centralized modifiers.
Interfaces
Signatures-only contracts for interacting with external deployed contracts like tokens.
Abstract contracts
Blueprints that can include state and helper methods, requiring derived contracts to implement missing functions.
Summary takeaway

Choose interfaces for external APIs, abstract contracts for shared state plus enforced functions, and inheritance to reuse implementation and modifiers while minding visibility and constructor chaining.
