Inheritance and Interfaces

Build modular, reusable contracts and standard APIs. Learn patterns like Ownable, abstract blueprints, and ERC-style interfaces.

Focus: Use inheritance to share state and modifiers; use interfaces to call external contracts safely without knowing implementation details.

Outcome: You will be able to design a base AccessControl and a derived ManagedToken, implement abstract functions, and call a token through an interface.

Explore Key Topics
Inheritance (is)
Adopt state and behavior from a base contract using the is keyword for reuse.
Abstract Contracts
Define unimplemented functions as a blueprint for derived contracts to implement.
Interfaces
Declare external function signatures so your contract can call any compatible contract.
Concept preview
Ownable pattern
Provides an owner address and an onlyOwner modifier that derived contracts inherit to protect sensitive functions.
Interfaces (IERC20)
A contract can call a token's balanceOf and transfer by casting an address to the interface type.
Hands-on
Follow the ManagedToken exercise in Remix: compile, deploy, mint as owner, transfer ownership, and observe reverts for non-owners.
