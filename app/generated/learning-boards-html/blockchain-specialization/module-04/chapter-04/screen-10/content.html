Module 4 › Chapter 4.4 › Combining patterns: mapping → struct → array
Architecture

Mapping stores truth • Struct models entity • Array indexes IDs

mapping(uint256 => Product) public products;
uint256[] public productIds;

function addProduct(...) {
    // create product in mapping
    productIds.push(nextProductId);
}
Design choice

Decide whether the array is maintained on-chain for on-chain listings or produced off-chain via events and indexes.

Trade-offs
  • Extra array writes cost gas but enable on-chain iteration.
  • Events can provide off-chain indexing at lower on-chain cost.
  • Avoid copying fields across structures to prevent inconsistency.
Key Takeaway

Design the mapping-struct-array trio around where iteration will happen and how often writes occur to balance cost and functionality.
