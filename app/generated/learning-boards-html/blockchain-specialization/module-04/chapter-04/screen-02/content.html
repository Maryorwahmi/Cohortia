01
Use mapping for key-value storage

Store and retrieve values by a key type like address or uint; very efficient for direct lookups.

VERIFIED COMPETENCY MILESTONE
Mnemonic: Think 'dictionary' — fast lookup, no enumeration. Pair with an array to iterate.
02
Define and use structs

Group related fields into one type for clearer models like Product or Asset.

VERIFIED COMPETENCY MILESTONE
Mnemonic: 'Record card' — one struct equals one entity with named fields.
03
Work with arrays

Use fixed-size when length is known; dynamic arrays when items are added or removed at runtime.

VERIFIED COMPETENCY MILESTONE
Mnemonic: 'List manager' — use push, pop, and length carefully to avoid gas issues.
04
Choose data locations

Be explicit about storage, memory, and calldata for gas efficiency and correct semantics.

VERIFIED COMPETENCY MILESTONE
Mnemonic: 'Where matters' — storage persists, memory is temporary, calldata is cheapest for external reads.
