Module 4 › Chapter 4.4 › Mappings — definition and simple usage
Definition

mapping(Key => Value) VariableName

Mappings store key-value pairs. Keys are not enumerable, and lookups are efficient.

// mapping: address => uint256
mapping(address => uint256) public userBalances;

function setBalance(address _user, uint256 _amount) public {
    userBalances[_user] = _amount;
}

function getBalance(address _user) public view returns (uint256) {
    return userBalances[_user];
}
Example

Use a mapping to store balances so the contract can look up any address in constant time without scanning storage.

Common misconception

Attempting to iterate a mapping directly. You must record keys elsewhere if you need enumeration.

Visual
Mapping characteristics
  • Direct lookup by key.
  • Keys are not stored as an iterable list.
  • Values can be complex types.
  • Nested mappings allowed.
When to use

Ownership maps, registry tables, quick access patterns where iteration is not required on-chain.

Key Takeaway

Use mappings for fast, keyed access. If you need to list entries later, maintain an array of keys alongside the mapping.
