Module 4 › Chapter 4.4 › Key Concepts
Mapping
A key-value store for O(1) lookups. Keys are not enumerable; pair with arrays for iteration.
Struct
Group related fields into a single type. Use storage for persistent edits and memory for temporary copies.
Array
Ordered collection with push, pop, and length. Avoid full-array loops; use swap-pop for removals.
Final summary

Design contracts that use mapping for truth, structs for modeling, and arrays or events for listing while minimizing redundant state and gas-costly operations.
