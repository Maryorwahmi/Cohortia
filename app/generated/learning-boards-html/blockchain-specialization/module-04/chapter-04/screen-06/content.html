Struct example

Product struct pattern

struct Product {
    uint256 id;
    string name;
    uint256 price;
    address seller;
    bool available;
}

mapping(uint256 => Product) public products;
uint256 public nextProductId = 0;

function addProduct(string memory _name, uint256 _price) public {
    Product storage newProduct = products[nextProductId];
    newProduct.id = nextProductId;
    newProduct.name = _name;
    newProduct.price = _price;
    newProduct.seller = msg.sender;
    newProduct.available = true;
    nextProductId++;
}
Example

Create a Product record and store it in a mapping so you can find product metadata by ID quickly.

Misconception

Assigning one storage struct to another creates a reference, not a deep copy. Use explicit copying to avoid accidental state changes.

Patterns & tips
  • Use storage for in-place updates to structs from mappings.
  • Use memory when you only need a temporary snapshot for calculations.
  • Keep a separate ID array when you must iterate over products.
Key Takeaway

Structs model complex entities. Be deliberate about storage vs memory to control when state changes occur.
