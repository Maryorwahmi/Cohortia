Module 4 › Chapter 4.4 › Arrays — fixed-size vs dynamic
Fixed-size

uint256[5] fixedNumbers;

Fixed arrays reserve space and cannot change length. Use when size is known and stable.

Dynamic

uint256[] dynamicNumbers;

Dynamic arrays support push, pop, and length, but operations that iterate all elements may be gas-heavy.

// Safe removal using swap and pop
function removeByIndex(uint256 index) internal {
    uint256 lastIndex = items.length - 1;
    if (index != lastIndex) {
        items[index] = items[lastIndex];
    }
    items.pop();
}
Common mistakes & advice
  • Avoid attempting to iterate very large arrays in one transaction.
  • Deleting sets defaults but leaves gaps; decide whether gaps are acceptable.
  • Use events and off-chain indexing to avoid on-chain enumeration when feasible.
Key Takeaway

Choose array type for expected operations. Use swap-and-pop for efficient removals and prefer batched or off-chain iteration when arrays grow large.
