Question

Store user profiles and allow fast lookup by ID

Which combo best stores profiles containing name, wallet, and reputation for direct lookup by numeric ID?

// Correct pattern
struct UserProfile {
    string name;
    address wallet;
    uint256 reputation;
}
mapping(uint256 => UserProfile) public profiles;
Why mapping + struct
  • Direct lookup by id is O(1).
  • Struct groups related fields for atomic reads and writes.
  • Maintains a single source of truth and reduces inconsistency.
Key Takeaway

Mapping from id to a struct is the most efficient, clear, and consistent choice when you need direct profile lookup by ID.
