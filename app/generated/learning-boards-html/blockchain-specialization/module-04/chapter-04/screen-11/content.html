Pitfall: iterating large arrays

Avoid attempting to process a very large list in a single transaction; it can fail as arrays grow.

// Swap and pop removal pattern
function removeFromOwner(uint256 index) internal {
    uint256 last = ownerAssets[msg.sender].length - 1;
    if (index != last) {
        ownerAssets[msg.sender][index] = ownerAssets[msg.sender][last];
    }
    ownerAssets[msg.sender].pop();
}
Tip

Keep an id-to-index mapping if you must remove specific elements frequently to avoid scanning for the index.

Off-chain indexing

Emit events and let off-chain services construct lists and histories, keeping on-chain operations minimal and cheap.

Warning

Do not rely on on-chain iteration for growing datasets; design for batching or off-chain queries to avoid gas failure.
