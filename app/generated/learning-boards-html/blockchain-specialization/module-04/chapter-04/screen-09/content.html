Module 4 › Chapter 4.4 › AssetTracker walkthrough
Asset struct
struct Asset {
    uint256 id;
    string name;
    address owner;
    uint256 creationTimestamp;
}

mapping(uint256 => Asset) public assets;
mapping(address => uint256[]) public ownerAssets;
uint256 public nextAssetId = 0;
Create flow

Create Asset in storage and push id into ownerAssets for the creator. Emit AssetCreated event for off-chain indexing.

Transfer flow

Update the owner in the asset struct, push id to new owner's array, emit AssetTransferred. Removing id from old owner is more complex and often avoided in simple demos.

Practical notes
  • Events let off-chain indexers maintain lists without on-chain enumeration.
  • When removing IDs from owner arrays, plan for swap-and-pop or an index map to avoid heavy loops.
  • Be explicit about storage when mutating the asset struct so changes persist.
Key Takeaway

AssetTracker unites mapping, struct, and arrays. Use events and careful removal strategies to balance correctness and gas.
