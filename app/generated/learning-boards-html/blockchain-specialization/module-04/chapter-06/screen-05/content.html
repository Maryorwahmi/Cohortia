Module 5 › Chapter 4.6 › Declaring & Emitting Events
Syntax & Indexed Fields
Use event Name(params) and emit Name(args). Mark up to three params as indexed to enable off-chain filtering by those values.
Example events
event ValueChanged(address indexed _changer, uint256 _oldValue, uint256 _newValue, uint256 _timestamp);
event UserRegistered(address indexed _userAddress, string _username);
Concrete task
Add a Deposit event to a wallet contract and confirm the frontend filters logs by depositor address using the indexed field.
Event Example Walkthrough
When updateValue executes, emit ValueChanged with msg.sender, the old value, the new value, and block.timestamp. The indexed address lets explorers and DApps find all changes by a user.
Example call
Call updateValue with a new integer. Inspect transaction logs to view ValueChanged and confirm the indexed address matches the caller.
Key Takeaway

Events are cheap, searchable logs. Use indexed fields for values you will query often in UIs or analytics.
