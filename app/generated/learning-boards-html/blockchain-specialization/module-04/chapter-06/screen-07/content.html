Module 5 › Chapter 4.6 › Access Control
Why it matters
Functions that change balances, ownership, or call external contracts must be restricted to authorized actors to avoid theft or contract misuse.
Common mistake
Leaving withdraw or selfdestruct without onlyOwner protection allows any caller to perform privileged actions.
Pro tip

List all state-changing functions during review and ensure each has an explicit guard. Test both owner and non-owner paths.

Example check
Use a modifier like onlyOwner that requires msg.sender equals owner and apply it to withdraw or critical setters.
Modifier
modifier onlyOwner() { require(msg.sender == owner, "Caller is not the owner"); _; }
