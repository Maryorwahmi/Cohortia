Verification checklist
  • Emit event on actions and inspect transaction logs for expected fields and indexed filters.
  • Write tests that assert revert behavior for unauthorized calls to privileged functions.
  • Attempt a reentrancy attack in tests and confirm the safe function resists re-entry after state updates.
  • Simulate large arrays or repeated calls to observe gas limits and prefer pull payments where needed.
  • Include OpenZeppelin modules and run full unit tests to exercise edge cases before deployment.

SecureWallet lab
Deploy SecureWallet in Remix, call deposit to produce a Deposit event, then call withdraw and confirm Withdraw event and that only owner can withdraw.
