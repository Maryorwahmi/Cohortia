Module 5 › Chapter 4.6 › What is an Event?
Definition
An event is a Solidity log entry recorded in transaction receipts for off-chain clients to read.
Purpose
Notify UIs and analytics, store historical records cheaply, and enable efficient querying via indexed fields.
Misconception
Events are not a replacement for on-chain state. Logs are off-chain readable but not accessible to other contracts.
Key Takeaway

Use events to expose important actions cheaply and index up to three fields for efficient filtering.

Concrete Example
Declare ValueChanged and UserRegistered events, emit them on updates and registrations. Index addresses you will filter by, such as the changer or user address.
Example code (excerpt)
event ValueChanged(address indexed _changer, uint256 _oldValue, uint256 _newValue, uint256 _timestamp);
Check your understanding
If you need a frontend to react instantly to a user action, prefer emitting an event rather than polling state every second.
