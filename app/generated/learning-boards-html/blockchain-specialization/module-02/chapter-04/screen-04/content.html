Module 02 › Chapter 2.4 › What a Wallet Is
Definition

Wallet = Key manager, not a vault of coins

A wallet creates, stores, and uses private keys to sign transactions. The blockchain stores balances by address; the private key proves the right to spend from those addresses.
Analogy
Like a mailbox key: the mail is not in the key, but the key grants access to what's stored elsewhere.
Concrete example
A mobile wallet shows a balance because it holds private keys for addresses. The coins remain recorded on the blockchain at those addresses.
Common mistake
Treating exchange custody as equivalent to your own private key control—remember: custodial services hold the keys.
How derivation works
Private key → public key → address. The process is one-way. You can derive public data from the private key but not vice versa.
