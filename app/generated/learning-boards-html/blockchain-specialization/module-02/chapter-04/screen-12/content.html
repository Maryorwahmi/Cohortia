Module 02 › Chapter 2.4 › Security Best Practices
Core practices
  • Never share private keys or seed phrases.
  • Store seed phrases offline and in multiple secure places.
  • Use hardware wallets for significant holdings.
  • Enable authenticator-based 2FA on services.
  • Keep software and firmware updated.
Operational tips
  • Segregate daily spending balances from long-term storage.
  • Verify recipient addresses before sending large amounts.
  • Avoid storing seeds digitally where they can be exfiltrated.
Concrete example
A user enables authenticator 2FA on an exchange, moves 90% of funds to a hardware wallet with an offline seed backup, and keeps a small hot wallet balance for daily use.
Misconception
Relying solely on exchange security is insufficient for long-term storage. You retain responsibility for key custody when using non-custodial wallets.
Key Takeaway

Adopt layered defenses: physical safekeeping of seeds, device hygiene, reliable authentication, and operational separation of funds.
