Module 02 › Chapter 2.4 › Learning Objectives
01 Differentiate wallet types
Distinguish hot vs cold and software vs hardware wallets.
Understand security versus convenience trade-offs so you can choose the right combination for spending, savings, or institutional custody.
VERIFIED COMPETENCY MILESTONE
02 Explain keys and addresses
Describe how private keys derive public keys and addresses.
Knowing the one-way derivation clarifies why revealing public data doesn’t reveal secrets, and why private keys must remain private.
VERIFIED COMPETENCY MILESTONE
03 Understand seed phrases
How HD seeds and mnemonic phrases restore wallets.
Practice backing up and simulating a recovery to see how one phrase regenerates many addresses and why it must be stored offline.
VERIFIED COMPETENCY MILESTONE
04 Identify security best practices
Implement physical and operational protections for private keys.
Learn specific habits: hardware wallets for large holdings, 2FA on services, and safe seed storage off-line.
VERIFIED COMPETENCY MILESTONE

These objectives progress from understanding basic concepts to applying secure behaviours and recovering an HD wallet using a seed phrase. Each milestone maps to a small hands-on check you can perform safely with dummy data.
Objective extension
Recognize common scams and perform a safe simulated seed recovery. Practice checking recipient addresses and avoiding clipboard-based address swaps to build secure habits.
