Module 02 › Chapter 2.4 › Seed Recovery Activity
Step-by-step
  1. Generate or copy a dummy 12-word seed phrase offline and write it by hand.
  2. Open a compatible wallet in recovery mode and input the words in order.
  3. Observe generated addresses and test that sending to them would be possible.
  4. Repeat the restore on a second compatible wallet to see identical derived addresses.
This exercise teaches that the seed is the root of all keys; protecting it protects access to every associated address.
Safety rules
  • Do not use a real seed for testing.
  • Keep the dummy seed offline and destroy it after use if unnecessary.
  • Use only trusted, offline recovery tools for practice.
Reflection
After the activity, ask: if someone obtained this seed, what level of access would they have? How would you change your storage approach?
Key Takeaway

Practice recovery with dummy data to build confidence in your backup process and reveal weak points before real funds are at stake.
