Module 2 › Chapter 2.2 › Change Outputs
Calculation pattern
Sum your selected inputs. Subtract the payment amount. Subtract the chosen fee. The result is your change output amount.
Hand-check example
Input: 0.5 BTC. Payment: 0.3 BTC. Fee: 0.001 BTC. Change: 0.5 - 0.3 - 0.001 = 0.199 BTC.
Common mistake
If you omit the change output, the miner claims leftover value as extra fee. Wallets normally prevent this, but manual construction must include change explicitly.
Illustrative code-like panel
// Inputs: 0.5 BTC
// Payment: 0.3 BTC
// Fee: 0.001 BTC
change = inputs - payment - fee
// change = 0.5 - 0.3 - 0.001 = 0.199 BTC
This pseudo-walkthrough mirrors wallet calculations; always verify each numeric step before broadcasting.
Why input choice matters
Using many small UTXOs increases the transaction byte size, raising the fee you pay. Choosing a larger UTXO reduces size but may require more change outputs over time.
