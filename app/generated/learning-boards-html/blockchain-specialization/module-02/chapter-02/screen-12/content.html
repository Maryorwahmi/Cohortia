Scenario
UTXO A: 0.15 BTC. UTXO B: 0.08 BTC. Send 0.20 BTC to Sarah. Fee: 0.0001 BTC.
Step 1: Select inputs
Neither UTXO alone covers payment plus fee. Select both.
Step 2: Compute totals
Total input = 0.15 + 0.08 = 0.23 BTC
Step 3: Outputs & change
Payment = 0.2000 BTC, Fee = 0.0001 BTC, Change = 0.23 - 0.2001 = 0.0299 BTC
Verify and sign
Confirm 0.23 inputs = 0.20 payment + 0.0299 change + 0.0001 fee. Then sign each input with its private key before broadcasting. If a UTXO is already spent, replace it with a valid one and re-calculate totals.
Why this matters
Accurate arithmetic and proper signatures prevent accidental loss and ensure the network accepts your transaction.
Check question
If one UTXO were already spent, which step would you repeat first? (Answer: re-evaluate input selection and totals.)
