What Script does
Defines the unlocking conditions for an output in a restricted, stack-based language. Most users interact only with common patterns like pay-to-public-key-hash.
P2PKH: Standard pay-to-public-key-hash locking to an address.
Multisig: Requires multiple signatures to unlock an output.
Timelock: Prevents spending until a specified time or block.
Practical notes
Complex scripts increase transaction size and cost. They also change validation steps: nodes must evaluate the script and confirm it returns a valid result before accepting a spend.
Misconception: Script is not for arbitrary computing. It's intentionally limited to ensure deterministic, safe validation.
