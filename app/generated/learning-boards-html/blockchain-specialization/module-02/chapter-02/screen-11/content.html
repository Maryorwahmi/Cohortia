Module 2 › Chapter 2.2 › Common Mistakes
Mistake checklist
  • Missing change output — leftover becomes a fee.
  • Fee too low — transaction stuck or dropped.
  • Missing or invalid signature — transaction rejected.
  • UTXO fragmentation — many inputs raise fees.
Debug routine
Start by verifying the UTXOs referenced are unspent, confirm signatures exist for each input, and check the numeric balance of inputs versus outputs plus fee.
Concrete example
You spend a 0.7 UTXO to send 0.5 with a 0.0002 fee. If you forget change, the miner would receive 0.1998 as fee instead of you receiving 0.1998 back. Always include the change output explicitly.
Pro tip
Use wallet fee estimation and review raw transactions only when you understand each field. For advanced fee control, adjust satoshis-per-byte rather than absolute fee alone.
