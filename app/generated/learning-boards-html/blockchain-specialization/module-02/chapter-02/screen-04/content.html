Module 2 › Chapter 2.2 › UTXO Model
Definition
A UTXO is a discrete output from a previous transaction that remains unspent and can be referenced as an input in a new transaction.
Analogy: Bills in a wallet — each bill is a UTXO you can spend whole.
Implication: You cannot split a UTXO without creating a change output.
Misconception: There is no single mutable account balance to edit; UTXOs are discrete.
Example
You receive two UTXOs: 0.2 and 0.3 BTC. To send 0.4 BTC you select both UTXOs, create an output to the recipient for 0.4 and a change output for the remainder minus fee.
Key Takeaway
Treat coins as separate pieces; wallets manage UTXO selection to optimize fees and privacy.
Visual breakdown
UTXO
Value, originating txid, index — unspent until referenced.
Input
References a UTXO and includes a signature proving ownership.
Output
Creates a new UTXO with amount and recipient address.
Fee
Inputs minus outputs equals miner fee for inclusion.

If you spend a 0.7 UTXO to pay 0.5 with a 0.0002 fee, what is the change returned? (Do the subtraction to verify inputs = outputs + fee.)
