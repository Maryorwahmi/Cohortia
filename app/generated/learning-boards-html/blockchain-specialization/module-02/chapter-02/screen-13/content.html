Change address behavior
Most wallets create a new change address for each transaction to avoid address reuse. This helps privacy but increases UTXO fragmentation.
UTXO consolidation
Consolidate multiple small UTXOs during low-fee windows to reduce future transaction sizes. Remember consolidation itself costs a fee, so time it well.
Privacy trade-offs
Fresh change addresses help, but chain analysis can still link transactions. Avoid combining funds from many sources if you require strong unlinkability.
When to consolidate
Choose low-fee times and avoid consolidating if it will harm privacy. Use consolidation strategically, not routinely.
