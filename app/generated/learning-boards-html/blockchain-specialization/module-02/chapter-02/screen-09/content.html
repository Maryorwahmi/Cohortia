Module 2 › Chapter 2.2 › Validation & Double-Spend
Validation checks
  • Inputs must reference an existing UTXO in the node's UTXO set.
  • Each input must include a valid signature for the referenced output.
  • The sum of inputs must equal sum of outputs plus fee.
  • Scripting rules must be satisfied for special outputs.
Why double-spend fails
Once a transaction is confirmed, the UTXOs it consumed are removed from the UTXO set, so any later transaction attempting to spend them will be invalid.
Debug checklist
If your transaction is rejected, first check that referenced UTXOs are unspent. Next, verify signatures are present and correspond to the original receiving addresses. Finally, confirm outputs add up correctly with the intended fee.
Example question
You see two transactions spending the same UTXO. What determines which one becomes final? (Answer: the one included in the blockchain by miners first and the chain rules that follow.)
