Module 2 › Chapter 2.2 › Transaction Anatomy
Step-by-step
  1. 1. Select UTXOs. Choose enough discrete outputs to cover payment plus planned fee.
  2. 2. Create outputs. One to the recipient and one change output back to you for any remainder.
  3. 3. Sign inputs. Each input needs a signature proving the private key controls the spent UTXO.
  4. 4. Broadcast and validate. Nodes verify unspent status and signature correctness before relaying.
  5. 5. Miner inclusion. Miners pick transactions by fee priority and include them in blocks.
Worked example
You hold UTXOs: 0.2 and 0.3 BTC. Goal: send 0.4 BTC. Fee chosen: 0.001 BTC. Build outputs: 0.4 to recipient, change output of 0.099 back to your address. Sign both inputs with their respective private keys, then broadcast. Nodes will check inputs are unspent and that the sum of inputs (0.5) equals outputs (0.499) plus fee (0.001).
Inputs
References to previous UTXOs and signatures.
Outputs
Recipient amounts and the change output.
Fee
Inputs minus outputs; paid to the miner.
Common mistake
Forgetting a change output implicitly increases the fee because the leftover value has no assigned output and miners collect it. Always verify outputs include change when inputs exceed the payment.
