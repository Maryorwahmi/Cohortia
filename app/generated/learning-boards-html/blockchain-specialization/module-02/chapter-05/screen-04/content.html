Altcoin — definition and origin
A practical description that separates clones from platform-level changes.
Definition
Any cryptocurrency other than Bitcoin. Can be a fork, an alternative architecture, or a new platform with distinct goals.
Concrete Example
Ethereum: an altcoin that functions as a programmable platform enabling smart contracts and DApps, not just a payment token.
Common Misconception
Not all altcoins are trivial Bitcoin copies. Many introduce novel consensus or programmability that change trade-offs and use cases.
Key Takeaway

Altcoins extend or alter Bitcoin's design. Identify whether a project is a fork, a new architecture, or a platform to understand its purpose.

Origin Story
Many altcoins began by copying Bitcoin's code and altering parameters. Forks can be soft or hard and can result in independent communities and tokens.
Fork Example
Litecoin changed block time and hashing algorithm to enable different mining dynamics.
Fork Example
Bitcoin Cash increased block size to improve throughput at the protocol level.
Reflection
Ask: does this altcoin change rules, add execution capabilities, or both? The answer guides its likely use cases and trade-offs.
