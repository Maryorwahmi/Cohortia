Module 3 › Chapter 2.5 › Governance and Platform Tokens
Two token roles
Understand economic and governance differences that affect long-term success.
Platform Token
Secures execution and pays fees. Example: Ether is used to run smart contracts and compensate validators.
Governance Token
Grants voting rights over protocol changes or treasury. Example: tokens that decide on upgrades or parameter changes for a DeFi protocol.
Concrete Example
A project issues governance tokens to fund and vote on feature roadmaps. The token's power matters only if holders actively participate and if voting is balanced to avoid capture.
Misconception
Governance tokens do not guarantee fair governance. Token distribution and voter turnout determine whose interests are represented.
Reflection
Ask: who holds voting power, and how are incentives aligned to support long-term protocol health?
