What happens on receipt
A node checks transaction validity, recomputes the merkle root, and hashes the block header once to confirm the Proof-of-Work meets the current target.
Why this is efficient
Verification needs one hash plus transaction checks, far less work than mining, enabling many nodes to participate in consensus.
Concrete flow
Miner finds nonce → broadcasts block → peers verify header hash once → peers add block and relay it → miners build atop the new tip.
Misconception
Nodes do not need to repeat the heavy search; they only perform a single verification hash and transaction checks.
Key takeaway
Fast verification enables wide participation and quick convergence on the same blockchain state.
