Module 2 › Chapter 2.3 › Difficulty Adjustment
Adjustment process
Every 2,016 blocks the network computes how long those blocks took and scales the target difficulty so the next period moves toward a ten-minute average.
If blocks are fast
Increase difficulty so miners must expend more work per block.
If blocks are slow
Decrease difficulty so block production speeds up.
Concrete scenario
Suppose powerful new miners join and block times drop to seven minutes. After the next 2,016 blocks, the target will be tightened so hashes must be lower to be valid, restoring the ten-minute pace on average. This keeps issuance predictable despite hardware churn.
Misconception
Difficulty adjustments do not redistribute past rewards; they only change future mining effort required.
Key takeaway
Difficulty is the protocol's feedback control to keep block timing and issuance steady as mining power changes.
