Module 2 › Chapter 2.3 › Key Concepts
Nonce
A number miners change to produce new header hashes during the search for a valid output.
Target Difficulty
Numeric threshold that a header hash must be below; it adjusts to keep block time near ten minutes.
Coinbase Transaction
The first transaction in a block that creates the block reward and awards fees to the miner.
One-line summary

Nonce + hashing + target = PoW; coinbase ties issuance to successful work; difficulty self-adjusts to preserve cadence.
