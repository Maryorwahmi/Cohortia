Module 2 › Chapter 2.3 › Key Concepts
Mining
Validating transactions, bundling them into blocks, and attempting PoW to add a block to the chain.
Proof-of-Work
A puzzle requiring computational work so that producing blocks is costly while checking them is cheap.
SHA-256
The cryptographic hash used to produce block header fingerprints; sensitive and hard to invert.
Summary

These three terms form the core of Bitcoin's security model: miners perform PoW using SHA-256 so the network can cheaply verify a single agreed chain.
