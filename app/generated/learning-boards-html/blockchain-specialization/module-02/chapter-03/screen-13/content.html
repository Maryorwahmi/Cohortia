Module 2 › Chapter 2.3 › SHA-256 Properties
Key properties
  • Determinism: Same input, same output every time.
  • Preimage resistance: Hard to find an input for a given hash.
  • Collision resistance: Hard to find two inputs with same hash.
  • Sensitivity: Tiny changes produce entirely different outputs.
Concrete demonstration
Hash 'Cohortia Blockchain' and then hash 'Cohortia Blockchain.' with a period. The outputs will differ drastically, illustrating sensitivity and why a single-bit change invalidates a block's hash.
Misconception
SHA-256 is not encryption and does not hide transaction data; it provides a fingerprint for verification.
Key takeaway
SHA-256's unpredictability and resistance properties are central to the security of PoW and chain integrity.
