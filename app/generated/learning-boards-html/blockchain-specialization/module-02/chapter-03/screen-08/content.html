Module 2 › Chapter 2.3 › Nonce Simulation
Guided steps
  1. Open a SHA-256 calculator and set input to 'Cohortia Blockchain0'. Hash and record the output.
  2. Increment the nonce to 'Cohortia Blockchain1', hash again, and compare the result.
  3. Repeat until you find an output that meets a toy target, such as starting with '0'.
  4. Change a single character in the base string, re-hash, and notice the entirely different output.
Note
This activity is conceptual; real Bitcoin targets require vast compute power and many leading zeros.
Reflection
You will experience firsthand why miners use optimized hardware and why verification remains a single, cheap hash check for every node.
Common error
Expecting the hash outputs to change gradually. In practice they appear random across attempts.
Key takeaway
The exercise shows brute-force searching for a nonce and the asymmetric cost of finding versus verifying.
