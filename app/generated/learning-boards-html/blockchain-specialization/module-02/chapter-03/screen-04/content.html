Module 2 › Chapter 2.3 › From Mempool to Block
Step-by-step block assembly
1. Gather from mempool
Select unconfirmed transactions, preferring higher fees and valid scripts.
2. Create coinbase
Add a special transaction that awards the block reward and claims fees.
3. Build header
Include previous hash, merkle root, timestamp, and a nonce placeholder.
4. Start PoW
Iterate nonces until the header hash is below the target difficulty.
Concrete example
Imagine a miner selects ten transactions totaling 0.003 BTC in fees. They create a coinbase awarding 6.25 BTC plus those fees to their address. The resulting header binds the chosen transactions via the merkle root. Any change to the transaction set changes the header hash completely, so miners rarely change the assembled set during intensive nonce searching.
Common misconception
Miners cannot cheaply rework many blocks because each header ties to the previous block hash, making deep changes costly.
Key takeaway
Block assembly is both a revenue optimization and a technical prerequisite for an efficient nonce search.
