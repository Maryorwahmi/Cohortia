Skills & Practices
These competencies turn upgrade and ops principles into repeatable steps for real projects.
Upgrade Workflow
Scripted UUPS or proxy upgrades
Practice deploying implementation contracts, running upgrade scripts, and confirming state is intact after upgrade.
Maintenance Routines
Monitor subgraphs, nodes, and frontends
Set alerts for indexing delays, RPC errors, and UI deployments so users never see outdated data.
Scaling Judgment
Match L2 choice to use case
Decide between optimistic or ZK rollups, sidechains, and channels based on finality and cost needs.
Security & Governance
Incident response and DAO controls
Prepare emergency plans, pausing mechanisms, and community approval flows for upgrades to maintain trust.
