Deploying a UUPS Proxy and Upgrading Safely

Follow the terminal steps and verify state preservation. Use multisig or DAO control for upgrade authorization.

Terminal: Example Commands
// Compile and deploy proxy
npx hardhat run scripts/deployProxy.js --network local
// Initialize and check value
await proxy.initialize(ownerAddress)
// Interact then upgrade
npx hardhat run scripts/upgradeToV2.js --network local
// After upgrade, call new method
await proxy.multiply(3)
Checklist
  • Use Initializable and avoid constructors
  • Keep storage layout identical across versions
  • Secure upgrade authority with multisig / DAO & timelock
  • Test upgrades on a stateful testnet before mainnet
Common Mistake

Changing storage order between versions leads to corrupted state. Preserve variable order and types exactly.

Key Takeaway

Script your deployment, secure upgrade rights, and verify state before and after each upgrade. Document every step for auditability.
