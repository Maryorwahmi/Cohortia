Learning Objectives
Skills to configure, secure, deploy, verify, and host your DApp.
Bloom: Learn → Understand → Apply → Master
01
Configure Hardhat/Truffle
Set up network entries and write deployment scripts that target local, testnet, and mainnet environments. This ensures repeatable deployment behavior and predictable addresses.
VERIFIED COMPETENCY MILESTONE
02
Secure Private Keys
Use environment variables and .env files kept out of source control. Understand when to prefer hardware wallets or managed key services for production deployments.
VERIFIED COMPETENCY MILESTONE
03
Deploy and Verify
Run deployment scripts on a testnet, capture the deployed address, and use a block explorer plugin to verify source code for transparency and interaction.
VERIFIED COMPETENCY MILESTONE
04
Host the Frontend
Publish static assets to IPFS for decentralization or to a conventional host, and inject environment-specific contract addresses at build time.
VERIFIED COMPETENCY MILESTONE
Objective Summary

These objectives give you a safe, auditable path from development to production, emphasizing secret management, verification, and predictable builds.
