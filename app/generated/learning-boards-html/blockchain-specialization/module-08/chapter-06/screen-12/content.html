Module 8 › Chapter 8.6 › Gas & mistakes
Gas estimation essentials
Estimate gas before sending transactions and ensure deployer holds enough native currency to cover the worst-case gas usage for deployment.
Checks to run
  • Confirm chain ID and RPC URL are correct.
  • Query account balance and compare to estimated gas cost.
  • Use a testnet dry run before mainnet deployment.
Common mistakes
  • Hardcoding private keys into config files or commits.
  • Deploying to the wrong network because of a misconfigured RPC URL.
  • Expecting local results to exactly match mainnet behavior without accounting for gas and finality differences.
Pro tip
Automate pre-deploy checks in scripts: verify chain ID, confirm funds, and fail fast if thresholds are not met.
