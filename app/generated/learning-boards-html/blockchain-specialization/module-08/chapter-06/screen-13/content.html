Module 8 › Chapter 8.6 › Hands-on Activity
Activity checklist
  1. Create a .env with SEPOLIA_RPC_URL, PRIVATE_KEY, and ETHERSCAN_API_KEY and add .env to .gitignore.
  2. Update hardhat.config to load environment variables and add the sepolia network entry.
  3. Create scripts/deploy.js that gets a signer, logs address and balance, deploys Counter, and awaits confirmation.
  4. Run the deploy command for Sepolia, copy the deployed address, and run the verification task.
  5. After testing, rotate or remove any temporary private keys used for the lab.
Expected outcome
You will have a Counter contract deployed to Sepolia, its address logged, and a verified source on the explorer. This proves full end-to-end deployment and verification skills.
Key Takeaway

Use environment variables, perform a testnet deployment, verify on the explorer, and secure or rotate keys after the exercise.
