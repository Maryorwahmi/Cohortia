What to place in .env
RPC endpoints, private keys or mnemonics, and explorer API keys. Always add .env to .gitignore.
SEPOLIA_RPC_URL="https://sepolia.infura.io/v3/YOUR_PROJECT_ID"
PRIVATE_KEY="your_private_key_here"
ETHERSCAN_API_KEY="your_etherscan_key"
Why environment variables?
They let you parameterize the same config for multiple networks and keep sensitive values out of committed files. For production, consider hardware wallets or managed services.
Network entry pattern
Provide a url, accounts array built from the private key, and the chain ID to avoid mismatches.
Practical check
Before deploying, ensure that the accounts array is not empty and that the RPC URL is reachable; failing to do so is a frequent source of error.
