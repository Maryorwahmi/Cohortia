Module 8 › Chapter 8.6 › Hosting tradeoffs
Traditional hosting
  • Easy CI/CD and automatic HTTPS.
  • Fast CDN delivery and simple rollbacks.
  • Centralized availability, provider-managed.
IPFS hosting
  • Content-addressed immutable builds and censorship resistance.
  • Requires pinning and gateway resolution for stable access.
  • Best for verifiable builds and archival snapshots.
Practical hybrid
Many teams host on a traditional platform for production performance while also publishing a pinned IPFS copy for verification and archival purposes. Use environment variables so each build points to the correct contract address for the intended network.
