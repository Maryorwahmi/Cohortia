Module 8 › Chapter 8.6 › Run deployment
Command flow
Invoke the runtime with the --network flag to run your deploy script on the chosen network. Inspect logs and transaction hashes.
// Example command (visual):
// npx hardhat run scripts/deploy.js --network sepolia
// Expected outputs: deployer address, balance, deployed address, tx hash
Practical checks
  • Confirm transaction hash is mined on the target explorer.
  • Record the deployed address for frontend configuration and verification.
Terminal example
Copy the important lines into a deployment log so you can later verify the contract with the explorer.
After deploy
Use the recorded address to run a verification command and to inject into the frontend environment for that network.
