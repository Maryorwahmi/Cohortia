Module 8 › Chapter 8.6 › Hardhat deployment
Pattern explained
Signer provides account and balance. ContractFactory builds new instances. Call deploy and await confirmation.
Why await deployment?
If you attempt to interact with the contract before the block confirms, calls will fail. Awaiting the mined transaction is essential for deterministic flows and scripts that run sequentially.

Pitfall
Not checking the deployer balance or chain ID can cause failed transactions or accidental mainnet deployment.
