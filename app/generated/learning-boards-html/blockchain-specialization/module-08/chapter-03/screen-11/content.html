Module 08 › Chapter 8.3 › Errors & Mistakes
User rejections

Treat rejection as user choice

When a user rejects a transaction, catch the error and show a clear message like 'Transaction cancelled by user' instead of a generic failure notice.

Security

Never expose private keys

All signing must occur inside the user's wallet. Never copy or store private keys in the frontend.

Network guidance
If your DApp requires a specific network, show instructions or prompt the wallet to switch chains. Handle refusal gracefully and allow users to continue in a read-only mode where possible.
