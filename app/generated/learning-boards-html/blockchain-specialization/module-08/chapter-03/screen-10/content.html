Module 08 › Chapter 8.3 › Polling vs Events
Polling

Simple periodic refresh

Call view functions on a timer to refresh displayed values. Works well for demos and small apps but can create extra load.

Example: setInterval to call getCount every 5 to 10 seconds and update the UI.
Event Listening

React to contract events

Subscribe to contract events like Transfer and update UI only when events relevant to the user occur. Efficient but needs careful handling when the frontend was offline.

Example: contract.on('Transfer', (from, to, amount) => { if (to === user) fetchBalance(); })
Combined approach

Use events for immediate reactions and occasional polling to catch missed events while the user was offline. For production, consider a backend indexer if you must guarantee no missed updates.
