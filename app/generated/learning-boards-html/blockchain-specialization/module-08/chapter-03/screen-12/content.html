Activity: Connect and display contract data

Follow this step-by-step checklist to implement the demo DApp described in the chapter.

Step 1: Project setup
Create a React app and install Ethers.js. Compile and deploy the Counter contract and save the ABI and address.
Step 2: Connect wallet
Detect window.ethereum, create a provider, and implement a connect function that requests accounts and gets a signer.
Step 3: Read contract
Instantiate the contract with ABI and provider, call getCount, and display the returned value.
Step 4: Send transaction
Use the signer-backed contract to call increment, show pending UI, await tx.wait, and then re-fetch the count.
Expected outcome

A React DApp that shows a Connect Wallet action, displays the connected account and network, reads and displays the counter, and increments it via signed transactions.
