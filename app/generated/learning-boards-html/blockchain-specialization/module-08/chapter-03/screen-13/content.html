Architecture

Layered responsibilities

Wallet Layer
Provider and signer, event listeners for accounts and chain changes.
Contract Abstraction
ABI, addresses, helper functions to read and write in one place.
UI Layer
React state, loading indicators, transaction feedback, and error messages.
Optional Backend
Index events for historical queries, provide reliable feeds to the frontend, and avoid missed events when users were offline.
Design question

Which responsibilities will you keep in the frontend and which will you move to a backend indexer for reliability and performance?
