Module 08 › Chapter 8.3 › Account & Network Changes
Accounts

Update signer and account

When accountsChanged emits, set the new account and get a signer for that address. If accounts array is empty, treat it as a disconnect.

Example handling
If accountsChanged returns no accounts, clear account and signer state so UI shows a disconnected state and prompts the user to reconnect.
Chain

Respond to chainChanged

Reload the app or reinitialize network-dependent providers and contract instances. Notify users when they're on an unsupported network and guide them to switch.

UX Tip

Make network requirements visible early and show a clear error if the user is on the wrong chain to avoid accidental gas costs.

Cleanup
Remove event listeners on component unmount to avoid duplicated handlers and memory leaks. This keeps your app stable when users navigate between pages.
