Frontend Development for DApps

Make blockchain interactions clear, safe, and responsive for users by wiring provider, signer, contract calls, and state updates.

In this lesson
Detect provider, connect wallet, perform reads and writes, handle network and account events, and keep UI state synchronized.
Provider
An interface to the blockchain and user's wallet. Example: MetaMask.
Signer
Represents a connected account that can sign transactions and change state.
Read vs Write
View functions read state for free; state-changing functions require gas and a signature.
Key Takeaway

The frontend must separate provider roles: use a provider for reads and a signer for writes, and always show clear feedback when transactions are pending.
