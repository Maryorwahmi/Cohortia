Module 08 › Chapter 8.3 › Reading Contract Data
Definition

Call view/pure functions

Instantiate a contract with ABI and address, pass a provider, and call read-only methods to display on-chain data without gas.

Concrete example
Call getCount on a Counter contract using a provider-backed contract instance and convert the returned number to a string for display.
UI note
Always show a loading indicator while waiting for the provider to return data. Handle errors when the node is unreachable.
Key Takeaway

Reads do not cost gas and use a provider. Re-fetch after state changes so UI stays in sync with the chain.

Code example
// Reading with Ethers.js
const contract = new ethers.Contract(contractAddress, contractABI, provider);
try {
  const value = await contract.getCount();
  // convert to string for display
  displayCount(value.toString());
} catch (err) {
  setError('Error reading contract data');
}
This pattern works for any view or pure function. Keep the ABI correct and handle node or provider errors.
