Module 08 › Chapter 8.3 › Key Concepts
Provider vs Signer
Use provider for reads and signer for writes; obtain signer only after user connects.
Transaction UX
Show pending state, confirm after tx.wait, and handle user rejections clearly.
State Sync
Polling works for demos, events are efficient, and a backend indexer helps production reliability.
Summary

Keep provider and signer roles explicit, design clear transaction feedback, and choose the right state synchronization strategy for your app's needs.
