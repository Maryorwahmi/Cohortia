Module 08 › Chapter 8.3 › Sending Transactions
Process

Submit a state-changing call

  1. Ensure user has connected and you have a signer.
  2. Instantiate contract with signer for write operations.
  3. Call the state-changing method; the wallet prompts the user to sign.
  4. Receive transaction hash and await confirmation with tx.wait.
  5. Re-fetch on-chain data and update UI after confirmation.
Concrete example
Call increment on your Counter contract using contractWithSigner.increment(), alert or display the hash, and wait for confirmation before showing the updated count.
UX patterns

Communicate cost and latency

  • Show a pending indicator and transaction hash while waiting.
  • Explain gas costs before asking the user to sign.
  • Provide success or failure messages and allow retry on failure.
Common mistake

Do not update the UI immediately after sending; wait for confirmation or you risk showing inaccurate on-chain state.
