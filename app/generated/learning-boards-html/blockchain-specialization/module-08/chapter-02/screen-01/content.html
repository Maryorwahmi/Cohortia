Concept Map
State vs. Logic — Upgrade flow
Proxy (State)

Holds contract storage and address that users call. Remains stable during upgrades.

Logic (Implementation)

Contains business logic and can be replaced to fix bugs or add features.

UUPS Pattern

A minimal proxy plus implementation that can authorize its own upgrade, reducing proxy complexity and attack surface.
