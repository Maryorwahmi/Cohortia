Module 08 › Chapter 8.2 › Loop Refactor
Step-by-step

Refactor for fewer SLOADs

  1. Identify loop with repeated storage reads.
  2. Cache length and frequently-read values to local variables.
  3. Perform computations using memory variables.
  4. Write final results back to storage with one or few SSTOREs.
Example summary
Reading an array length into a local reduces repeated SLOADs inside the loop and lowers gas per iteration.
Concrete scenario
You have a function that walks an array of user records to compute a summary. Originally each iteration reads storage for the same element multiple times. After refactor, you copy the element to memory, compute, then set the aggregated value back once.
Check your work
  • Run gas reports before and after refactor.
  • Ensure logic remains correct and writes to storage where intended.
Key Takeaway

Small changes in loops compound — cache reads and avoid repeated storage access to reduce gas noticeably.
