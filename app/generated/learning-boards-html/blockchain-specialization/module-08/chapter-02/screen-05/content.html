Module 08 › Chapter 8.2 › Proxy Architecture
Process Flow

Proxy → Delegatecall → Implementation

A call to the proxy uses delegatecall so implementation code runs in proxy storage context.

UUPS pattern

Implementation contains the upgrade authorization and triggers the proxy to point to a new implementation address.

Storage gap

Reserve unused slots in base contracts to allow future variables without shifting existing slots.

Misconception
Upgrading changes storage automatically. In truth, code must be written to preserve layout; upgrades can corrupt state if layout changes unexpectedly.
Annotated Diagram
Proxy (state)

Holds owner, user balances, and persistent variables. Never call initialize on implementation directly after proxy deployment.

Implementation (logic)

Contains functions, including an authorize upgrade hook that must be secured to onlyOwner or an admin role.

Test checklist
  • Assert storage values persist through upgrade.
  • Confirm initialization not re-executed after proxied upgrades.
  • Verify only authorized account can upgrade.
