Pattern

initialize + _authorizeUpgrade

Initialization replaces constructors and upgrade authorization must be explicit and minimal.

// excerpt (visual only)
function initialize(uint256 initialValue) public initializer { ... }
function _authorizeUpgrade(address newImpl) internal override onlyOwner {}
Common mistake
Calling initialize on implementation leaves proxy uninitialized. Always point initialization at the proxy instance.
Deployment Steps
  1. Deploy implementation contract.
  2. Deploy ERC1967Proxy with implementation address.
  3. Call initialize on proxy to set owner and state.
  4. When ready, deploy new implementation and call upgradeTo via authorized flow.
Pro tip
Add upgrade tests that try to upgrade from an unauthorized account and try to re-run initialization to ensure protections.
