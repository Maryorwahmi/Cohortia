Module 08 › Chapter 8.2 › Gas Optimization
Definition

Gas Optimization Fundamentals

Practical techniques to lower transaction fees by reducing on-chain computation and storage costs.

Minimize storage writes

Each storage write is expensive. Group writes and avoid redundant updates.

Use calldata

Calldata is cheaper than memory for external read-only parameters.

Cache storage reads

Load frequently-read storage into a memory local variable to avoid repeated SLOADs.

Concrete Example
Pseudo example — cache then write once
uint256 val = storageVar;
// work with val many times
storageVar = val; // single write
Misconception
Micro-optimizations without profiling can waste time. Measure gas to prioritize effort.
Key Takeaway

Profile and prioritize: cache reads, reduce storage writes, and prefer calldata for cheaper input handling.
