Module 08 › Chapter 8.2 › What to Remember
Error Handling
Use require for validations, revert for complex failures, and assert for invariants only.
Events
Emit logs for off-chain listeners so UIs and indexers can respond to state changes.
Natspec
Document intent, parameters, returns, and initialization so tooling and humans can understand contracts.
Final takeaway
Combine safe upgrade patterns, gas-aware code, clear access control, meaningful events, and Natspec to produce secure and maintainable smart contracts.
