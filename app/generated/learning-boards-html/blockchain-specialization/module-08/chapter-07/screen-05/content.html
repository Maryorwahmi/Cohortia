Architecture
Proxy pattern explained

A proxy holds the storage and forwards calls to an implementation contract. Upgrading swaps the implementation address so logic changes without losing state or changing the contract address.

UUPS
Upgrade authorization lives on the implementation; the implementation exposes a function to authorize upgrades.
Transparent Proxy
Separates admin calls from user calls to prevent selector collisions and accidental admin usage by users.
Example constraint

Never reorder existing state variables. When adding new variables, append them to keep storage slots aligned between versions.
