Definition
What monitoring covers

Monitoring combines on-chain event indexing with runtime metrics so you can detect failed transactions, gas anomalies, and suspicious interactions quickly.

  • Event counts and patterns for key functions
  • Transaction success vs failure rates and revert reasons
  • Gas usage distribution and sudden spikes
  • Unusual caller addresses or admin actions
Key Takeaway

Combine indexing for alerts with frontend telemetry to reduce detection time while respecting privacy.

Concrete example

Alert when failed transactions exceed 5x baseline for ten minutes, and surface the top caller addresses. Use an indexer to get event-level context for debugging.

Practical setup
  • Index events for core contracts and create alert rules.
  • Integrate a channel for alerts to the team and a public incident status page.
  • Log and retain transaction traces to speed debugging.
Common mistake: trusting explorer notifications alone. They are useful for lookup but not for proactive, correlated alerts.
