Definition
Integer Overflow / Underflow
When numeric operations exceed range and wrap, producing incorrect values that can be exploited.
Concrete example
If a balance is stored as an unsigned integer that wraps to zero after maximum, an attacker can manipulate transfers to produce an incorrect large or zero balance and withdraw more than rightful funds.
Mitigations
Use SafeMath on older Solidity, prefer Solidity 0.8.0+ which reverts on wrap, and add boundary unit tests.
Testing tip
Write tests for maximum and minimum values and for arithmetic sequences that approach wrapping boundaries.
Misconception check
Do not assume modern compiler default protects every arithmetic use. Know your compiler version and confirm behavior with tests and code reviews.
Concrete action
  1. Confirm compiler version for the project.
  2. For older compilers, add SafeMath and audit arithmetic sites.
  3. Add tests that assert expected behavior at numeric boundaries.
Key Takeaway

Treat arithmetic as security-sensitive. Verify compiler behavior and test edge cases to prevent wrapping attacks.
