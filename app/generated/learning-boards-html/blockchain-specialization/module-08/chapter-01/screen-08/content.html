Module 8 › Chapter 8.1 › Off-chain Components
Definition
Off-chain components perform tasks that are impractical or costly to run on-chain, such as indexing, heavy computation, or file storage orchestration.
Common off-chain roles
  • Indexers for fast queries and history aggregation.
  • Servers for complex computation or orchestration.
  • Decentralized storage gateways to pin IPFS content reliably.
Trade-off guide
Ask: does this need consensus-level enforcement? If not, off-chain may improve cost and responsiveness.
Concrete example
Use an indexer to list crowdfunding campaigns and compute totals from pledge events. The contract stays the single source of truth for balances, while the indexer provides a fast read model for the frontend.
Misconception: Off-chain equals centralization. Contrast: decentralized indexing services and pinned IPFS nodes can reduce single-point-of-failure while improving performance.
Pro tip: Design events specifically to support the indexer; emit concise events for critical state changes.
Common pitfall: Trusting unverified off-chain data. Always reconcile UI state with on-chain proofs for critical operations.
