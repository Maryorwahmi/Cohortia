Module 8 › Chapter 8.4 › Testing Pitfalls
Checklist to avoid pitfalls
  • Cover positive, negative, and edge cases.
  • Reset chain state between tests.
  • Mock oracles and third-party contracts in integration tests.
  • Verify event emissions and access control explicitly.
Example mistake
Sharing a contract instance between tests led to a passing test that depended on a previous mutation. The fix is to deploy fresh instances or snapshot/restore chain state.
Warning

Flaky tests erode trust. Prioritize deterministic setup and clear assertions.
