Module 8 › Chapter 8.4 › Environment & Safety
Local Network
Use Hardhat Network for deterministic, fast tests and snapshots for state reset.
Mocking
Mock oracles and external contracts so integration tests remain repeatable and isolated.
Key Safety Rule
Never use real private keys in tests or CI. Use ephemeral accounts or CI secrets with strict controls.
Recommended practice

Run full test suites locally, track gas changes with reporters, and gate merges with passing tests to prevent regressions.
