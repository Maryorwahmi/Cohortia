Module 8 › Chapter 8.4 › Gas Analysis
Capture gasUsed
After sending a transaction, await tx.wait() and inspect receipt.gasUsed. Store or log values for comparison across commits.
// example\nconst tx = await contract.increment();\nconst receipt = await tx.wait();\nconsole.log(`Gas used: ${receipt.gasUsed.toString()}`);
Reporter
Use hardhat-gas-reporter to generate per-test gas metrics and compare functions across the test suite. This helps prioritize optimizations.
Optimization tip
Refactor hotspots verified by gas reports. Avoid optimizing code paths rarely used; focus on frequently called functions.
