Polkadot architecture
Polkadot provides shared security via a Relay Chain and specialized parachains. This model lets chains optimize while reducing independent security burdens.
Relay Chain
Core chain that coordinates consensus and provides security for connected parachains.
Parachain
Independent chain with specialized logic that inherits Relay Chain security.
XCMP
Cross-Chain Message Passing protocol for secure inter-parachain communication.
Use case
A protocol requiring network-level guarantees for asset safety benefits from deploying as a parachain to inherit shared security instead of relying on an external bridge.
Key Takeaway
Polkadot’s shared security is a deliberate trade-off: parachains gain strong protection but operate within a common security umbrella.
