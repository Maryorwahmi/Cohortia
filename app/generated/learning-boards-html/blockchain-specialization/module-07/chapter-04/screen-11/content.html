Mock AMM on Hardhat
Sequence: deploy tokens → factory → router → add liquidity → swap.
Key steps
  1. Deploy MockERC20 tokens and note their addresses.
  2. Deploy MockUniswapV2Factory and create a pair for the tokens.
  3. Deploy MockUniswapV2Router, approve the router to spend tokens, and add liquidity.
  4. Swap tokens to observe reserve changes and balances.
Common mistake
Forgetting to approve the router or using expired deadlines will make transactions revert on the local node.
Example: ethers.js approval (visual)
// Visual snippet: approve router to spend tokens const tx = await tokenA.approve(router.address, ethers.constants.MaxUint256);
This visual shows the approve step: grant the router permission to transfer tokens from your account so addLiquidity and swap calls can succeed.
Key Takeaway

Local testnets let you validate interaction order, allowances, and resulting balances before moving to mainnet.
