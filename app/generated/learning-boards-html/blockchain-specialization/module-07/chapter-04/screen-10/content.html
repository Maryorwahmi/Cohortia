Decentralized Oracle Design
Nodes, sources, and aggregation patterns.
Key elements
  • Multiple node operators fetching independent sources.
  • Aggregation algorithms (median, trimmed mean) to resist outliers.
  • Incentives and staking to discourage bad behavior.
Practical example
A price oracle collects quotes from exchanges, applies a median aggregation, and publishes a signed update to the chain. Consumers trust this aggregated value rather than any single source.
Pro tip
Look for oracles that document their aggregation and list sources to assess independence and reliability.
Pitfall
Node diversity is not enough if all nodes pull from an identical, manipulable source.
Key Takeaway

Source diversity and robust aggregation are the most important properties of a secure oracle system.
