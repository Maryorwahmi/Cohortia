Definition › Zero-Knowledge Proofs
What is a ZKP?

A protocol where the prover demonstrates a statement is true while revealing no other information. The proof convinces the verifier but carries no secret data about the witness.

Analogy
Prove you're over a threshold without showing your exact birthdate.
Misconception
Zero-knowledge protects values in the proof, but external metadata can still leak identity if not addressed.
Example
Prove you hold enough tokens to vote without revealing the exact balance. The verifier checks the proof, not the balance itself.
Key Takeaway

ZKPs let you transform private data into public correctness without disclosure; design circuits to capture only the necessary claim.

Prover / Verifier
Prover knows the secret witness. Verifier checks the proof using a verification key and learns only that the statement is true.
Circuit idea
Represent the statement as arithmetic constraints so the prover can compute a proof that those constraints hold for a secret witness.
