Trusted Setup
Phase that generates SNARK parameters; must be run securely to avoid toxic waste.
Pedersen Commitment
A commitment that hides a value while still allowing arithmetic operations for validation.
Range Proof
A proof that a hidden numeric value lies within a specified range, ensuring non-negative balances.
Summary: treat these primitives as building blocks. Build secure ceremonies, audited circuits, and clear documentation about what remains private.
