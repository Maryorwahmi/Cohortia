Module 8 › Chapter 7.7 › Key Concepts
Decentralized Autonomous Organization
An organization governed by smart-contract rules and member voting.
Governance Token
A token granting voting rights and influence over DAO decisions.
Soulbound Token (SBT)
A non-transferable token tied to a wallet representing reputation or credentials.
Summary
These core concepts affect incentives, privacy, and governance. Use them to frame design decisions with attention to trade-offs.
