Module 8 › Chapter 7.7 › DAOs
Definition

A DAO is an organization governed by rules in smart contracts and controlled by members via on-chain voting.

Key elements
  • Governance tokens that grant voting rights.
  • Proposal lifecycle: create, vote, execute.
  • Incentives and game-theoretic vulnerabilities like whale influence.
Analogy
Think of a DAO as a cooperative where votes are weighted by tokens; the cooperative succeeds only if rules encourage broad, engaged membership.
Governance mechanics visualization
Proposal Flow
Create proposal → Token-weighted voting → Quorum check → Execute if passed.
Example
A DeFi protocol votes to adjust staking rewards; vote outcomes change on-chain parameters immediately after execution.
Common mistake
Low quorum or unrestricted proposal creation can let a few actors steer policy.
Key Takeaway

Design governance rules and participation incentives deliberately; tokens alone do not guarantee fair outcomes.
