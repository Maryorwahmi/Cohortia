Module 8 › Chapter 7.7 › Post-Quantum
Architectural patterns
  • Hybrid signatures combining classical and post-quantum proofs.
  • Key migration workflows and address upgrade paths.
  • Time-locked recovery to move funds when safe algorithms exist.
Testing and standards
Prefer vetted algorithms and gradual deployment on testnets before mainnet upgrades.
Concrete example
A hybrid transaction requires both an elliptic-curve signature and a post-quantum signature. Until the post-quantum part is widely trusted, funds remain protected by the classical scheme while the network gains experience with the new primitives.
Key Takeaway

Plan phased transitions with hybrid schemes and reversible migration steps; avoid ad-hoc swaps.
