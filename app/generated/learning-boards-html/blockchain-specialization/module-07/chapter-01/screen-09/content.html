Module 7 › Chapter 7.1 › Channels vs Sidechains
State Channels
Open a multi-signature contract on Layer 1, exchange signed off-chain messages instantly, close to settle final state.
Pros: near-zero fees in-session, instant interaction, low L1 usage.
Cons: limited to a fixed participant set and complex for many-party DApps.
Example: Lightning Network for Bitcoin, Raiden for Ethereum-style token transfers.
Sidechains
Independent chains with their own consensus connected via two-way pegs for asset transfer to the parent chain.
Pros: high throughput and custom features.
Cons: separate security model; assets may be at risk if sidechain validators behave badly.
Example: Polygon PoS started as a sidechain; Liquid Network for Bitcoin is another example.
Decision prompt

If interactions are private and repeated use channels. If general smart contract capability and throughput are required, consider sidechains but validate their security.

Common Mistake

Treating sidechain security as equal to the parent chain. Always evaluate validators and audit history.
