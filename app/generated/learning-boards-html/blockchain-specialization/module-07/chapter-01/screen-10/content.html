Module 7 › Chapter 7.1 › Integrating L2s
Practical steps
  • Point your provider to the L2 RPC and set the correct chain ID.
  • Use official bridge contracts or audited SDKs for deposits and withdrawals.
  • Poll L2 balances and block confirmations after a deposit.
  • Inform users of withdrawal windows and finality expectations.
Common mistake
Sending funds to a wrong network or unaudited bridge can cause irreversible loss. Always double-check endpoints in wallet UIs.
Example checklist
1. Configure ethers.js provider with L2 RPC URL and chain ID.
2. Verify the bridge contract address from official docs.
3. Deposit on L1, wait for L1 confirmation, then poll L2 for the credited balance.
4. For optimistic rollups, plan for the challenge period before accepting withdrawals.
Key Takeaway

Integration is as much about security checks and UX as it is about RPC wiring. Test on testnets first.
