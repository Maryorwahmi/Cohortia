Module 7 › Chapter 7.1 › Developer Objectives
Practical outcomes
  • Configure a Web3 provider for an L2 RPC endpoint and verify balances across chains.
  • Execute a testnet bridge deposit, wait for confirmation, and poll the L2 balance.
  • Interpret withdrawal finality differences and the security implications for user UX.
Safety mnemonic
Think: "Verify addresses, confirm contract sources, and audit bridge code or rely on audited official bridges only."
Common Mistake

Assuming every Layer 2 inherits full L1 security. Sidechains have separate validators and risk models.
