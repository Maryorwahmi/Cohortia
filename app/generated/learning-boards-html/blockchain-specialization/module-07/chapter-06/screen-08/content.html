Corda Design Principles
Privacy-by-design with legal and regulatory alignment for financial services.

Corda shares transactions only with the parties that need to see them, avoiding global broadcast. This reduces data exposure and simplifies compliance with confidentiality requirements.

Notaries provide uniqueness checks to prevent double-spend. They can be configured to avoid seeing transaction contents, maintaining confidentiality while preserving integrity.

CorDapps, written in Java or Kotlin, implement business logic and map ledger state to legal agreements, supporting enforceability.

Example
In an interbank trade, only the transacting banks and the notary see the settlement transaction; regulators can be added as observers when needed.
Common misconception
Notaries are not necessarily full network auditors; they can be set up to validate uniqueness without learning private payloads.
Key Takeaway
Corda is optimized for financial and regulated workflows where transaction-level privacy and legal mapping are central requirements.
