Module 7 › Chapter 7.6 › Corda Notaries
How Notaries Work
Uniqueness checks without unnecessary disclosure.
Submission
Parties build a transaction and request a notary check for input uniqueness.
Verification
Notary verifies inputs are unspent. It may do so using hashes or selective disclosure to avoid seeing payloads.
Decision
Notary signs the transaction if unique, allowing parties to record it; otherwise it rejects conflicting transactions.
Example
Two banks try to transfer the same asset. The notary grants uniqueness to the first valid request and rejects the conflicting one, preventing double-spend.
Design consideration
Choose single versus distributed notaries based on trust boundaries, throughput needs, and governance requirements.
Key Takeaway
Notaries protect integrity while enabling privacy; their architecture reflects governance tradeoffs between centralization and performance.
