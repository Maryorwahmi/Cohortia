Applied Objectives

These objectives focus on concrete build and verification skills for testnets and early prototypes.

01
Write and deploy ERC‑721
Use OpenZeppelin patterns and Hardhat to compile and deploy a simple mintable contract to a testnet.
VERIFIED COMPETENCY MILESTONE
02
Prepare and pin metadata
Upload images and JSON to IPFS and use the resulting CID as the token URI for minting.
VERIFIED COMPETENCY MILESTONE
03
Inspect tokens on a testnet
Verify ownership, tokenURI, and metadata visibility in a block explorer or marketplace testnet.
VERIFIED COMPETENCY MILESTONE
04
Assess economic and privacy tradeoffs
Recognize when tokenizing an asset adds value and when metadata exposure raises privacy or regulatory concerns.
VERIFIED COMPETENCY MILESTONE
