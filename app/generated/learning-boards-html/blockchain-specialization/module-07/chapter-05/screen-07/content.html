Definition

NFT metadata and URIs

Metadata is usually a JSON document that describes an NFT’s name, image, and traits and is referenced by the token URI stored in the contract.

Typical JSON fields
  • name: human name for the asset.
  • description: short textual description.
  • image: content address or URL to asset media.
  • attributes: array of trait objects used for rarity.
Persistence pattern
Pin media and JSON to IPFS or Arweave and then mint with the content address as tokenURI to ensure immutability and censorship resistance.
Example
tokenURI = ipfs://Qm...metadata_cid that contains name, image ipfs://Qm...image_cid, and attributes for the asset.
Common Mistake
Using centralized URLs for metadata leads to link rot and altered token displays.
Key Takeaway
Pin metadata and media to decentralized storage before minting to protect value and permanence.
