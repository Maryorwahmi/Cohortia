Core Concept

NFT: unique token + metadata

Non‑fungibility arises from uniqueness, provenance, and descriptive metadata that links a token to an asset.

Properties
  • Unique token identifier recorded on chain.
  • Immutable transfer history and ownership record.
  • Descriptive metadata gives the token its asset identity.
Concrete example
A virtual land parcel token with a tokenId, owner history, and metadata listing coordinates and an IPFS URI for the parcel image.
Why the distinction matters
If metadata is stored centrally, the token can become a broken link. If metadata is stored by content address, the token reliably points to the same content forever.
Key Takeaway

NFTs are ownership claims on chain; metadata stored decentrally is what preserves meaning and value.

Common Mistake

Treating the token as the media file instead of the pointer to metadata risks broken assets if hosting fails.
