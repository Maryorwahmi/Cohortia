Definition

ERC‑721 structure

A minimal set of functions and events that let external tools reliably read ownership and transfer tokens that are unique.

Core functions
  • ownerOf(tokenId) — returns the owner address for a token.
  • balanceOf(owner) — number of tokens an address owns.
  • transferFrom(from,to,tokenId) — move ownership.
  • approve(to,tokenId) — allow another address to transfer a token.
Developer considerations
  • Implement secure minting and restrict access as needed.
  • Decide metadata scheme: tokenURI per token or base URI.
  • Expect higher gas per unique token operation than multi‑token patterns.
Concrete example
A collectibles contract assigns tokenId 42 to a rare item, ownerOf(42) returns the holder, and tokenURI(42) points to a JSON describing the item.
Key Takeaway

ERC‑721 provides ownership primitives; metadata and persistence are separate design choices.
