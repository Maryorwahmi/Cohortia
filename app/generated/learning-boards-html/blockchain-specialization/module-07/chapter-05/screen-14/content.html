Key Concepts

Three compact reminders to guide design and evaluation.

NFT = Token + Metadata
The token is the identifier; metadata gives the asset its display and attributes.
Choose the right standard
ERC‑721 for one‑offs; ERC‑1155 for mixed inventories and batch operations.
Pin metadata
Use content addressing so token references remain immutable and censorship resistant.
Summary
Check token uniqueness, standard fit, and metadata permanence when building or evaluating NFTs.
