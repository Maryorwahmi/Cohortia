import hashlib

def calculate_hash(data_string):
    sha = hashlib.sha256()
    sha.update(data_string.encode('utf-8'))
    return sha.hexdigest()

block_data_v1 = """
Timestamp: 2023-10-27 10:00:00
Transactions:
  - Alice pays Bob 5 BTC
  - Charlie pays David 2 BTC
Previous Hash: 0000000000...
Nonce: 12345
"""

print("--- Version 1 Hash ---")
hash_v1 = calculate_hash(block_data_v1)
print(hash_v1)

# Modify one character in the transactions and re-run to compare hashes
Try this
Change a single digit in a transaction amount, re-run the script, and compare the two printed hashes to observe the avalanche effect.
What to observe
  • Hash length stays constant while output changes completely.
  • Small visible edit produces a completely different hash.
  • Hashes let nodes compare block integrity quickly without transferring full files.
Key Takeaway

Hands-on hashing turns abstract properties into an experiment you can repeat anytime to verify tamper detection.
