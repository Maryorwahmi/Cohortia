What is a cryptographic hash?

A deterministic function that maps input data to a fixed-size string. Small changes produce large, unpredictable changes in the output.

Property
Deterministic and one-way: you cannot recover the original input from the hash alone.
Property
Avalanche effect: a tiny change in input produces a drastically different hash.
Key Takeaway

Hashes let nodes verify that block contents have not been changed; a mismatch signals tampering without requiring every node to compare every byte manually.

Concrete illustration
Block data v1: Alice pays Bob 5
Hash v1: 9f2c... (different every run)
Block data v2: Alice pays Bob 6
Hash v2: a7b1... (completely different)
Note: hashes are fingerprints, not encryption. They detect changes; they do not hide content.
Common misconception
Hashing is not encryption. Hashes provide integrity checks, not confidentiality.
