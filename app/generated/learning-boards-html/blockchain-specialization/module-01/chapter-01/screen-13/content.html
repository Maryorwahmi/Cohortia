Module 1 › Chapter 1.1 › Hashing Activity
Checklist
  1. Paste the Python template into a script.
  2. Run it and save the printed hash as Hash A.
  3. Change one character in the transactions and re-run to get Hash B.
  4. Compare Hash A and Hash B; they should differ completely.
  5. Record your observation and what you changed for later discussion.
Why this works
Hash functions amplify small changes so the output changes unpredictably. That property is what makes tamper detection reliable and efficient.
Pro tip
Capture both the input block text and the hash outputs; keeping both makes your explanation more persuasive to others.
Key Takeaway

A simple local experiment demonstrates the foundational integrity property that supports blockchain immutability.
