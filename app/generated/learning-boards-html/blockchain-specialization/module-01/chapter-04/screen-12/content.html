Starter code (conceptual)
class Block:
    def __init__(self, index, transactions, timestamp, previous_hash, nonce=0):
        self.index = index
        self.transactions = transactions
        self.timestamp = timestamp
        self.previous_hash = previous_hash
        self.nonce = nonce
        self.hash = self.calculate_hash()

class Blockchain:
    def __init__(self):
        self.chain = []
        self.create_genesis_block()

    def add_block(self, transactions):
        latest = self.get_latest_block()
        new = Block(latest.index + 1, transactions, time.time(), latest.hash)
        self.chain.append(new)

    def is_chain_valid(self):
        for i in range(1, len(self.chain)):
            if self.chain[i].previous_hash != self.chain[i-1].hash:
                return False
        return True
Hands-on tasks
  1. Create the blockchain and print the genesis block.
  2. Add several blocks with sample transactions and display the chain.
  3. Run the validity check; then tamper a transaction and observe the failure.
Terminal expectations
When you add blocks, expect printed hashes and confirmations. After a tamper, is_chain_valid should return false and flag the index where linkage fails.
Key Takeaway
This simple lab reveals the chaining mechanism and gives practical intuition for why recomputing and consensus are costly defenses against tampering.
