Module 2 › Chapter 1.4 › Adding a Block
Pipeline steps
  1. Transaction collection by nodes.
  2. Transaction verification for signatures and funds.
  3. Block assembly and Merkle root computation.
  4. Consensus work (e.g., Proof-of-Work mining).
  5. Broadcast and network validation.
  6. Chain addition if valid.
Real-world timing note
Block finality and confirmation times vary by network and consensus mechanism; confirm when you need stricter finality guarantees.
Terminal-style summary
Candidate block built with valid transactions Compute Merkle root Miner attempts nonces until header hash < target Broadcast block Peers verify transactions, Merkle root, and previous hash Append to chain if valid
Key Takeaway
Block addition requires both correct local validation and network consensus. Each step prevents invalid or malicious data from joining the chain.
