Module 2 › Chapter 1.4 › Merkle Construction
Step-by-step example
Given transactions A, B, C, D:
  1. Compute H(A), H(B), H(C), H(D).
  2. Compute HAB = H(H(A)+H(B)), HCD = H(H(C)+H(D)).
  3. Compute Root = H(HAB + HCD).
Practical detail
If there is an odd leaf, duplicate the last leaf before pairing so every layer pairs evenly. This ensures deterministic roots across implementations.
Check your understanding
Which intermediate hashes would you provide to prove transaction C's inclusion in the four-leaf example? Answer: H(D) and HAB.

Key Takeaway
Merkle construction is deterministic and efficient: it converts many items into one compact verifiable root using repeated pairing and hashing.
