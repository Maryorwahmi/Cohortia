Genesis block facts
  • First block in a chain; no prior block exists.
  • Previous hash is a defined constant, often zeros.
  • Provides the known starting digest for validating the chain.
Python initialization example (concept)
# create_genesis_block self.chain.append(Block(0, ['Genesis Block Transaction'], time.time(), '0'))
This creates the anchor block your chain will reference when adding subsequent blocks.
Integrity verification
Nodes iterate the chain and confirm each current_block.previous_hash equals the stored previous block's hash. If any mismatch occurs, the chain is invalid from that point onward.
for i in range(1, len(chain)): if chain[i].previous_hash != chain[i-1].hash: invalid
Key Takeaway
The genesis block is the immutable origin of the chain; altering it invalidates the entire history unless every subsequent block is recomputed and accepted by the network.
