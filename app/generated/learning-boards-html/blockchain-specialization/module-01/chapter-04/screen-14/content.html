Module 2 › Chapter 1.4 › Key Concepts
Merkle Root
A single hash summarizing all transactions; used for efficient inclusion proofs.
Nonce
A value miners adjust during mining to find a valid header hash under the difficulty target.
Genesis Block
The first block, with no previous hash; it anchors the blockchain's history.
Wrap-up
These last definitions complete the vocabulary you need to reason about block composition, proof mechanisms, and chain anchoring.
