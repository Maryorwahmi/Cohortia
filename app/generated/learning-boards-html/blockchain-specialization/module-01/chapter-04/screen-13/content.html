Module 2 › Chapter 1.4 › Key Concepts
Block Header
Fixed metadata used to verify and identify the block.
Transaction Data
Validated, signed records of transfers or state changes included in a block.
Previous Block Hash
Digest of the prior header that cryptographically links blocks.
Summary takeaway
Keep these three concepts top-of-mind; they form the structural basis you will use to understand Merkle proofs and consensus security.
