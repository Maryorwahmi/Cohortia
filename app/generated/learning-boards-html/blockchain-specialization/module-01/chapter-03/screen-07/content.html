What is a Distributed System?

Many independent nodes replicate data and validate transactions, removing single points of control.

Definition
Data and processing power are spread across a mesh of independent nodes; no single node controls the ledger.
Example: a public blockchain where many nodes store complete copies of the ledger and validate new blocks through a consensus mechanism.
Why it matters
  • Fault tolerance: the network continues when nodes fail.
  • Auditability: transaction history is transparent and verifiable.
  • Censorship resistance: no single operator can unilaterally block transactions.
Question
How many independent nodes must be compromised to change history, and how does the consensus defend against that?
