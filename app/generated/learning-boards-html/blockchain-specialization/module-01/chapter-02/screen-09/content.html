Process Flow › Signing & Verification
Five steps
  1. Create transaction: build the message describing the transfer or action.
  2. Hash transaction: compute a digest of the transaction data.
  3. Sign digest: use private key to produce a digital signature.
  4. Broadcast: send transaction, signature, and public key to the network.
  5. Verify: nodes recompute hash and verify the signature with the public key.
Scenario card
Alice prepares a transaction to send 10 units to Bob. She hashes the transaction and signs the hash with her private key. The network verifies the signature using Alice's public key and the recomputed hash. If all checks pass, nodes accept and may include the transaction in a block.
Misconception
Never trust an unsigned transaction or skip verification; nodes must always validate signatures before acceptance.
