Conceptual code panel
import hashlib

def sha256_hash(data):
    return hashlib.sha256(data.encode('utf-8')).hexdigest()

data1 = "Cohortia Blockchain Specialization"
data2 = "Cohortia Blockchain Specialization"
data3 = "Cohortia Blockchain SpecializatioN"  # single char change

print(sha256_hash(data1))
print(sha256_hash(data2))
print(sha256_hash(data3))
Note: This code uses a standard library to demonstrate behavior only. Do not treat printed digests as secrets.
What to observe
  • Determinism: first two printouts match exactly.
  • Avalanche: the third printout is totally different after one character change.
  • Practical tip: use library implementations like hashlib instead of custom code.
Check your understanding
If you changed whitespace only, would the digest change? Yes — whitespace is part of the input and affects the hash.
