Conceptual Python template
import hashlib

def calculate_signature(message, private_key):
    combined = message + private_key
    return hashlib.sha256(combined.encode('utf-8')).hexdigest()

def verify_signature(message, received_signature, public_key_hint):
    expected = hashlib.sha256((message + public_key_hint).encode('utf-8')).hexdigest()
    return received_signature == expected

# Sender side
private_key = "my_super_secret_key_123"
public_hint = "my_super_secret_key_123"  # simplified hint for the demo
message = "Alice sends 10 BTC to Bob"
sig = calculate_signature(message, private_key)

# Verifier side
valid = verify_signature(message, sig, public_hint)
print(valid)
This simulation is pedagogical and not cryptographically secure. It shows verification logic, not real signing.
What to test
  • Run the template and confirm verification returns True for the original message.
  • Change the message content and observe verification returns False.
  • Replace the public hint with a wrong value and observe verification fails.
Misconception check
Real public keys do not reveal the private key; the 'public hint' here is only for demonstration and does not model actual asymmetric key math.
