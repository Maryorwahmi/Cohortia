Core Concept › What is a Cryptographic Hash?
Definition & properties
A cryptographic hash maps any-size input to a fixed-size digest with key security properties.
  • Deterministic: same input → same hash.
  • One-way: cannot recover input from hash.
  • Collision-resistant: very hard to find two inputs with same hash.
  • Avalanche effect: tiny input change → large hash change.
Key Takeaway

Hash functions give a compact, tamper-evident fingerprint; treat them as checksums with strong security properties, not encryption.

Concrete example
Example input
"Cohortia Blockchain Specialization"
What you observe
Hashing this exact string always returns the same 64-character SHA‑256 digest. Change one letter and the digest becomes completely different, demonstrating the avalanche effect.
Misconception
Hashing is not encryption. It does not hide data; it produces a fingerprint used to compare content integrity.
Pro tip
Always use well-vetted libraries for hashing, such as SHA‑256 implementations, rather than custom code.
