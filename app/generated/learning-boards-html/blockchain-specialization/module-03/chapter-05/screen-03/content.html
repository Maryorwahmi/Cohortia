Lab checklist
  • Confirm contract address and ABI are correct before instantiating the contract.
  • Ensure MetaMask is connected to the Sepolia network used for deployment.
  • Use provider.send to request accounts and obtain a signer for transactions.
  • Watch for console errors: malformed ABI, wrong address, or user-rejected signature.
Common mistakes
A wrong contract address, mismatched network, or missing signer are the most frequent causes of failed interactions. Treat error messages as diagnostic signals, not failures.
Mistake
Using RPC from a different network than the contract's.
Fix
Switch MetaMask to the correct network and reload the page.
Verification milestone
Run the demo page, connect MetaMask, read the contract's value, and successfully submit a transaction to update it. Observe console logs for confirmations and events.
