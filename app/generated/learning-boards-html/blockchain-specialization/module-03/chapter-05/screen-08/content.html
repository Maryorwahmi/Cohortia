Module 4 › Chapter 3.5 › Ethers.js Example
Code walkthrough
A minimal sequence used in the demo and lab.
Steps
  1. Detect window.ethereum and create a provider.
  2. Request accounts with eth_requestAccounts.
  3. Get signer and instantiate contract with address and ABI.
  4. Call read-only functions or send transactions for writes and await confirmation.
Representative static code (visual only)
// Create provider and signer
const provider = new ethers.BrowserProvider(window.ethereum);
await provider.send('eth_requestAccounts', []);
const signer = await provider.getSigner();

// Contract instance
const contract = new ethers.Contract(address, abi, signer);

// Read
const value = await contract.getData();

// Write
const tx = await contract.setData(500);
await tx.wait();
This static snippet demonstrates the pattern. For the lab, replace the address and ABI with your deployed contract values and test both read and write flows.
