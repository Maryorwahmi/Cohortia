Module 4 › Chapter 3.5 › Key Concepts
Decentralized Application
An app where backend logic and state live on a blockchain.
Web3 Provider
Interface that connects frontend code to a blockchain node.
Ethers.js / Web3.js
Libraries that abstract RPC to let JavaScript interact with contracts.
Summary

These terms are the vocabulary for building DApps: provider, signer, contract, and ABI describe how the frontend communicates with on-chain logic.
