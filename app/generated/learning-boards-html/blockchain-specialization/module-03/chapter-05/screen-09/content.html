Module 4 › Chapter 3.5 › Reading vs Writing
Read operations
View or pure functions; executed as node calls; no gas or signature required.
Example
getData() returns a stored number and can be displayed instantly from a node response.
Gotcha
Reads do not require wallet confirmation, so they cannot change state or cost gas.
Write operations
State-changing functions require signed transactions and gas; frontends must request user approval via the wallet.
User experience
Show gas estimates, pending status, and confirmations. Allow cancel or retry where appropriate.
Key Takeaway

Design clear UI states for pending transactions and avoid assuming reads immediately reflect unconfirmed writes.
