Sequence
  1. Create AdvancedStorage.sol and select a 0.8.x compiler.
  2. Compile and fix any errors listed in the console.
  3. Deploy in JavaScript VM with initialData and validate getData and DataChanged emission.
  4. Switch accounts to confirm setData reverts for non-owners in JS VM.
  5. Connect MetaMask to Sepolia, get test ETH from a faucet, and set Environment to Injected Provider.
  6. Deploy via MetaMask, confirm the transaction, and monitor the transaction hash until mined.
  7. Interact using MetaMask, observe events, and verify behavior on a block explorer.
Challenge
Try to call setData from a second MetaMask account and capture the revert message in Remix. Note the gas consumed by the failed transaction and reflect on how this impacts real deployments.
Completion hint
If you see the revert message in the console, you have correctly enforced the owner-only restriction.
