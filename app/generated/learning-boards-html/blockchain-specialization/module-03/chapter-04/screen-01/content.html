Developing and Deploying Your First Smart Contract

Hands-on lab using Remix to author, compile, and deploy the AdvancedStorage contract. Learn ownership checks, events, and real testnet deployment with MetaMask.

Lab Walkthrough
In this lesson
Set up Remix and author AdvancedStorage

Create the contract file, choose compiler settings, and add an event and owner pattern for safe writes.

Coming up
Deploy locally and to Sepolia

Test on the JavaScript VM, then connect MetaMask to Sepolia and deploy a test transaction.

Practice
Interact and observe events

Call getData and setData, watch emitted DataChanged events, and inspect revert messages.

Start here

Open Remix in your browser, create AdvancedStorage.sol, and paste the code from the lesson. Make sure your pragma matches the compiler version chosen in Remix.

Visual Concept
AdvancedStorage
State: data, owner • Events: DataChanged • Access control: require(msg.sender == owner)
JavaScript VM
A local in-browser blockchain for fast testing with pre-funded accounts.
Sepolia & MetaMask
Use MetaMask as the injected provider to deploy to the Sepolia public testnet.
Tip
Keep a Remix terminal open to inspect compilation output, transaction hashes, and revert messages during the lab.
