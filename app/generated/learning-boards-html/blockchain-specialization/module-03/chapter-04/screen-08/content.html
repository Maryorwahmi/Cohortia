Module 3 › Chapter 3.4 › Deploy: JavaScript VM
Step-by-step
  1. Select "JavaScript VM (London)" in Deploy & Run Transactions.
  2. Choose a pre-funded account to deploy from.
  3. Provide constructor initialData, e.g., 42, and click Deploy.
  4. Interact with getData and setData in the Deployed Contracts panel.
  5. Switch accounts to test require-based access restrictions and observe revert messages.
Key Takeaway

Use the JS VM to check behaviors that would be expensive on a public network, such as intentional reverts or repeated event emissions.

Concrete example
Deploy AdvancedStorage with initialData 42. Click getData to see 42. Call setData(123) from the owner account to observe DataChanged and updated getData. Switch to a different account and try setData again to see a revert with the require message in the console.
Misconception
Don’t assume JS VM replicates network timing; blocks are simulated instantly and behavior like propagation delays differ from a public testnet.
