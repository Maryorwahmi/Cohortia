Module 3 › Chapter 3.4 › Interact with Contract
Reading state

Click owner or getData in the deployed contract to perform a call and read values without spending gas on a call. Calls return the current state as observed by the node.

Example
Calling getData after deployment with initialData 42 should return 42 immediately in the UI.
Pitfall
Calling a view function through a transaction consumes gas unnecessarily. Use the call option for free reads.
Writing state

Enter a new value for setData and send the transaction. Observe the terminal for gas usage, transaction hash, and the emitted DataChanged event details. If the call reverts, the revert message explains why.

Example
If a different account calls setData, the transaction will revert with "Only the owner can set the data." and the terminal will show the revert reason.
