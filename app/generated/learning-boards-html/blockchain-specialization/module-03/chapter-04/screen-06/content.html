What is an event?

An event creates a log entry on the blockchain. External applications listen for these logs to react when contract state changes occur. They are indexed for efficient searching.

Efficiency
Logs cost less than equivalent on-chain storage and are optimized for off-chain consumption.
Searchability
Indexed fields allow event filters by address or other indexed values.
Key Takeaway

Emit events for UI updates and monitoring; do not rely on events as in-contract storage.

Concrete scenario
Imagine a DApp that displays the stored value. When the owner calls setData, the frontend listens for DataChanged and refreshes the visible number. If DataChanged includes the user address as indexed, the frontend can filter only events from a specific account efficiently.
Misconception
Do not assume events replace state. Contracts cannot access event logs during execution; store essential values in state variables if contracts must read them later.
