Transaction fee calculation
Gas used: actual units consumed by execution.
Gas limit: maximum allowed for the transaction.
Gas price: Ether-per-gas unit offered by the sender.
Total cost: gas used × gas price.
Concrete scenario
You call a contract expecting 100,000 gas usage and set a 120,000 gas limit. If code consumes 90,000 gas, you pay for gas used. If code unexpectedly consumes 130,000, execution halts and the transaction fails while still charging for gas consumed until failure.
Design guidance
Avoid expensive loops and unnecessary storage writes in frequently-called functions. Optimize for common paths to lower average cost for users.
Common mistake

Underestimating gas can cause failed transactions that still cost Ether. Always estimate conservatively and test on a testnet.
