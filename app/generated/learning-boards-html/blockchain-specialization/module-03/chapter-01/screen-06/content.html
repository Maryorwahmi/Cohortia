Module 3 › Chapter 3.1 › Externally Owned Accounts (EOAs)
Definition & Characteristics
  • Controlled by a private key.
  • Can sign and send transactions.
  • Holds Ether balance but contains no code.
  • Initiates interactions with contracts or transfers value.
Concrete example
A user with a wallet signs a transaction to call a contract's deposit function; that signed transaction originates from the EOA and triggers the contract's code when processed by nodes.
Block explorer cues
EOA pages show balance and transactions but lack a contract "Code" tab. Use that to distinguish human accounts from deployed contracts.
Key Takeaway

EOAs represent human-controlled keys that initiate on-chain actions; they are not stores of executable code.
