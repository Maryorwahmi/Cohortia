Module 3 › Chapter 3.1 › Bytecode & Deployment
From source to on-chain bytecode
Step 1: Write contract source in a high-level language.
Step 2: Compile to EVM bytecode.
Step 3: Deploy bytecode in a transaction, creating a contract account with that runtime code.
Step 4: Calls to the address execute the stored bytecode across nodes.
Concrete example
A deploy transaction includes initialization bytecode that sets up storage. After deployment, the contract's runtime bytecode remains at the address and is what gets executed on subsequent calls.
Audit note
Bytecode is authoritative. Verified source is helpful for humans, but the EVM uses the stored bytecode to enforce behavior.
Key Takeaway

Deployment converts source to bytecode; that bytecode is what the EVM executes and what determines contract behavior on-chain.
