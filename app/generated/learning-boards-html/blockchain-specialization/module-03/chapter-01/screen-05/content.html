EVM Architecture (high level)
Sandboxed runtime
Contracts run in isolation; no direct access to external networks or files.
Deterministic execution
Same bytecode + same input produces the same output on every node, enabling consensus.
Bytecode on-chain
Solidity compiles to bytecode stored with the contract account; that bytecode runs under the EVM.
Concrete example
Calling a transfer function runs the same sequence of opcodes on each node, which updates balances in the shared state. Nodes reach the same post-call state because execution is deterministic.
Why isolation matters
Isolation prevents contracts from producing non-deterministic effects caused by external systems. That containment keeps nodes in agreement and enhances security when code is replicated across the network.
Key Takeaway

EVM is the shared, isolated executor that ensures every node runs contract code the same way, enabling trustless, decentralized computation.
