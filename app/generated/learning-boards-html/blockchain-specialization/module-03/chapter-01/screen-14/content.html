Module 3 › Chapter 3.1 › Key Concepts
Ethereum Virtual Machine (EVM)
The decentralized, sandboxed runtime that executes smart contracts deterministically.
Externally Owned Account (EOA)
A private key-controlled account used by humans to sign transactions; holds Ether but no code.
Contract Account
An address that stores bytecode and state; executes when called and cannot initiate transactions itself.
Summary
Keep these three building blocks in mind: the EVM executes bytecode, EOAs sign transactions, and Contract Accounts contain code and storage.
