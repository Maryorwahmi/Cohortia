Module 3 › Chapter 3.1 › Ethereum vs Bitcoin
Side-by-side
Bitcoin — value transfer
Specialized ledger focused on secure currency transfers and balance history.
Ethereum — programmable state
Stores bytecode and executes smart contracts in a deterministic runtime shared by all nodes.
Concrete example
On Ethereum you can deploy an escrow contract that releases funds automatically when conditions are met. On Bitcoin similar functionality is more limited and not natively expressive the same way.
Common misconceptions
  • Ethereum is not just a currency; its core is the ability to run smart contract code.
  • Smart contracts are not autonomous agents with external access; they operate inside the EVM sandbox.
Key Takeaway

Programmability is the defining shift: Ethereum makes code part of the canonical state, enabling DApps and automated agreements.
