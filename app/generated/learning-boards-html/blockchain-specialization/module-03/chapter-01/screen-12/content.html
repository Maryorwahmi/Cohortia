What makes a DApp
  • One or more smart contracts holding logic and state.
  • Users interacting via EOAs that sign transactions.
  • Optional off-chain components for UI, indexing, or heavy computation.
Example categories
Decentralized finance, tokens and collectibles, supply chain registries — each uses on-chain contracts to enforce rules and state.
Design trade-offs
On-chain code gains decentralization and trustlessness but costs gas and must respect the EVM sandbox. Off-chain parts gain efficiency but require trust or additional mechanisms for verification.
Key Takeaway

Ethereum enables DApps by combining on-chain contracts for trust-minimized logic with off-chain components for performance and usability.
