Module 3 › Chapter 3.3 › Gas & Storage Tradeoffs

Costly vs cheap storage

Dynamic data like strings or arrays cost more to store and update. Use hashes or off-chain storage when possible.

On-chain hash pattern

Store a hash on-chain, keep large content off-chain, and verify integrity using the hash when needed.

Storage packing

Order variables to pack multiple small types into a single 256-bit slot to reduce storage cost.

Scenario
MessageBoard optimization

Instead of storing long messages, store a content hash and display full messages from an off-chain source validated against the on-chain hash.

Misconception

Assuming fixed-size types are always cheaper. Aligning with EVM word size can be more efficient depending on operations and access patterns.

Key Takeaway

Measure gas for representative inputs and prefer storing only the minimal necessary on-chain to balance cost and security.
