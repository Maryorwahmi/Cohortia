Module 3 › Chapter 3.3 › Function Visibility
Modifiers

Who can call a function?

public
Callable externally and internally. Useful for API functions and setters.
private
Only callable inside the declaring contract. Not visible to derived contracts or external callers.
internal
Callable within the contract and by derived contracts. Good for inheritance-safe helpers.
external
Callable only from external accounts or other contracts, not via internal calls in the same contract using simple calls.
Concrete Example
Helper vs API

Mark internal/private for internal helpers, and external/public for exposed API endpoints. This prevents unintended external access to internal functions.

Misconception

Confusing public and external. They differ in internal call semantics and gas profile; test to confirm desired behavior.

Key Takeaway

Set visibility deliberately to enforce access control, reduce mistakes, and favor gas-efficient patterns where applicable.
