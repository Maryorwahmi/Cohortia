Step-by-step

Implement and verify owner-restricted setter

// MessageBoard (starter)
pragma solidity ^0.8.0;

contract MessageBoard {
    string public currentMessage;
    address public owner;

    constructor() {
        currentMessage = "Hello Cohortia!";
        owner = msg.sender;
    }

    function setMessage(string memory _newMessage) public {
        // require check to ensure only owner can set the message
        currentMessage = _newMessage;
    }
}
Add require

Insert a require that msg.sender equals owner with an explanatory message to enforce owner-only updates.

Deploy and test

Deploy to the JavaScript VM, call setMessage from the deploying account, then from another account to observe the require failure.

Concrete Check

After adding require(msg.sender == owner, "Only the contract owner can set the message."), test both success and failure paths to validate access control.

Misconception

Leaving the require out or using an incorrect comparison allows unauthorized users to change state unexpectedly.

Try this

Make owner private and add a public getter only if you want read access without exposing a writable slot; reflect on tradeoffs.
