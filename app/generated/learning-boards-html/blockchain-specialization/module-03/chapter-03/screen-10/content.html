Module 3 › Chapter 3.3 › Common Beginner Mistakes

Frequent pitfalls and mitigations

Integer sizing

Choose an integer width that fits your domain, and test boundary values to avoid overflow or unintended truncation.

Visibility errors

Accidentally exposing internal functions or leaving setters open creates security and correctness problems.

No tests before deploy

Because contracts are immutable, testing on local VMs and code review are essential safeguards.

Practical checks
Test both success and failure paths

Include tests that trigger require failures and boundary conditions so you fully understand behavior before deployment.

Gas consideration

Move large content off-chain or store hashes on-chain to reduce cost when you must preserve integrity without storing bulky data.

Key Takeaway

Mitigate risk with conservative types, clear visibility, require assertions, and local testing before any mainnet deployment.
