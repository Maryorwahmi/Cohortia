Module 3 › Chapter 3.3 › What is a Smart Contract?
Definition

Smart Contract

A self-executing program deployed on a blockchain that enforces rules without a central authority.

Immutability

Once deployed, code cannot be altered. This ensures predictable behavior but requires rigorous pre-deployment checks.

Determinism

Same input yields same output across all nodes, which is essential for network consensus.

Transparency

Public contracts can be audited by anyone to verify logic and trustworthiness.

Trustlessness

Participants interact without trusting a central party because the blockchain enforces execution.

Concrete Example
Escrow example

Two parties deposit funds and the contract releases them only when both provide confirmation. The rule is enforced automatically and is immutable once deployed.

Common Mistake

Assuming immutability alone prevents all failures. Bugs can be permanent without built-in upgrade or governance patterns.

Key Takeaway

Design minimal trusted logic for any on-chain contract and validate behavior extensively before deployment.
