Module 3 › Chapter 3.3 › Solidity and the EVM
Architecture

High-level → Bytecode

Solidity source is compiled into EVM bytecode which executes deterministically on each node.

Compiler version

Pinning the pragma ensures consistent behavior and includes version-specific safety fixes and gas improvements.

Gas implications

Storage writes and dynamic types are expensive; reviewing compiled artifacts helps you estimate deployment cost.

Example
SimpleStorage pattern

Declare an unsigned integer state variable, initialize it in a constructor, and provide a setter. The compiler will create a getter for public state.

Misconception

Assuming the language's abstractions are free. Storage and dynamic types carry gas costs and affect deployment size.

Key Takeaway

Pin your compiler version and inspect compiled artifacts to make informed choices about safety and cost.
