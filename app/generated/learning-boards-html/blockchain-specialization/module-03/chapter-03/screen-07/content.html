Common Types

Understand the type, its purpose, and cost considerations when storing it on-chain.

uint / int

Unsigned and signed integers with bit widths from 8 to 256. Use the smallest safe size but measure gas; 256-bit words are often natural for the EVM.

address

20-byte identifier for accounts or contracts. Use it to record ownership or send value securely with checks.

bool

Boolean flags for simple conditions. Pack multiple booleans into a single word when possible to save gas.

string / bytes

Strings are dynamic and costly. bytes and fixed-size bytes are more efficient for raw data.

Concrete Scenario
Message board choices

To store a message, string is practical but increases gas. For short fixed-length tokens, bytes32 may be cheaper.

Misconception

Smaller bit widths always save gas. Not always—packing and word alignment matter. Measure in your environment.

Key Takeaway

Choose types to balance correctness, readability, and gas. Test storage cost in Remix or with local tools.
