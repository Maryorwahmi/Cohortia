Module 3 › Chapter 3.2 › Local Simulation
Run the example
Start Ganache, then run the Node.js script. The script reads nonce and gasPrice from the node, signs with the provided private key, and broadcasts the signed transaction.
What to observe
  • Nonce printed by the script matches the node's transaction count.
  • GasUsed in the receipt shows actual execution cost.
  • Total cost calculation equals gasUsed × gasPrice.
Example output
Transaction successful, gasUsed: 21000, Block Number: 1. Calculate fee by multiplying gasUsed by gasPrice reported earlier.
Snippet (visual only)
// Connect to Ganache, get nonce, gasPrice, set gasLimit = 21000, sign and send transaction. Log gasUsed and transactionHash.
Misconception
For simple transfers gasUsed is predictable; for contract calls, always estimate on a local run because storage and logic change consumption.
