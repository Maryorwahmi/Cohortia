Module 3 › Chapter 3.2 › What is a Transaction?
Definition & core claim

A signed instruction from an externally owned account that changes global state. It may transfer Ether, deploy a contract, or call contract functions.

Concrete example
Send 0.5 Ether: to contains the recipient, value is 0.5 Ether in Wei, data is empty, and signature fields prove intent.
Common misconception
A transaction is not only a payment. It also carries data to trigger contract behavior, which may consume more gas than a simple transfer.
Key takeaway
Treat transactions as generic signed requests. Knowing this helps you estimate gas and understand ordering rules.

Example scenario
A wallet creates and signs a transaction to call a contract. The transaction is broadcast; nodes add it to the mempool, and miners/validators include it in a block when selected.
