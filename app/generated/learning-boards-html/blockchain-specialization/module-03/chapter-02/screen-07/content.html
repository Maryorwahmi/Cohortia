Module 3 › Chapter 3.2 › gasPrice vs gasLimit
Compare: gasLimit and gasPrice
gasLimit
Maximum gas allowed for execution. If actual consumption exceeds this, the transaction reverts and the cap is still paid.
gasPrice
Price per gas unit in Wei. Higher values usually speed inclusion because miners/validators prefer higher-paying transactions.
Low gasLimit
Leads to failure and wasted gas if execution needs more than the cap.
Low gasPrice
May leave transaction pending in the mempool, waiting for inclusion.
Numerical intuition
If a function consumes 50,000 gas and you set gasLimit 60,000, only the 50,000 gas is used. If gasPrice is 20 Gwei, fee equals 50,000 times 20 Gwei. If gasLimit had been 40,000, the call would run out of gas and revert, and 40,000 gas would be consumed and paid.
Practical tip
When unsure, estimate gas with a local run and set gasLimit slightly above the estimate. Use an up-to-date gasPrice estimate to avoid long pending times.
