Module 3 › Chapter 3.2 › Transaction Fields
Fields explained
nonce
Sequential counter from the sender. Prevents replay and sets execution order. Skip a nonce and later transactions will stall until filled.
to
Recipient address; empty when deploying a contract.
value
Amount of Ether sent in Wei. Optional for contract calls that only execute logic.
data
Encoded function selector and arguments for contract interactions; empty for plain transfers.
v, r, s
Signature pieces proving authorization from the sender's private key.
Process example
Example: a token transfer call fills to with token contract address, sets data to the transfer function and recipient parameter, leaves value as zero, uses the current nonce, and signs producing v, r, s. Nodes validate signature, check nonce, and simulate execution using the provided gas limit.
Misread warning
Do not assume empty data means a harmless transaction; value or contract behavior may still change state differently.
Takeaway
Correctly populating each field ensures intended effect, proper ordering, and verifiable authorization.
