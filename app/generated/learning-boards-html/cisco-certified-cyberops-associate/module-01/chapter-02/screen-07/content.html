Key Protocols

SMTP, POP3, IMAP, and SSH

Securing Communication and Remote Administration

SMTP (Simple Mail Transfer Protocol)

Used for sending emails. Operates on TCP port 25. A prime vector for spam and malware delivery.

POP3 (Post Office Protocol 3) & IMAP (Internet Message Access Protocol)

Used for receiving emails. POP3 on TCP 110, IMAP on TCP 143. Common targets for phishing attacks.

SSH (Secure Shell)

Provides a secure, encrypted channel for remote access to devices. Operates on TCP port 22. Essential for secure administration.

Key Takeaway

Vigilant monitoring of email protocols is crucial for detecting phishing and malware, while SSH, though secure, requires strong access controls to prevent abuse.

Email & Remote Access Protocols

SMTP

Sending email, TCP 25. Malware C2 and spam relay vector.

POP3/IMAP

Receiving email, TCP 110/143. Phishing and malware delivery.

SSH

Secure remote access, TCP 22. Encrypted channel for administration.

Common Misconception: SSH is always safe

While SSH encrypts traffic, it's only as secure as the credentials used. Compromised credentials can still grant an attacker secure access, emphasizing the need for strong authentication.
