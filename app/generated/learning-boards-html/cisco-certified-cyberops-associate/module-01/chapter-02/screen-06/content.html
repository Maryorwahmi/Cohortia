Key Protocols

HTTP, HTTPS, and DNS

The Foundation of Web Browsing and Name Resolution

HTTP (Hypertext Transfer Protocol)

Used for web communication. Operates on TCP port 80. Transmits data in plain text, making it vulnerable to eavesdropping.

HTTPS (HTTP Secure)

Secure version of HTTP, encrypts traffic using TLS/SSL. Operates on TCP port 443. Essential for protecting sensitive web data.

DNS (Domain Name System)

Translates human-readable domain names into IP addresses. Uses UDP/TCP port 53. A critical service and frequent target for attackers.

Key Takeaway

Securing web traffic with HTTPS and monitoring DNS for anomalies are fundamental tasks in cybersecurity, as these protocols are central to internet use and common attack vectors.

Core Web & Name Resolution Protocols

HTTP/HTTPS

Web communication, TCP 80/443. HTTPS adds TLS/SSL encryption.

DNS

Domain Name System, UDP/TCP 53. Translates names to IPs.

Security Implication: DNS Spoofing

Attackers can manipulate DNS responses to redirect users to malicious websites, highlighting the need for robust DNS security and monitoring.
