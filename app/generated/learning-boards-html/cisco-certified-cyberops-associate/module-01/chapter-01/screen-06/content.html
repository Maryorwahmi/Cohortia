Strategic Guidance

The NIST Cybersecurity Framework

A voluntary framework providing a systematic methodology for managing cybersecurity risk.

Five Core Functions
  • Identify: Understand assets, systems, data, and capabilities.
  • Protect: Implement safeguards for critical services.
  • Detect: Identify cybersecurity events.
  • Respond: Take action on detected incidents.
  • Recover: Restore impaired capabilities or services.
Concrete Example

An organization uses the 'Identify' function to map all its critical servers and data, then applies 'Protect' measures like strong access controls and encryption.

The NIST Framework provides a continuous cycle for managing and reducing cybersecurity risk.

Key Takeaway

The NIST Cybersecurity Framework offers a flexible, five-function model (Identify, Protect, Detect, Respond, Recover) for organizations to systematically manage cybersecurity risks.
