Forensic Deep Dive

Examining Windows Event Logs and Registry

Uncovering Malicious Activity Through System Data

Windows Event Logs

  • Purpose: Records system activities, login attempts, errors.
  • Key Logs: Security, System, Application (via Event Viewer).
  • Indicators: Unusual login times (Event ID 4624/4625), repeated failed logins.

Windows Registry

  • Purpose: Hierarchical database for OS and application settings.
  • Indicators: New entries in 'Run' keys for persistence, disabled security features.
Additional Artifact

File System Metadata

Beyond logs and registry, file system metadata like creation, modification, and access timestamps can reveal malicious file activity. For example, a critical system file modified outside of maintenance windows could indicate tampering.

Suspicious Activity Example

Unauthorized RDP Login

An Event ID 4624 (successful logon) in the Security log shows an RDP login (Logon Type 10) for an administrative account at 3 AM from an unknown external IP address. This is highly suspicious and warrants immediate investigation, potentially indicating a compromised credential or remote access attack.

Key Takeaway

Mastering the interpretation of Windows Event Logs and Registry entries is crucial for CyberOps Associates to effectively detect, investigate, and respond to security incidents on endpoints.
