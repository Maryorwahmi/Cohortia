Configuring Host-based Firewalls

Controlling Network Traffic at the Endpoint Level

What is a Host-based Firewall?

A software firewall running on an individual endpoint (e.g., Windows Defender Firewall, Linux `iptables`) to control its specific network traffic, supplementing network-level firewalls.

Key Configuration Principles

  • Least Privilege: Allow only necessary inbound/outbound connections.
  • Default Deny: Block all traffic by default unless explicitly permitted.
  • Regular Review: Continuously audit and update firewall rules.
Practical Example

Securing an RDP Port

A Windows server requires remote administration via RDP (port 3389). Instead of leaving it open to the internet, a CyberOps Associate configures the host-based firewall to allow inbound RDP connections ONLY from specific, trusted administrative IP addresses. All other RDP traffic is blocked, significantly reducing the attack surface.
