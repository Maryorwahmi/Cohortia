Key Concepts: Foundational Security

Essential Terms for Endpoint Protection

Endpoint

Any device that is physically an end-point on a network, such as a workstation, laptop, server, or mobile device.

OS Security

Practices and controls implemented to protect the operating system from unauthorized access, use, disclosure, disruption, modification, or destruction.

Least Privilege

A security principle where users are granted only the minimum necessary permissions to perform their job functions.

Patching

The process of applying software updates to fix bugs, improve performance, or address security vulnerabilities.

EPP

Traditional endpoint security solutions focused on preventing known threats (antivirus, host firewall, encryption).

Summary Takeaway

Foundational endpoint security relies on robust OS principles, including user management, patching, and initial threat prevention via EPPs.
