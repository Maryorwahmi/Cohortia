Windows Security: Features and Vulnerabilities

Understanding the Most Prevalent OS in Enterprise

Key Security Features

  • Windows Defender Firewall: Host-based firewall for traffic control.
  • User Account Control (UAC): Prevents unauthorized system changes.
  • Extensive Event Logs: Records system activities for auditing and forensics.

Common Vulnerabilities

  • Widespread Use: Makes it a prime target for attackers.
  • Large Attack Surface: Due to numerous features and services.
  • Legacy Components: Older protocols can introduce exploitable flaws.
Scenario Example

Securing a Windows Workstation

A CyberOps Associate configures a new Windows workstation. They enable UAC, set up Windows Defender Firewall to block all unnecessary inbound connections, and ensure automatic updates are active. They also regularly review security event logs for suspicious login attempts or application errors, proactively identifying potential threats.
