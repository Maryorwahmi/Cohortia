Attack Objective

Man-in-the-Middle (MiTM)

An adversary secretly relays and potentially alters communication between two parties who believe they are directly communicating. This allows for eavesdropping, data manipulation, or credential theft.

  • •**Goal:** Intercept and control communication flow.
  • •**Impact:** Data theft, session hijacking, credential compromise.
  • •**Challenge:** Often difficult for victims to detect directly.
Analogy

Imagine a malicious postal worker intercepting your letters, reading them, changing parts, and then sending them on, making you think you're communicating directly.

Common MiTM Technique

ARP Poisoning: Redirecting Local Traffic

Mechanism

Attacker sends forged ARP messages to associate their MAC address with the IP address of another host (e.g., default gateway). This reroutes traffic through the attacker's machine.

Traffic Manifestation

Look for duplicate IP addresses with different MAC addresses in ARP tables, or an excessive number of gratuitous ARP requests on the network segment.

Detection Tip

Tools like `arpwatch` can detect changes in ARP mappings, and Wireshark can reveal suspicious ARP traffic patterns.
