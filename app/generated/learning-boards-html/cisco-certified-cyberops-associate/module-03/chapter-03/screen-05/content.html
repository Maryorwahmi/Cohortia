Reconnaissance Method

DNS Enumeration

Attackers query DNS servers to gather information about domain infrastructure, including subdomains, hostnames, and mail servers. This helps them build a comprehensive map of the target's digital footprint.

  • •**Objective:** Map out domain structure.
  • •**Technique:** Unusual DNS queries, attempts at zone transfers (AXFR).
  • •**Information Gained:** Subdomains, host IPs, service records.
Concrete Example

An attacker attempts an AXFR zone transfer on a target's DNS server to download a full list of internal hosts and their IP addresses, revealing potential targets.

Detection Strategy

Spotting Reconnaissance in Traffic

Port Scan Indicators

High volume of connection attempts (SYN/UDP) to many ports from a single source IP. Look for distinct flag patterns (e.g., SYN, Xmas, NULL scans).

Ping Sweep Indicators

Numerous ICMP echo requests to a range of IP addresses, often from a single external source.

DNS Enumeration Indicators

Unusual number of DNS queries for subdomains or specific record types (e.g., AXFR attempts) from an external IP.

Attacker Mistake

Attackers often fail to randomize source IPs or scan too quickly, triggering rate-limiting or NIDS alerts, making detection easier.
