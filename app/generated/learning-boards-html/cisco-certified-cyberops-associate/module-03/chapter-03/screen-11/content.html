Detection Focus

Unusual Outbound Connections

Malware often initiates connections to external C2 servers. Monitoring outbound traffic for unusual destinations or ports is a primary detection method.

  • •**Known Malicious IPs/Domains:** Connections to blacklisted or suspicious external addresses.
  • •**Unusual Ports:** Communication over non-standard ports for common services.
  • •**Unexpected Sources:** Connections originating from hosts that typically don't initiate external traffic.
Concrete Example

An internal HR server, which normally only connects to internal services, suddenly attempts to establish a connection to an IP address in Russia on port 8080.

Traffic Anomalies

DNS and HTTP Indicators

DNS Anomalies

Repeated queries for non-existent domains (NXDOMAIN), unusually long domain names, or high volume of DNS queries from a single host (DNS tunneling).

HTTP Anomalies

Connections to suspicious URLs, unusual user-agent strings, or large outbound HTTP POST requests (potential data exfiltration).

Key Takeaway

C2 traffic often attempts to blend in, but its underlying patterns reveal deviations from normal, legitimate network behavior.
