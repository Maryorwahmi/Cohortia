Attack Vector

UDP Flood

Overwhelming a target with UDP packets, often to high-numbered ports. The target expends resources sending ICMP 'Destination Unreachable' messages, leading to resource exhaustion.

  • •**Mechanism:** High volume of UDP packets.
  • •**Target:** Any UDP service or random ports.
  • •**Effect:** Resource consumption, service degradation.
Attack Vector

HTTP Flood

Sending a high volume of legitimate-looking HTTP GET/POST requests to exhaust web server resources. This is an application-layer attack, often harder to distinguish from normal traffic.

  • •**Mechanism:** High volume of HTTP requests.
  • •**Target:** Web servers and web applications.
  • •**Effect:** Slow response times, server crashes.
Detection & Mitigation

Spotting DoS/DDoS in Traffic

Traffic Volume Spike

Sudden, massive increase in bandwidth consumption, particularly of a specific protocol (SYN, UDP, HTTP).

System Resource Exhaustion

High CPU/memory usage on target server, slow response times, or connection timeouts.

NIDS/NIPS Alerts

Intrusion Detection/Prevention Systems flagging known flood patterns.

Attacker Mistake

Attackers often fail to sufficiently randomize their traffic, making it easier for NIDS/NIPS to identify the flood source or pattern.
