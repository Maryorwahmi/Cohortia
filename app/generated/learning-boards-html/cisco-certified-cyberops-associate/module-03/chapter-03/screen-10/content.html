Malware Lifecycle Phase

Malware Propagation

The process by which malicious software spreads across a network or to other systems. This can involve exploiting vulnerabilities or tricking users into executing infected files.

  • •**Vulnerability Exploitation:** Leveraging unpatched services (e.g., SMB) for lateral movement.
  • •**Social Engineering:** Phishing emails, malicious downloads (HTTP/S, FTP).
  • •**Goal:** Infect as many systems as possible.
Real-world Example

A user opens a malicious attachment from a phishing email, which then downloads a payload and attempts to spread to other machines on the internal network.

Malware Lifecycle Phase

Command & Control (C2) Communication

Mechanism

After infection, malware 'phones home' to a C2 server for instructions, to download additional components, or to exfiltrate data.

Disguise Tactics

Often uses common protocols (HTTP/S, DNS, ICMP) to blend in with legitimate traffic, making detection challenging.

Key Takeaway

Malware's network activity is a critical indicator of compromise, both during initial spread and ongoing operations.
