Detection Focus

Key Indicators of ARP Poisoning

Identifying ARP poisoning relies on recognizing specific anomalies in ARP traffic and table entries. These indicators signal that an attacker is attempting to redirect network traffic.

  • •**Duplicate IP-MAC Entries:** An IP address associated with multiple MAC addresses in ARP tables.
  • •**Excessive Gratuitous ARPs:** An unusual flood of unsolicited ARP replies.
  • •**Traffic Rerouting:** Unexpected changes in network path or latency.
Practical Tool

`arpwatch` is a utility that monitors ARP activity on a network and logs changes in IP-MAC address pairings, alerting to potential ARP poisoning.

Monitoring Techniques

Leveraging Network Monitoring

ARP Table Inspection

Regularly inspect ARP tables on critical devices for suspicious entries or rapid changes. Automated scripts can help.

Network Sniffing (Wireshark)

Capture and analyze ARP traffic to identify forged messages or an unusual volume of gratuitous ARPs.

NIDS/NIPS Rules

Configure Intrusion Detection/Prevention Systems to alert on patterns indicative of ARP poisoning attacks.

Attacker Mistake

Sending too many gratuitous ARPs can easily be flagged by monitoring tools, making the attacker's presence obvious.
