Core Concept

Reconnaissance Attacks

Adversaries perform reconnaissance to gather information about a target network before launching a full-scale attack. This phase is crucial for identifying vulnerabilities and planning subsequent exploitation.

  • •**Objective:** Discover active hosts, open ports, and services.
  • •**Methods:** Port scanning, ping sweeps, DNS enumeration.
  • •**Goal:** Build a detailed map of the target's network infrastructure.
Key Takeaway

Early detection of reconnaissance activities is vital to prevent more advanced attacks from succeeding.

Common Techniques

Port Scanning: Probing for Open Doors

What it is

Sending connection attempts to various ports on a host to discover active services. Think of it as knocking on every door to see which ones are unlocked.

Traffic Manifestation

High volume of SYN packets (for TCP) or UDP packets to different ports from a single source IP. Distinct flag patterns indicate scan types (e.g., SYN, Xmas, NULL).

Ping Sweeps: Finding Live Hosts

What it is

Using ICMP echo requests to identify which IP addresses in a range correspond to active hosts on a network.

Traffic Manifestation

Numerous ICMP echo requests sent to a range of IP addresses, often from a single source, expecting ICMP echo replies from live hosts.

Real-world Example

An attacker uses Nmap to scan a company's external IP range, looking for open ports like 22 (SSH), 80 (HTTP), or 443 (HTTPS) to identify potential entry points.
