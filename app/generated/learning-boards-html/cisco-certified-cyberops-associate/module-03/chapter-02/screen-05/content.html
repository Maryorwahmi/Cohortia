Capturing Traffic with tcpdump

Using the command-line to intercept and save raw network data.

The Core Command

The basic tcpdump command captures all traffic on a specified interface and saves it to a file for later analysis.

Why Save to .pcap?

Saving to a .pcap file allows for non-real-time, in-depth analysis using tools like Wireshark, and facilitates sharing capture data with other analysts.

Key Takeaway

tcpdump -i [interface] -w [filename.pcap] is fundamental for collecting raw network traffic for forensic analysis.

# Capture traffic on eth0 and save to capture.pcap
sudo tcpdump -i eth0 -w capture.pcap
# Explanation of flags:
  • -i eth0: Specifies the network interface to capture from (e.g., Ethernet 0).
  • -w capture.pcap: Writes the raw packet data to a file named 'capture.pcap'.

Pro Tip: Check Interfaces

Before capturing, use ip a or ifconfig to identify available network interfaces on your system to ensure you target the correct one.
