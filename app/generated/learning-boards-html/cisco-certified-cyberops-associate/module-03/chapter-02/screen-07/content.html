Filtering Essentials

Mastering tcpdump Capture Filters

Applying Berkeley Packet Filter (BPF) syntax to precisely narrow down captured traffic.

What are Capture Filters?

Capture filters are applied at the time of packet capture, instructing tcpdump to only process and save packets that match specific criteria, reducing the volume of data.

The Power of BPF Syntax

BPF (Berkeley Packet Filter) provides a powerful, flexible language for defining complex filtering rules based on various packet attributes like source/destination, port, and protocol.

Key Takeaway

Effective use of BPF capture filters is critical for efficient and focused network traffic analysis with tcpdump.

# Common BPF Filter Primitives
  • host [IP/hostname]: Filter by source or destination host.
  • net [network/CIDR]: Filter by network address.
  • port [number]: Filter by source or destination port.
  • src/dst host/port: Specify source or destination.
  • tcp/udp/icmp: Filter by protocol type.
# Combining Filters with Logical Operators
sudo tcpdump -i eth0 not port 22
sudo tcpdump -i eth0 src host 192.168.1.100 and tcp port 80

Example Scenario

To investigate a web server, you might use tcpdump -i eth0 port 80 or port 443 to capture only HTTP and HTTPS traffic, ignoring other noise.
