Wireshark Display Filters in Action

Applying powerful filters to refine your view of already captured data.

Capture vs. Display Filters

Capture filters (like BPF in tcpdump) determine what data is saved. Display filters, unique to Wireshark, only affect what is shown from already captured data, leaving the original .pcap intact.

Flexible Syntax

Wireshark's display filter syntax is highly flexible, allowing you to filter on virtually any field within a packet, from IP addresses and ports to specific application-layer attributes.

Key Takeaway

Wireshark display filters are essential for interactively exploring and narrowing down large datasets without altering the raw capture.

# Common Wireshark Display Filters
  • ip.addr == 192.168.1.100: Filter by IP address.
  • tcp.port == 80: Filter by TCP port.
  • http.request.method == "GET": Filter for HTTP GET requests.
  • dns: Show all DNS traffic.
  • tcp.flags.syn == 1 and tcp.flags.ack == 0: Show SYN packets.
  • !(arp or icmp or dns): Exclude ARP, ICMP, and DNS traffic.

Pro Tip: Autocomplete

Wireshark's display filter bar offers autocomplete suggestions, making it easier to construct complex filters and discover available fields.
