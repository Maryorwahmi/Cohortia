Real-time Monitoring

Inspecting Packets in the Terminal

Displaying network traffic directly for immediate insights without saving to a file.

Direct Output

By omitting the -w flag, tcpdump prints packet headers and data directly to the standard output, allowing for real-time observation.

Output Formats

Use -A for ASCII output to see human-readable data, or -X for both hexadecimal and ASCII, providing a more complete view of the packet payload.

Key Takeaway

Live tcpdump output is invaluable for quick network diagnostics and verifying traffic flows in real-time.

# Capture HTTP traffic involving a specific host
sudo tcpdump -i eth0 port 80 and host 192.168.1.100
# Example Output (simplified)
10:30:05.123456 IP 192.168.1.100.54321 > 192.168.1.1.80: Flags [S], seq 12345, win 29200, length 0
10:30:05.123678 IP 192.168.1.1.80 > 192.168.1.100.54321: Flags [S.], seq 67890, ack 12346, win 29200, length 0
# Common flags for live viewing:
  • -A: Print each packet (minus its link level header) in ASCII.
  • -X: Print each packet (minus its link level header) in hex and ASCII.

Misconception Alert

Don't confuse live output with saved captures. Live output is ephemeral; if you need to revisit data, always save to a .pcap file.
