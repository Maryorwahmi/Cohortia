Essential Tools

`netstat` and `ss` for Network Visibility

Command-line tools like netstat (Windows/Linux) and ss (Linux) are indispensable for security analysts to inspect active network connections and listening ports on a host.

  • •
    Identify Active Connections: See which processes are communicating over the network.
  • •
    Discover Listening Ports: Find out which services are open and awaiting connections.
  • •
    Link to Processes: Associate network activity with specific applications (PID).
Key Takeaway

Mastering `netstat` and `ss` provides immediate, actionable insights into a system's network posture, crucial for incident response.

Linux Commands (`ss`)

`ss` for Socket Statistics

sudo ss -tulnp
# -t: TCP, -u: UDP, -l: listening, -n: numeric, -p: process

sudo ss -tanp
# -t: TCP, -a: all, -n: numeric, -p: process

These commands reveal listening ports and established connections, along with the associated process IDs and program names.

Windows Command (`netstat`)

`netstat -ano`

netstat -ano
# -a: all connections, -n: numeric, -o: process ID

Displays all active TCP connections and listening ports, including the process ID for each connection, allowing you to identify the responsible application.
