Key Concepts

Essential Takeaways for Network Security

IP (Internet Protocol)

Responsible for addressing and routing packets across networks.

HTTP/S

HTTP (port 80) for web pages; HTTPS (port 443) is the secure, encrypted version using TLS/SSL.

DNS (Domain Name System)

Translates human-readable domain names to IP addresses (UDP/TCP port 53).

ICMP (Internet Control Message Protocol)

Used for diagnostic and error reporting (e.g., `ping`), but can be abused for attacks.

SSH (Secure Shell)

Provides secure encrypted remote access and file transfer (TCP port 22).

FTP (File Transfer Protocol)

Used for transferring files between computers (TCP ports 20, 21), but transmits data in plaintext.

Chapter Summary

Understanding these application and network layer protocols, their legitimate functions, and common attack vectors is crucial for any security analyst to effectively monitor and defend network environments.
