Core Function

ICMP: Network Diagnostics

Internet Control Message Protocol (ICMP) operates at the network layer and is primarily used for diagnostic and error reporting. It helps devices communicate network issues.

  • •
    Ping Command: Uses ICMP echo requests and replies to test network connectivity.
  • •
    Error Reporting: Informs senders about issues like unreachable hosts or expired Time-To-Live (TTL).
Key Takeaway

While essential for network health, ICMP's diagnostic nature makes it a prime candidate for malicious exploitation.

Security Concerns

ICMP Attack Vectors

  • •
    Reconnaissance: Ping sweeps to discover active hosts on a network.
  • •
    Denial-of-Service (DoS): ICMP floods overwhelm targets with excessive traffic.
  • •
    Data Exfiltration: ICMP tunneling embeds malicious data within ICMP packets.
Analyst Focus

Monitoring ICMP Anomalies

Security analysts must watch for excessive ICMP traffic, unusual source/destination patterns, or ICMP types not typically seen in normal network operations. These can signal reconnaissance, DoS, or covert channels.
