Core Function

DNS: The Internet's Phonebook

The Domain Name System (DNS) translates human-readable domain names (e.g., google.com) into machine-readable IP addresses (e.g., 172.217.160.142). This service is fundamental for navigating the internet.

  • •
    UDP Port 53: Primarily used for DNS queries (fast, connectionless).
  • •
    TCP Port 53: Used for DNS zone transfers (reliable, for larger data).
Key Takeaway

DNS is a critical infrastructure service, but its ubiquity makes it a prime target for various sophisticated attacks.

Security Concerns

Common DNS Attack Vectors

  • •
    DNS Tunneling: Encapsulating malicious traffic (C2, data exfiltration) within DNS queries/responses.
  • •
    DNS Spoofing: Redirecting users to malicious sites by providing false IP addresses.
  • •
    DDoS Attacks: Overwhelming DNS servers with traffic to deny service.
Anomaly Detection

Spotting Suspicious DNS Activity

Look for unusually high volumes of DNS queries from a single host, requests for non-existent domains (NXDOMAIN responses), or queries to suspicious external DNS servers. These can indicate compromise or data exfiltration attempts.
