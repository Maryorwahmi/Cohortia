Connection Establishment Process

The TCP Three-Way Handshake

1

SYN (Synchronize)

Client sends a request to establish a connection.

2

SYN-ACK (Synchronize-Acknowledge)

Server acknowledges SYN and sends its own SYN.

3

ACK (Acknowledge)

Client acknowledges server's SYN, connection established.

Why it matters

Ensures reliable, ordered data delivery by confirming both sides are ready to communicate.

Security Concern

Incomplete handshakes (e.g., SYN floods) can lead to Denial of Service (DoS) attacks, overwhelming server resources.

Key Takeaway

The TCP three-way handshake is a critical security checkpoint; monitoring its integrity helps detect connection-based attacks.
