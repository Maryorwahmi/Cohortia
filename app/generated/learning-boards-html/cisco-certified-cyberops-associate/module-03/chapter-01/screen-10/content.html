Core Function

FTP: Basic File Transfer

File Transfer Protocol (FTP) is used for transferring files between computers. It operates using two TCP ports:

  • •
    TCP Port 21: Control connection (commands, authentication).
  • •
    TCP Port 20: Data connection (actual file transfer).
Key Takeaway

FTP's plaintext nature makes it a significant security risk; always opt for encrypted alternatives.

Security Concerns

FTP's Major Vulnerability

  • •
    Plaintext Transmission: Credentials (usernames, passwords) and data are sent unencrypted.
  • •
    Eavesdropping: Attackers can easily intercept and read sensitive information.
  • •
    Man-in-the-Middle Attacks: Vulnerable to interception and modification of traffic.
Secure Alternatives

Protecting File Transfers

  • •
    SFTP (SSH File Transfer Protocol): Leverages SSH for encrypted control and data channels.
  • •
    FTPS (FTP Secure): Adds TLS/SSL encryption to standard FTP.
