            for line_num, line in enumerate(f, 1):
                for compiled_pattern, original_pattern in compiled_patterns:
                    if compiled_pattern.search(line):
                        found_incidents.append({
                            "line_num": line_num,
                            "log_entry": line.strip(),
                            "matched_pattern": original_pattern
                        })
                        # Break after first match per line to avoid duplicate reporting
                        break 
        
        if found_incidents:
            print("
--- Suspicious Activities Found ---")
            for incident in found_incidents:
                print(f"Line {incident['line_num']}: {incident['log_entry']}")
                print(f"  Matched Pattern: '{incident['matched_pattern']}'
")
        else:
            print("No suspicious activities found.")
            
    except Exception as e:
        print(f"An error occurred during log analysis: {e}")
        
    return found_incidents

File Handling & Iteration

The script safely opens the log file and iterates through each line, assigning a line number. This ensures every entry is processed and provides context for identified incidents.

Pattern Matching Loop

Each log line is checked against all compiled suspicious patterns. The first pattern that matches a line triggers an incident record, preventing redundant reporting for the same log entry.

Incident Reporting

When suspicious activity is found, the script compiles a list of incidents, each containing the line number, the full log entry, and the matched pattern. This provides clear, actionable intelligence.
