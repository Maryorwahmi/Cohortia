The 5 Whys Technique

Peeling Back Layers to Find the Core Problem

How it Works
  • **Start with the Problem:** Clearly define the incident or symptom.
  • **Ask 'Why?':** For each answer, ask 'Why?' again to delve deeper.
  • **Identify Root Cause:** Continue until you reach a cause that, if removed, would prevent the problem.
  • **Actionable Solution:** Develop a solution for the identified root cause.
Example: Compromised Server
Problem: Server compromised.
Why 1: Server was unpatched.
Why 2: Patching schedule not followed.
Why 3: System owner unaware of policy.
Why 4: No clear communication channel.
Root Cause: Communication breakdown.
Key Takeaway

The 5 Whys helps uncover systemic issues by repeatedly questioning the immediate cause, leading to more effective, long-term solutions.
