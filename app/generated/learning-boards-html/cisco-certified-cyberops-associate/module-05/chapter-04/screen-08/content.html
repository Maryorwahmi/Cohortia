Fishbone Diagram (Ishikawa Diagram)

Visualizing Potential Causes for Comprehensive Analysis

Diagram Structure
  • **Head:** The problem statement (e.g., 'Data Breach').
  • **Spine:** A central line leading to the problem.
  • **Major Bones:** Categories of potential causes (e.g., People, Process, Tools, Environment).
  • **Minor Bones:** Specific contributing factors under each category.
Example Categories & Factors
People:
  • Lack of training
  • Human error
  • Insufficient staffing
Process:
  • Outdated playbooks
  • Unclear procedures
  • No change management
Tools:
  • Outdated software
  • Misconfigured tools
  • Lack of necessary tools
Environment:
  • Network issues
  • Power outages
  • External threats
Key Takeaway

The Fishbone Diagram provides a visual, structured way to brainstorm and categorize all potential causes of a complex problem.
