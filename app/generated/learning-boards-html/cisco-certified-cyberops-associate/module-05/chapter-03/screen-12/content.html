Best Practices

Avoiding Pitfalls in CER

Key considerations for effective incident response.

Common Mistakes

  • Failing to identify the true root cause, leading to re-infection.
  • Restoring from compromised or unverified backups.
  • Rushing recovery without adequate system hardening.
  • Destroying evidence inadvertently during containment.
Concrete Example

An analyst pulls a network cable from a compromised server to stop data exfiltration, but in doing so, loses all volatile memory data, violating evidence preservation.

Safety Notes

  • Always verify backups: Ensure they are clean and uncorrupted.
  • Prioritize evidence: Image disks and memory before making changes.
  • Document everything: Meticulously record all actions, timestamps, and personnel.
  • Communicate clearly: Keep stakeholders informed throughout all phases.
Key Takeaway

Adhering to best practices and avoiding common mistakes, especially regarding evidence and backups, is crucial for a successful and compliant incident response.
