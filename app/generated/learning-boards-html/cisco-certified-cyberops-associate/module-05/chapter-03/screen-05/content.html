Incident Containment

Limiting the Blast Radius

Immediate actions to stop the spread of a security incident.

Short-Term Containment

Focuses on immediate actions to stop the spread and prevent further damage.

  • Network Segmentation: Isolate compromised systems using firewalls or ACLs.
  • Host Isolation/Quarantine: Disconnect or move compromised hosts.
  • Disabling Accounts: Suspend user accounts used maliciously.
  • Blocking Malicious IPs/Domains: Update network devices to block known threats.
Concrete Example

A server is found sending out suspicious traffic. Immediately, an administrator configures a firewall rule to block all outbound connections from that server to the internal network, effectively quarantining it.

Long-Term Containment

Aims for more robust, temporary solutions to prevent recurrence while full eradication and recovery are planned.

  • Temporary patches or reconfigurations.
  • Deployment of additional monitoring tools.
  • Implementing stronger temporary access controls.
Common Mistake

Rushing containment without proper analysis can lead to shutting down critical services unnecessarily or, conversely, failing to contain the threat effectively, allowing it to spread further.

Key Takeaway

Effective containment requires swift, informed decisions to isolate threats and prevent escalation, balancing immediate action with minimal business disruption.
