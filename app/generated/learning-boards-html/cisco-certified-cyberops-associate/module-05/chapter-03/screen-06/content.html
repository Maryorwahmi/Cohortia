Containment in Action

Isolating Threats with Network Controls

Practical techniques for segmenting networks and isolating hosts.

Network Segmentation

Using firewalls, ACLs, or VLANs to isolate compromised systems or network segments. This prevents lateral movement.

Host Isolation/Quarantine

Disconnecting a compromised host from the network entirely or moving it to a quarantined segment for analysis.

Concrete Example

A compromised web server (192.168.1.50) is actively scanning the internal network. An `iptables` rule is added to block its outbound connections to the internal subnet.

# Linux Host-based Firewall (iptables) Example
sudo iptables -A OUTPUT -s 192.168.1.50 -d 192.168.0.0/16 -j DROP
sudo service iptables save

# Cisco Firewall ACL Example (partial)
conf t
access-list 101 deny ip host 192.168.1.50 192.168.0.0 0.0.255.255 log
access-list 101 permit ip host 192.168.1.50 host <IR_JUMP_BOX_IP>
interface GigabitEthernet0/1
ip access-group 101 in
end
wr mem
Key Takeaway

Implementing network-level controls and host isolation are immediate, effective ways to contain a threat, preventing its spread and minimizing damage.
