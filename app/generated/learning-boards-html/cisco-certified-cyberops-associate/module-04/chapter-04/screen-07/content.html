Disabling Unnecessary Services

Managing Services with systemctl on Linux

Why Manage Linux Services?

  • •Each active service is a potential vulnerability.
  • •Reduces resource consumption and security risks.
  • •systemctl is the primary tool for service management.
Important Note

Always understand the implications of disabling a service; it can affect system functionality.

Linux Terminal Demo: Disabling CUPS Service
# Example: Disabling a non-essential service on Linux (e.g., "cups" - printing service)

# 1. Check its current state:
systemctl status cups

# Expected output (if active):
● cups.service - CUPS Scheduler
     Loaded: loaded (/lib/systemd/system/cups.service; enabled; vendor preset: enabled)
     Active: active (running) since ...

# 2. If active, stop it:
sudo systemctl stop cups

# 3. Then, disable it from starting at boot:
sudo systemctl disable cups

# 4. Verify the service status again:
systemctl status cups

# Expected output (after stopping and disabling):
● cups.service - CUPS Scheduler
     Loaded: loaded (/lib/systemd/system/cups.service; disabled; vendor preset: enabled)
     Active: inactive (dead) since ...
Key Takeaway

Use `systemctl status`, `stop`, and `disable` to effectively manage and secure services on Linux, reducing the attack surface.
