Security Principle

The Principle of Least Privilege

Granting Only Necessary Permissions

Core Idea

Users, applications, and services should only be granted the minimum necessary permissions to perform their intended functions.

  • •Standard users should not have administrative rights.
  • •Web server processes should not run with root/SYSTEM privileges.

Practical Examples

Windows

Manage user groups, NTFS permissions, and service account privileges carefully.

Linux

Set file permissions (`chmod`, `chown`), manage user groups, run services as unprivileged users.

Common Mistake

Granting blanket administrative rights for convenience significantly expands the impact of a compromised account.

Key Takeaway

Adhering to the principle of least privilege is crucial for containing potential damage and limiting an attacker's ability to escalate privileges within a system.
