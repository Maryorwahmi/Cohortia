Log Sources

Deep Dive: Linux System Logs

Navigating common log files and utilities for Linux incident investigations.

Authentication Logs

Records authentication and authorization events, including login attempts and sudo commands.

  • •/var/log/auth.log (Debian/Ubuntu)
  • •/var/log/secure (RHEL/CentOS)

General System Logs

Contains general system activity, kernel messages, and messages from various applications.

  • •/var/log/syslog (Debian/Ubuntu)
  • •/var/log/messages (RHEL/CentOS)

journalctl Utility

A utility for querying and displaying logs from the systemd journal, unifying logging for modern Linux systems.

  • •Powerful filtering and search capabilities.
  • •Centralized log management.
Key Takeaway

Linux logs, particularly authentication logs and the systemd journal via journalctl, are crucial for identifying suspicious activities and understanding system behavior.
