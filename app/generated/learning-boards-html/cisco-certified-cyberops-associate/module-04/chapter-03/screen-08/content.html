Incident Phase

Containment Strategy & Volatile Data Priority

Stopping the threat while preserving critical, ephemeral evidence.

Containment Actions

  • •Isolate compromised host from the network.
  • •Suspend suspicious user accounts.
  • •Block malicious IP addresses at the firewall.

Why Volatile Data First?

  • •Prevents loss of critical evidence (e.g., RAM contents).
  • •Crucial for understanding fileless attacks.
  • •Avoids destroying clues by drastic actions like rebooting.
Common Mistake

Immediately shutting down a compromised system without collecting volatile data, leading to irreversible evidence loss.

Containment Flow

Identify Incident
Collect Volatile Data (RAM, Processes)
Isolate Host / Suspend Accounts
Proceed to Eradication
Key Takeaway

Effective containment balances stopping the threat with the critical need to preserve volatile evidence before it's lost.
