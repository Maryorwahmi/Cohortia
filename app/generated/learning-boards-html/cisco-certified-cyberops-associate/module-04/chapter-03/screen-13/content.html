Practical Log Analysis Example

Identifying suspicious patterns in log data using a simple script.

log_data = [
    "Oct 27 10:30:05 server sshd[1234]: Failed password for invalid user admin from 192.168.1.10 port 54321 ssh2",
    "Oct 27 10:30:10 server sshd[1235]: Failed password for root from 192.168.1.10 port 54322 ssh2",
    "Oct 27 10:30:15 server sshd[1236]: Accepted password for user_valid from 192.168.1.10 port 54323 ssh2",
    "Oct 27 10:30:20 server kernel: [  123.456] usb 1-1: new high-speed USB device number 2 using ehci-pci"
]

suspicious_keywords = ["Failed password", "Accepted password", "malicious", "downloadstring"]

print("--- Analyzing Log Data ---")
for line in log_data:
    for keyword in suspicious_keywords:
        if keyword in line:
            print(f"SUSPICIOUS: {line}")
            break # Move to the next line after finding one keyword
Example Scenario

Multiple failed login attempts followed by a successful login from an unusual IP address strongly suggests a brute-force attack.

Key Observations

  • •Correlate events by timestamp to establish a sequence.
  • •Look for patterns like failed logins followed by success.
  • •Identify unusual source IP addresses or process command lines.
  • •Automated scripts can quickly highlight relevant entries.
Key Takeaway

Combining human analytical skills with simple automation is highly effective for sifting through log data and identifying potential compromises.
