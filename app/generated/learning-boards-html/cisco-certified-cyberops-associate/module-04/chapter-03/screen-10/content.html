Deep Dive: Windows Event Logs

Understanding the key categories and critical Event IDs for investigations.

Security Log

Records login/logout attempts, object access, privilege use, and process tracking.

  • •4624: Successful Logon
  • •4625: Failed Logon
  • •4688: Process Creation

System Log

Records events related to OS components, such as driver failures or service starts/stops.

  • •System startup/shutdown
  • •Driver errors
  • •Service control manager events

Application Log

Records events from applications or programs installed on the system.

  • •Application errors
  • •Warnings and informational messages
  • •Database events
Access Method

Access Windows Event Logs via the Event Viewer (eventvwr.msc) to filter and analyze events.

Key Takeaway

Focusing on the Security Log and specific Event IDs like 4624, 4625, and 4688 is crucial for detecting suspicious activities on Windows hosts.
