Data Types

Non-Volatile Data: Persistent Records

Digital evidence that remains even after a system loses power.

Disk Images

Bit-for-bit copies of storage devices, preserving all data including deleted files and unallocated space.

Tools: FTK Imager, dd (Linux)

Log Files

Operating system, application, and security logs that provide a chronological narrative of system activity.

Windows Event Logs, Linux /var/log/

Registry (Windows)

A hierarchical database storing configuration settings and options for the OS and installed applications.

Reveals system and application changes.

File System Metadata

Timestamps (creation, modification, access), file permissions, and ownership details for all files.

Helps establish event timelines.
Key Takeaway

Non-volatile data provides the historical context and deep insights necessary for a thorough and comprehensive forensic investigation.
