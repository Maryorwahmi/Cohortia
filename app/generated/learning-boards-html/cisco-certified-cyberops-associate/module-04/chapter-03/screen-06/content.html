Data Types

Volatile Data: Ephemeral Evidence

Information that is easily lost or altered when a system is powered off.

System Memory (RAM)

Contains running processes, open files, network connections, and even malware code that never touches the disk. Lost on reboot.

Tools: Volatility Framework (conceptual)

Running Processes

List of active processes, their parent-child relationships, and command-line arguments. Reveals what's currently executing.

Windows: tasklist /svc, Get-Process | Linux: ps aux, top

Network Connections

Active TCP/UDP connections and listening ports. Indicates ongoing communication and potential C2 channels.

Windows: netstat -ano | Linux: netstat -tulnp, ss -tulnp

System Time

Crucial for correlating events across different logs and systems, establishing a precise timeline of events.

Ensures accurate event sequencing.
Key Takeaway

Volatile data provides a real-time snapshot of a system's state, making its immediate and careful collection paramount to any investigation.
