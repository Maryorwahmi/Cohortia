Forensic Technique

Log Analysis Fundamentals

Uncovering system events and suspicious activities through digital records.

Windows Event Logs

  • •Categorized (System, Security, Application).
  • •Accessed via Event Viewer (eventvwr.msc).
  • •Key for login attempts (4624, 4625) and process creation (4688).
Why it matters

Logs provide a chronological narrative, acting as digital breadcrumbs to reconstruct incident timelines.

Linux Logs

  • •Typically found in /var/log/ (plain text files).
  • •auth.log/secure for authentication events.
  • •syslog/messages for general system activity.
  • •journalctl for modern systemd logs.
Key Takeaway

Mastering log analysis for both Windows and Linux is indispensable for identifying anomalies and reconstructing security incidents.
