Proactive Defense: Threat Hunting with EDR
Searching for Subtle Signs of Adversary Tactics (TTPs)
What is Threat Hunting?

The proactive and iterative process of searching through networks, endpoints, or datasets to detect and isolate advanced threats that evade existing security solutions.

Leveraging EDR Data

Utilizes EDR's rich telemetry and powerful query capabilities to search for subtle indicators of malicious activity.

MITRE ATT&CK Framework

A globally accessible knowledge base of adversary tactics and techniques (TTPs) used to guide threat hunting efforts.

EDR Threat Hunting Query (Conceptual)
SELECT process_name, command_line, user, hostname
FROM endpoint_telemetry
WHERE process_name = 'powershell.exe'
  AND command_line LIKE '%-NoP -NonI -Exec Bypass%'
  AND command_line LIKE '%DownloadString%'
  AND timestamp > '2023-10-01T00:00:00Z'
GROUP BY hostname, user
ORDER BY timestamp DESC;
Analysis Guidance

This query searches for PowerShell executions that download and execute content from the web, a common TTP for initial access or persistence. Analysts would then investigate the specific command lines and associated network connections.
