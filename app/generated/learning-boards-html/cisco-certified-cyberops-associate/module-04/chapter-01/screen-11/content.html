Incident Response Tools

Endpoint Investigation: Network Commands

Using netstat and other commands to identify active connections and processes during an incident.

Scenario: Suspicious Outbound Connection

A SOC analyst receives an alert about a suspicious process attempting to connect to a known malicious IP address from a Windows workstation. Immediate investigation is required.

  • Check firewall logs for blocked connections.
  • Create new firewall rules to contain the threat.
  • Identify active connections and processes.

Windows Command: netstat -ano

Lists active TCP connections, including the associated process ID (PID). Useful for identifying which process is making a suspicious connection.

Linux Command: netstat -tulnp

Lists listening TCP/UDP ports and associated processes. The -p flag shows the PID and program name, crucial for identifying rogue services.

# Example: Listing active TCP connections on Windows
netstat -ano | findstr "ESTABLISHED"

# Example: Listing listening ports on Linux
sudo netstat -tulnp
Key Takeaway

Command-line tools like netstat are essential for real-time endpoint investigation and threat containment.
