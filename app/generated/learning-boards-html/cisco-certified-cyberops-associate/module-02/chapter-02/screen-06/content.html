Data Type
Flow Data (NetFlow/IPFIX)
Summarizing Network Conversations for Efficiency

Flow data, like NetFlow and IPFIX, records metadata about network conversations, not the full packet content.

It summarizes key details such as source/destination IPs and ports, protocols, timestamps, and byte/packet counts.

  • Efficient Monitoring: Lightweight, requiring less storage and processing than PCAP.
  • High-Level Visibility: Ideal for continuous, network-wide traffic analysis and trend identification.
  • Anomaly Detection: Quickly spots unusual traffic patterns, volumes, or communication endpoints.
  • Payload Ignored: Does not capture the actual data content, limiting deep forensic detail.
