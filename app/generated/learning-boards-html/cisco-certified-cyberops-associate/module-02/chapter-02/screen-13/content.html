Capturing Traffic with tcpdump
A Practical Introduction to Packet Analysis

Use `tcpdump` to capture and filter network traffic, a fundamental skill for network security monitoring.

This lab demonstrates capturing HTTP traffic on port 80 and saving it to a `.pcap` file for analysis.

  • Identify Interface: Use `ip a` or `ifconfig`.
  • Capture Command: `sudo tcpdump -i [INTERFACE] -nnvvS port 80 -w http_traffic.pcap`
  • Generate Traffic: Browse to `http://example.com`.
  • Stop Capture: Press `Ctrl+C`.
  • Analyze: View summary with `tcpdump -r` or open in Wireshark.
Terminal Command
sudo tcpdump -i [INTERFACE] -nnvvS port 80 -w http_traffic.pcap
Key Takeaway

`tcpdump` is a powerful command-line tool for capturing and filtering network traffic, essential for basic packet analysis.
