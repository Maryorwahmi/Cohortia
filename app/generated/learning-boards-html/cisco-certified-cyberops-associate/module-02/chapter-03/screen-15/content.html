Key Concepts

Foundational Elements of Host-Based Analysis

Host-based Logging

The collection of log data directly from operating systems and applications running on an endpoint.

Windows Event Logs

A record of events generated by the Windows operating system, categorized into Application, Security, System, etc.

Syslog

A standard for message logging on Unix-like operating systems, typically storing logs in /var/log/.

Host-based Forensics

The process of collecting and analyzing data from a compromised host to understand the nature and scope of an incident.

Process Analysis

Examining running processes on a system to identify suspicious or malicious executables.

File Integrity Monitoring (FIM)

A process that validates the integrity of operating system and application files to detect unauthorized changes.

Summary Takeaway

Host-based analysis relies on detailed logging from operating systems like Windows and Linux, combined with forensic techniques like process analysis and file integrity monitoring, to investigate and understand security incidents.
