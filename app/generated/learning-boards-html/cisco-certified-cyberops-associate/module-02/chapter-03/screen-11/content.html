1. Process Analysis

Identifying Malicious Executions

  • Identify Running Processes: Use tools like Task Manager (Windows) or ps, top (Linux).
  • Look for Anomalies: Unusual names, unexpected parent-child relationships, processes from suspicious locations (e.g., /tmp).
  • Resource Usage: Processes consuming excessive CPU/memory without justification.
Example Tools

Windows: Task Manager, Process Explorer
Linux: ps aux, top, htop

2. File System Analysis

Discovering Malicious Files and Changes

  • Examine Recent Modifications: Look for files created or modified around the incident time.
  • Suspicious Locations: Check temporary directories (/tmp, C:\Windows\Temp) or user download folders.
  • Unusual File Types: Executables in data directories, hidden files.
  • Integrity Checks: Compare file hashes against known good baselines.
Example Tools

Windows: dir /OD, attrib
Linux: ls -alt, find

Key Takeaway

Process and file system analysis are critical initial forensic steps to uncover suspicious executables, unusual file modifications, and hidden attacker artifacts on a compromised endpoint.
