Linux Logging Mechanisms

Syslog and Journald for System Events

On Linux, syslog (or journald in modern systems) is the primary logging mechanism. Logs are typically stored in the /var/log/ directory, providing insights into various system activities.

auth.log

Authentication events (logins, sudo attempts).

kern.log

Kernel messages and warnings.

syslog

General system messages from various services.

auditd logs

Detailed system call and file access auditing (if configured).

Key Takeaway

Linux logs in /var/log/, especially auth.log and syslog, are crucial for detecting suspicious activities like failed logins or unusual service starts.

Monitoring for Malicious Activity

What to Look For in Linux Logs

  • Failed Login Attempts: Repeated failures in auth.log can indicate brute-force attacks.
  • Unusual Service Starts: Unexpected services launching in syslog might signal malware.
  • Privilege Escalation: Changes in user permissions or root access in auth.log.
  • Suspicious File Access: Unauthorized access to sensitive files via auditd logs.
Pro Tip

Use tools like grep, tail, and journalctl to efficiently filter and view log entries for specific events or timeframes.
