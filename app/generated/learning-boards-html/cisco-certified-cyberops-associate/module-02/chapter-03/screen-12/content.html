1. Network Connections Analysis

Spotting Suspicious Communications

  • Identify Active Connections: Use netstat (Windows/Linux) or ss (Linux).
  • Look for Anomalies: Connections to unknown IPs, unusual ports, or from unexpected processes.
  • Command & Control (C2): Indicators of communication with attacker infrastructure.
Example Tools

Windows/Linux: netstat -ano
Linux: ss -tunap

2. Registry Analysis (Windows)

Uncovering Persistence Mechanisms

  • Examine Run Keys: Check locations where programs are set to launch at startup.
  • Service Configurations: Look for malicious services installed.
  • Browser Helper Objects (BHOs): Investigate suspicious browser extensions.
  • Scheduled Tasks: Identify tasks set to run malicious code periodically.
Example Tools

Windows: regedit, Autoruns, specialized forensic tools

Key Takeaway

Analyzing network connections reveals attacker communications, while Windows Registry analysis uncovers persistence mechanisms, both crucial for understanding a compromise.
