Asymmetric Encryption: Public and Private Keys

A pair of mathematically linked keys for enhanced security.

Public Key

Can be freely distributed. Used to encrypt data or verify signatures.

Private Key

Must be kept secret by its owner. Used to decrypt data or create signatures.

Key Pair

Mathematically linked; what one key encrypts, only the other can decrypt.

Key Takeaway

Asymmetric encryption solves the key exchange problem by using distinct public and private keys for encryption and decryption.
