OpenSSL: Generating Keys and Certificates

A Powerful Command-Line Utility for Cryptography

Terminal
# Generate a new 2048-bit RSA private key
openssl genrsa -out server.key 2048

# Create a Certificate Signing Request (CSR)
openssl req -new -key server.key -out server.csr
# You will be prompted for information like Country Name, State, Organization Name, Common Name (your domain), etc.

OpenSSL Functions

Generate RSA/ECC key pairs, create/manage X.509 certificates, encrypt/decrypt files, calculate hash values.

Command Explanation

genrsa generates an RSA private key. req -new creates a new Certificate Signing Request using the generated private key.

Example Scenario

A web administrator uses OpenSSL to generate a private key and CSR for a new website, which is then sent to a Certificate Authority for signing.

Key Takeaway

OpenSSL is an indispensable command-line toolkit for managing cryptographic keys and certificates, foundational for securing web servers and other digital assets.
