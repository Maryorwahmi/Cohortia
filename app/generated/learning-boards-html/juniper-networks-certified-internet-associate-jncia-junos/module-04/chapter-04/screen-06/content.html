Broadcast vs Point-to-Point

Broadcast (Ethernet)
Multiple routers can exist on the same LAN; DR and BDR are elected and reduce flooding.
Point-to-Point
A single adjacency exists between two routers; no DR/BDR election required.
Why this matters

DR/BDR elections shape which routers exchange LSAs and can affect convergence and LSA traffic. On LANs, a stable DR reduces redundant flooding.

Example
Three routers on an Ethernet segment will elect a DR and BDR. The DR receives Link State Updates and coordinates LSDB synchronization.
Misconception
Believing DR/BDR prevent routing updates is incorrect — they centralize exchange and reduce duplicate flooding, not stop updates.
Key Takeaway

Accept Junos defaults for common setups, but set network type manually when your topology requires it.
