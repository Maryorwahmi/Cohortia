Process Flow › Firewall Filters & OSPF

What to permit for OSPF

Permit IP protocol 89 and the multicast groups 224.0.0.5 and 224.0.0.6 on OSPF-enabled interfaces to allow Hello and LSA traffic.
Check filters
show configuration firewall to find interface-level filtering that could block OSPF traffic.
Concrete example
If adjacency never leaves Down despite correct area and masks, temporarily allow protocol 89 on the interface to see if filtering is the cause.
Misconception
Assuming only unicast IP is relevant is wrong—multicast is required for neighbor discovery in OSPF.
Key Takeaway

Allow protocol 89 and OSPF multicast addresses through filters on OSPF interfaces to ensure adjacency formation.
