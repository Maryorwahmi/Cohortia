Enable OSPF — CLI walkthrough

Follow these commands in configuration mode to enable OSPF and add interfaces to Area 0.

user@R1# edit
user@R1# set routing-options router-id 1.1.1.1
user@R1# set protocols ospf area 0.0.0.0 interface ge-0/0/0.0
user@R1# set protocols ospf area 0.0.0.0 interface ge-0/0/1.0
user@R1# commit and-quit
Note: include logical unit suffix such as .0. After commit, Junos sends Hellos and begins neighbor discovery on those interfaces.
Explanation
  • Defining area and interface turns on OSPF Hello packets on that logical interface unit.
  • OSPF network type is auto-detected but can be overridden if needed.
  • Interfaces must reside in the same area ID to form adjacency on that segment.
Common mistake
Forgetting the unit, for example ge-0/0/0 vs ge-0/0/0.0, prevents Junos from applying OSPF to the intended logical interface.
Key Takeaway

Enable OSPF by assigning logical interface units to area 0.0.0.0 to begin neighbor discovery and LSA exchange.
