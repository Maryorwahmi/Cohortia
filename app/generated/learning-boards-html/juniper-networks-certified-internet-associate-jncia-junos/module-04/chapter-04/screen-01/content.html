Configuring OSPF (Single Area)

Translate OSPF concepts into Junos CLI steps: set a stable Router ID, enable OSPF in Area 0, assign interfaces, and verify neighbors and routes.

In this lesson

You will set router identifiers, add interfaces to Area 0, configure passive interfaces for LANs, and verify adjacency and route distribution using Junos operational commands.

Coming up

Explore Key Topics
Router ID
A stable numeric ID, best taken from a loopback, used for LSA origination and elections.
Passive Interfaces
Advertise networks but do not form adjacencies—useful on user-facing LANs.
Verification
Use show ospf neighbor, show ospf interface, and show route protocol ospf to confirm operation.
Network at a glance
Two-router lab: R1 ↔ R2, loopback advertised passive
Example
R1 uses 1.1.1.1 as router-id and advertises a loopback as passive while forming adjacency to R2 on ge-0/0/0.0.
Why it matters
Correct area and interface assignments determine whether routers exchange LSAs and learn remote prefixes.
