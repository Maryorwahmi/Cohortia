Router ID — stable identity for OSPF

A Router ID uniquely identifies the OSPF speaker for LSA origination and elections. Configure it under routing-options to keep it stable.

Definition
A 32-bit identifier represented like an IP address. Used internally by OSPF for identification and LSA origination.
Example CLI
user@router# set routing-options router-id 192.168.1.1
Verify after commit by checking the active configuration and OSPF process to ensure the chosen ID is in use.
Why it matters
  • Stable Router IDs prevent identity changes when physical interfaces go down.
  • Router ID determines LSA originator and appears in neighbor tables and debugging output.
  • Loopbacks are preferred as they remain administratively up and provide stability.
Common misconception
People sometimes think the Router ID must match a real interface address; it only needs to be unique and preferably stable, not necessarily assigned to a physical interface.
Key Takeaway

Explicitly set a Router ID from a loopback so the router identity does not change with link failures.
