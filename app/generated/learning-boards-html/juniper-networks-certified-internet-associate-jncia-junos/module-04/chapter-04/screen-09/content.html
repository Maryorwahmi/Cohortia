OSPF neighbor states — quick reference

  1. Init — Hello received but not bidirectional
  2. 2-Way — Two-way communication established
  3. ExStart / Exchange / Loading — DB synchronization in progress
  4. Full — LSDBs synchronized; adjacency complete
Quick checks when stuck
  • Verify area IDs match
  • Confirm subnet masks and IP reachability
  • Check Hello and Dead intervals
  • Ensure interface is not passive
Concrete example
If R1 shows R2 in Init, check show ospf interface on both routers for Hello and Dead values. If they differ, align them and re-check adjacency.
Common root cause
Mismatched timers or an accidental passive setting are frequent causes of persistent Init state.
Key Takeaway

Let the neighbor state guide your checks: map Init to timers/subnet, ExStart to DB/MTU issues, Full means success.
