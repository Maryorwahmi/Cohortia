Definition › Verify Neighbors & Interfaces

Commands to inspect OSPF state

Run these in operational mode to confirm adjacency and interface details.
user@router> show ospf neighbor
user@router> show ospf interface
user@router> show route protocol ospf
Interpreting output: Neighbor ID and State tell you adjacency progress; interface output shows DR/BDR, timers, and neighbor count.
Concrete example
After adding ge-0/0/0.0 on both R1 and R2, both devices should show the other as Neighbor ID with State Full. If not Full, check timers, area ID, and passive settings.
Misconception
Assuming Full is instantaneous is incorrect; adjacency moves through states such as Init and ExStart before reaching Full.
Key Takeaway

Verify neighbor state, interface details, and learned OSPF routes each time you change configuration to ensure correct operation.
