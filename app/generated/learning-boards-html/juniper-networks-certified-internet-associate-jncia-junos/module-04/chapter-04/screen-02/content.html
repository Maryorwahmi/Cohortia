Learning Objectives

Learn, understand, apply, and start mastering single-area OSPF tasks in Junos.

Learn
Understand
Apply
Master
01
Configure Router ID
Set a stable router-id under routing-options so the identity used for LSAs and elections does not change when interfaces flap.
Mnemonic: loopback → stable ID
VERIFIED COMPETENCY MILESTONE
02
Enable OSPF & Assign Areas
Enable protocols ospf and add interfaces to area 0.0.0.0 so neighbors send Hello packets and exchange LSAs.
Mnemonic: protocols → area → interface
VERIFIED COMPETENCY MILESTONE
03
Use Passive Interfaces
Advertise a directly connected subnet without sending Hello packets to avoid unnecessary adjacencies on LANs with no routers.
Mnemonic: advertise only
VERIFIED COMPETENCY MILESTONE
04
Verify and Troubleshoot
Interpret show ospf neighbor, show ospf interface, and show route protocol ospf to confirm Full state and locate common misconfigurations.
Mnemonic: neighbor → interface → routes
VERIFIED COMPETENCY MILESTONE
