Exercise: Neighbor stuck in Init

You see R2 in Init on R1's show ospf neighbor. List two common reasons and the commands you'd run to check them.

Check 1 — Timers
Command: show ospf interface ge-0/0/0.0 on both routers. Ensure Hello and Dead match.
Check 2 — IP and Mask
Command: show interfaces ge-0/0/0.0 terse or show configuration interfaces to confirm same prefix.
Expected verification
After fixes, confirm adjacency with show ospf neighbor and that the remote loopback appears using show route protocol ospf.
Key Takeaway

Use a short diagnostic checklist: timers, IP/mask, area ID, passive, and filters to resolve Init-state adjacencies quickly.
