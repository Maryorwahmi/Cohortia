Definition › Passive Interface

Passive interface — advertise without adjacency

Passive interfaces include the connected subnet in LSAs but do not send Hellos or form adjacencies.

CLI to make interface passive
user@router# set protocols ospf area 0.0.0.0 interface ge-0/0/2.0 passive
Use passive for loopbacks and access VLAN interfaces. Verify the prefix is in the OSPF LSDB and that no neighbor appears on that interface.
Example scenario
R1 has lo0.0 192.168.1.1/32 marked passive so it is advertised but never tries to form an adjacency on that loopback, keeping it stable.
Misconception
Passive does not stop LSAs for the interface; it only stops Hello packets and adjacency negotiation.
Key Takeaway

Mark access and loopback interfaces passive to advertise subnets while avoiding needless OSPF neighbor traffic.
