Frequent root causes

  • Mismatched Area IDs
  • Mismatched subnet masks
  • Mismatched Hello/Dead timers
  • Authentication mismatch
  • Firewall filters blocking OSPF
These account for the majority of adjacency issues—check them first before advanced debugging.
Troubleshooting commands
show configuration protocols ospf
show interfaces ge-0/0/0.0 terse
show ospf interface ge-0/0/0.0
show ospf neighbor detail
show route protocol ospf
Example
If neighbors are stuck in Init, compare Hello/Dead intervals and area IDs using the commands above to find the mismatch quickly.
Key Takeaway

Follow the checklist of common mismatches to resolve adjacency issues quickly and safely.
