Scenario
+-----+       Ethernet Segment       +-----+
| R1  |------------------------------| R2  |
| Pri:100                            | Pri:50
| RID:1.1.1.1                        | RID:2.2.2.2
+-----+                              +-----+
   |
   |
   |
   +-----+
   | R3  |
   | Pri:1
   | RID:3.3.3.3
   +-----+
Use the election rules: highest priority wins DR, second-highest becomes BDR, ties broken by highest Router ID.
Result
R1 (priority 100) → DR. R2 (priority 50) → BDR. R3 → DRother. If R1 fails, R2 becomes DR and R3 remains DRother until promoted.
Key takeaway

Election is deterministic: priority then Router ID. DR/BDR control adjacency counts on the segment.
