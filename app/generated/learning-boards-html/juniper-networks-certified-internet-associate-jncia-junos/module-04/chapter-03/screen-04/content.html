Module 4 › Chapter 4.3 › Dynamic Necessity
Definition

Dynamic routing protocols let routers discover topology and exchange routing information so routes update automatically when the network changes.

Scalability: eliminates manual route entries across many routers.
Fault tolerance: routes adapt to link failures automatically.
Automatic path selection based on protocol metrics.
Example
A retail campus with many branch routers uses dynamic routing so an uplink failure reroutes traffic over a backup path without manual changes.
Key Takeaway

Choose dynamic routing when scale, automation, or fast failure recovery matter.

Analogy & Misconception
Think of static routing as handwritten directions and dynamic routing as a GPS that updates when roads close. A common mistake is assuming dynamic routing is instantaneous; convergence time still matters and varies by protocol.
Static
Simple, predictable, but breaks on link failure and doesn't scale.
Dynamic
Automated, resilient, and scalable but uses CPU/memory for protocol work.
Try this
When designing, ask: will manual updates be practical after a failure? If not, plan for a dynamic IGP with appropriate hierarchy.
