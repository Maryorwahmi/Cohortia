Link-State fundamentals

Each router advertises LSAs describing its connected links. LSAs are flooded so every router in the area has the same dataset.

Routers store LSAs in the Link-State Database (LSDB).
SPF uses the LSDB to compute loop-free shortest paths (Dijkstra’s algorithm).
Trade-offs and example

Link-state gives faster convergence and a full view of topology at the cost of CPU and memory for LSDB storage and SPF calculations. OSPF and IS-IS are link-state examples.

Misconception
Do not assume link-state has no overhead; routers must store LSAs and run SPF when topology changes occur.
Key takeaway
Link-state protocols are well-suited for large networks that need fast, accurate convergence despite the extra resource cost.
