Question 1
Add a backup path to 172.16.10.0/24 via 10.0.0.9 while keeping the existing preferred route.
user@router# set routing-options static route 172.16.10.0/24 next-hop 10.0.0.9 preference 10
user@router# commit
Explanation: the higher preference makes this a floating backup route.
Question 2
Static route configured but traffic doesn't arrive. What two checks do you perform next?
  1. Confirm configuration was committed.
  2. Verify the next-hop IP is correct and reachable with ping.
Exam tip
When answering configuration questions, include the exact set commands and the verification commands you would run after commit. That demonstrates both configuration and operational competence.
