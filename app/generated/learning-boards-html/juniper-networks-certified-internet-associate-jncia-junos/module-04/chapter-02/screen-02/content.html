Learning Objectives

Learn, Understand, Apply, Master

Bloom: Learn → Understand → Apply → Master
01
Identify appropriate scenarios

Recognize when small or stable networks and stub networks benefit from static routing rather than a dynamic protocol.

VERIFIED COMPETENCY MILESTONE
02
Configure a basic static route

Use the routing-options static hierarchy to set a destination prefix and next-hop, then commit the change to activate forwarding.

VERIFIED COMPETENCY MILESTONE
03
Explain floating static routes

Assign preference values so a backup static route becomes active only if the primary route is unavailable.

VERIFIED COMPETENCY MILESTONE
04
Verify static routes

Use operational commands such as show route protocol static and ping tests to confirm active routes and next-hop reachability.

VERIFIED COMPETENCY MILESTONE
How these objectives connect
  • Choosing when to use static routing reduces configuration overhead in small networks.
  • Correct syntax and commit steps ensure routes actually take effect.
  • Floating static routes provide a lightweight backup without dynamic protocols.
  • Verification prevents blackholes and confirms the routing table state.
Quick mnemonic
S-T-A-T: Select scenario, Type command, Activate (commit), Test (show and ping).
