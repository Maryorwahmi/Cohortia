Module 04 › Chapter 4.2 › Floating static routes for redundancy
Process Flow

Primary and backup via preference

Configure the primary route with a lower preference and the backup with a higher preference. Junos installs the lower preference route into the routing table. If the primary becomes unreachable, the backup with higher preference floats into the table automatically.
user@router# set routing-options static route 192.168.3.0/24 next-hop 10.0.0.5 preference 5
user@router# set routing-options static route 192.168.3.0/24 next-hop 10.0.0.9 preference 10
user@router# commit
Concrete example
Primary link to 10.0.0.5 fails. Junos removes that next-hop from the forwarding table and installs the route via 10.0.0.9 because it is the highest-preference available backup.
Misconception
Floating static routes provide failover but are not as flexible as dynamic protocols that reroute based on multiple metrics.
Key Takeaway

Use preference values to make backup static routes float into place when the preferred route disappears.
