Static Routing on Junos

Manual routes, default routes, and floating static routes give you predictable forwarding paths for small or stable networks. Learn configuration, verification, and safe practices.

In this lesson

You will configure static and default routes, add a floating static route for redundancy, and verify behavior with operational commands.

Why it matters

Static routes reduce device load and surface area for routing updates, making them useful for stub networks and simple Internet access patterns.

Explore Key Topics
Basic static route
Set a destination prefix and a next-hop to control forwarding.
Default route
A 0.0.0.0/0 route directs unmatched traffic to a gateway.
Floating route
A backup static route uses a higher preference value and activates if the primary fails.
