Module 04 › Chapter 4.2 › Configuring a basic static route on Junos
Process

Set, commit, verify

Follow the configuration mode sequence and always commit before testing reachability.

user@router# set routing-options static route 192.168.2.0/24 next-hop 10.0.0.1
user@router# commit
These commands add a static route and apply it to the active configuration.
Common mistake
Forgetting to commit leaves the route in configuration mode only; it will not be present in the routing table.
Verification
Use show route protocol static or ping the next-hop to confirm the route is active and reachable.
Concrete scenario
A branch router needs to reach 192.168.2.0/24 across a single WAN peer at 10.0.0.1. A static route directs that traffic to the peer and removes the need for a routing protocol on this single hop.
Check your understanding
If your static route was set but you cannot reach the destination, what two things will you check first?
  • You committed the configuration.
  • The next-hop IP is correct and reachable.
