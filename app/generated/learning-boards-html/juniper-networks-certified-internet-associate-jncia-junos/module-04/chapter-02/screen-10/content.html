Module 04 › Chapter 4.2 › Common mistakes and safety issues
Risks
  • Blackhole from an incorrect or unreachable next-hop.
  • Configuration not active because commit was omitted.
  • Possible routing loop from reciprocal static entries if not planned.
Preventive steps
  1. Double-check destination prefix and next-hop for typos.
  2. Commit immediately and then run verification commands.
  3. Ping the next-hop and check interface state on adjacent routers.
Quick checklist
Commit the configuration, run show route protocol static, ping the next-hop, and watch for preference and active route indicators to ensure reachability before leaving the change.
