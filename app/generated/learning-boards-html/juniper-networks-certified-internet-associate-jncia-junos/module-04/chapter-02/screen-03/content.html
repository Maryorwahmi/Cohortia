Core focus

Practice the hands-on activity

Follow the lab to configure a route to 192.168.50.0/24, add a default route, and create a floating static route for redundancy.

Objective 05
Recognize common mistakes and safety issues
Identify forgetting to commit and unreachable next-hops as primary causes of static route failures, and learn how to test to avoid blackholes.
VERIFIED COMPETENCY MILESTONE
Quick checks
  • Always commit in configuration mode to activate a static route.
  • Ping the next-hop to ensure it is reachable before relying on the route.
  • Use show route protocol static to confirm which static routes are installed and which are active.
