Module 04 › Chapter 4.2 › Verifying static routes on Junos
Command panel
user@router> show route protocol static
user@router> show route 192.168.50.0/24
user@router> ping 10.0.0.2
These commands list static routes, inspect a specific prefix, and test reachability to the next-hop.
What to look for
  • A static route entry for the prefix.
  • The active marker or preference showing which route is installed.
  • Ping responses from the next-hop confirming reachability.
Troubleshooting steps
  1. Confirm the route exists with show route protocol static.
  2. Ping the next-hop IP to test reachability.
  3. Check interface administrative and physical state if ping fails.
Pro tip
If a static route is present but not active, verify there isn't a more specific route or a better path selected by policy.
