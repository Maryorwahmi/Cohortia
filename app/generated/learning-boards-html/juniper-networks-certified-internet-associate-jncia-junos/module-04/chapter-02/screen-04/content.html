Core Concept

What is a static route?

A manual routing entry specifying a destination prefix and a fixed next-hop for forwarding.

Simple example
Route 192.168.2.0/24 via next-hop 10.0.0.1 sends any traffic for that subnet to the adjacent router at 10.0.0.1.
When it helps
Ideal for stub networks or a single WAN link where routes rarely change.
Misconception
Static routing is not automatically fault-tolerant; without a backup it can blackhole traffic if the next-hop fails.
Key Takeaway

Use static routes where simplicity and stability are more important than automatic adaptation; always verify next-hop reachability.

Analogy

Think of a static route as a fixed street sign you install. It directs traffic along a single path until someone removes or updates the sign. It is predictable, cheap to maintain, but won’t reroute you if the street is closed unless you add an alternate sign.

Concrete example
user@router# set routing-options static route 192.168.2.0/24 next-hop 10.0.0.1
user@router# commit
This command installs a static route to 192.168.2.0/24 via 10.0.0.1 and activates it with commit.
