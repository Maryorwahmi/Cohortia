Module 04 › Chapter 4.2 › Key Concepts
Static Route
A manually configured path for a specific prefix.
Default Route (0.0.0.0/0)
Route of last resort for unmatched destinations.
Floating Static Route
A backup static route with a higher preference that activates if the primary fails.
Summary takeaway
Static routing is simple and predictable; always commit changes and verify next-hop reachability to avoid blackholes. Use floating static routes for basic redundancy when dynamic routing is not required.
