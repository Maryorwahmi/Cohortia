Module 04 › Chapter 4.2 › Default route (0.0.0.0/0)
Definition

Route of last resort

Directs traffic that lacks a more specific route to a configured gateway next-hop.

user@router# set routing-options static route 0.0.0.0/0 next-hop 172.16.0.1
user@router# commit
This installs a default route sending unmatched traffic to 172.16.0.1.
Operational note
After committing a default route, verify it with show route 0.0.0.0/0 and ping the next-hop to confirm connectivity. Without a default route internal hosts may not reach external destinations even if internal routes exist.
Misconception
A default route will not override more specific routes; specific prefixes always match before 0.0.0.0/0.
