Module 04 › Chapter 4.2 › When to choose static vs dynamic routing
Comparison

Static vs Dynamic

Static
  • Low CPU and memory usage
  • No routing updates exchanged
  • Predictable and secure for small setups
Dynamic
  • Automatic discovery and failover
  • Better for scaling and complex topologies
  • Requires routing protocol overhead
Misapplication example: installing static routes across dozens of sites becomes tedious and error-prone. Instead, reserve static routes for stable, limited-scope paths and use dynamic protocols where topology changes frequently.
Use case: stub network
If a network has a single exit and entry point, a static route is sufficient and simpler to operate than running a routing protocol on that segment.
Checklist before choosing
  • Number of routers to manage
  • Frequency of topology changes
  • Need for automatic failover
