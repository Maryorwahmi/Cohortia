Module 4 › Chapter 4.1 › Inspecting routes on Junos
Command examples
Run these in operational mode to view routing information and filter by protocol or prefix.
user@router> show route
user@router> show route protocol direct
user@router> show route protocol static
user@router> show route 0.0.0.0/0
In output, + = active route, and lines show destination, preference/metric, and the next-hop or interface used for forwarding.
Sample output interpretation
Example snippet shows a default route 0.0.0.0/0 learned statically with preference 5 pointing to 192.168.1.1 via ge-0/0/0.0. A directly connected 10.0.0.0/24 appears with preference 0 and via ge-0/0/1.0. The active marker indicates the route currently used for forwarding.
Practical exercise: Run show route protocol direct and pick one route. Explain its destination, next-hop, preference and protocol to confirm forwarding behavior.
Mistake to avoid: Interpreting preference as a metric — preference ranks sources, not path cost.
