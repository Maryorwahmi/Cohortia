Module 4 › Chapter 4.1 › Static vs Dynamic Routing
Comparison
Static — manually configured, no protocol overhead, predictable, best for small or fixed paths.
Dynamic — learned via protocols, adapts to topology changes, scales to larger networks.
Example: Small office uses a static default route to its ISP; a campus uses dynamic routing so routers discover alternative links after a failure.
Operational notes
Static routes require manual updates after topology changes. Dynamic protocols require correct metric and preference tuning to avoid undesired path selection.
Pitfall: A static route left configured after a link change can cause persistent black-holing of traffic.
Rule of thumb: Use static routes for simplicity when topology is stable; use dynamic routing when scale and resilience are required.
Key Takeaway

Choose static for control and simplicity; choose dynamic for scalability and automatic convergence after failures.
