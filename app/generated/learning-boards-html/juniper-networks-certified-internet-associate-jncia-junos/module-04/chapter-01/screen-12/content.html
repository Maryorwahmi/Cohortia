Module 4 › Chapter 4.1 › Key Concepts
Routing
Selecting paths for packets across IP networks.
Router
A Layer 3 device that forwards IP packets between networks.
Routing Table
Lists destinations, next-hops, interfaces, metrics and preferences used for forwarding.
Takeaway
Use the routing table and longest prefix match to explain forwarding decisions. Check next-hop, interface, preference and metric when troubleshooting reachability.
