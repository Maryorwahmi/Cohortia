Module 4 › Chapter 4.1 › What is IP routing?
Definition
Routing explained
Routing selects a path across multiple networks so packets can reach destinations outside the local network.
Example: Host on 10.0.0.0/24 sends to 192.168.1.10; router chooses next-hop toward that network.
Misconception: Routers know everything by default. Reality: routers only know configured, connected, or learned routes.
Why it matters: Missing routes or wrong masks can isolate hosts or services.
Key Takeaway

Routing maps are essential for inter-network reachability; the routing table is the router's map.

Analogy
Postal service: addresses correspond to IPs, cities to networks, and routers to sorting centers that read the address and forward to the next center toward the destination.
When routing is used
Any time a packet must leave its local IP network to reach a different network or the internet.
When switching suffices
When traffic stays inside the same broadcast domain and forwarding is done by MAC address.
