Module 4 › Chapter 4.1 › Router vs Switch
Comparison
Layer 2 Switch
Forwards frames based on MAC addresses inside a VLAN or broadcast domain.
Router
Forwards IP packets between networks using a routing table and longest prefix match.
Example: Two hosts on different subnets require routing; a switch alone cannot bridge their subnets unless it has Layer 3 features.
Misconception: All switches route between VLANs. Reality: Only Layer 3 switches or routers perform inter-subnet routing.
Practical check
To verify behavior, look at traffic that must cross subnets. If MAC learning tables suffice, switching is enough. If IP routing or route lookups occur, a router is involved.
Quick test: ping from one subnet to another and watch whether the router's route table shows the destination network.
Why it matters: Knowing which device performs routing informs where you configure access control, NAT, or route redistribution.
