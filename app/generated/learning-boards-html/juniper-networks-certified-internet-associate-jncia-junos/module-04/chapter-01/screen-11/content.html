Module 4 › Chapter 4.1 › Common routing mistakes
Common issues
Missing route or default route causes packet drops to unreachable networks.
Incorrect subnet masks result in wrong route matches and misdirected traffic.
Unexpected route sources: verify preference and protocol to ensure the chosen route is trustworthy.
Step-by-step debug
1. Confirm interface and IP assignment. 2. show route protocol direct to see connected networks. 3. show route 0.0.0.0/0 to check default route. 4. Inspect static and dynamic routes and their preferences.
Quick takeaway

Start with connected routes and default route checks, then broaden to static and dynamic sources when a destination remains unreachable.

Diagnostic hint: TTL-expired or ICMP unreachable messages can tell you which hop refused or dropped the packet.
