Module 4 › Chapter 4.1 › Routing table components
Definition
Destination Prefix — network or host reachable, e.g., 192.168.1.0/24.
Next-Hop Address — the next router IP or indication of directly connected.
Outgoing Interface — local interface used to forward the packet.
Metric — cost from a dynamic protocol; lower is preferred by that protocol.
Preference — administrative ranking of trustworthiness; lower is more trusted.
Protocol — how the route was learned: Direct, Static, OSPF, BGP, etc.
Scenario
Given a routing table entry, you can explain forwarding: a route to 10.0.0.0/24 via next-hop 192.168.1.1 on ge-0/0/0 means packets to 10.0.0.x are sent toward that next-hop on that interface.
Example: Default route 0.0.0.0/0 [Static/5] to 192.168.1.1 via ge-0/0/0.0 — used when no other specific match exists.
Mistake to avoid: Wrong subnet mask on a destination makes a route either too broad or too narrow, causing incorrect forwarding or unexpected drops.
Key Takeaway

Interpreting each field explains why a router chooses that route and whether it should be trusted in forwarding decisions.
