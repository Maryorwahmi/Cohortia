Module 4 › Chapter 4.1 › Packet forwarding steps
Process Flow
1. Inspect destination
Read the destination IP from the packet header.
2. Longest prefix match
Find the most specific route in the routing table that matches the destination.
3. Select next-hop/interface
Determine the outgoing interface and next-hop IP from the chosen entry.
4. Update TTL and checksum
Decrement TTL and recalc IP header checksum to prevent loops.
5. Encapsulate and forward
Wrap in a Layer 2 frame suitable for the outgoing link and transmit.
Example walkthrough
Packet to 192.168.1.10: router finds 192.168.1.0/24 entry, next-hop 10.0.0.1 via ge-0/0/0.0, TTL decremented, checksum updated, egress on ge-0/0/0.0.
Common misconception: Preference values decide the route during prefix selection. Correction: Preference is used when multiple routes exist for the exact same prefix; longest prefix matching happens first.
Pro tip

Watch for TTL-expired ICMP messages to locate where packets are being dropped in a path.
