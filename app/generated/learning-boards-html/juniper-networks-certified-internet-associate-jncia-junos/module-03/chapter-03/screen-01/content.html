Network Utilities and Troubleshooting Tools
Practical commands for reachability, path analysis, service tests, and packet captures on Junos OS.
In this lesson

You will learn how to interpret ping and traceroute outputs, when to use telnet or SSH for testing services, and how to capture relevant traffic with monitor traffic while avoiding common pitfalls.

Why it matters

Fast, targeted troubleshooting avoids long outages. These utilities give you actionable evidence to locate failures and confirm fixes without guessing.

Explore Key Topics
Ping & traceroute, telnet/ssh for service tests, and monitor traffic for packet analysis.
Ping & Traceroute
Confirm reachability and reveal the packet path so you can locate the hop that fails.
Telnet & SSH
Test service ports quickly with telnet; use SSH for secure remote management.
Monitor Traffic
Capture packet headers and payloads with filters to verify application-level behavior.
Quick workflow
Baseline → reachability → path → service → packet capture
Use these steps iteratively: a failed ping calls for a traceroute; a path break calls for a service test; a port or application issue calls for monitor traffic with filters.
Coming up
Hands-on commands and examples you can practice in a terminal demo: ping 8.8.8.8, traceroute to a target, telnet to a port, and monitor traffic with a port filter.
