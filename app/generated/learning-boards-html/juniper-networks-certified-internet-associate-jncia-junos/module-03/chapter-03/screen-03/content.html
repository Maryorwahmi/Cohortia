How to verify each skill
Each objective has a short checklist you can run in a terminal. The goal is to produce evidence you can explain.
Ping & Traceroute
Run multiple pings and a traceroute. Note packet loss, round-trip times, and where a trace stops. These observations guide your next step.
Telnet & SSH
Attempt a telnet to a service port to confirm it's listening, then connect with SSH to verify secure management access.
Monitor Traffic
Run a filtered capture while generating traffic that should match the filter; confirm packet headers and counts match expectations.
Short checklist example
A minimal verification sequence: ping the target five times; run traceroute to find failing hop; telnet to an expected service port; start monitor traffic with a focused filter and reproduce the traffic. Stop captures once you have the evidence.
VERIFICATION
Document success or failure at each step, and record the output snippets that support your diagnosis.
