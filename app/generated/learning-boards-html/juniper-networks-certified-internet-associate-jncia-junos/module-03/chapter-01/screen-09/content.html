Definition

System health commands

Inspect processes, memory, storage, and uptime to determine whether the system is contributing to network issues.

show system processes extensive
Shows CPU usage per process and helps identify runaway tasks.
show system memory
Reports memory allocation and free memory that supports control and data plane functions.
show system storage
Displays disk space; full storage can block logs and backups.
Key Takeaway

Include system health checks in routine monitoring to detect resource-driven incidents quickly.

Example commands and outputs
show system uptime
show system processes | no-more
show system memory
show system storage
Scenario
If user reports are intermittent, check processes and memory to rule out resource spikes before examining network-level causes.
Misconception
High CPU does not always mean heavy traffic; it can be a management or control-plane issue. Use precise process-level outputs to decide the next steps.
