Operational Mode
The default read-only mode for show commands and diagnostics.
show interfaces
Terse for discovery; extensive for counters and physical details.
show route
Authoritative view of learned routes, next-hops, and source protocols.
Summary

Use operational show commands to collect evidence, filter outputs to focus, and correlate interface, routing, and system data before making changes.
