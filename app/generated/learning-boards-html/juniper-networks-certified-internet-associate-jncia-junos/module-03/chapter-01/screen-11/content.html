Common Mistake

CRC and Input Errors

CRC and input error increases usually mean corrupted frames on the link. They are not routing problems and should be handled as physical or link-layer issues first.

Immediate checks
  • Verify duplex and speed on both ends of the link.
  • Replace the cable with a known-good cable and test again.
  • Swap the transceiver or try a different port if available.
Alert

Do not assume CRC errors are software or routing faults. Physical checks are the right first step.

Example diagnostics
# show interfaces ge-0/0/1 extensive
  Input errors: 345 CRC errors
  Output errors: 0
  Drops: 12

Next steps: check cable, verify duplex, swap transceiver
If swapping cable clears errors, you’ve found the cause. If errors persist across multiple ports and cables, the remote device or NIC may be faulty.
