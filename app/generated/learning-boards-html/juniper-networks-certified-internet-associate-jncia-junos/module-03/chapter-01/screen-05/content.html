Core Concept

show interfaces terse

Quickly lists interface names, admin/link states, and protocol bindings. Ideal for locating a port to inspect further.

Typical workflow
  1. Run show interfaces terse to locate the relevant interface name.
  2. Run the extensive command on that interface to view counters.
  3. Form a hypothesis (physical, routing, or resource) and test further.
Key Takeaway

Start with terse to identify candidates; it’s fast and non-disruptive.

Example output
# show interfaces terse
Interface               Admin Link Proto    Local                 Remote
ge-0/0/0                up    up
ge-0/0/0.0              up    up   inet     192.168.1.1/24
                                   inet6    fe80::.../64
Misconception
An interface showing up and an IP assigned does not guarantee good traffic; counters may reveal drops or CRC errors.
Check
If you see the interface here, run show interfaces <name> extensive next to read counters and errors.
