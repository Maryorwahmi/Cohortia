Hands-on Activity

Interface and Route Verification

Follow these steps in your lab or on a device to verify interface health and route presence.

  1. Log in and run show interfaces terse to locate candidate interface name such as ge-0/0/0.
  2. Run show interfaces <interface> extensive and note Link-level, Speed, State, and error counters.
  3. Run show route and search for 0.0.0.0/0 to confirm default route and the next-hop address.
  4. Run show system uptime and show system processes | no-more to check for recent reboots and CPU-intensive processes.
Key Takeaway

Document observed counters and next hops. That record helps confirm whether an issue is transient or persistent.

Expected snippets
# show interfaces terse
ge-0/0/0                up    up
# show interfaces ge-0/0/0 extensive
  Physical link is Up
  Input errors: 0, Output errors: 0
# show route
0.0.0.0/0          *[OSPF/10]
  > to 192.168.1.2 via ge-0/0/0.0
If error counters are increasing, focus on physical checks and duplex settings. If the default route is missing, check neighbor adjacency and routing protocol state.
