How to read show route

Look for the destination prefix, the protocol tag and preference, and the active next-hop line that shows where packets will be sent.

Common filters
  • show route <prefix> — query a specific destination.
  • show route protocol ospf — view routes learned by OSPF only.
  • show route table inet.0 — view the default IPv4 unicast table.
Key Takeaway

Treat the routing table as your source of truth for reachability; use filters to focus on protocol or table of interest.

Example
# show route
inet.0: 10 destinations, 10 routes (10 active, 0 holddown, 0 hidden)
0.0.0.0/0          *[OSPF/10] 00:01:23, metric 1
                    > to 192.168.1.2 via ge-0/0/0.0
192.168.1.0/24     *[Direct/0] 00:02:45
                    > via ge-0/0/0.0
Misconception
Seeing a protocol configured does not mean routes exist. Always check the routing table for active routes and next-hops.
Pro tip
Use specific prefix queries to speed verification: show route 10.0.0.0/8 will tell you immediately if that destination is present.
