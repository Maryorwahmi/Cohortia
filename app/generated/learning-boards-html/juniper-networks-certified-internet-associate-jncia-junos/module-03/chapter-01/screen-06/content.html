Process Flow

From terse to extensive

After identifying an interface with terse, run the extensive view to inspect counters and physical parameters that reveal underlying problems.

Inspect these fields
  • Link-level type, MTU, Speed, Duplex — basic capability and negotiation.
  • State and Physical link is Up — confirm both administrative and physical link.
  • Input errors / Output errors / Drops — counters that indicate corruption, mismatch, or congestion.
Key Takeaway

Compare counters over time. Increasing error counts are actionable signals to check cables, interfaces, or duplex settings.

Example extensive output
# show interfaces ge-0/0/0 extensive
  Physical interface: ge-0/0/0, Enabled, Physical link is Up
  Link-level type: Ethernet, MTU: 1514, Speed: 1Gbps, Duplex: Full
  Input errors: 0, Output errors: 0, Drops: 0
Misconception
A stable 'Up' state alone does not guarantee error-free forwarding. Always check counters for CRC and drops.
Practical step
If you see CRC errors, swap the cable and verify duplex on both ends before replacing hardware.
