Skills & Verification

Practice read-only checks that turn raw outputs into diagnostic hypotheses.

Locate and inspect interfaces
Use show interfaces terse to find candidate ports, then run show interfaces extensive for counters and status. Verified competency milestone.
Confirm routes and next hops
Use show route with a prefix or protocol filter to confirm reachability and the route source. Verified competency milestone.
Check processes and storage
Run show system processes extensive and show system storage to detect runaway processes or full disks. Verified competency milestone.
Form a hypothesis
Ask whether symptoms indicate a physical, routing, or system resource problem before taking corrective action. Verified competency milestone.
