Module 3 › Chapter 3.2 › Interpreting syslog messages
Sample output: show log system-events
Jun 21 10:30:05 R1 rpd[1234]: RPD_OSPF_NBRDOWN: OSPF neighbor 192.168.1.2 (area 0.0.0.0, interface ge-0/0/0.0) is down
Jun 21 10:30:10 R1 rpd[1234]: RPD_OSPF_NBRUP: OSPF neighbor 192.168.1.2 (area 0.0.0.0, interface ge-0/0/0.0) is up
Checklist
  • Confirm timestamps and sequence of events.
  • Note process and mnemonic to target troubleshooting.
  • Identify interfaces and peer IPs for correlation.
Misinterpretation to avoid
Do not treat a single critical line as root cause without checking preceding informational messages for leading indicators.
Scenario
Repeated neighbor down/up entries often indicate link instability or mismatched timers; check interface and physical layer next.
Key Takeaway

Treat logs as a timeline. Use mnemonics and sequence to find the underlying cause.
