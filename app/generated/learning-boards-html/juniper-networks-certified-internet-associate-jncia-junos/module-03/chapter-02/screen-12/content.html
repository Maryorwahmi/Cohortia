Step-by-step commands
edit system syslog
set host 192.168.1.100 any warning
set file system-events daemon info
set file system-events size 1m files 2
up
commit

edit protocols ospf
set traceoptions file ospf-trace.log size 5m files 3
set traceoptions flag packets
set area 0.0.0.0 interface ge-0/0/0.0 traceoptions flag packets
up
commit
Verification
Use show log system-events and show log ospf-trace.log to inspect messages and trace output after reproducing the event.
Critical cleanup
Delete protocols ospf traceoptions and commit to stop tracing and free resources.
Key Takeaway

Always bound traces with size and files, verify outputs, then remove traces immediately after the investigation.
