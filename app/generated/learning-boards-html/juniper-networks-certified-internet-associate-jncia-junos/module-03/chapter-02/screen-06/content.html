Module 3 › Chapter 3.2 › Configuring syslog destinations
Configuration examples
Terminal-style commands you would enter in configuration mode
edit system syslog
set host 192.168.1.100 any info
set file messages any notice
set file security-log security info
set file system-events daemon info
set file system-events size 1m files 2
up
Explain
Host line sends all facilities at info and higher to the remote server. File lines control local storage and rotation.
Verification
After commit, use show log system-events or show log messages to view file contents and confirm filters work.
Common mistake
Sending debug to a remote host will quickly consume bandwidth and storage. Only send necessary severities remotely.
Key Takeaway

Pair severity filtering with rotation to keep remote and local logs useful and bounded.
