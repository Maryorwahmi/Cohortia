Module 3 › Chapter 3.2 › What are traceoptions?
Traceoptions purpose
Traceoptions writes detailed debugging for a named protocol or process into local files; it shows packet contents, state transitions, and internal decisions.
set protocols ospf traceoptions file ospf-debug size 10m files 5
set protocols ospf traceoptions flag packets
set protocols ospf area 0.0.0.0 interface ge-0/0/0.0 traceoptions flag packets
Safety note
Avoid flag all on production systems for extended periods. Trace only what you need and remove it when finished.
Example trace line
Jun 21 10:30:08.123 R1 OSPF rcvd Hello from 192.168.1.2 on ge-0/0/0.0
Misuse risk

Long-running or wide-flag traces can degrade CPU and fill disk. Always bound size and files, then remove traceoptions when done.
