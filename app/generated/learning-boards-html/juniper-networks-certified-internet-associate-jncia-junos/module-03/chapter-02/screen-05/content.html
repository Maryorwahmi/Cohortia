Module 3 › Chapter 3.2 › Facility vs Severity
Router-focused policy
Example
Forward critical and above for security and kernel. Store notice and info locally for daemon events. Avoid remote debug.
Rule Illustration
send security critical to remote; file messages any notice for local review.
Firewall-focused policy
Example
Forward security and authorization at warning or higher for alerting. Keep detailed info locally for forensic review.
Mnemonic
Facility picks the shelf; severity picks how loud the alarm is.
Common mistake
Forwarding all facilities at debug floods collectors and obscures real alerts.
Pro tip
Start narrow. Expand facilities or lower severity only when you need more context for a specific incident.
Key takeaway
Use facility to select sources and severity to control urgency; forward only what supports detection and investigation.
