01
Explain syslog role
Describe how Junos OS uses syslog to record system events and security incidents. Knowing this helps you decide what to capture for auditing and troubleshooting.
VERIFIED COMPETENCY MILESTONE
02
Configure syslog destinations
Set syslog to write to local files or send to remote servers, filtering by facility and severity so logs are useful and efficient.
VERIFIED COMPETENCY MILESTONE
03
Interpret syslog output
Read facility and severity fields in log lines to prioritize incidents and find the root cause faster.
VERIFIED COMPETENCY MILESTONE
04
Use traceoptions safely
Enable targeted traceoptions with flags and rotation, then remove them to avoid CPU and disk impact during normal operations.
