Module 3 › Chapter 3.2 › Enabling traceoptions for OSPF
Safe troubleshooting steps
  1. Plan: choose flags and scope, e.g., packets or state on the affected interface.
  2. Enable: set traceoptions file with size and files to bound storage.
  3. Reproduce: bounce the interface or wait for protocol activity.
  4. Collect: use show log to view the generated trace file.
  5. Cleanup: delete the traceoptions configuration and commit.
edit protocols ospf
set traceoptions file ospf-trace.log size 5m files 3
set traceoptions flag packets
set area 0.0.0.0 interface ge-0/0/0.0 traceoptions flag packets
up
commit
Verification
Run show log ospf-trace.log after reproducing the event to inspect packet-level details and timestamps.
Pro tip

Prefer interface-scoped flags rather than global flags to reduce noise and resource use.
