Module 4 › Chapter 3.4 › request support information
What it collects
  • Configuration and commit history.
  • System logs and protocol trace information.
  • Routing tables and interface statistics.
  • System health and platform-specific diagnostic data.
Include a short incident summary and relevant timestamps when you share the file with support. This context helps engineers pinpoint the right sections of the bundle quickly.
Terminal example
# request support information | save /var/tmp/r1_support_info.txt
Generating support information...
Wrote 5000 lines of support information to '/var/tmp/r1_support_info.txt'

# file list /var/tmp/
r1_support_info.txt
