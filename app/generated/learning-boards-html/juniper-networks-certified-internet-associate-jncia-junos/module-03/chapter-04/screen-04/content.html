Module 4 › Chapter 3.4 › Configuration Backup
Definition & rationale
A backup file captures the active running configuration so you can restore a known-good state. This protects against mistakes, corrupt commits, and failed changes during upgrades.
Common mistake
Relying solely on in-memory commits without creating a saved file can complicate recovery after a failed reboot or software upgrade.
Pro tip
Script a pre-change save and a file-list check so the file presence is verified before you continue.
Terminal example
# save /var/tmp/my_config_backup.conf
Wrote 120 lines of configuration to '/var/tmp/my_config_backup.conf'

# file list /var/tmp/
/var/tmp/:
my_config_backup.conf
...
Example: Save before a planned interface change to enable quick rollback.
Key takeaway: Treat save as the first step of any change window.
