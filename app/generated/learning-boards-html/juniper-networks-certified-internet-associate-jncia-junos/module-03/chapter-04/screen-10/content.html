Module 4 › Chapter 3.4 › Gathering information
Common commands
show interfaces — interface state, errors, counters
show route — routing table entries and paths
ping and traceroute — reachability and path analysis
monitor traffic — short captures on an interface
show log messages and traceoptions — protocol logs and debugging
Example session
# show interfaces ge-0/0/0
# show route 10.0.0.0/24
# ping 10.0.0.1
# monitor traffic interface ge-0/0/0 count 100
