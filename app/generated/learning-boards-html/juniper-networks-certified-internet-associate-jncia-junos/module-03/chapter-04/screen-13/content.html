Module 4 › Chapter 3.4 › Hands-on activity
Activity steps
  1. Save the current configuration: save /var/tmp/initial_config.conf and verify with file list.
  2. Enter configuration mode and add a temporary description to an interface, commit the change.
  3. Collect support information: request support information | save /var/tmp/r1_support_info.txt and verify the file.
  4. Restore the initial configuration: load override /var/tmp/initial_config.conf, run commit check, and commit.
  5. Verify the temporary description is gone and delete temporary files when done.
This sequence builds confidence: creating a backup, making a controlled change, collecting diagnostics, and performing a rollback if needed. Repeat until each command and verification is second nature.
