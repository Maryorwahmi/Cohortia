Module 4 › Chapter 3.4 › Software upgrade procedure
General upgrade steps
  1. Review release notes and platform prerequisites.
  2. Backup the active configuration to local or remote storage.
  3. Copy the package to the device and verify checksum if available.
  4. Run request system software add <package-name> reboot to install and reboot.
  5. After reboot, verify interfaces, routing, and system health.
Quick command
# request system software add junos-package.tgz reboot
Schedule upgrades in maintenance windows and keep a backup copy of the configuration in case you must revert.
