Module 4 › Chapter 3.4 › Restore: override vs merge
load override
Completely replaces the candidate configuration with the file contents. Use when you need to return to the exact snapshot state.
  • Best for full rollbacks after major changes.
  • Removes any candidate changes that are not in the file.
  • Always run commit check before commit.
load merge
Merges file contents into the current candidate configuration, updating or adding statements without discarding others.
  • Best for selective updates or adding configuration snippets.
  • Can leave unintended settings if not reviewed.
  • Also use commit check before commit.
Concrete example
# load override /var/tmp/my_config_backup.conf
# commit check
# commit

# load merge /var/tmp/interface_changes.conf
# commit check
# commit
