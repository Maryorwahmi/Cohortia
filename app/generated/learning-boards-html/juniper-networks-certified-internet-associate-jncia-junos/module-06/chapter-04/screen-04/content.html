Module 6 › Chapter 6.4 › What is NAT and why it matters
Definition

NAT remaps one IP address space into another by modifying IP header addresses of passing packets. It is stateful and records translations for returning traffic.

Packet example
Original: src=192.168.10.10 dst=198.51.100.20. After SNAT: src=203.0.113.10 dst=198.51.100.20. Return traffic arrives to 203.0.113.10 and NAT maps it back to 192.168.10.10.
Why it matters
Conserves public IPv4 and lets private hosts use shared addresses for internet access.
Misconception
NAT is not a substitute for security policies; Junos requires explicit policies to permit translated flows.
Concrete analogy
Think of NAT as a mail forwarding service. Outbound mail is stamped with a shared public address; replies arrive there and the service forwards them internally to the correct private recipient.
Quick bullets
  • Operates on packet headers to remap IP addresses.
  • May be many-to-one (SNAT), one-to-many (pool), or one-to-one (static).
  • Stateful mapping is required to reverse translations for replies.
Key Takeaway

NAT changes only the address fields you configure; choose source, destination, or static mapping for the intended traffic flow.
