Module 6 › Chapter 6.4 › Types of NAT
Source NAT (SNAT)
Translates the source IP of outbound packets so private hosts share public addresses.
Variants
Interface NAT: maps to egress interface IP and uses ports for multiplexing. Pool NAT: assigns public addresses from a configurable pool to distribute load.
Destination NAT (DNAT)
Maps incoming public destination IP/port to an internal private server and port.
Typical use
Expose a web server on a public IP and forward port 80 to an internal IP.
Static NAT
Permanent one-to-one mapping between private and public IPs for servers requiring fixed public addresses.
When to use
Use for services that must be consistently reachable and do not benefit from port translation.
Decision guide
  • Need outbound internet for many hosts with few public IPs → SNAT (interface or pool).
  • Need to allow external clients to reach internal server on specific ports → DNAT (port forwarding).
  • Need a permanent public address for a server → Static NAT.
Common mistake
Exposing more ports than necessary in DNAT increases attack surface. Always limit destination matches to required ports and, when possible, restrict source addresses.
