Module 6 › Chapter 6.4 › Static NAT
Use case
Assign a stable public IP to a server that external clients must reach reliably, for example a mail gateway or an externally-visible application.
Design caution
Static NAT exposes the internal host at the mapped public address without port translation by default. Ensure policies and host hardening are in place before assigning a static mapping.
Checklist
  • Confirm required public IP is available.
  • Document mapping and update DNS if needed.
  • Verify with show security flow session after traffic.
Quick tip

Prefer DNAT for selective services; reserve Static NAT where a fixed public identity is mandatory.
