Module 6 › Chapter 6.4 › Key Concepts — Part 2
Interface NAT (PAT)
Many-to-one NAT using the egress interface IP and port numbers to differentiate sessions.
Pool NAT
Use a pool to distribute outbound translations across multiple public IPs to increase capacity.
Static NAT
Permanent one-to-one mapping providing a fixed public identity for an internal host.
Verification commands
Use show security nat source, show security nat destination, show security nat source persistent-nat and show security flow session to inspect configured rules and active translations.
