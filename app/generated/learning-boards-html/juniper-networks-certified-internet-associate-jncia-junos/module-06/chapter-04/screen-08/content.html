Module 6 › Chapter 6.4 › Destination NAT (DNAT)
How DNAT works

DNAT matches incoming traffic based on destination address and port, then rewrites that destination to the internal server address and port, enabling external access to private services.

Security requirement
After DNAT, create a security policy from the external zone to the internal zone allowing traffic to the translated private address. Without this policy the flow will be dropped.
Configuration note
Be specific in DNAT matches: include the public destination IP and the exact port to avoid unintentionally exposing services.
Key Takeaway

DNAT exposes services by translating destination addresses; pair it with a restrictive security policy to minimize attack surface.

Common mistake
Forgetting to allow the translated destination in a policy, or using too-broad destination matches that expose extra services.
