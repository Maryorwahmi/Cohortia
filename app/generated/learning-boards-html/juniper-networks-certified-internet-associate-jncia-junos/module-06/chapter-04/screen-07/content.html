Module 6 › Chapter 6.4 › Pool NAT
What pool NAT does
Selects public addresses from a configured pool to translate private source IPs, distributing outbound load across multiple public IPs.
When to choose pool NAT
  • When a single interface IP risks port exhaustion.
  • When you want remote servers to see different origin IPs for distribution, logging, or policy reasons.
Design note and caution
Pool NAT scales capacity but can complicate access control on remote services if those services expect a single origin IP. Also ensure logging and monitoring account for multiple translated addresses.
Practical tip

Document the pool ranges so that security teams and external services can whitelist expected public IPs if required.
