Network Address Translation (NAT)
Remaps IP address information in packet headers to enable private-to-public communication while tracking state for return traffic.
Source NAT (SNAT)
Changes the source IP of outbound packets so internal hosts can share public addresses; includes interface and pool variants.
Destination NAT (DNAT)
Maps incoming destination IP and port to an internal server; requires a corresponding security policy to permit the translated flow.
Summary
NAT types are tools: pick the one that changes the correct header field for your design, and always verify with show security nat and show security flow session after deployment.
