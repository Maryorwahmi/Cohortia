Module 6 › Chapter 6.4 › Configuring Source NAT
Junos configuration template
# Enter configuration mode
edit

# 1. Define the NAT rule set
set security nat source rule-set trust-to-untrust from zone trust
set security nat source rule-set trust-to-untrust to zone untrust

# 2. Create a rule within the rule set
set security nat source rule-set trust-to-untrust rule interface-nat match source-address 0.0.0.0/0
set security nat source rule-set trust-to-untrust rule interface-nat then source-nat interface

# Commit the changes
commit and-quit
Verification
  • show security nat source rule-set trust-to-untrust
  • show security nat source persistent-nat (after traffic)
  • show security flow session (to see active translated sessions)
Common mistake
Not creating or enabling a security policy from trust to untrust. NAT without a policy still results in blocked traffic.
Concrete example
Internal network 192.168.10.0/24 in zone trust needs internet access via untrust interface with a public IP. The sample configuration above sets interface NAT for all sources in that zone.
Key Takeaway

After committing your NAT rule-set, generate traffic and use flow and nat show commands to validate active translation entries.
