Trace packet changes
Practice tracing one packet from a private host to the internet and note the source IP before and after translation. This reinforces why NAT conserves public addresses.

Match scenarios to NAT types
Given a design scenario, choose SNAT for outbound sharing, DNAT for exposing services, and Static NAT for a permanent one-to-one mapping.

Implement and verify SNAT
Configure an interface-nat rule-set, generate traffic, then run show security nat source rule-set and show security flow session to confirm translations.

Implement DNAT and policies
