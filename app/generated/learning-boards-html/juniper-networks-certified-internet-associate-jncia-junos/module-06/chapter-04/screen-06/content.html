Module 6 › Chapter 6.4 › Interface NAT (PAT/NAPT)
Step-by-step flow
1. Packet exits private host
2. Router replaces src IP with egress interface IP
3. Port rewrite and state recorded
Interface NAT relies on the combination of translated source IP and source port to create unique mappings. The NAT device maintains a table so that returning packets are translated back to the original internal source IP and port.
Key Takeaway

Interface NAT is efficient for many hosts but relies on port space; monitor session counts to avoid port exhaustion.

Common mistake
Assuming source ports are preserved and not checking for collisions during heavy outbound connection loads.
Concrete example
Three hosts in 192.168.10.0/24 open connections to different web servers. The SRX replaces each source IP with 203.0.113.10 and assigns distinct ephemeral source ports so replies return correctly to each host.
Verification commands
After generating traffic: show security nat source persistent-nat; show security flow session. These show active translations and session mappings.
Pro tip
When you expect many concurrent sessions, monitor session counts and plan for pool NAT or additional public addresses to avoid port depletion.
