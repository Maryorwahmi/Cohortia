Module 6 › Chapter 6.3 › Configuring Zones and Assigning Interfaces
Code Walkthrough
Example commands to create zones and assign interfaces. Use these as a template in configuration mode on an SRX.
# Enter configuration mode
edit

# Create security zones
set security zones security-zone untrust
set security zones security-zone trust
set security zones security-zone dmz

# Assign interfaces to zones and set host-inbound-traffic
set security zones security-zone untrust interfaces ge-0/0/0.0 host-inbound-traffic system-services ping
set security zones security-zone trust interfaces ge-0/0/1.0 host-inbound-traffic system-services all
set security zones security-zone dmz interfaces ge-0/0/2.0 host-inbound-traffic system-services http

# Commit the changes
commit
Explanation
  • Create named zones so policies can reference meaningful contexts.
  • Assign exact physical or logical interfaces to the appropriate zone name.
  • Set host-inbound-traffic to limit services the SRX accepts on those interfaces.
Concrete example
Assign your WAN link to untrust and allow ping to verify connectivity, but avoid enabling management services on that interface. Put your internal switch uplink in trust and keep host-inbound-traffic minimal to avoid exposing firewall management to user networks.
Common-mistake
Forgetting to commit or leaving host-inbound-traffic too permissive can create unexpected exposure. Always verify after commit with show security zones.
