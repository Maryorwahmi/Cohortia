Module 6 › Chapter 6.3 › Security Policies: Structure and Semantics
Term
Security policy
A directional rule that matches traffic based on zone, addresses, ports or application, and then applies an action.
Example policy summary
From trust to untrust: match any source, any destination, any application, then permit.
from-zone: trust to-zone: untrust match: source-address any, destination-address any, application any then: permit
Takeaway
Be explicit: direction, match criteria, and action define the policy. Specific matches should be placed before general ones to avoid shadowing.
Concrete example
Allow HTTP from the internet to a DMZ web server by matching destination-address to the server and using the junos-http application to limit to port 80.
Common misconception
Policies are not symmetric. A permit from trust to untrust does not permit traffic from untrust to trust. You must author each directional rule you need.
