Module 6 › Chapter 6.3 › Applications and Match Conditions
Match elements
Policies can match on addresses, ports, and applications. Using application names keeps policies readable and reusable.
junos-http
junos-https
junos-ssh
Define address-book entries for important hosts and reference them in destination-address to avoid repeating IPs across policies.
Takeaway
Use predefined applications when they match the service; create address entries for hosts to make policies clearer and easier to maintain.
Concrete example
Create an address-book entry for the web server IP and match junos-http and junos-https in the policy so only those services reach the host from untrust.
Common mistake
Relying on port numbers alone can lead to errors; a mistyped port or ephemeral port mismatch may cause a policy not to match as expected.
