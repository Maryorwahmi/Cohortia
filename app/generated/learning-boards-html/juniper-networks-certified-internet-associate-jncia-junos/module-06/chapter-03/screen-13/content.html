Module 6 › Chapter 6.3 › Key Concepts — Part 1
Security Zone
A named grouping of interfaces that share a security posture for policy enforcement.
Security Policy
An ordered, directional rule with from-zone, to-zone, match criteria, and an action.
Default Deny
If no policy matches between zones, the traffic is denied by default.
Summary takeaway

Zones organize interfaces, policies control flows between those zones, and default deny ensures safety when rules are incomplete.
