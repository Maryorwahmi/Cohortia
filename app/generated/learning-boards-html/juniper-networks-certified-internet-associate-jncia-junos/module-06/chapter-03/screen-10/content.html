Module 6 › Chapter 6.3 › Verify and Troubleshoot Policies
Verification commands
Use the following commands after attempting traffic to inspect configuration and live flow handling.
# Examples for verification (run after generating traffic)
show security zones
show security policies
show security flow session
monitor traffic interface ge-0/0/0 detail
Checklist
  • Confirm the interface is in the expected zone.
  • Verify policy order and match conditions for the correct zone pair.
  • Inspect active sessions to see which policy matched.
Concrete troubleshooting example
If a client cannot reach a server, check the client's interface zone, then the server's zone, and finally run a session inspect to see which policy handled or denied the packet. Often a missing match or wrong policy order is revealed this way.
Common mistake
Assuming a policy applies globally; verification often shows a mismatch in zone pair or an earlier rule shadowing the intended policy.
