Routing Engines and Forwarding Engines

Understand the roles and how redundancy at each layer preserves operation.

Routing Engine (RE)
Controls routing protocols, the CLI, and builds forwarding tables. A standby RE stores configuration and protocol state for takeover.
Example
A chassis with two REs provides a backup that can run graceful switchover to avoid re-convergence delays.
Packet Forwarding Engine (PFE)
Performs the actual packet forwarding at line rate. Redundant PFEs can prevent forwarding-plane outages when a line card fails.
Operational note
Verify that forwarding plane state is synchronized or pre-populated to avoid a forwarding pause during switchover.
Power & Cooling
Redundant power supplies and fans keep hardware available.
Cabling
Ensure management and data plane cabling avoid single points of failure.
Testing
Regularly simulate failures to validate the combined hardware/software behavior.
