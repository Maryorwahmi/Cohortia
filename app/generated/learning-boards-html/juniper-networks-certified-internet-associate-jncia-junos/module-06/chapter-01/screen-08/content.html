Link Aggregation Group (LAG)

Bundle physical links into one logical interface for capacity and resilience.

How it helps
  • Combines the capacity of member links into a single logical link.
  • Provides redundancy so a failed member does not drop the logical interface.
  • Negotiation and health checks are commonly handled by LACP.
Example
Two 1 Gbps links in a LAG present as one 2 Gbps logical interface; if one fails, the logical interface remains available at 1 Gbps.
Limitations and misconceptions
Load balancing uses per-flow hashing; a single large flow might not use the aggregated capacity evenly. Plan hashing and flow distribution when designing capacity.
Key Takeaway
Use LAGs to combine bandwidth and gain link-level redundancy, and validate with real traffic patterns.
