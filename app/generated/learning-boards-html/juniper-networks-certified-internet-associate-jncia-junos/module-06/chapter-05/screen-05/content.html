Module 6 › Chapter 6.5 › Site-to-Site vs Remote-Access
Site-to-Site
Always-on tunnels between gateways that encrypt traffic between two networks without user action.
Operational traits
  • Gateway-to-gateway configuration
  • Transparent to end users
  • Common for branch office and data center links
Pitfall
If traffic selectors or proxy IDs don't match on both peers, the tunnel will not protect the expected subnets.
Remote-Access
Client-initiated tunnels that provide a single device access to the corporate network, typically using VPN client software.
Operational traits
  • User authentication required
  • Per-device configuration and credential management
  • Ideal for teleworkers and travelers
Pro tip
Centralize authentication and monitor client versions to reduce support load and increase security.
