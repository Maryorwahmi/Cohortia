Module 6 › Chapter 6.5 › IPsec Components
IPsec goals
  • Confidentiality: encryption of payloads.
  • Integrity: detection of modification.
  • Authentication: verify the peer identity.
ESP vs AH
ESP provides encryption and integrity; AH provides integrity only. ESP is typically preferred.
Diffie-Hellman & lifetimes
DH groups enable secure key exchange; lifetimes govern rekey frequency and impact security vs overhead.
Example & troubleshooting
If two peers cannot form SAs, first verify they agree on authentication method, encryption, hash, DH group, and lifetimes for both phases. Phase 1 secures negotiation; Phase 2 protects user data.
Key Takeaway

IPsec is a modular framework: validate each building block to find configuration mismatches quickly.
