Module 6 › Chapter 6.5 › ESP vs AH

How Phase 2 protects user traffic

Phase 2 negotiates the IPsec Security Association that encrypts or authenticates packets. The primary choice is ESP for confidentiality and integrity; AH provides only integrity.

  • •ESP: encryption + integrity; recommended for VPNs.
  • •AH: integrity-only; no payload encryption.
  • •Mode: Tunnel mode wraps the full IP packet for site-to-site use.
  • •Misconception: AH does not protect confidentiality even when combined with other techniques; ESP is the designed choice.
Key Takeaway
Use ESP for confidentiality and integrity. AH lacks encryption and is rarely used alone for VPNs.
Concrete Example
A branch office sends backups through ESP tunnel; the backups remain unreadable if intercepted on the internet.

Protocol Comparison

ESP (Encapsulating Security Payload)
Provides confidentiality, integrity, and authentication for user data. Preferred for site-to-site and remote-access VPNs.
AH (Authentication Header)
Provides integrity and authentication but does not encrypt payload. Useful only in narrow scenarios where confidentiality is not required.
Tunnel vs Transport
Use tunnel mode when networks are being joined or when you need to hide internal addressing; transport is for host-to-host protection.
Common Mistake
Expecting AH to provide privacy. AH ensures integrity but will not encrypt payloads, so use ESP when confidentiality is required.
