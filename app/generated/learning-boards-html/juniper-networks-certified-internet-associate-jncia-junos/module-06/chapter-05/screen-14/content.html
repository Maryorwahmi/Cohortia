IKE (Phase 1)
Establishes a secure, authenticated control channel for key exchange.
ESP (Phase 2)
Provides confidentiality and integrity for user traffic; the preferred data-protection protocol.
st0 Interface
Virtual tunnel interface that binds the VPN to routing and security policies on Junos.
Summary Takeaway
Match cryptographic parameters exactly, bind VPNs to st0 for routing, enable PFS and modern ciphers, and verify both SAs and routing/policy to ensure traffic flows securely.
