Step-by-step Troubleshooting

  1. 1. Compare IKE proposals, IPsec proposals, DH groups, lifetimes and auth method on both peers.
  2. 2. Check IKE and IPsec security associations: show security ike sa; show security ipsec sa.
  3. 3. Verify external-interface in gateway stanza and that public IPs are reachable.
  4. 4. Confirm routing points to st0 and security policies permit tunnel traffic.
  5. 5. Review logs for authentication failures or negotiation errors and adjust configurations.
Fast Commands
show security ike sa show security ipsec sa show interfaces st0 show route table inet.0 | match st0
Operational Tip
Use commit confirmed when testing risky changes and document any key rotations or algorithm changes.
Best Practices
  • Prefer certificates over PSKs for production.
  • Enable PFS to limit the impact of key compromise.
  • Choose modern ciphers (AES with SHA-256 or better).
  • Rotate keys and review VPN logs regularly.
Common Mistake: Relying on very long PSKs without enabling PFS or choosing strong algorithms. PSKs help but do not replace a robust crypto policy.
