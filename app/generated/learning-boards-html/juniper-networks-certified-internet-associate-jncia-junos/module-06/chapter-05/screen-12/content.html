What st0 does

st0 is a virtual interface used as the bind point for IPsec VPNs. Routes that point at st0 are automatically tunneled. The OS treats st0 like any other logical interface for routing and firewall purposes.

Example: Static route
set routing-options static route 10.10.0.0/16 next-hop st0.0
Checklist when traffic doesn't pass
  • 1. Is the st0 interface up and bound to the VPN?
  • 2. Is there a route to the protected prefix that points to st0?
  • 3. Do security policies allow the traffic between the zones?

Security Policies & Zones

After the tunnel binds to st0, traffic must still be permitted by zone-based policies. A typical pattern permits trust to untrust or trust to vpn zones, but you must explicitly allow the protected subnets to traverse the st0 interface.

Sample Policy Idea
Allow traffic from the internal trust zone to the st0 interface and allow replies back to the trust zone; remember to permit required services like ICMP for tests.
Verification Commands
show interfaces st0 show route table inet.0 | match st0 show security policies from-zone trust to-zone vpn
If the tunnel is up but no traffic flows, routing and policy ordering are usually the cause, not the IPsec crypto itself. Fix the policy or route, then re-test with a ping across the protected prefix.
