Router R1 (Master)
This configuration makes R1 the preferred master with preemption enabled and simple authentication.
edit interfaces ge-0/0/0 unit 0 family inet
set address 192.168.1.253/24
set vrrp group 1 virtual-address 192.168.1.1
set vrrp group 1 priority 150
set vrrp group 1 preempt
set vrrp group 1 authentication-type simple
set vrrp group 1 authentication-key "MySecretKey"
After commit, use show vrrp to verify R1 is in master state and advertising the virtual IP to the subnet.
Concrete check
Expected verification: show vrrp lists group 1 with state MASTER on R1, virtual-address 192.168.1.1, priority 150. If it shows BACKUP, verify authentication key and group ID match on the peer.
Key Takeaway

Be explicit with priority and preempt to ensure your intended router becomes the active gateway.
