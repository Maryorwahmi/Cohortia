Configure VRRP on Junos
Set group ID, virtual-address, priority and preempt on an interface and commit. Practice committing safely in lab or simulation.

Secure and troubleshoot VRRP
Use authentication to prevent spoofing and run show vrrp and traffic monitoring to diagnose failures. This avoids false elections and outages.
