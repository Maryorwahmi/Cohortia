Troubleshooting
Diagnose common issues
  1. Confirm interface is up and addresses are correct.
  2. Check group ID, virtual-address and authentication match on all routers.
  3. Run show vrrp and show vrrp detail for state and timers.
  4. Use monitor traffic to capture advertisements on multicast 224.0.0.18.
  5. Verify virtual IP is not assigned elsewhere and interfaces are stable.
Example verification commands
# show vrrp
# show vrrp detail
# monitor traffic interface ge-0/0/0 no-resolve no-port-service detail
If show vrrp shows no peers, suspect authentication mismatch, wrong group ID, or multicast filtering between routers. Fix configuration and re-check advertisements.
