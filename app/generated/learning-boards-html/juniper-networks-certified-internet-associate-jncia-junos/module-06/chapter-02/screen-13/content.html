Activity
Configure and verify VRRP
Follow these steps in a lab or simulator and compare show output with expectations.
  1. On R1: set interface address 192.168.1.253/24 and configure vrrp group 1 virtual-address 192.168.1.1, priority 150, preempt, authentication key.
  2. On R2: set interface address 192.168.1.252/24 and configure vrrp group 1 virtual-address 192.168.1.1, priority 100, authentication key.
  3. Commit on both routers and run show vrrp to verify roles.
  4. Simulate failure: deactivate interfaces on R1 and confirm R2 becomes master.
  5. Bring R1 back up and watch for preemption behavior.
Starter code templates
# R1
edit
set interfaces ge-0/0/0 unit 0 family inet address 192.168.1.253/24
set interfaces ge-0/0/0 unit 0 family inet vrrp group 1 virtual-address 192.168.1.1
set interfaces ge-0/0/0 unit 0 family inet vrrp group 1 priority 150
set interfaces ge-0/0/0 unit 0 family inet vrrp group 1 preempt
set interfaces ge-0/0/0 unit 0 family inet vrrp group 1 authentication-type simple
set interfaces ge-0/0/0 unit 0 family inet vrrp group 1 authentication-key "CohortiaVRRP"
commit and-quit
