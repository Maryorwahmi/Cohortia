Definition
Virtual IP and Virtual MAC
Hosts use the virtual IP as their gateway. The master owns the virtual MAC and replies to ARP, so traffic is forwarded via the master.
ARP behavior
When the master fails, backups take over and begin replying to ARP for the same virtual MAC so hosts keep their gateway mapping.
Important practice
Never assign the virtual IP to a physical interface. Keep it exclusive to the VRRP group to avoid duplicate ARP responses.
Concrete example
R1 and R2 share virtual-address 192.168.1.1 and present a virtual MAC. Hosts ARP for 192.168.1.1 and the master answers. When R1 fails, R2 takes over and answers ARP with the same virtual MAC, preserving connectivity without host reconfiguration.
Misconception
VRRP does not split traffic across routers — only the master handles the virtual IP, so plan capacity accordingly.
Key Takeaway

Keep the virtual IP exclusive to the VRRP group and consider ARP cache timing during maintenance and IP changes.
