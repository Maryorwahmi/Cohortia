Module 06 › Chapter 6.2 › Verification Steps
Lab checklist
  • Assign interface IPs on both routers in the same subnet (e.g., 192.168.1.253 and 192.168.1.252).
  • Configure VRRP group with virtual-address 192.168.1.1 and set priorities.
  • Commit, then run show vrrp to confirm master/backup roles.
  • Simulate master failure by deactivating the interface and confirm failover.
  • Bring master back up and observe preemption based on settings.
Quick command samples
# show vrrp
# show vrrp detail
# monitor traffic interface ge-0/0/0 no-resolve no-port-service detail
