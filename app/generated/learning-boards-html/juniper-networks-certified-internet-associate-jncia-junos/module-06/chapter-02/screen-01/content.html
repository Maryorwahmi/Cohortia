Implementing Redundancy with VRRP
Automatic default gateway redundancy for IP subnets on Junos OS
Interactive 16:9 Masterclass

You will understand VRRP operation, configure group ID and virtual IP, set priorities and preemption, and secure and troubleshoot VRRP groups on Junos devices. Learning VRRP helps keep hosts connected when gateways fail and reduces downtime in production networks.

Concept Preview
Virtual router made of two physical routers
A virtual IP and MAC float between master and backup so hosts always have a working gateway.
In this lesson
How VRRP elects a master, Junos configuration steps, preemption and authentication, and troubleshooting commands.
Coming up
A terminal-style walkthrough configuring R1 and R2, and verification using show vrrp.
