Verification
show vrrp and detail
Use these commands to confirm group state, priority values, and advertisement behavior. show vrrp detail includes authentication and timer information useful for debugging.
# show vrrp
Group 1, State: MASTER, Virtual Address: 192.168.1.1, Priority: 150
# show vrrp detail
Group 1, Advertisement interval: 1 sec, Authentication: simple, Key: Configured
Interpretation tips
  • MASTER vs BACKUP tells you which router currently forwards the virtual IP.
  • Advertisement interval and timers show how fast failover can occur.
  • Authentication fields confirm whether keys are configured and accepted.
Key Takeaway

Capture and compare expected show vrrp outputs during validation so you can quickly spot mismatches in production.
