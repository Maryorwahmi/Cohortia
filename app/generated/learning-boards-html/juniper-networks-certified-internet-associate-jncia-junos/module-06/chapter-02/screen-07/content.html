Process Flow
Configuring VRRP
1. Enter configuration mode and set the interface IP address on each router.
2. Add vrrp group 1 and set virtual-address to the shared gateway IP.
3. Configure priority and preempt as required for your design.
4. Set authentication-type and key if you need protection against spoofing.
5. Commit and run verification commands such as show vrrp and show vrrp detail.
Key Takeaway

Follow a predictable sequence: interface addressing, VRRP group and virtual IP, priority/preempt, authentication, verify.

Verification commands
# show vrrp
# show vrrp detail
# monitor traffic interface ge-0/0/0 no-resolve no-port-service detail
If you do not see advertisements, check that the group ID and authentication match on both routers and that the physical interface is up. Captured advertisements use multicast address 224.0.0.18.
