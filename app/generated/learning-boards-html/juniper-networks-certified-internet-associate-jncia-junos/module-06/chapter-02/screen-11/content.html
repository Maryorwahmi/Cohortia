Definition
VRRP Authentication
Authentication ensures that only routers with the correct key and type accept VRRP advertisements, preventing spoofed master announcements.
Options
  • Simple password (clear text)
  • MD5 (stronger cryptographic hash)
Operational guidance
Choose MD5 where possible, keep keys identical across members, and verify with show vrrp detail if the group fails to form. A mismatch in authentication often shows silence rather than an explicit error.
Warning

Using different authentication keys between routers prevents VRRP groups from forming and breaks redundancy.
