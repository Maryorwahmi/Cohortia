Router R2 (Backup)
R2 keeps the same virtual-address and authentication but uses a lower priority so it stays backup until needed.
edit interfaces ge-0/0/0 unit 0 family inet
set address 192.168.1.252/24
set vrrp group 1 virtual-address 192.168.1.1
set vrrp group 1 priority 100
# optional: set vrrp group 1 no-preempt
set vrrp group 1 authentication-type simple
set vrrp group 1 authentication-key "MySecretKey"
Operational tips
If you want stable mastership without automatic reclaim, configure no-preempt on the preferred master or on backups depending on your design. Document your preemption decision so operations know expected failover behavior.
Key Takeaway

Matching virtual-address and authentication is required; adjust preempt based on stability vs automatic recovery trade-offs.
