Comparison
Master vs Backup
Master
  • Forwards traffic for the virtual IP
  • Responds to ARP for the virtual MAC
  • Sends VRRP advertisements
Backup
  • Monitors advertisements
  • Takes over when master stops advertising
  • Does not respond to ARP while backup
Tip: use clear priority conventions in your network documentation so operators know which router should win elections and why.
Election rules & preemption
Priority value 1–255 selects the master; equal priorities use highest IP as tiebreaker. Preemption causes a recovered higher-priority router to reclaim mastership immediately when enabled.
Example scenarios
  • R1 priority 150, R2 priority 100 → R1 master. If R1 fails, R2 becomes master. If R1 returns and preempt is enabled, R1 reclaims mastership.
  • R1 and R2 priority 120, virtual IP highest on R2 → R2 becomes master.
Key Takeaway

Set priorities deliberately and decide whether preemption should minimize downtime or avoid churn.
