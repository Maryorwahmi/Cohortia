Saving the active configuration
Use save <filename> from operational mode to capture the current running configuration to a path on the device. This is handy before complex changes, and when you want to move config to another device.
Always confirm the save path and file name so you do not overwrite a valuable backup.
Loading files into candidate
Use load <filename> variants to bring file contents into the candidate configuration. Choose the mode carefully: merge adds or updates parts, override replaces everything, replace uses tags to swap sections selectively.
Key Takeaway

Files are a durable safety net. Save before change and verify loads in a candidate before committing.
