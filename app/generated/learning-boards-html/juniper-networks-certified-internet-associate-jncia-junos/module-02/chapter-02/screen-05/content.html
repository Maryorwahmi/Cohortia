Hierarchy view
The hierarchical output shows nested braces and structure, making it easy to see parent-child relationships such as protocols, interfaces, and routing policy sequences.
Use when you need to understand context and related settings before changing anything critical.
Set-style output (flat)
# show configuration | display set
set system host-name MyJunosRouter-v2
set interfaces ge-0/0/0 unit 0 family inet address 192.0.2.1/24
set system services ssh root-login deny
Set-style is ideal for copying lines into a file for load merge or scripting. It flattens nested blocks into individual commands.
Common Mistake

Do not assume set-style preserves comments or original order; it is a reconstruction useful for automation but not a perfect round-trip for human annotations.
