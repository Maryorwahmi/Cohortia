How compare works
The compare output shows lines prefixed with plus for additions and minus for deletions. It reports changes in set-style form so you can see exact statements affected.
Always scan for minus lines. A deletion might remove a service, ACL, or route policy that you did not intend to touch.
Example snippet
# show | compare
- set system services telnet
+ set system services ssh
This shows telnet will be removed and ssh added. Confirm this change matches your intent before commit.
Key Takeaway

Make compare your standard pre-commit check to prevent accidental removals and service disruptions.
