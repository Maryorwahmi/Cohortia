Module 2 › Chapter 2.2 › Rollback Types
Discard uncommitted edits
While in configuration mode, run rollback with no number to abandon any uncommitted changes and restore the candidate to the active configuration.
This is a local undo of the draft, not a restoration from history.
Restore previous commit
Use rollback N to load a prior committed configuration into the candidate. After review, commit to apply it live.
This is the mechanism for recovering from a bad committed change.
Key Takeaway

Use rollback without a number to cancel drafts, and numbered rollback when you need to restore an earlier published state. Validate services after either action.
