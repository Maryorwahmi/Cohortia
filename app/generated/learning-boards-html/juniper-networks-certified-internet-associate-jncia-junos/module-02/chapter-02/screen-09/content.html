Inspect saved commits
# show system commit
commit 0: 2026-09-25 10:05:12 by user
commit 1: 2026-09-24 16:12:03 by admin
commit 2: 2026-09-23 09:00:00 by auto-backup
The list helps you choose which prior configuration to restore.
Rollback procedure
  1. Enter configuration mode.
  2. Run rollback N to load the desired prior configuration into candidate.
  3. Review with show | compare and then commit to make it active.
Key Takeaway

Rollback gives a fast, reliable way to return to a previous known-good state; always verify services after committing the rollback.
