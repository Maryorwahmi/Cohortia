Module 2 › Chapter 2.2 › Common Mistakes
Mistake: Using override unnecessarily
Consequence: unintended removal of unrelated config. Prevention: preview the file and use merge for partial changes.
Mistake: Skipping compare
Consequence: missed deletions or harmful edits. Prevention: make show | compare a mandatory pre-commit step.
Mistake: Forgetting to confirm
Consequence: change auto-rolls back unexpectedly. Prevention: confirm commit confirmed after testing.
Quick checklist
  1. Save current config to a file.
  2. Load into candidate; run show | compare.
  3. Use commit or commit confirmed, test, then confirm or rollback.
Key Takeaway

Prevent outages by making simple checks habitual: preview, compare, and confirm.
