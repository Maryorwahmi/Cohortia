Module 2 › Chapter 2.2 › Load Modes
load merge
Merges file with candidate. Adds new statements and lets file override existing conflicting statements. Use for incremental updates.
load override
Replaces the entire candidate with the file content. Use only when you intend a full configuration replacement.
load replace
Replaces sections marked with replace tags, while merging other sections. Use when only specific blocks need swapping.
Practical checklist
  • Inspect the file contents before loading.
  • Use load merge for adding a neighbor or interface changes without touching unrelated settings.
  • Reserve load override for intended full rebuilds and verify backups first.
Common Mistake

Running load override unintentionally removes unlisted configuration elements. Always back up before override.
