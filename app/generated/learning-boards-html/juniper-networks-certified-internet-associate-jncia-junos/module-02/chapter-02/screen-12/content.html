Terminal steps (illustrative)
# Start from operational mode:
# user@router> configure

# 1. Initial change
set system description "Initial Config Change"
commit

# 2. Second change
set system host-name MyJunosRouter-v2
commit

# 3. View commit history
exit
show system commit
configure

# 4. Risky change with safety
set interfaces ge-0/0/0 description "Testing Rollback Interface"
commit confirmed

# 5. Recover
rollback 0
commit

# 6. Verify
exit
show system description
show system host-name
Guided checks
  • After each edit, run show | compare to catch removals.
  • Use display set when you want to extract lines for automation.
  • Confirm final state with operational show commands after rollback or commit.
Key Takeaway

Follow the sequence: save, change, compare, commit confirmed for risky edits, and rollback if tests fail. Validation is essential.
