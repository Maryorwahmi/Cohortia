Module 2 › Chapter 2.1 › Hands-on Walkthrough

Step-by-step

  1. Access the device via console and authenticate.
  2. Run show version and show interfaces terse to inspect the device.
  3. Enter configure and set hostname to MyJNCIA-Router.
  4. Set a strong root password and configure NTP and SSH.
  5. Run show | compare, then commit and verify with show system hostname and test SSH.
Starter code
# Console start
user@router> configure
[edit]
user@router# set system host-name MyJNCIA-Router
user@router# set system root-authentication plain-text-password
user@router# set system ntp server 1.pool.ntp.org
user@router# set system services ssh
user@router# commit
user@router# exit
user@router> show system hostname
Key Takeaway

Follow the sequence, review changes before committing, and verify active configuration to confirm success.
