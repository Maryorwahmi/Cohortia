Module 2 › Chapter 2.1 › Hostname
Code walkthrough
# From operational mode
user@router> configure
[edit]
user@router# set system host-name MyJNCIA-Router
user@router# commit
# Exit to operational mode
user@router# exit
user@router> show system hostname
MyJNCIA-Router
Example shows setting and committing a hostname, then verifying the active configuration returned by show system hostname.
Practical guidance
  • Use short, unique names that map to location or role.
  • Avoid spaces and unusual punctuation in hostnames.
  • After commit, automated systems will pick up the new name in logs and monitoring tools.
Key Takeaway

Set a clear hostname, commit, and verify with show system hostname to confirm the active configuration reflects your change.
