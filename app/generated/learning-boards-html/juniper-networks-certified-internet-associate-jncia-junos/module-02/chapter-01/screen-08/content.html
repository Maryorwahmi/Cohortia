Module 2 › Chapter 2.1 › Root Password
Secure step
# Set root password (device will prompt for the password)
user@router# set system root-authentication plain-text-password
# commit to apply
user@router# commit
The plain-text-password flow prompts you to type and confirm a password; the CLI avoids echoing the value. After commit, authenticate to verify.
Practical advice
  • Avoid using root for daily tasks; create a role-based admin account instead.
  • Pick a password manager to store complex passwords securely.
  • Plan periodic rotation and enforce strong password policies across devices.
Common mistake

Leaving the root password blank or using weak passwords exposes full device control to attackers.
