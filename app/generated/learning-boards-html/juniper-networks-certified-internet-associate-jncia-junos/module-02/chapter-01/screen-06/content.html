Process Flow

Stage → Review → Commit → Verify

Stage: Make set commands in configure mode to build the candidate configuration.
Review: Use show | compare to inspect differences between candidate and active configuration.
Commit: Apply all staged changes atomically with commit.
Recover: Use rollback to revert the active configuration to a previous committed snapshot if needed.
Pro tip

Run show | compare before any commit and consider commit confirmed when you want edits to persist across sessions.

Command examples
# Inspect differences
user@router# show | compare
# Apply staged edits
user@router# commit
# Revert to previous commit if needed
user@router# rollback 1
Use rollback with care; it restores a past committed configuration and changes the active state. For simple uncommitted edits you can also use exit to discard without impacting the active configuration.
