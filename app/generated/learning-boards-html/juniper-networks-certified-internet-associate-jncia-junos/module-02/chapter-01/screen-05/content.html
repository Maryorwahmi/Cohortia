Definition

Operational mode (read-only)

Use show, ping, and traceroute to monitor and diagnose. These commands do not alter the device state.

• show version — confirm Junos release and hardware.
• show interfaces terse — check interface states and addresses.
• ping — verify reachability.
Definition

Configuration mode (candidate)

Enter configure to stage changes. Use set commands to create a candidate configuration and commit to apply everything atomically.

• set system host-name — stage a hostname change.
• exit — discard uncommitted changes and return to operational mode.
• rollback — revert to a prior committed configuration if needed.
Example
Run show interfaces terse, then configure and set the hostname before committing all changes together.
Misconception
Typing set commands immediately changes the running system — it only stages changes until commit.
