Process

Console then SSH

Follow these steps when starting a fresh device.

  1. 1. Connect console cable to the console port and open a terminal at the device's baud rate.
  2. 2. Use show version to confirm boot and model.
  3. 3. Configure a management interface IP and enable SSH: set system services ssh, commit.
  4. 4. From your workstation, test SSH connectivity and login using a non-root account when possible.
Common-mistake
Assuming SSH will work before the device has IP routing. Always verify IP reachability before relying on remote access.
Key Takeaway

Console for first-touch; enable and test SSH only after you have configured an IP on the management interface.

Terminal snapshot
# Example operational check
user@router> show version
Junos: 18.4R?X
# After basic IP config and enabling SSH
user@router> configure
[edit]
user@router# set system services ssh
user@router# commit
Example shows starting in operational mode, entering configure, setting SSH, and committing. This sequence transitions you from local setup to secure remote management.
