Mistake vs Fix

Forgetting commit — Fix: run show | compare, then commit, and verify with relevant show commands.
Syntax errors — Fix: use tab-completion and ? help to confirm command structure.
Weak root password — Fix: set a strong password and create non-root admins for daily work.
Unverified SSH changes — Fix: test SSH logins immediately after commit and restrict allowed sources.
Quick checklist
  • Review candidate with show | compare.
  • Commit when ready and test changes.
  • Keep a recovery plan — know how to rollback.
Common-mistake

Assuming a configured change is active without committing and verifying is how many outages start.
