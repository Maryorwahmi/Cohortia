Module 2 › Chapter 2.1 › NTP Configuration
Command
# Configure an NTP server
user@router# configure
[edit]
user@router# set system ntp server 1.pool.ntp.org
user@router# commit
# Verify NTP status (operational)
user@router> show system ntp
Using an NTP pool ensures redundancy. Replace the sample pool with your internal NTP server when present for lower latency and controlled time sources.
Why it matters
  • Accurate logs: timestamps across devices match, aiding troubleshooting.
  • Security: certificates and authentication can rely on consistent time.
  • Auditing: event correlation and incident timelines are trustworthy.
Key Takeaway

Configure and verify NTP early so logs and certificates use accurate, synchronized timestamps across your network.
