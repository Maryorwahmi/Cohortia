Module 2 › Chapter 2.1 › Key Concepts
Operational Mode

Commands for monitoring and diagnostics that do not alter device configuration.

Configuration Mode

A candidate configuration is built here and becomes active only after commit.

Commit & Rollback

Commit applies staged edits atomically; rollback reverts to a previous committed state to recover from errors.

Takeaway
Practice Access → Inspect → Configure → Review → Commit → Verify as a repeatable checklist for safe device deployment.
