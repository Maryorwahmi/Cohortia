Commands
# Enable SSH and create a non-root admin
user@router> configure
[edit]
user@router# set system services ssh
user@router# set system login user admin class super-user authentication plain-text-password
user@router# commit
Commit to apply the SSH and user changes, then test by SSHing from your management workstation as the new admin account.
Best practices
  • Create non-root admins for daily tasks and reserve root for emergency use.
  • Restrict SSH access by source IP where possible.
  • Use strong password or public-key authentication and rotate credentials regularly.
Key Takeaway

Enable SSH and create role-based users. Test logins and minimize direct root usage to improve security posture.
