Module 2 › Chapter 2.1 › Skills Checklist

Verification tasks

  • • Log in via console, confirm prompt, and run show version.
  • • Enter configure, set hostname, set root-authentication, set NTP, set system services ssh.
  • • Commit changes and then run show system hostname to confirm.
  • • Practice exit to discard and rollback to restore a previous committed state.

Mnemonic

Remember: Access → Inspect → Configure → Commit → Verify. This sequence prevents accidental downtime by ensuring changes are reviewed before they become active.
Verified Competency Milestone

Successfully set hostname, root password, NTP, enabled SSH, committed, and verified the hostname in operational mode.
