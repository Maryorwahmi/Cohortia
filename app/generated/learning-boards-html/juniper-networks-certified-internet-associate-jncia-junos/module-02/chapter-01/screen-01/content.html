Explore Key Topics
Access Methods
Console for initial setup; SSH for remote management once networked.
Modes & Commit
Operational is read-only; configuration builds a candidate that must be committed.
Initial Tasks
Set hostname, root password, NTP, and SSH before placing the device on the network.
Concept snapshot
Operational Mode

Run show and ping commands to inspect and test without changing configuration.

Configuration Mode

Build a candidate configuration and then commit to apply changes atomically.

Commit

Makes candidate configuration active; forgetting this step leaves changes un-applied.

Common Pitfalls

Incomplete commits, weak root passwords, and mis-typed commands are frequent errors.
