Learning Objectives

Understand, perform, and verify initial Junos CLI tasks.

Bloom: Learn → Understand → Apply → Master
01
Access the CLI

Connect over console for initial setup and enable SSH for remote management once the device has IP reachability. Verified competency milestone.

02
Modes: Operational vs Configuration

Run show and diagnostic commands in operational mode; stage changes in configuration mode before commit. Verified competency milestone.

03
Perform initial configuration

Set hostname, root password, and NTP server; enable SSH and create a non-root admin. Verified competency milestone.

04
Use commit safely

Understand candidate vs active configuration, commit to apply, and rollback to recover. Verified competency milestone.
