Module 2 › Chapter 2.1 › Verification

Show commands

show system hostname — verify the active hostname.
show interfaces terse — check interface states and addresses.
show system ntp — confirm time synchronization.
ping / traceroute — validate connectivity to critical endpoints.
Verification checklist
  • Confirm hostname and management IP are correct.
  • Confirm NTP is synchronized and SSH accepts logins.
  • Run connectivity tests for management and data-plane reachability.
Key Takeaway

A successful commit means the config is active; verify runtime behavior with show commands and connectivity tests to ensure operational correctness.
