Authentication order and fallback
Define which methods the device tries and in what sequence.
Command example
set system authentication-order [ radius password ]
This example tries RADIUS first, then falls back to the local password database.
Best practice
Define a fallback strategy and test it during simulated server downtime.
Pitfall
Assuming remote servers are always available; without fallback you risk administrative lockout.
Runbook tip
Document authentication order and test steps to recover when servers are unreachable.
Key Takeaway
Choose authentication order to balance centralized control with safe local fallback during outages.
