Module 3 › Chapter 2.3 › Local User Creation
Create a local user on Junos OS
Follow these commands in configuration mode and test the new account.
# Log in as root or a super-user and enter configuration mode
user@router> configure

# Create a new user with read-only class
set system login user junior-admin class read-only authentication plain-text-password
# You will be prompted to enter and confirm the password: ReadOnly#1

# Commit the change
commit

# Exit configuration mode
exit
exit

# Test the account by logging in as 'junior-admin' and run show configuration (allowed)
# Attempt to enter configuration mode with 'configure' (should fail)
Example
The sample code above creates junior-admin with read-only privileges and shows the commit and test steps.
Common mistake
Forgetting to commit after configuration changes means the user will not exist at runtime.
Test scenario
Log in as the new user and verify allowed commands like show configuration and that configure is denied.
Key Takeaway
Always test a newly created account immediately to confirm class-based permissions.
