User Accounts and Authentication
Understand local user creation, user classes, remote authentication choices, and practical password policies for Junos OS devices.
In this lesson
You will learn how to add a local user with a class and password, how classes control permissions, when to use centralized RADIUS or TACACS+, and how to apply basic password options to strengthen accounts.
Secure, auditable access
Proper accounts ensure only authorized administrators can change device configuration and make actions attributable for auditing.
Explore Key Topics
Local user accounts
Create users under edit system login with set system login user & authentication commands.
User classes
Classes such as super-user, operator, and read-only define permitted CLI actions.
Remote auth & policies
Use RADIUS or TACACS+ for central user management and consistent password rules.
Visual overview
Local user
Credentials stored on the device for small deployments or fallback.
Central server

Password policy
