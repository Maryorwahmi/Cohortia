Module 3 › Chapter 2.3 › Hands-on: junior-admin
Lab: Create junior-admin and verify permissions
Execute these steps and confirm the expected outcomes.
# Enter configuration mode as super-user
user@router> configure

# Create a new user with read-only class
set system login user junior-admin class read-only authentication plain-text-password
# Enter password when prompted: ReadOnly#1

# Commit and exit
commit
exit
exit

# Log in as junior-admin and test
# junior-admin@router> show configuration  # should work
# junior-admin@router> configure           # should fail with a permission error
Expected result
Read-only commands succeed; entering configuration mode is denied for junior-admin.
Troubleshooting
If configure is allowed, check the user's class and reassign to read-only, then commit.
Safety note
Use unique strong passwords and disable or remove temporary lab accounts after use.
Key Takeaway
Verify both allowed and denied actions to confirm the user's permissions are correct.
