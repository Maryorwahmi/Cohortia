RADIUS and TACACS+ overview
Understand protocol differences and operational uses.
RADIUS
An open-standard protocol that combines authentication and authorization, commonly used for network access such as Wi-Fi and VPNs.
TACACS+
Separates authentication, authorization, and accounting for granular command control and flexible device administration.
Practical note
Choose the protocol that matches your need for centralization versus per-command authorization control.
Example
Use RADIUS to authenticate remote VPN users and TACACS+ to authorize which CLI commands administrators may perform.
Key Takeaway
Both centralize authentication; TACACS+ is better for granular device command control, RADIUS for broad network access.
