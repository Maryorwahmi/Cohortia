What mastery looks like
Concrete checks you can perform after each task.
01 — Create & test
Add a local user, set a password, commit, then log in to confirm permitted commands are correct.
VERIFIED COMPETENCY MILESTONE
02 — Role mapping
Assign operator or read-only classes to prevent configuration changes during routine monitoring.
VERIFIED COMPETENCY MILESTONE
03 — Centralization
Configure authentication-order to use RADIUS or TACACS+ and test fallback to local.
VERIFIED COMPETENCY MILESTONE
04 — Password policy
Set minimum-length and complexity to enforce stronger local passwords and reduce risk.
VERIFIED COMPETENCY MILESTONE
Quick verification checklist
  • Create user and confirm authentication prompt appears.
  • Log in as that user and try both allowed and disallowed commands.
  • Check active accounts and disable inactive ones.
