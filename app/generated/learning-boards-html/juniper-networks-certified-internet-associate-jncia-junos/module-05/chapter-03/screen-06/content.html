Process Flow
next-term and next-policy
Plan whether evaluation should continue within the same policy or jump to another policy in the chain. Missing final accept still causes implicit reject.
1. Term A: match prefix, then local-preference 50, then next-term
2. Term B: match prefix, then local-preference 150, then accept
Outcome: final local-preference = 150
Tip: Use next-policy to chain specialized and default policies so design remains modular and predictable.
Concrete example
set policy-options policy-statement SET-LP term 1 then local-preference 50
set policy-options policy-statement SET-LP term 1 then next-term
set policy-options policy-statement SET-LP term 2 then local-preference 150
set policy-options policy-statement SET-LP term 2 then accept
Misconception: next-term does not mean the term's actions are preserved forever; later terms can overwrite attributes.
Key Takeaway

Use next-term for cumulative edits and next-policy for modular policy composition; always ensure an eventual accept.
