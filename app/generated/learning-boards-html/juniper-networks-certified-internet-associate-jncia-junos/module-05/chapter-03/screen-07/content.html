Definition
local-preference
Used within an AS to prefer exit points. Higher values win in the BGP decision process inside the AS.
set policy-options policy-statement SET-LP term 1 then local-preference 200
  • Set in import policies that affect routes entering your AS.
  • Higher numeric value is preferred during selection.
  • Not advertised to external peers; scope is internal.
Verification
Run show route protocol bgp detail to confirm the local-preference field for the route was updated after policy application.
Pitfall: placing this on export policies will not change what peers see; test in lab before production.
Key Takeaway

Use local-preference to influence internal path selection; set it where routes are imported into the AS.
