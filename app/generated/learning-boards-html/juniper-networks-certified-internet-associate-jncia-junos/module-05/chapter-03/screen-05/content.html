Comparison
Accept vs Reject
Both stop processing, but one allows the route, the other drops it. The implicit reject at policy end can surprise you if you omit explicit actions.
Then accept — install or advertise route and stop processing.
Then reject — drop the route and stop processing.
Implicit reject — if nothing explicit permits, route is discarded at the end.
Concrete example
set policy-options policy-statement TAG-ROUTE term 1 from prefix-list EXAMPLE
set policy-options policy-statement TAG-ROUTE term 1 then community add INTERNAL
# missing then accept → implicit reject occurs
Explanation: The community add runs but without accept the policy will ultimately reject the route, so it won't be installed or advertised.
Key Takeaway

Be explicit: end intended-allowing terms with accept or next-term to avoid the implicit reject.
