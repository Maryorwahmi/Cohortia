Comparison
Metric (MED)
Lower MED values are preferred by the neighbor; use to suggest inbound preference.
set policy-options policy-statement SET-MED term 1 then metric 50
set policy-options policy-statement SET-MED term 1 then accept
Comparison
Origin
Origin declares whether a route came from IGP, EGP, or is incomplete and participates in tie-breaking.
set policy-options policy-statement SET-ORIGIN term 1 then origin igp
set policy-options policy-statement SET-ORIGIN term 1 then accept
Key Takeaway

Use MED to suggest inbound preference to neighbors (lower is better) and set origin only when necessary to influence tie-breaking; understand peer policies before relying on MED.
