Common pitfalls & safety
  • Implicit reject when no explicit accept: causes dropped routes.
  • Misplaced local-preference: set in import, not export, to be effective.
  • Overwriting communities with set removes prior tags unintentionally.
  • Prepending AS can create loops; use caution and test.
  • MED depends on peer agreement and is not always honored.
  • Next-hop must be reachable from peers to avoid blackholing.
  • Always verify using show route protocol bgp detail and advertising-protocol output.
Safety Note

Modifying BGP attributes affects global routing; validate changes in a lab and stage carefully to prevent instability.
