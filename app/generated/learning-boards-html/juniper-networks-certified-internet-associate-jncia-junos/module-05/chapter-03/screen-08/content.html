Definition
Community: add / set / delete
Tag routes for later filtering, tracking, or export behavior using named communities.
set policy-options community INTERNAL-TRACKING members 65001:100
set policy-options policy-statement TAG-ROUTE term 1 then community add INTERNAL-TRACKING
set policy-options policy-statement TAG-ROUTE term 1 then accept
Practical notes
  • Use add to preserve existing communities and append new tags.
  • Use set only when you mean to replace all communities on the route.
  • Use delete to remove a specific community when cleaning tags.
Verify with show route advertising-protocol bgp <neighbor> and confirm community values reach the neighbor when expected.
Key Takeaway

Appending communities preserves context; replacing communities can remove important tags. Choose add vs set carefully.
