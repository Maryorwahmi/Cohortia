next-hop edits
Set the forwarding hop used by other routers. Ensure the next-hop is reachable to avoid blackholing traffic.
set policy-options policy-statement SET-NEXT-HOP term 1 then next-hop self
set policy-options policy-statement SET-NEXT-HOP term 1 then accept
Use peer-address or an explicit IP when specific forwarding behavior is required. Always verify reachability from the neighbor.
Common mistake
Advertising a prefix with an unreachable next-hop causes traffic to be dropped at the peer. Validate the next-hop before committing.
Key Takeaway

Next-hop must be routable from the neighbor. Use self to make your router the forwarder and avoid reachability issues.
