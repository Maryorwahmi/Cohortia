Common 'from' criteria
Use these matches to target traffic precisely and avoid overbroad rules.
Addresses
source-address and destination-address with CIDR to match networks or single hosts.
Ports and protocol
source-port, destination-port, and protocol like tcp, udp, or icmp.
Interface and flags
Match the incoming interface or TCP flags when needed for precise control.
Example: narrow match
Match SSH from a single management host to the router’s management interface:
from {
  source-address 192.168.1.10/32;
  destination-port 22;
  protocol tcp;
}
All three conditions must be true for the term to match. If any are absent, the packet does not match this term and processing continues to the next term.
Misconception

Adding multiple match clauses does not create partial matches; the term only matches when every clause is satisfied.
