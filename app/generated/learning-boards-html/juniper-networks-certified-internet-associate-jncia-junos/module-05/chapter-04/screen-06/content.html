Core Concept
Terms: 'from' and 'then'
Use terms to express match criteria and the resulting actions in readable, ordered blocks.
Match conditions (from)
Source and destination address, ports, protocol, interface, and TCP flags are common matches you can combine.
Actions (then)
Accept, discard, reject, count, log, and policer define what happens after a match.
Key Takeaway

Compose terms clearly: specific matches and actions first, general catch-alls last. Name terms to document intent.

Example term sequence
set term allow-ssh-from-mgmt from source-address 192.168.1.10/32
set term allow-ssh-from-mgmt from destination-port 22
set term allow-ssh-from-mgmt from protocol tcp
set term allow-ssh-from-mgmt then accept

set term deny-all-others then discard
This shows a specific accept followed by a catch-all discard. The first match stops processing, so order is critical.
Pro tip
Use 'count' to observe matches before changing an action to 'discard' or 'accept'.
Common mistake
Placing a broad accept before specific denies prevents the denies from ever running.
