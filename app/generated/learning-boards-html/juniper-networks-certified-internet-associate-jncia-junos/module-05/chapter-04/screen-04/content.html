Definition
Firewall filter
A rule set that evaluates packets and applies actions based on matching conditions. Operates on packets, not routing information.
Why it matters
Enforces access control at the interface to protect router services and internal networks.
Concrete example
Allow SSH from a management workstation while discarding all other inbound packets to the management interface.
Misconception
A Junos firewall filter is stateless by default and does not remember previous packets unless separate stateful features are used.
Key Takeaway

Filters are explicit packet gates; plan terms and order carefully because the default is to discard unmatched packets.

Analogy: the security guard
Imagine a guard at the door checking ID, purpose, and dress code. Each check maps to a match condition; the guard’s instruction is the action.
Match
Source IP, destination port, protocol, or interface.
Action
Accept, discard, reject, log, or count, among others.
Quick check
If you allowed inbound SSH but didn't allow return packets in a stateless filter, the SSH session might not function. Always consider both directions.
