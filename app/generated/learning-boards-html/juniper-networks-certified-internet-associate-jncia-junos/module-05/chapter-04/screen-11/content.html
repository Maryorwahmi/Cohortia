Common Mistakes
Avoid these pitfalls
Incorrect term order
Specific denies must come before broad accepts. Otherwise, denies are never reached.
Forgetting return traffic
In stateless filters, allow both directions for connections or use stateful mechanisms where available.
Discard vs Reject
Use discard to avoid information leakage; use reject when you need diagnostic feedback.
Mitigation checklist
  • Stage with count and log before changing actions.
  • Test with a known client and examine counters.
  • Apply in maintenance windows where possible.
  • Name terms clearly and document intent in comments or config notes.
Key Takeaway

Adopt a conservative rollout: observe with count, then enforce with discard/accept, and always verify from real endpoints.
