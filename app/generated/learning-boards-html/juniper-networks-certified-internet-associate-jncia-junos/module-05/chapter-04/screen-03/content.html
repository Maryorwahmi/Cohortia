Practical Skills & Verification
Apply filters safely and check their effect before committing to production.
Verification checklist
  • 1. Plan a maintenance window for risky changes.
  • 2. Apply filter as input or output depending on traffic direction to control.
  • 3. Test from a known host and use packet counters or logs.
  • 4. Use explicit accept terms for required services before a final accept if you intend to allow anything else.
  • 5. If unsure, start restrictive in a lab and gradually open rules.
Quick tip
Use 'count' before 'accept' to observe how many packets match a rule without changing traffic flow.
