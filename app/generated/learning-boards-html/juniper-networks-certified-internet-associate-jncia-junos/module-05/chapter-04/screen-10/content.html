Comparison
Input vs Output filters
Map the packet path to the interface and direction before applying a filter.
Input filter
Applied to packets entering the interface. Use to protect router services and internal networks.
Output filter
Applied to packets leaving the interface. Use to limit egress and control external access from internal hosts.
Example decision
If you want to prevent your network from sending traffic to a service, place the filter on the egress interface as an output filter. If you want to block external hosts from reaching your router, use an input filter on the router-facing interface.
Key Takeaway

Always choose the interface and direction that observe the traffic flow you intend to control; direction does not change match semantics, only observation point.
