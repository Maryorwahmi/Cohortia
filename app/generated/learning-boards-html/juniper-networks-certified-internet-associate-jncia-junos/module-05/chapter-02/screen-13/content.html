Common mistakes
Recognize frequent errors and adopt habits to avoid them.
Incorrect match type
Pick exact, longer, upto, or prefix-length-range carefully. Test against sample routes.
Typos in object names
A misspelled prefix-list or as-path name makes the from condition inert; verify names in configuration.
Missing global definitions
Define prefix-list, as-path, community under policy-options before referencing them in a term.
Overly broad or narrow matches
Balance specificity and inclusiveness; prefer explicit ranges and test with route output.
Best practice

Define objects centrally, order terms carefully, and validate route attributes before deciding policy behavior.
