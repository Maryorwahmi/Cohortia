'from' statement
Specifies the conditions a route must meet for the policy term to apply.
Definition
Every condition inside a 'from' is evaluated together; the term matches only if all are true.
Misconception
Do not assume 'from' items are ORed. If you need OR behavior, create multiple terms each with its own from.
Key Takeaway

Use separate terms for distinct match sets; keep 'from' clauses logically consistent to avoid never-matching terms.

Concrete example
set policy-options policy-statement IMPORT-BGP
 set term only-from-peer from protocol bgp
 set term only-from-peer from neighbor 192.0.2.5
 set term only-from-peer then accept
This term matches only BGP routes learned from 192.0.2.5.
Check your understanding
  • Would a route learned from OSPF with neighbor 192.0.2.5 match the example above? No.
  • How do you implement OR logic for two different neighbors? Create two terms each matching a neighbor.
