Protocol matches
Separate treatment based on how a route was learned.
Examples
from protocol ospf — accept internal OSPF routes; from protocol bgp — apply BGP attribute checks.
Misconception
Protocol does not imply neighbor identity. If you need a specific peer, also use from neighbor.
Key Takeaway

Protocol matches are effective for broad classification; refine decisions with additional attributes for precision.

Concrete scenario
set policy-options policy-statement IMPORT-OSPF-ONLY
 set term accept-ospf from protocol ospf
 set term accept-ospf then accept
 set term reject-all-others then reject
This policy accepts only routes learned via OSPF and rejects all others.
Check
After applying, use show route protocol ospf and show route <prefix> detail to confirm expected matches.
