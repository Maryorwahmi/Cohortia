Module 5 › Chapter 5.2 › Community & Origin
Communities
Tags carried in BGP; define globally and match in terms.
Example
set policy-options community NO-EXPORT members no-export then from community NO-EXPORT prevents exporting tagged routes.
Origin attribute
from origin igp matches routes that were originally injected into BGP via the IGP.
Propagation warning
Some peers strip communities. Verify propagation if you depend on community matches across AS boundaries.
Key Takeaway

Communities and origin are powerful attributes for refined matching, but they depend on correct definition and propagation — always check both.

Code example
set policy-options community NO-EXPORT members no-export
set policy-options community CUSTOM-COMMUNITY members 65000:100
set policy-options policy-statement FILTER-COMMUNITY from community NO-EXPORT
Define and reference community objects; verify that peers preserve the community attribute.
Misconception check
Don’t assume communities will be present on every hop; confirm with show route and with your peer's policy behavior.
