Learning Objectives
Master the 'from' statement and common match patterns so your policies behave predictably.
01
Match destination prefixes
Use route-filter and prefix-list to match exact prefixes or ranges of prefix lengths. This lets you target the IP blocks you want to accept or export.
Mnemonic: Prefix = Pinpoint
VERIFIED COMPETENCY MILESTONE
02
Match by protocol
Match routes by their origin protocol (ospf, bgp, static, direct, aggregate) to accept or reject entire protocol families.
Mnemonic: Protocol = Provenance
VERIFIED COMPETENCY MILESTONE
03
Match BGP attributes
Use neighbor, as-path, community, and origin matches to create peer-specific or attribute-driven policies. Define these objects under policy-options first.
Mnemonic: Attributes = Tags
VERIFIED COMPETENCY MILESTONE
04
Avoid common mistakes
Learn to avoid wrong match types, typos, missing global objects, and overly broad or specific matches. Validate with show route detail commands.
Mnemonic: Check, Define, Test
