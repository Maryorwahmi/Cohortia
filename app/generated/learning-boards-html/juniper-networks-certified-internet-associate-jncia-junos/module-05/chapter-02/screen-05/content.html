Match type comparison
Choose the match that maps to your intended prefix set.
exact
Matches exactly the given prefix and length. Use when you want a single prefix only.
longer / orlonger
Include the base prefix and all more-specifics beneath it. Good for catching subnets.
upto
Match prefixes up to a specified maximum length, inclusive of the base length.
prefix-length-range
Specify an explicit inclusive length range, such as /20-/24, for precise control.
Key Takeaway

Match types determine which specific or aggregated prefixes are included; select the one that minimizes unintended matches and validate in a lab.

Concrete examples
route-filter 192.168.1.0/24 exact
route-filter 192.168.1.0/24 longer
route-filter 192.168.0.0/16 upto /24
route-filter 172.16.0.0/16 prefix-length-range /20-/24
Try each against a sample route table to see which prefixes would match.
Common mistake
Using longer when you intended upto can include more-specific prefixes you did not plan to affect. Conversely, using exact when you intended a range will under-match.
