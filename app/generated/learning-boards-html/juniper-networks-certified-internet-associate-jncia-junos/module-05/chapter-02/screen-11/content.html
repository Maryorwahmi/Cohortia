Task steps
Follow these steps in the Junos CLI to implement the scenario safely.
  1. Enter configuration mode: edit.
  2. Define the prefix-list under policy-options for 192.168.10.0/24 exact.
  3. Create policy-statement EXPORT-SPECIFIC-TO-PEER.
  4. Add term allow-10-to-peer with from prefix-list INTERNAL-NET-10 and from neighbor 10.0.0.1, then accept.
  5. Add term deny-10-to-others matching prefix-list INTERNAL-NET-10 then reject, placed after the specific term.
  6. Add a default-accept term to allow other routes to export if desired and commit.
  7. Verify using show route 192.168.10.0/24 detail and show route protocol bgp.
Key Takeaway

Define objects before referencing them, place specific terms first, and validate with show route commands.

Starter configuration template
edit policy-options
set prefix-list INTERNAL-NET-10 192.168.10.0/24 exact

edit policy-options policy-statement EXPORT-SPECIFIC-TO-PEER
set term allow-10-to-peer from prefix-list INTERNAL-NET-10
set term allow-10-to-peer from neighbor 10.0.0.1
set term allow-10-to-peer then accept
set term deny-10-to-others from prefix-list INTERNAL-NET-10
set term deny-10-to-others then reject
set term default-accept then accept
up
commit and-quit
Use this template in a simulated environment before applying to production.
Common pitfalls
Placing deny before allow, forgetting to define the prefix-list, or typos in object names — all lead to terms that never match as intended.
