Advanced Objectives
Reusable objects, term ordering, and verification habits that prevent errors in production.
01
Define prefix-lists & objects
Use policy-options to create prefix-list, as-path, and community objects for reuse across policies and clarity.
Mnemonic: Define once, reference many
VERIFIED COMPETENCY MILESTONE
02
Term ordering matters
Place specific terms before general ones. A specific accept for a neighbor should come before a generic reject for the same prefix range.
Mnemonic: Specific before general
VERIFIED COMPETENCY MILESTONE
03
Verify with show route
Use show route protocol and show route <prefix> detail to inspect attributes and confirm matches before committing disruptive changes.
Mnemonic: Inspect before you commit
VERIFIED COMPETENCY MILESTONE
04
Avoid common pitfalls
Watch for typos in object names, incorrect route-filter types, and missing global definitions that render terms ineffective.
Mnemonic: Check names, check scope
