Module 05 › Chapter 5.1 › Match Conditions: the 'from' clause
What you can match
Prefix, protocol, AS-path, community, next-hop, and more.
• Prefix: match specific networks or prefix-lists.
• Protocol: match by the protocol that learned the route, like ospf or bgp.
• AS-path/community: match based on BGP attributes to implement policy decisions.
Example
A term with from protocol ospf then accept will accept only routes learned via OSPF.
Ordering and overlap
Place more specific prefix matches before broader ones. Example pitfall: rejecting 10.0.0.0/8 before accepting 10.1.1.0/24 will prevent the host route from ever being accepted.
Common mistake
Assuming order is irrelevant. It is: Junos uses first-match-wins.
Check
When in doubt, simulate or test the match conditions in a lab to confirm which term matches a route.
