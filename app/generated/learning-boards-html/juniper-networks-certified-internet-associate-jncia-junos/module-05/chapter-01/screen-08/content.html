Module 05 › Chapter 5.1 › Action Statements: the 'then' clause
Basic actions
accept and reject are the core outcomes for matched routes.
• accept: allow the route to be installed or advertised.
• reject: deny the route and stop policy evaluation for that route.
• explicit final then statements avoid ambiguity from implicit reject.
Attribute modification
set actions alter attributes to influence selection and propagation.
• set local-preference: prefer a route inside your AS.
• set community: tag routes for downstream policies.
• as-path prepend: make a path less preferred to neighbors.
Best practice
Document every attribute change and understand how it affects neighbors and route selection chains.
