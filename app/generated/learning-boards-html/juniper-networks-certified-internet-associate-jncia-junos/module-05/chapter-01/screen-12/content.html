Module 05 › Chapter 5.1 › ACCEPT-OSPF-ONLY
CLI Walkthrough
Define a policy-statement and two terms: one to accept OSPF routes, one to reject all others.
edit policy-options policy-statement ACCEPT-OSPF-ONLY
set term accept-ospf from protocol ospf
set term accept-ospf then accept
set term reject-others then reject
up
commit and-quit
• Enter configuration mode and edit the policy-options hierarchy. The term accept-ospf matches protocol ospf and accepts those routes.
• The reject-others term has no from clause, so it matches everything else and rejects it explicitly.
Validation steps
After commit, check RIB entries and peer advertisements. If possible, monitor policy-match counters or logs to confirm which term matched routes.
Misconception
Defining a policy does not apply it. You must attach it to an import or export statement under the protocol or routing-instance.
Key takeaway
This pattern is explicit and safe: accept intended sources first, then explicitly reject the rest.
