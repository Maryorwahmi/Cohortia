Definition › Actions
Action types
  • accept — forward the packet normally.
  • discard — silently drop the packet.
  • reject — drop and send a reset when applicable.
  • count — increment a named counter for monitoring; does not alter forwarding.
  • log — emit a syslog entry for matched packets.
Monitoring example
set firewall family inet filter MY-FILTER term 9 then count HTTP-TRAFFIC set firewall family inet filter MY-FILTER term 10 then log Use show firewall to read named counters and verify expected hit counts.
Concrete scenario
Count web hits to measure load, log suspicious IPs to audit events, and explicitly accept or discard so the filter's final effect is clear.
Key takeaway
Observation actions provide visibility; pair them with an explicit final action so behavior is unambiguous.
