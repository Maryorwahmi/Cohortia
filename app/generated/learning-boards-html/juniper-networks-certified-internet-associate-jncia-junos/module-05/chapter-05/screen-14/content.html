Key Concepts › Match Essentials
Address matching
Match source or destination IPs. Use address-sets for reuse.
Protocol & Port
Match tcp, udp, icmp and specific ports; use port-lists for groups.
TCP flags
Use syn for new connections and ack for established replies to avoid blocking return traffic.
Summary

Design matches that are precise, maintain addresses and ports in reusable lists, and include explicit return-traffic terms when using stateless filters.
