Process › Policer & Rate-Limit
Policer definition example
set firewall policer SSH-RATE-LIMIT if-exceeding bandwidth-limit 1m burst-size-limit 15k set firewall policer SSH-RATE-LIMIT then discard set firewall family inet filter MY-FILTER term rate-limit-ssh from protocol tcp set firewall family inet filter MY-FILTER term rate-limit-ssh from destination-port ssh set firewall family inet filter MY-FILTER term rate-limit-ssh then policer SSH-RATE-LIMIT set firewall family inet filter MY-FILTER term rate-limit-ssh then accept
How it behaves
Traffic matching the term is evaluated against the policer. Conforming packets are accepted by the term action; packets that exceed the policer follow the policer's then action, such as discard.
Verification
Use show firewall policers to view policer counters and see how many packets exceeded the limit. Monitor during testing to avoid unintended drops.
Common mistake
Setting a policer too low for legitimate traffic can disrupt services. Start conservative and increase cautiously after testing.
