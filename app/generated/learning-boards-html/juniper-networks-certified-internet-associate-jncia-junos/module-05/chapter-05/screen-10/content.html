Comparison › next-term vs forwarding-class
next-term
Continue evaluation against subsequent terms. Useful when a term's role is logging or counting without deciding packet fate.
Example use
Log or count suspicious addresses and then next-term so a later rule can decide to discard or accept.
forwarding-class
Assign packets to a QoS forwarding class for scheduling and queuing; this class does not accept or drop by itself.
Design pattern
Classify traffic with forwarding-class, then enforce or police with later terms or QoS policies. Use next-term for telemetry-only terms.
