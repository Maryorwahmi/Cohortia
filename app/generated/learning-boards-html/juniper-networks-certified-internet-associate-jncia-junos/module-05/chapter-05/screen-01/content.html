Configuring Firewall Filters — Match Conditions & Actions
Learn how to match packets precisely and apply actions that enforce policy, record events, and limit rates.
In this lesson
Explore match criteria like source-address, protocol, ports, tcp-flags, interface; learn actions such as accept, discard, count, log, policer, and forwarding-class.
Why it matters
Correct filters secure network boundaries, protect devices, and provide counters for monitoring and troubleshooting.
Quick takeaway

Match precisely, order terms from specific to general, and verify with counters and policer statistics before applying filters in production.

Concept map
Match → Action → Verify
Match: source/dest, protocol, ports, tcp-flags, interface
Action: accept, discard, reject, count, log, policer
Verify: show firewall, show firewall policers, monitor traffic
Explore Key Topics
Match
Address sets, protocols, ports and tcp flags let you select specific traffic precisely.
Actions
Count and log for observability; policer to rate-limit; accept or discard for final disposition.
Best practices
Order specific rules first, allow return traffic, test in lab and use rollback plans.
