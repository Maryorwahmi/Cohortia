Module 6 › Chapter 5.5 › Learning Objectives
01
Match by addresses
Configure from statements to match source or destination addresses and use address-sets for reuse.
Mnemonic: Think of an address-set as a named list you can reuse across filters. Verified competency milestone
02
Match by protocol and port
Use protocol names or numbers and match source or destination ports; define port-lists for common service groups.
Mnemonic: Port-list groups ports like web ports into one reference. VERIFIED COMPETENCY MILESTONE
03
TCP flags and interface matches
Match tcp-flags to identify new connections or established traffic; match by interface to limit scope.
Mnemonic: SYN starts a connection, ACK typically denotes a reply. VERIFIED COMPETENCY MILESTONE
04
Actions and rate-limits
Apply then actions such as accept, discard, count, log, and policer for rate-limiting and monitoring.
Mnemonic: Count and log for visibility; policer to protect services. VERIFIED COMPETENCY MILESTONE
