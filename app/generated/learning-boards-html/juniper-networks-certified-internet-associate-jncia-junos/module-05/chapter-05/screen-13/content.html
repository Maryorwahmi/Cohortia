Architecture › Apply & Verify
Attach filters
Apply EXTERNAL-INBOUND as an input filter and EXTERNAL-OUTBOUND as an output filter on ge-0/0/0 unit 0 to enforce and monitor behavior at the network edge.
Verification commands
Use show firewall to view counters, show firewall policers to inspect policer stats, and monitor traffic interface ge-0/0/0 detail to observe packet matches in real time.
Troubleshooting checklist
  • Confirm counters increment for expected matches.
  • Check policer exceed counters for unexpected drops.
  • If return traffic is missing, add return-specific terms and reorder to avoid blanket discards.
Key takeaway
Verification is as important as configuration. Counters and policer stats tell you how the filter is affecting real traffic.
