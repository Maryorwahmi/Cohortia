Core Concept › Chapter 5.5 › Source & Destination Matching
How it works
  • Match examines packet IP headers against a prefix or a named address-set.
  • Address-sets are defined once and referenced across filters for reuse.
  • Specific host matches should precede broader subnet matches to ensure correct behavior.
Concrete example
Example configuration snippet you will use as a template: set policy-options address-set MANAGEMENT-HOSTS address 192.168.1.10/32 set policy-options address-set MANAGEMENT-HOSTS address 192.168.1.11/32 set firewall family inet filter MY-FILTER term 1 from source-address-set MANAGEMENT-HOSTS set firewall family inet filter MY-FILTER term 1 then accept
Common mistake
Placing a general subnet-accept before a host-discard or host-accept will mask the specific intent. Always order specific terms first.
Key takeaway
Address-sets make filters concise and easier to update. Keep term order deliberate to preserve specificity.
