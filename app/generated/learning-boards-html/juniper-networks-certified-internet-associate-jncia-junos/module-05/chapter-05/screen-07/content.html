When to match interface
Use interface matches to scope terms so they only apply to traffic on a specific logical or physical interface, avoiding accidental matches on other links.
Choosing input vs output
  • Input: protect the device and downstream networks; stop traffic early.
  • Output: control what leaves the device or network; apply egress policies or QoS classes.
Concrete example
Apply EXTERNAL-INBOUND as an input filter on ge-0/0/0 unit 0 to protect the device from unwanted inbound traffic, and apply EXTERNAL-OUTBOUND as an output filter for egress control.
Key takeaway
Decide placement by protection goal. Input filters stop bad traffic earlier; output filters shape or monitor egress traffic.
