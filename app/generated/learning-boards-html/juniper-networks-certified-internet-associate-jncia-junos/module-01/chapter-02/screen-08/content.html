How it works
Tab completion
Type a partial word and press Tab. If unique, it completes; if not, the CLI lists possibilities.
Examples: 
sh + Tab  -> completes to show
show int + Tab -> completes to show interfaces (if unique)
Context-Sensitive Help
The question mark
Type ? at any point in the command string to list valid next tokens for that context.
Examples: 
show ?
show interfaces ?
set system host-name ?
Pro tip
Use Tab to type faster and ? to understand available options before committing to a full command.
