Definition
Configuration Mode
Make changes to the candidate configuration and review them before committing.
Example session: 
configure
set system host-name my-router
show | display set
--- review changes ---
commit  (applies changes)
Useful reminders and behaviors:
  • Enter configuration mode by typing the configure command from operational mode.
  • Pending changes are visible with show in set format to confirm exact edits.
  • Exit without commit returns to operational mode and discards uncommitted edits if you choose not to save.
Common misconception
Typing configuration commands does not change the running system until commit is executed.
