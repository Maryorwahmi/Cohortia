Command Example
In configuration mode: 
set system host-name my-router
show | display set
Why use display set?
It presents the intended configuration as explicit set commands you can copy into templates or automation. Use it to verify no unintended lines were added, and include it in your change records.
Pro tip
Run show | display set after making edits and before commit to catch mistakes early.
Key Takeaway
Treat display set as a dry run for configuration changes; never skip this review in critical environments.
