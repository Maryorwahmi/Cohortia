Walkthrough
Inspect a verbose interface output
Session snippet (illustrative): 
show interfaces extensive | match "Link-level Type"
show interfaces extensive | except "statistics"
show interfaces extensive | no-more
Goal
Find link-level type quickly without reading all sections.
Example
Use match to surface only the lines showing the link type for each interface.
When to use no-more
Capture entire verbose output for analysis or automation scripts without interactive pauses.
