Process Flow
Move safely between modes
Operational prompt: user@router>
Type: configure
Configuration prompt: user@router#
Make edits
Type: show | display set  (review)
Type: commit  (apply) or exit (discard)
  • Use show | display set to view pending edits before committing.
  • The system issues a warning when you try to exit with uncommitted changes; read it before proceeding.
  • Navigation helpers like up and top let you move in the configuration hierarchy cleanly.
Scenario
You need to change an IP address without impacting traffic until a maintenance window. Enter configuration mode, set the new address, verify the candidate configuration, and only commit during the window. If you spot an error, exit to discard. This workflow prevents unexpected outages.
Key Takeaway
Always confirm your prompt and review pending edits; commit only when you intend to change the live system.
