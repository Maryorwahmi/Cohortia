Learning Objectives
Build practical CLI habits for safe and fast network work.
Navigate CLI modes
Recognize the operational and configuration prompts and move between them. This prevents running a configuration command in monitoring mode or vice versa.
VERIFIED COMPETENCY MILESTONE
Use completion and help
Use Tab to complete commands and the question mark to show context-sensitive options. This speeds discovery and reduces syntax errors.
VERIFIED COMPETENCY MILESTONE
Run key operational commands
Execute routine commands to view version, interfaces, routing, logs, and uptime so you can assess device state quickly.
VERIFIED COMPETENCY MILESTONE
Filter and refine output
Apply pipes like match, except, count, and no-more to focus on relevant lines when output is long.
