Comparison
Error type: Mode confusion
Symptoms: unknown command or syntax error when you expected a configuration change. Fix: check the prompt, enter configure for edits, use exit to leave if needed.
Error type: Output overwhelm
Symptoms: long output hides important lines. Fix: pipe to match or except, or use no-more to capture full output for offline review.
Error type: Assuming changes applied
Symptoms: unexpected device behavior after edits. Fix: in configuration mode use show | display set to verify, then commit to apply intentionally.
Quick recovery checklist
  • Verify prompt
  • Use ? to confirm syntax
  • Review pending changes with display set
