Key Concepts — Quick Reference
Three short definitions to recall during work.
Operational mode
A workspace for monitoring and diagnostics that does not change running configuration.
Configuration mode
Where you stage edits in a candidate configuration and commit them to apply changes.
Pipe operator
Used to filter and transform command output with match, except, count, display detail, and no-more.
Final takeaway
Before you type: observe the prompt, use built-in help, refine output with pipes, and commit only after reviewing changes.
