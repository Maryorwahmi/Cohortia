Definition
Rollback and Configuration History
Rollback loads a previous committed config into candidate so you can restore a known good state after an error.
How to think about indexes
  • rollback 0 = most recent committed configuration
  • rollback 1 = the commit before that, and so on
  • After rollback, review and run commit to apply.
Misconception
Assuming rollback immediately changes running state. It only stages the prior config until you commit.
Key Takeaway
Rollback is a fast way to recover; always inspect then commit the rollback to make it active.
CLI example
[edit]
user@router# rollback 0
load complete
[edit]
user@router# show | compare
# inspect the loaded config
user@router# commit
commit complete
Scenario: After a remote change disables routing, use rollback to restore the last known good configuration and regain stability quickly.
