Lab Walkthrough: Initial Setup
A safe, repeatable sequence to configure identity, access, and connectivity.
Step-by-step
  1. configure
  2. set system host-name <name>
  3. set system root-authentication plain-text-password
  4. set system login user <user> class super-user authentication plain-text-password
  5. set interfaces ge-0/0/0 unit 0 family inet address <addr/prefix>
  6. commit check
  7. commit confirmed 5 (if remote), test, then commit
Key Takeaway
Follow a fixed sequence and test each change; this reduces the chance of unpredictable outages.
Activity checklist
  • Confirm hostnames follow your naming convention.
  • Verify users can log in and have expected privileges.
  • Ping or test management access after interface commit.
  • If access fails, wait for commit confirmed to rollback or use rollback if already committed.
Reflection: After completing the lab, consider which checks saved you time and which steps you would add to your tailored pre-commit checklist.
