Definition
Root Password and Administrative Safety
Set a secure root password and create named administrative users instead of sharing root credentials.
Why it matters
Root can change system state, erase configs, or lock out other admins. Securing this account prevents accidental or malicious wide-impact changes.
Misconception: Sharing root is convenient. Reality: it removes accountability and increases risk.
Key Takeaway
Use strong passwords and separate accounts for daily tasks so you limit exposure and enable audit trails.
CLI example
[edit]
user@router# set system root-authentication plain-text-password

Concrete exercise
Set a strong root password, then create a user account named admin and give it the super-user class. Confirm you can authenticate with the new account before ending a session.
