Code Walkthrough
Configure a Physical Interface
Assign a logical unit and IPv4 family, then set the address and commit.
Key points
  • Use unit 0 for a basic logical interface unless you need subinterfaces.
  • family inet selects IPv4 addressing.
  • Confirm address and prefix to avoid routing errors.
Common mistake
Typos in the prefix length (for example /24 vs /16) can isolate your device from the intended network.
Key Takeaway
Configure interfaces carefully and verify connectivity immediately after commit to catch address mistakes.
CLI example
[edit]
user@router# set interfaces ge-0/0/0 unit 0 family inet address 192.168.1.1/24
[edit]
user@router# commit
commit complete
user@router> show interfaces terse
Interface               Admin Link Proto    Local                 Remote
ge-0/0/0                up    up   inet     192.168.1.1/24
Scenario: Assign a management IP to ge-0/0/0 in a lab and test ping to a host in the same subnet to confirm basic connectivity.
