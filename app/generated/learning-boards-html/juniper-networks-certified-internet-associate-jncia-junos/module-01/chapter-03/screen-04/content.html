Core Concept
Configuration Mode and Hostname
Enter the candidate configuration, stage changes, and use a consistent hostname pattern to simplify operations.
What is configuration mode?
  • It is the edit workspace where commands modify the candidate configuration.
  • Changes remain inactive until validated and committed.
  • Use show | compare to preview changes before commit.
Common mistake
Forgetting to commit after setting a hostname; the device will still present the old name until commit completes.
Key Takeaway
Make naming consistent and always review candidate changes prior to commit.
Example — CLI sequence
user@router> configure
Entering configuration mode
[edit]
user@router# set system host-name MyRouter-Branch1
[edit]
user@router# show | compare
---
+ system {
+     host-name MyRouter-Branch1;
+ }
[edit]
Try this
After staging the hostname, run show | compare and confirm the change before using commit. This prevents surprise edits.
