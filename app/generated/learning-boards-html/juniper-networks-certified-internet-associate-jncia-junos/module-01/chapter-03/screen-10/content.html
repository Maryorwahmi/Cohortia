Common Mistakes vs Best Practices
Compare frequent errors with the habits that prevent them.
Mistake
Forgetting to commit
Leads to staged edits that never take effect.
Best Practice
Run commit check then commit
Validate syntax before activation to avoid runtime errors.
Mistake
Using root for daily tasks
Removes accountability and increases risk.
Best Practice
Create named admin accounts
Use classes to limit privilege and enable auditing.
Practical checklist before commit
  • Run commit check to validate syntax and basic dependencies.
  • Confirm IP addresses and prefixes are correct.
  • If remote, use commit confirmed to protect against lockout.
  • Have rollback and console plans if connectivity is lost.
Key Takeaway
Adopt a short pre-commit checklist to prevent the most common configuration errors.
