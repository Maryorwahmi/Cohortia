Module 1 › Chapter 1.1 › Packet Forwarding Engine (PFE)
Definition

Packet Forwarding Engine — the data plane

The PFE is specialized forwarding hardware that implements the forwarding decisions prepared by the RE. It uses ASICs or other acceleration to forward packets without per-packet interaction with the control plane.
Example
After a route is accepted by the RE, the PFE uses programmed tables to forward matching traffic at line rate.
Troubleshooting
Hardware errors, TCAM exhaustion, or interface drops point to the PFE rather than the RE.
Analogy
Think of the PFE as a dedicated courier network that always follows the instructions it was given, delivering packets fast and predictably.
Key Takeaway

The PFE executes forwarding at high speed; the RE programs it with the correct forwarding state.
