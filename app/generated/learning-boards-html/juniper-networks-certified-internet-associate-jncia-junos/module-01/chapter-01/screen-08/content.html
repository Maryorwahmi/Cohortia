Module 1 › Chapter 1.1 › How RE and PFE interact
Process
RE learns → RE computes → RE programs PFE → PFE forwards
Step 1: Learn
Routing daemons receive updates from peers and learn network reachability.
Step 2: Compute & Validate
The RE selects best routes and applies routing policy and filters.
Step 3: Program
Validated forwarding entries are pushed to the PFE’s hardware tables.
Example
When a new BGP route is accepted, the RE converts it to a forwarding entry and programs the PFE so packets follow the route at line rate.
Diagnostic prompt
If a route shows in the RE but traffic is not forwarded, check whether the forwarding entry exists in the PFE tables.
Key Takeaway

RE decides, PFE executes. Problems require checking the component responsible for that stage.
