Module 1 › Chapter 1.1 › Routing Engine (RE)
Definition

Routing Engine — control plane

The RE runs routing daemons, stores the configuration, manages the CLI, and prepares forwarding information to send to the PFE.
Example
OSPF/BGP processes build routing tables here that determine reachability.
Misconception
The RE does not forward packets at line rate — the PFE does that work in hardware.
Troubleshooting cue
If routing adjacencies fail, inspect routing daemon logs and the RE’s resource utilization first.
Key Takeaway

The RE decides how traffic should flow and prepares the forwarding state for the PFE to implement.
