Operational vs Configuration mode

Follow this quick practice to internalize prompts and commands. Remember to commit to make changes active.
user@router>
show version
configure
user@router#
show configuration
edit interfaces ge-0/0/0 unit 0
set family inet address 10.0.0.1/24
commit
The code block shows the typical prompt changes and commands you will practice in the lab.
Exercise steps
  1. Log in and run show version.
  2. Enter configure and inspect show configuration.
  3. Edit an interface, commit, then exit.
Common misstep

Forgetting to commit leaves edits un-applied. Always verify with show configuration after commit.
