Hierarchy overview

Tree-like configuration model

Sections like interfaces, protocols, system, and security group related settings into readable blocks. This approach supports inheritance and makes bulk changes safer.
Example
interface ge-0/0/0 { unit 0 { family inet { address 10.0.0.1/24; } } }
Benefit
Scripts target hierarchical nodes instead of parsing line-oriented files, reducing errors.
Practical tip
Use the edit and show configuration commands to navigate and verify nodes in the hierarchy before committing changes.
Common mistake

Editing the wrong hierarchical level can leave missing or duplicated statements; always inspect the parent node first.
