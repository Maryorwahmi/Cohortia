Module 1 › Chapter 1.1 › Learning Objectives
01 — CLI Fluency
Practice entering operational and configuration modes, running show commands, and committing changes safely.
VERIFIED COMPETENCY MILESTONE
Example
Use "show version" to confirm software before making changes.
Misstep
Assuming edits are active before commit.
02 — Config Hierarchy
Locate interface and protocol configuration in the hierarchical tree and use inheritance to scale changes.
VERIFIED COMPETENCY MILESTONE
Mnemonic
Think in trees: interfaces, then specific interface entries.
Scenario
Apply the same interface block across multiple VLANs or nodes consistently.
Assessment alignment
These objectives map directly to the hands-on exercises and the short questions that verify you can identify RE vs PFE, change modes in the CLI, and read hierarchical configuration reliably.
