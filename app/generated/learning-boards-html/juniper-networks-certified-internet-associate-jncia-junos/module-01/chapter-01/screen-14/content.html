Module 1 › Chapter 1.1 › Key Concepts
Junos OS
A single OS across Juniper platforms for consistent operations.
Control plane
Routing Engine runs protocols, manages CLI, and prepares forwarding state.
Data plane
PFE forwards packets in hardware based on programmed tables.
Takeaway
Focus diagnostics and design on the component responsible: RE for control logic, PFE for forwarding performance, and use the configuration hierarchy to keep changes predictable.
