Verifying OSPF Neighbor Adjacency

Using show ospf neighbor to confirm successful OSPF operation.

Key Output Fields
  • Address: IP address of the neighboring router.
  • Interface: Local interface connected to the neighbor.
  • State: Current OSPF adjacency state (e.g., Full, Init, 2-Way).
  • ID: Router ID of the neighboring OSPF router.
  • Dead: Remaining time before neighbor is declared down.
Key Takeaway

A 'Full' state in show ospf neighbor indicates a successful and complete OSPF adjacency, ready for routing information exchange.

Junos OS CLI Output: show ospf neighbor
Address          Interface        State     ID               Pri Dead
192.168.1.2      ge-0/0/0.0       Full      2.2.2.2          128   33
# Explanation:
1. Neighbor at 192.168.1.2.
2. Connected via local interface ge-0/0/0.0.
3. State is 'Full', indicating complete adjacency.
4. Neighbor's Router ID is 2.2.2.2.
5. Priority is 128, Dead timer is 33 seconds.
Troubleshooting Tip

If the state is not 'Full', investigate mismatched parameters or connectivity issues preventing full database synchronization.
