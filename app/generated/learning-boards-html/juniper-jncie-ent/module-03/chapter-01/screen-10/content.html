Configuring OSPF on Juniper Devices

Enabling OSPF globally and on specific interfaces within an area.

Configuration Steps
  • Navigate to `[edit protocols ospf]`.
  • Define OSPF areas (Area 0 is mandatory for multi-area).
  • Specify interfaces within each area.
  • Use `passive` for interfaces that advertise subnets without forming adjacencies (e.g., loopbacks).
  • Commit changes to activate.
Key Takeaway

Juniper's hierarchical CLI simplifies OSPF configuration, allowing precise control over areas and interface participation.

Junos OS CLI Example
edit protocols ospf
set area 0.0.0.0 interface ge-0/0/0.0
set area 0.0.0.0 interface lo0.0 passive
commit
# Explanation:
1. Enters OSPF configuration hierarchy.
2. Adds interface `ge-0/0/0.0` to OSPF Area 0.
3. Adds loopback interface `lo0.0` to Area 0 as passive (no adjacencies).
4. Saves and applies the configuration.
Common Mistake

Forgetting to assign an interface to an OSPF area will prevent it from participating in the routing process.
