The Five OSPF Packet Types

Essential messages for neighbor discovery and database synchronization.

Hello

Discover neighbors, maintain adjacencies, elect DR/BDR.

Database Description (DBD)

Summarize link-state database contents for synchronization checks.

Link-State Request (LSR)

Request specific missing or outdated link-state information.

Link-State Update (LSU)

Carry actual Link-State Advertisements (LSAs) to update topology.

Link-State Acknowledgment (LSAck)

Reliably acknowledge receipt of LSUs to ensure database consistency.

Why it Matters

Each packet type plays a critical, specialized role in OSPF's ability to discover neighbors, build a consistent network topology, and maintain accurate routing information across the entire autonomous system.
