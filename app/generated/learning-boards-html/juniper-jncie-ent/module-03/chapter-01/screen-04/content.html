Definition

Link-State Protocol

Each OSPF router maintains a complete and identical 'map' or topology database of the entire OSPF domain, not just its direct neighbors.

How it Works
  • Routers exchange information about their directly connected links and their state (up/down, cost).
  • This information is flooded throughout the OSPF area.
  • Each router independently builds a Shortest Path First (SPF) tree using Dijkstra's algorithm.
  • Results in loop-free routing and rapid convergence.
Key Takeaway

OSPF's link-state approach provides a global network view, enabling intelligent, optimal path selection and fast recovery from topology changes.
