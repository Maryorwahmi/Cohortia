OSPF Neighbor States: Initial Steps

From silent to mutual recognition in the OSPF adjacency process.

01

Down State

No Hello packets have been received from the neighbor. This is the initial state for an OSPF-enabled interface.

02

Init State

The router has received a Hello packet from a neighbor, but its own Router ID was not included in the neighbor's Hello. One-way communication established.

03

2-Way State

Both routers have received each other's Hello packets and seen their own Router ID in the neighbor's Hello. Mutual communication is established. DR/BDR election occurs on multi-access networks.

Common Mistake

Routers stuck in 'Init' often indicate one-way Hello packet reception or a Router ID mismatch, preventing mutual recognition.
