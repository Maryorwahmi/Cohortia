Database Synchronization Packets

How OSPF routers build and update their link-state databases.

Database Description (DBD)

Summarizes the contents of a router's link-state database. Used to check for synchronization and identify missing or outdated LSAs.

Link-State Request (LSR)

Sent by a router to explicitly request specific missing or outdated LSAs from a neighbor, based on the DBD exchange.

Link-State Update (LSU)

Carries one or more Link-State Advertisements (LSAs), which are the actual building blocks of the OSPF topology database, containing detailed link information.

Link-State Acknowledgment (LSAck)

Used to reliably acknowledge the receipt of LSUs, ensuring that all routers have received and processed the latest link-state information.

Key Takeaway

These four packet types orchestrate the precise and reliable exchange of link-state information, ensuring every OSPF router maintains an identical and accurate network topology database.
