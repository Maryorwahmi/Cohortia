OSPF Neighbor States: Database Synchronization

Achieving full adjacency through link-state database exchange.

04

Exstart State

Routers determine the master/slave relationship for the Database Description (DBD) exchange, ensuring an orderly process.

05

Exchange State

Routers exchange DBD packets (summaries of their link-state databases) to identify missing or outdated Link-State Advertisements (LSAs).

06

Loading State

Routers send Link-State Request (LSR) packets for missing LSAs and receive Link-State Update (LSU) packets, acknowledging them with LSAcks.

07

Full State

Both routers have fully synchronized their link-state databases and are ready to exchange routing information. This is the ultimate goal of adjacency.

Key Takeaway

The 'Full' state signifies complete database synchronization, allowing routers to participate fully in OSPF routing decisions.
