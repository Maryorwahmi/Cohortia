Autonomous System Boundary Routers (ASBRs)

Integrating External Routing Domains

ASBR Functions

  • •External Connectivity: Connects the OSPF domain to other routing domains.
  • •Route Redistribution: Injects external routes into the OSPF domain.
  • •Inter-AS Routing: Enables communication with non-OSPF networks.
  • •Example: Connecting to BGP for Internet access.
Key Takeaway

ASBRs are essential for connecting an OSPF network to external routing protocols, allowing for the exchange of routes beyond the OSPF autonomous system.

Comparison

An ABR connects OSPF areas; an ASBR connects OSPF to external routing protocols or other autonomous systems.
