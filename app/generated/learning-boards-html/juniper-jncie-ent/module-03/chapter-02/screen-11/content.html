The LSA Flooding Process

Synchronizing Link-State Databases Across Areas

How LSAs are Distributed

  • •Intra-Area Flooding: LSAs flooded to all neighbors within the same area.
  • •Acknowledgment: Neighbors acknowledge receipt and re-flood to their neighbors.
  • •ABR Role: ABRs summarize intra-area LSAs (Type 1/2) into Type 3 LSAs.
  • •Inter-Area Flooding: Type 3 LSAs flooded into other connected areas (including Area 0).
Key Takeaway

LSA flooding ensures consistent network topology views within areas, while ABRs control inter-area flooding through summarization, maintaining OSPF scalability.

LSA Flooding Flow

Router generates LSA (e.g., Type 1)
LSA flooded within its area
ABR generates Type 3 LSA for inter-area routes
Type 3 LSA flooded to other areas via backbone
