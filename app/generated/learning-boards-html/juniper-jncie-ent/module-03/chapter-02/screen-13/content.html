Examining the OSPF Database

Using show ospf database to Verify LSA Information

Key Verification Commands

  • •show ospf database: Displays all LSAs known to the router.
  • •show ospf database area <area-id>: Filters LSAs by specific area.
  • •show ospf database router: Shows only Type 1 Router LSAs.
  • •Focus: Check 'Adv Router' field to identify LSA origin.
Key Takeaway

Regularly examining the OSPF database is crucial for verifying correct LSA propagation, troubleshooting routing issues, and ensuring network health in multi-area OSPF deployments.

Juniper CLI Example: Database Inspection

show ospf database

show ospf database area 0.0.0.0

show ospf database router
Troubleshooting Tip

If routes are missing, check `show ospf neighbor` for full adjacencies and then `show ospf database` for expected LSAs in the relevant areas.
