Router and Network LSAs (Type 1 & Type 2)

Describing Internal Area Topology

Type 1 Router LSA

  • •Generated by: Every OSPF router.
  • •Describes: Router's active interfaces, connected networks, neighbor adjacencies.
  • •Flooding Scope: Only within its own area.

Type 2 Network LSA

  • •Generated by: Designated Router (DR) on multi-access networks.
  • •Describes: All attached routers on that multi-access segment.
  • •Flooding Scope: Only within its own area.
Key Takeaway

Type 1 and Type 2 LSAs are crucial for building the detailed topology map within a single OSPF area, and their flooding is strictly localized to that area.
