Configuration Guide

Implementing SHA Authentication on Juniper

Leveraging Stronger Cryptography for OSPF

SHA Configuration Highlights

  • •Similar steps to MD5, but specify sha-256 (or other SHA variants).
  • •SHA offers stronger cryptographic protection than MD5.
  • •Always use Juniper's encrypted $9$ format for the key.
  • •All routers on the segment must use the exact same SHA algorithm and key.
Key Takeaway

SHA authentication provides enhanced OSPF security on Juniper devices, configured similarly to MD5 but specifying a SHA algorithm, with strict matching required across all neighbors.

Juniper Junos OS Configuration
edit protocols ospf
set area 0.0.0.0 interface ge-0/0/0.0 authentication sha-256
set area 0.0.0.0 interface ge-0/0/0.0 authentication-key "$9$JzX9-g.s/D" # Example encrypted key
commit
This command configures SHA-256 authentication on interface ge-0/0/0.0 within OSPF Area 0.0.0.0.
