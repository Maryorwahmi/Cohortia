Broadcast Networks: The Ethernet Default

Multicast Hellos and DR/BDR Election

The Broadcast network type is the default for Ethernet interfaces, characterized by efficient neighbor discovery and a critical election process.

  • •Hello packets sent via multicast (224.0.0.5, 224.0.0.6).
  • •DR/BDR election always takes place.
  • •Optimizes adjacency formation on multi-access segments.
Example Scenario

On an Ethernet LAN, all OSPF routers use multicast to discover neighbors, and a DR/BDR is elected to centralize LSA exchange, reducing overall traffic.

Key Takeaway

Broadcast networks leverage multicast and DR/BDR election for scalable OSPF operation on shared Ethernet segments.
