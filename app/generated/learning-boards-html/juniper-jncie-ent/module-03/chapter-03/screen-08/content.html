Point-to-Multipoint: Flexible NBMA

Dynamic Discovery Over Non-Broadcast Clouds

Point-to-Multipoint networks are a collection of point-to-point links over an NBMA cloud, allowing for dynamic neighbor discovery.

  • •No DR/BDR election.
  • •Dynamic neighbor discovery via multicast Hellos (224.0.0.5).
  • •Juniper supports 'Point-to-Multipoint Non-Broadcast' for explicit neighbors.
Use Case

Ideal for hub-and-spoke topologies over NBMA where dynamic neighbor discovery is desired without the complexity of DR/BDR election.

Key Takeaway

P2MP offers dynamic neighbor discovery over NBMA, simplifying configuration compared to traditional NBMA, without DR/BDR.
