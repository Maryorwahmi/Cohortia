Election Mechanics

DR/BDR Election: Priority and Router ID

Understanding the Non-Preemptive Process

DR/BDR Election Process
OSPF Priority (0-255)

Higher value is preferred. Priority 0 prevents a router from becoming DR/BDR.

Router ID

Used as a tie-breaker if OSPF priorities are equal. Highest Router ID wins.

Important Note

DR/BDR election is non-preemptive. A new router with higher priority will not take over unless the current DR/BDR fails.

Key Takeaway

The election process prioritizes OSPF priority, then Router ID, and is non-preemptive to maintain network stability.
