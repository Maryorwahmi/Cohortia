NBMA Networks: Manual Neighbors

Multi-Access Without Broadcast Support

Non-Broadcast Multi-Access (NBMA) networks are multi-access but lack native broadcast/multicast capabilities, requiring explicit neighbor configuration.

  • •Neighbors must be manually configured.
  • •DR/BDR election still occurs for efficiency.
  • •Historically used with Frame Relay or ATM.
Common Misconception

Some believe manual neighbor configuration on NBMA negates the need for DR/BDR election, but the DR/BDR still optimizes LSA flooding on multi-access segments.

Key Takeaway

NBMA requires explicit neighbor definitions and still benefits from DR/BDR election to manage multi-access communication effectively.
