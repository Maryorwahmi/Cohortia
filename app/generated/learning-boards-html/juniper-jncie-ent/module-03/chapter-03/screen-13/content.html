Troubleshooting Guide

Diagnosing OSPF Adjacency Problems

Common Mismatches and Verification Steps

OSPF adjacency issues often stem from network type mismatches or incorrect DR/BDR priority settings. Consistent configuration is key.

  • •Network type mismatches (e.g., P2P vs. Broadcast) prevent adjacency.
  • •Forgetting manual neighbors on NBMA networks.
  • •Incorrect OSPF interface priorities affecting DR/BDR election.
Verification Command

Use show ospf interface <interface-name> detail to check network type, DR/BDR status, and priority settings.

Key Takeaway

Thoroughly verify OSPF network types and priorities on all interfaces to prevent and resolve adjacency failures.

Common Troubleshooting Scenarios
Scenario 1: P2P vs. Broadcast

Problem: One side is Point-to-Point, other is Broadcast.
Result: No adjacency. Mismatched Hello mechanisms and DR/BDR expectations.

Scenario 2: NBMA No Neighbors

Problem: NBMA interface without manually configured neighbors.
Result: No adjacency. NBMA doesn't broadcast Hellos; explicit configuration is needed.

Scenario 3: DR/BDR Priority Conflict

Problem: Multiple routers with high priority, or priority 0 on intended DR.
Result: Unexpected DR/BDR election or no election. Verify and adjust priorities.
