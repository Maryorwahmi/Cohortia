JUNIPER IMPLEMENTATION

Configuring MSTP on Juniper EX Switches

Enabling Per-VLAN Load Balancing and Redundancy

Key Configuration Steps

  • •**Enable MSTP & Define Region:** Set region name and revision number.
  • •**Create MST Instances (MSTIs):** Define separate spanning trees.
  • •**Map VLANs to Instances:** Assign specific VLANs to each MSTI.
  • •**Set Instance Priorities:** Control root bridge election per MSTI.
  • •**Configure Port Costs/Priorities:** Influence topology per interface per instance.
Important Note

All switches in an MST Region must have identical region name, revision number, and VLAN-to-instance mappings.

CLI Commands Example
edit
set protocols mstp configuration name MY_REGION
set protocols mstp configuration revision 1

set protocols mstp configuration instance 1 vlan [10-19]
set protocols mstp configuration instance 2 vlan [20-29]

set protocols mstp instance 1 bridge-priority 4k
set protocols mstp instance 2 bridge-priority 8k

set protocols mstp interface ge-0/0/0 instance 1 cost 100
commit
Key Takeaway

Configure MSTP by defining regions, instances, VLAN mappings, and instance-specific bridge/port priorities to achieve per-VLAN load balancing on Juniper switches.
