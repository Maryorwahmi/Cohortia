RSTP MECHANICS

RSTP Port Roles and States

Streamlining Loop Prevention and Accelerating Convergence

RSTP Port States

Discarding

No data forwarding, no MAC address learning. Blocks traffic.

Learning

Learns MAC addresses, but still no data forwarding.

Forwarding

Actively forwards data frames and learns MAC addresses.

The Edge Port Advantage

Immediate Forwarding

Ports connected to end devices (e.g., PCs) can bypass delays and immediately transition to forwarding.

Important Note

Edge ports should ONLY be connected to end devices. Connecting an edge port to another switch can create temporary loops during topology changes.

Key Takeaway

RSTP simplifies port states to Discarding, Learning, and Forwarding. Edge Ports provide immediate forwarding for end devices, significantly accelerating convergence.
