Electing the Root Bridge

The Central Point of the Spanning Tree

What is the Root Bridge?

  • •The central switch in a spanning tree topology.
  • •All other switches determine their best path to the root.
  • •Dictates which links are forwarding and which are blocked.
  • •Elected through the exchange of Bridge Protocol Data Units (BPDUs).
Pro-Tip

Always plan your root bridge placement carefully. It should be a central, high-capacity switch to ensure optimal traffic paths.

How the Root Bridge is Elected

Lowest Bridge ID Wins

The switch with the numerically lowest Bridge ID becomes the Root Bridge.

Bridge ID Components

Composed of Bridge Priority (configurable) + MAC Address (unique).

Influencing Election

Set a lower `bridge-priority` (e.g., `4k` instead of default `32k`) on the desired root switch.

Key Takeaway

The Root Bridge, elected by the lowest Bridge ID (priority + MAC), is central to STP topology. Administrators can influence election via bridge priority.
