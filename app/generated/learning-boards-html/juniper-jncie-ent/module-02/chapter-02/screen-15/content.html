Key Concepts

Understanding Spanning Tree Components

Root Bridge

The central switch in a spanning tree topology, elected based on the lowest Bridge ID (priority + MAC address).

Edge Port

An RSTP port connected to an end device that can immediately transition to the forwarding state, bypassing typical delays.

MST Region

A group of switches running MSTP with identical configuration (name, revision, VLAN-to-instance mappings) to form a cohesive domain.

Summary Takeaway

The Root Bridge, Edge Port, and MST Region are fundamental elements that define how STP protocols build and maintain a stable, loop-free network topology.
