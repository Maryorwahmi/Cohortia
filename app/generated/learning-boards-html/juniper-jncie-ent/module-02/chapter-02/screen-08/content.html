Configuring and Verifying RSTP

Enabling Rapid Spanning Tree on EX Switches

Enabling RSTP

To activate RSTP on a Juniper EX Series switch, you enter configuration mode and use the `set protocols rstp` command. This enables the protocol globally.

  • •RSTP is often enabled by default, but explicit configuration ensures consistency.
  • •Always `commit` changes to apply them to the running configuration.
Pro-Tip

Use `commit confirmed` in production environments. This provides a rollback mechanism if the changes cause network issues.

CLI Commands
edit
set protocols rstp
commit

show spanning-tree interface
show spanning-tree bridge

Verifying RSTP Status

After configuration, use `show spanning-tree` commands to confirm RSTP is active and ports are in their correct roles and states.

  • •`show spanning-tree interface`: Displays port-specific RSTP information.
  • •`show spanning-tree bridge`: Shows global RSTP parameters and root bridge details.
Key Takeaway

Enable RSTP with `set protocols rstp` and verify its operation and port states using `show spanning-tree` commands on Juniper EX switches.
