Key Concepts

Essential Spanning Tree Terminology

Spanning Tree Protocol (STP)

The original protocol (802.1D) that creates a loop-free logical topology by blocking redundant paths in Ethernet networks.

Rapid Spanning Tree Protocol (RSTP)

An enhancement to STP (802.1w) providing faster convergence times through simplified port states and a quicker agreement mechanism.

Multiple Spanning Tree Protocol (MSTP)

An STP variant (802.1s) that allows for multiple independent spanning tree instances, enabling per-VLAN load balancing over redundant links.

Summary Takeaway

STP prevents loops, RSTP speeds convergence, and MSTP enables per-VLAN load balancing, each building upon the last to enhance network stability and efficiency.
