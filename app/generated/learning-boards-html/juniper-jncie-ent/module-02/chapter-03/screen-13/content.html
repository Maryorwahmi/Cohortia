Key Concepts: Foundational Layer 2 Security

Essential Terms for Network Protection

Layer 2 Security

Measures to protect against vulnerabilities and attacks at the data link layer of the OSI model.

Port Security (MAC Limiting)

Restricts MAC addresses learned on a switch port to prevent MAC flooding and unauthorized access.

DHCP Snooping

Inspects DHCP traffic to build a trusted IP-to-MAC binding database, preventing rogue DHCP servers and starvation attacks.

Summary Takeaway

Layer 2 security features like Port Security and DHCP Snooping are essential for controlling device access and ensuring legitimate IP address assignment, forming the bedrock of network defense.
