Configuring Port Security (MAC Limiting)

Setting Limits and Actions on Juniper EX Switches

Basic MAC Limiting Command

set ethernet-switching-options secure-access-port interface ge-0/0/1 mac-limit 2 action shutdown

This command limits interface ge-0/0/1 to 2 MAC addresses and shuts it down if the limit is exceeded.

Persistent MAC Addresses

set ethernet-switching-options secure-access-port interface ge-0/0/1 persistent-mac

Ensures learned MAC addresses are remembered across reboots, useful for static devices.

Key Takeaway

Careful configuration of MAC limits and actions is essential to prevent attacks without disrupting legitimate network operations.

Available Actions

  • shutdown: Disables the port (most aggressive).
  • drop: Silently discards packets from new MACs.
  • log: Logs a message but allows traffic.

Common Mistake: Overly Restrictive Limits

Setting mac-limit too low for ports connected to devices like IP phones with integrated mini-switches (which may have a PC connected) can cause legitimate traffic to be blocked.

Best Practice

Always assess the legitimate number of MAC addresses expected on a port before setting the limit. Test configurations in a lab environment first.
