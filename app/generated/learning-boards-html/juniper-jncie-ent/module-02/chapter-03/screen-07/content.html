DHCP Snooping: Protecting IP Address Assignment

Guarding Against Rogue DHCP Servers and Starvation Attacks

What is DHCP Snooping?

A security feature that monitors DHCP traffic to build and maintain a database of valid IP-to-MAC address bindings, acting as a firewall for DHCP exchanges.

Rogue DHCP Server Attack

An unauthorized DHCP server provides incorrect network configurations (IP, gateway, DNS) to clients, redirecting traffic or causing denial of service.

Key Takeaway

DHCP snooping is vital for ensuring legitimate IP address assignment and preventing network disruption from malicious DHCP activities.

DHCP Starvation Attack

An attacker floods the DHCP server with requests using spoofed MAC addresses, exhausting the IP address pool and preventing legitimate clients from obtaining addresses.

How it Works

It inspects DHCP messages, records valid bindings, and then uses this information to filter out unauthorized DHCP server responses and client requests with invalid source MAC addresses.

Analogy: Mail Carrier Validation

DHCP snooping is like a post office security guard who verifies that only authorized mail carriers (legitimate DHCP servers) deliver mail (IP addresses) to the correct recipients (clients).
