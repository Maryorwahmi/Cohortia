DHCP Snooping: Trusted vs. Untrusted Ports

Implementing Port Roles and Configuration on Juniper EX Switches

Trusted Ports

  • Connected to legitimate DHCP servers or other trusted switches.
  • Allow all DHCP traffic to pass without inspection.
  • Crucial for legitimate DHCP server operation.

Untrusted Ports

  • Connected to end devices (workstations, IP phones).
  • DHCP snooping actively inspects and restricts traffic.
  • Drops rogue DHCP server responses and invalid client requests.
Key Takeaway

Properly classifying ports as trusted or untrusted is fundamental for DHCP snooping to effectively block malicious DHCP traffic.

Enable DHCP Snooping for a VLAN

set ethernet-switching-options secure-access-port dhcp-snooping vlan EMPLOYEE

Configure a Trusted Interface

set ethernet-switching-options secure-access-port interface ge-0/0/0 dhcp-snooping trust

All other ports in EMPLOYEE VLAN become untrusted by default.

Security Principle

Always apply the principle of least privilege: only trust ports that absolutely need to be trusted, typically those directly connected to legitimate DHCP servers or other infrastructure devices.
