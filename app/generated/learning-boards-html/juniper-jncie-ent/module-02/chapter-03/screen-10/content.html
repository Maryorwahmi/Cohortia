DAI: Dependency and Configuration

Leveraging DHCP Snooping for Effective ARP Inspection

Trusted vs. Untrusted Ports for DAI

  • Trusted: Connected to other switches/routers; bypass DAI checks.
  • Untrusted: Connected to end devices; subject to ARP packet inspection.

Critical Dependency: DHCP Snooping

DAI relies heavily on the IP-to-MAC binding database built by DHCP snooping. Without a properly configured DHCP snooping, DAI will be ineffective or block legitimate traffic.

Key Takeaway

DAI's effectiveness hinges on DHCP snooping; ensure both are correctly configured for comprehensive ARP spoofing protection.

Enable DAI for a VLAN

set ethernet-switching-options secure-access-port arp-inspection vlan EMPLOYEE

Configure a Trusted Interface for DAI

set ethernet-switching-options secure-access-port interface ge-0/0/0 arp-inspection trust

Static IPs & DAI

For devices with static IP addresses, manual static ARP entries or trusted ports are needed, as DHCP snooping won't build bindings for them. This is a trade-off in security.
