Configuring IRB Interfaces for Inter-VLAN Routing

Setting Up Layer 3 Gateways for Your VLANs

# Enter configuration mode
edit

# Configure IRB interface for SALES VLAN 10
set interfaces irb unit 10 family inet address 192.168.10.1/24

# Configure IRB interface for HR VLAN 20
set interfaces irb unit 20 family inet address 192.168.20.1/24

# Link SALES VLAN to irb.10
set vlans SALES l3-interface irb.10

# Link HR VLAN to irb.20
set vlans HR l3-interface irb.20

# Commit changes
commit

IRB Configuration Steps

  • Define IRB Unit: Create a logical `irb` interface (e.g., `irb.10`).
  • Assign IP Address: Configure an IP address and subnet mask for the IRB (e.g., `192.168.10.1/24`).
  • Link to VLAN: Associate the IRB interface with its corresponding VLAN using `l3-interface`.
  • Gateway Role: The IRB IP becomes the default gateway for devices in that VLAN.

Example: Sales & HR VLANs

With irb.10 as 192.168.10.1 for SALES (VLAN 10) and irb.20 as 192.168.20.1 for HR (VLAN 20), the Layer 3 switch can now route traffic between these two distinct network segments.

Key Takeaway

Correctly configuring and linking IRB interfaces to VLANs is essential for enabling Layer 3 routing between your segmented networks.
