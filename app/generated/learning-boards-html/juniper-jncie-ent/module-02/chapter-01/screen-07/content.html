Trunk Ports and 802.1Q Tagging

Enabling Multi-VLAN Communication Between Network Devices

What is a Trunk Port?

A switch port configured to carry traffic for multiple VLANs. Used for links between switches or between a switch and a router, allowing different VLANs to share a single physical connection.

Multi-VLAN traffic

The 802.1Q Standard

The IEEE standard for VLAN tagging. It inserts a 4-byte tag into the Ethernet frame header, containing the VLAN ID, to identify which VLAN a frame belongs to as it traverses a trunk link.

VLAN ID in frame

How 802.1Q Tagging Works

  • Tag Insertion: Switch adds a 4-byte tag to frames leaving a trunk port.
  • VLAN Identification: Tag contains the VLAN ID, identifying the frame's origin.
  • Inter-Switch Communication: Allows multiple VLANs to share a single physical link.
  • Preserves Segmentation: Ensures VLAN identity is maintained across the network.
Key Takeaway

Trunk ports, using 802.1Q tagging, are vital for carrying traffic from multiple VLANs over a single link, maintaining network segmentation.
