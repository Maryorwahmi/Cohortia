Common VLAN and Trunking Mistakes (Part 2)

Addressing VLAN Membership, IRB Mapping, and IP Overlaps

Missing VLAN Members

Issue: Required VLANs not explicitly listed in `vlan members` on a trunk port. Traffic for those VLANs won't traverse the trunk.

Check: show ethernet-switching interfaces

Incorrect IRB Mapping

Issue: IRB unit ID doesn't match VLAN ID or is not correctly linked to the VLAN definition. Prevents inter-VLAN routing.

Check: show vlans, show interfaces irb

IP Address Overlaps

Issue: Assigning overlapping IP subnets to different VLANs. Causes routing conflicts and network instability.

Check: Network documentation, show interfaces irb

Safety Best Practices

  • Lab Testing: Always test new configurations in a lab environment first.
  • Maintenance Windows: Implement changes in production during scheduled maintenance.
  • Rollback Plan: Have a clear plan to revert changes if issues arise.
  • commit confirmed: Use this Juniper command to automatically revert changes if not confirmed, providing a safety net.
Key Takeaway

Thoroughly check VLAN membership, IRB mappings, and IP addressing, and always prioritize network stability with careful deployment and rollback strategies.
