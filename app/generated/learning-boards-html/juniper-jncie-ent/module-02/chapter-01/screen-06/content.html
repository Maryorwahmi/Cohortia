Port Configuration

Access Ports: Connecting End Devices to VLANs

Ensuring Single-VLAN Connectivity for Workstations and Servers

# Enter configuration mode
edit

# Configure interface ge-0/0/1 as an access port
set interfaces ge-0/0/1 unit 0 family ethernet-switching port-mode access

# Assign ge-0/0/1 to the SALES VLAN
set interfaces ge-0/0/1 unit 0 family ethernet-switching vlan members SALES

# Commit changes
commit

Access Port Characteristics

  • Purpose: Connects end devices (PCs, servers, IP phones).
  • VLAN Traffic: Carries traffic for only a single VLAN.
  • Tagging: Traffic is typically untagged (no 802.1Q tag).
  • Switch Action: Switch associates untagged frames with the configured VLAN.

Example Scenario

A workstation in the HR department connects to port ge-0/0/2. This port would be configured as an access port, and its vlan members would be set to HR, ensuring the workstation's traffic belongs exclusively to the HR VLAN.

Key Takeaway

Access ports provide single-VLAN connectivity for end devices, simplifying their integration into segmented networks.
