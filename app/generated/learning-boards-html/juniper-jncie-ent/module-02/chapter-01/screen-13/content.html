Key Concepts

Essential Terms for VLANs and Trunking

VLAN (Virtual Local Area Network)

A logical segmentation of a physical network into multiple broadcast domains, enhancing security and performance.

802.1Q

The IEEE standard for VLAN tagging, which inserts a 4-byte tag into Ethernet frames to identify the VLAN.

Access Port

A switch port configured to carry traffic for a single VLAN, typically connected to an end device, with traffic usually untagged.

Summary Takeaway

VLANs provide logical network segmentation, 802.1Q enables multi-VLAN traffic tagging, and access ports connect individual devices to specific VLANs.
