Key Concepts

Advanced VLAN and Routing Terms

Trunk Port

A switch port configured to carry traffic for multiple VLANs, typically used for inter-switch links, with traffic usually 802.1Q tagged.

Native VLAN

The VLAN whose traffic is sent untagged over a trunk port. Its ID must match on both ends of the trunk to avoid issues.

Inter-VLAN Routing / IRB

The process of routing traffic between different VLANs, typically using a Layer 3 switch's Integrated Routing and Bridging (IRB) interfaces.

Summary Takeaway

Trunk ports facilitate multi-VLAN links, native VLANs handle untagged traffic, and inter-VLAN routing via IRB interfaces enables communication between segmented networks.
