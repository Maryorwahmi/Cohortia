Configuring an RR Client & Verification

Configure the client router and verify the RR session status.

Router D as RR Client (AS 64500)

Router D (192.168.100.2) will peer with Router C (192.168.100.1), which is its RR.

set routing-options autonomous-system 64500
set protocols bgp group IBGP-PEER type internal
set protocols bgp group IBGP-PEER local-address 192.168.100.2
set protocols bgp group IBGP-PEER neighbor 192.168.100.1 peer-as 64500
set protocols bgp group IBGP-PEER neighbor 192.168.100.1 family inet unicast
  • No route-reflector-client command is needed on the client itself.
  • The client simply peers with the Route Reflector.
Key Takeaway

An RR client is configured as a standard iBGP peer to the RR. Verification involves checking BGP session status and confirming the RR client role via show bgp neighbor.

Verification Commands

show bgp summary

Confirms the BGP session state (should be 'Established').

user@router> show bgp summary
...
Peer                     AS      InPkt     OutPkt    OutQ   Flaps Last Up/Dwn State|#Active/Received/Accepted/Damped..
192.168.100.1          64500        10         10       0       0 00:01:30 Establ
show bgp neighbor <neighbor-IP>

Provides detailed information, including whether the peer is an RR client.

user@router> show bgp neighbor 192.168.100.1
...
  Type: Internal    State: Established    Flags: <Peer>
  Last State: OpenConfirm   Last Event: RecvKeepAlive
  Peer is a route reflector client
