Basic iBGP Peering: Router D & Verification

Complete the iBGP peering setup and verify session status.

Router D Configuration (AS 64500)

Router D's loopback address is 192.168.100.2/32. It will peer with Router C (192.168.100.1).

set routing-options autonomous-system 64500
set protocols bgp group IBGP-PEER type internal
set protocols bgp group IBGP-PEER local-address 192.168.100.2
set protocols bgp group IBGP-PEER neighbor 192.168.100.1 peer-as 64500
  • Configuration mirrors Router C, ensuring mutual peering.
  • peer-as 64500 confirms it's an iBGP session.
Key Takeaway

After configuring both iBGP peers, always verify IGP reachability of loopbacks and then check BGP session status using show bgp summary.

Verification Steps

1. Verify IGP Reachability

Ensure loopback addresses are reachable via your IGP (e.g., OSPF). Use show route <loopback-address> or ping <loopback-address>.

2. Verify BGP Session Status

After committing changes, check BGP session status. Use show bgp summary to see if the session is 'Established'.
