Understanding Internal BGP (iBGP)

iBGP distributes external routes throughout your Autonomous System.

What is iBGP?

Internal BGP (iBGP) is a protocol used to exchange BGP routing information between routers within the same Autonomous System (AS). It's distinct from eBGP, which operates between different ASes.

  • Purpose: Distribute external BGP routes learned via eBGP to all internal BGP speakers.
  • Consistency: Ensures every router in the AS has a uniform view of the global BGP routing table.
  • Traffic Flow: Enables internal traffic to correctly reach external destinations by providing necessary routing intelligence.
Key Takeaway

iBGP is essential for internal route consistency, allowing all routers within an AS to forward traffic to external destinations effectively.

iBGP vs. eBGP: A Quick Comparison

eBGP (External BGP)
  • Connects different Autonomous Systems.
  • Used for inter-AS routing.
  • Typically uses directly connected interfaces.
iBGP (Internal BGP)
  • Connects routers within the same Autonomous System.
  • Used for intra-AS route distribution.
  • Often uses loopback interfaces for stability.

Real-World Connection: Enterprise Network

Imagine a large enterprise with multiple internal routers. An edge router connects to an ISP via eBGP, learning routes to the internet. Without iBGP, internal routers wouldn't know how to reach those internet destinations. iBGP ensures that all internal routers receive these external routes, allowing employees to access web services, cloud applications, and remote resources seamlessly.
