Basic iBGP Peering: Router C

Configure iBGP peering using loopback interfaces for stability.

Router C Configuration (AS 64500)

Router C's loopback address is 192.168.100.1/32. We'll configure its iBGP group and neighbor.

set routing-options autonomous-system 64500# Define AS
set protocols bgp group IBGP-PEER type internal# Create iBGP group
set protocols bgp group IBGP-PEER local-address 192.168.100.1# Source BGP from loopback
set protocols bgp group IBGP-PEER neighbor 192.168.100.2 peer-as 64500# Neighbor's loopback & local AS
  • type internal: Specifies this is an iBGP session.
  • local-address: Uses the loopback for session stability.
  • peer-as: Must match the local AS for iBGP.
Key Takeaway

iBGP peering on Junos requires defining the AS, creating an internal BGP group, specifying a stable local-address (loopback), and configuring the neighbor with the same peer-as.

Why Loopback Interfaces?

Always Up

Loopback interfaces are virtual and are not tied to physical hardware, so they remain active even if physical interfaces fail.

Stable Source

Provides a consistent and stable source IP address for BGP sessions, preventing session flaps due to interface changes.

IGP Reachability Required

Crucially, the loopback addresses must be reachable via an Interior Gateway Protocol (e.g., OSPF, IS-IS) for the BGP session to establish.
