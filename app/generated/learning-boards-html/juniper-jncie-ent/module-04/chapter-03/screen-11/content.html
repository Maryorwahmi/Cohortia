Configuring a Route Reflector

Designate a router as a Route Reflector for its clients.

Router C as Route Reflector (AS 64500)

Router C (192.168.100.1) will be configured as the RR for Router D (192.168.100.2).

set routing-options autonomous-system 64500
set protocols bgp group IBGP-PEER type internal
set protocols bgp group IBGP-PEER local-address 192.168.100.1
set protocols bgp group IBGP-PEER neighbor 192.168.100.2 peer-as 64500
set protocols bgp group IBGP-PEER neighbor 192.168.100.2 family inet unicast# Ensure IPv4 unicast
set protocols bgp group IBGP-PEER neighbor 192.168.100.2 route-reflector-client# D is a client of C
  • route-reflector-client: This command designates the neighbor as an RR client.
  • This enables the RR to reflect routes to its client, bypassing split-horizon.
Key Takeaway

To configure a Route Reflector, add the route-reflector-client command to the neighbor statement for each client within the iBGP group.

RR Cluster Design

RR Cluster

A group of RRs and their clients. RRs within the same cluster must be fully meshed with each other for redundancy.

Redundancy

Typically, at least two RRs are used in a cluster to avoid a single point of failure.

Client Peering

Clients only need to peer with the RRs, not with other clients or non-clients.
