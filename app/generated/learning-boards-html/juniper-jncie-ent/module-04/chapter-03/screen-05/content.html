Fundamental Rule

The iBGP Full Mesh Requirement

Every iBGP router must peer with every other iBGP router in the same AS.

Why Full Mesh? The Split-Horizon Rule

The core reason for a full mesh is BGP's loop prevention mechanism, specifically the iBGP split-horizon rule.

  • Loop Prevention: A BGP router will NOT advertise an iBGP-learned route to another iBGP peer.
  • Consistency: Full mesh ensures every iBGP router directly learns all external routes from all other iBGP routers.
  • Direct Learning: This direct peering bypasses the split-horizon rule's restriction, ensuring all routers have complete routing information.
Key Takeaway

The iBGP full mesh is critical for maintaining routing consistency and preventing loops within an AS, by ensuring direct peering between all iBGP speakers.
