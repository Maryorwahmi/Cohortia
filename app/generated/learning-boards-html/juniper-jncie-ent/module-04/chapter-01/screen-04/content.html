Core Concept

BGP: The Internet's Exterior Gateway Protocol

Understanding the fundamental distinction between IGPs and EGPs.

Interior Gateway Protocols (IGPs)

Designed for routing *within* a single Autonomous System (AS). Examples: OSPF, EIGRP, RIP.

Exterior Gateway Protocols (EGPs)

Designed for routing *between* different Autonomous Systems (ASes). BGP is the primary EGP.

Why it Matters

This distinction defines BGP's role in connecting disparate networks to form the global internet, rather than optimizing paths within one network.

Key Takeaway

BGP's EGP nature makes it the essential protocol for inter-domain routing, enabling global internet connectivity.
