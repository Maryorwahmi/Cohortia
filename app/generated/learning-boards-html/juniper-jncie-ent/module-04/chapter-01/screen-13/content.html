Key Concepts

Essential terms to remember from this chapter

Autonomous System (AS) & ASN

A collection of IP networks and routers under a single administrative entity, identified by a globally unique Autonomous System Number (ASN).

Border Gateway Protocol (BGP)

An Exterior Gateway Protocol (EGP) used for exchanging routing information between different Autonomous Systems on the internet.

Path-Vector Protocol

A routing protocol that includes the full path (sequence of ASNs) a route has traversed, enabling loop prevention and policy-based routing.

Summary Takeaway

BGP, ASes, and the path-vector concept are foundational to understanding how the internet's global routing infrastructure operates.
