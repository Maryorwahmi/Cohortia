Module 4›Chapter 4.2›Understanding eBGP Direct Connection
Core Principle

eBGP Direct Connection Requirement

  • •By default, eBGP neighbors must be directly connected (share a common subnet).
  • •This is a security and sanity check to prevent accidental peering.
  • •Peering to loopback interfaces (a best practice) also requires bypassing this check.
Common Issue

Session fails to establish if peers are not directly connected and multihop is not configured.

Junos CLI Solution
set protocols bgp group EBGP-PEER multihop
Command Explanation

The multihop option disables the direct connection check, allowing eBGP sessions to form over multiple network hops.

Key Takeaway

Always consider the physical or logical connectivity between eBGP peers; use multihop when they are not directly connected.
