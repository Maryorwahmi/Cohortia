Learning Objectives: Part 1

LearnUnderstandApplyMaster
01

Configure Basic eBGP Peering

Set up an eBGP session between two Junos routers in different Autonomous Systems. This skill is foundational for connecting your network to external partners or the internet.

VERIFIED COMPETENCY MILESTONE
02

Identify Essential eBGP Parameters

Recognize and configure the core settings required for eBGP, such as local and remote AS numbers, and neighbor IP addresses. This ensures correct session establishment.

VERIFIED COMPETENCY MILESTONE
03

Verify eBGP Session Status

Utilize Junos CLI commands to confirm the operational status of eBGP sessions and the routes learned. This is vital for troubleshooting and ensuring network reachability.

VERIFIED COMPETENCY MILESTONE
04

Understand Common eBGP Issues

Identify and troubleshoot typical eBGP peering problems, such as direct connection requirements and TTL values. This prepares you for real-world network challenges.
