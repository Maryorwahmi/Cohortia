Overview

Starting eBGP on Junos

eBGP is the first step for inter-AS connectivity, allowing your network to exchange routes with external partners or the global internet.

  • •Primarily configured within the [edit protocols bgp] hierarchy.
  • •Connects routers in different Autonomous Systems.
  • •Establishes a TCP session on port 179 with the remote neighbor.
Key Parameters

Core eBGP Configuration Elements

Local AS Number

Your router's unique Autonomous System identifier.

Remote Neighbor IP

The IP address of the peer router in the external AS.

Remote AS Number

The Autonomous System identifier of the peer network.

Interface IP

The local interface IP used for peering.

Scenario Example

Router A (AS 64500, IP 192.168.1.1) wants to peer with Router B (AS 65000, IP 192.168.1.2).

Key Takeaway

Correctly defining local AS, remote IP, and remote AS is non-negotiable for eBGP session establishment.
