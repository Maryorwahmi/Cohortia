Key Concepts: Part 1

Essential terms and ideas from this chapter.

eBGP Configuration

The process of setting up BGP peering between routers in different Autonomous Systems.

routing-options autonomous-system

Junos command to define the local AS number for the router.

BGP Group

A logical grouping of BGP neighbors that share common configuration parameters.

type external

Specifies that a BGP group is for eBGP peering, influencing default behaviors.

neighbor <IP> peer-as <ASN>

Defines a remote BGP neighbor's IP address and its Autonomous System Number.

Summary Takeaway

Mastering these foundational eBGP configuration elements on Junos is crucial for establishing reliable inter-AS connectivity and managing your network's external routing.
