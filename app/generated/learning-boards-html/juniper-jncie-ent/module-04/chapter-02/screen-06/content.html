Module 4›Chapter 4.2›Configuring the eBGP Neighbor
Junos CLI Configuration
set protocols bgp group EBGP-PEER neighbor 192.168.1.2 peer-as 65000
Command Breakdown

neighbor <IP> peer-as <ASN>: Defines the remote BGP neighbor's IP address and its Autonomous System Number.

Explanation

Key Elements of Neighbor Configuration

  • •Neighbor IP Address: The specific IP of the remote router's interface for peering.
  • •Peer AS Number: The AS number of the remote network. Must match exactly for session establishment.
  • •TCP Port 179: BGP uses TCP port 179 for session establishment.
Common Mistake

A mismatch in the peer-as value will prevent the BGP session from forming, often leaving the session in an 'Active' state.

Key Takeaway

The neighbor command with the correct peer-as is the final piece to initiate eBGP peering and inter-AS route exchange.
