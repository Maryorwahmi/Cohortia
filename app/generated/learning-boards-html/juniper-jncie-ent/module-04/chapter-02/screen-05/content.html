Module 4›Chapter 4.2›Defining Local AS and BGP Group
Junos CLI Configuration
set routing-options autonomous-system 64500
set protocols bgp group EBGP-PEER type external
Command Breakdown

routing-options autonomous-system: Defines the local AS number for the router. This is a global BGP setting.

Explanation

Understanding Each Command

  • •Local AS Number: Establishes your router's identity for BGP. All BGP sessions on this router will use this AS.
  • •BGP Group: A logical container for neighbors sharing common parameters. Simplifies configuration and management.
  • •type external: Explicitly marks the group for eBGP peering, influencing default behaviors like TTL.
Example Scenario

Router A (AS 64500) sets its local AS and creates an eBGP group named 'EBGP-PEER' to connect to an external network.

Key Takeaway

The local AS is a global BGP identifier, and BGP groups are essential for organizing and applying consistent configurations to eBGP neighbors.
