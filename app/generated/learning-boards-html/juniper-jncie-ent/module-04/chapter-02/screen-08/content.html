Module 4›Chapter 4.2›Verifying Learned Routes
Junos CLI Verification
show route protocol bgp
Expected Output (Example)

10.0.0.0/24 *[BGP/170] 00:01:23, localpref 100, from 192.168.1.2

Explanation

Interpreting Learned Routes

  • •Purpose: Confirms that routes are being received from the eBGP peer and installed into the local routing table.
  • •Filtering: The command specifically shows routes learned via the BGP protocol.
  • •Troubleshooting: If no routes appear, investigate routing policies on both sides or verify the peer is advertising routes.
Why it Matters

Without learned routes, the eBGP session cannot facilitate data plane connectivity to the remote AS, making it functionally useless.

Key Takeaway

Always verify learned routes with show route protocol bgp to ensure actual inter-AS reachability, not just session establishment.
