Key Concepts

Essential takeaways from this chapter

BGP Path Attributes

Information carried with BGP routes, describing the path and used by the best path selection algorithm for policy-driven decisions.

NEXT_HOP

The IP address of the next router to which traffic for the advertised prefix should be sent. Reachability is a prerequisite for route validity.

AS_PATH

A list of ASNs traversed by a route, used for loop prevention (discard if own AS is present) and path length preference (shorter is better).

Summary Takeaway

BGP's intelligence stems from its path attributes, which provide rich context for routing decisions, ensuring loop prevention and enabling precise traffic control.
