Key Concepts (Continued)

More essential takeaways from this chapter

ORIGIN

Indicates how a route entered BGP (IGP, EGP, Incomplete), influencing its preference (IGP is most preferred).

LOCAL_PREF

Used *within* an AS to prefer an exit path (higher value preferred), influencing outbound traffic. Not advertised externally.

MED

Influences *inbound* traffic from an adjacent AS (lower value preferred), helping external ASes choose an entry point. Non-transitive.

Summary Takeaway

The BGP Best Path Selection Algorithm, driven by attributes like ORIGIN, LOCAL_PREF, and MED, provides granular control over both inbound and outbound traffic flows.
