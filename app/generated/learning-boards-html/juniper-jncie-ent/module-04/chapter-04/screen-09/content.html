Key Attribute

MED (Multi-Exit Discriminator)

Influencing inbound traffic from adjacent Autonomous Systems

Definition

An optional non-transitive attribute used to influence *inbound* traffic from an adjacent AS that has multiple entry points into your AS.

Preference Rule

A lower MED value is preferred. It helps external ASes choose the 'best' entry point into your network.

Key Takeaway

MED is for influencing *inbound* traffic from adjacent ASes; it is not propagated beyond the next AS hop.

ISP X (AS100)
Route via Router R1 (AS65000)
MED: 50

Configured lower to make this entry point preferred by ISP X.

Route via Router R2 (AS65000)
MED: 100

Higher MED means this path will be less preferred by ISP X.
