Key Attribute

AS_PATH Attribute

Tracing the route's journey and preventing loops

Definition

A sequence of Autonomous System numbers that a route has traversed to reach the current BGP speaker.

Loop Prevention

If a BGP router sees its own AS number in the AS_PATH, it discards the route to prevent routing loops.

Key Takeaway

AS_PATH is vital for BGP stability and path preference; manipulate it with prepending to influence inbound traffic.

AS_PATH Length Preference

Shorter AS_PATHs are generally preferred, indicating a more direct route. This is a key factor in best path selection.

Path A: AS100 AS200 (Length 2)
Path B: AS100 AS300 AS400 (Length 3)
Path A is preferred.
AS-Path Prepending

Artificially lengthens the AS_PATH by adding your own AS number multiple times. Used to influence inbound traffic, making a path less preferred.

Original: AS100
Prepended: AS100 AS100 AS100
