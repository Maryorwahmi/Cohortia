Key Attribute

LOCAL_PREF (Local Preference)

Influencing outbound traffic within an Autonomous System

Definition

A well-known discretionary attribute used *within* an Autonomous System to prefer an exit path to a destination.

Preference Rule

A higher LOCAL_PREF value is always preferred. It's a powerful tool for consistent outbound traffic engineering across your AS.

Key Takeaway

LOCAL_PREF is the primary attribute for controlling outbound traffic within your AS; it is not advertised externally.

AS 65000 (Your Network)
Route via ISP A (AS100)
LOCAL_PREF: 200

Configured higher to prefer this exit path for all internal routers.

Route via ISP B (AS200)
LOCAL_PREF: 100

Lower preference means this path will be used only if the ISP A path is unavailable.
