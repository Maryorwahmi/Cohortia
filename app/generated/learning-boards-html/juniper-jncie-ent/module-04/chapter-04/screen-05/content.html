Key Attribute

NEXT_HOP Attribute

Directing traffic to the next router in the path

Definition

The IP address of the next router where traffic for the advertised prefix should be sent. It's the immediate forwarding instruction.

Reachability Prerequisite

A BGP route is only considered valid and usable if the NEXT_HOP IP address is reachable via an IGP or static route.

Key Takeaway

NEXT_HOP is fundamental for BGP route validity; ensure its reachability, especially with iBGP and `next-hop-self`.

eBGP NEXT_HOP

Typically the IP address of the directly connected eBGP peer. Simple and direct.

Router A (AS100) --- eBGP --- Router B (AS200)
NEXT_HOP for Router A's routes is Router B's IP.
iBGP NEXT_HOP & `next-hop-self`

By default, iBGP retains the eBGP next-hop. `next-hop-self` changes it to the iBGP router's own IP to ensure internal reachability.

Router B (eBGP) --- iBGP --- Router C (iBGP)
Without `next-hop-self`, Router C might not reach Router A's IP.
