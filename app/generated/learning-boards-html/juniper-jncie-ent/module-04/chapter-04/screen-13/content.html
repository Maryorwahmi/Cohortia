BGP Best Path Selection: Criteria 5-8 & Common Mistakes

Tie-breakers and critical configuration considerations

Deterministic Tie-Breakers

These criteria ensure a single best path is always chosen, even in highly complex scenarios with many equal attributes.

Common Mistake: MED vs. LOCAL_PREF

Trying to influence outbound traffic with MED will fail because LOCAL_PREF is evaluated first and takes precedence. MED is for inbound traffic only.

Key Takeaway

Mastering the full algorithm, including tie-breakers, and understanding attribute scope prevents critical BGP routing errors.

05Prefer eBGP over iBGP

eBGP paths are generally preferred due to their directness to other ASes.

06Lowest IGP Cost to NEXT_HOP

If multiple iBGP paths exist, the one whose next-hop is closest (via IGP) is preferred.

07Lowest BGP Router ID

A tie-breaker: the path learned from the BGP peer with the lowest Router ID wins.

08Lowest Peer IP Address

The final tie-breaker: the path learned from the BGP peer with the lowest IP address.
