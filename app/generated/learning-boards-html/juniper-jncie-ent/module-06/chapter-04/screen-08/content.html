Checking BGP Session State

show bgp summary

This command provides a quick overview of all BGP peers and their current state. Look for peers not in the 'Established' state.

Key Takeaway

BGP sessions must reach the 'Established' state to exchange routes. If a session is stuck in 'Active' or 'Connect', it typically points to underlying TCP connectivity problems, requiring checks on network reachability and firewall rules.

Diagnosing TCP Connectivity

  • Ping Neighbor: Verify basic IP reachability to the BGP neighbor's IP address.
  • Firewall Filters: Check if TCP port 179 is blocked by any firewall rules on either side.
  • Interface Status: Ensure the interface used for peering is up and operational.
Common Mistake

Overlooking basic network connectivity issues, such as a down interface or a blocked TCP port, when a BGP session is stuck in 'Connect' or 'Active'.
