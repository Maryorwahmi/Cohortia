Module 6›Chapter 6.4›BGP Route Flow

Import Policies (Reception)

Control which routes are accepted from a BGP neighbor and installed into the local routing table.

show policy-options policy-statement <policy-name>
show bgp neighbor <neighbor-ip> | match "Import"

Export Policies (Advertisement)

Control which routes are advertised from the local router to a BGP neighbor.

show policy-options policy-statement <policy-name>
show bgp neighbor <neighbor-ip> | match "Export"

Verifying Installed Routes

show route protocol bgp

Confirms which BGP routes have been successfully received and installed into the routing table.

Key Takeaway

BGP route advertisement and reception are governed by import and export policies. Verifying these policies and using `show` commands to inspect received and advertised routes are essential for ensuring correct route exchange.
