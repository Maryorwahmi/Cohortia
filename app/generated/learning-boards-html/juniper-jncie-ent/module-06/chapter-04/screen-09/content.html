Module 6›Chapter 6.4›BGP Peering Problems
Incorrect Neighbor IP

A simple typo in the neighbor's IP address can prevent the BGP session from initiating.

AS Number Mismatch

The remote AS configured must exactly match the peer's actual Autonomous System number.

Authentication Mismatch

If MD5 authentication is used, ensure the configured keys match on both BGP peers.

TCP Port 179 Blocked

Firewall filters can block the BGP session by preventing TCP port 179 from connecting.

Loopback Not Reachable

If using loopbacks for peering, ensure they are advertised into an IGP or static routes exist.

`local-address` Incorrect

If the source IP for BGP isn't set, the router might use an unexpected interface IP.

Detailed Neighbor Information

show bgp neighbor <neighbor-ip> detail

This command provides comprehensive details on the BGP session, including AS numbers, authentication status, and local address, helping pinpoint configuration mismatches.

Key Takeaway

Many BGP peering failures stem from configuration errors like AS number mismatches, incorrect authentication, or network reachability issues. Thoroughly checking neighbor configuration and connectivity is crucial for establishing a stable BGP session.
