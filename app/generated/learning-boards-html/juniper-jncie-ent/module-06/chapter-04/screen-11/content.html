Received vs. Installed

BGP routes can be successfully received from a neighbor but fail to be installed into the active routing table. This distinction is crucial for troubleshooting.

Common Reasons for Inactivity

  • Import Policy: An inbound policy might be rejecting the route.
  • Next-Hop Unreachable: The next-hop IP for the route is not reachable via the IGP.
  • Routing Preference: Another protocol has a higher preference for the same destination.
Key Takeaway

A BGP route can be received but not installed in the routing table due to import policies, next-hop unreachability, or routing preference conflicts. The `show route extensive` command is vital for identifying the exact reason for inactivity.

Diagnosing with `show route extensive`

show route <destination> extensive

This command provides detailed information, including the route's active status and explicit reasons for inactivity (e.g., "Inactive: Rejected by policy", "Inactive: Next-hop invalid").

Pro-Tip

Use show bgp neighbor <neighbor-ip> received-routes to confirm if a route is even being received before troubleshooting installation issues. This helps distinguish between reception and installation problems.
