Module 6›Chapter 6.4›Systematic Troubleshooting
1
Physical/Link Layer

Is the interface up? Any errors? (show interfaces)

2
IP Connectivity

Can the neighbor be reached? (ping, traceroute)

3
Protocol Process

Is the protocol running? Interfaces enabled? (show ospf/bgp summary)

4
Adjacency/Peering

Is the neighbor established? Check parameters. (show ospf neighbor, show bgp summary)

5
Route Exchange

Are routes sent/received? Policies affecting? (show route, show bgp neighbor)

6
Detailed Debugging

Use `traceoptions` or `monitor traffic` if issues persist.

Key Takeaway

A systematic, layered troubleshooting approach is crucial for efficiently resolving complex routing protocol issues. Start with basic physical checks and progressively move to protocol-specific diagnostics and detailed debugging.
