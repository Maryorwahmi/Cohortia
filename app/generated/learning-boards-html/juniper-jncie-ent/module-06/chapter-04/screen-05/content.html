Common Mismatches

  • Subnet Masks: Must match for OSPF Hello packets to be processed.
  • Hello/Dead Intervals: Timers must be consistent between neighbors to maintain adjacency.
  • Authentication Settings: MD5 or simple password authentication keys must match exactly.

Detailed `show` Commands

show ospf interface <interface-name> detail
show ospf neighbor detail

These commands provide in-depth information on OSPF interface parameters and neighbor states, including timers and authentication.

Advanced Debugging with `traceoptions`

set protocols ospf traceoptions file ospf-debug flag hello detail

Enabling `traceoptions` captures OSPF Hello packets, revealing exact discrepancies preventing adjacency formation. This is crucial for deep-level analysis.

Key Takeaway

Mismatched OSPF parameters like subnet masks, Hello/Dead timers, or authentication settings are frequent causes of adjacency failures. Detailed `show` commands and `traceoptions` are essential for pinpointing these discrepancies.

Common Mistake

Forgetting to enable OSPF on a new interface or having an IP address mismatch on a point-to-point link are simple yet frequent errors that prevent adjacency.
