Diagnostic Tools

Identifying Packet Flow Failure Points

Use diagnostic commands to pinpoint issues at each stage of packet traversal through a Juniper device.

Ingress Check

Use monitor traffic interface <interface> to confirm if packets are arriving at the router.

Routing Verification

Check the routing table with show route <destination> to ensure a path exists.

Filter/NAT Inspection

If traffic isn't egressing, inspect output firewall filters (show firewall filter) or NAT rules.

Forwarding Plane Insight

Use show route forwarding-table for details on how the forwarding plane handles packets, which can differ from the routing table.

# Is the packet arriving at the router?
monitor traffic interface ge-0/0/0.0 no-resolve

# Does a route exist to the destination?
show route 10.0.0.1

# Is the forwarding plane behaving as expected?
show route forwarding-table destination 10.0.0.1

# Are output filters blocking traffic?
show firewall filter <filter-name>

# Example output for forwarding table:
"Routing table: inet.0"
"Destination        Type RtRef Act Pcl RtrGrp Group"
"10.0.0.1/32        user   0   1   0   0      0"
"  via ge-0/0/1.0, Push 100000"
Key Takeaway

By systematically checking each packet flow stage with targeted commands, you can efficiently isolate and resolve network issues.
