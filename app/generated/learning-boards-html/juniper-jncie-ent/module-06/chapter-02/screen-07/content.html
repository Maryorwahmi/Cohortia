Commit Confirm: Your Configuration Safety Net

Deploy changes with an automatic rollback timer to prevent lockouts and ensure network stability.

# Enter configuration mode
edit

# Make a potentially disruptive change (e.g., change management interface IP)
set interfaces fxp0 unit 0 family inet address 192.168.1.2/24

# Commit with a 5-minute confirmation timer
commit confirm 5

# Output indicates rollback timer started:
"commit confirmed, rollback in 5 minutes"

# If the change works, confirm it permanently:
commit

# If the change breaks connectivity and you cannot commit,
# the device will automatically revert after 5 minutes.

# To manually rollback before timer expires:
rollback 0
commit
How it Works

Activates configuration changes but starts a timer (default 10 min). If no commit is issued within the timer, it automatically reverts.

Key Benefit

Prevents lockouts and ensures network operability, especially for remote or high-risk configuration changes.

Common Scenario

Changing management interface IPs or firewall rules that could block administrative access. commit confirm provides a safety net.

Key Takeaway

Always use commit confirm when making potentially disruptive changes to ensure a safe rollback if issues arise.
