Monitor Traffic: Real-time Packet Capture

Capture and display raw packets directly from an interface for deep analysis of network flows.

# Basic packet capture on an interface
monitor traffic interface ge-0/0/0.0

# Output will show packets in tcpdump-like format:
"15:00:01.123456 IP 192.168.1.1.12345 > 10.0.0.1.80: Flags [S], seq 12345, win 65535, length 0"
"15:00:01.123500 IP 10.0.0.1.80 > 192.168.1.1.12345: Flags [S.], seq 67890, ack 12346, win 65535, length 0"

# Capture with more detail and without resolving hostnames
monitor traffic interface ge-0/0/0.0 no-resolve detail

# Stop capture: Ctrl+C
What it Does

Captures raw packets from a specified interface and displays them in a tcpdump-like format, showing headers and payload.

Key Benefit

Provides undeniable truth about data plane activity, crucial for verifying firewall rules, diagnosing NAT, and confirming traffic paths.

Caution

Payload inspection should be done with extreme caution due to privacy and security concerns. Focus on headers unless absolutely necessary.

Key Takeaway

monitor traffic is essential for seeing exactly what's on the wire, providing direct evidence for data plane troubleshooting.
