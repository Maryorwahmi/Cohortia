Configuration Best Practices

Configuring Traceoptions and Managing Logs

Learn to set up traceoptions judiciously and manage generated log files efficiently.

# Configure OSPF traceoptions
edit protocols ospf
set traceoptions file ospf-debug size 10m files 2
# 'size 10m' sets max file size to 10MB
# 'files 2' keeps 2 historical files

# Enable specific flags for detailed logging
set traceoptions flag hello detail
set traceoptions flag error detail

# Commit the changes
commit and-quit

# View the log file
show log ospf-debug

# Disable traceoptions after troubleshooting
edit protocols ospf
delete traceoptions
commit and-quit
Specify File & Size

Always direct logs to a specific file (e.g., file ospf-debug) and set size limits (size 10m files 2) to prevent disk exhaustion.

Use Flags Judiciously

Avoid flag all in production. Select specific flags (e.g., flag hello detail) to capture only relevant events and reduce log volume.

Common Mistake

Leaving traceoptions enabled indefinitely in production can severely impact device performance and fill up storage. Always disable them after use.

Key Takeaway

Traceoptions are powerful but require careful configuration and management to avoid adverse effects on network devices.
