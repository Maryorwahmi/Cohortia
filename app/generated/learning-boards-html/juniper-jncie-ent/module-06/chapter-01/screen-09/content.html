`monitor interface traffic` and `monitor log` in Action

Observing real-time traffic and log messages for immediate feedback during troubleshooting.

Monitoring Interface Traffic

# Monitor traffic on interface ge-0/0/0
monitor interface traffic ge-0/0/0

# Example Output (updates every few seconds):
Interface: ge-0/0/0 (Active) (SNMP ifIndex 501)
  Link-level type: Ethernet, MTU: 1514, Speed: 1Gbps
  Input bytes: 123456789, Output bytes: 987654321
  Input packets: 123456, Output packets: 98765
  Input rate: 1000 bps (1 pps), Output rate: 500 bps (0 pps)

Monitoring Log Files

# Monitor the 'auth-log' file in real-time
monitor log auth-log

# Example Output (new log entries appear instantly):
Aug 1 10:00:05 R1 sshd[12345]: USER_AUTH_SUCCESS: User 'admin' authenticated from 192.168.1.10
Aug 1 10:00:10 R1 sshd[12346]: USER_AUTH_FAILED: User 'guest' failed authentication from 192.168.1.11
Key Takeaway

monitor interface traffic provides live bandwidth and error updates, while monitor log offers immediate visibility into system events, both crucial for dynamic troubleshooting.

Pro-Tip

Use a split-screen terminal or multiple SSH sessions to run monitor commands while generating traffic or triggering events for a comprehensive view.
