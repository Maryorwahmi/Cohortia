Operational Modes and Command Filtering

Navigating Junos OS modes and refining command output with powerful pipe filters.

Junos OS Operational Modes

Operational Mode (>)

For executing show and monitor commands to view device status.

Configuration Mode (#)

For making configuration changes to the device.

# Switch to configuration mode
edit

# Commit changes and return to operational mode
commit and-quit

Powerful Pipe Filters (`|`)

# Display only interfaces that are 'up'
show interfaces terse | match up

# Exclude lines containing 'down'
show interfaces terse | except down

# Count the number of active BGP sessions
show bgp summary | count Established

# Display output in XML format for scripting
show interfaces | display xml
Key Takeaway

Mastering operational modes and utilizing pipe filters like match, except, and display xml significantly enhances efficiency in Junos OS diagnostics.

Helpful Hint

Use the ? (question mark) at any point in the CLI to get context-sensitive help on commands and options.
