Practical Application

`show interfaces` for Interface Status

Quickly assess interface health, operational status, and detailed statistics.

Command Walkthrough

# Get a concise summary of all interfaces
show interfaces terse

# Example Output:
Interface               Admin Link Proto    Local                 Remote
ge-0/0/0                up    up   inet     192.168.1.1/24
ge-0/0/1                up    down
lo0                     up    up   inet     127.0.0.1/8
# Get extensive details for a specific interface
show interfaces ge-0/0/0 extensive

# Example Output (snippet):
  Input errors: 0, Output errors: 0
  Input packets: 12345, Output packets: 9876
  Input bytes: 1.2M, Output bytes: 987K
  CRC errors: 0, L3 incompletes: 0

Interpreting the Output

  • •Admin/Link Status: 'up/up' indicates a healthy interface. 'down' suggests a physical or logical issue.
  • •Input/Output Errors: Non-zero values here can point to physical layer problems, duplex mismatches, or faulty cabling.
  • •Packet/Byte Counts: Useful for understanding traffic flow and identifying unexpected activity.
Key Takeaway

show interfaces terse provides a quick overview, while show interfaces <name> extensive offers deep diagnostic details for specific interface issues.

Pro-Tip

Always check both Admin and Link status. An interface can be Admin 'up' but Link 'down' if there's a physical layer problem.
