Setting Up SNMPv2c on Juniper Devices

Enabling basic network monitoring with community strings.

Community Strings Explained

These are plain-text passwords used for authentication in SNMPv1/v2c. They grant either read-only or read-write access to MIB data.

Security Risk: Plain-Text Passwords

Community strings are sent unencrypted, making them vulnerable to interception. Avoid default or easily guessable strings.

Best Practice: Restrict Clients

Always limit SNMP access to specific Network Management System (NMS) IP addresses. This significantly reduces the attack surface.

Key Takeaway

SNMPv2c is easy to configure but requires strict access control and strong, non-default community strings to mitigate security risks.

Junos CLI Configuration: SNMPv2c
set snmp community public-read authorization read-only # Defines a read-only communityset snmp community public-read clients 192.168.1.5/32 # Restricts access to a specific NMS IPset snmp trap-group my-traps categories link authentication # Configures trap categoriesset snmp trap-group my-traps targets 192.168.1.5 # Specifies trap destination
This configuration sets up a read-only community for 192.168.1.5 and configures the device to send link and authentication traps to the same target.
