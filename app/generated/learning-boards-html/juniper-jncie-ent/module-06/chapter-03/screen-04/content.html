SNMP Fundamentals: Manager, Agent, and MIBs

How network devices communicate management information.

01

SNMP Manager (NMS)

A central system that queries and receives data from SNMP Agents. It's your network's command center for monitoring.

02

SNMP Agent

Software running on a network device (e.g., Juniper router) that collects and provides management information. It's the device's local reporter.

03

Management Information Base (MIB)

A hierarchical database defining the structure and types of data available for management. Think of it as a detailed catalog of device metrics.

04

Object Identifier (OID)

A unique address used to identify specific data objects within a MIB. It's like a precise street address for a piece of information.

The SNMP Interaction Flow

SNMP Manager (NMS)
Queries/Requests (e.g., Get, GetNext)
SNMP Agent (on Device)
Responses/Traps (from MIB)
Key Takeaway

SNMP's Manager-Agent model, coupled with structured MIBs and OIDs, provides a standardized framework for network device monitoring.
