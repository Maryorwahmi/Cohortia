Configuring JTI Sensors and Export Profiles

Defining what data to collect and where to send it.

Step 1: Define a Sensor

Specify the data resource path (e.g., interface statistics) and the collection interval. This tells JTI *what* to monitor.

Step 2: Create an Export Profile

Configure the collector's IP, port, transport protocol (gRPC), and the export rate. This defines *where* and *how often* data is sent.

Step 3: Link with a Stream

Create a stream that connects your defined sensor to your export profile, initiating the continuous data flow.

Key Takeaway

JTI configuration involves defining sensors for data, export profiles for destinations, and streams to link them for continuous data streaming.

Junos CLI Configuration: JTI
set services analytics sensor interface-stats-sensor interval 10 # Collect every 10 secondsset services analytics sensor interface-stats-sensor resource /junos/system/linecard/interface/ # Resource path for interface statsset services analytics export-profile telemetry-profile-1 local-address 10.0.0.1 # Device's source IPset services analytics export-profile telemetry-profile-1 forwarding-options export-rate 10 # Export rate in secondsset services analytics export-profile telemetry-profile-1 transport grpc protocol udp port 50051 # Transport detailsset services analytics export-profile telemetry-profile-1 collector 192.168.1.100 # Collector IPset services analytics stream interface-stream sensor interface-stats-sensor # Link sensor to streamset services analytics stream interface-stream export-profile telemetry-profile-1 # Link export profile to stream
This configuration sets up a sensor for interface statistics, an export profile to send data via gRPC to a collector, and then links them in a stream.
