Beyond Polling: Why Modern Networks Need Telemetry

Addressing SNMP's challenges with high-frequency data streaming.

SNMP: Polling Model

The NMS actively *requests* data from devices at predefined intervals. This is a 'pull' model.

SNMP Limitations

  • Introduces latency and overhead.
  • Less granular data, often missing transient events.
  • Not optimal for real-time, high-frequency monitoring.
Key Takeaway

JTI's push model provides superior granularity and real-time insights compared to SNMP's polling, crucial for modern, dynamic network environments.

Junos Telemetry Interface (JTI): Streaming Model

Devices *stream* operational data to external collectors at high frequencies. This is a 'push' model.

JTI Benefits

  • Much higher data rates and lower latency.
  • Enables real-time visibility and predictive analytics.
  • Ideal for cloud-native and intent-based networking.

Underlying Technologies

JTI leverages open standards like gRPC (Google Remote Procedure Call) and Protocol Buffers for efficient data encoding and transport.
