Understanding the JTI Push Model and Architecture

How Juniper devices stream operational data efficiently.

Sensors: Data Definition

Specify *what* operational data to collect (e.g., interface statistics, routing engine metrics). They are the eyes of JTI.

Export Profiles: Destination & Rate

Define *where* and *how often* to send the collected data, including collector IP, port, and transport protocol.

Streams: Linking It All

Connect a specific sensor to an export profile, creating a continuous flow of data from the device to the collector.

Key Takeaway

JTI's architecture uses sensors, export profiles, and streams to efficiently push high-frequency, granular data to external collectors.

Sensor (Collects Data)
