Core Concepts of Network Visibility

Key definitions for SNMP and Telemetry.

SNMP

Standard protocol for remotely monitoring and managing network devices.

SNMP Manager (NMS)

A central system that queries and receives data from SNMP Agents.

SNMP Agent

Software on a network device that collects and provides management information.

MIB

Hierarchical database defining data structure for SNMP management.

OID

Unique address identifying specific data objects within a MIB.

Community String

Plain-text password used for authentication in SNMPv1 and SNMPv2c.

Summary Takeaway

SNMP provides a foundational, standardized approach to network monitoring through its Manager-Agent model, MIBs, OIDs, and community strings.
