Understanding Term Structure

  • 'From' Statement: Defines the match conditions (source/destination IP, protocol, port, etc.) that a packet must meet.
  • 'Then' Statement: Specifies the action to take if all 'from' conditions are matched (e.g., accept, discard, reject, log, count).
  • Sequential Processing: Terms are evaluated in order; the first match determines the packet's fate.
Common Mistake

Overlooking a broad 'accept' term placed before a specific 'deny' term, which can inadvertently allow unwanted traffic.

# Review Firewall Filter Terms
user@router> show firewall filter PROTECT_MGMT
term ALLOW_SSH_FROM_MGMT {
    from {
        source-address { 192.168.10.0/24; }
        protocol tcp;
        destination-port ssh;
    }
    then accept;
}
term DENY_ALL_ELSE {
    then {
        log;
        discard;
    }
}
# Review Security Policy Terms
user@srx> show security policies from-zone trust to-zone untrust
Policy: trust-to-untrust/allow-web {
    match {
        source-address any;
        destination-address any;
        application junos-http;
    }
    then {
        permit;
    }
}
