When to Use Traceoptions

  • Complex Issues: When `show` commands and session details aren't sufficient.
  • Granular Packet Flow: To see every decision point, policy lookup, and NAT translation.
  • Performance Impact: Use with caution; disable immediately after troubleshooting.
Critical Warning

Enabling `traceoptions` can severely impact device performance and fill log files quickly. Always use sparingly and disable promptly.

# Enable Security Flow Traceoptions (Example)
user@srx# set security flow traceoptions file security-debug flag all
user@srx# set security flow traceoptions file security-debug size 10m
user@srx# commit and-quit
# View Traceoptions Log
user@srx> show log security-debug | last 50
... (extensive packet flow details) ...
# Disable Traceoptions (Crucial Step)
user@srx# delete security flow traceoptions
user@srx# commit and-quit
# Explanation

`traceoptions` provide a deep dive into packet processing. Always set a file size limit and remember to delete the configuration after troubleshooting to prevent performance issues.
