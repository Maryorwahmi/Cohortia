Module 6›Chapter 6.5›Key Concepts: Switching Fundamentals

VLAN

A logical grouping of network devices that allows them to communicate as if on the same physical segment, regardless of physical location.

STP

A network protocol that prevents loop formation in switched networks by blocking redundant paths.

MAC Flapping

A condition where a switch repeatedly learns the same MAC address on different interfaces, often indicating a network loop.

Summary Takeaway

Effective troubleshooting of switching issues relies on a solid understanding of VLANs for segmentation, STP for loop prevention, and MAC address table behavior for connectivity.
