Identifying and Correcting Root Bridge Elections

Ensuring optimal traffic flow by controlling the Spanning Tree Protocol root.

Root Bridge Election Process

  • 1Switches exchange Bridge Protocol Data Units (BPDUs).
  • 2The switch with the lowest Bridge ID (priority + MAC address) becomes the Root Bridge.
  • 3All other switches calculate their shortest path to the Root Bridge.

Correcting Suboptimal Root Bridges

  • Use show spanning-tree bridge to identify the current Root Bridge.
  • Adjust the bridge priority on the desired Root Bridge (e.g., set protocols rstp bridge-priority 4096).
Key Takeaway

Proactively managing the STP root bridge ensures efficient traffic paths and prevents network performance degradation.

Junos OS CLI - Verifying and Setting Root Bridge Priority
root@switch> show spanning-tree bridge
STP bridge parameters:
  Bridge ID: 32768.00:10:f0:00:00:01
  Root ID:   32768.00:10:f0:00:00:01  # This switch is the Root Bridge
  Hello time: 2, Max age: 20, Forward delay: 15
  Topology change count: 0
  Time since last topology change: 0

# Example: A non-core switch is the root (priority 32768)
root@non-core-switch> show spanning-tree bridge
  Root ID:   32768.00:10:f0:00:00:01

# To make a core switch the root (assuming its MAC is lower or equal)
root@core-switch# set protocols rstp bridge-priority 4096
root@core-switch# commit and-quit

# After commit, verify again on core switch
root@core-switch> show spanning-tree bridge
  Bridge ID: 4096.00:10:f0:00:00:05
  Root ID:   4096.00:10:f0:00:00:05  # Core switch is now the Root Bridge
