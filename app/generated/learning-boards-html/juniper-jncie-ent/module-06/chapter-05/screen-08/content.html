Network Stability

MAC Flapping and Unknown Unicast Flooding

Resolving issues caused by dynamic MAC address learning and forwarding behavior.

MAC Flapping

  • MAC address learned on multiple interfaces.
  • Indicates a network loop or misconfiguration.
  • Detect with syslog or show ethernet-switching table detail | match "flapping".

Unknown Unicast Flooding

  • Unicast frame for unknown destination MAC.
  • Flooded out all ports in the VLAN (except ingress).
  • Often due to aged-out MACs or non-converged STP.
Key Takeaway

MAC flapping indicates loops, while unknown unicast flooding points to missing MAC entries or underlying issues, both requiring prompt investigation.

Junos OS CLI - Detecting MAC Flapping
# Example syslog message for MAC flapping
Feb 10 10:00:05 switch-1 eswd[1234]: ESWD_MAC_FLAP_DETECTED: MAC 00:11:22:33:44:55 flapping between interface ge-0/0/1.0 and ge-0/0/2.0

root@switch> show ethernet-switching table detail | match
