Core Concept

Understanding STP Roles and States

Preventing network loops and ensuring optimal traffic paths with Spanning Tree Protocol.

Key STP Port Roles

  • Root Port: The best path from a non-root bridge to the root bridge.
  • Designated Port: Forwards traffic on a network segment, elected per segment.
  • Alternate/Backup Port: Blocking state to prevent loops, provides redundancy.

Key STP Port States

  • Forwarding: Actively sending and receiving user traffic.
  • Blocking: Prevents loops, does not forward user traffic.
Key Takeaway

Understanding STP port roles and states is fundamental to diagnosing why a link might be blocking or taking an unexpected path.
