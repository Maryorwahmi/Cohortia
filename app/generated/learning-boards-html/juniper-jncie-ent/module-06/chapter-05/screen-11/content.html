Rule Processing: First Match Wins

Incorrect Order
1. Accept All HTTP
2. Deny Malicious IP HTTP

Malicious HTTP traffic will be ACCEPTED because it matches rule 1 first.

Correct Order
1. Deny Malicious IP HTTP
2. Accept All HTTP

Malicious HTTP traffic will be DENIED because it matches rule 1 first.

Common Mistake

Placing a broad 'accept' rule before a specific 'deny' rule, causing the 'deny' rule to never be evaluated.

Pro-Tip

Always structure your firewall filters and security policies from most specific 'deny' rules to most general 'accept' rules.
