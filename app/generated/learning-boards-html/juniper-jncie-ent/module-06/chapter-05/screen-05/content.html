Common Pitfall

Resolving Trunk Port VLAN Issues

Ensuring consistent VLAN tagging across inter-switch links to prevent traffic blocks.

Trunk Port Mismatch Scenarios

  • VLAN ID List Mismatch: Allowed VLANs on one side don't match the other.
  • Native VLAN Mismatch: Untagged VLAN IDs differ, causing unexpected behavior.
  • Solution: Ensure vlan-id-list and native VLANs are identical on both trunk ports.
Key Takeaway

Trunk ports require precise matching of allowed VLANs and native VLANs on both ends to ensure seamless inter-VLAN communication.

Junos OS CLI - Trunk Port Configuration
# Correct Trunk Configuration (Both Sides)
set interfaces ge-0/0/0 unit 0 family ethernet-switching interface-mode trunk
set interfaces ge-0/0/0 unit 0 family ethernet-switching vlan members [ VLAN-10 VLAN-20 VLAN-30 ]

# Mismatched Trunk Configuration (Side A)
set interfaces ge-0/0/1 unit 0 family ethernet-switching interface-mode trunk
set interfaces ge-0/0/1 unit 0 family ethernet-switching vlan members [ VLAN-10 VLAN-20 ]

# Mismatched Trunk Configuration (Side B - Missing VLAN-30)
set interfaces ge-0/0/2 unit 0 family ethernet-switching interface-mode trunk
set interfaces ge-0/0/2 unit 0 family ethernet-switching vlan members [ VLAN-10 VLAN-20 VLAN-40 ]

# Verification Command
root@switch> show ethernet-switching interfaces ge-0/0/1 detail
Interface: ge-0/0/1.0
  Link-type: Trunk
  VLAN members: VLAN-10 (10), VLAN-20 (20)
  Native VLAN: default (1)

root@switch> show ethernet-switching interfaces ge-0/0/2 detail
Interface: ge-0/0/2.0
  Link-type: Trunk
  VLAN members: VLAN-10 (10), VLAN-20 (20), VLAN-40 (40)
  Native VLAN: default (1)
