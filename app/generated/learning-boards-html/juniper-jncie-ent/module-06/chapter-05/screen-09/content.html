Module 6›Chapter 6.5›Verifying Filter and Policy Application

Initial Verification Steps

  • Confirm Application Point: Verify the filter or policy is attached to the correct interface or security zone.
  • Check Hit Counts: Use `show` commands to see if traffic is actually matching and incrementing policy counters.
  • Review Configuration: Ensure no other filters or policies are inadvertently overriding the intended behavior.
Key Takeaway

Before debugging policy logic, always confirm the filter or policy is applied correctly and actively processing traffic using hit counts.

# Verify Firewall Filter Application
user@router> show firewall | match BLOCK-PING
  input BLOCK-PING;
  output BLOCK-PING;
# Check Security Policy Hit Counts
user@srx> show security policies hit-count
Policy: trust-to-untrust/allow-web, hits: 12345
Policy: trust-to-untrust/deny-all, hits: 567
Policy: untrust-to-trust/deny-all, hits: 890
# Explanation

The `show firewall | match` command quickly confirms where a filter is applied. `show security policies hit-count` provides crucial insight into whether traffic is matching your policies. If hit counts are zero for an expected policy, investigate traffic flow or policy application.
