Configuration Mode

`configure private`

Isolating your changes for safe experimentation

Definition

Creates a private copy of the candidate configuration for a user, allowing isolated changes that don't affect others until merged.

Use Case: Isolated Testing

Perfect for testing complex or potentially disruptive changes without impacting other administrators' work or risking their in-progress configurations.

Merging Changes

Your private changes remain isolated until you explicitly merge them back into the shared candidate configuration using `commit full`.

Key Takeaway

Use `configure private` to safely experiment with configuration changes in an isolated environment before merging them.

Private Configuration Flow

User B enters `private` mode

Gets private config copy

Commits to shared config
