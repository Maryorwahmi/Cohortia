Reusable Configurations with Groups

Streamlining management using `configuration groups` and `apply-groups`

What are Configuration Groups?

Define a set of configuration statements once, then apply them to multiple interfaces, protocols, or other parts of the configuration hierarchy.

Benefits

  • Prevents repetitive typing
  • Reduces configuration errors
  • Simplifies ongoing management
  • Ensures consistency across devices

The `<*>` Wildcard

A powerful tool within groups, allowing the group to apply to dynamic elements, making configurations highly flexible and scalable.

Code Walkthrough: Defining & Applying Groups
# Define a configuration group for common interface settings
set groups common-access-port interfaces <*>/unit <*> description "Access Port"
set groups common-access-port interfaces <*>/unit <*> family ethernet-switching vlan members default

# Apply the group to specific interfaces
set interfaces ge-0/0/1 apply-groups common-access-port
set interfaces ge-0/0/2 apply-groups common-access-port

Verification: `display inheritance`

After applying groups, use `show configuration | display inheritance` to view the resulting inherited configuration and verify its application.

Key Takeaway

Configuration groups and `apply-groups` are essential for creating reusable configuration stanzas, significantly improving efficiency and consistency in Junos OS management.
