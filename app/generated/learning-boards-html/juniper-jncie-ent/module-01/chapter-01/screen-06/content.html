Core Component

The Brain: Routing Engine (RE)

Managing Protocols, Tables, and System Processes

  • •Runs Junos OS on a high-performance PC architecture.
  • •Responsible for all routing protocols (OSPF, BGP, ISIS).
  • •Handles management tasks like CLI, SNMP, and SSH.
  • •Maintains routing and forwarding tables (FIB).
Key Takeaway

The RE is the control plane, making all the intelligent decisions for routing, management, and system operations, then instructing the PFE.

Routing Protocols

Calculates and manages network routes.

Management Interface

Provides CLI, SNMP, and SSH access.

System Processes

Manages logging, alarms, and other background operations.

Forwarding Information Base (FIB)

Builds the table used by the PFE for packet forwarding.
