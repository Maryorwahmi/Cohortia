Troubleshooting Tips

Avoiding Common Junos OS Pitfalls

Commit Often, Understand Modes

  • •Forgetting to `commit` changes after configuration.
  • •Confusing operational mode (for `show` commands) with configuration mode (for `set`/`delete`).
  • •Not using `show | compare` to review changes before committing.
Key Takeaway

Always commit your changes and clearly distinguish between operational and configuration modes to prevent common errors and ensure smooth device management.

Mistake 1: Forgetting to Commit

Changes made in configuration mode are not active until explicitly committed. Always `commit` to apply changes.

Mistake 2: Mode Confusion

Operational mode is for `show` commands. Configuration mode is for `set`/`delete` commands. Use `run ` in config mode for operational commands.
