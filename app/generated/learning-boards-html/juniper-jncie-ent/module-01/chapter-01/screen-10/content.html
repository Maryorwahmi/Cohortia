Configuration Management

Understanding Configuration States

Candidate vs. Active Configuration

  • •Candidate configuration is a temporary, editable workspace.
  • •Changes made here do not immediately affect the network.
  • •Active configuration is the live, running state of the device.
  • •Changes move from candidate to active via the `commit` process.
Key Takeaway

The distinction between candidate and active configurations provides a crucial safety net, allowing you to prepare and review changes before they go live on the network.

Candidate Configuration

A temporary, editable version of the configuration where all changes are staged. It's a draft that can be reviewed or discarded.

Active Configuration

The currently running and operational configuration on the device. This is the live state that dictates network behavior.
