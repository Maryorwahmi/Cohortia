Key Concepts: Stateful Filtering & Zones

Essential terms for understanding advanced Junos firewall capabilities.

Stateful Firewall

A firewall that tracks the state of active network connections, allowing return traffic for established connections automatically.

Security Zone

A logical grouping of network interfaces, used to define security boundaries and apply stateful security policies.

Security Policy

A rule set that defines what traffic is permitted or denied between a specific source zone and destination zone.

Chapter Summary

Stateful firewalls, security zones, and security policies form the core of advanced Junos security, enabling intelligent, context-aware traffic control between network segments.
