Creating a Policer

Use the edit firewall policer hierarchy to define a new policer, specifying its bandwidth and burst limits, and the action to take when traffic exceeds these thresholds.

edit firewall policer LIMIT_GUEST_BANDWIDTHset if-exceeding bandwidth-limit 1mset if-exceeding burst-size-limit 15kset then discard

This example creates a policer named LIMIT_GUEST_BANDWIDTH, capping traffic at 1 Mbps with a 15KB burst size, discarding excess packets.

Key Takeaway

Defining a policer involves setting a sustained bandwidth limit, a burst tolerance, and a clear action like 'discard' for traffic that exceeds these thresholds.

Policer Parameters

Understanding the Limits

Bandwidth Limit

The maximum average rate (e.g., 1 Mbps) that traffic is allowed to transmit. Exceeding this triggers the policer's action.

Burst Size Limit

The maximum amount of traffic that can exceed the bandwidth limit for a short duration. This accommodates traffic spikes.

Action: Discard

The default and most common action, where packets exceeding the defined limits are immediately dropped from the network.
