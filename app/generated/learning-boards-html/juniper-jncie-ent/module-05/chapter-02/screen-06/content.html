Defining Security Zones in Junos

Setting Up Network Segments for Stateful Control

Zone Configuration Basics

  • •Enter `edit security zones` hierarchy.
  • •Use `set security-zone ` to create a zone.
  • •Assign interfaces to zones (e.g., `interfaces ge-0/0/1.0`).
  • •Define `host-inbound-traffic` for router management.
Common Mistake

Forgetting to configure `host-inbound-traffic` can make the Junos device unreachable for management from interfaces within that zone.

Key Takeaway

Properly defining security zones and their host-inbound services is the foundational step for implementing stateful security policies in Junos.

edit security zones
set security-zone trust interfaces ge-0/0/1.0 host-inbound-traffic system-services all
set security-zone untrust interfaces ge-0/0/0.0 host-inbound-traffic system-services ping

Explanation:

  • •`trust` zone: Internal network, allows all services to the router itself.
  • •`untrust` zone: External network (Internet), only allows ping to the router.
  • •`ge-0/0/1.0` and `ge-0/0/0.0`: Example interfaces assigned to these zones.
