Applying a Policer to an Interface

After defining a policer, integrate it into a firewall filter term and then apply that filter to the desired interface unit for either input or output traffic.

edit firewall family inetset filter GUEST_FILTER term LIMIT_GUEST_TRAFFIC from source-address 192.168.50.0/24set filter GUEST_FILTER term LIMIT_GUEST_TRAFFIC then policer LIMIT_GUEST_BANDWIDTHset filter GUEST_FILTER term GUEST_ALLOW_ALL then acceptedit interfaces ge-0/0/2 unit 0 family inetset filter input GUEST_FILTERcommit and-quit

This example applies GUEST_FILTER (containing the policer) to the input of interface ge-0/0/2.0.

Key Takeaway

Policers are activated by applying a firewall filter containing the policer action to a specific interface, ensuring traffic matching the filter's criteria is rate-limited.

Application Flow

From Policer to Interface

1. Define Policer

Create the policer with bandwidth, burst, and action settings.

2. Create Firewall Filter

Develop a stateless filter with terms that match traffic and apply the policer.

3. Apply to Interface

Attach the firewall filter to the input or output of a logical interface unit.
