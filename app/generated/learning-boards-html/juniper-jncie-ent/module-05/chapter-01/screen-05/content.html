The Building Blocks: Filters and Terms

Organizing rules with 'from' conditions and 'then' actions for precise traffic control.

Firewall Filter

A named container for a set of rules.

Term (Rule)

A logical block with match conditions and actions.

'From' Statements

Match conditions (e.g., source IP, port).

'Then' Statements

Actions (e.g., accept, discard, reject).

Filter Definition

A firewall filter is a named entity that groups multiple terms. It's the overarching policy container.

Term Explanation

Each term is a specific rule within the filter. Terms are processed sequentially, and the first matching term dictates the action.

'From' Conditions

These define the criteria a packet must meet to match the term. Examples include source/destination IP, port, protocol, and TCP flags.

'Then' Actions

These specify what happens to a packet that matches the 'from' conditions. Common actions include accept, discard, reject, log, and count.

Key Takeaway

Junos filters are modular, using named filters to contain ordered terms, each with specific match conditions ('from') and corresponding actions ('then').
