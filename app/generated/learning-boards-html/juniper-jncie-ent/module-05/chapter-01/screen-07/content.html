Sequential Processing

Junos processes terms from top to bottom. The first term that matches a packet's characteristics dictates the action, and processing stops.

Implicit Deny

If a packet does not match any term in the filter, it is implicitly dropped by default. This is a crucial security principle.

Key Takeaway

Always remember that term order is critical: the first match wins. The implicit deny ensures that only explicitly permitted traffic can pass.
