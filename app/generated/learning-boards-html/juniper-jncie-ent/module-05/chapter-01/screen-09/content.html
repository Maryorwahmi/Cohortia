Configuring a Basic Stateless Filter

Blocking SSH from a specific host while permitting all other traffic.

edit firewall family inet
set filter BLOCK_SSH_FROM_HOST
set filter BLOCK_SSH_FROM_HOST term BLOCK_SPECIFIC_SSH from source-address 192.168.1.10/32
set filter BLOCK_SSH_FROM_HOST term BLOCK_SPECIFIC_SSH from protocol tcp
set filter BLOCK_SSH_FROM_HOST term BLOCK_SPECIFIC_SSH from destination-port 22
set filter BLOCK_SSH_FROM_HOST term BLOCK_SPECIFIC_SSH then discard
set filter BLOCK_SSH_FROM_HOST term ALLOW_ALL_ELSE then accept
commit and-quit
Filter Creation

Start by entering the firewall hierarchy and defining a unique name for your filter.

Specific Block Term

Define a term with precise 'from' conditions (source IP, protocol, destination port) and a 'then discard' action.

General Allow Term

Include a final term with 'then accept' to permit all other traffic not explicitly blocked by preceding terms.

Key Takeaway

A basic filter involves defining a filter, creating specific 'discard' terms, followed by a general 'accept' term, and then committing the changes.
