Core Concept

What are Stateless Firewall Filters?

Stateless firewall filters are a set of rules that examine incoming or outgoing packets against defined criteria and then take a specified action based on whether a match is found.

  • •Per-Packet Basis: Each packet is evaluated independently, without regard for previous packets in the same flow.
  • •No Connection State: They do not maintain any information about the state of a connection.
  • •High Efficiency: Ideal for simple packet filtering tasks like blocking specific IP addresses, ports, or protocols.
Key Takeaway

Stateless filters offer fast, efficient packet inspection without tracking connection state, making them perfect for initial, broad traffic control.
