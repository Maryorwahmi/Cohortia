Applying Filters to Logical Interfaces

Controlling traffic flow at ingress and egress points for effective policy enforcement.

Input Direction

Applies to traffic entering the interface. Typically used to protect the device or network segment behind it.

Output Direction

Applies to traffic exiting the interface. Used to control traffic leaving a specific subnet or device.

CLI Example: Apply Filter
edit interfaces ge-0/0/1 unit 0 family inet
set filter input BLOCK_SSH_FROM_HOST
commit and-quit
Key Takeaway

Filters are applied to logical interfaces in either the 'input' or 'output' direction, a critical step for activating your security policies.
