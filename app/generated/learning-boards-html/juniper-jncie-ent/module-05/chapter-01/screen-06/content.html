Defining 'From' Statements: Match Conditions

Specifying precise criteria for packet identification to control traffic flow.

IP Addresses & Prefixes

Source or destination IP addresses (e.g., 192.168.1.10/32) or subnets (e.g., 10.0.0.0/8).

Ports (Source/Destination)

Specific port numbers (e.g., 80 for HTTP, 22 for SSH) or ranges.

Protocols

Network protocols like tcp, udp, icmp, or specific protocol numbers.

TCP Flags & Others

Specific TCP flags (e.g., syn, ack) or advanced criteria like IP options.

Why Granularity Matters

The more specific your match conditions, the more precise your traffic control. This prevents unintended blocking or permitting of traffic.

Example: Blocking SSH

To block SSH, you would match protocol tcp and destination-port 22. This ensures only SSH traffic is targeted.

Key Takeaway

'From' statements enable highly detailed packet matching, using criteria like IP addresses, ports, and protocols to define exactly what traffic a term applies to.
