DNAT Configuration

Configuring Destination NAT on Junos

Setting up rules to publish internal web services

Configuration Steps

  • Define Rule-Set: Create a destination NAT rule-set (e.g., UNTRUST-TO-DMZ).
  • Specify Zones: Set 'from zone' to 'untrust' for incoming internet traffic.
  • Match Criteria: Define rules to match the public destination IP and port.
  • Define Pool: Create a NAT pool specifying the internal server's private IP and port.
  • Apply Pool: Link the NAT rule to the defined destination NAT pool.
Example Scenario

Publish an internal web server (192.168.1.10:80) to the internet via public IP 203.0.113.10:80.

Key Takeaway

Successful DNAT configuration requires both the NAT rule to translate addresses and a corresponding security policy to permit the translated traffic through the firewall.

Junos CLI Configuration
edit security nat destination rule-set UNTRUST-TO-DMZ
set from zone untrust
set rule WEB_SERVER_ACCESS match destination-address 203.0.113.10/32
set rule WEB_SERVER_ACCESS match destination-port 80
set rule WEB_SERVER_ACCESS then destination-nat pool WEB_SERVER_POOL

edit security nat destination pool WEB_SERVER_POOL
set address 192.168.1.10/32 port 80
commit and-quit
Common Mistake

Forgetting the security policy! After configuring DNAT, you must also create a security policy (e.g., from-zone untrust to-zone dmz) to permit the translated traffic to reach the internal server.
