SNAT Configuration

Interface-based Source NAT on Junos

Simplifying outbound internet access with the egress interface IP

Key Characteristics

  • Automatic IP Selection: Uses the IP address of the router's outbound interface.
  • Simplicity: Easiest to configure, ideal for basic internet connectivity.
  • Common Use: Widely adopted for small to medium-sized networks.
  • Zone-based: Typically applied between a 'trust' (internal) and 'untrust' (external) zone.
Example Use Case

A small office network where all internal users need internet access through a single public IP provided by the ISP on the router's external interface.

Key Takeaway

Interface-based SNAT is the most straightforward way to provide internet access for internal hosts by leveraging the egress interface's IP address.

Junos CLI Configuration
edit security nat source rule-set TRUST-TO-UNTRUST
set from zone trust
set to zone untrust
set rule ALLOW_OUTBOUND_TRAFFIC match source-address 0.0.0.0/0 # Matches any source in the 'from' zone
set rule ALLOW_OUTBOUND_TRAFFIC then source-nat interface
commit and-quit
Important Note

Ensure your security policies permit traffic from the 'trust' zone to the 'untrust' zone, otherwise, NAT translations will occur but traffic will still be dropped.
