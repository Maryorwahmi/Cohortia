NAT Type

Destination NAT (DNAT): Publishing Internal Services

Translating public destination IPs to private internal server IPs

How DNAT Works

  • Inbound Traffic: Initiated from public internet to private network.
  • Address Translation: Public destination IP and port are translated to a private IP and port.
  • Service Exposure: Allows specific internal services to be accessible externally.
  • Port Forwarding: Often involves translating a public port to a different internal port.
Example Scenario

An external user accesses your public IP 203.0.113.10 on port 80. DNAT translates this to your internal web server at 192.168.1.10 on port 80.

Key Takeaway

DNAT is essential for securely exposing internal services to the internet by translating public requests to their corresponding private server addresses and ports.

DNAT Benefits & Considerations

Controlled Exposure

Only specific services on specific ports are exposed, maintaining internal network privacy.

Service Hosting

Enables organizations to host their own web, mail, or application servers internally while making them accessible globally.

Common Mistake

Forgetting to configure a corresponding security policy after setting up DNAT. The traffic will be translated but still blocked by the firewall if no policy permits it.
