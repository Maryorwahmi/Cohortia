Static NAT Configuration

Configuring Static NAT on Junos

Implementing a one-to-one mapping for internal servers

Configuration Steps

  • Define Rule-Set: Create a static NAT rule-set (e.g., MAIL_SERVER_STATIC_NAT).
  • Specify Zones: Set 'from zone' to 'untrust' for incoming internet traffic.
  • Match Criteria: Define rules to match the public destination IP address.
  • Apply Static NAT: Use 'then static-nat prefix' with the internal server's private IP.
Example Scenario

Map public IP 203.0.113.11 to internal server 192.168.1.20 for consistent bidirectional access.

Key Takeaway

Static NAT simplifies network design for critical servers by providing a stable, dedicated public IP, but always remember to pair it with appropriate security policies.

Junos CLI Configuration
edit security nat static rule-set MAIL_SERVER_STATIC_NAT
set from zone untrust
set rule MAIL_SERVER_RULE match destination-address 203.0.113.11/32
set rule MAIL_SERVER_RULE then static-nat prefix 192.168.1.20/32
commit and-quit
Important Note

Static NAT creates a bidirectional mapping. This means both inbound traffic to the public IP and outbound traffic from the private IP will be translated.
