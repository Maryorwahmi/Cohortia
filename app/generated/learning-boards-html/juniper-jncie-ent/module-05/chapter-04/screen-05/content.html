NAT Type

Source NAT (SNAT): Enabling Outbound Connections

Translating private IPs to public IPs for internet access

How SNAT Works

  • Outbound Traffic: Initiated from private network to public internet.
  • Address Translation: Private source IP and port are translated to a public IP and unique port.
  • Session Table: Junos maintains a NAT session table to track active translations.
  • Return Traffic: Public destination IP and port are translated back to the original private IP and port using the session table.
Example Scenario

An internal laptop (192.168.1.10) wants to browse a website. Its traffic leaves the Junos device with the public IP (203.0.113.1) of the internet-facing interface, and a unique source port.

Key Takeaway

SNAT is crucial for allowing multiple internal devices to share a single public IP for internet access, effectively conserving IPv4 addresses and simplifying network management.

SNAT Benefits & Naming

IPv4 Address Conservation

Many-to-one mapping significantly reduces the need for public IP addresses.

Network Obscurity

Internal IP addresses are hidden from the public internet, adding a layer of security.

Terminology Note

SNAT is often used interchangeably with PAT (Port Address Translation) or NAT Overload, highlighting its port-multiplexing capability.
