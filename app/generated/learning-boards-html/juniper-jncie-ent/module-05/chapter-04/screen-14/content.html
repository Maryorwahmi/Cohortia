Key Concepts: Advanced NAT & Rule Order

Recap of advanced NAT types and critical processing sequence

Pool-based SNAT

Uses an IP address from a defined pool of public IP addresses for source translation, offering flexibility and load distribution.

Destination NAT (DNAT)

Translates the destination IP address of incoming packets, typically from a public IP to a private IP, often with port translation.

Static NAT

Provides a one-to-one, bidirectional mapping between a private IP address and a public IP address for consistent identity.

Summary Takeaway

Advanced NAT types like Pool-based SNAT, DNAT, and Static NAT offer specialized translation capabilities, all governed by a strict processing order: Static -> Destination -> Source.
