SNAT Configuration

Pool-based Source NAT: Flexible IP Allocation

Utilizing a predefined pool of public IPs for outbound translation

Key Characteristics

  • Defined IP Range: Uses a specific range of public IP addresses for translation.
  • Enhanced Flexibility: Allows for load distribution across multiple public IPs.
  • Granular Control: Can assign specific public IPs to different internal subnets.
  • Scalability: Better suited for larger networks with more complex outbound requirements.
Example Use Case

An enterprise with multiple public IPs wants to ensure that traffic from the 'Marketing' department always uses a specific public IP, while 'Engineering' uses another.

Key Takeaway

Pool-based SNAT offers advanced control over public IP allocation for outbound traffic, enabling load balancing and specific IP assignments for internal subnets.

Junos CLI Configuration Snippet
edit security nat source pool OUTBOUND_POOL
set address 203.0.113.10-203.0.113.15 # Define a range of public IPs

edit security nat source rule-set TRUST-TO-UNTRUST
set from zone trust
set to zone untrust
set rule ALLOW_OUTBOUND_TRAFFIC match source-address 0.0.0.0/0
set rule ALLOW_OUTBOUND_TRAFFIC then source-nat pool OUTBOUND_POOL
commit and-quit
Pro Tip

When defining a pool, consider the number of concurrent sessions expected. A larger pool provides more unique public IP/port combinations, reducing the chance of port exhaustion.
