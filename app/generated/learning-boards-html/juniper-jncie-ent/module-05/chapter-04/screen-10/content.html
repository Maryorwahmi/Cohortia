NAT Type

Static NAT: One-to-One Permanent Mapping

Establishing a consistent, bidirectional link between private and public IPs

Key Characteristics

  • One-to-One: A single private IP maps to a single public IP.
  • Permanent: The mapping is constant and always active.
  • Bidirectional: Translates both source (outbound) and destination (inbound) addresses.
  • No Port Translation: Typically, ports are not modified, unlike SNAT/DNAT.
Example Use Case

An internal mail server (192.168.1.20) needs to be consistently accessible from the internet via 203.0.113.11, and its outbound emails should also appear from 203.0.113.11.

Key Takeaway

Static NAT provides a stable, dedicated public identity for internal servers, simplifying access and management for services requiring consistent IP addresses.

Benefits & Comparison

Predictable Access

External users always connect to the same public IP, which maps directly to the internal server.

Simplified DNS

Easier to manage DNS records as the public IP is fixed for the internal host.

Contrast with SNAT/DNAT

Unlike SNAT (many-to-one, outbound) or DNAT (one-to-many, inbound), Static NAT is a true one-to-one, bidirectional mapping without port translation.
