Configuring Screen Options

Applying Attack Mitigation to Security Zones

edit security zones security-zone untrust
set screen untrust-screen

edit security screen untrust-screen
set ip-options
set tcp syn-flood alarm-threshold 1000
set tcp syn-flood attack-threshold 2000
set tcp syn-flood timeout 20
set ip-spoofing
set icmp ping-of-death
commit and-quit

Command Breakdown

  • •edit security screen [name]: Creates or modifies a screen profile.
  • •set ip-options / set ip-spoofing: Enables specific screen protections.
  • •set tcp syn-flood alarm-threshold: Logs a warning when SYN rate exceeds this.
  • •set tcp syn-flood attack-threshold: Triggers active protection (e.g., dropping packets).
  • •set security zones security-zone [zone] screen [profile]: Applies the screen profile to a zone.
Key Takeaway

Screen options are configured in a profile and then applied to specific security zones, enabling tailored attack mitigation.
