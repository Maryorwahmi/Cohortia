Screen Option Thresholds and Safety

Balancing Protection with Network Performance

Understanding Thresholds

  • •alarm-threshold: Logs a warning when exceeded (early warning).
  • •attack-threshold: Triggers active protection (e.g., dropping packets).
  • •Critical for rate-based protections like tcp-syn-flood.
Key Takeaway

Carefully tune screen option thresholds based on network traffic patterns to prevent legitimate traffic from being blocked.

Safety Notes & Best Practices

Avoid Over-Aggression

Overly aggressive thresholds can block legitimate traffic during peak loads.

Monitor & Fine-Tune

Use show security log to monitor screen hits and adjust thresholds.
