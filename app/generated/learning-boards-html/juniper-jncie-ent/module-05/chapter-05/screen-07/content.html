Configuring Security Zones

Assigning Interfaces to Logical Boundaries

edit security zones
set security-zone internal interfaces ge-0/0/1.0 host-inbound-traffic system-services ssh
set security-zone dmz interfaces ge-0/0/2.0
set security-zone untrust interfaces ge-0/0/0.0 host-inbound-traffic system-services ping

Explanation of Commands

  • •edit security zones: Enters the security zones configuration hierarchy.
  • •set security-zone [name] interfaces [interface.unit]: Creates a zone and assigns a logical interface.
  • •host-inbound-traffic system-services [service]: Allows the Junos device to respond to specified services on interfaces within that zone.
Key Takeaway

Properly defining security zones and assigning interfaces, along with host-inbound-traffic settings, establishes the foundational security architecture.
