Identifying Routes with `from` Conditions

Criteria for matching routing attributes

Source Protocol

Match routes learned from specific protocols (e.g., OSPF, BGP, static, direct).

Route Prefixes

Specify exact prefixes or ranges using `route-filter` with options like `exact`, `longer`, `orlonger`, `upto`.

BGP Attributes

Match on BGP-specific attributes such as AS path, community values, or local preference.

Example

To match all OSPF routes: `from protocol ospf`. To match a specific prefix: `from route-filter 10.0.0.0/8 exact`.
