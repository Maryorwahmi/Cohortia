Influencing BGP Path Selection

Modifying `local-preference` for preferred paths

BGP Attributes

BGP uses attributes like `local-preference`, `MED`, `AS-path`, and `community` to determine the best path.

Scenario

Prefer routes learned from ISP-A over ISP-B for all outbound traffic by setting a higher `local-preference`.

Key Takeaway

Manipulating `local-preference` via import policies is a primary method for influencing outbound traffic paths in BGP.

Pro Tip

`local-preference` is a local attribute, meaning it's only significant within your autonomous system and is not advertised to external peers.

Junos CLI Configuration
edit policy-options policy-statement PREFER_ISP_A
set term SET_LP from protocol bgp
set term SET_LP then local-preference 200
set term SET_LP then accept

# Apply this policy as an import policy to the BGP group for ISP-A
edit protocols bgp group ISP-A
set import PREFER_ISP_A
commit and-quit
Code Explanation

This policy matches all BGP routes and sets their local preference to 200 (higher than the default 100). Applied as an import policy to ISP-A, it makes routes from ISP-A preferred.
