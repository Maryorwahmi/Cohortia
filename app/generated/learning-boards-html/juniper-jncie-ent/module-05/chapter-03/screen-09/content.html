Mastering `route-filter` Match Types

Understanding `exact`, `longer`, `orlonger`, and `upto`

`exact`

Matches only the specified prefix and prefix length exactly. E.g., `10.0.0.0/24 exact` matches only `10.0.0.0/24`.

`longer`

Matches the specified prefix and any more specific prefixes within it. E.g., `10.0.0.0/8 longer` matches `10.0.0.0/8` and `10.1.1.0/24`.

`orlonger`

Matches the specified prefix and any more specific prefixes, including the specified prefix itself. Similar to `longer` but explicitly includes the base prefix.

Key Takeaway

Choosing the correct `route-filter` match type is crucial for precise route filtering and avoiding unintended policy effects.

`route-filter` Options Explained

`exact`

Matches only the exact prefix and length.

route-filter 192.168.1.0/24 exact

`longer`

Matches the prefix and any more specific prefixes.

route-filter 10.0.0.0/8 longer

`orlonger`

Matches the prefix itself or any more specific prefixes.

route-filter 172.16.0.0/16 orlonger

`upto`

Matches the prefix and any less specific prefixes up to a given length.

route-filter 10.0.0.0/8 upto /24
