Module 05 › Chapter 5.6 › Postfix Configuration
/etc/postfix/main.cf
# /etc/postfix/main.cf
# Set Amavisd-new as the content filter for incoming mail
content_filter = amavisfeed:[127.0.0.1]:10024

# Example existing milter entry preserved if present
smtpd_milters = unix:/var/run/opendkim/opendkim.sock
Add the content_filter line and save. Next, add the master.cf service on 127.0.0.1:10025 to receive scanned mail back from Amavisd-new.
/etc/postfix/master.cf (snippet)
# Service for Postfix to receive scanned mail from Amavisd-new
127.0.0.1:10025 inet    n       -       y       -       -       smtpd
    -o content_filter=
    -o receive_override_options=no_unknown_recipient_checks,no_header_body_checks
    -o smtpd_recipient_restrictions=permit_mynetworks,reject
    -o mynetworks=127.0.0.0/8
    -o smtpd_delay_reject=no
    -o smtpd_tls_security_level=may
    -o smtpd_authorized_xforward_hosts=127.0.0.0/8
Remember: use tabs to align master.cf columns. Reload Postfix after editing with a safe backup in place.
