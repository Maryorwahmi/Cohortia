Module 05 › Chapter 5.6 › Key Concepts
Amavisd-new
High-level interface between Postfix and content filters that returns delivery decisions to the MTA.
SpamAssassin
Content scoring engine; thresholds in amavisd.conf determine tagging, quarantine, or bounce behavior.
ClamAV
Open-source virus engine; keep definitions updated with freshclam and ensure socket paths match between clamd and amavisd.
Summary takeaway

A correctly configured pipeline prevents spam and malware, preserves server reputation, and reduces user incidents. Verify configuration, service order, and test with GTUBE/EICAR.
