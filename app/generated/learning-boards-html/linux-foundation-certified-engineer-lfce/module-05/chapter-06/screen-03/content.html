Module 05 › Chapter 5.6 › Objectives — Practice
Install & enable
Install amavisd-new, spamassassin, clamav, and the clamd daemon using your package manager. Enable the daemons to start now and on boot, and run freshclam to update definitions immediately.
Postfix handoff
Add content_filter pointing to amavisfeed at 127.0.0.1:10024 and add a master.cf listener on 127.0.0.1:10025 for returning scanned mail.
amavisd.conf checks
Confirm SpamAssassin threshold variables and the ClamAV clamd socket or TCP address match clamd configuration.
Test & verify
Use GTUBE for spam checks and an EICAR attachment for virus checks. Inspect amavisd and mail logs to confirm actions taken.
