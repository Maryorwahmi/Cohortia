Module 05 › Chapter 5.6 › Install
Commands (RHEL/CentOS)
sudo dnf install amavisd-new spamassassin clamav clamd -y
sudo systemctl enable --now amavisd
sudo systemctl enable --now spamassassin   # may be spamd on some systems
sudo systemctl enable --now clamd@scan
sudo freshclam
Verify the services are active. If freshclam reports errors, resolve networking or DNS before continuing. Confirm service names because they vary between distributions.
Verification checklist
  • systemctl status clamd@scan, amavisd, and spamassassin/spamd show active.
  • freshclam completes and updates virus definitions.
  • Server DNS resolution works for SpamAssassin network tests.
Pro tip
If your system uses a different clamd socket path, note it now; you will reference it when editing amavisd.conf.
