Process Flow
The reliable handoff requires two Postfix endpoints: the outbound content_filter target where Postfix sends unsifted mail to Amavisd-new, and a returning listener (127.0.0.1:10025) where scanned mail arrives for final delivery or further SMTP processing.
1. Postfix receives SMTP and sends to Amavisd-new via content_filter at 127.0.0.1:10024.
2. Amavisd-new invokes SpamAssassin and ClamAV; collects scores and findings.
3. Amavisd-new decides action (pass, quarantine, reject) and returns mail to Postfix on 127.0.0.1:10025.
4. Postfix performs final delivery using relaxed checks for the trusted source.
Common misconception
Amavisd-new is not a mail store. It scans and instructs Postfix; configure Postfix listeners correctly so mail is not bypassed or dropped.
