Module 05 › Chapter 5.6 › Troubleshooting
Checklist
  1. Are clamd, spamassassin, and amavisd active?
  2. Is content_filter present in main.cf?
  3. Is 127.0.0.1:10025 listener defined in master.cf?
  4. Do socket paths in amavisd.conf match clamd.conf?
  5. Are there socket permission errors in amavisd logs?
  6. Does DNS resolution work for SpamAssassin network checks?
Log commands
sudo journalctl -u amavisd --since "10 minutes ago"
tail -n 200 /var/log/maillog
sudo systemctl status clamd@scan spamassassin amavisd
If you see connection refused to clamd, check socket path and permissions; if mail bypasses filtering, check main.cf for content_filter.
