Module 05 › Chapter 5.6 › Service Management
Recommended restart order
  1. sudo systemctl restart clamd@scan
  2. sudo systemctl restart spamassassin (or spamd)
  3. sudo systemctl restart amavisd
  4. sudo systemctl reload postfix
Follow this sequence to ensure Amavisd-new finds both scanners and can initialize correctly.
Socket checks
Confirm clamd LocalSocket with a listing command and verify amavisd.conf references the same path. If you use TCP, use 127.0.0.1:3310 and ensure no firewall blocks localhost TCP connections.
Common log signs
  • Connection refused to clamd socket in amavisd logs — socket path mismatch or clamd not running.
  • SpamAssassin network tests failing — DNS resolution problem.
  • Mail bypassing filters — missing content_filter in Postfix main.cf.
