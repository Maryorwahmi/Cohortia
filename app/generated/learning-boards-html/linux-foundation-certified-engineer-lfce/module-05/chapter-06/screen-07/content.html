SpamAssassin thresholds
$sa_tag_level_temp = -999; # add spam info headers if spam score >= -999
$sa_tag_level_kill = 6.31; # treat as spam if score >= 6.31
$sa_quarantine_cutoff_level = 6.31; # quarantine if score >= 6.31
$sa_dsn_cutoff_level = 10; # bounce if score >= 10
Adjust these values to match your tolerance for false positives. Document any changes and notify user support if thresholds change.
ClamAV integration
['ClamAV-clamd',
  \&ask_daemon, ["CONTSCAN {}
", "/var/run/clamd.scan/clamd.sock"],
  qr/\bOK$/, qr/\bFOUND$/]
Confirm the socket path here matches clamd.conf LocalSocket, or use 127.0.0.1:3310 for TCP connections where appropriate.
$final_virus_lovers
Set to D_REJECT to reject infected mail, D_DISCARD to drop, or D_PASS to allow delivery with warnings.
Whitelist maps
Use @bypass_virus_checks_maps and @bypass_spam_checks_maps to whitelist trusted senders or internal systems.
Logging & errors
After edits, restart amavisd and check journalctl -u amavisd for socket or syntax problems.
