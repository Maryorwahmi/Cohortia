Module 6 › Chapter 5.8 › Postfix Logs
Process Flow

Subsystem mapping

  • postfix/smtpd — incoming SMTP sessions and command responses.
  • postfix/qmgr — queue manager, enqueue and handoffs to delivery agents.
  • postfix/smtp — outbound deliveries and remote SMTP responses.
  • postfix/local / postfix/pipe — local delivery and external delivery agents like dovecot-lda.
Commands & filters
sudo journalctl -u postfix -n 50
sudo journalctl -u postfix -f
sudo journalctl -u postfix | grep "reject" | less
sudo journalctl -u postfix | grep ""
Example
If you see a line with 'status=deferred' and a 450 response in postfix/smtp, the remote host returned a temporary error. Retry or investigate network/DNS reachability.
Common misconception
Treating all 'reject' entries as permanent. Check the numeric SMTP code (4xx vs 5xx) — 4xx is temporary and often resolves, 5xx is permanent and needs content or routing fixes.
Key Takeaway

Match the Postfix subsystem to the observed symptom and use queue IDs to correlate across logs and mailq output.
