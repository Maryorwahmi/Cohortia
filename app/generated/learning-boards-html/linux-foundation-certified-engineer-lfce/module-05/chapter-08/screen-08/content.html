Code Walkthrough

Queue and config commands

mailq
sudo postqueue -p
sudo postsuper -d ALL deferred     # careful: deletes deferred messages
sudo postqueue -f                   # force queue flush

postconf -n                         # show non-default parameters
postconf myhostname                 # show specific parameter
postconf -d                         # show defaults

sudo postlog -t mytest "This is a test log entry from postlog."
Use mailq to read the queue and pair queue IDs with journalctl lines. Use postconf -n to spot non-default routing or filtering settings introduced by administrators or automation.
Scenario
If many messages show 'Host not found', do not delete the queue immediately. First fix DNS or resolver, then run postqueue -f to retry deliveries.
Common mistake: running postsuper -d ALL deferred without preserving evidence. Capture logs and queue snapshots before destructive actions.
Key Takeaway

Postfix utilities let you inspect and act on the queue and configuration — pair them with logs before any destructive change.
