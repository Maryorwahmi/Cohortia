Module 6 › Chapter 5.8 › Hands-on Activity
Scenario

Simulate incorrect mydestination

Remove $mydomain from mydestination, reload Postfix, send a local email, and use logs and mailq to diagnose and fix.

Example edit
# /etc/postfix/main.cf
mydestination = $myhostname, localhost.$mydomain, localhost
# REMOVED: $mydomain
Verification commands
sudo systemctl reload postfix
echo "This email should fail local delivery." | mail -s "Troubleshooting Test" mailuser1@your_domain.com
sudo journalctl -u postfix -n 50 --no-pager
mailq
postconf -n
Fix
# Restore main.cf
mydestination = $myhostname, localhost.$mydomain, localhost, $mydomain
sudo systemctl reload postfix
# Resend test
echo "This email should now deliver successfully." | mail -s "Troubleshooting Fix Test" mailuser1@your_domain.com
sudo journalctl -u postfix | grep "status=sent"
Expected: first send appears in mailq with an error; after fix and reload, the message is delivered and logs show status=sent with delivery via dovecot-lda.
Key Takeaway

Controlled misconfigurations teach systematic diagnosis: reproduce, inspect logs and queue, apply a minimal fix, and verify the outcome.
