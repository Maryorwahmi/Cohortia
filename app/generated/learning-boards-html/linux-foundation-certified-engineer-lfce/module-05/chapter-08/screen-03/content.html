Practice Milestones

Complete the following applied tasks to demonstrate troubleshooting fluency.

05 Diagnose outgoing delivery
Resolve 'Host not found' by checking DNS resolution and network reachability.

Check /etc/resolv.conf, run dig for MX and A records, and confirm firewall rules permit outbound SMTP on port 25.

Verified Competency Milestone
06 Fix local delivery mishaps
Restore correct mydestination and verify mail reaches maildirs.

Use journalctl output and mailq to find bounce reasons, edit main.cf, reload Postfix, and re-test delivery.

Verified Competency Milestone
07 Check authentication failures
Diagnose Dovecot login errors and mailbox path or permission issues.

Search Dovecot logs for 'authentication failed' and verify user entries and plaintext-auth settings where necessary.

Verified Competency Milestone
08 Verify DNS & anti-abuse records
Confirm SPF, DKIM, and DMARC are present to improve deliverability.

These DNS records do not live in Postfix, but missing or incorrect entries often cause rejections or downstream mailbox filtering.

Verified Competency Milestone
