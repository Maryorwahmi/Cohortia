Definition

Logs and journalctl usage

Use journalctl filters and legacy maillog to isolate Postfix, Dovecot, and Amavisd events. Correlate queue IDs and timestamps.

Common commands
sudo journalctl -u postfix -n 50
sudo journalctl -u postfix -f
sudo journalctl -u dovecot -n 50
sudo journalctl -u amavisd -n 50
sudo tail -f /var/log/maillog
Example observation
If log shows status=deferred with host lookup errors, suspect DNS or resolver issues rather than mailbox problems.
Common mistake
Reading isolated errors without following the queue ID can mislead you about the true cause.
Practical tip

Correlate log lines to queue entries

  • Capture the Postfix queue ID from a log line and run mailq to match delivery attempts.
  • Use journalctl -u --since "10 minutes ago" to limit output to the incident window.
  • Follow logs live to reproduce a failure while you resend a test message.
Key takeaway
Key Takeaway

Logs show what the service tried; combine timestamps and queue IDs to reconstruct the message path.
