Module 6 › Chapter 5.8 › Key Concepts
journalctl
Query and follow systemd logs including Postfix and Dovecot units.
mailq / postqueue
Inspect queued messages and their delivery status reasons.
postconf -n
Show non-default Postfix configuration parameters for quick auditing.
telnet / openssl
Reproduce SMTP/IMAP sessions and TLS handshakes to see exact responses.
SPF / DKIM / DMARC
DNS records that affect deliverability and server reputation.
Open Relay / Blacklisting
Security risks and reputation impacts to monitor during troubleshooting.
Keep this checklist handy: journalctl for evidence, mailq for queue state, postconf for configuration checks, telnet/openssl to reproduce, and DNS/SPF/DKIM/DMARC to ensure deliverability.
