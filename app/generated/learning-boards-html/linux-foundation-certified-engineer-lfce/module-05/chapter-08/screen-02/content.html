Learning Objectives

Skill-based goals tied to troubleshooting workflows and verification milestones.

Bloom: Learn → Understand → Apply → Master
01 Identify mail logs
Locate Postfix, Dovecot, and Amavisd logs and why each is useful.

Knowing which file or journal unit to inspect reduces noise and speeds diagnosis. Matching log types to symptoms prevents chasing unrelated events.

Verified Competency Milestone
02 Use journalctl effectively
Filter mail units, follow in real-time, and search for error keywords.

Journalctl gives structured access to systemd logs; learning to combine unit filters and grep-like searches isolates relevant entries quickly.

Verified Competency Milestone
03 Inspect queue & config
Use mailq, postqueue, postsuper, and postconf to view queue and settings.

Queue inspection reveals delivery errors and transient conditions; configuration checks confirm intended routing and delivery behavior.

Verified Competency Milestone
04 Simulate client sessions
Use telnet and openssl s_client to reproduce SMTP/IMAP behavior and TLS negotiation.

Simulating the protocol is the quickest way to separate client misconfiguration from server-side failures and TLS certificate issues.

Verified Competency Milestone
