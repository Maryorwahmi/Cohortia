Module 6 › Chapter 5.8 › Amavisd-new & Filtering
Definition

Filtering visibility

Amavisd and scanning services log spam and virus detections; Postfix shows handoffs via content_filter and transports like 10025.

Commands
sudo journalctl -u amavisd -n 50
sudo journalctl -u amavisd | grep "SPAM"
sudo systemctl status spamassassin clamav-daemon amavisd
sudo freshclam
Troubleshooting steps
  1. Check amavisd logs for detection and transport handoff messages.
  2. Confirm content_filter entries in Postfix main.cf and master.cf for the proper port (often 10025).
  3. Ensure SpamAssassin and ClamAV are running and updated with freshclam.
Common misconception: blaming content rules first. Always verify inter-service connectivity and service status before altering filtering rules.
Key Takeaway

Filter failures are often service or handoff issues; logs show whether a message was scanned, tagged, or dropped.
