Safety and Verification Checklist
A compact checklist to validate connectivity, configuration, and authentication choices before you move to production.
Quick Tests
Start and enable Dovecot
sudo systemctl enable --now dovecot
sudo systemctl status dovecot
Firewall ports
sudo firewall-cmd --permanent --add-service=imap --add-service=imaps
sudo firewall-cmd --permanent --add-service=pop3 --add-service=pop3s
sudo firewall-cmd --reload
Connectivity checks
telnet your_mail_server_ip 143
# or
openssl s_client -connect your_mail_server_ip:993
Common Pitfalls
  • Wrong mail_location path prevents Dovecot from finding mail.
  • Not reloading Dovecot after edits means changes won't apply.
  • Firewall blocking IMAP/POP3 ports prevents client connections.
  • User accounts missing or passwords are incorrect for PAM auth.
