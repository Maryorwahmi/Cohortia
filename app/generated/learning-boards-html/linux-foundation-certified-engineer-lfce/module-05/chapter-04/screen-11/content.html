Open IMAP/POP3 ports in the firewall
Examples for firewalld and ufw to allow client access to Dovecot.
firewalld (RHEL/CentOS)
sudo firewall-cmd --permanent --add-service=imap --add-service=imaps
sudo firewall-cmd --permanent --add-service=pop3 --add-service=pop3s
sudo firewall-cmd --reload
ufw (Debian/Ubuntu)
sudo ufw allow 'IMAP'
sudo ufw allow 'IMAPS'
sudo ufw allow 'POP3'
sudo ufw allow 'POP3S'
sudo ufw reload
Why it matters

If ports are blocked, clients cannot reach Dovecot even if the service is running. Verify both host firewall and any external network security controls.
