Create a test user and verify IMAP connectivity
Practical steps to confirm client logins and mailbox creation.
Create user
sudo useradd -m testuser
sudo passwd testuser
# enter a strong password
Confirm the home directory and then attempt a client login.
Connectivity test
# Test IMAP
telnet localhost 143
# Type: a1 LOGIN testuser your_password
# Expect: a1 OK Logged in.
# Test IMAPS requires TLS
openssl s_client -connect localhost:993
Confirm

After a successful login, look for a Maildir in the user’s home directory: ls -la /home/testuser/ should show Maildir.
