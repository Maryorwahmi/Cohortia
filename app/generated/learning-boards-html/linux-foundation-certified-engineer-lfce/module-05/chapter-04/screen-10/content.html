Enable authentication with PAM
Edit 10-auth.conf to configure authentication; be careful with plaintext auth settings.
Example 10-auth.conf lines
# /etc/dovecot/conf.d/10-auth.conf
disable_plaintext_auth = no # For testing, but should be 'yes' with TLS
auth_mechanisms = plain login
!include auth-system.conf.ext
Practical notes
  • Plaintext auth is convenient for labs but insecure without TLS.
  • auth-system.conf.ext loads PAM-based authentication for system users.
  • Production should use disable_plaintext_auth = yes and TLS-enabled ports.
