Common mistakes and production notes
A practical checklist to avoid the issues that commonly block mail service deployment.
Checklist
  • Confirm mail_location syntax and path correctness.
  • Reload Dovecot after edits: sudo systemctl reload dovecot.
  • Open IMAP/POP3 ports and confirm external network rules.
  • Ensure user accounts exist for PAM authentication and have valid passwords.
Production considerations
Move from system users to virtual users or LDAP for scale, enforce TLS, and set disable_plaintext_auth to yes in production.
Quick commands
sudo systemctl reload dovecot
grep -E "mail_location|disable_plaintext_auth|auth_mechanisms" /etc/dovecot/conf.d/*
ls -la /home/username/
