Key Concepts
Three concise reminders you can apply immediately.
Dovecot = MDA + IMAP/POP3
Dovecot stores mail and serves it to MUAs while the MTA handles transport.
Prefer Maildir
One file per message reduces corruption and improves concurrency.
Secure auth & TLS
Use PAM for labs, but require TLS and disable plaintext auth in production; plan for virtual users/LDAP.
Summary

These three concepts guide installation, configuration, and secure operation of Dovecot for client mail access.
