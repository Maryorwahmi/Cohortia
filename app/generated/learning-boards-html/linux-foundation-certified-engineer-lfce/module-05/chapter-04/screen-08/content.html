Mail storage: mbox versus Maildir
Understand the storage formats and why Maildir is usually better for servers handling multiple clients.
mbox
Stores all messages in a single file. Simpler but prone to corruption and poor concurrent performance for large mailboxes.
Maildir
Stores each message as a file in ~/Maildir/new, ~/Maildir/cur, and ~/Maildir/tmp. More robust and recommended for modern servers.
Example

Set mail_location = maildir:~/Maildir so Dovecot creates and uses per-user Maildir directories under their home folders.

Pitfall

Pointing mail_location to the wrong format or path prevents Dovecot from finding mail and causes client failures.
