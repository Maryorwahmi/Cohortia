Configure Maildir in 10-mail.conf
A single setting that ensures Dovecot uses Maildir storage under each user's home.
Edit file
# /etc/dovecot/conf.d/10-mail.conf
mail_location = maildir:~/Maildir
Save the file and then reload Dovecot so the change takes effect: sudo systemctl reload dovecot
Checks
  • grep -E "mail_location" /etc/dovecot/conf.d/*
  • ls -la /home/username/ to see Maildir
  • Ensure Dovecot can write to the home directory
