Core Concept › Dovecot LDA
What the LDA does
The LDA writes incoming messages into Maildir or a virtual mailbox path using Dovecot configuration.
Responsibilities
  • Resolve the user's mail_location from Dovecot configuration.
  • Create a new message file in Maildir/new with appropriate metadata.
  • Preserve sender and delivery flags when invoked with the right arguments.
  • Handle virtual mailbox paths for non-system users when configured.
Analogy
Think of the LDA as the mail carrier who puts letters into the correct mailbox — the MTA hands them to the carrier.
Common mistake
Pointing Postfix at a non-existent or wrong-path binary leads to delivery failures.
Example LDA configuration
# /etc/dovecot/conf.d/15-lda.conf
protocol lda {
  # For system users: maildir:~/Maildir
  # For virtual users: mail_location = maildir:/var/vmail/%d/%n/Maildir
  # user = vmail
}
Check
Confirm the LDA binary exists and Dovecot's mail_location matches how you want to store mail.
Key Takeaway

The LDA must align with Dovecot's mail_location; mismatch or missing binary is a primary cause of delivery failure.
