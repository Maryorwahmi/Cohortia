Assessment › Diagnose Delivery Failure
Scenario
Postfix accepts mail but Maildir remains empty; logs show user-related errors.
Stepwise diagnosis
  1. Check mailbox_command in main.cf for correct path and args.
  2. Inspect /var/log/maillog or journalctl -u postfix for dovecot delivery lines.
  3. Verify Dovecot LDA configuration and mail_location.
  4. Confirm mailbox ownership and permissions.
Correct answer rationale
The mailbox_command parameter instructs Postfix to use an external program, and if it is missing or wrong Postfix will not hand mail to Dovecot’s LDA. That leads to mismatches between what Postfix does and where Dovecot expects mail.
Misconception
Other parameters like mynetworks or inet_interfaces control network and listener behavior but not the MTA→MDA handoff.
Key Takeaway

When delivery fails while Postfix accepts mail, mailbox_command is the primary Postfix setting to verify; follow logs and mailbox checks to confirm.
