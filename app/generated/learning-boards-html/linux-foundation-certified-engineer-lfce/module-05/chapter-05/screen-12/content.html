Hands-on Activity › Integrate Postfix & Dovecot
Step-by-step checklist
  1. Verify /etc/dovecot/conf.d/15-lda.conf and mail_location.
  2. Set mailbox_command in /etc/postfix/main.cf to the correct binary.
  3. Ensure your domain is in mydestination and reload Postfix.
  4. Send a test message and check Maildir/new for the new file.
  5. For aliases, edit /etc/postfix/virtual, run sudo postmap /etc/postfix/virtual, and reload Postfix.
Verification & expected checks
  • Maildir contains a new file: ls -la /home/mailuser1/Maildir/new/.
  • Postfix logs show delivery via dovecot-lda: look for "delivered via dovecot-lda" lines.
  • For aliased mail, confirm forwarding targets receive messages after postmap and reload.
Note
If multiple issues appear, fix the path and permissions first, then address mapping errors.
Key Takeaway

Follow the checklist in order: LDA config, mailbox_command, reload, test, and then alias mapping with postmap to ensure clean integration.
