Process › virtual_alias_maps
Alias file and postmap
# /etc/postfix/main.cf
virtual_alias_maps = hash:/etc/postfix/virtual

# /etc/postfix/virtual
info@your_domain.com mailuser1
sales@your_domain.com external_email@another.com
  • After editing: sudo postmap /etc/postfix/virtual
  • Then: sudo systemctl reload postfix
  • Postfix consults the hashed DB at delivery time to expand aliases.
Architecture note
On receipt, Postfix looks up the recipient in virtual_alias_maps; if an alias is found it rewrites the envelope recipient and routes accordingly.
Misconception
Editing the text file alone is not enough. You must run postmap to create the hashed DB that Postfix uses.
Key Takeaway

virtual_alias_maps plus postmap is the correct workflow for managing aliases and forwarding in Postfix.
