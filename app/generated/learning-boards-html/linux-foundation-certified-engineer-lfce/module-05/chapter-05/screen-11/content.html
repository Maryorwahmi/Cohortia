Troubleshooting › Common mistakes
Issue → How to check → Fix
Incorrect mailbox_command path
Check with: which dovecot-lda. Fix main.cf and reload Postfix.
Permission problems
Check Maildir ownership and modes: ls -la /home/mailuser/Maildir. Fix ownership and permissions so LDA can write.
mydestination missing domain
Check main.cf. If Postfix doesn't consider the domain local, mailbox_command won't be invoked. Add domain to mydestination.
Dovecot LDA disabled or misconfigured
Inspect /etc/dovecot/conf.d/15-lda.conf and ensure mail_location lines are correct for system or virtual users.
Log indicators and commands
  • Postfix delivery entries: look for "status=sent (delivered via dovecot-lda)".
  • Unknown user errors suggest a mismatch between Postfix and Dovecot user lookup.
  • Use journalctl -u postfix -n 50 or tail of maillog to get recent hints.
Practical tip
Reproduce the error with a test message and capture logs immediately after to see the precise failure mode before changing config widely.
Key Takeaway

Check binary paths, permissions, domain settings, and Dovecot LDA configuration in that order to quickly resolve delivery issues.
