main.cf (Postfix)
# /etc/postfix/main.cf
mailbox_command = /usr/lib/dovecot/deliver -c /etc/dovecot/dovecot.conf -d $USER
mydestination = $myhostname, localhost.$mydomain, localhost, $mydomain
Confirm the exact path and flags for your distribution, then reload Postfix and run a delivery test.
Sanity check
Run which dovecot-lda or which deliver to confirm the executable path.
Permissions
Ensure the Postfix process can execute the LDA and the LDA user can write to the mailbox dirs.
If you see errors
Check both Postfix and Dovecot logs for failures before changing configuration further.
