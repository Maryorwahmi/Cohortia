Comparison › System vs Virtual Users
System Users
Maildir in user home directories. Easier to set up for a handful of accounts.
  • Uses system account names; $USER works for mailbox_command.
  • Simpler authentication if accounts already exist on the system.
  • Less flexible for hosting many domains.
When to use
Small teams, single domain, or when system accounts are already managed centrally.
Virtual Users
Separate mapping from system accounts, suitable for many domains and mailboxes.
  • Requires virtual_mailbox_maps and userdb/passdb in Dovecot.
  • Mail stored under centralized path like /var/vmail/%d/%n/Maildir.
  • Scales without creating system users.
When to use
Multi-domain hosting, service providers, or when you want a dedicated mail owner user.
Key Takeaway

Pick system users for simplicity and virtual users for scale; ensure Postfix and Dovecot mappings match your choice to avoid delivery errors.
