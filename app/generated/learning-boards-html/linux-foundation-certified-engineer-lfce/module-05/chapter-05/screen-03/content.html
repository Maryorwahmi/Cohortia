Module 5 › Chapter 5.5 › Learning Objectives
Tasks & Verification
Check LDA
Open /etc/dovecot/conf.d/15-lda.conf, confirm protocol lda is enabled and mail_location is correct for system or virtual users.
Set mailbox_command
Edit /etc/postfix/main.cf to point mailbox_command at dovecot-lda or deliver with proper flags for sender and recipient.
Alias workflow
Create /etc/postfix/virtual, run postmap, reload Postfix, and test forwarding to local or external recipients.
Verification
Find a new file in Maildir/new and check Postfix logs for delivery via dovecot-lda.
Common failure
If Postfix reports unknown user or delivery errors, check mailbox_command, paths, permissions, and Dovecot status.
