Verification › Testing Local Delivery
Run these steps
  1. Reload Postfix: sudo systemctl reload postfix
  2. Send a test message from the host: echo "This is a test message for local delivery." | mail -s "Local Delivery Test" mailuser1@your_domain.com
  3. Check Maildir contents: ls -la /home/mailuser1/Maildir/new/
  4. Inspect Postfix logs for delivery: check /var/log/maillog or journalctl -u postfix for "delivered via dovecot" lines.
Example output
You should see a new file in Maildir/new and a Postfix log entry indicating delivery via dovecot-lda or deliver.
Troubleshooting checklist
If Maildir is empty
Confirm mailbox_command path and arguments. Check permissions on the Maildir and parent directories.
If logs show unknown user
Verify Postfix user lookup: is the recipient a system user or must you configure virtual mailboxes and userdb/passdb in Dovecot?
Common mistake
Testing from an external MUA without checking Maildir can mask delivery failures; always verify the file and logs.
Key Takeaway

Use a quick send-and-check loop: send a message, look for Maildir/new, then read logs to confirm dovecot-lda delivery.
