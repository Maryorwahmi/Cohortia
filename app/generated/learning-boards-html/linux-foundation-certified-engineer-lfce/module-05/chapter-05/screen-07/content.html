Definition › Virtual Users & Mailboxes
What is a virtual user?
A mail identity that does not require a corresponding system account; mailboxes stored in a separate vmail hierarchy.
Example path
mail_location = maildir:/var/vmail/%d/%n/Maildir resolves domain and user into a directory.
  • Postfix uses virtual_mailbox_maps and virtual_mailbox_domains to map recipients to mailboxes.
  • Dovecot needs userdb/passdb entries or an SQL/LDAP lookup for virtual users.
  • Files are often owned by a dedicated mail user such as vmail to centralize permissions.
Migration note
When moving from system to virtual users, update Postfix maps and Dovecot userdb so delivery paths change without breaking client access.
Common mistake
Forgetting to align Postfix virtual maps with Dovecot userdb results in unknown user or permission errors.
Practical tip
Use a single mail owner UID/GID for virtual maildirs and ensure both Postfix and Dovecot can access them.
Key Takeaway

Virtual users allow hosting many domains without system accounts but require explicit mapping in both Postfix and Dovecot.
