Process Flow › Configure mailbox_command
Edit /etc/postfix/main.cf
Add or replace mailbox_command and confirm mydestination lists local domains so Postfix invokes the LDA.
# /etc/postfix/main.cf
# Set the command for local mail delivery
mailbox_command = /usr/lib/dovecot/deliver -c /etc/dovecot/dovecot.conf -d $USER

# Ensure Postfix knows which domains are local
mydestination = $myhostname, localhost.$mydomain, localhost, $mydomain
  • Find the correct path with which dovecot-lda or which deliver.
  • Use the binary and flags appropriate for your distro; examples vary.
  • Reload Postfix after edits: sudo systemctl reload postfix.
Checklist & Examples
Example (RHEL/CentOS)
mailbox_command = /usr/libexec/dovecot/dovecot-lda -f "\"$SENDER\"" -a "\"$RECIPIENT\""
Misconception
Setting mailbox_command is necessary but not sufficient—Postfix must also treat the domain as local via mydestination.
Pro Tip
Test the binary directly as the postfix user to confirm it runs and can write to the Maildir location.
Key Takeaway

A correct mailbox_command path and a proper mydestination setting ensure Postfix invokes Dovecot’s LDA for local delivery.
