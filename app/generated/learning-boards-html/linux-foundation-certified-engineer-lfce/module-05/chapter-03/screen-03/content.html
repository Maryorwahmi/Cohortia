Module 5 › Chapter 5.3 › Learning Objectives
Permission Checks
Private key: chmod 600; public cert: chmod 644. Ownership by root or root:postfix so Postfix can read the key.
Configuration Paths
Set smtpd_tls_cert_file and smtpd_tls_key_file to point to /etc/postfix/certs/postfix.crt and .key.
Validation Steps
Use postconf -n, sudo systemctl reload postfix, and openssl s_client -starttls smtp to verify operation.
Why these matter
A permission error prevents Postfix from loading a private key and leads to immediate TLS failures; mismatched CNs cause remote rejections; missing reloads mean settings are not applied.
