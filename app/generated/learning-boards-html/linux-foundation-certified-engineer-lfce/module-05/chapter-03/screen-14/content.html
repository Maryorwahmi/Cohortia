Module 5 › Chapter 5.3 › Key Concepts
TLS Encrypts Transport
Protects messages and credentials during transit between clients and servers.
Protect Private Key
Use restrictive permissions; Postfix must be able to access the key, but it must not be world-readable.
CN Must Match myhostname
A hostname mismatch will cause certificate warnings or rejections from peers.
Summary takeaway

Enable TLS, secure keys, match hostnames, pick an appropriate TLS policy, and validate with openssl s_client to ensure your Postfix instance encrypts SMTP reliably.
