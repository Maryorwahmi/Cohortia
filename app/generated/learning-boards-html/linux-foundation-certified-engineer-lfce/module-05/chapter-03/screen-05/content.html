Module 5 › Chapter 5.3 › Generate a Self-Signed Certificate
Step-by-step
  1. 1) Create cert directory and secure it with chmod 700.
  2. 2) Run openssl req to produce a 2048-bit RSA key and certificate valid for 365 days.
  3. 3) Enter the server FQDN as the Common Name when prompted.
  4. 4) Set file permissions and ownership so Postfix can access the key safely.
Example command
sudo mkdir -p /etc/postfix/certs
sudo chmod 700 /etc/postfix/certs/
sudo openssl req -x509 -nodes -days 365 -newkey rsa:2048 \
  -keyout /etc/postfix/certs/postfix.key \
  -out /etc/postfix/certs/postfix.crt
Permissions checklist
  • • Private key: chmod 600 so only root/postfix can read it.
  • • Certificate: chmod 644 so it can be read by services and peers.
  • • chown root:root or root:postfix depending on your distribution.
Pitfall
If you enter the wrong Common Name the certificate will not match Postfix's myhostname and remote systems may reject the TLS handshake.
