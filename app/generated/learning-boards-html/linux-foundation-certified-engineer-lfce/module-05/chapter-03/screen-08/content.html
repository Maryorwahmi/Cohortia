Module 5 › Chapter 5.3 › Reloading Postfix and Verifying Configuration
Apply changes
Reload Postfix to apply new TLS settings without downtime.
sudo systemctl reload postfix
# Verify active non-default settings
postconf -n | grep -i tls
Validation steps
  • • Confirm smtpd_tls_cert_file and key file paths match files you created.
  • • Inspect /var/log/syslog or journald for TLS-related errors after reload.
  • • Ensure firewall allows SMTP ports before attempting remote tests.
Quick test
From another machine run openssl s_client -connect mail.your_domain.com:25 -starttls smtp to see the TLS handshake and certificate details.
