Module 5 › Chapter 5.3 › Common TLS Issues and How to Fix Them
Permissions
Fix with chmod/chown so Postfix can read the private key; check for 'Permission denied' in logs.
Hostname mismatch
Regenerate the certificate with CN matching Postfix myhostname to avoid client rejections.
Network
Ensure firewall allows SMTP ports. A blocked port prevents remote TLS validation even when Postfix is configured correctly.
Diagnostic commands
postconf -n sudo systemctl reload postfix journalctl -u postfix -n 200 openssl s_client -connect mail.example.com:25 -starttls smtp
