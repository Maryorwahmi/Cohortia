Module 5 › Chapter 5.3 › Secure File Permissions for Keys
Recommended commands
sudo chmod 600 /etc/postfix/certs/postfix.key
sudo chmod 644 /etc/postfix/certs/postfix.crt
sudo chown root:root /etc/postfix/certs/postfix.key /etc/postfix/certs/postfix.crt
ls -l /etc/postfix/certs/
Operational note
If Postfix runs as the postfix user and requires group access, use chown root:postfix then chmod 640 to grant group read only to postfix.
Common error
Permission denied errors while reading the key indicate Postfix cannot access the file; adjust ownership or mode rather than changing TLS security levels.
Key Takeaway
Secure the private key with restrictive modes while ensuring the Postfix process can read it; misconfigured permissions are a leading cause of TLS failures.
