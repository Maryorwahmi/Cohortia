Module 5 › Chapter 5.3 › Test TLS with openssl s_client
Run the test
openssl s_client -connect mail.example.com:25 -starttls smtp
Look for certificate details, negotiated cipher suite, and a line like Verify return code: 0 (ok) to confirm a trusted chain.
Interpreting failures
  • • Hostname mismatch: certificate CN must match Postfix myhostname.
  • • Permission denied: Postfix cannot read the private key.
  • • Trust failure: self-signed certs require local trust to show Verify return code 0.
Practical tip
Use a remote host to test; testing from the same host may hide firewall or network path issues that external peers would encounter.
