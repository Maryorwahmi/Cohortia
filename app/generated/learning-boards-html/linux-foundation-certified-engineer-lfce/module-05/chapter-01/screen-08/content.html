Module 5 › Chapter 5.1 › Important Postfix Params
Parameter
myhostname — internet hostname for this mail system. Should be FQDN that resolves.
mydomain — the local internet domain name for mail delivery context.
inet_interfaces — which network interfaces Postfix listens on; default is all but restrict if needed.
mydestination — domains considered local for delivery; mail to these domains is delivered locally.
Example edit
# /etc/postfix/main.cf (partial)
myhostname = mail.example.com
mydomain = example.com
inet_interfaces = all
mydestination = $myhostname, localhost.$mydomain, $mydomain
After saving, reload Postfix and run postconf -n to confirm values are applied.
Key Takeaway

Set these parameters deliberately and verify with postconf -n; incorrect hostnames or destinations are frequent causes of delivery problems.
