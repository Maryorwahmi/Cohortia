Quick commands
sudo postconf -n > ~/postfix_initial_config.txt
cat ~/postfix_initial_config.txt
# Edit main.cf if necessary
sudo systemctl reload postfix
Save the postconf -n output so you can record baseline configuration and detect unintended changes later.
Checklist
  • myhostname is a resolvable FQDN.
  • mydomain matches your mail domain.
  • inet_interfaces is intentionally set.
  • mydestination lists only local domains.
Pro tip

Keep a copy of postconf -n output after initial deployment to speed up future audits and troubleshooting.
