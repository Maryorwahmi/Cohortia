Module 5 › Chapter 5.1 › Security Considerations
Risks & Controls
  • Open Relay: Ensure relay is restricted to trusted clients and authenticated submissions.
  • Ports: Expose only required ports (25, 587, 465 as needed) and lock them down with a firewall.
  • Least Privilege: Keep components isolated and run with minimal privileges.
  • Updates: Apply OS and Postfix updates promptly to reduce vulnerability windows.
Concrete action
Inspect mynetworks and submission settings; add firewall rules that only allow necessary inbound SMTP from expected sources.
Common mistake
Leaving inet_interfaces set to all and not restricting relaying can expose you to abuse immediately after installation.
Key Takeaway

Treat mail servers as high-visibility infrastructure. Start with restrictive defaults, verify relay control, and open only the ports you need.
