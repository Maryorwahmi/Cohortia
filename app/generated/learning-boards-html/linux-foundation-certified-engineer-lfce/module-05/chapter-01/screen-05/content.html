Module 5 › Chapter 5.1 › Message Flow & DNS
Claim

MX and hostname resolution are critical

  • Why: MTAs use MX records to locate recipient servers and rely on hostname resolution to open connections.
  • Example: If mail.example.com is not resolvable, sending MTAs cannot connect and will queue the message for retry.
  • Misconception: Don’t assume local hostnames are sufficient for internet delivery.
Quick check
Use DNS tools to confirm MX and A records point to your mail host before expecting delivery.
Annotated example
Trace of a delivery attempt:
  1. Local MUA submits mail to local MTA.
  2. MTA queries DNS for recipient MX record.
  3. If MX exists, MTA resolves MX hostname to IP and connects to port 25.
  4. On connection, SMTP transaction proceeds; on failure, message is queued and retried.
# Example DNS check (conceptual)
dig MX example.com
# Expect an MX record that points to a resolvable hostname
Key Takeaway

Always confirm MX and hostname resolution before blaming Postfix. DNS issues are a frequent root cause of delivery failures.
