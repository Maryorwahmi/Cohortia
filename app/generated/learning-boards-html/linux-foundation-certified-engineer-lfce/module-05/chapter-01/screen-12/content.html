Module 5 › Chapter 5.1 › Activity
Steps
  1. Install Postfix using the system package manager.
  2. Choose "Internet Site" and set the mail name when prompted.
  3. Enable and start Postfix, then check service status.
  4. Run postconf -n and save the output for review.
  5. Edit main.cf for hostname and domain, then reload Postfix.
  6. Verify DNS MX records for your domain before testing mail delivery.
Commands (review)
# Red Hat example
sudo dnf install postfix -y
sudo systemctl enable --now postfix
sudo systemctl status postfix
postconf -n > ~/postfix_initial_config.txt
sudo systemctl reload postfix

# Debian example
sudo apt update && sudo apt install postfix -y
Key Takeaway

Follow a consistent install-verify-edit-reload cycle and verify DNS before expecting mail to flow to or from your server.
