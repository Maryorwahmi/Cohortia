Sample questions
Question 1
Which parameter controls which domains are considered local for delivery?
Answer: mydestination
Question 2
Which command shows only explicitly set Postfix parameters?
Answer: postconf -n
Walk through these questions in a lab environment by changing one parameter, reloading Postfix, running postconf -n, and observing the effect. This practical loop builds confidence diagnosing real-world issues.
Key Takeaway

Assessment questions should map directly to the commands and parameters you will use in the field: postconf -n, systemctl status, and mydestination checks.
