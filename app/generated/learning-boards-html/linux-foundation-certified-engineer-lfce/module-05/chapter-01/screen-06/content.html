Module 5 › Chapter 5.1 › Postfix Installation
Commands
Use the platform package manager, then ensure the service runs and is enabled on boot. 
# Red Hat-family
sudo dnf install postfix -y
sudo systemctl enable --now postfix
sudo systemctl status postfix

# Debian-family
sudo apt update && sudo apt install postfix -y
sudo systemctl enable --now postfix
sudo systemctl status postfix
Example
After install, a quick status check confirms the service is active. If not, start and enable it so it persists across reboots.
Verification Steps
  1. Confirm package installed and files present.
  2. Ensure systemctl shows active (running).
  3. Run postconf -n to see explicit settings.
  4. Validate hostname and MX DNS records externally.
Key Takeaway

Installation is only the first step. Always enable, start, and verify the service, and then inspect the active configuration.
