systemctl status postfix
sudo systemctl status postfix
# Look for: Active: active (running)
# Look at recent logs for startup errors
Use this command to confirm the service started and to find recent journal entries if Postfix fails during startup.
postconf -n
postconf -n
# Shows only non-default settings from /etc/postfix/main.cf
# Example lines: myhostname = mail.example.com
This command is your quickest audit of active configuration changes. If you edited main.cf, confirm those edits appear here.
Concrete workflow
  1. Install and enable Postfix.
  2. Run systemctl status postfix and check Active state.
  3. Run postconf -n and confirm myhostname, mydomain, inet_interfaces, mydestination.
  4. If edits required, update /etc/postfix/main.cf and reload with systemctl reload postfix.
Key Takeaway

Use systemctl for service health and postconf -n to audit what Postfix is actually using from main.cf.
