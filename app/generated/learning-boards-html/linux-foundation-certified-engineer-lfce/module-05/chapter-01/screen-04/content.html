Definition

MTA, MDA, MUA explained

  • MTA: Routes and queues messages; consults MX DNS; retries on failure.
  • MDA: Accepts mail from MTA and deposits it in user mailboxes; may filter or sort mail.
  • MUA: End-user client for composing and reading mail via submission and retrieval protocols.
Concrete example
Alice composes mail in a desktop client (MUA); Postfix (MTA) routes it to recipient MTA; Dovecot (MDA) delivers to the local mailbox.
Common misconception
Do not assume one program must handle all roles. Separation helps security and troubleshooting.
