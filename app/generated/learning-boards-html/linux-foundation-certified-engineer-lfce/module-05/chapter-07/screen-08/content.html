Module 5 › Chapter 5.7 › Dovecot passdb & userdb
Configuration

Authenticate and locate virtual mailboxes

Use a passwd-file passdb and a static userdb that returns vmail UID/GID and mail_location templates.

auth-passwdfile.conf.ext
passdb {
  driver = passwd-file
  args = /etc/dovecot/users.db
}
userdb {
  driver = static
  args = uid=vmail gid=vmail home=/var/vmail/%d/%n mail_location=maildir:/var/vmail/%d/%n/Maildir
}
Security note

Keep /etc/dovecot/users.db readable only by root (chmod 600) to protect plaintext or hashed credentials.

Key Takeaway

A passwd-file for auth and a static userdb pointing to /var/vmail let Dovecot serve virtual users without system accounts.

Example users.db
# /etc/dovecot/users.db
user1@your_virtual_domain.com:{PLAIN}your_password_here
user2@your_virtual_domain.com:{PLAIN}another_password
Verify

Reload Dovecot and test authentication with doveadm auth test user1@your_virtual_domain.com password or with an IMAP client.
