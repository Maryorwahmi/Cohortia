Advanced Mail Server Features

Aliases, virtual domains, virtual mailboxes, LMTP integration, and Dovecot quotas for scalable mail services.

In this lesson
Set aliases, map virtual addresses, configure vmail layout, and enable quotas.
Coming up
LMTP handoff to Dovecot and mailbox permission best practices.
Hands-on
Create /etc/postfix/virtual, run postmap, and enable quota plugin in Dovecot.
Concept map
Aliases
/etc/aliases & newaliases for system addresses
Virtual Domains
virtual_alias_maps & virtual_mailbox_domains
Quotas
Dovecot quota plugin to limit mailbox storage
Quick Commands
sudo newaliases
sudo postmap /etc/postfix/virtual
sudo systemctl reload postfix
sudo systemctl reload dovecot
Why this matters

Correct aliasing and mailbox layout avoid lost mail, enable multi-domain hosting, and prevent disk exhaustion through quotas.

Explore Key Topics
Aliases
Use /etc/aliases + newaliases for system addresses like root and postmaster.
Virtual Maps
virtual_alias_maps route addresses for domains you host without system accounts.
Quotas
Dovecot quotas enforce per-user storage limits and must be enabled as a plugin.
