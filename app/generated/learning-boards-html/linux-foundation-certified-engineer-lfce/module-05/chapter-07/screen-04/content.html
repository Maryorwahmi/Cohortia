Module 5 › Chapter 5.7 › System-wide Aliases
Definition

/etc/aliases format and use

Map local alias names to one or more recipients so system mail is forwarded to monitored accounts.

Example /etc/aliases
# /etc/aliases
postmaster: root
root: sysadmin@your_domain.com
abuse: sysadmin@your_domain.com, security_team@your_domain.com
sales: john.doe@your_domain.com, jane.smith@your_domain.com
Command
sudo newaliases
sudo systemctl reload postfix
Common mistake
Editing /etc/aliases but not running newaliases means Postfix will not see your changes.
Key Takeaway

/etc/aliases is for system-level forwards; run newaliases after edits and verify with a test email.

Analogy

Think of /etc/aliases as a local receptionist directory that forwards internal mail to proper individuals.

Check

After newaliases, send a test email to verify the alias resolves to the expected external address.

Pro Tip

Use a single monitoring mailbox for admin aliases so on-call shifts can be rotated without changing aliases.
