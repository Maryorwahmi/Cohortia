Module 5 › Chapter 5.7 › Postfix lookup tables
Definition

Use postmap to update binary lookup tables

Text map files must be compiled by postmap for Postfix to use them at delivery time.

Commands
sudo postmap /etc/postfix/virtual
sudo postmap /etc/postfix/vmailboxes
sudo systemctl reload postfix
postconf -n
Troubleshooting note

If a mapping is not applied, confirm the map file has a .db file next to it and that Postfix was reloaded after postmap.

Key Takeaway

Always run postmap on map files and check postconf -n to verify that Postfix sees your domain and map settings.

Example check

Use postmap -q 'info@example.net' /etc/postfix/virtual to query a specific mapping during debugging.

Pro Tip

Keep a small set of well-documented map files and automate postmap in deployment scripts to avoid stale databases.
