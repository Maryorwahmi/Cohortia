Practical Verification

Small checks prevent large outages — learn the commands and checks you need.

Learn → Understand → Apply → Master
Alias verification

After editing /etc/aliases run newaliases, reload Postfix, and send a test message to confirm forwarding to the intended mailbox.

Map verification

After updating /etc/postfix/virtual or vmailboxes run postmap and reload Postfix; use postmap -q to query mappings during troubleshooting.

Permissions check

Ensure /var/vmail is owned by vmail:vmail and that virtual_minimum_uid matches your vmail user to avoid delivery permission errors.

Quota verification

Enable quota plugins in IMAP/POP3 blocks and check with an IMAP client or doveadm quota get to ensure Dovecot reports limits.
