Module 5 › Chapter 5.7 › Aliases vs Virtual Domains
Comparison

When to use each mapping

/etc/aliases
System-level forwards for root, postmaster, and administrative aliases. Requires newaliases.
virtual_alias_maps
Redirects for domain addresses without creating storage. Use postmap after editing the file.
virtual_mailbox_domains
Hosts real mailboxes under /var/vmail, requires Dovecot auth and mailbox access.
Concrete Example

Forward webmaster to root using /etc/aliases. Redirect info@marketing.example to an internal mailbox using virtual_alias_maps. Host user1@customer.com as a real mailbox under /var/vmail with virtual_mailbox_maps and Dovecot auth.

Misconception

Attempting to store mail via virtual_alias_maps will fail — the map only redirects, it does not create mail storage for virtual users.

Key Takeaway

Pick the correct mapping tool and test deliverability after making changes to avoid surprising mail routing behavior.
