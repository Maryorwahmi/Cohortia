Module 5 › Chapter 5.7 › Virtual Alias Domains and Maps
Process

Create and enable virtual alias maps

Declare virtual_alias_domains and point virtual_alias_maps to a hash:/etc/postfix/virtual lookup table.

main.cf snippet
# /etc/postfix/main.cf
virtual_alias_domains = your_virtual_domain.com another_virtual_domain.org
virtual_alias_maps = hash:/etc/postfix/virtual
Commands
sudo postmap /etc/postfix/virtual
sudo systemctl reload postfix
Key Takeaway

virtual_alias_maps are your central redirect table for hosted domains; always run postmap after editing the file.

Example /etc/postfix/virtual
# /etc/postfix/virtual
info@your_virtual_domain.com    john.doe@your_domain.com, jane.smith@your_domain.com
support@your_virtual_domain.com helpdesk@external.com
sales@your_virtual_domain.com   sales_team_list@your_domain.com

# another domain
admin@another_virtual_domain.org root
webmaster@another_virtual_domain.org web_dev_team@your_domain.com
Misconception

Do not use /etc/aliases when you manage many domain-scoped addresses; virtual_alias_maps scales better for multi-domain redirects.

Check

Use postmap -q address /etc/postfix/virtual to query a single entry during troubleshooting, then reload Postfix.
