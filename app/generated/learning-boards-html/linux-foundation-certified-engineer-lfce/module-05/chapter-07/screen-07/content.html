Module 5 › Chapter 5.7 › vmail User and Mailbox Layout
Procedure

Create vmail user and prepare /var/vmail

Create a dedicated group and user, create the mailbox base, and set ownership so Dovecot and Postfix can access maildirs.

Commands
sudo groupadd -g 5000 vmail
sudo useradd -u 5000 -g vmail -s /sbin/nologin -d /var/vmail vmail
sudo mkdir -p /var/vmail
sudo chown -R vmail:vmail /var/vmail
Pitfall

If /var/vmail is owned by root or a conflicting UID exists, Dovecot or LMTP delivery may fail with permission denied errors.

Key Takeaway

Use a dedicated vmail user with a recorded UID/GID and secure ownership on /var/vmail for safe virtual mailbox hosting.

Analogy

Think of vmail as a locked mailroom key assigned to a non-login account used only for mailbox storage.

Check

Verify ownership with ls -ld /var/vmail and ensure UID 5000 matches your Postfix virtual_minimum_uid setting.
