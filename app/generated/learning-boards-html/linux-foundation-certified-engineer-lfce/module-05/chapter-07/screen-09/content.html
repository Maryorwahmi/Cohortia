Module 5 › Chapter 5.7 › LMTP Delivery & virtual_transport
Delivery

Configure Postfix to hand off to Dovecot via LMTP

Set virtual_transport in Postfix and ensure Dovecot's LMTP listener is available with correct permissions.

main.cf transport
virtual_transport = lmtp:unix:private/dovecot-lmpa
dovecot 10-master.conf
service lmtp {
  unix_listener /var/spool/postfix/private/dovecot-lmpa {
    mode = 0666
  }
}
Misconfiguration

If the socket path or permissions are wrong, Postfix cannot reach Dovecot and deliveries will queue or bounce.

Key Takeaway

Match Postfix's virtual_transport to Dovecot's LMTP listener and verify socket access to enable smooth local delivery.

Performance note

LMTP is optimized for local single-recipient transfers; it reduces overhead compared to SMTP for local handoff.

Check

Use journalctl or mail.log to watch for delivery failures referencing the socket path if Postfix cannot connect to LMTP.
