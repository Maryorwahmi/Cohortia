Learning Objectives

A focused skill list for configuring aliases, virtual domains, and quotas.

Learn → Understand → Apply → Master
01
Configure /etc/aliases

Edit /etc/aliases to forward system addresses and run newaliases so Postfix loads changes. This ensures root and postmaster mail is monitored.

VERIFIED COMPETENCY MILESTONE
02
Implement virtual_alias_maps

Define virtual_alias_domains and virtual_alias_maps, create /etc/postfix/virtual, run postmap, and reload Postfix to centralize multi-domain redirects.

VERIFIED COMPETENCY MILESTONE
03
Host virtual mailbox domains

Configure virtual_mailbox_domains, virtual_mailbox_maps, and a virtual_mailbox_base so Postfix can accept mail for hosted domains without OS users.

VERIFIED COMPETENCY MILESTONE
04
Enable and verify Dovecot quotas

Enable the quota plugin for IMAP/POP3 and set storage limits so mail users cannot exceed disk allocations. Verify with an IMAP client or doveadm.

VERIFIED COMPETENCY MILESTONE
