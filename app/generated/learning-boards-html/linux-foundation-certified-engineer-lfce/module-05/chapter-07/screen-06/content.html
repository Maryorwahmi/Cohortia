Module 5 › Chapter 5.7 › Virtual Mailbox Domains
Postfix architecture

Map virtual addresses to mailbox directories

Define virtual mail domains and map each email to a mailbox path under virtual_mailbox_base.

main.cf snippet
virtual_mailbox_domains = your_virtual_domain.com another_virtual_domain.org
virtual_mailbox_base = /var/vmail
virtual_mailbox_maps = hash:/etc/postfix/vmailboxes
virtual_minimum_uid = 5000
virtual_transport = lmtp:unix:private/dovecot-lmpa
Example vmailboxes
# /etc/postfix/vmailboxes
user1@your_virtual_domain.com your_virtual_domain.com/user1/
user2@your_virtual_domain.com your_virtual_domain.com/user2/
Common pitfall

If mailbox paths in vmailboxes do not match the on-disk layout under virtual_mailbox_base, delivery fails silently or messages bounce.

Key Takeaway

Keep mailbox mappings consistent and use a dedicated vmail user with matching UID/GID for secure delivery.

LMTP transport

LMTP via a Dovecot socket delivers mail efficiently to virtual mailboxes. Ensure the socket path matches Postfix's virtual_transport.

Security note

Run mail storage under vmail:vmail with a low privileged UID and protect the mailbox directory permissions.
