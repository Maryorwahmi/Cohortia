Module 5 › Chapter 5.7 › Dovecot Mail Quotas
Configuration

Enable and configure quota plugin

Load quota in mail_plugins for IMAP and POP3 and set a storage limit in the plugin block.

20-imap.conf & 20-pop3.conf
protocol imap {
  mail_plugins = $mail_plugins quota imap_quota
}
protocol pop3 {
  mail_plugins = $mail_plugins quota
}
90-quota.conf
plugin {
  quota = maildir:storage=100M # Test value
}
Common oversight

Defining quota in 90-quota.conf without adding quota to mail_plugins results in quotas not being enforced.

Key Takeaway

Enable the quota plugin and set a storage limit, then reload Dovecot and verify with an IMAP client or doveadm.

Behavior

When users exceed quotas, the MUA will see errors and delivery may be rejected; plan quota messaging and archival policies accordingly.

Check

After reload, use an IMAP client or doveadm quota get to confirm the quota is visible and enforced for the user.
