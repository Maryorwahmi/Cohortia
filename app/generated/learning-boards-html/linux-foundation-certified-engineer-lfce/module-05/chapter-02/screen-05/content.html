Process Flow

Bind Postfix to specific interfaces

Decide which IPs and protocols should accept SMTP connections and reflect that in main.cf.

# examples inet_interfaces = all inet_interfaces = $myhostname, localhost, 192.168.1.100 inet_protocols = all inet_protocols = ipv4
Concrete example
For an internal relay set inet_interfaces to localhost and the internal IP so public networks can't connect directly.
Verification
# reload after edit
sudo systemctl reload postfix
# confirm listening sockets
ss -ltnp | grep :25
Misconception
Relying only on a firewall while leaving inet_interfaces = all increases the risk of accidental exposure if firewall rules change. Bind intentionally where possible.
Key Takeaway

Match inet_interfaces and inet_protocols to your topology; explicit bindings reduce accidental exposure and simplify firewall rules.
