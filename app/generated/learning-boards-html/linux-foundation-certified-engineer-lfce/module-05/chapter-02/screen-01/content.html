Server Identity
Set myhostname and mydomain so other MTAs can verify your server and so outgoing mail uses the correct HELO/EHLO name.
Access Controls
Use mynetworks and smtpd_recipient_restrictions to avoid becoming an open relay and to permit authenticated clients correctly.
DNS & Testing
Ensure an MX record points to your mail host and an A record maps that host to your IP; verify with dig and test mail flow.
