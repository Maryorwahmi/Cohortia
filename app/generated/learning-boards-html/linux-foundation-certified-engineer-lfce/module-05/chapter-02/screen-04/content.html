Core Concept

Server Identity

myhostname sets the FQDN Postfix advertises. mydomain defines the local internet domain used for local delivery decisions.

# /etc/postfix/main.cf myhostname = mail.example.com mydomain = example.com
Concrete example
If myhostname = mail.example.com and DNS has an A record for that name, other MTAs can resolve and connect to your server.
Common misconception
Using only the system hostname or an internal name without a public A record will break remote delivery and can look suspicious to receiving servers.
Verification steps
postconf -n
# verify DNS
dig A mail.example.com
dig MX example.com
Why it matters
  • HELO/EHLO name should match a resolvable A record to avoid rejections.
  • mydomain controls which destinations are considered local for delivery.
  • Misconfigured identity can cause reputation and routing issues.
Key Takeaway

Always configure myhostname to an FQDN that has an A record; set mydomain to the domain you serve so local delivery rules align with DNS.
