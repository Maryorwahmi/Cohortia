Edit, Reload, Verify

# edit /etc/postfix/main.cf sudo nano /etc/postfix/main.cf # then reload sudo systemctl reload postfix # check settings postconf -n
Concrete example
Change myhostname to mail.example.com, save, run systemctl reload postfix, and confirm postconf -n shows the new name.
Troubleshooting tips
  • If postconf -n shows the old value, reload Postfix; the service does not auto-reload.
  • Check journalctl -u postfix for parse errors or warnings after reload.
  • Use postconf -n to see only non-default values you changed.
Key Takeaway

Follow edit → reload → verify. postconf -n and the service logs are your primary verification tools after a configuration change.
