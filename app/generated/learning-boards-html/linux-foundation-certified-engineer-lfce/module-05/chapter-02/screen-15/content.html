What to Remember

Reload Postfix
Use systemctl reload postfix and confirm with postconf -n after edits to main.cf.
Test relay behavior
Send mail from an internal client and an external client to validate allowed and rejected relays.
Use logs & dig
Check logs for denial messages and use dig MX/A to confirm DNS that directs mail to your server.
Final Takeaway

Combine correct main.cf parameters, narrow mynetworks, ordered ACLs, and proper DNS to run a secure and functional Postfix SMTP server.
