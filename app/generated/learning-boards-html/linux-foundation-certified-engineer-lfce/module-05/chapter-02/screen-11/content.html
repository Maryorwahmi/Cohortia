Hands-on Activity

Internal vs External Tests

# internal client (trusted) echo "Test email from internal client." | mail -s "Internal Relay Test" your_personal_email@gmail.com # external client (untrusted) echo "Test email from external client." | mail -s "External Relay Test" your_personal_email@gmail.com
Expected outcome
Internal test succeeds; external test fails with 'Relay access denied' visible in logs.
Verification commands
# logs
journalctl -u postfix --since "10 minutes ago"
# or
tail -f /var/log/maillog
Common Mistake

Forgetting to reload Postfix after editing mynetworks leaves behavior unchanged; always reload and re-test.
