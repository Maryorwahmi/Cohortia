Definition

What mydestination does

It lists the domains Postfix should accept and deliver locally instead of relaying elsewhere.

# example mydestination = $myhostname, localhost.$mydomain, localhost, $mydomain
Concrete example
If you host example.com, include it in mydestination so mail for user@example.com is delivered locally.
Misconfiguration
Omitting your domain will cause Postfix to treat local mail as non-local and trigger relay checks or rejection.
Verification
Send a message to a local user and watch the mail log to confirm local delivery rather than relay attempts.
# send a local test
echo "Local delivery test" | mail -s "Local Test" localuser
# check logs
journalctl -u postfix --since "5 minutes ago"
Key Takeaway

Only include domains you should accept mail for in mydestination to avoid accidental acceptance or rejection of mail.
