Learning Objectives — Practical Skills

These objectives focus on verification, testing, reloading, and troubleshooting common failures.

01
Mitigate misconfigurations
Recognize and fix issues that create open relays or cause rejections, such as too-broad mynetworks or missing destinations.
VERIFIED COMPETENCY MILESTONE
02
Reload Postfix safely
Use sudo systemctl reload postfix and postconf -n to apply and confirm changes to main.cf without restarting mail queues.
VERIFIED COMPETENCY MILESTONE
03
Test relay behavior
Send mail from inside and outside mynetworks to observe allowed relays and 'Relay access denied' for untrusted clients.
VERIFIED COMPETENCY MILESTONE
04
Use logs and dig
Inspect /var/log/maillog or journalctl and run dig MX and dig A to verify DNS and delivery paths.
VERIFIED COMPETENCY MILESTONE
