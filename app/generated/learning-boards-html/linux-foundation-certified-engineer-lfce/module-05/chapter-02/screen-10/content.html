Definition

MX and A records for mail

Ensure your domain's MX points to your mail hostname and that hostname has an A record to your server IP.

# verify DNS dig MX example.com dig A mail.example.com
Concrete example
If MX for example.com is mail.example.com but mail.example.com has no A record, remote MTAs cannot connect to deliver mail.
Common errors
  • MX pointing to a name without an A record causes 'Host not found' or connection failures.
  • Pointing an MX to a hostname that resolves to a private IP will fail for internet senders.
  • Remember to allow DNS propagation before testing externally.
Key Takeaway

Confirm MX and A records with dig and ensure the A record points to the public IP where Postfix listens for SMTP connections.
