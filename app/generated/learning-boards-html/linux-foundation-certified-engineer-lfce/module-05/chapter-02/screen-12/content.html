Troubleshooting

Interpreting common log messages

Start with the log entry and timestamp, then check configuration and DNS to determine the root cause.
# common messages Relay access denied -> client not trusted or authenticated Host not found -> MX or A record missing or incorrect status=deferred -> delivery delayed or DNS/recipient resolution failed
Diagnostic routine
  1. Check logs for the error line and nearby context.
  2. Confirm current Postfix settings with postconf -n.
  3. Verify DNS with dig MX and dig A for hostnames involved.
Key Takeaway

Logs provide the fastest path to the cause: match times, inspect configuration, then verify DNS to find why mail was rejected or deferred.
