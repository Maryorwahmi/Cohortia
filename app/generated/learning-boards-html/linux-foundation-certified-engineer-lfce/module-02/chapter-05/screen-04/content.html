Module 2 › Chapter 2.5 › XFS: Design & Use
Definition
A journaling filesystem optimized for large files and parallel I/O. Records metadata changes before applying them to speed recovery.
Example scenario
A media archive storing multi-terabyte files uses XFS to maintain high write throughput and efficient directory handling.
Allocation & Delayed Writes
Delayed allocation batches writes to reduce fragmentation and increase throughput.
Common mistake
Attempting to shrink XFS, which is not supported and can lead to data loss if misapplied.
Key Takeaway

XFS is the strong choice for large-scale throughput and mounted growth, but it requires planning because shrinking is unsupported.

Quick reference
Common commands
sudo mkfs.xfs /dev/vg_xfs/lv_data
sudo mount /dev/vg_xfs/lv_data /mnt/xfs_data
# After lvextend
sudo xfs_growfs /mnt/xfs_data
sudo xfs_fsr /mnt/xfs_data
Why it matters
Predictable performance characteristics and a stable toolset make XFS suitable for production workloads that need consistent throughput and minimal downtime.
