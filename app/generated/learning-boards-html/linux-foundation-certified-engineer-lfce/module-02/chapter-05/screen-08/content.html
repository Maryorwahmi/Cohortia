Module 2 › Chapter 2.5 › Btrfs Snapshots
Snapshot workflow
Create a read-only snapshot for archival or a writable snapshot to test changes, then mount snapshots to verify content.
Commands (examples)
sudo btrfs subvolume snapshot -r /mnt/btrfs_root/home_users /mnt/btrfs_root/home_users_snap_readonly
sudo btrfs subvolume snapshot /mnt/btrfs_root/home_users /mnt/btrfs_root/home_users_snap_writable
sudo btrfs subvolume list /mnt/btrfs_root
Verification example
After modifying the original subvolume, mount the read-only snapshot and confirm that files from the earlier point in time still exist there.
Snapshot caution
Snapshots share the same disk; they are not a replacement for backups. Regularly prune unused snapshots to reclaim space.
Key Takeaway

Snapshots are instant and efficient rollback points, but must be paired with lifecycle policies and backups.
