Module 2 › Chapter 2.5 › Key Concepts
XFS
A journaling filesystem optimized for very large files and parallel I/O, supports online growth.
Btrfs
A copy-on-write filesystem offering snapshots, subvolumes, integrated RAID, and checksumming.
Journaling
A logging mechanism that records metadata changes to improve recovery after crashes.
Summary

Understand these core terms to make informed choices about performance, recoverability, and maintenance.
