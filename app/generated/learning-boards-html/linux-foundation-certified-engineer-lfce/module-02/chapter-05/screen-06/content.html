Module 2 › Chapter 2.5 › XFS Defragmentation
When to defragment
Fragmentation appears after many small file operations and can reduce random I/O efficiency. Monitor I/O latency to decide whether to run defragmentation.
Example command
sudo xfs_fsr /mnt/xfs_data
Maintenance note
Run defragmentation during low-load windows and monitor system resources; heavy defrag can create significant I/O traffic.
Common mistakes & checks
  • Assuming all workloads benefit from defrag — sequential writes usually do not.
  • Neglecting to check load before running xfs_fsr on production mounts.
  • Forgetting offline repairs after severe metadata corruption; use xfs_repair when required.
Pro tip

Schedule light scrubs of activity and defragment only when monitoring indicates fragmentation-related slowdowns.
