Module 2 › Chapter 2.5 › Btrfs: CoW & Subvolumes
Copy-on-Write (CoW)
Changes are written to new blocks; metadata is updated to reference the new versions. This makes snapshots efficient and fast.
Why it helps
Snapshots share unchanged data blocks, so they consume space only for differences after the snapshot was taken.
Subvolumes
Independently mountable trees inside the same filesystem. They do not reserve disk space and can be snapshotted separately.
Example commands
sudo btrfs subvolume create /mnt/btrfs_root/home_users
sudo mount -o subvol=home_users /dev/vg_btrfs/lv_data /mnt/home_users_mount
Misconception check
Do not treat subvolumes as separate block devices; they share the same pool and must be managed as part of the filesystem.
