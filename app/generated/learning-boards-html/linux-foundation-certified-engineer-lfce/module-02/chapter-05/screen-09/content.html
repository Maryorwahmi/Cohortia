Checksums and self-healing
Btrfs stores checksums for data and metadata so it can detect corruption. With redundancy, it can repair corrupted blocks using a good copy.
Scrub example
sudo btrfs scrub start -B /mnt/btrfs_root
Run scrubs regularly and inspect reports for unrecoverable errors. Plan redundant devices and choose RAID levels with care.
Creating a RAID1 filesystem
sudo mkfs.btrfs -d raid1 -m raid1 /dev/sdb /dev/sdc
Note: integrated RAID simplifies admin but requires informed choices; evaluate RAID5/6 carefully due to historical edge-case concerns.
Key Takeaway

Checksums plus redundancy enable detection and repair, but regular scrubs and careful RAID selection are required to maintain integrity.
