Module 2 › Chapter 2.5 › Btrfs Resize & Compression
Online resize
After increasing the LV or device, request Btrfs to grow (or shrink) the mounted filesystem using the resize command.
# grow to maximum available
sudo btrfs filesystem resize max /mnt/btrfs_root

# grow by 10G
sudo btrfs filesystem resize +10G /mnt/btrfs_root
Compression
Enable compression at mount-time for a subvolume or globally to save space. Choose algorithms like zstd or lzo based on performance needs.
# mount with zstd compression
sudo mount -o compress=zstd /dev/vg_btrfs/lv_data /mnt/btrfs_root
Misconception: compression always speeds I/O. In some cases compression overhead can reduce performance, particularly on already-compressed or small-file workloads.
