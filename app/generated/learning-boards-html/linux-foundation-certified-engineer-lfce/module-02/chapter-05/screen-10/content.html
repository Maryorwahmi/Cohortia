Module 2 › Chapter 2.5 › Subvolume Lifecycle
Create and mount
Create a subvolume and mount it using the subvol mount option to isolate a dataset without a new block device.
sudo btrfs subvolume create /mnt/btrfs_root/home_users
sudo mount -o subvol=home_users /dev/vg_btrfs/lv_data /mnt/home_users_mount
Lifecycle & housekeeping
List subvolumes to confirm names and hierarchy, and delete unused subvolumes to reclaim space.
sudo btrfs subvolume list /mnt/btrfs_root
sudo btrfs subvolume delete /mnt/btrfs_root/old_subvol
Misconception: a subvolume delete does not affect other subvolumes, but ensure the correct path to avoid removing critical data.
