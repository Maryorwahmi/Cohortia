Monitoring & Benchmarking
Observe and validate
Use these tools to collect data before and after changes, and run realistic benchmarks in a safe environment.
# Observe device IO
iostat -x 1
# System-level historical metrics
sar -b 1 5
# Simple fio example for 4k random reads
fio --name=random-read --rw=randread --bs=4k --size=1G --numjobs=4 --iodepth=32
Warning
Run destructive tests only on non-production systems and ensure LUKS headers and configs are backed up before disruptive operations.
Key Takeaway
Measure with representative workloads, document results, and keep a rollback plan for every tuning change.
