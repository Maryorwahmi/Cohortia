Learning Objectives
Skill-focused outcomes and verification steps
01
Implement LUKS encryption
Encrypt block devices with cryptsetup, open mappings, and format mapped devices. This protects data if disks are stolen.
Verified competency milestone
02
Manage ACLs
Use setfacl and getfacl to grant specific users or groups read, write, or execute access without changing ownership.
Verified competency milestone
03
Enforce disk quotas
Enable usrquota/grpquota, run quotacheck, and set soft and hard inode and block limits to manage usage.
Verified competency milestone
04
Tune I/O and kernel params
Choose schedulers like noop or mq-deadline, and tune vm.swappiness and vm.dirty_ratio to fit workload patterns.
Verified competency milestone
