Definition
Disk Quotas
Set soft and hard limits on disk blocks and inodes for users and groups to prevent resource exhaustion.
Why it matters
Quotas avoid denial-of-service caused by a single user filling a filesystem and preserve multi-tenant stability.
Enable & inspect
# /etc/fstab example
UUID=... /mnt/shared_project ext4 defaults,acl,usrquota 0 0
# Initialize
sudo mount -o remount /mnt/shared_project
sudo quotacheck -cum /mnt/shared_project
sudo edquota -u alice
# Check
quota -s alice
Common mistake
Not remounting the filesystem with quota options or skipping quotacheck leaves quotas inactive despite edits.
Key Takeaway
Configure, initialize, then test quotas; use soft limits to warn and hard limits to protect space.
