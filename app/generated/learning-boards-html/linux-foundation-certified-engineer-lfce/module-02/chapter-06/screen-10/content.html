Quota configuration and test sequence
Follow these commands to initialize and verify quota behavior in a controlled environment.
# fstab: add usrquota
UUID=... /mnt/shared_project ext4 defaults,acl,usrquota 0 0
sudo mount -o remount /mnt/shared_project
sudo quotacheck -cum /mnt/shared_project
sudo edquota -u alice    # set soft=10240 hard=15360
# Test as alice:
su - alice
dd if=/dev/zero of=/mnt/shared_project/alice_file bs=1M count=12   # triggers warning
dd if=/dev/zero of=/mnt/shared_project/alice_file2 bs=1M count=10  # should fail at hard limit
quota -s alice
Pitfall
Setting quotas too low for service accounts can break system services. Exclude or size limits appropriately.
Key Takeaway
Always test quota behaviour by simulating writes; monitor with quota tools and alert before hard limits are hit.
