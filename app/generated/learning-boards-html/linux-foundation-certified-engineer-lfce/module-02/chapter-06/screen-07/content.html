Definition
Access Control Lists (ACLs)
ACLs extend Unix permissions to grant named users or groups explicit rights on files and directories, enhancing flexibility in multi-user environments.
Example
sudo setfacl -m u:bob:rwX /shared/project_alpha — grants bob read/write and directory traversal without changing owner.
Commands
sudo setfacl -m u:bob:rwX /shared/project_alpha
getfacl /shared/project_alpha
sudo setfacl -x u:bob /shared/project_alpha
Common mistake
Assuming ownership changes automatically reflect ACLs. Always audit with getfacl and test access as the target user.
Key Takeaway
Use ACLs for precise grants, but keep permission strategy documented and audited to avoid surprises.
