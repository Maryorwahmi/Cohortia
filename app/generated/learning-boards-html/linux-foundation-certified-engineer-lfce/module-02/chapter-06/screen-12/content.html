Tuning swappiness and dirty_ratio
Change values temporarily with sysctl, benchmark, and if beneficial persist via /etc/sysctl.conf.
vm.swappiness
0 to 100. Lower values favor RAM; higher values swap more aggressively.
vm.dirty_ratio
Percent of RAM allowed to be dirty before writeback. Lower values result in more frequent flushes.
Commands
sudo sysctl vm.swappiness=10
sudo sysctl vm.dirty_ratio=10
# Make persistent in /etc/sysctl.conf
vm.swappiness=10
vm.dirty_ratio=10
Misconception
Lowering swappiness always improves performance. In memory-constrained systems it can cause out-of-memory conditions if not sized carefully.
Key Takeaway
Tune parameters iteratively and measure with representative workloads to avoid unintended regressions.
