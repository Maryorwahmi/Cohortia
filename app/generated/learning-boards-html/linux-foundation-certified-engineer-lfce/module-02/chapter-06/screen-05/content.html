Process Flow
LUKS workflow
1. Prepare device
Ensure the device is the correct target and is unmounted. This will overwrite existing data.
2. Format with LUKS
Run cryptsetup luksFormat /dev/device and choose a strong passphrase.
3. Backup header
Immediately run luksHeaderBackup to an off-device location.
4. Open mapping
cryptsetup luksOpen creates /dev/mapper/name for formatting.
5. Format mapped device
mkfs.ext4 /dev/mapper/name then mount as usual.
6. Close mapping
umount then cryptsetup luksClose to remove mapping.
Command snapshot
sudo cryptsetup luksFormat /dev/sdb
sudo cryptsetup luksHeaderBackup /dev/sdb --header-backup-file /root/sdb_header.img
sudo cryptsetup luksOpen /dev/sdb mydisk
sudo mkfs.ext4 /dev/mapper/mydisk
sudo mount /dev/mapper/mydisk /mnt/secure
# close when done
sudo umount /mnt/secure
sudo cryptsetup luksClose mydisk
Common mistake
Not backing up the LUKS header or storing keyfiles on the encrypted device will make recovery impossible.
Key Takeaway
Follow the full workflow and test recovery immediately after creating backups.
