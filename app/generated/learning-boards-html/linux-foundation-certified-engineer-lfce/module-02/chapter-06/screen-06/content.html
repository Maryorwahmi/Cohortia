Architecture
crypttab and fstab integration
crypttab defines mapping names and sources for unlocking devices; fstab mounts the resulting /dev/mapper entries. Secure keyfiles and the crypttab itself with proper permissions.
Example crypttab line
mydisk UUID=... /root/keyfile luks
Security note
Store keyfiles off the encrypted device and restrict file permissions to root only.
Checklist
  • Back up LUKS header off-device.
  • Place keyfiles on a separate secure medium if used.
  • Lock down /etc/crypttab permissions.
  • Test reboot unlock sequence in maintenance window.
Key Takeaway
Automatic unlock is convenient but introduces new secrets that must be protected and tested.
