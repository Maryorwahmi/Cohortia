Module 6 › Chapter 6.7 › auditd rules
Rule examples
-w /etc/passwd -p wa -k passwd_changes
-w /etc/shadow -p wa -k shadow_changes
-w /etc/sudoers -p wa -k sudoers_change
These watch rules monitor write and attribute changes and label entries with the provided key for focused searching.
Testing approach
  1. Backup existing rules and add your new file in /etc/audit/rules.d/
  2. Reload auditd with the service command
  3. Perform a safe change and search the log using the key
Search and analysis
# Example search by key (visual only):
ausearch -k passwd_changes

aureport --summary
Use ausearch to filter by the key you assigned and aureport to get summary statistics for a time range or daily report.
Common mistake
Adding broad directory watches without permission filters can generate large volumes of events and hide important incidents.
