Module 6 › Chapter 6.7 › Remote syslog server
Server steps
  1. Enable imudp or imtcp and configure input on port 514.
  2. Create rules to write authpriv messages to /var/log/remote_auth.log and stop further processing for those messages.
  3. Open firewall for UDP/TCP 514 from known clients only.
Verification
Perform a failed SSH login on a client and tail the remote log on the server to verify the event was received with the client's hostname.
Firewall note
Allow only the necessary protocol and IP addresses to reduce exposure and unwanted traffic reaching your collector.
Operational check
Document and test the end-to-end flow: client generates event, forwarder sends, server receives and writes to dedicated file.
