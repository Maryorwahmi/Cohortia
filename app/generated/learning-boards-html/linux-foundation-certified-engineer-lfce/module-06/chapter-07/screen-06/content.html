Module 6 › Chapter 6.7 › SUID/SGID execution rules
Rule examples
-a always,exit -F arch=b64 -F perm=x -F sgid -S execve -k sgid_exec
-a always,exit -F arch=b64 -F perm=x -F suid -S execve -k suid_exec
These rules log execve for SUID and SGID binaries on 64-bit systems. Replace arch if you are on 32-bit hosts.
Testing tip
Run a known SUID program under test and search for the suid_exec key. Consider testing in a staging environment to tune which binaries generate meaningful alerts.
Noise management
  • Limit to architectures in use to avoid irrelevant records.
  • Exclude known, benign admin binaries where appropriate.
  • Review and iterate: rule tuning is normal after initial deployment.
Pro tip
Tag each rule with a unique key and keep a short inventory mapping keys to the monitored asset to simplify queries during investigations.
