Module 6 › Chapter 6.7 › Mistakes & trade-offs
Too broad
Example: watching entire directories or logging all executable calls without filters can fill audit.log with routine system activity and make incident searches expensive.
Better
Scope rules to critical assets and tag each rule with a key for efficient search and correlation.
Rotation mistakes
Incorrect postrotate scripts or wrong file ownership can prevent services from writing to new log files or stop rotation altogether, risking silent data loss.
Action card
When deploying new rules, run them in a controlled environment, measure event volume, and iterate. Force rotations to test postrotate behavior and permissions.
