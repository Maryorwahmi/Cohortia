01
Configure auditd rules

Define rules in /etc/audit/rules.d to monitor file changes, system calls, and account events. Focus on critical assets to avoid noise.

02
Analyze audit logs

Use ausearch and aureport to filter by keys and generate summaries for triage and forensics. Practice focused searches to save time.

VERIFIED COMPETENCY MILESTONE
03
Implement rsyslog forwarding

Filter and forward auth events to a central server, choosing TCP for reliability in high-volume or critical streams.

VERIFIED COMPETENCY MILESTONE
04
Manage log rotation

Create logrotate policies that compress and rotate logs, run safe postrotate scripts, and preserve permissions to avoid data loss.
