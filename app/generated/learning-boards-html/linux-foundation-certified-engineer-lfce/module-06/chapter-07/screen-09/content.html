Module 6 › Chapter 6.7 › rsyslog forwarding
Client rule example
authpriv.* @192.168.1.100
# Use @@ for TCP where reliability is required
This directs authentication messages to the remote syslog. Use @@ to enable TCP for reliable delivery.
Server setup
Enable the imudp or imtcp modules and create a rule to write incoming auth messages to a separate remote_auth.log file for easier review.
Filtering & organization
On the collector, filter by host and facility so you can quickly pull a client's authentication stream for an incident without sifting through unrelated logs.
Operational check
After enabling forwarding, perform a failed login and verify the entry appears on the collector's remote_auth.log with the expected fromhost value.
