Module 6 › Chapter 6.7 › ausearch & aureport
Command patterns
# Find events related to a rule key (visual only):
ausearch -k identity_change

# Generate a daily summary (visual only):
aureport -ts today --summary
Use keys and time filters to keep searches fast and focused. Avoid scanning raw logs without filters.
Example
After a test change to /etc/passwd, search by the identity_change key to retrieve the audit entry and extract the user and timestamp for your timeline.
Analysis cards
Quick check
Search by key for a fast yes/no about whether an asset changed.
Daily triage
Use aureport summaries to spot unusual spikes in events and then drill down with ausearch.
Misconception
Assuming raw audit.log is easy to scan — instead, rely on the tools to filter and summarize for speed.
Takeaway
Build reusable queries and keys so evidence retrieval during an incident is fast and repeatable.
