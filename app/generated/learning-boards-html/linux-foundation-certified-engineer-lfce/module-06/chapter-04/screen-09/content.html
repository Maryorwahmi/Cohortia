Module 6 › Chapter 6.4 › OSSEC Overview
Components
  • Agents: run on hosts, collect logs and FIM events.
  • Manager: aggregates events, applies rules, and generates alerts.
  • Active response: optional scripts to block IPs or take other actions.
Example detection
Multiple failed SSH attempts followed by a changed file in /etc can be correlated to indicate a compromise. OSSEC rules elevate correlated sequences above single-file or single-log events.
Active response benefit: automatic temporary firewall bans for repeated attackers. Misconfiguration risk: false positives can block legitimate users.
