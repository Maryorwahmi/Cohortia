Module 6 › Chapter 6.4 › What is an IDS?
IDS Overview
An IDS observes activity and alerts on suspicious patterns; it does not guarantee prevention.
Network-based IDS (NIDS)
Monitors traffic for signatures or anomalies. Example: Snort inspects packets against rule signatures.
Host-based IDS (HIDS)
Monitors logs, file integrity, and host artifacts. Example: AIDE and OSSEC detect changed files and log events.
Concrete example
If /etc/passwd is modified, AIDE or OSSEC will report the change. A NIDS may only show the network activity that preceded the compromise, if any.
Common misconception
IDS does not inherently block attacks. HIDS may include active response features, but detection and proper investigation remain the primary outcomes.
Key Takeaway

Combine HIDS file checks with NIDS traffic monitoring and correlate alerts for stronger detection.
