Module 6 › Chapter 6.4 › Testing OSSEC
Test steps
  1. Create a monitored test file: sudo touch /etc/ossec_test_file.txt
  2. Watch the alerts: sudo tail -f /var/ossec/logs/alerts/alerts.log
  3. Generate failed SSH logins from another terminal and observe correlation alerts.
Document alerts and adjust configuration to reduce false positives while preserving detection.
