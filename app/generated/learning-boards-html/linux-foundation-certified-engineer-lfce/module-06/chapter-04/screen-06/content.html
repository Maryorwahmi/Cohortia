Module 6 › Chapter 6.4 › Installing AIDE
Step-by-step
  1. Install the package for your OS (apt or dnf).
  2. Edit /etc/aide/aide.conf to add directories with attributes and hashes.
  3. Exclude volatile directories (e.g., /var/log, /tmp).
  4. Run sudo aide --init and review the generated database.
  5. Move the database into place and schedule periodic checks via cron.
Do not accept changes blindly with aide --update; investigate alerts first.
Recommended config snippet
/etc    p+i+n+u+g+s+m+sha256
/usr/bin    p+i+n+u+g+s+m+sha256
/boot   p+i+n+u+g+s+m+sha256
!/var/log
!/tmp
!/proc
!/sys
After editing, initialize and move the database. Protect the stored database by copying it to read-only media or a separate secure host.
