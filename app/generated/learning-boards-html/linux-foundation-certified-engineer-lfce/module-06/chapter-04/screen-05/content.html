Module 6 › Chapter 6.4 › FIM with AIDE
How AIDE works
AIDE computes hashes and records attributes into a baseline database, then compares later to detect changes.
Attributes
Common options: p (permissions), i (inode), n (links), u (user), g (group), s (size), m (mtime), c (ctime), a (atime), md5, sha256.
Exclusions
Exclude /var/log, /tmp, /proc, /sys to avoid constant expected changes.
Key Takeaway

Baseline integrity plus careful exclusions are the core of reliable FIM.

Concrete terminal example
sudo apt update && sudo apt install aide aide-common
sudo aide --init
sudo mv /var/lib/aide/aide.db.new.gz /var/lib/aide/aide.db.gz
sudo aide --check
# To test: sudo touch /etc/testfile.txt then sudo aide --check
Tip: review the database file before moving it into /var/lib; keeping an offline copy prevents an attacker from erasing history.
