Module 6 › Chapter 6.4 › Learning Objectives
01
Deploy AIDE for FIM
Install AIDE, set up /etc/aide/aide.conf rules, initialize the database, and run checks via cron to detect unauthorized file changes.
VERIFIED COMPETENCY MILESTONE
02
Configure OSSEC local agent
Add log sources and directories to /var/ossec/etc/ossec.conf so the agent reports SSH login events and file integrity changes to a manager or local logs.
VERIFIED COMPETENCY MILESTONE
03
Implement secure baselines
Create and protect the AIDE database off-host or on read-only media to prevent attackers from tampering with your baseline.
VERIFIED COMPETENCY MILESTONE
04
Analyze and integrate alerts
Correlate HIDS alerts with NIDS and central logging to prioritize investigation and automate response where safe.
VERIFIED COMPETENCY MILESTONE
