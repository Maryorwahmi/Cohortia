Terminal commands
sudo apt update && sudo apt install aide aide-common
sudo aide --init
sudo mv /var/lib/aide/aide.db.new.gz /var/lib/aide/aide.db.gz
sudo aide --check
# Test: sudo touch /etc/testfile.txt
sudo aide --check
# If change is verified:
sudo aide --update
sudo mv /var/lib/aide/aide.db.new.gz /var/lib/aide/aide.db.gz
Inspect the output carefully. The check lists attribute differences so you can triage changes effectively.
Investigation checklist
  • Verify who changed the file and when from logs.
  • Check for related suspicious entries in auth and syslogs.
  • Do not update baseline until the change is validated.
  • Preserve the pre-change database copy offline for forensics.
If you see unexpected changes to core files like /etc/passwd, escalate and preserve evidence immediately.
