Module 6 › Chapter 6.4 › Protecting the AIDE DB
Threat model
If an attacker gains root, they can edit files and the AIDE database on the same filesystem, hiding their activity. Treat the baseline as sensitive forensic evidence.
Best practices
  • Copy baseline to read-only media or external host.
  • Archive historical baselines off-host.
  • Require manual validation before updating the baseline.
Operational pattern
  1. Init baseline and copy to secure archive.
  2. Run daily checks and review diffs.
  3. Investigate before updating baseline.
  4. Store updated baseline off-host after validation.
Protecting the baseline preserves your ability to detect attackers who attempt to erase their tracks.
