Rule anatomy
Header: action protocol srcIP srcPort direction dstIP dstPort
Options: message, content, flow, threshold, sid, rev.
Example rule
alert tcp any any -> $HOME_NET 21 (msg:"FTP Brute Force Attempt"; flow:to_server,established; content:"USER"; depth:4; threshold:type limit,track by_src,count 5,seconds 60; sid:1000001; rev:1;)
Map this to host events: repeated FTP USER attempts in network logs plus new accounts or file changes on a host could indicate coordinated attack activity.
