Module 6 › Chapter 6.4 › Key Concepts
Host-based IDS (HIDS)
Monitors logs and file changes to detect tampering and persistence on individual hosts.
File Integrity Monitoring
Creates a cryptographic baseline and reports any attribute or hash changes compared to that snapshot.
OSSEC and Active Response
Combines FIM, log analysis, rootkit checks, and automated responses when properly tuned.
Summary

Use HIDS for host-level detection, keep baselines secure, and correlate signals across hosts and network sensors to prioritize response.
