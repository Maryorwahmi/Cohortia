Intrusion Detection Systems and Host-based Security
Understand practical HIDS deployment with AIDE and OSSEC, plus core NIDS concepts for integrated monitoring.
This module focuses on hands-on steps: install, configure, initialize, and test AIDE; configure OSSEC agent local monitoring for SSH and FIM; and read a Snort rule to interpret NIDS alerts. Emphasis is on what to monitor, how to protect baselines, and how to integrate alerts into a security workflow.

Quick start
You’ll follow a terminal-first flow: install AIDE, initialize a baseline, simulate a file change, observe AIDE results, then install an OSSEC agent, configure SSH and FIM monitoring, and generate an alert to see active response behavior. Keep a copy of the AIDE database off-host for integrity.
