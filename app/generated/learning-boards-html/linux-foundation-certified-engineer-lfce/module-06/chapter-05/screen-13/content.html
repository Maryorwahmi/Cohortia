Module 6 › Chapter 6.5 › SELinux vs AppArmor
When to Use SELinux
  • Require fine-grained, label-based system-wide policy.
  • Need port and resource labeling for many services.
  • Operate on distributions where SELinux is standard.
When to Use AppArmor
  • Prefer quicker per-application profile authoring.
  • Target single executables without relabeling the filesystem.
  • Work on Debian/Ubuntu where AppArmor is default.
Common Troubleshooting Checklist
1) Confirm mode with sestatus or aa-status. 2) Inspect contexts with ls -Z and ps -Z or AppArmor logs. 3) Reproduce denials in permissive/complain. 4) Decide relabel vs module/profile. 5) Apply minimal change and verify.
