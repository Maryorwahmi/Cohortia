Module 6 › Chapter 6.5 › Booleans & Ports
Booleans
# Make httpd network-connect allowed permanently
sudo setsebool -P httpd_can_network_connect on
# List booleans
sudo getsebool -a
Booleans tune policy without module compilation and survive reboots when -P is used.
Port Labeling
# Add port 8080 to http_port_t
sudo semanage port -a -t http_port_t -p tcp 8080
# Verify
sudo semanage port -l | grep http_port_t
Use semanage port to let services listen on nonstandard ports under existing SELinux types.
