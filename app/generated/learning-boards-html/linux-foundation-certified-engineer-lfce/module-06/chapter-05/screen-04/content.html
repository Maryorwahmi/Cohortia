Module 6 › Chapter 6.5 › MAC vs DAC
Definition

Mandatory Access Control

Kernel-enforced policy binds subjects and objects using labels or profiles so that access cannot be bypassed by users or processes.

Key points:
  • SELinux: label-based contexts for files, processes, and ports.
  • AppArmor: path-based profiles tied to executables.
  • MAC persists across user privilege changes.
Key Takeaway

Use MAC to reduce the damage possible from a compromised process; prefer policy changes over disabling enforcement.

Analogy & Example
Think of DAC as personal keys each user controls and MAC as a central access policy controlled by the building manager. If one tenant is compromised, they cannot rekey the building under MAC.
Concrete Example
# File under wrong context will be denied
ls -Z /var/www/html/index.html
# process context for Apache
ps -Z | grep httpd
Label-based: httpd_t and httpd_sys_content_t
Path-based: AppArmor profiles in /etc/apparmor.d/
