Module 6 › Chapter 6.5 › AppArmor
Core Ideas
AppArmor profiles live under /etc/apparmor.d/ and attach rules to an executable path rather than applying labels to every file and process.
# Status
sudo aa-status
# Put profile in complain
sudo aa-complain /usr/bin/myapp
# Enforce profile
sudo aa-enforce /usr/bin/myapp
Profile Generation
Typical flow: complain mode to collect logs, aa-genprof to generate a profile, review and then enforce.
Comparison note: AppArmor is often simpler for individual app rules; SELinux offers broader, label-based system policy. Choose based on distribution and operational needs.
