Module 6 › Chapter 6.5 › AVC & Audit
Locate Denials
# Search for httpd denials
sudo ausearch -c 'httpd' --raw
# Or inspect the audit log
sudo tail -n 200 /var/log/audit/audit.log
Denial entries include source and target contexts and the requested permission set; these details guide your fix.
Analyze with audit2allow
# Generate a module from recent denials
sudo ausearch -c 'httpd' --raw | audit2allow -M webapp_fix
# This produces webapp_fix.te and webapp_fix.pp
Inspect the .te file and confirm the allow rules are specific and justified before installing with semodule -i.
