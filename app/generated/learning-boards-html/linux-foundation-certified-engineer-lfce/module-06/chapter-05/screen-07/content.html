Module 6 › Chapter 6.5 › Inspect & Correct Contexts
Inspection Commands
ls -Z /srv/webapp/html/index.html
ps -Z | grep httpd
Verify the type fields: the process should show httpd_t and the files httpd_sys_content_t for normal Apache serving.
Fixing Contexts
# Temporary change
sudo chcon -t httpd_sys_content_t /srv/webapp/html/index.html
# Permanent default
sudo semanage fcontext -a -t httpd_sys_content_t "/srv/webapp/html(/.*)?"
sudo restorecon -Rv /srv/webapp/html
Example mistake: moving files into a managed directory without running restorecon will leave them with the old type and cause access denied.
