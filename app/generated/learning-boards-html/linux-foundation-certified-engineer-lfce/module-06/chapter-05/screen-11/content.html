Module 6 › Chapter 6.5 › Lab Walkthrough
Lab Timeline
1. Setup and verify
Install httpd, create /srv/webapp/html/index.html, and confirm SELinux is enforcing with sestatus.
2. Reproduce denial and collect AVC
Try to access the page, then use ausearch -c 'httpd' --raw or check /var/log/audit/audit.log to gather messages.
3. Apply permanent label
sudo semanage fcontext -a -t httpd_sys_content_t "/srv/webapp/html(/.*)?"
sudo restorecon -Rv /srv/webapp/html
4. Ports & booleans if needed
Add port 8080 to http_port_t and enable httpd_can_network_connect when Apache proxies to a backend.
5. Verify
Restart httpd, test the site, and ensure AVC denials related to the fix no longer appear.
