Module 6 › Chapter 6.5 › SELinux Modes
Modes Explained
  • Enforcing — policy enforced and violations blocked and logged.
  • Permissive — violations logged but not blocked; for diagnostics.
  • Disabled — SELinux enforcement is off; not recommended.
Check mode: sestatus. Temporarily set permissive for debugging, then return to enforcing after fixes.
Troubleshooting Workflow
1) Reproduce denial in permissive. 2) Gather AVC entries. 3) Decide relabel or module. 4) Apply change. 5) Return to enforcing and verify.
# Check mode
sestatus
# Temporarily set permissive (appropriate for test)
sudo setenforce 0
# Return to enforcing
sudo setenforce 1
Misconception: setting permissive on production is safe — it will hide active policy violations. Use permissive only on isolated testing or short windows with clear monitoring.
