Module 6 › Chapter 6.5 › Practical Skills
Commands to Know
sestatus • ls -Z • ps -Z • semanage • restorecon • chcon • audit2allow • semodule
Practice the flow: verify mode, inspect contexts, reproduce denial, collect audit evidence, choose relabel or module.
Decision Guide
  • Files in managed directories: use semanage fcontext + restorecon.
  • Missing policy for an expected behavior: use audit2allow to propose a module.
  • Avoid chcon for permanent fixes; it’s temporary.
Quick Tip
Use permissive mode locally to collect denials before applying changes in enforcing production systems. Permissive lets you see what would be blocked without service interruption.
Why This Matters
Keeping SELinux enabled in enforcing mode preserves a powerful layer of defense. These skills let you maintain functionality while retaining protection.
