Definition

chattr: special file attributes

Attributes like immutable (+i) and append-only (+a) add an additional protection layer that operates independently of UNIX permissions.

Immutable (+i)
Prevents modification, deletion, renaming, and linking until removed; useful for critical config files.
Append-only (+a)
Allows only appending data; ideal for preserving log integrity while still recording new entries.
Pitfall
Applying +i to a rotating log prevents rotation and can cause a disk-full condition. Always test in staging first.
Commands & Example
# Make a config file immutable
sudo chattr +i /etc/myapp/config.yml
# Make a log file append-only
sudo chattr +a /var/log/app/critical.log
# Verify attributes
lsattr /var/log/app/critical.log
Pro Tip

Document any use of immutable or append-only attributes and include attribute changes in your change control system so others know why a file is locked.
