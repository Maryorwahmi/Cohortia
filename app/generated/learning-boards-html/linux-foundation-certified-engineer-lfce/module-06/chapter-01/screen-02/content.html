Bloom Progress
Learn → Understand → Apply → Master
01
Use ACLs
Apply setfacl and getfacl to grant specific users access without changing ownership. This avoids creating unnecessary groups and preserves existing permissions.
VERIFIED COMPETENCY MILESTONE
02
Set file attributes
Use chattr to apply immutable and append-only flags, protecting critical files from accidental or malicious changes while noting operational impacts.
VERIFIED COMPETENCY MILESTONE
03
Harden mounts
Configure noexec,nosuid,nodev for non-system filesystems and tmpfs for /tmp to reduce execution and privilege risks.
VERIFIED COMPETENCY MILESTONE
04
Audit & baseline
Use find and getfacl to locate SUID files, review ACLs, and create a repeatable audit schedule to detect drift from your baseline.
VERIFIED COMPETENCY MILESTONE
Mnemonic & Quick Guide
  • ACL: Assign users directly.
  • chattr: Lock files when needed.
  • fstab: Apply noexec/nosuid/nodev on non-system mounts.
Follow the milestone guidance to demonstrate competency with commands and audits.
