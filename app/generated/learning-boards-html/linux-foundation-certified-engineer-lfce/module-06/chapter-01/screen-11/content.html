Hands-on Activity

Secure /opt/app/config and /var/log/app/critical.log

Follow these commands in a controlled environment to apply ACLs and attributes as shown in the chapter source.
# Create group and users
sudo groupadd appdevs
sudo useradd -m appadmin
sudo usermod -aG appdevs appadmin
sudo useradd -m testuser

# Set up directory and ownership
sudo mkdir -p /opt/app/config
sudo chown appadmin:appdevs /opt/app/config
sudo chmod 750 /opt/app/config

# Apply ACLs
sudo setfacl -m u:appadmin:rwx /opt/app/config
sudo setfacl -m g:appdevs:r-x /opt/app/config
sudo setfacl -m o::--- /opt/app/config
getfacl /opt/app/config

# Secure the log file
sudo mkdir -p /var/log/app
sudo touch /var/log/app/critical.log
sudo chown appadmin:appdevs /var/log/app/critical.log
sudo chmod 640 /var/log/app/critical.log
sudo chattr +a+i /var/log/app/critical.log
lsattr /var/log/app/critical.log
Tests to run
  • sudo -u appadmin touch /opt/app/config/admin_file.txt should succeed.
  • sudo -u testuser cat /opt/app/config/admin_file.txt should fail.
  • echo "First log" | sudo tee -a /var/log/app/critical.log should append.
  • Trying to overwrite or delete the log should fail until attributes are removed.
Reminder

Run this scenario in a staging environment first and document attribute changes before applying on production systems.
