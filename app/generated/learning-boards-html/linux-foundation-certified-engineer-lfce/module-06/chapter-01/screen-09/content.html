Implement tmpfs for temporary dirs

tmpfs keeps temporary files in RAM and clears them on reboot. Use with mount hardening options for extra protection.

Add to /etc/fstab
tmpfs /tmp tmpfs defaults,noexec,nosuid,nodev 0 0
Validation
  • Run mount or findmnt to confirm options.
  • Test common application workflows to detect compatibility issues.
  • If execution is required, create a controlled exception with strict ACLs.
Why it matters
Without tmpfs and hardened options, an attacker can drop a binary into /tmp and execute it, or create device files. This practice reduces these vectors and makes temporary files ephemeral.
Key Takeaway

Use tmpfs plus noexec,nosuid,nodev for /tmp and /var/tmp to reduce execution and device-related risks and to avoid persistent malicious files across reboots.
