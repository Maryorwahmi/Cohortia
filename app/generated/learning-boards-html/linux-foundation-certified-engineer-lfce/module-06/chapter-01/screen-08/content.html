Core Concept

Secure Mount Options

Apply mount options to reduce risky operations on non-system filesystems.

noexec
Prevents execution of binaries on the mounted filesystem.
nosuid
Disables SUID and SGID bits from taking effect on this mount.
nodev
Blocks interpretation of device files on the filesystem.
Example /etc/fstab entry
# Mount /tmp as tmpfs with hardening options
tmpfs /tmp tmpfs defaults,noexec,nosuid,nodev 0 0
# A data partition with nodev and noexec
/dev/sdb1 /mnt/data ext4 defaults,nodev,noexec 0 2
Misconception check

noexec stops direct binary execution but does not block interpreters from loading scripts; treat it as part of a layered defense rather than a complete control.
