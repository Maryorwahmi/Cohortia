Objective Cards
Grant a single user access with ACLs
Use setfacl to add a user entry without altering ownership. This avoids broader group changes and preserves existing permissions.
Apply and remove chattr attributes
Use +i to protect critical files and +a for logs. Test impacts before applying in production to avoid breaking services.
Harden temporary mounts
Add a tmpfs with noexec,nosuid,nodev for /tmp and /var/tmp to reduce execution and device risks for user-space temporary files.
Checklist & Mnemonics
  • Test: Always test chattr and ACL changes in staging.
  • Baseline: Record permission baselines for critical dirs.
  • Schedule: Run weekly audits for SUID files and ACL reviews.
Each item maps to a verified competency milestone for operational readiness.
