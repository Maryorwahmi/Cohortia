Core Concept

What are ACLs?

ACLs let you set permissions for specific users or groups beyond owner, group, and others.

Definition
An ACL is a list of permission entries attached to a file or directory that names users or groups and their permissions.
Common misconception
ACLs always increase access. In reality, the mask can reduce effective permissions, so verification is required.
Key takeaway
Use ACLs for specific exceptions. Maintain group-based control for broader membership rules.
Illustration & Example
Scenario
A shared config directory must allow appadmin full control, appdevs group read access, and a single testuser temporary write access without changing group membership.
Command example
# Grant user write access with ACL
sudo setfacl -m u:testuser:rwx /opt/app/config
# View ACLs
getfacl /opt/app/config
Check your understanding
  • After setfacl, run getfacl to inspect the mask and effective permissions.
  • If a user still cannot write, verify the mask is not restricting access.
