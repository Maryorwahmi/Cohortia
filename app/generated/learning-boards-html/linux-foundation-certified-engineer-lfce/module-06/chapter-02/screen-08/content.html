Visudo snippet
Define aliases and give the user only the service restart commands needed.
# Sudoers snippet example
User_Alias APACHE_NGINX_ADMINS = opsadmin
Cmnd_Alias SERVICE_RESTARTS = /usr/bin/systemctl restart nginx, /usr/bin/systemctl restart apache2
APACHE_NGINX_ADMINS ALL=(root) SERVICE_RESTARTS
Testing
  1. Run an allowed restart command as the opsadmin user and expect success.
  2. Attempt a disallowed command such as opening a shell with sudo; expect denial and a log entry.
Practical notes
  • Prefer absolute paths in Cmnd_Alias to avoid ambiguity.
  • Avoid NOPASSWD unless required and reviewed for accountability impacts.
  • Group similar commands into aliases to make audits and reviews easier.
Common mistake
Using broad wildcards or directories in command lists can unintentionally widen privileges. Be explicit and conservative.
