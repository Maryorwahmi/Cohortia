Module 6 › Chapter 6.2 › pam_pwquality configuration
Configuration example
Add or update the password module line with specific options for length and character classes.
# Example pam_pwquality configuration line (place in common-password or system-auth)
password    requisite     pam_pwquality.so retry=3 minlen=14 ucredit=-1 lcredit=-1 dcredit=-1 ocredit=-1 enforce_for_root
Notes
  • minlen sets the shortest allowed password length.
  • ucredit, lcredit, dcredit, and ocredit require character classes by using negative values.
  • retry configures how many times a user may retry during password entry.
Lab test sequence
  1. Create a test account and try to set an intentionally weak password. Expect a PAM rejection with a reason.
  2. Set a compliant password using the required classes and confirm success.
  3. If rejection persists, confirm you edited the correct PAM file and that the service uses that stack.
Common mistake
Editing the wrong PAM file or failing to restart the service that sources a different pam.d entry will make changes appear ineffective.
Key Takeaway

Use pam_pwquality options to set a strict baseline and always validate by creating a test user and trying weak and strong passwords.
