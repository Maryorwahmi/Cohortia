Module 6 › Chapter 6.2 › Learning Objectives — Implementation
Validation checklist
Short terminal checks you will run after each change.
PAM policy check
  • Edit the pam_pwquality line and save with the appropriate tool for your distribution.
  • Create a new user and attempt a weak password; expect a clear rejection message from PAM.
  • Try a compliant password and confirm account creation succeeds.
chage and expiry
  • Set maximum age and warning period for a test user and run the command to view expiry fields.
  • Confirm the warning appears within the configured window when close to expiry.
  • Use account metadata in /etc/shadow to audit real values.
Sudo testing
  • Create a limited sudoers entry with visudo and test an allowed command as the target user.
  • Try a disallowed command and observe the denial and sudo log entry.
  • Review the audit trail in auth logs to ensure visibility of elevated actions.
Locking & fail2ban
  • Configure a faillock rule that locks after a small number of failures and test from a separate client.
  • Enable an SSH jail in fail2ban and generate repeated failures to see a dynamic ban in action.
  • Inspect faillock and fail2ban logs to confirm the block and reset the test user as needed.
