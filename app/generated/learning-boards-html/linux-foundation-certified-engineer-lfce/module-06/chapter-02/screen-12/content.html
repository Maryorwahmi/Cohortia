Module 6 › Chapter 6.2 › Secure account workflow
Workflow summary
A concise, repeatable process you can run in a lab or production validation.
Step 1
Enforce PAM
Set pam_pwquality rules for complexity and dictionary checks.
Step 2
Set aging
Use chage for max age, min change interval, and warn days.
Step 3
Scope sudo
Add minimal sudoers entries with visudo and test logs.
Step 4
Lock on failure
Configure pam_faillock to block repeated attempts per account.
Step 5
Block abusive IPs
Deploy fail2ban jails to add temporary firewall bans for noisy attackers.
Key Takeaway

A layered approach gives prevention, detection, and the audit trail you need to investigate incidents and limit damage from compromised credentials.
