Concept map
How PAM, chage, sudo, system users, and locking fit together.
Authentication and password rules are enforced by PAM modules before account access is granted.
chage sets how long passwords remain valid and when users receive warnings.
sudo provides controlled elevation and creates an audit trail for privileged actions.
