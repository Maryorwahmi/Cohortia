Module 6 › Chapter 6.2 › Sudo and least privilege
Why scoping sudo matters
A narrowly scoped sudo entry limits what a compromised account can do and makes audits meaningful.
Best practice
Use visudo, prefer command aliases for clarity, and list absolute command paths to avoid ambiguity between distributions.
Audit
Review /var/log/auth.log or journal entries to see who executed an elevated command and when. Sudo creates a reliable trail when used correctly.
Key Takeaway

Restrict sudo to exact commands and verify audit logs after allowing elevated actions to maintain control and visibility.

Analogy & example
Think of sudo entries as giving keys that open only specific doors. Instead of handing someone a master key, grant access to the single service door they need. The code panel on the next slide contains a secure example that grants restart rights for two services without broader control.
Common mistake
Adding a user to the sudo or wheel group without understanding the resulting privileges effectively grants full root access, removing accountability and increasing risk.
