Module 6 › Chapter 6.2 › Password aging with chage
chage examples
Set maximum age, minimum interval, and warning days for a user.
# Example: set maximum 90 days, minimum 7 days, warn 14 days
chage -M 90 -m 7 -W 14 username

# View aging information
chage -l username
What to verify
  • Run the chage list command to see the updated fields.
  • Confirm that users receive a warning within the configured window before expiry.
  • Use a short max value in a lab to test the expiry workflow quickly.
Scenario and pitfalls
A typical policy sets a maximum and a warning to ensure users rotate credentials without surprises. Avoid setting minimum to zero if you have password-history controls, because users could cycle through weak variants quickly. Also remember chage changes metadata; it does not change password complexity.
Common mistake
Assuming the warning will appear via email. The warning is shown at login or password-change; notify users separately if you need email reminders.
Key Takeaway

Use chage to enforce rotation windows and always validate with the chage list and a user login test to confirm warnings.
