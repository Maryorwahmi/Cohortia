01. Enforce password complexity

Define rules in PAM using pam_pwquality or pam_cracklib to require length and mixed character classes. This prevents weak passwords at creation time and raises baseline account strength.

Mnemonic: Venn of length and classes
VERIFIED COMPETENCY MILESTONE
02. Configure password aging

Use the chage utility to set maximum age, minimum days between changes, and warning windows so passwords rotate predictably and users receive advance notice.

Mnemonic: timeline card with expiry and warning
VERIFIED COMPETENCY MILESTONE
03. Secure sudo with least privilege

Edit sudoers only with visudo, specify exact commands and arguments, and avoid broad group additions that yield unrestricted root access.

Mnemonic: command alias tile
VERIFIED COMPETENCY MILESTONE
04. Lock accounts and monitor brute force

Use pam_faillock to lock accounts after a few failures and deploy fail2ban to block offending IPs, reducing attack effectiveness against SSH and services.

Mnemonic: shield with lock
VERIFIED COMPETENCY MILESTONE
