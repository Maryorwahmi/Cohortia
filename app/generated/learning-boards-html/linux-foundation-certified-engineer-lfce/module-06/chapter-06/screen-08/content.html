Using cryptsetup: Format, Open, and Mount
A safe, repeatable sequence for putting an encrypted filesystem into service.
Step-by-step commands (example)
# Initialize LUKS header on a spare partition
sudo cryptsetup luksFormat /dev/sdb1

# Open the LUKS volume and create a mapper node
sudo cryptsetup luksOpen /dev/sdb1 mysecretdata

# Format the mapped device and mount
sudo mkfs.ext4 /dev/mapper/mysecretdata
sudo mkdir -p /mnt/secret
sudo mount /dev/mapper/mysecretdata /mnt/secret
Use a dedicated spare device for practice. The luksFormat step will overwrite existing data permanently.
Verification and cleanup
  • Verify the mapping with tools that list /dev/mapper and lsblk.
  • Set ownership of the mount directory to the intended user for testing.
  • When finished, unmount and close the LUKS mapping to return to an encrypted state.
Example caution
Do not run luksFormat on a partition with production data. Always confirm the target device path.
Key Takeaway

The sequence luksFormat → luksOpen → mkfs → mount turns an encrypted block device into usable storage; practice carefully on disposable media.
