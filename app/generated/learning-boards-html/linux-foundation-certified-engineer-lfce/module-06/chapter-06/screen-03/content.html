Module 6 › Chapter 6.6 › Objectives — Skills
Verification Tasks
  • Reproduce a Secure Boot validation failure and document remediation steps.
  • Encrypt a spare partition with LUKS, open it, and mount a test filesystem.
  • Create a key file, add it to LUKS, then remove the file and recover using a passphrase.
  • Backup the LUKS header and store it securely off the device.
Why these matter
Each task shows how to keep data available and secure under real operational threats: theft, tampering, lost keys, and unauthorized boot modifications. Practice turns theory into repeatable procedures.
