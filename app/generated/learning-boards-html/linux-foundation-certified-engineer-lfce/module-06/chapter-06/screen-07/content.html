LUKS Key Slots and Header Structure
Key slots wrap the master key, enabling multiple credentials and safe rotation.
Header breakdown
  • Master key: single symmetric key that encrypts the data area.
  • Key slots: up to eight independent slots storing encrypted wrappers of the master key.
  • Metadata: algorithm identifiers, salt, and versioning for portability.
Management pattern
To rotate keys: add a new slot, verify unlock works, then remove the old slot. This avoids re-encrypting the entire volume and preserves access continuity.
Concrete example
An operator adds a second passphrase for backup on slot two. Later, if the second passphrase is compromised, they can kill slot two without affecting slot one.
Danger point
Losing the LUKS header makes all slots unusable. Back up the header and keep backups offline.
Key Takeaway

Use key slots for redundancy and rotation, and back up the header to prevent irrecoverable data loss.
