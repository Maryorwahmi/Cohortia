Learning Objectives
Four verified milestones that build practical skill and judgment.
01
UEFI Secure Boot Principles
Explain code signing checks during boot and why they stop rootkits.
VERIFIED COMPETENCY MILESTONE
Describe a boot failure caused by an unsigned kernel module and the enrollment options.
02
Full Disk Encryption with LUKS
Format a partition, open it, create a filesystem, and mount encrypted storage.
VERIFIED COMPETENCY MILESTONE
Perform a complete encrypt, open, format, and mount sequence on a spare partition.
03
Key Management for LUKS
Add and rotate passphrases, use key files, and remove compromised key slots safely.
VERIFIED COMPETENCY MILESTONE
Add a key file and then demonstrate recovery using a passphrase when the key file is lost.
04
TPM and HSM Integration
Conceptually bind keys to platform measurements and know when to use an HSM in enterprise settings.
VERIFIED COMPETENCY MILESTONE
Explain how a TPM can automatically release a LUKS key only when the system boots unchanged.
Bloom’s progression: Learn → Understand → Apply → Master
