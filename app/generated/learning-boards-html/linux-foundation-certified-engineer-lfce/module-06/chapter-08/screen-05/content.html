Nmap command walkthrough

Commands you will use in the hands-on lab and what their output tells you.

nmap -sS <target_ip>
# SYN scan: lists open TCP ports without completing full connections

nmap -sV <target_ip>
# Service version detection: attempts to identify exact software versions

nmap -O <target_ip>
# OS detection: uses TCP/IP stack fingerprinting

nmap -A <target_ip>
# Aggressive: combines -O, -sV, script scanning, and traceroute; use with permission
Simulated output snippet
PORT   STATE SERVICE VERSION
22/tcp open  ssh     OpenSSH 7.4
80/tcp open  http    Apache httpd 2.4.6

OS guesses: Linux 3.x - 4.x
Interpretation
  • OpenSSH on 22 may need configuration hardening or patching.
  • Apache version disclosure suggests version hardening (suppress headers) and patch checks.
  • OS guess guides which packages to inspect for CVEs.
Best practices & caution
  • Obtain explicit written permission before scanning any asset you do not own.
  • Start with low-impact scans and increase scope slowly if authorized.
  • Avoid -T5 on production or sensitive systems to prevent service disruption.
Key Takeaway

Use Nmap methodically: discovery first, then targeted scans, and always respect authorization and system stability.
