Scan workflow steps

A repeatable process reduces noise and increases verification confidence.

1. Define targets
List IPs/hosts and ensure explicit permission is recorded.
2. Configure task
Choose templates and authentication settings for deeper checks.
3. Run scan
Monitor performance and impact; avoid production disruption.
4. Analyze & remediate
Prioritize by CVSS, exploitability, and asset exposure; re-scan after fixes.
Authenticated scans
When you provide credentials the scanner can check installed packages and configuration files. This produces richer, more accurate findings but requires secure credential handling and approval in the rules of engagement.
Key Takeaway

Treat scanning as an iterative program: configure carefully, prioritize with context, and verify fixes with re-scans.

Report anatomy
  • Vulnerability title and description.
  • Severity and CVSS score.
  • Affected host and affected port/service.
  • Suggested remediation steps.
