Module 7 › Chapter 6.8 › Lab Scenario
Activity checklist
  1. Confirm you have written permission for the lab scope.
  2. Identify the target IP and run: nmap -sS <target_ip>.
  3. Run: nmap -sV -O <target_ip> to profile services and OS.
  4. If available, analyze the GVM report snippet and prioritize fixes.
  5. Implement fixes, document steps, and re-scan to verify closure.
Assessment idea
Which Nmap command did you choose for the initial scan and why? Describe the ethical check you performed before scanning.
Key Takeaway

Turn lab findings into documented fixes and verifiable evidence to close the security loop and support audits.
