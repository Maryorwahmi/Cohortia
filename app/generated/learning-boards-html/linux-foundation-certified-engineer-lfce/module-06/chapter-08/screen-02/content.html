Learning Objectives

Skills you will practice and why they matter for system security and operations.

Bloom: Learn → Understand → Apply → Master
01
Distinguish scanning vs pen testing
Explain the different goals, intrusiveness, and typical operators for scans versus pen tests.
Mnemonic: Scan = Sweep, Pen Test = Attempt
VERIFIED COMPETENCY MILESTONE
02
Run network discovery with Nmap
Use SYN, version and OS detection scans to inventory hosts and services for later assessment.
Mnemonic: Map before you probe
VERIFIED COMPETENCY MILESTONE
03
Use GVM/OpenVAS scans
Define targets and tasks, run scans, and collect reports to find known vulnerabilities.
Mnemonic: Targets → Tasks → Reports
VERIFIED COMPETENCY MILESTONE
04
Interpret reports & prioritize fixes
Use CVSS, exploitability, and asset exposure to decide which vulnerabilities to remediate first.
Mnemonic: Severity + Context = Priority
VERIFIED COMPETENCY MILESTONE
