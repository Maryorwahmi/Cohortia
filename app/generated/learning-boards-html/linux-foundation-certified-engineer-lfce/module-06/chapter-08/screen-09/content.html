Module 7 › Chapter 6.8 › Remediation & Verification
From finding to closure

Documented changes and verification prevent recurring vulnerabilities and support audits.

# Example remediation for SSH weak MACs
# 1. Edit /etc/ssh/sshd_config
#    Add: MACs hmac-sha2-512,hmac-sha2-256,umac-128@openssh.com
# 2. Restart sshd: sudo systemctl restart sshd
# 3. Verify with: nmap -sV -p 22 <host>  (or run a targeted GVM check)
Ticket contents
Include the finding, remediation steps, change window, rollback plan, and personnel responsible. Attach pre- and post-scan evidence.
Verification
Run a focused scan against the updated service and archive the resulting report to prove closure.
Key Takeaway

A fix is not complete until you verify it with a re-scan and keep records of the remediation for audits.

Practical checklist
  • Map vulnerability to package/config file and exact command.
  • Schedule change with rollback instructions.
  • Re-scan and archive before/after evidence.
