Terminal-style command examples

Run these in your scanner VM against a target VM you control and have permission to test.

# Identify target reachability
nmap -sn 192.168.1.0/24

# SYN scan for open TCP ports
nmap -sS 192.168.1.10

# Service version and OS detection
nmap -sV -O 192.168.1.10

# Aggressive profile (use only when authorized)
nmap -A 192.168.1.10
Suggested workflow
  1. Discover hosts with -sn.
  2. Run -sS to find open ports.
  3. Run -sV and -O for more details on interesting hosts.
  4. Map findings to remediation and re-scan to verify.
Safety note
Keep scans within the lab network and avoid high timing parameters on production systems that might cause disruptions.
Mapping to remediation
  • OpenSSH outdated → check package manager and update.
  • Apache version disclosure → change ServerTokens and patch.
  • Unknown service → deeper authenticated scan or host inspection.
