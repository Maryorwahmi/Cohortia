Safe rollout steps
  1. Open a persistent console session with tmux or screen.
  2. Schedule a rollback: echo "nft flush ruleset" | at now + 5 minutes.
  3. Apply your nft changes and test connectivity quickly.
  4. Cancel the rollback when verified and persist the ruleset to /etc/nftables.conf.
Example rollback command
echo "nft flush ruleset" | at now + 5 minutes
Common pitfall

Persisting a broken ruleset immediately can prevent remote recovery. Verify first, then save.

Verification checklist
  • Can you SSH in from an external IP?
  • Are HTTP and HTTPS reachable from a browser or curl test?
  • Can a machine in the trusted subnet reach management ports?
  • Does port forwarding reach the internal service?
If a test fails, rely on the rollback or the console to restore access, then iterate on the ruleset. Only persist when tests pass.
