NAT › DNAT vs SNAT
Destination NAT (DNAT)

Change destination address/port of incoming packets before routing decisions using prerouting.

sudo nft add table ip nat
sudo nft add chain ip nat prerouting { type nat hook prerouting priority -100; }
sudo nft add rule ip nat prerouting iifname "eth0" tcp dport 8081 dnat to 192.168.1.10:80
Why prerouting?
Packets must have their destination rewritten before the kernel decides where to route them, so the routing decision directs them to the correct internal host.
Source NAT (SNAT / Masquerade)

Change source addresses for outgoing packets after routing decisions using postrouting, commonly for masquerading internal networks.

sudo nft add chain ip nat postrouting { type nat hook postrouting priority 100; }
sudo nft add rule ip nat postrouting oifname "eth0" masquerade
Common mistake
Forgetting to enable IP forwarding in the kernel (net.ipv4.ip_forward) will prevent forwarded flows even if NAT rules appear correct.
Key Takeaway

DNAT belongs in prerouting; SNAT and masquerade belong in postrouting. Always enable and verify IP forwarding when forwarding packets between interfaces.
