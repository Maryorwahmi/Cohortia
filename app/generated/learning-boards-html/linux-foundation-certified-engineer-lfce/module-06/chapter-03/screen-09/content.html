Legacy › iptables & migration
iptables snapshot

Separate commands for IPv4 and IPv6, organized by tables and chains.

iptables -A INPUT -p tcp --dport 22 -j ACCEPT
When migrating, first capture iptables rules, run a translation utility to see the nftables equivalent, and then decide whether to import or redesign for clarity and performance.
Migration guidance
  • Use iptables-restore-translate to inspect conversions.
  • Prefer re-architecting rather than one-to-one translation to exploit sets and inet.
  • Test translated rules in a staging environment before production rollout.
Key Takeaway

Translate for quick inspection, but re-architect in nftables to reduce duplication and leverage modern features.
