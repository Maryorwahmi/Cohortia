Definition › Connection tracking
What is connection tracking?

A kernel facility that classifies packets as new, established, related, or invalid so the firewall can apply stateful rules.

Rule example
sudo nft add rule inet filter input ct state established,related accept
Best practice
  • Allow established and related to enable replies without opening new inbound ports.
  • Drop invalid state packets explicitly to reduce malformed traffic risks.
Concrete scenario

A client connects to your server's HTTPS port. The server replies. The connection tracker marks both directions as part of the same session, allowing the server's replies to be accepted if established is permitted.

Common mistake
Relying only on broad accept rules for replies instead of using ct state can allow unexpected inbound sessions. Be explicit.
Key Takeaway

Use connection tracking to keep stateful policies concise; always handle invalid state packets explicitly.
