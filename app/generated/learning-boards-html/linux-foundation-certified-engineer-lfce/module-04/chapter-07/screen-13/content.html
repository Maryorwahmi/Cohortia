Module 5 › Chapter 4.7 › Assessment Scenario
Question Summary

Which command allows only 192.168.2.10 to connect to MariaDB on port 3306? Explain why your choice follows least privilege and how you'd verify it.

Correct Command Example
sudo firewall-cmd --permanent --add-rich-rule='rule family="ipv4" source address="192.168.2.10" port port="3306" protocol="tcp" accept'
sudo firewall-cmd --reload
sudo firewall-cmd --list-all
Verification: attempt a connection from 192.168.2.10 (allowed) and from another host (denied).
