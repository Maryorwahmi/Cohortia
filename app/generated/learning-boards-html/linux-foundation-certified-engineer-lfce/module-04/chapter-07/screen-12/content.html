Module 5 › Chapter 4.7 › Lab: Harden Nginx
Step-by-step checklist
  1. Confirm firewalld running and remove default services if restricting access.
  2. Add rich rule to allow HTTP from client IP and add HTTPS for later TLS work.
  3. Create /srv/web/mysecureapp/html and server block; test with nginx -t.
  4. If 403 occurs, switch SELinux to permissive, gather audit logs, then apply semanage/restorecon fixes.
  5. Apply Nginx hardening: server_tokens off, disable unused modules, verify headers.
Commands to run
sudo systemctl enable --now firewalld
sudo firewall-cmd --permanent --remove-service=http
sudo firewall-cmd --permanent --remove-service=https
sudo firewall-cmd --permanent --add-rich-rule='rule family="ipv4" source address="/32" port port="80" protocol="tcp" accept'
sudo firewall-cmd --permanent --add-service=https
sudo firewall-cmd --reload

# Create custom root and test
sudo mkdir -p /srv/web/mysecureapp/html
# ... add index and server block
nginx -t && sudo systemctl reload nginx
