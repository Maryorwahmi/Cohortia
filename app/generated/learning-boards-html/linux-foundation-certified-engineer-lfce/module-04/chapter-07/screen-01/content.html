Securing Web and Database Servers

Learn precise firewall rules, mandatory access control configuration, server hardening patterns, and log-based detection to protect services and data.

Firewall: control external access
MAC: enforce process policies
Logging: detect and respond
In this lesson
You will follow a terminal-first lab workflow: restrict service exposure with firewalld or iptables, correct SELinux/AppArmor contexts that block access, harden server configuration, and validate changes with logs.
Layered Security Overview
Firewall → MAC → Hardening → Monitoring
Firewall rules limit who can reach ports like 80, 443, and 3306.
SELinux/AppArmor prevent processes from accessing files or network sockets even with permissive file permissions.
Logs confirm whether a change fixed the problem or introduced denials.
Explore Key Topics
Precise Firewall Rules
Open only necessary services and restrict database ports to trusted IPs.
SELinux / AppArmor
Label custom paths and enable booleans to allow needed behaviors without weakening policy.
Hardening & Logs
Disable unnecessary modules, enforce least privilege, and monitor access and audit logs.
