Module 5 › Chapter 4.7 › Database Hardening
Configuration Best Practices
  • Use mysql_secure_installation to remove test users and set strong root password.
  • Set bind-address appropriately; 127.0.0.1 for local-only, or specific IP for controlled access.
  • Disable remote root logins and grant least privilege to application accounts.
  • Restrict /var/lib/mysql ownership and SELinux/AppArmor contexts for the data directory.
Example & Commands
# Allow only a specific app server to reach MariaDB
sudo firewall-cmd --permanent --add-rich-rule='rule family="ipv4" source address="192.168.2.10" port port="3306" protocol="tcp" accept'
sudo firewall-cmd --reload

# SELinux context for MySQL data directory (if custom)
sudo semanage fcontext -a -t mysqld_db_t "/custom/mysql(/.*)?"
sudo restorecon -Rv /custom/mysql
Key Takeaway

Combine bind-address, firewall rules, and least-privilege accounts to prevent unnecessary database exposure.
