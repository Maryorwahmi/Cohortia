Profiles & Modes
AppArmor binds profiles to binaries. Use aa-enforce to set enforcement and aa-disable when troubleshooting. Complain mode is your safe way to collect evidence before enforcing.
Check status: sudo apparmor_status
Enforce: sudo aa-enforce /etc/apparmor.d/usr.sbin.nginx
Disable: sudo aa-disable /etc/apparmor.d/usr.sbin.nginx
Troubleshooting
If a service is denied, check dmesg and journalctl for 'apparmor' or 'audit' lines, tune the profile, and test again in complain mode before enforcing.
Caution

Editing or disabling profiles without testing can break services or remove important protections.
