Definition
What SELinux enforces

SELinux enforces policy rules using contexts. Types like httpd_sys_content_t control what resources a process can access, independent of traditional file permissions.

sudo semanage fcontext -a -t httpd_sys_content_t "/srv/web/myapp(/.*)?"
sudo restorecon -Rv /srv/web/myapp
sudo setsebool -P httpd_can_network_connect 1
# To test permissively
sudo setenforce 0
# Check denials and propose rules
sudo ausearch -c 'httpd' --raw | audit2allow -M myapache
sudo semodule -i myapache.pp
Explanation & Pitfalls
  • Label custom content correctly; otherwise the server will return 403 or fail to read files.
  • Use setsebool for common toggles instead of creating broad allow rules.
  • Test in permissive mode and inspect audit logs before applying permanent module changes.
Common Mistake

Disabling SELinux to fix an access problem masks the underlying misconfiguration and eliminates an important security layer.
