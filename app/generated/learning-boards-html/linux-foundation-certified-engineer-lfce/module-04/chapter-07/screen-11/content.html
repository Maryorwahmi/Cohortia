Module 5 › Chapter 4.7 › Log Analysis & Monitoring
What to monitor
  • Web access and error logs for unusual request patterns and spikes in errors.
  • Database logs for failed connections, authentication failures, and suspicious queries.
  • Audit logs for SELinux/AppArmor denials or unexpected privilege escalations.
  • System logs for repeated failed logins and other authentication anomalies.
Quick commands & checks
sudo journalctl -u nginx -f
sudo tail -F /var/log/nginx/access.log /var/log/nginx/error.log
sudo tail -F /var/log/mariadb/mariadb.log
sudo ausearch -m AVC -ts recent
# For audit-to-allow troubleshooting
sudo ausearch -c 'nginx' --raw | audit2allow -M mynginx
Pro Tip

Tail logs while reproducing the error to see immediate evidence that a fix worked or that further tuning is required.
