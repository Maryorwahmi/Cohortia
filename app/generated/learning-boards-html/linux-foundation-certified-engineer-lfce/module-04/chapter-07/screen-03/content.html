Practical verification cards
Firewall Check
Reload rules and run list-all or iptables-save to ensure only intended ports are open. Remember to allow SSH before adding a DROP policy.
SELinux/AppArmor Check
Search audit logs for denials and generate minimal allow modules when necessary. Test in permissive mode first to avoid service breakage.
Server Hardening Check
Confirm server headers, disabled modules, and directory permissions with curl, nginx -t, and file ownership checks.
Common verification commands
sudo firewall-cmd --list-all
sudo iptables -L -n --line-numbers
sudo ausearch -c 'nginx' --raw | audit2allow -M mynginx
sudo semanage fcontext -a -t httpd_sys_content_t "/srv/web/myapp(/.*)?" && sudo restorecon -Rv /srv/web/myapp
Use these to confirm policy and to build repeatable verification steps for your environment.
