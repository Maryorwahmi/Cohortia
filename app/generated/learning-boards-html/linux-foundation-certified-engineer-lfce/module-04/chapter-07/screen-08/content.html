Module 5 › Chapter 4.7 › Hardening Web Servers
Checklist
  • Disable directory listing (Options Indexes / autoindex off).
  • Remove or disable unused modules to shrink the attack surface.
  • Hide server tokens/versions (ServerTokens Prod / server_tokens off).
  • Restrict AllowOverride to prevent uncontrolled .htaccess rules.
  • Ensure document root owned by root, readable but not writable by web user; logs writable by web user only.
http {
    server_tokens off; # Nginx to hide version
}

# Test & reload
nginx -t && sudo systemctl reload nginx
Example & Misconception

Example: setting server_tokens off prevents clients from seeing Nginx version. Misconception: file permissions like 777 make debugging easy; in reality they enable a compromised process to modify content and should be avoided.

Key Takeaway

Hardening is about removing unnecessary capabilities and then validating that service behavior remains correct through tests and logs.
