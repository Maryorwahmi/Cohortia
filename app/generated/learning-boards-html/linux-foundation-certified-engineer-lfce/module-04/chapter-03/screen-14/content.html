Assessment Idea

Diagnose missing client IP

Symptoms
Backend logs show requests coming from the proxy server IP rather than the original client addresses.
Root cause
proxy_set_header directives are missing or misconfigured in the Nginx location block that forwards requests.
Fix
proxy_set_header Host $host;
proxy_set_header X-Real-IP $remote_addr;
proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
proxy_set_header X-Forwarded-Proto $scheme;
Verification
After adding headers, run nginx -t, reload, then curl and check backend logs for the original client IP entries.
Key Takeaway

Passing client headers to backends is essential for correct logging and security-related logic; proxy_set_header is the directive to check.
