Hands-on Activity

Lab steps (terminal-first)

Static site setup
sudo mkdir -p /var/www/static.example.com/html
sudo tee /var/www/static.example.com/html/index.html > /dev/null <<'HTML'
<html><body>Static site</body></html>
HTML
# Create server block using the static example
sudo nginx -t
sudo systemctl reload nginx
Flask app & proxy
sudo apt install python3 python3-pip -y
pip install Flask
# create app.py with the provided Flask content and run
nohup python3 app.py &
# configure app.example.com server block with proxy_pass and headers
sudo nginx -t
sudo systemctl reload nginx
Verification
Edit /etc/hosts to point static.example.com and app.example.com to your server and use curl or a browser to check both sites and headers.
Troubleshoot
If a site fails, run nginx -t, inspect /var/log/nginx/* logs, check firewall rules, and confirm SELinux booleans on RHEL systems.
Key Takeaway

Follow the lab steps methodically, test frequently, and use logs, nginx -t, and firewall/SELinux checks when troubleshooting.
