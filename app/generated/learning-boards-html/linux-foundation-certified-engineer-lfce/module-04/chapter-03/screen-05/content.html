Process Flow

Install and verify

Follow a short sequence: install, enable, open firewall, verify service and connectivity.

RHEL-family commands
sudo dnf install epel-release -y
sudo dnf install nginx -y
sudo systemctl enable nginx --now
sudo firewall-cmd --permanent --add-service=http
sudo firewall-cmd --permanent --add-service=https
sudo firewall-cmd --reload
Debian-family commands
sudo apt update
sudo apt install nginx -y
sudo systemctl enable nginx --now
sudo ufw allow 'Nginx Full'
sudo ufw enable
Common mistake
Installing without opening firewall ports or forgetting to enable EPEL prevents installation or external access.
Key Takeaway

Follow install → enable → firewall → verify steps and confirm the daemon is active before continuing to config changes.
