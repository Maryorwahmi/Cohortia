Definition

Files and directives

nginx.conf holds global settings; server blocks define domains and behavior for each site.

listen
Bind address and port, e.g., listen 80; or listen [::]:80; for IPv6.
server_name
Domain names the block responds to; specificity avoids accidental matches.
root & index
Document root and default files like index.html. Use correct paths to avoid 404s.
Example server block
server {
    listen 80;
    listen [::]:80;
    server_name static.example.com www.static.example.com;
    root /var/www/static.example.com/html;
    index index.html index.htm;

    location / {
        try_files $uri $uri/ =404;
    }

    error_log /var/log/nginx/static.example.com_error.log;
    access_log /var/log/nginx/static.example.com_access.log;
}
Misconfiguration pitfall

Using incorrect root paths or misplacing files is the most common cause of site 404s; verify filesystem paths and permissions.

Key Takeaway

Understand directive roles and always test with nginx -t before reloading to avoid service interruption.
