Skills You’ll Practice

Commands, checks, and verification steps

Hands-on checks
Install & enable
Run package install, enable systemd, and open firewall ports. Verify the service is active and reachable.
Server block validation
Create server files, test with nginx -t, and reload. Confirm the domain returns the expected index page.
Reverse proxy checks
Run a local app, set proxy_pass, include proxy_set_header directives, and confirm backend sees original Host and X-Real-IP.
Load balancing verification
Define an upstream pool, send repeated requests, and observe distribution across backends or log rotation.
