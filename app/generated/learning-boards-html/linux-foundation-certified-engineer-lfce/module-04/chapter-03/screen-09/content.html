Definition

Test then reload

Validate with nginx -t, then reload to apply changes without dropping active connections.

Commands
sudo nginx -t
sudo systemctl reload nginx
# Or to restart fully
sudo systemctl restart nginx
Troubleshooting example
If nginx -t reports a duplicate listen or invalid path, fix the indicated file and line before reloading. Review error_log for context if failures persist.
Misconception
Restarting is not always harmless; reload is safer for live workloads because it preserves existing connections.
Key Takeaway

Use nginx -t as a gatekeeper before reloading to avoid configuration-induced downtime.
