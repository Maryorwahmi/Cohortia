Learning Objectives

Learn, Understand, Apply, Master

Bloom: Learn → Understand → Apply → Master
01
Install and manage Nginx
Install via package manager, enable the service, and open HTTP/HTTPS in the firewall. This matters because correct installation and firewall setup are prerequisites for serving traffic.
Verified competency milestone
02
Configure server blocks
Define server_name, root, index, and location to host multiple domains. This allows a single host to serve different sites reliably and predictably.
Verified competency milestone
03
Set up Nginx as a reverse proxy
Use proxy_pass and proxy_set_header to forward requests and preserve client information. This is essential for accurate logging and application logic on the backend.
Verified competency milestone
04
Implement basic load balancing
Configure an upstream block to distribute traffic across backends. This increases availability and spreads load for simple scaling.
Verified competency milestone
