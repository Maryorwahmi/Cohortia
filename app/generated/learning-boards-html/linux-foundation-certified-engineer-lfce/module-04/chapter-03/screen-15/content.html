Module 04 › Chapter 4.3 › Key Concepts
Nginx
An event-driven web server, reverse proxy, and load balancer for efficient edge handling.
Server Block
Defines configuration for a domain or IP: listen, server_name, root, index, and location rules.
Reverse Proxy
proxy_pass forwards requests; proxy_set_header passes Host and client IP to the backend.
Summary

Remember to validate with nginx -t, reload gracefully, configure firewall and SELinux contexts as needed, and pass client headers when proxying.
