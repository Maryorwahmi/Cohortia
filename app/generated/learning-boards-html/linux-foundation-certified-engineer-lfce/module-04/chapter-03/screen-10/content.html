Architecture

Upstream example

upstream app_pool {
    server 10.0.0.11:5000;
    server 10.0.0.12:5000;
}

server {
    listen 80;
    server_name app.example.com;

    location / {
        proxy_pass http://app_pool;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
Verification
  • Send repeated requests and check which backend logged each request.
  • Consider sticky sessions only when backend state requires it.
Operational note
Nginx provides basic load balancing out of the box. For active health checks or advanced algorithms, add the proper modules or use a dedicated balancer.
Misconception
Default Nginx does not perform active health checks of backends without additional configuration or modules.
Key Takeaway

Upstream blocks enable simple round-robin balancing; plan monitoring or health checks depending on production needs.
