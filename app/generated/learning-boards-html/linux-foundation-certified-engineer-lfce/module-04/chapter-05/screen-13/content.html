Hands-on Activity › Install, Secure, Create DB/User

Checklist

  1. Install server & client and enable the service.
  2. Open firewall for MariaDB/MySQL if remote access is required.
  3. Run sudo mysql_secure_installation and complete prompts.
  4. Connect as root and run CREATE DATABASE and CREATE USER.
  5. GRANT appropriate privileges and FLUSH PRIVILEGES.
  6. Test connections as the new user and verify reduced access.

Starter SQL

CREATE DATABASE webapp_db;
CREATE USER 'webapp_user'@'localhost' IDENTIFIED BY 'WebAppP@ssw0rd!';
GRANT ALL PRIVILEGES ON webapp_db.* TO 'webapp_user'@'localhost';
FLUSH PRIVILEGES;
Verify by running: mysql -u webapp_user -p webapp_db and then try mysql -u webapp_user -p mysql which should fail.
