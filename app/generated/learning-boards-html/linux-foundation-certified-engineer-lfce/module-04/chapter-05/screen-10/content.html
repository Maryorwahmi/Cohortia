Process › Grant & Flush

Grant example

GRANT SELECT, INSERT, UPDATE, DELETE
  ON webapp_db.*
  TO 'webapp_user'@'localhost';

FLUSH PRIVILEGES;

SHOW GRANTS FOR 'webapp_user'@'localhost';

Replace ALL PRIVILEGES with specific privileges whenever possible. Verify with SHOW GRANTS and test connections.

Common pitfalls

  • Forgetting FLUSH PRIVILEGES when required.
  • Granting ALL PRIVILEGES on *.* to application users.
  • Assuming changes apply to existing connections immediately.
Key Takeaway

Limit privileges to required operations, flush grant tables when needed, and test with actual user connections.
