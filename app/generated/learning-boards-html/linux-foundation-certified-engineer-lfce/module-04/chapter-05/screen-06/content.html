Process Flow › mysql_secure_installation

Run the script

sudo mysql_secure_installation
Expected prompts include setting root password, removing anonymous users, disallowing remote root login, and removing the test database.
Why set root password?
Prevents privilege escalation and unauthorized full access.
Why remove anonymous users?
Anonymous accounts allow unauthenticated access which is rarely desirable in production.

Post-script checks

  • Attempt remote root login to confirm it is disabled.
  • Check mysql.user to ensure anonymous entries are gone.
  • Confirm no test database exists.
Common Mistake

Skipping this script leaves default, weakly-configured accounts and opens the server to trivial attacks.
