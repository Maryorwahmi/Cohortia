Definition › Common mistakes

Access denied causes

  • FLUSH PRIVILEGES not executed after GRANT or direct table edits.
  • User host qualifier does not match client origin.
  • Incorrect password entry or authentication plugin mismatch.
Assessment tip
If INSERT fails for a granted user, the most likely reason is that FLUSH PRIVILEGES was not executed after GRANT.

SELinux / AppArmor

If MariaDB fails to start after changes to data directories or file ownership, check SELinux audit logs or AppArmor messages. These LSMs can silently block access.

Quick Troubleshoot

Inspect journalctl -u mariadb and /var/log/audit/audit.log for denied messages and adjust contexts or profiles accordingly.
