Definition › my.cnf & bind-address

File locations & sections

Typical paths: /etc/my.cnf (RHEL) and /etc/mysql/my.cnf (Debian). Sections include [mysqld], [client], [mysqld_safe], each holding related directives.

Example directive
[mysqld]
bind-address = 127.0.0.1
# other directives: max_connections, log_error

Network exposure

bind-address controls interfaces the server listens on. Use 127.0.0.1 for local-only access, a specific internal IP for controlled remote access, and avoid 0.0.0.0 unless firewalled.
Why it matters
Restricting interfaces reduces attack surface and is often the first line of defense before firewalling.
Troubleshoot
After edits, restart the server and check journalctl and SELinux/AppArmor logs if the service fails to start.
