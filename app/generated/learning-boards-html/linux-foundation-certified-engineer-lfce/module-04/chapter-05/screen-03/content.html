Objectives — Security & Operations

Hands-on security steps and operational checks you must be able to perform.

Run mysql_secure_installation
Complete the interactive hardening script to set root password and remove test/anonymous users to reduce attack surface.
VERIFIED COMPETENCY MILESTONE
06
Apply least privilege & FLUSH PRIVILEGES
Grant minimal permissions for an application user and remember to reload grant tables so changes take effect immediately.
VERIFIED COMPETENCY MILESTONE
07
Configure bind-address & firewall
Limit listening interfaces in my.cnf and restrict port 3306 access to trusted networks or VPNs for production safety.
VERIFIED COMPETENCY MILESTONE
08
Monitor logs & respect SELinux/AppArmor
Enable and inspect logs, and check SELinux or AppArmor messages when the server fails to start after configuration changes.
VERIFIED COMPETENCY MILESTONE
Complete these objectives as checkboxes in your lab: run the secure script, restrict bind-address, grant least privilege, reload privileges, and confirm logs are healthy.
