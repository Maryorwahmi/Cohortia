Comparison › Host qualifiers
localhost
Connect only from the same machine. Strong for single-host apps and local testing.
Example: 'webapp_user'@'localhost'
Specific IP
Allow only a known server or subnet. Good for predictable architectures with fixed IPs.
Example: 'remoteuser'@'192.168.1.100'
Wildcard %
Allows any host to connect. Use only with strong network controls and monitoring.
Example: 'anyuser'@'%'
Key Takeaway

Always match user host qualifiers to your network model and prefer the narrowest scope that satisfies application requirements.

Check your setup

If a user cannot connect, verify the host qualifier matches the client address and that firewall rules allow the connection.
