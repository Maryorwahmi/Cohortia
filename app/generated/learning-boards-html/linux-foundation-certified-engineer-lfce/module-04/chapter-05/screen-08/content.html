Core Concept › mysql client

Connect & Inspect

# Connect as root
mysql -u root -p

# Show databases
SHOW DATABASES;

# Show users and hosts
SELECT user, host FROM mysql.user;

Use these commands to confirm your installation and verify host restrictions for existing accounts.

Create DB, user, grant

CREATE DATABASE webapp_db;
CREATE USER 'webapp_user'@'localhost' IDENTIFIED BY 'WebAppP@ssw0rd!';
GRANT ALL PRIVILEGES ON webapp_db.* TO 'webapp_user'@'localhost';
FLUSH PRIVILEGES;
After creating the user and granting privileges, test by connecting as the new user to the application database to confirm expected access and rejection for other databases.
