Process Flow › Installing MariaDB / MySQL

RHEL / CentOS / Rocky

sudo dnf install mariadb-server mariadb -y
sudo systemctl enable mariadb --now
sudo firewall-cmd --permanent --add-service=mysql
sudo firewall-cmd --reload

Enable the service and update the firewall so the server is reachable by trusted hosts. Check status with systemctl status mariadb.

Debian / Ubuntu

sudo apt update
sudo apt install mariadb-server mariadb-client -y
sudo systemctl enable mariadb --now
sudo ufw allow 'MariaDB'
sudo ufw enable

On Debian-family systems, ufw commands open the default MariaDB service. If you need MySQL vendor packages, add the official repository before installing mysql-server.

Pro Tip
After installation, run a quick status and journalctl -u mariadb to verify startup messages before proceeding to hardening.
Common Mistake
Installing without enabling the service or opening firewall rules can make the DB unreachable even though packages are present.
Check
Confirm listening ports with ss -ltnp and verify the server listens only on intended interfaces.
