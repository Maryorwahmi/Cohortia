Learning Objectives

Progress from installation to secure user management and basic operations.

Learn → Understand → Apply → Master
01
Install & start MariaDB/MySQL
Use package tools to install server/client, enable and start the service, and open the DB service port in the firewall.
VERIFIED COMPETENCY MILESTONE
02
Configure my.cnf directives
Identify sections like [mysqld] and directives such as bind-address and logging, and understand their security implications.
VERIFIED COMPETENCY MILESTONE
03
Create and manage users & databases
Write CREATE DATABASE, CREATE USER, and GRANT statements that follow least-privilege principles and host restrictions.
VERIFIED COMPETENCY MILESTONE
04
Use the mysql client for administration
Connect as root or a specific user to execute SQL, inspect user hosts, and validate privilege boundaries with real commands.
VERIFIED COMPETENCY MILESTONE
These objectives align to hands-on lab steps: install, secure, configure, create a webapp database and a localhost-only user, and verify restricted access.
