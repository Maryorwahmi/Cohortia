Core Concept › What is MariaDB / MySQL

Definition & Model

Relational DBs store data in tables with rows and columns. The server accepts SQL from clients and enforces authentication by user and host.

Key terms
  • Table: collection of rows and columns
  • User@host: authentication identity that includes connection origin
  • SQL: language used to manage data and permissions
Concrete example
Create a dedicated app user that can connect only from localhost so external sources cannot misuse credentials.
Key Takeaway

Treat user host qualifiers as first-class access controls; design users for the application host, not for convenience.

Analogy

Think of the server as a secured office that admits employees by both badge and location: the badge is the username, and location is the host allowed for that badge.

Why this matters
  • Restricting host reduces exposure to stolen credentials.
  • Least privilege limits damage if a user account is compromised.
Common misconception

Developers sometimes create users with '%' host for convenience; this opens access from anywhere and defeats host-level security controls.
