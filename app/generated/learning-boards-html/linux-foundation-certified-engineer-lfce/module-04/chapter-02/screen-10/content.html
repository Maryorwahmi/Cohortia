What mod_security does
mod_security inspects requests and applies rules. It can run in DetectionOnly to log triggers or in Prevention mode to block requests.
OWASP CRS

The OWASP Core Rule Set is a baseline ruleset to detect common attacks. Use it as a starting point and tune rules to reduce false positives.

Deployment steps
  1. Install mod_security package for your distribution.
  2. Enable OWASP CRS and set SecRuleEngine DetectionOnly.
  3. Review audit logs and tune rules to avoid false positives.
  4. Enable Prevention mode when confident.
Warning
Enabling prevention without tuning can block legitimate requests. Use logs to guide rule adjustments.
Key Takeaway

Start in detection, learn from logs, tune rules, then enable prevention to harden your site safely.
