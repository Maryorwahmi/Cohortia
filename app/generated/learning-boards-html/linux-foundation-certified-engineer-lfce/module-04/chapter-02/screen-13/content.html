Troubleshooting Checklist
1. Syntax
Run apachectl configtest to catch syntax errors before reload.
2. Logs
Inspect error_log for permission, module load, or directive errors.
3. Permissions
Verify certificate key ownership and file modes; do not relax key permissions to workaround errors.
4. SELinux
If on RHEL, confirm file contexts and use semanage/restorecon when necessary.
5. Modules
Ensure required modules are installed and enabled for your platform.
6. MPM & Resources
Check active MPM and system memory; adjust MaxRequestWorkers to avoid exhaustion.
Key Takeaway

A systematic checklist focused on syntax, logs, permissions, modules, and MPMs resolves most Apache issues efficiently.
