Module 4 › Chapter 4.2 › Config Testing
Commands to know
apachectl configtest
# or
apachectl -t
# Check active MPM
httpd -V | grep -i mpm
# Firewall example
sudo firewall-cmd --permanent --add-service=https && sudo firewall-cmd --reload
Use these checks every time you change virtual hosts, SSL settings, modules, or MPMs. Logs are your primary debugging tool for startup errors.
Troubleshooting pattern
  1. Run configtest and fix reported syntax errors.
  2. Check error_log for permission or module load failures.
  3. Confirm certificate and key paths and permissions.
  4. Verify SELinux contexts on RHEL if Apache cannot read keys.
Key Takeaway

A predictable change process — test, inspect logs, then reload — prevents unexpected outages when tuning Apache.
