Validation & Safety
Practical checks and safe rollout practices for production changes.
Quick checks
  • Run apachectl configtest before reloading.
  • Check active MPM: httpd -V | grep -i mpm
  • Verify certificate paths and permissions; key should be restrictive.
WAF rollout
Start mod_security in DetectionOnly, review logs, then enable prevention once false positives are addressed.
Cache hygiene
Understand Cache-Control headers and invalidation to avoid serving stale content to users.
SELinux note
On RHEL, use semanage fcontext and restorecon if Apache cannot read keys due to contexts.
