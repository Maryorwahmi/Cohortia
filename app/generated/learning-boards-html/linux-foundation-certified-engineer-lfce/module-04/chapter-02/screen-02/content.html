Learning Objectives
Learn, understand, apply, and verify key Apache production skills.
01
Configure SSL/TLS
Enable HTTPS with correct certificate, key, and chain; verify with Apache restart and browser check.
VERIFIED COMPETENCY MILESTONE
02
Use common Apache modules
Enable and configure modules such as mod_rewrite, mod_cache, and mod_security for capabilities and protection.
VERIFIED COMPETENCY MILESTONE
03
Tune MPMs and caching
Select and tune prefork, worker, or event; configure mod_cache/mod_disk_cache for static content acceleration.
VERIFIED COMPETENCY MILESTONE
04
Harden with mod_security and troubleshoot
Install mod_security in DetectionOnly initially, tune rules, and diagnose common SSL/module failures.
VERIFIED COMPETENCY MILESTONE
