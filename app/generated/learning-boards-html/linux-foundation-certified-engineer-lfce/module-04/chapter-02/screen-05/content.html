Module 4 › Chapter 4.2 › Enable HTTPS
Step-by-step
  1. Ensure mod_ssl is installed and loaded on your platform.
  2. Create or obtain certificate, key, and chain files and place them in secure paths.
  3. Add a <VirtualHost *:443> block with SSLEngine on and certificate directives.
  4. Add a <VirtualHost *:80> block to Redirect permanent / to HTTPS.
  5. Run apachectl configtest, open port 443 in firewall, then reload Apache.
Example firewall command
sudo firewall-cmd --permanent --add-service=https && sudo firewall-cmd --reload
Code snippet
<VirtualHost *:443>
    ServerAdmin webmaster@secureapp.com
    DocumentRoot /var/www/secureapp/html
    ServerName secureapp.com

    SSLEngine on
    SSLCertificateFile /etc/pki/tls/certs/secureapp.com.crt
    SSLCertificateKeyFile /etc/pki/tls/private/secureapp.com.key
    SSLCertificateChainFile /etc/pki/tls/certs/secureapp.com_chain.crt
</VirtualHost>

<VirtualHost *:80>
    ServerName secureapp.com
    Redirect permanent / https://secureapp.com/
</VirtualHost>
Common mistake

Not running apachectl configtest before reloading often leads to downtime; always test configuration syntax first.
