Common Modules
  • mod_rewrite — rule-based URL rewriting for friendly URLs and redirects.
  • mod_proxy — proxy and reverse-proxy capabilities for backend services.
  • mod_deflate — compress responses to save bandwidth.
  • mod_cache / mod_disk_cache — cache static responses on disk.
  • mod_security — Web Application Firewall to detect and prevent attacks.
Enabling modules

On Debian use a2enmod module_name and systemctl reload apache2. On RHEL ensure the package is installed or the module is compiled, then load it and reload Apache.

Example scenario
You enable mod_rewrite to redirect old page URLs to new ones. After enabling, test rules with a single vhost and avoid enabling globally until rules are stable.
Common mistake
Enabling many modules without testing causes unexpected interactions and resource overhead. Turn on only the modules you need.
Pro Tip

Document module changes in your runbook and apply them in a maintenance window for production sites.
