MPM Profiles
prefork
One process per connection. Stable for non-threaded modules but memory-intensive.
worker
Multiple processes with multiple threads each. More efficient memory usage and better concurrency.
event
Similar to worker but optimized for keep-alive by offloading waiting connections. Recommended for high-traffic modern sites.
How to check active MPM
httpd -V | grep -i mpm
Misconception

Increasing MaxRequestWorkers without measuring memory is dangerous; it can cause system-wide swapping or process crashes. Tune based on observations.

Key Takeaway

Match your MPM to application thread-safety and concurrency needs, then tune conservatively.
