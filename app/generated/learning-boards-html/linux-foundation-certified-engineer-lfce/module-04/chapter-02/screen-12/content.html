Module 4 › Chapter 4.2 › SELinux & Permissions
Permission checklist
  • Ensure private key file mode is restrictive, e.g., 600 owned by root:root.
  • Confirm Apache can read certificate files from their configured paths.
  • Use semanage fcontext and restorecon if files are outside standard locations.
Never loosen key permissions to make Apache start; instead correct SELinux contexts or move files to approved locations and restore contexts.
Example SELinux commands
Use semanage fcontext to add a file context and restorecon to apply it. After applying contexts, retry the Apache start; logs will indicate if the files remain blocked.
Common mistake
Chmod 644 on a private key to make it readable is insecure. Use SELinux context fixes instead of relaxing permissions.
Key Takeaway

Preserve private key secrecy and use SELinux tools to grant Apache access safely if needed.
