Module 4 › Chapter 4.2 › Switch & Tune MPM
Example MPM configuration (event)
<IfModule mpm_event_module>
    StartServers             2
    MinSpareThreads         25
    MaxSpareThreads         75
    ThreadsPerChild         25
    MaxRequestWorkers      150
    MaxConnectionsPerChild   0
</IfModule>
Switching steps
  1. Ensure only one MPM is enabled in config.
  2. Edit the MPM block with conservative values.
  3. Run apachectl configtest and reload Apache.
  4. Monitor memory and request rates to iterate on values.
Practical guidance
Start with the example values as a baseline on a test server. Use monitoring to detect memory pressure, then adjust MaxRequestWorkers down if usage approaches system RAM limits.
Common mistake
Changing MPMs without checking linked modules may break compatibility for non-thread-safe modules like mod_php; verify module thread-safety first.
Key Takeaway

Change MPMs in a controlled manner, test, and tune conservatively based on live metrics.
