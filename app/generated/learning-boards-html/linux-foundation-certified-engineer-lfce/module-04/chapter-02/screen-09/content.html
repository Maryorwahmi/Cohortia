Module 4 › Chapter 4.2 › Caching
Example mod_cache block
<IfModule mod_cache.c>
    <IfModule mod_disk_cache.c>
        CacheRoot "/var/cache/apache2/mod_cache_disk"
        CacheEnable disk /
        CacheDirLevels 2
        CacheDirLength 1
        CacheMaxFileSize 10000000
        CacheMinFileSize 1000
        CacheLock on
        CacheLockPath /tmp/mod_cache_lock
        CacheLockMaxAge 5
        CacheIgnoreCacheControl On
        CacheIgnoreQueryString Off
        CacheMaxExpire 86400
        CacheLastModifiedFactor 0.1
    </IfModule>
</IfModule>
This block creates a disk cache root and configures size, locking, and expiry behavior for cached assets. Ensure the cache root has sufficient disk space and correct ownership.
When to cache
  • Static files such as images, CSS, and JS are good candidates.
  • Avoid caching personalized or frequently changing dynamic pages without a clear invalidation mechanism.
  • Use Cache-Control headers from the application to coordinate expiration policies.
Pitfall
Turning off CacheIgnoreQueryString can cause query-based resources to be cached incorrectly; understand your application's query semantics.
Key Takeaway

Implement disk caching for static content, size the cache, and use headers and invalidation to avoid stale assets.
