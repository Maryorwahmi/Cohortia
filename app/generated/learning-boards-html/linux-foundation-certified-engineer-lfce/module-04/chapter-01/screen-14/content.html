Module 4 › Chapter 4.1 › Key Concepts
Install & Start
Install the right package, enable at boot, and open firewall ports 80/443 so the server is reachable.
Virtual Hosts
Use VirtualHost blocks to map hostnames to DocumentRoots and logs; ensure unique ServerName values.
Permissions & SELinux
Set ownership and permissions and, on RHEL, correct SELinux context to allow Apache to read site files.
Final takeaway

Practice a complete flow: install, create document roots, configure VirtualHosts, test syntax, open firewall, adjust SELinux if needed, and verify from a client.
