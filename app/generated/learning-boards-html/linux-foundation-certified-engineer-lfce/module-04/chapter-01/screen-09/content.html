Module 4 › Chapter 4.1 › RHEL vs Debian
RHEL-family
  • Main config: /etc/httpd/conf/httpd.conf
  • Site files: /etc/httpd/conf.d/
  • Logs: /var/log/httpd/
Debian-family
  • Main config: /etc/apache2/apache2.conf
  • Sites: /etc/apache2/sites-available/ and sites-enabled/
  • Helpers: a2ensite / a2dissite
Common mistake

Creating a file in sites-available without running a2ensite leaves the site disabled. Use the distro helper to enable and then run configtest.
