Definition

Document Root explained

The directory Apache exposes as the site root. Ensure it exists and Apache can read its contents.

Concrete commands
sudo mkdir -p /var/www/example.com/html sudo chown -R apache:apache /var/www/example.com # or on Debian sudo chown -R www-data:www-data /var/www/example.com Create index.html and visit the site IP in a browser.
Example site file
<!DOCTYPE html>
<html>
<head>
  <title>Site Example</title>
</head>
<body>
  <h1>Welcome to example.com</h1>
  <p>This is a test page served from the DocumentRoot.</p>
</body>
</html>
Common pitfall

Files owned by root with restrictive permissions or incorrect SELinux context cause Apache to return 403 Forbidden even when the file exists.

Key Takeaway

Create the DocumentRoot, set ownership to Apache's user, and test a simple index to confirm the server can read files.
