Module 4 › Chapter 4.1 › SELinux
What SELinux does

SELinux applies security labels that may deny httpd access even when Unix permissions permit it. Fix contexts instead of disabling SELinux.

Command example
sudo semanage fcontext -a -t httpd_sys_content_t "/var/www/example.com(/.*)?"
sudo restorecon -Rv /var/www/example.com
Debug tip

Inspect /var/log/audit/audit.log for AVC denials that indicate SELinux is blocking httpd access.

Key Takeaway

When file permissions look correct but Apache still gets 403, suspect SELinux and correct file contexts with semanage and restorecon.
