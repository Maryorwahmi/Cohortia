Definition

What a Virtual Host does

It binds a hostname to a DocumentRoot, allowing multiple sites to co-exist on one server instance.

Basic template (RHEL or Debian)
<VirtualHost *:80>
    ServerAdmin webmaster@example.com
    DocumentRoot /var/www/example.com/html
    ServerName example.com
    ServerAlias www.example.com
    ErrorLog /var/log/httpd/example.com_error.log
    CustomLog /var/log/httpd/example.com_access.log combined

    <Directory /var/www/example.com/html>
        Options Indexes FollowSymLinks
        AllowOverride All
        Require all granted
    </Directory>
</VirtualHost>
Concrete scenario

Host site1.local and site2.local with two separate VirtualHost files and distinct DocumentRoots to serve two simple sites from one server.

Common error

Forgetting to enable the site on Debian with a2ensite or having duplicate ServerName entries causes requests to land on the default site.

Key Takeaway

Use distinct ServerName values and enable the site configuration, then validate by editing the client hosts file and testing in a browser.
