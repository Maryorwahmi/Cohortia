Files & Directives

httpd.conf and apache2.conf

These main files set global behavior and include additional site-level files. Know the platform path and included directories.

Listen
Which ports Apache binds to, e.g., Listen 80.
ServerRoot
Directory for configuration and logs.
User/Group
Process privilege reduction for security.
Directory / AllowOverride
Control per-directory options and .htaccess usage.
Directory block example
<Directory /var/www/example.com/html>
    Options Indexes FollowSymLinks
    AllowOverride All
    Require all granted
</Directory>
Misconception: .htaccess is required. In production, prefer centralized directives and set AllowOverride None unless per-directory overrides are needed.
