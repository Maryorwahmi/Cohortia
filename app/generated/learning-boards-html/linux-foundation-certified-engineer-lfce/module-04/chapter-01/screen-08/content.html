Code Walkthrough
# Debian: enable site, test, reload
sudo a2ensite site1.local.conf
sudo apache2ctl configtest
sudo systemctl reload apache2

# RHEL: place conf in /etc/httpd/conf.d/, then
sudo apachectl configtest
sudo systemctl reload httpd
If configtest outputs Syntax OK, proceed to reload. If not, read the error, fix the file, and re-run the test.
Concrete example

A missing </VirtualHost> or mistyped directive will be flagged by configtest. Fix the tag mismatch and run the test again.

Common misconception

Reload is not dangerous; when configtest is OK, reload updates configuration without full restart and avoids connection drops.

Key Takeaway

Always test configuration syntax before reloading Apache to prevent service disruption from a bad config file.
