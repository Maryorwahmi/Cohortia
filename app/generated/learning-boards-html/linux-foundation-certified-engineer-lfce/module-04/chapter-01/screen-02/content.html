Module 4 › Chapter 4.1 › Learning Objectives
01
Install and Manage Apache
Install httpd or apache2, enable the service, and verify it serves files. This ensures predictable startup and recovery after a reboot.
VERIFIED COMPETENCY MILESTONE
02
Configure Virtual Hosts
Create site-specific VirtualHost blocks with DocumentRoot, ServerName, and logging to host multiple domains on one server.
VERIFIED COMPETENCY MILESTONE
03
Edit Core Directives
Understand Listen, ServerRoot, User/Group, and Directory options to control binding ports, file paths, and permission behavior.
VERIFIED COMPETENCY MILESTONE
04
Apply Basic Access Control
Set file ownership and permissions, configure Directory directives, and open firewall ports for HTTP/HTTPS to allow safe access.
VERIFIED COMPETENCY MILESTONE
