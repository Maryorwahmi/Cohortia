Module 4 › Chapter 4.1 › Troubleshooting
Checklist
  1. Confirm Apache service is active (systemctl status).
  2. Open firewall ports 80 and 443 (firewall-cmd or ufw).
  3. Check file ownership and permissions for DocumentRoot.
  4. Inspect SELinux audit logs and restore contexts if needed.
  5. Run apachectl configtest and fix syntax errors.
  6. Review VirtualHost ServerName/ServerAlias for overlaps.
  7. Examine error and access logs for specific failures.
Example

If users see 403 after moving files, check ownership, then check SELinux labels; audit logs will show AVC denials pointing to context issues.

Key Takeaway

Follow the checklist sequentially to avoid wasted effort and to isolate the true cause of access problems.
