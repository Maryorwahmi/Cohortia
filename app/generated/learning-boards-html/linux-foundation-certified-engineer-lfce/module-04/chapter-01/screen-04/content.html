Process

Install and enable the service

Follow the platform-appropriate commands and then verify the service status and that port 80 is reachable.

Commands (examples)
# RHEL/CentOS/Rocky Linux sudo dnf install httpd -y sudo systemctl enable httpd --now sudo firewall-cmd --permanent --add-service=http sudo firewall-cmd --permanent --add-service=https sudo firewall-cmd --reload # Debian/Ubuntu sudo apt update sudo apt install apache2 -y sudo systemctl enable apache2 --now sudo ufw allow 'Apache Full' sudo ufw enable
Concrete example

Place an index.html in /var/www/html and point a browser to the server IP. If you see the page, install and network are working.

Common mistake

Forgetting to open the firewall is the most common reason a site remains unreachable after installation.

Key Takeaway

Installation succeeds only when the package, service, and firewall are all configured and verified.
