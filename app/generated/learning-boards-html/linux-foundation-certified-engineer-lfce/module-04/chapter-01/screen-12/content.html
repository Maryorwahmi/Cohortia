Module 4 › Chapter 4.1 › Lab — Two Virtual Hosts
Server steps
# create document roots
sudo mkdir -p /var/www/site1.local/html
sudo mkdir -p /var/www/site2.local/html

# set ownership (RHEL example)
sudo chown -R apache:apache /var/www/site1.local
sudo chown -R apache:apache /var/www/site2.local

# create simple index.html files and add VirtualHost files then test
sudo apachectl configtest
sudo systemctl reload httpd
Client steps
Add to /etc/hosts on your client machine:
192.0.2.10 site1.local
192.0.2.10 site2.local
Then open http://site1.local and http://site2.local in the browser to confirm separate content.
Key Takeaway

This lab demonstrates how document roots, VirtualHost files, ownership, and hosts file mapping create an end-to-end multi-site setup on one server.
