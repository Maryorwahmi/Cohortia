HAProxy Example
A basic HAProxy configuration for HTTP
global
    log /dev/log local0
    user haproxy
    group haproxy
    maxconn 20000

defaults
    mode http
    timeout connect 10s
    timeout client 1m
    timeout server 1m

frontend http_frontend
    bind *:80
    default_backend web_backends

backend web_backends
    balance roundrobin
    option httpchk GET /health
    server web1 192.168.1.101:8080 check inter 2000 rise 2 fall 3
    server web2 192.168.1.102:8080 check inter 2000 rise 2 fall 3
    server web3 192.168.1.103:8080 check inter 2000 rise 2 fall 3 backup
Line-by-line highlights
  • maxconn limits global connections to protect the host.
  • defaults set HTTP timeouts and logging to avoid repetition.
  • option httpchk instructs HAProxy to use an HTTP GET for health verification.
  • server ... check inter 2000 rise 2 fall 3 configures frequent checks and up/down thresholds.
Practical tip
Always run sudo haproxy -c -f /etc/haproxy/haproxy.cfg before reloading to validate syntax and checks.
Key Takeaway

Configured checks and sensible timeouts make HAProxy resilient to transient backend failures and reduce false positives.
