Monitoring & Stats
Monitoring HAProxy and troubleshooting backends
Stats page
Expose a listen block on a non‑public port, enable stats uri and auth, and use it to observe backend UP/DOWN, sessions, and errors.
Example listen snippet
listen stats
  bind *:8080
  mode http
  stats enable
  stats uri /haproxy?stats
  stats auth admin:password123
Troubleshooting steps
  1. Reproduce the issue from a client.
  2. Check HAProxy stats for backend health and connection counts.
  3. Inspect backend logs and firewall rules for reachability problems.
  4. Validate health check endpoints return appropriate status codes.
Pro Tip

Protect the stats page with authentication and restrict access with firewall rules to trusted IPs.
