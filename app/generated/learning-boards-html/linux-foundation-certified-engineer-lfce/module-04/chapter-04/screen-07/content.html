HAProxy Overview
HAProxy architecture and configuration sections
global
System-level settings: logging, user, chroot, maxconn, and sockets for stats.
defaults
Timeouts, retries, logging mode, and options inherited by frontends and backends.
listen
Combined frontend/backend used commonly for a stats interface.
frontend
Defines how HAProxy accepts client connections (bind directives) and which backend to use.
backend
Lists servers, balancing algorithm, and health check parameters like option httpchk and server check flags.
Key Takeaway

HAProxy separates listening from backend logic so you can tune health checks and balancing independently of connection handling.
