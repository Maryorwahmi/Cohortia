HAProxy with Flask backends
Backend steps (each VM)
  1. Install Python and Flask.
  2. Create app.py with / and /health endpoints that reply on port 5000.
  3. Run Flask on host 0.0.0.0:5000 and allow firewall from HAProxy.
Flask snippet
from flask import Flask
app = Flask(__name__)
SERVER_NAME = "Backend 1"
@app.route('/')
def hello():
  return f"Hello from {SERVER_NAME}!
"
@app.route('/health')
def health_check():
  return "OK", 200
if __name__ == '__main__':
  app.run(host='0.0.0.0', port=5000)
HAProxy steps
  1. Install HAProxy and enable the service.
  2. Edit /etc/haproxy/haproxy.cfg: add frontend on :80 and backend with servers on port 5000.
  3. Add option httpchk GET /health and a listen stats on :8080 with auth.
  4. Validate with sudo haproxy -c -f /etc/haproxy/haproxy.cfg and reload the service.
Key Takeaway

Follow the lab steps to validate health checks and stats-driven troubleshooting; stopping a backend should show it as DOWN and route traffic to healthy instances.
