Common problems and checks
Use this checklist to triage replication and backup issues.
Privileges
Ensure replication user has REPLICATION SLAVE and run FLUSH PRIVILEGES if needed.
server_id
Confirm unique server_id values across all servers in topology.
Network
Verify port 3306 is open and reachable between master and slave.
Binlog presence
Confirm master is producing mysql-bin files and SHOW MASTER STATUS returns data.
Slave status
Use SHOW SLAVE STATUS\G to inspect Slave_IO_Running, Slave_SQL_Running, and Last_Error.
Backups
Always test restores; don’t keep backups only on the database host.
Scenario question

If SHOW SLAVE STATUS shows Slave_IO_Running: No, check replication user auth and network connectivity before any further reconfiguration.
