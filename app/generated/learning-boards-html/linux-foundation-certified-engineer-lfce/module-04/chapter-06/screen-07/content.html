Module 04 › Chapter 4.6 › Binlog Types
Statement-based
Records SQL statements executed on the master.
  • Smaller logs for simple deterministic statements.
  • Can diverge if statements are nondeterministic.
  • Example risk: functions returning different results on replica.
Row-based
Records the actual row changes, ensuring exact data reproduction.
  • Larger logs but more deterministic replication.
  • Preferred for complex updates, stored procedures, and non-deterministic operations.
  • Example: exact changed rows guarantee consistent replica state.
Asynchronous behavior and lag
Replicas may lag; monitor Seconds_Behind_Master. Decide if lag is acceptable for read replicas or if stricter patterns are needed for critical writes.
Key Takeaway

Choose row-based for correctness, statement-based for smaller logs, and monitor lag to understand read consistency boundaries.
