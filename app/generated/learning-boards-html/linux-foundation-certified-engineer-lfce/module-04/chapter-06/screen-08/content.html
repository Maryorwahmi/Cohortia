Module 04 › Chapter 4.6 › Replication User & Status
Create replication user
Grant minimum privileges and restrict by host.
CREATE USER 'repl_user'@'10.0.0.5' IDENTIFIED BY 'ReplicationP@ssw0rd!';
GRANT REPLICATION SLAVE ON *.* TO 'repl_user'@'10.0.0.5';
FLUSH PRIVILEGES;
Security tip

Avoid granting replication access from all hosts; use a CIDR or fixed IP for the slave to reduce exposure.

Capture master coordinates
Lock tables, show status, and release locks.
FLUSH TABLES WITH READ LOCK;
SHOW MASTER STATUS;
-- Note the File and Position values
UNLOCK TABLES;
Key Takeaway

Record the exact File and Position under a consistent snapshot. These coordinates seed the slave to the correct point in the master's binlog stream.
