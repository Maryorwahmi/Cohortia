Database Replication and Backup Strategies
Ensure high availability, scale reads, and enable safe recovery for MariaDB/MySQL.
Interactive 16:9 Masterclass

This chapter teaches the mechanics and practical steps: enabling binary logs, creating a replication user, recording the master log position for initial sync, and configuring a slave. You will also learn two backup approaches: logical exports using mysqldump and physical hot backups using mariabackup. Together these tools let you design a recovery plan that balances downtime, storage, and restore speed.

We emphasize production safety: use unique server_id values, restrict replication user access, use --single-transaction for InnoDB when using mysqldump, always run mariabackup's prepare step, and store backups off-site. Practical command examples and a short lab are included so you can reproduce the flow on two VMs.
