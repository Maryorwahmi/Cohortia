Key Concepts
Essential terms to recall while working with replication.
Replication
Copying changes from primary to replicas for availability and scale.
Master-Slave
One server accepts writes; others apply those changes as replicas.
Binary Log
Master's record of data-modifying events read by replicas.
Summary: Keep these terms front-of-mind while configuring replication and diagnosing issues.
