Module 04 › Chapter 4.6 › Backup Strategy
Backup policy components
Define the who, what, where, when, and how of your backups.
Frequency
Daily fulls; hourly incrementals if needed.
Retention
7 daily, 4 weekly, 12 monthly as an example plan.
Storage
Keep off-site copies and use immutable storage when available.
Monitoring
Alert on failed jobs, space usage, and long-running prepares.
Testing
Schedule restore drills and verify data integrity after restore.
Security
Protect backup credentials and ensure proper SELinux contexts on targets.
Key Takeaway

A backup is only useful if it is tested. Automate, monitor, store off-site, and run scheduled restores to validate recoverability.
