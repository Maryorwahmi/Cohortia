Module 04 › Chapter 4.6 › Lab Walkthrough
Master steps (summary)
  1. Install MariaDB and run mysql_secure_installation.
  2. Edit my.cnf: log_bin=mysql-bin, server_id=1. Restart service.
  3. Create database test_app_db and table users; insert sample rows.
  4. Create repl_user@'slave_ip' with REPLICATION SLAVE and FLUSH PRIVILEGES.
  5. FLUSH TABLES WITH READ LOCK; SHOW MASTER STATUS; UNLOCK TABLES.
  6. mysqldump --single-transaction test_app_db > /tmp/test_app_db_master_backup.sql and scp to slave.
Slave steps (summary)
  1. Edit my.cnf: server_id=2. Restart MariaDB.
  2. Import the dump: mysql -u root -p test_app_db < /tmp/test_app_db_master_backup.sql.
  3. Run CHANGE MASTER TO with recorded MASTER_LOG_FILE and MASTER_LOG_POS.
  4. START SLAVE; SHOW SLAVE STATUS\G and confirm both threads are Yes.
  5. Test: insert a row on master and verify it appears on the slave.
Lab tip

Transfer the dump file with scp and verify file integrity before importing. Import first, then point the slave at the recorded master coordinates.
