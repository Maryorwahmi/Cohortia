Backup Concepts
Commands and safety notes to remember.
mysqldump
Logical export; use --single-transaction for InnoDB consistency.
mariabackup
Hot physical backups; must run --prepare before restore.
Safety best practices
Off-site storage, unique server_id, FLUSH PRIVILEGES, and restore testing.
Final takeaway: Backups and replication together create resilience, but only if configured securely and tested regularly.
