Definition
Interactive system checks
Commands to profile logins, processes, and network sockets
Investigate • Record • Preserve
Command panel
# Check recent successful logins
last

# Check recent failed logins
lastb

# Who is logged in now
w
who

# List processes and arguments
ps aux

# Find network listeners and connections
lsof -i
Record outputs to files for later evidence preservation before making changes.
Example workflow
  1. Spot spike of failed logins with lastb and note timestamps.
  2. Run ps aux to find processes started at nearby times and record PID and exe path.
  3. Use lsof -p <PID> to see network activity before taking containment actions.
Key Takeaway

Collect live evidence first; do not destroy volatile data by killing processes or rebooting without capture.

Concrete example
An unknown listener on port 31337: use lsof -i :31337 and ps aux | grep <PID> to capture binary path and arguments before containment.
Common Mistake
Killing processes without collecting evidence; doing so may destroy artifacts needed for forensic analysis.
Check
If you find matching PIDs across servers, consider network containment steps and centralized logging review next.
