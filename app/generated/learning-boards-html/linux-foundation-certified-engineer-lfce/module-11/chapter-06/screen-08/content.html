Definition
Using ausearch and aureport
Query auditd for forensic fields and summaries
Fields to inspect: comm, exe, uid, auid, pid, syscall
Example commands
# Search by audit key
sudo ausearch -k user_account_changes

# Show raw records for deeper analysis
sudo ausearch -k user_account_changes --raw | less

# Summary reports
sudo aureport -k
Save outputs externally and record the command used for chain-of-custody documentation.
Interpreting fields
  • type=SYSCALL and msg timestamp show the system call and when it happened.
  • comm and exe identify the command and the executable path used.
  • uid and auid differentiate the effective user from the original authenticating user.
Key Takeaway

Focus on the audit fields that attribute actions to users and binaries; they are central to reliable investigation.

Concrete example
Using ausearch -k user_account_changes will show TYPE=SYSCALL entries with comm="useradd" and exe pointing to the binary that created the account.
Misconception
Assuming uid alone identifies the actor—use auid to find the original authenticated user when sudo was involved.
Pro Tip
Use --raw output in ausearch for the full record when preparing evidence for legal processes.
