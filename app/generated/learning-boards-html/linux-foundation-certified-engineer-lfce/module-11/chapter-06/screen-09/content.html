Comparison
Detecting rootkits
chkrootkit and rkhunter compared and practical cautions
Scan • Verify • Corroborate
chkrootkit
Focuses on kernel and user-level rootkit patterns and common signs in system binaries.
  • Checks for hidden processes and suspicious network connections.
  • Reports anomalies by comparing expected binary behavior.
Run from live media when deep compromise is suspected.
rkhunter
Inspects for hidden files, incorrect permissions, and suspicious strings in modules and binaries.
  • Can check for known rootkit signatures and unusual file attributes.
  • Produces warnings that require human review.
Corroborate findings with logs and system integrity checks.
Concrete Example
Run chkrootkit and rkhunter as part of routine scans; if they flag kernel module tampering, consider imaging and offline analysis.
Common Mistake
Trusting a scanner run on a compromised host without cross-checks; scanner binaries may be subverted.
Pro Tip
If deep compromise is suspected, run scans from trusted live media or a separate clean system to avoid false negatives.
