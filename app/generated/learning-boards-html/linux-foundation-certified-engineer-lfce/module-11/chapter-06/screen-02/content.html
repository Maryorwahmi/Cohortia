Learning Objectives
Learn → Understand → Apply → Master
01
Recognize IOCs
Identify unauthorized accounts, unusual ports, and modified system files.
Mnemonic: watch for new users + new listeners + changed system files.
VERIFIED COMPETENCY MILESTONE
02
Use log analysis tools
Query journalctl and application logs; filter with grep and awk for patterns.
Mnemonic: journal + filters = signal from noise.
VERIFIED COMPETENCY MILESTONE
03
Configure and review auditd
Create audit rules to monitor files and system calls and use ausearch/aureport to investigate.
Mnemonic: rules, restart, review.
VERIFIED COMPETENCY MILESTONE
04
Detect rootkits & contain
Run chkrootkit and rkhunter, then isolate systems and preserve evidence when compromise is suspected.
Mnemonic: scan, isolate, document.
VERIFIED COMPETENCY MILESTONE
