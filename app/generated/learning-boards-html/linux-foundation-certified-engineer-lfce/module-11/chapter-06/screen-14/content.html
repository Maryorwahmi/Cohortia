Key Concepts — Practical notes
Three compact reminders to act on
Rootkit detection
Run chkrootkit and rkhunter, preferrably from trusted media when compromise is suspected.
Live evidence
Capture PIDs, exe paths, and memory before disrupting processes.
Central logs
Ship logs remotely to prevent tampering and enable cross-host correlation.
Closing takeaway
Combine detection, audit trails, rootkit checks, containment, and secure log retention to create a robust incident response posture.
