Learning Objectives — Practice
Build timelines, interpret audit fields, and practice containment
01
Timeline building
Correlate journalctl, auth logs, and auditd events by time to reconstruct attacker activity.
Mnemonic: timestamp correlation reduces false leads.
VERIFIED COMPETENCY MILESTONE
02
Interpret audit fields
Use comm, exe, uid, auid, pid, and syscall fields to identify actors and actions.
Mnemonic: comm + exe + uid -> who ran what.
VERIFIED COMPETENCY MILESTONE
03
Hands-on detection
Simulate a useradd and find it via audit rules and journal queries.
Mnemonic: simulate, detect, clean up.
VERIFIED COMPETENCY MILESTONE
04
Containment & preservation
Block ports, capture RAM if needed, take disk images, and document all actions.
Mnemonic: stop, preserve, document.
