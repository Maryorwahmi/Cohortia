Containment & initial forensics
Actions to limit damage while protecting evidence
Isolate • Capture • Document
Containment checklist
  1. Identify and block malicious ports using firewall rules.
  2. If safe, isolate the host from networks while considering investigative needs.
  3. Capture volatile memory before making changes when forensics is required.
Block ports example: use iptables rules to drop traffic for a suspected backdoor port.
Preservation steps
  • Take a full disk image when possible before making changes.
  • Record timestamps, commands run, and observed artifacts in an incident log.
  • Avoid rebooting to retain volatile memory and kernel state.
Key Takeaway

Contain first, preserve evidence next, and document everything to enable later forensic and legal analysis.

Concrete Example
Block port 31337 with firewall rules, then capture lsof and ps outputs and take a RAM dump using LiME if legal and practical.
Common Mistake
Disconnecting or rebooting too quickly and losing volatile evidence that could indicate attacker activity and memory-resident artifacts.
Check
If you must disconnect, document the reason and ensure someone captures volatile evidence immediately beforehand when possible.
