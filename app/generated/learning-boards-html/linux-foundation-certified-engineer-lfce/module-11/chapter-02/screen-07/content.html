Module 11 › Chapter 11.2 › LVM Diagnosis
Component mapping
Physical Volume (PV)

A disk or partition reported to LVM. Use pvdisplay to check status and UUIDs.

Volume Group (VG)

Aggregation of PVs. vgdisplay shows free space and missing PVs.

Logical Volume (LV)

Block device used by filesystems. lvdisplay reveals LV status and attributes.

Commands to inspect:

sudo pvdisplay
sudo vgdisplay
sudo lvdisplay
sudo pvs -o +devices
Example

If vgdisplay shows a missing PV after a disk failure, first repair or replace the disk and rebuild RAID if used, then run pvscan and vgchange -ay to reactivate the VG.

Pro tip

Map LVM devices to /dev entries before making changes and keep a copy of vg metadata via vgcfgbackup.
