Learning Objectives

Skills you'll build and verify in this chapter.

Bloom: Learn → Understand → Apply → Master
01
Identify corruption symptoms

Learn the common signs like I/O errors, missing files, and slow reads so you detect issues early.

VERIFIED COMPETENCY MILESTONE
02
Run fsck safely

Understand unmounted requirements, rescue environments, and flags that automate or force checks.

VERIFIED COMPETENCY MILESTONE
03
Diagnose LVM and RAID

Use pvdisplay, vgdisplay, lvdisplay, mdadm, and /proc/mdstat to find the failed layer and plan recovery.

VERIFIED COMPETENCY MILESTONE
04
Manage bad blocks & backups

Integrate badblocks and SMART checks, and create a backup and monitoring plan to prevent data loss.

VERIFIED COMPETENCY MILESTONE
