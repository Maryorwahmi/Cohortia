What are bad blocks?

Physical sectors on a drive that cannot reliably store or return data. Drives can remap, but increasing counts indicate failure.

Tool

badblocks scans a device; for Ext filesystems, use e2fsck -c to integrate results safely into filesystem metadata.

Example command
# Non-destructive read-only scan
sudo badblocks -sv /dev/sdb

# Integrate with Ext filesystem via e2fsck
sudo e2fsck -c /dev/sdb1
If badblocks finds many sectors, schedule drive replacement and restore from backups instead of relying on marking alone.
