Module 11 › Chapter 11.2 › Badblocks + fsck
Recommended command flow
# Non-destructive scan (device-level)
sudo badblocks -sv /dev/sdb

# Run e2fsck which invokes badblocks and marks bad blocks in FS
sudo e2fsck -c /dev/sdb1
Use read-only or non-destructive scans whenever you need to preserve data. Only run destructive tests on disposable media.
Interpretation checklist
  • Compare badblocks output with S.M.A.R.T. pending/reallocated counts.
  • If many blocks are marked, schedule an immediate replacement.
  • After marking, remount and verify important files are readable.
Key Takeaway

Marking is temporary mitigation. Persistent or expanding bad block counts require drive replacement and restore from backup.
