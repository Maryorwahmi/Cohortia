Module 11 › Chapter 11.2 › RAID Recovery
RAID status commands
cat /proc/mdstat
sudo mdadm --detail /dev/md0
sudo mdadm --add /dev/md0 /dev/sdb
sudo mdadm --manage /dev/md0 --remove /dev/sdX
Use --detail to see which member is faulty and the rebuild percent. Always prefer safe add/remove sequences rather than forcing operations when possible.
Rebuild example

If /proc/mdstat shows one device missing in a RAID5 array, replace the failed disk, prepare partitions, then run mdadm --add. Monitor the rebuild until clean.

Gotcha

Do not interrupt a rebuild unless you have a tested recovery plan. Interruptions can leave the array inconsistent.
