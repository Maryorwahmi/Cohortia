Verification tasks

Four short lab checks to confirm each applied objective.

Filesystem checker choice

Verify that xfs_repair is used for XFS and fsck.ext4 for Ext4 in a test VM.

mdadm rebuild

Simulate a failed member and perform mdadm --add then verify the rebuild progress via /proc/mdstat.

LVM mapping

Use pvdisplay/vgdisplay to trace a missing LV back to a failed PV device.

Bad block marking

Run a non-destructive badblocks scan and merge results with e2fsck -c to mark bad sectors.
