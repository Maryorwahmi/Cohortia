Terminal checklist
# Inspect devices
sudo lsblk -o NAME,SIZE,FSTYPE,MOUNTPOINT
sudo blkid /dev/sda1

# If root is corrupted: boot a live CD/USB, then
sudo fsck -fcc /dev/sda1

# Mount read-only to inspect
sudo mount -o ro /dev/sda1 /mnt/rescue
ls /mnt/rescue/etc /mnt/rescue/boot
The code above shows the safe sequence: identify, image, fsck with badblock scan, then mount read-only to check important files.
Supporting notes
  • Always confirm device names; mistakes here can destroy other partitions.
  • Use a read-only mount to verify configuration and boot files before making changes.
  • When in doubt, make a dd image of the partition for offline analysis.
Common mistake

Booting normally and running fsck from a mounted root risks overwriting live metadata and losing changes you need.
