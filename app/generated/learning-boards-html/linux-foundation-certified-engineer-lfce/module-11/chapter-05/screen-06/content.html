Quick snapshot: free -h
              total        used        free      shared  buff/cache   available
Mem:           16G         14G         1G         0G         1G         2G
Swap:          4G          1G         3G
Note the -/+ buffers/cache line when judging true available memory. Buffers and cache are reclaimable.
Continuous view: vmstat
procs -----------memory---------- ---swap-- -----io---- -system-- -----cpu-----
 r  b   swpd   free   buff  cache   si   so    bi    bo   in   cs us sy id wa
 1  0  102400 1024000  51200 204800  0    256    0    128   50  100 20 10 60 10
Watch si and so for swap activity; high values indicate active swapping and poor performance.
Example
Run a memory-hungry process that allocates 1GB and observe so rising in vmstat until the allocation ends.
Common mistake
Treating cached memory as unavailable and adding unnecessary RAM when reallocating caches would suffice.
Key Takeaway

Active swap (nonzero si/so) is a reliable indicator of memory pressure and will also increase disk I/O; address the root cause rather than only adding swap space.
