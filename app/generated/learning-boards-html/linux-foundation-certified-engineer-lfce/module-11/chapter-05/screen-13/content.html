Swap behavior and tuning
Understand why swapping drastically reduces performance and how vm.swappiness influences kernel choices.
What swap does
Provides virtual memory on disk to avoid immediate process termination when RAM is exhausted.
Why it's slow
Accessing swapped pages requires disk operations, which are vastly slower than RAM and can increase I/O wait.
Tuning
Adjust vm.swappiness via sysctl to influence when the kernel swaps, but treat it as a temporary mitigation.
Key Takeaway

Reduce memory demand or add RAM for sustained performance; changing swappiness can help temporarily but does not replace capacity planning.

Example action
sudo sysctl vm.swappiness=10 to test a lower swappiness value; monitor si/so and application behavior.
Mistake
Using swappiness as a substitute for fixing memory leaks or right-sizing application memory settings.
