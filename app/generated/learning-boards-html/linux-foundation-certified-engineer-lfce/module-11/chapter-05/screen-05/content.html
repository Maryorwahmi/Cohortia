Live monitor: top (compact)
Quick snapshot of system and processes; default sorts by CPU.
top - 12:34:56 up 10 days,  2:22,  1 user,  load average: 1.23, 0.98, 0.75
Tasks: 123 total,   2 running, 121 sleeping
%Cpu(s): 70.0 us, 10.0 sy, 18.0 wa,  0.0 id
Mem:  16G total, 14G used, 2G free,  1G buffers
  PID USER      PR  NI    VIRT    RES    SHR S  %CPU %MEM COMMAND
 2345 webapp    20   0  1.2g  200m   10m R  65.0  1.2  python3
  • Watch the CPU line for us, sy, wa to map behavior to causes.
  • Sort by %CPU or %MEM to find heavy consumers quickly.
Interactive: htop (user-friendly)
Color bars, easy sorting, and actions like killing or renicing processes.

Use htop to toggle tree view, sort by memory, and spot processes with large RES values. Remember: a process with high CPU and associated high wa suggests I/O wait; investigate the device with iostat next.

Common mistake
Killing the first seen process without confirming its role can stop critical system services.
Pro tip
Use a second terminal to run iostat while you watch wa in top to correlate CPU wait with device utilization.
