Resource Exhaustion — definition and symptoms
Recognize the distinct signatures of CPU, memory, and I/O pressure.
Core definition
A resource is exhausted when demand exceeds capacity and the system cannot supply work at required speed.
Common signatures
  • CPU: sustained high user/system percentages and runnable queue growth.
  • Memory: high swap activity, low available memory counters.
  • Disk I/O: high CPU wait (wa) and device %util near 100%.
Concrete example
A web server becomes slow. top shows 70% us and 20% wa. iostat shows /dev/sda %util 98 and await high. This points to disk I/O as the primary bottleneck, not CPU capacity.
Misconception
Don't assume high CPU total equals CPU-bound work; check wa and per-process metrics before acting.
Key Takeaway

Match observable metric signatures to the resource type before choosing a remediation path — that avoids wasted effort and incorrect fixes.

Try this
When diagnosing, capture both live output and a short iostat snapshot to distinguish CPU vs I/O causes.
