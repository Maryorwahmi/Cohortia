sar: capture and analyze historical activity
Enable sysstat collection to retain useful historical trends for later analysis.
Common commands
sar -u        # CPU usage history
sar -r        # memory history
sar -b        # I/O and transfer rates
sar -q        # run queue and load averages
Practical notes
  • Confirm sysstat cron jobs are enabled to collect sar data.
  • Look for repeating patterns to identify scheduled tasks or daily peaks.
  • Correlate sar output with logs and cron to find the root cause.
Key Takeaway

Historical data is essential for diagnosing intermittent problems that do not appear in short live observations.

Common mistake
Assuming sar is enabled by default; verify collection and retention settings on your system.
Example
Use sar to find that backups every night caused disk %util spikes and plan a staggered schedule.
