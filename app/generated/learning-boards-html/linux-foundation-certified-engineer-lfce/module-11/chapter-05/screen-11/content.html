Module 11 › Chapter 11.5 › Hands-on simulations
CPU simulation
# multi-core stress with yes (run several times)
yes > /dev/null &
# or use stress to target cores
stress -c 1 &
Observe top and watch us increase and the run queue grow under sustained CPU load.
Disk I/O simulation
# large sequential write
dd if=/dev/zero of=tempfile bs=1M count=1000 oflag=direct &
# or use fio for more patterns
fio --name=randwrite --ioengine=posixaio --rw=randwrite --bs=4k --size=1G --numjobs=1 --iodepth=1 --filename=/tmp/fio_test.tmp &
Run iostat -x 1 to watch %util and await increase while the write runs.
Memory simulation
# allocate ~1GB and wait for Enter to free it
python3 -c "a = ' ' * (1024**3); input('Press Enter to free memory')" &
Key Takeaway

Always run generators in isolated test environments and monitor metrics concurrently to validate signatures before applying fixes in production.

Safety
Do not run heavy generators on production without maintenance windows and clear rollback plans.
Verify
After mitigation, re-run the same monitoring to confirm metrics return to expected ranges.
