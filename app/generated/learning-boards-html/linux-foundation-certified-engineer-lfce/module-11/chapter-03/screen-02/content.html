Learning Objectives

Practical skills mapped to Linux tools and common failure modes.

Bloom: Learn → Understand → Apply → Master
01
Systematic OSI troubleshooting

Learn the ordered checks from link to application and why each step narrows root cause hypotheses.

VERIFIED COMPETENCY MILESTONE
02
Inspect link and interface state

Use ip link show, check NIC and switch indicators, and identify common physical and layer-2 problems.

VERIFIED COMPETENCY MILESTONE
03
Validate IP and routing

Read ip addr and ip route outputs to detect wrong subnet masks or missing default gateway entries.

VERIFIED COMPETENCY MILESTONE
04
Use diagnostic tools

Run ping, traceroute, dig, ss, and tcpdump with filters to confirm reachability and examine traffic behavior.

VERIFIED COMPETENCY MILESTONE
