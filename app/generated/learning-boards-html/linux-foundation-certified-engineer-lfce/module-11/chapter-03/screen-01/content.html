Network Connectivity & Performance Problems

Learn a repeatable sequence of checks and the precise Linux commands that reveal link, addressing, DNS, service, firewall, and bandwidth issues.

Terminal Demo Mode
16:9 HD Classroom
In this lesson
  • Follow an OSI-inspired checklist from link to application layer.
  • Use ip, ss, tcpdump, and firewall inspection to localize the fault.
  • Measure capacity with iperf3 to separate network from application bottlenecks.
Why this matters

Quick, ordered checks save time during incidents and avoid chasing red herrings. You will practice patterns that scale from two VMs to production clusters.

Explore Key Topics
Link & Addressing
Check cables, NIC state, ip addr, and routing to ensure basic reachability.
DNS & Name Resolution
Inspect resolv.conf, use dig and systemd-resolve to verify name services.
Capture & Firewalls
Use tcpdump and ss to see packets and iptables or nftables to find blocked traffic.
Visual Concept
Layered Checks
Link → Address → Name → Service → Firewall → Capacity
Tool Palette
ip, ss, ping, traceroute, dig, tcpdump, iptables/nftables, iperf3
Quick tip
When a service seems down, confirm IP first, then name resolution, then service binding, and finally firewalls and capacity.
