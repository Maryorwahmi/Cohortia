Key Concepts

OSI Model
A layered framework to order checks from physical link to application.
ip command
Primary tool for interfaces, addresses, and routing state on Linux.
Ping / Traceroute / mtr
Core reachability tools to verify connectivity and hop-level paths.
Summary
Apply ordered checks, use the right tool for each layer, and always validate fixes by re-testing connectivity or performance.
