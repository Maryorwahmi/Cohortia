Tools & Actions

Hands-on skills: socket inspection, packet capture, firewall review, and capacity testing.

Bloom: Learn → Understand → Apply → Master
01
Discover sockets with ss

Use ss -tunlp to map ports to processes and detect services bound to unexpected interfaces.

VERIFIED COMPETENCY MILESTONE
02
Capture with tcpdump filters

Apply host, port, and interface filters to collect only the traffic needed for analysis and privacy.

VERIFIED COMPETENCY MILESTONE
03
Audit firewall rules

List iptables or nftables rules and use counters to see whether traffic is hitting a drop rule.

VERIFIED COMPETENCY MILESTONE
04
Measure bandwidth

Run iperf3 between two hosts to decide if poor throughput is a network or an application problem.
