Comparison

Inspecting iptables and nftables

List rules and counters to see whether traffic is explicitly dropped or accepted by rules.

# List iptables with counters
sudo iptables -L -nv

# List nftables ruleset
sudo nft list ruleset
Concrete example
An INPUT rule dropping packets from the client IP will show non-zero packet counters; remove or adjust that rule to restore access and then document the change.
Practical notes
  • Look for packet counters in rule listing to see active matches.
  • Test changes in a maintenance window or with a rollback; many mistakes are caused by overly broad rules.
  • Remember to persist intentional rule changes so they survive reboot if desired.
Common mistake
Adding temporary ACCEPT rules and forgetting to remove them adds risk. Always record and revert test rules after validation.
Key Takeaway
Firewall counters are diagnostic gold; use them to prove whether packets are being matched and dropped.
