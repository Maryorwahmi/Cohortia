Module 11 › Chapter 11.3 › IP configuration and routing
Definition

IP addresses and kernel routing

Verify assigned addresses, prefixes, and the default route so packets go where you expect.

# Show addresses
ip addr show

# Show routing table
ip route show

# Simulate kernel routing decision
ip route get 8.8.8.8
Concrete example
Two VMs on same switch cannot reach each other: compare subnet prefixes; a host with /24 and another with /25 may not see each other if addresses fall outside the shared range.
Explanation & pitfalls
  • Missing default gateway prevents external access even if local subnet works.
  • Multiple routes or 0.0.0.0 entries can lead to asymmetric routing and dropped replies.
  • DHCP failures can leave stale or no addresses; validate lease state when applicable.
Pro tip
Use ip route get to see the exact outgoing interface and gateway the kernel picks for a destination.
Key Takeaway
Addressing and routes must align with your network design; mismatches are frequent causes of isolation.
