Learning Objectives

Build practical debugging skills for scripts and CM tools.

Learn → Understand → Apply → Master
01
Diagnose shell script failures

Use tracing, echo prints, and trap handlers to find where a script diverges from expectation and reveal incorrect variable expansion.

VERIFIED COMPETENCY MILESTONE
02
Troubleshoot Ansible connectivity

Confirm SSH reachability, validate inventory, and increase playbook verbosity to reveal module parameters and return codes.

VERIFIED COMPETENCY MILESTONE
03
Fix Puppet agent and master issues

Read agent and master logs, validate manifests with puppet parser, and resolve certificate problems to restore catalog application.

VERIFIED COMPETENCY MILESTONE
04
Adopt idempotent and safe practices

Design tasks to be repeatable, use version control, and test changes in a non-production environment before wide deployment.

VERIFIED COMPETENCY MILESTONE
