Comparison

Connectivity & Inventory vs Playbook Logic

Use quick connectivity checks first, then move to verbose runs and module isolation to narrow down the cause.

Connectivity / Inventory
  • ansible all -m ping to test reachability
  • Check SSH keys, ansible_user, ansible_host entries
  • Use -vvv to inspect SSH handshake and auth
Playbook Logic
  • Run modules ad-hoc to validate behavior
  • Check for missing dependencies on managed host
  • Use ansible-lint to find style and syntax issues
# connectivity quick test
ansible all -i inventory.ini -m ping

# verbose playbook run
ansible-playbook -i inventory.ini playbook.yaml -vvv
Concrete tip

If ansible all -m ping fails but SSH to the host succeeds, compare the connection user and key used by Ansible and the manual SSH session; inventory variables often diverge from expectations.

Checkpoint

Decide whether to fix the network/credentials or the playbook based on quick ad-hoc tests and verbose output.
