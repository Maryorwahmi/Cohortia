Learning Objectives — Applied

Practical checks, validators, and recovery steps to reduce downtime.

Learn → Understand → Apply → Master
05
Increase run verbosity

Use ansible-playbook -vvv or puppet agent --debug to collect detailed execution and connection info for precise diagnosis.

VERIFIED COMPETENCY MILESTONE
06
Use validators and linters

Run ansible-lint and puppet parser validate to catch syntax and style problems before deploying changes.

VERIFIED COMPETENCY MILESTONE
07
Isolate failing tasks

Run modules directly or try commands manually on the managed host to determine whether a problem is remote or local to the task.

VERIFIED COMPETENCY MILESTONE
08
Recover Puppet certificates safely

Remove stale SSL data, request a new certificate from the agent, and sign it on the master to restore secure communication.

VERIFIED COMPETENCY MILESTONE
