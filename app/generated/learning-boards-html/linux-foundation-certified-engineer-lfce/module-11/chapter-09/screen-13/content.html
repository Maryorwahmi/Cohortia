Methodical steps

Use these steps as a reproducible process whenever automation fails.

1. Isolate
Run the command manually on the target host to classify the failure.
2. Connectivity
Use ping checks, SSH, or ansible -m ping to confirm reachability.
3. Verbose Evidence
Run ansible-playbook -vvv or puppet agent --debug for detailed logs.
4. Validate
Use linters and parsers to catch syntax and style errors before fixes.
5. Apply minimal fix
Make the smallest change that addresses the root cause, not a broad rollback.
6. Verify
Use ad-hoc module calls or service checks to confirm the system is healthy.
Key Takeaway

A structured checklist reduces wasted effort and prevents making speculative changes that could worsen production issues.
