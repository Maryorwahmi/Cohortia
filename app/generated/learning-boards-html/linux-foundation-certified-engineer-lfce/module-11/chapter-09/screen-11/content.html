Module 11 › Chapter 11.9 › Puppet Master issues
Process

Validate manifests and inspect compilation errors

Compilation errors point to the exact manifest line or module problem; fix those before restarting services or signing certs.

Validation commands
  • puppet parser validate manifest.pp
  • puppet-lint manifests/
  • Check modulepath in puppet.conf
Resolve resource conflicts

Identify duplicate resource declarations and consolidate or use resource defaults to avoid collisions during compilation.

Master log hints
  • Look for file, class, or type names in the stack trace to locate the faulty manifest.
  • Missing modules usually show explicit 'could not find' messages referencing modulepath.
  • Compilation failures often include resource names that clash; search for duplicates.
Key Takeaway

Fix manifest and modulepath errors using validation tools before restarting the master to avoid repeated failures.
