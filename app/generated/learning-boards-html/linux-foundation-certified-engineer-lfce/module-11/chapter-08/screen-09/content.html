Failing Dockerfile
# Dockerfile
FROM alpine/git
CMD ["non_existent_command"]
Build and run to see the exit status, then collect logs and inspect metadata before changing the Dockerfile.
Fix and verify
# Fix: replace the CMD with a known binary
# Dockerfile (fixed)
FROM alpine/git
CMD ["echo", "Hello from Docker!"]

# Commands to verify
docker build -t failing-app .
docker run --name my-failing-app failing-app
docker logs my-failing-app
Remember: rebuild the image, then run the new image. Editing a running container does not update the source artifact used in deployments.
