Docker task
# Build and run
docker build -t failing-app .
docker run --name my-failing-app failing-app
# Diagnose
docker ps -a
docker logs my-failing-app
docker inspect my-failing-app
Fix the Dockerfile and rebuild the image; do not edit the container for persistent fixes.
Kubernetes task
# Failing pod manifest snippet
apiVersion: v1
kind: Pod
metadata:
  name: failing-nginx
spec:
  containers:
  - name: nginx-container
    image: nginx:latest
    command: ["/bin/sh", "-c"]
    args: ["sleep 5; exit 1"]

# Diagnose
kubectl apply -f failing-pod.yaml
kubectl get pods
kubectl describe pod failing-nginx
kubectl logs failing-nginx
Fix by providing a proper long-running command (for nginx, use the standard nginx foreground args) and reapply.
