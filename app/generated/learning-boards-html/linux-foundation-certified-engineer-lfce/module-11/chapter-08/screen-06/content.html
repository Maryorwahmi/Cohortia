Module 11 › Chapter 11.8 › VM Networking
Host Bridge Checks
  • Use brctl show or ip link show to list bridges and attached interfaces.
  • Confirm the VM's tap device is present and UP on the expected bridge (e.g., virbr0 or br0).
  • Ping the guest IP from the host to verify L2/L3 connectivity.
# On host
brctl show
ip link show br0
ip addr show
Guest Interface Checks
  • Use ip addr show and ip route to confirm the guest has an IP and default route.
  • Check DHCP client logs if the guest should receive an address automatically.
  • If the tap exists but no IP is present, focus on guest network config rather than the host bridge.
# In guest
ip addr show
ip route show
journalctl -u dhclient
Common mistake

Restarting the guest firewall before checking the host bridge can waste time if the tap device is missing on the host.
