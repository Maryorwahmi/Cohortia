Module 11 › Chapter 11.8 › Key Concepts
KVM/QEMU
Hypervisor layer; use libvirt logs and virsh for domain control and diagnostics.
libvirt / virsh
Management interface; virsh list, console and logs reveal VM state and boot errors.
Docker
Container runtime; docker logs, inspect and exec are primary diagnostic tools.
Summary
A short, repeatable checklist reduces firefighting time: determine scope, collect logs, inspect metadata, then apply immutable fixes or resource adjustments.
