Module 11 › Chapter 11.8 › VM Storage
Checks for virtual disks
  • Run qemu-img info <image_path> to view format, virtual size, and backing file.
  • Confirm the host filesystem has sufficient free space where images reside.
  • Use iostat or similar to detect high disk latency from competing VMs.
qemu-img info /var/lib/libvirt/images/webserver.qcow2
df -h /var/lib/libvirt/images
iostat -x 1 5
Example scenario

A VM experiences frequent timeouts accessing disk-backed databases. qemu-img shows a backing file on shared storage and iostat indicates high await times. The correct fix is to move high-I/O guests to less contended storage or add IOPS, rather than spending time tuning guest filesystem caches alone.

Pro tip

If an image has a backing file, never delete the backing without rebasing; that causes immediate corruption for derived images.
