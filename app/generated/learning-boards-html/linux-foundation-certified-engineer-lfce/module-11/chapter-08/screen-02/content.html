Troubleshoot guest networking & storage

03
Debug Docker containers
Use docker logs, inspect, and exec to find incorrect entrypoints, env vars, and permission issues.
VERIFIED COMPETENCY MILESTONE
04
Triage Kubernetes pod failures
Use kubectl get, describe, and logs to resolve CrashLoopBackOff, ImagePullBackOff, and OOMKilled states.
VERIFIED COMPETENCY MILESTONE
Why these objectives matter
  • Diagnosing at the right layer avoids risky changes and reduces downtime.
  • Inspecting runtime metadata prevents guesswork and points directly to configuration errors.
  • Understanding pod statuses in Kubernetes speeds cluster recovery and avoids unnecessary redeploys.
  • Combining logs with resource checks helps you decide whether to restart, resize, or rollback.
Mnemonic
Layer → Logs → Inspect → Fix
