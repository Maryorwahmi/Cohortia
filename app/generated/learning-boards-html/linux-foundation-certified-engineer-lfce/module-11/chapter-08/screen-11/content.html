Module 11 › Chapter 11.8 › Kubernetes Networking
Service & Endpoint checks
kubectl get svc
kubectl describe svc my-service
kubectl get endpoints my-service
If endpoints are empty, the Service selector doesn't match pods. Fix labels or selector in the manifest rather than tinkering with kube-proxy.
Node-level checks
  • Check kube-proxy logs on the node for iptables or IPVS errors.
  • Inspect the CNI plugin daemon logs when pod-to-pod networking or overlay issues appear.
  • For Ingress, verify the controller logs and resource mapping.
Pro tip

Confirm endpoints first; it often saves hours of node-level debugging.
