Module 11 › Chapter 11.8 › Quick Reference
Kubernetes
kubectl get/describe/logs. Watch for CrashLoopBackOff, ImagePullBackOff, OOMKilled.
Docker
docker ps, logs, inspect, exec to find exit codes and configuration errors.
KVM / libvirt
virsh list/console/domiflist and libvirt/qemu logs are your direct source for VM boot and device errors.
Final Tip
Treat status strings and log errors as precise signals. Let them tell you whether to check images, manifests, host resources, or CNI components next.
