Module 11 › Chapter 11.8 › Resources & Limits
Kubernetes resource signals
  • OOMKilled indicates the container exceeded its memory limit and was terminated.
  • CPU throttling reduces compute performance when limits are hit; no explicit termination occurs.
  • Describe output includes termination reason and exit codes to confirm resource-related kills.
Practical steps
  1. Check pod usage and limits in the manifest.
  2. If OOMKilled, increase memory limit or optimize the app's memory footprint.
  3. If the node is saturated, scale or move workloads to balance I/O and CPU.
Key Takeaway

Tune requests and limits based on observed metrics to prevent terminations and noisy neighbors on shared hosts.
