Command walkthrough
Examples and safe checks for typical module operations.
# List loaded modules and usage counts
$ lsmod
Module                  Size  Used by
pcnet32                16384  0
e1000                 123456  1

# Inspect module metadata
$ modinfo pcnet32
filename:       /lib/modules/.../pcnet32.ko
author:         Vendor
parm:           debug:Enable debug (int)

# Load with dependencies
$ sudo modprobe pcnet32
# Remove when safe
$ sudo rmmod pcnet32
Pro tip
Use lsmod before rmmod to ensure usage is zero. If not zero, stop dependent services first.
Common mistake
Forcing removal of in-use modules can cause crashes. Prefer graceful service stop and unbind device drivers.
Quick checks
  • Confirm presence with lsmod.
  • Inspect modinfo for parameters and aliases.
  • Use modprobe to pull dependencies; check dmesg after load.
Key Takeaway

Treat module changes as state changes: check, apply, verify in dmesg, and keep rollback steps ready.
