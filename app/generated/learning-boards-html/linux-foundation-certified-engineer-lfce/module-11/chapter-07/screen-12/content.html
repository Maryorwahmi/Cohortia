Module 11 › Chapter 11.7 › Blacklisting & initramfs
Why blacklisting sometimes fails
Early-boot images can contain modules that bypass runtime blacklists until rebuilt.
Update commands
Debian/Ubuntu: sudo update-initramfs -u. RHEL/Fedora: sudo dracut -f.
Warning
Blacklisting over an SSH session that removes network drivers can lock you out; plan alternate access before testing.
Quick checklist
  • Create blacklist file under /etc/modprobe.d/
  • Run update-initramfs -u or dracut -f
  • Reboot and verify with dmesg
Key Takeaway
Blacklisting alone may not change early-boot behavior; rebuild boot images so changes take effect at startup.
