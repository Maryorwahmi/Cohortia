When to blacklist
Use blacklisting to confirm a module causes instability, or to prevent an unwanted driver from binding.
Steps
  1. Create a file in /etc/modprobe.d/ with blacklist <module_name>.
  2. Update initramfs if necessary (update-initramfs -u or equivalent).
  3. Reboot and observe whether the issue persists.
Warning
Blacklisting removes device functionality. Ensure you have remote access alternatives if blacklisting affects networking.
Example
# Blacklist pcnet32 (simulated)
$ sudo sh -c 'echo "blacklist pcnet32" > /etc/modprobe.d/blacklist-pcnet32.conf'
# Rebuild initramfs if module is in initramfs
$ sudo update-initramfs -u
# Reboot to test
Why it helps
Blacklisting isolates the driver so you can see if system stability returns without that module loaded at boot.
