Learning Objectives
From observation to recovery: practical skills and safety checks.
Bloom: Learn → Understand → Apply → Master
Diagnose kernel & driver issues
Learn to interpret dmesg and kernel events to find hardware and driver problems.
Verified competency milestone
Use module tools confidently
lsmod, modinfo, modprobe, rmmod and dependency awareness for safe module control.
Verified competency milestone
Isolate and blacklist drivers
Learn when to blacklist and how to confirm that a module is the root cause.
Verified competency milestone
Update and rollback kernels
Use package tools and GRUB selection to maintain a safe fallback kernel set.
Verified competency milestone
