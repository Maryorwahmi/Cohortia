Module 11 › Chapter 11.7 › Reading dmesg
What dmesg contains
Boot and runtime kernel messages, driver probe logs, and stack traces.
Common filters
  • dmesg | grep -i "error|fail|warn|bug" — find likely faults quickly.
  • dmesg | tail -n 50 — view recent events after an action.
  • Filter by device name or vendor string to narrow scope.
Misconception
Seeing the word error does not always mean the system is unusable; check repetition and stack traces to assess severity.
Terminal example
$ dmesg | grep -i "network"
[  1.234567] pci 0000:00:03.0: Ethernet controller: ExampleNet 1000
[  1.234789] e1000: Intel(R) PRO/1000 Network Driver
[  1.235000] e1000 0000:00:03.0: firmware: failed to load e1000-fw.bin
[  1.235200] e1000 0000:00:03.0: failed to initialize

# Notice the firmware load failure and the initialization failure indicating a driver/hardware issue.
Example
A firmware load failure often points to missing firmware files or an incorrect module; use modinfo and distribution packages to confirm.
Key Takeaway
Capture dmesg output before and after changes to compare evidence and support reports to maintainers.
