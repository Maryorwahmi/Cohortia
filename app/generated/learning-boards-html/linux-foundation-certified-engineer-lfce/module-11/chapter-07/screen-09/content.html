Module 11 › Chapter 11.7 › Kernel updates & rollback
Update and rollback strategy
Install new kernels in a controlled way and keep at least one fallback kernel available.
Install safely
Use package manager to install kernels so they integrate with the bootloader and initramfs tools.
Rollback
Select an older kernel at GRUB. Once confirmed, remove the bad kernel with the package manager.
Recovery tip
If boot fails for all kernels, use a live USB to chroot and reinstall or restore a working kernel package.
Commands (examples)
# Debian/Ubuntu: install kernel package
$ sudo apt install linux-image-generic
# RHEL/Fedora: install kernel
$ sudo dnf install kernel
# Remove a problematic kernel (example)
$ sudo apt remove linux-image-5.15.0-xx-generic
Key Takeaway
Treat kernel updates as planned maintenance and keep a tested fallback for emergency boot recovery.
