Module 11 › Chapter 11.7 › modprobe vs insmod vs rmmod
Tool comparison
When to prefer each command and why.
insmod
Loads a single .ko file without dependency resolution. Useful for development and testing a specific binary module.
modprobe
High-level loader that resolves dependencies and aliases. Preferred for normal operations.
rmmod
Removes a module but requires usage count zero. Check lsmod first to avoid forcing removal.
Quick decision guide
  • If you need deps and aliases handled, use modprobe.
  • If testing a single out-of-tree .ko, use insmod then dmesg for immediate feedback.
  • To remove, verify with lsmod and stop consumers, then use rmmod.
Misconception
Do not use insmod in place of modprobe on production systems; insmod ignores depmod maps and can cause missing helper modules.
