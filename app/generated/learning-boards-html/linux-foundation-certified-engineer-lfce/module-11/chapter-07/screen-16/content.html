Module 11 › Chapter 11.7 › Key Commands & Recovery
lsmod / modinfo
Inspect loaded modules and module metadata to determine version and aliases.
modprobe / rmmod
Load with dependencies or remove when usage is zero; prefer modprobe for normal tasks.
dmesg & GRUB
Use dmesg for evidence; boot older kernels via GRUB to recover from recent regressions.
Final takeaway
Combine these commands with evidence capture and a fallback kernel to troubleshoot kernel and driver issues safely and effectively.
