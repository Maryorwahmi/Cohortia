Module 11 › Chapter 11.7 › Dependencies & Aliases
How modprobe chooses modules
Aliases match device IDs; depmod builds the dependency map used at runtime.
Files to check
  • /lib/modules/$(uname -r)/modules.alias — alias mappings.
  • /lib/modules/$(uname -r)/modules.dep — dependency map generated by depmod.
  • modinfo <module> — shows alias and parameter lines for a module.
Practical check
If modprobe fails, run depmod -a and ensure your module files match the running kernel version.
Quick commands
$ modinfo pcnet32 | grep -i alias
alias: pci:v00001234d0000ABCDsv*sd*bc*sc*i*

$ sudo depmod -a
$ sudo modprobe pcnet32
Key Takeaway
Dependency maps and aliases automate correct module selection; update them when modifying modules.
