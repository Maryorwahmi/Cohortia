Key Concepts — Tools & Remedies

Practical reminders for the tools and fixes you will use most often.

Configuration Errors
Syntax or include errors often prevent services from starting; run the daemon's config test to catch them before reload.
Permission Issues
Incorrect ownership or missing execute bits on parent directories block service access; use ls -l and namei -l to diagnose and chown/chmod to fix.
strace & lsof
Use strace for system call errors and lsof to see open files and sockets; together they reveal missing resources or leaks.
Final takeaway

Work top-down: confirm state, read logs, validate config and permissions, then use strace and lsof to inspect process behavior and resources.
