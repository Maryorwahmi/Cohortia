Key Concepts — Diagnostics

A short set of compact reminders to guide quick triage.

systemctl
Control and inspect systemd units; it shows state, PID, and unit configuration used for diagnosis.
journalctl
Query systemd journal entries for a unit; use -xe and time filters to isolate failure messages.
Application Logs
Look under /var/log for application-specific errors and stack traces that journalctl may not include.
Summary

Confirm state, correlate journal and app logs, and run config tests before moving to process-level inspection tools like strace and lsof.
