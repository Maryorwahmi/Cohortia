Learning Objectives

Build repeatable troubleshooting steps and tool fluency for service failures.

Bloom
Learn → Understand → Apply → Master
01
Systematic diagnosis

Confirm service state and follow a checklist from logs to process inspection. This reduces wasted restarts and narrows root causes quickly.

VERIFIED COMPETENCY MILESTONE
02
journalctl & app logs

Correlate systemd journal output with /var/log application files to see complementary messages and full stack traces when available.

VERIFIED COMPETENCY MILESTONE
03
strace & lsof

Observe system calls and open resources to diagnose missing files, permission denied errors, or sockets held by processes.

VERIFIED COMPETENCY MILESTONE
04
Config & permission checks

Run configuration tests like nginx -t and inspect ownership with ls -l and namei -l to prevent common causes of failure.

VERIFIED COMPETENCY MILESTONE
