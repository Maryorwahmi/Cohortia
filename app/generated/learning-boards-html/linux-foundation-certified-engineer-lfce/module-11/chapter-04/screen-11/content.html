Debugging scripts and compiled applications

Use simple traces for scripts and a debugger for native binaries when source-level inspection is required.

Script techniques
# Bash: enable execution trace
set -x

# Python: add basic logging
import logging
logging.basicConfig(level=logging.DEBUG)
logging.debug('starting handler')
Tracing prints the execution flow so you can see the failing statement and input values quickly.
Compiled applications
Use gdb to get a backtrace and inspect variables at the crash point. This is developer-focused and requires symbol information. When system administrators need to gather evidence, capture core dumps or run gdb in a controlled debugging session rather than instrumenting production processes live.
Caveat
Avoid leaving verbose debug output enabled in production; it may impact performance and expose sensitive data.
