Using lsof to find open files and sockets

lsof reveals which processes hold files or network ports so you can resolve conflicts or leaks.

Common lsof commands
# show processes using port 80
sudo lsof -i :80

# list files held by a PID
sudo lsof -p 12345

# find deleted files still held open
sudo lsof | grep deleted
Use lsof to detect leftovers like deleted files still consuming disk because a process holds the descriptor open, or to detect binding conflicts before changing service ports.
Example output
COMMAND   PID   USER   FD   TYPE DEVICE SIZE/OFF NODE NAME
nginx    2345  www-data  6u  IPv4  12345      0t0  TCP *:http (LISTEN)
python   3456  www-data  3u  REG   8,1  12345   567 /opt/my_app/log.txt
This shows nginx listening on port 80 and a Python process holding a log file. Use the PID to correlate with systemctl or ps to decide how to proceed.
Pro tip
Combine lsof with grep and ps to script checks that detect port conflicts during deployments.
