Learning Objectives

Apply deeper debugging methods and check the broader system context.

Bloom
Learn → Understand → Apply → Master
01
Troubleshoot common issues

Identify configuration mistakes, permission denials, and missing files that commonly stop services from starting or serving requests.

VERIFIED COMPETENCY MILESTONE
02
Debug scripts & binaries

Use trace modes for scripts and consider gdb for compiled programs when source level debugging is required.

VERIFIED COMPETENCY MILESTONE
03
Check system context

Look for disk full, file descriptor limits, and memory pressure; environmental limits often masquerade as application faults.

VERIFIED COMPETENCY MILESTONE
04
Methodical escalation

Escalate from logs and config tests to strace and lsof only when the cause remains unclear to avoid unnecessary disruption.

VERIFIED COMPETENCY MILESTONE
