Post-mortem with GDB
# Load core and get full backtrace
gdb my_app /tmp/core-my_app--
# (gdb) bt full

# Inspect a local variable and source context
# (gdb) frame 2
# (gdb) list
# (gdb) print some_variable
Keep the exact binary with -g and the source that was compiled. Without symbols, gdb shows addresses only.
Profile with perf
# Record a command with call graphs
perf record -g ./my_app
perf report

# System-wide 30s sampling
sudo perf record -a -g sleep 30
sudo perf report
Use -g for call graphs. Root may be required for system-wide kernel counters.
Live tracing: bpftrace one-liner
# Print process and filename for open syscalls
sudo bpftrace -e 'tracepoint:syscalls:sys_enter_openat { printf("%s %s
", comm, str(args->filename)); }'

# Aggregated count example
sudo bpftrace -e 'tracepoint:syscalls:sys_enter_openat { @[comm]++ } interval:s:5 { print(@); clear(@) }'
Always test bpftrace scripts on non-production hosts when possible.
Save perf.data, core dumps, and bpftrace outputs as artifacts for future analysis.
