Learning Objectives
Practical skills for post-mortem, live debugging, profiling, and tracing.
Bloom: Learn → Understand → Apply → Master
01
Use GDB for post-mortem analysis
Load core dumps to inspect call stacks and local variables to identify the exact line that crashed.
Mnemonic: stack trace + variables = root cause
VERIFIED COMPETENCY MILESTONE
02
Attach safely to live processes
Understand the impact of attaching and how to minimize disruption on production systems.
Mnemonic: pause with care — attach can halt threads
VERIFIED COMPETENCY MILESTONE
03
Profile with perf
Collect performance counters and call graphs to find CPU hotspots and cache issues.
Mnemonic: record, report, repeat
VERIFIED COMPETENCY MILESTONE
04
Use dynamic tracing (systemtap / eBPF)
Instrument kernel and user-space events safely to capture elusive runtime behavior.
Mnemonic: probe, collect, correlate
VERIFIED COMPETENCY MILESTONE
