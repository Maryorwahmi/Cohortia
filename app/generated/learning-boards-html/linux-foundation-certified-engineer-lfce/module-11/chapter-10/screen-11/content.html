Module 11 › Chapter 11.10 › Tool Selection
Quick comparison
strace
Trace syscalls and arguments for a single process; good for file/permission failures and short reproductions.
gdb
Source-level debugging and core dump inspection; use for crashes and memory errors when you have debug symbols.
perf
Sampling profiler for CPU hotspots and call graphs across user-space and kernel; use perf record & perf report.
eBPF / bpftrace
Low-overhead, in-kernel tracing for high-frequency events, syscalls, and aggregated metrics in production.
Scenario mapping
Intermittent segfault in C daemon
Generate core, load in gdb with debug symbols and run bt full to inspect the exact line and variable state.
System-wide CPU but no single top process
Use sudo perf record -a -g sleep 30 then perf report to find code paths consuming cycles across processes.
High-rate open syscalls from unknown process
Run bpftrace one-liner to print process and filename for open calls and identify the offender with low overhead.
