Quick tour
bpftrace one-liners

bpftrace offers terse expressions to attach to tracepoints, kprobes, or uprobes and print arguments or timestamps. They are ideal for short, live diagnostics.

# Print process and filename for every open syscall
sudo bpftrace -e 'tracepoint:syscalls:sys_enter_openat { printf("%s %s
", comm, str(args->filename)); }'

# Show top functions by count for 10 seconds
sudo bpftrace -e 'kprobe:do_sys_open { @[comm]++ } interval:s:10 { exit() }'
Run
Use sudo; prefer dev or staging for experiments.
Output
Live lines printed for each matched event; aggregated maps for counts.
Comparing choices
When to choose bpftrace
Low-overhead, live tracing for I/O, syscalls, and sched events; concise diagnostics in production-safe mode.
Safety note
Avoid heavy loops in probes; prefer maps and post-processing. Validate on non-production kernels first.
Pro tip
Use bpftrace aggregated maps for counts and export results rather than printing million lines in high-frequency paths.
