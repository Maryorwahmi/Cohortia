Module 11 › Chapter 11.10 › Key Concepts
GDB
Source-level debugger for post-mortem and live inspection; needs debug symbols for best results.
Core Dump
A snapshot of process memory at crash time; pair with its executable and symbols for analysis.
perf
Sampling profiler for CPU, events, and call graphs; ideal for finding performance hotspots.
Summary

Keep a short, prioritized set of artifacts: core files, perf.data, and concise trace outputs. They speed root-cause analysis and make your debugging reproducible.
