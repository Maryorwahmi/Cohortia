Advanced Debugging Techniques & Tools
From core dumps to eBPF: inspect crashes, profile CPU, and trace kernel events.

This lesson package shows why deep tools matter for intermittent crashes and subtle performance issues. Expect terminal-first demos: compiling with debug symbols, producing a core dump, using gdb to examine a backtrace, and using perf to find hot functions. We'll also introduce dynamic tracing options for when you need live, low-overhead visibility.

In this lesson: careful troubleshooting, reproducible experiments, and safety practices for production systems.
