Process Flow
perf for profiling and call graphs
Record call graphs, view hotspots, and profile across kernel and user space.
perf record → perf report
Quick reference
  • perf stat <command> — summary counters for a run.
  • sudo perf record -g <command> — record samples plus call graphs.
  • perf report — analyze perf.data and inspect call stacks and percentages.
  • perf top — live, top-like view of hottest symbols.
Misconception
Believing perf replaces functional debugging. perf shows where time is spent, not why logic is incorrect.
Example terminal steps
# Record a program with call graphs
sudo perf record -g ./my_app

# After run completes
perf report

# System-wide recording for 30s
sudo perf record -a -g sleep 30
perf report
Key Takeaway

Use call-graph sampling to prioritize optimization on functions that consume the most CPU, not guesses.
