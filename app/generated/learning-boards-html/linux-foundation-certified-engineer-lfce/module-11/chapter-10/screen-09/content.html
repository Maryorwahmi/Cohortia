Module 11 › Chapter 11.10 › systemtap Basics
Core Idea
Scripted probes that inspect kernel and user events

Write stap scripts to declare probes and actions, then run them to collect counts or arguments. Requires privilege and matching kernel stabs for best results.

When to use
  • Count or log specific kernel function calls for intermittent faults.
  • Inspect syscall arguments or user-space function entry/exit with probes.
  • Collect contextual data where sampling misses rare events.
Common mistake

Doing expensive work inside a probe. Probes fire in hot paths; heavy actions can slow or destabilize the system.

Key Takeaway

Use systemtap for targeted, scriptable kernel/user probes; keep actions minimal and test off-production first.

Example stap script
Counts a kernel function over a short run
Demo
# stap example_count.stp
probe kernel.function("do_some_io") {
  ++count[probefunc()]
}

probe timer.ms(60000) {
  foreach (f in count) {
    printf("%s %d
", f, count[f])
  }
  exit()
}
Run
sudo stap example_count.stp
Output
Function name followed by invocation count for the interval.
