Module 11 › Chapter 11.1 › Unbootable System Recovery Checklist
Timeline
  1. Boot live media to avoid writing to the broken system.
  2. Identify partitions with lsblk or fdisk -l.
  3. Mount the root and bind /dev, /proc, /sys.
  4. Chroot and run grub-install and update-grub if needed.
  5. Use journalctl -xb and check failed units with systemctl.
  6. Exit, unmount, and reboot to verify repairs.
Practice steps (hands-on)
Follow a lab to simulate a kernel update that leaves the system in emergency mode. Use the live ISO, mount and chroot to restore bootloader or revert kernels, and practice reading journal outputs to find the failing unit.
Key Takeaway

A methodical checklist reduces risk. Practice the full sequence in a VM before applying these steps to production systems.
