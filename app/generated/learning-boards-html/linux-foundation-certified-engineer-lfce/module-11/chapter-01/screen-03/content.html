Module 11 › Chapter 11.1 › Learning Objectives — Continued
05
Fix service start failures
Diagnose service failures caused by dependencies or config errors.
You will learn to inspect unit logs and the dependency chain with systemctl so you can correct the real cause instead of restarting the top-level service repeatedly.
VERIFIED COMPETENCY MILESTONE
06
Use chroot safely
Prepare bind mounts and enter the installed root for repairs.
You will practice the exact mount and bind steps required so repair commands run in the correct filesystem context and have access to device and proc information.
VERIFIED COMPETENCY MILESTONE
07
Know MBR vs GPT effects
Recognize how partition tables affect bootloader location and reinstall targets.
You will learn why installing GRUB to the correct disk matters and how a mismatch can make a device non-bootable even if the OS files are intact.
VERIFIED COMPETENCY MILESTONE
08
Practice a full recovery
Execute a stepwise rescue from live media to verify skills under controlled conditions.
This objective connects the techniques into a reproducible routine so you can recover a VM or physical server with confidence and minimal downtime.
VERIFIED COMPETENCY MILESTONE
