Module 11 › Chapter 11.1 › grub-install and grub-mkconfig
What each does

grub-install writes GRUB code to the chosen disk or EFI location so firmware can load it. grub-mkconfig -o /boot/grub/grub.cfg or update-grub scans available kernels and writes the menu configuration. They are related but not interchangeable.

Before running either ensure /boot and /boot/efi (for UEFI) are mounted inside the chroot and verify kernel files exist.

Common Mistake

Installing GRUB to a USB or the wrong disk leaves the real boot disk unchanged. Confirm with lsblk before grub-install.

Concrete commands
# reinstall bootloader to disk
grub-install /dev/sda
# rebuild GRUB config
grub-mkconfig -o /boot/grub/grub.cfg
# or on some systems
update-grub
If using UEFI, mount the ESP at /boot/efi before grub-install so the installer can place the boot entry correctly.
