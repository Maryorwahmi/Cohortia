Module 11 › Chapter 11.1 › Practice Scenario & Assessment
Scenario steps
  1. Boot a VM from live ISO and open a terminal.
  2. Identify root partition with lsblk or fdisk -l.
  3. Mount root, bind /dev /proc /sys, chroot into /mnt.
  4. Run grub-install /dev/sda and update-grub.
  5. Inspect journalctl -xb and systemctl list-units --failed.
Assessment check
Provide the exact commands you used and a short log excerpt showing the root cause. Explain how you confirmed the correct install disk and why you chose to reinstall GRUB or regenerate its config.
Key Takeaway

Assessment focuses on command accuracy, partition awareness, and interpretation of journal outputs that point to the real failure.
