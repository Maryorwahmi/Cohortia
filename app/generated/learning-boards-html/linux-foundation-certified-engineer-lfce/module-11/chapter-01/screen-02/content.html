Module 11 › Chapter 11.1 › Learning Objectives
01
Diagnose GRUB failures
Identify missing or misinstalled bootloaders and incorrect grub.cfg entries.
You will practice mounting a broken root filesystem and using grub-install and grub-mkconfig to restore the bootloader. This skill matters because a faulty bootloader prevents any kernel from starting, making the system unreachable without recovery media.
VERIFIED COMPETENCY MILESTONE
02
Analyze systemd unit failures
Use journalctl and systemctl to find failed units and dependency problems.
You will learn to use journalctl -xb and unit-specific filtering. This skill helps you find root causes when the system drops to emergency mode and prevents wasted time chasing misleading symptoms.
VERIFIED COMPETENCY MILESTONE
03
Interpret kernel panics
Read panic traces to identify faulty modules, drivers, or hardware issues.
You will practice deciding whether to boot an older kernel, run memory diagnostics, or blacklist a module. Correct diagnosis avoids unnecessary reinstallation and prevents repeat failures.
VERIFIED COMPETENCY MILESTONE
04
Recover unbootable systems
Mount, bind pseudo-filesystems, chroot, and repair system files safely.
You will follow a repeatable checklist to access a broken system and repair boot components. This reduces risk because every step preserves the installed filesystem and keeps changes reversible when possible.
VERIFIED COMPETENCY MILESTONE
