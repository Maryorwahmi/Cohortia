Module 11 › Chapter 11.1 › Using journalctl for systemd Failures
Essential commands
journalctl -xb
journalctl -u nginx.service -xb
systemctl list-units --failed
Use -xb to restrict logs to the current, failed boot and show verbose output. For specific services, the -u flag narrows the log and makes the root cause visible quickly.
Example diagnosis
If nginx.service fails, journalctl -u nginx.service -xb may show a port conflict or configuration error. If it shows a dependency failure, inspect the named dependent unit in the journal; fixing the dependency often restores the higher-level service.
Check this first
  • Look for permission denied, file not found, or address in use messages.
  • If a dependency failed, correct that unit before restarting the main service.
  • Document log excerpts before editing configuration to preserve a reference if changes worsen the situation.
