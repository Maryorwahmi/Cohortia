Timer unit example
[Unit]
Description=Runs daily log file cleanup

[Timer]
OnCalendar=*-*-* 03:30:00
Persistent=true
Unit=daily-cleanup.service

[Install]
WantedBy=timers.target
OnCalendar
Flexible calendar syntax. Use full timestamps for exact times and aliases for common schedules.
Persistent=true
Ensures a missed run occurs after boot. This is a key advantage compared to cron's behavior on downtime.
Install & enable

Place units in /etc/systemd/system, run systemctl daemon-reload, then systemctl enable --now daily-cleanup.timer
