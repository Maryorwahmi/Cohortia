What cron is

crond and crontabs

cron runs jobs from crontab files. Use crontab -e to edit user crontabs, or edit system files under /etc for system-wide jobs. Always prefer absolute paths and explicit environment settings.

Crontab format
minute hour day_of_month month day_of_week command
Common mistake
Relying on non-standard PATH or shell functions causes silent failures. Put environment setup in the script.
Key Takeaway
Use absolute paths and handle logging to avoid mailbox spam and invisible errors.
Concrete example
# Runs backup.sh every day at 02:00
0 2 * * * /usr/local/bin/backup.sh >> /var/log/backup.log 2>&1
Explanation
  • Minute 0, hour 2 triggers at 02:00 local time daily.
  • Absolute path ensures cron finds the executable without relying on PATH.
  • Redirect appends both stdout and stderr to a log file to preserve output and reduce mailbox traffic.
