Module 9 › Chapter 9.3 › Enable & verify timers
Commands
Reload units: sudo systemctl daemon-reload
Enable and start: sudo systemctl enable --now daily-cleanup.timer
List timers: systemctl list-timers --all
View logs: journalctl -u daily-cleanup.service
Verification checklist
  • Unit files in /etc/systemd/system and permissions correct.
  • Run daemon-reload and confirm timer is enabled.
  • Use list-timers to confirm next and last run times.
  • Check journalctl for service output and errors.
Pro tip

If you need to test scheduling without waiting, set a short OnCalendar or manually start the service to validate behavior under systemd.
