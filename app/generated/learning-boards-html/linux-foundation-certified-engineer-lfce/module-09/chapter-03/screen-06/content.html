System crontab format
/etc/crontab entries include an additional user column. Example: 
# /etc/crontab example
0 3 * * * root /usr/local/bin/system_cleanup.sh
This tells cron to run the command as root at 03:00 each day. The explicit user field is what distinguishes system crontab lines.
cron.d and cron.daily
Place executables in /etc/cron.daily for daily execution, or drop unit-style files in /etc/cron.d with crontab-like lines including a user field. These are ideal for package-managed tasks.
Advantage
Centralized management and simple drop-in scripts for system tasks.
Risk
Scripts often run as root; audit and use least privilege where possible.
