Module 9 › Chapter 9.3 › Security & Best Practices
Security rules of thumb
  • Least privilege: create a dedicated service user where practical, rather than using root.
  • Use absolute paths and define PATH if necessary within scripts.
  • Set Environment or EnvironmentFile in systemd units if configuration must be present.
  • Log to files or the journal and rotate logs to prevent disk issues.
  • Apply resource limits in systemd to contain runaway tasks.
Error handling
Capture and test exit codes. Use set -e or explicit checks and write meaningful messages to logs for post-mortem analysis.
Testing
Validate scripts manually and use short timers or manual starts to confirm behavior before enabling in production.
Key Takeaway

Operational safety and logging are as important as scheduling syntax. Build predictable, auditable jobs that fail loudly and safely.
