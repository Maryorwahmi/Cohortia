Module 9 › Chapter 9.3 › systemd timers
Service unit example
[Unit]
Description=My daily backup service

[Service]
Type=oneshot
ExecStart=/usr/local/bin/backup.sh
User=backupuser
WorkingDirectory=/home/backupuser
Type oneshot signals a task that runs to completion and exits. Use User to avoid running as root when unnecessary.
Timer unit example
[Unit]
Description=Runs my daily backup script

[Timer]
OnCalendar=*-*-* 02:00:00
Persistent=true

[Install]
WantedBy=timers.target
OnCalendar provides flexible calendar-style schedules. Persistent=true ensures missed runs are executed after boot.
Practical notes
  • Place both files in /etc/systemd/system/ and run systemctl daemon-reload.
  • Enable and start the timer with systemctl enable --now name.timer.
  • Inspect timers with systemctl list-timers and logs with journalctl -u name.service.
