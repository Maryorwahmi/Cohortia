Learning Objectives

Bloom: Learn → Understand → Apply → Master

Bloom's taxonomy
01
Configure and manage cron jobs

Write crontab entries, edit with crontab -e, and know when to use user vs system crontabs. Absolute paths and environment setup are critical.

VERIFIED COMPETENCY MILESTONE
02
Understand systemd timers

Explain how .timer and .service units pair, use OnCalendar schedules, and the benefits of Persistent=true for missed jobs.

VERIFIED COMPETENCY MILESTONE
03
Create custom service and timer units

Author a .service to run a script and a matching .timer that schedules it. Reload systemd and enable timers for persistent scheduling.

VERIFIED COMPETENCY MILESTONE
04
Identify security and best practices

Apply least privilege, explicit paths, logging, resource limits, and test schedules in non-production before deploying to production systems.

VERIFIED COMPETENCY MILESTONE
