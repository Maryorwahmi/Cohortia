Module 9 › Chapter 9.3 › Key Concepts — Notes
Check timers
systemctl list-timers shows next and last run times for timers.
Persistent=true
Runs missed jobs after boot to avoid gaps from downtime.
Cron scheduling quirks
Specifying both day-of-month and day-of-week can produce surprising matches; prefer clear patterns.
Test manually
Run the script manually and check logs before enabling scheduled runs.
Resource limits
Use systemd directives to cap CPU or memory for scheduled jobs if needed.
Separation of concerns
Keep scheduling in timers and logic in scripts to simplify maintenance.
Concluding thought

Combine the right scheduler with clear scripts, good logging, and least privilege to make automation safe and maintainable.
