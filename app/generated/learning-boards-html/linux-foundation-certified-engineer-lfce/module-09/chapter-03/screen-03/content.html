Learning Objectives — Verification & Practice

Practical steps to confirm that scheduled jobs work as expected.

Apply → Master
01
Inspect cron and cron directories

Know /etc/crontab, /etc/cron.d, and /etc/cron.daily locations. Use these for system-wide scheduled scripts managed by packages or root.

VERIFIED COMPETENCY MILESTONE
02
Redirect and log job output

Append stdout and stderr to files or use systemd journal integration to avoid mailbox spam and keep useful diagnostics.

VERIFIED COMPETENCY MILESTONE
03
Use systemctl and journalctl

Reload units, enable timers, start timers, and inspect logs with journalctl -u unitname to validate runs and failures.

VERIFIED COMPETENCY MILESTONE
04
Practice a full lab

Create a cleanup script, a .service unit, and a .timer unit, then enable and verify the timer works and logs to the journal or files.

VERIFIED COMPETENCY MILESTONE
