Module 9 › Chapter 9.8 › SFTP and network device automation
Process
  1. 1. Authenticate and open an SSH session with verified host keys.
  2. 2. Open an SFTP client and perform put/get operations.
  3. 3. Verify remote ownership and permissions after transfer.
  4. 4. Close SFTP and SSH channels cleanly and log results.
Example: Device config
Use netmiko when automating routers or switches. It wraps paramiko and handles prompts, timeouts, and paginated outputs for you. Example workflow: connect, send configuration commands, confirm changes, and save the running configuration. Always test commands in a sandboxed device first.
Pro tip
Record each device's response and exit status. If a command fails on one device, continue with others and reconcile later.
Common mistake
Assuming permissions are preserved. Remote umask and SELinux can change ownership; verify after upload.
