Module 9 › Chapter 9.8 › Managing systemd services from Python
Subprocess
Call systemctl with subprocess.run(['systemctl', 'start', 'my_service']) for simple control. Check return codes and stderr for failures. This is portable and easy to audit.
D‑Bus / python-systemd
Use a D‑Bus wrapper for direct interaction with systemd's API when you need unit property access, event subscription, or richer introspection.
Decision guidance
  • Choose subprocess for portability and simplicity.
  • Choose D‑Bus when you need event hooks or deep state inspection.
  • Be aware of platform dependencies when using python-systemd.
