Module 9 › Chapter 9.8 › Cloud SDKs and custom service clients
Architecture
Inventory / Control API
Provides authoritative lists of hosts or tasks to perform.
Cloud SDK
Creates snapshots, provisions VMs, or queries provider metadata.
Endpoint controller
SSH-based scripts or agents that perform the actual configuration steps.
Concrete workflow
Query inventory → snapshot targeted machines using cloud SDK → perform SSH maintenance → report results to API. Each step should be idempotent and logged.
