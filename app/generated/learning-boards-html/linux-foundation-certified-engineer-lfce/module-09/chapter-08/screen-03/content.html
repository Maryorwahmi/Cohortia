Verify each skill with a small lab

Each objective below includes a short verification step and a practical tip for avoiding common mistakes.

SSH verification

Connect to your VM, run a simple uname command, and use SFTP to transfer a file. Verify host keys are loaded rather than auto-accepted in production.

Automation verification

Run your script against multiple test hosts and inspect logs for idempotence and clear error messages.

Service control verification

Query service status, attempt a restart if necessary, and verify the status changed. Distinguish subprocess simplicity from D‑Bus depth.

Cloud SDK verification

List or tag a set of sandbox resources using environment-based credentials. Avoid committing keys and prefer temporary credentials or managed identities.
