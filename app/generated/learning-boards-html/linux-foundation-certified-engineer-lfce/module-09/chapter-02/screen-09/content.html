Definition
sed: stream edits and in-place changes
Common sed patterns
# Substitute globally on each line
sed 's/old_text/new_text/g' file.txt

# Delete empty lines
sed '/^$/d' file.txt

# In-place with backup
sed -i.bak 's/PORT=80/PORT=8080/' myconfig.conf
Always inspect the .bak file after running in-place edits to confirm behavior.
When to prefer alternatives
  • Use sed for line-based substitutions and deletions.
  • For field-aware changes or calculations, awk is often clearer.
  • For multi-line context edits, consider a small script or perl if necessary.
Pro tip

Preserve a backup when using sed -i and validate changes before replacing production files.
