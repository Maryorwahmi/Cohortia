Definition
Here documents for multiline input and remote execution
Local file creation
cat < myconfig.conf
# Configuration
SERVER_NAME="web01.example.com"
PORT=8080
LOG_LEVEL="INFO"
EOF
This generates myconfig.conf without multiple echo statements.
Remote execution
ssh user@remote_host 'bash -s' <<'EOF'
# remote script that runs there
uname -a
df -h
EOF
Quote the EOF marker to prevent local variable expansion before sending the document to the remote shell.
Key Takeaway

Here documents are an efficient way to supply multiline input; control variable expansion with quoted delimiters to avoid surprises.
