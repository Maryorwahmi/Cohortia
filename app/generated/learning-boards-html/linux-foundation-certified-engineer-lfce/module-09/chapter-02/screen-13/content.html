Implementation checklist
  1. Validate arguments and readability of the log file.
  2. Create TEMP_REPORT and register trap immediately after creation.
  3. Implement report_errors using grep -i and awk to extract timestamps and messages, and print a total count.
  4. Implement report_warnings using grep -i and wc -l to count warnings.
  5. Call both functions and append to TEMP_REPORT, then cat the report before exit.
Key Takeaway

A small collection of focused functions, paired with validation and a trap, yields a maintainable reporting utility.
