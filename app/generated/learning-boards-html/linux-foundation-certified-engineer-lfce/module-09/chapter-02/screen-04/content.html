Core Concept
Functions: define, call, and reuse
Encapsulate behavior and accept positional parameters for flexible reuse.
Definition pattern
Example function
# Define a simple greeting function
my_function() {
  echo "Hello from function!"
}

# Function with an argument
greet_user() {
  local name="$1"
  echo "Hello, $name!"
}

# Calling a function
# greet_user "Alice"
Notes: functions use positional parameters. Use local variables to avoid polluting the global namespace. Test a function directly in a shell when debugging.
Why this helps
  • Reduces duplicated code so fixes apply in one place.
  • Makes intent explicit with clear names and small responsibilities.
  • Improves testability: run the function with sample inputs in a shell.
Key Takeaway

Prefer small, argument-driven functions defined near the top of scripts so behavior is discoverable and testable.
