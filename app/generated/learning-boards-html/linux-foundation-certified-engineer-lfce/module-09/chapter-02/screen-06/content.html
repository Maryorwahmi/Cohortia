Process Flow
Error handling: set -e, exit status, and checks
Fail-fast example
# At top of script
set -e

# Any command that fails will stop the script
cp /important/source /dest/
# If cp fails, script exits immediately
Use set -e for straightforward scripts where any failure should abort the run.
Granular check example
command_that_might_fail
if [ $? -ne 0 ]; then
  echo "Error: operation failed" >&2
  # take corrective action or exit with code
  exit 1
fi
Manual checks let you log better messages, retry, or continue when appropriate.
Pro tip

Use set -e plus selective traps around known fragile commands to get the best of both approaches.

Key Takeaway

Combine fail-fast for unexpected errors and manual checks where recovery or special messaging is required.
