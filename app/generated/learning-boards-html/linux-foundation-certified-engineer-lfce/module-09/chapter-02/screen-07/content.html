Definition
trap for cleanup and signal handling
Guarantee resource cleanup and respond to signals predictably.
Pattern
TEMP_REPORT="/tmp/log_report_$$"
trap "rm -f $TEMP_REPORT" EXIT

# create and use the temp file
echo "Generating report" > "$TEMP_REPORT"
# ... more operations ...
Note: $$ expands to the current shell's PID to avoid collisions between parallel runs.
Best practices
  • Set the trap immediately after creating the resource to ensure cleanup even on early failures.
  • Keep trap handlers simple and idempotent; avoid complex logic inside the handler.
  • Test traps by simulating errors and interrupts to confirm cleanup occurs.
Common mistake

Declaring a trap after the point where an early failure can occur leaves a window where resources are not cleaned up.
