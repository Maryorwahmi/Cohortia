Logging setup
import logging

logging.basicConfig(filename='/var/log/my_python_script.log', level=logging.INFO,
                    format='%(asctime)s - %(levelname)s - %(message)s')

logging.info('Script started.')
try:
  # ... script logic ...
  logging.info('Task completed successfully.')
except Exception as e:
  logging.error(f'Script failed: {e}', exc_info=True)
Use levels DEBUG, INFO, WARNING, ERROR, CRITICAL and add exc_info=True when logging unexpected exceptions to capture tracebacks.
Exception mapping
  • FileNotFoundError → inform user and exit with status 2.
  • CalledProcessError → log stderr and exit with status 3.
  • ValueError on parsing → log and exit with status 4.
Common mistake

Relying on prints instead of structured logging makes post-failure diagnosis harder.
