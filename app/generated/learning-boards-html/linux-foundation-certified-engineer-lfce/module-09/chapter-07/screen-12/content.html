Module 09 › Chapter 9.7 › Testing & Tips
Testing strategy
  1. Unit-test parsing functions and edge cases.
  2. Mock subprocess.run for success, failure, and unexpected output.
  3. Integration test against temporary directories and controlled df output.
Common mistakes & fixes
  • Parsing fragile: use structured output or robust splitting and validation.
  • Shell injection: avoid shell=True and string concatenation.
  • Permissions: document or check file write access before logging.
Pro Tip

Keep parsing logic separate so it can be unit-tested without executing system commands.
