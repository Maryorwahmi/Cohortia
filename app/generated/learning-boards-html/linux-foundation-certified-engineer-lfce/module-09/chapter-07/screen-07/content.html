Module 09 › Chapter 9.7 › subprocess.run
Typical call pattern
import subprocess

result = subprocess.run(['df', '-h', '/'], capture_output=True, text=True, check=True)
print('Disk Usage:
', result.stdout)

try:
  subprocess.run(['systemctl', 'is-active', 'nginx'], check=True, capture_output=True)
  print('Nginx is running.')
except subprocess.CalledProcessError:
  print('Nginx is not running.')
Note the use of list arguments and check true. This ensures a CalledProcessError is raised for non-zero exit codes so you can react programmatically.
Tips and pitfalls
  • capture_output=True captures both stdout and stderr.
  • text=True decodes bytes to string using UTF-8 by default.
  • check=True raises CalledProcessError on failures; handle it in except blocks.
  • Use shell=False by default; only use shell=True with sanitized input.
Warning

Using shell=True with unsanitized input can lead to shell injection vulnerabilities.
