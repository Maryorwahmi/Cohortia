Module 09 › Chapter 9.7 › argparse
Typical argparse setup
import argparse

parser = argparse.ArgumentParser(description='A simple system monitoring script.')
parser.add_argument('-d', '--directory', type=str, default='/',
                    help='Directory to check disk usage (default: /)')
parser.add_argument('-v', '--verbose', action='store_true',
                    help='Enable verbose output')
args = parser.parse_args()

if args.verbose:
  print(f'Checking disk usage for: {args.directory}')
Argparse also supports subcommands, choices, and custom type converters for advanced validation.
Practical notes
  • Provide default values for sensible behaviour.
  • Use descriptive help strings to aid discoverability.
  • Prefer named arguments for optional values and flags for booleans.
Key Takeaway

Argparse makes scripts self-documenting and reduces manual validation work.
