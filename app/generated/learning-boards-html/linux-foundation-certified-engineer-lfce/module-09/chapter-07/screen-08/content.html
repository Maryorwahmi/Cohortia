Module 09 › Chapter 9.7 › subprocess Options
Options quick reference
  • capture_output=True — capture stdout and stderr for parsing or logging.
  • text=True — decode bytes to strings for easier processing.
  • check=True — raise CalledProcessError on non-zero exit.
  • shell=True — execute via shell; only use with trusted input.
Security note

Avoid shell mode with user-provided strings. Prefer argument lists to eliminate shell parsing altogether.

Example: replace pipeline
If you previously piped commands, consider calling components directly and combining results in Python. This avoids shell parsing edge cases and improves testability.
Key Takeaway

Use subprocess options to capture and check outputs, and prefer argument lists for security and portability.
