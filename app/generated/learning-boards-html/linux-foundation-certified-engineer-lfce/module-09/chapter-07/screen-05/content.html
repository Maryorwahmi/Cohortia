Reading logs safely
# Reading a file
from datetime import datetime
with open('/var/log/syslog', 'r') as f:
  for line in f:
    if "ERROR" in line:
      print(f"Found error: {line.strip()}")

# Writing a file
with open('/tmp/report.txt', 'w') as f:
  f.write("System health report:
")
  f.write(f"Current time: {datetime.now()}
")
Use pathlib for path manipulations and prefer utf-8 text handling where possible. For very large files, streaming line by line avoids large memory consumption.
Explanation & example
  • Context manager: ensures close even on errors.
  • Line iteration: memory-friendly for large logs.
  • Writing: open with mode 'w' and write formatted strings.
Common mistake

Opening files without a context manager can leave files open after exceptions, causing hard-to-find issues.
