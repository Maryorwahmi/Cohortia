Module 09 › Chapter 9.7 › os & sys
Core functions
os module
  • listdir, mkdir, rmdir, path.exists
  • chmod and chown interactions for permissions
  • os.environ for environment variables
sys module
  • sys.argv for raw arguments
  • sys.stdin, sys.stdout for stream handling
  • sys.exit to return status codes
Scenario

Use os.path.exists to guard file reads and use sys.exit(2) to indicate a configuration error to higher-level automation.

Quick mnemonic
Think: os = operating system actions, sys = script runtime and streams. Prefer built-in APIs over spawning commands.
Key Takeaway

Use os and sys for portability and clarity; reserve external commands for specialized tasks.
