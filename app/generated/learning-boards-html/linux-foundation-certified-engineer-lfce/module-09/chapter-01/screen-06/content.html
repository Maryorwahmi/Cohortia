Process Flow

if / elif / else and test operators

Write clear checks for files, directories, numeric comparisons, and command success to drive script decisions.

Examples
if [ -f "$CONFIG" ]; then
  echo "Found config"
elif [ -d "$CONFIG_DIR" ]; then
  echo "Found directory"
else
  echo "Missing configuration"
  exit 1
fi

# Check command by exit status
if pgrep apache2 &>/dev/null; then
  echo "Apache running"
fi
Supporting notes
Key Takeaway

Prefer testing exit status for commands and use bracket spacing correctly to avoid syntax errors.

Common mistake
Writing if [ -f$file ]; then ... without spaces makes the test fail. Always put spaces around brackets and operands.
Practice
Write checks for a file and for numeric threshold values, then log which branch executed.
