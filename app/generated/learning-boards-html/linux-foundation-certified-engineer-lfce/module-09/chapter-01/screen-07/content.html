Process

for and while loops

Use for to iterate lists and while to monitor conditions; both require safe exit conditions.

for loop example
for FILE in *.txt; do
  echo "Processing: $FILE"
  # process "$FILE"
done
while loop example
while ! ping -c 1 example.com &>/dev/null; do
  echo "Waiting for network..."
  sleep 5
done

echo "Network is up"
Practical notes
Key Takeaway

Protect loops with timeouts, retries, and logging to avoid indefinite execution and aid debugging.

Common mistake
Not quoting loop variables when filenames contain spaces. Use "${FILE}" to preserve the name.
