Definition

Shebang and Permissions

The shebang line tells the kernel which interpreter to run. Permissions allow the kernel to execute the file directly.

Correct file example
#!/bin/bash
# myscript.sh
echo "Hello from myscript"
Make executable
chmod +x myscript.sh — now you can run ./myscript.sh and the shebang will select bash.
Common mistake
Relying on running the script by calling the interpreter hides missing execute permissions and can mask portability issues.
Quick checks & examples
Run directly
./myscript.sh # uses the shebang interpreter
Run via interpreter
bash myscript.sh # executes under bash but ignores the shebang for kernel selection
Key Takeaway

Use both shebang and execute permissions for predictable script behavior across environments.
