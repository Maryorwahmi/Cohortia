Comparison

Single vs Double vs Unquoted

Single quotes
'literal text' — no expansion, useful for patterns you want passed verbatim.
Double quotes
"$VAR" — allows variable and command substitution but preserves spaces and prevents globbing.
Unquoted
$VAR — subject to splitting and globbing; risky for filenames or user input.
Examples & fix
Problem
LOG_DIR="/var/log/my logs" find $LOG_DIR -type f -mtime +7 -delete # breaks because of space
Fix
find "$LOG_DIR" -type f -mtime +7 -delete
Practice
Rewrite commands that accept paths to always quote variable expansions and check behavior with filenames with spaces.
