Log rotation: steps

Outline of a safe rotation script using Bash building blocks. Keep variables at the top for easy tuning.
#!/bin/bash
LOG="/var/log/app.log"
THRESHOLD_GB=1

if [ -f "$LOG" ]; then
  SIZE_GB=$(du -BG "$LOG" | cut -f1 | tr -d 'G')
  if [ "$SIZE_GB" -ge "$THRESHOLD_GB" ]; then
    mv "$LOG" "$LOG.$(date +%Y%m%d_%H%M%S)"
    gzip "$LOG."*
    : > "$LOG"  # truncate safely
  fi
fi
Notes & safety
Why variables matter
Change path and threshold in one place; makes review and maintenance easier.
Caveat
Test script on sample files before running on production logs. Mistakes can cause data loss.
Key Takeaway

Combine tests and file operations with logging and testing to build safe automation that preserves data integrity.
