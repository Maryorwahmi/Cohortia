Include shebang & chmod
Scripts should declare the interpreter and be explicitly executable.
Keep config at top
Variables for paths and thresholds make scripts easier to change and review.
Quote & validate
Quote expansions and check command exit statuses to avoid errors and false positives.
Final Note

Start small, test often, and iterate. These habits will turn simple scripts into reliable automation for your systems.
