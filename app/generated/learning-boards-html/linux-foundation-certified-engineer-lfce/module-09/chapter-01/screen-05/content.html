Core Concept

Variables and read

Define variables without spaces and use read to capture interactive input. Always validate and quote.

Example pattern
THRESHOLD_GB=10
read -p "Enter directory to check: " DIR
if [ -d "$DIR" ]; then
  echo "Directory exists: $DIR"
fi
Tip
Use descriptive names and keep values configurable at the top of the script.
Gotcha
Do not write MY VAR = value — spaces around equals will not assign the variable.
Variable safety
Key Takeaway

Quote variables when used: "$DIR" to preserve spaces and avoid globbing or splitting issues.

Example: Incorrect vs Correct
Incorrect: rm $FILE_NAME — may break if filename has spaces. Correct: rm "$FILE_NAME".
Practice Prompt
Prompt for a path, print it, then check for existence and exit on failure.
