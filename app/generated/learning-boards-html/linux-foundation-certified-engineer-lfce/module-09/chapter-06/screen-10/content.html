Module 9 › Chapter 9.6 › Delegation
Code Example
- name: Register new web server with load balancer
  ansible.builtin.uri:
    url: "http://loadbalancer.example.com/api/register"
    method: POST
    body_format: json
    body: '{"hostname": "{{ inventory_hostname }}"}'
  delegate_to: localhost
  run_once: true
This pattern ensures the API call runs from the control node and only once, avoiding duplicated registrations and centralizing credentials.
Guidance
  • Use run_once for group-level operations that only need to execute once.
  • Handle API failures with retries and idempotent calls to avoid double-registration.
  • Avoid delegating high-volume tasks to localhost to prevent a single point of contention.
Key Takeaway

Delegate centralized actions to the control node with run_once to perform single-group operations safely.
