Hands-on

Create my_inventory and group_vars

# my_inventory
[webservers]
web1.example.com ansible_host=your_web_node_ip ansible_user=your_ssh_user

[databases]
db1.example.com ansible_host=your_db_node_ip ansible_user=your_ssh_user

[all:vars]
ansible_python_interpreter=/usr/bin/python3

# group_vars/webservers.yml
web_docroot: /var/www/html/myapp
php_version: 8.1

# group_vars/databases.yml
mysql_root_password: "MySecureRootPassword"
mysql_app_user: webapp
mysql_app_db: app_database
Steps to validate
  1. Run ansible-inventory -i my_inventory --list to confirm groups and hosts.
  2. Run ansible-playbook -i my_inventory lamp_orchestration.yml --check to preview changes.
  3. Encrypt secrets with ansible-vault before running in production.
Security note

Store mysql_root_password and other secrets in Ansible Vault when moving beyond a lab environment.
