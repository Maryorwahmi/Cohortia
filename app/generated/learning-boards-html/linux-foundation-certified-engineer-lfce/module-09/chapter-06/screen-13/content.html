Module 9 › Chapter 9.6 › MySQL Role
Code Walkthrough
- name: Ensure MySQL server package is installed
  ansible.builtin.apt:
    name: mysql-server
    state: present
    update_cache: true
  become: true
  when: ansible_os_family == "Debian"

- name: Ensure MySQL service is running
  ansible.builtin.service:
    name: mysql
    state: started
    enabled: true
  become: true

- name: Set MySQL root password
  community.mysql.mysql_user:
    name: root
    password: "{{ mysql_root_password }}"
    state: present
  become: true
  no_log: true
Implementation notes
  • Use become for package and service tasks that require root.
  • Use no_log on tasks that handle plaintext credentials.
  • Document collection or library prerequisites outside the role so control nodes are prepared.
Key Takeaway

Test roles in isolation and ensure idempotency and secure handling of secrets before composing them into orchestration playbooks.
