Process

Rolling update example

- name: Perform rolling update on web servers
  hosts: webservers
  serial: 1
  roles:
    - webserver_update_role
Include tasks to: take the host out of rotation, update application code, run migrations, run health checks, then re-add the host to the load balancer.
Practical sequence
  1. Deregister host from load balancer (delegate_to: localhost, run_once where appropriate).
  2. Apply updates and run migrations.
  3. Run health checks and verify service responds.
  4. Re-register host and proceed to next batch.
Note

serial controls batch size; health checks and load balancer integration complete the safety model.
