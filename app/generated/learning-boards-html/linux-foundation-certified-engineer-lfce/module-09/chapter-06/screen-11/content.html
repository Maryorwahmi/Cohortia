Module 9 › Chapter 9.6 › Safety Notes

Common Mistakes

Undefined dependencies — results in connection errors when services start in the wrong order.
Inadequate testing — rolling updates without staging can cause widespread outages.
Load balancer fragility — failing register/unregister steps leave hosts misrouted.

Mitigations

  • Use wait_for and explicit checks for readiness.
  • Test rolling updates in staging and verify health before advancing batches.
  • Encrypt secrets with Ansible Vault and avoid no_log=false on sensitive tasks.
  • Set max_fail_percentage to stop a play if failures exceed tolerance.
Key Takeaway

Plan for failure modes, test in staging, and automate checks to reduce human error during orchestration.
