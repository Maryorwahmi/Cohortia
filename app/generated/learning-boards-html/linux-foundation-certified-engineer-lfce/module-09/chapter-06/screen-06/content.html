Module 9 › Chapter 9.6 › Execution Order
Process Flow

Playbook sequencing pattern

---
- name: Configure Database Servers
  hosts: databases
  roles:
    - database_role

- name: Configure Application Servers
  hosts: appservers
  roles:
    - app_role
  # use wait_for to ensure DB port is open

- name: Configure Web Servers
  hosts: webservers
  roles:
    - webserver_role
Practical checks
  • Add wait_for tasks where services must be reachable (e.g., wait_for: port=3306).
  • Use pre_tasks to prepare prerequisites and post_tasks for verification steps.
  • Role dependencies in meta/main.yml help include required roles, but do not replace runtime checks.
Common mistake

Relying solely on role order without verifying the service is actively listening can lead to transient connection failures.

Key Takeaway

Combine play ordering and explicit readiness checks for reliable orchestration.
