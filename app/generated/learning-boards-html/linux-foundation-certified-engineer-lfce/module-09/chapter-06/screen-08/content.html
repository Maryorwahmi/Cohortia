Module 9 › Chapter 9.6 › Dynamic Inventory
Definition

Inventory from external sources

Dynamic inventory scripts query cloud APIs or CMDBs and return JSON that Ansible reads at run time, keeping the inventory current for autoscaling infrastructures.

# Example run
ansible-playbook -i ec2.py deploy.yml

# Inspect inventory
ansible-inventory -i ec2.py --list
Practical notes
  • Ensure scripts return valid JSON and are executable by Ansible.
  • Use cloud tags to shape groups and maintain role separation.
  • Secure cloud credentials used by the dynamic inventory.
Warning

Dynamic inventory reflects live state; ensure your playbooks handle hosts being added or removed during a run.
