Architecture

Role layout and dependency pattern

Roles keep tasks, handlers, defaults, vars, files, templates and meta together. Declare dependencies in meta/main.yml to ensure required roles run first. 
# roles/webserver/meta/main.yml
dependencies:
  - { role: common }
Best practices
  • Design roles to be idempotent and targeted (one responsibility per role).
  • Use handlers to restart services only when configuration changes.
  • Keep role defaults minimal and overwrite with group_vars when needed.
Misconception

Role dependencies ensure inclusion, not operational readiness. Add runtime checks where necessary.

Key Takeaway

Use roles and meta dependencies for modularity; use readiness checks for runtime guarantees.
