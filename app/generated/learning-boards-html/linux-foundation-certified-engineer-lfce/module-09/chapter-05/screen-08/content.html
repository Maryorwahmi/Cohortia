Vault commands
ansible-vault create roles/nginx_webserver/vars/secret_vars.yml
ansible-vault edit roles/nginx_webserver/vars/secret_vars.yml
ansible-vault view roles/nginx_webserver/vars/secret_vars.yml
Store API keys, passwords, and other sensitive values in Vault-encrypted files. Provide the password at runtime rather than embedding it in scripts or code repositories.
Include and use
- name: Load secret variables
  ansible.builtin.include_vars:
    file: secret_vars.yml
    name: secrets

# then use {{ secrets.db_password }} in templates or tasks
Security note
Use a vault password file with strict permissions for automation, and never commit that file to VCS.
