Common facts
  • ansible_os_family — OS family such as Debian or RedHat
  • ansible_default_ipv4.address — default IPv4 address
  • ansible_memtotal_mb — memory in MB
Use facts in templates and conditions to make decisions like which package name to install or which path to use for logs.
Variable precedence (simplified)
Extra vars (-e) > Playbook vars > Inventory vars > Role vars > Role defaults. When debugging, print values with debug to confirm which level provided the final value.
Tip
Document which variables are intended to be overridden and where to avoid accidental conflicts.
