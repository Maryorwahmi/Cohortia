Task with notify
- name: Deploy custom Nginx configuration
  ansible.builtin.template:
    src: nginx.conf.j2
    dest: /etc/nginx/sites-available/default
    owner: root
    group: root
    mode: '0644'
  notify: restart nginx
If the template changes, the task reports changed and the handler will be queued. Handlers run at the end of the play and only once per handler name.
Handler example
---
- name: restart nginx
  ansible.builtin.service:
    name: nginx
    state: restarted
  become: true
Pro tip
Test handlers by running the playbook twice and confirming only the first run triggers the restart.
Common mistake
Avoid direct immediate restarts in tasks; they cause unnecessary disruptions when no change occurred.
