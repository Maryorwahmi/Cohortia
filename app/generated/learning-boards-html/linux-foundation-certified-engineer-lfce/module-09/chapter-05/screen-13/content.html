Question 1
Which approach ensures a service restarts only when its config file changed? The correct answer is: define a handler and use notify on the template task. Handlers run once at the end of the play when notified.
Question 2
How to store a DB password securely for use in a template? Encrypt the password with Ansible Vault, include the file with include_vars, and reference the variable in your template. This avoids plain text secrets in VCS.
