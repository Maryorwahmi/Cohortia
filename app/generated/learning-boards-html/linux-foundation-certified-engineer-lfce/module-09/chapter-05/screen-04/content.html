Definition

Role directory

my_role/
├── defaults/
├── handlers/
├── tasks/
├── templates/
├── files/
├── vars/
├── meta/
└── README.md
Defaults are low-precedence values you expect to override.
Handlers live in handlers/main.yml and are triggered by notify.
Templates are Jinja2 files placed in templates/ and rendered by the template module.
Example use
Reference a role in a playbook to apply its tasks and handlers to hosts. Ansible will look for tasks/main.yml and handlers/main.yml automatically in the role directory. This keeps the playbook focused on which roles to run and on which hosts.
Playbook snippet
---
- name: Deploy web server with Nginx role
  hosts: webservers
  become: true
  roles:
    - webserver
Concrete example
Extract install and config tasks for Nginx into an nginx_webserver role so different projects can reuse it.
Key takeaway
Roles reduce duplication and make automation easier to reason about.
