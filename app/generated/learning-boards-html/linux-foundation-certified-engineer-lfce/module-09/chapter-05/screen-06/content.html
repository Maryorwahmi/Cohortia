Template: index.html.j2
<!DOCTYPE html>
<html>
<head>
    <title>Welcome to {{ inventory_hostname }}</title>
</head>
<body>
    <h1>Hello from {{ inventory_hostname }}!</h1>
    <p>This page is served by Nginx on port {{ nginx_port }}.</p>
    <p>OS Family: {{ ansible_os_family }}</p>
</body>
</html>
Template: nginx.conf.j2
server {
    listen {{ nginx_port | default(80) }};
    server_name {{ inventory_hostname }};
    root {{ app_root_dir }};
    index index.html;

    access_log {{ nginx_log_path }};
    error_log /var/log/nginx/custom_error.log;

    location / {
        try_files $uri $uri/ =404;
    }
}
Deploy templates with the template module and include notify to trigger an appropriate handler when the file changes. This keeps service restarts controlled and idempotent.
