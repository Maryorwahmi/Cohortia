Mistake
Over-templating: templating whole files when a small change is needed.
Vault password leaked: storing password file in VCS or weak permissions.
Handlers causing repeated restarts due to non-idempotent handlers.
Mitigation
Prefer lineinfile/blockinfile for small edits; keep templates focused.
Use vault_password_file with strict permissions and do not commit it.
Make handlers idempotent and test by running plays repeatedly.
