Run a playbook in check mode to confirm defaults are used correctly. Remember: defaults have the lowest precedence and are intended to be overridden by inventory or -e values.
Concrete example
If you create defaults/main.yml with nginx_port: 8080, a host-specific inventory can override it to 80 without editing the role. This enables environment-specific configuration while keeping the role generic.
Common mistake
Putting secrets in defaults or committing them to VCS. Use Ansible Vault for secrets instead.
