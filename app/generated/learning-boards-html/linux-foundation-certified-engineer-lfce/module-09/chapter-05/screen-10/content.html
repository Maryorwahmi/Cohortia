Starter commands
mkdir -p my_nginx_project/roles/nginx_webserver
cd my_nginx_project
ansible-galaxy init roles/nginx_webserver
# create my_inventory with a webservers group
Then populate defaults, tasks, templates, and handlers as shown in the chapter. Use ansible-playbook with the inventory file to run the role against your managed node.
Playbook: deploy_web.yml
---
- name: Deploy Nginx web server using role
  hosts: webservers
  roles:
    - nginx_webserver
Verify
Open http://your_managed_node_ip:8080 to see the rendered index.html. Check /var/log/nginx/custom_access.log and /var/www/my_app/index.html to confirm behavior.
