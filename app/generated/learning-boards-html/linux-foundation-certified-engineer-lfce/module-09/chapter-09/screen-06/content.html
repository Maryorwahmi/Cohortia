Module 10 › Chapter 9.9 › Init, Add, Commit
Terminal sequence (example)
mkdir my_automation_project
cd my_automation_project
git init
# create .gitignore before first commit
echo ".venv/" > .gitignore
echo "__pycache__/" >> .gitignore
echo "*.retry" >> .gitignore
# add a simple script
echo '#!/bin/bash' > disk_check.sh
echo 'echo "Disk OK"' >> disk_check.sh
chmod +x disk_check.sh
# stage and commit
git add .
git commit -m "Initial commit: add disk_check script and .gitignore"
Note: if you accidentally committed a file that should be ignored, remove it from tracking with git rm --cached <file> and commit the removal.
Example Explanation
We create a .gitignore early to prevent accidental tracking of virtual environments and caches. Small, descriptive commits make history actionable.
Key Takeaway
Initialize and ignore first, then stage deliberate changes; this preserves clean history.
