Module 10 › Chapter 9.9 › Ansible Repo Layout
Suggested layout
roles/
Reusable roles, e.g., roles/monitoring_agent/tasks/main.yml
inventories/
Environment inventories: staging, production
group_vars/ host_vars/
Per-group and per-host variable files
playbooks/ or root playbook
Main orchestration entry points
scripts/ or src/
Helper scripts and Python modules
README, .gitignore, ansible.cfg
Operational guidance and ignored patterns
Example
Include roles by name in your playbook to keep plays concise and role responsibilities clear.
