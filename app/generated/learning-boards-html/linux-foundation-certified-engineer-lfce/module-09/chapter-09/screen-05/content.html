Module 10 › Chapter 9.9 › Daily Workflow
Process Steps
  1. Initialize repository: git init.
  2. Check status often: git status.
  3. Stage changes: git add file or git add ..
  4. Commit with intent: git commit -m "message".
  5. Push/pull with remotes: git remote add origin <URL>, git push, git pull.
Example
After adding a new role, stage changed files, commit with a descriptive message, then push to origin on your feature branch for review.
Mistake to avoid
Committing unrelated changes together makes it hard to revert. Instead, create logical commits each focused on one change or fix.
