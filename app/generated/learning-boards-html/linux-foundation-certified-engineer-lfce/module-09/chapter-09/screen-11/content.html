Module 10 › Chapter 9.9 › Remotes & Collaboration
Key remote commands
# add a remote
git remote add origin https://example.com/your/repo.git
# push branch and set upstream
git push -u origin main
# pull changes from remote
git pull origin main
If others update main while you're working, pull their changes first and resolve any conflicts before pushing to keep history linear and shared. Use pull requests for review and discussion when available.
Example
Push your feature branch for backup and for reviewers to fetch and test the change in their own environment.
