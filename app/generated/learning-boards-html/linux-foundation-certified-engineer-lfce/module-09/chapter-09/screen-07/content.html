What staging does
  • Selects specific file contents for the next commit.
  • Enables atomic commits: group related changes together.
  • Helps create clear history that supports blame and reverts.
Example
Stage only the role task change: git add roles/monitoring_agent/tasks/main.yml, then commit with a specific message.
Misconception
People sometimes assume git add stages a file's path only; it stages the current content as a snapshot for the next commit. If you edit files after staging, remember to stage again before committing to capture newer content.
Key Takeaway
Use the index intentionally to create commits that are easy to review, revert, and understand later.
