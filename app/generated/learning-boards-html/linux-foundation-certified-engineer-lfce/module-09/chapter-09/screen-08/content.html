Branch workflow
# create and switch
git checkout -b feature/add-monitoring
# make changes, then stage and commit
git add .
git commit -m "Feature: added monitoring role"
# switch back and merge
git checkout main
git merge feature/add-monitoring
If a conflict occurs, open the file, resolve the conflicting sections, then git add the resolved file and complete the merge with a commit. Conflicts are a sign of overlapping edits and need human judgment.
Team pattern
Prefer short-lived branches and pull requests to enable review, reduce conflicts, and keep integration frequent.
