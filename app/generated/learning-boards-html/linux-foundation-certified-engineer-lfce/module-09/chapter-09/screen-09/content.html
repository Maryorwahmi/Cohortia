Example .gitignore
# .gitignore example
*.log
*.swp
.venv/
__pycache__/
ansible.cfg
*.retry
secrets.yml
If secrets.yml was committed accidentally, remove it from tracking and rotate keys: git rm --cached secrets.yml, then commit and rotate the credential.
Warning
Adding a file to .gitignore does not remove it from existing commits or history. Use removal and credential rotation when exposure occurs.
Key Takeaway
Never commit plain-text passwords; store only encrypted vault files and provide passwords securely at runtime.
