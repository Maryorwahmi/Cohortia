Module 10 › Chapter 9.9 › Lab Walkthrough
Step-by-step
Prepare
cd into your Ansible project and run git init. Create a .gitignore listing .venv, __pycache__, and local configs.
Feature work
Create a branch git checkout -b feature/add-monitoring, scaffold the role and update playbook, then git add . and git commit -m "Feature: added monitoring_agent role".
Merge & Push
Switch to main, merge the feature branch, resolve conflicts if any, and push to a remote if configured.
Verify
Use git status and git log --oneline to confirm the commit history and current branch state.
Lab Tip
Keep changes small and commit messages precise. This makes review and later debugging much easier.
