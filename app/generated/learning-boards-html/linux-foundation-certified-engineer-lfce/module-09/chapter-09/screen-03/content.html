Module 10 › Chapter 9.9 › Applied Objectives
Assessment-aligned Objectives
01 Initialize & Commit
Create a repository, add files, set .gitignore, and make a meaningful initial commit that records intent.
02 Branch & Merge
Create a feature branch, implement a role or script change, and merge after resolving conflicts and review.
03 Remote Collaboration
Connect to a remote repository, push branches, and pull upstream changes to keep synchronized.
04 Repo Hygiene
Organize roles, inventories, scripts, and ignore transient files; commit vault files encrypted, not the password.
