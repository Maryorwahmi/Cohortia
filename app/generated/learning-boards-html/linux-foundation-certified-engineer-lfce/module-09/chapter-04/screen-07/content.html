Core Concept

What modules do

Modules perform discrete tasks and return structured results. They are transferred and executed remotely and should aim to be idempotent.

Popular modules
  • ansible.builtin.apt / yum / package — manage packages
  • ansible.builtin.service — manage services
  • ansible.builtin.copy / file — manage files and permissions
  • ansible.builtin.user / group — manage accounts
Misuse
Using shell when a module exists makes tasks non-idempotent and brittle across distributions.

Concrete example

Idempotent: 
- name: Ensure nginx installed
  ansible.builtin.apt:
    name: nginx
    state: present
Non-idempotent shell: 
- name: Install nginx with shell
  ansible.builtin.shell: |
    apt-get update && apt-get install -y nginx
Key Takeaway

Prefer native modules for predictable, repeatable results. Reserve shell for tasks without module support and test carefully.
