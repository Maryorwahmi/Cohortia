Process Flow

Common ad-hoc patterns

Connectivity check
ansible all -m ping
Run a simple command
ansible webservers -a "uptime"
Install package (group)
ansible databases -m apt -a "name=postgresql state=present"
When to convert to playbook
If you repeat a sequence of ad-hoc steps or need testing and version control, create a playbook instead.

Quick checklist

  • Prefer modules in ad-hoc calls when possible.
  • Confirm the target group is correct to avoid accidental changes.
  • For audit and reuse, move sequences into playbooks.
Key Takeaway

Ad-hoc commands are fast and useful for checks; use playbooks for repeatability, testing, and auditing of configuration changes.
