Module 09 › Chapter 9.4 › Key Concepts
Agentless
Ansible uses SSH to run ephemeral modules; no persistent agent is required on managed nodes.
Inventory
Host groups and variables let you target specific machines and set connection values like ansible_user.
Idempotence
Modules should leave systems in the desired state without producing repeated side effects when rerun.
Summary
Design automation around secure SSH, accurate inventories, and idempotent modules for predictable, repeatable configuration management.
