Lab Walkthrough

Control node install

Install Ansible with your package manager. Example: on Debian run update and apt install ansible. Confirm ansible --version once done.
SSH keys
Generate keys with ssh-keygen and copy public keys to managed nodes with ssh-copy-id to enable passwordless access.
Inventory
[target_servers]
192.0.2.10 ansible_user=ubuntu

Verification

Run ansible all -m ping to confirm that the control node can reach all hosts. If you see authentication failures, recheck keys and ansible_user settings.
Gotcha
Minimal images may lack Python; install Python or use raw commands as a bootstrap step so Ansible can run modules.
Key Takeaway

A reliable control node setup — Ansible installed, SSH keys distributed, inventory verified, and Python present on targets — is essential to safe automation.
