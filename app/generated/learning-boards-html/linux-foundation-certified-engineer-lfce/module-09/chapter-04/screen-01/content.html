Introduction to Ansible

A hands-on introduction to agentless automation, inventories, modules, ad-hoc commands, and playbooks to manage system state consistently.

In this lesson
Control node and managed nodes, inventory and groups, ad-hoc commands, writing a simple Nginx playbook, and a lab to create a user and directory.
Why it matters
Automation reduces manual errors and scales configuration across dozens or hundreds of servers while preserving reproducibility and auditability.
Key takeaway
Agentless SSH and idempotent modules let you describe desired state and apply it reliably across diverse systems.
Visual summary
Control node drives managed nodes using an inventory and modules over SSH.
Control Node
Your workstation or server with Ansible and Python installed. Runs playbooks and ad-hoc commands.
Managed Nodes
Target servers reachable via SSH. No Ansible agent required; standard OS tooling and Python are used.
Inventory
A hosts file or dynamic source that organizes servers into groups and allows variables per host or group.
Playbook
YAML file that maps hosts to tasks, using modules to perform idempotent operations and manage desired state.
