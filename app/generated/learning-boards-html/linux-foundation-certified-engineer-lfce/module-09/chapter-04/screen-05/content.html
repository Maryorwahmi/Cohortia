Definition

Parts of the architecture

  • Control node: Runs Ansible CLI and playbooks; requires Python and Ansible.
  • Inventory: Hosts file or dynamic source that groups managed nodes.
  • Managed nodes: Targets reachable via SSH; modules execute briefly and return results.
  • Communication: SSH with keys is recommended for secure, passwordless operation.
Misconception
Ansible installs an agent — false. Modules are copied and run momentarily; no persistent agent is required.
Execution flow
1. Command
You run ansible or ansible-playbook from control node.
2. Push module
Ansible copies a module payload to managed nodes over SSH.
3. Execute & return
The module runs and returns a result to the control node for reporting.
Concrete example
Running ansible webservers -m ping connects to each host in the webservers group, executes a small ping module, and reports success or failure back to the control node.
Key Takeaway

Secure SSH and inventory validation are prerequisites for reliable automation; modules are ephemeral and do not leave agents behind.
