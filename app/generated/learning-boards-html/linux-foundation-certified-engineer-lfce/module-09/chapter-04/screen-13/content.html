Assessment & Practice

Sample quiz

Q: Check disk space on database group — which command?
ansible databases -m command -a "df -h"
Why: command module runs a shell command and targets the databases group explicitly.
Playbook variable approaches
  • Separate tasks with when conditions per OS family.
  • Define package_name in inventory for each host or group.
  • Use a vars block to compute package_name based on facts.

Pre-run checklist

  • Validate inventory format and ansible_user settings.
  • Confirm SSH key connectivity with ansible -m ping.
  • Run --syntax-check and --check to validate YAML and simulate changes.
  • Start with a staging group or single host before wide deployment.
Key Takeaway

Combine quiz practice with a pre-run checklist to build confidence and reduce automation risk.
