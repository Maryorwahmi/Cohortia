Lab Walkthrough
setup_dev_environment.yml
---
- name: Setup development user and project directory
  hosts: target_servers
  become: true
  tasks:
    - name: Ensure 'devuser' group exists
      ansible.builtin.group:
        name: devuser
        state: present

    - name: Ensure 'devuser' user exists with home directory
      ansible.builtin.user:
        name: devuser
        group: devuser
        shell: /bin/bash
        state: present
        create_home: true

    - name: Create the project directory
      ansible.builtin.file:
        path: /opt/dev_projects
        state: directory
        owner: devuser
        group: devuser
        mode: '0775'

    - name: Set permissions for dev_projects to allow group write
      ansible.builtin.command: chmod g+s /opt/dev_projects # Setgid bit for new files to inherit group

Checklist

  • Ensure inventory lists target_servers with correct ansible_user.
  • Run ansible-playbook with --check to preview changes.
  • Verify post-run with id devuser and ls -ld /opt/dev_projects.
Key Takeaway

Use idempotent modules for user and file management, test with dry runs, and validate results on the managed node.
