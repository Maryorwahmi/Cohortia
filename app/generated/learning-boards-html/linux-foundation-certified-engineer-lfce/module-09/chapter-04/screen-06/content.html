Inventory structure

Use groups and optional variables to target hosts precisely. Keep files readable and versioned with your config repo.

Example hosts file
[webservers]
web1.example.com
web2.example.com

[databases]
db1.example.com ansible_user=dbadmin
Tips
  • Version your inventory or generate it dynamically for cloud environments.
  • Set ansible_user when the SSH login differs from your control node user.
  • Test groups with ansible -m ping before running changes.

Common mistakes

Formatting errors
Missing newlines or incorrect spacing can make hosts invisible to Ansible.
Wrong connection user
If ansible_user is wrong, SSH will fail; prefer key-based authentication and test with ping.
Dynamic inventories
When hosts change often, use dynamic sources but validate the output format matches Ansible expectations.
Key Takeaway

Group hosts logically, set connection vars explicitly when needed, and always verify reachability before applying playbooks.
