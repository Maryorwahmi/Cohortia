Common mistakes

  • Malformed inventory or incorrect ansible_user entries.
  • Missing SSH keys or blocked SSH ports.
  • Using shell for tasks that have idempotent modules.
  • Forgetting become for privileged operations.

Safety practices

Run ansible-playbook --syntax-check to catch YAML mistakes.
Use ansible-playbook --check for a dry run, keeping in mind some modules cannot fully simulate.
Prefer small, incremental changes and test in staging before production.
Misconception check

Dry runs are helpful but not infallible; always complement them with testing in representative environments.
