Validation & Recovery
Check faillock
sudo faillock --user testuser
# Expected output shows fail count and unlock time
Reset when necessary after verification:
sudo faillock --user testuser --reset
Test password policy
sudo passwd testuser
# Try weak passwords to see rejection messages, then set a compliant password.
Practical note
Correlate faillock output with auth logs to determine the root cause of denials.
Audit
Log manual resets and changes to maintain an audit trail for security reviews.
Key Takeaway
Verification and controlled resets keep your policy effective while preserving access when needed.
