Session — Setup & teardown
Common session modules
  • pam_systemd.so — registers the session with systemd logind.
  • pam_limits.so — applies limits from /etc/security/limits.conf.
  • pam_mkhomedir.so — creates home directories on login if missing (when used).
Why session modules matter
They control environment and resource policies. Misconfigured session modules can leave accounts without correct limits or fail to register sessions for logging and accounting.
Common Pitfall
Removing pam_systemd.so on a systemd-based host can break session accounting and desktop session behavior.
Pro tip
After session edits, log in and run limits and env checks to confirm behavior applies as expected.
Key Takeaway
Session modules ensure the login is usable and accountable; treat them as part of system hardening.
