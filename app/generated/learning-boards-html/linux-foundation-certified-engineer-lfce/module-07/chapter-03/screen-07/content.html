Password Policy
pam_pwquality example
password required pam_pwquality.so retry=3 minlen=12 dcredit=-1 ucredit=-1 ocredit=-1 lcredit=-1 reject_username enforce_for_root remember=5
This enforces minimum length, at least one digit, uppercase, lowercase, and special character, prevents username-based passwords, applies to root, and remembers five previous passwords.
Arguments explained
  • minlen — minimum characters required.
  • dcredit/ucredit/ocredit/lcredit — set negative values to require that class.
  • remember — number of old passwords to prevent reuse.
  • reject_username — disallow passwords based on the username.
Misconception
Making policies too strict without testing causes frequent help desk calls; balance security and usability.
Pro tip
Use retry=3 to allow users to correct mistakes during passwd operations.
Key Takeaway
Configure pam_pwquality with realistic defaults and verify with passwd before rolling out broadly.
