Account — Eligibility checks
Account modules evaluate attributes like expiration, maintenance locks, and faillock state recorded earlier.
Common modules
  • pam_unix.so — account checks for local accounts.
  • pam_nologin.so — prevents login when /etc/nologin exists.
  • pam_faillock.so — consulted to enforce lockouts.
Example account entry
account required pam_faillock.so
account required pam_unix.so
Account lines ensure that previously recorded lock state blocks access even if authentication succeeded.
Misconception
Account modules are not just optional checks — they enforce system policies after identity is confirmed.
Pro tip
Place faillock in account section to ensure locks block access regardless of auth results.
Key Takeaway
Account checks enforce eligibility rules that are separate from password verification.
