Safe Editing Workflow
Backup commands
sudo cp /etc/pam.d/sshd /etc/pam.d/sshd.bak
sudo cp /etc/pam.d/system-auth /etc/pam.d/system-auth.bak
Keep backups with timestamps when making multiple edits.
Test commands
# Check faillock status
sudo faillock --user testuser
# Reset faillock
sudo faillock --user testuser --reset
# Change password
sudo passwd testuser
Danger
Never close your only admin session until you verify the change on a separate console.
Recovery
If locked out, restore backup file from console or use single-user mode if necessary.
Key Takeaway
Backups and alternate sessions make PAM edits safe. Validate with faillock and passwd before finishing.
