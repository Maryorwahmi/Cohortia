Module 7 › Chapter 7.6 › NOPASSWD
Example: narrow NOPASSWD
adminuser ALL=(ALL) NOPASSWD: /usr/sbin/systemctl restart httpd

This is acceptable for automation that only needs to restart a specific service. Use exact paths and exact commands.

Danger: broad NOPASSWD
%dev_team ALL=(ALL) NOPASSWD: ALL
This configuration removes the authentication barrier and is a major security risk. Avoid it in production.
Mitigation

If automation requires passwordless execution, use a dedicated service account with a Cmnd_Alias for precisely the commands it needs, and enable strict logging for that account.
