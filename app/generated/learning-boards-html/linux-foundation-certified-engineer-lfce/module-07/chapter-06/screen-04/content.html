Module 7 › Chapter 7.6 › Why use sudo?
Definition

Sudo allows specified users to run commands as another user, usually root, while recording who ran the command and requiring the invoking user's password.

Concrete example
# Allow ops to restart httpd only
webop ALL=(root) /usr/sbin/systemctl restart httpd
Common misconception

Sudo is not just convenience: its authentication and logging are security features. Also, sudo does not protect against poorly specified command paths; use absolute paths.

Key Takeaway

Grant only the commands a user needs and ensure those entries are testable and logged.

Visual: Delegation cards

Audit
Sudo records which user ran the command and when, enabling forensics if something goes wrong.
