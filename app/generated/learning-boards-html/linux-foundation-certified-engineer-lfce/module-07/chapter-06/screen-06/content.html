Row format
user_spec  host_spec=(runas_spec)  tag_list:  command_spec

# Example
user_name  ALL=(ALL)  ALL
Elements: user or %group, host constraint, runas user or group, optional tags like NOPASSWD, and the allowed commands. Use absolute paths for commands.
Example: safer use
Cmnd_Alias WEB_SERVICES = /usr/sbin/systemctl restart httpd, /usr/sbin/systemctl status httpd
WEBADMINS ALL=(root) WEB_SERVICES
This grants only two commands to the WEBADMINS alias, improving readability and limiting scope.
Runas specifics

Runas allows specifying a user and optionally a group using (user:group). When omitted, commands run as root by default. For database maintenance, you may want commands to run as the postgres user.

Misconception check

Never assume an entry applied system-wide. If the host field restricts a rule to a hostname, it will not apply elsewhere. Use host specifications intentionally.
