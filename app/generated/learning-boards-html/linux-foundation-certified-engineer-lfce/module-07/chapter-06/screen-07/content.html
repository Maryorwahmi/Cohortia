Module 7 › Chapter 7.6 › Aliases
Alias examples
User_Alias      WEBADMINS = john, jane
Cmnd_Alias      WEB_SERVICES = /usr/sbin/systemctl restart httpd, /usr/sbin/systemctl status httpd
WEBADMINS ALL=(root) WEB_SERVICES
Aliases let you change membership or command lists in one place instead of editing many lines. They help when teams or responsibilities change.
Operational tip

When adding or removing users from an alias, prefer group membership for dynamic team changes instead of editing sudoers directly. Still use visudo for edits.

Misuse example

An alias that expands to ALL or includes wildcards can unintentionally grant broad root access. Audit aliases for overly permissive entries.
