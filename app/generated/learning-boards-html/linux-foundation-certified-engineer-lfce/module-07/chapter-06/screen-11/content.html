Module 7 › Chapter 7.6 › Common Mistakes
Mistake examples
  • Editing /etc/sudoers directly instead of using visudo.
  • Using command names without absolute paths.
  • Granting NOPASSWD: ALL or broad wildcard commands.
  • Leaving entries for inactive users or stale groups.
How to avoid
Backup first, edit with visudo, require exact command paths, prefer aliases over wildcards, schedule periodic sudoers reviews, and enable logging.
Tip: Automate checks with visudo -c in CI before deploying configuration changes.
