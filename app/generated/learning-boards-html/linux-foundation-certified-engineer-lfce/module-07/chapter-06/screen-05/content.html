Module 7 › Chapter 7.6 › visudo
Steps to edit safely
  1. Backup: sudo cp /etc/sudoers /etc/sudoers.bak
  2. Edit: sudo visudo and make changes within the editor.
  3. Validate: visudo will check syntax on save; use visudo -c to check files non-interactively.
  4. Test: sudo -l -U username and run allowed commands to confirm behavior.
Warning

Do not edit /etc/sudoers with a plain text editor; a syntax mistake can lock out all admin access.

Quick command examples
# Backup
sudo cp /etc/sudoers /etc/sudoers.bak

# Edit safely
sudo visudo

# Non-interactive check
sudo visudo -c

# List allowed commands for a user
sudo -l -U alice
Example scenario

You add a single line for a test user, save via visudo, then run sudo -l for that user. If visudo reports an error, it will prompt you to fix or abort without saving.

Common mistake

Forgetting to use absolute paths or inserting uncontrolled wildcards can open broader privileges than intended. Always specify full command paths in your sudoers entries.
