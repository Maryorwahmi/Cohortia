Module 7 › Chapter 7.6 › Key Commands
visudo
sudo visudo
Safe editor that checks syntax before saving /etc/sudoers.
List privileges
sudo -l -U username
Shows allowed commands for a user; use it to validate entries after edits.
Run as another user
sudo -u postgres psql
Execute commands as a different user to confirm runas behavior and permissions.
Final takeaway

Combine visudo, sudo -l, and sudo -u when changing sudoers: edit safely, test thoroughly, and verify logs for auditability.
