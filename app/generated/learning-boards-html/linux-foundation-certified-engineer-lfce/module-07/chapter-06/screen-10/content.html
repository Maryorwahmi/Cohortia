Module 7 › Chapter 7.6 › su vs sudo
su

Switches user context to the target account and requires the target account's password. Provides a full login environment when using a dash.

Auditing: limited. su itself does not provide a clear record of the original user for each command executed after the switch.
sudo

Executes single commands as another user, typically authenticating the invoking user and logging the action. Supports fine-grained rules and auditing.

Auditing: strong. Sudo records which user ran which command and when.
Best Practice

Prefer sudo for daily admin tasks. Use su only when you explicitly need a root login environment, and ensure additional session auditing if possible.
