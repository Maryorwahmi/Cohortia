Learning Objectives

Learn, understand, apply, and master sudo configuration and auditing.
Bloom: Learn → Understand → Apply → Master
01
Purpose & Security Benefits

Explain how sudo supports least privilege and provides an auditable trail for administration. This matters because it reduces the risk of misuse while preserving accountability.

Mnemonic: padlock + logbook
VERIFIED COMPETENCY MILESTONE
02
Safe sudoers editing

Use visudo for syntax checking and saving, preventing lockouts from malformed entries. Practice: create a backup then edit within visudo.

Mnemonic: safety helmet
VERIFIED COMPETENCY MILESTONE
03
Granular policies & aliases

Create Cmnd_Alias and User_Alias entries to grant only required commands, and avoid NOPASSWD for broad privileges. Practice: define a WEB_SERVICES alias for service management.

Mnemonic: tidy toolbox
VERIFIED COMPETENCY MILESTONE
04
Logging & auditing

Configure Defaults logfile, log_input and log_output to capture command activity and outputs for critical systems. Verify entries in the configured sudo log.

Mnemonic: magnifying glass
VERIFIED COMPETENCY MILESTONE
