Module 7 › Chapter 7.6 › Key Concepts
sudo
Execute commands as another user with authentication and logging, enabling least privilege delegation.
/etc/sudoers
The authoritative file defining who can run which commands. Edit only with visudo to avoid syntax errors.
NOPASSWD:
Allows passwordless execution for specified commands; useful for automation but risky if applied broadly.
Summary

Design sudo policies with least privilege, use visudo for edits, prefer aliases for maintainability, and enable logging to record administrative activity.
