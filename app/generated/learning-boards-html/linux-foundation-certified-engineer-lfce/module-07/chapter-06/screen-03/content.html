Practice & Validation

Skill demonstrations you will perform in the lab: backup, safe edit, test privileges, and check logs.

Backup

Create a copy of /etc/sudoers before editing so you can restore if necessary.

Edit

Use sudo visudo to open the file with syntax checking before saving changes.

Test

Run sudo -l -U username and sudo -u target command to validate permissions behave as intended.

Quick Tip

Prefer precise command paths and aliases rather than broad ALL grants. This reduces attack surface and prevents accidental privilege escalation.
