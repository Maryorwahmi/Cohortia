Module 7 › Chapter 7.6 › Sudo Logging
Configuration snippet
# Add these lines in visudo
Defaults    logfile=/var/log/sudo.log
Defaults    log_input
Defaults    log_output
After adding these, test by running a privileged command and check /var/log/sudo.log for entries. Ensure only authorized staff can read the sudo log and configure logrotate to prevent unbounded growth.
Why it matters

Command logs support accountability and are often required for compliance and incident investigations.

Testing
# Run a command and watch the log
sudo systemctl status nginx
sudo tail /var/log/sudo.log
