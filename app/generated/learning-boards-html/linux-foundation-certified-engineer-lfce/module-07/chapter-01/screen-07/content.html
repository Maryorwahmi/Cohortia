Module 7 › Chapter 7.1 › Modifying users
Common commands
  • groupadd name — create a new group for projects or roles.
  • groupmod — change a group's attributes; use carefully.
  • usermod -aG group user — append a secondary group.
  • usermod -g group user — change primary group.
  • gpasswd — manage group administrators or group passwords if used.
Misconception

Assuming usermod -G will add groups; without -a it replaces all secondary groups.

Example workflow
1) Create group: groupadd devops_team. 2) Add user as secondary: usermod -aG devops_team jane_doe. 3) Change primary if needed: usermod -g devops_team jane_doe. 4) Verify: id jane_doe.
Key Takeaway

Always verify group changes after modifying accounts and prefer tools over manual file edits to keep consistency.
