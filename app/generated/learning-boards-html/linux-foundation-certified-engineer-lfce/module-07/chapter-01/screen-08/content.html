Module 7 › Chapter 7.1 › /etc/passwd & /etc/shadow
/etc/passwd
Contains username, UID, GID, comment, home directory, and default shell. It is world readable for name resolution.
/etc/shadow
Contains password hashes and aging fields and is readable only by root to protect sensitive hashes from unprivileged access.
Misconception

Editing /etc/shadow directly is dangerous; use passwd to change passwords to ensure correct hashing and permissions.

Example entries
alice:x:1001:1001:Alice:/home/alice:/bin/bash
# In /etc/shadow (root only)
alice:$6$...hashed...:18765:0:99999:7:::
Inspect /etc/passwd for shell and home. Use chage -l username to get aging and expiration information without viewing the raw hash directly.
