Module 7 › Chapter 7.1 › Creating users
Flags and intent
  • -r creates a system account; often lower UID range and no interactive session.
  • -s sets the default shell; e.g., /sbin/nologin to prevent login.
  • -d sets a custom home directory for application data.
  • -c adds an administrative comment describing the account purpose.
  • -G assigns secondary groups at creation time.
Key Takeaway

Select flags to match account purpose; verify attributes after creation with id and grep.

Example commands
sudo useradd -r -s /sbin/nologin -d /var/www/mywebapp -c "My WebApp Service User" mywebapp
# Verify user creation
id mywebapp
grep mywebapp /etc/passwd
grep mywebapp /etc/shadow
Note: verify the user exists and check the shell and home directory fields in /etc/passwd. Use id to confirm UID and group membership.
