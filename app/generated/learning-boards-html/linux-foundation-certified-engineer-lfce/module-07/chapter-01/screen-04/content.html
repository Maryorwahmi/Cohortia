Module 7 › Chapter 7.1 › UIDs and GIDs
Definition
UID: kernel-level numeric user identifier. GID: numeric group identifier used for group ownership.
Concrete example
User devuser has UID 1001 on Host A. If Host B has UID 1001 assigned to another account, the file ownership will not match the username when mounted over NFS.
Common mistake
Relying on usernames for permission checks rather than verifying numeric IDs across systems.
Key Takeaway

UIDs and GIDs are the authoritative owners. Plan for consistent mapping when sharing storage or migrating users.

Annotated notes
  • Kernel compares numbers; user and group names are for display.
  • Networked storage and NFS depend on matching IDs to preserve permissions.
  • Establish an ID allocation policy ahead of service and user provisioning.
