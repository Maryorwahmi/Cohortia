Module 7 › Chapter 7.1 › Group files & defaults
/etc/group
Maps group names to GIDs and lists members. Use it to audit membership quickly.
/etc/gshadow
Stores group passwords and admin lists. Readable only by root and managed via gpasswd for safety.
/etc/login.defs
Defines system defaults for useradd including UID/GID ranges and password aging defaults. Adjust to enforce organizational policy.
Key Takeaway

Audit group membership in /etc/group, manage secure group settings via gpasswd and gshadow, and tune login.defs to ensure consistent user and system account ranges.
