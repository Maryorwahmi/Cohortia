Module 7 › Chapter 7.1 › Account lifecycle
Expiration and locking
  • Use chage to set expiration dates and view aging information.
  • Use passwd -l to lock accounts immediately.
  • Verify with chage -l and passwd -S or getent passwd.
Best practice

Lock first, locate and reassign files, then delete. This staged approach avoids accidental data loss or orphaned ownership.

Quick commands
# Set an expiration date for john_doe
sudo chage -E YYYY-MM-DD john_doe

# Lock a user immediately
sudo passwd -l jane_doe

# Verify
chage -l alice
passwd -S alice
Use chage -l to review aging fields such as last changed, min and max days, and set expiration to automate retirement.
