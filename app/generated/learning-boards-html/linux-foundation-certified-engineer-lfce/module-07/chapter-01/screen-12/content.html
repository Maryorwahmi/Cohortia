Module 7 › Chapter 7.1 › Hands-on Activity
Planned steps
  1. Create dev_team group.
  2. Create alice and bob with homes and add to dev_team as secondary group.
  3. Create deploy_svc system account with no login and custom data directory.
  4. Set alice's expiration to 90 days from today.
  5. Verify every account with id and grep.
Key Takeaway

Follow the create-verify pattern and prepare directories before assigning them as home paths.

Commands (example)
# Step 1: Create the dev_team group
sudo groupadd dev_team

# Step 2: Create users alice and bob
sudo useradd -m -s /bin/bash -G dev_team alice
sudo useradd -m -s /bin/bash -G dev_team bob

# Step 3: Prepare and create deploy_svc
sudo mkdir -p /opt/deploy_data
sudo useradd -r -s /sbin/nologin -d /opt/deploy_data -c "Automated Deployment Service" deploy_svc

# Step 4: Set expiration for alice
# Calculate date: date -d "+90 days" +%Y-%m-%d
sudo chage -E YYYY-MM-DD alice

# Step 5: Verify
id alice
grep alice /etc/passwd
chage -l alice
grep dev_team /etc/group
