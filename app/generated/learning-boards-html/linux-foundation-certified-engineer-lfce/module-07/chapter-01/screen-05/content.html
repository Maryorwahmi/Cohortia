Module 7 › Chapter 7.1 › Primary vs Secondary
Primary group
Typically a private group created with the username. Files you create will usually inherit this group as owner.
Secondary groups
Used for shared resources, project directories, and role-based access. Users can belong to multiple secondary groups.
Common mistake

Using usermod -G without -a will replace secondary groups and may remove needed access.

Visual comparison
Scenario: default file creation

Scenario: project access

Key Takeaway

Manage primary groups for default ownership and use secondary groups for shared permissions; append with -aG to avoid accidental removal.
