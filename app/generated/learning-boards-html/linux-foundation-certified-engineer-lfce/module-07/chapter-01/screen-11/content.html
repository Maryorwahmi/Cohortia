Module 7 › Chapter 7.1 › Deleting users
What userdel -r does
Removes the account entry and, with -r, the user's home directory and mail spool, but not files elsewhere on the filesystem.
Common mistake

Assuming userdel -r purges all files owned by that account; it does not touch files outside the home.

Find and reassign
# Find files owned by a deleted UID and reassign
sudo find / -xdev -uid 1005 -exec chown newuser:newgroup {} \;

# Or archive first
sudo find / -xdev -uid 1005 -print0 | tar --null -T - -czf /root/orphaned-1005.tar.gz
Use -xdev to avoid crossing mountpoints unintentionally. Replace numeric UID with the deleted UID you observed from prior grep of /etc/passwd.
