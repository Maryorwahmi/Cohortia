Step 3: Trigger tests
# Modify a file to generate auth_config_changes
sudo sh -c 'echo "# test" >> /etc/passwd'

sudo non_existent_command
sudo ls /
Step 4: Search and report
sudo ausearch -k auth_config_changes
sudo ausearch -k sudo_fail
sudo aureport -au
sudo aureport -ts today -f
Checkpoint

If you cannot find events, confirm rules are loaded, verify filters like arch and exe, and ensure auditd is running with proper permissions.
