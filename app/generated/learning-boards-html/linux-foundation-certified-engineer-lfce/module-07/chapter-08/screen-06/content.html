Definition & Example
Rule file content
Save this into /etc/audit/rules.d/auth_critical.rules and then load with auditctl.
# Monitor changes to critical authentication files
-w /etc/passwd -p wa -k auth_config_changes
-w /etc/shadow -p wa -k auth_config_changes
-w /etc/group -p wa -k auth_config_changes
-w /etc/gshadow -p wa -k auth_config_changes
-w /etc/sudoers -p wa -k auth_config_changes
-w /etc/pam.d/ -p wa -k pam_config_changes
Key Takeaway

Tag file watches with descriptive keys to make later searching with ausearch easy and reliable.

What each part means
  • -w path: watch the given file or directory
  • -p wa: watch for writes and attribute changes
  • -k key: a searchable tag applied to generated events
Testing tip: modify a watched file without saving and then run an ausearch by the key to see the attempt. Interpreting the event will show the process and whether the operation succeeded or failed.
Misconception: File watches alone always detect misuse. They show an attempt but should be combined with exec or syscall monitoring for full context.
