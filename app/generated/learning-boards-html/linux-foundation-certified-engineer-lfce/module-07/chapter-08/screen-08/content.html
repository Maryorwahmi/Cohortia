Steps
  1. Save your rule file in /etc/audit/rules.d with a descriptive name.
  2. Load the rules: use auditctl -R path-to-file or restart auditd to read rules on boot.
  3. Confirm with auditctl -l to list active rules.
  4. Trigger a controlled test to generate a matching event.
  5. Use ausearch -k your_key to find and inspect generated events.
Verification commands (visual)
# Load rules
sudo auditctl -R /etc/audit/rules.d/auth_critical.rules
# List rules
sudo auditctl -l
# Search for events by key
sudo ausearch -k auth_config_changes
Tip: If you see no events after testing, check rule filters (arch, exe, uid) that might be excluding the test action, and verify auditd is running and that rules were loaded without errors.
