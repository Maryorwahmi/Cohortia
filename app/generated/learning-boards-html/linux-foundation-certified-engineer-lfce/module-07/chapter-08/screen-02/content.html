Learning Objectives
By the end you will configure and query audit trails, analyze authentication logs, and manage log retention.
Bloom Path
Learn → Understand → Apply → Master
01
Explain auditd
Describe the Linux Audit System and why kernel-level auditing resists tampering. Verified competency milestone: can explain differences between auditd logs and syslog entries.
Mnemonic: kernel shield
02
Write targeted rules
Create rules that monitor files, syscalls, or executables without generating noise. Verified competency milestone: deploy a rule that watches /etc/shadow and demonstrates events are created.
Mnemonic: aim small, log loud
03
Query and report
Use ausearch and aureport to find failed authentications and create summary reports. Verified competency milestone: run an ausearch by key and produce an aureport authentication summary.
Mnemonic: search then summarize
04
Manage log retention
Configure logrotate for auth and audit logs so logs stay available without filling disk. Verified competency milestone: create rotate rules and force logrotate to produce archived files.
Mnemonic: rotate to retain
