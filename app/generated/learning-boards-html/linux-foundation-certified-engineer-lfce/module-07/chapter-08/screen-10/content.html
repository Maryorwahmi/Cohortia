Using aureport to summarize authentication
Generate concise reports for triage and trend analysis.
Authentication report
sudo aureport -au
Shows authentication events by user.
Failed events today
sudo aureport -ts today -f
Summarizes failed events occurring today.
Report by key
sudo aureport -k auth_config_changes
Aggregates events tagged with a specific key.
Triage pattern
Run aureport to identify anomalous users or time windows, then use ausearch to inspect the raw events for evidence.
