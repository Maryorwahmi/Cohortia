Auditd vs System Logs
Use auditd for kernel-level evidence and system logs for readable authentication messages and service context.
  • /var/log/auth.log or /var/log/secure: PAM, sshd, sudo messages — human readable.
  • journalctl: filter by unit or command (for example _COMM=sshd or -u sshd.service) and time ranges.
  • /var/log/audit/audit.log: structured, kernel-level events with metadata for forensics.
Practical journalctl examples
# View sshd entries
journalctl _COMM=sshd
# Tail live
journalctl -f
# Filter by unit and time range
journalctl -u sshd.service --since "1 hour ago"
Tip: Correlate timestamps between auditd and journal entries. Ensure NTP is configured so events align for forensic timelines.
