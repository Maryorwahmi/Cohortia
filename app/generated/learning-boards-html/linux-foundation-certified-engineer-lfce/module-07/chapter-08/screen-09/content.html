Using ausearch to find events
Common search patterns for incident investigation.
Search by key
sudo ausearch -k auth_config_changes
Finds events tagged with a specific rule key.
Search for failed events in a range
sudo ausearch -ts 2024-01-01 -te 2024-01-01 --success no
Filters by time range and unsuccessful operations.
Search by message type
sudo ausearch -m USER_AUTH,USER_LOGIN
Restrict to authentication-related audit messages.
Interpret numeric values
sudo ausearch -m USER_CMD -sv no -i
The -i flag interprets numeric codes for readability.
Investigation tip

Start with keys and time ranges, then expand to surrounding event types to reconstruct a timeline of actions.
