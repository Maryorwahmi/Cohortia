Competency Checklist
  • Create an audit rule file under /etc/audit/rules.d and load it with auditctl.
  • Verify audit events appear in /var/log/audit/audit.log for test changes or failed sudo attempts.
  • Run ausearch with a rule key and interpret the event fields to identify actor, executable, and result.
  • Create logrotate entries for auth logs and audit logs and force rotation to validate retention.
Milestone
Produce a searchable audit event
You should be able to run an ausearch by key and find an event generated by a test sudo fail or a file change.
