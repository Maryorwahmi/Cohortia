Module 7 › Chapter 7.2 › Traditional rwx permissions
Definition

Symbolic and octal modes

Owner, group, others each map to three bits. Convert by summing read=4, write=2, execute=1 to produce octal digits.

Example conversions
  • rw-r--r-- = owner 6, group 4, others 4 → 644
  • rwxr-xr-x = owner 7, group 5, others 5 → 755
  • rwxrwx--- = owner 7, group 7, others 0 → 770
Common misconception
Files usually don't get execute by default; treat files with max 666 when computing umask subtraction, directories use 777.
Code examples
# Show symbolic and octal modes
ls -l /path/to/file   # e.g. -rw-r--r--
stat -c '%A %a %n' /path/to/file  # e.g. -rw-r--r-- 644 /path/to/file

# Quick conversions by reasoning:
# rw-r--r-- → owner 4+2=6, group 4, others 4 → 644
# rwxr-xr-x → owner 4+2+1=7, group 4+1=5, others 5 → 755
Key Takeaway

Map symbolic bits to octal by summing 4/2/1. Remember directory vs file maxima when reasoning about umask.
