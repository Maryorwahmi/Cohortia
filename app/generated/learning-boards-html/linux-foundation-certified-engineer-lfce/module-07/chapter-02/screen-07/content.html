Comparison

SUID on scripts vs binaries

Compiled binary with SUID
Runs with file owner's UID. If the binary is vulnerable, it can be exploited for privilege escalation.
Script with SUID
Often ignored by the kernel; setting it offers little benefit and can mislead admins about real privilege changes.
Practical warning
Never rely on SUID for custom scripts. Use sudo with precise command allowances and logging instead.
Commands to check and mitigate
# Find SUID files
sudo find / -perm /4000 -type f 2>/dev/null

# Check file type before deciding
file /usr/local/bin/custom_tool

# Remove SUID if unnecessary
sudo chmod u-s /usr/local/bin/custom_tool

# Safer alternative: permit specific command via sudoers instead of setting SUID
Key Takeaway

Prefer sudo and auditing to SUID on custom tools; validate file type and remove unnecessary u+s bits promptly.
