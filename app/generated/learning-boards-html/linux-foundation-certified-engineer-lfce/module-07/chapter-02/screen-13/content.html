Module 7 › Chapter 7.2 › Quick Commands
ls -l
Shows symbolic bits; a trailing + indicates ACLs, s/t mark special bits.
getfacl
Displays owner, group, named entries, mask, and default ACLs for directories.
setfacl
Use -m to add/modify entries, -x to remove, and d: prefix to set defaults on directories.
Final check
After changes, always re-run getfacl and test access with sudo -u so you don't rely on symbolic mode alone.
