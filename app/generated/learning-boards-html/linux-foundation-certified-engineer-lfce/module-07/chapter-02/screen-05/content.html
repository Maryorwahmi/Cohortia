Module 7 › Chapter 7.2 › umask: defaults and calculation
Process

Compute effective modes from umask

Subtract the umask from the maximum (666 files, 777 directories) to get new object permissions.

Examples
  • umask 0022 → files: 666 - 022 = 644, directories: 777 - 022 = 755
  • umask 0002 → files: 666 - 002 = 664, directories: 777 - 002 = 775
Misconception
umask does not set bits; it removes them from the maximum. Always compute against 666 or 777, not against current file mode.
Terminal demo
# Show current umask
umask

# Compute defaults for umask 0022
umask 0022
# New file default: 666 - 022 = 644
# New dir default : 777 - 022 = 755

# Example: create a file and inspect
umask 0002
touch newfile.txt
ls -l newfile.txt  # expected -rw-rw-r-- (664)

# To persist, add umask 0002 to shell profile or service unit
Key Takeaway

Set umask deliberately: 0022 for private defaults, 0002 for collaborative groups. Always test by creating files.
