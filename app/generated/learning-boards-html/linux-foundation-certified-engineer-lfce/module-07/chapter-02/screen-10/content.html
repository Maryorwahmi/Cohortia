Code walkthrough

Common setfacl patterns

Here are the typical commands you'll use to grant, restrict, and remove ACL entries. Practice and then inspect with getfacl to ensure intended effects.
# Give user john read/write on a file
sudo setfacl -m u:john:rw shared_doc.txt

# Give group devs read/execute on a directory
sudo setfacl -m g:devs:r-x project_data

# Set default ACLs for alice and dev_team on a directory
sudo setfacl -m d:u:alice:rwx project_dir
sudo setfacl -m d:g:dev_team:r-x project_dir

# Remove diana's ACL from a file
sudo setfacl -x u:diana /srv/project_alpha/report.txt
Mask example & verification
After setting entries, the mask may limit effective rights. Always check with getfacl and test as the target user.
# Inspect ACL and mask
getfacl /srv/project_alpha/report.txt

# Test access as another user without logging in
sudo -u john test -r /srv/project_alpha/report.txt && echo "john can read" || echo "john cannot read"
Key Takeaway

setfacl gives you named entries and defaults; always inspect the mask and verify access by simulating users.
