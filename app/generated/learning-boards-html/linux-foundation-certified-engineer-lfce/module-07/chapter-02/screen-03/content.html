Verification checklist

Concrete tests you should perform to prove competence for each objective.

Compute & confirm umask
Create files and directories, apply umask values, and confirm modes like 644 and 755 using ls -l.
Inspect special bits
Use ls -l to find s and t bits and run controlled examples to see effective behavior.
Apply and test ACLs
Run setfacl, getfacl, and use sudo -u to confirm effective permissions for named users.
Check masks and defaults
Verify ACL masks and default ACLs on directories to ensure inheritance and effective permissions.
