Definition

What ACLs add to permissions

ACLs let you define permissions for specific users and groups beyond the owning group and others. They are ideal when a single file must be accessible to particular users without opening it to the group or others.
Key components
  • Named user entries: u:alice:rwx
  • Named group entries: g:devs:r-x
  • Mask: limits named users/groups
  • Default ACLs: inherited by new items in a directory
Indicator
If ls -l shows a trailing +, check getfacl to see the full ACL details.
getfacl example
$ getfacl shared_doc.txt
# file: shared_doc.txt
# owner: alice
# group: dev_team
user::rw-
user:john:rw-
group::r--
mask::rwx
other::r--
Key Takeaway

Use getfacl to read ACLs and remember the mask can reduce effective permissions even if entries show rwx.
