Module 7 › Chapter 7.2 › Shared project scenario
Scenario steps

Setup and verification

  1. Ensure group exists and users exist; add alice to dev_team.
  2. Create /srv/project_alpha, chown root:dev_team, chmod 2770 to set SGID.
  3. Grant charlie read-only and default ACLs on the directory so future files inherit access.
  4. Create report.txt and set setfacl for diana with rw only on that file.
  5. Create a new file as alice and verify charlie can read it; remove diana's ACL when done.
Commands
# Preconditions (create group/users as needed)
sudo groupadd dev_team
sudo useradd -m alice
sudo useradd -m charlie
sudo useradd -m diana
sudo usermod -aG dev_team alice

# Directory setup
sudo mkdir -p /srv/project_alpha
sudo chown root:dev_team /srv/project_alpha
sudo chmod 2770 /srv/project_alpha

# Grant charlie read-only and default ACL for future files
sudo setfacl -m u:charlie:r-x /srv/project_alpha
sudo setfacl -m d:u:charlie:r-x /srv/project_alpha

# Give diana read-write to a single file
sudo touch /srv/project_alpha/report.txt
sudo setfacl -m u:diana:rw /srv/project_alpha/report.txt

# Create file as alice and verify charlie can read
sudo -u alice touch /srv/project_alpha/new_document.txt
sudo -u charlie test -r /srv/project_alpha/new_document.txt && echo "Charlie can read" || echo "Charlie cannot read"

# Remove diana's access
sudo setfacl -x u:diana /srv/project_alpha/report.txt
Key Takeaway

Use SGID for group ownership and default ACLs for predictable inheritance; always verify by simulating target users.
