Module 7 › Chapter 7.2 › SGID on directories
Architecture

Group inheritance flow

When SGID is applied to a directory the kernel marks new child objects with the parent directory's group. This preserves group ownership across collaborative contributions without manual chown calls.
Example setup
Create /srv/project_alpha, set owner root:dev_team, and chmod 2770 so all new items inherit dev_team group ownership and remain private to the group.
Commands & verification
# Setup
sudo mkdir -p /srv/project_alpha
sudo chown root:dev_team /srv/project_alpha
sudo chmod 2770 /srv/project_alpha

# Verify
ls -ld /srv/project_alpha   # drwxrws--- shows the 's' in group position
# Create a file as alice (in dev_team) and check group ownership
sudo -u alice touch /srv/project_alpha/example.txt
ls -l /srv/project_alpha/example.txt  # group should be dev_team
Key Takeaway

Use SGID on shared project directories to preserve group ownership and simplify collaboration; remember to manage group membership.
