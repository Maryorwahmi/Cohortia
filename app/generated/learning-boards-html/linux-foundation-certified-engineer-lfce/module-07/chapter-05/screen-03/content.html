Module 7 › Chapter 7.5 › Learning Objectives — Advanced
Agent Forwarding & Tunnels
Learn when to use -A and -L/-R safely to avoid exposing private keys or opening unnecessary network paths.
Mnemonic: Forward with intent — only forward what you need. VERIFIED COMPETENCY MILESTONE
Match blocks & ForceCommand
Write Match blocks to limit user capabilities, force scripts, and disable forwarding for automation accounts.
Mnemonic: Match narrowly, not broadly. VERIFIED COMPETENCY MILESTONE
Threats and Mitigations
Recognize brute force, weak passwords, exposed keys, and outdated daemons; apply configuration and tooling mitigations.
Mnemonic: Harden, monitor, update. VERIFIED COMPETENCY MILESTONE
Testing & Recovery
Always test sshd -t before restart and ensure console access when changing ports or authentication to avoid lockout.
Mnemonic: Test, then restart. VERIFIED COMPETENCY MILESTONE
