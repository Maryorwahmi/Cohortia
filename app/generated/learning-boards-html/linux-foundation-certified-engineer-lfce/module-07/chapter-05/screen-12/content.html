Module 7 › Chapter 7.5 › Risks & Mitigations
Risk: Weak passwords
Mitigation: disable PasswordAuthentication and enforce key-based auth; use PAM for strong password policies if needed.
Risk: PermitRootLogin yes
Mitigation: set PermitRootLogin no and require sudo for administrative tasks.
Risk: Exposed private keys
Mitigation: protect keys with passphrases, set chmod 600, and limit key use with Match blocks.
Risk: Default port scans
Mitigation: consider changing Port, but also enforce key-only auth and rate-limiting tools like fail2ban.
Risk: Outdated sshd
Mitigation: keep the system updated and monitor advisories for cv es affecting sshd.
Risk: Brute-force
Mitigation: use pam_faillock, fail2ban, and disable password authentication to reduce brute-force opportunities.
