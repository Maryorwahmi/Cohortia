SSH
A cryptographic network protocol for secure remote access and data communication.
SSH Key-based Authentication
Use a matching private/public key pair so the server can cryptographically verify the client.
Private Key
Keep secret and encrypted with a passphrase; protect with chmod 600.
Summary

Master key generation and secure deployment first. All secure SSH operations rest on correct keys and permissions.
