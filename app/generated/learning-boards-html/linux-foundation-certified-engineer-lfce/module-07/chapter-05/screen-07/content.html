Module 7 › Chapter 7.5 › sshd_config Essentials
Essential directives
  • Port: change default 22 to reduce automated scans.
  • PermitRootLogin no: disallow direct root logins.
  • PasswordAuthentication no: force key-based authentication.
  • PubkeyAuthentication yes: ensure key auth enabled.
  • AllowUsers / AllowGroups: restrict who can connect.
  • ClientAliveInterval / ClientAliveCountMax: detect idle clients.
Misconception: changing Port alone is not a substitute for disabling weak authentication or protecting keys. Port changes reduce noise but do not prevent credential abuse.
Example snippet
# Example sshd_config entries
Port 2222
PermitRootLogin no
PasswordAuthentication no
PubkeyAuthentication yes
AuthorizedKeysFile .ssh/authorized_keys
AllowUsers testuser adminuser
ClientAliveInterval 60
ClientAliveCountMax 3
UseDNS no
LogLevel VERBOSE
Remember to run sudo sshd -t to test before restarting and keep a backup of /etc/ssh/sshd_config when making changes.
