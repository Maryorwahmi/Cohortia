Module 7 › Chapter 7.5 › Learning Objectives
01
Master key-based authentication
Generate Ed25519 or RSA key pairs, select a strong passphrase, and use ssh-agent to cache keys in memory for the session.
Mnemonic: Key = identity, Passphrase = lock. VERIFIED COMPETENCY MILESTONE
02
Deploy and verify public keys
Use ssh-copy-id to install public keys, then verify ~/.ssh is 700 and authorized_keys is 600 to avoid failures.
Visual: small permission Venn. VERIFIED COMPETENCY MILESTONE
03
Harden sshd_config
Configure Port, PermitRootLogin no, PasswordAuthentication no, PubkeyAuthentication yes, and sensible ClientAlive values.
Mnemonic: least privilege first. VERIFIED COMPETENCY MILESTONE
04
Use forwarding and Match blocks safely
Apply agent and port forwarding intentionally and use Match blocks to limit user capabilities, force commands, and disable forwarding where needed.
Visual: simple timeline. VERIFIED COMPETENCY MILESTONE
