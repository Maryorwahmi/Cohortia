Secure Shell: Practical authentication and server hardening

This lesson teaches commands, configuration edits, and safe practices you will use when securing SSH on production servers.

Duration: ~15 minutes demo
In this lesson
Key-based auth, sshd hardening, forwarding, Match blocks, and mitigation hands-on.
Key-based Auth
Generate keys with ssh-keygen, protect private keys with passphrases, deploy public keys with ssh-copy-id.
Hardening sshd
Change port, disable root, disable passwords, enforce PubkeyAuthentication, test with sshd -t.
Forwarding & Match
Use agent and port forwarding intentionally. Use Match blocks to force commands and limit forwarding.
Visual Concept

sshd_config

Forwarding
Tunnels and agent forwarding enable flexible workflows but add risk if misused.
Explore Key Topics
Deploying keys
Use ssh-copy-id to copy a public key and fix permissions to 700/600 to avoid failures.
Config hardening
Disable root login, disable passwords, and restrict users or groups in sshd_config.
Advanced flows
Use agent forwarding for chained logins and port forwarding for internal service access.
