Module 7 › Chapter 7.5 › Port Forwarding
Local forwarding (ssh -L)
Creates a tunnel from your local port to a target host through the SSH server.
# Example: tunnel local 8080 to internal webserver
ssh -L 8080:webserver.internal:80 user@ssh_server
# Then open http://localhost:8080 locally to access the internal site
Use case: access an internal admin interface while keeping it unexposed to the internet.
Remote forwarding (ssh -R)
Opens a port on the SSH server that forwards back to your local machine.
# Example: expose local web server to remote host's port 8080
ssh -R 8080:localhost:80 user@remote_server
# Then on remote_server, http://localhost:8080 reaches your local service
Caution: only use remote forwarding when you trust the remote server and have controlled PermitOpen settings to limit exposure.
