Module 7 › Chapter 7.5 › Match Blocks
Example Match block
# Add to /etc/ssh/sshd_config
Match User git_deploy
   ForceCommand /usr/local/bin/git-receive-pack-wrapper
   PermitTunnel no
   AllowAgentForwarding no
   X11Forwarding no
   PermitOpen none
This enforces a single action for git_deploy and disables forwarding, making the account safe for automated operations.
Best practices
  • Place Match blocks near the end of sshd_config so global defaults apply first.
  • Combine ForceCommand with strict key-only auth for automation accounts.
  • Use Address or Host criteria to limit from where accounts may connect.
