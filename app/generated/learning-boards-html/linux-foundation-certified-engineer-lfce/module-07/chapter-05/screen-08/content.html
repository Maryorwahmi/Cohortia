Module 7 › Chapter 7.5 › Hardening Workflow
Step 1: Backup
Create a backup before editing: sudo cp /etc/ssh/sshd_config /etc/ssh/sshd_config.bak.
Step 2: Test
Run sudo sshd -t to check for syntax errors. Fix issues before restarting.
Step 3: Firewall
Open the new port before restart. Example: sudo firewall-cmd --add-port=2222/tcp --permanent && sudo firewall-cmd --reload.
Step 4: Restart & verify
Restart: sudo systemctl restart sshd, then verify by connecting from a new session: ssh -p 2222 user@host.
