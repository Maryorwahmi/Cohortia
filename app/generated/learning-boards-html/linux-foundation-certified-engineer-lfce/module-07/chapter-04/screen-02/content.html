Learning Objectives
Progress from conceptual understanding to practical configuration and troubleshooting.
01
Explain LDAP and Kerberos architecture
Define the role of LDAP as a directory and Kerberos as a ticket-based authentication mechanism. Understand why both are used together in enterprise environments to separate identity from authentication.
VERIFIED COMPETENCY MILESTONE
02
Configure SSSD for LDAP
Write a secure /etc/sssd/sssd.conf for an LDAP domain, set appropriate permissions, and enable SSSD with NSS and PAM so user lookups and authentication flow through SSSD.
VERIFIED COMPETENCY MILESTONE
03
Integrate Kerberos with SSSD
Set krb5_realm and KDC entries, configure SSSD for krb5 id and auth provider, and test ticket acquisition with kinit and klist.
VERIFIED COMPETENCY MILESTONE
04
Troubleshoot integration issues
Use logs, verify ports and DNS, check TLS settings and time synchronization, and clear SSSD cache to resolve common authentication failures.
VERIFIED COMPETENCY MILESTONE
