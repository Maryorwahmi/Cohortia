Definition
SSSD: Role, Caching, and Offline Authentication
SSSD is the local bridge between NSS/PAM and remote identity providers, with caching for resilience.
Protect /etc/sssd/sssd.conf • Cache management
SSSD responsibilities
  • Provide NSS name service responses for passwd, group, and shadow via sss module.
  • Proxy PAM authentication requests to configured auth providers.
  • Cache identity and credential information for offline logins.
  • Log to /var/log/sssd for domain-specific troubleshooting.
Permissions
/etc/sssd/sssd.conf must be mode 0600 to protect secrets such as ldap_default_authtok.
Visual: SSSD in the authentication path
Applications ask NSS/PAM. NSS/PAM use SSSD. SSSD queries LDAP or Kerberos and caches results locally.
Example: Offline login
User authenticates using cached credentials when LDAP is unreachable for a short period.
Common-mistake
Relying on cache without knowing its TTL leads to unexpected stale identity data; consider cache clearing when debugging.
