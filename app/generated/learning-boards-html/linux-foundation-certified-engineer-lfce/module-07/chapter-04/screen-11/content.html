Process Flow
Hands-on Scenario: Join a Host to LDAP and Kerberos
Execute commands in sequence to integrate the host with ldap.example.com and EXAMPLE.COM.
Use lab user names from the scenario
Terminal steps
# Install packages (RHEL/CentOS)
sudo yum install sssd sssd-ldap sssd-krb5 krb5-workstation authselect -y
# Or Debian/Ubuntu
# sudo apt install sssd sssd-ldap sssd-krb5 krb5-user libpam-sss libnss-sss

# Secure sssd.conf after editing
sudo chmod 0600 /etc/sssd/sssd.conf

# Enable SSSD in NSS/PAM
sudo authselect select sssd with-mkhomedir --force

# Start SSSD
sudo systemctl enable --now sssd

# Test LDAP user lookup
id ldapuser@example.com
getent passwd ldapuser@example.com

# Test Kerberos
kinit kerberosuser@EXAMPLE.COM
klist
Follow these steps in order; if any command fails, capture its error and check relevant logs before proceeding.
Example verification outputs
id should show uid and gid for the LDAP user. getent passwd returns a full passwd line. klist shows a TGT with valid times.
Troubleshooting
If getent fails while id works, check nsswitch.conf contains sss for passwd and group; authselect typically manages this.
