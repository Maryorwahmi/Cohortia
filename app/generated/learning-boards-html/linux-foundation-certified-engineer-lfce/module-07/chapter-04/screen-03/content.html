Practical Skills and Tests
Commands and outcomes to confirm a working integration.
Bloom: Apply → Master
Typical verification checklist
  • Install: sssd, sssd-ldap, sssd-krb5, krb5-workstation.
  • Configure: /etc/sssd/sssd.conf and /etc/krb5.conf, set 0600 on sssd.conf.
  • Enable SSSD: authselect select sssd with-mkhomedir --force.
  • Service: systemctl enable --now sssd and verify status.
  • Test: id ldapuser@example.com, getent passwd ldapuser@example.com, kinit kerberosuser@EXAMPLE.COM, klist.
Pro tip
Always set ldap_tls_reqcert according to your TLS policy. In testing you may allow, but in production use demand and proper certificates.
What a passing test looks like
LDAP lookups: getent returns the user line and id shows correct UID and groups.
Kerberos: kinit prompts for password, klist shows a TGT with a valid lifetime.
Authentication: SSH or local login accepts the LDAP or Kerberos credentials according to your PAM policy.
Common mistake
If home directories are not created, ensure you included with-mkhomedir when running authselect.
