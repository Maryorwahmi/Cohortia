Process Flow
Combining LDAP and Kerberos in SSSD
Step sequence for a successful combined configuration.
id_provider = ldap • auth_provider = krb5
Step-by-step sequence
Step 1
Install sssd, sssd-ldap, sssd-krb5, and krb5 client tools.
Step 2
Create /etc/krb5.conf with realm and KDC entries.
Step 3
Write /etc/sssd/sssd.conf with LDAP id_provider and Kerberos auth_provider.
Step 4
Enable SSSD in NSS/PAM: sudo authselect select sssd with-mkhomedir --force. Then sudo systemctl enable --now sssd.
Step 5
Test identity lookup with id and getent, then authenticate with kinit and verify with klist.
Troubleshooting note
If identity lookups succeed but authentication fails, verify krb5 realm and KDC entries, time sync, and that auth_provider is set to krb5 in the sssd domain block.
Key Takeaway

Define providers explicitly in SSSD: LDAP for identity, Kerberos for authentication gives a robust enterprise pattern.
