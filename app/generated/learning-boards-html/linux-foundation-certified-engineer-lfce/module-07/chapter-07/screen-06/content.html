Module 7 › Chapter 7.7 › pam_pwquality Parameters
Common pam_pwquality options
  • minlen=<N> — set minimum password length.
  • dcredit=<-N> — require digits when negative (dcredit=-1 → one digit).
  • ucredit, lcredit, ocredit — uppercase, lowercase, other characters.
  • remember=<N> — remember last N passwords to prevent reuse.
  • reject_username — prevent username-based passwords.
  • enforce_for_root — apply checks to root as well.
Policy example
password requisite pam_pwquality.so try_first_pass local_users_only retry=3 minlen=10 dcredit=-1 ucredit=-1 ocredit=-1 lcredit=-1 remember=4 reject_username
Place this in the password stack of system-auth or common-password and test carefully.
Practical guidance
  • Favor longer passwords and password history over forcing obscure substitutions.
  • Test policy on new_user to observe prompts and rejections.
  • Document the policy and communicate to users so they can prepare strong, memorable passwords.
