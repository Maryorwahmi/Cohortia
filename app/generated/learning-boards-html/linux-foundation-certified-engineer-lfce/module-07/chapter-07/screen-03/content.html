Edit /etc/login.defs
Set PASS_MAX_DAYS, PASS_MIN_DAYS, PASS_WARN_AGE for new users and understand the difference between defaults and per-user chage settings.
VERIFIED COMPETENCY MILESTONE
Configure pam_pwquality
Tune minlen, dcredit, ucredit, lcredit, ocredit, remember, reject_username, and optionally enforce_for_root. Test in a controlled environment first.
VERIFIED COMPETENCY MILESTONE
Schedule expirations and inactivity
Use chage -E for absolute expirations and chage -I for inactivity locking after expiry. Use passwd -l for immediate manual locks.
VERIFIED COMPETENCY MILESTONE
Audit accounts and report
Script chage -l across UIDs, grep PAM configs, and look for '!' in /etc/shadow to find locked accounts. Produce a simple report for compliance checks.
