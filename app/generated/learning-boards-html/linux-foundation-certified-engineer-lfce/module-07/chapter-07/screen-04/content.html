chage flags and meaning
  • -l list aging information for a user.
  • -M maximum days a password is valid.
  • -m minimum days before password change.
  • -W warning days before expiration.
  • -E absolute account expiration date.
  • -I inactivity days after expiry before lock.
Concrete example
sudo chage -M 90 -m 7 -W 14 alice
sudo chage -l alice
Run chage -l to verify the resulting expiry and warning.
Explanation and common misconception
Changing /etc/login.defs affects defaults for newly created accounts only. Administrators often expect it to update existing users, but you must run chage on those accounts. Misconfiguring PASS_MAX_DAYS too low can frustrate users; too high reduces security. Choose values that balance organizational policy and user workflow, and document the change.
Key Takeaway

Use chage for per-user settings and login.defs for defaults. Always verify with chage -l and test policies before broad rollout.
