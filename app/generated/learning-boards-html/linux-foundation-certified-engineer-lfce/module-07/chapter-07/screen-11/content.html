Module 7 › Chapter 7.7 › Hands-on Workflow
Implementation steps
  1. Backup /etc/login.defs and set PASS_MAX_DAYS, PASS_MIN_DAYS, PASS_WARN_AGE.
  2. Backup PAM files and add pam_pwquality options in the password stack.
  3. Create temp_user and set chage -E to six months from today; verify with chage -l.
  4. Set inactivity with chage -I 30 for sample accounts.
  5. Configure pam_faillock deny and unlock_time; test with failures and faillock --reset.
  6. Use passwd -l and passwd -u for manual lock/unlock practice.
  7. Run audit scripts to list aging, locks, and PAM settings for a final report.
Caution

Always maintain console/root recovery before changing PAM or lock settings to avoid accidental lockouts.

Verify

Confirm with chage -l, faillock --user, and grep checks, and document results for compliance records.
