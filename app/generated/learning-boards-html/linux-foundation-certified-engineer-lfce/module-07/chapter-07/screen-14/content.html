Module 7 › Chapter 7.7 › Key Concepts
Password Aging
Use chage for per-user settings; use login.defs for defaults for new users.
Password Complexity
pam_pwquality parameters control length, character classes, and history during password changes.
Account Locking
pam_faillock handles failed attempts; passwd -l and chage -E/-I handle manual and inactivity locks.
Summary Takeaway
Combine lifecycle policies, PAM complexity rules, locking mechanisms, and regular audits to build a secure, usable account management practice. Test and document every change.
