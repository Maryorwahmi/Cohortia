Module 7 › Chapter 7.7 › login.defs Defaults
Key variables in /etc/login.defs
PASS_MAX_DAYS
Maximum password age (days) for new users.
PASS_MIN_DAYS
Minimum days before a password can be changed.
PASS_WARN_AGE
Days of warning before expiry.
Example change sequence: back up the file, edit the three lines to your policy values, and update your user creation scripts so new users receive the intended defaults. Then run audits to compare current users to the new policy.
Audit command
grep -E 'PASS_MAX_DAYS|PASS_MIN_DAYS|PASS_WARN_AGE' /etc/login.defs
Rollout checklist
  • Backup login.defs
  • Update new-user provisioning
  • Run chage -l script for existing users
  • Communicate to users before enforcement
