Recommended edit workflow
  1. Backup file: sudo cp /etc/pam.d/system-auth /etc/pam.d/system-auth.bak
  2. Edit carefully and save changes.
  3. Test with a non-critical account: sudo passwd new_user
  4. Revert if unexpected behavior occurs.
Example PAM line
password    requisite     pam_pwquality.so try_first_pass local_users_only retry=3 minlen=10 dcredit=-1 ucredit=-1 ocredit=-1 lcredit=-1 remember=4 reject_username
Place in the password stack of system-auth or common-password depending on your distro.
Testing checklist
  • Try weak passwords and confirm rejection messages.
  • Try a compliant strong password and confirm acceptance.
  • Record the behavior and revert if system login is impaired.
