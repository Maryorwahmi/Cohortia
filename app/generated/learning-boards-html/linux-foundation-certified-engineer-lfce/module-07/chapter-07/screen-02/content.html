Module 7 › Chapter 7.7 › Learning Objectives
01
Manage password aging with chage
Set and read max/min days, warning periods, inactivity and absolute expiration with chage and login.defs.
VERIFIED COMPETENCY MILESTONE
02
Enforce complexity via PAM
Configure pam_pwquality or pam_cracklib parameters like minlen, credit flags, remember, and reject_username to raise password quality.
VERIFIED COMPETENCY MILESTONE
03
Automate account locking
Use pam_faillock for failed attempts and chage or passwd -l for inactivity or manual locks. Learn how to reset locks safely.
VERIFIED COMPETENCY MILESTONE
04
Audit and report account status
Run scripted chage, grep PAM configs, and inspect /etc/shadow to produce compliance reports and find locked or expired accounts.
VERIFIED COMPETENCY MILESTONE
