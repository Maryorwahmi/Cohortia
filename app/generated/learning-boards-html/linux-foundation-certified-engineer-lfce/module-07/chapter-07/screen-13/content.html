Module 7 › Chapter 7.7 › Testing & Recovery
Backup and rollback
Always copy original files before editing, for example sudo cp /etc/pam.d/system-auth /etc/pam.d/system-auth.bak. Keep rollback steps documented including how to restore files and which services to restart if needed.
Staged testing
  • Test locally on non-critical accounts.
  • Pilot with a small user group.
  • Roll out system-wide after verification.
Emergency recovery

Keep console or alternate root access and test reverting backups. Use passwd -u and faillock --reset to repair specific account issues while you restore configurations.
