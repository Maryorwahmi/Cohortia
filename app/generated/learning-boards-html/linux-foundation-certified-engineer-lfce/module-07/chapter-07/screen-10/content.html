Script pattern for chage across users
for u in $(awk -F: '$3 >= 1000 && $1 != "nfsnobody" {print $1}' /etc/passwd); do
  echo "--- $u ---"
  chage -l $u
done
This lists aging info for regular users for review or to feed into reports.
Useful greps
  • grep -E 'PASS_MAX_DAYS|PASS_MIN_DAYS|PASS_WARN_AGE' /etc/login.defs
  • grep pam_pwquality /etc/pam.d/*
  • grep pam_faillock /etc/pam.d/*
Detect locked accounts
cat /etc/shadow | grep '!'
# Shows accounts with an exclamation mark indicating passwd -l
Combine these outputs into a CSV or human-friendly report and schedule it regularly to detect drift from policy.
