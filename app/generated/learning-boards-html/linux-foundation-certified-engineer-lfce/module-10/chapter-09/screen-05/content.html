Module 10 › Chapter 10.9 › Apache MPMs vs Nginx
Apache MPMs
Prefork creates separate processes, Worker uses threads, and Event adds asynchronous handling of keepalive. Tune StartServers, MinSpareServers, MaxSpareServers, and MaxRequestWorkers to avoid running out of workers or using excessive memory.
Key param
MaxRequestWorkers — prevents running out of worker processes but can exhaust memory if set too high.
Nginx worker model
Nginx is event-driven; set worker_processes typically to CPU cores and worker_connections to a high value so each worker supports many sockets. Also consider kernel limits such as file descriptors and somaxconn.
Tuning checklist
Calculate concurrency, set worker_processes to core count, raise worker_connections, and test with a realistic load while watching memory and accept errors.
Example
4 cores → worker_processes 4; expected 4000 concurrent sockets → worker_connections 4096 and kernel tuning for somaxconn.
Misconception
More connections always equals better throughput. In reality, excessive connections without resources leads to queuing, memory exhaustion, or dropped accepts.
Key Takeaway
Tune workers to resource capacity and verify by measuring accept failures, memory use, and response latency under representative load.
