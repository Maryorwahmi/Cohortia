Module 10 › Chapter 10.9 › Key Concepts
innodb_buffer_pool_size
Primary memory parameter for caching InnoDB data and indexes; set to cover the working set when possible.
noatime / relatime
Mount options that prevent frequent access-time writes, reducing unnecessary disk I/O on read-heavy workloads.
Connection Pooling
Reuse database connections at the application level to reduce overhead from frequent connection setup and teardown.
Final takeaway
Use role-specific starting points, test changes incrementally, and verify with the metric that the change should affect. This is the repeatable path to reliable performance.
