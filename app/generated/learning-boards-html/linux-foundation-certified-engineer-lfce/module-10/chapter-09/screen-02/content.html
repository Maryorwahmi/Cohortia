Identify dominant resource
Learn to detect whether CPU, memory, disk, or network limits a service and why it matters.
Mnemonic: Venn of CPU, RAM, I/O

02
Configure web server workers
Tune Apache MPM or Nginx worker processes and connections so web servers handle peak traffic without exhausting RAM.
Mnemonic: worker per core, connections per worker
VERIFIED COMPETENCY MILESTONE
03
Allocate database memory
Set innodb_buffer_pool_size or shared_buffers appropriately so databases minimize disk reads and stay responsive.
Mnemonic: 50–80% of RAM for InnoDB on dedicated DB hosts
VERIFIED COMPETENCY MILESTONE
04
Optimize file-server I/O
Choose filesystem, mount options like noatime, and an I/O scheduler that suits your storage and redundancy needs.
Mnemonic: filesystem → mount → scheduler
