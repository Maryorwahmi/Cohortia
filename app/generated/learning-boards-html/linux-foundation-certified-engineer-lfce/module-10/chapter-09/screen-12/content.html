Module 10 › Chapter 10.9 › Caching & Compression
Caching tiers
Browser caching for static assets, reverse-proxy caching for repeated responses, and application caches for expensive computations reduce backend load and I/O.
Example
Use Nginx or Varnish for static or cacheable dynamic responses; use Memcached/Redis for computed results.
Compression
Enable Gzip or Brotli for text assets to cut bandwidth. Avoid compressing already-compressed files like images or videos.
Key Takeaway
Caching reduces repeated backend work; compression lowers bandwidth. Measure both CPU and bandwidth when enabling these features.
