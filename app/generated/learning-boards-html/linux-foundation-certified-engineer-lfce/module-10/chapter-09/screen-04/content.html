Module 10 › Chapter 10.9 › Workload Characteristics
Definition and classification
Classify a server by which resource is limiting performance: CPU, memory, disk I/O, or network. Each classification points to a different set of tuning knobs.
Web servers
Network and CPU focus; tune workers, keepalive, caching, and network kernel params.
Databases
Memory and disk I/O focus; tune buffer pools, storage, and query execution.
File servers
Disk throughput and network buffers; choose filesystem, mount options, and scheduler carefully.
How to know: quick checks
  • High run-queue and CPU: suspect CPU-bound load.
  • High disk wait or low buffer hit rate: suspect I/O-bound database or file server.
  • Many connections with low CPU: suspect network or worker configuration limits.
Key Takeaway
Choose the tuning area that directly addresses the dominant metric and test changes against that metric only.
Common mistake
Changing unrelated kernel params while troubleshooting a CPU-bound site can mask the real issue and complicate rollback.
