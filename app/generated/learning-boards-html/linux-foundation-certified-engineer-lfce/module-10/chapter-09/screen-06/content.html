Module 10 › Chapter 10.9 › Nginx Config Demo
Steps (safe, verifiable)
  1. Backup: sudo cp /etc/nginx/nginx.conf /etc/nginx/nginx.conf.bak
  2. Inspect: open nginx.conf to find worker_processes and worker_connections.
  3. Calculate: worker_processes = number of CPU cores (nproc).
  4. Set: e.g., worker_processes 4; worker_connections 4096; add multi_accept on;
  5. Test: sudo nginx -t then sudo systemctl reload nginx; monitor connection metrics.
Common check: ensure ulimit and file-descriptor limits accommodate the increased connections.
Config snippet (example)
worker_processes 4;

events {
  worker_connections 4096;
  multi_accept on;
}
