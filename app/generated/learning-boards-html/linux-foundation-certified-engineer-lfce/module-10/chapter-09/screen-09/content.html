Module 10 › Chapter 10.9 › File Server Tuning
Filesystem choice
XFS is effective for large files and high concurrency; ext4 is stable and general-purpose. Choose based on file sizes, directory layout, and concurrency patterns.
Mount options
  • noatime / relatime: reduce writes from access-time updates on reads.
  • nobarrier: can improve throughput on controllers with safe write caches—use with caution.
Network and protocol tuning
For Samba, tune socket options like TCP_NODELAY and buffer sizes. For NFS, choose appropriate rsize and wsize. Ensure network bandwidth matches storage throughput.
Common mistake
Assuming mount options always help; changes can alter durability or correctness and must be validated in staging.
Key Takeaway
Match filesystem and mount options to workload I/O patterns, test changes safely, and monitor write and read I/O metrics to confirm results.
