Safe change workflow
  • 1. Baseline: collect metrics and save configuration backups.
  • 2. Small changes: adjust one parameter, note expected metric impact.
  • 3. Test: validate config syntax and reload services carefully.
  • 4. Monitor: compare after-change metrics to baseline over representative load.
Mnemonic: Backup → Change → Test → Measure
Verification examples
Nginx: test with nginx -t and reload; monitor connections and accept errors.
MySQL: change innodb_buffer_pool_size, restart, then monitor buffer hit rate and disk reads.
File server: remount with noatime and measure write I/O reduction on repeated reads.
