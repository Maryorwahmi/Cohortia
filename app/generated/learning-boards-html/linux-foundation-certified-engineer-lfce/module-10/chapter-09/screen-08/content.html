Storage and layout
Prefer SSD or NVMe for low latency. Use RAID 10 for high-performance storage. Separate data, logs, and tmp files across different devices to isolate workloads.
Kernel and scheduler
  • Tune vm.dirty_ratio and vm.dirty_background_ratio to control writeback behavior.
  • Choose noop or deadline for SSDs to avoid unnecessary scheduler overhead.
Query optimization
Use EXPLAIN to find slow queries, add indexes, and avoid full table scans. Query-level fixes often yield larger performance gains than hardware changes alone.
Key Takeaway
Combine faster storage and scheduler choices with query and index tuning; measure physical reads per query to validate improvements.
