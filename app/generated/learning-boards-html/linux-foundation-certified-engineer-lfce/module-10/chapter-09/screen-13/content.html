Module 10 › Chapter 10.9 › Hands-on Activity
Activity steps
  1. Backup: sudo cp /etc/nginx/nginx.conf /etc/nginx/nginx.conf.bak
  2. Find cores: nproc
  3. Set worker_processes = cores; worker_connections = target_concurrency / workers
  4. Test: sudo nginx -t; sudo systemctl reload nginx
  5. Monitor: connection accepts, memory, and response latency under test load
Reflection prompts
  • Which metric moved most after the change and why?
  • If the server hosts both web and DB, which process must keep priority to avoid swapping?
  • Would you apply the same worker settings to a machine with slower disks or less RAM?
Key Takeaway
Use the activity to practice the baseline-change-measure loop and to prioritize resource allocation when services share a host.
