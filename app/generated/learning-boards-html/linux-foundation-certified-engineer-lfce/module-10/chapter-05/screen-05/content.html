Command examples
netstat
netstat -tulnp  # TCP/UDP listening ports with PID/program name
netstat -s       # Summary statistics for all protocols
ss
ss -tulnp  # Faster socket listing
ss -s      # Summary statistics
ip
ip addr show
ip -s link show eth0  # bytes, packets, errors, dropped
Explanation & example
Scenario

Users report a service connection error. Run ss -tulnp to verify the process is listening, then ip -s link show to check for interface errors. If the interface shows RX errors, start with physical checks like cables and switch ports.

Common mistake

Assuming a listening port means reachability. Always verify interface health and routing as well.

Key Takeaway

Combine socket listings with interface counters to build a reliable hypothesis about reachability.
