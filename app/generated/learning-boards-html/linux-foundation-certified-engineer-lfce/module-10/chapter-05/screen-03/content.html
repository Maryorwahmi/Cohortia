Practice & Verification

Concrete checks to prove each objective, using repeated samples and correlated tools.

Verify → Repeat → Confident
01 Metrics

Measure iperf3 throughput, compare to ip -s link counters, repeat tests to confirm stability.

VERIFIED COMPETENCY MILESTONE
02 Inspect tools

Use ss and ip to map sockets to PIDs and confirm expected services own the ports reported.

VERIFIED COMPETENCY MILESTONE
03 Monitor live traffic

Run sar -n DEV and iftop during load to identify top hosts and per-second rates, confirming peak times.

VERIFIED COMPETENCY MILESTONE
04 Diagnose & troubleshoot

Use ping/traceroute and iperf3 to determine whether the network path or the application is the bottleneck.

VERIFIED COMPETENCY MILESTONE
