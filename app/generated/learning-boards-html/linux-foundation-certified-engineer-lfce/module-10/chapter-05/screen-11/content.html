Module 10 › Chapter 10.5 › Troubleshooting Flow
Step-by-step sequence
1. Physical
Check cables, link lights, and switch ports for errors.
2. Connectivity
Ping and traceroute to local and remote hops.
3. Monitor
Use sar and iftop to see traffic patterns and top talkers.
4. Measure
Run iperf3 tests between hosts to measure capacity.
5. Firewall
Confirm rules and connection tracking are not blocking traffic.
6. Tune
Adjust kernel params and NIC settings after evidence supports the change.
Example

High RX errors → check cable and switch port → confirm duplex with ethtool → run sar to see if error correlates with traffic spike → if resolved, document the fix.
