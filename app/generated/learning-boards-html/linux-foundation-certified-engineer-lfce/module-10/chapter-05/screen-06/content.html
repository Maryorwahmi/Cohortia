Module 10 › Chapter 10.5 › Interface Health
ip -s link show
ip -s link show eth0
# shows: RX packets, RX errors, RX dropped, TX packets, TX errors, TX dropped
Interpretation
  • High RX errors → likely receive-side physical issue or duplex mismatch.
  • High dropped packets → buffer drops, possible congestion or driver limits.
  • Compare TX and RX patterns to localize upstream vs server problems.
ethtool for NIC details
ethtool eth0        # show speed, duplex, offload
ethtool -S eth0     # detailed NIC statistics
Practical example

If RX errors climb and ethtool shows a mismatch in duplex or lower negotiated speed, check the switch port and cable. Duplex mismatch often causes collisions and receive errors.

Key Takeaway

Use ip counters and ethtool together to identify whether a problem is physical, driver, or configuration related.
