Tools
sar -n DEV / sar -n EDEV and iftop
Live → Trend
sar examples
sar -n DEV 1 5    # network device stats every 1s, 5 times
sar -n EDEV 1 5   # error stats for devices
Use sar to capture short sampling windows or longer collections for post-analysis.
iftop
sudo iftop -i eth0   # interactive per-connection bandwidth monitor
iftop shows which remote hosts consume bandwidth at the moment you run it.
Example workflow

Start sar to sample every second, then run iftop to see current top talkers. Correlate the iftop snapshot with sar samples to decide if the spike is sustained.

Key Takeaway

Short interactive views and repeating samples together give both context and evidence for remediation decisions.
