Module 10 › Chapter 10.5 › iperf3
Setup
# Server
iperf3 -s

# Client
iperf3 -c 10.0.0.2 -t 10         # 10 second test
iperf3 -c 10.0.0.2 -t 10 -P 5    # 5 parallel streams
Compare iperf3 output to your interface's advertised speed and ip -s counters to draw conclusions.
Example diagnosis
Scenario

If iperf3 measures near 900 Mbps on a 1 Gbps link, the network path is likely fine. If your web app is still slow, investigate CPU, memory, disk I/O, or application design.

Common mistake

Interpreting a single short iperf3 run as definitive. Repeat tests and correlate with sar or ip counters for robust conclusions.

Key Takeaway

iperf3 gives a controlled throughput baseline that helps you decide whether to troubleshoot the network or the application.
