Module 10 › Chapter 10.5 › Kernel Tuning
Inspect parameters
sysctl -a | grep net.
# example: view somaxconn
echo net.core.somaxconn = $(sysctl net.core.somaxconn)
Example change
sudo sysctl -w net.core.somaxconn=65535
# persist by adding to /etc/sysctl.conf
When to adjust
  • High connection rates and backlog drops visible in ss or application logs.
  • TIME-WAIT exhaustion or unusual connection teardown behavior.
  • Only after confirming network path and application behavior with tests like iperf3 and sar.
Caution

Kernel tuning can have system-wide effects. Make small changes, test under load, and document reversions.
