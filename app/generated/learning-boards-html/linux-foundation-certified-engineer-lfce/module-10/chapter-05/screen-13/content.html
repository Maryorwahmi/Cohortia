ethtool commands
ethtool eth0     # show speed, duplex, autoneg
ethtool -k eth0  # show offload settings
ethtool -S eth0  # detailed statistics
Example diagnostic step

If driver issues are suspected, disable a specific offload, rerun iperf3, and observe whether throughput or errors change. Re-enable when done.

When offloads matter
  • High throughput targets where CPU reduction matters.
  • When packet processing bugs or measurement anomalies appear tied to hardware acceleration.
  • Only toggle for testing; default to enable for performance.
Key Takeaway

Treat offload changes as experiments and verify their effect with iperf3 and interface counters before making permanent changes.
