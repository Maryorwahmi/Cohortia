Learning Objectives

Know, inspect, monitor, and troubleshoot network performance using CLI tools.

Bloom: Learn → Understand → Apply → Master
01
Interpret core metrics

Describe bandwidth, throughput, latency, and packet loss, and why each matters to user experience.

Venn: capacity vs observed
VERIFIED COMPETENCY MILESTONE
02
Inspect connections and interfaces

Use ss, netstat, and ip to list sockets, listening ports, addresses, and interface counters.

Mnemonic: socket → state → stats
VERIFIED COMPETENCY MILESTONE
03
Monitor live traffic

Collect per-second device stats with sar and view top connections with iftop to find heavy users.

Timeline: short sample → pattern
VERIFIED COMPETENCY MILESTONE
04
Diagnose and troubleshoot

Run ping, traceroute, and iperf3; inspect kernel and NIC settings; follow a physical-to-application troubleshooting flow.

Flow: physical → path → capacity → app
VERIFIED COMPETENCY MILESTONE
