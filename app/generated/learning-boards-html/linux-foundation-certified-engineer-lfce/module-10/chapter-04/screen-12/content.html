Module 10 › Chapter 10.4 › Filesystem Tuning
Mount options
noatime / nodiratime reduce writes for read-heavy workloads by avoiding access-time updates. Test and measure before applying widely.
Example: mount -o noatime for a read-mostly dataset to lower write amplification.
Filesystem choice
XFS and ext4 have different strengths; choose based on file sizes and concurrency. Journaling mode impacts write patterns.
Tip: measure after changes — mount options affect durability and performance trade-offs.
