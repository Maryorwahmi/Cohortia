Module 10 › Chapter 10.4 › iotop
Command
sudo iotop
# Shows per-process read/write bandwidth and I/O totals
If a dd or cp process is present during a spike, you can stop or reschedule it. If a daemon shows high writes, inspect its logs and config.
Example
Run iostat to confirm saturation, then run iotop to reveal the process. If it’s a backup process, consider throttling or off-peak scheduling.
Tip: iotop requires root and may need installation via your package manager.
