Module 10 › Chapter 10.4 › I/O Scheduler
Check current
cat /sys/block/sda/queue/scheduler
Temp set example:
echo noop | sudo tee /sys/block/sda/queue/scheduler
When to try
Try noop or deadline for SSDs; deadline helps read-priority workloads like databases; cfq is generalist and may be better for mixed desktop workloads.
Always measure device metrics and application latency before and after changes; revert if performance worsens.
