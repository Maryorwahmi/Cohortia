Module 10 › Chapter 10.4 › Learning Objectives
01
Understand disk I/O fundamentals

Define disk I/O-bound systems and why iowait rises. This helps you tell when CPU is idle waiting for storage rather than compute-limited.

VERIFIED COMPETENCY MILESTONE
02
Use iostat and sar to measure I/O

Run iostat -x and sar -b/-d to read %util, await, svctm, avgqu-sz and throughput. These metrics tell you device health and contention patterns.

VERIFIED COMPETENCY MILESTONE
03
Pinpoint processes with iotop

Install and run iotop to see real-time per-process read/write bandwidth and cumulative I/O. Use it to match device saturation to a process.

VERIFIED COMPETENCY MILESTONE
04
Apply initial mitigation strategies

From scheduler changes to mount options and application tuning, pick the least invasive step first and validate with metrics afterward.
