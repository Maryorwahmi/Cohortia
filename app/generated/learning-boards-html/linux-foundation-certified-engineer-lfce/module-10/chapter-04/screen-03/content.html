Experiment

Safe dd and observation

Create a loop file or use a non-critical mount. Run dd with oflag=direct to avoid caching and observe iostat and iotop while the job runs.

dd if=/dev/zero of=large_file.img bs=1M count=2048 oflag=direct &
# iostat -x 1 5
# sudo iotop
Safety note

Avoid critical partitions

Do not run destructive writes on system partitions. Prefer a disposable test volume or loopback file for experiments, and monitor system load closely.
