Definition
perf quick commands
# Real-time view
perf top

# Record call graphs at 99Hz for a command
perf record -g -F 99 <command>

# Analyze recorded data
perf report
What perf reveals
  • Function-level CPU hotspots and inclusive time.
  • Cache misses and branch mispredictions to highlight memory locality issues.
  • Kernel function overhead and how system calls contribute to CPU time.
Example
perf top may show a library or kernel function at the top; use perf record and perf report to see the call stacks that lead there.
Remember: without debug symbols you will see addresses only. Ensure your build includes symbols or install debug packages for meaningful names.
