Process Flow
Reproducible profiling workflow
1. Reproduce
Create a reliable case in staging; if profiling production, limit scope and duration.
2. Trace
Use strace or ltrace to gather visible kernel or library activity.
3. Confirm
Use perf record -g to capture call graphs and measure inclusive time.
4. Prioritize & Validate
Make focused code or configuration changes and re-run perf to validate impact.
Analogy: think of strace/ltrace as opening the hood to see the moving parts, and perf as a high-resolution thermometer that spots where heat accumulates across the whole system.
