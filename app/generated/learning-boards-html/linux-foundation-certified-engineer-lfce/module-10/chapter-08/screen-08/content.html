Definition
ltrace basics
Trace calls to shared libraries to detect repeated expensive functions or allocation patterns.
# Run and observe library calls
ltrace ./myprogram

# Attach to a process
ltrace -p <PID>
Example scenario
Program showing heavy CPU in string handling
Run ltrace and you might see many calls to strlen or strcpy. This points to a user-space optimization: reduce copies or change algorithms.
Misconception
Seeing a library call doesn't always mean the library is at fault; check what that call triggers at the kernel layer or measure CPU time.
Pro tip
Combine ltrace with perf to see whether a heavy library call actually consumes CPU cycles or merely prepares kernel work.
