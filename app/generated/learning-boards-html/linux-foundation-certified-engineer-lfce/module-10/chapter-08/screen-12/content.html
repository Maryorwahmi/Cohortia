Definition
Inclusive vs Exclusive time
Inclusive time = function + callees. Exclusive time = self only. Use inclusive time to prioritize impactful optimizations.
Example
A wrapper function may have low exclusive time but high inclusive time because it calls heavy processing deeper in the stack. Optimize the heavy processing for greater effect.
How to confirm
  • Record a perf session with call graphs.
  • Examine inclusive time to find the top-consuming call stacks.
  • Make a focused change, then re-run perf to validate reduced inclusive time.
Misconception
Optimizing a frequent tiny helper often yields little overall benefit; target long inclusive time first.
