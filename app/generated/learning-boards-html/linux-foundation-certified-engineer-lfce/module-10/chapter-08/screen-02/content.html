Learning Objectives
Practical competencies to verify in a lab or staging system.
Learn → Understand → Apply → Master
01
Purpose of profiling
Explain why monitoring tools show symptoms while profiling shows causes. Practice: Identify a service waiting on I/O using strace on staging.
VERIFIED COMPETENCY MILESTONE
02
strace usage patterns
Run strace for a short command, attach to a PID, and generate a summarized table. Practice: strace -c ls -l /tmp.
VERIFIED COMPETENCY MILESTONE
03
ltrace fundamentals
Trace library calls to find inefficient repeated calls to functions like string routines. Practice: ltrace a small compiled program that uses strlen or malloc.
VERIFIED COMPETENCY MILESTONE
04
perf and call graphs
Record a perf session, generate a report, and interpret hotspots. Note: debug symbols and permissions improve results. Practice: perf record -g -F 99 .
VERIFIED COMPETENCY MILESTONE
