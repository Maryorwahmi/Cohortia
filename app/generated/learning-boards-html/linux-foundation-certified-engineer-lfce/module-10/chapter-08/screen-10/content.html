Process Flow
Prepare perf for useful reports
  • Install or build debug symbols so function names and line numbers appear.
  • Ensure appropriate permissions: CAP_PERFMON or run perf as an allowed user.
  • Pick sampling frequency to balance overhead and resolution; 99Hz is a common starting point.
Example questions to ask
  • Does perf report function names or only addresses?
  • Are you allowed to access hardware counters on this host?
  • Will sampling at this frequency change production behavior?
Key takeaway
Fix environment issues first—symbols and permissions—so that perf data points to meaningful code locations you can act on.
