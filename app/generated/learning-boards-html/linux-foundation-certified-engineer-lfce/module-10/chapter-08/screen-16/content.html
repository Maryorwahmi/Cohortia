What to Remember
A compact practical checklist.
strace
Use for system-call visibility: attach, save output, and run summaries with -c.
ltrace
Trace library calls to find repeated or expensive user-space operations.
perf
Sample CPU and kernel events with low overhead; use call graphs to prioritize by inclusive time.
Final takeaway
Develop a hypothesis, select the right tracer, run focused traces, and validate fixes by re-measuring inclusive time.
