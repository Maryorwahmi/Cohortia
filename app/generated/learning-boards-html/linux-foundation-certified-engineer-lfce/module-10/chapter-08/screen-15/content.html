Key Concepts
Compact definitions to carry forward.
Profiling
Measuring program execution to identify where CPU, memory, or I/O time is spent so you can prioritize fixes.
System Call
A request from a program to the kernel for services like file I/O, sockets, or process control; visible via strace.
Library Call
A function invocation inside a shared library such as libc; visible with ltrace and useful for user-space inefficiency detection.
Takeaway
Use the right tool for the symptom: strace for kernel interactions, ltrace for library patterns, and perf for CPU-level hotspots and call graphs.
