Comparison
System calls (strace)
Observes kernel interactions such as open, read, write, poll, and nanosleep. Ideal for diagnosing blocking, permissions, and I/O patterns.
Common strace commands
strace -p <PID>
strace -o output.txt <command>
strace -c <command>
strace -T <command>
strace -tt <command>
Library calls (ltrace)
Follows calls to shared libraries like libc, showing functions such as malloc, free, strlen, or other library-specific routines. Useful for spotting repeated expensive library usage.
Common ltrace commands
ltrace <command>
ltrace -p <PID>
When to use strace
Blocked reads, permission errors, unexpected file access, or socket waits.
When to use ltrace
Inefficient library loops, repeated parsing functions, heavy string manipulation in user space.
Common mistake
Running long traces in production causes overhead and may change program behavior. Prefer short traces or staging.
