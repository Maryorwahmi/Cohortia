Troubleshooting workflow
A quick, practical sequence for CPU issues.
1. Observe
Use top/htop to see CPU states and active PIDs. Note load averages and which state is high.
2. Inspect cores
Run mpstat -P ALL to detect per-core saturation or imbalance.
3. Trend
Query sar for historical context to confirm whether the issue is persistent.
4. Act
Profile the process, check I/O, or address hypervisor contention depending on the evidence.
Common indicators and their likely cause
High iowait
Usually indicates disk I/O bottlenecks; check disk metrics and iostat.
High system time
Suggests kernel work or drivers; consider strace or perf for deeper inspection.
High steal time
Indicates hypervisor resource contention; coordinate with the host operator.
