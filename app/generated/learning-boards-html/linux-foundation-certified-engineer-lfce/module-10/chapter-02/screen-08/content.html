Module 10 › Chapter 10.2 › Using sar
Command examples
# Live short-term samples
sar -u 5 3

# View saved data for day XX
sar -u -f /var/log/sysstat/saXX
Use cases
  • Confirm whether high CPU is sustained across hours or days
  • Correlate CPU trends with cron jobs, backups, or traffic patterns
Scenario
If sar shows a nightly sustained rise in user time corresponding to backups, you might reschedule the job or throttle concurrency instead of changing application code.
Misconception
Assuming a single observation equals a trend. Always check historical data before major changes.
Key takeaway
Use sar to separate transient spikes from recurring load and to plan corrective actions with confidence.
