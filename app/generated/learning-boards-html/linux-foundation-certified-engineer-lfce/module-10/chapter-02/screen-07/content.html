Module 10 › Chapter 10.2 › mpstat per-core
Command example
mpstat -P ALL 1 5  # show per-CPU stats every 1s for 5 samples
What to look for
  • One core at 100% user time: single-threaded saturation.
  • All cores high: system-wide CPU pressure or highly parallel workload.
  • High system on a few cores: kernel activity concentrated by IRQ affinity or drivers.
Scenario and action
If mpstat shows one core saturated, examine application threading, check affinity settings, or consider running multiple instances to utilize other cores.
Misconception
Assuming more cores always improve performance. Some workloads are inherently single-threaded and require redesign to gain parallel benefit.
Key takeaway
Per-core stats reveal whether to optimize code, adjust affinity, or scale horizontally.
