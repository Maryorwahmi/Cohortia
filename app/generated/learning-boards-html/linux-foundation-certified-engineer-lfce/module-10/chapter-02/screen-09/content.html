Module 10 › Chapter 10.2 › Common CPU bottlenecks
Bottleneck list
Single-threaded saturation
One core at 100% while others idle; consider profiling or scaling horizontally.
Excessive context switching
High cs rate wastes CPU on switching; reduce thread count or batch tasks.
Kernel overhead
High sy time may point to drivers, system calls, or kernel-side inefficiencies; use perf.
Virtualization steal
High st percentage means host is oversubscribed; coordinate with the host operator.
Concrete scenario
An analytics job runs nightly and saturates one core; mpstat shows one core at 100 percent. The correct action is to profile the job or split the workload, not to immediately add cores to the host.
Key takeaway
Map symptoms to this taxonomy so your remediation targets the real cause, not a surface metric.
