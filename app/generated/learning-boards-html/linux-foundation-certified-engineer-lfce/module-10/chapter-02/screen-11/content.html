Module 10 › Chapter 10.2 › Lab walkthrough
Starter commands
# In terminal 1
top

# In terminal 2 (recommended tool)
stress --cpu 4 --timeout 60s &

# Or a simple single-core loop
while true; do :; done &

# Inspect per-core
mpstat -P ALL 1 10
Expected observations
  • Cpu user time rises and idle falls when stress runs.
  • mpstat shows either balanced core utilization or a single saturated core.
  • Load average increases while the workload runs, then returns to baseline afterward.
Reflection
After the exercise, ask whether the workload is expected and whether the observed pattern requires code changes, scheduling, or different resource allocation.
