Local profiling tools
strace for system-call traces; perf for sampling CPU usage across user and kernel code.
# trace a process's system calls
strace -p 

# sample system-wide CPU hotspots
perf top
When to involve the host
If steal time is consistently high, or perf indicates host-side activity beyond your VM, collect evidence and consult the host operator for resource adjustments.
Key takeaway
Use local profiling to rule out guest issues, then escalate with captured evidence when the root cause is the host.
