Cpu(s) breakdown
Read these percentages to determine where time is spent.
us — user time
Time running application code. High during compute-heavy workloads.
sy — system time
Time in kernel mode for drivers and system calls. Excessive values suggest kernel or driver issues.
wa — iowait
CPU idle but waiting for I/O completion. High wa usually means a disk I/O bottleneck, not CPU compute pressure.
st — steal
Cycles stolen by a hypervisor. If high, your VM is being starved of CPU by the host configuration or oversubscription.
Example top snippet
%Cpu(s): 12.3 us,  3.6 sy,  0.0 ni, 82.7 id,  1.4 wa,  0.0 hi,  0.0 si,  0.0 st
Interpretation
Most time is idle; small user time indicates light application work. If wa were high, focus on storage.
Key takeaway
Always map each high percentage to the subsystem it implicates; that guides the next diagnostic tool.
