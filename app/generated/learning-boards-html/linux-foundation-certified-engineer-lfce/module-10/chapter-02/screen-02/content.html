Bloom's taxonomy
Learn → Understand → Apply → Master
01
Run top and htop
Open live views to see CPU states and identify the most active processes. This skill helps you spot immediate causes of slowness.
VERIFIED COMPETENCY MILESTONE
02
Interpret CPU states
Learn what user, system, idle, and iowait tell you about where time is spent and where to investigate next.
VERIFIED COMPETENCY MILESTONE
03
Per-core analysis with mpstat
Check whether a single core is saturated, which suggests a single-threaded limitation or uneven workload distribution.
VERIFIED COMPETENCY MILESTONE
04
Analyze historical trends with sar
Use recorded CPU stats to determine if high usage is persistent or linked to specific events or times.
VERIFIED COMPETENCY MILESTONE
Visual mnemonic
Think of the flow: Observe (top/htop) → Inspect cores (mpstat) → Confirm trend (sar) → Act (profile, tune, or scale).
Observe
top / htop
Inspect
mpstat -P ALL
Confirm
sar -u
Act
Profile or tune
