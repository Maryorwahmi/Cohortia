Why this matters

Misinterpreting CPU usage leads to wasted time chasing the wrong subsystem. This chapter gives you an investigation path that quickly tells you whether to profile an app, tune kernel parameters, or check storage and virtualization hosts.

Key takeaway
High CPU usage must be interpreted by category—user, system, or wait—before deciding remediation.
Concept Map
Tools → States → Actions
top / htop: live processes and CPU state
mpstat: per-core details
sar: historical trends for root-cause timing
