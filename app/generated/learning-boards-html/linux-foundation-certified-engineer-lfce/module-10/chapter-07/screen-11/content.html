Module 10 › Chapter 10.7 › Apply & Persist
Step-by-step
  1. Record the current value and parameter name.
  2. Apply a temporary change for testing and re-read to confirm.
  3. Run representative workload tests and collect metrics.
  4. If results improve and no regressions appear, add the setting to /etc/sysctl.conf or /etc/sysctl.d/.
  5. Reload configuration to apply persistent settings and verify again.
Example code
# Read current value
sysctl vm.swappiness

# Temporary change for test
sudo sysctl -w vm.swappiness=10

# Persist after validation
echo "vm.swappiness = 10" | sudo tee -a /etc/sysctl.conf
sudo sysctl -p
Checklist
  • Record original value
  • Confirm change applied
  • Run realistic tests
  • Document and persist only if safe
Warning

Do not persist untested changes in production; verify in staging first.
