Compare: swappiness
Lower values favor keeping pages in RAM, which reduces latency at the cost of higher memory pressure. Higher values lead to more swap usage and potential I/O overhead.
Server-friendly
Lower value such as 10–20 is commonly used for servers to keep active data in memory.
Desktop-friendly
Higher values may help desktop machines by making more RAM available to active apps by moving idle pages to swap.
Compare: dirty_ratio vs dirty_background_ratio
dirty_background_ratio triggers background writeback earlier; dirty_ratio is the maximum allowed dirty data before processes must write out. Lowering both smooths write bursts but can increase steady write I/O.
Example
A write-heavy database may use lower ratios to avoid large spikes of writeback that interfere with latency-sensitive reads. Test thoroughly under representative transactions.
Key Takeaway

Memory parameters change residency and write behavior; choose settings by workload profile and verify with monitoring.
