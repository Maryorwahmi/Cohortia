Module 10 › Chapter 10.7 › Inspecting kernel parameters
Process: inspect and verify
  1. Discover relevant parameters for the subsystem of interest.
  2. Read the current value and note the exact parameter name and number.
  3. Make a temporary change for testing and re-query to confirm.
  4. Collect workload metrics while testing to observe impact.
  5. Revert to the recorded original value if needed.
Common-mistake
Not recording the original numeric value before changing, which makes rollback ambiguous.
Quick examples
Code block shows standard commands you will use during inspection and verification.
sysctl -a        # list all parameters
sysctl vm.swappiness    # show a specific parameter
cat /proc/sys/vm/swappiness  # equivalent read via procfs
Pro tip

Use the list output to locate parameter names, then read exact values before modifying anything.
