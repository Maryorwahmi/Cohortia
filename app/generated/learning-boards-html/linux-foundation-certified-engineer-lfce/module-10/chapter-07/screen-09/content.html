Module 10 › Chapter 10.7 › Network parameters
Key parameters
  • Pending connection queue size for listening sockets.
  • Packet input backlog to absorb bursts of incoming packets.
  • Ephemeral port range for outbound connections.
  • TIME_WAIT reuse and timeout for managing closed sockets.
Practical note
Tune these when you observe dropped connections, insufficient ephemeral ports, or excessive TIME_WAIT growth during high connection churn.
Scenario
A busy web server drops new connections during short spikes. Increasing the socket pending queue and the SYN backlog, and checking the web server accept queue size, can reduce dropped connections. Test with realistic connection patterns and monitor packet drops and accept queue statistics.
Misconception

Assuming increasing backlog always fixes drops ignores limits at the application or NIC driver level; verify at every layer.
