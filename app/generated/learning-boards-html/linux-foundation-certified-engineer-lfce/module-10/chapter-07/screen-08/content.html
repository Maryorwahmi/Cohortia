Module 10 › Chapter 10.7 › vm.overcommit_memory
What it does

Controls kernel policy for granting allocations that may exceed physical memory plus swap.

Heuristic (default)
Kernel estimates if memory can be safely granted based on current usage.
Always allow
Kernel grants allocations even if physical memory is not available; risk of OOM if allocations are used.
Strict deny
Kernel denies allocations that would exceed RAM plus swap, preventing overcommit but potentially causing allocation failures.
Example scenario
A custom in-memory service that pre-allocates large regions may prefer conservative settings so allocations fail fast during testing rather than causing unpredictable out-of-memory situations in production. Test allocation patterns under realistic loads before choosing a mode.
Misconception

There is no universally correct setting. Application behavior dictates the safest option.
