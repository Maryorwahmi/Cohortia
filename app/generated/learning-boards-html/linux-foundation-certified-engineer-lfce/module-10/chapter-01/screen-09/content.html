Module 10 › Chapter 10.1 › Establishing a performance baseline
Baseline essentials
Collect CPU, memory, disk I/O, and network metrics during normal operation and store them with context.
What to record
  • Average and peak CPU utilization
  • Memory free vs cached and swap usage
  • Disk reads/writes and latency
  • Network throughput per interface
Why it matters
Baselines let you see deviations and quantify the impact of configuration or load changes.
Hands-on snapshot steps
The activity in this chapter suggests a short sequence of commands to capture a basic baseline.
# Quick baseline snapshot
uptime          # load averages
free -h         # memory usage
df -h           # disk space
# Install sar (sysstat) and sample:
# sudo apt install sysstat
sar -u 1 5      # CPU
sar -r 1 5      # memory
sar -b 1 5      # disk I/O
sar -n DEV 1 5  # network
Key Takeaway

Capture representative samples, annotate them with context, and store them for future incident comparisons.
