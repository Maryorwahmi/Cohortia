Module 10 › Chapter 10.1 › Network-bound behavior
Network constraints
Bandwidth caps, latency, and packet loss all reduce effective throughput and increase perceived slowness.
Concrete example
A streaming service hits link limits and users experience buffering, while CPU and disk remain underused.
Misconception
Assuming application timeouts are not network-related. Always correlate application logs with network counters.
Key Takeaway

Measure throughput, latency, and retransmissions. If network metrics line up with symptoms, optimize transfers or scale to mitigate the bottleneck.

Diagnostic checks
Commands
sar -n DEV for interface stats; check error and retransmit counters; capture latency from ping/traceroute if needed.
Possible fixes
Tune buffer sizes, enable compression, change routing or add capacity at the network boundary.
