Module 10 › Chapter 10.1 › Memory and swap behavior
Memory-bound systems
When RAM is insufficient, the system swaps, turning memory waits into disk waits and harming latency.
Concrete example
A long-running service leaks memory, gradually exhausting RAM; once swapping begins, interactive tasks slow down dramatically.
Misconception
Cached memory is helpful and reclaimable; low free memory alone is not proof of a problem without swap or high page faults.
Key Takeaway

Watch swap I/O and page fault rates. If swapping correlates with slowdown, fix memory use or increase RAM, and then re-measure against the baseline.

Quick diagnostic checks
Commands to run
free -h, vmstat, sar -r, /proc/vmstat, top to see RES and VIRT.
What to look for
High page-in/page-out rates, rising swap usage, and growing resident sizes for processes.
