Module 10 › Chapter 10.1 › CPU as a limiting resource
CPU-bound
Sustained high CPU use; performance limited by instruction throughput.
Symptoms
  • Sustained high CPU percentage
  • Single process dominates CPU time
  • Thread contention or busy loops
Example
A compression task spikes CPU, causing web requests to queue even though disk and network are idle.
Key Takeaway

Profile the offending process, validate algorithmic inefficiency before adding CPU, and measure after single changes.

Diagnostic process
1. Observe
Confirm sustained CPU load via top or sar.
2. Identify
Find the process or thread using top, ps, or pidstat.
3. Profile
Use strace or perf to understand where cycles are spent.
Analogy
Think of CPU as a cashier lane. If one lane has a complex transaction, everyone waits even if other lanes are empty.
