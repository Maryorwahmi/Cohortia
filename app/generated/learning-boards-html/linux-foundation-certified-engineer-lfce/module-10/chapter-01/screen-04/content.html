Module 10 › Chapter 10.1 › What is performance?
Performance defined
Tie an observable user outcome to numeric metrics and collect them consistently.
Concrete example
Web server goal: 95% of requests respond within 200 milliseconds. Baseline captures average and percentile response times during normal traffic.
Common misconception
Low CPU usage does not guarantee good performance; latency may be caused by I/O or network constraints.
Key Takeaway

Write a concrete metric for success, collect baseline values, and always validate tuning changes against that baseline.

Performance categories
Latency
Time for a single operation.
Throughput
Operations per second over time.
Resource utilization
CPU, memory, I/O, network percentages and rates.
Percentiles
95th or 99th percentile measures reveal outlier behavior.
