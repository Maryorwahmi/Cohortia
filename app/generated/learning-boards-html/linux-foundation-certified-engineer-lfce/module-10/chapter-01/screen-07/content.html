Disk I/O constraints
High latency or low throughput at the storage layer creates wait states that slow the whole system.
Symptoms
  • High iowait percentage
  • Long average read/write latency
  • Processes in uninterruptible sleep
Example
A database on spinning disks exhibits rising query latency as random I/O saturates the drive, despite low CPU usage.
Key Takeaway

Measure read/write latency and IOPS. Fix by improving storage performance or changing access patterns, then re-measure against baseline metrics.

Guided checks
Commands
iostat, sar -b, iotop, dstat to view I/O rates and latency.
Tuning options
Change filesystem mount options, tune queue depths, or move to faster storage.
