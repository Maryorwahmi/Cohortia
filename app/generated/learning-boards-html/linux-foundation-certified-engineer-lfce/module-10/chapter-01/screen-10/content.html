Command examples
Run these exactly to create a repeatable snapshot. Save outputs with timestamps and notes.
# Quick snapshot sequence
uptime
free -h
df -h
# Install sysstat (if needed):
# sudo apt install sysstat
sar -u 1 5
sar -r 1 5
sar -b 1 5
sar -n DEV 1 5
Practical tips
  • Sample at consistent intervals and label outputs with date and running workload.
  • Keep a baseline directory with timestamped files and a short note about active services.
  • Automate collection with cron or a monitoring agent for continuous baselines.
Key Takeaway

Use these simple commands to build repeatable snapshots, then automate and store them to form a meaningful baseline.
