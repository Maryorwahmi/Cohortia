Module 10 › Chapter 10.6 › Configure atop
Edit configuration
Set LOGINTERVAL (seconds) and LOGPATH to a writable directory. Ten minutes (600 seconds) is a common starting point.
# Example setting
LOGINTERVAL=600
LOGPATH=/var/log/atop
Enable & validate
  1. sudo systemctl enable atop && sudo systemctl start atop
  2. Wait for the configured interval and check /var/log/atop for a new file.
  3. Replay with atop -r to confirm recorded intervals.
