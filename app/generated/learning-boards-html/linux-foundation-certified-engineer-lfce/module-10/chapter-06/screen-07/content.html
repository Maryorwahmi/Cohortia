Module 10 › Chapter 10.6 › Configure sysstat
Checklist
  1. Check for cron or systemd timer entries in /etc/cron.d/sysstat or systemd timers.
  2. Force an immediate sample with sudo /usr/lib/sysstat/sa1.
  3. Verify sa files appear in /var/log/sysstat or /var/log/sa.
  4. Use sar -f to inspect the newly created file.
Quick verification commands
ls -l /var/log/sysstat/
sudo /usr/lib/sysstat/sa1    # force a collection
sar -A -f /var/log/sysstat/sa$(date +%d)
If files are not created, ensure the sysstat package’s collection job is enabled. Also verify file rotation/retention policies so logs are available when you need them.
