Module 10 › Chapter 10.6 › Tasks
Four task cards
01 Verify sysstat logging
Check cron entries and force /usr/lib/sysstat/sa1 to create sa files.
02 Read historical sar
Use sar -A -f /var/log/sysstat/saDD and narrow times with -s and -e.
03 Drill with pidstat
Run pidstat -u -r -d to capture per-process CPU, memory, and I/O over intervals.
04 Replay atop
Start atop logging, create load, then use atop -r to replay the day and step through time.
Demo flow
Follow a simple loop: confirm logging, generate load for one interval, wait for logs to be written, then inspect sar and atop logs to build the incident timeline.
