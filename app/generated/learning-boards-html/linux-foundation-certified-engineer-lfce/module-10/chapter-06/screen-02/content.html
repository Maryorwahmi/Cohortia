Module 10 › Chapter 10.6 › Learning Objectives
01
Master sysstat tools
Learn sar, pidstat and sadc to collect and analyze historical metrics for CPU, memory, disk and network.
Verified competency milestone
02
Configure persistent logging
Enable sadc and atop logging so data is available after an incident for replay and analysis.
Verified competency milestone
03
Interpret atop output
Read CPU, MEM, DSK and PRC sections and use sorting keys to find the busiest processes quickly.
Verified competency milestone
04
Combine historical + real-time
Correlate sar timelines with atop process deltas to attribute spikes to specific processes and times.
Verified competency milestone

Enable logging, generate load, then use sar and atop logs to trace the event. Use pidstat to confirm the offending process.
