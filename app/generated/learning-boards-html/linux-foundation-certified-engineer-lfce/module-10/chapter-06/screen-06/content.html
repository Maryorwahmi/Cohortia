Module 10 › Chapter 10.6 › sysstat internals
Key components
  • sadc — the periodic data collector that writes sa binary files.
  • sar — reader and reporter for saved data and live samples.
  • pidstat — per-process sampling for CPU, memory and I/O.
Useful sar flags
-u CPU, -r memory, -b block I/O, -n network, -q run queue, -W swap, -d per-device, -A all stats.
File locations & examples
/var/log/sysstat/sa15   # binary samples for day 15
sar -u -f /var/log/sysstat/sa15   # read CPU stats for that day
sar -A -f /var/log/sysstat/sa$(date +%d)   # all stats for today
Operational tip
Schedule sadc at an interval that matches the burst duration you need to capture; ten minutes is common but not universal.
