Module 10 › Chapter 10.6 › atop Overview
What atop shows
  • CPU per core and breakdown of sys, user, irq, idle and wait.
  • Memory totals and swap usage with real-time changes.
  • Disk per-device utilization, reads/writes, and queue lengths.
  • Network per-interface activity and errors.
  • Process list with CPU%, memory%, WDSK/RDSK and network R/W per process.
Atop highlights resource bottlenecks via color, and because it records deltas it can report activity from short-lived processes that have already exited. Use sort keys to focus on CPU, memory, disk or network contributors during investigation.
Run & replay
Run atop for live inspection with atop. To replay, use atop -r /var/log/atop/atop_YYYYMMDD and step through time. Use keys c, m, d, n to sort processes by different metrics during replay.
