Module 11 › Chapter 10.10 › Designing actionable alerts
Alert rule anatomy
Metric + Threshold
E.g., CPU > 80% averaged over 5 minutes.
Duration
Require sustained breaches to reduce false positives.
Routing
Send alerts to the team that can act, with a clear playbook link or step list.
Example alert templates
CPU sustained
Trigger when CPU > 80% for 5 minutes. Remediation: check processes, scale or optimize service.
Memory available
Trigger when available memory < 10%. Remediation: check swap activity and heavy processes.
Disk fill
Trigger when critical disk > 90%. Remediation: clean logs or increase capacity.
Pro Tip

Document expected remediation steps inside the alert so responders know the first actions to take and can reduce mean time to resolution.
