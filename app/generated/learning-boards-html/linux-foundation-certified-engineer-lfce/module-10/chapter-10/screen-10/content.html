Module 11 › Chapter 10.10 › Collectd & Grafana (Conceptual)
Conceptual steps
  1. Install collectd and enable cpu, memory, disk, interface plugins.
  2. Configure output plugin (WriteGraphite or WriteJSON) to forward data.
  3. Set up time-series storage and define retention policy.
  4. Create Grafana dashboard panels and add alerting rules.
Sample collectd snippet
LoadPlugin cpu
LoadPlugin memory
LoadPlugin disk
LoadPlugin interface

# Example output to write JSON locally

  DataDir "/var/lib/collectd/json"
This snippet shows enabling plugins and a simple local JSON output. In production you would configure a remote write or writer that your metric store accepts.
