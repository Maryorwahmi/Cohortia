Collectors (agents)
node_exporter
Prometheus exporter for OS metrics. Good for scrape-based architectures.
collectd
Plugin-based collector that can write to Graphite, Influx, or files for later ingestion.
Telegraf
Agent with many output plugins, often used with InfluxDB and Grafana.
Monitoring systems & trade-offs
Prometheus + Grafana
Flexible querying and alerting; plan for long-term storage or remote write for retention.
Zabbix
Integrated solution with data collection and robust alerting suitable for enterprise features.
Nagios / Icinga
Traditional availability checks with extensions for performance metrics.
Common trade-off

Choose tools by the retention and query needs: short-term fast queries or long-term trend analysis require different storage planning.
