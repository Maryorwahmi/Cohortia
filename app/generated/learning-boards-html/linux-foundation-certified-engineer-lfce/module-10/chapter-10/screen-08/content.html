Module 11 › Chapter 10.10 › Capacity Planning
Trend analysis steps
  1. Collect historical metrics over a consistent window.
  2. Compute growth rates (weekly/monthly) for each KPI.
  3. Project when KPIs will hit critical thresholds.
  4. Plan capacity actions using what-if scenarios.
Concrete example
If CPU grows 5% monthly and is at 70% now, plan a capacity action before it reaches 90%.
Scaling options
Scale Up
Add more CPU/RAM to existing servers for simplicity but limited elasticity.
Scale Out
Add more servers behind load balancers to distribute load.
Cloud Bursting
Temporarily add cloud resources to handle peaks without long-term cost.
Optimize
Improve efficiency by tuning application or identifying underutilized resources.
Key Takeaway

Project trends, run what-if scenarios, and pick scaling or optimization strategies aligned to business needs and cost models.
