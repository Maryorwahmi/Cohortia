Memory Performance Monitoring and Analysis

Practical techniques to observe, interpret, and troubleshoot memory behavior on Linux systems. Learn which metrics matter and what to do when memory becomes a bottleneck.

Concept Map
RAM ↔ Page Cache ↔ Swap. Cache is reclaimable; swap is slow.
RAM
Fast volatile working memory for active processes.
Cache
Kernel page cache used to speed disk access; reclaimable.
Swap
Disk-based overflow when RAM is exhausted; slow and can cause thrashing.
Tools
free, vmstat, sar -r for snapshots, live data, and history.
Explore Key Topics
Reading free -h
Understand available vs free and why buff/cache is healthy.
Interpreting vmstat
Key columns: swpd, si, so, bi, bo — indicators of swap and I/O activity.
Mitigation
Initial steps: find greedy processes, tune swappiness, or add RAM.
