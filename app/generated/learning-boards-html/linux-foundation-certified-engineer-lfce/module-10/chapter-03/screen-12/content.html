Hands-on Activity

Observe free, vmstat and swappiness

Use two terminals: one to monitor free -h, another to change swappiness and create memory pressure. Safely revert settings when finished.

    # Terminal 1: Observe
    watch -n 1 free -h

    # Terminal 2: Check and change swappiness
    cat /proc/sys/vm/swappiness
    sudo sysctl vm.swappiness=80

    # Create a safe memory allocation (example)
    python3 -c "x = 'A' * (512*1024*1024); input('Press Enter to release...')" &

    # Observe vmstat while running
    vmstat 1 60

    # After test: reset swappiness
    sudo sysctl vm.swappiness=10
What to watch
available, swpd, si, so, bi, bo; confirm swap activity correlates with performance drop.
Safety note
Do not exhaust all RAM and swap; adjust allocation size to avoid OOM or impacting other users.
Key Takeaway

A controlled experiment reinforces how available and si/so change and how swappiness affects swap behavior.
