Mitigation

Actions to relieve memory pressure

Quick & Reversible
Restart low-risk services, temporarily adjust vm.swappiness, pause non-critical jobs.
Medium-term
Profile and optimize application memory use, fix leaks, reduce in-app caches.
Long-term
Add RAM, redesign workload distribution, or resize swap for capacity planning.
Guided workflow
  1. Confirm pressure with free -h and vmstat (si/so).
  2. Identify processes with top/htop and test a controlled restart.
  3. Temporarily tune swappiness and monitor immediate effect.
  4. Plan permanent fixes: code changes or capacity increases.
Key Takeaway

Prefer reversible changes first and use monitoring to validate their effect before committing to long-term solutions.
