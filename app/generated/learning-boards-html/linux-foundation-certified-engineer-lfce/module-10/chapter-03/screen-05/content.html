Definition · Tool

free -h

A snapshot showing memory totals, buffers/cache, and the useful 'available' column.

              total        used        free      shared  buff/cache   available
    Mem:           7.8G        4.5G        500M        100M        2.8G        3.0G
    Swap:          2.0G        1.5G        500M
Interpretation: high buff/cache with ample available is ok. Persistent swap in use is a concern.
Misconception
Clearing cache to make 'free' bigger improves performance. It usually harms it.
Pro tip
Focus on 'available' and Swap values instead of raw 'free'.
Concrete example
You set a memory-heavy job and rerun free -h. If available drops and swap grows, the job caused real pressure. If buff/cache drops while available remains stable, the kernel reclaimed cache.
Key Takeaway

Use free -h for quick checks; interpret buff/cache and available, not just free.
