Definition · Tool

sar -r

Historical memory reporting to detect trends, leaks, and recurring events.

    sar -r 5 3        # collect samples every 5s, 3 times
    sar -r -f /var/log/sysstat/saXX   # view archived file
Interpret mapped columns: look for kbmemused, kbbuffers, kbcached and kbswpfree to understand long-term behavior.
Concrete example
You observe a performance regression at 02:00 every night. Use sar -r logs to see if swap usage grows on that schedule, confirming cron jobs or backups as a cause.
Misconception
Assuming a single snapshot shows long-term health. Always check historical logs for trends.
Pro tip
Combine sar -r with log timestamps to correlate memory trends with scheduled tasks.
Key Takeaway

Historical data from sar -r distinguishes transient spikes from slow leaks or recurring scheduling-related pressure.
