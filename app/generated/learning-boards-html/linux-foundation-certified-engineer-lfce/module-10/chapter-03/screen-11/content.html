Troubleshooting

Common memory issues

OOM (Out of Memory)
System and swap exhausted; kernel may kill processes.
Thrashing
Sustained swapping with high si/so and poor throughput.
Memory leaks
Processes with steadily rising RES over time.
Diagnostic flow
  1. Run free -h and note 'available' and swap usage.
  2. Run vmstat with short intervals to observe si/so and bi/bo trends.
  3. Use top/htop to find processes with large or growing RES.
  4. Check sar -r logs to confirm long-term trends or leaks.
Example: a background job that slowly increases RES each day will show up in sar -r and top; plan a controlled restart and code inspection.
Common mistake

Clearing cache to 'fix' memory signs causes reduced performance and masks the real issue.

Pro tip

Document changes and observe vmstat after each change to confirm improvement before persisting.
