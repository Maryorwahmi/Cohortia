Core Concept

RAM, Swap, Page Cache & Buffers

Understand each term and why kernel caching is beneficial and reclaimable when needed.

RAM
Volatile memory for active processes; fastest store the CPU uses.
Swap
Disk area used as overflow; slow and causes performance issues when used heavily.
Page cache
Kernel cache of disk blocks to accelerate reads; reclaimable for applications.
Buffers
Kernel memory for block device I/O operations.
Concrete example
A server shows:
free: 200M, buff/cache: 3.0G, available: 2.8G — This is healthy caching; the kernel will free cache when applications need memory. Persistently increasing swap usage would be the real concern.
Misconception
Treating low 'free' as a problem without checking 'available' and swap activity.
Tip
Use 'available' as a better indicator of freeable memory for new apps.
Key Takeaway

Cache is useful and reclaimable; watch swap growth and si/so to detect real pressure.
