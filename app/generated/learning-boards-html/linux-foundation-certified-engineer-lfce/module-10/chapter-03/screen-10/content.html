Process · Tuning

vm.swappiness

Controls kernel swapping behavior; tune carefully and monitor effects.

    # Check current swappiness
    cat /proc/sys/vm/swappiness

    # Temporarily set swappiness to 10
    sudo sysctl vm.swappiness=10

    # Persistently set in /etc/sysctl.conf
    echo "vm.swappiness = 10" | sudo tee -a /etc/sysctl.conf
    sudo sysctl -p
After changing, run vmstat and free -h while exercising your workload to observe si/so and available changes.
Concrete example
You lower swappiness from 60 to 10 on a database server and observe less swap activity under peak load, improving latency. However, if cache-sensitive workloads require freed pages, watch for increased disk reads.
Misconception
Lower swappiness always improves performance. It depends on workload and cache needs.
Pro tip
Make temporary changes first and monitor vmstat si/so before persisting to sysctl.conf.
Key Takeaway

Swappiness tuning is a measured trade-off; reduce it to keep active processes in RAM but verify effects under load.
