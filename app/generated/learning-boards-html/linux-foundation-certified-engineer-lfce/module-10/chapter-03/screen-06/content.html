Use vmstat as a live tracer to observe memory, swap and block I/O trends.

Important columns
  • swpd — swap used
  • free — idle memory
  • buff/cache — kernel buffers and page cache
  • si/so — swap in/out per second
  • bi/bo — block device IO
Concrete observation
Run vmstat while starting a memory-heavy job. If si and so spike and bi/bo increase, swapping is causing extra disk activity and slowdowns.
Misconception
A single vmstat snapshot proves nothing — trends matter.
Pro tip
Run vmstat with short interval samples to reveal swapping behavior over time.
Key Takeaway

Use vmstat as a live tracer; sustained si/so values are your signal for swapping and thrashing.
