Module 3 › Chapter 3.4 › Server setup
Create directories & ownership
sudo mkdir -p /srv/nfs_share /srv/samba_public /srv/samba_private
sudo chown nobody:nogroup /srv/nfs_share
sudo chown nobody:nogroup /srv/samba_public
sudo useradd -M -s /sbin/nologin smbuser1
sudo smbpasswd -a smbuser1
sudo chown smbuser1:smbuser1 /srv/samba_private
sudo chmod 770 /srv/samba_private

These steps prepare the filesystem so NFS and Samba services can serve the paths with predictable ownership and permissions.

Enable services & exports
/etc/exports:
/srv/nfs_share *(rw,sync,no_subtree_check,root_squash,anonuid=65534,anongid=65534)

sudo exportfs -ra
sudo systemctl enable --now nfs-server rpcbind
sudo systemctl enable --now smb nmb
sudo firewall-cmd --add-service=nfs --permanent && sudo firewall-cmd --reload
sudo firewall-cmd --add-service=samba --permanent && sudo firewall-cmd --reload
Key Takeaway

Prepare directories and ownership before enabling services; service status and firewall rules are required for successful client access.
