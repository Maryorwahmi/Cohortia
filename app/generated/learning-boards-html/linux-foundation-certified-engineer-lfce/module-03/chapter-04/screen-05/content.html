Module 3 › Chapter 3.4 › Export lifecycle
Steps to apply an export
  1. Write the export line into /etc/exports with client and option list.
  2. Run sudo exportfs -ra to re-export all shares and update rpcbind mappings.
  3. Restart or reload nfs-server if service-level changes are required.
  4. On the client, mount with sudo mount -t nfs server_ip:/path /mnt/path or add to /etc/fstab for persistence.
Command checklist
sudo exportfs -ra
sudo systemctl restart nfs-server
sudo mount -t nfs server_ip:/data/shared /mnt/shared
Example scenario

You add a new export for /srv/nfs_share to allow a build farm access. After editing /etc/exports you run exportfs -ra; the clients can then mount the share without a full service restart, which reduces disruption.

Key Takeaway

exportfs -ra applies changes safely; prefer it before restarting services to minimize interruptions.

Common mistake

Forgetting to open NFS in the firewall or to start rpcbind prevents mounts even if exports are correct.
