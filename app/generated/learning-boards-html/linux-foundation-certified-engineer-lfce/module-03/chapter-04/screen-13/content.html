Module 3 › Chapter 3.4 › Client Access
Mount and test NFS
sudo mount -t nfs :/srv/nfs_share /mnt/nfs_client
ls -l /mnt/nfs_client
# create a test file to validate write access
sudo touch /mnt/nfs_client/testfile && ls -l /mnt/nfs_client/testfile

Verify the file appears on the server with expected owner and group IDs, especially when root_squash or anonuid/anongid are in use.

Access Samba shares
smbclient -L  -N
smbclient ///public_share -N
smbclient ///private_share -U smbuser1%password123

List shares, connect anonymously to public shares, and authenticate to private shares. Confirm file creation and ownership on the server side after writes.

Key Takeaway

A successful mount or connection is only the first step; validate read/write as the intended user and check server-side ownership and SELinux.
