Secure File Sharing with NFS and Samba

Learn when to export a Linux directory with safe options, and how to expose SMB/CIFS shares to Windows users while enforcing authentication. This chapter mixes configuration, security choices, and practical troubleshooting you will use in production.

Why this matters

Misconfigured exports or samba shares can grant unintended access, break backups, or stop Windows clients from finding servers. Learning export options, Samba security modes, and the common fixes keeps data available and secure.
