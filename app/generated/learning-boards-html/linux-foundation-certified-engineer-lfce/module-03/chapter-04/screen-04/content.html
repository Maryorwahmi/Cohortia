Core Concept

NFS: Linux-native file sharing

NFS lets Linux clients mount remote directories and use files with familiar POSIX permissions and ownership. It relies on a server-side /etc/exports configuration and services like rpcbind and nfs-server to operate.

Definition: Network File System protocol for Unix-like OSes to share directories.
When to use: Linux-to-Linux home dirs, build servers, or central data stores requiring POSIX semantics.
Misconception: Export options replace filesystem permissions — they don't; check ownership and SELinux too.
Example export
# /etc/exports on the NFS server
/data/shared 192.168.40.100(rw,sync,no_subtree_check,no_root_squash)
/data/projects 192.168.40.0/24(rw,sync,no_subtree_check,root_squash,anonuid=1000,anongid=1000)
Key Takeaway

Export lines control who can mount, but server-side ownership, permissions, and SELinux ultimately decide allowed operations.
