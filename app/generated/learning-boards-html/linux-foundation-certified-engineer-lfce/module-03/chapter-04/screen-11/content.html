Validation steps
  • Run testparm to validate smb.conf syntax.
  • Check smb and nmb service status and enable them if necessary.
  • Open Samba in firewalld or verify UDP 137/138 and TCP 139/445 ports.
  • Validate filesystem ownership and SELinux contexts for the share path.
Commands & checks
List shares anonymously
smbclient -L <server_ip> -N
Open firewall
sudo firewall-cmd --add-service=samba --permanent && sudo firewall-cmd --reload
Common mistake

Assuming Windows name resolution fails due to smb.conf errors; often it's nmbd or blocked UDP ports 137/138.
