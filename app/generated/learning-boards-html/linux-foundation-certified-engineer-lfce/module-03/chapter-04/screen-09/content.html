What Samba provides

Samba exposes SMB/CIFS shares so Windows and other clients can list, connect, and read or write files using Samba users and optional domain integration. The server is driven by /etc/samba/smb.conf.

Example configuration
# /etc/samba/smb.conf
[global]
    workgroup = WORKGROUP
    server string = Samba Server %v
    netbios name = SAMBASERVER
    security = user
    map to guest = Bad User

[public]
    comment = Public Share
    path = /srv/samba/public
    browseable = yes
    read only = no
    guest ok = yes
    create mask = 0664
    directory mask = 0775
Operational tips
  • Use testparm to validate smb.conf before restarting services.
  • Create Samba users separate from system accounts using smbpasswd -a.
  • Adjust create and directory mask so new files have expected permissions.
Key Takeaway

Samba is a configuration-driven service; file permissions and SELinux still determine actual access regardless of share settings.
