Module 3 › Chapter 3.4 › Samba Authentication
User setup steps
sudo useradd -M -s /sbin/nologin smbuser
sudo smbpasswd -a smbuser

These commands create a local system user without a login shell and register a Samba password for that user so they can authenticate to Samba shares in security = user mode.

Share example
[private]
    comment = Private Share
    path = /srv/samba/private
    browseable = no
    read only = no
    valid users = smbuser
    force group = smbgroup
Key Takeaway

Samba authentication requires both a Samba user and proper filesystem ownership; using force group simplifies shared write access.
