Module 3 › Chapter 3.4 › Export options
Key export options
rw / ro
Grant read-write or read-only access respectively. Use ro for sensitive or archival exports.
sync / async
sync writes to disk before reply for durability; async improves performance but risks data loss on crash.
no_subtree_check
Disable subtree checking for improved performance when exporting whole filesystems; use cautiously when sharing only subdirectories.
Practical comparisons
Durability-focused
Use rw, sync, root_squash for backups and critical data stores.
Performance-focused
For build caches, consider async with care and ensure proper backups exist.
Key Takeaway

Choose options based on data criticality: prefer sync and root_squash for production data, and document exceptions like no_root_squash.
