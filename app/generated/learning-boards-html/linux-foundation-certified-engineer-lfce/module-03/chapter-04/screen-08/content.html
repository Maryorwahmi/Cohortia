Module 3 › Chapter 3.4 › NFS Troubleshooting
Checklist
Firewall
Enable the nfs service in firewalld to open rpcbind, nfs, and related ports as the chapter suggests.
rpcbind
Ensure rpcbind is running so RPC program numbers map to network ports for NFS services.
Permissions
Verify filesystem ownership and modes so the squashed anonymous user or specified anonuid can read/write.
SELinux
Set appropriate contexts with semanage fcontext and restorecon or enable nfs_export_all_rw where necessary.
Example fixes
Open NFS in firewalld
sudo firewall-cmd --add-service=nfs --permanent && sudo firewall-cmd --reload
SELinux context
semanage fcontext -a -t public_content_rw_t "/data/shared(/.*)?" && restorecon -Rv /data/shared
Common mistake

Switching export options without checking firewall and SELinux can hide the true cause of a failed mount. Diagnose network and contexts first.
