Module 3 › Chapter 3.4 › Key Concepts
NFS
A distributed file system protocol for Unix-like OSes to share directories and files.
/etc/exports
The NFS server file that defines exported paths, client rules, and option lists.
rw / ro
Export options controlling read-write or read-only access for clients.
Summary

NFS exports express intent, but server-side permissions and SELinux enforce actual access. Choose options to match your data safety needs.
