Learning Objectives

Learn → Understand → Apply → Master

Bloom bar
01
Configure and manage NFS

Write /etc/exports entries, reload with exportfs -ra, and manage nfs-server and rpcbind so clients can mount shared directories reliably.

Mnemonic: Exports = map of path → clients
VERIFIED COMPETENCY MILESTONE
02
Implement secure NFS export options

Use root_squash, no_root_squash only for trusted hosts, and set anonuid/anongid to control squashed identities; prefer sync when durability matters.

Mnemonic: Squash maps root → anonymous
VERIFIED COMPETENCY MILESTONE
03
Configure Samba and user authentication

Author shares in /etc/samba/smb.conf, create local Samba users with smbpasswd, and choose security modes such as user or domain integration concepts.

Mnemonic: smb.conf = share catalogue
VERIFIED COMPETENCY MILESTONE
04
Troubleshoot permissions, network and authentication

Validate firewall services, check nmbd and rpcbind, and adjust SELinux file contexts so shares are both accessible and secure.

Mnemonic: Check ports, services, contexts
VERIFIED COMPETENCY MILESTONE
