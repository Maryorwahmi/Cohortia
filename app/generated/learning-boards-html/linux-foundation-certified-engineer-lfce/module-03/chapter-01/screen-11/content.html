Module 3 › Chapter 3.1 › Access controls
Directive comparison
allow-query
Controls which clients can query records. Default can be restricted to trusted networks for internal zones.
allow-transfer
Permits AXFR/IXFR to the listed IPs. Only slave servers should be included here.
allow-recursion
Limits recursive queries. Leave recursion off or tightly scoped on authoritative servers to reduce misuse.
Practical ACL pattern
acl "trusted" { 127.0.0.1; 192.168.10.0/24; };
options {
  allow-recursion { trusted; };
};
zone "example.com" {
  type master;
  allow-transfer { 192.168.10.200; };
};
Common mistake
Using broad allowances like any or 0.0.0.0/0 for transfers or recursion exposes your server to misuse and data leakage.
