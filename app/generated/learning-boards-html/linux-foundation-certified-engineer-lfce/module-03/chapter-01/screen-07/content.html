Module 3 › Chapter 3.1 › Forward zone file
db.example.com (example)
; /var/named/db.example.com
$TTL 86400
@       IN      SOA     ns1.example.com. admin.example.com. (
                        2023102701 ; Serial
                        3600       ; Refresh
                        1800       ; Retry
                        604800     ; Expire
                        86400 )    ; Minimum TTL
@       IN      NS      ns1.example.com.
@       IN      NS      ns2.example.com.
ns1     IN      A       192.168.10.100
ns2     IN      A       192.168.10.200
www     IN      A       192.168.10.101
mail    IN      A       192.168.10.102
@       IN      MX 10   mail.example.com.
Explanation cards
SOA serial
Increment on each authoritative change. Slaves compare serials to decide whether to request transfers.
NS vs A
NS lists authoritative servers; A maps names to IPv4 addresses used by NS and other hosts.
MX & PTR note
MX points mail to a host; ensure the mail host has a matching A and reverse PTR record to avoid mail delivery problems.
Key Takeaway

Maintain clear serial conventions and validate zone files before reloading to avoid propagation issues and service disruption.
