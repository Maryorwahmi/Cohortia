Module 3 › Chapter 3.1 › Validation tools
Command examples
# Check named.conf syntax
sudo named-checkconf

# Validate a zone file
sudo named-checkzone example.com /var/named/db.example.com

# Reload a single zone
sudo rndc reload example.com

# View named logs
sudo journalctl -u named -f
Operational notes
  • Run checks before reloads to avoid service failures.
  • Use rndc for zone reloads to avoid full restarts where possible.
  • Monitor logs immediately after reload for warnings or transfer issues.
Check sequence
named-checkconf → named-checkzone → rndc reload → journalctl review
