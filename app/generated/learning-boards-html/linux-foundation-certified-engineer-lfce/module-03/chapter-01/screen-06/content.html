Module 3 › Chapter 3.1 › Zone declarations
Forward zone example
zone "example.com" IN {
    type master;
    file "db.example.com";
    allow-update { none; };
    allow-transfer { 192.168.10.200; };
};
Ensure the filename and path match directory in options. Allow-transfer must list trusted slave IPs.
Reverse zone example
zone "10.168.192.in-addr.arpa" IN {
    type master;
    file "db.192.168.10";
    allow-update { none; };
    allow-transfer { 192.168.10.200; };
};
Validation
Run named-checkzone example.com /var/named/db.example.com to confirm SOA and record syntax before reloading.
Common pitfall
Typos in the reverse zone name (in-addr.arpa ordering) or wrong file paths prevent zone loading at startup.
