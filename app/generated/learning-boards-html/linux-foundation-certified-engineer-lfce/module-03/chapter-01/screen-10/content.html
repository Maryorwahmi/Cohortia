Module 3 › Chapter 3.1 › Slave configuration
Slave zone declaration
zone "example.com" IN {
    type slave;
    file "slaves/db.example.com";
    masters { 192.168.10.100; };
};
The slave stores zone data received from the master; do not edit slave files manually. Keep them separated under a slaves directory.
Verification & logs
On the slave run: dig @192.168.10.200 example.com to confirm the slave answers. Check journalctl -u named for AXFR activity and look for successful transfer messages.
Common operational checks
  • Master's allow-transfer must include slave IP.
  • TCP port 53 must be open between master and slave.
  • Serial must be incremented after edits on master.
