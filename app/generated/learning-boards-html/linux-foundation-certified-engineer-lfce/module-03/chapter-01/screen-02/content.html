Learning Objectives

Bloom ladder: Learn → Understand → Apply → Master

Learn → Understand → Apply → Master
01
Authoritative zone configuration

Write named.conf zone declarations and create a forward zone file with SOA, NS and host records. Practice: use the provided db.example.com template and load it on a master server.

VERIFIED COMPETENCY MILESTONE
02
Forward & reverse zones

Build a reverse lookup zone for an IPv4 subnet with PTR records and validate reverse lookups using dig -x. Why it matters: mail and logging often require reverse resolution.

VERIFIED COMPETENCY MILESTONE
03
Security and transfer controls

Apply allow-query, allow-transfer and allow-recursion to limit access. Practice: permit transfers only to known slave IPs and restrict recursion to trusted nets.

VERIFIED COMPETENCY MILESTONE
04
Validation & troubleshooting

Use named-checkconf, named-checkzone, rndc, journalctl and dig to confirm correct configuration and to diagnose failures like stale serials or blocked ports.

VERIFIED COMPETENCY MILESTONE
