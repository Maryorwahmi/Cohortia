Sample options (readable code)
options {
    directory "/var/named"; // Or /var/cache/bind on Debian
    allow-query { any; };
    listen-on port 53 { any; };
    recursion yes;
    allow-recursion { 127.0.0.1; 192.168.10.0/24; };
    forwarders { 8.8.8.8; 8.8.4.4; };
};
This block sets runtime behavior. Notice allow-recursion limits who can use recursive queries. Forwarders are optional for non-authoritative queries.
Practical advice & common mistakes
  • Validate with named-checkconf to avoid syntax errors.
  • Don’t allow recursion to the public internet on authoritative servers.
  • Prefer ACL names for clarity: acl "trusted" { 192.168.10.0/24; 127.0.0.1; }.
  • Use rndc reload <zone> to reload a single zone after changes.
Check before reload
Run named-checkconf; if a zone is changed, run named-checkzone <zone> <file> before rndc reload.
