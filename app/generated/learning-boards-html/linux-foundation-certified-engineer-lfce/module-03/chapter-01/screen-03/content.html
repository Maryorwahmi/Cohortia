Operational objectives

These objectives pair configuration steps with verification commands so you can demonstrate working DNS services.

05
Configure slave zones and masters block so transfers work reliably. Verify with dig axfr and log entries after the slave requests transfer.
VERIFIED COMPETENCY MILESTONE
06
Maintain SOA serial discipline: increment serials after edits and reload the zone with rndc so slaves detect changes. Stale serials are a common cause of propagation failure.
VERIFIED COMPETENCY MILESTONE
07
Check DNSSEC presence with dig +dnssec and understand the concept of KSK and ZSK as signature keys which authenticate DNS responses when implemented.
VERIFIED COMPETENCY MILESTONE
08
Practice a full lab: install bind, add zones, run named-checkconf and named-checkzone, open port 53, start named, and verify forward and reverse lookups from a client machine.
VERIFIED COMPETENCY MILESTONE
