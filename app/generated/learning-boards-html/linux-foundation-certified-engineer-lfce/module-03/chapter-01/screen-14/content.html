Common dig commands
# Query a specific server
dig @192.168.10.100 www.example.com

# Check SOA serial
dig soa example.com @192.168.10.100

# Test full zone transfer
dig axfr example.com @192.168.10.200

# Trace resolution path
dig +trace example.com
Interpret logs
Look for refused transfers, permission denied, or file parse errors in journalctl -u named when diagnosing transfer failures or syntax errors.
Firewall gotcha
Ensure both UDP and TCP port 53 are permitted; AXFR uses TCP and will fail silently if TCP is blocked.
