Module 3 › Chapter 3.1 › SOA serial workflow
Change workflow
  1. Edit the zone file and increment the SOA serial using YYYYMMDDNN.
  2. Run named-checkzone <zone> <file> to validate syntax.
  3. Reload the zone with rndc reload <zone> to publish updates.
  4. Verify slave transfer with dig axfr and check slave logs.
Example serial
Use 2023102701 → 2023102702 on the next change. This makes ordering clear and audit-friendly.
Misconception
Restarting the service without changing the serial does not trigger slaves to fetch updates. Always increment the serial for authoritative changes.
