Module 4 › Chapter 3.7 › chronyd Configuration
Server configuration example
# /etc/chrony.conf
pool 0.pool.ntp.org iburst
pool 1.pool.ntp.org iburst
allow 127.0.0.1/32
allow 192.168.70.0/24
bindcmdaddress 0.0.0.0
bindaddress 0.0.0.0
logdir /var/log/chrony
Verification commands
chronyc sources — lists upstream sources and flags.
chronyc tracking — shows offset, prediction, and stability.
ss -lnu | grep 123 — confirm chronyd listening on UDP 123.
Key Takeaway

Set allow for trusted networks and verify both sources and listening sockets to ensure service reachability.
