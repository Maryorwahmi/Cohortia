Learning Objectives
Progress from understanding to practical configuration and verification.
01
Explain the importance of synchronized time
Describe why consistent clocks matter for logs, authentication, and certificates. Being able to justify time services helps prioritize operations and audits.
VERIFIED COMPETENCY MILESTONE
02
Configure an NTP client with ntpd or chronyd
Write server or pool directives and enable the daemon. This skill ensures systems keep accurate time and validate certificates correctly.
VERIFIED COMPETENCY MILESTONE
03
Operate an internal NTP server for clients
Allow trusted networks and open UDP 123 selectively so internal clients sync to a controlled source for consistency.
VERIFIED COMPETENCY MILESTONE
04
Secure and troubleshoot NTP services
Apply restrict/allow, firewall rules, and optional authentication keys; diagnose blocked UDP 123, offsets, SELinux, and service state.
VERIFIED COMPETENCY MILESTONE
