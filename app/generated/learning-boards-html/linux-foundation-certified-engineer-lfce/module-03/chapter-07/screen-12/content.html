Module 4 › Chapter 3.7 › Security Best Practices
Network controls
Open UDP 123 only where needed: firewall-cmd --add-service=ntp --permanent; reload.
Use restrict (ntpd) or allow (chronyd) to limit client queries to trusted subnets.
Verify listening sockets with ss -lnu | grep 123.
Authentication and stratum
NTP authentication keys pair servers and clients to verify packets; configure keys and trustedkey or keyfile directives.
Use local stratum to allow internal serving when upstream sources are temporarily unavailable.
Note

Authentication requires secure key management; rotate keys and secure distribution to clients.
