Module 4 › Chapter 3.7 › ntpd Basics
Key directives
server or pool — upstream time sources.
iburst — send startup bursts for faster sync.
restrict — control client access and modification rights.
Inspecting ntpd
# Check peers and selection
ntpq -p
# Shows: remote, refid, st, when, poll, reach, delay, offset, jitter
# A '*' marks the currently selected source
Example ntp.conf snippet
# /etc/ntp.conf
server 0.pool.ntp.org iburst
server 1.pool.ntp.org iburst
restrict 127.0.0.1
restrict ::1
restrict 192.168.70.0 mask 255.255.255.0 nomodify notrap
Common Mistake

Using broad or permissive restrict rules can let untrusted hosts query or attempt to modify server behavior. Be specific.
