Module 4 › Chapter 3.7 › Hands-on: chrony Lab
Step sequence (server & client)
1. Install
sudo dnf install chrony or sudo apt install chrony
2. Configure
Edit /etc/chrony.conf: pool + allow 192.168.70.0/24 + bindaddress
3. Enable
systemctl enable --now chronyd
4. Firewall
firewall-cmd --add-service=ntp --permanent && firewall-cmd --reload
5. Client config
server 192.168.70.100 iburst and restart chronyd
6. Verify
chronyc sources; chronyc tracking; ss -lnu | grep 123
Analogy
Think of the server as the master clock in an office. Clients must be allowed to look at that clock; firewall and allow rules are the door and guest list.
Key Takeaway

Follow the sequence: install, configure, open UDP 123, enable, and verify both server and client roles.
