Diagnostic checklist
  1. Firewall: confirm UDP 123 open for required zones.
  2. Service: systemctl status ntpd|chronyd and journalctl logs.
  3. Network: ping upstream servers and check DNS resolution.
  4. Large offsets: manually correct before starting ntpd; chronyd may handle it automatically.
  5. SELinux: check audit.log and set booleans if needed.
Example commands
# Firewall check
sudo firewall-cmd --list-all
# Service check
sudo systemctl status chronyd
# Verify listening
sudo ss -lnu | grep 123
# Logs
sudo journalctl -u chronyd -n 200
Key Takeaway

Follow a consistent diagnostic order: firewall, service, network, logs, and then corrective actions.
