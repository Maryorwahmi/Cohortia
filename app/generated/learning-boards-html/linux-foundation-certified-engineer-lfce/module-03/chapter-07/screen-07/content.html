Module 4 › Chapter 3.7 › Chrony Overview
Core differences
  • Faster initial sync and better behavior on suspend/resume.
  • pool directives in /etc/chrony.conf act like server entries.
  • chronyc gives sources and tracking commands for status.
Short example
# /etc/chrony.conf
pool 0.pool.ntp.org iburst
pool 1.pool.ntp.org iburst
allow 127.0.0.1/32
allow 192.168.70.0/24
ntpserver 0.0.0.0
Pro tip

Use chronyd for VMs and laptops where network interruptions are common. It recovers quickly and keeps offsets small.
