Module 4 › Chapter 3.7 › ntpd Walkthrough
Step-by-step
  1. Edit /etc/ntp.conf and add server lines with iburst.
  2. Add restrict for localhost and the internal subnet with nomodify and notrap.
  3. Open UDP 123 in the firewall for the server role.
  4. Enable and start ntpd: systemctl enable --now ntpd.
  5. Verify with ntpq -p from server and clients.
Example config
# /etc/ntp.conf
server 0.pool.ntp.org iburst
server 1.pool.ntp.org iburst
restrict 127.0.0.1
restrict ::1
restrict 192.168.70.0 mask 255.255.255.0 nomodify notrap
Pitfall

If UDP 123 is blocked, ntpq -p will show peers but clients cannot reach the server. Confirm firewall rules and listen sockets.
