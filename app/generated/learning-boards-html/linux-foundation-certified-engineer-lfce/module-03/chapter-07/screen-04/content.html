Module 4 › Chapter 3.7 › Importance of Time
Definition and impacts
  • Logging: correlate events across hosts using timestamps.
  • Security: Kerberos and TLS rely on correct validity windows.
  • Distributed systems: timestamp-based ordering and caches depend on clocks.
  • Forensics: trustworthy event reconstruction needs stable time.
Concrete example
A fleet node set 10 minutes ahead rejects a valid TLS certificate as 'not yet valid', causing service failures. The eventual fix is to sync the clock and restart the service that caches certificate state.
Key Takeaway

Monitor clocks and automate NTP/chrony to avoid security and operational failures due to drift.
