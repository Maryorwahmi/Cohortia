Module 3 › Chapter 3.3 › Assessment Scenarios
Scenario 1 — Wrong site served
Steps: check ServerName in the suspect VirtualHost file, confirm the site is enabled, run apachectl configtest, examine vhost ordering, and verify DocumentRoot paths. The root cause is typically a missing or incorrect ServerName so Apache selects the first vhost by default.
Scenario 2 — Backend sees 127.0.0.1
Steps: inspect Nginx config for proxy_set_header X-Real-IP and X-Forwarded-For, add missing headers, reload Nginx, and verify the backend reads those headers. Without these headers the backend only sees the proxy's connection address.
Key Takeaway

Assessment questions test reading configuration, running syntax checks, and applying focused fixes such as ServerName corrections or adding proxy headers.
