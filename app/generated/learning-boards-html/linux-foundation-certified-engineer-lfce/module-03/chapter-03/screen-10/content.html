sudo tail -f /var/log/nginx/error.log
sudo tail -f /var/log/httpd/error_log
Permissions & SELinux
Set ownership so the web user reads files: sudo chown -R nginx:nginx /var/www/site. Use sudo restorecon -Rv /var/www to correct SELinux contexts and setsebool -P httpd_can_network_connect 1 for reverse proxying needs.
Firewall
Ensure ports 80 and 443 are open. Example: firewall-cmd --add-service=http --permanent; --add-service=https --permanent; then firewall-cmd --reload.
Key Takeaway

Follow a structured debug flow: syntax checks, logs, permissions/SELinux, then network and DNS. This order saves time and reduces risk of cascading changes.
