Module 3 › Chapter 3.3 › Key Concepts
DocumentRoot
Filesystem path served by the web server; ensure correct ownership and permissions.
Let's Encrypt / Certbot
Automates certificate issuance and renewal; requires reachable domain validation and open ports.
proxy_pass & headers
Use proxy_pass to forward requests and set X-Real-IP/X-Forwarded-For so backends receive original client info.
Final takeaway: verify DNS and firewall, validate configs, protect certificates through automation, and forward client headers when proxying to keep logs and behavior correct.
