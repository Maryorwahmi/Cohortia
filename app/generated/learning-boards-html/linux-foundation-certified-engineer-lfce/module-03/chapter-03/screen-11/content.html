Module 3 › Chapter 3.3 › Lab Checklist
Step-by-step
  1. Install Nginx and Node.js with your package manager.
  2. Create document roots: mkdir -p /var/www/static.example.com/html and /var/www/app.example.com/html.
  3. Add index.html for the static site and place app.js for the Node app; run node app.js &.
  4. Create server blocks for both sites and include proxy_set_header for the proxied app.
  5. Run nginx -t and systemctl reload nginx; fix errors found in logs.
  6. Install certbot with the nginx plugin and run certbot --nginx -d static.example.com -d app.example.com.
  7. Verify renewal with sudo certbot renew --dry-run and confirm a timer or cron exists.
Verification
Use curl -I https://static.example.com and https://app.example.com to confirm HTTPS and redirects. Check certificate paths under /etc/letsencrypt/live.
Key Takeaway

A reproducible checklist reduces unexpected failures: install, configure, validate, secure, and verify renewals.
