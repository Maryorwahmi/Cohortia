Apache HTTP Server
A flexible, modular web server used when per-directory control and legacy modules are required.
Nginx
High-performance server ideal for static content, TLS termination, and reverse proxying to backends.
Virtual Host / Server Block
Configuration that allows one server to respond for multiple domain names on the same IP and port.
