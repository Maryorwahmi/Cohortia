Module 3 › Chapter 3.3 › Lab Objectives
01
Syntax checks and safe reloads

Use nginx -t and apachectl configtest before reloading. These checks avoid service interruption from bad configuration changes.

VERIFIED COMPETENCY MILESTONE
02
Permissions, ownership, SELinux

Ensure web users can read DocumentRoot and write logs. Use chown, chmod, and restorecon; setsebool may be required for network connects on RHEL/CentOS.

VERIFIED COMPETENCY MILESTONE
03
DNS and firewall verification

Confirm A records point to your server and ports 80/443 are open; certbot fails if domain validation cannot reach the server.

VERIFIED COMPETENCY MILESTONE
04
Complete lab: static + proxy + HTTPS

Deploy a static site and a proxied app, run certbot --nginx to enable HTTPS for both, and confirm HTTP redirects to HTTPS.
