Safe load sequence
  1. Save /etc/nftables.conf with desired rules.
  2. Run sudo nft -f /etc/nftables.conf to apply changes.
  3. Verify with sudo nft list ruleset.
  4. Monitor real-time events with sudo nft monitor.
  5. Persist with sudo systemctl enable --now nftables once verified.
Troubleshooting commands
sudo nft list ruleset — view active kernel ruleset.
sudo nft monitor — watch matches and events in real time.
journalctl -u nftables — review service load errors.
Common Mistake

Running flush ruleset without a fallback can remove all protections. Keep a recovery path and test incrementally.
