DNAT example (prerouting)
table ip nat {
  chain prerouting {
    type nat hook prerouting priority -100;
    iifname "eth0" tcp dport 22 dnat to 192.168.1.100:22
  }

  chain postrouting {
    type nat hook postrouting priority 100;
    oifname "eth0" ip saddr 192.168.60.0/24 masquerade
  }
}
Prerouting changes destination before routing; postrouting alters source after routing to allow reply packets to reach the internet.
Verification checklist
  • From outside, attempt to reach public IP on forwarded port and confirm internal server responds.
  • On internal client, ping or browse internet to ensure masquerade allows egress.
  • Use sudo nft monitor to observe translation events in real time.
Key Takeaway

Place DNAT in prerouting and SNAT/masquerade in postrouting; verify both translation directions during testing.
