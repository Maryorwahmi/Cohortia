Module 3 › Chapter 3.6 › nftables vs iptables
Key differences and benefits
  • Single utility and syntax for multiple families (use inet to cover IPv4 and IPv6).
  • Sets and maps replace long repetitive rule lists and improve match performance.
  • Kernel-level bytecode evaluation reduces rule processing overhead.
  • Unified ruleset management simplifies persistence and inspection.
Concrete example
Group SSH clients into a set instead of writing multiple allow rules; one membership check matches all clients.
Common misconception

Treating nftables as a drop-in for iptables misses its strengths. Look for opportunities to replace long rule lists with sets and maps for clarity and speed.

Key Takeaway

Use nftables to centralize firewall logic across families and replace repetitive rules with sets and maps for better performance.
