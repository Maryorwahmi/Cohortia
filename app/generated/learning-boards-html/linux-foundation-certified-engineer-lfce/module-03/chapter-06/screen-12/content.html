Module 3 › Chapter 3.6 › Troubleshooting
Mistake
Rule placed too early that drops traffic.
Fix: Reorder rules and place ct state and service allows before drop.
Mistake
Switching to policy drop without tests.
Fix: Start policy accept, test, then change to drop after verification.
Mistake
Flushing ruleset on production.
Fix: Avoid flush ruleset; if used, have console access and an immediate recovery plan.
Mistake
Wrong interface names in rules.
Fix: Verify with ip link and update iifname/oifname values accordingly.
Useful commands
sudo nft list ruleset, sudo nft monitor, journalctl -u nftables
Practice tip
Intentionally misorder a rule set, observe failure, and then fix it while documenting the recovery steps.
