Safe practice

Start with policy accept for testing, confirm services, then swap to drop. Use console access or an out-of-band method as a safety net.

Connection tracking

Include ct state {established, related} accept early so replies and established sessions are not blocked accidentally.

Commands to know
sudo nft -f /etc/nftables.conf to load, sudo nft list ruleset to inspect, sudo systemctl enable --now nftables for persistence.
Quick checklist
  • Allow loopback and ct state first
  • Allow SSH before enabling drop policy
  • Verify DNAT and SNAT flows
