01
Explain nftables architecture

Describe tables, chains, hooks and how a unified 'nft' utility replaces multiple legacy tools. This helps you choose correct families and hooks when designing rules.

Mnemonic: single toolkit = one control plane
VERIFIED COMPETENCY MILESTONE
02
Author rulesets and load them

Create inet and ip tables, add chains and rules, then load with nft -f and enable nftables service for persistence. This ensures consistent policy on reboot.

Mnemonic: write, load, persist
VERIFIED COMPETENCY MILESTONE
03
Use sets and maps

Group addresses and map ports to verdicts to reduce rule duplication and increase lookup performance. This is essential for scalable rule management.

Mnemonic: group once, reference many
VERIFIED COMPETENCY MILESTONE
04
Implement NAT and troubleshoot

Configure prerouting DNAT for port forwarding and postrouting SNAT/masquerade for internet access, and use nft monitor and logs to debug issues.

Mnemonic: preroute = destination, postroute = source
VERIFIED COMPETENCY MILESTONE
Assessment tip

You will be asked to write a ruleset, load it, verify traffic matches, and fix a misordered rule that blocks legitimate traffic.
