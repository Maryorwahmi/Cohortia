Server setup checklist
  • Create /etc/sysctl.d/99-ip-forward.conf and set net.ipv4.ip_forward = 1, then sudo sysctl -p.
  • Assume eth0 = external, eth1 = internal (192.168.60.1).
  • Write /etc/nftables.conf with inet filter (policy drop) and ip nat tables.
  • Load with sudo nft -f and persist with sudo systemctl enable --now nftables.
Client and verification
Set internal client gateway to 192.168.60.1 and run a web server on port 80.
From outside, curl http://firewall_public_ip:8080 to test DNAT to 192.168.60.100:80.
From internal client, ping 8.8.8.8 or browse to verify SNAT/masquerade allows egress.
Use sudo nft monitor to watch translation events live.
Reminder

Add forward rule iifname "eth1" oifname "eth0" accept so internal to external forwarding is permitted before drop policy takes effect.
