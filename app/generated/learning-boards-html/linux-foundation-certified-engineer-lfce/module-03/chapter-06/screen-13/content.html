Module 3 › Chapter 3.6 › Hands-on Challenge
Challenge steps
  1. Create /etc/nftables.conf with inet filter allowing loopback, ct state, SSH, HTTP, HTTPS and forward rule for eth1→eth0.
  2. Add ip nat table with prerouting DNAT for public port 8080 to 192.168.60.100:80 and postrouting masquerade for 192.168.60.0/24 on eth0.
  3. Load with sudo nft -f and persist with sudo systemctl enable --now nftables.
  4. Verify: ssh to firewall, curl public_ip:8080 to reach internal web server, and test internal client internet access.
After completing, document commands run and the outputs of nft list ruleset and nft monitor used during verification.
Pro Tip

When scaling, move port lists into named sets or maps to simplify updates and reduce the number of kernel checks.
