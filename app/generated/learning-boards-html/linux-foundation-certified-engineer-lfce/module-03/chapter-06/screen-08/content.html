Map example (vmap usage)
map port_actions {
  type inet_service : verdict;
  elements = {
    22 : accept,
    80 : accept,
    443 : accept
  }
}

# inside chain
tcp dport vmap @port_actions
Once defined, vmap consults the map and executes the matching verdict for a given port, avoiding multiple rules.
Anonymous set example
# inline list
tcp dport { 22, 80, 443 } accept
Good for small, static lists. If you expand the list frequently, move it to a named set for easier updates.
Check

After loading a map, test access to included ports from a client and confirm excluded ports are dropped by policy.
