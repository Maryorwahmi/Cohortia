Set example
set ssh_clients {
  type ipv4_addr;
  flags constant;
  elements = { 192.168.1.10, 192.168.1.20 }
}

# usage inside a chain
tcp dport 22 ip saddr @ssh_clients accept
This defines a named set you can reference by @ssh_clients, reducing repeated per-IP rules.
Map and anonymous set
map port_actions {
  type inet_service : verdict;
  elements = {
    22 : accept,
    80 : accept,
    443 : accept
  }
}

# anonymous set example
tcp dport { 22, 80, 443 } accept
Maps let you associate a key to an action so one rule can vmap ports to verdicts. Anonymous sets are quick inline lists for small groups.
Key Takeaway

Choose named sets for reuse and maps for key→action relationships; use anonymous sets for concise inline rules.
