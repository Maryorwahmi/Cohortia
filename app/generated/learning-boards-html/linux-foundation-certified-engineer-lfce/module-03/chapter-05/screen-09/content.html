Module 3 › Chapter 3.5 › Relay control
Trusted networks (mynetworks)
List specific IP ranges allowed to relay without authentication. Typical entries include loopback and internal subnets. Example: 127.0.0.0/8 and 192.168.50.0/24.
Benefit: simple for internal hosts. Risk: if misconfigured, it opens your server to being an open relay.
SMTP authentication
Require clients to authenticate before relaying, typically on port 587. Use SASL (with Dovecot or another provider) to validate credentials and allow relay only for authenticated users.
Benefit: safer for mixed networks and remote users. Requires additional configuration.
