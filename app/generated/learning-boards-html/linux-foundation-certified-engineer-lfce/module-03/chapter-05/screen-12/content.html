Live diagnostics
# Watch Postfix logs
sudo tail -f /var/log/mail.log

# Check Dovecot via systemd journal
sudo journalctl -u dovecot -f

# View mail queue
mailq
Common log messages
  • Relay access denied — check mynetworks and SMTP auth.
  • Illegal user or authentication failure — check Dovecot logs and user accounts.
  • Permission denied writing to mailbox — check file ownership and SELinux contexts.
