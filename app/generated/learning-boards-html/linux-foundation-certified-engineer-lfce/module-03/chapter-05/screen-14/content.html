MTA vs MDA
Postfix handles transport; Dovecot handles delivery and client access.
Maildir alignment
Set home_mailbox and mail_location to Maildir so both services use the same mailbox format.
TLS for clients
Configure certificates for Postfix and Dovecot to encrypt client connections and protect credentials.
Summary
A reliable mail server demands correct configuration, matched mailbox formats, secure TLS, strict relay policy, and methodical verification with logs and mailbox checks.
