Learning Objectives
Progression: Learn → Understand → Apply → Master
01
Identify MTA vs MDA

Explain the responsibilities of Postfix (relaying) vs Dovecot (delivery and IMAP/POP3). This helps you design where messages are handled and stored.

VERIFIED COMPETENCY MILESTONE
02
Configure Postfix basics

Set myhostname, mydomain, mydestination, mynetworks and mailbox format so Postfix sends and accepts mail correctly for your domain.

VERIFIED COMPETENCY MILESTONE
03
Configure Dovecot for IMAP/POP3

Enable IMAP/POP3, set mail_location to Maildir, and configure authentication so clients can retrieve mail.

VERIFIED COMPETENCY MILESTONE
04
Secure and troubleshoot

Implement TLS certificates, open necessary ports, verify MX/A records, and read mail logs to resolve common failures.

VERIFIED COMPETENCY MILESTONE
