Postfix & Dovecot: deliver and retrieve mail securely

In this lesson you'll see the pieces for a minimal, working mail server: Postfix as the MTA, Dovecot as the MDA and IMAP/POP provider, mailbox format alignment, TLS, firewall and DNS considerations.

In this lesson
Set up Postfix and Dovecot for local delivery, create self-signed TLS keys, verify mail delivery, and inspect logs for troubleshooting.
Coming up
