Common services and ports
  • SMTP: 25
  • Submission: 587
  • SMTPS: 465
  • IMAP: 143 / IMAPS: 993
  • POP3: 110 / POP3S: 995
Example firewall commands
sudo firewall-cmd --add-service=smtp --add-service=imaps --add-service=submission --permanent
sudo firewall-cmd --reload

# Verify from a client
telnet mail.example.com 993
If telnet fails, the issue is likely network-level even if Postfix and Dovecot are running.
