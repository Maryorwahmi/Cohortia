Step-by-step checklist
  1. Install Postfix and Dovecot packages and enable both services.
  2. Create a test user and ensure a Maildir exists in the home directory.
  3. Edit /etc/postfix/main.cf: set myhostname, mydomain, mydestination, mynetworks, home_mailbox=Maildir/.
  4. Edit Dovecot to match mail_location=maildir:~/Maildir and enable IMAP/POP3.
  5. Generate TLS certs, copy to Postfix and Dovecot paths, and set permissions to 600 for keys.
  6. Open firewall ports for SMTP, submission, and IMAPS and reload firewall rules.
  7. Restart services, send a local test mail, and verify Maildir delivery. Then configure an IMAP client and confirm retrieval over TLS.
Key Takeaway

Follow a consistent checklist and verify each step by observing logs and mailbox files; this prevents small misconfigurations from masking as service failures.
