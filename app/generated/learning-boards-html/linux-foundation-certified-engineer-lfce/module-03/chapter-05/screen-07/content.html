Module 3 › Chapter 3.5 › Generating TLS certificates
Create a self-signed cert (example)
sudo openssl req -x509 -nodes -days 365 -newkey rsa:2048 \
  -keyout /etc/pki/tls/private/mailserver.key \
  -out /etc/pki/tls/certs/mailserver.crt \
  -subj "/CN=mail.example.com"

sudo cp /etc/pki/tls/certs/mailserver.crt /etc/postfix/postfix.pem
sudo cp /etc/pki/tls/private/mailserver.key /etc/postfix/postfix.key
sudo cp /etc/pki/tls/certs/mailserver.crt /etc/dovecot/dovecot.pem
sudo cp /etc/pki/tls/private/mailserver.key /etc/dovecot/dovecot.key
sudo chmod 600 /etc/postfix/postfix.key /etc/dovecot/dovecot.key
Service configuration pointers
  • Postfix: set smtpd_tls_cert_file and smtpd_tls_key_file and choose a security level.
  • Dovecot: set ssl_cert and ssl_key and consider ssl = required for clients.
  • Protect private keys with 600 permissions and correct ownership so services can read them.
Verification: connect an IMAP client to port 993 and inspect the certificate thumbprint. If hostname mismatches occur, the client will warn and the connection may fail for strict TLS settings.
