Module 3 › Chapter 3.5 › Testing mail flow
Local send and verification
# Send a local test message
echo "Hello from Postfix" | mail -s "Test Subject" testuser@example.com

# Check Maildir for delivery
ls -l /home/testuser/Maildir/new/

# Watch mail logs
sudo tail -f /var/log/mail.log
Troubleshooting hints
  • If Maildir is empty, verify home_mailbox and mail_location alignment.
  • Check permissions on the user home and Maildir directories.
  • Look for delivery errors in the mail log that explain rejects or permission failures.
Common Mistake

Sending mail from root without proper HOME or MAIL environment can place mail somewhere unexpected. Use a test user account.
