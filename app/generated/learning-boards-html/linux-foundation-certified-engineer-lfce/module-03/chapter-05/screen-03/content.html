Module 3 › Chapter 3.5 › Learning Objectives — Practical Outcomes
Objective Checklist
  • Install Postfix and Dovecot packages and start their services.
  • Create a test user and confirm Maildir delivery after sending a message from the server.
  • Generate or obtain TLS certificates and configure both Postfix and Dovecot to use them.
  • Open SMTP and IMAP ports in the server firewall and verify connectivity from a client.
Verification Mnemonic
Install → Configure → Secure → Verify. Each step has a file to edit and a command to run for proof: edit main.cf/dovecot.conf, restart services, test send, and check logs.
