Module 3 › Chapter 3.5 › DNS and MX records
MX and A relationship

An MX record points to a hostname; that hostname must resolve to an IP via an A record so other servers can open an SMTP connection.

Example: MX 10 mail.example.com. Then ensure mail IN A 192.168.50.100 exists in DNS for direct resolution.
Troubleshooting DNS
  • Use dig MX example.com and dig A mail.example.com to verify records.
  • If MX points to a host without an A record, mail cannot be delivered.
  • Allow DNS propagation time after changes before retrying.
