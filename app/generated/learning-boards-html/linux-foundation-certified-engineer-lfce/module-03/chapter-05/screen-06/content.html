Essential Dovecot values
  • protocols — which services to offer, e.g. imap pop3 lmtp.
  • mail_location — e.g. maildir:~/Maildir to match Postfix Maildir delivery.
  • listen — set to * to accept connections on all server interfaces.
  • auth_mechanisms — methods such as plain login; disable plaintext unless TLS is used.
Example configuration
# /etc/dovecot/dovecot.conf (or conf.d includes)
protocols = imap pop3
listen = *
mail_location = maildir:~/Maildir
disable_plaintext_auth = no  # set to yes when TLS is enforced
auth_mechanisms = plain login

# SSL/TLS
ssl = required
ssl_cert = <
        
Restart Dovecot after edits. If clients cannot authenticate, check logs and confirm the test user and Maildir exist with correct permissions.
