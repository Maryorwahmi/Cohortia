Module 3 › Chapter 3.2 › Key Concepts
dhcpd.conf
Global options, subnet declarations, ranges and host reservations centrally control addressing and options.
Relay Agents
Relays forward client broadcasts as unicast to a DHCP server so a single server can serve multiple subnets.
Diagnostics & Security
Use dhcpd.leases and logs for troubleshooting, and employ firewall rules, file perms and DHCP snooping to mitigate risks.
Summary
Keep configuration clear, use relays to scale across networks, and combine logs with layered protections for resilient DHCP services.
