What DHCP tells PXE clients
DHCP provides pointers: filename indicates the boot file; next-server is the TFTP server IP. Both must be reachable for PXE to succeed.
Example
In the subnet block include: filename "pxelinux.0"; next-server 192.168.20.50; so clients learn the TFTP server and boot file during DHCP Offer.
Misconception
DHCP only points to TFTP. The TFTP server must be configured and accessible for the client to fetch the boot file.
Checklist for PXE
  • Set filename and next-server in dhcpd.conf
  • Ensure TFTP server is reachable and serves the file
  • Open TFTP and DHCP ports in firewall
Troubleshoot
If PXE fails, inspect DHCP Offers for filename/next-server and test TFTP access from a host on the same network segment.
Key Takeaway

DHCP supplies pointers for PXE; coordinate DHCP options with a functioning TFTP server to enable network booting.
