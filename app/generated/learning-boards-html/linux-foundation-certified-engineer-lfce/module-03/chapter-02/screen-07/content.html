Module 3 › Chapter 3.2 › Static Reservations
Host reservation example
host myprinter {
    hardware ethernet AA:BB:CC:DD:EE:FF;    # REPLACE with actual MAC
    fixed-address 192.168.30.201;
}
Save and restart dhcpd so the reservation takes effect, then trigger a client renewal to get the fixed address.
When to reserve
  • Servers and management interfaces
  • Network printers and NAS devices
  • PXE/TFTP servers that clients must reach reliably
Avoid this mistake
Do not place fixed-address entries inside the dynamic range. Instead move the reservation outside the range or shrink the range.
Key Takeaway

Reservations centralize stable addressing via DHCP; they still participate in the lease flow but always receive the configured fixed-address.
