Server steps (example commands)
Follow these terminal actions as a checklist. Replace interface and IP values with your environment specifics.
# Install (RHEL/CentOS)
sudo dnf install dhcp-server
# or Debian/Ubuntu
sudo apt install isc-dhcp-server

# Edit /etc/dhcp/dhcpd.conf and add subnet + reservation

# Set interface
# Debian: /etc/default/isc-dhcp-server
INTERFACESv4="eth0"

# Start and enable
sudo systemctl enable --now dhcpd
# Watch logs
sudo journalctl -u dhcpd -f
Relay steps
Install dhcrelay or isc-dhcp-relay and configure to listen on the client-facing interface and forward to the DHCP server IP.
# Runtime example
sudo dhcrelay -i eth0 192.168.30.100

# Debian config: /etc/default/isc-dhcp-relay
INTERFACESv4="eth0"
SERVERS="192.168.30.100"
Verification
  • On client: sudo dhclient -v to request a lease and watch DORA
  • Confirm dhcpd.leases on server has the client MAC and IP
  • Change client MAC to reserved MAC and renew — confirm fixed-address assignment
