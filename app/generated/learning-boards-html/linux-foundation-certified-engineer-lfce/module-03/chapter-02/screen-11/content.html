Module 3 › Chapter 3.2 › DHCP Security
Server hardening
  • Protect /etc/dhcp/dhcpd.conf and the lease file with restrictive permissions.
  • Limit which hosts can reach the DHCP service via firewall rules.
  • Audit changes to dhcpd.conf and the lease file regularly.
Switch-level controls
  • Enable DHCP snooping to mark trusted ports and filter server Offers from untrusted ports.
  • Use port security to lock ports to expected MAC addresses for critical devices.
  • Combine switch features with server-side controls for layered defense.
Misconception

File permissions alone do not stop rogue servers on the network; use switch-level features to reject unauthorized DHCP Offers.
