Module 3 › Chapter 3.2 › Learning Objectives
01
Configure dhcpd.conf
Define global options, subnets, ranges and lease times so clients receive complete network configuration.
Mnemonic: layered file → global → subnet → range
Verified Competency Milestone
02
Create static reservations
Use host blocks tied to MAC addresses to guarantee consistent IPs for printers, servers, and infrastructure devices.
Mnemonic: MAC → host block → fixed-address
Verified Competency Milestone
03
Enable PXE boot options
Set filename and next-server so network clients can discover a TFTP server and boot installer images.
Mnemonic: boot file + TFTP IP
Verified Competency Milestone
04
Bind service to interface and start
Specify INTERFACES or DHCPDARGS, enable the dhcpd systemd service, and confirm listening using systemctl or journalctl.
Mnemonic: interface → start → verify
Verified Competency Milestone
