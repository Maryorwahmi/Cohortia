Module 3 › Chapter 3.2 › Troubleshooting
Server-side artifacts
  • dhcpd.leases: current and historical lease entries; check MAC, IP, and timestamps.
  • journalctl -u dhcpd: runtime errors, binding problems, and option parsing messages.
  • /var/log/messages or syslog: additional DHCP server messages on some distros.
Client-side checks
On the client, use dhclient -v to observe Discover/Offer/Request/Ack. Use ip a to confirm the assigned address and route table. For conflicts, look for duplicate-address warnings and verify that no static IP lives inside the DHCP range.
Quick diagnostic

If a client gets no IP, check relay logs, server logs, firewall rules and confirm the server is bound to the correct interface.
