Configure interface
Debian/Ubuntu: edit /etc/default/isc-dhcp-server and set INTERFACESv4="eth0". RHEL/CentOS: edit /etc/sysconfig/dhcpd and set DHCPDARGS="eth0".
Operational checklist
  • Save config and restart the service: sudo systemctl restart dhcpd
  • Enable at boot: sudo systemctl enable --now dhcpd
  • Inspect logs: sudo journalctl -u dhcpd -f
  • Verify client: on client run sudo dhclient -v or check network manager logs
Firewall & ports
DHCP uses UDP 67 for server and UDP 68 for clients. With firewalld, run:
sudo firewall-cmd --add-service=dhcp --permanent
sudo firewall-cmd --reload
Common mistake

The service may appear active but not serve clients if INTERFACES is blank or firewall blocks UDP 67/68; always check both.

Key Takeaway

Binding to the correct interface and allowing UDP 67/68 are essential operational steps before client verification.
