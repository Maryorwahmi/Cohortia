Module 3 › Chapter 3.2 › Learning Objectives
05
Configure DHCP relay agents
Set dhcrelay or isc-dhcp-relay to listen on the client-facing interface and forward to the central server IP.
Mnemonic: listen → forward → server
Verified Competency Milestone
06
Troubleshoot leases and logs
Use dhcpd.leases, journalctl -u dhcpd and client dhclient output to find lease issues and conflicts.
Mnemonic: lease file → server logs → client output
Verified Competency Milestone
07
Secure DHCP services
Open only required UDP ports, protect config and lease files, and use switch DHCP snooping and port security where available.
Mnemonic: firewall + file perms + switch features
Verified Competency Milestone
08
Identify common misconfigurations
Detect overlapping ranges, wrong netmasks, or multiple servers on a segment and learn corrective steps.
Mnemonic: ranges → masks → servers
Verified Competency Milestone
