Relay configuration examples
RHEL/CentOS: set /etc/sysconfig/dhcrelay DHCP server IP(s) and interface. Debian/Ubuntu: edit /etc/default/isc-dhcp-relay with INTERFACESv4 and SERVERS.
# Example runtime command
sudo dhcrelay -i eth0 192.168.30.100

# Debian config snippet
INTERFACESv4="eth0"
SERVERS="192.168.30.100"
Verification steps
  • Tail journalctl on the relay: discover messages should be logged.
  • Check server logs for the forwarded request and subsequent Offer.
  • Confirm client received a lease from the server's range.
Watch out
If you see no Offers at the server, verify relay is listening on the correct interface and that network ACLs allow traffic to the server.
Key Takeaway

Relays forward client broadcasts as unicast to servers; confirm interface, server IP, and firewall rules to ensure proper forwarding.
