Learn the config file patterns, reservations, PXE boot options, and relay techniques that let one server service many networks.

Explore Key Topics
What you'll see
dhcpd.conf
Global options, subnet declarations, ranges and host reservations control addressing.
PXE Boot
Use filename and next-server to point clients to a TFTP server for network boot.
Relay Agents
Relay agents forward broadcasts to a central DHCP server so multiple subnets can be served.
Terminal-first lab
Follow configuration examples and verification commands step-by-step.
Preview: dhcpd.conf snippet
ddns-update-style interim;
ignore client-updates;
default-lease-time 600;
max-lease-time 7200;

option domain-name "example.com";
option domain-name-servers 192.168.20.10, 8.8.8.8;

subnet 192.168.20.0 netmask 255.255.255.0 {
  range 192.168.20.100 192.168.20.199;
  option routers 192.168.20.1;
}
Key Takeaway

A single well-configured ISC DHCP server can provide dynamic addressing, static reservations, and PXE boot options for multiple subnets when combined with relay agents.
