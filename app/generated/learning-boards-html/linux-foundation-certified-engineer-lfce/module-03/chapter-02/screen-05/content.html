Example dhcpd.conf
This snippet demonstrates global options, a subnet block, and a host reservation used in many labs and production setups.
# /etc/dhcp/dhcpd.conf
ddns-update-style interim;
ignore client-updates;
default-lease-time 600;
max-lease-time 7200;

option domain-name "example.com";
option domain-name-servers 192.168.20.10, 8.8.8.8;
option ntp-servers 192.168.20.10;

subnet 192.168.20.0 netmask 255.255.255.0 {
    range 192.168.20.100 192.168.20.199;
    option routers 192.168.20.1;
    option broadcast-address 192.168.20.255;
    # filename "pxelinux.0";
    # next-server 192.168.20.50;
}

host webserver {
    hardware ethernet 00:11:22:33:44:55;
    fixed-address 192.168.20.200;
}
Explainer
  • default-lease-time and max-lease-time control how long clients keep an address by default.
  • option domain-name-servers lists resolvers clients receive; include local and public DNS as needed.
  • Keep host reservations (fixed-address) outside the dynamic range to avoid accidental conflicts.
Example scenario
If a PXE server at 192.168.20.50 provides installers, uncomment filename and next-server so clients learn the boot file and TFTP server IP during the Offer step.
Key Takeaway

dhcpd.conf is layered: globals set defaults and subnet blocks define concrete address assignments and options for each network.
