Module 8 › Chapter 8.2 › Install & Enable
Process

Install packages and start libvirtd

Run the package installation, enable the libvirt daemon, and add your user to the libvirt group. This readies the host to create and manage virtual machines.

sudo dnf install qemu-kvm libvirt-daemon-kvm libvirt-client virt-install virt-viewer -y
sudo systemctl enable --now libvirtd
sudo usermod -aG libvirt $(whoami)
newgrp libvirt
Check
Run virsh list --all. If libvirt is active, virsh will return a list or an empty set rather than a connection error.
Common mistake
Skipping newgrp or relogin leaves you without libvirt group privileges and may cause permission errors when running virsh.
Key Takeaway

Install the packages, ensure libvirtd is running, and add your user to libvirt to allow secure, non-sudo VM management.

Why this matters

A running libvirtd daemon is the host-side control plane for VM lifecycle operations. Without the correct packages and a running daemon, VM creation and management commands will fail.

Example
After installing, enabling libvirtd and adding your user, run virsh list --all to confirm connectivity. If you see an error, check sudo journalctl -u libvirtd for hints.
Misconception
Installing packages alone is not enough; forgetting to enable the daemon is the most frequent reason for "connection refused" errors when using virsh.
