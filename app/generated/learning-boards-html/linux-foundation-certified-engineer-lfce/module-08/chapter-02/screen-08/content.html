Process

Common virsh commands

virsh list --all
virsh start my-web-server
virsh shutdown my-web-server
virsh destroy my-web-server   # force off
virsh reboot my-web-server
virsh suspend my-web-server
virsh resume my-web-server
virsh undefine my-web-server
When to use destroy
Only when shutdown fails and you need an immediate power-off. It can cause guest data loss.
Undefine behavior
Undefine removes the VM definition but does not delete disk images by default; this lets you preserve disks for analysis or reuse.
Concrete example

If app-server becomes unresponsive, run virsh destroy app-server to power it off, then run virsh undefine app-server to remove its libvirt entry while keeping the disk image for later analysis.

Common mistake

Do not assume destroy deletes files. Always inspect disk paths before deleting images to avoid data loss.
