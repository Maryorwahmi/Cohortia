Activity Steps

Create and manage a basic VM

1. Install
Install packages, enable libvirtd, add your user to libvirt, and newgrp libvirt to apply the group change.
2. Download ISO
Place a minimal ISO in /var/lib/libvirt/boot for quick installs.
3. Create VM
Run virt-install with explicit --name, --ram, --vcpus, --disk, --network, and --location options; include --noautoconsole.
4. Connect and install
Use virt-viewer or virsh console to complete the OS installation and then shut down from inside the guest.
5. Manage and clean up
Practice start, shutdown, destroy, and undefine, then remove the disk image only after confirming paths with virsh dumpxml.
Commands to try
virsh list --all
virsh start mytestvm
virsh shutdown mytestvm
virsh undefine mytestvm
sudo rm /var/lib/libvirt/images/mytestvm.qcow2
Key Takeaway

Follow the sequence and verify each step with virsh list and virsh dumpxml; backups before removal are essential.
