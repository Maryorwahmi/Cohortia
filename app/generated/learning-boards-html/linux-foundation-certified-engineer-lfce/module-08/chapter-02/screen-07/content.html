Code Walkthrough

Sample virt-install command

sudo virt-install \
--name my-web-server \
--ram 2048 \
--vcpus 2 \
--disk path=/var/lib/libvirt/images/my-web-server.qcow2,size=20,format=qcow2 \
--os-variant rhel8.0 \
--network bridge=virbr0 \
--graphics vnc,listen=0.0.0.0 \
--location /path/to/rhel-8.iso \
--extra-args "console=ttyS0,115200n8 serial" \
--noautoconsole
What to change for tests
Adjust --ram and --vcpus for different workloads, change disk path for LVM-backed storage, or switch --graphics to spice if needed.
Troubleshoot
If installation fails, check that the ISO path is correct and inspect journalctl -u libvirtd for registration errors.
Concrete scenario

Use this command to create a test web server. After install, shut down the VM from within the guest and start it with virsh start my-web-server for lifecycle testing.

Key Takeaway

Use the sample command as a template and modify RAM, vCPUs, disk path, and network to match your environment and automation scripts.
