Module 8 › Chapter 8.2 › Connect to VMs
Definition & Example

virt-viewer and virsh console

Choose virt-viewer for graphical installations and virsh console for headless servers. Configure the serial console during installation for reliable access.

virt-viewer my-web-server
# For serial console, include during install:
--extra-args "console=ttyS0,115200n8 serial"
# Then connect:
virsh console mytestvm
When to use console
Use virsh console for servers without a GUI, for early-boot kernel logs, and when network-based display is not available.
Misconception
Assuming virt-viewer will always succeed. If graphics are not enabled or network policies block VNC, use the serial console instead.
Practical tip

When creating production server images, enable a serial console in the kernel command line so you always have a fallback method to connect for recovery or automation.

Key Takeaway

Plan for console access: configure serial during install and use virt-viewer for graphical needs; this prevents being locked out of VMs.
