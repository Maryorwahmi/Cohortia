Install and configure KVM/QEMU

Install packages like qemu-kvm and libvirt, enable libvirtd, and add your user to the libvirt group so you can manage VMs without sudo.

VERIFIED COMPETENCY MILESTONE
02
Create VMs with virt-install

Define CPU, RAM, disk, and network from the CLI so VM creation is repeatable and automatable across hosts.

VERIFIED COMPETENCY MILESTONE
03
Manage lifecycle with virsh

Use virsh list, start, shutdown, destroy, suspend and undefine to operate VM state and definitions safely.

VERIFIED COMPETENCY MILESTONE
04
Connect and troubleshoot

Connect with virt-viewer or virsh console and use journalctl and virsh dumpxml to diagnose failures and misconfigurations.

VERIFIED COMPETENCY MILESTONE

Mnemonic

Remember: Install, Define, Operate, Connect — IDOC. Each step maps to a tool: install packages and enable libvirtd, define with virt-install, operate with virsh, and connect with virt-viewer or console.
Milestone

Complete a reproducible virt-install creation and perform start, shutdown, and undefine without losing the disk image.
