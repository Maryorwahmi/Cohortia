Objectives

Hands-on VM creation and access

Work through a complete virt-install command using an ISO or network tree, and confirm the VM boots. Practice opening virt-viewer and using virsh console to complete the installation or perform console-based troubleshooting when no graphical path is available.

Why this matters

Being able to create and access VMs without a GUI is essential for servers, automation, and reproducible labs used in certification exams.

Misconception

Don't assume a VM failing to boot is the guest OS: often it's a wrong ISO path, missing serial console args, or a disabled libvirtd service on the host.

Quick mnemonic
ISO path, libvirtd, bridge, console — verify each of these when a VM won't start.
Try this

After creating a VM, run virsh list --all and then virsh dumpxml to confirm the disk and network settings match your intent.
