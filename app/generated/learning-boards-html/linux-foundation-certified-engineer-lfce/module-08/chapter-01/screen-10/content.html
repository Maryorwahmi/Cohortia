VM components
vCPU: virtual processors scheduled by the hypervisor.
vMemory: mapped pages handled by the hypervisor and guest OS.
vDisk: virtual disks backed by files, LVM, or raw block devices.
vNIC: virtual network interfaces attached to bridges or switches.
Key Takeaway

Treat VMs like real servers: manage updates, backups, and monitoring for each instance.

Example: Snapshot and clone
Snapshots capture a VM's disk and state for quick rollback during testing. Cloning copies a VM image to create a new instance quickly, speeding deployment of repeatable environments.
Misconception: A snapshot is a full backup by itself. Snapshots are useful for short-term testing and rollback but should be complemented by dedicated backups for long-term protection.
