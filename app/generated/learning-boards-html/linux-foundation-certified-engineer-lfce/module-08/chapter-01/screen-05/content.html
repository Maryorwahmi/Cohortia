Module 8 › Chapter 8.1 › Hypervisor Role
What the hypervisor controls
CPU scheduling: maps vCPUs to physical CPUs and controls time slices.
Memory mapping: translates guest memory to host pages and may use ballooning.
Storage virtualization: virtual disks backed by files, LVM, or block devices.
Network interfaces: virtual NICs connect to bridges, providing isolation or shared networks.
Key Takeaway

Understand which layer schedules and maps resources so you can tune performance and isolation settings effectively.
