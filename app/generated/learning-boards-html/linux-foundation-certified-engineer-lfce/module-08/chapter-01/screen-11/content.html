Virtual disk backends
File-backed images: simple and portable.
LVM or raw block: often better for performance and snapshots.
Snapshot: fast rollback for testing; not a long-term backup.
Key Takeaway

Plan storage backends with performance and snapshot behavior in mind, and keep backups separate from snapshot chains.

Portability & Live Migration
Portability allows moving or copying VM images between hosts for maintenance or scaling. Live migration transfers a running VM with minimal downtime when storage and host compatibility permit it.
Misconception: Live migration eliminates planning. In practice, shared storage, network configuration, and matching CPU features are prerequisites to successful live migration.
