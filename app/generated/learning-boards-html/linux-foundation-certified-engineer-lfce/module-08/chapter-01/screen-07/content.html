Module 8 › Chapter 8.1 › Host Support Checks
Detect virtualization environment
systemd-detect-virt
# returns: none, kvm, vmware, oracle, etc.
Use this to know if you're running inside a VM or on bare metal as an initial quick check.
Check CPU virtualization flags
grep -E 'svm|vmx' /proc/cpuinfo
# presence of output → CPU supports virtualization extensions
If no output appears, virtualization extensions may be disabled in BIOS/UEFI or not present on the CPU.
Example
Output contains 'vmx'
Indicates Intel VT-x support is present and can be used by KVM.
Tip
Combine checks
Run both detection and CPU flag checks before provisioning a KVM host.
Common mistake
Assuming detection alone proves KVM readiness. Verify kernel modules and acceleration support separately.
