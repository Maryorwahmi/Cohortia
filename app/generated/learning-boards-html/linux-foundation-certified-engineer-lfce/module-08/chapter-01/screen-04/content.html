Module 8 › Chapter 8.1 › What is Virtualization?
Definition and analogy
Virtualization creates virtual hardware that guest OSes use like real machines. Think of a house split into apartments by a landlord.
Benefit: Better resource utilization reduces hardware, power, and cooling costs.
Benefit: Isolation improves security and stability between workloads.
Misconception: Virtualization always improves performance. Not true if hardware acceleration is missing or resources are misallocated.
Key Takeaway

Virtualization brings portability and consolidation, but it requires deliberate resource planning and monitoring to avoid contention.

Concrete Example
Landlord scenario:
- House = physical server
- Landlord = hypervisor
- Apartments = virtual machines
Each apartment has its own doors, wiring, and furniture isolated from others.
