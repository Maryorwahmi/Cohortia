Module 8 › Chapter 8.1 › Type 1 vs Type 2
Type 1 — Bare-metal
Runs directly on hardware, offering lower overhead and better isolation.
Examples: KVM, VMware ESXi, Hyper-V
Use case: Data centers, production database hosts needing near-native I/O.
Type 2 — Hosted
Runs on top of a host OS and is convenient for development and testing.
Examples: VirtualBox, VMware Workstation, Parallels
Use case: Desktop testing, quick multi-OS access for developers.
Practical guidance
  • Choose Type 1 for production workloads needing performance and scale.
  • Choose Type 2 for convenience on desktops where performance is not critical.
  • Ensure CPU virtualization extensions are enabled for KVM to perform well.
