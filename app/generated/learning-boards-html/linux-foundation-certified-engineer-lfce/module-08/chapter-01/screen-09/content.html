Connectivity patterns
Bridge: VMs share the host's L2 network and appear as normal hosts on that network.
NAT: VMs are isolated and use the host to provide outbound connectivity.
Isolated networks: No external connectivity; useful for testing or security zones.
Remember to plan firewall rules and VLAN tagging when bridging to production networks to avoid accidental exposure.
Practical scenario
If you need low-latency access to storage arrays from VMs, bridge to a dedicated NIC and avoid NAT. For multi-tenant isolation, give tenants separate bridges or VLANs and restrict bridge forwarding with firewall rules.
Common mistake

Assuming default bridge settings are secure. Always validate network isolation and filtering after deployment.
