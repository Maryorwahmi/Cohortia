Definition
docker-compose — define multi-container apps
A YAML file that declares services, networks, and volumes, enabling you to start and stop the entire stack together.
Example docker-compose.yml
version: '3.8'
services:
  web:
    image: nginx:latest
    ports:
      - "8080:80"
    volumes:
      - ./nginx.conf:/etc/nginx/conf.d/default.conf:ro
      - ./html:/usr/share/nginx/html:ro
    networks:
      - my-app-network
    restart: always

  db:
    image: postgres:13
    environment:
      POSTGRES_DB: mydb
      POSTGRES_USER: user
      POSTGRES_PASSWORD: password
    volumes:
      - db_data:/var/lib/postgresql/data
    networks:
      - my-app-network

networks:
  my-app-network:
    driver: bridge

volumes:
  db_data:
Key notes
  • docker-compose up -d reads this file, creates services, networks, and volumes, and runs them in detached mode.
  • docker-compose down stops and removes the resources defined in the file; remember that volumes persist unless explicitly removed.
  • depends_on controls start ordering but not service readiness; use health checks if you need readiness gating.
Key Takeaway

Compose files codify multi-service deployments. Keep secrets out of the file in production and use named volumes for persistent data.
