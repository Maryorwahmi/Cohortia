Module 8 › Chapter 8.6 › Learning Objectives
Manage container lifecycle
Start, stop, restart, and remove containers reliably and confirm status with docker ps and docker ps -a.
Command
docker stop, docker start, docker rm
Verify
docker ps, docker logs
VERIFIED COMPETENCY MILESTONE
Use docker exec and logs
Run commands inside containers for debugging and use logs to trace startup failures or configuration issues.
Command
docker exec -it, docker logs
Outcome
Interactive shell or aggregated logs for diagnosis
