Definition
Environment variables for runtime configuration
Pass variables at container start to configure behavior without changing the image.
Example
docker run -d --name my-db -e MYSQL_ROOT_PASSWORD=mysecretpassword mysql:latest
This sets MYSQL_ROOT_PASSWORD inside the container at startup so the database initializes with that credential.
Misconception
Storing sensitive secrets as plain environment variables is risky. In production use a secrets facility rather than plain text in shell history or orchestration files.
Practical notes
  • Environment variables are applied at container start; changing them requires a new container.
  • Use docker-compose environment sections to keep values organized for multi-service stacks.
  • For development, consider an env file to avoid long command lines when launching containers.
Key Takeaway

Use environment variables to configure containers at runtime, but manage secrets securely and avoid embedding sensitive values in shared files.
