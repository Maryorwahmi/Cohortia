Key Concepts
Three compact reminders to carry forward.
docker run & flags
Use -d, --name, -p, -v, and -e to control runtime behavior and make containers reproducible.
Volumes & persistence
Prefer named volumes for persistent service data; host mounts are useful for local file editing but require permission care.
Networking & compose
User-defined bridges enable DNS-based discovery; docker-compose binds services, networks, and volumes into one reproducible file.
Summary
Follow explicit runtime flags, persist data with named volumes, choose networking for discovery needs, and codify stacks with docker-compose to make deployments repeatable and maintainable.
