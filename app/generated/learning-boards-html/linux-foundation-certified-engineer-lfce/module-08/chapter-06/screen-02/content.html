Learning Objectives
These four competencies will give you practical control over container run-time behavior, storage, networking, and multi-service orchestration.
01
Run containers with options
Execute containers using detached mode, names, port mappings, and environment variables so services are reachable and configurable. This matters because it lets you expose services and change behavior without rebuilding images.
VERIFIED COMPETENCY MILESTONE
02
Persist data with volumes
Mount host directories or use Docker-managed named volumes to retain state beyond container lifetimes. Named volumes improve portability and avoid path assumptions across hosts.
VERIFIED COMPETENCY MILESTONE
03
Choose and configure networks
Use default bridge for simple isolation, host network for performance, and user-defined bridges when you need name-based service discovery between containers.
VERIFIED COMPETENCY MILESTONE
04
Author docker-compose stacks
Define services, networks, and volumes in a single YAML file so you can start a multi-container application reproducibly and manage it as a unit.
VERIFIED COMPETENCY MILESTONE
