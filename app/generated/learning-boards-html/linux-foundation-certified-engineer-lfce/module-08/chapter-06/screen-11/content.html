Comparison
Host vs Bridge vs User-defined bridge
A side-by-side view of the common Docker network modes to help choose the right one for your service.
Host Network
  • Performance: High
  • Isolation: None
  • Discovery: Host IP, direct ports
  • Use case: high-throughput or low-latency tools
Default bridge
  • Performance: Moderate
  • Isolation: Yes (NAT)
  • Discovery: IP-based only
  • Use case: simple isolated tasks
User-defined bridge
  • Performance: Moderate
  • Isolation: Yes
  • Discovery: DNS by container name
  • Use case: composed applications, docker-compose
Pro Tip
For multi-service apps, prefer a user-defined bridge created in your docker-compose so services can use stable DNS names and network settings are captured in the composition file.
