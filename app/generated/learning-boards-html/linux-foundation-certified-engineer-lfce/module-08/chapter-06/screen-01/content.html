Running & Orchestrating Docker Containers
Interactive 16:9 Masterclass
Practice the docker run command and its options, learn volume patterns for persistence, configure containers with environment variables, manage lifecycle commands, explore network modes, and define multi-service applications with docker-compose. These are essential skills for deploying reliable containerized services.
Concept map
Run
docker run creates and starts containers; you control network, volumes, and env.
Persist
Use host mounts or named volumes to keep data outside container lifecycles.
Compose
Describe multi-service apps with a YAML file and run them as a unit with docker-compose.
Explore Key Topics
Container Execution
How docker run options control mode, naming, and port mapping so services are reachable from the host.
Persistence
Host mounts vs named volumes and why named volumes improve portability and lifecycle management.
Networking & Compose
When to use bridge, host, or user-defined bridge networks and how docker-compose wires services together.
