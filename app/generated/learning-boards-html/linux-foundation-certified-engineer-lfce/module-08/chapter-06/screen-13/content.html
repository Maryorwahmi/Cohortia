Hands-on Activity
Deploy and manage a multi-container app
Follow the steps to build a reproducible Nginx plus optional backend stack with docker-compose.
Starter commands
mkdir my-web-app && cd my-web-app
mkdir html
echo "<h1>Hello from Nginx!</h1>" > html/index.html
# create nginx.conf and docker-compose.yml as shown in the previous screen

docker-compose up -d
docker ps
# Verify: open http://localhost:8080

docker-compose logs web
docker-compose down
Troubleshooting checklist
  • If the site is unreachable, confirm docker ps shows the web container and the port mapping column lists 0.0.0.0:8080->80.
  • If Nginx returns permission denied, check host file ownership and adjust with chown or use a named volume.
  • Use docker-compose logs to view both web and db logs in one place for correlated failures.
