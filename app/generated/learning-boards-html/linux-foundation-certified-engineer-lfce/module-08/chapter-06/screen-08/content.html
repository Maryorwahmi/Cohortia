Process Flow
Managing container lifecycle & inspection
Control containers and use inspection commands to verify and debug runtime behavior.
Common commands
docker ps
docker ps -a
docker stop my-nginx
docker start my-nginx
docker restart my-nginx
docker rm my-nginx
docker logs my-nginx
docker exec -it my-nginx bash
Use logs and exec to collect evidence before removing a container. Restarting does not change configuration flags; recreate for config changes.
Scenario
If a service exits immediately after start, run docker logs to capture the startup error. If logs point to a missing configuration file, use docker exec on a running container or docker cp to inspect file contents. If the container never runs, check docker inspect to see command and mount configuration.
Key Takeaway

Use inspection commands first to diagnose failures. Only remove containers after collecting logs and evidence or when you can recreate the service reproducibly.
