Network-Attached Storage (NFS & iSCSI)

Extend KVM storage capabilities using network protocols for shared and scalable disk access.

Comparison: NFS vs. iSCSI
NFS (Network File System)
  • File-level access over network.
  • VM disk images reside on mounted NFS shares.
  • Simpler to set up for file sharing.
  • Good for general-purpose VM storage.
iSCSI (Internet SCSI)
  • Block-level access over network.
  • Remote storage presented as local disks to KVM host.
  • Often higher performance for demanding I/O.
  • Requires iSCSI initiator/target configuration.
Real-World Application

In a KVM cluster, multiple hosts can access the same NFS share or iSCSI LUNs. This shared storage is a prerequisite for live migration, allowing VMs to seamlessly move between hosts without their disk images needing to be copied, ensuring zero downtime.

Key Takeaway

NFS and iSCSI provide essential network-attached storage options for KVM, enabling shared access, scalability, and support for advanced features like live migration.

Security Consideration

Ensure proper network segmentation and access controls for NFS and iSCSI storage. Unauthorized access to these shares could compromise your VM data. Use firewall rules and authentication where possible.
