Configuring Bridged Networking (Part 2)

Attach your physical network interface to the bridge and activate the new configuration.

Terminal: Attach Physical Interface & Restart
# Create /etc/NetworkManager/system-connections/enp1s0.nmconnection (modify existing or create)
[connection]
id=enp1s0-slave
uuid=<generate_uuid_here>
type=ethernet
interface-name=enp1s0
master=br0
slave-type=bridge
autoconnect=yes

# Restart NetworkManager
sudo systemctl restart NetworkManager

# Verify bridge status
ip a show br0

# Use with virt-install
sudo virt-install ... --network bridge=br0
Explanation
  • id=enp1s0-slave: Identifier for the physical interface's connection.
  • interface-name=enp1s0: Specifies the actual physical network adapter.
  • master=br0: Designates br0 as the master bridge for this interface.
  • slave-type=bridge: Confirms the interface is a slave to a bridge.
  • sudo systemctl restart NetworkManager: Applies the new network configurations.
  • --network bridge=br0: Directs virt-install to connect the VM to the br0 bridge.
Key Takeaway

Connecting the physical interface to the bridge and restarting NetworkManager completes the bridged network setup, enabling VMs to join the physical network.

Troubleshooting Tip

If you lose network connectivity after restarting NetworkManager, check your connection files for typos and ensure the physical interface name is correct. Use nmcli connection show to inspect active connections.
