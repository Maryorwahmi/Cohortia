Seamless Operations with Live Migration

Move running KVM VMs between physical hosts without any service interruption.

Terminal: Live Migration Command
# On source host:
virsh migrate --live --uri qemu+ssh://destination_host/system my-web-server
Key Prerequisites
  • **Shared Storage:** VM disk image must be accessible by both source and destination hosts (e.g., NFS, iSCSI).
  • **Bridged Networking:** VM's network must be configured for bridging on both hosts.
  • **Consistent CPU Types:** Or compatible CPU flags between hosts for optimal performance.
  • **SSH Access:** For libvirt to connect to the destination host.
Key Takeaway

Live migration is a powerful KVM feature enabling zero-downtime VM mobility, critical for maintenance, load balancing, and high availability, provided shared storage and bridged networking are in place.

Safety Note

Always test live migration thoroughly in a non-production environment first. Improper configuration can lead to VM instability or network issues during the migration.
