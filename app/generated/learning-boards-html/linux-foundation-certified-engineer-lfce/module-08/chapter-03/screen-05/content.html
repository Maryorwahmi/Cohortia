Configuring Bridged Networking (Part 1)

Create the NetworkManager connection file for your bridge interface, defining its properties and IP method.

Terminal: Create br0.nmconnection
# Example for a bridge named br0 connected to physical interface enp1s0
# Create /etc/NetworkManager/system-connections/br0.nmconnection
[connection]
id=br0
uuid=<generate_uuid_here>
type=bridge
interface-name=br0
autoconnect=yes

[bridge]
stp=no

[ipv4]
method=auto # Or manual with address/gateway/dns

[ipv6]
addr-gen-mode=stable-privacy
method=auto
Explanation
  • id=br0: Assigns a unique identifier for the connection.
  • type=bridge: Specifies that this connection defines a network bridge.
  • interface-name=br0: Sets the name of the bridge interface that will be created.
  • autoconnect=yes: Ensures the bridge activates automatically on system boot.
  • stp=no: Disables Spanning Tree Protocol, often preferred for simple KVM bridges.
  • method=auto: Configures IPv4 to obtain an address via DHCP. Can be changed to manual for static IPs.
Key Takeaway

Defining the bridge connection file is the foundational step, establishing the virtual switch that will connect your physical network and VMs.

Pro Tip

Always generate a unique UUID for each NetworkManager connection using uuidgen to avoid conflicts. This ensures proper identification and management of your network profiles.
