VM Management

VM Snapshots for Rollback and Testing

Save the state of a VM at a specific point in time for quick rollback and testing purposes.

Terminal: Snapshot Commands
# Create a snapshot (disk only)
virsh snapshot-create-as my-web-server --name "pre-update-snapshot" --description "Snapshot before OS update"

# Create a snapshot (disk and memory)
virsh snapshot-create-as my-web-server --name "running-state-snapshot" --description "Snapshot of running VM" --memspec shm=1 --disk-only no

# List snapshots
virsh snapshot-list my-web-server

# Revert to a snapshot
virsh snapshot-revert my-web-server "pre-update-snapshot"

# Delete a snapshot
virsh snapshot-delete my-web-server "pre-update-snapshot"
Snapshot Types & Usage
  • **Disk-only:** Saves the VM's disk state. Useful for quick rollback of data changes.
  • **Disk and Memory:** Saves disk and RAM, allowing the VM to resume from the exact running state.
  • **Testing:** Ideal for trying out risky updates or configurations.
  • **Rollback:** Provides a safety net to revert to a stable state if issues arise.
Key Takeaway

VM snapshots are powerful for creating temporary rollback points for testing and recovery, but they are not a substitute for a robust, long-term backup strategy.

Important Note

Snapshots can consume significant disk space, especially if they include memory. Manage them carefully and delete old, unnecessary snapshots to free up storage.
