Module 9 › Chapter 8.9 › Hands-on Activity
Access the VM
# If serial console is configured
virsh console mytestvm

# Or use SSH if enabled
ssh user@<VM_IP_ADDRESS>
Deploy nginx inside the VM
# Using Docker
docker run -d --name vm-nginx -p 80:80 nginx:latest

# Or using Podman
podman run -d --name vm-nginx -p 80:80 nginx:latest
Verify and monitor
From your host, confirm the site loads at http://<VM_IP_ADDRESS>. Then monitor:
  • On the host: virt-top or virsh list --all
  • Inside the VM: top
  • Container-level: docker stats vm-nginx or podman stats vm-nginx
Network tip

Ensure host and VM firewalls allow inbound traffic. If the container needs external access, open the VM firewall port that maps to the container.
