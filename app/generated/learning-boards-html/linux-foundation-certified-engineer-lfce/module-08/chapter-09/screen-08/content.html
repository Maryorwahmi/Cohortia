Module 9 › Chapter 8.9 › Resource Management
VM strategy

Set vCPUs and RAM on the hypervisor. Monitor for over-provisioning and use hypervisor tools to adjust reservations or limits.

Container strategy

Set container CPU and memory limits using runtime flags or orchestrator resource requests and limits. For example, use runtime options to constrain containers inside a VM.

Concrete example

Assign a VM 2 vCPUs and 4 GB RAM at the hypervisor. Inside that VM, run a container with --cpus=1 and --memory=512m so the container cannot exhaust the VM's budget.

Pro-tip

Use monitoring to correlate container-level spikes to VM-level metrics. If containers frequently max the VM, consider raising the VM budget or redistributing containers across hosts.
