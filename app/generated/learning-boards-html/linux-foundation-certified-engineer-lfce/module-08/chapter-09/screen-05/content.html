Module 9 › Chapter 8.9 › When to choose VMs
Definition
Virtual machines abstract physical hardware and run a complete guest OS with its own kernel. This provides a strong isolation boundary between guests and the host.
Typical use cases
  • Highly sensitive or multi-tenant workloads requiring maximal isolation.
  • Running different operating systems on the same physical host.
  • Legacy applications with OS-specific dependencies.
  • Hardware virtualization needs like GPU passthrough or nested virtualization.
Concrete scenario

Imagine a regulated environment where tenant data must be isolated. Placing each tenant in its own VM prevents kernel-level attacks from spreading across tenants and supports per-tenant OS patching schedules.

Misconception check

VMs are not obsolete. They remain the best choice where kernel separation or heterogeneous OS support is mandatory, despite higher resource cost.
