Three-step drilldown example
  1. Host: detect CPU or I/O spikes with atop or node exporter.
  2. Hypervisor: use virt-top or virsh domstats to find the VM with abnormal usage.
  3. Container: inside the VM run docker stats or podman stats to locate the offending container.
Tools at each level
  • Host: atop, sar, Prometheus Node Exporter
  • Hypervisor: virt-top, libvirt statistics, virsh domstats
  • VM guest: top, htop, free, iostat
  • Container: docker stats, podman stats, cAdvisor
  • Orchestration: Kubernetes dashboards, Prometheus, Grafana
Misconception

Metrics from a single layer can mislead. Always correlate host, hypervisor and container metrics during incident investigation.

Key takeaway

Design monitoring to traverse layers smoothly so you can quickly find the root cause of performance issues.
