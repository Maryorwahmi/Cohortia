Module 9 › Chapter 8.9 › When to choose Containers
Definition

Containers provide isolated user-space environments that share the host kernel, enabling lightweight, fast-starting runtimes for applications.

When to use containers
  • Microservices that benefit from independent deployment and scaling.
  • Rapid development and CI/CD workflows requiring consistent images.
  • Resource-efficient deployments where packing density matters.
  • Stateless services with externalized persistence.
Concrete example

A stateless API deployed as containers behind a load balancer can scale quickly during traffic spikes, with new instances starting in seconds and using minimal additional memory.

Misconception check

Containers are not a replacement for VMs when kernel differences matter. They are a complementary tool for services that can share the host kernel.
