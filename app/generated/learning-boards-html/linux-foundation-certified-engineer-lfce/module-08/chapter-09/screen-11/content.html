Module 9 › Chapter 8.9 › Network & Security
End-to-end checklist
  • Host firewall: allow forwarding to VM networks.
  • Hypervisor network: ensure bridge or NAT is configured correctly.
  • VM firewall: open ports mapped to container services.
  • Container port mapping: map host port to container port and confirm binding.
Concrete example

If the host allows traffic to a VM but the VM blocks port 80, a browser cannot reach the nginx container. Check both firewalls and test with curl from an external client to verify reachability.

Misconception

Assuming the host firewall is the only control is risky. In hybrid stacks, each layer can restrict traffic and must be validated.
