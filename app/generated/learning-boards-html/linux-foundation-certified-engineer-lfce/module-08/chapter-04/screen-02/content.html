Learning Objectives

Bloom path: Learn → Understand → Apply → Master

Bloom progression
01

Explain containerization

Define containers as packaged apps that share a host kernel and run in isolated user spaces. This skill helps you reason about when containers offer a better fit than full virtual machines.

Mnemonic: layered box showing app + deps
VERIFIED COMPETENCY MILESTONE
02

Describe Docker architecture

Identify the Docker Daemon, Client, and REST API and explain how they interact to build, run, and manage images and containers.

Mnemonic: client ↔ daemon ↔ registry arrows
VERIFIED COMPETENCY MILESTONE
03

Understand container benefits

Explain portability, efficiency, isolation, and scalability, and give a practical example for each—such as consistent testing environments or rapid horizontal scaling.

Mnemonic: four colored dots
VERIFIED COMPETENCY MILESTONE
04

Install and verify Docker

Perform package installation, start and enable the Docker service, add your user to the docker group, and confirm with a hello-world run.

Mnemonic: terminal icon + checkmark
VERIFIED COMPETENCY MILESTONE
