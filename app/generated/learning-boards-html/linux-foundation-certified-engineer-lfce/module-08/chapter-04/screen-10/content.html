Definition › Docker Registries

How registries work

Registries host image manifests and layer blobs. When pulling an image, only missing layers are downloaded, enabling reuse.

Concrete example

Pulling an official runtime image then pulling your app image that reuses the runtime layer downloads only the app-specific layers if the runtime layer already exists locally.

Practical notes
  • Use private registries for internal images and access control.
  • Inspect manifests to understand which layers are shared.
Key Takeaway

Registries accelerate distribution by reusing shared layers. Choose public or private registries based on security and operational needs.
