docker ps

docker ps -a
What happens

docker run hello-world pulls the image if missing, creates a container, runs it, then the container exits after printing a message.

Inspecting state

docker ps shows running containers; docker ps -a shows all, including exited containers like the one created by hello-world.

Key Takeaway

Use docker run for verification and docker ps / docker ps -a to inspect container states when troubleshooting.
