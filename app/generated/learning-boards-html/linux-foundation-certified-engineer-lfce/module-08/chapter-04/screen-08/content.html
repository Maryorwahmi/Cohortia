Core Concept › Docker Containers: Lifecycle

Lifecycle overview

  • Run: docker run starts an image as a container.
  • List: docker ps shows running containers; docker ps -a shows all.
  • Stop / Remove: Stop a container when finished and remove if not needed.
Concrete example

Run a simple web server image, verify it's running with docker ps, stop it, and then remove the stopped container.

State & persistence

Containers are ephemeral by default. Use volumes to persist application data beyond a container's lifecycle.

Key Takeaway

Treat containers as disposable processes; manage persistent state with volumes and use lifecycle commands for debugging.
