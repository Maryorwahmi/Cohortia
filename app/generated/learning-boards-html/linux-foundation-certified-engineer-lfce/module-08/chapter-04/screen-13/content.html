Process › Start Docker & Add User 
# Start and enable Docker
sudo systemctl start docker
sudo systemctl enable docker

# Add user to docker group
sudo usermod -aG docker $(whoami)
newgrp docker # apply group change in current shell

# Verify Docker
docker --version
Common error

If you see permission denied running docker, confirm your user is in the docker group and you applied the group change; logging out and back in is a reliable fix.

Key Takeaway

Start the daemon, add your user to the docker group, and verify with docker --version before running containers.
