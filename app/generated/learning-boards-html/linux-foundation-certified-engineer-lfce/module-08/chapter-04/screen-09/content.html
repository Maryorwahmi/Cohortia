Process Flow › Docker Engine Architecture

Components

  • Docker Daemon (dockerd): Manages images, containers, networks, volumes.
  • Docker Client: CLI used to send commands like docker run or docker build.
  • REST API: Protocol used by the client and other tools to talk to the daemon.
Example flow

docker run → client sends API call → daemon pulls image → daemon creates container → daemon starts process with namespaces and cgroups.

Troubleshooting hints
  • Check client errors for syntax or permission issues.
  • Inspect daemon logs for image pull failures or runtime errors.
  • Confirm network access if pulling from a registry fails.
Key Takeaway

Commands you run go through the client and API to the daemon, which performs the actual container management work.
