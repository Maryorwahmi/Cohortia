Definition › cgroups and namespaces

Namespaces

Namespaces create isolated views of kernel resources so processes in one namespace don't see others' resources.

  • PID namespace: isolates process IDs.
  • Network namespace: isolates interfaces and routing tables.
  • Mount namespace: isolates filesystem mounts.
Concrete impact

Processes in different namespaces cannot see each other's processes or network stacks, improving isolation for multi-tenant workloads.

cgroups (control groups)

Cgroups limit and account for CPU, memory, disk I/O, and network resources for grouped processes.

  • Limit memory: prevents a container from using all host RAM.
  • Limit CPU: assign CPU shares or quotas.
Pitfall

Relying only on namespaces without resource limits can let a busy container impact other containers through resource exhaustion.

Key Takeaway

Namespaces isolate views; cgroups enforce resource limits. Both are needed for robust container behavior.
