Practical Objectives

Checklists that map directly to commands you'll run in a lab.

Install & Verify
Install Podman from distro repos

Confirm package installation and run a diagnostic to see if Podman is operating rootless. This gives you a reproducible verification artifact for exams.

VERIFIED COMPETENCY MILESTONE
Rootless Mapping
Edit /etc/subuid and /etc/subgid if needed

Add a UID/GID range for your user and re-login so Podman can map user namespaces correctly.

VERIFIED COMPETENCY MILESTONE
Core Commands
Pull, run, ps, stop, rm, exec

These commands mirror Docker and let you manage containers without a root daemon.

VERIFIED COMPETENCY MILESTONE
Build & Compose
podman build and podman-compose

Build images from Dockerfiles and reuse existing Compose files to run multi-container apps rootlessly.
