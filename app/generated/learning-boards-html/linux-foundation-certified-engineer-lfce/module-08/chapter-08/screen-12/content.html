Module 8 › Chapter 8.8 › Troubleshooting
Checklist: startup failures
  • Confirm /etc/subuid and /etc/subgid entries for your user
  • Re-login after edits so mappings apply to your session
  • Run podman info --debug to inspect rootless and mapping status
Networking & storage
  • Check host port binding and ensure no conflicts between user sessions
  • Be aware of ownership mapping for files created by builds or mounted volumes
Diagnostic Commands
podman info --debug, podman ps -a, podman logs <container>
Common Fix
Add subordinate UID/GID ranges and re-login; adjust ownership on host files if build artifacts are inaccessible.
Key Takeaway
Start troubleshooting with mapping checks and podman debug output; networking and ownership are the most frequent sources of friction.
