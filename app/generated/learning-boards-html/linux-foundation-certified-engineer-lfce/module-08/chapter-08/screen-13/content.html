Module 8 › Chapter 8.8 › Security Best Practices
Image hygiene
Use minimal base images, build images with non-root users where possible, and run vulnerability scans before deployment.
Mounts & capabilities
Avoid mounting sensitive host paths and avoid granting extra capabilities or privileged mode unless necessary for the workload.
Multi-tenant controls
Use per-user Podman sessions, resource limits, and monitoring to reduce cross-user impact on shared systems.
Reflection

Rootless reduces host-level privilege risk, but build and runtime controls remain essential. How will you combine these controls in your environment?
