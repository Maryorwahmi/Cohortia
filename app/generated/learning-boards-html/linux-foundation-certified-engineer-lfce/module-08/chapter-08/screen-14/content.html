Module 8 › Chapter 8.8 › Key Concepts
Podman
A daemonless, OCI-compliant container engine that manages containers without dockerd.
Rootless Containers
Run containers as non-root users using UID/GID mappings to reduce host-level privilege risk.
podman build & podman-compose
Build images from Dockerfiles and run multi-container apps with Compose files in a rootless environment.
Summary Takeaway

Podman brings familiar workflows with stronger per-user isolation. Verify subuid/subgid mapping, practice core commands, and maintain image and runtime hygiene.
