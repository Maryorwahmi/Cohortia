Module 8 › Chapter 8.8 › Rootless Containers
What rootless means

Rootless containers let you run container workloads without granting host root to the container runtime. Instead, Podman maps a range of UIDs/GIDs so container root maps to non-privileged host IDs.

Configuration files
# /etc/subuid (example)
alice:100000:65536
# /etc/subgid (example)
alice:100000:65536
After adding these lines for your user, re-login so the new subordinate ID ranges are available to your session and Podman can use them.
Verify
Run the Podman debug info command shown in the exercise to confirm it reports rootless mode and shows the ID mappings.
Common Mistake
Editing subuid/subgid without a re-login or missing the entry will prevent rootless containers from starting and lead to UID mapping errors.
Why it matters
Subuid/subgid mappings enable per-user isolation on shared systems, reducing the chance that a container compromise affects the host root account.
