Learning Objectives

Practical competencies you will demonstrate in a lab or interview.

Bloom
LearnUnderstandApplyMaster
01
Explain Podman's architecture

Describe daemonless operation, conmon monitoring, and why no central dockerd reduces a single point of failure. This matters for secure multi-tenant hosts.

VERIFIED COMPETENCY MILESTONE
02
Configure rootless containers

Add and verify subuid/subgid mappings, and use podman info --debug to confirm rootless mode so containers run without sudo.

VERIFIED COMPETENCY MILESTONE
03
Manage containers with Podman

Use podman pull, run, ps, stop, rm, exec to operate containers and inspect images and processes for troubleshooting.

VERIFIED COMPETENCY MILESTONE
04
Build and compose

Build images from Dockerfiles with podman build and deploy multi-container apps using podman-compose with existing Compose files.

VERIFIED COMPETENCY MILESTONE
