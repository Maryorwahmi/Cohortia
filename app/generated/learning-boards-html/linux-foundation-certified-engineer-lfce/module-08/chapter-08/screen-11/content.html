Why use systemd user units?

You can auto-start and supervise containers per user, integrate logs into the systemd journal, and manage restart policies without creating system-level services.

# Example generator command
podman generate systemd --name my-container --files --new
The generator helps create a unit you can enable in your user systemd instance.
Concrete Use
Enable a user-level unit to restart a container after user login or system reboot, keeping services scoped to the owning user.
Misconception
User systemd units do not provide system-wide service guarantees; they operate in the user's login/session context.
Key Takeaway
Systemd user integration gives robust lifecycle control while preserving per-user isolation inherent to Podman.
