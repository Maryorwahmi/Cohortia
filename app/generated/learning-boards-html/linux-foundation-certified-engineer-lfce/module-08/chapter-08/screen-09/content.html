Module 8 › Chapter 8.8 › podman-compose
Install and run a Compose stack
Install podman-compose and reuse your existing Compose files to deploy multi-container applications without Docker.
sudo dnf install podman-compose -y
podman-compose up -d
podman-compose down
Concrete Example
Bring up a web service and a database defined in docker-compose.yml and confirm services are running with podman ps.
Caveat
Some Compose extensions and third-party drivers may not translate perfectly; test Compose files before relying on them in production.
Try this

Use podman-compose up -d with a simple two-service compose file and verify both services are accessible on their forwarded ports.
