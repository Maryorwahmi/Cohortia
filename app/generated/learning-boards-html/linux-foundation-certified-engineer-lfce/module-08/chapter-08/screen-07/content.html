Terminal commands

Use these commands to perform basic container lifecycle operations with Podman. They map closely to Docker equivalents.

podman pull nginx:latest
podman run -d --name my-nginx -p 8080:80 nginx:latest
podman ps
podman ps -a
podman stop my-nginx
podman rm my-nginx
podman exec -it my-nginx bash
podman images
podman rmi nginx:latest
These commands will run without sudo when your rootless mapping is configured. Use podman ps and podman images to inspect runtime state and local images.
Concrete example
Run nginx, forward host 8080, and verify through podman ps and by browsing http://localhost:8080 on the host.
Misconception
Don't assume rootless containers have no mapping between container root and host; the container root is present inside the namespace but mapped to non-root host IDs.
Key Takeaway
Podman offers the same operational commands you're used to, but privileges are bound to the user's namespace when rootless.
