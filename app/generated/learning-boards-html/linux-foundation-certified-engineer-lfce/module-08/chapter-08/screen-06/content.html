Module 8 › Chapter 8.8 › Install & Verify
Install

Install from your distribution's default repository so package updates and dependencies are managed by the system package manager.

sudo dnf install podman -y
Note: The install step requires privileges, but running containers can be done rootless after configuration.
Verify mapping
Ensure /etc/subuid and /etc/subgid contain entries for your user. If missing, add a range and re-login so mappings apply.
Diagnostic
podman info --debug | grep -i "rootless"
A returned value indicating rootless true confirms your session is configured correctly.
Install podman-compose
If you plan to run Compose files, install podman-compose from the repos so you can reuse docker-compose.yml files in a rootless environment.
Check your understanding

Why is logging out and back in required after editing subuid/subgid? Consider the kernel and session mapping lifecycle.
