Module 8 › Chapter 8.8 › Build Images
Create a simple Dockerfile
# Dockerfile
FROM alpine:latest
RUN apk add --no-cache cowsay
CMD ["cowsay", "Moo from Podman!"]
Build the image using podman build and tag it so you can run it locally with podman run. The same Dockerfile works unchanged.
Build & run
podman build -t my-cow-app:latest .
podman run my-cow-app:latest
Note: When run rootless, the container runs in your user namespace; inside the container the user may be root, but that root is mapped to non-root host IDs.
Concrete example
Build the cowsay image and run it to see the output, then use podman images and podman ps to confirm artifacts.
Common Mistake
Forgetting to tag the image makes it harder to reference and remove later; use a clear tag like my-cow-app:latest.
Key Takeaway
podman build is compatible with existing Dockerfiles, letting you build images without a central daemon.
