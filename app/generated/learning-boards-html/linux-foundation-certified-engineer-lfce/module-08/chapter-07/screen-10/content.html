Image Scanning for Vulnerabilities

Tools
Trivy: fast, easy to run locally and in CI.
Clair: deeper analysis that can be integrated into registries.
Practice: run the scanner after building and review severity levels; focus remediation on critical and high issues first.
Example command
# Example using Trivy
trivy image secure-nginx:latest
Interpretation: a scan lists packages and CVEs by severity. Integrate this step in CI to block risky images from deploying.
