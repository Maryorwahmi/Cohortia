Multi-stage Builds & Cleaning Caches

Step-by-step
1. Build stage: include compilers, install dependencies, run tests or builds.
2. Artifact extraction: copy only built artifacts into final stage with COPY --from=builder.
3. Final stage: use minimal base and install only runtime packages, if any.
4. Cleanup: combine install and cache remove in a single RUN so caches are not stored across layers.
Verification: run docker history and inspect the final image layers for build tools or package caches.
Concrete example
RUN apk add --no-cache build-base git && \
    npm install && \
    rm -rf /var/cache/apk/*
Tip: chain install and cleanup with && so a single layer contains neither cache nor build tools in the final image.
