How you will validate each objective

Every objective includes an actionable verification step so you can demonstrate competency in a lab or exam.

Runtime Hardening
Verify non-root with whoami and enforce read-only by attempting a write inside the container.
VERIFIED COMPETENCY MILESTONE
Image Scanning
Run a scanner such as Trivy against your built image and review CVE severity before deployment.
VERIFIED COMPETENCY MILESTONE
Network Controls
Create user-defined bridge networks and test access between tiers to confirm segmentation.
VERIFIED COMPETENCY MILESTONE
Secrets Handling
Demonstrate using Docker Secrets or an external vault; do not store credentials in images or source control.
VERIFIED COMPETENCY MILESTONE
