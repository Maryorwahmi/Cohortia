Non-Root Dockerfile: Walkthrough

Dockerfile example
FROM alpine:latest
RUN apk add --no-cache nginx && \
    adduser -D -g 'nginx' nginx && \
    mkdir -p /var/cache/nginx /var/run/nginx && \
    chown -R nginx:nginx /var/cache/nginx /var/run/nginx /var/log/nginx && \
    chmod 755 /var/cache/nginx /var/run/nginx

COPY default.conf /etc/nginx/conf.d/default.conf
RUN echo "<h1>Hello Secure Nginx!</h1>" > /usr/share/nginx/html/index.html

USER nginx
EXPOSE 80
CMD ["nginx","-g","daemon off;"]
Verification steps
  1. Build the image and run the container.
  2. Exec into the container and run whoami to confirm the non-root user.
  3. Attempt to write to the root filesystem when --read-only is set to confirm denied writes.
Common mistake: omitting chown after COPY. Always set ownership for non-root users.
