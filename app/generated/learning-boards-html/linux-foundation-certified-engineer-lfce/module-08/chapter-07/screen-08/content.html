Secure Container Networks and Segmentation

Architecture pattern
User-defined bridge networks for each tier (public, private, management).
Only connect the web server to the public network and allow the database on a private network reachable only by web.
Host firewall rules restrict traffic entering and leaving Docker-managed ports.
Verification: create networks and attempt access from a container on the wrong network to confirm isolation.
Concrete commands
docker network create public-net
docker network create private-net
docker run --network public-net -p 80:80 my-web
Tip: avoid -P. Publish only the ports your service needs with -p.
