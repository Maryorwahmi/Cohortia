Quick Reference

Verify Non-root
Run whoami inside the container and ensure files are chowned to the runtime user.
Use Capability Controls
Prefer --cap-drop ALL and selectively add required capabilities like NET_BIND_SERVICE.
Scan & Secrets
Run trivy in CI and keep secrets out of build layers using BuildKit or orchestrator secrets.
Final Thought

Small, deliberate changes at build and runtime dramatically reduce container risk. Practice these checks until they become routine.
