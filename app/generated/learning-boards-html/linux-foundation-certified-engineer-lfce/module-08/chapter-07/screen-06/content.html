Run Containers with Least Privilege

Non-root user example
FROM alpine:latest
RUN adduser -D appuser
USER appuser
WORKDIR /app
COPY --chown=appuser:appuser . /app
CMD ["./my-app"]
Remember to chown files copied into the image so the non-root user can access them without errors.
Runtime flags and capability control
Use --cap-drop ALL --cap-add NET_BIND_SERVICE to restrict capabilities to only what the app needs.
Run with --read-only and mount writable volumes where necessary to prevent unauthorized writes.
Common mistake: running as root because it's the default. Fix by adding USER and chown in the Dockerfile.
