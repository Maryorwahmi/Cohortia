Key Concepts

Attack Surface
Every package or file in the image increases potential vulnerabilities.
Least Privilege
Run non-root, drop capabilities, and use read-only filesystems to limit damage from compromises.
Scan & Secrets
Automate vulnerability scans and keep secrets out of images using secure secret stores.
Summary Takeaway

Layered controls—smaller images, runtime constraints, network segmentation, scanning, and secret management—collectively reduce container risk.
