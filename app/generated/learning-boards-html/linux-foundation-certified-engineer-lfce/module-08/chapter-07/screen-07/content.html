Capability Drops vs Privileged Mode

--cap-drop / --cap-add
Remove all capabilities and selectively add only those you need. Example: drop all then add NET_BIND_SERVICE for low ports.
Benefit: granular control, fewer privileges available to an attacker.
--privileged
Grants broad host access and many capabilities. Use only for special cases like system tooling or Docker-in-Docker.
Risk: compromise may allow host-level actions and device access, effectively breaking isolation.
Key Takeaway

Prefer capability drops and explicit adds. Avoid --privileged unless strictly necessary and audited.
