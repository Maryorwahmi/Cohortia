Minimize attack surface

Create non-root users, drop capabilities, and use read-only filesystems to limit attacker actions.
VERIFIED COMPETENCY MILESTONE
03
Secure container networks
Segment networks, limit exposed ports, and add host firewall rules to constrain traffic flows.
VERIFIED COMPETENCY MILESTONE
04
Scan images and manage secrets
Use scanners in CI and keep secrets out of images using Docker Secrets or vaults and BuildKit for build-time secrets.
