Dockerfile Instructions

Configuring Your Container Environment

Setting working directories, exposing ports, and defining environment variables

WORKDIR

Sets the working directory for subsequent instructions. Simplifies paths and organizes files.

WORKDIR /app

EXPOSE

Documents which network ports the container listens on at runtime. It's informational, not functional.

EXPOSE 80/tcp

ENV

Sets environment variables within the container. Useful for configuration and application settings.

ENV NODE_ENV production
Key Takeaway

WORKDIR, EXPOSE, and ENV are essential for defining the operational context and configuration of your containerized application.
