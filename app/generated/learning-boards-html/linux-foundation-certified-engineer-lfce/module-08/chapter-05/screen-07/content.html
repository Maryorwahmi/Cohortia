Adding Files: COPY vs. ADD

Choosing the right instruction for including local and remote resources

COPY Instruction

  • •Copies new files or directories from `` to `` in the container.
  • •Source must be within the build context.
  • •More transparent and predictable.
COPY ./index.html /usr/share/nginx/html/
Pro Tip

Always prefer COPY over ADD for local files due to its explicit nature and reduced potential for unexpected behavior.

ADD Instruction

  • •Similar to COPY, but with extra features.
  • •Can extract tar files (e.g., .tar.gz) automatically.
  • •Can fetch remote URLs.
ADD http://example.com/latest.tar.gz /app/
Security Note

Using ADD with remote URLs can introduce security vulnerabilities if the source is compromised. Always verify the integrity of remote resources.
