Dockerfile Instruction

Executing Commands with RUN

Installing packages and configuring your image layers

Example: Installing Nginx
# Bad Practice: Multiple RUN commands
FROM ubuntu:22.04
RUN apt-get update
RUN apt-get install -y nginx
RUN rm -rf /var/lib/apt/lists/*
Explanation

Each RUN instruction creates a new layer. The example above creates three separate layers for update, install, and cleanup, which is inefficient. The temporary files from apt-get update would persist in a lower layer.

Common Mistake

Using separate RUN commands for related tasks. This creates unnecessary layers and can lead to larger image sizes due to uncleaned temporary files persisting in lower layers.

Best Practice: Chaining Commands
# Good Practice: Chain commands and clean up in one RUN
FROM ubuntu:22.04
RUN apt-get update && \
    apt-get install -y nginx && \
    rm -rf /var/lib/apt/lists/*
Explanation

Combining commands with && into a single RUN instruction creates only one layer. This significantly reduces image size and ensures that temporary files like apt caches are removed within the same layer they were created, preventing bloat.

Key Takeaway

Always chain related RUN commands with && and clean up temporary files in the same instruction to optimize image size and build speed.
