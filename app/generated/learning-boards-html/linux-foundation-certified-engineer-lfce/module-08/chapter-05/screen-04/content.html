Core Concept

The Layered Architecture of Docker Images

Understanding how images are built and shared efficiently

Writable Container Layer
Image Layer 3 (e.g., CMD)
Image Layer 2 (e.g., COPY app)
Image Layer 1 (e.g., RUN apt-get)
Base Image Layer (e.g., FROM ubuntu)

Shared Layers

Common base layers are stored once, reducing disk space and improving efficiency across multiple images.

Build Caching

Docker reuses unchanged layers from previous builds, significantly accelerating subsequent image creation processes.

Modularity & Immutability

Each layer is read-only, ensuring consistency. Changes only affect specific layers, making updates predictable and isolated.

Key Takeaway

The layered architecture is fundamental to Docker's efficiency, enabling shared components, fast builds, and predictable updates.
