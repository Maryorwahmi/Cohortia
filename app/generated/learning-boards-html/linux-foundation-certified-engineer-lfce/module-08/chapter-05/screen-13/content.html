Multi-Stage Build Example

Implementing a Multi-Stage Build

A Node.js application with Nginx serving static assets

Stage 1: Build the Application
# Stage 1: Build the application
FROM node:18-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
RUN npm run build
Explanation

This stage uses a Node.js base image to install dependencies and build the application. All build tools and development dependencies are confined to this stage and will not be part of the final image.

Stage 2: Create Final Production Image
# Stage 2: Create the final production image
FROM nginx:alpine
COPY --from=builder /app/build /usr/share/nginx/html
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
Explanation

This stage uses a minimal Nginx base image. The COPY --from=builder instruction copies only the compiled application artifacts from the previous stage, resulting in a much smaller and more secure final image.

Key Takeaway

Multi-stage builds are essential for creating lean, production-ready images by separating build-time dependencies from runtime requirements.
