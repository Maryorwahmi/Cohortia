Dockerfile Instruction

Defining Default Commands with CMD

Providing executable defaults for your container

Example: Default Nginx Command
FROM nginx:alpine
COPY ./index.html /usr/share/nginx/html/
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
Explanation

This Dockerfile sets the default command to start Nginx in the foreground. If you run docker run my-nginx-image, Nginx will start. If you run docker run my-nginx-image /bin/bash, the CMD is ignored, and /bin/bash is executed.

Key Characteristics of CMD

  • •Provides defaults for an executing container.
  • •Only the last CMD instruction in a Dockerfile is used.
  • •Easily overridden by providing a command to docker run.
Analogy

Think of CMD like the default program that runs when you turn on your computer, but you can always choose to open a different program instead.

Key Takeaway

CMD sets the default command for a container, offering flexibility for users to override it at runtime.
