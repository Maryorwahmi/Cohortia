Setting API Key Environment Variables

Environment variables keep sensitive data out of your code. Here's how to set them temporarily in different operating systems.

Linux/macOS

Use export MERAKI_API_KEY="your_actual_meraki_api_key" in your terminal.

Windows (Command Prompt)

Use set MERAKI_API_KEY=your_actual_meraki_api_key.

Windows (PowerShell)

Use $env:MERAKI_API_KEY="your_actual_meraki_api_key".

Terminal Commands

Example of setting an environment variable.

# Linux/macOSexport MERAKI_API_KEY="your_actual_meraki_api_key"

# Windows (Command Prompt)set MERAKI_API_KEY=your_actual_meraki_api_key

# Windows (PowerShell)$env:MERAKI_API_KEY="your_actual_meraki_api_key"

These commands set the variable for the current terminal session only.

Key Takeaway

Use OS-specific commands to set API keys as environment variables for temporary, secure access.
