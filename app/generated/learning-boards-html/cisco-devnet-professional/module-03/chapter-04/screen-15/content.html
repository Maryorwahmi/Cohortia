Meraki Network Creation & Webex Notification Logic

The main automation logic orchestrates the sequence of operations for cross-platform integration.

Initialization

Retrieve Meraki organization ID and Webex Teams room ID.

Meraki Action

Call create_meraki_network to provision a new network.

Webex Notification

Construct a message and call send_webex_message if network creation is successful.

Main Automation Flow

The core logic of the Meraki-Webex integration script.

if __name__ == "__main__":
    # ... (API key checks) ...
    meraki_org_id = get_first_meraki_org_id()
    webex_room_id = get_first_webex_room_id()

    # ... (ID validation) ...

    new_network_name = f"Automated_Network_{int(time.time())}"
    product_types = ["appliance", "switch"]

    created_network = create_meraki_network(meraki_org_id, new_network_name, product_types)

    if created_network:
        message = f"**ALERT:** New Meraki Network Created!
**Name:** {created_network['name']}"
        send_webex_message(webex_room_id, message)
        print("Automation complete.")
    else:
        print("Failed to create Meraki network.")

This code orchestrates the creation of a Meraki network and sends a Webex notification.

Key Takeaway

The main logic ties together API calls and helper functions to execute a complete cross-platform automation workflow.
