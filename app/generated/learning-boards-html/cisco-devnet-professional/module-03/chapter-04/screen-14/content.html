Modular API Call & Webex Message Functions

Reusable helper functions centralize API interaction logic, improving code clarity and maintainability for cross-platform integration.

make_api_call

A generic function to handle GET, POST, PUT, DELETE requests for any API, with centralized error handling.

send_webex_message

A specific function to simplify sending messages to a Webex Teams room, abstracting payload details.

Benefit

Reduces code duplication, makes the main logic cleaner, and simplifies debugging and future extensions.
