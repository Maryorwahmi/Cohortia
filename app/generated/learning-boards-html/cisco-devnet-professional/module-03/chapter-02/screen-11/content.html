Endpoints: Resource Addresses

Endpoints are specific URLs that identify the resources you want to interact with. They often include path parameters for dynamic resource identification.

/organizations
/networks/{networkId}/vlans

Path Parameters

These are dynamic parts of the URL (e.g., {networkId}) that you replace with actual values to target specific resources.

Key Takeaway

Combine the correct endpoint with the appropriate HTTP method to precisely target and manipulate API resources.

Common HTTP Methods

GETRetrieve data
POSTCreate new resource
PUTReplace existing resource
DELETERemove resource
PATCHPartial update
