Module 3 › Chapter 3.2 › Key Concepts: DevNet & Sandboxes

Cisco DevNet

Cisco's developer program and portal providing resources, tools, sandboxes, and documentation for network programmability.

DevNet Sandbox

Live, isolated environments of Cisco network devices and software for safe experimentation and testing without impacting production.

Always-On Sandbox

Shared, continuously available sandbox for quick testing; changes may not persist due to periodic resets.

Chapter Summary

Cisco DevNet provides essential resources, including sandboxes for safe experimentation and comprehensive API documentation, crucial for network programmability.
