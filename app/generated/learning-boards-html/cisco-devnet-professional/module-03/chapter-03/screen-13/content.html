Advanced Error Handling for APIs

Customizing responses to API failures

Beyond `raise_for_status()`
  • •**`response.status_code`:** Direct inspection for specific HTTP codes.
  • •**`response.text` / `response.json()`:** Access raw or parsed error messages from the API.
  • •**Custom Logic:** Implement different actions based on error type (e.g., retry, log, alert).
Scenario Example

If a `404 Not Found` occurs, log a warning and skip the resource. If a `401 Unauthorized` occurs, trigger an alert to check credentials.

Key Takeaway

Advanced error handling involves inspecting `status_code` and response body for granular control, enabling intelligent and robust automation scripts.

import requests
import json

API_URL = "https://api.example.com/resource"
HEADERS = {"Authorization": "Bearer YOUR_TOKEN"}

try:
    response = requests.get(API_URL, headers=HEADERS)
    
    if response.status_code == 200:
        print("Success:", response.json())
    elif response.status_code == 401:
        print("Error 401: Unauthorized. Check credentials.")
        print("API Response:", response.text)
    elif response.status_code == 404:
        print("Error 404: Resource not found. Skipping.")
    else:
        print(f"Unexpected HTTP Error {response.status_code}: {response.text}")

except requests.exceptions.RequestException as e:
    print(f"Network or connection error: {e}")
