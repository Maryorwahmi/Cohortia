Creating a Webex Teams Room

A practical POST request for collaboration

Code Highlights
  • •`WEBEX_ACCESS_TOKEN` for `Authorization` header.
  • •`create_room_payload` as a Python dictionary.
  • •`requests.post()` with `json` parameter for automatic serialization.
  • •Extracting `room_id` from the `response.json()`.
Pro-Tip

Always consult the specific API documentation for required headers, endpoint paths, and the exact structure of JSON payloads for `POST` requests.

Key Takeaway

`POST` requests are used to create resources, and `requests` simplifies sending JSON payloads, making it ideal for provisioning tasks like creating Webex rooms.

import requests
import json

WEBEX_ACCESS_TOKEN = "YOUR_WEBEX_ACCESS_TOKEN" # Replace with your actual Webex token
WEBEX_BASE_URL = "https://api.ciscospark.com/v1"

webex_headers = {
    "Authorization": f"Bearer {WEBEX_ACCESS_TOKEN}",
    "Content-Type": "application/json"
}

# 1. Create a new Webex Teams room
room_name = "DevNet Automation Project Room"
create_room_payload = {
    "title": room_name
}

try:
    create_room_response = requests.post(f"{WEBEX_BASE_URL}/rooms", headers=webex_headers, json=create_room_payload)
    create_room_response.raise_for_status()
    new_room = create_room_response.json()
    room_id = new_room['id']
    print(f"Successfully created room: '{new_room['title']}' with ID: {room_id}")

except requests.exceptions.HTTPError as errh:
    print(f"HTTP Error: {errh} - Response: {errh.response.text}")
except requests.exceptions.RequestException as err:
    print(f"An error occurred: {err}")
