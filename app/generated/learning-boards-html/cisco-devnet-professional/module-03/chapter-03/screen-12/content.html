Updating a Meraki Network Name

Applying PUT for resource modification

Code Highlights
  • •`organization_id` and `network_id` identify the target.
  • •`update_network_payload` contains the new name.
  • •`requests.put()` sends the update request.
  • •`response.json()` verifies the updated resource.
Important Note

For Meraki, `PUT` is often used for network updates, even for partial changes. Always verify the expected behavior in the official API documentation.

Key Takeaway

`PUT` requests are used to update existing resources. Always confirm the API's specific requirements for `PUT` vs. `PATCH` to avoid unintended data loss.

import requests
import json

MERAKI_API_KEY = "YOUR_MERAKI_API_KEY" # Replace with your actual Meraki API key
BASE_URL = "https://api.meraki.com/api/v1"

headers = {
    "X-Cisco-Meraki-API-Key": MERAKI_API_KEY,
    "Content-Type": "application/json"
}

# Example: Updating a Meraki network name (PUT request)
# Assuming you have an organization_id and network_id from previous GET calls
organization_id = "YOUR_ORG_ID" # Replace with actual ID
network_id = "YOUR_NETWORK_ID" # Replace with actual ID
new_network_name = "My_Updated_DevNet_Network"

update_network_payload = {
    "name": new_network_name
}

try:
    update_response = requests.put(f"{BASE_URL}/networks/{network_id}", headers=headers, json=update_network_payload)
    update_response.raise_for_status()
    updated_network = update_response.json()
    print(f"Successfully updated network '{network_id}' to name: '{updated_network['name']}'")

except requests.exceptions.HTTPError as errh:
    print(f"HTTP Error updating network: {errh} - Response: {errh.response.text}")
except requests.exceptions.RequestException as err:
    print(f"An error occurred: {err}")
