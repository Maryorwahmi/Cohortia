Data Interchange

JavaScript Object Notation (JSON)

Structured Data for API Communication

Lightweight & Human-Readable

Easy for both developers and machines to understand and parse.

Name/Value Pairs

Represents objects or dictionaries (e.g., "vlan_id": 100).

Ordered Lists of Values

Represents arrays or lists (e.g., ["port1", "port2"]).

Key Idea

JSON: The API Language

JSON is a lightweight, human-readable format for structured data, using name-value pairs and ordered lists, making it ideal for API data exchange.

Concrete Example
{
  "vlan_id": 100,
  "name": "Voice_VLAN",
  "ports": ["GigabitEthernet1/0/1", "GigabitEthernet1/0/2"]
}

This JSON object describes a VLAN with its ID, name, and associated ports.

Key Takeaway

JSON's simplicity and universal support make it the preferred format for exchanging data in modern RESTful APIs.
