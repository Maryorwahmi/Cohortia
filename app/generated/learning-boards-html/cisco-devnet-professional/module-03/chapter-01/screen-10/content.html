Response Structure

Server Feedback: Status Codes

Interpreting API Call Outcomes

Status Line

HTTP Version, 3-digit Status Code, Status Message (e.g., 200 OK).

Response Headers

Metadata about the response, like Content-Type or caching directives.

Response Body (Optional)

The data payload returned by the server, typically in JSON format.

Key Idea

Decoding Server Responses

HTTP responses provide status codes and data, with status codes being essential for understanding success or failure and implementing robust error handling.

Status Code Ranges

2xx: Success (e.g., 200 OK, 201 Created)
4xx: Client Error (e.g., 400 Bad Request, 404 Not Found)
5xx: Server Error (e.g., 500 Internal Server Error)

Common Misconception

A 404 Not Found doesn't always mean a typo in the URL; it can also mean the specific resource you're requesting does not exist at that valid endpoint.

Key Takeaway

Always check HTTP status codes in your automation scripts to ensure success and implement graceful error handling.
