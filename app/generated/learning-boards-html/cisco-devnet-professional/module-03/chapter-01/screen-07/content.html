HTTP Verbs

GET and POST

Retrieving and Creating Data

GET Request

  • •Used to retrieve data from a specified resource.
  • •Does not alter server state (safe).
  • •Can be repeated without side effects (idempotent).
Example

GET /api/v1/interfaces/GigabitEthernet1 to read interface status.

POST Request

  • •Used to submit new data, often creating a new resource.
  • •Alters server state (not safe).
  • •Not necessarily idempotent; repeated calls may create duplicates.
Example

POST /api/v1/vlans with a JSON body to create a new VLAN.

Key Takeaway

Use GET for reading data and POST for creating new resources, being mindful of their impact on server state and idempotency.
