HTTP Verbs

PUT, PATCH, and DELETE

Updating and Removing Resources

PUT Request

  • •Replaces an entire resource or creates if non-existent.
  • •Idempotent: repeated calls have same effect.
Example

Update a VLAN config by sending the full new object.

PATCH Request

  • •Applies partial modifications to a resource.
  • •Not necessarily idempotent.
Example

Change only the 'name' field of an interface, leaving other settings intact.

DELETE Request

  • •Removes a specified resource from the server.
  • •Idempotent: repeated calls have same effect (resource remains deleted).
Example

DELETE /api/v1/vlans/100 to remove VLAN 100.

Key Takeaway

Carefully select PUT, PATCH, or DELETE based on whether you're replacing, partially updating, or removing a resource to ensure correct API behavior.
