Essential GitLab CI/CD Concepts

Reinforcing the foundational terminology for network automation pipelines.

.gitlab-ci.yml

The YAML file defining the entire CI/CD pipeline in a GitLab repository.

Stages

High-level, sequential phases of a pipeline (e.g., lint, test, deploy).

Jobs

Individual units of work within a stage, executed in parallel.

Summary Takeaway

The .gitlab-ci.yml file orchestrates your pipeline through defined stages and jobs, providing a structured approach to network automation.
