Pipeline Structure

Building Blocks: Stages and Jobs

Understanding the fundamental components that define your CI/CD workflow.

Stages: Sequential Phases

High-level phases (e.g., lint, test, deploy) that run one after another.

Jobs: Parallel Tasks

Independent units of work within a stage that execute commands concurrently.

Execution Flow

Stages run sequentially; jobs within the same stage run in parallel.

Key Takeaway

Stages provide structure and order to your pipeline, while jobs perform the actual work, allowing for efficient, parallel execution of tasks.
