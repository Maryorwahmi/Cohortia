The .gitlab-ci.yml File: Global Directives

Exploring the initial sections that set the foundation for your pipeline.

.gitlab-ci.yml
# .gitlab-ci.yml
stages:
- lint
- test
- deploy_lab
# - deploy_prod # This stage would typically have a manual approval

variables:
ANSIBLE_INVENTORY: inventory.yml
ANSIBLE_CONFIG: ansible.cfg # Optional: path to ansible.cfg

default:
image: python:3.9-slim-buster # Use a Python image for Ansible
before_script:
- pip install ansible ansible-lint netmiko # Install necessary tools
- ansible-vault decrypt --output inventory.yml $ANSIBLE_INVENTORY_VAULTED_CONTENT # Decrypt inventory if vaulted
Stages Definition

Defines the high-level, sequential phases of your pipeline, like linting, testing, and deployment.

Global Variables

Sets variables accessible across all jobs, promoting consistency and reusability (e.g., inventory paths).

Default Job Properties

Specifies common settings for all jobs, including the Docker image for the execution environment and `before_script` commands.

Key Takeaway

Global directives in .gitlab-ci.yml establish the foundational structure and environment, ensuring consistent and efficient pipeline execution for all defined jobs.
