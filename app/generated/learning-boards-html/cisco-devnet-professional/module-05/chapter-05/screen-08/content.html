Pre-Deployment Validation

Simulating Changes with Dry Runs

Using --check --diff to preview network configuration modifications safely.

.gitlab-ci.yml
test_dry_run:
stage: test
script:
- ansible-playbook -i $ANSIBLE_INVENTORY playbooks/configure_ntp.yml --check --diff # Simulate and show differences
tags:
- network-runner
allow_failure: false # If dry run fails, the pipeline fails
The --check Flag

Runs the playbook in a dry-run mode, reporting changes without actually applying them to devices.

The --diff Flag

Displays the exact configuration differences between the current state and the desired state.

Critical Safety Measure

Prevents unintended network disruptions by allowing review and approval of changes before deployment.

Key Takeaway

Dry runs with --check --diff are essential for safely validating network configuration changes, providing a clear preview and preventing accidental deployments.
