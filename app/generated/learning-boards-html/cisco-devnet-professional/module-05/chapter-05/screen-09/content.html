Controlled Deployment

Automating Lab Deployments

Configuring jobs for controlled application of changes in a test environment.

.gitlab-ci.yml
deploy_to_lab:
stage: deploy_lab
script:
- ansible-playbook -i $ANSIBLE_INVENTORY playbooks/configure_ntp.yml # Applies configuration to lab devices
tags:
- network-runner
environment:
name: lab
rules:
- if: '$CI_COMMIT_BRANCH == "main"' # Only deploy to lab on main branch pushes
when: manual # Make this a manual job for safety, even in lab
Actual Application

Executes the Ansible playbook to apply configurations to devices in the specified lab environment.

Conditional Execution (rules)

Defines when a job should run, for example, only on pushes to the main branch.

Manual Trigger (when: manual)

Requires explicit user action to start the job, adding a crucial human review step for safety.

Key Takeaway

Lab deployment jobs, combined with conditional rules and manual triggers, provide a safe and controlled way to validate network changes in a non-production environment.
