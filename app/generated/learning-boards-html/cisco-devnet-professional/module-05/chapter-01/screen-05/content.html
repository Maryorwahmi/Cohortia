Understanding Imperative Automation

Dictating the exact sequence of commands to reach a desired network state.

Explicit Command Sequence

Each step is precisely defined, mirroring manual CLI operations. The script dictates the 'how'.

Potential for Brittleness

Highly dependent on the network's current state; unexpected conditions can lead to script failures or unintended changes.

Complex State Management

Requires the script itself to manage and verify the device's state, increasing complexity for large-scale deployments.

Python Script (Conceptual)
def configure_vlan_imperative(device):
    # Step 1: Enter configuration mode
    device.send_command('config t')
    # Step 2: Create VLAN 10
    device.send_command('vlan 10')
    # Step 3: Name the VLAN
    device.send_command('name DATA')
    # Step 4: Exit VLAN configuration
    device.send_command('exit')
    # Step 5: Exit global configuration
    device.send_command('end')
    print("VLAN 10 configured imperatively.")
Common Pitfall

Imperative scripts can fail if a command is run on a device where the desired state already exists, leading to errors or unexpected behavior.
