Key Concepts

Review the fundamental terms and ideas from this chapter.

Agentless Architecture

Automation tools (like Ansible) that do not require software agents to be installed on managed devices.

Agent-based Architecture

Automation tools (like Puppet, Chef) that require a software agent to be installed on managed devices.

Source Control Management (SCM)

Systems (e.g., Git) used to manage changes to code, configurations, and other files, providing versioning, collaboration, and history.

Summary Takeaway

Choosing between agentless and agent-based architectures, and integrating Source Control Management, are crucial decisions for building scalable and maintainable network automation.
