Core Concept

Continuous Delivery (CD)

Ensuring changes are always ready for production release.

Extends CI by ensuring all validated code changes are always in a deployable state.

Automates the process of preparing changes for release, often involving staging environments.

Deployment to production is a manual step, but it's a push-button operation.

Provides confidence that changes are vetted and ready, while maintaining human oversight for critical deployments.

Key Takeaway

Always have changes ready for production, with a manual approval before final deployment.
