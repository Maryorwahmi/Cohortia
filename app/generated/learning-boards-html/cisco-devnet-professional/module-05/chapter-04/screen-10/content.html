Tool Spotlight

Popular CI/CD Tools: GitHub Actions

Automating workflows directly within GitHub.

Integrated into GitHub repositories for workflow automation.

Uses YAML workflow files (e.g., `.github/workflows/*.yml`) triggered by GitHub events.

Supports a wide range of events beyond code pushes, enabling diverse automation.

Features a marketplace of reusable actions for simplifying tasks.

Offers hosted runners or self-hosted options for execution environments.

Key Takeaway

GitHub Actions provides a flexible, event-driven automation platform tightly integrated with the GitHub ecosystem.

# Example GitHub Actions Workflow (.github/workflows/ci.yml)

name: Network CI Pipeline

on:
  push:
    branches: [ main ]
  pull_request:
    branches: [ main ]

jobs:
  build_and_test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Set up Python
        uses: actions/setup-python@v4
        with:
          python-version: '3.x'
      - name: Install dependencies
        run: pip install ansible ansible-lint
      - name: Run Ansible Lint
        run: ansible-lint *.yml
      - name: Run Syntax Check
        run: ansible-playbook --syntax-check site.yml
