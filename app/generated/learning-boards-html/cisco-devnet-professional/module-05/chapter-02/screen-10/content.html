Core Definition

Ansible Ad-hoc Command

A single-line Ansible command executed directly from the command line for quick, one-off tasks or gathering information without writing a full playbook.

Use Cases

Quick checks, troubleshooting, initial connectivity tests, simple configuration changes.

Syntax Overview

`ansible [host/group] -i [inventory] -m [module] -a "[arguments]"`

Key Flags

`-i` (inventory), `-m` (module), `-a` (module arguments), `-k` (ask password).

Example Scenario

To quickly check the running configuration of a single router without creating a playbook, an ad-hoc command is ideal.

Key Takeaway

Ad-hoc commands are powerful for immediate, single-task automation, offering quick feedback and a flexible way to interact with devices.
