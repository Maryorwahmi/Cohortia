Key Inventory Variables
ansible_hostIP address or hostname of the device.
ansible_network_osSpecifies the network platform (e.g., `ios`, `nxos`).
ansible_userUsername for SSH access.
ansible_passwordPassword for SSH access (use Vault!).
ansible_becomeEnable privilege escalation (e.g., `yes`).
ansible_become_methodMethod for escalation (e.g., `enable` for Cisco).
ansible_become_passPassword for privilege escalation (use Vault!).
Connectivity

Variables like `ansible_host` and `ansible_user` define how Ansible establishes its initial SSH connection.

Security Note

Always use Ansible Vault to encrypt sensitive data like passwords, never hardcode them in plain text in your inventory.

Network OS

`ansible_network_os` is crucial for Ansible to select the correct modules and connection plugins for device interaction.

Key Takeaway

Properly configuring inventory variables, especially with Ansible Vault for sensitive data, is fundamental for secure and effective network automation.
