Essential Ansible Terminology

Foundational Concepts for Network Automation

Control Node

The machine where Ansible is installed and from which all automation tasks are executed.

Inventory File

A file (INI or YAML) that defines managed hosts, their groups, and associated variables for Ansible.

Ad-hoc Command

A single-line Ansible command executed directly from the command line for quick, one-off tasks.

Chapter Summary

These core components enable you to establish your Ansible environment and perform initial, direct interactions with your network devices.
