Module 5›Chapter 5.2›`ios_facts` Module
Ad-hoc Command
ansible cisco_router_1 -i inventory.yml -m ios_facts -k

# Or, with SSH keys and Vault for enable password:
ansible cisco_router_1 -i inventory.yml -m ios_facts --ask-become-pass
Example Output Snippet (JSON)
"ansible_facts": {
  "ansible_net_hostname": "cisco_router_1",
  "ansible_net_version": "16.09.05",
  "ansible_net_model": "CSR1000V",
  "ansible_net_interfaces": {
    "GigabitEthernet1": {
      "description": "WAN Link",
      "ipv4": [{"address": "192.168.1.101", "subnet": "24"}]
    }
  }
}
Module Purpose

Gathers extensive operational facts (hostname, version, interfaces) from Cisco IOS-XE devices.

Output Structure

Returns structured JSON data, making it easy to parse and use in further automation or reporting.

Password Prompts

Use `-k` for SSH password and `--ask-become-pass` for enable password when not using Vault or SSH keys.

Key Takeaway

The `ios_facts` module is invaluable for dynamic inventory, pre-deployment checks, and gaining a comprehensive understanding of your network's current state.
