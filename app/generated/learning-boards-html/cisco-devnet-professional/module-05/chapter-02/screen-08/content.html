Module 5›Chapter 5.2›YAML Inventory
inventory.yml
---
all:
  hosts:
    cisco_router_1:
      ansible_host: 192.168.1.101
      ansible_network_os: ios
    cisco_switch_1:
      ansible_host: 192.168.1.102
      ansible_network_os: ios
  vars:
    ansible_user: admin
    ansible_password: "{{ vault_password }}"
    ansible_become: yes
    ansible_become_method: enable
    ansible_become_pass: "{{ vault_enable_password }}"
YAML Structure

Uses indentation to define hierarchy. The `all` group contains all hosts and global variables.

Host Definition

Each device is listed under `hosts` with its unique name, IP address (`ansible_host`), and network OS type.

`ansible_network_os`

Crucial variable that tells Ansible which platform-specific modules (e.g., `ios`, `nxos`) to use for communication.

Key Takeaway

A well-structured YAML inventory file is essential for Ansible to correctly identify, connect to, and manage your network devices.
