Terminal Command & Output
ansible --version

# Example Output:
ansible [core 2.15.5]
  config file = None
  configured module search path = ['/home/user/.ansible/plugins/modules', '/usr/share/ansible/plugins/modules']
  ansible python location = /home/user/ansible_env/bin/python
  ansible collection location = /home/user/.ansible/collections:/usr/share/ansible/collections
  executable location = /home/user/ansible_env/bin/ansible
  python version = 3.9.18 (main, Sep 11 2023, 13:39:18) [GCC 11.2.0]
  jinja version = 3.1.2
  libyaml = True
Command Purpose

Confirms Ansible is installed and accessible, displaying its version and environment details.

Output Details

Shows Ansible core version, Python version, executable path, and module locations, vital for troubleshooting.

Troubleshooting Tip

If the command fails, ensure your Python virtual environment is activated and Ansible was installed correctly within it.

Key Takeaway

Always verify your Ansible installation with `ansible --version` to confirm readiness and gather essential environment information.
