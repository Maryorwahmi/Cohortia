Module 5›Chapter 5.2›Basic Playbook
first_playbook.yml
---
- name: Configure basic settings on Cisco devices
  hosts: all
  gather_facts: no
  connection: network_cli

  tasks:
    - name: Configure MOTD banner
      ios_config:
        lines:
          - banner motd #
          - Welcome to the Cohortia Network!
          - Unauthorized access is prohibited.
          - #
        match: exact
        replace: yes

    - name: Configure NTP server
      ios_config:
        lines:
          - ntp server 10.0.0.1 prefer
          - ntp server 10.0.0.2
        parents: "config"
        before:
          - no ntp server 10.0.0.3
        after:
          - logging host 10.0.0.10
Playbook Structure

Defines a descriptive `name`, targets `hosts`, and lists `tasks` to be executed on those hosts.

`ios_config` Module

A powerful module for declaratively managing configuration lines on Cisco IOS-XE devices, ensuring desired state.

Idempotent Lines

The `lines` argument specifies configuration commands, and `ios_config` ensures they are applied only if needed, preventing redundant changes.

Key Takeaway

Playbooks, using modules like `ios_config`, enable declarative and idempotent configuration, ensuring your network devices consistently match their desired state.
