Protecting Credentials with Ansible Vault

Encrypting Sensitive Data in Your Automation

What it is

Ansible Vault encrypts sensitive data like passwords, API keys, or private certificates.

How it works

Encrypted content is unreadable without the correct vault password, which is prompted at runtime.

Why it matters

Prevents storing sensitive information in plain text, mitigating critical security vulnerabilities.

Key Takeaway

Ansible Vault is a fundamental tool for building secure and compliant automation solutions.

Vaulted Variable Example

Referencing encrypted passwords in `group_vars`

`group_vars/cisco_ios_devices.yml` (Partial)
---
ansible_user: admin
ansible_become: yes
ansible_become_method: enable
ansible_password: "{{ vault_ssh_password }}" # Encrypted SSH password
ansible_become_pass: "{{ vault_enable_password }}" # Encrypted enable password
`vault_ssh_password` and `vault_enable_password` are stored securely in an Ansible Vault file.
Executing with Vault
ansible-playbook my_playbook.yml --ask-vault-pass
Ansible prompts for the vault password to decrypt variables.
