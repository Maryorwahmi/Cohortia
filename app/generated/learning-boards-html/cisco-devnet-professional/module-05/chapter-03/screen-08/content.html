Controlling Task Flow with Conditionals

Executing Tasks Based on Specific Conditions

What it is

Conditionals allow tasks to run only if certain criteria are met, using the `when:` keyword.

Purpose

Enables dynamic behavior, adapting playbooks to varying network states or device types.

Benefit

Prevents unnecessary tasks from running, saving time and avoiding errors on inapplicable devices.

Key Takeaway

Conditionals make your playbooks smarter and more resilient by introducing decision-making logic.

Conditional Task Example

Configuring Loopback0 only on routers

- name: Configure Loopback0 on router if it's a router
  ios_config:
    parents: "interface Loopback0"
    lines:
      - description Router_Loopback
      - ip address {{ router_loopback_ip }} 255.255.255.255
      - no shutdown
  when: ansible_network_os == 'ios' and 'router' in inventory_hostname
This task runs only if the device OS is IOS and its hostname contains 'router'.
Common Mistake

Overly complex `when` conditions can be hard to debug. Keep them simple or break them down.
