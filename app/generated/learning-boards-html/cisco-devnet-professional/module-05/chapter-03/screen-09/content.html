Streamlining Configurations with Loops

Applying Similar Settings Across Multiple Items

What it is

Loops allow a task to be repeated for each item in a list, reducing repetitive code.

Purpose

Efficiently apply similar configurations multiple times with slightly different values.

Benefit

Significantly reduces playbook length, improves readability, and scales effortlessly.

Key Takeaway

Loops are crucial for concise and scalable playbooks when configuring numerous similar network elements.

Looping VLAN Configurations

Applying multiple VLANs with a single task

- name: Configure multiple VLANs
  ios_config:
    lines:
      - "vlan {{ item.id }}"
      - "name {{ item.name }}"
    parents: "config"
  loop:
    - { id: 10, name: "DATA" }
    - { id: 20, name: "VOICE" }
    - { id: 30, name: "MANAGEMENT" }
This task iterates through the list, configuring VLANs 10, 20, and 30.
Common Mistake

Using loops for tasks better handled by specialized modules designed for bulk operations.
