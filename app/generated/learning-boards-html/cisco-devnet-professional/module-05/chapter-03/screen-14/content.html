Role Integration

Deploying Configurations with Roles

Referencing and Utilizing Predefined Roles

How to use

Reference a role by its name in the `roles:` section of your playbook.

Execution Flow

Ansible automatically executes `tasks/main.yml` within the specified role's directory.

Variable Overrides

Role `defaults/main.yml` variables can be overridden by group or host variables.

Key Takeaway

Roles simplify playbooks by abstracting complex logic into reusable, customizable units.

Playbook Using a Role

Deploying OSPF configuration via `my_network_role`

---
- name: Deploy OSPF configuration using a role
  hosts: cisco_routers
  roles:
    - my_network_role
This playbook applies all tasks within `my_network_role` to `cisco_routers`.
Pro Tip

Always test role deployments thoroughly in a lab environment to catch variable resolution issues.
