Core Concept

Dynamic Configurations with Variables

Making Playbooks Reusable and Adaptable

Definition

Variables are placeholders for values, allowing you to avoid hardcoding data directly into tasks or templates.

Purpose

They enable a single playbook to be applied across many devices or environments by simply changing variable values.

Benefit

Reduces repetitive code, improves maintainability, and minimizes human error in deployments.

Key Takeaway

Variables are the foundation for flexible, scalable, and maintainable Ansible automation.

Variables in Action

From hardcoded to dynamic configuration

Hardcoded Configuration
- name: Configure Interface Gi0/1
  ios_config:
    lines:
      - description "Uplink to Core"
      - ip address 10.1.1.1 255.255.255.0
Dynamic Configuration with Variables
- name: Configure Interface {{ interface_name }}
  ios_config:
    lines:
      - description "{{ interface_description }}"
      - ip address {{ ip_address }} {{ subnet_mask }}
Variables like `interface_name`, `ip_address`, `subnet_mask` are defined elsewhere.
