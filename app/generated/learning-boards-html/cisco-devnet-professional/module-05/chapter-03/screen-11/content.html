Practical Application

Integrating Templates into Your Playbooks

Rendering Configurations with `ios_config`

How it works

Ansible renders the `.j2` template on the control node, substituting variables, then applies the generated config.

Module Usage

Network modules like `ios_config` use the `src` parameter to specify the Jinja2 template file.

Variable Sourcing

Template variables can come from task `vars:`, inventory, group, or host variables.

Key Takeaway

Templates enable consistent configuration patterns with dynamic values, maximizing reusability.

Playbook Using Jinja2 Template

Configuring GigabitEthernet0/1 dynamically

- name: Configure GigabitEthernet0/1 using a template
  ios_config:
    src: interface_config.j2
    vars:
      interface_name: GigabitEthernet0/1
      interface_description: "Uplink to Core"
      ip_address: 10.1.1.1
      subnet_mask: 255.255.255.0
This task uses `interface_config.j2` and provides variables for rendering.
Pro Tip

Always test your templates in a lab environment to verify the generated configuration before deployment.
