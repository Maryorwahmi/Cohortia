Understanding IaC State Management

State files are crucial for IaC tools to track deployed resources, detect drift, and plan future changes.

Why State Files are Critical
  • Resource Tracking: Records what resources are deployed.
  • Drift Detection: Identifies manual changes outside IaC.
  • Change Planning: Informs what to create, update, or destroy.
  • Source of Truth: Represents the actual state of managed infrastructure.
Key Takeaway

Proper state management is essential for IaC, ensuring consistency, preventing conflicts, and enabling reliable infrastructure operations.

Example

A Terraform state file (`terraform.tfstate`) maps your HCL code to the actual network interfaces, VLANs, and routes deployed on your devices.

IaC State Flow
1. Desired State (Code)

Your HCL or YAML definitions.

2. IaC Tool (e.g., Terraform)

Compares code with state file.

3. State File (e.g., .tfstate)

Records actual deployed infrastructure.

4. Actual Network Infrastructure

The physical or virtual devices.
