Desired State: Declarative Configuration

The declarative approach focuses on defining the desired end-state of the network, letting the tool manage the execution.

Key Characteristics
  • Focus on 'What': Describes the target configuration.
  • Tool Intelligence: Automation tool determines execution steps.
  • Idempotent by Nature: Repeated application yields same result.
  • Simplified Logic: Less need for complex conditional scripting.
Key Takeaway

Declarative IaC simplifies automation by focusing on the desired outcome, making configurations more robust and easier to manage.

Example Scenario

You declare that a specific firewall rule should allow traffic on port 80. The IaC tool checks if the rule exists, and if not, creates it. If it exists but is misconfigured, it corrects it.

Declarative Flow
1. Define Desired State (Code)

e.g., VLAN 10, Name: 'Users'

2. IaC Tool Compares States

Compares desired state with current network state.

3. Tool Executes Necessary Changes

Only applies commands required to reach desired state.

4. Network Reaches Desired State

Consistent and idempotent outcome.
