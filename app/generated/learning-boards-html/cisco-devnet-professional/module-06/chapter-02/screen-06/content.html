Declarative vs. Imperative Approaches

Understanding the core philosophies that drive Infrastructure as Code configuration.

A

Declarative Approach

Focuses on what the desired end-state of the infrastructure should be. The tool figures out the steps.

Example

"VLAN 10 should exist with name 'Users'." The IaC tool determines if VLAN 10 exists and creates/modifies it as needed.

Analogy

Ordering a pizza: You state what you want (a large pepperoni pizza), and the pizzeria handles the 'how'.

B

Imperative Approach

Focuses on how to achieve a state, detailing every step in a specific sequence.

Example

"SSH to router, enter config mode, create interface, assign IP, enable interface." Each command is explicitly given.

Analogy

Following a recipe: You are given step-by-step instructions (chop onions, sauté, add tomatoes) to achieve the final dish.

Key Takeaway

Declarative IaC simplifies automation by focusing on the desired outcome, while imperative IaC provides granular control over execution steps.
