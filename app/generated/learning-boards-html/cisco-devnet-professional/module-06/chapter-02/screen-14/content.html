Key Concepts

Essential terms to remember from this chapter on Infrastructure as Code for Networks.

Infrastructure as Code (IaC)

Managing and provisioning infrastructure through machine-readable definition files, rather than manual configuration.

Declarative Configuration

Defining the desired end-state of the infrastructure, letting the automation tool determine the steps to achieve it.

Imperative Configuration

Specifying the exact sequence of commands or steps that must be executed to reach a desired state.

Summary Takeaway

IaC transforms network management by codifying infrastructure, with declarative and imperative approaches offering distinct ways to define and achieve desired network states.
