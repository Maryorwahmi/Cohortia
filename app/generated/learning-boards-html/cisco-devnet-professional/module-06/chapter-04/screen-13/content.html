Ansible Vault: Encrypting Sensitive Data

Protecting credentials within Ansible playbooks and variable files.

What is Ansible Vault?

Ansible's built-in feature for encrypting sensitive data (like passwords or API keys) within playbooks, roles, or variable files.

How to Use It

Use ansible-vault create to encrypt files. Store sensitive variables inside. Decrypt at runtime with --ask-vault-pass or a vault password file.

Benefits

Allows sensitive data to be safely committed to version control, protecting it at rest and only decrypting it during playbook execution.

Key Takeaway

Ansible Vault is essential for securing credentials and other sensitive information in your Ansible automation.

Ansible Vault Workflow

# 1. Create an encrypted file for group variables
ansible-vault create group_vars/ios_routers.yml

# Content inside group_vars/ios_routers.yml (encrypted)
---
ansible_password: your_ssh_password_here
ansible_become_pass: your_enable_password_here

# 2. Example inventory.ini
[ios_routers]
your_router_ip_or_hostname

[all:vars]
ansible_network_os=ios
ansible_user=your_ssh_username
ansible_become=yes
ansible_become_method=enable

# 3. Run playbook, prompting for vault password
ansible-playbook -i inventory.ini test_connection.yml --ask-vault-pass
