Code Integrity

Managing Dependencies and Command Execution

Securing third-party libraries and preferring native modules.

Dependency Management

Regularly update and scan third-party libraries and modules for known vulnerabilities. Use tools like pip freeze and pip-audit for Python.

Avoid Raw Shell Commands

Where possible, use native modules (e.g., cisco.ios.ios_config) instead of generic command or shell modules, as native modules offer better security and idempotency.

Pro-Tip: Strict Input Control

If command or shell is unavoidable, ensure all inputs are strictly controlled, validated, and sanitized to prevent injection attacks.

Key Takeaway

Maintain a secure software supply chain and prioritize native, secure modules over raw command execution.

Dependency Scanning (Python)

# Generate a list of installed packages
pip freeze > requirements.txt

# Audit for known vulnerabilities
pip-audit -r requirements.txt
