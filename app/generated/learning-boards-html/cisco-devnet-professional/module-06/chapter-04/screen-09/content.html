Secure Development

Writing Robust Automation Scripts

Validating inputs and handling errors gracefully to prevent vulnerabilities.

Input Validation

Never trust user input or data from external sources. Always validate and sanitize inputs to prevent injection attacks (e.g., command, SQL injection).

Robust Error Handling

Implement graceful error management to prevent crashes and avoid leaving devices in inconsistent states. Log errors securely without exposing sensitive data.

Example: Input Sanitization

If expecting a number, ensure the input is indeed numeric before using it in a command or calculation. Reject or clean unexpected characters.

Key Takeaway

Validate all inputs and implement comprehensive error handling to build resilient and secure automation scripts.

import re

def validate_interface_name(name):
    # Example: Only allow alphanumeric and hyphen for interface names
    if re.match(r"^[a-zA-Z0-9-]+", name):
        return True
    return False

def configure_interface(interface_name, ip_address):
    if not validate_interface_name(interface_name):
        print(f"Error: Invalid interface name: {interface_name}")
        return
    # ... proceed with configuration if valid ...
    print(f"Configuring {interface_name} with {ip_address}")

# Example usage
configure_interface("GigabitEthernet1/0/1", "192.168.1.1")
configure_interface("GigabitEthernet1/0; rm -rf /", "10.0.0.1")
