Ansible Troubleshooting

Diagnosing Ansible Connection Failures

A systematic approach to resolving SSH and network connectivity problems.

1. Network Reachability

Is the target device reachable from the Ansible control node? Use `ping` to verify basic IP connectivity. If it fails, check physical connections, routing, and basic network configuration.

2. SSH Credentials & Keys

Are `ansible_user` and `ansible_password` (or SSH keys) correct in your inventory or vault? Attempt a manual SSH connection to confirm credentials and SSH service on the device.

Key Takeaway

Systematically check network reachability, SSH credentials, `ansible_network_os`, and firewalls to quickly resolve Ansible connection failures.

3. `ansible_network_os`

Ensure the `ansible_network_os` variable is correctly specified for the target device in your inventory. An incorrect OS type can cause Ansible to use the wrong connection plugin or modules.

4. Firewall Rules

Check if any firewalls (network-based or host-based) are blocking SSH traffic (port 22) between the Ansible control node and the target device. Review firewall logs if available.
