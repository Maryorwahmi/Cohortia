Ansible Debugging

Gaining Insight with Verbosity and the `debug` Module

Uncovering hidden details during playbook execution.

Increased Verbosity (`-v`, `-vvv`)

Adding `-v` (or `-vvv`, `-vvvv`) to your `ansible-playbook` command increases the detail of the output. This reveals more about module execution, SSH connections, and API calls, helping to diagnose underlying issues.

ansible-playbook my_playbook.yml -vvv
Key Takeaway

Verbosity and the `debug` module provide granular insight into playbook execution, essential for diagnosing complex or hidden issues.

The `debug` Module

Ansible's `debug` module allows you to print variables, messages, or the results of tasks to the console during playbook execution. It's invaluable for inspecting data, verifying conditional logic, and understanding task outputs.

- name: Display a variable
  debug:
    var: my_variable

- name: Display a custom message
  debug:
    msg: "The interface status is {{ interface_status }}"
Example Output (`debug`)
TASK [Display a variable] **************************************
ok: [router1] => {
    "my_variable": "value_from_previous_task"
}

This output confirms the value of `my_variable` at that point in the playbook execution.
