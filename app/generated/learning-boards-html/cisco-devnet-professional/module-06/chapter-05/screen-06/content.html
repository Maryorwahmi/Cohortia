Python Debugging

Stepping Through Code with `pdb`

Using Python's built-in debugger for in-depth analysis.

Code with `pdb.set_trace()`
def calculate_total(price, quantity):
    # Simulate a complex calculation
    intermediate_value = price * quantity
    import pdb; pdb.set_trace() # Breakpoint here
    tax_rate = 0.05
    total = intermediate_value * (1 + tax_rate)
    return total

item_price = 100
item_quantity = 2
final_amount = calculate_total(item_price, item_quantity)
print(f"Final amount: {final_amount}")

How `pdb` Works

`pdb` is Python's interactive source code debugger. By inserting `pdb.set_trace()` into your script, execution pauses at that point, and you gain a command-line interface to inspect variables, step through code, and evaluate expressions. This is invaluable for understanding runtime state.

Key `pdb` Commands

  • `n` (next): Execute current line, stop at next line in current function.
  • `s` (step): Execute current line, stop at next line, stepping into called functions.
  • `c` (continue): Continue execution until next breakpoint or end of program.
  • `p <variable>`: Print the value of a variable.
  • `l` (list): List source code around the current line.
Key Takeaway

`pdb` allows you to interactively explore your script's execution, providing granular control and visibility into variable states at any point.
