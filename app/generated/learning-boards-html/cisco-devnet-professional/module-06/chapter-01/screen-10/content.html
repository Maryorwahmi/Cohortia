Scalable Automation with Ansible Variables

Separate data from logic for reusable playbooks.

Where to Define Variables

  • Inventory File: For host-specific or group-specific variables.
  • `group_vars/`: Directory for variables applying to entire groups.
  • `host_vars/`: Directory for variables unique to individual hosts.
  • Playbook: Directly within the playbook (less common for reusability).

Benefits of Variable Usage

Variables make playbooks generic and adaptable. A single playbook can configure many devices with different parameters, reducing code duplication and improving maintainability. This is essential for managing large and complex network infrastructures efficiently.

Example: Host-Specific Variables
# host_vars/router1.example.com.yml
loopback_ip: 192.168.1.1/32

# host_vars/router2.example.com.yml
loopback_ip: 192.168.1.2/32

# In your playbook (e.g., configure_loopback.yml)
---
- name: Configure Loopback Interface
  hosts: ios_routers
  tasks:
    - name: Ensure Loopback0 is configured
      cisco.ios.ios_config:
        lines:
          - ip address {{ loopback_ip }}
        parents: "interface Loopback0"
Pro-Tip

Use `ansible-inventory --list` to inspect your inventory and verify that variables are being loaded correctly for your hosts and groups.
