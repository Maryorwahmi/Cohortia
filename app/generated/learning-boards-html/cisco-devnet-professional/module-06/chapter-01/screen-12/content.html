Practical: Configure VLANs with Ansible

Apply your knowledge to a real-world scenario.

Scenario: VLAN Configuration

You need to create two new VLANs (VLAN 10 for "Users" and VLAN 20 for "Servers") on a Cisco IOS-XE router using Ansible.

Instructions

  1. Create an `inventory.ini` file for your Cisco IOS-XE device.
  2. Create a playbook named `configure_vlans.yml`.
  3. Use `cisco.ios.ios_config` to add VLAN 10 and VLAN 20.
  4. Run the playbook and verify VLANs on your device.
Key Takeaway

Hands-on practice with Ansible playbooks and modules is essential for building practical network automation skills.

Starter Code
# inventory.ini
[ios_routers]
your_router_ip_or_hostname

[all:vars]
ansible_network_os=ios
ansible_user=your_ssh_username
ansible_password=your_ssh_password
ansible_become=yes
ansible_become_method=enable
ansible_become_pass=your_enable_password

# configure_vlans.yml
---
- name: Configure VLANs on Cisco IOS-XE
  hosts: ios_routers
  gather_facts: no

  tasks:
    - name: Create VLAN 10 and VLAN 20
      cisco.ios.ios_config:
        lines:
          - name Users
        parents: "vlan 10"
      # TODO: Add configuration for VLAN 20 here following the same pattern
      # ...
      register: vlan_result

    - name: Display VLAN configuration changes
      debug:
        var: vlan_result.updates
