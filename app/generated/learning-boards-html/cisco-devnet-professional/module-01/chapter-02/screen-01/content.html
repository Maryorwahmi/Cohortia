Core Concepts of Network Programmability and APIs

Unlocking Automation with APIs and Data Models

Key Idea

APIs provide a structured way for software to interact with network devices, moving beyond manual CLI commands to enable powerful automation.

This chapter introduces the fundamental concepts of network programmability, focusing on various API types like REST, NETCONF, and gRPC. It explores the critical role of data models, particularly YANG, in structuring network configuration and state data. Learners will also understand how data is represented using JSON and XML, and master the essential CRUD operations for interacting with network APIs.
