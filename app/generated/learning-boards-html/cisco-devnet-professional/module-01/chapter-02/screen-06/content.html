NETCONF: The Network Configuration Standard

IETF Standard for Secure, Structured Device Management

Key Characteristics of NETCONF

  • IETF Standard: Specifically designed for network configuration.
  • Secure Transport: Typically uses SSH for connection-oriented communication.
  • Transactional: Changes are committed or rolled back as a single unit.
  • Structured Data: Clear separation of configuration, state, and RPC operations.

Example: Configuring an Interface

A NETCONF <edit-config> operation to set an interface description:

<rpc message-id="101"><edit-config><target><running/></target><config><interfaces xmlns="urn:ietf:params:xml:ns:yang:ietf-interfaces"><interface><name>GigabitEthernet1</name><description>Uplink to Core</description></interface></interfaces></config></edit-config></rpc>

This XML payload is sent over the secure NETCONF session.

Why NETCONF is Preferred for Configuration

  • Ensures configuration integrity with transactional capabilities.
  • Strong schema validation with XML prevents malformed configurations.
  • Designed for robust, mission-critical network changes.
  • Vendor-agnostic standard for device management.
Key Takeaway

NETCONF is an IETF standard protocol providing a secure, transactional, and highly structured approach to network device configuration, ideal for critical operations.
