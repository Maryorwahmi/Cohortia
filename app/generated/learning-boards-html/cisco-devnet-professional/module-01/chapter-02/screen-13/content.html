API Actions

Performing CRUD Operations with Network APIs

Mapping Actions to HTTP Methods for Resource Control

Create (POST)

Used to add a new resource to the network device.

  • Example: Provisioning a new VLAN or adding a new user account.

Read (GET)

Used to retrieve information about existing resources.

  • Example: Fetching the status of an interface or listing routing protocols.

Update (PUT/PATCH)

Used to modify an existing resource.

  • PUT: Replaces the entire resource.
  • PATCH: Applies partial modifications (e.g., changing an interface description).

Delete (DELETE)

Used to remove a resource from the network device.

  • Example: De-provisioning a VLAN or deleting a firewall rule.
Key Takeaway

CRUD operations map directly to HTTP methods (POST, GET, PUT/PATCH, DELETE), providing a standardized way to programmatically manage the lifecycle of network resources via APIs.
