Data Format

JSON: Human-Readable Data for API Interactions

Key-Value Pairs and Arrays for Simplicity

Key Characteristics of JSON

  • Lightweight: Minimal syntax, efficient for data transfer.
  • Human-Readable: Easy to understand and write.
  • Key-Value Pairs: Data represented as attribute-value pairs (e.g., "name": "GigabitEthernet1").
  • Arrays: Ordered lists of values (e.g., ["vlan10", "vlan20"]).

Why JSON is Widely Adopted

  • De facto standard for web APIs (REST).
  • Easy to parse and generate in most programming languages (e.g., Python).
  • Less verbose than XML, leading to smaller payloads.
  • Flexible for various data structures.

Example: Interface Configuration in JSON

{  "interface": {    "name": "GigabitEthernet1",    "description": "Uplink to Distribution",    "enabled": true,    "ip_address": "192.168.1.1/24"  }}

This JSON payload configures a network interface with its properties.

Key Takeaway

JSON is a lightweight, human-readable data interchange format using key-value pairs and arrays, making it the preferred choice for many modern network REST APIs.
