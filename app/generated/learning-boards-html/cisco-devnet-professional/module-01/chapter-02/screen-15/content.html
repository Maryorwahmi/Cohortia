Key Concepts

Essential terms to remember

Data Model

A formal description of the structure and semantics of data, defining how network configuration and state information is organized.

YANG

An IETF standard data modeling language used to define configuration and state data for network devices, providing a common structure for APIs.

CRUD Operations

The four basic functions of persistent storage: Create, Read, Update, and Delete, which map directly to common API actions.

Summary Takeaway

Data models like YANG provide the essential structure for network data, while CRUD operations define the universal actions for programmatic interaction with network resources.
