Learning Objectives

Skills You'll Master in This Chapter

LearnUnderstandApplyMaster
01

Install Python & `pip`

Learn to correctly install Python and its package manager, `pip`, ensuring they are accessible from your command line. This is the first step to running any Python-based automation script.

VERIFIED COMPETENCY MILESTONE
02

Manage Virtual Environments

Understand how to create and activate isolated Python environments to prevent dependency conflicts across your projects. This ensures a clean and stable development workflow.

VERIFIED COMPETENCY MILESTONE
03

Use `requests` Library

Utilize the `requests` library in Python to make basic HTTP GET requests to public APIs. This is your programmatic gateway to interacting with network devices and services.

VERIFIED COMPETENCY MILESTONE
04

Configure Postman & Sandboxes

Install and configure Postman for API testing and understand how to access Cisco DevNet Sandboxes for hands-on practice. These tools are vital for both quick tests and in-depth development.

VERIFIED COMPETENCY MILESTONE
