Python `requests` GET Example (Part 2)

import requests

api_url = "https://jsonplaceholder.typicode.com/todos/1"

try:
    response = requests.get(api_url)
    response.raise_for_status()

    # Check if the request was successful (HTTP status code 200)
    if response.status_code == 200:
        data = response.json() # Parse JSON response
        print("Successfully retrieved data:")
        print(f"User ID: {data['userId']}")
        print(f"Title: {data['title']}")
        print(f"Completed: {data['completed']}")
    else:
        print(f"Error: Received status code {response.status_code}")

except requests.exceptions.RequestException as e:
    print(f"An error occurred: {e}")
Code Explanation

The response.json() method converts the JSON response body into a Python dictionary. The try...except block handles network-related errors gracefully.

Understanding the Response

  • 1
    Status Code Check: Verifies response.status_code == 200 for successful retrieval.
  • 2
    JSON Parsing: response.json() converts the raw JSON into a usable Python dictionary.
  • 3
    Data Access: Access specific data fields using dictionary keys, e.g., data['title'].
  • 4
    Error Handling: The except block catches network-related issues, preventing script crashes.
Key Takeaway

Effective API interaction involves not only sending requests but also correctly parsing responses and implementing robust error handling.
