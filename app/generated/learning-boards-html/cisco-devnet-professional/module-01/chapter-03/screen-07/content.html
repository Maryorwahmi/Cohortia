Steps to Manage Your Environment

  • 1
    Navigate to Project Directory: Use cd my_project to enter your project folder.
  • 2
    Create Virtual Environment: Run python -m venv venv. This creates a folder named 'venv' containing the isolated Python installation.
  • 3
    Activate Environment: This step is OS-dependent.
  • 4
    Install Packages: While active, use pip install <package> to install libraries only within this environment.
  • 5
    Deactivate Environment: When done, type deactivate to return to your global Python.
Common Mistake

Forgetting to activate the virtual environment before installing packages. This leads to global installations and potential conflicts.

Activation Commands

For Windows:

.\venv\Scripts\activate

For macOS / Linux:

source venv/bin/activate

You'll see the environment name in your prompt:

(venv) user@hostname:~/my_project$
Pro Tip

Always activate your virtual environment before starting work on a project to ensure dependency isolation.

Key Takeaway

Creating and activating a virtual environment is a simple yet powerful way to manage project-specific Python dependencies.
