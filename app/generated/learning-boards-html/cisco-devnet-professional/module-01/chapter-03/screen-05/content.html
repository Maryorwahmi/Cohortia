Python Installation Steps

  • 1
    Download Python: Get the installer for Python 3.8+ from python.org.
  • 2
    Run Installer: Follow the on-screen prompts.
  • 3
    Crucial Step: Add to PATH: Check the box that says "Add Python to PATH" during installation. This makes Python and `pip` accessible from your terminal.
  • 4
    Complete Installation: Finish the setup process.
Common Mistake

Forgetting to add Python to PATH. This prevents you from running Python commands directly from the terminal.

Verify Installation in Terminal

Open your terminal or command prompt and run:

python --version

Expected output (version may vary):

Python 3.9.7

Then verify `pip`:

pip --version

Expected output (version may vary):

pip 21.2.4 from ... (python 3.9)
Troubleshooting `pip`

If `pip` is not found, try running python -m ensurepip or reinstall Python.

Key Takeaway

Always verify Python and `pip` installations from the command line to confirm they are correctly configured and accessible.
