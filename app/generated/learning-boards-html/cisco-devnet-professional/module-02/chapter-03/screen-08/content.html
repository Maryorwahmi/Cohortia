`requests` for Data Submission and Robustness

Sending Data and Managing API Responses

POST Request Essentials
  • Use requests.post() to send data.
  • Pass JSON data via the json= parameter.
  • Specify Content-Type: application/json in headers.
  • Crucial for creating/updating resources on APIs.
Robust Error Handling
  • response.raise_for_status() for HTTP errors (4xx/5xx).
  • Catch requests.exceptions.ConnectionError for network issues.
  • Catch requests.exceptions.Timeout for slow responses.
  • Use requests.exceptions.RequestException as a general catch-all.
Key Takeaway

Mastering POST requests and comprehensive error handling with requests ensures your automation scripts can reliably interact with and manage API-driven network services.

requests Example: POST Request & Error Handling
import requests

post_url = "https://jsonplaceholder.typicode.com/posts"
new_post_data = {"title": "DevNet Automation", "userId": 1}
headers = {"Content-Type": "application/json"}

try:
    post_response = requests.post(post_url, json=new_post_data, headers=headers)
    post_response.raise_for_status()
    print(f"Post successful! Status: {post_response.status_code}")
    print(f"Created ID: {post_response.json().get('id')}")
except requests.exceptions.HTTPError as e:
    print(f"HTTP Error: {e.response.status_code}")
except requests.exceptions.ConnectionError as e:
    print(f"Connection Error: {e}")
except requests.exceptions.RequestException as e:
    print(f"An unexpected Requests error occurred: {e}")
Pro Tip: Always include Content-Type header for POST requests with JSON data.
