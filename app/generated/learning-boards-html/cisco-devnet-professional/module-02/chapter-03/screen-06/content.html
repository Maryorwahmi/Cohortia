Robust `subprocess` Error Handling

Ensuring Reliable Command Execution

Common Error: CalledProcessError

Occurs when the external command runs but returns a non-zero exit code, indicating a failure (e.g., ping fails to reach host). Handled by check=True.

Common Error: FileNotFoundError

Occurs if the command executable itself (e.g., ping, ls) is not found in the system's PATH. This means the OS cannot locate the program.

Key Takeaway

Always use try-except blocks with subprocess calls to catch CalledProcessError and FileNotFoundError, making your scripts resilient to execution issues.

Robust Error Handling Example
import subprocess

target_ip = "192.168.1.99" # Example unreachable IP
try:
    result = subprocess.run(
        ["ping", "-c", "1", target_ip],
        capture_output=True, text=True, check=True
    )
    print(f"Ping successful: {result.stdout}")
except subprocess.CalledProcessError as e:
    print(f"Ping failed for {target_ip}. Error: {e.stderr}")
except FileNotFoundError:
    print("Error: 'ping' command not found. Check your PATH.")
except Exception as e:
    print(f"An unexpected error occurred: {e}")
Tip: Use a general Exception catch-all for any other unforeseen issues.
