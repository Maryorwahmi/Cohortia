The `requests` Library

Simplifying HTTP/HTTPS Interactions for REST APIs

Why `requests`?
  • User-friendly API for HTTP/HTTPS.
  • Handles GET, POST, PUT, DELETE methods.
  • Effortlessly manages JSON data and headers.
  • Simplifies authentication (basic, token, OAuth).
Real-World Connection

requests is essential for automating tasks with Cisco DNA Center, Meraki, ACI, and other API-driven network platforms.

Key Takeaway

requests is the industry standard for Python HTTP communication, making API interactions intuitive and efficient for network automation.

requests Example: GET Request
import requests

api_url = "https://jsonplaceholder.typicode.com/posts/1"

try:
    response = requests.get(api_url)
    response.raise_for_status() # Check for HTTP errors

    data = response.json() # Parse JSON response
    print(f"Title: {data['title']}")
    print(f"Body: {data['body'][:50]}...")

except requests.exceptions.RequestException as e:
    print(f"An error occurred: {e}")
Tip: response.json() converts the JSON response body into a Python dictionary.
