The `os` Module

Bridging Python with the Operating System

Definition

The os module provides a way to use operating system-dependent functionality, such as file path manipulation, directory creation, and environment variable access.

Key Use Cases
  • Checking file or directory existence (os.path.exists())
  • Creating and removing directories (os.mkdir(), os.rmdir())
  • Accessing environment variables (os.getenv())
Key Takeaway

The os module is fundamental for making Python scripts aware of and interactive with their execution environment, enhancing robustness and security.

os Module Example: File Check & Environment Variable
import os

config_file = "router_config.txt"
if os.path.exists(config_file):
    print(f"'{config_file}' found.")
else:
    print(f"Error: '{config_file}' not found.")

# Accessing environment variables for security
api_key = os.getenv("DNA_CENTER_API_KEY")
if api_key:
    print("API Key loaded from environment.")
else:
    print("Warning: API Key not set.")
Pro Tip: Use os.getenv() to avoid hardcoding sensitive credentials directly in your scripts.
