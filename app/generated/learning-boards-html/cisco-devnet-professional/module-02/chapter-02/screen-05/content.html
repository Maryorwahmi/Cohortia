# Python List of Dictionaries for Network Devices
network_devices = [
    {
        "hostname": "CoreRouter1",
        "ip_address": "10.0.0.1",
        "os": "IOS-XE",
        "interfaces": [{"name": "Gi0/0", "status": "up"}, {"name": "Gi0/1", "status": "down"}]
    },
    {
        "hostname": "AccessSwitch1",
        "ip_address": "10.0.1.1",
        "os": "IOS",
        "interfaces": [{"name": "Fa0/1", "status": "up"}, {"name": "Fa0/2", "status": "up"}]
    }
]
Accessing a device's hostname:
print(network_devices[0]["hostname"])
# Output: CoreRouter1

Lists of Dictionaries for Device Inventory

Using Python's lists of dictionaries to manage multiple network devices.

Representing Collections

A list of dictionaries is ideal for collections of similar items, where each item has distinct properties, like a fleet of network devices.

Key-Value Pairs per Item

Each dictionary within the list holds key-value pairs, allowing you to store specific attributes for each individual device (e.g., hostname, IP, OS).

Iterating for Automation

This structure simplifies iterating through your inventory, enabling you to perform actions or gather data for each device efficiently.

Key Takeaway

Lists of dictionaries are a versatile Python structure for managing collections of complex, attribute-rich network entities like device inventories.
