# Nested Data Structure Example
network_devices = [
    {
        "hostname": "CoreRouter1",
        "ip_address": "10.0.0.1",
        "interfaces": [ # List of dictionaries for interfaces
            {"name": "Gi0/0", "status": "up"},
            {"name": "Gi0/1", "status": "down"}
        ]
    }
]
Accessing a nested element:
interface_name = network_devices[0]["interfaces"][0]["name"]
print(interface_name)
# Output: Gi0/0
Advanced Data Structures

Modeling Hierarchical Network Information

Deep diving into nested lists and dictionaries for intricate data.

Reflecting Real-World Hierarchy

Network data naturally forms hierarchies (e.g., device > interface > IP address). Nested structures mirror this complexity.

Chaining Access

Accessing nested elements requires a sequence of key lookups and index accesses, allowing precise data retrieval.

Foundation for APIs & Configs

Mastering nesting is crucial for parsing complex API responses and generating detailed, multi-level network configurations.

Key Takeaway

Nested data structures are indispensable for accurately representing and manipulating the hierarchical nature of network device configurations and operational states.
