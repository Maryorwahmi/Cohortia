# Python to YAML and back
import yaml

# Python dictionary (same as JSON example)
device_config_py = {
    "hostname": "BranchRouter",
    "loopback0": {"ip": "192.168.255.1", "mask": "255.255.255.255"},
    "interfaces": [
        {"name": "GigabitEthernet0/0", "description": "Uplink to Core"},
        {"name": "GigabitEthernet0/1", "description": "LAN Interface"}
    ]
}

# Serialize Python dict to YAML string
yaml_string = yaml.dump(device_config_py, sort_keys=False)
print("
--- YAML String ---")
print(yaml_string)

# Deserialize YAML string back to Python dict
yaml_data_from_file = """
hostname: BranchRouter
loopback0:
  ip: 192.168.255.1
  mask: 255.255.255.255
interfaces:
  - name: GigabitEthernet0/0
    description: Uplink to Core
  - name: GigabitEthernet0/1
    description: LAN Interface
"""
parsed_config_py_yaml = yaml.safe_load(yaml_data_from_file)
print("
--- Parsed Python Dictionary from YAML ---")
print(parsed_config_py_yaml["loopback0"]["ip"])
Python Integration

Python's `PyYAML` Library: Serialize and Deserialize

Leveraging `PyYAML` for converting Python objects to YAML and vice versa.

Serialization (`yaml.dump()`)

Converts Python objects into YAML formatted strings, often used for generating configuration files. `sort_keys=False` helps maintain order.

Deserialization (`yaml.safe_load()`)

Parses a YAML string and converts it into a Python object. `safe_load()` is recommended for security to prevent arbitrary code execution.

Installation Requirement

The `PyYAML` library needs to be installed (`pip install PyYAML`) as it's not a built-in Python module.

Key Takeaway

`PyYAML` provides the essential functions (`dump()` and `safe_load()`) for managing YAML data in Python, crucial for configuration management and secure parsing.
