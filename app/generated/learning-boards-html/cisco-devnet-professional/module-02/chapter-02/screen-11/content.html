# Writing to a file
try:
    with open("device_inventory.txt", "w") as f: # "w" for write mode (overwrites existing)
        f.write("CoreRouter1,10.0.0.1,IOS-XE
")
        f.write("AccessSwitch1,10.0.1.1,IOS
")
    print("Device inventory written to device_inventory.txt")
except IOError as e:
    print(f"Error writing to file: {e}")

File Operations

File I/O: Writing Data to Files

Storing network data with Python's `open()` function in write mode.

Write Mode (`'w'`)

Opens a file for writing. If the file exists, its contents are truncated (erased). If it doesn't exist, a new file is created.

Append Mode (`'a'`)

Opens a file for appending. Data is added to the end of the file without overwriting existing content. Creates the file if it doesn't exist.

Context Manager (`with open()`)

Ensures the file is automatically closed after operations, even if errors occur, preventing resource leaks and data corruption.

Key Takeaway

Always use `with open()` for file writing, carefully choosing between `'w'` (overwrite) and `'a'` (append) modes to manage file content safely.
