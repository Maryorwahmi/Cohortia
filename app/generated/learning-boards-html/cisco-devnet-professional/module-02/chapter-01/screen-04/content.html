Core Concept

Variables: Storing Network Data

In Python, a variable is a named storage location in memory used to hold data. Python automatically infers the data type based on the assigned value.

  • •Named Containers: Variables act as labels for data, making your code readable and manageable.
  • •Dynamic Typing: Python determines the data type at runtime, simplifying variable declaration.
  • •Network Relevance: Essential for storing dynamic network information like device IPs, hostnames, or interface states.
Key Takeaway

Variables are fundamental for holding and referencing all the dynamic information your network automation scripts need to operate effectively.

Code Example: Variable Assignment
# Storing an IP address (string)@ndevice_ip = "192.168.1.1"@n@n# Storing an interface speed (integer)@ninterface_speed = 1000@n@n# Storing a device status (boolean)@nis_online = True@n@n# Printing the values and their types@nprint(f"Device IP: {device_ip} (Type: {type(device_ip).__name__})")@nprint(f"Interface Speed: {interface_speed} (Type: {type(interface_speed).__name__})")@nprint(f"Is Online: {is_online} (Type: {type(is_online).__name__})")
Output
Device IP: 192.168.1.1 (Type: str)@nInterface Speed: 1000 (Type: int)@nIs Online: True (Type: bool)
Real-world Example

Imagine a script that collects network device inventory. Variables would store each device's hostname, management IP, operating system version, and current operational status, making this data easily accessible for reporting or further automation.
