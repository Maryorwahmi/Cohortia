Core Concept

Lists and Dictionaries

Python offers powerful data structures for organizing collections of related information:

  • •Lists (`list`): Ordered, mutable collections of items (e.g., `["Gi0/1", "Gi0/2"]`). Accessed by index.
  • •Dictionaries (`dict`): Unordered collections of key-value pairs (e.g., `{"hostname": "R1", "ip": "10.0.0.1"}`). Accessed by key.
Key Takeaway

Lists and dictionaries are indispensable for structuring complex network data, enabling efficient storage, retrieval, and manipulation of device configurations and states.

Code Example: Lists and Dictionaries
# List of active interfaces@nactive_interfaces = ["GigabitEthernet0/1", "GigabitEthernet0/2", "Loopback0"]@nprint(f"Active Interfaces: {active_interfaces}")@nprint(f"First interface: {active_interfaces[0]}")@n@n# Dictionary: Device attributes@ndevice_info = {@n    "hostname": "Router1",@n    "ip": "10.0.0.1",@n    "os": "IOS-XE"@n}@nprint(f"Device Hostname: {device_info['hostname']}")@nprint(f"Device OS: {device_info['os']}")
Output
Active Interfaces: ['GigabitEthernet0/1', 'GigabitEthernet0/2', 'Loopback0']@nFirst interface: GigabitEthernet0/1@nDevice Hostname: Router1@nDevice OS: IOS-XE
Scenario

You're building an inventory script. A list could hold all device IPs, while a dictionary could store detailed attributes for each device, like its vendor, model, and software version.
