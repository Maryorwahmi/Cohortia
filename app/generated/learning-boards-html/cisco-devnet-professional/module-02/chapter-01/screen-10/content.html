Core Concept

for Loops for Iteration

A for loop is used to iterate over a sequence (like a list, tuple, dictionary, string, or range) and execute a block of code for each item in the sequence.

  • •Sequence Traversal: Ideal for processing each item in a collection.
  • •Automating Repetition: Eliminates redundant code when performing the same action on multiple network elements.
  • •Readability: Makes code cleaner and easier to understand than manual repetition.
Key Takeaway

for loops are indispensable for automating tasks across multiple network devices or data points, making your scripts efficient and scalable.

Code Example: Iterating Device IPs
device_ips = ["192.168.1.10", "192.168.1.11", "192.168.1.12"]@n@nfor ip in device_ips:@n    print(f"Attempting to connect to device at {ip}")@n    # In a real scenario, you'd call a connection function here@n    print(f"--- Processing {ip} complete ---")@n@nprint("All devices processed.")

Network Scenario

You have a list of interface names and need to shut down each one. A for loop can iterate through the list, sending the 'shutdown' command to each interface via a network library.
