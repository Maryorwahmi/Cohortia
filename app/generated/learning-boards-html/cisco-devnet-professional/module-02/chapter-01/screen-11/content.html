Core Concept

while Loops for Continuous Operations

A while loop repeatedly executes a block of code as long as a given condition remains True.

  • •Condition-Driven: Continues execution until the condition becomes False.
  • •Use Cases: Ideal for retries, polling, or waiting for a specific network state.
  • •Caution: Must ensure the condition eventually becomes False to avoid infinite loops.
Key Takeaway

while loops are powerful for dynamic, condition-based repetition, but require careful management of their termination condition to prevent script freezes.

Code Example: Polling Device Status
device_ready = False@nattempts = 0@nmax_attempts = 3@n@nwhile not device_ready and attempts < max_attempts:@n    print(f"Attempt {attempts + 1}: Checking device status...")@n    # Simulate a check (e.g., ping, API call)@n    if attempts == 2: # Simulate success on 3rd attempt@n        device_ready = True@n    attempts += 1@n    import time@n    time.sleep(1) # Wait 1 second before next attempt@n@nif device_ready:@n    print("Device is now ready!")@nelse:@n    print("Device not ready after multiple attempts.")
Output
Attempt 1: Checking device status...@nAttempt 2: Checking device status...@nAttempt 3: Checking device status...@nDevice is now ready!
Misconception

Forgetting to update the condition variable inside the while loop is a common mistake that leads to infinite loops, consuming system resources and freezing your script.
