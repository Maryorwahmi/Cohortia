Core Concept

Indentation: Python's Code Block Structure

In Python, indentation (whitespace at the beginning of a line) is used to define code blocks, unlike other languages that use curly braces.

  • •Syntactic Requirement: Indentation is not optional; it's a core part of Python's syntax.
  • •Consistent Spacing: All lines within a block must have the same level of indentation.
  • •Common Error: Inconsistent indentation leads to an IndentationError.
  • •Standard Practice: Use 4 spaces for each level of indentation.
Key Takeaway

Correct and consistent indentation is paramount in Python; it dictates code execution flow and is a frequent source of errors if not followed precisely.

Code Example: Correct vs. Incorrect Indentation
device_status = "reachable"@n@n# Correct Indentation@nif device_status == "reachable":@n    print("Device is online.")@n    print("Ready for configuration.")@nelse:@n    print("Device is offline.")@n@n# Incorrect Indentation (will raise IndentationError)@n# if device_status == "reachable":@n#  print("Device is online.") # Inconsistent indentation@n#     print("Ready for configuration.")
Output (for correct code)
Device is online.@nReady for configuration.
Pro-Tip

Most modern code editors automatically handle indentation. Configure your editor to use 4 spaces for Python to maintain consistency and avoid errors.
