Fundamental Data Types

Python's basic data types allow us to represent different kinds of information:

  • •Strings (`str`): Textual data, enclosed in quotes (e.g., device names, command outputs).
  • •Integers (`int`): Whole numbers (e.g., VLAN IDs, port numbers, interface speeds).
  • •Booleans (`bool`): Logical values, `True` or `False` (e.g., device status, interface state).
Key Takeaway

Choosing the correct data type for network information ensures accurate representation and enables appropriate operations within your automation scripts.

Code Example: Basic Data Types
# String: Device hostname@nhostname = "EdgeRouter01"@n@n# Integer: VLAN ID@nvlan_id = 100@n@n# Boolean: Interface status@ninterface_up = True@n@nprint(f"Hostname: {hostname} (Type: {type(hostname).__name__})")@nprint(f"VLAN ID: {vlan_id} (Type: {type(vlan_id).__name__})")@nprint(f"Interface Up: {interface_up} (Type: {type(interface_up).__name__})")
Output
Hostname: EdgeRouter01 (Type: str)@nVLAN ID: 100 (Type: int)@nInterface Up: True (Type: bool)
Practical Application

When parsing `show interface status` output, you'd extract interface names as strings, port numbers as integers, and operational status as booleans to build a structured representation of your network's state.
