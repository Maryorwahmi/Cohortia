RESTCONF URL Structure

Mapping YANG data hierarchy directly to API endpoints.

URL Path Segments
  • /restconf/data: Base path for configuration and operational data.
  • /restconf/operations: Base path for RPCs and actions.
  • YANG Module Name: Specifies the module defining the data.
  • YANG Node Path: Corresponds to containers, lists, and leaves.
  • List Keys: Used to identify specific entries in a YANG list (e.g., interface=GigabitEthernet1).
Key Takeaway

The RESTCONF URL path directly reflects the hierarchical structure of the underlying YANG data model, ensuring consistency and predictability.

YANG to RESTCONF URL Mapping
/restconf/data

Base path for data resources

/ietf-interfaces:interfaces

YANG module and container

/interface=GigabitEthernet1

List entry with key

Example URL: /restconf/data/ietf-interfaces:interfaces/interface=GigabitEthernet1

This URL targets a specific interface configuration based on its YANG definition.
