JSON and XML Payloads

Specifying data formats with Content-Type and Accept headers.

JSON (JavaScript Object Notation)

Preferred data format due to its lightweight nature, human readability, and widespread use in web APIs.

  • Header: application/yang-data+json
XML (Extensible Markup Language)

Also supported, though less common in modern RESTCONF implementations compared to JSON.

  • Header: application/yang-data+xml
HTTP Headers

Content-Type specifies the format of data being sent; Accept specifies the desired response format.

Key Takeaway

Always use Content-Type and Accept headers to explicitly define JSON or XML data formats for RESTCONF requests and responses.
