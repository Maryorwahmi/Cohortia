HTTP Methods: PUT, DELETE, and PATCH

Replacing, removing, and partially modifying data resources.

PUT Method

Creates or replaces an entire data resource at the specified URL. If the resource exists, it's fully replaced; if not, it's created.

  • Example: Replacing an entire interface configuration.
  • Idempotent: Ensures the resource state matches the payload.
DELETE Method

Removes the data resource specified by the URL. This operation permanently deletes the resource.

  • Example: Deleting a specific static route or an entire interface.
  • Idempotent: Deleting an already deleted resource has no further effect.
PATCH Method

Modifies parts of an existing data resource without replacing the entire resource. Ideal for granular updates.

  • Example: Changing only the description of an interface.
  • Not Idempotent: Repeated requests can have different effects if the resource state changes.
Key Takeaway

PUT replaces, DELETE removes, and PATCH partially updates data resources; understanding their differences is critical to avoid unintended configuration changes.
