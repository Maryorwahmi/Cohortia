RESTCONF Protocol

Bridging YANG Data Models with RESTful APIs

RESTCONF is an IETF standard protocol that provides a REST-like interface for accessing and manipulating YANG-modeled network data over HTTP/HTTPS. It leverages standard HTTP methods to interact with network resources, making network automation accessible and efficient.

Key Idea

RESTCONF combines YANG data modeling with RESTful API principles for accessible network automation over HTTP/HTTPS.
