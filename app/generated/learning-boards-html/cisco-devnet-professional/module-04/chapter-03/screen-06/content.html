HTTP Methods: GET and POST

Retrieving and creating configuration or operational data.

GET Method

Used to retrieve configuration or operational data from the device. It's a read-only operation and does not modify the resource.

  • Example: Fetching interface status or entire running configuration.
  • Idempotent: Multiple identical requests have the same effect as a single one.
POST Method

Used to create a new data resource, typically adding an entry to a YANG list or container. The server assigns the resource's identifier.

  • Example: Creating a new loopback interface or adding a static route.
  • Not Idempotent: Repeated requests can create duplicate resources.
Key Takeaway

GET is for reading data, while POST is for creating new resources, both operating on /restconf/data endpoints.
