Operations Resources: RPCs and Actions

Executing device-specific functions beyond standard CRUD operations.

Purpose of Operations Resources

Represent RPCs (Remote Procedure Calls) or actions defined in YANG modules. Used for device-specific functions that don't directly map to CRUD operations on data.

  • Path: Accessed via /restconf/operations.
  • Method: Typically invoked using POST requests.
Common Use Cases

Examples include clearing interface counters, performing diagnostic tests, initiating a device reboot, or other non-data-modifying actions.

  • Example: Triggering a 'clear counters' command via RESTCONF.
Key Takeaway

Operations resources are for executing specific device functions (RPCs/actions) and are accessed via /restconf/operations, typically with a POST request.

Data vs. Operations Resources
Data Resources

Configuration & State Data

/restconf/data

Operations Resources

RPCs & Actions

/restconf/operations

While data resources manage the 'what' of the network, operations resources handle the 'how' by triggering specific device functions.
