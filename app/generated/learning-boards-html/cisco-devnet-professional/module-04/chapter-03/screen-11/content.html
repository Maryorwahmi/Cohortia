Retrieving Interface Configuration (GET)

Using Python `requests` to fetch data from a RESTCONF endpoint.

Function Breakdown
  • URL Construction: Dynamically builds the URL using the base path, YANG module (e.g., Cisco-IOS-XE-native:native), and specific interface details.
  • HTTP GET Request: Uses requests.get() with authentication and headers to fetch data.
  • Error Handling: response.raise_for_status() checks for HTTP errors (4xx/5xx) and raises an exception if found.
  • JSON Parsing: response.json() converts the response body into a Python dictionary for easy access.
Key Takeaway

A successful RESTCONF GET request requires precise URL construction, proper authentication, and robust error handling to retrieve configuration or operational data.

Python `get_interface_config` Function
def get_interface_config(interface_type, interface_name):
    """Retrieves configuration for a specific interface."""
    url = f"{BASE_URL}/Cisco-IOS-XE-native:native/interface/{interface_type}={interface_name}"
    
    print(f"
--- Attempting GET from: {url} ---")
    try:
        response = requests.get(url, auth=(USER, PASS), headers=HEADERS, verify=False)
        response.raise_for_status()
        
        print(json.dumps(response.json(), indent=2))
        return response.json()
    except requests.exceptions.RequestException as e:
        print(f"Error retrieving interface config: {e}")
        if response and response.text:
            print(f"Response content: {response.text}")
        return None

This function fetches the configuration for a specified interface and prints the JSON response.
