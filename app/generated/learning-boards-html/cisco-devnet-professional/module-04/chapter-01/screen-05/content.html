Introducing Network Data Models
A Blueprint for Network Configuration and State

A formal description of data used by a network device.

Acts as a schema or blueprint for configuration and state.

Enables predictable, vendor-agnostic interaction.

Facilitates machine parsing and validation of data.

Supports a declarative approach to network management.

Analogy

Think of it like building a house:

  • CLI: Giving verbal instructions to a construction worker, hoping they understand and execute correctly each time.
  • Data Model: Providing a detailed architectural blueprint with precise measurements, materials, and specifications that the worker follows exactly.

The blueprint ensures consistency and accuracy, regardless of who is building.
