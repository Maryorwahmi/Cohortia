YANG Node Types: Leaf and Leaf-List
Holding Actual Data Values

Leaf: A single data item with a specific type and value. Terminal node.

Leaf-list: Allows multiple instances of a single data type without keys.

Use Case (Leaf): Interface `description`, `enabled` status, `IP address`.

Use Case (Leaf-list): Multiple `DNS servers`, `logging servers`.

Conceptual Example

Modeling interface details:


container interface {
  leaf name { type string; }
  leaf description { type string; default "Configured by DevNet"; }
  leaf enabled { type boolean; default "true"; }
}

container dns-settings {
  leaf-list server-address { type inet:ipv4-address; }
}

`name`, `description`, and `enabled` are leaves. `server-address` is a leaf-list that can hold multiple IP addresses.
