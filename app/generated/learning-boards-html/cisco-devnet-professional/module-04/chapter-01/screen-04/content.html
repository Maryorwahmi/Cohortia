Challenges in Automation
The Problem with CLIs
Why Traditional Network Interfaces Hinder Automation

CLIs are designed for human interaction, not machine parsing.

They are often vendor-specific, leading to inconsistent behavior.

Imperative commands are hard to reconcile with declarative automation goals.

Output is unstructured text, making reliable parsing difficult.

Minor changes can break existing automation scripts.

Example Scenario

Imagine automating interface configuration:

  • Cisco IOS: `interface GigabitEthernet0/1`, `ip address 192.168.1.1 255.255.255.0`, `no shutdown`
  • Juniper Junos: `set interfaces ge-0/0/0 unit 0 family inet address 192.168.1.1/24`, `set interfaces ge-0/0/0 enable`

Notice the different syntax and structure. A script for one won't work for the other without adaptation.
