Ensuring Data Integrity
YANG Data Types
Defining the Nature of Data

Primitive Types: `string`, `boolean`, `int8`-`int64`, `uint8`-`uint64`, `empty`, `decimal64`.

Derived Types: Built upon primitives with added constraints (e.g., `inet:ipv4-address`, `inet:port-number`).

Custom Types: Defined using `typedef` for reusability and clarity.

Purpose: Enforce data format, ensure integrity, enable validation.

Type Examples

Common YANG Types:

  • `string`: For interface descriptions, names.
  • `boolean`: For enabling/disabling features (true/false).
  • `uint16`: For VLAN IDs (0-65535).
  • `inet:ipv4-address`: For IP addresses, enforcing correct format.
  • `enumeration`: For a fixed set of string values (e.g., `active`, `suspended`).

Using the right type prevents invalid data from being configured.
