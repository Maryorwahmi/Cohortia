Interpreting a Simple YANG Module
Understanding Structure and Data

Module: `my-interface-config` with namespace.

Top-level: `container interfaces`.

Data Structure: `list interface` with `key "name";`.

Nested Elements: `name` (string), `ipv4` (container), `description` (string, default), `enabled` (boolean, default).

Data Types: `string`, `inet:ipv4-address`, `boolean`.

YANG Snippet

module my-interface-config {
  namespace "urn:example:my-interface-config";
  prefix "mic";

  import ietf-inet-types { prefix "inet"; }

  container interfaces {
    list interface {
      key "name";
      leaf name { type string; }
      container ipv4 {
        leaf address { type inet:ipv4-address; }
        leaf netmask { type inet:ipv4-address; }
      }
      leaf description { type string; default "Configured by DevNet Professional"; }
      leaf enabled { type boolean; default "true"; }
    }
  }
}

This structure clearly defines how interface configurations should be represented.
