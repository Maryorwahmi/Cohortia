What is YANG?
The IETF Standard for Network Data Modeling

YANG: Yet Another Next Generation.

An IETF standard data modeling language.

Defines structure and constraints for network data.

Used by protocols like NETCONF and RESTCONF.

Organized into modules and submodules.

Key Distinction

YANG vs. Protocols:

  • YANG: The *language* used to describe data (like grammar and vocabulary).
  • NETCONF/RESTCONF: The *protocols* used to transport that data (like the postal service delivering a letter written in that language).

YANG provides the schema; protocols provide the mechanism for interaction.
