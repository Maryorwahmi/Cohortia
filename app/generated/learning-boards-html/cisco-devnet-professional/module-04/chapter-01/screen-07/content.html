YANG Module Structure
Organizing Data Hierarchically

Module: Primary unit, defines namespace.

Submodule: For better organization and reusability.

Container: Conceptual grouping of nodes (like a directory).

List: Sequence of entries, identified by keys (like multiple objects).

Leaf: A single data item with a value.

Leaf-list: Multiple values of the same type without keys.

Hierarchy Example

Imagine modeling network interfaces:

  • A top-level `interfaces` container.
  • Inside, a `list` named `interface` to hold multiple interface configurations.
  • Each `interface` entry in the list has a `name` leaf (key).
  • Nested within each `interface` could be an `ipv4` container.
  • Inside `ipv4`, `address` and `netmask` leaves.

This nested structure allows for complex data representation.
