NETCONF Protocol: Programmatic Network Management
Automating network configuration with structured data models.
NETCONF is an IETF standard protocol designed for installing, manipulating, and deleting configurations on network devices. It's machine-to-machine oriented, secure, and built to work with structured data models like YANG.
