Retrieving Configuration and Operational Data
Using `get` and `get-config` for device information.

The `get` Operation

Retrieves both operational data (e.g., interface stats) and configuration data. Supports filters for specific data nodes.

The `get-config` Operation

Specifically retrieves configuration data from a target datastore (e.g., `running`, `candidate`).

Example: Interface Configuration

Use `get-config` with a filter to retrieve all interface configurations from the `running` datastore.

XML Output Example (Filtered `get-config`)
<data> <native xmlns="http://cisco.com/ns/yang/Cisco-IOS-XE-native"> <interface> <GigabitEthernet> <name>1</name> <description>Main Uplink</description> </GigabitEthernet> <Loopback> <name>0</name> <ip> <address> <primary> <address>192.168.1.1</address> <mask>255.255.255.0</mask> </primary> </address> </ip> </Loopback> </interface> </native></data>
Key Takeaway

`get` and `get-config` are essential for retrieving structured operational and configuration data from network devices.
