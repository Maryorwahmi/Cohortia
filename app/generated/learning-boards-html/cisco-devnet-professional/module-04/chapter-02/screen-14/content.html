Key Concepts
Essential terms to remember.

NETCONF (Network Configuration Protocol)

An IETF standard protocol for managing configuration and operational data on network devices using YANG data models over SSH.

Capabilities Exchange

The initial phase of a NETCONF session where client and server advertise their supported YANG modules, protocol versions, and features.

Datastores

Logical storage locations for configuration and operational data on a device (e.g., `running`, `startup`, `candidate`).

Summary Takeaway

NETCONF provides a secure, structured, and programmatic way to manage network devices, relying on capabilities exchange and distinct datastores.
