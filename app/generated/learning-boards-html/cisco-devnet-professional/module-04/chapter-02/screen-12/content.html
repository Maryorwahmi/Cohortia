Fetching Interface Configuration with Python
Using `ncclient` to `get-config` specific data.

Define an XML Filter

Specify which parts of the configuration to retrieve, based on the device's YANG model.

Execute `get-config`

Use `m.get_config(source='running', filter=interface_filter)` to fetch the data.

Process XML Output

The `result.data_xml` contains the structured configuration, ready for parsing.

`get_interfaces_config` Function
def get_interfaces_config(): with manager.connect(host=HOST, port=PORT, username=USER, password=PASS, hostkey_verify=False, device_params={'name': 'iosxe'}) as m: print("--- Connected to device ---") interface_filter = """ <filter> <native xmlns="http://cisco.com/ns/yang/Cisco-IOS-XE-native"> <interface/> </native> </filter> """ try: result = m.get_config(source='running', filter=interface_filter).data_xml print("
--- Interface Configuration ---") print(result) except Exception as e: print(f"Error retrieving config: {e}")
Key Takeaway

`ncclient` simplifies filtered `get-config` operations, providing structured XML output for programmatic use.
