Handshake: Capabilities Exchange
Discovering device capabilities and supported YANG modules.

Client Initiates Connection

A NETCONF client connects to the server (network device) over a secure transport like SSH.

Client Advertises Capabilities

The client sends its supported NETCONF versions and features to the server.

Server Responds with Capabilities

The server sends its supported YANG modules, NETCONF versions, and optional features.

Key Takeaway

Capabilities exchange ensures client-server compatibility by advertising supported features and YANG models.
