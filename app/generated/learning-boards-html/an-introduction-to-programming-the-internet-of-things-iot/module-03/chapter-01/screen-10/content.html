Module 3 › Chapter 3.1 › Smart Lock Activity
Activity steps
  1. Wire servo signal to pin 9 and power servo from external 5V; connect external ground to Arduino ground.
  2. Wire relay module signal to pin 7 and verify relay LED toggles before connecting mains.
  3. Attach I2C LCD and initialize with LiquidCrystal_I2C; confirm text display works.
  4. Implement control: on trigger, write servo to 90°, set relay high, display "UNLOCKED", delay five seconds, then reverse.
  5. Test safety: confirm wiring, check grounds, and only connect mains to relay after low-voltage behavior is confirmed.
Scenario card
Simulate a door button press: the servo moves to unlock, the relay energizes the latch circuit, and the LCD displays the state. This demonstrates timing, power distribution, and user feedback working together.
Key Takeaway

Integration validates wiring, timing, and power choices; test with low-voltage loads before enabling mains switching.
