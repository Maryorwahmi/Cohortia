Relay basics
A coil on the low-voltage side actuates separated contacts on the high-voltage side, creating isolation between the control and the load.
Concrete example: Toggle a relay pin high for five seconds to simulate a door latch being engaged, then set it low to release.
Safety practice: Use modules with optocouplers, keep mains wiring in a protective enclosure, and never touch live terminals while powered.
Misconception: Isolation reduces risk but does not replace correct wiring and enclosures for mains circuits.
Safety reminder

When testing, keep the high-voltage side disconnected until wiring is verified and use proper protective gear and enclosures for mains tests.

Relay code
const int relayPin = 7; void setup() { pinMode(relayPin, OUTPUT); } void loop() { digitalWrite(relayPin, HIGH); // Turn relay on delay(5000); digitalWrite(relayPin, LOW); // Turn relay off delay(5000); }
Practical note
Label control and load terminals. Test control logic with a low-voltage LED before connecting mains so you can verify timing and behavior safely.
