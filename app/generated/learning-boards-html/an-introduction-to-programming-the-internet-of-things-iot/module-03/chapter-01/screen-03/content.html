Translate objectives into outcomes
Each actuator type enables specific real-world behaviors. The cards below show common pairings and why they matter.
DC motor + H-bridge
Drive wheels or fans with speed and reverse control. Use PWM and an external driver for current handling.
Servo + position control
Precisely set angles for locks or levers. Use the Servo library and an external 5V supply for torque demands.
Relay module + AC load
Switch mains devices while isolating the microcontroller from high voltage. Use opto-isolated relay modules and enclosures.
LCD / OLED + local UI
Show immediate status text like "UNLOCKED" and sensor readings without needing a web app.
Mnemonic
Think: Signal → Driver → Actuator → Supply. Always check the supply and common ground before energizing actuators.
Verified Competency Milestone

Assemble and test the smart lock circuit: servo on pin 9, relay on pin 7, I2C LCD, and external 5V supply for the servo.
