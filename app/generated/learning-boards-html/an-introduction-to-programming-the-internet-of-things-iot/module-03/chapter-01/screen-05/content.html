Module 3 › Chapter 3.1 › DC Motors & H-Bridge
Core concept
H-bridge drivers allow direction control and PWM-based speed control for DC motors while protecting the Arduino.
Why use an H-bridge: It switches polarity safely and accepts PWM on an enable pin so the motor does not draw current through the Arduino pin.
Example: Use L298N with IN1/IN2 for direction and ENA for PWM. Use an external supply for the motor and common the grounds.
Misconception: analogWrite does not change supply voltage; it varies duty cycle to control average power to the motor.
Common mistake

Driving a motor directly from an Arduino I/O pin risks large current draw and board resets; always use a motor driver.

Code example
const int motorPin1 = 9;   // L298N IN1
const int motorPin2 = 10;  // L298N IN2
const int enablePin = 11;  // L298N ENA (PWM)

void setup() {
  pinMode(motorPin1, OUTPUT);
  pinMode(motorPin2, OUTPUT);
  pinMode(enablePin, OUTPUT);
}

void loop() {
  // Forward at half speed
  digitalWrite(motorPin1, HIGH);
  digitalWrite(motorPin2, LOW);
  analogWrite(enablePin, 128);  // 50% duty cycle
  delay(2000);

  // Stop
  digitalWrite(motorPin1, LOW);
  digitalWrite(motorPin2, LOW);
  delay(1000);

  // Reverse at full speed
  digitalWrite(motorPin1, LOW);
  digitalWrite(motorPin2, HIGH);
  analogWrite(enablePin, 255);  // 100% duty cycle
  delay(2000);
}
Concrete example
A small robot wheel driven via L298N where ENA is PWM to control speed and IN1/IN2 set direction.
Key takeaway
Always use a driver and external supply; common the grounds with the Arduino to ensure correct signal reference.
