Display options
16x2 Character LCD
Two lines of 16 characters. Use LiquidCrystal library or I2C backpack to save pins.
OLED (SSD1306)
Graphical display for text and shapes. Uses I2C or SPI and supports compact interfaces.
Neopixel / WS2812
Addressable RGB LEDs for attention and status. Controlled individually but can draw heavy current at full brightness.
Example: In the smart lock, use a 16x2 LCD to show "UNLOCKED" and a Neopixel ring to flash green briefly for user confirmation.
Power note: If using many Neopixels, provide a dedicated 5V supply sized for peak current and common the grounds.
Code sample (LCD)
#include <LiquidCrystal_I2C.h> LiquidCrystal_I2C lcd(0x27, 16, 2); void setup() { lcd.init(); lcd.backlight(); lcd.setCursor(0,0); lcd.print("IoT System"); } void loop() { lcd.setCursor(0,1); lcd.print("Temp: "); lcd.print(analogRead(A0) * 0.488); // Convert to temperature lcd.print(" C "); delay(1000); }
Tip
Prefer an I2C backpack for the 16x2 LCD to reduce pin usage and wiring complexity on small projects.
