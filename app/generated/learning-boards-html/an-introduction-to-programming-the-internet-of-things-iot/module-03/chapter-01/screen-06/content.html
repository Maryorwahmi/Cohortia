How servo positioning works
Pulse width selects angle; library handles the timing for you.
#include <Servo.h>

Servo myServo;

void setup() {
  myServo.attach(9);  // Servo signal pin
}

void loop() {
  myServo.write(0);    // 0 degrees
  delay(1000);
  myServo.write(90);   // 90 degrees
  delay(1000);
  myServo.write(180);  // 180 degrees
  delay(1000);
}
Concrete example: Use a servo to actuate a latch to 90 degrees for unlock and return to 0 degrees to lock.
Misconception: The servo does not accept generic duty-cycle PWM; the position depends on pulse width timing in a fixed period.
Power note
Servos draw significant current when moving. Use an external 5V supply and common the grounds with the Arduino. Avoid powering moving servos from the Arduino 5V pin to prevent resets.
Key Takeaway

Use the Servo library for timing and keep servo power separate from the Arduino's supply while sharing ground reference.
