Actuators: Motors, Servos, Relays, Displays
Control motion, switching, and local feedback while managing power and safety
In this lesson
You will see the main actuator types, example Arduino code, and the wiring and power rules that make them reliable and safe.
Explore Key Topics
Motors
DC motors need H-bridges for direction and PWM for speed control. Current limits require drivers and external supply.
Servos
Servos accept position pulses. Use the Servo library and an external 5V supply for reliable torque during movement.
Relays & Displays
Relays isolate high-voltage loads; LCDs or OLEDs give local feedback. Both require correct wiring and ground references.
Concept Map
Signal → Driver → Actuator → Physical Effect
Arduino pin: low-power control signal
Driver module: provides current and direction control
Actuator: motor, servo, relay, or display
External supply: meets current and voltage needs
Key Takeaway

Design around power and isolation: use drivers, separate supplies, and safe relay modules so the Arduino only controls signals, not heavy currents.
