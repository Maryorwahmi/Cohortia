Process

HC-05 pairing and usage

Steps
  1. Install bluetooth tools on Pi.
  2. Put HC-05 in AT mode to configure if needed.
  3. Use bluetoothctl to scan, pair, and trust the device.
  4. Connect and use /dev/rfcomm0 with pyserial.
Usage notes
Once connected, pyserial code is identical to USB serial. Verify baud matches the HC-05 configuration and the Arduino serial settings.
Concrete scenario: pair HC-05, open /dev/rfcomm0 on the Pi, and confirm the Arduino's TEMP: lines arrive without a USB cable.
