Designing a message protocol

1. Delimiters
Choose a start marker and end marker (or newline) so frames are detected reliably.
2. Labels
Use key-value pairs like TEMP, HUM so the parser knows which number maps to which sensor.
3. Checksum
Include a checksum to detect corruption, for example an XOR of payload bytes.
Example frame:
$TEMP,25.5,HUM,60.2,*5A
Here $ begins the frame, comma separates pairs, * starts the checksum and ends the frame.
ACK pattern
Pi sends CMD:LED_ON; Arduino performs and replies ACK:OK. If no ACK arrives, Pi may retry after a timeout.
Common mistake
Relying on timing instead of clear delimiters leads to misaligned reads when data bursts or buffering occurs.
