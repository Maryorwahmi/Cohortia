Practical Outcomes

Map each objective to a test you can run on real hardware.

Serial Test
Arduino prints labeled lines and Pi parses them with pyserial.
I2C Polling
Pi reads a byte from the Arduino slave address and interprets the value.
Bluetooth Pairing
HC-05 appears as a serial port and exchanges the same labeled messages wirelessly.
Protocol Check
Each message uses clear delimiters and a checksum so corrupted data is detected before display or action.
