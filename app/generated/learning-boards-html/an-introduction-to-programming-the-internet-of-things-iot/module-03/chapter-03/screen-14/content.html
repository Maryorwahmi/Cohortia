Module 4 › Chapter 3.3 › Quick Reference
Check devices
Confirm /dev nodes, i2cdetect output, and rfcomm connections before running code.
Use delimiters
Start/end markers or newlines prevent misaligned parsing when streams interleave.
Verify checksums
A simple XOR checksum flags corrupted payloads before acting on them.
Final tip
Build and verify each layer in order: Arduino output, Pi parsing, transport configuration, then UI and commands. That sequence keeps troubleshooting fast.
