Definition

Edge device vs Edge gateway

A short definition and practical mapping to hardware tasks.

Arduino — Edge device
  • Real-time sampling and GPIO control
  • Low-latency actuator feedback
  • Simple serial output for transport
Raspberry Pi — Edge gateway
  • Runs Python services and web UIs
  • Handles network connectivity and storage
  • Parses, timestamps, and persists sensor streams
Key Takeaway

Split responsibilities: let the Arduino do time-sensitive I/O and the Pi handle higher-level logic and networking.

Analogy

Analogy: Sensor assistant and server

Think of the Arduino as an assistant who reads instruments and flips switches, and the Raspberry Pi as the server that stores results and shows them to visitors.

Concrete scenario
An Arduino reads temperature and light every second and sends labeled lines like TEMP:25.5 to the Pi. The Pi logs readings and serves them in a browser dashboard.
Common mistake
Putting all responsibilities on the Pi can make timing brittle and debugging harder when the OS schedules unpredictably.
