Connecting Arduino to Raspberry Pi

Learn serial, I2C, and Bluetooth links and design message formats for safe, extensible IoT communication.

Duration: ~12 minutes
Edge Device
Arduino: reads sensors, controls actuators, real-time tasks.
Edge Gateway
Raspberry Pi: processes data, serves web UI, connects to network.
This lesson groups wiring, code, and protocol design into practical patterns you can reuse in greenhouse monitors, home automation, and low-power sensing projects.
Explore Key Topics
Serial
USB or UART for simple labeled streams using pyserial on the Pi.
I2C
Pi as master, Arduino as slave — poll sensors and send bytes with smbus.
Bluetooth
HC-05 modules create wireless serial ports that behave like USB serial once paired.
Quick concept map
How data flows in a simple setup
Sensor → Arduino
Analog/digital sensors are read and serialized with labels like TEMP: or LIGHT:.
Transport
USB serial, I2C polling, or Bluetooth serial carry messages to the Pi.
Pi → UI
Pi parses messages and serves a web UI or stores readings for processing.
