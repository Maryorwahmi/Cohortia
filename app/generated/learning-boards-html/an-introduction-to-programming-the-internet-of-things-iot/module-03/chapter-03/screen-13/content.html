Module 4 › Chapter 3.3 › Key Concepts
Serial streams
Label and newline-terminate messages so the Pi can parse sensor data reliably with pyserial.
I2C master/slave
Pi polls the Arduino slave over SDA and SCL for compact, frequent reads using smbus.
Bluetooth serial
HC-05 modules create /dev/rfcomm0 on the Pi after pairing so you can use pyserial wirelessly.
Takeaway
Choose the simplest reliable link that fits your physical constraints, and always design a protocol with delimiters, checksums, and acknowledgments for robust IoT data exchange.
