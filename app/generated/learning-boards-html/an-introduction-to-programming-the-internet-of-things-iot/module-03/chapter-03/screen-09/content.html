Pi (I2C master)
import smbus
import time

bus = smbus.SMBus(1)
SLAVE_ADDRESS = 0x04

while True:
    data = bus.read_byte(SLAVE_ADDRESS)
    print(f"Sensor value: {data}")
    bus.write_byte(SLAVE_ADDRESS, ord('1'))  # Turn LED on
    time.sleep(1)
    bus.write_byte(SLAVE_ADDRESS, ord('0'))  # Turn LED off
    time.sleep(1)
Use i2cdetect and raspi-config to verify the bus and device before running the script.
Troubleshooting checklist
  • Is I2C enabled in raspi-config?
  • Are SDA/SCL and GND wired correctly and short?
  • Does i2cdetect show the slave address?
Pro tip
Use single-byte scaling for frequent polls and reserve multi-byte frames for less frequent, richer payloads.
