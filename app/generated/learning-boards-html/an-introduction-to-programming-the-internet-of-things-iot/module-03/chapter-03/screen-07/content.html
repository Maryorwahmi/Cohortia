Architecture

I2C master-slave roles

The Pi starts transactions and the Arduino responds. Use it for compact, frequent reads without USB overhead.
Wiring
Connect SDA (GPIO 2, pin 3), SCL (GPIO 3, pin 5), and GND. Enable I2C in raspi-config.
Software
Install python3-smbus and use read_byte/write_byte to exchange single bytes with the slave address.
Key Takeaway

I2C is efficient for short, co-located connections and tight polling loops but not for long distances.

Example flow
Pi requests a byte; Arduino reads analog A0, scales to a byte and sends it back via Wire.write. Pi interprets the byte as the sensor value.
When to choose I2C
  • Boards share the same enclosure
  • Short wires and frequent polling
  • Need low overhead direct reads
Gotcha
I2C requires pull-ups and short wires; check address conflicts if multiple slaves are present.
