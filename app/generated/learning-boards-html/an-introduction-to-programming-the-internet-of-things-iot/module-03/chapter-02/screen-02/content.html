Module 3 › Chapter 3.2 › Learning Objectives
01
Use the Ethernet Shield
Wire a W5100/W5500 shield, set MAC and IP, and use the Ethernet library to send and receive HTTP traffic. Verified competency milestone.
Mnemonic: RJ45 + SPI = wired link
02
Use Wi‑Fi Shield or ESP modules
Connect wirelessly using a Wi‑Fi shield alternative or program an ESP8266/ESP32 to join Wi‑Fi and send data. Verified competency milestone.
Mnemonic: SSID + password → join network
03
Send HTTP requests from Arduino
Use the Ethernet or HTTP client libraries to send GET requests with sensor data to a server or cloud service. Verified competency milestone.
Mnemonic: GET with query parameters
04
Host a simple Arduino web server
Implement a tiny HTTP server that serves a control page and parses requests to toggle outputs like an LED. Verified competency milestone.
Mnemonic: HTTP server = remote control
