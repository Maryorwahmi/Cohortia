Definition Ethernet Shield wiring
Key hardware
  • Controller: W5100 or W5500 chip provides 10/100 Mbps Ethernet.
  • Physical jack: RJ45 for network cable and link lights for status.
  • SPI connection: pins 10, 11, 12, 13 with pin 10 as chip select.
  • microSD slot: optional logging, shares SPI with separate chip select.
Troubleshooting tip
If the board does not connect, check the RJ45 cable and link lights first, then confirm the correct MAC and IP or DHCP assignment in code.
Practical checks
  1. Confirm physical connection and link lights on RJ45.
  2. Verify SPI pins and chip select pin are not used by another device.
  3. Run Ethernet.begin with MAC and IP or use DHCP and observe Serial output.
Common Mistake

Sharing SPI devices without managing chip selects causes bus contention and failed communications.
