Core Concept MAC & IP
MAC address
A hardware identifier used on the local link. In Arduino code you set a MAC byte array so the shield has a unique identifier on the network.
IP address
An IP can be static (set in code) or assigned by DHCP. Static IPs are predictable; DHCP is convenient but can change over time.
Practical checklist
  • Ensure MAC uniqueness on the same network.
  • Choose static IPs only when you can avoid address conflicts.
  • Use the router's DHCP table to verify assigned addresses when troubleshooting.
