Hands-on Activity ESP8266 → ThingSpeak
Step-by-step
  1. Install ESP board support in Arduino IDE and connect NodeMCU.
  2. Create ThingSpeak channel and copy API key into the sketch.
  3. Wire a temperature sensor and read values in loop.
  4. Use HTTPClient to send a GET with the API key and field value every 30 seconds.
  5. Open Serial to confirm 'WiFi connected' and HTTP response codes; verify the dashboard graph updates.
Checks and extension
If posts fail, verify SSID/password, API key, and that the URL matches the service's expected format. Extension: configure an alert that sends a notification when a threshold is exceeded using the service's reaction tools.
Key Takeaway

Break the lab into hardware, network, and server checks; confirm each layer to isolate issues quickly.
