Definition ESP8266 HTTP client
Code (ESP8266)
#include <ESP8266WiFi.h>
#include <ESP8266HTTPClient.h>

const char* ssid = "YourNetwork";
const char* password = "YourPassword";

void setup() {
  Serial.begin(115200);
  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }
  Serial.println("WiFi connected");
}

void loop() {
  if (WiFi.status() == WL_CONNECTED) {
    WiFiClient client;
    HTTPClient http;
    http.begin(client, "http://api.thingspeak.com/update?api_key=YOURKEY&field1=25.5");
    int httpCode = http.GET();
    Serial.println(httpCode);
    http.end();
  }
  delay(60000);  // Send every minute
}
Explanation
  • Use WiFi.begin with SSID and password and wait for WL_CONNECTED.
  • Create an HTTPClient, call begin with the URL, then GET and inspect the returned code.
  • Always call http.end to free resources and respect delays between sends to avoid rate limits.
Concrete example
Sending a GET to ThingSpeak with your channel key stores a value that appears on a real‑time graph on the ThingSpeak dashboard once the channel receives it.
Troubleshooting tip

If Wi‑Fi connection fails, check the SSID, password, and signal strength; ensure the router allows new devices and is not blocking traffic.
