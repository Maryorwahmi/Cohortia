Module 7 › Chapter 7.2 › Implementation Levels
Definition

Sensor, Gateway, Regional

Choose the level that balances speed, compute, and connectivity for each function.

Sensor-level
Simple processing on microcontrollers for thresholds and immediate safety actions.
Example: ESP32 stopping a motor on an alarm.
Gateway-level
Aggregates, runs inference, and filters many sensors before cloud sync.
Example: Raspberry Pi doing anomaly detection.
Regional edge
Local micro data center for heavier analytics with low regional latency.
Example: On-premise analytics for a factory campus.
Decision guide
  1. List task urgency, data size, compute needs, and privacy level.
  2. Map urgent tasks to sensor or gateway; heavy analytics to regional or cloud.
  3. Consider failover: local autonomy if connectivity is unreliable.
Key Takeaway

Match processing level to the function’s urgency and compute needs to keep systems responsive and cost-effective.
