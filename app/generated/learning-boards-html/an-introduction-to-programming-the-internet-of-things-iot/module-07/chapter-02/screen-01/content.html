Sensor Edge
Tiny processing: averaging, threshold detection, immediate safety stops.
Example: ESP32 detecting temperature threshold.
Gateway Edge
Aggregates data, runs ML inference, filters events before cloud sync.
Example: Raspberry Pi performing anomaly detection.
Regional Edge
Micro data centers handle heavier processing for a campus or factory.
Example: On-premise analytics for a factory floor.
Key Takeaway

Place time-critical decisions on the fastest local compute. Use the cloud for long-term storage and heavy analytics.

Common Mistake

Sending all raw sensor data to the cloud wastes bandwidth and can break systems when connectivity drops.
