Latency & Bandwidth Trade-offs

Quantify requirements to decide what runs where.

Latency rule
If an action must complete within tens of milliseconds, implement it on the sensor microcontroller or dedicated local controller.
Bandwidth rule
Aggregate, summarize, or sample at the edge. Avoid sending raw continuous streams when summaries or events suffice.
Example calculation
1,000 sensors at 1 sample/sec produce 86.4 million data points per day—edge aggregation can reduce this by orders of magnitude.
Design checklist
  • Set required response time and classify decisions by urgency.
  • Estimate per-device data generation and network capacity.
  • Choose edge aggregation and event thresholds to reduce cloud load.
Pro Tip

Simulate worst-case traffic to validate gateway and network capacity before deployment.
