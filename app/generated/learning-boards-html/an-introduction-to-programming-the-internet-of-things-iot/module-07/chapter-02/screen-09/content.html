Architecture

Platforms & Protocols

Match hardware and connectivity to functional and non-functional requirements.

Platform selection
ESP32 or Arduino for low-power threshold tasks; Raspberry Pi for richer edge compute or inference.
Protocol selection
Use MQTT for lightweight telemetry, HTTP for REST integrates, and local buses for device-level communication.
Bill of Materials (BOM)
A BOM lists sensors, actuators, communication modules, power sources, enclosures, and estimated cost for each item. Keep it updated as prototypes evolve.
Example BOM entries
Ultrasonic sensor, ESP32 microcontroller, Wi‑Fi module, Li-ion battery, enclosure, wiring harness.
Key Takeaway

Choose components that meet measured requirements and use standard interfaces to maintain modularity.
