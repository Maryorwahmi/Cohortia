Module 7 › Chapter 7.1 › Best Practices
Checklist
Prioritize these actions when securing devices.
1. Strong, unique passwords
Never use defaults; require unique credentials for each device or use provisioning tokens.
2. TLS everywhere
Encrypt all network traffic using TLS for HTTP, MQTT and WebSocket communications.
3. Certificate pinning
Pin server certificate or public key for high-security devices to prevent MitM with forged certs.
4. Signed firmware
Ensure updates are cryptographically signed and verified before install.
Additional measures
Use HSMs for key storage, disable unused services, monitor for anomalies, and secure the supply chain.
Concrete scenario
A production device is flashed in the factory with a unique credential, connects over TLS to the vendor backend, verifies firmware signatures, and stores keys in an HSM. If compromise is suspected, credentials are rotated and the device is quarantined.
Common mistake

Skipping updates or leaving debug interfaces enabled are frequent sources of compromise. Make these checks part of manufacturing and deployment QA.
