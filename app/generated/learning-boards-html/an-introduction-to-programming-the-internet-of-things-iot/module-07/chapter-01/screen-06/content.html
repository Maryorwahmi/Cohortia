Passive vs Active interception
Understand the attacker capability and the defensive focus.
Eavesdropping (passive)
Attacker reads traffic without altering it. Primary defense: encryption such as TLS.
MitM (active)
Attacker intercepts and modifies messages. Primary defense: certificate validation, pinning, and message integrity checks.
Concrete example
A phone on public Wi-Fi can eavesdrop on HTTP traffic; an attacker with router access can perform a MitM and change responses or inject commands if certificate checks aren’t enforced.
Misconception
Assuming TLS is configured correctly. If the client skips certificate validation, TLS provides little protection against MitM. Always validate certificates and prefer pinning for critical devices.
Check your understanding
  • What additional check prevents replay attacks alongside TLS?
  • When would certificate pinning be excessive?
Key Takeaway

Encryption hides content; validation and integrity checks stop tampering. Use both.
