TLS for MQTT
Use a CA file and optional client certificate for mutual authentication.
Concrete example
Connect to a broker on 8883 with TLS and verify the server using ca.crt; provide client certificate for two-way trust when required.
Key Takeaway

Use TLS for MQTT and never skip certificate validation in production.

import paho.mqtt.client as mqtt

client = mqtt.Client()
client.tls_set(ca_certs="ca.crt", certfile="client.crt", keyfile="client.key")
client.connect("broker.example.com", 8883)
Practical notes
  • Store keys securely and limit file access permissions on the device.
  • Test with a public TLS broker to confirm certificate configuration before production.
  • Use mutual TLS when device identity must be strictly enforced.
