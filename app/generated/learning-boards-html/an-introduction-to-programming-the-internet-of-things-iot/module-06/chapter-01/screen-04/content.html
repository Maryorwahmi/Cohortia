What is CoAP?

A lightweight, UDP-based protocol that mirrors HTTP patterns but uses binary compact messages and optional observe behavior for publish-subscribe needs. CoAP reduces bytes and handshake cost to save power.

When to use
  • Smart home sensors on Thread or ZigBee IP
  • Industrial sensors with constrained memory
  • LPWAN devices where every byte costs energy
Example exchange
A client requests a temperature and receives a compact response that includes only the payload and a small status code. This exchange avoids large text headers and keeps packets short.
CON [MID=1234] GET /sensors/temperature
ACK [MID=1234] 2.05 Content [temperature: 25.5]
Protocol mechanics
Header

Four-byte fixed header carrying message type and code, followed by optional token and options in binary form.

Security

DTLS secures CoAP on top of UDP, providing confidentiality and integrity similar to TLS for TCP.

Common misconception
UDP is unreliable by default, but CoAP provides confirmable messages and acknowledgements so you can trade reliability for lower overhead when needed.
Key takeaway
CoAP is the right fit when packet size, memory, and power are the top constraints.
