Module 6 › Chapter 6.1 › Hands-on Activity
Step-by-step
  1. Install flask-socketio on the Raspberry Pi and start the server that handles sensor_data and emits update events.
  2. Create a simple HTML client that connects using the socket.io client, listens for update events, and shows values on the page.
  3. Open the client on multiple devices and trigger a sensor_data event to verify all clients receive the same broadcast.
  4. Test reconnection and rapid update bursts to observe server performance and tune the update rate.
Tip
During testing, keep CORS open for local devices but plan a secure CORS policy before production deployment.
Concrete test
Verify that a phone and laptop show the same temperature reading within one second of the Pi broadcasting the event.
Reflection
How did actual latency and reliability compare to your expectations? Use that observation to adjust architecture choices.
