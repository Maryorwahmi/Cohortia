Practice: CoAP inspection

Open a CoAP GET exchange and spot the fixed four-byte header, optional token, and compact options rather than verbose text headers. Notice how this reduces packet size for constrained devices.

Mnemonic: Tiny Postcard
Practice: WebSocket broadcast

Run a server that emits sensor_data events and confirm multiple browsers receive updates instantly. This demonstrates full-duplex, low-latency interactions without polling.

Mnemonic: Open Line
Practice: BLE read

Scan for a peripheral, connect as a central, and read a characteristic value to see how GATT organizes data into services and characteristics.

Mnemonic: Service Shelf
Practice: Protocol selection

Compare transport, model, and overhead for a sample design: wearable tracker, realtime dashboard, or LPWAN sensor. Justify your protocol choice in one sentence.
