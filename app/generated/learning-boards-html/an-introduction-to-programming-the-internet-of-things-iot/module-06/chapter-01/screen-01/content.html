Advanced IoT Protocols

Understand compact transports, persistent channels, and ultra-low-power wireless, and learn how they map to common hardware and apps.

Duration ~35 min • Beginner
CoAP
UDP-based, compact messaging for constrained sensors and LPWANs.
WebSockets
Persistent TCP channel for real-time dashboards and control.
BLE
Short-range, very-low-power radio for wearables and beacons.
Explore Key Topics
Transport & Overhead
Choose UDP for minimal bytes, TCP for reliability, RF for local devices.
Messaging Models
Request-response, publish-subscribe, or bidirectional streaming shape architecture.
Security Options
DTLS for CoAP, TLS for WebSockets, pairing and GATT security for BLE.
Protocol Snapshot
CoAP
UDP, binary options, supports observe for publish-subscribe patterns.
WebSockets
Full-duplex, low-latency, server push without polling.
BLE
GATT services and characteristics, peripheral and central roles.
Practical orientation

This chapter focuses on when each protocol is useful and provides short code examples for Raspberry Pi and Python libraries. You will practice building a WebSocket server and scanning BLE devices. Use CoAP when packet size and power matter; use WebSockets when interactive updates must be instant; use BLE when range is short and battery must last months.
