bluepy central example
from bluepy.btle import Peripheral, UUID

device = Peripheral("aa:bb:cc:dd:ee:ff")
service = device.getServiceByUUID(UUID("0000180a-0000-1000-8000-00805f9b34fb"))
char = service.getCharacteristics()[0]
value = char.read()
print(f"Sensor value: {value}")
device.disconnect()
This snippet connects to a known MAC address, retrieves a service by UUID, reads the first characteristic, and closes the connection. Interpret the returned bytes according to the device's spec.
Concrete scenario
A Pi polls a fitness band once per minute, reads heart rate characteristic, and forwards the data to a cloud service via a WebSocket or HTTP API.
Pitfall
Characteristic payloads may be raw bytes; check the device documentation before assuming text encoding.
