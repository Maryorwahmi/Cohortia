Python aiocoap client

This example creates a context, issues a GET to a coap URI, waits for the response, and prints the payload. It shows the simplicity of client-side reads on constrained networks.

import asyncio
from aiocoap import Context, Message

async def main():
  protocol = await Context.create_client_context()
  request = Message(code=GET, uri='coap://192.168.1.50/sensors/temperature')
  response = await protocol.request(request).response
  print(f"Result: {response.payload.decode()}")

asyncio.run(main())
Tip
Use asynchronous code so the device can sleep between operations and avoid blocking loops.
Pitfall
Do not assume DTLS is automatic; configure security separately if you need encrypted UDP traffic.
Concrete example
A gateway polls a battery-powered temperature sensor once per hour. The gateway uses this simple client to read the sensor resource and forward the payload to a backend.
Key takeaway
aiocoap hides UDP details so your code remains compact and focused on payload handling.
