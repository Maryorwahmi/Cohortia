Comparison
Storage strategies
Match storage to durability, query, and retention needs.
SQLite (gateway)
Durable local buffer for unsent records, easy to query and small footprint.
Time-series DB
Optimized storage for range queries, downsampling, and fast charting.
Data lake / archive
Long-term compressed storage for historical analysis and backups.
Concrete example
The Raspberry Pi writes readings to SQLite with a sent flag. The cloud channel stores recent time-series points for charts, and a scheduled job exports older data to long-term storage if needed.
Key Takeaway

Combine local persistent buffers with cloud time-series stores and archival layers to balance durability and query needs.
