Definition
Error handling, retries, and fault tolerance testing
Design for interruptions and validate recovery with tests.
Practical tactics
  • Emit error tokens for out-of-range sensor readings.
  • Persist unsent rows with a sent flag and transactional writes.
  • Use scheduled batch uploads, interpret HTTP responses, and back off on rate limits.
  • Alert when buffers exceed expected size or when repeated failures occur.
Validation tests
  1. Disconnect serial for 5 minutes; confirm resume and no duplicates or losses beyond buffer limits.
  2. Disconnect Wi‑Fi for 10 minutes; confirm buffered rows upload when reconnected.
  3. Send malformed messages and verify parser handles them gracefully without crashing.
  4. Measure latency from sample timestamp to cloud update for performance baselining.
Key Takeaway

Test failure modes deliberately and design buffers and retries so the system recovers without data loss wherever practical.
