Architecture
Cloud ingestion and validation
Treat incoming data as untrusted and design clear success/failure paths.
Core ingestion steps
  • Authenticate sender with API key or token.
  • Validate formats and numeric ranges per field.
  • Enforce rate limits and return clear status codes.
  • Route valid records to storage or analytics pipelines.
Example behavior
When ThingSpeak responds with a non-success code, the gateway should leave rows marked unsent and retry later. If the response indicates rate limiting, back off for a longer interval to avoid repeated failures.
Key Takeaway

Design predictable success/failure responses and ensure gateways act on those responses to keep local state consistent with cloud acceptance.
