Arduino edge code example
A moving-average sketch that prints CSV to serial.
// Arduino sketch (simplified)
void setup() {
  Serial.begin(9600);
}

void loop() {
  long soilSum = 0, lightSum = 0;
  float tempSum = 0, humSum = 0;

  for (int i = 0; i < 5; i++) {
    soilSum += analogRead(A0);
    lightSum += analogRead(A1);
    // DHT22 readings (simplified)
    tempSum += 25.0;
    humSum += 60.0;
    delay(2000);
  }

  int soilAvg = soilSum / 5;
  int lightAvg = lightSum / 5;
  float tempAvg = tempSum / 5;
  float humAvg = humSum / 5;

  Serial.print("SOIL:"); Serial.print(soilAvg);
  Serial.print(",LIGHT:"); Serial.print(lightAvg);
  Serial.print(",TEMP:"); Serial.print(tempAvg);
  Serial.print(",HUM:"); Serial.println(humAvg);
}
Explanation
  • A five-sample average reduces transient spikes and noise.
  • Delays space readings; for more tasks consider non-blocking timing.
  • Serial-formatted output should be predictable for parsing on the gateway.
  • Add range checks to detect sensor faults or calibration drift.
Key Takeaway

Keep edge code simple, deterministic, and produce clearly parseable output; detect and report out-of-range values.
