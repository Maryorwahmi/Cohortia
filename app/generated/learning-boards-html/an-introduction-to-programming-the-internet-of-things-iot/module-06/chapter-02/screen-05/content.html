Definition
Sensing: from physics to readings
How ADCs and digital sensors produce usable data.
What to design
  • Sampling frequency — how often to read the sensor.
  • Filter strategy — moving average, median, or low-pass filter.
  • Validity checks — acceptable numeric ranges and error codes.
  • Power profile — sampling vs sleep trade-offs for battery devices.
Common mistake
Sampling too fast without improving signal quality and burning power.
Concrete example
Soil moisture analog values vary quickly when the probe is moved. A five-sample moving average taken every 10 seconds stabilizes the value so the gateway sees one averaged record every 30 seconds. If the measured value is outside a plausible range, the Arduino emits an error token instead of a numeric reading.
Key Takeaway

Sample thoughtfully, apply simple filters at the sensor, and emit clear error signals when readings fall outside expected ranges.
