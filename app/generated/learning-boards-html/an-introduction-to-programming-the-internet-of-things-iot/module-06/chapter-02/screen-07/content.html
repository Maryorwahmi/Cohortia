Transmission: protocols, latency, and trade-offs
Match the transport to your device needs.
Serial
Reliable local link between microcontroller and gateway. Low latency, limited range. Ideal for Arduino→Pi connections.
HTTP
Simple cloud uploads but higher overhead per request. Use batching to reduce calls and handle rate limits with backoff.
MQTT
Lightweight publish/subscribe suitable for frequent small messages and low-power devices, needs a broker.
Concrete example
The Pi uploads up to ten unsent SQLite rows to ThingSpeak in a single HTTP request every two minutes. On network failure it retries on the next cycle.
Key Takeaway

Use batching and exponential backoff where possible to reduce requests and handle transient network failures gracefully.
