Definition
Visualization and analytics
Design dashboards and alerts that turn data into decisions.
Dashboard elements
  • Current values and recent history graphs.
  • Trend detection and simple analytics like moving averages.
  • Alerting with thresholds and hysteresis to reduce noise.
  • Local fallbacks for offline visibility using buffered data.
Smart garden example
ThingSpeak provides charts for each field and triggers an IFTTT email when moisture is low. The Flask dashboard on the Pi reads SQLite for a local 24-hour trend and immediate readings if cloud connectivity is lost.
Key Takeaway

Provide actionable displays and tune alerts. Use local dashboards for resilience during outages.
