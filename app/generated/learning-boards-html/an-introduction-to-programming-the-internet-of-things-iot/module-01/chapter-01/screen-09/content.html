The five-layer architecture
A consistent stack helps you name components and make design decisions at each level.
Device
Sensors, actuators, microcontrollers that touch the physical world.
Edge / Gateway
Aggregates devices, performs local processing, reduces latency and bandwidth.
Network
Local and wide-area links: Wi‑Fi, Bluetooth, LoRa, cellular.
Cloud
Storage, analytics, device management, APIs and large-scale processing.
Application
Dashboards, mobile apps, alerts, and control interfaces used by people.
Example — soil moisture system
Device: moisture sensor and microcontroller. Edge: Raspberry Pi aggregates many sensors. Network: LoRaWAN sends summaries. Cloud: time-series DB and rules engine. Application: web dashboard and automated irrigation control.
Design note
Separating edge and cloud clarifies where to do filtering, privacy enforcement, and latency-sensitive actions.
