Network trade-offs
Networks differ in range, data rate, power use and cost. Match the protocol to the device's needs and environment.
Wi
Wi‑Fi
High bandwidth, good for cameras and gateways; higher power use makes it unsuitable for tiny battery sensors.
BT
Bluetooth LE
Low-power short-range protocol for wearables and local device pairing.
LR
LoRa / ZigBee
Low-power, long-range or mesh networking for distributed sensors and city deployments.
4G
Cellular (4G/5G)
Wide coverage for mobile or remote devices; can be pricier and consume more power.
Concrete example — an outdoor weather sensor
If the sensor transmits small packets hourly and must run for months on a battery, choose a low-power protocol like LoRaWAN. If streaming images are required, Wi‑Fi or cellular is necessary despite higher power use.
Common pitfall
Selecting Wi‑Fi because it is familiar, while ignoring battery and signal-range constraints that make other protocols better choices.
Key Takeaway

Match network to the payload and power budget: bandwidth and coverage drive network choice, not familiarity.
