Response time segments
Sensor read
ADC or sensor sampling delay
Processing
Firmware compute time
Network
Radio wake, transmission, routing
Actuation
Physical mechanism response
Example budget: sensor 5 ms, processing 10 ms, network 60 ms, actuation 25 ms → total 100 ms. To hit a tighter goal, identify the largest contributors and optimize them: move processing local, reduce network hops, or select faster radios.
Concrete scenario
Smart door unlock: requirement under 500 ms. Focus on fast sensor read, local processing for fingerprint verification, and low-latency actuation to meet the constraint.
Misconception
Optimizing only sensor speed may not help if network latency dominates. Always measure end-to-end.
