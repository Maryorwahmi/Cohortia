Module 1 › Chapter 1.2 › Key Concepts
Embedded system
Processor, memory, I/O, and firmware optimized for one task.
Microcontroller
Low cost and low power for simple sensing and control.
SBC & SoC
SBCs run full OS and are powerful; SoCs combine MCU and wireless for battery devices.
Summary

Use these core distinctions to start every design: identify constraints, then pick the processor and connectivity that satisfy them.
