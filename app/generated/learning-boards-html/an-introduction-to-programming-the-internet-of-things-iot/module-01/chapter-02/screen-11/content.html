Module 1 › Chapter 1.2 › Security vs Convenience
Security cost components
  • CPU cycles for cryptography.
  • Memory for keys, certificates, and secure storage.
  • Flash space for secure updates and rollback protection.
Designers must budget these resources and choose lightweight protocols when hardware is constrained or offload to a gateway when possible.
Concrete example
A remote sensor should authenticate to the server using lightweight handshakes and maintain an update mechanism. Avoid disabling security to save a few dollars.
Common-mistake
Designers assume security can be added later without hardware changes. In many constrained devices, hardware limits make later additions infeasible.
