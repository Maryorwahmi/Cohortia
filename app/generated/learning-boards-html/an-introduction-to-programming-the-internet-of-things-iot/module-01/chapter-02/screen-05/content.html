Quick comparison cards
Microcontroller (MCU)
Low cost, milliwatt power, ideal for simple sensors and actuators. Example cost range: low dollars.
Single-board computer (SBC)
Higher performance, runs Linux, suitable for gateways and heavy processing. Consumes watts and costs more.
SoC with wireless
Includes Wi‑Fi or Bluetooth on a microcontroller-class chip, balancing low power and connectivity for battery devices.
Misconception
Assuming a single processor class fits all cases. Instead, match the class to cost, power, and capability needs of the scenario.
Scenario mappings
Microcontroller: simple temperature logger, event counters, LED control. SBC: local dashboard, protocol gateway, computer vision prototype. SoC+wireless: wearable fitness tracker, battery sensors needing Wi‑Fi or Bluetooth.
Example justification
If you must run for 7 days on one charge, avoid SBCs. If you need local web serving and protocol bridging for 50 sensors, prefer an SBC for CPU and memory headroom.
Key Takeaway

Match hardware class to role: conserve power with MCUs, get capability with SBCs, or choose SoCs for built-in wireless and balanced power.
