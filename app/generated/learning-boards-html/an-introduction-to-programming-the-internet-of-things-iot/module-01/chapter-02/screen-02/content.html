Learning Objectives

Bloom progression: Learn → Understand → Apply → Master

01
Define an embedded system
Explain processor, memory, I/O, and firmware and why these are optimized for a single purpose.
Mnemonic: "PIMS" — Processor, I/O, Memory, Software
VERIFIED COMPETENCY MILESTONE
02
Compare processor classes
Distinguish microcontrollers, microprocessors, and SBCs using cost, power, and OS capability.
Mnemonic: "Small, Medium, Large" capacity and power
VERIFIED COMPETENCY MILESTONE
03
Evaluate design trade-offs
Apply cost vs capability and power vs performance reasoning to pick hardware.
Mnemonic: trade-off triangle
VERIFIED COMPETENCY MILESTONE
04
Identify key constraints
Recognize how power, size, connectivity, security, and response time limit design choices.
Mnemonic: "P S C S R" — Power Size Connectivity Security Response
VERIFIED COMPETENCY MILESTONE
