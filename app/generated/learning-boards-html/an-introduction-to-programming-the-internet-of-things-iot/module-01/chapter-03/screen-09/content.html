Module 2 › Chapter 1.3 › Gateway Role
Definition

What a gateway does

A gateway bridges local sensor networks and the internet, translating protocols and optionally processing data at the edge before forwarding to cloud services.

Translation
Converts ZigBee/Bluetooth frames to TCP/IP packets for cloud transport.
Edge processing
Filtering, aggregation, and light analytics to reduce cloud load.
Practical note
In many designs the gateway also handles security boundaries and may cache messages when cloud connectivity is intermittent.
Concrete example
A Raspberry Pi gateway receives ZigBee sensor data, aggregates readings every minute, filters noise, and forwards compact payloads to the cloud via HTTPS or MQTT over TCP.
Warning

Avoid centralizing all logic at the gateway without redundancy; the gateway can be a single point of failure.

Key Takeaway

Use gateways to translate, reduce bandwidth, and handle intermittent cloud connectivity, but design for redundancy if required.
