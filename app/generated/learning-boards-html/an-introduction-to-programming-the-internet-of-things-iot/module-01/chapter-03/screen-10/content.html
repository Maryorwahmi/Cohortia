Code-like example
# Service → port mapping (illustrative)
HTTP  -> 80
HTTPS -> 443
MQTT  -> 1883
MQTT over TLS -> 8883
SSH   -> 22

# Example: device connecting to broker
connect to 198.51.100.10:1883
publish topic 'sensors/1' payload '{"t":22.4}'
This snippet shows how IP and port together locate a service. Firewalls and gateways must permit the correct port pairings for communication to succeed.
Concrete example
A sensor publishes to broker.example on port 1883. If the gateway blocks port 1883, the connection will fail even if DNS resolves the broker address.
Key Takeaway

Ports are part of the address used to reach a service. Verify both IP and port when diagnosing connectivity issues.
