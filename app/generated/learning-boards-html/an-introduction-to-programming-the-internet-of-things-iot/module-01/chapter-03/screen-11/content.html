Module 2 › Chapter 1.3 › IoT Protocols
Protocol

MQTT

Publish-subscribe broker model, commonly runs over TCP. Offers different quality-of-service levels and is popular for telemetry and control when reliable delivery is desired.

Protocol

CoAP

A web-like protocol for constrained devices that often runs over UDP to reduce transport overhead. It supports confirmable messages at the application layer when needed.

Concrete example
Choose MQTT over TCP when ordered, reliable delivery to a broker is important. Choose CoAP over UDP when the device needs minimal transport overhead and can manage acknowledgments at the application level.
Key Takeaway
Match application requirements to protocol features and transport overhead.
Misconception
Transport choice is protocol-dependent; some protocols can add reliability at the application layer.
Check
Ask: Does the application require ordered, guaranteed delivery or minimal overhead?
