Learning Objectives

Four practical outcomes for designing and evaluating IoT networks.

Bloom: Learn → Understand → Apply → Master
01
Explain IP, TCP, UDP

Describe addressing and the trade-offs between reliable and lightweight transports.

VERIFIED COMPETENCY MILESTONE
02
Differentiate comms models

Contrast client-server and publish-subscribe and explain when to use each model.

VERIFIED COMPETENCY MILESTONE
03
Describe network topologies

Explain star, mesh, and point-to-point topologies and their resilience and latency implications.

VERIFIED COMPETENCY MILESTONE
04
Identify gateway responsibilities

List how a gateway translates protocols, aggregates data, and forwards to the cloud.

VERIFIED COMPETENCY MILESTONE
These objectives map to practical tasks: inspecting device IPs, choosing UDP for streaming sensors, designing a mesh for range, and configuring a gateway to bridge local radios to TCP/IP.
