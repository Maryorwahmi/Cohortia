Quick diagnostic checklist

  1. Verify device IP is assigned and in the expected private range.
  2. Confirm DNS resolves the cloud service domain to an IP.
  3. Check that the target service is listening on the expected port.
  4. Look up the device MAC in the router's client list to confirm local link visibility.
  5. For mesh, verify routing and that intermediate nodes are awake and forwarding.
Common mistake
Treating normal UDP loss as application failure. For streaming sensors, occasional lost datagrams may be acceptable.
Pro tip
Use gateway edge processing to reduce cloud traffic and to create local confirmations for critical events before forwarding.
Check
Ask: Does the problem look like DNS failure, port blocked, absent MAC, or mesh routing issue?
