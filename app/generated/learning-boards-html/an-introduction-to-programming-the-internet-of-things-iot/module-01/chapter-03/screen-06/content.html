Architecture

How these identifiers interact

DNS gives you an address to connect to. MAC ensures delivery on the local link. Ports pick the service on the destination device.

DNS
Resolves domain names to IP addresses; used before connecting to cloud services.
MAC address
Hardware identifier on the local network used by switches and bridges.
Ports
Numeric service entry points like 80 for HTTP or 1883 for MQTT.
Concrete example
A camera looks up camera-cloud.example and receives an IP. The camera's network frame includes its MAC so the router can forward locally, and the application connects to the cloud IP at port 443 for secure upload.
Troubleshooting
If a device cannot reach a service, check DNS resolution first, then verify the IP and service port, and finally confirm link-level delivery via MAC address visibility on the router.
Key Takeaway

Name resolution, link-level addressing, and service ports together determine whether a device can reach the correct endpoint.

Check your understanding
Ask: If a device has an IP but cannot connect, did DNS resolve, does the service listen on the expected port, and is the device visible in the router's MAC list?
