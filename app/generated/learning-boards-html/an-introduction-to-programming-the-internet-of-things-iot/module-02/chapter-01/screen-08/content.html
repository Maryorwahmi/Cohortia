Common types
  • int — integer numbers for general use.
  • float — decimal numbers, use sparingly.
  • byte / unsigned int — small positive values, memory efficient.
  • char — single characters; C-style strings use char arrays.
Memory practice
Prefer scaled integers over floats when possible. For example, store millivolts as integers instead of volts as floats to save RAM.
Key Takeaway

Matching types to data keeps memory usage low and code responsive on small microcontrollers.

Concrete example
A temperature stored as an int in tenths of degrees avoids using a float array. For a 2 KB SRAM board, that difference matters when you buffer samples.
Misconception
String objects are convenient but can fragment heap memory over time. Use fixed-size char arrays when you format repeated serial messages.
Quick reference
  • Use byte for small counts.
  • Use long for timestamps if needed.
  • Minimize float arrays on small Arduinos.
