Module 2 › Chapter 2.1 › Strings & memory
Char arrays
Fixed-size buffers that you control. Use snprintf to format safely into these buffers for Serial output.
String objects
Easier to code but allocate on the heap. Repeated concatenation can fragment memory over time on small boards.
Concrete example
Format CSV with snprintf into a char buffer: this produces deterministic memory usage and is safer for long-running sketches that send frequent messages.
Misconception
While String is convenient, it can cause subtle failures in deployed devices. Choose fixed buffers for reliability.
Key Takeaway

Prefer char arrays and formatted printing for stable serial messaging in memory-limited IoT devices.
