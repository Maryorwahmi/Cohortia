Module 2 › Chapter 2.1 › Control structures
If / else
Use for branching logic based on sensor values or command input. Example: if temperature > threshold then activate fan.
For loop
Use when you know the number of iterations, for instance iterating over a small buffer to compute an average.
While loop
Use with caution. While can block program flow if the exit condition depends on slow events or absent serial input.
Concrete example
Use a for loop to sum the last five samples stored in an array then divide to compute the average. Inside a timeout window, check Serial.available to allow remote commands to interrupt long operations.
Common mistake
Blocking loops that wait for events without checking serial input cause missed commands and unresponsive devices.
Key Takeaway

Choose structures that balance clarity with responsiveness; prefer short iterations or non-blocking timers when accepting serial commands.
