Module 2 › Chapter 2.1 › Functions & arrays
Function benefits
  • Encapsulate repeated behavior.
  • Improve readability and testability.
  • Pass parameters to reuse logic across sensors.
Array uses
Store recent samples for averaging, hold calibration tables, or buffer values before sending to a gateway. Keep arrays small on devices with limited SRAM.
Concrete scenario
Create a function readSensor() that returns a scaled integer. Use an array samples[5] to store values and a function average(samples) to compute the mean before sending.
Stack caution
Avoid large local arrays inside functions; allocate them globally or pass references to reduce stack pressure on small microcontrollers.
Key Takeaway

Modular functions and small arrays make sketches easier to maintain and reduce bugs during integration with external systems.
