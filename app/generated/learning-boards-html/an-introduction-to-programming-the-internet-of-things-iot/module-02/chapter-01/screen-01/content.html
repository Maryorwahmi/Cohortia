Arduino Setup and C Programming for IoT

Install the IDE, understand board and port selection, and write sketches that initialize sensors, read data, and communicate over serial. This chapter focuses on practical, repeatable patterns for IoT prototypes.

In this lesson
You will set up the Arduino IDE, view the blink example, write a sensor-reading sketch, and use the Serial Monitor to send and receive simple commands.
Why it matters
Small boards and simple code let you iterate quickly. Understanding setup, loop and serial saves time when your prototype must report sensor data reliably.
Explore Key Topics
IDE & Boards — configure board and serial port to upload and debug.
Sketch Structure — how setup runs once and loop repeats indefinitely.
Serial I/O — send readings and accept simple commands for remote control.
Visual concept
IDE & Upload
Select board and serial port, open the Serial Monitor to see output and type commands back to the board.
Sketch Lifecycle
setup() runs once. loop() repeats. Use setup to configure pins and Serial; use loop to read sensors and send data.
Data Types
Choose int, float, or byte carefully. Memory on small Arduinos is limited to a few kilobytes.
Serial Protocols
Send CSV or JSON for structured parsing. Use Serial.available() before reading to avoid errors.
Starter example
void setup() {
  Serial.begin(9600);
  pinMode(13, OUTPUT);
}

void loop() {
  digitalWrite(13, HIGH);
  delay(1000);
  digitalWrite(13, LOW);
  delay(1000);
}
