Module 2 › Chapter 2.1 › setup() and loop()
Pattern
Read → Process → Send → Wait

Use setup to start Serial and configure pins. Use loop to implement periodic sensor reads, simple processing such as averaging, and communication to a gateway.

Non-blocking tip
Avoid long blocking delays if you need to respond to serial commands. Consider state timers or shorter sleep intervals to poll for input.
Common mistake
Placing heavy processing in setup so that loop never has a chance to run as intended, or using large delays that block serial parsing.
Example: temperature logger
Read sensor every 10 seconds, push value into an array of five samples, compute average, and send average to the gateway once a minute. Then continue sampling. This balances local smoothing with less frequent transmissions to save bandwidth.

Key Takeaway

Structure code around initialization and repeatable cycles; plan for responsiveness when accepting serial commands.
