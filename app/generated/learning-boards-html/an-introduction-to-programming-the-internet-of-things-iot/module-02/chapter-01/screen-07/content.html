Transform
Use the ADC value and known reference to compute voltage or temperature with simple arithmetic. Be explicit about the divisor to preserve precision.
int sensorValue = analogRead(A0);
float voltage = sensorValue * (5.0 / 1023.0);
Serial.print("Sensor: ");
Serial.print(sensorValue);
Serial.print("  Voltage: ");
Serial.println(voltage);
delay(1000);
Averaging with arrays
Store recent samples in a small array, compute the average before sending. Arrays use SRAM, so pick a small buffer size on an Uno.
Example flow
  1. Read ADC using analogRead.
  2. Convert counts to voltage or temperature.
  3. Push value into a circular buffer for averaging.
  4. Format as CSV or JSON and send over Serial.
Memory note
Arduino Uno has limited SRAM (about 2 KB); avoid large arrays or many String objects to prevent fragmentation or crashes.
Key Takeaway

Transform raw readings into useful units and manage buffering and formats with memory constraints in mind.
