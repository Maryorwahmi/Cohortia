Module 2 › Chapter 2.2 › Voltage Divider
Architecture
Sensor + fixed resistor → measurable voltage
The ADC reads the midpoint voltage of a divider. For best sensitivity, the fixed resistor should be similar to the sensor resistance at the operating point.
Example setup
LDR in series with 10k resistor; midpoint to A1. Cover the LDR and watch the analogRead change from high to low values.
Convert to percentage
Read raw = analogRead(A1). voltage = (raw / 1023.0) * Vref. Map expected dark and bright voltages to 0–100% for a useful light level.
Pitfall
If sensor values stay near 0 or 1023, change the fixed resistor so the range centers in the ADC span.
