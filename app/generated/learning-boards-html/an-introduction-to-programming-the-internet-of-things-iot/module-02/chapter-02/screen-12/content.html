Module 2 › Chapter 2.2 › Hysteresis
Process
Low threshold → turn on. High threshold → turn off.
Maintain state. Only change when the corresponding threshold condition is met to avoid toggling when values bounce near the threshold.
Example thresholds: lowThreshold = 300, highThreshold = 500. Use filtered readings to decide.
Example code snippet
const int lowThreshold = 300;
const int highThreshold = 500;
bool lightOn = false;

void loop() {
  int lightLevel = analogRead(A0);
  if (!lightOn && lightLevel < lowThreshold) {
    digitalWrite(ledPin, HIGH);
    lightOn = true;
  } else if (lightOn && lightLevel > highThreshold) {
    digitalWrite(ledPin, LOW);
    lightOn = false;
  }
}
Choose thresholds based on filtered measurement variance; larger variance needs a wider hysteresis gap.
