Module 2 › Chapter 2.2 › Analog Sensors
Definition
analogRead → 0..1023 mapping
The analogRead function returns a 10-bit integer. Convert counts into voltage using the reference voltage before applying sensor-specific formulas.
Formula
voltage = (analogRead(pin) / 1023.0) * Vref
Concrete example
If analogRead(A0) returns 512 and the board is 5V, voltage = (512 / 1023.0) * 5.0 ≈ 2.5V. This voltage is the starting point for sensor conversions.
Check your assumptions
Different Arduino boards use different reference voltages. Confirm Vref before converting.
