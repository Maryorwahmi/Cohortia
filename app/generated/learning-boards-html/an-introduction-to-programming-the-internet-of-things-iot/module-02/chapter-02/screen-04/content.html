Module 2 › Chapter 2.2 › Digital Sensors
Core Concept
Binary signals and pull-ups
Digital sensors output HIGH or LOW. INPUT_PULLUP keeps an unused input at HIGH until a switch connects it to ground.
Common mistakes
  • Leaving inputs floating causes random HIGH/LOW reads.
  • Forgetting debounce leads to multiple false triggers on a single press.
Key Takeaway
Define pin state with INPUT_PULLUP and treat LOW as pressed when wired to ground.
Concrete example
const int buttonPin = 2;
const int ledPin = 13;

void setup() {
  pinMode(buttonPin, INPUT_PULLUP);
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int buttonState = digitalRead(buttonPin);
  if (buttonState == LOW) {
    digitalWrite(ledPin, HIGH);
    Serial.println("Button pressed!");
  } else {
    digitalWrite(ledPin, LOW);
  }
  delay(50);  // Simple debounce
}
Analogy: pull-up is like a spring that holds the state until you press the button.
Check: if Serial prints without pressing, you likely have a wiring issue or no pull-up.
