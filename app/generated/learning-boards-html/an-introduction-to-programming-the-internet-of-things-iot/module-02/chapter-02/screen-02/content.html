Module 2 › Chapter 2.2 › Learning Objectives
01
Interface digital sensors
Configure inputs like switches, PIR, and Hall sensors so the Arduino reliably detects HIGH or LOW events. Practicing this reduces false reads from floating pins.
VERIFIED COMPETENCY MILESTONE
02
Interface analog sensors
Use analogRead to capture variable voltages from TMP36, LDRs, and potentiometers and understand the mapping from 0–1023 counts to voltage.
VERIFIED COMPETENCY MILESTONE
03
Convert and calibrate sensor readings
Apply formulas and two-point or multi-point calibration so readings reflect real units like °C or percentage light level.
VERIFIED COMPETENCY MILESTONE
04
Filter and detect thresholds
Use averaging, median filters, and exponential smoothing plus hysteresis-based thresholds to trigger actions reliably without flicker.
VERIFIED COMPETENCY MILESTONE
