Two-point calibration
Measure two known references
Record raw readings at two known physical points, compute slope and intercept, then apply the linear conversion in code.
// Two-point calibration example
// At 0°C raw = 100
// At 100°C raw = 920
float calibrateTemperature(int raw) {
  float slope = 100.0 / (920.0 - 100.0);
  return (raw - 100.0) * slope;
}
Multi-point calibration
Collect multiple reference pairs and fit a polynomial or build a lookup table for non-linear sensors. Validate with independent references.
Practical note
Store calibration constants in EEPROM or in code so you don't need to recalibrate every run.
