Module 2 › Chapter 2.2 › Button Debounce
Process Flow
Wire → Pull-up → Read → Debounce
  1. Wire button: pin to one side, ground to the other.
  2. Enable pinMode(pin, INPUT_PULLUP) so open state is HIGH.
  3. Read digitalRead(pin) and treat LOW as pressed.
  4. Debounce: require a stable read for a short window before accepting a change.
Pro tip
Use a non-blocking timestamp method if your loop must do other tasks while debouncing.
Non-blocking debounce pattern (concept)
// Concept: check time, accept new state only after stable interval
int lastState = HIGH;
unsigned long lastChange = 0;
const unsigned long debounceMs = 30;

void loop() {
  int reading = digitalRead(buttonPin);
  if (reading != lastState) {
    lastChange = millis();
  }
  if ((millis() - lastChange) > debounceMs) {
    // state has been stable for debounceMs
    // handle stable state change here
  }
  lastState = reading;
}
Example: count presses by incrementing a counter when a stable LOW is detected.
Misconception: delay-based debounce blocks sensor reads and is bad for multitasking.
