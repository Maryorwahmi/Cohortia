Definition Sensor modules & libraries

What a module contains

  • Sensor chip (e.g., BME280).
  • Support components: pull‑ups, level shifters, regulators.
  • Standard connector pins and a consistent communication interface.
Why use libraries
They provide initialization, calibration, and friendly read functions so you can get physical units quickly.

Concrete scenario

Install Adafruit_BME280 and Unified Sensor libraries. Run the example. If temperature looks wrong, run an I2C scanner and then a raw-read sketch to compare ADC values.
Check your understanding: If the library initializes but values are steadier than expected, could the sensor be reading a nearby heat source? Consider placement as well as wiring.
