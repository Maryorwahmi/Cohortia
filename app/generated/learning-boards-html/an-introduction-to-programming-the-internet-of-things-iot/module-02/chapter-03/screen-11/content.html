Process Flow Troubleshooting I2C

Checklist

  1. Run an I2C scanner to list addresses.
  2. If duplicate addresses, change AD0/ADDR or use a multiplexer.
  3. Confirm common ground and correct VCC for each module.
  4. Add external 4.7k pull‑ups on SDA and SCL if necessary.
  5. Test devices one at a time to isolate faults.

Concrete example

If two modules return the same address 0x68 and one has an AD0 pin, change that pin to VCC or GND as the datasheet instructs to move the address to 0x69. If neither module exposes an address pin, place a TCA9548A I2C multiplexer between them.
Pro tip
Label devices and record addresses during initial setup. When adding a new device re-run the scanner to catch conflicts early.
