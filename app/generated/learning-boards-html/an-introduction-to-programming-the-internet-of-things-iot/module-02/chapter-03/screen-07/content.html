Core Concept SPI fundamentals

Signals & pins

  • MOSI (master out, slave in) — Arduino pin 11.
  • MISO (master in, slave out) — Arduino pin 12.
  • SCK (clock) — Arduino pin 13.
  • CS (chip select) — one digital pin per device.
Practical note
SPI mode and clock frequency must match the peripheral’s requirements. Check the device datasheet or library defaults.

Example devices

MicroSD card modules
NRF24L01 transceivers
MAX7219 LED drivers
Ethernet controllers (W5100/W5500)
Analogy: SPI is a multi‑lane highway with a separate gate (CS) for each destination. Only the gate you open will accept cars; otherwise collisions occur.
