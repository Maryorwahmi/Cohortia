01 — Compare
I2C vs SPI mnemonic
I2C: 'Two wires, many addresses'. SPI: 'Four lanes, one guard per device'. Use the mnemonic when choosing a bus for sensors.

02 — I2C Practice
Scan & read
Run an I2C scanner, note addresses like 0x76 for BME280, then read registers with Wire to verify raw data before using a library.

03 — SPI Practice
Toggle CS
Assert chip select low, transfer command and read response. Use prints to confirm SPI responses from SD or display drivers.

04 — Modules
Library then debug
Install module libraries, initialize in setup, and validate Serial output. If values are wrong, inspect the bus with an I2C scanner or check pull-ups.
