Hands-on Activity BME280 + SSD1306

Wiring checklist

  • SDA → A4, SCL → A5, GND → GND, VCC → 3.3V.
  • Confirm module voltage labels (3.3V vs 5V).
  • Optional: add 4.7k pull‑ups on SDA and SCL if unstable.

Software steps

  1. Install Adafruit_BME280, Adafruit_SSD1306, and Unified Sensor libraries.
  2. Run each library example to confirm initialization.
  3. Combine reads: print values to Serial and draw to OLED every 2 seconds.
Verification: If a device fails to appear, run an I2C scanner. If two devices share an address use AD0/ADDR or a multiplexer. If readings fluctuate, add pull‑ups and check wiring. Record which fix resolved the issue.
