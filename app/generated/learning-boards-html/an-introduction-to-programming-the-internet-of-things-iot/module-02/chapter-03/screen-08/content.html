Process SPI code walkthrough

Example sketch (SPI)

#include <SPI.h>

const int csPin = 10;  // Chip select pin

void setup() {
  SPI.begin();
  pinMode(csPin, OUTPUT);
  digitalWrite(csPin, HIGH);
  Serial.begin(9600);
}

void loop() {
  digitalWrite(csPin, LOW);
  SPI.transfer(0x00);  // Send command
  byte response = SPI.transfer(0x00);  // Read response
  digitalWrite(csPin, HIGH);
  Serial.println(response);
  delay(1000);
}

Explanation

  • Set CS high when idle so no device is selected.
  • Bring CS low to start, transfer the command and read the response, then set CS high to end the transaction.
  • SPI.transfer both sends and receives because the clock moves bits both directions.
  • Use separate CS pins for each peripheral and ensure only one is low at a time.
Common mistake
Not raising previously used CS before lowering another leads to bus contention. Confirm CS states in code and wiring.
