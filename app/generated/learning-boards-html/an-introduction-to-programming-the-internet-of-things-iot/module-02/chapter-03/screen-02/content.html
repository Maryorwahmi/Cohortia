01
Explain I2C vs SPI

Describe signaling, wiring, addressing, and when to prefer one protocol. This helps you design reliable sensor networks with appropriate speed and pin usage.

VERIFIED COMPETENCY MILESTONE
02
Interface I2C sensors

Use the Wire library to start the bus, request bytes, and translate registers into temperature and humidity values for sensors like the BME280 and MPU6050.

VERIFIED COMPETENCY MILESTONE
03
Interface SPI devices

Initialize the SPI bus, toggle chip select pins, and transfer bytes to devices such as SD card modules or display drivers for fast data exchange.

VERIFIED COMPETENCY MILESTONE
04
Read composite modules

Use available libraries to query modules that combine sensors and interfaces, while understanding how to access lower-level registers if necessary.
