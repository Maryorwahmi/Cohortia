Module 8 › Chapter 8.2 › ThingSpeak Bug
Original code excerpt
import requests
import time

API_KEY = "YOUR_KEY"
URL = "https://api.thingspeak.com/update"

while True:
    temp = 25.5
    response = requests.get(URL, params={"api_key": API_KEY, "field1": temp})
    print(response.status_code)
    time.sleep(1)
The sleep value should be changed to 15 seconds to comply with the ThingSpeak rate limit and avoid rejected writes.
Fix
Replace time.sleep(1) with time.sleep(15) and move API keys to environment variables to prevent accidental exposure.
Pro tip

Check response codes and apply exponential backoff on errors rather than aggressive retries.

Key Takeaway

Obey API rate limits and handle error responses to maintain reliable uploads.
