IoT layers
Device to application layers determine where processing, storage, and control belong.
Protocol choice
MQTT suits frequent, small updates; HTTP polling is heavier and less efficient for battery devices.
Practical security
Keep secrets out of code, use encrypted transport, and add basic firmware and network protections.
Summary: design with constraints in mind — power, latency, security — and use simple, auditable patterns for reliability.
