Module 8 › Chapter 8.2 › MCQ Reasoning
Common correct answers
  • IoT vs internet: IoT connects physical objects to cloud and each other.
  • Edge role: Bridge devices to networks and perform local processing.
  • Arduino basics: setup runs once; loop runs continuously; Serial.begin sets baud rate.
Common mistakes
Choosing answers that confuse where work should be done, or assuming wireless implies IoT alone.
Practical example
If a temperature sensor must trigger an immediate alarm, placing that logic at the edge or on the device avoids cloud latency. Selecting the cloud for that job would be a design mistake
Key Takeaway

Answer choices usually encode trade-offs. Explain the trade-off to confirm the right selection.
