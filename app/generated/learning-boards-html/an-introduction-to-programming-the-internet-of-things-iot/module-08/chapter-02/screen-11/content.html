Module 8 › Chapter 8.2 › MQTT Subscriber
Problem snippet
import paho.mqtt.client as mqtt

def on_message(client, userdata, msg):
    print(msg.payload)

client = mqtt.Client()
client.on_message = on_message
client.connect("localhost", 1883)
client.subscribe("sensors/temperature")
# missing: client.loop_forever() or client.loop_start()
Add a network loop call, such as loop_forever, to process messages continuously.
Fix
Append client.loop_forever() for a blocking loop, or client.loop_start() to run in the background.
Key Takeaway

Connection is not processing. Start the network loop to receive messages.
