Practical security steps
  1. Store API keys in environment variables or secure vaults, not in source code.
  2. Use TLS/HTTPS to encrypt data in transit and avoid eavesdropping.
  3. Require authentication for device uploads and use signed firmware updates.
  4. Segment networks and apply firewalls to reduce attack surface.
Example
Store the ThingSpeak API key in an environment variable on the Pi, not in the Python file.
Key Takeaway

Small protections remove the most common routes for accidental exposure; start with secrets and transport.
