Module 8 › Chapter 8.2 › IoT Layers

Five layers explained

Device layer
Sensors and actuators that directly interact with the world.
Edge / Gateway
Local collection, pre-processing, and bridging to the network.
Network
Transport medium: Wi‑Fi, cellular, LPWAN — drives latency and reach.
Cloud
Scale storage, processing, analytics, and centralized services.
Application layer
Dashboards and mobile apps that present data and enable control.
Why it matters
Correctly assigning tasks preserves battery, reduces latency, and simplifies security boundaries.
Key Takeaway

Decide by constraints: time-critical actions at device/edge; heavy analysis in cloud.
