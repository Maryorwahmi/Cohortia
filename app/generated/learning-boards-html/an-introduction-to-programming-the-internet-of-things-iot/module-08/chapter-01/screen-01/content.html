Capstone Project: Smart Home Monitor

Build a complete IoT system that senses temperature, humidity, and light; controls a fan and lamp; logs data locally; uploads to the cloud; and provides a web dashboard for monitoring and control.

In this lesson

You will design hardware, write Arduino firmware, implement a Python gateway with SQLite buffering, integrate with ThingSpeak, and build a Flask dashboard.

Coming up

Fault tolerance tests and a demo video that proves the end-to-end system works under network faults.

Explore Key Topics
Hardware & Wiring
Arduino sensors, relay and motor driver details you must wire and test safely.
Edge Processing
Raspberry Pi parses JSON, timestamps, logs to SQLite and applies thresholds for actuators.
Dashboard & Cloud
Flask dashboard with Chart.js and ThingSpeak uploads with retry when offline.
System Concept
Royal blue accents mean primary flow
Note: The Pi performs edge decisions, buffering, and cloud uploads. This avoids blind spots when internet fails.
Safety: Use motor drivers for fan control and observe relay voltage/current limits for the lamp.
