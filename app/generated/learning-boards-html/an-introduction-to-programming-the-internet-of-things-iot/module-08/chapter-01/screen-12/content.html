Module 8 › Chapter 8.1 › Testing Plan
Fault injection checklist
  1. Disconnect serial: confirm Pi detects serial loss and reconnects gracefully.
  2. Disconnect Wi‑Fi: ensure SQLite buffers samples and uploader retries after reconnect.
  3. Malformed data: send broken JSON and verify parser logs but continues processing subsequent lines.
  4. Actuator tests: send commands and verify Arduino acknowledgement and physical actuation.
Evidence to collect: serial logs, SQLite row counts before/after reconnect, ThingSpeak chart updates, and a short recovery clip for your demo video.
Document expected results for each test and record the actual results in the project report for grading.
