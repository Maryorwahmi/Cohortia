Gateway responsibilities
Validate and parse JSON lines from serial. Add an ISO timestamp and insert into SQLite for history and buffering.
Apply threshold logic and control GPIO for the fan, or send serial commands to Arduino for the relay.
Buffer uploads and retry when internet connectivity returns to avoid data loss.
Debug tip: run the gateway in a terminal and watch both inserts and control outputs to confirm end-to-end behavior before adding cloud uploads.
Illustrative Python parsing and insert
# Pseudocode for gateway parsing
import json
import sqlite3
from datetime import datetime

# assume serial_line is a single-line JSON string
try:
  data = json.loads(serial_line)
  temp = float(data['temp'])
  hum = float(data['hum'])
  light = int(data['light'])
  ts = datetime.utcnow().isoformat()
  conn.execute('INSERT INTO samples(timestamp,temp,hum,light) VALUES (?,?,?,?)', (ts,temp,hum,light))
  conn.commit()
except Exception as e:
  print('parse error', e)
Ensure the insert matches your SQLite schema and add retry-safe transactions for resilience.
