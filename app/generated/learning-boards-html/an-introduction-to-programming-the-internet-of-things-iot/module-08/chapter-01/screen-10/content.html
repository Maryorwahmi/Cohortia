Dashboard features
  • Show current temperature, humidity, and light level.
  • Render a 24-hour trend with Chart.js using SQLite history.
  • Provide controls to set thresholds and buttons to manually toggle fan and lamp.
  • Use HTTPS and basic authentication on the Pi for local network access.
Example Flask route (illustrative)
# Flask endpoint to return latest sample
from flask import Flask, jsonify
app = Flask(__name__)

@app.route('/api/latest')
def latest():
  row = db.query_one('SELECT timestamp,temp,hum,light FROM samples ORDER BY timestamp DESC LIMIT 1')
  return jsonify(row)
Front-end Chart.js should call this API regularly or fetch historical rows for the 24-hour trend to keep the UI responsive and current.
