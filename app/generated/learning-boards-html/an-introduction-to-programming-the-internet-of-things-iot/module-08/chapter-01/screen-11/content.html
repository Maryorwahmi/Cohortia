Module 8 › Chapter 8.1 › Security
Minimum security checklist
  • Flask served over HTTPS (self-signed is acceptable for local labs).
  • Cloud uploads use TLS; do not send credentials in clear text.
  • Strong Pi password and SSH key authentication for remote access.
  • Limit open ports and disable unused services.
Practical steps
Generate an SSH keypair and add the public key to the Pi's authorized keys; disable password login.
Create a self-signed certificate for Flask or use a local reverse proxy like NGINX to terminate TLS.
Verify ThingSpeak or cloud endpoints are contacted using HTTPS and check certificate validation where possible.
