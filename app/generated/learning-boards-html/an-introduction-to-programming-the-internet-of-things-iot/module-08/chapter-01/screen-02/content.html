How you'll be assessed
Rubric items include hardware correctness, firmware readings and serial output, software logging and uploads, integration and documentation.
The hands-on activity spans two weeks with staged checkpoints: Arduino standalone, Pi gateway, cloud uploads, and dashboard.
Deliverables: working system demo, a project report, and a short demonstration video showing fault tolerance tests.
