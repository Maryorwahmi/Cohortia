Checklist for each milestone
  • Design: wiring diagram with pin numbers, voltages, and failure modes.
  • Hardware: breadboard test of sensors and actuators, recorded observations.
  • Software: serial JSON output verified and SQL rows stored with timestamps.
Delivery & Demo
Record a 3-minute demo video showing sensors, dashboard charts, and actuators responding to control inputs.
Prepare a project report with architecture diagram, code listings, test results, and challenges solved.
