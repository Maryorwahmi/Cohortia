Module 8 › Chapter 8.1 › Serial Communication
Recommended message flow
Arduino → Pi
One-line JSON every 5s: {"temp":25.5,"hum":60.2,"light":450}. Keep lines compact and predictable.
→
Pi → Arduino
Short ASCII commands for actuators: SET_LAMP:ON, SET_LAMP:OFF. Expect OK or ERROR replies.
Test: send SET_LAMP:ON; Arduino replies OK; Pi updates dashboard state.
Pitfall: no acknowledgement leads to uncertain actuator state. Add timeouts and retries.
