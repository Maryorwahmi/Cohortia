Upload policy
Schedule uploads every two minutes. On each run, select unsent rows from SQLite, attempt to upload them to ThingSpeak, and mark rows as sent only on HTTP success.
Resilience tip: implement exponential backoff for repeated failures and retain data until successfully uploaded to avoid silent data loss.
Uploader pseudocode
# Uploader loop pseudocode
while True:
  unsent = db.query('SELECT id,temp,hum,light FROM samples WHERE sent=0')
  for row in unsent:
    success = send_to_thingspeak(row)
    if success:
      db.execute('UPDATE samples SET sent=1 WHERE id=?', (row.id,))
  sleep(120)  # two minutes
Confirm success by observing ThingSpeak chart updates and by checking the SQLite 'sent' flags after a temporary network outage.
