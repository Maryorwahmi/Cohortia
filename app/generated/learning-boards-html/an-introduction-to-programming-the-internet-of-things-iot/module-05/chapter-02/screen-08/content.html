Module 05 › Chapter 5.2 › Retain & Last Will
Retained message
When a message is published with the retain flag, the broker stores it and immediately sends it to new subscribers for that topic. Use it for status or configuration that a new client must know immediately.
Example: Publish home/sensor/status = online with retain. A new dashboard subscribing afterward sees 'online' instantly.
Last Will and Testament
Register an LWT when connecting. If the client disconnects uncleanly, the broker publishes the LWT so other systems know the device is offline.
Example: Client sets LWT to home/sensor/status = offline. If the device loses power, the broker publishes 'offline'.
Key Takeaway

Retain delivers a last-known value to new subscribers; LWT signals unexpected disconnects. Use both for state awareness, not for full message history.
