Module 05 › Chapter 5.2 › CLI Testing
Subscribe (terminal A)
mosquitto_sub -h localhost -t "home/sensor/temperature"
This will print messages published to the topic in real time.
Publish (terminal B)
mosquitto_pub -h localhost -t "home/sensor/temperature" -m "{\"temperature\":22,\"unit\":\"C\"}"

# To publish retained
mosquitto_pub -h localhost -t "home/sensor/status" -m "online" -r
Use -r to retain the last message, and -q to choose a QoS level for testing delivery behavior.
Check your understanding

After publishing a retained status, start a new subscriber and confirm it receives the retained value immediately. Then kill the publisher process without a clean disconnect to observe the LWT if configured.
