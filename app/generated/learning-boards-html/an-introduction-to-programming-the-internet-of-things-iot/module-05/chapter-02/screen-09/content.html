Module 05 › Chapter 5.2 › Mosquitto Installation
Install steps
sudo apt-get install mosquitto mosquitto-clients
sudo systemctl enable mosquitto
sudo systemctl start mosquitto
After starting, Mosquitto listens on port 1883 by default.
Quick test
# Subscribe in terminal A
mosquitto_sub -h localhost -t "test/topic"

# Publish in terminal B
mosquitto_pub -h localhost -t "test/topic" -m "Hello MQTT"
Pro tip
Use two terminals to observe live message flow while developing publishers and subscribers.
Misconception
A default Mosquitto install is production-ready. It needs proper security before exposure to untrusted networks.
Local brokers accelerate debugging and let you verify message format and QoS behavior before deploying to the cloud.
