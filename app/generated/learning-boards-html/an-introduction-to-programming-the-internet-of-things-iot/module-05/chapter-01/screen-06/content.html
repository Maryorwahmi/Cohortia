Safe JSON access pattern
Use nested gets and validate values before use.
# parse and extract safely
weather = response.json()
temp = weather.get('main', {}).get('temp')
if temp is None:
  # handle missing value: retry or use fallback
  pass
else:
  temp_value = float(temp)
  # store or act on temp_value
Check for None, convert types explicitly, and avoid indexing into nested structures without safeguards to prevent runtime errors on devices.
Memory and performance
Small devices have limited RAM. Only keep necessary fields and process streams incrementally if payloads are large.
Example: converting types
If a numeric value arrives as text, convert it before storing in SQLite to ensure correct column types and comparisons.
Key Takeaway

Treat JSON as untrusted input: validate structure and types, handle missing values, and minimize memory use on devices.
