GET example (weather)
Fetch current temperature and parse JSON safely.
import requests

response = requests.get("https://api.openweathermap.org/data/2.5/weather?q=London&appid=YOUR_API_KEY&units=metric")
if response.status_code == 200:
  weather = response.json()
  temperature = weather.get("main", {}).get("temp")
  print(f"Current temperature in London: {temperature}°C")
else:
  print("Failed to fetch weather", response.status_code)
Use dict.get to avoid KeyError if fields are missing. Check status_code before parsing.
POST example (sensor upload)
Send sensor fields to a cloud update endpoint and examine the response status.
import requests

payload = {
  "api_key": "YOUR_KEY",
  "field1": 25.5,
  "field2": 60.0
}
response = requests.post("https://api.thingspeak.com/update", data=payload)
print(f"Response status: {response.status_code}")
Some APIs require form data and others expect JSON. Read the API docs and use data= or json= accordingly.
Key Takeaway

Use response.status_code to detect success and response.json() to get structured data. Never assume keys exist.
