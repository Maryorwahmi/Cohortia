Lab & verification tasks
Practice endpoints, scrape only if necessary, and secure keys with environment variables.
Endpoint 1
POST /api/sensor
Receive JSON sensor data and write to SQLite. Verify with curl and a sample payload.
Endpoint 2
GET /api/sensor/{id}
Return the last ten readings for a sensor. Verify ordering and types in the response.
Endpoint 3
POST /api/led
Send LED control commands that the server forwards to connected hardware. Confirm command delivery on the device.
Common mistake
Hardcoding API keys in code. This exposes secrets when sharing or committing repositories. Use environment variables instead.
Pro tip
Test your endpoints with curl and with a small Python client using requests. That verifies both network reachability and correct JSON handling.
