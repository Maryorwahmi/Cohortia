BeautifulSoup example
from bs4 import BeautifulSoup
import requests

response = requests.get("https://example.com/weather")
soup = BeautifulSoup(response.text, 'html.parser')
temp = soup.find('span', class_='temperature').text
print(f"Scraped temperature: {temp}")
This extracts a span with a specific class. If the page structure changes, the find call may return None, so add checks.
When to prefer APIs
APIs provide structured, stable data designed for consumption. Use scraping only if no API exists and the site permits it.
Fragility warning
Web markup changes can silently break scrapers. Add monitoring and fallbacks when relying on scraped data.
Key Takeaway

Scraping works but is brittle and may violate terms. Prefer APIs, and if scraping is necessary, build resilient selectors and caching.
