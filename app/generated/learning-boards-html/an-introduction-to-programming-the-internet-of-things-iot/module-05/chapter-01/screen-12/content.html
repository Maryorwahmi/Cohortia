Storing API keys
Use environment variables and avoid committing secrets to version control.
import os
API_KEY = os.environ.get('THINGSPEAK_API_KEY')

# On the Raspberry Pi shell or systemd file:
# export THINGSPEAK_API_KEY="your_key_here"
Use systemd environment entries or shell profiles to provide secrets to services without embedding them in code.
Comparison: hardcode vs environment
Hardcode
Easy but unsafe. Keys may be exposed via commits, shared archives, or logs.
Environment
Safer and standard for deployment. Still protect access to the environment and avoid printing secrets.
Key Takeaway

Use environment variables for API keys, secure access to system files, and never print secrets in logs or error messages.
