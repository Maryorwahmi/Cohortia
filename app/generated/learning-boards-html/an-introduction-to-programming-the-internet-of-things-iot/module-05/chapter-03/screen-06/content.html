Module 6 › Chapter 5.3 › ThingSpeak visualization
How channels work
  • Create a channel and define up to eight fields for different measurements.
  • Each field automatically produces a time-series chart that updates with new values.
  • Charts can be embedded or shared via a public URL for simple reporting.
Server-side analytics
Use MATLAB analytics to transform incoming data, compute averages, or flag anomalies before visualization.
Automation & commands
React reacts to data thresholds to call webhooks or send notifications. TalkBack queues commands that devices can poll to receive remote instructions. Together they let you close the loop from telemetry to action.
Example

Trigger an email if temperature > 30°C and push a TalkBack command to the device to increase sampling frequency.
