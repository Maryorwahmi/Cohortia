Module 6 › Chapter 5.3 › Azure IoT Hub
Device twins
A synchronized JSON document storing desired and reported states. Use twins to push configuration and verify device status across a fleet.
Direct methods
Invoke synchronous commands on a device to run maintenance actions or request diagnostics. They are useful for immediate operational control.
Integration
Connect telemetry to Stream Analytics, Functions, and Power BI for transformation and dashboarding in the Azure ecosystem.
Operational note
Plan configuration rollouts and rollback strategies when using device twins, and secure direct methods to prevent unauthorized operations.
