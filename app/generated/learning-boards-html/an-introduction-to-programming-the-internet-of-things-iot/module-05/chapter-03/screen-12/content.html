Module 6 › Chapter 5.3 › Node-RED & Grafana
Node-RED flow example
Create an MQTT input, add a function node to parse and transform payloads, then forward to an InfluxDB output or an HTTP webhook. Use a debug node to inspect messages while developing.
Hands-on
Install Node-RED on the Pi and wire an MQTT node to a debug node to verify incoming messages before connecting storage.
Grafana dashboards
Connect Grafana to InfluxDB to build panels for temperature trends, gauges for current readings, and alerts for threshold breaches. Grafana excels when you need rich, query-driven visuals.
Why it matters

Combining Node-RED and Grafana gives a powerful prototype and production path: visual flows to process data and flexible dashboards to display it.
