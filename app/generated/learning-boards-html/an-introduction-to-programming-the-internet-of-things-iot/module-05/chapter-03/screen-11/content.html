Write to InfluxDB — example
INFLUX_URL = "http://localhost:8086/write?db=iot_db"

while True:
  temperature = 25.5
  line = f"temperature,sensor=temp_01 value={temperature}"
  requests.post(INFLUX_URL, data=line)
  time.sleep(10)
This pattern posts the InfluxDB line protocol to the write endpoint. Grafana then queries InfluxDB to build dashboards and alerts.
Operational notes
  • Manage backups, retention policies, and security for InfluxDB and MQTT.
  • Grafana gives powerful visualizations but requires query knowledge for advanced panels.
  • Self-hosting gives privacy, but you assume maintenance responsibilities.
Key Takeaway

Self-hosted stacks are ideal when you require data control and long-term cost predictability, and can manage the operational burden.
