Hierarchy of script parts
Break your script into clear, testable sections.
Initialization
Set up sensors, GPIO, serial ports, and open files or network clients.
Main loop
Read sensors, process values, write logs, and sleep between iterations.
Cleanup
Handle KeyboardInterrupt and exceptions to close files and reset hardware.
Concrete pattern
Wrap the main loop in try/except and place reusable logic in functions. Use if __name__ == '__main__' to separate import-time side effects from runtime behavior.
Key Takeaway

A simple, modular script is easier to debug and integrates cleanly with supervisors like systemd.
