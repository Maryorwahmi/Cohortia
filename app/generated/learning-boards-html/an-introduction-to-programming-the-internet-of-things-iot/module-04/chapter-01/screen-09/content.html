Minimal systemd service file
A service file gives process supervision and restart behavior.
[Unit]
Description=IoT Sensor Logger
After=network.target

[Service]
Type=simple
User=pi
WorkingDirectory=/home/pi/project
ExecStart=/home/pi/iot_env/bin/python /home/pi/project/main.py
Restart=always

[Install]
WantedBy=multi-user.target
Enable & start
sudo systemctl enable iot-sensor.service ; sudo systemctl start iot-sensor.service ; sudo systemctl status iot-sensor.service
Why prefer systemd
Provides restarts, logging, and ordering so your script waits for the network and recovers after crashes.
Quick checks
  • Confirm ExecStart points to the venv python binary.
  • Use Restart=always for long-running tasks.
  • Use After=network.target if the script needs networking on start.
Key Takeaway

A simple systemd file yields production-grade service behavior with little complexity.
