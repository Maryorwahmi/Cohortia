Create and use venv
Commands to practice and why they matter for IoT.
python3 -m venv ~/iot_env
source ~/iot_env/bin/activate
pip install flask requests paho-mqtt pyserial
# run your script with the venv python
/home/pi/iot_env/bin/python /home/pi/project/main.py
Practical note
Use the venv python binary in systemd ExecStart so the service uses the correct dependencies.
Why isolate
  • Prevents package version conflicts between projects.
  • Makes deployments reproducible on another Pi with the same venv or requirements file.
  • Simplifies rollback and testing of package upgrades.
Common mistake

Installing everything globally into the system Python may break other services. Use venv for each IoT project.
