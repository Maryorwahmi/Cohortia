Practical checklist
Commands and files that you'll edit during the lab.
SSH & system updates
Example: ssh username@raspberrypi.local and then run sudo apt update && sudo apt upgrade -y to ensure packages are current.
Wi‑Fi & static IP
Edit wpa_supplicant.conf for Wi‑Fi and /etc/dhcpcd.conf to assign a static IP when required by IoT deployments.
Python 3 pattern
Initialize hardware, enter a main loop that reads sensors and writes JSON lines, handle exceptions and cleanup.
venv & pip
python3 -m venv ~/iot_env ; source ~/iot_env/bin/activate ; pip install flask requests
Checkpoint
After completing these steps you should be able to SSH in, run your script manually, and see JSON records appended to a log file.
