SSH & Wi‑Fi basics
Enable SSH with an empty file named ssh; precreate wpa_supplicant.conf to auto-join networks.
# Example wpa_supplicant.conf section
network={
  ssid="YourNetwork"
  psk="YourPassword"
  key_mgmt=WPA-PSK
}
SSH example
ssh username@raspberrypi.local — then run the initial setup commands.
Static IP considerations
Edit /etc/dhcpcd.conf to set a predictable address if needed by other devices or services.
When to use static IP
  • When dashboards, other devices, or scripts expect a stable endpoint.
  • In small networks where DHCP reservations are not available.
Common mistake

Assigning an IP outside your subnet or colliding with DHCP can disrupt network access—test carefully after changes.
