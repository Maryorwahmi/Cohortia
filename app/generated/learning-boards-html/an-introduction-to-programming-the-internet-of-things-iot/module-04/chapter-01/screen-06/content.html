Logger example
A minimal pattern for continuous sensor logging in Python 3.
#!/usr/bin/env python3
import time
import json
from datetime import datetime

try:
  while True:
    # Read sensor (placeholder)
    temperature = 25.5
    humidity = 60.0

    # Create data record
    data = {
      "timestamp": datetime.now().isoformat(),
      "temperature": temperature,
      "humidity": humidity
    }

    # Save to file
    with open("sensor_data.json", "a") as f:
      f.write(json.dumps(data) + "
")

    print(f"Logged: {data}")
    time.sleep(5)

except KeyboardInterrupt:
  print("Program stopped by user")
Example
Every five seconds a JSON line with a timestamp is appended to sensor_data.json for later parsing.
Misconception
Relying on print for persistence is unsafe; logs should be written to disk or sent to a remote store.
Explanation bullets
  • Use python3 to run the script so the runtime is current.
  • JSON lines are easy to append and parse later with line-based readers.
  • Context manager ensures file handles are closed even on error.
  • KeyboardInterrupt handling lets you stop the program cleanly during development.
Key Takeaway

A short, well-structured loop gives reliable logs and is simple to adapt for real sensors or network forwarding.
