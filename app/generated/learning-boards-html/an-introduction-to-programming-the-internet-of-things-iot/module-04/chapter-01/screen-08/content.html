Using cron @reboot
A low-friction method to start scripts at boot.
# Edit crontab
crontab -e
# Add this line to run on reboot
@reboot /home/pi/iot_env/bin/python /home/pi/project/main.py &
Pros
Simple to configure and suitable for quick experiments.
Cons
No automatic restarts, limited logging, and no explicit handling of network dependencies.
Check your understanding
After adding @reboot, reboot and verify the JSON log file is growing. If it does not, check paths and that the virtual environment exists at the referenced location.
Key Takeaway

Cron @reboot is fine for simple tasks but does not replace a service manager for long-running, production scripts.
