Headless OS Lite
Lean OS with preconfigured SSH/Wi‑Fi for remote IoT devices.
Python 3 pattern
Initialize, loop, write timestamped JSON, and handle cleanup.
venv & pip
Isolate packages per project to avoid conflicts and improve reproducibility.
Cron @reboot
Simple boot start for experiments; limited supervision.
systemd
Service supervision, restarts, and logging for production scripts.
Network setup
Enable SSH, preconfigure Wi‑Fi, and set static IP when a stable address is required.
Takeaway
Combine a headless Pi, Python 3 with venv, and systemd services to build dependable edge gateways for IoT.
