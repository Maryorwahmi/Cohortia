Step-by-step first-boot
A repeatable routine reduces surprises when deploying devices.
1
SSH into the Pi
ssh username@raspberrypi.local or use the static IP if configured.
2
Update packages
sudo apt update && sudo apt upgrade -y to apply fixes and security patches.
3
Enable interfaces
sudo raspi-config → Interface Options → enable I2C, SPI, UART if your sensors need them.
4
Network identity
Set a static IP in /etc/dhcpcd.conf if the device must be reliably reachable on your network.
Common mistake

Skipping updates or forgetting to enable required interfaces will cause sensor libraries to fail later; perform the full checklist before deploying.

Quick command reference
sudo apt update && sudo apt upgrade -y sudo raspi-config # edit /etc/dhcpcd.conf for static IP # edit /etc/wpa_supplicant/wpa_supplicant.conf for Wi-Fi
Example scenario
You enable I2C because your temperature sensor library requires it. After reboot the sensor is accessible from Python and readings succeed.
