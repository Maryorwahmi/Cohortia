Lab steps
Turn the earlier pieces into a working, reboot-resilient logger.
# Create venv and activate
python3 -m venv ~/iot_env
source ~/iot_env/bin/activate
pip install requests

# Example run
/home/pi/iot_env/bin/python /home/pi/project/main.py

# systemd service file example
[Unit]
Description=IoT Sensor Logger
After=network.target

[Service]
Type=simple
User=pi
WorkingDirectory=/home/pi/project
ExecStart=/home/pi/iot_env/bin/python /home/pi/project/main.py
Restart=always

[Install]
WantedBy=multi-user.target
Checkpoint

After reboot, confirm sensor_data.json contains new lines and sudo systemctl status shows active (running).

Common pitfalls
  • Using relative paths in systemd ExecStart — always use absolute paths.
  • Forgetting to use the venv python — resulting in missing packages at runtime.
  • Not setting Restart=always so crashes remain unrecovered.
