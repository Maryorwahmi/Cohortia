Module 4 › Chapter 4.1 › Headless & OS Lite
Definition and pattern
A headless Pi boots without a GUI and is administered remotely; Raspberry Pi OS Lite is the minimal OS for this use.
Why choose Lite
  • Keeps memory and storage available for services.
  • Reduces background processes and updates.
  • Simplifies security and remote management.
Boot-time files (example)
# On the SD card boot partition create these files
# 1) empty file named ssh
# 2) wpa_supplicant.conf with your network
ctrl_interface=DIR=/var/run/wpa_supplicant GROUP=netdev
update_config=1
country=US
network={
  ssid="YourNetwork"
  psk="YourPassword"
  key_mgmt=WPA-PSK
}
Key Takeaway

Preconfigure SSH and Wi‑Fi on the boot partition to enable reliable headless first boot and remote management.

Practical checklist
Use Raspberry Pi Imager
Select Raspberry Pi OS Lite (64-bit) and configure network/SSH if Imager supports it.
Add boot-time files
Place an empty file named ssh and a wpa_supplicant.conf on the boot partition for first boot access.
First SSH login
ssh username@raspberrypi.local then run sudo apt update && sudo apt upgrade -y and raspi-config for interfaces.
Common mistake: leaving a GUI image installed will add maintenance overhead and may hide services failing on the headless startup.
