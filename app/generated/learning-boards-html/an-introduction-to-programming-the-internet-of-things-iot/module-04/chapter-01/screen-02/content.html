Learning Objectives
Skills to practice and verify
Bloom: Learn → Understand → Apply → Master
Verified competency milestone
01
Install OS & headless setup
Preconfigure Raspberry Pi OS Lite with SSH and Wi‑Fi so the Pi boots without a screen. This lets you manage the device remotely and reduces system overhead.
VERIFIED COMPETENCY MILESTONE
02
SSH, Wi‑Fi & network
Enable SSH and set Wi‑Fi or a static IP so the Pi is reachable and stable on your network, a common requirement for IoT devices.
VERIFIED COMPETENCY MILESTONE
03
Python 3 & file I/O
Use Python 3 to read sensors, create timestamped JSON records, and write them to disk for later analysis or forwarding.
VERIFIED COMPETENCY MILESTONE
04
venv & boot automation
Create virtual environments and run scripts on boot using cron or systemd so your service survives reboots and dependency conflicts.
VERIFIED COMPETENCY MILESTONE
