Code Example
from picamera import PiCamera
from time import sleep

camera = PiCamera()
camera.start_preview()
sleep(5)
camera.capture('/home/pi/image.jpg')
camera.stop_preview()
This sequence opens a preview, waits for exposure to stabilize, captures an image, and stops the preview. Use returned files as input to vision code or to save evidence in IoT applications.
Use cases
  • Security monitoring snapshots
  • Object detection pipelines with OpenCV
  • Visual inspection and OCR pre-processing
Performance note
Capturing and encoding video uses CPU. For continuous vision, consider lightweight models or offloading processing.
Key Takeaway
Enable the camera interface, allow exposure to settle, and tune settings for your lighting and resolution needs.
