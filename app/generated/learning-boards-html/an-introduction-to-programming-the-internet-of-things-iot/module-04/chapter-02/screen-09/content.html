Process Flow
1) Arduino reads analog pin & converts to a number. 2) Arduino sends value over serial or I2C. 3) Pi reads serial, parses the value, and acts on it. 4) Pi logs, thresholds, or triggers camera capture based on the value.
Arduino
Samples analog sensors with built-in ADC and serializes readings.
Connection
Use USB serial or I2C. Ensure logic levels match or use a level shifter.
Raspberry Pi
Reads and scales values, integrates with gpiozero code for control and logging.
Practical tip
Run a fixed-value test and compare Arduino and Pi readings to validate calibration and wiring.
