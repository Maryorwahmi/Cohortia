Architecture
I2C bus: shared SDA & SCL
Multiple devices share the same two wires; each device has a 7-bit address. Use smbus to open bus 1 on modern Pis and communicate with device addresses reported by the scanner.
Code pattern
import smbus
from bme280 import BME280

bus = smbus.SMBus(1)
bme280 = BME280(i2c_dev=bus)

temperature = bme280.get_temperature()
Use the sensor library to interpret register values. Confirm device address and wiring first.
Troubleshooting
Run an I2C scan to detect addresses, ensure pull-up resistors are present if needed, and verify voltage compatibility.
