Core Concept
GPIO header and pin roles

Pins include 3.3V, 5V, ground, and 26 user-configurable GPIO lines. Dedicated buses include I2C, SPI, and UART, plus a few PWM pins for hardware PWM.

Quick facts
  • Pi logic level: 3.3V — do not apply 5V to GPIO pins
  • No built-in ADC — use MCP3008 or Arduino
  • I2C: GPIO2 (SDA), GPIO3 (SCL). SPI: pins for MOSI, MISO, SCK
Key Takeaway

Treat the Pi's GPIO as digital-only and protect it with correct wiring and level shifting when needed.

Example wiring scenario: a temperature sensor with a 3.3V output can be connected directly to GPIO for digital I2C data. A potentiometer must be wired to an MCP3008 channel on SPI and read as a scaled value between 0 and 3.3V.
Common Mistake
Assuming 5V devices can be attached directly. Always confirm voltage and use level shifters or voltage dividers.
