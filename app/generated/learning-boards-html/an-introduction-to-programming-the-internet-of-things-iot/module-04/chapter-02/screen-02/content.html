Module 4 › Chapter 4.2 › Learning Objectives
01
Use gpiozero and RPi.GPIO

Write Python to control digital outputs and read digital inputs. You'll learn safe pin numbering, and why gpiozero simplifies common tasks.

Mnemonic: Object-oriented controls & event callbacks
VERIFIED COMPETENCY MILESTONE
02
Read analog sensors with MCP3008 or Arduino

Understand why the Pi needs an external ADC and how to wire and read an MCP3008 over SPI or receive ADC values from an Arduino bridge.

Mnemonic: SPI channel mapping + scale to 3.3V
VERIFIED COMPETENCY MILESTONE
03
Interface I2C and SPI sensors

Use smbus for I2C devices like environmental sensors and the SPI bus for ADCs and fast sensors, including required pin mappings.

Mnemonic: SDA/SCL for I2C; MOSI/MISO/SCK for SPI
VERIFIED COMPETENCY MILESTONE
04
Use the Pi Camera Module

Capture still images and video, and connect basic computer-vision pipelines. Learn camera control with the picamera library and safe mounting tips.

Mnemonic: preview, capture, save
VERIFIED COMPETENCY MILESTONE
