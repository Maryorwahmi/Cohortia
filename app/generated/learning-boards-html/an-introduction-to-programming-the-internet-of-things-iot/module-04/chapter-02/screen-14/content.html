Current limiting
Always use a resistor with LEDs and verify current paths to protect GPIO pins.
Pull resistors
Use pull-up or pull-down resistors for buttons so inputs are never floating and readings are stable.
Enable interfaces
Enable SPI, I2C, and camera interfaces in the Pi configuration before running code that depends on them.
Final takeaway

Small protective habits and interface checks prevent hardware damage and make experiments reliable and repeatable.
