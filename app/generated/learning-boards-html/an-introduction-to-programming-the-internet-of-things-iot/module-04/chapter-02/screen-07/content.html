Code Example
from gpiozero import Button
from signal import pause

def button_pressed():
  print("Button was pressed!")

button = Button(18)
button.when_pressed = button_pressed

pause()
This code sets a callback and uses pause to keep the script running. Use a known pull-up or pull-down configuration so the pin reads cleanly when the button is not pressed.
Wiring
Connect the button to GPIO 18 and 3.3V or ground with a 10kΩ pull-up or pull-down so the input is never floating. Verify with a multimeter before running code.
Common Mistake
Not debouncing buttons. Mechanical switches can generate multiple transitions; debounce in software or add a small capacitor.
Key Takeaway
Use callbacks for responsiveness and ensure hardware debouncing or software filtering for reliable input events.
