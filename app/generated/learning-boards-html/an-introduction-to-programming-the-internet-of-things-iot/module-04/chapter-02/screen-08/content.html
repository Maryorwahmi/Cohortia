Code Example
from gpiozero import MCP3008
from time import sleep

adc = MCP3008(channel=0)

while True:
  voltage = adc.value * 3.3
  print(f"Voltage: {voltage:.2f} V")
  sleep(1)
This example reads channel zero and scales the normalized value to a voltage. Ensure SPI is enabled and wiring matches the MCP3008 datasheet.
Wiring checklist
  • Power MCP3008 from 3.3V, not 5V
  • Connect MOSI, MISO, SCK to Pi SPI pins
  • Connect CS (chip select) to the Pi's CE pin
Example scenario: a potentiometer on channel 0 gives you a smooth reading to control an LED threshold or log sensor data to CSV.
Key Takeaway
Use the MCP3008 for analog sensors. Always power it at 3.3V and confirm SPI is enabled before running code.
