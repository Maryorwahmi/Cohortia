Module 5 › Chapter 4.3 › Separation of Concerns
Collection
Sensor read loop, normalize readings, and insert into SQLite immediately to ensure durability.
Storage
SQLite holds readings with a sent flag and supports queries for retry and presentation layers.
Presentation
Flask serves recent readings and a JSON API for charts, separate from collection and retry processes.
Concrete deployment tip
Run each role as a separate process or service so dashboard or network problems do not block sensor writes. This keeps your gateway resilient and easier to debug.
