Module 5 › Chapter 4.3 › Practical Milestones
01 — Logger loop
Insert a reading every 10 seconds with columns: timestamp, sensor_id, value, sent. Confirm new rows appear in sqlite3 CLI or query output.
Check
Run SELECT * FROM sensor_readings ORDER BY timestamp DESC LIMIT 5 and observe timestamps advancing by your sample interval.
02 — SQLite & WAL
Enable WAL mode and confirm the database remains consistent even after a forced shutdown during writes.
Check
Use PRAGMA journal_mode to verify WAL and inspect that .db file can be copied and reopened successfully.
03 — Buffering & retry
Simulate network failure, let the Pi collect data, reconnect, and confirm unsent rows are uploaded and marked sent.
Check
Observe a sequence: rows accumulate with sent=0; after reconnect, process_unsent updates those rows to sent=1 and cloud returns success codes.
04 — Local dashboard
Run Flask on host 0.0.0.0 and confirm you can view the dashboard and call /api/data from another device on the same network.
Check
Open the Pi IP and see the last 20 readings rendered in the template or receive JSON from /api/data containing timestamp and value pairs.
