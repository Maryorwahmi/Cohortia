Module 5 › Chapter 4.3 › SQLite Storage
Core benefits
  • Serverless: no separate process to install, ideal for small systems.
  • Durable: WAL mode guards against corruption on power loss.
  • Queryable: SQL lets you filter, aggregate, and inspect readings.
  • Portable: the .db file is easy to copy or back up.
Schema suggestion
Create a sensor_readings table with timestamp TEXT, sensor_id TEXT, value REAL, sent INTEGER DEFAULT 0.
Common misconception

Assuming a plain text file is equivalent. Text files need manual parsing, are hard to query, and are more vulnerable to corruption during interrupted writes.

Concrete example
import sqlite3
from datetime import datetime

conn = sqlite3.connect('iot_data.db')
c = conn.cursor()
c.execute('''CREATE TABLE IF NOT EXISTS sensor_readings
             (timestamp TEXT, sensor_id TEXT, value REAL, sent INTEGER DEFAULT 0)''')
conn.commit()

# Insert a reading
timestamp = datetime.now().isoformat()
c.execute("INSERT INTO sensor_readings VALUES (?, ?, ?, ?)",
          (timestamp, "TEMP_01", 25.5, 0))
conn.commit()
conn.close()
Run PRAGMA journal_mode = WAL to enable WAL. Verify with PRAGMA journal_mode; it should return WAL.
