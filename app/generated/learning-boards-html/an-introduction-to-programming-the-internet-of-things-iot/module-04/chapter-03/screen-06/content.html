Module 5 › Chapter 4.3 › Create & Query
Insert example
conn = sqlite3.connect('iot_data.db')
c = conn.cursor()
# Create table (if needed)
c.execute('''CREATE TABLE IF NOT EXISTS sensor_readings
             (timestamp TEXT, sensor_id TEXT, value REAL, sent INTEGER DEFAULT 0)''')
conn.commit()

# Insert
from datetime import datetime
c.execute("INSERT INTO sensor_readings VALUES (?, ?, ?, ?)",
          (datetime.now().isoformat(), "TEMP_01", 25.5, 0))
conn.commit()
conn.close()
Tip: wrap writes in short transactions and commit promptly to minimize lock contention and reduce risk during power loss.
Query recent readings
conn = sqlite3.connect('iot_data.db')
c = conn.cursor()
c.execute("SELECT * FROM sensor_readings ORDER BY timestamp DESC LIMIT 10")
rows = c.fetchall()
for row in rows:
    print(row)
conn.close()
Misconception check: printing rows is useful during development, but production systems should export or visualize these results rather than relying on console logs.
