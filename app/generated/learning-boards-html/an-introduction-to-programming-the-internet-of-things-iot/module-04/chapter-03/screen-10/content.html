Flask essentials
Define routes for the dashboard and for an API endpoint. Query SQLite for recent rows and pass them to the template or jsonify them for client consumption. Bind to 0.0.0.0 to allow other devices on your LAN to connect.
from flask import Flask, render_template, jsonify
import sqlite3

app = Flask(__name__)

@app.route('/')
def dashboard():
    conn = sqlite3.connect('iot_data.db')
    c = conn.cursor()
    c.execute("SELECT * FROM sensor_readings ORDER BY timestamp DESC LIMIT 20")
    data = c.fetchall()
    conn.close()
    return render_template('dashboard.html', readings=data)

@app.route('/api/data')
def api_data():
    conn = sqlite3.connect('iot_data.db')
    c = conn.cursor()
    c.execute("SELECT timestamp, value FROM sensor_readings WHERE sensor_id = 'TEMP_01' ORDER BY timestamp DESC LIMIT 100")
    data = c.fetchall()
    conn.close()
    return jsonify(data)

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=5000, debug=False)
Client visualization
The /api/data route returns JSON that a browser can fetch and render with a charting library to display recent trends. Serving raw JSON keeps the server simple and lets the client handle rendering.
Key Tip

Use a small client-side chart and poll the JSON endpoint on an interval to update the view without reloading the page.
