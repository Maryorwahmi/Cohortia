Module 5 › Chapter 4.3 › Learning Objectives
01
Design a Pi data logger
Create a schema and read loop that writes timestamped sensor values to local storage and forwards them to the cloud when possible. This verifies end‑to‑end data flow.
VERIFIED COMPETENCY MILESTONE
02
Use SQLite for local storage
Create a table, enable WAL mode for reliability, and run SQL queries to read and filter sensor data for analysis.
VERIFIED COMPETENCY MILESTONE
03
Implement buffering and retry
Save all readings locally, mark rows as sent on success, and periodically scan the database for unsent entries to retry upload attempts.
VERIFIED COMPETENCY MILESTONE
04
Run a local Flask dashboard
Serve recent readings and a JSON API on the Pi so devices on the same network can visualize data in a browser or charting library.
VERIFIED COMPETENCY MILESTONE

Mnemonic: Buffer Chain
Think: Sensor → SQLite buffer → retry loop → cloud. Each stage must be verifiable and atomic to avoid data loss.
Quick check
Can you reproduce a network outage and confirm unsent rows accumulate then upload on reconnect? That is the milestone for buffering and retry.
