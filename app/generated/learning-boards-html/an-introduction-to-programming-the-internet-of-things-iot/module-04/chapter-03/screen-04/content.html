Module 5 › Chapter 4.3 › Gateway Role
Definition

A gateway collects sensor data, performs local processing and storage, and forwards data to cloud services while handling network failures gracefully.

Durability
Persist readings immediately to prevent loss on power failure.
Observability
Expose recent data via SQL or a local web UI for debugging and verification.
Graceful degradation
Continue to collect and buffer when connectivity is lost, then retry uploads later.
Key Takeaway

Design the Pi as the authoritative short‑term store: write first, send later.

Architecture Snapshot
Sensors
Multiple sensor inputs, serial, I2C, or ADC, normalized to a common format.
Raspberry Pi
  • Store readings in SQLite
  • Run retry loop for unsent rows
  • Host Flask dashboard
Cloud
Receive forwarded events; Pi ensures eventual delivery.
Concrete example
A temperature sensor sends readings every 10 seconds; the Pi writes each reading to a table with timestamp and sensor id, then attempts to POST it to the cloud. If the POST fails, the row remains unsent and the retry loop will resend it later.
