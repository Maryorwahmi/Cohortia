JSON endpoint shape
Return a simple array of timestamp/value pairs for a sensor, for example: [["2023-01-01T12:00:00", 25.5], ["2023-01-01T12:00:10", 25.6]]. This keeps client parsing straightforward.
Misconception

Returning a large, nested payload without pagination or limits makes charts slow and memory hungry on small clients. Keep the payload focused and cacheable.
