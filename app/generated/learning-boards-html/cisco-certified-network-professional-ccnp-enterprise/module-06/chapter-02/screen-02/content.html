Module 6 › Chapter 6.2 › Learning Objectives
01
Configure SNMP
Enable device telemetry and event traps using SNMPv2c or SNMPv3.
Skill: Define community strings or SNMPv3 users, restrict access to the NMS, and verify traps are received. Why it matters: Without secure SNMP the network exposes sensitive operational data.
VERIFIED COMPETENCY MILESTONE
02
Implement NetFlow / IPFIX
Export flow metadata for traffic analysis and capacity planning.
Skill: Configure exporters, set export destinations and timeouts, and apply flow monitoring to interfaces. Why it matters: Flow data reveals top talkers and supports incident analysis.
VERIFIED COMPETENCY MILESTONE
03
Configure Syslog
Centralize event messages and choose appropriate severity levels.
Skill: Point devices to a syslog server and set the trap level to capture meaningful events without overload. Why it matters: Better correlation and fewer missed incidents.
VERIFIED COMPETENCY MILESTONE
04
Use IP SLA for active checks
Create synthetic tests that measure latency, jitter, and packet loss to critical services.
Skill: Schedule an ICMP echo operation, set thresholds, and tie results to traps or logging for proactive alerts. Why it matters: Detect service degradation before users complain.
VERIFIED COMPETENCY MILESTONE
