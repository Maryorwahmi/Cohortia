Module 6 › Chapter 6.2 › SNMP & MIBs
SNMP Defined
An application protocol that exposes device variables and sends traps or informs for events.
MIB (Management Information Base)
Hierarchical object names for metrics, e.g., interface counters and system uptime.
Use case example
Poll ifInOctets and ifOutOctets periodically to compute link utilization trends and detect sustained increases indicating capacity issues.
Common mistake
Using default community strings or failing to restrict SNMP to trusted NMS addresses exposes sensitive operational data.
Key Takeaway

SNMP + MIBs give you consistent device metrics; secure access and use SNMPv3 in production.

MIB Table — conceptual view
Example objects:
  • ifTable: ifIndex, ifDescr, ifInOctets, ifOutOctets
  • system: sysUpTime, sysContact
  • process metrics: CPU and memory OIDs provided by vendor MIB
Concrete verification
Use your NMS to poll a device and confirm values change over time. Verify traps are received when an interface flaps.
