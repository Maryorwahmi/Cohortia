Module 6 › Chapter 6.2 › SNMP Configuration
Commands (examples)
Paste these into a simulated router to create a read-only v2c community and a simple SNMPv3 user.
Router(config)# snmp-server community cohortia_ro RO
Router(config)# snmp-server host 192.168.1.100 traps version 2c cohortia_ro
Router(config)# snmp-server enable traps

! SNMPv3 minimal example
Router(config)# snmp-server view V1 iso included
Router(config)# snmp-server group GROUP1 v3 priv read V1 write V1
Router(config)# snmp-server user USER1 GROUP1 v3 auth sha AUTH_PASS priv aes 256 PRIV_PASS
Router(config)# snmp-server host 192.168.1.100 informs version 3 USER1
Note: Replace AUTH_PASS and PRIV_PASS with strong secrets; do not use default community strings in production.
Verification checklist
  • Run show snmp to confirm communities and users are present.
  • Check the NMS for trap/inform arrival after generating an event.
  • Verify ACLs allow NMS IPs to query SNMP ports.
Common mistake
Not restricting snmp-server host or forgetting to enable traps leads to missed notifications or open access.
Key Takeaway

Apply the example commands in lab, verify with show commands, and secure access using ACLs and SNMPv3.
