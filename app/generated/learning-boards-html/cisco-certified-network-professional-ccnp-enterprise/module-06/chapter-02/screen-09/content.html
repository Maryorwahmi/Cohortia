Module 6 › Chapter 6.2 › Syslog & Severity
Syslog essentials
Devices send event messages to a server; messages include a facility and a severity level that indicates importance.
Severity levels
Range from emergency to debugging; choose a threshold like informational or warnings for production.
Facilities
Use local0–local7 to categorize messages and simplify retention and analysis.
Example configuration
Point a device at the logging host and set the trap level to informational or warnings depending on noise tolerance.
Router(config)# logging host 192.168.1.100
Router(config)# logging trap informational
Common mistake
Sending debug-level logs in production can fill storage and obscure critical alerts.
Key Takeaway

Balance visibility and noise: centralize logs, choose sensible severity, and categorize by facility for easier correlation.
