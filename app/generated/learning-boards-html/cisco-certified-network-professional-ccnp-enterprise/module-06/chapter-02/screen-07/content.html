Module 6 › Chapter 6.2 › NetFlow Configuration
Example commands
This example sets NetFlow version 9, an exporter destination and applies ingress monitoring on GigabitEthernet0/0.
Router(config)# ip flow-export version 9
Router(config)# ip flow-export destination 192.168.1.100 2055
Router(config)# ip flow-cache timeout active 1
Router(config)# ip flow-cache timeout inactive 15
Router(config)# interface GigabitEthernet0/0
Router(config-if)# ip flow ingress
Router(config-if)# exit
Adjust timeouts and consider sampling on high-volume links to avoid CPU impact.
Verification and planning
  • Use show ip flow export to verify exporter state and destination reachability.
  • Check the collector for incoming records and confirm fields match expected interfaces.
  • Plan which interfaces provide the highest-value visibility (typically core and internet-facing links).
Common mistake
Monitoring all interfaces without sampling or export planning can overwhelm router CPU and memory.
Key Takeaway

Export flows to a collector, tune timeouts, and apply monitoring to selected interfaces for high-fidelity, low-impact visibility.
