Module 6 › Chapter 6.2 › Applied Objectives
Baselining Strategy
Collect SNMP counters, NetFlow summaries, and IP SLA over time to define normal ranges and seasonal patterns.
Mnemonic: Collect → Compare → Tune
Why: Reduces false positives
VERIFIED COMPETENCY MILESTONE
Hands-on Lab Verification
Use show snmp, show ip flow export, show logging, and show ip sla statistics to confirm each service is active and sending data.
Mnemonic: Show → Inspect → Confirm
Why: Ensures collectors receive usable telemetry
VERIFIED COMPETENCY MILESTONE
Secure Monitoring Access
Prefer SNMPv3 with authentication and privacy, restrict SNMP and syslog sources with ACLs to trusted NMS IPs.
Mnemonic: No defaults, use ACLs
Why: Prevents data exposure and spoofed traps
VERIFIED COMPETENCY MILESTONE
Flow Analysis for Response
Use NetFlow to find top talkers and protocols; correlate with CPU and syslog to determine if traffic or device fault is root cause.
Mnemonic: Flow → Correlate → Remediate
Why: Faster, focused investigations
