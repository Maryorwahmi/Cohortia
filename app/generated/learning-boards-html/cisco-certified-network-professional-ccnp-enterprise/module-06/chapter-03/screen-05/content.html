Commands
Switch(config)# monitor session 1 source interface GigabitEthernet0/1 both
Switch(config)# monitor session 1 destination interface GigabitEthernet0/2
Switch(config)# end
Switch# show monitor session 1
Tip: choose both, ingress, or egress to capture the direction you need.
Validation & Safety
  • Run show monitor session to confirm source/destination mapping and status.
  • Ensure destination port is not in a trunk or bundled into production forwarding.
  • Do not connect the monitoring destination back to the production network to avoid loops.
  • Use analyzer-side filters to limit capture size and focus on relevant protocols or IPs.
Pro tip

If you need low-impact troubleshooting, mirror only the minimal set of ports or VLANs and rely on analyzer filters to reduce disk usage.
