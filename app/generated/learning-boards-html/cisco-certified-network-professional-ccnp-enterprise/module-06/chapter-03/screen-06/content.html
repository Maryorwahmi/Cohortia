Module 6 › Chapter 6.3 › RSPAN: Mirroring Between Switches
How it works
RSPAN carries mirrored frames using a dedicated VLAN that is trunked between switches. The source mirrors into the RSPAN VLAN, and the destination extracts from it.
Create RSPAN VLAN
Define the VLAN only for mirrored traffic and trunk it across the fabric.
Example sequence
Switch A: monitor session 1 destination remote vlan 900. Switch B: monitor session 2 source remote vlan 900 destination Gi0/2.
Validation & Pitfalls
  • Ensure the RSPAN VLAN is trunked across intermediate switches and not used for production traffic.
  • Verify VLAN membership and trunk configuration to avoid dropped mirrored frames.
  • Do not rely on RSPAN for cross-subnet routing — it remains a Layer 2 VLAN for mirrored frames.
Common mistake

Allowing the RSPAN VLAN into production or forgetting to trunk it will break mirroring. Treat it as an isolated transport for mirrored frames only.
