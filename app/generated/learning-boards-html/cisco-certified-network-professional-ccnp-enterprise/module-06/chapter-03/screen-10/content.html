Display Filters
  • ip.addr == 192.168.1.10 — filter by an IP address.
  • tcp.port == 80 — filter by TCP port.
  • http — show HTTP protocol packets.
  • tcp.flags.syn == 1 and tcp.flags.ack == 1 — show SYN-ACK packets.
Analysis Tools
Use Follow TCP Stream to reconstruct sessions and Expert Information to highlight retransmissions, duplicate ACKs, and other anomalies. Protocol decodes show application data when available, which helps relate symptoms to root causes.

ip.addr == 192.168.20.50 and tcp.port == 80
