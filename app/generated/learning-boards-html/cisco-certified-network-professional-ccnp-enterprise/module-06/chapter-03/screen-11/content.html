Module 6 › Chapter 6.3 › Interpreting TCP Anomalies
Anomaly cards
TCP Retransmission
Sender resends a segment due to missing ACK; suggests packet loss or timeout.
Duplicate ACK
Receiver repeatedly ACKs the last in-order byte, indicating a later segment was lost.
Zero Window
Receiver advertises zero-sized receive window; application or buffer exhaustion on the receiver side.
Practical steps
  1. Filter to the TCP stream and Follow TCP Stream to reconstruct the conversation.
  2. Examine Expert Information to find retransmissions, duplicate ACKs, and zero window events.
  3. Correlate with device counters, interface errors, and queue drops to locate the problem node.
Misconception check

Seeing retransmissions does not automatically mean the server is faulty. Retransmissions indicate loss; root cause might be the network path.
