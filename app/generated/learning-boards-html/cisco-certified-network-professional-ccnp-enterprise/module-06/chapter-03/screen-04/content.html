Module 6 › Chapter 6.3 › SPAN: Local Port Mirroring
Definition
SPAN mirrors traffic to a local destination port

SPAN duplicates frames from source interfaces or VLANs to a destination port for local packet analysis with tools like Wireshark.

When to use
Analyzer attached to the same switch; quick capture of a user or server port.
Common mistake
Connecting the destination port back into the network can create loops or unintended forwarding.
Key Takeaway

SPAN provides a local copy of frames for analysis. Only mirror what you need and keep the destination isolated from production traffic.

Example & Diagram
Scenario
Mirror GigabitEthernet0/1 both directions to GigabitEthernet0/2 where a laptop with Wireshark is connected.
Switch(config)# monitor session 1 source interface GigabitEthernet0/1 both
Switch(config)# monitor session 1 destination interface GigabitEthernet0/2
Switch(config)# end
Switch# show monitor session 1
Misconception check
SPAN reduces production bandwidth — false. It duplicates traffic and uses switch forwarding resources; filter where possible.
