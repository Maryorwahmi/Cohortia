Definition & Risks

Why redistribution can be hazardous

Protocols use different metrics and administrative distances; careless redistribution can create loops or prefer suboptimal routes.

Administrative Distance
External routes often have higher AD; routers may prefer internal protocol routes over redistributed ones.
Seed Metric
Provide a metric when redistributing so the target protocol can advertise meaningful costs (examples vary by protocol).
Route Tags
Tag redistributed routes and filter by tag to prevent re-redistributing the same routes back into their origin protocol.
Practical rule

Test redistribution in a lab, always set explicit metrics and tags, and use the OSPF subnets keyword when redistributing subnetted routes into OSPF.
