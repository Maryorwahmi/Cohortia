Module 6 › Chapter 6.4 › EIGRP Neighbor Formation
Definition

How neighbors appear

EIGRP uses Hellos; AS numbers must match. If there's no neighbor entry, verify AS, ACLs, and passive interfaces first.

show ip eigrp neighbors
show ip protocols
show ip eigrp interfaces detail
Example
Two routers on the same network but no neighbor entry. Check for passive-interface or mismatched AS on one side.
Pitfalls

K-values and authentication

K-values affect metric compatibility. If K-values differ, routers may form adjacency but will not exchange routes. Authentication mismatches silently block updates.

Commands to inspect
show ip eigrp interfaces detail (for K-values), show running-config for authentication and passive-interface settings.
