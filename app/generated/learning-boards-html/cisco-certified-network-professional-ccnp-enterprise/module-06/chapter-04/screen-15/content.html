Key Concepts

Administrative Distance
AD affects route selection when multiple protocols provide a path to the same destination.
Seed Metric
Assign a sensible initial metric when redistributing so the target protocol can advertise cost correctly.
Route Tags
Tag redistributed routes and filter by tag to prevent loops during mutual redistribution.
Final takeaway

Treat redistribution and filters with caution. Test changes in a lab, verify with show commands, and use tags and metrics to preserve predictable routing behavior.
