BGP States

From Idle to Established

States reflect TCP and BGP message exchange progress. Use show ip bgp summary to see peer state quickly.

show ip bgp summary
show ip bgp neighbors <neighbor_ip>
TCP Checks

Test connectivity to port 179

If telnet to port 179 fails, investigate ACLs, firewalls or routing that block or misroute BGP TCP sessions.

Concrete example
If a peer is stuck in Connect, ping first, then telnet <neighbor_ip> 179. If telnet fails, there is a TCP-level blockage to resolve before BGP can form.
