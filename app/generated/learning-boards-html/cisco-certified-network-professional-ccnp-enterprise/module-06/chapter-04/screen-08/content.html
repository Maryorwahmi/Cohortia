Module 6 › Chapter 6.4 › EIGRP K-values and Passive Interface Issues
K-values

Metric compatibility matters

If K-values differ, route updates are rejected even when neighbors exist. Confirm via show ip eigrp interfaces detail.

Example check
Compare K-coefficients on both peers; align them to allow routes to be accepted.
Passive Interface

Suppressing Hellos

A passive-interface prevents Hellos and neighbor formation. Verify running-config and show ip eigrp interfaces to find passive settings.

Common mistake
Operators sometimes set passive-interface for security but forget to allow necessary neighbors on adjacent segments.
Verification
show ip eigrp neighbors, show ip eigrp interfaces detail, and check key-chains for authentication mismatches.
