Problem

OSPF stuck in INIT

Start with show ip ospf neighbor and show ip ospf interface GigabitEthernet0/1 on both R1 and R2 to identify parameter mismatches.

! R1 initial configuration
R1(config)# router ospf 1
R1(config-router)# network 10.0.12.0 0.0.0.255 area 0
R1(config-router)# interface GigabitEthernet0/1
R1(config-if)# ip address 10.0.12.1 255.255.255.0
R1(config-if)# no shutdown

! R2 initial configuration (problematic)
R2(config)# router ospf 1
R2(config-router)# network 10.0.12.0 0.0.0.255 area 0
R2(config-router)# interface GigabitEthernet0/1
R2(config-if)# ip address 10.0.12.2 255.255.255.0
R2(config-if)# ip ospf hello-interval 5
R2(config-if)# no shutdown
Fix & Redistribution

Commands to apply

Correct the hello interval on R2, then configure EIGRP and mutual redistribution with a seed metric and the subnets keyword.
! Fix OSPF hello mismatch on R2
R2(config-if)# no ip ospf hello-interval 5

! Configure EIGRP and redistribute on R2
R2(config)# router eigrp 100
R2(config-router)# network 10.0.20.0 0.0.0.255
R2(config-router)# redistribute ospf 1 metric 10000 100 255 1 1500
R2(config-router)# exit

R2(config)# router ospf 1
R2(config-router)# redistribute eigrp 100 subnets metric 100
R2(config-router)# exit
Verification
Use show ip ospf neighbor, show ip route on both R1 and R2 to confirm OSPF reaches FULL and routes are exchanged. Remember to use show ip protocols to review redistribution settings.
