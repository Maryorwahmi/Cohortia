Module 6 › Chapter 6.4 › OSPF Adjacency States
Definition

OSPF neighbor state machine

Each state indicates which packets have been sent and acknowledged. Use the state to decide the next verification command.

Init → 2-Way
Init shows Hellos received; 2-Way confirms bidirectional Hellos and DR/BDR election context.
ExStart / Exchange
Negotiation of master/slave and DB Description. MTU mismatches often appear here.
Loading → Full
Link-state databases are exchanged; Full means adjacency is complete.
Key Takeaway

Read the OSPF state first. It tells you whether to check Hellos, MTU, or LSDB exchange steps.

Evidence & Commands
show ip ospf neighbor
show ip ospf interface <interface_type/number>
debug ip ospf adjacency  (use with caution)
Concrete Example
Neighbor stuck in INIT. Use show ip ospf interface to compare hello/dead timers; correct mismatches and wait for Full state.
Common Mistake
Restarting routing processes without gathering state information can hide the root cause. Always collect evidence first.
