Module 6 › Chapter 6.4 › BGP Source Interface and ebgp-multihop
Update-source

Using loopbacks

Set update-source to use the loopback IP as the TCP source. Ensure the remote peer has a route back to that loopback address.

Verification
Ping the loopback from the neighbor and use traceroute to confirm symmetric reachability. Test TCP to port 179 from the source address if possible.
ebgp-multihop

When peers are not directly connected

Configure ebgp-multihop to increase TTL for eBGP peers across multiple hops. Check that intermediate ACLs allow TCP 179.

Common mistake
Forgetting to route to the loopback source or to allow TCP/179 through intermediate devices makes sessions fail even with update-source configured.
