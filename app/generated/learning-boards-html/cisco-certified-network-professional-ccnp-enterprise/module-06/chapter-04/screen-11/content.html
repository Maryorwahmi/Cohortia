Module 6 › Chapter 6.4 › BGP Route Filtering and Prefix Controls
Inspection

Look for broad denies

Check inbound/outbound route-maps, prefix-lists and distribute-lists. A single deny can drop all prefixes if ordering is wrong.

show ip bgp summary
show ip bgp
show running-config | section neighbor
Safe testing

Use permissive rules first

Temporarily apply a permissive route-map or remove a prefix-list to confirm whether filtering is the cause. Reapply targeted rules after verification.

Coordination tip
Because filters can be bi-directional, coordinate with the neighbor admin before changing production filters.
