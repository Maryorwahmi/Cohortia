Module 6 › Chapter 6.4 › Common OSPF Configuration Mismatches
Checklist

Step-by-step verification

  1. Run show ip ospf neighbor and note the state.
  2. Use show ip ospf interface <if> to read hello/dead timers and network type.
  3. Compare area IDs on both sides; ensure they match.
  4. Verify authentication configuration and keys match if enabled.
Misconception
Don't assume only MTU causes ExStart issues. Network type or timers may equally prevent progress.
Commands
show ip ospf neighbor
show ip ospf interface <interface_type/number>
show ip interface <interface_type/number>
debug ip ospf adjacency  (use carefully)
Example Fix
If R2 has ip ospf hello-interval 5 and R1 uses default 10, align timers by removing the custom hello interval or setting both to the same value.
Why it matters
Mismatches silently stop route exchange. A single forgotten authentication setting can keep an entire LSDB from synchronizing.
