Process Flow
Divide-and-Conquer
Binary partitioning steps
  1. Define affected population and resources.
  2. Test simple reachability from representative hosts.
  3. Split population and compare results to isolate differences.
  4. Repeat until a single device, VLAN, or link is implicated.
Tip: map what differs between working and non-working groups—routing, ACLs, VLANs.
Example
If half the office can reach a server and half cannot, compare switch configuration and VLAN assignment between the two groups to find the divergence.
Common mistake
Not recording which subset was tested; you can re-test the same hosts repeatedly without progress. Keep a short list of tests and results.
Key takeaway
Narrow the scope methodically. Each split should reduce the candidate set until the faulty component is obvious.
