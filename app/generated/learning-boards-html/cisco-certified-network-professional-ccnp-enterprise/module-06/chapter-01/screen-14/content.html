Lab Walkthrough
RouterA: Troubleshoot access to 192.168.10.100
CLI script to run
RouterA# show ip interface brief
! Verify the user's VLAN interface is up/up and has the correct IP.

RouterA# show ip route 192.168.10.100
! Confirm whether RouterA has a route to the server's network.

RouterA# ping 192.168.10.100
! Test end-to-end reachability.

RouterA# traceroute 192.168.10.100
! Identify the hop where connectivity fails.
Record each output and decide the next device to inspect based on next-hop information. If RouterA has no route, fix routing here. If RouterA has a route but traceroute shows a failure at the next hop, investigate that device.
Example analysis
If show ip route shows a next-hop of 172.16.5.2 and traceroute times out at that hop, inspect 172.16.5.2's interfaces, routing, and ACLs.
Key takeaway
Follow a scripted sequence, capture outputs, and use next-hop evidence to move from local checks to the responsible device.
