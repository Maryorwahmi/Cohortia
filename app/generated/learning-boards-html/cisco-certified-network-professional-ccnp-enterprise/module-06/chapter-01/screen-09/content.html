Reading Key Show Outputs
Example output: show ip interface brief
Interface              IP-Address      OK? Method Status                Protocol
GigabitEthernet0/1.10  10.0.10.1       YES manual up                    up
GigabitEthernet0/2     unassigned      YES unset  administratively down down
Interpretation: interface with VLAN subinterface is up and carrying traffic. An administratively down port must be enabled or checked for configuration errors.
Example output: show ip route
O    10.0.0.0/24 [110/2] via 10.0.20.2, 00:02:34, GigabitEthernet0/2
C    192.168.10.0/24 is directly connected, GigabitEthernet0/1.10
Interpretation: the router has a direct route to the server's subnet. If destination is missing, investigate routing protocols or static route configuration.
Key takeaway
Combine interface and route outputs to decide if the fault is local to the router or further along the path.
