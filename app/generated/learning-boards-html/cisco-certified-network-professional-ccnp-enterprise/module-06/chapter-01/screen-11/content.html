Definition
debug Commands — Use carefully
When debug is appropriate
  • When show commands do not reveal packet-level or event sequencing details.
  • To observe protocol exchanges like OSPF adjacency transitions.
  • When you can apply filters to limit output to a single host or subnet.
Safety checklist
  • Choose protocol-specific debug.
  • Apply ACL filters or address filters where possible.
  • Monitor CPU and disable debug with undebug all when done.
Key takeaway
Reserve debug for targeted investigation and always have an exit plan to stop it immediately to protect device stability.
