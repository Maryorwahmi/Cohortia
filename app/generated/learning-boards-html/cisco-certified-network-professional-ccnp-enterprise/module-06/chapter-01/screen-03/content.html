Show commands: read first
Start with non-intrusive evidence to avoid altering device state.
  • show ip interface brief for interface status and addresses.
  • show ip route for active routing decisions.
  • show running-config to confirm applied settings.

Debug commands: powerful but risky
Use targeted protocol debug and filters; always stop debugging when done.
  • Prefer debug ip ospf adjacency over broad packet debug.
  • Apply ACL filters to confine output when possible.
  • Terminate with undebug all or no debug all.
