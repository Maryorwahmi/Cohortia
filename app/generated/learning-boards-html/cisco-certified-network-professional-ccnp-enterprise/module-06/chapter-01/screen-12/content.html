Process Flow
Safe Debugging
Five-step pattern
  1. Plan the exact problem and select a protocol-specific debug.
  2. Apply ACL or address filters to limit output.
  3. Monitor CPU, memory, and log buffers while debugging.
  4. Capture output needed for analysis.
  5. Terminate debugging immediately: undebug all / no debug all.
Example filter
Use an ACL that matches the host IP to restrict debug ip packet detail to traffic involving only that host.
Key takeaway
Treat debug as temporary and targeted, and always ensure you have a quick command to stop it when the data is collected.
