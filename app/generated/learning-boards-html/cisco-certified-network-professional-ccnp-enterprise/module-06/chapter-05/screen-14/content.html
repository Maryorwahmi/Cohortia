What to Remember

Diagnostic Commands
Use show interfaces trunk, show spanning-tree active, and show etherchannel summary to reveal root causes quickly.
Follow the Path
Access port → trunk → gateway → server. Confirm each hop before changing configs.
Validate Servers
Check show ip dhcp binding, nslookup, and show ntp associations on the servers or gateways to confirm service health.
Use this compact checklist during incidents: commands first, path second, server validation last. This prevents unnecessary configuration changes and speeds resolution.
