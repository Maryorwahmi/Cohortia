Spanning Tree Protocol troubleshooting

Use show spanning-tree active to find the root bridge and port roles. Mis-elections cause suboptimal forwarding or downtime.

show spanning-tree active → root and per-VLAN port roles
Check Bridge ID: priority and MAC determine the root
If root is wrong, set explicit priority or run root primary on intended switch
Misconfiguration Example
A newly-installed access switch used default priority and became the root. Traffic took nonoptimal paths causing congestion. The fix was to configure the intended core switch with a lower priority and set the access switch to a higher priority.
PortFast and BPDU Guard
PortFast immediately forwards host ports but should not be enabled on ports connecting to other switches. BPDU Guard disables a port on BPDU receipt, protecting topology but requiring investigation when triggered.
Key Takeaway

Confirm the root and port roles and apply PortFast/BPDU Guard only on true edge ports to avoid topology disruption.
