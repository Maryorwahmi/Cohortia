Definition

VLAN Trunking and native VLAN mismatches

Trunks carry multiple VLANs with tagging. A native VLAN mismatch causes untagged frames to be misclassified and can destabilize STP.

show interfaces trunk → trunk status, encapsulation, native
show interfaces switchport → port mode and access/trunk details
show vlan brief → confirm VLAN presence and active ports
Diagnostic Flow
  1. Confirm trunk operational: show interfaces trunk.
  2. Check encapsulation matches on both ends (dot1q).
  3. Verify native VLAN on both sides is identical.
  4. Ensure required VLANs are allowed: switchport trunk allowed vlan.
Concrete Scenario
User in VLAN 20 cannot reach servers on VLAN 20. You run show interfaces trunk and find VLAN 20 is not allowed across the aggregation. Adding VLAN 20 to the allowed list restores connectivity.
Key Takeaway

Trunk links must match encapsulation, native VLAN, and allowed VLANs — one mismatch can break connectivity.
