Key Concepts

VLAN Trunking
Carry multiple VLANs over one link with 802.1Q; confirm encapsulation and allowed VLANs.
Native VLAN Mismatch
Different native VLANs between trunk ends cause untagged traffic leakage and STP issues.
STP Root Bridge
Lowest Bridge ID (priority + MAC) becomes root; ensure intended device has lowest priority.
EtherChannel
Bundle links for bandwidth and redundancy; member ports must match and modes must be compatible.
DHCP Helper Address
Forward DHCP broadcasts from a subnet to a remote server using ip helper-address on the gateway.
DNS, NTP & AAA
DNS for names, NTP for time, AAA for access — all require reachability and correct server configuration.
Summary: When troubleshooting start with reachability and VLAN/frame verification, then inspect protocol-specific state with show/debug commands before changing configuration.
