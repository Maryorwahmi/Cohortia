DHCP helper-address lab walkthrough

Follow the steps to reproduce a missing helper address and restore DHCP service.

Step 1: Configure Switch A access port to VLAN 20. Verify with show vlan brief.
Step 2: Confirm Router subinterface has encapsulation and IP. Use show ip interface.
Step 3: Attempt DHCP lease on PC; if fail, add ip helper-address on router subinterface.
Step 4: Verify with show ip dhcp binding on server and test client lease.
Verification Commands
show vlan brief | show interfaces GigabitEthernet0/1 switchport | show ip interface GigabitEthernet0/0.20 | show ip dhcp binding
Scenario Config (starter)
! Switch A (starter)
interface GigabitEthernet0/1
 switchport mode access
 switchport access vlan 20
 no shutdown

! Router R1 (starter)
interface GigabitEthernet0/0.20
 encapsulation dot1Q 20
 ip address 10.0.20.1 255.255.255.0
 no shutdown
