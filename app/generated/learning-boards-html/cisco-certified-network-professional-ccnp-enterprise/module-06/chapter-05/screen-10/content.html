Definition

DNS and NTP troubleshooting

Check configured name servers and NTP servers, verify reachability, and test responses to prove service health.

DNS: verify client DNS via DHCP, ping DNS server, use nslookup to test resolution.
NTP: show ntp status and show ntp associations to confirm synchronization.
Concrete Example
Users can ping 8.8.8.8 but cannot browse by name. On the gateway, show ip name-servers reveals an incorrect server IP. After correcting ip name-server and confirming ping succeeds, hostnames resolve and browsing works again.
Check Your Understanding
When NTP shows no association, what two quick checks should you perform before changing server configuration? (Answer: ping for reachability and verify authentication keys if used.)
Key Takeaway

DNS and NTP troubleshooting are reachability-first tasks; confirm the server and then the protocol response.
