EtherChannel faults: Mode vs Configuration

Mode Mismatch: LACP vs PAgP vs static. Use show etherchannel summary to identify negotiation failures.
Config Inconsistency: speed/duplex, native VLAN, allowed VLANs must match on every member interface.
Port-channel State: check the logical interface with show interfaces port-channel <n> to confirm up/up.
Diagnostic Commands
show etherchannel summary → bundle and member status. show interfaces port-channel <n> → logical interface details. show running-config interface <int> → verify per-interface settings.
Concrete Example
One side was set to LACP active and the other to channel-group mode on (no LACP). The bundle did not form. Changing both sides to LACP active fixed the aggregation.
Key Takeaway

Ensure matching protocols and identical interface settings. Use show etherchannel summary to uncover mode mismatch quickly.
