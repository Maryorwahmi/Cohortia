Process Flow

AAA service troubleshooting

Authentication, authorization, and accounting require reachable servers and matching secrets; verify both sides.

show aaa servers → server list and reachability
ping → basic reachability
debug aaa authentication → observe authentication flow
Concrete Example
Users cannot log in because the RADIUS server moved IPs. A ping from the switch failed. After updating the server entry and secret, authentication succeeded and accounting entries resumed.
Common Mistake
Changing local authentication before confirming the AAA server is reachable can hide root causes and complicate rollback.
Key Takeaway

Confirm AAA server reachability and shared secrets, then use debug traces and server logs to complete diagnosis.
