Troubleshooting DHCP failures and helper-addresses

Verify VLAN membership, router subinterface, and helper address before changing server scopes.

Show Commands
  • show vlan brief
  • show interfaces switchport
  • show ip interface
  • show ip dhcp binding
Key Takeaway

Always confirm the helper address and path to the DHCP server before altering pools.

Configuration Example
! Switch A (access port)
SwitchA(config)# interface GigabitEthernet0/1
SwitchA(config-if)# switchport mode access
SwitchA(config-if)# switchport access vlan 20
SwitchA(config-if)# no shutdown

! Router R1 subinterface (problematic initially)
RouterR1(config)# interface GigabitEthernet0/0.20
RouterR1(config-subif)# encapsulation dot1Q 20
RouterR1(config-subif)# ip address 10.0.20.1 255.255.255.0
RouterR1(config-subif)# no shutdown

! Fix: add helper address
RouterR1(config-subif)# ip helper-address 192.168.1.50
After configuring the helper address, verify with show ip interface GigabitEthernet0/0.20 and then test the client obtaining an IP. On the DHCP server use show ip dhcp binding to confirm assignment or debug ip dhcp server packet to watch the transaction.
