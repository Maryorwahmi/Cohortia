Module 8 › Chapter 8.2 › RESTCONF curl examples
GET hostname
curl -k -u <username>:<password> -X GET \ https://<device-ip>/restconf/data/Cisco-IOS-XE-native:native/hostname \ -H 'Accept: application/yang-data+json'
The response should include a JSON object like { "Cisco-IOS-XE-native:hostname": "MyAutomatedRouter" }.
PATCH hostname
curl -k -u <username>:<password> -X PATCH \ https://<device-ip>/restconf/data/Cisco-IOS-XE-native:native \ -H 'Content-Type: application/yang-data+json' \ -d '{ "Cisco-IOS-XE-native:native": { "hostname": "MyAutomatedRouter-REST" } }'
Use PATCH for a partial update. Verify the change with the GET command or via CLI.
Safety reminder
Avoid -k and basic auth in production. Use HTTPS certificates or token-based auth, and test in a lab first.
