Learning Objectives
Build vocabulary, practice device API calls, and adopt safe automation habits.
Learn → Understand → Apply → Master
01
Explain YANG and its role
Describe how a formal model defines types, constraints and the hierarchical paths automation uses. This matters because consistent schemas make multi-vendor automation reliable.
VERIFIED COMPETENCY MILESTONE
02
Differentiate NETCONF and RESTCONF
Explain transport, encoding and operation styles. This helps you choose transactional or web-native APIs appropriately.
VERIFIED COMPETENCY MILESTONE
03
Describe NETCONF/RESTCONF operations
List NETCONF RPCs and RESTCONF HTTP methods and how they map to YANG datastores and resources. This supports correct API calls and safe automation.
VERIFIED COMPETENCY MILESTONE
04
Perform basic RESTCONF/NETCONF calls
Use curl or Python requests to GET and PATCH a hostname in a lab, observing authentication, content-types and namespaces. This proves end-to-end automation ability.
VERIFIED COMPETENCY MILESTONE
