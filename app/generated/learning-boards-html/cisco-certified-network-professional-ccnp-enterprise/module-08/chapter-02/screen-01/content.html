YANG
A formal schema for device configuration and state so automation tools speak a common language.
NETCONF
XML RPCs over SSH, transactional edits and datastores that keep configurations consistent.
RESTCONF
HTTP/HTTPS interface mapped to YANG paths. Uses JSON and common web verbs for CRUD operations.
