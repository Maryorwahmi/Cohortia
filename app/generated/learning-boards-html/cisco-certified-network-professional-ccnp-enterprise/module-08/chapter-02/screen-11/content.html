Module 8 › Chapter 8.2 › Lab Walkthrough
Step 1: Prepare
Enable RESTCONF/NETCONF and ensure a lab account with correct privileges.
Step 2: Inspect
Read the YANG modules or device documentation to identify correct namespaces and paths.
Step 3: Test GET
Run a GET and verify returned JSON matches expected structure before attempting changes.
Step 4: Apply change
Use PATCH/PUT for RESTCONF, or edit-config and commit for NETCONF, following safety patterns like locking and validation.
Step 5: Verify
Perform a read-back GET and cross-check in CLI. Revert changes if unexpected results appear.
Python note
Using Python requests: set requests.get(url, auth=(user,pass), headers=headers) and inspect response.status_code and response.json() for predictable handling.
