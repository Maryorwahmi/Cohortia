Module 8 › Chapter 8.2 › Practice Targets
Find YANG paths
Locate the namespace and hierarchical path for elements like hostname or interface. This prevents wrong-path API calls that fail silently.
Map operations
Decide between NETCONF edit-config and RESTCONF PATCH or PUT based on transactional needs and idempotency.
Curl & Python practice
Compose authenticated GET and PATCH calls and verify responses. Use Accept and Content-Type headers per YANG encoding.
Safety checks
Use lab devices, minimal privileges, and read-back verification. Test idempotency and rollback where available.
