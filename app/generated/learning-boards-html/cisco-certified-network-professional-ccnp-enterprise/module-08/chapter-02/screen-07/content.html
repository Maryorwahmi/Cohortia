Module 8 › Chapter 8.2 › NETCONF edit-config
Example XML payload
<rpc message-id="101" xmlns="urn:ietf:params:xml:ns:netconf:base:1.0"> <edit-config> <target> <running/> </target> <config> <native xmlns="http://cisco.com/ns/yang/Cisco-IOS-XE-native"> <hostname>MyAutomatedRouter</hostname> </native> </config> </edit-config> </rpc>
Annotations
  • xmlns — identifies the NETCONF base namespace on the rpc element.
  • native xmlns — module namespace for hostname; must match device YANG module.
  • message-id — correlates request and rpc-reply for tracking.
  • target — selects the datastore you are editing, e.g., running or candidate.
Common mistake: wrong module URI or omitted namespace; the payload may be accepted but ignored or rejected.
