YANG building blocks
  • Container — groups related nodes, like native features under a common parent.
  • List — repeated entries, such as interfaces or VLANs identified by a key.
  • Leaf — a single value node, for example hostname or IP address.
  • Types & constraints — enforce expected formats and ranges to reduce invalid inputs.
Tip: Always check the module's namespace and path before forming API calls.
Practical inspection
Devices often expose YANG modules via a developer portal or through the device itself. Locate the module that contains the element you need and note mandatory children and default values.
Concrete example
If a model requires hostname inside Cisco-IOS-XE-native:native, your RESTCONF URI must include that exact module name to retrieve or update the field.
Misconception
YANG is optional. In truth, it's the canonical way automation understands device structure.
Why it matters
Correct models prevent invalid writes and make multi-vendor automation feasible.
Check
Have you confirmed the namespace and mandatory leaves before your first API call?
