Module 8 › Chapter 8.1 › Imperative Example: SSH Scripting
Process Flow
Imperative script pattern
Open session → Authenticate → Enter config mode → Run commands → Verify → Save/rollback.
Example (pseudo-shell steps)
# Connect to device over SSH
ssh admin@router.example.com
# enter enable and config mode
enable
configure terminal
interface GigabitEthernet0/1
ip address 192.168.10.1 255.255.255.0
no shutdown
end
write memory
# verify interface status
show ip interface brief | include GigabitEthernet0/1
Note: this code panel is a readable pattern, not vendor-specific output. Replace with secure session methods in production.
Risks & Mitigations
  • Risk: brittle if device prompts differ. Mitigation: robust parsing and error handling.
  • Risk: partial failures leave devices inconsistent. Mitigation: add verification and rollback steps.
  • Risk: exposed credentials. Mitigation: use vaults or environment-based secrets.
Key Takeaway
Imperative scripts are direct but need verification, version control, and secure secrets to be safe in production.
