Module 8 › Chapter 8.1 › From CLI to Programmable Networks
Core Concept
What changes when you automate
Manual CLI: human steps, prone to typos and drift. Programmable: machine-readable interfaces and repeatable workflows for scale and auditability.
Concrete example
Applying a VLAN across 30 switches becomes a single run from a playbook rather than 30 console sessions.
Common misconception
Automation replaces knowledge — not true. You still must know addressing, interfaces, and failure modes to automate safely.
Key Takeaway

Programmability turns manual steps into repeatable, auditable operations so changes scale reliably.

Definition & Analogy
Think of the network as software you can version and test
Analogy: instead of manually building ten identical assemblies, you run a tested script that builds each the same way. This reduces variance and speeds delivery.
