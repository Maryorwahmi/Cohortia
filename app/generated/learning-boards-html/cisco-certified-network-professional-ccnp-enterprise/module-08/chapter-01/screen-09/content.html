Module 8 › Chapter 8.1 › APIs and Data Models
Definition
APIs give access; data models give meaning
APIs return structured data and accept structured inputs. Data models like YANG define the schema and semantics of that data so automation tools can validate and act consistently.
Concrete example
Query interface counters via an API that returns JSON, then map those fields directly into a monitoring database without fragile parsing.
Misconception
Assuming all devices implement identical models — vendor variations exist, so normalize and validate returned data.
Practical checklist
  • Prefer structured APIs over CLI screen-scraping for reliability.
  • Use standardized data models when possible and implement normalization layers.
  • Validate API responses before applying dependent automation steps.
Key Takeaway
APIs plus data models replace brittle parsing with predictable contracts, making automation maintainable and testable.
