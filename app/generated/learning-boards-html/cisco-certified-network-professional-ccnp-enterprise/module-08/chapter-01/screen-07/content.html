Module 8 › Chapter 8.1 › Declarative Example: Playbooks & Idempotence
Definition
Declarative playbook pattern
Declare the desired configuration and let the engine converge state; re-running is safe when idempotent.
Example (declarative intent)
# Pseudo-playbook intent
- name: Ensure management interface configured
  target: switch-group
  state:
    interface: Management0
    ip: 10.0.0.10/24
    admin: up
    ssh: enabled
This shows intent rather than step commands; the engine computes changes needed to reach this state.
Best practices
  • Model desired state clearly and keep playbooks modular.
  • Test on canary devices before wide rollouts.
  • Use version control and document expected outcomes for audits.
Key Takeaway
Declarative methods promote safe, repeatable convergence and are ideal for large-scale consistent changes.
