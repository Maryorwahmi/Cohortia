Differentiate imperative vs declarative

Explain APIs & data models

Use secure credential storage
Adopt vaults or environment-based secrets and avoid hardcoding credentials in scripts to reduce operational risk.
VERIFIED COMPETENCY MILESTONE

Map tasks to automation patterns
Be able to take a manual process like branch onboarding and decide which steps suit imperative scripts and which fit declarative playbooks.
