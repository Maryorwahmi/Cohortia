Module 8 › Chapter 8.1 › Imperative vs Declarative
Comparison
Imperative
Explicit steps executed in order. Useful for direct device scripting and quick sequential changes.
Concrete example
A script logging in via SSH and issuing configuration lines to enable an interface and set an IP.
Misconception
Imperative is always faster to write — sometimes true, but it can be more fragile at scale without idempotence.
Comparison
Declarative
Describe desired state; the tool ensures convergence. Idempotent by design for predictable re-runs.
Concrete example
An Ansible playbook declaring interface state and VLAN membership, applied across many switches to converge configurations.
Key Takeaway
For large-scale, repeatable tasks, declarative methods reduce unintended side effects and ease audits.
Decision checklist
  • Is the task repeated across many devices? Prefer declarative.
  • Does the toolchain provide idempotence? Important for safety.
  • Is there a direct SSH-only interface? Imperative may be pragmatic for quick fixes.
Analogy
Imperative is a recipe. Declarative is a picture of the finished model — the builder figures out the steps.
