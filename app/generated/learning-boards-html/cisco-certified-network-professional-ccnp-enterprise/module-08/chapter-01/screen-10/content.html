Module 8 › Chapter 8.1 › Activity: Identify Automation Opportunities
Hands-on Activity
Branch onboarding — break it down
List tasks, describe manual CLI steps, and decide on an automation approach for each task.
Sample task 1: Router basic config
Manual: console login, enable, configure terminal, set hostname, interface IP, enable SSH. Automation: Declarative playbook to ensure hostname, IP, and SSH present across devices.
Sample task 2: VLANs on switches
Manual: enter each switch, create VLAN IDs, configure trunks. Automation: Declarative inventory-driven playbook or template to converge VLANs consistently.
Sample task 3: Apply firewall rules
Manual: sequence of ACLs and order-sensitive commands. Automation: Declarative where possible, or imperative with careful ordering and verification.
Activity guidance
  • Start with tasks that are repetitive and low-risk.
  • Choose declarative for state convergence and imperative for unique or procedural fixes.
  • Document expected outcomes and include verification steps after automation runs.
Key Takeaway
Mapping manual steps to automation patterns enables safe, incremental adoption and clearer governance.
