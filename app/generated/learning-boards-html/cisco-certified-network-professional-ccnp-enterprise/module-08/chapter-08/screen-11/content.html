Rollback Strategies

Make rollbacks automated, verifiable, and rehearsed.
Safe rollback patterns
  • Tagged restore: Reapply a known-good commit or tag from the Git repository.
  • Corrective playbook: Have a playbook that undoes only the problematic section.
  • Feature toggle: Use template variables to disable a feature without a full revert.

Verification

Automate post-rollback checks to confirm connectivity and protocol states before marking the rollback complete.

Runbook Snapshot

Keep a short runbook with the rollback command, owner, expected timeline, and verification commands to reduce confusion during incidents.

Gotcha

Some changes, like database migrations or stateful sessions, do not revert cleanly. Plan for these cases separately.
