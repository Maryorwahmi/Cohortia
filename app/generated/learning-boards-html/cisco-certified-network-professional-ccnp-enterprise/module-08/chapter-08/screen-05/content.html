Git: commands and example workflow
A terminal-style walkthrough you can follow on your workstation.
Core Git commands
  • git init — initialize a repository.
  • git add <file> — stage changes for commit.
  • git commit -m "message" — save staged changes to history.
  • git status / git diff — inspect working tree and changes.
  • git branch / git checkout / git merge — manage branches and integrate features.
Why this matters
These commands let you create a reproducible history of network templates and scripts. When used with CI/CD, commits become the trigger for validation and deployment pipelines.
Hands-on file and commands
mkdir network_configs
cd network_configs
git init
# create router_base.cfg with base IOS XE config
git status
git add router_base.cfg
git commit -m "Initial base configuration for router"

# edit to add NTP server
git status
git diff
git add router_base.cfg
git commit -m "Added NTP server configuration"
Use the sequence above to observe how Git records changes. The repository becomes the single source of truth for your device templates and automation scripts.
