Key Concepts to Remember

Essential Terms for Web Penetration Testing

HTTP Methods (Verbs)

Actions to be performed on the resource identified by the Request-URI (e.g., GET, POST, PUT, DELETE).

HTTP Request

A message sent by a client to a server, consisting of a Request Line, Headers, and an optional Body.

HTTP Response

A message sent by a server to a client, consisting of a Status Line, Headers, and an optional Body.

Status Code

A three-digit integer in an HTTP response indicating the outcome of the request (e.g., 200 OK, 404 Not Found).

HTTP Headers

Key-value pairs in HTTP messages that provide metadata about the request or response (e.g., User-Agent, Cookie, Set-Cookie).

Summary Takeaway

Mastering the core components of HTTP messages is the first step towards effective web vulnerability analysis.
