Server Directives

Analyzing Response Headers

Security Controls and Information Disclosure

Set-Cookie

Sets cookies in the client's browser. Insecure flags lead to session hijacking.

CSP

Content-Security-Policy. Mitigates XSS by controlling resource loading.

X-Frame-Options

Prevents clickjacking by controlling if a page can be embedded in an iframe.

HSTS

Strict-Transport-Security. Enforces HTTPS, preventing downgrade attacks.

Server / X-Powered-By

Identifies web server/application technology. Can reveal vulnerable software versions.

Content-Type

Indicates the media type of the resource in the response body (e.g., text/html, application/json).

Key Takeaway

Misconfigurations or the absence of critical security headers can expose an application to various attacks. Always check for their proper implementation.
