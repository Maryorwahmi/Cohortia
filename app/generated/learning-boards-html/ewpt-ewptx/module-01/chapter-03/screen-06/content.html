Understanding Request Headers

Metadata for Client-Server Communication

Host

Specifies the domain name of the server. Critical for virtual hosting.

User-Agent

Identifies the client software (e.g., browser). Can be manipulated to bypass controls.

Cookie

Contains session tokens or client-side data. A primary target for session hijacking.

Referer

URL of the page that linked to the current request. Can be a vector for XSS if manipulated.

Content-Type

For POST/PUT, specifies the format of the request body (e.g., JSON, form data).

Accept

Indicates content types the client can process. Can reveal client capabilities.

Key Takeaway

Each request header can be a source of information leakage or a vector for attack if not securely handled by the server. Always scrutinize their values.
