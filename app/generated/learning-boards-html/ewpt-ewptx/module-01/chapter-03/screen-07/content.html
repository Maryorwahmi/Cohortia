Data Transmission

The Optional Request Body

Sending Data for Processing

Purpose

Carries data for methods like POST and PUT, typically for processing or creation.

Common Formats

application/x-www-form-urlencoded for forms, application/json or application/xml for APIs.

Pentesting Relevance

The primary area for crafting and injecting attack payloads (e.g., SQLi, XSS, Command Injection).

Key Takeaway

Understanding the expected format and content of the request body is crucial for effective vulnerability testing.

Example: Request Body Formats

Form URL-Encoded:

username=testuser&password=testpass

JSON Payload:

{
  "user": "admin",
  "pass": "secret123"
}
Misconception

Only POST requests have a body. While most common, PUT requests also use the body to send resource data.
