Decoding Status Lines and Codes

Response Structure
HTTP/1.1 200 OK
Content-Type: text/html
Set-Cookie: sessionid=abc; HttpOnly

<html>...</html>
  • •Status Line: HTTP Version, Status Code, Reason Phrase.
  • •Response Headers: Metadata about the server or resource.
  • •Response Body: The requested resource (e.g., HTML, JSON).
Key Status Codes for Pentesters
200 OK

Request successful. (Expected behavior)

302 Found

Redirection. (Potential for abuse in certain scenarios).

401 Unauthorized

Authentication required. (Indicates access control).

403 Forbidden

Access denied. (Strong indicator of access control issues if bypassed).

404 Not Found

Resource not found. (Common, but can hide directory traversal).

500 Internal Error

Server-side error. (Often reveals sensitive error messages/stack traces).

Key Takeaway

Status codes are a quick and powerful diagnostic tool, often hinting at underlying vulnerabilities or misconfigurations.
