Maintaining State

Cookies: The State of the Web

Managing User Sessions and Their Vulnerabilities

How Cookies Work

  • •Server sends small data pieces (cookies) to the browser.
  • •Browser stores cookies and sends them back with subsequent requests.
  • •Used to maintain user state in stateless HTTP.
Example: Session Management

After login, server issues a session ID in a cookie; browser sends it back to identify the authenticated user.

Cookie Vulnerabilities

  • •Session Fixation: Attacker forces a known session ID.
  • •Session Hijacking: Attacker steals a valid session ID.
  • •Insecure Flags: Missing HttpOnly, Secure, SameSite.
Key Takeaway

Insecure cookie handling is a common source of web vulnerabilities. Always check for proper flag configuration and session management.

Pro-Tip

Use browser developer tools or an intercepting proxy like Burp Suite to inspect all cookie attributes and identify potential weaknesses.
