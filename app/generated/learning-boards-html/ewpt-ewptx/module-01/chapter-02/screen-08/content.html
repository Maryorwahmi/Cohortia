Browser Proxy Configuration Steps

01

Open Browser Settings

Navigate to your browser's network configuration.

02

Manual Proxy Config

Select manual proxy settings for HTTP and SSL.

03

Set IP & Port

Use 127.0.0.1:8080 for Burp Suite.

04

Verify Traffic

Check Burp's 'Intercept' tab for incoming requests.

Example: Firefox Proxy Settings

In Firefox, navigate to Settings -> Network Settings -> Manual proxy configuration. Enter 127.0.0.1 for both HTTP and SSL Proxy, and 8080 for the port. Remember to click 'OK' to save your changes.

Key Takeaway

Configuring your browser to proxy through Burp Suite is a fundamental step, redirecting all web traffic for inspection and manipulation, enabling deep analysis of web application behavior.
