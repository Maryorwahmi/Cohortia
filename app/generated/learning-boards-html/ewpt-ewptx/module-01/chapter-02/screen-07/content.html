What is an Intercepting Proxy?

A tool that sits between a client (e.g., browser) and a server, allowing traffic to be viewed, modified, or dropped before reaching its destination.

Key Capabilities
  • Inspect HTTP/S requests & responses.
  • Modify parameters and headers on the fly.
  • Analyze application communication flows.
Example: Launching Burp Suite

After installing Java, you can typically launch Burp Suite Community Edition from your terminal using: java -jar /path/to/burpsuite_community.jar
