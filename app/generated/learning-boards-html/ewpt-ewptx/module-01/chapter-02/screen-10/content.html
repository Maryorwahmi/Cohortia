CA Certificate Installation Steps

01

Navigate to http://burp

Access Burp's certificate download page.

02

Download Certificate

Download the cacert.der file.

03

Import into Browser

Add the .der file to your browser's trust store.

04

Trust CA

Explicitly trust the certificate to identify websites.

05

Restart Browser

Apply changes and clear any cached security warnings.

06

Verify Interception

Access an HTTPS site and check Burp's Proxy tab.

Example: Firefox Certificate Import

In Firefox, after downloading cacert.der, go to Settings -> Privacy & Security -> Certificates -> View Certificates -> Authorities -> Import. Select the file and check 'Trust this CA to identify websites'.

Key Takeaway

The successful installation and trusting of Burp Suite's CA certificate in your browser is the final technical hurdle to transparently intercepting and analyzing all HTTPS traffic within your lab environment.
