The Database

Persistent Data Storage for Web Applications

The database is a structured collection of data, managed by a DBMS, used for storing and retrieving application information persistently.

  • •Stores all persistent data: user info, product details, content.
  • •Interacts with the application server to fulfill data requests.
  • •Examples: MySQL, PostgreSQL, MongoDB, SQL Server.
Key Takeaway

Databases are critical for data persistence and are often high-value targets for attackers due to the sensitive information they hold.

Security Note

Vulnerabilities like SQL Injection directly target databases, allowing unauthorized data access or manipulation.
