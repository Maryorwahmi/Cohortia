Time-based Blind SQL Injection

Deducing information through server response delays.

Core Mechanism

Relies on injecting time-delay functions into queries. If a condition is true, the server pauses; if false, it responds immediately.

When to Use It

When there are no discernible differences in application response (page content, errors) for true/false conditions.

Key Takeaway

Time-based Blind SQLi uses server response delays as a binary signal to extract data, making it a last resort in highly blind scenarios.

Time-based Blind SQLi: The Delay Signal
1. Inject Conditional Delay

id=1 AND IF(condition, SLEEP(5), 0)

2. Observe Long Response Time

Page loads after 5 seconds.

3. Infer Condition is TRUE

The injected condition was met.

Alternatively, if the page loads immediately, the condition was FALSE.
