Key Concepts

Essential ideas to remember

Blind SQL Injection

SQLi where the attacker cannot see query results directly but infers information from application behavior or response.

Boolean-based Blind SQLi

Information extracted by observing differences in application response (e.g., page content changes) based on true/false conditions.

Time-based Blind SQLi

Information extracted by observing time delays in the server's response, triggered by injecting time-delay functions.

Summary Takeaway

Blind SQL Injection techniques are essential for extracting data when direct output is unavailable, relying on subtle application responses or server delays to infer information.
