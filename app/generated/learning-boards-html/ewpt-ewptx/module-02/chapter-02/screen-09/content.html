Out-of-Band (OOB) SQL Injection

Forcing database interaction with external attacker-controlled systems.

Core Mechanism

The database server initiates an interaction (e.g., DNS lookup, HTTP request) with an external system controlled by the attacker.

Why it Matters

Highly effective in restricted environments where traditional output channels are completely blocked, offering a covert way to exfiltrate data.

Key Takeaway

OOB SQLi bypasses web application responses by making the database server communicate directly with an attacker's external system, providing a robust exfiltration channel.

OOB SQLi: External Communication Flow
1. Inject OOB Payload

SQL query designed to trigger external call.

2. Database Server Initiates External Request

e.g., DNS lookup, HTTP request.

3. Attacker's System Logs Interaction

Data exfiltrated via external log.

This method works even when web application output is completely blocked.
