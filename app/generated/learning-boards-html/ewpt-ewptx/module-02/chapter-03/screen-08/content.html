File System Exploitation

Local File Inclusion (LFI)

A vulnerability allowing an attacker to include and execute files from the local server's file system through user-supplied input, often via directory traversal.

Attack Example

Reading /etc/passwd

http://example.com/index.php?page=../../../../etc/passwd can force the application to display the contents of the password file.

Key Takeaway

LFI allows attackers to read sensitive local files by manipulating file paths, often using directory traversal characters.

Vulnerable PHP Code Pattern
<?php
// Highly vulnerable LFI example
$file = $_GET['page'] . '.php';
include($file);
?>
Directory Traversal

Attackers use ../ (dot-dot-slash) sequences to move up directory levels and access files outside the intended web root.

Common Targets
  • /etc/passwd (Linux user accounts)
  • /etc/shadow (Linux hashed passwords)
  • Web server access logs (e.g., /var/log/apache2/access.log)
  • Application source code and configuration files
