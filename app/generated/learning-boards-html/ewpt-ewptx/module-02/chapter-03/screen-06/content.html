Module 3›Chapter 2.3›Impact and Prevention
Potential Impact

Severe System Compromise

  • Reading sensitive files (e.g., /etc/passwd)
  • Creating new users or installing backdoors
  • Full system takeover and data exfiltration
  • Wiping entire file systems
Common Mistake

Relying on Blacklisting

Attempting to filter out known malicious characters is often insufficient, as attackers can frequently bypass these filters with creative payloads.

Prevention Strategies

Robust Input Validation

  • Whitelisting: Only allow explicitly defined safe characters or values.
  • Parameterized APIs: Use language-specific functions that do not interpret user input as commands.
  • Avoid Direct Execution: Never directly concatenate user input into shell commands.
  • Least Privilege: Run applications with minimal necessary permissions.
Key Takeaway

Proactive input validation, especially whitelisting, and avoiding direct command execution are the strongest defenses against Command Injection.
