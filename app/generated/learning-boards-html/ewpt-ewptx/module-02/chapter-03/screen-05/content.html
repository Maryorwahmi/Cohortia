Command Separators

Special characters used in shell commands to execute multiple commands in a single line, enabling attackers to inject their own commands.

Example Payload

Listing Root Directory

If an application runs ping -c 4 user_input_ip, an attacker could input 127.0.0.1; ls -la / to first ping localhost and then list the contents of the root directory.

Key Takeaway

Mastering command separators is essential for crafting effective Command Injection payloads and understanding their execution flow.

Common Separators & Usage

& (Ampersand)

Execute commands sequentially, regardless of success.

&& (Double Ampersand)

Execute second command only if first succeeds.

| (Pipe)

Pipe output of first command to input of second.

|| (Double Pipe)

Execute second command only if first fails.

; (Semicolon)

Execute commands sequentially, similar to '&', but without backgrounding.
