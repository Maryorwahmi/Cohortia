Core Vulnerability Class

File Inclusion

A vulnerability where a web application is tricked into including or executing files that were not intended by the developer, often leading to information disclosure or RCE.

Key Distinction

Local vs. Remote

File Inclusion vulnerabilities are categorized into Local File Inclusion (LFI) and Remote File Inclusion (RFI), depending on the source of the included file.

Key Takeaway

File Inclusion vulnerabilities exploit how applications handle user-controlled file paths, leading to unintended file access or code execution.

Types of File Inclusion

Local File Inclusion (LFI)

Includes files from the local server's file system.

Remote File Inclusion (RFI)

Includes files from a remote server, typically controlled by an attacker.
