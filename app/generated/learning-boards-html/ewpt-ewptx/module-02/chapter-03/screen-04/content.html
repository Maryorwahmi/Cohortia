Core Concept

Command Injection

A vulnerability allowing an attacker to execute arbitrary operating system commands on the server by injecting malicious input into an application's command execution.

Impact

Remote Code Execution (RCE)

Often the result of Command Injection, RCE grants attackers the ability to run arbitrary code on the remote server, leading to full system compromise.

Key Takeaway

Any user input directly used in shell commands is a potential Command Injection vector, leading to severe RCE risks.

Vulnerable Code Example (PHP)
<?php
$ip = $_GET['ip'];
// Highly vulnerable: user input directly in shell_exec
$command = "ping -c 4 " . $ip;
$output = shell_exec($command);
echo "<pre>$output</pre>";
?>
Vulnerable Functions
  • PHP: exec(), system(), shell_exec(), passthru()
  • Python: subprocess.run() (when shell=True)
  • Node.js: child_process.exec()
Attack Scenario

Injecting Commands

If ping -c 4 user_input_ip is executed, an attacker can input 127.0.0.1; ls -la / to first ping localhost and then list the root directory contents.
