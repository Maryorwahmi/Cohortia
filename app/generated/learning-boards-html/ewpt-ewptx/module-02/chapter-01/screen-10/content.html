Identifying String-Compatible Columns

Using UNION SELECT NULL to locate columns that accept and display string data.

Why it's Needed

To ensure extracted text-based data is displayed correctly on the web page.

The Technique

Use UNION SELECT NULL, ..., NULL (matching column count) and replace NULLs with a test string like 'TEST'.

Observation

Note which columns successfully display the test string on the web page.

Assuming 5 columns:
http://example.com/products?id=-1 UNION SELECT NULL, 'TEST', NULL, 'ANOTHER TEST', NULL--+
Webpage Output:

ID: NULL - Name: TEST - Description: NULL - Category: ANOTHER TEST - Price: NULL

Columns 2 and 4 are string-compatible.
Key Takeaway

By replacing NULLs with test strings in UNION SELECT, you can identify which columns are suitable for displaying extracted data on the web page.
