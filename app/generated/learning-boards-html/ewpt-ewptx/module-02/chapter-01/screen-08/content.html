Introduction to UNION-based SQLi

Combining query results to extract hidden data from other tables or databases.

Core Principle

Combine the results of an injected query with the original query's results.

Purpose

Extract data from other tables, databases, or system information that the application wouldn't normally display.

Key Requirements

Injected and original queries must have the same number of columns and compatible data types.

Original Query:
SELECT id, name, description FROM products WHERE id = [id];
Injected Query (Conceptual):
SELECT id, name, description FROM products WHERE id = [id] UNION SELECT username, password, NULL FROM users;
Combines product data with user credentials.
Key Takeaway

UNION-based SQLi is a powerful data exfiltration technique that merges results from an injected query with the original, requiring matching column counts and data types.
