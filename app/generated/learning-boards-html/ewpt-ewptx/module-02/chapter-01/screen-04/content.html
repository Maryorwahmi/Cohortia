Core Concept

What is SQL Injection (SQLi)?

Executing malicious SQL statements through vulnerable web applications.

Definition

SQL Injection is a web security vulnerability that allows an attacker to interfere with the queries an application makes to its database.

How it Works

Occurs when an application directly concatenates user-supplied data into a SQL query string without proper sanitization or validation.

Potential Impact

Bypass authentication, retrieve sensitive data, modify database content, or take control of the database server.

Vulnerable Query Example:
SELECT * FROM users WHERE username = 'user_input' AND password = 'pass_input';
Injected Query Example:
SELECT * FROM users WHERE username = '' OR 1=1--' AND password = 'pass_input';
Malicious input alters query logic.
Key Takeaway

SQLi exploits the direct concatenation of user input into SQL queries, allowing attackers to manipulate database operations.
