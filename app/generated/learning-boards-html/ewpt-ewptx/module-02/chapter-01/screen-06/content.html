Common Attack

Authentication Bypass Explained

Gaining unauthorized access to a system with a simple SQLi payload.

The Goal

Log into an application without knowing valid credentials.

How it Works

Manipulate the SQL query's WHERE clause to always evaluate to true, bypassing the password check.

Impact

Unauthorized access, potentially as an administrator, leading to full system compromise.

Original Query:
SELECT * FROM users WHERE username = '[username]' AND password = '[password]';
Injected Username: ' OR 1=1--
SELECT * FROM users WHERE username = '' OR 1=1--' AND password = '[password]';
The '--' comments out the rest of the query.
Key Takeaway

Authentication bypass leverages SQLi to force the WHERE clause to true, granting unauthorized access by nullifying credential checks.
