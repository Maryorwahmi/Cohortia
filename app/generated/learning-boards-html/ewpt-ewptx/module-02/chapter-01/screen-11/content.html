Data Exfiltration

Extracting Data with UNION SELECT

Using SQL functions and information_schema to retrieve sensitive database details.

SQL Functions

Replace string-compatible NULLs with functions like version(), user(), and database().

Information Schema

Query the information_schema database to enumerate tables, columns, and other metadata.

Example Use

List all tables in the current database using information_schema.tables.

Extracting Database Name (assuming 3 columns, 2nd is string-compatible):
http://example.com/products?id=-1 UNION SELECT 1, database(), NULL--+
Extracting Database Version:
http://example.com/products?id=-1 UNION SELECT 1, version(), NULL--+
These functions reveal critical system information.
Key Takeaway

By leveraging SQL functions and querying the information_schema, attackers can extract a wealth of sensitive database information through UNION-based SQLi.
