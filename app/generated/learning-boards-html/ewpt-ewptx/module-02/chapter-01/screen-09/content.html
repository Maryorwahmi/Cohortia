Reconnaissance Step

Determining Column Count with ORDER BY

Using the ORDER BY clause to discover the number of columns in the original query.

Why it's Needed

The UNION SELECT statement requires both queries to have an identical number of columns.

The Technique

Incrementally increase the column number in the ORDER BY clause until a database error occurs.

Example

If ORDER BY 5 works but ORDER BY 6 errors, the query has 5 columns.

Vulnerable URL Parameter:
http://example.com/products?id=1
Testing Column Count:
http://example.com/products?id=1 ORDER BY 1--+
http://example.com/products?id=1 ORDER BY 2--+
...
http://example.com/products?id=1 ORDER BY 5--+ // Works!
http://example.com/products?id=1 ORDER BY 6--+ // Error!
Conclusion: 5 columns.
Key Takeaway

The ORDER BY clause is used to systematically determine the number of columns in a query by observing when an incremented column number causes an error.
