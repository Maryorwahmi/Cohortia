Web Application Firewall (WAF) Evasion

Obfuscating XSS Payloads to Bypass Detection

WAF Detection & Challenges

WAFs are designed to filter and block malicious traffic, often using signature-based detection to identify common XSS patterns. Attackers must craft payloads that can bypass these filters without losing their malicious functionality, requiring creative encoding and obfuscation.

Key Takeaway

Effective WAF evasion requires understanding the WAF's logic and experimenting with diverse encoding, obfuscation, and alternative HTML/JS syntax.

Why it matters

Bypassing WAFs allows attackers to deliver XSS payloads to vulnerable applications, even when a WAF is deployed as a primary defense layer.

Evasion Techniques

  • 1

    Encoding Schemes: URL encoding (%3cscript%3e), HTML entities (&lt;script&gt;), Unicode encoding.

  • 2

    JavaScript Obfuscation: Using functions like eval(String.fromCharCode(...)) to construct payloads at runtime.

  • 3

    Keyword Breaking: Inserting comments or non-standard characters to break up keywords, e.g., <scr<script>ipt>.

  • 4

    Alternative HTML Tags: Using tags like <img onerror=>, <svg onload=>, or <details ontoggle=> that support event handlers.

Pro Tip

Test WAFs with a variety of payloads and encoding methods. Often, a combination of techniques is needed to achieve successful bypass.
