Injecting Malicious Scripts via URL Fragments

Try navigating to #<img src=x onerror=alert(1)>
Key Takeaway

Always sanitize user-controlled input before using it to modify the DOM, especially with properties like innerHTML, to prevent DOM XSS.

The Vulnerability Flow

  • 1

    User visits crafted URL: https://example.com/page#<img src=x onerror=alert(1)>

  • 2

    Client-side script reads hash: window.location.hash.substring(1) extracts <img src=x onerror=alert(1)>.

  • 3

    Unsafe DOM modification: The extracted string is directly assigned to innerHTML without sanitization.

  • 4

    Payload execution: The browser parses the injected HTML, and the onerror event handler triggers, executing alert(1).

Pro Tip

Use DOMPurify or similar libraries to sanitize HTML before injecting it into the DOM, even if the source is believed to be client-side controlled.
