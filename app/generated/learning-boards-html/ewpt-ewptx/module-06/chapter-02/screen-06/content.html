Mutation XSS: Browser Parsing Quirks

Exploiting Browser HTML Re-parsing Behavior

What is Mutation XSS?

Mutation XSS exploits the way browsers parse and re-parse HTML. An attacker injects seemingly harmless HTML that, when processed by the browser's rendering engine in a specific context (e.g., when its innerHTML is accessed or moved), is 'mutated' into a malicious, executable script.

Key Takeaway

Mutation XSS highlights the need for context-aware sanitization, as simple string-based filters can be bypassed by browser re-parsing.

Why it matters

This technique can bypass security filters that only check initial input, making it a potent threat against applications with dynamic DOM manipulation.

Mutation XSS Example

<noscript><p title="</noscript><img src=x onerror=alert(1)>">

Initially, this might appear as a benign <noscript> tag. However, if the browser re-parses its content, it could interpret the </noscript> as closing the tag, and the subsequent <img> tag as executable HTML.

Common Misconception

Assuming that once input is filtered, it remains safe. Browser parsing engines can re-interpret content, leading to unexpected execution.
