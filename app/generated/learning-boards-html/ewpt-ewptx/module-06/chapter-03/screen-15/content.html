Key Concepts

Essential Terms from WAF Evasion Techniques

Web Application Firewall (WAF)

A security solution that filters, monitors, and blocks malicious HTTP traffic to and from a web application.

Encoding & Obfuscation

Techniques used to hide malicious payloads from WAFs by transforming characters into different representations.

HTTP Parameter Pollution (HPP)

An attack exploiting how web servers and applications handle multiple parameters with the same name.

Summary Takeaway

Understanding WAFs, encoding, and HPP forms the foundation for effective web application security testing and bypass strategies.
