Encoding and Obfuscation

Hiding malicious payloads from WAF signatures.

The Disguise
Original Malicious Payload

<script>alert(1)</script>

Encoded/Obfuscated Payload

%3Cscript%3Ealert(1)%3C/script%3E

WAF Inspection

Limited decoding capabilities

Bypass Success

Payload reaches application

Definition

Techniques to hide malicious payloads by transforming characters into different representations.

Purpose

To confuse WAFs that rely on signature-based detection, allowing payloads to bypass filters.

Common Types

URL encoding, HTML entities, Unicode escape sequences, SQL comments.

Key Takeaway

Encoding and obfuscation transform malicious strings into alternative representations, aiming to bypass WAF signature detection.
