Evasion Technique 3

HTTP Protocol-Level Evasions

Manipulating HTTP requests to bypass WAF logic.

HTTP Methods

Using non-standard HTTP methods (e.g., sending a payload in a GET request body) if the WAF only inspects POST bodies.

GET /path?id=1 HTTP/1.1 <script>alert(1)</script>

HTTP Headers

Manipulating headers like X-Forwarded-For to spoof IP addresses or sending unexpected Content-Type headers.

X-Forwarded-For: 127.0.0.1

Protocol Quirks

Exploiting specific behaviors or vulnerabilities in HTTP/2 or other protocol versions that WAFs might not fully parse.

HTTP/2 pseudo-headers manipulation

Example Scenario

A WAF expects SQLi in POST data. Attacker sends GET /search?q=1 with UNION SELECT in the GET request body, bypassing WAF if server processes it.

Key Takeaway

Exploiting HTTP protocol nuances, such as non-standard methods or header manipulation, can trick WAFs into overlooking malicious traffic.
