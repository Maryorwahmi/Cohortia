Core Concept

Time-Based Blind SQL Injection

Inferring data when no direct output is available.

How it Works

  • •Inject a conditional query that evaluates to true or false.
  • •If true, a time-delay function (e.g., SLEEP()) is executed.
  • •Observe the server's response time to infer the truthiness of the condition.
  • •Systematically test characters and positions to reconstruct data.
Key Takeaway

Time-based blind SQLi is a last resort for data exfiltration when no other output channel exists, relying on precise timing observations.

Example: Inferring MySQL Version

Original Query:
SELECT * FROM products WHERE id = [USER_INPUT]

Injected Payload:
1 AND IF(SUBSTRING(VERSION(), 1, 1) = '5', SLEEP(5), 0)

Explanation:
- If the first character of the MySQL version is '5', the server will pause for 5 seconds.
- If not, the response will be immediate.
- This allows an attacker to deduce the version character by character.
Pro Tip

Automate time-based blind SQLi with tools like SQLMap for efficiency, but always understand the manual process for verification and custom bypasses.

Common Mistake

Failing to establish a baseline response time can lead to misinterpreting network latency or server load as a successful time-based delay.
