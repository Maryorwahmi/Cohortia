Out-of-Band (OOB) SQL Injection

Exfiltrating data via external network requests.

Why OOB SQLi?

  • •Direct data exfiltration via web response is blocked or impossible.
  • •Provides a covert channel for data retrieval.
  • •Confirms SQLi vulnerability even without visible output.
Key Takeaway

OOB SQLi is essential when traditional data retrieval methods fail, leveraging the database server's ability to make external network calls.

OOB Channels & Mechanisms

DNS Lookups

Database attempts to resolve an attacker-controlled domain, visible in DNS logs.

HTTP Requests

Database makes an HTTP request to an attacker's web server, capturing headers/data.

Common Mistake

Assuming OOB is always available. It often depends on specific database configurations and network egress policies, which might block outbound connections.
