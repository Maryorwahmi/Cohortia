OS Command Execution: MSSQL xp_cmdshell

Running operating system commands on Microsoft SQL Server.

What is xp_cmdshell?

  • •An extended stored procedure in Microsoft SQL Server.
  • •Allows execution of operating system commands directly from SQL queries.
  • •Often disabled by default due to its high security risk.
Key Takeaway

xp_cmdshell is a critical vulnerability point in MSSQL, enabling direct OS command execution if misconfigured or exploited.

Payload Example: whoami

Injected Payload:
'; EXEC xp_cmdshell 'whoami';--

Explanation:
- Executes the 'whoami' command on the underlying OS.
- Reveals the user context of the SQL Server process.
- Output is typically returned in the SQLi response.
Enabling xp_cmdshell

Attackers may attempt to enable xp_cmdshell if they gain sufficient privileges, often via configuration changes.

Permission & Configuration

Requires the database user to have sysadmin role or equivalent, and the feature must be enabled via sp_configure.
