Exploitation Path

File System Interaction: Reading Files

Accessing server files directly through SQL Injection.

Why Read Files?

  • •Retrieve sensitive configuration files (e.g., database credentials).
  • •Access application source code for further vulnerability discovery.
  • •Exfiltrate system files like /etc/passwd or Windows SAM files.
Key Takeaway

Reading server files via SQLi provides critical system intelligence and can lead to deeper compromise.

DBMS-Specific Functions

MySQL: LOAD_FILE()
SELECT LOAD_FILE('/etc/passwd')

Reads the content of a specified file path.

PostgreSQL: pg_read_file()
SELECT pg_read_file('/etc/shadow', 0, 100)

Reads a portion of a file from the database server.

Permission Check

These functions require the database user to have appropriate file system read permissions. Always enumerate privileges first.
