File System Interaction: Writing Files

Uploading web shells and configuration files via SQLi.

Why Write Files?

  • •Upload web shells for remote code execution.
  • •Modify existing configuration files to alter application behavior.
  • •Establish persistence on the compromised server.
Key Takeaway

Writing files via SQLi is a critical step for gaining remote code execution and maintaining access to a compromised system.

MySQL: INTO OUTFILE / INTO DUMPFILE

Web Shell Payload:
SELECT '<?php system($_GET["cmd"]); ?>'
INTO OUTFILE '/var/www/html/shell.php'

Explanation:
- Writes a simple PHP web shell to the specified path.
- Allows remote command execution via HTTP GET parameter 'cmd'.
Post-Exploitation

After uploading a web shell, you can access it via a web browser to execute OS commands on the server.

Critical Considerations

Requires write permissions to the target directory and `secure_file_priv` must not restrict file writes. Always check these first.
