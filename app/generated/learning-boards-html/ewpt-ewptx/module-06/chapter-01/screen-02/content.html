Learning Objectives: Part 1

Skills you'll gain to master advanced SQL Injection.

LearnUnderstandApplyMaster
01

Identify Advanced SQLi Types

Understand and identify different types of advanced SQL Injection, including time-based blind SQLi and out-of-band (OOB) SQLi. This skill is vital for recognizing complex vulnerabilities in modern web applications.

VERIFIED COMPETENCY MILESTONE
02

Exploit File System Access

Learn techniques for exploiting SQL Injection vulnerabilities to read and write files on the database server. This enables data exfiltration and potential web shell uploads, critical for gaining deeper access.

VERIFIED COMPETENCY MILESTONE
