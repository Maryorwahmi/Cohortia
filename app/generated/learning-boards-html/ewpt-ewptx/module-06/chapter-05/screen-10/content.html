CVSS Breakdown

CVSS Metrics in Detail

Understanding the components that contribute to a vulnerability score

Attack Vector (AV)

How the vulnerability is exploitable (Network, Adjacent, Local, Physical).

Attack Complexity (AC)

Conditions beyond attacker's control (Low, High).

Privileges Required (PR)

Level of privileges needed by attacker (None, Low, High).

User Interaction (UI)

Whether user interaction is required (None, Required).

Scope (S)

Whether the vulnerability can impact resources beyond its security scope (Unchanged, Changed).

Confidentiality (C)

Impact on data confidentiality (None, Low, High).

Integrity (I)

Impact on data integrity (None, Low, High).

Availability (A)

Impact on system availability (None, Low, High).

Key Takeaway

Each CVSS metric provides a granular detail about a vulnerability, contributing to a comprehensive and objective risk score.
