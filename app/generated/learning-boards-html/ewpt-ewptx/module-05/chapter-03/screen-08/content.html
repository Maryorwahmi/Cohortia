Crafting a Malicious PHP Payload

Modify serialized data to achieve privilege escalation by altering object properties.

Intercept & Decode

Capture the serialized cookie data (e.g., Base64 encoded) and decode it to reveal the object structure.

Modify Object Properties

Alter critical properties like isAdmin from false to true within the serialized string.

Re-encode & Inject

Base64 encode the malicious payload and inject it back into the application's cookie.

PHP Payload Modification
// Original serialized UserProfile("Guest")
O:11:"UserProfile":2:{s:8:"username";s:5:"Guest";s:7:"isAdmin";b:0;}

// Base64 encoded (example)
T:11:"UserProfile":2:{s:8:"username";s:5:"Guest";s:7:"isAdmin";b:0;}

// Attacker modifies isAdmin to true
O:11:"UserProfile":2:{s:8:"username";s:5:"Admin";s:7:"isAdmin";b:1;}

// Base64 encoded malicious payload (example)
T:11:"UserProfile":2:{s:8:"username";s:5:"Admin";s:7:"isAdmin";b:1;}
Impact

When deserialized, the __destruct method is called with isAdmin set to true, leading to privilege escalation.

Key Takeaway

By modifying specific properties within serialized data, attackers can trick the application into executing privileged actions, demonstrating a clear path to privilege escalation.
