Exploiting Local File Inclusion

LFI allows attackers to read or execute files on the target server's filesystem. This is commonly achieved through path traversal, navigating outside the intended directory.

Common LFI Targets

  • •Sensitive configuration files (e.g., /etc/passwd, /etc/apache2/apache2.conf)
  • •Application source code (revealing logic or credentials)
  • •Log files (e.g., access.log, error.log) for log poisoning
  • •Session files (e.g., /var/lib/php/sessions/) for session poisoning

Path Traversal

Using sequences like ../ to move up directory levels and access files outside the intended web root. This is the primary mechanism for LFI.

Key Takeaway

LFI allows access to local files, often via path traversal, to disclose sensitive information or set the stage for further exploitation.

Vulnerable Code Example (PHP)

<?php
// view.php
if (isset($_GET['page'])) {
    $file = $_GET['page'] . '.php';
    // DANGER: No proper sanitization
    include($file);
} else {
    echo "Welcome!";
}
?>

LFI Path Traversal Attack

Attacker Input: ?page=../../../../etc/passwd
Application attempts to include /etc/passwd.php
Result: /etc/passwd contents displayed
