Key Concepts

More essential terms to remember from this chapter.

Null Byte (%00)

A character used in LFI payloads to truncate a string, bypassing appended file extensions in older PHP versions.

Log Poisoning

An LFI exploitation technique where malicious code is injected into a server log file and then included via LFI to achieve RCE.

allow_url_include

A PHP configuration directive that, when enabled, allows include() and require() to load files from remote URLs, enabling RFI.

php://filter

A PHP stream wrapper used in LFI to read local files in various encodings (e.g., base64) to bypass filters.

Key Takeaway

These concepts provide a deeper understanding of both the exploitation methods and the underlying mechanisms that enable file inclusion attacks.
