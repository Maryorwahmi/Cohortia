Key Concepts

Essential terms to remember from this chapter.

Local File Inclusion (LFI)

A vulnerability allowing an attacker to include and potentially execute files from the local server's filesystem.

Remote File Inclusion (RFI)

A vulnerability allowing an attacker to include and execute files from a remote, attacker-controlled server on the target.

Path Traversal

A technique used in LFI to navigate the filesystem using sequences like ../ to access directories outside the intended web root.

Key Takeaway

LFI, RFI, and Path Traversal are fundamental concepts for understanding how attackers manipulate file inclusion vulnerabilities to access or execute unintended files.
