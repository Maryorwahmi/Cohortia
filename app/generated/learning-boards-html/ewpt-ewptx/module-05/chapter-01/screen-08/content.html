Bypassing Basic SSRF Filters: IP Obfuscation

Circumventing Blacklists with Alternative IP Representations

Blacklist Limitations

Filters often block literal IP addresses (e.g., 127.0.0.1) but miss alternative representations.

Alternative Loopback IPs

Try 0.0.0.0 (resolves to localhost) or [::] (IPv6 loopback) if 127.0.0.1 is blocked.

IP Encoding Schemes

Use decimal (2130706433), octal (0177.0.0.1), or hexadecimal (0x7f000001) representations for 127.0.0.1.

Key Takeaway

Effective SSRF filter bypass relies on understanding how different systems parse and resolve IP addresses, exploiting inconsistencies to circumvent literal blacklists.

Common Mistake: Simple Blacklists

Relying solely on blacklisting literal IP addresses is a common mistake, as attackers can easily bypass these filters using various encoding and alternative representations.
