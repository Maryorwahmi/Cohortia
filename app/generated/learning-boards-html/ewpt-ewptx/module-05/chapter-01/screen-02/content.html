01

Understand Core SSRF Concepts

Grasp the fundamental nature of Server-Side Request Forgery and its distinction from client-side attacks. Learn how a server's network context is exploited and the broad range of potential impacts, from data exposure to remote code execution.

VERIFIED COMPETENCY MILESTONE
02

Identify SSRF Vulnerabilities

Recognize common patterns and indicators of SSRF in web applications, such as URL-accepting parameters and less obvious data inputs. Learn initial testing methodologies using local file access and internal IP addresses to confirm vulnerability presence.

VERIFIED COMPETENCY MILESTONE
03

Exploit Internal Resources

Learn various techniques to exploit SSRF, including accessing internal network resources, sensitive cloud metadata services, and bypassing network controls. Understand how different URL schemes can be leveraged for diverse attack vectors.

VERIFIED COMPETENCY MILESTONE
04

Bypass SSRF Filters

Develop advanced strategies for circumventing common SSRF filters and protections. Explore techniques like IP encoding, DNS rebinding, URL parsing inconsistencies, and the use of URL shorteners or redirects to bypass blacklists.

VERIFIED COMPETENCY MILESTONE
