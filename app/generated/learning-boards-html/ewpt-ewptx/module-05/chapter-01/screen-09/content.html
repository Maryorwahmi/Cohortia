Advanced Filter Bypass: DNS & Redirects

Tricking Servers with DNS Rebinding and URL Parsing Inconsistencies

DNS Rebinding

A DNS entry changes from a legitimate external IP to an internal IP after the initial DNS lookup, bypassing filters.

URL Parsing Inconsistencies

Exploiting differences in how various parsers interpret URLs (e.g., http://example.com@127.0.0.1).

URL Shorteners & Redirects

Using a URL that redirects to an internal IP, which the server might follow without re-validation.

Key Takeaway

Advanced SSRF bypasses exploit dynamic network behaviors and parsing logic, requiring defenders to consider the full lifecycle of a URL request.

DNS Rebinding Attack Flow

1. Attacker provides malicious.com

2. Server resolves malicious.com to external IP

3. Filter allows request (external IP)

4. DNS record changes to internal IP

5. Server makes actual request (internal IP)

6. Access to internal resource granted

Pro-Tip: URL Parsing Inconsistencies

Experiment with different URL formats like http://user:pass@host:port/path or http://host#@internal-ip to see if the filter and the underlying request library parse them differently.
