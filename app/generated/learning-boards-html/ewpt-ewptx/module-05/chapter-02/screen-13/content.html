Essential XXE Terminology

Understanding the Building Blocks of XML Security

XML (Extensible Markup Language)

A markup language defining rules for encoding documents in a format that is both human-readable and machine-readable.

DTD (Document Type Definition)

A set of markup declarations that define the document type for an XML document, including its structure, elements, and attributes.

External Entity

A construct within an XML DTD that refers to content located outside the XML document itself, often a file path or a URL.

Summary Takeaway

XML, DTDs, and external entities are foundational concepts; understanding their interplay is key to comprehending XXE vulnerabilities.
