Document Type Definitions and External Entities

The Document Type Definition (DTD) defines the structure and legal building blocks of an XML document. Within a DTD, external entities can be declared to load content from external sources, which is a key component of XXE attacks.

DTD Purpose

A DTD acts as a blueprint, specifying the valid elements, attributes, and structure for an XML document, ensuring consistency and validation.

Entity Declaration

Entities are declared within the DTD using <!ENTITY>, allowing them to represent a piece of data or reference an external resource.

Key Takeaway

The DTD's ability to declare external entities, especially with the SYSTEM keyword, is the foundational mechanism exploited in XXE attacks.

DTD Entity Declaration
<?xml version="1.0"?>
<!DOCTYPE foo [
  <!-- Declares an external entity 'xxe' -->
  <!ENTITY xxe SYSTEM "file:///etc/passwd">
]>
<data>&xxe;</data>

<!-- Explanation: -->
<!-- 1. <!DOCTYPE foo [...]> defines the Document Type Definition. -->
<!-- 2. <!ENTITY xxe SYSTEM "file:///etc/passwd"> declares 'xxe' -->
<!--    as an external entity, pointing to a local file. -->
<!-- 3. &xxe; in the <data> element references this entity. -->
<!-- 4. If the parser is vulnerable, it will substitute &xxe; -->
<!--    with the content of /etc/passwd. -->
