Core Concept

What is XXE Injection?

XXE injection is a vulnerability where an XML parser processes XML input containing a reference to an external entity, and the parser is configured to resolve these entities, leading to various attacks.

What is XML?

Extensible Markup Language (XML) is a markup language for encoding documents in a format that is both human-readable and machine-readable, widely used for data storage and transport.

What is an External Entity?

An external entity is a variable within an XML document whose value is loaded from an external source, such as a local file path or a URL, allowing for dynamic content inclusion.

Key Takeaway

XXE injection leverages the XML parser's ability to process external entities, turning a data format into a potential attack vector for unauthorized resource access.
