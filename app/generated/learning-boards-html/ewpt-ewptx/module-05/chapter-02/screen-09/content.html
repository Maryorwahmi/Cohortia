Exfiltrating Data with Out-of-Band (OOB) XXE

Out-of-band (OOB) XXE attacks are employed when the application does not return the content of the external entity directly in its response. This technique involves using an attacker-controlled server to receive exfiltrated data.

Why OOB?

OOB XXE is necessary when the application's response does not directly display the content of external entities, or when direct in-band display is sanitized or blocked.

Key Components

It involves an attacker-controlled HTTP server to host a malicious DTD and receive exfiltrated data, and a crafted XML payload referencing this DTD.

Key Takeaway

OOB XXE enables data exfiltration even when direct in-band display is prevented, by leveraging an attacker-controlled server to receive the sensitive information.

Process Flow

Out-of-Band XXE Data Flow

Attacker Sends XML (Ref. OOB DTD)
Vulnerable Server Fetches DTD
DTD Instructs Server to Read File
Server Sends Data to Attacker
