Server-Side Enforcement of Access Control

The only reliable defense against BAC.

The Golden Rule

Never trust the client. All authorization checks must be performed on the server, as client-side controls are easily bypassed.

What to Enforce

  • Validate permissions on every request.
  • Check authorization for specific actions on specific resources.
  • Implement robust Role-Based (RBAC) or Attribute-Based (ABAC) Access Control.
Key Takeaway

Server-side enforcement is the cornerstone of secure application design against BAC vulnerabilities.

Common Mistakes

  • Relying solely on client-side checks (e.g., JavaScript).
  • Failing to validate user permissions on every request.
  • Using predictable or easily guessable object IDs.
  • Exposing internal object references directly.
Pro-Tip

Implement a 'deny by default' policy: explicitly grant permissions rather than implicitly allowing them.
