Horizontal Privilege Escalation

Accessing peer-level data or functionality.

Definition

Occurs when a user gains access to functionality or data intended for a peer user (i.e., another user with the same level of privilege).

Impact

  • Privacy breaches and data theft.
  • Unauthorized access to sensitive personal or organizational data.
  • Competitive intelligence theft or fraud.
Key Takeaway

Horizontal escalation is about moving 'across' to another user's resources at the same privilege level.
