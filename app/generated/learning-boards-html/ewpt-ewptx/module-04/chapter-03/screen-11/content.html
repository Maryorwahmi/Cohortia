Parameter Tampering

Modifying request parameters to bypass logic.

Definition

An attacker modifies parameters in an HTTP request (URL query strings, form fields, HTTP headers, cookies) to bypass authorization checks or manipulate application logic.

Example: Price Manipulation

An e-commerce site sends price=100 in a request. An attacker changes it to price=10, and the server accepts the lower price without re-validation.

Key Takeaway

All sensitive parameters must be validated and authorized on the server, not just object IDs.

Broader Scope than IDORs

While IDORs focus on object references, parameter tampering can affect any application logic tied to client-supplied parameters.

Example: Role Modification

A parameter like isAdmin=false in a request could be changed to isAdmin=true to attempt unauthorized privilege escalation.
