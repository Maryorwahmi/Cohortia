Vertical Privilege Escalation

Gaining access to higher-privileged roles or data.

Definition

Occurs when a user gains access to functionality or data intended for a higher-privileged role (e.g., a regular user accessing an administrator's dashboard).

Impact

  • Full system compromise.
  • Data breaches and unauthorized modifications.
  • Bypassing critical security controls.
Key Takeaway

Vertical escalation is about moving 'up' the privilege ladder to gain more power than intended.

Escalation Path

Regular User
Admin Dashboard (Unauthorized)
