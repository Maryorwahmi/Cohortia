Path Traversal in URLs

Accessing Restricted Admin Paths

The Vulnerable Flow

Initial Check: Server sees /admin/ in /admin/../user/profile and allows it.

Path Normalization: /admin/../user/profile resolves to /user/profile.

Unauthorized Access: Attacker gains access to /user/profile without proper admin checks.

Example: Admin Panel Bypass

https://example.com/admin/../user/profile

If the server checks for /admin/ at the beginning of the path, it might allow this request. However, after normalization, the path becomes /user/profile, which might have weaker or no authorization checks, granting unauthorized access to a regular user.

This vulnerability exploits the order of operations: authorization check before full path resolution.

Key Takeaway

Always normalize URL paths to their canonical form at the earliest possible stage of request processing, before any authorization decisions.
