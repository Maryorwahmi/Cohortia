Path Traversal for Authorization

Bypassing Access Checks with Directory Navigation

How It Leads to Bypass

Path-Based Controls: Applications use URL path segments (e.g., /admin/) for access control decisions.

../ Sequences: Attackers insert directory traversal sequences (../ or URL-encoded equivalents) into the URL.

Post-Normalization Bypass: Server normalizes the path *after* initial checks, granting access to restricted resources.

Common Misconception

Many developers assume that URL normalization happens before any access control checks, but often it occurs later in the request processing pipeline, creating a window for bypass.

Impact

Unauthorized access to sensitive administrative panels, private user data, or internal application resources that should be restricted based on URL path.

Key Takeaway

Always ensure URL paths are fully normalized and canonicalized *before* any authorization checks are performed.
