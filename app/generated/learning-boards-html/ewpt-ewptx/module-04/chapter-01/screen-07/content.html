Brute-Force & Dictionary Attacks

Systematic approaches to guessing credentials

Dictionary Attack

  • •Uses a pre-defined list of common credentials.
  • •Effective against weak, common passwords.
  • •Faster than brute-force if passwords are in the list.
Example

Trying 'admin', 'password', '123456' from a wordlist.

Brute-Force Attack

  • •Systematically tries every possible character combination.
  • •Guaranteed to find the password eventually.
  • •Can be very time-consuming for complex passwords.
Example

Trying 'a', 'aa', 'aaa', 'aab', 'aac' and so on.

Key Takeaway

Both dictionary and brute-force attacks exploit weak password practices; strong passwords and countermeasures are essential to defeat them.
