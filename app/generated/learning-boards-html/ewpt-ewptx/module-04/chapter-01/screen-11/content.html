Burp Suite Intruder (Attack & Analysis)

Launching and interpreting automated brute-force attacks

Intruder Steps

  1. 1.Go to the "Intruder" tab in Burp Suite.
  2. 2.In "Positions", clear all pre-selected payload positions.
  3. 3.Manually select the password parameter's value and click "Add §" to mark it.
  4. 4.Go to "Payloads", set "Payload type" to "Simple list", and add your password list.
  5. 5.In "Options" under "Grep - Match", add strings for successful (e.g., "Welcome") and failed (e.g., "Invalid username") logins.
  6. 6.Click "Start attack" and observe the results for differences in length or status code.
Identifying Success

Look for a request with a significantly different response length (e.g., a shorter redirect for success) or a different HTTP status code (e.g., 302 Found vs 200 OK).

Key Takeaway
