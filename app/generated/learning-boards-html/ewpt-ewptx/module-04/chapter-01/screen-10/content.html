Brute-Forcing with Burp Suite Intruder (Setup)

Configuring Burp Suite for automated login attacks

Setup Steps

  1. 1.Start Burp Suite and configure your browser to use it as a proxy (e.g., 127.0.0.1:8080).
  2. 2.Access a vulnerable login form (e.g., login.php) in your proxied browser.
  3. 3.Attempt to log in with *any* credentials (e.g., testuser/wrongpass).
  4. 4.Intercept the POST request in Burp Suite's Proxy tab.
  5. 5.Right-click the intercepted request and select "Send to Intruder".

Key Takeaway

Properly configuring Burp Suite as a proxy and intercepting the target request is the foundational step for any automated attack using Intruder.
