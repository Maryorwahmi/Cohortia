Key Concepts

Essential terms to remember

Authentication

The process of verifying a user's identity, confirming they are who they claim to be.

Authorization

The process of determining what an authenticated user is permitted to do or access.

Session ID

A unique identifier used by web applications to maintain state for an authenticated user across multiple requests.

Summary Takeaway

Authentication confirms identity, authorization grants permissions, and session IDs maintain user state, forming the pillars of secure web access.
