Intercepting Session Cookies

Using Burp Suite for Analysis and Observation

Capture Traffic

Use Burp Suite's Proxy to intercept all HTTP/S requests and responses between your browser and the web application.

Analyze `Set-Cookie`

Locate the server's response that sets the session cookie and examine its value and attributes (e.g., `HttpOnly`, `Secure`).

Key Takeaway

Burp Suite's Proxy allows observation of session cookies and their attributes during web traffic, providing crucial insights into an application's session management implementation.

# Burp Suite HTTP History - Server Response
HTTP/1.1 200 OK
Content-Type: text/html; charset=UTF-8
Set-Cookie: PHPSESSID=abcdef123456; path=/; HttpOnly; Secure
X-Frame-Options: DENY
...

# Key Observations:
- Session ID: abcdef123456
- Attributes: HttpOnly and Secure are present.
- Path: /
- No SameSite attribute (potential vulnerability).
