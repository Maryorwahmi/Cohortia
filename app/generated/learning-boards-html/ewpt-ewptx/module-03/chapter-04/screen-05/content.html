Process Flow: Victim Authentication
1. Victim Logs In

Accesses legitimate web app (e.g., bank.com)

2. Session Cookie Issued

Browser stores cookie for automatic sending

Role of Session Cookies

Session cookies are small data packets issued by the server upon successful login. They are automatically attached by the browser to all subsequent requests to the same domain, maintaining the user's authenticated state.

Common Misconception

Some believe that simply being logged in is enough. However, the critical factor is the *automatic inclusion* of the session cookie by the browser, which makes the forged request appear legitimate.

Key Takeaway

An active, authenticated session with the target application, maintained by session cookies, is a prerequisite for a CSRF attack.
