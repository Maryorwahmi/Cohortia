Definition

What is CSRF?

Cross-Site Request Forgery (CSRF) is an attack that forces an end-user to execute unwanted actions on a web application in which they're currently authenticated.

  • Exploits trust between a user's browser and a trusted website.
  • Attacker tricks the user into sending a malicious request.
  • Browser automatically includes session cookies, making the request appear legitimate.
  • Results in unauthorized actions like changing passwords, transferring funds, or making purchases.
Concrete Example

The Banking Scenario

You're logged into bank.com. An attacker sends you a link to attacker.com. When you visit attacker.com, a hidden request is sent to bank.com to transfer money. Your browser automatically includes your bank.com session cookies, and the bank processes the transfer, believing it's from you.

Key Takeaway

CSRF leverages a user's active session to trick their browser into performing unauthorized actions on a trusted web application.
