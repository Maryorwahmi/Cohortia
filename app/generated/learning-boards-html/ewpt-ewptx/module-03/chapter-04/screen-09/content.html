Definition

What are CSRF Tokens?

A CSRF token is a unique, unpredictable, secret value generated by the server for each user session or sensitive form. It's used to verify that a request originated from the legitimate user.

  • **Uniqueness:** Each token is distinct, preventing replay attacks.
  • **Unpredictability:** Cryptographically secure random values make guessing impossible.
  • **Secrecy:** Stored server-side in the user's session, inaccessible to attackers.
  • **Validation:** Server compares submitted token with stored token; mismatch means rejection.
Why it's Effective

Bypassing Same-Origin Policy

Attackers cannot read the victim's session data or dynamically generated tokens from the legitimate site due to the Same-Origin Policy. This prevents them from including a valid token in their forged requests.

Key Takeaway

CSRF tokens are unique, secret values that the server generates and validates to ensure that requests originate from legitimate user interactions, effectively blocking forged requests.
