Filter Bypass Techniques

Null Bytes, Newlines & Non-Standard Tags

Exploiting parser inconsistencies and legacy features to bypass filters.

Null Bytes (`%00`)

Inserting null bytes can break up a malicious string, causing filters to miss patterns while the browser still executes the code.

<scr%00ipt>alert(1)</scr%00ipt>

Newlines (`%0a`) & Comments

Similar to null bytes, newlines or HTML comments can disrupt single-line pattern matching in filters.

<script%0a>alert(1)</script>
<!--<script>-->alert(1)<!--</script>-->

Non-Standard Tags/Attributes

Some older browsers or rendering engines might interpret unusual tags or attributes in ways that lead to XSS.

<marquee onstart=alert(1)>

Pro Tip

Always test XSS payloads across different browsers and versions, as parsing behaviors can vary significantly.

Key Takeaway

Robust XSS defense requires anticipating how browsers interpret malformed or non-standard input.
