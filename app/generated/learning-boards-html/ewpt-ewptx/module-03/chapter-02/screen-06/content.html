Filter Bypass Techniques

Case Sensitivity & Encoding

Simple yet effective ways to evade basic XSS filters by altering input format.

Case Sensitivity

Filters often look for specific lowercase patterns. Changing the case of tags or attributes can bypass them.

<sCrIpT>alert(1)</sCrIpT>

HTML Entities

Encoding characters as HTML entities can hide them from filters that don't decode input.

&lt;script&gt;alert(1)&lt;/script&gt;

URL Encoding

Using URL encoding for characters can bypass filters that don't URL-decode input before checking.

%3Cscript%3Ealert(1)%3C/script%3E

JavaScript String Encoding

JavaScript itself can decode strings, allowing payloads to be hidden from filters.

eval('\x3cscript\x3ealert(1)\x3c/script\x3e')
Key Takeaway

Filters must normalize input (decode, lowercase) before applying blacklist rules to be effective.
