Filter Bypass Techniques

Obfuscation & Event Handlers

Hiding malicious code and leveraging legitimate HTML features for execution.

Obfuscation

Making code difficult to read or analyze, often using JavaScript functions to dynamically construct and execute payloads.

eval(String.fromCharCode(100,111,99,117,109,101,110,116,46,99,111,111,107,105,101))

Base64 Encoding

Hiding payloads in Base64 and decoding them at runtime using atob() and eval().

eval(atob('YWxlcnQoMSk=')) // decodes to alert(1)

Event Handlers

Using legitimate HTML tags with event attributes that execute JavaScript when triggered.

<img src=x onerror=alert(1)>
<svg onload=alert(1)>
<a href="javascript:alert(1)">Click Me</a>

Common Mistake

Filters often miss event handlers because they are not explicitly looking for script tags, assuming other HTML is safe.

Key Takeaway

Comprehensive XSS defense requires understanding dynamic code execution and all possible event-driven injection points.
