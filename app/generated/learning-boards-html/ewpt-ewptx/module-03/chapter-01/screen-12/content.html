Module 3›Chapter 3.1›DOM-based XSS Code

The Vulnerability

Client-side JavaScript reads user input from location.hash and directly inserts it into the DOM using document.write() without sanitization, leading to script execution.

Example Payload

A URL like page.html#<script>alert('DOM XSS')</script> will cause the JavaScript to read and execute the script from the URL fragment.

Key Takeaway

Always sanitize user input before dynamically writing it to the DOM via JavaScript to prevent DOM-based XSS.

Vulnerable JavaScript: page.html
<!-- In page.html -->
<script>
    var user_input = location.hash.substring(1); // Reads from #fragment
    document.write("Hello, " + user_input);
</script>

Line 4: user_input directly inserted into the DOM via document.write().
