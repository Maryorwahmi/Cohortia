What is XSS?

Cross-Site Scripting (XSS) is a web security vulnerability that allows attackers to inject malicious client-side scripts (e.g., JavaScript) into web pages viewed by other users. These scripts execute in the victim's browser, under the context of the trusted, vulnerable website.

The 'Cross-Site' Aspect

The malicious script originates from an attacker's site or input but executes on a *different*, trusted site. This bypasses the browser's Same-Origin Policy, making the script appear legitimate.

Key Takeaway

XSS is about tricking a trusted website into serving malicious code, which then runs with the full privileges of that site in the victim's browser.
