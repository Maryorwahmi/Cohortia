Module 3›Chapter 3.1›Reflected XSS Code

The Vulnerability

The PHP script directly echoes the $_GET['query'] parameter into the HTML output without any sanitization or encoding. This allows an attacker to inject arbitrary HTML or JavaScript.

Example Payload

If the URL contains ?query=<script>alert('XSS')</script>, the <script> tag will be rendered directly in the HTML, causing the JavaScript to execute.

Key Takeaway

Always sanitize or encode user-supplied input before reflecting it in HTML to prevent Reflected XSS.

Vulnerable PHP Code: search.php
<?php
    $query = $_GET['query'];
    echo "<h1>Search Results for: " . $query . "</h1>";
    // ... rest of the page
?>

Line 3: $_GET['query'] directly inserted into HTML.
