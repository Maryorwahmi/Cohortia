Key Concepts

More essential terms to remember

DOM-based XSS

A client-side XSS vulnerability where JavaScript processes user input and dynamically writes it to the DOM without proper sanitization.

Same-Origin Policy (SOP)

A critical browser security mechanism restricting a web page from interacting with resources from a different origin (protocol, port, host).

Sanitization & Encoding

Processes of cleaning/filtering user input (sanitization) and converting special characters to a safe format (encoding) to prevent XSS.

Summary Takeaway

DOM-based XSS is client-side, SOP is the browser's defense, and proper sanitization/encoding are crucial for preventing XSS vulnerabilities.
