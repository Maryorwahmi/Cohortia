What is Stored XSS?

The malicious script is permanently stored on the target server (e.g., in a database, forum post, comment section). It is then delivered to any user who accesses the affected web page.

Why it's Dangerous

Unlike Reflected XSS, the attacker doesn't need to trick individual victims. The payload is served directly by the legitimate application to anyone who views the affected content, increasing its reach.

Key Takeaway

Stored XSS is persistent and highly impactful, as the malicious payload is served automatically to all users viewing the compromised content.

Stored XSS Process Flow

1. Attacker injects script into Web App
2. Web App stores script (e.g., in DB)
3. Victim views page, script executes
