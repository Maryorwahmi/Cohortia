What is SOP?

The Same-Origin Policy (SOP) is a critical browser security mechanism that restricts how a document or script loaded from one origin can interact with a resource from another origin.

How XSS Bypasses SOP

XSS doesn't directly violate SOP. Instead, it tricks the *trusted* website into serving the malicious script itself, making the script appear to originate from the trusted site, thus operating within SOP's boundaries.

Key Takeaway

SOP is the browser's defense against cross-origin attacks, but XSS circumvents it by making malicious code appear 'same-origin' to the browser.

Defining 'Same Origin'

Origin: https://www.example.com:443

Same Origin:

  • https://www.example.com:443/path
  • https://www.example.com:443/another

Different Origin:

  • http://www.example.com:80 (Protocol)
  • https://sub.example.com:443 (Host)
  • https://www.example.com:8080 (Port)

For two URLs to be 'same-origin', they must share the exact same protocol, host, and port.
