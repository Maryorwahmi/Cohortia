Three Primary Types of XSS Attacks

Differentiating Reflected, Stored, and DOM-based XSS.

Reflected XSS

Non-persistent. Malicious script is reflected off the web server directly to the victim's browser as part of the HTTP response, often via a crafted URL.

Stored XSS

Persistent. Malicious script is permanently stored on the target server (e.g., database) and delivered to any user who accesses the affected web page.

DOM-based XSS

Client-side. Vulnerability exists purely within client-side JavaScript that processes user input and dynamically writes it to the DOM without proper sanitization.

Key Takeaway

Each XSS type has a distinct injection and delivery mechanism, impacting its persistence and how it's exploited.
