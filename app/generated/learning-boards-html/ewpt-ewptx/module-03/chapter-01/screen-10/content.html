Module 3›Chapter 3.1›Stored XSS Code

The Vulnerability

The $comment_text from user input is directly inserted into the SQL query without sanitization. This allows malicious scripts to be stored in the database.

Persistence

Once stored, the malicious script is retrieved and executed by any user who views the affected content, making the attack persistent and widespread.

Key Takeaway

Always sanitize and validate user input on the server-side before storing it in a database to prevent Stored XSS.

Vulnerable PHP Code: save_comment.php
<?php
    if (isset($_POST['comment'])) {
        $comment_text = $_POST['comment'];
        $user_id = $_SESSION['user_id'];
        // Vulnerable: No sanitization before SQL insertion
        $sql = "INSERT INTO comments (user_id, comment_text) VALUES ('$user_id', '$comment_text')";
        mysqli_query($conn, $sql);
    }
?>

Line 6: $comment_text directly inserted into SQL query.
