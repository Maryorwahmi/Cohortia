Cookie Security

Secure Flag: Encrypted Cookie Transmission

The Secure flag ensures that a cookie is only sent over encrypted HTTPS connections, protecting it from eavesdropping during transmission.

  • •Prevents cookies from being sent over unencrypted HTTP.
  • •Protects against Man-in-the-Middle (MitM) attacks.
  • •Essential for maintaining confidentiality of session data.
Key Takeaway

Always use the Secure flag for cookies in production to ensure they are only transmitted over encrypted HTTPS, preventing network interception.

PHP Example: Secure Cookie
<?php
setcookie('user_pref', 'dark_mode', [
    'expires' => time() + (86400 * 30),
    'path' => '/',
    'domain' => '.example.com',
    'secure' => true,   // Only send over HTTPS
    'httponly' => true,
    'samesite' => 'Lax'
]);
?>
Risk without Secure Flag

Unencrypted Transmission

Without the Secure flag, a cookie could be sent over plain HTTP, allowing an attacker to easily capture it using network sniffers.
