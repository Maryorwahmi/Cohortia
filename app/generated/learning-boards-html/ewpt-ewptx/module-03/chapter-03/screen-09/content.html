Encoding Best Practice

Context-Aware Encoding: HTML Entities

For data inserted into HTML body, attributes, or text nodes, convert special characters to HTML entities.

  • •Converts < to &lt;, > to &gt;, & to &amp;, etc.
  • •Ensures browser renders characters as text, not HTML tags or attributes.
  • •Example: PHP's htmlspecialchars() function.
Key Takeaway

Always use HTML entity encoding for user-supplied data displayed within HTML contexts to prevent browser interpretation of malicious tags.

PHP Example: HTML Encoding
<?php
$user_input = "<script>alert('XSS')</script>";
// Encodes special HTML characters
$safe_output = htmlspecialchars($user_input, ENT_QUOTES, 'UTF-8');
echo "<p>You searched for: " . $safe_output . "</p>";
// Output: <p>You searched for: &lt;script&gt;alert('XSS')&lt;/script&gt;</p>
?>
Common Mistake

Incorrect Encoding Context

Using HTML encoding for data inserted into a JavaScript context can still lead to XSS, as JavaScript has its own special characters that need escaping.
