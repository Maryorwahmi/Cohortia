Encoding Best Practice

Context-Aware Encoding: JavaScript & URL

Apply specific encoding methods for data inserted into JavaScript contexts and URL parameters.

  • •JavaScript Encoding: Escape " and \ with backslashes (e.g., json_encode()).
  • •URL Encoding: Convert special characters to percent-encoded equivalents (e.g., urlencode()).
  • •Prevents breaking out of string literals or URL structures.
Key Takeaway

Always use context-specific encoding for JavaScript and URL contexts to prevent XSS, as generic HTML encoding is insufficient.

PHP Example: JS & URL Encoding
<?php
$user_data = "user's name";
$search_term = "hello world";

// JavaScript Encoding (safer with json_encode)
echo "<script>var name = " . json_encode($user_data) . ";</script>";
// Output: <script>var name = "user's name";</script>

// URL Encoding
echo "<a href=\"/search?q=" . urlencode($search_term) . "\">Search</a>";
// Output: <a href="/search?q=hello%20world">Search</a>
?>
Misconception

One-Size-Fits-All Encoding

Believing that a single encoding function will protect all contexts is a common and dangerous mistake. Each context has unique parsing rules.
