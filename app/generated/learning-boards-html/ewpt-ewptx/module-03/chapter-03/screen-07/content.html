Input Validation Strategy

Blacklisting: A Weaker Strategy

This approach attempts to block known bad input, such as <script> or javascript:, but is inherently weaker.

  • •Relies on blocking known malicious patterns.
  • •Prone to bypasses as attackers find new evasion techniques.
  • •A reactive approach, constantly playing catch-up with new threats.
Key Takeaway

Blacklisting is generally ineffective for XSS prevention due to its reactive nature and the ease with which attackers can bypass filters.

Concrete Example

Bypassing a Script Tag Filter

A filter blocks <script>. An attacker bypasses it with <img src=x onerror=alert('XSS')>, using an event handler instead of a script tag.

Why it Matters

The Whack-A-Mole Problem

Blacklisting creates an endless cycle of patching vulnerabilities as new bypasses are discovered, making it an unsustainable long-term security strategy.
