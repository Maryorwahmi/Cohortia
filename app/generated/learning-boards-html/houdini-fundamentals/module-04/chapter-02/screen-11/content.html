Typical connections
file_basecolor -> principled.basecolor (sRGB)
file_roughness -> principled.roughness (Linear)
file_metallic -> principled.metallic (Linear)
file_normal   -> principled.normal (Tangent Space)
file_height   -> principled.displacement (Linear)
file_ao       -> multiply with basecolor or use as mask
Always verify each map in isolation to ensure correct mapping and color space.
Common pitfalls
  • • Forgetting sRGB for Base Color causes color shifts.
  • • Leaving Roughness in sRGB makes highlights look wrong.
  • • Incorrect Normal map type flips lighting detail.
Key Takeaway
Correct color space settings are as important as correct map connections for realistic PBR materials.
