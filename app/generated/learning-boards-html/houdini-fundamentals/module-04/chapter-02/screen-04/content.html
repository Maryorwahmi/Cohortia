What is a layered material?

A layered material composes multiple full materials so each contributes separate PBR properties. Use it when a surface shows distinct physical materials across its area.

• Create two Principled Shaders: set Base Color, Metallic, Roughness per layer.
• Add a Material Blend node and connect Input 1 and Input 2.
• Provide a Mask: white = first material, black = second, grays = blend.
• Assign the blended result to geometry.
Example
Polished metal base + rusty matte rust layer blended with a noise mask to simulate corrosion.
Common mistake
Using a purely color mask instead of a mask that reflects material change; color alone may not match physical properties.
Material Blend example (node layout)
// Node pseudo-layout
principledshader_base_metal
principledshader_rust
materialblend
  Input1 -> principledshader_base_metal
  Input2 -> principledshader_rust
  Mask   -> procedural_noise_comp_output
assign materialblend to geo
Try creating a sharp mask to test inputs, then smooth values with a fit remap for gradual corrosion transitions.
Key Takeaway

Think of blends as physical mixes of full materials guided by masks, not just layered textures.
