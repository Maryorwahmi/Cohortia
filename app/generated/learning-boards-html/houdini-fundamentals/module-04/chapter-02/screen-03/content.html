Module 4 › Chapter 4.2 › Learning Objectives
Objective Checks
  • 1. Render the Material Blend and inspect mask edges; try white/black extremes to confirm inputs.
  • 2. Adjust Noise node type and frequency to change rust scale; use Fit node to remap contrast.
  • 3. Subdivide a grid or add Displace SOP before rendering to observe true geometry changes from displacement maps.
  • 4. Import PBR maps and verify sRGB only for Base Color; all other maps should be linear.
Pro-tip
Use low-frequency noise for large patches and higher frequency for fine grit; blend them for realism.
Common mistake
Forgetting to subdivide geometry before displacement leads to flat results despite a strong map.
Milestone
Render Verification

You can demonstrate a layered material using a procedural mask, show displacement affecting silhouette, and prove correct map color spaces on an imported asset.
