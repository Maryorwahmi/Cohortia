Typical node combination
// Example shader node flow
noise_low (Type: Fractal, Frequency: 6)
noise_high (Type: Fractal, Frequency: 36)
blend = mix(noise_low, noise_high * 0.6)
fit(blend, src_min=0.2, src_max=0.7, dst_min=0, dst_max=1)
-> roughness input
This creates large tonal areas from noise_low, adds fine grain from noise_high, then remaps the final value into a practical roughness range.
Use cases and guidance
  • Base Color variation: low-frequency noise with color ramps for natural stone or wood.
  • Roughness modulations: subtle, low-amplitude fractal noise to avoid flat specularity.
  • Masks: Worley for patches, curl for organic growth edges.
Pro-tip
Bake procedural controls into attributes or export maps when a downstream tool needs image inputs.
Misconception
Procedural is not always lighter: complex shader math can be expensive at render time; bake when needed.
