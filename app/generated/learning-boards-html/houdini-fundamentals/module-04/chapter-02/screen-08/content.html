Definition › Chapter 4.2 › Displacement Workflow
Prepare geometry
  1. 1) Subdivide mesh sufficiently (Subdivide SOP) or ensure renderer tessellation supports detail.
  2. 2) Connect a displacement map to the Principled Shader Displacement input.
  3. 3) Adjust scale and bias so mid-gray = no displacement.
  4. 4) Preview at render settings to assess silhouette changes and render cost.
Practical example
// Geometry and shader steps
geo1 -> subdivide (iterations: 2)
assign material -> principledshader
principledshader.displacement_map -> my_displacement.exr
render and compare subdivision levels
If displacement looks blocky, increase subdivision or bake a higher-resolution height map. Keep displacement values conservative for predictable results.
Key Takeaway

Displacement needs geometry; refine topology and remap values to avoid artifacts and excessive render cost.
