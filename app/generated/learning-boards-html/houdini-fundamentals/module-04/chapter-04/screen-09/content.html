Module 5 › Chapter 4.4 › AOVs (Render Passes)

What are AOVs?

Separate image planes containing specific per-pixel data. They enable compositing control without re-rendering.

P
Position — 3D coordinates per pixel for re-projection work.
N
Normals — useful for relighting and edge detection.
Z
Depth — distance from camera, helpful for depth-of-field and compositing passes.
diffuse_color
Base color or diffuse result used for color corrections without reflections.
How to add in Karma
In the Karma Render ROP, open the Images tab, click Add Extra Image Plane, and set Name and Type to match the pass you need. Repeat for each pass.
Practical Example
Add P, N, Z and diffuse_color, render to a single EXR, and verify channels in MPlay.
Common mistake
Using a viewer that only shows beauty; instead open the EXR in a multi-channel viewer to confirm AOVs.
