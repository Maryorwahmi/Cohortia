Output Picture

Include path, base name and frame padding. Use EXR for multi-channel capability and high dynamic range.

Example: C:/temp/my_first_karma_render.$F4.exr
Tip: Use consistent folder structure to keep frames organized across shots.
Misstep: Missing $F4 can overwrite a single file instead of writing a sequence.

Resolution & Frame Range

Resolution sets pixel width and height. Frame range defines start and end frames for sequences; test short ranges first.
