Process

Quick checklist for Karma

1. Create Karma ROP
Place in OUT context and open node parameters.
2. Output Picture
Include $F4 for padded frames and choose EXR format.
3. Images tab
Click Add Extra Image Plane and set Name/Type.
4. Verify
Open the EXR in MPlay and check channel dropdown.
Example planes
Plane 1: Name = P, Type = P
Plane 2: Name = N, Type = N
Plane 3: Name = Z, Type = Z
