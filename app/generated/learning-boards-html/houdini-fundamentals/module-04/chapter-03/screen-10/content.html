Process Flow
Light Linking workflow
  1. Open Windows > Light Linker.
  2. Select a light node you want to control.
  3. Choose target objects and mark include or exclude settings.
  4. Render to verify the light affects only the intended objects.
Example: exclude the key light from the floor grid so the subject keeps dramatic modeling while the floor remains softly lit by environment light.
Cards — Why link?
Artistic control: isolate highlights to subject without affecting background.
Optimization: avoid costly light calculations on objects that do not need the light.
Debugging: toggle links to see single-light contributions easily.
Try: disable a light for a single object and note the difference in a small render to learn each light's contribution.
