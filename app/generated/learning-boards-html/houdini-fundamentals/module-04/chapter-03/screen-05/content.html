Process Flow
Creating and placing lights
A step-by-step routine to add lights and tune parameters.
  1. Create a light in obj context using the menu or Tab menu.
  2. Open the parameter panel and choose type: Point, Spot, Area, or Environment.
  3. Position and orient the light; set size for area lights and cone angle for spots.
  4. Tune intensity/exposure and enable quadratic decay for realistic falloff.
  5. Render single-light isolations, then combine lights and refine balance.
Example: create an area light above a sphere, size it to soften shadows, set intensity to 1200, then add a low-intensity fill at 25% of key.
Check: can you produce a visible silhouette without overexposing highlights?
Practice Panel
Use this checklist every time you add a new light:
  • Does it serve a role (key, fill, rim, environment)?
  • Is decay set appropriately for scene scale?
  • Do shadows have the correct hardness for the intended material?
Pro Tip
Use isolation renders and the Render View's exposure controls to judge brightness rather than relying on viewport lighting alone.
