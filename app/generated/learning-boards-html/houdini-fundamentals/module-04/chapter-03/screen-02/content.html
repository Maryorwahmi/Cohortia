Learning Objectives
Learn the skills and checks you will use to verify lighting setups.
Bloom: Learn → Understand → Apply → Master
01
Identify & use light types
Recognize point, spot, area, and environment lights and choose the right one for highlights, focused beams, soft shadows, or global illumination.
Mnemonic: icons grouped by shape (dot, cone, surface, sphere)
VERIFIED COMPETENCY MILESTONE
02
Set up Environment Light with HDRI
Load an HDRI map, rotate for dominant light direction, and balance intensity to provide realistic reflections and ambient fill.
Mnemonic: sphere with a photo wrap
VERIFIED COMPETENCY MILESTONE
03
Control color, intensity, exposure, decay
Tune light parameters to shape brightness, falloff, and color so reflections and shadows match the scene scale.
Mnemonic: small dial icons
VERIFIED COMPETENCY MILESTONE
04
Implement basic light linking
Use the Light Linker to include or exclude lights per object, enabling artistic isolation and render optimizations.
Mnemonic: Venn showing light/object overlap
VERIFIED COMPETENCY MILESTONE
