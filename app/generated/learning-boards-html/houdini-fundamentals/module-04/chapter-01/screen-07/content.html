What are UVs?
2D coordinates mapped to each 3D vertex. They control how texture images project onto geometry.
Clean UV Checklist
  • Non-overlapping shells when unique texturing is needed
  • Consistent texel density across shells
  • Minimal stretching visible with checker maps
Inspection Tools
UV Quick Shade, UV Visualize, checker textures reveal stretching and overlap quickly.
Key Takeaway

Always validate UVs before applying detailed PBR textures; good UVs prevent most texture-related artifacts.

Quick Workflow
For a simple prop: create base UVs, run UV Unwrap, use UV Relax/Layout, preview with a checkerboard, then apply final textures.
Tool: UV Unwrap
Generates basic unwrapping suitable for boxes and organic shapes.
Tool: UV Quick Shade
Fast visual check using a checker texture to reveal stretching.
Mistake To Avoid
Applying high-resolution PBR maps to poorly scaled UVs wastes detail and can make textures look blurry or repeating.
