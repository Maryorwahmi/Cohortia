Definition › Chapter 4.1 › Normal Maps and Tangent Space
How Normal Maps Work
Normal maps encode per-pixel surface directions to modify lighting without additional geometry.
Tangent-Space Normals
Provide direction relative to the surface tangent so the map can be reused on different meshes.
Non-Color Data
Normal maps are linear data. Do not treat them as sRGB color textures.
Channel Conventions
Some tools invert the green channel; flipping it can correct inverted bump directions.
Example Scenario
Apply a brick normal map to a flat plane to create believable mortar shadows and brick ridges without extra geometry.
Result
Lighting responds to micro-detail: highlights and occlusion appear where bumps change the normal direction.
Troubleshooting
If detail appears inverted, check green-channel convention and set Normal Map Type to Tangent Space.
Key Takeaway

Normal maps give high visual fidelity for low geometry cost, but require correct interpretation and orientation.
