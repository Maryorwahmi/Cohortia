Module 4 › Chapter 4.1 › Learning Objectives — Practice
Practice Checks
Small, repeatable verification tasks that confirm competency.
Vocabulary Check
Explain material vs shader and provide a quick example of each so you can reason about their roles.
Principled Shader
Create and name a Principled Shader in MAT, then adjust Base Color and Roughness to see immediate changes.
Texture & UV Check
Apply a Base Color and Roughness map and use UV Quick Shade to ensure the texture aligns without stretching.
Mnemonic
MAP
Material — Assign — Preview. Repeat this short loop whenever you create or tune a material to catch mistakes early.
Verification

If textures appear stretched, use UV Visualize. If specular looks wrong, check Metallic and Roughness values or their texture inputs.
