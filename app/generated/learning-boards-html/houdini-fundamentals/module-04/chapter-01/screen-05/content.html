Parameter Cards
Base Color (Albedo)
Primary surface color. For dielectrics it represents the diffuse reflectance; for metals it interacts with reflections.
Metallic
0 = dielectric, 1 = metal. Changes how the shader mixes diffuse and specular responses.
Roughness
Controls microfacet distribution. Low values produce sharp reflections, high values soften them.
Key Takeaway

Adjust metallic and roughness together. Roughness controls clarity of reflection; metallic changes the reflection's color behavior.

Quick Comparison
Three example presets to test in the Principled Shader.
Chrome-Like
Metallic 1.0 · Roughness 0.02 · Base Color near neutral yields strong, colored reflections.
Glossy Paint
Metallic 0.0 · Roughness 0.12 · Base Color defines body color while highlights stay white.
Rough Stone
Metallic 0.0 · Roughness 0.7 · Muted highlights and scattered light.
Misconception
Shininess is not a single property. It is a combination: metallic determines reflection type and roughness controls highlight shape.
