Process Flow › Chapter 4.1 › Texturing a Simple Prop
Step-by-step Activity
  1. Create geometry: geo1 → Box. Optionally Subdivide for smooth silhouette.
  2. Generate UVs: add UV Unwrap; preview with UV Quick Shade to check stretching.
  3. Create material: in MAT create Principled Shader and rename it my_prop_material.
  4. Assign textures: Base Color, Roughness, Metallic via Use Texture; set Normal Map to Tangent Space.
  5. Assign material: OBJ → select geo1 → Render tab → Material = /mat/my_prop_material. Add Environment Light and Camera, then Render View.

Iteration Tip
If results are unexpected, test by plugging a constant into Roughness to observe shader response and isolate the issue.
Why this helps
This short loop trains you to validate UVs, keep materials organized, and tune parameters under realistic lighting instead of guessing in isolation.
