Color vs Non-Color
Understand which textures need gamma correction and which do not.
Base Color
Treat as sRGB so colors appear correct under gamma-corrected rendering.
Roughness / Metallic / Normal
Treat as linear, non-color data to preserve exact numeric values.
Troubleshoot Steps
  • Swap a texture for a constant to confirm shader response.
  • Check import settings or image nodes for forced color-space conversion.
  • If normal detail appears inverted, flip the green channel or test alternate normal types.
Quick Test
Load a neutral gray into roughness; roughness should appear uniform. If not, color-space is likely incorrect.
