Process Flow › Chapter 4.1 › Material Context and Principled Shader
Step-by-step
  1. Open the network editor and create a MAT context (Tab → mat).
  2. Inside MAT, press Tab and create a Principled Shader node. Rename it for clarity.
  3. Open the node and locate parameter groups: Base Color, Roughness, Metallic, Normal Map.
  4. Enable 'Use Texture' on a parameter and choose an image to drive it.
  5. Save or duplicate the node as a template for future materials.
Pro Tip
Use consistent naming like my_prop_material to make assignment and debugging faster when you return to the OBJ context.
Visual Checklist
Parameters to confirm
Base Color set or textured, Metallic enabled if needed, Roughness set or textured, Normal map plugged and set to Tangent Space.
Organization
Group related maps in the shader node and add comments if you reuse complex layered setups.
