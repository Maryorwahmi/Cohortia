Map Types
How each map contributes to the final shaded result.
Base Color / Albedo
Color data for the surface. Use sRGB for correct color reproduction.
Roughness
Scalar map controlling microfacet spread. Dark = smooth, bright = rough.
Metallic
Scalar mask: metal vs dielectric. Often binary or grayscale for blended surfaces.
Normal Map
Encodes normal direction in RGB to fake bumps. Use tangent-space normal maps for typical workflows.
Practical Tips
  • Enable 'Use Texture' on the Principled Shader parameter to feed the map.
  • Set normal maps to tangent space and confirm the Normal Map Type in the shader.
  • Use a checker or UV Quick Shade to ensure texture alignment before final maps are applied.
  • If roughness appears inverted, inspect the grayscale values and flip or remap as needed.
Common Mistake
Treating roughness or metallic maps as color data can lead to incorrect gamma interpretation and wrong shading. Verify color space settings if results look off.
