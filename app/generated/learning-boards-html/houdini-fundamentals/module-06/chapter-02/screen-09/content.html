Module 6 › Chapter 6.2 › Box HDA Walkthrough
Steps
  1. Add floats: box_size_x, box_size_y, box_size_z (default 1, soft range 0.1–10).
  2. Add extrude_dist (default 0.1, soft 0.01–1) and mountain_height (default 0.5, soft 0–2).
  3. Create folder box_controls and move parameters into it.
  4. Apply changes, dive inside HDA, paste relative references into internal SOP parameters.
  5. Test sliders and Save Node Type to persist edits.
Checkpoint
After saving, create a new instance and confirm parameters and folder structure appear as expected.
Example expressions
When Paste Relative References is used, Houdini writes the necessary channel calls. If typing manually, ensure the expression points up into the HDA to find the parameter by its internal name.
Troubleshoot
  • Broken link? Re-check parameter name spelling and the relative path level.
  • Type mismatch? Confirm the HDA parameter kind matches the internal input.
  • Not persisted? Ensure you selected Save Node Type on the HDA node after Apply and Accept.
