Exposing Parameters

Turn internal controls into a clean, user-facing HDA interface so others can drive behavior without opening the node graph.

In this lesson
  • Use the Parameter Interface editor to add and configure parameters.
  • Link parameters to internal nodes with channel expressions.
  • Organize controls with folders and separators.

Visual Concept
HDA Interface Map
Operator names become channels. Clear labels guide users. Folders group related sliders like Size and Extrude.
Mini checklist
  • Give each parameter a concise name and friendly label.
  • Set sensible defaults and soft ranges to guide users.
  • Save the node type after edits to persist changes.
Example: Box HDA
Expose three floats named box_size_x, box_size_y, box_size_z. Paste relative references into the Box SOP's size channels so the HDA changes geometry without entering the node.
