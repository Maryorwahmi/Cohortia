Checklist to debug a non-responsive parameter
  • Verify the expression path level; adjust ../ or ../../ if needed.
  • Confirm the internal operator name matches the HDA parameter name exactly.
  • Ensure data types match; convert or use explicit functions for integers or strings.
  • Apply and then Save Node Type so changes persist to disk.
Diagnostic tips
Set a visible default value and inspect the internal node to see if the expression appears.
If a vector is required, try pasting references into each component to observe behavior.
Remember: Apply modifies the instance only; Save Node Type writes the HDA definition to disk.
