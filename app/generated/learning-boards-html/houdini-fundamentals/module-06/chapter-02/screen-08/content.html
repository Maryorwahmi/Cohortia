Module 6 › Chapter 6.2 › Organizing the HDA Interface
UI Elements
Folder (Simple)
Collapsible group for a set of related parameters like box size and extrude.
Tab
Creates a separate tab page; use for distinct workflows, not minor groupings.
Separator
Visual divider to break up parameter lists inside folders or tabs.
Design pattern

Group by what the user wants to change. Example groups: Transform, Geometry, Deformation, Output. Avoid grouping by node names.

Example: Box Controls folder
Create a folder named box_controls, label it Box Controls, and drag box_size_x, box_size_y, box_size_z, extrude_dist, mountain_height into it.
Visibility tip
Keep frequently used controls visible by default; collapse advanced or debugging groups.
Key Takeaway

Organize controls around user tasks, not internal structure, and prefer folders and separators to maintain visibility.
