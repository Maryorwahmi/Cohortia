Module 6 › Chapter 6.2 › Parameter Interface Editor
Step-by-step
  1. Open Type Properties and go to the Parameters tab.
  2. Drag a parameter type from the left to the right pane.
  3. Configure Name, Label, Default, Range and Soft Range.
  4. Organize Reorder, add folders and separators.
  5. Apply & Save Apply to instance, then Save Node Type to persist.
Pro tip
Use clear names for expressions and friendlier labels for users. Soft ranges guide typical behavior without hard limiting power.
Parameter properties
Name
Internal identifier used by expressions. Keep concise and avoid spaces.
Label
User-facing display name. Can be friendly and descriptive.
Default
Initial value when the HDA is placed in a scene.
Range / Soft Range
Hard range limits valid input; soft range defines the slider's typical span.
Example setup
box_size_x: default 1, soft range 0.1 to 10, hard range 0.01 to 100. This gives a sensible slider while allowing extreme typing if needed.
Common error
Forgetting to Save Node Type: Apply updates the instance but does not persist the HDA definition on disk.
Check
After saving, place a fresh instance of the HDA to verify parameters and organization are stored.
