Module 6 › Chapter 6.2 › Expression Types
Quick comparison
ch
Generic channel reference. Houdini tries to infer type.
chf / chi / chs
Type-specific: float, integer, and string. Use when you need explicit casting or safety.
When to use which
  • Counts and indices: use chi.
  • Continuous scales: chf or ch.
  • Names or file paths: chs for strings.
Practical examples
Fence posts
Use an Integer parameter and link it with an integer-aware expression for the Copy to Points node's number of copies.
Vector fields
When internal parameter expects a vector, supply components individually or construct a vector from multiple channel calls.
Tip
If you are unsure, test with ch first and switch to chf or chi to remove ambiguity in edge cases.
