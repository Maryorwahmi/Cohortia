Module 6 › Chapter 6.2 › Channel Expressions
How it works

Copy a parameter from an internal node, then paste the relative reference from your HDA parameter. Houdini writes the channel reference so the internal parameter reads the HDA control at runtime.

Manual example (visual code)
ch("../box_size")
ch("../box_size_x")
ch("../box_size_y")
Use Paste Relative References to avoid typing mistakes. The path goes up to the HDA where the parameter is defined.
Example scenario
Create float box_size on the HDA. Inside the HDA, paste relative references into the Box SOP size channels. When you move the slider, the geometry updates in the scene.
Common pitfalls
  • Spelling errors in the parameter name break the reference. Verify the operator name exactly.
  • Wrong data type: linking a string to a float input causes errors or silent failures.
  • Vector parameters require either individual components or a constructed vector expression.
Try this
Create box_size, then paste relative references into sizex, sizey, sizez. Change box_size and confirm geometry responds. If it does not, re-check the parameter name and type.
Key Takeaway

Paste Relative References whenever possible and ensure parameter names and types match to create reliable links.
