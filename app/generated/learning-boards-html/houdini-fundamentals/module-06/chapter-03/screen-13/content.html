Module 6 › Chapter 6.3 › Distribution & Troubleshooting
Step-by-step Simulation
  1. Copy cohortia_simple_box.hda to C:/Temp/MySharedHDAs.
  2. On the other machine, run a terminal check for HOUDINI_PATH to see if the folder is listed.
  3. If missing, add the folder to houdini.env or the system HOUDINI_PATH and restart Houdini.
  4. If unresolved, open the instance and update Definition File to point to the new .hda location.
  5. After updating, choose Match Current Definition to re-lock and clean local overrides.
Terminal Check Example
echo $HOUDINI_PATH
# or on Windows (PowerShell): $env:HOUDINI_PATH
If the output doesn't include your shared folder, Houdini won't find the copied .hda until you add it and restart.
Key Takeaway

A simple copy + HOUDINI_PATH update is enough to distribute an HDA. Restart Houdini and repair Definition File entries when needed to resolve broken instances.
