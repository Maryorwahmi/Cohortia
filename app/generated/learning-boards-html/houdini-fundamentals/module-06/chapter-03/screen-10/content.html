Path Strategies
Clear rules for where HDAs live
  • Project-relative hda folder (recommended for single-project assets).
  • Central shared HDA library added to HOUDINI_PATH for cross-project teams.
  • Avoid user-specific absolute paths when saving definitions.
  • Document the chosen layout in project setup notes or houdini.env.
These rules reduce unresolved HDAs and speed onboarding for new team members.
Repair Guide
  1. Open the HDA node and choose Type Properties → Basic.
  2. Check the Definition File parameter to see the recorded path.
  3. Point it to the correct .hda or copy the .hda into the expected project folder.
  4. Restart Houdini if you changed HOUDINI_PATH to ensure a fresh scan.
Example houdini.env entry
HOUDINI_PATH = C:/Projects/MyGame/hdas;&HOUDINI_PATH
Adding the shared folder here makes HDAs appear in the Tab menu for all users who use that houdini.env.
