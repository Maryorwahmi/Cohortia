Module 6 › Chapter 6.3 › Distribution & HOUDINI_PATH
Shared HDA library architecture
Keep .hda files in a central folder scanned by Houdini. Add that folder to HOUDINI_PATH so everyone sees the assets without copying them into each project.
houdini.env example
HOUDINI_PATH = C:/Project/SharedHDAs;<$HOUDINI_PATH>
Place houdini.env in the Houdini preferences or project folder to configure paths for the team.
Unresolved HDA fix
If an instance is unresolved, check that the .hda exists at a path listed in HOUDINI_PATH or update the instance's Definition File to the correct .hda. Consistent paths avoid this problem.
Manual copy
Copy the .hda into another machine's project folder to share quickly, but use this sparingly for teams to avoid divergence.
Best practice
Store shared HDAs in version control and document HOUDINI_PATH setup in project onboarding materials.
Key Takeaway

A single, versioned shared HDA library and consistent HOUDINI_PATH settings keep assets resolved and teams synchronized.
