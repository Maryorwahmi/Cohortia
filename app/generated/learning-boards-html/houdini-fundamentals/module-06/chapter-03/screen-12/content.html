What to put in Help
Short, actionable guidance
  • Purpose statement: what the HDA generates and when to use it.
  • Key parameters and recommended ranges.
  • Performance notes and expensive toggles to avoid in production.
  • How to add the HDA to HOUDINI_PATH and expected project folder layout.
Usage Example
Example snippet to include in Help explaining a common task:
Use the Scale parameter for coarse sizing. For fine placement, use Offset X/Y/Z. Avoid enabling High Detail on large counts.
Including a short example like this helps artists quickly choose sensible settings and reduces support interruptions.
