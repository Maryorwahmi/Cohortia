Module 6 › Chapter 6.3 › Referencing External .hda
Definition Reference
What the scene stores for each HDA instance
Houdini stores a pointer to the HDA's definition file on disk. If that file is missing or moved, the instance becomes unresolved. Maintain consistent storage locations and use project-relative paths whenever feasible to keep instances stable across machines.
Quick Troubleshooting
Steps to resolve an unresolved HDA
  • Confirm the .hda file still exists at the expected path.
  • Check HOUDINI_PATH includes the containing directory.
  • Open Type Properties → Basic → Definition File to point to a new location if needed.
Example: Definition File Path
A path the instance uses to find its .hda
Definition File: ./hdas/cohortia_simple_box.hda
Using a relative path like this ties the HDA to the project layout rather than a single user's folder. If the whole project is copied or moved, the reference remains valid.
Common Mistake
Relying on absolute, user-specific paths when saving HDAs. These break when the project moves or when another user loads the scene.
Key Takeaway
Keep definition paths consistent and share HDAs via a shared library so instances remain resolvable.
