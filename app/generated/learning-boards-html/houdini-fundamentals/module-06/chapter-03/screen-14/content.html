Module 6 › Chapter 6.3 › Key Concepts — A
Versioning
Creating separate numbered iterations so older scenes keep working.
HDA Locking
Default state preventing direct edits to the internal network for stability.
Allow Editing
Temporary unlock to change internals; must save to make permanent.
Summary

Version numbers, locks, and the save action are the key levers for stable, collaborative HDA development. Use them consistently.
