Module 6 › Chapter 6.3 › HDA Versioning
Versioning — clear definition
A version is a saved HDA definition on disk. Houdini keeps old definitions so scenes continue to reference the version they were created with. This enables safe, non-destructive updates.
Why it matters
  • Prevents unexpected behavior when assets change.
  • Provides rollback points if a new version introduces bugs.
  • Communicates compatibility expectations to your team.
Common mistake
Not incrementing a version for breaking changes, which silently replaces older behavior and can break saved scenes.
Concrete example
You maintain a modular building HDA at v1.0 used across multiple levels. You add a new algorithm for window placement that changes geometry. Save a new definition as v2.0 so older levels continue referencing v1.0 while new designers can opt into v2.0.
Key takeaway
Version numbers are contracts. Use them strategically to control risk and communicate compatibility.
Check your understanding
If you change display-only labels on parameters, do you always need to increment the major version? Think about whether the change affects behavior or only usability.
