Module 6 › Chapter 6.4 › Plugin Role
Core Concept

Houdini Engine as the cooking bridge

The plugin asks a Houdini session to compute geometry for HDAs and returns the results so the engine can display and update them in real time.

Definition

A library that enables engines to load and cook .hda files inside the editor.

Why it matters

Faster iteration and fewer context switches when adjusting procedural assets for levels.

Example

Drag a road generator HDA into a level, change width and curvature, and let the engine cook the updated mesh.

Misconception

It is not a lightweight runtime system. Editor cooking can be expensive if not baked later for final builds.

Key takeaway

Use Houdini Engine for iteration, and bake outputs for runtime performance.
