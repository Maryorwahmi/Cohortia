Module 6 › Chapter 6.4 › Compatibility
Definition

Version compatibility

Plugin and Houdini must match supported pairings; mismatches cause session failures and cook errors.

Checklist
  • Confirm Houdini version.
  • Download matching plugin build.
  • Place plugin in correct folder and restart editor.
Example

Installing a plugin for Houdini 18 while running Houdini 19 usually leads to failed cooks and error logs indicating a version mismatch.

Misconception

Don't assume minor updates are safe. Always validate each pair before adopting in production.
