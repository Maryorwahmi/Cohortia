Module 6 › Chapter 6.4 › Baking
Process

Bake HDA outputs into engine static meshes

Unreal
  1. Place and configure the HDA instance in your level.
  2. Right-click the Houdini Asset in World Outliner → Houdini Engine → Bake.
  3. Inspect generated static meshes and replace the HDA instance as needed.
Unity
  1. Select the HDA instance in the scene.
  2. Click Bake in the Inspector to generate static mesh assets.
  3. Replace the HDA instance with baked meshes for final packaging.
Why bake

Baking ensures runtime speed, allows engine LODs and collisions, and avoids editor dependency on Houdini Engine at runtime.

Common mistake

Not baking before packaging can cause missing geometry or build-time errors if the engine expects Houdini cooking.

Key takeaway

Bake for production; keep cooking for iteration.
