Process

Install and enable Houdini Engine for Unreal

1
Download the plugin build that matches your Houdini version and place it in your project's Plugins or engine Plugins folder.
2
Restart the editor, open Edit → Plugins, find Houdini Engine, and enable it. Restart again if prompted.
3
Verify an active Houdini Engine session exists and that Houdini Parameters appear on an HDA instance.
Example

After enabling, drag the cohortia_simple_box.hda into Content Browser. If the Details panel shows 'Houdini Parameters', the plugin is working.

Troubleshoot
  • Check plugin placement if it does not appear in Edit → Plugins.
  • Confirm Houdini and plugin versions are compatible to avoid cook errors.
  • Inspect plugin and editor logs for failed session messages.
Key Takeaway

Follow install, enable, restart, verify to ensure in-editor cooking works reliably.
