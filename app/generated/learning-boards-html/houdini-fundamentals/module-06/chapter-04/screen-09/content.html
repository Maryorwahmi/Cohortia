Steps

Import and edit HDAs in Unity

  1. Drag the .hda into the Project window so Unity creates a Houdini Asset entry.
  2. Drag the asset into the scene hierarchy to instance it.
  3. Select the instance and use the Inspector's Houdini Parameters to change sliders and trigger cooks.
Example

Duplicate an instance five times and change Box Size X across duplicates to produce five variations from one HDA quickly.

Check the Unity console for cook errors or session messages if parameters do not update.
Key takeaway

Use in-editor cooking for rapid generation, then bake for final packaging.
