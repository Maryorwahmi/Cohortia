Module 6 › Chapter 6.4 › Hands-on Activity
Guided steps
  1. Enable Houdini Engine plugin in your editor and restart if prompted.
  2. Import cohortia_simple_box.hda into Content (Unreal) or Project (Unity).
  3. Drag the asset into the scene to instance it and open Houdini Parameters.
  4. Adjust Box Size X/Y/Z, Extrusion Distance, Mountain Height and observe cooks.
  5. Bake selected instances to static meshes and replace the HDA instances for final builds.
