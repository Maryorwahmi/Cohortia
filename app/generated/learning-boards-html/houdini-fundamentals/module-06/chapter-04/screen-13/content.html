Module 6 › Chapter 6.4 › Troubleshooting
Definition

Common causes of non-updating HDAs

Checklist
  • Is Houdini Engine enabled in the editor?
  • Do plugin and Houdini versions match?
  • Are plugin files in the correct Plugins folder?
  • Is the cook indicator showing activity?
Example

No Houdini Parameters visible after import usually means the plugin is disabled or the session failed to start.

Misconception

Missing updates rarely indicate a broken HDA; more often they indicate an installation or session issue.
