Module 6 › Chapter 6.4 › Key Concepts
Houdini Engine

A plugin library that lets engines load and cook Houdini Digital Assets inside the editor.

Real-time Cooking

The dynamic generation of geometry when HDA parameters are changed in the engine.

Plugin Installation

Place the plugin files into the engine's Plugins folder and enable them to establish a working connection to Houdini.

Summary

Install the plugin correctly, instance HDAs to access parameters, and use cooking for iteration before baking for production.
