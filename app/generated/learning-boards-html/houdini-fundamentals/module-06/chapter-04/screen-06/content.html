Module 6 › Chapter 6.4 › Install (Unity)
Process

Import Houdini Engine package into Unity

1
Download the Unity package matching your Houdini version and import it into the Project window.
2
Confirm package installed entries appear and check the Inspector for Houdini Engine settings.
3
Import an .hda into Project and drag it into the scene to verify Houdini Parameters and cooking.
Verification

Use cohortia_simple_box.hda: drag into Project, then drag the generated asset into a scene. Adjust a slider in the Inspector and confirm a cook runs and the mesh updates.

Common mistake

Using a plugin build that doesn't match your Houdini version causes failed cooks. Re-import the correct package to resolve this.
