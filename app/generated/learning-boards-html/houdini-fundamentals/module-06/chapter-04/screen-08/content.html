Steps

Drag, Instance, Inspect

  1. Drag cohortia_simple_box.hda into the Content Browser.
  2. Drag the asset into the viewport or World Outliner to create an instance.
  3. Select the instance and open the Details panel to find Houdini Parameters and adjust sliders.
Pro tip

Wait for the cook indicator to finish before making multiple rapid parameter changes to reduce editor lag.
