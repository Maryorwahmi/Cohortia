Sample question
You created a complex procedural building in a subnet and want to make it reusable. What is the correct sequence to convert and save it so other artists can use it in other scenes?
Correct sequence
  1. Collapse to Subnet
  2. Create Digital Asset From Subnet
  3. Configure Operator Type Properties
  4. Accept and then Save Node Type to write the .hda
Troubleshooting question
An artist used Allow Editing and made changes, but other instances do not show them after reopening the file. Why?
Because the artist did not Save Node Type after editing, the .hda definition on disk was not updated. The fix: Save Node Type and have collaborators pull and Match Current Definition or re-instantiate the operator.
