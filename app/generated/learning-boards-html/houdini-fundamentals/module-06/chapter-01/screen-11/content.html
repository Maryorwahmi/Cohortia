Troubleshooting › Changes not appearing?
Quick diagnostic steps
  1. Did you Save Node Type after editing the instance?
  2. Was the edit made via Allow Editing and left local?
  3. Is the .hda saved to the expected project folder or library path?
  4. Are operator names unique or conflicting with another .hda?
  5. Has the updated .hda been committed and pulled by collaborators?
Fixes
  • Perform Save Node Type to persist the definition.
  • Have team members Match Current Definition or re-instantiate after pulling changes.
  • Standardize the hda save path and include it in VCS to avoid duplicate definitions.
Misconception check

Editing an instance is not the same as editing the definition. Always save the node type to make a global change.
