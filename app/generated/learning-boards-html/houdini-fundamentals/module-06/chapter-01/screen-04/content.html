Core Concept › What is an HDA?
Precise definition

A Houdini Digital Asset is both a definition (a .hda file on disk) and an operator instance in a scene that refers to that definition. It encapsulates node graphs and exposes designer-facing parameters.

Examples
  • Procedural rock generator with density and roughness parameters.
  • Modular building system that exposes floor count and module variants.
  • Foliage tool that randomizes scale and rotation for natural variety.
Key Takeaway

Treat an HDA as a formal tool: design an interface, hide complexity, and keep a single definition to maintain consistency.

Analogy
Think of an HDA like a kitchen appliance: the user sees buttons and dials, but not the heating elements or wiring. The appliance performs complex steps internally while presenting a simple interface.
Blueprint
The .hda file that stores the blueprint.
Instance
A usable node in a scene that follows the blueprint.
Common misconception
Beginners often assume changing one instance will update others. Only saving the node type updates the definition; local edits remain local until explicitly saved.
