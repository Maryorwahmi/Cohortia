Module 6 › Chapter 6.1 › Learning Objectives
01 Instance vs Definition
Describe the blueprint (definition) versus a working node in a scene (instance).
Mnemonic: Blueprint vs toy — change the blueprint to update all toys.
VERIFIED COMPETENCY MILESTONE
02 Allow Editing Workflow
Practice temporary local edits then explicitly save to the definition when ready.
Mnemonic: Test locally, Save globally.
VERIFIED COMPETENCY MILESTONE
03 Naming & Paths
Use descriptive operator names and a project hda folder to avoid conflicts.
Mnemonic: name clearly, save predictably.
VERIFIED COMPETENCY MILESTONE
04 Versioning Habit
Keep .hda files under version control so you can revert if a definition breaks.
Mnemonic: commit often after saving node type.
VERIFIED COMPETENCY MILESTONE
Practical check
  • Can you save a definition and re-create it with Tab?
  • Do you have a consistent save folder for project HDAs?
  • Have you practiced Allow Editing without forgetting to save?
