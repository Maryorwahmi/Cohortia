Save Node Type
Saves the operator definition to disk as a .hda file. Choose a project folder so the file is discoverable by teammates and across sessions.
Steps to persist an HDA:
1. Right-click the HDA instance
2. Choose "Save Node Type"
3. Confirm the file path and write the .hda
4. Use Tab in other scenes and type the operator name to instantiate
Editing and syncing
  • Allow Editing of Contents: make local changes to an instance for testing.
  • Save Node Type: commit those changes to the .hda so all instances update.
  • Match Current Definition: discard local edits and re-sync with the saved .hda.
Key Takeaway

Explicitly save definitions to share tools. Use editing and matching commands to manage local changes versus global updates.
