Naming Conventions
  • Use lowercase operator names with underscores (example: cohortia_simple_box).
  • Use clear Labels for UI display so non-technical artists understand the tool.
  • Avoid generic names that collide across teams.
Mnemonic: name clearly, save predictably.
Save Paths & Versioning
Save .hda files to a project hda folder or shared asset library and include them in your version control system. After Save Node Type, commit the new file with a message describing the change.
Key Takeaway

Treat .hda files like code: clear names, consistent paths, and commits make tool development manageable and reversible.
