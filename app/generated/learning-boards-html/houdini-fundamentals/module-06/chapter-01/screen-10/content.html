Hands-on Activity › Create a Box HDA
Quick steps (copyable)
1. Create Box SOP
2. Connect PolyExtrude
3. Connect Mountain
4. Connect Normal
5. Select all nodes → Collapse to Subnet
6. Right-click subnet → Create Digital Asset From Subnet
7. Operator Name: cohortia_simple_box
8. Label: Cohortia Simple Box
9. Save Node Type to write the .hda
10. Press Tab → instantiate Cohortia Simple Box
This short activity helps you internalize the sequence and the importance of saving the node type to create a reusable definition.
Scenario card
Imagine you need a procedural box generator for use across multiple levels. Build it, expose size and roughness parameters on the HDA interface, save the .hda to your project hda folder, and then artists can drop the operator into any scene and tune parameters without editing nodes.
Key Takeaway

Small experiments like this build muscle memory for creating, saving, and instancing HDAs in production workflows.
