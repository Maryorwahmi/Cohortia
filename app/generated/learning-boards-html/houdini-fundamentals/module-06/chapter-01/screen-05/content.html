Comparison › Reusability vs Copy-Paste
Copy-Paste Networks
  • Each copy is independent and must be updated individually.
  • High risk of inconsistencies across scenes and artists.
  • Time-consuming to propagate changes across many copies.
Common mistake
Relying on copies for speed often creates long-term maintenance debt that slows iteration.
HDAs (Reusable)
  • One definition, many instances; update the blueprint once.
  • Encourages clear interfaces and parameter exposure for designers.
  • Supports versioning and consistent behavior across projects.
Key Takeaway

Prefer HDAs for production tools to reduce maintenance and ensure consistent updates across many instances.

Concrete example
If you maintain 50 trees from one HDA, adding a new branch type requires one change. With copies, you must edit 50 networks.
