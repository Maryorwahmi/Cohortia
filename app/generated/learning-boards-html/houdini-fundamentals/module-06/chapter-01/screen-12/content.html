Architecture › Team Workflow
Technical Artists
Own HDA design, expose parameters, test behavior, and Save Node Type when changes are ready.
Environment Artists
Use exposed parameters to populate scenes; use Allow Editing for local experimentation but request saves for global fixes.
Team rules
  • Document operator names and save paths.
  • Require testing in representative scenes before saving.
  • Include .hda changes in version control with clear commit messages.
Key Takeaway

Define ownership and a simple review workflow so HDAs remain stable and helpful across the team.
