Comparison › Editing vs Matching
Allow Editing of Contents
Temporarily enable editing inside one instance for testing or scene-specific fixes. Edits remain local until explicitly saved to the definition.
Use when:
  • Trying a change in context before committing it.
  • Fixing a scene-specific issue that doesn’t need global propagation.
Match Current Definition
Revert an instance to the saved .hda on disk. This discards local overrides and restores the blueprint’s current state.
Use when:
  • Local edits caused unexpected behavior and you need to return to the trusted definition.
  • Synchronizing an instance after the definition was updated elsewhere.
Pro tip

Document experimental edits and only Save Node Type after testing to avoid unintended global changes.
