Key Concepts › What to Remember
Houdini Digital Asset (HDA)
A reusable operator that encapsulates a node network and exposes parameters for designers.
Subnet
Container node used to group nodes before converting them into an HDA.
Operator Type Properties
Window where you set operator name, label, icon, and the save location for the .hda file.
Summary Takeaway

Design HDAs as shared tools: pick clear names, save definitions to a consistent folder, and commit .hda files so teams can rely on them.
