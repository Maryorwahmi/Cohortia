Process Flow › Create HDA from Subnet
Step-by-step
  1. Select the nodes you want to encapsulate in the network editor.
  2. Collapse to Subnet by right-clicking and choosing the action; confirm the new subnet node.
  3. Create Digital Asset From Subnet from the subnet's context menu to open Operator Type Properties.
  4. Configure Operator Name, Label, and Save To Library; choose a project hda folder.
  5. Accept the dialog to convert the subnet into an HDA instance.
  6. Save Node Type from the instance's context menu to write the .hda definition to disk.
Misconception check: the HDA definition is not guaranteed to exist on disk until you perform Save Node Type. Create Digital Asset only sets up the operator type in memory and UI until saved.
Operator Type Properties — key fields
  • Operator Name: unique identifier, typically lowercase with underscores (e.g., my_rock_generator).
  • Label: human-readable display name such as "My Rock Generator".
  • Save To Library: filesystem path where the .hda will be stored; use a project hda folder or shared library.
Pro tip

Choose a clear operator name to avoid conflicts. Keep a consistent hda folder per project for discoverability.
