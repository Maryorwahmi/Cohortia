01
Modularity

Break complex systems into smaller HDAs so each can be optimized, tested, and exported independently for engine use.

VERIFIED COMPETENCY MILESTONE
02
Clear Parameters

Expose only the parameters artists need and organize them logically to prevent accidental high-cost settings.

VERIFIED COMPETENCY MILESTONE
03
LODs & Collision

Plan for Level of Detail outputs and simplified collision geometry so engines can render efficiently at range.

VERIFIED COMPETENCY MILESTONE
04
Documentation

Document purpose, parameter ranges, and export steps so other artists and engineers reuse the HDA correctly.

VERIFIED COMPETENCY MILESTONE
Mnemonic & Example
Treat each HDA like a small tool: one job, clear inputs, predictable outputs. Example: split city generation into separate HDAs for buildings, roads, and props so each has a specific performance budget and export path.
Why this matters
Smaller, documented HDAs are easier to optimize, test, and integrate in a game pipeline than a single monolithic asset.
