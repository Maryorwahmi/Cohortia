Module 6 › Chapter 6.5 › Pre-baking & Export
Bake Patterns
Create dedicated outputs for each required file. Use consistent naming and folder structure so exported FBX or BGEO files map cleanly into the engine pipeline.
ROP Geometry Output
Use for exporting FBX/OBJ/Alembic. Configure Output File and SOP Path to target the cleaned SOP chain you want to export.
File Cache
Cache heavy computations locally as .bgeo.sc for fast iteration and to avoid re-cooking expensive nodes during development.
Example Export Paths
$HIP/geo/cohortia_simple_box_baked.fbx
$HIP/cache/cohortia_simple_box_cache.$F.bgeo.sc
$HIP/geo/rock_mesh_lod1.fbx
$HIP/geo/rock_collision.fbx
Use clear suffixes so engine importers pick the correct file for visuals, collisions or LODs.
Key Takeaway

Bake explicit outputs for each engine need and cache intermediate results to speed iteration and avoid re-cooks.
