Module 6 › Chapter 6.5 › Streamlining Networks
Optimization Steps
  1. Profile cooks and identify slow nodes or heavy SOPs.
  2. Remove or collapse redundant nodes and branches.
  3. Replace expensive operations or reduce their parameters (e.g., Subdivide iterations).
  4. Use Attribute Delete to remove unneeded attributes before export.
  5. Expose a small set of LOD parameters to the HDA interface.
Pro tip
Expose PolyReduce target as a slider so final quality can be adjusted per platform without modifying the network.
Example Scenario
A building HDA had multiple decorative boolean cuts and per-brick procedural bevels. By caching the combined boolean result, deleting temporary group attributes, and running a single PolyReduce with a promoted parameter, cook time dropped and exported geometry fit the engine budget.
Common Mistake

Leaving many intermediate attributes and temporary groups increases memory usage and file size. Delete them before exporting.
