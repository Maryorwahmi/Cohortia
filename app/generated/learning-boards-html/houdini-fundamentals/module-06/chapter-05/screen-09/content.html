Baking Workflow
  1. Ensure clean UVs with UV Unwrap / UV Layout.
  2. Create the procedural attribute (moss density, curvature, AO).
  3. Use Labs Maps Baker or Attribute VOP/Transfer to sample and bake to texture.
  4. Export maps as PNG/EXR for engine import and test them in materials.
Concrete Example
Generate a moss density attribute on rock faces, verify UVs, then bake the attribute to a grayscale PNG. Use that texture in the engine as a mask to blend moss materials without expensive runtime calculations.
Common Mistake

Baking before fixing UVs produces distorted maps; always check UV layout and padding before baking for mipmapping.
