Module 6 › Chapter 6.5 › PolyReduce & Cleanup
Quick Comparison
PolyReduce
Decimate triangles with shape preservation; promote target percentage for artists.
Fuse
Merge near-coincident points to reduce vertex count after simplification.
Clean
Remove degenerate primitives and unused groups; fixes non-manifold issues.
Attribute Delete
Trim attributes that increase memory or are unnecessary in the engine.
Practical Sequence
  1. Run PolyReduce to hit triangle target.
  2. Run Fuse to collapse close points.
  3. Run Clean to remove degenerate geometry and groups.
  4. Run Attribute Delete to drop unused attributes before export.
Key Takeaway

PolyReduce sets the budget; Fuse, Clean and Attribute Delete enforce hygiene and export safety.
