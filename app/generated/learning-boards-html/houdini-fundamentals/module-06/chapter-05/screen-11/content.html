Module 6 › Chapter 6.5 › Activity Walkthrough
Activity Steps (condensed)
  1. Open cohortia_simple_box HDA and dive into the SOP chain.
  2. Insert PolyReduce after Normal, set Target Percentage to 50%, and expose as HDA parameter.
  3. Insert Clean after PolyReduce; enable Remove Unused Groups and Remove Degenerate Geometry.
  4. Connect a ROP Geometry Output node to Clean, set Output File and SOP Path, and export FBX.
  5. Optionally add File Cache to save .bgeo.sc for faster iteration.
  6. Save the HDA definition so parameters and baked paths persist.
Example Paths

$HIP/cache/cohortia_simple_box_cache.$F.bgeo.sc
Key Takeaway

Follow a baked pipeline: reduce → clean → cache/export. Expose only necessary parameters and save the HDA for reproducible exports.
