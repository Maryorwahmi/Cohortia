Definition
Static Object vs RBD Packed Object
Static Object is for environment or non-fracturing geometry; RBD Packed Object is for dynamic fractured pieces. Deforming geometry must be enabled when animated geometry collides with simulations.
Use static objects for walls, containers, and landscapes.
Use RBD Packed for shards, debris, and moving rigid pieces.
Example
Character feet deform the sand. If you used Static Object without Deforming Geometry checked, sand particles might pass through. Enable Deforming Geometry and set SOP Path to the animated foot mesh to resolve this.
Pro tip
For heavy scenes, create a simplified proxy of the animated geometry for collisions to reduce computational cost while preserving contact behavior.
Key Takeaway

Match object types to motion. Enable Deforming Geometry and point SOP Paths for animated colliders to keep particle interactions reliable.
