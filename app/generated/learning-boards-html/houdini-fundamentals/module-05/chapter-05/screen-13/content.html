Module 6 › Chapter 5.5 › Caching Pitfalls
Checklist
  • Confirm DOP Import references the correct network and node.
  • Use $HIP and $F variables in cache names for clarity and portability.
  • Save caches to a fast local drive and confirm Save to Disk completes.
  • Monitor disk space and use descriptive cache file names.
Example Failure Modes
Empty geometry after DOP Import — check DOP path.
Slow reads — cache stored on network drive.
Partial frames — Save to Disk interrupted or insufficient space.
Key Takeaway

Treat caching as a two-step operation: write and then validate. Only then disconnect heavy DOP networks or delete source nodes.
