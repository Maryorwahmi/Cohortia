Module 6 › Chapter 5.5 › DOP Import & File Cache
Process
DOP Import → File Cache
  1. Place a DOP Import SOP and set DOP Network and DOP Node to your solver output.
  2. Connect a File Cache SOP after the DOP Import.
  3. Set the Cache Name and frame range, then click Save to Disk.
  4. Switch File Cache to Load From Disk and verify playback.
Code Example — Cache Path
$HIP/geo/pop_grains_cache.$F.bgeo.sc
Use the $HIP and $F variables so the path is portable and writes one file per frame. Use a descriptive name so you can identify caches later.
Key Takeaway

Caching with DOP Import and File Cache keeps your scene responsive and lets you safely disconnect or remove heavy simulations after saving results.
