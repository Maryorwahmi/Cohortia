Module 6 › Chapter 5.5 › Troubleshooting
Forces
  • Are forces merged into the correct solver?
  • Is strength/amplitude reasonable?
  • Add damping or substeps if motion is unstable.
Collisions
  • SOP Paths correct on Static Objects?
  • Deforming Geometry enabled for animated colliders?
  • Use proxies or concave only as needed.
Caching
  • DOP Import points to the correct DOP Network and Node?
  • Did File Cache complete Save to Disk for the target frames?
  • Is cache stored locally with enough disk space?
Pro tip

Run short diagnostic ranges and change one setting at a time. This isolates the cause and prevents wasted re-simulations while you test fixes.
