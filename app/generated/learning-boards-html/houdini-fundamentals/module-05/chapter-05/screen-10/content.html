Module 6 › Chapter 5.5 › Hands-on: POP Wind & Cache
Step-by-step
  1. Open pop_grains_sim and dive into the DOP Network.
  2. Create POP Wind, set Amplitude = 2, Direction = 1,0,0 and merge into the solver.
  3. Back in SOPs, add DOP Import pointing to popnet1/popsolver1.
  4. Add File Cache after DOP Import, set path and frame range, click Save to Disk, then Load From Disk = Automatic.
Quick Reference
DOP Import: DOP Network = popnet1
DOP Node: popsolver1
File Cache: $HIP/geo/pop_grains_cache.$F.bgeo.sc
Frames: 1-120
Validate by switching File Cache to Automatic and scrubbing; playback should be immediate. If geometry is empty, re-open DOP Import and confirm the network and node selection.
