Controlling Simulations: Forces, Collisions, and Caching
Use force nodes to sculpt motion, make collisions reliable for deforming geometry, and cache simulation results for fast iteration.
In this lesson
Explore force node types, collision setup, and the DOP Import → File Cache workflow so you can stabilize and store results.
Why it matters
Proper forces and collisions make simulations believable; caching frees you from re-simulating and speeds iteration dramatically.
Practical result
Add a wind force to POP Grains, verify collisions with deforming geometry enabled, then use DOP Import and File Cache to save a playback-ready cache.
Explore Key Topics
Forces
POP and RBD forces shape particle and rigid-body motion; learn strength, noise, and direction controls.
Collisions
Deforming colliders and proxy geometry keep simulations accurate without killing performance.
Caching
DOP Import plus File Cache saves frames to disk so you can disconnect heavy DOP networks and iterate quickly.

Quick Start
Open the POP Grains scene from Chapter 5.3, add a POP Wind node in your DOP Network, set amplitude and direction, then DOP Import the result and save with File Cache to disk for playback.
