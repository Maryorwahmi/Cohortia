Practice Tasks
  1. Add POP Wind to a POP Grains scene, set amplitude and direction, observe particle drift.
  2. Enable Deforming Geometry on a Static Object for an animated mesh and test collisions across frames.
  3. DOP Import the solver output into SOPs and save a File Cache for frames 1–120.
Troubleshooting Checklist
  • Are your forces merged into the correct solver?
  • Is the Static Object's SOP Path pointing to the animated geometry?
  • Is Deforming Geometry enabled for dynamic colliders?
  • Are substeps and collision shapes adequate for fast-moving pieces?
  • Is the File Cache path local and do you have disk space?
