Architecture
Proxy workflow for collisions
Create a simplified collision mesh with PolyReduce or VDB from Polygons. Use the proxy in the Static Object SOP Path. Test for visual contact errors and preserve features that affect collisions.
Simplified proxy preserves gross shape and reduces collision tests.
Concave collision is accurate but expensive; prefer for static, highly detailed environments only.
Example
Replace a high-poly environment mesh with a VDB-based proxy. If particle contacts remain visually acceptable, the proxy wins because it is faster and stable.
Common Mistake
Removing thin features in a proxy can allow small particles to slip through. Preserve features that influence contact zones.
Key Takeaway

Use the simplest collision geometry that still reproduces the visible interaction. Test visually and iterate on the proxy until it matches contact behavior.
