Force Choice
Use POP for particles, RBD for rigid bodies; tune not just magnitude but noise and damping.
Deforming Colliders
Enable Deforming Geometry and confirm SOP Paths for animated meshes so collisions update per frame.
Caching Best Practice
DOP Import then File Cache to save frames locally; validate files before disconnecting heavy DOP networks.
Final Thought
These three reminders form the core of a robust simulation workflow: choose forces deliberately, ensure accurate collisions, and cache results for speed.
