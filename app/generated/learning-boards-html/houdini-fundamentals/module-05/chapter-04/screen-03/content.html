Skills and practical outcomes
Concrete setup habits to avoid common mistakes and produce clean renders.
Apply → Master
FLIP practical checklist
  • Emitter geometry placed above container, particle separation chosen for resolution.
  • FLIP Source with SOP path to emitter and matching particle separation.
  • Static Object for container with Volume collision and watertight geometry.
  • Particle Fluid Surface after DOP Import for mesh generation.
Pyro practical checklist
  • Prepare attributes like density and temperature on source geometry.
  • Use Volume Rasterize Attributes to create voxel fields.
  • Feed volumes to Pyro Source and Pyro Solver; tweak buoyancy and dissipation.
  • Import density and temperature with DOP Import for rendering with a Pyro shader.
Why this matters
Choosing the correct simulation type reduces wasted time and produces visuals that match the real-world behavior you expect: fluid surfaces and splashes with FLIP, soft volumetric smoke with Pyro.
