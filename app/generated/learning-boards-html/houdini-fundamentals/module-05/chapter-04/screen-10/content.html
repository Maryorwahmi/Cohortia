Core Concept
Pyro solver and key controls
How solver parameters shape volumetric motion and appearance.
Control descriptions
  • Buoyancy: controls vertical motion driven by temperature differences.
  • Dissipation: reduces density over time to thin smoke.
  • Turbulence: adds small-scale chaotic motion for detail.
  • Combustion: used when fuel and temperature interact to create fire.
Iterative workflow
Run quick low-resolution tests to tune buoyancy and dissipation. Add controlled turbulence only after base motion looks correct. Increase division size only when you need finer detail and can budget compute time.
Misconception check
Don't rely solely on turbulence to create detail. If the base motion or resolution is insufficient, turbulence will only add noise, not meaningful structure.
