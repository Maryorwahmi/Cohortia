Process Flow
Importing and visualizing simulation results
Fetch simulated particles or fields and prepare them for rendering.
FLIP import sequence
  1. Add DOP Import: DOP Network = ../dopnet1, DOP Node = /obj/flip_pour_sim/dopnet1/flipsolver1
  2. Set Import Style to Fetch Geometry from DOP Network.
  3. Apply Particle Fluid Surface with Particle Separation matching FLIP Source.
Pyro import & shading
DOP Import the density and temperature volumes from the Pyro Solver. Use a Pyro Shader in your material network to interpret density and temperature for realistic smoke and fire rendering.
Visual checks
  • Scrub timeline to confirm fields are present.
  • Preview Particle Fluid Surface for surface continuity.
  • Preview Pyro density slices to check voxel coverage and values.
