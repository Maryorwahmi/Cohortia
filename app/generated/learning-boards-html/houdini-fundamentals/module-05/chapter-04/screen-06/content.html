Hands-on: FLIP pour setup (live coding)
Stepwise SOP and DOP commands presented like a script you can follow.
Starter script (SOPs & DOPs)
# SOP: flip_pour_sim
Tube: Height=2, Radius=1, End Caps=On
Reverse (if needed)
Null -> name OUT_CONTAINER

Box: Size=0.5, Translate Y=2.5
Null -> name OUT_EMITTER

# Add a DOP Network node in /obj/flip_pour_sim and connect OUT_CONTAINER to input1, OUT_EMITTER to input2

# Inside dopnet:
FLIP Source: SOP Path=/obj/flip_pour_sim/OUT_EMITTER, Particle Separation=0.05
FLIP Solver
Static Object: SOP Path=/obj/flip_pour_sim/OUT_CONTAINER, Collision Type=Volume
Gravity Force
Merge: connect FLIP Source, Static Object, Gravity -> FLIP Solver

# Back in SOPs:
DOP Import: DOP Network=../dopnet1, DOP Node=/obj/flip_pour_sim/dopnet1/flipsolver1, Import Style=Fetch Geometry from DOP Network
Particle Fluid Surface: Particle Separation=0.05
Practical tips
  • Match Particle Separation in FLIP Source and Particle Fluid Surface.
  • Use Volume collision for Static Object to prevent leaks.
  • If simulation is noisy, increase particle count or adjust solver substeps cautiously.
