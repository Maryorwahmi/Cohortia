Core Concept Definition
What is FLIP (Fluid Implicit Particle)?
A hybrid particle + grid approach for realistic liquid behavior.
Key idea
Particles represent local detail; a grid enforces pressure and volume. This combination produces splashes and stable bulk motion.
Common mistake
Using non-watertight collision geometry causes leaks. Always check volume collision and normals.
Example
A box emitter above a tube creates particles with an initial velocity. The FLIP Solver uses grid pressure to maintain a realistic surface while particles form splashes at the impact point.
Visual breakdown
Particles • Carry momentum, create droplets and foam
Grid • Stores velocities, solves pressure to keep flow incompressible
Key takeaway
Key Takeaway

FLIP balances particle detail and grid stability. Choose particle separation for the detail you need and ensure solid collision geometry.
