Common mistakes and troubleshooting
Simple checks that fix the majority of FLIP and Pyro issues.
FLIP checks
  • Ensure container geometry is watertight and has proper normals.
  • Set Static Object Collision Type to Volume.
  • Match Particle Separation between FLIP Source and Particle Fluid Surface.
Pyro checks
  • Run Volume Rasterize Attributes to create density/temperature volumes.
  • Verify attribute names and voxel coverage before simming.
  • Reduce division size for more detail; balance cost and quality.
Workflow tip
Validate sources and run short preview sims to tune behavior. Fixing geometry and attribute issues early avoids wasted high-resolution sim time.
