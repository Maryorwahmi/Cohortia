Definition
Pyro fundamentals: Voxels and Fields
Pyro stores volumetric attributes in a voxel grid and evolves them with a Pyro Solver.
Core fields
Density: controls visible smoke; Temperature: drives buoyancy and fire behavior; Velocity: moves the volume through space.
Important parameter
Division Size

Voxel size determines simulation detail. Smaller division size yields finer smoke at higher cost.

Concrete example
Rasterize a sphere's temperature attribute into a volume, feed it to a Pyro Source, then run a Pyro Solver. The warm voxels will rise and expand into smoke. Adjust Dissipation and Turbulence to refine the look.
Misconception check
Pyro is not for surface detail. If you need a visible liquid surface, use FLIP. Use Pyro when you want volumetric shading and soft, diffusive motion.
