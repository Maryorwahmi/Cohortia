Hands-on: Build the flip_pour_sim (lab walkthrough)
A concise lab replicating the scripted example.
Step list
  1. Create Geometry node: flip_pour_sim.
  2. Inside: Tube: Height=2, Radius=1, End Caps=On → Reverse (if needed) → OUT_CONTAINER.
  3. Box emitter: Size=0.5, Translate Y=2.5 → OUT_EMITTER.
  4. DOP Network: connect OUT_CONTAINER to input1 and OUT_EMITTER to input2.
  5. Inside dopnet: FLIP Source (SOP Path=/obj/flip_pour_sim/OUT_EMITTER, Particle Separation=0.05), FLIP Solver, Static Object (SOP Path=/obj/flip_pour_sim/OUT_CONTAINER, Collision Type=Volume), Gravity Force, Merge → FLIP Solver → Output.
  6. Back in SOPs: DOP Import (fetch flipsolver geometry) → Particle Fluid Surface (Particle Separation=0.05). Play timeline.
Quick checks
  • Are End Caps enabled on the tube?
  • Does the Static Object use Volume collision?
  • Do Particle Separation values match?
Reflection prompt
After your first run, note whether splashes look detailed enough. If not, which parameter would you change and why?
