Process Flow
FLIP Setup Workflow
Emitter to solver to surfacing — follow these steps to produce a reliable pour.
Step-by-step
1.
Create emitter and container geometry in SOPs: a Box emitter and a Tube container with end caps.
2.
Add a DOP Network and connect OUT_CONTAINER and OUT_EMITTER to its inputs.
3.
Inside DOPs: add FLIP Source (SOP Path to emitter) and FLIP Solver, plus a Static Object for the container and Gravity Force.
4.
Merge nodes into the solver, run sim, then use DOP Import and Particle Fluid Surface to mesh particles for render.
Quick code-like checklist
# SOPs
Create Tube -> OUT_CONTAINER
Create Box -> Translate Y = 2.5 -> OUT_EMITTER

# DOP Network
Inside dopnet:
FLIP Source: SOP Path = /obj/flip_pour_sim/OUT_EMITTER, Particle Separation = 0.05
FLIP Solver
Static Object: SOP Path = /obj/flip_pour_sim/OUT_CONTAINER, Collision Type = Volume
Gravity Force
Merge -> FLIP Solver -> Output
Visualization and checks
  • Confirm container normals and ensure End Caps are on for watertight geometry.
  • Match Particle Fluid Surface Particle Separation to source value to avoid artifacts.
  • Watch for particle leaks; if present, increase collision fidelity or fix geometry.
