FLIP vs Pyro — When to use each
Choose the solver that matches the physical data you need to control.
FLIP (Liquids)
Particles + grid, best for visible surfaces, splashes, and foam. Controls include particle separation and solver substeps.
Use when: pouring water, splashes, coherent liquid bodies
Pitfall: non-watertight collisions cause leaks. Always verify container geometry and collision type.
Pyro (Gases)
Pure volumetric fields like density and temperature across voxels. Controls include division size, buoyancy, turbulence, and dissipation.
Use when: smoke, fire, steam, explosive plumes
Pitfall: forgetting to rasterize attributes into volumes leads to empty Pyro sources. Use Volume Rasterize Attributes first.
Combined workflows
You can combine FLIP and Pyro: simulate liquid with FLIP and add Pyro for mist or steam. Plan interactions so each solver drives the right visual data.
