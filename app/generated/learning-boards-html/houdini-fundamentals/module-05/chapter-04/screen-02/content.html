Learning Objectives
Learn, understand, apply, and master foundational FLIP and Pyro setups.
Bloom: Learn → Understand → Apply → Master
01
Differentiate FLIP and Pyro
Explain how FLIP mixes particles and a grid while Pyro uses voxel fields for density and temperature. This distinction helps you select the correct solver for a visual effect.
Verified Competency Milestone
02
Set up a basic FLIP pour
Build emitter and container geometry, create FLIP Source and FLIP Solver, and convert particles into a mesh for rendering. Practical setup avoids common issues like leaks and incorrect particle separation.
Verified Competency Milestone
03
Configure a simple Pyro source
Rasterize attributes into volume grids, feed them to a Pyro Source, and use a Pyro Solver to simulate buoyancy, turbulence, and dissipation. Correct rasterization is crucial for meaningful smoke and fire.
Verified Competency Milestone
04
Import and visualize simulation results
Use DOP Import to fetch FLIP particles or Pyro fields, then apply Particle Fluid Surface or Pyro shaders to produce renderable surfaces and volumes for final output.
Verified Competency Milestone
