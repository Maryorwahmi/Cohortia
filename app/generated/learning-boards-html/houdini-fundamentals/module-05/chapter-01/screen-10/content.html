Merge nodes and connection order
Combine objects, forces and solvers carefully; missing merges cause silent failures.
Typical merge layout
RBD Packed Object + Static Object + Gravity Force → Merge → RBD Solver → Output
Verify each merged input by tracing it back to SOP Path and node type.
Concrete debugging steps
  • • Pause the timeline and inspect the Merge node to see active inputs.
  • • Confirm the solver receives the Merge output on the correct input index.
  • • Check that object types match the selected solver (RBD/FLIP/POP).
Common mistake

Forgetting to connect a force to the Merge is a very common cause of missing behaviour. Merges need to include both actors and influences.
