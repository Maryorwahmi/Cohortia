Learning Objectives
Learn the essentials of DOPs and how to build a minimal dynamics network.
01
Explain SOPs vs DOPs
Describe how SOPs build geometry and DOPs describe motion over time. This matters because it separates authoring from simulation, allowing faster iteration.
Mnemonic: Venn — geometry vs behaviour
VERIFIED COMPETENCY MILESTONE
02
Identify DOP components
Name Solvers, Objects, and Forces and explain the role each plays in a running simulation, with a short example of each.
Mnemonic: Timeline — solver steps through frames
VERIFIED COMPETENCY MILESTONE
03
Build a basic DOP Network
Create a minimal network to simulate a falling sphere: RBD Packed Object, Static Object, Gravity Force, RBD Solver and Merge connections.
Mnemonic: Step cards — follow the setup steps
VERIFIED COMPETENCY MILESTONE
04
Navigate and debug DOPs
Dive into a DOP Network, return to SOPs, and check paths and merges to resolve common simulation failures.
Mnemonic: Checklist — SOP path, object type, merged inputs
VERIFIED COMPETENCY MILESTONE
