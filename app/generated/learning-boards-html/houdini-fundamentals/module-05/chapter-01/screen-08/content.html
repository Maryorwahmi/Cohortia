Object nodes — RBD Packed, Static, and FLIP objects
Object nodes point to SOP geometry and give it simulation properties.
RBD Packed Object
Efficient rigid body wrapper; often used for moving, colliding geometry and fracture pieces.
Static Object
Non-moving collider for ground, walls, and fixed props. Participates in collisions but does not move under solver forces.
FLIP Object
Fluid container that works with FLIP Solvers to simulate liquids and splashes.
Common pitfalls
  • • Wrong object type: assigning Static when you intended dynamic will keep the object immobile.
  • • Missing SOP Path: the object will have no geometry to simulate.
  • • Ignoring packing: unpacked geometry can be slower and use more memory.
Key Takeaway

Pick the object type to match behavior and verify the SOP Path. Packing improves performance for rigid simulations.
