Force nodes — gravity, wind, and turbulence
Forces change velocities and accelerations which solvers integrate across frames.
Gravity Force
Applies constant downward acceleration. The primary driver for falling objects in many sims.
Wind Force
Adds directional force to create sweeps or consistent flow across objects and particles.
Turbulent Force
Introduces randomness and small-scale motion details. Useful for realism when used subtly.
How forces are applied
For a force to influence an object, it must be part of the merged input feeding the solver or otherwise connected so the solver considers it when computing the next frame. Always confirm the Merge node includes both forces and objects feeding the solver.
Common mistake

Adding a Gravity Force node but not merging it with the solver input will result in no visible effect. Check your Merge node connections first.
