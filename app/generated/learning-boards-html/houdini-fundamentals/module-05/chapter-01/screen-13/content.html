Assessment › Quiz & Extension
Assessment idea and next steps
Two short questions and a practical extension you can complete to demonstrate mastery.
Quiz question 1
Which DOP object node would you use for a table that should not move? Explain briefly.
Correct: Static Object — participates in collisions but remains immobile.
Quiz question 2
What is the primary purpose of the DOP Network and what do you see inside it when you dive in?
Answer: A container for the running simulation; inside are objects, forces, solvers and merge connections that together drive the sim.
Extension task
Create two boxes: one driven only by Gravity, the other driven by Gravity plus Wind. Use appropriate Object nodes, Merge them into an RBD Solver, run the simulation, and explain the difference in motion and why it occurred.
Key Takeaway

Use the quiz and extension to verify you not only know node names but can assemble and explain a working DOP Network.
