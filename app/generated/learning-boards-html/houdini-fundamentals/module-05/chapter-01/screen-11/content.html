Hands-on Activity › Sphere Fall
Create a sphere falling onto a ground plane
Follow these exact steps to build and run the simulation.
SOP setup
  1. Create Geometry node: rename to sphere_fall_sim.
  2. Inside, add Sphere: Radius 0.5, Primitive Type Polygon.
  3. Add Grid: Size 10, 10 for ground.
  4. Merge Sphere and Grid.
DOP Network creation
  1. Create a DOP Network node and connect the Merge output into its first input.
  2. Dive inside the DOP Network.
  3. Add RBD Packed Object and set SOP Path to the Sphere node.
  4. Add Static Object and set SOP Path to the Grid node.
  5. Add Gravity Force and RBD Solver, Merge the three, and connect Merge to the Solver and Solver to Output.
Run and verify
Return to the DOP Network container and play the timeline. Expect the sphere to fall and collide with the grid. If not, verify SOP Paths, object types, and Merge connections.
Key Takeaway

Follow the checklist: SOP geometry → DOP object paths → Merge inputs → Solver. This sequence ensures your simulation runs predictably.
