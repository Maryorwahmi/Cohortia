Key Concepts — What to Remember
Three compact concept cards to anchor the chapter's core ideas.
DOPs (Dynamics Operators)
The context for running time-varying simulations that update object state per frame.
SOPs (Surface Operators)
Procedural nodes for creating and manipulating geometry; they remain separate from simulation logic.
DOP Network
The container node that holds objects, forces, solvers, and merges to run a simulation.
Summary takeaway
Remember: match solver to object type, merge needed inputs, and keep geometry in SOPs while behaviour lives in DOPs.
