Navigating DOPs and common mistakes
A practical checklist to isolate and fix simulation problems.
Stepwise debug checklist
  1. Pause and inspect object properties (velocity, mass).
  2. Confirm SOP Path on each Object node.
  3. Open the Merge node and verify all inputs are present.
  4. Check solver type matches object types.
Isolation technique
Recreate the problem with a minimal scene: one object, one force, one solver. If it works there, add complexity until the failure reappears — this points to the breaking connection.
Common trap

Assuming merges are implicit. Always open and visually confirm merged inputs; a single missing input often explains why a force or object has no effect.

Quick verification question
If your sphere does not fall, which checks do you perform first? The correct order: check SOP Path, check object type, check Merge inputs, then check solver connectivity and per-frame properties.
