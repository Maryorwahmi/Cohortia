Node Roles and Best Practices
Three concise reminders to speed simulation setup and debugging.
Solver selection
Pick the solver type that matches your simulation domain for correct behaviour and performance.
Object configuration
Set SOP Paths, choose RBD vs Static vs FLIP, and tune mass and collision settings.
Merge verification
Confirm all intended objects and forces feed the solver via the Merge node to avoid silent failures.
Final prompt
If a simulation fails, first check SOP Path, object type versus solver, and Merge inputs. These three quick checks solve many issues.
