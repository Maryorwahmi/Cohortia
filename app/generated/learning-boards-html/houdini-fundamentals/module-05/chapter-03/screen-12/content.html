Tuning, performance and common mistakes
Which knobs affect quality and speed, and where to look when things fail.
Parameters to balance
  • Birth Rate — visual density vs cost
  • POP Grains Radius — packing vs neighborhood cost
  • Solver substeps — collision accuracy vs time
Debug checklist
  1. Confirm Static Object SOP Path and merges.
  2. Reverse normals if container behaves oddly.
  3. Test with low particle counts before scaling.
Optimization cards
Profile: reduce birth rate and search radius to speed iterations
Tweak: use solver substeps only when collisions need it
Warning: very high birth rate + large radius = long sim times
Key Takeaway

Tune gradually. Validate behavior at low counts, and then scale up once collisions, grains, and solver settings are stable.
