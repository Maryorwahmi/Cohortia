Definition
Particle attributes and POP Wrangle
Attributes let you read and write particle state to control both behavior and shading.
Common attributes
  • P — position vector
  • v — velocity vector
  • id — unique identifier
  • age — lifetime progress
  • pscale, Cd — visual attributes
Best practice
Use id for stable randomness and age to drive transitions such as size or color over lifetime.
POP Wrangle example
// inside a POP Wrangle
float life = @life; // particle lifetime
float a = @age / life; // normalized age from 0 to 1
@pscale = fit(a, 0, 1, 0.1, 0.0);
@Cd = lerp({1,0.9,0.7}, {0.2,0.2,0.25}, a);
// use @id for per-particle seeded randomness
Tip: Map age to both pscale and Cd for smooth fade-out effects
Key Takeaway

Attributes are the levers for behavior and look. Use POP Wrangle to compute them every step and test with low particle counts.
