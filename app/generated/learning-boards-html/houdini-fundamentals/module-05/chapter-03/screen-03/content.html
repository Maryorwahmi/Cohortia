Learning Objectives — Lab Focus
Stepwise tasks you'll complete in the guided walkthrough.
Bloom stages: Learn → Understand → Apply → Master
Geometry setup
Create a tube with inward normals and a small sphere positioned above it as OUT_EMITTER to act as the source.
VERIFIED COMPETENCY MILESTONE
DOP & POP network
Wire the tube and emitter into a DOP Network, create a POP Network, and place POP Source, POP Grains, and POP Solver inside.
VERIFIED COMPETENCY MILESTONE
Forces & colliders
Add gravity and static object colliders. Ensure mergers include POP Network, colliders, and forces into the DOP solver.
VERIFIED COMPETENCY MILESTONE
Playback & import
Use DOP Import to fetch geometry for viewport playback and tweak birth rate and grain radius for visual control.
VERIFIED COMPETENCY MILESTONE
