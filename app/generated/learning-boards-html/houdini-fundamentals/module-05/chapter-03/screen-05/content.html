Process Flow
POP Network in a DOP Network
How SOPs, DOPs, POP Network and the solver interact to simulate particles.
Step diagram (cards)
1. Create SOP geometry: emitter and collider. Add a Null named OUT_EMITTER.
2. Create a DOP Network and connect SOPs to its inputs as scene objects.
3. Inside DOP, add a POP Network and place POP Source, POP Grains and POP Solver.
4. Merge POP Network, colliders, and forces into the DOP Output for simulation.

Common mistake

Forgetting to set SOP Path on Static Object or not merging colliders means particles will not collide. Verify SOP paths and merge inputs first.
