Process Flow
Guided lab: assemble the simulation
Step-by-step tasks to get particles pouring and piling inside a tube.
SOPs — Geometry
  1. Create Geometry node named pop_grains_sim. Add Tube: Height 2, Radius 1, End Caps On.
  2. Add Reverse SOP after Tube to ensure inward normals for collisions.
  3. Create Sphere: Radius 0.2, Polygon primitive; translate Y to 2.5 and add Null named OUT_EMITTER.
DOP & POP
  1. Create DOP Network. Connect Tube to first input, OUT_EMITTER to second input.
  2. Inside DOP, add POP Network. Inside POP Network add POP Source (Surface), POP Grains (Radius 0.05), POP Solver.
  3. Add Static Object pointing to reversed tube SOP path, Gravity Force, Merge everything into DOP Output.
  4. Add DOP Import set to Fetch Geometry from popsolver1 to visualize results.
Practice checkpoints
Checkpoint 1: Particles emit and fall under gravity
Checkpoint 2: Particles collide and accumulate inside tube
Checkpoint 3: Adjust Birth Rate and Radius to change density and packing
Key Takeaway

Assemble geometry, DOP and POP networks carefully. Verify SOP paths, normals and merges before scaling particle numbers.
