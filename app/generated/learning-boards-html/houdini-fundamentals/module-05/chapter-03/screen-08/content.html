Collisions: Static vs Dynamic
Make particles interact with fixed or moving geometry and tune collision responses.
Static Object
Use for immovable colliders such as a container. Set SOP Path to the container geometry and ensure normals point inward if required.
RBD Packed Object
Use when the collider itself should move or break during simulation and be part of the DOP solve.
POP Collision Detect
Use in the POP Network to control bounce and friction per particle.

Example check
If particles pass through a tube, verify the Static Object SOP Path, reversed normals, and solver substeps.
Tip: Reverse normals for an inward-facing container
Pitfall: Missing merge of collider into DOP Network
Key Takeaway

Pick the right collider type for the job and confirm SOP paths, normals and solver settings when collisions fail.
