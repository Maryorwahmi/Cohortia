Learning Objectives
Understand, configure, and control Houdini particle systems.
Bloom stages: Learn → Understand → Apply → Master
01
POP fundamentals
Learn to define particle systems and POP Network structure. Knowing this prevents common setup mistakes and helps you plan simulations for performance.
VERIFIED COMPETENCY MILESTONE
02
Configure emission
Create a POP Source: choose an emission type, set birth rate and life expectancy, and establish initial velocity to shape motion from the start.
VERIFIED COMPETENCY MILESTONE
03
Forces & collisions
Apply POP Wind, POP Drag, gravity and add static or dynamic colliders so particles interact realistically with the scene.
VERIFIED COMPETENCY MILESTONE
04
POP Grains & attributes
Use POP Grains to simulate granular behavior and edit P, v, id, age, pscale and Cd via POP Wrangle to vary appearance over lifetime.
VERIFIED COMPETENCY MILESTONE
