Definition
POP Source — Emission control
Set emission type, birth rate, life, and initial velocity to shape particle births.
Key parameters
  • Emission Type: surface, points, or volume
  • Birth Rate: particles per second
  • Life Expectancy: particle lifetime
  • Velocity: initial speed and direction
Checker
Start with a low birth rate, verify normals and SOP path, then increase rate for final render.
Concrete example
Emitter: Sphere
Set POP Source → Emission Type: Surface, SOP Path: /obj/pop_grains_sim/OUT_EMITTER, Birth Rate: 5000.
Tip: Use 'Scatter' for even distribution
Pitfall: Very high Birth Rate during debugging
Key Takeaway

Tune emission first: birth rate and life determine visual density; velocity shapes initial motion.
