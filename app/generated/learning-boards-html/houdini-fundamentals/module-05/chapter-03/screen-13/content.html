Hands-on challenge & reflection
Try parameter sweeps and observe the simulation trade-offs.
Step sequence
  1. Set Birth Rate to 500, play and observe.
  2. Increase to 2,000 then 5,000, note density vs performance.
  3. Set POP Grains Radius to 0.02, 0.05, 0.1 and compare piling.
  4. Toggle solver substeps to observe collision stability.
Reflection prompts
Which setting had the largest visual impact?
When did solver substeps noticeably improve behavior?
What combination produced the best balance of look and speed?
Key Takeaway

Active experimentation is the fastest way to learn particle trade-offs. Test small, iterate, then scale up once settings are reliable.
