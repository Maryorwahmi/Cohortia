Module 5 › Chapter 5.2 › Learning Objectives
01
Tune solver accuracy
Adjust Substeps and Collision Iterations to reduce interpenetration. Higher values increase stability but cost time.
VERIFIED COMPETENCY MILESTONE
02
Choose collision shapes
Use Convex Hull or BBox for speed, Concave for complex accuracy, and proxy geometry when needed to balance accuracy with cost.
VERIFIED COMPETENCY MILESTONE
03
Cache simulations
Import results with DOP Import and write them with File Cache so you can iterate without re-simulating the DOP network each play.
VERIFIED COMPETENCY MILESTONE
04
Optimize geometry & attributes
Reduce piece count, check scale (Houdini: 1 unit = 1 meter), and ensure mass and density attributes are reasonable for realistic motion.
VERIFIED COMPETENCY MILESTONE
Practical checklist
  • Confirm SOP Path on RBD Packed Object and Static Object nodes.
  • Run a short simulation with higher Substeps if pieces interpenetrate.
  • Write a File Cache after a successful run to lock results for shots and renders.
Hint
Small changes to mass, padding, or substeps often fix visible artifacts faster than rebuilding geometry. Test increments rather than large jumps.
