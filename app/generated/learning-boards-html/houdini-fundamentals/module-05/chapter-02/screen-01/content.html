RBDs: Shattering and Collisions
Prepare fractured geometry, bring it into DOPs as packed objects, and tune the solver for reliable collisions and performance.
In this chapter you’ll follow a hands-on flow: fracture in SOPs, assemble and pack pieces, create an RBD Packed Object, add a Static Object and Gravity, run the RBD Solver, then import and cache results. Each step trades off accuracy and performance — we’ll make those tradeoffs explicit.
In this lesson
Fracture with Voronoi, pack with Assemble, configure RBD Packed Object and RBD Solver, handle collisions, then cache the simulation for iteration.
