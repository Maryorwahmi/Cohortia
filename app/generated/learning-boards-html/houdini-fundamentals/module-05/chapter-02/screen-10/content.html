Node layout
Assemble the core nodes in a Merge, then feed them into the RBD Solver.
# Inside DOP Network
RBD Packed Object (SOP Path = /obj/shatter_sim/assemble1)
Static Object (SOP Path = /obj/shatter_sim/grid1)
Gravity Force
Merge: connect Packed, Static, Gravity
RBD Solver: input = Merge
Output: RBD Solver -> Output
Key Takeaway

Follow the Merge→Solver pattern. Verify SOP Paths and Gravity orientation if nothing moves.

Scenario card
If shards do not collide with the ground, ensure the Static Object's SOP Path points to the correct grid and that its collision shape is set to Concave if the grid is complex. Often the Ground is simple and BBox/Concave are both fine.
Check list
  • SOP Path for RBD Packed Object correct?
  • Gravity Force enabled and oriented?
  • Merge node includes all objects and forces?
