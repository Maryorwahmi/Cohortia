Module 5 › Chapter 5.2 › Learning Objectives
01
Prepare fractured geometry
Break geometry into pieces using Scatter and Voronoi so each shard becomes simulatable. Proper fractures avoid glued polygons and unpredictable collisions.
VERIFIED COMPETENCY MILESTONE
02
Configure RBD Packed Object
Point the SOP Path to your packed Assemble result, set Initial State when needed, and select a Collision Shape that balances speed and accuracy.
VERIFIED COMPETENCY MILESTONE
03
Implement collision detection
Use Static Objects for immobile collision geometry and verify the collision shapes of dynamic pieces so objects interact rather than pass through each other.
VERIFIED COMPETENCY MILESTONE
04
Troubleshoot common issues
Identify and fix interpenetration and empty objects by checking Substeps, Collision Padding, SOP Path, mass attributes, and gravity orientation.
VERIFIED COMPETENCY MILESTONE
