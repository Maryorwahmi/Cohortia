Assemble: pack geometry
Packing creates one primitive per shard, which is what the RBD Packed Object expects.
Important flags
  • Create Name Attribute — keeps piece identity for later targeting.
  • Pack Geometry — required for RBD Packed Object to read pieces efficiently.
  • Leave velocity attributes if you need per-piece initial motion.
Practical example: 50 fractured shards becomes 50 packed primitives for fast DOP import and simulation.
Misconception: Packing removes geometry detail. It does not; it changes storage and references but the rendered geometry remains available when needed.
Key Takeaway

Use Assemble + Pack for performance and reliable DOP imports; keep identifying attributes for post-sim operations.

Quick checklist
  • Confirm Pack Geometry is enabled on Assemble.
  • Enable Create Name Attribute for piece lookup and caching.
  • Check that packed pieces retain any necessary per-piece attributes like mass.
When sending to DOPs, point the RBD Packed Object’s SOP Path to the Assemble output. If you see empty dynamics, re-check this path first.
