Shape trade-offs
Choose shapes based on accuracy needs and piece counts.
Convex Hull
Fast and stable for most pieces; ignores concavities but is the usual default for shards.
BBox
Proxy shape for quick iteration or very small debris where cost must be minimal.
Concave
Accurate but expensive. Best used for static complex geometry or selective pieces only.
Key Takeaway

Mix collision shapes: convex for dynamics, concave only where surface accuracy is essential, and BBox for fast proxies.

Scenario card
A detailed environment like a ruined building can be a single Static Object with Concave collision; dynamic debris created by fracture should usually use Convex Hull. This hybrid approach keeps collision fidelity where it matters and performance where it counts.
Quick tests
  • Run with Convex Hull for all pieces, measure time and artifacts.
  • Switch a few problem pieces to Concave and compare visual difference to cost.
