Module 5 › Chapter 5.2 › Performance Strategies
Optimization checklist
Reduce fracture count where silhouette detail is not needed.
Use Convex proxies for many dynamic pieces; keep Concave for static collision geometry.
Confirm scene scale (1 unit = 1 meter) and sensible mass/density attributes.
Cache final simulations with File Cache for reproducible playback.
Key Takeaway

Optimization is iterative: validate on a subset, choose proxies, tune solver, then cache the final approved run.

Scenario
For a wide shot with many small debris pieces, prefer convex proxies and a slightly lower shard count. For a close-up, increase shard detail only in the area that will be visible to the camera, then cache and composite.
Pro tip
Keep a versioned cache strategy: quick low-res caches for layout, high-res caches for final render, and keep the solver settings documented for each.
