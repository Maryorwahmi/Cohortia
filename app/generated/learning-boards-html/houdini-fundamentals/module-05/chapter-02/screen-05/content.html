Step-by-step fracture
Use this repeatable SOP sequence when preparing a rigid body for shattering.
  1. Create a Box or Sphere and set realistic size (Houdini: 1 unit = 1 meter).
  2. Scatter points on the surface or volume; set Force Total Count to your desired shard density.
  3. Feed geometry and points into Voronoi Fracture to output pieces.
  4. Add Peak to separate pieces slightly for visual clarity and solver stability.
  5. Run Assemble and enable Pack Geometry and Create Name Attribute.
Key Takeaway

Packing fractured pieces is essential. The SOP sequence above makes the transition to DOPs reliable and performant.

Practical example (SOP steps)
# Inside a new Geometry node named shatter_sim
Box size 2,2,2
Scatter input -> Force Total Count = 50
Voronoi Fracture: input 1 = Box, input 2 = Scatter
Peak: Distance = 0.01
Assemble: Create Name Attribute = on, Pack Geometry = on
Common mistake: forgetting to pack. If pieces remain unpacked, the DOP RBD Packed Object may not reference them correctly, or simulation performance will suffer.
