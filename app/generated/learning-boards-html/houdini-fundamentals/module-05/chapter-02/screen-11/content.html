Import and cache steps
Bring simulation results into SOPs and save them to disk for iteration.
# In SOPs after DOP Network
DOP Import:
  DOP Network = ../dopnet1
  DOP Node = /obj/shatter_sim/dopnet1/rbd_solver1
  Import Style = Fetch Geometry from DOP Network

File Cache:
  Load From Disk = Manual
  Save to Disk =  (click to write)
Key Takeaway

Cache finalized simulations to avoid re-simulating and to guarantee consistent playback for lighting and rendering work.

Practical note
Use descriptive cache filenames that include scene name and frame ranges. If you update solver settings, clear or version caches so you can reproduce earlier results if needed.
Common mistake
Relying on live DOPs for final renders can cause non-deterministic behavior; always bake to disk for final output.
