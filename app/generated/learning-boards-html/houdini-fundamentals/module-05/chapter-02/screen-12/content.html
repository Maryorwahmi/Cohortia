Module 5 › Chapter 5.2 › Troubleshoot
Issue & Fix cards
Interpenetration
Increase Substeps, raise Collision Iterations, or add Collision Padding to problem objects.
No collisions / empty objects
Check SOP Path on RBD Packed Object and Static Object nodes first; incorrect paths are the top cause.
Unrealistic motion
Verify mass/density attributes and confirm Gravity Force is correctly oriented and active.
Pro Tip

Isolate problems by testing a single piece and gradually expanding to the full set. This identifies whether the issue is geometry-specific or global.

Guided check sequence
  1. Confirm SOP Path(s) and that packed primitives exist.
  2. Play a few frames with Substeps=1; raise to 2 or 3 if tunneling occurs.
  3. Add Collision Padding and re-test.
  4. Check mass attributes and gravity orientation.
Keep notes of which tweak fixed the issue. This prevents later undoing a useful change and helps you understand solver sensitivity.
