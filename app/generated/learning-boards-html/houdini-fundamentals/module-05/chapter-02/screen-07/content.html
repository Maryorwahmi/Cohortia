Module 5 › Chapter 5.2 › RBD Packed Object
Node essentials
RBD Packed Object consumes packed geometry and exposes per-object settings to the solver.
SOP Path
Set the path to your Assemble output; missing this is the most common setup error.
Initial State
Define initial velocity or spin if pieces must start with motion.
Collision Shape
Choose Convex Hull, BBox for speed, or Concave for detail where necessary.
Key Takeaway

Always verify the SOP Path and prefer convex approximations for many-piece sims; use concave shapes sparingly.

Example parameters
SOP Path: /obj/shatter_sim/assemble1
Collision Shape: Convex Hull (default fast option)
Mass: set per-piece attribute or use the node's mass settings
Quick test: run a short simulation with Convex Hull; if pieces slide unrealistically on complex surfaces, test Concave for a single piece to evaluate cost versus benefit.
