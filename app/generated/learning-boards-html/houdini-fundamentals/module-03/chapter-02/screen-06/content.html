Module 3 › Chapter 3.2 › Attribute Access
Access patterns
Read
Use @name to read the current element's attribute value, for example @P or @Cd.
Write
Assign values to attributes directly: @P *= 2; or @Cd = {1,0,0};
Declare
Create typed attributes with prefixes: f@height, v@velocity, i@id, s@name.
Example
i@custom_id = @ptnum; creates an integer attribute storing the point index for export.
Common mistake
Assigning wrong types, such as @Cd = 0.5, will either error or produce an unexpected result. Use a vector for colors.
Quick code
// Declare a float and a vector attribute
f@height = 0.5;
v@myVec = {1, 0, 0};

// Create an exportable ID
i@custom_id = @ptnum;
Key takeaway
Be explicit with types. Use the Geometry Spreadsheet to confirm the attribute class and type after declaration.
