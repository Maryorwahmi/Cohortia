if / else example
// Color points based on Y threshold
if (@P.y > 0.5) {
  @Cd = {1, 0, 0};
} else {
  @Cd = {0, 0, 1};
}
This clearly separates the two color branches and is easy to read and debug in the spreadsheet.
for loop use-case
// Average a small fixed set of values inside one execution
float sum = 0;
for (int i=0; i<4; i++) {
  sum += rand(@ptnum + i);
}
float avg = sum / 4.0;
f@local_avg = avg;
Use loops for bounded internal work. Avoid large or unbounded loops on per-element code to keep performance predictable.
Concrete example
Use if/else to separate tall and short points, then compute a nearby-sample average with a small fixed for loop to smooth values.
