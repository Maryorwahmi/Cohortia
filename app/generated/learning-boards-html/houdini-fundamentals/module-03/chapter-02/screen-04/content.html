VEX — a concise definition
VEX runs a program for each geometry component. It uses typed variables and direct attribute access to manipulate data efficiently.
Data types
float, int, vector, vector2, vector4, string and typed attribute prefixes like f@, i@, v@.
Attribute access
Use the at sign to read and write attributes such as @P, @Cd, @N in the running instance.
Performance
VEX is optimized for per-element execution and is preferable for large, repeated operations.
Concrete example
Move every point upward slightly by changing its y coordinate with a single VEX line.
Key takeaway
Small VEX programs replace many nodes and run efficiently across geometry.
Analogy
Treat VEX as a per-row formula in a spreadsheet: the same formula runs for each row, but it can read and write that row's values.
Common misconception
Learners often assume loops are required to process all points. The wrangle already executes per component, so loops are only needed for inner iteration within a single element's context.
Short code panel
// Move each point upward by 0.1
@P.y += 0.1;

// Assign a random color per point
@Cd = rand(@ptnum);
