Assessment code (visual)
// Seeded random, remapped to -0.2..0.2
float offset_x = fit(rand(@ptnum + ch('seed')), 0, 1, -0.2, 0.2);
@P.x += offset_x;
Set the Group parameter on the wrangle to offset_points so only those points run. The ch seed parameter allows repeatable variation or animation control.
Checklist
  • Group: offset_points
  • Use rand with @ptnum + seed
  • Use fit to map to -0.2..0.2
Misconception
Avoid using an if inside a full-point run to filter points; using the Group parameter is clearer and more efficient.
