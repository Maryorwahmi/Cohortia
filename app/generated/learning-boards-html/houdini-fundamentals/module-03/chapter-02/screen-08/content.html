ch() — exposed parameter
Create a node parameter you can tweak without editing code. Useful for artist control and iterative testing.
Pattern
float scale = ch('scale_factor'); @P *= scale;
rand(), fit(), set()
rand produces floats; fit remaps ranges; set constructs vectors from floats for color or position components.
// remap Y from -0.5..0.5 to 0..1
float t = fit(@P.y, -0.5, 0.5, 0, 1);
// color from random seeds
@Cd = set(rand(@ptnum), rand(@ptnum+1), rand(@ptnum+2));
Concrete example
Use ch to expose a scale slider, fit to remap a Y position into that slider's domain, and rand to seed color variation — this produces a controllable, visually varied result.
