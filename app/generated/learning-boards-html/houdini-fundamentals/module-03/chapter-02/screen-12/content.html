Modular wrangle pattern
Split responsibilities: displacement wrangle, color wrangle, export wrangle. Keep each node small and documented so you can re-order or bypass nodes during iteration.
Expose a limited set of ch parameters for artists to control without editing code.
After geometry changes, add a Normal SOP to maintain correct shading and a Color SOP to visualize Cd.
Use explicit attribute names for downstream clarity and export compatibility.
Concrete example
Wrangle A: scale points; Wrangle B: assign @Cd and i@custom_id; Normal SOP; Color SOP reading @Cd.
Key takeaway
Design wrangles as modular steps and verify with the spreadsheet to keep networks maintainable.
