Module 3 › Chapter 3.2 › Debugging Pitfalls
Checklist of common mistakes
  • Missing the @ prefix when referencing attributes.
  • Assigning wrong types, e.g., float to a vector attribute.
  • Incorrect Run Over setting (points vs primitives vs detail).
  • Unbounded loops inside per-element execution causing slowdowns.
Pitfall example
Attempting @Cd = 0.5; will not produce valid RGB—use a vector form instead.
Strategies to verify
Open Geometry Spreadsheet and check attribute names, classes, and types after running the wrangle.
Expose temporary channels with ch to adjust values interactively and watch results change.
Write intermediate attributes such as f@debugVal to capture expressions for inspection.
Key takeaway
Small tests and the spreadsheet are the fastest way to find whether a problem is syntactic, type-related, or a Run Over mismatch.
