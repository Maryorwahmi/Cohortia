Module 3 › Chapter 3.2 › Performance Tips
Practical rules
  • Avoid loops that iterate over all elements inside a per-element wrangle.
  • Use built-in functions and specialized SOPs for heavy topology work.
  • Write only necessary attributes; temporary debug attributes cost memory.
Testing strategy
Prototype on smaller grids, test timings, and profile expensive steps. If a calculation is global, move it to a detail wrangle to run once.
Key takeaway
Plan algorithmic complexity: per-element work times element count determines cost, so avoid hidden multiplicative work inside wrangles.
