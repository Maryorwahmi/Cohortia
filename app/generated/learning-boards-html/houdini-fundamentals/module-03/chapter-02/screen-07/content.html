Move points upward
// Move every point upward by 0.1
@P.y += 0.1;
This line modifies the running point's y coordinate directly. When combined with a parameter channel, you can scale this movement without changing code.
Example outcome
A grid will visibly rise and create displacement that you can visualize in the viewport.
Assign random color per point
// Random color using point number as seed
@Cd = rand(@ptnum);

// Ensure proper vector form when needed
@Cd = set(rand(@ptnum), rand(@ptnum+1), rand(@ptnum+2));
rand returns a float; using set or a vector literal ensures @Cd receives a vector. Seeding with different offsets produces RGB variety.
Key takeaway
Use deterministic seeds like @ptnum to create repeatable randomness across runs.
