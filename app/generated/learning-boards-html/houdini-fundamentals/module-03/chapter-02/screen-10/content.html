Module 3 › Chapter 3.2 › Hands-on Grid
Starter VEX (visual)
// Create a channel
float scale_intensity = ch('scale_intensity');

// Remap Y and scale
float y_scale = fit(@P.y, -0.5, 0.5, 0.5, 1.5);
@P *= y_scale * scale_intensity;

// Assign random color
@Cd = rand(@ptnum);

// Add ID for export
i@custom_id = @ptnum;
Adjust scale_intensity on the node to see immediate changes. Add a Color SOP After the wrangle to pick Color Type: From Attributes, and add a Normal SOP to recalculate normals.
Checklist
  • Grid: Rows and Columns = 50
  • Wrangle: Run Over = Points
  • Use ch to expose scale_intensity
  • Verify Cd and custom_id in Geometry Spreadsheet
Real-world benefit
This pattern produces an adjustable procedural surface that exports per-point metadata for downstream tools.
