Module 3 › Chapter 3.1 › Color faces on a box
Procedure
1) Add Box SOP inside a Geometry node.
2) Add Group SOP, set Group Type = Primitives, select a face, name it face_red.
3) Add Attribute Create: Class = Vertex, Name = Cd, Type = Vector, Size = 3, Value = 1,0,0; Group = face_red.
4) Repeat for face_blue with Value = 0,0,1.
5) Add Color SOP set to From Attributes and open Geometry Spreadsheet to verify Cd values.
Scenario card
You want two faces colored differently for export to a game engine that reads vertex color attributes. This workflow ensures each face's vertices carry the intended color.
Key Takeaway

Groups + Attribute Create = reproducible per-area edits. Use Vertex class for per-face vertex color when points are shared.
