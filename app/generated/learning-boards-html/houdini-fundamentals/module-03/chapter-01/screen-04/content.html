Attributes: the data layer
Named values stored on geometry components
Attributes define geometry behavior. They are typed and scoped. Common attribute roles include:
  • P — position vector with X, Y, Z coordinates.
  • N — normal vector used for shading and direction-based operations.
  • Cd — color vector for RGB values.
  • uv — 2D texture coordinate stored as a vector of size 2.
Analogy
Attributes are like tags or spreadsheet columns attached to geometry rows; you can filter, sort, and act on them downstream.
Concrete example
Assign Cd as a vertex attribute for a face so each face can have a different color even when points are shared.
// Visual: Attribute Create settings
Class: Vertex
Name: Cd
Type: Vector
Size: 3
Value: 1, 0, 0  // red for that group's vertices
Key Takeaway

Attributes are flexible; match class and type to the role you need so downstream nodes behave correctly.
