Module 3 › Chapter 3.1 › The four attribute classes
Class comparison
Choose the class that matches your desired data granularity
Point
Stored per point. Use for position and point-wide properties.
Primitive
Stored per primitive. Use for material IDs or face-level flags.
Vertex
Stored per vertex (point+primitive). Use for UVs or per-face vertex colors on shared points.
Detail
Single value for the whole geometry. Use for project_version or global scale factors.
Quick decision flow
  1. Does it vary per face even when points are shared? Use Vertex.
  2. Is it a property of a whole polygon? Use Primitive.
  3. Is it tied to a point location or velocity? Use Point.
  4. Is it a single global value? Use Detail.
Misconception check: vertex is not the same as point — vertex stores the combination of point and primitive.
