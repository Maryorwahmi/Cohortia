Understanding Attributes and Groups
How geometry carries data and how to target parts of a mesh

Attributes are pieces of data attached to geometry. Groups name selections so you can apply operations to only those components. Both are essential to procedural modeling and simulations because they let you control behavior without manual edits.

In this lesson
Identify attribute classes and create attributes with Attribute Create SOP.
Coming up
Use groups to isolate faces and assign vertex colors.
Why it matters
Attributes + groups make your node networks flexible and data-driven.
Visual concept
Attributes (P, N, Cd, uv) + Groups (named masks)
Point / Primitive / Vertex / Detail — each stores data at a different geometric granularity.
Groups let nodes operate only on selected components, like extruding only the panels in a named group.
