Attribute Create parameters
What each field controls
Class — pick point, primitive, vertex, or detail.
Name — attribute identifier, e.g., Cd or project_version.
Type & Size — integer, float, string, or vector components.
Value — the default value to write for the attribute.
Group — optional; limits writes to a named selection.
Practical example
// To color a face red for only that face's vertices
Class: Vertex
Name: Cd
Type: Vector
Size: 3
Value: 1, 0, 0
Group: face_red
Common mistake

Setting Class to Point instead of Vertex will make shared points carry the same color across faces.
