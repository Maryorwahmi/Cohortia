How to create groups
Manual selections and procedural methods
  • Select primitives in the viewport and name the group (manual).
  • Use bounding boxes or ranges to select points procedurally.
  • Use normals/angle to select sharp edges or oriented faces.
  • Use expressions for parametric groups that update automatically.
Practical scenario
Create damaged_panels with Group SOP by angle or mask. Then use Attribute Create with Class = Primitive and Group = damaged_panels to set material_type = "damaged" so only those panels use the damaged material downstream.
