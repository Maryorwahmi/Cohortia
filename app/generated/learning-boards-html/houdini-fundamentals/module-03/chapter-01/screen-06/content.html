Module 3 › Chapter 3.1 › Built-in attributes
Common attribute roles
How built-ins are typically used
P — position
Vector3. Stores point coordinates.
N — normal
Vector3. Surface orientation for shading and directional ops.
Cd — color
Vector3. RGB values, often Vertex for per-face colors.
uv — texture coord
Vector2. UV layout, often stored per vertex to vary across faces.
v — velocity
Vector3. Used by simulations; typically per-point when representing motion per vertex position.
Quick example
Set Cd as Vertex for red on a face: Attribute Create → Class: Vertex → Name: Cd → Type: Vector → Value: 1,0,0
Misconception check: detail Cd will not color per-face; it is a single color for the whole geometry.
