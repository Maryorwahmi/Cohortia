Module 3 › Chapter 3.1 › Combining attributes & groups
Pattern: select → annotate → act
Define where, attach what, then let nodes react
  1. Create selection logic using Group SOPs (e.g., curvature, bounding box, manual).
  2. Use Attribute Create to write attributes for that selection (e.g., material_type, Cd).
  3. Downstream nodes read attributes and perform actions like shading, extrusion, or simulation.
Example: rock chipping
Use curvature to group sharp edges, name it high_curvature, then set a primitive attribute chipped = 1 for that group and run a bevel or Vellum simulation only on chipped primitives.
Key Takeaway

Design your networks so selections and data are separate — this supports reuse and safer edits.
