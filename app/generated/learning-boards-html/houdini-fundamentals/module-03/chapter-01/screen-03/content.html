Hands-on workflow
Box → Group → Attribute Create → Color SOP → Spreadsheet
Create a Box SOP and enter its node context.
Use Group SOP set to Primitives and select a face; name it descriptively.
Use Attribute Create, set Class to Vertex for Cd, and assign RGB values for that group's vertices.
Place a Color SOP set to From Attributes and open the Geometry Spreadsheet to verify attributes.
Common pitfalls
  • Choosing Point class when Vertex is required will make shared points use the same value across primitives.
  • Not naming groups leads to confusion when networks grow; use descriptive names like face_red.
  • Expecting detail attributes to vary per face — detail is global and stored once for the whole geometry.
