Module 3 › Chapter 3.1 › Key Concepts
Attributes
Named data on geometry that nodes read and write to control appearance and behavior.
Classes
Point, Primitive, Vertex, Detail — choose based on desired granularity.
Groups
Named selections used to scope operations and write attributes only where needed.
Summary
Use groups to select, Attribute Create to annotate, and the Geometry Spreadsheet to verify. Keep names clear and classes correct.
