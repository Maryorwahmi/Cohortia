Module 3 › Chapter 3.1 › Troubleshooting & best practices
Common mistakes
  • Using Point when Vertex is required for per-face variation.
  • Typo in attribute name so downstream nodes can't find it.
  • Leaving Group blank and unintentionally writing the whole geometry.
Quick fix
Open Geometry Spreadsheet and inspect the correct class tab to confirm the attribute exists where you expect it.
Best practices
  • Name groups descriptively: face_red, damaged_panels, high_curvature.
  • Use detail attributes for global metadata like project_version.
  • Document the purpose of custom attributes so other artists understand downstream uses.
Key Takeaway

Validate early, name clearly, and separate selection logic from data writes to keep networks maintainable.
