// Run Over: Points
// Read a primitive float and a detail integer
float prim_float_val = prim(0, "prim_id_float", @primnum);
i@prim_id_int = (int)prim_float_val; // explicit cast

int detail_scale = detail(0, "global_scale_int");

// Modify point position using the read values
@P.y += (float)i@prim_id_int * detail_scale * 0.1;

// Demonstrate implicit broadcast: float to color
@Cd = prim_float_val / 10.0; // becomes {v,v,v}
Step explanation
Read primitive and detail, cast primitive float to int for index-like use, then update point position and color.
Validation
Open Geometry Spreadsheet to verify prim_id_float, prim_id_int, global_scale_int and the modified @P and @Cd.
Misconception check
prim() won’t implicitly pick the primitive for you unless you supply the correct prim index; confirm with @primnum or computed mapping.
Key Takeaway

When reading across classes, always supply correct indexes and cast results explicitly when they feed logic or indexing operations.
