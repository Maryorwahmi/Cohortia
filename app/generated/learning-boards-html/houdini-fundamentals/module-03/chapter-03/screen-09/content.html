Module 3 › Chapter 3.3 › set*attrib
Architecture
Explicit cross-class writes
Index-based APIs let you write attributes precisely but require correct indexes and modes.
setpointattrib
setpointattrib(0, "Cd", ptIndex, {1,0,0}, "set"); writes color to a given point index.
setprimattrib / setvertexattrib
Same pattern: choose the right target class and supply appropriate index and mode.
setdetailattrib
Write a single global value; useful for configuration-like attributes.
Performance note

These functions are fine when necessary, but prefer direct assignments when writing to the running class to keep nodes efficient.

Example usage
// Inside a Primitive wrangle: write point colors for points of this primitive
int pts[] = primpoints(0, @primnum);
foreach (int pt; pts) {
  setpointattrib(0, "Cd", pt, {1,0,0}, "set");
}

// Create a detail integer
setdetailattrib(0, "global_scale_int", 2, "set");
Key Takeaway

Use set*attrib for targeted writes across classes but be mindful of cost and always validate created attribute names and types in the spreadsheet.
