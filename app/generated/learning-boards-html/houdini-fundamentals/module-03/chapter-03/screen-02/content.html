Learning Objectives
Four verified skills to demonstrate in the Geometry Spreadsheet and wrangle nodes.
Bloom: Learn → Understand → Apply → Master
01
Recognize VEX types
Identify when to use int, float, vector2, vector, vector4 and string in practical contexts like positions and colors.
Mnemonic: group types by dimensionality (scalar vs vector)
VERIFIED COMPETENCY MILESTONE
02
Explain conversions
Describe implicit broadcasting and truncation and perform explicit casts when precision matters.
Mnemonic: implicit is automatic, explicit is deliberate
VERIFIED COMPETENCY MILESTONE
03
Use attribute scope
Access and reason about point, primitive, vertex and detail classes and their access patterns with point, prim and detail functions.
Mnemonic: scope determines where the data lives
VERIFIED COMPETENCY MILESTONE
04
Write attributes safely
Apply setpointattrib, setprimattrib and related functions for targeted writes across classes while understanding performance trade-offs.
Mnemonic: set* functions act on indexes, direct @ access is faster when appropriate
VERIFIED COMPETENCY MILESTONE
