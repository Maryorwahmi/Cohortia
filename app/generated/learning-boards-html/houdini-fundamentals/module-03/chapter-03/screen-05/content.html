Comparison
Implicit broadcast vs truncation
See how VEX treats scalar-to-vector and scalar-to-int assignments differently.
Float → Vector (Broadcast)
Assigning 0.5 to @Cd yields {0.5,0.5,0.5}. Useful for uniform color or scale values.
Float → Int (Truncation)
Assigning 5.7 to an int becomes 5. This discards precision and can break index logic.
Practical checklist
  • Inspect the spreadsheet after conversions.
  • Prefer explicit casts when precision or indexing matters.
  • Name attributes to indicate their intended type and purpose.
Misconception

Implicit conversions will always preserve intent. Not true — they may silently alter values and should be used with awareness.

Concrete example
Broadcasting
@Cd = 0.2; // becomes {0.2, 0.2, 0.2}
Truncation
int x = 7.9; // x becomes 7
Key Takeaway

Use implicit conversions when helpful, but verify effects and prefer explicit casts for precise behavior.
