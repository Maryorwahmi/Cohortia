Module 3 › Chapter 3.3 › Explicit conversions
Process
Casting steps for safe conversions
  1. Decide target type and intent: discrete index or continuous measure.
  2. If converting to int, choose rounding behavior: truncation vs round() vs floor()/ceil().
  3. Construct vectors explicitly when you need multi-component values rather than relying on implicit broadcasts.
  4. Document casts with comments and type-hinted attribute names.
Pro tip

Use round() before casting when you want conventional rounding instead of truncation.

Code examples
// Cast float to int with rounding
float myFloat = 3.8;
int myInt = (int)round(myFloat); // becomes 4

// Build a uniform color from a float
float val = 0.2;
vector col = {val, val, val};
@Cd = col;

// Explicitly cast primitive read to point int
float prim_float_val = prim(0, "prim_id_float", @primnum);
i@prim_id_int = (int)prim_float_val;
Key Takeaway

Explicit casting makes your intent and numeric behavior explicit; prefer it for conversions that affect logic or indexing.
