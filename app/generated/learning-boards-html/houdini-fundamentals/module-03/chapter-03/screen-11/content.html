Guided lab: reproduce the Attribute Wrangle
Follow these steps and validate in the Geometry Spreadsheet.
Step 1 — Geometry setup
Create Grid SOP and two Attribute Create SOPs: prim_id_float (Primitive, Float, $PR) and global_scale_int (Detail, Integer, 2).
Step 2 — Wrangle code
Add Attribute Wrangle running over Points and paste the provided code to read prim and detail values, cast, and modify @P and @Cd.
// Run Over: Points
float prim_float_val = prim(0, "prim_id_float", @primnum);
i@prim_id_int = (int)prim_float_val;
int detail_scale = detail(0, "global_scale_int");
@P.y += (float)i@prim_id_int * detail_scale * 0.1;
@Cd = prim_float_val / 10.0;
Step 3 — Inspect
Open Geometry Spreadsheet and check Point, Primitive, and Detail tabs for the new attributes and their types.
Validation tip
If values look wrong, verify input index for prim/detail and attribute names for typos.
Key Takeaway

A small reproducible lab plus spreadsheet checks is the fastest way to verify type conversions and cross-class attribute access.
