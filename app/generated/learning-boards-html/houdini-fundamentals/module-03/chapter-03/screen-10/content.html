Common pitfalls and defensive patterns
Small habits save hours of debugging in complex networks.
Naming
Include type hints (_int, _float) and class context in attribute names.
Spreadsheet checks
Open the Geometry Spreadsheet and confirm attribute class and numeric type after changes.
Explicit casts
Cast when converting to indices or discrete categories to avoid truncation surprises.
Index validation
When using prim() or point(), ensure the index you supply refers to a valid component index.
Explicit vectors
Construct vectors from scalars explicitly when downstream code relies on particular channels.
Test small
Use minimal examples and spreadsheet verification as unit tests for your wrangles.
Key Takeaway

Adopt small defensive habits: naming, validation, and explicit casting drastically reduce debugging time.
