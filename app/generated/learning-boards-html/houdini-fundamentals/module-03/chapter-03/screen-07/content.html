Module 3 › Chapter 3.3 › Attribute scope
Definition
Point, Primitive, Vertex, Detail
Each class controls how data is stored and accessed and affects which functions you must use.
Point
Per-point data such as @P and per-point colors.
Primitive
Per-primitive data like material assignments.
Vertex
Per-corner values, useful for differing UVs on shared points.
Detail
Single global values that affect the whole geometry.
Key Takeaway

Always confirm attribute class when reading or writing. Use prim, point and detail to bridge classes safely.

Practical example
Reading a primitive string from point context
s@prim_material = prim(0, "material_name", @primnum);
Here prim() takes input index, attribute name and primitive index, returning the primitive's value.
Common pitfall

Using the wrong attribute class for a lookup causes errors. Confirm with the Geometry Spreadsheet before accessing.
