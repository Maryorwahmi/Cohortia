Definition
Scalar vs Vector families
Clear definitions reduce type errors and improve readability.
int
Whole numbers for counts, indices, and discrete states.
float
Real numbers with fractional precision for weights and measures.
vector2 / vector / vector4
Multi-component containers for UVs, positions/normals, and RGBA colors respectively.
string
Textual identifiers like material names or tags.
Common mistake

Using a vector when a scalar was intended makes math and comparisons harder and may produce type errors in functions that expect scalars.

Concrete examples
Positions
@P is a vector representing XYZ coordinates of a point.
Texture coords
@uv is a vector2 for U and V texture coordinates.
Color
@Cd is a vector; @Cd.w or vector4 holds alpha when needed.
Identifiers
Use strings for names and material labels accessed with prim() or detail().
Key Takeaway

Name attributes with type hints and pick types that reflect the underlying meaning — it saves time and prevents errors.
