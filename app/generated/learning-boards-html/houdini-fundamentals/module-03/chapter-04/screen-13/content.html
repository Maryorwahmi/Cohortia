Transfer
Use when shapes align but topology differs
Projects attributes by proximity and interpolates values.
Copy
Use when indices or IDs match
Exact attribute duplication without interpolation.
Promote
Change class and aggregate values
Average, Sum, Min, Max control how data condenses across classes.
Production tip

Combine tools: transfer fine detail from sculpt, promote for metadata, or copy simulation outputs back to original geometry when indices align. Validate at each stage using the geometry spreadsheet.
