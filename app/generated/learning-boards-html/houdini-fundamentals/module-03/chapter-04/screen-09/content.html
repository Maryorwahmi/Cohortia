VEX Techniques

prim() and point()

Read attributes from other component types to build relationships between points, primitives, and the whole geometry.

Example: compute average velocity (chapter example)
// Run Over: Detail
vector total_velocity = {0,0,0};
int num_points = npoints(0); // Get total number of points from input 0

for (int i = 0; i < num_points; i++) {
  total_velocity += point(0, "v", i); // Sum up all point velocities
}
v@avg_velocity = total_velocity / (float)num_points; // Calculate average and store as new detail attribute
Practical tips
  • When in a point wrangle, use prim(0, "attr", @primnum) to sample primitive attributes related to the point.
  • Pass explicit indices into point() or prim() when sampling arbitrary elements.
  • Use detail wrangles to store global aggregates computed from individual components.
Key Takeaway

prim() and point() provide controlled access across classes; use them for custom summaries and mappings that SOPs cannot express directly.
