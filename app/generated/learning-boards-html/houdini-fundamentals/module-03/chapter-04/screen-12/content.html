Debugging

Common Mistakes

  • Distance Threshold too low → patchy or missing transfers.
  • Distance Threshold too high → bleeding and loss of locality.
  • Using Copy when indices differ → misaligned or wrong attribute values.
  • Assuming Average preserves totals when it reduces magnitude.
Quick fixes
  1. Visualize attributes after each node with Color From Attributes.
  2. Open Geometry Spreadsheet to inspect raw values and counts.
  3. Test on a small subset so changes are fast to iterate.
Warning

Never copy attributes between meshes unless you have verified index or ID correspondence; silent mismatches are common and destructive.
