Comparison

Promotion Examples

Point → Primitive (Average)
Each primitive's value becomes the average of its points. Good for per-face material colors.
Primitive → Point
Primitive values are assigned to constituent points, which can create sharp seams between faces.
Point → Detail (Average)
Computes a single representative value for the whole geometry. Useful for global metadata or thresholds.
Pitfalls & Fixes
  • Assuming sums are preserved by Average. If totals matter, use Sum or compute manually with VEX.
  • Visual seams when promoting primitive values to points; consider smoothing after promotion if needed.
  • Detail attributes discard spatial detail; use them only for metadata or single-value controls.
