Definition

Attribute Promote

Change an attribute's class between point, primitive, and detail. Choose a method to aggregate when going from finer to coarser granularity.

Average
Compute mean value for coarser class.
Sum / Min / Max
Use when totals or extrema are required.
Example
Promote point Cd to Detail with Average to produce a single representative color you can use for whole-geometry logic or exported metadata.
Impact and gotchas
  • Promoting to a coarser class aggregates values; understand the method's effect on numeric magnitudes.
  • Promoting to a finer class usually duplicates values across new elements, which may be acceptable or require smoothing later.
  • When promoting color attributes, perceptual averaging may not always produce the visual result you expect; validate in the viewport.
Key Takeaway

Choose promotion methods deliberately: Average for smooth representative values, Sum for totals, Min/Max for bounds. Inspect results in the spreadsheet.
