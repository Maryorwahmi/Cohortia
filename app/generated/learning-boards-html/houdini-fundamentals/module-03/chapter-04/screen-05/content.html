Process Flow

Tune Transfer Parameters

1. Select Attributes
Choose only necessary names like Cd, v, uv to avoid copying excess data.
2. Estimate Distance Threshold
Start with a radius that reaches the nearby source surface; increase if coverage is sparse.
3. Adjust Blend Width
Raise for smooth blending, lower for sharper attribute edges.
4. Validate
Use Color From Attributes and geometry spreadsheet to confirm values and distribution.
Concrete Scenario
You have a sphere with a vertical Cd ramp and a low-poly box. Set Distance Threshold to about the average distance from box points to the sphere surface. If you see isolated points without color, slightly increase the threshold. If colors spread across faces that should be different, reduce the threshold or tighten the blend.
Common Mistake
Treating Blend Width as unrelated to Distance Threshold. Blend only affects falloff inside the threshold; both parameters must be tuned together.
Key Takeaway

Tune threshold for coverage and blend for smoothness, then verify visually and in the spreadsheet.
