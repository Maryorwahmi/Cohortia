Core Tool

Attribute Copy SOP

Copy attributes by matching point/primitive indices or by using a custom ID attribute. Ideal when source and destination are topologically identical or intentionally indexed.

Practical example
After a simulation on a proxy mesh, use Attribute Copy to transfer the velocity attribute back to the original high-res mesh that shares the same point order.
Key Takeaway

Copy when indices or IDs align; transfer when shapes align but topology differs.

Checklist before copying
  • Confirm identical point counts or a reliable custom ID attribute.
  • Verify attribute names and types match between source and destination.
  • Test on a subset of points to ensure mapping behaves as expected.
Common mistake
Assuming two similarly shaped meshes have matching indices. Always check ordering or provide explicit IDs.
