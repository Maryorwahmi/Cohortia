Module 4 › Chapter 3.4 › Learning Objectives
01
Attribute Transfer Mastery
Project attributes by proximity and control falloff.

You will learn which attributes can be transferred, how to tune Distance Threshold and Blend Width to avoid patchiness, and how to validate results visually and in the geometry spreadsheet. This skill matters when baking details from high-res to game-ready meshes.

Verified Competency Milestone
02
Attribute Promote Fluency
Change attribute class and aggregate values safely.

Practice promoting point attributes to primitive or detail, and choose methods like Average or Sum. Understand how aggregation changes per-primitive and per-point usage so materials or simulation inputs behave correctly.

Verified Competency Milestone
03
Attribute Copy Precision
Copy attributes when topology or IDs align exactly.

Learn to copy attributes by index or ID between meshes with identical ordering. This is essential when returning simulation data to a high-res original or transferring velocities precisely.

Verified Competency Milestone
04
VEX Cross-Component Access
Use prim() and point() to read attributes across components.

You will practice reading primitive data from within a point context and vice versa. This unlocks custom logic that depends on relationships between points, primitives, and the whole geometry.

Verified Competency Milestone
