Hands-on Lab

Walkthrough Steps

1. Create source
Sphere → Polygon, Frequency 10. Add an Attribute Wrangle (Points) with a color ramp parameter to assign Cd along Y.
2. Create destination
Box sized ~2,2,2 with low divisions to receive the transferred Cd.
3. Transfer attributes
Attribute Transfer: connect sphere to input 1 and box to input 2. Add Cd to Attributes to Transfer, tune Distance Threshold and Blend Width.
4. Visualize and promote
Add Color From Attributes to view Cd. Then Attribute Promote: Original Name Cd, Original Class Point, New Class Detail, Method Average.
Checkpoints
  • After transfer: confirm Cd exists on points in the geometry spreadsheet.
  • After promote: confirm Cd appears on the Detail tab as a single aggregated value.
  • If transfer looks patchy: slightly increase Distance Threshold or add source density.
Key Takeaway

This lab combines projection and promotion: practice parameter tuning and always verify attributes in the spreadsheet.
