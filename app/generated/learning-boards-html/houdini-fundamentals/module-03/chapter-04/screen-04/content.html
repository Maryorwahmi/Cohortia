Core Concept

Attribute Transfer SOP

Project attributes by proximity from source to destination. Control which attributes to transfer and how values are blended across distance.

Key parameters
  • Attributes to Transfer — list which attribute names are copied (e.g., Cd, N, uv).
  • Distance Threshold — maximum search radius for source points.
  • Blend Width — falloff for interpolation inside the threshold.
Example
Project Cd from a high-res sphere onto a low-res box, then visualize with a Color SOP set to From Attributes.
Key Takeaway

Use Attribute Transfer when geometries differ topologically but have similar shapes; tune distance and blend to control locality and smoothness.

Troubleshooting tips
  • Too patchy: increase Distance Threshold slightly or add more source density.
  • Unwanted bleeding: reduce Distance Threshold or tighten Blend Width.
  • Topology matches? Consider Attribute Copy instead for exactness.
