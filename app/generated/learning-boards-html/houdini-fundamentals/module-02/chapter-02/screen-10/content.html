Extruding Faces and Edges

Giving dimension to flat surfaces with PolyExtrude

PolyExtrude SOP Parameters

  • •**Distance:** Controls how far the extrusion extends along the normal.
  • •**Divide Into:** Specifies the number of segments along the extrusion, useful for curvature.
  • •**Output Back:** If enabled, closes the back of the extruded volume, creating a solid object.

Example: Creating a Window Recess

Start with a flat `Grid` representing a wall. Select the faces where you want a window. Apply a `PolyExtrude` SOP to these selected faces, setting a negative `Distance` to extrude them inwards. This creates a clean recess for your window frame, adding realistic depth to your model.

Key Takeaway

The `PolyExtrude` SOP is essential for adding depth and detail by extruding selected faces or edges, with parameters like `Distance` and `Output Back` for precise control.

Pro Tip: Multiple Extrusions

Combine multiple `PolyExtrude` nodes for complex profiles. For instance, extrude once for a basic shape, then extrude again on the new faces for a beveled edge or a stepped detail.
