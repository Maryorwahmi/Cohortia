Intersecting Volumes and Troubleshooting Booleans

Keeping overlapping areas and resolving common artifacts

Boolean Intersect Mode

Intersect (A & B)

Keeps only the overlapping volume common to both input geometries. Useful for creating forms defined by shared space.

Common Mistake: Incorrect Normals

Inverted geometry or artifacts often occur when input geometries have inconsistent normal directions. Normals define the 'outside' of a face, and incorrect orientation can confuse the `Boolean` operation.

WARNING: Check Normals!
Solution: Normal Correction

Use the `Reverse` SOP to flip problematic normals or the `Facet` SOP with "Post-Compute Normals" enabled to unify their orientation, ensuring correct `Boolean` results.

Key Takeaway

The `Boolean` SOP's Intersect mode is for finding common volumes, but always ensure correct normal directions using `Reverse` or `Facet` SOPs to avoid artifacts.
