Learning Objectives

Skills you'll master in this chapter

LearnUnderstandApplyMaster
01

Apply Transformations

Learn to precisely move, rotate, and scale geometry using the `Transform` SOP. This skill is vital for accurate placement and orientation of any 3D asset.

VERIFIED COMPETENCY MILESTONE
02

Combine Geometry Streams

Master the `Merge` SOP to combine multiple geometry inputs into a single output. This is fundamental for assembling complex scenes and modular assets efficiently.

VERIFIED COMPETENCY MILESTONE
03

Utilize Boolean Operations

Learn to create complex shapes using `Boolean` SOP modes: union, subtract, and intersect. This enables precise sculpting and cutting of geometry.

VERIFIED COMPETENCY MILESTONE
04

Extrude Faces and Edges

Learn to add depth and detail to geometry by extruding faces and edges using the `PolyExtrude` SOP. This is key for creating features like walls, frames, and intricate patterns.

VERIFIED COMPETENCY MILESTONE
