Key Concepts: VEX & Manipulation

Advanced tools for procedural control.

Attribute Wrangle SOP

A node for writing VEX code to programmatically manipulate attributes.

VEX (Vector Expression)

A high-performance, C-like scripting language for parallel geometry processing.

@P, @Cd, @pscale

Key built-in attributes for position, color, and instance scale manipulation.

@ptnum, npoints(), rand()

VEX variables/functions for point index, total points, and random values.

'Run Over' Parameter

Specifies which component type (Points, Primitives, etc.) the VEX code operates on.

Chapter Summary

VEX, through the Attribute Wrangle, is the ultimate tool for dynamic attribute manipulation. Mastering its syntax and built-in variables allows for unparalleled procedural control over geometry properties.
