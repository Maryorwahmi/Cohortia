The Attribute Wrangle and VEX Language

High-performance scripting for granular control.

What is VEX?

VEX (Vector Expression) is a high-performance, C-like scripting language optimized for parallel processing of geometry data. It allows for granular, programmatic control over attributes.

  • C-like syntax for familiar programming.
  • Optimized for speed and large datasets.
  • Used within the Attribute Wrangle SOP.
Key Takeaway

VEX, accessed via the Attribute Wrangle, is Houdini's most powerful tool for dynamic, data-driven geometry manipulation.

The 'Run Over' Parameter

// Attribute Wrangle SOP
Run Over: Points  // VEX code operates on each point
Run Over: Primitives // VEX code operates on each primitive
Run Over: Vertices // VEX code operates on each vertex
Run Over: Detail   // VEX code operates once on the entire geometry
Important Note

Always match the 'Run Over' setting to the component type of the attribute you intend to modify (e.g., '@P' for 'Points').
