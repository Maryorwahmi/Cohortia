Coloring Geometry with VEX

Applying uniform and gradient colors.

Uniform Color Assignment

Set all points to a specific color by assigning a constant vector to the @Cd attribute. Remember to set 'Run Over' to 'Points'.

@Cd = {0, 1, 0}; // Set RGB to green

Gradient Color based on Point Number

Create a dynamic color gradient using @ptnum (point index) and npoints(0) (total points).

@Cd = { @ptnum / (float(npoints(0)) - 1), 0, 0 }; // Red gradient
Key Takeaway

VEX allows you to precisely control color attributes, from simple uniform assignments to complex gradients driven by geometry data.

VEX Variables Explained
  • @Cd: The color attribute (vector).
  • @ptnum: The current point's unique index.
  • npoints(0): Total points in the first input.
  • float(): Casts an integer to a float for accurate division.
Common Mistake

Forgetting to cast integers to floats in division (e.g., 1/2 results in 0, not 0.5). Always use float() for decimal results.
