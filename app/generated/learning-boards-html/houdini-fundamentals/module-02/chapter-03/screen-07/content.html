Using the Attribute Create SOP

Adding uniform attributes to your geometry.

Define & Assign Attributes

The Attribute Create SOP allows you to define a new attribute, specify its type (e.g., float, integer, vector), and set a constant value or a simple ramp across your geometry.

  • Choose attribute name and class (point, primitive, etc.).
  • Set data type (float, integer, vector, string).
  • Assign a constant value to all selected components.
Key Takeaway

The Attribute Create SOP is ideal for simple, uniform attribute assignments but lacks the dynamic control of VEX.

Example: Adding a Custom Float Attribute

// Attribute Create SOP Parameters
Attribute Name: myCustomValue
Class: Point
Type: Float
Value: 0.5

// Result in Geometry Spreadsheet (Points tab)
// myCustomValue
// 0.5
// 0.5
// ...
Use Case

Assigning a default 'active' state (e.g., 0 or 1) to all points before further procedural processing.
