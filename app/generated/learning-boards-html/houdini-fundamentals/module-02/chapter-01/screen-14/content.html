Module 2 › Chapter 2.1 › Key Concepts
Surface Operators (SOPs)
Composable nodes that create and modify geometry in a procedural chain.
Primitives (Box, Sphere, Grid)
Simple shapes used as seeds; parameters determine scale and topology.
Points, Vertices, Primitives
Points are coordinates, vertices link points into faces, primitives are the visible faces.
Summary Takeaway
Treat nodes as editable recipe steps, pick primitive types that match downstream needs, and monitor topology using the Geometry Spreadsheet to keep performance under control.
