Grid parameters at a glance

Rows and Columns control point density; Size determines the plane's real-world dimensions. Plan subdivisions with intended detail and export needs in mind.

Use cases
  • Terrain base for displacement and sculpting.
  • Floor or panel with regular UV mapping.
  • Tileable surface where consistent topology is required.
Pro tip
Adjust Rows/Columns only as needed; prefer procedural local detail over global high density to preserve performance.
Concrete example
Create a Grid with Size 2.0 x 1.5 and 20 rows, 15 columns to begin a low-resolution terrain. Later add detail only where the camera will focus.
Check
Open the Geometry Spreadsheet and confirm the expected point count after changing Rows and Columns to ensure budget compliance.
