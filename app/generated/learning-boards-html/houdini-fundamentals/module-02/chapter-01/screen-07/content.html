Module 2 › Chapter 2.1 › Sphere Types
Primitive Sphere
A mathematical surface, light on explicit vertex data, smooth for rendering but not editable as a mesh. Useful for previews and math-driven shapes.
Pros: low data, smooth. Cons: limited direct mesh editing, awkward for export.
Example
Render-only scenic elements where no per-face edits are required.
Polygon Sphere
Creates actual polygon faces suitable for per-vertex edits, UVs, and export to game engines. Choose frequency (division) to control density.
Pros: editable, exportable. Cons: more geometry data at high frequency.
Example
A decorative object you will texture and export to a game engine; start with polygonal output and low frequency.
Check your understanding
If you need to paint UVs and export the mesh, which sphere type should you choose? Answer: Polygon, because it produces editable faces and topology suited for export.
