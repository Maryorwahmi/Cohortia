Module 2 › Chapter 2.1 › Table Activity
Table build steps
  1. Create Geometry node in /obj and dive into SOP context.
  2. Place Box: Size X 0.1 Y 1.0 Z 0.1 for a leg.
  3. Duplicate or create three more legs, position them with Transform.
  4. Place Box for tabletop: Size X 2.0 Y 0.1 Z 1.5, Center Y 0.5.
  5. Place a Merge node, connect all boxes, and set the Display flag on Merge.
Check
Open Geometry Spreadsheet and verify points and primitives after Merge to ensure geometry is combined as expected.
Concrete scenario
You need a low-poly table for a game scene. Use minimal divisions on each Box and merge. Confirm final primitive count and set the Render flag on the Merge node before export.
Optional challenge
Add a Polygon sphere on the tabletop and observe the difference in the Geometry Spreadsheet between the table primitives and the sphere's topology.
