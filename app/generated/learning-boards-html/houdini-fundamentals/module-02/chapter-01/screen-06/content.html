Box parameters explained

Size controls shape; Center repositions pivot; Divisions control the number of segments. Choose values that match your target polygon budget.

Parameter examples
Size
Numeric dimensions X,Y,Z—affects physical scale.
Divisions
Segments per axis. Lower is faster and appropriate for game props.
Concrete Example

Make a table leg: Size X 0.1 Y 1.0 Z 0.1. Keep divisions minimal then duplicate and transform legs to assemble a table.

Common Mistake

Beginners often set Divisions very high to get smooth surfaces. Instead, start low and add subdivision later. Excessive early density slows the viewport and increases processing time.

Check your understanding
If a Box is meant as a simple prop, what are the key parameters you'd set to keep performance good? Answer: Size for scale and low Divisions for fewer polygons.
