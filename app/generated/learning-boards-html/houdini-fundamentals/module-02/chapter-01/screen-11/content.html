Flags you will use every session

Display, Render, and Template flags determine what you see and what gets rendered or used as a reference. Use them intentionally to avoid debugging confusion.

Display (blue)
Sets viewport output.
Render (purple)
Sets render/export output.
Template (pink)
Ghosted reference for alignment.
Concrete example
After merging legs and tabletop with a Merge node, set the Display and Render flags on the Merge node so both viewport and exports reference the combined table, not an individual leg.
Common mistake
Exporting the wrong node because the Render flag remained on an earlier node. Always verify the Render flag before exporting or rendering.
