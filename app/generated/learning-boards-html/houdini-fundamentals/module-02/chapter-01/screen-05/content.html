Object vs Geometry

The Object context is the scene-level area. Geometry nodes live here. Double-click a Geometry node to "dive" and edit SOPs inside it. Keep scene hierarchy clean by naming and grouping geometry objects.

Step-by-step
  1. Create a Geometry node in /obj.
  2. Double-click the geometry node to enter SOP context.
  3. Press Tab, type Box, place a Box SOP.
  4. Place a Transform SOP, connect it to the Box and modify values.
Pro tip
Name nodes immediately and use Merge to combine related parts for clarity and reuse.
