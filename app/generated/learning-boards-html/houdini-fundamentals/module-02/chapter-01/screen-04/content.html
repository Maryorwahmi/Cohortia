SOPs: a clear definition

A SOP is a node that performs one geometry operation. Nodes are connected to form a network that defines a procedural recipe. This recipe can be changed at any step and re-evaluated downstream.

Examples
  • Box node: creates a cube-like primitive with Size and Divisions.
  • Transform node: moves, scales, or rotates geometry numerically.
  • Merge node: combines multiple inputs into a single stream.
Key Takeaway

Design geometry as a chain of operations so you can iterate earlier steps and propagate changes predictably.

SOP Network Example
1 • Box
Generate base geometry with Size and Divisions.
2 • Transform
Adjust position or pivot without rewriting the box.
3 • Subdivide
Add detail later, after topology is established.
Common misconception
Some learners expect SOPs to be one-off effects. Instead, treat them as parameters and recipes that work together. Changing an early node updates the whole chain.
