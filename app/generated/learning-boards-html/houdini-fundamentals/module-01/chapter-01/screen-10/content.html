Object Level vs SOP Level
Choose the right scope for transforms and edits.

Comparison: Object level controls whole-scene transforms and containers. SOP level edits the mesh geometry inside those containers.

Concrete example
Move a wheel at Object level. Bevel the rim at SOP level. Mixing these can cause unexpected instancing or scale issues.
Misconception
Trying to edit faces at Object level will fail because that workspace doesn't contain per-vertex operations.
Key Takeaway

When in doubt, ask whether the change affects the whole object in the scene or the mesh’s internal structure.

Quick reference
Object level: transforms, instancing, scene hierarchy.
SOP level: points, edges, faces, topology edits.
Rule: Object for scene, SOP for mesh.
Practice prompt
Create a geometry node, add a Box SOP, then try scaling at Object and editing shape at SOP to see the difference.
