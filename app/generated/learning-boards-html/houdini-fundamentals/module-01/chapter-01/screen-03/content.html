Practical scope and hands-on steps
Hands-on Activity
Rearrange panels, split the Network Editor, and save your desktop.
1. Drag Parameter Editor next to 3D Viewport.
2. Right-click Network Editor tab → Split Pane Left/Right.
3. Windows → Desktop → Save Current Desktop As... → MyFirstLayout.
4. At obj level: Tab → type geo → Enter.
5. Double-click geometry1 → at SOP level: Tab → type box → Enter.
6. Select Box and change Size to see live updates.
These steps establish a workflow pattern you will reuse: layout, create, dive, parameterize, test.
Why this helps
Small layout changes reduce context switching. Saving desktops guarantees the same workspace for repeatable tasks such as modeling or simulation.
Key Takeaway

Practice the simple create-and-dive cycle: object → dive → SOP edit. It prevents the common error of editing at the wrong level.
