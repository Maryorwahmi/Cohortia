3D Viewport Essentials
Viewport is the live preview of your scene and node results.

Use the viewport to inspect geometry updates when you change parameters. If a change doesn't appear, verify the node's display flag.

Quick checks
Ensure camera framing, selection filters, and display flags are correct before assuming a node is broken.
Pro tip
Use frame selection and isolate nodes you are testing to reduce visual clutter while troubleshooting.
Key Takeaway

The viewport is your truth source. Use it to validate changes before proceeding downstream.

Viewport checklist
  • Is the node display flag active?
  • Is camera framing correct for the edited object?
  • Are visual helpers or guides hiding detail?
Practice prompt
Create a box SOP and toggle the display flag while changing size parameters to learn the visual feedback loop.
