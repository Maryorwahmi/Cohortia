Create Your First Geometry
Step-by-step: create geo, dive, add box, adjust parameters.
Steps
1. At obj level open Network Editor.
2. Press Tab, type: geo → Enter (creates Geometry node).
3. Double-click geometry1 to dive into SOP context.
4. Press Tab, type: box → Enter (adds Box SOP).
5. Ensure Box display flag is active.
6. Select Box and change Size (e.g., 1, 2, 1) in the Parameter Editor.
This recorded sequence trains the create-dive-edit loop you'll repeat for modeling and procedural systems.
Checks & Troubleshooting
  • Is the Network Editor showing /obj or /obj/geometry1?
  • Is the Box node's display flag blue?
  • Are parameter changes visible in the viewport?
Key Takeaway

Practice the exact six-step flow until it becomes second nature: create, dive, add SOP, set display flag, edit parameters, verify in viewport.
