Parameter Editor
Tune node behavior and expose parameters for artists.

Good parameter design balances flexibility with simplicity. Expose the parameters that matter and hide the ones that don’t.

Example
Expose wall width and window count. Hide low-level thresholds used internally by the generator.
Mistake to avoid
Placing too many low-level parameters at the top level creates noise and increases the chance of accidental breakage.
Key Takeaway

Design parameter exposure with an artist in mind: make common adjustments easy and protect internal logic.

Parameter hygiene
  • Use descriptive names and units.
  • Group related controls together.
  • Hide or lock internal controls when possible.
Practice prompt
Create a small network and expose two parameters on a subnetwork interface to test usability for other artists.
