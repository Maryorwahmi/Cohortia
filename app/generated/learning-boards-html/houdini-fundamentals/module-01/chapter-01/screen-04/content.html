Node-based Paradigm
Each node does one job; networks create complex behavior.

Definition: A node is an encapsulated operation. Networks chain operations to produce geometry or simulation results.

Example pipeline
Box → PolyExtrude → Subdivide. Change the Box and see all steps update.
Common misconception
Nodes are not only for complex effects; they make simple workflows more maintainable and reusable.
Key Takeaway

Treat nodes as single-purpose building blocks. Name them and group logically to keep networks readable.

Visual: Node cards
Box
Creates a primitive with size parameters.
PolyExtrude
Extrudes faces and adds depth to the mesh.
Subdivide
Smooths geometry by adding geometry detail downstream.
Practice prompt
Create a short chain of three nodes and change the first node’s parameter to observe propagation and to practice naming nodes.
