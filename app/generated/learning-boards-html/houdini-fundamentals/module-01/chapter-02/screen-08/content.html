What the Scene Graph shows
A tree of objects where parent nodes contain child nodes. Parent transforms automatically affect children. Use drag-and-drop in the Scene Graph to create relationships.
Concrete example
Make a Car parent and Wheel children. Translate the car and watch wheels follow. Rotate the car and the wheels inherit that rotation while keeping local offsets.
Pitfall
Attempting to move a child without unparenting will apply a local offset relative to the parent’s space — the result may not match expectations if you think in world coordinates.
Practical guidelines
  • Group related parts under a single parent to move them together.
  • Use parenting for animation rigs and modular assets so transforms propagate predictably.
  • Keep scale conventions consistent; treat 1 unit as 1 meter for game exports when required.
Key Takeaway

Use the Scene Graph intentionally to organize assets; check parent influence before making local edits to children.
