Module 1 › Chapter 1.2 › Assessment
Checklist
  • Frame selection and frame all to confirm camera control.
  • Create tabletop using Box SOP with Size 2, 0.1, 1.5 and correct Center Y.
  • Create legs with Size 0.1, 1, 0.1, place corners using Translate values.
  • Parent legs to tabletop and move parent to verify inheritance.
Troubleshooting
  • Geometry intersecting ground? Check Center Y values.
  • Child not following parent? Confirm correct parenting in Scene Graph.
  • Handle moving oddly? Verify manipulator is in local or world mode as intended.
Outcome

A reproducible tabletop scene that frames, transforms, and parents correctly is the expected result of this chapter.
