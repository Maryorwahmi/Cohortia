Module 1 › Chapter 1.2 › Hands-on Activity
Step-by-step
  1. File → New to start a fresh scene.
  2. At obj level create Geometry node named tabletop_geo; dive inside and add Box SOP.
  3. Set Box Size to 2, 0.1, 1.5 and Center Y to 0.05 so it rests on ground.
  4. Create leg_geo with a Box SOP sized 0.1, 1, 0.1 and Center Y 0.5; translate to a corner using T or numeric values.
  5. Duplicate leg_geo three times, move duplicates to remaining corners using Translate X/Z values.
  6. In Scene Graph parent each leg to the tabletop so transforms propagate.
Checklist & Tips
  • Verify Center Y on boxes to avoid clipping through ground.
  • Use Spacebar + F to focus on a leg, then Alt + LMB to fine-tune orientation.
  • After parenting, move the tabletop to confirm legs inherit transforms.
Key Takeaway

Follow procedural creation steps and always verify center and parenting to prevent alignment surprises.
