Module 1 › Chapter 1.2 › Skill Checklist
Viewport Practice
  • Hold Alt + LMB to tumble around a point until the corner lines up visually.
  • Hold Alt + MMB to pan to align objects without rotating the view.
  • Hold Alt + RMB or use the wheel to zoom smoothly; use Spacebar + G if lost.
Mnemonic: Tumble = rotate, Pan = slide, Zoom = move closer.
Scene Graph & Parenting
  • Drag a child onto a parent in the Scene Graph to establish inheritance.
  • Move the parent to confirm children follow; check local offsets when needed.
  • Avoid moving children expecting global independence once parented.
Verified competency: parent four legs to a tabletop and move the table.
Create Primitives
  • Use Shelf Tools for rapid placement of boxes or spheres at the origin.
  • Use Tab inside a geometry node to create SOPs and see procedural chaining.
  • Prefer Tab when you need node-level control or to expose parameters later.
Transforms & Manipulators
  • Press T to translate, R to rotate, and E to scale and use handles visually.
  • Use Parameter Editor to enter precise numeric values for Translate, Rotate, Scale.
  • Check local vs world space when results seem unexpected.
Tip

If you ever lose orientation, press Spacebar + G to frame all objects and regain a stable view before continuing.
