Module 1 › Chapter 1.2 › Transformations
What each transform does
  • Translate moves an object along X, Y, Z coordinates; use T or numeric Translate fields.
  • Rotate orients an object around axes; use R or numeric Rotate fields.
  • Scale resizes an object uniformly or non-uniformly; use E or Scale parameters.
Common mistake
Applying transforms without checking parent influence. A child inherits parent transforms and may appear to snap when the parent moves.
Concrete example
Create a box sized for a tabletop, set Translate Y so it rests on the ground plane, then rotate the tabletop 5 degrees around Z to test orientation. Finally scale uniformly to adjust overall size. Use parameter fields to type exact values for reproducible results.
Key Takeaway

Combine manipulators for quick edits and numeric parameters for exact placement; always verify local vs world orientation and parent influence.
