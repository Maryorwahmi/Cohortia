Module 1 › Chapter 1.2 › Hotkeys Recap
Navigation
Alt + Mouse
  • Alt + LMB — Tumble
  • Alt + MMB — Pan
  • Alt + RMB or wheel — Zoom
Transforms
T, R, E
  • T — Translate
  • R — Rotate
  • E — Scale
Framing
Spacebar shortcuts
  • Spacebar + F — Frame selection, set pivot
  • Spacebar + G — Frame all objects, recover view
Practice drill

Select a leg, press Spacebar + F, tumble with Alt + LMB, pan with Alt + MMB, zoom with Alt + RMB, then press T and nudge Translate X by a small numeric value. Repeat three times to build reflex.
