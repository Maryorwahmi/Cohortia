Module 2 › Chapter 1.3 › Modular Wall Build
Step-by-step
  1. Create a Geometry node named modular_wall and dive inside.
  2. Add Box SOP: Size = 4,3,0.2; Center Y = 1.5. Set display flag.
  3. Add Group SOP: Type = Primitives, Name = window_faces; select front faces in viewport.
  4. Add PolyExtrude: Group = window_faces; Distance = -0.1; Divisions = 1; set display flag.
  5. Create another Box for window frame, adjust Size, then Transform to place it into the recess.
  6. Add Merge SOP to combine wall and frame into a single output stream.
  7. Open Geometry Spreadsheet to inspect P, N, and counts after key steps.
Concrete checks
Checkpoint
After Group, confirm window_faces appears in Primitive tab. After PolyExtrude, confirm increased point/primitive counts.
Tip
Use a negative extrusion distance to push inward for a recess. Keep Divisions low for a clean cut.
Mistake to avoid
Merging before positioning the frame can make the transform harder; position before merge to preserve local transforms.
Key Takeaway

Follow the pipeline and verify after each topology-changing node to keep the network predictable.
