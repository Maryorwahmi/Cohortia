Module 2 › Chapter 1.3 › Attributes: P, N, Cd
Attribute breakdown
P — Position
Vector of three floats defining point location. Visible in the Points tab of the spreadsheet.
N — Normal
Surface direction used for shading and directional operations like extrusion.
Cd — Color
Diffuse color stored as r, g, b; can live per-point or per-primitive.
Where attributes live
Attributes can be stored on points, vertices, primitives, or detail. The storage location determines how attributes behave when topology changes. For example, point attributes move with points, while primitive attributes stay tied to faces.
Practical check
Open Geometry Spreadsheet and verify which tab (Points, Primitives) shows P, N, or Cd after each node.
Tip
If an operation behaves strangely, check whether the expected attribute exists on the component type the SOP operates on.
