Module 2 › Chapter 1.3 › Common SOPs Compared
At-a-glance
Transform
Topology-preserving position, rotate, scale.
PolyExtrude
Topology-changing extrusion of selected primitives.
Merge
Combine multiple inputs into a single stream.
Group
Create named selections for targeted operations.
Practical example
Create a Box for the wall, Group the front face primitives as window_faces, use PolyExtrude on window_faces with a negative distance to carve a recess, create a separate Box for the window frame, Transform that box into place, then Merge the frame with the wall to produce one object.
Check the spreadsheet
Compare point counts and primitive IDs before and after PolyExtrude to confirm topology changes.
