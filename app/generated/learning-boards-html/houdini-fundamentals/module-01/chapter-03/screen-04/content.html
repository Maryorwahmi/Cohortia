Module 2 › Chapter 1.3 › What is a Node?
Definition
A single, focused operator

Nodes accept inputs, expose parameters, process data, and send results downstream. Treat them like steps in a recipe rather than layers of a finished model.

Concrete example
Create a Box SOP and change its Size parameters. The P attribute for each generated point updates to the new coordinates.
Common misconception
Treating nodes as final layers can hide the sequence of operations and make debugging harder.
Key Takeaway

Design networks as small steps with clear parameters so changes remain predictable and debuggable.
