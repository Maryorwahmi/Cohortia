Module 2 › Chapter 1.3 › Group SOP
Purpose

Use groups to name and isolate parts of geometry for targeted operations. Group Type must match the type of components you intend to select.

Example
Create a primitive group named window_faces and reference it in PolyExtrude to recess those faces only.
Pitfall
Creating the wrong component type for the group (points vs. primitives) will cause later nodes to appear to do nothing.
Workflow
  1. Choose Group Type: Points, Vertices, or Primitives.
  2. Select using viewport picks, bounding regions, or attribute filters.
  3. Name the group clearly and confirm membership in the Spreadsheet.
  4. Reference the group in downstream nodes' Group parameter.
Key Takeaway

Use groups to scope operations and keep networks readable and reusable.
