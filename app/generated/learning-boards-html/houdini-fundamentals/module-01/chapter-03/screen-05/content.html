Module 2 › Chapter 1.3 › Inputs, Outputs, Parameters
Contract

Inputs: geometry and attributes. Parameters: control behavior. Outputs: modified geometry and attributes. Parameters can change topology and attribute layout.

Example
PolyExtrude with negative distance reduces front-face position along normals and creates additional primitives, increasing point count visible in the spreadsheet.
Misconception
Parameters only change appearance. In fact, many change topology and attributes, which downstream nodes may rely on.
Key Takeaway

Always inspect the Geometry Spreadsheet after parameter changes to verify topology and attribute changes.

Step-by-step check
1. Inspect inputs
Open the Geometry Spreadsheet on the input node to see P, N, Cd and counts.
2. Change parameters
Adjust distance, translate, or selection, and observe immediate viewport changes.
3. Inspect outputs
Compare the Spreadsheet to see how attributes and counts were affected.
