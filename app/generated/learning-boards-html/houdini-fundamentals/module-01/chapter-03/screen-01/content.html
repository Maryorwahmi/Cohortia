Introduction to Nodes: Geometry and Attributes
How SOPs, attributes, and node chains shape procedural geometry
In this lesson

Explore how nodes accept inputs, expose parameters, and output geometry. Learn common SOPs and how attributes like P, N, and Cd flow through a node chain.

Why it matters
Procedural workflows let you iterate quickly and create reusable, parametric assets for games and VFX.
What you'll practice
Creating a box, grouping faces, extruding for a window recess, merging pieces, and inspecting attributes.
Visual concept
Data flows through node chains; attributes ride on geometry.
Explore Key Topics
Nodes & Chaining
A node performs one operation; connect them to build complex results.
Attributes
Data like P, N, and Cd live on geometry and move through the network.
SOP Toolbox
Transform, Group, PolyExtrude, and Merge are core building blocks you will use often.
