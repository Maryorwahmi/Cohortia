Core SOPs
Points, Primitives, Edges

Know which SOP operates on which component and ensure your groups match that selection type. Using the correct selection type prevents unintended consequences during operations like extrusion.

Box
Generates points and primitives for a simple cube or flat box.
Transform
Manipulates point positions to move, rotate, or scale geometry.
PolyExtrude
Extrudes selected primitives, creating new faces and changing topology.
Selection & Verification
Use the Group SOP to name collections of points or primitives. Always confirm group membership in the Geometry Spreadsheet or viewport highlighting before running topology-changing nodes.
Example workflow
Create Box → Group front-face primitives as window_faces → PolyExtrude using window_faces to make a recess.
Pitfall
Selecting the wrong component type for a group will make some SOPs appear to do nothing; confirm selection mode before applying.
