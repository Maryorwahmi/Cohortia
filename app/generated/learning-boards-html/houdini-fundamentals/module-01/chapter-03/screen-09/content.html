Reading the table

Open Points, Primitives, or Detail tabs to see attribute columns. P shows coordinates; N shows normals; Cd shows color. Compare counts and values across nodes to identify changes.

Example inspection
Before PolyExtrude: 24 points. After PolyExtrude: 32 points. Verify P values for new points and N directions for extruded faces.
Debug tip
Missing Cd column means the color attribute was not created. Check upstream nodes that should add attributes and ensure they're set to write to the correct component type.
Quick checks
  • Toggle node display flags and compare Spreadsheet rows and columns.
  • Confirm attribute types (float, vector) and number of components.
  • Note topology changes: point and primitive counts should match expected transformations.
Key Takeaway

Treat the Spreadsheet as a truth table for your network; it prevents assumptions about attribute presence and topology.
