Module 2 › Chapter 1.3 › Practice & Verification
Practice Task
  1. Create a Geometry node named modular_wall and dive inside.
  2. Add a Box SOP and set Size to 4,3,0.2 and Center Y to 1.5.
  3. Create a Group SOP to select window faces and name it window_faces.
  4. Use PolyExtrude on that group with a negative distance to create a recess.
Checkpoints: display flags, Geometry Spreadsheet, viewport normals.
Verification Tips
  • Set display flags on intermediate nodes to inspect incremental changes.
  • Open Geometry Spreadsheet to compare point and primitive counts before/after extrusion.
  • Visualize normals to confirm correct face orientation after operations.
Common mistake: leaving nodes unconnected or applying operations in the wrong order.
Why this matters
Verification is how you build trust in a procedural network. Small checks prevent compounding errors downstream and keep assets predictable for reuse.
Mini-mnemonic
Generate → Group → Modify → Inspect → Merge
