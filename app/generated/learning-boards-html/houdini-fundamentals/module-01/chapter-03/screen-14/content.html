Module 2 › Chapter 1.3 › Key Concepts
Nodes are steps
Design small, focused nodes so networks are predictable and testable.
Attributes carry data
P, N, and Cd describe position, surface direction, and color; check where they live.
Order affects topology
Reordering nodes can change point counts and attributes; verify intermediate outputs.
Summary takeaway
Design networks as generate → group → modify → combine → inspect and use the Geometry Spreadsheet to validate each step.
