Chain example
Box → Group(window_faces) → PolyExtrude(window_faces) → Transform → Merge(frame). Each step builds on the last, and changing order alters results.
Try this
Apply Transform before PolyExtrude and then after to compare differences in point positions and extrusion behavior.
Common error
Connecting the wrong output or leaving a node unconnected often results in stale geometry being used downstream.
Verification strip
Display flags
Set the display flag on a node to preview that node's output. Use this to confirm each step before chaining more operations.
Label nodes
Add short labels describing intent so you remember why a node was placed in the network and can reorder safely.
