Module 7 › Chapter 7.1 › Lab Walkthrough
Tasks
  1. Write my_robot.urdf: base_link, left_wheel, right_wheel, visual/collision/inertial.
  2. Add gazebo plugin for differential drive with matching joint names and topic mappings.
  3. Add LiDAR and camera plugins with topics /scan and /camera/image_raw and correct frames.
  4. Create robot_gazebo.launch to set robot_description, include empty_world.launch, spawn_model, and run robot_state_publisher.
  5. Launch and verify Gazebo, then publish a Twist on /cmd_vel to test motion.
  6. Implement a Python node that reads /scan and publishes /cmd_vel to avoid obstacles.
Example check
After launching, run rostopic list and confirm /cmd_vel, /odom, /scan, and /camera/image_raw are present. Use rostopic echo on /scan to inspect ranges.
Safety step
Start with low linear and angular speeds in your Python controller. Observe behavior and tune thresholds for obstacle distance before increasing speed.
Reflection
Which sensor helped the avoidance node most, LiDAR or camera? LiDAR gives direct range readings, making simple reactive avoidance straightforward.
