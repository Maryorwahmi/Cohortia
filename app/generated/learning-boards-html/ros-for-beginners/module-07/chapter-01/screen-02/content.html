Learning Objectives

Master the URDF format, spawn a robot into Gazebo, connect plugins to ROS topics, and run basic teleoperation and sensor checks.

Bloom: Learn → Understand → Apply → Master
01 — Read URDF
Identify links, joints, visual, collision, and inertial elements and why each is required for simulation.
Verified Competency Milestone
02 — Write URDF
Author a minimal mobile-robot URDF with a base, two wheels, and a sensor element suitable for Gazebo.
Verified Competency Milestone
03 — Launch & Spawn
Load robot_description, start Gazebo empty world, and spawn the model with spawn_model so the robot appears in simulation.
Verified Competency Milestone
04 — Control & Read Topics
Publish geometry_msgs/Twist to /cmd_vel, observe /odom and sensor topics to verify motion and sensor outputs.
Verified Competency Milestone
