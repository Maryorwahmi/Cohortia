Practical Lab Steps

A focused sequence to go from a URDF file to a running simulation with sensors and control topics.

Step 1
Write URDF
Base link, two wheels, caster, sensor element. Keep collision simple.
Step 2
Add Plugins
Configure gazebo_ros_diff_drive and sensor plugins mapped to topics.
Step 3
Launch & Spawn
Set robot_description param, start empty_world.launch, spawn_model, run robot_state_publisher.
Step 4
Control & Verify
Publish a Twist on /cmd_vel and check /odom, /scan, and /camera/image_raw as applicable.
Safety
Start Conservative
Use low speeds, validate collision geometry, and fix unstable inertial values before increasing complexity.
