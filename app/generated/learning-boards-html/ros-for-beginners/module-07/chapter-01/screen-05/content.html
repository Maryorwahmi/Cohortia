Module 7 › Chapter 7.1 › Links: visual, collision, inertial
Definition

Three roles inside a link

Visual defines appearance, collision defines efficient physics shape, and inertial defines mass and inertia tensor for dynamics.
Visual
Detailed meshes for rendering in RViz and Gazebo.
Collision
Simplified primitives used by the physics engine.
Inertial
Mass and inertia values needed for realistic motion.
Common mistakes
  • Using complex meshes for collision geometry causes slow simulation.
  • Omitting inertial tags leads to unstable dynamics in Gazebo.
  • Collision shapes unintentionally intersecting other links on spawn causes immediate collisions.
Example
Wheel link
Visual: cylinder mesh. Collision: cylinder primitive. Inertial: small mass and inertia tensor.
Key Takeaway

Match visual and collision roughly, keep collision simple, and supply realistic inertial numbers for stable simulation.
