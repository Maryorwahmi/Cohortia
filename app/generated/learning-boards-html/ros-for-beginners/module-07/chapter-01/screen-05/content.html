Code walkthrough
Minimal mobile URDF
<robot name="my_robot">
  <link name="base_link">
    <visual>
      <geometry><box size="0.5 0.3 0.1" /></geometry>
    </visual>
  </link>

  <link name="right_wheel">...</link>

  <joint name="right_wheel_joint" type="continuous">
    <parent link="base_link" />
    <child link="right_wheel" />
    <axis xyz="0 0 1" />
  </joint>

  <gazebo>...plugin configuration...</gazebo>
</robot>
Annotated notes
  • base_link: The robot’s frame of reference. Provide visual, collision, and inertial entries.
  • wheel links: Cylinders with small mass; include collision and visual separately.
  • joint type continuous: Use for wheels to allow unlimited rotation. Match joint names in plugin configs.
  • gazebo plugin: Configure leftJoint, rightJoint, wheelSeparation, wheelDiameter, cmd_vel and odom topics so controllers work.
Example values
wheelSeparation 0.3, wheelDiameter 0.1, torque 0.5, updateRate 50
Common mistake
Mismatched joint names between URDF and plugin prevents motion. Verify names exactly.
