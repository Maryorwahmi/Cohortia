Module 7 › Chapter 7.1 › Sensor plugins
LiDAR
gazebo_ros_laser / gazebo_ros_ray
Publishes LaserScan messages on /scan. Useful for obstacle detection and mapping algorithms.
Checks
  • rostopic list and rostopic echo /scan
  • Use RViz LaserScan display for visualization
  • Confirm TF frames include sensor link
Camera
gazebo_ros_camera
Publishes image messages such as /camera/image_raw and camera info topics used by vision pipelines.
Practical tips
  • Tune updateRate and resolution to balance fidelity and CPU load.
  • Add realistic noise parameters to better match hardware sensors.
Exercise

Add a LiDAR plugin to your URDF, spawn the robot, then run rostopic echo /scan while an obstacle approaches the vehicle to observe range values decrease.
