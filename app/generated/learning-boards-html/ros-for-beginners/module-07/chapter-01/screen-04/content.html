Core Concept
URDF structure

URDF models the robot as a tree of links and joints. Visual tags affect rendering; collision tags affect physics; inertial tags affect dynamics. Keep collision geometry simple.

Links
Rigid bodies with visual, collision, and inertial entries.
Joints
Define motion constraints between links; types include fixed, revolute, continuous, prismatic, and floating.
Visual vs Collision
Use detailed meshes for visuals and simple primitives for collision to save compute.
Concrete URDF snippet
<link name="base_link">   <visual>     <geometry>      <box size="0.5 0.3 0.1" />     </geometry>   </visual> </link>
Example
Model a rectangular base and two cylindrical wheels. Specify inertial mass for each link so physics responds correctly when accelerating or colliding.
Key takeaway
URDF ties visual, collision, and inertial data to physical behavior; treat each intentionally.
