Module 7 › Chapter 7.1 › What is URDF?
Definition

URDF: the robot blueprint

URDF is an XML file that declares links, joints, and the geometry and inertial parameters required for simulation and visualization.

Key parts
  • Link: a rigid body with visual, collision, and inertial sections.
  • Joint: connects parent and child links and defines motion type.
  • Inertial: mass and inertia tensor required for physics.
Key Takeaway

URDF expresses both structure and physics. Keep collision geometry simple, and always include inertial data for dynamic simulation.

Analogy & Example
Think of URDF as a set of LEGO instructions

Each link is a brick and the joints are the hinges that let bricks rotate. The visual block makes the model look good, collision blocks tell the physics engine where to collide, and inertial data gives each brick its weight and balance.

Common misconception

Using identical complex meshes for both visual and collision is tempting, but it degrades performance. Use simplified primitives for collision whenever possible.
