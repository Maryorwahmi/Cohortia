Module 7 › Chapter 7.1 › System Architecture
Components and responsibilities
URDF
Model definition for links, joints, visuals, collisions, and plugins.
Parameter Server
Holds robot_description so spawn_model and other nodes can access the URDF.
Gazebo
Simulates physics and hosts the spawned model and plugins.
spawn_model
Reads robot_description and inserts the model into Gazebo, setting initial pose.
robot_state_publisher
Publishes TF frames derived from joint states so other nodes can compute transforms.
Troubleshooting guide
  • Missing model: check spawn_model args and robot_description content.
  • No odom: verify plugin configuration and topic names.
  • No TF: ensure robot_state_publisher is running and joint states are published.
