Comparison
Visual vs Collision vs Inertial
Visual: detailed meshes for realistic rendering. No heavy physics cost but large files increase load time.
Collision: primitives or simplified meshes used by the physics engine. Keep simple to speed up simulation.
Inertial: mass and inertia tensor values that determine how the body accelerates and rotates under force.
Concrete scenario

You have a heavy rectangular base and two small wheels. For visuals, a detailed mesh makes the robot look correct. For collision, model the base as a single box and each wheel as a cylinder. For inertial entries, set the base mass to a realistic number and smaller masses for the wheels; include inertia values that approximate the distribution of mass. This balance gives stable contacts and realistic acceleration.

Pro tip
When in doubt, test with simplified collision shapes and tune inertia until the behavior matches expectations.
Common mistake
Using complex visual meshes for collision causes slow simulation and unstable contact physics.
