Module 7 › Chapter 7.1 › Gazebo Plugins
How plugins connect
Plugins bridge ROS and Gazebo by subscribing and publishing to ROS topics while manipulating Gazebo joints and sensors.
Diff drive plugin
Subscribes to cmd_vel → applies torques to left and right wheel joints → publishes odom.
Sensor plugins
Camera and LiDAR plugins publish image and scan topics usable by ROS nodes and RViz.
Plugin parameters
  • leftJoint, rightJoint — exact names from URDF
  • wheelSeparation, wheelDiameter — used to compute odometry
  • commandTopic, odometryTopic — ROS topic names to use
Debug tips
Use rostopic list to confirm topics like /cmd_vel and /odom appear, and check Gazebo logs for plugin errors when joint names differ.
Concrete example
A configured diff drive plugin converts a published linear x and angular z into left and right wheel velocities and applies torque to those joints in Gazebo.
