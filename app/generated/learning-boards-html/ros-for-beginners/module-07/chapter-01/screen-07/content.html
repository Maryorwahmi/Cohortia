Code example
URDF snippet
Below is a shortened XML snippet showing base and wheel links, joint, and a gazebo plugin.
<?xml version="1.0"?>
<robot name="my_robot">
  <link name="base_link"> ... </link>

  <link name="right_wheel"> ... </link>
  <joint name="right_wheel_joint" type="continuous">
    <parent link="base_link" />
    <child link="right_wheel" />
    <origin xyz="0.2 -0.15 0" rpy="0 1.5708 0" />
    <axis xyz="0 0 1" />
  </joint>

  <gazebo>
    <plugin name="differential_drive_controller" filename="libgazebo_ros_diff_drive.so">
      <leftJoint>left_wheel_joint</leftJoint>
      <rightJoint>right_wheel_joint</rightJoint>
      <commandTopic>cmd_vel</commandTopic>
      <odometryTopic>odom</odometryTopic>
    </plugin>
  </gazebo>
</robot>
Explanation
  • Joint names in URDF must match plugin entries for correct mapping.
  • Origin and axis define physical placement and rotation direction of joints.
  • Plugin parameters convert cmd_vel messages into wheel torques and publish odom.
Concrete example
If wheelDiameter increases, the same motor angular speed produces greater linear speed. Tune plugin parameters accordingly.
Pro tip
Keep plugin updateRate moderate (e.g., 50 Hz) to balance responsiveness and CPU load.
