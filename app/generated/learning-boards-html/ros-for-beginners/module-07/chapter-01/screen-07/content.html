Definition
Gazebo plugins
Plugins run inside Gazebo to control joints, sensors, and communication with ROS.
The differential-drive plugin subscribes to /cmd_vel and publishes /odom, acting as a translator between ROS and physics.
Sensor plugins publish streams like /scan and /camera/image_raw so other ROS nodes can subscribe and process data.
Sample plugin fragment
<gazebo>
  <plugin name="differential_drive_controller" filename="libgazebo_ros_diff_drive.so">
    <leftJoint>left_wheel_joint</leftJoint>
    <rightJoint>right_wheel_joint</rightJoint>
    <wheelSeparation>0.3</wheelSeparation>
    <wheelDiameter>0.1</wheelDiameter>
    <commandTopic>cmd_vel</commandTopic>
    <odometryTopic>odom</odometryTopic>
  </plugin>
</gazebo>
Pro tip
Start with a low torque value and increase while testing to avoid sudden unstable motion.
