Module 7 › Chapter 7.2 › Launch File

warehouse_patrol.launch

Author a single launch file that starts Gazebo, spawns the robot, sets parameters, and runs all nodes for a reproducible demo.

Launch responsibilities
  • Start Gazebo with the warehouse world.
  • Spawn the robot URDF and ensure TF frames are published.
  • Set /waypoints and other parameters centrally.
  • Start each node with the correct namespace and remappings.
Quick verification
# after launch
roslaunch warehouse_patrol.launch
# verify connections
rqt_graph
rostopic list | grep robot_status
rosnode list
Key Takeaway

Keep your launch file readable, parameterized, and able to selectively run subsets for incremental testing.
