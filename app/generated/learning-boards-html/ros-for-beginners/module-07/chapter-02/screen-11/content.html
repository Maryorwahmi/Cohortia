Toolset
Common commands to verify runtime behavior and capture evidence for debugging and grading.
# Visualize connections
rqt_graph

# Inspect a topic
rostopic echo /robot_status

# Plot numeric data
rqt_plot /odom/pose/pose/position/x

# Record a run
rosbag record -a
Common mistake
Relying on logs alone without reproducing errors in a rosbag. Always record a failing run to replay and isolate causes.
Example workflow
  1. Run full system via launch file.
  2. Open rqt_graph to check connectivity.
  3. Echo key topics and plot signals with rqt_plot.
  4. If failure occurs, rosbag record and replay to reproduce offline.
Takeaway
Make testing repeatable and record evidence for grading and future debugging.
