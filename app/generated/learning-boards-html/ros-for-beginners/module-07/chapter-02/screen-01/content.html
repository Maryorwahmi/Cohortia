Capstone Project: Building a Complete ROS Application

Design a simulated warehouse patrol robot that navigates waypoints, avoids obstacles, reports status, and accepts remote action goals. Implement nodes in Python and C++, orchestrate with a launch file, and test in Gazebo and RViz.

In this lesson
You will plan the system architecture, implement nodes incrementally, verify communication with rqt_graph and rostopic, and produce a final demo and report.
