Learning Objectives

Master the practical skills needed to implement and demonstrate the warehouse patrol project.

Bloom: Learn → Understand → Apply → Master
01
Design and implement multi-node system

You will map responsibilities to nodes, select topics and services, and implement node behavior to keep concerns separated. This matters because clear design prevents coupling and simplifies testing.

Verified Competency Milestone
02
Use launch files to orchestrate

You will author a single launch file that starts Gazebo, spawns the robot, sets parameters, and runs all nodes for a reproducible demo. This ensures your project is easy to run and grade.

Verified Competency Milestone
03
Test and debug in simulation

You will use rqt_graph, rostopic, rosbag, and RViz to validate data flows, inspect messages, and replay test runs to find bugs efficiently.

Verified Competency Milestone
04
Document and version control

You will write READMEs, architecture diagrams, and commit checkpoints. Clear documentation makes your project reproducible and easier to grade.

Verified Competency Milestone
