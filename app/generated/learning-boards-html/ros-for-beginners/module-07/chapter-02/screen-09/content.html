Definition

RobotStatus & LED service

Publish concise RobotStatus messages and expose a /set_led service to reflect runtime conditions on a simulated LED panel.

Terminal checks
# Observe robot status stream
rostopic echo /robot_status

# Call LED service manually
rosservice call /set_led "{red: true, green: false, yellow: false}"
Example log
RobotStatus: position (x:1.2 y:0.3), obstacle_detected: true, waypoint_index: 1
Why keep messages small?
Compact messages reduce bandwidth and make logs easier to read. Include only fields necessary for monitoring and tests.
Misconception
More fields equal better observability — false. Too much data slows tools and hides the essential state changes you need to see.
