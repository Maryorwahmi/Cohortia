navigation_controller

Drive to /target_waypoint using odometry and offer an action server for remote goals.

Controller sketch
# conceptual control loop
while running:
  current = read_odometry()
  target = last_received_target()
  pos_error = distance(current.position, target.position)
  angle_error = shortest_angle(current.yaw, target.yaw)
  linear = k_p_pos * pos_error
  angular = k_p_ang * angle_error
  publish('/cmd_vel', Twist(linear, angular))
  if goal_canceled or emergency_stop:
    publish('/cmd_vel', Twist(0,0))
    set_action_canceled()
Pro tip

Always publish a zero velocity when stopping to ensure the robot halts in simulation and replay.

Action behavior

The action server accepts a waypoint index, drives there, publishes feedback, and returns success on arrival or preemption on cancel.

Common mistake

Failing to handle cancellations or emergency parameters leaves the robot publishing commands after it should stop.
