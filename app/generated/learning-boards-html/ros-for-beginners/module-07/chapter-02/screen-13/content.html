Module 7 › Chapter 7.2 › Workflow

Incremental development & deliverables

Implement nodes one at a time, document them, and record a concise demo and report for submission.

Step-by-step plan
  1. Model and spawn robot in Gazebo.
  2. Implement waypoint_manager and verify /target_waypoint.
  3. Implement navigation_controller and test with fake odometry.
  4. Add obstacle_avoider, status_monitor, led_controller.
  5. Implement remote_controller and emergency_stop, then orchestrate with launch file.
Deliverables
  • warehouse_patrol.launch that starts the full system.
  • 3-minute demo video showing behavior, rqt_graph, and RViz.
  • Project report with architecture diagram, node descriptions, communication matrix, and testing results.
Key Takeaway

Make small commits, document everything, and produce a short, focused demo to show system behavior clearly.
