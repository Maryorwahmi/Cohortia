List concrete components and their contracts: sensors, topics, services, actions, and parameters.

Key topics

Parameters

Why this matters
A precise contract prevents runtime surprises. When message types and parameter names are explicit, nodes can be developed independently and integrated later with confidence. Use this sheet as the single source of truth during implementation and for your project report.
Misconception
"Nodes can infer message structure at runtime" — they cannot. Define types and fields up front to avoid mismatches.
Takeaway
A written spec shortens integration time and becomes the foundation for tests and documentation.
