URDF Robot & Gazebo

Define links, joints, sensors, and validate sensor topics before writing other nodes.

Validation checklist
  • Spawn robot in Gazebo and confirm no spawn errors.
  • Use rostopic list to see /scan and /camera/image_raw topics.
  • Use RViz to visualize robot model, TF frames, and sensor data.
  • Check collision geometry for physics interactions with obstacles.
Common mistake

Mismatched TF frames or missing collision geometry causes sensors and physics to behave unexpectedly.

Quick spawn demo (terminal-style)
# example spawn sequence (conceptual)
# spawn robot model into Gazebo
spawn_robot(urdf_file='warehouse_bot.urdf')
# confirm topics
rostopic_list = run_command('rostopic list')
assert '/scan' in rostopic_list and '/camera/image_raw' in rostopic_list
# visualize in RViz
open_rviz(config='warehouse.rviz')
Key Takeaway

A correct URDF and a successful Gazebo spawn let all other nodes assume reliable sensor data.
