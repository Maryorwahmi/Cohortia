Process

URDF → Gazebo → RViz

Build URDF for the differential-drive base and sensor mounts. Spawn in Gazebo and open RViz to check TFs and sensor topics.

  • Confirm /scan publishes LaserScan messages in simulation.
  • Confirm /camera/image_raw frames are present and viewable.
  • Verify /odom frame_id and consistency for navigation.
Terminal: spawn robot
# Start Gazebo and spawn the robot
roslaunch warehouse_patrol.launch gazebo:=true

# Verify topics
rostopic list | grep "/scan\|/camera\|/odom"
