warehouse_patrol.launch

Include robot spawn, parameter settings, and node launch groups with optional flags to start subsets for debugging.

Terminal: launch command
# Full system launch
roslaunch warehouse_patrol.launch

# Launch only simulation and core nodes for debugging
roslaunch warehouse_patrol.launch core_only:=true
Design tip
Provide named launch arguments so graders can run the full demo or narrow tests quickly without editing files.
Common mistake
Hard-coding paths or parameters in launch files prevents reproducible runs on other machines. Use arguments and relative package paths.
Takeaway
A well-structured launch file is an essential deliverable for grading: one command to start the entire demo and clear options for debugging.
