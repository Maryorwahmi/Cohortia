Assessment Goals

Understand how each objective maps to the rubric and the demo requirements.

Time estimate: 15-minute demo + project report
Architecture
Clear separation of concerns

Does each node have a single responsibility and well-defined inputs and outputs?

Integration
Correct topics, services, actions

Are messages exchanged and parameters used as specified in the project sheet?

Simulation
Behavior in Gazebo

Robot navigates waypoints, stops for obstacles, resumes, and responds to remote actions.

Demo checklist
  • Robot moves between waypoints in simulation.
  • Obstacle stops and red LED indicator turn on.
  • Remote controller sends and cancels goals.
  • Launch file starts everything with one command.
