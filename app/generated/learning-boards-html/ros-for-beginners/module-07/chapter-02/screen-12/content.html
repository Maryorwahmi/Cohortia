Testing and ROS tools

Combine rqt_graph, rostopic, rqt_plot, rosbag, and RViz to validate messages and behavior in simulation.

Recommended checks
  • rqt_graph: verify node connections and topic edges.
  • rostopic echo /robot_status: confirm periodic updates.
  • rosbag record: capture a failing run and replay it for debugging.
  • rqt_plot: inspect numeric signals like distance to target.
Debugging example

If the robot does not resume after an obstacle, record a bag, replay sensor input, and observe which node fails to clear /obstacle_detected or publishes incorrect /cmd_vel.

Key Takeaway

Record and replay when behavior is intermittent; it makes root-cause analysis far more deterministic.
