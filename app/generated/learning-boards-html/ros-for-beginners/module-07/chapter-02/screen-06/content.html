waypoint_manager (conceptual)

Load /waypoints from the parameter server and publish /target_waypoint as a Pose to drive navigation.

Conceptual pseudocode
# conceptual pseudocode for waypoint_manager
waypoints = params.get('/waypoints', default=[])
index = 0
while running:
  target = waypoints[index]
  publish('/target_waypoint', Pose(target))
  wait_for_reach_or_timeout()
  index = (index + 1) % len(waypoints)
Test tip

Set /waypoints manually, run the node, and use rostopic echo /target_waypoint to confirm output.

Example scenario

If /waypoints has three entries, the manager cycles 0 → 1 → 2 → 0. Use an explicit arrival detection or timeout to advance the index.

Key Takeaway

Make parameter reads robust and include clear logs so missing waypoints are detected early.
