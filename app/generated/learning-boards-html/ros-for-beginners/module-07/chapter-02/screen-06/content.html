Process Flow

Node responsibilities

waypoint_manager (Python)
Reads /waypoints parameter, publishes /target_waypoint (geometry_msgs/Pose) in a loop.
navigation_controller (Python)
Subscribes /target_waypoint and /odom, computes proportional control, publishes /cmd_vel.
obstacle_avoider (Python)
Subscribes /scan, stops robot and sets /obstacle_detected when obstacle within 0.5 m.
Contracts & example
For each node, specify: parameters, topics published, topics subscribed, services provided or consumed, and actions involved. This contract becomes your node README and test plan.
Example node contract (navigation_controller)
  • Subscribes: /target_waypoint (Pose), /odom (Odometry)
  • Publishes: /cmd_vel (Twist)
  • Provides: action server /move_to_waypoint (goal: waypoint index)
  • Parameters: none local, checks /emergency_stop
Takeaway
Document contracts early to allow parallel development and straightforward integration tests.
