Definition

Obstacle detection & emergency stop

Detect obstacles from /scan, set /obstacle_detected, and use /emergency_stop to halt all nodes through a global parameter.

Terminal: set emergency stop
# Trigger emergency stop from a client
rosservice call /emergency_stop "{}"

# OR set parameter for testing
rosparam set /emergency_stop true
Common mistake
Assuming a single node's stop command suffices for system safety. Ensure every node checks /emergency_stop and respects a global stop condition.
Example scenario
Robot approaches a pallet. LiDAR reports an obstacle within 0.5 m. obstacle_avoider sets /obstacle_detected true. navigation_controller stops publishing forward velocities. led_controller turns on the red LED via /set_led service call. When obstacle clears, parameter is false and motion resumes.
Takeaway
Global flags and service calls coordinate safety across multiple nodes without heavy coupling.
