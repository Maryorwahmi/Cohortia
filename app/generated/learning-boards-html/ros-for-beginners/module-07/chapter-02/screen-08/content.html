Safety: obstacle_avoider & emergency_stop

Design both local obstacle responses and a global emergency parameter so stops are reliable across the system.

Detection flow
LiDAR /scan
obstacle_avoider
/cmd_vel stop & set /obstacle_detected
Scenario

Robot approaches crate, obstacle_avoider detects < 0.5 m, publishes zero velocity and sets /obstacle_detected true.

Global emergency

Emergency service call sets /emergency_stop to true. All nodes must watch this parameter and halt immediately.

Key Takeaway

Use both local stop commands and a persistent emergency parameter so the system cannot be accidentally resumed without acknowledgment.
