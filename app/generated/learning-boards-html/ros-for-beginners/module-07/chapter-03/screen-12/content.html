Module 7 › Chapter 7.3 › Smart-home Architecture
System Components
sensor_publisher
Publishes /temperature (Float64), /motion (Bool), /camera/image_raw (Image).
patrol_controller
Subscribes to /motion, sends goals to /inspect_area, and calls /send_alert when motion occurs.
camera_node
Hosts an action server /inspect_area and publishes higher-resolution images during inspection.
alert_service
Provides /send_alert service to log alerts when called by patrol_controller.
Key Takeaway

Design each node with a single responsibility and pick the communication primitive that matches the interaction pattern.

Launch & Parameters
smart_home.launch sets /house_name, /patrol_interval, and /alert_threshold_temp, then starts all nodes. Tuning these values at launch lets you reuse the code across environments.
