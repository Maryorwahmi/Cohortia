Debug Subscriber Failures
Five frequent causes
  1. Workspace not sourced: devel/setup.bash missing so messages not found.
  2. Message mismatch: types must be identical and generated from same package.
  3. Topic name mismatch: exact names and leading slashes matter.
  4. No spin: callbacks not processed without ros::spin or rospy.spin.
  5. Executable mismatch: wrong executable name in rosrun or launch file or permissions missing.
Diagnostic steps: use rostopic list/echo, rqt_graph, and rosbag to isolate where the pipeline breaks. Test with a minimal publisher or subscriber to confirm type and name alignment.
