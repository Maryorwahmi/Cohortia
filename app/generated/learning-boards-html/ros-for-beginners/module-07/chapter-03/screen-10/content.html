Bug example
<launch>
  <node pkg="my_pkg" type="my_node.py" name="my_node" />
  <param name="max_speed" value="1.5" />
</launch>

Fix: move the param inside the node block so it is private to my_node.
Make parameters private when they are node-specific and global when they are shared. Always test the launch outcome with rqt_graph and rostopic list.
Remap usage
Use <remap from="/old_name" to="/new_name" /> inside a node to redirect names without changing source code. This is ideal for experimentation or integrating modules with different name conventions.
Key Takeaway

Launch files are powerful: design them to express configuration and mappings so your code remains portable.
