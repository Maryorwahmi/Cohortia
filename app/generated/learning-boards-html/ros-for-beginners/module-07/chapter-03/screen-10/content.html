Design Architecture
Node responsibilities
sensor_publisher
Publishes /temperature (Float64), /motion (Bool), /camera/image_raw (Image) at configured rates.
patrol_controller
Subscribes to /motion. On detection, sends a goal to /inspect_area and calls /send_alert service.
camera_node
Hosts /inspect_area action server, publishes higher-res images during inspection, supports preemption.
alert_service
Provides /send_alert to log or forward alerts; discrete request-response service.
Parameters & launch
/house_name, /patrol_interval, /alert_threshold_temp set via launch file so behavior is configurable without code changes.
