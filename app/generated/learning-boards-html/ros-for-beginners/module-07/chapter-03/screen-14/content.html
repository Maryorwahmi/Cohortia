Communication primitives
Choose topics for streams, services for requests, and actions for cancellable goals with feedback.
Discovery & config
The Master manages discovery; the Parameter Server plus launch files configure behavior at runtime.
Defensive node design
Keep nodes alive, check for preemption, match message types, and verify exact topic names to avoid runtime failures.
Summary

These three ideas let you explain answers, find bugs, and architect simple ROS systems reliably.
