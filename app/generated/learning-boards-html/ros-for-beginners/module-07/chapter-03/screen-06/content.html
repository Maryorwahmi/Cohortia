rospy.init_node('listener')

Problem: script exits immediately because there is no event loop to process callbacks.
Corrected pattern
#!/usr/bin/env python3
import rospy
from std_msgs.msg import String

def callback(msg):
  print(msg.data)

if __name__ == '__main__':
  rospy.init_node('listener')
  sub = rospy.Subscriber('/chatter', String, callback)
  rospy.spin()
Test with roscore and publishing to /chatter. Verify the listener prints messages and stays alive.
