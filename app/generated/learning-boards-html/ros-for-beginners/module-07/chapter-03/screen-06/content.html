Module 7 › Chapter 7.3 › Parameters & Launch
Process Flow
1
Start roscore
Parameter Server becomes available for storing config values.
2
Launch file sets params
Launch loads YAML or sets tags to configure nodes at startup.
3
Nodes read parameters
Nodes fetch values from the Parameter Server at runtime to vary behavior without code changes.
Key Takeaway

Place params where you intend them to live: inside a node tag for private params, globally when you want system-wide values.

Concrete example & fix
The buggy launch file placed outside the node. To make it a private parameter for the node, move the param inside the node block so it configures that node only.
Why this matters: scoping mistakes lead to unexpected values and make debugging harder when many nodes share similar names or parameters.
