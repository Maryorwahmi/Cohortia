Design Implementation Notes
sensor_publisher snippet
# sensor_publisher.py
rospy.init_node('sensor_publisher')
temp_pub = rospy.Publisher('/temperature', Float64, queue_size=10)
motion_pub = rospy.Publisher('/motion', Bool, queue_size=10)
image_pub = rospy.Publisher('/camera/image_raw', Image, queue_size=10)
rate = rospy.Rate(1)
while not rospy.is_shutdown():
  # publish sensors
  rate.sleep()
Use queue_size and controlled rate so the publisher behaves well under load.
patrol_controller notes
Wait for the action server, send a goal, and handle the result or preemption. Call alert service with error handling for service exceptions.
Common cross-language causes
  • devel/setup.bash not sourced so new message packages not visible.
  • Message types not from the same package or differing definitions.
  • Topic name mismatches including leading slash differences.
  • Missing spin or spin-like loops so callbacks never run.
