Problematic snippet
for (int i = 0; i < goal->count; ++i) {
    my_pkg::MyActionFeedback feedback;
    feedback.percentage = float(i) / goal->count;
    _as.publishFeedback(feedback);
}
_as.setSucceeded(result);
This loop never checks for preemption and will always report success even if the client cancels the goal.
Corrected approach
for (int i = 0; i < goal->count; ++i) {
    if (_as.isPreemptRequested()) {
        _as.setPreempted();
        return;
    }
    my_pkg::MyActionFeedback feedback;
    feedback.percentage = float(i) / goal->count;
    _as.publishFeedback(feedback);
    ros::Duration(0.1).sleep();
}
_as.setSucceeded(result);
Pro Tip

Give frequent, meaningful feedback and check preemption often so clients can cancel promptly and the system remains responsive.
