Module 7 › Chapter 7.3 › What is ROS?
Core Concept

ROS as middleware

ROS provides naming, discovery, and communication channels for distributed robot software. The Master registers node names, topics, and services.

Definition

Middleware framework that provides communication infrastructure for robots.

Misconception

ROS is not a real-time OS and the Master does not forward every message; it manages discovery and registration.

Concrete example

A camera node registers /camera/image_raw with the Master; when a display node subscribes, the Master supplies connection info so the two can communicate.

Key Takeaway

Think discovery and naming first. If nodes are missing in rqt_graph, check roscore and node names.

Quick checklist
  • Is roscore running? Without it, discovery fails.
  • Do nodes use unique names or anonymous=True where needed?
  • Use rqt_graph to confirm registrations and connections.
Why this matters

Discovery problems look like communication failures. Fix the registry issues before chasing message-handling bugs.
