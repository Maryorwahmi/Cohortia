Section A Multiple Choice
Definitions
Key definitions the exam checks:
  • ROS — middleware framework providing communication infrastructure for robots.
  • ROS Master — central registry that matches publishers and subscribers by name.
  • Topic — asynchronous stream suitable for sensor data.
  • Service — synchronous request-response for discrete tasks.
  • Action — asynchronous, cancellable task with feedback and result.
Common misconception
Don't assume Master forwards messages. If connections fail, check name resolution and namespaces first.
Practice mapping
Given a scenario, pick the primitive by matching behavior:
Streaming camera frames
Use topics — continuous flow, many subscribers can listen.
Request battery level
Use a service — single request, immediate response.
Navigate to a waypoint with progress
Use an action — long running, needs feedback and cancellation.
