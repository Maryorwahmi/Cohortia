Multiple-choice tactics
  • Match definitions to use cases, not just short descriptions.
  • Eliminate distractors that state partial truths out of context.
  • Prefer the answer that aligns with the communication pattern and runtime behavior.
Code & design tactics

For code, run through lifecycle expectations: is the node kept alive, are callbacks processed, are preemption checks present? For designs, map requirements directly to nodes and primitives and show a launch file to tie them together.

A calm, stepwise approach beats guesswork when time is limited.
