Section B Short Answer
Definition cards
Topic
Asynchronous, one-way stream. Example: /camera/image_raw for continuous images.
Service
Synchronous request-response. Example: /get_battery_level returns a single value on demand.
Parameter Server
Shared key-value store for runtime configuration, loaded at roscore startup or via launch files.
Process: choosing the right tool
Steps to decide:
  1. Is this continuous data or a single query? If continuous, use a topic.
  2. Does the caller need a blocking response? If yes, use a service.
  3. Does the operation take time and need feedback or cancellation? Use an action.
Example
A camera publishes images on a topic; a dashboard subscribes. A client queries battery level via a service when needed.
