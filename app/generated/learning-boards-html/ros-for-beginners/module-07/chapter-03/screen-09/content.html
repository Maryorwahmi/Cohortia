Actions Preemption
Problematic pattern
for (int i = 0; i < goal->count; ++i) {
  my_pkg::MyActionFeedback feedback;
  feedback.percentage = float(i) / goal->count;
  _as.publishFeedback(feedback);
}
_as.setSucceeded(result);
Issue: no preemption checks and no rate limiting.
Robust fix
for (int i = 0; i < goal->count; ++i) {
  if (_as.isPreemptRequested()) {
    _as.setPreempted();
    return;
  }
  // publish feedback
  ros::Duration(0.1).sleep();
}
_as.setSucceeded(result);
Add preemption checks and a sleep to yield CPU and allow cancellations to take effect.
