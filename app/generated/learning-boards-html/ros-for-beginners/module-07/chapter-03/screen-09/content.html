Module 7 › Chapter 7.3 › rospy.spin()
Problem
import rospy
from std_msgs.msg import String

def callback(msg):
    print(msg.data)

rospy.init_node('listener')
sub = rospy.Subscriber('/chatter', String, callback)
This node creates the subscriber but exits immediately because there is no call to keep the process alive.
Corrected version
#!/usr/bin/env python3
import rospy
from std_msgs.msg import String

def callback(msg):
    print(msg.data)

if __name__ == '__main__':
    rospy.init_node('listener')
    sub = rospy.Subscriber('/chatter', String, callback)
    rospy.spin()
Key Takeaway

rospy.spin() or an equivalent loop is required so callbacks can run; use the __main__ guard for safe imports.
