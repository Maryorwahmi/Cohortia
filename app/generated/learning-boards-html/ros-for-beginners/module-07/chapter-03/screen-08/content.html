Module 7 › Chapter 7.3 › Publisher/Subscriber Mismatch
Common Causes
  1. devel/setup.bash not sourced — message types not found.
  2. Message definitions differ — generated types mismatch.
  3. Topic name mismatch — leading slash or typo.
  4. Node not spinning — callbacks never executed.
  5. Wrong executable or launch configuration.
Step-by-step fix
1) Confirm roscore is running and inspect rqt_graph. 2) Use rostopic list and rostopic type to verify topic names and types. 3) Source your workspace and rebuild message packages if needed. 4) Add logging and verify nodes call spin. 5) Check launch file names and remaps.
Key Takeaway

Work from discovery to message format to runtime behavior; that order finds root causes faster than random edits.
