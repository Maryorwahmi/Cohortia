Module 3 › Chapter 3.1 › Adding services to CMakeLists
CMake snippet
find_package(catkin REQUIRED COMPONENTS
  ...
  message_generation
)

add_service_files(
  FILES
  SetLed.srv
)

generate_messages(
  DEPENDENCIES
  std_msgs
)
Add the service file here and list dependencies. Then rebuild so generated headers and Python modules are available.
Checklist
  • Place .srv file in srv/ directory.
  • Add message_generation to find_package.
  • Call add_service_files with your .srv filename.
  • Call generate_messages with any dependencies listed.
Common mistake
Forgetting to rebuild the workspace after adding .srv files. Always rebuild and verify the generated types before running nodes that import them.
