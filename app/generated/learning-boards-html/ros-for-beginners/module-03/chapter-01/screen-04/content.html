Module 3 › Chapter 3.1 › What is a ROS Service?
Definition & claim

A service is a synchronous request-response interaction. The client sends a request message and blocks until the server returns a response. Services act like remote function calls across nodes in ROS.

Concrete example: Ask \'What is the current battery level?\' — the server replies with the numeric percentage and the client uses that value immediately.
Misconception check: Services are not streams. They are one-off, blocking calls. For continuous updates, use a topic.
Visual metaphor
Think of a service as a two-way street: you ask a question and wait for the reply before continuing.
Contrast: a topic is a one-way highway where messages flow continuously without waiting.
Key Takeaway

Use services for short, synchronous queries or commands that must return a confirmation or value immediately.
