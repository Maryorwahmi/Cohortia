The .srv contract
# File: srv/SetLed.srv
int32 led_number
bool state
---
bool success
string message
Request fields are above the separator and response fields are below. Keep fields concise so calls return quickly.
Process steps
  1. Define .srv with request and response fields.
  2. Add the .srv file to add_service_files() in CMakeLists.txt.
  3. Generate messages so both Python and C++ can import the types.
  4. Implement server and client using the generated types.
Design tip
Favor small, typed fields in .srv files. Avoid placing large blobs or streaming data in service requests or responses.
