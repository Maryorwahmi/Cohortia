Server example (visual)
#!/usr/bin/env python3
import rospy
from my_first_robot.srv import SetLed, SetLedResponse

def handle_set_led(req):
  rospy.loginfo("Setting LED %d to %s", req.led_number, req.state)
  # control hardware here
  success = True
  message = "LED %d set to %s" % (req.led_number, req.state)
  return SetLedResponse(success, message)

if __name__ == '__main__':
  rospy.init_node('led_server')
  srv = rospy.Service('/set_led', SetLed, handle_set_led)
  rospy.loginfo("LED server is ready.")
  rospy.spin()
The handler returns a SetLedResponse instance. Use logging to record requests and avoid long blocking operations inside the handler.
Explanation
  • rospy.Service advertises the service to the ROS Master.
  • Handler receives a typed request object matching the .srv file.
  • Return the generated response type, not raw primitives.
Key Takeaway

Keep the handler simple and fast. Use the generated response type and verify with rosservice call.
