Module 3 › Chapter 3.1 › What to Remember
Block responsibly
Avoid high-frequency service polling. Use topics for repeated telemetry.
Generate types
Add .srv to CMakeLists and run the build to produce Python/C++ bindings.
Pick the right pattern
Topic for streaming, service for single queries, action for long-running goals.
Final thought
Test services from the terminal early and keep service operations short and predictable to maintain system responsiveness.
