Lab checklist
  1. Write ComputeSum.srv with two request integers and one response integer for sum.
  2. Add the .srv file to add_service_files() and run catkin_make or colcon to generate messages.
  3. Implement Python server that returns the computed sum and logs the request.
  4. Use rosservice call to test the server from the terminal before running the client.
  5. Implement clients in Python and C++ and verify cross-language compatibility.
Quick terminal cheatsheet
rosservice list — show active services
rosservice info /set_led — inspect a service
rosservice call /set_led "led_number: 1 state: true" — call from terminal
Common pitfall
Don't call a service at high frequency for streaming data. Use a topic for continuous telemetry to avoid blocking the caller.
