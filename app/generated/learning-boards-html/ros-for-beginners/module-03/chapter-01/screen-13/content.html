Test plan
  1. Start Python server and confirm rosservice list shows /compute_sum.
  2. Call rosservice call /compute_sum "a: 5 b: 3" and confirm sum: 8.
  3. Run the Python client to request 5 and 3 and print the result.
  4. Implement and build C++ versions and verify cross-language calls.
Real-world callout
Cross-language testing proves ROS serializes messages consistently. This is how a Python client can call a C++ server without adapter code.
