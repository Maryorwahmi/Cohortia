Terminal demo blocks
rosservice list — shows active services, e.g. /set_led, /get_battery_level
rosservice info /set_led — shows provider node and service type
rosservice call /set_led "led_number: 1 state: true" — invoke the service from terminal
Test flow
  1. Start the server node and confirm it appears in rosservice list.
  2. Use rosservice info to verify the type and provider node.
  3. Call rosservice call to exercise the handler and inspect response.
Debugging tip
If rosservice info or args shows no type, rebuild your workspace to ensure generated message types are present.
