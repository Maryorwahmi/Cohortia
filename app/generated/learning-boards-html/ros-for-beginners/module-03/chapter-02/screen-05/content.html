Common service calls
# Reset the simulation
rosservice call /reset

# Clear the drawing
rosservice call /clear

# Spawn turtle2 at (5,5)
rosservice call /spawn "x: 5.0
y: 5.0
theta: 0.0
name: 'turtle2'"

# Teleport turtle1 to (2,3)
rosservice call /turtle1/teleport_absolute "x: 2.0
y: 3.0
theta: 1.57"

# Set pen color to red
rosservice call /turtle1/set_pen "r: 255
g: 0
b: 0
width: 3
off: 0"
Tips and common mistakes
  • Remember to match the service type fields and use proper indentation in the YAML payload.
  • Check the service response; CLI calls return immediately when a response arrives.
  • If a service is missing, confirm the node providing it is running.
Key Takeaway

CLI calls are an essential habit: they make the request structure visible and let you debug service interactions before coding clients.
