Module 3 › Chapter 3.2 › Service-based control pattern
Pattern explained
The battery node publishes BatteryState messages continuously. The monitor subscribes to that topic and calls a /set_led service when the percentage falls below a threshold. The service changes the LED panel state synchronously and returns success.
Python client snippet (concept)
rospy.wait_for_service('/set_led')
set_led = rospy.ServiceProxy('/set_led', SetLed)
# in callback:
if msg.percentage < threshold and not led_on:
    set_led(3, True)
    led_on = True
Safety and performance
  • Prevent repeated calls by tracking local state or using hysteresis.
  • Keep service handlers fast to avoid blocking important callbacks.
  • Always check the service response and log or retry based on success flags.
Common mistake
Calling services on every topic message
Use local guards so repeated identical calls are avoided.
