Module 3 › Chapter 3.2 › Hands-on turtlesim lab
Step-by-step
  1. rosservice call /spawn to create turtle2 at (5,5).
  2. rosservice call /turtle1/teleport_absolute to set turtle1 starting pose.
  3. rosservice call /turtle1/set_pen to set color and width.
  4. Use teleop to publish cmd_vel and draw a square or circle.
  5. rosservice call /kill to remove simulation turtles when finished.
Automation advice
  • Keep spawn/kill logic in the script using services and movement in a separate publisher loop.
  • Test CLI calls first to confirm request fields and expected responses.
  • Log service responses so your script knows whether setup succeeded before moving the turtle.
Key Takeaway

Separate discrete state changes (services) from continuous motion (topics) when building automation scripts.
