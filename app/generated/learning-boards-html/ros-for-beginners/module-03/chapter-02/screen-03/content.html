Module 3 › Chapter 3.2 › Objectives — Hands-on and Design
Hands-on checklist
  1. Run rosservice call to spawn turtle2 at (5,5), teleport turtle1, set pen color and width, and kill turtle2.
  2. Write a Python script that spawns turtle2, commands turtle1 via topic to draw a circle, and kills turtle2 using services.
  3. Implement a gripper service server with a position request and boolean success response; test with a client at positions 0.0, 0.5, 1.0.
Design checks
  • Is the service fast enough? If not, consider an action.
  • Is the service idempotent? Prefer idempotent semantics to allow safe retries.
  • Does the response include success flags and error messages for client handling?
