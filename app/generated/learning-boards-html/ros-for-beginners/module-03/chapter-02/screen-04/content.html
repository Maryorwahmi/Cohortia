Module 3 › Chapter 3.2 › What a ROS service is
Definition

A service is a synchronous call where a client sends a typed request and receives a typed response after the server processes the request.

Key properties
  • Typed requests and responses (service definition).
  • Synchronous: client blocks or waits for reply.
  • Used for discrete, quick actions or queries.
Concrete example
Turtlesim spawn
rosservice call /spawn "x: 5.0
y: 5.0
theta: 0.0
name: 'turtle2'"
The command blocks until the server returns the spawned turtle name, so the client knows the spawn succeeded.
Misconception
Services are for streaming data
Use topics for continuous data, not services.
Takeaway
Use services for quick, discrete operations and include clear success responses.
