Module 3 › Chapter 3.2 › Service vs Topic vs Action
Topic
Continuous, asynchronous streams like sensor data or joystick inputs. Not for discrete commands.
Service
Synchronous, single request/response. Best for discrete, immediate state changes like mode switches.
Action
Long-running tasks with feedback and preemption, such as move-to-goal behaviors.
Assessment
Question: Should a mode switch be a topic, service, or action? Answer: a service — it is discrete and the client benefits from immediate confirmation.
