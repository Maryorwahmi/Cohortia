Module 3 › Chapter 3.2 › Real robot applications for services
Common robot services
  • /gripper/close — request force, response success flag.
  • /set_mode — request mode string (autonomous/manual) and confirmation.
  • /set_pid_gains — update controller gains without restart.
  • /reset_odometry — zero encoder counts for calibration.
  • /save_map — trigger SLAM to write map file and return status.
Design implications
  • Use services when the client needs immediate confirmation that a state change happened.
  • Prefer actions for long-running tasks needing feedback and preemption.
  • Include success flags and messages to support robust client logic and retries.
