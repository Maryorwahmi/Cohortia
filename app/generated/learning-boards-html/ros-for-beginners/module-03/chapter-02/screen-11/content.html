Script skeleton (concept)
#!/usr/bin/env python3
import rospy
from turtlesim.srv import Spawn, Kill
from geometry_msgs.msg import Twist

rospy.init_node('turtle_automation')
rospy.wait_for_service('/spawn')
spawn = rospy.ServiceProxy('/spawn', Spawn)
kill = rospy.ServiceProxy('/kill', Kill)
vel_pub = rospy.Publisher('/turtle1/cmd_vel', Twist, queue_size=10)

# Spawn helper turtle
res = spawn(5.0, 5.0, 0.0, 'turtle2')
# Draw a circle by publishing Twist messages for a duration
# Kill helper turtle when done
kill('turtle2')
Test each step from the CLI first, then compose into a script. Use small waits between service calls and motion to ensure entities exist.
Testing checklist
