Module 3 › Chapter 3.2 › Turtlesim service reference
Stateless services
  • /reset — std_srvs/Empty: clears screen, recenters the turtle.
  • /clear — std_srvs/Empty: clears drawing without moving turtle.
  • /kill — turtlesim/Kill: request has name; removes a turtle.
Stateful services
  • /spawn — turtlesim/Spawn: x, y, theta, name → returns name.
  • /turtle1/teleport_absolute — TeleportAbsolute: move to absolute pose.
  • /turtle1/teleport_relative — TeleportRelative: move relative to current pose.
  • /turtle1/set_pen — SetPen: r,g,b,width,off to change pen attributes.
Quick reminder
Use spawn and kill to manage multiple turtles; use set_pen to change future drawing properties, not past paths.
