Module 2 › Chapter 2.2 › Python Subscriber
Code
#!/usr/bin/env python3
import rospy
from std_msgs.msg import String

def callback(msg):
  rospy.loginfo("Received: %s", msg.data)

if __name__ == '__main__':
  rospy.init_node('robot_news_listener', anonymous=True)
  sub = rospy.Subscriber('/robot_news', String, callback)
  rospy.loginfo("Subscriber is ready. Waiting for messages...")
  rospy.spin()
This pattern shows node init, subscriber creation, logging, and spin to process callbacks.
Explanation
  • rospy.Subscriber registers the callback for messages on /robot_news.
  • Keep the returned subscriber in a variable to prevent garbage collection in Python.
  • rospy.spin() blocks and lets rospy process incoming messages and call callbacks.
Example
Publish a string with rostopic pub and watch the log from the callback showing Received: <message>.
Misconception
rospy.Subscriber does not block; spin is required to prevent the script from exiting immediately.
Key Takeaway

Follow the init → subscribe → spin pattern and keep callbacks brief or delegate heavy work.
