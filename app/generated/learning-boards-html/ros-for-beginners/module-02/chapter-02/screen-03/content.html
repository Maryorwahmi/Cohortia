How to verify and avoid mistakes

Practical checks and small tests to confirm your subscriber logic works and stays alive.

Test
rostopic pub / rostopic echo

Send test messages and watch the output topic to confirm transforms and published messages.

Check
Python Subscriber object

Keep the subscriber in a variable so it is not garbage collected and remains active.

Verify
Anonymous names

Use anonymous=True or AnonymousName to run multiple instances without name collisions.

Common mistake

Exiting the node immediately after creating a subscriber prevents callbacks from ever running. Always call spin or keep the node alive.

Pro tip

If processing may block, consider offloading work to a worker thread or use a multi-threaded spinner for C++.
