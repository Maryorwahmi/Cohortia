Definition

Subscriber and callback model

A subscriber registers for messages on a topic; the callback is executed by ROS when messages arrive.

Key points
  • ROS pushes messages to your callback; no polling required.
  • Python callbacks run sequentially in the main thread unless you use extra threading.
  • C++ can execute callbacks on separate threads with appropriate spinners.
Common misconception
Subscribers do not actively fetch data; ROS delivers messages for you. Expect that slow callbacks slow down subsequent processing in Python.
Key Takeaway

Design callbacks to be fast, or move heavy work out of the callback to avoid blocking message delivery.

Analogy

Mailbox and mail-handler

Mailbox (Topic)

Messages arrive here and wait for the subscriber to handle them.

Mail-handler (Callback)

Opens and processes messages when notified by ROS.

Example scenario
A camera publishes frames at 30 Hz. The subscriber's callback processes each frame. If processing takes 200 ms per frame, callbacks may fall behind unless you buffer or parallelize work.
Check your understanding
If your Python callback takes 5 seconds, what happens to incoming messages?
Pro tip
Keep only minimal logic in callbacks and hand off heavy work to background threads or queues.
