Module 2 › Chapter 2.2 › Anonymous Nodes
Definition

Anonymous node names

Append a random suffix to node names so multiple instances can run without colliding on the ROS master.

Python
rospy.init_node('sensor_reader', anonymous=True)
C++
ros::init(argc, argv, "sensor_reader", ros::init_options::AnonymousName)
Why use it
Run many identical nodes, each with a unique name, so they register independently.
When not to use
If other components discover nodes by a stable name, avoid anonymous naming.
Validation
Check rosnode list to see unique instance names like sensor_reader_12345.
Key Takeaway

Anonymous names are essential for scalable deployments of identical nodes; use stable names when needed for discovery.
