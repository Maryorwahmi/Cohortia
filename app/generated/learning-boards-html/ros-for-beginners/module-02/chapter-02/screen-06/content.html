Module 2 › Chapter 2.2 › C++ Subscriber
Code
#include <ros/ros.h>
#include <std_msgs/String.h>

void callback(const std_msgs::String::ConstPtr& msg) {
  ROS_INFO("Received: %s", msg->data.c_str());
}

int main(int argc, char** argv) {
  ros::init(argc, argv, "robot_news_listener");
  ros::NodeHandle nh;

  ros::Subscriber sub = nh.subscribe("/robot_news", 10, callback);
  ROS_INFO("Subscriber is ready. Waiting for messages...");
  ros::spin();

  return 0;
}
Note the use of ConstPtr and queue_size. Build and run this node, then publish strings to /robot_news to see ROS_INFO output.
Explanation
  • ConstPtr provides a shared pointer to the message without copying data.
  • queue_size sets how many messages to buffer before dropping old ones.
  • ros::spin() processes incoming messages until shutdown.
When to use multithreading
If callbacks perform heavy work, a MultiThreadedSpinner in C++ allows parallel callback execution and reduces message loss due to slow handlers.
Key Takeaway

C++ offers efficient zero-copy access through ConstPtr and configurable buffering via queue_size; pick a spinner strategy that matches your processing needs.
