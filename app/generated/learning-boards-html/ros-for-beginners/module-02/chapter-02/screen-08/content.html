Module 2 › Chapter 2.2 › Callback: Python vs C++
Python

Sequential callbacks

Callbacks run in the main thread and are invoked in arrival order. A single slow handler delays subsequent callbacks.

Misconception
Python callbacks are not automatically parallel; they run one after another unless you create your own threads.
Tip

Use worker threads from callbacks if you must handle long-running tasks.

C++

Threaded callbacks possible

With a MultiThreadedSpinner, callbacks can run concurrently on multiple threads, improving throughput for CPU-bound handlers but requiring thread-safe code.

Queue and buffering
queue_size controls how many messages are buffered. If callbacks are slower than incoming rate, messages will be dropped when the buffer is full.
Concrete example

A 5-second callback and 1 Hz publisher result in two processed messages in 10 seconds; queue_size affects how many intermediate messages are retained or dropped.
