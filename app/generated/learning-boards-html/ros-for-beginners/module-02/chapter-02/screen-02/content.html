Learning Objectives

Progress from writing subscribers to building a reliable transform node and understanding event-loop behavior.

Bloom: Learn → Understand → Apply → Master
01
Write a Python subscriber

Create a rospy.Subscriber, implement a callback that processes messages, and keep the node alive so callbacks run reliably.

VERIFIED COMPETENCY MILESTONE
02
Write a C++ subscriber

Use nh.subscribe, understand ConstPtr usage for efficiency, and manage queue_size when messages arrive quickly.

VERIFIED COMPETENCY MILESTONE
03
Understand the event loop

Explain why rospy.spin() and ros::spin() keep nodes alive and how callback execution differs in Python and C++.

VERIFIED COMPETENCY MILESTONE
04
Build a subscriber–publisher node

Implement a node that receives data, applies a transform, and republishes results for downstream consumers.

VERIFIED COMPETENCY MILESTONE
