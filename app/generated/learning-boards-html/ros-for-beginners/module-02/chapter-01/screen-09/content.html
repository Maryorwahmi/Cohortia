Module 2 › Chapter 2.1 › rostopic Debugging
Common commands
List topics
rostopic list
Topic info
rostopic info /robot_news
Echo messages
rostopic echo /robot_news
Rate & publish
Measure rate
rostopic hz /robot_news
Publish from terminal
rostopic pub -1 /robot_news std_msgs/String "data: 'Hello from terminal'"
# Or publish at 5 Hz
rostopic pub -r 5 /robot_news std_msgs/String "data: 'Repeating message'"
Debug tip
If a topic is silent, check rostopic info to ensure publishers exist and verify node namespaces match topic names.
