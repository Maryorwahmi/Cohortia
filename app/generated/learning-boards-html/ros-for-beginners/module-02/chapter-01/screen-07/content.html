Example code
#!/usr/bin/env python3
import rospy
from std_msgs.msg import String

if __name__ == '__main__':
  rospy.init_node('robot_news_radio', anonymous=True)
  pub = rospy.Publisher('/robot_news', String, queue_size=10)
  rate = rospy.Rate(2)  # 2 Hz

  while not rospy.is_shutdown():
    msg = String()
    msg.data = "Hello from the Robot News Radio!"
    pub.publish(msg)
    rospy.loginfo("Published: %s", msg.data)
    rate.sleep()
Key points
  • init_node sets up the node and name.
  • Publisher(topic, Type, queue_size) creates the publisher object.
  • rospy.Rate maintains consistent frequency and cooperates with shutdown handling.
Practice & verification
Try this
Run the node, then run rostopic echo /robot_news to see messages and rostopic hz /robot_news to check rate.
Pro tip
Use queue_size=1 for time-sensitive sensor streams to avoid processing stale data.
Common mistake
Using time.sleep breaks cooperative shutdown handling; prefer rospy.Rate for loops.
