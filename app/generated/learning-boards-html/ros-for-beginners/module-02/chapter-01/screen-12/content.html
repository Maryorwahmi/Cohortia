Quick debugging checklist

1. Check topic names & namespaces
Use rostopic list to confirm exact names and namespaces.
2. Confirm active publishers
rostopic info shows which nodes publish and subscribe to the topic.
3. Verify message types
Use rosmsg show to inspect types and ensure both sides use the same structure.
4. Inspect rates & queues
Check rostopic hz and review queue_size settings for buffering issues.
5. Confirm clean shutdown
Ensure the node honors shutdown (rospy.is_shutdown or ros::ok) so stale processes do not interfere.
Key Takeaway

Work step-by-step: name, publishers, type, rate/queue, then shutdown behavior to find the culprit quickly.
