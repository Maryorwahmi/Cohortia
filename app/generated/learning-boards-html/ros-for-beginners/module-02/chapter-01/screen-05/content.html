Definition

Topic name structure

Topic names use a slash-separated path. A leading slash makes a name global. Names without a leading slash are relative and resolved against the node's namespace.
Example
/robot1/cmd_vel and /robot2/cmd_vel are different topics for two identical robots. Namespaces let identical code run without renaming topics by hand.
Common mistake
Omitting the leading slash can make a topic resolve to a different namespace and appear to not exist to other nodes.
Why it matters

Namespaces are essential when scaling to multiple robots or instances. Use them to avoid naming collisions and to organize topics logically.

Quick reference
Global name
/camera/image_raw
Relative name
camera/image within node namespace
Namespace use-case
Launch two robots with namespaces /robot1 and /robot2 to reuse identical nodes without name collisions.
