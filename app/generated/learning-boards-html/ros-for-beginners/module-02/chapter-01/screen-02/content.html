Learning Objectives

Skills and verification steps you'll practice in the lab.

Learn → Understand → Apply → Master
01
Explain publish-subscribe

Describe one-to-many asynchronous messaging and the Master's role in discovery. This knowledge helps design scalable systems.

VERIFIED COMPETENCY MILESTONE
02
Write a Python publisher

Create a node that publishes std_msgs at a fixed rate and handles clean shutdown. This is the fastest way to prototype sensors and commands.

VERIFIED COMPETENCY MILESTONE
03
Write a C++ publisher

Implement an advertise-based publisher, build it, and observe API differences versus Python. This is important for performance-critical nodes.

VERIFIED COMPETENCY MILESTONE
04
Use rostopic & rosmsg

Inspect message structures, echo topics, measure rates, and send test messages from the terminal to debug systems quickly.

VERIFIED COMPETENCY MILESTONE
