Core idea

Typed messages and nesting

Messages define the fields you can read and write. Many message types nest other message types, so inspect structures before use.

Common types
  • std_msgs/String — text data
  • std_msgs/Int64 — integer numbers
  • geometry_msgs/Twist — linear and angular Vector3s
  • sensor_msgs/LaserScan — LiDAR ranges with angles
Inspecting messages
Command
rosmsg show geometry_msgs/Twist
Output shows linear and angular Vector3 fields with x, y, z components.
Example interpretation
For a planar robot use linear.x for forward velocity and angular.z for yaw rate; other axes are ignored in 2D contexts.
