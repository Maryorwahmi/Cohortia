How to prove each objective

Publish-Subscribe Check

Run a single publisher and two subscribers; both should receive identical messages after discovery.

Python Publisher

Run the Python node, then rostopic hz to confirm publishing rate and rostopic echo to see message content.

C++ Publisher

Build the C++ node, run it, and compare logs and rate to the Python publisher to contrast behaviors.

Message Inspection

Use rosmsg show to inspect fields and reason about which components you need, like linear.x and angular.z for planar robots.
