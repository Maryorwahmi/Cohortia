Core Concept › What is a .msg file?
Definition and example
A .msg file lists typed fields and may reference other messages.
Example .msg
# File: msg/RobotStatus.msg
string robot_name
int32 battery_percent
float32 temperature
bool is_moving
geometry_msgs/Pose current_pose
Why nesting matters
Referencing geometry_msgs/Pose lets you reuse standard types and build complex structures without duplication.
Concrete example
If you define sensor_id and temperature in SensorData.msg, every node importing that type will expose those same fields in the generated Python class or C++ struct.
Common misconception
Don't use language-specific containers in place of .msg files. They won't be serialized consistently across nodes in different languages.
Key Takeaway

Design messages as explicit, reusable blueprints so generated bindings remain predictable and compatible.
