Code Walkthrough › Python: use generated class
Python example
Import the generated class, construct an instance, and set fields before publishing.
from my_first_robot.msg import RobotStatus

status = RobotStatus()
status.robot_name = "TurtleBot_01"
status.battery_percent = 85
status.temperature = 42.5
status.is_moving = True
status.current_pose.position.x = 1.0
status.current_pose.position.y = 2.0

# Then publish with rospy.Publisher and publish(status)
This generated class exposes attributes named exactly as in the .msg file. Nested message fields are accessible as attributes on subobjects created by the generated class.
Concrete practice
Write a small publisher that sets random values for sensor fields and publishes them at one hertz to test imports and serialization.
Misconception

The generated Python class is not a free-form dict; it has typed fields and participates in ROS serialization when published.

Key Takeaway

After building and sourcing, test imports immediately to confirm bindings are present before using them in longer nodes.
