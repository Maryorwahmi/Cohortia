Common Mistakes › Troubleshooting: Three Frequent Errors
Missing message_generation
Symptom: build succeeds but import fails. Fix: add message_generation to CMakeLists and package.xml and call generate_messages.
Forgetting to source
Symptom: ImportError in Python or missing headers in C++ compile. Fix: source devel/setup.bash in the shell where you test.
Naming conflicts
Symptom: ambiguous imports or wrong type at runtime. Fix: use package-qualified references and avoid duplicate message names across packages.
Quick diagnostic

Use the build log, rospack find, and rosls to verify generated files. If errors persist, re-check package.xml and CMakeLists.txt entries for message_generation and message_runtime.
