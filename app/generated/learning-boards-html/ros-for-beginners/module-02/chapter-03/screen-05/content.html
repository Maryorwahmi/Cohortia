Definition › msg/ Directory and Field Declarations
msg/ directory
Put all .msg files under the package's msg/ directory so the build system finds them.
Field declaration examples
# File: msg/SensorData.msg
float32 temperature
float32 humidity
int32 light_level
string sensor_id

# To include a nested type from another package:
geometry_msgs/Pose current_pose
Design tips
  • Use clear field names and consistent units.
  • Prefer package-prefixed message names for external types.
  • Document arrays and expected ranges in comments above fields.
Concrete scenario
For a drone, include latitude, longitude, altitude and battery_voltage fields. Consumers will expect the same units and types when deserializing the message.
Check your work
After build, use rospack find and rosls to confirm the message file and generated artifacts are present in the package.
Common Mistake

Referencing another package's type without the package name will cause generation to fail. Always write package_name/MessageName.
