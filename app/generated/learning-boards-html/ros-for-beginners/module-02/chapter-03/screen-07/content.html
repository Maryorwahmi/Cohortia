Process Flow › Build and Source
Build steps
Run the build, then source the workspace to make runtime imports work.
# Change to your workspace
cd ~/catkin_ws

# Build generated messages and the workspace
catkin_make

# Make generated modules visible to the current shell
source devel/setup.bash
Verify by opening a Python REPL and attempting to import your generated message. If you see ImportError, confirm you sourced setup.bash in the current shell and that catkin_make completed successfully.
Concrete check
After sourcing, run a short Python test to construct the generated class and set a field to confirm bindings are present.
Warning

If you forget to source setup.bash you will see import errors even though the build succeeded.

Key Takeaway

Always source devel/setup.bash in shells where you import or run nodes that use generated messages.
