Core Tools › roscd, rospack, rosls & Tab Completion
Navigation commands
Small commands that save time when working across packages.
# Jump to a package directory
roscd my_first_robot

# Find a package path
rospack find my_first_robot

# List files of a package
rosls my_first_robot
Use tab completion after commands like rosrun, rostopic, and rosservice to list available executables, topics, or services. This reduces errors and helps discover names in crowded projects.
Practice task
Run roscd to enter your package, then use rosls to verify msg/SensorData.msg exists after a build.
Pro Tip

Tab completion is particularly useful when topics or services include long hierarchical names; it prevents naming mistakes during tests.
