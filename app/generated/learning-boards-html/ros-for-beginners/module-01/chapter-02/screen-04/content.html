Module 1 › Chapter 1.2 › Prepare Ubuntu
Checklist
  1. Confirm Ubuntu 20.04 with lsb_release -a.
  2. Check memory: free -h (4 GB minimum, 8 GB recommended).
  3. Check disk: df -h (20 GB free recommended).
  4. If using VM enable 3D acceleration for Gazebo.
Common mistake
Using a different Ubuntu version may cause package conflicts.
Practical example

Run these commands in a new terminal to validate your environment before installation.

lsb_release -a
free -h
df -h
If any check fails, fix the underlying issue before proceeding to avoid harder troubleshooting later.
