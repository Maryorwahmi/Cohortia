Installing ROS and Setting Up Your Development Environment

Follow a clear, terminal-first workflow to add the ROS repository, install Noetic, configure your shell, and build a catkin workspace so your packages are discoverable.

In this lesson

Repository, keys, apt install, and rosdep.

roscore & turtlesim

Workspace & Verification Visual
Terminal demo
# add repo
sudo sh -c 'echo "deb http://packages.ros.org/ros/ubuntu $(lsb_release -sc) main" > /etc/apt/sources.list.d/ros-latest.list'
# install
sudo apt update
sudo apt install ros-noetic-desktop-full
# workspace
mkdir -p ~/catkin_ws/src
cd ~/catkin_ws
catkin_make
source ~/catkin_ws/devel/setup.bash
# verify
roscore
rosrun turtlesim turtlesim_node
rosrun turtlesim turtle_teleop_key
Key checks
  • roscore shows Master URI
  • turtlesim window appears
  • teleop moves the turtle
Quick tip
Always source your setup files after building

Add the workspace setup to ~/.bashrc so your environment stays configured across terminals.
