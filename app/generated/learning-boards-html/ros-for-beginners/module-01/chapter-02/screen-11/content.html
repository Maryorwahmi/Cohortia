Module 1 › Chapter 1.2 › Verify Installation
Terminal steps
# terminal 1
roscore

# terminal 2
rosrun turtlesim turtlesim_node

# terminal 3
rosrun turtlesim turtle_teleop_key
Use the arrow keys in the teleop terminal to move the turtle and observe real-time messages.
Inspection commands
  • rosnode list — shows registered nodes
  • rostopic list — shows active topics
  • rostopic echo /turtle1/cmd_vel — view velocity commands
Practical check
If the turtle moves, nodes can communicate and your ROS master is healthy.
