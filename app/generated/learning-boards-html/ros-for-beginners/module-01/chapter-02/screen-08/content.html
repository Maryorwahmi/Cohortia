Module 1 › Chapter 1.2 › Sourcing
Key commands
echo "source /opt/ros/noetic/setup.bash" >> ~/.bashrc
source ~/.bashrc

# after building a workspace
source ~/catkin_ws/devel/setup.bash
Add both ROS and workspace setup lines to ~/.bashrc for persistent environment configuration.
Example scenario

You build a package with catkin_make, then open a new terminal and try rosrun. If rosrun cannot find your package, source the workspace's setup.bash in that terminal to register the newly built packages.

Misconception
Sourcing is not an installation step; it simply tells the shell where to find installed artifacts.
