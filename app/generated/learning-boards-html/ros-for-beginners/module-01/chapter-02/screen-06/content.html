Module 1 › Chapter 1.2 › Install ROS
Code walkthrough
sudo apt update
sudo apt install ros-noetic-desktop-full
This download is approximately 2 GB. Watch apt's output for errors or held packages.
Post-install tasks
  • Initialize rosdep with sudo rosdep init and rosdep update.
  • Install tooling: python3-rosinstall, python3-wstool, build-essential.
  • Source /opt/ros/noetic/setup.bash to expose ROS commands.
Pro tip
If disk space is tight, consider the smaller ros-base installation and add only the packages you need later.
