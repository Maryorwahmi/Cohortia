Module 1 › Chapter 1.2 › Troubleshooting
Error: command not found
Fix: source the ROS setup script or add it to ~/.bashrc: 
source /opt/ros/noetic/setup.bash
# persistent
echo "source /opt/ros/noetic/setup.bash" >> ~/.bashrc
Error: package not found or build failures
Fix: ensure packages are inside src and run rosdep to install system deps: 
rosdep install --from-paths src --ignore-src -r -y
catkin_make
Port conflicts & Gazebo
  • Port 11311 in use: kill existing master with killall rosmaster or use the running roscore.
  • Gazebo slow/crash: enable 3D acceleration or reduce simulation fidelity.
