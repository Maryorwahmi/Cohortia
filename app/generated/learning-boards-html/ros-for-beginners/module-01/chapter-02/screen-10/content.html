Module 1 › Chapter 1.2 › catkin_make
Commands
mkdir -p ~/catkin_ws/src
cd ~/catkin_ws
catkin_make

# then source
source ~/catkin_ws/devel/setup.bash
# to persist
echo "source ~/catkin_ws/devel/setup.bash" >> ~/.bashrc
Run catkin_make from the workspace root so the build system locates src automatically.
Example outcome

After building you'll see build/ with intermediate files and devel/ with compiled shared libraries and generated Python modules. Sourcing devel/setup.bash lets rosrun and roslaunch find these artifacts.

Key Takeaway
Always source the workspace after building to register generated packages.
