Module 1 › Chapter 1.2 › rosdep & Tools
rosdep commands
sudo rosdep init
rosdep update
Run these once after installing ROS to prepare rosdep's database of dependency mappings.
Install helper tools
sudo apt install python3-rosinstall python3-rosinstall-generator python3-wstool build-essential
These let you fetch complex source sets and compile C++ or Python nodes.
Practical example

After cloning packages into src, use rosdep to install missing OS packages: rosdep install --from-paths src --ignore-src -r -y. This reduces build failures due to missing headers or libraries.
