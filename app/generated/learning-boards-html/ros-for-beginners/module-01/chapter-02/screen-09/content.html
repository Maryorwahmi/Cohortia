Module 1 › Chapter 1.2 › Workspace Structure
Diagrammed hierarchy
catkin_ws/ ├── src/ (your packages) ├── build/ (cmake & compile artifacts) ├── devel/ (compiled libs + setup.bash) └── install/ (optional)
Practical advice
  • Always add new packages inside src before running catkin_make.
  • Source devel/setup.bash after the build to use generated message bindings.
  • If creating multiple workspaces stack them by sourcing in the correct order.
Check
If a package isn't built, confirm its folder is directly under src and that package.xml is present.
