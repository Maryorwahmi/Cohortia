Module 1 › Chapter 1.2 › Hands-on Activity
Step-by-step lab
  1. Confirm Ubuntu 20.04, RAM, and disk space.
  2. Add the ROS apt repository and import the key; run apt update.
  3. Install ros-noetic-desktop-full; initialize rosdep and install helper tools.
  4. Create ~/catkin_ws/src, run catkin_make, and source devel/setup.bash.
  5. Run roscore, turtlesim_node, and turtle_teleop_key to verify.
  6. Use rosnode list, rostopic list, and rostopic echo to inspect runtime.
Deliverable

Save output from commands into a text file: include outputs from roscore, rosnode list, and rostopic echo. Note any errors and how you fixed them.

Reflection
Did sourcing or rosdep solve the issues you encountered? Document your troubleshooting steps.
