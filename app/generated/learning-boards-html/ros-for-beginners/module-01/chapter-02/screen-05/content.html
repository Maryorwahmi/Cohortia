Module 1 › Chapter 1.2 › APT Repos & Key
Commands to run
sudo sh -c 'echo "deb http://packages.ros.org/ros/ubuntu $(lsb_release -sc) main" > /etc/apt/sources.list.d/ros-latest.list'

sudo apt-key adv --keyserver 'hkp://keyserver.ubuntu.com:80' --recv-key C1CF6E31E6BADE8868B172B4F42ED6FBAB17C654

sudo apt update
The key command imports the package signing key so apt accepts ROS packages as trusted.
Explanation & pitfalls
  • Repository file lets apt find ROS binaries for your Ubuntu release.
  • Missing key leads to authentication errors during apt install.
  • Use sudo for the file write and key import commands.
Warning
Do not edit system files without sudo. If the keyserver is unreachable, try again or use an alternative keyserver mirror.
