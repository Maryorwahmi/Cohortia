Role of the Master

The Master maintains a registry of active nodes, topic publishers and subscribers, services, and parameters. It enables discovery so nodes can connect dynamically without hard-coded addresses.

Important clarification
The Master does not forward messages. After discovery, nodes negotiate direct connections and messages flow peer-to-peer.
Command
Start the Master using the roscore command so nodes can register and discover each other.
Distributed systems
For multi-machine setups ensure the Master is reachable by every host. The Master centralizes discovery but not transport, so network reachability is essential.
Misconception
Don’t assume the Master relays data; it only helps nodes find each other and the topics they use.
