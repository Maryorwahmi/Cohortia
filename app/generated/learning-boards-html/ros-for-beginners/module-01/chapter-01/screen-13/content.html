Module 1 › Chapter 1.1 › Gazebo & RViz
Why simulate?

Simulation lets you test perception, planning, and control without risking hardware. Gazebo provides physics and sensor models; RViz visualizes messages, frames, and sensor output for inspection.

Practical workflow
  1. Run Gazebo with a robot model and simulated sensors.
  2. Start your nodes against simulated topics.
  3. Use RViz to inspect sensor data, TF frames, and diagnostics.
  4. Tune parameters and then move to hardware testing.
Example
Run a simulated camera and LiDAR in Gazebo, let the vision node process images, and view detections and scans in RViz to verify topic names and message formats.
Caveat
Simulation simplifies noise and timing; adjust parameters once on hardware for best performance.
