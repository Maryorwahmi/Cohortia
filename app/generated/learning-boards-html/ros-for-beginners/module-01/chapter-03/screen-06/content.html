Module 2 › Chapter 1.3 › Understanding package.xml
Core elements
  • Name, version, description: basic metadata for the package.
  • Maintainer and license: who owns it and legal terms.
  • build_depend: packages needed to compile this package.
  • exec_depend: packages needed when the package runs.
Example snippet
<build_depend>roscpp</build_depend>
<exec_depend>rospy</exec_depend>
Practice and checks
Run rosdep after editing package.xml to install missing system dependencies.
Remember: if your package defines custom messages, you must list message generation dependencies and ensure they are present at build time.
Question: if a header is missing during C++ compile, which dependency tag likely needs updating? The answer is build_depend.
Common mistake

Forgetting to add message-generation dependencies will cause missing headers during C++ builds; check CMakeLists and package.xml together.
