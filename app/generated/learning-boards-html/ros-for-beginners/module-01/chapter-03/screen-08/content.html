Module 2 › Chapter 1.3 › Package directory structure
Directory map
my_first_robot/
├── package.xml
├── CMakeLists.txt
├── src/        # C++ sources
├── scripts/    # Python executables
├── include/    # C++ headers
├── msg/        # message types
└── launch/     # launch files
Practical notes
  • scripts/ should contain executable Python nodes with a proper shebang and chmod.
  • src/ and include/ support C++ source and header organization so CMake can find them.
  • msg/ and srv/ are required if you define custom message or service types; update both files accordingly.
Key Takeaway

Use the conventional folders so build and run tools behave as expected and collaborators can find code quickly.
