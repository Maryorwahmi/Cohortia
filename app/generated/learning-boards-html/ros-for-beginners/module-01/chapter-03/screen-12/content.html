Module 2 › Chapter 1.3 › Running nodes with rosrun and verifying with rosnode list
Run examples
# Run Python node
rosrun my_first_robot my_first_node.py

# Run C++ node
rosrun my_first_robot my_first_cpp_node

# List running nodes
rosnode list
Name collision and anonymous nodes
If two nodes use identical names, the second will replace the first on the master. Use anonymous naming in Python to avoid this when running duplicates.
To check anonymous instances, look for unique suffixes or differing node names in rosnode list output after launching multiple copies.
Key Takeaway

rosrun launches nodes by package and executable name; rosnode list confirms registration and helps debug name collisions.
