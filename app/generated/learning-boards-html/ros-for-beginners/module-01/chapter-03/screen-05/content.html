Module 2 › Chapter 1.3 › Scaffolding a package with catkin_create_pkg
Terminal demo (example command)
cd ~/catkin_ws/src
catkin_create_pkg my_first_robot std_msgs geometry_msgs roscpp rospy
What is created: package.xml, CMakeLists.txt and placeholders for src/, scripts/, msg/, srv/.
Why list deps: they populate package.xml so rosdep and the build system know what to install and link.
Common mistake: running outside src/ or omitting a dependency you later need for compilation.
Inspecting the manifest
<package format="2">
  <name>my_first_robot</name>
  <build_depend>roscpp</build_depend>
  <build_depend>rospy</build_depend>
  <exec_depend>rospy</exec_depend>
</package>
Example check
Confirm that packages used only at runtime are under exec_depend and compile-time needs like roscpp appear under build_depend.
Pro tip

If you plan C++ code, include roscpp as a build_depend. If only Python nodes, python-related libs belong in exec_depend.
