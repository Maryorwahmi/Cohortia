Module 2 › Chapter 1.3 › Building with catkin_make and sourcing
Build commands
cd ~/catkin_ws
catkin_make
source devel/setup.bash
If you add or change C++ sources or CMakeLists, rebuild. For new Python scripts, ensure they are executable and sourcing may still be needed so rosrun finds the package path.
Troubleshooting checklist
  • Did catkin_make finish without errors?
  • Did you source the workspace setup file in the same shell?
  • Is the executable name correct for rosrun?
Pro tip

Keep one terminal dedicated to building and another to running nodes. Source setup in each terminal you use to run nodes.
