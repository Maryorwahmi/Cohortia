Module 2 › Chapter 1.3 › Writing a simple C++ node
C++ source example
#include <ros/ros.h>

int main(int argc, char** argv) {
    ros::init(argc, argv, "my_first_cpp_node");
    ros::NodeHandle nh;

    ROS_INFO("Hello, ROS! This is my first C++ node.");
    ros::Duration(2.0).sleep();
    ROS_INFO("Node is shutting down.");

    return 0;
}
Save as src/my_first_node.cpp and declare the executable in CMakeLists.txt before building.
Build and run checklist
  • Add add_executable and target_link_libraries to CMakeLists.
  • Run catkin_make at the workspace root.
  • Source devel/setup.bash before rosrun.
Common mistake

Editing a C++ source requires rebuilding; forgetting to rebuild causes old behavior or missing binary errors when running.
