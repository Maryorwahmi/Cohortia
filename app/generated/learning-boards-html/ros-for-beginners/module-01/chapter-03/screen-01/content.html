Create, build, and run your first ROS package

You will scaffold a package, inspect manifest and build files, write both Python and C++ nodes, and run them using catkin tools. This gives you the minimum full cycle for ROS development.

Package Preview
my_first_robot · depends: std_msgs, geometry_msgs, roscpp, rospy
In this lesson

Scaffold a package with catkin_create_pkg, inspect package.xml and CMakeLists, write a simple Python node and a C++ node, build with catkin_make, and run with rosrun. Practice anonymous node names and using rosnode list.

Coming up
  • Package scaffold and structure
  • Python and C++ node examples
  • Build and run workflow
Why this matters

Packages make ROS projects reusable, discoverable, and buildable. Knowing this cycle means you can iterate quickly and integrate with other ROS components.

Quick Commands
cd ~/catkin_ws/src
catkin_create_pkg my_first_robot std_msgs geometry_msgs roscpp rospy
Explore Key Topics
Scaffold
Use catkin_create_pkg to create a package with dependencies declared in package.xml.
Nodes
Write small executable programs in scripts/ or src/ and initialize with the ROS client API.
Build & Run
Use catkin_make and source setup to compile and run C++ nodes and rosrun to launch nodes.
