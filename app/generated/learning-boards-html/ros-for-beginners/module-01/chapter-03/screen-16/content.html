Module 2 › Chapter 1.3 › What to Remember
Declare dependencies
Keep package.xml accurate so rosdep and catkin know what to install and build.
Respect folder roles
scripts/ for Python, src/ and include/ for C++, msg/ and srv/ for custom types.
Build and source
After catkin_make, always source devel/setup.bash before running nodes.
Final takeaway
Follow the scaffold, implement, build, source, run pattern. It prevents most beginner issues and makes development repeatable.
