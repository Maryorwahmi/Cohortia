Module 2 › Chapter 1.3 › Learning Objectives — continued
Objective detail
C++ build
Add an add_executable and target_link_libraries to CMakeLists so catkin_make compiles your node into a binary that rosrun can execute.
Node identity
Use anonymous names in Python to allow multiple instances; otherwise duplicates will cause the first to be deregistered.
Verified competency
You will add a C++ source to src/, update CMakeLists, run catkin_make, and see the binary in devel. You will also run two Python instances with anonymous names and confirm both appear in rosnode list.
