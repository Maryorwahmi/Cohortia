Module 2 › Chapter 1.3 › Custom messages, services, and where to put them
Folder usage
Place .msg files in msg/, .srv files in srv/, and update CMakeLists with message and service generation rules so catkin_make produces language bindings and headers.
Why generate
Generated code lets C++ and Python nodes publish and subscribe to your custom types with correct serialization and headers.
Practical checklist
  • Add message files to msg/ and service files to srv/.
  • Update CMakeLists with add_message_files, add_service_files, and generate_messages.
  • Update package.xml with message-generation dependencies and run catkin_make.
Note

You will not need custom messages for the basic hello nodes, but this prepares you for sharing structured data across your package.
