Module 2 › Chapter 1.3 › Writing a simple Python node
Code example
#!/usr/bin/env python3
import rospy

if __name__ == '__main__':
    rospy.init_node('my_first_python_node', anonymous=True)
    rospy.loginfo("Hello, ROS! This is my first Python node.")
    rospy.sleep(2.0)
    rospy.loginfo("Node is shutting down.")
Make it executable: chmod +x scripts/my_first_node.py
Run: rosrun my_first_robot my_first_node.py
Explanation and checks
  • init_node registers the node with the ROS master so it can communicate.
  • anonymous=True appends a unique suffix so multiple instances do not conflict.
  • rospy.loginfo writes to the ROS logging system instead of standard print for integrated logs.
Common mistake

Forgetting the shebang or the executable bit prevents rosrun from launching the script; verify with ls -l.
