Module 2 › Chapter 1.3 › Hands-on: Build, run, and verify two instances
Activity steps
  1. cd ~/catkin_ws/src; catkin_create_pkg my_first_robot roscpp rospy std_msgs
  2. Create scripts/my_first_node.py and make it executable
  3. Add src/hello_ros.cpp and update CMakeLists
  4. cd ~/catkin_ws; catkin_make; source devel/setup.bash
  5. rosrun my_first_robot my_first_node.py (run two instances with anonymous names)
  6. rosrun my_first_robot my_first_cpp_node
  7. rosnode list to verify
Troubleshooting hints
If rosrun fails to find a node, ensure you sourced devel/setup.bash and that the executable name matches.
If a C++ binary is missing, check that add_executable in CMakeLists references the correct source path and rebuild.
If two Python nodes collide, use anonymous names to avoid deregistration of the first instance.
