CMake example (key lines)
add_executable(my_first_cpp_node src/my_first_node.cpp)
target_link_libraries(my_first_cpp_node ${catkin_LIBRARIES})
include_directories(${catkin_INCLUDE_DIRS})
Ensure catkin_package() is present so downstream packages can find your headers and libraries.
For message generation add the appropriate find_package and add_message_files rules before catkin_package.
Build workflow
  1. cd ~/catkin_ws
  2. catkin_make
  3. source devel/setup.bash
  4. rosrun my_first_robot my_first_cpp_node
Pro tip

If you change CMakeLists or add new source files, always rebuild with catkin_make and re-source the setup file before running binaries.
