Module 2 › Chapter 1.3 › Key Concepts
Package Structure
package.xml and CMakeLists are the manifest and build instructions for a package.
Python vs C++
Python scripts need executable permissions; C++ requires compilation and CMake declarations.
Build & Run
Use catkin_make then source devel/setup.bash; run nodes with rosrun and inspect with rosnode list.
Takeaway
Follow the scaffold → implement → build → source → run loop. This predictable flow reduces errors and speeds iteration when developing ROS nodes.
