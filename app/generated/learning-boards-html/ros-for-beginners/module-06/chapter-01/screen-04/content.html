Module 6 › Chapter 6.1 › rosnode — Inspect and control nodes
Definition
rosnode reveals running node metadata
rosnode lists active nodes and exposes their published and subscribed topics, advertised services, process id, and network URI. It is indispensable for confirming node registration and cleaning stale entries left by crashes.
When to use
When a node is not responding, to inspect connections, or to remove stale registrations.
Common misconception
rosnode shows topology not log contents; check ~/.ros/log for error messages.
Terminal examples
$ rosnode list
/rosout
/turtlesim
/turtle_teleop_key

$ rosnode info /turtlesim
Publications: /turtle1/pose
Subscriptions: /turtle1/cmd_vel
Services: /spawn
PID: 12345
URI: http://192.168.1.5:1234/
Example
Use rosnode ping to confirm liveness before assuming network problems.
Takeaway
rosnode is the first stop to map active processes and their connections.
