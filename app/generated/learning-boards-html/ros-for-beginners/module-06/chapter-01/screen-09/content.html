Module 6 › Chapter 6.1 › rospack — Find packages and dependencies
Filesystem and dependency queries
rospack helps map package names to paths and enumerates dependency graphs so you can locate launch files and resources referenced by packages.
Commands
rospack find <pkg>, rospack depends <pkg>, rospack list
When it helps
When a launch file fails due to missing files or when you need the package path to edit assets.
Terminal samples
$ rospack find turtlesim
/home/user/catkin_ws/src/turtlesim

$ rospack depends turtlesim
roscpp
rospy
std_msgs
Tip
If rospack cannot find a package, ensure you sourced the workspace that built it; unsourced workspaces are invisible to rospack.
