Module 6 › Chapter 6.1 › Turtlesim lab: apply the toolkit
Guided task list
  1. Launch turtlesim with roslaunch or start roscore and nodes manually.
  2. Run rosnode list and rosnode info to inspect nodes and their connections.
  3. Use rostopic list and rostopic info to find /turtle1/cmd_vel publisher and subscriber.
  4. rostopic echo /turtle1/cmd_vel while teleoperating to confirm messages and fields.
  5. Use rostopic hz to measure rate; call /turtle1/teleport_absolute to move the turtle directly.
  6. Change logging level with rqt_logger_level to capture extra details, then inspect ~/.ros/log/latest for findings.
Example command
$ rostopic echo /turtle1/cmd_vel
Why it matters
Practicing on turtlesim builds muscle memory for the diagnostic sequence you will use on larger robots.
Note: This guided lab intentionally uses live terminal commands; reproduce each step and inspect both console output and the log files to complete the exercise.
