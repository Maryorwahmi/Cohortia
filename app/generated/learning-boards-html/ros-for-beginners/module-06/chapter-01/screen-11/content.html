Module 6 › Chapter 6.1 › Controlling log verbosity
Set level in a launch file
Define ROS_PYTHON_LOG_LEVEL in the node stanza to set initial verbosity before startup so early messages are available.
<node pkg="my_package" type="my_node.py" name="my_node" output="screen">
  <env name="ROS_PYTHON_LOG_LEVEL" value="DEBUG" />
</node>
Note: The XML snippet is part of roslaunch configuration; escaping shown for display.
Dynamic changes with rqt_logger_level
rqt_logger_level allows you to pick a running node and change its log level instantly. This avoids restarts and is ideal for intermittent faults or timing-sensitive bugs.
When to use
When you need temporary detailed logs for a specific scenario.
Caution
Remember to revert the level after debugging to reduce log noise.
