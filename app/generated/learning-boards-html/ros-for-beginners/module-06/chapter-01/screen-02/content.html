Learning Objectives
Bloom stages: Learn → Understand → Apply → Master
01
Inspect ROS runtime
Use rosnode, rostopic and rosservice to list and inspect registrations and connections. This helps you verify what components are present and how they interact.
VERIFIED COMPETENCY MILESTONE
02
Manage parameters and packages
Use rosparam to read and set parameters; use rospack to find package paths and dependencies so launch files and assets resolve correctly.
VERIFIED COMPETENCY MILESTONE
03
Inspect message and service types
Use rosmsg and rossrv to view the field layout of messages and services so you can confirm type compatibility between nodes and tools.
VERIFIED COMPETENCY MILESTONE
04
Control and read logs
Configure logging levels, use rqt_logger_level to change verbosity live, and inspect ~/.ros/log for crash traces and aggregated messages.
VERIFIED COMPETENCY MILESTONE

Each objective pairs a command set with a small practice: list items, inspect a specific resource, then confirm by reading messages or logs. The hands-on lab with turtlesim lets you apply all four objectives in sequence.
Tip: Start with observation commands before changing parameters or log levels to avoid introducing fresh variables when debugging.
