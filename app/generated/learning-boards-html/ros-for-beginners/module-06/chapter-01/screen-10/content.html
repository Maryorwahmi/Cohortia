Module 6 › Chapter 6.1 › ROS Logging Levels
Logging severity and intent
INFO
Normal operational messages such as startup completion.
DEBUG
Detailed state useful only when tracing a problem.
WARN
Potential problems that do not stop operation.
ERROR / FATAL
Errors that prevented an operation; fatal indicates shutdown.
Code examples
# Python examples
rospy.logdebug("Debug: x = %f", x)
rospy.loginfo("Node started successfully.")
rospy.logwarn("Battery is low: %d percent", battery)
rospy.logerr("Failed to connect to sensor.")
rospy.logfatal("Critical error: shutting down.")

# C++ examples
ROS_DEBUG("Debug: x = %f", x);
ROS_INFO("Node started successfully.");
ROS_WARN("Battery is low: %d percent", battery);
ROS_ERROR("Failed to connect to sensor.");
ROS_FATAL("Critical error: shutting down.");
Practical tip
Use DEBUG sparingly and switch levels dynamically to capture relevant context only when needed.
