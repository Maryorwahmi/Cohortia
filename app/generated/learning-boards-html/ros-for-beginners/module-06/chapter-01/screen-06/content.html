Module 6 › Chapter 6.1 › rosservice — Inspect and call services
Service inspection
Discover service names and types, then call them to exercise server logic.
Commands
rosservice list, rosservice info /service, rosservice type /service, rosservice args /service, rosservice call /service
When to call
Call a service directly to verify the server handler or reproduce a failing case before integrating it into larger logic.
Terminal sample
$ rosservice list
/turtle1/teleport_absolute
/clear

$ rosservice info /turtle1/teleport_absolute
Node: /turtlesim
Type: turtlesim/TeleportAbsolute

$ rosservice call /turtle1/teleport_absolute "x: 5.0
y: 5.0
theta: 0.0"
Analogy
Think of services like pressing a remote button — you send a single request and receive a response.
Tip
Use rosservice args to avoid formatting errors when calling complex services manually.
