Module 6 › Chapter 6.1 › rostopic — Observe topic traffic
Quick reference
rostopic commands for inspection and testing
When a node appears not to receive messages, use rostopic to confirm: the list and info commands show registrations; echo shows payloads; hz and bw help gauge timing and throughput; pub lets you publish test messages to exercise subscribers.
Common sequence
  • rostopic list to find names
  • rostopic info /topic to see publishers/subscribers
  • rostopic echo /topic to inspect messages
Terminal walkthrough
$ rostopic list
/turtle1/cmd_vel
/turtle1/pose
/rosout

$ rostopic info /turtle1/cmd_vel
Type: geometry_msgs/Twist
Publishers: /teleop_node
Subscribers: /turtlesim

$ rostopic echo /turtle1/cmd_vel
linear:
  x: 1.0
  y: 0.0
  z: 0.0
angular:
  z: 0.5
Example
Use rostopic pub to simulate velocity commands when the teleop node is not running.
Check your understanding
If rostopic info shows no publishers, the subscriber won't receive messages — confirm publisher node and topic name first.
