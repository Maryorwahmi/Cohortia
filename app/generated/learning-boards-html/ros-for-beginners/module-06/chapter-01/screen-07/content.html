Parameter workflows
Parameters are best treated as tunable configuration. Dump and save known-good sets, then experiment by setting parameters at runtime. If nodes do not respond to changes, restart or implement parameter callbacks in your code.
Commands
rosparam list, rosparam get /key, rosparam set /key value, rosparam dump file.yaml, rosparam load file.yaml
Practical example
Dump parameters before changing control gains so you can quickly revert if performance degrades.
Terminal examples
$ rosparam list
/background_r
/robot/max_speed

$ rosparam get /background_r
255

$ rosparam set /robot/max_speed 0.5
$ rosparam dump params.yaml
$ rosparam load params.yaml
Takeaway
Use dump/load for safe experiments and confirm whether nodes will pick up live changes.
