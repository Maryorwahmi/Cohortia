Module 6 › Chapter 6.1 › rosmsg and rossrv — Inspect types
Why inspect types?
Correct message and service fields are necessary for serialization and compatibility. These tools prevent subtle runtime mismatches.
Commands
rosmsg show <type>, rossrv show <service>, rosmsg package <pkg>
Example use
Check geometry_msgs/Twist before publishing velocity commands from a custom node.
Terminal sample
$ rosmsg show geometry_msgs/Twist
geometry_msgs/Vector3 linear
  float64 x
  float64 y
  float64 z
geometry_msgs/Vector3 angular
  float64 x
  float64 y
  float64 z
Takeaway
Always confirm types before publishing or calling services to reduce silent runtime mismatches.
