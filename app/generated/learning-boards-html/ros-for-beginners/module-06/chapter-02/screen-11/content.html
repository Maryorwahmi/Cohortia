Module 7 › Chapter 6.2 › Plotting Turtle Pose
Plot coordinates live
Add x and y pose fields to rqt_plot and observe trajectories as you move the turtle.
Why this helps
You learn to correlate inputs and measured motion, spot discrete jumps, and verify the temporal behavior of the pose publisher.
Commands and hints
# Plot pose fields with rqt_plot
rosrun rqt_plot rqt_plot /turtle1/pose/x /turtle1/pose/y

# Inspect message structure if flat
rostopic echo /turtle1/pose
Try this
Drive the turtle and watch the curves. Note spikes, sudden jumps, or discontinuities and trace them back to publishers or transforms.
Key Takeaway

Plotting position while issuing commands reveals timing, noise, and discrete update behavior that helps isolate bugs.
