Module 7 › Chapter 6.2 › rqt_graph
What rqt_graph shows
Nodes (ellipses), topics (rectangles), actions (hexagons), and edges showing publish/subscribe relationships.
Useful controls
  • Hide dead or debug nodes to reduce noise.
  • Group by namespace to see logical modules together.
  • Save the graph as an image for reports or bug reports.
Diagnostic flow
Open rqt_graph, spot missing edges, then run rostopic list and rostopic type to confirm names and message types.
Command examples
# Launch rqt_graph
rosrun rqt_graph rqt_graph

# Or open full GUI with plugins
rqt
Concrete example
If a controller should subscribe to /scan but the graph shows no edge, check the topic name and namespace; sometimes launch files remap names unexpectedly.
Key Takeaway

rqt_graph makes communication topology visible so you can rapidly find naming or type errors that stop data flow.
