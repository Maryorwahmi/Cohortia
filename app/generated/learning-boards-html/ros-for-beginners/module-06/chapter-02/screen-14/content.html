Module 7 › Chapter 6.2 › Troubleshooting Checklist
Quick checklist
  • Check topic names with rostopic list
  • Confirm message types with rostopic type
  • Verify nodes with rosnode list and logs
  • Set valid RViz fixed frame and check TF
  • Inspect nested fields with rostopic echo when plots are flat
  • Use --clock for bag playback if clocks differ
Document and share
Capture screenshots and small rosbag files to reproduce the issue for teammates or future debugging.
