Common RViz displays
RobotModel
Displays URDF meshes, links, and joint states from /robot_description.
LaserScan
Renders 2D LiDAR scans as points; set topic to /scan.
PointCloud2
3D point clouds from depth sensors and lidar.
Image
Raw camera frames for visual verification.
TF and Fixed Frame
TF shows coordinate frames. If RViz is empty, check that the fixed frame exists (for example world, map, or base_link).
Command examples
# Launch RViz
rosrun rviz rviz

# Launch with config
rosrun rviz rviz -d $(find my_package)/rviz/config.rviz
Common mistake
Fixed frame error: set fixed frame to a valid existing frame, or ensure TF publishes the frame names you expect.
Key Takeaway

Match display type to message type and verify TF frames; otherwise RViz will not render the expected data.
