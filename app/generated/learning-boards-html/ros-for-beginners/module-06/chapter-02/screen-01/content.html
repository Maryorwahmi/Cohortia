Visual debugging with ROS tools
Make node connections, sensor feeds, and parameters visible so you can diagnose and reproduce bugs quickly.
Tools you'll use
rqt_graph, RViz, rqt_plot, rqt_reconfigure, and rosbag for recording and replay.
Hands-on lab
A guided turtlesim activity: observe graph, plot pose, record, replay, and reproduce a bug offline.
Explore Key Topics
rqt_graph
Visualize which nodes publish and subscribe so you can find missing links and type conflicts.
RViz
Inspect sensor feeds, frames, and the robot model to verify perception and transforms.
rosbag
Record and replay data to reproduce bugs and train algorithms offline.
Visual concept
Communication
rqt_graph: nodes as stations, topics as lines. Find missing edges and type collisions fast.
Perception
RViz: 3D sensor feeds, robot model, and TF frames reveal alignment and occlusion issues.
Signals
rqt_plot: live graphs for tuning controllers and spotting spikes, oscillations, or bias.
Record
rosbag: time machine that captures and replays topic streams for offline debugging.
