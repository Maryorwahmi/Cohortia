Module 7 › Chapter 6.2 › Turtlesim lab — Setup
Launch and inspect
Run turtlesim, then open rqt_graph to capture the node/topic topology before interacting.
Steps
  1. Launch turtlesim.
  2. Run rqt_graph and hide dead/debug nodes.
  3. Note topics like /turtle1/pose and /turtle1/cmd_vel.
  4. Take a screenshot for baseline comparison.
Commands
# Launch turtlesim
rosrun turtlesim turtlesim_node

# Run rqt_graph
rosrun rqt_graph rqt_graph
Practical note
Use the baseline screenshot to compare after you record or replay a bag and to demonstrate that nodes appear or disappear after actions.
Key Takeaway

Observe topology first; it narrows the search space for later sensor and behavior issues.
