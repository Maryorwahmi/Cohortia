Frames and static transforms
RViz needs TF to relate sensors and robot frames. If no TF exists, add a static transform.
Practical steps
  1. Add a TF display in RViz.
  2. If empty, publish a static transform between map and turtle frame.
  3. Set RViz fixed frame to the parent frame (map, world, or base_link).
Example command
# Example static transform publisher (syntax varies by version)
# Publish a static transform from 'map' to 'turtle1_base' at the origin
rosrun tf static_transform_publisher 0 0 0 0 0 0 map turtle1_base 10
Misconception
Assuming RViz derives frames from arbitrary topics: frames must be published through TF messages or static publishers.
Key Takeaway

If RViz is empty, check TF and the fixed frame; publish a static transform when nodes do not provide TF.
