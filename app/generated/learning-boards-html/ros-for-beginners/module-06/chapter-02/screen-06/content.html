Module 7 › Chapter 6.2 › rqt_plot
Live plotting for fast insight
Plot one or more fields. Nested fields are supported and multiple curves can be compared in the same view.
When to use it
  • Compare setpoint vs measured value during tuning.
  • Inspect sensor noise, drift, or spikes.
  • Check for timing offsets between streams.
Commands and examples
# Plot a single field
rosrun rqt_plot rqt_plot /topic/field

# Plot multiple fields
rosrun rqt_plot rqt_plot /cmd_vel/linear/x /cmd_vel/angular/z

# Plot nested field
rosrun rqt_plot rqt_plot /sensor_data/temperature
Common mistake
Flat lines usually mean the field path is incorrect. Use rostopic echo to inspect the message structure and pick the right path.
Key Takeaway

Use rqt_plot to compare related signals and identify spikes, oscillations, and offsets that guide tuning decisions.
