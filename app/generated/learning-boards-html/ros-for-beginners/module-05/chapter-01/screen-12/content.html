Module 5 › Chapter 5.1 › Troubleshooting
YAML errors
Indentation problems and tabs cause load failures. Use a YAML linter or rosparam load to detect issues early.
Type mismatches
Keep types consistent between YAML and code. C++ templates will expose mismatches earlier, but always validate at runtime.
Scoping issues
Verify whether a parameter is intended as private or global. Use rosparam list to inspect the server's namespace layout.
Logging & validation
Add startup logs that print parameter values and implement basic validation to fail gracefully if values are out of range.
Debug checklist
  1. rosparam list to inspect namespaces.
  2. rosparam get to check specific keys.
  3. Confirm YAML loaded and types match expected values.
