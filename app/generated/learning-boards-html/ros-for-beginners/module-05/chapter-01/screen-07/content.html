param_reader.py
#!/usr/bin/env python3
import rospy

if __name__ == '__main__':
  rospy.init_node('param_reader')

  # Get parameters with defaults
  robot_name = rospy.get_param('/robot_name', 'default_robot')
  sensor_freq = rospy.get_param('/sensor_frequency', 10)
  simulation = rospy.get_param('/simulation_mode', True)
  kp = rospy.get_param('/pid_gains/kp', 1.0)

  rospy.loginfo("Robot: %s, Freq: %d Hz, Sim: %s, Kp: %.2f",
                robot_name, sensor_freq, simulation, kp)

  # Set a status parameter
  rospy.set_param('/status', 'running')
This example shows defaults to avoid crashes when parameters are missing. Always perform validation after reading numeric values.
Example use
Start your node, then change a parameter from the CLI. If your node re-reads the value, it can adapt without restart.
Misconception
Don't rely on type coercion. Treat values as typed and validate ranges explicitly to avoid unexpected behavior.
