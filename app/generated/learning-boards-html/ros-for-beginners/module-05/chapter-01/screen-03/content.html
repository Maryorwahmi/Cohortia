Hands-on checklist
  • Create robot_config.yaml with nested pid_gains and waypoints.
  • Load YAML with rosparam load and confirm values with rosparam get.
  • Write Python node param_reader.py that logs robot_name and kp with defaults.
  • Write C++ node param_reader.cpp using nh.param templates and log the same values.
Common checkpoints
Verify parameter scoping: run two controllers with ~max_speed differences. Validate numeric ranges on read to catch misconfigured files before acting.
Quick tip
Document each parameter: name, type, default, purpose. A small table in the package README makes experimentation safer and handoffs smoother.
