Module 5 › Chapter 5.1 › Private vs Global
Global parameters
Use a leading slash, e.g. /robot_name. These values are shared across all nodes and useful for environment-wide settings. They are simple to access from any node without resolving a namespace.
Example
/robot_name = "turtlebot_01" used by navigation, logging, and UI nodes.
Private parameters
Use the tilde form ~max_speed when reading; it is stored under the node namespace, preventing conflicts when multiple instances run.
Example
Two motor controllers can each have ~max_speed and be launched under different node names, resulting in /left_motor/max_speed and /right_motor/max_speed.
Misconception
Private parameters are secret; in reality they are simply namespaced. Any node can read them if given the full path, but the convention is to treat them as local.
Takeaway
Use private parameters for node-specific tuning and global parameters for environment configuration to keep behavior predictable and collision-free.
