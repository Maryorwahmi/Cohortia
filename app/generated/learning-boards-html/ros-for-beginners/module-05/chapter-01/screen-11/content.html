Starter YAML
robot_name: "my_robot"
max_speed: 1.2
sensor_frequency: 40

pid_gains:
  kp: 2.0
  ki: 0.1
  kd: 0.5

waypoints:
  - [0.0, 0.0]
  - [1.0, 2.0]
Save as robot_config.yaml and load with rosparam load robot_config.yaml to populate the Parameter Server for testing.
Validation checks
  • Confirm sensor_frequency > 0 before using it in loops.
  • Clamp max_speed to a safe upper bound in controllers.
  • Verify that pid_gains keys exist and are numeric before applying to actuators.
Reload test
Modify max_speed in the YAML and rosparam load again. If your node polls parameters or implements a periodic re-read, it will observe the new value without a restart. This is a practical way to tune live systems safely.
