Parameter Server
A runtime dictionary of typed keys accessible to all nodes while roscore runs.
rosparam & YAML
Use rosparam for live edits and YAML files as versioned configuration records for reproducible runs.
Scope & validation
Choose private or global scope deliberately and validate values at read time to keep systems safe.
Summary takeaway

Treat YAML as the canonical configuration, use rosparam for live control, and scope parameters to avoid conflicts while validating values in your nodes.
