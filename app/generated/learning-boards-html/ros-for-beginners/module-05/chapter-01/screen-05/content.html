Module 5 › Chapter 5.1 › rosparam CLI
Command cheatsheet
# Set a parameter
rosparam set /robot_name "my_robot"
rosparam set /sensor_frequency 40
rosparam set /simulation_mode false

# Get a parameter
rosparam get /robot_name

# List parameters
rosparam list

# Delete a parameter
rosparam delete /robot_name

# Dump and load
rosparam dump params.yaml
rosparam load params.yaml
Use these commands during an experiment for quick tuning. Remember that dump captures the server state and load merges values into the server.
Practical example
Suppose a sensor is noisy at 40 Hz. Use rosparam set /sensor_frequency 20 while testing; the node reading that parameter can adapt on its next check. After tuning, use rosparam dump to save the tuned configuration.
Common misconception
rosparam load will overwrite everything. In fact it merges keys; keys present in the YAML will be set or updated, others remain unchanged.
Pro tip
Dump a params.yaml before a long run so you can restore the exact configuration if you need to repeat the experiment.
