Module 5 › Chapter 5.1 › YAML Parameters
Example YAML
robot_name: "turtlebot_01"
simulation_mode: false
sensor_frequency: 40

pid_gains:
  kp: 2.0
  ki: 0.1
  kd: 0.5

waypoints:
  - [0.0, 0.0]
  - [1.0, 2.0]
  - [3.0, 1.0]
This file maps directly to parameter names: pid_gains/kp becomes the nested key you can read with get_param. Lists preserve order and are useful for sequences like waypoints.
Why YAML
Human readable, supports nesting and lists, and integrates with rosparam load/dump for reproducible configurations.
Common mistake
Using tabs or inconsistent indentation causes parse failures. Always validate by loading and listing parameters after load.
Real-world tip
Keep separate YAML files for simulation vs real hardware and version them in your package so experiments are repeatable.
