Module 6 › Chapter 5.2 › What is a launch file?
Definition

Launch file explained

An XML file saved in a package's launch/ directory that describes nodes, parameters, and composition rules. It is executed with roslaunch to bring up a full system.

Why use it
Automates startup, captures config, simplifies experiments.
Where to put it
Package root under launch/ with a .launch extension.
Key Takeaway

A launch file is the reproducible recipe to start and configure all parts of a robot system so you avoid manual startup steps.

Analogy & Example
Analogy
Think of a launch file as a recipe: ingredients are nodes and parameters, the steps are launch directives, and includes are reusable sub-recipes.
Concrete example (snippet)
<launch>
  <param name="robot_name" value="my_robot" />
  <node pkg="my_first_robot" type="my_first_node.py" name="robot_publisher" output="screen" />
</launch>
Misconception
Launch files hide errors — actually they surface them if you use output="screen" and inspect logs.
Pro tip
Keep launch files small. Use <include> to compose larger systems from reusable pieces.
