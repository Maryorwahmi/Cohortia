Common errors and fixes
A checklist for diagnosing launch failures
Cannot find package
Source your workspace's setup.bash and ensure the package is built and in ROS_PACKAGE_PATH.
Cannot find executable
Check the type attribute and make Python scripts executable with chmod +x.
Node dies immediately
Use output="screen" to see logs; run the node directly to reproduce the error.
Topic not found
Verify remaps and that the publisher has started; use rostopic list and echo.
Pro tip

Start small. Verify each include or node independently before composing them to reduce search space for bugs.

When stuck

Run failing nodes directly from the terminal to see full tracebacks and environment errors that roslaunch might hide.
