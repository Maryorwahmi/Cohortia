Module 6 › Chapter 5.2 › $(find) substitution
Definition
Make launch file paths portable
<rosparam file="$(find my_first_robot)/config/robot_config.yaml" command="load" />
<param name="robot_description" textfile="$(find my_robot)/urdf/robot.urdf" />
Why it matters
Ensures launch files work across different machines and workspace layouts.
Common error
Cannot find package usually means you need to source devel/setup.bash so the package is discoverable.
Key Takeaway

Use $(find) for any package-relative file references to make your launch files portable and shareable.
