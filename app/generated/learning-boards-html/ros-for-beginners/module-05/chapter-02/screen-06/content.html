Module 6 › Chapter 5.2 › Arguments and substitutions
Process
Define, substitute, and override
Step 1 — Define args
<arg name="robot_name" default="my_robot" />
Step 2 — Use $(arg)
Substitute with $(arg robot_name) in <param> or node attributes.
Step 3 — Override
Launch: roslaunch pkg file.launch robot_name:=turtlebot_01
Key Takeaway

Args let you write one launch file that supports multiple runtime configurations. Override defaults from the command line during testing and deployment.

Pitfall

Misspelling an arg name in $(arg) is silent and leads to unresolved substitution. Keep names consistent.
