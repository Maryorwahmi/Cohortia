Module 6 › Chapter 5.2 › <param> vs <rosparam>
Use <param>
Single settings

Example: <param name="max_speed" value="1.5" /> inside a node block makes that parameter private to the node's namespace if needed.

When to choose
Quick, explicit values and node-scoped settings.
Use <rosparam>
Load structured YAML

Example: <rosparam file="$(find my_first_robot)/config/robot_config.yaml" command="load" /> loads many structured keys for sensors or controllers.

When to choose
Use when parameters are numerous or nested; avoids many repeated <param> tags.
Key Takeaway

Prefer <param> for single values and <rosparam> to load structured YAML files for clarity and maintainability.

Common mistake

Using many <param> tags for nested structures becomes error-prone; prefer a single <rosparam> load.

Verify

After launch, use rosparam list and rosparam get to confirm values were loaded correctly.
