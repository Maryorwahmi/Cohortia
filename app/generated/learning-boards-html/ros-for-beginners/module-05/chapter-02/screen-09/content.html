Module 6 › Chapter 5.2 › Include and composition
Architecture
Compose reusable launch modules
<include file="$(find my_robot)/launch/sensors.launch" />

<include file="$(find my_robot)/launch/navigation.launch" />
Design each include to accept args like namespace or rate so it can be reused for multiple robot instances. Test includes independently before composing them.
Practical pattern
Top-level launch
Includes sensors, navigation, and visualization; sets global parameters like robot_description.
Included launch
Defines nodes for a subsystem and accepts args for configuration.
Key Takeaway

Build maintainable launch hierarchies by composing tested includes and passing configuration via args.
