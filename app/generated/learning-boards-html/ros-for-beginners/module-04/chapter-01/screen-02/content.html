Module 4 › Chapter 4.1 › Learning Objectives
01
Explain why actions are needed
Understand limitations of services for long tasks.
You will argue why services block clients and cannot be canceled. This matters for motion and any task taking multiple seconds. Recognize scenarios where actions are the correct choice. Verified Competency Milestone
02
Understand the action protocol
Goal, feedback, result, preemption.
You will map protocol terms to runtime behavior and learn to design feedback and results that help clients monitor progress. Verified Competency Milestone
03
Implement a SimpleActionServer
Python server that publishes feedback and handles preemption.
You will write the execute callback, publish feedback at intervals, and respond to is_preempt_requested. Verified Competency Milestone
04
Implement a SimpleActionClient
Send goals, handle feedback, cancel goals.
You will connect to the server, send a goal with callbacks for feedback and completion, and request a cancel. Verified Competency Milestone
