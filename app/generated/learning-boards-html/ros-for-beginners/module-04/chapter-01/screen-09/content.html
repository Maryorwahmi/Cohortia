Server execution flow
Initialize → loop with feedback → check preemption → set result or preempted.
Step 1
Initialize state
Set flags, create rate, log receipt of goal.
Step 2
Loop and publish feedback
Publish meaningful progress at a controlled rate so clients can react.
Step 3
Check preemption
If requested, set_preempted and break the work loop.
Practical tip

Keep loop iterations short and check is_preempt_requested near the end of each work chunk so cancellation takes effect quickly. Design feedback to allow the client to make safe decisions.
