Sample: CountUntil.action
Three sections: goal, result, feedback. This defines the contract used by generated messages.
CountUntil.action
# File: action/CountUntil.action
# Goal
int32 max_number
---
# Result
int32 count
---
# Feedback
float32 percentage
This file tells the build system what message types to generate. The goal is max_number, result is the final count, and feedback is the percentage progress.
Build checklist
  • Add action file to action/ directory.
  • Call add_action_files() in CMakeLists.txt and generate_messages with actionlib_msgs dependency.
  • Declare actionlib_msgs in package.xml for build and run.
Common mistake
Forgetting generate_messages steps will cause import errors when Python code tries to import the generated messages.
