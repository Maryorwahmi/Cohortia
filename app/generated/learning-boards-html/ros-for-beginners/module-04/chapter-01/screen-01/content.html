Design long-running, cancellable tasks that report progress and return structured results. Learn the protocol, server and client patterns, and when to choose an action over a service or topic.

Goal
Send an actionable request, like move to a pose.
Feedback
Progress updates while the task runs.
Result
Final outcome when finished.
Preemption
Client can cancel a running goal.
