Module 4 › Chapter 4.1 › Comparison
Services • Topics • Actions
Match the primitive to the task characteristics for safe, responsive code.
Services
Synchronous
Use for quick requests. Client blocks until reply; no feedback or cancel.
Topics
Streaming
Continuous data streams for sensors and telemetry. Not goal-oriented.
Actions
Asynchronous with feedback
Best for long tasks needing progress updates and cancellation.
Concrete scenario
A drone takeoff, hover, and land should be an action: the client monitors altitude and can abort if a problem occurs. A quick query like "what is battery level?" is a service. Continuous IMU data is a topic.
