Activity: MoveRobot.action
Define the action, build messages, implement server and client, run and observe cancellations and state transitions.
MoveRobot.action (outline)
# Goal
geometry_msgs/Pose target_pose
---
# Result
bool success
string message
---
# Feedback
geometry_msgs/Pose current_pose
float32 progress
Place this file under action/ and follow build steps to generate messages.
Execution steps
  1. Add action file and update CMakeLists and package.xml.
  2. Build workspace and source it so messages are available.
  3. Implement SimpleActionServer to simulate movement over 5 seconds and publish feedback every 0.5s.
  4. Implement client: send goal to (5,5), sleep 2s, cancel goal, observe PREEMPTED. Then try without cancel to observe SUCCEEDED.
Why this matters

This exercise demonstrates the end-to-end action lifecycle and trains you to design feedback and cancellation handling for safe robot behavior.
