Action lifecycle: what each state means
Use states to guide retry, alerting, and cleanup logic.
Pending / Active
Waiting and running
PENDING before work starts; ACTIVE while processing.
Preempted / Succeeded
Canceled or finished
PREEMPTED is client-initiated stop; SUCCEEDED is normal completion.
Aborted / Rejected
Error or refusal
ABORTED indicates server-side failure; REJECTED means invalid or refused goal.
Design note

Log state transitions and include diagnostic messages in results so clients can decide next steps. Treat PREEMPTED as a valid and expected outcome when cancellation is part of normal operations.
