Actions for long tasks
Use for operations that take seconds and require monitoring.
Protocol: goal/feedback/result
Design each field so clients can act on progress and results.
Actionlib hides topics
The library uses multiple topics internally; you use the high-level API instead.
Summary

Design actions for monitored multi-second tasks, build .action files and generate messages, implement server/client patterns with feedback and preemption, and handle action states in client logic.
