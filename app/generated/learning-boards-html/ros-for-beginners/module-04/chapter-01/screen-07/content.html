CMakeLists and package.xml checklist
CMakeLists snippet
find_package(catkin REQUIRED COMPONENTS
  actionlib_msgs
  message_generation
  ...
)

add_action_files(
  FILES
  CountUntil.action
)

generate_messages(
  DEPENDENCIES
  std_msgs
  actionlib_msgs
)
Run your catkin build after these edits and then source the workspace so generated messages are importable in Python.

Key Takeaway

The build pipeline must generate message types from .action files before Python servers or clients import them.
