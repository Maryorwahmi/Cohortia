Skill → Task mapping
Server
Write CountUntilServer class, start _as in constructor, and publish periodic feedback while checking preemption.
Client
Create SimpleActionClient, call waitForServer, sendGoal with done/active/feedback callbacks, and cancel when needed.
Build
Add add_dependencies in CMakeLists so generated action headers are present during compilation.
Debug
Use rqt_graph to inspect the five topics and understand the action protocol wiring across nodes.
Quick checklist for the lab
  1. Implement CountUntilServer in C++ and start the action server.
  2. Build with catkin and ensure add_dependencies is present in CMakeLists.txt.
  3. Run Python client against C++ server and observe feedback and result logs.
  4. Open rqt_graph and toggle Actions to see topics grouped or expanded.
Common mistake: compiling before action headers are generated. Use add_dependencies to avoid it.
