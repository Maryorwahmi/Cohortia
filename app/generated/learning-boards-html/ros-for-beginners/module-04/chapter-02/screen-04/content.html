Module 5 › Chapter 4.2 › Why C++ for Action Servers
Definition

C++ provides compiled performance and tighter control over resources, which matters for servers that must reply to preemption and publish frequent feedback without delay.

When to prefer C++
Control loops, motion control, sensor fusion, or any task where timing is critical.
Common misconception
Choosing C++ is required for all nodes — false. Use C++ for performance-sensitive servers, Python for rapid prototyping.
Key Takeaway

Use C++ when you need reliable timing, low latency, and tight memory behavior for action servers.

Concrete example: CountUntil server
A server loops from 1 to max_number at 2 hertz, publishes feedback percentage, checks isPreemptRequested each iteration, and calls setSucceeded on success. The C++ path uses a CountUntilGoalConstPtr to avoid copying the request.
<!-- snippet adapted from chapter -->
void executeCB(const my_first_robot::CountUntilGoalConstPtr& goal) {
  ros::Rate rate(2);
  for (int i=1; i<=goal->max_number; ++i) {
    if (_as.isPreemptRequested()) {
      _as.setPreempted();
      return;
    }
    my_first_robot::CountUntilFeedback feedback;
    feedback.percentage = float(i) / float(goal->max_number);
    _as.publishFeedback(feedback);
    rate.sleep();
  }
  my_first_robot::CountUntilResult result;
  result.count = goal->max_number;
  _as.setSucceeded(result);
}
Analogy
C++ action servers are like a compiled controller board: minimal overhead and tight timing.
