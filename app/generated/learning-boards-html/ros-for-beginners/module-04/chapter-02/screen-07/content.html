Client core snippet
// create client and send goal
CountUntilClient() : _ac("/count_until", true) {
  _ac.waitForServer();
}

void sendGoal(int max_number) {
  my_first_robot::CountUntilGoal goal;
  goal.max_number = max_number;
  _ac.sendGoal(goal,
               boost::bind(&CountUntilClient::doneCB, this, _1, _2),
               boost::bind(&CountUntilClient::activeCB, this),
               boost::bind(&CountUntilClient::feedbackCB, this, _1));
}
Note the three bindings: done, active, and feedback. The client remains responsive after sendGoal, and you may call cancelGoal to request termination.
Callbacks explained
  • activeCB: notifies when the goal becomes active on the server side.
  • feedbackCB: receives ongoing feedback messages such as percentage complete.
  • doneCB: called when the action completes; receives a SimpleClientGoalState and a result pointer.
Example
Send a goal of 10, sleep three seconds, then call cancelGoal. The feedbackCB will run several times and the doneCB will report a cancelled or preempted final state.
Common misconception

sendGoal blocks until the action completes — false. It returns immediately and uses callbacks to notify progress and completion.
