Module 5 › Chapter 4.2 › Cross-language Interop
Comparison: Python client vs C++ server
Common ground
Both sides use the same action definition; actionlib maps protocol messages to the five topics so they can interoperate.
Differences
C++ favors ConstPtr and boost::bind; Python uses direct functions and simpler callback registration. The runtime protocol is identical.
Exercise
Run count_until_server (C++) and the Python client from Chapter 4.1. Observe feedback messages and final result. Then reverse roles: run Python server and C++ client. Confirm both combinations work and inspect rqt_graph.
Key Takeaway

Message definitions, not language, define compatibility. Keep action definitions consistent and rebuild generated code after changes.
