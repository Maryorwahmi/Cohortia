Module 5 › Chapter 4.2 › rqt_graph & Action Topics
Action topics to check
  • /count_until/goal — publishes new goals.
  • /count_until/cancel — client cancels are published here.
  • /count_until/feedback — server sends progress updates.
  • /count_until/result — final result message is published by server.
  • /count_until/status — actionlib status messages about goal states.
Debug workflow
Run server and client, open rqt_graph, uncheck Actions to reveal the individual topics, and confirm which node is publishing each topic to diagnose missing messages.
Example check
If feedback stops arriving, inspect /count_until/feedback publisher. If the server publishes but the client does not receive it, check topic namespace mismatches and verify both nodes use the same action name.
Pro tip

Toggle Actions in rqt_graph to switch between high-level and topic-level views; this quickly narrows down communication issues.
