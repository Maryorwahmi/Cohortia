Scaling Strategy

Vertical Scaling: Scaling Up

Enhancing a single instance's capacity

Definition

Increasing the resources (CPU, RAM, disk) of a single server or instance to handle more load. It's about making one machine more powerful.

Use Cases
  • Legacy applications difficult to distribute.
  • Workloads with strong stateful requirements (e.g., certain databases).
  • Initial stages of application growth for simplicity.
Limitations

Inherent capacity limits, single point of failure, potential downtime during upgrades, and can be less cost-effective at extreme scales.

Visual Concept

Server A (Small)

2 CPU, 4GB RAM

Server A (Large)

16 CPU, 64GB RAM

Example Scenario

A legacy CRM application running on a single virtual machine experiences slow performance. Vertical scaling involves upgrading that VM to a larger instance type with more CPU and RAM to handle the increased user load.

Key Takeaway

Vertical scaling is simple but limited; it's best for specific workloads or initial growth, but eventually, distributed architectures become necessary for true cloud-native resilience.
