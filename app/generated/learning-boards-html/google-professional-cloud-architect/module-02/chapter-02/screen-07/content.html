Scaling Triggers

Flexible Auto-scaling Policies

Choose the right metric to drive your scaling decisions.

CPU Utilization

Scales based on average CPU usage across instances. Ideal for CPU-bound workloads.

HTTP(S) Load Balancing Capacity

Scales based on requests per second or load balancer backend utilization. Best for web services.

Cloud Monitoring Metrics

Scale using any custom metric (e.g., queue depth, memory). Offers maximum flexibility.

Schedule-based Scaling

Define scaling policies based on time schedules for predictable traffic patterns.

Pro-Tip

Align your auto-scaling policy with the bottleneck of your application. If it's CPU-bound, use CPU utilization; if it's I/O-bound, consider custom metrics.

Key Takeaway

Selecting the appropriate auto-scaling policy is crucial for efficient resource utilization and maintaining application performance under varying loads.
