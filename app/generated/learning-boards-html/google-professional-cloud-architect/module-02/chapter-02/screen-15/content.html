Chapter Recap

Key Concepts to Remember

Essential terms for scalable cloud architectures.

Managed Instance Group (MIG)

A Compute Engine service that manages a group of identical VM instances, providing auto-scaling, auto-healing, and rolling updates.

Instance Template

A global resource that defines the configuration (machine type, image, disk, network) for VMs created by a MIG.

Auto-scaling

The automatic adjustment of the number of instances in a MIG based on predefined policies (e.g., CPU utilization, HTTP load, custom metrics).

Summary Takeaway

MIGs, instance templates, and auto-scaling are foundational components for building resilient, scalable, and cost-effective applications on Google Cloud.
