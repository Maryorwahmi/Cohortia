Role Types

Custom Roles: Tailoring Permissions to Your Needs

Creating bespoke roles when predefined options aren't enough.

Specific Permission Sets

Allows you to define a precise collection of permissions from scratch, tailored to unique job functions.

Principle of Least Privilege

Ideal for enforcing strict least privilege when predefined roles are either too broad or too narrow.

Project or Organization Level

Can be created at the project level (default) or at the organization level for broader application.

Key Takeaway

Use custom roles for highly specialized access requirements to achieve maximum granularity and security.

Creating a Custom Role (Conceptual)
# storage-viewer-custom-role.yaml
title: "Custom Storage Viewer"
description: "Custom role to view Cloud Storage buckets and list objects."
stage: "GA"
includedPermissions:
- storage.buckets.get
- storage.buckets.list
- storage.objects.get
- storage.objects.list
# Deploying the custom role
gcloud iam roles create customStorageViewer \
    --project=[YOUR_PROJECT_ID] \
    --file=storage-viewer-custom-role.yaml
# Result: A role with only view/list permissions for Cloud Storage.

Use Case:

A data analyst needs to inspect Cloud Storage data but should not be able to modify or delete anything. A custom role ensures this precise access.
