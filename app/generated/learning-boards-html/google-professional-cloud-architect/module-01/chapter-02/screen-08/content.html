Role Types

Predefined Roles: Granular and Service-Specific

Leveraging GCP-managed roles for precise access control.

Granular Permissions

Provide specific permissions tailored to individual GCP services and functions.

GCP-Managed

These roles are maintained and updated by Google Cloud, ensuring they reflect current service capabilities.

Principle of Least Privilege

They enable you to grant only the necessary permissions, significantly enhancing your security posture.

Key Takeaway

Always prioritize predefined roles to implement fine-grained access control and uphold security best practices.

Examples of Predefined Roles
Compute Instance Admin

Manages Compute Engine instances (create, delete, start, stop).

Storage Object Viewer

Views objects in Cloud Storage buckets.

BigQuery Data Editor

Edits data in BigQuery datasets.

Cloud SQL Client

Connects to Cloud SQL instances.
