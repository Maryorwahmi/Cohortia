MIG Integration

Load Balancing & Web App Scenario

MIGs are commonly used as backends for GCP load balancers, distributing traffic across healthy instances for highly available applications.

Load Balancer Types
  • HTTP(S) Load Balancers
  • TCP/SSL Proxy Load Balancers
  • UDP Load Balancers
  • Internal Load Balancers
Web App Example Setup
  • Instance template for web server (OS, machine type, startup script).
  • Regional MIG with auto-scaling (e.g., CPU utilization > 70%).
  • HTTP health check for instance monitoring.
  • GCP HTTP(S) Load Balancer directing traffic to the MIG.
