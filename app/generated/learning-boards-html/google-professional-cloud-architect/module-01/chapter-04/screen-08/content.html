Instance Group Types

Unmanaged Instance Groups (UMIGs)

UMIGs are logical groupings of independently created and managed VMs. They offer fine-grained control over each instance.

Primary Use Case
  • Applying load balancing to existing, manually managed VMs.
  • Scenarios requiring individual control over each VM's lifecycle.
Limitations
  • **No Auto-scaling:** Does not automatically adjust instance count.
  • **No Auto-healing:** Does not automatically replace unhealthy instances.
  • Requires manual management of VM lifecycles.

Key Takeaway

UMIGs are suitable for grouping existing VMs for load balancing but require manual management and do not offer auto-scaling or auto-healing capabilities.
