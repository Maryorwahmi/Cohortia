Preemptible VMs: Cost-Effective

Preemptible VMs are highly cost-effective instances that can be stopped (preempted) by Compute Engine if capacity is needed elsewhere.

Ideal Use Cases
  • Fault-tolerant batch processing jobs.
  • Stateless workloads that can tolerate interruptions.
  • Applications that can restart from a checkpoint.
  • Examples: rendering, scientific simulations, big data processing.
Limitations
  • **Not for Critical Apps:** Unsuitable for long-running or stateful applications.
  • **Interruption Risk:** Can be preempted with short notice.
  • **No Continuous Availability:** Not designed for workloads requiring constant uptime.

Preemptible VMs can be stopped by GCP, requiring fault-tolerant applications to handle interruptions and resume work.

Key Takeaway

Preemptible VMs offer significant cost savings for workloads that can tolerate interruptions, making them ideal for batch processing and stateless tasks.
