Key Concepts: Part 1

Essential terms and definitions from this chapter

Compute Engine (GCE)

GCP's IaaS for running virtual machines.

Virtual Machine (VM) Instance

A virtual server running on GCP's infrastructure.

Machine Type

Defines vCPUs and memory for a VM instance.

Instance Group

A collection of VMs managed as a single entity.

Unmanaged Instance Group (UMIG)

Logical grouping of independently managed VMs.

Managed Instance Group (MIG)

Homogeneous VMs managed by an instance template.

Summary Takeaway

Compute Engine provides flexible VMs, and Instance Groups, especially MIGs, are crucial for managing and scaling these resources effectively.
