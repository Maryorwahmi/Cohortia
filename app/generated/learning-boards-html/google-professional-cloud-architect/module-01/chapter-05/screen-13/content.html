Key Concepts

Essential terms from this chapter.

Cloud Storage

GCP's highly scalable, durable, and globally available object storage service.

Bucket

A logical container for objects in Cloud Storage.

Object

An individual piece of data stored in Cloud Storage, which is immutable.

Storage Classes

Different tiers of Cloud Storage (Standard, Nearline, Coldline, Archive) optimized for access frequency and cost.

Object Lifecycle Management

Policies to automatically transition objects between storage classes or delete them based on age or other criteria.

Summary Takeaway

Cloud Storage provides flexible object storage with tiered classes and automated lifecycle management for cost optimization.
