Cloud Storage: Scalable Object Storage

Storing unstructured data globally with high durability.

What is Cloud Storage?

GCP's highly scalable, durable, and globally available object storage service. It stores data as 'objects' within 'buckets'.

Objects and Buckets

A bucket is a container for objects. An object is an individual piece of data (e.g., a file) stored within a bucket.

Key Characteristic

Objects are immutable: once uploaded, they cannot be changed in place. A new version replaces the old one.

Ideal Use Cases

  • Images and videos
  • Backups and archives
  • Data lakes for analytics
  • Static website content
  • Software distribution
Key Takeaway

Cloud Storage excels at storing vast amounts of unstructured, immutable data, offering global accessibility and high durability for diverse applications.
