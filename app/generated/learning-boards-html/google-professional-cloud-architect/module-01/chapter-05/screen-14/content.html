Key Concepts

Expanding your storage vocabulary.

Persistent Disk

GCP's block storage for Compute Engine VMs, functioning like a virtual hard drive.

Disk Types

Different performance tiers of Persistent Disk (Standard, Balanced, SSD, Extreme).

Snapshot

A point-in-time backup of a Persistent Disk, useful for data protection and recovery.

Filestore

GCP's fully managed Network File System (NFS) service for shared file storage.

NFS

Network File System, a protocol allowing client computers to access files over a network.

Summary Takeaway

Persistent Disk provides flexible block storage for VMs, while Filestore offers managed shared file systems via NFS for collaborative workloads.
