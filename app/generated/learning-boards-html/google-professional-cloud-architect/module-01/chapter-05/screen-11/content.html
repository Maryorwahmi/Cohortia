Filestore: Managed Network File System (NFS)

Providing shared file access for traditional and cloud-native applications.

What is Filestore?

GCP's fully managed service for Network File System (NFS) file shares. Provides shared file storage.

Shared Access

Accessible by multiple Compute Engine instances, Kubernetes Engine clusters, or on-premises machines via VPN.

Ideal Use Cases

  • Content management systems
  • Web serving with shared static files
  • Media rendering farms
  • Lift-and-shift migrations relying on NFS
Key Takeaway

Filestore simplifies the provision of managed NFS, making it the go-to solution for applications requiring shared, hierarchical file system access in GCP.
