Rule Structure

Anatomy of a Firewall Rule

Defining Precise Network Access Policies

Direction & Action

Ingress (inbound) or Egress (outbound); Allow or Deny traffic.

Priority

Lower numbers are evaluated first (e.g., 100 is higher priority than 1000).

Protocol & Ports

Specify TCP, UDP, ICMP, and port ranges (e.g., tcp:22 for SSH).

Source/Destination & Targets

IP ranges (CIDR) for traffic origin/destination; target tags/service accounts for instances.

Key Takeaway

A firewall rule combines multiple parameters to precisely control network traffic flow.

Each component contributes to the precise definition of a firewall rule.
