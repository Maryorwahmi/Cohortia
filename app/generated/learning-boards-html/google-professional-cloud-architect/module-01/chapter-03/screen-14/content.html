Key Concepts

Essential terms from this chapter

Virtual Private Cloud (VPC) Network

A global, software-defined network in GCP providing private and isolated connectivity.

Subnet

A regional component of a VPC network, defining an IP address range (CIDR block).

Firewall Rule

A rule controlling ingress (inbound) and egress (outbound) traffic to/from VM instances.

Summary Takeaway

VPC networks, subnets, and firewall rules are the core building blocks for secure and scalable cloud networking in GCP.
