Practical Application

Creating Firewall Rules with gcloud

Allowing SSH Access to Web Servers

Command Breakdown

The `gcloud compute firewall-rules create` command is used to define a new rule.

Key Parameters

Specify `--network`, `--action`, `--rules` (protocol:port), `--source-ranges`, `--target-tags`, and `--direction`.

Security Warning: `0.0.0.0/0`

Allowing `0.0.0.0/0` for SSH is highly discouraged in production; restrict to specific IP ranges.

Key Takeaway

Use `gcloud` to create precise firewall rules, always prioritizing restrictive source IP ranges for security.

`gcloud` Command Example
gcloud compute firewall-rules create allow-ssh-web-servers \
    --network=my-custom-vpc \
    --action=ALLOW \
    --rules=tcp:22 \
    --source-ranges=0.0.0.0/0 \
    --target-tags=web-server \
    --direction=INGRESS \
    --priority=1000

This command creates an ingress rule allowing SSH to instances tagged 'web-server' on 'my-custom-vpc'.
