Core Concept

VPC Networks and Regional Subnets

Segmenting Your Global Network with IP Address Ranges

VPC Network (Global)

A single VPC network spans multiple GCP regions, providing a unified private network.

Subnet (Regional)

A component of a VPC, associated with a single region and a specific IP address range (CIDR block).

CIDR Blocks

Define the IP address range for resources within a subnet, enabling logical segmentation.

Key Takeaway

VPC networks are global, while subnets are regional, each with a unique CIDR block for IP allocation.

VPC vs. Subnet Scope

Subnets are regional and define specific IP ranges within the global VPC.
