Essential Database Concepts (Part 2)

Reinforcing advanced database services and properties.

Cloud Spanner

A globally distributed, strongly consistent, relational database for mission-critical applications at petabyte scale.

Firestore

A flexible, scalable NoSQL document database for mobile, web, and server development with real-time synchronization.

Real-time Synchronization

Firestore feature that automatically updates connected clients when data changes.

Summary Takeaway

Cloud Spanner provides global relational consistency, while Firestore offers real-time NoSQL capabilities for dynamic, scalable applications.
