Firestore: Flexible NoSQL for Real-time Apps

A scalable document database for web, mobile, and server development.

Document-Oriented

Stores data in flexible, JSON-like documents. Each document contains key-value pairs and can have nested objects.

Collections & Subcollections

Documents are organized into collections, which can also contain subcollections for hierarchical data.

Flexible Schema

No need to define a strict schema upfront, allowing for agile development and easy data evolution.

Key Takeaway

Firestore's document model and flexible schema are ideal for applications requiring agile data structures and rapid development.

Collection: usersID: user_alice

name: Alice

email: alice@example.com

age: 30

Collection: usersID: user_bob

name: Bob

email: bob@example.com

city: New York

interests: ["coding", "hiking"]

Documents can have varied fields within the same collection.
