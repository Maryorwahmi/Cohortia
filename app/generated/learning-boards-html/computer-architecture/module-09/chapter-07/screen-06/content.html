Process

List scheduling for bundle packing

Maintain a ready list, prioritize by critical path, and pack instructions until resources for the bundle are exhausted.

Priority heuristic
Use critical-path length to prefer instructions that unlock more work.
Resource check
Ensure no two instructions in a bundle need the same unit type or exceed slots.
Misconception

Filling every slot greedily can increase spills and harm performance.

Packing decision
Select up to four ready instructions that don't clash on unit type and whose latencies won't violate consumer timing.
Concrete example
If a multiply has high latency, slot the multiply earlier and fill intervening slots with independent loads from later iterations.
Pro tip
Consider leaving a slot unused if using it would expand live ranges and force spills.
