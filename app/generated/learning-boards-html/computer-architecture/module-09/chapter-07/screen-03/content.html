Practice tasks

Four measurable exercises that validate your understanding.

1. Build a dependency graph
Classify RAW, WAR, and WAW edges for a basic block.
2. Implement list scheduling
Schedule to 4 slots, prioritizing critical-path nodes.
3. Software pipeline a loop
Compute prologue, steady-state, epilogue, and cycles per iteration.
4. Experiment with unrolling
Measure code size, register pressure, and spill costs.
Tip

Start with the dot-product loop from Chapter 9.6. Use small N to observe prologue/epilogue effects, and large N to study steady-state throughput.
