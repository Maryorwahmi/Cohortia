Pipeline phases

Prologue fills M-1 stages; steady state overlaps iterations; epilogue drains the pipeline.

Formula
Prologue: M-1 cycles. Epilogue: M-1 cycles. Steady-state cycles: N - M + 1 (cycles that complete full iterations).
Concrete numbers
Example: M = 3 stages. Prologue = 2 cycles, epilogue = 2 cycles. For N = 100, steady-state dominates and overhead is small.
When pipelining hurts
If N < M, the pipeline never reaches steady state and prologue/epilogue costs can increase total time.
