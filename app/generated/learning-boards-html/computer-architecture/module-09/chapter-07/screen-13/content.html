Trade-offs and lab

Measure performance, code size, compile time, and spills to choose the best transform for a workload.

Hands-on task
Write a Python scheduler that: builds a dependency graph, schedules with list scheduling for 4 slots, and prints bundles. Test on a dot-product loop and compare variants: baseline, pipelined, unrolled by 2.
Measurements to collect
  • Cycles per iteration
  • Prologue and epilogue overhead
  • Code size increase
  • Estimated spill count
Reflection

Use quantitative results to pick transforms. When speed gains are marginal but spills increase, prefer safer, smaller transforms.
