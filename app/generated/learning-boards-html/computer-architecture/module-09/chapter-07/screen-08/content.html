Module 9 › Chapter 9.7 › VLIW vs Superscalar
VLIW

Compiler-managed bundles

The compiler must produce correct, tightly packed bundles because hardware assumes bundles are final.

Requirements
Precise latency/resource models at compile time; careful register allocation.
Risks
Spills and mis-packing can cause significant performance loss.
Superscalar

Hardware-assisted issue

Hardware decides which instructions to issue, but compiler scheduling still reduces stalls and helps throughput.

Strengths
Runtime reordering tolerates some uncertainty in dependencies and latencies.
When compiler helps
Reducing critical stalls and exposing independent work still improves performance.
Takeaway

VLIW demands stronger static scheduling; superscalar gains from compiler help but retains dynamic recovery mechanisms.
