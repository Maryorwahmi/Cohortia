Module 9 › Chapter 9.7 › Key Concepts
Dependency graphs
Nodes are instructions; edges are RAW/WAR/WAW and include latencies.
Software pipelining
Overlap iterations into stages; remember prologue and epilogue costs.
Unrolling & pressure
Unrolling increases ILP but also code size and register pressure; measure spills.
Summary takeaway
Apply transforms based on profiling and models; prefer modest unrolling and pipelining for hot loops when steady-state benefits exceed overheads.
