Module 9 › Chapter 9.1 › Branch frequency and typical patterns
Branch Frequency
Typical: one branch every 5–10 instructions (10–20%).
  1. Loop branches (backward): often taken repeatedly; high predictability.
  2. Error checks: usually not taken; predictable default behavior.
  3. Induction-variable branches: regular taken/not-taken patterns tied to counters.
  4. Data-dependent branches: outcomes vary with input; often unpredictable.
Why it matters
Frequency determines exposure; pattern determines achievable accuracy. Combine both to estimate real cost.
Concrete examples
Loop end
A backward branch at loop end is taken repeatedly; predictors reach 90%+ accuracy quickly.
Sorting comparison
Compare branch outcomes in quicksort: outcomes depend on input order and are effectively random for uniform inputs.
Misconception
Assuming rare branches can be ignored. Even infrequent branches matter if misprediction penalty is enormous for that code path.
