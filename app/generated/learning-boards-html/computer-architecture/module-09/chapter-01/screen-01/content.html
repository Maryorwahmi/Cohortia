The Branch Prediction Problem
Why a wrong guess costs many cycles in deep pipelines

Branches create control hazards. While the processor waits for the branch outcome it continues fetching sequential instructions; a misprediction discards that work and costs cycles equal to the unresolved pipeline depth. We will use frequency, penalty and predictor accuracy to compute CPI impact and guide design decisions.

In this lesson
  • Measure branch frequency and predictability in code
  • Compute CPI cost from mispredictions
  • Compare static and dynamic prediction trade-offs
