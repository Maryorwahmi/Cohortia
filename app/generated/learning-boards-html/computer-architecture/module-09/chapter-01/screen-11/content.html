Module 9 › Chapter 9.1 › Choosing prediction strategy
Strategy matrix
Balance workload predictability, branch frequency, and penalty sensitivity.
Static / Compiler hints
Use when loops dominate and area/power are constrained.
Simple dynamic
Good balance for general-purpose cores with moderate mispredict rates.
Aggressive dynamic
Justified when mispredict penalty and branch frequency produce a large CPI impact.
Misconception
Assuming a single predictor fits all workloads; instead, tailor complexity to measured needs.
Concrete decision step
  1. Profile the workload and identify top branch hotspots.
  2. Compute CPI impact for each hotspot using an assumed penalty.
  3. Estimate hardware cost for each predictor option.
  4. Choose the lowest-cost predictor that reduces overall CPI enough to justify its cost.
Key Takeaway
Design choices should be justified by measurable CPI reductions on your important workloads.
