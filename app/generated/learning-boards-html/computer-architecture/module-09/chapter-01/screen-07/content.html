Module 9 › Chapter 9.1 › Static vs Dynamic Prediction
Static Prediction
Rules or compiler hints without runtime history.
  • Very low hardware cost and power use.
  • Effective for loop branches and simple structures.
  • Limited accuracy on data-dependent branches.
When to use
Embedded systems with predictable control flow or strict area/power constraints.
Dynamic Prediction
Hardware learns branch history to improve future guesses.
  • Higher accuracy on irregular or data-dependent branches.
  • Requires tables, state, and design complexity.
  • Best for general-purpose, performance-focused processors.
When to use
High-performance CPUs running diverse applications where misprediction cost is significant.
Concrete scenario
If profiling shows many loop-backwards and few data-dependent branches, static or simple dynamic predictors may suffice. If profile shows high mispredicts on hot paths, invest in advanced dynamic predictors.
