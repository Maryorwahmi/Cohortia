Module 9 › Chapter 9.1 › Control hazards and pipeline cost
Definition
Control hazard = uncertainty about the next instruction due to a branch.

When a branch's outcome is unknown, the fetch unit continues. A later misprediction forces a pipeline flush and refetch, wasting cycles equal to unresolved stages.

Deeper pipelines increase the misprediction cost in cycles. Out-of-order execution reduces some stalls but cannot recover work already thrown away.

Example: a 20-stage pipeline misprediction ≈ 20 cycles lost in the simple cost model.

Key Takeaway
Flushing a deep pipeline is expensive; reduce mispredicts or reduce depth to save cycles.
Common Mistake
Assuming out-of-order execution completely removes branch penalties—flushes still cost cycles.
Concrete scenario
A mispredicted forward branch in a search routine
Consider a search that tests many values; each comparison is followed by a branch. If branch outcomes vary with input data, many mispredictions occur and each mispredict in a deep pipeline forces refetching tens of instructions. The net effect is a large increase in CPI and observable slowdown.
