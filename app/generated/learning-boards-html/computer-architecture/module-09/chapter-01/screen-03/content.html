Why these objectives matter

Numeric measurement and classification of branch behavior let you choose cost-effective hardware. We focus on translating profiler numbers into CPI impact and then into architecture trade-offs.

Metric
Branch Frequency
% of instructions that are branches; typical 10–20%.
Metric
Mispredict Rate
Fraction of branches mispredicted; small changes can have large CPI effect.
Metric
Branch Penalty
Cycles lost per mispredict; equals pipeline depth in the simple model.
VERIFIED COMPETENCY MILESTONE
Compute CPI impact from profile data and recommend predictor complexity for a given workload.
