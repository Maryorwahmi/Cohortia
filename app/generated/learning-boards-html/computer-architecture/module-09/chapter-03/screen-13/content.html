Loop accuracy calculation

A backward branch is taken 999 times and not taken once per 1000-iteration loop.

1-bit predictor
Two mispredictions per loop → 2/1000 → 99.8% accuracy.
2-bit predictor
One misprediction per loop → 1/1000 → 99.9% accuracy.
Reflection

Which workload patterns would still cause significant mispredictions for a 2-bit predictor? Consider alternating branches that alias to the same entry.
