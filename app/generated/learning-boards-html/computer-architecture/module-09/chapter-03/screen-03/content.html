Practice flow

Three guided exercises to connect theory to measured accuracy.

Exercise 1
1-bit predictor on loop traces

Run a 256-entry BHT and count mispredictions for loops of different lengths.

Exercise 2
2-bit saturating counter

Observe state transitions and see how the exit mispredict is reduced to one per loop.

Exercise 3
BHT sizing and aliasing

Compare 256 vs 4096 entries and observe aliasing on alternating-branch traces.
