Learning Objectives

What you will be able to do and why it matters

Learn → Understand → Apply → Master
01
Design a 1-bit predictor

Create a BHT entry with a single bit and explain how it flips on a wrong prediction. This matters because simplicity is cheap but can hurt loop accuracy.

VERIFIED COMPETENCY MILESTONE
02
Implement a 2-bit counter

Build the four-state saturating counter, explain MSB-based prediction, and show state transitions. This reduces loop mispredictions with a small hardware cost.

VERIFIED COMPETENCY MILESTONE
03
Explain BHT organization

Describe indexing by PC bits (e.g., bits 2–11 for 1024 entries) and why size affects aliasing and accuracy.

VERIFIED COMPETENCY MILESTONE
04
Analyze aliasing and mitigations

Show how aliasing reduces accuracy and why XOR indexing or tags help without much extra area.
