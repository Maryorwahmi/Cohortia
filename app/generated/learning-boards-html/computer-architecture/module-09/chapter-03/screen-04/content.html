Module 9 › Chapter 9.3 › BHT Overview
Definition

Branch History Table

A small, indexed cache where each entry stores the predictor state for branches that map to that index.

Indexing example
1024-entry BHT uses PC bits 2–11 (bits 0–1 are zero for 4-byte alignment).
Why history helps
Many branches are biased; remembering the recent outcome lets the hardware guess correctly most of the time and keep pipelines busy.
Common misconception
A simple BHT entry is not global history. If two branches share an index, they can corrupt each other's state.
Concrete scenario

Loop with 1000 iterations

A loop taken 999 times then not taken once will push a local counter toward strongly taken; a small BHT that properly indexes the branch will reflect this bias with high accuracy.

Key Takeaway

BHT layout determines whether a branch's recent behavior is captured or corrupted by others mapping to the same index.
