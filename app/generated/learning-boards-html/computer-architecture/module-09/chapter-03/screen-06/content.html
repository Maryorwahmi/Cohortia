Module 9 › Chapter 9.3 › Counting Mispredictions
Step-by-step

Simulate and count

  1. Set the initial bit (0 or 1).
  2. For each iteration, compare prediction to actual outcome.
  3. If wrong, flip the bit and increment misprediction count.
  4. After full execution, compute accuracy = 1 - mispredictions/iterations.
Worked examples
100-iteration loop
Two mispredictions → accuracy = 98%.
2-iteration loop
Two mispredictions → accuracy = 0% for that branch pattern.
Misconception check

Initial state only changes the very first execution; steady-state mispredictions per loop remain two for the loop-exit pattern.
