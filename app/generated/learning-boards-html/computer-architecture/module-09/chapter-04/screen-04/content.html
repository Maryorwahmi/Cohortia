Core Concept Independent vs correlated
Independent 2-bit predictor
Each branch has its own 2-bit saturating counter. No information crosses branches.
  • • Definition: per-branch 2-bit counters track recent taken/not-taken for one branch.
  • • Limitation: averages behavior across contexts and loses conditional patterns.
  • • Misconception: adding bits to the counter captures correlation — it does not.
Key Takeaway

Use history, not larger counters, to capture correlations between branches.

Concrete example
Three branches where the third depends on the first two:
Trace A
If prior pattern is 11 then Branch 3 is taken 90% of the time.
Trace B
If prior pattern is 00 then Branch 3 is taken 30% of the time.
Because a 2-bit counter sees a mixed stream, it converges to an average and mispredicts in each context. A predictor that indexes based on prior bits can separate these contexts and store distinct counters for them.
