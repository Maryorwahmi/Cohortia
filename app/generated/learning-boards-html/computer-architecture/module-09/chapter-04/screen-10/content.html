Architecture Branch Target Buffer
BTB entry fields
  • • Index: low bits of PC to select a set or entry.
  • • Tag: high bits of PC to validate the entry.
  • • Data: target address and optional prediction bits.
  • • Size: typically hundreds to a few thousand entries.
Why BTB matters
For indirect branches the BTB supplies a cached target immediately. For taken conditional branches it avoids waiting for target computation, enabling deeper speculative fetch and better pipeline utilization.
Design trade-offs: larger BTBs reduce misses but increase access time and complexity; associativity and tag bits shape collision behavior.
