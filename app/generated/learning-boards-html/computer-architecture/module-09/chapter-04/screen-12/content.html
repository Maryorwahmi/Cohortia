Definition Return Address Stack
How RAS works
On a call, push return address; on a return, pop the predicted return address and use it to speculatively fetch the caller's next instruction.
Common limitation: hardware stack overflow on deeply nested calls. Circular buffers help but cannot make the RAS infinite.
Concrete example
A 16-entry RAS handles typical call nesting in most programs. A recursive routine that goes deeper than 16 will overflow and start mispredicting returns until the stack unwinds.
Key Takeaway

RAS is a low-cost, high-accuracy mechanism for call/return prediction but must be sized for expected nesting depth.
