Process Flow Tournament Runtime
Step-by-step
  1. Fetch: compute local and global predictions in parallel.
  2. Select: meta-predictor chooses which to use for fetch-time speculation.
  3. Resolve: when branch outcome is known, compare each predictor to the real outcome.
  4. Update: update both predictor tables and adjust the meta-predictor toward the more accurate predictor.
Example
If local predicted taken and global predicted not taken, and the branch is actually not taken, the selector shifts toward global. Repeat over time and the selector converges to the better predictor for that branch address.
Pro tip: give the selector hysteresis by using a 2-bit counter so the predictor doesn't flip on a single outcome.
