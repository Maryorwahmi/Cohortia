Definition Global Branch History Register
What the GHR stores
An N-bit vector of recent taken (1) and not-taken (0) outcomes, shifting in a new bit each branch.
Example value: 10110101 represents eight recent outcomes. Use this as context when indexing pattern tables so the predictor can distinguish behavior after different histories.
Misconception

Longer history is always better — not necessarily. More bits raise aliasing risk and hardware cost, and older events may not help prediction.

Why it matters
  • • Context separation: Different histories map to distinct table entries and counters.
  • • Captures correlations: When later branches depend on earlier outcomes, history helps.
  • • Hardware trade-offs: Width and update timing affect complexity and latency.
