Core Concept Tournament Predictor
Structure
  • • Local predictor: indexed by branch address, captures stable local patterns.
  • • Global predictor: often gshare, captures inter-branch correlations via GHR.
  • • Meta-predictor: a selector table that learns which predictor was more accurate per branch.
Concrete selector behavior
A 2-bit selector per branch index can count votes. If global was correct, increment; if local was correct, decrement. A strong bias is needed to avoid flip-flopping on noisy branches.
Misconception: tournament predictors are magic — they improve accuracy but cost extra table entries and complexity. The benefit is adaptation: the hardware picks the best predictor for each dynamic branch.
Key Takeaway

Adaptivity beats one-size-fits-all: let hardware learn which predictor to trust for each branch.
