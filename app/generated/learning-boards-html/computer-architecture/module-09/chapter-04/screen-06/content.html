Process Gshare Indexing
How Gshare computes an index
XOR the low-order bits of the program counter with the GHR, then mask to the table size.
// pseudocode for gshare index
pc_low = PC & (TableSize - 1)
index = (pc_low ^ GHR) & (TableSize - 1)
predict = counter_table[index] >= 2 ? TAKEN : NOT_TAKEN
Update rules: increment or decrement the 2-bit counter at that index on branch resolution, and shift the actual outcome into the GHR.
Concrete walkthrough
With an 8-bit GHR and a 256-entry table, use the 8 low bits of PC. Example: PC low = 10101010, GHR = 11001010, XOR = 01100000; consult counter_table[0x60].
Common mistake: XOR eliminates aliasing — it helps but collisions remain. Measure alias counts in your simulator rather than assuming perfect separation.
