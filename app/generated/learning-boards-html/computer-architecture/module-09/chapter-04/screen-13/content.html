Lab Walkthrough Implement & Compare
Step 1 — gshare
Add an 8-bit GHR and a 256-entry 2-bit table. Compute index = (PC_low8 ^ GHR) & 0xFF. Update counter_table[index] on resolution and shift the real outcome into GHR.
Step 2 — tournament
Add a local 256-entry 2-bit table indexed by PC_low8, a gshare global table (256 entries), and a meta 256-entry 2-bit selector. On resolution update local, global, and meta based on correctness.
Step 3 — BTB
Implement a 16-entry BTB with index = PC_low4, store tag and target. Report BTB hit rate and effect on fetch stalls for indirect branches.
Experiment
Run traces with correlated branches and report accuracy for: 2-bit baseline, gshare, tournament. Note how meta-predictor behavior changes per branch.

// update gshare
index = (PC_low << 0) ^ GHR
if (outcome == TAKEN) counter[index] = min(counter[index]+1, 3) else counter[index] = max(counter[index]-1, 0)
GHR = ((GHR << 1) | (outcome==TAKEN?1:0)) & 0xFF

// meta update
