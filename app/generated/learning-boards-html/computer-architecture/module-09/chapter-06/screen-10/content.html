Module 9 › Chapter 9.6 › Code Bloat

Measuring utilization

Utilization = useful ops per bundle / total slots. Low utilization increases binary size via NOPs.

Example calculation

An 8-slot bundle with 3 useful ops → utilization = 3/8 = 37.5%.

Where low ILP appears

Branch-heavy control flow, pointer chasing, and code with serialization constraints produce many NOPs.

Techniques to reduce NOPs
  • Software pipelining
  • Loop unrolling
  • Predication
  • Variable-length bundles
Key Takeaway

Improving utilization reduces code bloat and increases effective throughput; compiler transforms are the primary tool.
