Applied practice

Each objective includes a practical task you can do to demonstrate mastery.

Read & interpret bundles

Given a bundle, identify resource constraints and data dependencies; mark which slots are truly parallel.

Mnemonic: mark deps, count units
Construct schedules

Produce a bundle sequence for a basic loop and insert NOPs where latencies require waiting.

Mnemonic: respect latency windows
Apply compiler transforms

Use loop unrolling, software pipelining, and predication to increase utilization and reduce NOPs.

Mnemonic: overlap iterations
Compare architectures

Given a workload, decide whether VLIW or superscalar OoO will perform better and why.

Mnemonic: predictable vs unpredictable
