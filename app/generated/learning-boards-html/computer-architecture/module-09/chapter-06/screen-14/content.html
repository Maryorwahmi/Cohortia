Module 9 › Chapter 9.6 › Key Concepts
VLIW philosophy
Compiler-scheduled parallelism rather than hardware scheduling.
Bundle structure
Multiple slots map to functional units; NOPs fill empty slots.
Code bloat & remedies
Software pipelining, unrolling, predication, and variable-length bundles raise utilization.
Summary takeaway

VLIW provides a path to simple, efficient hardware when compilers and workloads supply the required parallelism; otherwise, dynamic hardware scheduling remains the robust choice.
