Assembly loop

LOOP: LW R1,0(Ra)       # Load a[i]
      LW R2,0(Rb)       # Load b[i]
      MUL R3,R1,R2      # Multiply (latency 2)
      ADD Rsum,Rsum,R3  # Accumulate
      ADDI Ra,Ra,4      # Increment pointer a
      ADDI Rb,Rb,4      # Increment pointer b
      ADDI Ri,Ri,1      # Increment counter
      BLT Ri,RN,LOOP    # Branch if i < N
Assumed units
  • 2 integer ALUs
  • 1 multiplier (latency 2)
  • 1 load/store unit (latency 2)
  • 1 branch unit
Naive schedule (illustrative)
Bundle A: LW R1,0(Ra) | NOP | NOP | NOP | NOP
Bundle B: LW R2,0(Rb) | NOP | NOP | NOP | NOP
Bundle C: MUL R3,R1,R2 | NOP | NOP | NOP | NOP
Bundle D: NOP           | NOP | NOP | NOP | NOP   # wait for MUL
Bundle E: ADD Rsum,... | ADDI Ra,... | ADDI Rb,... | ADDI Ri,... | BLT ...

This conservative placement respects latencies but uses many bundles per iteration and leaves empty slots.

Software pipelining

Overlap loads of future iterations with multiplies and adds from current iterations to fill empty slots and reduce bundles per iteration.
