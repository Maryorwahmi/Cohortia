Module 9 › Chapter 9.6 › Reduce Code Bloat

Compiler techniques

Software pipelining

Overlap different iterations so operations from multiple iterations fill a bundle more effectively.

Loop unrolling

Duplicate loop body to expose additional independent instructions for scheduling.

Predication

Convert small branches into conditional operations so both paths can be scheduled together.

Variable-length bundles

Encode only non-NOP operations to reduce padding at the cost of more complex fetching.

When to apply
  • Software pipelining for long-running loops with stable dependencies.
  • Unrolling when loop overhead is low compared to body size.
  • Predication for small branches and critical inner loops.
Key Takeaway

Combining transforms increases ILP and reduces NOPs, but each transform has trade-offs in code size and complexity.
