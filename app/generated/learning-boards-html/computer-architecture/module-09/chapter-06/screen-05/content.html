Definition

Bundle structure and NOPs

Slots correspond to functional units. The compiler assigns operations to slots and inserts NOPs when necessary.

Slot constraints
  • One load/store unit means at most one memory op per bundle.
  • Two integer ALU slots allow up to two independent integer ops per bundle.
  • Latency matters — results are not usable until ready.
Concrete example

A five-slot bundle could be: ADD | MUL | LW | NOP | BEQ. The NOP indicates a missing useful operation for that slot.

Key Takeaway

Bundle slot types and counts define both the compiler's scheduling task and the shape of code bloat when ILP is low.
