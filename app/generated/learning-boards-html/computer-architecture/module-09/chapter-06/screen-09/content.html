Module 9 › Chapter 9.6 › Disadvantages

Key drawbacks

  • Code bloat: many NOPs increase binary size and reduce code density.
  • Compile-time scheduling: compilers must know exact latencies and unit counts.
  • Branch handling: unpredictable branches reduce scheduling opportunities.
  • Memory latency: variable cache behavior breaks static assumptions.
  • Lock-in: binaries often tied to a specific VLIW configuration.
Practical implication

Because of these disadvantages, VLIW tends to be successful only when compiler technology and workload characteristics align closely with hardware constraints.

Historical note

Some wide-bundle architectures suffered in practice because compilers could not reliably extract enough ILP, causing poor utilization and limited adoption.
