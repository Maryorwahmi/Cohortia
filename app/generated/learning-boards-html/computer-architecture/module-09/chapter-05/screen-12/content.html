Activity › Hands-on research
Research steps
1) Find published hints about your CPU's predictor type and table sizes.
2) Run targeted benchmarks and collect branch-misprediction counters with perf.
3) Compare measured misprediction rates to expected accuracy ranges for predictor classes.
4) Write a one-page comparison describing accuracy versus area and power trade-offs.
Measurement note
perf stat -e branch-misses,branches ./your-benchmark
Example
If a CPU claims TAGE-like predictors, you should see lower misses on correlated code than a CPU with only a 2-bit BHT.
Limitation
Vendor details are often partial; combine documentation with empirical counters for insight.
Key Takeaway
Measurement plus documentation yields a practical view of predictor design trade-offs and real workload impact.
