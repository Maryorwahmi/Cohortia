Concept › History Lengths
Why geometric spacing works
• Geometric series provides exponential coverage: a small number of tables span short to very long histories.
• Each branch needs a near-optimal depth; geometric spacing increases chance a table closely matches that need.
• Fewer tables reduce tag storage, useful counters, and probing hardware compared to many narrowly spaced tables.
Example
A branch requiring ~20 bits will match the 16 or 32 table, providing accurate prediction without a table at exactly 20 bits.
Misconception
Believing adding many narrowly spaced tables is always better; storage and tag overhead can dominate improvements.
Key Takeaway
Geometric spacing gives wide coverage with limited tables, balancing accuracy and hardware cost.
