Process Flow › Indirect branch techniques
Target cache
Stores multiple candidate targets for an indirect branch. Selection can be based on history or a small tag. Useful when a branch has a limited set of common destinations.
Example
A virtual call that dispatches to three likely methods can have those three targets cached and be selected based on recent context.
Path history
Use a sequence of recent targets or compressed path information to index a predictor that maps path patterns to next targets, capturing calling context.
Example
If the last two targets were A then B, the next target is likely C; path-history indexes exploit this correlation.
Virtual call speculation
Learn the common object types at a call site and guess the most likely method implementation.
Misconception
Assuming a larger BTB alone solves indirect branches; selection among many targets needs context-aware structures.
Key Takeaway
Indirect branches require multi-target storage or path/type context to choose the correct destination reliably.
