Definition › Perceptron Predictor
How it works
• Each branch has a vector of integer weights.
• Prediction = sign(weight vector · global-history vector).
• Learning updates weights to reinforce correct correlations.
Concrete example
If earlier branches A and B correlate positively with current branch, perceptron weights for A and B become positive, increasing the dot product and predicting taken.
Trade-offs
• Better at linear correlations than simple tables.
• Requires more storage per branch (weights) and dot-product compute.
• May be expensive to implement at high clock rates without approximation.
Key Takeaway
Perceptrons capture correlations that table predictors miss but cost more in storage and computation.
Misconception
Assuming perceptrons are always better; they depend on workload characteristics and hardware limits.
Pro tip
Hardware often uses approximations or hybrid schemes to get perceptron advantages without full cost.
