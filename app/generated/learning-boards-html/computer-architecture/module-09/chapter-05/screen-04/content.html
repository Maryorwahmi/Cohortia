What TAGE is
A hybrid predictor: base 2-bit predictor plus several tagged tables indexed with different history lengths.
• Base predictor: inexpensive 2-bit saturating counters as fallback.
• Tagged tables: each table uses a different geometric history length (e.g., 4,8,16,32...).
• Longest matching useful entry provides the final prediction.
Example
A counting loop flips predictability every two iterations and needs only short history; a branch correlated with distant events may need 64 bits. TAGE matches both.

Key Takeaway
Multiple history-length tables let TAGE adapt to each branch's optimal history depth with manageable storage.
Common mistake
Assuming a single long-history table is superior; it increases aliasing and wastes entries for short-history branches.
Pro tip
Geometric spacing of lengths covers many behaviors using few tables.
