Module 10 › Chapter 9.8 › Predication vs Branch Prediction
Comparison

Choose based on predictability and cost

Branch prediction
  • Pros: avoids executing the unlikely path when prediction is correct.
  • Cons: misprediction leads to pipeline flush and penalty.
  • Best when branches are predictable and one path is long.
Predication
  • Pros: eliminates misprediction stalls and enables scheduling both paths.
  • Cons: executes both paths, wastes cycles and power, raises register pressure.
  • Best when both paths are short and unpredictable.
Example
A short conditional update inside a loop: predication avoids repeated misprediction cost and lets the compiler schedule both updates.
Misconception
Predication is not always better; executing a long false path can cost far more than an occasional misprediction.
Key Takeaway

Decide using predictability, path length, register pressure, and energy trade-offs.
