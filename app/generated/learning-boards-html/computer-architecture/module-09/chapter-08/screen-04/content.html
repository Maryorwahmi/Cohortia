Module 10 › Chapter 9.8 › What is Predication?
Definition

Predication

Convert branches into conditional instructions that execute under predicate control. This removes the branch but executes both paths.

Traditional branch assembly
CMP a, b
BLE else
MOV c, d
JMP end
else: MOV c, e
end:
Predicated assembly (if-conversion)
CMP a, b       # Sets predicate P0 (true if a > b)
P0: MOV c, d   # Execute only if P0 is true
!P0: MOV c, e  # Execute only if P0 is false
Why it helps
  • Removes branch mispredictions and the associated pipeline flushes.
  • Lets the compiler schedule operations from both paths together to improve ILP.
  • Enables software pipelining of loops with small conditionals.
Common misconception

Predication is not a free win. If one path is much longer, executing both wastes cycles and power. Predication also increases register pressure because both paths may need live values simultaneously.

Key Takeaway

Use predication when branches are unpredictable and both paths are short; otherwise prefer branch prediction or other techniques.
