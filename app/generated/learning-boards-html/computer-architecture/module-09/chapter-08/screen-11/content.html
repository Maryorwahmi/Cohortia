Simulator design

Follow these steps to implement the hands-on activity that compares branch-based vs predicated execution under varying prediction accuracy and path lengths.

  1. Parse a short if-else snippet and label the two paths.
  2. Generate branch-based assembly with CMP, conditional branch, and moves.
  3. Generate predicated assembly with predicate setup and guarded moves.
  4. Define a processor model: instruction cost, branch penalty, and prediction accuracy.
  5. Run scenarios: perfect prediction, 80% accuracy, and a long false-path case.
Example test case
if (x > 0) {
  y = a + b;      # short path
} else {
  y = a - b;      # short path
}
Key Takeaway

A simulator reveals the exact cycles bought or lost by predication across realistic branch accuracies and path lengths.
