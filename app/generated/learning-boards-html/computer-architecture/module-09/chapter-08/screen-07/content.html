Module 10 › Chapter 9.8 › Predicate Registers
Definition

Predicate registers and if-conversion

Predicate registers hold Boolean conditions set by comparisons. Each instruction includes a predicate field and executes only when the predicate is true.

IA-64 detail
IA-64 provided 64 predicate registers to support wide-scale predication and scheduling.
Live-range impact
Both paths keep values live until the predicate selection point; this often increases register pressure and can cause spills.
Limits
Not all instructions can be predicated safely: calls and stores are often excluded or require special handling.
Concrete example
# after CMP sets P0
P0: ADD r1, r2, r3    # writes r1 only if P0 true
!P0: SUB r1, r2, r4    # writes r1 only if P0 false
Both arithmetic operations execute; only the instruction with true predicate updates the destination register.
Key Takeaway

Predicates let the compiler control execution at the instruction granularity, but they increase pressure on registers and do not prevent microarchitectural side effects.
