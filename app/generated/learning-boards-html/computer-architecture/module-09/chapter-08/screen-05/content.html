Process Flow

If-conversion, explained

1
Select branch candidates
Prefer short, side-effect-free branches inside hot loops.
2
Analyze register pressure
Both paths may require live values simultaneously; check for spills.
3
Emit predicates
Set predicate registers from comparisons and attach predicates to instructions.
4
Schedule instructions
Interleave both-path ops to improve ILP and fill bundles.
5
Insert checks for speculation
If speculative memory ops are used, add check instructions to validate them.
Example
if (x > 0) {
  y = a + b;
} else {
  y = a - b;
}
After if-conversion the adds and subs are predicated and can be scheduled together.
Pitfall
Do not predicated long sequences or operations with stores without careful verification: cost can exceed the saved misprediction penalty.
