Two scenarios

Compare a tight-loop short conditional with a branch whose false path is long to see where predication helps or hurts.

Scenario A — Short conditional in loop
Predication removes repeated misprediction penalties, enables scheduling both operations together, and typically wins when both paths are short and resource contention is low.
Scenario B — Long false path
Predication forces execution of the long path every time, wasting cycles, increasing register pressure and often losing to branch prediction.
Comparison rule
Estimate false-path cost versus misprediction penalty plus spill costs. If false-path cost is smaller, predication may be worthwhile.
Key Takeaway

Use the ratio of false-path work to predicted penalty as a rule of thumb when deciding to if-convert.
