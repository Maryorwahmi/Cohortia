IA-64 / EPIC architecture

IA-64 provided architectural support so compilers could schedule parallelism explicitly: many registers, predicate support, bundles with templates, rotating registers and checks for speculation.

Large register files
128 integer and 128 floating-point registers to reduce spills during aggressive unrolling and software pipelining.
Predicate registers
64 predicate registers to control conditional execution at instruction granularity.
Bundles & templates
Groups of instruction slots with template bits describing parallelism and hazards.
Rotating registers
Support software pipelining by remapping registers across iterations without renaming code.
Bundle illustration
IA-64 encodes three instruction slots per bundle plus template bits that indicate which slots are independent and which require stops.
Key Takeaway

IA-64 gave the compiler many tools to express parallelism, but doing so required very advanced compiler analysis and scheduling.
