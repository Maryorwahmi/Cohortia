Module 10 › Chapter 9.8 › Branch vs Predicated Assembly
Branch-based
CMP a, b
BLE else
MOV c, d
JMP end
else: MOV c, e
end:
This version avoids executing the not-taken path, but mispredictions cause pipeline penalties and lost cycles.
Predicated
CMP a, b       # sets P0
P0: MOV c, d   # writes if P0 true
!P0: MOV c, e  # writes if P0 false
Both moves execute and can be scheduled together; predicates ensure only one architectural write occurs.
Consider
Instruction counts, potential parallelism, and the cost of misprediction vs wasted work.
Micro-effects
Predicated loads can still generate cache traffic; predicates suppress some architectural effects but not all microarchitectural side-effects.
Key Takeaway

Compare cycle costs, including misprediction penalties, resource contention, and register spills when choosing a strategy.
