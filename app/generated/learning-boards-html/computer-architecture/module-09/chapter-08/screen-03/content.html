Skills to practice

These activities make the trade-offs concrete and produce artifacts you can use to reason about predication and EPIC designs.

If-conversion exercise
Convert a short if-else into predicated moves and verify that only the correct predicate writes the destination.
Predication simulator
Implement a simulator that compares branched vs predicated execution under different prediction accuracies and path lengths.
Bundle analysis
Read sample IA-64 bundles and explain template bits, stop bits, and rotating register use.
Design critique
Write a short memo that applies Itanium lessons to modern processor trade-offs.
Each activity maps back to a verified competency milestone: predication skills, trade-off analysis, EPIC feature comprehension, and architectural critique.
