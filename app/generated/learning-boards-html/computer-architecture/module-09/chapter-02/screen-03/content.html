Practice & Analysis
Run simulations, compare scores, and validate compiler hints.
Recommended traces
  • For loop: steady backward branch repeated many times.
  • Binary search: predictable forward/back alternation near midpoints.
  • Quicksort: data-dependent branch outcomes varying by input.
  • Random pattern: measure baseline unpredictability.
Measurement pitfalls
Avoid non-representative training, and separate prediction accuracy from overall timing when caches and memory dominate runtime.
Milestone
A simulator that reports percent accuracy per predictor and explains which predictor is best for each trace.
