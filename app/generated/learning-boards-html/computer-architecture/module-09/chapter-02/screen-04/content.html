Module 9 › Chapter 9.2 › What is static branch prediction?
Definition
A fixed guess per branch. No hardware history, no updates.
Key idea

Static predictors choose a constant direction per branch instruction or by simple rule. They require minimal control logic.

When it helps
  • Small processors with fixed, predictable workloads.
  • First-time execution as a simple fallback before dynamic state warms up.
  • Branches with no clear dynamic pattern — static costs less than dynamic hardware.
Common misconception

People sometimes assume static is useless. But for loop-heavy code it can be nearly as good as simple dynamic schemes and is far cheaper to implement.

Concrete example
Consider a simple for-loop that checks an end condition every iteration. That branch is backward and taken for most iterations until the final exit.
Loop trace
Taken, Taken, Taken, ... Taken, Not taken (exit). A static rule that predicts taken for backward branches will be correct on most iterations.
Key takeaway

Static prediction is a pragmatic trade-off: low hardware cost, useful for predictable control structures, but inadequate for complex data-dependent branching.
