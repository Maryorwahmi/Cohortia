Module 9 › Chapter 9.2 › Use Cases & Fallbacks
Use Cases
Low-cost hardware, cold-start, and unpredictable branches.
Embedded processors
Minimal logic and deterministic timing often make static prediction the right fit.
Fallback mode
Use static rules until dynamic predictor tables warm up after resets or context switches.
Unpredictable branches
Where dynamic prediction yields no advantage, static saves power and complexity.
Reflection
Inspect your codebase: which hot functions are stable across inputs and therefore candidates for profile-guided hints or static prediction?
