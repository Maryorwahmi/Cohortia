Module 9 › Chapter 9.2 › Key Concepts
Static prediction
Fixed, no-history guesses. Low hardware cost, limited adaptation.
BTFNT
Predict backward taken, forward not taken; good for loop-dominant code.
Profile-guided
Compilers record branch outcomes and encode hints, improving static accuracy when profiles are representative.
Summary takeaway
Use static rules where simplicity and determinism matter; use profiling or dynamic predictors where accuracy drives performance.
