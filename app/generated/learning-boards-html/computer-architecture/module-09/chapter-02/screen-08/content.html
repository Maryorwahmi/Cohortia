Accuracy by branch type
Interpret the table and focus on why numbers differ.
Representative numbers
  • Loop backward: Always-Taken ~95%, Always-Not-Taken ~5%, BTFNT ~95%, Profile ~98%.
  • Loop forward: Always-Taken ~5%, Always-Not-Taken ~95%, BTFNT ~95%, Profile ~98%.
  • If-then: Always-Taken ~30%, Always-Not-Taken ~70%, BTFNT ~70%, Profile ~80%.
  • If-then-else: Always rules ~50%, Profile ~75%.
  • Data-dependent: Always rules ~50%, Profile ~60%.
Why these numbers
Structural branches like loops have strong direction bias. If-then-else and data-dependent branches depend on input distributions and cannot be reliably guessed by direction alone.
Key takeaway
Use the accuracy matrix to choose a baseline predictor and to judge how much uplift profiling may provide for a particular branch mix.
