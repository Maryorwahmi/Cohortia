Static Branch Prediction
Make a fixed decision per branch that does not depend on run-time history. Low hardware cost, limited accuracy.
Always-Taken
Predict every branch is taken. Simple, often good for loops.
Always-Not-Taken
Predict sequential flow continues. Favored by early RISC designs.
BTFNT
Predict backward branches taken, forward branches not taken.
In this lesson
Understand static rules and compiler hints. Compare accuracy for loops, ifs, and data-dependent branches.
Coming up
A hands-on simulation you can code to measure predictor accuracy on different traces.
Why it matters
Static rules minimize hardware but cannot match dynamic predictors on complex workloads.
