Profile-Guided Prediction
Collect run-time branch statistics and encode hints during compilation.
How it works
  1. Run the program on representative inputs and collect branch outcomes.
  2. Compile again using recorded frequencies to mark likely directions.
  3. Encode the hint as a bit in the instruction or in a separate table indexed by address.
Practical trade-offs
  • Accuracy improves to about eighty percent for many workloads.
  • Requires profiling runs and recompilation.
  • Hints can be wrong if production inputs differ from profiling.
Example encoding
Some ISAs offer a dedicated hint bit like "likely" or a separate table. The compiler flips the bit for branches seen mostly taken during profiling.
