A minimal structure for tracing and evaluation.
# Trace format: address direction outcome
# direction: backward|forward
# outcome: T | N
# Example lines:
# 0x100 backward T

# Training pass (for profile-guided):
for line in training_trace:

Example traces
Loop: repeated backward taken entries. Binary search: predictable changes. Quicksort: data-dependent decisions.
Common mistake
Using the same trace for training and testing inflates profile-guided accuracy. Use separate runs or cross-validation.
Key takeaway
A small simulator reveals how each rule behaves on targeted workloads and clarifies trade-offs.
