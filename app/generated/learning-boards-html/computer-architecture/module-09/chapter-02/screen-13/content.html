Interpreting simulation results
From accuracy tables to engineering decisions.
Per-branch analysis
Identify the few branches that cause most mispredictions for targeted fixes or hints.
Training vs production
Check that your profile data matches real inputs; otherwise profile-guided hints may mislead.
System context
Combine accuracy with timing results to ensure changes produce measurable runtime improvements.
Action
Use simulation to find hotspots, then measure end-to-end performance before committing to hints or hardware changes.
