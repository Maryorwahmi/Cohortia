Disassemble & compare

Follow these steps to measure instruction length and compare code density across ISAs.

Step 1

Use objdump to list instruction bytes. Annotate prefix, opcode, ModR/M, SIB, displacement, immediate.

Step 2

Identify instructions that map to single μops and those using microcode or multiple μops.

Step 3

Compile the same program for x86-64 and ARM64 and compare text section sizes to measure code density differences.

Reflection

Consider how instruction length, register availability, and addressing patterns influenced the overall code size and likely runtime memory traffic.
