ModR/M and SIB

How complex memory and register operands are encoded and decoded.

Process: decode a memory operand
  1. Read ModR/M. If it indicates memory, note whether a SIB byte follows.
  2. If SIB present, parse scale, index, and base to form base + index*scale.
  3. Read displacement bytes if ModR/M or SIB specify a displacement length.
  4. Compute effective address and fetch the memory operand for execution.
Example

Address form [RBX + RSI*8 + 16] uses ModR/M to indicate memory and a SIB with scale=8, index=RSI, base=RBX, plus a displacement of 16.

Practical tip

When disassembling, map each ModR/M and SIB bit to the addressing expression to trace data flow and identify compiler-generated patterns like array indexing.
