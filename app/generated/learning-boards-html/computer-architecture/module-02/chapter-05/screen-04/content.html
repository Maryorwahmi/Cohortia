Evolution timeline — milestones

A concise timeline of the most influential x86 generations and their defining features.

8086 (1978)
16-bit, segmented memory, origin of x86.
80286 (1982)
Protected mode and memory management.
80386 (1985)
32-bit, flat memory model, paging.
Pentium / MMX (1993)
Superscalar pipelines and SIMD extensions.
Pentium Pro (1995)
Out-of-order, register renaming, μop translation.
Pentium 4 (2000)
Deep pipeline, hyper-threading, later abandoned for power.
Core 2 (2006)
Efficiency, shorter pipeline, wider issue.
x86-64 (2003)
64-bit registers, 16 GPRs, flat 64-bit address space.
Modern cores
Sandy Bridge → Skylake → Alder/Raptor Lake: microarchitecture refinement.
Key takeaway

Generations improved pipelines, execution, and efficiency but kept the ISA stable to protect existing software.

Misconception

Names like Pentium or Core represent microarchitectural generations, not changes to the ISA itself.

Pro tip

When studying a chip, ask which features are ISA changes and which are internal microarchitecture optimizations.
