Variable-length format

A compact encoding composed of optional prefixes, opcode, ModR/M, optional SIB, displacement, and immediate bytes.

Prefixes

Operand and address overrides, segment overrides, and REX for 64-bit and extended registers.

ModR/M and SIB

ModR/M selects registers or memory mode. SIB encodes scale, index, base for complex addressing.

Displacement & immediate

Optional numeric operands that make an instruction fully specified.

Example bytes annotation

A complex memory load might include a REX prefix, one or more opcode bytes, a ModR/M byte, a SIB byte, and a displacement. Each field is necessary to resolve the final effective address and operands.

Why this matters

Dense encodings save bytes and cache space, improving code density, but the decoder must do more parsing work per instruction.

Misconception check

Variable length is not ambiguous; it is precise but it makes hardware decoding more complex and sometimes more power-hungry.
