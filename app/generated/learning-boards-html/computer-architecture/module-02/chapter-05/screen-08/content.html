MOV examples

Practice annotating bytes for simple and complex MOV encodings to see how fields combine.

Simple: MOV RAX, RBX
[ opcode ] [ ModR/M ]
// opcode selects MOV, ModR/M encodes RAX dest, RBX source
Complex: MOV RAX, [RBX + RSI*8 + 16]
[ REX? ] [ opcode ] [ ModR/M ] [ SIB ] [ displacement ]
// REX may indicate 64-bit operand, ModR/M marks memory, SIB encodes scale=8,index=RSI,base=RBX, displacement=16
Exercise

Use a disassembler to measure the byte length of each example and note how many bytes each field consumes.
