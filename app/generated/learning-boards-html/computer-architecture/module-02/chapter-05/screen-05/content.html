Module 2 › Chapter 2.5 › x86-64 Registers

Register file

Sixteen 64-bit general-purpose registers plus SIMD register sets reduce memory traffic and improve compiler-generated code.

General-purpose
RAX RBX RCX RDX RSI RDI RBP RSP R8–R15
SIMD
XMM0–XMM15 (SSE), YMM0–YMM15 (AVX), ZMM0–ZMM31 (AVX-512)
Alias example

AL, AX, EAX, and RAX are aliases: they view the same physical register at different widths. Writing to EAX affects RAX contents in specified ways by the ISA.

Key takeaway

More registers reduce memory spills and improve performance, while aliases preserve legacy encodings and semantics.

REX prefix

A prefix used in x86-64 encodings to access extended registers and indicate 64-bit operand size; it complicates the decoder but enables R8–R15.

Why it matters
  • Compilers generate fewer memory accesses when more registers are available.
  • Aliases allow old binaries to run without ISA changes.
  • The REX prefix increases encoder and decoder complexity but expands register reach.
