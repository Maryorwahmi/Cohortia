Skills & Evidence

Concrete tasks you can complete to verify each learning objective.

Evolution task

List 8086, 80286, 80386, Pentium, Pentium Pro, Core 2, and x86-64. Note the features each added.

Registers task

Open a disassembly and identify RAX..R15 and SIMD registers; point out AL/AX/EAX aliases.

Encoding task

Annotate instruction bytes for prefix, opcode, ModR/M, SIB, displacement, and immediate.

μop task

Compare a simple instruction that maps to one μop and a complex instruction that uses microcode ROM.

Verified competency milestone

Complete the disassembly and μop-mapping tasks to show applied understanding of x86 instruction mechanics and trade-offs.
