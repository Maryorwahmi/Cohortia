Module 2 › Chapter 2.2 › CISC Characteristics
Definition
Complex Instruction Set Computer: ISA with expressive, multi-action instructions that may operate directly on memory and use variable-length encodings.
Characteristic
Memory-to-memory operations and many addressing modes.
Characteristic
Variable instruction lengths for higher code density.
Characteristic
Complex microcode or multi-cycle hardware paths to implement rich instructions.
Concrete scenario
Imagine a tight loop in early systems: a single CISC instruction updates a pointer, reads memory, adds to an accumulator, and checks a counter. For a kilobyte-limited program, replacing four simple instructions with one complex instruction saved precious memory and fetch cost.
Common mistake

Assuming fewer instructions means faster execution. The complexity can make a single instruction take many cycles and hinder pipelining.

Key Takeaway

CISC trades hardware simplicity for code density by embedding multi-step behavior in individual instructions.
