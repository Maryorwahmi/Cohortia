RISC principles
  • Simple, mostly single-cycle instructions.
  • Load-store architecture: only loads and stores touch memory.
  • Fixed instruction length for easy decode and fetch.
  • Large register file to reduce memory references.
  • Hardwired control rather than microcode for common operations.
  • Reliance on compiler optimization to form efficient sequences.
Example sequence
To add two numbers from memory and store the result, a RISC program typically emits: load A into register, load B into register, add registers, store result. These explicit steps are regular and pipeline-friendly.
Contrast

Unlike CISC, which might do all steps in one complex instruction, RISC separates concerns to simplify the hardware.

Key Takeaway

RISC trades compactness for regularity, enabling higher clock speeds and energy efficiency through simpler hardware.
