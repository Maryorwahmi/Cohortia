Objective practice checklist
  • Compile an array-sum program for two ISAs and record instruction counts.
  • Note instruction lengths and whether the ISA uses fixed or variable sizes.
  • Trace memory accesses: do computations operate directly on memory or only on registers?
  • Measure register use: how many general-purpose registers are active in the assembly?

Assessment idea
Answer the microcontroller design question: which ISA produces smaller code for a 4 KB memory and why? Use evidence from your compiled assembly to support your conclusion.
Tip
When you compare assembly, count both instructions and bytes if possible to measure code density accurately.
