CISC Philosophy
Complex instructions, memory-to-memory operations, variable length, higher code density.
RISC Philosophy
Simple instructions, load-store model, fixed length, large register file for simpler hardware.
Modern Blends
x86 keeps CISC externally but translates to μops; ARM and RISC-V are RISC examples with different trade-offs.
Summary
Choose an ISA by weighing memory constraints, performance goals, power targets, and the ecosystem. Use compiler output to make empirical assessments.
