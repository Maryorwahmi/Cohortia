Module 2 › Chapter 2.2 › Fixed vs. Variable Instruction Length
Fixed length (RISC)
All instructions share the same size (often 32 bits). This yields simple fetch logic, straightforward alignment, and predictable decode timing, which helps pipelines and high clock rates.
Benefit: simpler hardware and predictable timing.
Variable length (CISC)
Instructions vary in size, letting the ISA encode richer operations in fewer bytes. This improves code density but requires complex decoders that can parse many formats and align operands at runtime.
Benefit: denser code, smaller binaries for memory-limited systems.
Practical middle ground
Compressed instruction extensions provide optional shorter encodings for frequent patterns, giving RISC ISAs better density while retaining a fixed core size for most instructions.
