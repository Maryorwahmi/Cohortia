Starter C program
#include <stdio.h>

int sum_array(int *a, int n) {
  int s = 0;
  for (int i = 0; i < n; ++i) {
    s += a[i];
  }
  return s;
}

int main(void) {
  int data[100];
  for (int i = 0; i < 100; ++i) data[i] = i;
  int result = sum_array(data, 100);
  printf("%d
", result);
  return 0;
}
Compile with host or cross compilers (for example, produce assembly with compiler flags to view the .s output). Compare x86-64 and a RISC target such as ARM64 or a RISC-V configuration.
Analysis checklist
  • Number of instructions emitted for the core loop.
  • Instruction length variability: fixed-size words or mixed byte lengths.
  • Memory access pattern: are loads/stores explicit or are memory operands used inside instructions?
  • Register allocation: how many registers are used and spilled?
