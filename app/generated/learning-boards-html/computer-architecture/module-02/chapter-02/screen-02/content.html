01
Compare RISC & CISC
Explain distinguishing features and their consequences for compilers and hardware performance.
Venn mnemonic: overlap on instruction purpose, difference on complexity.
02
Historical evolution
Articulate why CISC appeared first and why RISC emerged later as memory costs fell and compilers improved.
Timeline mnemonic: 1970s CISC → 1980s RISC.
03
Describe ISA characteristics
List load-store, instruction length, register file, and addressing mode differences and their effects.
Simple icon mnemonic: register, memory, length, addressing.
04
Evaluate trade-offs
Decide when code density matters versus when simpler pipelines and power efficiency matter for an implementation.
Milestone: justify a design choice for a 4 KB embedded project.
How to verify competency
Each objective maps to a small deliverable: a written compare/contrast, a timeline explanation, a descriptive table of ISA characteristics, and a short evaluation answering the memory-constrained microcontroller question. Together these show you can both describe and apply the chapter material.
Practice
Compile a simple C program for two ISAs and compare instruction counts and memory access patterns.
Milestone
Write a one-page analysis that selects the better ISA for a 4 KB microcontroller and justify your choice.
