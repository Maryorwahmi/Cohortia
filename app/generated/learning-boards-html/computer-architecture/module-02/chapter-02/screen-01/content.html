RISC vs. CISC
Design philosophies that shaped modern ISAs, performance, and implementation choices.
This lesson unpacks historical causes, core trade-offs, and the characteristics you will use when evaluating or choosing an ISA for a design: instruction length, memory model, register file, and addressing modes. Expect concrete examples and a hands-on comparison activity.
In this lesson
  • Historical roots: why CISC arose.
  • RISC principles: load-store, fixed length, many registers.
  • Modern outcomes: x86 μops, ARM, and RISC-V modularity.
Coming up
A step-by-step comparison, implementation trade-offs, and a hands-on compiler activity to compare generated assembly from different ISAs.

CISC
Swiss-army style instructions. Variable length. Memory-to-memory ops. Dense code for small memories.

RISC
Simple, fixed-size instructions. Load-store model. Large register files to reduce memory traffic.
Example: sequence of load, add, store implemented in separate instructions.
