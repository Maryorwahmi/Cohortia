Module 2 › Chapter 2.2 › Load-Store vs. Register-Memory
Load-store (RISC)
Memory is accessed only by load and store instructions. Arithmetic and logical operations work exclusively on registers, producing simpler and more regular pipelines.
Example
load r1, [addr]; load r2, [addr2]; add r3, r1, r2; store [addr3], r3
Register-memory (CISC)
Instructions may combine memory access and computation, such as adding a memory operand directly into a register and optionally updating the address.
Example
ADD memAddr, regA ; read from memory, add to regA, update flags
Key Takeaway

Load-store simplifies execution at the instruction set level and helps scalable pipelining; register-memory offers expressiveness that can reduce code size.
