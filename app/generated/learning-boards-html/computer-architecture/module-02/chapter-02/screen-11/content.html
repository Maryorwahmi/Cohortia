Modular extensions
  • Base integer ISA: RV32I or RV64I.
  • Standard extensions: M (multiply), A (atomics), F/D (floating point), C (compressed).
  • Choose only the extensions required to reduce area and complexity.
Practical implications
RISC-V supports use in tiny microcontrollers and in larger application processors because implementers pick a configuration that fits the product goals. The openness removes licensing restrictions that can limit custom designs.
Key Takeaway

RISC-V’s modularity is its strength: pick features to balance capability, silicon area, and complexity.
