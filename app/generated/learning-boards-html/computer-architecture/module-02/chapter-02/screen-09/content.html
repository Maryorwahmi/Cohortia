Module 2 › Chapter 2.2 › Register File Size
RISC: Many registers
Large register files reduce spills and memory accesses. Compilers can keep live variables in registers, improving performance and energy efficiency.
CISC: Fewer registers historically
Smaller register sets increase use of memory operands and richer addressing modes to compensate for fewer registers.
Key Takeaway

More registers help performance if compilers allocate them well, but larger register files increase hardware area and complexity.
