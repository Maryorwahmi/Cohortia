Process Flow
Exception elements
  • • Types and priorities (interrupts, faults, traps).
  • • State save format so handlers can inspect registers and restart.
  • • Control transfer mechanism and handler entry point.
  • • Return-from-exception semantics.
Concrete scenario
A page fault traps to the OS with fault information. The OS fixes page tables, then returns control so the faulting instruction can be retried if the ISA allows it.
Misconception
Not all exceptions are asynchronous; many are synchronous and precisely tied to a failing instruction's semantics.
Why this matters
Precise exception semantics enable safe OS recovery and debugging, and they are essential verification points for hardware implementers.
