Core Concept
Registers & ABI
Register roles
General-purpose registers hold temporaries and local values. Special registers include the program counter, stack pointer, and frame pointer used by calling conventions and control flow.
Trade-offs
  • • More registers improve performance via fewer memory accesses.
  • • More registers increase hardware area and context-switch state to save.
  • • Register allocation in compilers grows more complex but yields better code.
Concrete comparisons
Examples from the chapter: x86-64 (16 integer registers), ARM64 (31 integer registers), RISC-V base with 32 registers. These choices reflect different balances between compiler friendliness and implementation overhead.
Real-world implication
An OS context switch must save all architectural registers. More registers mean larger save/restore costs, which affects latency for preemption and interrupt handling.
