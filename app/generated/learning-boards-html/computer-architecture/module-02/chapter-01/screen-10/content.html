Hierarchy
User Mode
Unprivileged execution; limited instruction set to prevent direct hardware configuration.
Supervisor Mode
Privileged execution for the OS; access to memory management, interrupt controls and device configuration.
Mode transitions
ISA specifies controlled entry and exit mechanisms such as traps, system calls, and return-from-exception paths, including saved state.
Concrete implication
An OS depends on ISA-specified saved state and transfer semantics to implement secure context switches and system calls without exposing privileged state to user code.
