Definition
Arithmetic & Logical
ADD, SUB, AND, OR, NOT. Basis for computation and comparisons.
Data Movement
LOAD, STORE, MOVE. Define how values move between registers and memory.
Control Flow
BRANCH, JUMP, CALL, RETURN. Determine program sequencing and subroutine calls.
Floating-Point
FADD, FMUL, FDIV. Needed for numerical and scientific code.
Special Instructions
SIMD, atomic ops, system calls. Enable performance or privileged services when present.
Designer trade-off
Extra instructions can reduce instruction count but increase decoding and verification complexity.
Concrete Example
A fused multiply-accumulate instruction reduces multiple operations into a single ISA-level op, helping compilers generate fewer instructions for common numerical kernels.
Misconception
More instruction types automatically improve performance. Only if compilers and workloads use them does complexity pay off.
