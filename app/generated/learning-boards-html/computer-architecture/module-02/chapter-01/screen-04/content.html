Core Concept
Definition
ISA — a contract
A formal, machine-visible specification that defines instructions, state and memory behavior for software and hardware to agree upon.
  • • Operations: arithmetic, data movement, control flow, floating-point, special ops.
  • • State: programmer-visible registers, special registers like PC.
  • • Memory rules: address space, alignment, endianness, ordering.
  • • Exception contract: how faults are reported and handled.
Analogy & Example
Think of the ISA as a signed contract. A sample clause: the add instruction writes a register and may set flags; a conditional branch updates control flow when a condition holds.
Misconception check: Microarchitectural optimizations must preserve the ISA-visible behavior even if they reorder or pipeline execution.
Key Takeaway
The ISA sets the observable rules; microarchitecture implements them without changing their guarantees.
