Definition
Address space & addressing modes
32-bit or 64-bit address spaces; addressing modes include immediate, direct, indirect, indexed, and scaled addressing. These determine how instruction encoding expresses memory accesses.
Alignment & endianness
Alignment requires data at certain boundaries; endianness chooses byte ordering (big vs little). These affect IO, binaries, and cross-platform data exchange.
Memory ordering
Sequential consistency is easiest to reason about. Weaker models improve performance but require explicit synchronization and careful reasoning in concurrent programs.
Concrete Example
Network protocols often use big-endian (network byte order). If a little-endian machine sends raw memory, bytes must be swapped to match the protocol.
