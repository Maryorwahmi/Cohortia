Process Flow
Immediate
Operand embedded in the instruction.
Direct
Instruction encodes a memory address directly.
Indirect
Register contains target address.
Indexed
Base register plus index register computes address.
Scaled
Index is multiplied by element size before adding to base.
Example
Array access base + index*element_size can be a single instruction if the ISA supplies scaled indexing, reducing instruction count and memory accesses.
Misconception
Adding rare addressing modes increases decoder and verification complexity and only helps when workloads commonly use them.
