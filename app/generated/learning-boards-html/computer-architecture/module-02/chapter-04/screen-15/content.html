Module 2 › Chapter 2.4 › Quick Reference
Registers
31 general-purpose 64-bit registers reduce spills and ease compiler allocation.
Exception levels
EL0–EL3 map user, kernel, hypervisor and secure monitor roles.
SIMD
NEON mandatory (128-bit); SVE optional and scalable for wider vectors.
Review Tip
When evaluating platforms, ask about register availability, supported vector extensions, and which exception levels are used by the firmware and hypervisor.
