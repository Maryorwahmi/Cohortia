Exception levels EL0 to EL3
A hierarchical privilege model for modern system needs
EL0
User
Least privilege for applications and user processes.
EL1
OS Kernel
Manages processes, drivers, and core resources.
EL2
Hypervisor
Virtualisation support; runs and isolates guest OS instances.
EL3
Secure Monitor
Highest privilege for trusted firmware and secure operations.
Example
Cloud hypervisors typically run at EL2, allowing isolation of multiple OS kernels running at EL1.
Misconception
Not every device uses all four levels; embedded devices may omit EL2 and EL3 for simplicity.
