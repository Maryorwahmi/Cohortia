Memory addressing in AArch64
Immediate sizes and explicit address calculations to keep encodings simple
Immediate ranges
Small signed or unsigned immediates are supported for many loads/stores; larger offsets require explicit computation.
Scaled indexing
Compilers emit an ADD to compute base + index*scale, then use a simple load/store instruction for memory access.
Pipeline benefits
Separating address arithmetic from memory access reduces addressing complexity and eases out-of-order engines.
Key Takeaway
Predictable addressing encodings help maintain consistent performance and simplify hardware design.
Example
To load an array element beyond a 12-bit offset, the compiler computes the address with an ADD and then performs the load using that computed register.
