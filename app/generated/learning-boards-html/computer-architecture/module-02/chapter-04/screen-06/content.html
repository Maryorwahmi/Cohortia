Module 2 › Chapter 2.4 › ISA Comparison
AArch32
  • Thumb compressed encodings for code density.
  • Many instructions could set or test condition flags implicitly.
  • Addressing and register usage include legacy modes and banked registers in privileged contexts.
AArch64
  • Fixed 32-bit instructions simplify decode and alignment.
  • 31 general-purpose 64-bit registers remove previous register pressure.
  • Explicit compare instructions reduce flag-based pipeline hazards; no Thumb mode.
Example
A load with a small offset in AArch64 uses a constrained immediate; larger address computations use an explicit add, which clarifies pipeline behavior.
Misconception
Fixed-size ISA always worsens code size. In practice, register pressure and pipeline throughput often offset density loss.
Key Takeaway
AArch64 favors pipeline clarity and register availability over legacy encoding density tricks.
