31 × 64-bit registers
X0–X30 with SP and link register conventions
  • X0–X7 typically hold arguments and return values in common ABIs.
  • X30 is the link register (LR); SP is the stack pointer with dedicated usage rules.
  • No register banking simplifies mode switches and exception handling.
Compiler impact
More registers reduce memory spills for temporaries and calling sequences, improving performance and power characteristics. However, ABIs still reserve registers and require conventions for callee-saved and caller-saved registers.
Example
A tight loop that used to spill a temporary into memory on ARMv7 may keep that temporary in an X register on AArch64, reducing memory traffic.
Check
When profiling, count spills around function calls to see ABI effects on register pressure.
