AArch64 factorial (annotated)
Use QEMU or an ARM64 host to assemble and run this routine and compare instruction counts to x86-64.
<!-- AArch64 assembly: compute factorial(n) in X0. Registers: X0=input/return, X1=accumulator, X2=counter --> MOV X1, #1 // acc = 1 MOV X2, X0 // counter = n CMP X2, #1 // if n <= 1, return 1 B.LE end loop: MUL X1, X1, X2 // acc *= counter SUB X2, X2, #1 // counter-- CMP X2, #1 B.GT loop end: MOV X0, X1 // return value in X0 RET
What to observe
Register usage and explicit control flow. Compare instruction count and naming to x86-64 output for the same function.
Key Takeaway
This example illustrates how AArch64 uses explicit compare and branch patterns rather than pervasive conditional execution.
