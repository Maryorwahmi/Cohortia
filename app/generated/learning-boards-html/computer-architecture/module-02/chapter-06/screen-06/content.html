Extensions Overview
M
Integer multiply and divide.
A
Atomics for synchronization.
F / D
Single and double precision FP units.
C
Compressed 16-bit encodings for density.
V
Scalable vector operations for SIMD.
B, J, T
Bit ops, dynamic language support, transactional memory.
Impact on Design
  • Hardware cost: Some extensions require more units and pipeline stages.
  • Toolchain: Compilers must generate and optimize for added instructions.
  • Code density: C reduces size but affects decoder support.
  • Performance: V and M can significantly speed workloads that use them.
Common decision

Choose extensions that match your workload. For embedded controllers, atomics and compressed encodings may be enough; for AI, vector or custom tensor extensions are essential.
