Module 2 › Chapter 2.6 › Toolchain & Simulator
Workflow
  1. Assemble with RISC-V GNU toolchain selecting the ISA string.
  2. Run on Spike or QEMU to validate execution.
  3. Disassemble and inspect bytes to observe encoding format.
  4. Enable C or M extensions and compare outputs.
Checks & Tips
  • Match assembler flags and simulator target ISA strictly.
  • Use runtime checks for extensions before optimized code paths.
  • Document custom instructions and provide compiler intrinsics.
Key Takeaway

Tools reveal the concrete implications of ISA choices. Use simulation and disassembly to validate design assumptions.
