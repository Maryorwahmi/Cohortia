RV32I Example
        
# Sum array of 10 integers (pseudocode-like, RV32I only)
addi x1, x0, 0       # x1 = sum = 0
addi x2, x0, 0       # x2 = index = 0
addi x3, x10, 0      # x3 = base pointer in x10 (caller provides)
loop:
  lw   x4, 0(x3)     # load word at base + index*4
  add  x1, x1, x4    # sum += value
  addi x3, x3, 4     # advance pointer
  addi x2, x2, 1     # index++
  bne  x2, x11, loop # compare to length in x11
  j    done
done:
  sw   x1, 0(x5)     # store result to memory referenced by x5
Use the RISC-V GNU toolchain or Spike to assemble and simulate. Inspect output bytes to see consistent 32-bit instruction words. If you include the C extension, the assembler can emit 16-bit compressed encodings for some patterns.
Checklist
  • Reserve accumulator and pointer registers.
  • Use lw/sw for memory, add/addi for arithmetic.
  • Loop with bne and unconditional j when needed.
Common mistake
Expect compressed encodings without enabling C
Compressed 16-bit instructions are only available when the C extension is present and the assembler emits them.
