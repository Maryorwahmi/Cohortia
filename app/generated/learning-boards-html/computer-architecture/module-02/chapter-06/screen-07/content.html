Module 2 › Chapter 2.6 › Privilege Architecture
Modes
User (U)
Application execution with limited privileges.
Supervisor (S)
Operating system execution and memory management.
Machine (M)
Firmware, bootloader, highest privilege; always present.
Trap Flow
  1. Fault or interrupt triggers a trap condition.
  2. Core saves PC to mepc and trap cause to mcause.
  3. Control transfers to address in mtvec where the handler runs.
  4. Handler inspects state, corrects or terminates, then returns via mret.
Example
Page fault handling

When a page fault occurs, the CPU stores the faulting address in mepc and jumps to mtvec. The OS can then install a page table entry or send a signal to the process.
