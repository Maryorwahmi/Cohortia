Core Facts

RV32I and RV64I

  • RV32I: 32-bit ISA, 32 registers, x0 is zero.
  • RV64I: 64-bit ISA, same semantics with 64-bit registers and addresses.
  • Includes arithmetic, logical, shift, load/store, and branch instructions.
  • Base is intentionally small to ease implementation and verification.
Key Takeaway

A small, frozen base makes toolchains and hardware simpler and prepares the ISA for optional performance extensions.

Example
Why x0 exists

x0 simplifies certain encodings by providing a guaranteed zero source. Compilers use it for immediate moves and comparisons without extra instructions.

Common misconception
Minimal base means minimal performance

A minimal base is a foundation. Performance features are added via standard extensions such as M, V, and F/D when needed.
