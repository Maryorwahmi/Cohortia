Indexed and scaled index addressing

Step 1 — Base
Use base register holding a reference (frame pointer or array base).
Step 2 — Index
Take an index register pointing to element number.
Step 3 — Scale & Displacement
Multiply or shift index by element size, then add displacement for field offset.
Concrete example
Address = R2 + R3 * 4 + 8. This gives direct element access for a four-byte element array with an extra structure offset.
Compiler vs Hardware
Hardware supports scaled addressing to save instructions. Alternatively, compiler emits a shift and add to keep hardware simple.
