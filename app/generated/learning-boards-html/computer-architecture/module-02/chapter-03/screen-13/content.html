Code density versus pipeline simplicity

High density (CISC)
Allows complex addressing in one instruction, reducing code size but increasing decode complexity and power.
Pipeline simplicity (RISC)
Favors simple addressing modes and fixed-length instructions to keep decode and execute fast and predictable.
Assessment idea
Why does x86 expose complex addressing while AArch64 uses simple base+disp? The answer is a trade-off between code density and pipeline complexity: x86 optimized for density and legacy compatibility; AArch64 optimized for pipeline simplicity and frequency.
