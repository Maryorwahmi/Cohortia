Module 2 › Chapter 2.3 › Key Concepts
PC-relative branches
Essential for position independence and compact branching; displacement limits matter.
Scaled index
Powerful for arrays; can be optimized with shifts when scale is a power of two.
Compressed sets
Improve density for common ops without making the execution core variable-width.
Reflective question
Which addressing mode would you prefer for your ISA if you could only add one complex feature, and why? Consider compiler patterns and hardware cost.
