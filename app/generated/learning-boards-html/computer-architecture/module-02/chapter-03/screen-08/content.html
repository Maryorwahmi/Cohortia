PC-relative and auto-increment/decrement

PC-relative

Compute target as PC + offset. Enables position-independent code and compact branches.

Most branches use a limited displacement field. If the target is far, use an indirect jump sequence generated by the compiler.
Why it matters
PC-relative reduces relocations and keeps branches short and dense for common control flow.
Auto-increment / Auto-decrement

Register updates automatically after an access. Useful for stacks and sequential array scans.

Example pattern: load from pointer register and increase the pointer by element size to walk memory with fewer instructions.
Misconception
Auto-update always simplifies code. It can complicate register liveness and exception handling because the register changes as a side effect of memory access.
