Where address calculation happens

Simple modes

Register or immediate modes often need no address math, so decode and execute can be short and predictable.

Address arithmetic for base+displacement can be a single adder in the execute stage. Shift-based scaling for power-of-two scales is cheap and fast.
Complex modes

Scaled indexing with arbitrary scale or variable-length decoding requires more logic and can lengthen critical paths, increasing cycle time or requiring additional pipeline stages.

Compilers can trade off by performing scale and add explicitly to keep hardware simple. This increases instruction count but improves clock speed.
Example scenario
A load with R2 + R3*4 + 8 may either use a single complex address unit or be implemented as a separate shift and add instruction followed by a load, depending on ISA and pipeline design.
