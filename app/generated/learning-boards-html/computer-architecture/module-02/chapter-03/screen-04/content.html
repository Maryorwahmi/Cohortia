Addressing mode — precise definition

Formal claim

An addressing mode is the method encoded by an instruction that produces the effective address used to fetch or store an operand. It determines whether the value is immediate, in a register, or computed from registers and constants.

  • Immediate: operand is part of the instruction word.
  • Register: operand held in a register; no address computation needed.
  • Indirect: a register contains the memory address to use.
  • Indexed/scaled: base plus index times scale plus displacement.
Concrete examples
// Example visuals (not spoken literally)
ADD R1, R2, #5     ; immediate: add constant five
LOAD R1, 0x1000    ; direct/absolute address
LOAD R1, (R2)      ; register indirect: R2 holds address
LOAD R1, 4(R2)     ; indexed: base R2 + displacement 4
LOAD R1, 8(R2,R3,4); scaled index: R2 + R3*4 + 8
Common misconception
Richer modes always reduce execution time. In fact, they reduce instruction count but can lengthen the pipeline critical path and increase power.
