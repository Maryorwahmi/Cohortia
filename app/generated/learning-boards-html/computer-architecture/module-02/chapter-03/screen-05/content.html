Immediate vs Direct addressing

Immediate

Operant constant encoded in the instruction. No memory access required.

  • Fast: avoids loads.
  • Limited by immediate field size.
  • Ideal for small loop counters and offsets.
ADD R1, R2, #5   ; add constant five
Key takeaway
Use immediates for common small constants to save cycles.
Direct (Absolute)

Instruction contains a full memory address. No address computation needed but instruction grows large.

  • Flexible: any address reachable directly.
  • Increases instruction size and reduces density.
  • Useful for fixed data or boot code.
LOAD R1, 0x1000   ; load from absolute address
Warning
Direct addressing can bloat code size and harm cache locality.
