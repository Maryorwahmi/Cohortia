Register vs Register-Indirect

Register mode

Operand lives in a register. No address computation or memory access required.

ADD R0, R1, R2 // R0 = R1 + R2
Registers are the fastest storage accessible to the ALU. Compilers favor register allocation to minimize memory traffic.
Register-indirect

Instruction dereferences an address held in a register to perform memory access.

LOAD R0, (R2) // R2 contains memory address; load into R0
Often used for pointer chasing and dynamic data structures. Paired with auto-increment to walk arrays or stacks efficiently.
