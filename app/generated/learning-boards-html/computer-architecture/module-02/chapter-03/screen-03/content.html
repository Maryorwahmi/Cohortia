Bloom Progress and Practice Tasks

Describe

Write example instructions that use immediate, direct, and register addressing. Annotate each instruction with the effective address computation.

Analyze

Compare instruction sequences where scaled indexed addressing reduces instruction count versus sequences that use explicit scale and add instructions.

Evaluate trade-offs

Mark stages in a pipeline where address calculation hardware increases cycle time or power, and propose simpler alternatives.

Design

Lay out bit fields for a 16-bit RISC instruction and compute immediate and displacement limits; discuss compiler implications.

Each task ends with a verified milestone: a diagram, an annotated sequence, or a short explanation showing understanding.
