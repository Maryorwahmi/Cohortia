Module 3 › Chapter 2.7 › x86 Extension Timeline
Process Flow

Major x86 extensions

1997 — MMX

64‑bit SIMD registers mapped onto x87. Added integer SIMD for multimedia but shared register file with floating point.

1999–2001 — SSE & SSE2

128‑bit XMM registers independent from x87. SSE2 added integer SIMD and double-precision support.

2004–2006 — SSE3 / SSSE3 / SSE4

Specialized horizontal and string operations to simplify common patterns in media and signal code.

2011–2013 — AVX & AVX2

256‑bit YMM registers and three‑operand instructions; AVX2 adds integer 256‑bit operations, gather and FMA.

2017 — AVX‑512

512‑bit ZMM registers, mask registers, and new opcodes for predicate and embedded control.

Supporting notes
  • Each extension often added register state requiring OS awareness to preserve context.
  • CPUID flags let software query supported features before executing new instructions.
  • Three‑operand formats reduce register pressure compared to two‑operand encodings.
Key Takeaway

x86 history shows incremental widening and capability additions; each step improved throughput but increased complexity for hardware, OS, and compilers.
