Module 3 › Chapter 2.7 › AVX and AVX2
Architecture highlights

AVX

  • 256‑bit YMM registers process more data per instruction.
  • Three‑operand instructions avoid destructive overwrites and reduce moves.

AVX2 additions

256‑bit integer SIMD, gather instructions for scatter/gather memory patterns, and FMA for combined multiply‑add throughput.

Pro Tip

Use three‑operand forms to reduce register spills; that often improves real performance more than raw width alone.

Concrete example

A dot product on single‑precision floats: an AVX kernel operates on eight floats per vector instruction versus four with SSE, reducing the instruction count for arithmetic by about twofold.

  • Real gains depend on memory bandwidth and alignment.
  • Gather helps when data is not contiguous, but is often slower than contiguous loads.
Key Takeaway

Wider vectors and three‑operand formats reduce instruction count and spills, but overall speedup depends on memory and execution-unit limits.
