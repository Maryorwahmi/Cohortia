Code Walkthrough

Below is a compact C skeleton for an AVX dot product. Replace headers and intrinsics for SSE and AVX‑512 variants and provide scalar fallback for tails.

// AVX skeleton (compile with -mavx or proper intrinsics header escapes shown below)
#include <immintrin.h>
float dot_avx(const float *a, const float *b, size_t n) {
  size_t i = 0;
  __m256 vsum = _mm256_setzero_ps();
  for (; i + 8 <= n; i += 8) {
    __m256 va = _mm256_loadu_ps(a + i);
    __m256 vb = _mm256_loadu_ps(b + i);
    vsum = _mm256_add_ps(vsum, _mm256_mul_ps(va, vb));
  }
  float tmp[8];
  _mm256_storeu_ps(tmp, vsum);
  float sum = tmp[0]+tmp[1]+tmp[2]+tmp[3]+tmp[4]+tmp[5]+tmp[6]+tmp[7];
  for (; i < n; ++i) sum += a[i]*b[i];
  return sum;
}
Practical notes
  • Use matching intrinsic headers: <xmmintrin.h> for SSE, <immintrin.h> for AVX/AVX‑512.
  • Measure with warm caches and multiple iterations to average noise.
  • Compute speedup ratios and explain non-linear scaling due to bandwidth and latency.
