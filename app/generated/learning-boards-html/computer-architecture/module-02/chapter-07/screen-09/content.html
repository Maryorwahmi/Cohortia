Module 3 › Chapter 2.7 › ARM Extensions
Core Concept

NEON

128‑bit SIMD for multimedia and signal processing. Often replaces VFP for vector floating point in modern ARM systems.

SVE and SVE2

Scalable Vector Extension allows variable vector lengths; SVE2 adds integer and DSP enhancements.

SME

Scalable Matrix Extension adds tiled matrix storage and operations targeted at AI kernels and high-throughput matrix math.

Key Takeaway

ARM's model favors scalable abstractions that let binaries run across diverse hardware without separate builds for each vector width.

Concrete example

A compiled SVE kernel can run on a processor with 128‑bit vectors and also on a processor with 512‑bit vectors; the hardware reports the vector length and the same binary adapts using predicates.
