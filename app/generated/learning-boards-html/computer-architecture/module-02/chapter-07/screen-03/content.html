Module 3 › Chapter 2.7 › Skill Targets and Assessment
What to demonstrate
  • Check CPUID and OS feature bits before using an extension.
  • Write three SIMD versions of a kernel: SSE, AVX, AVX‑512 and measure throughput.
  • Explain OS context-switch obligations for new registers and XCR0 usage.
  • Compare SVE's scalable vectors to fixed 512‑bit vectors and argue portability trade-offs.
Practical exercise

Implement the dot-product in three SIMD variants, compile and measure speedup. If AVX‑512 hardware is not available, reason from theoretical throughput.

Key Takeaway

Mastering feature checks and fallback code preserves correctness across diverse hardware while letting you exploit faster paths where available.
