Module 3 › Chapter 2.7 › MMX vs SSE
Comparison

MMX

64‑bit integer SIMD registers aliased onto x87 floating-point registers. Introduced integer parallelism but created register aliasing complications.

  • Pros: faster integer multimedia operations for older code.
  • Cons: shared register file with x87; required careful state management.
Common Mistake

Assuming MMX and x87 can be used interchangeably without saving state; aliasing leads to corruption.

Comparison

SSE / SSE2

128‑bit XMM registers independent of x87, supporting floating point and, with SSE2, integer SIMD. Cleaner for compilers and ABI design.

  • Pros: independent register file, better floating-point SIMD, broader instruction set.
  • Cons: requires compilers and OS to recognize new registers for context saving.
Key Takeaway

Independent register files simplify use and ABI support, which is why SSE replaced MMX for most SIMD work.
