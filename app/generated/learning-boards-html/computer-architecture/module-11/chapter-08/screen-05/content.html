CCDs and IOD explained

CCDs group cores with a shared L3. The I/O Die centralizes memory controllers and PCIe connectivity and hosts the directory for cross-chiplet coherence.

Local sharing
Snooping and shared L3 provide low-latency sharing within a CCD.
Directory coherence
Directory-based protocols manage cross-CCD coherence through Infinity Fabric and the IOD.
Key Takeaway
Thread placement and memory affinity can reduce cross-CCD latency and improve throughput.
Concrete example
A multi-threaded simulation with shared data benefits when communicating threads are scheduled on cores within the same CCD to avoid directory lookups between chiplets.
Common mistake
Assuming L3 is uniformly shared across all chiplets; it is L3-per-CCD.
