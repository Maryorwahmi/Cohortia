Cache & Memory Hierarchy

L1 and L2 provide fast private storage. L3 is larger and shared per CCD. DDR channels provide the long-latency, high-capacity tier.

L1 & L2
32 KB L1I/L1D, 1 MB L2 per core for small, low-latency hits.
L3 (per CCD)
32 MB shared among eight cores to reduce DRAM traffic for shared data.
DDR channels
12-channel DDR5-4800 provides high aggregate bandwidth for streaming workloads.
Concrete example
A data-parallel solver with contiguous memory access benefits more from higher channel count than from a modest increase in shared L3.
Key Takeaway
Cache reduces latency; memory channels scale throughput. Measure which resource your workload stresses.
Common misconception
Believing larger L3 alone cures streaming bandwidth limits; it cannot replace channel bandwidth for large, streaming data.
