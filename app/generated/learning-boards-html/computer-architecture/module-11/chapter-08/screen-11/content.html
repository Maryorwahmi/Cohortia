Snooping vs Directory

Snooping is efficient inside CCDs or tiles; directory coherence enables scaling across chiplets and sockets at the cost of added latency.

Snooping (intra-domain)
Low latency for small-scale sharing inside CCDs or tiles.
Directory (inter-domain)
Scales across chiplets; incurs directory lookup and remote access costs.
Example
A shared counter updated by many threads benefits from placing threads in the same snoop domain to avoid remote coherence traffic.
Key Takeaway
Profile coherence events and reduce cross-domain sharing to minimize latency and bandwidth pressure.
Common mistake
Assuming coherence costs are identical across all cache accesses; domain boundaries matter.
