EMIB, mesh & UPI

EMIB bridges tiles on the package; an on-die mesh connects cores regionally; UPI connects sockets coherently in multi-socket systems.

EMIB
High-bandwidth short bridge between tiles on the same package.
Mesh
On-die routing for caches and core traffic.
UPI
Coherent multi-socket links for cross-socket memory access.
Scenario
Low-latency services should be scheduled to minimize cross-tile and cross-socket hops; throughput services can exploit many tiles and EMIB bandwidth.
Key Takeaway
Interconnect topology shapes where latency occurs; use placement and affinity to mitigate cross-hops.
