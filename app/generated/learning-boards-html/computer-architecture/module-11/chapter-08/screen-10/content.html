CMN-700 + CXL

CMN-700 provides coherent on-die paths. CXL lets systems add coherent off-die memory for pooling and expansion.

Directory-based coherence
Tracks ownership to avoid global snoops while scaling cores.
CXL expansion
Adds coherent memory pools that systems can share or expand into.
Concrete scenario
An analytics platform can attach CXL memory to handle peak in-memory aggregation without over-provisioning local DRAM across all servers.
Key Takeaway
CXL plus CMN-700 enables flexible, coherent memory architectures where capacity scales independently from core sockets.
Common misconception
Assuming CXL only increases capacity; it also changes memory topology and sharing semantics.
