Module 11 › Chapter 11.2 › Bus Actions
Bus action table (conceptual)
BusRd: Other caches may supply data. M transitions to S and writes back; E becomes S and supplies.
BusRdX: Request exclusive ownership. S/E caches transition to I; M writes back and becomes I after supplying.
BusUpgr: Invalidate other sharers only; no data fetch if requester already has a clean copy.
Example
If P2 issues BusRd and P1 has the block in M, P1 supplies data and writes back to memory, then transitions to S. The requester obtains S. That writeback is the extra memory transaction MESI sometimes triggers.
Misconception
Don't assume BusUpgr moves data. It only invalidates peers when the requester already has the clean copy locally.
Why this matters

Choosing between BusRdX and BusUpgr changes whether data crosses the memory controller. That choice directly affects latency and memory bandwidth under sharing patterns.
