Processor-triggered transitions
PrRd from I: Issue BusRd → result S or E depending on sharers.
PrWr from I: Issue BusRdX → transition to M once exclusive data obtained.
PrWr from S: Issue BusUpgr → invalidate sharers and transition to M.
PrWr from E: No bus transaction → local write, E→M.
PrRd/PrWr from M: Access locally, remain M.
Example
A core that reads a block and later writes it will often see I→E on BusRd and then E→M locally with zero bus traffic. This saves the cost of fetching or invalidating peers.
Common mistake
Issuing BusRdX instead of BusUpgr when the cache already holds a clean shared copy wastes bus bandwidth because BusRdX fetches data and exclusive rights rather than just invalidating peers.
Key Takeaway

Use BusUpgr to upgrade a local shared copy to modified without fetching data; avoid unnecessary BusRdX calls.
