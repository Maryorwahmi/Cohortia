Module 11 › Chapter 11.2 › Cache-to-Cache Supply
Why it helps
Supplying data from another cache avoids a memory read, typically lowering latency and reducing memory controller load.
When an M or E owner responds to BusRd, the requester can get data faster than fetching from DRAM.
Measure cache-to-cache supplies separately from memory read counts when evaluating protocol performance.
Example scenario
P2 modifies a block, making it M. A subsequent BusRd from P1 can be satisfied by P2 directly, giving P1 a clean copy quickly and reducing memory reads.
Misconception
Assuming memory will always be used to serve requests inflates predicted memory traffic. Cache-to-cache supply is an intended optimization in MESI implementations.
Key Takeaway

Cache-to-cache transfers can significantly reduce memory reads and lower latency when ownership or forwarder responsibilities allow caches to supply data directly.
