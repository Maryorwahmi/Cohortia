Module 11 › Chapter 11.2 › MESI States
State definitions
M
Modified
Dirty copy, sole valid owner. Memory is stale; writeback required on eviction.
E
Exclusive
Clean and only this cache has it. Can be written locally without bus traffic.
S
Shared
Clean, may be in multiple caches. A write requires invalidation of peers.
I
Invalid
No valid copy locally.
Example
A core reads a block nobody else has. The controller grants E. If the core writes immediately, it transitions to M locally with zero bus traffic — this reduces latency for read-then-write patterns.
Common misconception
Treating E and S as equivalent misses the critical exclusivity guarantee. If a cache believes it is Exclusive when another has a copy, correctness fails. Protocols ensure E only when no sharers exist.
Key Takeaway

Encode ownership separately from cleanliness: Exclusive gives permission to write without announcing it.
