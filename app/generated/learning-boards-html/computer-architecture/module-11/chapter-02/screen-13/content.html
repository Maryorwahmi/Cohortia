Trace starter (copy and step through)
P1: Read 0x1000  // BusRd -> P1: I → E
P2: Read 0x1000  // BusRd -> P1: E → S, P2: I → S
P3: Write 0x1000 // BusUpgr/BusRdX -> P3: I → M, others invalidate
P1: Read 0x1000  // BusRd -> P3 supplies; MESI: P3 M→S + writeback, MOESI: P3 M→O no writeback
P2: Write 0x1000 // ... continue tracing
P3: Read 0x1000  // ... continue tracing
Guidance for counting
  • Record each processor action and whether it issued BusRd, BusRdX, or BusUpgr.
  • Note which cache supplies data and whether the supplier writes back to memory.
  • Sum total bus transactions and total writebacks for MESI and then for MOESI.
Key Tip

When the supplier is a modified owner, ask whether the protocol transitions M→S with writeback (MESI) or M→O without writeback (MOESI).
