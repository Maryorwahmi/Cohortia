Module 11 › Chapter 11.2 › MOESI Owned
Owned explained
Owned is a dirty but shareable state. The owner supplies data to readers and avoids writing back to memory immediately.
When M receives BusRd, it becomes O and continues to provide the dirty copy to new readers.
MOESI reduces memory writebacks for workloads where modified data is read by other cores.
Example
If P2 modifies a line then P1 reads it, under MOESI P2 can become O and supply the dirty data to P1 without a writeback to memory, avoiding two memory transactions.
Where used
MOESI appears in AMD implementations to reduce memory traffic for dirty-sharing workloads.
Key Takeaway

Owned permits dirty sharing, avoiding writebacks and later memory reads when modified data is read by peers.
