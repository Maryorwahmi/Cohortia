Module 11 › Chapter 11.2 › Protocol Comparison
MESI
Baseline four states. May write back when M transitions to S. Supports cache-to-cache supply but can incur memory writebacks.
MESIF
Adds Forward state. One sharer supplies clean data to new readers, reducing memory reads for shared lines.
MOESI
Adds Owned state for dirty sharing. The owner keeps a dirty copy and supplies it to readers, avoiding writebacks.
Practical guidance

Choose MESIF when clean read sharing is common and the memory controller is a bottleneck. Choose MOESI when modified data is frequently read by others and writebacks are expensive. Measure to decide.
