Module 11 › Chapter 11.5 › Key Concepts
Directory Messages
RdReq, WrReq, UpgReq, DReply, Inv, Ack, WB are the essential messages used to coordinate caches and memory.
Directory Entry
State, sharers, owner, pending — together they permit targeted invalidations and ownership transfer.
Scalability
Snooping is O(N) broadcast; directories are O(1)/O(S) and scale better for large N.
Summary
Directory protocols trade hops for bandwidth savings. Choose representation and fallback strategies based on sharing patterns and network cost.
