Module 11 › Chapter 11.5 › Directory vs. Snooping
Latency
Hop counts
  • Directory read miss to modified owner: 3 hops (Req→Dir, Dir→Owner, Owner→Requester).
  • Snooping broadcast: 1 hop but must wait for arbitration and responses.
Bandwidth
Directory: O(1) or O(S). Snooping: O(N) per request due to broadcast. For large N, directory bandwidth wins.
Concrete contrast
In a 32-core system a snoop broadcast consumes bandwidth to all 32 caches even if only one had the block. A directory targets only the caches that matter, reducing traffic especially when sharing is limited.
Reflection
Which matters more for your design: per-request latency or aggregate network bandwidth? The answer guides the choice between snooping and directory protocols.
