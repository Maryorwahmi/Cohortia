Sequence
P1: Read 0 P2: Read 0 P3: Write 0 P1: Read 0 P4: Write 0 P2: Read 0 # Track after each step: state, sharers, owner, pending
Start: Block0 state=Uncached, sharers={}, owner=Memory. Step 1: P1 reads → state=Shared, sharers={P1}. Step 2: P2 reads → sharers={P1,P2}. Step 3: P3 writes → Inv to P1,P2; two Acks; state=Modified, owner=P3. Continue similarly for later steps.

Key Takeaway

Simulating the sequence makes message-count differences concrete: directories send targeted messages, while snooping sends broadcasts to all caches.
