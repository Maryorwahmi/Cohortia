Module 11 › Chapter 11.5 › Upgrade Request Handling
Definition
UpgReq flow
Requester already holds Shared. Directory invalidates others (not requester), waits for Acks, then sets Modified and owner=requester. No data transfer in the common case.
Key takeaway
Upgrades save bandwidth by avoiding redundant data replies when the requester already has the value.
Example
P1,P2 are sharers. P2 issues UpgReq. Directory: Inv -> P1. P1 -> Ack. Directory: owner=P2, state=Modified. No DReply needed.
Misconception
Upgrades never require data transfer — but if the requester had a stale or invalid copy due to an earlier race, correctness would fail; pending flags and proper serialization avoid this.
