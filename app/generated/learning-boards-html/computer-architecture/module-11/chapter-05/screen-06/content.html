Module 11 › Chapter 11.5 › Read Request Handling
Process
Read handling rules
  • Uncached: directory → memory; set state to Shared; add requester as sharer.
  • Shared: forward to memory or a sharer; add requester to sharers.
  • Modified: forward to owner; owner sends data to requester and becomes Shared; update sharers.
Key Takeaway

Reads to modified blocks require contacting the owner, producing a three-hop path but enabling targeted transfers without broadcast.

Concrete example
Sequence: P1 has Modified X. P2 issues RdReq(X).
# Message sequence (conceptual) P2 -> Dir : RdReq(X) Dir -> P1 : ForwardRdReq(X) P1 -> P2 : DReply(data) P1 : becomes Shared Dir : sharers = {P1,P2}, state = Shared
Misconception
Do not assume owner always writes back to memory first; forwarding directly to the requester is common and reduces latency.
