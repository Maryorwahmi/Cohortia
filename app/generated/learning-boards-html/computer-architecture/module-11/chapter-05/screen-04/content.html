Module 11 › Chapter 11.5 › Directory Entry Format
Definition
Directory entry
Each block's record tracks state, sharers, owner pointer, and a pending flag to serialize requests and avoid races.
State: Uncached / Shared / Modified
Sharers: bit vector or pointer list
Owner: cache id when Modified
Pending: prevents concurrent conflicting requests
Concrete example
Initial: Block 0 -> state=Uncached, sharers=empty, owner=Memory, pending=false. After P1 reads: state=Shared, sharers={P1}.
Common misconception
People assume a full bit vector is always used. In contrast, pointer lists save storage but require fallback handling when the list is full.
Key Takeaway

Directory entries are compact records that make targeted invalidation and ownership transfer possible without system-wide broadcasts.
