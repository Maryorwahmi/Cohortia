Module 11 › Chapter 11.5 › Directory Messages
Process
Message types
Each message plays a role in request handling and state transitions.
RdReq
Cache → Directory, asks for shared copy.
WrReq
Cache → Directory, requests exclusive ownership.
UpgReq
Shared cache → Directory to upgrade to Modified without data transfer.
DReply / WB / Inv / Ack
Responses, writebacks, invalidations, and acknowledgments complete the flows.
Example sequence
P1: Read 0 → RdReq to directory. Directory forwards to memory, DReply to P1. Directory adds P1 as sharer. Later P2: Read 0 adds P2 to sharers. P3: Write 0 → WrReq. Directory sends Inv to P1 and P2, waits for Ack, sets owner=P3.
Misconception check
Invalidations are not instantaneous; acknowledgments are required. Forgetting Acks can create races where two caches think they have exclusive ownership.
Pro tip
Track messages per request to reason about bandwidth and latency trade-offs.
