Directory Protocols and Scalability
Point-to-point metadata that tracks state, sharers, owner, and pending requests.
Why it matters: avoids system-wide broadcasts and reduces bandwidth on large core counts.
When used: large multi-socket or many-core systems where O(N) snooping is costly.

Key Takeaway
Directories use per-block metadata to limit messages to only involved caches, trading a small increase in latency per miss for far better bandwidth and storage scaling.
