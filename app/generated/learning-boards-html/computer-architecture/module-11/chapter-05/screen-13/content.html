Directory message accounting
  • Read miss to modified: 3 messages (Req→Dir, Dir→Owner, Owner→Req).
  • Write with S sharers: WrReq→Dir (1), Inv→S (S), Ack→Dir (S), final grant→Req (1) — plus any DReply or WB.
  • Upgrade: avoids DReply because requester already has data; still requires Inv/Ack to other sharers.
Snooping accounting
Every request is broadcast to N caches. Each broadcast consumes bandwidth proportional to N and requires arbitration. The owner responds directly, but the broadcast cost is paid regardless of the number of actual sharers.
