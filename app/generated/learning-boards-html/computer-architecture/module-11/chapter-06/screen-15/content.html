Module 11 › Chapter 11.6 › Key Concepts — Practical
Producer-consumer
Release on publish and acquire on consume form the synchronization edge that guarantees visibility.
Pitfalls
Avoid using relaxed for ordered synchronization and do not rely on x86-only behavior for portability.
Measure
Run spinlock and queue experiments on target hardware to see the real cost of fences and validate correctness.
Final takeaway
Always ask: what is the weakest memory order that still ensures the required happens-before relationship? Use that to guide your design.
