01
Explain memory fences

Describe each C++ memory order and the reordering constraints it imposes. This skill helps you pick orders that prevent races.

Verified competency milestone
02
Implement sync with std::atomic

Use acquire for loads and release for stores to build correct lock-free synchronization patterns like producer-consumer.

Verified competency milestone
03
Understand the memory model

Recognize sequential consistency and the weaker acquire-release and relaxed models, and how they compose in programs.

Verified competency milestone
04
Analyze performance trade-offs

Measure and compare relaxed, acquire/release, and seq_cst to understand where fences cost cycles and where they are unnecessary.
