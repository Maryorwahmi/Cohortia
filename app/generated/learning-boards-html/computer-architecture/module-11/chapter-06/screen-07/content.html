Module 11 › Chapter 11.6 › Producer-consumer example
Canonical code
// Producer
std::atomic data(0);
std::atomic ready(false);

void producer() {
  data.store(42, std::memory_order_relaxed);
  ready.store(true, std::memory_order_release);
}

// Consumer
void consumer() {
  while (!ready.load(std::memory_order_acquire)) {}
  int value = data.load(std::memory_order_relaxed);
  // value is guaranteed to be 42
}
Explanation
  • data.store is relaxed because ordering is provided by the flag.
  • ready.store uses release to publish prior writes.
  • ready.load uses acquire so subsequent reads see published data.
