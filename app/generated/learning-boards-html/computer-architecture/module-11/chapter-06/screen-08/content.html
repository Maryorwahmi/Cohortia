Module 11 › Chapter 11.6 › Performance implications
Relative cost (typical)
Relaxed < Acquire/Release < Seq_cst. On ARM, acquire/release often requires DMB, increasing latency. On x86, acquire/release often avoids hardware fences due to TSO.
Experiment
Implement three spinlock variants and measure 1,000,000 acquisitions with 4 threads. Compare timings to observe the cost of fences.
Practical recommendation
Prefer acquire/release for synchronization patterns. Use seq_cst only when you need global ordering. Use relaxed only when you can prove ordering is irrelevant.
Pro tip

Measure on the target architecture because fence costs vary significantly between x86 and ARM.
