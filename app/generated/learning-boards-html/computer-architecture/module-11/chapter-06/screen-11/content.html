Module 11 › Chapter 11.6 › Spinlock experiment
Version 1
Use memory_order_seq_cst for lock and unlock. Correct but potentially slow due to full fences.
Version 2
Use memory_order_acquire when acquiring and memory_order_release when releasing. Correct and usually faster.
Version 3
Use memory_order_relaxed everywhere. Likely incorrect but useful to measure and observe visibility failures.
Measurement checklist
4 threads, 1,000,000 lock/unlock per thread. Time each variant. Verify shared data is protected under the lock for correctness.
