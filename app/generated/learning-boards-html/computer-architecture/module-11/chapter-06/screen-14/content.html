C++ memory orders
seq_cst, acquire, release, acq_rel, relaxed, consume — know the guarantee each provides.
Hardware mapping
x86 TSO vs ARM DMB vs RISC-V fence forms determine whether hardware fences are required.
Choose weakest order
Prefer acquire/release where possible; use seq_cst only when global ordering is necessary.
Summary takeaway
Memory ordering choices shape correctness and performance. Practice with the producer-consumer and spinlock experiments to make these trade-offs concrete.
