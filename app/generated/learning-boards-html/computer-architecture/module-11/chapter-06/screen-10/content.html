Module 11 › Chapter 11.6 › x86 vs ARM
x86 TSO
Stronger default ordering reduces need for hardware fences for acquire/release. Compilers still insert compiler barriers when required.
ARM / RISC-V
Weaker memory models allow more reorderings, so acquire and release typically map to DMB or fence instructions to enforce ordering.
Practical tip
When writing portable code, program to the C++ memory model and test on your target architecture. Assume weak ordering if unsure.
