Learning Objectives
Four competency milestones you will verify.
Bloom: Learn → Understand → Apply → Master
01
Calculate speedup & efficiency
Compute S = T1 over Tp and E = S over P, then judge whether parallel resources are used effectively.
VERIFIED COMPETENCY MILESTONE
02
Understand Amdahl and Gustafson
Apply each law to predict limits: Amdahl for fixed-size strong scaling, Gustafson for weak scaling when workload grows.
VERIFIED COMPETENCY MILESTONE
03
Use profiling tools
Interpret output from tools like perf, VTune, or HPCToolkit to find hotspots, contention, and memory issues.
VERIFIED COMPETENCY MILESTONE
04
Identify bottlenecks & fixes
Recognize load imbalance, sync and communication overhead, and memory limits, and choose mitigation strategies.
VERIFIED COMPETENCY MILESTONE
