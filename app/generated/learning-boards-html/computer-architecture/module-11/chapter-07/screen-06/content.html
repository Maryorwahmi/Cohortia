Module 11 › Chapter 11.7 › Gustafson's Law
Law & formula
Gustafson suggests scaling problem size with P so parallel work grows while serial work stays constant.
S = P - f * (P - 1)
# f = serial fraction for scaled workload, P = processors
Numeric example:
f = 0.1, P = 64
S = 64 - 0.1 * 63 = 57.7×
When to use it
  • Weak scaling experiments where per-processor work remains constant as P increases.
  • Problems where larger problem size is meaningful and desirable to exploit more processors.
  • When evaluating throughput or capacity rather than single-case latency.
Misconception
Do not apply Gustafson's result to a fixed-size workload; it assumes you can increase parallel work with processor count.
Key Takeaway

If you can scale the problem size with P, Gustafson predicts much better speedup than Amdahl for the same serial fraction.
