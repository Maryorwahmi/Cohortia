Module 11 › Chapter 11.7 › Roofline Model
Model concept
Plot performance versus operational intensity. Two ceilings are the memory bandwidth roof and the compute roof.
Parallel extension:
Use aggregate peak flops and aggregate memory bandwidth across processors. Model communication as extra data movement or a separate network roof.
Practical steps
  1. Measure operational intensity of kernel.
  2. Measure aggregate bandwidth and peak compute for your parallel configuration.
  3. Place the point on the roofline and target the limiting roof.
Example guidance
If your point is memory-bound, focus on blocking, locality, and reducing data traffic. If compute-bound, optimize algorithms or exploit vectorization. If communication-bound, batch messages or redesign data layout.
Key Takeaway

The roofline gives a prioritized list of optimizations: choose the roof that limits your kernel to get the largest performance improvement.
