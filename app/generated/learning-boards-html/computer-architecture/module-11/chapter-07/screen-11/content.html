Module 11 › Chapter 11.7 › Memory & Sequential Limits
Memory bandwidth issues
When many cores request data faster than the memory subsystem supplies it, execution is memory-bound and scaling stalls.
Locality fixes
  • Cache blocking and tiling to reuse cached data.
  • Reorder loops to improve spatial and temporal locality.
  • Reduce working set sizes when possible.
Sequential bottlenecks
Identify code sections that cannot be parallelized and consider algorithmic changes or pipelining to reduce their impact.
Example: a serial reduction over a global structure may be converted to a two-stage local reduction followed by a final serial combine to reduce its cost.
Measure: use profiler counters for bandwidth utilization and wall-clock time for sequential sections to prioritize optimization.
Key Takeaway

Improving locality and removing or hiding sequential work often yields larger gains than micro-optimizing parallel kernels alone.
