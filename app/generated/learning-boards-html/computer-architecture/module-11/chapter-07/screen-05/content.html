Module 11 › Chapter 11.7 › Amdahl's Law
Law & formula
Amdahl's Law: speedup is limited by the serial fraction f in a fixed-size problem.
S = 1 / ( f + (1 - f) / P )
# f = serial fraction, P = processors
Worked numeric example:
T1 serial fraction f = 0.1 (10%)
P = 64
S = 1 / (0.1 + 0.9 / 64) ≈ 8.77×
Upper bound = 1 / f = 10×
Why this matters
  • Shows diminishing returns when serial work is nonzero.
  • Encourages measuring f to make informed scaling decisions.
  • Helps predict whether adding processors will be cost effective.
Misconception
Assuming linear gains with more processors ignores the serial cap; always compute both observed S and predicted Amdahl bound.
Key Takeaway

For fixed-size problems, even a small serial fraction dramatically limits maximum speedup as P grows.
