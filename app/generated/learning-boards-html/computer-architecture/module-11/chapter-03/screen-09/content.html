Module 11 › Chapter 11.3 › Dekker's Algorithm
Dekker's example
/* P1 */
flag1 = 1;
if (flag2 == 0) enter_critical();

/* P2 */
flag2 = 1;
if (flag1 == 0) enter_critical();
Under weak ordering, stores to flags can be delayed or bypassed, letting both threads see the other flag as zero and enter simultaneously.
Fenced fix
/* P1 */
flag1 = 1;
fence;              // ensure store is visible
if (flag2 == 0) enter_critical();
The fence forces ordering so the reader cannot observe the writer's store out of sequence. Alternatively, a release on the writer and an acquire on the reader achieve the same effect with potentially lower overhead.
Key takeaway
Prove algorithms under the target memory model or add the minimal synchronization to preserve their invariants under weaker models.
