Module 11 › Chapter 11.3 › Assessment
Guided activity
Run a two-thread experiment to detect weak memory outcomes, then add fences and measure performance impact.
Starter program (conceptual)
/* Thread 1 */
A = 1;
B = 1;

/* Thread 2 */
r1 = B;
r2 = A;
Observe whether r1 == 1 and r2 == 0 occurs. If it does, the architecture allowed a reorder or buffer bypass.
Evaluation checklist
  • Detect the forbidden outcome with many trials.
  • Add fences between writes and re-run.
  • Measure and report runtime differences.
  • Explain why fences fixed the bug and which guarantees they provide.
Why this matters
You will learn to connect formal models to measurable machine behavior and to reason about minimal synchronization for correct programs with acceptable performance.
