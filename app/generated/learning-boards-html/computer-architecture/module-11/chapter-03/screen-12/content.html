Module 11 › Chapter 11.3 › Key Concepts
Multiprocessor problem
Ordering of operations across processors determines which outcomes are allowed.
Sequential consistency
A single global interleaving that preserves per-processor program order; expensive to enforce.
Relaxed models & fences
Processor consistency, weak ordering, and release semantics trade some ordering for performance; fences restore necessary order at sync points.
Takeaway

Reason about visibility and program order, use the weakest correct fence, and validate assumptions experimentally.
