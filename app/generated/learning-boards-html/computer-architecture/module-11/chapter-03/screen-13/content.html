Module 11 › Chapter 11.3 › Quick reference
Fences
SFENCE: order stores. LFENCE: order loads. MFENCE: order both directions. Use weakest fence that keeps correctness.
Acquire/Release
Acquire prevents later ops from moving before it; release prevents earlier ops from moving after it. Pair for locks.
Models
SC is simple but costly. Processor consistency and weak/release order give performance with explicit sync points.
Final thought

Always ask: which memory order do I need at synchronization points, and what is the minimal fence that ensures it?
