Module 11 › Chapter 11.3 › Sequential Consistency
What hardware must provide
Property 1 — Program-order preservation
A processor must not let later operations be observed before earlier operations from that processor.
Property 2 — Single global interleaving
All processors must agree on one interleaving of all memory operations that respects each processor's program order.
Common hardware actions to enforce SC
  • Stall pipelines until previous stores complete.
  • Flush write buffers so stores become globally visible in order.
  • Prevent cache or buffer bypassing by loads that would read out-of-order values.
Process illustration
Imagine a post office queue where each clerk must release letters in sequence and every city receives those letters in the same order. If one clerk holds a letter in a private bag, others may see letters out of order unless the bag is delivered before later letters are sent.
Key takeaway
Preserving per-core order and synchronizing visibility are both required. Hardware that fails either will allow SC violations.
