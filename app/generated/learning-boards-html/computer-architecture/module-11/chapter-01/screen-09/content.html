Architecture

Interconnect topologies

Buses are simple, rings fit moderate core counts, and meshes scale to many cores. Topology influences latency and congestion behavior.
Ring: lower latency for neighboring cores, limited bandwidth for distant traffic.
Mesh: multiple paths, better scalability, hardware routing complexity.
Bus: simple arbitration, poor scaling.

Memory controller

Manages DRAM channels and request ordering. More channels raise total system bandwidth; the per-core share depends on core count.

Concrete question
If two chips have the same core count but one has twice the channels, the second will likely provide higher per-core bandwidth for streaming workloads.
