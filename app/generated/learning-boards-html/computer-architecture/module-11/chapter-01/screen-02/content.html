Learning Objectives

Master the taxonomy, memory models, multicore organization, and scaling trade-offs.

Bloom: Learn → Understand → Apply → Master
01
Describe Flynn's taxonomy
Explain SISD, SIMD, MISD, MIMD and give one example for each class.
Verified competency milestone
02
Differentiate memory models
Show when shared memory simplifies communication and when message passing is required.
Verified competency milestone
03
Explain multicore organization
Identify cores, private L1, shared L2/L3, interconnects, and the memory controller on a die.
Verified competency milestone
04
Analyze scaling trends
Calculate per-core bandwidth and discuss mitigation strategies like channels, HBM, and larger caches.
Verified competency milestone
