Module 11 › Chapter 11.1 › Flynn's Taxonomy
Definition

Flynn's 2×2 grid

Categorize systems by the number of concurrent instruction streams and data streams.

SISD
Single instruction, single data. Example: single-core CPU.
SIMD
Single instruction across multiple data elements. Example: vector units, GPUs.
MISD
Multiple instructions on same data. Rare; used in fault tolerance.
MIMD
Multiple instructions on multiple data sets. Example: multicore CPUs and clusters.
Analogy & guidance
Analogy: workers in a shop. SISD is one worker doing one task. SIMD is one instruction like an assembly jig that multiple workers use at once. MIMD is a team with different jobs. MISD is like several supervisors checking the same work item; uncommon but useful for safety checks.
Common misconception
SIMD inside a core does not make the whole machine SIMD. Many MIMD machines contain SIMD execution units for data-parallel work.
Key takeaway

Use Flynn's taxonomy to match workload patterns to hardware capabilities and to reason about programming models.
