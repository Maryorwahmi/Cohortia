Module 11 › Chapter 11.1 › Memory Bandwidth per Core
Calculation

Compute per-core bandwidth

Divide the processor's total memory bandwidth by the number of cores to obtain a simple per-core metric.

/* Example calculations (numbers from the chapter) */ TotalBandwidth_quad = 51.2 // GB/s (dual-channel DDR4) Cores_quad = 4 PerCore_quad = TotalBandwidth_quad / Cores_quad // 12.8 GB/s per core TotalBandwidth_64core = 409.6 // GB/s (8-channel DDR5) Cores_64 = 64 PerCore_64 = TotalBandwidth_64core / Cores_64 // 6.4 GB/s per core
Interpretation

Per-core bandwidth falling with core count explains why streaming workloads may prefer accelerators like GPUs or HBM-equipped chips that provide higher per-lane bandwidth.

Key takeaway
Always compute per-core bandwidth before assuming a many-core CPU will serve a bandwidth-heavy workload efficiently.
