Module 11 › Chapter 11.1 › Shared vs Distributed Memory
Definition

Shared-memory

Processors share a common address space. Communication happens through reads and writes to shared variables.

Examples: multicore CPUs, multi-socket servers.
Requires: cache coherence, locks or atomic operations, careful locality management.
Misconception
Shared memory hides communication but does not remove latency or bandwidth limits; coherence traffic can cause contention.

Distributed-memory

Each processor has private memory; data is exchanged with explicit messages, often via MPI or other libraries.

Examples: clusters, some supercomputers.
Requires: explicit communication, careful partitioning of data, and network-aware algorithms.
When to pick which
Use shared-memory for ease inside a node; use distributed-memory to scale across many nodes where you control data movement.
