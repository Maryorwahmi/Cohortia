Architecture

Anatomy of a multicore die

Identify the building blocks and their roles so you can reason about latency, capacity, and coherence traffic.
Cores: independent pipelines and registers; run threads.
Private L1 caches: per-core, low-latency storage for instructions and data.
Shared L2/L3: larger capacity caches shared among cores to reduce DRAM traffic.
Interconnect: bus, ring, or mesh connecting cores, caches and memory controller.
Memory controller & I/O: manages DRAM channels and off-chip interfaces like PCIe.
Concrete example
When many cores access the same memory addresses, private L1s can reduce immediate contention, but coherence protocols produce traffic that travels over the interconnect and can saturate links to the memory controller.
Key takeaway

Knowing each block's purpose helps you locate bottlenecks: is the delay in L1 hits, shared cache misses, interconnect congestion, or memory controller queuing?
