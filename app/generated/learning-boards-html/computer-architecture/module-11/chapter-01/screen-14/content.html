Module 11 › Chapter 11.1 › Key Concepts
Flynn's taxonomy
SISD, SIMD, MISD, MIMD guide mapping of programs to hardware.
Memory models
Shared memory uses implicit sharing; distributed memory uses explicit messages.
Hardware anatomy
Cores, private L1, shared L2/L3, interconnect, memory controller determine bottlenecks.
Summary takeaway

Use taxonomy to choose programming models, use memory model to design communication, and inspect hardware blocks to locate performance bottlenecks.
