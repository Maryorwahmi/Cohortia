Hierarchy

Levels and ownership

Caches trade off latency and capacity. L1: smallest and fastest. L2/L3: larger but slower and often shared.

L1 (private): fastest hits, per-core isolation.
L2/L3 (shared): larger capacity, reduce DRAM traffic, enable data sharing.
Coherence: kept by protocols that generate interconnect traffic.
Scenario
If several threads read the same dataset, a shared L3 can store that dataset once, saving DRAM bandwidth. If threads access private working sets, large private L1s would be ideal but are costly in area and power. Designers compromise with private L1s and one or more shared levels.
Check your understanding
When you see a performance hotspot, ask: is it an L1 miss, a shared cache miss, or a DRAM access? The correct diagnosis guides whether to change data layout, increase local caching, or reduce cross-core sharing.
