Trends

What grows and what doesn't

Core count: increases across generations (desktop: ~4–24, servers: dozens to ~96 cores).
Cache size: L3 caches have grown from MB to hundreds of MB; vendors use V-Cache to extend capacity.
Memory bandwidth: total bandwidth grows slower than cores, reducing per-core share.
Power: DVFS, clock gating, and core parking are used to control TDP as core counts rise.
Mitigations
Techniques include adding memory channels, using HBM, increasing cache capacity, cache compression, and prefetching. These reduce the impact of limited per-core bandwidth for many workloads.
Quick action
When profiling shows streaming bottlenecks, check channel count and consider HBM or accelerators rather than relying solely on more cores.
