Applied milestones

Each milestone links assessment to a real artifact or calculation you can perform.

Taxonomy task
Classify three systems and justify using instruction/data stream mapping.
Memory-model task
Map a parallel algorithm to shared or distributed memory and list synchronization points.
Organization task
Draw cache ownership and identify L1/L2/L3 sizes in a datasheet.
Scaling task
Compute memory bandwidth per core and suggest one hardware mitigation when bandwidth is low.
