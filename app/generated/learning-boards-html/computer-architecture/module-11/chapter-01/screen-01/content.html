Factory metaphor

Think of cores as workers, caches as local toolboxes, memory as the supply line, and the scheduler as the manager who assigns tasks. This helps reason about bottlenecks and power choices.

Flynn's taxonomy
A 2×2 classification that explains instruction and data streams for parallel machines.
Memory models
Shared memory uses implicit communication; distributed memory uses explicit message passing.
Scaling challenges
Core count grows faster than per-core bandwidth, creating bottlenecks designers must mitigate.

Scaling trade-offs
More cores mean lower bandwidth per core unless memory grows proportionally.
Heterogeneous cores
Combining big and little cores improves power efficiency but raises scheduling complexity.
