Module 11 › Chapter 11.1 › SIMD vs MIMD
Comparison

SIMD

Single instruction across multiple data lanes; great for vector arithmetic and streaming kernels.

Programming: vectorize loops, avoid divergence.
Example hardware: GPUs, vector units.
Pitfall: divergent branches reduce efficiency.
Comparison

MIMD

Multiple instruction streams on multiple data sets; fits threads, task parallelism, and heterogeneous workloads.

Programming: threads, synchronization, message passing
Example hardware: multicore CPUs, clusters.
Pitfall: synchronization overhead and data distribution complexity.
Concrete example
A matrix multiply can use SIMD inside each core for inner loops while using MIMD across cores to divide rows among threads. Combining levels of parallelism often yields the best throughput.
