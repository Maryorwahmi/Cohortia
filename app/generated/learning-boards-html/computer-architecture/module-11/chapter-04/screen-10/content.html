Module 11 › Chapter 11.4 › Test-and-Test-and-Set
Pattern
  1. Read lock variable in a tight loop without writing.
  2. When the read shows free, attempt TAS once.
  3. If TAS fails, apply a short randomized backoff before retrying.
Backoff types
  • Random fixed sleep between retries.
  • Exponential backoff increasing wait after each failure.
Concrete code sketch
while (true) {
  while (*lock == 1) { /* read-only spin */ }
  if (TAS(&lock) == 0) break; // acquired
  backoff(); // randomized pause
}
// critical section
*lock = 0;
Tune backoff so it reduces collisions without adding excessive latency.
