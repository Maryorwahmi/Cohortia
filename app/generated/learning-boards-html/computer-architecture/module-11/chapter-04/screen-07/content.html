How LL/SC works

LL marks a reservation on a memory address. SC stores only if the reservation is intact, failing if another core wrote to that address.

Practical note

On architectures with LL/SC, implement retry loops and consider instrumentation to detect frequent SC failures under contention.

Key Takeaway

LL/SC pairs allow atomic conditional stores without CAS and detect intervening writes even if the value returns to its prior state.

Pseudo
val = LL(&x)
// compute new_val from val
if (SC(&x, new_val)) {
  // success
} else {
  // failure: retry
}
Concrete example
On ARM or RISC-V, LL/SC sequences are preferred where CAS is not available; be prepared for SC to fail often under contention and plan backoff strategies.
