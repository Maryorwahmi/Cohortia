What is atomicity?

An atomic instruction executes as a single indivisible step as observed by other processors. It prevents interleaving on the targeted memory location.

Key examples
  • Test-and-set: read-and-set in one step, used for simple spinlocks.
  • Compare-and-swap: conditional update only when expected value matches.
  • Load-linked/Store-conditional: pair that checks for intervening writes.
Key Takeaway

Atomic primitives are necessary for correct shared-memory updates; choose the primitive that matches your architecture and algorithm needs.

Concrete example: lock-free push using CAS
old = head;
node->next = old;
if (CAS(&head, old, node)) {
  // push succeeded
} else {
  // retry: another thread changed head
}
LL/SC pattern (pseudo)
val = LL(&x);
// compute new_val
if (SC(&x, new_val)) {
  // store succeeded
} else {
  // another core modified x, retry
}
