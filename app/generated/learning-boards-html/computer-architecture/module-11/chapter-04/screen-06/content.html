CAS semantics

CAS(address, expected, new) does: if (*address == expected) *address = new and return true, otherwise return false.

Misconception

CAS alone does not prevent ABA; a location can change and revert to an earlier value, fooling a plain CAS-based check.

Pro Tip

Use version counters or tagged pointers with CAS to detect ABA where necessary.

CAS pseudo-code
CAS(address, expected, new_value):
  if (*address == expected) {
    *address = new_value
    return true
  } else {
    return false
  }
}
Concrete example
A lock-free push: read head, set node->next to head, CAS(&head, head, node). On failure, reload head and retry.
