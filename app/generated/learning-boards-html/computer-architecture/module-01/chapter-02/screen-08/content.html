Module 1 › Chapter 1.2 › Frequency vs Cycle Time
Definitions
Clock cycle time = 1 / frequency. Use seconds per cycle as the unit when computing execution time. Higher frequency reduces cycle time but may raise CPI.
Example
2.5 GHz → cycle time = 1 / 2.5e9 = 0.4 nanoseconds. Use that in the Iron Law.
Misconception
Advertised GHz is not a direct measure of application speed without CPI and IC context.
Quick comparison table
Compare hypothetical changes by computing execution time for fixed IC:
# Processor X: freq=2.5 GHz, CPI=1.2
cycle_time = 1/2.5e9 = 0.4e-9 s
ExecTime_X = IC * 1.2 * 0.4e-9

# Processor Y: freq=3.0 GHz, CPI=1.5
cycle_time = 1/3.0e9 = 0.333...e-9 s
ExecTime_Y = IC * 1.5 * 0.333...e-9
# Compare ExecTime_Y / ExecTime_X to see net effect
Always compute the ratio to decide which processor is faster for your IC and CPI values.
