Module 1 › Chapter 1.2 › Peak vs Sustained
Sources of the gap
  • Instruction mix: not all code uses peak functional units.
  • Memory and bandwidth limits cause stalls regardless of peak compute.
  • Branch and pipeline behavior reduce sustained throughput.
Practical advice
Report both peak and benchmarked sustained numbers and document workloads and configuration.
Real-world connection
A server optimized for ML training will look different from one tuned for single-threaded latency. Benchmarks reveal the differences so architects can match hardware to workloads.
