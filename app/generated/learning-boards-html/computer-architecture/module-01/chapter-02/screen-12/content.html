Module 1 › Chapter 1.2 › Hands-on: Race
Problem statement
Calculate execution time for IC = 10,000,000,000 on three processors.
# Given
IC = 10e9

Processor A: freq=2.0e9 Hz, CPI=1.5
cycle_A = 1/2.0e9 = 0.5e-9 s
Exec_A = IC * 1.5 * 0.5e-9 = 7.5 s

Processor B: freq=3.0e9 Hz, CPI=2.0
cycle_B = 1/3.0e9 ≈ 0.333333e-9 s
Exec_B = IC * 2.0 * 0.333333e-9 ≈ 6.67 s

Processor C: freq=2.5e9 Hz, CPI=1.2
cycle_C = 1/2.5e9 = 0.4e-9 s
Exec_C = IC * 1.2 * 0.4e-9 = 4.8 s
Result
Processor C is fastest (4.8 s), Processor A is slowest (7.5 s), B is intermediate.
Follow-up
If B increases frequency by 50% but CPI rises by 30%, recompute to decide whether performance improved.
