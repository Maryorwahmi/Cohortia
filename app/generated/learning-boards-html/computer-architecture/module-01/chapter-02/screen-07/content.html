Step-by-step calculation
# Given
CPI_base = 1.0
Branches: fraction = 0.20, mispredict = 0.05, penalty = 10 cycles
Loads: fraction = 0.25, miss = 0.04, penalty = 20 cycles

# Compute contributions
CPI_branch = 0.20 * 0.05 * 10 = 0.1
CPI_load   = 0.25 * 0.04 * 20 = 0.2

CPI_total = CPI_base + CPI_branch + CPI_load = 1.0 + 0.1 + 0.2 = 1.3
After computing CPI, convert to IPC where useful, but remain aware that IPC depends on instruction-level parallelism and issue width assumptions.
Check your units
Percentages must be fractions; penalties are cycles. A common error is treating percentages as cycles directly.
Misconception
IPC is not an absolute property of a core; it depends on the workload mix and available parallelism.
