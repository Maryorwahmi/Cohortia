Question
Is the new processor faster when frequency increases but CPI also increases?
# Old: freq_old = 2.5 GHz, CPI_old = 1.2
time_prop_old = CPI_old / freq_old = 1.2 / 2.5 = 0.48

# New: freq_new = 3.0 GHz, CPI_new = 1.5
time_prop_new = CPI_new / freq_new = 1.5 / 3.0 = 0.50

# Ratio
ratio = time_prop_new / time_prop_old = 0.50 / 0.48 ≈ 1.0417
# New is ≈4% slower
Interpretation
The advertised GHz increase did not yield a faster processor because CPI grew enough to offset the benefit.
