Module 1 › Chapter 1.2 › Measurement Methodology
Practical steps
  1. Select representative input datasets and execution modes.
  2. Warm up caches and predictors, then run trials.
  3. Collect counters for instructions, cycles, misses, and mispredictions.
  4. Repeat runs and report median or mean with variance.
Pitfall
Ignoring system noise and configuration differences leads to misleading comparisons.
From counters to CPI
Use counters to estimate fraction and penalty terms for CPI decomposition. For example, measure branch mispredictions and cycles lost to infer CPI_branch.
