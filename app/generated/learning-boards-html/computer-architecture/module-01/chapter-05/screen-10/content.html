Module 1 › Chapter 1.5 › Parallelism Levels
Instruction-level (ILP)
Extract parallelism within a single thread using multiple issue and speculation.
Data-level (DLP)
Vectorize operations across data elements using SIMD units and wide registers.
Thread-level (TLP)
Run independent threads or processes on separate cores with coherent caches and scalable interconnects.
Request-level (RLP)
Handle many independent requests concurrently in servers or distributed systems.
Design note
Apply Amdahl reasoning per level: determine the fraction that can be parallelized and the expected speedup to decide hardware resources.
Key Takeaway
Identify which parallelism level your workload exposes and invest transistor budgets where they yield the highest measured returns.
