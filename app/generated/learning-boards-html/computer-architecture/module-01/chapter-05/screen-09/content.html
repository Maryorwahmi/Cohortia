Module 1 › Chapter 1.5 › Common Case Fast
Principle explained
Make typical operations as fast as possible, accept slower execution for uncommon cases so average performance improves.
Example: RISC designs make common instructions single-cycle. Branch predictors aim for the common predictable branches to reduce pipeline stalls.
Trade-off
Optimizing for the common case can add complexity; validate with instruction-mix profiles to avoid overfitting to specific benchmarks.
Check your understanding
List the five most frequent dynamic operations in your workload and show how making them one cycle faster changes average CPI.
Key Takeaway
Accelerate what happens most often. Use measured instruction mixes to support design choices and avoid optimizing rare events.
