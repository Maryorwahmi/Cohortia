Learning Objectives
Understand, compute, apply, and evaluate core quantitative principles.
Learn → Understand → Apply → Master
01
Apply Amdahl's Law
Compute overall speedup from an optimization and decide whether it meaningfully improves performance. Practice with numeric examples so decisions are data-driven.
Verified competency milestone
02
Use the principle of locality
Explain temporal and spatial locality and show how a small amount of fast memory captures the working set, justifying cache levels in a hierarchy.
Verified competency milestone
03
Explain common-case-fast
Identify the frequent paths to optimize (e.g., simple instructions, cache hits) and justify designs that make common operations very fast.
Verified competency milestone
04
Analyze cost-performance
Compute performance per dollar or watt and decide if a faster but costlier design is justified by the market or power constraints.
Verified competency milestone
