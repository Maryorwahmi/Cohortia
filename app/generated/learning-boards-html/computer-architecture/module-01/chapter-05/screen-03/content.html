Practice & Assessment
Turn principles into calculations and design choices.
Learn → Understand → Apply → Master
Exercises
  • Compute end-to-end speedup using Amdahl's formula
  • Estimate cache hit rates from temporal locality
  • Compare performance per dollar for two designs
Assessment
Short problems: numeric Amdahl questions, justify a cache level from a working set heat map, and explain a cost-performance decision in a sentence.
Hands-on Activity
You are given a breakdown of execution time and a budget to improve a single component. Use Amdahl's Law to compute the net speedup for each option and justify your choice.
