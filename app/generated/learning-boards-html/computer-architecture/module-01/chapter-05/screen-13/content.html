Module 1 › Chapter 1.5 › Hands-on: Amdahl Choices
Problem statement
Breakdown: integer 30%, FP 20%, memory 30%, branches 20%. Options: A 2× integer, B 4× FP, C 2× memory, D 3× branch predictor. Calculate net speedups and compare.
// Formula
// Speedup = 1 / ((1 - f) + f / s)

// Option A: integer 2x
// f=0.3, s=2 → 1 / (0.7 + 0.15) = 1 / 0.85 = 1.176×

// Option B: FP 4x
// f=0.2, s=4 → 1 / (0.8 + 0.05) = 1 / 0.85 = 1.176×

// Option C: memory 2x
// f=0.3, s=2 → 1 / 0.85 = 1.176×

// Option D: branch 3x
// f=0.2, s=3 → 1 / (0.8 + 0.0667) = 1 / 0.8667 ≈ 1.154×
Interpretation and combined case
Options A, B, and C are tied here because their f × effect produces similar overall gain. A higher local s on a small fraction may not beat a moderate s on a larger fraction. For combined improvements, compute combined denominator as (1 - total_f) + sum(f_i / s_i) for all improved fractions; the result is bounded by the parts you didn't improve.
Common pitfall
Assuming independence of improvements. Some optimizations interact, so measure or model combined effects carefully.
Key Takeaway
Always compute numeric net speedups and normalize by cost or complexity. Fraction and independence determine the true return.
