Module 1 › Chapter 1.5 › Design for Moore's Law
Opportunities as transistors grow
  • Add more cores for TLP if workloads parallelize well
  • Increase cache capacity to hold larger working sets
  • Add specialized accelerators where DLP is dominant
Constraints to watch
  • Memory bandwidth and coherence traffic can bottleneck extra cores
  • Power and thermal limits may restrict transistor use
  • Software must expose parallelism to use added hardware
Practical tip
Design modular features that can scale with transistor budgets rather than fixed monolithic resources to ease future growth and improve longevity.
Key Takeaway
Plan for growth deliberately: add resources where workloads will use them and avoid designs that create new bottlenecks as you scale.
