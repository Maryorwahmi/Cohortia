Amdahl calculation steps
A repeatable process to compare optimizations numerically.
1.
Measure baseline fractions
Profile to find f for the targeted component (e.g., memory, ALU, branches).
2.
Estimate achievable local speedup
Predict s conservatively; use microbenchmarks where possible.
3.
Compute overall speedup
Use Speedup = 1 / ((1 - f) + f / s) and compute the limit 1/(1-f) for max possible gain.
4.
Compare and decide
Rank options by net speedup and cost; prefer changes with high net gain per dollar or watt.
Worked example
f=0.4, s=2 → overall 1.25×; max = 1.67×. Use this gap to decide whether more effort is worthwhile.
Common mistake
Overestimating s or ignoring the cost of engineering yields poor ROI despite good-sounding local speedups.
Check
Before committing, run a microbenchmark to narrow s and adjust your decision.
