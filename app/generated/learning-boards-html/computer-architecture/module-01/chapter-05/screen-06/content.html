Module 1 › Chapter 1.5 › Max Speedup
Scenario A
90% arithmetic, 10% memory
• Improve arithmetic by 10× → overall ≈ 5.26×
• Improve memory by 10× → overall ≈ 1.10×
• Max if arithmetic → ∞: 1 / (1 - 0.9) = 10×
• Max if memory → ∞: 1 / (1 - 0.1) = 1.11×
Interpretation
These numbers show that even dramatic local speedups on rare events have small global effect. Focus engineering effort where it impacts most cycles.
Pro tip
Always present both f and s in trade-off discussions so reviewers see the bounded return clearly.
Key Takeaway
Large fractions matter more than large local speedups. Use this rule to prioritize optimizations with real global impact.
