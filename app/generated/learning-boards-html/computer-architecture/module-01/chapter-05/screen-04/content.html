Core Concept
Amdahl's Law
A formula that bounds overall speedup from a partial optimization.
• Definition: Speedup = 1 / ((1 - f) + f / s), with f = fraction improved, s = local speedup.
• Consequence: Maximum speedup as s → ∞ is 1 / (1 - f).
• Misconception: Speeding a rare path gives weak overall benefit.
• Use case: Prioritize optimizations by f × expected s impact.
Key Takeaway
Local speedups must be applied to a large fraction to produce big global gains.
Formula and immediate intuition
Speedup = 1 / ((1 - f) + f / s)
// f = fraction of execution time affected
// s = speedup of that fraction
Concrete example
If f = 0.4 (40% memory) and s = 2, Speedup = 1 / (0.6 + 0.2) = 1.25×.
Common mistake
Assuming infinite local speed yields infinite global speed. In fact, the serial portion caps gains.
Try this thought
Before optimizing, estimate f from profiling. A small f usually means low return on big engineering effort.
