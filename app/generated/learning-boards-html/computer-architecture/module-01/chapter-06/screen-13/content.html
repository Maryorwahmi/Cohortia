Module 2 › Chapter 1.6 › Avoiding Benchmarketing
Fair benchmarking practices
Use conservative compilation rules, require disclosure, and prefer base-mode results for fair comparisons.
Checks for vendor claims
  • Are compiler flags and environment documented?
  • Are both base and peak scores reported?
  • Can results be independently reproduced following the rules?
Concrete example
A compiler that replaces a benchmark's algorithm with a special-case routine improves the reported score but provides no benefit to users whose inputs differ; ask for base-mode runs to assess general performance.
Common mistake

Trusting peak-mode scores as representative. Peak scores explore best-case tuning but are not a substitute for reproducible base-mode comparisons.

Key Takeaway

Demand documented methodology and reproducible base results to avoid being misled by benchmark-specific optimizations.
