Module 2 › Chapter 1.6 › Other Benchmark Suites
Geekbench
Cross-platform consumer tests; easy to run but less strict than SPEC for reproducibility.
MLPerf
Machine learning benchmarks for training and inference; essential for AI accelerator evaluation.
STREAM
Memory-bandwidth microbenchmark; useful for diagnosing memory-bound workloads.
TPC-C / TPC-E
Transaction processing benchmarks for server database workloads and throughput evaluation.
EEMBC
Embedded workloads for low-power processors found in devices and appliances.
Use guidance
Combine suites to cover compute, memory, and domain-specific behavior rather than relying on a single number.
Concrete comparison
If profiling shows high memory stalls, STREAM helps estimate raw bandwidth; if ML kernels dominate, run MLPerf to compare accelerators.
Key Takeaway

No benchmark family fits all problems. Match the suite to the target workload's dominant resources.

Misconception
A good score in one suite implies system-wide excellence. Not true unless the suite stresses the same resources as your real workloads.
