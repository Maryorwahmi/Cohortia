Module 2 › Chapter 1.6 › Profiling with perf
Perf checklist and calculations
Collect counters, compute CPI and miss rates, and reason from numbers to bottlenecks.
Counters to collect
  • Total instructions executed
  • Total cycles
  • L1, L2, L3 cache misses
  • Branch mispredictions
  • Page faults
Key calculations
CPI = cycles / instructions. Miss rate = misses / references. Use these to estimate stall cycles and dominant bottlenecks.
Concrete example
Total instructions: 2,000,000,000
Total cycles: 3,000,000,000
CPI = 3,000,000,000 / 2,000,000,000 = 1.5
L1 misses: 20,000,000 of 200,000,000 refs → 10% L1 miss rate
Interpretation: CPI above pipeline ideal indicates stalls; 10% L1 miss rate suggests memory subsystem improvements or data layout changes could help.
Key Takeaway

Systematic collection and interpretation of counters lets you pinpoint whether compute, memory, or control flow limits performance.
