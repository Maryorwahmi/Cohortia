Cache behavior and working sets
Measure misses at L1/L2/L3 and compare working set to cache capacities to decide hierarchy trade-offs.
Metrics to collect
  • L1, L2, L3 miss counts and rates
  • Working set size and access patterns
  • Memory bandwidth utilization
Concrete example
A streaming workload shows high L1 misses but sequential accesses; prefetchers or higher bandwidth reduce stalls more than larger caches. A cache-friendly workload benefits from larger L2/L3 to reduce CPI.
Common mistake

Treating a single-level miss rate as the full story. Always check multiple levels and bandwidth to find the true bottleneck.

Key Takeaway

Cache tuning must match the working set and access pattern: sometimes prefetching and bandwidth improvements outperform larger caches.
