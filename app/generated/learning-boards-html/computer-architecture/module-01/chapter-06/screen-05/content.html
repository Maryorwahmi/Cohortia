SPEC CPU: process and scoring
Standardized compilation and geometric mean aggregation produce fair cross-machine comparisons.
Run steps
  1. Compile each benchmark with specified flags (base or peak).
  2. Run on the test machine and record execution time.
  3. Compute the ratio to the reference machine for each benchmark.
  4. Aggregate ratios using the geometric mean to form the final score.
Concrete example
If benchmarks produce ratios 1.2, 0.9, 1.1, 1.0, the geometric mean balances them so no single fast or slow case dominates.
Base vs Peak
Base enforces conservative flags for reproducibility; peak allows aggressive, possibly architecture-tuned optimizations.
Architects use base scores to compare hardware fairly. Peak can explore tuning limits but may not reflect general performance.
Key Takeaway

SPEC's rules and geometric mean make scores comparable and robust; prefer base-mode for fair hardware comparisons.

Quick note
The geometric mean treats ratios multiplicatively, avoiding outlier domination that the arithmetic mean can produce.
