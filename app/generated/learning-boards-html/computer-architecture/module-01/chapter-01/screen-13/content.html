Assessment Idea

Comparing Two Processors

Processor A: 3 GHz, CPI = 2 → relative time ∝ 2 / 3

Processor B: 2 GHz, CPI = 1 → relative time ∝ 1 / 2

Ratio: (2/3) / (1/2) = 1.33 → Processor B is 1.33× faster for the same instruction stream.

Common error: comparing only clock speeds or only CPI.
Correct method: compute the Iron Law product for each design and compare.
Key Takeaway

Always form the product of instruction count, CPI, and cycle time to compare designs fairly.
