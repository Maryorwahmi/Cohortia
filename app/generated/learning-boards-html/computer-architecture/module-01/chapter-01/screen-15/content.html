ISA is stable
Changing the ISA impacts software widely; architects usually keep it stable.
Microarchitecture matters
Different implementations of the same ISA produce very different performance and efficiency profiles.
Use the Iron Law
Compute instruction count × CPI × cycle time to compare real performance across designs.
Closing takeaway

Reason across the implementation stack, prioritize metrics by product, and use quantitative comparisons to guide design choices.
