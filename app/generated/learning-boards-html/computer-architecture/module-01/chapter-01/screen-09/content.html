Concept Formula

The Iron Law of Processor Performance

A compact product showing the three knobs architects tune to change execution time.

Execution Time = Instruction Count × CPI × Clock Cycle Time

Instruction Count: set by ISA & compiler
CPI: average cycles per instruction (microarchitecture)
Clock Cycle Time: 1 / frequency (microarchitecture & technology)
Use this product to compare processors quantitatively. Changing one factor often impacts the others.
Worked example

Processor A: IC = 1.0×10^9, CPI = 2, freq = 3 GHz → cycle time = 1/3 ns.

Processor B: IC = 1.0×10^9, CPI = 1, freq = 2 GHz → cycle time = 1/2 ns.

Execution time A ∝ 2 × 1/3 = 0.667; B ∝ 1 × 1/2 = 0.5. Processor B is faster by 1.33×.

Pro tip

Always convert specs to the three-factor product for apples-to-apples comparisons between designs.
