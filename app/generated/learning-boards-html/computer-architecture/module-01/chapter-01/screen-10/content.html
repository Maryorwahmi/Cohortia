Core i9 vs Atom — same ISA, different goals

Core i9 (example)
  • Out-of-order, wide issue → lower CPI
  • Large caches → fewer memory stalls
  • Higher area and power
Atom (example)
  • In-order, narrow issue → higher CPI
  • Smaller caches → more memory sensitivity
  • Lower area and power
Designers pick microarchitecture to meet product constraints while keeping the ISA stable so software remains compatible. Quantify choices using CPI, cache miss rates, and measured power for representative workloads.
Key Takeaway

ISA compatibility enables diverse implementations; microarchitecture decides how that ISA performs in practice.
