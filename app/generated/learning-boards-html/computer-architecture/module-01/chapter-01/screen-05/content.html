Definition

Microarchitecture: How the ISA is Realized

Microarchitecture defines pipelines, caches, branch prediction, and the execution engine used to implement ISA semantics.

Pipeline
Stages that split instruction processing to increase throughput.
Cache Hierarchy
Multi-level caches reduce average memory latency and affect CPI.
Prediction
Branch predictors lower misprediction stalls at the cost of area and power.
Out-of-order Engine
Extracts instruction-level parallelism to reduce CPI for many programs.
Example scenario

An in-order core used in low-power devices may accept higher CPI but achieves lower power and area. A server core targets low CPI for throughput even if it uses more silicon.

Mapping microarchitecture to metrics
  • Pipelines and predictors primarily affect CPI and throughput.
  • Caches reduce memory stalls but increase area and power budget.
  • Out-of-order engines increase performance for many workloads but raise design complexity, area, and verification effort.
Common Mistake

Assuming microarchitectural complexity always improves real-world performance. It may not for code with limited parallelism.
