Learning Objectives

Build competency across ISA, microarchitecture, logic, and the key evaluation metrics for processor design.

01
Distinguish ISA vs Microarchitecture
Explain the ISA as the programmer interface and microarchitecture as the internal implementation. Recognize cases where the same ISA has different implementations.
Verified Competency Milestone
02
Explain roles of each layer
Describe how ISA, microarchitecture, and logic/technology interact and the responsibilities at each level.
Verified Competency Milestone
03
Identify key metrics
List and explain performance, power, area, cost, and reliability and why each matters in design decisions.
Verified Competency Milestone
04
Understand the implementation stack
Explain how changes at one level change constraints or opportunities at other levels and give concrete examples.
Verified Competency Milestone
Bloom: Learn → Understand → Apply → Master
