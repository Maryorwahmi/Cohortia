What Is Computer Architecture?

Explore the instruction set as the programmer-visible contract, learn how microarchitecture implements it, and see how logic and technology realize the design with trade-offs across performance, power, and area.

Implementation Stack
ISA → Microarchitecture → Logic
ISA
Programmer-visible contract: instructions, registers, and memory model.
Microarchitecture
Pipelines, caches, predictors — how the ISA is realized.
Logic
Transistors, gates, and process node trade-offs for speed and area.
Explore Key Topics
ISA
Defines what instructions and registers look like to software. It is stable and shapes compilers and OS design.
Microarchitecture
Implements the ISA with pipelines, caches, and execution engines, and is where performance engineering happens.
Iron Law
Execution Time equals instruction count times CPI times clock cycle time. Architects tune these three knobs.
