How to verify each objective

Practical checks and small deliverables that prove understanding.

Inspect binaries and compilers
Verify that two processors run the same compiled binary to confirm a shared ISA. Write a short note explaining differences in assembler syntax if any.
Trace a memory operation
Map a load instruction through pipeline stages, cache lookup, and DRAM access to show which layer controls each behavior.
Collect metrics
Gather IPC, clock, power, and die area values and explain which design decisions produced them.
Compare two microarchitectures
Create a small table contrasting an out-of-order design and an in-order design that implement the same ISA.
