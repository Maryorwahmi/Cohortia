Strategies after Dennard: a short playbook
Five levers
  • Parallelism: more cores, wider SIMD, better threading.
  • Efficiency: heterogeneity, DVFS, and power gating.
  • Specialization: accelerators like GPU, NPU, DSP.
  • Memory: larger caches, smarter prefetch, 3D stacking.
  • Software: compilers, vectorization, parallel algorithms.
Concrete example

An AI inference pipeline pairs an NPU for matrix operations, a small CPU cluster for control, and a DMA engine for memory movement to maximize throughput per watt.

Misconception

Assuming hardware changes alone suffice ignores the need for software and system co-design to achieve real gains.

Key Takeaway

Sustained performance gains require coordinated use of multiple architectural and software strategies.
