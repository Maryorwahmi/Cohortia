Core Concept
Dark silicon: capacity without power to use it all
Power limits force parts of a die to remain off under typical workloads.
Mechanics
  • Power domains partition the die so blocks can be turned off.
  • Fine-grained gating reduces leakage and static power when units are idle.
  • Runtime schedulers decide which blocks to power based on performance needs.
Example

A SoC might keep an NPU and some GPUs dark until an application requests heavy inference or media processing, saving energy for common tasks.

Design implication

Designers must plan which blocks are likely to be active together and provision power delivery and thermal paths accordingly.

Misconception

Treating transistor count as uniformly usable ignores dark silicon; usable performance depends on which blocks can be powered simultaneously.

Key Takeaway

Dark silicon forces architectural choices about which features to include and when to activate them.
