Verification tasks
Task: Annotated Timeline

Collect transistor count, frequency, and TDP for a set of processors across years and annotate when Dennard scaling ends and when multicore rises.

Outcome: a short written analysis linking events to architectural shifts.
Task: Trade-off brief

Write a 250-word brief arguing whether a mobile SoC should weight area for an NPU versus adding more CPU cores, using power and reliability constraints.

Outcome: a justified design decision referencing power-per-operation.
Task: Short quiz

Explain dark silicon and give one management technique designers use to handle parts that cannot be powered simultaneously.

Outcome: a concise explanation and example.
Task: Reliability checklist

List four reliability risks introduced by smaller transistors and one mitigation strategy for each.

Outcome: concrete mitigations linked to risks.
