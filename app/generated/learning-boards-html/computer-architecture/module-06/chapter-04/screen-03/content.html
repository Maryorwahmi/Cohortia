Implementation Objectives

These four cards map to the hands-on activity in the chapter. Each explains the 'what' and 'why'.

ROB lifecycle
Allocate at dispatch, write result at execute completion, commit at head when ready. This enforces precise architectural order.
ROB entry fields
Each entry stores type, destination, value, ready, exception and speculation bits so commit can make correct decisions.
Commit & Flush
Commit writes results to the register file; on exception or mispredict, flush discards later entries and restores the last committed state.
Simulation goal
Run the provided trace to show that speculative instructions I3 and I4 are discarded and compute the misprediction cycle penalty.
