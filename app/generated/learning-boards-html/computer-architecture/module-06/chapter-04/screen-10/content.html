Module 6 › Chapter 6.4 › ROB ↔ RS ↔ RF
Reservation Station
Holds instructions and operand tags. Fires when operands are ready and issues execution out of order.
Reorder Buffer
Stores results, ready bits, exceptions, and speculation markers until commit ensures architectural updates in order.
Register File / PRF
Holds committed state; with a PRF and map table, uncommitted values can be stored in a physical register allocated at dispatch.
Flow: dispatch → RS (tags) → execute → write ROB or PRF → commit → update RF / memory. The mapping between architecture and physical registers or ROB entries is what lets reads find the latest value without corrupting committed state.
