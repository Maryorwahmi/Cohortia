Module 6 › Chapter 6.4 › Dispatch & Execute
Steps at a glance
  1. Dispatch: allocate ROB entry at tail and mark destination as pending.
  2. Place in RS: instruction sits in a reservation station until operands are ready.
  3. Execute: instruction executes out of order when operands available.
  4. Write result: write value into ROB entry and set ready bit.
Misconception
Writing a result to the ROB is not the same as writing to the register file; only commit writes to the architectural state.
Visual: Dispatch → Reservation → ROB writeback
Dispatch
Allocate ROB[tail] and update destination mapping so reads can find the pending value.
Reservation Station
Instruction waits for operands. When ready it fires and executes even if older ROB entries are not ready.
ROB Writeback
Result written to ROB entry and ready bit set. Commit will later move the value to the register file in order.
Pro tip
Ensure your simulator writes the value to ROB entries on execution completion so commit logic reads the ready bit, not reservation stations, for commit decisions.
