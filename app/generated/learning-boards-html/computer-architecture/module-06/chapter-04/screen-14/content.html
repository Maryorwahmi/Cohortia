Module 6 › Chapter 6.4 › Key Concepts
Imprecise exceptions
Out-of-order writes can hide the faulting instruction; precise handling requires in-order visibility.
Reorder Buffer
Circular buffer storing results, ready bits, exception and speculation flags until commit.
Dispatch → Execute → Commit
Dispatch allocates ROB entries; execute writes to ROB; commit makes changes architectural in-order.
Speculation & Flush
Speculative entries are marked and discarded on misprediction so their results never reach the register file.
PRF & Map Table
Map architectural registers to physical ones at dispatch to speed reads and reduce ROB search overhead.
ROB size matters
More ROB entries increase ILP potential but also increase area, power, and misprediction recovery cost.
Final takeaway
The ROB is the microarchitectural mechanism that reconciles out-of-order execution with the need for an ordered, recoverable architectural state.
