Module 6 › Chapter 6.5 › Why memory disambiguation is hard
Definition and contrast
Compare explicit register dependencies with implicit memory dependencies.
Register dependency
Instruction names registers; hardware compares register numbers to detect hazards.
Memory dependency
Addresses are computed at runtime; dependencies appear only after address calculation.
Misconception
Only the most recent store matters. Incorrect. A load must find the most recent store to the same address, which may be older than intervening stores to other addresses.
Concrete example
SW R1, 0x1000(R0)   # Store to 0x1000
SW R2, 0x2000(R0)   # Store to 0x2000
LW R3, 0x1000(R0)   # Load from 0x1000
The load must skip the store to 0x2000 and match the earlier store to 0x1000. That requires checking multiple prior stores, not only the immediately preceding store.
Key Takeaway

Implicit memory dependencies force associative address checks across prior stores, increasing hardware complexity versus register tracking.
