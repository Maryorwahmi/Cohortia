Memory Disambiguation and LSQ
Understanding store-to-load forwarding, speculation, and LSQ structure
Interactive 16:9 Masterclass
Problem

Loads may execute before prior stores compute their addresses. If addresses match, a load must receive the store's value rather than stale memory data.

Correctness

The LSQ tracks outstanding memory ops and enables store-to-load forwarding so that loads read the newest pending store value when needed.

Visual metaphor
Warehouse = Memory
Stores place shipments; loads request packages.
Loading dock = LSQ
Pending stores hold data until commit; loads may be served directly at the dock.
Speculation = Truck guessing
A load may depart early under a prediction; recovery is needed if the guess was wrong.
Explore Key Topics

Load-store queue (LSQ)

Speculative disambiguation
Predict conflicts to increase parallelism, with rollback on misprediction.
