Timeline comparison
Events and cycle counts for correct and incorrect speculation cases.
Correct speculation
Issue load early → load executes at cycle N → store resolves to different address at N+3 → no replay. Net gain: early completion cycles saved.
Incorrect speculation
Issue load early → load executes at N → store resolves to same address at N+3 → detect violation → replay load + dependents = extra cycles (e.g., 6). Net penalty: early cycles + replay cycles (e.g., 10 total).
Key Takeaway

Even a small number of costly mis-speculations can offset the benefits of speculation; quantify predicted gains against expected replay costs.
