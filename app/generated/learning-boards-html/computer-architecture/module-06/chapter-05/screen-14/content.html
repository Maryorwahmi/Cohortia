Module 6 › Chapter 6.5 › Key Concepts
Memory Disambiguation
Detect whether a load depends on earlier stores by comparing addresses at runtime.
Store‑to‑Load Forwarding
A load receives the value directly from a pending store in the LSQ when addresses match.
Load‑Store Queue (LSQ)
Program-order buffer holding addresses, data, ROB tags and status bits for loads and stores.
Final summary
Memory disambiguation seeks a balance: accurate detection and forwarding preserve correctness while prediction and clever scheduling unlock performance.
