Module 6 › Chapter 6.5 › Store-to-Load Forwarding
Forwarding process
Steps the processor follows when issuing a load.
1
Compute addresses
The load and prior stores compute effective addresses; the LSQ tracks address-known bits.
2
Associative check
The load compares its address against all prior store addresses in the LSQ to find the most recent match.
3
Forward or access memory
If a matching store with available data is found, forward it; otherwise read from cache/memory.
Concrete assembly example
SW R1, 0x1000(R0)    # pending store writes 0xABCD
LW R2, 0x1000(R0)    # load should receive 0xABCD via forwarding
The LSQ entry for the store contains the data 0xABCD; when the load issues, it finds that entry and reads the value without accessing the cache.
Key Takeaway

Forwarding allows loads to observe pending store data and avoids unnecessary memory accesses while preserving program order semantics.
