Module 6 › Chapter 6.5 › Value Prediction & Fusion
Value prediction
Predict instruction results to allow dependents to execute early.
Pros: can expose additional parallelism if predictions are highly accurate. Cons: misprediction causes re-execution and pipeline cleanup, often making it impractical for general-purpose processors.
Instruction fusion
Combine simple instructions into a single micro-op to reduce pipeline work.
Macro-op or micro-op fusion reduces the number of in-flight operations, lowering LSQ pressure and issue complexity without changing program semantics.
Key Takeaway

Use fusion widely to cut micro-op count; treat value prediction cautiously because of replay costs unless accuracy is proven high.
