Quick Reference

Issue rule
If Qi=0 copy Value to V; else copy Qi into Q.
Broadcast rule
One broadcast per cycle per CDB; listeners match tags to capture values.
Qi overwrite
New issues overwrite Qi; registers update only when Qi equals the broadcast tag.
Final Thought

When debugging, trace tags first: they reveal producer-consumer relationships and explain why a station remains busy or a register does not change.
