Execute

When execution begins

Execution requires both operands ready (Qj = Qk = 0) and access to a functional unit. Memory operations add address calculation and memory unit timing.

Operand readiness
Stations capture values from CDB broadcasts; only then can execution start.
Unit allocation
A ready station still waits if the functional unit is occupied.
Latency
Different operations have different cycle costs that determine overlap possibilities.
Scenario
MUL (3-cycle) starts early
If both operands are ready at issue, MUL occupies the multiplier and completes after its latency, broadcasting its result.
Misconception

Ready stations always execute immediately — not true. Functional units can be the bottleneck even when operands are present.
