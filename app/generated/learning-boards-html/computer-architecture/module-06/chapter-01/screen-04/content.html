Definition

Reservation Station Fields

Each entry stores operation, tags, values, an address offset, and a busy flag to manage readiness and allocation.

Op
Operation type (ADD, MUL, LOAD, etc.).
Qj / Qk
Tags naming reservation stations that will produce operands, or 0 if ready.
Vj / Vk
Operand values valid only when the corresponding Q is 0.
A
Address offset for memory operations.
Illustration
Example Entry (RS1)
Op: SUB
Qj: RS4
Vj: —
Qk: 0
Vk: 4
A: —
Busy: true
Concrete scenario
At issue, the station recorded RS4 as the producer for the first operand. It will wait for RS4 to broadcast and then capture Vj.
Key Takeaway

Tags, not speculative values, coordinate readiness. V fields are only valid when their Q is zero.
