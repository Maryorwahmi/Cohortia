WAW and Qi overwrites

When a new instruction claims a destination, Qi is overwritten to the new tag. The older producer still broadcasts, but the register only updates if Qi matches that older tag.

Implication
This prevents younger instructions from observing older writes as the register's future value, implementing write-order semantics via renaming.
Concrete example
Scenario
If RS_old will write R1 but before it does a newer RS_new issues to R1, Qi[R1] points to RS_new. When RS_old later broadcasts, Qi[R1] != RS_old so the register won't accept that older value.
