Architecture

Write Result & CDB

Complete operations broadcast a (tag, value) pair on the CDB. Reservation stations and the register file capture values by matching tags.

Broadcast
A tag and its result are sent on the CDB once the unit finishes.
Capture
Stations with matching Q fields capture the value and clear their Q.
Register update
If Qi[reg] matches the tag, Value updates and Qi becomes zero.
Trade-offs
Single bus hazard
Only one station can broadcast per cycle; simultaneous completions create a structural conflict.
Mitigation
Designers add more result buses or pipeline writes to reduce conflicts, trading area and power for throughput.
Key Takeaway

CDB semantics determine when stations and registers observe values; bus width affects structural conflicts and performance.
