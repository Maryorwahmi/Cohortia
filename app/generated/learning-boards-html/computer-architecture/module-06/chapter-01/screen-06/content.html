Process Flow

Issue (Dispatch)

1. Find station
Wait until an appropriate reservation station is free.
2. Read registers
If Qi=0 copy value into V; otherwise copy Qi into Q field.
3. Set destination Qi
Write the reservation station tag into the destination register's Qi.
4. Mark busy
Reservation station Busy becomes true; instruction awaits operands or execution unit.
Example
MUL R6, R2, R4 → RS4
At issue: Qi[R6]=RS4. For sources R2 and R4, if their Qi were 0 their values copy into Vj/Vk; otherwise RS4 records Qj/Qk tags.
Pitfall

Issue does not wait for operands to arrive; it records tag links so execution can start as soon as operands broadcast.
