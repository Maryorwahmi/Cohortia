Definition

Register file: Qi and Value

Every architectural register tracks which reservation station will produce its next value through Qi. If Qi is zero, the Value field is current and available to issue logic.

Qi
Tag of the pending producer reservation station, or 0 if the register is valid.
Value
Current register value; valid only when Qi = 0.
Example
Initial state
R1=5 (Qi=0), R2=3 (Qi=0), R6 pending from RS4 → Qi[R6]=RS4
Issue example
When MUL issues to produce R6, the simulator sets Qi[R6]=RS4. Other instructions that read R6 record Qj=RS4 until RS4 broadcasts.
Common misconception

Overwriting Qi discards earlier mappings for new readers, but it does not cancel the old instruction's broadcast — the old result can still satisfy stations that were waiting for it.
