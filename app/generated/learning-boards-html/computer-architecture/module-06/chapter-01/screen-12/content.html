Code Walkthrough

Simulator components

Data structures
Reservation stations: list of dicts with Op, Qj, Qk, Vj, Vk, A, Busy. Registers: Qi and Value per register. Functional units with remaining latency counters.
Core loop
Per cycle: issue (if possible), start executions for ready stations, decrement latencies, perform CDB broadcast for completed units, capture values, clear Busy tags.
Exercise
Simulate the sample sequence, measure cycles, then vary reservation station counts and plot cycles vs stations.
