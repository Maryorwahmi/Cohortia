In-order vs Out-of-order

In-order
Each instruction blocks the next until it completes; latencies sum sequentially.
Out-of-order (Tomasulo)
Independent instructions can run while others are in flight; tags and CDB enable this overlap.
Practical note

Measure with realistic sequences: only then will you see whether out-of-order execution yields fewer cycles for your code.
