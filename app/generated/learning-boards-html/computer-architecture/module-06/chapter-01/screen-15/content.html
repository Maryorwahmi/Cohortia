Key Concepts

Reservation station fields
Op, Qj/Qk, Vj/Vk, A, Busy — the scheduling unit that holds work until operands are ready.
Register Qi mapping
Qi points to the station that will write the register; Value is valid only when Qi = 0.
Common Data Bus
Broadcasts results by tag; listeners capture values and registers update when Qi matches.
Takeaway

Tomasulo's dynamic scheduling links producers and consumers via tags and broadcasts; performance depends on latencies, station counts, and CDB bandwidth.
