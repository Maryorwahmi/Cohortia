Module 6 › Chapter 6.7 › Intel Core Characteristics
Family summary

Sandy Bridge → Skylake → Raptor Lake

Shared traits: 4-wide decode, µop cache, TAGE branch predictors, unified scheduler. Issue widths often range around 6 μops per cycle while ROB and register counts grow across generations.

Ports & Units

8 execution ports with specialization: some ports focused on load/store, others on integer or branch operations. Port contention limits parallelism for certain instruction mixes.

Scheduler & Registers

Unified scheduler with 60–120 reservation entries and physical register counts that rose from ~180 to ~256 across generations.

Example

Skylake expanded the ROB and register file compared to Sandy Bridge, improving speculative work and throughput without changing decode width.

Spec highlights
Decode: 4-wide
Issue width: 4–6 μops/cycle
ROB: 168 → 224 → 512 entries
L1: 32KB I / 32KB D, L2: ~256KB, L3: shared
Misconception check

Seeing a high ROB count does not mean unlimited parallelism; decoders, physical registers, and cache behavior limit how many instructions can complete usefully.

Key Takeaway

Intel cores evolve by growing instruction windows and register files while maintaining a balanced front-end and port specialization.
