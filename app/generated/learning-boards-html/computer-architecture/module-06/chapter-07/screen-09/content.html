Module 6 › Chapter 6.7 › Evolution Timeline
Milestone timeline
Pentium Pro (1995)
3-wide issue, ~40-entry ROB, reservation stations
Introduced practical OoO execution and renaming in commercial CPUs.
Pentium 4 (2000)
Deep pipeline, trace cache; limited IPC for many workloads.
Core 2 (2006)
Return to wider issue, larger ROB (~96 entries)
Sandy Bridge (2011)
µop cache, 6-wide issue, 168-entry ROB
Skylake (2015)
6-wide issue, 224-entry ROB, AVX support
Zen (2017 → 2022)
6→8-wide issue, ROB 192→320 entries, unified L3
Apple M1 (2020)
8-wide issue, 630-entry ROB, large caches
Apple M4 (2024)
10-wide issue, 900+ entry ROB—industry-leading windows
Design trend
Wider issue, larger ROBs, more ports, bigger caches, accelerators, and heterogeneous cores
Reflection

Consider how pipeline depth, instruction window, and cache size interacted at each milestone to influence IPC and clock choices.
