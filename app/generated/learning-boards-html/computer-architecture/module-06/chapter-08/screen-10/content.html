Value Prediction
Guessing Results to Break Dependencies

What is Value Prediction?

A speculative technique that predicts the result of an instruction before it executes, allowing dependent instructions to proceed early.

Goal: Reduce Critical Path

By breaking data dependency chains, value prediction aims to increase instruction-level parallelism and accelerate program execution.

Key Takeaway

Value prediction is a high-risk, high-reward speculative technique to bypass instruction latency by guessing results, potentially boosting ILP.
