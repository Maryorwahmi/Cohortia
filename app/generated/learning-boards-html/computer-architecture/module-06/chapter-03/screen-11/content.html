Process Flow

Branch Misprediction Recovery

Restore RAT and reclaim speculative physical registers to return to a safe state.

Full RAT copy

Make a complete snapshot of the RAT for each branch prediction. Fast to restore, higher memory cost per checkpoint.

Checkpoint stack

Record only changed mappings on a stack when a branch is predicted; on mispredict, pop changes to restore the RAT incrementally.

Future file

Keep speculative mappings separate from the architectural RAT until commit; merge them on commit or discard them on mispredict.

Common mistake

Forgetting to free speculative physical registers on mispredict leaks storage and eventually starves the free list, causing stalls.

Key Takeaway

Checkpoint choice balances memory cost and restore complexity; always reclaim speculative registers when aborting speculation.
