Techniques to Reduce PRF Cost

Banking, hierarchical files, and bypassing each approach the same problem differently.

Register file banking

Split the PRF into banks to reduce ports per bank. Access based on low bits of the physical register number.

Trade-off: fewer ports per bank versus bank conflicts.

Hierarchical register file

A small, fast register file caches hot values; a large, slower file holds the rest.

Trade-off: manage movement between levels and consistency with the RAT.

Read-after-write bypassing

Forward a write directly to a same-cycle read to avoid PRF access when data is fresh from a write port.

Trade-off: bypass logic adds wiring but saves port energy and latency.

Key Takeaway

No single mitigation is perfect; combine banking, hierarchy, and bypassing based on workload and conflict profiles.
