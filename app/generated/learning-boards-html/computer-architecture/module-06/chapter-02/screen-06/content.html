CDB signal breakdown
  • Tag: reservation-station identifier (5–8 bits) used for comparators.
  • Value: result payload (32–64 bits) consumed by stations or register file.
  • Valid: 1-bit that marks the broadcast as meaningful this cycle.
Match logic

Every station uses a comparator to check incoming tag vs Qj and Qk. On match the station captures the value and clears the tag field so the operand is marked ready.

Physical implications

The CDB is a long wire driving many comparators and register-file inputs. Its capacitance and fanout increase delay and power. Designers sometimes broadcast only tags and let receivers fetch values separately to reduce wire width, but that increases read complexity.

Analogy

The CDB is like a long PA cable; the louder and longer it gets, the more careful you must be with amplifiers and listeners.
