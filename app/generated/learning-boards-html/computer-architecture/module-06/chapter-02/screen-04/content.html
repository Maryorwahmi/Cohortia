Per-field description
  • Op: opcode encoding, small (3–5 bits) but must cover supported operations.
  • Qj, Qk: producer tags (5–8 bits). Zero indicates the value is ready.
  • Vj, Vk: operand values (32–64 bits) present only when Q=0.
  • A: address offset for loads/stores (16–32 bits).
  • Busy: 1 bit indicating the station is occupied.
  • Dest: destination tag or register ID (5–8 bits).
Concrete sizing example
// Example sizing (typical)
Op: 4 bits
Qj: 6 bits
Qk: 6 bits
Vj: 64 bits
Vk: 64 bits
A: 16 bits
Busy: 1 bit
Dest: 6 bits
----
Total ≈ 167 bits per station
Tip: Round sizes to simplify layout planning and wiring.
Common misconception

Although the storage size seems small relative to a cache, the distributed comparators and the wiring to the CDB create significant area, routing congestion, and power demands that must be considered in floorplanning.

Station file scaling

Multiply per-station bits by the number of stations to get total storage. For 50 stations at ~200 bits each you get about 10,000 bits, roughly one to two kilobytes. That storage is modest, but wiring and per-station comparators multiply area and power costs.

Key takeaway
Bits are cheap; routing, comparators, and timing are expensive.
