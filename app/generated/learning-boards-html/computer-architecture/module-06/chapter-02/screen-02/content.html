Use these objectives as milestones. Each one links to a verified competency you can self-assess with a short design task.

01
Design reservation station structure

Map op, Qj/Qk, Vj/Vk, A, Busy, and Dest fields to bits and compute storage area. This matters because the station file size affects layout and timing on chip.

Mnemonic: "Fields → Bits → Area"
VERIFIED COMPETENCY MILESTONE
02
Implement CDB arbitration logic

Select a priority scheme for simultaneous completions and reason about latency and fairness. This decides which result is delivered and which must wait.

Mnemonic: "One mic at a time"
VERIFIED COMPETENCY MILESTONE
03
Analyze CDB area and timing

Explain why a long bus driving many comparators creates a critical path and propose mitigations such as segmentation or hierarchical drivers.

Mnemonic: "Wire length → Delay"
VERIFIED COMPETENCY MILESTONE
04
Relate CDB bandwidth to IPC

Calculate how many results per cycle the CDB must carry to avoid stalls, and weigh that against comparator and wire cost when adding buses.

Mnemonic: "Bandwidth vs. Comparators"
VERIFIED COMPETENCY MILESTONE
