Module 6 › Chapter 6.2 › CDB Arbitration
Arbitration options
  • Oldest-first: pick the instruction that entered the window earliest.
  • Type-priority: prioritize integer over FP or vice versa.
  • Round-robin: cycle through units to ensure fairness.
Three-completion example

Suppose three FUs finish at once and the system uses oldest-first. The oldest result broadcasts now; the other two wait in an internal queue and compete in the next cycle. With type-priority, a lower-priority result might be delayed repeatedly, which reduces its downstream throughput.

Implementation notes
  • Arbiter latency must be minimized; it sits on the write path.
  • Keep a small hardware queue for completed-but-not-broadcast results.
  • Consider fairness and starvation when choosing priority rules.
Misconception check

Arbitration changes timing but not program correctness. However, timing differences change IPC and latency for instruction classes.
