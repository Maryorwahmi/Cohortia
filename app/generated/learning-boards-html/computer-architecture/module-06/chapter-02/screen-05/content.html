Module 6 › Chapter 6.2 › Reservation Station Control
Four-cycle responsibilities
Issue
Allocate a free station for the instruction and initialize Op, Dest, Qj/Qk or Vj/Vk, Busy, and A if needed.
Operand monitoring
Check the CDB each cycle. If a broadcast tag matches Qj or Qk, capture the value and clear the tag field to indicate readiness.
Dispatch
When both operands are ready and the FU is free, issue the instruction to the FU and mark the station as no longer blocking resources.
Write
The completed FU broadcasts on the CDB; receiving stations update Vj/Vk or register file entries accordingly.
Concrete trace example
Trace an ADD that depends on a previous MUL: at issue, ADD gets Qj pointing to MUL. When MUL writes its tag on the CDB, ADD captures Vj and clears Qj. If Qk is ready, ADD will dispatch next time the FU is free. This shows how tags convert to values over time.
Common pitfalls
  • Assuming only one producer needs monitoring. The station must match every broadcast each cycle.
  • Not handling partial readiness: store the first-arrived operand until the second arrives.
  • Failing to check FU availability before dispatch can cause structural hazards.
Key Takeaway

Station control must be low-latency and checked each cycle; missing a CDB capture or dispatch decision reduces IPC.
