Safe proof-of-concept steps

Follow these controlled steps to implement or analyze a Spectre-like POC. Only test on hardware you own and never target others' data.

Setup
  • Allocate array1 (small) and array2 (large probe array with 256-step spacing).
  • Ensure probe entries map to distinct cache lines.
Trigger
  • Train branch predictor with valid inputs.
  • Call the vulnerable code with an out-of-bounds index to cause speculative read and probe touch.
Probe & measure

Flush or evict probe array, trigger speculation, then time reads across probe entries to find the fast cached line and reconstruct the secret.

Safety & ethics

Only use your machine and data you own. Do not attempt to access other users' memory or systems. Use VMs or isolated hardware where appropriate.

Mitigation check

Inspect /proc/cpuinfo for flags like kpti, ibrs, ibpb, ssbd. Reason whether each flag blocks your POC and which attack step it interrupts.
