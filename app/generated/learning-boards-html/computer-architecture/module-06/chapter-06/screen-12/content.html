Module 6 › Chapter 6.6 › Hardware mitigations & browser defenses
Hardware features
  • SSBD — stops speculative load-store bypass to mitigate v4.
  • IBRS — restricts indirect branch speculation across privilege levels.
  • IBPB — flushes or restricts BTB entries on context switches.
Vendor trade-offs

Modern CPUs integrate mitigations to reduce runtime overhead, but these features still require validation and sometimes microcode updates.

Browser mitigation: Site isolation

Isolate different websites into separate processes so a renderer compromised by Spectre cannot access another site's memory in the same process.

Practical check

On Linux, examine CPU flags in /proc/cpuinfo and browser configuration to see which mitigations are enabled — then reason about the remaining risk given your threat model.

Key Takeaway

Hardware features and site isolation reduce the attack surface but are part of a layered defense; check flags and browser settings to assess protection levels.
