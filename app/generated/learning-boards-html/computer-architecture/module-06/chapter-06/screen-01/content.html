Speculative Execution and Security

Explore how high-speed CPU optimizations affect security, the mechanics of Spectre and Meltdown, and the trade-offs of mitigations.

Orientation

Speculative and out-of-order execution perform 'guesses' to keep pipelines full. These guesses leave microarchitectural traces like cache state. Attackers measure those traces to infer secrets. We will follow from concept to variants to mitigations with examples and practical guidance.

Speculation mechanics

How branch prediction and out-of-order execution can run instructions ahead of time and leave microarchitectural traces.

Attack variants

Spectre variants target predictors or memory disambiguation; Meltdown abuses privilege checks during out-of-order access.

Mitigations

Software and hardware fixes reduce leakage but often cost cycles; we'll evaluate the trade-offs.
