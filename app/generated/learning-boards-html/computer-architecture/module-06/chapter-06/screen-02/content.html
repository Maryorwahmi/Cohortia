Learning Objectives

Four focused competencies you will verify by explanation and example.

Bloom: Learn → Understand → Apply → Master
01
Explain speculative leaks

Describe how speculative execution can be exploited to leak information via microarchitectural state and why the architectural rollback does not erase cache changes.

VERIFIED COMPETENCY MILESTONE
02
Describe Spectre variants

Summarize Spectre-v1, v2, and v4 mechanics and the attacker prerequisites for each variant.

VERIFIED COMPETENCY MILESTONE
03
Understand Meltdown

Explain how out-of-order execution can allow a user-mode program to read kernel memory and why Meltdown differs from Spectre.

VERIFIED COMPETENCY MILESTONE
04
Analyze mitigations

Compare KPTI, retpoline, speculation barriers, and hardware features and evaluate their likely performance impact for different workloads.

VERIFIED COMPETENCY MILESTONE
