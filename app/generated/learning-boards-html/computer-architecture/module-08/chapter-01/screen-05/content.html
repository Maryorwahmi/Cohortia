Module 8 › Chapter 8.1 › Trace: P1 & P2
Trace steps
1. List program order
P1: S1(A), S2(B). P2: L1(B), L2(A).
2. Consider reorderings
Which operations the model allows to pass each other or buffer.
3. Consider propagation
Stores may be buffered and become visible later to other cores.
Enumerated outcomes
  • R1=0, R2=0 — both reads see initial values.
  • R1=1, R2=1 — both stores visible before reads.
  • R1=1, R2=0 — possible on weak models when stores are reordered or visibility delayed.
  • R1=0, R2=1 — possible with different interleavings or buffering.
Example check
Run a simulator for SC, TSO and weak models to see which outcomes are legal and why.
Key takeaway
Mechanical enumeration reveals which model permits which surprising behavior.
