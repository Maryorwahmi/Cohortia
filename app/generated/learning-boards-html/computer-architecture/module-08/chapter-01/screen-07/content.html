TSO: practical compromise
Store buffer enables write buffering; loads may bypass earlier stores to other addresses.
Store buffer behavior
  • Stores are placed in a local buffer and later propagated to cache/memory.
  • Local loads may read from the buffer, enabling the issuing core to see its own writes early.
This allows the CPU to continue without stalling for global visibility.
Ordering guarantees
  • Store-store order preserved.
  • Load-load order preserved.
  • Load may bypass earlier store to a different address (load-store reordering).
Fence instructions flush buffers to enforce ordering when required.
Illustration
Imagine a loading dock where outgoing trucks wait before entering the main road; local drivers can read from trucks in the dock immediately.
Example
x86 programs usually work without explicit fences because TSO preserves many useful orderings.
Takeaway
TSO balances hardware optimizations and programmer convenience using a store buffer.
