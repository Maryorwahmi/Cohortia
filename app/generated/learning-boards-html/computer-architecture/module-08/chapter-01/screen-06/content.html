Sequential Consistency
A single global order that preserves per-thread program order.
Formal rules
  • Result equals some sequential interleaving of all processors' operations.
  • Each processor's operations appear in program order in that interleaving.
Because of this, programmers can reason linearly about memory effects without inserting fences.
Hardware cost
  • Prevents store buffering and many out-of-order optimizations.
  • Requires strong ordering of memory commits, reducing throughput and latency hiding.
Most high-performance ISAs choose weaker models to avoid these costs.
Analogy
All cars follow a single lane — no passing allowed.
Example
Under SC, R1=1,R2=0 from our example cannot occur; program order must be preserved in the global view.
Takeaway
SC is simple for reasoning but expensive for fast hardware.
