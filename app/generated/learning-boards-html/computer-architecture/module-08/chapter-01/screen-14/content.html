Module 8 › Chapter 8.1 › Key Concepts
Consistency vs Coherence
Coherence: single up-to-date value. Consistency: ordering contract across threads.
Sequential Consistency
Single global interleaving that preserves each thread's program order.
TSO & Weak Models
TSO uses store buffer and allows load bypassing; weak models allow more reorderings and need fences.
Final takeaway

Always consult the ISA memory model when reasoning about concurrency; prefer library atomics and use fences only where necessary.
