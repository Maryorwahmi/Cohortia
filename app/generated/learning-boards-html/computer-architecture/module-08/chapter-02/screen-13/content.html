Module 8 › Chapter 8.2 › Message Count Comparison
Directory messages (per step)
  • Reads: requester→directory, directory→owner/sharer or memory, data back to requester
  • Write: requester→directory, directory→sharers(invalidate), sharers→directory(ACK), directory→requester(grant)
Snooping messages
Snooping broadcasts invalidations and requests to all caches; every core inspects the message and responds if it holds the block.
Reflection
For workloads with many readers in sparse groups, directories sharply cut message volume. For tightly-coupled small sockets, snooping keeps latency low. Ask: how often will your writes force many invalidations across the whole system?
