Module 8 › Chapter 8.2 › Key Concepts
Directory Entry
State, sharers, owner — the metadata that enables targeted messages instead of broadcasts.
Sharer Compression
Coarse vectors, limited pointers, hierarchical directories reduce storage at the cost of complexity or extra messages.
Directory vs Snooping
Snooping: low-latency small systems. Directory: scalable bandwidth for many cores, with storage and lookup cost.
Summary

Directories trade storage and per-request lookups for reduced broadcast traffic, making them the preferred approach for large multi-socket and many-core systems when designed with compression and distribution techniques.
