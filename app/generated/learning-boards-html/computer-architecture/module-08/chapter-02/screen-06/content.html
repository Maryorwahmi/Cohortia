Module 8 › Chapter 8.2 › Write Request Handling
Write request flow
Invalidations, owner transfer, and writeback handling
Uncached: Directory grants Modified and sets owner to requester.
Shared: Directory sends invalidations to all sharers, waits for ACKs, then grants Modified to requester.
Modified: Directory forwards request to owner; owner supplies data and invalidates its copy; ownership transfers to requester.
Scenario
P1 and P2 share block 0. P3 writes: directory issues invalidations to P1 and P2, waits for acknowledgements, then sets owner=P3 and state=Modified.
Message types
  • Read request/response
  • Invalidation and invalidation ACK
  • Forward-to-owner and writeback
Misconception check: ownership transfer often includes a writeback or data-forward so the directory can maintain memory consistency; ownership is carried via messages, not by simple pointer updates alone.
