Module 8 › Chapter 8.2 › Read Request Handling
Read request flow
Uncached • Shared • Modified paths
Uncached: Directory asks memory, sets state to Shared, adds requester to sharers.
Shared: Directory forwards to a sharer or memory, then appends requester to sharer list.
Modified: Directory forwards to owner; owner supplies data and downgrades to Shared; directory updates sharers.
Example
P1 reads block 0 (Uncached) → memory replies → directory adds P1 as sharer. P2 later reads → directory adds P2; now both are sharers.
Diagrammatic steps
1. Cache sends read request to directory.
2. Directory checks state and forwards request appropriately.
3. Directory updates sharer list and state as needed.
4. Data is returned to requester from memory or owner/sharer.
Misconception check: the directory is not a cache of data. It only points you to where the data currently resides so read requests can be satisfied without unnecessary broadcasts.
