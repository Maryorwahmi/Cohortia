Latency components
Directory lookup is one of several serialized steps.
  • Cache request to directory
  • Directory lookup time
  • Forwarding to owner/sharers and their responses
  • Data return to requester
When it matters
For more than tens of cores, directory access overhead (tens of cycles) is often acceptable because broadcast costs of snooping grow worse. For latency-sensitive code, hybrid approaches and directory caching help balance the trade-off.
Pro tip

Measure end-to-end request latency and traffic. Use distribution and caching if directory lookup time or hotspots cause queueing delays.
