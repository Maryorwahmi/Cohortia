Directory bandwidth
Controller must handle all coherence messages for its addresses.
Queueing at the directory increases access time. For large systems, a single controller can limit throughput and raise tail latencies.
Mitigations
  • Distributed directories: scatter directory entries to multiple memory controllers to spread load.
  • Directory caching: keep hot directory entries cached near requesters to avoid repeated lookups.
Design note: distribution reduces hotspot probability but complicates address-to-directory mapping and cross-controller coordination.
