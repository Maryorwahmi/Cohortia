Module 8 › Chapter 8.2 › Directory vs Snooping
Snooping
Broadcast-based coherence
  • Low latency for small numbers of cores
  • High broadcast bandwidth as cores increase
  • Little directory storage required
Directory
Point-to-point, per-block metadata
  • Scales to many cores with lower bandwidth cost
  • Higher per-request latency due to directory lookup
  • Significant storage overhead per memory block
Design rule of thumb
Snooping works well for 2–16 cores; directories become attractive beyond that range because broadcast costs dominate link bandwidth and contention.
