Module 8 › Chapter 8.2 › Directory Entry
Per-block entry
State • Sharers • Owner
State: Uncached, Shared, or Modified. Guides how requests are routed.
Sharers: Bit vector indicating caches that hold the block in Shared state.
Owner: Cache ID of the writer when state is Modified; otherwise memory controller.
Analogy
Think of the directory as a phone book listing who has a copy and who is the current writer.
Key Takeaway

The directory stores metadata for routing coherence messages; it must be present per memory block to avoid broadcast-based snooping.

Example state snapshot
Block 0
State: Modified
Sharers: 0000... (none)
Owner: P3
Block 1
State: Shared
Sharers: P1, P2
Owner: memory controller
Common misconception: the directory does not contain the block's payload. It contains only metadata and pointers used to route data and invalidation messages to the caches that actually hold the data.
