Module 8 › Chapter 8.2 › Sharer Lists & Storage
Problem: N-bit growth
Storage grows as N × M where N is cores and M is blocks.
Example: 1024 cores → 1024-bit sharer list per block (128 bytes). If memory has many blocks, directory storage becomes impractical.
Compression techniques
  • Coarse bit vectors: one bit per group of cores; reduces bits but may require group broadcast.
  • Limited pointers: store a small number of sharer IDs; fallback to broadcast if exceeded.
  • Hierarchical directories: multiple levels manage subsets to reduce per-entry size.
Design trade-off
Compression reduces storage but can add messaging or require fallbacks. Always analyze how often fallbacks will occur for your workload before committing to a compression strategy.
