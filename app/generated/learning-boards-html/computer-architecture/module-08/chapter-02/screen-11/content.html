Module 8 › Chapter 8.2 › Hybrid Protocols
Why hybrid?
Combine low intra-socket latency with scalable inter-socket messaging.
Snooping inside a socket benefits from fast shared L3 and short interconnect hops. The directory coordinates cross-socket coherence so you avoid expensive broadcasts across slow links.
Integration details
  • Map sockets as snoop domains; directory tracks which domain or cache holds data.
  • Ensure directory fallbacks and snoop acknowledgements are coordinated for correctness.
Designers should not assume this is trivial glue; it requires careful handling of ownership, invalidations, and fallbacks between domains.
