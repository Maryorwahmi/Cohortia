Task

Implement ZVC and BDI

Model lines, run encoders, and measure compressed size and a simple decompression cost estimate.

Test patterns
  • All zeros (1 KB).
  • Sequential integers (1 KB).
  • Random data (1 KB).
  • Repeated 0xABCD (1 KB).
Key Takeaway

Hands-on testing reveals which patterns benefit and shows the trade-off when decoding cycles are counted.

Example output
Expected results

All zeros: very high ratio. Sequential: high ratio with BDI. Random: near 1:1 ratio. Repeated pattern: good ratio depending on encoder.

Evaluation

Compare raw compression ratio and a net metric that subtracts decompression-cycle cost to judge practical benefit.

Pitfall

Measuring only bytes saved without considering decode latency can lead to misleading conclusions.
