Module 8 › Chapter 8.5 › Frequent Pattern Compression
Core Idea

Encode frequent full-line patterns

Detect a set of common templates and use short codes to represent them; uncommon lines remain uncompressed.

Detection

A fast check matches the line against known patterns; matching entries are stored as small tags and the full bytes are omitted.

Decoding

Code lookup replaces the tag with the original pattern on read, a cheap operation compared to full decompression.

Key Takeaway

FPC is cheap and effective for recurring constants, but only covers data that matches predefined patterns.

Concrete cards
Example patterns

0x00000000, 0xFFFFFFFF, repeated small constants like 0x00000001.

Pitfall

Choosing too many templates increases hardware checks; too few reduce effectiveness.

Pro tip

Profile your workload to pick the most frequent patterns before committing a hardware table.
