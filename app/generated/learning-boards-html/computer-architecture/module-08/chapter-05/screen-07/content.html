Module 8 › Chapter 8.5 › BDI Compression
Algorithm

Base plus deltas

Choose a base value and store each element as a small delta; decode by adding deltas back to the base.

// Example: values = [100,101,102,103]
base = 100
deltas = [0,1,2,3]
store: base + compressed deltas
reconstruct: for each d -> base + d
Key Takeaway

BDI is a strong low-latency encoder for nearby numeric values but needs small deltas to work well.

Concrete cards
Example: sequential integers

100, 101, 102 compress to base 100 and small deltas [0,1,2].

Limit

Floating-point data and widely separated pointers often do not yield small deltas.

Pro tip

Try different base choices and delta widths; hardware often tests a small set of encodings for speed.
