Module 8 › Chapter 8.5 › What is cache compression?
Definition

Cache compression explained

Store lines in compressed form to increase how much effective data fits in a cache set. This reduces misses when data is compressible.

Suitcase analogy

Vacuum-sealed clothes let you pack more in the same suitcase — similarly, compressible cache lines let a cache hold more logical lines.

When it helps
  • Sparse data with many zeros.
  • Arrays with small deltas or repeated patterns.
  • Workloads where decompression fits the cache latency budget.
Key Takeaway

Compression increases effective cache capacity but must respect latency and data compressibility constraints.

Concrete example
All-zero buffer

An entire cache line of zeros can be represented by a single bit indicating "all zeros," saving the full 64 bytes.

Sequential integers

An array of sequential numbers can be encoded as a base value and small deltas, reducing stored bytes per element.

Common mistake

Assuming all data compresses; encrypted or random data yields no benefit and may add overhead.
