Module 8 › Chapter 8.3 › Deadlock Avoidance
Deadlock: cycle of waiting
When packets form a resource cycle, none can progress.
Acyclic routing
Enforce an ordering, for example XY routing, so channels cannot form cycles.
Virtual channels
Separate traffic classes onto different virtual channels to break cyclic dependencies.
Important
Buffers alone do not remove cycles. Use ordering or channel separation to guarantee forward progress.
Example prevention
XY routing prevents turns that would create cycles. Alternatively, use two virtual channels: one for increasing X moves and another for Y moves, ensuring requests never wait in a way that cycles resources.
Takeaway
Design routing with deadlock avoidance in mind; combine virtual channels and ordering when needed.
