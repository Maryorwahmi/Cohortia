Module 8 › Chapter 8.3 › Torus & Crossbar
Torus
A mesh with wrap-around links connecting opposite edges. Reduces maximum distance and worst-case latency for large arrays.
Crossbar
Fully connected switch enabling any input to reach any output simultaneously. Maximum bandwidth but cost grows as N² for N ports.
Fat tree
Hierarchical tree with increasing bandwidth toward the root. Good for locality and large-scale systems where traffic funnels up the hierarchy.
Example use
Torus in supercomputers; crossbar inside small cache arrays or local switch fabrics.
Trade-off
Better connectivity often increases area and power significantly.
Visual: torus wrap vs crossbar
Torus: imagine the grid edges glued to opposite edges so paths can wrap, shortening long routes.
Crossbar: imagine teleporters allowing direct connections between any two endpoints at once.
Fat tree: multiple upward links that widen toward the root to avoid bottlenecks near the aggregation point.
