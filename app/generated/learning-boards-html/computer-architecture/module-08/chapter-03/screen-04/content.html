Interconnect: definition and role
A communication fabric made from links, routers and buffers
Key parts
  • Links: physical connections with width and latency constraints.
  • Routers: forward packets using routing logic and arbiter.
  • Buffers: store packets temporarily to handle contention.
Concrete example
A 2D mesh NoC maps cores to a grid. Each router connects to N,S,E,W and a local core. The physical layout matches chip placement, reducing wire length and offering multiple paths for traffic.
Key Takeaway

The interconnect is often the limiting resource; choose topology and routing to match concurrency needs.

Common misconception

Faster cores alone solve performance—no. Insufficient interconnect bandwidth can idle cores.
