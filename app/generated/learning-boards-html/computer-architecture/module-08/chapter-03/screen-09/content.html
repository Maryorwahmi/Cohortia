Module 8 › Chapter 8.3 › Flow Control
Store-and-forward
Each router receives the full packet before forwarding. Simple but adds packet-size dependent latency and requires larger buffers.
Wormhole switching
Packets split into flits. Header flit reserves path and flits stream through routers. Low buffer cost and low latency, common on-chip.
Virtual channels
Multiple logical buffers on the same physical link. They reduce head-of-line blocking and can be used to avoid deadlock.
Analogy
Wormhole is like a train; virtual channels are parallel tracks allowing overtaking.
Design note
Buffers cost area and power; choose flow control to match area and latency needs.
Visual: flit pipeline
Header flit reserves route
Body flits follow in a pipelined stream
Tail flit releases resources
Virtual channels: imagine two logical queues on the same link. If queue A stalls, queue B can still forward packets, increasing throughput and preventing head-of-line blocking.
