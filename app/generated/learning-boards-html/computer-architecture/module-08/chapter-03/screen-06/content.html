Mesh topology
2D grid; multiple paths and good bisection bandwidth
Manhattan distance
Hop count = |Δx| + |Δy|. This predicts latency if each hop costs a cycle or two.
Why meshes scale
  • Links grow with array edges; aggregate bandwidth increases.
  • Locality keeps many transfers short, reducing average latency.
  • Maps well to 2D silicon, minimizing wire length and power.
Concrete example

A 4×4 mesh: the path from (0,0) to (3,3) is 6 hops (3 in X, 3 in Y). If each hop costs 1 cycle plus 1 cycle routing, latency approximates 12 cycles total under no contention.
