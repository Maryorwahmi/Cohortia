Packet switching essentials
Headers, flits and hop-by-hop forwarding
Packet structure
Header with destination and control followed by payload flits. Header sets up route and subsequent flits follow.
Routing algorithms
XY routing: deterministic and deadlock-free. Adaptive routing: balances load but adds complexity. Minimal routing picks a shortest path.
Example path

Route (0,0) → (3,3) with XY: travel 3 steps in X, then 3 in Y. If each hop adds 1 cycle and routing decision costs 1 cycle, estimate per-hop latency accordingly.

Hop-by-hop: each router inspects header, picks next port and either forwards flits immediately or buffers them when blocked.
Misconception
Headers are prohibitive overhead. In practice header bytes are small and allow efficient multiplexing of many flows on the same fabric.
