Hotspot scenario
Sending many packets to (2,2) concentrates arrivals near that router. XY routing funnels paths into the final coordinates, increasing buffer occupancy and queuing delay. Adaptive routing or virtual channels can distribute load or allow bypassing blocked flows.
Bisection bandwidth
For a 4×4 mesh, consider a cut that divides the grid into two 2×4 halves. Count the number of links crossing that cut; that number, times link bandwidth, gives bisection bandwidth. Use this to reason whether the network can support aggregate flows between halves.
