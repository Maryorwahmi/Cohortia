Module 8 › Chapter 8.4 › Memory Bandwidth
Formula
Per-channel GB/s = bytes per transfer × transfers per second. Total GB/s = per-channel GB/s × number of channels.
Example: DDR4-3200
8 bytes × 3200M = 25.6 GB/s per channel.
Dual-channel total
25.6 × 2 = 51.2 GB/s.
Real factors that reduce sustained bandwidth
  • Refresh cycles that consume bus time.
  • Row misses and bank conflicts that serialize transfers.
  • Controller overhead and request reordering effects.
