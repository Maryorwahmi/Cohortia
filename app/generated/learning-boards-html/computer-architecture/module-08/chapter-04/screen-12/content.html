Module 8 › Chapter 8.4 › Theoretical Bandwidth
Calculations (exact)
// Dual-channel DDR4-3200
bytes_per_transfer = 8                      // 64-bit bus = 8 bytes
per_channel_rate = 3200e6                  // 3200 MT/s
per_channel_gb_s = (bytes_per_transfer * per_channel_rate) / 1e9
// per_channel_gb_s = 25.6
system_channels = 2
total_gb_s = per_channel_gb_s * system_channels
// total_gb_s = 51.2 GB/s

// Quad-channel DDR5-5600
bytes_per_transfer = 8
per_channel_rate = 5600e6
per_channel_gb_s = (bytes_per_transfer * per_channel_rate) / 1e9
// per_channel_gb_s = 44.8
system_channels = 4
total_gb_s = per_channel_gb_s * system_channels
// total_gb_s = 179.2 GB/s

// HBM2E with 4 stacks
per_stack_gb_s = 307
stacks = 4
total_gb_s = per_stack_gb_s * stacks
// total_gb_s = 1228 GB/s
Notes
  • These are theoretical peak numbers; sustained bandwidth will be lower due to refresh, conflicts, and controller overhead.
  • Keep units consistent: bytes, transfers per second, and channels.
