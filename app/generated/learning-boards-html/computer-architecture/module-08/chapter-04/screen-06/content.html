Module 8 › Chapter 8.4 › DRAM Organization
Hierarchy cards
Ranks
Independent sets of chips sharing the data bus; modules commonly have 1–2 ranks.
Banks
Independent arrays inside a chip, each with its own row buffer allowing parallel accesses across banks.
Rows & Columns
Rows are large addressable lines (e.g., ~8 KB); columns select smaller pieces (usually 64 bits) from a row buffer.
Practical implication
  • Interleaving addresses across banks lets multiple banks be active and transfer data simultaneously.
  • Many accesses to different rows in the same bank cause repeated activate and precharge steps, lowering throughput.
  • A good memory system maps hot, consecutive addresses to different banks to exploit parallelism.
Analogy: think of banks as rooms and rows as shelves inside those rooms. You can read from multiple rooms in parallel, but switching shelves in the same room is costly.
