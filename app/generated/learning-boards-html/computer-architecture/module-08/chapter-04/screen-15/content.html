Module 8 › Chapter 8.4 › Key Concepts
DRAM vs SRAM
Transistor counts, speed, density, refresh and use cases.
Organization
Ranks, banks, rows and columns set parallelism and row buffer behavior.
Bandwidth vs Latency
Bandwidth is throughput (GB/s); latency is time for a single access (ns). Both influence performance differently.
Takeaway
Use organization and bandwidth math together to determine whether a workload is bandwidth-limited, latency-limited, or both.
