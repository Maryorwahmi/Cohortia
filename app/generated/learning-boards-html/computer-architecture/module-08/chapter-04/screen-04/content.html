Module 8 › Chapter 8.4 › Why DRAM matters
Definition

DRAM is main memory optimized for density using one capacitor and one transistor per bit. It trades access speed for capacity and cost.

Concrete example

A server may have hundreds of gigabytes of DRAM but each random access can take tens of nanoseconds, while an L1 cache access is on the order of 1–2 ns.

Common misconception

High peak bandwidth does not guarantee low latency for single random accesses; they are separate metrics and both matter depending on workload.

Key Takeaway

Understand whether your workload needs sustained GB/s or low single-access latency before choosing memory technology.
