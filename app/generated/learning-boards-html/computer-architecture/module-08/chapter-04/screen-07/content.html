Module 8 › Chapter 8.4 › Rows, columns & row buffer
Access sequence
1. Activate (ACT): open a row and copy it into the row buffer (~15 ns).
2. Read/Write (CAS): access columns from the row buffer (~15 ns for the command/latency).
3. Precharge (PRE): close the row and write back modified data (~15 ns).
If the next access targets the same row, only CAS is needed. If it targets a different row in the same bank, precharge + activate + CAS are required, adding roughly 45 ns total compared to a hit.
Concrete example

Reading four consecutive columns in a row after a single activate is much faster than performing four separate accesses that each change rows. This is why spatial locality in programs maps well to DRAM row buffers.

Pro tip

Arrange hot data so consecutive accesses fall within the same row or across different banks to exploit row hits and parallelism.
