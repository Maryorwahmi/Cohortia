Module 8 › Chapter 8.4 › Memory Controller
Policies
Open-page: keep row open to favor locality and increase row hits.
Close-page: precharge immediately to reduce latency for random accesses.
Bank interleaving: distribute addresses across banks to enable parallel transfers.
Request reordering: reorder to improve row hits but may delay some requests.
Practical example

If the queue contains requests to rows A, B, A in the same bank, reordering to A, A, B yields two row hits instead of two misses. But that reordering can increase latency for the B requester. Controllers therefore mix throughput optimization with QoS rules to prevent starvation.
