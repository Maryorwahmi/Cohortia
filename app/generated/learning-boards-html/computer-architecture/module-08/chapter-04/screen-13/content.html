Matrix multiply (4096×4096)
N = 4096
flops ≈ 2 * N**3                          // ≈ 137,438,953,472 FLOPs
bytes_per_flop = 2                        // assumption from chapter
total_bytes = flops * bytes_per_flop     // ≈ 274,877,906,944 bytes ≈ 274.9 GB
// If performed in 1 second: required bandwidth ≈ 274.9 GB/s
