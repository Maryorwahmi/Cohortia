Module 9 › Chapter 8.6 › Hands-on Activity
Testing steps
  1. Check CPU feature flags for 'mte' or 'cet' to detect advertised support.
  2. If MTE is present, write an allocate/free/reallocate test that triggers a tag mismatch on stale access.
  3. If CET is present, test shadow-stack enforcement by attempting to redirect return addresses in a controlled program.
  4. Run tests under a kernel and runtime that enable the feature; log faults and verify behavior.
Example report
Describe the sequence, the observed fault type, and whether the behavior matched expectations. If you cannot run the test, describe the expected kernel fault and why it would occur.
Caution
Do not assume feature flags guarantee full protection. Kernel support and allocator behavior determine effectiveness.
