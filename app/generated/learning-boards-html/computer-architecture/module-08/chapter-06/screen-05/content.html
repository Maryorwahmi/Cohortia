Module 9 › Chapter 8.6 › Hardware bounds checking
Concept
Bounds checking and Intel MPX
Bounds checking stores metadata with pointers and verifies every access. MPX provided bounds registers and instructions on x86 to do this checking in hardware-assisted form.
Why MPX struggled
  • High overhead for some workloads (10–20%).
  • Needed compiler, runtime, and OS support.
  • Compatibility issues with legacy binaries.
Key takeaway
Strong protection is valuable only when it can be deployed with acceptable cost and effort.
Compare
MPX
High coverage for bounds checks but high overhead and integration cost; deprecated.
Tagging (MTE)
Lower overhead and easier integration; catches use-after-free and some cross-granularity overflows.
Reflection
When evaluating an architecture-level change, weigh not only theoretical coverage but the ecosystem work required to adopt it. If integration costs are high, even stronger mechanisms can fail in practice.
