Module 9 › Chapter 8.6 › Key Concepts
Memory safety vulnerabilities
Buffer overflow, use-after-free, dangling pointers cause corruption and exploits.
Hardware bounds checking
Checks each access against pointer-associated ranges; integration cost matters.
ARM MTE
4-bit tags per 16-byte granule and pointer tags; catches UAF and some overflows with low overhead.
Summary takeaway

Match defenses to threat models: use MTE and CET for low-overhead production protection and consider CHERI for research-grade, high-coverage designs.
