Memory encryption and control-flow integrity
Encryption protects physical confidentiality; CFI protects control-flow integrity against code-reuse after corruption.
Memory encryption
AMD SME/SEV and Intel TME encrypt memory to prevent data disclosure from physical access. This is orthogonal to software memory-safety mechanisms.
Control-Flow Integrity
Intel CET and ARM BTI add shadow stacks and branch target validation to stop ROP/JOP even if memory is corrupted.
Example
Use MTE to detect stale pointers, and use CET to ensure return addresses cannot be redirected by an overflow. Encryption protects memory if an attacker obtains physical access.
