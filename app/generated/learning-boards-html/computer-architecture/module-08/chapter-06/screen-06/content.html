ARM Memory Tagging Extension — Process
MTE assigns tags to 16-byte memory granules and to pointer high bits and checks them on access.
Steps
  1. Allocator tags a memory granule with a 4-bit value when it is given to a program.
  2. Pointers carry a 4-bit tag in their high bits representing expected tag.
  3. On memory access hardware compares pointer tag and granule tag.
  4. Mismatches cause a fault, catching reuse or cross-granule overwrites.
Key takeaway
MTE is a pragmatic middle ground: wide deployment is possible because overhead is low, though it does not close every gap.
Concrete example
Allocate block A tagged 3. Free A. Allocate block B at same location but allocator assigns tag 7. An old pointer to A still carries tag 3; hardware raises a tag-mismatch fault when the old pointer is used, preventing unintended access.
Check your understanding
Design two short tests: one that triggers a tag mismatch and one intra-granule overflow that MTE would miss. Observing the fault in the first proves MTE is active; the second highlights its limits.
