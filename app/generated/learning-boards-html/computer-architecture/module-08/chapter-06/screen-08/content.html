CHERI capability structure
A capability includes base, length, permissions, and a hardware-validity tag that prevents forging.
Fields
  • Base and length: define permitted address range.
  • Permissions: read, write, execute controls tied to the capability.
  • Tag: a hardware bit indicating capability validity, preventing forgery.
Security guarantees
CHERI prevents all buffer overflows and use-after-free dereferences by bounding every pointer. It also stops pointer forgery because the validity tag cannot be set by software.
Morello
ARM research prototype that implements CHERI-like capabilities for exploration and evaluation.
Deployment note
CHERI gives strong guarantees but requires broad ISA and toolchain changes, keeping it in research and prototype stages for now.
