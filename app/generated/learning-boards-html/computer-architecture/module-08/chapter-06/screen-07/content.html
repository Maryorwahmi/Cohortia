Conceptual C walkthrough
The following code is a conceptual sketch showing the allocate/free/reuse pattern that MTE detects when tags change on free and reallocation. It should be run on an MTE-enabled environment as an experiment rather than production code.
/* Conceptual C example (escape HTML) */
#include <stdlib.h>
#include <stdio.h>

int main() {
  char *p = malloc(32);           // allocate block A
  p[0] = 'x';                     // write via pointer with tag T1
  free(p);                        // allocator frees and may change memory tag

  char *q = malloc(32);           // new allocation at same address may get tag T2
  q[0] = 'y';                     // new occupant

  // dereference old pointer p: on MTE this should fault due to tag mismatch
  char c = p[0];
  printf("read: %c
", c);
  return 0;
}
Experiment steps
Run on MTE-enabled kernel. Observe a tag-mismatch fault when the stale pointer is accessed. This proves allocator-assigned tags are enforced by hardware.
Misconception
This test does not show all overflows are prevented; intra-granule overwrites within 16 bytes may not be detected.
