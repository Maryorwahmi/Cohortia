Module 9 › Chapter 8.6 › Memory safety vulnerabilities
Definition
Common memory-safety bugs
  • Buffer overflow: write past an object's bounds that can corrupt adjacent state or control data.
  • Use-after-free: accessing memory after it was freed and possibly reallocated for another purpose.
  • Dangling pointer: a pointer that still references deallocated memory.
  • Integer overflow: arithmetic that yields an incorrect size causing incorrect allocations or copies.
Common mistake
Assuming a crash proves an exploit failed. Silent memory corruption is common and more dangerous.
Key takeaway
These bugs enable both data corruption and exploit primitives; preventing them reduces attack surface significantly.
Concrete example
A network parser trusts a length field and copies payload into a stack buffer. If the packet reports a larger length than the buffer, the write can overwrite the return address. An attacker crafts the length to place controlled values where a future return will use them. This is a classic buffer overflow exploitation path.
