Cycle-by-cycle example
LW and ADD progression over cycles (abstract):
Cycle 1: LW in IF | ADD in IF
Cycle 2: LW in ID | ADD in ID
Cycle 3: LW in EX | ADD in EX  <- ADD needs R1 now
Cycle 4: LW in MEM (data ready at end of cycle)
Cycle 5: LW in WB  | ADD can use forwarded data in EX
Note that ADD's EX stage occurs before the load's MEM stage completes, causing the inability to forward in time. The stall inserts one cycle so ADD's EX happens when data is available.
Implication
  • Data from LW is not ready during the EX of the following instruction.
  • Forwarding cannot create data earlier than MEM produces it.
  • One-cycle stall aligns the dependent EX with the load's MEM/WB availability.
Concrete correction
Stall IF/ID for one cycle, insert bubble into EX, then allow MEM and WB to proceed; the dependent executes EX when the data is available and can be forwarded.
