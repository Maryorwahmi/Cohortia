Module 4 › Chapter 4.5 › Loop unrolling
How unrolling creates room
Original loop body with no scheduling room:
LW R1, 0(R2)
ADD R3, R1, R4
After unrolling twice, the body has more instructions the compiler can interleave:
LW R1, 0(R2)
ADD R3, R1, R4
LW R5, 0(R6)
ADD R7, R5, R8
Scheduler can reorder to place independent instructions between loads and uses, removing some stalls. Evaluate register pressure and code size before applying aggressively.
Trade-offs
Unrolling increases code size and may raise register pressure, which can introduce spills that hurt performance; use profiling to guide unrolling.
