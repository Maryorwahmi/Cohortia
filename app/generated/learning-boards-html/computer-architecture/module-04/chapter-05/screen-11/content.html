Module 4 › Chapter 4.5 › Compiler scheduling
Before scheduling
LW R1, 0(R2)    # Load
ADD R3, R1, R4  # Use (causes 1-cycle stall)
SUB R5, R6, R7  # Independent
After scheduling
LW R1, 0(R2)    # Load
SUB R5, R6, R7  # Independent moved into delay slot
ADD R3, R1, R4  # Use (no stall)
Compiler checks
The compiler must prove the moved instruction has no data or memory dependence on the load or its use. Conservative analysis may limit opportunities, especially with memory aliasing.
