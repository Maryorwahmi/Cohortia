Module 4 › Chapter 4.5 › Scheduling practice
Sequence A
LW R1, 0(R2)
ADD R3, R1, R4
SUB R5, R6, R7
AND R8, R9, R10
Scheduler can move SUB or AND between LW and ADD to eliminate the stall.
Sequence B
LW R1, 0(R2)
ADD R3, R1, R4
SUB R5, R1, R6
SUB depends on R1 as well, so it cannot be moved to fill the delay slot. Stall is unavoidable without unrolling.
Sequence C (loop)
LW R1, 0(R2)
ADD R3, R1, R4
LW R5, 0(R6)
ADD R7, R5, R8
Scheduling may rearrange between independent loads, but if dependencies form chains, unrolling can create room for scheduling; otherwise stalls remain.
Activity
Write a pass that finds load-use pairs, searches forward for independent instructions, and moves one into the delay slot; if none found, insert a NOP or leave the stall.
