Module 4 › Chapter 4.5 › CPI impact
Formula
CPI = CPI_base + p × 1
Compute p as the fraction of all instructions that cause a load-use stall. For the provided example:
Given
Load frequency = 0.20, fraction of loads followed by dependent = 0.50
Compute p
p = 0.20 × 0.50 = 0.10 → CPI increases by 0.10
Example result
If CPI_base = 1.0 then CPI = 1.0 + 0.10 = 1.10, a 10% slowdown due to load-use stalls.
