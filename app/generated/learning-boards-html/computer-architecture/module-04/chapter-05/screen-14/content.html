Module 4 › Chapter 4.5 › Hardware techniques
Speculative loads
Issue loads earlier out-of-order so their memory accesses overlap other work. Reduces observed latency but requires mechanisms to check memory ordering correctness.
Load buffering
Buffer load data allowing dependent instructions to read from the buffer before the value is written back to the register file, enabling earlier use.
Value prediction
Predict the load's value and execute dependent instructions speculatively. On misprediction, replay the dependent instructions, which costs cycles.
Practical trade-offs
Hardware removes some software limits but increases complexity and verification cost. Use profiling to justify hardware investment for critical workloads like pointer-chasing.
