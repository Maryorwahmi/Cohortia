Detection logic
The canonical boolean condition is shown below. It checks that the instruction in ID/EX is performing a memory read and that its destination register matches one of the sources in IF/ID.
ID/EX.MemRead && (ID/EX.Rd == IF/ID.Rs1 || ID/EX.Rd == IF/ID.Rs2)
Why MemRead?
Only loads require waiting for memory; other instructions produce data earlier and are handled by forwarding.
Register equality
Compare register IDs, taking care with encoding for register zero if the ISA defines it specially.
Misconception check
Do not check IF/ID destination registers; the comparison must use ID/EX destination against IF/ID sources to detect an imminent load-use pair.
