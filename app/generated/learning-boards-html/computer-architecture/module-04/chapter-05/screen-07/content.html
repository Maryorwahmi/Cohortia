Module 4 › Chapter 4.5 › Stall mechanics
Stall sequence
  1. Detect ID/EX.MemRead and register overlap with IF/ID sources.
  2. Freeze IF and ID stages: PC does not increment; hold IF/ID register.
  3. Insert a bubble into EX by preventing ID/EX update (NOP signals into EX).
  4. Allow MEM and WB to continue normally so load reaches MEM and provides data.
This preserves program order and correctness with minimal extra hardware: a stall control signal and bubble insertion logic.
Common pitfalls
  • Not freezing PC/IF causes fetch to continue and misalign instruction order.
  • Failing to neutralize EX control signals for the bubble causes unintended behavior.
Key Takeaway
A one-cycle stall is a small set of control changes that preserve correctness by aligning the dependent instruction with the load's data availability.
