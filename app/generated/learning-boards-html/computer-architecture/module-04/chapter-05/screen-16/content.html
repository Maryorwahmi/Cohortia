Timing gap
Data is ready at end of MEM but needed at start of EX.
Stall action
Freeze IF/ID, insert bubble in EX, forward from MEM/WB next cycle.
Mitigation
Try scheduling and unrolling first; use hardware techniques only when dependencies prevent software fixes.
Final reflective question: for a hot loop with p measured at 0.20 and limited independent instructions, would you first hand-tune code, unroll, or advocate hardware features? The answer depends on cost, code-size budget, and whether the workload is stable across deployments.
