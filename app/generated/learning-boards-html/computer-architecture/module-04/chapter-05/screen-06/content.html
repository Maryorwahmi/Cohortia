Module 4 › Chapter 4.5 › Forwarding vs Load
ALU result (forwardable)
When an ALU instruction produces a result in EX, that result can be forwarded immediately into the next instruction's EX stage. This supplies the dependent exactly when needed without extra cycles.
Example: 
ADD R1, R2, R3
SUB R4, R1, R5  # forwarded from ALU result
Load result (not early enough)
A load produces its value at the end of MEM. If the dependent instruction is immediately next, its EX happens before MEM finishes, so there is nothing to forward in time.
Example: 
LW R1, 0(R2)
ADD R3, R1, R4  # needs R1 too early -> stall required
Takeaway
Forwarding depends on when data is produced. If production occurs later than the dependent's demand, use scheduling or stalls to align timing.
