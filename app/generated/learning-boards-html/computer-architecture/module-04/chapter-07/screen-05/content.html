Benefits of Deeper Pipelines
How splitting stages raises clock frequency and throughput, and when it succeeds.
Shorter clock
  • Less combinational logic per stage reduces critical path time.
  • Shorter stage logic often yields higher maximum clock frequency.
  • Register insertion cost prevents an exact 1:2 speedup when doubling stages.
Example: 1.0 ns → 0.55 ns after splitting, assuming modest register overhead.
Higher throughput
  • Smaller cycle time increases instructions per second if IPC stays similar.
  • Works best with high ILP and accurate branch prediction.
  • Memory stalls and mispredicts can erode throughput gains.
Key Takeaway

Deeper pipelines can increase throughput, but only when hazards, mispredictions, and memory behavior are controlled.
