Core Concept
What is Superpipelining?
Dividing stages to shorten the clock and increase throughput.
Formal definition

Superpipelining increases the number of pipeline stages beyond the classic five by splitting work across more stage boundaries. The goal is to reduce per-stage work and enable a shorter clock period.

Concrete example
Split EX into EX1 and EX2; split MEM into address calc and data access. A 5-stage becomes a 10-stage pipeline.
Common misconception
More stages automatically halve cycle time — false. Register overhead and stage boundary costs reduce gains.
Key Takeaway

Superpipelining changes where work happens and shortens the clock, but real benefit depends on overhead and hazards.

Illustration: five vs ten stages
5-stage (classic)
IF → ID → EX → MEM → WB. Each stage does a larger chunk of work and sets a longer cycle.
10-stage (superpipelined)
IF → ID → EX1 → EX2 → MEM-addr → MEM-data → ... More boundaries, shorter per-stage work, faster clock in theory.
