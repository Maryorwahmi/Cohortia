Design Trade-offs
The Sweet Spot: Modern Pipeline Depths
Why 10–20 stages are common and how architects support them.
Pipeline depth
Modern depths trade frequency against branch penalty and register overhead.
Prediction & IPC
Large predictors and wider out-of-order issue help keep pipelines full at moderate depths.
Memory hierarchy
Caches, prefetchers, and coherence reduce memory stalls that would otherwise waste pipeline cycles.
Practical note
Pipeline depth decisions must be made with the whole microarchitecture in mind; depth alone is not a performance guarantee.
