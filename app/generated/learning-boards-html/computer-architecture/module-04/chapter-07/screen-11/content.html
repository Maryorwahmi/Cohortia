Calculate Branch CPI Impact — Worked Example
Step through the formula and apply it to a real number example.
Formula
CPI_mispredict = branch_freq × mispredict_rate × branch_penalty
Then: execution_time_per_instruction = (base_CPI + CPI_mispredict) × cycle_time
Worked numbers
// Example values
branch_freq = 0.20    // 20% of instructions are branches
mispredict = 0.05     // 5% misprediction rate
penalty = 19          // cycles lost on mispredict for 20-stage pipeline
CPI_mispredict = 0.20 * 0.05 * 19 = 0.19 cycles
// If cycle_time = 0.263 ns (3.8 GHz)
extra_time_ns = 0.19 * 0.263 ≈ 0.05 ns per instruction
Common pitfalls: forget to convert cycles to seconds, or use total stages instead of correct penalty count.
