Module 4 › Chapter 4.1 › Pipeline Depth Trade-off
Why deeper pipelines?
Splitting work into more stages can shorten each stage's logic, permitting a shorter clock cycle and higher frequency.
Downside: branch penalty
A mispredicted branch requires flushing more stages, wasting more cycles in deeper pipelines.
Design complexity
Hazard detection and forwarding logic become more elaborate as depth increases.
Workload impacts
Choose depth based on expected code: branch-light scientific kernels tolerate deeper pipelines; branch-heavy control code benefits from shallower designs with better branch handling.
