Module 4 › Chapter 4.1 › What is pipelining?
Core definition

Pipelining divides instruction execution into discrete stages that operate in parallel on different instructions. Each stage does a simple, repeatable task and passes results forward via pipeline registers.

Analogy
Assembly line: workers repeat one step; finished items exit more frequently even though each item still needs all steps.
Misconception
Pipelining does not reduce single-instruction latency; it increases throughput by overlapping stages.
Key Takeaway

Overlap stages to complete more instructions per unit time; stage timing balance matters for throughput.
