Module 4 › Chapter 4.1 › 5-Stage Pipeline
Pipeline stages
IF
Fetch instruction and increment PC.
ID
Decode, read registers, compute branch target if needed.
EX
ALU operations and address calculation for loads/stores.
MEM
Access data memory for loads and stores.
WB
Write ALU or memory results back to the register file.
Stage variance
Some instructions do less work in MEM or WB, so stage durations must be balanced to avoid a slow bottleneck.
When stages idle
Stages that are not used by a particular instruction simply pass values through via pipeline registers.
Concrete example
ADD uses IF, ID, EX (ALU), and WB. A load uses IF, ID, EX (address calc), MEM (read), and WB (write data). A store writes in MEM and does not write back.
Key Takeaway

Identify which stages an instruction truly uses; unmapped stages simply forward their inputs through pipeline registers.
