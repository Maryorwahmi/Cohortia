Module 4 › Chapter 4.1 › Ideal Speedup
Why ideal ≈ N
If stages are equal and there are no stalls, the pipeline completes one instruction per cycle, giving throughput roughly equal to the number of stage partitions compared to a single long cycle.
Register overhead
Setup and clock-to-Q delays reduce the theoretical division of the single-cycle period.
Imbalance
A single slow stage fixes the clock; dividing work unevenly hurts the expected speedup.
Estimate real speedup
  1. Measure T_single.
  2. Measure T_pipe = slowest_stage + register_overhead.
  3. Compute ideal ratio = T_single / T_pipe, then subtract stall penalties for hazards.
Key Takeaway

Use measured stage delays and realistic stall estimates to predict practical speedup; ideal N× is only a starting point.
