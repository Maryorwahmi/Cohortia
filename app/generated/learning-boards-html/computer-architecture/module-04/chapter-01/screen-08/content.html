Module 4 › Chapter 4.1 › Clock Period Comparison
Equations
T_single = T_IF + T_ID + T_EX + T_MEM + T_WB
T_pipe = max(T_IF, T_ID, T_EX, T_MEM, T_WB) + register_overhead
Use these formulas to compute ideal speedup and understand why it deviates from the number of stages when stages are unbalanced or registers add delay.
Worked example
If T_single = 5 ns and T_pipe = 1.2 ns, ideal speedup = 5 / 1.2 = 4.17×. The missing factor from 5× is stage imbalance and register overhead.
Key Takeaway

Always measure the slowest pipelined stage and include register delay when estimating clock period and speedup.
