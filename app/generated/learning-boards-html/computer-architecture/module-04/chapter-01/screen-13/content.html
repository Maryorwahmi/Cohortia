Module 4 › Chapter 4.1 › Forwarding
How forwarding works
When a producing instruction's result is available before WB, hardware can route it from an intermediate pipeline register into the dependent instruction's ALU input, usually via multiplexers controlled by hazard logic.
Common source
EX/MEM or MEM/WB registers feed the EX stage of a following instruction as a forwarded operand.
Limitations
Load results that are only available after MEM may still force a one-cycle stall; forwarding cannot always remove this hiccup.
Example effect
In the example sequence, forwarding from the ADD's EX/MEM output to the next instruction's EX input often removes the need to wait for WB, saving cycles across multiple dependent instructions.
Key Takeaway

Forwarding recovers many stalls by delivering values earlier; design hazard logic to select forwarded sources and detect when stalls remain necessary.
