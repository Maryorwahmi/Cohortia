Module 4 › Chapter 4.1 › Pipeline Registers
Role and effects
Pipeline registers store intermediate values at the clock boundary so the next stage sees a stable snapshot. They shorten combinational paths and therefore influence the clock period, but they add register overhead that slightly increases the cycle time.
What they hold
Instruction bits, register operand values, ALU control signals, memory addresses, and destination register identifiers.
Timing impact
Registers add setup and clock-to-Q delays; these increase the minimum cycle time compared to an ideal zero-overhead split.
Illustration
IF → [IF/ID reg] → ID → [ID/EX reg] → EX → [EX/MEM reg] → MEM → [MEM/WB reg] → WB
Key Takeaway

Treat pipeline registers as explicit state elements; list their fields when designing a pipeline to avoid correctness bugs.
