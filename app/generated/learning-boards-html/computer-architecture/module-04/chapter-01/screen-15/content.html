Module 4 › Chapter 4.1 › Key Concepts
Pipelining as assembly line
Overlap instruction stages to increase completed instructions per unit time; latency per instruction remains the sum of stages.
Five-stage pipeline
IF, ID, EX, MEM, WB describe fetch through write back responsibilities used in many RISC designs.
Pipeline registers
Interstage latches capture transient outputs each cycle to present stable inputs to the next stage and partition timing.
Summary takeaway
Use the laundry analogy, timing diagrams, and forwarding logic to reason about expected speedup and the real-world limits caused by hazards, imbalance, and register overhead.
