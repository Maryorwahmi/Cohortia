Mechanism

Delay slot semantics

The instruction after a branch is executed unconditionally. If the compiler fills it with useful independent work, the branch penalty disappears.

BEQ R1, R2, label    # Branch if equal
ADD R3, R4, R5       # Delay slot: always executed
label: SUB R6, R7, R8
Advantages
  • No branch penalty when delay slot is useful.
  • Hardware remains simple because no flush is required for that cycle.
Disadvantages
  • Compiler must find safe instruction or insert NOPs, wasting cycles.
  • Exceptions and atomicity of branch+delay instruction are complicated.
Key Takeaway

Delayed branches remove hardware stalls but place heavy burden on the compiler; modern predictors replace them.
