Definition

Control hazard explained

When a branch is in flight, the processor may fetch instructions down the wrong path until the branch direction and target are known. The distance to resolution sets how many instructions might be wrong.

Quick example
If resolution is in EX, two following instructions might be fetched and need flushing when the branch is taken.
Common misconception
Branches do not always cost a single cycle; the penalty scales with resolution distance and pipeline depth.

Key Takeaway

Count the stages between fetch and resolution to bound the maximum number of flushed instructions.
