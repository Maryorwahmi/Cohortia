Hierarchy

Capacity and conflict behavior

BTB hit rate rises with capacity and associativity. A tiny BTB can be powerful for tight loops; a larger BTB benefits general code with many unique branch sites.

4-entry
Good for small repetitive branches in exercises and microbenchmarks.
512–4096
Typical practical sizes balancing hits and silicon cost.
Indexing detail
The index is taken from lower PC bits. The tag matches higher bits. Aliasing occurs if many branches map to the same index.
Key Takeaway

BTB sizing must reflect the working set of branch PCs; small, well-used BTBs can yield large benefits.
