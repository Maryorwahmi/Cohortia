Module 4 › Chapter 4.6 › 4-entry BTB
Process

Add a 4-entry BTB and observe hits

Track BTB state as you run the trace. Record when a branch PC maps to an entry and whether the entry's tag matches.

Measurement
Count BTB hits, misses, and mispredictions and show how many penalties were avoided by hits.
Example result
If a branch repeats often and the 4-entry BTB retains its entry, the trace will show many hits and near-zero penalty for those branches. If branches are unique, hits are rare and benefit is small.
Key Takeaway

Even a tiny BTB can greatly reduce penalty for repeated branch behavior; measure hits to justify design cost.
