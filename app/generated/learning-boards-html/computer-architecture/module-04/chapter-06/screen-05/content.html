Module 4 › Chapter 4.6 › Branch penalty by stage
Process

Count flushed instructions by resolution stage

ID resolution
Condition checked in decode; only IF contains a wrong instruction if taken. Penalty = 1 cycle.
EX resolution
Resolved during execute; IF and ID hold wrong instructions when taken. Penalty = 2 cycles.
MEM resolution
If branch depends on a load, resolution waits until MEM. Penalty = 3 cycles.
Example calculation
If your pipeline resolves branches in EX and has a 10-stage depth between IF and EX, multiply the number of stages between fetch and resolution to estimate cycles wasted per mispredicted branch. The simple model here assumes one instruction per stage; adjust for your pipeline's fetch/decode width and instruction throughput.
Key Takeaway

The number of flushed instructions equals the distance from fetch to the branch resolution stage.
