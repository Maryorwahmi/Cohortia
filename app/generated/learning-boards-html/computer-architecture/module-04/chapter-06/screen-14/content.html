Module 4 › Chapter 4.6 › Key Concepts
Resolution stage sets penalty
ID=1, EX=2, MEM=3 cycles without prediction.
Delayed branch trade-offs
Removes penalty if compiler fills the delay slot; otherwise NOPs waste cycles.
BTB reduces fetch latency
On a BTB hit with correct prediction, the target is fetched immediately and penalty is near zero.
Summary takeaway
Evaluate designs by combining CPI and clock period. Use BTBs and predictors for deep pipelines and rely on delayed branches only when compilers and code patterns make them effective.
