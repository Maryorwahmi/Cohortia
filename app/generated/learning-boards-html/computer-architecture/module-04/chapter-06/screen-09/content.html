Architecture

BTB organization and behavior

The BTB stores entries keyed by PC: an index from low bits, a tag from high bits, and data containing the branch target and a taken/not-taken hint. On a hit, the fetch unit gets the target immediately.

Index / Tag / Data
Index: lower PC bits. Tag: upper PC bits. Data: target address + prediction bit.
Size
BTBs commonly range from 512 to 4096 entries depending on the design's needs and silicon budget.
Behavior on a hit
Fetch can begin at the target immediately, eliminating the fetch-related penalty for correctly predicted taken branches.
Misconception check

A BTB hit does not guarantee correctness; direction prediction still matters and a wrong guess requires flushing.
