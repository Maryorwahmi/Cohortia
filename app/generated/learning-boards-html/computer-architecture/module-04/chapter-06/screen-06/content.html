Comparison

ID resolution vs EX resolution

ID resolution
Penalty: 1 cycle. Cost: extra logic in ID may increase clock period.
EX resolution
Penalty: 2 cycles. Cost: shorter ID stage and potentially faster clock.
Worked assessment
Given: ID increases clock from 1.0 ns to 1.3 ns. Branch frequency 20%, half taken. ID CPI impact = 0.10, EX CPI impact = 0.20. Execution times: ID = 1.10 × 1.3 = 1.43 ns, EX = 1.20 × 1.0 = 1.20 ns. EX wins here.
Key Takeaway

Always multiply CPI by clock period when comparing branch handling strategies.
