Assessment

Worked numeric example

ID: clock = 1.3 ns, branch CPI impact = 0.10 → CPI = 1.10 → time = 1.10 × 1.3 = 1.43 ns per instruction.

EX: clock = 1.0 ns, branch CPI impact = 0.20 → CPI = 1.20 → time = 1.20 × 1.0 = 1.20 ns per instruction.

Reflection
The shorter clock dominates here. If branch frequency or taken rate changes, rerun the math to see if the trade-off flips.
Misconception check

Reducing branch penalty is not always best if it slows the clock significantly; compute execution time to decide.
