Module 4 › Chapter 4.2 › IF Stage: fetch and forward
IF components
  • PC register holds the current instruction address.
  • Adder increments PC by 4 to compute PC+4 for the next sequential instruction.
  • Instruction memory returns the 32-bit instruction at the PC address.
  • Multiplexer selects between PC+4 and a branch target when control dictates.
  • IF/ID register stores instruction and PC+4 for the decode stage.
Example scenario
A BEQ fetch stores instruction and PC+4 in IF/ID. Decode computes branch decision and target; if branch taken, IF's PC multiplexer will choose the target instead of PC+4 on subsequent cycles.
Why store PC+4?

PC+4 becomes a reference for branch target calculation and for returning to the next instruction after jumps. Keeping PC+4 with the instruction means later stages can compute targets or perform write-back decisions without re-fetching context.

IF/ID: instruction, PC+4
PC mux: chooses PC+4 or branch target
Common Mistake

Assuming IF only needs the instruction. Without PC+4 carried forward, branch and jump calculations lack context and correctness fails.
