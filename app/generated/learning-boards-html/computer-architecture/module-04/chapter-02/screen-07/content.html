Module 4 › Chapter 4.2 › EX Stage: ALU operations and branch evaluation
EX responsibilities
  • Choose second ALU operand via ALUSrc (register or immediate).
  • Apply ALU operation specified by ALUOp to compute result.
  • Compute branch target as PC + sign-extended immediate.
  • Detect zero or condition flags for branch decisions.
Example
For an ADDI instruction, ALUSrc selects the immediate. ALUOp indicates addition. The ALU produces the result and EX/MEM carries it forward for possible memory access or write-back.
Visual: EX block
[ALU input A] — ALU — [ALU result]
ALUSrc and ALUOp control inputs; EX/MEM stores ALU result and control bits like MemRead or RegWrite that are still needed.
Misconception

ALUOp is not needed after EX. Storing it beyond EX increases register width unnecessarily.
