Module 4 › Chapter 4.2 › Hazard detection and control integration
What the hazard unit watches
  • Data hazards: load followed by a use before the load completes.
  • Control hazards: branches whose resolution invalidates fetched instructions.
  • Structural hazards: resource conflicts requiring stalls (less common in simple 5-stage pipelines).
Examples
Load-use: insert one stall so dependent instruction doesn’t read stale register. Branch taken: flush instructions fetched on the wrong path.
Control signals for hazards
Hazard unit produces stall and flush signals that freeze or clear pipeline registers so incorrect control bits do not drive later stages.
