Pipelined datapath at a glance

Split execution into IF, ID, EX, MEM and WB with registers between stages that hold both data and control bits.

IF
IF — instruction fetch
PC, instruction memory, adder for PC+4, IF/ID register.
ID
ID — decode and control generation
Register file read, sign-extend, control unit output stored in ID/EX.
EX
EX — ALU, branch target
ALU operation, operand selection, branch zero detection, EX/MEM register.
Key Takeaway

Pipeline registers carry both data and the control signals produced in ID so each downstream stage can act independently.

Visual: stage cards and pipeline registers
IF/ID
Holds fetched instruction and PC+4 to pass decode information to ID stage on the next cycle.
ID/EX
Carries register operands, sign-extended immediate, PC+4 and control signals like ALUSrc and ALUOp.
EX/MEM
Contains ALU result, destination register, and control bits needed by MEM and WB.
MEM/WB
Carries data read from memory or ALU result plus RegWrite and MemtoReg for write-back.
Example
When decoding a load, ID asserts MemRead and MemtoReg. Those bits ride in ID/EX and EX/MEM so that when the instruction reaches MEM, the data memory is accessed and later written back in WB.
