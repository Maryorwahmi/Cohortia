Module 4 › Chapter 4.2 › Pipelined control signals: propagation and storage
Control mapping
ID/EX holds: RegWrite, MemRead, MemWrite, ALUSrc, MemtoReg, Branch, ALUOp
EX/MEM holds: RegWrite, MemRead, MemWrite, MemtoReg
MEM/WB holds: RegWrite, MemtoReg
Example
A store sets MemWrite in ID. That bit is stored in ID/EX and carried to EX/MEM so MEM can perform the write when the instruction reaches MEM.
Visual: shrinking control payload
ID
Generates full control set
ID/EX
Carries all bits needed by EX, MEM and WB
EX/MEM
Drops ALUSrc and ALUOp, keeps bits for MEM/WB
Common Mistake

Carrying every control bit through all pipeline registers increases register width and power without changing correctness.
