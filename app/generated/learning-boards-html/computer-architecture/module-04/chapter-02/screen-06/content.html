Module 4 › Chapter 4.2 › ID Stage: register reads and control generation
ID responsibilities
  • Read two source registers from the register file (Rs1, Rs2).
  • Sign-extend immediate fields to 32 bits.
  • Generate control signals using the combinational control unit.
  • Pack operands, immediate, PC+4 and control bits into ID/EX.
Example
A load instruction sets MemRead and MemtoReg in ID. Those bits are stored in ID/EX and later used in MEM and WB to read memory and write the loaded value back to the register file.
Visual: control packaging
Control bits produced: RegWrite, MemRead, MemWrite, ALUSrc, MemtoReg, Branch, ALUOp
ID/EX stores: register operands, immediate, PC+4, and the control bits needed by EX, MEM and WB.
Pro tip

Always draw control bits next to the ID/EX register in your diagram so you remember they move with the instruction.
