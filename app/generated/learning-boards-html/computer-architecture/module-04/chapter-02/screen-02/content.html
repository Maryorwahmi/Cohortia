Learning Objectives

These four skills will guide your practice and the hands-on activity at the end of the chapter.

01
Design the 5-stage datapath

Place PC, instruction memory, register file, ALU and data memory and insert IF/ID, ID/EX, EX/MEM, MEM/WB registers so instructions flow each cycle.

VERIFIED COMPETENCY MILESTONE
02
Identify control signals per stage

List RegWrite, MemRead, MemWrite, ALUSrc, MemtoReg, Branch and ALUOp and map each to the stage that needs it.

VERIFIED COMPETENCY MILESTONE
03
Understand pipelined control propagation

Explain how control signals generated in ID are stored in ID/EX, EX/MEM and MEM/WB so later stages have the correct control bits.

VERIFIED COMPETENCY MILESTONE
04
Analyze differences from single-cycle control

Describe why pipelined control uses the same combinational logic but adds registers, stalls, and flushes to handle hazards.

VERIFIED COMPETENCY MILESTONE
