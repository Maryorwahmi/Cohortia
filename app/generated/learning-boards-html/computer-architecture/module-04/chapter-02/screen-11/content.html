Module 4 › Chapter 4.2 › Control signal reduction: drop unused bits
Rule of thumb

Keep a control bit only until the stage that needs it has acted. Removing bits afterward reduces register width and power without affecting functionality.

ALUSrc, ALUOp → used in EX only
MemRead, MemWrite → used in MEM
RegWrite, MemtoReg → used in WB
Example activity
On paper, draw ID/EX with all bits, then show EX/MEM with ALUSrc and ALUOp removed, and MEM/WB with only RegWrite and MemtoReg left.
Why this matters

Reducing register width saves silicon area and power, and simplifies timing. It is a local optimization that preserves behavior if applied after the last use of each bit.
