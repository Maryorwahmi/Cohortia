Module 4 › Chapter 4.2 › MEM & WB stages: memory access and write-back

MEM stage

Uses MemRead and MemWrite to interact with data memory; EX/MEM provides the ALU address and the value to store if needed.

MemRead asserted → memory returns data to be stored in MEM/WB.
MemWrite asserted → memory writes the provided value using the ALU-computed address.
Key Takeaway

Only RegWrite and MemtoReg need to remain until WB; other control bits can be dropped earlier to slim registers.

WB stage

WB chooses between ALU result and memory data based on MemtoReg, and uses RegWrite to enable writing into the register file.

MEM/WB: memory data, ALU result, RegWrite, MemtoReg
WB selects the correct source and performs the register file write when RegWrite=1
Example
For LW, MemRead and MemtoReg are set in ID, passed through ID/EX and EX/MEM, and used in MEM to read memory and in WB to select memory data for register write-back.
