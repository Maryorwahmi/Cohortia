Module 4 › Chapter 4.2 › Learning Objectives

Demonstrations you will produce

Draw the datapath

Label all components, show pipeline registers and annotate the data flowing between stages. This proves structural understanding.

Map control bits to stages

For each instruction type, list which control signals are asserted and where they are used downstream.

Annotate pipeline registers

Show which control signals are stored in ID/EX, EX/MEM and MEM/WB and which can be dropped earlier.

Explain hazard handling

Illustrate how hazard detection generates stall and flush signals to preserve correctness when dependencies or branches appear.
