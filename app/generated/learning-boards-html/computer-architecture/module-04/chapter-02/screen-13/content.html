Module 4 › Chapter 4.2 › Key Concepts
Pipelined datapath
Five stages with pipeline registers that let instructions overlap and increase throughput.
Pipelined control
Control bits generated in ID are stored in ID/EX, EX/MEM and MEM/WB so downstream stages get the correct flags.
Hazard detection
The hazard unit issues stalls or flushes when data or control dependencies would otherwise produce incorrect results.
Takeaway
Treat control as data that must be transferred with the instruction and pruned after its last use. This keeps pipeline registers efficient and behavior correct.
