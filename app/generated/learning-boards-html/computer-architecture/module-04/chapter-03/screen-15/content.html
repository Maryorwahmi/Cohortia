Module 4 › Chapter 4.3 › Key Concepts
Structural hazards
Resource conflicts solved by separation, pipelining, replication, or stall.
Data hazards
RAW handled by forwarding; WAW and WAR handled by register renaming; load-use needs one-cycle bubble.
Control hazards
Branch penalty is reduced by prediction and a BTB which supplies target addresses.
Summary takeaway
Spot the hazard type first, then apply the corresponding remedy: hardware for structural, forwarding/renaming for data, and prediction/BTB for control.
