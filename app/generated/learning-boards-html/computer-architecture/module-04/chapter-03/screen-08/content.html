Module 4 › Chapter 4.3 › Load-use hazard
Timing explanation

A load produces its data at the end of MEM. The following ALU instruction needs that data at the start of its EX stage. The mismatch requires a bubble.

Example sequence
LW R1, 0(R2)   # data available end of MEM
ADD R3, R1, R4   # needs R1 in EX immediately
Insert a one-cycle bubble between the LW and ADD so the ADD's EX receives the data via forwarding from MEM/WB or directly from MEM.
Compiler and hardware options
  • Compilers may fill the delay slot with an independent instruction to avoid the bubble.
  • Some microarchitectures support load-forwarding that can reduce the need for a stall, but typical 5-stage pipelines still need the bubble.
Common mistake

Assuming MEM/WB → EX forwarding fixes the immediate successor. It does not for load-use; the dependent instruction is already in EX when data arrives.
