Measuring the penalty

If a branch is resolved late, more wrong-path instructions are fetched and later flushed. Penalty equals number of speculative instructions that must be discarded when prediction fails.

Example: 5-stage pipeline
Branch resolved in ID → 1-cycle penalty. Branch resolved in EX → 2-cycle penalty.
Deep pipeline impact
Longer pipelines increase opportunities for wrong-path fetches and thus increase penalty when mispredicted.
Practical implication
Because mispredicted branches cause wasted work, designers invest in prediction accuracy and target availability. The best improvements combine high prediction accuracy with immediate access to the branch target.
Key Takeaway

Branch penalty directly affects CPI; reducing either misprediction rate or target-latency reduces wasted cycles.
