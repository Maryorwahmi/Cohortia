How forwarding works

Detect when a later instruction's source matches an earlier instruction's destination and route the earlier result directly to the ALU input using multiplexers.

Common forwarding paths
  • EX/MEM → EX for the next instruction.
  • MEM/WB → EX for the instruction after next.
  • MEM/WB → MEM for some load-use interactions.
Detection logic
Comparators check destination and source register IDs across pipeline registers and assert multiplexers when forwarding is required.
Key Takeaway

Forwarding removes most RAW stalls by supplying values earlier from pipeline registers to ALU inputs, preserving architecture order.

Concrete example
ADD R1, R2, R3    # result ready at end of EX
SUB R4, R1, R5    # needs R1 in EX of next instruction
Forward from EX/MEM into SUB's ALU input. No stall required. A common pitfall is forgetting to handle the case where the producer is a load; that is handled differently.
