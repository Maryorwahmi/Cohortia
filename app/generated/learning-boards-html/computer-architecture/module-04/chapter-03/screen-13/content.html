Module 4 › Chapter 4.3 › BTB architecture
BTB elements
  • Index: branch instruction address bits to find an entry.
  • Target: cached target address to start fetching from immediately.
  • Valid and tag bits: confirm entry matches the branch.
  • Optional direction bits: small prediction history or state per entry.
Entries are updated when branches commit and can be allocated for predicted-taken branches to speed future fetches. A BTB is much smaller than an instruction cache and optimized for low-latency lookup.
Integration with predictor
When a branch is fetched, consult the branch predictor for direction and the BTB for target. If predictor says taken and BTB has a target, begin speculative fetch from the target immediately.
Key Takeaway

BTBs reduce fetch latency by supplying target addresses early; prediction determines whether to use them.
