Module 4 › Chapter 4.3 › Forwarding detection
Rule summary
  1. If EX.src == EX_MEM.dest and EX_MEM.regWrite then forward EX_MEM.value.
  2. Else if EX.src == MEM_WB.dest and MEM_WB.regWrite then forward MEM_WB.value.
  3. Prioritize the freshest producer and avoid forwarding from loads in EX_MEM if the data is not yet available.
Implementation notes
Comparators are simple equality checks on register IDs; multiplexers select between register file data and forwarded values. Extra control bits indicate whether the pipeline stage's instruction will write the register so false forwards are avoided.
Pseudo detection snippet
# detection for source A
if EX_MEM.regWrite and EX_MEM.dest != 0 and EX_MEM.dest == EX.srcA:
  forwardA = EX_MEM.value
elif MEM_WB.regWrite and MEM_WB.dest != 0 and MEM_WB.dest == EX.srcA:
  forwardA = MEM_WB.value
else:
  forwardA = registerFile[EX.srcA]
This snippet prioritizes EX_MEM because it holds the most recent computed result; handle srcB analogously.
