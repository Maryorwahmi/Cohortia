Module 4 › Chapter 4.3 › Branch mitigations
Strategy comparison
Stall
Wait until branch resolves — simple but wastes cycles.
Delayed branch
Execute the next instruction regardless; compiler fills delay slot with useful work.
Branch Target Buffer (BTB)
Cache likely branch targets so fetching can begin immediately from the predicted address.
Branch prediction
Predict taken or not-taken. Combine with BTB to reduce penalty when prediction is correct.
Practical note
Early RISC used delayed branches effectively. Modern superscalar designs prefer prediction plus BTB because they support deeper pipelines and aggressive out-of-order execution.
Key Takeaway

Prediction plus a BTB gives both direction and target early, minimizing fetch-side penalties on correct predictions.
