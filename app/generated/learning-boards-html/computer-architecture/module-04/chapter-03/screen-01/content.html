Pipeline Hazards: Structural, Data, and Control

Understand why pipelines stall, how to detect RAW/WAW/WAR hazards, and the hardware techniques that reduce penalties.

In this lesson
Examples, timing diagrams, forwarding, and branch mitigation strategies with a short simulator activity.
Why it matters
Minimizing hazards increases throughput and reduces CPI, a core goal of modern CPU design.
Explore Key Topics
Structural Hazards
Resource conflicts like shared memory ports and how replication or pipelining fixes them.
Data Hazards
RAW, WAW, WAR and forwarding vs. stalls. See a load-use example that forces a bubble.
Control Hazards
Branch penalties, prediction strategies, and the value of a branch target buffer.

Visual concept: hazards as traffic

Structural = lane conflict
Two instructions need the same memory port. One must wait or hardware must be replicated.
Data = missing sign
A later instruction needs a value that an earlier instruction has not yet produced.
Control = missing signpost
A branch creates uncertainty about where to fetch next; speculation or stalls are needed.
