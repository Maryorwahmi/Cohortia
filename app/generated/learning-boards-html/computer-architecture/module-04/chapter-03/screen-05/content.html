Module 4 › Chapter 4.3 › Structural hazards
Problem scenario

A single memory port used for both instruction fetch and data access causes a conflict when IF and MEM stages coincide. That conflict is a structural hazard.

1. Separate resources
Use separate instruction and data caches so IF and MEM do not contend.
2. Pipeline the resource
Make multi-cycle units accept one new operation per cycle by internal pipelining.
3. Replicate
Add ports, banks, or extra ALUs to serve parallel requests.
4. Stall
Insert a bubble until the resource is free when cheaper options are unavailable.
Tradeoff example
For a small embedded core, adding a second memory port may be too expensive in area and power. A single-cycle stall may be acceptable. For high-performance cores, separate L1 caches or multiporting is preferred.
Check your understanding
  • Is adding another ALU always worth the area cost? Consider expected instruction mix and contention rate.
  • Would pipelining a long-latency unit increase complexity in control? Yes, but it amortizes latency.
Key Takeaway

Choose the structural remedy based on performance need and hardware cost: separation and pipelining are low-friction; replication is costly but effective.
