Module 5 › Chapter 4.8 › State Saving
What to save
  • Program counter: PC of the excepting instruction for faults; next PC for traps when appropriate.
  • Processor status: Flags and mode bits so the handler can run in the correct context.
  • Other state: Any exception-specific registers the architecture requires for diagnosis.
Handler execution

The handler inspects saved state, corrects faults when possible, and prepares for an exception return that restores state and resumes execution.

Return

An exception return restores the saved PC and processor status so execution resumes exactly where it should after the fault is handled.
