Module 5 › Chapter 4.8 › Stages & Exceptions
Stages that detect exceptions
IF stage
Page fault or instruction-access violation while fetching the opcode.
ID stage
Illegal instruction encoding or privilege checks fail at decode.
EX stage
Arithmetic exceptions like overflow or divide-by-zero are detected here.
MEM stage
Data page faults, access violations, and misaligned accesses during memory operations.
WB stage
Typically no exceptions; writes are controlled before commit.
Design implications
  • Each stage must assert an exception flag that travels with the instruction's pipeline register.
  • Exception types determine which stage must be observed for relevant checks.
  • Flags enable prioritization and allow write-disable when necessary.
Key takeaway

Map exceptions to pipeline stages and carry flags forward; this enables program-order prioritization later.
