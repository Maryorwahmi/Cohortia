Module 5 › Chapter 4.8 › Key Concepts
Precise exception
Earlier instructions complete; later ones do not modify state; enables restartable execution.
Exception flags
Per-stage flags travel in pipeline registers and let control logic prioritize exceptions.
ROB for OoO
The reorder buffer buffers results and commits them in program order so exceptions remain precise in out-of-order designs.
Summary takeaway

Design exception logic to preserve program-order semantics: carry flags, prioritize by order, flush and disable writes, and use the ROB when executing out of order.
