Module 5 › Chapter 4.8 › Quick Reference
Stage map
IF: fetch faults; ID: illegal/privilege; EX: arithmetic; MEM: data faults.
Flags & propagation
Latch per-stage exception flags into pipeline registers so they travel with the instruction.
Flush & write-disable
Disable writes for following instructions and flush pipeline registers when handling an exception.
Final note

For out-of-order processors, the ROB is the principal tool to ensure precision; buffer results and commit in program order.
