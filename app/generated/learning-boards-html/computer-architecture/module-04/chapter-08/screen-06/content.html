Per-stage flags

When a stage detects an exception, it asserts a flag that is latched into the pipeline register between stages. That flag travels with the instruction until resolution.

Example
EX detects divide-by-zero and sets EX flag; the EX/MEM register carries the flag into MEM so the control can later decide to flush before state changes.
Misconception check
A flag does not immediately commit handling. It is an annotation used by later prioritization and commit logic.
Control decisions
  • Compare flags and program counters or use stage order to find the earliest excepting instruction.
  • Assert write-disable signals for any later instructions so they cannot update registers or memory.
  • When the excepting instruction reaches the stage that could alter state, assert a pipeline flush and transfer control to the handler.
Key takeaway

Flags tied to pipeline registers let prioritization and flush logic operate without ambiguity.
