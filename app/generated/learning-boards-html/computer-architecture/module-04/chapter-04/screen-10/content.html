Module 4 › Chapter 4.4 › Stall & Bubble Insertion
Stall sequence
Detect load-use, hold ID, prevent IF, insert NOP into EX for one cycle.
Detection condition
If the ID/EX stage is a memory read and its destination equals IF/ID source registers then Stall = 1 and insert bubble.
Pipeline control
Gate the program counter update, hold ID/EX input latches, and write NOP control signals into EX stage for one cycle to create the bubble.
Cycle-by-cycle illustration
Cycle N: load in ID/EX (MemRead asserted). Cycle N+1: Stall asserted, bubble in EX, dependent instruction remains in ID. Cycle N+2: dependent enters EX with data available.
Verification tip
Step through a load-use test and inspect that the bubble occupies EX exactly one cycle and that control signals during the bubble are NOPs.
