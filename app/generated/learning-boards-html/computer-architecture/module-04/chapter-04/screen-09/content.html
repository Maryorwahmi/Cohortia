Module 4 › Chapter 4.4 › Load-use Hazard
Why forwarding can't fix load-use
A timing mismatch between memory and EX stage forces a stall.
Concrete example
LW R1,0(R2) followed immediately by ADD R3,R1,R4. The load's data arrives only at end of MEM; ADD needs it at start of EX, so a stall is required.
Hazard detection
When the ID/EX stage indicates a memory read and its destination equals the next instruction's source, assert Stall, hold ID, prevent fetching, and insert a bubble into EX.
Common mitigation
Compilers can insert an independent instruction between load and use; out-of-order execution or value prediction can also reduce frequency of stalls, but not remove the fundamental timing constraint in an in-order pipeline.
Sequence to simulate
LW R1,0(R2)
ADD R3,R1,R4
Key takeaway
Forwarding is powerful but cannot supply memory data earlier than MEM stage completion; load-use requires a single-cycle stall.
