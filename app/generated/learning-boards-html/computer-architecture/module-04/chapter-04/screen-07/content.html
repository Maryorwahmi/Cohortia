Module 4 › Chapter 4.4 › ForwardA / ForwardB Logic
Comparator rules
Priority to EX/MEM, then MEM/WB; ignore register zero.
Behavior
Check EX/MEM first. If it matches and writes a nonzero destination, forward from EX/MEM. Else, if MEM/WB matches and writes, forward from MEM/WB. Else use register file.
Subtle checks
Always require the write-enable signal and that the destination register is not zero to avoid false matches and incorrect forwarding.
Pseudocode (visual)
ForwardA =
  if (EX/MEM.RegWrite and EX/MEM.Rd != 0 and EX/MEM.Rd == ID/EX.Rs1) then 01
  else if (MEM/WB.RegWrite and MEM/WB.Rd != 0 and MEM/WB.Rd == ID/EX.Rs1) then 10
  else 00

ForwardB =
  if (EX/MEM.RegWrite and EX/MEM.Rd != 0 and EX/MEM.Rd == ID/EX.Rs2) then 01
  else if (MEM/WB.RegWrite and MEM/WB.Rd != 0 and MEM/WB.Rd == ID/EX.Rs2) then 10
  else 00
Test idea
Run a sequence where two previous instructions write the same register to confirm EX/MEM forwarding wins over MEM/WB.
