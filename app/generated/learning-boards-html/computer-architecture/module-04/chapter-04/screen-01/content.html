Forwarding (Bypassing)
Use results before they reach the register file to avoid RAW stalls
Interactive 16:9 Masterclass
Why it matters
Reduces stall cycles and improves CPI for typical workloads.
Where it acts
At ALU inputs via multiplexers selecting EX/MEM or MEM/WB data.
Key exception
Load-use hazards still require a one-cycle stall.
In this lesson
You will design forwarding selects, write hazard detection conditions, and reason about performance trade-offs.
Explore key topics
Three compact previews below prepare you to build the unit and measure its impact.
Forwarding Paths
EX/MEM→EX, MEM/WB→EX, MEM/WB→MEM
Hazard Logic
Comparators produce select signals for ALU multiplexers.
Load-Use Stall
A load followed by a use requires a single cycle bubble.
Visual concept
Express highways bypass the register file. The hazard control center watches registers and sets multiplexer selects.
Express: EX/MEM → EX
For the immediately preceding instruction.
Fallback: MEM/WB → EX
When the result is from two cycles earlier.
Store case: MEM/WB → MEM
Forwarding data into the memory write input for a store.
Reflection
As you proceed, watch for where forwarding cannot help. That limitation defines compiler and microarchitectural techniques that follow.
