Module 4 › Chapter 4.4 › Forwarding Paths
Three forwarding paths
Step-by-step conditions and use cases
1. EX/MEM → EX (Forward A)
When the instruction in EX/MEM will write a register and that destination matches the EX instruction's source, forward the ALU result into EX ALU input.
2. MEM/WB → EX (Forward B)
When the instruction in MEM/WB will write a register and its destination matches the EX source, forward the value from MEM/WB into EX ALU input.
3. MEM/WB → MEM (Forward C)
For a store instruction needing a value that was just loaded, forward MEM/WB data into the memory write-data input during MEM.
Misconception check
MEM/WB cannot always resolve use by the immediately following instruction because timing may be too late for EX.
Visual summary
Three compact cards below show direction and typical source data.

MEM/WB → MEM
Source: MEM/WB. Destination: memory write-data for a store instruction in MEM stage.
Key takeaway
These three paths cover most RAW dependencies in a five-stage pipeline; implement them with multiplexers and comparator-based selects.
