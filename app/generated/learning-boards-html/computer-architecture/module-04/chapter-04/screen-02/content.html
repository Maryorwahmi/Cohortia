Learning Objectives
Four targeted competencies to implement and evaluate forwarding
Learn → Understand → Apply → Master
01
Implement forwarding paths
Wire multiplexers to ALU inputs so results in pipeline registers can be selected. This reduces many RAW stalls and is essential for a correct five-stage datapath.
VERIFIED COMPETENCY MILESTONE
02
Design hazard detection logic
Compare destination and source register fields across pipeline registers to generate forward selects, applying priority rules when both match.
VERIFIED COMPETENCY MILESTONE
03
Recognize forwarding limits
Detect load-use hazards that require a one-cycle stall because loaded data is only ready at the end of the MEM stage.
VERIFIED COMPETENCY MILESTONE
04
Analyze CPI impact
Compute how forwarding reduces average stalls and how load-use pairs still add cycles to CPI for real workloads.
VERIFIED COMPETENCY MILESTONE
