ALU input selection
Each ALU operand chooses among three sources using two select bits.
Select encoding
00 = register file, 01 = EX/MEM, 10 = MEM/WB. EX/MEM takes priority when both could match.
Comparator inputs
Compare destination register fields in EX/MEM and MEM/WB with the EX stage source fields, and ensure RegWrite is asserted and Rd is not zero.
Practical note
Keep forwarding decisions local to the EX stage; only the hazard unit needs visibility into pipeline register fields to drive selects.
Illustration
A compact diagram: ALU input multiplexer accepts RegFile, EX/MEM data, MEM/WB data. Hazard unit supplies select bits for each input.
Key takeaway
Design simple two-bit selects per ALU input and centralize comparator logic in the hazard unit for clarity and priority enforcement.
