Module 4 › Chapter 4.4 › What is Forwarding?
Forwarding explained
Route results directly to where they are needed to avoid waiting for writeback.
Definition
Select ALU or memory output from a pipeline register instead of the register file when a source register matches a recently written destination.
Concrete example
ADD writes R1, immediately followed by SUB that reads R1. Forward the ADD's ALU result into the SUB's ALU input so the SUB does not stall.
Common misconception
Forwarding does not remove load-use hazards because load data is only ready at the end of the memory stage, too late for the dependent instruction in EX.
Key takeaway
Forwarding is the express lane that greatly reduces RAW stalls, but it is not universal — loads still force stalls.
Analogy
Think of the register file as a busy toll bridge. Forwarding is a dedicated highway exit that lets a recent result bypass the toll and arrive sooner.
