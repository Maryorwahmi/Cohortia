Simulate and label forwards
Trace forwarding for each dependent instruction in the sequence below.
Instruction sequence
ADD R1, R2, R3
SUB R4, R1, R5
AND R6, R1, R7
OR  R8, R4, R9
LW  R10, 0(R1)
ADD R11, R10, R12
Walkthrough tips
  • Identify the producer of each source register and its pipeline stage when the consumer needs it.
  • Assign Forward A when the producer is in EX/MEM and producer.Rd matches consumer source.
  • Assign Forward B when the producer is in MEM/WB and EX/MEM did not match.
  • Mark MEM/WB→MEM for stores that need a recently loaded value.
Key deliverable
Produce a cycle-by-cycle table showing the forwarding path used for each dependency and total cycles with and without forwarding.
Expected highlights
SUB uses EX/MEM→EX. AND may use EX/MEM or MEM/WB depending on timing. The load followed by ADD requires a one-cycle stall.
Reflection
This trace practice helps you confirm forwarding selects and understand the residual cost of memory dependencies.
