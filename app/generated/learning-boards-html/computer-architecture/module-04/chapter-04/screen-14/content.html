Key Concepts
Three compact cards capture the essentials.
Forwarding paths
EX/MEM→EX, MEM/WB→EX, MEM/WB→MEM.
ALU multiplexers
Choose regfile, EX/MEM, or MEM/WB for each ALU input using hazard selects.
Hazard logic
Comparators set ForwardA/ForwardB; EX/MEM comparisons take priority over MEM/WB.
Summary takeaway

Forwarding is the most effective technique to remove RAW stalls in an in-order pipeline, but load-use hazards still need explicit stall logic and a bubble insertion strategy.
