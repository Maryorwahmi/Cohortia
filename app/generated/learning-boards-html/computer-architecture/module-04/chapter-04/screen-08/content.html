Module 4 › Chapter 4.4 › Priority: EX/MEM over MEM/WB
Priority explained
Recent writes must be observed first to preserve program order.
Example sequence
ADD writes R1; SUB writes R1; AND reads R1. AND must use SUB's result, which is in EX/MEM, not ADD's result in MEM/WB.
Wrong implementation
Choosing MEM/WB blindly when both match returns a stale value and breaks correctness. Always check EX/MEM first.
Verification tip
Simulate a case with two writers to one register and inspect which pipeline register supplies the forwarded value to the dependent instruction.
Test scenario
Use the sequence: ADD R1,R2,R3; SUB R1,R4,R5; AND R6,R1,R7. Confirm AND receives SUB's result via EX/MEM forwarding and not ADD's via MEM/WB.
Key takeaway
Priority is a correctness requirement: newer writes supersede older ones when forwarding decisions overlap.
