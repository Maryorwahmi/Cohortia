Sequences
Draw RAW edges and find the critical path for each sequence; then compute the theoretical max IPC for infinite issue width.
Sequence A — Independent
ADD R1, R2, R3
ADD R4, R5, R6
ADD R7, R8, R9
ADD R10, R11, R12
Max IPC = 4 (no RAW edges).
Sequence B — Dependent chain
ADD R1, R2, R3
MUL R4, R1, R5
ADD R6, R4, R7
MUL R8, R6, R9
Each instruction depends on the previous result. Max IPC = 1 (critical chain).
Sequence C — Loop body with memory
LW R1, 0(R2)
ADD R3, R1, R4
SW R3, 0(R2)
ADDI R2, R2, 4
Pointer increment ties the load address to the pointer; RAW chains plus memory latency typically limit ILP to about 1 in this kernel.
Analysis cards
How to draw the graph
Create nodes per instruction and draw an edge for each RAW use from producer to consumer. Longest path length determines bound.
Example takeaway
Sequence A can saturate a 4-way issue; B and C cannot, so adding issue slots yields little benefit.
Check your thinking
If loads in Sequence C hit L1 cache and have low latency, IPC may rise slightly; if they miss, ILP collapses further.
Key Takeaway

Always combine dependency graph analysis with memory and branch behavior to estimate realistic IPC.
