Module 5 › Chapter 5.6 › What is ILP?
Instruction-Level Parallelism
Potential overlap among instructions in a single thread.
Short definition
ILP is the portion of a program where multiple instructions can be issued without violating dependencies.
Why it matters
ILP sets the ceiling for single-thread performance on wide-issue cores and affects area and power trade-offs.
Key Takeaway

Independent instructions define ILP; true dependencies and branches limit how many can run together.

Concrete example
ADD R1, R2, R3     # independent add
ADD R4, R5, R6     # independent add
These two adds produce no RAW dependency and could issue together if the core has two issue slots and resources.
Misconception
Wider issue width always increases IPC. Not true when ILP is absent.
Pro tip
Distinguish name dependencies that renaming solves from true data hazards that cannot be removed.
