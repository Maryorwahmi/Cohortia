Module 5 › Chapter 5.6 › Memory & ILP
Memory latency reduces ILP
Loads that miss caches lengthen producers' latency and constrain dependent consumers.
Pointer chasing
Each load computes the next address, creating a serial dependence chain.
Memory-level parallelism
The ability to have multiple outstanding misses helps mitigate latency but is limited.
Common misunderstanding

Assuming all loads are short-latency. Cache misses amplify critical paths and cut IPC dramatically.

Concrete contrast
Array scans with independent addresses can show much higher ILP because multiple loads are independent and the core can issue many outstanding requests. Pointer-chasing loops cannot, because each load's address depends on the prior load's result.
Key Takeaway

Consider cache behavior and address dependencies when predicting IPC for memory-bound code.
