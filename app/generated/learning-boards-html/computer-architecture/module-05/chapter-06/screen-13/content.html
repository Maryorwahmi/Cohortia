From ILP limits to architecture choices
When single-thread ILP is scarce, other forms of parallelism deliver better returns.
Multicore
Run multiple threads in parallel to increase throughput across workloads.
SMT
Share core resources among threads to improve utilization when ILP is low.
SIMD / GPUs
Exploit data parallelism where the same operation repeats across many data elements.
Accelerators
Specialized hardware for common high-cost tasks that general cores cannot accelerate efficiently.
Key Takeaway

Invest silicon where it yields the largest throughput gains given typical workload ILP and power constraints.
