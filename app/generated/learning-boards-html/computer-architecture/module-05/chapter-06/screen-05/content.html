True Data Dependencies (RAW)
Read-after-write chains define the critical path.
Core claim
If instruction X produces a value used by Y, Y must wait for X to complete that value.
Common error
Assuming forwarding or OOO always removes stalls. They reduce latency but do not remove the ordering constraint.
Key Takeaway

Chains of RAW dependencies form the critical path and cap IPC regardless of issue width.

Dependent chain example
ADD R1, R2, R3     # Cycle 1
ADD R4, R1, R5     # depends on R1
ADD R6, R4, R7     # depends on R4
ADD R8, R6, R9     # depends on R6
This sequence's longest dependent chain forces a maximum IPC of 1 — each instruction depends on the earlier result.
Example insight
Even infinite issue width cannot overcome a length-n dependency chain; the critical path sets the bound.
