Module 5 › Chapter 5.6 › Key Concepts
ILP
Potential overlap among independent instructions in a single thread; the basis for single-thread throughput.
Dependency types
RAW are fundamental; WAR and WAW are name hazards removable by renaming; control dependencies require prediction and speculation.
Instruction window
Larger windows expose more ILP but with significant hardware and power cost and diminishing returns beyond practical sizes.
Final takeaway

ILP is useful but limited by program structure; architecture choices should reflect realistic ILP and workload behavior.
