Critical Path and IPC
Longest dependent chain bounds the achievable IPC.
Computation steps
  1. Draw dependency graph.
  2. Identify longest RAW chain and include instruction latencies.
  3. Maximum IPC = instructions on independent paths per cycle, bounded by longest chain.
Key Takeaway

Always find the longest dependent chain including latencies to compute theoretical IPC.

Two contrasting sequences
# Dependent chain (max IPC = 1)
ADD R1, R2, R3
ADD R4, R1, R5
ADD R6, R4, R7
ADD R8, R6, R9

# Independent (max IPC = 4 if 4-way issue available)
ADD R1, R2, R3
ADD R4, R5, R6
ADD R7, R8, R9
ADD R10, R11, R12
The dependent chain's critical path enforces serialization; the independent sequence enables full utilization up to the issue width.
Misconception
Treating each instruction as one cycle without considering producer latency can undercount the true critical path.
Check
After drawing the graph, highlight the longest path and sum latencies — that sum sets the bound.
