Definition › Fetch Unit Components

The parts that make fetch possible

BP
Branch Predictor & BTB
Predict next PC and branch target so fetch can continue speculatively; reduces stalls from control flow.
L1I
Instruction Cache (L1I)
Supplies instruction bytes using predicted PC; often separate from data cache to avoid hazards.
PD
Predecoder
Decides instruction boundaries in parallel for variable-length ISAs so multi-instruction fetches are possible.
IQ
Instruction Queue / Buffer
A FIFO that decouples fetch and decode, smoothing bursts and enabling fetch to run ahead.
LW
Line & Way Prediction
Guesses which cache line and way will respond to the fetch to reduce access latency for set-associative caches.
Supporting explanation
  • Predecoding in parallel lets the fetch unit propose multiple instruction start points then discard wrong guesses.
  • BTB supplies immediate branch target addresses to avoid waiting for decode results.
  • The instruction queue is sized to absorb transient stalls; typical sizes are tens of entries to hide cache misses and redirects.
Example card
When decode stalls for 10 cycles due to a microarchitectural hazard, a filled instruction queue lets the decode unit continue issuing without waiting for fetch to resume.
