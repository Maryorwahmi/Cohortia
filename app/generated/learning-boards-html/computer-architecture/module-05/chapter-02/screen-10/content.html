Why fetch must match or exceed issue

Fetch-side constraints
  • Branches and mispredictions create wasted cycles and redirects.
  • Cache misses can pause fetch for several cycles.
  • Predecode and μop caching create bursts of high throughput.
Issue-side needs
  • Issue units need a steady supply to keep functional units busy.
  • If fetch average < issue peak, execution units will be underutilized.
  • Instruction queue lets issue tolerate brief fetch shortfalls without stalling.
Key Takeaway

Design for slightly higher fetch capacity than issue and add buffers to tolerate transient disruptions.
