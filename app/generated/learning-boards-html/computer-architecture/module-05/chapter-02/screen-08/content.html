Branch Target Buffer and Return Address Stack

What the BTB does
BTB entries map branch PCs to predicted target PCs so the fetch unit can request the target address without waiting for decode. This reduces the delay on taken branches and keeps the fetch stream moving.
RAS for returns:
Return addresses pushed at call time and popped at return time give highly accurate predictions for function returns, a common control pattern.
Supporting bullets
  • Branch predictor decides taken/not-taken; BTB gives the target for taken ones.
  • A BTB miss means even a taken prediction must wait to compute the target, adding cycles.
  • RAS accuracy is usually high for well-formed call/return sequences, reducing return redirects.
Key Takeaway

Predicting both that a branch will be taken and where it goes are separate tasks; both need to be fast to preserve fetch bandwidth.
