What to remember

Fetch Unit Components
Branch predictor, L1I, predecoder and instruction queue each solve a different fetch bottleneck.
Branches & Bandwidth
Taken branches and mispredictions reduce effective fetch throughput; redirect cost matters even when prediction is correct.
Buffers & Bypass
Instruction queues, loop detectors, and μop caches smooth delivery and reduce decode work for hot streams.
Takeaway strip
Design the fetch side for headroom and resilience: size buffers to cover typical stalls, improve predictors where misprediction cost is highest, and use bypasses to make hot code cheap to fetch.
