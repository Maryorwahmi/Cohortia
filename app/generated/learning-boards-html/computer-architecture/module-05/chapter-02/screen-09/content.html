Core Concept › Loop Stream & μop Cache

Saving work on repeated instruction sequences

Loop Stream Detector
Detects tiny loops and serves instructions from a small buffer for subsequent iterations, avoiding repeated cache lookups.
Example
A tight loop of 8 instructions can be stored and replayed from the detector so the fetch path never touches L1I during steady-state iterations.
μop Cache
Stores decoded micro-operations so future fetches can bypass the decode stage and deliver μops straight to the pipeline, saving time and energy.
Key Takeaway

When code repeats, bypassing work yields both faster fetch delivery and lower power by avoiding decode and cache accesses.
