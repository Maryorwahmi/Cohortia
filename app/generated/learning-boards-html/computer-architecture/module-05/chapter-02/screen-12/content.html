Architecture › Fetch Unit Design

Blocks and handling key cases

Essential blocks
  • PC + Adder: computes sequential next PCs.
  • Branch Predictor & BTB: supply next target and decide taken/not-taken.
  • L1I + Line/Way predictor: deliver bytes with low latency.
  • Predecoder: find instruction boundaries for variable-length ISAs.
  • Instruction Queue: buffer decoded-start entries for decode to consume.
Case notes
Sequential: With fixed 4-byte instructions and 64-byte lines, one read can hold 16 instructions. The fetcher forms a 4-instruction packet each cycle.
Taken branch (unaligned): BTB supplies target; alignment logic and possibly a second line read reconstruct the contiguous stream before predecode.
Cache miss: Fetch stalls on L1I; the instruction queue supplies entries to keep decode working until fill completes or the queue empties.
Key Takeaway

A robust fetch design uses predictors, alignment logic and a queue to hide the common disruptions of real code and maintain steady instruction delivery.
