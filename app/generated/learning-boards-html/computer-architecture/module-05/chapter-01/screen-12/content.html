Module 5 › Chapter 5.1 › Key Concepts
Superscalar
Multiple instructions per cycle enabled by widened fetch/decode and parallel units.
Issue width & units
Issue width must be matched by functional units and register file ports to be effective.
In‑order vs OoO
In‑order is simpler and lower power; OoO uses reservation stations and ROB to exploit ILP.
Summary
Balance issue width with unit counts, port budgets, and window size; measure ILP and memory behavior to predict achievable IPC.
