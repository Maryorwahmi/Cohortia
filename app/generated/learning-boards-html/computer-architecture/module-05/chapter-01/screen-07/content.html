Architecture
Window → Reservation → ROB
Instruction window
Holds decoded instructions that are waiting to be issued or retired.
A larger window finds more ILP but increases power and hardware for wakeup and select logic.
Reservation stations
Hold operands or tags until the instruction is ready. When all operands are present, the reservation station forwards the instruction to a functional unit.
Reorder buffer (ROB)
Tracks instruction program order, stores results, and commits them in sequence to maintain precise exceptions.
The ROB also supports recovery on misprediction: results are only made visible after retirement, so a mispredicted path can be flushed without altering architectural state.
Analogy: reservation stations are waiting areas; the ROB is the finish line where cars must cross in start order.
Misconception: ROB = reservation station. They are distinct: ROB enforces commit order; reservation stations track readiness.
