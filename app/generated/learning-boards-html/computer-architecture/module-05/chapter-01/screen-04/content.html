Core Concept
Definition
Superscalar pipelines
Fetch, decode, and issue parallel instruction lanes to increase IPC.
Lane metaphor
Imagine a four‑lane road: each lane carries one instruction per cycle to a functional unit. Traffic controllers check for collisions (dependencies).
Misconception
Advertised issue width is an upper bound. Real IPC depends on independence among instructions and resource availability.
Concrete example
If four instructions are fetched but two form a RAW pair, the issue logic must stall one or avoid issuing both to conflicting units, reducing IPC below four.
Key Takeaway

Superscalar hardware increases potential throughput, but dependency checks and unit availability determine actual performance.

Annotated visual — multi-lane highway
The lanes represent parallel issue slots; the controller must check for collisions before letting cars proceed.
