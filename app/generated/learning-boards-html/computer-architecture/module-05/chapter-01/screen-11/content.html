Factors that reduce IPC
Finite ILP in program
Combinatorial dependency checks (critical path)
Structural hazards: insufficient units or ports
Control hazards and cache misses
Measure dependency distance, port utilization, and cache miss rates to estimate realistic IPC for a candidate issue width.
Concrete number intuition
A 4‑way core often sustains IPC around 2–3 for many workloads because of the combined effects listed above. Adding more lanes without solving the limiting factors yields diminishing returns.
Common mistake
Assuming maximum IPC equals issue width without analyzing workload characteristics.
