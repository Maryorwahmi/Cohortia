Simplified timing table (conceptual)
Cycle 1
Issue: ADD (slot A), SUB cannot issue because it reads R1 produced by ADD (RAW). Slot B idle or filled with a later independent instruction if available.
Cycle 2+
ADD moves through pipeline stages; SUB can issue once operand is forwarded and unit available. LW may introduce long latency, blocking later in‑order instructions.
Takeaway
Count empty slots to compute effective IPC. In many realistic sequences, the average IPC falls well below 2 even on a 2‑way core.
