Common functional units
  • Integer ALUs (2–4)
  • Floating‑point ALUs (2–4)
  • Load/Store units (2–3)
  • Branch units (1–2)
  • Multiplier/Divider (1–2)
Instruction mix impact
Scientific workloads: higher FP demand. Server workloads: many integer and memory ops. Mobile: prioritize power and simple in‑order pipelines.
Design rule: provision units and register ports to match expected parallelism; otherwise lanes go unused.
Concrete scenario
A 4‑way core with two ALUs and one load unit cannot execute four independent memory ops simultaneously; it is constrained by the single load unit.
Key Takeaway

Issue width only matters if functional units, register ports, and memory subsystem are balanced to sustain parallel execution.
