What to Remember

Dataflow model
Instructions execute when their operands are ready.
Reservation stations
Hold operations, values, or producer tags until execution.
Common Data Bus
Broadcasts results and tags so every waiting consumer can capture values simultaneously.
Summary takeaway
These mechanisms combine to implement a runtime dataflow graph on a von Neumann core, enabling out-of-order execution while preserving correctness.
