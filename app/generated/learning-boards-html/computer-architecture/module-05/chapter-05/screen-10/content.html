Module 5 › Chapter 5.5 › Register Renaming
Definition

Register tags and renaming

Replace architectural destinations with unique tags that point to the producing RS. This prevents write and read hazards among writers to the same architectural name.

Concrete sequence
ADD R1, R2, R3     # I1 -> R1 tagged RS1
SUB R4, R1, R5     # I2 reads R1 from RS1
MUL R1, R6, R7     # I3 -> R1 tagged RS2
DIV R8, R1, R9     # I4 reads R1 from RS2
Why this removes hazards
WAW and WAR depend on a shared architectural name. If each write gets a unique tag, writes no longer conflict and reads refer to the correct producer. The register file stores tags to indicate which RS will produce the current logical value.
Key Takeaway

Renaming decouples logical registers from physical producers via tags, removing many ordering hazards and enabling out-of-order progress.
