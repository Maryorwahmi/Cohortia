Module 5 › Chapter 5.5 › Dataflow Model
Definition

Dataflow execution

Instructions fire as soon as their operands are present. Dependencies, not program position, determine readiness.

Concrete example
Two independent adds can both execute when their inputs are ready, even if a multi-cycle multiply sits between them in the instruction stream.
Misconception check
Dataflow in hardware schedules instructions by values available, not by changing language semantics or rewriting code.
Practice task
Sketch a dependency graph for this sequence: load A, add B,C, mul D,E, store F. Label nodes and indicate which can fire concurrently. Use tags to show which producer each consumer waits for.
Why it matters
Making dependencies explicit is the first step to letting hardware schedule independent work earlier and recover cycles otherwise lost to stalls.
