What to Remember

Register renaming
Tags map logical registers to dynamic producers, removing name-based hazards.
Practical limits
Window size, CDB bandwidth, and physical registers set practical bounds on performance gains.
Reorder buffer
Holds completed results until they commit in program order to provide precise exceptions.
Takeaway
Tomasulo's ideas let hardware schedule by data readiness while renaming and ROBs preserve correctness; they remain central to modern high-performance processors.
