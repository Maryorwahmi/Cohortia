Learning Objectives

Skills you'll build and why they matter for performance and correctness.

Bloom: Learn → Understand → Apply → Master
01
Explain the dataflow model
You will describe how instructions become nodes in a dataflow graph and fire when inputs are ready, exposing ILP for execution units.
VERIFIED COMPETENCY MILESTONE
02
Implement Tomasulo's algorithm
You will be able to place instructions into reservation stations, track tags, and simulate CDB broadcasts in a small processor model.
VERIFIED COMPETENCY MILESTONE
03
Understand register renaming
You will explain how tags replace architectural registers to remove WAW and WAR hazards and why additional physical registers are required.
VERIFIED COMPETENCY MILESTONE
04
Analyze dynamic scheduling limits
You will evaluate how reservation station counts, memory disambiguation, and exception handling constrain ILP and hardware cost.
VERIFIED COMPETENCY MILESTONE
