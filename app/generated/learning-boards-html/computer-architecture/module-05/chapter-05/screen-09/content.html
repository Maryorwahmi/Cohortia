Process Flow

Broadcasting results

When a functional unit finishes, it puts the value and its RS tag on the CDB. All listeners capture matching tags and update their state.

- Producer writes value and tag to the CDB.
- All RS entries and the register file snoop and capture if tag matches.
- Producer's RS is freed after broadcast; register updated if still waiting for that tag.
Example
RS3 broadcasts a multiply result V with tag RS3. Any RS waiting on RS3 captures V. If the architectural register mapped to RS3 still expects that tag, it receives V too.
Design cost
The broadcast nature of the CDB simplifies dynamic discovery of consumers but creates scaling and bandwidth costs. The number of listeners and frequency of broadcasts are practical limits.
Misconception check

The CDB only carries values and tags. It does not route addresses or control signals; it is a broadcast result channel for completed instructions.
