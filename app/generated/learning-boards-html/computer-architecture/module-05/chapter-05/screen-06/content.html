Architecture

Reservation Stations, CDB, and Register Tags

These structures together implement a runtime dataflow graph that supports safe out-of-order execution.

Reservation Stations
Buffer instructions per functional unit and record values or tags of awaited operands.
Common Data Bus
Broadcast completed results with producing tag so all consumers can capture values simultaneously.
Register Tags
Map architectural registers to the reservation station that will produce the next value, enabling renaming.
Interaction
On issue, an RS records tags or values. On completion, the producer broadcasts on the CDB and RS entries and the register file snoop and capture matching tags.
Analogy
Think of RS as waiting rooms with tickets, the CDB as a loudspeaker announcement, and register tags as name badges that tell who will arrive with the value.
Key Takeaway

These three structures coordinate to let producers publish values while consumers wait safely using tags.
