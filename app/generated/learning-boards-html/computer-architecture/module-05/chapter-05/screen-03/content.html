Skill Breakdown

Concrete tasks that show you can apply each learning objective.

Dataflow sketches
Draw a small graph for a 5-instruction sequence and mark when each node fires. Mnemonic: pipes and valves — values flow when sources are open.
Tomasulo simulation
Step through issue, execute, and write back on RS tables for two functional units. Mnemonic: waiting rooms with name tags.
Renaming mappings
Rewrite examples to show distinct tags for each write to the same architectural register. Mnemonic: unique ID badges stop conflicts.
Performance analysis
Compare cycles with and without dynamic scheduling and reason about memory speculation. Mnemonic: stopwatch comparisons for in-order vs dynamic runs.
