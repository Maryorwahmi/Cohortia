Instruction window

The number of RS entries bounds how many instructions can wait and be discovered as independent. Bigger windows find more ILP but increase area and power.

- Small window: limited ILP, fewer simultaneous tasks.
- Large window: more ILP, larger register file/rename map, higher power.
Memory disambiguation
Speculative loads may need address checks or rollback if a previous store targets the same address, which complicates correctness and increases hardware state.

Exceptions and ROB

Out-of-order completion makes precise exceptions difficult. A reorder buffer commits results in program order so the machine can recover and present correct architectural state on faults.

Design question
How many physical registers do you need given your RS count and target ILP? The answer balances performance gains and hardware cost.
