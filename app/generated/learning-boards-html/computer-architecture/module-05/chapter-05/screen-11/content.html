MUL R4, R1, R5     # Latency: 3
ADD R6, R2, R3     # Latency: 1
MUL R7, R4, R6     # Latency: 3
ADD R8, R1, R7     # Latency: 1
Simulation prompt
Track: RS state, register tag map, CDB broadcasts each cycle. Note issue, dispatch, and writeback cycles. Compare total cycles with an in-order run for the same latencies.
Walkthrough notes
- Cycle 1: ADD issues to RS_A1 and executes, writes back end of cycle, R1 receives value.
- MUL that reads R1 can issue earlier if RS free but waits for R1's result tag until the ADD writes on the CDB.
- The independent ADD R6 issues and may complete during the MUL's multi-cycle execution, demonstrating ILP.
Key Takeaway

A cycle-by-cycle trace shows how RS entries and renaming let independent instructions proceed earlier, lowering total cycles versus in-order execution.
