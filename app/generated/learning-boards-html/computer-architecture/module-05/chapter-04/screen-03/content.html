Practice and Assessment
Concrete tasks to verify competency.
Hands-on task
Simulate six instructions with 8 architectural registers and 16 physical registers, track RAT, free list, and PRF state after each decode and commit.
VERIFIED COMPETENCY MILESTONE
Assessment question
Compute minimum physical registers required: number of architectural registers plus reorder buffer entries that can write before commit.
VERIFIED COMPETENCY MILESTONE
Common pitfalls
  • Not saving old mappings at rename, making recovery after misprediction impossible.
  • Freeing physical registers before commit, which breaks precise state.
  • Underestimating port needs for the PRF, causing performance stalls.
Mnemonic: Always save old mappings; always free only at commit.
