Module 5 › Chapter 5.4 › Key Concepts
Register renaming
Eliminates WAW and WAR by allocating fresh physical registers per write.
RAT vs PRF
RAT maps names to physical registers; PRF stores the values and needs many ports.
Free list & recovery
Free list allocates physical registers; old mappings must be saved to restore RAT on squash.
Summary takeaway
Renaming enables out-of-order execution by separating names from storage, but it shifts complexity to mapping, allocation, and the physical register file design—trade-offs designers must balance.
