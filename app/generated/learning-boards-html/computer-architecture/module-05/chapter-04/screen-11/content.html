Module 5 › Chapter 5.4 › Mispredict Recovery
Restoring state after misprediction
Use saved old mappings to rebuild the RAT and free list.
Restore steps
1. Walk saved mappings for squashed instructions in reverse program order.
2. For each saved mapping, write the old physical register back into the RAT entry.
3. Rebuild or restore the free list so freed physical registers become available again.
Why reverse order?
Restoring in reverse program order ensures that earlier saved mappings are not overwritten by later ones during the restore. It matches the natural undo sequence of speculative updates.
If saved mappings are stored in the reorder buffer, the RB's natural program order and squash logic make restoration straightforward.
Key Takeaway

Saved old mappings make correct recovery possible; restore RAT entries in reverse program order and repair the free list to resume decoding safely.
