Mnemonic: lockers and name tags
Think of architectural registers as name tags and physical registers as lockers. The RAT is the directory mapping tags to lockers. The free list is the pile of unused lockers.
Why this matters

If you can trace mappings and free-list allocations, you'll reason about how many physical registers a design needs and how renaming affects performance and hardware cost.
