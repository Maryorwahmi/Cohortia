Objective cues and quick heuristics

Use these targeted heuristics while you step through scoreboard tables or a cycle-by-cycle simulation.

Dispatch check
Is the functional unit free? Is any earlier instruction scheduled to write the same destination? If either is false, stall.
Table scan
Read instruction state, then unit row fields (Busy, Fi, Fj, Qj, Rj) and the register result table to understand producer-consumer links.
Hazard mnemonic
WAW: two writers to same register. WAR: later writer may clobber a previous reader. Scoreboard must stall these cases.
Compare to Tomasulo
If you see renaming or reservation stations in a design, expect fewer write-order stalls and more overlapping execution.
