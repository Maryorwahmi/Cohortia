Module 5 › Chapter 5.3 › Issue Stage
Issue Checks
1) Functional unit free. 2) No WAW on destination. Both must hold to issue.
Example
I1 writes F1 and is pending. I2 writes F1 later: scoreboard stalls I2 at Issue until I1 completes its write.
Misconception
Issue checks both unit availability and destination conflicts. Missing either leads to wrong schedules.
Reading tip
Scan the register result table first for the destination, then check the target unit’s Busy bit to estimate issue timing.
Key Takeaway

WAW checks at Issue serialize writes to the same architectural register, limiting parallelism compared to rename-based designs.
