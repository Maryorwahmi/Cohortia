Learning Objectives

Develop actionable skills to analyze and compare scoreboarding behavior
Learn → Understand → Apply → Master
01
Describe multi-issue dispatch
Explain how instructions are allocated to functional units and why in-order appearance is preserved. Useful for predicting instruction throughput.
VERIFIED COMPETENCY MILESTONE
02
Explain the scoreboard tables
Name the instruction, functional unit, and register tables and state what each field records. A Venn mnemonic links tables to stage transitions.
VERIFIED COMPETENCY MILESTONE
03
Identify WAR and WAW limits
Detect where scoreboarding stalls because it lacks register renaming, and explain the performance cost.
VERIFIED COMPETENCY MILESTONE
04
Compare to Tomasulo
Explain how register renaming and reservation stations in Tomasulo remove certain stalls and improve parallelism.
VERIFIED COMPETENCY MILESTONE
