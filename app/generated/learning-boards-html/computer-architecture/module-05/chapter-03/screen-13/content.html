Instruction Sequence
ADD F1, F2, F3     # ALU, 2 cycles
MUL F4, F1, F5     # MUL, 4 cycles, depends on ADD
SUB F6, F2, F3     # ALU, 2 cycles, independent
DIV F7, F4, F6     # MUL, 6 cycles, depends on MUL and SUB
Simulation steps
For each cycle: update Issue, check RegResult and unit Busy, set Q/R, advance Execute latencies, and gate Write Result by WAR checks.
What to track
  • Instruction Status rows with stage timestamps
  • Functional Unit rows showing Qj/Qk and Rj/Rk
  • Register Result mapping to identify pending writers
Key Takeaway

Cycle-by-cycle bookkeeping reveals precisely where dependencies create stalls and how they propagate through Q/R and RegResult entries.
