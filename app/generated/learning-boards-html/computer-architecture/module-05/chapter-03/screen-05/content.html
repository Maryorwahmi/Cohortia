Instruction Status Table
Each row tracks an instruction's stage. This table is the departure board for in-order scheduling.
Fields
Instruction ID, Operation, Stage (Issue, Read Operands, Execute, Write Result), cycle timestamps
Reading tip
Compare timestamps to find where an instruction waits: stalled at Issue vs delayed at Write Result indicate different hazards.
Example row
I3: MUL — Issue: cycle 2, Read Operands: cycle 4, Execute: cycles 5-8, Write Result: pending
Key Takeaway

The Instruction Status table is the primary source to spot where hazards turn into stalls across cycles.
