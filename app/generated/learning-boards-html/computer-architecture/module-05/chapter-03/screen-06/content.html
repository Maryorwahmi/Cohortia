Module 5 › Chapter 5.3 › Functional Unit Status
Functional Unit Row
Busy | Operation | Fi | Fj | Fk | Qj | Qk | Rj | Rk
Busy and Operation
Indicate whether the unit can accept a new issue and which opcode it is performing.
Q and R fields
Qj/Qk name the producing unit when an operand is pending; Rj/Rk mark readiness. These are the heart of producer-consumer links.
Example rows
ALU1: Busy=Yes, Op=ADD, Fi=F1, Fj=F2, Fk=F3, Qj=-, Qk=-, Rj=1, Rk=1
MUL1: Busy=Yes, Op=MUL, Fi=F4, Fj=F1, Fk=F5, Qj=ALU1, Qk=-, Rj=0, Rk=1
Key Takeaway

Q and R fields explicitly encode where an operand will come from and whether it is ready, enabling staged reads and safe execution starts.
