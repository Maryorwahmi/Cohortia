Module 5 › Chapter 5.3 › Key Concepts
Three tables
Instruction status, functional unit status, and register result table coordinate scheduling.
Four stages
Issue, Read Operands, Execute, Write Result — each enforces checks that ensure correctness.
Hazard limits
No renaming means WAR and WAW require stalls; this is the scoreboard’s main limitation.
Summary Takeaway

Scoreboarding was a practical early dynamic scheduler: simpler hardware, correct in-order execution, and limited by name-based hazards that later renaming schemes solved.
