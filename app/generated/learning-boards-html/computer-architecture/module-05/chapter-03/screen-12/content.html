WAR and WAW
WAW
Two writers to same architectural register. Scoreboard stalls later writer at Issue to preserve write order.
WAR
A later writer could overwrite a value before an earlier reader reads it. Scoreboard delays writes until reads finish.
Example contrast
With renaming, WAW disappears because each writer gets a distinct physical register. With scoreboarding, the writers must serialize.
Key Takeaway

Scoreboarding enforces correct ordering at the cost of stalls; register renaming is the mechanism that removes these particular constraints.
