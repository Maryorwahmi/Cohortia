Module 5 › Chapter 5.3 › Algorithm Stages
Process Flow

Issue → Read Operands → Execute → Write Result

Issue
Check unit free and WAW. Stall if conflict.
Read Operands
Wait until operands ready; check WAR when relevant.
Execute
Functional unit runs for its latency and then signals completion.
Write Result
Check WAR before writing to avoid overwriting a value needed by earlier readers.
Concrete example
ADD issues to ALU, operands ready → moves to Execute for two cycles → on completion the scoreboard may still delay Write Result if a previous instruction must read the old destination.
Misconception
Do not assume Write Result happens immediately after Execute. Scoreboard may delay for WAR checks even after execution completes.
