Module 5 › Chapter 5.3 › Read Operands
Read rules
An instruction reads when operands are ready and no WAR hazard will give it the wrong value.
Example
I1 needs F2; I2 (younger) will write F2. Scoreboard prevents I2’s write from happening before I1 reads.
Fields in play
Rj/Rk readiness flags from the producing unit and RegResult table entries determine whether a value is available to read.
Common pitfall

Ready operands do not always mean immediate read — WAR checks can still delay the read to preserve correct values.
