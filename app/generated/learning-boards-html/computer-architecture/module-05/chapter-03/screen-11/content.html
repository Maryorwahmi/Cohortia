Module 5 › Chapter 5.3 › Execute & Write Result
Execution
Functional units run for their latency. On completion they notify the scoreboard.
Write Result gating
Before writing, the scoreboard verifies no earlier reader needs the old value, and only then commits to the register file.
Key Takeaway

Execution completion does not imply immediate architectural update; WAR checks can create a commit delay that limits parallelism.
