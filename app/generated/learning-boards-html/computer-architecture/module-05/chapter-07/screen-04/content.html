Core Concept

Branch prediction enables speculative work

Processors guess branch outcomes to fetch and execute from a predicted path, avoiding stalls when guesses are correct.

Concrete example
A conditional jump whose condition depends on a load can be guessed; subsequent instructions execute while the load completes.
Common misconception
Speculation does not change program results because commits occur only after correctness is confirmed.
Key Takeaway
Branch prediction improves throughput when accuracy is high enough that recovery cost is outweighed by saved stalls.
Visual checklist
  • Predict branch direction
  • Fetch from predicted path
  • Execute speculatively, mark results as speculative
  • Commit only after branch resolution
  • Flush on misprediction
