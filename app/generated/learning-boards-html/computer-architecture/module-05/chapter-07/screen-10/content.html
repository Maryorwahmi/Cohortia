Module 6 › Chapter 5.7 › Hands-on CPI
Problem
Workload: 20% branches. Predictor accuracy: test 90%, 95%, 99%. Branch penalty on mispredict: 15 cycles. Without speculation stall per branch: 2 cycles. Processor can execute 4 instructions per cycle.
# steps (illustrative calculation):
Base CPI without stalls = 1 / IPC = 1 / 4 = 0.25
No-speculation branch penalty = branch_freq × stall = 0.20 × 2 = 0.40
Effective CPI without speculation = 0.25 + 0.40 = 0.65

With speculation:
Per-branch expected penalty = (1 - accuracy) × 15
Per-instruction penalty = branch_freq × per-branch penalty
Add to base CPI 0.25 to get effective CPI.

Compare effective CPIs to compute speedup = CPI_no_spec / CPI_with_spec
Concrete numbers
For accuracy = 0.90: per-branch penalty = 1.5 cycles, per-instruction = 0.20 × 1.5 = 0.30, CPI = 0.25 + 0.30 = 0.55. Speedup = 0.65 / 0.55 ≈ 1.18. For 0.95 and 0.99 compute similarly to observe improved speedup but diminishing returns.
Key takeaway
Small improvements in accuracy can give noticeable speedups for branch-heavy workloads, but the gains taper as other limits dominate.
