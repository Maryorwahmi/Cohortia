Module 6 › Chapter 5.7 › Expected Gain
Formula
<!-- Expected gain inequality -->
Expected Gain = Accuracy × Gain_when_correct
Expected Cost = (1 - Accuracy) × Cost_when_wrong
Profit if: Accuracy × Gain_when_correct > (1 - Accuracy) × Cost_when_wrong

# numeric example:
Accuracy = 0.95
Gain_when_correct = 1  # cycle saved
Cost_when_wrong = 15   # cycles lost on mispredict
Expected Gain = 0.95 × 1 = 0.95
Expected Cost = 0.05 × 15 = 0.75
Profit = Expected Gain - Expected Cost = 0.20 cycles per branch
Concrete note
Even small positive expected gains add up across many branches. But if recovery cost or misprediction rate rises, the same calculation can flip and make speculation unprofitable.
Key takeaway
Always compute expected gain for your specific workload; accuracy alone is not sufficient to decide.
