Module 6 › Chapter 5.7 › Memory Disambiguation
Comparison

Three approaches

Address-based disambiguation
Compare store and load addresses when available; re-execute or forward if they match.
Store set prediction
Predict which stores a load might conflict with using historical conflict patterns.
Conservative scheduling
Delay loads until prior store addresses are known — safe, but reduces parallelism.
Concrete example
A load that often reads the same address as a recent store benefits from store set prediction to avoid stalls. If prediction misses, the load is replayed or forwarded when the store address becomes known.
Key takeaway
Mixing a fast predictor with precise address checks gives performance while retaining correctness through replay or forwarding on conflicts.
