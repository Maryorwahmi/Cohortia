Techniques
Value prediction
Guess the result of an instruction; rarely used in commercial designs due to replay cost on misses.
Cache line prediction
Prefetch likely cache lines to hide memory latency; mispredictions waste bandwidth and power.
Concrete contrast
Memory disambiguation speculates about addresses and can forward data directly. Value prediction guesses computed values and requires re-execution on error. Cache prediction only affects cache state and is simpler to recover from.
Key takeaway
Different speculative techniques have different recovery models and costs; their usefulness is workload-dependent.
