Module 6 › Chapter 5.7 › Key Concepts
Speculative execution
Execute before confirmation to save cycles when correct.
Reorder Buffer (ROB)
Holds speculative results until safe to commit in program order.
Memory disambiguation
Predict whether loads alias earlier stores to execute loads early or wait.
Summary takeaway

Speculation multiplies throughput when accurate; the ROB ensures correctness; memory dependence prediction often determines whether aggressive out-of-order designs win or lose.
