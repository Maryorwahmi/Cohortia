Learning Objectives — Practice & Measurement

Apply experiments to validate parallel performance and find bottlenecks.

Hands-on activity summary
  • Parallelize outer loop of matrix multiplication with OpenMP pragmas.
  • Measure run time for N = 512, 1024, 2048 with 1, 2, 4, 8 threads.
  • Compute speedup and efficiency; try static, dynamic, and guided schedules.
  • Observe cache locality and false sharing; mitigate with padding.
Why measure?
Measurement reveals whether theoretical speedup matches real behavior and helps diagnose serial bottlenecks and cache effects.
