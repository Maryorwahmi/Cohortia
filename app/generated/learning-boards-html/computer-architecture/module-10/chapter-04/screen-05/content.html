Comparison

Message-passing model

Each process has private memory; communication is done explicitly by sending and receiving messages. MPI is the standard interface.

Advantages
  • Scales to thousands of processes without shared-memory bottlenecks.
  • Makes data movement explicit and visible to the programmer.
Disadvantages
  • More complex code due to explicit send/receive calls.
  • Higher overhead for fine-grained communication and load balancing.
Concrete example
A distributed matrix multiplication where processes own blocks and exchange boundary rows explicitly. Communication cost must be accounted for in performance calculations.
Key Takeaway

Message-passing makes data movement explicit and scales well, but requires careful design for latency and load balance.

Common misconception

Believing that message-passing removes all synchronization; sends and receives must still be coordinated to avoid deadlock.
