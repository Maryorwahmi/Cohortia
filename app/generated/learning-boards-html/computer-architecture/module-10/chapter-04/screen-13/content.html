Matrix multiplication with OpenMP

Parallelize the outer loop using #pragma omp parallel for and test with N = 512, 1024, 2048. Measure for 1, 2, 4, 8 threads and compute speedup and efficiency.
/* Outer-loop parallelization sketch */
#pragma omp parallel for schedule(static)
for (int i = 0; i < N; ++i) {
  for (int j = 0; j < N; ++j) {
    double sum = 0.0;
    for (int k = 0; k < N; ++k) sum += A[i][k] * B[k][j];
    C[i][j] = sum;
  }
}
Measurement checklist
  • Record wall-clock times for each configuration.
  • Compute speedup = T1 / TN and efficiency = speedup / N.
  • Compare schedules and try padding to detect false sharing.
Key Takeaway
Empirical measurement is essential: theory guides expectations, experiments reveal real bottlenecks like coherence or imbalance.
