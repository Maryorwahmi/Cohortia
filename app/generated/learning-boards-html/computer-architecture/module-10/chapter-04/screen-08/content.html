Parallel sum with reduction

int N = 1000000;
double sum = 0.0;
#pragma omp parallel for reduction(+:sum)
for (int i = 0; i < N; ++i) {
  sum += a[i];
}
This pattern gives each thread a private sum and merges them after the loop. It's both correct and efficient for associative operations.
Explanation
  • parallel for: creates threads and distributes iterations.
  • reduction(+:sum): private partial sums then combine safely.
  • Avoid critical sections for frequent updates; they serialize work.
Key Takeaway

Reductions are the preferred pattern for associative aggregation in OpenMP loops.
