Process Flow

Fork-join execution model

  1. Start with a single master thread running serial code.
  2. Encounter a parallel region; master forks worker threads.
  3. All threads execute the region; use synchronization as needed.
  4. At region end, workers join and master resumes serial execution.
Pro tip
Group work into coarser parallel regions to reduce thread creation and synchronization overhead.
Concrete example
A function runs serially, then a parallel for is executed where the master creates N threads; after loop completion threads join and the function continues serially.
Common mistake
Placing many tiny parallel regions in hot code so thread management overhead dominates runtime.
Key Takeaway
Balance fork-join boundaries to amortize thread overhead and improve efficiency.
