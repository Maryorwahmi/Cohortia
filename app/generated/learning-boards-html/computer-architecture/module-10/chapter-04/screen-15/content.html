Key Concepts — Part 2

Performance formulas and common pitfalls in parallel programs.

Speedup & Efficiency
Speedup = 1 / ((1-P) + P/N). Efficiency = speedup / N. Use these to set realistic expectations.
Amdahl's Law
A serial fraction limits maximum speedup even with infinite threads; quantify it to set goals.
Pitfalls
False sharing and excessive synchronization often explain poor scaling; adjust layout and sync points to fix them.
Final takeaway

Measure, reason with formulas, and apply model-specific patterns to turn parallel code into real performance gains.
