Definition

OpenMP fundamentals

Compiler directives that mark parallel regions, split loops, and handle synchronization and reductions.

#pragma omp parallel
Creates a team of threads; each runs the region body.
#pragma omp for
Distributes loop iterations across threads.
critical / barrier / reduction
Synchronize access, wait for all threads, and combine partial results safely.
Example card
/* Parallel sum with reduction */
#pragma omp parallel for reduction(+:sum)
for (int i = 0; i < N; ++i) {
  sum += a[i];
}
Key Takeaway

Reductions are preferable to critical sections for associative combines because they avoid serializing updates.
