Definition

Cache coherence & false sharing

False sharing occurs when threads modify different data in the same cache line, causing unnecessary invalidations and reduced performance.

Why it matters
Even logically independent updates can serialize due to hardware cache behavior, reducing speedup.
Concrete mitigation
Pad per-thread counters to 64 bytes or use per-thread arrays so that threads write to separate cache lines and avoid bouncing traffic.
Pro tip
When profiling shows poor scaling, test with padded data structures to confirm false sharing as the cause.
