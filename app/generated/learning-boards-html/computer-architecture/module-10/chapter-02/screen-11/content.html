Hardware Components

Streaming Multiprocessor (SM) Architecture

The basic building block of NVIDIA GPU parallelism.

Many SMs per GPU

A single GPU contains numerous SMs (e.g., 128 in H100), each capable of independently managing and executing multiple warps.

Shared Resources

Each SM has its own shared memory, register files, and schedulers to manage the execution of threads within its domain.

Key Takeaway

SMs are the core parallel processing units of NVIDIA GPUs, integrating various specialized cores for diverse workloads.

SM Core Types

CUDA Core

Simple ALU for integer/floating-point operations. General-purpose parallel compute.

Tensor Core

Specialized matrix multiply-accumulate unit. Accelerates deep learning workloads.

RT Core

Specialized ray tracing intersection unit. Accelerates realistic graphics rendering.
