Execution Model

Single Instruction, Multiple Threads (SIMT)

Executing thousands of threads in lockstep on different data.

Warp Definition

A group of 32 threads that are scheduled and executed together as a single unit on the GPU. This is the fundamental unit of scheduling.

Lockstep Execution

All threads within a warp execute the same instruction simultaneously, but each thread operates on its own distinct data element.

Key Takeaway

SIMT leverages warps for efficient data-parallel execution, where a single instruction drives multiple threads on varied data.
