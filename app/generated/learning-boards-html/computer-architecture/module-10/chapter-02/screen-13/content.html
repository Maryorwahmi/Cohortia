Simple CUDA Kernel: Array Addition

Illustrating parallel computation with a basic example.

Kernel Function

The __global__ function executed by each GPU thread. It defines the parallel work for each element.

Host Code Role

Manages GPU memory allocation, data transfers (CPU to GPU and back), and launching the kernel with appropriate grid and block dimensions.

Key Takeaway

Simple kernels demonstrate how to leverage GPU threads for data-parallel tasks, with each thread processing a distinct data element.

Conceptual CUDA Array Addition

__global__ void addArrays(float* a, float* b, float* c, int n) {
  int idx = blockIdx.x * blockDim.x + threadIdx.x;
  // Each thread calculates a unique index

  if (idx < n) {
    c[idx] = a[idx] + b[idx];
    // Each thread performs one addition
  }
}

// Host code (CPU) would:
// 1. Allocate memory on GPU (a_d, b_d, c_d)
// 2. Copy data from CPU to GPU (a_h -> a_d, b_h -> b_d)
// 3. Define grid and block dimensions
// 4. Launch kernel: addArrays<<<gridDim, blockDim>>>(a_d, b_d, c_d, n);
// 5. Copy results from GPU to CPU (c_d -> c_h)
