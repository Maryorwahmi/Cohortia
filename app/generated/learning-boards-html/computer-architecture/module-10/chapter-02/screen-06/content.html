Performance Impact

Understanding Branch Divergence

The cost of conditional logic in SIMT execution.

What is Divergence?

When threads within the same warp take different execution paths due to conditional statements (e.g., if-else).

Performance Penalty

The GPU executes each divergent path sequentially, masking off inactive threads. This effectively serializes execution within the warp, reducing parallelism.

Key Takeaway

Minimize branch divergence in GPU code to maintain high parallel efficiency and avoid significant performance degradation.

Branch Divergence Process

Warp executes common instruction
Encounter if-else statement
Execute 'if' path (mask 'else' threads)
Execute 'else' path (mask 'if' threads)
Warp reconverges and continues
