Architecture

System-on-Chip Integration

Combine CPU, GPU, NPU, ISP and accelerators in one package to reduce latency and power per operation.

Local memory and interconnect
Place memory buffers close to accelerators to reduce data movement and energy.
Heterogeneous scheduling
Coordinating work across engines requires OS and runtime support to choose the best target.
Examples
  • Apple SoCs: CPU clusters, GPU, Neural Engine, ISP tuned for mobile use.
  • AMD packages: compute chiplets with I/O die for memory and I/O functions.
Design note
Integration reduces off-chip transfers but increases thermal density. Balance integration with cooling and interconnect design.
Key Takeaway

SoC design trades off integration benefits against thermal and design complexity; co-locate high-traffic elements to save power.
