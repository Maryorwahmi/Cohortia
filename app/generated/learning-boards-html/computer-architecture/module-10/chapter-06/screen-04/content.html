Core Concept

Heterogeneous Computing

Different processors for different workloads improve efficiency and latency.

CPU
Control, branching, system orchestration
GPU
Massively parallel arithmetic
NPU / TPU
Optimized tensor ops, inference/training
DSP / FPGA / ASIC
Signal processing, reconfigurable logic, fixed functions
Why it matters
  • Higher performance per watt when computation matches hardware strengths.
  • Lower latency for on-device inference and improved privacy without cloud round trips.
  • Better total system throughput by offloading dominant kernels to accelerators.
Example
A phone uses its NPU for face recognition and the CPU for UI navigation. The NPU reduces energy per inference and avoids waking a larger CPU pipeline for every camera frame.
Key Takeaway

Treat processors as a team; delegate repetitive heavy arithmetic to accelerators and keep control logic on the CPU.
