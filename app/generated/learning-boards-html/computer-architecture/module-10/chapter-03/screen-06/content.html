Definition Fine-Grained Multithreading
How FGMT works
The scheduler rotates active threads every cycle so instructions from multiple threads are interleaved in the pipeline.
GPU example
A GPU switches warps each cycle so memory latency is hidden by other ready warps.
Effect on threads
Individual threads see slower apparent progress but the core achieves high utilization overall.
Trade-offs
  • Hides both short and long latencies effectively.
  • Increases contention for caches and memory bandwidth.
  • Reduces per-thread effective issue bandwidth.
Common mistake

Assuming FGMT always improves all workloads — some workloads suffer from increased cache thrash and lower per-thread performance.

Key Takeaway

FGMT keeps pipelines full across varied latencies but requires careful data locality and bandwidth management.
