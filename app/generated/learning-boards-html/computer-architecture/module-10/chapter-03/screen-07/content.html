Core Concept Simultaneous Multithreading (SMT)
How SMT implements multithreading
  • Architectural state is replicated per thread (PCs, register aliases, return stacks).
  • Execution resources, caches, and predictors are shared across threads.
  • The pipeline fetches and issues instructions from multiple threads in the same cycle.
Practical result
Higher throughput without duplicating execution units; cost-effective area usage.
Concrete numbers from practice
A two-way SMT core often attains roughly 70–90% of the throughput of two physical cores while adding only about 5–10% more area. This makes SMT valuable in throughput-oriented designs.
Misconception

SMT is just two cores merged — actually it shares execution units and therefore can suffer inter-thread contention.

Key Takeaway

SMT increases core utilization by allowing multiple threads to use idle issue slots in the same cycle, trading per-thread isolation for throughput.
