Core Concept Thread-level parallelism (TLP)
Definition and motivation
TLP runs multiple independent threads to overlap stalls and increase overall CPU utilization.
Example
A web server handles separate requests; while one thread waits for disk, another uses the core's execution units.
Misconception
More threads always improve performance — false. Threads can compete for caches and functional units, lowering per-thread throughput.
Key Takeaway

TLP improves aggregate work done by overlapping stalls, but requires careful scheduling to avoid contention.

Comparing ILP and TLP
Instruction-level parallelism
Reorders and issues independent instructions from the same thread to fill execution slots.
Thread-level parallelism
Runs multiple threads to utilize idle resources when one thread stalls on misses or I/O.
Practical rule
Use TLP for workloads with independent tasks and limited ILP, such as servers and databases.
