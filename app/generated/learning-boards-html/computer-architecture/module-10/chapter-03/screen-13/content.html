Hands-on Activity Measure SMT impact
Workflow
  1. Disable SMT in BIOS or the system control interface.
  2. Compile a compute-intensive benchmark (matrix multiply or prime sieve).
  3. Run with 1,2,4,8 threads; record execution time and throughput.
  4. Enable SMT and repeat measurements; compute speedup and plot results.
Measurement tip
Run each configuration multiple times and average to reduce noise.
