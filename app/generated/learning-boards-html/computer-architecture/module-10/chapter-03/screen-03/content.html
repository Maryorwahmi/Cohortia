Module 10 › Chapter 10.3 › Practice & Assessment
Hands-on experiment
Run a compute benchmark with SMT off and on, record execution time for 1,2,4,8 threads, then compute speedup and plot performance vs thread count.
Outcome
Identify when SMT provides the best marginal gain and when thread contention reduces returns.
Assessment tip
For scheduler questions, explain resource contention: L1/L2 cache, branch predictor, TLB, and execution units. Recommend spreading compute threads across physical cores first.
Security
Explain why SMT increases side-channel risk and how core scheduling isolates sensitive contexts.
