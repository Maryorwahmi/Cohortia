Module 10 › Chapter 10.5 › Loop-Carried Dependencies

What it is

A loop-carried dependency means iteration i depends on results from iteration i-1 or earlier, preventing parallel execution.

for (int i = 1; i < N; i++) {
  a[i] = a[i-1] + 1;
}
This example is inherently serial; the value of a[i] cannot be computed until a[i-1] is known.

Options and misconceptions

  • Some dependent patterns require algorithmic transforms such as parallel scan; compilers do not automatically rewrite to parallel algorithms.
  • If the dependency is incidental, a code rewrite may expose independent iterations that a compiler can vectorize.
  • Do not assume compiler heuristics will hide a fundamental serial dependency.
Common mistake

Trying to force vectorization with pragmas on a truly dependent loop will not preserve correctness.
