Module 10 › Chapter 10.5 › Memory Alignment
Why alignment helps

Aligned loads and stores match SIMD register widths and avoid extra instructions for handling unaligned memory.

Compilers can generate a faster path when they know the pointer meets alignment constraints.
Tell the compiler
float *p = (float*)ptr;
p = (float *) __builtin_assume_aligned(p, 32);
Use assume_aligned only when you can enforce alignment from allocation or API guarantees.
