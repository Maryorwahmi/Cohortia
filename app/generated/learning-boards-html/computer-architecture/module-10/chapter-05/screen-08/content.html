Branches and masking

When iterations diverge on a condition, compilers use masking to disable lanes, which preserves correctness but reduces throughput.

for (int i = 0; i < N; i++) {
  if (a[i] > 0) b[i] = a[i] * 2;
  else b[i] = a[i] + 1;
}
Function calls

Calls that cannot be inlined or have unknown side effects usually block vectorization. Keep loop bodies small and inlinable.

If a call is expensive or non-inlinable, consider extracting work or using lookup tables that are vector-friendly when possible.
