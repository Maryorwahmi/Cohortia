Module 10 › Chapter 10.5 › Performance Factors
Key factors
  • SIMD width — theoretical limit on parallel lanes.
  • Memory bandwidth — often the real bottleneck.
  • Alignment — determines efficient load/store instructions.
  • Remainder & masking — tail processing reduces effective speedup.
Measurement tips
Run both scalar and vectorized versions with large N, ensure aligned allocations when testing alignment effects, and isolate memory-bound versus compute-bound behavior by varying working set sizes.
Key Takeaway

Vectorization increases arithmetic throughput but real gains depend on memory system and control flow.
