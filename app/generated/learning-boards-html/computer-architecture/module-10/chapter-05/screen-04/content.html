Module 10 › Chapter 10.5 › What is Vectorization?
Definition

Vectorization

Turning repeated scalar operations into SIMD instructions that process multiple data elements at once.

Why it matters
  • Potentially multiplies arithmetic throughput by SIMD width.
  • Requires data independence and cooperative memory behavior.
  • Not always beneficial if the loop is memory-bound or has dependencies.
Concrete example
for (int i = 0; i < N; i++) {
  c[i] = a[i] + b[i];
}
This element-wise add can be vectorized into a single SIMD add that handles multiple elements per instruction when a, b, and c do not overlap and memory is appropriately aligned.
Key Takeaway

Vectorization is safe only when the loop has independent iterations and the memory system supports the grouped accesses.
