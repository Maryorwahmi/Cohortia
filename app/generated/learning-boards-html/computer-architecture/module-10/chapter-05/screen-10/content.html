Common hints
  • __restrict__ — promise no aliasing.
  • __builtin_assume_aligned() — assert pointer alignment.
  • pragma omp simd — request or force vectorization.
  • ivdep — ignore assumed dependencies (vendor-specific).
When to use each
Start by reading the vectorization report. If aliasing blocks vectorization, use restrict after confirming non-overlap. If alignment blocks performance, use assume_aligned when you control allocation. Use pragmas to document intent and enable vectorization, but avoid silent undefined behavior.
Tip: prefer clear API contracts and allocation-time alignment guarantees over ad-hoc directives.
