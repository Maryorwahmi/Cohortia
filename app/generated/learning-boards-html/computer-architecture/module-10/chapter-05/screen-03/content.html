Module 10 › Chapter 10.5 › Practice & Diagnosis

Practice objectives

Run reports, interpret messages, and make conservative fixes that restore vectorization.

Enable reporting
Use -fopt-info-vec-all with GCC or vendor opt-report flags to see vectorization decisions.
Fix non-vectorized loops
Add __restrict__ or pragmas when safe, or rewrite the algorithm when dependencies are serial.
Measure changes
Compare scalar and vectorized runs; watch for memory-bound limits and remainder effects.
