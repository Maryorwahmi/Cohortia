Module 10 › Chapter 10.5 › Aliasing & __restrict__
Problem: possible aliasing

If arrays overlap, reordering or grouping operations can change program results, so vectorization is blocked.

void add(float *a, float *b, float *c, int N) {
  for (int i = 0; i < N; i++) c[i] = a[i] + b[i];
}
Solution: __restrict__

Use __restrict__ on pointer parameters to promise no aliasing, enabling the compiler to vectorize safely.

void add(float * __restrict__ a,
         float * __restrict__ b,
         float * __restrict__ c, int N) { ... }
Only apply restrict when you can guarantee pointers do not overlap. Otherwise behavior is undefined.
