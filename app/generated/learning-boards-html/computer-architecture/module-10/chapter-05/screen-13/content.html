Intrinsics example
#include <immintrin.h>
__m256 a_vec = _mm256_load_ps(a + i);
__m256 b_vec = _mm256_load_ps(b + i);
__m256 c_vec = _mm256_add_ps(a_vec, b_vec);
_mm256_store_ps(c + i, c_vec);
This sequence shows an explicit 256-bit load, add, and store for float arrays on AVX2-capable CPUs.
Practical notes
  • Handle remainders with a scalar tail or masked operations.
  • Test correctness against scalar code and measure end-to-end performance.
  • Prefer manual intrinsics only when compiler output is insufficient.
