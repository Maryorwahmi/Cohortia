Module 10 › Chapter 10.5 › Vectorization Reports
GCC example
gcc -O3 -fopt-info-vec-all -o program program.c
The report lists loops that were vectorized and those that were not, along with reasons that map directly to the checks we discussed.
Workflow
  1. Compile with vector-report flags.
  2. Locate reported loops and read the reason text.
  3. Apply minimal, safe change: restrict, assume_aligned, or refactor.
  4. Recompile and measure performance changes.
