Fixed-width vs scalable vectors
Fixed widths give predictable lane counts; scalable vectors let hardware choose width at runtime for portability.
x86 family
SSE 128-bit, AVX 256-bit, AVX-512 512-bit.
ARM family
NEON 128-bit; SVE variable length for portability and scalability.
Practical guidance
Target portable abstractions when possible, and test compiled code on intended hardware to ensure expected vector widths and performance.
Misconception: wider SIMD always wins. Only when memory and alignment support feeding wide lanes will you realize the theoretical speedup.
Key Takeaway
Know your target ISA's vector model: fixed-width vs scalable changes portability and the way you handle strip mining and alignment.
