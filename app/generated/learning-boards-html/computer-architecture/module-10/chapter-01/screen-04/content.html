Module 10 › Chapter 10.1 › ILP vs DLP
Instruction-level parallelism (ILP)
Execute independent instructions simultaneously using pipelining and out-of-order techniques.
  • Good for irregular control flow and independent operations.
  • Limited by hazards and available instruction-level independence.
  • Typical real-world ILP is often 2–4 independent operations per cycle.
Example: executing independent arithmetic and memory operations from different instructions.
Data-level parallelism (DLP)
One instruction applies across many data elements using SIMD or vector units.
  • Excellent for regular loops over arrays.
  • Removes loop and branch overhead by operating per-lane.
  • Requires regular memory access patterns and similar control per element.
Example: adding two arrays element-wise with a single vector add instruction.
Key takeaway
Use ILP to extract parallelism within instruction streams and DLP to scale across many data elements. Combine both to maximize throughput, but choose DLP when data regularity and memory throughput allow it.
