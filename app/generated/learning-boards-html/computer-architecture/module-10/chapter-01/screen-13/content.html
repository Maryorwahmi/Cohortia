Module 10 › Chapter 10.1 › Programming for SIMD
Three programming approaches
  • Auto-vectorization: simplest, relies on compiler heuristics.
  • Intrinsics: explicit vector operations in C, architecture-specific.
  • Assembly: maximal control, least portable and most effort.
Guidance: structure loops for simple memory access and no hidden dependencies to help compilers. If auto-vectorization fails, use intrinsics sparingly and profile to justify their use.
Common pitfalls
  • Assuming the compiler always vectorizes.
  • Using intrinsics without addressing alignment and memory layout.
  • Relying on wider vectors without confirming memory can feed them.
Key Takeaway: prioritize clean code and measurement; escalate to intrinsics only after profiling reveals missed vectorization opportunities.
