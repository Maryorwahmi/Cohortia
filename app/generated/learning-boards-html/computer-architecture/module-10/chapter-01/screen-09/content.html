Sample workflow
  1. Write scalar loop adding two arrays of N floats.
  2. Compile two binaries: one without vectorization, one with -O3 and target SIMD flags.
  3. Time both, compute speedup, and inspect assembly for vector instructions like packed adds.
Tip: warm CPU caches and run multiple trials to reduce noise. If the compiler does not vectorize, restructure the loop or use compiler pragmas carefully.
Code example (visual)
// add.c
void add(float *a, float *b, float *c, int n) {
  for (int i = 0; i < n; i++) {
    c[i] = a[i] + b[i];
  }
}
Compile examples: gcc -O1 and gcc -O3 -mavx2; inspect with objdump -d to find vectorized instructions.
Key Takeaway
Experimenting with builds and assembly links the architecture to practical outcomes. Measure, inspect, and reason about the results.
