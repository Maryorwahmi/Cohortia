Module 10 › Chapter 10.1 › SIMD execution model
What lockstep means
Every lane executes the same instruction at the same time; divergence is handled by masking.
Benefits include lower fetch/decode overhead and compact code. The main costs are wasted operations on masked lanes and the need for aligned, regular memory accesses.
Concrete example: vector add replacing a scalar loop of adds and increments.
Misconception: SIMD will speed any loop. Not true for irregular control or dependent operations.
Masking and predication
When lanes need different behavior, SIMD hardware masks inactive lanes and executes both paths with writes disabled for masked lanes.
This preserves correctness but reduces the effective parallelism. Designing data layouts and reducing divergence improves SIMD utilization.
Key Takeaway
Lockstep execution gives high throughput for regular operations; manage divergence to avoid wasted lanes.
