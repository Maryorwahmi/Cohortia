Module 10 › Chapter 10.1 › SIMD speedup
Calculate expected vs observed
Start with theoretical lanes, then account for memory, alignment, masking, and Amdahl's Law to estimate real speedup.
Theoretical: lanes = vector_bits / element_bits.
Observed: multiply by memory utilization and lane utilization factors.
Example: AVX-512 can perform 16 float adds per instruction, but measured speedup may be 4–8× because of bandwidth, masks, and non-vectorizable loop parts.
Practical steps
  • Compute theoretical lanes.
  • Measure memory throughput required and available.
  • Estimate fraction of vectorizable code and masking penalties.
Key Takeaway: theoretical maximum guides expectations; profiling reveals the true bottlenecks to address.
