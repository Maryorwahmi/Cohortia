Strip mining: chunk, process, remainder
Process full vector-width chunks and handle the leftover elements with masking or a scalar tail loop.
Step 1: compute full_chunks = N / L and tail = N % L.
Step 2: execute full_chunks vector operations in a loop.
Step 3: handle tail with masked vector or scalar loop.
Masked vector example: use a predicate to enable only active lanes, simplifying code but possibly executing inactive lanes.
Scalar tail example: separate small loop that processes the remainder without extra vector lane work.
Key Takeaway
Pick masking for code simplicity or scalar tails for minimal wasted compute; measure performance for your data sizes.
