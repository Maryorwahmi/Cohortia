Module 7 › Chapter 7.7 › Hybrid Coherence
Why hybrid?
Hybrid coherence keeps fast snooping inside a socket where a shared bus or ring is efficient, and uses directory protocols across sockets to avoid global broadcasts. This reduces global traffic while preserving low-latency local operations.
Local: snooping within socket for quick invalidations and supplies.
Global: directory between sockets for targeted messages and reduced bandwidth.
Design note
Profile workloads to choose domain boundaries. Lines hot within a socket should avoid directory involvement.
Key Takeaway

Hybrid coherence balances latency and scalability and is common in multi-socket designs.
