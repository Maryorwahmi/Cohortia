Module 7 › Chapter 7.7 › The Cache Coherence Problem
Problem statement
Multiple private caches can hold different values for the same address; coherence enforces agreement.
Concrete example
P1 writes A=5 into its cache. P2 still has A=0. If P2 reads, it sees stale data. A coherence protocol must prevent or correct this.
Why it matters
Correct program behavior and reproducibility depend on a coherent view of memory across cores. Without it, shared-memory algorithms break.
Common misconception
Coherence is not the same as consistency. Coherence is per-location agreement; consistency governs ordering across locations. Also, hardware does not magically keep caches synchronized without protocol traffic.
Analogy
Two people reading the same book: if one edits a page, the other must be told or discard the page; otherwise they read different stories.
Check your understanding
If a processor writes and keeps the line Modified, what should happen when another cache issues a read for that line?
Key Takeaway

Coherence requires protocol actions to keep cached copies consistent; without it shared-memory semantics fail.
