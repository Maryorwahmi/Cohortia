Module 7 › Chapter 7.7 › MSI: States & Transitions
States
Modified (M) — only this cache has the updated copy; memory is stale.
Shared (S) — clean copy; may be present in multiple caches.
Invalid (I) — no valid copy.
Key transitions
  • PrRd on I → BusRd → become S (or E in MESI).
  • PrWr on S → BusRdX/BusUpgr → become M after invalidations.
  • BusRd seen by M → supply data, M → S.
Annotated transition table
Event: PrRd
If I: BusRd issued. If another cache is M, that cache supplies data and moves to S. Requester → S.
Event: PrWr
If S: issue BusRdX to invalidate others, then move to M. If I: fetch then invalidate, then M.
Event: BusRd
If you are M: supply data and downgrade to S. If S: remain S. If I: ignore.
Event: BusRdX
If you are M or S: invalidate (→ I). If M: write back first.
Key Takeaway

MSI enforces a single writer (M) and allows multiple readers (S); bus events implement the necessary communication.
