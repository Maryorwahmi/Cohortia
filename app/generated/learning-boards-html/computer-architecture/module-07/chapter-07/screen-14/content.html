Module 7 › Chapter 7.7 › Key Concepts
Cache coherence problem
Multiple private caches need rules so all cores see the latest value for a block.
Snooping protocols
Caches monitor a shared bus and respond to BusRd and BusRdX messages to maintain coherence.
MSI & MESI
MSI uses M, S, I; MESI adds E so a sole reader can write without extra bus traffic.
Summary

Trace examples to see transitions, count bus events to measure cost, and choose snooping or directory based on system scale.
