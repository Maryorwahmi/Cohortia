Module 7 › Chapter 7.7 › Directory-Based Coherence
Directory entry
State: Uncached / Shared / Modified
Sharers: Bit vector or list of caches holding the block in Shared state
Owner: The cache holding Modified data, if any
When a cache requests a block, the directory issues targeted messages: invalidate only the known sharers or ask the owner to write back. This reduces broadcast traffic at the cost of directory storage and lookup latency.
Concrete example
If only caches A and B hold a block among 128 cores, the directory contacts only A and B rather than broadcasting to all cores.
Trade-off
Lower broadcast bandwidth versus added directory storage and lookup latency.
