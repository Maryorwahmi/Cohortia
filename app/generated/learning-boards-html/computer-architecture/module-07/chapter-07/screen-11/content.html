Module 7 › Chapter 7.7 › Snooping vs Directory
Snooping
Pros: simple hardware, fast reactions on a shared bus. Cons: every cache must snoop every broadcast, causing bandwidth and power costs as cores increase.
Directory
Pros: targeted messages, scalable to many cores. Cons: directory storage, lookup latency, and more complex hardware.
Hybrid approach
Use snooping within a socket or chiplet and directory coherence between sockets to balance latency and scalability.
Key Takeaway

Choose protocols based on system size and sharing patterns: small systems favor snooping, large systems favor directory or hybrid solutions.
