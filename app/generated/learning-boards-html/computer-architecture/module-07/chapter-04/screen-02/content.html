Learning Objectives

Four competency goals grounded in cache design and performance analysis.

Bloom: Learn → Understand → Apply → Master
01
Describe non-blocking behavior
Explain how a cache serves hits while misses are in flight, why that matters for pipelines, and give a concrete example with an out-of-order core issuing multiple loads.
VERIFIED COMPETENCY MILESTONE
02
Implement MSHR fields
List and explain address, valid, issued, waiting instructions, and data fields, and how they are used when responses arrive from memory.
VERIFIED COMPETENCY MILESTONE
03
Distinguish hit/miss interactions
Define hit under miss and miss under miss, and explain how merging reduces memory traffic and MSHR usage.
VERIFIED COMPETENCY MILESTONE
04
Analyze performance effects
Relate the number of MSHRs to latency hiding, explain workload dependence, and evaluate when non-blocking caches give real gains.
VERIFIED COMPETENCY MILESTONE
