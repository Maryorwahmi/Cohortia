Definition

MSHR fields and role

Each MSHR is a small state unit used to track a single outstanding block fetch and its dependents.

Address & Valid

Identifies the missing block and whether this MSHR entry is currently used.

Issued bit

Records whether the memory request was sent, supporting re-tries or ordering decisions.

Waiting list, Data, and Store support
Waiting instructions
Queue of loads/stores to wake when data returns.
Returned data
Buffer for the block returned from memory until update and wake-up complete.
Store misses
MSHR must carry store data and a byte mask so the write can be merged into the fetched block before releasing the store's completion.
Common design mistake

Under-provisioning the waiting-list capacity or store buffer per-MSHR leads to dropped merges or complex overflow handling.
