Pointer chasing vs independent loads

Different workloads use memory differently; this determines how useful MSHRs will be.

Independent loads

Many outstanding misses can be issued and overlapped. MSHRs and non-blocking caches provide large benefit.

Pointer chasing

Loads are serialized by address dependence; MSHRs cannot create independent work. Prefetching tends to help more here.

Key Takeaway

Profile workloads to decide whether more MSHRs or stronger prefetchers will provide the greater performance benefit.

Scenario comparison
Streaming example

Many independent cache-line loads; non-blocking caches keep many misses in flight and hide latency effectively.

Linked-list example

Each load produces the pointer for the next; even many MSHRs cannot issue the next address until the prior returns.
