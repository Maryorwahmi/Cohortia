Page and frame basics

Pages and frames are fixed-size units. With 4 KB pages, the offset is 12 bits. The VPN indexes into a page table to find the PFN; the PFN combined with the offset yields the physical address.

Physical Address = (PageTable[VPN] << pageOffsetBits) | pageOffset
Example
Page size 4096 → offset 12 bits. Address 0x1000 has VPN 1 and offset 0.
Misconception
Translation is per-page, not per-byte; permissions and swapping operate at page granularity.
Concrete walkthrough
  1. Given virtual address 0x1000 and 4 KB pages: compute offset = 0, VPN = 1.
  2. Look up PageTable[1] → PFN, say 10.
  3. Physical address = (10 << 12) | 0 = frame base address.
Key Takeaway

The page offset flows unchanged to the physical address; only the page number is translated.
