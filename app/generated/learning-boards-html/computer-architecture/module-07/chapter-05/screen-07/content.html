Module 7 › Chapter 7.5 › TLB
TLB anatomy
Each entry: VPN tag, PFN, valid bit, protection bits, optional ASID and dirty bit.
Sizes are tiny: typical capacity is 32–128 entries, making fully-associative designs practical.
Associativity choices change the hit rate and hardware complexity; full associativity maximizes hit chance for small sizes.
ASID note
ASIDs identify which process a translation belongs to so TLB flushes on context switch can be avoided.
Example behavior
On a TLB hit, the PFN is available immediately and the processor forms the physical address in roughly the same cycle as a cache tag probe. On a miss, the hardware walks the page table, loads the entry into the TLB, and retries the access. If the page is not present, a page fault is raised and the OS handles loading the page from disk.
Key Takeaway

The TLB makes translation cheap for the common case; its design and size greatly influence average memory-access performance.
