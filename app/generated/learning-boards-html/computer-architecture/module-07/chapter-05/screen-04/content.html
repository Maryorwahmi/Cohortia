Module 7 › Chapter 7.5 › What is virtual memory?
Definition

Virtual memory maps an application's virtual addresses to physical memory frames, enabling isolation and per-page protection. The OS keeps page tables for each process and enforces permissions; swapping moves pages to disk when needed.

Benefit — Isolation
Each process sees a private space and cannot access another process' pages without explicit sharing.
Benefit — Protection
Permission bits prevent unwanted writes or execution; violations trigger faults.
Benefit — Swapping
OS can move pages to disk to increase apparent memory capacity.
Analogy & Example
Think of virtual memory as a set of numbered rooms assigned to guests; the OS maintains a directory mapping room numbers to actual building locations. For example, a process believing it owns addresses from zero up can have its logical page 1 mapped to physical frame 10. If a page is not present, access triggers a page fault and the OS may allocate a frame and load data from disk.
Key Takeaway

Virtual memory separates logical addressing from physical storage, enabling protection and flexible memory management.
