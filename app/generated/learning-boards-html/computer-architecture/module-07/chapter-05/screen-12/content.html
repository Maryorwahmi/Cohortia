Starter code (conceptual)
PAGE_SIZE = 4096  # 12-bit offset
TLB_SIZE = 4
page_table = {1:10, 2:20, 3:30, 4:40, 5:50}

# Example translator function
def translate(virtual_address, tlb, page_table):
  vpn = virtual_address // PAGE_SIZE
  offset = virtual_address % PAGE_SIZE
  if vpn in tlb:
    pfn = tlb[vpn]
    # update LRU
    return (pfn << 12) | offset, True  # hit
  if vpn in page_table:
    pfn = page_table[vpn]
    # insert into TLB with LRU eviction
    return (pfn << 12) | offset, False  # miss, but present
  raise Exception('page fault')
Run the sequence 0x1000, 0x2000, 0x3000, 0x1000, 0x4000, 0x2000, 0x5000 to observe TLB hits and misses, and compute the final hit rate.
What to observe
  • How the TLB state changes after each access.
  • Where hits occur because of temporal locality.
  • How LRU eviction removes the least recently used VPN when capacity exceeds 4 entries.
Key Takeaway

A working translator shows the mechanics: extraction, lookup, TLB caching, misses, and page-fault detection.
