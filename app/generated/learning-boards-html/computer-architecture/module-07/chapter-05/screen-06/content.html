Module 7 › Chapter 7.5 › Page Table Walk
Step-by-step
1. CPU issues virtual address.
2. Probe TLB for VPN → PFN mapping.
3. On hit: form physical address and access memory.
4. On miss: walk page table levels in memory to find PTE.
5. If present, update TLB and retry; if not, raise page fault.
Performance note
Each memory probe during a page-walk increases latency; multi-level tables multiply that cost on misses.
Visualized cards

Data Access

Common mistake

Assuming TLB misses are rare enough to ignore. Even a small miss rate matters because miss penalties are large.
