Module 7 › Chapter 7.5 › Reducing Overhead
Hardware choices
  • Increase TLB size or associativity to raise hit rate.
  • Include ASIDs to avoid flushes on context switches.
  • Support large pages to cover more virtual space per translation.
Software choices
  • Improve spatial locality in data structures so hot data spans fewer pages.
  • Use prefetching and allocate contiguous memory for large working sets.
  • Measure TLB miss rates before choosing hardware vs software fixes.
Key Takeaway

Combine hardware and software tactics to reduce translation cost, always guided by measured miss rates and penalties.
