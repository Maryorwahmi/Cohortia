Module 7 › Chapter 7.5 › Key Concepts
Virtual Memory
Provides per-process address spaces, protection, swapping, and sharing capabilities.
TLB
A small cache of recent VPN→PFN mappings that makes translation fast for common accesses.
Multi-level Tables
Hierarchical tables save memory for large address spaces but increase page-walk cost on misses.
One-sentence takeaway

Balance translation caching, page-table design, and OS policies to keep average memory access fast and safe.
