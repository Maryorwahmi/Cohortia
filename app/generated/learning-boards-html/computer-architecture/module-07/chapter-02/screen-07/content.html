Comparison table (qualitative)
Direct-Mapped
  • Hit rate: lowest
  • Access time: fastest
  • Area/power: smallest
Set-Associative
  • Hit rate: medium
  • Access time: medium
  • Area/power: medium
Fully-Associative
  • Hit rate: highest
  • Access time: slowest
  • Area/power: largest
Design guidance

For latency-critical L1 caches use lower associativity (2–8 ways). For L2, higher associativity is acceptable because the latency budget is larger and conflict reduction can improve performance.

Key takeaway
Key Takeaway

Pick associativity to trade off hit rate against comparator and multiplexer cost; measure diminishing returns as N grows.
