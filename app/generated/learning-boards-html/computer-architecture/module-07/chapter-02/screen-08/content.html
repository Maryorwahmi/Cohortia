Module 7 › Chapter 7.2 › Bit Calculations
Step-by-step checklist
// Given: S (cache bytes), L (line bytes), A (associativity), W (address bits)
offset = log2(L)
lines = S / L
sets = S / (L * A)
index = log2(sets)
tag = W - offset - index
// Include valid + dirty bits per line when computing tag storage
Common pitfall: using lines instead of sets for index when A > 1. Always divide by associativity to get the set count.
Worked example
  • 32 KB, 64‑byte, 4‑way: offset=6, sets=128, index=7, tag=19.
  • Direct (1‑way): sets=512, index=9, tag=17.
  • 8‑way: sets=64, index=6, tag=20.
Key Takeaway

Index width decreases as associativity increases because each set holds more lines; tag width increases accordingly for fixed address width.
