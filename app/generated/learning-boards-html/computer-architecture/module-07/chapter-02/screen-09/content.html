Module 7 › Chapter 7.2 › Area & Tag Overhead
Formulas
Data array bits = S × 8
Lines = S / L
Tag array bits = Lines × (T + 1 valid + 1 dirty)
Total ≈ Data array + Tag array + overhead
Tag overhead percentage = Tag array bits / Data array bits.
Worked numbers
  • 64‑byte lines, 32‑bit address → T ≈ 20 bits; T+2 = 22 bits → overhead = 22 / 512 = 4.3%.
  • 32‑byte lines → overhead ≈ 8.6% because fewer data bits per line.
Key Takeaway

Tag overhead is sensitive to line size. Small lines raise tag overhead; large lines reduce overhead but may increase wasted data movement.
