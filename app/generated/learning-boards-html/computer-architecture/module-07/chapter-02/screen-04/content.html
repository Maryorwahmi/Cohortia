Module 7 › Chapter 7.2 › Direct‑Mapped Cache
Definition & access steps
  1. Extract offset and index from address.
  2. Read the tag and valid bit for the indexed line.
  3. Compare tag; if match and valid, it's a hit; otherwise miss.
  4. On miss, fetch block and replace the line (update valid/dirty accordingly).
Concrete example
32 KB cache, 64‑byte line → 512 lines
Offset = 6 bits, Index = 9 bits, Tag = 32 - 6 - 9 = 17 bits.
Common misconception

Simplicity equals poor performance. In many workloads the simplicity gives lower latency and fewer dynamic power costs, making direct mapping competitive when access patterns are friendly.

Key takeaway
Key Takeaway

Direct mapping is the fastest and simplest mapping. Watch for conflict misses when multiple hot blocks map to the same index.
