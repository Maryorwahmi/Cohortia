Why it matters

Quick formulas
CacheLine = (BlockAddress) mod (NumberOfCacheLines)
Set = (BlockAddress) mod (NumberOfSets)
NumberOfLines = S / L
NumberOfSets = S / (L × A)
Example snapshot
32 KB cache, 64‑byte lines:
  • Lines = 32768 / 64 = 512
  • Direct-mapped: 512 lines, index bits = 9, offset = 6
  • 4-way: sets = 128, index bits = 7
Concept map
Mapping → Hit rate → Cost
Direct-mapped: 1 location per block • fastest comparator
Set-associative: N lines per set • parallel tags
Fully-associative: all lines compared • highest hit rate
