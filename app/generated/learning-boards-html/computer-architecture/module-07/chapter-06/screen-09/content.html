Architecture
Multi-level TLBs

Use L1 for speed and L2 for reach. L2 catches most L1 misses without invoking a page walk, reducing average access cost.

Example design
L1: 32-entry fully-associative, 1-cycle. L2: 512-entry, 4-way, 4 cycles. L1 hits are common; L2 reduces page walks significantly.
Techniques
Large pages reduce entries needed. TLB prefetching fetches nearby page entries. Hardware walkers speed misses.
Performance impact
  • TLB miss penalty can be tens to hundreds of cycles; reducing miss rate has high payoff.
  • Large pages help large working sets but increase fragmentation and reduce alloc flexibility.
  • Prefetching benefits sequential patterns but may waste TLB entries for random access.
Key Takeaway

Calibrate L1 speed and L2 reach to your workload; add large pages or prefetch when memory footprint patterns justify them.
