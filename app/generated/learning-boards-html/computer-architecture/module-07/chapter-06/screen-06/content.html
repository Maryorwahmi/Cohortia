Definition
Virtual caches & aliasing

When caches use virtual addresses for indexing or tagging, two virtual addresses that map to the same physical page can create duplicate cache lines. That causes stale reads and coherence problems.

Concrete example
A process maps the same page at two aliases. Both virtual addresses may be cached; a write through one alias does not update the other cache line unless the system detects the synonym.
Common resolutions
  • Restrict index to page offset bits.
  • Use physical tags (VIPT) so coherence uses physical identity.
  • Tag cache lines with ASIDs or flush on context switch.
Why it matters
Alias-induced inconsistency can silently violate memory model assumptions and correctness. Systems with shared mappings or copy-on-write must guard against stale cache copies.
Key Takeaway

Avoid virtual-tag-only caches in environments with aliases or enforce physical tagging, ASIDs, or flushes to maintain coherence.

Misconception: more associativity alone removes synonyms. Associativity helps conflicts but cannot eliminate duplicates caused by differing virtual indexes for the same physical block.
