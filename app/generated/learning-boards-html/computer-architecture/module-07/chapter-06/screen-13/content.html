Design Guidance
TLB & Cache Checklist

A practical order to make choices and validate them numerically before committing to silicon.

1. Characterize workload
Measure working set pages, streaming vs random access.
2. Compute VIPT feasibility
page_offset_bits - line_offset_bits = index budget.
3. Size L1 vs L2
Small L1 for latency, larger L2 for reach; simulate page counts.
4. Choose associativity
Increase associativity to raise VIPT capacity if area permits.
5. Replacement & ASIDs
Match complexity to hardware; add ASIDs to avoid flushes.
6. Validate
Simulate miss rates and latencies for representative workloads.
Key Takeaway

Design is a sequence: understand workloads, compute constraints, pick parameters, and validate numerically. Avoid optimizing a single metric in isolation.
