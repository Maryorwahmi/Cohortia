What to Remember
Key Concepts — Part 1
TLB parameters
Size, associativity, page sizes, replacement, ASIDs set hit rate and switch cost.
Serial vs Parallel
Parallel access reduces latency only when index bits are within the page offset.
Virtual cache synonyms
Different virtual addresses for the same physical page can cause duplicate cache lines and inconsistency.
Reflection: Which constraint — index bits, associativity, or area/power — will drive your cache/TLB trade-offs?
