Core Concept Stream prefetching
Stream buffers for contiguous flows
Multiple buffers can track independent contiguous streams and reduce early cache pollution.
How stream buffers operate
  • Detect a contiguous access and allocate a stream buffer.
  • Prefetch several subsequent blocks into the stream buffer.
  • Deliver blocks to the cache or CPU on demand, reducing immediate cache insertions.
Practical considerations
Choose the number and size of buffers based on expected parallel streams. Use admission policies to decide when to place prefetched data into the cache to avoid eviction of useful lines.
Common pitfall
Allocating many large stream buffers may cost area and still fail if streams are short or unpredictable.
Key Takeaway

Stream buffers let you track multiple contiguous accesses and delay cache insertion, reducing immediate pollution for stream-friendly workloads.
