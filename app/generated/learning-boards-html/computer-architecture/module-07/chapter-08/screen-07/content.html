Process Flow Prefetch lifecycle
Prefetching: fetch, buffer, and deliver
Measure usefulness by accuracy, timeliness, and pollution effects.
Prefetch stages
  1. Detect pattern from accesses or misses.
  2. Compute next address to prefetch and issue request.
  3. Place fetched block into cache or stream buffer.
  4. Track whether the prefetched block is useful before eviction.
Design knobs include aggressiveness (how many lines ahead), filtering by confidence, buffer sizes for streams, and whether to place data directly in cache or a separate structure to avoid immediate pollution.
Evaluation checklist
  • Hit-rate change
  • Prefetch accuracy = useful / total
  • Bandwidth consumed by prefetches
  • Pollution measured by evicted useful blocks
Key Takeaway

Treat prefetchers as bandwidth consumers. Tune aggressiveness and use confidence or limited buffers to avoid harming demand traffic.
