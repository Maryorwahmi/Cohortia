Comparison Next-line vs others
Next-line prefetching
Low cost, high benefit for contiguous access patterns.
Where it shines
  • Sequential array traversals.
  • Instruction fetch streams.
  • Linear scans in data processing.
Limitations
  • Blind to non-sequential strides.
  • Can waste bandwidth and pollute caches in mixed workloads.
  • May fetch too early; timeliness matters.
Key Takeaway

Use next-line prefetching for predictable spatial locality but throttle it when bandwidth is constrained or access patterns vary.

Example: scanning bytes in memory frequently turns next-line prefetches into useful hits, improving throughput with minimal logic.
