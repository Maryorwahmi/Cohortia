Implementation & Evaluation
Extend the simulator, run four trace types, and compare results with and without prefetching.
Practical milestones
Traces to test
  • Sequential: constant small stride (array traversal)
  • Strided: larger fixed stride (scientific kernels)
  • Random: no pattern
  • Mixed: changing stride patterns
Metrics to collect
  • Hit rate
  • Prefetches issued and useful prefetches
  • Cache pollution measured by evicted useful blocks
  • Bandwidth consumed
Hands-on tip
Use counters to track when a prefetched block is later accessed before eviction; that measures usefulness. Track evictions due to prefetched blocks separately to quantify pollution.
