Process & Code Stride prefetcher
Pseudocode for a simple stride prefetcher
Track last two misses per set, detect constant stride, issue prefetch.
Pseudocode
// On cache miss for address A in set S
prev2 = last_miss[S].older
prev1 = last_miss[S].recent
last_miss[S].older = prev1
last_miss[S].recent = A
if (prev1 != null and prev2 != null) {
  stride = prev1 - prev2
  if (prev1 + stride == A) {
    // detected consistent stride
    // optionally check confidence before issuing
    prefetch_addr = A + stride
    issue_prefetch(prefetch_addr)
  }
}
Implementation notes
  • Keep per-set small state: last two miss addresses and a confidence counter.
  • Place prefetched block in cache or separate buffer to limit pollution.
  • Reset confidence when pattern breaks to avoid long bursts of useless prefetches.
Example traces
Sequential: stride 64. Strided: stride 128. Mixed: stride changes and requires adaptation.
Key Takeaway

Stride prefetchers capture regular deltas well but must include confidence or reset logic to handle changing patterns without wasting bandwidth.
