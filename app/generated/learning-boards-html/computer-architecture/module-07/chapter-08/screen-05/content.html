Definition Victim cache
Small fully-associative buffers that reduce conflict misses
Low-cost alternative to raising global associativity.
How it works
  1. Main cache evicts a block.
  2. Evicted block is inserted into the victim cache.
  3. On a miss, victim cache is checked; on hit swap restores block to main cache.
Concrete example
A 4-entry victim cache may prevent repeated conflict misses when three frequently-used blocks map to the same set in a low-associativity L1 cache, turning thrashing into reusable data in the victim buffer.
When it helps
When conflict misses dominate and the recent eviction working set fits the small victim buffer.
Key Takeaway

Victim caches provide a compact, fully-associative rescue area for evicted lines, improving conflict behavior without redesigning the main cache.

Common misconception: a small victim cache fixes all associativity problems. It only helps if recently-evicted lines are the ones needed again soon.
