Definition Skewed-associative cache
Per-way hashing to spread conflicts
Map sets differently per way so hot addresses disperse across the structure.
Why it helps
  • Reduces the chance that multiple frequently-used lines map to the same set.
  • Achieves some benefits of higher associativity at lower implementation cost.
  • Useful when associativity is the primary source of misses.
Replacement and tag checking become slightly more complex because each way's index differs, but the lookup remains deterministic and efficient with per-way hashed indices.
Analogy
Think of a parking lot with multiple entry ramps, each sending cars to a different set of spaces so that local traffic doesn't congest a single aisle.
Common misconception
Skewing does not make a cache fully associative; it reduces conflict probability but cannot eliminate all collisions.
Key Takeaway

Skewed associativity spreads pressure across ways, reducing conflict misses at modest added complexity.
