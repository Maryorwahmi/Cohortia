Cache Mapping Strategy

Fully-Associative Cache

Maximum flexibility, highest cost

Core Principle

Any memory block can be placed in any available cache line. This offers the greatest flexibility in data placement.

Advantages

  • Eliminates conflict misses entirely.
  • Optimal utilization of cache space.
  • Best possible hit rate for a given cache size (with optimal replacement).

Disadvantages & Use Cases

Requires expensive hardware (N comparators for N cache lines) to search all lines simultaneously. This makes it impractical for large caches due to high cost, power, and complexity.

Used for very small, critical structures like Translation Lookaside Buffers (TLBs) where the number of entries is limited.

Key Takeaway

Fully-associative caches offer the best performance by eliminating conflict misses, but their high hardware cost restricts their use to very small, specialized cache structures.
