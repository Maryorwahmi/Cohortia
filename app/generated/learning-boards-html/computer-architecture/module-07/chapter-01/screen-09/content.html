Cache Mapping Strategy

Direct-Mapped Cache

Simple, but prone to conflict misses

Mapping Formula
Cache Line = (Block Address) mod (Number of Cache Lines)

Each memory block maps to exactly one specific cache line, determined by its address modulo the total number of lines in the cache.

Advantages

  • Simple hardware implementation.
  • Fast lookup and placement.
  • No complex replacement policy needed.

Disadvantage: Conflict Misses

Two frequently accessed memory blocks that map to the same cache line will repeatedly evict each other, even if other cache lines are empty. This significantly degrades performance.

Example: Blocks A and B both map to Cache Line 0. If A is used, then B, then A again, they will constantly replace each other.

Key Takeaway

Direct-mapped caches are simple but suffer from conflict misses, where frequently used data blocks contend for the same cache line, leading to performance degradation.
