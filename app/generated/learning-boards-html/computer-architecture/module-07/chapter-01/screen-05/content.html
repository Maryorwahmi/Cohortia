Fundamental Principle

Temporal Locality

Accessing data again, soon after its first use

Definition

If a memory location is accessed, it is likely to be accessed again in the near future.

Example: Loop Counter

A variable `i` in a `for` loop is accessed, modified, and then accessed again in quick succession for each iteration.

Example: Function Variables

Local variables within a function are repeatedly accessed throughout the function's execution.

Key Takeaway

Temporal locality is the tendency for programs to re-access the same data soon, which caches exploit by keeping recently used data close to the processor.
