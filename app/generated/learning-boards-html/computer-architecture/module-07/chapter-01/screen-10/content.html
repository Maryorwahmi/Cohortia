Cache Mapping Strategy

Set-Associative Cache

Balancing flexibility and complexity

Mapping Formula
Set = (Block Address) mod (Number of Sets)

Each memory block maps to a specific set, and within that set, it can be placed in any of N available cache lines.

How it Works

  • Memory blocks map to a 'set' of cache lines.
  • An 'N-way' cache means each set has N lines.
  • Block can be placed in any of the N lines within its assigned set.

Benefits & Trade-offs

Significantly reduces conflict misses compared to direct-mapped caches by allowing more flexibility in block placement. Requires more complex hardware for searching within a set and for replacement policies (e.g., LRU).

Example: A 2-way set-associative cache allows two blocks mapping to the same set to coexist, avoiding constant evictions.

Key Takeaway

Set-associative caches offer a practical balance, reducing conflict misses by allowing blocks to be placed in any line within a set, at a moderate increase in hardware complexity.
