Address Translation

Deconstructing Memory Addresses for Cache Access

Tag, Index, Offset, Valid Bit, and Dirty Bit

Offset

Low-order bits that select the specific byte within a cache line (e.g., 6 bits for a 64-byte line).

Index

Bits that select the set (or line for direct-mapped) within the cache (e.g., 8 bits for 256 sets).

Tag

High-order bits that uniquely identify the memory block. Stored in the cache to verify a match.

Cache Line Metadata

Valid Bit

Indicates if the cache line contains valid, up-to-date data. If 0, the line is empty or invalid.

Dirty Bit

For write-back caches, indicates if the data in the cache line has been modified and needs to be written back to main memory.

Address Breakdown Example (32-bit address)
Cache: 64-byte lines, 256 sets, 2-way
Offset: 6 bits (2^6 = 64 bytes)
Index:  8 bits (2^8 = 256 sets)
Tag:    18 bits (32 - 6 - 8)
Key Takeaway

Memory addresses are parsed into Tag, Index, and Offset to locate data in the cache, while Valid and Dirty bits manage the state and consistency of cached data.
