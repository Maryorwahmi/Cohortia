Core Challenge

The Processor-Memory Speed Gap

Why memory access is a bottleneck for modern CPUs

Diverging Speeds

Processors follow Moore's Law, doubling speed every ~2 years. Main memory (DRAM) speed improves much slower, creating a widening performance gap.

CPU Idle Time

If every instruction waited for DRAM, CPUs would be idle over 99% of the time, wasting computational power and severely limiting system performance.

The Bottleneck

This speed mismatch is a fundamental challenge, as memory access becomes the primary limiting factor for overall system performance, despite faster processors.

Performance Disparity

Processor vs. Main Memory Access Time

Processor Instruction Execution

~0.3 ns

Main Memory (DRAM) Access

~100 ns

This represents a difference of over 300 times, highlighting the severe performance penalty if data is not readily available to the CPU.

Key Takeaway

The processor-memory speed gap necessitates a hierarchical memory system to keep the CPU busy and maximize computational throughput.
