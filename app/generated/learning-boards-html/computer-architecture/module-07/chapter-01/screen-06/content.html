Fundamental Principle

Spatial Locality

Accessing data near previously accessed locations

Definition

If a memory location is accessed, nearby locations are likely to be accessed soon.

Example: Array Traversal

Iterating through an array accesses elements sequentially, one after another, in contiguous memory.

Example: Instruction Fetching

Programs execute instructions sequentially, meaning the next instruction is usually located right after the current one in memory.

Key Takeaway

Spatial locality is the tendency for programs to access nearby data, which caches leverage by fetching entire blocks (cache lines) of data at once.
