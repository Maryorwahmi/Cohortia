System Structure

The Memory Hierarchy Pyramid

Levels of speed, size, and cost

Registers

~1 KB | ~0.3 ns | SRAM | Compiler

L1 Cache

~32 KB | ~1 ns | SRAM | Hardware

L2 Cache

~256 KB | ~4 ns | SRAM | Hardware

L3 Cache

~8 MB | ~15 ns | SRAM | Hardware

Main Memory

~16 GB | ~100 ns | DRAM | Hardware/OS

SSD/HDD

~1 TB | ~10 μs-10 ms | Flash/Magnetic | OS

Key Takeaway

Each level of the memory hierarchy offers a trade-off between speed, size, and cost, working together to provide efficient data access to the processor.
