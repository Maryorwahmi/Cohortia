Calculating Average Memory Access Time (AMAT)

The true cost of memory access

AMAT Formula
AMAT = Hit Time + Miss Rate × Miss Penalty

This formula combines the speed of cache hits with the cost of cache misses to give an overall average memory access time.

Example Scenario

  • L1 Cache Hit Time: 2 cycles
  • L1 Cache Miss Rate: 5% (0.05)
  • Miss Penalty (to next level): 100 cycles

Calculation

AMAT = 2 + 0.05 × 100
AMAT = 2 + 5
AMAT = 7 cycles

Even a small miss rate can significantly increase the average access time due to the high miss penalty.

Key Takeaway

AMAT is the most critical metric for memory system performance, highlighting the disproportionate impact of cache misses on overall CPU efficiency.
