Write policies: implement and measure

Replacement strategies: implement and compare
Build LRU, FIFO, Random. Run traces and compare miss rates and pathological cases.
3
Miss classification and optimization
Label each miss as compulsory, capacity, or conflict and test victim caches, associativity, and prefetching to see which reduces which miss type.
Trace checklist
  • Trace A: sequential, tests spatial locality
  • Trace B: random, shows lack of locality
  • Trace C: cyclic conflict, exposes mapping conflicts
Record miss rates per configuration, annotate the dominant miss type, and recommend the most effective single change for each trace.
