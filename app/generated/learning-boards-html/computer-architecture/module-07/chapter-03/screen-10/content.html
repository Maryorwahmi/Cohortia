Module 7 › Chapter 7.3 › Non-Blocking Cache
Architecture
MSHRs and outstanding misses
Record outstanding misses and continue to serve independent hits to increase throughput.
MSHR duties
Track address, pending requesters, and merge duplicate requests to avoid extra memory traffic.
Limitations
Finite MSHRs cause backpressure; you must model this limit in the simulator.
Misconception: non-blocking caches eliminate all stalls. They improve parallelism but require enough outstanding independent requests to be effective.
Lab task
Add MSHR bookkeeping to track outstanding misses, merge duplicate requests, and cap the number of entries. Compare throughput and effective latency with a blocking cache under multi-request traces.
Key Takeaway

Non-blocking caches increase memory-level parallelism but need MSHR limits and request-merging to be modeled correctly.
