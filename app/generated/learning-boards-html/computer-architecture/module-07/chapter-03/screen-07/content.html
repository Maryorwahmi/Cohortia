Module 7 › Chapter 7.3 › Write Allocation
Definition
Write-Allocate vs No-Write-Allocate
Decide whether a write miss should bring the block into cache or write directly to memory.
Write-Allocate
Fetch the block on a write miss, perform the write in cache. Pairs well with write-back.
No-Write-Allocate
Write directly to memory on a miss and do not cache the block. Often used with write-through.
When to choose which
  • Write-allocate helps if the line will be accessed again soon.
  • No-write-allocate avoids polluting the cache for one-shot writes or streaming writes.
Example
A video encoder writing sequential frames may never reread the same line; no-write-allocate keeps those writes out of cache. A data structure that is updated and read soon after benefits from write-allocate and write-back to reduce memory writes.
Key Takeaway

Match allocation policy to write reuse: allocate when reuse is likely; avoid allocation for one-shot writes.
