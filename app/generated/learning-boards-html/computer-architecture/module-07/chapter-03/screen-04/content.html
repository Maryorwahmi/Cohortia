Module 7 › Chapter 7.3 › 3C Model
Definition
Compulsory, Capacity, Conflict
Classify each miss by cause so you can apply a targeted fix rather than guessing.
Compulsory (cold-start)
First-time access. Reduce by larger line size or prefetching.
Capacity
Working set bigger than cache. Fix by increasing cache size or improving locality.
Conflict
Multiple blocks map to same set. Fix by higher associativity or layout padding.
Key Takeaway

Diagnose before you optimize: each miss type calls for different remedies.

Walkthrough & example
Example scenario: A program sequentially reads a new array — the first accesses are compulsory. If the array is larger than cache, later accesses become capacity misses. If two arrays map to the same sets, alternating accesses cause conflict misses. Tagging misses in a simulator lets you see this progression and verify which component dominates.
Misconception
Treating misses as a single rate hides whether bandwidth or mapping is the real problem.
Pro tip
When classifying, mark the very first access to each block as compulsory to avoid mislabeling later misses.
Check your understanding
If increasing line size reduces misses significantly for your trace, which miss type likely dominated? (Answer: compulsory/spatial locality.)
