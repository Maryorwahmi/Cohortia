List sizes, associativity, line sizes, and write policy. Use the 3C model to explain miss behavior.

Compute AMAT = L1_hit_time + L1_miss_rate * (L2_hit_time + L2_miss_rate * DRAM_penalty).
Explain prefetcher strategy and replacement policy and how they alter miss rates.
Example calculation
Assume L1 hit time 1 cycle, L1 miss rate 5%, L2 hit time 6 cycles, L2 miss rate 20%, DRAM penalty 200 cycles. AMAT = 1 + 0.05*(6 + 0.20*200) = compute and convert to CPI impact using memory accesses per instruction.
Misconception: Bigger caches always win. Reality: trade-offs include higher access latency, area, and diminishing returns for capacity misses.
