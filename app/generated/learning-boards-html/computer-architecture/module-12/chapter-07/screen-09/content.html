Module 12 › Chapter 12.7 › Branch Prediction
Definition

Predictor type, size, and CPI contribution

State chosen predictor and table sizes; compute misprediction rate and its cycles-per-instruction effect using pipeline penalty.

  • List predictor type and table sizes used in your analysis.
  • Show misprediction penalty based on pipeline depth and how it multiplies the misprediction rate.
  • Report accuracy assumptions and how you measured or estimated them.
Concrete example: 14-stage pipeline, 4% mispredict rate gives 0.56 cycles per instruction penalty for branch stalls (14 * 0.04), to be added to base CPI.
Misconception: Complex predictors always pay off. Reality: area and power costs can outweigh the small accuracy gains in certain domains.
Takeaway: Report predictor parameters, accuracy, penalty, and CPI contribution so reviewers can judge the trade-off.
