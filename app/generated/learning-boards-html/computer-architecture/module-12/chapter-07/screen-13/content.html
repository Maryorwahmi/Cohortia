Module 12 › Chapter 12.7 › Roofline Model
Definition

Roofline: operational intensity and ceilings

Calculate arithmetic intensity for representative kernels, then place those points relative to compute and memory roofs drawn using your projected peak and sustained bandwidths.

Compute arithmetic intensity = FLOPs / bytes moved for the kernel in your workload.
Plot the point and determine if performance is limited by compute or memory bandwidth.
Concrete guidance
If a kernel is memory-bound on your roofline, prioritize bandwidth or local SRAM. If compute-bound, prioritize ALU/vector resources and instruction throughput.
Misconception: Using peak theoretical bandwidth is optimistic; instead use realistic sustained bandwidth under contention for the roofline ceiling.
