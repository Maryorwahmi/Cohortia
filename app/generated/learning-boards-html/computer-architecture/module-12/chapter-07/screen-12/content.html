Process

Use Amdahl's Law to rank optimizations

Compute the fraction of runtime an optimization can affect and use it to estimate maximum speedup. Create a sensitivity table for key knobs.

Example: If memory stalls are 40% of runtime, eliminating them yields max speedup 1/(1-0.40)=1.67× overall.
Tornado chart: list cache size, predictor accuracy, pipeline depth, memory channels, and show percent change in projected performance across realistic ranges.
Takeaway: Focus on optimizations that affect the largest fraction of runtime; document assumptions and show diminishing returns clearly.
