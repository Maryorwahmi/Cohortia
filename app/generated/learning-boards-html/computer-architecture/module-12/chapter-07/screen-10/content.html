Architecture

Channels, bandwidth, and prefetchers

State channel count and bus width and compute peak bandwidth versus workload demand. Include prefetcher design and expected benefit.

  • Compute peak bandwidth: channels × channel_bandwidth. Compare to sustained demand from representative kernels.
  • Describe prefetching strategy and estimate percent of cache misses avoided.
  • Estimate DRAM latency and fold into AMAT to show CPI impact.
Example
If a matrix kernel requires 50 GB/s sustained and each channel provides 12.8 GB/s, show you need at least four channels plus headroom for contention and other traffic.
Misconception: More channels always fix bandwidth issues. Reality: Amdahl-style serial sections, interconnect contention, and memory controller limits can still create bottlenecks.
