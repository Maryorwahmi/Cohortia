Comparison

Compare ISAs against domain priorities

Create a table that maps each ISA to energy, customization ability, toolchain maturity, and expected pipeline complexity.
Example: RISC-V — high customizability, good for adding tensor instructions; need to justify toolchain support.
Example: ARM — strong mobile ecosystem and energy-optimized cores, useful for mobile/embedded baselines.
Checklist
  • State chosen ISA and the specific reasons tied to workload and constraints.
  • Explain how ISA choices affect microarchitecture and compiler expectations.
  • Note any custom instruction sets or extensions and justify them with a quantifiable benefit.
Takeaway: Show how the ISA enables your microarchitectural choices and how you will measure its impact.
