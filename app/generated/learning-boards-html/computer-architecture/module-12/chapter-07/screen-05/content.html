Comparison

Required deliverables

Each deliverable must be explicit and reproducible: avoid vague language and include assumptions and baselines.
  • Architecture Spec: ISA, pipeline stages, in-order/OoO, caches, branch predictor, memory interfaces.
  • Quantitative Analysis: CPI breakdown, AMAT, 3C model, Amdahl analysis, roofline expectations.
  • Area & Power: area per component and estimated power using stated densities.
  • Performance Projection: expected benchmark score and sensitivity analysis.
Example detail
Specify cache line size and associativity (e.g., L1 D: 32KB 8-way 64B line, write-back). Use that to compute AMAT and include hit/miss rates used in the calculation.
Misconception: A bigger cache always reduces CPI. Reality: area and access latency trade-offs can make larger caches worse for some IPC targets.
Takeaway: Explicit numbers and assumptions make your report verifiable and defensible.
