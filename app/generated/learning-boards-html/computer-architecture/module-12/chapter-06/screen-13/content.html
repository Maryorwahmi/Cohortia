Key metrics
  • IPC — instructions per cycle, primary performance metric.
  • Execution time — wall-clock time for a workload, complements IPC.
  • Power and energy — watts and joules for runtime cost.
  • Area — use proxies like cache bytes and issue-width related area for quick comparisons.
Speedup-per-area example
If baseline_time = 100s and variant_time = 80s, speedup = 100/80 = 1.25. If variant doubles L1 (area factor 1.2 overall when combined with other structures), then speedup-per-area = 1.25 / 1.2 ≈ 1.04. Rank variants by this metric to evaluate performance efficiency under area constraints.
Caveat
Area proxies are approximations. If precise area matters, use detailed layout or synthesis estimates to refine comparisons.
