Module 12 › Chapter 12.6 › Learning Objectives — Practical Skills
Task flow
  1. Choose representative benchmark(s) that exercise the microarchitecture.
  2. Specify metrics: IPC, execution time, power, energy, and area proxies.
  3. Run baseline and variants using sampling to reduce runtime.
  4. Analyze results and identify Pareto-optimal candidates.
Assessment idea

Explain why SimPoint sampling reduces simulation time drastically while preserving accuracy, and show a Pareto plot. Demonstrate a short experiment doubling cache sizes or issue width and report IPC and speedup-per-area.

Key Takeaway

Practical experiments combine representative workloads, sampling, and Pareto analysis to make design choices defensible.
