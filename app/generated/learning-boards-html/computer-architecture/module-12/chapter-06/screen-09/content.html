SimPoint (phase sampling)
SimPoint finds representative program phases via basic block vectors. It clusters execution behavior and selects short simulation points that represent the whole run. This reduces runtime dramatically while preserving accuracy; published studies report less than 3% error in many cases.
When to use
Programs with stable phases across configurations; validate with some full runs.
SmartSim & regression
SmartSim uses machine learning to predict performance from a small set of simulations. Regression and surrogate models fit functions to data and estimate performance for untested points. These methods can reduce simulations by 10–100× depending on model quality.
Practical tip
Always reserve a few validation runs to measure the surrogate model's error before trusting predictions.
