Experiment plan
  • Baseline: 2 GHz, 4-issue, 128 ROB, 32 KB L1, 256 KB L2, 8 MB L3.
  • Variant A: L1 = 64 KB. Variant B: L2 = 512 KB. Variant C: L3 = 16 MB. Variant D: issue width = 8.
  • Run benchmark, collect IPC and execution time, compute speedups and speedup-per-area.

# Example invocation (conceptual)

# Repeat with variants by changing l1-size, l2-size, l3-size, or issue-width
Analysis card
Compute speedup = baseline_time / variant_time, and speedup-per-area = speedup / (relative area). Assume area proportional to cache bytes and issue-width when comparing variants. Use plots or a small table to find Pareto-optimal candidates.
Pro-tip
Isolate one parameter per variant so you can attribute performance changes reliably; validate sampling assumptions with at least one full run per benchmark.
