Module 12 › Chapter 12.6 › Core Design Parameters
Parameter hierarchy
Pipeline depth (5–20)
Affects clock potential and branch penalty; deeper pipelines may improve frequency but increase misprediction cost.
Issue width (1–8)
More parallelism capacity but higher area and diminishing returns without parallelism in code.
Cache sizes & associativity (8 KB–64 MB, 1–32 way)
Larger caches reduce misses; associativity reduces conflict misses at area cost.
Buffers and bandwidth
ROB size (40–900)
Larger ROB increases instruction window for out-of-order execution, improving IPC until diminishing returns.
Branch predictor (1K–64K)
Larger predictors reduce mispredictions but add area and power.
Memory bandwidth (10–1000 GB/s)
Caps throughput for memory-bound workloads; adding bandwidth helps those workloads but increases cost.
Key Takeaway

Choose parameters to explore based on likely bottlenecks and the interactions that affect your workload's behavior.
