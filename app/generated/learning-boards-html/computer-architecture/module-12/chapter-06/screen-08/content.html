Module 12 › Chapter 12.6 › Simulation Methodology
Five-step process
1. Select benchmarks
Pick representative suites like SPEC CPU, PARSEC, or focused kernels to exercise the microarchitecture.
2. Choose metrics
IPC, power, energy, and area proxies. Decide which metric is primary and which are constraints.
3. Configure simulator
Set clock, issue width, ROB size, cache sizes and other parameters for baseline and variants.
4. Run simulations
Use sampling to reduce time; run full detailed simulations for validation points.
5. Analyze results
Compute speedups, normalize by area or energy, and identify Pareto-optimal designs.
Concrete baseline used in the lab
Base: 2 GHz, 4-issue, 128-entry ROB, 32 KB L1, 256 KB L2, 8 MB L3. Variants adjust cache sizes or issue width, then measure IPC and execution time to compute speedup and speedup-per-area.
Pitfall
Comparing raw IPC without accounting for area or power can mislead decisions when those are constraints.
