Starter commands
# baseline counters
perf stat -e cpu-cycles,instructions ./matrix_program

# add cache counters
perf stat -e cpu-cycles,instructions,L1D_CACHE_LOAD_MISS,L2_RQSTS_MISS,LLC_MISSES ./matrix_program

# record samples for hotspots
perf record -g ./matrix_program
perf report
Experiment steps
Measure baseline, identify bottleneck with Top-Down, apply one optimization (e.g., blocking), re-measure, and compare the same counters.
Expected observation
If the kernel is LLC bound, expect high LLC_MISSES and low IPC before blocking; after blocking LLC_MISSES should fall and IPC should rise.
Key takeaway
Practice the full loop: measure, hypothesize with Top-Down, change one factor, re-measure to confirm improvement.
