Top-Down Method
A hierarchy that guides diagnosis from a high-level symptom to a specific cause.
Front-End Bound
Causes: instruction cache misses, branch mispredictions, decode bottlenecks.
Back-End Bound
Causes: memory stalls or core execution limits. Drill into Memory vs Core.
Bad Speculation
Causes: branch mispredictions or memory disambiguation failures causing wasted work.
Retiring
Useful work completes. High retiring is good, but check IPC for efficiency.
How to use it
  1. Collect baseline counters like cycles, instructions, and cache misses.
  2. Compute top-level percentages to see which category dominates.
  3. Drill down into the indicated branch with focused counters for the next level.
Key takeaway
The method converts many counters into a short diagnostic path to direct optimizations.
