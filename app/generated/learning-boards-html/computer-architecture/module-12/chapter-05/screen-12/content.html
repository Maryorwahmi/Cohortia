Module 12 › Chapter 12.5 › Optimization Loop
Measure → Identify → Optimize → Verify
A disciplined sequence to ensure changes produce measurable gains.
Measure
Collect cycles, instructions, and cache events for a stable baseline.
Identify
Use Top-Down and ratios to find front-end, back-end, speculation, or retiring issues.
Optimize
Apply targeted changes: blocking for memory, unrolling for core, branch rewrites for speculation.
Verify
Re-run identical measurements to confirm reduced stalls and improved IPC.
Practical tip
Change one variable at a time and keep input data and CPU configuration identical between runs to attribute changes correctly.
Key takeaway
A disciplined loop prevents wasted effort and proves that optimizations actually worked.
