Module 12 › Chapter 12.5 › Hardware Counters
What are hardware counters?
Small on-chip registers that tally microarchitectural events without changing program logic.
Examples of events
  • CPU_CLK_UNHALTED — cycles when the core is running
  • INST_RETIRED — instructions committed
  • L1D_CACHE_LOAD_MISS — L1 data cache misses
  • BR_MISP_RETIRED — branch mispredictions retired
Concrete example
Run a matrix kernel and collect cycles and instructions. From those counts compute CPI to judge how many cycles each instruction costs on average, and use cache miss counters to see if memory accesses are causing stalls.
Common mistake
Treating raw counts as the final answer. Counters need ratios and context; they are evidence, not proof by themselves.
Inspector panel
How to start
Begin with cycles, instructions, and a single cache-level miss counter. Compute CPI and IPC before collecting many specialized counters.
Key takeaway
Counters are precise measurements; interpreting them with ratios is how you find real bottlenecks.
