Module 12 › Chapter 12.5 › Common Counters
Key counters
Counters you will collect first and how to read them.
CPU_CLK_UNHALTED
Total active cycles — use as time base to compute CPI or IPC.
INST_RETIRED
Committed instructions — compare with cycles to compute CPI or IPC.
L1/L2/LLC miss counters
Track where cache misses occur; their ratios identify the level causing most stalls.
BR_INST_RETIRED / BR_MISP_RETIRED
Branch counts and mispredictions reveal wasted speculative work and control flow penalties.
Interpretation panel
Concrete scenario
Many LLC misses with low L1 misses suggest working sets exceed caches and data is being streamed from memory; this points to LLC misses as the optimization target.
Misconception
A high number of a single event without context can mislead; always compute ratios like miss rates or CPI before concluding.
Key takeaway
Use a short focused set of counters to form a hypothesis, then drill down with additional counters if needed.
