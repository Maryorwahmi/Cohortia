Module 12 › Chapter 12.5 › Using perf
Key commands
perf stat ./program
perf stat -e cpu-cycles,instructions,cache-references,cache-misses ./program
perf record ./program
perf report
Quick workflow
Baseline perf stat → add cache and branch events → perf record to find hotspots → optimize → re-run same stats to verify.
Practical checklist
  • Keep inputs and CPU settings identical between runs.
  • Collect a small, focused set of counters first.
  • Use recorded profiles to map counter hotspots to code locations.
Common mistake
Comparing runs with different input sizes or CPU scaling can lead to incorrect conclusions.
