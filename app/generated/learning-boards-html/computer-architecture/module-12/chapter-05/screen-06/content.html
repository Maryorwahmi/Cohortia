Module 12 › Chapter 12.5 › Metrics
Compute these ratios
Use these formulas to convert counters into metrics you can reason about.
CPI
Formula: CPU_CLK_UNHALTED / INST_RETIRED. Higher CPI means more cycles per instruction.
IPC
Formula: INST_RETIRED / CPU_CLK_UNHALTED. IPC is instructions per cycle; higher is usually better.
Miss & misprediction rates
Branch mispredict rate = BR_MISP_RETIRED / BR_INST_RETIRED. L1 miss rate = L1D_CACHE_LOAD_MISS / MEM_LOAD_RETIRED.
Concrete calculation
# Example counts from one run
CPU_CLK_UNHALTED = 2_000_000_000
INST_RETIRED   =   500_000_000

CPI = CPU_CLK_UNHALTED / INST_RETIRED = 4.0
IPC = INST_RETIRED / CPU_CLK_UNHALTED = 0.25

# Interpretation: low IPC, many cycles per instruction — investigate stalls
Key takeaway
Use ratios to translate raw counts into the program's efficiency and to direct further measurement.
