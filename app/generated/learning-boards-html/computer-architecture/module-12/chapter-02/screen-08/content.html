Multi-level trade-offs
Level 1: tiny, fastest, expensive per bit. Level 2: larger, slower. Level 3: bigger, slower still. DRAM stores the rest. This tiering yields near-SRAM speed at near-DRAM cost.
  • Hit rate × latency determines effective access time.
  • Design line size by measuring access stride and spatial locality.
  • Associativity reduces conflict misses at area cost.
Example calculation
If L1 hit rate rises by 5% and L1 latency is 1 cycle versus 50 cycles for DRAM, estimate runtime reduction and plug into Amdahl to see whole-system impact.
Analogy
Think of cache as a small express lane that most travelers use; the main road handles the rest more slowly.
Misconception
A larger cache is not always better if the working set fits a smaller cache; cost and latency matter more than raw size.
