Formula for maximum
Set s → ∞ to get Speedup_max = 1 / (1 - f). This is the asymptotic limit when the improved section becomes instantaneous.
  • f = 0.4 → max = 1 / 0.6 = 1.67×
  • f = 0.6 → max = 1 / 0.4 = 2.5×
  • f = 0.9 → max = 1 / 0.1 = 10×
Design implication
If the ceiling is low, invest elsewhere. If ceiling is high, additional investment might be justified—especially if raising f is possible by algorithmic changes.
Misconception check
Don't assume infinite hardware makes an infinte system faster. The rest of the program still runs.
