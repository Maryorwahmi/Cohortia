Temporal locality
Recently accessed data is likely to be used again. Caches store recent lines to speed repeated accesses.
  • Works well for loops and repeated data structures.
  • Look for reuse windows in profiling to estimate benefit.
Spatial locality
Nearby addresses are likely to be used together. Fetching blocks amortizes long memory latency.
  • Influences cache line size and prefetch policies.
  • Strided accesses can reduce effective spatial locality.
Cache design implications
Choose line size, associativity, and levels to match expected locality. Small fast caches capture working sets; larger slower levels store the rest.
Key Takeaway

Locality is the reason a small amount of fast memory yields outsized performance when it captures the working set.
