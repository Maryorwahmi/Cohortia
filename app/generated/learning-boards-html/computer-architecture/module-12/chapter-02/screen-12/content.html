Module 12›Chapter 12.2›Cost-Performance
Metric definition
Performance per dollar = measured performance / incremental cost. Performance per watt = measured performance / power draw. Use marginal values for accurate trade-offs.
  • Compute expected performance gain using Amdahl before comparing costs.
  • Divide improvement by extra dollars or watts to get marginal return.
Practical example
If Option A gives 10% gain for 50% more cost and Option B gives 8% gain for 10% more cost, Option B might offer better performance per dollar.
Pitfall
Benchmarks that exercise unusual hotspots can mislead cost-performance calculations for typical users.
Key Takeaway

Always compute marginal performance per dollar/watt and weigh it against market and power constraints before committing to expensive changes.
