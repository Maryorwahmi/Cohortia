Design choices
As transistor budgets grow, choose whether to add cores, widen issue width, or increase cache capacity. Each choice targets different bottlenecks.
  • More cores → better throughput for multi-threaded workloads.
  • Wider issue → boosts single-thread ILP when dependencies allow.
  • Larger caches → reduce memory-bound fractions for many workloads.
Consider power and software
Transistor growth must be matched to power budgets and software that can exploit it; otherwise returns will be limited.
Timeline
Plan modular designs so future transistor increases can be applied where they yield the largest f-weighted benefit.
Key Takeaway

Anticipate scaling: design choices should let you apply more transistors where measured workloads will benefit most.
