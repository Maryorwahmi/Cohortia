Problem
Runtime fractions: int 30%, fp 20%, mem 30%, branches 20%. Options: A: int×2, B: fp×4, C: mem×2, D: branches×3.
Option A (int 0.3, s=2): Speedup = 1 / (0.7 + 0.3/2) = 1.176×
Option B (fp 0.2, s=4): Speedup = 1 / (0.8 + 0.2/4) = 1.176×
Option C (mem 0.3, s=2): Speedup = 1.176×
Option D (branches 0.2, s=3): Speedup ≈ 1 / (0.8 + 0.0667) ≈ 1.163×
Interpretation
Several options tie because a larger local s applied to a small f can match a modest s applied to a larger f. Choose the option with the best marginal performance per cost and implementation complexity.
Key Takeaway

Always compute numeric speedups for each candidate and then compare their marginal returns, not just local speedup factors.
