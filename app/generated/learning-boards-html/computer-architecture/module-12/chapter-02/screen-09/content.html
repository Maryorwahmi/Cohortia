Module 12›Chapter 12.2›Common Case Fast
Principle explained
Make the operations that occur most often very fast. This boosts average performance and gives the best return on investment when guided by measurements.
  • RISC: simple common instructions optimized.
  • Branch prediction: tuned for predictable looping behavior.
  • Caches: optimize for the working set, not every possible access pattern.
Analogy
Think of an express lane for frequent commuters; optimizing it helps most travelers even if the occasional user waits longer.
Common mistake
Prioritizing exotic features that few users exercise wastes area, power, and design time.
