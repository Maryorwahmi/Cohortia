Case A: memory 40%
If memory (f=0.4) is improved by 2× (s=2):
Speedup = 1 / ((1 - 0.4) + 0.4 / 2)
        = 1 / (0.6 + 0.2)
        = 1.25×
Max (s→∞) = 1 / (1 - 0.4) = 1.67×
Case B: compute 50%
If compute (f=0.5) is improved by 2× (s=2):
Speedup = 1 / ((1 - 0.5) + 0.5 / 2)
        = 1 / (0.5 + 0.25)
        = 1.33×
Max (s→∞) = 1 / (1 - 0.5) = 2×
Interpretation
  • Higher f yields larger whole-program impact for the same s.
  • Infinite local speedup is still bounded by 1/(1-f).
  • Profiling accuracy matters: misestimating f misleads optimization choices.

When given three candidate optimizations, compute each overall speedup and rank them. The highest local s may lose to the option with the largest f.
