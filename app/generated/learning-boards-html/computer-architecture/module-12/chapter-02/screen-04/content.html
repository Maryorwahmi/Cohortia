Module 12›Chapter 12.2›Amdahl's Law
Definition
Amdahl's Law: overall speedup = 1 / ((1 - f) + f / s). Use f from measured runtime fractions.
  • Define f precisely: fraction of total runtime affected by the improvement.
  • Define s: how many times faster that fraction becomes after improvement.
  • Measure f using profiling, not guesswork.
Concrete Example
// Example numbers
// f = 0.4 (memory), s = 2
Speedup = 1 / ((1 - 0.4) + 0.4 / 2)
        = 1 / (0.6 + 0.2)
        = 1.25×

// If s -> infinity, max = 1 / (1 - 0.4) = 1.67×
Common misconception
Speedups on different components do not simply add; they combine according to the runtime fraction each affects. Failing to weight by f leads to overoptimistic forecasts.
Key Takeaway

Always compute the affected fraction f from measurements before estimating benefit; that's the most important input to Amdahl's Law.
