Apply common-case-fast
Justify making frequent operations very fast, knowing rare cases must remain correct. This improves average performance for real workloads.

Analyze cost-performance
Use metrics like performance per dollar or per watt to balance gains with cost. This prevents expensive, low-return optimizations.
