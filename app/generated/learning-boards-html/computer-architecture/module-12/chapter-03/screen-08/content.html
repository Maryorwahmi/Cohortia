Module 12 › Chapter 12.3 › Sub-Rooflines
What are sub-rooflines?
They are additional ceilings for L1 and L2 bandwidth, and for in-core execution limits, that refine which resource is actually constraining the kernel.
When to use them
If a kernel is below peak but above the main memory line, check cache-level bandwidth and in-core issues — a sub-roofline will reveal the real bottleneck.
Pro tip
Measure bandwidth at each cache level if possible. If not, reason from access patterns: streaming accesses hit main memory; tight reuse may hit L1/L2.
Hierarchy of ceilings
L1 bandwidth ceiling
Applies when working set fits in L1; limited by core-to-L1 transfer rates.
L2 bandwidth ceiling
Applies when L1 misses but L2 hits; can be the dominant limiter for some tiled workloads.
In-core parallelism ceiling
Represents limits from issue width, pipeline stalls, or missing FMA instructions that reduce achievable GFLOPS.
