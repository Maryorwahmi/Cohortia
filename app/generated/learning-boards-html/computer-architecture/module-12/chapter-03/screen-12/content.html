Module 12 › Chapter 12.3 › Construct a Roofline
Steps
  1. Measure peak compute (GFLOPS) or use vendor spec.
  2. Measure sustainable memory bandwidth (GB/s) with STREAM or use spec.
  3. Compute ridge = peak / bandwidth (FLOPs/byte).
  4. Compute operational intensity for each kernel.
  5. Plot kernels and choose optimizations based on placement.
Example checklist
Record precision assumptions, count reads vs writes, and note whether caches are warmed — these choices affect traffic estimates.
Scenario card
If your matrix multiply is compute-bound but achieves far below peak, try vendor BLAS first. If vector kernels are slow, prioritize reducing memory traffic.
Reflection
