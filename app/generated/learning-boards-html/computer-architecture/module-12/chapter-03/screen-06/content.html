Module 12 › Chapter 12.3 › Operational Intensity
Formula
Operational Intensity = Total Operations / Total Memory Traffic (bytes)
Be explicit: count reads and writes and convert elements to bytes using precision size.
Misconception: assuming cache makes memory traffic negligible. Cache changes the effective traffic, but you must model what is actually loaded from each level.
Matrix multiply derivation
Operations = 2N³. Memory traffic ≈ 3N² × 8 bytes. So intensity = N/12 FLOPs/byte.
Example: N=1024 → intensity ≈ 85.3 FLOPs/byte.
Vector add derivation
Operations = N. Memory traffic ≈ 3N × 8 bytes. So intensity = 1/24 ≈ 0.042 FLOPs/byte.
Try this
Compute the intensity for N=256 and N=4096 to observe how matrix intensity scales linearly with N while vector intensity is constant.
