Module 12 › Chapter 12.3 › Matrix Multiply vs Vector Add
Matrix multiply (N×N)
Operations ≈ 2N³, traffic ≈ 3N²×8 bytes → intensity ≈ N/12 FLOPs/byte. For large N this is high and compute-bound.
Optimization focus: high-quality vendor BLAS, blocking/tiling, vectorization, and FMA.
Vector addition (N elements)
Operations = N, traffic ≈ 3N×8 bytes → intensity ≈ 1/24 ≈ 0.042 FLOPs/byte. Remains memory-bound regardless of N.
Optimization focus: reduce memory traffic, aligned streaming, and minimizing writes.
