Measure and compute the ridge point
Ridge point = Peak compute / Memory bandwidth. It is the operational intensity where the model transitions.
Example: 100 GFLOPS / 25 GB/s = 4 FLOPs/byte.
Calculate operational intensity
Operational intensity = total operations / total bytes moved. Apply to simple formulas for matrices and vectors.
Example: Dense N×N matrix multiply gives intensity proportional to N.
Map optimizations to the roofline
Cache blocking and tiling increase intensity; vectorization and FMA increase achieved compute.
Mnemonic: move right to reuse data; move up to use the CPU more fully.
Use sub-rooflines to pinpoint bottlenecks
Add L1 or L2 bandwidth ceilings and in-core ceilings to find narrower limits inside the system.
This helps when a kernel hits cache bandwidth before reaching compute peak.
