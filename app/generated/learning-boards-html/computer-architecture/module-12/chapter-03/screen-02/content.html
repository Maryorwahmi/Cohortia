Module 12 › Chapter 12.3 › Learning Objectives
01
Construct and interpret a roofline model
Find peak compute and memory ceilings, compute the ridge point, and read performance limits for a workload.
Mnemonic: axis-map (performance vs intensity).
Verified competency milestone
02
Identify compute-bound vs memory-bound workloads
Use operational intensity to determine whether a workload follows the memory slope or hits the compute cap and why that distinction matters.
Mnemonic: slope vs cap.
Verified competency milestone
03
Use the roofline to guide optimizations
Decide whether to increase data reuse or compute utilization based on where the kernel sits on the roofline.
Mnemonic: move right to increase intensity; move up to increase throughput.
Verified competency milestone
04
Calculate operational intensity
Apply the formula operations divided by bytes moved to common algorithms like matrix multiply and vector add.
Mnemonic: ops per byte.
Verified competency milestone
