Module 12 › Chapter 12.3 › Optimizing Memory-Bound Workloads
Techniques to increase intensity
  • Cache blocking / loop tiling to reuse data in cache.
  • Reorder loops to increase spatial and temporal locality.
  • Reduce writes and temporaries; use in-place updates when safe.
  • Change data layout to improve contiguous access patterns.
When hardware helps
Use wider memory channels or HBM where available to raise the diagonal slope. This moves the diagonal ceiling upward, benefiting low-intensity code directly.
Common pitfall
Adding more parallel threads without increasing bandwidth often increases contention and may not improve memory-bound kernels.
