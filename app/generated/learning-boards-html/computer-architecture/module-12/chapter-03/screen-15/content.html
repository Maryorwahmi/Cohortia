Module 12 › Chapter 12.3 › Key Concepts
Roofline model
A visual upper bound combining memory and compute ceilings to locate performance limits.
Operational intensity
Operations per byte of memory traffic; compute as total ops / total bytes.
Ridge point
Peak compute divided by memory bandwidth; the intensity that separates regimes.
Summary takeaway
Use these core concepts to plot kernels and choose whether to prioritize data reuse or better compute utilization.
