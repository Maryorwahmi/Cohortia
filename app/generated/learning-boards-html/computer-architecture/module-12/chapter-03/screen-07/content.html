System numbers
Peak compute
100 GFLOPS
Memory bandwidth
25 GB/s
Ridge point = 100 / 25 = 4 FLOPs/byte. Kernels with intensity above 4 are compute-bound; below 4 are memory-bound.
Kernel placements
Matrix multiply (N large): intensity ≈ 85 FLOPs/byte → predicted performance ≈ 100 GFLOPS (compute-bound).
Vector addition
Intensity ≈ 0.042 → predicted performance = 25 × 0.042 ≈ 1.05 GFLOPS (memory-bound).
Dot product
Intensity ≈ 0.25 → predicted performance = 25 × 0.25 = 6.25 GFLOPS (memory-bound).
