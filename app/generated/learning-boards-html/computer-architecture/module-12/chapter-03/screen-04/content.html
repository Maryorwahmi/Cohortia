Module 12 › Chapter 12.3 › What is the Roofline Model?
Formal claim
Performance ≤ min(Bandwidth × Intensity, Peak Compute). Use this relation to determine the active bottleneck.
Performance = min(bandwidth × intensity, peak_compute)
Concrete example
If peak compute = 100 GFLOPS and bandwidth = 25 GB/s, ridge point = 4 FLOPs/byte. Intensity above 4 is compute-bound; below 4 is memory-bound.
Misconception: higher peak compute alone fixes slow kernels. Not if intensity is low.
Key Takeaway

Use measured peak numbers and intensity calculations to diagnose the resource that limits your kernel.

Definition cards
Compute ceiling
Horizontal limit equal to peak arithmetic throughput.
Memory bandwidth ceiling
Diagonal line equal to bandwidth × intensity.
Practical note
  • Use vendor specs or microbenchmarks for peak numbers.
  • Operational intensity is workload-specific and depends on data movement assumptions.
  • Plot several kernels to compare their limiting factors.
