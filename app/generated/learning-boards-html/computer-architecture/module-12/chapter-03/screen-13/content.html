Module 12 › Chapter 12.3 › Assessment Example
Given
Peak compute = 200 GFLOPS. Memory bandwidth = 50 GB/s. Ridge = 200 / 50 = 4 FLOPs/byte.
Kernel: matrix multiply with intensity 16 FLOPs/byte, achieved 50 GFLOPS.
Interpretation
Intensity 16 > 4, so theoretically compute-bound. Achieved 50 GFLOPS ≪ 200 GFLOPS suggests in-core bottlenecks like poor vectorization or lack of FMA.
Suggested actions
  • Check compiler vectorization reports and assembly for SIMD/FMA.
  • Try blocking to rule out cache effects.
  • Use tuned BLAS kernels or intrinsics if needed.
Key Takeaway
A high intensity with low achieved GFLOPS points to in-core or vectorization issues more than memory bandwidth.
