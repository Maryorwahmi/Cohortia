VC Microarchitecture and Buffer Sizing
How to compute buffer bits and what matters when adding VCs.
Per-router buffer calculation
Use the formula: ports × VCs per port × flits per VC × flit width.
Example: 4×4 mesh router
Ports = 5
VCs per port = 2
Flits per VC = 4
Flit width = 128 bits

Total buffer bits per router = 5 × 2 × 4 × 128 = 5120 bits
Total routers = 16
Total chip buffer bits = 16 × 5120 = 81,920 bits
Common mistake
Forgetting to multiply by the number of ports or neglecting VC count underestimates buffer cost and power impact.
Design considerations
  • More VCs improve isolation but require more storage and control logic.
  • Depth trades off buffering for area and power; size to expected burst lengths.
  • Synthesizable SRAM or register files have area and timing differences—budget accordingly.
Pro Tip

Perform buffer sizing early in the design so routing and allocator choices can be co-optimized with memory area constraints.
