Deadlock Scenario and VC Prevention
A stepwise simulation of a circular wait and the VC-based fix.
Simulated deadlock steps
  1. Packet A at router R0 requests link to R1 and holds a buffer entry in VC0.
  2. Packet B at R1 requests link to R0 and holds a buffer entry in VC0 at R1.
  3. Each waits for the other’s buffer to free; no progress — a two-node cycle.
If only one VC exists per link this cycle locks both packets. With two VCs, assign A to VC0 and B to VC1 so each has independent buffering and credit bookkeeping and one can proceed.
VC assignment strategies
  • Separate request and reply flows into distinct VCs.
  • Assign VCs by direction to prevent cycles involving turns.
  • Ensure resource dependency graph per VC is acyclic.
Key Takeaway

Prevent deadlock by designing VC allocation rules so no cyclic buffer dependency can occur within a single VC network.
