NoC Router Microarchitecture
The key hardware blocks that move flits between ports.
Definition and roles
  • Input buffers: hold arriving flits; typical depth 4–16 flits.
  • Route computation: maps destination to output port using routing algorithm.
  • Switch allocator: arbitrates competing requests; round-robin or priority.
  • Crossbar: N×N fabric to connect inputs to outputs.
Example
A 5-port router (N,S,E,W,local) uses a 5×5 crossbar. If two inputs request the same output, the allocator grants one and the other waits in its input buffer.
Key Takeaway

Decompose a router into buffers, decision logic, arbitration and fabric. Each part contributes to latency, throughput and area.

An annotated microarchitecture panel
Input Buffers
Per-input buffers store flits; per-VC buffers if virtual channels are present.
Route Computation
Compute next hop using destination address and routing rules (e.g., XY routing).
Switch Allocator
Resolve conflicts; choose grant ordering and fairness policy.
Crossbar
Connects winners to outputs; traversal may be pipelined for timing.
Common misconception
Bigger buffers always increase performance. In reality larger buffers increase area and power and may hide systemic congestion instead of solving it; allocator fairness and routing decisions are equally important.
