Designing a 4×4 Mesh Router — Calculation and XY Routing
Stepwise arithmetic and a routing trace for a packet from (0,0) to (3,3).
Buffer sizing code block
// Parameters
ports = 5
vcs_per_port = 2
flits_per_vc = 4
flit_width_bits = 128

// Per-router calculation
buffer_bits_per_router = ports * vcs_per_port * flits_per_vc * flit_width_bits
// = 5 * 2 * 4 * 128 = 5120 bits

// Network-wide
num_routers = 16
total_buffer_bits = buffer_bits_per_router * num_routers
// = 16 * 5120 = 81920 bits
Round-robin switch allocator ensures fairness and bounded starvation risk; implement per-output arbitration rotating grants each cycle.
XY routing trace and latency
XY routing: move in X until correct column, then in Y. From (0,0) to (3,3): Δx=3, Δy=3 ⇒ hops=6.
// Latency parameters
router_cycles = 2  // with lookahead
link_cycles = 1
hops = 6

// Naive estimate
latency_cycles = hops * (router_cycles + link_cycles)
// = 6 * (2 + 1) = 18 cycles

// With lookahead overlaps, effective router cycles per hop may reduce; account for overlaps in detailed timing models.
Remember: each hop requires VC allocation and a switch grant; contention increases latency beyond the arithmetic estimate.
