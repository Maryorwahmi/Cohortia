Router Pipeline and Lookahead
How staging work affects latency and how lookahead can reduce visible per-hop cost.
1. Buffer Write (BW)
Incoming flit is written into the input buffer and awaits allocation.
→
2. Route Computation + Switch Allocation (RC/SA)
Compute output port and arbitrate grants among competing inputs.
→
3. Switch Traversal + Link Traversal (ST/LT)
Flit crosses the crossbar and is sent over the physical link to the next router.
Lookahead routing
Compute the next hop earlier so the downstream allocator can start work in parallel. This reduces effective cycles per hop but adds control complexity and possible speculative state management.
Why this matters
  • Pipeline depth determines per-hop latency and influences throughput under contention.
  • Lookahead shortens end-to-end latency for small packets at the expense of complexity.
  • Choose pipeline style based on target packet size and timing budget.
