Virtual Channels and Their Uses
Why VCs are used and what they buy you in a router.
What is a virtual channel?
A VC is a separate logical buffer and flow-control context multiplexed on a physical link; it provides isolation between packet streams.
Benefits
  • Deadlock avoidance by separating traffic into virtual networks.
  • Quality-of-service via dedicated VCs for high-priority flows.
  • Reduced head-of-line blocking so other VCs can progress when one is stalled.
Misconception
VCs do not come for free: more VCs require more buffers and control logic, increasing area and power. Choose VCs to balance isolation and cost.
Concrete example
Consider request and reply packets crossing the same link. If both use the same VC they can create a cyclic wait. Assign request packets to VC0 and replies to VC1 to prevent this cycle.

VC1 ─ replies
VC2 ─ priority traffic

Key Takeaway

Use VCs to break dependency cycles and isolate flows, and budget area/power for the added buffers and control logic.
