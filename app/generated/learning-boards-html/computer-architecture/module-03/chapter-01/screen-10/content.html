Design Task

Single-cycle datapath sketch

Include these connections and label control signals for each instruction type. Use this checklist to avoid common omissions.
  • PC → Instruction Memory → Decoder
  • Register File (2 reads, 1 write) connected to ALU inputs
  • ALU second input mux: register vs sign-extended immediate
  • Data Memory addressed by ALU result; mem-to-reg mux for write-back
  • Branch comparator and PC select logic for BEQ
Example control signals to label
ALUOp, ALUSrc, MemRead, MemWrite, MemToReg, RegWrite, Branch
Common mistake
Forgetting a write-back multiplexer or misrouting the ALU input when immediates are used.
