Reusing the ALU across cycles means we need only one ALU instance but an FSM to sequence control signals. Memory accesses are separated in time; instruction memory is accessed during fetch and data memory during the memory stage.
Why reuse matters
  • Reduces hardware duplication and area.
  • Shorter clock period since each cycle does less work.
  • Requires FSM or microcode to generate per-cycle control signals.
