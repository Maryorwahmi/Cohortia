Practice: build and compare

Two hands-on tasks consolidate the theory: datapath design and timing calculation followed by a multi-cycle redesign.

Task A — Single-cycle datapath
  • Support ADD, SUB, AND, OR, LW, SW, BEQ
  • Show PC, instruction memory, register file, ALU, data memory
  • Label control signals per instruction
Task B — Timing & multi-cycle
  • Compute clock period from component delays
  • Redesign as multi-cycle with a 2 ns clock
  • Count cycles per instruction and compare run times
VERIFIED COMPETENCY MILESTONE — provide timing math and a cycle-by-cycle FSM trace for a load instruction.
