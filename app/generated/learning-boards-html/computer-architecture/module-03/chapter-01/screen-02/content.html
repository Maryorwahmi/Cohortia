Learning Objectives

From design to timing to control sequencing.

Bloom: Learn → Understand → Apply → Master
01
Design single-cycle datapath

Place PC, instruction memory, register file, ALU, data memory, sign-extension and muxes so each instruction completes in one cycle. Verified competency milestone.

02
Calculate critical-path timing

Add component delays to find the longest path and compute the maximum clock frequency. Verified competency milestone.

03
Explain single-cycle limits

Describe why long clock cycles and duplicated resources make single-cycle designs inefficient. Verified competency milestone.

04
Design multi-cycle control

Break instructions into cycles, generate control per stage with an FSM or microcode, and show how ALU and memory are reused. Verified competency milestone.

VERIFIED COMPETENCY MILESTONE — show design sketches, timing calculations, and a simple FSM trace.
