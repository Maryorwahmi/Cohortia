Module 3 › Chapter 3.1 › Key Concepts
Single-cycle datapath
All units present; one cycle per instruction; clock set by longest instruction.
Critical path timing
Trace the longest combinational path and sum delays to get the clock period.
Multi-cycle reuse
Split execution across cycles to reuse ALU and shorten the clock, with FSM or microcode control.
Summary takeaway
Single-cycle is educational and simple; multi-cycle improves clock speed and utilization but increases control complexity. Pipelining builds on these ideas to raise throughput further.
