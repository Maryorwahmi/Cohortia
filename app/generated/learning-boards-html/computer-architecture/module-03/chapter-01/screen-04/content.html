Core Concept

Datapath components

Every component exists simultaneously and signals flow combinationally to produce the correct outputs within one long cycle.

Program Counter (PC)
Holds instruction addresses and increments each cycle.
Instruction Memory
Read-only store of opcodes fetched by PC.
Register File
Two read ports, one write port for operands and results.
ALU & Data Memory
ALU does arithmetic/addressing; data memory holds load/store data.
Multiplexers & Sign-extend
Muxes select register vs immediate and memory vs ALU results; sign-extension prepares immediates for the ALU.
Example: LW instruction path
  1. PC fetches instruction from instruction memory.
  2. Register file read supplies base register.
  3. ALU computes effective address using base + offset.
  4. Data memory reads the word from computed address.
  5. Write back the data into register file.
Key Takeaway

Single-cycle is conceptually simple but forces one cycle to accommodate the slowest instruction.

Common mistake
Assuming the clock can be set by average instruction time. It must accommodate the worst-case critical path.
