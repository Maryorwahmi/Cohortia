FSM vs Microcode

Finite-State Machine (FSM)
Explicit states like FETCH, DECODE, EXECUTE. Fast and compact for RISC instruction sets.
Microcode
Control words stored in a ROM. Easier to add complex behaviors, trades ROM area for control logic complexity.
Design checklist
  • List needed states for each instruction type.
  • Specify control outputs required in each state.
  • Define transitions based on opcode fields and flags.
  • Decide FSM logic or microcode ROM depending on extensibility needs.
Pro tip

Draw a small table: state × control signals. This makes missing signals or illegal states obvious.
