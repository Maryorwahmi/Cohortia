Module 3 › Chapter 3.1 › Critical Path
Definition

Trace and compute the longest path

Identify every component the signal traverses from fetch to write-back for the slowest instruction and sum delays.

Critical path (load):
PC → Instruction Memory (2 ns)
→ Register Read (1 ns)
→ ALU (2 ns)
→ Data Memory (2 ns)
→ Mux (0.5 ns)
→ Register Write (1 ns)
Total = 8.5 ns  → Max freq ≈ 1 / 8.5 ns ≈ 117.6 MHz
Pro tip

Always include register write setup and multiplexer delays in the critical path sum.

Explanation bullets
  • Clock period must fit the slowest instruction's total combinational delay.
  • Short instructions cannot use a shorter cycle even if they are faster logically.
  • Component delays are additive; identify memory, ALU, and mux contributions.
  • Designing for worst-case can waste cycles and power for simple instructions.
Analogy
A factory conveyor must be as long as the slowest processing station; every product waits for the longest station even if it doesn't need it.
