Module 3 › Chapter 3.4 › Performance & Bottlenecks
What to measure
  • Decode latency per instruction class.
  • Decode width (x86 instr/cycle) and μop width (μops/cycle).
  • Average μops per instruction and fusion rates.
Analysis steps
If IPC is low, check whether μop queue underflows. If so, inspect decode width and μop expansion. If the queue is full but execution units idle, the back-end likely lacks sufficient ports or has long-latency operations.
Key takeaway
Diagnose performance by separating front-end supply issues from back-end resource constraints.
