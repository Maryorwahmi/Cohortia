Module 3 › Chapter 3.4 › x86 → μop examples
Simple mapping
; x86 assembly (conceptual)
ADD R1, R2

; generated μop stream (conceptual)
μop1: ALU  dst=R1  src1=R1  src2=R2  update_flags=1
This single μop encodes the ALU operation and operands so the back-end can schedule and execute it like a RISC instruction.
Complex mapping (conceptual)
; x86 string move
REP MOVSB

; possible μop expansion or microcode sequence
μop1: LOAD  dst=tmp, src=[RDI]
μop2: STORE dst=[RDI], src=tmp
μop3: ADD   dst=RDI, src=1
μop4: SUB   dst=RCX, src=1
μop5: BRNZ  target=loop_start
A string instruction becomes a loop of loads, stores, index updates, and branches. Microcode can emit this sequence when hardware decode is impractical.
