Translators create μops
Simple instructions map to one μop; complex ones map to many or use microcode.
Outbox queues μops
A μop queue feeds the out-of-order execution engine at steady rate.
Key takeaway

Translation is the front-end’s job: make complex x86 semantics into simple, fixed μops so a fast execution engine can run them. The cost is decode complexity and potential front-end bandwidth limits.
