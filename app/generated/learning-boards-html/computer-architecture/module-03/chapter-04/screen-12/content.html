Macro-op fusion
Decoder recognizes common instruction pairs and emits a single fused μop. Example: compare + branch → fused compare-and-branch μop.
Micro-op fusion
Back-end merges compatible μops for execution efficiency, such as load + ALU that uses the loaded value immediately.
Why fusion helps
  • Reduces μop count the engine must track.
  • Frees reservation station and reorder buffer entries.
  • Effectively increases issue throughput without adding ports.
