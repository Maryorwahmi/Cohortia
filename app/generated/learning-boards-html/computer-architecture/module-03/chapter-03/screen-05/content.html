Module 3 › Chapter 3.3 › Micro-instruction fields
Field breakdown
  • ALU op: add, sub, and, or — selects arithmetic logic.
  • Register enables: source reads and destination write signals.
  • Memory controls: read/write strobes and byte enables.
  • Multiplexer selects: route operands into ALU or writeback path.
  • Next address: fixed next or conditional branch target based on flags.
Common mistake
Assuming a micro-instruction can change datapath wiring arbitrarily. The micro-instruction controls existing datapath signals; it cannot add hardware behaviors beyond what the datapath supports.
Sequencing example
Step
Fetch micro-instruction at control store address A, assert ALU and register enables specified in the fields, then compute next address. If a condition flag is set, choose the branch target; otherwise proceed sequentially.
Concrete mapping
Map a machine instruction like LOAD to micro-steps: load address register, enable memory read, write result to destination, update pointers, set done flag. Each of these actions appears in micro-instruction fields and may take separate entries depending on format.
