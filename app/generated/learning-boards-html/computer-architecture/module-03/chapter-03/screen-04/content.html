Module 3 › Chapter 3.3 › What is Microcoded Control?
Core idea
The control store contains micro-instructions. A sequencer fetches them and asserts control signals serially to implement a machine instruction.
Micro-instruction fields
  • ALU operation select: add, subtract, bitwise ops.
  • Register file read/write enables.
  • Memory read/write signals and byte controls.
  • Multiplexer selects and next-address or conditional branch fields.
Key Takeaway

Microcode controls the datapath by sequencing small, hardware-level operations recorded in the control store; it is flexible but typically slower than hardwired control.

Analogy & quick example
Analogy
Microprograms are like short scripts for the control unit. The sequencer plays each line and the datapath performs that line's action.
Concrete example
A micro-instruction may say: read R1 and R2, ALU add, write R3, next address 0x11. That single entry activates multiple datapath signals concurrently within one cycle.
