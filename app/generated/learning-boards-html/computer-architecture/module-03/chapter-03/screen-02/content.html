Learning Objectives

Four competency targets that prepare you to analyze and design microcode.

01
Explain hardwired vs microcoded
Describe each control style and why hardwired is faster while microcode provides flexibility. This helps choose an approach for instruction sets.
VERIFIED COMPETENCY MILESTONE
02
Read micro-instruction fields
Identify ALU selects, register enables, memory controls and next-address fields to trace execution precisely.
VERIFIED COMPETENCY MILESTONE
03
Compare vertical and horizontal microcode
Explain how format affects microprogram length, micro-instruction width, and parallelism inside a cycle.
VERIFIED COMPETENCY MILESTONE
04
Analyze hybrid control use
Reason about why processors use hardwired control for common instructions and microcode for the complex or patchable behaviors.
VERIFIED COMPETENCY MILESTONE
