CPI example
Given baseline CPI = 1.2. If microcode adds one cycle per instruction, new CPI = 1.2 + 1.0 = 2.2. Performance ratio = 2.2 / 1.2 ≈ 1.83× slowdown. This simple calculation shows the heavy cost when microcode is applied to every instruction.
Common microcode ROM uses
  • Complex instructions that don't map to simple execution units.
  • Exception handling and fault recovery sequences.
  • System calls, virtualization, power management sequences.
  • Security patches distributed as microcode updates.
Misconception check
Microcode updates cannot synthesize new hardware; they can only change sequences that exercise existing datapath resources. Patches can fix behavior but not create new execution units.
Key Takeaway
Use microcode where complexity or patchability outweighs per-instruction cycle cost; otherwise prefer hardwired control for the hot path.
