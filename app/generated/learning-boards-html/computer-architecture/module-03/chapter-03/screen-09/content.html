Module 3 › Chapter 3.3 › Vertical vs Horizontal
Vertical microcode
Narrow micro-instructions that each control one small action. Pros: compact control store, easier to edit. Cons: more micro-instructions per machine instruction.
Horizontal microcode
Wide micro-instructions that specify many control signals at once. Pros: fewer cycles per machine instruction, more parallelism. Cons: wide control-store words and more silicon area.
Practical considerations
  • Data-path parallelism: horizontal formats exploit it to reduce cycles.
  • Control-store capacity: vertical saves memory but increases fetches.
  • Implementation complexity and updateability: encoding schemes affect ease of patching.
Key Takeaway
The choice between vertical and horizontal microcode is a trade-off between control-store bits and microprogram length; match the format to datapath parallelism and memory constraints.
