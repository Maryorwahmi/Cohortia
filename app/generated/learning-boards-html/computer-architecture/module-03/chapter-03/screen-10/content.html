Microcode table template
Fill this table for your 4-bit ALU. The rows below show example micro-rows for ADD and LOAD.
microaddr | ALU | R_A_en | R_B_en | R_res_en | MemRead | MemWrite | next
0x00     | NOP |   0    |   0    |    0    |    0   |    0     | 0x01
0x01     | READ_ADDR | 1 | 0 | 0 | 1 | 0 | 0x02    ; LOAD address in A, then MemRead
0x02     | WRITE      | 0 | 0 | 1 | 0 | 0 | 0xFF    ; write to result reg and return

; ADD microprogram (register A + register B -> res)
0x10     | RREAD      | 1 | 1 | 0 | 0 | 0 | 0x11    ; put operands on bus
0x11     | ADD        | 0 | 0 | 1 | 0 | 0 | 0xFF    ; ALU computes and result written
Simulate step-by-step: at each microaddr note which signals are asserted and what changes in registers or memory. Count the micro-rows executed for each machine instruction to estimate cycles consumed by control store fetches.
Simulation hint
Track three columns per step: control signals asserted, data movement observed, and next micro-address. This reveals hidden costs like extra cycles for memory or pointer updates.
Key Takeaway
Design microprograms with attention to memory cycles and pointer updates; these often determine the dominant cost of complex instructions.
