Step 1 — Stage mapping
For each instruction, list active signals in IF, ID, EX, MEM and WB. Example: ADD asserts RegWrite only in WB.
Example row
ADD: IF(read instruction), EX(ALU compute), WB(RegWrite). LW: MEM(MemRead), WB(RegWrite with MemtoReg).
Step 2 — Equations with state
Derive expressions that include state bits. Example below.
// WB stage is state == 100 for example
RegWrite = (ADD AND WB) OR (LW AND WB)
ALUSrc   = (LW AND EX) OR (SW AND EX)
Key Takeaway

Include state bits in product terms for stage-accurate control. PLAs map these combinations cleanly into an AND plane.
