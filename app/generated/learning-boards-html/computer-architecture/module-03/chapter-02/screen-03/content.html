Practice steps
  1. Create the truth table for ADD, SUB, LW, SW, BEQ and list each control signal.
  2. Derive Boolean equations for each control output using decoded instruction signals.
  3. Implement equations with AND-OR gates and program a PLA to match results.
  4. Calculate propagation delay assuming 1 ns per gate along the critical path.
Assessment prompts
Short answer
Why is a PLA a sensible implementation for a RISC hardwired control unit?
Design task
