Module 3 › Chapter 3.2 › Decoder and Instruction Signals
Decoder: opcode → instruction signals
A small combinational block asserts named instruction lines used by control equations.
Benefits
  • Simpler boolean equations
  • Independent testing of decoder and control logic
  • Easier factoring and optimization
Stage-dependent control
AND decoded instruction signals with state bits to produce outputs only in intended stages, e.g., enable RegWrite in WB stage only.
Concrete example
If the decoder asserts LW and the state equals WB, then RegWrite = LW AND WB. Without the WB mask a load might attempt to write too early or at the wrong time.
Decoder outputs
ADD, SUB, LW, SW, BEQ — each is a decoded line used in equations.
Key Takeaway

Decoding separates opcode decoding from control logic and simplifies design and verification.
