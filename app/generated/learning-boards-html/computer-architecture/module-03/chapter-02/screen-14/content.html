Module 3 › Chapter 3.2 › Key Concepts
Control Signals
RegWrite, MemRead, MemWrite, ALUSrc, MemtoReg, Branch, ALUOp — the signals that steer the datapath.
Truth Table → Equations
Use the truth table rows to create sums-of-products equations for each control output.
PLA vs Gates
Implement sums-of-products with an AND plane and an OR plane (PLA) or with wired AND/OR gates; choose by complexity and speed needs.
Takeaway

Hardwired control is fast and appropriate for simple, stable ISAs. Use truth tables and decoded instruction signals as the basis for clear, verifiable control logic design.
