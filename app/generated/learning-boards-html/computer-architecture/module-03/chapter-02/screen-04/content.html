Control unit: role and behavior
Generates RegWrite, MemRead, MemWrite, ALUSrc, MemtoReg, Branch, ALUOp, and PCSrc from opcode and state.
Example: LW
MemRead = 1, MemtoReg = 1, RegWrite = 1, ALUSrc = 1. The ALU computes address, memory is read, result written to register.
Example: ADD
RegWrite = 1, ALUSrc = 0, MemRead/MemWrite = 0. The ALU performs arithmetic and the result is written back.
Common misconception
Hardwired control computes outputs from the opcode and state; it does not fetch microinstructions. This is why it is fast but less flexible.
Concrete signal list
  • RegWrite — enable register file write
  • MemRead / MemWrite — data memory access
  • ALUSrc — select second ALU operand
  • MemtoReg — choose register write source
  • Branch, ALUOp, PCSrc — control flow and ALU selection
Key Takeaway

Control signals encode the precise actions the datapath must take; hardwired logic produces them directly and quickly.
