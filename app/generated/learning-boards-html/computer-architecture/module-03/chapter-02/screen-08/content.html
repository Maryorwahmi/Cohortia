Module 3 › Chapter 3.2 › AND-OR Logic
Wiring sums of products
Product terms from decoded signals feed OR gates to produce control outputs.
Practical notes
  • Limit OR gate fan-in by factoring expressions into smaller OR trees.
  • Use inverters where the logic needs negated inputs.
  • Test by comparing outputs for every opcode against the truth table.
Concrete gate example
// Example wiring for RegWrite
// Decoder asserts ADD and LW
RegWrite = OR(ADD, LW)   // two-input OR gate

// ALUSrc = OR(LW, SW)
ALUSrc = OR(LW, SW)
Pro tip
Factor expressions shared across outputs to reduce redundant product terms and lower gate count.
