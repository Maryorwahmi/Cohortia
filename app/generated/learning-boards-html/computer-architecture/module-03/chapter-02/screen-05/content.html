Truth table (compact)
Rows list instruction and control outputs used to derive equations.
Instruction | RegWrite MemRead MemWrite ALUSrc MemtoReg Branch ALUOp
ADD         | 1       0       0       0      0        0      10
LW          | 1       1       0       1      1        0      00
SW          | 0       0       1       1      X        0      00
BEQ         | 0       0       0       0      X        1      01
How to use the table
  • Verify datapath semantics for each instruction before converting to equations.
  • Mark don't-care values as X only when safe.
  • Use decoded instruction signals (e.g., ADD, LW) as product terms to build outputs.
Concrete example
For LW: RegWrite = 1 because the load writes the register, MemRead = 1 to read data memory, MemtoReg = 1 to route memory data to the register file.
