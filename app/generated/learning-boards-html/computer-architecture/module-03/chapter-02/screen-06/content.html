Module 3 › Chapter 3.2 › Deriving Boolean Equations
Boolean equations (derived)
RegWrite = ADD + LW
MemRead  = LW
MemWrite = SW
ALUSrc   = LW + SW
MemtoReg = LW
Branch   = BEQ
ALUOp1   = ADD
ALUOp0   = BEQ
Plus signs mean logical OR, concatenation or product terms are used when needed. Use the decoder to assert ADD, LW, SW, BEQ signals from the opcode bits.
Implementation notes
  • Decoder converts opcode to instruction signals used as inputs to OR gates.
  • Factor common signals to reduce OR fan-in and gate levels for speed.
  • For multi-cycle control include state bits in product terms to vary outputs by stage.
Misconception
Equations are not code; they represent structural wiring you implement with gates or a PLA.
