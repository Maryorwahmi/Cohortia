Handler steps
  1. Save PC and PSR to exception stack
  2. Optionally save required registers
  3. Signal or print the exception type
  4. Restore registers, PSR, PC and execute return-from-exception
Note: use the architecture's return-from-exception instruction so masked bits and privileged state are restored correctly.
Pseudocode assembly
  ; Exception handler entry (pseudocode)
  PUSH  PC        ; save program counter
  PUSH  PSR       ; save processor status register
  PUSH  R0..Rn    ; save minimal registers if needed
  CALL  print_exception_type
  POP   R0..Rn
  POP   PSR
  POP   PC
  IRET            ; return-from-exception (architecture-specific)
Key Takeaway

Handlers must save and restore the exact context and return with the privileged return instruction; treat them as privileged code, not regular functions.

Trace task

Record the PC values: before the exception, handler entry, and after return. Verify the return PC matches the expected restart point.

If no simulator

Draw the pipeline diagram showing EX detection, flush, state save, vector transfer, handler, and return stages.
