01 — Classify & verify

Task: for a given event decide if it's an interrupt, trap, fault, or abort and state where the return address will point. Mnemonic: "Cause then return" — synchronous events often point back to the faulting instruction; traps advance to the next instruction.

02 — Map hardware steps

Task: draw the sequence from detection at a pipeline stage to executing the return-from-exception instruction. Check that interrupts are masked while state is saved.

03 — Inspect vector tables

Task: explain how the base register stores a table address and how the exception number indexes the right handler entry.

04 — Analyze pipelines

Task: compare a five-stage pipeline flush strategy with an out-of-order core that uses a reorder buffer to provide precise exceptions.
