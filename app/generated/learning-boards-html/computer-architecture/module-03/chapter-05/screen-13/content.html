Module 3 › Chapter 3.5 › Virtualization
Trap-and-emulate

Hypervisor intercepts exceptions and emulates behavior for the guest. Simple but can be costly in software traps.

Hardware virtualization

Processor provides root and guest modes so exceptions can be routed to the hypervisor or to the guest with hardware support, reducing overhead.

Concrete example

A privileged guest instruction that would trap to an OS may instead trap to the hypervisor for emulation or shadowing, depending on virtualization configuration.

Design tradeoff

Intercepting more exceptions improves isolation but increases overhead; passing exceptions to the guest reduces hypervisor work but requires safe hardware support.

Key Takeaway

Virtualization adds a routing decision: choose which exceptions the hypervisor intercepts and which are delivered to the guest to balance performance and correctness.
