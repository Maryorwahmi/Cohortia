Module 3 › Chapter 3.5 › Exception vector table
What it is

An array of handler addresses indexed by exception type. The processor computes address = base + exception_number * entry_size.

Example entries: reset, NMI, timer, system call, page fault, divide-by-zero.
Why base register matters

The base register stores the table address; it must be initialized and accessible only in privileged mode to prevent malicious redirection.

Practical checks
  • Confirm base register value at boot
  • Ensure table entries contain valid privileged addresses
  • Respect alignment and entry-size conventions
Common mistake

Assuming vector entries are auto-filled or protected from user-space — ensure privilege separation and correct initialization.

Key Takeaway

The vector table is a simple arithmetic lookup; correct base and entry layout are critical to direct exceptions to the right handler.
