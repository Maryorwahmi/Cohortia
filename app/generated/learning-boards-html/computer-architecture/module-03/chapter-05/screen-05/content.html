Module 3 › Chapter 3.5 › Handling sequence
1 — Detect
Hardware observes an exceptional condition in a pipeline stage.

Example: execute stage detects divide-by-zero; memory stage detects page fault.

2 — Save state
PC, PSR, and architectural registers are stored to allow later resume.
3 — Mask interrupts
Set the interrupt-disable bit to avoid nested corruption while saving context.
4 — Vector lookup
Calculate handler address from the vector table base and exception number.
5 — Execute handler
OS code services the event, e.g., fetch page, complete system call.
6 — Return
Return-from-exception restores saved state and resumes at the proper address.
Key Takeaway

Each stage of handling has a verifiable hardware action; treat handlers as privileged sequences that must restore saved state explicitly.

Pro tip

When debugging, log the saved PC and PSR to confirm the exact trap point and interrupt mask state.
