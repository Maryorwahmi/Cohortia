Module 3 › Chapter 3.5 › Saving processor state
What to save
  • Program Counter (PC)
  • Processor Status Register (PSR) including interrupt mask
  • Architectural register file or indicators of committed state
Where to save

A privileged stack or special registers dedicated to exception context. The mechanism must be atomic with masking so state is not corrupted by nested events.

Example: page fault flow

Memory stage detects a page fault, CPU saves PC and PSR, jumps to page-fault handler, handler loads page, then return-from-exception restores saved state and restarts the faulting instruction.

Common mistake

Assuming speculative register updates are preserved. Uncommitted speculative state must be discarded or never made architectural until commit.

Key Takeaway

The saved context must let the OS restore the architectural state exactly as if instructions executed in order; missing pieces break precise exceptions.
