Module 3 › Chapter 3.5 › Maskable vs NMI
Maskable interrupt

Can be disabled by the interrupt-enable bit. Suitable for routine devices where latency can be tolerated.

Example: timer tick used for scheduling.
Non-maskable interrupt

Cannot be disabled; used for urgent hardware conditions that require immediate attention.

Example: hardware parity error or immediate watchdog expiration.
Key Takeaway

Reserve NMIs for critical circumstances; use maskable interrupts for normal device-driven activity to keep handlers simpler and predictable.

Common mistake

Using NMI for convenience leads to complex recovery paths; NMIs must remain robust and minimal.
