Module 3 › Chapter 3.5 › 5-stage pipeline
Stage detection

Different stages detect different exceptions: decode, execute, memory. Each stage's logic can raise a signal that begins the handling sequence.

Flushing

If an exception is detected in stage N, stages N+1..WB are flushed so no younger instruction commits its results.

Concrete example

A divide-by-zero in EX flushes MEM and WB instructions that followed. The saved PC corresponds to the excepting instruction so the OS can decide to abort or retry.

Common misconception

Believing only fetch needs stalling. In fact exceptions can come from later stages and require flush coordination across the pipeline.

Key Takeaway

Precise exceptions require the pipeline to flush younger instructions so only effects from committed instructions become visible.
