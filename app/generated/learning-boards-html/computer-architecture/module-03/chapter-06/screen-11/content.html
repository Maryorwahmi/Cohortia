Control unit and the critical path

Control signal generation must be fast enough that it does not set the clock period. Designers use several techniques to avoid control-induced bottlenecks.

Hardwired control
Combinational logic generates control quickly with small gate delays. Preferred for common-case speed.
Microcoded control
Easier to build and more flexible, but control-store access can add to cycle time.
Mitigations
Pre-decoding, μop caches, and overlapping control generation with fetch reduce control delay impact.
Design question
If ALU and memory are already optimized, invest in hardwired control and pre-decoding to keep the control unit off the critical path.
Visual mnemonic
Imagine the slowest worker defines the assembly line speed — the control unit must not be that slow worker.
