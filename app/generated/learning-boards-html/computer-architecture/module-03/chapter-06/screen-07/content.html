Module 4 › Chapter 3.6 › CPI Calculation
Process

Compute average CPI from an instruction mix

Step-by-step
  1. List instruction classes and cycles per instruction.
  2. List fraction of workload for each class.
  3. Multiply fraction × cycles for each class.
  4. Sum the results to get average CPI.
Worked arithmetic
Mix: 40% ALU (4 cycles)
30% load (5 cycles)
20% store (4 cycles)
10% branch (3 cycles)
Compute:
0.4×4 = 1.6
0.3×5 = 1.5
0.2×4 = 0.8
0.1×3 = 0.3
CPI_avg = 1.6 + 1.5 + 0.8 + 0.3 = 4.2
Why this matters
CPI_avg determines execution time when multiplied by the clock period and instruction count. It makes design comparisons quantitative.
Common error
Do not average cycles without weighting by class frequency; that misrepresents the actual CPI.
Check
Given another mix, repeat the arithmetic and verify the CPI_avg numerically.
Concrete example
Result
CPI_avg = 4.2 for the given mix. Use this with T_mc to compute execution time per instruction.
Key takeaway
Weighted averages give real CPI. Always show the multiplication steps when you present your calculation.
