Module 4 › Chapter 3.6 › Practical Objectives
Apply calculations

You will perform numerical comparisons for single-cycle, multi-cycle, and pipelined processors using the same functional units and given stage delays.

Formula reminder
Single-cycle: T_sc = sum(stage delays). Multi-cycle: T_mc = max(stage delay). Pipelined: T_pipe = T_mc + pipeline overhead.
Execution time
Execution = clock period × CPI × instruction count. Compute CPI from instruction mix when needed.
Mnemonic: TIC
Think: Time per cycle, Instruction complexity (cycles), Count of instructions — multiply to compare designs.
Assessment example
You will compute times for 1,000 instructions using stage delays IF=2, ID=1, EX=2, MEM=2, WB=1 and a defined mix.
Tip
When stages are balanced T_mc ≈ T_sc / number_of_stages, but always use max(stage) for correctness.
