Module 4 › Chapter 3.6 › Pipelined Control
Definition

Pipelined control

Instructions overlap across stages. Clock period equals stage max plus pipeline register overhead: T_pipe = T_mc + T_overhead. CPI ≈ 1 with stalls increasing it.

Performance
Ideal CPI = 1. With hazards: CPI = 1.1–1.5 typical, 2–3 for heavy hazards.
Costs
  • Area: pipeline registers and hazard logic increase silicon.
  • Power: more registers toggle; speculation increases dynamic power.
Key Takeaway

Pipelining raises throughput dramatically but requires hazard management and adds area/power. Evaluate CPI including stalls to judge real performance.

Numeric example
If T_pipe = 1.1×T_mc and CPI = 1.2
Execution per instruction = 1.2 × 1.1 × T_mc = 1.32 × T_mc. Compared to single-cycle T_sc = 5 × T_mc, pipeline can be several× faster.
Analogy
A linear conveyor with many products in parallel; transfer stations (pipeline registers) add overhead but greatly increase throughput.
