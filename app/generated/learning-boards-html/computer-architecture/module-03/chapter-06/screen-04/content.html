Module 4 › Chapter 3.6 › Single-Cycle Control
Definition

Single-cycle control

Every instruction completes in one clock cycle. Clock period equals the sum of all stage delays: T_sc = T_fetch + T_decode + T_execute + T_memory + T_writeback.

Costs
  • High area: dedicated units for all stages.
  • High power: units active every cycle even if unused.
  • Long clock period can make it slower overall.
Misconception
CPI = 1 does not guarantee best performance because T_sc may be long.
Key Takeaway

Single-cycle is simple and predictable but pays in clock length, area, and power. Use it only when simplicity outweighs speed and cost.

Concrete example
Given stage delays: IF=2 ns, ID=1 ns, EX=2 ns, MEM=2 ns, WB=1 ns
T_sc = 2 + 1 + 2 + 2 + 1 = 8 ns
CPI = 1.0
Execution time for 1000 instructions = 8 ns × 1000 = 8000 ns
Analogy
A single long assembly line where every product must travel the entire line before the next begins.
Check your understanding
If you reduce one stage by 0.5 ns, what happens to T_sc and execution time proportionally? Why might that not change the multi-cycle clock?
