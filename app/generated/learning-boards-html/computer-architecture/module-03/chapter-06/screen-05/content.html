Module 4 › Chapter 3.6 › Multi-Cycle Control
Definition

Multi-cycle control

Stages execute in separate cycles. The clock period equals the slowest stage: T_mc = max(stage delays). Units are reused across cycles.

Benefits
  • Lower area: shared functional units.
  • Lower power: fewer units switching each cycle.
  • Shorter clock period than single-cycle when stages are balanced.
CPI behavior
Different instructions take different cycle counts. Average CPI = sum(fraction_i × cycles_i).
Key Takeaway

Multi-cycle reduces clock length and hardware cost but relies on the instruction mix; compute average CPI to compare performance.

Concrete example
50% ALU, 50% load example
Average CPI = 0.5×4 + 0.5×5 = 4.5 cycles. If T_mc ≈ T_sc/5, execution per instruction ≈ 4.5×T_sc/5 = 0.9×T_sc, so multi-cycle can be faster than single-cycle.
Analogy
Think of a circular conveyor where a product revisits stations; stations are shared rather than duplicated.
Common pitfall
Do not equate lower area with lower latency without computing execution time using CPI and clock period.
