Common misconceptions

Review common errors and how to avoid them with conservative, measurable assumptions.
Metric isolation
Comparing only CPI or only clock period leads to wrong conclusions. Use execution time.
Optimistic pipeline assumptions
Include pipeline overhead and realistic stalls; speculative numbers can mislead.
Ignoring control delay
Slow control units raise the clock period; mitigate with hardwired paths or pre-decoding.
Engineering responses
  • Compute execution time explicitly for each design using measured mixes.
  • Model pipeline stalls conservatively and test sensitivity to higher stall rates.
  • Deploy pre-decoding, μop caches, or hardwired control for latency-critical paths.
