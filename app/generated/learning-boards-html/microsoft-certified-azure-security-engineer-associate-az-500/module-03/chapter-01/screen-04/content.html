Network Security Groups (NSGs): Your Virtual Firewall

Controlling inbound and outbound traffic in Azure Virtual Networks

What is an NSG?

An NSG is a virtual firewall that filters network traffic to and from Azure resources in an Azure Virtual Network. It acts as a security guard, inspecting every packet.

  • •Controls inbound and outbound traffic.
  • •Applies to network interfaces (NICs) or subnets.
  • •Decides whether to allow or deny traffic based on rules.
Key Takeaway

NSGs are stateful virtual firewalls, essential for controlling traffic flow and providing a foundational security layer in Azure.
