Dissecting NSG Security Rules

Understanding the components that define traffic flow

1

Source & Destination

IP addresses, IP ranges, Service Tags (e.g., Internet, VirtualNetwork), or Application Security Groups (ASGs).

2

Port Ranges

Specific ports (e.g., 80, 443, 3389) or ranges (e.g., 1000-2000) for source and destination.

3

Protocol

TCP, UDP, ICMP, or Any. Defines the type of network communication.

4

Direction & Access

Inbound or Outbound traffic. Access can be Allow or Deny.

Rule Priority (100-4096)

A numerical value that determines the order in which rules are processed. Lower numbers have higher precedence.

Example: Rule A (Priority 100, Allow SSH) vs. Rule B (Priority 200, Deny All Inbound). Rule A will be evaluated first, allowing SSH traffic before Rule B denies everything else.

Key Takeaway

Each NSG rule component is critical for precise traffic control, with 'Priority' being key for rule evaluation order.
