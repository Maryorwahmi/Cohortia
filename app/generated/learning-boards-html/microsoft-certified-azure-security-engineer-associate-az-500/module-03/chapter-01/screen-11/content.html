Implementing NSGs and ASGs: Network Infrastructure Setup

Creating virtual networks, subnets, and application security groups

# 1. Create a resource groupaz group create --name ASG-NSG-Demo-RG --location eastus# 2. Create a Virtual Network (VNet)az network vnet create --resource-group ASG-NSG-Demo-RG --name MyVNet --address-prefix 10.0.0.0/16# 3. Create subnets for web and database serversaz network vnet subnet create --resource-group ASG-NSG-Demo-RG --vnet-name MyVNet --name WebSubnet --address-prefix 10.0.1.0/24az network vnet subnet create --resource-group ASG-NSG-Demo-RG --vnet-name MyVNet --name DbSubnet --address-prefix 10.0.2.0/24# 4. Create Application Security Groups (ASGs)az network asg create --resource-group ASG-NSG-Demo-RG --name WebASG --location eastusaz network asg create --resource-group ASG-NSG-Demo-RG --name DbASG --location eastus

Resource Group & VNet

The resource group organizes resources, and the VNet provides the isolated network space for your application.

Subnets for Segmentation

Subnets logically divide your VNet, allowing for distinct security policies and resource isolation.

Application Security Groups

ASGs enable grouping of VMs by application role, simplifying rule definition and management.

Key Takeaway

Properly structured VNets, subnets, and ASGs are the foundation for implementing effective network security in Azure.
