NSG Association: Network Interface vs. Subnet

Defining the scope of your security policies

Network Interface (NIC) Association

When an NSG is associated with a NIC, its rules apply only to that specific virtual machine. This provides granular control for individual VMs.

  • •VM-specific security policies.
  • •Overrides subnet NSG rules for outbound traffic.

Use Case: Apply a unique security policy to a jump box VM, allowing specific management access not permitted for other VMs in the subnet.

Subnet Association

When an NSG is associated with a subnet, its rules apply to all virtual machines within that subnet. This enforces a baseline security posture for a group of VMs.

  • •Applies to all VMs in the subnet.
  • •Evaluated first for inbound traffic.

Use Case: Block all inbound internet access to a backend database subnet, protecting all database servers within it.

Key Takeaway

Combining NIC and subnet NSGs allows for layered security, providing both broad protection and specific exceptions.
