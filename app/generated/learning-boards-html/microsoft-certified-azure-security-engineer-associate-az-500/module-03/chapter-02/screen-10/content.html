DNAT Rule Collections

Translating inbound public IPs to private IPs

What are DNAT Rules?

  • Used for Destination Network Address Translation.
  • Translates inbound public IP addresses to private IP addresses.
  • Enables external access to internal resources securely.
  • Processed first in the Azure Firewall rule hierarchy.
Example Scenario

Exposing a web server: A DNAT rule maps the firewall's public IP (e.g., 20.1.2.3:80) to your web server's private IP (e.g., 10.0.1.4:80) within the VNet.

How DNAT Works

Internet (Public IP)
Azure Firewall (DNAT Rule)
Internal VNet (Private IP)
Key Takeaway

DNAT rules are essential for securely publishing services from your VNet to the internet via the firewall's public IP.
