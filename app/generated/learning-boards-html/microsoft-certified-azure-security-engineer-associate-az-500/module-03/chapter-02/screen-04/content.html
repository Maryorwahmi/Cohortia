Core Concept

Azure Firewall vs. Network Security Groups

Understanding the key differences in network security

Azure Firewall

  • Managed, cloud-native, stateful service.
  • Centralized deployment (e.g., hub VNet).
  • Advanced threat protection: FQDN filtering, Threat Intelligence.
  • Supports Network, Application, and DNAT rule collections.
  • Ideal for perimeter security and consistent policy enforcement.
Key Takeaway

Azure Firewall provides a robust, centralized security appliance for advanced, stateful traffic inspection.

Network Security Groups (NSGs)

  • Distributed, stateless packet filtering.
  • Applied at NIC or subnet level.
  • Filters based on IP, port, protocol (basic).
  • No FQDN filtering or built-in threat intelligence.
  • Best for micro-segmentation within VNets.
Common Misconception

NSGs are not a replacement for a centralized firewall; they serve different purposes in network security.
