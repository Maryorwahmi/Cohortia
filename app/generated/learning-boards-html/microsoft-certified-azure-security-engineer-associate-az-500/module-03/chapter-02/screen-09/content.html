Rule Processing Logic

Azure Firewall Rule Processing Order

Understanding how rules are evaluated

1

DNAT Rules

Destination Network Address Translation for inbound traffic.

2

Network Rules

Filter based on IP, port, and protocol (TCP, UDP, ICMP, Any).

3

Application Rules

Filter outbound HTTP/S traffic based on FQDNs.

Key Takeaway

Rules are processed in a strict order: DNAT, then Network, then Application, with priority within each collection.
