Deployment Walkthrough

Preparing for Azure Firewall Deployment

Setting up the foundational network infrastructure

Key Steps for Network Setup

  • Create a Resource Group to organize all related resources.
  • Define a Hub Virtual Network (VNet) to host the firewall.
  • Create a dedicated subnet named `AzureFirewallSubnet` within the Hub VNet.
  • Ensure the `AzureFirewallSubnet` is exactly `/26` in size.
  • Plan IP addressing to avoid conflicts and meet requirements.
Common Mistake

Forgetting to create the `AzureFirewallSubnet` or using an incorrect size (e.g., not /26) will cause deployment failure.

Key Takeaway

Proper network preparation, especially the dedicated /26 subnet, is crucial for successful Azure Firewall deployment.

# Azure CLI Commands: Network Setup
# 1. Create Resource Group
az group create --name Firewall-Demo-RG --location eastus

# 2. Create Hub VNet and Firewall Subnet
az network vnet create \
  --resource-group Firewall-Demo-RG \
  --name HubVNet \
  --address-prefix 10.0.0.0/16 \
  --location eastus

az network vnet subnet create \
  --resource-group Firewall-Demo-RG \
  --vnet-name HubVNet \
  --name AzureFirewallSubnet \
  --address-prefix 10.0.0.0/26
These commands establish the necessary resource group and hub VNet with the required firewall subnet.
