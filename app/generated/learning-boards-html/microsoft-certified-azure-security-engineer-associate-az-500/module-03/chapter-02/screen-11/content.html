Rule Collection Type

Network Rule Collections

Granular control over IP, port, and protocol traffic

Network Rule Capabilities

  • Filter traffic based on Source/Destination IP addresses.
  • Control access using specific ports and protocols (TCP, UDP, ICMP, Any).
  • Centralized management plane for all network-level rules.
  • Applies to traffic between VNets, to the internet, or within a VNet.
  • Processed after DNAT rules, before Application rules.
Example Scenario

Allow outbound SSH: Create a network rule to permit outbound TCP traffic on port 22 from your VMs (source IP range) to a specific management server's public IP (destination IP).

Network Rule Structure

Source IP(s)
Protocol & Port(s)
Destination IP(s)
Key Takeaway

Network rules provide centralized, IP/port/protocol-based filtering, offering a powerful layer of defense for network traffic.
