Threat Intelligence-based Filtering

Proactive defense against known malicious traffic

How it Works

  • Automatically blocks traffic to/from known malicious IP addresses and domains.
  • Leverages Microsoft-curated threat intelligence feeds.
  • Provides proactive protection against common attack vectors.
  • Reduces manual intervention for threat mitigation.
Configuration Modes
  • Alert only: Logs malicious traffic but allows it to pass.
  • Alert and deny: Blocks malicious traffic and logs the event (recommended for production).

Benefits & Best Practices

Enhanced Security Posture
Automated Defense
Reduced Operational Overhead
Key Takeaway

Enable Threat Intelligence in 'Alert and deny' mode for production to leverage automated, proactive defense against known threats.
