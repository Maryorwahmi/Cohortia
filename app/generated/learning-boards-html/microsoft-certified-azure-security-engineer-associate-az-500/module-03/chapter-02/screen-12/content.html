Application Rule Collections

Filtering outbound HTTP/S traffic by FQDNs

Key Features of Application Rules

  • Filter outbound HTTP/S traffic based on Fully Qualified Domain Names (FQDNs).
  • Works for encrypted HTTPS traffic without SSL termination.
  • Crucial for preventing data exfiltration and ensuring compliance.
  • Processed after DNAT and Network rules.
  • Allows precise control over web and SaaS service access.
Example Scenario

Allowing specific web access: Permit VMs to access *.nuget.org and *.github.com, while blocking all other outbound web traffic.

Key Takeaway

Application rules provide unique FQDN-based filtering for HTTP/S, offering fine-grained control over outbound web connectivity.

# Azure CLI Commands: Configure Application Rule
# 7. Configure Azure Firewall Application Rule
az network firewall application-rule create \
  --resource-group Firewall-Demo-RG \
  --firewall-name MyAzureFirewall \
  --collection-name AppRules \
  --name AllowMicrosoft \
  --priority 100 \
  --action Allow \
  --source-addresses 10.1.1.0/24 \
  --protocols Http=80 Https=443 \
  --fqdn-tags None \
  --target-fqdns www.microsoft.com
This command creates an application rule to allow outbound HTTPS traffic to www.microsoft.com.
