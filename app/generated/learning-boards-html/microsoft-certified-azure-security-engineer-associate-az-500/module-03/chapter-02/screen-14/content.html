Key Concepts: Part 1

Essential terms for Azure Firewall

Azure Firewall

A managed, cloud-native, stateful network security service providing advanced threat protection for Azure Virtual Networks.

Hub-and-Spoke Topology

A network architecture where a central 'hub' VNet hosts shared services (like Azure Firewall) and 'spoke' VNets host workloads.

DNAT Rule Collection

Rules used for Destination Network Address Translation, typically for inbound traffic to expose internal services via the firewall's public IP.

Summary Takeaway

Azure Firewall provides centralized, advanced network security, best implemented in a hub-and-spoke model, with DNAT rules handling inbound service exposure.
