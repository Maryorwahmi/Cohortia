Key Concepts: Part 2

Advanced rule types and threat protection

Network Rule Collection

Rules that filter traffic based on IP addresses, ports, and protocols (TCP, UDP, ICMP, Any).

Application Rule Collection

Rules that filter outbound HTTP/S traffic based on Fully Qualified Domain Names (FQDNs), supporting both HTTP and HTTPS.

Threat Intelligence-based Filtering

A feature that automatically blocks traffic to and from known malicious IP addresses and domains, leveraging Microsoft's curated threat feeds.

User Defined Routes (UDRs)

Custom routing rules that override Azure's default routing, often used to direct traffic through a network virtual appliance like Azure Firewall.

Summary Takeaway

Azure Firewall's advanced rules (Network, Application) and Threat Intelligence, combined with UDRs, provide comprehensive and proactive network security.
