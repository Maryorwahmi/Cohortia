Module 3›Chapter 3.3›Prevention Mode

Actively Blocks Threats

In Prevention Mode, the WAF actively blocks requests that match configured threat rules. It returns an error page to the user, preventing malicious traffic from reaching your backend servers.

Production Environment Ready

  • Recommended mode for production deployments.
  • Provides real-time, proactive protection.
  • Requires thorough testing in Detection Mode first.
  • Minimizes false positives to ensure application availability.

Example: Blocking XSS in Production

After extensive testing, your WAF is in Prevention Mode. A user attempts to submit a comment containing a known Cross-Site Scripting (XSS) payload. The WAF immediately detects this malicious pattern, blocks the request, and displays a generic error page to the user. This prevents the XSS script from being stored or executed, protecting other users and maintaining the integrity of your application.

Key Takeaway

Prevention Mode is the active defense stage for WAF, blocking threats in real-time. It must be implemented only after careful validation in Detection Mode to avoid disrupting legitimate application traffic.
