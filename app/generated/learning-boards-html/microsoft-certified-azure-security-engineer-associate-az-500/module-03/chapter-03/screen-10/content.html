Monitor & Log Threats

In Detection Mode, the WAF monitors all traffic for threats based on configured rules and logs alerts, but it does not actively block any requests. Traffic still reaches your backend.

Key Benefits

  • Ideal for initial deployment and testing.
  • Identifies potential false positives without impacting users.
  • Allows for fine-tuning rule sets and creating exclusions.
  • Provides insights into WAF behavior with your application traffic.

Example: False Positive Identification

Your application has a legitimate feature that involves sending a long string of encoded data in a URL parameter. In Detection Mode, the WAF might flag this as a potential 'Buffer Overflow' attack. By observing the logs, you realize this is legitimate traffic. You can then create an exclusion rule for this specific parameter, preventing it from being blocked when you eventually switch to Prevention Mode, ensuring your application's functionality remains intact.

Key Takeaway

Detection Mode is a crucial testing phase for WAF, allowing you to identify and resolve false positives without disrupting legitimate user traffic, ensuring a smooth transition to active protection.
