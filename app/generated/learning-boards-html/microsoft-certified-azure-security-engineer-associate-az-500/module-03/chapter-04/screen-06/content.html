Types of Shared Access Signatures

Choosing the right SAS for enhanced security

User Delegation SAS

Secured with Azure AD credentials. Offers superior security and auditability. Recommended for most application scenarios.

  • Leverages Azure AD for authentication
  • Most secure option
  • Auditable via AD logs

Service SAS

Secured with the storage account key. Grants access to a specific storage service (e.g., Blob, Queue).

  • Uses storage account key
  • Limited to one service type
  • Less secure than User Delegation SAS

Account SAS

Secured with the storage account key. Grants access to multiple storage services.

  • Uses storage account key
  • Accesses multiple service types
  • Broadest access, highest risk if compromised
Key Takeaway

Prioritize User Delegation SAS for applications to leverage Azure AD for authentication, minimizing reliance on storage account keys and enhancing security.
