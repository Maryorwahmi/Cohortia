Security Mechanism

Shared Access Signatures (SAS)

Granting granular, time-limited access to storage resources

What is an SAS?

A URI that grants restricted access rights to your Azure Storage resources.

Key Parameters

  • Permissions (Read, Write, Delete, List)
  • Resources (Blob, Container, File, Queue, Table)
  • Validity (Start & End Times)
  • Allowed IP Addresses

Example Scenario

Allow a mobile app to upload images to a specific blob container for only 30 minutes, with no other permissions.

SAS Token URI

https://mystorage.blob.core.windows.net/mycontainer?sv=2021-08-01&st=2023-01-01T00:00:00Z&se=2023-01-01T00:30:00Z&sr=c&sp=rw&sig=...

A secure, time-bound link with specific permissions.

Key Takeaway

SAS tokens enable fine-grained, temporary access to storage resources, significantly enhancing security by limiting exposure compared to full access keys.
