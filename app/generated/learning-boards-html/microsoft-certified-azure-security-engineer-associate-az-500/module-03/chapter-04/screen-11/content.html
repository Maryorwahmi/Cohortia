Authorization Models

Key Vault Access Policies vs. RBAC

Controlling access to your sensitive Key Vault data

Vault Access Policies

Define specific permissions (e.g., get, list, set for secrets) for users, groups, or applications directly on a Key Vault.

  • Configured per Key Vault
  • Fine-grained control over operations
  • Legacy method, still relevant for specific needs

Azure Role-Based Access Control (RBAC)

Assign predefined roles (e.g., 'Key Vault Secrets User') at Key Vault, resource group, or subscription level for unified access management.

  • Unified, granular access management
  • Integrates with Azure AD
  • Preferred for managing access at scale
Key Takeaway

While Access Policies offer granular control within a vault, Azure RBAC provides a more unified and scalable approach for managing Key Vault access across your Azure environment.
