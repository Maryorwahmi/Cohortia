Key Principle

Embracing Just-in-Time (JIT) Access

Granting elevated permissions only when needed, for a limited duration.

How JIT Access Works

  • Request: User requests activation for an eligible role.
  • Justification: User provides a reason for needing elevated access.
  • Approval (Optional): A designated approver grants or denies the request.
  • Activation: User gains permissions for a specified, limited time.
  • Deactivation: Role automatically deactivates after the duration expires.
Key Takeaway

JIT access is a proactive security measure that minimizes the window of opportunity for attackers by making privileged roles temporary.

JIT Access Flow

From eligible to active, then back to baseline.

Eligible Assignment

User is qualified, but permissions are inactive.

Role Activation

Temporary elevation for specific tasks.

Automatic Deactivation

Permissions revoked after duration.
