Key Concepts: PIM Operations

Understanding the lifecycle of privileged role management.

Active Assignment

A PIM assignment where a user currently holds the permissions of a role.

Role Activation

The process by which an eligible user requests and gains temporary access to a privileged role.

Access Reviews

A PIM feature that allows administrators to periodically review and certify who has access to privileged roles.

Summary Takeaway

PIM's operational features ensure that privileged access is not only temporary but also continuously verified and auditable, reinforcing a strong security posture.
