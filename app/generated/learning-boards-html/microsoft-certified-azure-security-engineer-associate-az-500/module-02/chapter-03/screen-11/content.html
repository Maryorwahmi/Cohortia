Lab: Assigning an Eligible User Administrator Role

Step-by-step guide to making a user eligible for a PIM role.

Scenario: Implement JIT for User Administrator

  1. Navigate to the Azure portal and search for "Azure AD Privileged Identity Management."
  2. In the PIM blade, under "Manage," select "Azure AD roles."
  3. Select "Roles" from the left-hand menu.
  4. Search for and select the "User Administrator" role.
  5. Click "Add assignments."
  6. Under "Select member(s)," search for and select your own user account.
  7. For "Assignment type," choose "Eligible."
  8. Click "Next," then "Assign."

Checkpoint: Eligible Assignment

After completing these steps, you should see your user account listed as an 'Eligible assignment' for the 'User Administrator' role in PIM. This means you have the potential to activate the role, but do not currently hold its permissions.

Why this matters:

This establishes the foundation for Just-in-Time access, ensuring that privileged permissions are not permanently active.

Key Takeaway

Successfully assigning a role as 'Eligible' is the critical first step in implementing PIM, transforming permanent access into on-demand, temporary elevation.
