Lab Walkthrough

Hands-on: Creating an MFA Policy (Part 2)

Configuring cloud apps, location conditions, and grant controls.

Policy Configuration Steps

1

Under "Assignments" > "Cloud apps or actions": Include "Microsoft Azure Management".

2

Under "Conditions" > "Locations": Configure 'Yes', Include 'Any location', Exclude 'Corporate Network' (Named location).

3

Under "Access controls" > "Grant": Select "Grant access" and check "Require multi-factor authentication".

4

Ensure "Require one of the selected controls" is chosen.

Important Note

If you haven't created a 'Corporate Network' named location, do so under 'Named locations' by adding your public IP range before configuring this step.

Finalizing and Testing

5

Set "Enable policy" to "Report-only".

6

Click "Create" to save the policy.

7

Navigate to "Conditional Access" > "What If" to test the policy's predicted outcome.

Reflection Prompt

Consider a scenario where you need to block access to Salesforce for users not on a compliant device. How would you structure this Conditional Access policy?

Key Takeaway

Completing policy configuration with precise conditions and grant controls, then enabling in 'Report-only' mode, is crucial for safe and effective deployment and validation.
