Access Controls

Grant Controls: Defining 'Then' Access Requirements

Specifying what is required to gain access.

Grant Access Options

These controls determine if access is granted and under what conditions. You can choose to require one or all of the selected controls.

  • Require multi-factor authentication: Adds a second verification step.
  • Require device to be marked as compliant: Integrates with Intune for device health.
  • Require Hybrid Azure AD joined device: Ensures devices are registered with both AD and Azure AD.
  • Require approved client app: Restricts access to specific, secure applications.
Example Scenario

For accessing sensitive HR data, require both MFA and a compliant device.

How Grant Controls Work

1

User attempts to access a cloud app.

2

Conditional Access policy conditions are met.

3

Grant controls are evaluated (e.g., Is MFA required? Is device compliant?).

4

If all required controls are satisfied, access is granted.

5

If not, access is blocked or challenged.

Key Takeaway

Grant controls are the gatekeepers, enforcing essential security requirements like MFA and device compliance before a user can access protected resources.
