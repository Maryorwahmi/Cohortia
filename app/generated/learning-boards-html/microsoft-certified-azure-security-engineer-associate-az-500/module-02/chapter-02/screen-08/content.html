Access Controls

Session Controls: Fine-Grained In-Session Management

Applying restrictions during an active user session.

In-Session Restrictions

Session controls apply restrictions and monitoring *after* access has been granted, throughout the user's active session.

  • Use app enforced restrictions: Limits actions like download/print in apps like SharePoint.
  • Use Conditional Access App Control: Real-time monitoring and control via Defender for Cloud Apps.
  • Sign-in frequency: Periodically re-authenticates users to verify identity.
  • Persistent browser session: Controls how long users stay signed in.
Example Scenario

Prevent downloading sensitive documents from SharePoint Online when accessed from an unmanaged device.

How Session Controls Enhance Security

1

User passes initial Grant controls and gains access.

2

Session controls are applied to the active session.

3

Actions within the app are monitored and restricted (e.g., no downloads).

4

Continuous security is maintained throughout the session.

5

If a policy violation occurs, action can be taken (e.g., block specific action).

Key Takeaway

Session controls provide continuous, real-time security management during a user's active session, offering granular control over actions within cloud applications.
