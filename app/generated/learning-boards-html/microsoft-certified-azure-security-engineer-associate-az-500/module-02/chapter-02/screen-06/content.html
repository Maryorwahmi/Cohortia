Policy Structure

Building Blocks: Assignments - Conditions

Specifying 'where' and 'how' access attempts are made.

Device Platforms

Target specific operating systems like iOS, Android, Windows, or macOS.

Locations

Define trusted IP ranges or block access from untrusted geographic regions.

Client Apps

Specify browser, mobile apps, or block legacy authentication protocols.

Device State

Require devices to be marked as compliant or Hybrid Azure AD joined.

Sign-in / User Risk

Integrate with Identity Protection to use real-time risk assessments.

These conditions form the 'IF' part, enabling highly adaptive security decisions.

Key Takeaway

Leveraging diverse conditions allows Conditional Access to make intelligent, risk-based decisions, moving beyond static security to a dynamic, context-aware approach.
