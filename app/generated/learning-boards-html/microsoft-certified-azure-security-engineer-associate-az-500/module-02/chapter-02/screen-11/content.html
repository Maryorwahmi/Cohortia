The 'What If' Tool: Simulating Policy Impact

Predicting policy outcomes before deployment.

Purpose of the 'What If' Tool

The 'What If' tool allows you to simulate a user's sign-in attempt against your Conditional Access policies to predict the outcome.

  • Prevent unintended consequences: Avoid accidental lockouts or security gaps.
  • Troubleshoot policies: Identify why a policy might not be behaving as expected.
  • Validate design: Confirm new policies will work correctly before enabling them.
  • Understand policy interaction: See how multiple policies combine to affect access.
Why it's Critical

It's the last line of defense against misconfigurations, ensuring policies are safe and effective before impacting real users.

How to Use the 'What If' Tool

1

Navigate to Conditional Access > 'What If' in the Azure portal.

2

Specify user, cloud app, IP address, device platform, etc.

3

Click 'What If' to run the simulation.

4

Review the predicted outcome (Grant, Block, Require MFA) and applicable policies.

Key Takeaway

The 'What If' tool is an essential pre-deployment step, allowing you to proactively test and validate Conditional Access policies to ensure desired security outcomes without user impact.
