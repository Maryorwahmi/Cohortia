Monitoring Identity Risks in Azure Portal

Leveraging dedicated reports for proactive threat hunting.

Risk Detections Report

Lists all individual suspicious events identified by Identity Protection, with details like detection type and risk level.

Risky Users Report

Aggregates all detected risks for specific users, showing accounts frequently targeted or persistently compromised.

Risky Sign-ins Report

Provides a consolidated view of all sign-in attempts flagged as risky, including details about sign-in properties.

Key Takeaway

These reports are essential for proactive threat hunting, incident response, and improving Identity Protection's machine learning models.
