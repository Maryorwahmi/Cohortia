Best Practice

Testing Policies with Report-Only Mode

Safely evaluate policy impact before full enforcement.

Simulate Impact

Observe which users and sign-ins would be affected without enforcing any actions.

Fine-Tune Policies

Gather data to adjust risk thresholds and remediation actions for optimal performance.

Prevent Lockouts

Avoid inadvertently locking out legitimate users, including administrators, during deployment.

Key Takeaway

Always start with report-only mode to validate policies and prevent unintended user disruption.

Policy Configuration
Set Policy to 'Report-only'

Policy evaluates risks but does not enforce actions.

Monitor Reports

Review 'Risky Users' and 'Risky Sign-ins' to see potential impact.

Adjust & Enforce

Refine policy settings, then switch to 'On' mode for enforcement.
