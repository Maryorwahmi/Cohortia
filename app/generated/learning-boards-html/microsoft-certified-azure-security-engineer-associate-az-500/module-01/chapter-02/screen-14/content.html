Key Concepts

Essential terms from this chapter

Hybrid Identity

A solution connecting on-premises Active Directory with Azure Active Directory, providing a single identity for users across both environments.

Azure AD Connect

A Microsoft tool used to synchronize users, groups, and contacts from on-premises Active Directory to Azure AD.

Password Hash Sync (PHS)

An Azure AD Connect authentication method where a hash of the user's password hash is synchronized to Azure AD.

Summary Takeaway

Hybrid Identity unifies user access across on-premises and cloud, powered by Azure AD Connect, with PHS being a common and secure authentication method.
