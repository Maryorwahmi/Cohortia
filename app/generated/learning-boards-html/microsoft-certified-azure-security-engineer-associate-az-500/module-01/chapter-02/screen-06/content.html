Definition

Pass-through Authentication (PTA)

PTA is an Azure AD Connect authentication method where Azure AD sign-in requests are validated directly against on-premises Active Directory via lightweight agents.

Key Advantages & Requirements
  • Passwords Stay On-Premises: Enhanced control for compliance.
  • No Password Hashes in Cloud: Strong security posture.
  • Requires Agents: Lightweight agents on domain-joined servers.
  • On-Premises Dependency: Cloud authentication relies on agent and AD availability.
How PTA Works
Key Takeaway

PTA ensures passwords never leave on-premises AD by redirecting cloud authentication requests to local agents, offering strong security but introducing a dependency on on-premises infrastructure.
