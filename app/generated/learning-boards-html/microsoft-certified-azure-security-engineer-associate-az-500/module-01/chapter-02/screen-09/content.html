Installation Overview

Wizard-Driven Deployment

Azure AD Connect is installed via a guided wizard, simplifying the process of setting up identity synchronization between on-premises AD and Azure AD.

Prerequisites
  • Dedicated Server: Install on a domain-joined server.
  • Network Connectivity: Ensure access to domain controllers and Azure AD.
  • Administrative Privileges: Required for installation and configuration.
  • Service Account: Azure AD Connect creates a highly privileged service account.
Key Configuration Steps
1

Source Directories: Specify on-premises AD forests.

2

Target Directory: Select your Azure AD tenant.

3

Authentication Method: Choose PHS, PTA, or AD FS.

4

Synchronization Scope: Define OUs and attributes to sync.

Key Takeaway

Install Azure AD Connect on a dedicated server with proper network access, then use the wizard to configure source/target directories, authentication method, and synchronization scope.
