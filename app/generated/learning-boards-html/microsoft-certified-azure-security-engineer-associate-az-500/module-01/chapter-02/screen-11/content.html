Overview

Ensuring Identity Flow

After Azure AD Connect installation, it's crucial to verify that identity synchronization is working correctly to ensure users can access cloud resources.

PowerShell Commands
# Check the last synchronization time
Get-MsolDirSyncFeatures -Feature PasswordSync | Select-Object LastDirSyncTime

# Force a delta synchronization cycle (use with caution)
Start-ADSyncSyncCycle -PolicyType Delta

These commands provide quick insights into sync status and allow for manual intervention when necessary.

Synchronization Service Manager

This GUI tool provides detailed insights into the synchronization process, helping to diagnose and resolve complex issues.

  • Connectors: View status of AD and Azure AD connectors.
  • Operations: Review run histories for sync cycles and errors.
  • Metaverse Search: Inspect individual object attributes and their flow.
  • Error Resolution: Identify specific synchronization errors and their causes.
Key Takeaway

Use PowerShell for quick sync status checks and forced delta syncs, and leverage the Synchronization Service Manager GUI for in-depth troubleshooting and monitoring of identity flow.
