Key Concepts

Essential terms from this chapter

Pass-through Auth (PTA)

An Azure AD Connect authentication method where authentication requests are validated directly against on-premises Active Directory via lightweight agents.

Federation (AD FS)

An Azure AD Connect authentication method where Azure AD trusts an on-premises Active Directory Federation Services (AD FS) infrastructure for user authentication.

Azure AD Connect Health

A monitoring service that provides insights into the health, performance, and synchronization status of Azure AD Connect.

Summary Takeaway

PTA and AD FS Federation offer distinct authentication controls, while Azure AD Connect Health is essential for monitoring and maintaining the health of your hybrid identity solution.
