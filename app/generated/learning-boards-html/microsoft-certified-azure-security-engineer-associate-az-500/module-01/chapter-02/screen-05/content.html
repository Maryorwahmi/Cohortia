Definition

Password Hash Synchronization (PHS)

PHS is an Azure AD Connect authentication method where a hash of the user's password hash is synchronized from on-premises AD to Azure AD for cloud authentication.

Key Advantages
  • Simplicity: Easy to implement with minimal infrastructure.
  • High Availability: Authentication handled by Azure AD, reducing on-premises dependency.
  • Enhanced Security: Actual passwords never leave on-premises AD.
  • Seamless SSO: Enables automatic sign-in for users on corporate networks.
How PHS Works
Key Takeaway

PHS is a secure, simple, and highly available authentication method that synchronizes password hashes to Azure AD, enabling seamless cloud access without storing actual passwords in the cloud.
