Security Controls

Managing Guest Invitations

Controlling who can invite guests and from which domains

Guest Invite Settings

  • Control who can invite guest users (e.g., administrators only, or members and guests).
  • Prevents unauthorized or accidental invitations.
  • Ensures a controlled and auditable onboarding process.
Configuration Path

Azure Active Directory > External identities > External collaboration settings

Collaboration Restrictions

  • Allow List: Only allow invitations to specified domains (e.g., `fabrikam.com`).
  • Deny List: Block invitations to specified domains (e.g., `gmail.com`, `outlook.com`).
  • Critical for preventing collaboration with untrusted or unapproved entities.
Key Takeaway

Implement strict controls over who can invite guests and use domain restrictions to enforce secure collaboration boundaries.
