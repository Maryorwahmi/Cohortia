Scenario Application

Scenario: Securing Partner Access

Applying collaboration settings and access reviews in practice

01

Restrict Guest Permissions

Set guest user access to 'limited' to prevent broad directory visibility.

02

Control Inviters & Domains

Limit who can invite guests and use domain allow/deny lists (e.g., allow `fabrikam.com`, deny `gmail.com`).

03

Implement Access Reviews

Schedule recurring reviews for partner groups to ensure access remains necessary and is promptly removed if not.

Why it Matters

This layered approach ensures that external collaboration is both efficient and secure, minimizing risks associated with external access and maintaining compliance.

Key Takeaway

Proactive configuration of collaboration settings combined with regular access reviews creates a robust defense against external identity risks.
