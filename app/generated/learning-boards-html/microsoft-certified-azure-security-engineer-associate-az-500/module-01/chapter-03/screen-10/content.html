Security Configuration

Controlling Guest User Permissions

Restricting what guest users can see and do in your directory

Default Guest Permissions

By default, guest users may have broader visibility into your directory than required, posing an information leakage risk.

Principle of Least Privilege

Always grant the minimum permissions necessary for guest users to perform their tasks, and no more.

Configuration Path

Azure Active Directory > External identities > External collaboration settings > Guest user access

Recommended Setting

Select "Guest users have limited access to properties and memberships of directory objects."

Key Takeaway

Proactively restrict guest user permissions to prevent unnecessary information exposure and strengthen your security posture.
