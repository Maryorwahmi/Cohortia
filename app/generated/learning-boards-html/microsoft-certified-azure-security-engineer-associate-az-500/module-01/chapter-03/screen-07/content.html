Onboarding Guest Users

Using the Azure portal and PowerShell to send invitations

Azure Portal Method

  • Navigate to Azure Active Directory > Users > New guest user.
  • Provide email, display name, and optional personal message.
  • Guest receives email link to accept invitation.
  • Account provisioned with limited default permissions.
Important Note

Always apply the principle of least privilege: assign specific roles or groups to grant access, not broad permissions.

# Connect to Azure AD
Connect-AzureAD

# Define guest user details
$GuestEmail = "guest.user@example.com"
$DisplayName = "Guest User Example"
$InviteMessage = "Welcome to Cohortia's portal."
$RedirectUrl = "https://myapps.microsoft.com"

# Invite the guest user
New-AzureADMSInvitation -InvitedUserEmailAddress $GuestEmail -DisplayName $DisplayName -SendInvitedUserMessage $true -InvitedUserMessageInfo $InviteMessage -InviteRedirectUrl $RedirectUrl
Key Takeaway

Use the Azure portal for simple, manual invitations and PowerShell for automated or bulk guest user onboarding.
