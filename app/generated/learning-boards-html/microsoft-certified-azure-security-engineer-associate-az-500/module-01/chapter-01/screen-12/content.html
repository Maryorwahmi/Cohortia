Creating Users, Groups, and Administrative Units

Step-by-step guide to setting up the delegation foundation.

1

Create CloudOps Admin User

Navigate to Azure AD > Users > New user. Set User name: cloudops.admin and a strong initial password. Ensure 'Require new password on first sign-in' is checked.

2

Create CloudOps Users Security Group

Go to Azure AD > Groups > New group. Set Group type: Security and Group name: CloudOps Users.

3

Add Test User to Group

Create a new user test.cloudops and add them to the CloudOps Users group. This user will be managed by the CloudOps Admin.

Key Takeaway

These initial steps establish the necessary identities and groups, forming the base for defining our administrative unit and delegation scope.
