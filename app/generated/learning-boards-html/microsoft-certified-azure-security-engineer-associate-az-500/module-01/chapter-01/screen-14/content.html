Key Concepts: Azure AD Identities

Essential terms and definitions from this chapter.

Azure Active Directory (Azure AD)

Microsoft's cloud-based identity and access management service, providing authentication and authorization for cloud resources and applications.

Azure AD Tenant

A dedicated instance of Azure AD for an organization, containing its users, groups, and application registrations, isolated from others.

Cloud-only User

A user account created and managed entirely within Azure AD, without an on-premises counterpart, ideal for cloud-native environments.

Chapter Summary

Azure AD is the cornerstone of cloud identity, providing a dedicated tenant for each organization to manage users, groups, and applications securely. Understanding cloud-only and synchronized users is key to effective identity governance.
