Key Concepts: Groups and Delegation

Understanding group types, administrative units, and security principles.

Synchronized User

A user account originating from an on-premises Active Directory and replicated to Azure AD via Azure AD Connect.

Security Group

An Azure AD group used to manage access to Azure resources, applications, and services by assigning roles and permissions.

Administrative Unit (AU)

An Azure AD resource that allows for the logical grouping of users and groups to delegate administrative permissions over a specific subset of identities.

Chapter Summary

Groups streamline access management, with Security Groups being key for role assignment. Administrative Units enable granular delegation, and the Principle of Least Privilege is paramount for secure identity configurations.
