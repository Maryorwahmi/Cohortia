Azure AD Tenants and User Accounts

Provisioning your dedicated identity instance and creating users.

Azure AD Tenant

A dedicated, isolated instance of Azure AD for your organization, automatically created with your first Azure subscription. It houses all your identities.

Creating User Accounts
  • Cloud-only: Created and managed directly in Azure AD.
  • Synchronized: Replicated from on-premises Active Directory via Azure AD Connect.
Key Takeaway

Always apply the Principle of Least Privilege: grant users only the minimum permissions necessary for their job functions to reduce security risks.

Pro Tip

Regularly review user permissions and remove any unnecessary role assignments to maintain a strong security posture.
