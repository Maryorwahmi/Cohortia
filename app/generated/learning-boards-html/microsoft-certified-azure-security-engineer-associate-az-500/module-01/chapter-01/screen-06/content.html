Identity Types

Differentiating Azure AD Identity Types

Understanding cloud-only, synchronized, and guest users.

Cloud-only User

Account created and managed entirely within Azure AD, with no on-premises counterpart. Ideal for cloud-native organizations.

Example: A new administrator for a cloud-only startup.

Synchronized User

Originates from on-premises Active Directory and is replicated to Azure AD via Azure AD Connect. Changes sync from on-premises.

Example: An employee whose account is managed by the corporate domain controller.

Guest User

External identity invited to collaborate within your Azure AD tenant, from other ADs, Microsoft accounts, or social providers.

Example: A consultant from a partner company needing access to a project.

Key Takeaway

Each identity type has unique management and security considerations; understanding these differences is crucial for effective identity governance.
