Configuration Guide

Configuring Diagnostic Settings

Directing security-relevant logs to Log Analytics.

Purpose

Specify which log categories to collect and where to send them for each Azure resource.

Key Destination

Log Analytics Workspaces are the primary target for security-relevant logs.

Key Takeaway

Properly configured diagnostic settings are crucial for ensuring all necessary security logs are collected for analysis.

Diagnostic Settings Flow
1
Select Resource

Navigate to your Azure resource (e.g., VM, NSG, Web App).

2
Add Diagnostic Setting

Create a new setting, give it a name, and choose log categories.

3
Choose Destination

Select 'Send to Log Analytics workspace' and pick your workspace.
