Querying Security Logs with KQL

Identifying failed login attempts in Log Analytics.

Objective

Use KQL to query security events and identify failed login attempts in Log Analytics.

Generate Events

Attempt failed RDP (Windows) or SSH (Linux) logins on your configured VM.

Key Takeaway

KQL is essential for extracting actionable security intelligence from your collected logs.

KQL Query EditorLog Analytics
SecurityEvent| where EventID == 4625 // Failed logins (Windows)| where Computer == "YourVMName" // Replace with your VM's name| project TimeGenerated, Computer, Account, Activity, SubStatus| order by TimeGenerated desc
Syslog| where ProcessName == "sshd"| where SyslogMessage contains "Failed password" // Failed logins (Linux)| where Computer == "YourVMName" // Replace with your VM's name| project TimeGenerated, Computer, SyslogMessage| order by TimeGenerated desc
