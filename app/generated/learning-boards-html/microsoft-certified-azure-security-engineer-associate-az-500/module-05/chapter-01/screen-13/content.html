Hands-on Activity

Configuring Diagnostic Settings for a VM

A practical walkthrough to enable security log collection.

Objective

Configure diagnostic settings for an Azure VM to send security logs to Log Analytics.

Prerequisites

Azure subscription, running Azure VM (Windows/Linux), existing Log Analytics Workspace.

Key Takeaway

Correct diagnostic settings are the gateway for VM security events into Log Analytics.

Step-by-Step: VM Diagnostic Settings
1
Navigate to VM

In Azure portal, find your Virtual Machine.

2
Add Diagnostic Setting

Under 'Monitoring', select 'Diagnostic settings', then '+ Add diagnostic setting'.

3
Configure & Save

Name it, select 'allLogs' or specific security logs, choose Log Analytics Workspace, and save.
