Advanced KQL

Advanced KQL for Security Analysis

Deep dives into security incidents with complex queries.

Capabilities

Perform complex aggregations, time-series analysis, and joins across different log tables.

Common Mistake

Not understanding the specific schemas of different log tables (e.g., AzureActivity, SecurityEvent).

Key Takeaway

Leverage KQL's advanced features to uncover sophisticated attack patterns and conduct thorough investigations.

KQL Query ExamplesLog Analytics
AzureActivity| where OperationName == "Microsoft.Compute/virtualMachines/delete" // Track VM deletions| summarize count() by Caller, ResourceGroup, bin(TimeGenerated, 1h)
SigninLogs| where ResultType != 0 // Failed sign-ins| summarize FailedAttempts = count() by IPAddress, UserDisplayName, bin(TimeGenerated, 5m)| where FailedAttempts > 5 // Identify potential brute-force
