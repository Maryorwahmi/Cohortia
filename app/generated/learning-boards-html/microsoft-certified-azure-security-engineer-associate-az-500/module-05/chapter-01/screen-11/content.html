Advanced Threat Protection with Defender Plans

Tailored security for specific Azure resource types.

Purpose

Provide specific, tailored protections for different Azure resource types.

Examples

Defender for Servers, Defender for SQL, Defender for Storage, each with unique capabilities.

Key Takeaway

Activate specific Defender plans to ensure critical workloads receive specialized, advanced threat protection.

Key Defender Plans
Defender for ServersJIT VM access, adaptive controls
Defender for SQLVulnerability assessments, threat detection
Defender for StorageMalware scanning, sensitive data discovery
Defender for Key VaultThreat detection for secrets
