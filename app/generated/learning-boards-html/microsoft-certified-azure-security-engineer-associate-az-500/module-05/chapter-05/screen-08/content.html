Defender Plans in Action

Securing Modern Applications and Containers

How Azure Defender protects App Service and containerized environments.

Azure Defender for App Service
  • •Identifies code injection attempts.
  • •Detects web shell presence.
  • •Flags API abuse and other web attacks.
  • •Protects applications on Azure App Service.
Azure Defender for Containers
  • •Vulnerability management for container images.
  • •Real-time threat protection for AKS clusters.
  • •Monitors Azure Container Registry.
  • •Detects runtime threats in containers.
Key Takeaway

Defender for App Service secures web applications against common attacks, while Defender for Containers provides end-to-end protection for containerized workloads.

App Service Threat Example

Defender for App Service detects an attempt to upload a malicious script to your web application's directory, which could lead to remote code execution and compromise.

Container Threat Example

During runtime, Defender for Containers identifies a container in your AKS cluster attempting to establish an outbound connection to a known command-and-control server, indicating a potential compromise.

Why it Matters

As applications become more distributed and containerized, specialized security is vital to protect against new attack vectors and ensure the integrity of your cloud-native deployments.
