Adaptive Application Controls

Hardening virtual machines by whitelisting known-safe applications.

What are AAC?
  • •Creates a list of known-safe applications.
  • •Only allowed applications can run on VMs.
  • •Uses machine learning to recommend baselines.
  • •Any deviation is flagged as a security alert.
Security Benefit

Prevents the execution of unauthorized or malicious software, significantly reducing the risk of malware infections and persistent threats on VMs.

Key Takeaway

Adaptive application controls enforce application whitelisting on VMs, preventing unauthorized software execution and enhancing protection against malware and exploits.

Example: Web Server VM

On a VM configured as a web server, AAC allows IIS and necessary utilities but blocks any attempt to run an unknown executable, such as a PowerShell script downloaded from the internet.

Implementation Challenge

Careful planning is needed to avoid blocking legitimate applications. Initial setup often involves a 'audit-only' mode to identify and whitelist all necessary software before enforcement.

Why it Matters

AAC provides a strong defense against zero-day malware and unauthorized software, ensuring that only trusted applications can execute on your critical virtual machines.
