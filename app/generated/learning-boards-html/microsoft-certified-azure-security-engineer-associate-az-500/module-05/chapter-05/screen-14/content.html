Key Concepts

Essential terms for managing cloud security posture with Azure Defender for Cloud.

CSPM

Identifies and remediates misconfigurations and vulnerabilities to improve security posture.

CWPP

Provides advanced threat protection for specific cloud workloads like VMs, SQL, and containers.

Defender Plans

Specific paid offerings providing CWPP capabilities for different Azure resource types.

Summary Takeaway

Azure Defender for Cloud unifies security posture management and workload protection through specialized plans, all contributing to your overall Secure Score.
