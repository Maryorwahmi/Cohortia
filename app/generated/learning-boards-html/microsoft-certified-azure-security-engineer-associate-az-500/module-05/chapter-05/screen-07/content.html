Defender Plans in Action

Securing Storage and Key Vaults

Understanding how Azure Defender protects your data at rest and cryptographic keys.

Azure Defender for Storage
  • •Detects suspicious access patterns.
  • •Identifies malware uploads to blobs.
  • •Flags potential data exfiltration attempts.
  • •Protects Blob, File, and Data Lake Storage.
Azure Defender for Key Vault
  • •Detects unusual access to Key Vault accounts.
  • •Identifies potential brute-force attacks.
  • •Flags privilege escalation attempts.
  • •Protects keys, secrets, and certificates.
Key Takeaway

Defender for Storage safeguards your data at rest from exploitation, while Defender for Key Vault protects your critical cryptographic assets and secrets.

Storage Anomaly Example

An alert is triggered when a storage account, usually accessed only from within your corporate network, suddenly sees multiple successful logins from a foreign IP address, indicating potential compromise.

Key Vault Threat Example

Defender for Key Vault detects a rapid succession of failed attempts to retrieve a specific secret, followed by a successful attempt from a previously unseen identity, suggesting a brute-force attack and potential compromise.

Why it Matters

Protecting storage and key vaults is fundamental. Compromised storage can lead to data breaches, while compromised key vaults can undermine your entire cryptographic security posture.
