Defender Plans in Action

Protecting Servers and SQL Databases

Deep dive into Azure Defender for Servers and Azure Defender for SQL capabilities.

Azure Defender for Servers
  • •Vulnerability assessment for Windows/Linux VMs.
  • •EDR integration with Microsoft Defender for Endpoint.
  • •Just-in-Time (JIT) VM access.
  • •Adaptive application controls.
Azure Defender for SQL
  • •Protects Azure SQL Database, Managed Instance, and SQL on VMs.
  • •Detects SQL injection attacks.
  • •Identifies brute-force attacks.
  • •Covers other database-specific threats.
Key Takeaway

Defender for Servers provides comprehensive VM protection, while Defender for SQL offers specialized defense against database-specific threats.

Server Threat Example

Defender for Servers detects if an unauthorized executable is launched on a Windows VM, flagging it as a potential malware infection or intrusion attempt.

SQL Threat Example

Defender for SQL identifies a series of malformed queries targeting your Azure SQL Database, indicating a potential SQL injection attempt to extract sensitive data.

Why it Matters

These plans provide specialized, deep-level protection that generic security tools cannot offer, crucial for safeguarding your most critical infrastructure and data.
