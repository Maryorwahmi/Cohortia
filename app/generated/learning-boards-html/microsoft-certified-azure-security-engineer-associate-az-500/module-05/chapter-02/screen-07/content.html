Analytics Rules: The Core of Sentinel's Detection

Analytics rules are KQL (Kusto Query Language) queries that run against ingested data to detect specific patterns or anomalies.

  • •Built-in Templates: Leverage Microsoft's security research and threat intelligence.
  • •Custom Rules: Create rules from scratch using KQL for specific organizational needs.
  • •Incident Generation: When a rule's condition is met, it generates an 'incident' – an aggregation of related alerts.
Example Rule Scenario

Detect multiple failed login attempts followed by a successful login from a new IP address, indicating a potential brute-force attack.

Key Takeaway

Analytics rules, powered by KQL, are fundamental for transforming raw security data into actionable incidents, enabling proactive threat detection.
