Policy Actions

Understanding Azure Policy Effects

How policies influence resource behavior and compliance.

Audit

Reports non-compliance without blocking resource creation or updates. Ideal for initial assessment.

Deny

Prevents non-compliant resource creation or updates. Strong enforcement, but can cause friction if not planned.

DeployIfNotExists (DIFE)

Deploys a resource or configuration if a condition is not met. Useful for ensuring required components are present.

Modify

Modifies properties of a resource to bring it into compliance (e.g., adding tags, enabling settings).

Key Takeaway

Choosing the right policy effect is crucial for balancing security enforcement with operational flexibility. Start with 'Audit' to understand impact.
