Response Phase

Eradication & Recovery: Eliminating the Threat

Removing Root Causes and Restoring Operations

Eradication: Removing the Root Cause

  • Delete Malware: Remove malicious software from all affected systems.
  • Patch Vulnerabilities: Address the security flaws that allowed the breach.
  • Reset Compromised Accounts: Change passwords, revoke tokens, and enforce MFA.
  • Ensures the attacker's access is completely severed and the initial entry point is closed.
Common Mistake

Failing to thoroughly eradicate the root cause, leading to re-infection or persistent access for attackers.

Recovery: Restoring Trusted Operations

  • Restore from Backups: Revert data and systems to a known good state.
  • Rebuild Servers: Deploy new, clean instances for compromised systems.
  • Reconfigure Security: Apply hardened security baselines and settings.
  • Aims to bring affected systems back online securely and efficiently.

Example: Post-Phishing Recovery

After a user's credentials are stolen via phishing, eradication involves resetting their password and enforcing MFA. Recovery might involve reviewing their recent activities for unauthorized changes and restoring any affected files from backup.

Key Takeaway

Eradication and recovery are about not just fixing the immediate problem, but ensuring the environment is clean, secure, and resilient for future operations.
