Example Scenario

Highly Confidential Document

A document classified as "Highly Confidential" could automatically be:

  • Encrypted: Only authorized users can open it.
  • Watermarked: "Highly Confidential" applied as a visual marking.
  • Access Restricted: Limited to a specific Azure AD group, preventing unauthorized sharing.
Key Takeaway

AIP's protection actions ensure sensitive data remains secure and compliant, even when it moves beyond your immediate control.
