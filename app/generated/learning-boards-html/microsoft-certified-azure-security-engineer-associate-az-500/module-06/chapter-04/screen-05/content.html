How AIP Classifies Data

Azure Information Protection (AIP) helps organizations classify and optionally protect documents and emails by applying labels. These labels can be applied manually by users or automatically based on predefined rules.

  • Manual Labeling: Users apply labels based on content knowledge.
  • Automatic Labeling: Rules detect sensitive info (e.g., credit card numbers) and apply labels.
  • Consistent Protection: Ensures policies are applied uniformly across data.
  • Visibility: Provides insights into sensitive data usage.
Key Benefit

Extends data protection beyond organizational boundaries, ensuring sensitive information remains secure even when shared externally.

Key Takeaway

AIP enables organizations to classify and protect sensitive data consistently through intelligent labeling, reducing the risk of data exposure.
