Retention for Databases and Logs

Configuring policies for Azure SQL, Cosmos DB, and Log Analytics.

Data Retention Mechanisms
Azure SQL Database / Cosmos DB
  • Point-in-time restore
  • Automated backups
  • Built-in retention settings
Log Analytics Workspaces
  • Configurable retention period for ingested logs
  • Crucial for security and compliance audits
Example

For security audit logs, you might set a 7-year retention period in Log Analytics to meet regulatory requirements like PCI DSS or HIPAA.

Key Takeaway

Align your backup and retention strategies for Azure databases and logs with compliance needs, actively configuring settings rather than relying on defaults.
