Preparation and Identification

Building resilience and detecting threats early.

01

Preparation

Establishing policies, procedures, tools, and training necessary to prevent and respond to incidents. This includes security awareness, vulnerability management, and incident response plans.

  • •Develop incident response plan
  • •Implement preventative controls
  • •Conduct security training
Pro-Tip

Regularly review and update your incident response plan to adapt to new threats and technologies.

02

Identification

Detecting security events, analyzing them, and determining if they are actual security incidents. This involves monitoring logs, alerts, and user reports.

  • •Monitor security logs and alerts
  • •Analyze suspicious activity
  • •Confirm incident scope and severity
Example Scenario

Azure Sentinel detects multiple failed logins from an unusual country, triggering an investigation to confirm a potential brute-force attack.

Key Takeaway

Proactive preparation and vigilant identification are the cornerstones of an effective incident response strategy.
