Sentinel Capabilities

Collecting Data and Detecting Incidents

Aggregating security data for holistic threat detection.

Diverse Data Sources

Sentinel collects security data from a wide range of sources, centralizing it for analysis.

  • •Azure AD, Azure Activity Logs
  • •Microsoft Defender for Cloud
  • •Microsoft 365, Defender for Endpoint
  • •Third-party firewalls and cloud providers
Data Ingestion

All collected data is ingested into a Log Analytics Workspace for centralized storage and analysis.

Intelligent Incident Generation

Sentinel uses machine learning, built-in rules, and custom queries to detect threats and generate 'incidents'.

  • •Correlates related alerts and events
  • •Provides a holistic view of potential threats
  • •Reduces alert fatigue for analysts
Example Incident

Sentinel correlates a suspicious login from an unusual location with a data exfiltration attempt, grouping them into one incident.

Key Takeaway

Microsoft Sentinel centralizes security data from across your environment and intelligently correlates alerts into actionable incidents, streamlining threat detection.
