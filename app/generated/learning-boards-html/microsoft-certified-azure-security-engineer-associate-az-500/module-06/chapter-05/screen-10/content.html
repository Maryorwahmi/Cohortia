Investigating Incidents with Microsoft Sentinel

A rich interface for security analysts to drill down into threats.

Incident Details & Entities

Analysts can investigate incidents by drilling down into associated entities (users, hosts, IP addresses) to understand the scope.

  • •View incident overview and alerts
  • •Examine involved entities
  • •Understand the attack surface
Investigation Graph

The investigation graph visually shows relationships between entities, helping to uncover complex attack patterns.

Timelines and Workbooks

Sentinel provides event timelines for chronological analysis and built-in workbooks for visual data exploration.

  • •Reconstruct attack chains
  • •Identify event sequences
  • •Leverage visual analytics for insights
Example Scenario

An analyst uses a workbook to visualize login attempts over time, identifying a spike from a new region correlated with a data access alert.

Key Takeaway

Microsoft Sentinel's rich interface empowers security analysts with detailed incident views, entity correlation, and visual analytics for efficient investigation.
