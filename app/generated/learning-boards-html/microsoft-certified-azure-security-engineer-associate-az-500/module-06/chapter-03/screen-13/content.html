Workflow: Isolate VM on Alert

This workflow demonstrates how a Logic App can automatically isolate a virtual machine when a high-severity security alert is triggered in Microsoft Defender for Cloud.

Trigger: Defender for Cloud Alert

A high-severity alert for a VM initiates the Logic App.

Action: Parse Alert Details

Extracts the compromised VM's name and resource group from the alert.

Action: Update NSG Rules

Modifies the VM's Network Security Group to block all inbound and outbound traffic.

NSG Rule Example (JSON)

{
  "properties": {
    "securityRules": [
      {
        "name": "DenyAllInbound",
        "properties": {
          "priority": 100,
          "direction": "Inbound",
          "access": "Deny",
          "protocol": "*",
          "sourcePortRange": "*",
          "destinationPortRange": "*",
          "sourceAddressPrefix": "*",
          "destinationAddressPrefix": "*"
        }
      },
      {
        "name": "DenyAllOutbound",
        "properties": {
          "priority": 101,
          "direction": "Outbound",
          "access": "Deny",
          "protocol": "*",
          "sourcePortRange": "*",
          "destinationPortRange": "*",
          "sourceAddressPrefix": "*",
          "destinationAddressPrefix": "*"
        }
      }
    ]
  }
}
Key Takeaway

This Logic App workflow demonstrates a powerful, automated incident response to isolate compromised VMs, minimizing potential damage.
