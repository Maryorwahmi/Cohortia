Querying Logs with Kusto Query Language (KQL)

Unlocking insights from your security data in Log Analytics.

Kusto Query Language (KQL) is a powerful, read-only language used to query, analyze, and visualize data in Azure Log Analytics Workspaces.

  • •Enables deep investigation of security events.
  • •Designed for large-scale telemetry data.
  • •Supports complex filtering, aggregation, and joins.
  • •Crucial for identifying deviations from security baselines.
Common Misconception

KQL is not overly complex; its intuitive syntax becomes accessible with practice, and many resources are available.

Key Takeaway

KQL is essential for transforming raw log data into actionable security insights within Log Analytics.

KQL Code Example
// Basic KQL Query to find security events
SecurityEvent
| where TimeGenerated > ago(1h)
| where EventID == 4625 // Failed login attempts
| project TimeGenerated, Computer, Account, IpAddress
| summarize count() by Computer, Account, IpAddress
| order by count_ desc
This query identifies and counts failed login attempts to computers in the last hour.
