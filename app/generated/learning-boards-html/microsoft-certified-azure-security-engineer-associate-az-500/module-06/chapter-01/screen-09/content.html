Blueprint Components

Building Blocks of an Azure Blueprint

Combining policies, RBAC, and ARM templates for full environments.

Azure Policy Assignments

Ensures specific governance rules are applied to deployed resources.

Role-Based Access Control (RBAC)

Defines who has what permissions within the deployed environment.

ARM Templates

Declarative JSON files defining infrastructure and configuration of Azure resources.

Resource Groups

Logical containers for all deployed resources, ensuring organized deployments.

Blueprint Locking

Blueprints offer a locking mechanism that prevents changes to resources deployed by the blueprint, further enhancing governance and preventing configuration drift. This ensures the environment remains in its desired compliant state.

Key Takeaway

Blueprints combine various artifacts like policies, RBAC, and ARM templates to define and deploy complete environments, with optional locking to prevent configuration drift.
