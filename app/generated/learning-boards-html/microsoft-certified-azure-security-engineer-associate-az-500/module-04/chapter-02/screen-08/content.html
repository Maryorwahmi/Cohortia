Data at Rest Encryption

Transparent Data Encryption (TDE)

Protecting Data Files Without Application Changes

# Verify TDE status for a database
az sql db tde show \
  --resource-group $RESOURCE_GROUP \
  --server $SQL_SERVER_NAME \
  --name $SQL_DATABASE_NAME \
  --query status
# Conceptual: Enable TDE if not already enabled
# az sql db tde set --resource-group $RESOURCE_GROUP --server $SQL_SERVER_NAME --name $SQL_DATABASE_NAME --status Enabled
Expected Output

"Enabled"

TDE Fundamentals
  • Encrypts data, log, and backup files at rest.
  • Real-time I/O encryption/decryption, transparent to applications.
  • Enabled by default for new Azure SQL Databases (service-managed key).
  • Can be configured with Customer-Managed Keys (CMK) in Azure Key Vault for more control.
Why it Matters

TDE protects against unauthorized access to physical data files, ensuring that if someone gains access to the storage, the data remains unreadable without the encryption key.

Key Takeaway

TDE provides essential data-at-rest encryption for Azure SQL Databases, offering a transparent and effective way to protect your stored information without application changes.
