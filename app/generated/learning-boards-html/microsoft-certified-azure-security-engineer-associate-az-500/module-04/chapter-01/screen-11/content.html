Choosing the Right Shared Access Signature

User Delegation, Service, and Account SAS

User Delegation SAS (Recommended)

Secured with Azure AD credentials, offering granular control and better auditability. Ideal for most scenarios.

Service SAS & Account SAS

Secured with the storage account key. Service SAS grants access to a specific service; Account SAS grants access to multiple services.

Security Pitfall

Service and Account SAS rely on the highly sensitive storage account key. Overly permissive or long-lived tokens are a significant risk.

Key Takeaway

Prioritize User Delegation SAS for enhanced security and auditability. Always apply the principle of least privilege and shortest duration for all SAS types.
