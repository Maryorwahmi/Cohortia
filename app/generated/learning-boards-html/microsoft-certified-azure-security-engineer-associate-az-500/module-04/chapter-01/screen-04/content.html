Understanding Data Encryption at Rest

Protecting Data on Disk with SSE and CMK

Storage Service Encryption (SSE)

Azure Storage encrypts all data at rest by default using Microsoft-managed keys. This provides a baseline security level with no configuration required.

Customer-Managed Keys (CMK)

For enhanced control, you can use your own encryption keys stored in Azure Key Vault. This allows you to manage the key lifecycle, including rotation and revocation.

Key Takeaway

Encryption at rest is fundamental. Choose between Microsoft-managed (default) or customer-managed keys based on your control and compliance needs.
