Soft Delete and Purge Protection

Safeguarding against accidental or malicious data deletion.

Soft Delete

Retains deleted Key Vaults and objects for a configurable period (e.g., 90 days), allowing for recovery.

Purge Protection

Prevents permanent deletion of soft-deleted items during the retention period, even by privileged users.

Combined Benefit

Provides a robust safety net against both accidental and malicious permanent data loss, crucial for compliance.

Enabling Soft Delete and Purge Protection
During Key Vault Creation (Azure CLI)
az keyvault create \
  --name "myProtectedVault" \
  --resource-group "myResourceGroup" \
  --location "eastus" \
  --sku Standard \
  --enable-soft-delete true \
  --enable-purge-protection true

Recommended to enable at creation time for maximum protection.

After Creation (Azure CLI)
az keyvault update \
  --name "myProtectedVault" \
  --resource-group "myResourceGroup" \
  --enable-soft-delete true \
  --enable-purge-protection true

Can also be enabled or updated on an existing Key Vault.

Key Takeaway

Soft delete and purge protection are essential for preventing permanent data loss and protecting against insider threats in Key Vault.
