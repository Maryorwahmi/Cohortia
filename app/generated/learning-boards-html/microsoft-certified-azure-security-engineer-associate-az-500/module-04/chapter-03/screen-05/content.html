Secrets: Protecting Sensitive Strings

Storing passwords, connection strings, and API keys securely.

Definition

Small data blobs, typically strings, that need protection from unauthorized disclosure.

Common Examples
  • Database connection strings
  • API keys for external services
  • Application passwords
Security Benefit

Prevents hardcoding, encrypts data at rest and in transit, and enables easy rotation without application redeployment.

Storing and Retrieving a Secret
Store a Secret (Azure CLI)
az keyvault secret set \
  --vault-name "myKeyVault" \
  --name "DbConnectionString" \
  --value "Server=...;Password=MySecurePassword;"

The secret is stored encrypted in Key Vault.

Retrieve in Application (Conceptual C#)
// using Azure.Security.KeyVault.Secrets;
// using Azure.Identity;

var client = new SecretClient(new Uri(keyVaultUri), new DefaultAzureCredential());
KeyVaultSecret secret = await client.GetSecretAsync("DbConnectionString");
string connectionString = secret.Value;

Application retrieves the secret at runtime using its identity.

Key Takeaway

Key Vault secrets are for any sensitive string data, offering secure storage and retrieval to prevent exposure in code.
