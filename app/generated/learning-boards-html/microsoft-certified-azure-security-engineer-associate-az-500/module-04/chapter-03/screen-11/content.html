Creating Azure Key Vault and Storing Secrets

Setting up your secure vault with essential protection features.

Step 1: Create Resource Group

Organize your Azure resources by creating a dedicated resource group for the Key Vault.

Step 2: Create Key Vault with Protections

Provision the Key Vault, ensuring soft delete and purge protection are enabled for data recovery and security.

Step 3: Store a Secret

Add a sensitive string, like a database connection string, to your newly created Key Vault.

Azure CLI Commands
Create Resource Group
RESOURCE_GROUP="KeyVaultSecurityRG"
LOCATION="eastus"

az group create --name $RESOURCE_GROUP --location $LOCATION
Create Key Vault
KEY_VAULT_NAME="kvsec$(openssl rand -hex 4)"

az keyvault create \
  --name $KEY_VAULT_NAME \
  --resource-group $RESOURCE_GROUP \
  --location $LOCATION \
  --sku Standard \
  --enable-soft-delete true \
  --enable-purge-protection true
Store a Secret
DB_CONNECTION_STRING="Server=tcp:mydbserver.database.windows.net,1433;..."
az keyvault secret set \
  --vault-name $KEY_VAULT_NAME \
  --name "DbConnectionString" \
  --value "$DB_CONNECTION_STRING"
Key Takeaway

Always enable soft delete and purge protection when creating a Key Vault to ensure data recoverability and prevent permanent loss.
