Managed Identities for Secure Access

Eliminating credential management for Azure services.

What they are

Automatically managed Azure AD identities for Azure services, simplifying secure access to other Azure resources.

How they work
  • Azure AD manages identity lifecycle.
  • Application requests token from Azure AD.
  • Token used to access Key Vault (after permissions granted).
Key Benefits

Eliminates hardcoded credentials, simplifies authentication, and enhances overall security posture.

Managed Identity Flow
1. Enable Managed Identity
az webapp create \
  --name "myWebApp" \
  --resource-group "myRG" \
  --assign-identity # System-assigned MI

Azure creates an identity for your service in Azure AD.

2. Grant MI Access to Key Vault
# Grant 'Get' secret permission via RBAC
az role assignment create \
  --role "Key Vault Secrets User" \
  --assignee $WEB_APP_PRINCIPAL_ID \
  --scope $KEY_VAULT_ID

Assign appropriate permissions to the Managed Identity.

3. Application Accesses Key Vault
// Application uses DefaultAzureCredential
// to authenticate with its Managed Identity.
var secretClient = new SecretClient(new Uri(keyVaultUri), new DefaultAzureCredential());
string secretValue = (await secretClient.GetSecretAsync("mySecret")).Value;

Application retrieves secrets without managing its own credentials.

Key Takeaway

Managed Identities are the most secure way for Azure services to access Key Vault, eliminating credential management overhead.
