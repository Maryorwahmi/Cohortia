Keys: Cryptographic Protection

Managing encryption, decryption, signing, and verification keys.

Definition

Cryptographic keys used for operations like encryption, decryption, signing, and verification.

Protection Levels
  • Software-protected keys
  • HSM-protected keys (highest security)
Key Benefit

Private key material never leaves Key Vault, even during cryptographic operations, enhancing security significantly.

Using a Key for Digital Signing
Application Request
// Application sends data hash to Key Vault
// for signing with a specific key.
var signResult = await keyClient.SignAsync(
    SignatureAlgorithm.RS256,
    HashAlgorithm.SHA256,
    dataToSignHash);

Application requests Key Vault to perform a signing operation.

Key Vault Response
// Key Vault performs signing internally
// and returns the digital signature.
byte[] signature = signResult.Signature;

Key Vault returns the signature; private key remains secure.

Key Takeaway

Keys in Key Vault enable secure cryptographic operations without exposing private key material to applications.
