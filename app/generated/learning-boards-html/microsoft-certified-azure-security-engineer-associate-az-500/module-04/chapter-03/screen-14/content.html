Network Access and Monitoring

Restricting access and auditing Key Vault operations.

Private Endpoints

Creates a private IP address for Key Vault within your VNet, enabling private and secure access.

VNet Service Endpoints

Extends your VNet's private address space to Azure services over a direct connection, enhancing security.

Azure Monitor Integration

Collects audit logs and diagnostic information for security monitoring, compliance, and incident response.

Configuring Network Access
Enable Private Endpoint (Azure CLI)
az network private-endpoint create \
  --name "myKeyVaultPrivateEndpoint" \
  --resource-group "myResourceGroup" \
  --vnet-name "myVNet" \
  --subnet "mySubnet" \
  --private-connection-resource-id $(az keyvault show -n "myKeyVault" -g "myResourceGroup" --query id -o tsv) \
  --group-ids vault \
  --connection-name "myKeyVaultConnection"

Creates a private endpoint for Key Vault within your virtual network.

Configure Diagnostic Settings (Azure CLI)
az monitor diagnostic-settings create \
  --name "send-to-log-analytics" \
  --resource $(az keyvault show -n "myKeyVault" -g "myResourceGroup" --query id -o tsv) \
  --logs '[{"categoryGroup": "audit", "enabled": true}]' \
  --workspace $(az monitor log-analytics workspace show -n "myLogAnalyticsWorkspace" -g "myResourceGroup" --query id -o tsv)

Sends Key Vault audit logs to a Log Analytics workspace for monitoring.

Key Takeaway

Implement private endpoints for secure network access and integrate with Azure Monitor for comprehensive auditing and security insights.
