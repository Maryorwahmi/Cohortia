Core Concept

Simplify Authentication with Easy Auth

Offload identity management to Azure for various providers, reducing development effort.

1. Request Interception

Easy Auth intercepts unauthenticated requests to your App Service application.

2. Redirect to Identity Provider

User is redirected to Azure AD, Google, Facebook, or Microsoft Account for login.

3. Token Returned to App

Upon successful authentication, a token is returned, and the user gains access to the application.

Benefits
  • No authentication code needed.
  • Supports multiple identity providers.
  • Integrates with Azure AD for enterprise.
  • Reduces developer overhead.
Example Scenario

A corporate web application requires users to log in with their existing Azure AD credentials. Easy Auth is configured to use Azure AD, automatically handling the login flow and user session management.

Key Takeaway

Easy Auth simplifies application security by offloading authentication to Azure, allowing developers to focus on core application logic while leveraging robust identity providers.
