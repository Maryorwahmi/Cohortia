Safe Deployments

Securing Deployment Slots and Application Settings

Enable zero-downtime deployments while protecting sensitive configurations.

What are Deployment Slots?
  • Separate staging environments for your app.
  • Enable zero-downtime deployments.
  • Facilitate easy rollbacks.
  • Share the same App Service Plan.
The Critical Security Point

Sensitive application settings (e.g., connection strings, API keys) must NOT swap between slots.

How to Implement: Slot Settings
  • Mark sensitive app settings as 'slot settings'.
  • These settings 'stick' to their slot and do not swap.
  • Ensures production uses production credentials, staging uses staging.

Preventing Credential Leakage

Slot settings ensure sensitive configurations remain tied to their respective environments.

Key Takeaway

Deployment slots enable safe, zero-downtime deployments, but sensitive application settings must be marked as 'slot settings' to prevent accidental exposure or misconfiguration during swaps.
