Module 02 › Chapter 2.1 › Focused SELECT
Step-by-step
  1. Inspect the table structure or run SELECT star to discover columns.
  2. Choose only fields needed for your task.
  3. Write an explicit SELECT with commas between column names.
  4. Verify the result set and adjust if any fields are missing or extra.
Concrete example
SELECT EmployeeID, FirstName, LastName, Salary
FROM Employees;

This query returns only the fields you need for a payroll review, reducing transfer and exposure of unrelated fields like Email or HireDate.

Code walkthrough: common mistakes
-- Missing comma causes syntax error
SELECT FirstName LastName FROM Employees;

-- Misspelling a column causes "column does not exist"
SELECT FirsName FROM Employees;

Notice the two quick errors: missing comma between columns, and a misspelled column name. Check the schema to fix both issues.

Check your understanding

When order matters for downstream code, explicitly list columns in the desired order rather than relying on the table's current column order.
