Module 02 › Chapter 2.1 › Performance & Privacy
Performance

Selecting fewer columns reduces network transfer and memory load, which matters for large tables and repeated queries.

Privacy

Requesting only required fields limits exposure of sensitive data like emails, salaries, or identifiers not needed for analysis.

Governance tip

When sensitive fields are necessary, coordinate with governance teams to mask or filter data appropriately before returning it to analysis environments.

Scenario

For a public dashboard, avoid returning PII. Instead select aggregate or non-identifying columns to meet both analytic and privacy requirements.
