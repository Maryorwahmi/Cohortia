Module 02 › Chapter 2.1 › SELECT * vs Columns
SELECT *
SELECT *
FROM Products;
  • Quickly inspects every column for exploration.
  • May transfer unnecessary or sensitive data for large tables.
  • Can break downstream code if schema changes add columns.
Explicit columns
SELECT ProductName, UnitPrice, StockQuantity
FROM Products;
  • Retrieves only required fields for analysis or reporting.
  • Reduces network and memory usage when loading results.
  • Makes intent clear for collaborators and stable for scripts.
Example scenario

For a pricing model, you only need product name and price. Requesting supplier identifiers and long descriptions can slow down training and leak data you don’t need.

Common mistake

Leaving SELECT star in production code is a frequent oversight that leads to extra cost and possible data exposure when table schemas expand.
