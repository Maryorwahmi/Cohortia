Module 02 › Chapter 2.1 › Syntax Errors
Common mistakes
  • Missing FROM clause: the query lacks a table source.
  • Missing comma between column names causes parser errors.
  • Misspelled column or table names lead to "does not exist" errors.
  • Forgetting semicolon in scripts causes statement batching issues.
Examples and fixes
-- Missing FROM
SELECT FirstName, LastName;

-- Fix:
SELECT FirstName, LastName
FROM Customers;

-- Misspelled column
SELECT FirsName FROM Customers; -- fix: FirstName
Pro tip

Use your client’s schema browser to copy column names to avoid typos and confirm casing when working on case-sensitive systems.
