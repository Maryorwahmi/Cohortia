Module 02 › Chapter 2.1 › Workflow
Four-step process
1. Inspect
Use schema browser to view tables and column names.
2. Explore
Run a short SELECT star or LIMIT to sample rows.
3. Select
Write an explicit SELECT listing only needed columns.
4. Validate
Confirm types, counts, and absence of sensitive fields.
Example: payroll CSV
-- Final production query for payroll export
SELECT EmployeeID, FirstName, LastName, Salary
FROM Employees;
