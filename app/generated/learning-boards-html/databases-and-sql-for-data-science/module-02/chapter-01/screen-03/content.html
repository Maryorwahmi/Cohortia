Why these skills matter

Small choices in SELECT shape performance, collaboration, and privacy.

Performance

Requesting fewer columns limits network transfer and memory use when loading data into your analysis environment.

Clarity

Explicit column lists document intent so teammates can quickly understand which features drive your results.

Privacy

Avoiding SELECT star reduces the risk of exposing sensitive fields that are irrelevant to the task at hand.

Practical checklist
  • Confirm table and column names in the schema browser before querying.
  • Use SELECT star for quick exploration only, then switch to explicit columns.
  • Include a semicolon when running multiple statements in a script.
