Definition

What SELECT and FROM mean

SELECT names the data you want. FROM tells the database where to find it. Both together form the simplest useful query.

Concrete example
SELECT *
FROM Customers;

This returns every column and every row from Customers. Good for exploration, not always for production.

Common misconception

Some learners try to run SELECT without FROM. That fails because the database needs a source table. Always include FROM unless using expressions supported by your SQL dialect.

Check your understanding

If a query returns an error saying a table doesn't exist, check the FROM clause for typos or incorrect casing before changing the SELECT list.
