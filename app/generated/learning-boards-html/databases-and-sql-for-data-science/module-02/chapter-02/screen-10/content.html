Module 2 › Chapter 2.2 › NULL and IS NULL
NULL is not a value
Treat NULL as unknown or missing; use IS NULL to test for it.
Examples
-- Find orders with missing customer
SELECT OrderID, CustomerID, OrderDate
FROM Orders
WHERE CustomerID IS NULL;

-- Find orders with a customer
SELECT OrderID, CustomerID
FROM Orders
WHERE CustomerID IS NOT NULL;
Misconception
WHERE column = NULL returns no rows because comparisons with NULL are unknown, not true.
Careful

Comparisons like > or < yield unknown for NULLs and will exclude those rows unless you explicitly include them.

Practical handling
When cleaning data, decide whether NULL means missing, unknown, or inapplicable, and handle it consistently for analysis.
Try
-- Compare equality attempt (returns no rows)
SELECT * FROM Orders WHERE CustomerID = NULL;

-- Correct approach
SELECT * FROM Orders WHERE CustomerID IS NULL;
