Relational operators
Use them to compare numbers and dates; be explicit about inclusivity.
Examples
-- Salary threshold
SELECT FirstName, LastName, Salary
FROM Employees
WHERE Salary > 70000;

-- Hire date check
SELECT FirstName, LastName, HireDate
FROM Employees
WHERE HireDate > '2022-01-01';
Notes
  • Use YYYY-MM-DD for dates to avoid ambiguity.
  • Ensure column types are numeric or date; otherwise comparisons may misbehave.
  • > and < are exclusive; >= and <= are inclusive.
Key Takeaway

Choose operators that match the boundary behavior you need and confirm column data types before comparing.
