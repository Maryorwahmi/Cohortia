Membership testing with IN
A compact way to express multiple OR conditions for exact matches.
Example
SELECT FirstName, LastName, Department
FROM Employees
WHERE Department IN ('Sales', 'Marketing', 'IT');
Equivalence
This is equivalent to Department = 'Sales' OR Department = 'Marketing' OR Department = 'IT'. Use IN for readability.
Key Takeaway

IN improves readability for multiple exact matches; normalize text to handle case differences before matching.

Practical tips
Include a small list manually for clarity. For larger lists, consider a join or a subquery: WHERE Category IN (SELECT Category FROM Categories WHERE Active = 1).
Watch for NULL
NULL values do not match IN unless explicitly included; use IS NULL to find missing values.
