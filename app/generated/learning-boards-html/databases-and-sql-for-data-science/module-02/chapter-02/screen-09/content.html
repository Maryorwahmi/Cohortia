Pattern matching with LIKE
Use % for zero or more characters and _ for a single character.
Examples
-- Starts with Laptop
SELECT ProductName FROM Products WHERE ProductName LIKE 'Laptop%';

-- Ends with @gmail.com
SELECT Email FROM Customers WHERE Email LIKE '%@gmail.com';

-- Single char then 'ohn'
SELECT FirstName FROM Employees WHERE FirstName LIKE '_ohn%';
Case sensitivity
If LIKE is case-sensitive, normalize with LOWER(column) LIKE 'laptop%'. Some databases provide ILIKE for case-insensitive matching.
Performance note

Leading wildcards like '%term%' may prevent index usage and be slower on large tables; prefer anchored patterns when possible.

Practice and verification
Write a pattern, run the query, and inspect sample rows to confirm the pattern matches the intended set of strings.
Try
SELECT ProductName FROM Products WHERE ProductName LIKE '%phone%';
