AND, OR, NOT — building blocks
Combine conditions and control evaluation order with parentheses.
Step-by-step examples
1) All true: WHERE Department = 'Sales' AND Salary > 70000 — both must be true.
2) Any true: WHERE Department = 'Sales' OR Department = 'Marketing' — either condition passes.
3) Negation: WHERE NOT OrderStatus = 'Cancelled' — excludes cancelled orders.
4) Parentheses: WHERE (Department = 'Sales' AND Salary > 70000) OR Department = 'Marketing' — grouping enforces intended logic.
Common mistake

Omitting parentheses when mixing AND and OR can return unexpected rows because AND typically evaluates before OR.

Try this mentally then run it
-- Sales who earn > 70000 OR anyone in Marketing
SELECT FirstName, LastName, Department, Salary
FROM Employees
WHERE (Department = 'Sales' AND Salary > 70000) OR Department = 'Marketing';
Before running, predict whether an employee in Sales earning 65000 appears. Then run and verify how parentheses affect inclusion.
Key Takeaway

Use parentheses to express intent clearly and test results with sample rows to avoid logic errors.
