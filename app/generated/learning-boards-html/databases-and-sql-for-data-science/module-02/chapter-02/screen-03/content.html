Practice checks

Each objective is paired with a concrete verification step to ensure filters behave as expected.

Compare results and counts
Run SELECT with COUNT(*) after a filter to confirm the number of returned rows matches expectations.
Equivalent queries
Write an IN list and an OR chain to confirm they return the same rows, and use BETWEEN vs explicit inequalities to check inclusivity.
Pattern validation
Try patterns like 'Laptop%' and '%phone%' and inspect sample results to ensure wildcards match your intent.
NULL checks
Compare IS NULL results with equality attempts to see why equals does not work for NULL and adjust queries accordingly.
Validation examples
Short snippets show how to check filters quickly.
-- Count Electronics
SELECT COUNT(*) FROM Products WHERE Category = 'Electronics';

-- Compare IN vs OR
SELECT * FROM Products WHERE Category IN ('Electronics','Appliances');
-- vs
SELECT * FROM Products WHERE Category = 'Electronics' OR Category = 'Appliances';
These checks are quick and reveal logic errors early, before you build downstream analyses on incorrect subsets.
