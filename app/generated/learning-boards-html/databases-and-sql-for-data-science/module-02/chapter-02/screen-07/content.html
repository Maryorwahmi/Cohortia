BETWEEN in practice
Use BETWEEN for clear inclusive range checks on numbers and dates.
Example
SELECT ProductName, UnitPrice
FROM Products
WHERE UnitPrice BETWEEN 20.00 AND 50.00; -- includes 20.00 and 50.00
Equivalence check
Confirm equivalence to explicit inequalities: UnitPrice >= 20.00 AND UnitPrice <= 50.00.
Key Takeaway

BETWEEN is inclusive. Test boundary values explicitly to avoid off-by-one or boundary surprises.

Date ranges and edge cases
When using BETWEEN with dates, include time if your column stores timestamps. Otherwise, using YYYY-MM-DD matches dates at midnight in many systems.
Try
-- Orders in February
SELECT OrderID, OrderDate
FROM Orders
WHERE OrderDate BETWEEN '2023-02-01' AND '2023-02-28';
Verify by checking the earliest and latest OrderDate rows returned to ensure boundaries are included as expected.
