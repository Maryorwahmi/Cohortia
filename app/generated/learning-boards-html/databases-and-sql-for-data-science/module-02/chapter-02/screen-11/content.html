Tasks — write and verify queries
Follow these starter queries and validate results by checking counts and example rows.
Task 1: Filter by Status
-- Task 1: Filter by Status
-- SELECT * FROM Orders WHERE OrderStatus = 'Pending';
Run and inspect a few rows to confirm only pending orders are returned.
Task 2: Amount and Date
-- Task 2: Amount and Date
-- SELECT * FROM Orders WHERE OrderDate > '2023-01-01' AND TotalAmount > 100.00;
Verify both conditions exclude rows that meet only one requirement.
Task 3: Multiple statuses or high amount
-- Task 3: Multiple statuses or high amount
-- SELECT * FROM Orders WHERE (OrderStatus IN ('Cancelled', 'Shipped')) OR TotalAmount > 500.00;
Use parentheses so the status list is evaluated together. Compare results to an equivalent OR chain.
Task 4: Missing customer IDs
-- Task 4: Find missing customer info
-- SELECT * FROM Orders WHERE CustomerID IS NULL;
IS NULL is required; equality comparisons with NULL will not work. Inspect returned rows to plan cleaning steps.
Key Takeaway

Work through these tasks step-by-step, checking counts and samples to build confidence in your WHERE clauses.

Hints and checks
After each query, run a COUNT(*) to confirm how many rows matched and sample a few rows to ensure they look correct.
Alternative forms
Use IN for task 3 to improve readability. Use BETWEEN for numeric ranges when inclusive boundaries are desired.
