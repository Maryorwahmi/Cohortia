Module 2 › Chapter 2.2 › WHERE clause basics
What WHERE does
Filter rows based on conditions; it does not control which columns appear.
Core idea
  • WHERE evaluates each row and includes it only if the condition is true.
  • Placed after FROM and before GROUP BY / ORDER BY.
  • Works with comparisons, logical operators, and special filters we’ll cover next.
Example
SELECT ProductID, ProductName
FROM Products
WHERE Category = 'Electronics';
Misconception
WHERE filters rows only; use SELECT to pick columns. Also confirm types before comparing.
Key Takeaway

Start filters simple, inspect results, then add complexity. WHERE decides which rows survive to analysis.

Visual: Row gate analogy
Imagine each row lined up and passing through a gate labeled with your condition. Only rows that pass the test continue. This clarifies why wrong operators or NULLs can accidentally block rows you need.
Quick practice
-- Run and inspect results
SELECT * FROM Products WHERE Category = 'Electronics';
-- Check count and a few rows to confirm
