Ordering

ORDER BY defines how rows are sequenced. Use ASC for lowest-to-highest and DESC for highest-to-lowest. Multiple columns define a hierarchy.

Limiting

LIMIT or dialect equivalents return a fixed number of rows. Combined with ORDER BY it yields top or bottom N results.

Example
Top 5 by salary
Order by salary descending, then LIMIT 5.
Pitfall
OFFSET cost
Deep OFFSET can be inefficient on large tables.
Try this
Page 2 of 5
Combine LIMIT 5 OFFSET 5 to get rows 6–10.
