Module 3 › Chapter 2.3 › ASC vs DESC
Definition

ASC and DESC

Use ASC for lowest-to-highest and DESC for highest-to-lowest. ASC is the default if unspecified.

Example: Highest-paid employees
SELECT FirstName, LastName, Salary
FROM Employees
WHERE Department = 'IT'
ORDER BY Salary DESC;
This returns only IT employees, ordered from highest salary down.
Mixing directions

You can specify ASC or DESC per column. For example, order departments alphabetically but salaries descending within each department to show top earners first in each group.

SELECT FirstName, LastName, Department, Salary
FROM Employees
ORDER BY Department ASC, Salary DESC;
Takeaway
Direction controls whether 'top' means largest or smallest.
Misconception
Direction does not resolve ties; add columns to fully order rows.
