How precedence works

Left-to-right evaluation

ORDER BY Department ASC, LastName ASC first groups by Department, then sorts last names within each group. Swap the columns and you change grouping and order.

SELECT FirstName, LastName, Department, Salary
FROM Employees
ORDER BY Department ASC, LastName ASC;
Include a unique column like EmployeeID as the last ORDER BY expression for stable sorting across repeated queries and during pagination.
Practical notes
  • Mix ASC and DESC to express different priorities per column.
  • Order of columns changes grouping and final sequence.
  • Use a stable tie-breaker to avoid unpredictable pagination results.
Analogy
Think of sorting keys as nested folders: first sort by folder, then by file name inside each folder.
