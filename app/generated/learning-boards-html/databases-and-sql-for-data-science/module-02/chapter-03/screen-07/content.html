Module 3 › Chapter 2.3 › LIMIT: top N
Pattern

ORDER BY + LIMIT

Sort to define what 'top' means, then LIMIT the number of rows returned. Without ORDER BY, LIMIT returns arbitrary rows.

Example: Top 3 expensive order items
SELECT OrderItemID, LineTotal
FROM OrderItems
ORDER BY LineTotal DESC
LIMIT 3;
Use case
Leaderboards, top-N reports, outlier inspection.
Warning
LIMIT without ORDER BY is non-deterministic.
Hands-on tip

When you want the bottom N instead of top N, reverse the sort direction. For deterministic results, especially across pages, include a final unique tie-breaker column.

Analogy
Sort is like sorting exam scores high-to-low, LIMIT is like taking the top five students from that sorted list.
