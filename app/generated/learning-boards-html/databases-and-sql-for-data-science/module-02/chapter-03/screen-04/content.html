Module 3 › Chapter 2.3 › ORDER BY: purpose
Core Concept

ORDER BY sorts the final results

ORDER BY is placed after WHERE. The database filters rows first and then sorts those rows. This ensures you order only the rows you intend to analyze.

Concrete Example
List employees alphabetically by last name.
SELECT FirstName, LastName, Department
FROM Employees
ORDER BY LastName ASC;
Key takeaway
ORDER BY acts on filtered rows.
Common mistake
Placing LIMIT before ORDER BY or expecting ORDER BY to change data.
Explanation & analogy

Think of filtering as selecting pages from a book and ORDER BY as arranging those selected pages on a table. You first choose which pages matter, then you order them for reading.

Step visual
  • Select columns and rows with SELECT and WHERE.
  • ORDER BY applies after filtering to sort that set.
  • LIMIT or OFFSET finally selects a slice for presentation.
Check your understanding
If you want the highest-paid employees in the IT department, do you filter by department before or after ordering? Remember: filter first, then order.
