Common mistakes and safety notes

Clause order

SELECT → FROM → WHERE → ORDER BY → LIMIT/OFFSET. Follow this sequence to avoid syntax errors and incorrect results.

Default direction

Omitting ASC/DESC uses ASC. Be explicit when you need descending order to avoid reversed expectations.

Ambiguous sorting

If a sort key has duplicates, add a secondary column so the ordering is deterministic across runs.

OFFSET performance

Deep OFFSET values may be slow. For large datasets consider keyset pagination or filtering on indexed columns instead.

Pro tip

When paging, include a stable ORDER BY key like primary key to keep rows on the same page when data changes minimally.
