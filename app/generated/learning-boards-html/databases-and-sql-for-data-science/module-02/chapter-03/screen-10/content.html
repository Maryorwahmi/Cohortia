Basic pagination

Calculate the OFFSET as the number of rows to skip. For page two with 5 items per page, OFFSET 5 and LIMIT 5 returns rows 6–10.

SELECT OrderItemID, LineTotal
FROM OrderItems
ORDER BY LineTotal DESC
LIMIT 5 OFFSET 5; -- returns items 6 through 10
Always pair OFFSET with ORDER BY; without a stable order pages will not be consistent between requests.

Performance note

  • OFFSET can be inefficient on very large tables because skipped rows are still processed.
  • For deep pagination consider alternatives such as keyset pagination using a WHERE clause on an indexed column.
  • For typical reports and small to moderate page sizes, LIMIT/OFFSET is simple and effective.
