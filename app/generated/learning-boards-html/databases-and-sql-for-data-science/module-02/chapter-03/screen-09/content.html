Top N example

Order by the metric descending, then limit the rows to get the top items.

-- Top 5 highest-paid employees
SELECT FirstName, LastName, Salary
FROM Employees
ORDER BY Salary DESC
LIMIT 5;
If you need the bottom five, switch to ORDER BY Salary ASC and LIMIT 5. Always test to confirm the returned rows meet your business definition of top or bottom.

Group-level top N (note)

For top N within groups, you will often use window functions or correlated subqueries. That technique ensures the top items are selected per group rather than globally.

Practical tip
Add a stable tie-breaker like EmployeeID to make paging deterministic when equal values occur.
