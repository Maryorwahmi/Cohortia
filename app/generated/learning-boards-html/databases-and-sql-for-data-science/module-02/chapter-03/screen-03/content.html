Objective Mnemonics

Short, repeatable phrases help you choose the right clause and order when writing queries.

Sort
"Sort key then direction"

Pick a column to be the sort key, then specify ASC or DESC to get the intended order; ASC is the default if omitted.

Multi-column
"Primary then tie-breaker"

Place the most important sort column first. Subsequent columns resolve ties within groups defined by earlier columns.

Limit
"Limit the list"

After ordering, apply LIMIT or TOP to return only the top N rows you need for reporting or display.

Pagination
"Skip then take"

Use OFFSET to skip rows and LIMIT to take the next block, e.g., LIMIT 5 OFFSET 5 for page two of five-per-page results.

Repeat these mnemonics while you write queries; they map directly to clause order and help avoid common mistakes like placing LIMIT before ORDER BY.
