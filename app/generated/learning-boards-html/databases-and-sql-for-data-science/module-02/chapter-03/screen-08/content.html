Module 3 › Chapter 2.3 › LIMIT / TOP / FETCH

Syntax mapping

All three accomplish the same task. Here are example forms side-by-side to help you translate between dialects.
LIMIT (MySQL/Postgres/SQLite)
SELECT FirstName, LastName
FROM Employees
ORDER BY Salary DESC
LIMIT 5;
TOP (SQL Server)
SELECT TOP 5 FirstName, LastName
FROM Employees
ORDER BY Salary DESC;
FETCH FIRST (Standard SQL)
SELECT FirstName, LastName
FROM Employees
ORDER BY Salary DESC
FETCH FIRST 5 ROWS ONLY;
Practical guidance
  • Use LIMIT in data science examples for portability across common engines.
  • When porting queries, preserve ORDER BY and translate the limiting clause to the target dialect.
  • Test the translated form to ensure identical results.
Remember: the semantics of selecting top rows do not change across dialects — only the syntax does.
