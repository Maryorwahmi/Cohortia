Module 3 › Chapter 2.3 › Key Concepts
ORDER BY
Sorts the result set after filtering.
ASC / DESC
ASC = default, DESC for highest-first.
LIMIT / TOP / FETCH
Restricts rows returned; syntax varies by dialect.
Multiple-column sort
Left-to-right precedence; later columns break ties.
OFFSET
Skips rows; use with LIMIT for pagination.
Stability
Add tie-breakers for deterministic results and pagination.
Summary takeaway

Sort to define order, then limit or offset to select slices. Be explicit and stable so results are reproducible.
