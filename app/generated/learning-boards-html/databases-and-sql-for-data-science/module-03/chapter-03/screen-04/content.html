Core Concept
What is an aggregate function?
A function that computes a single value from multiple rows, like a sum, count, average, minimum, or maximum.
  • They operate on the result set defined by your query, including WHERE filters.
  • Most aggregates ignore NULL values; COUNT(*) is an exception that counts rows regardless.
  • Use aggregates to produce reports and high-level summaries quickly across large datasets.
Analogy
Think of aggregates as a blender: many ingredients (rows) go in and a single smoothie (summary) comes out.
Example
Sales table summaries
SELECT
  SUM(quantity * unit_price) AS total_revenue,
  AVG(quantity) AS avg_items_per_sale,
  COUNT(*) AS total_sales
FROM Sales;
This query returns three single-value summaries you can use as key metrics in a dashboard.
Key Takeaway

Aggregates convert many rows into single statistics; use them to summarize and compare datasets efficiently.
