Comparison
Multiple aggregates
Combine COUNT, DISTINCT, MIN, MAX, AVG, and SUM to return a single overview row for a dataset.
Benefits:
  • One query for many metrics
  • Efficient computation in a single scan
  • Clear labels make results interpretable
Code Example
SELECT
  COUNT(*) AS total_products,
  COUNT(DISTINCT category) AS unique_categories,
  MIN(price) AS min_price,
  MAX(price) AS max_price,
  AVG(price) AS average_price,
  SUM(price) AS total_inventory_value
FROM Products;
Label aggregates with AS so your result row is self-describing. If price is per unit, SUM(price) is a simple sum, not inventory value unless multiplied by quantity.
Key Takeaway

Grouping multiple aggregates gives a snapshot of distribution, totals, and ranges in one query.
