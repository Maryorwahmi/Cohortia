Practice & Integrity
Apply aggregates correctly and ensure results are meaningful.
01
Use DISTINCT in aggregates
COUNT(DISTINCT column) returns the number of unique non-NULL values. This is essential when duplicates exist.
Mnemonic: unique only
VERIFIED COMPETENCY MILESTONE
02
Handle NULL values
Replace NULLs with COALESCE when you need them treated as zero or another default before SUM or AVG.
Mnemonic: fill missing
VERIFIED COMPETENCY MILESTONE
03
Combine aggregates in one query
Return multiple summary statistics at once to create compact reports and dashboards.
Mnemonic: pack the summary
VERIFIED COMPETENCY MILESTONE
04
Scope with WHERE (and later GROUP BY)
Aggregates operate on the row set defined by WHERE. Use filters to limit what you summarize; GROUP BY creates subgroup summaries.
Mnemonic: narrow then summarize
VERIFIED COMPETENCY MILESTONE
