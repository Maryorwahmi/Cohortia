Process Flow
SUM and AVG
SUM adds values, AVG divides the sum by the count of non-NULL values.
  1. Identify the numeric column to aggregate, e.g., total_amount.
  2. Decide whether NULLs should be treated as missing or zero.
  3. If needed, replace NULLs using COALESCE before aggregation.
  4. Run SUM and AVG and verify counts to ensure correct interpretation.
Tip: compare COUNT(*) and COUNT(column) to measure how many rows are excluded from AVG.
Code Walkthrough
SELECT
  SUM(total_amount) AS total_revenue,
  AVG(total_amount) AS average_order_value,
  COUNT(total_amount) AS non_null_amounts,
  COUNT(*) AS total_rows
FROM Orders;

-- Treat NULL as zero before summing
SELECT SUM(COALESCE(total_amount, 0)) AS revenue_with_nulls_as_zero
FROM Orders;
Notice how SUM and AVG ignore NULLs unless you explicitly replace them. Use COALESCE when missing values should count as zeros in financial sums.
