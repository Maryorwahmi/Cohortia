GROUP BY preview
GROUP BY divides rows into subgroups so aggregates are computed per group, enabling comparisons across categories or time periods.
Example use cases:
  • Total sales per product category
  • Average order value per month
  • Count of unique customers per region
Illustration
Example syntax (preview)
SELECT category,
  SUM(quantity * unit_price) AS revenue,
  AVG(quantity) AS avg_items
FROM Sales
GROUP BY category;
