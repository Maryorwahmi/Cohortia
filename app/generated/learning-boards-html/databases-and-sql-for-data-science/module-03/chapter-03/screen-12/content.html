Common Pitfalls
Validation checks
Use these quick checks before trusting aggregates:
  • Compare COUNT(*) and COUNT(column) to detect NULLs.
  • Use COUNT(DISTINCT) when you want unique entities.
  • Inspect MIN and MAX to find outliers or data errors.
  • Confirm WHERE filters are correct with sample rows.
Pro Tip
Quick SQL sanity checks
-- NULL check
SELECT COUNT(*) AS total_rows, COUNT(total_amount) AS non_null_amounts FROM Orders;

-- Distinct vs total
SELECT COUNT(*) AS total_orders, COUNT(DISTINCT customer_id) AS unique_customers FROM Orders;

-- Inspect extremes
SELECT MIN(total_amount), MAX(total_amount) FROM Orders;
Run these lightweight queries to understand how data shape affects aggregates before building reports.
