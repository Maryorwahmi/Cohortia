Module 3 › Chapter 3.3 › What to Remember
Choose the right COUNT
Rows, non-NULL values, or unique values answer different questions.
Handle NULLs deliberately
Decide if NULL means unknown or zero, and use COALESCE when appropriate.
Inspect extremes
Use MIN and MAX to detect outliers and validate ranges against expectations.
Short checklist: compare counts, check for NULLs, run MIN/MAX sanity checks, and document choices when replacing NULLs.
