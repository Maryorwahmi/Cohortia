Module 3 › Chapter 3.3 › Key Concepts
Aggregate Functions
Functions that compute a single summary value across multiple rows.
COUNT variants
COUNT(*), COUNT(column), COUNT(DISTINCT column) differ by rows, non-NULL values, and unique values.
SUM & AVG
SUM adds numbers, AVG computes the mean; both ignore NULLs unless you COALESCE first.
Bottom line
Use these core aggregates to condense data into actionable metrics, and always validate your results for NULLs, duplicates, and filter scope.
