Definition
COUNT(*)
Counts all rows in the result set, including rows with NULLs.
COUNT(column_name)
Counts only non-NULL values in that specific column.
COUNT(DISTINCT column_name)
Counts unique non-NULL entries, useful for counting distinct entities.
Common mistake: treating COUNT(column) as if it counts rows. It does not count NULLs.
Concrete examples
Orders table queries
<-- Total orders
SELECT COUNT(*) AS total_orders
FROM Orders; 

<-- Orders with a shipping address
SELECT COUNT(shipping_address) AS orders_with_address
FROM Orders;

<-- Unique customers who ordered
SELECT COUNT(DISTINCT customer_id) AS unique_customers
FROM Orders;
Run all three queries to see how NULL shipping addresses lower the second count compared with COUNT(*), and how DISTINCT reduces duplicates when counting customers.
Common-mistake

Don't assume counts match across variants — NULLs and duplicates change results.
