Definition
COALESCE before aggregation
COALESCE(column, default) replaces NULLs with a chosen default value before applying SUM, AVG, or other aggregates.
When to use it:
  • Financial sums where missing equals zero.
  • Counts that should include missing as a default value in derived expressions.
  • When preparing data for downstream calculations that cannot accept NULLs.
Example & Caution
-- Treat NULL total_amount as zero
SELECT
  SUM(COALESCE(total_amount, 0)) AS total_revenue_with_defaults,
  SUM(total_amount) AS total_revenue_ignoring_nulls,
  COUNT(total_amount) AS non_null_count,
  COUNT(*) AS total_rows
FROM Orders;
Compare both SUMs to see how much missing data affects totals. Deciding to coalesce is an analytic choice, not a default rule.
Misconception

Automatically replacing all NULLs with zero can mask data quality issues. Validate first.
