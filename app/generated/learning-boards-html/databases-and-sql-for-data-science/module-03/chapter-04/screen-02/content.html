Learning Objectives
Four skill milestones for grouping and filtering groups
Learn → Understand → Apply → Master
01
Use GROUP BY to categorize rows
Define groups by one or more columns so aggregates compute per category. This matters when you need totals per customer or per product.
VERIFIED COMPETENCY MILESTONE
02
Apply aggregate functions correctly
Use SUM, AVG, COUNT on grouped rows to produce meaningful summaries like revenue or counts per group.
VERIFIED COMPETENCY MILESTONE
03
Differentiate WHERE vs HAVING
Remember WHERE filters rows first; HAVING filters groups after aggregation. You cannot use aggregates inside WHERE.
VERIFIED COMPETENCY MILESTONE
04
Build combined queries
Compose WHERE, GROUP BY, HAVING, and ORDER BY in the right order to answer complex questions like category revenue after a date filter.
VERIFIED COMPETENCY MILESTONE
