Practice checks to avoid common mistakes
Short verifications and mnemonics to use while building grouped queries.
Group by multiple columns
When you add year or region to GROUP BY, aggregation becomes more granular. Verify by counting distinct groups.
VERIFIED COMPETENCY MILESTONE
Every non-aggregated column must be grouped
If you select order_date without aggregating or grouping by it, results are ambiguous or error-prone.
VERIFIED COMPETENCY MILESTONE
Use HAVING for group filters
Aggregates belong in HAVING, not WHERE. Remember: WHERE filters rows; HAVING filters finished groups.
VERIFIED COMPETENCY MILESTONE
Repeat aggregates in HAVING
Don't rely on SELECT aliases in HAVING across dialects. Safer to write the aggregate expression again.
