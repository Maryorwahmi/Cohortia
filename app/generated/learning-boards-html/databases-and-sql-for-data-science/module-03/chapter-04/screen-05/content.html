Module 4 › Chapter 3.4 › Aggregates with GROUP BY
How aggregates behave per group
  • COUNT: number of rows in each group.
  • SUM: total of numeric values in the group; ignores NULLs in many dialects.
  • AVG: mean of values in the group; influenced by NULL handling and outliers.
Example
SELECT customer_id,
       COUNT(order_id) AS num_orders,
       SUM(total_amount) AS revenue
FROM Orders
GROUP BY customer_id
HAVING SUM(total_amount) > 1000;
This returns customers who have more than 1000 total revenue, demonstrating aggregate filtering with HAVING.
Supporting notes
  • If you need to exclude raw rows first, use WHERE before grouping; WHERE cannot reference aggregates.
  • HAVING can reference aggregates to keep or drop groups after calculation.
  • When portability matters, repeat aggregate expressions in HAVING instead of relying on SELECT aliases.
Common mistake

Attempting SUM(amount) > 1000 in WHERE will fail because WHERE runs before aggregation.
