Module 4 › Chapter 3.4 › Query Workflow
Step-by-step recipe
1. Select & From
Identify tables and columns you need.
2. WHERE
Filter raw rows before grouping.
3. GROUP BY
Choose grouping columns to set aggregation level.
4. SELECT aggregates
Add SUM, COUNT, AVG for each group.
5. HAVING
Filter groups using aggregate conditions.
6. ORDER BY
Sort final results for presentation.
Key Takeaway

Build grouped queries in stages, validate group counts against raw data, and fix any non-grouped columns explicitly.
