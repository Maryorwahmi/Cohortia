Why selecting non-grouped columns causes errors

Selecting a raw column that is not part of GROUP BY causes ambiguity. The database needs a rule to choose one value from many possible row values inside a group. Different SQL systems treat that differently; rely on explicit grouping or aggregation to be safe.

-- Problematic query
SELECT customer_id, order_date, SUM(total_amount)
FROM Orders
GROUP BY customer_id;
To fix this, either GROUP BY customer_id, order_date if you intend per-date groups, or use MIN(order_date) to show the earliest order per customer.
Fixes
  • Include the column in GROUP BY when appropriate.
  • Aggregate the column using MIN, MAX, or ARRAY_AGG when useful.
  • Avoid relying on non-standard engine behavior that returns an arbitrary row.
Warning

Selecting non-grouped columns without aggregation leads to errors or non-reproducible results. Be explicit.
