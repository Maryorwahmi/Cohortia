Safe HABITS for HAVING
Write HAVING clauses using explicit aggregate expressions to ensure queries behave the same across SQL dialects.
-- Less portable (uses alias)
SELECT customer_id, SUM(total_amount) AS total_customer_revenue
FROM Orders
GROUP BY customer_id
HAVING total_customer_revenue > 1000;
-- More portable (explicit aggregate)
SELECT customer_id, SUM(total_amount) AS total_customer_revenue
FROM Orders
GROUP BY customer_id
HAVING SUM(total_amount) > 1000;
Why prefer explicit
Explicit aggregates avoid dialect-specific parsing and make your intent clear to reviewers.
Key Takeaway

Write HAVING using aggregate expressions directly to increase portability and clarity.
