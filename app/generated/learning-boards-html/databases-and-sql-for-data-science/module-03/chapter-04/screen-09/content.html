Starter queries and patterns
-- 1. Total enrollment per instructor
SELECT instructor, SUM(enrollment_count) AS total_enrollment
FROM Courses
GROUP BY instructor;

-- 2. Instructors teaching more than one course
SELECT instructor, COUNT(course_id) AS course_count
FROM Courses
GROUP BY instructor
HAVING COUNT(course_id) > 1;

-- 3. Instructors whose total credits exceed 6
SELECT instructor, SUM(credits) AS total_credits
FROM Courses
GROUP BY instructor
HAVING SUM(credits) > 6;

-- 4. Enrollment > 50 considering only courses with credits > 2
SELECT instructor, SUM(enrollment_count) AS total_enrollment
FROM Courses
WHERE credits > 2
GROUP BY instructor
HAVING SUM(enrollment_count) > 50;
Run each query and compare results to expected outcomes. If values don't match, check whether a WHERE filter removed rows that should contribute to a group total.
Example outcomes
Using the sample Courses data, totals show Dr. Smith, Prof. Johnson, and Dr. Lee each teaching multiple courses and having totals consistent with the sample sums.
Key Takeaway

When mixing WHERE and HAVING, remember: WHERE changes the rows that form groups; HAVING changes which groups survive.
