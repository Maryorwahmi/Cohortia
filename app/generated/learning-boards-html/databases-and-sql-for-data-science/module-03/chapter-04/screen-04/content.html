Module 4 › Chapter 3.4 › What GROUP BY Does
Definition & behavior
  • Partitioning: GROUP BY collects rows that share the same values into groups.
  • Aggregation: Aggregate functions compute one value per group, not across the whole table.
  • Granularity: Adding more columns to GROUP BY increases granularity and creates more groups.
  • Rule: Every non-aggregated column selected must appear in GROUP BY.
Concrete example
SELECT customer_id, SUM(total_amount) AS total_customer_revenue
FROM Orders
GROUP BY customer_id;
This query returns one row per customer with that customer's total amount.
Illustration: grouping by customer and year
You can group by an expression derived from a column to change the grouping level, such as extracting the year from order_date.
SELECT customer_id,
STRFTIME('%Y', order_date) AS order_year,
SUM(total_amount) AS yearly_customer_revenue
FROM Orders
GROUP BY customer_id, order_year
ORDER BY customer_id, order_year;
Key Takeaway

Choose grouping columns to control the level of summary. More columns -> finer groups; fewer -> coarser totals.
