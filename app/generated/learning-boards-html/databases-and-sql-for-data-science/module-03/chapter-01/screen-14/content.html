Module 3 › Key Concepts
INSERT INTO
Add rows. Use explicit column lists and quote text/date literals.
UPDATE
Modify values with SET; protect scope with a precise WHERE clause.
DELETE / TRUNCATE
DELETE removes rows and logs each deletion. TRUNCATE is faster but often irreversible.
One-line summary
Always preview affected rows with SELECT, use explicit column lists, and prefer transactions or sandboxes for destructive changes to protect production data.
