Definition › INSERT single-row
How to write it

List the column names, then supply the matching VALUES in the same order. Quote strings and dates; leave numbers unquoted.

INSERT INTO Customers (customer_id, first_name, last_name, email, registration_date)
VALUES (101, 'Alice', 'Smith', 'alice.smith@example.com', '2023-01-15');
Tip: Run a SELECT after insert to confirm values and data types.
Example explained
  • • The column list matches the VALUES list, ensuring each value goes to the correct field.
  • • Strings and the date are in single quotes; customer_id is numeric so not quoted.
  • • Omitted column lists force values for all table columns in schema order — fragile.
Common mistake
Forgetting quotes around strings, or omitting columns, often causes errors or silent misplacements.
Key Takeaway

Explicit column lists and correct quoting make single-row INSERTs predictable and maintainable.
