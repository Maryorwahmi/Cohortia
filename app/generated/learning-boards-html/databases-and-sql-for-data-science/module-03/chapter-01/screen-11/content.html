Core Concept › DELETE
Example deletion
DELETE FROM Customers
WHERE customer_id = 101;
Confirm the customer exists with a SELECT before running DELETE, and prefer transactions for safety.
When to soft-delete
If you need to retain history for auditing or rollback, consider marking rows as inactive instead of physically deleting them. Soft deletes preserve data for analysis while keeping it out of active queries when needed.
Key Takeaway

DELETE removes rows and logs deletions; always preview the affected rows and consider soft deletes when history matters.
