DML — Quick definition

A set of SQL commands for managing table rows: add, change, or remove data that your analyses depend on.

Insert (create)
Add new records so queries and feature pipelines include them.
Update (modify)
Change existing values when data is corrected or enriched.
Delete (remove)
Remove obsolete or incorrect rows; do so with caution.
Analogy & Example
Think of a table as a spreadsheet. INSERT adds a new row at the bottom, UPDATE edits cells in place, and DELETE removes rows. If you created a new customer record, that single INSERT makes the customer visible to reports and models that query the Customers table.
Common mistake
Treating DML as a read-only experiment. Always preview changes with a SELECT and run destructive commands in a transaction when possible.
Key Takeaway

DML makes your data live. Use explicit columns, WHERE clauses, and testing to avoid broad accidental changes.
