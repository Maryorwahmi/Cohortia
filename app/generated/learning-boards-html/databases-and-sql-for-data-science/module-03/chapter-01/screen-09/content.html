Core Concept › Multi-column UPDATE
Example: multiple columns
UPDATE Products
SET price = 1250.00, category = 'Premium Electronics'
WHERE product_id = 201;
This updates two fields together so the product is consistent after the change.
Example: arithmetic update
UPDATE Products
SET price = price * 0.90 -- Apply a 10% discount
WHERE category = 'Accessories';
Preview the rows with the WHERE clause to ensure only the intended items are discounted.
Key Takeaway

Update multiple columns and use expressions for in-place changes, but always confirm the WHERE selection before executing.
