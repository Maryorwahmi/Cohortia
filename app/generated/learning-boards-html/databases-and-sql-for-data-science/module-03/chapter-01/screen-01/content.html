Data Manipulation Language

Practical commands to insert, update, and delete rows. This module teaches syntax, safety checks, and when to use TRUNCATE instead of row-by-row deletion.

DML Snapshot
Insert • Update • Delete
Practical | Safe | Transactional
Insert
Add new rows. Use column lists and single-quote strings.
Update
Modify existing values. WHERE clause controls scope.
Delete
Remove rows carefully; test first and consider transactions.
Truncate
Fast table reset; cannot usually be rolled back and skips delete triggers.
