Hands-on checklist
  • • Create table if missing and inspect schema with a SELECT or describe command.
  • • Insert single rows with explicit column lists and single-quoted strings for text and dates.
  • • Insert multiple rows in one VALUES list for efficiency when loading small batches.
  • • Update targeted rows using WHERE and preview the rows before committing.
  • • Delete rows cautiously; prefer transaction rollback capability during testing.
Mnemonic
IUD — Insert, Update, Delete. Remember: list columns, use WHERE, test on sandbox.
