Module 3 › Chapter 3.2 › LIKE and Wildcards
Definition
LIKE tests whether a string fits a pattern built from literals and wildcard symbols. % matches any sequence of characters; _ matches a single character.
Example
SELECT customer_id, first_name, email
FROM Customers
WHERE email LIKE '%@example.com';
% wildcard
Matches zero or more characters. Good for domain suffixes and contains checks.
_ wildcard
Matches exactly one character. Useful for fixed-length patterns.
Common mistake
Assuming LIKE is case-insensitive. Behavior varies by database; normalize with LOWER(column) if you need consistent matching.
Pattern examples and result hints
Contains 'pro'
WHERE LOWER(product_name) LIKE '%pro%'
Matches names with 'pro' anywhere; use LOWER to ignore case.
Starts with Jo and 4 more chars
WHERE product_name LIKE 'Jo____'
Matches names like 'Jordan' or 'Joseph' where underscores represent single characters.
Key takeaway
Use % for flexible spans, _ for single-character constraints, and normalize case when needed.
