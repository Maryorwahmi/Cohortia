Module 3 › Chapter 3.2 › IS NULL & IS NOT NULL
Concept
NULL signals missing data; comparisons using = or != don't work. Use IS NULL and IS NOT NULL to detect absence or presence explicitly.
Example
SELECT customer_id, first_name, last_name
FROM Customers
WHERE email IS NULL;
Common mistake
Writing email = NULL will not return rows with missing emails because NULL cannot be compared with =.
When to check for NULL
Check NULLs before aggregations, joins, or when a missing value changes the meaning of a filter. Explicit checks prevent silent data loss.
Key Takeaway

Treat NULL specially: use IS NULL / IS NOT NULL, and never compare to NULL with = or !=.

Quick check
If a filter seems to exclude expected rows, verify whether NULL values exist and whether you used IS NULL correctly.
