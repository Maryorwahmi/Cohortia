Learning Objectives
Learn, Understand, Apply, Master
Bloom: Learn → Understand → Apply → Master
01
Use LIKE and wildcards
Write patterns with % and _ to match email domains, prefixes, or character shapes.
Mnemonic: think of % as a wide net and _ as a single slot.
VERIFIED COMPETENCY MILESTONE
02
Apply BETWEEN for ranges
Select inclusive numeric or date ranges with clear, readable syntax.
Mnemonic: BETWEEN is a bracket that includes endpoints.
VERIFIED COMPETENCY MILESTONE
03
Use IN to test lists
Filter by membership in a set instead of chaining multiple OR conditions.
Mnemonic: IN is a short list check.
VERIFIED COMPETENCY MILESTONE
04
Identify and handle NULL
Use IS NULL and IS NOT NULL to detect missing values; avoid equals comparisons to NULL.
Mnemonic: NULL is an empty box — you must ask if the box is empty.
