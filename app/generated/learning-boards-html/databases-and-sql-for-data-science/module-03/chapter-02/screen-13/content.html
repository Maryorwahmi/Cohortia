Quick Reference
IS NULL
Detect missing values explicitly; do not use = NULL.
Operator precedence
NOT > AND > OR. Use parentheses when mixing operators.
Normalize text
Use LOWER or UPPER for consistent LIKE behavior across DBs.
Final Tip
Follow a filter checklist: pick operator, decide inclusivity, handle NULLs, normalize text, and group logic. Test stepwise to confirm expected rows.
