Module 3 › Chapter 3.2 › IN and NOT IN
Concept
IN tests whether a column value appears in a supplied list. It's shorthand for multiple equality checks joined by OR.
Example
SELECT product_name, category, price
FROM Products
WHERE category IN ('Electronics', 'Books', 'Home Goods');
Readability
IN simplifies maintenance compared to long OR lists.
NOT IN
Select values not present in a list. Use with care and add explicit IS NOT NULL when necessary to handle missing values.
Equivalent OR chain
WHERE category = 'Electronics' OR category = 'Books' OR category = 'Home Goods'
Key Takeaway

Use IN for concise list checks and be explicit about NULL handling when the column may be missing values.
