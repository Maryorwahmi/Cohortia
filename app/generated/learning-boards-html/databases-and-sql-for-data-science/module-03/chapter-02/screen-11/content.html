Common Mistakes and Fixes
NULL comparisons
Don't use = NULL. Use IS NULL or IS NOT NULL to detect missing values; otherwise rows disappear silently.
Operator precedence
Parentheses control evaluation order. When mixing AND and OR, group related conditions to avoid logical errors.
Case sensitivity
If LIKE behaves differently between environments, normalize with LOWER or UPPER.
BETWEEN endpoints
BETWEEN is inclusive. For timestamps, prefer half-open intervals when you need exclusive upper bounds.
Stepwise debugging
Apply predicates one at a time, check counts, and isolate the constraint that removes expected rows.
Practice tip
Use LIMIT and sample rows during debugging to iterate quickly and confirm results before running full queries.
