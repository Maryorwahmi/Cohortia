Module 3 › Chapter 3.2 › BETWEEN for Ranges
Concept
BETWEEN offers inclusive start and end values for numbers, dates, or strings where that semantics makes sense.
Example
SELECT order_id, customer_id, order_date, total_amount
FROM Orders
WHERE order_date BETWEEN '2023-01-01' AND '2023-01-31';
Equivalence
BETWEEN A AND B is the same as column >= A AND column <= B.
Timestamp caution
If values include time, the end date includes all times on that day; use half-open ranges when needed.
Alternative half-open range
To include all of January without relying on day inclusivity, write an exclusive upper bound:
WHERE order_date >= '2023-01-01' AND order_date < '2023-02-01'
Key Takeaway

BETWEEN is convenient and inclusive; choose explicit bounds if you must control endpoint semantics with timestamps.

Try this
Identify whether your date column includes time and pick BETWEEN or an explicit half-open range accordingly.
