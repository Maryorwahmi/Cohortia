Module 3 › Chapter 3.2 › AND / OR / NOT
Rules and precedence
NOT has highest precedence, then AND, then OR. Parentheses override this order and make intent explicit.
Examples
-- All must be true
WHERE city = 'New York' AND is_active = TRUE
  AND registration_date BETWEEN '2023-10-01' AND '2023-10-31';

-- Either condition is enough
WHERE category = 'Electronics' OR price > 1000;

-- Using NOT with parentheses
WHERE NOT (category = 'Electronics' OR price > 1000);
De Morgan reminder
NOT (A OR B) is equivalent to (NOT A) AND (NOT B). Rewriting expressions can make intent clearer when negating complex logic.
Misconception
Chaining AND and OR without parentheses often yields unexpected rows because of precedence rules. Add parentheses to be explicit.
Key Takeaway

Group logical conditions with parentheses and test with sample data so the filter returns the intended rows.
