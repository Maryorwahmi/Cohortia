Task hints
  • Use LIKE 'A% e' styles with underscores or combined anchors for first-name patterns.
  • Use BETWEEN for the registration window and check date inclusivity.
  • Use IN for the city list and IS NULL for missing email rows.
Important note
The sample dataset contains a trick: the combined condition in task 5 returns no rows. This illustrates that precise filters can legitimately return zero results.
Key takeaway
Build queries stepwise, test each WHERE clause, and add constraints only after verifying intermediate results.
