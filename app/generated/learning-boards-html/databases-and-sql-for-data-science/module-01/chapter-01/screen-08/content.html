Definition

What is SQL?

A domain-specific language for defining structure and performing data operations in relational databases.

DDL (schema)
Commands like CREATE TABLE and ALTER TABLE define structure.
DML (data)
Commands like SELECT, INSERT, UPDATE, DELETE manage the data itself.
Practical note

Use SQL to prepare and reduce data before analysis, which speeds workflows and avoids duplicated cleaning work.

Short example
-- Select customers with recent orders
SELECT c.customer_id, c.first_name, SUM(o.amount) AS total_spent
FROM Customers c
JOIN Orders o ON c.customer_id = o.customer_id
WHERE o.order_date > '2023-01-01'
GROUP BY c.customer_id, c.first_name;
This SELECT with JOIN shows how SQL combines tables and aggregates results before analysis.
