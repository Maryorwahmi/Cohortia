Key Concepts

Three compact cards summarize the essentials from this chapter.

Database
An organized electronic collection for efficient storage and retrieval.
Tables, Rows, Columns
The relational structure that supports uniform queries and aggregations.
Keys
Primary and foreign keys ensure uniqueness and meaningful connections between tables.
Summary: Design tables, choose stable keys, and use SQL to prepare data so analyses are reproducible and accurate.
