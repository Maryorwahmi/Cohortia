Definition

Tables, Rows, Columns

Think in entities and attributes: tables model entities; columns are attributes; rows are instances.

Concrete example
Table: Customers Columns: customer_id (PK), first_name, last_name, email Row example: 42 | Sara | Khan | sara@example.com
Common mistake
Allowing inconsistent attributes across records or not defining nullability makes analysis error-prone.
Hierarchy visual
Table
A named set of rows with shared columns.
Row (Record)
A single instance with values for each column.
Column (Attribute)
Holds the same type of value across rows.
Why uniform columns help
  • Simplifies SELECT and aggregation
  • Enables indexing and validation
Design question
What attributes does this entity always need for analysis?
