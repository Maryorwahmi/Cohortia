Process Flow

DDL → DML → Query

Follow a simple sequence to define structure, add data, and then extract what you need for analysis.

1. CREATE TABLE (DDL)
Define columns, types, and primary keys.
2. INSERT (DML)
Add rows of data into the table.
3. SELECT (DML)
Retrieve, filter, and aggregate records for analysis.
Code examples
-- Create Students table
CREATE TABLE Students (
  student_id INTEGER PRIMARY KEY,
  first_name TEXT,
  last_name TEXT,
  email TEXT
);

-- Insert a student
INSERT INTO Students (student_id, first_name, last_name, email)
VALUES (1, 'Alex', 'River', 'alex@example.com');

-- Select students
SELECT student_id, first_name, last_name
FROM Students
WHERE email IS NOT NULL;
Practice these steps with sample data to observe how queries behave on real records.
