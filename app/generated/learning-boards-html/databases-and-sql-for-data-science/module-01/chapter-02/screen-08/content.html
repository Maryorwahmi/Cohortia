Structuring Your Data: The `CREATE TABLE` Statement

Learn to define new tables, specifying their names, columns, and data types.

DDL Command

`CREATE TABLE` is part of Data Definition Language, used to define database schema.

Table Structure

Establishes the table's name, column names, and their corresponding data types.

Key Takeaway

The `CREATE TABLE` statement is fundamental for defining the logical structure of your database, ensuring organized and consistent data storage.

Basic `CREATE TABLE` Syntax
CREATE TABLE TableName (
    column1_name DATATYPE,
    column2_name DATATYPE,
    ...
);
Example: Simple `Products` Table
CREATE TABLE Products (
    product_id INTEGER,
    product_name TEXT,
    price REAL
);
