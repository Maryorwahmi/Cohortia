Interacting with SQLite: The Command-Line Interface (CLI)

Learn how to launch and use the SQLite CLI to manage your databases.

What is the CLI?

The SQLite Command-Line Interface (`sqlite3`) is a simple program for direct interaction with SQLite databases.

Installation & Launch

Often pre-installed on Linux/macOS. Launch by typing `sqlite3 [database_file.db]` in your terminal.

Key Takeaway

The SQLite CLI is your essential tool for direct database interaction, allowing you to execute SQL commands and manage your file-based databases.

Terminal Command: Check SQLite Version
$ sqlite3 --version
3.34.1 2020-12-01 16:14:00 ...
Terminal Command: Launch CLI & Create/Open DB
$ sqlite3 my_first_db.db
SQLite version 3.34.1 2020-12-01 16:14:00
Enter ".help" for usage hints.
sqlite>
CLI Command: Exit SQLite
sqlite> .quit
$
