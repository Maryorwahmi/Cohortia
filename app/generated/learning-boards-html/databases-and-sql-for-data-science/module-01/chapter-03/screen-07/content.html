Selecting All Columns: The Wildcard `*`

Quickly explore table contents without listing every column name.

SELECT *
FROM Students;
This query retrieves all columns and all rows from the 'Students' table.
Practical Use

Ideal for initial data exploration, understanding table schema, or when you genuinely need all data for a quick overview.

How it Works

The asterisk (*) acts as a placeholder for 'all columns'. When used in a SELECT statement, the database returns every column defined in the specified table.

Key Takeaway

The `SELECT *` syntax is a powerful shortcut for quickly viewing all data in a table, perfect for initial exploration and learning.
