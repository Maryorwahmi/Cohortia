Key Concepts Reinforced

Review and solidify your understanding of core SQL terminology.

Query

A request for data or information from a database. Every `SELECT` statement is a query.

SQL Statement

A complete instruction to the database, often ending with a semicolon, to perform a specific action.

Data Manipulation Language (DML)

A subset of SQL commands, including `SELECT`, `INSERT`, `UPDATE`, and `DELETE`, used for managing data.

Chapter Summary

Queries are requests for data, SQL statements are complete instructions, and DML commands like `SELECT` are used to interact with data.
