Definition › read_sql_table()
What it does
Loads an entire named table from the database into a DataFrame. Optionally use schema and index_col.
Practical checks
  • Confirm table size before loading.
  • Use index_col when the table has a meaningful identifier.
  • Prefer it for small-to-medium tables or offline snapshots.
Example check
In the lesson code we call pd.read_sql_table('sensor_readings', conn) to inspect the full table and then run df.head() and df.info() to see columns and types.
df_all = pd.read_sql_table('sensor_readings', conn)
print(df_all.head())
print(df_all.shape)
df_all.info()
Misconception
Assuming read_sql_table is always faster — it's about convenience, not magic performance gains for large datasets.
Key takeaway
Use read_sql_table for full snapshots, but prefer read_sql_query for targeted loads to save resources.
