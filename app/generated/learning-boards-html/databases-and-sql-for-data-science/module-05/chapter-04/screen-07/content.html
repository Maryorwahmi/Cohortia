Inspection checklist
  • df.head(): glimpse values and column order.
  • df.shape: confirm row/column counts match expectation.
  • df.info(): check dtypes and missing values.
  • Convert timestamp strings with pd.to_datetime when needed.
Pro tip
If timestamps are strings, parse them early so groupby and resample operations work reliably.
