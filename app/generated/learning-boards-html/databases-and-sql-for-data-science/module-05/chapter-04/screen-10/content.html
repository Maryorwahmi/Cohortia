Comparison › read_sql_query vs read_sql_table
read_sql_query
  • Run arbitrary SQL for precise result sets.
  • Reduces data transfer for large tables.
  • Best when you need filtered or aggregated data.
read_sql_table
  • Convenience wrapper to load a full table by name.
  • Useful for snapshots and full-table EDA.
  • Beware of memory cost on very large tables.
Decision rule
If you can express a precise SELECT that returns far fewer rows, prefer read_sql_query. If you genuinely need everything for exploration, use read_sql_table.
