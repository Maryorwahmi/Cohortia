Core Concept › read_sql_query()
Definition
Execute a SQL statement on the database and load the returned rows into a Pandas DataFrame.
Why use it?
  • Filter or aggregate at the database to minimize data transfer.
  • Run joins in SQL when relationships are better expressed there.
  • Return a DataFrame directly for immediate analysis.
Concrete example
Load all temperature readings above 23.0 and order by timestamp descending, then inspect the DataFrame shape to confirm you received only the subset you expected.
Code sketch
This pattern runs a SQL query and returns a DataFrame. The exact code appears in the lab, but the pattern is query + connection → DataFrame.
sql_query = """
SELECT device_id, timestamp, temperature
FROM sensor_readings
WHERE temperature > 23.0
ORDER BY timestamp DESC;
"""
df_filtered = pd.read_sql_query(sql_query, conn)
print(df_filtered.shape)
Common mistake
Loading the entire table when only a few rows are needed — use a WHERE clause instead.
Key takeaway
Filter early in SQL with read_sql_query to make downstream Pandas analysis efficient and focused.
