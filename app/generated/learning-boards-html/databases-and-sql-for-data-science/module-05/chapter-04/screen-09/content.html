Core Concept › DataFrame.to_sql()
Parameters that matter
  • name: target table name
  • con: database connection
  • if_exists: 'fail', 'replace', or 'append'
  • index: whether to write the DataFrame index as a column
Concrete examples
Write a new city_data table with replace and index=False, then append more rows with append.
df_cities.to_sql('city_data', conn, if_exists='replace', index=False)
more_cities.to_sql('city_data', conn, if_exists='append', index=False)
Warning
Using replace will drop the existing table and any data in it. Use with caution and backups where needed.
