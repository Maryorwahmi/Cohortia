Insecure Python snippet (illustration only)

This snippet shows the pattern to avoid. Do not run code that concatenates user input into SQL strings.

# Vulnerable pattern - do not execute user_input = "admin' OR '1'='1" query = f"SELECT * FROM users WHERE username = '{user_input}';" # Executing the query in this form would allow input to change SQL behavior
Why it is bad
Interpolated input can turn a filter into a universal truth or inject additional statements. This can leak rows or modify schema.
Quick fix
Replace the string building with a parameterized query using question-mark placeholders and pass a tuple of values to execute.
Pro tip
Add unit tests that pass malicious-looking strings to queries to confirm they do not alter database structure or return unexpected rows.
