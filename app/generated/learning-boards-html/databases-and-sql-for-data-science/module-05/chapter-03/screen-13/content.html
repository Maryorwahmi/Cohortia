Safety first: practical checklist

1
No concatenation
Ensure SQL does not include direct user input via string formatting.
2
Correct parameter shapes
Pass tuples/lists that match placeholders exactly.
3
Handle constraints
Filter or catch IntegrityError when inserting duplicates.
4
Use transactions
Wrap multi-step changes and commit or rollback appropriately.
5
Test malicious input
Add tests that pass inputs like "admin' OR '1'='1" to confirm safe behavior.
6
Centralize DB access
Keep helpers so safe patterns are easy to reuse and review.
