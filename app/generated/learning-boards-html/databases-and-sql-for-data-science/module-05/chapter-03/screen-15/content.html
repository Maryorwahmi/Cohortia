What to Remember

Don't concatenate
Embedding user input into SQL text creates injection risk.
Use placeholders
Question-mark placeholders in sqlite3 and parameter tuples keep values literal.
Batch safely
Use executemany with filtered lists for efficient, secure bulk inserts.
Final thought

A small, consistent habit—treating all input as untrusted and parameterizing every query—prevents most SQL injection risks in data science code.
