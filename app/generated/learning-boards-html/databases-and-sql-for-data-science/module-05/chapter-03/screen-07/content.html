Parameterized Queries in sqlite3

Mechanics
Use question marks as placeholders in the SQL text. Pass values as a tuple in the second argument to cursor.execute. Values bind positionally and are treated as data only.
select_sql = "SELECT * FROM users WHERE username = ?;" cursor.execute(select_sql, (search_username,)) found = cursor.fetchone()
Practical notes
  • For a single parameter use a one-element tuple: (value,) not (value).
  • Parameter order maps to placeholder order.
  • Do not try manual escaping; rely on the adapter's binding behavior.
Common mistake
Passing a bare value instead of a tuple for single-parameter calls, which can raise an error or bind incorrectly.
Pro tip
Write small helper functions that centralize parameterized calls so every query follows the same safe pattern.
Key Takeaway
Placeholders plus parameter tuples keep values from being interpreted as SQL logic.
