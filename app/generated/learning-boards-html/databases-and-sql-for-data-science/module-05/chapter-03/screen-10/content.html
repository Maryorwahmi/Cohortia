Check existing rows before bulk insert

# Prepare new users list new_users_data = [ ('diana', 'diana@example.com'), ('eve', 'eve@example.com'), ('frank', 'frank@example.com') ] # Parameterized select to find existing usernames existing_users_query = "SELECT username FROM users WHERE username IN (?, ?, ?);" cursor.execute(existing_users_query, tuple(u[0] for u in new_users_data)) existing_usernames = {row[0] for row in cursor.fetchall()} # Filter and batch insert filtered_new_users = [user for user in new_users_data if user[0] not in existing_usernames] if filtered_new_users: insert_many_sql = "INSERT INTO users (username, email) VALUES (?, ?);" cursor.executemany(insert_many_sql, filtered_new_users) conn.commit()
Why this helps
Avoids IntegrityError, keeps runs idempotent, and provides a clear audit of how many new rows were added.
Edge case
If you expect many names, generate the IN clause programmatically with the correct number of placeholders to match the parameter list length.
Common mistake
Hardcoding a fixed IN clause without matching the number of parameters will cause errors. Build the placeholders to match your tuple length.
