Bulk insertion with executemany()

Process
1. Prepare a list of tuples: [(username, email), ...]
2. Optionally check existing rows with a parameterized SELECT and filter the new list.
3. Call cursor.executemany("INSERT INTO users (username, email) VALUES (?, ?)", list_of_tuples)
4. Commit the transaction and verify inserted rows with a secure SELECT.
Example snippet
insert_many_sql = "INSERT INTO users (username, email) VALUES (?, ?);" cursor.executemany(insert_many_sql, filtered_new_users) conn.commit()
Why use executemany
It reduces overhead and batches parameter binding, improving performance and safety over looping execute calls with concatenation.
Best practice
Filter out existing rows before executemany to avoid IntegrityError and wasted work.
Check your understanding
Why is executemany safer than building a single long SQL string with many VALUES clauses assembled from input?
Common mistake
Assuming executemany bypasses parameterization — it does not; it uses parameterized binding per row when called correctly.
