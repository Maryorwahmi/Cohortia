Secure SELECT and INSERT examples

# Secure SELECT select_sql = "SELECT id, username, email FROM users WHERE username = ?;" cursor.execute(select_sql, (search_username,)) user = cursor.fetchone() # Secure INSERT with error handling try: cursor.execute("INSERT INTO users (username, email) VALUES (?, ?)", (uname, email)) conn.commit() except sqlite3.IntegrityError: # handle duplicate or constraint failure pass
Notes
Always pass a tuple or list of values. For single-value binds use a one-element tuple. Catch IntegrityError for unique constraints.
Why commit?
Committing persists changes. Use transactions for grouped changes and roll back on failure when appropriate.
Safety First!
Never construct SQL from user input even if you plan to sanitize. Parameterize instead.
