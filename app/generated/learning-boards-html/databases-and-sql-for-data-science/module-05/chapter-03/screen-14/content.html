Key Concepts

SQL Injection
Untrusted input that changes query logic and can expose or destroy data.
Parameterized Queries
Use question-mark placeholders and pass a tuple of values so the adapter binds values as data only.
executemany()
Provide a list of parameter tuples to insert many rows efficiently while staying secure.
Summary

Treat structure and data separately: placeholders for SQL structure, parameter tuples for values, and executemany for safe bulk operations.
