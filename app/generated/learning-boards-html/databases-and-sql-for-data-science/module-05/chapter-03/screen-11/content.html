Implement update_user_email(username, new_email)

def update_user_email(username, new_email): conn = None try: conn = sqlite3.connect(db_file) cursor = conn.cursor() # Parameterized UPDATE - safe binding of values update_sql = "UPDATE users SET email = ? WHERE username = ?;" cursor.execute(update_sql, (new_email, username)) conn.commit() if cursor.rowcount > 0: print(f"Successfully updated email for user '{username}'.") else: print(f"User '{username}' not found, no update performed.") except sqlite3.Error as e: print(f"Database error during update: {e}") finally: if 'cursor' in locals() and cursor: cursor.close() if conn: conn.close()
Verification steps
1. Print the user before update with a parameterized SELECT. 2. Run update_user_email for 'bob' to 'robert@example.com'. 3. Re-run the SELECT to confirm the change. 4. Try a malicious username and confirm no error and no unintended change.
Why check rowcount
cursor.rowcount indicates whether an UPDATE matched any rows, providing clear feedback for logging or UI messages.
Safety First!
Treat all inputs as untrusted. Parameterized UPDATE prevents the username from being interpreted as SQL.
