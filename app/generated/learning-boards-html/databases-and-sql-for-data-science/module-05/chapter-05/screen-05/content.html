Module 6 › Chapter 5.5 › ORM vs Raw SQL
ORM — Benefits
  • Readable, Pythonic domain models.
  • Built-in parameterization for safety.
  • Easy handling of relationships and cascading.
Example
Creating and committing a Product object adds a row; querying returns model instances you can inspect and modify directly.
Raw SQL — When to use
  • Complex analytic queries for performance tuning.
  • Vendor-specific features not exposed by the ORM.
  • Fine-tuned set-based updates across many rows.
Misconception
Using raw SQL everywhere is not inherently better; it increases boilerplate and risk. Use it only where necessary and isolate it behind well-tested functions.
