Module 6 › Chapter 5.5 › Hands-on: Order & Stock
Starter steps
  1. Define Order with a ForeignKey to products.id and a relationship to Product.
  2. Run Base.metadata.create_all(engine) to create the orders table.
  3. Create a session, find the Product by name, create an Order, update product.stock, commit.
  4. Query orders and orders filtered by product to verify results.
Starter code snippet
from datetime import datetime

# Create an order if stock allows
keyboard = session.query(Product).filter_by(name='Keyboard').first()
if keyboard and keyboard.stock >= 5:
    new_order = Order(product_id=keyboard.id, quantity=5, order_date=datetime.now().isoformat())
    session.add(new_order)
    keyboard.stock -= 5
    session.commit()
Verification steps
Query all orders, and query orders for a product by product_id. Inspect product.stock to confirm it decreased by the ordered quantity after commit.
Key Takeaway

Updating related rows and inserting new ones within the same transaction keeps data consistent; verify with follow-up queries after commit.
