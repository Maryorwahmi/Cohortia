Module 6 › Chapter 5.5 › Learning Objectives
Apply: Transactions and Error Handling
You will write try, except, finally patterns that call session.rollback on errors and always session.close in the finally block. This ensures data integrity and releases connections.
Practice
Create an Order, subtract stock, and commit atomically.
Watch out
Forgetting session.commit leaves changes in memory and not persisted.
Decision guide
  • Use ORM when you want readable, maintainable Python code for common CRUD.
  • Use raw SQL for vendor-specific tuning or complex set-based queries not easily expressed via the ORM.
  • Remember you can combine both: use ORM for most logic and raw SQL for hotspots.
