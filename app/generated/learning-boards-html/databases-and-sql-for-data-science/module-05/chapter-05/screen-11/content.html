Order model (code)
class Order(Base):
    __tablename__ = 'orders'
    id = Column(Integer, primary_key=True)
    product_id = Column(Integer, ForeignKey('products.id'), nullable=False)
    quantity = Column(Integer, nullable=False)
    order_date = Column(String, nullable=False)

    product = relationship("Product", back_populates="orders")

    def __repr__(self):
        return f"<Order(id={self.id}, product_id={self.product_id}, quantity={self.quantity}, date='{self.order_date}')>"

# On Product model:
# orders = relationship("Order", back_populates="product")
Usage
After creating and committing an order, you can access order.product.name or product.orders to inspect related data. Update stock on the product instance and commit to persist both the order and stock change as part of the session's transaction.
Performance note
Be aware of lazy loading and the n+1 query problem when iterating related collections; use explicit joined loading for bulk fetches when needed.
Key Takeaway

Relationships provide convenient object navigation and reflect foreign key constraints; use them thoughtfully to avoid extra queries.
