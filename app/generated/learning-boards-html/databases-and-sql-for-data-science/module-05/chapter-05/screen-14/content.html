Module 6 › Chapter 5.5 › Key Concepts
ORM
Maps objects to tables and generates parameterized SQL.
Engine & Base
Engine manages connections; Base collects model metadata for table creation.
Session & Transactions
Session stages changes; commit, rollback, and close control persistence and resources.
Keep these concepts in mind when building and maintaining database-backed Python apps: models, sessions, transactions, relationships, and the decision when to use raw SQL.
