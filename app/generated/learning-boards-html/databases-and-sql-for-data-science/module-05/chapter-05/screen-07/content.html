Module 6 › Chapter 5.5 › Defining a Model Class
Product model (code)
class Product(Base):
    __tablename__ = 'products'

    id = Column(Integer, primary_key=True)
    name = Column(String, nullable=False, unique=True)
    price = Column(Float, nullable=False)
    stock = Column(Integer, default=0)

    def __repr__(self):
        return f"<Product(id={self.id}, name='{self.name}', price={self.price}, stock={self.stock})>"
Notes
  • unique=True ensures the database enforces uniqueness for the name column.
  • default applies when no value is provided at insert time.
  • __repr__ helps when printing query results for debugging.
Concrete example
When you create Product(name='Mouse', price=25.5, stock=200) and call session.add then session.commit, SQLAlchemy generates the INSERT with bound parameters for name, price, and stock.
Common mistake

Defining models without constraints can lead to inconsistent data; prefer explicit nullable and unique settings where appropriate.
