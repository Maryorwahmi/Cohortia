Essential commands
Base.metadata.create_all(engine)

from sqlalchemy.orm import sessionmaker
Session = sessionmaker(bind=engine)
session = Session()
These steps create missing tables and open a session bound to the engine for transactional work. Use session objects for a clear unit of work scope.
Session lifecycle pattern
Use try, except, finally with commit and rollback to ensure changes are atomic and resources are always released.
Pattern example
try:
    session.add(obj)
    session.commit()
except Exception:
    session.rollback()
    raise
finally:
    session.close()
Key Takeaway

Commit to persist changes, rollback on error, and always close the session to free the connection.
