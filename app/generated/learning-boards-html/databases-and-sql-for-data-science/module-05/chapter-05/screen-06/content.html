Module 6 › Chapter 5.5 › Engine & Declarative Base
Step-by-step
  1. Create an engine with create_engine('sqlite:///inventory.db', echo=True) to manage connections and optionally log SQL.
  2. Create Base by calling declarative_base() so models inherit metadata and mapping behavior.
  3. Define models as classes inheriting from Base and set __tablename__ and Column fields.
  4. Call Base.metadata.create_all(engine) to create tables if they do not exist.
Why echo=True?
Enabling SQL logging helps you see generated SQL and troubleshoot queries during development. It's especially helpful when learning how the ORM translates object operations.
Code snippet
from sqlalchemy import create_engine
from sqlalchemy.orm import declarative_base

engine = create_engine('sqlite:///inventory.db', echo=True)
Base = declarative_base()
Key Takeaway

Engine ties to the DB and Base centralizes model metadata so the ORM can create tables and map classes correctly.
