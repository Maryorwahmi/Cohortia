Developer checklist
  • Enable echo=True during development to inspect SQL.
  • Scope sessions to short-lived units of work and close them promptly.
  • Use try/except/finally with rollback on exceptions.
  • Enforce constraints in models and validate inputs before commit.
  • Profile queries and use raw SQL selectively for performance-critical paths.
Small test idea
Write a test that creates a product, creates an order, commits, then re-queries both to assert the stock change and the order exist. Include rollback in teardown to keep tests isolated.
Key Takeaway

Good tooling, scoped sessions, and explicit constraints make ORM-backed systems reliable and debuggable.

Debug tip
When behavior is unexpected, reproduce the sequence in a small script with echo=True and inspect SQL and returned rows step by step.
