Module 6 › Chapter 5.5 › What to Remember
1. Session Safety
Commit on success, rollback on failure, close to release resources.
2. Explicit Constraints
Define nullable, unique and defaults to let the DB enforce invariants.
3. Pragmatic SQL
Use the ORM for most tasks; drop to raw SQL only for complex or tuned queries.
Parting thought

Use the ORM to make your data code clearer and safer, while keeping the option to run raw SQL where it truly matters.
