Module 6 › Chapter 5.5 › What is an ORM?
Definition
An ORM maps application classes to database tables and converts object operations into SQL. It manages parameterization, state, and transactions.
  • Abstraction: work with objects instead of raw SQL strings.
  • Safety: parameterized queries are generated by the library.
  • Productivity: less repetitive SQL for CRUD and relationships.
Concrete example
Creating a product object and committing the session inserts a new row without writing an INSERT statement manually. The ORM generates the SQL for you while keeping the operation parameterized and safe.
Common misconception
Some people think ORMs eliminate the need for SQL knowledge. In reality, understanding joins, query plans, and indexing remains important when performance matters. Use the ORM for clarity and safety, and drop to raw SQL when you need precise control.
