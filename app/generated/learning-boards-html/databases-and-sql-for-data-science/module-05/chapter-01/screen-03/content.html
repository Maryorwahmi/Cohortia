Objective tasks

These tasks translate the objectives into short checks you can run in minutes during setup.

01
Install & import

pip install package, then run a quick import to ensure it loads in your environment.

02
SQLite connect test

Open a connection to a file, run SELECT sqlite_version(), and close the connection.

03
Use SQLAlchemy when needed

Choose SQLAlchemy to write engine-agnostic code that can target multiple back ends with one API.

04
Troubleshoot installs

If pip fails on compilation, try a binary wheel like psycopg2-binary to avoid C build requirements.

VERIFIED COMPETENCY MILESTONE
Practical mnemonic

Remember: Install inside virtual environment, Import to test, Connect to verify, Close to free resources. This sequence prevents common errors in new projects.

Check
If a package installs but cannot be imported, confirm the virtual environment is active in the terminal you used to run pip and python.
Quick tip
Use small connection tests as the first step in troubleshooting remote database access rather than inspecting large scripts.
