Module 5 › Chapter 5.1 › PostgreSQL vs MySQL Connectors
Key choices
psycopg2 / psycopg2-binary
psycopg2 is common for PostgreSQL. If pip install fails due to C compilation, use the psycopg2-binary wheel to avoid build steps.
mysql-connector-python
Official connector for MySQL, typically installs via pip without compilation in many environments.
PyMySQL
Pure Python MySQL client that can be easier to install on systems without compilation tools.
Installation considerations

If your environment lacks C compilers or development headers, pre-built wheels solve the problem. In some production setups you may prefer compiled packages tied to system libraries.

Concrete scenario
On Windows or macOS where build tools are not installed, try pip install psycopg2-binary to avoid compilation errors when connecting to PostgreSQL.
Mistake to avoid
Installing a connector globally by accident. Always activate your virtual environment first to keep installs local to your project.
Key Takeaway

Connector choice balances database compatibility and installation constraints; validate installs with a small import and connect test.
