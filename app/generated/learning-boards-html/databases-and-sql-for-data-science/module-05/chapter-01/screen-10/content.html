Read the error

Pip errors usually indicate either missing system libraries for compilation or missing pre-built wheels. Match the error to the remedy rather than guessing.

Missing C headers
Install system dev packages or use a binary wheel if available.
Wheel not available
Install required system tools or use an alternative pure-Python client if appropriate.
psycopg2-binary example

If installing psycopg2 fails, run pip install psycopg2-binary to get a pre-compiled wheel and avoid local compilation errors during setup.

Production note
Some teams prefer to build from source in production for compatibility with system libraries; choose based on policy and stability needs.
Key Takeaway

Match pip errors to remedies: binary wheels for quick setup, source builds when system alignment is required.
