Module 5 › Chapter 5.1 › pip & Virtual Environments
Step-by-step
1. Create env
Use python -m venv .venv to create an isolated environment for your project.
2. Activate
Activate the environment in your terminal so subsequent pip installs go into that environment.
3. Install
Run pip install psycopg2-binary or pip install mysql-connector-python as needed.
4. Verify
Open python and import the module to confirm it loads in this environment.
Warnings & tips
For reproducibility, export a requirements.txt after installing so teammates can recreate the same environment.
If pip install fails due to missing build tools, consider a binary wheel if available for that package.
Always import the package after installation to ensure it works in your active environment.
Key Takeaway

Virtual environments make installs predictable. Activate before installing and verify with a quick import test.
