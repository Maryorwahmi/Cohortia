Starter script
import sqlite3
import os

# Define the database file name
db_file = 'data_science_db.db'

# Check if the database file already exists
if os.path.exists(db_file):
    print(f"Database '{db_file}' already exists.")
else:
    print(f"Database '{db_file}' will be created.")

try:
    conn = sqlite3.connect(db_file)
    print(f"Successfully connected to {db_file}")

    cursor = conn.cursor()
    cursor.execute("SELECT sqlite_version();")
    version = cursor.fetchone()
    print(f"SQLite version: {version[0]}")

except sqlite3.Error as e:
    print(f"Error connecting to database: {e}")
finally:
    if 'conn' in locals() and conn:
        conn.close()
        print("Database connection closed.")
This script demonstrates connection, a simple verification query, error handling, and guaranteed closure in finally.
Explanation
  • os.path.exists lets you know whether the file is new or existing before connecting.
  • cursor.execute runs a small query to confirm the connection and driver are working.
  • finally ensures conn.close runs even on error, releasing file locks.
Try this
Change db_file to my_data_analysis.db and add a CREATE TABLE statement, then commit and close the connection to persist schema changes.
Key Takeaway

Use this script as your first diagnostic when setting up a database connection for any project.
