What a connector does

Connectors implement the client protocol for a database server. They establish a session, send SQL, receive results, and expose simple Python APIs for those operations.

  • sqlite3: built into Python, file-based, ideal for local development and quick tests.
  • psycopg2: common choice for PostgreSQL; often installed as a binary wheel to avoid compilation.
  • mysql-connector-python / PyMySQL: common options for MySQL servers with slightly different installation and APIs.
Example & contrast

If you need a local test database created when your script runs, sqlite3 is sufficient: it creates a new file if the file path doesn't exist. For production or multi-user access you'll choose a client-server database and the appropriate connector.

Concrete example
Calling pandas.read_sql_query relies on an underlying connector. Pandas itself does not open the TCP connection to the database; it delegates that work.
Common mistake
Assuming pandas replaces the connector. Pandas simplifies data IO but depends on connectors to execute SQL.
Key takeaway
Pick the connector that aligns with your database type and environment; test with a small query to confirm functionality.
