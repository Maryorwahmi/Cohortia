Module 5 › Chapter 5.2 › CREATE TABLE
Table definition
CREATE TABLE IF NOT EXISTS sensor_readings (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  device_id TEXT NOT NULL,
  timestamp TEXT NOT NULL,
  temperature REAL,
  humidity REAL
);
This schema captures device identity, a textual timestamp, and numeric readings for analysis.
When to use IF NOT EXISTS
During development and scripts that set up environments. It avoids aborting when the table already exists.
Misconception
Expecting strict type enforcement in SQLite. SQLite types are flexible; enforce constraints in the application if you need strict typing.
Takeaway
Make schema changes deliberately and prefer idempotent DDL in setup scripts to avoid developer friction.
