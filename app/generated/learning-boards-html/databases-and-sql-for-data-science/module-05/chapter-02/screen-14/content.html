Module 5 › Chapter 5.2 › Key Concepts
Connection
Manages the open database file and transaction boundaries.
Cursor
Executes SQL and provides fetch methods to read rows.
Commit & Close
Call commit after DML and close resources to persist changes and release locks.
Summary Takeaway

Follow the connection→cursor→execute→fetch→commit→close sequence every time. Use parameterized queries and executemany for safety and performance.
