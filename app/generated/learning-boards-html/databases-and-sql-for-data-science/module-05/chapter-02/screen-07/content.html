Insert example using executemany
insert_data_sql = """
INSERT INTO sensor_readings (device_id, timestamp, temperature, humidity)
VALUES (?, ?, ?, ?);
"""
readings = [
  ('sensor_001', '2023-10-26 10:00:00', 22.5, 60.1),
  ('sensor_002', '2023-10-26 10:05:00', 23.1, 59.5),
]
cursor.executemany(insert_data_sql, readings)
conn.commit()
executemany sends the same statement with each tuple of parameters, which is more efficient than many separate execute calls.
Why placeholders
Placeholders separate SQL structure from data, preventing injection and ensuring correct quoting.
Pitfall
Constructing SQL by concatenating strings with values can create security holes and bugs with quotes or types.
Tip
Check for existing rows when running setup scripts repeatedly to avoid duplicates.
