Module 5 › Chapter 5.2 › Open a Connection
Example: connect and confirm
import sqlite3

db_file = 'data_science_db.db'
conn = None
try:
  conn = sqlite3.connect(db_file)
  print(f"Connected to {db_file}")
except sqlite3.Error as e:
  print("Database error:", e)
finally:
  if conn:
    conn.close()
    print("Connection closed")
This pattern ensures the connection is closed even if an error occurs. Closing also releases file locks.
Why it matters
The connection holds uncommitted changes. If you interrupt a program without committing, those changes are lost or rolled back.
Common mistake
Assuming execute writes to disk immediately. Remember to call commit for DML operations.
Key takeaway
Always pair connect with try/finally or context management to close the connection and avoid leaks.
