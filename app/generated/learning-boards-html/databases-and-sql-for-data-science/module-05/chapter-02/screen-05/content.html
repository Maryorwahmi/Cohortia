Create a cursor and run DDL
# After connecting
cursor = conn.cursor()
create_table_sql = """
CREATE TABLE IF NOT EXISTS sensor_readings (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  device_id TEXT NOT NULL,
  timestamp TEXT NOT NULL,
  temperature REAL,
  humidity REAL
);
"""
cursor.execute(create_table_sql)
Use IF NOT EXISTS to make re-runs idempotent and avoid errors when the table already exists.
Tip
Reuse a cursor for multiple commands in a session, but consider new cursors for parallel operations in other threads.
Pitfall
Treating the cursor like a separate connection. Changes still require conn.commit because the transaction belongs to the connection.
Example result
After running CREATE TABLE, your script can safely insert rows without schema errors on re-runs.
