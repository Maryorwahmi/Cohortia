Module 5 › Chapter 5.2 › Fetch Methods
Examples
# fetchall
cursor.execute("SELECT * FROM sensor_readings;")
all_rows = cursor.fetchall()

# fetchone
cursor.execute("SELECT * FROM sensor_readings ORDER BY timestamp ASC LIMIT 1;")
first = cursor.fetchone()

# iterate
cursor.execute("SELECT id, temperature FROM sensor_readings;")
for row in cursor:
  print(row)
Choose the method that matches your data shape. Iteration avoids a large in-memory list.
Concrete example
Use fetchall during development for quick prints, then switch to iteration if data grows unexpectedly.
Misconception
Assuming fetchall is always fine. It can cause memory pressure on large tables.
Key takeaway
Match the fetch method to the expected result size to keep scripts scalable and predictable.
