Cleanup example
finally:
  if 'cursor' in locals() and cursor:
    cursor.close()
  if conn:
    conn.close()
This ensures resources are released even after exceptions. It is a reliable cleanup pattern for small scripts.
Practical reason
Closing prevents database locks that block other processes or tools like DB Browser for SQLite.
Misconception
Assuming the OS will close everything immediately when the script ends. It may, but relying on it yields flaky behavior.
