Common queries
# Temperatures > 23.0
cursor.execute("SELECT device_id, temperature FROM sensor_readings WHERE temperature > 23.0;")
results_q1 = cursor.fetchall()

# Humidity for sensor_002
cursor.execute("SELECT device_id, humidity FROM sensor_readings WHERE device_id = 'sensor_002';")
results_q2 = cursor.fetchall()

# Average temperature
cursor.execute("SELECT AVG(temperature) FROM sensor_readings;")
avg_temp = cursor.fetchone()[0]
Aggregate functions return a single row; index into the tuple to get the scalar value.
Concrete use
Use the average to report sensor health or compute baselines for anomaly detection.
Misconception
Expecting AVG to return None-safe numbers. NULLs can affect aggregates; watch for None when all inputs are NULL.
