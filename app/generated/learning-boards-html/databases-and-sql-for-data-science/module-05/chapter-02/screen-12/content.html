Module 5 › Chapter 5.2 › Parameterization
Safe pattern
sql = "INSERT INTO sensor_readings (device_id, timestamp, temperature, humidity) VALUES (?, ?, ?, ?);"
values = ('sensor_010', '2023-10-26 12:00:00', 21.8, 55.0)
cursor.execute(sql, values)
The driver substitutes values into placeholders safely. This removes manual escaping concerns.
Unsafe pattern
Building SQL by joining strings with values can break with quotes and open security holes. Avoid this pattern.
Tip
Use executemany when inserting many rows and parameterization for each tuple of values for both safety and speed.
