Transaction pattern
try:
  cursor.executemany(insert_sql, readings)
  conn.commit()
except sqlite3.Error as e:
  conn.rollback()
  print("Database error:", e)
finally:
  cursor.close()
  conn.close()
This pattern ensures either all rows are saved or none are, keeping your data consistent.
Concrete example
If one row insertion fails, rollback prevents partial data that could mislead analysis.
Misconception
Thinking program exit commits automatically. Always call commit explicitly for DML you intend to keep.
Pro tip
For many small scripts, commit after a logical set of operations rather than after every single statement to balance safety and performance.
