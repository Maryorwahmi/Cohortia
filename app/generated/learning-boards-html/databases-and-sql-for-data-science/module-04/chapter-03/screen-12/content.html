Q1 — Courses and enrollment counts
SELECT
  c.course_name,
  COUNT(e.enrollment_id) AS num_enrolled_students
FROM
  Courses AS c
LEFT JOIN
  Enrollments AS e ON c.course_id = e.course_id
GROUP BY
  c.course_name
ORDER BY
  c.course_name;
COUNT on the joined id returns zero for courses with no enrollments — a reliable way to show all courses with counts.
Q2 — Users who never logged in
SELECT
  u.username
FROM
  Users AS u
LEFT JOIN
  Logins AS l ON u.user_id = l.user_id
WHERE
  l.login_id IS NULL;
This preserves all users and selects those with no login entries, exposing inactive accounts for follow-up.
