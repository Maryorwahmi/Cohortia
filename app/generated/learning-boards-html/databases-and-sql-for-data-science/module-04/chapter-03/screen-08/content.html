Module 4 › Chapter 4.3 › Finding unmatched records
Pattern: customers with no orders
SELECT c.first_name, c.last_name
FROM Customers AS c
LEFT JOIN Orders AS o ON c.customer_id = o.customer_id
WHERE o.order_id IS NULL;
This returns only customers whose orders did not match — a direct way to find inactive users.
Pattern: products never ordered
SELECT p.product_name
FROM Products AS p
LEFT JOIN Order_Items AS oi ON p.product_id = oi.product_id
WHERE oi.order_item_id IS NULL;
The same LEFT JOIN + IS NULL pattern locates products that never appear in any order items.
Key Takeaway

Use OUTER JOINs intentionally with IS NULL filters to surface the exact missing relationships you need to act on.
