Module 4 › Chapter 4.3 › LEFT JOIN deep dive
LEFT JOIN example
SELECT
  c.first_name,
  c.last_name,
  o.order_id,
  o.order_date
FROM
  Customers AS c
LEFT JOIN
  Orders AS o ON c.customer_id = o.customer_id;
This returns all customers. For David Lee, who has no orders, order_id and order_date will be NULL. That NULL is the diagnostic you use to find inactive customers.
Find customers with no orders
SELECT c.first_name, c.last_name
FROM Customers AS c
LEFT JOIN Orders AS o ON c.customer_id = o.customer_id
WHERE o.order_id IS NULL;
Misstep to avoid
Filtering on o.order_date > '2023-01-01' without handling NULL will drop unmatched customers, effectively undoing the OUTER JOIN.
Annotated walkthrough
  1. FROM Customers AS c — the left table is the primary set you want to keep.
  2. LEFT JOIN Orders AS o ON c.customer_id = o.customer_id — matching rule for join.
  3. Result: matched pairs, plus rows where o.* is NULL when no order exists.
Key Takeaway

LEFT JOIN is your go-to when the left table is authoritative and you need to reveal non-participation via NULLs.
