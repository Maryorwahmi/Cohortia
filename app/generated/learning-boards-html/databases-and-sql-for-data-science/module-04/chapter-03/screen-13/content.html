Module 4 › Chapter 4.3 › When to swap
Decision rule

Ask which table must retain all rows. That side should be the preserved side in an OUTER JOIN.

Keep customers
FROM Customers LEFT JOIN Orders — use when customers are primary for analysis.
Keep orders
FROM Orders LEFT JOIN Customers — use when orders are primary or when auditing referential integrity.
Practical tip

Write the query in the form that best expresses the question you are asking. Readability helps avoid logical mistakes.
