Learning Objectives

Learn to use OUTER JOIN patterns to find unmatched records and ensure your datasets are complete for analysis.

Differentiate INNER and OUTER JOIN

Explain how INNER returns only matched rows while OUTER preserves non-matching rows as NULLs. This distinction decides which records survive a join.

Construct LEFT JOIN queries

Write SELECT statements using LEFT JOIN to retain all rows from your primary table and reveal NULLs for missing matches.

VERIFIED COMPETENCY MILESTONE
03
Construct RIGHT JOIN queries

Construct RIGHT JOIN statements to keep every row from the right table, useful when that table is your anchor or you audit orphaned rows.

VERIFIED COMPETENCY MILESTONE
04
Construct FULL JOIN queries

Use FULL JOIN to present all rows from both tables together, exposing overlaps and non-overlaps for reconciliation tasks.
