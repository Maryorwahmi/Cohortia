Module 4 › Chapter 4.3 › Performance & Safety
Index join keys
Make sure columns used in ON clauses are indexed to speed lookup. This reduces the cost of scanning both tables for matches.
Filter placement matters
Put constraints on the JOIN condition when you want them to affect matching; use WHERE IS NULL to intentionally select unmatched rows.
Counting matches
Use COUNT(joined.primary_key) after LEFT JOIN so unmatched rows count as zero rather than being excluded by INNER semantics.
FULL JOIN caution
FULL JOIN processes both tables entirely. On very large datasets, consider sampling or running two targeted joins if you only need one side at a time.
