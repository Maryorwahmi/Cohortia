Module 4 › Chapter 4.3 › Key Concepts
LEFT JOIN
Keeps all left-table rows; right-side columns are NULL when no match exists.
RIGHT JOIN
Keeps all right-table rows; left-side columns are NULL for unmatched rows.
FULL JOIN
Returns rows from both sides; use when you need a complete union and must inspect NULLs to reconcile differences.
Summary

OUTER JOINs are diagnostic tools that expose missing relationships as NULLs. Use them for completeness checks, reconciliation, and auditing data integrity.
