Module 4 › Chapter 4.3 › Hands-on queries
Task 1 — All customers and their order_id
SELECT c.first_name, c.last_name, o.order_id
FROM Customers AS c
LEFT JOIN Orders AS o ON c.customer_id = o.customer_id;
This lists every customer; order_id will be NULL for customers without orders, like David Lee.
Task 2 — All products and related orders
SELECT p.product_name, oi.order_id
FROM Products AS p
LEFT JOIN Order_Items AS oi ON p.product_id = oi.product_id;
Products without order items (like Monitor) will show NULL order references and can be flagged for inventory review.
Task 3 — Customers with no orders
SELECT c.first_name, c.last_name
FROM Customers AS c
LEFT JOIN Orders AS o ON c.customer_id = o.customer_id
WHERE o.order_id IS NULL;
This query intentionally filters for NULL to identify inactive customers for targeted outreach or cleaning.
