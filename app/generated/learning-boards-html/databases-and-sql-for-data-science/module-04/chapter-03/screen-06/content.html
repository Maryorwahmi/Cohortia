RIGHT JOIN example
SELECT
  c.first_name,
  c.last_name,
  o.order_id,
  o.order_date
FROM
  Customers AS c
RIGHT JOIN
  Orders AS o ON c.customer_id = o.customer_id;
If Orders contains an order with customer_id = 999 not in Customers, that order will appear and c.first_name will be NULL. This surfaces orphaned orders for investigation.
Equivalence
Orders LEFT JOIN Customers AS an equivalent alternative; choose the form that reads best for your analysis.
When to use RIGHT JOIN
  • When the right table is your authoritative set for the report or audit.
  • When you want to quickly spot rows in the right table without left-side details.
  • When you want to highlight orphaned rows that reference missing parents.
Key Takeaway

RIGHT JOIN keeps the right table intact and is useful for audits; swapping to LEFT JOIN is a valid alternative when preferred.
