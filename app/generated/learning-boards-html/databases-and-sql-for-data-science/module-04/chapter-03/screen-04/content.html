Module 4 › Chapter 4.3 › What are OUTER JOINs?
Definition

An OUTER JOIN returns all rows from one or both tables and fills missing matches with NULLs. It is used to reveal items without relationships across tables.

Key property
Unmatched side columns become NULL — this is intentional and informative.
Common use
Completeness checks and audits: find missing orders or orphaned rows.
Misconception
NULL is an informative signal, not an error to be immediately removed.
Key Takeaway

OUTER JOINs expose missing matches as NULLs, turning absence into analyzable data for diagnostics and reporting.

Concrete example
SELECT c.first_name, c.last_name, o.order_id, o.order_date
FROM Customers AS c
LEFT JOIN Orders AS o ON c.customer_id = o.customer_id;

In this query, customers without orders will still appear; order_id and order_date will be NULL. That NULL flags non-participation and supports follow-up analysis.
