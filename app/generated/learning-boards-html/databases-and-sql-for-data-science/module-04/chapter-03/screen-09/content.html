Module 4 › Chapter 4.3 › INNER vs OUTER
INNER JOIN (paired)
SELECT c.first_name, o.order_id
FROM Customers AS c
INNER JOIN Orders AS o ON c.customer_id = o.customer_id;
Only customers with orders appear. Use this when you only need matched data.
LEFT JOIN (inventory)
SELECT c.first_name, COUNT(o.order_id) AS num_orders
FROM Customers AS c
LEFT JOIN Orders AS o ON c.customer_id = o.customer_id
GROUP BY c.first_name;
All customers are kept; those with no orders will count as zero when you use COUNT on the joined key.
Misconception

Filtering on a joined table without IS NULL handling can unintentionally convert an OUTER JOIN into the effect of an INNER JOIN.
