Definition Second Normal Form (2NF)
Rule
The table must be in 1NF and all non-key attributes must depend on the whole primary key, not just part of it.
Violation example
Order_Items(order_id, product_id, product_name, quantity) — product_name depends only on product_id.
Normalized fix
Move product_name to Products(product_id PK, product_name). Order_Items keeps order_id, product_id, quantity.
Key Takeaway

When a column depends on only part of a composite key, move it to a table keyed by that part.
