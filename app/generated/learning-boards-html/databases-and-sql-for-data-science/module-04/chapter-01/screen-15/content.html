What to Remember Key Concepts — Part 2
Junction Table
A linking table with FKs to both entities to capture many-to-many pairings and attributes.
Normalization (1NF–3NF)
Organize tables to remove repeating groups, partial dependencies, and transitive dependencies.
Referential Integrity
Constraints that ensure foreign keys reference existing primary key values and avoid orphan rows.
Final takeaway

Design for correctness with keys and normalization. When performance needs arise, apply targeted denormalization with clear reasoning.
