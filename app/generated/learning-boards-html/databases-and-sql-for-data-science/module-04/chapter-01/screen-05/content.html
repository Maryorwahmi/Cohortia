Definition Primary Keys
Properties of a good PK
  • Uniqueness: one value per row.
  • Non-null: cannot be missing.
  • Stability: does not change over time.
  • Simplicity: favors single column when possible.
Practical choices
Surrogate integer keys are common. Natural keys work if they remain stable and unique.
Example
CREATE TABLE Students (
  student_id INT PRIMARY KEY,
  first_name VARCHAR(50) NOT NULL,
  last_name VARCHAR(50) NOT NULL,
  email VARCHAR(100) UNIQUE
);
Choose student_id as a stable identifier. Email is unique but may change, so it is not always a good PK.
