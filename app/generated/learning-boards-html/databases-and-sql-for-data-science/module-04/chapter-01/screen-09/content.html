Definition First Normal Form (1NF)
Rule
Each column must contain atomic values. No lists or repeating groups in a cell.
Example violation
A Customers table with phone_numbers column containing comma-separated numbers.
Normalized fix
Create PhoneNumbers(phone_id PK, customer_id FK, phone_number). Each row holds one number and links to Customers.
Key Takeaway

Atomic data makes constraints and joins straightforward. Prefer rows over lists for relational design.
