What to Remember Key Concepts — Part 1
Primary Key (PK)
A unique, non-null identifier for each row in a table.
Foreign Key (FK)
A column that references a primary key in another table to enforce valid links.
One-to-Many
One record in A relates to many in B; implemented by FK in the child table.
Summary

Use these terms to describe schema choices and to write constraints that enforce correct data relationships.
