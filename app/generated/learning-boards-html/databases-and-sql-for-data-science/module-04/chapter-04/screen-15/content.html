Module 5 › Chapter 4.4 › Key Concepts
Subquery
A nested query that produces a value, set, or temporary table used by the outer query.
Correlated vs Scalar
Scalar subqueries return one value per row; correlated subqueries reference the outer row and may execute per row, affecting performance.
CTE
WITH defines named temporary result sets; chain them to build readable, testable analytic pipelines.
Final summary

Use the right pattern for the right shape of intermediate data: scalar for single-value enrichment, derived table or CTE for grouped aggregates, and chained CTEs for sequential transforms. Check for correlated subqueries and favor CTEs for clarity when you refactor.
