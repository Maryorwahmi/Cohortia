Skills & Tasks

Each objective links to a hands-on task and a clear success criterion.

Task
Orders > Average
Use a subquery in WHERE to filter orders whose total exceeds the global average.
Task
Items per Customer
Create a CTE to sum item quantities per customer, then filter for customers over a threshold.
Task
Order item totals
Use a scalar subquery in SELECT to return the total quantity for each order row.
Assessment Tip

Correct answers should show proper aggregation, HAVING filters when needed, and clear naming when CTEs are used. Replace correlated subqueries with grouped CTEs when per-row execution is inefficient.
