From anonymous subquery to named CTE

Naming the intermediate result clarifies its purpose and makes adding debug columns easy.

-- Using CTE to find the average total amount of orders for multi-order customers
WITH CustomerOrderSummary AS (
  SELECT
    o.customer_id,
    SUM(o.total_amount) AS customer_total_amount,
    COUNT(o.order_id) AS num_orders
  FROM
    Orders AS o
  GROUP BY
    o.customer_id
  HAVING
    COUNT(o.order_id) > 1
)
SELECT
  AVG(customer_total_amount) AS average_total_for_multi_order_customers
FROM
  CustomerOrderSummary;
Practical advice
  • Name CTEs descriptively to communicate the computation.
  • Add aggregate columns like MIN and MAX inside the CTE to help verify results.
  • If you need reuse across statements, persist results instead of relying on CTE scope.
Key Takeaway

Refactor derived tables into CTEs when you want clearer names and stepwise debugging; results remain the same.
