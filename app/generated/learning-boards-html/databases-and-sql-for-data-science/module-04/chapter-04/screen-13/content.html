Assessment: Products ordered > 5 times

Use a CTE to calculate total quantity sold per product, filter, then join to Products to return names. The chapter provides the correct answer below.

WITH ProductSales AS (
  SELECT
    product_id,
    SUM(quantity) AS total_quantity_sold
  FROM
    Order_Items
  GROUP BY
    product_id
  HAVING
    SUM(quantity) > 5
)
SELECT
  p.product_name
FROM
  Products AS p
INNER JOIN
  ProductSales AS ps ON p.product_id = ps.product_id;
Instructor note: look for correct use of GROUP BY and HAVING. If a student used WHERE SUM(quantity) > 5, remind them that WHERE cannot filter on aggregates.
Key Takeaway

CTEs make aggregation-first patterns readable and make it easy to validate intermediate totals before final joins.
