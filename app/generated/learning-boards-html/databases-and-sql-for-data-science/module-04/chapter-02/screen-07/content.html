Module 4 › Chapter 2 › Chaining INNER JOINs
Process Flow

Join sequence: Customers → Orders → Order_Items → Products

Each step expands fields and filters rows so only fully-matched records remain in the final result.

Step 1
Customers INNER JOIN Orders ON customer_id yields orders with known customers.
Step 2
Add Order_Items ON order_id to include only orders that contain items.
Step 3
Add Products ON product_id to attach product details for each ordered item.
Example final query
SELECT
  c.first_name,
  c.last_name,
  o.order_date,
  p.product_name,
  oi.quantity
FROM
  Customers AS c
INNER JOIN Orders AS o ON c.customer_id = o.customer_id
INNER JOIN Order_Items AS oi ON o.order_id = oi.order_id
INNER JOIN Products AS p ON oi.product_id = p.product_id;
Why it matters

Chaining allows you to reconstruct complex relationships and build an analysis-ready view that includes only fully-matching, meaningful rows.
