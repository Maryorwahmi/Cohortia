Example INNER JOIN

This query joins order items to products and uses aliases for clarity.

SELECT
  oi.order_item_id,
  oi.order_id,
  p.product_name,
  oi.quantity,
  p.price
FROM
  Order_Items AS oi
INNER JOIN
  Products AS p
ON
  oi.product_id = p.product_id;
• Aliases: oi and p shorten references and make the SELECT list readable.
• ON condition: oi.product_id = p.product_id matches order items to product definitions.
• Result: only order items that reference an existing product appear in the output.
Pro tip

Always qualify columns when names repeat and write ON conditions that clearly reference the intended keys.

Why ON is essential
If ON is omitted, you risk a Cartesian product that multiplies rows and hides the true relationships. Verifying the ON clause prevents data quality errors and keeps result sets meaningful for analysis.
Quick check
Confirm that the columns on both sides of the equals operator represent the same conceptual key (e.g., FK to PK).
Common mistake
Joining on unrelated columns will produce nonsense or empty results; double-check relationships before running expensive queries.
