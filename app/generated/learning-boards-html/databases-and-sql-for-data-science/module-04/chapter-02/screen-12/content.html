Starter queries
Use these INNER JOIN patterns to answer the activity tasks from the chapter.
-- Task 1: orders with customer names
SELECT
  o.order_id,
  o.order_date,
  c.first_name,
  c.last_name
FROM Orders AS o
INNER JOIN Customers AS c ON o.customer_id = c.customer_id;

-- Task 2: products that have been ordered
SELECT
  p.product_name,
  oi.quantity,
  oi.order_id
FROM Order_Items AS oi
INNER JOIN Products AS p ON oi.product_id = p.product_id;

-- Task 3: customers, orders, and products for each item
SELECT
  c.first_name,
  c.last_name,
  o.order_id,
  p.product_name
FROM Customers AS c
INNER JOIN Orders AS o ON c.customer_id = o.customer_id
INNER JOIN Order_Items AS oi ON o.order_id = oi.order_id
INNER JOIN Products AS p ON oi.product_id = p.product_id;
How to validate results
  • Confirm row counts align with expectations from the sample tables.
  • Inspect a few rows to ensure names and product matches are correct.
  • If rows are missing, check the ON clauses; if too many rows, check for omitted ON or extra joins.
Example quick check
