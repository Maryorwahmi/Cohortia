Query example
SELECT
  oi.order_item_id,
  oi.order_id,
  p.product_name,
  oi.quantity,
  p.price
FROM
  Order_Items AS oi
INNER JOIN
  Products AS p ON oi.product_id = p.product_id;
What to expect
  • Rows for order items that reference existing products (e.g., order 101 includes Laptop and Mouse entries).
  • Each row shows the product_name and quantity, enabling item-level revenue calculation.
  • Unmatched order items (if any) would be excluded by this INNER JOIN.
Example result snippet

order_item_id 2 — order 101 — Mouse — qty 2
