Module 4 › Chapter 2 › Common Mistakes
Wrong pattern
Omitted ON clause
FROM Customers AS c INNER JOIN Orders AS o — without ON, this can act like a CROSS JOIN and combine every customer with every order.
Ambiguous column
Selecting id when multiple tables define id will create ambiguity. Qualify columns: c.id or o.id.
Correct pattern
Include ON and qualify
FROM Customers AS c INNER JOIN Orders AS o ON c.customer_id = o.customer_id — qualifies columns and prevents Cartesian products.
Debugging steps
  • Run the first join alone and inspect rows.
  • Confirm the ON clause matches FK to PK.
  • Then add the next join and repeat.
