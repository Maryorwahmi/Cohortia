Learning Objectives

Bloom progression: Learn → Understand → Apply → Master

Learn → Understand → Apply → Master
01
Explain INNER JOIN

Describe how INNER JOIN returns only matching rows and why that intersection is useful for analysis. This helps you choose the right join type.

VERIFIED COMPETENCY MILESTONE
02
Construct SELECT with INNER JOIN

Write queries that join two or more tables to collect fields needed for reports or modeling. Practice with Customers, Orders, and Products examples.

VERIFIED COMPETENCY MILESTONE
03
Identify common use cases

Recognize scenarios like joining Orders to Customers to produce customer-facing order reports and sales analysis per product.

VERIFIED COMPETENCY MILESTONE
04
Correct ON clauses & avoid pitfalls

Specify join conditions accurately and qualify ambiguous column names to avoid errors and unexpected results like Cartesian products.

VERIFIED COMPETENCY MILESTONE
