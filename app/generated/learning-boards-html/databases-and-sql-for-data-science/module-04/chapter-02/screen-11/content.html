Module 4 › Chapter 2 › Composite Key Joins
Definition

Joining on multiple columns

When a relationship requires two or more columns to match, include all of them in the ON clause joined with AND.

-- Composite key join example
SELECT *
FROM table1 AS t1
INNER JOIN table2 AS t2
ON t1.col1 = t2.col1
AND t1.col2 = t2.col2;
Why use composite joins?
They enforce a multi-attribute relationship so only precisely matching rows are combined.
Indexing note
If joins use composite keys frequently, consider composite indexes on those columns to keep performance acceptable.
Key Takeaway

Use multiple equality checks in the ON clause when the relationship requires more than one column to uniquely match rows.
