Learning Objectives

Master core indexing concepts, mechanics, types, and SQL operations so you can optimize queries responsibly.

01
Explain what an index is

Define a database index and the book-index analogy. Knowing this helps you reason about when a query will benefit from an index.

Mnemonic: book index ↔ lookup table
VERIFIED COMPETENCY MILESTONE
02
Describe B-tree internals

Explain how a balanced tree stores sorted keys and pointers so searches, inserts, and deletes are logarithmic in cost.

Mnemonic: balanced tree = log-time operations
VERIFIED COMPETENCY MILESTONE
03
Differentiate index types

Distinguish primary, unique, non-unique, composite, partial, and expression indexes and match them to query patterns.

Mnemonic: primary/unique enforce identity; composite matches multi-column filters
VERIFIED COMPETENCY MILESTONE
04
Create, drop, and verify

Write SQL to create and drop indexes and use EXPLAIN ANALYZE to confirm the planner uses the index.

Mnemonic: create → measure → drop if not used
VERIFIED COMPETENCY MILESTONE
