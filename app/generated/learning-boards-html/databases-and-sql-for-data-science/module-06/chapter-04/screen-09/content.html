Definition

Partial and Expression Indexes

Partial: index a subset of rows using a WHERE clause. Expression: index the result of a function or expression rather than the raw column.
Partial index example: CREATE INDEX idx_users_active_email ON users (email) WHERE status = 'active';
Expression index example: CREATE INDEX idx_lower_email ON users (LOWER(email)); useful when queries use LOWER(email).
Misconception

Partial and expression indexes only help if your queries use the same predicate or expression; otherwise the planner won't match them.

Practical scenarios
Use partial indexes when a small, frequently queried subset exists (active users, flagged items). Use expression indexes when queries filter or sort on a computed value, like a normalized case or extracted date part.
Key Takeaway
Partial and expression indexes let you focus index resources where queries actually run, saving space and maintenance cost.
Common pitfall
Failing to match the exact predicate or function call in queries prevents the planner from using the index.
