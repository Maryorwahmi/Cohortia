Key Concepts

Index
A lookup structure mapping values to rows to speed data retrieval.
B-tree
Balanced multi-way tree used by most indexes for efficient search and range scans.
Full Table Scan
Reading all rows sequentially; efficient for queries that return most of the table, otherwise costly.
Takeaway

Index selectively and verify with EXPLAIN ANALYZE; balance improved reads against write and storage costs.
