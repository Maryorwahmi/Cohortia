Module 6 › Chapter 6.5 › Why routine maintenance matters
Definition & consequences
  • Dead tuples and fragmentation increase the data volume the server scans.
  • Stale planner statistics cause suboptimal execution plans.
  • Log files and unreclaimed space can exhaust disk if unrotated.
Analogy
Think of a database like a workshop bench. Leaving scraps and tools scattered makes tasks slower and more error prone. Regular cleaning keeps the bench efficient.
Practical signs of neglect
Slow sequential scans
Rapid growth in pg_relation_size
Rising disk I/O wait times
Large, unrotated log files
Key Takeaway

Plan lightweight, frequent maintenance to keep performance predictable and reduce the need for disruptive, locking operations.
