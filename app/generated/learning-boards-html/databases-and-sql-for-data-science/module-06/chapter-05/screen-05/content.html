Module 6 › Chapter 6.5 › Dead Tuples & Bloat
What is a dead tuple?

A dead tuple is a previously valid row version no longer visible to any transaction. It remains in the data file until reclaimed.

  • Accumulation causes table and index bloat.
  • Increased physical size leads to higher I/O and slower scans.
  • Reclaiming space can be internal or returned to the OS depending on the command.
Common misconception
Basic VACUUM reclaims space for reuse inside the database but does not always shrink the file seen by the operating system. VACUUM FULL does, but it locks the table.
Example scenario
A log_events table receives 100,000 inserts then half are deleted. pg_relation_size reports a large file despite fewer rows. This is classic bloat that VACUUM addresses.
Check: SELECT pg_size_pretty(pg_relation_size('log_events'));
Key Takeaway

Watch table size and scan times. Bloat is a performance and storage risk; reclaim proactively.
