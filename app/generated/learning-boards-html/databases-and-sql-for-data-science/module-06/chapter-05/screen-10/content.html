Module 6 › Chapter 6.5 › Connectivity Diagnostics
Terminal checks

Use these commands to verify basic connectivity and listening ports

# check host reachability
ping -c 3 database_host

# check port (example for PostgreSQL default 5432)
telnet database_host 5432

# verify process on host (server-side)
sudo systemctl status postgresql
Python connection example (visual)
import psycopg2
try:
  conn = psycopg2.connect("dbname=prod user=data_user host=db.example.com port=5432 password=secret")
except psycopg2.OperationalError as e:
  print(f"Connection error: {e}")
Misconception

Assuming an application bug is the problem wastes time. Verify network and service first; often the fix is configuration or a firewall rule.

Checklist
  • Ping host; confirm packet reachability.
  • Telnet or equivalent to test TCP port.
  • Confirm service is running and listening on expected address.
  • Verify credentials and client IP authorization.
  • Check firewall rules and network ACLs.
Quick Tip

If the server is listening only on localhost, set listen_addresses and restart the service during a maintenance window.
