Command-line practice

Follow small reproducible steps: create a sample database, run a logical backup, simulate data loss, restore to a new database, and verify rows. Repeat on both PostgreSQL and MySQL if available.

Mnemonic
Create backup → Store safely → Test restore → Document RPO/RTO
VERIFIED COMPETENCY MILESTONE
Why test restores
  • Backups can be corrupted or incomplete; only a restore proves usability.
  • Testing reveals missing privileges, version mismatches, or schema drift before a real incident.
  • Documenting a successful restore shortens recovery time during an outage.
