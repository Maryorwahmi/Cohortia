Module 6 › Chapter 6.1 › Choosing between backup types
Decision factors
  • RPO — how much data loss is acceptable?
  • RTO — how quickly must services be restored?
  • Storage and bandwidth available for backups.
  • Operational complexity of restores.
Example choice
Large DB: weekly full + daily incremental for minimal daily overhead. Medium DB: weekly full + daily differential for faster restores.
Checklist for selection
  1. Define RPO and RTO with stakeholders.
  2. Estimate backup size and time for each option.
  3. Test restores and measure actual recovery time.
  4. Document the final cadence and automate it.
Key Takeaway

Choose the backup type and schedule by measuring acceptable loss and acceptable downtime, then validate with test restores.
