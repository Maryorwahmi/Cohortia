Module 6 › Chapter 6.2 › Parameterized Queries with psycopg2
Correct pattern using driver parameter binding
import psycopg2

conn = psycopg2.connect("dbname=datascidb user=your_username password=your_password")
cur = conn.cursor()

user_input_username = "admin' OR '1'='1"  # malicious input
user_input_password = "any_password"

# Correct way: use a parameterized query with placeholders handled by the driver
cur.execute("SELECT * FROM users WHERE username = %s AND password = %s;",
            (user_input_username, user_input_password))

results = cur.fetchall()
print(results)

cur.close()
conn.close()
Because values are passed separately, the driver treats the malicious sequence as a literal username value and the query structure is preserved. This is the recommended fix for injection vulnerabilities.
