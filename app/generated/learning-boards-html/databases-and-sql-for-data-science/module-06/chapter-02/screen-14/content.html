Module 6 › Chapter 6.2 › Key Concepts
Authentication
Verifying who is connecting to the database.
Authorization
Determines what authenticated users are allowed to do.
Least Privilege
Grant only the permissions needed to do the job.
SQL Injection
When input is interpreted as SQL and changes query behavior.
Parameterized Queries
Driver-supported placeholders that keep data and code separate.
Encryption & Auditing
Protect stored and transmitted data and log activity for accountability.
Summary
Apply these controls together: authenticate identities, authorize minimally, prevent injection, encrypt sensitive data, and audit activity to maintain trust and compliance.
