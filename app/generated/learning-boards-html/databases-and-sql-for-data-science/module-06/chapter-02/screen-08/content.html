Vulnerable query construction (example shown for teaching)
# Vulnerable pattern: concatenating user input into SQL
user_input = "admin' OR '1'='1"
query = f"SELECT * FROM users WHERE username = '{user_input}' AND password = '{user_password}';"
# If user_input contains SQL syntax, it can change the WHERE clause and bypass checks.
This example demonstrates how an attacker can inject SQL fragments into a query string. Do not use this pattern in production code. Instead, use parameterized queries provided by your database driver to separate data from code.
