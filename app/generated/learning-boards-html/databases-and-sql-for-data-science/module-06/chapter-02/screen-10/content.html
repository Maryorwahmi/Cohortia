Module 6 › Chapter 6.2 › Encryption: At Rest and In Transit
What encryption protects
At rest: protects stored files, database files, and backups. In transit: protects data moving between clients and servers via TLS.
When to use
Use for PII, financial, and regulated datasets and for backups stored offsite or on shared infrastructure.
Misconception
Encryption is not a substitute for access control. It complements authentication and authorization by reducing exposure if storage is compromised.
Practical checklist
  • Enable TLS for client connections to the database.
  • Use database or disk encryption for stored data and backups.
  • Manage encryption keys securely and rotate keys per policy.
Key Takeaway

Encryption protects data from physical and network exposure, but must be combined with access controls and auditing.
