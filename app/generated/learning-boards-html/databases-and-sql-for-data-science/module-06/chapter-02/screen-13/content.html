Module 6 › Chapter 6.2 › Common Mistakes and Best Practices
Avoid these mistakes
  • Granting ALL PRIVILEGES for convenience.
  • Concatenating user input into SQL strings.
  • Neglecting periodic permission reviews.
  • Storing sensitive data unencrypted and not using TLS.
  • Failing to enable audit logs for critical tables.
Adopt these practices
  • Use roles with minimal permissions and avoid granting directly to users.
  • Replace concatenation with parameterized queries provided by your driver.
  • Schedule regular reviews to remove unused grants and roles.
  • Enable encryption at rest and TLS for client connections.
  • Enable auditing and protect logs as part of your security posture.
Quick action: run a permissions inventory this week and identify any accounts with write access that should be read-only.
