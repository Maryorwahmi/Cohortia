Learning Objectives
Four measurable competencies and why they matter for data workflows.
01
Identify key metrics for database health
Learn which metrics to watch and why CPU, I/O, memory, network, connections, and latency each matter to performance.
Venn mnemonic: Metrics → Symptoms → Action
VERIFIED COMPETENCY MILESTONE
02
Use built-in tools and SQL to inspect activity
Query views like pg_stat_activity or process lists to find active and long-running sessions that need attention.
Timeline mnemonic: Observe → Isolate → Diagnose
VERIFIED COMPETENCY MILESTONE
03
Interpret EXPLAIN ANALYZE for query plans
Read the plan tree, spot Seq Scan, Index Scan, joins and sorts, and use Actual Time and Cost to find hotspots.
Visual mnemonic: Plan tree → hotspots highlighted
VERIFIED COMPETENCY MILESTONE
04
Establish and use performance baselines
Collect normal operating metrics so spikes and trends become visible and actionable over time.
Chart mnemonic: Baseline → Threshold → Alert
VERIFIED COMPETENCY MILESTONE
