Common bottlenecks
Symptoms and what they typically indicate.
CPU
Sustained high CPU suggests heavy query processing like expensive joins or sorts.
I/O
High disk reads often indicate full table scans or large sequential reads.
Memory
Swapping or buffer eviction increases I/O and latency.
Network & connections
Network latency is important for remote clients and large result sets. Many connections can cause resource contention; use pooling or connection limits when necessary.
Diagnostic pattern
  1. Detect the dominant signal (CPU, I/O, memory, or network).
  2. List active sessions to find the queries causing the signal.
  3. Run EXPLAIN ANALYZE in staging on suspect queries to find costly nodes.
  4. Apply targeted fixes: index, rewrite, or schedule changes.
Practical example
High read rates during a data load likely point to inefficient queries or missing indexes used by that load process.
Key Takeaway

Map symptoms to probable bottlenecks, then confirm with session and plan diagnostics before changing infrastructure.
