Definition
EXPLAIN vs EXPLAIN ANALYZE
Planner estimates versus observed execution times — both are useful.
When to use each
  • EXPLAIN: safe preview of the plan without execution.
  • EXPLAIN ANALYZE: runs the query and reports actual time and rows for each node.
Misconception
Planner estimates are always accurate — they are not. Costs are heuristics that can differ from actual performance when data distribution changes.
Example EXPLAIN ANALYZE output cues
  • Seq Scan on a large table: indicates a full table scan and a candidate for an index.
  • Actual Time and Cost: high actual times point to slow nodes to target for optimization.
  • Rows Removed by Filter: many removed rows suggest inefficient filtering with too much row scanning.
Safety note

EXPLAIN ANALYZE executes the query; prefer staging or smaller datasets for heavy statements to avoid production impact.
