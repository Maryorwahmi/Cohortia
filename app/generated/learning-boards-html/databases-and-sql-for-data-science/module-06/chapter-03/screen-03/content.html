How you'll apply each objective
Concrete diagnostic actions and safeguards to practice in staging before production.
Metric Snapshot
Create a short checklist to capture CPU, I/O, memory, network, active connections, and query latency at regular intervals to form a baseline.
Tip: capture during peak and idle times
VERIFIED COMPETENCY MILESTONE
Inspect Active Sessions
Run a pg_stat_activity query to list active queries, duration, and client addresses to isolate problematic sessions.
Safety: avoid heavy diagnostics on production
VERIFIED COMPETENCY MILESTONE
Analyze Execution Plans
Run EXPLAIN ANALYZE on representative slow queries in staging to read actual times and decide index or rewrite changes.
Misconception: higher CPU alone isn't always the root cause
VERIFIED COMPETENCY MILESTONE
Maintain Baselines
Store summary metrics and compare current values to detect anomalies, then investigate deviations with session and plan tools.
Tip: keep weekly and monthly aggregates
