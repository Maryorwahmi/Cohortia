Key metrics to monitor
Capture these metrics regularly to detect and correlate performance issues.
CPU
Shows processor load; watch for sustained high values during queries.
I/O
Reads/writes to disk; high reads often signal table scans.
Memory
Insufficient memory forces swapping and increases latency.
Network
Important for remote clients and large result sets.
Connections
High counts can exhaust server resources and increase contention.
Query latency
The user-facing measure; use with other metrics to find root cause.
Quick diagnosis guide
Match patterns to likely causes:
  • High CPU, high sort activity: expensive query operations or missing indexes for order by.
  • High reads, low CPU: likely sequential scans reading lots of rows from disk.
  • Memory pressure: swapping will increase I/O and latency.
  • High network latency: slow client transfers for large result sets.
Key Takeaway

Correlate multiple metrics before concluding a root cause; patterns are more meaningful than single metrics.
