EXPLAIN ANALYZE example
Inspect actual times and row statistics to find hotspots.
EXPLAIN ANALYZE
SELECT *
FROM transactions
WHERE account_id = 500
AND transaction_date BETWEEN '2023-01-01' AND '2023-01-31'
ORDER BY amount DESC;
When you run this, examine nodes for 'Seq Scan' vs 'Index Scan', compare Cost versus Actual Time, and look at 'Rows Removed by Filter' to see wasted reads.
Step-by-step reading
  1. Find the node with the largest Actual Time — this is your bottleneck.
  2. If Seq Scan appears on a large table, check Rows Removed by Filter for wasted reads.
  3. Check Sort nodes; if costly, consider indexes that satisfy ORDER BY.
Example insight
If you see Seq Scan + high rows removed, adding an index on account_id and transaction_date often reduces I/O and shifts the plan to an Index Scan.
Key Takeaway

Read EXPLAIN ANALYZE to find the node doing most of the work and focus optimization there, using indexes or query changes as appropriate.
