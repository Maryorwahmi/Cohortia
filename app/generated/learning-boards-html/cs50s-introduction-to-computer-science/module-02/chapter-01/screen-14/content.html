Module 2 › Chapter 2.1 › Key Concepts
Pointer
Variable that stores a memory address and allows indirect access to a value.
Arrays & pointer arithmetic
Array names can decay to pointers; pointer increments move by the size of the element type.
Heap management
Use malloc/calloc/realloc to allocate and free to release memory; forgetful code causes leaks and instability.
Final takeaway

Treat pointers as powerful tools that require explicit safety checks: initialize, validate, and free. These habits make your C programs robust.
