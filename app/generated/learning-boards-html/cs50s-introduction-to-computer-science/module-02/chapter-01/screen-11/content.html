Typical memory regions
Code (text) | Global data | Heap (dynamic) | Stack (locals)
Contiguous storage
Array elements occupy adjacent addresses. Pointer increments move you from one element to the next.
Alignment
Types often require alignment; pointer arithmetic abstracts away byte offsets by using element counts.
