VERIFIED COMPETENCY MILESTONE
Mnemonic: Mailboxes
Picture memory as numbered mailboxes. A pointer stores the mailbox number; dereferencing opens the mailbox to read or write the contents.
Practice tip
When you allocate memory, immediately check for NULL and plan where free will occur. Habitually set freed pointers to NULL.
