Index-based iteration
for (int i = 0; i < 5; i++)
{
  printf("%d
", arr[i]);
}
Pointer-based iteration
int *p = arr;           // points to arr[0]
for (; p < arr + 5; p++)
{
  printf("%d
", *p);
}
Explanation
  • arr decays to &arr[0] in many expressions, giving a pointer to its first element.
  • Pointer arithmetic steps by the size of the pointed type, enabling element-wise traversal.
  • arr + 5 yields a pointer one past the last element; do not dereference it.
Common mistake
Treating pointer arithmetic as byte arithmetic causes incorrect indexing when types differ. Always reason in elements, not bytes.
