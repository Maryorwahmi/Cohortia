Pointer definition
A variable whose value is an address in memory.
Example: Declare an integer and a pointer, then make the pointer refer to the integer and change it through the pointer. This shows how address and value are distinct.
Concrete code
int x = 10;
int *ptr = &x;
printf("%d
", *ptr);  // prints 10
*ptr = 25;              // changes x to 25
Common misconception
Pointers do not contain values, they contain addresses. Treat them like mailbox numbers — you must open the mailbox to access the value inside.
Visual: Mailbox analogy
A pointer stores a mailbox number. Dereferencing opens that mailbox to read or write contents. Only dereference when you know the mailbox is valid.

Key Takeaway

Pointers let you refer to and modify memory indirectly. Initialize before dereferencing and prefer NULL when you lack a valid address.
