Module 2 › Chapter 2.1 › malloc, calloc & realloc
Step 1: Request memory
Use malloc(bytes) or calloc(count, size). For example: int *arr = (int *) malloc(n * sizeof(int));
Step 2: Check the result
If the pointer is NULL, handle the error. Never assume allocation succeeded.
Step 3: Use & resize
Populate memory and use realloc when you need a new size. Use a temporary pointer with realloc to avoid losing the original on failure.
Concrete code pattern
int *a = (int *) malloc(n * sizeof(int));
if (a == NULL) { /* handle error */ }

// later
int *tmp = (int *) realloc(a, new_n * sizeof(int));
if (tmp == NULL) { /* handle error, a still valid */ }
else { a = tmp; }
Common mistake
Assigning realloc result directly to the original pointer without checking can lose the only reference to allocated memory on failure, causing a leak.
