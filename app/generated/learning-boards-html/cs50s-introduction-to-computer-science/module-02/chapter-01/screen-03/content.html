Verified Competencies
Clear, testable tasks to build confidence
Initialize pointers
Practice setting pointers to NULL or valid addresses before use.
Check allocations
Always verify malloc or calloc returned a non-NULL pointer before using it.
Match allocate/free
Design where free should run so your code does not leak memory.
Nullify after free
Set pointers to NULL after freeing to avoid accidental dereference.
Mnemonic
Think: Allocate, Use, Free, Nullify. Repeat this checklist whenever you work with the heap.
