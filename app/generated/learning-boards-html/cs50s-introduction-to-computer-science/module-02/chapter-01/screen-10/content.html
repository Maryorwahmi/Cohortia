Module 2 › Chapter 2.1 › NULL, Dangling & UB
NULL pointer

A pointer explicitly set to indicate it points nowhere. Check against NULL before dereferencing to avoid crashes.

Dangling pointer

When memory is freed but a pointer still holds the old address. Dereferencing it is undefined. After free, set pointer to NULL.

Undefined behavior

Actions not defined by the C standard, like dereferencing uninitialized pointers or writing out of bounds. Results are unpredictable and often catastrophic.

Key Takeaway

Check pointer validity, free paired allocations, and set pointers to NULL after free to reduce risk of undefined behavior.
