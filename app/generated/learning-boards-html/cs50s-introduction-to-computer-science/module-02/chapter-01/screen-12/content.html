Practical checklist
  • Initialize pointers to NULL.
  • Check allocation returns before use.
  • Pair each allocate with a free in all paths.
  • Set pointer to NULL after free.
  • Use a temporary variable with realloc.
Tools & methods
When available, run memory-checking tools that report leaks and invalid accesses. Otherwise instrument allocation functions with counters and logs to find mismatches.
Key Takeaway

Discipline and small runtime checks catch most pointer and leak errors. Adopt a checklist and use tooling when possible.
