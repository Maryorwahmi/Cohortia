Module 2 › Chapter 2.1 › Stack vs Heap
Stack (automatic)
  • Holds local variables and call frames.
  • Allocated and freed automatically on function calls/returns.
  • Fast but limited in size.
Heap (dynamic)
  • Manually allocated with malloc, calloc, or realloc.
  • Exists until you call free on the memory.
  • Flexible size but requires explicit management.
Concrete contrast
// Stack allocation
void f(void)
{
  int local[10]; // lifetime ends when f returns
}

// Heap allocation
int *a = malloc(10 * sizeof(int)); // lifetime until free(a)
Danger
Never return a pointer to a local stack array. That pointer becomes dangling and dereferencing it is undefined behavior.
