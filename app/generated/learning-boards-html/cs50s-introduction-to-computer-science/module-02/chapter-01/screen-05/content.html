Module 2 › Chapter 2.1 › Declaring & Dereferencing
Annotated code
#include <stdio.h>

int main(void)
{
  int x = 10;           // a value stored in memory
  int *p = &x;       // p is initialized to x's address

  printf("%d
", *p); // dereference to read: prints 10

  *p = 25;             // write through the pointer: changes x
  printf("%d
", x); // prints 25

  int *q;              // uninitialized pointer (danger)
  // if we do: printf("%d
", *q); // undefined behavior

  return 0;
}
Safety check
Always initialize pointers. When using pointers obtained from functions, validate before dereferencing and prefer explicit checks against NULL.
Common mistake
Declaring a pointer without initialization leads to a garbage address. Dereferencing then usually causes a segmentation fault.
Concrete example explained
We declare x, capture &x into p, and then *p reads and writes x. Leaving q uninitialized illustrates the undefined behavior risk.
Key Takeaway

Initialize pointers and check for NULL. Treat uninitialized pointers as immediate red flags during code review.
