Starter code (complete)
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
  int num_grades;
  float *grades;
  float sum = 0.0f;

  printf("How many grades do you want to enter? ");
  scanf("%d", &num_grades);

  if (num_grades <= 0) { printf("Number of grades must be positive.
"); return 1; }

  grades = (float *) malloc(num_grades * sizeof(float));
  if (grades == NULL) { printf("Memory allocation failed!
"); return 1; }

  for (int i = 0; i < num_grades; i++)
  {
    printf("Enter grade %d: ", i + 1);
    scanf("%f", &grades[i]);
    sum += grades[i];
  }

  printf("Average grade: %.2f
", sum / num_grades);

  free(grades);
  grades = NULL;

  return 0;
}
Explanation
We validate input, allocate appropriate heap storage, check malloc's result, populate entries by indexing, compute the average, and free the block before exiting. Setting the pointer to NULL prevents accidental use afterward.
Misconception
A program that exits may release OS memory, but relying on process exit removes the discipline of pairing allocate and free in long-running programs.
Key Takeaway

This small program shows the full lifecycle: allocate, use, free, nullify. Always check returns and plan where free will execute.
