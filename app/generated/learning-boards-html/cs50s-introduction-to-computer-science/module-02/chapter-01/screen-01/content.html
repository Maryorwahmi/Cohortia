Pointers and Memory Management in C
Control where data lives, manipulate it indirectly, and manage heap memory safely.
Orientation

You will learn how variables map to memory addresses, how pointers store addresses, how pointer arithmetic works with types, and how to use malloc, calloc, realloc, and free to manage the heap.

Why it matters

Manual memory control enables efficient data structures and systems programming. It also requires discipline to avoid crashes and leaks.

Pointer Example

int *p = &x;

Tip: Treat the array name as a pointer to its first mailbox. Pointer arithmetic adds whole-object steps, not bytes.
