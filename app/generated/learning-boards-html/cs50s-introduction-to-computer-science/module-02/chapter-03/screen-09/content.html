Successful completion

Loop on read return values. After the loop, use feof and ferror to check why it ended, then fclose the file.

• Use read return values to control loops rather than feof alone.
• After the loop, if feof is true then you reached end-of-file normally.
• If ferror is true, an I/O error occurred and should be reported.

Example pattern

int c;
while ((c = fgetc(file)) != EOF) {
  // process c
}
if (feof(file)) {
  // normal EOF
} else if (ferror(file)) {
  // handle error
}
fclose(file);
Key Takeaway

fclose matters for correctness. Use read-return-values then feof/ferror to determine success or failure.
