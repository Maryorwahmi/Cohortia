fread and fwrite

Block reads and writes move bytes efficiently. Use a buffer and loop until all bytes are copied.

char buf[4096];
size_t n;
while ((n = fread(buf, 1, sizeof(buf), in)) > 0) {
  fwrite(buf, 1, n, out);
}
Why binary mode?
Binary mode prevents runtime translations such as newline conversions. It preserves raw bytes exactly as stored on disk.
Common mistake
Mixing text and binary modes across platforms may corrupt files. Choose the right mode and match it across read/write operations.
Key Takeaway

For raw data and speed, use fread/fwrite in binary mode and check element counts to handle partial transfers.
