Reading lines safely

fgets(buffer, size, file) reads at most size-1 characters and null-terminates. Always check the return value for NULL to detect EOF or errors.

char buf[128];
if (fgets(buf, sizeof(buf), file) != NULL) {
  // buf contains a null-terminated line
}

Formatted I/O and conversion

Use fprintf to write formatted data. For parsing numbers, strtol is safer than atoi because it reports conversion errors.

Example: Read a line with fgets and convert a number with strtol, checking the end pointer for errors.
Avoid: fscanf(file, "%s", buf) without width limits; it may overflow buf.
Key Takeaway

Bounded reads plus explicit conversion checks are the safe path for string and numeric input.
