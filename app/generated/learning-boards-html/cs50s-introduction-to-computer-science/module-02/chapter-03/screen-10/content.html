argc and argv explained

argc is an integer count. argv is an array of C strings. Always check argc before using argv indexes.

int main(int argc, char *argv[])
{
  // argc is count, argv[0] is program name
}
Example run
If you run: ./myprog Alice 123 — argc is 3, argv[1] is Alice, argv[2] is 123.
Conversion tip
Use strtol to convert numeric argv to integers while checking for conversion errors rather than atoi which silently fails.
Key Takeaway

Validate argc and parse argv with error-aware conversion functions to keep your program robust.
