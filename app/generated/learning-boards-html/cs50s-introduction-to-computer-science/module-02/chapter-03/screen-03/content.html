Safety-first practice

Exercises show explicit error handling and buffer-aware reads so you avoid common runtime failures.

  • Open files and immediately check for NULL. Report a helpful message if open fails.
  • When reading strings, use bounded functions and reserve room for the terminating character.
  • Always close files to flush output and free handles. Closing also makes behavior predictable across platforms.

Command-line practice

Try running programs with different numbers of arguments to see how argc changes. Validate inputs before use.

Example: If argc < expected, print usage and return an error code.
Example: Convert numeric argv using safe functions like strtol and check for conversion errors.
