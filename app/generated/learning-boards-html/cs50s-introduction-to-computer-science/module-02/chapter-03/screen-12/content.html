Module 3 › Chapter 2.3 › Comparison
Unsafe pattern
  • Call fopen and use the result without NULL check.
  • Use fscanf with "%s" and no width limit.
  • Use char to store fgetc return value.
  • Open with "w" expecting to append.
Safer alternative
  • Check fopen return and handle errors with messages and nonzero exit codes.
  • Use fgets with a buffer size and parse with sscanf or strtol while checking results.
  • Store fgetc results in int and compare to EOF.
  • Choose "a" to append or explicitly handle file contents before writing.
Key Takeaway

Adopt checked, bounded, and mode-aware patterns to avoid crashes and data loss.
