Copying characters

Read with fgetc into an int, check for EOF, and write with fputc. Close both streams.

#include <stdio.h>
int main(void)
{
  FILE *in = fopen("source.txt", "r");
  FILE *out = fopen("dest.txt", "w");
  if (in == NULL || out == NULL) return 1;
  int c;
  while ((c = fgetc(in)) != EOF) {
    fputc(c, out);
  }
  fclose(in);
  fclose(out);
  return 0;
}
Why use int for fgetc?
fgetc returns EOF as a negative integer. If you use char, EOF can be misinterpreted as a valid character and the loop fails.
Misconception
Character loops are slow for large files. They are fine for small tasks and clear teaching examples; for larger data prefer block reads with fread.
Key Takeaway

Use int for fgetc, test for EOF, and always fclose to flush output.
