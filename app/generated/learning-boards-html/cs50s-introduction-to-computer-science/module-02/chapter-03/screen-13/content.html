Module 3 › Chapter 2.3 › Key Concepts
File I/O
Reading and writing files for data that persists beyond a run.
FILE *
A stream handle returned by fopen; test it for NULL before use.
File Modes
Modes like r, w, a and binary variants determine how the file is opened and whether it is truncated.
Summary
Remember to validate opens, choose modes carefully, and close files. These small steps prevent most file I/O errors.
