Open file process

Follow this safe sequence every time you open a file.

  1. Decide mode: read, write, append, or binary.
  2. Call fopen(filename, mode).
  3. Immediately test if returned FILE * is NULL. If NULL, print a descriptive error and exit the action.
  4. On success, perform reads or writes and then fclose.
Common Mistake
Opening in "w" when you meant to read will delete existing contents. Confirm mode intent before calling fopen.
Mode quick reference
"r" — read existing file; NULL if missing
"w" — write and truncate; creates file if missing
"a" — append; writes go to end; creates if missing
Add "b" for binary: "rb", "wb", "ab"
Example snippet
FILE *file = fopen("data.txt", "r");
if (file == NULL) {
  printf("Error: Could not open data.txt for reading.
");
  return 1;
}
// proceed with reads
fclose(file);
