03. Read & Write Methods
Use fgetc/fputc for characters, fgets/fputs for strings, and fread/fwrite for binary blocks. Match functions to data types.
VERIFIED COMPETENCY MILESTONE
04. Command-line Arguments
Use argc and argv to accept filenames and options from the terminal. Convert string arguments to numbers safely with checks.
