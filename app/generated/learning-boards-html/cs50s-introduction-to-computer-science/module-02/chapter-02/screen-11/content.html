print_list and free_list
void print_list(Node *head)
{
  Node *current = head;
  while (current != NULL)
  {
    printf("%d -> ", current->data);
    current = current->next;
  }
  printf("NULL
");
}

void free_list(Node *head)
{
  Node *current = head;
  while (current != NULL)
  {
    Node *next_node = current->next;
    free(current);
    current = next_node;
  }
}
Key steps
When freeing, always save the pointer to the next node before calling free on the current node.
Bug pattern
Accessing current after free or forgetting to set next correctly will cause crashes or memory corruption.
