Module 2 › Chapter 2.2 › Learning Objectives
01 Define a struct
Create a blueprint with struct
Declare a struct to group related fields so functions accept one cohesive value instead of many separate variables.
Mnemonic: think "recipe card" — one card describes all fields.
VERIFIED COMPETENCY MILESTONE
02 Access with dot
Read and write members with dot
Use the dot operator on a struct variable to access its members directly for clear single-field updates.
Mnemonic: dot = direct field access.
VERIFIED COMPETENCY MILESTONE
03 Use typedef
Create readable aliases
Make struct types feel like built-in types so declarations are concise and easier to scan.
Mnemonic: typedef = friendly name.
VERIFIED COMPETENCY MILESTONE
04 Arrays of structs
Manage many records
Declare an array where each element is a struct instance to hold a roster or collection of records by index.
Mnemonic: think ledger rows — each row is a full record.
