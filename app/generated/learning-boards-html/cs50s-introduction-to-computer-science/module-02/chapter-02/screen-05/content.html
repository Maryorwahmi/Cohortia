Module 2 › Chapter 2.2 › Declare & Initialize
Code example
#include <string.h> // for strcpy

struct Student {
  char name[50];
  int id;
  float gpa;
};

int main(void)
{
  struct Student s1;
  strcpy(s1.name, "Alice");
  s1.id = 12345;
  s1.gpa = 3.8f;

  // initializer list
  struct Student s2 = {"Bob", 54321, 3.5f};

  return 0;
}
Explanation
  • Use strcpy to place a C-string into a char array member.
  • Use s.field to set or read members on a struct variable.
  • Initializer lists set fields in declaration order.
Common mistake
Attempting to assign a char array directly with the equals operator will not copy characters; use a copy function instead.
Key Takeaway

Treat struct variables as single values and use dot syntax and initializer lists to set fields correctly.
