05 Pointers to structs
Refer to struct storage
Learn why using a pointer avoids copying and how to get the address of a struct with the address operator.
Mnemonic: pointer = address card.
VERIFIED COMPETENCY MILESTONE
06 Arrow operator
Access members via pointer
Use the arrow operator as a shorthand for dereferencing a struct pointer and accessing its field in one step.
Mnemonic: arrow points to a member through a pointer.
VERIFIED COMPETENCY MILESTONE
07 Dynamic allocation
malloc and free for structs
Allocate struct storage at runtime and free it when done, always checking that allocation succeeded.
Mnemonic: allocate when size must vary.
VERIFIED COMPETENCY MILESTONE
08 Linked lists
Self-referential structs
Define a node type that points to the next node to build dynamic sequences that can grow or shrink.
Mnemonic: each node holds data and the address of the next node.
