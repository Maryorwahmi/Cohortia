Pointer example
typedef struct {
  int x;
  int y;
} Point;

Point p1;
Point *ptr_p1 = &p1;

// two equivalent forms:
(*ptr_p1).x = 10;
ptr_p1->y = 20;
Explanation: arrow is shorthand for dereference then dot access, and it reads more naturally for pointers.
When to use pointers
Pass large structs to functions, share mutable state, or build linked structures with next pointers.
Common mistake
Using the dot operator on a pointer variable is incorrect; dot operates on a value, not on a pointer.
Check your understanding

Is the pointer pointing to stack storage or heap storage? Confirm before dereferencing to avoid undefined behavior.
