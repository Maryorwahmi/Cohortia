Module 2 › Chapter 2.2 › Best Practices
Naming & typedef
Use typedef for concise names, keep the typedef close to the struct, and choose names that reveal intent.
Initialization
Initialize struct variables and set pointer members to NULL if they do not yet point to valid storage.
Memory hygiene
Check malloc results, free when done, and avoid using freed pointers by setting them to NULL.
Centralize pointer logic
Write small helper functions for insertions, deletions, printing, and freeing so pointer updates are implemented in one place and easier to test.
