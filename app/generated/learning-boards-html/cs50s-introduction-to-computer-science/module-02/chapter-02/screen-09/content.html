Heap allocation example
#include <stdlib.h>
#include <stdio.h>

typedef struct {
  int x;
  int y;
} Point;

int main(void)
{
  Point *dynamic_point = (Point *) malloc(sizeof(Point));
  if (dynamic_point == NULL)
  {
    printf("Memory allocation failed!
");
    return 1;
  }
  dynamic_point->x = 100;
  dynamic_point->y = 200;
  printf("Dynamic point: (%d, %d)
", dynamic_point->x, dynamic_point->y);
  free(dynamic_point);
  dynamic_point = NULL;
  return 0;
}
Allocation checklist
  • Call malloc with sizeof(type).
  • Check the returned pointer for NULL.
  • free when finished and set pointer to NULL.
Common mistake
Failing to free allocated structs leads to memory leaks; freeing too early leads to dangling pointer use.
Key Takeaway

Heap allocation enables variable-sized structures but requires explicit lifecycle management.
