Module 2 › Chapter 2.2 › Arrays vs Linked Lists
Arrays of Structs
  • Contiguous memory layout with predictable indexing.
  • Fast random access via indices (O(1)).
  • Fixed-size unless you allocate dynamically and resize.
Linked Lists (Nodes)
  • Dynamic growth without moving existing nodes.
  • Fast insertion/removal at head or known positions.
  • Slower random access and extra memory for pointers.
When to use arrays
Fixed-size rosters, where indexed reads are common.
When to use lists
Queues or stacks implemented with frequent insertions and removals.
Memory note
Pointers add overhead; measure if memory is tight.
