Module 2 › Chapter 2.2 › What is a struct?
Definition
A struct is a user-defined data type that groups variables of different types under a single name. It describes the layout of a compound value and is used to model related pieces of information as one unit.
Analogy
Imagine a recipe card: it lists all fields required for one recipe. A struct is that card in code and each declared variable is one printed card you can use.
Key takeaway
Declaration does not allocate memory. You must declare variables of the struct type to store actual values.
Example declaration
// Define a Student type
struct Student {
  char name[50];
  int id;
  float gpa;
};

// Declare a variable of that type
struct Student s1;  // allocates storage for one Student
Explanation: the struct block tells the compiler the fields and types. The later declaration s1 reserves memory for that layout.
