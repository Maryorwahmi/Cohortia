Node definition and insert_at_head
typedef struct Node {
  int data;
  struct Node *next;
} Node;

Node *insert_at_head(Node *head, int value)
{
  Node *new_node = (Node *) malloc(sizeof(Node));
  if (new_node == NULL) exit(1);
  new_node->data = value;
  new_node->next = head;
  return new_node;
}
Explanation
The new node points to the previous head, and the returned node becomes the new head. If head was NULL, the new node's next is NULL and it is the only element.
Pitfall
Failing to set new_node->next correctly will sever part of the list. Always assign next before returning.
Key Takeaway

Linked lists use self-referential structs; insertion at head is simple and efficient but requires careful pointer updates.
