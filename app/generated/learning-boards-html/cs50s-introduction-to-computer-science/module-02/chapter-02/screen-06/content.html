Before and after
// With a tag name
typedef struct StudentTag {
  char name[50];
  int id;
  float gpa;
} Student;

// Now you can write:
Student s1;

// Or anonymous struct with typedef
typedef struct {
  char name[50];
  int id;
  float gpa;
} StudentAnon;
When to use a tag
If the struct needs to refer to itself via pointers (self-referential), use a tag name so the type name is available inside the definition.
Example: benefit
Using an alias shortens later declarations and makes code that manipulates many struct variables much easier to read.
Pro tip

Prefer clear alias names and keep the typedef close to the struct definition so the association is obvious.
