Module 2 › Chapter 2.2 › Key Concepts
struct
A user-defined type that groups different fields into one named record.
. and -> operators
Use dot for struct variables and arrow for pointers to structs; they are not interchangeable.
Arrays & Lists
Arrays store contiguous struct instances for fast indexing; linked lists use nodes and pointers for flexible growth.
Final Takeaway

Model related data with structs, choose the right storage for your needs, and handle pointers and memory deliberately to avoid common bugs.
