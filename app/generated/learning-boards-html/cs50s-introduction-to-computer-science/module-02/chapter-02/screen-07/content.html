Example: array of structs
// Declare an array of 100 Students
Student class_roster[100];

// Set fields of the first element
strcpy(class_roster[0].name, "Charlie");
class_roster[0].id = 98765;
class_roster[0].gpa = 3.7f;

// Copying elements assigns all fields
class_roster[1] = class_roster[0];
Memory layout
Elements are stored contiguously; element i is at base + i * sizeof(element).
Common misconception
An array declared as Student arr[10] stores full Student values, not pointers. Declare Student *arr[] when you want pointers.
Key Takeaway

Choose arrays for fixed-size needs with fast indexing; choose dynamic allocation or linked lists for variable sizes.
