Reflection prompt

Identify one application you might build—backup tool, data importer, config loader, or server log manager—and describe how you would use file modes, with, and which exceptions you would catch to ensure a reliable user experience.

Example: Data importer
Use 'r' to read CSVs, iterate lines to avoid memory spikes, catch FileNotFoundError to ask for the correct path, and catch ValueError for malformed fields while logging and continuing.
Example: Logger
Open the log file in 'a' mode, use with to close, and avoid catching Exception while writing so errors are visible during development.
Key Takeaway

Design your file and exception strategy around user impact: favor recovery or clear error messages over silent failures.
