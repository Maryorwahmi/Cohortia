Module 5 › Chapter 4.4 › Writing to files
Code examples
# Using write
with open("output.txt", "w") as f:
  f.write("Line one
")
  f.write("Line two
")

# Using writelines (each string must end with a newline)
lines = ["First
", "Second
"]
with open("output.txt", "w") as f:
  f.writelines(lines)

# Append mode
with open("output.txt", "a") as f:
  f.write("Appended line
")
Remember: write and writelines do not add separators automatically. Explicitly include ' ' when creating lines.
Example scenario
A logger should open a file in append mode so that each run adds new entries rather than erasing history. Use with to ensure log file handles are closed properly.
Key Takeaway

When writing multiple lines, include newlines explicitly and choose append to preserve history or write to replace content deliberately.
