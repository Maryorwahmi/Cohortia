Module 5 › Chapter 4.4 › Common pitfalls
Pitfalls & tips
  • Wrong working directory or path leads to FileNotFoundError.
  • Missing ' ' when writing produces concatenated lines when read back.
  • Opening in binary returns bytes; decode when needed for text.
  • Broad except blocks can hide the real error—narrow them during debugging.
  • Rely on with to avoid subtle resource leaks and locking issues.
Quick checklist
  1. Confirm path and permissions.
  2. Print exception messages in except blocks to capture details.
  3. Check mode: 't' vs 'b', and include newlines when needed.
Pro tip

When debugging, temporarily avoid catching Exception so the interpreter prints a traceback that points to the root cause.
