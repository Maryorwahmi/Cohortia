01
Read files safely

Use read, readline, readlines, and iteration to access file contents. Processing line by line prevents high memory usage with large files.

Mnemonic: "Stream, don’t stash" — stream lines when large.
VERIFIED COMPETENCY MILESTONE
02
Write with intent

Use write and writelines and remember to include " " for explicit line breaks. Choose 'w' or 'a' mode depending on whether you want to replace or append.

Mnemonic: "Write with care" — add newlines when needed.
VERIFIED COMPETENCY MILESTONE
03
Choose the right mode

Understand 'r', 'w', 'a', 'x' and text versus binary modes so file creation and truncation are controlled and intentional.

Mnemonic: "Read, Write, Append, eXclusive".
VERIFIED COMPETENCY MILESTONE
04
Handle exceptions

Use try, except, else, and finally to catch predictable errors like FileNotFoundError or ValueError and ensure cleanup using finally or with.

Mnemonic: "Try, Catch, Succeed, Clean".
