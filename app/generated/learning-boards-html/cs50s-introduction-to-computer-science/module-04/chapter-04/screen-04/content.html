Module 5 › Chapter 4.4 › Opening files and choosing modes
Definition

open(path, mode)

The mode string controls whether a file is read, created, truncated, appended, and whether it is text or binary.

'r' — read
Default. Fails if file missing.
'w' — write
Creates or truncates existing file.
'a' — append
Adds to end; creates if missing.
'x' — exclusive
Creates and fails if file exists.
Example
# Create or overwrite
file = open("notes.txt", "w")
file.write("Hello
")
file.close()

# Append safely
file = open("notes.txt", "a")
file.write("More notes
")
file.close()
Common mistakes & checks
  • Using 'w' unintentionally erases previous content.
  • Choosing binary mode without encoding when working with text leads to byte objects.
  • Expecting 'x' to create safely but not handling FileExistsError if the file exists.
Key Takeaway

Pick the most conservative mode that expresses your intent; use 'x' to prevent overwrite, 'a' for logs, and 'r' for read-only access.
