Module 5 › Chapter 4.4 › Log generator & analyzer
Starter code (generator)
import random

def generate_log(filename, num_entries):
    """Generates a log file with random success/warning entries."""
    with open(filename, "w") as f:
        for i in range(num_entries):
            if random.random() < 0.7:
                f.write(f"Log entry {i+1}: Operation successful.
")
            else:
                f.write(f"Log entry {i+1}: Warning - Low disk space.
")
    print(f"Generated {num_entries} log entries in '{filename}'.")
Starter code (analyzer)
def analyze_log(filename):
    """Analyzes a log file for success and warning entries."""
    success_count = 0
    warning_count = 0
    try:
        with open(filename, "r") as f:
            for line in f:
                if "successful" in line:
                    success_count += 1
                elif "Warning" in line:
                    warning_count += 1
        print(f"Analysis of '{filename}':")
        print(f"  Successful operations: {success_count}")
        print(f"  Warning operations: {warning_count}")
    except FileNotFoundError:
        print(f"Error: Log file '{filename}' not found.")
    except Exception as e:
        print(f"An unexpected error occurred during analysis: {e}")
Run generate_log then analyze_log to test both creation and error handling. Try analyze_log on a missing filename to see the FileNotFoundError message.
Key Takeaway

Combining with for safety and specific except blocks yields a reliable utility that both creates and analyzes files without leaking resources.
