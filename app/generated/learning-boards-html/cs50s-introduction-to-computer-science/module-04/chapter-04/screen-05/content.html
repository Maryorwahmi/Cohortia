Code walkthrough
Common read patterns
# Read entire file
with open("my_notes.txt", "r") as f:
  content = f.read()
  print(content)

# Read line by line with readline
with open("my_notes.txt", "r") as f:
  line = f.readline()
  while line:
    print(line.strip())
    line = f.readline()

# Iterate for memory efficiency
with open("large_log.txt", "r") as f:
  for line in f:
    if "ERROR" in line:
      process(line.strip())
Note: use strip() to remove trailing newline characters when processing or comparing lines.
Explanation & example
  • read loads everything: convenient but not scalable.
  • readline gives you manual control for each line.
  • Iterating a file is lazy and efficient for large streams.
Concrete example
Count how many lines contain the word "successful" in a log by iterating the file and incrementing a counter when the substring appears.
Key Takeaway

Prefer iteration for large files; reserve read/readlines for small, bounded inputs.
