Module 5 › Chapter 4.4 › Try/except/else/finally
File read with error handling
try:
  with open("non_existent.txt", "r") as file:
    content = file.read()
except FileNotFoundError:
  print("The file was not found.")
except Exception as e:
  print(f"An error occurred: {e}")
else:
  print("File read successfully.")
finally:
  print("Attempt completed.")
Walkthrough
  1. Try to open and read inside a with to ensure closure.
  2. Catch FileNotFoundError to give a helpful message.
  3. Use else to run post-read logic only on success.
  4. Use finally to report completion or run cleanup unrelated to with.
Key Takeaway

Structure error handling so that expected problems are caught and everything that must run gets executed in finally or by context managers.
