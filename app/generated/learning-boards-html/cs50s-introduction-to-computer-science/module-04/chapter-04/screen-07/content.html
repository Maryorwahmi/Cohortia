Context-managed file handling

The with block calls setup and teardown automatically; use it to avoid manual close calls and resource leaks.
# Preferred pattern
with open("my_notes.txt", "r") as file:
  for line in file:
    print(line.strip())
# File is closed automatically here
Contrast with manual close which requires a finally block to guarantee cleanup when exceptions are possible.
Why use with?
  • Reduces boilerplate and errors.
  • Ensures deterministic cleanup.
  • Works for files and other context managers.
Key Takeaway

Prefer with for file handling. It provides automatic and reliable resource cleanup even in the face of exceptions.
