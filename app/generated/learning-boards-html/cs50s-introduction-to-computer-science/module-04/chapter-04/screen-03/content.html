Scenarios & Skills

Each objective maps to common tasks: processing logs, saving settings, safe deployment, and resilient data imports.

Large file processing
Iterate with for line in file to maintain low memory usage when parsing large logs or datasets.
Saving state
Use 'w' to replace a config file and 'a' to maintain an append-only history.
Deployment safety
Use 'x' to avoid overwriting files unintentionally during setup scripts.
Robust imports
Catch specific exceptions like ValueError to handle malformed data while processing the rest.
Verified Milestone
Write a small script that reads a provided log file line by line, counts occurrences of a keyword, and prints counts. Ensure the script handles missing files gracefully.
