Module 5 › Chapter 4.4 › Exception handling basics
Flow
try
Run code that might raise exceptions.
except
Handle a specific exception type and recover or log an error.
else
Execute only if try succeeded without exceptions.
finally
Always execute for cleanup, regardless of exceptions.
Example
try:
  with open("data.txt", "r") as f:
    content = f.read()
except FileNotFoundError:
  print("The file was not found.")
except Exception as e:
  print(f"An error occurred: {e}")
else:
  print("File read successfully.")
finally:
  print("Attempt to read file finished.")
Note how specific except blocks handle predictable errors and finally runs regardless to report completion.
Key Takeaway

Catch specific exceptions, use else for success-only code, and use finally to guarantee cleanup actions.
