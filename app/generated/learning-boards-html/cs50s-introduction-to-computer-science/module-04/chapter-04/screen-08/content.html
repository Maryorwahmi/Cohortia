Module 5 › Chapter 4.4 › Closing files
Symptoms of not closing
  • Missing data because buffers not flushed to disk.
  • Resource limits reached due to too many open file descriptors.
  • Intermittent failures that are hard to reproduce.
Safe manual pattern
try:
  f = open("data.txt", "w")
  f.write("important
")
finally:
  if 'f' in locals():
    f.close()
Prefer with
With reduces error-prone code and guarantees timely closure, preventing the failures above.
Key Takeaway

Deterministic cleanup matters. Prefer with for files; use try/finally only when required for more complex resource management.
