Module 4 › Chapter 4.3 › List Operations
Step-by-step
  1. append(item): add to end
  2. insert(index, item): place at position
  3. remove(value): remove first match
  4. pop(index=-1): remove and return
  5. sort(): sort in place
# append and pop
items = ["a", "b"]
items.append("c")    # ["a","b","c"]
last = items.pop()     # last == "c", items == ["a","b"]

# insert and remove
items.insert(1, "x") # ["a","x","b"]
items.remove("x")     # ["a","b"]

# sort in place
numbers = [3,1,2]
numbers.sort()         # [1,2,3]
Performance note
Insert and remove at arbitrary positions shift elements. For large lists, prefer append and pop at the end. If you need frequent middle inserts, consider a different data structure.
Common mistake
Modifying a list in place while iterating can skip items or raise errors. Iterate over a copy or build a new list instead.
Key Takeaway

Use append/pop for simple stack-like growth and remove/insert with care; sort mutates the list.
