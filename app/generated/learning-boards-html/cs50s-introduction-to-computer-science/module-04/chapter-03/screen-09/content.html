Module 4 › Chapter 4.3 › Dictionaries
Structure & example
student = {
    "name": "Alice",
    "age": 20,
    "major": "Computer Science",
    "courses": ["CS50", "Calculus"]
}

# access and update
name = student["name"]
student["year"] = "Sophomore"
age = student.get("age", 0)

# iterate
for key, value in student.items():
    print(key, value)
Dictionaries map identifiers to data and are the natural choice for records and configurations.
Best practice
Use get when a key might be missing to avoid KeyError and provide a sensible default.
Misconception
Dictionaries used to be unordered; in modern Python they preserve insertion order, but they are still best thought of for mapping rather than positional access.
Key Takeaway

Use dictionaries for fast keyed lookup and to represent structured records.
