Module 4 › Chapter 4.3 › Inventory Exercise
Starter code and steps
# 1. Create the inventory list
inventory = ["Laptop", "Mouse", "Keyboard"]

# 2. Add "Monitor"
inventory.append("Monitor")

# 3. Remove "Mouse"
if "Mouse" in inventory:
    inventory.remove("Mouse")

# 4. Create the item_details dictionary
item_details = {
    "Laptop": {"price": 1200.00, "quantity": 5},
    "Keyboard": {"price": 75.00, "quantity": 10}
}

# 5. Add details for "Monitor"
item_details["Monitor"] = {"price": 250.00, "quantity": 8}

# 6. Update quantity of "Laptop"
item_details["Laptop"]["quantity"] = 3

# 7-8. Print and calculate total
print("Current Inventory:", inventory)
print("Item Details:", item_details)

total_value = 0.0
for item_name in inventory:
    if item_name in item_details:
        item = item_details[item_name]
        total_value += item["price"] * item["quantity"]
print("Total Inventory Value:", total_value)
Concrete checks
  • Check membership before accessing item_details to avoid KeyError.
  • Use append and remove to maintain inventory order.
  • Use set(inventory) if you only need unique item names.
Analogy
Think of inventory as the shelf order (list), and item_details as the product manual keyed by name (dictionary).
Key Takeaway

Apply lists for order, dictionaries for keyed details, and sets when uniqueness is the main concern.
