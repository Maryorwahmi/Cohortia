Definition & code
coordinates = (10.0, 20.5)
rgb = (255, 0, 0)

# Access works the same way
lat = coordinates[0]

# But modification raises an error
# coordinates[0] = 11.0  # TypeError: 'tuple' object does not support item assignment
Use tuples when the values should remain fixed or when you need a hashable sequence to use as a dictionary key.
Use case
Dictionary keys and fixed records
Store a point or configuration as a tuple and use it as a key in another dictionary if the tuple contains only immutable elements.
Misconception
Immutability is not a limitation; it prevents accidental changes and makes certain operations like hashing possible.
Key Takeaway

Choose tuples for fixed collections of values and when you need hashable, ordered data.
