Module 4 › Chapter 4.3 › Key Concepts
List
Ordered, mutable collection accessed by index and defined with square brackets.
Indexing
Access elements by position; negative indexes count from the end.
Slicing
Extracts a sub-sequence from start inclusive to end exclusive; returns a new list or tuple.
Summary
Keep these basics in mind as you build and read code; they explain most behaviors you will encounter with sequences.
