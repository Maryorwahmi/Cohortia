Examples & operations
unique_numbers = {1, 2, 3, 2, 4, 1}  # becomes {1,2,3,4}
vowels = {'a', 'e', 'i', 'o', 'u'}

# operations
set1 = {1,2,3}
set2 = {3,4,5}
union = set1.union(set2)         # {1,2,3,4,5}
inter = set1.intersection(set2)  # {3}
diff = set1.difference(set2)     # {1,2}

# membership
if 2 in set1:
    pass
Sets are excellent for removing duplicates and performing fast membership tests. They do not preserve order and require hashable elements.
Use case
Unique IDs
Convert a list of student IDs to a set to quickly count unique students and perform comparisons.
Misconception
Sets are not ordered; do not rely on iteration order. Also, elements must be immutable and hashable.
Key Takeaway

Use sets for uniqueness and set algebra; convert lists to sets to remove duplicates quickly.
