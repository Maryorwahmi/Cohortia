Module 4 › Chapter 4.3 › Key Concepts
Dictionary
Key-value pairs for fast lookup; keys must be immutable; get provides a safe default.
Set
Unordered collection of unique elements; supports union, intersection, and difference.
Mutability
Mutability determines whether a structure can change in place; it affects safety and whether a value can be a dictionary key.
Final takeaway
Match the properties you need — order, mutability, keyed lookup, or uniqueness — to make confident, efficient choices about data structures.
