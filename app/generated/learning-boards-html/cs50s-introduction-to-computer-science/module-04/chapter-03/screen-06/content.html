Module 4 › Chapter 4.3 › Indexing & Slicing
Code walk-through
numbers = [1, 2, 3, 4, 5]

# indexing
first = numbers[0]    # 1
second = numbers[1]   # 2
last = numbers[-1]    # 5

# slicing (start:end, end exclusive)
middle = numbers[1:4] # [2, 3, 4]
from_start = numbers[:3] # [1,2,3]
to_end = numbers[2:]     # [3,4,5]

# slicing past bounds
out = numbers[3:10]   # [4,5] - no error
Practical tip
Visualize indices as slots between elements to avoid off-by-one errors. End index is excluded.
Misconception
Remember: negative indexes count from the end and slices return new lists, not references to the original slice.
Example
Log window
Use slicing to get the most recent N log entries: logs[-10:] returns up to the last ten entries safely even if fewer exist.
Check your understanding
What does items[2:2] return? (Hint: an empty list). Why is that useful when building algorithms?
Key Takeaway

Indexing selects an element; slicing returns a new sequence defined by start inclusive to end exclusive.
