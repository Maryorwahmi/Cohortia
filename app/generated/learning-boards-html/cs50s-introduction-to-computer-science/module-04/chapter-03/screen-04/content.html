Module 4 › Chapter 4.3 › Lists
Definition & examples
Lists are ordered, mutable collections defined with square brackets.
# examples
fruits = ["apple", "banana", "cherry"]
numbers = [1, 2, 3, 4, 5]
mixed = ["hello", 123, True, 3.14]

# indexing and slicing
first = fruits[0]         # "apple"
last = fruits[-1]         # "cherry"
slice_mid = numbers[1:4] # [2, 3, 4]
Common methods
  • append, insert
  • remove, pop
  • sort (in-place)
Misconception
Slicing modifies the original list — it does not; slicing returns a new list.
Example scenario
Shopping list
Start with items you plan to buy, append as you remember more, and pop when purchased. Order matters because you might want to keep a priority sequence.
Check your understanding
  • What happens when you use negative indexing?
  • Does sort modify the list or return a new one?
Key Takeaway

Use lists when you need an ordered, changeable sequence and index-based access.
