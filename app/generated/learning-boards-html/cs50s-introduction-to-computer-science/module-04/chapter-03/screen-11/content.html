Decision flow (rules of thumb)
  • Need ordered, mutable sequence? Use a list.
  • Need ordered, fixed record? Use a tuple.
  • Need fast lookup by key? Use a dictionary.
  • Need unique elements or set math? Use a set.
Combine structures when necessary: a list of dictionaries models collections of records, and tuples can be keys when records are fixed.
Scenario
Inventory system
Use a list for inventory order, a dictionary to map item names to details, and a set to identify unique categories or detect duplicates quickly.
Common mistake: using a list for frequent keyed lookup rather than a dictionary, causing slower code.
Key Takeaway

Let the properties you need — order, mutability, key lookup, or uniqueness — guide your choice of structure.
