Module 4 › Chapter 4.3 › Mutation during iteration
Problem and example
items = [1,2,3,4]
for x in items:
    if x % 2 == 0:
        items.remove(x)
# This may skip elements and behave unexpectedly

# Safer: iterate over a copy
for x in items[:]:
    if x % 2 == 0:
        items.remove(x)

# Or build a new list
filtered = [x for x in items if x % 2 != 0]
The first loop mutates the list while the iterator advances, causing a mismatch between expected and actual positions.
Alternative patterns
  • Iterate over a shallow copy (items[:])
  • Use list comprehensions to build a new list
  • Use reversed index loops when removing by index
Analogy
Removing guests from a queue while you walk the line changes positions; instead, mark guests to remove and update after the pass, or start with a fresh list.
Key Takeaway

Mutating while iterating is error-prone; iterate a copy or build a new list to keep behavior predictable.
