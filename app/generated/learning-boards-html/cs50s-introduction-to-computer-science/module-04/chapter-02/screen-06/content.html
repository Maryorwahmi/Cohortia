Module 4 › Chapter 4.2 › While Safety
Guidelines
  • Identify the condition variable and ensure it changes every loop iteration.
  • Provide clear exit conditions and consider sentinel values for input loops.
  • Add a maximum iteration counter when processing uncontrolled external data.
Example: guessing loop
secret = 7
guess = None
attempts = 0
while guess != secret and attempts < 10:
  # imagine reading user input here
  guess = int(input("Guess: "))
  attempts += 1
  if guess == secret:
    print("You win!")
  else:
    print("Try again")
Common Mistake
Not updating the variable used in the condition, or relying on input that never arrives, will cause an infinite loop.
Pro tip
When testing, deliberately make the loop run only a few iterations to confirm termination, then remove the guard for production if it's safe.
