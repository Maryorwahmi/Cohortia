Example with break and continue
for num in range(10):
  if num % 2 == 0:
    continue  # skip even numbers
  if num > 7:
    break     # stop when greater than 7
  print(num)  # prints 1, 3, 5, 7
This loop skips even numbers with continue and exits entirely when num is greater than seven with break.
When to use which
  • Use continue to filter or ignore items while keeping the loop running.
  • Use break when a terminal condition is met or when you can stop early for performance.
  • Avoid many break points; they can obscure loop termination logic.
