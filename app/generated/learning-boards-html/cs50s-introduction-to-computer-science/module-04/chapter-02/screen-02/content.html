Learning Objectives
Learn, Understand, Apply, Master
Bloom progress
Learn
Recognize syntax and basic examples.
Understand
Explain behavior and common mistakes.
Apply
Write functioning code for small tasks.
01
Implement Conditional Logic
Write if, elif, else blocks and order conditions correctly so the intended branch runs. Verified competency milestone.
Mnemonic: Venn-style decision set
02
Use for and while loops
Iterate with range and sequences; use while when repetition depends on changing conditions. Verified competency milestone.
Mnemonic: Timeline dots for iterations
03
Control loops with break/continue
Exit early or skip iterations to handle special cases or optimize performance. Verified competency milestone.
Mnemonic: Arrow forks
04
Define and call functions
Use def, parameters, return values, and docstrings while preferring local variables over globals. Verified competency milestone.
Mnemonic: Box for inputs and outputs
