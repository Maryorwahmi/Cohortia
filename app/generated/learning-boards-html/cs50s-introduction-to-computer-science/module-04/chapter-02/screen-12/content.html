Code to Trace
def mystery_function(x):
  if x % 2 == 0:
    return "Even"
  elif x > 5:
    return "Odd and Large"
  else:
    return "Odd and Small"

print(mystery_function(4))
print(mystery_function(7))
print(mystery_function(3))
Expected Output
Even Odd and Large Odd and Small
Debug Tip
When outputs differ from expectations, step through each condition and note which branch returns early.
