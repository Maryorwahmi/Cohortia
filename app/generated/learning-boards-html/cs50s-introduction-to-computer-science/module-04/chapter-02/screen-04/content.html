Module 4 › Chapter 4.2 › Conditionals
Definition
if / elif / else
A chain of tests where the first true condition's block executes. Indentation and colons are required syntax markers.
Key Points
  • Evaluate conditions in order; stop at the first true branch.
  • Order tests from most specific to most general to avoid unreachable code.
  • Always use a colon and consistent indentation to define blocks.
Concrete Example
Assign a letter grade based on score boundaries.
Common Mistake
Placing a general test before a specific one, making the specific branch unreachable.
Code Example
# Example: assign a letter grade
score = 85
if score >= 90:
  print("Grade: A")
elif score >= 80:
  print("Grade: B")
elif score >= 70:
  print("Grade: C")
else:
  print("Grade: F")
Takeaway
Write conditions so the intended branch matches first. Use else to catch unexpected inputs.
