Module 4 › Chapter 4.2 › for vs while
for loop
Iterate over sequences or a fixed range
Use for when the number of iterations or the items are known. Range is common for counted loops.
for i in range(5):
  print(f"Iteration {i}")

# iterate over a string
for ch in "Python":
  print(ch)
Example: count or iterate letters.
while loop
Repeat while a condition holds
Use while when repetition depends on state that changes during execution, like waiting for user input or a condition to be met.
count = 0
while count < 3:
  print(f"Count is {count}")
  count += 1
Pitfall: missing the increment can cause an infinite loop.
