Starter Function
def calculate(num1, num2, op):
  """
  Performs a basic arithmetic operation on two numbers.
  """
  if op == '+':
    return num1 + num2
  elif op == '-':
    return num1 - num2
  elif op == '*':
    return num1 * num2
  elif op == '/':
    if num2 == 0:
      return "Error: Division by zero!"
    return num1 / num2
  else:
    return "Error: Invalid operator."
Example Call
result = calculate(10, 2, '/') # returns 5.0
Edge Case
calculate(5, 0, '/') returns an error string rather than raising an exception.
Design Note
Separating the calculation from input/output makes the function reusable in other programs or tests.
