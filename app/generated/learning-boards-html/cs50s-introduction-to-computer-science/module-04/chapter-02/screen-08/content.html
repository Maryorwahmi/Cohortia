Module 4 › Chapter 4.2 › Functions
Structure
def greet(name):
  """Return a greeting for name."""
  return f"Hello, {name}!"

message = greet("Alice")
print(message)
This function returns a value rather than printing directly so the caller can decide what to do with it.
Docstring and tests
Place a short docstring under the def line and write simple calls to confirm expected behavior. Use return for outputs and avoid modifying global state when possible.
Takeaway
Functions should have a single responsibility, clear parameters, and explicit return values.
