Module 4 › Chapter 4.2 › Variable Scope
Local scope
def counter():
  x = 0  # local to this function
  x += 1
  return x

print(counter())  # prints 1
The local x exists only while counter runs and is recreated on each call.
Global scope
g = 0  # global

def bump():
  global g
  g += 1

bump()
print(g)  # prints 1
Using global allows modification but can cause unexpected interactions across functions.
Best Practice
Prefer passing state as parameters and returning results. Use globals sparingly and document intent if used.
