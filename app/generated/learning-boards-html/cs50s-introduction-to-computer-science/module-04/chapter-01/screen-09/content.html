Module 4 › Chapter 4.1 › Input and Output
Output with print
Print displays values and automatically separates multiple items with spaces when given multiple arguments.
name = "Alex"
age = 30
print("Hello,", name, "you are", age, "years old.")
Input and conversion
Input returns text. Convert that text to a number before arithmetic to avoid type errors.
birth_year_str = input("What year were you born? ")
birth_year = int(birth_year_str)  # convert to integer
current_year = 2023
age = current_year - birth_year
print("You are approximately", age)
Example flow
Prompt, convert, compute, and print. Each step is explicit to avoid runtime errors.
Common mistake
Trying to subtract a number from a text string returned by input, which raises a type error.
Takeaway
Always convert input explicitly when you need numeric behavior, and print values clearly for the user.
