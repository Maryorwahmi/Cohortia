Module 4 › Chapter 4.1 › Hello, World — C vs Python
C example
#include <stdio.h>

int main(void) {
    printf("Hello, World!
");
    return 0;
}
C requires headers, a main function, explicit return, and braces to mark scope. Types and semicolons are explicit.
Python example
print("Hello, World!")
Python uses a single call to the print function. Scope is shown by indentation when defining blocks like functions or conditionals.
Example
Translate a small C function into Python by keeping the algorithm and removing explicit type declarations and braces.
Common mistake
Expecting braces or semicolons in Python. Indentation is mandatory and mixing tabs/spaces causes errors.
Takeaway
Focus on the algorithm and let Python handle low-level details; be deliberate about indentation and variable types.
