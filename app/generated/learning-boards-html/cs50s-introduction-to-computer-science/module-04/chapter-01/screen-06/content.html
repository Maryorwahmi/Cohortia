Module 4 › Chapter 4.1 › Comments, Variables, and Dynamic Typing
Code examples
# Ask for a name and store it as text
name = input("What is your name? ")  # user's name as a string

# Assign a number
x = 10

# Reassigning to a different type is allowed but can be confusing
x = "ten"  # now x holds text, not a number

print(name)
print(x)
Comments explain intent. Variable names are your contract with future readers; changing a variable’s role can break that contract.
Explanation & analogy
Think of a variable name as a labeled jar. In Python you can replace the contents with any type of item, but if you swap contents frequently you confuse anyone who expects the jar to hold one thing.
Pro tip
Use descriptive names and limit reassignments across a function to keep intent clear.
Common mistake
Treating dynamic typing as license to reuse names for disparate purposes; prefer new variable names when types change meaningfully.
