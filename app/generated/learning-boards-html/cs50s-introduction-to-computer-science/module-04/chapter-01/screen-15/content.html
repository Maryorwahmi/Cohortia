Module 4 › Chapter 4.1 › What to Remember
1. Indentation
Structure your code with consistent spaces; the interpreter relies on this structure.
2. Convert input
Always explicitly convert text input to numbers before arithmetic to avoid type errors.
3. Name clearly
Use descriptive names and avoid repurposing a name for different types to keep intent clear.
Final reflection
Before running a script, ask: are blocks indented consistently, are inputs converted where needed, and do variable names make the code easy to read? These simple checks make beginner code far more reliable.
