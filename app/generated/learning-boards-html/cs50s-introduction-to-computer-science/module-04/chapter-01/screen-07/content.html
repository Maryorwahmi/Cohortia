Module 4 › Chapter 4.1 › Integers and Floating-point Numbers
Integers (int)
Whole numbers without a fractional part. Python integers grow to fit values instead of overflowing at a fixed size.
count = 42
big = 10 ** 20  # large integer handled safely
Use integers for counts, indexes, and cases where fractional parts are not meaningful.
Floating-point (float)
Numbers with fractional components. Floating-point arithmetic is approximate due to binary representation.
price = 19.99
share = 10 / 3  # true division, result is a float
quotient = 10 // 3  # floor division, integer result
For critical decimal precision, other approaches exist, but floats work well for many tasks. Choose division operator to match the result you need.
Concrete example
Splitting a 100 unit bill among 3 people: true division gives fractional shares; floor division gives whole units and requires handling the remainder.
Misconception
Expecting float arithmetic to be exact. Small rounding differences are normal and not bugs in your code logic.
Key takeaway
Pick int for discrete counts and float for fractional values; be deliberate with division operators and conversions.
