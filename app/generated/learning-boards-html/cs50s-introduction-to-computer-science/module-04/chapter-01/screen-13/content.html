Quick assessment & fixes
Assessment question
a = 5
b = "10"
c = a + int(b)
print(c)
Expected output is 15 because the text was converted to an integer before addition; forgetting conversion would raise a type error.
Indentation question
Which statement is true? Consistent indentation is required to define blocks. Mixing tabs and spaces is not allowed and causes errors.
Debug step
On a type error, inspect the values and convert input types explicitly before performing arithmetic.
Debug step
On an indentation error, check for mixed tabs and spaces and reformat to a consistent style.
Takeaway
A short checklist of conversions, indentation consistency, and boolean correctness catches most beginner problems quickly.
