Module 4 › Chapter 4.1 › Indentation and Block Structure
Definition
Indentation defines which statements belong to which blocks, such as the body of an if statement or a loop. Use four spaces per level for consistency.
x = 10
if x > 5:
    print("x is greater than 5")
    print("still in the block")
print("outside the block")
Misplacing indentation changes which lines run conditionally and can introduce subtle bugs or raise IndentationError exceptions.
Practice tips
  • Set your editor to insert spaces, not tabs.
  • Use four spaces per indentation level as the community convention.
  • When copying code, re-indent to match your file’s style.
Common mistake
Mixing tabs and spaces leads to hard-to-find errors. Reformatting in your editor fixes many indentation problems.
Key takeaway
Indentation is syntax. Be consistent and your code will be both valid and easier to read.
