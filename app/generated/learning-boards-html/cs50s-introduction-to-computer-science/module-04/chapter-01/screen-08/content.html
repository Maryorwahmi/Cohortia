Module 4 › Chapter 4.1 › Strings and Booleans
Strings (str)
greeting = 'Hello'
name = "Alice"
message = greeting + ", " + name
snippet = message[0:5]  # slicing creates a new string
Strings are immutable; concatenation and slicing return new string values rather than altering existing ones.
Booleans (bool)
is_valid = (password == stored_password)
if is_valid:
    print("Access granted")
else:
    print("Access denied")
Comparisons produce booleans used to control flow. Combine booleans with logical operators to express complex conditions.
Concrete example
Check if a user’s favorite color equals a stored value and print a customized message when it does.
Common mistake
Trying to modify a string in place or using text where a number is required without converting it first.
Takeaway
Treat strings as immutable descriptors and booleans as the basis for decision-making in your programs.
