Comparison examples
a = 5
b = 10
print(a == b)   # False
print(a < b)  # True
print(a != b)   # True
Comparisons return booleans that you can use directly in conditional statements.
Logical examples
age = 25
is_adult = (age >= 18)
has_id = True
if is_adult and has_id:
    print("Entry allowed")
Combine booleans with and, or, and not to form precise conditions for decision making.
Concrete check
Check if a number is positive and even by combining a greater-than comparison and a modulo equality check with and.
Common mistake
Assuming comparisons chain like mathematics in all cases; use parentheses to make intent explicit when combining comparisons and logical operators.
Key Takeaway
Use comparisons to produce booleans and logical operators to combine them for real decision logic in programs.
