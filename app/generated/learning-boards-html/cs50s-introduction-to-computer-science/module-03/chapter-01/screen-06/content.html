Module 3 › Chapter 3.1 › Big O notation
Complexity cards
O(1) — Constant
Time does not depend on input size. Example: accessing an array element by index.
O(log n) — Logarithmic
Halving or reducing search space repeatedly. Example: binary search on sorted arrays.
O(n) — Linear
Proportional to input size. Example: scanning every element in a list.
More classes and intuition
O(n log n)
Combines linear work with logarithmic steps. Often appears in efficient sorts like mergesort and quicksort on average.
O(n^2) — Quadratic
Nested loops over the input. Example: simple comparison-based double loop over a list of n items.
Misconception
Big O is not exact runtime; it classifies growth and ignores constants and lower-order terms.
Key Takeaway

Recognize common growth patterns so you can predict how algorithms scale as input size increases.
