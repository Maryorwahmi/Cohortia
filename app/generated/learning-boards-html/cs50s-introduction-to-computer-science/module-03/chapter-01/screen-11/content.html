Module 3 › Chapter 3.1 › Linear search with strings
Starter code hint
#include <stdio.h>
#include <string.h> // For strcmp

int linear_search_strings(char *arr[], int size, char *target) {
  for (int i = 0; i < size; i++) {
    if (strcmp(arr[i], target) == 0) {
      return i;
    }
  }
  return -1;
}
Each strcmp may scan several characters, so include that cost when you count operations.
Complexity reasoning
If average string comparison cost is O(m), and linear search does O(n) comparisons, total worst-case is O(n * m). If m is constant or bounded, this reduces to O(n).
Concrete example
Searching for "Christopher" in a list of long names may require many character comparisons per strcmp, increasing cost relative to short names.
Misconception
Treating string comparison as free can hide multiplied costs when strings are long; account for both n and string length.
Key Takeaway

When elements are strings, include per-comparison cost. Total worst-case time is O(n * m), with m the string comparison cost.
