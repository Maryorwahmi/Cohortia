Module 3 › Chapter 3.1 › Hands-on Activity
Task
  1. Modify the starter code so linear_search_strings searches an array of char pointers using the string comparison function.
  2. Test with targets at the front, middle, last, and absent; record number of comparisons and character checks.
  3. Write the time complexity as a function of n and m, explaining your assumptions about string length.
Starter hint
Use strcmp and return index on strcmp == 0. To count character checks, instrument the comparison mentally or with additional code that tallies compared characters.
Analysis tip
If average string length is m, and each comparison can cost O(m), then worst-case time is O(n * m). Be explicit about assumptions when writing average-case claims.
Reflection prompt
After testing, decide whether linear search is acceptable for your dataset sizes and string lengths, or whether a different approach is necessary.
When you finish, compare your recorded counts to theoretical predictions to validate your complexity reasoning.
