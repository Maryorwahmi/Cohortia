Counting comparisons
Treat the equality check inside the loop as the dominant operation. How many such checks occur in different cases?
Best case
1 comparison — O(1)
Average case
~n/2 comparisons on average — O(n)
Worst case
n comparisons when target is absent or last — O(n)
Misconceptions and notes
  • Big O ignores constant factors: n/2 is the same class as n.
  • Average-case results depend on assumptions about input distribution.
  • Worst-case is conservative and often preferred for guarantees.
Practical question
If you expect many repeated searches over the same dataset, consider preprocessing (like sorting) to enable faster repeated queries.
Key Takeaway

Analyze dominant operations and consider input distributions; worst-case provides a robust guarantee.
