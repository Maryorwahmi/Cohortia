Count dominant ops
Find the repeated or costly operation that scales with input size.
Account for per-element cost
Multiply element-wise cost, like string length, by the number of elements.
Prefer worst-case
Use worst-case bounds for guarantees unless average-case assumptions are explicit.
Final takeaway
These heuristics help you quickly evaluate algorithm choices and explain trade-offs to teammates when designing systems.
