Off-by-one example
If you set low = mid or high = mid you may not reduce the interval, causing loops that never terminate. Use mid+1 and mid-1.
Overflow-safe mid
Prefer mid = low + (high - low) / 2 to avoid overflow when summing indexes.
Edge-case tests
  • Single-element arrays
  • Two-element arrays
  • Targets at array boundaries and absent values
Key Takeaway

Simple index mistakes break correctness. Use safe mid arithmetic and thorough tests to ensure reliability.
