Module 1 › Chapter 3.3 › Key Concepts
Hash Function
Converts keys to indices; good distribution minimizes collisions.
Collision
Two keys mapping to the same bucket; handle with chaining or probing.
Load factor
The ratio of stored elements to table size; affects performance and determines when to resize.
Final takeaway
Choose binary search for sorted, mostly-static data with many queries; choose hashing for dynamic datasets and many inserts or lookups, while planning for collisions and resizing.
