Module 1 › Chapter 3.3 › Iterative Binary Search
Code (iterative)
#include <stdio.h>

// Function to perform iterative binary search
int binary_search_iterative(int arr[], int size, int target) {
  int low = 0;
  int high = size - 1;

  while (low <= high) {
    int mid = low + (high - low) / 2; // Prevent potential overflow

    if (arr[mid] == target) {
      return mid;
    }

    if (arr[mid] < target) {
      low = mid + 1;
    } else {
      high = mid - 1;
    }
  }

  return -1; // Target not found
}
Testing notes
Always test with targets at the start, middle, end, and absent values. These cases reveal off-by-one errors and improper loop conditions.
Concrete example
Using the provided sorted array, searching for 23 returns index 5; searching for 100 returns -1.
Key Takeaway

Compute mid safely and update low/high with mid+1 or mid-1. Test both hits and misses.
