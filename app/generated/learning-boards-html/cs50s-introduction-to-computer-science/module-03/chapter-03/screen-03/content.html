Practical check
If data changes frequently and you need many queries, hashing can be preferable. If data is stable and sorted or you need order, binary search is ideal.
Reflection
Which would you pick for a dynamic address book that must support inserts and fast lookups? Think about the cost of maintaining order versus handling collisions.
