Module 1 › Chapter 3.3 › Hashing Basics
Core terms
  • Hash function — maps keys to integer indices.
  • Hash table — array of buckets or slots indexed by hashes.
  • Collision — two keys map to the same index.
Simple example
With table size 10 and h(key) = key % 10, inserting 42 goes to index 2; inserting 12 also maps to 2, causing a collision.
When to use hashing
Choose hashing when you need many fast insertions and lookups and can accept average-case guarantees given a well-designed hash function.
Caveat
Worst-case hashing can degrade to O(n) if collisions are poorly handled or the hash function clusters keys.
