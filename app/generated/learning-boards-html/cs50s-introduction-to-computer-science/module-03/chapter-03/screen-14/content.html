Module 1 › Chapter 3.3 › Key Concepts
Binary Search
Efficient search on sorted lists by repeatedly halving the search interval.
Divide and Conquer
Break a problem into smaller subproblems of the same type; binary search is a classic example.
Logarithmic Time
Halving the search space yields O(log n) comparisons, which scales well for large n.
Summary
Choose binary search for sorted data with many queries; choose hashing for dynamic datasets needing many inserts and lookups, while handling collisions carefully.
