Step trace (successful)
Array: [2,5,8,12,16,23,38,56,72,91]; target = 23.
  1. low=0, high=9, mid=4, arr[mid]=16 → 16 < 23 ⇒ low=mid+1=5
  2. low=5, high=9, mid=7, arr[mid]=56 → 56 > 23 ⇒ high=mid-1=6
  3. low=5, high=6, mid=5, arr[mid]=23 → match ⇒ return 5
Step trace (unsuccessful)
Pick a value not in the array, e.g., 20. The process halves until low > high, then return -1. This confirms loop termination and correct boundary updates.
Key Takeaway

Concrete traces help you reason about correctness and detect off-by-one errors early.

Check this
Try tracing targets at array bounds and between elements to ensure your implementation covers all cases.
