Starter code
#include <stdio.h>

int binary_search_recursive(int arr[], int low, int high, int target) {
  // Base case: empty interval
  if (low > high) {
    return -1;
  }

  int mid = low + (high - low) / 2;

  if (arr[mid] == target) {
    return mid;
  }

  if (arr[mid] < target) {
    return binary_search_recursive(arr, mid + 1, high, target);
  } else {
    return binary_search_recursive(arr, low, mid - 1, target);
  }
}
Activity
Implement the recursive function and run it on the sample array to verify index results for present and absent targets. Compare outputs with the iterative version.
Pro tip
Trace one recursive call by hand to ensure your low and high updates match the iterative logic and to verify the base case fires correctly.
Key Takeaway

Recursion expresses halving compactly, but you must ensure correct base case and index updates to avoid stack issues or missed elements.
