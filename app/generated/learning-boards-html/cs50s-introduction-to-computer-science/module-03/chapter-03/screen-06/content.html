Module 1 › Chapter 3.3 › Binary Search Steps
Step-by-step
  1. Set low = 0 and high = size - 1.
  2. While low <= high: compute mid = low + (high - low) / 2.
  3. Compare arr[mid] to target: if equal, return mid.
  4. If arr[mid] < target, set low = mid + 1; else set high = mid - 1.
  5. If loop ends, target not found; return -1.
Invariant and progress
Invariant: if the target exists it is in [low,high]. Each update reduces interval size, so the loop must terminate.
Concrete trace
Given [2,5,8,12,16,23,38,56,72,91] searching for 23: initial low 0, high 9, mid 4 gives 16 < 23 so low becomes 5; next mid 7 gives 56 > 23 so high becomes 6; next mid 5 equals 23 and returns index 5.
Common mistake
Using mid = (low + high) / 2 can overflow for extreme indexes in some languages; prefer low + (high - low) / 2.
