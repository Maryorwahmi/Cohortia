Searching Algorithms

Understand how algorithm choice changes performance. We'll contrast linear and binary search, step through C implementations, and introduce hashing so you can decide which lookup strategy fits your data.

In this lesson
Compare linear and binary search; implement binary search iteratively and recursively in C; analyze O(log n); and learn basic hashing concepts and collisions.
Why it matters
Choosing the right search approach can turn an infeasible operation on large datasets into something fast and practical.
Concept Preview
Linear vs Binary
Linear checks elements one-by-one. Binary halves the search space but needs sorted data.
Binary Search
Divide and conquer yields O(log n) comparisons for sorted arrays.
Hashing
Map keys to indices for average-case O(1) lookups; collisions require handling.
Explore Key Topics
Binary Search Mechanics
Low, high, mid and repeated halving for sorted arrays.
C Implementations
Iterative and recursive patterns with careful mid calculation.
Hashing Basics
Hash functions, tables, and simple collision strategies.
