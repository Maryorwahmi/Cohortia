Selection Sort steps
  1. Set boundary between sorted and unsorted at start.
  2. Scan unsorted portion to find index of minimum element.
  3. Swap found minimum with first unsorted position.
  4. Move boundary one position right and repeat until sorted.
Practical note: performs roughly the same number of comparisons regardless of initial order; swaps are limited to at most n-1.
Key Takeaway

Selection Sort reduces swaps but still requires O(n²) comparisons in every case, making it suitable when writes are expensive.

C implementation
void selection_sort(int arr[], int n) {
  int i, j, min_idx;
  for (i = 0; i < n - 1; i++) {
    min_idx = i;
    for (j = i + 1; j < n; j++) {
      if (arr[j] < arr[min_idx])
        min_idx = j;
    }
    int temp = arr[min_idx];
    arr[min_idx] = arr[i];
    arr[i] = temp;
  }
}
Try counting comparisons and swaps on input [64,25,12,22,11] to see one swap per pass but many comparisons scanning the unsorted region.
