Sorting Algorithms
Core techniques for ordering arrays: bubble, selection, insertion.
Orientation

You will trace each algorithm on small arrays, inspect C code examples, and compare their Big O behaviour for best, worst, and average cases.

Why it matters

Sorted data enables faster searching, merging, and predictable behavior for many higher-level algorithms.

Explore Key Topics
Bubble Sort
Compare adjacent items repeatedly until array is ordered.
Selection Sort
Find the minimum in the unsorted portion and swap to front.
Insertion Sort
Insert each item into an already-sorted prefix, like sorting cards in hand.
