Module 3 › Chapter 3.2 › What is sorting
Definition & examples

Sorting rearranges list elements into numerical or alphabetical order. Example orders include ascending numbers and lexicographic strings.

In-place
Sorts that reuse the original array with only a constant amount of extra memory. All three algorithms here are in-place.
Why it matters
Sorted data enables faster search, easier merging, and more predictable downstream processing.
Analogy

Sorting is like arranging a deck of cards so you can find a particular card quickly. If cards are unordered you must scan every card; if ordered you can find a range quickly.

Common misconception: simplicity equals suitability. While simple algorithms are easy to implement and reason about, they may not scale well. Always match algorithm choice to data size and existing order.
Key Takeaway

Sorted data enables faster algorithms; simple sorts teach core ideas but may not scale for large n.
