Module 3 › Chapter 3.2 › Bubble Sort Complexity
Complexity breakdown
Best Case
O(n) with swapped flag; one pass detects no swaps and exits.
Average Case
O(n²) for random order; many adjacent comparisons are needed.
Worst Case
O(n²) for reverse-ordered arrays; many swaps required.
Misconception check

Some believe Bubble Sort with swapped flag becomes competitive with better sorts. In practice the flag improves the best case only; average and worst remain quadratic. Insertion Sort often outperforms Bubble for nearly-sorted arrays due to fewer movements.

Concrete comparison: try arrays like [1,2,3,5,4,6]. Count swaps and comparisons for Bubble and Insertion to see the practical difference in constants even when both have favorable behavior.
Key Takeaway

Optimization reduces work for sorted inputs, but it does not change average or worst-case O(n²) behavior.
