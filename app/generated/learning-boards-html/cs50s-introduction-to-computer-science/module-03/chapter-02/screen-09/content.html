Module 3 › Chapter 3.2 › Algorithm Comparison
Bubble Sort
Comparisons: many adjacent pairs. Swaps: frequent. Best-case with optimization: O(n). Stability: can be stable.
Selection Sort
Comparisons: ~n²/2 always. Swaps: ≤ n-1. Stability: generally not stable.
Insertion Sort
Comparisons and shifts depend on disorder. Best-case O(n), good for nearly-sorted inputs. Stability: stable.
Experiment idea
Use the starter program to count comparisons and swaps for arrays in three orders: already sorted, random, and reversed. Observe how each algorithm’s counts change and relate that to Big O claims.
