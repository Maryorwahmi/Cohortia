Module 3 › Chapter 3.2 › Lab Walkthrough
Step 1 — Choose array
Pick a 5–7 element array such as [5,1,4,2,8]. Write it at the top of a table where each row will be a comparison or swap you observe.
Step 2 — Trace Bubble
Record each adjacent comparison and whether a swap occurred. Group observations by pass. Stop when a full pass has no swaps.
Step 3 — Trace Selection
For each pass record the index of the minimum and the single swap that moves it to the front of the unsorted portion.
Step 4 — Trace Insertion
Record how many elements are shifted for each insertion and where the key is placed.
Checkpoints
  • Do counts (comparisons, swaps) match expectations?
  • Which algorithm had the fewest swaps?
  • Was any algorithm noticeably faster for this small input?
