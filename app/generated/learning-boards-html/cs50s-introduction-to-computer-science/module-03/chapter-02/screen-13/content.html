Example Question
You have an array of 10 elements that is almost always sorted. Which algorithm and why? Write a two-paragraph justification: one about Big O and one about observed operations.
Model answer sketch: Insertion Sort is best because best-case O(n) and few shifts. Empirical note: count shifts on a sample to show small constants.
Reflection checklist
  • State input size and degree of disorder.
  • Give Big O classification for best, average, worst.
  • Support with one measured count or example.
