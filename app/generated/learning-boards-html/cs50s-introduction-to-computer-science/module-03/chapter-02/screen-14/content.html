Module 3 › Chapter 3.2 › Key Concepts
Sorting Algorithm
An algorithm that puts list elements in a specific order for easier processing and search.
In-place
All three sorts rearrange elements within the original array and use only a small constant of extra space.
Stability & Trade-offs
Bubble and Insertion can be stable; Selection generally is not. Choose based on data size, disorder, and write cost.
Summary Takeaway

Simple sorts teach core ideas and work for small or nearly-sorted data; for large data use O(n log n) algorithms which are far more efficient.
