If the array is already sorted, how many passes will the optimized version perform? Answer: one pass, because swapped remains false and the algorithm exits early.
Key Takeaway

Bubble Sort is easy to trace and can stop early with a swaps flag, but it still compares many adjacent pairs for large arrays.

C implementation (illustrative)
#include <stdio.h>
#include <stdbool.h>

void bubble_sort(int arr[], int n) {
  int i, j;
  bool swapped;
  for (i = 0; i < n - 1; i++) {
    swapped = false;
    for (j = 0; j < n - i - 1; j++) {
      if (arr[j] > arr[j+1]) {
        int temp = arr[j];
        arr[j] = arr[j+1];
        arr[j+1] = temp;
        swapped = true;
      }
    }
    if (swapped == false)
      break;
  }
}
Try instrumenting this code with counters for comparisons and swaps to see how many operations each pass performs for different input orders.
