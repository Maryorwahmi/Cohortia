Module 3 › Chapter 3.2 › Insertion Sort
How it works
Take the next element and insert it into the already-sorted prefix by shifting larger elements right.
Card-game analogy
You insert the next card into your sorted hand by sliding other cards to make room.
Example
Start [12,11,13,5,6] → insert 11 before 12 → result [11,12,13,5,6], continue until sorted.
C implementation
void insertion_sort(int arr[], int n) {
  int i, key, j;
  for (i = 1; i < n; i++) {
    key = arr[i];
    j = i - 1;
    while (j >= 0 && arr[j] > key) {
      arr[j+1] = arr[j];
      j = j - 1;
    }
    arr[j+1] = key;
  }
}
Try the array [1,2,3,5,4,6] and count shifts; insertion should perform very few shifts compared to bubble swaps.
