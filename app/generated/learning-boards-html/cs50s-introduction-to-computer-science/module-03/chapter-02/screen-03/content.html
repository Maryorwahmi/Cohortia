Module 3 › Chapter 3.2 › Learning Objectives
Lab Tasks
  • • Implement Bubble, Selection, and Insertion in one program and verify outputs.
  • • Create separate copies of the original array for each sort to ensure identical input.
  • • Add optional counters for swaps and comparisons and print them to compare efficiency.
  • • Trace small arrays step-by-step to visually confirm how elements move.
Mnemonic: copy, run, count, compare. This lab gives you empirical evidence that matches Big O reasoning for small and large n.
Assessment Idea
Answer scenario questions explaining which algorithm to choose and why, using both Big O and measured swap/comparison counts from your lab.
