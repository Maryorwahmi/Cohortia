Module 4 › Chapter 3.4 › Practice Goals
Practice & Strategy
Apply → Trace → Optimize

These objectives emphasize hands-on practice: write recursive functions, trace their call stacks, identify redundant work, and apply divide-and-conquer thinking.

01
Divide and conquer thinking

Identify how to split inputs into smaller instances that can be combined. This strategy underlies merge sort, quick sort, and many recursive algorithms.

Verified competency milestone
02
Implement recursive power function

Write and test a recursive power function using x^0 = 1 and x^n = x * x^(n-1). Validate results with sample inputs like 2^5 and 10^3.

Verified competency milestone
03
Recognize redundant recursion

Spot cases where recursive calls repeat work, and consider memoization or iterative solutions to improve performance.

Verified competency milestone
04
Trace call stack by hand

Predict return values by stepping through each push and pop. This practice helps validate base cases and uncover off-by-one errors.

Verified competency milestone
