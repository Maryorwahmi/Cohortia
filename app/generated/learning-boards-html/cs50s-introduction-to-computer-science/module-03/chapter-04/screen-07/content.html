Module 4 › Chapter 3.4 › Recursion vs Iteration
Recursive factorial
long long factorial(int n) {
  if (n == 0 || n == 1) return 1;
  else return n * factorial(n - 1);
}
Clear mapping to the mathematical definition, concise, but uses a frame per call on the stack.
Iterative factorial
long long factorial_iterative(int n) {
  long long result = 1;
  for (int i = 2; i <= n; i++) result *= i;
  return result;
}
Uses constant stack space and is often preferred for simple numeric problems where recursion adds unnecessary overhead.
When to use recursion
Problems with natural recursive structure or where clarity matters, like tree traversal.
When to prefer iteration
Simple repeated calculations or deep recursion that risks stack overflow.
