Module 4 › Chapter 3.4 › Key Concepts
Recursion
A function solving smaller instances of the same problem until a base case.
Base case & Recursive step
The base case stops recursion; the recursive step reduces the input toward that base case.
Call stack
Manages frames for active calls; popped frames return results to callers.
Summary takeaway

Design recursion intentionally: specify divide, base, and combine. Test with small inputs, hand-trace call frames, and prefer memoization or iteration when recursion repeats work or risks deep stacks.
