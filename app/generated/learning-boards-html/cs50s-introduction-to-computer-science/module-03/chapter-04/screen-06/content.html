Module 4 › Chapter 3.4 › Fibonacci inefficiency
Naive recursive code
#include <stdio.h>

int fibonacci(int n) {
  if (n == 0) return 0;
  else if (n == 1) return 1;
  else return fibonacci(n - 1) + fibonacci(n - 2);
}

// fibonacci(7) returns 13, but uses many repeated calls
Before running, sketch the call tree for fib(5) and count repeated nodes. That reveals exponential growth in the naive approach.
Call tree snapshot
fib(5)
fib(4) and fib(3)
fib(4) expands to fib(3) and fib(2)
fib(3) appears multiple times — repeated work
Optimization: memoization
Store previously computed fib(k) results and reuse them, reducing time to linear.
Alternative: iteration
An iterative loop computes Fibonacci in linear time using constant stack space.
Key Takeaway

Check for overlapping subproblems in recursive designs. If they exist, memoization or iteration is often necessary.
