What a stack frame holds
  • Function parameters and local variables
  • Return address to resume execution after the call
  • Saved registers or bookkeeping used by the runtime
Each recursive call creates a fresh frame. That is why local variables are not shared between calls, and why deep recursion consumes stack memory.

Common mistake

Confusing local state across frames. Each call has its own locals; do not rely on previous frames' values.
