Module 4 › Chapter 3.4 › Common mistakes
Top mistakes
  • Missing or wrong base case → infinite recursion
  • Not reducing the problem correctly in the recursive step
  • Assuming local variables are shared across calls
Debug tip: add prints that show the argument on function entry and on return. Hand-trace small inputs to validate the flow before bigger tests.
Quick debugging checklist
1. Base case present and correct?
2. Each recursive call reduces the input toward base case?
3. Any repeated subproblems that require memoization?
4. Test with n=0, n=1, and a small n to validate behavior
Common Pitfall

Relying on large inputs to test recursion hides termination errors. Start small and trace by hand.
