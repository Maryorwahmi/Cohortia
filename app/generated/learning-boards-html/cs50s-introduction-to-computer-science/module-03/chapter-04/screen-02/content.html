Learning Objectives
Learn → Understand → Apply → Master

Each card below describes a measurable skill. Practice by writing, tracing, and testing simple recursive programs in C.

01
Define recursion, base case, recursive step

Explain recursion as a function calling itself, identify the base case that stops calls, and the recursive step that reduces the problem size. This definition prevents infinite recursion and informs correct code design.

Verified competency milestone
02
Implement factorial and Fibonacci in C

Write correct recursive functions with clear base cases and test them on small inputs such as n = 0, 1, and 5 to validate behavior and results.

Verified competency milestone
03
Compare recursion and iteration

Describe trade-offs: recursion often improves readability for recursive structures, while iteration can be more efficient and avoids deep stacks.

Verified competency milestone
04
Explain the call stack and stack overflow

Describe how each recursive call pushes a stack frame and why missing base cases or excessive depth can exhaust stack memory, causing a stack overflow.

Verified competency milestone
