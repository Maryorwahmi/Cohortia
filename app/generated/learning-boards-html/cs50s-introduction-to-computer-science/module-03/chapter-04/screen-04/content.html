Module 4 › Chapter 3.4 › What is recursion?
Definition & Analogy

Recursion is a solution built from smaller instances of the same problem. Like nested dolls, each call contains a smaller call until you reach the smallest, solvable case.

Base Case
A condition that stops recursion, e.g., 0! = 1.
Recursive Step
Call the function with a smaller input that moves toward the base case.
Key Takeaway

A correct recursive design has a base case and a step that reduces the problem each call.

Concrete example: factorial explained
#include <stdio.h>

long long factorial(int n) {
  if (n == 0 || n == 1) {
    return 1;
  } else {
    return n * factorial(n - 1);
  }
}

// factorial(5) unfolds to 5 * 4 * 3 * 2 * 1
Trace the calls by writing out each frame: factorial(5) calls factorial(4) and so on until factorial(1) returns 1. Each return composes the final answer.
Common mistake
Omitting a base case causes infinite recursion and a stack overflow.
Pro tip
Start by writing the base case first, then the recursive step; that keeps you focused on termination.
