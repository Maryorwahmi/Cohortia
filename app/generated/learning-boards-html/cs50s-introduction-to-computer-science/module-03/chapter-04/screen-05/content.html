C implementation
#include <stdio.h>

long long factorial(int n) {
  if (n == 0 || n == 1) {
    return 1;
  } else {
    return n * factorial(n - 1);
  }
}

int main() {
  printf("Factorial of 5 is %lld
", factorial(5));
}
Run the program mentally: list each active call and its n. That list is the call stack. Confirm the base case and the order of returns.

Key Takeaway

Work backward: base case returns, then each frame computes its result as frames pop.
