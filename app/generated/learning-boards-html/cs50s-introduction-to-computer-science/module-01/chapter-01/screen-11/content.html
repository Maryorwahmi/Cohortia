Code-like pseudocode
# Assume list has at least one element
best = list[0]
for each item in list[1..end]:
  if item > best:
    best = item
return best
This pseudocode intentionally avoids language-specific syntax and focuses on the exact mechanics and assumptions.
Worked example
Input: [3, 7, 2, 7] → best=3 → compare 7 → best=7 → compare 2 → keep 7 → compare 7 → keep 7 → return 7.
