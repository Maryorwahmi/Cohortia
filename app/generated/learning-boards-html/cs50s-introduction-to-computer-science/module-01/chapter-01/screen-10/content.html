Module 1 › Chapter 1.1 › Algorithm
Definition

What an algorithm is

A precise, finite set of instructions that solves a problem. Ambiguity is not allowed; every step must be executable.

Concrete example
A tea-making algorithm: boil water, place bag, pour, steep 3 minutes, remove bag, serve. Each step is specific and testable.
Key Takeaway

Write algorithms with explicit steps and consider efficiency for large inputs.

Design note
When writing an algorithm, state initial conditions, the exact steps, termination criteria, and what to do in edge cases. This prevents ambiguity and makes testing possible.
Misconception
An algorithm is not just code: it is a plan that can be expressed in words, diagrams, or code.
Check your understanding
Write steps to find the maximum of a list and identify any ambiguous phrases to refine.
