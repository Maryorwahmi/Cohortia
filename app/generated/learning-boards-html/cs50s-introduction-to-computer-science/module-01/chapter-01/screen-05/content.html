Definition

Bits and bytes explained

A bit holds 0 or 1. A byte is 8 bits and can encode 256 values. This is how electrical states map to information.

Why bytes matter
Bytes provide a practical unit for characters and small data values; many standards use 8-bit groupings.
Concrete example
A text character like 'A' can be represented by a single byte in ASCII.
Key Takeaway

Bits combine into bytes, and bytes are the common unit for storing characters and small values.

Place value in binary
Binary digits represent powers of two: 2^0, 2^1, 2^2, etc. Reading right to left, each bit doubles the value range.
Example: 101 = 1×4 + 0×2 + 1×1 = 5.
Capacity question
Six bits can represent 64 values because 2^6 = 64.
Misconception
Binary is not mystical; it's base two place-value arithmetic, like decimal but with powers of two.
