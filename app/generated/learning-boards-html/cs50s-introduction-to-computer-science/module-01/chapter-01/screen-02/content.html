Learning Objectives

Four practical competencies to check as you learn.

Bloom: Learn → Understand → Apply → Master
01
Define computer science
Explain CS as the study of computation, not just coding. This helps you ask better questions about system design.
VERIFIED COMPETENCY MILESTONE
02
Explain binary representation
Describe bits and why base two maps to on/off states; this reasoning is critical for storage and encoding.
VERIFIED COMPETENCY MILESTONE
03
Perform conversions
Convert small binary numbers to decimal and vice versa using powers of two; this builds numeric intuition about capacity.
VERIFIED COMPETENCY MILESTONE
04
Describe hardware roles
Name and explain CPU, RAM, and storage and why software needs these components to run and persist data.
VERIFIED COMPETENCY MILESTONE
Tip: Use the hands-on activity to self-check conversions and capacity questions.
