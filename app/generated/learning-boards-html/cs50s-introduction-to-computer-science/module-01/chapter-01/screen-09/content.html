Architecture

CPU, RAM, Storage

These three components collaborate to run programs. Understanding their roles explains performance and persistence characteristics.

CPU
Executes instructions, performs computation, coordinates data flow.
RAM
Volatile, fast access memory for active programs and data.
Storage
Persistent long-term storage such as HDDs and SSDs.
Concrete example: opening an application loads executable code and data from storage into RAM, then the CPU fetches and runs that code, reading and writing data in RAM and saving to storage when you save the document.
Why it matters
Performance tuning and debugging often involve knowing which component is the bottleneck: CPU speed, available RAM, or storage throughput.
Misconception
RAM is not persistent—expect data loss on power-off unless saved to storage.
