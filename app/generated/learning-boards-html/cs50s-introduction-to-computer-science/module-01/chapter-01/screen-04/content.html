Module 1 › Chapter 1.1 › Computer Science vs Programming
Definition

What each term means

Computer science studies computation, efficiency, and representation. Programming writes the instructions that implement ideas.

Analogy
Like cookery versus chopping: the craft and the planning are different but related.
Concrete example
Choosing a sorting method is a CS decision; writing the code is programming.
Key Takeaway

Treat programming as a skill and CS as the framework that guides which skills to apply.

Compare
Computer Science
  • Theory and limits
  • Representations and algorithms
  • Analysis of efficiency
Programming
  • Writing executable code
  • Using languages and APIs
  • Testing and debugging
Misconception
Knowing a language doesn’t imply understanding algorithmic efficiency or representation choices.
Pro tip
When solving a problem, first design an algorithm before writing code to implement it.
