Module 2 › Chapter 1.3 › Integer vs Float Division
Integer division
Both operands are integers; the result is an integer with fractional part truncated. Example: 10 divided by 3 yields 3.
Why it trips up beginners
Students often expect decimals and forget that types control the operation's result.
Floating-point division
If one operand is float or double, the result is floating-point. Example: casting one integer to float yields a decimal quotient like 3.33.
int a = 10;
int b = 3;
printf("Int: %i
", a / b);
printf("Float: %.2f
", (float)a / b);
Try it

Change the cast to double and observe the precision difference, then format the output to two decimals for readable results.
