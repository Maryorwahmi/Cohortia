Module 2 › Chapter 1.3 › Key Concepts
Variable
A named storage location in memory that holds a value.
Data Type
Specifies what kind of data a variable can hold and how it’s stored.
Input & Output
Use format specifiers for printing; pass addresses to scanf to store input into variables.
Final takeaway

Type choices, matching format specifiers, and correct use of addresses for input are the foundations of reliable C programs.
