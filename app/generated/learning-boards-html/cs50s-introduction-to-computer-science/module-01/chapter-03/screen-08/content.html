Module 2 › Chapter 1.3 › scanf & Address-of
How it works
scanf reads formatted input and stores it at the memory address you provide. The address-of operator gives that address. Without it, scanf does not know where to put the input.
Analogy
Handing a delivery driver the box's address so they can put the package inside, rather than giving them the package and expecting them to find the box.
Warning

Forgetting the address-of operator often leads to a segmentation fault because the function tries to write to an invalid address.

Code example
#include <stdio.h>

int main(void)
{
  int user_age;
  printf("Please enter your age: ");
  scanf("%i", &user_age); // '&' gives scanf the address to store the value
  printf("You are %i years old.
", user_age);
  return 0;
}
Run this and enter a number to observe successful input storage. Then try removing & to see the runtime error and understand why the address is required.
