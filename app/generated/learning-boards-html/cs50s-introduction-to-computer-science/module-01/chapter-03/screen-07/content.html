Specifiers to remember
  • %i or %d for integers.
  • %f for floating-point numbers; use format like %.2f for two decimals.
  • %c for single characters; %s for strings (covered later).
Common confusion
Using the wrong specifier will not convert the value; it tells the print function how to interpret the bits you pass.
Key Takeaway

Always align placeholders with variable types and pass variables in the precise order to avoid incorrect output.

Example code
#include <stdio.h>

int main(void)
{
  int id = 12345;
  double avg = 87.45678;
  char grade = 'B';
  printf("ID: %i
Average: %.2f
Grade: %c
", id, avg, grade);
  return 0;
}
This prints the average with two decimals. Try changing %.2f to %.1f to see the effect on rounding and readability.
