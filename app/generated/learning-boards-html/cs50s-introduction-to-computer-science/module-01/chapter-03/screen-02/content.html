Declare & initialize
Write declarations like int age; and initialize with int score = 100; to give variables an initial value.

02
Use core data types
Choose int, float, double, char, or bool depending on the value’s nature and precision needs.
VERIFIED COMPETENCY MILESTONE
03
Print with specifiers
Use %i, %f, %c and precision like %.2f so output is interpreted correctly by readers and the runtime.
VERIFIED COMPETENCY MILESTONE
04
Read input safely
Use scanf with the address-of operator so the input is stored in the correct memory location.
VERIFIED COMPETENCY MILESTONE
How you will practice
  • Declare and initialize variables in short code snippets.
  • Match types to values and use format specifiers to print results.
  • Use scanf to read from the console and inspect behavior when forgetting &.
Ready check

You will complete a small program that reads two numbers and prints arithmetic results to demonstrate all four objectives.
