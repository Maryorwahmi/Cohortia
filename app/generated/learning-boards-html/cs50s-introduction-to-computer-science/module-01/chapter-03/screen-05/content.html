Module 2 › Chapter 1.3 › Declaring & Initializing
Rules & best practices
  • Write the type, then the name, then optionally = initial value, then semicolon.
  • Use meaningful names like student_id or average_score.
  • Initialize when you need a known start to avoid garbage values.
Common pitfall
Forgetting the f suffix for float literals can lead the literal to be treated as double in some contexts; be explicit when you need single precision.
Try this

Declare and initialize three variables of different types, then print them to confirm values match expectations.

Code example
#include <stdio.h>

int main(void)
{
  int score = 100;
  float price = 9.99f; // 'f' suffix for float literal
  char grade = 'A';
  printf("Score: %i
Price: %.2f
Grade: %c
", score, price, grade);
  return 0;
}
Observe that each variable was both declared and initialized. Run and confirm that price prints with two decimal places using %.2f.
