Checklist for safer code
  • Use descriptive variable names for readability and maintenance.
  • Initialize variables to sensible defaults to avoid garbage values.
  • Validate input by checking scanf's return value in robust code.
  • Prefer double for decimal math and cast explicitly when needed.
Small code guard
Check that scanf returns 1 when expecting a single integer before using the value, and handle the error case appropriately.
Example guard
int n;
if (scanf("%i", &n) != 1) {
  printf("Invalid input
");
  return 1;
}
This simple check makes the program more robust when users enter unexpected text.
