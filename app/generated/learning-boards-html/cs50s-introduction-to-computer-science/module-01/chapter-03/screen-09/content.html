Module 2 › Chapter 1.3 › scanf: Correct vs Incorrect
Correct
int value;
scanf("%i", &value); // address provided
printf("Value: %i
", value);
This form safely writes the input into the variable's memory location.
Incorrect
int value;
scanf("%i", value); // missing '&' — undefined behavior
printf("Value: %i
", value);
This often causes a crash because the function tries to write to an invalid address. Always include the ampersand.
Developer tip

When testing input code, start with simple types and a single scanf call so you can quickly observe correct storage and errors.
