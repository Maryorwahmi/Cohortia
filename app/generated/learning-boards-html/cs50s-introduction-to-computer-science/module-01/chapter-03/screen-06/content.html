Type hierarchy & usage
int
Whole numbers like counts, indices, or IDs. Example: int age = 21;
float
Single precision decimals. Example: float temp = 36.6f;
double
Double precision decimals for accuracy. Example: double pi = 3.14159;
char
Single character in single quotes. Example: char grade = 'A';
bool (from stdbool.h)
Stores true or false for logical conditions. Example: bool is_active = true;
Misconception

Assuming float precision is always enough. For many calculations, double is the safer default to avoid rounding errors.

Quick examples
int count = 10;
double average = 87.256;
char initial = 'Z';
bool done = false;
Use these small snippets to test printing and behavior in short programs.
