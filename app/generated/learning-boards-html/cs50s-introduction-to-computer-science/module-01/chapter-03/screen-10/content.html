Module 2 › Chapter 1.3 › Arithmetic Operators
Operator list
  • Addition: +
  • Subtraction: -
  • Multiplication: *
  • Division: / (integer or floating behavior depends on operand types)
  • Modulo: % (remainder of integer division)
Pitfall
Integer division truncates the decimal. To get a decimal result, cast at least one operand to float or use float literals.
Key Takeaway

To preserve fractional parts, operate with floating-point numbers or cast integers before division.

Example calculations
int a = 10;
int b = 3;
printf("Sum: %i
", a + b);         // 13
printf("Quotient (int): %i
", a / b); // 3
printf("Remainder: %i
", a % b);    // 1
printf("Quotient (float): %.2f
", (float)a / b); // 3.33
Try casting only one operand to see the difference in division results and confirm the printed decimal places match expectations.
