Module 2 › Chapter 1.3 › Learning Objectives
01 — Declare & Initialize
Create variables and give them starting values to avoid unpredictable contents. Example: int age = 30; confirms the variable holds 30 when printed.
VERIFIED COMPETENCY MILESTONE
02 — Choose Types
Pick int for whole numbers, float/double for decimals, char for single characters, and bool from stdbool.h for logical flags.
VERIFIED COMPETENCY MILESTONE
03 — Print Correctly
Match %i with integers, %.2f with floats for two decimals, and %c for characters. Wrong matches produce incorrect output or warnings.
VERIFIED COMPETENCY MILESTONE
04 — Read Input Safely
Use scanf with the address-of operator so input is stored in the variable's memory. Observe the failure when you omit & and then fix it.
VERIFIED COMPETENCY MILESTONE
Quick mnemonic

Name the box, pick the size, tell the printer, give the address. This four-step checklist helps avoid common beginner mistakes.
