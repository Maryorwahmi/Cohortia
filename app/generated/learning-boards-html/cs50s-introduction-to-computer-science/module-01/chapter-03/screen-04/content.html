Module 2 › Chapter 1.3 › What is a Variable?
Definition & analogy

Think of variables as labeled boxes in memory. The type on declaration decides how big each box is and what can be stored inside.

Analogy
Label the box "age" and put the number 30 inside. The label makes it easy to find and use later.
Common mistake
Assuming an uninitialized variable contains zero. In C it contains whatever bits were present unless you initialize it.
Key Takeaway

Declare with a type and initialize to define a starting value; otherwise expect unpredictable contents.

Concrete example
#include <stdio.h>

int main(void)
{
  int age = 30;      // a named integer box with initial value 30
  char initial = 'A'; // a char box holding a single character
  printf("Age: %i
Initial: %c
", age, initial);
  return 0;
}
Run this to confirm the boxes contain the expected values. If age were not initialized, printing could show an unexpected number.
