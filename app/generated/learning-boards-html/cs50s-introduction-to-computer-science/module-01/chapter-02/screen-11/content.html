Personalized Greeting Steps
  1. Save the starter program as greeting.c in your editor.
  2. Change the text inside the print call to a custom message and save.
  3. Compile with a compiler command to create an executable.
  4. Run the executable and observe the custom output.
  5. Experiment: remove the newline and re-run; then restore it.
  6. Optional: remove a semicolon intentionally, compile, read the error, then fix it.
Concrete example
Change the greeting to include your name, recompile, and verify that the output shows your personalized message followed by a newline if included.
