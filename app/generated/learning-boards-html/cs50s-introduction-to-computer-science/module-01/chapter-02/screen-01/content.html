Your First C Program: Hello, World!
A short, practical introduction to writing, compiling, and running a simple C program.
In this lesson
Write a minimal program, use a compiler, and observe program output.
Why it matters
This workflow is the foundation for all compiled languages and for understanding program behavior.
Quick orientation
  • Source code is human-readable text saved with a .c extension.
  • The compiler translates source into an executable binary.
  • The operating system runs the executable, producing console output.
Explore Key Topics
Source & File
Naming the file with .c and saving your source code.
Compile
Use clang or gcc to produce an executable from source.
Run & Output
Execute the program and inspect console output and errors.
Concept Map
How source becomes output
Source File
hello.c
Compiler

Executable
hello (machine code)
Run
./hello → prints text to terminal
Getting ready
Open a text editor, save a file named hello.c, and keep a terminal ready. We’ll type, compile, and run together.
