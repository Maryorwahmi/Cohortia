Module 1 › Chapter 1.2 › Source File
Definition and attributes
A source file is plain text, saved with a .c extension, containing C code that the compiler will process.
Why the extension matters: editors and compilers use it to recognize language syntax and apply the correct processing rules. Keeping descriptive filenames prevents confusion when you compile and run multiple programs.
Example
Save the following as hello.c and later compile it with a compiler command. The file itself is editable text you change while learning.
#include <stdio.h>

int main(void)
{
  printf("Hello, World!
");
  return 0;
}
Common misconceptions
  • Myth: You edit the executable. Reality: Edit source and recompile; the executable is generated.
  • Myth: Extension doesn't matter. Reality: Missing correct extension can confuse tools and editors.
Try this
Create a file named hello.c, paste the example, save, and prepare to compile in the terminal.
