Annotated example
#include <stdio.h>    // provides declarations for input/output

int main(void)         // program entry point, returns an int
{                      
    printf("Hello, World!
"); // call to print function, 
 moves to next line
    return 0;           // exit status: zero typically means success
}
Each punctuation mark and keyword contributes to the program's meaning. For example, quotes denote string literals and semicolons terminate statements. Misplacing or omitting one symbol often causes the compiler to stop parsing and report an error nearby.
Misconception check
The include does not insert runnable code; it provides declarations so the compiler knows about library functions.
Compact explanations
  • String literal: text inside quotes printed exactly.
  • Escape sequence: backslash followed by a letter that modifies output, such as newline.
  • Return value: communicates program status to the system.
Key Takeaway
Learn the role of each line and each piece of punctuation; this makes diagnostics actionable.
