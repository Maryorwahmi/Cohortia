What main does
main is the entry point where program execution begins. It returns an integer to the operating system indicating success or failure.
A typical declaration uses an integer return type and no parameters for beginner programs. Returning zero conventionally means the program succeeded.
Analogy
Think of main as a room you enter to run the program. When you leave, you hand the operating system a number that says whether the visit was successful.
Quick note
Even if you omit an explicit return in some environments, returning zero is good practice to signal success and avoid ambiguity when programs get larger.
Key takeaway
Declare main and return a value to communicate program status to the system; zero usually means success.
