Key punctuation
  • Semicolon: ends a statement.
  • Quotes: delimit string literals.
  • Braces: group statements into a block for functions and control structures.
Compiler message tip
If the compiler points at a line that looks fine, look at the line above for a missing semicolon or unmatched punctuation.
Example error scenario
If you remove the semicolon from a print statement, recompile and expect an error referencing the subsequent line. Fixing the missing semicolon typically resolves follow-on errors.
Try this
Intentionally remove a semicolon, compile, read the error, then restore the semicolon to see the change in messages.
