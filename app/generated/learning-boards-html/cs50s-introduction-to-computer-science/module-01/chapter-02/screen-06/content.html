What the preprocessor does
Preprocessor directives prepare source for compilation. The include directive makes declarations available to the compiler so it knows how to type-check function calls.
Example declaration
The standard input/output header declares the print function used to write text to the console, so the compiler recognizes calls to it.
Common mistake
Omitting the include leads to compiler warnings or errors about implicit declarations. Read the message: it points to where the compiler lacks a declaration.
Quick reference
Preprocessor directive example (visual only)
#include <stdio.h>
Key takeaway
Include headers to declare library functions before you call them; omission often causes compiler diagnostics.
