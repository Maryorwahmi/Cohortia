Module 1 › Chapter 1.2 › Quick Reference
Save Source
Use .c and save before compiling to ensure your edits are visible to the compiler.
Include stdio
Provide declarations for the print function so the compiler recognizes it.
Read compiler output
Fix the first error reported, then recompile. Warnings are helpful prompts to improve code quality.
Final prompt
Before your next compile: did you save, include headers you need, and balance punctuation? If yes, compile and learn from the output.
