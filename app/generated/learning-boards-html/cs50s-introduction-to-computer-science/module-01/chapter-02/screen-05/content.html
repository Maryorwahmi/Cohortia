Module 1 › Chapter 1.2 › Compile & Run
Three-step workflow
1
Save source
Write code in a text editor and save as hello.c so the compiler can read it.
2
Compile
Run the compiler with a command that names input and output. If errors exist, read them and fix the source.
3
Run
Execute the produced binary in the terminal and observe printed output or runtime behavior.
Terminal example
(save file) → (compile) → (execute)
clang hello.c -o hello
./hello
# Output:
# Hello, World!
Notes & mistakes
  • Forgetting to save means the compiler sees the old version of the file.
  • The compiler does not run the program; it only produces an executable when compilation succeeds.
  • Read the first error carefully — subsequent errors may cascade from it.
