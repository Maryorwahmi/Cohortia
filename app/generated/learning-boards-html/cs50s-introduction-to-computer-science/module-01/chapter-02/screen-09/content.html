The ability to control newlines is useful for formatting prompts and combining output across multiple print calls. When you see unexpected combined output, check whether the newline escape was omitted.
Common mistakes
  • Missing closing quote: leads to an unterminated string error.
  • Missing semicolon after the print statement: compiler reports a syntax error near the next line.
Pro tip
When experimenting, toggle the newline to see how output formatting changes; it helps debug display logic.
