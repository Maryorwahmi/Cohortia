Run SELECT before UPDATE/DELETE
A select using the same where clause shows which rows will be affected and is your first safety step.
Explicit Columns
List columns on INSERT
Listing columns makes inserts robust when a table gains new columns with defaults.
Transaction
Group related changes
Begin a transaction, run multiple commands, then commit or rollback to ensure atomicity.
Competency tip
Before performing a destructive change, write and run the select that would match your where clause. Confirm the exact rows returned, and then run the update or delete inside a transaction when changes are grouped.
