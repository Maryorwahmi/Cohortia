Definition

DELETE rows with care

A delete removes rows permanently in most systems. Confirm the scope before you run it.
Example
DELETE FROM Students
WHERE StudentID = 1003;
Danger
Omitting WHERE removes every row. Treat deletes as high-risk actions.
Safety check
Run SELECT with the same WHERE to preview rows that will be deleted.
Key Takeaway

Deletes are irreversible in many contexts. Preview affected rows and consider soft deletes or transactions for recoverability.
