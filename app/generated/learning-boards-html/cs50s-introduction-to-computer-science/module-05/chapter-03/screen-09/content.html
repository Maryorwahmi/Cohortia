Insert a new inventory item
-- 1. Insert a new item
INSERT INTO Inventory (ItemID, ItemName, Quantity, LastUpdated)
VALUES (4, 'Doodad D', 100, '2023-10-26');

-- Confirm the row was added
SELECT *
FROM Inventory
WHERE ItemID = 4;
Check for primary key conflicts and validate the LastUpdated format your database uses. If ItemID is auto-increment, omit it and list only the other columns.

After running the insert and select, you should see a row where ItemID is 4, ItemName is Doodad D, Quantity is 100, and LastUpdated is the date you set.
