Delete Gizmo C and safety select
-- 4. Delete Gizmo C
DELETE FROM Inventory
WHERE ItemID = 3;

-- Verify deletion
SELECT *
FROM Inventory
WHERE ItemID = 3;

-- 5. Bonus: Safety check for deleting items with quantity < 100
SELECT *
FROM Inventory
WHERE Quantity < 100;
The bonus select shows which rows match a bulk delete condition. Confirm these rows carefully before running a delete without a scoped where clause.
After delete
A select by id should return no rows once deletion is complete. If using transactions you can rollback instead of committing until verified.
Key Takeaway

A select preview prevents accidental large deletions. Consider soft deletes or transactions for recovery when needed.
