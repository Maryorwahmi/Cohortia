Update with SET

Use SET to assign new values and WHERE to narrow which rows change. Multiple columns can be set together.
Example
UPDATE Students
SET Major = 'Data Science'
WHERE StudentID = 1001;
Misconception: omitting WHERE updates all rows. Always preview with select, then update.
Update multiple columns
Assign several columns in one statement — useful when a single change affects multiple fields.
UPDATE Students
SET Major = 'Data Science', GPA = 4.0
WHERE StudentID = 1001;
Safety practice
Run SELECT with the same WHERE to confirm affected rows before updating.
Tip
Include a timestamp column to record when updates occur, and update it together for traceability.
