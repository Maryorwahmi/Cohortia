Module 5 › Chapter 5.3 › Cheat Sheet
Preview before change
Run SELECT with the intended WHERE to confirm which rows will be affected.
List columns on INSERT
Explicit column lists avoid order-related errors and are robust to schema changes.
Group with TRANSACTION
Begin a transaction for multi-step changes, then commit or rollback after verification.
Final thought
Adopt these habits every time you write DML and you will prevent most accidental data incidents in practice.
