Module 5 › Chapter 5.4 › Key Concepts
Relational Design
Structure entities as tables and link with keys to avoid duplication.
Normalization (1NF–3NF)
Apply atomicity, full-key dependency, and remove transitive dependencies.
INNER vs LEFT JOIN
INNER returns only matching rows; LEFT returns all left-table rows with NULLs for missing matches.
Final Takeaway

Design for one source of truth. Normalize to manage updates; use joins to reconstruct the view you need while ensuring the join condition reflects the correct keys.
