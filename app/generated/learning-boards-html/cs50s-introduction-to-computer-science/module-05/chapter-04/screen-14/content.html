Module 5 › Chapter 5.4 › Hands-on: Orders & Customers
Starter code — INNER JOIN
-- 1. INNER JOIN Customers and Orders
SELECT
  C.FirstName,
  C.LastName,
  O.OrderID,
  O.TotalAmount
FROM
  Customers AS C
INNER JOIN
  Orders AS O ON C.CustomerID = O.CustomerID;
This returns only orders that have matching customers. Orders that reference non-existent customers are excluded.
Starter code — LEFT JOIN
-- 2. LEFT JOIN Customers and Orders
SELECT
  C.FirstName,
  C.LastName,
  O.OrderID,
  O.TotalAmount
FROM
  Customers AS C
LEFT JOIN
  Orders AS O ON C.CustomerID = O.CustomerID;
This returns all customers. Customers without orders will have NULL for OrderID and TotalAmount.
Tip: compare row counts between the two queries to validate expected behavior.
