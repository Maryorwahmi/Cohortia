Module 5 › Chapter 5.4 › Key Concepts
Model entities
Give each real-world thing its own table and reference it by keys.
Normalize to 3NF
1NF: atomic; 2NF: full key dependency; 3NF: no transitive dependencies.
Choose JOINs
INNER for matches only; LEFT to include all left-side rows with NULLs for no match.
Summary takeaway

Design first for correctness and consistency. Use normalization to centralize facts and JOINs to present the combined view you need.
