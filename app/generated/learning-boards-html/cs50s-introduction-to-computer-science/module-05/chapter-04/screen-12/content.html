Module 5 › Chapter 5.4 › Common JOIN Mistakes
Mistake checklist
  • Missing ON: produces Cartesian product.
  • Wrong columns: join on non-related columns or wrong types.
  • Wrong join type: choose INNER vs LEFT carefully.
  • Aggregate traps: joins can duplicate rows before aggregation.
Quick debugging steps
1) Run each table SELECT alone to confirm keys and types.
2) Add the JOIN with ON and inspect a small sample of rows.
3) Check counts: compare row counts before and after join to spot unexpected increases.
Tip: use explicit column qualifiers like S.StudentID and E.StudentID to avoid ambiguous column names.
