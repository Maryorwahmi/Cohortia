Module 5 › Chapter 5.4 › LEFT JOIN
Example query
SELECT
  S.FirstName,
  S.LastName,
  E.CourseID,
  E.Grade
FROM
  Students AS S
LEFT JOIN
  Enrollments AS E ON S.StudentID = E.StudentID;
Explanation: all students appear. If no enrollment exists for a student, CourseID and Grade will be NULL. Use COALESCE to substitute defaults if needed.
Use case: auditing who has not enrolled in any course yet; LEFT JOIN surfaces those missing relationships.
Concrete output scenario
With four students and two enrollments, the LEFT JOIN returns four rows. The two students without enrollments will show NULL in CourseID and Grade columns, making it easy to identify them.
Misconception: LEFT JOIN will never return NULLs. In fact, NULLs are the indicator of missing matches from the right table.
