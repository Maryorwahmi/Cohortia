Module 5 › Chapter 5.4 › INNER JOIN
Example query
SELECT
  S.FirstName,
  S.LastName,
  E.CourseID,
  E.Grade
FROM
  Students AS S
INNER JOIN
  Enrollments AS E ON S.StudentID = E.StudentID;
Explanation: the ON clause matches StudentID values so only enrollments with existing students appear. Aliases S and E keep the SELECT readable.
Common mistake: leaving out ON produces a Cartesian product of Students and Enrollments, multiplying rows and returning incorrect results.
Concrete output scenario
If Students has Alice and Bob, and Enrollments only references Alice, the INNER JOIN returns only Alice's rows. Bob does not appear because he has no matching enrollment row.
Check your understanding
If an enrollment references StudentID 999 that does not exist, will the INNER JOIN include that enrollment? No — it will be excluded.
