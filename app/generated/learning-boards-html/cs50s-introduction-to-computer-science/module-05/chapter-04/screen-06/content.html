1NF — Atomic values

If a cell contains multiple values, split them into separate rows or use a linking table. This makes querying and updating reliable.

Example violation: a CoursesEnrolled column holding a comma-separated list for each student.
Fix: Create Enrollments rows, one per student-course pair, with StudentID and CourseID.
Misconception: using arrays within columns is convenient but reduces portability and query clarity for standard SQL.
Concrete scenario
Original: Students table with Courses='CS50,Math101'. Normalized: Students table with StudentID and a separate Enrollments table with a row for each StudentID and CourseID pair. This allows simple SELECT, INSERT, and DELETE operations for a single enrollment.
Check: When you add or remove one item from a multi-valued column, can you do it with a single INSERT or DELETE rather than string parsing?
