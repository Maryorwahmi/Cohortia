Learning Objectives

Bloom progression: Learn → Understand → Apply → Master
Learn → Understand → Apply → Master
01
Construct SELECT statements
Build queries that retrieve chosen columns from a single table and understand why selecting fewer columns improves performance.
Mnemonic: "Pick only what you need" (checkbox icon)
VERIFIED COMPETENCY MILESTONE
02
Use FROM to specify tables
Identify the table that contains your columns so the database knows where to read rows from, even when tables have similar column names.
Mnemonic: "Where to look" (map pin icon)
VERIFIED COMPETENCY MILESTONE
03
Apply WHERE for filtering
Write conditions using comparison operators to return only rows that meet your criteria, such as GPA thresholds or price limits.
Mnemonic: "Keep only matching rows" (filter funnel icon)
VERIFIED COMPETENCY MILESTONE
04
Combine conditions with logic
Use AND, OR, and NOT with parentheses to express complex filters without ambiguity and avoid common precedence mistakes.
Mnemonic: "Group to control order" (parentheses icon)
VERIFIED COMPETENCY MILESTONE
