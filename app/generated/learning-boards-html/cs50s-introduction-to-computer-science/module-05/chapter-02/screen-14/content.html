Module 5 › Chapter 5.2 › Key Concepts
SQL (Declarative)
Tell the database what you want, not how to compute it.
SELECT
Specifies which columns to return; prefer explicit lists in production.
FROM
Names the table that contains the columns you selected.
WHERE
Filters rows using comparison and logical operators to return only relevant data.
Comparisons
=, !=, >, <, >=, <= compare values and types matter.
Logic
AND narrows, OR widens, NOT negates; use parentheses to control precedence.
Summary takeaway

Use SELECT, FROM, and WHERE together to retrieve precise data. Test filters carefully and prefer explicit column lists for safety and performance.
