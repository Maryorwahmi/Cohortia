Module 5 › Chapter 5.2 › What is SQL?
Definition

SQL is declarative

You say what you want, not how to get it. This frees the database to optimize retrieval for you.

Concrete example
Request first and last names from Students and let the DB decide scanning or indexing.
Common misconception
Treating SQL like a step-by-step script and attempting procedural loops inside queries leads to complexity and poor performance.
Key takeaway
Write set-based, declarative queries and rely on the DB optimizer for execution details.
Analogy
Think of SQL as telling a librarian which books and pages you need rather than instructing them to walk through each shelf one by one.
Try this mentally
SELECT FirstName, LastName
FROM Students;
This small query declares the desired columns and table; the database chooses how to fetch them efficiently.
