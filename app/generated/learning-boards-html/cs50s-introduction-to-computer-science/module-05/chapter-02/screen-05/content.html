Module 5 › Chapter 5.2 › SELECT basics
Quick walkthrough
-- Inspect all columns quickly
SELECT *
FROM Students;

-- Then select only needed fields
SELECT FirstName, LastName
FROM Students;
Why list columns?
Less data to transfer and clearer outputs for reports or UI layers.
Misconception
SELECT * is convenient but may expose sensitive fields or harm performance at scale.
Concrete scenario
You need a class roster to display names only. Selecting just first and last names returns a compact, safe result suitable for a public page.
Takeaway
Key Takeaway

Prefer explicit column lists in production queries; use SELECT * only for quick inspection.
