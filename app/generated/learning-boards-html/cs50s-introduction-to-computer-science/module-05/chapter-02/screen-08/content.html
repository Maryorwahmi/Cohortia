Module 5 › Chapter 5.2 › WHERE fundamentals
Step-by-step
-- Find Computer Science majors
SELECT FirstName, LastName, Major
FROM Students
WHERE Major = 'Computer Science';

-- Numeric filter example
SELECT FirstName, LastName, GPA
FROM Students
WHERE GPA >= 3.5;
Notes
  • Strings use single quotes. Numbers are unquoted.
  • WHERE reduces rows returned; it does not change column selection.
  • Test complex filters incrementally to avoid logic errors.
Common mistake
Writing OR 'Math' without a column comparison makes the expression always true.
