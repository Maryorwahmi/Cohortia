Module 5 › Chapter 5.2 › Comparison operators
Common operators
  • = equals
  • != or <> not equals
  • > greater than
  • < less than
  • >= greater than or equal
  • <= less than or equal
Examples
SELECT ProductName, Price
FROM Products
WHERE Price > 100;

SELECT FirstName, LastName
FROM Students
WHERE GPA >= 3.5;
Case note
String comparisons may be case-sensitive depending on database settings; test or normalize values before comparing.
