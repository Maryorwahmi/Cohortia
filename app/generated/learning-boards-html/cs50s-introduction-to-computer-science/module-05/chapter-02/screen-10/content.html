Module 5 › Chapter 5.2 › Literals
Correct
SELECT ProductName, Price
FROM Products
WHERE Price > 100;

SELECT FirstName, LastName
FROM Students
WHERE Major = 'Computer Science';
Incorrect forms
-- Quoted number may coerce types
WHERE Price > '100';

-- Missing quotes around string is a syntax error
WHERE Major = Computer Science;
Tip
When in doubt, check the column type or run a sample query and inspect one or two rows to confirm behavior.
