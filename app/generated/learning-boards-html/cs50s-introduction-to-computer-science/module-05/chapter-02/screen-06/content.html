Module 5 › Chapter 5.2 › SELECT * vs specific
All columns
SELECT *
FROM Students;
Use for inspection and debugging when you need to see the full table layout quickly.
Risk
May expose columns you didn't intend to share and transfers extra data.
Specific columns
SELECT FirstName, LastName
FROM Students;
Choose specific columns for clarity, performance, and privacy.
When to prefer
Production queries, APIs, and public reports should select only the necessary fields.
