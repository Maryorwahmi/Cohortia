Module 5 › Chapter 5.2 › FROM clause

Purpose

Name the table that contains the columns you select so the database knows where to look for data.

SELECT FirstName, LastName
FROM Students;
Ambiguity note
If two tables have the same column name, qualify it using TableName.ColumnName to be explicit.
Concrete scenario
An application joining Courses and Students might have an ID column in each table; always qualify to avoid returning the wrong ID.
Key Takeaway

FROM tells the database which table to scan — it anchors column names and prevents ambiguity in queries.
