Module 6 › Chapter 5.5 › Avoiding Common Mistakes
Mistakes to avoid
  • Not closing connections and cursors (use finally to close).
  • Concatenating user input into SQL (use parameterized queries).
  • Forgetting to commit DML changes you expect to persist.
  • Not using transactions for related multi-step operations.
  • Hardcoding credentials in code; prefer environment variables.
Defensive practices
  • Validate input before sending to the database as an added safety layer.
  • Log errors without exposing sensitive data.
  • Use rowcount checks to detect missing updates and react accordingly.
  • Test rollback paths by simulating failures during transactions.
Check your app
Run the to-do manager through edge cases: duplicates, missing rows, invalid dates, and simulated exceptions to confirm your commits and rollbacks behave as intended.
