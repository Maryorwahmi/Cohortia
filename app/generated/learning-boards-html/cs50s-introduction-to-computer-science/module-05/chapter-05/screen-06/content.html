Example code (Insert, Select, Update)
import sqlite3

conn = sqlite3.connect('my_application.db')
cursor = conn.cursor()

# --- INSERT (Create) ---
username = "alice"
email = "alice@example.com"
try:
    cursor.execute("INSERT INTO users (username, email) VALUES (?, ?)", (username, email))
    conn.commit()
    print(f"User '{username}' inserted successfully.")
except sqlite3.IntegrityError:
    print(f"Error: User '{username}' already exists.")

# --- SELECT (Read) ---
cursor.execute("SELECT id, username, email FROM users WHERE username = ?", ("alice",))
user = cursor.fetchone()
if user:
    print(f"Found user: ID={user[0]}, Username={user[1]}, Email={user[2]}")
else:
    print("User 'alice' not found.")

# --- UPDATE ---
new_email = "alice.smith@example.com"
cursor.execute("UPDATE users SET email = ? WHERE username = ?", (new_email, "alice"))
conn.commit()
print(f"User 'alice' email updated. Rows affected: {cursor.rowcount}")
Practical notes
  • Use placeholders (!) and pass values as a tuple to avoid injection.
  • Check cursor.rowcount after UPDATE or DELETE to detect missing rows.
  • For large SELECT results, prefer fetchmany to avoid high memory use.
Common mistake
Forgetting conn.commit after DML: your change may not be visible to other connections or saved to disk.
