Module 6 › Chapter 5.5 › Key Concepts — Security
Cursor Object
Executes SQL statements and returns rows from the connection's pipeline.
Parameterized Queries
Placeholders separate SQL code from data values, preventing SQL injection attacks.
Transaction (Commit / Rollback)
A transaction groups statements so they either all succeed when committed or are undone on rollback.
Final takeaway: Apply parameterized queries, check row counts, and protect multi-step operations with transactions to keep data correct and secure.
