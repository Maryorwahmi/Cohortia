Module 6 › Chapter 5.5 › Preventing SQL Injection
Vulnerable pattern
import sqlite3

def search_products(product_name):
    conn = sqlite3.connect('products.db')
    cursor = conn.cursor()
    query = f"SELECT * FROM products WHERE name = '{product_name}'"
    cursor.execute(query)
    results = cursor.fetchall()
    conn.close()
    return results
This pattern concatenates user input into SQL and can allow injected commands to run.
Safe pattern (parameterized)
import sqlite3

def search_products_safe(product_name):
    conn = sqlite3.connect('products.db')
    cursor = conn.cursor()
    query = "SELECT * FROM products WHERE name = ?"
    cursor.execute(query, (product_name,))
    results = cursor.fetchall()
    conn.close()
    return results
The placeholder separates code from data. Even malicious-looking input is treated as a literal value, not executable SQL.
Check your understanding
Try the safe function with a string like "Laptop'; DROP TABLE products; --" and observe that it is treated as a search string and does not execute additional SQL.
