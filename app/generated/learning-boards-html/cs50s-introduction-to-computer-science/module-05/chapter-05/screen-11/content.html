Module 6 › Chapter 5.5 › To-Do Manager Plan
Step-by-step checklist
  1. Initialize: Create tasks table and set conn.row_factory to sqlite3.Row for readable output.
  2. Add: Insert with placeholders and commit on success.
  3. List: SELECT all tasks and print ID, description, due date, and status.
  4. Update status: UPDATE with placeholder, check rowcount, then commit.
  5. Delete: DELETE with WHERE and commit; confirm rowcount.
  6. Transaction: mark_task_as_critical_and_reschedule should update status then due_date, rollback on failure.
Pro tip
Validate user input such as date strings before inserting. Parameterized queries protect SQL, but validation improves data quality.
