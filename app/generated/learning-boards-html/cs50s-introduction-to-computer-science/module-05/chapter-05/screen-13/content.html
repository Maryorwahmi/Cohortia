Module 6 › Chapter 5.5 › Assessment Exercise
Vulnerable snippet
def search_products(product_name):
    conn = sqlite3.connect('products.db')
    cursor = conn.cursor()
    query = f"SELECT * FROM products WHERE name = '{product_name}'"
    cursor.execute(query)
    results = cursor.fetchall()
    conn.close()
    return results
Corrected snippet
def search_products_safe(product_name):
    conn = sqlite3.connect('products.db')
    cursor = conn.cursor()
    query = "SELECT * FROM products WHERE name = ?"
    cursor.execute(query, (product_name,))
    results = cursor.fetchall()
    conn.close()
    return results
Assessment steps
Run the vulnerable function with a malicious-looking string to demonstrate the risk, then run the safe version to show the input is treated as data. Write a short remediation note for the codebase explaining the fix and recommending input validation and tests.
