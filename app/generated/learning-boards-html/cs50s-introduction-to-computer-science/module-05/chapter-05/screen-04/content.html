Module 6 › Chapter 5.5 › Database Components
Definitions
Driver / Connector: Software that translates application calls into the database protocol. Example: sqlite3 in Python for SQLite files.
Connection object: Represents an open pipeline to the database file or server and manages transactions and resource handles.
Cursor object: Executes SQL, binds parameters, and fetches results. It does not load the whole table into memory by default.
Concrete example
Call sqlite3.connect with a filename to get a connection. Call connection.cursor to get a cursor. Use the cursor to execute SQL and fetch rows.
Common misconception
A cursor does not mean the whole table is in memory; rely on fetchone and fetchmany to control memory use. Also, forgetting to close the connection causes resource leaks.
Annotated pipeline
Driver / Connector → Connection object → Cursor → Execute SQL → Fetch results → Close cursor and connection. Each arrow carries requests and results; commit seals changes in the connection's transaction.
Key takeaway
Treat connections as long-lived handles you open and close deliberately; treat cursors as short-lived query tools used to run statements and fetch results.
