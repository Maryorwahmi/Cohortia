Module 6 › Chapter 5.5 › Key Concepts
Database Driver / Connector
Translates application requests into the database protocol so your code can run SQL and get results.
sqlite3
Python's built-in module for SQLite, ideal for file-backed learning projects and prototypes.
Connection Object
An open handle to the database that manages transactions and file or server resources.
Takeaway: Use the driver to get a connection, get a cursor to run SQL, protect queries with parameters, and group multi-step work in transactions.
