Module 5 › Chapter 5.1 › Mistakes & Tips
Common mistakes
  • Duplicating data across tables instead of normalizing.
  • Using mutable fields as primary keys.
  • Skipping foreign keys and letting invalid references appear.
  • Over-normalizing without considering query patterns.
Best practices
  • Sketch entities and relationships before coding.
  • Choose stable, minimal primary keys.
  • Add constraints in the schema to enforce rules.
  • Use join tables for many-to-many relationships.
