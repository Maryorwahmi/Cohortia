Module 5 › Chapter 5.1 › Database Schema
Definition

Schema = blueprint

A schema declares tables, columns, types, keys, and constraints that the database enforces.

Enforces data types and NOT NULL rules.
Defines UNIQUE constraints to avoid duplicates.
Specifies foreign keys for referential integrity.
Example snippet
CREATE TABLE Students (
  StudentID INT PRIMARY KEY,
  FirstName VARCHAR(50) NOT NULL,
  LastName VARCHAR(50) NOT NULL,
  Email VARCHAR(100) UNIQUE,
  EnrollmentDate DATE
);
Design tip
Define the schema early so constraints catch mistakes before code relies on faulty data.
