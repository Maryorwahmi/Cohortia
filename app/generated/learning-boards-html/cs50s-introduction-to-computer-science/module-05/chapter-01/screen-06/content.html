Definition

Tables, rows, columns

A table stores many rows, each with the same set of columns describing attributes of an entity.

Column: FirstName — attribute for every row.
Row: one student entry with values for each column.
Table: Students, the collection of student rows.
Common misconception
Rows are not ordered by default. If order matters, include a column to express it or use ORDER BY in queries.
Example
Students
StudentID | FirstName | LastName | Email
---------------------------------------
1         | Ada       | Lovelace | ada@example.com
2         | Alan      | Turing   | alan@example.com
Key Takeaway

Treat tables as collections of uniform records with named attributes and enforced types.
