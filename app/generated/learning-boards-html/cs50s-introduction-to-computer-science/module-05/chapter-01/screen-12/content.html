Module 5 › Chapter 5.1 › Library Schema Task
Steps
  1. Identify entities: Authors, Books, Borrowers, Loans.
  2. Define tables and attributes for each entity.
  3. Choose primary keys that are stable and unique.
  4. Add foreign keys to express relationships.
  5. Apply constraints like UNIQUE and NOT NULL where needed.
Starter template
-- Authors
CREATE TABLE Authors (
  AuthorID INT PRIMARY KEY,
  FirstName VARCHAR(50),
  LastName VARCHAR(50)
);

-- Books
CREATE TABLE Books (
  BookID INT PRIMARY KEY,
  Title VARCHAR(200) NOT NULL,
  AuthorID INT,
  ISBN VARCHAR(20) UNIQUE,
  PublicationYear INT,
  FOREIGN KEY (AuthorID) REFERENCES Authors(AuthorID)
);

-- Loans
CREATE TABLE Loans (
  LoanID INT PRIMARY KEY,
  BookID INT,
  BorrowerID INT,
  LoanDate DATE,
  ReturnDate DATE,
  FOREIGN KEY (BookID) REFERENCES Books(BookID),
  FOREIGN KEY (BorrowerID) REFERENCES Borrowers(BorrowerID)
);
Key Takeaway
Sketching a schema before coding clarifies relationships and reveals where constraints are required to keep data correct.
