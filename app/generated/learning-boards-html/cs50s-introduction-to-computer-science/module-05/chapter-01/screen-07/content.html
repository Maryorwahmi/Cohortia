Core Concept

Primary key

A unique, non-null column or combination of columns that identifies a row.

Benefits: uniqueness, efficient lookup, reliable joins.
Often implemented as an integer ID or a natural unique value if stable.
Key Takeaway

Use a stable, minimal key. Prefer a surrogate numeric ID when natural values can change.

Example
Students
StudentID (PK) | FirstName | LastName | Email
--------------------------------------------
1001           | Maya      | Patel    | maya@example.com
1002           | Juan      | Rivera   | juan@example.com
Misconception
Don't assume a natural field like email is immutable. Choose keys with stability in mind.
