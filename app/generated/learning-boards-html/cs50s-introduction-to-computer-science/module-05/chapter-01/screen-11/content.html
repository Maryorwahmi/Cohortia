Module 5 › Chapter 5.1 › Constraints
Constraint types
NOT NULL: prevents missing values in required columns.
UNIQUE: avoids duplicate values like duplicate emails or ISBNs.
FOREIGN KEY: enforces that references point to existing rows.
Benefit
Constraints move checks into the database so application code can rely on valid data.
Concrete example
CREATE TABLE Books (
  BookID INT PRIMARY KEY,
  Title VARCHAR(200) NOT NULL,
  ISBN VARCHAR(20) UNIQUE
);
Misconception
Constraints are not optional quality-of-life decorators — they are essential guards against corrupt data.
