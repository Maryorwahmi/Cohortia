Learning Objectives

Learn, understand, apply, and verify competency in database integration and security.
Learn
Understand

Master
01
Explain databases & persistence
Describe why in-memory lists lose data and how persistent storage keeps records between restarts. This helps you design applications that retain user content reliably.
VERIFIED COMPETENCY MILESTONE
02
Integrate SQLite with Flask
Configure SQLALCHEMY_DATABASE_URI and initialize Flask-SQLAlchemy so the app can open a site.db file and manage connections. This enables local development without a separate database server.
VERIFIED COMPETENCY MILESTONE
03
Define models & create tables
Write a Message model with id, text, author, and date_posted, and call db.create_all() in an application context to create tables on startup.
VERIFIED COMPETENCY MILESTONE
04
Perform CRUD from Flask routes
Use db.session.add and db.session.commit to create, Message.query to read, and commit changes for updates or deletes so your routes manage persistent records.
VERIFIED COMPETENCY MILESTONE
