Definition

ORMs and SQLAlchemy

An ORM maps classes to tables so you can manipulate rows as objects in your language instead of writing raw SQL. Flask-SQLAlchemy connects SQLAlchemy to the Flask app lifecycle.

Model concept
A model class defines columns as attributes, primary keys, defaults, and constraints. The ORM uses that to generate SQL table definitions.
Analogy
Think of the ORM as a translator between your Python code and the database language. You give it objects; it issues safe, parameterized SQL behind the scenes.
Model example
class Message(db.Model):
  id = db.Column(db.Integer, primary_key=True)
  text = db.Column(db.Text, nullable=False)
  author = db.Column(db.String(50), default='Anonymous')
  date_posted = db.Column(db.DateTime, default=datetime.utcnow)
Why this helps
Use class methods and attributes to query and modify data; SQLAlchemy handles safe parameter binding to prevent injection.
