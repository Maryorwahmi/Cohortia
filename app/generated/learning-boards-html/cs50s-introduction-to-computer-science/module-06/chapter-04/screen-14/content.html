Module 6 › Chapter 6.4 › Key Concepts
Database
Structured, persistent storage for application data that survives restarts.
ORM / SQLAlchemy
Map Python classes to tables and use safe parameterized queries rather than string concatenation.
CRUD
Create, Read, Update, Delete using db.session for changes and model.query for retrieval.
Summary Takeaway

Combine persistent storage with safe ORM patterns and basic output/input defenses to build reliable, secure Flask applications.
