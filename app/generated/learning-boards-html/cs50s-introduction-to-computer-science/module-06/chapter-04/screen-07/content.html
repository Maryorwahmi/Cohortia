Process Flow

Configure Flask-SQLAlchemy and create tables

Follow these steps to wire the database into your app and ensure tables exist before the app serves requests.
1. Install
Run pip install Flask-SQLAlchemy to add the extension to your environment.
2. Configure
Set SQLALCHEMY_DATABASE_URI = 'sqlite:///site.db' and SQLALCHEMY_TRACK_MODIFICATIONS = False in your app config.
3. Initialize
Call db = SQLAlchemy(app) so models and sessions attach to your Flask application.
4. Create tables
Use with app.app_context(): db.create_all() so table creation runs with the app configuration available.
Code snippet
from flask import Flask
from flask_sqlalchemy import SQLAlchemy

app = Flask(__name__)
app.config['SQLALCHEMY_DATABASE_URI'] = 'sqlite:///site.db'
app.config['SQLALCHEMY_TRACK_MODIFICATIONS'] = False
db = SQLAlchemy(app)

if __name__ == '__main__':
  with app.app_context():
    db.create_all()
  app.run(debug=True)
Common mistake
Calling create_all without an app context raises an error because the app config isn't available. Use the app context wrapper.
