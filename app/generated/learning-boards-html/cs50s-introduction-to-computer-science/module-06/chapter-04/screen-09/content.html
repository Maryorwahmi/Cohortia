Process Flow

CRUD from Flask routes: create and read

On POST create a model instance, add it to the session, and commit. On GET, query the model to retrieve records for rendering.

Create
new_message = Message(text=..., author=...); db.session.add(new_message); db.session.commit()
Read
messages = Message.query.order_by(Message.date_posted.desc()).all()
Error handling
Wrap commits in try-except to handle database errors and rollback if necessary. Keep transactions short in request handlers.
Code
@app.route('/', methods=['GET','POST'])
def index():
  if request.method == 'POST':
    message_text = request.form['message_text']
    author_name = request.form.get('author_name', 'Anonymous')
    if message_text:
      new_message = Message(text=message_text, author=author_name)
      db.session.add(new_message)
      db.session.commit()
    return redirect(url_for('index'))

  messages = Message.query.order_by(Message.date_posted.desc()).all()
  return render_template('index.html', messages=messages)
