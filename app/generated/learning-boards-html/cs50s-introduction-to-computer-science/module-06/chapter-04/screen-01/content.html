Databases & Security for Flask Web Apps
Understand how to add persistent storage to a Flask app using SQLite and SQLAlchemy, and learn essential security practices to protect user data.
Interactive 16:9 Masterclass
In this lesson

From short-lived lists to durable databases

We will replace an in-memory Python list with a SQLite database, move to an ORM-backed model, run simple CRUD operations from routes, and add defenses against SQL injection and XSS.

Why databases
Persistent storage for users, posts, and configuration.
Why ORMs
Work with Python objects and avoid manual SQL concatenation.
Why security
Protect databases and users from common attacks.
Why SQLite
Simple, file-based, ideal for development and small apps.
Coming up
Live coding: install Flask-SQLAlchemy, define the Message model, create tables, and refactor POST/GET routes. Then a security segment on SQL injection, XSS, and password hashing.
