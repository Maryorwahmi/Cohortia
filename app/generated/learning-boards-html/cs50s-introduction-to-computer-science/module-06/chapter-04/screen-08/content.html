Code Walkthrough

Define the Message model

Declare id, text, author, and date_posted with types and defaults so records have structure and useful defaults for new entries.

Best practices
  • Use primary keys to identify rows uniquely.
  • Use nullable=False for required fields to let the database enforce integrity.
  • Choose Text for long content, String for short fields like names.
Model example
class Message(db.Model):
  id = db.Column(db.Integer, primary_key=True)
  text = db.Column(db.Text, nullable=False)
  author = db.Column(db.String(50), default='Anonymous')
  date_posted = db.Column(db.DateTime, nullable=False, default=datetime.utcnow)

  def __repr__(self):
    return f"Message('{self.author}', '{self.text}', '{self.date_posted}')"
Debug tip
A readable __repr__ helps when inspecting objects in a console during development.
