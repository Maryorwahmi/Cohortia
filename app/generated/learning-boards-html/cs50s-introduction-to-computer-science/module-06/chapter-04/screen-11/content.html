Definition

SQL Injection

When user input is embedded into SQL syntax the input can change query meaning. Treat user input as data, not code.

Why it's dangerous
An attacker can bypass authentication, exfiltrate data, or modify records by changing the query logic via crafted input.
Prevention
Use an ORM or parameterized queries so the query structure and data are separate. Avoid concatenating user input into SQL strings.
Concrete contrast
Unsafe pattern
Concatenating strings to build SQL is fragile and opens injection paths.
Safe pattern
Use Message.query or prepared statements. The ORM sends user-provided values separately from the SQL structure.
Quick check
Audit code for any place where strings are combined to form SQL and replace with parameterization or ORM calls.
