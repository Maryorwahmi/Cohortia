Update and Delete operations

Load the object, modify attributes for updates, or call delete for removals, then commit the session to persist changes.
Update pattern
message = Message.query.get(id); message.text = 'new'; db.session.commit()
Delete pattern
message = Message.query.get(id); db.session.delete(message); db.session.commit()
Common mistake
Not verifying the object exists before operating. Check for None and return an appropriate response or error.
Example scenario
Two users edit the same post at once. Without checks, the later save will overwrite earlier edits. Consider simple timestamp comparisons or alerts to avoid accidental overwrites.
Pro tip
Keep transactions short and perform validation before committing to reduce conflicts and ensure data integrity.
Takeaway
Updates and deletes are simple but require presence checks and validation to be safe in a web context.
