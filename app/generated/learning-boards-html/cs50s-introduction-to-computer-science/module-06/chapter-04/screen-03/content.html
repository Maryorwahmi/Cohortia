Security & Best Practices

Build safe defaults into routes, templates, and data storage so user data remains protected as your app grows.
05
Recognize SQL injection & XSS
Identify inputs that affect queries and outputs that are rendered in pages, and understand how attackers abuse them to run queries or scripts.
VERIFIED COMPETENCY MILESTONE
06
Use ORM/parameterized queries
Rely on SQLAlchemy or parameter binding to keep data separate from query code and prevent injection attacks.
VERIFIED COMPETENCY MILESTONE
07
Sanitize and escape output
Trust Jinja2's default HTML escaping for user content and avoid using safe filters unless you have manually sanitized data.
VERIFIED COMPETENCY MILESTONE
08
Hash passwords & validate input
Never write plain-text passwords. Validate length and format on the server so your database only stores properly formed, hashed secrets.
