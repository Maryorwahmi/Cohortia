Module 6 › Chapter 6.5 › Ethical Frameworks Process
Process

Identify → Evaluate → Decide → Monitor

1. Identify stakeholders & harms

List users, bystanders, and third parties. Note privacy, safety, and equity risks for each.

2. Evaluate options against principles

Use principles like minimize harm, preserve autonomy, and fairness to score design choices.

3. Decide and document

Record the chosen design, tradeoffs, and tests required before launch.

4. Monitor and adapt

Set metrics to detect harm and a rollback plan. Revisit decisions as usage data appears.

Scenario application

For the Smart Notifications feature, options include local processing on device, anonymized server scoring, or explicit user opt-in. Evaluate each for privacy, autonomy, and bias, then pick the least-harmful design and document why.

Monitoring metric example

Track the rate of suppressed urgent messages that users later mark as missed. A rising rate suggests harmful suppression and triggers review.

Key Takeaway

Documented, repeatable processes make ethical reasoning concrete and allow teams to learn from outcomes.
