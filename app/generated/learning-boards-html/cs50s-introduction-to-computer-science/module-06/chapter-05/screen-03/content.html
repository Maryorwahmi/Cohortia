Module 6 › Chapter 6.5 › Learning Objectives — Applied Practice
Habits to adopt
Concrete routines that make ethical choices automatic.
01
Data minimization

Collect the least amount needed and set retention limits. Ask whether a field is required before storing it.

02
Bias testing

Run fairness metrics and check training data for skew. Treat bias reduction as part of model validation.

03
Explainability

Document how models make decisions and provide human-interpretable explanations when outcomes affect people.

04
Accessibility checks

Use semantic HTML, ARIA attributes, and contrast testing so services serve more users fairly.

Verification

Each habit should result in a measurable check. For example, retention policies, fairness test reports, explanation pages, and accessibility audits.

Scenario prompt

When adding a new analytics event, ask: do we need PII? Who can access it? When will we delete it?

Key Takeaway

Habits convert ethical principles into routine engineering steps that reduce risk and increase trust.
