What is the DOM?
  • The DOM is a tree of objects created by parsing HTML.
  • JavaScript accesses these objects with selection methods and updates properties like textContent or style.
  • Changes to DOM objects are reflected immediately in the page rendering.
Concrete Example
<h1 id="myHeading">Hello</h1>

// JavaScript
const heading = document.getElementById('myHeading');
heading.textContent = 'Updated by JavaScript!';
If the script runs before the h1 exists, document.getElementById returns null. Place the script after the element or use defer.
