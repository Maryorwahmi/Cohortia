Module 6 › Chapter 6.2 › Selecting & Updating
Step-by-step
  1. Ensure the element exists when the script runs.
  2. Select it with getElementById or querySelector.
  3. Update textContent or style properties to change the page.
Code Example
const heading = document.getElementById('myHeading');
if (heading) {
  heading.textContent = 'Text has been changed by JavaScript!';
  heading.style.color = 'red';
} else {
  console.log('Element not found');
}
Check for null to avoid runtime errors and use console.log to debug selection results.
