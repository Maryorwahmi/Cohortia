Module 6 › Chapter 6.2 › Counter Example
Starter code (script.js)
// Get references
const counterDisplay = document.getElementById('counterDisplay');
const incrementButton = document.getElementById('incrementButton');
const decrementButton = document.getElementById('decrementButton');

let count = 0; // state

function updateCounterDisplay() {
  counterDisplay.textContent = `Count: ${count}`;
}

incrementButton.addEventListener('click', function() {
  count++;
  updateCounterDisplay();
  console.log('increment to', count);
});

decrementButton.addEventListener('click', function() {
  if (count > 0) {
    count--;
    updateCounterDisplay();
    console.log('decrement to', count);
  } else {
    console.log('Cannot go below zero!');
  }
});

updateCounterDisplay();
Explanation
  • Use let for state so it can change over time.
  • Encapsulate display logic in updateCounterDisplay to avoid duplication.
  • Guard conditions prevent invalid state, like negative counts.
Check
Open the browser console to confirm console.log messages when clicking buttons.
