Module 6 › Chapter 6.2 › Script Inclusion
Comparison: inline • internal • external
Inline: quick, mixes markup and logic, not scalable.
Internal: part of HTML, okay for small pages, placement matters for DOM access.
External: best for maintainability, reuse, and separation of concerns.
Example: Link script at end of body
<!-- index.html -->
<!-- ... body content ... -->
<script src="script.js"></script> <!-- placed before closing body -->
Placing the script here ensures that elements referenced by document.getElementById already exist when the script runs.
