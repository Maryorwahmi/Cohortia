Module 6 › Chapter 6.2 › What JavaScript does
Definition

JavaScript is a client-side scripting language that runs in the browser to make pages dynamic. It can read and modify the Document Object Model, respond to user events, and change content or style without a reload.

Analogy
Think of HTML as a page's skeleton, CSS as clothing, and JavaScript as muscles and nerves that move and react.
Common Mistake
Attempting to manipulate an element before the browser has parsed it. This causes null references.
Concrete Example
A button click updates a heading and toggles a panel's visibility. No page reload is required; the change is immediate because the code runs in the browser.
Key Takeaway
Use JavaScript when you need the page to react to users, update content, or animate state changes without navigating away.
