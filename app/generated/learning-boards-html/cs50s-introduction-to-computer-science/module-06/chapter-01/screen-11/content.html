Definition
Box model layers
Content: text or image size.
Padding: space inside the border.
Border: the line around padding and content.
Margin: space outside the border separating elements.
Key Takeaway

When sizing elements, remember padding and border add to total size unless you set box-sizing to border-box.

Interactive example (visualized)
Example: width:200px; padding:20px; border:5px solid #ccc; total width without border-box increases beyond 200px.
Pro tip: include *{ box-sizing: border-box; } at the top of your stylesheet for more predictable sizing.
Common confusion: vertical margins can collapse between adjacent elements, making spacing appear different than expected.
