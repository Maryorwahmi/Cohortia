index.html starter
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>My Profile</title>
  <link rel="stylesheet" href="styles.css">
</head>
<body>
  <h1>[Your Name Here]</h1>
  <img src="https://via.placeholder.com/150" alt="Profile picture of [Your Name]" class="profile-pic">
  <p>Hello! I'm [Your Name], an aspiring web developer passionate about building for the web.</p>
  <h2>My Interests</h2>
  <ul>
    <li>Coding</li>
    <li>Reading</li>
    <li>Hiking</li>
  </ul>
  <footer>&copy; 2023 [Your Name]. All rights reserved.</footer>
</body>
</html>
Explanation & checks
  • Doctype and html lang ensure correct parsing and language metadata.
  • meta viewport allows responsive scaling on mobile devices.
  • link rel="stylesheet" prepares for external CSS; practice refactoring later.
  • Always include alt text on images for accessibility.
Try this: open index.html in a browser, inspect the DOM, and toggle elements to see the effect.
