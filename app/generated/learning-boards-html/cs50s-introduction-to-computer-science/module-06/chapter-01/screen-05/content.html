Tag categories and attributes
  • Block elements: h1–h6, p, ul, ol, div — occupy their own box.
  • Inline elements: a, img, span, strong — flow within text.
  • Paired vs self-closing: most tags have an opening and closing tag; img and br are self-closing.
  • Attributes: href, src, alt, class, id provide metadata and behavior.
Key Takeaway

Use semantic tags and attributes for clarity and accessibility. Avoid using tags solely for appearance.

Examples and common mistakes
Example: <img src="avatar.jpg" alt="Photograph of Jordan smiling"> — alt improves accessibility.
Mistake: using <b> or <i> for headings instead of semantic <h2> — semantics matter for structure.
Pro tip: use class and id attributes to target elements with CSS later rather than inline styles.
