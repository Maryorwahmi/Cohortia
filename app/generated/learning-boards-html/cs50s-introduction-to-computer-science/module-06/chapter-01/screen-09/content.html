Comparison
Where to place CSS
Inline: <h1 style="color:red;"> — quick, not reusable, mixes content and style.
Internal: <style> h1 { color:red; } </style> — good for single-page testing.
External: styles.css linked from head — scalable and cacheable across pages.
Refactor example

<h1 style="color:blue;">Title</h1>


<style>
h1 { color: blue; }
</style>


/* styles.css */
h1 { color: blue; }
Pro tip: start with internal during learning, then move to external styles.css as your site grows.
