styles.css starter
/* styles.css */
body { font-family: Arial, sans-serif; color: #333; margin: 0; padding: 20px; }
h1, h2 { text-align: center; color: #0056b3; }
.profile-pic { border-radius: 50%; border: 4px solid #fff; width:150px; height:150px; object-fit:cover; display:block; margin: 10px auto; }
p { padding: 10px 0; }
ul { list-style: none; padding: 0; text-align: center; }
li { color: #333; }
footer { background:#f1f5f9; text-align:center; padding:10px; margin-top:20px; }
/* box-sizing to include padding and border in width/height */
* { box-sizing: border-box; }
Explanation
  • Set a global font on body to keep typography consistent.
  • Center headings for a clean profile layout.
  • Use border-radius and object-fit to make images circular and cropped.
  • Include box-sizing: border-box to make sizing predictable when padding/borders are added.
Try refactoring: change the profile-pic width and see how the layout adapts across devices.
