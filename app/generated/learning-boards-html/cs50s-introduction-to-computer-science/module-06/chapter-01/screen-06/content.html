Checklist to prevent common mistakes
  1. Start with <!DOCTYPE html> and declare <html lang="en">.
  2. Keep head metadata and links in <head> and visible content in <body>.
  3. Use semantic tags and close every paired tag.
  4. Use attributes correctly: src for images, href for links, alt for accessibility.
  5. Validate HTML and inspect the DOM to catch errors early.
Common misconception: "The browser will always fix my mistakes." It may, but results vary and accessibility can suffer.
Scenario: unclosed list items
If you write <ul><li>Item one<li>Item two</ul> some browsers will close missing tags for you, but the resulting DOM may nest content in unexpected ways. Fix by ensuring each <li> has a closing tag. Use the DOM inspector to compare before and after.
Pro tip: adopt a small linter or validator into your workflow to highlight missing tags.
Check your nesting when moving blocks of code; editors often auto-indent to hint where tags belong.
