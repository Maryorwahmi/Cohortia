Process Flow
Build the Profile Page — Checklist
1. Create index.html with doctype, head, title, and body.
2. Add semantic elements: h1, p, h2, ul/li, img with alt.
3. Create styles.css and link it: <link rel="stylesheet" href="styles.css">.
4. Set global font and center headings.
5. Style profile image: border-radius:50%; width and object-fit to crop.
6. Apply box-sizing: border-box; add padding and margin for spacing.
7. Style footer with background and centered text.
8. Test in a browser and inspect the DOM and computed styles.
9. Reflect: which change made layout most predictable?
