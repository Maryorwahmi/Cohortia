Core Concept
HTML structure and semantics
  • Tags name elements: h1, p, ul, li, a, img.
  • Attributes add metadata: href, src, alt, lang.
  • Head holds title, meta, and links; body holds visible content.
  • Correct nesting and closed tags prevent unexpected rendering.
Key Takeaway

HTML provides structure and meaning. Keep tags semantic and nested correctly for accessibility and clarity.

Live example: minimal document
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>My First Web Page</title>
</head>
<body>
  <h1>Welcome to My Website!</h1>
  <p>This is a simple paragraph about web development.</p>
  <a href="https://www.cohortia.com">Visit Cohortia</a>
  <img src="logo.png" alt="Cohortia Logo">
  <ul>
    <li>Item One</li>
    <li>Item Two</li>
  </ul>
</body>
</html>
Concrete example: a header, paragraph, link, image, and list are present and each tag carries meaning.
Common mistake: leaving tags unclosed or incorrectly nested; use a validator or inspector to catch this.
