Core Concept
CSS rule structure
Selector examples: h1, .profile, #main, ul li, a:hover.
Declaration: property: value; — e.g., color: navy; font-size: 2em;
The cascade resolves conflicts by specificity and later declarations.
Misconception: inline styles always win — inline has higher specificity but external styles improve maintainability.
Key Takeaway

Write clear selectors and consistent properties. Keep styles reusable to avoid conflicts.

Concrete examples
h1 { color: navy; font-size: 2em; }
.profile-pic { border-radius: 50%; border: 3px solid #ddd; }
ul li { color: #333; }
Example: group selectors to apply consistent spacing across lists.
Pro tip: use classes for styling rather than tag selectors for more predictable results.
