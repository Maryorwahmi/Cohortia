Login route (example)
@app.route('/login', methods=['GET', 'POST'])
def login():
  if request.method == 'POST':
    username = request.form['username']
    password = request.form['password']
    if username == 'admin' and password == 'password':
      return f"Welcome, {username}!"
    else:
      return "Invalid credentials."
  return '''
    <form method="post">
      <p><input type="text" name="username"></p>
      <p><input type="password" name="password"></p>
      <p><input type="submit" value="Login"></p>
    </form>
  '''
Explanation
  • The methods argument allows GET and POST on the same route.
  • Check request.method so you only access request.form when the form is submitted.
  • Return a rendered template or string depending on the outcome.
Common mistake: trying to read request.form on GET requests. Always branch on the method.
