templates/index.html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>{{ title }}</title>
</head>
<body>
  <h1>{{ greeting }}</h1>
  <p>This page was rendered dynamically by Flask.</p>
  {% if user %}
    <p>Welcome back, {{ user }}!</p>
  {% else %}
    <p>Please log in.</p>
  {% endif %}
  <a href="{{ url_for('login') }}">Login Page</a>
</body>
</html>
Notes
  • Use {{ '{{ variable }}' }} to display data passed from render_template.
  • Use {% raw %}{% if %}{% endraw %} blocks for conditionals and loops for lists like messages.
  • Keep templates focused on presentation; put logic in view functions.
Key Takeaway

Templates let you produce dynamic HTML while keeping Python code and markup separate.
