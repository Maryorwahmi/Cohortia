Example app.py
# app.py
from flask import Flask

app = Flask(__name__)

@app.route('/')
def index():
  return "Hello from Flask!"

if __name__ == '__main__':
  app.run(debug=True)
Walkthrough
  • Flask(): creates the application object used to register routes.
  • @app.route: decorator that binds a URL path to a function.
  • Return value: the function return is the HTTP response body.
  • app.run: starts a development server when the script runs directly.
Misconception: debug=True is fine for production. No — debug exposes internals and should be disabled in production.
