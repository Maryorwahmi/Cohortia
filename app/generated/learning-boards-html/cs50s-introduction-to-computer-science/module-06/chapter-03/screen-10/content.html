Module 6 › Chapter 6.3 › request Object
What it contains
  • request.method: the HTTP verb used.
  • request.form: form fields submitted in POST.
  • request.args: query parameters for GET.
Tip: use request.form.get('field', '') for optional values to avoid errors when a key is missing.
Example: message processing
Read message_text and author_name from request.form. If message_text is empty, do not add it to the messages list. For optional author_name, default to Anonymous when absent.
Common mistake

Assuming client validation is sufficient. Always re-check inputs on the server.
