Server-Side Development
Run code on a server to handle persistence, secrets, and authoritative logic before returning responses to clients.
GET vs POST
Use GET to retrieve data in URLs; use POST to send data in the request body for submissions and sensitive payloads.
Flask & Templates
Flask maps routes to functions and uses Jinja2 to render dynamic HTML from Python variables.
Final takeaway

Combining secure request handling, templating, and routing lets you build interactive, data-driven web apps with Flask. Practice the message board pattern to reinforce these ideas.
