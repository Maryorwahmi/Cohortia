Module 6 › Chapter 6.3 › Dynamic Routes
Example
@app.route('/greet/<name>')
def greet(name):
  return f"Hello, {name}!"
Visit /greet/Alice to see a personalized response. Flask passes Alice as the name argument to the function.
Usage notes
  • Path parameters are part of the URL and are good for readable addresses.
  • Validate path data before using it to query databases or run actions.
  • Prefer path parameters for identity and query strings for optional filters.
Check: try several names in the path to confirm dynamic behavior and think about edge cases like empty or malicious values.
