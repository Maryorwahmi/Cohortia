Module 6 › Chapter 6.3 › render_template & redirect
Example snippet
@app.route('/')
def index():
  return render_template('index.html', title='Home Page', greeting='Welcome!', user='Cohortia Student')

@app.route('/submit', methods=['POST'])
def submit():
  # process data...
  return redirect(url_for('index'))
Why redirect?

Redirecting after POST converts the result into a GET request so refreshing won't repeat the form submission. url_for constructs the URL for a named view function, reducing hard-coded paths.

Developer tip

Use url_for('index') instead of '/': it adapts when you rename routes and avoids accidental broken links.
