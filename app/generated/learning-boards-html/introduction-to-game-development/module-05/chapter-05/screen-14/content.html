Module 6 › Chapter 5.5 › Key Concepts
Health System
Track current/max health, clamp values, and raise OnHealthChanged for UI updates.
Game State
Central mode like Playing, Paused, GameOver; transitions should be orchestrated by GameManager.
GameManager Singleton
One persistent manager. Initialize in Awake, use DontDestroyOnLoad, and expose methods like AddScore.
Summary takeaway
Centralize health logic, make UIs listen to events, and let a single persistent manager govern score and game flow for reliable, maintainable gameplay.
