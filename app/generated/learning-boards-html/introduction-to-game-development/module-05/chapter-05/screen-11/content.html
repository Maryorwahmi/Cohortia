Module 6 › Chapter 5.5 › Editor & Testing

Top: Editor checklist

  • • Set Player.MaxHealth (e.g., 100) in Inspector.
  • • Assign Coin.CoinValue and Hazard.DamageAmount with positive numbers.
  • • Place a GameManager in the scene and wire OnGameOver to RestartLevel.

Bottom: Playtest steps

  1. Run the scene, collect coins, and check the Console for AddScore logs.
  2. Trigger hazards and watch health decrease and events fire.
  3. Force death to confirm GameManager pauses the game and restarts if configured.
