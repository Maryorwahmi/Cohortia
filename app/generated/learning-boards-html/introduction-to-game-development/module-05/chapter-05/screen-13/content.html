Module 6 › Chapter 5.5 › Restart & Reset

Top: Pause and GameOver

On player death, pause with Time.timeScale = 0f and trigger OnGameOver for UI panels to show retry or main menu options.

Bottom: Restart flow

  1. Time.timeScale = 1f to resume simulation.
  2. SceneManager.LoadScene with current scene name to reload environment.
  3. Reset GameManager variables such as score and re-invoke OnScoreChanged to update UI.
