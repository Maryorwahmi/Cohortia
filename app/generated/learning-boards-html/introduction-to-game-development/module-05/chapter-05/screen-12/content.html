Common mistakes and fixes

Singleton init in Start
Move initialization to Awake to guarantee Instance is ready for other scripts.
Negative inputs
Guard methods against negative amounts and use Mathf.Clamp to keep health valid.
Duplicate subscriptions
Track subscriptions for persistent managers or rewire on scene load to avoid doubled handlers.
Tight coupling
Use events to decouple UI and gameplay logic for clearer responsibilities.
Quick debug tip
Use temporary buttons or Inspector-driven calls to force health set to 0 and to max to verify clamping, death events, and GameManager reactions.
