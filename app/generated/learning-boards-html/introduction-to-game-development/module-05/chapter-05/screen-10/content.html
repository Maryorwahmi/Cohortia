Subscribing in Start

void Start()
{
  GameObject player = GameObject.FindGameObjectWithTag("Player");
  if (player != null)
  {
    HealthSystem playerHealth = player.GetComponent();
    if (playerHealth != null) playerHealth.OnPlayerDied.AddListener(HandlePlayerDeath);
  }
  OnScoreChanged?.Invoke(score);
}
If GameManager persists across scenes, use SceneManager.sceneLoaded to re-wire listeners for new player instances instead of double-subscribing in Start each scene load.
Practical checks
  • • Log subscription events to verify single registration.
  • • Guard against null when finding the player in Start.
  • • Reset or re-wire subscriptions when scenes reload to reference new objects.
Key Takeaway

Manage subscriptions carefully with persistent managers to prevent duplicated handlers and missing references across scenes.
