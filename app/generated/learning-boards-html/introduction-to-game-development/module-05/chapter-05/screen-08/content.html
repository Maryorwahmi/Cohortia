Process

Coin collection and hazard collision

  1. Coin detects player via OnTriggerEnter and CompareTag("Player").
  2. Coin calls GameManager.Instance.AddScore(coinValue) and destroys itself.
  3. Hazard checks collisions, retrieves HealthSystem from the other object, and calls TakeDamage(damageAmount).
  4. HealthSystem processes damage through clamped setter, invokes events, and triggers Die if needed.
Code snippets
// Coin.cs
void OnTriggerEnter(Collider other)
{
  if (other.CompareTag("Player"))
  {
    GameManager.Instance.AddScore(coinValue);
    Destroy(gameObject);
  }
}

// Hazard.cs
void OnCollisionEnter(Collision collision)
{
  if (collision.gameObject.CompareTag("Player"))
  {
    HealthSystem playerHealth = collision.gameObject.GetComponent();
    if (playerHealth != null) playerHealth.TakeDamage(damageAmount);
  }
}
Key Takeaway

Thin interaction scripts call centralized systems so behavior stays consistent and easy to tune.
