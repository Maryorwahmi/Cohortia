Module 6 › Chapter 5.5 › GameManager Singleton
Architecture

Singleton responsibilities

  • • Expose public static Instance for global access.
  • • Persist across scenes with DontDestroyOnLoad.
  • • Manage score, game state enums, and global UnityEvents.
public static GameManager Instance { get; private set; }

void Awake()
{
  if (Instance != null && Instance != this) Destroy(gameObject);
  else { Instance = this; DontDestroyOnLoad(gameObject); }
}
Example methods
public void AddScore(int amount)
{
  if (amount < 0) return;
  score += amount;
  OnScoreChanged?.Invoke(score);
}

public void HandlePlayerDeath()
{
  Time.timeScale = 0f;
  OnGameOver?.Invoke();
}
Safety note
Avoid accessing GameManager.Instance in other scripts' Awake if the Instance may not exist yet. Initialize critical subscriptions in Start or ensure order explicitly.
