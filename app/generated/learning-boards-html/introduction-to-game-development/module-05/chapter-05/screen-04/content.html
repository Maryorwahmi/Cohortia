Module 6 › Chapter 5.5 › Health Essentials
Definition

What a HealthSystem contains

  • • maxHealth: a public value set in the editor for tuning difficulty.
  • • currentHealth: an internal value exposed via a read-only property or event.
  • • TakeDamage(amount) and Heal(amount): validated methods that modify health through the setter.
  • • OnHealthChanged events to update UI and other reactions.
Analogy
Think of health as a water tank with a labeled maximum. Damage removes water, healing adds it, but valves keep it between empty and full.
Common mistake
Updating UI from many scripts instead of subscribing to a single health event causes inconsistent displays and harder debugging.
Example
A property setter clamps values and invokes a UnityEvent for UI updates. The code snippet below shows the currentHealth setter used throughout the class.
private int _currentHealth;
public int currentHealth
{
  get { return _currentHealth; }
  private set
  {
    _currentHealth = Mathf.Clamp(value, 0, maxHealth);
    OnHealthChanged?.Invoke(_currentHealth, maxHealth);
    if (_currentHealth <= 0)
    {
      Die();
    }
  }
}
Key Takeaway

Use a clamped setter and events to make health authoritative and observable across systems.
