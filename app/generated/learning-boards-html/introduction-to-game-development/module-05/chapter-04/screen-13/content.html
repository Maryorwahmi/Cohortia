Lab Walkthrough: Build the Enemy AI
Follow these steps and test after each change to isolate issues quickly.
  1. Prepare Scene: Create Ground plane and obstacle cubes. Mark them Navigation Static.
  2. Bake NavMesh: Window → AI → Navigation → Bake. Confirm blue overlay on walkable area.
  3. Create Enemy: Add Capsule named Enemy, add NavMeshAgent, adjust speed and angularSpeed.
  4. Waypoints: Create Waypoint1 and Waypoint2, assign them to patrolPoints array.
  5. Script: Attach EnemyAI, set patrolSpeed, chaseSpeed, sightRange, and obstacleLayer.
  6. Test: Run scene, block line of sight with an obstacle to confirm raycast behavior.
Quick checks
If the enemy doesn't move: check NavMesh bake and Navigation Static flags first. If it chases through walls: check obstacleLayer for raycast and layer mask setup.
