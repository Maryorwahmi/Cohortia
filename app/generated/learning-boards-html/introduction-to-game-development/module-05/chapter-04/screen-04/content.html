Core Concept
Why simple AI matters
Small rules produce predictable, extensible behaviors that are easier to test and tune than large, opaque systems.
Concrete example
A capsule enemy patrols two waypoints. When the player is seen, it switches to chase; when lost, it returns to patrol.
Common misconception
More complexity does not always equal better gameplay. Start simple and add states only when they change player experience.
Key Takeaway

Simple state-based rules create predictable, testable enemy behavior that you can iterate on quickly.

Analogy
Think of the enemy as a guard following a shift schedule: routine until they spot something suspicious, then react. The schedule is the state machine.
Try this
Place waypoints and run the game. Change a state's speed value and observe how feel changes. This is the fastest path to learning.
Why it matters
Predictability lets players learn and outplay AI, creating emergent gameplay.
Watch out
Over-tuning speeds or angular speed can make motion look unnatural.
