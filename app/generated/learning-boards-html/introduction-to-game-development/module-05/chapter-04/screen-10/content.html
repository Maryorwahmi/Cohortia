Process
Bake the NavMesh
Generate a navigation surface so NavMeshAgent can find walkable paths around obstacles.
Steps
1) Mark ground and obstacles Navigation Static. 2) Window → AI → Navigation. 3) Bake and confirm blue overlay.
Verify
If no blue overlay appears, rebake after marking static. Agents will not move without a valid NavMesh.
Practical example
Select the Ground plane and cubes as obstacles. In their Inspector check Navigation Static. Open Navigation window and press Bake. You should see blue where agents can walk.
Troubleshooting
If the agent still won't move, ensure agent radius and step height settings in Bake are compatible with your geometry scale.
Key Takeaway

Baking is essential. No NavMesh means no pathfinding; mark statics and rebake after scene changes.
