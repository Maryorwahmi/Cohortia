Process Flow
Patrol: waypoints → destination
Cycle an index through patrolPoints and set the agent destination each time a point is reached.
1
Set initial destination
In Start, if patrolPoints length > 0 set agent.SetDestination(patrolPoints[0].position).
2
Check arrival
If !agent.pathPending and agent.remainingDistance < threshold, advance the index and SetDestination to next point.
3
Loop
Use modulo arithmetic so patrol repeats: currentPatrolIndex = (currentPatrolIndex + 1) % patrolPoints.Length.
Concrete scenario
Two empty GameObjects named Waypoint1 and Waypoint2 placed in the scene form a simple patrol. Assign them to the script array and watch the enemy cycle.
Pro-tip
Use small thresholds like 0.5 for remainingDistance to avoid premature switching while the agent is still computing the path.
Key Takeaway

Patrol with SetDestination and check remainingDistance; never move a NavMeshAgent by changing transform.position.
