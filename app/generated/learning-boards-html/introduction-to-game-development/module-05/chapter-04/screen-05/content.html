Definition
State Machines
Define explicit states and transitions so an enemy's logic is easy to follow and modify.
Minimal pattern
Use an enum, a currentState variable, and separate methods for each state's behavior. Example states: Patrol, Chase, Attack, Flee.
Misconception
Putting many unrelated checks in Update makes behavior hard to reason about. Keep transitions centralized and behaviors concise.
Example flow
Patrol runs until CheckForPlayerInSight returns true. Then set currentState to Chase and raise agent speed. While chasing, if sight is lost, set state back to Patrol.
Quick checklist
  • Define enum with all states you'll use.
  • Keep state methods single-purpose.
  • Use clear transition conditions and logs for debugging.
Key Takeaway

Explicit states and focused methods help you tune and extend enemy behavior safely.
