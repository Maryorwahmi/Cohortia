NavMeshAgent basics
GetComponent, SetDestination, and arrival checks with remainingDistance and pathPending.
void Start()
{
  agent = GetComponent<NavMeshAgent>();
  agent.speed = patrolSpeed; // initial speed
  if (patrolPoints.Length > 0)
  {
    agent.SetDestination(patrolPoints[currentPatrolIndex].position);
  }
}

void PatrolBehavior(bool playerInSight)
{
  if (!agent.pathPending && agent.remainingDistance < 0.5f)
  {
    currentPatrolIndex = (currentPatrolIndex + 1) % patrolPoints.Length;
    agent.SetDestination(patrolPoints[currentPatrolIndex].position);
  }
}
Practical notes
  • Do not set transform.position while agent is active.
  • Use agent.remainingDistance to check arrival reliably.
  • Tune agent properties to match visual animation speed.
Key Takeaway

NavMeshAgent takes care of path calculation and movement; drive it with SetDestination and tune parameters for believable motion.
