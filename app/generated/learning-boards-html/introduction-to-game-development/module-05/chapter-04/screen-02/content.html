Learning Objectives
A Bloom progression to guide your practice: Learn → Understand → Apply → Master
01
Design patrolling and chasing
Build patrol routes with waypoints and trigger chase when detection conditions are met. This makes NPCs feel purposeful.
VERIFIED COMPETENCY MILESTONE
02
Implement a state machine
Use an enum and a single currentState variable to switch between Patrol and Chase logic cleanly and predictably.
VERIFIED COMPETENCY MILESTONE
03
Use NavMesh for pathfinding
Bake walkable surfaces and let NavMeshAgent compute paths instead of manual transform movement for robust navigation.
VERIFIED COMPETENCY MILESTONE
04
Apply raycasting for sight
Use Physics.Raycast to check for obstacles between enemy and player so the enemy only chases when sight is clear.
VERIFIED COMPETENCY MILESTONE
