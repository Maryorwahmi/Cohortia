Common mistakes vs fixes
Issue: Agent not moving
Cause: NavMesh not baked or ground not Navigation Static. Fix: mark static and rebake.
Issue: Enemy spins or teleports
Cause: angularSpeed or acceleration too high, or manipulating transform directly. Fix: tune agent properties and use SetDestination only.
Checklist to debug
  1. Open Navigation window and confirm blue overlay over ground.
  2. Ensure obstacles are marked Navigation Static.
  3. Do not change transform.position of NavMeshAgent objects.
  4. Use OnDrawGizmos to visualize raycasts and sight range.
Key Takeaway

Follow the bake → agent → tuning order to troubleshoot movement and detection issues efficiently.
