Comparison
Distance vs Raycast
Combine a distance filter with a raycast to balance performance and accuracy.
Distance Check
Cheap and broad; use Vector3.Distance to quickly reject far-away players.
Raycast
Expensive but precise; cast a ray and check obstacleLayer to confirm visibility.
Practical pattern
First check distance < sightRange. If true, compute directionToPlayer and raycast from slightly above the enemy to avoid ground collision. If the ray hits the player, set state to Chase.
Misconfiguration
If obstacleLayer is set incorrectly, raycasts may ignore obstacles or hit unwanted layers. Double-check layer masks.
Key Takeaway

Filter by distance, then raycast to confirm. Correct layer masks and origin offsets are essential.
