CheckForPlayerInSight method
// Distance filter first
float distanceToPlayer = Vector3.Distance(transform.position, playerTarget.position);
if (distanceToPlayer < sightRange)
{
  Vector3 directionToPlayer = (playerTarget.position - transform.position).normalized;
  RaycastHit hit;
  // Raycast from slightly above to avoid immediate ground hits
  if (Physics.Raycast(transform.position + Vector3.up * 0.5f, directionToPlayer, out hit, sightRange, obstacleLayer))
  {
    if (hit.collider.CompareTag("Player"))
    {
      return true; // Player visible
    }
  }
}
return false; // Not visible
Explanation
  • Distance check reduces raycast calls for performance.
  • Raycast uses an obstacle layer mask to ignore non-environment colliders.
  • An upward offset prevents hitting the ground immediately.
  • Compare the hit collider tag to detect the player specifically.
Debug tip

Use OnDrawGizmos or Debug.DrawRay to visualize the ray in the editor and confirm origin and direction.
