Process Flow
Chase: follow the player
Continuously set the agent destination to the player's transform so the agent recalculates a path as the player moves.
Behavior
In Chase, call agent.SetDestination(playerTarget.position) each Update while the player remains in sight.
Tuning tips
  • chaseSpeed > patrolSpeed for clear urgency.
  • Keep angularSpeed reasonable to avoid snapping turns.
  • Use acceleration to smooth starts and stops.
Concrete example
When transitioning to Chase, agent.speed = chaseSpeed; while chasing, agent.SetDestination(playerTarget.position); if sight is lost, return to Patrol and reset speed.
Common mistake
Using only Vector3.Distance to trigger chase can cause enemies to try to walk through obstacles. Add a raycast to check visibility.
Key Takeaway

Keep chase responsive by updating destination each frame and tune agent parameters to preserve believable motion.
