Checklist
  • Set anchors before styling elements.
  • Use Image Type = Filled for bars controlled by scripts.
  • Assign UI references in Inspector; avoid GameObject.Find.
  • Ensure EventSystem and Graphic Raycaster are present.
Pro Tips
Split dynamic UI into smaller canvases to reduce redraw overhead.
Use easing when updating bars for a polished feel.
Document required Inspector fields in the script header for teammates.
Key Takeaway

Avoid common layout mistakes by testing early, wiring explicitly, and optimizing canvases for better runtime performance.
