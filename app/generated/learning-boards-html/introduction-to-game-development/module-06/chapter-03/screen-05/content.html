Definition
Rect Transform & Anchors
Anchors set where an element ties to its parent; pivot sets its local origin for transforms.
Anchored Position: Pixel offset from the anchor rectangle.
Size Delta: Width and height relative to anchors.
Pivot: The point used for rotation and scale inside the element.
Example: Top-right score stays anchored and readable.
Mistake: Leaving default center anchors causes drift on resize.
Practical Steps
  1. Select Rect Tool, pick an anchor preset that matches desired behavior.
  2. Use Shift+Alt with a preset to set both anchors and offsets quickly.
  3. Test by changing Game view resolution and observing repositioning.
Checklist: Did the element keep its offset? Did it stretch appropriately? If not, adjust anchors or switch to stretch anchors.
