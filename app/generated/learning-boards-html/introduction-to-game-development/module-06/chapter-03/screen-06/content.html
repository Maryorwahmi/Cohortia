Core Component
Text, Image, Button
Use TextMeshPro for crisp labels, Image for visuals, Button for interaction.
TextMeshPro: import TMP Essentials if prompted, then add a TextMeshPro UGUI element.
Image Fill: child Image set to Filled and Horizontal allows script control via fillAmount.
Button: assign a public method to On Click() via Inspector.
Example Card
Create a Stop button that calls GameManager.PauseGame() by dragging the GameManager into the button's On Click slot and selecting the method.
Common mistake
Assuming a button must have a script on itself; instead it only triggers public methods on referenced objects.
Key Takeaway

Use Button's On Click to call public methods; keep logic in manager scripts, not on the button itself.
