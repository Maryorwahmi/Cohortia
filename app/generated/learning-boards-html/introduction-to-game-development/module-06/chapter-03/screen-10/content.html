Architecture
Inspector & Wiring
Expose UI references, assign them in Inspector, and add null checks in code.
Public Fields: Visible and editable in Inspector.
[SerializeField] Private: Keeps encapsulation but still assignable in Editor.
Null Checks: Prevent runtime errors if a reference is left unset during testing.
Practical Example
Select UIManager in the Hierarchy and drag the ScoreText object into the scoreText field. Repeat for HealthBarFill. Run the scene and press P/O to verify updates.
Pro tip: annotate scripts with a small header comment describing which fields must be set in the Inspector for designers.
Common Mistake

Leaving references unassigned and then relying on runtime searches leads to fragile scenes.
