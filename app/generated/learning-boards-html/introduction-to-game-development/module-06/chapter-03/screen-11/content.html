Fixed Offsets vs Anchors
Fixed offsets can break on different aspect ratios; anchors express intended behavior across sizes.
Anchored: Maintains margin from corner regardless of resolution.
Fixed Offset: Looks correct on one resolution but drifts on others.
Canvas Scaler
Set Reference Resolution and Screen Match Mode to control how UI elements scale between small and large devices.
Tip: test with a phone, tablet, and desktop preset to ensure touch targets and text remain readable.
Key Takeaway

Simulate target devices and tune anchors plus Canvas Scaler to keep UI consistent and accessible.
