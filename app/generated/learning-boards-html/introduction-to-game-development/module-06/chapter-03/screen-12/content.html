Definition
Event System
It dispatches clicks, drags and pointer events to UI elements and requires an input module suited to your input setup.
Graphic Raycaster: Component on Canvas that allows it to receive pointer events.
Input Module: Standalone Input Module or Input System module handles device input mapping.
Troubleshooting
  • Ensure EventSystem exists. If missing, add one via GameObject > UI > Event System.
  • Check for blocking panels with Raycast Target enabled that might capture clicks unintentionally.
  • Verify the correct input module is active for keyboard, mouse, or gamepad support.
Key Takeaway

If UI doesn't respond, check EventSystem, Graphic Raycaster, and overlapping objects that can block input.
