Layout Groups
Add a layout component to a parent to manage child positions automatically.
Horizontal: Arrange children in a row with spacing and padding.
Vertical: Stack children in a column; useful for menus.
Grid: Produce uniform cell grids for inventory or level selectors.
Example & Notes
Inventory example: parent GameObject has Horizontal Layout Group and child slots are Image objects. Adding slots automatically updates layout spacing.
Tip: combine Layout Element on a child to override min width or preferred height when one slot needs different sizing.
Common Mistake

Putting layout groups on objects that should not change size leads to jitter. Use them for dynamic content only.
