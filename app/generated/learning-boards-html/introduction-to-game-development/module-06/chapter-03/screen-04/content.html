Core Concept
Canvas and Render Modes
Choose how UI is rendered relative to the screen and cameras.
  • Overlay: Always on top, scales with screen — ideal for HUDs and menus.
  • Camera: Renders in front of a specific camera — good for view-dependent UI.
  • World Space: UI as 3D objects — use for in-world panels and signs.
Example: HUD uses Overlay to remain visible.
Misconception: World Space equals better visuals — not for HUDs.
Annotated Cards
When to use Overlay
Health bars, score counters, and pause menus that must always be visible use Overlay for consistency and simplicity.
When to use Camera
Use Camera mode when UI should respect camera depth or when render order matters with scene objects.
When to use World Space
Use World Space for floating screens or interactable terminals that players can approach in the 3D world.
