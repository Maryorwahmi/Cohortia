Module 6 › Chapter 6.3 › Key Concepts
Canvas
Container for UI elements; choose Overlay, Camera or World Space to control where UI renders.
Rect Transform
UI-specific transform with anchors, pivot, and size controls for 2D layouts.
Anchors
Define how a UI element's position and size relate to its parent for responsive behavior.
Quick takeaway: these terms capture where UI lives, how it sizes, and how it reacts to input.
