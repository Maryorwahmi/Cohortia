Hands-on Activity
Building a Simple HUD
1. Create Canvas
GameObject > UI > Canvas, choose Screen Space - Overlay. Ensure EventSystem exists.
2. Add ScoreText
Add TextMeshPro, set anchors to top-left (Shift+Alt preset), set text to "Score: 0" and adjust font size.
3. Health Bar
Create Image for background, child Image for fill. Set child to Filled, Horizontal, Fill Origin Left and color to green.
4. UIManager
Create UIManager object, attach script and drag ScoreText and HealthBarFill into their slots in Inspector.
Checklist & Tips
  • Set the fill image type to Filled or fillAmount won't work.
  • Assign references in Inspector instead of using GameObject.Find.
  • Test with Game view presets to validate anchors across resolutions.
Key Takeaway

Follow the sequence and verify anchor behavior early to prevent layout breakage later.
