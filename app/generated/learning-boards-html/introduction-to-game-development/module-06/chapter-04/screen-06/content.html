Module 6 › Chapter 6.4 › Preparing a Playtest Build
Build Steps (summary)
  1. Open File > Build Settings.
  2. Add the scenes you want in "Scenes In Build."
  3. Select target platform (PC, Mac & Linux Standalone).
  4. Open Player Settings to set company, product, and resolution options.
  5. Choose Windowed mode and enable resizable window for testers.
  6. Click Build and choose an empty folder for the output.
Example
Save the build to a folder named MyGame_Playtest_Build_v1 and include a README with controls and focus points.
Player Settings to check
  • Company Name and Product Name
  • Resolution and Presentation: Windowed, Resizable
  • Icon and splash if relevant
Common mistakes
  • Not adding scenes to the build list
  • Leaving debug console keys exposed
  • Not testing the build on a different machine
Key Takeaway
A small README and windowed build increase the chance of useful tester responses.
