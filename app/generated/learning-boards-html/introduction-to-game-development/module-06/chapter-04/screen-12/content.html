Module 6 › Chapter 6.4 › Activity
Step-by-step checklist
  1. Confirm playable prototype with one core mechanic.
  2. File > Build Settings: add scenes and select target platform.
  3. Player Settings: set Company & Product, Resolution to Windowed, Resizable on.
  4. Build into an empty folder named MyGame_Playtest_Build_v1.
  5. Create README with controls and focus questions.
  6. Create a short feedback form (ratings + open questions).
  7. Self-test the build, then schedule two external sessions.
Sample feedback form items
  • Controls clarity: 1–5
  • Enjoyment: 1–5
  • Most frustrating part: (open)
  • Did you encounter bugs? (open)
Self-test tip
Run the build on a different account or machine to catch missing files and platform issues.
Outcome
A shareable playtest folder and a short feedback form ready to distribute.
