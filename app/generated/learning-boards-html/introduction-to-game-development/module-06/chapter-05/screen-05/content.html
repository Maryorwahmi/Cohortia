Step-by-step: Prepare Build Settings
  1. Save all open scenes in the Editor to prevent lost changes.
  2. Open File → Build Settings and choose the target platform.
  3. Use Add Open Scenes to include each scene you want in the build.
  4. Drag scenes to order them; the first scene is the startup scene.
  5. If needed, click Switch Platform to enable the correct build support.
  6. Click Build and choose a new output folder for the final files.
Example folder name
MyGame_Final_Build — contains the executable and a data folder.

Misconception
Assets in the Project folder are not automatically included — only assets referenced by included scenes and resources are packaged.
