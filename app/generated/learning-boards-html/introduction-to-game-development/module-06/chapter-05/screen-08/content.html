Module 6 › Chapter 6.5 › Platform Differences
Desktop (Windows/Mac/Linux)
Produces an executable and data folder. Configure icons, fullscreen mode, and window resizability. Test installers or simple run instructions.
Mobile (Android/iOS)
Pay attention to orientation, API levels, touch input, and store icon requirements. Test on real devices for performance and memory behavior.
WebGL
Generates HTML and data files that need a web server to run properly. Configure compression and loading behavior for web delivery.
Practical checklist
  • Choose the primary target and install its build support module.
  • Adjust Player Settings to match platform expectations.
  • Build and test in the target environment (desktop executable, mobile device, or web server).
