Module 6 › Chapter 6.5 › Learning Objectives
01
Build a standalone executable
Select target platforms and include scenes to produce a runnable build. This matters because the correct platform and scene list determine whether players can launch your game successfully.
Mnemonic: Platform → Scenes → Build
Verified Competency Milestone
02
Configure Player Settings
Set company and product names, icons, splash, and presentation settings so your game opens with a clear identity and correct window behavior.
Mnemonic: Identity → Icon → Presentation
Verified Competency Milestone
03
Identify basic optimizations
Find quick wins like reducing texture sizes, disabling unused components, and avoiding heavy per-frame work to improve build size and runtime performance.
Mnemonic: Clean assets → Compress → Test
Verified Competency Milestone
04
Package and share builds
Prepare the output folder, test the executable, then compress and share the folder so players can install or run your game easily.
Mnemonic: Build → Test → Zip
Verified Competency Milestone
