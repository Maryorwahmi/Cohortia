Module 6 › Chapter 6.5 › Key Concepts
Build
The compiled, runnable package that includes the executable and required data files for the platform.
Player Settings
Global build properties such as company name, product name, icon, splash image, and resolution settings.
Target Platform
The OS or device you build for; determines output format and may need separate testing and settings.
Takeaway: Keep a short checklist for each concept and run it before packaging your final build.
