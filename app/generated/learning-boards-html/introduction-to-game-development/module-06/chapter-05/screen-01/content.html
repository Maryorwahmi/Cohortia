Exporting and Sharing Your Game
What it means to build, configure, and share a release-ready game.
Interactive 16:9 Masterclass
This lesson shows a practical workflow: select a target platform, verify scenes in build, configure identity and presentation, run a test outside Unity, then package the build for distribution.
Why this matters
A polished build is how players first experience your game. Small details — icon, splash, resolution — influence first impressions and ease of installation.
In this lesson

Output Folder
A final build contains an executable and a data folder. Example: MyGame.exe and MyGame_Data. WebGL produces an index.html and data files.
MyGame_Final_Build/
MyGame.exe • MyGame_Data/ • README.txt
Distribution
Zip the full build folder before sharing. For web builds, host the generated files on a web server or a hosting platform that serves files over HTTP.
Tip: Include a short install/run instruction in a README to help players.
Key Takeaway

Building is the final packaging step. Confirm scenes, pick the right platform, set identity options, run a test build, and then package the folder for distribution.
