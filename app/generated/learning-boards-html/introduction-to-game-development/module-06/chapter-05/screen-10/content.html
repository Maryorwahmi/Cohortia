Testing Checklist
  1. Launch the executable and confirm the startup scene loads.
  2. Play through main menu, at least one level, and exit flows.
  3. Verify icons and splash appear per Player Settings.
  4. Check resolution, fullscreen, and input responsiveness.
  5. Inspect build folder logs for errors if available.
Pro Tip
Document any reproduction steps and the exact build folder contents before sharing with testers. This speeds debugging and helps isolate platform-specific issues.
Example scenario
You launch MyGame dot exe and notice the title screen appears but no background music plays. You check the data folder to confirm the audio asset exists then run the build on a second machine to verify whether this is machine-specific or a missing asset in the build.
Debugging Hints
If a feature fails, reproduce it, note exact steps, and inspect the build output folder for missing assets. Keep a short reproduction guide to share with collaborators.

Misconception
Passing Play mode tests guarantees a flawless build. In reality, platform differences and packaging can reveal different failures.
