Module 6 › Chapter 6.5 › Objectives — Practical Steps
Verify Scenes In Build
List every scene you want in the final game and arrange them so the first scene is your starting point. Missing or misordered scenes are a frequent cause of broken builds.
Checklist:
  • Open File → Build Settings
  • Ensure scenes are ticked and ordered
  • Save any open scenes before building
Confirm Build Support Modules
Make sure platform modules are installed so Unity can compile for that target. If a module is missing, the build dialog will prevent the build or fail partway through.
Test the Executable
Run the built executable on your machine to verify launch behavior, input, and performance. This uncovers issues not visible in the Editor.
Prepare Player Instructions
Include a short README with run instructions and minimum system requirements. Clear instructions reduce support questions and make playtests smoother.
