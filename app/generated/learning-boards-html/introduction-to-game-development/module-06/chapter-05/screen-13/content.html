Final Release Checklist
Scene & Build
Verify Scenes In Build order and first scene startup.
Player Settings
Confirm company name, product name, icons, splash image, and resolution settings.
Optimization
Compress textures, remove unused assets, and simplify models where appropriate.
Test Run
Run the executable, play core flows, and check for missing assets or crashes.
Package
Zip the full build folder, include README and minimum requirements, and test extraction.
Distribute
Choose a host, upload the package, and provide clear player instructions.
Common Pitfall
Skipping a full extraction and run test. Always extract the zip to a clean folder and run the included executable to confirm nothing was left out.
Why this matters
These steps protect your players from installation confusion and reduce the time you spend troubleshooting distribution problems.
