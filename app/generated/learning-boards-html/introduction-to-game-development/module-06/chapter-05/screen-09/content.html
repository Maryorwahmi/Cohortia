What you get
A platform-specific executable and the supporting data folder that contains assets, scene data and runtime files. This pair must travel together when sharing your build.
  • Executable file (Windows: dot exe, Mac: app bundle)
  • Data folder with scenes, textures, and assets
  • Platform-specific runtime files and metadata
Quick example
Windows build folder contents:
MyGame.exe
MyGame_Data/
  managed/
  resources.assets
  sharedassets0.assets
Key Takeaway

Always keep the executable and its entire data folder together when distributing. If a file is missing the build may not start or will break at runtime.

Checks to run
  • Confirm executable exists and is recent.
  • Confirm data folder is present and non-empty.
  • Verify file sizes look reasonable (not zero bytes).
  • Do not edit files generated by Unity inside the data folder.
Common Mistake
Copying only the executable to share and omitting the data folder. The program will fail to load scenes or assets.
