Module 6 › Chapter 6.5 › Zipping & Packaging
Step-by-step
  1. Build into a new, empty folder named MyGame_Final_Build.
  2. Verify MyGame dot exe and MyGame_Data are inside the folder.
  3. Right-click the folder and choose Compress/Send to Compressed (zipped) folder.
  4. Add a README with run instructions and minimum system requirements.
  5. Test extraction and run the game on another machine.
Example README
1. Extract MyGame_Final_Build dot zip. 2. On Windows double-click MyGame dot exe. 3. Minimum: Windows 10, 4GB RAM, GPU with drivers installed.
Visual checklist
[ ] Executable present
[ ] Data folder present and non-empty
[ ] README included with extraction instructions
[ ] Zip tested by extracting to another folder
Common Mistake
Zipping only the executable instead of the full folder causes missing assets and runtime failures for players who extract and run the game.
