Module 6 › Chapter 6.5 › What is a Build?
Definition & core idea
A build compiles scenes, assets, and scripts into a standalone package for a specific platform. It must include every resource your game needs at runtime.
Example
Windows: MyGame.exe + MyGame_Data folder. WebGL: index.html + data files that must be served over HTTP.
Common mistake
Assuming Editor performance equals build performance. Always test the built executable to see real behavior.
Key takeaway
Treat the build as the product: verify scenes, referenced assets, and platform modules before distributing.
Quick checklist
  • Open File → Build Settings and confirm Scenes In Build
  • Select your Target Platform and ensure support modules are installed
  • Test the compiled executable on your machine
Reflection prompt
After your first build, what differences did you notice between Editor play and the executable? Use those observations to guide optimization and fixes.
