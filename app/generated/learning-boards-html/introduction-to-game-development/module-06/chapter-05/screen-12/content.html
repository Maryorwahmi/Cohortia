Why WebGL needs a server
Browsers restrict local file access for security. WebGL builds load additional data files via HTTP, so they must be served by a web server. Testing locally without a server often causes load errors and corrupt data requests.
What to upload
  • Include index dot html and all related data and code files generated by WebGL build.
  • Zip the full WebGL output for upload if required by the host.
  • Provide run instructions and any known browser recommendations.
Platform notes
itch dot io — Easy indie-focused distribution. Upload a zip, add a description, and share a link with players.
Direct hosting — Use any web server to host your WebGL folder; testers open the URL to play.
Common Mistake
Sharing index dot html alone or asking testers to open it locally. Always package the full output and instruct testers to host or extract it correctly.
