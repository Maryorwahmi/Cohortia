Process Flow

Create groups and route audio for central control

Use the Audio Mixer to group sources and expose parameters for UI and scripts.

Common groups
  • Music
  • SFX
  • Voice
Routing
Set an AudioSource's Output to the chosen mixer group so effects and volume affect that source.
Expose & control
Expose volume parameters to let UI sliders or scripts adjust mix levels at runtime.
Example
Route a player's jump AudioSource to the SFX group so muting SFX will silence jumps but not music.
Misconception
A mixer is not required early, but it saves time when you must tune levels across many sources.
