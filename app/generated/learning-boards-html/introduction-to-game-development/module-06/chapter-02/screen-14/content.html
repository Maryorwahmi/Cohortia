Module 6 › Chapter 6.2 › Performance & Design
Definition

Balance quality with runtime cost

Pick import and mixing strategies that fit your project's memory and CPU constraints while preserving critical audio clarity.

Short SFX
Decompress On Load for low latency; keep them small in size.
Long Music
Use Streaming to save memory and avoid loading large audio into RAM.
Compression
Test compressed output to ensure artifacts don't break important audio cues.
Mixer strategy
Use groups and expose parameters for runtime control and player settings.
Playtest
Run representative scenes, listen for masking and clipping, and adjust rolloff and levels accordingly.
