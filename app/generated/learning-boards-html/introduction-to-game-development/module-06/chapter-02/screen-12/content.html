SoundEffectPlayer and invoking PlayOneShot

Expose AudioClip fields and call PlayJumpSound from your PlayerController when the jump is triggered.

// Example usage in PlayerController (conceptual)
// In Start or Awake get reference:
// sfxPlayer = GetComponent();
// Then when jump input detected:
// sfxPlayer.PlayJumpSound();
Test checklist
  • Assign AudioSource to Player.
  • Assign jump AudioClip in Inspector.
  • Trigger PlayJumpSound on jump input and listen for overlap.
Debug tip
If no sound plays, check for missing AudioSource or null AudioClip; the script logs an error when AudioSource is missing.
Key Takeaway

Modular audio components keep playback reliable and make balancing through mixers straightforward.
