Module 6 › Chapter 6.2 › Key Concepts
AudioClip
Imported audio asset; set Load Type and Compression.
AudioSource
Plays AudioClips; use PlayOneShot for overlapping SFX.
AudioListener
The scene's ear; normally on the Main Camera.
Spatial Blend
0 = 2D, 1 = 3D; tune Min/Max distance and rolloff.
Audio Mixer
Groups audio by category to centralize volume and effects.
PlayOneShot
Plays a clip without stopping current sounds on the source.
Summary takeaway

Import strategically, use PlayOneShot for SFX, and organize audio with mixers to preserve clarity and control.
