Definition

Import & configure AudioClip

Decide load type and compression based on clip length and performance requirements.

Load Types
  • Decompress On Load — low latency for short SFX.
  • Streaming — read from disk, good for long music.
  • Compressed In Memory — balance size and speed.
Compression
Choose compression formats to reduce file size while listening for artifacts that hurt clarity. Test compressed output before finalizing.
Common Mistake
Streaming every clip causes excessive disk access and latency for short sounds. Reserve streaming for long tracks.
Concrete example
Coin jingle: Decompress On Load for instant playback. 3-minute ambient: Streaming to save RAM.
Why this matters
Correct import settings prevent audio lag and keep builds small while preserving quality where it counts.
