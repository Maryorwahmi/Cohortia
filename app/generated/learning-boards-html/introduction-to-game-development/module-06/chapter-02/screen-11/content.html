Hands-on Activity

Add looping background music

Create a MusicManager object, add an AudioSource, assign a music clip, and enable Play On Awake and Loop.

Step-by-step
  1. Create empty GameObject and name MusicManager.
  2. Add AudioSource component and drag the music AudioClip in.
  3. Check Play On Awake and Loop; set Volume.
  4. Route Output to Music mixer group if using a mixer.
Checks
  • Only one MusicManager active or music may overlap.
  • Loop point sounds smooth; trim silence if needed.
Why this matters
A persistent music layer sets tone and can be adjusted separately from SFX using the mixer, improving player control over audio experience.
