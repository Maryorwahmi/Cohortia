Process Flow

2D vs 3D audio and attenuation

Set Spatial Blend along with Min/Max distance and Volume Rolloff to make sounds fade and pan naturally in space.

Steps to tune 3D audio
  1. Set Spatial Blend to 1 for positional behavior.
  2. Choose Min Distance for full-volume radius.
  3. Set Max Distance for when the sound fades to inaudible.
  4. Pick Volume Rolloff curve for natural attenuation.
Concrete example
Monster growl: Spatial Blend = 1, Min Distance small so close ups are loud, Max Distance large so it can be heard from afar and pan across speakers.
Spatial = 0
Use for UI or global cues that should not change with position.
Spatial = 1
Use for world sounds that need direction and distance behavior.
Check
Move the camera around the source to verify panning and attenuation feel natural.
