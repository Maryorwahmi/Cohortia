Module 6 › Chapter 6.2 › AudioListener
Core Concept

The game's ear and correct placement

Use a single AudioListener that follows the player's viewpoint so 3D audio pans and attenuates as expected.

Typical setup
Attach the listener to the Main Camera to match player perspective.
Pitfall
Multiple active listeners can produce duplicate or confusing audio behavior.
Multiplayer note
For split-screen experiences, avoid enabling multiple listeners; route audio carefully per player instead.
Concrete example
If the player pivots, the AudioListener should move with the camera so sounds pan from left to right correctly as objects move relative to the player.
