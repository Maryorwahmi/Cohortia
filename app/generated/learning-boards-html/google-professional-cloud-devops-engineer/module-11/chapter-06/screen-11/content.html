Module 11 › Chapter 11.6 › Spot VMs / Preemptible VMs
Use cases
Batch processing, large-scale compute for models, CI/CD jobs, and any workload that tolerates interruption and restarts.
Example
A data pipeline checkpoints progress every few minutes, restarts jobs when preempted, and processes work on spot instances to reduce costs.
Design requirements
Implement checkpointing, idempotent work units, and orchestration that retries or reassigns tasks when instances are preempted.
Key Takeaway

Preemptible instances are cost-effective when workloads are fault-tolerant and can recover from interruptions.
