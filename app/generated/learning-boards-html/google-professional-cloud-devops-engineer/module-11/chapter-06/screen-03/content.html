Module 11 › Chapter 11.6 › Learning Objectives
Showable outcomes
Each objective should produce evidence you can present during a review.
Dashboard
Screenshot of Cloud Monitoring with KPI charts for CPU, memory, and request rate over time.
Profiler Flame
A flame graph highlighting the function responsible for the most CPU time.
Autoscaler Policy
Cloud Run, MIG, or HPA configuration demonstrating automatic scaling by metric.
Load Test Report
Graphs showing latency and error rate under target load and under stress conditions.
Optimization Note
A short note describing code changes or right-sizing decisions and the cost impact.
