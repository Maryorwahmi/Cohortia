Module 11 › Chapter 11.6 › Profiler Lab
Steps
  1. Install and start Cloud Profiler with a service and version label.
  2. Deploy the Python app on Compute Engine, GKE, or Cloud Run.
  3. Generate representative load and wait for CPU profiles to appear.
  4. Open flame graphs and identify the top CPU consumers.
  5. Make a targeted optimization, redeploy, and re-profile to confirm impact.
Starter snippet
try:
  profiler.start(service='my-python-app', service_version='1.0.0')
except Exception as e:
  print(f"Failed to start Cloud Profiler: {e}")

# Simulate CPU work
cpu_intensive_task(500)
Run the app in a detached session and monitor profiler for CPU time flame graphs. Identify functions that dominate and prioritize fixes by cost and risk.
Safety note

When running large-scale tests, inform your team and isolate from production if possible to avoid impacting real users.
