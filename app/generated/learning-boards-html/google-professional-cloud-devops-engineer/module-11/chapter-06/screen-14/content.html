Module 11 › Chapter 11.6 › Load & Stress Testing
Plan
Define goals, traffic profile, and success criteria. Use ramp-up, steady-state, and ramp-down phases in tests.
Metrics to collect
Latency percentiles, error rates, CPU, memory, queue depth, and database response times.
Execute
Run generators on Compute Engine or GKE. Vary payloads and concurrency. Coordinate with teams and avoid production if possible.
Key Takeaway

Well-planned tests reveal both capacity and failure modes; use them to validate planning methodology choices.
