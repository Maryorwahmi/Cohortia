Module 11 › Chapter 11.6 › Performance-based Planning
Testing types
  • Load testing: Simulate expected peak load to verify SLOs.
  • Stress testing: Push beyond limits to find breaking points and failure modes.
Tools
Apache JMeter, Locust, and k6. For large-scale tests, run generators on Compute Engine or GKE.
Safety & orchestration
Always inform stakeholders and isolate tests where possible. Use staging or dedicated test environments to avoid harming production users.
Example scenario
Deploy load generators to several Compute Engine instances, ramp traffic gradually, watch latency and error rate percentiles, and stop if error rate spikes unexpectedly.
Key Takeaway

Active testing is essential to find the true capacity and understand failure modes under load.
