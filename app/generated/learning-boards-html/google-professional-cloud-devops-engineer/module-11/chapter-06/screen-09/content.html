Profiler purpose
Continuous sampling to locate hot code paths.
Cloud Profiler collects CPU time and heap allocation across languages and visualizes them as flame graphs. Use CPU profiles to find functions that dominate processing time and allocation profiles to find memory pressure points.
# cpu_intensive_task example (from the chapter)
import time

def expensive_calculation(n):
  result = 0
  for i in range(n):
    for j in range(1000):
      result += (i * j) % 12345
  return result

def process_request_data():
  data_size = 10000
  expensive_calculation(data_size)
  return "Processed"
How to act
When profiler shows expensive_calculation dominating CPU, consider algorithmic improvements, reducing loop work, or caching results. After changes, re-profile to confirm reduced CPU time.
Misconception
Profiler suggests hotspots but does not automatically prescribe the fix. Use profiling plus tests and monitoring to validate any optimization.
Key Takeaway

Use Cloud Profiler to find where your code spends time and measure the benefit of optimizations with repeat profiling.
