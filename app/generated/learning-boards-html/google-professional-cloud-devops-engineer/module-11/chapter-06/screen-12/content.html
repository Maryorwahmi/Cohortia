Module 11 › Chapter 11.6 › Database & Caching
Optimize queries
Profile slow queries, inspect execution plans, add appropriate indexes, and measure performance improvements before and after changes.
Example
An unindexed lookup that scanned millions of rows can be transformed into an indexed seek to reduce CPU and latency dramatically.
Use caching
Add caching for frequent reads using Cloud Memorystore or in-process caches and design eviction policies to avoid stale data problems.
Key Takeaway

Improving the database and adding caching often reduces compute and memory needs for application tiers, lowering overall cost.
