Dashboard design
Combine infrastructure and business metrics.
  • Show CPU, memory, request rate, and a business metric on a single page.
  • Prefer 95th/99th percentiles for latency and CPU percentiles for capacity decisions.
  • Annotate deployments to explain metric shifts.
Example chart
Request rate over time plotted together with CPU utilization and active user count to verify demand correlation.
Alerting & validation
Create alerts on percentile breaches or error-rate spikes instead of average thresholds. Validate assumptions regularly with targeted tests and profiling.
Pro tip
Use custom metrics for product-specific measures and keep dashboards simple to reduce cognitive load during incidents.
Key Takeaway

Design dashboards that surface correlations and percentile risks so planners can act before SLO breaches.
