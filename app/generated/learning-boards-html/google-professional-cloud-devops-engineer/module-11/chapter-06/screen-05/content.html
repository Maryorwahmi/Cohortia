Module 11 › Chapter 11.6 › Utilization-based Planning
Process
Collect → Baseline → Forecast → Provision
  1. Collect resource metrics over representative windows.
  2. Establish baseline and percentile targets (95th/99th).
  3. Apply growth projections and a safety margin.
  4. Choose an instance size or scale-out plan that meets projected need.
Scenario
A web service at 60% CPU with 10% monthly growth should have projected CPU targets and an instance plan that meets the 95th percentile load.
Notes & pitfalls
Averages mask spikes. Use latency and error rate percentiles when setting SLO-driven capacity. Also consider seasonal or marketing events that deviate from trends.
Pro tip
Automate alerts on percentile thresholds so planners get notified before SLO breaches occur.
Key Takeaway

Prefer percentile-based targets and documented safety margins rather than simple averages.
