Module 11 › Chapter 11.6 › Right-sizing, Autoscaling, Serverless
Right-sizing
Select instance sizes that match observed usage. Use Cloud Monitoring to find underutilized machines and downsize them.
Autoscaling
Managed Instance Groups and HPAs adapt capacity to demand. Ensure scalers use the right metric for your bottleneck.
Serverless
Cloud Run and Functions scale automatically and charge per use, ideal for bursty or unpredictable workloads when cold-starts are acceptable.
Example trade-off
A steady, high-volume API may be cheaper on right-sized VMs or reserved capacity. A bursty, unpredictable job often benefits from serverless to avoid paying for idle capacity.
Key Takeaway

Pick the strategy that minimizes cost while satisfying SLOs; use monitoring and profiling to validate the choice.
