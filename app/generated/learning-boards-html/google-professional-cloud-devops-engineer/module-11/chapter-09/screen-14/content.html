Module 11 › Chapter 11.9 › Assessment — Tooling & Safety
Question 1
Which service orchestrates multi-step processes with conditional logic?
Answer: Cloud Workflows. Rationale: Workflows sequence tasks, call APIs, contain conditional branches, and centralize retries and error handling.
Question 2
What is the most critical safety consideration for a destructive deletion step?
Answer: Implement robust error handling and ensure the script targets only non-critical files. Rationale: Precise targeting and error handling prevent accidental data loss.
Reflection prompt: Pick an alert in your environment. Map out the runbook steps and annotate which GCP service will perform diagnostics, evaluate outcomes, and execute safe remediation.
