Learning Objectives

Bloom progression: Learn → Understand → Apply → Master
Bloom: Apply & Master focus
01
Differentiate runbook vs playbook
Define each term and explain when to use a runbook or a playbook. This distinction helps you choose automation scope and control points.
VERIFIED COMPETENCY MILESTONE
02
Design and document runbooks
Create clear, concise runbooks with preconditions, expected outputs, and test steps so automation can safely run them.
VERIFIED COMPETENCY MILESTONE
03
Implement automation on GCP
Use Cloud Functions for event-driven tasks, Workflows for orchestration, and Scheduler for timed checks to reduce manual intervention.
VERIFIED COMPETENCY MILESTONE
04
Build self-healing patterns
Automate diagnostics first, then remediation with safeguards and least privilege to avoid data loss or unexpected restarts.
VERIFIED COMPETENCY MILESTONE
Use these milestones as checkpoints. Each objective maps to design exercises and a hands-on activity that reinforces automation, safety checks, and orchestration choices.
