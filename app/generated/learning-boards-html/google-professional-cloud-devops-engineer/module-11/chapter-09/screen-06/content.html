Architecture

Match service to need

Cloud Functions
Event-driven tasks, quick diagnostics, and small remediation steps triggered by Pub/Sub or Scheduler.
Cloud Workflows
Orchestration with conditional logic, API calls, and centralized error handling for multi-step runbooks.
Cloud Scheduler
Cron-style triggers for recurring diagnostics or maintenance tasks.
Cloud Build
Automation tied to code/config changes, rolling deployments, and deployment pipelines for operational tasks.
Example flow: Monitoring alert → Pub/Sub → Cloud Function collects VM state → Cloud Workflow evaluates and runs remediation steps, posting status updates. Keep Functions small and stateless; let Workflows orchestrate and report.
Decision guide
  • • If the step is atomic and event-driven, choose Cloud Functions.
  • • If you need sequencing, retries, or conditional decisions, choose Cloud Workflows.
  • • Use Scheduler for recurring checks and Build for CI-triggered operations.

For a multi-step runbook that calls multiple APIs and updates a ticket, which service coordinates those calls? Cloud Workflows.
