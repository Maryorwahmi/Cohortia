Module 11 › Chapter 11.9 › Automated Disk Cleanup
Process

Alert to remediation workflow

  1. 1. Cloud Monitoring alert triggers Pub/Sub.
  2. 2. Cloud Function parses the alert and starts a Cloud Workflow.
  3. 3. Workflow calls Compute API for VM metadata and invokes a helper function to run read-only disk checks.
  4. 4. Workflow evaluates output; if cleanup_needed then call cleanup function with strict filters.
  5. 5. Post status updates and verify disk space; close incident if resolved.
Example outcome
A workflow performed a targeted log cleanup and reduced disk usage below threshold, then posted a diagnostic summary to Slack and closed the alert.
Safety checks
  • Start with read-only diagnostics.
  • Use whitelist paths and age filters for deletion.
  • Require a verification pass before destructive actions.
  • Grant minimal IAM to service accounts.
Check your understanding
Why separate functions for diagnostics and cleanup? Because small, focused functions are easier to test and grant least privilege; the workflow handles decisions and sequencing.
