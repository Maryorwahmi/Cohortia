Module 11 › Chapter 11.9 › Runbooks vs Playbooks
Comparison

Runbook

A prescriptive sequence of steps for a specific operational task. Designed to be executed and verified.

  • • Short, command-level steps and expected outputs.
  • • Easily automatable as a Cloud Function or script.
  • • Best for routine, repeatable tasks.
Example
A "Cloud SQL Failover Runbook" that lists the exact API calls, checks, and verification commands needed to fail over a database.
Comparison

Playbook

A strategic incident response guide that assigns roles, communication protocols, and references multiple runbooks for detailed actions.

  • • Describes decision points and stakeholder coordination.
  • • References runbooks rather than listing low-level commands.
  • • Ideal for complex incidents where coordination matters.
Example
A "Database Outage Playbook" that names the incident commander, communication channels, and which runbooks to run for failover and restore.
Misconception: Treating playbooks as detailed command lists makes them hard to maintain.
Pro tip: Keep runbooks short and automatable; let playbooks focus on roles and escalation.
Check: For your most frequent alert, separate strategic steps from automatic commands.
