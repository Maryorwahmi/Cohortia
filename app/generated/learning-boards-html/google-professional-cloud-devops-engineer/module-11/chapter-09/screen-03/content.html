Objectives — Demonstrations

Convert learning goals into repeatable checks and lab tasks.
Practical checklist
01 — Map incident to playbook
Create a diagram or list that shows how a playbook references runbooks and roles for a sample outage.
VERIFIED COMPETENCY MILESTONE
02 — Write a testable runbook
Include commands, verification outputs, and a safe rollback path so automation can be validated in staging.
VERIFIED COMPETENCY MILESTONE
03 — Implement automation
Deploy a function and a workflow that together perform a diagnostic and post a status update to a communication channel.
VERIFIED COMPETENCY MILESTONE
04 — Build a self-healing test
Stage an alert, observe the automated workflow performing read-only checks, then safely execute a remediation step in a controlled environment.
VERIFIED COMPETENCY MILESTONE
Treat these as lab deliverables. Each milestone should be documented, peer-reviewed, and included in incident runbooks and playbooks so the whole team benefits.
