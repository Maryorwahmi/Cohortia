Module 11 › Chapter 11.9 › Disk Full — Manual Runbook
Definition

Manual disk cleanup steps

Step 1
Alert for disk > 90%
Step 2
SSH into VM and run a disk usage report.
Step 3
Identify large directories with directory size commands.
Step 4
Delete old logs or temporary files and verify free space.
Misconception: SSHing and running broad deletion commands is safe if you are careful. Reality: it risks accidental deletion and inconsistent verification.
Pro tip: Replace manual inspection with a function that returns structured output for automated evaluation before removal.
Example: Use 'du' to detect large files and only delete files older than a defined age using precise paths.
Key Takeaway

Automate diagnostics first. Only perform deletions after a programmatic verification step to avoid costly mistakes.
