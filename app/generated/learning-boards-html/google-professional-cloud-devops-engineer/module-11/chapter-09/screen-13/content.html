Module 11 › Chapter 11.9 › Hands-on Activity

Activity steps

  1. 1. Grant the function's service account Compute Viewer role for the project.
  2. 2. Implement a Cloud Function that parses Pub/Sub, calls Compute API, and formats a diagnostic message.
  3. 3. Configure SLACK_WEBHOOK_URL and GCP_PROJECT_ID as environment variables and deploy the function to a test region.
  4. 4. Create a Cloud Monitoring alert that publishes to your Pub/Sub topic or publish a synthetic message for testing.
  5. 5. Verify logs and Slack messages; iterate until the diagnostic output is clear and reproducible.
Safety note: test in staging and avoid destructive commands in the function. Keep the function focused on diagnostics and let workflows perform remediation after evaluation.
Expected outcome
An automated diagnostic report that includes VM status and IP, posted to your Slack channel or available in logs for the next step in a workflow.
Key Takeaway

Start with diagnostics and incremental automation. Verify outputs and iterate before adding remediation.
