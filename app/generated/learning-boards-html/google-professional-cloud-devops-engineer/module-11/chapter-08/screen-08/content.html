Accessing a secret in Python
This snippet demonstrates the recommended client call and the requirement that the running identity has Secret Accessor permissions for that secret.
from google.cloud import secretmanager

def access_secret_version(project_id, secret_id, version_id="latest"):
  """
  Access the payload for the given secret version if it exists.
  """
  client = secretmanager.SecretManagerServiceClient()
  name = f"projects/{project_id}/secrets/{secret_id}/versions/{version_id}"
  response = client.access_secret_version(request={"name": name})
  payload = response.payload.data.decode("UTF-8")
  return payload

Practical Notes
  • Run with a service account granted Secret Accessor for the secret.
  • Avoid logging or persisting the secret; keep it in memory briefly.
  • Read project id from env or metadata, not hardcoded.
Error handling

Catch exceptions and show a clear, generic error to avoid leaking secret details in stack traces.

Key Takeaway

Use client libraries with scoped service accounts and handle failures safely to keep secrets protected.
