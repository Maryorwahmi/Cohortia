Best Practices
Avoid these common mistakes
  • Do not hardcode secrets or check them into source control.
  • Avoid project-level IAM roles for services that only need a single secret.
  • Do not rely on repository presence alone—scan and attest artifacts.
  • Protect CI signing keys and rotate them regularly.
Immediate Actions
  1. Enable Container Analysis scanning in CI and configured SCC alerts.
  2. Migrate credentials to Secret Manager and scope IAM to secrets.
  3. Configure Binary Authorization with a CI attestor and require attestations.
  4. Document and automate remediation playbooks for common findings.
Safety Note

Treat CI signing keys and service account credentials as sensitive secrets; manage and rotate them rigorously.
