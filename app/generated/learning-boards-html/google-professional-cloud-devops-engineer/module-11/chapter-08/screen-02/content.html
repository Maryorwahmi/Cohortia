Module 11 › Learning Objectives
Bloom: Learn → Understand → Apply → Master
01
Integrate security into SRE workflows

Define security checks as code and embed them in CI/CD and incident playbooks so detection leads to automatic remediation steps.

Mnemonic: pipeline-as-contract
VERIFIED COMPETENCY MILESTONE
02
Implement vulnerability and secret management

Use Security Command Center for scanning and alerts, and Secret Manager to store credentials with IAM-controlled access and audit logs.

Mnemonic: scan, store, audit
VERIFIED COMPETENCY MILESTONE
03
Secure the software supply chain

Store artifacts in Artifact Registry, scan them with Container Analysis, and require Binary Authorization attestations before deployment.

Mnemonic: store, scan, sign
VERIFIED COMPETENCY MILESTONE
04
Apply least privilege and defense-in-depth

Grant minimal permissions and implement multiple security layers so compromises are contained and observable.

Mnemonic: least, layered, logged
