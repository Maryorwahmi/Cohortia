Architecture
Artifact Registry + Container Analysis

Store images in Artifact Registry, use Container Analysis to scan them, and surface results to SCC and CI pipelines for enforcement.

Push artifact → Artifact Registry
Scan artifact → Container Analysis reports vulnerabilities
Use scan results for gating and audit trails
Concrete Example

A CI build pushes an image to Artifact Registry. Container Analysis runs and reports a medium-severity CVE. The pipeline blocks promotion until the dependency is updated and a successful scan is recorded.

Common Mistake

Failing to enforce scans before production allows vulnerable images to be deployed despite having a repository in place.

Key Takeaway

Combine repository, scanning, and policy enforcement to ensure only scanned artifacts are promoted and deployed.
