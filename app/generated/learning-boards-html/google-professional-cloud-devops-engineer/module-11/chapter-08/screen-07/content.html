Definition
Secret Manager

A central, auditable store for secrets with encryption and IAM-based access controls to prevent exposure in code or artifacts.

Access: Controlled via IAM roles such as Secret Accessor.
Encryption: Secrets are encrypted at rest and in transit.
Rotation: Combine with rotation policies to limit exposure time.
Concrete Example

An application running on a VM uses a service account with the Secret Accessor role to retrieve the database password at startup. The password is never stored in code or image layers.

Common Mistake

Granting broad secret access to many service accounts; instead, scope access to the smallest set of identities possible.

Key Takeaway

Use Secret Manager with narrow IAM grants, rotation, and audit logs to keep credentials out of code and artifacts.
