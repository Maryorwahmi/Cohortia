Comparison › A/B Testing
Experiment workflow
  1. Define hypothesis and primary metric.
  2. Implement variants behind flags and target segments.
  3. Collect events and analyze results in BigQuery or Firebase.
  4. Decide: promote, iterate, or roll back based on data.
Concrete example
Test two checkout flows for conversion rate; enable new flow for a random 10% cohort and measure purchases over two weeks.
Pitfall
Insufficient sample size or wrong metrics can lead to false positives; predefine success criteria and sample size.
Key Takeaway

Design experiments with clear metrics and thresholds. Use flags to run controlled comparisons, then measure with BigQuery or Firebase tools.
