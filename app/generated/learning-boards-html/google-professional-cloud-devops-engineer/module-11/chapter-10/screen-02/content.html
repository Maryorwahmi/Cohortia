How to use these objectives
  • Map each objective to a measurable outcome, like completed action items from a post-mortem or a scheduled SLO review cadence.
  • Use small experiments: pilot developer on-call, run a single blameless post-mortem, or create a single canonical runbook page.
  • Track follow-through: assign owners and deadlines to action items so culture becomes practice rather than rhetoric.
These objectives form the rubric you will use during assessments and the hands-on activity.
