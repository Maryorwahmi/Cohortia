Toolset overview

Connectivity Tests and Topology

Connectivity Tests simulates packet flow and identifies the configuration element blocking it. Network Topology draws relationships between resources and traffic flows. Firewall Insights finds shadow and overly broad rules.

  • Connectivity Tests analyze firewall rules, routes, and tags to predict success.
  • Topology helps reveal unexpected resource paths and dependencies.
  • Firewall Insights highlights rules that never match or which are too permissive.
Concrete example
Blocked probe identified by Connectivity Test

A test from a VM to a load balancer will report which firewall rule or route prevents the connection. It provides the exact match and the reason, which is actionable evidence for a fix.

Misconception
Topology is not a live packet trace. Use it to form hypotheses, then confirm with flow logs or connectivity tests that evaluate live configuration state.
Key Takeaway

Use simulation and visualization together to convert configuration complexity into precise, actionable evidence.
