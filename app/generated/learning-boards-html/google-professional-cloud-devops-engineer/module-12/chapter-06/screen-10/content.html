Health checks

Probe path, port, and protocol must match

If health checks fail, the load balancer will stop sending requests to that backend. Verify the probe path and port are correct and that the application returns success on that path.

Checklist
  • Health check path and port match the application.
  • Backend instance groups include correct instances and ports.
  • Firewall rules allow probes from Google health check ranges.
  • Use load balancer logs to correlate errors with backend selection.
Concrete example
Backends removed due to wrong probe path

If your app only serves status on "/healthz" but the health check uses "/", probes will fail. Fix the probe path, then check backend health and logs to confirm requests resume normally.

Misconception: scaling backends will not help if health checks are misconfigured. Address probe mismatch first to restore healthy endpoints.
Key Takeaway

Confirm probe configuration and firewall allowances before adjusting capacity or instance groups.
