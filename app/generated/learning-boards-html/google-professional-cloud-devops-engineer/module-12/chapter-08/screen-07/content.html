Investigation

Form hypotheses and test fast

Collect logs, traces, metrics, and runtime status. Prioritize checks that confirm or refute the most likely causes.

Quick checks: recent_deploy, pod_status, top_error_logs, SLO trend.
Tools: Cloud Logging, Cloud Trace, Cloud Debugger, kubectl.
Method: hypothesis → minimal check → iterate.
Scenario walkthrough
  1. Alert: 5xx spike for checkout.
  2. Check recent deploys and pod restarts.
  3. Look for error traces that reference payment integration.
  4. Confirm hypothesis before rollback: failing dependency or bad image.
Common mistake
Spending hours on deep root causes before restoring service. First stabilize, then analyze for permanent fixes.
