Metrics

Measure and improve

Track MTTD and MTTR. Use post-mortem action items to target the largest contributors to those metrics and verify improvement over time.

MTTD: How long until an incident is detected. Improve with better alerts and synthetic checks.
MTTR: How long until service is restored. Improve with runbooks and automation for common tasks.
Hands-on activity
Simulate a checkout outage, run the triage and rollback, draft internal and external communications, and write a 200–300 word blameless post-mortem including action items and owners.
Reflection prompt
Think about a past outage: which single action item from a post-mortem would most reduce MTTR if completed now?
