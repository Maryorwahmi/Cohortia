Module 12 › Chapter 12.8 › Objectives: Evidence
Objective Evidence Map
  • Detection: Create or refine an alert that reduces MTTD. Include threshold and runbook link.
  • Triage: Use a severity matrix and classify a simulated incident correctly.
  • Communication: Submit an internal log entry and an external status page draft.
  • Post-mortem: Write a blameless document with assigned action items.
How we'll validate
Review artifacts for clarity and measurability. Action items should be specific, measurable, and assigned. Runbooks should be runnable and up-to-date.
Milestone: Reduce MTTR on a common incident in the next simulation.
Reminder: Blameless is about systems and process, not individuals.
