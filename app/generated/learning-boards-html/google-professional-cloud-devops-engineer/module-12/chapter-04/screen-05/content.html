The four golden signals
Latency, Traffic, Errors, Saturation — the minimal set to start effective monitoring.
Latency
Track p50, p95, p99 to capture normal and tail latency.
Traffic
Requests per second or active sessions measure load on the system.
Errors
Error rate such as 5xx responses indicates failed user requests.
Saturation
Resource utilization and queue lengths that cap throughput.
Concrete scenario
During a flash-sale, traffic doubles and saturation rises. If latency and errors increase only while saturation is high, scaling or throttling is likely the right mitigation. If errors increase without saturation, investigate failure modes or dependency issues.
Key Takeaway

Use the four golden signals as the default dashboard spine and adapt charts per service and business flow.
