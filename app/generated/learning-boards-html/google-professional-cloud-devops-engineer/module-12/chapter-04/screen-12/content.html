From logs to metrics
Create counters from structured logs to feed dashboards and SLOs without code changes.
Example log-based counters to create
  1. app_requests_total: Filter by log name for all request entries.
  2. app_errors_total: Filter by log name and jsonPayload.status_code = 500 for error counts.
After creation, use these metrics to build charts or compute an error rate via MQL or by joining numerator and denominator in alerts and SLO definitions.
Hands-on checklist
  • Simulate structured logs with gcloud logging write to populate sample data.
  • Define log-based metrics in Cloud Logging and wait a few minutes for data to appear.
  • Use metrics in dashboard panels and SLO definitions as required.
Key Takeaway

Log-based metrics are a quick path to observability when code changes are not feasible; monitor processing delays and label cardinality.
