01
Design effective dashboards
Build dashboards that surface the four golden signals and business metrics so triage starts with clear context. A concise dashboard reduces time-to-detect and helps you know which drill-down to run first.
Venn mnemonic: Signals + Business + Infra
VERIFIED COMPETENCY MILESTONE
02
Create advanced alerting policies
Combine multiple conditions and appropriate notification channels to reduce false positives and ensure on-call actionability. Multi-condition logic like AND helps surface only service-impacting events.
Timeline mnemonic: Condition → Channel → Priority
VERIFIED COMPETENCY MILESTONE
03
Utilize SLO monitoring
Define SLIs and SLOs, track error budget burn, and configure alerts that warn you when budget is being consumed too quickly. This protects customer experience proactively rather than reacting after violations.
Timeline mnemonic: SLI → SLO → Budget
VERIFIED COMPETENCY MILESTONE
04
Implement custom and log-based metrics
Instrument business metrics via the API or OpenTelemetry, and derive metrics from logs when needed, so monitoring reflects core application behavior for debugging and alerting.
Icon mnemonic: Counter + Label + Time
VERIFIED COMPETENCY MILESTONE
How to use these objectives
Follow the hands-on lab to practice each objective. Each milestone maps to a lab task: build the dashboard, create the alert, define the SLO, and push a custom metric. Validation is hands-on: the dashboard shows the metric, the alert triggers under conditions, and the SLO reports burn rate.
