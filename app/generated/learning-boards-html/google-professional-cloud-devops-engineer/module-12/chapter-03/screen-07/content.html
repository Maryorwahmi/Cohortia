Architecture

How instrumentation reaches Cloud Trace

SDKs create spans and an exporter sends them to Cloud Trace. You configure a TracerProvider, exporter, and processors to control export behavior.

TracerProvider
Registers instrumentation and resources like service name.
Exporter
Transforms and sends spans to Cloud Trace using your project credentials.
Instrumentation
Automatic or manual; ensures spans are created for framework and library operations.
Concrete example
# Configure OpenTelemetry TracerProvider and Cloud Trace exporter
resource = Resource.create({"service.name": "my-python-service"})
provider = TracerProvider(resource=resource)
cloud_trace_exporter = CloudTraceSpanExporter(project_id="YOUR_PROJECT_ID")
provider.add_span_processor(SimpleSpanProcessor(cloud_trace_exporter))
trace.set_tracer_provider(provider)
This setup creates a provider, attaches the Cloud Trace exporter, and registers it so spans flow to Cloud Trace.
