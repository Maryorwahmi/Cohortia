from opentelemetry.instrumentation.flask import FlaskInstrumentor

resource = Resource.create({"service.name": "service-b"})

provider.add_span_processor(SimpleSpanProcessor(cloud_trace_exporter))

Explanation

Service B continues traces by reading propagated headers and creating spans for validation. Attributes on the span allow you to filter traces by item id or validation status in Cloud Trace.

Error case
If item_id is "invalid", the span sets validation.status to failed, which you will see in the waterfall and span details.
Takeaway
Downstream attributes are critical for diagnosing whether a business-level check failed in validation or earlier.
