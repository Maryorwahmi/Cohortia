Waterfall diagram and filters

The waterfall diagram visualizes span timing. Filters let you find traces by service, latency, or attributes like item id.

Filter example
Filter by service.name and item.id to locate a failing request trace quickly.
Interpreting bars
Long bars point to latency; error-marked bars indicate exceptions or non-OK status.
Practical flow
  1. Open Cloud Trace and set a time window that includes your test run.
  2. Filter by service.name or attribute like item.id to find the trace.
  3. Inspect the waterfall and click the slow or error spans to view attributes and related logs.
Quick tip

Use attribute-based filters to find business-specific failures, not just service-level latency spikes.
