Practical Skills to Practice

These skills will be validated during the hands-on lab: export, enrich, filter, and correlate.

Configure exporters
Set the Cloud Trace exporter and confirm spans arrive in the console.
Create custom spans
Wrap important business steps in manual spans and add attributes like user or item IDs.
Filter and analyze
Use latency filters and attribute searches to locate representative traces.
Correlate logs
Ensure trace IDs are available in logs to jump from a span to related log entries.
