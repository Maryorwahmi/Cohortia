Read-only checks

Describe commands you can run immediately

These commands collect configuration, status, and recent events that form the factual basis of your hypotheses.
gcloud compute instances describe my-instance --zone=us-central1-a

gcloud container clusters describe my-cluster --zone=us-central1-a

# Save outputs for incident notes
gcloud compute instances describe my-instance --zone=us-central1-a > instance-describe.txt
Interpretation tip: look for 'status', 'networkInterfaces', attached disk states, and any recent events that reference reboots, image changes, or maintenance.
Example
Scenario
A VM in us-central1-a shows a stopped state after an unexpected outage. Describe output reveals a recent maintenance event.
Misconception
Don’t assume application logs are the first stop; platform events can explain many outages faster.
Key Takeaway

Start with read-only describe commands, save outputs for RCA, and only escalate to deeper access after initial facts are collected.
