kubectl and gcloud sequence

# List pods and check status
kubectl get pods -n default

# Describe the failing pod to read events
kubectl describe pod broken-nginx-deployment-xxxxx -n default

# Inspect cluster health
gcloud container clusters describe troubleshooting-cluster --zone=us-central1-a

# Fix the deployment and reapply
kubectl apply -f deployment.yaml

# Verify pods are Running
kubectl get pods -n default
Note: these commands are read-only except for kubectl apply; always capture describe outputs before applying changes so you can record the before-state.

  replicas: 1
  template:

Fix and verification
Correct the image to nginx:latest, apply the manifest, and ensure pods become Running then test service connectivity.
