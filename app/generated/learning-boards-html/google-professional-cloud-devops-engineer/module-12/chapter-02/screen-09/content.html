Module 12 › Chapter 12.2 › Log-based Metrics
Counter metric example
Filter:
logName="projects/YOUR_PROJECT_ID/logs/my-application-logs" AND jsonPayload.status="failure"
Metric Type: Counter
Metric Name: failed_payments_total
Counters give an immediate event count for alerting and dashboards.
Distribution metric example
Filter: logName="projects/YOUR_PROJECT_ID/logs/access_logs" AND jsonPayload.latency_ms>0
Metric Type: Distribution
Field: jsonPayload.latency_ms
Distributions let you chart percentiles and detect latency regressions.
Testing & common mistakes
  • Generate sample logs with gcloud logging write to verify metrics increment.
  • Avoid filters that match unrelated logs; use resource and jsonPayload filters together.
  • Decide alert thresholds based on historical values, not guesswork.
Key Takeaway

Log-based metrics turn logs into operational signals for monitoring and alerts.
