Basic query example
resource.type="cloud_run_revision"
resource.labels.service_name="auth-service"
severity=ERROR
jsonPayload.user="john.doe"
timestamp>="2023-10-26T10:00:00Z"
Combine resource, severity, and jsonPayload filters. Use timestamp limits to bound results and improve performance.
Operators & tips
  • AND / OR to combine conditions.
  • ~ for regex matches when values vary.
  • Start broad then narrow; always include a recent time range when testing.
Common mistake
Writing a complex regex as a first step; instead, filter by severity and service first to reduce volume.
