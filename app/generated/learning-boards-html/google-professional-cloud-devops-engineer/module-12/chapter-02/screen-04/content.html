What is structured logging?

Structured logging is emitting JSON objects with fields that describe the event. Cloud Logging maps JSON into jsonPayload for direct filtering and extraction.

Concrete example
{
  "message": "User failed to login",
  "severity": "ERROR",
  "user": "john.doe",
  "ip_address": "192.168.1.100",
  "service": "auth-service",
  "transaction_id": "abc-123"
}
Why it matters
Fields are searchable and stable for metrics.
Common mistake
Over-logging or emitting inconsistent field names across services.
Practice checklist
  • Emit JSON to stdout/stderr so Cloud Logging parses jsonPayload.
  • Choose consistent field names such as transaction_id and user.
  • Limit fields to those needed for queries, metrics, and tracing.
Key Takeaway

Treat logs as structured data: choose fields that enable fast queries and metrics.
