Module 12 › Chapter 12.2 › Query Process
Step-by-step
1. Resource
Filter by resource.type and labels.
2. Severity
Keep ERROR/WARNING to reduce noise.
3. Payload
Use jsonPayload.field="value".
4. Time
Always set a timestamp bound for tests.
5. Extract
Move to metrics or CSV export if you need counts.
Example iterative query: start with resource and severity, confirm volume, then add jsonPayload.order_id to isolate problematic transactions. This iterative approach avoids timeouts and large result sets.
