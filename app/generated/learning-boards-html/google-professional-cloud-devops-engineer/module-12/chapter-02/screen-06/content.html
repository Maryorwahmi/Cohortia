What jsonPayload gives you
  • Direct access to keys like jsonPayload.user in queries and filters.
  • Ability to create log-based metrics from specific fields.
  • Cleaner, more reliable searches than text parsing.
Naming best practice
Use stable field names such as transaction_id, user_id, latency_ms across services to simplify cross-service queries and metric definitions.
Example: distribution metric
Filter: logName="projects/YOUR_PROJECT_ID/logs/access_logs" AND jsonPayload.latency_ms>0
Metric type: Distribution
Field: jsonPayload.latency_ms
This creates a metric you can chart for latency percentiles and use in alerting policies.
