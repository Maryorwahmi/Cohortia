Module 12 › Chapter 12.2 › Emit JSON
Python example (conceptual)
import json
import logging

logger = logging.getLogger('app')
# Configure a JSON formatter in production; here we format manually
entry = {
  "message": "Order processed successfully",
  "order_id": "ORD-12345",
  "status": "success",
  "user_id": "user-A"
}
print(json.dumps(entry))
Output this to stdout. Cloud Logging will parse it into jsonPayload so fields are queryable.
Node.js / Java notes
Use Winston, Pino, or your framework's JSON layout to emit single-line JSON. Avoid multi-line stack traces embedded in JSON; prefer structured error fields.
Quick test using gcloud
gcloud logging write my-app-log '{"message":"Payment failed","order_id":"ORD-12346","status":"failure","user_id":"user-B","error_code":"PAY-001"}' --payload-type=json --severity=ERROR --log-name=my-application-logs
Key Takeaway

Emit a single-line JSON object per event to ensure reliable jsonPayload parsing.
