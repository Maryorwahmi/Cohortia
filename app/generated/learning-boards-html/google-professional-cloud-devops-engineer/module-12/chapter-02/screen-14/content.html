Structured Logging
Emit JSON so fields like transaction_id and user are queryable.
Log-based Metrics
Create counters or distributions from matching log entries for monitoring and alerts.
Log Sinks
Export filtered logs to Storage, BigQuery, or Pub/Sub for retention and analysis.
Summary

Design logs as structured data, derive metrics for signals, and export selectively to manage cost and support analytics.
