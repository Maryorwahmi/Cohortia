Module 12 › Chapter 12.2 › Log Sinks
Cloud Storage
Long-term, cost-effective archival. Good for compliance retention of raw logs.
BigQuery
Analytical queries over large log volumes with SQL for security and BI workflows.
Pub/Sub
Real-time streaming to downstream processors or third-party systems.
gcloud example
gcloud logging sinks create my-error-logs-sink \
    storage.googleapis.com/my-log-archive-bucket \
    --log-filter='severity=ERROR' \
    --description="Archive all ERROR logs to Cloud Storage" \
    --organization=organizations/YOUR_ORG_ID
After creating a sink, grant the Cloud Logging service account Storage Object Creator on the bucket so exports succeed.
Key Takeaway

Use filtered sinks plus exclusions/retention rules to balance observability and cost.
