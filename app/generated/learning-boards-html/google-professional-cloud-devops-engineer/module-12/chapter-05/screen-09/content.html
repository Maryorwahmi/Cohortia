Process Flow › Console & CLI
Console flow
Open Cloud Debugger in the Console, select your service, open the file, and click a line number to add a snapshot or logpoint. Wait for a hit and inspect captured state.
Trigger example
# Trigger snapshot curl "YOUR_CLOUD_RUN_URL/calculate/10" # Check the Cloud Debugger console for the captured snapshot
gcloud usage
You can script point create/remove with gcloud for repeatable debugging during incidents. Use scripted commands cautiously and remove points after use.
Troubleshooting: If points do not appear, verify the agent is running, module and version match source context, and the service account has the Cloud Debugger Debuggee role.
Check your understanding
Did the snapshot show the expected variables and stack frames? If not, re-check mapping and agent initialization.
