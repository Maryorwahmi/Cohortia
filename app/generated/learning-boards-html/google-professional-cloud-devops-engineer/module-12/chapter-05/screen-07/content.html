Architecture › Agent & Environments
Supported environments
  • App Engine (Standard / Flexible)
  • Google Kubernetes Engine (GKE)
  • Compute Engine
  • Cloud Run
Key requirement: include the language agent and ensure the runtime's service account has the Cloud Debugger Debuggee role so the agent can register debuggees and send snapshots/logpoints.
Concrete code hint
# Python example snippet (initialize early) import googleclouddebugger googleclouddebugger.enable(module='my-flask-app', version='v1.0.0')
Misconception: environment managed means automatic mapping. You still must provide accurate module and version labeling or integrate with source context so the Console can match source lines.
Pro-tip
Initialize the agent in your application entrypoint before creating server listeners to ensure it registers before serving traffic.
