Log
Use logpoints for streaming checks
Inject temporary logs that include expressions to watch values over time without heavy overhead.
Snapshot
Use snapshot points for full state
Capture local and global variables plus call stack for a precise frozen view when investigating complex bugs.
Safety
Follow safety and cleanup
Limit hits, avoid sensitive fields, grant least privilege, and remove points when finished.
