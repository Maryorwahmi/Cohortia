Initialization pattern
import os
from flask import Flask, request
import googleclouddebugger

try:
  googleclouddebugger.enable(
    module=os.environ.get('K_SERVICE', 'my-cloud-run-service'),
    version=os.environ.get('K_REVISION', 'default')
  )
  print("Cloud Debugger enabled.")
except Exception as e:
  print(f"Failed to enable Cloud Debugger: {e}")
Note: guard the call so local testing without credentials doesn't break startup. Use environment-provided module/version values in managed runtimes.
Where to set points
Set a snapshot on intermediate calculations such as intermediate_value = result + 5 to capture num, result, and intermediate_value. Set a logpoint on response construction to emit a debug message including user_input.
Misconception: the enable call alone will not allow snapshots if the service account lacks the required IAM role. Confirm Cloud Debugger Debuggee permission for the runtime's service account.
