Debugging Applications in Production with Cloud Debugger

Learn how to safely inspect state, set snapshot points, and inject temporary logs into running services across App Engine, GKE, Compute Engine, and Cloud Run. This reduces disruption and helps diagnose bugs that only appear in production.

In this lesson
Set snapshot points and logpoints, enable the debugger agent, and follow safety practices when inspecting production state.
Why it matters
You can diagnose race conditions, data-specific errors, and environment-dependent bugs without redeploying or creating downtime.
Explore Key Topics
Snapshot Points
Capture variables and the call stack when a line executes, giving a frozen view of state without pausing requests.
Logpoints
Inject temporary log messages that include expressions, then view results in Cloud Logging.
Safety & Mapping
Ensure agent installation, IAM role, and correct module/version mapping to avoid confusion and overhead.
