Best Practices › Safety & Ops
Permissions
Assign the Cloud Debugger Debuggee role to the runtime service account so the agent can register and communicate securely.
Source mapping
Provide correct module and version labels or source context so the Console can match running code to repository lines.
Data & overhead
Avoid capturing or logging sensitive PII. Limit snapshot hits and keep logpoint expressions simple to reduce performance impact and log volume.
Cleanup
Remove snapshot points and logpoints when debugging is complete as part of incident closure.
