Logpoints
Temporary injected logs that evaluate expressions and deliver messages to Cloud Logging without redeploying.
When to use
  • Track a value over many requests.
  • Gather occurrence frequency or patterns before using a snapshot.
  • Low-overhead checks in high-traffic services.
Key Takeaway

Use logpoints for repeated, lightweight observation, and avoid capturing sensitive fields in log messages.

Concrete example
# Set a logpoint on greeting line # Message: DEBUG: Greeting for user: {user_input} # Then curl the root URL to see injected logs in Cloud Logging
Misconception check: A logpoint is not a replacement for a snapshot when you need the call stack. It is a focused log emission, not a full state capture.
Pro-tip: include only necessary expressions to reduce log volume and privacy risk.
