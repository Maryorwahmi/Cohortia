Troubleshooting › Common Errors
Source mapping error
Cause: module/version mismatch. Fix: update agent labels or provide source context so the Console can map lines to deployed code.
Permission failure
Cause: missing Cloud Debugger Debuggee role. Fix: grant the role to the runtime service account and retry registration.
Agent init issues
Cause: agent enable called too late or exceptions during enable. Fix: initialize elector early, wrap with try/except, and log failures safely.
Quick checklist
  • Check agent startup logs for enable confirmation.
  • Confirm IAM role on service account.
  • Verify module/version matches the Console's source view.
  • Trigger a controlled request and inspect Console snapshots.
