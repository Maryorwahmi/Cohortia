Architecture

Pipeline components

Cloud Build
Build and test container images as part of CI/CD pipelines.
Artifact Registry
Store and manage container images and artifacts used in deployments.
GKE
Common compute target for containerized apps; supports canary, blue/green, and rolling updates.
Deployment strategies
Canary
Shift a small subset of traffic to the new version, monitor real behavior, and gradually increase traffic if stable.
Blue/Green
Deploy a complete new environment and switch traffic after validation to achieve near-zero downtime.
Rolling update
Replace instances incrementally; lower resource cost but higher immediate blast radius than canary.
Concrete example:
For a payment system demanding 99.99% availability and automated rollback, a blue/green or canary with automated monitoring-triggered rollback meets the constraints while minimizing operational overhead.
