Definition

IAM and secret management

Practice the principle of least privilege with service accounts for CI/CD pipelines. Use secure secret stores instead of embedding secrets in images, and prefer native network controls to limit data exposure.
Concrete example
Grant Cloud Build a service account that only has permissions to push images and deploy to a specific cluster, not organization-wide admin rights.
Common misconception
Using overly broad roles to avoid setup friction. The exam favors minimal, auditable permission models aligned with security best practices.
Supporting practice
Map each CI/CD step to the specific IAM permissions it needs. Practice rotating and retrieving secrets from a secret manager during pipeline runs to internalize secure patterns.
Key Takeaway

Prefer least privilege service accounts and native secret management when the scenario requires secure, auditable automation.
