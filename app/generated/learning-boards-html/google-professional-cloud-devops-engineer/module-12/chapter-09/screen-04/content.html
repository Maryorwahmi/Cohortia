Core Concept

Exam format and structure

Multiple-choice and multiple-select questions, 50–60 items, ~120 minutes. Scenarios require applied decisions, not memorization.
Key facts
  • 50–60 questions; roughly two minutes per question.
  • Scenario-based items ask for practical trade-offs.
  • Answers favor native Google Cloud best practices.
Concrete example
A question asks for zero-downtime deployments with automatic rollback. You should prefer strategies that automate rollback via monitoring and use native services like Cloud Build and Cloud Monitoring wherever possible.
Common misconception
Treating the exam as fact recall. Instead, practice mapping constraints to operational solutions and weigh trade-offs.
Key Takeaway

Prepare to reason about scenarios. Use two-minute pacing during practice to build steady timing.

Exam quick-reference panel
Timing
~120 minutes total; aim for two minutes per question and mark hard items for review.
Question types
Multiple-choice, multiple-select, and scenario-based questions that require trade-off reasoning.
Scoring tip
Prioritize answers that meet all constraints and follow Google Cloud native best practices.
Practice prompt
Simulate a timed session and practice extracting the scenario’s core requirements first.
