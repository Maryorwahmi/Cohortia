Module 12 › Chapter 12.7 › Image & Registry Issues
Checklist for image issues
  1. Does the pushed image exist with the expected tag in Artifact Registry?
  2. Does the GKE node or service account have reader permissions?
  3. Is the manifest using the exact tag and repository string?
Example fix

If deployment refers to v0.0.0 but you pushed v0.0.2, update the k8s manifest to the correct v0.0.2 tag and redeploy. If nodes cannot pull, grant Artifact Registry Reader or Storage Object Viewer to node service accounts.
