Module 12 › Chapter 12.7 › Cloud Build Logs
What to look for
  • Step id and command that failed.
  • Lines before the error for dependency resolution or network timeouts.
  • Permission denied messages for push or deploy steps.
  • Exit codes and stack traces indicating OOM or compilation errors.
Pro tip

Copy the exact failing command into a local container that matches your base image and run it there to reproduce the error reliably.

Example log snippet
Step #2: RUN pip install -r requirements.txt
Step #2: Collecting Flask
Step #2:   Downloading Flask-1.1.2-py2.py3-none-any.whl (94 kB)
Step #2: ERROR: Could not find a version that satisfies the requirement requests (from -r requirements.txt (line 3))
Step #2: ERROR: No matching distribution found for requests
Finished step #2 with status "FAILURE"
From this output you know the failing command, the missing package, and that the fix is adding the package to requirements.txt or fixing the package index configuration.
