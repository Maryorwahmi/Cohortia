Module 12 › Chapter 12.7 › Key Concepts
Cloud Build Logs
Per-step output that identifies the failing command and error context.
ImagePullBackOff / ErrImagePull
Indicates tag or permission issues preventing Kubernetes from pulling an image.
Readiness & Liveness Probes
Health checks that control serving readiness and pod restarts; misconfigured probes block traffic or cause restarts.
Summary

Start with logs, reproduce locally, check tags and IAM, tune probes, then validate with kubectl commands.
