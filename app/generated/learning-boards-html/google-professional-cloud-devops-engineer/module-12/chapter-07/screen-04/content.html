Module 12 › Chapter 12.7 › Troubleshooting Process
Process Flow
1. Collect logs — Cloud Build step logs, kubectl describe, get events.
2. Isolate the failing step — find the exact failing command or pod.
3. Reproduce locally — run the command or Docker run to confirm the error.
4. Make a minimal change — fix requirements, path, or tag.
5. Validate — re-run build and check pod readiness and events.
Example

Cloud Build fails at a pip install step. You copy the failing pip command into a local Python 3.9-slim container and run it. The error shows a missing dependency. You add the package to requirements.txt, rebuild, and Cloud Build succeeds.

Key Takeaway

A small, reproducible test isolates whether the issue is pipeline configuration or application code.

Common mistake

Changing multiple manifest files at once hides which change fixed the pipeline. Apply one change and rerun.
