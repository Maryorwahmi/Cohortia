Module 12 › Chapter 12.7 › Image Pull Errors
kubectl checks
  • kubectl get pods — check status.
  • kubectl describe pod <pod-name> — read events for manifest, tag, or auth errors.
  • Confirm image exists in Artifact Registry with the exact tag.
Quick fixes
Correct the image tag in the deployment if it’s wrong. If the error indicates 'access denied', grant Artifact Registry Reader to node service accounts or configure Workload Identity so the pod can authenticate to the registry.
