Module 12 › Chapter 12.7 › Probes & Health Checks
Symptoms of probe issues
  • Pod remains NotReady despite container running.
  • Pod restarts frequently and shows CrashLoopBackOff.
  • Probe failures mention HTTP codes or timeout in events.
Debug steps
  1. kubectl describe pod to read probe events.
  2. kubectl logs to inspect app startup errors.
  3. curl the health path from inside the cluster or locally.
Key Takeaway

Probes are safeguards; tune timings or fix the application endpoint instead of disabling them.

Common mistake

Using a non-existent probe path like /healthz when the app only serves / will keep pods NotReady.
