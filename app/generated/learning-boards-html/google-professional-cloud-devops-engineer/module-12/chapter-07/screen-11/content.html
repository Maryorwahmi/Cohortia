Module 12 › Chapter 12.7 › Local Reproduction
Steps
  1. Run the failing command in a matching base image container.
  2. For probes, start the container and curl the health endpoint.
  3. For image pulls, confirm tag exists in Artifact Registry before cluster pull.
Local reproduction reduces uncertainty and points you to either build config, networking, or IAM differences if it still fails in CI/CD.
Example

You run a container locally, curl /healthz and get 404 because the app exposes / only. Update the readiness probe path in the manifest and redeploy.
