Module 12 › Chapter 12.7 › Permission Errors
Symptoms in logs
  • 'permission denied' during docker push.
  • 'access denied' when writing to a storage bucket.
  • Deploy steps failing with API permission errors.
Trace the principal shown in logs — the Cloud Build service account — and check its IAM bindings on the resource referenced by the failing step.
Common roles to verify
  • Artifact Registry Writer for pushing images.
  • Storage Object Admin for writing GCS artifacts.
  • Kubernetes Engine Developer for deploying to clusters.
Mistake to avoid

Granting overly broad roles can mask the real need and create security risk. Apply the least privilege required to the specific resource.
