Module 12 › Chapter 12.7 › Lab Walkthrough
Lab steps (overview)
  1. Trigger Cloud Build with the provided cloudbuild.yaml to see failing pip install.
  2. Run the failing pip command in a matching local container and reproduce the missing dependency.
  3. Update requirements.txt and app.py to include requests; bump the _TAG substitution and rebuild.
  4. Use kubectl to inspect pods; fix image tag and readiness probe path in k8s-deployment.yaml.
  5. Apply manifest and confirm pods become Ready and Service is reachable.
Checkpoint

By the end you should have a successful build and a Ready pod in GKE, and you will have recorded the minimal changes that fixed the pipeline.

Starter file excerpts
app.py, requirements.txt, Dockerfile, k8s-deployment.yaml, cloudbuild.yaml are provided. Key intentional errors: missing requests in requirements, bad image tag v0.0.0 in deployment, bad readiness path /healthz.
