Module 12 › Chapter 12.7 › Dependency Issues
Symptoms
  • pip or npm install fails with "No matching distribution" or similar message.
  • Build logs show compilation errors for packages that need system libs.
  • Runtime import errors after container starts.
How to debug
  1. Run the failing install command in a local container matching your base image.
  2. Ensure requirements.txt/package.json includes the package and correct versions.
  3. Install any system-level build dependencies in the Dockerfile if needed.
Concrete analogy

Think of the image as an empty kitchen. If a recipe needs a special tool, the recipe will fail unless that tool is installed. The Dockerfile must provide that tool before the install step runs.

Key Takeaway

Missing build dependencies show up in build logs; reproduce and fix in the Dockerfile or requirements file, not by editing runtime code alone.
