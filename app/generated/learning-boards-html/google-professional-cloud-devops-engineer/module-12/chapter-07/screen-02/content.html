Module 12 › Chapter 12.7 › Learning Objectives
01
Diagnose Cloud Build failures

Read step-by-step build logs to find dependency installs, failing commands, and resource errors. This helps you know whether the fix belongs in code, Dockerfile, or cloudbuild.yaml.

VERIFIED COMPETENCY MILESTONE
02
Troubleshoot GKE deployments

Diagnose ImagePullBackOff, readiness and liveness probe failures, and resource constraints using kubectl describe, logs, and events.

VERIFIED COMPETENCY MILESTONE
03
Use logs and events effectively

Combine Cloud Build logs with kubectl describe, logs, and get events to triangulate causes instead of relying on a single error message.

VERIFIED COMPETENCY MILESTONE
04
Fix service account permission issues

Identify when Cloud Build or GKE needs IAM roles like Artifact Registry Writer, Storage Object Admin, or Kubernetes Engine Developer, and know how to check for permission denied errors.

VERIFIED COMPETENCY MILESTONE
