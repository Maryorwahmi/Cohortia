Module 12 › Chapter 12.7 › Build Steps vs Code Errors
Common cloudbuild.yaml issues
  • Commands run in wrong working directory (missing files).
  • Step ordering that expects artifacts not yet produced.
  • Typos in args or substitutions causing unexpected commands.
Fix these by checking step ids, verifying COPY/WORKDIR lines in Dockerfile, and running the same sequence locally if possible.
Comparison
Build config error

Fails during build steps; no image produced. Edit cloudbuild.yaml or Dockerfile.

Application bug

Image builds but pod crashes or misbehaves. Inspect application logs and code.

Check this first

If build logs show 'file not found' or command not recognized, start in cloudbuild.yaml. If container runs then crashes, start in app logs.
