Authentication Bypass: Weak & Default Credentials

Exploiting easily guessable or factory-set login details.

Default Credentials

Many systems ship with pre-set usernames and passwords (e.g., admin:admin) that are often left unchanged.

Weak Passwords

Users often choose easily guessable passwords, making them vulnerable to simple dictionary attacks.

Key Takeaway

Always check for default and weak credentials first; they are often the path of least resistance to initial access.

Common Default Credentials

Examples of frequently encountered default username:password pairs.

admin:admin

Generic administrator login.

root:toor

Common for Linux systems, 'root' spelled backward.

ftp:ftp

Default for some FTP servers.

user:user

Another common generic user account.

Warning: Always change default credentials immediately after deployment to prevent easy compromise.
