Nmap for Service Version Detection

Using the -sV flag to identify specific service versions.

The -sV Flag

Instructs Nmap to perform service and version detection on open ports.

Targeted Exploitation

Specific versions often have known public exploits, allowing for precise attack planning.

Key Takeaway

Always use -sV with Nmap to gather crucial version information, which directly informs your exploit selection.

# Scan for common services and their versions on a target IPnmap -sV <TARGET_IP>

This command initiates a service version detection scan. Replace <TARGET_IP> with the actual IP address of your target machine. The output will list open ports along with the detected service and its version, if identifiable.

# Example Nmap Output (partial)PORT   STATE SERVICE VERSION21/tcp open  ftp     vsftpd 2.3.422/tcp open  ssh     OpenSSH 7.2p2 Ubuntu 4 (Ubuntu Linux; protocol 2.0)80/tcp open  http    Apache httpd 2.4.18 ((Ubuntu))

Notice how Nmap identifies not just the service (e.g., ftp, ssh, http) but also the specific software and version (e.g., vsftpd 2.3.4, OpenSSH 7.2p2). This detail is invaluable for finding known exploits.
