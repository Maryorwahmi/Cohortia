Core Concept

Network Services as Attack Surfaces

Understanding common service vulnerabilities beyond web applications.

Essential Services

FTP, SSH, and SMB are critical for network operations but can be exploited if not secured.

Vulnerability Factors

Misconfigurations, unpatched software, and weak authentication are primary causes of compromise.

Initial Access Vector

Exploiting these services often provides the first foothold into a target network or system.

Key Takeaway

Every active network service represents a potential attack surface that must be thoroughly enumerated and secured.

Common Vulnerable Services

Services frequently targeted due to inherent risks or common misconfigurations.

FTP (Port 21)

File Transfer Protocol: often vulnerable to anonymous login or weak credentials.

SSH (Port 22)

Secure Shell: can be vulnerable to brute-force attacks or outdated versions.

SMB (Port 445)

Server Message Block: often exploited due to weak permissions or unauthenticated access.

Telnet (Port 23)

Remote Terminal: often transmits credentials in plaintext, making it highly vulnerable.
