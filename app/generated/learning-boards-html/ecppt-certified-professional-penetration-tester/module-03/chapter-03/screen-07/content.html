Executing Arbitrary OS Commands

Command Injection occurs when an application executes OS commands based on user input without proper validation, allowing attackers to inject additional commands.

Vulnerable Application Behavior

If a web application passes user input directly to system commands (e.g., ping, ls, cat), it's vulnerable.

Command Separators

Characters like semicolon (;) on Linux or ampersand (&) on Windows allow chaining multiple commands.

Key Takeaway

Command Injection provides a direct path to operating system control, enabling arbitrary code execution and system compromise.

Command Injection Example

// Original command structure:
ping -c 4 user_input

// Attacker input (Linux):
127.0.0.1; ls -la /

// Resulting command executed by server:
ping -c 4 127.0.0.1; ls -la /

The semicolon (;) allows the ls -la / command to execute after ping.

// Example URL with encoded payload:
http://example.com/ping.php?host=127.0.0.1;ls%20-la%20/

%20 is the URL-encoded space, essential for web requests.
