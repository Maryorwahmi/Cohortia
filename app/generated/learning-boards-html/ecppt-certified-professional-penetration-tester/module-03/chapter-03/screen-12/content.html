Essential Concepts: Injection Attacks

Core vulnerabilities in server-side web applications.

SQL Injection (SQLi)

A vulnerability allowing attackers to interfere with database queries via malicious SQL code in user input.

UNION-based SQLi

A technique to extract data by combining results of a malicious query with the legitimate query using UNION SELECT.

Command Injection

A vulnerability allowing attackers to execute arbitrary operating system commands on the server via unvalidated user input.

Summary Takeaway

Injection vulnerabilities exploit improper input validation, enabling attackers to manipulate backend systems or execute arbitrary code on the server.
