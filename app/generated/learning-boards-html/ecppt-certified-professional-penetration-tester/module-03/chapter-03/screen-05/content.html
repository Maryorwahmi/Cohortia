The Anatomy of SQL Injection

SQL Injection (SQLi) occurs when malicious SQL code is inserted into an input field and executed by the database due to improper input sanitization.

Vulnerable Query Example

A login form might construct a query using user input directly, making it susceptible to injection attacks.

Authentication Bypass

By injecting ' OR '1'='1, an attacker can force the query condition to always be true, granting unauthorized access.

Key Takeaway

SQLi exploits trust in user input, allowing attackers to manipulate database logic and gain unauthorized access.

SQLi Login Bypass

// Original vulnerable query structure
SELECT * FROM users WHERE username = 'user_input' AND password = 'password_input';

// Attacker input for username:
admin' --
// Attacker input for password:
' OR '1'='1

// Resulting query with injected password:
SELECT * FROM users WHERE username = 'user_input' AND password = '' OR '1'='1';

// Simplified effective query (if username is valid or bypassed):
SELECT * FROM users WHERE username = 'admin' OR '1'='1';

The ' OR '1'='1 payload makes the password condition always true, granting access.
