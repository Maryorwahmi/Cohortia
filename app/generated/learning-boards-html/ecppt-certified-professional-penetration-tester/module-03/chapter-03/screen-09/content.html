Reading Files on the Server

Local File Inclusion (LFI) enables attackers to include local files on the server by manipulating user-supplied input in file path parameters.

Directory Traversal (../)

The ../ sequence allows an attacker to move up in the directory hierarchy, eventually reaching the root to access any file.

Information Disclosure

LFI can expose sensitive data like configuration files, source code, or system password files (e.g., /etc/passwd).

Key Takeaway

LFI is a powerful reconnaissance tool, providing critical insights into the server's internal structure and sensitive data, often paving the way for deeper exploits.

LFI Exploitation Example

// Vulnerable URL parameter:
http://example.com/index.php?page=contact.php

// Attacker modifies 'page' parameter:
http://example.com/index.php?page=../../../../etc/passwd

The ../../../../ traverses directories to reach the root, then accesses /etc/passwd.

// Example of /etc/passwd content (partial):
root:x:0:0:root:/root:/bin/bash
daemon:x:1:1:daemon:/usr/sbin:/usr/sbin/nologin
www-data:x:33:33:www-data:/var/www:/usr/sbin/nologin

This reveals user accounts and their associated shells on a Linux system.
