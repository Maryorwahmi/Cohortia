Attack Vector

Drive-by Downloads

Drive-by downloads occur when malware is downloaded and executed automatically on a user's machine simply by visiting a compromised website, often without explicit user consent.

Key Characteristic: No User Consent

Malware is installed silently in the background, exploiting browser or plugin vulnerabilities.

Common Targets

Outdated web browsers, vulnerable browser plugins (e.g., Flash, Java - historically).

Scenario Example

Compromised News Site

A user visits a popular news website. Unbeknownst to them, the site has been compromised, and malicious JavaScript has been injected. This script exploits a zero-day vulnerability in their outdated browser, silently downloading and installing a keylogger without any prompts or warnings.

Unaware Victim
Key Takeaway

Keep browsers and plugins updated, and use robust endpoint protection to defend against silent drive-by downloads.
