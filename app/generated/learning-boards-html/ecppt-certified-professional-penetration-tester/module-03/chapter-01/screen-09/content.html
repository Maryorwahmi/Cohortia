Attack Vector

Malicious Payload Delivery

Malicious payloads are the harmful code executed on a target system, often delivered through seemingly legitimate files or disguised programs after successful social engineering.

Office Documents

Macros & Embedded Objects

Malicious macros in Word/Excel documents that execute code when 'content is enabled' by the user.

DOCX, XLSX
PDF Files

Reader Vulnerabilities

Exploiting flaws in PDF reader software to execute code when a malicious PDF is opened.

PDF
Executable Files

Disguised Programs

Malware disguised as legitimate software (e.g., installers, updates) that executes when run by the user.

EXE, MSI
Key Takeaway

Payloads leverage common file types and user trust; vigilance against suspicious files is crucial for prevention.
