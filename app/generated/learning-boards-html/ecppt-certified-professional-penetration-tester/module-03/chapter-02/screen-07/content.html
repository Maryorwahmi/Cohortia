Staged vs. Unstaged Payloads

Choosing the right delivery mechanism

Unstaged Payload

A self-contained payload that delivers all its components at once. The entire malicious code is embedded in the initial file.

  • • Larger initial file size.
  • • No further downloads needed after execution.
  • • Example: windows/meterpreter_reverse_tcp
Advantage

More reliable once executed, as it doesn't depend on an active listener for subsequent stages.

Staged Payload

A smaller initial payload (the 'stager') that establishes a connection and then downloads the full, larger payload from the attacker's machine.

  • • Smaller initial file size.
  • • Requires an active listener for the second stage.
  • • Example: windows/meterpreter/reverse_tcp
Disadvantage

Dependent on the attacker's listener remaining active throughout the entire payload delivery process.

Key Takeaway

Choose staged for stealth and smaller initial footprint, but be aware of listener dependency. Choose unstaged for robustness after initial execution, accepting a larger file size.
