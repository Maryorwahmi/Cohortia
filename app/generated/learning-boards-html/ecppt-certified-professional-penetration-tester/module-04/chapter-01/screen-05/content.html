HTTP and HTTPS

The Protocols of Web Communication

Key Characteristics
  • **HTTP:** Unencrypted, stateless, standard for web data transfer.
  • **HTTPS:** Encrypted via TLS/SSL, secure for sensitive data.
  • **Port Differences:** HTTP uses port 80, HTTPS uses port 443.
Concrete Example

Accessing a banking website uses HTTPS to encrypt your login credentials and financial data, preventing eavesdropping.

Key Takeaway

HTTPS is critical for protecting sensitive information on the web; always verify its proper implementation during testing.

HTTP
