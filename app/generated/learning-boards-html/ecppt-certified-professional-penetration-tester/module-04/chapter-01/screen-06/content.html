Architectural Component

The Web Server

Serving Static Content and Directing Traffic

Serve Static Files

Delivers HTML, CSS, JavaScript, images directly to the client.

Forward Dynamic Requests

Routes requests requiring processing to the application server.

Examples

Apache, Nginx, Microsoft IIS.

Pro Tip for Pen Testers

Identify the web server software and version early in reconnaissance. This can reveal known vulnerabilities or default configurations to exploit.

Key Takeaway

Web servers are the first line of defense and a critical point for information gathering and potential misconfiguration vulnerabilities.
