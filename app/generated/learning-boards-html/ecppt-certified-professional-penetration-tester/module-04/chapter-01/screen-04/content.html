Core Concept

The Client-Server Foundation

How Web Applications Communicate

Key Principles
  • **Client:** Typically a web browser, initiates requests for resources.
  • **Server:** Hosts application logic and data, processes requests, and sends responses.
  • **Interaction:** A continuous cycle of requests and responses.
  • **Foundation:** The core model for all internet-based services.
Concrete Example

When you type a URL into your browser, your browser (client) sends a request to the website's server, which then sends back the webpage content.

Key Takeaway

Understanding the client-server model is crucial for identifying where data flows and where security controls need to be implemented and tested.
