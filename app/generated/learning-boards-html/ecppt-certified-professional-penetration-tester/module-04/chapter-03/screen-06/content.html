Setup Step 1

Configuring Burp Suite's Proxy Listener

Setting the Stage for Interception

Default Address: Burp Suite listens on 127.0.0.1:8080 by default, which is your local machine's loopback address.

Verification: Check Proxy -> Options in Burp Suite to confirm the listener is active and configured correctly.

Crucial First Step: An incorrectly configured listener will prevent any traffic interception from occurring.

Key Takeaway

Ensure Burp Suite's Proxy Listener is active on 127.0.0.1:8080 as the foundational step for intercepting web traffic.

Burp Suite Proxy Options
[Proxy Listeners] Status: Running
--------------------------------------------------
  Interface: 127.0.0.1:8080
  Running:   Yes
  Intercept: Yes

[Intercept Client Requests] Status: On
--------------------------------------------------
  Rules:     (0 rules configured)

[Intercept Server Responses] Status: Off
--------------------------------------------------
  Rules:     (0 rules configured)

  # To modify, navigate to Proxy -> Options in Burp Suite
  # Ensure 'Running' checkbox is ticked for 127.0.0.1:8080

Pro Tip: While 127.0.0.1:8080 is standard, you might configure Burp to listen on a different port or network interface if you're proxying traffic from a separate device or virtual machine.
