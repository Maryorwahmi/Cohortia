Setup Step 2

Configuring Your Browser for HTTP Proxying

Directing Traffic to Burp Suite

Browser Settings: Navigate to your browser's network or proxy settings (e.g., Firefox: Settings -> Network Settings).

Manual Configuration: Select 'Manual proxy configuration' and enter 127.0.0.1 for HTTP Proxy and 8080 for Port.

Apply to All: Ensure these settings apply to both HTTP and HTTPS traffic for comprehensive interception.

Key Takeaway

Proper browser proxy configuration is essential to direct all web traffic through Burp Suite, enabling interception.

Firefox Proxy Settings

1. Open Settings
2. Search for "Network Settings"
3. Select "Manual proxy configuration"
HTTP Proxy: 127.0.0.1 Port: 8080
SSL Proxy: 127.0.0.1 Port: 8080
4. Check "Use this proxy server for all protocols"
5. Save Changes

Common Mistake: Forgetting to save changes or not applying the proxy to all protocols can lead to partial or no interception.
