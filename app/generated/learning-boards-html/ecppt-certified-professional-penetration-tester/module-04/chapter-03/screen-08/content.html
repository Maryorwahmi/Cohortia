HTTPS Interception

Handling Encrypted Traffic: The CA Certificate

Decrypting SSL/TLS for Full Visibility

SSL/TLS Decryption: Burp Suite acts as a 'man-in-the-middle' to decrypt and re-encrypt HTTPS traffic.

CA Certificate: Your browser needs to trust Burp's Certificate Authority (CA) certificate to avoid security warnings.

Installation: Download the cacert.der from http://burpsuite/ and import it into your browser's trust store.

Key Takeaway

Installing Burp's CA certificate is crucial for seamless HTTPS interception, preventing browser security warnings and enabling full traffic visibility.

CA Certificate Installation Flow

1. Ensure Burp Proxy is Active
2. Browse to http://burpsuite/ in Proxied Browser
3. Download CA Certificate (cacert.der)
4. Import into Browser's Trust Store (e.g., Firefox: Settings -> Certificates -> View Certificates -> Authorities -> Import)
5. Trust for Identifying Websites

Common Error: If you still get 'connection not private' errors, ensure you've fully trusted the certificate and restarted your browser.
