Intercepting and Inspecting Requests

Pausing the Conversation for Analysis

Toggle Intercept: Ensure 'Intercept is on' in Burp Suite's Proxy tab to pause incoming requests.

Raw Request View: Inspect HTTP method, URL, headers, parameters, and body for hidden details.

Identify Points of Interest: Look for sensitive data, unusual parameters, or clues about application logic.

Key Takeaway

Intercepting requests provides a critical raw view of web traffic, enabling detailed inspection for security vulnerabilities.

Intercepted HTTP Request
POST /login.php HTTP/1.1
Host: testphp.vulnweb.com
User-Agent: Mozilla/5.0 (Firefox)
Accept: text/html,application/xhtml+xml,application/xml;q=0.9,*/*;q=0.8
Accept-Language: en-US,en;q=0.5
Accept-Encoding: gzip, deflate
Content-Type: application/x-www-form-urlencoded
Content-Length: 28
Referer: http://testphp.vulnweb.com/login.php
Cookie: PHPSESSID=abcdef1234567890
Connection: close

username=test&password=password

Example: An intercepted login request reveals the exact parameters username and password, which can then be modified to test for authentication bypasses.
