Advanced Testing

Utilizing Burp Suite's Repeater Tool

Crafting and Resending Requests for Iterative Testing

Send to Repeater: Right-click an intercepted request and select 'Send to Repeater'.

Modify & Resend: Edit any part of the request in the Repeater tab and click 'Send' repeatedly.

Observe Responses: Analyze server responses to different inputs, identifying vulnerabilities efficiently.

Key Takeaway

Repeater is invaluable for manual, iterative testing, allowing rapid modification and resending of requests to pinpoint vulnerabilities.

Burp Repeater Interface
# Request Panel
POST /login.php HTTP/1.1
Host: testphp.vulnweb.com
Content-Type: application/x-www-form-urlencoded
Content-Length: 28

username=test&password=password

---

# Response Panel
HTTP/1.1 200 OK
Content-Type: text/html; charset=UTF-8
Content-Length: 1500

<html><body>Login failed.</body></html>

Example: In Repeater, you can change password=password to password=admin and click 'Send' to quickly test another credential, observing the response for a successful login message.
