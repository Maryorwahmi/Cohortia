Reconnaissance and Information Gathering for Web Applications
Building a Comprehensive Target Profile for Effective Penetration Testing
This chapter introduces the critical initial phase of web application penetration testing: reconnaissance and information gathering. It differentiates between passive and active techniques, covering tools like `dig`, `whois`, Google Dorking, Shodan, `gobuster`, and `whatweb`. Learners will understand how to gather DNS information, enumerate subdomains and directories, fingerprint technologies, and apply these methods ethically to build a comprehensive target profile.
