Key Concepts
Essential ideas from this chapter
Passive Reconnaissance

Gathering information about a target without directly interacting with it, minimizing detection risk.

Active Reconnaissance

Directly interacting with a target system to gather information, potentially detectable but yields specific data.

DNS Records

Information stored in the Domain Name System, providing details about domain ownership, IP addresses, and mail servers.

Summary Takeaway

Reconnaissance, both passive and active, is the critical first step in web application penetration testing, providing the necessary intelligence to identify vulnerabilities effectively.
