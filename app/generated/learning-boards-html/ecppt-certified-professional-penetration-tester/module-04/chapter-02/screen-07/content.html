Shodan: IoT Search Engine

Shodan indexes internet-connected devices, revealing open ports, services, and banners, often including specific software versions.

  • Identifies web servers and other devices exposed to the internet.
  • Reveals open ports and running services.
  • Often includes software versions, aiding vulnerability research.
  • Provides a unique 'attacker's view' of internet-facing assets.
Example Use

Searching for `apache country:US` to find Apache servers in the United States.

Social Media & Code Repos

Developers might inadvertently expose sensitive information, API keys, or configuration files on public platforms.

  • Search GitHub, GitLab, and personal blogs for target-related keywords.
  • Look for hardcoded credentials, API keys, or sensitive configuration.
  • Can reveal internal project names or development practices.
  • Requires careful filtering to distinguish relevant from irrelevant data.
Key Takeaway

Leveraging specialized search engines like Shodan and scrutinizing public code repositories can uncover critical, often overlooked, intelligence.
