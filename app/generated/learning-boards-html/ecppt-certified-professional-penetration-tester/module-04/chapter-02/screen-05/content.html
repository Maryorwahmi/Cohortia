Understanding DNS Records

`dig` (Domain Information Groper) is a flexible tool for querying DNS name servers. It's used to retrieve various DNS record types, such as A (address), MX (mail exchange), and NS (name server) records.

  • **A Record:** Maps a domain name to an IPv4 address.
  • **MX Record:** Specifies mail servers for the domain.
  • **NS Record:** Lists the authoritative name servers.
  • **Subdomains:** Can reveal additional infrastructure.
WHOIS Information Explained

`whois` queries databases that store registered users or assignees of an Internet resource. It provides domain registration details, including contact information, registration dates, and name servers.

  • **Registrant Details:** Name, organization, contact info.
  • **Registration Dates:** Creation, update, and expiry dates.
  • **Name Servers:** Often duplicates `dig` NS records.
  • **Privacy Concerns:** Can expose sensitive personal data.
Key Takeaway

`dig` and `whois` are powerful passive tools for mapping a target's network infrastructure and identifying ownership details.
