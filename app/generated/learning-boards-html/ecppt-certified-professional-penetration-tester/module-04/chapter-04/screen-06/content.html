Impact and Detection of SQLi

Uncovering the consequences and methods to find SQL Injection.

Impact of SQLi

  • Data Theft: Unauthorized access to sensitive information.
  • Data Modification: Altering or deleting database records.
  • Schema Discovery: Mapping the database structure.
  • Remote Code Execution: In some cases, executing OS commands.
Key Takeaway

SQLi can lead to severe data compromise and system control, making robust detection and prevention essential.

Common Mistake

Relying on blacklisting (filtering bad characters) instead of whitelisting (allowing only good characters) or parameterized queries.

SQLi Detection Techniques

Error-Based SQLi

Inject a single quote (') to trigger SQL error messages, revealing database details.

Boolean-Based SQLi

Compare responses for true (' AND 1=1--) vs. false (' AND 1=2--) conditions.

Time-Based Blind SQLi

Inject commands that cause a delay (e.g., SLEEP(5)) to infer information based on response time.
