Key Concepts: Broken Authentication

Essential terms for securing user identities and sessions.

Command Injection

Injecting OS commands into an application's input for arbitrary execution.

Broken Authentication

Vulnerabilities in improperly implemented authentication or session management.

Session Hijacking

An attacker taking over a legitimate user's active session.

Session Token/ID

A unique identifier used to maintain a user's authenticated state.

Password Hashing

Transforming a password into an irreversible string for secure storage.

Salt

Random data added to a password before hashing to enhance security.

Summary Takeaway

Broken Authentication covers a range of flaws, from weak credentials to poor session management, all requiring robust, multi-layered defenses.
