Command Injection: Executing OS Commands

When user input directly controls the operating system.

The Vulnerability

Command Injection occurs when an application executes OS commands using unsanitized user input, allowing attackers to inject and run arbitrary commands.

  • Impacts include remote code execution and full system compromise.
  • Common mistake: directly concatenating user input into shell commands.
Key Takeaway

Command Injection allows attackers to run arbitrary OS commands, leading to severe system control and data exfiltration.

Example Scenario

A web app pings an IP. Attacker inputs 127.0.0.1; ls -la /, executing ls -la / on the server.

OS Command Manipulation

Original Command (Expected):

ping -c 4 [user_input_ip]

Attacker Input for IP Address:

127.0.0.1; ls -la /

Resulting Malicious Command:

ping -c 4 127.0.0.1; ls -la /

The semicolon (;) chains commands, executing ls -la / after the ping.
