DNS Enumeration: Mapping a Target's Infrastructure

Leveraging Public DNS Records for Host Discovery

Key DNS Record Types

  • •MX (Mail Exchange): Identifies mail servers for email delivery.
  • •NS (Name Server): Specifies authoritative DNS servers for the domain.
  • •A (Address): Maps a domain name to an IPv4 address.
  • •AAAA (IPv6 Address): Maps a domain name to an IPv6 address.
  • •TXT (Text): Stores arbitrary text, often used for SPF/DKIM records.
Key Takeaway

DNS enumeration provides a detailed map of a target's online infrastructure, revealing critical hosts and services without direct interaction.

Using 'dig' for DNS Queries
# Example: Querying MX (Mail Exchange) records
dig example.com MX

# Example: Querying NS (Name Server) records
dig example.com NS

# Example: Querying A (Address) records
dig example.com A

# Example: Querying all records (ANY)
dig example.com ANY
Pro Tip

Combine DNS enumeration with other OSINT techniques. For instance, knowing MX records can inform targeted phishing campaigns, while A records reveal potential web servers.
