Public Code Repositories & Social Media

Leveraging Developer and Employee Information

Information Sources

  • •Code Repositories (GitHub, GitLab): API keys, credentials, internal configurations.
  • •Professional Social Media (LinkedIn): Employee roles, technologies used, company structure.
  • •General Social Media (Twitter, Facebook): Personal habits, locations, potential social engineering hooks.
Key Takeaway

Public code and social media offer unique insights into a target's technical and human elements, crucial for comprehensive OSINT.
