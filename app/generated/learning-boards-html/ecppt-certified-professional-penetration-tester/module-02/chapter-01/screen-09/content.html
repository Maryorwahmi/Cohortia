Practical Application

DNS Enumeration: Interpreting Command Output

Extracting Actionable Intelligence from DNS Queries

What to Look For

  • •MX Records: Mail server hostnames and their priority levels.
  • •NS Records: Authoritative name servers and their providers.
  • •A Records: IP addresses of web servers and other hosts.
  • •Subdomains: Any unusual or forgotten subdomains that might be vulnerable.
Key Takeaway

Analyzing DNS query output provides direct targets and insights into a target's communication and hosting infrastructure.

Example 'dig' Output (Abbreviated)
# dig example.com MX output:
example.com.    3600    IN      MX      10 mail.example.com.

# dig example.com NS output:
example.com.    3600    IN      NS      ns1.example-dns.com.
example.com.    3600    IN      NS      ns2.example-dns.com.

# dig example.com A output:
example.com.    3600    IN      A       93.184.216.34
Common Mistake

Don't assume DNS records are always current. Cross-reference findings with other sources to verify accuracy, as records can be outdated.
