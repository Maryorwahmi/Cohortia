Stealthy Port Discovery: TCP SYN Scan

The "half-open" technique for efficient and discreet port identification.

# Basic TCP SYN Scan
nmap -sS <target_IP_or_hostname>

# Example: Scan a web server for common ports
nmap -sS -p 80,443,22 192.168.1.100

How it Works (Half-Open)

  • •Nmap sends a SYN packet to the target port.
  • •If open, target responds with SYN/ACK.
  • •Nmap sends RST (reset) instead of ACK.
  • •Connection is never fully established.
Key Takeaway

The TCP SYN scan is Nmap's default for its speed and stealth, identifying open ports without completing the full TCP handshake.
