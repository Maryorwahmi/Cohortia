Defining a Vulnerability

A vulnerability is a weakness in a system, design, implementation, or configuration that could be exploited by an attacker.

Key Characteristic

It represents a potential entry point for an attacker to compromise a system's security.

Impact

Can lead to unauthorized access, data breaches, service disruption, or privilege escalation.

Key Takeaway

Identifying vulnerabilities is the foundational step in penetration testing, revealing potential attack vectors.

Common Types of Weaknesses

Outdated Software

Using software versions with known, unpatched security flaws (e.g., old web servers, OS).

Misconfigurations

Incorrectly set up services, firewalls, or permissions that expose systems (e.g., default credentials).

Insecure Code

Flaws in application logic or coding practices (e.g., SQL injection, cross-site scripting).

Example Scenario

A web server running an old version of OpenSSL with a known Heartbleed vulnerability. This specific software flaw allows attackers to steal sensitive information from the server's memory.
