Common Vulnerabilities and Exposures (CVE)

A dictionary of publicly known information security vulnerabilities and exposures.

Purpose

Provides a standardized identifier (e.g., CVE-YYYY-NNNNN) for each vulnerability, facilitating communication and tracking.

Example

CVE-2021-41773 refers to a specific Path Traversal and Remote Code Execution vulnerability in Apache HTTP Server 2.4.49.

Common Vulnerability Scoring System (CVSS)

A free and open industry standard for assessing the severity of computer system security vulnerabilities.

Scoring

Provides a numerical score (0-10) and a textual representation (Low, Medium, High, Critical) based on exploitability and impact.

Importance

Helps prioritize remediation efforts, focusing on high-scoring vulnerabilities that pose the greatest risk.

Key Takeaway

CVEs standardize vulnerability identification, while CVSS scores provide a quantifiable measure of severity, both crucial for risk prioritization.
