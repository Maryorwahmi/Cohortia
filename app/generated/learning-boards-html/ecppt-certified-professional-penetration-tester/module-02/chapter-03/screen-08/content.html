False Positives

A vulnerability is reported by the scanner, but it does not actually exist on the system.

Common Causes

Incorrect assumptions based on banner grabbing, scanner not detecting a manual patch, or environmental factors.

Example

Scanner reports 'Weak SSH Ciphers' but the administrator confirms all weak ciphers are disabled, indicating a misinterpretation by the scanner.

False Negatives

An actual vulnerability exists on the system, but the scanner fails to detect or report it.

Common Causes

Custom application logic flaws, complex business logic vulnerabilities, or zero-day exploits.

Example

The scanner misses a custom SQL injection vulnerability in a web application because it doesn't have a signature for that specific flaw.

Key Takeaway

Always manually verify critical findings from automated scans to confirm true positives and uncover potential false negatives, ensuring a comprehensive assessment.
