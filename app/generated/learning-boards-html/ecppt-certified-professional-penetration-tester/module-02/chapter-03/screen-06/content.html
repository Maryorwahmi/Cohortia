The Scanning Process

1

Information Gathering: Collects data like open ports, service versions, and OS details from the target.

2

Database Comparison: Compares gathered information against a continuously updated database of known vulnerabilities (CVEs).

3

Non-Intrusive Probes: Sends specific requests to targets to confirm conditions indicating a vulnerability without exploitation.

4

Report Generation: Compiles findings into a detailed report, including severity and remediation.

Example: Apache Vulnerability

Scenario

Nmap identifies Apache HTTP Server version 2.4.49 on a target system.

Scanner Action

Scanner checks its database for CVEs related to Apache 2.4.49.

Result

Flags CVE-2021-41773 (Path Traversal and Remote Code Execution) if found for that version.

Key Takeaway

Vulnerability scanners operate by matching system details against known vulnerability databases, using non-intrusive probes to confirm potential flaws.
