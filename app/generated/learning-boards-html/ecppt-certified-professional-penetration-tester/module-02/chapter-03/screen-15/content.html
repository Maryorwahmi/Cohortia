Key Concepts

More Essential Terms to Remember

False Negative

An actual vulnerability that is missed by a scanner.

Manual Vulnerability Identification

Manually testing for vulnerabilities using knowledge of common weaknesses.

Directory Traversal

A web vulnerability allowing access to files outside the web root via path manipulation.

Information Disclosure

The accidental or intentional exposure of sensitive system information.

Summary Takeaway

These concepts emphasize the necessity of human insight and targeted manual techniques to complement automated scanning for a truly comprehensive vulnerability assessment.
