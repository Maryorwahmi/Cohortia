Default Credentials

Many devices and applications come with pre-set, easily guessable usernames and passwords that are often not changed.

Common Examples

admin:admin, root:toor, user:password, guest:guest.

Manual Check

Attempt to log in to identified services (web interfaces, SSH, databases) using these common default combinations.

Directory Traversal (Path Traversal)

A vulnerability allowing access to files outside the web root by manipulating file paths in URLs using ../ sequences.

Attack Vector

Injecting ../ or ..%2f (URL-encoded) into parameters that handle file paths.

Example curl Command
curl http://<target_IP>/path/to/web/app/../../../../etc/passwd
Key Takeaway

Manually checking for default credentials and directory traversal vulnerabilities can quickly expose critical weaknesses often missed by automated tools.
