Key Concepts

Essential Terms to Remember

Vulnerability

A weakness in a system that can be exploited by an attacker.

Vulnerability Scanners

Automated tools (e.g., Nessus, OpenVAS) that identify potential security weaknesses.

CVE

A dictionary of publicly known information security vulnerabilities and exposures.

CVSS

A free and open industry standard for assessing the severity of computer system security vulnerabilities.

False Positive

A vulnerability reported by a scanner that does not actually exist.

Summary Takeaway

Understanding these core concepts is fundamental for accurately identifying, assessing, and communicating security risks in any penetration testing engagement.
