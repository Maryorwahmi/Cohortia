Technique Overview

What is Pass-the-Hash (PtH)?

PtH is an attack where an attacker authenticates to a remote server or service by using a user's NTLM hash instead of their plaintext password. This is highly effective in Active Directory environments.

  • Context: Primarily Windows networks, especially Active Directory.
  • Benefit: Bypasses password cracking, directly uses hash for authentication.
Key Tool

pth-winexe (Impacket)

A Linux-based tool from the impacket toolkit that allows execution of commands on remote Windows machines using an NTLM hash.

# Example: Pass-the-Hash using pth-winexe (from Impacket) # Assuming you have the NTLM hash for a user 'Administrator' pth-winexe -U Administrator%aad3b435b51404eeaad3b435b51404ee:31d6cfe0d16ae931b73c59d7e0c089c0 //TARGET_IP cmd.exe
Practical Scenario

Admin Hash Reuse

You've compromised a low-privilege workstation and found an NTLM hash for a domain administrator. Using pth-winexe, you can now authenticate to other servers where this administrator has local admin rights, gaining a shell without ever knowing the actual password.

Key Takeaway

PtH exploits NTLM authentication by using stolen hashes, making it a powerful technique for lateral movement in Windows environments, especially with tools like pth-winexe.

Common Misconception

PtH is for NTLM authentication. It cannot be directly used for Kerberos authentication, which relies on tickets. For Kerberos, you'd look at Pass-the-Ticket.
