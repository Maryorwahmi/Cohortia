Concept

What is Port Forwarding?

Port forwarding redirects a communication request from one address and port number combination to another. It's used to access specific services on remote machines through a compromised pivot host.

  • Benefit: Targeted access to specific services on isolated hosts.
  • Mechanism: Creates a direct tunnel for a single port.
Key Tool

ssh -L (Local Port Forwarding)

Establishes a local port on your attacking machine that forwards traffic through an SSH connection to a specified port on a remote machine via the compromised host.

# Example: Local port forwarding via SSH # On attacker: ssh -L 3389:10.10.10.20:3389 user@compromised_linux_host # Then RDP to localhost:3389 from attacker to reach 10.10.10.20
Practical Scenario

RDP to an Isolated Server

You've compromised a Linux host that can reach an internal Windows server running RDP (port 3389). By setting up an SSH local port forward, you can now RDP from your attacking machine to localhost:3389, which will tunnel your connection to the internal Windows server.

Key Takeaway

Port forwarding, especially with ssh -L, provides a precise method to tunnel specific service traffic through a compromised host to an otherwise unreachable internal target.

Common Mistake

Incorrectly mapping local and remote ports or IP addresses. Always verify the target IP and port, and ensure your local port is not already in use.
