Purpose

Why Enumerate Internally?

From a compromised host, enumeration helps map the local network, identify connected hosts, and discover open ports and running services. This reveals potential new targets and attack paths.

  • Windows Tools: ipconfig /all, netstat, arp -a.
  • Linux Tools: ip a, ss -tuln, nmap (if uploaded).
Common Targets

Services for Lateral Movement

Specific services are frequently targeted for lateral movement due to their remote access capabilities or common misconfigurations.

  • SMB (445): Server Message Block for file and printer sharing.
  • WinRM (5985/5986): Windows Remote Management.
  • RDP (3389): Remote Desktop Protocol.
  • SSH (22): Secure Shell.
Example

Listing SMB Shares

After identifying an open SMB port on a remote Windows host and having valid credentials, you can attempt to list shares to discover valuable files or directories.

# Example: List SMB shares on a remote Windows host net view \\TARGET_IP net use \\TARGET_IP\sharename /user:DOMAIN\username password
Key Takeaway

Internal network enumeration is crucial for identifying new targets and understanding the network topology from a compromised host's perspective, guiding subsequent lateral moves.
