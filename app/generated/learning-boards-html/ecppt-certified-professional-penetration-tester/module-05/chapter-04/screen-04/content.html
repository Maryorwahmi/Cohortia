Module 5›Chapter 5.4›Lateral Movement and Pivoting
Core Concept

Lateral Movement

The process of moving from one compromised host to another within the same network segment or across different segments. It expands control and searches for higher-value targets.

  • Goal: Deeper access, sensitive data discovery, reaching critical systems.
  • Method: Exploiting trust relationships, credential reuse, service vulnerabilities.
Related Concept

Pivoting

Routing network traffic through a compromised host to access otherwise unreachable internal network segments. The compromised machine acts as a proxy.

  • Goal: Bypass network segmentation, reach isolated hosts.
  • Method: SOCKS proxies, port forwarding, SSH tunnels.
Analogy

Navigating a Building

Imagine gaining access to a building's reception (initial foothold). Lateral movement is like moving from the reception to different offices or floors, searching for the CEO's office or the server room. Pivoting is like using a maintenance tunnel or a specific internal network connection to reach a secure server room that has no direct public entrance.

Key Takeaway

Lateral movement expands your reach to new hosts, while pivoting enables access to segmented networks by routing traffic through a compromised host.

Common Misconception

Many confuse lateral movement and pivoting as the same. Remember, lateral movement is about moving *between* hosts, while pivoting is about *routing traffic through* a host to reach others.
