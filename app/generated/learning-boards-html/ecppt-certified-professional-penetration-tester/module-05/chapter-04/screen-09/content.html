Concept

What is a SOCKS Proxy?

A SOCKS proxy allows you to route all your network traffic (e.g., from nmap, Metasploit, web browsers) through a compromised host. This makes your traffic appear to originate from within the internal network.

  • Benefit: Bypasses network segmentation and firewalls.
  • Flexibility: Routes various types of traffic, not just specific ports.
Key Tool

ssh -D (Dynamic Port Forwarding)

Creates a SOCKS proxy on your local machine, routing traffic through an SSH connection to a compromised Linux host.

# Example: SSH Dynamic Port Forwarding (SOCKS proxy) # On attacker: ssh -D 9050 user@compromised_linux_host # Then configure proxychains to use localhost:9050
Practical Scenario

Scanning an Internal Segment

You've compromised a Linux host in a DMZ. By setting up an SSH SOCKS proxy through it, you can now use proxychains with nmap from your attacking machine to scan an internal network segment that was previously unreachable.

Key Takeaway

SOCKS proxies, often created with ssh -D, provide a flexible way to route all types of network traffic through a compromised host, enabling access to segmented internal networks.

Common Mistake

Forgetting to configure your attacking tools (like proxychains) to actually use the local SOCKS proxy, leading to direct connections that fail.
