Key Concepts: Expanding Your Network Footprint

Essential Terms for Lateral Movement and Pivoting

Lateral Movement

Moving from one compromised host to another within a network to expand control and reach further targets.

Pivoting

Routing network traffic through a compromised host to access otherwise unreachable internal network segments.

Pass-the-Hash (PtH)

Authenticating to a remote server using a user's NTLM hash instead of the plaintext password.

Summary Takeaway

Lateral movement and pivoting are crucial post-exploitation techniques that enable deeper network penetration by leveraging credential reuse and strategic traffic routing.
