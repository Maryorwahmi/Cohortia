Tool Overview

What is BloodHound?

BloodHound is a powerful graph theory tool used to map and visualize relationships between users, groups, computers, and ACLs in Active Directory environments. It helps identify attack paths for privilege escalation and lateral movement.

  • Benefit: Visualizes complex AD relationships, identifies hidden attack paths.
  • Goal: Find paths to Domain Admin, identify lateral movement opportunities.
Data Collection

SharpHound.exe

The primary data collector for BloodHound, SharpHound.exe is run on Windows targets to gather information about the Active Directory environment.

# Example: Running SharpHound.exe on a Windows target to collect BloodHound data # First, transfer SharpHound.exe to the target .\SharpHound.exe -c All -d YOUR_DOMAIN.LOCAL
Practical Scenario

Identifying Shortest Path to DA

After importing SharpHound data into the BloodHound GUI, you can query for the 'shortest path to Domain Admin'. This quickly highlights the most efficient lateral movement and privilege escalation routes, saving significant time in a penetration test.

Key Takeaway

BloodHound is indispensable for Active Directory penetration testing, providing a visual and queryable map of relationships to uncover critical attack paths for lateral movement and privilege escalation.

Common Mistake

Not collecting data with sufficient privileges or forgetting to specify the domain, leading to incomplete or inaccurate graph data in BloodHound.
