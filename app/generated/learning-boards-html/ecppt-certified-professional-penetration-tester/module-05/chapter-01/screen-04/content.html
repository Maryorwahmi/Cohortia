Confirming Initial Access & System Reconnaissance
Understanding your environment after gaining a shell.
Windows System Enumeration
whoami

Identifies the current user and their privileges.

systeminfo

Provides detailed OS configuration, hotfixes, and network info.

ipconfig /all

Displays comprehensive network adapter configuration.

Linux System Enumeration
id

Shows user and group identities for the current session.

uname -a

Prints detailed kernel and system information.

ip a / ifconfig

Lists network interfaces and their IP addresses.

Concrete Example

Running whoami on Windows reveals nt authority\system, indicating maximum privileges, while id on Linux showing uid=1000(user) gid=1000(user) indicates a standard user.

Common Mistake

Attempting privilege escalation or lateral movement without first understanding your current user context and system details.

Key Takeaway

Initial reconnaissance is the foundation of post-exploitation, guiding all subsequent actions and strategies.
