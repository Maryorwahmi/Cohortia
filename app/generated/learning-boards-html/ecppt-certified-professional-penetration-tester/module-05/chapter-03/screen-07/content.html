Insecure Scheduled Tasks

Leveraging automated tasks for elevated code execution.

How Scheduled Tasks Work

  • Automate program/script execution at specific times or events.
  • Can run with elevated privileges (e.g., SYSTEM, Administrator).
  • Configuration stored in XML files or registry.

Exploiting Insecure Tasks

  • Modify Executable: Replace the legitimate program with a malicious one.
  • Inject Code: Modify a script run by the task to include your payload.
  • Requires write permissions on the task's executable or script.
Code Example: Enumerating Scheduled Tasks
schtasks /query /fo LIST /v
This command lists all scheduled tasks with verbose details, including the 'Run As' user and the 'Task Command' (executable path).
Key Takeaway

Insecure scheduled tasks allow attackers to inject malicious code into programs run by high-privileged tasks, leading to privilege escalation.
