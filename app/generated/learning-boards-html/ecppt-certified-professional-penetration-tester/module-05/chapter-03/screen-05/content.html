Unquoted Service Paths

Exploiting Windows' path interpretation for privilege escalation.

How it Works

  • Service path contains spaces (e.g., C:\Program Files\App\service.exe).
  • Path is not enclosed in double quotes.
  • Windows attempts to execute C:\Program.exe first.
  • If C:\Program.exe exists and is writable by a low-priv user, it runs with service privileges.

Impact & Exploitation

  • Arbitrary Code Execution: Malicious executable runs with high privileges.
  • Privilege Escalation: Gain SYSTEM or Administrator access.
  • Persistence: If service restarts, payload re-executes.
Code Example: Identifying Unquoted Paths
wmic service get name,displayname,pathname,startmode | findstr /i "auto" | findstr /i /v "c:\windows\\" | findstr /i /v """
This command identifies services with automatic startup, not in the Windows directory, and without quoted paths.
Key Takeaway

Unquoted service paths allow Windows to execute malicious code placed in intermediate path segments with elevated service privileges.
