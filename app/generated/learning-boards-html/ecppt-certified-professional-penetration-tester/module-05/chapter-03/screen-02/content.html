Learning Objectives

What you'll achieve in this chapter

Bloom's Taxonomy:
LearnUnderstandApplyMaster
01

Identify Windows PE Vectors

Recognize common misconfigurations and vulnerabilities in Windows systems that enable privilege escalation. This skill is vital for initial reconnaissance.

VERIFIED COMPETENCY MILESTONE
02

Exploit Service Misconfigurations

Learn to exploit unquoted service paths and weak service permissions to execute code with elevated privileges. This is a common and effective technique.

VERIFIED COMPETENCY MILESTONE
03

Leverage Insecure Scheduled Tasks

Understand how to modify or inject code into scheduled tasks running with elevated privileges. This allows for persistent, high-level execution.

VERIFIED COMPETENCY MILESTONE
04

Understand AlwaysInstallElevated

Grasp the AlwaysInstallElevated policy and how it can be exploited to install malicious MSI packages with SYSTEM privileges. A powerful bypass.

VERIFIED COMPETENCY MILESTONE
