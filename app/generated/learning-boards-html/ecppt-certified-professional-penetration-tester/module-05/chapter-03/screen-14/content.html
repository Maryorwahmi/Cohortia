Key Concepts

Essential terms for Windows Privilege Escalation

NT AUTHORITY\SYSTEM

The highest privilege level on a Windows operating system, equivalent to root on Linux, granting ultimate control.

Service Misconfiguration

Vulnerabilities arising from improperly configured Windows services, often related to their executable paths or permissions.

Unquoted Service Path

A vulnerability where a service's executable path contains spaces and is not enclosed in quotes, allowing arbitrary code execution.

Understanding these core concepts is fundamental to identifying and exploiting Windows privilege escalation vectors effectively.
