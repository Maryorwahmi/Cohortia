Credential Access

Stored Credentials: A Goldmine for Attackers

Uncovering sensitive authentication data from Windows memory.

Where Credentials are Stored

  • Memory (LSASS process): Plaintext passwords, NTLM hashes, Kerberos tickets.
  • SAM Database: Local user hashes.
  • Registry: Cached credentials, service account passwords.

Why They Matter

  • Privilege Escalation: Reuse credentials for higher-privileged accounts.
  • Lateral Movement: Access other systems on the network.
  • Persistence: Maintain access even after reboots.

Key Takeaway

Windows stores sensitive credentials in memory and the SAM database, which can be extracted by tools like Mimikatz to gain higher privileges.
