PowerSploit's PowerUp.ps1 Module

Identifying and exploiting Windows PE vectors using PowerShell.

PowerUp Capabilities

  • Identifies unquoted service paths (Get-ServiceUnquotedPath).
  • Checks for weak service permissions.
  • Can bypass User Account Control (UAC) (Invoke-BypassUAC).
  • Comprehensive checks via Invoke-AllChecks.

PowerShell Integration

  • Module-based, loaded directly into PowerShell.
  • Highly flexible and scriptable.
  • Often less prone to immediate AV detection than standalone executables.
Code Example: Running PowerUp.ps1
# First, bypass execution policy if needed:Set-ExecutionPolicy Bypass -Scope Process -Force# Then, load PowerUp:. .\PowerUp.ps1# And invoke checks:Invoke-AllChecks
These commands prepare PowerShell, load PowerUp, and execute all available checks.
Key Takeaway

PowerSploit's PowerUp.ps1 module provides PowerShell functions to identify and exploit Windows privilege escalation vulnerabilities, including Invoke-AllChecks.
