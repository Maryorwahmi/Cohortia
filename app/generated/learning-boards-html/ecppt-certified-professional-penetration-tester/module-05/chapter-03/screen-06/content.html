Weak Service Permissions

Gaining control by modifying service executables or configurations.

Exploitation Scenarios

  • Executable Replacement: Low-priv user has write access to the service's .exe.
  • Service Reconfiguration: Low-priv user can modify service binary path (e.g., via sc config).
  • DLL Hijacking: If service loads a DLL from a writable path, replace it with malicious DLL.

Common Weak Permissions

  • (M) - Modify: Allows changing the file.
  • (F) - Full control: Complete control over the file.
  • Often found for BUILTIN\Users or Everyone groups.
Code Example: Checking Permissions
icacls "C:\Program Files\Vulnerable Service\vulnerable.exe"
This command displays the Access Control List (ACL) for the specified service executable. Look for 'M' or 'F' for low-privileged groups.
Key Takeaway

Weak permissions on service executables or configurations allow low-privileged users to replace or reconfigure services for elevated code execution.
