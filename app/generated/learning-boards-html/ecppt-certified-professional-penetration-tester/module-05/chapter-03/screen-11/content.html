WinPEAS: Comprehensive Vulnerability Scanning

Streamlining privilege escalation checks with an all-in-one script.

What WinPEAS Checks For

  • Unquoted service paths and weak service permissions.
  • Insecure registry settings and installed software vulnerabilities.
  • Network configurations, running processes, and user privileges.
  • Much more, providing a holistic view of potential weaknesses.

Key Features

  • Comprehensive: Checks a wide array of PE vectors.
  • Color-Coded Output: Easy to spot potential vulnerabilities.
  • Automated: Significantly reduces manual enumeration time.
