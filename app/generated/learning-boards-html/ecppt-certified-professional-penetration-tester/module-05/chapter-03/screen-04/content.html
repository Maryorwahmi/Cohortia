Core Concept

Understanding Windows Privilege Escalation

Elevating access from low-level user to SYSTEM.

Why Privilege Escalation?

  • Initial access often yields low-level user privileges.
  • Higher privileges (Administrator, SYSTEM) are needed for critical actions.
  • Enables full system control, data access, and persistence.
  • Crucial for achieving penetration testing objectives.

Windows vs. Linux PE

  • Distinct Architecture: Windows has unique service management and security models.
  • Registry Focus: Windows heavily relies on the registry for configuration.
  • Permission Models: Different approaches to user and group permissions.
  • Exploitation Vectors: Unique vulnerabilities like service misconfigurations and specific policies.
Privilege Hierarchy

Key Takeaway

Privilege escalation aims to gain higher access on Windows, moving from a low-privileged user to full system control.
