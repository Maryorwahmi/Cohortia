Manipulating MAC Times for Stealth

Altering file metadata to obscure forensic timelines and hinder investigations.

What are MAC Times?

Modified, Accessed, and Created timestamps are metadata associated with every file, providing a chronological record of file activity.

Why Manipulate Them?

Changing MAC times makes it harder for forensic investigators to identify newly created or modified files, blending them with legitimate system files.

Forensic Impact

This technique disrupts the chronological order of events, complicating the reconstruction of an attack timeline.

MAC Time Manipulation Commands

# Linux: Change MAC times to a specific date/time (YYYYMMDDhhmm.ss)touch -a -m -t 202310261430.00 /path/to/file.txt# Linux: Copy MAC times from another filetouch -r /path/to/reference_file.txt /path/to/target_file.txt# PowerShell (Windows): Set LastWriteTime (Modified)Set-ItemProperty -Path "C:\path  o\file.txt" -Name LastWriteTime -Value "10/26/2023 2:30:00 PM"

Pro Tip: Reference Legitimate Files

To be more stealthy, copy the MAC times from an existing, legitimate system file to your modified files.

Key Takeaway

Manipulating MAC times is a fundamental anti-forensics technique that helps obscure your activities by altering file metadata, making forensic analysis more difficult.
