Diverse Techniques for Data Extraction

Choosing the Right Method for the Environment

Factors Influencing Method Choice

  • Network Environment: Outbound internet access, firewall rules, proxy configurations.
  • Available Tools: Pre-installed utilities on the target system (e.g., curl, wget, ftp, PowerShell).
  • Stealth Requirements: Level of monitoring, need to avoid detection by security solutions.
  • Data Volume: Amount of data to exfiltrate (covert channels are slower).
Key Takeaway

Selecting an exfiltration method is a strategic decision based on network conditions, available tools, and the required level of stealth to ensure successful and undetected data transfer.

Primary Exfiltration Categories

Direct Transfers

Using common protocols like HTTP, FTP, SCP for straightforward data movement.

DNS/ICMP Tunneling

Encoding data within DNS queries or ICMP packets to bypass strict firewalls.

Covert Channels

Embedding data within legitimate traffic, such as HTTP headers or image metadata.
