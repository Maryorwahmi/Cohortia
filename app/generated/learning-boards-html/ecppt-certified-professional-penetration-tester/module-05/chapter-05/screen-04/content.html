Module 6›Chapter 5.5›What is Data Exfiltration?

The Core Definition

Data exfiltration is the unauthorized transfer of data from a compromised system to an attacker-controlled location. It's the ultimate demonstration of impact in many penetration tests.

Why it matters: Successfully exfiltrating data provides tangible proof of a breach's potential consequences, validating the severity of vulnerabilities found.

Common Sensitive Data Types

  • Credentials: Usernames, passwords, API keys, cloud access tokens.
  • Configuration Files: Database connection strings, application settings (`wp-config.php`, `/etc/passwd`).
  • Intellectual Property: Source code, design documents, proprietary algorithms.
  • Personal Data: Customer records, employee information, health records.
  • Financial Data: Credit card numbers, bank account details.

Typical Data Locations

User Home Directories

Personal files, documents, browser history.

Database Files

SQL dumps, application databases.

Web Server Roots

Website files, upload directories.

Cloud Credentials

AWS keys, Azure service principal files.

Common Mistake: Overlooking less obvious locations like temporary files or backup directories that might contain sensitive data.

Key Takeaway

Data exfiltration is the unauthorized removal of sensitive data, a critical step in demonstrating the impact of a breach, and requires thorough reconnaissance to identify valuable information and its location.
