ICMP Tunneling Explained

ICMP tunneling is a covert communication method where data is encapsulated within ICMP (ping) packets. This technique exploits the fact that ICMP traffic is often allowed through firewalls for network diagnostic purposes.

  • Mechanism: Data is embedded in the payload section of ICMP echo requests or replies.
  • Bypass: Often bypasses firewalls that permit basic ping traffic.
  • Tools: ptunnel, icmpshell are common tools for establishing ICMP tunnels.
  • Performance: Generally slower than direct transfers, but more stealthy.
Key Takeaway

ICMP tunneling and advanced covert channels offer highly stealthy data exfiltration by embedding data in less scrutinized network traffic, making them challenging to detect without specialized monitoring.

Advanced Covert Channels

These are highly specialized techniques that embed data within legitimate network traffic, making them extremely difficult to detect.

HTTP Header Manipulation

Embedding small chunks of data within custom or standard HTTP headers (e.g., User-Agent, Referer).

Image Metadata (Steganography)

Hiding data within the EXIF or other metadata fields of image files, then exfiltrating the image.

TCP Sequence Numbers

Manipulating TCP sequence numbers to embed small amounts of data, requiring custom network stack tools.
