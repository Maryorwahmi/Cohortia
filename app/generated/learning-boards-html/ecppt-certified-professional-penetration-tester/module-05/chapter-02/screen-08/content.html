Vulnerability Class

Weak File and Directory Permissions

A Gateway to Privilege Escalation Through Misconfigured Access Controls

What Constitutes 'Weak'?

  • World-Writable Files: Files writable by any user on the system.
  • Group-Writable Files: Files writable by a group that includes low-privileged users.
  • Insecure Configuration Files: Writable config files for root-owned services.
  • Overwritable Binaries: Low-privileged users can replace executables run by root.
Key Takeaway

Weak file and directory permissions, especially world-writable files in critical system paths, create direct opportunities for privilege escalation by allowing unauthorized modification of system behavior or credentials.

Impact of Weak Permissions

If a low-privileged user can modify:

  • Root-executed scripts: Inject malicious code.
  • `/etc/passwd` or `/etc/shadow`: Add new root users or change passwords.
  • Service configuration files: Alter service behavior to gain control.

Terminal: Find World-Writable Files

# Find world-writable files in /etcfind /etc -type f -perm -o=w 2>/dev/null# Find world-writable files in /var/www (web server root)find /var/www -type f -perm -o=w 2>/dev/null
Common Mistake: Overlooking Context

A world-writable file isn't always exploitable. Its exploitability depends on whether a privileged process interacts with it (e.g., a root cron job, a SUID binary, or a root-owned service).
