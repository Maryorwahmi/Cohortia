Locating SUID and SGID Binaries

Scanning for Privileged Executables on a Linux System

Why Find Them?

  • Potential Escalation: SUID/SGID binaries can run with elevated privileges.
  • Initial Recon: First step in identifying privilege escalation vectors.
  • Targeted Exploitation: Focus efforts on known vulnerable binaries.
Key Takeaway

Systematically identifying SUID/SGID binaries is the crucial first step in Linux privilege escalation, revealing potential pathways to root access.

Understanding the `find` Command

The `find` command is versatile for searching files. Here's a breakdown of the flags used:

  • `/` : Start search from the root directory.
  • `-perm -u=s` : Search for files with the SUID bit set.
  • `-perm -g=s` : Search for files with the SGID bit set.
  • `-type f` : Only search for regular files (not directories).
  • `2>/dev/null` : Suppress 'Permission denied' errors for cleaner output.

Terminal: Find SUID/SGID Binaries

# Find SUID binaries across the filesystemfind / -perm -u=s -type f 2>/dev/null# Find SGID binaries across the filesystemfind / -perm -g=s -type f 2>/dev/null
Pro Tip: Focus Your Search

Start with common directories like `/usr/bin`, `/usr/sbin`, `/bin`, `/sbin` if a full system scan is too slow or noisy. Prioritize binaries owned by root.
