Scenario

Accessing Internal Web App

You have compromised a Windows server (192.168.50.10) with access to a restricted internal network (10.0.0.0/24). You want to access an internal web application on 10.0.0.5 on port 80 from your attacking machine using meterpreter.

Compromised Host: Windows Server (192.168.50.10)

Target: Internal Web App (10.0.0.5:80)

Step 1: Add Route

Using `autoroute`

meterpreter > run autoroute -s 10.0.0.0/24

This command routes traffic for 10.0.0.0/24 through the Meterpreter session.

Step 2: Port Forward

Using `portfwd`

meterpreter > portfwd add -l 8080 -r 10.0.0.5 -p 80

Forwards local port 8080 to the internal web app (10.0.0.5:80).

Key Takeaway

Meterpreter's `autoroute` and `portfwd` commands enable direct access to internal services by establishing necessary network routes and forwarding mechanisms.
