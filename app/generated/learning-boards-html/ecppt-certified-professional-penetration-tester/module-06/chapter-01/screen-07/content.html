Module 6›Chapter 6.1›SSH Remote Port Forwarding
Concept

Forwarding Remote to Local

Remote port forwarding binds a port on the pivot host to a port on your local attacking machine. This allows the pivot host to initiate connections back to your machine.

Use Case

Bypassing Egress Filtering

Remote forwarding is crucial when internal networks restrict outbound connections, allowing the pivot host to 'call home' to your machine.

Example Command

SSH -R Syntax

ssh -R 9000:localhost:22 user@pivot_ip

This forwards pivot host port 9000 to your local machine's port 22 (SSH).

Key Takeaway

Remote port forwarding is essential for establishing reverse connections from a compromised host back to your attacking machine, bypassing egress filters.
