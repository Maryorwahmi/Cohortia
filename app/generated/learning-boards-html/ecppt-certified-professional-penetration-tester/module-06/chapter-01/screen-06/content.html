Module 6›Chapter 6.1›SSH Local Port Forwarding
Concept

Forwarding Local to Remote

Local port forwarding allows you to bind a port on your local attacking machine to a port on a target machine, with all traffic securely tunneled through an SSH connection to a pivot host.

Use Case

Accessing Internal Web Server

If an internal web server (10.10.10.5:80) is only reachable from your pivot host, local port forwarding makes it accessible from your machine.

Example Command

SSH -L Syntax

ssh -L 8080:10.10.10.5:80 user@192.168.1.10

This forwards local port 8080 to 10.10.10.5:80 via the pivot host 192.168.1.10.

Key Takeaway

Local port forwarding is ideal for accessing a single, specific service on an internal network from your attacking machine.
