Learning Objectives

Skills for Deeper Web Application Penetration Testing

Learn
Understand
Apply
Master
01

Understand SSRF Concepts

Grasp the core mechanics of Server-Side Request Forgery and its potential to force a server to interact with arbitrary internal or external resources. This skill is vital for recognizing the subtle indicators of SSRF in web applications.

VERIFIED COMPETENCY MILESTONE
02

Exploit SSRF Vulnerabilities

Learn to craft and execute SSRF payloads to access internal files, perform port scans on internal networks, or retrieve sensitive cloud metadata. This practical application demonstrates how to turn theoretical knowledge into actionable attack vectors.

VERIFIED COMPETENCY MILESTONE
03

Explain Insecure Deserialization

Articulate the dangers of insecure deserialization, where untrusted data can be reconstructed into malicious objects, leading to severe consequences like arbitrary code execution. Understanding this process is key to preventing such attacks.

VERIFIED COMPETENCY MILESTONE
04

Demonstrate Deserialization Exploitation

Perform basic exploitation techniques for insecure deserialization, including identifying gadget chains and using tools to generate malicious payloads. This hands-on experience solidifies your understanding of how these attacks unfold.

VERIFIED COMPETENCY MILESTONE
