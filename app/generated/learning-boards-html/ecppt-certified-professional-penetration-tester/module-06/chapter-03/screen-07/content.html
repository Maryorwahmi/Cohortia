Core Concept

Insecure Deserialization

Reconstructing Malicious Data Structures from Untrusted Data

What is Deserialization?

Deserialization is the process of reconstructing a data structure (like an object) from a sequence of bytes. It's the reverse of serialization, which converts an object into a byte stream for storage or transmission.

  • •Converts byte stream back into a live object.
  • •Common in inter-process communication, caching, and persistent storage.
Key Takeaway

Insecure deserialization transforms seemingly inert data into a potent attack vector, allowing attackers to execute code or manipulate application logic by controlling the object reconstruction process.

The Vulnerability

When an application deserializes untrusted data without proper validation, an attacker can inject malicious objects or modify existing ones within the serialized stream.

  • •Arbitrary Code Execution: The most severe impact, allowing full system control.
  • •Denial of Service (DoS): Triggering resource-intensive operations or crashes.
  • •Authentication Bypass: Modifying user objects to gain unauthorized access.

Languages at Risk

This vulnerability is particularly prevalent and dangerous in languages with powerful object serialization mechanisms, such as Java, PHP, and Python. Each language has its own specific serialization formats and common gadget chains.
