Behavioral Evasion

Bypassing Behavioral Analysis

Monitoring process actions for malicious intent.

Behavioral Detection Principles

  • **Real-time Monitoring:** Observes process actions, API calls, and system interactions as they happen.
  • **Malicious Indicators:** Flags activities like injecting into other processes, modifying system files, or suspicious network connections.
  • **Contextual Analysis:** Evaluates actions within the broader system context to determine maliciousness.
  • **Dynamic Sandboxing:** Often involves executing suspicious files in isolated environments to observe their full behavior.
Focus

This method aims to catch unknown or polymorphic malware by its actions, not just its signature.

Evasion Strategy: Mimicry

  • **Appear Normal:** Make payloads perform actions that resemble legitimate system or user activity.
  • **Living Off The Land Binaries (LOLBINs):** Use trusted, pre-existing system binaries to execute malicious code.
  • **Process Masquerading:** Inject into or impersonate legitimate processes to hide malicious activity.
  • **Stealthy Persistence:** Use less common or more legitimate-looking persistence mechanisms.
Example

Using `rundll32.exe` to execute a malicious DLL, as `rundll32` is a legitimate Windows process.

Key Takeaway

Bypassing behavioral AV requires making malicious actions appear legitimate, often by leveraging trusted system processes (LOLBINs) or blending into normal system activity to avoid flagging suspicious behaviors.
