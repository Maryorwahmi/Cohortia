Advanced AV Evasion

Custom Shellcode Loaders: Advanced Obfuscation

Adding junk code and using legitimate APIs to appear benign.

Obfuscation Techniques

  • **Junk Code:** Inserting irrelevant code to change signatures and execution flow.
  • **API Call Manipulation:** Using legitimate Windows API calls in non-standard or delayed sequences.
  • **Runtime Decryption:** Encrypting shellcode and decrypting it only when executed in memory.
  • **Anti-Analysis Checks:** Adding checks for sandboxes or debuggers to prevent analysis.
Pro-Tip

Continuously test your custom loaders against target AV solutions in a controlled environment to refine evasion.

Process Injection Methods

# Reflective DLL Injection
  - Load a malicious DLL directly into a target process's memory.
  - Avoids writing the DLL to disk, reducing detection.

# Process Hollowing
  - Create a legitimate process in a suspended state.
  - Unmap its original code and inject malicious shellcode.
  - Resume the process, executing the shellcode under a trusted name.

# Goal:
  - Execute shellcode within a legitimate process context.
  - Obscure the origin and nature of the malicious code.
Why it matters

These techniques make the malicious code appear to be part of a trusted process, making behavioral detection much harder.

Key Takeaway

Beyond basic custom loaders, techniques like junk code, API call manipulation, and process injection (e.g., reflective DLL, process hollowing) are crucial for evading advanced AV that monitors for suspicious execution patterns.
