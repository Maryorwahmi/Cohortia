Chapter 6.2

Key Concepts

Advanced evasion techniques and tools.

Heuristic Analysis

AV method that identifies threats by analyzing code for suspicious characteristics or behaviors.

Behavioral Analysis

AV method that monitors the actions of processes and applications for malicious intent.

Custom Shellcode Loader

A program written by the attacker to load and execute raw shellcode, often used to evade signature-based AV.

Summary Takeaway

Advanced AV uses heuristic and behavioral analysis to detect threats, which can be bypassed by custom shellcode loaders that control execution and mimic legitimate processes.
