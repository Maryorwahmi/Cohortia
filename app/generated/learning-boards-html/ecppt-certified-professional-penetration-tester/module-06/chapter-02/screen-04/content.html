Core Concept

Layers of Defense: AV and IDS/IPS

Differentiating endpoint and network security mechanisms.

Antivirus (AV) Software

  • **Focus:** Endpoint protection (individual computers, servers).
  • **Detection:** Identifies malicious files, processes, and software.
  • **Mechanisms:** Uses signatures, heuristics, and behavioral analysis.
  • **Action:** Quarantines, deletes, or blocks detected threats.
Example

Windows Defender scanning a downloaded executable for known malware patterns.

Intrusion Detection/Prevention System (IDS/IPS)

  • **Focus:** Network traffic monitoring (perimeter, internal segments).
  • **Detection:** Identifies known attack patterns, anomalous behavior, policy violations.
  • **Mechanisms:** Signature-based, anomaly-based, policy-based detection.
  • **Action:** Alerts (IDS) or blocks (IPS) suspicious network activity.
Example

Snort detecting a SQL injection attempt in web traffic and generating an alert.

Key Takeaway

AV and IDS/IPS serve distinct but complementary roles: AV secures endpoints, while IDS/IPS secures the network. Evasion requires tailored approaches for each.
