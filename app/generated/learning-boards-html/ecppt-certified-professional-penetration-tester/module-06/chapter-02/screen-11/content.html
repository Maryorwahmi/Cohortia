IDS/IPS Evasion: Fragmentation Techniques

Splitting payloads to evade network detection.

How Fragmentation Works

  • **Packet Splitting:** An attack payload is divided into multiple smaller IP packets.
  • **Reassembly Challenge:** Some IDS/IPS may fail to correctly reassemble these fragments.
  • **Signature Bypass:** If not reassembled, the full attack signature might not be detected.
  • **Performance Impact:** Fragmented packets can also cause performance issues for IDS/IPS, leading to dropped packets or less thorough inspection.
Mechanism

Exploits potential weaknesses in how network security devices handle IP packet reassembly.

Fragmentation with `nmap`

# Basic fragmented SYN scan
nmap -f -sS <target_ip>

# Explanation of -f:
  - Causes the requested scan (e.g., SYN scan) to use tiny fragmented IP packets.
  - Nmap splits the TCP header across several packets.
  - This makes it harder for simple packet filters and IDS to detect.

# Limitations:
  - Modern IDS/IPS are often robust against simple fragmentation.
  - Can sometimes lead to unstable connections or dropped packets.
  - Effectiveness varies greatly depending on the target's network stack and IDS configuration.
Real-world Use

Useful for testing the robustness of an IDS/IPS's reassembly capabilities and its ability to detect fragmented attacks.

Key Takeaway

Fragmentation is an IDS/IPS bypass technique that splits attack payloads into smaller packets, aiming to evade detection by systems that struggle with reassembly or inspection of fragmented network traffic.
