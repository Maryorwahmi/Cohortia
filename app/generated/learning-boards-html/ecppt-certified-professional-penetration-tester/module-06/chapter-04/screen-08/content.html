Hash Cracking

Cracking Kerberos Hashes with Hashcat

Recovering Passwords from Stolen Tickets

hashcat for Kerberos
  • •Powerful password cracking utility.
  • •Uses mode 13100 for Kerberos 5 TGS-REP etype 23 hashes.
  • •Requires a wordlist (e.g., rockyou.txt) for dictionary attacks.
  • •Offline process, no network alerts.
Key Takeaway

hashcat is the go-to tool for efficiently cracking Kerberos hashes offline, revealing plaintext passwords that can be used for further exploitation.

Terminal Command
hashcat -m 13100 kerberos_hashes.txt /usr/share/wordlists/rockyou.txt --force
Command Breakdown

-m 13100: Specifies the hash type (Kerberos 5 TGS-REP etype 23).

kerberos_hashes.txt: Input file containing the extracted Kerberos hash.

/usr/share/wordlists/rockyou.txt: Path to the wordlist for cracking.

--force: Overrides warnings, often needed in VM environments.
