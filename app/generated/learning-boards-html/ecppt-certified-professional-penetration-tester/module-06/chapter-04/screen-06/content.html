Kerberoasting: Exploiting Service Principal Names

Stealing Hashes from Service Accounts

What is Kerberoasting?

An attack that exploits Service Principal Names (SPNs) registered to user accounts to obtain their NTLM password hashes for offline cracking.

  • •Targets services running under user accounts.
  • •Does not require direct interaction with the service account.
  • •Can be performed from any domain-joined machine.
Key Takeaway

Kerberoasting leverages misconfigured SPNs to extract password hashes, enabling offline cracking and credential theft without direct interaction.

How Kerberoasting Works
1. Identify SPNs

Attacker identifies Service Principal Names associated with user accounts.

2. Request Service Ticket

Attacker requests a Kerberos service ticket for the identified SPN.

3. Offline Crack Hash

The KDC encrypts the ticket with the service account's NTLM hash, which can be extracted and cracked offline.
