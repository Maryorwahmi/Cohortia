Executing Kerberoasting with Impacket

Requesting Service Tickets for Offline Cracking

GetUserSPNs.py Overview
  • •Part of the Impacket toolkit.
  • •Requests Kerberos service tickets for SPNs.
  • •Output is in hashcat-compatible format (mode 13100).
  • •Requires low-privileged domain credentials.
Key Takeaway

GetUserSPNs.py is a critical tool for automating the extraction of Kerberos service tickets, providing the necessary hashes for offline password cracking.

Terminal Command
GetUserSPNs.py -request -dc-ip <DOMAIN_CONTROLLER_IP> <DOMAIN>/<USERNAME>:<PASSWORD>
Example Output (Hashcat Format)
$krb5tgs$23$*svc_web$cohortia.local$HTTP/webserver.cohortia.local*$A1B2C3D4E5F6...
Pro Tip

Save the output hash to a file (e.g., kerberos_hashes.txt) for efficient cracking with hashcat.
