Practical Application

Lateral Movement with Cracked Credentials

Using Cracked Passwords for Remote Execution

psexec.py for Remote Access
  • •Part of the Impacket toolkit.
  • •Executes commands on remote Windows hosts.
  • •Can use plaintext passwords (from cracking) or NTLM hashes.
  • •Establishes a command shell on the target.
Key Takeaway

Leveraging cracked credentials with tools like psexec.py is a direct path to lateral movement, enabling remote command execution and expanding control within the network.

Terminal Command Example
psexec.py <DOMAIN>/svc_web:<CRACKED_PASSWORD>@<TARGET_MACHINE_IP> cmd.exe
Scenario Card

After cracking the password for svc_web, you use psexec.py to connect to a web server (10.0.0.15) where svc_web has local admin rights. This grants you a command shell on the web server, allowing further reconnaissance or exploitation.

Security Best Practice

Enforce strong, unique passwords for all service accounts and regularly audit their privileges to prevent such lateral movement.
