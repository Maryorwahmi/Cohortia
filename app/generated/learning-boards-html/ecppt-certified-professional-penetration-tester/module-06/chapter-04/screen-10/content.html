Pass-the-Hash: Authenticating with NTLM Hashes

Moving Across the Network Without Plaintext Passwords

What is Pass-the-Hash (PtH)?

A technique where an attacker authenticates to a remote system using a user's NTLM hash instead of their plaintext password.

  • •Bypasses the need to crack the hash.
  • •Effective in environments caching NTLM hashes.
  • •Enables remote command execution.
Key Takeaway

Pass-the-Hash is a powerful lateral movement technique that leverages NTLM hashes directly for authentication, enabling remote access without knowing the plaintext password.

Impacket Tools for PtH

psexec.py: Executes commands on remote Windows hosts.

smbexec.py: Similar to psexec.py, often more stealthy.

wmiexec.py: Executes commands via Windows Management Instrumentation.

Example Command
psexec.py <DOMAIN>/<USERNAME>@<TARGET_IP> -hashes :<NTLM_HASH>
Common Mistake

Trying to use a plaintext password where only a hash is accepted, or vice-versa. Understand the authentication mechanism.
