Mapping Attack Paths with BloodHound

Visualizing Relationships for Strategic Exploitation

What BloodHound Does
  • •Visualizes AD relationships (users, groups, computers, ACLs).
  • •Identifies potential attack paths to high-value targets.
  • •Helps prioritize exploitation efforts.
  • •Uncovers complex trust relationships between domains.
Key Takeaway

BloodHound is essential for understanding the complex attack surface of Active Directory, enabling strategic and efficient exploitation.

BloodHound Workflow
1

Data Collection (Ingestor)

Run SharpHound.exe (Windows) or BloodHound.py (Linux) to gather AD data.

2

Data Import (GUI)

Import collected JSON/ZIP files into the BloodHound graphical user interface.

3

Query & Visualize

Use built-in queries (e.g., "Find Shortest Path to Domain Admins") to visualize attack paths.
