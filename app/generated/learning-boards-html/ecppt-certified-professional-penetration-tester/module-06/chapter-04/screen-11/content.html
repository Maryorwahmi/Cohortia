Pass-the-Ticket: Leveraging Kerberos TGTs

Injecting Tickets for Seamless Authentication

What is Pass-the-Ticket (PtT)?

A lateral movement technique where an attacker injects a stolen Kerberos Ticket Granting Ticket (TGT) or Service Ticket (ST) into their session to authenticate as another user.

  • •Relies on Kerberos authentication tickets.
  • •Bypasses password or hash knowledge.
  • •Effective for maintaining persistence and network traversal.
Key Takeaway

Pass-the-Ticket allows attackers to impersonate users by injecting stolen Kerberos tickets, providing a stealthy and persistent method for lateral movement.

mimikatz Commands for PtT

sekurlsa::tickets /export: Extracts Kerberos tickets from memory.

kerberos::ptt <ticket_file>: Injects a stolen ticket into the current session.

Scenario Card

Imagine you've compromised a workstation. Using mimikatz, you extract a TGT for a domain administrator. You can then inject this TGT into your session and access other domain resources as the administrator, without ever knowing their password.

Security Tip

Implement credential guard and regularly purge Kerberos tickets from memory to mitigate PtT attacks.
