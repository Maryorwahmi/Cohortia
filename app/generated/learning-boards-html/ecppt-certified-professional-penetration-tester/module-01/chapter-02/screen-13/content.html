Configuration Check

Ensure Host-only Adapter

For both your Kali Linux and Metasploitable2 VMs, go to their VirtualBox/VMware settings and ensure their network adapter is set to 'Host-only Adapter'. Crucially, they must be on the *same* Host-only network instance.

Identify IP Addresses

Using `ip a` or `ifconfig`

Boot both VMs. In Kali, open a terminal and type ip a. In Metasploitable2, log in (msfadmin/msfadmin) and type ifconfig. Note the IP addresses associated with their host-only interfaces (e.g., eth0, enp0s3), typically in the 192.168.56.x range.

# In Kali Linux terminal:ip a
Test Connectivity

Ping from Kali to Metasploitable2

From your Kali Linux terminal, use the ping command to test reachability to Metasploitable2's IP address. Successful replies confirm your isolated lab network is correctly configured.

# In Kali Linux terminal:ping 192.168.56.101  # Replace with Metasploitable2's IP

Common Mistake: Using NAT or Bridged for Metasploitable2, accidentally exposing it. Always verify Host-only.

Key Takeaway

Successful `ping` tests between Kali and Metasploitable2 on a Host-only network confirm your lab's secure and functional isolation.
