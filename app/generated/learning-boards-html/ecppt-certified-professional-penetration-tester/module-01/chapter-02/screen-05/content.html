Definition

What is Virtualization?

Virtualization is the technology that creates a virtual (rather than physical) version of a resource, such as an operating system, server, storage device, or network resource. It allows for efficient use of hardware by consolidating multiple workloads.

Key Component

The Hypervisor

A hypervisor, also known as a Virtual Machine Monitor (VMM), is the software that creates and runs virtual machines (VMs). It manages the allocation of physical hardware resources to each virtual machine, ensuring they can operate independently.

Types of Hypervisors

Type 1 (Bare-Metal)

Runs directly on physical hardware. Examples: VMware ESXi, Microsoft Hyper-V. Offers high performance and security, typically for data centers.

Type 2 (Hosted)

Runs on top of an existing operating system. Examples: Oracle VirtualBox, VMware Workstation/Player. Ideal for personal labs due to ease of setup.

Key Takeaway

Virtualization, powered by hypervisors, is fundamental for creating flexible and cost-effective penetration testing labs on a single machine.
