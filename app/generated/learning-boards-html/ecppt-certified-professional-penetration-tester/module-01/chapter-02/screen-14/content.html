Key Concepts

Virtualization

The creation of a virtual version of something, such as an operating system or server, allowing multiple instances on one physical machine.

Hypervisor

Software that creates and runs virtual machines (VMs), also known as a Virtual Machine Monitor (VMM).

Virtual Machine (VM)

An emulation of a computer system, providing the functionality of a physical computer within a virtualized environment.

Kali Linux

A Debian-derived Linux distribution specifically designed for digital forensics and penetration testing, pre-loaded with essential tools.

Metasploitable2

A deliberately vulnerable Linux virtual machine, designed by Rapid7 for practicing penetration testing techniques safely and legally.

Summary Takeaway

Understanding these core components is essential for building and managing a secure and effective penetration testing lab environment.
