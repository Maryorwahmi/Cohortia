Key Concepts

Host-only Adapter

A network mode that creates a private network between the host and its VMs, isolating them from external networks.

NAT

Network Address Translation; allows VMs to access the internet through the host, but prevents external machines from direct access.

Bridged Adapter

Connects a VM directly to the physical network, making it appear as a separate device with its own IP address.

`ip a` / `ifconfig`

Linux commands used to display and configure network interface parameters, including IP addresses.

`ping`

A network utility used to test the reachability of a host on an IP network and measure round-trip time.

Summary Takeaway

Mastering network configuration and basic command-line tools is crucial for maintaining a secure and functional penetration testing lab.
