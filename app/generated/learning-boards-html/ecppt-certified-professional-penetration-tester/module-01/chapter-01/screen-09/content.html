Pen Test Phases

Gaining and Maintaining Access

Exploiting vulnerabilities and establishing persistence.

Gaining Access

  • Exploiting identified vulnerabilities to gain initial entry.
  • Bypassing security controls to achieve unauthorized access.
Example

Using a known exploit for an unpatched service to execute code remotely on a server.

Maintaining Access

  • Establishing persistence to re-enter the system.
  • Escalating privileges and setting up backdoors.
Key Takeaway

Gaining and Maintaining Access are critical phases where vulnerabilities are actively exploited, and persistence is established to simulate a real attacker's objectives and assess long-term risk.
