Key Components & Concepts

Essential services and terminology for centralized architectures.

Spoke VPC

An application VPC that connects to a central hub (like a Transit Gateway or security VPC) for shared services or connectivity.

AWS Transit Gateway (TGW)

A network transit hub that connects VPCs and on-premises networks, facilitating routing in centralized architectures.

Network Address Translation (NAT)

Used in egress VPCs to allow instances in private subnets to initiate outbound connections to the internet.

Key Takeaway

Spoke VPCs, Transit Gateway, and NAT are fundamental components that enable the efficient and secure routing of traffic within centralized network architectures.
