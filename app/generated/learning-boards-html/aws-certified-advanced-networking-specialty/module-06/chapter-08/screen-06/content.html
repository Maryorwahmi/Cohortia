Egress VPC: Routing Outbound Traffic

Understanding the detailed traffic flow from spoke VPCs to the internet.

Step-by-Step Flow
1.

Spoke VPC Outbound Request

Application instances in private subnets initiate internet-bound traffic (0.0.0.0/0).

2.

Route to Transit Gateway

Spoke VPC route tables direct 0.0.0.0/0 traffic to the Transit Gateway attachment.

3.

TGW Routes to Egress VPC

Transit Gateway route tables forward 0.0.0.0/0 traffic to the Egress VPC attachment.

4.

Inspection by Network Firewall

Egress VPC routes traffic to AWS Network Firewall for deep packet inspection and filtering.

5.

Traffic to Internet Gateway

Legitimate traffic is forwarded by Network Firewall to the Egress VPC's Internet Gateway.

Common Mistake
Incorrect Route Table Configuration

Misconfigured routes can lead to traffic blackholes or accidental bypasses of the security VPC, compromising inspection.

Key Takeaway

Each hop in the egress traffic flow requires precise route table configuration to ensure all outbound traffic is correctly directed through the centralized security VPC for inspection.
