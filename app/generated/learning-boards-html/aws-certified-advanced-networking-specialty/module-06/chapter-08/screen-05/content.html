Centralized Egress VPC Architecture

Inspecting and controlling all outbound internet traffic from spoke VPCs.

Core Definition

A dedicated VPC that acts as a single point for all outbound internet traffic from multiple application (spoke) VPCs, enabling centralized security inspection.

Key Components
AWS Transit Gateway

Connects spoke VPCs to the egress VPC.

AWS Network Firewall

Performs stateful inspection and filtering.

Internet Gateway (IGW)

Provides internet connectivity from the egress VPC.

How it Works
1.

Spoke VPCs route 0.0.0.0/0 traffic to Transit Gateway.

2.

Transit Gateway routes traffic to the Egress VPC attachment.

3.

Egress VPC routes traffic to AWS Network Firewall for inspection.

4.

Network Firewall forwards legitimate traffic to the Internet Gateway.

Key Takeaway

The Egress VPC centralizes outbound traffic inspection, ensuring all internet-bound connections are secured by a single, consistent policy.
