Conceptual Egress VPC Setup with CLI

Understanding the logical steps for configuring a centralized egress architecture.

Logical Steps
1.

Create EgressVPC and DevVPC.

2.

Create AWS Transit Gateway.

3.

Attach VPCs to Transit Gateway.

4.

Deploy AWS Network Firewall in EgressVPC.

5.

Configure EgressVPC Route Tables (TGW to NF, NF to IGW).

6.

Configure DevVPC Route Tables (0.0.0.0/0 to TGW).

7.

Configure Transit Gateway Route Tables (DevVPC to EgressVPC, EgressVPC to DevVPC).

Conceptual CLI Snippets
# Create Transit Gateway (conceptual)aws ec2 create-transit-gateway --description "Central TGW"# Create TGW Attachments (conceptual)aws ec2 create-transit-gateway-vpc-attachment \    --transit-gateway-id <TGW_ID> \    --vpc-id <EGRESS_VPC_ID> \    --subnet-ids <EGRESS_VPC_TGW_SUBNET_ID>aws ec2 create-transit-gateway-vpc-attachment \    --transit-gateway-id <TGW_ID> \    --vpc-id <DEV_VPC_ID> \    --subnet-ids <DEV_VPC_TGW_SUBNET_ID># Configure EgressVPC Route Tables (conceptual)aws ec2 create-route --route-table-id <EGRESS_TGW_RT_ID> \    --destination-cidr-block 0.0.0.0/0 \    --network-interface-id <NF_ENDPOINT_ENI_ID>aws ec2 create-route --route-table-id <EGRESS_FIREWALL_RT_ID> \    --destination-cidr-block 0.0.0.0/0 \    --gateway-id <EGRESS_IGW_ID># Configure DevVPC Route Tables (conceptual)aws ec2 create-route --route-table-id <DEV_APP_RT_ID> \    --destination-cidr-block 0.0.0.0/0 \    --transit-gateway-id <TGW_ID>
Key Takeaway

The conceptual CLI steps highlight the precise routing configurations required at each layer to enforce centralized egress traffic inspection.
