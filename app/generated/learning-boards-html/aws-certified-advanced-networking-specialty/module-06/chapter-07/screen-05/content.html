VPC Flow Logs: Your Network's Eyes and Ears

Capturing IP traffic metadata within your Virtual Private Clouds

What Flow Logs Capture

  • •
    Source/Destination IPs: Who is talking to whom.
  • •
    Ports & Protocols: What services are being used.
  • •
    Action: Whether traffic was ACCEPTED or REJECTED.
  • •
    Bytes & Packets: Volume of data transferred.
Key Takeaway

VPC Flow Logs provide granular, real-time insights into all IP traffic, essential for network diagnostics and security monitoring.

Practical Use Case

Diagnose why a web server cannot connect to a database by checking if traffic is being rejected by Security Groups in Flow Logs.
