Amazon GuardDuty: Intelligent Threat Detection

Continuously monitoring for malicious activity and unauthorized behavior

Threats GuardDuty Detects

  • •
    Compromised EC2 Instances: Crypto mining, port scanning, C2 communication.
  • •
    Unauthorized S3 Access: Suspicious data access patterns.
  • •
    CloudTrail Tampering: Attempts to disable or modify logging.
  • •
    Unusual API Calls: From unusual locations or with unusual parameters.
Key Takeaway

GuardDuty is a critical, automated threat detection service that uses machine learning to identify a wide range of malicious activities across your AWS environment.

Foundational Security

GuardDuty should be enabled in all AWS accounts as a baseline security measure to protect workloads and data.
