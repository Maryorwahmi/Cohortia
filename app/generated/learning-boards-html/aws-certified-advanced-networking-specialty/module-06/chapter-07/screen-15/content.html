Chapter Review

Key Concepts (Continued)

Additional essential terms and services to remember

Amazon Security Hub

Provides a comprehensive view of your security posture, aggregating findings from various AWS services.

SIEM

Software solution that aggregates and analyzes security events from various sources across IT infrastructure.

Kinesis Data Firehose

Fully managed service for delivering real-time streaming data to various destinations, including SIEMs.

DNS Logs

Records of DNS queries made by resources within your VPC, used by GuardDuty for threat detection.

Summary Takeaway

These services and concepts enable a holistic, enterprise-grade security monitoring and threat detection platform in AWS and hybrid environments.
