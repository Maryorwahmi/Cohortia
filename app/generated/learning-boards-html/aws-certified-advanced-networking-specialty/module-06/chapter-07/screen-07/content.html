AWS CloudTrail: Tracking Actions in Your Account

Logging API calls for security, compliance, and operational troubleshooting

What CloudTrail Logs

  • •
    User Actions: API calls made by IAM users.
  • •
    Role Actions: Activities performed by assumed IAM roles.
  • •
    AWS Service Actions: Actions taken by AWS services on your behalf.
  • •
    Network Configuration Changes: VPC, Security Group, NACL modifications.
Key Takeaway

CloudTrail provides an immutable record of all API activity, crucial for auditing, compliance, and identifying unauthorized changes.

Practical Use Case

Investigate an unexpected change to a Security Group by reviewing CloudTrail logs to identify the user and API call responsible.
