Securing a Three-Tier Application: App & DB Tiers

Configuring Security Groups for internal application and database servers.

Application Tier (Private Subnet)
  • •Role: Process business logic.
  • •Communication: Receives from Web Tier, sends to DB Tier.
AppSG Rules
  • •Inbound: Port 8080 from WebSG
  • •Outbound: Port 3306 to DBSG
Database Tier (Private Subnet)
  • •Role: Store and manage data.
  • •Communication: Receives from App Tier only.
DBSG Rules
  • •Inbound: Port 3306 from AppSG
  • •Outbound: Default (-1) to 0.0.0.0/0 (adjust for strict security)
Key Takeaway

Each internal tier's Security Group should only allow traffic from the preceding tier on necessary ports, enforcing strict isolation and least privilege.
