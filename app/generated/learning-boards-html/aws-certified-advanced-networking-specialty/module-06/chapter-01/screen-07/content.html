Defense-in-Depth: Combining SGs and NACLs

Building robust perimeter protection with a layered security approach.

NACLs: Subnet Perimeter
  • •Broadly filter traffic at the subnet boundary.
  • •Block known malicious IP addresses or ranges.
  • •Deny specific protocols not expected in a subnet.
  • •Act as a coarse-grained, stateless firewall.
Security Groups: Instance Protection
  • •Precisely control traffic to individual instances or application tiers.
  • •Allow specific ports and protocols for application functionality.
  • •Act as a fine-grained, stateful firewall.
  • •Refine access within a subnet after NACL filtering.
Key Takeaway

A defense-in-depth strategy leverages both NACLs and SGs to create multiple layers of security, enhancing overall protection.
