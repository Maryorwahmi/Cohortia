Key Concepts: Core Definitions

Essential terms for advanced network security.

Security Group (SG)

A virtual firewall for an EC2 instance and other AWS resources, controlling inbound and outbound traffic. Stateful.

Network Access Control List (NACL)

An optional layer of security that acts as a firewall for controlling traffic in and out of one or more subnets. Stateless.

Stateful Firewall

A firewall that tracks the state of active connections, allowing return traffic for an established connection without an explicit rule.

Stateless Firewall

A firewall that treats each packet as an independent entity, requiring explicit rules for both inbound and outbound traffic.

Ephemeral Ports

A range of short-lived ports used by client applications when initiating connections (typically 1024-65535).

Summary Takeaway

Security Groups are stateful and instance-level, while Network ACLs are stateless and subnet-level, each with distinct rule processing and use cases.
