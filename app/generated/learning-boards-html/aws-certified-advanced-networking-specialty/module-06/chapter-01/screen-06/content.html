SG vs. NACL: A Fundamental Comparison

Understanding their distinct operational models and use cases.

Security Groups (SG)
  • •Scope: Instance level
  • •Statefulness: Stateful (return traffic automatically allowed)
  • •Rules: Allow rules only; implicit deny for unmatched traffic
  • •Processing: All rules evaluated, most permissive applies
  • •Primary Use: Controlling traffic to/from individual instances/resources
Network ACLs (NACL)
  • •Scope: Subnet level
  • •Statefulness: Stateless (explicit rules for both inbound and outbound)
  • •Rules: Allow and Deny rules; implicit deny at the end
  • •Processing: Rules evaluated in order (lowest to highest), first match applies
  • •Primary Use: Broad filtering, blocking malicious IPs at subnet boundary
Key Takeaway

Security Groups are stateful and instance-level, while Network ACLs are stateless and subnet-level, each serving distinct but complementary security roles.
