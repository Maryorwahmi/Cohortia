Diagnosing Connectivity: SGs, NACLs, and Flow Logs

Identifying common misconfigurations and using VPC Flow Logs for diagnosis.

Common Misconfigurations
  • •Forgetting that a restrictive NACL might be blocking traffic before it reaches the SG.
  • •Missing explicit inbound/outbound rules for ephemeral ports in stateless NACLs.
  • •Overly permissive rules that create security vulnerabilities.
Using VPC Flow Logs
  • •Capture IP traffic information for network interfaces in your VPC.
  • •Show if traffic is being ACCEPTed or REJECTed.
  • •Help pinpoint whether the issue is with a Security Group or a Network ACL.
Key Takeaway

Always check both SGs and NACLs when troubleshooting, and leverage VPC Flow Logs to gain visibility into traffic flow and rejection points.
