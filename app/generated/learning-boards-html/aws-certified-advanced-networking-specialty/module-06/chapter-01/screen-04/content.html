Core Concept

Security Groups: Stateful Instance Firewalls

Controlling traffic to and from AWS resources at the instance level.

Key Characteristics
  • •Operate at the instance level, acting as a virtual firewall for EC2 instances, RDS, and Load Balancers.
  • •Are stateful: if outbound traffic is allowed, corresponding inbound return traffic is automatically permitted.
  • •Only allow traffic; they never explicitly deny it. Traffic not matching an allow rule is implicitly denied.
  • •Simplify configuration by only requiring rules for the initial connection direction.
Example: Stateful Connection

An EC2 instance initiates an outbound connection to a web server on port 80. The Security Group has an outbound rule allowing port 80. The web server's response on port 80 is automatically allowed back to the EC2 instance, even without an explicit inbound rule for port 80.

Outbound initiates, Inbound returns
Key Takeaway

Security Groups simplify firewall management by automatically handling return traffic, but remember they only allow, never explicitly deny.

Common Misconception

Creating inbound rules for return traffic or expecting a deny rule to block return traffic from an allowed outbound connection.
