Securing a Three-Tier Application: Web Tier

Configuring Security Groups for public-facing web servers.

Web Tier (Public Subnet)
  • •Role: Serve public HTTP/HTTPS requests.
  • •Communication: Receives traffic from internet, sends to App Tier.
WebSG Inbound Rules
  • •HTTP (80) from 0.0.0.0/0
  • •HTTPS (443) from 0.0.0.0/0
WebSG Outbound Rules
  • •To AppSG: Port 8080 (application port)
  • •To Internet: All traffic (-1) to 0.0.0.0/0 (for updates/external services)
Traffic Flow

Internet (80/443) → WebSG → Web Servers → AppSG (8080)

Key Takeaway

The WebSG must allow public access for web traffic and specific outbound access to the application tier, adhering to the principle of least privilege.
