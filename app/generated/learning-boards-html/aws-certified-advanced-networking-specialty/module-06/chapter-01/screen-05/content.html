Core Concept

Network ACLs: Stateless Subnet Firewalls

Granular control over traffic entering and leaving a subnet.

Key Characteristics
  • •Operate at the subnet level, controlling traffic for all instances within that subnet.
  • •Are stateless: require explicit rules for both inbound and outbound traffic, including return traffic.
  • •Process rules in order, from lowest to highest numbered rule. The first matching rule is applied.
  • •Include an implicit deny rule at the end, blocking any traffic not explicitly allowed.
Example: Stateless Connection

To allow inbound HTTP on port 80, you need an inbound rule for port 80. For the web server's response to leave the subnet, you also need an explicit outbound rule for ephemeral ports (1024-65535).

Explicit rules for both directions
Key Takeaway

NACLs provide granular subnet-level control but demand explicit rules for all traffic directions, including return traffic.

Safety Note

Be extremely careful with NACL deny rules; a misconfiguration can easily block legitimate traffic for an entire subnet.
