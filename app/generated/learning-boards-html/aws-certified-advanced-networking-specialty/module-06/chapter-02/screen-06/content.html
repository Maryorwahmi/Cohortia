Web ACLs and Rule Processing

Defining How WAF Inspects and Acts on Traffic

Web ACL Fundamentals

  • Container for Rules: A Web ACL holds all your WAF rules.
  • Resource Association: Must be associated with a protected resource (e.g., ALB, CloudFront).
  • Rule Actions: Each rule specifies an action: ALLOW, BLOCK, or COUNT.
  • Default Action: Applied if no rules match. Crucial for security posture.
Concrete Example

You set a Web ACL's default action to ALLOW. Then, you add a rule to BLOCK requests from a known malicious IP. Any request from that IP will be blocked, while all other traffic is allowed by default.

WAF Rule Processing Flow
Incoming Web Request
Evaluate Rule 1 (Priority 1)
Evaluate Rule 2 (Priority 2)
...and so on...
First Match? Apply Action & Stop.
No Match? Apply Default Action.
Key Takeaway

WAF rules are processed in priority order; the first matching rule with a terminal action dictates the outcome for a request.
