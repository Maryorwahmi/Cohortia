AWS Shield Standard: Baseline DDoS Defense

Automatic and Always-On Protection for All AWS Customers

Shield Standard Features

  • Automatic: Enabled for all AWS customers by default.
  • No Additional Cost: Included with your AWS services.
  • Always-On: Continuous detection and mitigation.
  • Layer 3/4 Protection: Defends against common network and transport layer DDoS attacks.
  • Examples: SYN floods, UDP reflection attacks, basic HTTP floods.
Concrete Example

A small blog hosted on an EC2 instance experiences a sudden SYN flood. AWS Shield Standard automatically detects this and applies inline mitigation, preventing the attack from overwhelming the instance's network interface, all without any configuration or cost to the user.
