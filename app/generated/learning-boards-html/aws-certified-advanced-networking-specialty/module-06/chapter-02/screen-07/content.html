WAF Rule Types

IP Set and Rate-Based Rules

Blocking Malicious IPs and Mitigating DDoS Attacks

IP Set Rules

  • Purpose: Allow or block traffic from specific IP addresses or CIDR ranges.
  • Mechanism: You create an 'IP Set' resource containing the list of IPs.
  • Use Case: Blocking known attackers, allowing trusted partners.
  • Example: Block 192.0.2.1/32 from accessing your application.
Concrete Example

A security report identifies a botnet operating from a specific range of IP addresses. You create an IP set with these ranges and a WAF rule to block all requests originating from them, immediately cutting off a known threat.

Rate-Based Rules

  • Purpose: Mitigate DDoS attacks by blocking IPs sending too many requests.
  • Mechanism: Defines a request threshold (e.g., 100 requests) within a 5-minute period.
  • Action: Automatically blocks IPs exceeding the threshold.
  • Use Case: Defending against HTTP floods, brute-force attacks, web scraping.
Key Takeaway

IP set rules offer static blocking/allowing, while rate-based rules provide dynamic, automated DDoS mitigation based on request volume.
