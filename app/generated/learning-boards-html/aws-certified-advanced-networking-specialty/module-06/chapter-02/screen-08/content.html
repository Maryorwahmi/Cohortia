WAF Rule Types

String Matching and AWS Managed Rules

Detecting Specific Patterns and Leveraging Expert-Curated Protection

String Matching Rules

  • Inspects: HTTP headers, query strings, URI, request body.
  • Detects: Specific patterns, keywords, or known attack signatures.
  • Specialized Rules: SQL injection and Cross-Site Scripting (XSS) detection.
  • Example: Block requests with a specific malicious string in the User-Agent header.
Concrete Example

An attacker attempts to exploit an XSS vulnerability by injecting a <script>alert('XSS')</script> tag into a comment field. A WAF XSS rule detects this pattern in the request body and blocks it, preventing the script from executing in users' browsers.

AWS Managed Rules

  • Pre-configured: Rule groups managed and updated by AWS.
  • Protection: Against common threats like OWASP Top 10, bad bots.
  • Benefit: Saves time and expertise, provides immediate baseline protection.
  • Consideration: May require tuning to avoid false positives for unique applications.
Key Takeaway

String matching rules offer precise pattern detection, while AWS Managed Rules provide convenient, broad protection against common web vulnerabilities.
