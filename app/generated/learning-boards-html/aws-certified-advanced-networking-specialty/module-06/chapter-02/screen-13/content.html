WAF and Shield Integration Points

Securing Various AWS Services and Hybrid Architectures

Key Integration Points

  • CloudFront: WAF filters traffic at the edge, Shield protects the distribution.
  • Application Load Balancer (ALB): WAF and Shield protect ALBs directly exposed to the internet.
  • API Gateway: WAF secures REST API endpoints from web exploits.
  • AppSync: WAF protects GraphQL API endpoints.
  • Hybrid Cloud: Extend consistent security posture to AWS-hosted components.
Concrete Example

A company uses API Gateway for its mobile application backend. By associating a WAF Web ACL with the API Gateway, they can block requests from known malicious IPs or detect SQL injection attempts targeting their API, protecting the backend services.

Key Takeaway

WAF and Shield integrate broadly across AWS services, enabling flexible and consistent edge protection for diverse application architectures, including hybrid environments.
