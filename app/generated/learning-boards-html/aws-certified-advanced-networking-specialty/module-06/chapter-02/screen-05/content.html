Service Overview

AWS WAF: Your Web Application Firewall

Monitoring and Controlling HTTP/HTTPS Requests at Layer 7

Key WAF Characteristics

  • Application Layer (Layer 7): Inspects HTTP/HTTPS request content.
  • Granular Control: Allows or blocks traffic based on specified conditions.
  • Protects Against: Common web exploits like SQLi, XSS, and HTTP floods.
  • Integrated Services: CloudFront, ALB, API Gateway, AppSync.
Concrete Example

A malicious actor tries to inject SQL code into your web form. WAF can detect this specific pattern in the HTTP request body and block it, preventing the attack from reaching your database.

Key Takeaway

WAF provides crucial Layer 7 protection by inspecting HTTP/HTTPS requests, integrating with key AWS services to filter malicious traffic.
