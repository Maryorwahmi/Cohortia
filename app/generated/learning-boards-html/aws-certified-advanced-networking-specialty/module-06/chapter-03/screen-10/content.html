Module 6 › Chapter 6.3 › Route 53 Resolver DNS Firewall Policies
Policy Type
Route 53 Resolver DNS Firewall Policies
Centrally manage domain filtering for DNS queries within your VPCs, blocking access to known malicious domains or enforcing corporate acceptable use policies.
  • Define and apply domain lists to filter DNS queries.
  • Block access to malicious or prohibited domains.
  • Enforce corporate acceptable use policies at the DNS level.
  • Provides a proactive layer of security against domain-based threats.
Key Takeaway

Route 53 Resolver DNS Firewall policies in Firewall Manager allow centralized management of domain filtering for DNS queries, enhancing security by blocking malicious domains and enforcing policies.
