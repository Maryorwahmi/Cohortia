Module 6 › Chapter 6.3 › AWS WAF Policies
Policy Type
AWS WAF Policies
Centrally deploy and manage AWS WAF Web ACLs across accounts for resources like CloudFront distributions, ALBs, API Gateways, and AppSync APIs.
  • Ensures all public-facing applications have baseline WAF protection.
  • Target policies to specific resources (e.g., all ALBs, or tagged ALBs).
  • Option to create new Web ACLs or use existing ones.
  • Protects against common web exploits like SQL injection and XSS.
Key Takeaway

AWS WAF policies in Firewall Manager automate the deployment of Web ACLs to protect web applications across your organization, ensuring consistent security against common web threats.
