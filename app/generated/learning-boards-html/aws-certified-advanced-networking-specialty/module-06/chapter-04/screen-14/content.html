Key Concepts

Essential terms and ideas from this chapter.

AWS Network Firewall

A managed service for deploying network firewalls in your VPCs, offering stateful inspection, intrusion prevention, and web filtering.

Firewall Endpoint

The actual component of Network Firewall deployed in an Availability Zone within a VPC, through which traffic is routed for inspection.

Stateless Rule Group

A collection of rules that inspect individual packets without regard to connection state, processed before stateful rules.

Stateful Rule Group

A collection of rules that inspect traffic based on connection state, enabling advanced features like 5-tuple inspection, domain filtering, and IPS.

Chapter Summary

AWS Network Firewall provides advanced, managed network security for deep traffic inspection across VPCs, utilizing both stateless and stateful rule groups for granular control and threat prevention.
