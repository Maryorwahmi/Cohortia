Rule Logic

Understanding Network Firewall Rule Groups

Defining the inspection logic with stateless and stateful rule sets.

Rule Group Overview

  • **Collections of Rules:** Define how Network Firewall inspects traffic.
  • **Two Primary Types:** Stateless and Stateful rule groups.
  • **Crucial Order:** Stateless rules are always processed before stateful rules.
  • **Layered Security:** Combines fast initial filtering with deep connection insight.

Analogy: Airport Security

Think of rule groups like different stages of airport security. **Stateless rules** are like the initial ID check and metal detector – quick, basic checks on individual passengers (packets) without knowing their travel history. **Stateful rules** are like the detailed baggage inspection and interview process – they consider the passenger's entire journey (connection state) and context to make more informed decisions, looking for deeper threats.

Rule Group Types & Flow

Key Takeaway

Network Firewall uses stateless (packet-based) and stateful (connection-based) rule groups, with stateless rules always processed first for layered security.
