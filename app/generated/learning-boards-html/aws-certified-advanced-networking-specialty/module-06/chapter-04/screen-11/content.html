Rule Processing

Rule Evaluation Order and Actions

Understanding how Network Firewall processes rules and applies actions.

Evaluation Flow

  • **Stateless First:** All stateless rules are evaluated before any stateful rules.
  • **Action Applied:** If a stateless rule matches, its action is immediately applied.
  • **To Stateful Engine:** Traffic not dropped or explicitly passed by stateless rules proceeds to stateful inspection.
  • **Stateful Evaluation:** Stateful rules are then evaluated based on connection context.

Rule Actions

  • **DROP:** Discards the traffic, blocking it completely.
  • **ALERT:** Generates a log entry for the traffic but allows it to pass. Useful for monitoring.
  • **PASS:** Forwards the traffic to the next rule group or the firewall policy's default action.
  • **Default Actions:** Can be configured for traffic that doesn't match any explicit stateful rules.

Key Takeaway

Stateless rules are processed first, followed by stateful rules, with actions like DROP, ALERT, and PASS determining traffic flow and logging behavior.
