Network Firewall Deployment & Integration

Understanding how Network Firewall integrates into your VPC network.

Deployment Model

  • **VPC-Level Operation:** Deployed directly within a chosen VPC.
  • **AZ Endpoints:** Creates a firewall endpoint in each Availability Zone for high availability.
  • **Managed Service:** AWS manages the underlying infrastructure and scaling.

Traffic Routing Essentials

  • **Route Table Configuration:** Crucial for directing traffic through firewall endpoints.
  • **Inspection Points:** Traffic (ingress, egress, inter-VPC) must be explicitly routed.
  • **Traffic Flow:** Ensure all desired traffic passes through the firewall ENI for inspection.

Key Takeaway

Network Firewall deploys endpoints per AZ within a VPC, requiring precise route table configuration to direct traffic for inspection.
