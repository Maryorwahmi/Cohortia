Module 6 › Chapter 6.5 › Secure Endpoints
Security Groups
Attach one or more Security Groups to interface endpoint ENIs. Configure inbound rules to allow only the source Security Groups or IP ranges that require access. Use HTTPS (443) for most managed service endpoints.
Example rule
Allow inbound 443 from the EC2 application's Security Group ID to the endpoint SG.
Endpoint policies
Attach IAM resource policies to endpoints to restrict which principals and actions are allowed when using that endpoint. This is a second layer of authorization beyond network controls.
Common pitfall
Overly permissive endpoint policies or missing Security Group restrictions can expose services to unintended callers. Use least privilege everywhere.
Audit checklist
  • Verify endpoint SG inbound rules match intended callers.
  • Review endpoint policy statements for principal and action scope.
  • Confirm NLB listeners and backend target protections align with expected traffic.
