Module 6 › Chapter 6.5 › What is AWS PrivateLink?

Definition

PrivateLink creates interface endpoints that keep service traffic inside AWS, using ENIs with private IP addresses.

Benefits
  • Reduces attack surface by avoiding the public internet.
  • Simplifies compliance and private hybrid connectivity.
  • Enables partner and multi-account service exposure.
Example
EC2 in a private subnet sends messages to SQS via an SQS interface endpoint without a NAT gateway.
Explainer
Interface endpoint anatomy
A set of ENIs with private IPs placed in your subnets. DNS resolves service names to those private IPs so clients use private paths.
Common misconception
Not all endpoints are equal: gateway endpoints are route table targets for S3/DynamoDB, not ENIs, and are not reachable from on-premises.
Key takeaway
Use PrivateLink when you need private, hybrid, or multi-account access to services beyond S3 and DynamoDB.
