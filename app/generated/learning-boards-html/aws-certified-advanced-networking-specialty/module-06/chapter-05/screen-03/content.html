Practical outcomes

These outcomes map directly to the hands-on activities in this chapter. Each outcome has clear verification steps.

SQS private connectivity
Create an interface endpoint, test SQS send-message from EC2 using the endpoint's DNS name, and validate Security Group rules.
VPC Endpoint Service
Front your service with an NLB, publish a VPC Endpoint Service, grant a consumer account, and validate acceptance and connectivity.
Security checks
Confirm Security Groups only allow intended sources and that endpoint policies enforce least privilege for IAM principals and actions.
Milestone
Demonstrate a validated PrivateLink connection between two accounts or between VPC and on-premises via Direct Connect.
This proves you can design for hybrid and multi-account service sharing without exposing services to the public internet.
