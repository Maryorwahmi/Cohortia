Question 1

Which endpoint configuration allows EC2 in private subnet and on-premises via Direct Connect to access S3 privately?

Answer: S3 interface endpoint
Reason: Gateway endpoints aren't reachable from on-premises. Interface endpoints create ENIs that support hybrid access through the VPC.

Question 2

How do you expose a SaaS API privately to customer accounts?

Answer: VPC Endpoint Service (PrivateLink)
Reason: Provider publishes service backed by NLB; consumers create interface endpoints and are granted access, keeping traffic inside AWS.
Security checklist
  • Narrow endpoint SGs to intended caller SGs.
  • Attach endpoint policies to restrict principals and actions.
  • Validate NLB health checks and restrict listener access.
