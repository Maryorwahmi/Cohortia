Module 6 › Chapter 6.5 › VPC Endpoint Service Flow
Provider steps
  1. Run your service on EC2 or containers and register targets with a Network Load Balancer.
  2. Create a VPC Endpoint Service pointing to the NLB and configure allowed principals or require acceptance.
  3. Grant access to specific consumer account IDs or set open acceptance cautiously.
Consumer steps
Create an interface endpoint specifying the provider's service name, wait for provider acceptance, then use the endpoint's private DNS or ENI IPs to reach the service.
Security & routing
Security Groups on interface endpoints restrict which resources can connect. NLB target protections and endpoint policies enforce additional controls. Routing stays within AWS backbone once accepted.
Key takeaway
Provider/consumer separation gives a secure model for multi-account, private service sharing, ideal for SaaS and internal platform teams.
