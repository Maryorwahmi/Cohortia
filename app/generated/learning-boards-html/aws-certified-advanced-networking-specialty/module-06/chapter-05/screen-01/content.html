Concept snapshot
Private connectivity patterns and provider vs consumer roles
Interface Endpoint
ENIs with private IPs. Supports many AWS and partner services and hybrid access via Direct Connect or VPN.
Gateway Endpoint
Route table target for S3 and DynamoDB. Free and scalable but not reachable from on-premises.
Provider / Consumer
Provider creates a VPC Endpoint Service backed by an NLB. Consumer creates an interface endpoint and, once accepted, accesses the service privately.
