Module 6 › Chapter 6.5 › Key Concepts
PrivateLink (Interface Endpoint)
ENIs with private IPs that keep service traffic on the AWS network for hybrid and multi-account use cases.
Gateway Endpoint
Route table targets for S3 and DynamoDB; free and scalable but not reachable from on-premises.
Secure by design
Combine Security Groups and endpoint policies to enforce least privilege at network and IAM layers.
Summary takeaway
Choose the endpoint type that fits your reachability needs, secure endpoints on both network and IAM levels, and test with consumer/provider roles to validate PrivateLink designs.
