Module 6 › Chapter 6.5 › Troubleshooting

Common failure modes

  • Security Group on endpoint ENI blocks intended source.
  • Provider did not accept a consumer endpoint request or account not whitelisted.
  • Private DNS not enabled so clients resolve the public endpoint instead of private ENIs.
  • Using gateway endpoints when hybrid access is required.
  • Overly permissive endpoint policies causing governance issues.
Diagnostic steps
  1. Check endpoint ENI Security Groups and NACLs.
  2. Confirm provider acceptance and service permissions.
  3. Verify private DNS settings and test name resolution inside the VPC.
  4. Use VPC Flow Logs and CloudWatch to trace traffic paths.
Pro tip
Always test with the simplest client configuration first, then add endpoint policies and stricter SG rules once connectivity is proven.
