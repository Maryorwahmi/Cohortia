Module 6 › Chapter 6.5 › ENIs & Private DNS
ENI anatomy
Interface endpoints provision one or more ENIs in selected subnets. Each ENI gets a private IP from your VPC. Traffic to the service is sent to those private IPs and forwarded over AWS's internal network to the service or NLB.
Subnet planning
Place ENIs in subnets across availability zones for redundancy and to keep traffic local to your application instances.
Private DNS
When private DNS is enabled, the standard service domain resolves to the endpoint's private IPs inside the VPC, so your application uses the private route without configuration changes.
Gotcha
Ensure private DNS overrides don't conflict with other hosted zones. Also, attach Security Groups to ENIs to avoid accidental exposure.
Example
Enable private DNS for an SQS interface endpoint so existing EC2 clients that use the default SQS hostname automatically route to the private ENIs without code changes.
