Module 6 › Chapter 6.5 › Gateway vs Interface
Gateway Endpoint

S3 & DynamoDB only

  • Works as a route table target for S3 and DynamoDB.
  • No ENIs or private IPs in your subnets.
  • Free to use; not reachable from on-premises via Direct Connect or VPN.
When to pick
VPC-only S3 or DynamoDB access where cost is a priority and hybrid reachability is not required.
Interface Endpoint

PrivateLink-powered ENIs

  • Creates ENIs with private IPs in your subnets.
  • Supports many AWS services, partner services, and custom endpoint services.
  • Reachable from on-premises networks via Direct Connect or VPN through the VPC.
When to pick
Use when you need hybrid access, partner integrations, or to expose services across accounts with PrivateLink.
Common mistake

Trying to access S3 from on-premises through a gateway endpoint will fail because gateway endpoints are not reachable from outside the VPC. For hybrid scenarios, create an S3 interface endpoint instead.
