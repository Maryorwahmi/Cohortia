Module 6 › Chapter 6.5 › Expose Custom Service
Sequence
  1. Launch EC2 running NGINX and ensure port 80 is open on the instance SG only from NLB SG.
  2. Create an NLB and register the EC2 instance as a target; configure health checks.
  3. Create a VPC Endpoint Service pointing to the NLB and grant access to consumer account ID.
  4. Consumer creates an interface endpoint to the service; provider accepts if required.
  5. Consumer tests by curling the endpoint's private DNS or ENI IP.
Verification
Confirm NLB health checks pass, endpoint ENIs are present in consumer subnets, and that requests return the expected web content. Use VPC Flow Logs if you need to trace traffic paths.
Pitfall
Not granting access or forgetting to accept the consumer connection will leave the consumer endpoint in a pending state.
Real-world analogy
Think of the provider's NLB as the private reception door and the endpoint ENIs as secure hallways inside the data center that only authorized visitors can use.
