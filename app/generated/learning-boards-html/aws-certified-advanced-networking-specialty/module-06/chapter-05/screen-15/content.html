Module 6 › Chapter 6.5 › Quick Reference
Interface Endpoint
VPC endpoint with ENIs and private IPs; supports services via PrivateLink.
Gateway Endpoint
Route table target for S3 and DynamoDB; free but not reachable from on-premises.
VPC Endpoint Service
Provider resource pointing to an NLB that lets other accounts create interface endpoints to your service.
Handy reminder
For hybrid or multi-account service access, prefer interface endpoints and enforce least privilege with SGs and endpoint policies.
