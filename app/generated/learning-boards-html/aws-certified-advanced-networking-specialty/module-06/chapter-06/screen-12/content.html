Setting Up Your Private CA

Using AWS CLI to create a Root Certificate Authority

# 1. Create a Root CA in Private CA
aws acm-pca create-certificate-authority \
    --certificate-authority-configuration '{"KeyAlgorithm":"RSA_2048","SigningAlgorithm":"SHA256WITHRSA","Subject":{"CommonName":"MyOrgRootCA"}}' \
    --certificate-authority-type ROOT \
    --usage-mode GENERAL_PURPOSE \
    --region us-east-1

# Expected Output (truncated):
{
    "CertificateAuthorityArn": "arn:aws:acm-pca:us-east-1:123456789012:certificate-authority/abcdef12-3456-7890-abcd-ef1234567890"
}

  • Command Explanation: `create-certificate-authority` initiates the creation of your CA.

  • Configuration: Define key and signing algorithms, and the CA's common name.

  • Output: The command returns the `CertificateAuthorityArn`, which is essential for future steps.

Key Takeaway

Creating a Private CA involves specifying cryptographic details and type, resulting in a unique ARN for identification.

Important Note

After creation, you typically need to activate the CA by installing its certificate. For a Root CA, this often involves self-signing its CSR.
