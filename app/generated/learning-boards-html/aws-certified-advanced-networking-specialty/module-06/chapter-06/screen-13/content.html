Issuing a Private Certificate via ACM

Requesting a certificate from your Private CA for internal use

# Assume CA_ARN is set from previous step
CA_ARN="arn:aws:acm-pca:us-east-1:123456789012:certificate-authority/abcdef12-3456-7890-abcd-ef1234567890"

# 4. Request a Private Certificate from ACM, issued by Private CA
aws acm request-certificate \
    --domain-name "internal.example.com" \
    --validation-method DNS \
    --certificate-authority-arn $CA_ARN \
    --region us-east-1

# Expected Output (truncated):
{
    "CertificateArn": "arn:aws:acm:us-east-1:123456789012:certificate/a1b2c3d4-e5f6-7890-1234-567890abcdef"
}

  • Command Explanation: `request-certificate` is used to request a new certificate.

  • Private CA as Issuer: The `--certificate-authority-arn` flag directs ACM to use your Private CA.

  • Output: The command returns the `CertificateArn`, which identifies your new private certificate.

Key Takeaway

ACM can request private certificates from your Private CA, streamlining the issuance and management for internal domains.
