Module 7 › Chapter 7.2 › Lab walkthrough
Prerequisites
An existing VPC and EC2 instance; IAM role VPCFlowLogsRole and policy created; CloudWatch log group /aws/vpc/flowlogs created.
Enable Flow Log
  1. Create flow log with traffic-type ALL and destination set to your log group.
  2. Use the IAM role ARN that grants CloudWatch Logs permissions.
Generate denied traffic
From outside the VPC, attempt an SSH connection while your EC2 security group denies that source. The failed SSH creates REJECT entries.
Query
Run: fields @timestamp, srcaddr, dstaddr, srcport, dstport, protocol, action | filter action = "REJECT" | sort @timestamp desc | limit 50
If no results
Verify IAM role permissions, the log group name, and Flow Log status. Check for log-status values like NODATA or SKIPDATA.
