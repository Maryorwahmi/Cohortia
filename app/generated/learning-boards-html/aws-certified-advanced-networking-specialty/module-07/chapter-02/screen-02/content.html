01
Enable Flow Logs (VPC / Subnet / ENI)

Configure capture at the level that balances coverage and cost. Knowing when to enable subnet or ENI level logging reduces noise and expense.

Mnemonic: Scope = Breadth vs Depth
VERIFIED COMPETENCY MILESTONE
02
Read and interpret flow log fields

Understand fields like action, protocol, bytes, packets, and timestamps so you can spot rejected flows and traffic patterns.

Mnemonic: 5-tuple + action
VERIFIED COMPETENCY MILESTONE
03
Deliver logs to S3 or CloudWatch Logs

Choose S3 for archival and batch analysis or CloudWatch Logs for real-time queries and alerts.

Mnemonic: Archive vs Alert
VERIFIED COMPETENCY MILESTONE
04
Query with CloudWatch Logs Insights

Write queries to find REJECT entries, filter by IP or port, and sort results to investigate incidents quickly.

Mnemonic: Filter → Sort → Inspect
VERIFIED COMPETENCY MILESTONE
Quick guide
Milestones map to hands-on tasks: create IAM role, create log group, enable flow logs, run a Logs Insights query for REJECT.
Why this matters
These objectives turn raw packets into answers about whether a security group, NACL, or route is blocking traffic.
