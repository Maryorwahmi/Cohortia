Example Logs Insights query
fields @timestamp, srcaddr, dstaddr, srcport, dstport, protocol, action
| filter action = "REJECT"
| sort @timestamp desc
| limit 20
This query surfaces recent rejected flows with IPs, ports, and protocol. Adjust the filter to target a port or time range when you generated test traffic.
Refinement examples
  • Filter by dstport to find denied attempts to a specific service port.
  • Filter by srcaddr to find a particular external tester IP.
  • Include log-status to detect incomplete records like SKIPDATA.
Checklist
Select the correct log group, confirm time range, run query, and correlate IPs to instances.
Misconception
Logs Insights returns the fields you ask for. If you need instance names, include instance-id in log records or perform external correlation.
