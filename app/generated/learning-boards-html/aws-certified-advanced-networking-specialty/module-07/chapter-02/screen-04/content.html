Module 7 › Chapter 7.2 › What are VPC Flow Logs?
Definition

VPC Flow Logs capture IP traffic flows for network interfaces in a VPC and write structured records describing source, destination, ports, protocol, bytes, packets, start and end times, and the action taken.

Why this matters
  • Confirm whether traffic was explicitly accepted or rejected.
  • See five-tuple details to diagnose connectivity and route issues.
  • Provide evidence for compliance and incident investigations.
Analogy

Think of each flow log record as a short police report for a single network conversation: who called whom, what port they used, how much data moved, and whether the call was allowed.

Concrete example
An EC2 instance at 10.0.1.10 attempts to reach 172.31.2.5 on port 443. Flow Logs record srcaddr 10.0.1.10, dstaddr 172.31.2.5, dstport 443, protocol 6, and action REJECT if a security group blocks the traffic. That REJECT entry is direct evidence the packet was denied.
Common misconception
Flow Logs do not show application names or HTTP status codes. Use instance metadata and tags to map IPs to services.
