Module 7 › Chapter 7.2 › Common mistakes
Incorrect IAM permissions
Missing logs:PutLogEvents or create permissions prevents delivery. Validate role ARN and permissions if logs do not appear.
Misreading fields
Remember action is network allow/deny; protocol is numeric by default. Correlate fields rather than assuming meanings.
Over-filtering vs noise
Logging only REJECT can hide baseline ACCEPT patterns; logging ALL without partitioning increases cost.
Missing context
Flow Logs lack application names. Keep tagging and ENI-instance mapping to provide context.
Cost management
Send bulk historical data to S3 and use CloudWatch for targeted, short-term investigations to reduce cost.
Delivery status
Check log-status values like SKIPDATA or NODATA to detect incomplete records.
