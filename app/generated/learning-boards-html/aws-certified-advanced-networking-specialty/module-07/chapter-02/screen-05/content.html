Module 7 › Chapter 7.2 › Where to enable Flow Logs
Step 1 — VPC level

Capture all ENIs in the VPC. Use when you need comprehensive coverage across an entire network segment. Best for incident reviews and audits, but expect higher volume.

Step 2 — Subnet level

Target a specific application tier or security zone. Useful when the problem is localized to a service group or zone and you want to limit noise.

Step 3 — ENI level

Zoom in to a single network interface for deep troubleshooting of one instance or attachment. Use sparingly to control cost and volume.

Decision guide
  • If you don't know where the issue is: enable VPC-level to gather signals.
  • If you have an application tier in question: enable subnet-level to reduce noise.
  • If a single instance shows abnormal behavior: enable ENI-level for focused logs.
Pro-tip
Use VPC-level logging briefly to locate a problem, then switch to subnet or ENI level for ongoing monitoring to save cost and improve signal-to-noise.
