Module 7 › Chapter 7.2 › Mapping records to resources
Mapping steps
  1. Identify interface-id in the flow record.
  2. Use DescribeNetworkInterfaces or console to find the ENI attachment and instance-id.
  3. Correlate instance-id with tags to find the application owner.
Design recommendation
Include instance-id and vpc-id fields in customized logs and maintain consistent tags so each log line can be linked to a service without ad hoc lookups.
Example
A REJECT entry that includes eni-0a1b2c corresponds to an EC2 instance. Use the ENI lookup to find the instance and then its tags to identify the owning team.
Misconception
Do not assume IP-to-instance mapping is static; IPs may move. Prefer interface-id or instance-id when available.
