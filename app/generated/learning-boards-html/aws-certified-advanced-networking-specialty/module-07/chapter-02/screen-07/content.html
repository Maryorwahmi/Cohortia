Module 7 › Chapter 7.2 › Record format
Default fields
  • version, account-id, interface-id
  • srcaddr, dstaddr, srcport, dstport, protocol
  • packets, bytes, start, end
  • action (ACCEPT or REJECT), log-status (OK, NODATA, SKIPDATA)
Interpreting fields
Use action to confirm a block; use protocol numbers to identify TCP/UDP; combine packets and bytes to spot heavy flows; map interface-id to ENI and instance metadata for ownership.
Custom fields
You can include vpc-id, subnet-id, instance-id, tcp-flags, type, or region to tailor logs to analysis needs.
Misinterpretation risk
Seeing REJECT does not tell you which security control triggered it without correlating with security group or NACL evaluation timelines.
