Practice Tasks
Complete these tasks to validate competency.
Create IAM role and policy

Grant logs:CreateLogGroup, logs:CreateLogStream, logs:PutLogEvents, and related read operations so flow logs can publish to CloudWatch Logs.

Milestone: Role ARN available
Create a CloudWatch Log Group

Use a clear naming convention like /aws/vpc/flowlogs to make queries repeatable.

Milestone: Log group exists
Enable Flow Logs

Create the flow log with traffic-type ALL for testing; restrict later to reduce volume if needed.

Milestone: Flow log has logGroup destination
Run Logs Insights query

Filter action = "REJECT" and confirm you can identify the source IP of a blocked SSH attempt.

Milestone: REJECT results returned
Common mistakes
  • Missing logs:PutLogEvents permission on the IAM role.
  • Over-filtering so ACCEPT traffic is never recorded during baseline collection.
Testing tip
Generate a denied connection from outside the VPC to create a clear REJECT entry to query.
