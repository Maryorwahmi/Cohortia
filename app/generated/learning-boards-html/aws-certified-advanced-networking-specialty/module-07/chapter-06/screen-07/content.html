Module 7 › Chapter 7.6 › Direct Connect Metrics
Definition

Direct Connect metrics

ConnectionState: UP/DOWN for the physical link.
ConnectionBpsIngress/Egress: Bandwidth utilization for capacity and saturation checks.
ConnectionErrorCount: Physical errors indicating cabling or port faults.
BGPState: The routing session state for each virtual interface; critical for route exchange.
Scenario
Observed
ConnectionState = 1, but users cannot reach VPC resources.
Likely cause
BGPState is DOWN; routes are not exchanged despite the link being up.
Common mistake: Alerting only on ConnectionState and ignoring BGPState, which can leave you blind to routing-level issues.
