CLI example

Create an alarm that fires when a VPN tunnel state goes down and notifies an SNS topic.

aws cloudwatch put-metric-alarm \ 
    --alarm-name "VPN_Tunnel_1_Down_Alarm" \ 
    --alarm-description "Alert when VPN Tunnel 1 goes down" \ 
    --metric-name TunnelState \ 
    --namespace AWS/VPN \ 
    --statistic Minimum \ 
    --period 300 \ 
    --threshold 1 \ 
    --comparison-operator LessThanThreshold \ 
    --dimensions Name=VpnId,Value=vpn-0abcdef1234567890 Name=TunnelIpAddress,Value=1.2.3.4 \ 
    --evaluation-periods 1 \ 
    --alarm-actions arn:aws:sns:us-east-1:123456789012:NetworkAlertsTopic \ 
    --treat-missing-data breaching
Notes
  • Replace VpnId, TunnelIpAddress, and SNS ARN with your values.
  • Use statistic Minimum and a one-evaluation period to detect state flips quickly.
  • Validate the alarm by observing CloudWatch alarm state and SNS delivery.
Key Takeaway
CLI alarms must include correct metric dimensions; test notifications and tune evaluation windows to avoid false alerts.
