Module 7 › Chapter 7.6 › VPN vs Direct Connect
Comparison

Site-to-Site VPN

  • Key metrics: TunnelState, TunnelDataIn/Out, IPSecTunnelState.
  • Failure modes: internet path issues, CGW errors, IPSec negotiation problems.
  • Alert strategy: Per-tunnel alarms, correlate with ISP and CGW logs.
Comparison

Direct Connect

  • Key metrics: ConnectionState, ConnectionBpsIngress/Egress, ConnectionErrorCount, BGPState.
  • Failure modes: physical link faults, cabling, colocation port issues, BGP session problems.
  • Alert strategy: Link and BGP alarms, track error counts and utilization.
Shared practices
Correlate provider metrics with on-prem logs, centralize alerts, tune thresholds to avoid fatigue, and document runbooks for rapid triage.
