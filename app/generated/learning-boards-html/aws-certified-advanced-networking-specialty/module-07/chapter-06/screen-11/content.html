Module 7 › Chapter 7.6 › On-prem Monitoring

What to collect

  • CGW interface up/down, CPU, memory, and IPSec logs.
  • BGP neighbor state and route changes from your edge routers.
  • ISP link metrics: latency, packet loss, and outages.
  • Internal device errors and interface counters for switches and firewalls.

How to use it

Correlate these local signals with CloudWatch alarms by timestamp and include them in the same incident ticket. This makes it straightforward to identify customer-side faults versus provider issues.
Common mistake
Keeping cloud and on-prem alerts in separate systems, which delays root-cause identification.
