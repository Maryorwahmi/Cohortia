Process Flow

Responding to a TunnelState alarm

  1. Confirm alarm time and which tunnel(s) are affected.
  2. Inspect customer gateway device logs and interface counters for flaps or resource exhaustion.
  3. Check ISP path health and packet loss during the event window.
  4. Validate AWS VPN configuration and CloudWatch tunnel metrics for mismatches.
  5. Verify BGP session state if routing issues persist, then escalate with correlated logs.
Example scenario
Observed
Tunnel 0 TunnelState = 0 at 10:12, Tunnel 1 = 1. CGW log shows interface down at 10:11.
Action taken
Contact ISP with timestamps and failover traffic to the healthy tunnel until the CGW interface is repaired.
Pro-tip: Always attach CGW logs and ISP timestamps to your escalation to avoid back-and-forth evidence requests.
