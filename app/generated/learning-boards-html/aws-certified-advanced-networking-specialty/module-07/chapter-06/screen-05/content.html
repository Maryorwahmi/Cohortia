Module 7 › Chapter 7.6 › VPN Metrics
Definition

Site-to-Site VPN metrics

Metrics provide per-tunnel and per-connection visibility. Use each for a specific purpose.

TunnelState
Binary per-tunnel status (1 = UP, 0 = DOWN). Critical for immediate alerts.
TunnelDataIn / TunnelDataOut
Bytes in/out per tunnel. Used for traffic patterns and load balancing checks.
VPNConnectionState / IPSecTunnelState
Aggregated or IPSec-phase details for higher-level views or deep diagnostics.
Example
Symptom
Tunnel 0 TunnelState oscillates between 1 and 0; Tunnel 1 remains 1.
Likely cause
On-premise internet instability or CGW interface flapping for the affected tunnel.
Key Takeaway

Per-tunnel metrics are essential. Use TunnelState for alerts and TunnelData counters for performance insights.
