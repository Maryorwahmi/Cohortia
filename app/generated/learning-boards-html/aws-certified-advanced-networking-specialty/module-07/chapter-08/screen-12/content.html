Module 8 › Chapter 7.8 › Lab: Config Rule
Checklist
  1. Enable AWS Config with an S3 bucket and IAM role.
  2. Add managed rule ec2-instance-no-public-ip.
  3. Wait for evaluation and inspect non-compliant resources.
  4. Remediate and re-evaluate the rule.
Outcome
You should be able to identify any EC2 instances with public IPs, take remediation action, and confirm they return to compliant status after re-evaluation.
