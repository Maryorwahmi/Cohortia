Module 8 › Chapter 7.8 › VPC Flow Logs
Definition & Use Cases
VPC Flow Logs emit connection metadata. Use them for troubleshooting, traffic accounting, detection of unusual flows, and forensic investigations.
CloudWatch Logs
Real-time queries, alerting, short retention (30–90 days typical).
S3
Long-term archival, Athena queries, lifecycle to Glacier for compliance.
Best practice
Send copies where they have distinct value: CloudWatch for alerts, S3 for archives and analytics.
Concrete Example
Collect 10-second aggregated flow logs to CloudWatch for anomaly alerts and send 10-minute aggregated flow logs to S3 for Athena-based traffic trend reports. Use lifecycle rules to move 12-month-old logs to Glacier.
Common Mistake

Publishing extremely high-resolution flow logs everywhere without cost analysis creates unexpected CloudWatch and S3 costs.
