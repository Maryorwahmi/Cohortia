Module 8 › Chapter 7.8 › AWS Config
What Config provides
Continuous resource configuration recording, managed and custom rules, compliance reporting, and EventBridge integration for automation.
Managed rules to consider: vpc-flow-logs-enabled, restricted-ssh, restricted-common-ports, s3-bucket-logging-enabled.
CLI Example
aws configservice put-config-rule \
    --config-rule-name restricted-ssh \
    --description "Checks whether security groups that are in use disallow unrestricted incoming SSH traffic." \
    --source Identifier=RESTRICTED_SSH,Owner=AWS \
    --input-parameters '{"allowedPort":"22"}'
Run with a role that can write Config rules. After enabling, review non-compliant resources in the console.
