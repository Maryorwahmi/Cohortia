Module 8 › Chapter 7.8 › Centralizing Logs
Delivery Process
1
Create logging account
Dedicated account with encrypted S3 buckets and CloudWatch log groups.
2
Grant write-only permissions
Use bucket policies that allow the specific AWS service principal to PutObject only.
3
Configure sources
Enable VPC Flow Logs, CloudTrail multi-region trail, ALB access logs, and Resolver Query logs to the central destinations.
Checks and Controls
  • Verify bucket policies only allow the service principal to write.
  • Enable bucket encryption and object locking if required by policy.
  • Monitor delivery failures and set alerts from CloudWatch.
Concrete Example
Account A VPC Flow Logs → Account Log S3 bucket. Bucket policy allows vpc-flow-logs.amazonaws.com PutObject to a single prefix. CloudWatch Log Group in logging account receives flow log events for immediate queries with Logs Insights.
Key Takeaway

Centralization simplifies search and access control without granting broad cross-account read permissions.
