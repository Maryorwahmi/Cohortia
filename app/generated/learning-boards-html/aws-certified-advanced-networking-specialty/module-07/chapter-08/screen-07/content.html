Module 8 › Chapter 7.8 › Log Type Comparison
ELB Access Logs
Request-level data, useful for web forensics and content troubleshooting. Keep enough history for performance trend analysis.
Resolver Query Logs
DNS query visibility useful for detecting suspicious domains and exfiltration. Often useful for medium-term retention.
Network Firewall Logs
Flow and alert logs for firewall inspection. Critical for detection and tuning of network controls.
Practical guidance
  • Route each log type to central S3 for archival and optionally to CloudWatch for realtime parsing.
  • Define retention per log type based on forensic value and compliance needs.
  • Index only the logs you query often to reduce SIEM ingestion costs.
