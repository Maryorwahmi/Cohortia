Module 8 › Chapter 7.8 › Event-driven Remediation
Architecture Pattern
Config Rule → EventBridge rule → Lambda remediation
Or: Config Rule → EventBridge → SNS → human approval → Lambda
Audit all remediation actions. Keep remediation Lambdas idempotent and test in a non-production environment before enabling automated fixes in production.
Example Scenario
Restricted SSH rule flags security group sg-123. EventBridge invokes Lambda remove-open-ssh which removes 0.0.0.0/0 ingress and emits a CloudTrail event for traceability.
Pro Tip

Start with notification-only workflows, then selectively enable automatic remediation for low-risk changes.
