Module 7 › Chapter 7.1 › Flow Logs: destination choices
Option A

CloudWatch Logs

Use CloudWatch Logs when you need quick analysis and alerts. Metric filters can detect suspicious patterns and drive CloudWatch Alarms.

- Near real-time alerting
- Built-in query and metric filters
- Higher cost for large volumes
Option B

Amazon S3

Publish flow logs to S3 for archival storage and batch forensics. Use lifecycle policies for retention and cost control.

- Cost-effective long-term storage
- Good for compliance and batch analysis
- Requires external tooling for near real-time alerts
Recommended pattern
Stream to both CloudWatch Logs for operational alerts and to S3 for archival. Filter and sample where appropriate to manage costs and focus on critical traffic sources.
