Module 7 › Chapter 7.1 › CloudTrail — audit logs
What CloudTrail records
  • API calls from console, CLI, or SDKs.
  • Who made the call, when, and from which IP.
  • Request parameters and responses that show what changed.
Network examples
- Security group rule changes like adding 0.0.0.0/0 to port 22.
- Route table modifications and VPC peering creation.
- Changes to VPN or Direct Connect configuration.
Best practice
Centralize CloudTrail logs and consider streaming to CloudWatch Logs to create metric filters for API-change detection and automated response playbooks.
