Module 7 › Chapter 7.1 › Troubleshooting Scenario
Guided steps
  1. Check CloudWatch for NetworkIn/NetworkOut, CPU, and HealthyHostCount.
  2. Inspect VPC Flow Logs for source-destination pairs and ACCEPT/REJECT actions.
  3. Search CloudTrail for recent security group, route table, or instance configuration changes.
  4. Correlate timestamps to build a timeline and identify the likely root cause.
  5. Create a remediation plan based on evidence and document the incident.
Scenario example
CloudWatch shows a drop in NetworkIn at 10:12. Flow logs show many rejects from the load balancer IP on port 80 at 10:12. CloudTrail shows a security group change at 10:11 that removed the healthcheck rule. Timeline created: change, rejects, symptom.
Common mistake
Declaring root cause from a single source. Always correlate metrics, flow logs, and CloudTrail events to avoid false conclusions.
