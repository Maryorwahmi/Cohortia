Module 7 › Chapter 7.1 › Tooling Comparison
CloudWatch
Numeric metrics and alarms. Use to detect timing and magnitude of network events and trigger automated responses.
VPC Flow Logs
Connection-level records. Use to verify which IPs and ports were involved and whether traffic was accepted or rejected.
CloudTrail
API audit trail. Use to trace configuration changes like security group edits or route updates that might explain network behavior.
Example workflow
1) CloudWatch shows NetworkOut spike. 2) Flow Logs confirm destination peers and whether traffic was allowed. 3) CloudTrail reveals a recent security group change. Correlate timestamps across all three sources for root cause.
