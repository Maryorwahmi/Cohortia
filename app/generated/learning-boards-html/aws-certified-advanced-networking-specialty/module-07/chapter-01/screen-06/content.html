Module 7 › Chapter 7.1 › Create alarm & SNS
Step-by-step
  1. Create an SNS topic and add a subscription for notifications.
  2. Choose the CloudWatch metric (NetworkOut) and select instance dimension.
  3. Pick statistic and period (Sum, 5 minutes) and set threshold.
  4. Attach alarm-actions to the SNS topic and name the alarm.
  5. Test by generating outbound traffic and verify notification arrives.
CLI example (visual only)
# Create SNS topic
aws sns create-topic --name NetworkPerformanceAlerts

# Use the TopicArn in a put-metric-alarm call
aws cloudwatch put-metric-alarm \
  --alarm-name "HighNetworkOutAlarm" \
  --alarm-description "Alarm when EC2 NetworkOut exceeds 50 MB/second for 5 minutes" \
  --metric-name NetworkOut \
  --namespace AWS/EC2 \
  --statistic Sum \
  --period 300 \
  --threshold 52428800 \
  --comparison-operator GreaterThanThreshold \
  --dimensions Name=InstanceId,Value=i-0abcdef1234567890 \
  --evaluation-periods 1 \
  --alarm-actions arn:aws:sns:us-east-1:123456789012:NetworkPerformanceAlerts \
  --unit Bytes
The code block shows the required parameters. Replace the instance ID and TopicArn for your environment.
