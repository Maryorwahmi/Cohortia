Practice & Interpretation

Run analyses, read explanations, and map to remediation
Hands-on focus
Run a Reachability path
Use ENI IDs or IPs, specify protocol and port, and read the 'Explanation' to find the blocker.
Define an access scope
Create scopes like 'no internet to prod DB subnet' to have the analyzer flag violating paths.
Map output to remediation
Translate the identified blocking component into a concrete change: SG rule added, route fixed, or NACL adjusted.
Remember: these are static configuration analyses, not a substitute for tracing live packets when needed.
