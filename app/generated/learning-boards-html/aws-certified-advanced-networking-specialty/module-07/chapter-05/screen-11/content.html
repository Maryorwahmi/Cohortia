Module 7 › Chapter 7.5 › Lab: Ping Failure
Lab steps
Setup
Two EC2 instances in same VPC, different subnets. Ensure initial security group rules permit ICMP between them.
Induce failure
Remove the inbound ICMP rule on the destination's security group and confirm ping fails from the source.
Analyze
Create a Reachability Analyzer path: select ENIs, protocol ICMP, run analysis, and read the Explanation to find the denying SG.
Remediate & Verify
Restore the SG rule, rerun Reachability Analyzer, confirm Reachable: Yes, and verify ping succeeds.
Note: follow IAM least privilege—run analyses with a principal that has only the necessary Describe and Create permissions.
