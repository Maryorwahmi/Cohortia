Module 7 › Chapter 7.5 › Analyzer Comparison
Side-by-side
Network Access Analyzer
  • Scope-based auditing across many resources.
  • Finds potential paths and latent exposures.
  • Useful for compliance and periodic checks.
Reachability Analyzer
  • Point-to-point path analysis with hop details.
  • Identifies the exact component blocking traffic.
  • Ideal for targeted incident response and debugging.
Workflow example: run a Network Access Analyzer scope to detect exposures. If a specific source-destination pair cannot communicate, run Reachability Analyzer to get the exact blocking hop and remediate accordingly.
Common Mistake

Treating these tools as substitutes for flow logs. Use them together: analyzers for config, flow logs for observed traffic.
