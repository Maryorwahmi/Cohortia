Learning Objectives

Learn, Understand, Apply, Master
Bloom: Learn → Understand → Apply → Master
01
Audit with Network Access Analyzer
Define an access scope and run an analysis to find any network paths that violate your security policy. This matters for proactive compliance checks across security groups, NACLs, and routes.
VERIFIED COMPETENCY MILESTONE
02
Diagnose with Reachability Analyzer
Create a source-destination path with protocol and port to get a hop-by-hop trace that identifies the exact component blocking traffic.
VERIFIED COMPETENCY MILESTONE
03
Interpret analysis output
Translate the 'Explanation' into precise remediation: add a route, adjust a security group, or update a NACL entry as required.
VERIFIED COMPETENCY MILESTONE
04
Understand limitations and permissions
Recognize that both tools are static analyses and ensure correct IAM permissions. Also watch analysis cost when automating checks.
VERIFIED COMPETENCY MILESTONE
