Module 7 › Chapter 7.5 › Access Scope
Process
Follow a short process to get meaningful results from Network Access Analyzer: choose origin, choose destination, optionally add intermediates or protocol constraints, run the analysis, then refine the scope if output is noisy.
Step 1: Origin
Pick exactly where traffic starts: an IP range, VPC, or the internet.
Step 2: Destination
Select targeted resources like a subnet or ENIs for focused auditing.
Step 3: Intermediates
Optionally lock in components such as Transit Gateway or peering to limit paths considered.
Example
Origin = 0.0.0.0/0, Destination = production-db-subnet. Run analysis. If paths appear, inspect the listed route entries and security groups to see how exposure occurs.
Refinement
If you get too many paths, restrict by protocol, add an intermediate, or narrow the IP range to eliminate noise.
