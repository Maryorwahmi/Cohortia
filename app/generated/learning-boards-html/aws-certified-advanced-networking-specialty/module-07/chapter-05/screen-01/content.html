Advanced Troubleshooting

Network Access Analyzer • Reachability Analyzer
Interactive 16:9 Masterclass

This chapter teaches two complementary AWS tools. Network Access Analyzer finds unintended potential paths by evaluating configuration state against a defined scope. Reachability Analyzer traces a specific path between a source and destination to confirm connectivity and locate the blocking component. Both are static, configuration-based analyses that reduce manual checks.

You will learn how to define scopes, run point-to-point analyses, interpret the explanation output, and apply findings to remediate misconfigurations in multi-VPC, Transit Gateway, and hybrid environments.
