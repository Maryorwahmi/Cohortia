Module 7 › Chapter 7.5 › Network Access Analyzer
Purpose
Network Access Analyzer helps you define and prove security constraints by evaluating configuration state. It reports any potential network paths that match your scope so you can remediate unintended access before it becomes an incident.
Access Scope
A declarative origin and destination with optional intermediate components used to filter and find relevant paths.
Analysis output
A list of matching paths and the components that form them so you can identify exposures or confirm compliance.
Key Takeaway

Use Network Access Analyzer to proactively verify that your configuration does not permit disallowed paths.

Concrete example
Define a scope: origin = internet (0.0.0.0/0), destination = production DB subnet. Run analysis. If the analyzer returns a path, it will show the route plus a security group allowing inbound traffic, or a NAT/IGW combo that enables the path. That single report points to precise remediation.
Misconception check
This is not a live traffic monitor. If no traffic has occurred, Network Access Analyzer can still find a path that would allow traffic if attempted.
