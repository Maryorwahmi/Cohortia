Module 7 › Chapter 7.5 › Key Concepts
Network Access Analyzer
Scope-based audits that find potential unintended network paths across configuration components.
Reachability Analyzer
Point-to-point path analysis with detailed hop explanations and denial reasons.
Static Analysis
Both tools analyze current configuration state, not live packets. Rerun after changes to validate new state.
Summary takeaway

Use Network Access Analyzer for policy audits and Reachability Analyzer for targeted debugging, and combine both with logs and least-privilege IAM.
