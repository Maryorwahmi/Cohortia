Learning Objectives — Expanded
Interpretation in practice
  • Use NetworkIn/Out to detect large transfers or traffic surges.
  • Watch PacketsPerSecond on large instances to avoid PPS limits.
  • Learn to read units: bytes vs. bits vs. packets.
VERIFIED COMPETENCY MILESTONE
Custom metrics in production
  • Publish meaningful dimensions (for example, ServiceEndpoint) for segmentation.
  • Limit frequency to control cost and noise.
VERIFIED COMPETENCY MILESTONE
Dashboards and alarms
Choose statistics like Sum, Maximum and not only Average so you don’t hide short spikes. Tune periods to match the expected cadence of the metric.
VERIFIED COMPETENCY MILESTONE
Diagnosis and correlation
Always correlate network metrics with CPU, disk I/O and application logs to identify root cause instead of treating a symptom.
