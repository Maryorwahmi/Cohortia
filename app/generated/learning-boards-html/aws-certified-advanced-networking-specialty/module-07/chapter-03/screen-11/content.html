Module 7 › Chapter 7.3 › Diagnosing Bottlenecks
Correlation checklist
  • Identify user-visible symptom (latency, errors).
  • Match timestamps across ELB, EC2, VPN and Direct Connect metrics.
  • Check application logs and instance CPU/disk for correlated anomalies.
  • Use Maximum and Sum statistics to uncover spikes.
Example
ELB Latency and EC2 NetworkOut spike together while CPU is low — points to network saturation or external calls, not compute exhaustion.
Avoid these mistakes
Do not rely solely on instance NetworkIn/Out to judge link health; check Direct Connect and BGPState for routing issues. Don’t trust averages when bursts matter.
Key Takeaway

Diagnose by correlation: overlay metrics from each layer and include logs to distinguish network path issues from application problems.
