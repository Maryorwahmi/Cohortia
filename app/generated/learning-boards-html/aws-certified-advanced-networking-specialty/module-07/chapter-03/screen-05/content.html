Module 7 › Chapter 7.3 › Interpreting EC2 Metrics
Process for meaningful metrics
Observe → Baseline → Detect → Correlate
Observe
Collect representative data over time to map normal patterns.
Baseline
Define expected ranges and peak windows for each metric.
Detect
Choose statistics and periods that expose spikes and sustained issues.
Correlate
Combine network metrics with CPU, ELB latency and logs to find root cause.
Misconception
HealthyHostCount being stable does not guarantee low latency; slow processing on healthy targets will still raise latency metrics.
Practical tip
Use Maximum and Sum alongside Average and set alarms to fire only when multiple statistics show deviation.
