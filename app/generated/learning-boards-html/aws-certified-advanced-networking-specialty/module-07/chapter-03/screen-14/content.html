Latency
Measure of delay; often indicates target processing or network congestion.
TunnelState / ConnectionState
Binary indicators for VPN and Direct Connect availability; alarm on DOWN.
PutMetricData API
Use this API to send custom metrics; include dimensions for segmentation and control frequency for cost.
Takeaway

Use these quick references during incidents to focus investigation and design monitoring that is secure and cost-aware.
