Module 7 › Chapter 7.3 › VPN Connection Metrics
Core VPN Metrics
Treat TunnelState as critical. Use data counters for capacity planning.
TunnelState
Binary UP/DOWN. Configure immediate alarms on DOWN.
TunnelDataIn/Out
Volume flowing through the tunnel for traffic analysis and capacity planning.
VPNConnectionState
Overall connection status composed of two tunnels; use to detect degraded redundancy.
Scenario
If TunnelState flips frequently, inspect ISP and on-premise VPN devices; if TunnelData spikes, check backups or large transfers.
Why this matters

VPN state changes can cause immediate traffic interruptions. Treat the binary states as high-priority alerts and use data metrics for planning.
