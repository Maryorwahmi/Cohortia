Module 7 › Chapter 7.3 › Hands-on: Publish & Visualize
Step-by-step Activity
Practice publishing MicroserviceLatency and adding it to a dashboard.
Step 1 — Publish
Send latency values with ServiceEndpoint dimension at controlled intervals.
Step 2 — Dashboard
Create or edit dashboard, add a line widget, choose your namespace and metric.
Step 3 — Alert
Set an alarm using period and statistic that reflect your baseline to avoid noise.
Key Takeaway

Walk the full loop: instrument the application, publish metrics securely, visualize them meaningfully, and set tuned alarms to act on deviations.
