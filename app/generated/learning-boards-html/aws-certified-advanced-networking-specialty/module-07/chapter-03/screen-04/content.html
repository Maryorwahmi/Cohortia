Module 7 › Chapter 7.3 › EC2 Instance Network Metrics
Definition
NetworkIn/NetworkOut measure bytes. PacketsIn/PacketsOut measure packet counts. PPS is packets-per-second.
When to watch
Sustained high volume, sudden drops, or unusual patterns require investigation.
Practical example
NetworkIn doubles overnight — check application logs and rule out bulk backups or DDoS before scaling.
Common mistake
Relying only on averages hides short spikes. Inspect Maximum and Sum statistics as well.
Metrics at a glance
NetworkIn
Bytes received on all interfaces. Use Sum or Maximum to detect bursts.
NetworkOut
Bytes sent. Sudden drops can indicate outbound failures.
PacketsIn/PacketsOut
Packet counts — useful for PPS limits.
PPS
Watch for packet-processing saturation on high-traffic instances.
Key Takeaway

Use byte and packet counters together. Check statistics beyond averages and correlate with CPU and logs to find root cause.
