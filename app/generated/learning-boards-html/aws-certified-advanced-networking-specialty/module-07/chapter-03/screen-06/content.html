ELB Metric Comparison
Use these metrics together to separate network problems from backend slowness.
Latency
Time between LB forwarding and target response. High latency = congestion or slow app.
HealthyHostCount
Number of healthy targets. Drops point to backend failures rather than network alone.
TargetConnectionErrorCount
Failed connections to targets. Indicates security groups, NACLs, or connectivity problems.
HTTPCode_Target_5XX_Count
Backend 5xx errors — confirms target-originated failures affecting perceived network performance.
Scenario
If Latency rises and HealthyHostCount is steady, targets respond but slowly — investigate application processing or network path between LB and targets. If TargetConnectionErrorCount rises, check security groups and NACLs first.
Pro tip
ConsumedLCUs help understand scaling and cost — watch LCUs when traffic patterns change rapidly.
Key Takeaway

Combine latency, connection errors and healthy host counts to pinpoint whether the issue is network path or backend processing.
