Analyzing Network Performance with CloudWatch
Measure, visualize, and respond to network behavior for EC2, ELB, VPN, and Direct Connect.
CloudWatch centralizes network metrics so you can detect traffic surges, tunnel outages, or Direct Connect errors quickly. You’ll learn which metrics indicate volume, which show health, and how to publish custom application metrics to fill monitoring gaps.
