Key Direct Connect Metrics
Link health and utilization are distinct; monitor both.
ConnectionState
UP or DOWN — primary link health metric.
ConnectionBpsEgress / Ingress
Bits per second on the AWS side — use for utilization and headroom planning.
ConnectionErrorCount
Counts errors at the physical or port layer — early indicator of hardware problems.
BGPState
Virtual interface routing health — a down BGP session disrupts routing even when the link is up.
Investigation steps
  1. Check ConnectionState; if DOWN, escalate to provider and check physical cabling.
  2. If ConnectionState is UP but traffic is missing, check BGPState to validate route exchange.
  3. Review ConnectionErrorCount for recurring physical errors or flaps.
Key Takeaway

Direct Connect requires watching both link health and routing state to maintain stable hybrid connectivity and avoid routing blackholes.
