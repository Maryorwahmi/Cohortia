Module 7 › Chapter 7.3 › Publishing Custom Metrics
CLI example
Publish a single custom metric datapoint with a dimension for endpoint segmentation.
aws cloudwatch put-metric-data \
    --namespace "MyApplication/Network" \
    --metric-name "ExternalAPILatency" \
    --value 150 \
    --timestamp 2023-10-27T10:00:00Z \
    --dimensions Name=APIEndpoint,Value=payments.example.com
Security note
Grant only cloudwatch:PutMetricData to the IAM principal that publishes metrics.
Cost note
Custom metrics incur costs; limit cardinality and publish at reasonable intervals.
After publish
Add metric to a dashboard and choose statistic and period to make the data actionable.
