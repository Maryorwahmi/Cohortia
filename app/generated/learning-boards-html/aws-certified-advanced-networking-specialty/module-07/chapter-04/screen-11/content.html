Module 7 › Chapter 7.4 › Common Mistakes
Mistakes and mitigations
  • Missing integrity validation — enable cryptographic log validation.
  • Insufficient retention — implement S3 lifecycle policies aligned to compliance.
  • Single-region trails — use multi-region to capture global service events.
  • Over-forwarding data events — limit CloudWatch ingestion to necessary events.
  • Loose metric filters — inspect nested parameters to avoid false alarms.
Pro-tip
Keep a small test trail for validating filters and alarms before applying them to production trails.

Warning
