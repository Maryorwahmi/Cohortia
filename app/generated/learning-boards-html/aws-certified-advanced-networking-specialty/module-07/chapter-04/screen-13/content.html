Test steps
  1. Create the filter in the CloudWatch Logs console for your CloudTrail log group.
  2. Create an alarm on the emitted metric PublicHTTPAccessCount with threshold > 0.
  3. Add an HTTP inbound rule (0.0.0.0/0) to a test security group.
  4. Confirm SNS notification and then remove the test rule.
Safety notes
Perform tests in a non-production account or VPC. Clean up test rules immediately to avoid accidental exposure.
Why this matters
Testing confirms detection works end-to-end and that your team will be notified when real exposures occur.
