Management Events (Network-focused)
  • CreateSecurityGroup
  • AuthorizeSecurityGroupIngress / RevokeSecurityGroupEgress
  • CreateRoute / ReplaceRouteTableAssociation
  • DeleteNetworkAclEntry / DeleteVpc
Data Events
Capture object-level or function-level activity such as S3 object API calls or Lambda invocations; useful for access auditing but not primary for network configuration.
Practical check

When auditing a change to a route table or security group, search management events first; these contain the API call, parameters, and invoking principal.

Misconception
Turning on only data events will not give you the configuration timeline auditors expect. Ensure management events are enabled and routed to your monitoring tools.
