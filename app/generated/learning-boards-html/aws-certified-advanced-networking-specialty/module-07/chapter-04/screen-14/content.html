Module 7 › Chapter 7.4 › Key Concepts
AWS CloudTrail
Records API calls and events as an auditable trail for network changes.
Management Events
Capture create/modify/delete operations that alter network configuration.
CloudWatch Integration
Forward events to CloudWatch Logs, create metric filters, and alarm via SNS for real-time detection.
Bottom line

A secure, multi-region CloudTrail trail plus CloudWatch metric filters forms the backbone of network configuration monitoring and compliance evidence.
