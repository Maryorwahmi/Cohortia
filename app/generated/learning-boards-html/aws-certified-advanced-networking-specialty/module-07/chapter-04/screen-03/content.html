Module 7 › Chapter 7.4 › Learning Objectives
From event to alert
Define metric filters that match specific API calls and parameter values, then trigger alarms to notify response teams.
Secure storage
Use S3 with restrictive policies and log file integrity validation to preserve admissible evidence for audits.
Test and validate
Simulate a forbidden change and confirm the CloudWatch alarm and SNS notification workflow works end-to-end.
Mnemonic
CAP: Capture → Analyze → Protect. Capture events, analyze with metric filters, protect via alarms.
Success check
You receive an SNS message within minutes of a simulated risky change.
