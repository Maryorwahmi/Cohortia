Module 7 › Chapter 7.4 › Create CloudWatch Alarm
CLI example (visual)
aws cloudwatch put-metric-alarm \
    --alarm-name "PublicSSHSecurityGroupAlarm" \
    --alarm-description "Alerts on security group rule allowing SSH from 0.0.0.0/0" \
    --metric-name UnauthorizedSSHAccessCount \
    --namespace NetworkSecurity \
    --statistic Sum \
    --period 300 \
    --threshold 0 \
    --comparison-operator GreaterThanThreshold \
    --evaluation-periods 1 \
    --alarm-actions arn:aws:sns:us-east-1:123456789012:topic/NetworkSecurityAlertsTopic \
    --treat-missing-data notBreaching
Operational test
Run a controlled security group change and confirm the SNS topic sends the notification to all subscribers.
Permissions checklist
  • CloudWatch can publish to the SNS topic.
  • SNS subscriptions are confirmed and monitored.
  • Resources are in the same region or cross-region permissions are configured.
Pitfall
Alarms without confirmed SNS subscribers or correct permissions produce silent failures. Test delivery paths regularly.
