Module 7 › Chapter 7.4 › Critical Events
High-impact events
  • DeleteVpc, DeleteSubnet — destructive topology changes.
  • ReplaceRouteTableAssociation, AssociateRouteTable — routing changes.
  • DeleteNetworkAclEntry, ReplaceNetworkAclEntry — subnet access changes.
Operational tip
Map each event to remediation playbooks so alerts lead to the right response path quickly.
Categorize and alert
Use immediate alarms for destructive/exposure events and aggregated metrics for frequent, low-impact changes to reduce noise.
Common mistake
Treating all events uniformly leads to alert fatigue. Prioritize by potential impact.
