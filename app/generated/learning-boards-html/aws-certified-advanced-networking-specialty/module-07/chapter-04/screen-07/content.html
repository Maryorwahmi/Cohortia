Module 7 › Chapter 7.4 › Forward to CloudWatch Logs
What to send
Send management events for real-time detection. Consider filtering data events to limit volume.
Operational notes
  • Name log groups clearly, e.g., CloudTrail/DefaultLogGroup.
  • Set retention and monitor ingestion costs.
  • Test filters with sample events before production use.
Example filter purpose
Detect security group changes that open SSH or HTTP to the internet. The filter should match the eventName and the requestParameters.ipPermissions fields.
Key takeaway

CloudWatch Logs integration converts audit events into signals you can monitor and alert on in real time.
