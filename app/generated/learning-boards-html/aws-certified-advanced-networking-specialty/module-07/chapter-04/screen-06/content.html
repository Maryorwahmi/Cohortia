Module 7 › Chapter 7.4 › Configure a Trail
Step-by-step
  1. Create trail and select multi-region logging.
  2. Set S3 bucket destination with encryption and strict policies.
  3. Enable log file integrity validation.
  4. Optionally integrate CloudWatch Logs and select a log group.
  5. Set retention lifecycle rules on S3.
Why integrity validation

It provides cryptographic proof that logs were not modified after delivery — essential for forensics and compliance.

Example bucket policy notes
Use ACL-free buckets, enforce server-side encryption, restrict PutObject and DeleteObject to the CloudTrail service principal and your audit role, and enable S3 versioning to prevent silent deletion.
Key takeaway

A properly configured trail centralizes events and creates verifiable logs you can trust during an incident or audit.
