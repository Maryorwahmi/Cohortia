Module 7 › Chapter 7.7 › Hands-on: NetworkEventLogger
Starter Lambda code
import json

def lambda_handler(event, context):
  print(f"Received network event: {json.dumps(event, indent=2)}")
  return {'statusCode':200,'body':json.dumps('Event logged successfully!')}
Deploy this as the NetworkEventLogger and give it basic CloudWatch Logs permissions. Do not run against production resources during tests.
EventBridge rule steps
  1. Create rule: AWS service > CloudTrail > AWS API Call via CloudTrail.
  2. Specific operation: DeleteRouteTable.
  3. Target: NetworkEventLogger Lambda.
  4. Test: Delete a non-critical route table and confirm logs in CloudWatch.
Key Takeaway

This exercise proves the end-to-end event flow while keeping changes minimal and auditable.
