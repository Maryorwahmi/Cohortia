Common sources
  • CloudTrail: API calls for configuration changes.
  • CloudWatch Alarms: metric breaches that indicate performance or traffic changes.
  • Custom applications or SaaS partners publishing structured events.
Pattern tip
Match nested fields when needed. For CloudTrail, check requestParameters and nested ipPermissions to avoid over-triggering.
Validation checklist
Before enabling remediation, run these steps:
  1. Collect sample events from CloudTrail or CloudWatch.
  2. Test your event pattern on samples to ensure correct matches.
  3. Route events to SNS to review payload volume and contents.
  4. Only then add a Lambda remediation target and monitor logs closely.
Common-mistake

Matching too broadly or not validating payload structure is the top cause of false positives in automation.
