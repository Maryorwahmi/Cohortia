Example Lambda (simplified)
import json
import boto3

ec2 = boto3.client('ec2')
sns = boto3.client('sns')
NOTIFICATION_TOPIC_ARN = 'arn:aws:sns:us-east-1:123456789012:NetworkSecurityAlertsTopic'

def lambda_handler(event, context):
  print(f"Received event: {json.dumps(event)}")
  try:
    detail = event['detail']
    if detail.get('eventName') == 'AuthorizeSecurityGroupIngress':
      group_id = detail['requestParameters']['groupId']
      ip_permissions = detail['requestParameters']['ipPermissions']['items']
      for perm in ip_permissions:
        if perm.get('fromPort') == 22 and perm.get('toPort') == 22 and 'ipRanges' in perm:
          for ipr in perm['ipRanges']['items']:
            if ipr.get('cidrIp') == '0.0.0.0/0':
              ec2.revoke_security_group_ingress(GroupId=group_id, IpPermissions=[perm])
              sns.publish(TopicArn=NOTIFICATION_TOPIC_ARN, Message='Revoked public SSH')
              return {'statusCode':200,'body':json.dumps('Rule revoked')}
    return {'statusCode':200,'body':json.dumps('No action')}
  except Exception as e:
    sns.publish(TopicArn=NOTIFICATION_TOPIC_ARN, Message=f'Error: {str(e)}')
    return {'statusCode':500,'body':json.dumps(str(e))}
Explanation & constraints
  • Extract detail, inspect nested requestParameters and ipPermissions precisely.
  • Revoke using the specific IpPermissions structure to match API expectations.
  • Publish SNS alerts and log full event for audit trails.
  • Ensure the execution role has minimal necessary permissions.
Misconception

Do not grant ec2:*; scoped permissions reduce blast radius if the Lambda is compromised.
