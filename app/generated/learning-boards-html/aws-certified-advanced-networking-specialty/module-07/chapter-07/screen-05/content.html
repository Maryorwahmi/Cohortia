Module 7 › Chapter 7.7 › EventBridge Basics
What EventBridge does
Receives events, evaluates rules, and forwards matching events to targets for action or processing.
Sources
AWS services like CloudTrail, CloudWatch, EC2 events, VPC flow derived events, custom events, and SaaS partners.
Targets
Lambda, SNS, Step Functions, SQS — choose based on action type and reliability needs.
Event patterns
JSON structures that match specific fields in events. Narrow fields to reduce noise.
Practical guidance
  • Test your event pattern using sample CloudTrail events before enabling remediation.
  • Deliver to SNS first to observe frequency and payloads.
  • Expect possible duplicate delivery; code for idempotency.
  • Use many matched fields to avoid broad matches that trigger on unrelated activity.
Key Takeaway

EventBridge is the router; make patterns precise and validate events before adding remediation targets.
