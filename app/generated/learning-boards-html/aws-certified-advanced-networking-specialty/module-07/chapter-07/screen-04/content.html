Module 7 › Chapter 7.7 › Why automate?
What it is
Detect network events and run programmatic actions that remediate or notify, creating fast and auditable responses.
Concrete example
CloudTrail logs an AuthorizeSecurityGroupIngress that opens SSH to 0.0.0.0/0; an EventBridge rule triggers a Lambda to revoke that rule and publish an SNS alert.
Common misconception
Automation replaces humans entirely. Start with notification and dry-run, and only enable remediation after validation.
Key Takeaway

Automation reduces time to remediate and enforces consistent, auditable actions when designed with safety controls.

Scenario walkthrough
A security guardrail: revoke public SSH on detection.
Sequence
  1. CloudTrail records API call AuthorizeSecurityGroupIngress.
  2. EventBridge rule with a CloudTrail pattern matches the event.
  3. EventBridge routes the event to a Lambda target.
  4. Lambda revokes the ingress and notifies an SNS topic.
