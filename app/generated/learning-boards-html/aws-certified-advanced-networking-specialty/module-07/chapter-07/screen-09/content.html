Module 7 › Chapter 7.7 › IAM Comparison
Broad permissions
Example: ec2:* on Lambda role. Pros: simple. Cons: large blast radius if compromised.
Scoped permissions
Example: ec2:RevokeSecurityGroupIngress on specific security group ARNs and sns:Publish. Pros: smaller blast radius. Cons: requires careful testing.
Best practices
  • Start with the minimal permissions and add only what tests show missing.
  • Use condition keys and resource ARNs to narrow access.
  • Audit roles and rotate access when ownership or logic changes.
Warning

Overly broad IAM is a common cause of serious security incidents; plan and review policies carefully.
