Module 7 › Chapter 7.7 › Lambda Architecture
Design checklist
  • Least-privilege IAM role scoped to required API calls.
  • Idempotent operations and safe checks before applying changes.
  • Structured logging of original event and actions.
  • Notification to SNS on critical actions or failures.
Pattern examples
Simple remediation: Lambda revokes SG rule, logs, and publishes SNS.
Orchestration: Step Functions handle multi-step network repair with retries.
Human-in-loop: Events go to SNS for approval before Lambda acts.
Key Takeaway

Choose the execution model that matches risk: notifications, dry-run, manual approval, or full automation with safeguards.
