LOA-CFA: permission and instruction
Contains port ID, patch panel, cable type and expiration — everything a facility needs to provision the cross-connect.
Port ID
Identifies the specific AWS port the provider must connect to.
Patch panel / rack
Shows where the fiber terminates on both sides.
Cable type
Specifies the required fiber or copper type and connector form factor.
Expiration
The LOA-CFA is time-limited; sending an expired LOA-CFA prevents provisioning.
Quick guidance
Always validate port and patch IDs against the console before release.
Confirm the LOA-CFA expiry and re-generate if necessary.
Include the LOA-CFA PDF in your provider packet to avoid delays.
