A layered troubleshooting checklist
Separate checks by physical, data link and network layers to find root causes efficiently.
Layer 1 — Physical
Link light, correct port ID, and correct patch panel per LOA-CFA.
Layer 2 — VLAN
Confirm subinterface tagging and VLAN ID match the VIF configuration.
Layer 3 — BGP
Verify ASN values, peer IPs, authentication keys, and route advertisements.
Common failures
  • Expired LOA-CFA preventing provisioning.
  • Transcription errors in port or patch IDs.
  • Mismatched VLAN or wrong ASN on the router.
Remember

A healthy physical layer with incorrect logical settings will still fail; always validate both sides.
