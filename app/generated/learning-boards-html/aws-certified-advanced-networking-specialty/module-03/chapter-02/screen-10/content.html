Module 3 › Chapter 3.2 › VGW vs TGW
Choose the right AWS endpoint
VGW attaches to a single VPC; TGW provides a hub for many VPCs and on-premises connections.
Virtual Private Gateway (VGW)
Good for single-VPC direct attachments and simpler routing models.
Transit Gateway (TGW)
Use when you need centralized routing among many VPCs and on-prem networks.
Scenario
If three VPCs need shared access to on-premises services, attach them to a Transit Gateway and use a private VIF to the TGW. If a single VPC requires direct connectivity, a VGW may suffice.
Key Takeaway

Match private VIF endpoints to your scaling needs: VGW for simple setups, TGW for hub-and-spoke scale.
