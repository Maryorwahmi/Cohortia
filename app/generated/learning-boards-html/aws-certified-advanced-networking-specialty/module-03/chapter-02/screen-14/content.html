Module 3 › Chapter 3.2 › Key Concepts
Direct Connect Location
The physical facility housing AWS routers where cross-connects terminate.
LOA-CFA
Authorization document with port ID, patch and cable details required by the facility.
VIFs & BGP
Logical interfaces using VLANs and BGP to carry routes to AWS endpoints.
Summary takeaway
Treat the Direct Connect setup as paired physical and logical tasks: secure proper authorization and cabling, then mirror those details in your VIF and BGP configuration to enable route exchange.
