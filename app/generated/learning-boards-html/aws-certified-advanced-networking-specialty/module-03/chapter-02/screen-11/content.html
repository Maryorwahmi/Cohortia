Module 3 › Chapter 3.2 › On-Prem Router Checklist
Essential router parameters
Follow this checklist to avoid common cutover failures.
VLAN ID and subinterface
Match the VLAN assigned to the VIF exactly on your subinterface.
Peer IPs and ASNs
Configure neighbor with the AWS peer IP and remote-as value provided by AWS.
BGP authentication
If AWS provides a BGP auth key, set the same password on the neighbor definition.
Verification steps
  1. Confirm physical link and VLAN tagging.
  2. Check neighbor IPs and ASN match AWS VIF details.
  3. Validate BGP adjacency and route exchange.
Pro Tip

Document the exact console-provided values and paste them into your router config to avoid manual transcription errors.
