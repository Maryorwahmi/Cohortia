Module 3 › Chapter 3.2 › Virtual Interfaces (VIFs)
What VIFs do
Logical interfaces that run over a physical Direct Connect port and separate traffic types.
Types of VIFs
Private VIFs for VPCs, public VIFs for AWS public services, and transit VIFs for TGW connectivity.
VLAN and BGP requirements
Each VIF uses a VLAN and requires a BGP peering session with the AWS router.
Capacity note
Multiple VIFs share the physical port’s bandwidth; plan VIF capacity against port speed.
Concrete example
Create a private VIF for VPC routing and a public VIF for S3 access. Assign distinct VLANs and configure BGP peerings so routes do not mix.
Key Takeaway

VIFs provide logical separation; ensure VLAN and BGP parameters match the AWS-provided configuration.
