Module 3 › Chapter 3.4 › Public VIFs
How Public VIFs work
They allow your on-premises network to reach AWS public endpoints over Direct Connect and advertise public prefixes to AWS.
Benefits
Lower latency and more predictable performance to public AWS services compared to the internet.
Security considerations
  • Implement strict firewall rules on on-premises routers.
  • Advertise only the public prefixes you own and need.
  • Monitor BGP advertisements and filter unexpected routes.
Common mistake

Failing to filter outbound traffic on the on-prem router can allow unnecessary access to the entire AWS public IP space.

Concrete scenario
You want to access S3 directly from your data center. A Public VIF will route S3 traffic over DX, but you must restrict traffic so that only S3 destination prefixes are reachable and only allowed application source ranges can use the VIF.
Key Takeaway

Public VIFs improve performance to public services but require strict on-premises controls to avoid accidental exposure to the AWS public IP space.
