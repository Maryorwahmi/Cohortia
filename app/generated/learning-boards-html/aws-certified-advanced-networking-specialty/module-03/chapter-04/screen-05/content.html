Private VIF details
Connects on-prem to a VPC via a VGW using BGP for dynamic routing.
Required parameters
  • connection-id: your physical DX link
  • vlan: unique VLAN ID for this VIF
  • asn: your on-prem ASN
  • amazonAddress/customerAddress: /30 BGP peering addresses
  • virtualGatewayId: VGW attached to the target VPC
Concrete example
Typical values are vlan=100, asn=65000, and a /30 like 169.254.10.1/30 and 169.254.10.2/30 for BGP peering.
Key Takeaway

A Private VIF gives private IP reachability to one VPC via VGW; validate unique VLANs and non-overlapping CIDRs before enabling routes.

AWS CLI example
aws directconnect create-private-virtual-interface \
    --connection-id dxcon-abcdefgh \
    --new-private-virtual-interface \
        virtualInterfaceName="MyPrivateVIF" \
        vlan="100" \
        asn="65000" \
        authKey="mysecretkey" \
        amazonAddress="169.254.10.1/30" \
        customerAddress="169.254.10.2/30" \
        virtualGatewayId="vgw-1234567890abcdef0" \
        --region us-east-1
Use BGP authentication when required and check the BGP session state after creation. Verify your on-prem router advertises only intended private prefixes.
