Per-VIF security considerations
Match controls to the VIF type to prevent leaks and misrouting.
Private VIF
Risk: overlapping CIDRs. Mitigation: plan unique address spaces and validate before enabling BGP advertisements.
Public VIF
Risk: exposure to broad AWS public IP space. Mitigation: strict on-premise firewall rules and selective advertisement.
Transit VIF
Risk: unintended propagation to many VPCs. Mitigation: careful TGW route table hygiene and association control.
Pro tip

Perform a routing dry-run: check CIDR uniqueness and simulate route advertisements before enabling production traffic.
