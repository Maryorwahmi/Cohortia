Module 3 › Chapter 3.4 › Planning scenario
Task summary
Two VPCs and on-prem S3 access — choose VIF types and list required parameters and security steps.
Decision
Use a Transit VIF to a TGW for VPC-A and VPC-B. Use a Public VIF to reach S3. Only use Private VIFs if a single VPC needs a dedicated private lane.
What to configure
  • Transit VIF: unique VLAN, public ASN, /30 peering, TGW attachment.
  • Public VIF: unique VLAN, BGP session, outbound filters on on-premises router.
  • Address plan: ensure no overlapping CIDRs across on-prem and VPCs.
Concrete diagram guide
Sketch boxes for: on-prem network → physical DX location → DX router. From DX router show two logical lanes: Transit VIF → TGW → VPC-A & VPC-B, and Public VIF → AWS public network → S3.
Key Takeaway

Transit VIF + TGW is the efficient multi-VPC choice; Public VIF is the direct path to S3 but requires on-premises filtering and careful advertisement of public prefixes.
