Module 3 › Chapter 3.4 › Key Concepts
Virtual Interface (VIF)
Logical connection over Direct Connect that combines VLAN, BGP, and AWS target.
Private VIF
Connects to a VGW and a single VPC; uses private IP BGP peering and unique VLAN.
Public VIF
Provides access to AWS public services; secure with on-premise filters and selective advertisements.
Takeaway
Treat each VIF as a full design element: plan VLANs, BGP, and security controls before provisioning.
