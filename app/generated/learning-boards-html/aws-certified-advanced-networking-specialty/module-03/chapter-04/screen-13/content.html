Module 3 › Chapter 3.4 › Deployment checklist
Pre-deployment checklist
Verify each item before creating VIFs.
Addressing
Confirm no overlapping CIDRs between on-prem and VPCs; reserve /30s for each BGP peer.
VLANs & BGP
Unique VLAN per VIF; ASN planned; decide on BGP authKey usage and test adjacency.
Routing & security
Prepare route filters, AS_PATH prepending for failover, and strict firewall rules for Public VIFs.
Key Takeaway

Follow the checklist to minimize downtime and misconfiguration: plan addressing, VLANs, BGP, and security before provisioning VIFs.
