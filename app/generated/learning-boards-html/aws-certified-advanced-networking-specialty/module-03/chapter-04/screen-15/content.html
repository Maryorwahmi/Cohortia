Module 3 › Chapter 3.4 › Key Concepts
Transit VIF
Use for hub-and-spoke architectures via a Transit Gateway to reach many VPCs.
VLAN & BGP
Each VIF needs a unique VLAN and independent BGP peering to keep routing domains separate.
Routing best practices
Filter routes per VIF, advertise only intended prefixes, and use BGP attributes for traffic engineering.
Final takeaway
Plan VLANs, BGP, and route filters as first-class design items for every VIF to ensure secure and predictable hybrid connectivity.
