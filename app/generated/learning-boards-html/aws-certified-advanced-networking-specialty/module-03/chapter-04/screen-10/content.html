Module 3 › Chapter 3.4 › Route advertisement
What to advertise per VIF
Private VIFs: private CIDRs. Public VIFs: public prefixes. Transit VIFs: on-prem CIDRs to TGW.
Private VIF
Advertise private on-prem CIDRs; receive VPC CIDRs from AWS via BGP.
Public VIF
Advertise your public prefixes if applicable; receive AWS public prefixes for routing.
Transit VIF
Advertise on-prem CIDRs to TGW for propagation to associated VPCs.
Traffic engineering
Use AS_PATH prepending and route filters to influence path selection across DX and backup VPNs. Filter at BGP neighbors to avoid unintended route propagation.
Key Takeaway

Control which prefixes travel each VIF and use BGP attributes and filters to manage preference and avoid accidental route leaks.
