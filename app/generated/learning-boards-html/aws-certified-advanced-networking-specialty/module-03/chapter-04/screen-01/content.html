Virtual Interfaces (VIFs)
Logical connections over a physical Direct Connect link, each dedicated to a specific AWS destination.
Segmentation
Multiple VIFs allow traffic separation and tailored routing policies for different destinations.
BGP Control
Each VIF uses a separate BGP session, allowing dynamic route exchange and filtering.
In this lesson
Explore Private, Public, and Transit VIFs, required configuration parameters, routing impacts, and a hands-on planning scenario for two VPCs needing S3 access.
Explore Key Topics
Private VIF
Connects to a VGW and a single VPC using private IPs and a /30 BGP peering.
Public VIF
Access AWS public services over DX; requires careful on-premises filtering.
Transit VIF
Peers with a Transit Gateway to reach many VPCs through a single VIF.
