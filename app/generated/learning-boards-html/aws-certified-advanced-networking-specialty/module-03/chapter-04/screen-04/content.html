Module 3 › Chapter 3.4 › What is a VIF?
VIF concept and purpose
Logical lane plus control plane (BGP) for dedicated reachability.
Core claim
VIF = VLAN + BGP + reachability target; multiple VIFs can share a physical port but maintain separate routing domains.
Bullets
  • Each VIF needs a unique VLAN ID on the physical Direct Connect link.
  • Each VIF establishes its own BGP session using a small /30 peering subnet.
  • VIF types map to specific AWS endpoints — VGW, public services, or TGW.
Concrete example
A Private VIF with VLAN 100, BGP ASN 65000, and a /30 peering connects your on-premises router to a VPC's VGW to advertise private CIDRs.
Key Takeaway

Treat VIFs as full logical connections: VLAN identifier, BGP parameters, and a clear AWS endpoint target. Planning avoids routing and security errors.

Analogy & common mistake
Analogy: highway lanes — each VIF lane leads to a different exit. Mistake: overlapping CIDRs between on-prem and VPC causing route conflicts.
