Module 4 › Chapter 3.7 › Incident Checklist
Step-by-step
  1. Record alarm details and timestamps.
  2. Check ConnectionState and BGPState in CloudWatch.
  3. If link down: gather LOA-CFA, light levels, contact colo.
  4. If link up & BGP down: verify VLAN, interface IP, ASN, auth key.
  5. Validate route propagation and overlapping CIDRs.
  6. Escalate to AWS with connection ID and captured outputs if suspected AWS-side issue.
Pro Tip
Attach the CloudWatch metric snapshot and router outputs to any support ticket to avoid back-and-forth requests for basic data.
Key Takeaway

A short runbook with clear owner handoffs reduces downtime and prevents duplicated effort in incidents.
