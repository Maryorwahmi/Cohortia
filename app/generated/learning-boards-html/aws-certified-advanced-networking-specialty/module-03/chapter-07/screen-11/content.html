Module 4 › Chapter 3.7 › Terminal Demo
Simulated Steps
  1. Check CloudWatch: ConnectionState = up, BGPState = down.
  2. Run show ip interface brief to validate interface and IP.
  3. Run show vlan brief to confirm VLAN assignment.
  4. Compare VLAN to AWS VIF configuration; correct mismatch.
Example Outputs
# show ip interface brief
GigabitEthernet0/1  up   up  10.0.0.1/30

# show vlan brief
VLAN  Name    Status    Ports
100   Direct  active    Gi0/1
If AWS VIF is VLAN 101 but local port is VLAN 100, the VLAN mismatch prevents the VIF from receiving frames despite an active physical link.
