Module 4 › Chapter 3.7 › Router Diagnostics
Essential Commands
  • show ip interface brief — verify interface IPs and up/down state.
  • show vlan brief — confirm VLAN assignment matches VIF.
  • show ip bgp summary — BGP peer state, uptime, prefix counts.
  • ping & traceroute — test reachability to BGP peer and beyond.
Example Router Output
# show ip bgp summary
Neighbor        V    AS MsgRcvd MsgSent  TblVer  InQ OutQ Up/Down  State/PfxRcd
10.0.0.2        4 65002   1234   1210       0    0    0 02:14:55        120
Interpretation: 'State/PfxRcd' shows prefixes received. A non-zero value with an Up time indicates a working adjacency and advertised routes.
