Module 4 › Chapter 3.7 › VLAN & MTU Issues
VLAN Mismatch

Ensure the VLAN ID on your on-prem router matches the VIF VLAN in AWS. Mismatches prevent frames from reaching the intended virtual interface.

Check: show vlan brief | Compare to VIF config
MTU & Jumbo Frames

If jumbo frames are enabled, ensure both sides support the same MTU. Mismatches cause fragmentation or dropped packets and can appear as performance problems.

Check: interface MTU values and application packet sizes
Real-world scenario
After maintenance, ConnectionState is up but pings to the peer timeout. Evidence points to a VLAN ID mismatch — verify VLANs before escalating to the colo provider.
