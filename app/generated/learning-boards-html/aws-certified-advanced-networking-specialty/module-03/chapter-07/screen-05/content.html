Module 4 › Chapter 3.7 › CloudWatch Metrics
Metric Reference
  • ConnectionState: physical link up/down indicator.
  • BGPState: BGP session status for VIFs; up or down.
  • ConnectionBpsIn/Out: throughput for the whole connection.
  • VirtualInterfaceBpsIn/Out: per-VIF bandwidth usage.
  • ConnectionErrorCount and LightLevelTx/Rx: physical layer diagnostics.
Key Takeaway

Alarms should cover both ConnectionState and BGPState so you know whether to escalate the fiber vendor or the BGP configuration team.

Example CLI
aws cloudwatch get-metric-statistics \
  --namespace AWS/DirectConnect \
  --metric-name BGPState \
  --dimensions Name=VirtualInterfaceId,Value=dxvif-abcdefghij \
  --start-time 2023-01-01T00:00:00Z \
  --end-time 2023-01-01T01:00:00Z \
  --period 300 \
  --statistic Average \
  --region us-east-1
Interpretation: a returned value of 1 means BGP is up; 0 means BGP is down. Use these calls to populate dashboards or runbooks during incident response.
