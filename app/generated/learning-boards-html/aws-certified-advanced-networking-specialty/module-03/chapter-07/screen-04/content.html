Module 4 › Chapter 3.7 › Pricing — Port Hours & DTO
Definition

Port Hours: an hourly charge per Direct Connect port. Data Transfer Out: variable egress cost from AWS across Direct Connect, usually tiered and cheaper than public internet egress.

Example Estimate
Model both hourly port cost and DTO for expected monthly TB. Use the AWS Pricing Calculator to combine these figures.
Key Takeaway

Port hours can dominate costs for idle circuits; DTO matters most for consistent heavy egress.

Pricing Breakdown
Port Hours
Fixed hourly rate by speed. Applies while port exists, even if idle.
Data Transfer Out
Variable egress pricing, often tiered by TB. Data in is typically free.
VIF / DX Gateway
VIFs and DX Gateways do not usually have separate hourly port charges; DTO still applies for attached VPCs.
Common Mistake

Overlooking port hours for seldom-used connections is common. If you expect low traffic, consider resizing or scheduling downtime.
