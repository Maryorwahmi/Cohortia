Alarm Design Steps
  1. Select critical metrics: ConnectionState and BGPState first.
  2. Set thresholds with short confirmation windows to avoid flaps.
  3. Route alerts to SNS with runbook links and escalation contacts.
  4. Create dashboards with per-connection and per-VIF tiles for quick triage.
Key Takeaway

Focus alerts on link and routing failures and verify that notifications include a next-step for responders.

Example Dashboard Row
Tiles: ConnectionState | BGPState | VirtualInterfaceBpsOut | ConnectionErrorCount
