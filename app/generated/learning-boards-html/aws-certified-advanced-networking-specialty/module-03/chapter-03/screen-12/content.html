Module 3 › Chapter 3.3 › Key Concepts
Dedicated Connection
Exclusive 1/10/100 Gbps port, LOA‑CFA and colo cross‑connect required; best for sustained high throughput and control.
Hosted Connection
Partner-managed virtual circuits from 50 Mbps to 10 Gbps; faster provisioning but reliant on partner SLAs.
MACsec
Layer 2 encryption for supported Dedicated 10/100 Gbps links; requires 802.1AE-capable hardware and key management.
Summary

Choose connection type by weighing control, provisioning time, and security needs; confirm hardware and macSecCapable status with the AWS CLI before ordering.
