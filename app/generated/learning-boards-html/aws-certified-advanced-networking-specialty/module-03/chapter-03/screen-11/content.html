Module 3 › Chapter 3.3 › Hands-on Scenario
Scenario task list
  1. Run aws directconnect describe‑connections to check for existing capacity.
  2. Request quotes and provisioning timelines from two Direct Connect Partners.
  3. Compare provisioning lead time, SLA, and expected performance for 200 Mbps.
  4. Document recommendation with partner SLA and expected activation date.
Recommended decision
Choose Hosted from a vetted partner for rapid provisioning and precise 200 Mbps capacity, and include the partner's SLA as evidence.
Why this matters

This exercise practices translating technical requirements into procurement actions and measurable evidence for stakeholders.

Decision checklist
  • Partner provisioning time ≤ 2 weeks
  • Clear SLA and redundancy plan
  • Pricing for 200 Mbps and scaling path
  • Monitoring and support contact details
