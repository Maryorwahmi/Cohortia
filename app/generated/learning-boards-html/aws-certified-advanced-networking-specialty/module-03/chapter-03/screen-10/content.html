Module 3 › Chapter 3.3 › CLI — describe-connections
Command
Run this to retrieve connection metadata for auditing.
aws directconnect describe-connections --region us-east-1

# Look for fields: connectionId, bandwidth, type, macSecCapable, partnerName
Reading the output
If type is dedicated you own the port. If hosted the partnerName field will be present and bandwidth may be a granular value like 500Mbps.
Example action
Capture the CLI output as evidence for your decision table and to verify macSecCapable before enabling link encryption.
Common mistake
Assuming UI labels are current; the CLI output is authoritative and includes the macSecCapable boolean you need to plan encryption.
Key Takeaway

Use the CLI to audit connections and produce the evidence items required for procurement and compliance checks.
