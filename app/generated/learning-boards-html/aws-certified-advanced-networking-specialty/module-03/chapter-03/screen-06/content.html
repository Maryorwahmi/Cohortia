Module 3 › Chapter 3.3 › Provisioning Timeline
Order → LOA‑CFA → Cross‑connect → Test
A step-by-step process and where delays commonly occur.
1. Order
Create Dedicated Connection in AWS console and choose location and speed.
2. LOA‑CFA
Receive LOA‑CFA. Provide this to your colo team so they can schedule the cross‑connect.
3. Cross‑connect
Colocation completes fiber/copper work between your equipment and AWS port.
4. Test & Verify
Validate link status, bandwidth, jumbo frames, and routing before production traffic.
Delay hotspots
  • Colocation scheduling and physical labor windows.
  • Procurement approvals for hardware or cross‑connect orders.
  • Incorrect LOA‑CFA handling or mismatched rack coordinates.
Mitigation
Initiate procurement early, confirm colo SLAs, and use hosted options if time-to-market is the priority.
