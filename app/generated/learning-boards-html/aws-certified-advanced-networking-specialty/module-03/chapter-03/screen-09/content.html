Module 3 › Chapter 3.3 › Decision Criteria
Decision matrix
C
Control
Dedicated provides exclusive physical control; hosted relies on partner.
T
Time
Hosted typically faster to provision; Dedicated requires colocation work and LOA‑CFA handling.
S
Security
MACsec is available for certain Dedicated links; evaluate if link-level encryption is required.
Example scenarios
Urgent 200 Mbps need
Recommend Hosted from a vetted partner for speed and bandwidth granularity.
High-throughput + MACsec
Choose Dedicated at a location with MACsec support and plan for LOA‑CFA and colo coordination.
Avoid this mistake
Assuming partner SLAs match AWS SLAs—validate the partner's own SLA and recovery procedures before production cutover.
