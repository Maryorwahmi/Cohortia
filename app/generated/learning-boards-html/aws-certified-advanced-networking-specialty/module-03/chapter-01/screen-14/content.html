Module 3 › Chapter 3.1 › Key Concepts
Direct Connect (DX)
A private fiber link into AWS that bypasses the public internet to deliver predictable performance.
Virtual Interface (VIF)
A logical interface over the DX physical link used to reach VPCs or AWS public services.
BGP Peering
The routing protocol used to exchange prefixes and ensure correct path selection between your network and AWS.
Summary Takeaway
Match Direct Connect to workloads needing consistent performance or high-volume transfers, plan encryption overlays when required, and prepare a provisioning checklist before ordering.
