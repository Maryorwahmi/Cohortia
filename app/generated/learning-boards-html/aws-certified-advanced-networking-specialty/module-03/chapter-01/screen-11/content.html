Privacy vs Encryption
Direct Connect gives path privacy by avoiding public internet routing, but it does not encrypt payloads by default. For cryptographic protection, plan an IPsec overlay.
Recommended pattern
Direct Connect + IPsec VPN = predictable bandwidth with encryption. Test tunnel stability and BGP interaction.
Misconception
Do not assume private path eliminates encryption requirements from compliance frameworks.
Operational actions
  • Decide whether to run IPsec tunnels over DX for end-to-end encryption.
  • Plan key and certificate lifecycle and tests for tunnel rekey events.
  • Verify BGP advertisements and ensure tunnels do not block necessary route exchanges.
Pro tip

When using an IPsec overlay, validate both the tunnel and your routing policies during maintenance windows to avoid route disruption.
