Module 3 › Chapter 3.1 › Hybrid Cloud
Architecture pattern
Use Direct Connect to create a private routed path between on-premises and VPCs. Exchange routes via BGP and use VIFs to direct traffic to specific services.
Why it matters
Predictable connections reduce application errors and make replication and synchronization windows reliable.
Example
On-prem identity servers handle validation for cloud apps. Direct Connect reduces login time variability and session dropped rates compared to internet paths.
Common mistake
Assuming a single Direct Connect link is sufficient for resilience. Always design redundancy and failover strategies.
Practical considerations
  • BGP policies: define route preference to prefer DX routes and fall back to VPN or internet when necessary.
  • VLANs & VIFs: separate traffic types (private VPC access vs public service access) with appropriate VIFs.
  • Redundancy: include a backup connection or VPN for failover and maintenance windows.
Key Takeaway

Direct Connect makes hybrid systems more predictable, but you must design BGP, VIFs, and redundancy deliberately.
