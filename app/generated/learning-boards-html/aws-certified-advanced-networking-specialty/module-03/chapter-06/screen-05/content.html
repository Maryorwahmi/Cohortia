Module 3 › Chapter 3.6 › Designing Diverse Paths
Validation process
  1. Inventory DX locations, carrier circuits, and cross‑connect IDs.
  2. Request separate cable paths and carrier termination points.
  3. Terminate on separate on‑prem racks and routers with independent power.
  4. Establish independent BGP sessions and review route advertisements.
  5. Run simulated failover tests and record outcomes.
Use this flow as a checklist during design reviews with carriers and colocation teams.
Example scenario
Primary: DX-A (Ashburn) — Carrier X
Secondary: DX-B (Miami) — Carrier Y with different fiber route. On‑prem termination on Router1 and Router2 in separate racks.
Key Takeaway

Physical diversity is the most effective mitigation against common‑mode failures; verify with providers.

Pro tip
Request carrier path documentation and put it in your runbook to prevent assumptions about diversity.
