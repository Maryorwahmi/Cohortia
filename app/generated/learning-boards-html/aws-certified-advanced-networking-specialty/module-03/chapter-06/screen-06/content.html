Module 3 › Chapter 3.6 › Router Termination
Architecture pattern
Terminate each Direct Connect on a different customer router in separate racks. Use separate UPS or power circuits to minimize correlated failures.
Ensure independent BGP sessions from each router with consistent prefix advertisement.
Label rack IDs, router serials, and power circuit IDs in the runbook and on diagrams.
Concrete scenario
Router A (rack 10, power A) — DX1
Router B (rack 12, power B) — DX2. Each router peers with AWS over separate VIFs and advertises identical prefixes.
Key Takeaway

Router separation reduces a common hardware or software failure from taking both DX links down.
