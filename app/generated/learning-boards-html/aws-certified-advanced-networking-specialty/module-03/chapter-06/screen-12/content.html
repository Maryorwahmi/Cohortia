Module 3 › Chapter 3.6 › Hands-on Activity
Task checklist
  1. Write BGP neighbor and network statements for Router A and Router B advertising 172.16.0.0/16.
  2. On Router B create route-map PREPEND_AS and set as-path prepend 65000 65000 65000.
  3. Confirm AS_PATH lengths via show ip bgp on both routers and on any BGP monitor.
  4. Simulate failure of Router A's BGP session and measure convergence time.
  5. Document outputs and expected recovery actions in your test report.
Starter configuration (conceptual)
# Router A (Primary DX)
router bgp 65000
 neighbor <AWS_IP_PRIMARY> remote-as 64512
  address-family ipv4
   network 172.16.0.0 mask 255.255.0.0
  exit-address-family

# Router B (Secondary DX)
router bgp 65000
 neighbor <AWS_IP_SECONDARY> remote-as 64512
  address-family ipv4
   network 172.16.0.0 mask 255.255.0.0
   neighbor <AWS_IP_SECONDARY> route-map PREPEND_AS out
  exit-address-family

route-map PREPEND_AS permit 10
 set as-path prepend 65000 65000 65000
Replace <AWS_IP_PRIMARY> and <AWS_IP_SECONDARY> with peer IPs. Capture show ip bgp and peer states before and after tests.
