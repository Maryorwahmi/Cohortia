Module 3 › Chapter 3.6 › N+1 Redundancy
Definition

N+1 redundancy provides one spare component above operational needs so that a single failure does not cause a service outage.

Why it matters: avoids single point failures in transport and termination equipment.
Sizing note: ensure spare can carry peak load or implement degradation rules at application layer.
Documentation: list failure domain and recovery action for each component.
Concrete example
Two 10 G Direct Connects
Primary carries production traffic. Secondary is configured to be capable of handling the full 10 G during failover. Traffic engineering makes the primary preferred for inbound traffic.
Key Takeaway

N+1 is effective only if the spare is independent and can carry required load when needed.

Common mistake
Two circuits that share the same conduit or router are not true N+1. Confirm physical independence.
