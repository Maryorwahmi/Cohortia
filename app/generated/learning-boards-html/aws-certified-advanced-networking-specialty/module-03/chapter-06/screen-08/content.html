Module 3 › Chapter 3.6 › BFD — Fast Detection
What BFD does

BFD provides rapid detection of forwarding plane failures and notifies control protocols like BGP so they can withdraw routes quickly.

Benefit: sub‑second detection reduces outage time for sensitive applications.
Compatibility: BFD works alongside BGP; both must be configured and tested together.
Testing BFD
  1. Enable BFD on both BGP peers and verify session establishment.
  2. Record baseline convergence time without BFD by simulating link down.
  3. Enable BFD with conservative timers, retest, and measure reduced convergence.
Key Takeaway

BFD dramatically shortens detection time but must be validated and coordinated with AWS and carriers.
