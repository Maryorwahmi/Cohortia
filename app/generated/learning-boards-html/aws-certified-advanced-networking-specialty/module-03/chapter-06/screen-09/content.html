Module 3 › Chapter 3.6 › Failover Testing
Test plan checklist
  • Define scope, safety, and rollback steps.
  • Capture baselines: BGP state, route tables, application metrics.
  • Simulate failure: BGP shutdown, interface down, or coordinated physical disconnect.
  • Observe convergence and application behavior; document times.
  • Restore and verify normal operation; write a short test report.
Example test script
Step A:
Record show ip bgp and application latency for 5 minutes.
Step B:
Administratively shut down primary BGP neighbor and time convergence.
Step C:
Restore BGP and confirm route preferences and application recovery.
Key Takeaway

Test in a controlled manner, measure, and document. Tests reveal hidden dependencies and validate runbooks.
