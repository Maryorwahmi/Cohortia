Module 3 › Chapter 3.5 › Create DX Gateway
Step-by-step
  1. Create Direct Connect Gateway and set a name.
  2. Choose an Amazon-side ASN (private range 64512–65534).
  3. Create a Private VIF or Transit VIF to the DX Gateway.
  4. Complete BGP peering between on-premises router and DX Gateway.
CLI Example
aws directconnect create-direct-connect-gateway \
    --direct-connect-gateway-name "MyGlobalDXGateway" \
    --amazon-side-asn 64512 \
    --region us-east-1
Checks and validations
  • Verify the DX Gateway appears in the console and note the Amazon-side ASN.
  • Confirm the VIF is linked to the DX Gateway and BGP sessions are established.
  • Ensure on-premises router advertises intended prefixes and accepts routes from AWS.
Pitfall

Do not select an ASN that conflicts with your on-premises ASN policies; validate routing filters to avoid unwanted advertisements.
