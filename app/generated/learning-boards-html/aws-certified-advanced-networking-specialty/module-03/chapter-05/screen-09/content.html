Module 3 › Chapter 3.5 › Transitive Routing
Direct Connect Gateway

Exchanges routes between on-premises and each associated gateway but does not forward traffic between associated VGWs.

Example

Traffic from EC2 in VPC-A to EC2 in VPC-B will not traverse the DX Gateway if both VGWs are merely associated; it must take another path.

When to use TGW

Attach a Transit Gateway to DX Gateway with a Transit VIF to enable hub-and-spoke inter-VPC routing across regions.

Comparative table
DX Gateway
No transitive VPC-to-VPC routing
DX Gateway + TGW
TGW route tables manage inter-VPC and on-prem routing
Takeaway

Plan for TGW or peering if you need direct VPC-to-VPC flows across regions via your hybrid connection.
