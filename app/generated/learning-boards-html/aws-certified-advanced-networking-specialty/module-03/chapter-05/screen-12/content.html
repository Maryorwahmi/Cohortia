Module 3 › Chapter 3.5 › Hands-on Scenario
Scenario checklist
  1. Create Direct Connect Gateway and set Amazon-side ASN.
  2. Create and attach VGW to us-east-1 VPC.
  3. Create and attach VGW to eu-west-1 VPC.
  4. Associate both VGWs with the DX Gateway.
  5. Validate BGP and update VPC route tables to send on-premises traffic to VGW.
Question

How will on-premises learn both VPCs' routes? Via BGP advertisements from the DX Gateway after association.

Question

What route table changes are needed? Each VPC route table must route on-premises prefixes to its VGW or TGW.

Question

Can VPCs communicate directly via DX Gateway? No — Direct Connect Gateway does not support transitive VPC-to-VPC routing.

Practical guidance

Follow the checklist, validate BGP advertisements, and verify VPC route tables to ensure reachability.
