Module 3 › Chapter 3.5 › DX Gateway + Transit Gateway
Why pair with TGW

TGW provides the routing plane for VPC-to-VPC communication and centralized route management across regions.

Attach TGW to DX Gateway using a Transit VIF.
Use TGW route tables to manage which VPCs and attachments are reachable from on-premises.
Enable route propagation for attachments that must receive on-premises routes.
Operational checklist
  • Create Transit VIF to attach TGW to DX Gateway.
  • Verify TGW route tables and propagation settings.
  • Confirm on-premises route table learns VPC prefixes managed by TGW.
Key Takeaway

Pairing DX Gateway with TGW creates a scalable global hub that supports inter-VPC routing and hybrid connectivity.
