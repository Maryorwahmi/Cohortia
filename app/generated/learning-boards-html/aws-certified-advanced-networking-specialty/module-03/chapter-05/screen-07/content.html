Module 3 › Chapter 3.5 › Routing with DX Gateway
Routing sequence
  1. On-prem advertises corporate prefixes via BGP to the DX Gateway.
  2. DX Gateway shares on-prem prefixes with associated VGWs/TGWs.
  3. VGWs/TGWs propagate these routes to their VPC route tables.
  4. VPCs advertise their CIDRs back through VGWs/TGWs to DX Gateway and on-prem.
Concrete scenario

If on-premises advertises 10.0.0.0/8 and a VPC has 10.1.0.0/16, ensure VPC route table points 10.0.0.0/8 to its VGW so return traffic flows correctly.

Checks
  • Verify BGP adjacency status and learned prefixes on your router.
  • Confirm each VPC route table has a route to on-prem via VGW or TGW.
  • Remember DX Gateway does not perform NAT; routing must use private addresses.
Key Takeaway

Routing depends on BGP advertisements both ways and correct VPC route tables for return paths.
