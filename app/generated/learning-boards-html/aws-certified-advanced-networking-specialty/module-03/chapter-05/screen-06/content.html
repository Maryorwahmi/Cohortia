Module 3 › Chapter 3.5 › Associating VGWs and TGWs
Required preconditions
  • VGW must be attached to its VPC before association.
  • TGW must have VPC attachments before associating with DX Gateway.
  • Know the region of each VGW/TGW so you specify the correct region for association.
CLI Example
aws directconnect associate-virtual-gateway \
    --direct-connect-gateway-id dxgw-abcdefgh \
    --virtual-gateway-id vgw-1234567890abcdef0 \
    --region us-east-1
Validation checklist
  1. Confirm association status in the console or via CLI.
  2. Verify on-premises router learns the VPC CIDRs through BGP.
  3. Confirm each VPC route table returns on-premises traffic to the VGW or TGW.
Tip

Use route filters and BGP prefix limits to protect your on-premises routing table from unexpected advertisements.
