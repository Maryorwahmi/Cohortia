Create Direct Connect Gateway (example)
aws directconnect create-direct-connect-gateway \
    --direct-connect-gateway-name "MyGlobalDXGateway" \
    --amazon-side-asn 64512 \
    --region us-east-1
Note the command is managed from a region but creates a global DX Gateway. Record the dxgw ID from the response for associations.
Associate a VGW (example)
aws directconnect associate-virtual-gateway \
    --direct-connect-gateway-id dxgw-abcdefgh \
    --virtual-gateway-id vgw-1234567890abcdef0 \
    --region us-east-1
Verify the association status and confirm the VGW was attached to its VPC before running this command.
