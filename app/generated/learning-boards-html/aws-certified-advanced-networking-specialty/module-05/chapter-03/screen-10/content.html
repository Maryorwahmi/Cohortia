Use Case Scenario

Deploying a Multi-Region Web App with GA

A hands-on scenario for improved performance and availability using Standard Accelerator.

Scenario Overview

You have a web application deployed in us-east-1 and eu-west-1, each behind an Application Load Balancer (ALB). You want to use AWS Global Accelerator to provide a single entry point, direct users to the closest healthy region, and ensure automatic failover.

Goal

Achieve global performance and high availability with a unified user experience.

Key Configuration Steps

1

Prepare ALBs: Ensure ALBs are created in us-east-1 and eu-west-1, pointing to healthy web servers.

2

Create Standard Accelerator: Initialize a new Global Accelerator instance.

3

Add Listener: Configure a listener for HTTP (port 80) to accept incoming traffic.

4

Create Endpoint Groups: Set up two groups, one for us-east-1 and one for eu-west-1.

5

Add Endpoints: Register the respective ALBs as endpoints within their regional groups.

6

Configure Health Checks: Set up health checks for the ALBs to enable automatic failover.

Key Takeaway

This scenario demonstrates how Global Accelerator provides a unified, high-performance, and highly available entry point for multi-region applications, leveraging its core features for traffic management and failover.
