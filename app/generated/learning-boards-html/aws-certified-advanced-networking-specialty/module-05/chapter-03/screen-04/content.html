Core Concept

What is AWS Global Accelerator?

Optimizing the path for global user traffic to application endpoints.

Key Characteristics

  • Static Anycast IP Addresses: Provides two fixed, public IP addresses as entry points, simplifying DNS.
  • AWS Global Network: Traffic traverses the optimized AWS backbone, bypassing public internet congestion.
  • Performance & Availability: Reduces latency and improves reliability for global users.
  • Non-HTTP(S) Traffic: Ideal for applications sensitive to network jitter and packet loss, beyond typical web content.

How it Works: The Optimized Path

1. User RequestConnects to Anycast IP.
2. Nearest AWS Edge LocationTraffic enters AWS network.
3. AWS Global NetworkTraffic traverses optimized backbone.
4. Application EndpointTraffic reaches target in AWS region.
Common Misconception

Global Accelerator is not a CDN. It optimizes the network path, while CDNs cache content. They are complementary services.
