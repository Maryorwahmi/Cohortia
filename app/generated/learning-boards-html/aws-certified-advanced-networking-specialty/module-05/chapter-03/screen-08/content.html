Configuration Essentials

Managing Endpoint Groups and Health Checks

Ensuring traffic is directed to healthy, available resources with granular control.

Endpoint Groups & Traffic Dials

  • Regional Grouping: Collections of endpoints (ALBs, NLBs, EC2, EIPs) in a specific AWS region.
  • Traffic Dial: Controls the percentage of traffic directed to a specific region.
  • Use Cases: Controlled testing, blue/green deployments, planned maintenance.

Health Checks & Failover

Health Check Function

  • Global Accelerator performs its own health checks on registered endpoints.
  • If an endpoint fails, traffic is automatically redirected to a healthy alternative.

Common Mistakes

  • Misconfiguring health checks (e.g., wrong path/port).
  • Not considering cost implications (data transfer, hourly rates).
Key Takeaway

Properly configured Endpoint Groups and health checks are vital for Global Accelerator's ability to manage traffic distribution, enable controlled deployments, and ensure automatic failover for continuous application availability.
