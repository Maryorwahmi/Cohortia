Accelerator Types

Standard Accelerators for Optimal Routing

Automatically directing traffic to the best healthy endpoint based on various factors.

Components of a Standard Accelerator

  • Listeners: Define ports and protocols (e.g., TCP 80) for incoming client connections.
  • Endpoint Groups: Represent specific AWS regions where your application endpoints reside.
  • Endpoints: Application Load Balancers (ALBs), Network Load Balancers (NLBs), EC2 instances, or Elastic IPs.
  • Health Checks: Continuously monitor endpoint health, automatically routing traffic away from unhealthy ones.

Routing Logic & Example

Routing Factors

  • Endpoint Health
  • Endpoint Weight
  • Client Location

Example: Multi-Region Application

Application deployed in us-east-1 and eu-west-1. Global Accelerator directs users to the closest healthy endpoint, failing over if one region becomes unavailable.

Key Takeaway

Standard Accelerators provide automated, intelligent traffic routing and robust fault tolerance for global applications by leveraging health checks and regional endpoint groups.
