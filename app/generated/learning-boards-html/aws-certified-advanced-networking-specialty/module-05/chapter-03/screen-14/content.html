Key Concepts

What to remember from this chapter

Custom Routing Accelerator

Provides deterministic routing, allowing explicit mapping of source IP/port to a specific destination IP/port within a VPC.

Listener

Defines the port and protocol that Global Accelerator accepts incoming client connections on.

Endpoint Group & Traffic Dial

A collection of endpoints in a specific AWS region, with a traffic dial to control traffic percentage.

Chapter Summary

AWS Global Accelerator provides a consistent entry point, leverages the high-speed AWS global network, and offers intelligent traffic management with automatic failover, making it a cornerstone for advanced networking architectures.
