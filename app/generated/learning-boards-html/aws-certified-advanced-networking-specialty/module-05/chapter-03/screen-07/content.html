Accelerator Types

Custom Routing Accelerators for Deterministic Traffic

Explicitly mapping source IP/port to a specific destination IP/port within a VPC.

Key Features

  • Granular Control: Provides precise control over traffic distribution, unlike automatic routing.
  • Explicit Mapping: Maps a source IP/port to a specific destination IP/port within a VPC.
  • Deterministic Routing: Ensures a user or device always connects to the same instance.

Use Cases & Example

Ideal For:

  • Multi-tenant applications
  • Gaming servers requiring session affinity
  • IoT solutions with specific device-to-instance routing

Example: Gaming Scenario

A player needs to consistently connect to the same game server instance to maintain game state, regardless of their entry point into the AWS network. Custom routing ensures this persistence.

Key Takeaway

Custom Routing Accelerators offer precise, deterministic traffic control, enabling specific source-to-destination mappings crucial for multi-tenant, gaming, and IoT applications.
