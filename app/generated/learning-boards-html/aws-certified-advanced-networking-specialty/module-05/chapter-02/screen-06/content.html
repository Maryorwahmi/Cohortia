Inbound Resolver Endpoints: On-Prem to AWS

Enabling on-premises DNS servers to resolve AWS-hosted private DNS names.

Step 1

On-Prem Query

An on-premises application queries for an AWS private DNS name (e.g., `app.corp.internal`).

Step 2

Conditional Forwarding

On-premises DNS forwards the query to the Inbound Resolver Endpoint's IP addresses.

Step 3

Endpoint Receives

The Inbound Resolver Endpoint (ENI) in your VPC receives the query.

Step 4

AWS Resolves

Route 53 Resolver in the VPC resolves the AWS-hosted private DNS name.

Step 5

Response Back

The resolved IP address is sent back to the on-premises DNS server and then to the application.

Key Takeaway

Inbound Endpoints enable on-premises systems to resolve AWS private DNS, crucial for hybrid resource discovery.
