Outbound Resolver Endpoints: AWS to On-Prem

Enabling AWS resources to resolve on-premises DNS names.

Step 1

AWS Query

An AWS application queries for an on-premises DNS name (e.g., `db.onprem.corp.com`).

Step 2

Resolver Rule Match

VPC's Route 53 Resolver matches the query with an Outbound Resolver rule.

Step 3

Forward to Endpoint

Query is forwarded to the Outbound Resolver Endpoint (ENI) in the VPC.

Step 4

Forward to On-Prem DNS

Endpoint forwards the query to the specified on-premises DNS servers via VPN/Direct Connect.

Step 5

On-Prem Resolves

On-premises DNS resolves the name and sends the IP back to the AWS application.

Key Takeaway

Outbound Endpoints enable AWS resources to resolve on-premises DNS names, critical for hybrid application connectivity.
