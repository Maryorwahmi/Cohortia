Creating Resolver Rules and VPC Association

Defining which domains are forwarded and linking the rule to your VPC.

# 2. Create a Resolver Rule
aws route53resolver create-resolver-rule \
    --name "OnPremLegacyRule" \
    --rule-type FORWARD \
    --domain-name "legacy.corp.com" \
    --target-ips Ip=10.0.0.10 \
    --resolver-endpoint-id rslvr-ep-0123456789abcdef0

# 3. Associate the Rule with your VPC
aws route53resolver associate-resolver-rule \
    --resolver-rule-id rslvr-rule-0123456789abcdef0 \
    --vpc-id vpc-0abcdef1234567890

Command Breakdown

  • `--rule-type FORWARD`: Specifies that queries for this domain should be forwarded.
  • `--domain-name`: The specific domain to forward (e.g., `legacy.corp.com`).
  • `--target-ips`: IP addresses of your on-premises DNS servers.
  • `--resolver-endpoint-id`: Links to the Outbound Endpoint created previously.
  • `--vpc-id`: The VPC where this rule will apply.
Common Mistake

Forgetting to associate the rule with the VPC, or using an incorrect domain name, will prevent resolution.

Key Takeaway

Resolver rules direct specific DNS queries to your on-premises DNS via the Outbound Endpoint, and must be associated with the target VPC.
