Configuring an Outbound Resolver Endpoint

Setting up the network interface for AWS to on-premises DNS queries.

# 1. Create Outbound Resolver Endpoint
aws route53resolver create-resolver-endpoint \
    --name "MyOutboundResolver" \
    --direction OUTBOUND \
    --security-group-ids sg-0123456789abcdef0 \
    --ip-addresses SubnetId=subnet-0a1b2c3d4e5f6a7b8,SubnetId=subnet-0c9d8e7f6a5b4c3d2

Command Breakdown

  • `--name`: A descriptive name for your endpoint.
  • `--direction OUTBOUND`: Specifies this endpoint is for queries *from* AWS *to* on-premises.
  • `--security-group-ids`: Crucial for allowing port 53 traffic.
  • `--ip-addresses`: Subnets where ENIs will be provisioned for redundancy.
Common Mistake

Incorrect security group rules (e.g., not allowing UDP/TCP 53 outbound) will prevent DNS resolution.

Key Takeaway

The Outbound Resolver Endpoint creates the network path; security groups and subnet selection are critical for its functionality.
