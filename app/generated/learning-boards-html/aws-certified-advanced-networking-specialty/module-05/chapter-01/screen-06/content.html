Geolocation Routing Policy

Routing traffic based on the user's geographic location.

How Geolocation Routing Works

You define rules to send users from specific geographic locations (countries, continents, states) to particular endpoints.

Mechanism

Based on the geographic location of the DNS query's source IP address.

Use Cases
  • Data residency compliance
  • Localized content delivery
  • Geographic access restrictions
Concrete Example

You configure a record to send all users from Germany to an EC2 instance in eu-central-1, while users from the US are sent to us-east-1. This ensures GDPR compliance for German users.

Key Takeaway

Geolocation routing provides explicit, rule-based traffic direction based on user location, crucial for compliance and localized experiences.
