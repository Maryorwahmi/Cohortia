High Availability

Failover Routing Policy & Health Checks

Ensuring continuous availability for mission-critical applications.

Failover Mechanism

Configures primary and secondary resources. Route 53 monitors the primary's health and automatically routes to a healthy secondary if needed.

Active-Passive

Traffic to primary; secondary is standby. Common for disaster recovery.

Active-Active

Traffic distributed to all healthy resources. If one fails, others handle load.

Concrete Example

You have a primary web server in us-east-1 and a DR server in us-west-2. If the us-east-1 server fails its health check, Route 53 automatically directs all traffic to us-west-2.

Key Takeaway

Failover routing, combined with health checks, is essential for building highly available and resilient applications that can withstand outages.
