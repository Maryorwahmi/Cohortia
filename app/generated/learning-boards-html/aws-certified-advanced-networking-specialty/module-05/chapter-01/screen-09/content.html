Multivalue Answer Routing Policy

Returning multiple healthy records for client-side selection.

How Multivalue Answer Works

Returns up to eight healthy records in response to a DNS query. The client then chooses one of the returned IP addresses.

Mechanism

Not a true load balancer; provides a list of healthy IPs. Relies on client-side retry logic.

Benefit
  • Simple traffic distribution
  • Fault tolerance (with health checks)
  • Cost-effective for basic needs
Concrete Example

A query for app.example.com returns 192.0.2.10, 192.0.2.11, and 192.0.2.12. The client attempts to connect to one, and if it fails, tries another from the list.

Key Takeaway

Multivalue Answer routing offers a straightforward way to provide multiple healthy endpoints, allowing clients to handle distribution and basic fault tolerance.
