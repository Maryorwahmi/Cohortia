Private Hosted Zones

Managing DNS resolution within your AWS VPCs.

What are Private Hosted Zones?

Containers for DNS records that can only be resolved within specified Amazon VPCs. They are not exposed to the public internet.

Key Feature

Allows custom domain names (e.g., api.internal) for internal AWS resources.

Use Cases
  • Microservices discovery
  • Internal application communication
  • Simplified resource addressing
Concrete Example

You create a private hosted zone for service.local and associate it with your application VPC. An EC2 instance in that VPC can then resolve database.service.local to the correct private IP of your database.

Key Takeaway

Private Hosted Zones are fundamental for secure and manageable internal DNS resolution within your AWS environment, especially for complex architectures.
