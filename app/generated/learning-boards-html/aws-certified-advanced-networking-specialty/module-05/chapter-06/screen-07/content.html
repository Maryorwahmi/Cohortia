Initiating and Accepting a Peering Connection

Establish a cross-region VPC peering connection by sending a request from one VPC and accepting it from the peer VPC.

1. Request Peering Connection

From the requester VPC's region, use `request-vpc-peering-connection` specifying peer VPC ID, region, and owner ID.

2. Accept Peering Connection

From the accepter VPC's region, use `accept-vpc-peering-connection` with the generated peering connection ID.

Terminal Demo: Request & Accept Peering
# 1. Initiate Peering Connection Request (from us-east-1)aws ec2 request-vpc-peering-connection 
    --vpc-id vpc-0a1b2c3d4e5f6a7b8 
    --peer-vpc-id vpc-0c9d8e7f6a5b4c3d2 
    --peer-region us-west-2 
    --peer-owner-id 123456789012 
    --region us-east-1 
    --tag-specifications 'ResourceType=vpc-peering-connection,Tags=[{Key=Name,Value=VPC-A-to-VPC-B-Peering}]'

# Note down the VpcPeeringConnectionId, e.g., "pcx-0123456789abcdef0"

# 2. Accept Peering Connection Request (from us-west-2)aws ec2 accept-vpc-peering-connection 
    --vpc-peering-connection-id pcx-0123456789abcdef0 
    --region us-west-2
Key Takeaway

Establishing a cross-region VPC peering connection is a two-part process involving a request from one region and an explicit acceptance from the other, using specific AWS CLI commands.
