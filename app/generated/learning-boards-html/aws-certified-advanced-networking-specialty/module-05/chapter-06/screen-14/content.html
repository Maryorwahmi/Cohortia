Key Concepts

Essential Terms for Global Networking

Cross-Region VPC Peering

A direct, private network connection between two VPCs located in different AWS regions.

Non-Transitive

A property of VPC peering where traffic cannot pass through a peered VPC to reach another VPC.

AWS Transit Gateway (TGW)

A network transit hub that connects VPCs and on-premises networks, simplifying network topology.

Summary Takeaway

Understanding the direct but limited nature of VPC peering versus the scalable, centralized hub of Transit Gateway is key to designing effective global networks.
