Host-Based Routing
Serving Multiple Domains
Directing traffic based on the Host header.
How it Works

ALB listener rules inspect the `Host` header of incoming requests to determine the target group.

Use Cases
  • Hosting multiple websites on a single ALB.
  • Serving different applications (e.g., web app, admin portal).
  • Consolidating infrastructure and simplifying management.
Benefit

Simplifies DNS, SSL certificate management, and reduces the number of load balancers needed.
