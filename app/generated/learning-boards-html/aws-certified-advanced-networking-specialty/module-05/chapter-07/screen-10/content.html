Stateful Applications
Sticky Sessions
Ensuring user session continuity across requests.
Purpose

Crucial for stateful applications to maintain user session data (e.g., shopping carts, login status) by routing requests to the same server instance.

Configuration
  • Enabled at the Target Group level for ALBs.
  • Uses Load Balancer-generated cookie (default) or application-generated cookie.
  • Configurable duration (e.g., 5 minutes, until browser close).
Misconception Check

Sticky sessions are not always needed. For stateless applications, they can hinder load distribution and fault tolerance. Use them only when state management requires it.
