Understanding Routing Logic
Applying knowledge of ALB routing rules.
Scenario

ALB with rules: Default (`default-tg`), Priority 10 (`/api/*` → `api-tg`), Priority 20 (`/images/*` → `images-tg`).

Rule Evaluation
  • Request: `/api/users` → Matches Priority 10 rule → `api-tg`.
  • Request: `/about` → No match for 10 or 20 → Matches Default rule → `default-tg`.
Key Takeaway

The order of rules and their conditions are critical for correct traffic routing in an ALB.
