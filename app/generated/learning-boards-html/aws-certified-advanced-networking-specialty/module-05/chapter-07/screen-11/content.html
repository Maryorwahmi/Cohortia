High Availability
NLB Cross-Zone Load Balancing
Understanding default behavior and enabling for resilience.
Default Behavior

Disabled by default. Routes traffic only to targets within the same Availability Zone as the client connection.

When Enabled
  • Distributes traffic evenly across all healthy targets in all enabled AZs.
  • Enhances high availability and fault tolerance.
  • Incurs additional data transfer charges between AZs.
Key Consideration

For NLBs, enabling cross-zone load balancing is crucial for high availability but requires careful cost management due to inter-AZ data transfer fees.
