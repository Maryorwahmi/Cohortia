What to Remember
Core principles for advanced traffic management.
Listener Rules (ALB)

Conditions (path, host) and actions (forward, redirect) for precise traffic routing.

Advanced Health Checks

Custom paths, success codes, and thresholds ensure targets are truly operational.

Sticky Sessions

Maintains user state by routing requests to the same instance for stateful applications.

Cross-Zone Load Balancing

Ensures even traffic distribution across all AZs for high availability (ALB: always on, NLB: configurable).

Summary Mastering these advanced load balancing features is key to building resilient and scalable AWS applications.
