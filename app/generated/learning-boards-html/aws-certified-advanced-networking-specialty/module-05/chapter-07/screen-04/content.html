Core Concept
ALB Listener Rules
Directing traffic with precision based on request attributes.
Conditions
  • Path-based routing (e.g., `/api/*`)
  • Host-based routing (e.g., `app1.example.com`)
  • HTTP header/method
  • Query string parameters
  • Source IP address
Actions
  • Forward to Target Group(s)
  • Return Fixed Response
  • Redirect to URL
Common Mistake

Creating overly complex rule sets that are difficult to manage and debug. Start simple and add complexity as needed.

Example Routing Logic
Single ALB, Multiple Target Groups
Request
`Host: app.example.com`
Rule 1
IF Path is `/api/*` THEN Forward to `api-tg`
Rule 2
IF Path is `/images/*` THEN Forward to `images-tg`
Default
ELSE Forward to `default-tg`
