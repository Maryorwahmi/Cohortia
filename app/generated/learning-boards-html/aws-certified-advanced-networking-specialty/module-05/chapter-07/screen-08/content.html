Microservices Routing
Path-Based Routing Example
Directing traffic to different services based on URL path.
Scenario

A single domain (`api.example.com`) serving multiple backend services (Auth, Users, Orders) via an ALB.

Routing Rules
  • Requests to `/auth/*` → `auth-tg`
  • Requests to `/users/*` → `users-tg`
  • Requests to `/orders/*` → `orders-tg`
  • Default rule → `default-tg`
Benefit

Simplifies client interaction and enables independent scaling and deployment of microservices under a unified API gateway.
