Caching Strategy

Defining Content Handling with Cache Behaviors

Rules that dictate how CloudFront processes requests for specific URL paths.

Path Pattern

Specifies which requests a cache behavior applies to (e.g., /images/*, /static/*, *.html).

Allowed HTTP Methods

Determines which HTTP methods (GET, HEAD, OPTIONS, etc.) CloudFront will process and forward.

Viewer Protocol Policy

Controls whether HTTP, HTTPS, or a redirect to HTTPS is used for communication between the viewer and CloudFront.

Key Takeaway

Cache behaviors are essential for fine-tuning how CloudFront handles different content types, impacting both performance and security.

Cache Behavior Configuration Flow
