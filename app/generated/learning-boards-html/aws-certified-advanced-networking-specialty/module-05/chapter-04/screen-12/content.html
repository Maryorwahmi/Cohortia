Hands-on Activity

Setting Up an S3 Bucket for CloudFront

Preparing your static website content for global delivery.

Create S3 Bucket

Establish a new S3 bucket to host your static website content. Ensure it's configured to block public access by default.

Upload Content

Upload your index.html file and any other static assets to the S3 bucket, ensuring they are set to private access.

Key Takeaway

The first step to secure CloudFront delivery is to host your content in a private S3 bucket, preventing direct public access.

S3 Bucket Creation & Content Upload
# 1. Create S3 bucket (replace unique-bucket-name)
aws s3 mb s3://my-static-website-unique-bucket-name --region us-east-1

# 2. Create a simple index.html file
echo "<h1>Hello from CloudFront!</h1>" > index.html

# 3. Upload index.html to S3 with private ACL
aws s3 cp index.html s3://my-static-website-unique-bucket-name/index.html --acl private

# Verify bucket policy blocks public access (default for new buckets)
# You can check via AWS Console or 'aws s3api get-public-access-block'
These commands create your S3 bucket and upload the initial content, ensuring it's not publicly accessible.
