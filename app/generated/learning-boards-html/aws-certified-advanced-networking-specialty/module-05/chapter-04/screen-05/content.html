CloudFront Distributions and Origins

Defining where CloudFront fetches your content from.

CloudFront Distribution

The primary resource that defines how CloudFront delivers your content, including origins, cache behaviors, and security settings.

Origin Server

The backend source where CloudFront retrieves your content. This can be an S3 bucket, an EC2 instance, or an Application Load Balancer.

Key Takeaway

Properly configuring your CloudFront distribution and selecting the right origin type are fundamental steps for efficient content delivery.

Common CloudFront Origin Types
Amazon S3 Bucket

Ideal for static website hosting, media storage, and large files. Highly scalable and durable.

EC2 Instance / HTTP Server

For dynamic content, web applications, or on-premises servers. Requires public accessibility.

Application Load Balancer (ALB)

Distributes traffic to multiple targets, often EC2 instances, for highly available and scalable applications.
