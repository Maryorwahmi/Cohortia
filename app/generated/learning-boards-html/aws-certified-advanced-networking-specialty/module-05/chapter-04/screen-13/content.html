Hands-on Activity

Configuring CloudFront Distribution with OAC

Connecting CloudFront to your private S3 origin and enforcing HTTPS.

Create OAC

Generate an Origin Access Control (OAC) resource to securely link CloudFront to your private S3 bucket.

Create Distribution

Configure a new CloudFront distribution, specifying your S3 origin and associating it with the OAC ID.

Update S3 Bucket Policy

Modify the S3 bucket policy to grant CloudFront permission to retrieve objects, completing the secure connection.

Key Takeaway

Properly configuring OAC and the S3 bucket policy is essential for securely linking CloudFront to a private S3 origin.

CloudFront Distribution & S3 Policy (Conceptual)
# 1. Create CloudFront Distribution with OAC (using OAC ID from previous step)
aws cloudfront create-distribution \
    --distribution-config file://distribution-config.json

# Example distribution-config.json snippet:
{
  "DefaultCacheBehavior": {
    "TargetOriginId": "S3-my-static-website-unique-bucket-name",
    "ViewerProtocolPolicy": "redirect-to-https",
    ...
  },
  "Origins": {
    "Quantity": 1,
    "Items": [
      {
        "Id": "S3-my-static-website-unique-bucket-name",
        "DomainName": "my-static-website-unique-bucket-name.s3.us-east-1.amazonaws.com",
        "OriginAccessControlId": "K1A2B3C4D5E6F7", # Replace with your OAC ID
        "S3OriginConfig": { "OriginAccessIdentity": "" }
      }
    ]
  },
  "Enabled": true,
  "DefaultRootObject": "index.html"
}

# 2. Update S3 Bucket Policy (replace bucket name and CloudFront ARN)
aws s3api put-bucket-policy \
    --bucket my-static-website-unique-bucket-name \
    --policy file://bucket-policy.json

# Example bucket-policy.json snippet:
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "AllowCloudFrontServicePrincipal",
      "Effect": "Allow",
      "Principal": { "Service": "cloudfront.amazonaws.com" },
      "Action": "s3:GetObject",
      "Resource": "arn:aws:s3:::my-static-website-unique-bucket-name/*",
      "Condition": {
        "StringEquals": {
          "AWS:SourceArn": "arn:aws:cloudfront::123456789012:distribution/E1A2B3C4D5E6F7" # Replace with your CloudFront ARN
        }
      }
    }
  ]
}
These conceptual commands illustrate the JSON structure for creating the distribution and updating the S3 bucket policy.
