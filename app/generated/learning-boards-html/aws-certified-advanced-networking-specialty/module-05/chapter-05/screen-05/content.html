Scenario Walkthrough

Hybrid Global Network: An Enterprise Use Case

Connecting global on-premises offices to critical AWS applications.

The Challenge

Global enterprise with on-premises offices needs low-latency, secure, private access to critical AWS applications across regions.

Global Accelerator Entry

On-premises users send traffic to GA's anycast IPs, routed to the nearest AWS edge location.

Direct Connect Gateway Exit

Traffic traverses AWS global backbone to DX Gateway region, then over private DX connection to on-premises.

Traffic Flow for On-Premises Users
1. On-Premises User Request
2. Global Accelerator Anycast IP
3. Nearest AWS Edge Location
4. AWS Global Backbone
5. Direct Connect Gateway
6. On-Premises Network / Application
Key Takeaway

This integrated approach ensures on-premises users benefit from Global Accelerator's performance optimization and Direct Connect Gateway's private, secure path, bypassing the public internet for critical applications.
