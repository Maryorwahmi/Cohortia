Integration Patterns

Integrating GA with Public-Facing Applications for Hybrid Access

Optimizing access for both external and internal users.

External User Flow

Global Accelerator provides optimized path for public internet users to reach public-facing application endpoints.

On-Premises Connectivity

Direct Connect Gateway provides private access from on-premises to the AWS VPC hosting the application.

Internal User Flow (via GA)

On-premises users accessing the public GA endpoint will hit the closest AWS edge, traverse the AWS backbone, and then route to the application.

Key Takeaway

For public-facing applications, Global Accelerator provides optimized paths for both external and internal users, with Direct Connect Gateway handling private connectivity to the VPC.
