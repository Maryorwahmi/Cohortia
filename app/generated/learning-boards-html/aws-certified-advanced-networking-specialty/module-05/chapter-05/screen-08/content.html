Global Accelerator for Private Endpoints in Hybrid Scenarios

Exposing internal AWS resources via Global Accelerator for hybrid access.

GA's Primary Function

Global Accelerator primarily optimizes ingress from the public internet, not direct private access.

Exposing Private Endpoints

Private endpoints (e.g., internal ALBs) can be fronted by GA if exposed via an NLB/ALB registered as a GA endpoint.

Routing Requirement

Your on-premises network must have routes to Global Accelerator's public IP ranges to initiate this traffic flow.

Private Endpoint Access via GA
1. On-Premises User Request
2. Resolve to GA Public IP
3. Traffic to Nearest AWS Edge
4. AWS Global Backbone
5. NLB/ALB (GA Endpoint) to Private Resource
Key Takeaway

Global Accelerator can front private endpoints by using an intermediate load balancer registered as a GA endpoint, extending performance benefits to internal hybrid access.
