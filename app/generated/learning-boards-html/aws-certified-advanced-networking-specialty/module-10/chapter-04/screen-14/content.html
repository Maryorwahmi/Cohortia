Chapter Summary

Key Concepts (Continued)

More essential terms and ideas to remember.

GWLB Endpoint

A VPC endpoint type allowing traffic from an application VPC to be routed to a GWLB service.

Inspection VPC (Security VPC)

A dedicated VPC where the GWLB and virtual network appliances are deployed for centralized security inspection.

Transparent Inspection

The ability of GWLB to pass traffic through security appliances without altering original packet headers.

Virtual Network Appliance

An EC2 instance running third-party networking or security software (e.g., firewall, IDPS, DPI).

Summary Takeaway

GWLB endpoints and dedicated Inspection VPCs enable transparent, centralized traffic inspection by virtual appliances, simplifying security architecture and management.
