Inbound Traffic Inspection with GWLB

Securing internet-originated traffic to your application VPCs.

Traffic Source: Internet traffic entering your VPC via an Internet Gateway (IGW).

Route Table Modification: IGW route table directs traffic destined for your application to the GWLB Endpoint.

Inspection Flow: Traffic goes IGW → GWLBE → GWLB Service → Appliances → GWLB Service → Application.

Key Takeaway

For inbound traffic, GWLB enables robust, centralized inspection by routing internet-bound traffic through security appliances before it reaches your applications.

Scenario

Web Application Firewall

A public-facing web application needs protection from common web exploits. By routing all inbound traffic through a GWLB to a fleet of Web Application Firewalls (WAFs) running on EC2 instances, you can centralize threat detection and filtering before traffic reaches your web servers, ensuring robust security.
