Common Mistakes and Safety Notes

Avoid common pitfalls in advanced ALB configuration to ensure reliable and secure operations.

  • •
    Incorrect Rule Priority: Specific rules must have higher priority (lower number) to avoid being overridden.
  • •
    Infinite Redirect Loops: Thoroughly test redirects, especially HTTP to HTTPS or URL canonicalization.
  • •
    Insufficient Monitoring: Implement robust monitoring for weighted target groups in deployments to detect issues quickly.
  • •
    WAF `COUNT` Mode: Start new WAF rules in `COUNT` mode to observe impact before switching to `BLOCK`.
Key Takeaway

Proactive testing, careful priority management, and robust monitoring are critical for successful advanced ALB deployments.

Scenario: Debugging

Unexpected Routing

A specific API path is not reaching the intended new target group.

# Problem:
# Rule 1 (Priority 10): Path '/api/*' -> Old-TG
# Rule 2 (Priority 20): Path '/api/v2/*' -> New-TG

# Issue: Requests to '/api/v2/*' are always routed to Old-TG.
# Reason: Rule 1 (more general) has higher priority (lower number) and matches first.

Solution: Change Rule 2's priority to 5 (higher than Rule 1) to ensure specific paths are evaluated first.

Pro-Tip

Use AWS CloudWatch metrics and ALB access logs to diagnose routing issues and validate traffic distribution.
