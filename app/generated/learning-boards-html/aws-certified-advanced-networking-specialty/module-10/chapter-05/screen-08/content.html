Deployment Strategy

Blue/Green Deployments

Deploy a new application version ('Green') alongside the current ('Blue'), then instantly shift 100% of traffic.

  • •
    Parallel Environments: Run both old ('Blue') and new ('Green') versions simultaneously.
  • •
    Instant Traffic Shift: Update ALB listener rule to direct all traffic to 'Green' once tested.
  • •
    Zero Downtime: Users experience no interruption during the switch.
  • •
    Immediate Rollback: Easily revert to 'Blue' if issues arise in 'Green'.
Key Takeaway

Blue/Green deployments provide a safe, zero-downtime method for releasing new application versions with instant rollback capabilities.
