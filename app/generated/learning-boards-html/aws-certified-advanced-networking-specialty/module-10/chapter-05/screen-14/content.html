CLI Example: Fixed Response Action

Configure an ALB listener rule to return a custom HTTP response (e.g., 403 Forbidden) directly from the load balancer.

  • •
    Listener ARN: Use the ARN of your HTTPS listener.
  • •
    Specific Condition: Define a condition (e.g., path pattern) to trigger the fixed response.
  • •
    Fixed Response Action: Specify Type=fixed-response with desired StatusCode, ContentType, and MessageBody.
  • •
    Edge Security: Block traffic or provide custom messages without involving backend servers.
Key Takeaway

The Fixed Response Action is a powerful tool for enforcing security policies and managing application state directly at the ALB, providing immediate feedback to clients.

AWS CLI Code

Add Fixed 403 Response Rule

# Assume LISTENER_ARN is the ARN of your HTTPS listener
LISTENER_ARN="arn:aws:elasticloadbalancing:REGION:ACCOUNT:listener/app/cohortia-web-alb/ID/LISTENER_ID"

aws elbv2 create-rule \
    --listener-arn $LISTENER_ARN \
    --priority 15 \
    --conditions "Field=path-pattern,Values=['/api/admin/*']" \
    --actions \
        Type=fixed-response,FixedResponseConfig='{"StatusCode":"403","ContentType":"text/plain","MessageBody":"Access Denied: Unauthorized API Access"}'

This command creates a rule to return a 403 Forbidden response for requests to /api/admin/*, blocking access at the ALB.

Pro-Tip

Use specific path patterns or host headers in conditions to precisely target which requests receive the fixed response.
