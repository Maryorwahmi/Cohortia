URL Redirection Actions

ALBs can redirect clients from one URL to another, crucial for security, SEO, and user experience.

  • •
    HTTP to HTTPS: Automatically redirect all HTTP requests to their secure HTTPS equivalent.
  • •
    URL Canonicalization: Redirect old or deprecated URLs to new, standardized ones.
  • •
    Status Codes: Use 301 Moved Permanently or 302 Found to inform clients and search engines.

This ensures consistent access and helps maintain search engine optimization.

Key Takeaway

URL redirection is a powerful ALB feature for enforcing security best practices and maintaining a clean, accessible web presence.

Example Scenario

Enforcing HTTPS

Redirect all incoming HTTP traffic to HTTPS for enhanced security.

ALB HTTP Listener (Port 80) Rule:
  Condition: Path is '/*' (all requests)
  Action: Redirect
    Protocol: HTTPS
    Port: 443
    Status Code: HTTP_301

This rule ensures that any user attempting to access your site via HTTP is automatically and permanently redirected to the secure HTTPS version.

Common Mistake

Be cautious of infinite redirect loops, especially when configuring HTTP to HTTPS or canonicalization rules. Always test thoroughly.
