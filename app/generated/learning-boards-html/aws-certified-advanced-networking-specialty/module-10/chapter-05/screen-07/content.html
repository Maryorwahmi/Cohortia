Fixed Response Action

Configure a rule to return a custom HTTP response directly from the ALB, without forwarding to a target group.

  • •
    Block Traffic: Quickly return 403 Forbidden for specific IP ranges or malicious patterns.
  • •
    Maintenance Windows: Gracefully handle downtime with a 503 Service Unavailable response.
  • •
    Custom Messages: Include a custom message body to inform users or provide context.

This offloads response handling from backend servers and provides immediate feedback.

Key Takeaway

The Fixed Response Action is a powerful tool for rapid security enforcement and graceful application state management at the load balancer layer.

Example Scenario

Blocking Malicious IPs

Prevent traffic from a known malicious IP range from reaching your application.

ALB Listener Rule:
  Priority: 1 (highest)
  Condition: Source IP is '192.168.1.0/24'
  Action: Fixed Response
    Status Code: 403
    Content Type: text/plain
    Message Body: 'Access Denied: Malicious IP Detected'

This rule immediately blocks requests from the specified IP range, protecting your backend resources.

Pro-Tip

Combine Fixed Response with WAF for more sophisticated blocking logic, using WAF for pattern matching and ALB for direct responses.
