CLI Example: HTTP to HTTPS Redirect

Configure an ALB listener rule to automatically redirect all HTTP traffic to HTTPS, enforcing secure communication.

  • •
    Listener ARN: Identify the ARN of your HTTP listener (e.g., on port 80).
  • •
    High Priority: Assign priority 1 to ensure this rule is evaluated first.
  • •
    Redirect Action: Specify Type=redirect with HTTPS protocol and port 443.
  • •
    Status Code: Use HTTP_301 for a permanent redirect, beneficial for SEO.
Key Takeaway

Implementing HTTP to HTTPS redirection at the ALB level is a fundamental security practice, ensuring all client-server communication is encrypted.

AWS CLI Code

Add HTTP to HTTPS Redirect Rule

# Assume HTTP_LISTENER_ARN is the ARN of your HTTP listener on port 80
HTTP_LISTENER_ARN="arn:aws:elasticloadbalancing:REGION:ACCOUNT:listener/app/cohortia-web-alb/ID/HTTP_LISTENER_ID"

aws elbv2 create-rule \
    --listener-arn $HTTP_LISTENER_ARN \
    --priority 1 \
    --conditions "Field=path-pattern,Values=['/*']" \
    --actions Type=redirect,RedirectConfig='{"Protocol":"HTTPS","Port":"443","StatusCode":"HTTP_301"}'

This command creates a rule on the HTTP listener to redirect all incoming requests to the HTTPS listener on port 443 with a 301 status code.

Pro-Tip

Always test your redirects thoroughly after configuration to ensure they behave as expected and avoid infinite loops.
