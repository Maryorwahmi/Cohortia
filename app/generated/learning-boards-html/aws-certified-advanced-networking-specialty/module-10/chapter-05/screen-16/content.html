Key Concepts (Continued)

More essential takeaways for advanced ALB routing.

Redirect Action

An ALB rule action that redirects client requests to a different URL, often used for HTTP to HTTPS redirection or URL canonicalization.

Blue/Green Deployment

A deployment strategy where a new version of an application (green) is deployed alongside the current version (blue), and traffic is switched instantly between them.

Canary Deployment

A deployment strategy where a small percentage of traffic is gradually shifted to a new version of an application, allowing for controlled testing and monitoring.

Summary Takeaway

URL redirection, Blue/Green, and Canary deployments are critical for managing application URLs and implementing safe, agile release processes.
