Component Hierarchy

The Building Blocks of Global Acceleration

Accelerator

Static Anycast IPs, global entry point

Listener

Defines ports and protocols (e.g., TCP 80, 443)

Endpoint Group

Region-specific, traffic dialing, health checks

Endpoint

ALB, NLB, EC2, Elastic IP (actual application resource)

Traffic Dialing

Control the percentage of traffic sent to an endpoint group in a specific region, useful for controlled rollouts.

Health Checks

Global Accelerator continuously monitors endpoint health to ensure traffic is only routed to healthy application instances.

Key Takeaway

The hierarchical structure of Global Accelerator components ensures precise control over global traffic routing and application availability.
