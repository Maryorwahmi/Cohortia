Custom Routing Definition

Deterministic Routing for Specific Needs

Custom Routing Accelerators allow explicit mapping of client source IP addresses and destination ports to specific private IP addresses and ports on EC2 instances.

  • •Provides deterministic routing, unlike standard accelerators.
  • •Simplifies management of large numbers of application instances.
  • •Crucial for maintaining session state in specific scenarios.
Key Use Case

Multi-player online gaming servers where specific players must consistently connect to specific game server instances.

Example: Gaming Servers

Ensuring Player-to-Server Consistency

  • •Guarantees a specific client always reaches a specific backend instance.
  • •Essential for maintaining game session state and consistent player experience.
  • •Bypasses traditional load balancer limitations for deterministic routing.
