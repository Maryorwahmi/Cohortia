AWS CLI Walkthrough

Step-by-Step Configuration Example

# 1. Create a Global Acceleratoraws globalaccelerator create-accelerator \    --name cohortia-global-app \    --ip-address-type IPV4 \    --enabled \    --query 'Accelerator.AcceleratorArn' --output text

# Get the static IP addresses assignedaws globalaccelerator describe-accelerator \    --accelerator-arn $ACCELERATOR_ARN \    --query 'Accelerator.IpSets[].IpAddresses' --output text

# 2. Create a Listener (e.g., TCP 80)aws globalaccelerator create-listener \    --accelerator-arn $ACCELERATOR_ARN \    --port-ranges FromPort=80,ToPort=80 \    --protocol TCP \    --client-affinity NONE \    --query 'Listener.ListenerArn' --output text

# 3. Create an Endpoint Group for a region (e.g., us-east-1)# Assume you have an ALB in us-east-1 (ALB_ARN_US_EAST_1)ALB_ARN_US_EAST_1="arn:aws:elasticloadbalancing:us-east-1:ACCOUNT:loadbalancer/app/cohortia-web-alb/ID"

aws globalaccelerator create-endpoint-group \    --listener-arn $LISTENER_ARN \    --endpoint-group-region us-east-1 \    --traffic-dial-percentage 100 \    --health-check-port 80 \    --health-check-protocol HTTP \    --health-check-path /index.html \    --health-check-interval-seconds 30 \    --threshold-count 3 \    --endpoint-configurations \        EndpointId=$ALB_ARN_US_EAST_1,Weight=100,ClientIPPreservationEnabled=true \    --query 'EndpointGroup.EndpointGroupArn' --output text
Accelerator Creation

Establishes the global entry point and assigns static Anycast IP addresses.

Listener Configuration

Defines the network ports and protocols that Global Accelerator will accept from incoming client connections.

Endpoint Group Setup

Associates a specific AWS region with the listener and configures the target application endpoints, including health checks.

Key Takeaway

The AWS CLI provides a programmatic way to define the entire Global Accelerator architecture, from global entry points to regional application endpoints.
