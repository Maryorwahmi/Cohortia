Key Concepts

Advanced Global Accelerator Terminology

Accelerator

The top-level resource in Global Accelerator, providing the static Anycast IP addresses that serve as the global entry point.

Listener

Defines the ports and protocols that Global Accelerator accepts from clients, acting as the initial traffic filter.

Endpoint Group

A collection of endpoints in a specific AWS region, associated with a listener, configurable with traffic dialing and health checks.

Summary Takeaway

These components form the structured architecture of Global Accelerator, enabling precise control over global traffic routing and application endpoint management.
