Endpoint Compatibility

Connecting to Your AWS Resources

Application Load Balancers (ALBs)

Ideal for web applications and APIs requiring Layer 7 routing and SSL/TLS termination.

Network Load Balancers (NLBs)

Perfect for high-performance TCP/UDP applications or services needing static regional IPs.

EC2 Instances

For direct routing to instances, typically bypassing load balancers or for specific requirements.

Elastic IPs (EIPs)

Can be used as endpoints for specific, single-instance applications requiring a fixed public IP.

Seamless Integration

Global Accelerator acts as a global front-end, directing traffic to your existing regional AWS resources.

Architectural Flexibility

Supports diverse application architectures, from simple web servers to complex microservices, enhancing their global reach.

Key Takeaway

Global Accelerator's broad endpoint compatibility allows you to enhance the global performance and availability of nearly any application hosted on AWS.
