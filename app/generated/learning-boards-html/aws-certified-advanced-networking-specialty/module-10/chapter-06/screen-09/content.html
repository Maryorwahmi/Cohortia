Standard Accelerator Definition

Optimizing Performance and Availability

Standard Accelerators are the most common type, designed to improve application performance and availability by routing traffic to optimal healthy endpoints.

  • •Automatically directs users to the best regional endpoint.
  • •Considers endpoint health, client location, and configured weights.
  • •Ideal for general web applications and APIs.
Key Use Case

Ensuring global users connect to the fastest and most reliable application instance available, without requiring specific client-to-server mapping.

How Routing Works

Dynamic Selection for Best User Experience

  • •Traffic is routed to the 'best' endpoint based on real-time conditions.
  • •Ensures high availability by automatically failing over to healthy endpoints.
  • •Simplifies global traffic management for most common application patterns.
