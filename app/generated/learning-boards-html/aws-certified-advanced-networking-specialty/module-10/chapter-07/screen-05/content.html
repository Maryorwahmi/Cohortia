WAF Architecture

Web ACLs and Rules: The Foundation of WAF

Web ACLs are the main containers for your WAF rules, associated with your ALB to control incoming traffic. Rules define specific conditions for WAF to evaluate.

Web ACLs Explained

A Web ACL is a collection of rules that you associate with an AWS resource like an Application Load Balancer. It specifies the default action (allow or block) for requests that don't match any rules.

Rule Evaluation

WAF evaluates rules in the order you define them. The first rule that matches a request and has a BLOCK action will stop further processing.

Key Takeaway

Understanding Web ACLs and granular rule types is fundamental to building effective WAF protection for your applications.
