Rate-based Rules: Throttling Malicious Traffic

A powerful WAF feature to mitigate DDoS attacks and brute-force attempts by blocking excessive requests from a single IP address.

How it Works

You define a threshold for requests from a single IP within a five-minute period. If exceeded, WAF blocks subsequent requests from that IP.

Example Scenario

An attacker launches a Layer 7 DDoS attack, sending 3000 requests per minute from a single IP. A rate-based rule set to 2000 requests/5min would quickly block this IP.

Key Takeaway

Rate-based rules are essential for protecting against application-layer DDoS attacks, ensuring your services remain available to legitimate users.
