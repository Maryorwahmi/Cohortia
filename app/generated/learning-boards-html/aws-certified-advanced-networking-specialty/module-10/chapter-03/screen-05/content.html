NLB Performance & Flow-Based Routing

Achieving Ultra-Low Latency and High Throughput

  • Direct Packet Forwarding: NLB forwards packets directly to targets without inspecting application-level content, minimizing overhead.
  • Flow-Based Routing: Once a target is selected, subsequent packets for that connection flow directly between the client and target, bypassing the NLB.
  • Ultra-Low Latency: Achieves latency in microseconds, critical for real-time applications like gaming and HPC.
  • High Throughput: Capable of handling millions of requests per second, making it suitable for demanding workloads.
Key Takeaway

NLB's Layer 4 flow-based routing ensures minimal latency and maximum throughput, making it ideal for high-performance, real-time applications.
