Static IP Use Cases

Where Fixed Endpoints Make a Difference

  • DNS Integration: Create A records pointing directly to NLB's static EIPs, simplifying DNS management and resolution.
  • Firewall Whitelisting: On-premises firewalls can whitelist specific NLB EIPs, enabling secure and predictable hybrid cloud connectivity.
  • Legacy Systems: Support older systems or protocols that require fixed IP endpoints and cannot resolve dynamic DNS names.
Key Takeaway

NLB's static IPs are crucial for simplifying DNS, enabling secure hybrid connectivity via firewall whitelisting, and ensuring compatibility with legacy systems.
