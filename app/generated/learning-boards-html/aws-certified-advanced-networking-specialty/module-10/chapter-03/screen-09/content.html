Client Source IP Preservation

Maintaining True Client Identity

  • Direct IP Pass-Through: NLB passes the client's original source IP directly to the target instances.
  • Critical for Logging: Ensures accurate logging and analytics based on the true client origin.
  • Simplified Security: Enables straightforward implementation of IP-based access controls and security policies.
  • Contrast with ALB: ALBs proxy connections and pass client IP in `X-Forwarded-For` headers, requiring application-level parsing.
Key Takeaway

NLB's preservation of client source IP simplifies security, logging, and analytics by providing direct visibility into the true origin of network requests.

NLB directly passes the client's original IP to the target.
Pro-Tip

For TLS listeners performing termination, the NLB acts as a proxy, and the target will see the NLB's private IP. Consider end-to-end encryption or proxy protocol for client IP preservation in this specific scenario.
