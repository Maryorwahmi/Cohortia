NLB vs. ALB: The Core Distinction

Understanding Layer 4 vs. Layer 7 Operation

Layer 4 (Transport Layer)

NLB forwards packets based on IP address and port. It does not inspect application content, ensuring ultra-low latency and high throughput.

Layer 7 (Application Layer)

ALB inspects HTTP/HTTPS headers and URL paths for intelligent routing. It offers content-based routing and advanced application features.

Key Takeaway

Choose NLB for raw performance and direct packet forwarding, and ALB for application-aware routing and advanced HTTP/HTTPS features.

Comparison: NLB vs. ALB
Network Load Balancer (NLB)
  • Layer 4 (TCP, UDP, TLS)
  • Millions of requests/sec
  • Microsecond latency
  • Static IP support (EIPs)
  • Preserves client IP
Application Load Balancer (ALB)
  • Layer 7 (HTTP, HTTPS)
  • Hundreds of thousands/sec
  • Millisecond latency
  • Dynamic IP addresses
  • Proxies client IP (X-Forwarded-For)
