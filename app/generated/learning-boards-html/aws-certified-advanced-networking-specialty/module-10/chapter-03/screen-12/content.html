Creating an NLB with Static IP (Part 1)

Target Group and Elastic IP Allocation

  • Create Target Group: Define a target group for TCP traffic on port 80, specifying your VPC ID and health check protocol.
  • Allocate Elastic IP (EIP): Allocate a static public IPv4 address to your AWS account for use with the NLB.
  • Capture ARNs/IDs: Note down the Target Group ARN and EIP Allocation ID/Public IP for subsequent NLB configuration.
Key Takeaway

Setting up an NLB begins with defining a target group for your backend instances and allocating Elastic IPs to ensure static, predictable network endpoints.

Terminal Output
# 1. Create a Target Group for TCP traffic
# Replace with your VPC ID and desired name
VPC_ID="vpc-0abcdef1234567890"
TG_NAME="cohortia-nlb-tcp-tg"
TG_ARN=$(aws elbv2 create-target-group \
    --name $TG_NAME \
    --protocol TCP \
    --port 80 \
    --vpc-id $VPC_ID \
    --health-check-protocol TCP \
    --health-check-port 80 \
    --query 'TargetGroups[0].TargetGroupArn' --output text)

echo "Target Group ARN: $TG_ARN"

# 3. Create an Elastic IP for the NLB
ALLOCATION_ID=$(aws ec2 allocate-address --domain vpc --query 'AllocationId' --output text)
EIP_ADDRESS=$(aws ec2 describe-addresses --allocation-ids $ALLOCATION_ID --query 'Addresses[0].PublicIp' --output text)
echo "Elastic IP: $EIP_ADDRESS, Allocation ID: $ALLOCATION_ID"
Pro-Tip

Always use descriptive names for your target groups and ensure your VPC ID is correct to avoid deployment errors.
