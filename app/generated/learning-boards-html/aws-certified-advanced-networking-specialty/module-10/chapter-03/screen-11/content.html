Common Mistakes with NLB

Avoiding Pitfalls in NLB Configuration

  • Assuming Layer 7 Intelligence: NLBs are Layer 4 only; they do not inspect HTTP headers or URL paths for routing.
  • Misconfigured Security Groups: Target instances' security groups must allow inbound traffic from NLB IPs or client IPs on the target port.
  • Invalid TLS Certificates: For TLS listeners, ensure the certificate is correctly associated and valid to prevent connection failures.
  • Basic Health Checks: NLB health checks are often basic (e.g., TCP port reachability); ensure they accurately reflect application health.
Key Takeaway

Always remember NLB's Layer 4 nature, configure target security groups correctly, validate TLS certificates, and understand health check limitations to avoid common deployment issues.
