Key Concepts: NLB Fundamentals

Essential takeaways from this chapter

Layer 4 Load Balancing

NLB operates at the transport layer (TCP/UDP/TLS), forwarding packets based on IP and port without inspecting application content.

Static IP Addresses

NLBs can use Elastic IP (EIP) addresses for each AZ, providing fixed, public entry points for applications, crucial for hybrid cloud.

Client Source IP Preservation

NLBs pass the client's original source IP directly to targets, vital for logging, security, and analytics.

Summary Takeaway

NLB's Layer 4 operation, static IP support, and client IP preservation make it the ideal choice for high-performance, low-latency, and hybrid cloud networking scenarios.
