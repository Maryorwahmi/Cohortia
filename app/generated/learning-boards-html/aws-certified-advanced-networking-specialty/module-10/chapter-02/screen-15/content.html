What to Remember

Key features for advanced ALB management.

Weighted Target Groups

Distribute traffic among multiple target groups based on specified weights, ideal for blue/green deployments and A/B testing.

Sticky Sessions (Session Affinity)

Ensures all requests from a specific client are consistently routed to the same target instance, maintaining session state.

SSL/TLS Termination

The ALB decrypts incoming HTTPS traffic and encrypts responses, offloading this computational burden from backend instances.

Security Policy

A predefined set of SSL/TLS protocols and ciphers that an ALB uses for secure connections, ensuring compliance and security.

Summary Takeaway

Mastering weighted target groups, sticky sessions, SSL/TLS termination, and security policies is crucial for building resilient, secure, and high-performing applications with ALBs.
