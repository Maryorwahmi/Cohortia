Advanced Routing

Path and Host-Based Routing

Directing traffic based on URL paths and domain names for microservices and multi-domain setups.

Path-Based Routing

Routes requests based on the URL path. Ideal for directing traffic to specific microservices or application components.

  • /api/v1/users/* → User Service
  • /images/* → Image Processing Service
Use Case

Enables independent scaling and deployment of microservices by segmenting traffic.

Host-Based Routing

Routes requests based on the Host header in the HTTP request. Useful for hosting multiple domains on a single ALB.

  • api.example.com → API Target Group
  • www.example.com → Web App Target Group
Use Case

Consolidates infrastructure by allowing multiple applications or environments to share one ALB.

Key Takeaway

Path-based and host-based routing are essential for building scalable, organized application architectures, supporting microservices and multi-domain hosting respectively.
