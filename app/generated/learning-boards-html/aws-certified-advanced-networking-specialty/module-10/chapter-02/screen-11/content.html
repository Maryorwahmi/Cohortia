Troubleshooting Common ALB Issues

Diagnosing and resolving problems with security groups, health checks, and SSL/TLS certificates.

Security Group Misconfigurations

  • ALB SG: Must allow inbound traffic on listener ports (e.g., 80, 443) from the internet.
  • Target SG: Must allow inbound traffic from ALB's security group on target group port (e.g., 80).

Failing Health Checks

  • Verify target instance's security group allows ALB traffic.
  • Ensure application is listening on correct port and path.
  • Check health check path and protocol in target group config.

SSL/TLS Certificate Issues

  • Ensure certificate is valid and not expired.
  • Verify certificate is issued for the correct domain name.
  • Confirm correct association with the HTTPS listener.
Key Takeaway

Systematic troubleshooting of security groups, health checks, and SSL/TLS configurations is essential for maintaining ALB functionality and application availability.
