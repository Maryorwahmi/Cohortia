Sticky Sessions: Maintaining User State

Ensuring consistent routing to the same backend instance for stateful applications.

What are Sticky Sessions?

A mechanism to ensure that all requests from a specific client are consistently routed to the same target instance, maintaining session state.

How it Works

  • ALB inserts a cookie (e.g., AWSELB) into the first response.
  • Subsequent client requests with this cookie are routed to the same target.
  • Can also use application-generated cookies.

Potential Drawbacks

Can hinder load balancing distribution and instance scaling, potentially creating 'hot spots' on certain instances.

Key Takeaway

Sticky sessions are vital for stateful applications but require careful consideration of their impact on load distribution and auto-scaling.
