Core Concept

ALB Routing Rules: Directing Traffic

How listeners use conditions and actions to route requests to target groups.

Rule Components

  • Conditions: Criteria for evaluating requests (e.g., path, host, headers).
  • Actions: What to do when conditions are met (e.g., forward to target group).
  • Priority: Determines evaluation order (lowest number = highest priority).

The Default Rule

Every listener has a default rule that processes requests if no other rules match. It acts as a fallback to a primary target group.

Example Scenario

Route /api/* requests to a microservice target group, while all other requests go to the main web application target group.

Key Takeaway

ALB routing rules provide granular control over traffic flow, enabling sophisticated application architectures through conditional forwarding to target groups.
