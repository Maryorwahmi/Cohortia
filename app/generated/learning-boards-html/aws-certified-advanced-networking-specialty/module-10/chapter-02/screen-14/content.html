Key Concepts

Essential takeaways from this deep dive.

Listener Rules

Conditions and actions associated with an ALB listener that determine how incoming requests are routed to target groups.

Path-Based Routing

Requests are directed to different target groups based on the URL path in the HTTP request, ideal for microservices.

Host-Based Routing

Requests are directed to different target groups based on the Host header, allowing multiple domains on one ALB.

HTTP Header-Based Routing

Routing requests based on the presence or value of specific HTTP headers, useful for A/B testing or client types.

Query Parameter-Based Routing

Routing requests based on specific query string parameters in the URL, for targeted deployments.

Summary Takeaway

ALB's advanced routing capabilities provide granular control over traffic, enabling flexible and scalable application architectures.
