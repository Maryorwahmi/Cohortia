Understanding Rule Priority

How ALBs evaluate routing rules to determine the correct target group.

Priority Order

Rules are evaluated from the lowest priority number (highest priority) to the highest. The first rule whose conditions are met is applied.

First Match Wins

Once a rule's conditions are met, its actions are executed, and no further rules are evaluated for that request. This ensures deterministic routing.

The Default Rule

If no custom rules match, the default rule is applied. It typically has the highest priority number (lowest actual priority) and acts as a fallback.

Key Takeaway

Understanding rule priority is critical for predictable traffic management; more specific rules should have lower priority numbers to be evaluated first.
