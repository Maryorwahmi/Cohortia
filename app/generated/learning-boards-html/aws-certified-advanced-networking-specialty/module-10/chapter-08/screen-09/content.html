Granular Analysis with Access and Flow Logs

Troubleshooting, security, and network-level insights.

Why use logs?

CloudWatch metrics provide aggregated data; logs offer detailed, per-request or per-flow information essential for deep troubleshooting and auditing.

Storage & Analysis

Access logs are stored in Amazon S3 and can be queried using services like Amazon Athena or AWS Glue for efficient analysis.

Complementary Tools

Access logs focus on load balancer requests, while Flow Logs provide broader network traffic visibility within your VPC.

Log Types Comparison

Access Logs (ALB/NLB)

  • Client IP, request time, target IP, HTTP status.
  • Troubleshooting application errors.
  • Security auditing.
  • Understanding user behavior.

VPC Flow Logs

  • IP traffic records for network interfaces.
  • Diagnosing network connectivity.
  • Identifying security group issues.
  • Detecting unusual traffic patterns.
Key Takeaway

Access logs provide granular request-level data for ELBs, while VPC Flow Logs offer network-level traffic insights, both crucial for deep diagnostics and security.
