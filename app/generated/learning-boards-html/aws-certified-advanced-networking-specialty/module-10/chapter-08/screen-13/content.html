Key Concepts

Essential takeaways from this chapter.

Connection Draining

Allows a load balancer to stop sending new requests to a deregistering target while keeping existing connections open for a specified duration, enabling graceful shutdowns.

Idle Timeout

The maximum amount of time a load balancer waits for a response from a target before closing the connection, impacting resource use and application behavior.

LB Pre-warming

A process of requesting AWS Support to pre-scale an ALB's capacity to handle anticipated large traffic spikes, preventing initial performance degradation.

Summary Takeaway

Mastering connection draining, idle timeouts, and pre-warming ensures your load balancers provide a resilient and high-performing foundation for your applications.
