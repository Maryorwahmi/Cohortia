Core Components

Listeners, Target Groups, and Health Checks

The Building Blocks of Load Balancing

Key Functions
  • Listener: Checks for connection requests on a configured protocol and port.
  • Target Group: A logical grouping of backend resources (instances, IPs, etc.).
  • Health Check: Periodically tests target health to ensure availability.
  • Automated Failover: Load balancer stops sending traffic to unhealthy targets.
Key Takeaway

Listeners, target groups, and health checks are the essential components that enable load balancers to distribute traffic reliably and maintain application availability.

Example Workflow

A client request flows through the ELB as follows:

Client sends request to the load balancer's IP/DNS.
The Listener on the load balancer accepts the request.
The Listener forwards the request to a Target Group based on rules.
The Target Group selects a healthy target instance based on health checks.
Why it Matters

These components are critical for ensuring that traffic is directed only to healthy backend resources, preventing application downtime and improving user experience.
