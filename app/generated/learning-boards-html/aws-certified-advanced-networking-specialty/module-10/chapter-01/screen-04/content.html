Core Concept

Application Load Balancer (ALB)

Intelligent Routing at the Application Layer (Layer 7)

Key Features
  • Operates at Layer 7 (HTTP/HTTPS).
  • Supports content-based routing (URL path, host header, query params).
  • Ideal for microservices and web applications.
  • Supports sticky sessions and TLS termination.
  • Integrates with AWS WAF and Auto Scaling.
Key Takeaway

ALBs provide advanced, content-aware routing for HTTP/HTTPS traffic, making them perfect for modern microservices architectures.

Example Scenario

A large e-commerce platform uses an ALB to route incoming requests:

Requests to `/api/users` go to the User Service backend.
Requests to `/images/*` go to the Image Processing Service.
Requests to `/checkout` go to the Order Processing Service.
Common Misconception

ALBs are not suitable for raw TCP/UDP traffic or when static IP addresses are a strict requirement, as NLBs excel in those areas.
