Core Concept

Network Load Balancer (NLB)

Extreme Performance at the Transport Layer (Layer 4)

Key Features
  • Operates at Layer 4 (TCP, UDP, TLS).
  • Optimized for extreme performance and low latency.
  • Provides static IP addresses per Availability Zone.
  • Preserves client source IP address.
  • Ideal for high-throughput, high-performance applications.
Key Takeaway

NLBs deliver unparalleled speed and static IP addresses at Layer 4, making them perfect for performance-critical and hybrid connectivity scenarios.

Example Scenario

A company uses an NLB for its online gaming platform:

The NLB handles millions of TCP connections per second with minimal latency.
On-premises gaming servers connect to the NLB's static IP addresses.
The original client IP is preserved for accurate player tracking.
Common Misconception

NLBs cannot perform content-based routing like ALBs, making them unsuitable for complex microservices that require application-level decision-making.
