Process
Systematic Troubleshooting Approach
1. Verify symptoms and timeframe.
2. Check health checks and target states.
3. Review CloudWatch metrics for anomalies.
4. Query access logs for per-request evidence.
5. Inspect SGs, NACLs, and routes.
6. Test connectivity with curl/telnet/netcat.
7. Check application logs last and verify fixes.
Pro-tip
Capture metrics and logs before making changes so you can validate whether your actions resolved the issue.
Example checklist
  1. Document symptom, affected LB and TG names, and the exact timestamps.
  2. Check UnHealthyHostCount and HTTPCode_* metrics during that window.
  3. Query access logs for matching timestamps and request paths.
  4. Run curl from an EC2 in the same VPC to the target health path.
  5. Fix application or security rules and re-observe metrics and health status.
