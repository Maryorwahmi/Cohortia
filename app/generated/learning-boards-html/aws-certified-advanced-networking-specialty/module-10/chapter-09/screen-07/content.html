Definition
Analyzing Access Logs
Use access logs for per-request visibility and to correlate timestamps and response codes with CloudWatch metrics.
ALB logs: client IP, request time, elb_status_code, target_status_code, request processing time.
NLB logs: connection status, source/destination IP and ports, bytes transferred.
Athena query example
SELECT elb_status_code, target_status_code, count(*) as cnt
FROM alb_logs
WHERE load_balancer = 'cohortia-web-alb' AND date BETWEEN '2023-01-01' AND '2023-01-01'
GROUP BY elb_status_code, target_status_code
ORDER BY cnt DESC;
Investigation tips
  • Filter logs to the metric spike window for precise correlation.
  • Look for client IPs generating many errors to detect abuse or misconfiguration.
  • Compare elb_status_code and target_status_code to locate the origin of the error.
Common mistake
Relying only on aggregated metrics can miss per-request anomalies and intermittent failures visible only in the access logs.
