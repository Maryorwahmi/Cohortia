CloudWatch Metrics for ALBs
Use grouped metrics to pinpoint whether the load balancer or targets are the source of errors.
HTTPCode_ELB_5XX_Count — errors from the ALB itself, often no healthy targets.
HTTPCode_Target_5XX_Count — backend application errors; check application logs and resource usage.
TargetConnectionErrorCount — connection failures between ALB and targets; check SGs and NACLs.
HealthyHostCount / UnHealthyHostCount — fast indicator whether targets pass health checks.
Concrete example
If HTTPCode_ELB_5XX_Count spikes and UnHealthyHostCount increases, check the target group. If the target returns 502 on health checks, inspect the service and its logs.
Quick metric comparison
When ELB metric up
Suspect load balancer-level issue or zero healthy targets.
When Target metric up
Suspect backend application errors or resource exhaustion.
High Latency
Investigate target performance, threads, DB calls, or network congestion.
TLS negotiation errors
For HTTPS, ClientTLSNegotiationErrorCount shows handshake problems between client and ALB.
Pro-tip
Always correlate at least two metrics before changing infrastructure: a single spike rarely tells the full story.
