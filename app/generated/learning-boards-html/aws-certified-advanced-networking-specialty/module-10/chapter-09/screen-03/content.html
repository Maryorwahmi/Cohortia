Learning Objectives — Skills & Tools
Understand which metrics and logs to query, and how they map to root causes.
CloudWatch mapping
  • HTTPCode_ELB_5XX_Count → load balancer level issues such as no healthy targets.
  • HTTPCode_Target_5XX_Count → backend application errors; inspect application logs.
  • HealthyHostCount / UnHealthyHostCount → health check failures driving routing problems.
Logs & network checks
  • Access logs provide per-request traceability; use Athena for queries.
  • VPC Flow Logs reveal blocked IP traffic caused by SG or NACL rules.
  • TargetConnectionErrorCount indicates connection setup failures between LB and targets.
