Diagnosing Network Path Issues
Walk the full network path from client to load balancer to target.
Security groups: ALB must allow listener ports; targets must allow from ALB SG or appropriate IP ranges.
Network ACLs: allow inbound and outbound on health and ephemeral ports; stateless rules require both directions.
Route tables: ensure internet-facing LBs have correct internet gateway routes; internal LBs route to target subnets.
DNS & connectivity: verify DNS resolves and test direct IP connectivity for NLBs with static IPs.
Use VPC Flow Logs
Enable Flow Logs to capture accept or reject entries for traffic between LB and targets. This is often decisive when SGs and NACLs disagree.
Diagnostic checklist
  • Confirm LB listeners open to client ranges.
  • Confirm target SG allows LB source (ALB SG or NLB IP/VPC CIDR).
  • Confirm NACL inbound/outbound for health and ephemeral ports.
  • Check route tables and DNS resolution.
  • Enable VPC Flow Logs and inspect accept/deny patterns.
