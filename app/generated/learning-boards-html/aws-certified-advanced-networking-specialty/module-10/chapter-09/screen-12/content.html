Testing Connectivity and Verifying Fixes
Use concrete tests and log evidence to confirm a fix worked as expected.
Connectivity tests: curl, telnet, nc from EC2 in same VPC and load balancer subnet.
Metric verification: confirm UnHealthyHostCount and 5xx counts return to baseline.
Log confirmation: query access logs for successful response codes at the expected timestamps.
Flow logs: ensure accept entries replace previously denied traffic after SG/NACL changes.
Final tip
Document the change, timestamp it, and capture before-and-after metrics so you can roll back if the fix had unexpected impact.
Quick verification checklist
  • Health check shows Healthy.
  • CloudWatch 5xx and UnHealthyHostCount returned to baseline.
  • Access logs show successful responses for the same requests.
  • VPC Flow Logs show accepted traffic if you modified network rules.
