CloudWatch Metrics for NLBs
NLB metrics show connection-level behaviors and help narrow network vs target faults.
TCP_Target_Reset_Count — indicates connections reset by the target or network device.
UDP_Target_Dropped_Count — packets dropped by the target or not processed.
TargetConnectionErrorCount — failures establishing TCP connections from NLB to targets.
ConsumedLCUs — capacity metric; spikes can indicate traffic surges or scaling needs.
Practical check
If TCP resets increase, validate the target's listener process, OS socket limits, and security group rules allowing response ports. Remember NLB preserves client IPs, so target SG rules must account for client source addresses or VPC CIDR patterns.
Checklist
  • Confirm target process listening on correct port and binding to correct interface.
  • Check security group inbound rules for client IP ranges or VPC CIDR if source preservation applies.
  • Review Network ACLs on target subnets for both inbound and outbound ephemeral port rules.
  • Enable VPC Flow Logs for packet-level confirmation of blocked traffic.
