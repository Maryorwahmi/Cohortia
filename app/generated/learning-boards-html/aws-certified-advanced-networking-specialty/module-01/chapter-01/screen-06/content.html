Module 1 › Chapter 1.1 › VPC Quotas
Core limits to consider
  • ENIs per instance type — impacts how many network interfaces and IPs your nodes can have.
  • Security groups per ENI and rules per security group — limits shape firewall strategy.
  • Number of route entries and peering attachments — affects complex routing topologies.
Mitigations
  1. Consolidate rules and use prefix lists where many CIDRs are needed.
  2. Choose instance types with appropriate ENI counts or use fewer ENIs per host.
  3. Leverage Transit Gateway to centralize routes and reduce peer-count complexity.
Scenario

If an application requires many inbound ports for monitoring, you may hit a 60-rule security group limit. Instead of creating dozens of per-port rules, use a prefix list or multiple security groups scoped by function to stay within limits.

Pro tip

Inventory expected quotas during design and add quota alarms. If quotas are likely to be reached, request increases early or adapt architecture to reduce count pressure.

Key Takeaway

Quotas shape architecture. Plan for limits at design time, not after deployment failures appear.
