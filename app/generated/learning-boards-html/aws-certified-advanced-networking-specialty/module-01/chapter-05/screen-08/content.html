Module 1 › Chapter 1.5 › Deployment Models
Centralized Inspection
Use a Transit Gateway and an Inspection VPC that hosts Network Firewall or GLB with appliances. Application VPCs route to the Transit Gateway. Central policy, centralized logging, but more routing complexity and single inspection path to scale.
  • • Best for uniform perimeter filtering and third‑party appliance chaining.
  • • Requires careful TGW route table and capacity planning.
Distributed Inspection
Deploy Network Firewall endpoints in each application VPC. Simpler routing, localized inspection, but operational overhead managing policies across many endpoints.
  • • Best when low-latency local inspection matters or VPCs have different policies.
  • • Increases policy distribution effort and potential inconsistency.
Key Takeaway

Choose centralized inspection for consistent controls and third‑party chains; choose distributed to reduce routing complexity and localize performance.
