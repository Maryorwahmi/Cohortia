Module 1 › Chapter 1.5 › Assessment
Scenario 1
Some HTTP blocked, some allowed in centralized inspection. Check stateless Drop rules, GLB target health, and potential asymmetric routing.
Scenario 2
ICMP fails after deploy but HTTP succeeds. Likely a stateless ICMP Drop—confirm rule intent and exceptions for monitoring hosts.
Scenario 3
Appliances receive no traffic. Verify GLB endpoint routing, Security Groups/NACLs for GENEVE, and target group health checks.
Key Takeaway

A reproducible troubleshooting sequence—stateless rules, routes, SG/NACLs, GLB health, capacity—finds most failures quickly.
