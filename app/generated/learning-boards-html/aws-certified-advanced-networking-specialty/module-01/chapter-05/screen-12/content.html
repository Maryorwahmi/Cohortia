Console-style steps (conceptual)
1) Create stateless rule group: block-icmp-stateless - Type: Stateless - Default action: Pass - Add rule: Priority 100, Action: Drop, Protocol: ICMP, Source/Dest: 0.0.0.0/0 2) Create firewall policy: my-first-firewall-policy - Add stateless group: block-icmp-stateless 3) Create Network Firewall: my-vpc-firewall - VPC: my-advanced-networking-vpc - Policy: my-first-firewall-policy - Subnets: firewall-subnet-az1, firewall-subnet-az2 4) Update route tables: - App subnet route 0.0.0.0/0 -> firewall endpoint ENI - Firewall subnet route 0.0.0.0/0 -> Internet Gateway
Verification checklist
  • • Endpoint status: Ready and ENI IDs visible.
  • • App instance fails ping to public IP but can curl web pages if allowed.
  • • Firewall subnet has IGW route for outbound traffic.
  • • Security Groups/NACLs permit inspection flows and management traffic.
Key Takeaway

Follow a route-then-policy-then-verify order. Route traffic through endpoints, attach policies, then validate with both ICMP and HTTP checks.
