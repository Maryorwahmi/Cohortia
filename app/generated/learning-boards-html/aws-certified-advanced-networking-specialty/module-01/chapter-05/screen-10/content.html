Module 1 › Chapter 1.5 › Inspection VPC Pattern
Architecture

Transit Gateway → Inspection VPC → GLB / Appliances

Steps to implement: connect Application VPCs and Inspection VPC to a Transit Gateway, configure the Transit Gateway route table to send 0.0.0.0/0 to the Inspection VPC attachment, place GLB endpoints and appliance ENIs in the Inspection VPC, and configure their subnets with an Internet Gateway route for outbound traffic.
Scaling
Use multiple appliances across AZs and GLB target groups with health checks to distribute load and handle failures.
Asymmetric routing risk
Ensure return traffic is routed through the same inspection path; otherwise appliances may see only half the session and breaks will occur.
Scenario
You need a central NGFW that sees original source IPs for threat correlation. Deploy GLB in Inspection VPC and third‑party NGFWs as EC2 appliances in target groups to preserve headers and enable full inspection.
Key Takeaway

Transit Gateway plus an Inspection VPC gives centralized inspection. Plan routes and scaling carefully to avoid asymmetric flows and performance issues.
