Module 1 › Chapter 1.5 › Gateway Load Balancer
Core Concept

Transparent appliance insertion with GENEVE

  • • GLB endpoints receive traffic and encapsulate it using GENEVE to target appliance ENIs.
  • • Appliances see original packet headers so inspection is transparent and accurate.
  • • Target groups contain ENIs of EC2 appliances and must have health checks configured.
Operational note
Permit GENEVE and required flows in Security Groups and NACLs. Configure target group health checks so GLB routes traffic only to healthy appliances. Monitor appliance capacity to avoid creating a bottleneck in the inspection chain.
Key Takeaway

Use GLB when third‑party appliances must see original headers; configure health checks and network rules for GENEVE carefully.
