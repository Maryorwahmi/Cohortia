Module 1 › Chapter 1.5 › Common Mistakes
Routing
Verify app subnet routes send 0.0.0.0/0 to the firewall endpoint or TGW. Verify IGW route exists in the firewall subnet route table for outbound traffic.
Security Rules
Allow GENEVE protocol and any ports required by appliances in Security Groups and NACLs; otherwise GLB cannot communicate with targets.
Rule Order
Stateless rules run before stateful rules. A Drop in stateless will block traffic permanently unless the stateless group is changed.
Key Takeaway

A small checklist—routes, SG/NACLs, stateless rule review, and capacity tests—will catch most inspection failures before they impact production.
