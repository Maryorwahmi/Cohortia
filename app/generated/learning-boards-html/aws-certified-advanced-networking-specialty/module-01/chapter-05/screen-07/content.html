Module 1 › Chapter 1.5 › Policies & Routing
Process

Create rule groups → policy → firewall endpoints → update routes

  1. Create stateless and stateful rule groups with proper actions and priorities.
  2. Assemble rule groups into a firewall policy and set defaults.
  3. Create a firewall resource in your VPC and select subnets per AZ for endpoints.
  4. Update application subnet routes so 0.0.0.0/0 points to the firewall endpoint.
  5. Ensure firewall subnet routes send outbound to an Internet Gateway.
Checks & Example
Verify route tables: the app subnet route for default traffic should target the firewall endpoint. Then verify the endpoint subnet has a route to the Internet Gateway. If either direction is missing, traffic will either bypass inspection or be dropped after inspection. Also confirm ENI IDs and endpoint readiness.
Troubleshooting
If legitimate traffic is blocked, check for stateless drops first, then confirm stateful allow rules and route symmetry.
Key Takeaway

Firewall policy enforces rules, but routing mistakes are the primary cause of inspection failures. Verify both forward and return routes.
