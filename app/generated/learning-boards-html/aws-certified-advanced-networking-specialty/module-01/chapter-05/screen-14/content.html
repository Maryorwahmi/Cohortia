Module 1 › Chapter 1.5 › Key Concepts
AWS Network Firewall
Managed, highly available service for stateful inspection, IPS, and web filtering for VPC traffic.
Stateless Rule Group
Inspects individual packets quickly; processed before stateful rules. Drops here are final for the packet.
Stateful Rule Group / Suricata
Inspects traffic with session context and supports Suricata-compatible signatures for IPS-style detection.
Takeaway
Remember: rule order, routing, and health checks are operational priorities when deploying Network Firewall and GLB.
