Module 2 › Chapter 1.6 › Hands-on Activity
Activity steps
  1. Create or confirm an S3 bucket in the same region and set a bucket policy allowing Flow Logs to write.
  2. Create an IAM role VPCFlowLogsToS3Role with S3 write permissions and update the trust policy to allow vpc-flow-logs.amazonaws.com.
  3. In the VPC console select your VPC, create a Flow Log with filter All, destination S3, supply bucket ARN and IAM role.
  4. Wait for objects to appear in the S3 prefix and then create an Athena external table pointing to that location using the provided DDL.
  5. Run SQL to find rejected connections for incident analysis.

Pro tip
Use a predictable S3 prefix and consider compressing logs to reduce Athena scan costs when you query large datasets.
