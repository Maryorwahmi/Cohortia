Module 2 › Chapter 1.6 › What is Traffic Mirroring?
Core components
Mirror Source
An ENI whose traffic you capture, such as a web server's primary ENI.
Mirror Target
NLB or ENI of a monitoring instance that receives mirrored traffic for analysis.
Mirror Filter
Rules to select traffic by protocol, ports, or CIDR to reduce mirrored volume.
Why use mirroring?

Use Traffic Mirroring when you need payload visibility for DPI, intrusion detection, forensic analysis, or protocol-level troubleshooting that metadata can't reveal.

Operational notes
  • Mirrored traffic can be heavy; apply filters to limit volume.
  • Ensure target security groups and NACLs allow GENEVE (UDP 6081).
  • Targets must have capacity to process mirrored streams.
Use case
Mirror web and backend traffic to an IDS to detect malware patterns inside payloads that Flow Logs cannot show.
