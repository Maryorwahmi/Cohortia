Feature comparison
FeatureVPC Flow LogsTraffic Mirroring
Data CapturedMetadata: IPs, ports, proto, action, bytesFull packet content (payload)
PurposeMonitoring, troubleshooting, auditingDeep packet inspection, IDS/IPS, forensics
OverheadLowHigher
ComplexityLowerHigher; needs monitoring tools
Decision guide
If you need to find blocked or rejected connections quickly, start with Flow Logs. If you need to inspect payloads for compliance or malware detection, choose Traffic Mirroring and plan target capacity and filters carefully.
Example
Use Flow Logs to identify suspicious IPs, then mirror relevant traffic for payload inspection on those flows.
Misconception
Don't assume Flow Logs show payloads; they only show metadata. For payloads, use mirroring.
