Module 2 › Chapter 1.6 › Mirroring Setup
Step-by-step session creation
1. Identify Mirror Source
Select the ENI(s) whose traffic you need to inspect.
2. Provision Mirror Target
Choose an ENI on a monitoring instance or an NLB to distribute streams.
3. Create Mirror Filter
Define rules for protocol, ports, and CIDR to limit mirrored traffic.
After these components exist, create Traffic Mirror Sessions linking sources to a target using the filter. Tune sessions by sampling, applying filters, or scaling targets behind an NLB for higher throughput.
Operational requirement
Allow UDP 6081 (GENEVE) in the target's security group and NACL for mirror traffic to arrive.
Pitfall
Failing to provision target capacity results in packet drops and incomplete inspection.
