Module 2 › Chapter 1.6 › Enable Flow Logs
Choose scope
  1. VPC Level: All ENIs in the VPC — broad visibility for trends and security auditing.
  2. Subnet Level: All ENIs in a subnet — focused on an application tier or security zone.
  3. ENI Level: Single ENI — targeted troubleshooting for a specific instance.
Decision mnemonic
Broad for trends, narrow for incidents. Balance cost vs. need.
Select destination
CloudWatch Logs
Near real-time queries and alerts with Logs Insights.
Amazon S3
Cost-effective archival and Athena analysis for historical data.
Kinesis Data Firehose
Stream logs to Redshift, Splunk, or custom endpoints for near real-time processing.
Practical note: when creating a Flow Log you must also configure the IAM role and ensure the destination accepts writes. Overlapping Flow Logs are possible but cost more — scope carefully.
Example
Use VPC-level logs for a centralized security feed; use ENI-level logs to troubleshoot an application instance with repeated rejects.
Common mistake
Enabling multiple overlapping scopes without a retention or cost plan leads to unexpected charges.
