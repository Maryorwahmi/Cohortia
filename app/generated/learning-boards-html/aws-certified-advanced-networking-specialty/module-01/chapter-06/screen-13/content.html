Module 2 › Chapter 1.6 › Assessment: Rejected Connections
Question

Your security team suspects data exfiltration from an EC2 instance in a private subnet. Identify all outbound connections from the instance that were rejected in the last hour, including destination IP and port. Which tool and query will you use?

Correct approach
Use VPC Flow Logs stored in CloudWatch Logs and run a Logs Insights query filtering for the instance's ENI with action = "REJECT". Sort by timestamp and display key fields to find the most recent rejected outbound attempts.
Example CloudWatch Logs Insights query
filter interfaceId = "eni-xxxxxxxxxxxxxxxxx" | filter action = "REJECT" | sort @timestamp desc | display @timestamp, srcAddr, dstAddr, dstPort, protocol, action
Assessment tip
Confirm the correct ENI for the instance. If logs are in S3 instead, use Athena and the same logic with SQL WHERE action = 'REJECT'.
