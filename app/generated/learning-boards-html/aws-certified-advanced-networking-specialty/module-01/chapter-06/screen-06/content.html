Athena DDL (example)
Use this DDL as a starting point. Replace the LOCATION with your S3 bucket path for the Flow Logs.
CREATE EXTERNAL TABLE IF NOT EXISTS vpc_flow_logs (
  version int,
  accountid string,
  interfaceid string,
  srcaddr string,
  dstaddr string,
  srcport int,
  dstport int,
  protocol int,
  packets int,
  bytes bigint,
  starttime bigint,
  endtime bigint,
  action string,
  logstatus string,
  vpcid string,
  subnetid string,
  instanceid string,
  tcpflags int,
  type string,
  pktsrcaddr string,
  pkt_dst_addr string,
  region string,
  azid string,
  sublocationid string,
  sublocationtype string
)
ROW FORMAT DELIMITED
FIELDS TERMINATED BY ' '
LOCATION 's3://my-flow-logs-bucket-12345/AWSLogs/your-account-id/vpcflowlogs/your-region/'
TBLPROPERTIES ("skip.header.line.count"="1");
Sample Athena query
Use SQL to find top rejected connections, grouping by source and destination.
SELECT srcaddr, dstaddr, dstport, action, COUNT(*) as connection_count
FROM vpc_flow_logs
WHERE action = 'REJECT'
GROUP BY srcaddr, dstaddr, dstport, action
ORDER BY connection_count DESC
LIMIT 10;
Best practices
  • Ensure IAM role trust policy allows vpc-flow-logs.amazonaws.com to assume it.
  • Confirm S3 bucket policy permits write from the Flow Logs service.
  • Consider compression and partitioning to reduce Athena scan costs.
Key Takeaway
Archival to S3 plus Athena gives powerful historical analysis, but requires correct IAM and bucket policies and attention to data layout for cost efficiency.
