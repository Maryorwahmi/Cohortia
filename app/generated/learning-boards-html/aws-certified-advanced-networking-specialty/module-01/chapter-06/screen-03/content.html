Applied Skills

Each objective maps to a concrete task: enable Flow Logs, write queries, mirror specific traffic, or centralize logs for auditing. Practicing these tasks builds operational fluency.

CloudWatch Logs Insights
Write queries to filter actions like REJECT and display source, destination, and ports for fast incident triage.
VERIFIED COMPETENCY MILESTONE
Athena on S3
Create a table for archived Flow Logs and run SQL queries to analyze historical trends or compliance evidence.
VERIFIED COMPETENCY MILESTONE
Mirror Filters & Targets
Define filters to capture only relevant ports and route mirrored traffic to a monitored target behind an NLB or to a monitoring instance.
VERIFIED COMPETENCY MILESTONE
Centralized Design
Plan a central logging account or security VPC to aggregate Flow Logs and mirrored streams for consolidated analysis.
VERIFIED COMPETENCY MILESTONE
Real-world check
When logs must be kept for audits, choose S3. When you need alerts and near real-time investigation, choose CloudWatch Logs. When payload inspection is required, use Traffic Mirroring with appropriate filters.
