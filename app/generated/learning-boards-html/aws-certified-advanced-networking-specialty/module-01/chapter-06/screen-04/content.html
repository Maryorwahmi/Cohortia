Module 2 › Chapter 1.6 › What are VPC Flow Logs?
Definition

VPC Flow Logs capture metadata for IP traffic to and from ENIs in a VPC. They show addresses, ports, protocol, bytes, packets, start and end times, and the action field that marks ACCEPT or REJECT.

Fields
  • src/dst IP and ports
  • protocol, bytes, packets
  • start/end time, ACTION
Common uses
Troubleshooting, security auditing, and traffic analysis.
Example
Find rejected SSH attempts by filtering for action="REJECT" and dstPort=22 in your log queries.
Metaphor

Think of Flow Logs as a network traffic ledger: they record who tried to talk to whom and whether the attempt worked, but they don’t record the conversation itself.

Concrete scenario
If an instance owner reports failing connections, query Flow Logs for that instance's ENI and look for REJECT actions to quickly identify whether a security control blocked the traffic.
Key Takeaway

Flow Logs provide essential metadata for fast triage and historical analysis, but not payload content.
