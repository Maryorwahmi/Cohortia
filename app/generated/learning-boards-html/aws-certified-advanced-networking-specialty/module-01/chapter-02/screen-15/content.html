Module 1 › Chapter 1.2 › Technical Terms
Transit Gateway Attachments
Connections from VPCs, VPNs, and Direct Connect to a TGW.
Transit Gateway Route Tables
TGW‑level routing domains used to control traffic between attachments with associations and propagation.
PrivateLink Endpoints
VPC Endpoint Service (provider) and Interface VPC Endpoint (consumer ENI) for private service connectivity.
Quick summary

Use this terminology to plan and document designs: attachment, association, propagation, route table, endpoint service, and interface endpoint.
