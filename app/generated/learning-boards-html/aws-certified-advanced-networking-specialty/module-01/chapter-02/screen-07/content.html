Concepts
Associations vs Propagation
Use associations to assign attachments to a TGW route table and propagation to allow a route table to learn attachment CIDRs automatically.
1. Create TGW route tables for segmentation e.g., Production and Development.
2. Associate attachments with the appropriate route table to control their view of other attachments.
3. Enable propagation from attachments you want the route table to learn automatically.
Troubleshooting prompts
If cross‑VPC traffic fails, check: VPC route tables point to the TGW attachment; the attachment is associated with the expected TGW route table; propagation is enabled for the remote attachment; and Security Groups permit traffic.
Example
Attach AppVPC to TGW and associate with Development route table. Ensure DataVPC propagates its CIDR into Development if you expect reachability.
Key Takeaway
Associations control which route table an attachment uses; propagation controls which routes that table learns — both are necessary for correct routing.
