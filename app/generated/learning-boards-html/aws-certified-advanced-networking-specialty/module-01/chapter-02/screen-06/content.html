Module 1 › Chapter 1.2 › Transit Gateway
Architecture
Hub‑and‑spoke network transit
TGW attaches VPCs and other networks, then controls how traffic flows using TGW‑specific route tables and propagation.
Attachments
Connections from VPCs, VPNs, Direct Connect gateways, and other TGWs.
TGW Route Tables
Segment traffic by associating attachments with specific route tables.
Route Propagation
Automatically learn attachment CIDRs into a TGW route table to simplify management.
Concrete scenario
Attach AppVPC (10.10.0.0/16) and DataVPC (10.20.0.0/16) to a TGW. Associate both attachments with the default TGW route table and enable propagation so the TGW learns both CIDRs. Update each VPC route table to point 10.20.0.0/16 or 10.10.0.0/16 to the TGW attachment. Now instances can communicate transitively through the TGW, subject to TGW routing rules and security controls.
Misconception
Assuming VPC route tables alone determine cross‑VPC flow. Both VPC and TGW route tables must be correct for connectivity to work.
Key Takeaway
TGW simplifies many‑VPC topologies by centralizing routing and enabling segmentation via multiple TGW route tables.
