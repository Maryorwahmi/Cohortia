Mesh math
N*(N-1)/2 connections
This formula gives the number of pairwise peering links needed for a full mesh. Each new VPC increases connections by N-1, where N is the resulting count of VPCs.
Operational implications
  • Route table updates across many VPCs create human error risks.
  • Security groups must be coordinated per connection, increasing policy sprawl.
  • Transitivity is not supported, so a mesh is the only way to allow arbitrary pairwise traffic.
Example
If you have 5 VPCs, full mesh peering requires 10 peering connections. Add VPC six and you jump to 15 connections. The management and troubleshooting effort increases sharply as you add VPCs.
Misconception
Assuming peering automatically forwards across peers leads to silent connectivity gaps. Always test pairwise reachability.
Key Takeaway
Peering is practical for a small set of VPCs; use hub approaches like Transit Gateway for many VPCs.
