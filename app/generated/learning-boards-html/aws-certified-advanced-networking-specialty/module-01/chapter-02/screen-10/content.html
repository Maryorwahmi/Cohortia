Module 1 › Chapter 1.2 › PrivateLink
Definition
Private service connectivity
PrivateLink lets consumers call services privately using interface endpoints that appear as ENIs in the consumer VPC and route traffic to a provider’s NLB-backed service.
Components
  • VPC Endpoint Service — created by the service provider and backed by an NLB.
  • Interface VPC Endpoint — created by the consumer, appears as ENIs in subnets.
  • Endpoint policies and security groups control access.
Example
A provider publishes an API behind a Network Load Balancer and creates a VPC Endpoint Service. Your account creates an Interface Endpoint in your subnets. Your application sends requests to the interface ENI's private IP and traffic flows over the AWS private backbone to the provider's NLB and service instances, never touching the public internet.
Misconception
PrivateLink is not a general routing fabric; it exposes services, not arbitrary VPC subnets or internet egress.
Key Takeaway
Use PrivateLink for secure service consumption across accounts without public endpoints or CIDR coordination.
