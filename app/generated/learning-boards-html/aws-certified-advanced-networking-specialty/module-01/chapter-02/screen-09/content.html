Module 1 › Chapter 1.2 › Troubleshooting
Stepwise checks
  1. Confirm VPC route tables point to the peer or TGW target.
  2. Confirm TGW route table has learned or contains the remote CIDR.
  3. Verify attachment is associated with the TGW route table that contains the route.
  4. Confirm attachment status is available.
  5. Check Security Groups and NACLs allow the expected traffic.
Example failure
An engineer updated the VPC route but forgot TGW propagation. The TGW route table lacked the remote CIDR, so traffic was dropped. Fixing propagation restored the learned route and connectivity returned. This illustrates why both VPC and TGW tables must be validated.
Common pitfall
Treating TGW like a single route table. Multiple TGW route tables may isolate attachments — confirm the correct table is referenced.
Key Takeaway
A structured checklist that validates routing, associations, propagation, and security shortens troubleshooting time.
