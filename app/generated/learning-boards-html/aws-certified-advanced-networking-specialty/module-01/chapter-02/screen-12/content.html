Module 1 › Chapter 1.2 › Choosing connectivity
VPC Peering
Best for 1:1 or a very small set of connections. Low cost per link, non‑transitive, route tables must be updated on both sides.
Transit Gateway
Best for many VPCs and hybrid connectivity. Transitive hub, TGW route tables, attachments, propagation; easier to manage as scale grows.
PrivateLink
Best for exposing or consuming a specific service privately across accounts without general routing or CIDR coordination.
Scenario match
SharedServices VPC with many Application VPCs → Transit Gateway. Single API offered to many consumers without broad routing needs → PrivateLink. A few direct connections between known VPCs → VPC Peering.
