Module 1 › Chapter 1.2 › PrivateLink Security
Traffic path
Application → Interface Endpoint ENI in consumer VPC → AWS private network → Provider NLB → Provider service instances. No public internet hop is required.
Interface Endpoint Security Groups: restrict which IPs and ports can use the endpoint.
Endpoint Policies: restrict which IAM principals or actions can call the service via the endpoint.
Provider side controls: NLB listeners and instance Security Groups enforce service access.
Example: Central DNS service
Security VPC exposes a resolver via a VPC Endpoint Service. Each consumer creates an interface endpoint and applies an SG allowing DNS from application subnets and an endpoint policy restricting which principals can use it. The resolver never needs a public IP and consumers don’t need peering or TGW attachments just to use the service.
Misconception
Assuming PrivateLink eliminates provider-side security responsibilities. Providers still need to secure their service instances and NLB listeners.
Key Takeaway
Use endpoint policies and SGs on the interface ENI plus provider controls to enforce least privilege for service consumption.
