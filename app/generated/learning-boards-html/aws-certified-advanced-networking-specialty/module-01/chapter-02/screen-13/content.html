Module 1 › Chapter 1.2 › Security VPC scenario
Problem
Multiple Application VPCs must send internet‑bound traffic to a central Security VPC for inspection before egress.
With peering you would need one peering link per Application VPC and manual routing to the Security VPC. With a Transit Gateway you attach each VPC once and configure TGW routing so traffic from all application spokes is forwarded to the security spoke, which then egresses to the internet gateway.
Alternatives
If the Security VPC only exposes a specific service such as a DNS resolver, PrivateLink lets customers consume that service via interface endpoints. For full egress routing and inspection, Transit Gateway is the practical choice.
Key Takeaway
Match the pattern: TGW for centralized routing and inspection, PrivateLink for discrete service consumption without broad routing.
