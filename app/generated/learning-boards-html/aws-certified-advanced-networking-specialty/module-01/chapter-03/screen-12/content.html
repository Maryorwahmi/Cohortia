Security and Common Mistakes
Checklist for endpoints, security groups, ports, and routing to avoid common DNS outages.
Inbound Endpoint SG
Allow UDP/TCP 53 from your on-prem DNS IPs only; deny broader access.
Outbound Endpoint SG
Allow outbound UDP/TCP 53 to your on-prem DNS IPs; allow inbound from VPC resolver as needed.
Mistake
Forgetting TCP 53 in rules which breaks larger responses and some resolver interactions.
Redundancy
Deploy ENIs in at least two AZs and ensure on-premises DNS is also redundant.
Troubleshooting steps
  1. Check VPN/Direct Connect status and latency.
  2. Confirm Security Groups and NACLs allow UDP/TCP 53.
  3. Verify route tables include paths to on-premises and ENI IPs.
  4. Check endpoint Operational status in the console.
Key Takeaway

DNS problems often look like application failures; start troubleshooting at connectivity, SGs, NACLs, and endpoint status before changing application code.
