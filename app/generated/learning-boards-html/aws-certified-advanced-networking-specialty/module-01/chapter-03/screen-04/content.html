Definition
VPC Default DNS Resolver
Built-in DNS service accessible at VPC_CIDR_RANGE.2 or 169.254.169.253 that resolves public names and private hosted zones associated with the VPC.
How it works
Instances send queries to the VPC resolver which consults private hosted zones associated with the VPC, then public DNS as needed.
Common misconception
It will not forward queries to on-premises DNS servers by itself. Bridging requires Route 53 Resolver endpoints.
Concrete example
An EC2 instance querying api.aws.example.com uses the VPC resolver; if the zone is private and associated with the VPC, it resolves locally.
Key Takeaway

Use the VPC default resolver for local resolution; deploy Route 53 Resolver endpoints when you must bridge to or from on-premises DNS.

Annotated addresses
Link-local address
169.254.169.253 — universally reachable inside the VPC for DNS resolution needs.
Subnet-specific resolver
VPC_CIDR_RANGE.2 — common resolver address used by hosts in a subnet when present.
