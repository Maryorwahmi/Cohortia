DNS Resolution and Hybrid DNS with Route 53 Resolver
Bridging VPC DNS and on-premises naming using Inbound/Outbound Endpoints and Resolver Rules.
In this lesson you will learn what the VPC default resolver provides, when to deploy Route 53 Resolver endpoints, and how resolver rules create consistent hybrid namespaces. We focus on configuration, connectivity, and common pitfalls that break name resolution between cloud and data center.
Hybrid DNS Concept
Endpoints + Rules = conditional forwarding
Inbound Endpoint
On-premises → AWS private zones
Outbound Endpoint
AWS → on‑premises for specific domains
Connection, firewall rules, and redundancy are essential. Missing port 53 trafﬁc rules or single-AZ endpoints are common failures.

Inbound Endpoints

Outbound Endpoints
Allow VPC hosts to forward selected domains to external DNS servers using resolver rules.
Resolver Rules
