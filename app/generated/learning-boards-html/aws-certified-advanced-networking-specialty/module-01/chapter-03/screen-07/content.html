Process Flow
Create an Outbound Endpoint
ENI IPs act as source addresses for forwarded queries; pair the endpoint with resolver rules for domains to forward.
Step 1
Select VPC and two private subnets in different AZs.
Step 2
Specify ENI IPs and a security group permitting outbound DNS to on-premises targets.
Step 3
Create a Resolver Rule for the domain and associate it with the outbound endpoint and target IPs.
Supporting details
  • Resolver Rules must specify the domain name and at least one target IP address for the external DNS server.
  • Ensure UDP and TCP port 53 are allowed from the endpoint ENIs to your on-premises addresses.
  • Test from an EC2 instance with a dig against a corp domain to confirm forwarding occurs.
Concrete example
Outbound endpoint my-outbound-resolver + rule for corp.example.com forwarded to 192.168.1.10 and 192.168.1.11.
Common Mistake
Creating the outbound endpoint but forgetting to create the resolver rule, resulting in no conditional forwarding.
