Process Flow
Create an Inbound Endpoint
At least two ENIs in different subnets; ENI IPs become the targets for on-premises conditional forwarders.
Step 1
Select VPC and two private subnets in different AZs.
Step 2
Specify two IP addresses for ENIs and attach a restrictive security group.
Step 3
Configure conditional forwarders on on-prem DNS to point to the ENI IPs.
Supporting notes
  • Security groups should allow only your on-premises DNS server IPs on UDP/TCP port 53.
  • ENIs should be in subnets with route table entries that allow communication back to on-premises networks via VPN or Direct Connect.
  • Use at least two ENIs across AZs for high availability.
Concrete example
Create inbound endpoint with ENI IPs 10.0.1.10 and 10.0.2.10 in subnets in AZ-A and AZ-B. On AD DNS add a conditional forwarder for aws.example.com to these IPs.
Common Mistake
Not opening port 53 both UDP and TCP or allowing broader access in the security group, leaving endpoints unreachable or exposed.
Key Takeaway

Inbound endpoints let on-premises DNS resolve AWS private hosted zone records when properly secured and placed across AZs.
