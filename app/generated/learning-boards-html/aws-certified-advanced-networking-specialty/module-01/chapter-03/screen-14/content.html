Common verification pitfalls
  • Testing only UDP; try TCP as well for larger responses.
  • Assuming console status is sufficient; combine with live lookups and packet captures if available.
  • Forgetting route table entries that return traffic to on-premises routers.
Quick checklist
  1. Connectivity up (VPN/Direct Connect)
  2. SGs and NACLs allow UDP/TCP 53
  3. Endpoint Operational in console
  4. Resolver Rule present and correct
  5. DNS server conditional forwarders configured as needed
Key Takeaway

A small set of repeatable checks will resolve most hybrid DNS problems: connectivity, SGs/NACLs, route tables, endpoint status, resolver rules, and DNS server config.
