Process Flow
AWS → on-premises resolution
Create outbound endpoint, add a forward rule, and ensure routes/firewalls permit DNS traffic to targets.
Step 1
Create outbound endpoint with ENIs across AZs.
Step 2
Create Resolver Rule for corp.example.com with on-prem target IPs.
Step 3
Run validation queries from EC2 to confirm forwarding and responses.
Concrete example
Outbound endpoint my-outbound-resolver; resolver rule corp-example-forwarding forwards corp.example.com to 192.168.1.10, 192.168.1.11.
Troubleshooting hint
If the endpoint shows non-operational, check ENI subnets, IP availability, and security group egress rules.
Key Takeaway

Outbound endpoints plus rules enable AWS hosts to reach on-prem authoritative DNS; verify both configuration and network reachability.
