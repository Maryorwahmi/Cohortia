Comparison
Inbound Endpoint
Purpose: allow external (on-prem) DNS servers to query AWS private hosted zones.
Key facts
Requires ENIs in multiple subnets; on-premises conditional forwarders point to ENI IPs.
Example
AD DNS forwarder sends aws.example.com queries to endpoint IPs so on-prem apps resolve AWS private hostnames.
Outbound Endpoint
Purpose: forward AWS-originated queries to external DNS servers for specific domains.
Key facts
ENIs are the source of forwarded queries; Resolver Rules define which domains are forwarded and to which targets.
Example
EC2 instance queries db.corp.example.com → resolver rule for corp.example.com forwards to on-prem DNS IPs via outbound endpoint.
