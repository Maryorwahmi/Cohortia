Core Concept
What Route 53 Resolver Does
Accepts external queries and forwards VPC queries to external DNS servers using endpoints and rules.
Inbound Endpoint
Allows on-premises DNS servers to resolve private hosted zones inside associated VPCs.
Outbound Endpoint
Enables AWS-originated queries to be forwarded to external DNS servers for specific domains.
Resolver Rules
Define domain-to-target mappings and select the outbound endpoint used for forwarding.
Supporting explanation
  • Resolver uses ENIs created in your VPC subnets as network endpoints for DNS traffic.
  • Endpoint ENIs must be created in at least two subnets across Availability Zones for redundancy.
  • Resolver Rules are consulted before the default resolver paths; a matching rule triggers forwarding.
  • If no rule matches, the VPC resolver resolves using private hosted zones and public DNS as normal.
Analogy
Think of Resolver as a postal sorting center that directs letters (DNS queries) to the right delivery network based on the address (domain).
Key Takeaway

Use Resolver endpoints when you need controlled, conditional DNS forwarding between AWS and external networks.
