Definition
Resolver Rules
Rules determine which domains are forwarded and where they are forwarded to.
Rule components
  • Domain name to match (for example, corp.example.com)
  • Target IP addresses of external DNS servers
  • Outbound endpoint to use as the source for forwarded queries
Behavior example
A rule for corp.example.com will match queries for app.corp.example.com and forward them to configured targets via the specified outbound endpoint.
Supporting bullets
  • Rules are consulted before default resolver behavior. A matching rule triggers conditional forwarding.
  • Rule order matters if you have overlapping domains; test the most specific rules first.
  • Rules do not establish network connectivity; ensure routes and firewall rules allow the traffic.
Practical tip
When debugging, temporarily set your rule to target a reachable test server to confirm forwarding is taking place.
Key Takeaway

Resolver Rules are the control plane for conditional forwarding; verify both rule configuration and network reachability when troubleshooting.
