Scenario Walkthrough
On-premises → AWS resolution
Create inbound endpoint, configure conditional forwarder on AD DNS, ensure firewall and route connectivity.
Create Endpoint
Two ENIs in separate AZs with static private IPs.
Configure AD DNS
Add conditional forwarder for aws.example.com to the ENI IPs.
Validate
Run a lookup from an on-prem client and confirm a private hosted zone record is returned.
Checks if resolution fails
  • Is the VPN or Direct Connect link operational?
  • Do security groups allow UDP/TCP port 53 from on-prem DNS IPs?
  • Are route tables configured so ENI IPs can reach the on-premises network and return traffic?
