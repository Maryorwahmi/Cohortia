Module 1 › Chapter 1.4 › Process Flow
Steps
  1. Allocate an Elastic IP for the NAT Gateway.
  2. Create the NAT Gateway in a public subnet and attach the EIP.
  3. Update the private subnet route table: 0.0.0.0/0 → NAT Gateway.
  4. Launch or use a private instance and validate connectivity from a bastion.
Validation advice: test an IP ping first, then DNS-based curl to distinguish routing from DNS problems.
Terminal demo snippets
# From bastion or VPN
# Connect to private instance then:
ping -c 3 8.8.8.8
curl -I https://example.com

# If ping works but DNS fails, check DNS and Security Groups
