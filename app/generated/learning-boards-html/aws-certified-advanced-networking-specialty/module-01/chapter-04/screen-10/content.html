Module 1 › Chapter 1.4 › Cross-account NAT
Design considerations
Host the Shared Egress VPC in a security or shared services account. Use Transit Gateway attachments to connect spoke accounts and enforce that only security teams can alter NAT Gateways or firewall appliances. Centralize logging and traffic inspection in the egress account.
Operational checklist: TGW attachment, route propagation, route table default route, IAM restrictions, centralized flow logs.
Example scenario
App accounts A and B send default routes to TGW. TGW forwards them to Shared Egress account where NAT Gateway and firewall inspect and forward to internet. All logs are pushed to a central S3 bucket owned by the security account.
Common error
Assuming route propagation alone is sufficient; attachments must be associated and permissions coordinated across accounts to allow the path.
