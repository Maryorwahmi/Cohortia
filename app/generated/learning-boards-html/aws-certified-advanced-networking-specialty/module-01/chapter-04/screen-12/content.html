Module 1 › Chapter 1.4 › Troubleshooting
Checklist
  • Is NAT Gateway in a public subnet with IGW route?
  • Does private route table have 0.0.0.0/0 → NAT Gateway?
  • Are Security Groups and NACLs allowing outbound and return traffic?
  • For NAT Instance: is Source/Destination Check disabled?
  • For TGW: are route propagation and default routes correct?
Diagnostic tips
Ping a public IP to verify routing. If that works but DNS fails, inspect DNS settings. Check NAT Gateway status and EIP attachment for availability.
Quick remediation
If route is missing, add 0.0.0.0/0 target NAT Gateway and re-test; most outages resolve after correcting a route table entry.
