Module 1 › Chapter 1.4 › Architecture
Pattern summary
Deploy NAT Gateways and inspection appliances in a Shared Egress VPC. Connect spoke VPCs using a Transit Gateway. Configure spoke private subnet route tables to send 0.0.0.0/0 to the TGW. The TGW route for default traffic should target the attachment to the Shared Egress VPC, which forwards to NAT Gateways and out via an Internet Gateway.
Cost benefit
Consolidating NAT Gateways reduces the total number of gateways billed and centralizes monitoring.
Security benefit
A single egress point allows centralized firewalling and auditing of outbound traffic.
Transit Gateway route example
TGW route entries must include spoke CIDRs pointing to their attachments and a default 0.0.0.0/0 pointing to the Shared Egress VPC attachment.
Pitfall
Omitting route propagation of the Egress VPC CIDR to the TGW or missing default TGW routes will break return traffic and prevent successful NAT egress.
