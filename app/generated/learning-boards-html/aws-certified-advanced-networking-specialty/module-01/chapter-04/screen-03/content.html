Allocate EIP & Create NAT Gateway
A NAT Gateway requires an Elastic IP; once allocated, associate it and wait for the gateway to become available before updating routes.
Update Private Route Tables
Add a default route for 0.0.0.0/0 pointing to the NAT Gateway for IPv4 or ::/0 to EIGW for IPv6.
Disable Source/Destination Check (NAT Instance)
For NAT Instances, disable the check on the ENI so traffic can be forwarded for other instances.
Centralize with Transit Gateway
Route spoke VPC default routes to the Transit Gateway and set a default route on TGW to the shared egress attachment.
Why this matters
Correct configuration ensures private workloads can reach external resources without becoming reachable from the public internet, preserving a strong security posture while enabling necessary outbound access.
