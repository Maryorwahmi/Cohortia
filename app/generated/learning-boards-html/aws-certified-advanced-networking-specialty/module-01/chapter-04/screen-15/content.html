Module 1 › Chapter 1.4 › Key Concepts
NAT Gateway
Managed, scalable IPv4 outbound egress; requires EIP and correct route placement.
NAT Instance
EC2-based NAT for custom inspection; requires disabling source/destination checks and HA planning.
Egress-Only IGW
Provides outbound-only IPv6 connectivity for instances without permitting inbound IPv6 connections.
Final takeaway

Place NAT correctly, configure routes and EIPs, centralize when you need inspection and governance, and pair NAT with proper firewalling and logging.
