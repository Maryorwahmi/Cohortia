Module 1 › Chapter 1.4 › Egress-Only IGW
What it does
The Egress-Only Internet Gateway allows IPv6-only instances in private subnets to initiate outbound IPv6 connections while preventing any inbound IPv6 traffic from the internet. It is attached to the VPC and referenced by the private subnet route table using ::/0 as the destination.
Configuration example:
# Route table entry for IPv6 private subnet
Destination: ::/0
Target: eigw-xxxxxxxxxxxxxxxxx
Misconception: EIGW is not a direct replacement for IPv4 NAT and only applies to IPv6-only traffic.
Concrete example
An IPv6-only instance fetches updates from a public repository. With the EIGW route in place, the instance can reach the repository but cannot be reached from the internet.
Key takeaway
Use EIGW to give IPv6-only private instances safe outbound access while preserving privacy and blocking inbound connections.
