Definition
NAT maps private IP addresses to a public address so private resources can initiate external connections while remaining unreachable from the internet.
Analogy: a post office forwarding mail without revealing the sender’s home address.
Concrete example
A backend instance in a private subnet requests an update package from a public repository. The NAT device replaces the instance’s private IP with a public Elastic IP, forwards the request, and translates the reply back to the instance.
Misconception: NAT alone is not a firewall; it does not replace security group rules or NACLs for layered security.
How NAT works (annotated flow)
1. Private instance opens connection
Packet leaves with private source IP and reaches NAT device.
2. NAT translates source to public EIP
External server sees traffic from the EIP, not the instance.
3. Return traffic arrives at NAT
NAT maps the response to the original private IP and forwards it to the instance.
Key takeaway
NAT enables outbound connectivity without exposing private addresses to inbound internet routes.
