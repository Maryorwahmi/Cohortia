Module 1 › Chapter 1.4 › NAT Instance
Configuration steps
  1. Launch EC2 in a public subnet and assign an Elastic IP.
  2. Disable the Source/Destination Check on the ENI.
  3. Open Security Group and NACL rules for required traffic.
  4. Update private route tables to point to the NAT Instance.
Terminal CLI note
# To disable source/dest check (CLI example)
aws ec2 modify-instance-attribute --instance-id i-0123456789abcdef \ 
  --no-source-dest-check
Operational caveat
Plan for HA and patching; NAT Instances introduce ongoing maintenance not present with managed gateways.
