Concept map
NAT Gateway • NAT Instance • Egress-Only IGW
NAT Gateway
Managed egress for IPv4, scalable and redundant per AZ when deployed across AZs.
NAT Instance
EC2-based NAT for custom processing but with operational overhead.
Egress-Only IGW
IPv6-only outbound gateway preventing inbound connections.
Tip: Place NAT Gateways in public subnets and update private subnet route tables to point at them.
