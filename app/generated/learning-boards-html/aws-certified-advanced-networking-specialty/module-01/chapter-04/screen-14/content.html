Inspection & logging
Place a firewall appliance in the Shared Egress VPC before NAT Gateways to inspect outbound traffic. Centralize VPC Flow Logs and firewall logs into a security account for auditing and alerting.
Retention and access control for logs are as important as the inspection itself for incident response.
Governance steps
  • Limit route table and TGW attachment permissions via IAM.
  • Use central account for NAT changes and firewall management.
  • Automate log collection and retention policies.
Misconception
NAT is not a replacement for a firewall; pair it with inspection tools when you need policy enforcement or content filtering.
