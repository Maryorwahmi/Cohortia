Module 8 › Chapter 8.6 › Primary Drivers
Definition
What creates network charges and why they matter for budgeting.
  • Data Transfer Out – bytes leaving AWS to the internet or between regions.
  • NAT Gateway processing and usage hours.
  • Transit Gateway data processing and attachment fees.
  • Load balancer and Elastic IP charges.
Common misconception
All intra‑AWS traffic is free. In reality, inter‑AZ and inter‑region transfers often incur costs that matter at scale.
Measurement and example
Map your traffic flows to billing usage types in Cost Explorer to see which flows dominate spend.
Example scenario
If a service repeatedly moves data between AZs, those inter‑AZ bytes appear as regional transfer costs. Consolidating the service or using private routing reduces that recurring charge.
Action checklist
  • Identify top DTO lines in Cost Explorer by usage type.
  • Map flows to architecture components and owners.
  • Prioritize fixes: cache, private path, consolidate.
Key Takeaway

Focus on DTO and managed service processing charges first, because they scale with data and usage patterns.
