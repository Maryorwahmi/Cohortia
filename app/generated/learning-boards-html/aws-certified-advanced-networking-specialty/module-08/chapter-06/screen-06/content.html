Module 8 › Chapter 8.6 › Peering vs Transit Gateway
VPC Peering
Direct peering link between two VPCs with no transit routing through another service.
Strengths
Low overhead for a small number of VPC pairs; simple network path; no Transit Gateway data processing fees.
Limitations
Doesn't scale well: many-to-many topologies require N*(N-1)/2 peering links.
Transit Gateway
Central hub that attaches VPCs and on-premises networks, simplifying routing and reducing peering complexity.
Strengths
Simplifies large topologies and hybrid connectivity; reduces route table complexity.
Watchouts
Charges for attachments and data processing mean high central traffic can be costly.
Key Takeaway

Choose Transit Gateway for scale and manageability, but model expected central traffic to avoid high data processing costs.
