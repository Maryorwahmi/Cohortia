Module 8 › Chapter 8.6 › Mistakes & Heuristics
Common mistakes
  • Choosing VPN for high-volume hybrid transfers without modeling DTO costs.
  • Enabling Transfer Acceleration or many endpoints without cost comparison to current paths.
  • Centralizing everything on Transit Gateway without checking data processing fees for central flows.
Decision heuristics
  • Estimate monthly bytes and compare total cost over a 12-month window for hybrid choices.
  • Use endpoints when service traffic through NAT is high enough to offset endpoint fees.
  • Prioritize fixes by measurable expected savings and implementation complexity.
Validation plan example
Define the usage type you will monitor, the expected percent reduction, the verification period, and a rollback threshold to ensure the optimization actually saves money.
Key Takeaway

Model, implement, and verify. That cycle prevents repeated ineffective or costly changes.
