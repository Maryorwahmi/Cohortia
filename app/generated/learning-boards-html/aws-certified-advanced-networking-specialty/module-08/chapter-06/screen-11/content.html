Module 8 › Chapter 8.6 › Cost Explorer Workflow
Step-by-step
A concise checklist to locate network costs and plan fixes.
  1. 1. Set time range to the last 3–6 months for representative data.
  2. 2. Filter by networking-related services (EC2, S3, CloudFront, VPC, Direct Connect, VPN, Transit Gateway, ELB).
  3. 3. Group by usage type to reveal DTO, NATGateway-Bytes, TransitGateway-DataProcessing, and others.
  4. 4. Map high-cost usage types to architecture owners and flows.
  5. 5. Prioritize fixes and validate after implementation.
Concrete example
If Cost Explorer shows large DataTransfer-Regional-Bytes between AZs, investigate cross‑AZ communication and consider co‑location or configuration changes to reduce cross‑AZ traffic.
Common pitfall
Making changes without mapping usage types to flows. Measurement first prevents wasted effort and incorrect optimizations.
Key Takeaway

Use Cost Explorer to find precise usage lines driving cost and only then apply targeted architecture or service changes to reduce expenses.
