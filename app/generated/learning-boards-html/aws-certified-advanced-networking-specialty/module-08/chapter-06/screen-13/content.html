Activity steps
Follow these steps in Cost Explorer to find network cost drivers and decide actions.
Step 1
Open Cost Explorer and set the time range to the last 3–6 months.
Step 2
Filter for networking services: EC2, S3, CloudFront, VPC, Direct Connect, VPN, Transit Gateway, ELB.
Step 3
Group by usage type to surface DTO, NATGateway-Bytes, TransitGateway-DataProcessing, and similar lines.
Step 4
Map each top usage type to architecture components and owners.
Step 5
Propose an optimization per usage line (cache, endpoint, transit change, Direct Connect).
Step 6
Prioritize by estimated savings and complexity; schedule a verification period.
Key Takeaway

Use Cost Explorer to move from numbers to prioritized actions, then validate changes to confirm real savings.
