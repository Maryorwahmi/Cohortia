Module 8 › Chapter 8.6 › VPC Endpoints
How endpoints help
Endpoints route service calls over the AWS private network, avoiding NAT processing charges for that traffic.
Gateway Endpoint
Used for S3 and DynamoDB; typically removes NAT egress for these services without per-interface fees.
Interface Endpoint
Creates network interfaces and may have hourly or per-interface costs; evaluate against NAT savings.
Example and steps
If you see significant NATGateway-Bytes to S3 in Cost Explorer, add a gateway endpoint for S3 and measure the resulting change.
Implementation checklist
  • Find NATGateway-Bytes for S3 or other service traffic in Cost Explorer.
  • Create the appropriate gateway or interface endpoint for that service.
  • Measure endpoint costs versus NAT processing savings after deploying.
Key Takeaway

Endpoints often remove recurring NAT processing charges for service traffic — model their costs versus savings before rolling out broadly.
