Module 8 › Chapter 8.6 › Objectives (cont.)
Optimize Transit Gateway
Balance fewer peering links with Transit Gateway data processing charges. Use Network Manager for visibility.
Audit NAT & Elastic IPs
Ensure NAT Gateways aren’t idle and release unassociated Elastic IPs to avoid charges.
Use VPC Endpoints
Bypass NAT for AWS services to eliminate NAT data processing costs for that traffic.
Run Cost Explorer analysis
Filter by usage type to find DTO, NAT, Transit Gateway, and Direct Connect cost lines for action.
Key Takeaway

Measure first, then apply architecture changes. Small fixes like endpoints and audits often compound into large savings.
