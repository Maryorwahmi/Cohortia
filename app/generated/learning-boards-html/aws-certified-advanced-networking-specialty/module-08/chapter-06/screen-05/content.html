Module 8 › Chapter 8.6 › CloudFront & Transfer Acceleration
Compare
CloudFront vs S3 Transfer Acceleration vs direct origin DTO.
CloudFront (CDN)
Caches content at Edge Locations to reduce origin egress. Best for public or cacheable user content.
S3 Transfer Acceleration
Accelerates uploads using the AWS network. Evaluate when upload volume from distant locations is large.
Direct origin DTO
Serves bytes directly from S3 or EC2 to users. Often the most expensive path for high-volume egress.
Example and actions
A content site with global users: enable CloudFront to reduce EC2/S3 DTO and measure the change in Cost Explorer.
Concrete example
If 80% of downloads are static objects, CloudFront will serve most requests from Edge, lowering origin egress significantly and often paying back any CDN overhead.
Checklist before enabling
  • Measure current origin DTO by usage type in Cost Explorer.
  • Estimate cache hit ratio for your content.
  • Test Transfer Acceleration on sample uploads to compare latency and cost.
Key Takeaway

Cache to reduce origin DTO; accelerate uploads only when volume and distance justify the additional fees.
