VPC Flow Logs: Unpacking Network Traffic

Capturing IP Traffic Details for Granular Analysis

What are VPC Flow Logs?

A feature that captures information about the IP traffic going to and from network interfaces in your VPC. They provide a record of network activity.

Key Data Points Captured

  • Source and Destination IP addresses
  • Source and Destination Ports
  • Protocol (e.g., TCP, UDP)
  • Number of Bytes and Packets
  • ACCEPT or REJECT action
  • Start and End timestamps
Key Takeaway

VPC Flow Logs provide granular, per-flow IP traffic records, essential for detailed network analysis and troubleshooting within your VPC.
