Automating VPC Creation with CloudFormation

Deploy a basic VPC, Internet Gateway, and public subnet using a CloudFormation template.

Define VPC, Subnets, IGW, and Route Tables in YAML.
Deploy using `aws cloudformation deploy` command.
Verify resources in the AWS VPC console.
Clean up resources by deleting the CloudFormation stack.
Key Takeaway

Automating VPC creation with CloudFormation demonstrates the power of IaC for consistent and repeatable network infrastructure deployments.

basic-vpc.yaml 
AWSTemplateFormatVersion: '2010-09-09'
Description: A simple VPC with an Internet Gateway and a public subnet.

Parameters:
  VpcCidrBlock:
    Type: String
    Default: 10.0.0.0/16

Resources:
  MyVPC:
    Type: AWS::EC2::VPC
    Properties:
      CidrBlock: !Ref VpcCidrBlock
      # ... other VPC properties

  MyInternetGateway:
    Type: AWS::EC2::InternetGateway
    # ... properties

  AttachGateway:
    Type: AWS::EC2::VPCGatewayAttachment
    # ... properties

  MyPublicSubnet:
    Type: AWS::EC2::Subnet
    Properties:
      VpcId: !Ref MyVPC
      CidrBlock: 10.0.1.0/24
      # ... other subnet properties

# ... Route Tables, Associations, etc.
