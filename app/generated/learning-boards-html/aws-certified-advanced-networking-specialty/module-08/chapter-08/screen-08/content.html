Advanced Techniques

CloudFormation Custom Resources

Extend CloudFormation to manage resources not natively supported or perform custom logic.

Extend Capabilities: Manage resources outside native CloudFormation support.
Custom Logic: Execute specific actions during stack lifecycle events.
Lambda Integration: Typically implemented using AWS Lambda functions.
Flexibility: Manage third-party services or complex configurations.
Key Takeaway

Use custom resources to bridge gaps in CloudFormation's native support, enabling management of virtually any resource or process.

Custom Resource Workflow

CloudFormation Stack Operation

1. CloudFormation detects a custom resource in the template.

2. It invokes a specified Lambda function (or other endpoint).

3. The Lambda function performs the required action (e.g., creates a resource).

4. The Lambda function sends a success or failure response back to CloudFormation.

5. CloudFormation proceeds or rolls back based on the response.

This allows CloudFormation to orchestrate actions beyond its built-in resource types.
