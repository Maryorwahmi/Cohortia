Module 8 › Chapter 8.2 › Edge Locations
What Edge Locations do
Serve cached content from a nearby data center so the request does not traverse long distances to the origin.
Benefits:
  • Lower latency for end users.
  • Lower origin request rates and costs.
  • Edge-level protections, including mitigations against some volumetric attacks.
Regional Edge Caches
Act as regional mid-tier caches for less-frequently requested objects, reducing the need to fetch from the origin.
Practical note: Use caching and invalidation policies to control freshness—short TTLs for changing content, long TTLs for static assets.
Concrete example
A media site caches video segments at Edge Locations so playback starts quickly for viewers worldwide. A Regional Edge Cache keeps popular segments available for longer, reducing origin bandwidth spikes during viral events.
