Module 8 › Chapter 8.2 › CloudFront Cache Flow
Step-by-step
  1. User requests object; Edge Location checks cache.
  2. If miss, ask Regional Edge Cache; if still miss, fetch from origin.
  3. CloudFront caches object per policy and returns response.
  4. Subsequent requests hit the Edge and respond faster.
Controls that matter
Cache-Control headers, CloudFront cache policies, invalidation, and origin configuration.
Visual example
Imagine a user in Brazil requests an image. CloudFront checks the Sao Paulo edge. If cached, immediate response. If not, it checks a regional cache, then the origin in the appropriate Region. After the origin response, the edge caches the image for the next user in Brazil.
Key Takeaway
Design cache policies for object freshness and aim to maximize hits for stable assets to reduce latency and origin load.
