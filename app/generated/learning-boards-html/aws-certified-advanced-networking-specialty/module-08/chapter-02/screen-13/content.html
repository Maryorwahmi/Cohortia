Module 8 › Chapter 8.2 › Mistakes & Best Practices
Common mistakes
  • Using the wrong S3 origin (REST API instead of static website endpoint).
  • Over-caching personalized content or not using short TTLs where needed.
  • Testing only from a single location and missing global performance issues.
Best practices
  • Separate static assets from dynamic APIs and apply appropriate caching strategies.
  • Use Global Accelerator for session-based, latency-sensitive traffic and static Anycast IPs.
  • Instrument headers and monitoring to validate cache hits and transport health.
Practical reminder
Always include cache warm-up in tests and consider operational costs when choosing caching and routing strategies.
