Module 8 › Chapter 8.2 › CloudFront + S3 Walkthrough
Steps
  1. Create S3 bucket and enable static website hosting with index.html.
  2. Upload index.html and an image, adjust permissions or bucket policy for public read.
  3. Create CloudFront distribution using the S3 static website endpoint as origin.
  4. Set Viewer protocol to redirect HTTP to HTTPS and choose CachingOptimized policy.
  5. Validate the distribution domain and inspect X-Cache headers to confirm hits after the first request.
Code snippets
Bucket policy (replace bucket name):
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "PublicReadGetObject",
      "Effect": "Allow",
      "Principal": "*",
      "Action": "s3:GetObject",
      "Resource": "arn:aws:s3:::my-global-perf-website-YOURNAME/*"
    }
  ]
}
Example index.html:
<!doctype html>
<html>
  <head><meta charset='utf-8'><title>Hello from S3</title></head>
  <body>
    <h1>Hello from S3!</h1>
    <p>This is a test page delivered through CloudFront.</p>
  </body>
</html>
Debug tip
Use developer tools' network tab to read the X-Cache header. The first request is often a miss; repeat requests should show hits if caching works.
