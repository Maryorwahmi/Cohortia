Module 8 › Chapter 8.2 › Testing & Validation
Metrics to capture
  • Latency and time-to-first-byte.
  • Cache hit ratio (X-Cache values).
  • Origin request rate and error rates.
Test types
Geographic tests, cache warm-up, sustained load, and failover verification for Global Accelerator endpoints.
Concrete approach
Run tests from representative locations, compare cached vs origin responses, and simulate endpoint failures to confirm Global Accelerator reroutes traffic to healthy endpoints.
Pitfall to avoid
Don't rely on single-region tests or only synthetic short-lived requests; include priming and longer runs to see origin pressure.
