Module 8 › Chapter 8.2 › Layered Architecture
Layer roles
  • Edge: CloudFront caches static assets and serves global consumers.
  • Transport: Global Accelerator provides consistent routing for dynamic sessions.
  • Regional backends: Application services run in Regions across AZs for resilience.
Misconception
Treating a CDN as a transport optimizer. CDNs cache content; transport optimization comes from services like Global Accelerator.
Concrete scenario
An e-commerce platform uses CloudFront for assets and Global Accelerator for checkout APIs to ensure the checkout flow is low-latency and resilient across regions. Backends in each Region handle payments and inventory replication across AZs.
Key Takeaway
Design by responsibility: cache where content is stable, route where transport consistency matters.
