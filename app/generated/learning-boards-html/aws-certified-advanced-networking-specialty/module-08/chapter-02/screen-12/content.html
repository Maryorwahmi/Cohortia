Module 8 › Chapter 8.2 › Use Cases
CloudFront
Static site hosting, media streaming, website assets, API caching.
Global Accelerator
Interactive games, VoIP, real-time feeds, APIs requiring consistent latency and static IPs.
Both together
Use CloudFront for assets and Global Accelerator for session-oriented API traffic to optimize both content and transport.
Key decision point
Identify whether your primary problem is content delivery or transport consistency, then pick the service that directly addresses that problem.
