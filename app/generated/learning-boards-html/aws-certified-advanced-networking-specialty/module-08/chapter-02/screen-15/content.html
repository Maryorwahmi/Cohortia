Module 8 › Chapter 8.2 › Key Concepts — Services
AWS Global Accelerator
Static Anycast IPs and optimized routing over the AWS backbone for dynamic traffic.
Amazon CloudFront
A CDN that caches content at Edge Locations and Regional Edge Caches to speed delivery.
Anycast IP
A single IP announced from many locations; traffic reaches the nearest or best route to that IP.
Final takeaway
Match each tool to the problem: caching for content, Anycast and backbone routing for consistent transport.
