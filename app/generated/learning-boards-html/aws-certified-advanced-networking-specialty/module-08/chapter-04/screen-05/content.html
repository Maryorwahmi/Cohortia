Activating Transfer Acceleration

Simple steps to enable faster S3 uploads

1

Enable on S3 Bucket

Activate Transfer Acceleration via the AWS Management Console, CLI, or SDK within your S3 bucket's properties.

2

Use Specific Endpoint

For uploads, switch to the S3 Transfer Acceleration endpoint: your-bucket-name.s3-accelerate.amazonaws.com.

3

Update Applications

Ensure all client applications or scripts are configured to use the new acceleration endpoint for uploads.

Key Takeaway

A simple configuration change and endpoint update are all that's needed to leverage S3 Transfer Acceleration for faster data uploads.

# AWS CLI Example: Enable Transfer Acceleration
aws s3api put-bucket-accelerate-configuration \
  --bucket my-accel-test-bucket-YOURNAME \
  --accelerate-configuration Status=Enabled

# Example S3 Transfer Acceleration Endpoint
my-accel-test-bucket-YOURNAME.s3-accelerate.amazonaws.com

# AWS CLI Example: Upload using acceleration endpoint
aws s3 cp localfile.txt \
  s3://my-accel-test-bucket-YOURNAME \
  --endpoint-url https://my-accel-test-bucket-YOURNAME.s3-accelerate.amazonaws.com
Important Note

Always verify the new endpoint is correctly configured in your applications or scripts to ensure data is routed through the acceleration service.
