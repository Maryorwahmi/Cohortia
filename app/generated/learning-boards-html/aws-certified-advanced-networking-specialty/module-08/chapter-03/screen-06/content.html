Module 08 › Chapter 8.3 › Elastic Fabric Adapter
What EFA does
Provides user-level access to NIC functionality and an OS bypass that reduces kernel overhead, improving latency consistency for tightly coupled workloads.
Best fit
MPI, distributed machine learning with frequent small-message exchanges.
Misconception
Not required for bulk transfer workloads where ENA plus high bandwidth is sufficient.
Example
A distributed training job using many small gradient exchanges benefits from EFA’s lower, consistent latency compared to ENA, improving synchronization efficiency.
Pro tip

Confirm EFA support in both instance type and OS image, and test with representative communication patterns before adoption.
