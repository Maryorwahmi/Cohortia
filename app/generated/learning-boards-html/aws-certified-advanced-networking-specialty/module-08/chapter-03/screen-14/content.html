Module 08 › Chapter 8.3 › What to Remember
Instance selection
Match family and size to bandwidth and PPS needs.
ENA & EFA
ENA for throughput; EFA for low, consistent latency in HPC.
Placement groups
Cluster for co-location; spread and partition for availability and fault domains.
Summary takeaway
Treat network performance as a system property and validate every layer: instance, adapter, placement, and MTU must all be consistent to achieve predictable results.
