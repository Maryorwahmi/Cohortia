Module 08 › Chapter 8.3 › Instance Selection
Definition
Network-optimized instances include higher NIC capacity, better PPS, and are tuned for high-throughput workloads.
When to choose
Large data transfers, network appliances, HPC and distributed storage nodes.
Misconception
Not all sizes in a family have identical networking — check bandwidth for the chosen size.
Key Takeaway

Match instance family and size to your network throughput and packet rate requirements and validate with a pilot test.

Concrete example
A data-processing cluster moves terabyte-sized batches between nodes. Switching from general-purpose instances to C5n yields measurable improvement because the C5n family advertises higher bandwidth and PPS suitable for this workload.
Quick checklist
  • Identify workload throughput and PPS needs.
  • Compare instance family bandwidth and NIC features.
  • Run pilot throughput tests to confirm real-world performance.
