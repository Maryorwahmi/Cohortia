Shell steps (Amazon Linux 2)
Edit the interface configuration, restart networking, and verify the MTU. Example commands and configuration follow; use them in a lab first.
# Example for Amazon Linux 2 (eth0)
sudo ip link set dev eth0 mtu 9001
sudo ethtool -K eth0 rx-checksumming on tx-checksumming on sg on tso on gro on lro on

# Or persist in /etc/sysconfig/network-scripts/ifcfg-eth0
# Add the line: MTU="9001"
Checklist & common pitfall
Apply MTU to every instance and connected network device. Restart services and verify with ip link show eth0. Forgetting any hop causes fragmentation.
Try this

After setting MTU, run iperf3 between two instances to confirm throughput and watch for packet fragmentation.
