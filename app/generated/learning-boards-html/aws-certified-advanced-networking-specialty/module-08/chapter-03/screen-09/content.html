Module 08 › Chapter 8.3 › Cluster Placement Flow
Step-by-step
  1. Plan instance types and AZ capacity to ensure available network-optimized instances.
  2. Create a cluster placement group in the chosen AZ.
  3. Launch instances and specify the placement group at launch time.
  4. Run iperf3 or representative workloads to measure inter-node throughput and latency.
Pitfall
You cannot move a running instance into a cluster placement group; placement is set at launch.
Example verification
After launching C5n instances into a cluster, run iperf3 between nodes to compare throughput to the same instances outside a cluster. Expect lower latency and higher inter-instance bandwidth.
Key Takeaway

Cluster placement maximizes inter-node networking but requires single-AZ planning and capacity checks.
