Quick verification checklist
  • Adapter and driver: Use ethtool to confirm ENA/EFA driver presence.
  • MTU state: ip link show eth0 should display mtu 9001 after configuration.
  • Throughput test: Use iperf3 server/client to observe expected bandwidth.
  • Placement group rules: Cluster placement groups are single-AZ only; avoid cross-AZ placement.
Common mistakes
MTU mismatch across hybrid links, missing ENA/EFA drivers, and attempting cluster placement across multiple AZs are frequent causes of degraded performance or failures.
