Module 08 › Chapter 8.3 › Placement Groups
Overview
Placement groups change how instances are placed on the underlying hardware to trade off latency, throughput, and failure characteristics.
Cluster
Co-locate instances in one AZ for low latency and high throughput.
Spread
Place instances on distinct hardware to reduce correlated failures.
Partition
Divide instances into partitions for large distributed workloads.
Common mistake
Trying to create cluster placement groups across AZs causes launch failures. Always create cluster groups within a single AZ.
