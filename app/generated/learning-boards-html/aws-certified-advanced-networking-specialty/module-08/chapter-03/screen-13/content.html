Testing sequence
  1. Verify current MTU: ip link show eth0.
  2. Configure MTU and NIC offloads and restart networking.
  3. Start iperf3 server on one node and run client on the other.
  4. Observe throughput and packet loss; adjust if fragmentation occurs.
Troubleshooting checklist
  • Did ethtool show the expected driver and offload settings?
  • Does every hop in the path support MTU 9001?
  • Are instances launched into the correct placement group and AZ?
Common failure

Partial jumbo-frame deployment across hybrid links leads to fragmentation and worse performance than before.
