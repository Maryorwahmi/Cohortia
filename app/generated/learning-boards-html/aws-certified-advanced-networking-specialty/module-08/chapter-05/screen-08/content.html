Auto Scaling Policy Example
A target-tracking policy using ASGAverageNetworkOut.
{
  "PolicyName": "ScaleOutOnNetworkOut",
  "ScalingTargetId": "arn:aws:autoscaling:region:account:autoScalingGroup:my-asg",
  "TargetTrackingConfiguration": {
    "PredefinedMetricSpecification": {
      "PredefinedMetricType": "ASGAverageNetworkOut"
    },
    "TargetValue": 80.0,
    "DisableScaleIn": false
  }
}
Notes: TargetValue can be percent-like or an absolute byte value depending on metric. Monitor NetworkOut in CloudWatch and choose a target that avoids consistently hitting 100% of expected capacity.
Concrete use
Set a policy so the ASG launches new instances before network bandwidth reaches critical levels.
Common Mistake
Scaling only on CPU while NetworkOut is saturated leads to continuing network bottlenecks despite more CPU availability.
Check your math
Choose a target based on instance network capability and expected per-instance throughput so scaling triggers at the right moment.
