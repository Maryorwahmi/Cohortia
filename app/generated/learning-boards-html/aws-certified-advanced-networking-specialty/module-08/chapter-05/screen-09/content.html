Hands-on Activity
Launch Template → Auto Scaling Group
Conceptual steps you will perform in the console or automation.
1. Launch Template
Choose AMI, instance type (e.g., m5.large), enable detailed monitoring, and specify security group rules for SSH and HTTP.
2. Auto Scaling Group
Select the template, choose at least two subnets in separate AZs, and set min/desired/max capacity.
3. Scaling Policy
Add a target tracking policy on ASGAverageNetworkOut or a custom NetworkOut threshold to trigger scale-out.
Testing advice
Generate sustained outbound traffic, such as large file transfers or iperf3 streams, to validate scale triggers and cooling behavior.
Validation
Monitor CloudWatch NetworkOut, ASG activity history, and RequestCountPerTarget to confirm the system scales as expected.
