ASG Design for Network Workloads
Pick metrics and sensitivity that reflect network constraints.
Estimate per-instance bytes/sec capacity and set target accordingly.
Use ASGAverageNetworkOut or RequestCountPerTarget depending on request model.
Tune cooldowns and target values to avoid oscillation.
Key Takeaway

Align the scaling metric with the real bottleneck and validate with sustained load tests before finalizing targets.

Concrete scenario
If instances show low CPU but high NetworkOut, switching scaling to ASGAverageNetworkOut prevents adding CPU-bound instances that don’t relieve the network bottleneck.
Common Mistake
Relying only on CPU utilization for network-bound services leads to persistent network saturation despite more instances.
