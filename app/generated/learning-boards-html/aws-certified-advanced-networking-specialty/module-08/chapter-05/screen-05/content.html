Definition
Target Groups & Health Checks
Make sure only healthy targets receive traffic.
Target Group
A named set of targets that the load balancer forwards requests to. Targets can be instances, IPs, or serverless endpoints.
Health Check types
HTTP/HTTPS checks validate app responses; TCP checks validate port availability. Use HTTP checks for readiness when possible.
Key Takeaway

Design health checks that exercise the same code paths your users hit, and tune intervals and thresholds to avoid flapping.

Example health check
Use GET /health which checks DB connectivity and downstream caches; return 200 only when ready to serve traffic.
Common Mistake
Relying on a simple TCP check that does not validate the application’s ability to process requests.
Pro Tip
If startup time is long, increase healthy threshold or startup delay to avoid premature removal during boot.
