Metrics to monitor

Testing methods
iperf3, sustained file transfers, or scripted request streams to generate steady outbound traffic.
Pitfall
Short spikes can mislead you into thinking scaling is sufficient; run sustained tests to validate steady-state.
Validation tip
Confirm new instances complete health checks and serve traffic before concluding success.
