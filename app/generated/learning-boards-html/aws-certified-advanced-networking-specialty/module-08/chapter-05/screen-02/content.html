Learning Objectives
Skills you will demonstrate and why they matter
01
Differentiate ALB and NLB
Explain Layer 7 routing versus Layer 4 forwarding, and select the balancer that matches protocol and latency needs.
Verified Competency Milestone
02
Optimize load balancer settings
Tune target group health checks and connection settings so healthy targets serve traffic with minimal latency.
Verified Competency Milestone
03
Design ASGs for network metrics
Use NetworkIn, NetworkOut, or RequestCountPerTarget to trigger scale events when the network is the bottleneck.
Verified Competency Milestone
04
Evaluate cross-zone trade-offs
Understand how cross-zone routing affects performance and when NLB cross-zone transfer costs matter.
Verified Competency Milestone
