Core Concept
Network Load Balancer (NLB)
Minimal processing for extreme throughput.
  • Operates at Layer 4: TCP, UDP, TLS.
  • Preserves client IP addresses for backend visibility.
  • Handles millions of requests per second when needed.
Cross-zone behavior & example
NLB cross-zone is enabled by default but may incur cross-AZ data transfer charges. If you disable cross-zone balancing, traffic is only routed to targets in the same Availability Zone as the client’s connection, which can lower transfer costs but can create uneven distribution if AZ target counts differ.
Operational tip
If you must disable cross-zone, ensure each AZ has balanced capacity and health checks to avoid hotspots.
Key Takeaway

NLBs minimize latency and preserve IPs; balance cross-zone cost decisions with availability and even target counts across AZs.
