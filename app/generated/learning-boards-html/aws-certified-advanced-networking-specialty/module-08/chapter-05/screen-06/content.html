Process Flow
ALB Optimization Steps
  1. Design readiness checks. Use endpoints that verify essential dependencies.
  2. Set intervals thoughtfully. Match checks to startup and recovery times.
  3. Tune keepalives and timeouts. Reduce handshakes for persistent traffic.
  4. Distribute targets across AZs. Ensure capacity per zone to avoid hotspots.
  5. Monitor and iterate. Use RequestCountPerTarget and latency metrics to refine settings.
Key Takeaway

Defaults are a starting point; match checks and timeouts to real application behavior to avoid instability.

Concrete example
If a service needs a cold-start time of around 10 seconds, set your health-check grace and healthy thresholds accordingly rather than relying on very short intervals. This prevents the ALB from marking the instance unhealthy during boot.
Misconception
Shorter intervals always improve availability. In reality, overly frequent checks can create load and false failures.
Check: After a deployment, if you see flapping, increase healthy thresholds or add a startup grace period for checks.
