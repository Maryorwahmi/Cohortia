Checklist
Common Mistakes & Remediation
Health checks
  • Use app-level endpoints that validate dependencies.
  • Adjust intervals for startup times.
AZ distribution
  • Ensure even target counts per AZ before disabling cross-zone.
  • Monitor per-AZ target utilization.
Scaling metric
  • Prefer network metrics for network-bound services.
  • Set realistic TargetValue and cooldowns.
Work through changes one at a time, rerun sustained tests, and confirm metrics stabilize before making further adjustments.
