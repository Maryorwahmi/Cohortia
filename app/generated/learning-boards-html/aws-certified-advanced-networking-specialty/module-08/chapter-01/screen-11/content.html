Module 8 › Chapter 8.1 › Global Infrastructure & Edge
Components
  • Regions: isolated geographic areas for compute and storage.
  • Availability Zones: isolated locations within regions to balance availability and latency.
  • Edge Locations: CDN/edge caches placed near users for low-latency content delivery.
Key Takeaway

Map user locations to region and edge usage. Use CDN for static assets and regional compute for dynamic processing.

Scenario
A global user base benefits from CloudFront for assets and selective multi-region compute for latency-sensitive APIs; evaluate complexity trade-offs before wide regional expansion.
Misconception
Edge caching is not a substitute for regional compute when server-side logic must run close to users.
