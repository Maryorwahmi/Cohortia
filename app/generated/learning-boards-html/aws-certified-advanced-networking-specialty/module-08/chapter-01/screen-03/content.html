Measurement checklist
  • Instrument EC2 with CloudWatch per-instance metrics: NetworkIn, NetworkOut, packet counts.
  • Run iperf3 to generate controlled traffic and measure throughput and latency between test hosts.
  • Establish baselines for same-AZ, cross-AZ, and cross-region tests to compare placement effects.
  • Record before-and-after graphs for any change and validate that improvements are consistent and repeatable.
Safe change rules
  • Make single-variable changes in staging and monitor results closely with CloudWatch.
  • Confirm end-to-end support before enabling jumbo frames or altering MTU.
  • Avoid permissive security groups during tests; mimic production to get realistic metrics.
  • Use placement groups for latency-sensitive workloads after testing for diminishing returns.
