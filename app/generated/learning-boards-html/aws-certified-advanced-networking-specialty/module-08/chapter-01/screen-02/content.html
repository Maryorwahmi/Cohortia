Learning Objectives
A four-step Bloom path to help you measure, understand, apply, and validate network performance changes.
01
Identify metrics
Name and measure latency, throughput, jitter, and packet loss. This skill helps you pick the right diagnostic tools and avoid guesswork.
Verified Competency Milestone
02
Understand principles
Learn the holistic approach: measure traffic, find bottlenecks, and apply targeted fixes. This reduces cost and improves outcomes.
Verified Competency Milestone
03
Map AWS features
Match CloudFront, Global Accelerator and placement strategies to use cases so you apply the right service, not just more capacity.
Verified Competency Milestone
04
Avoid anti-patterns
Detect chatty applications and misconfigurations. Fixing the architecture often beats larger instances for long-term performance and cost control.
Verified Competency Milestone
