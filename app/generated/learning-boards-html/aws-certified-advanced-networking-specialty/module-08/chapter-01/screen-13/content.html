Module 8 › Chapter 8.1 › End-to-end Example
Steps taken
  1. Measure: CloudWatch showed latency variance and iperf3 confirmed cross-region latency.
  2. Analyze: Static assets had high origin fetch times; dynamic calls showed routing variance.
  3. Target: Enable CloudFront for static assets and evaluate Global Accelerator for dynamic endpoints.
  4. Validate: Re-run iperf3 and CloudWatch graphs in staging and compare baselines.
Result expectations
CloudFront should reduce origin fetches and speed static content delivery.
Global Accelerator should reduce latency variance for dynamic calls by improving routing over the AWS network.
Key Takeaway

The proof of success is measurable: reduced variance in latency or higher sustained throughput in repeated tests.
