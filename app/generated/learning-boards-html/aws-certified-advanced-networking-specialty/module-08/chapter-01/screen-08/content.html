Terminal commands (visual)
Install iperf3 and run a server on one instance, then run a client from the other to measure throughput. Watch CloudWatch metrics while the test runs.
# On server instance
sudo yum install -y iperf3
iperf3 -s

# On client instance
sudo yum install -y iperf3
iperf3 -c <server-private-ip> -P 4 -t 60

# Monitor CloudWatch metrics: NetworkIn, NetworkOut, NetworkPacketsIn, NetworkPacketsOut
# Compare same-AZ vs cross-AZ vs cross-region runs
Keep security groups restricted to your test IPs and ensure both instances are launched in similar instance families to avoid confounding variables.
Example observation
You may see higher sustained throughput inside the same AZ and increased variance and latency across regions. Use this evidence to decide on placement or Global Accelerator.
Key Takeaway

Controlled tests expose root causes; CloudWatch graphs show how traffic patterns change when you modify placement or routing.
