Module 8 › Chapter 8.1 › Common Anti-patterns
Chatty applications
Many small transfers cause overhead. Solution: batch requests, use persistent connections, or protocol features like multiplexing.
Misconfigurations
Security group or routing errors can drop packets or add hops. Validate rules and test connectivity under load.
Over-provisioning
Upgrading instances masks architectural problems and increases cost. Diagnose before you scale up.
Example

If CloudWatch shows high NetworkOut but the application is slow, check for chatty calls. Batching or persistent connections often reduces overhead more effectively than larger instances.
