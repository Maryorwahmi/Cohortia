Practical: Creating a Gateway VPC Endpoint for S3

A step-by-step walkthrough in the AWS Console.

Scenario

Your company needs to ensure all S3 traffic from its AppVPC remains private and cost-optimized, currently accessing S3 over the Internet Gateway.

  • •Navigate: Go to VPC console > Endpoints > Create Endpoint.
  • •Select Service: Choose 'AWS services' and search for com.amazonaws.us-east-1.s3 (Gateway).
  • •Configure VPC: Select your target VPC (e.g., AppVPC).
  • •Route Tables: Select route tables associated with subnets needing S3 access.
  • •Policy: For this exercise, leave as 'Full Access'.
  • •Create: Click 'Create endpoint'.
Key Takeaway

Creating a Gateway VPC Endpoint for S3 is a quick, impactful step to enhance security and eliminate egress costs for S3 traffic.

AWS Console Walkthrough
Step 1: Locate Endpoints

In the VPC console, find 'Endpoints' under 'Virtual Private Cloud'.

Step 2: Select S3 Gateway Service

Choose 'AWS services' and select the S3 Gateway endpoint for your region.

Step 3: Associate Route Tables

Crucially, select the route tables of the subnets that need S3 access.

Step 4: Create Endpoint

Review settings and click 'Create endpoint' to finalize the configuration.
