Minimizing Egress Data Transfer Costs

Keeping traffic within the AWS network to reduce charges.

Core Principle

Ingress data transfer to AWS is generally free, but egress data transfer (data leaving AWS) is almost always charged. Design to keep traffic private.

  • •Egress Charges: Apply to data to the internet, between regions, and sometimes between Availability Zones.
  • •Private IP Priority: When EC2 instances communicate within the same VPC using private IPs, traffic is not charged.
  • •Cross-AZ Costs: Be aware that even within the same region, data transfer between different AZs can incur costs.
Key Takeaway

Proactively design your network to keep traffic within the AWS private network to significantly reduce unexpected egress data transfer costs.
