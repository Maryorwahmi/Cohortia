Module 4 › Chapter 4.1 › Common Mistakes and Best Practice
Pitfalls

Common mistakes

  • Assuming TGW route tables act like VPC route tables that resolve to ENIs
  • Overlapping CIDR ranges across attached VPCs or on-prem networks
  • Enabling propagation too broadly and exposing unintended routes
Best practice
Use separate TGW route tables for different trust zones, document ownership, and enforce least-privilege propagation.
Operational checklist
  1. Assign unique CIDRs across on-prem and AWS VPCs
  2. Define attachment ownership and association roles
  3. Restrict propagation and review route tables regularly
Scenario check
If a security VPC must inspect traffic, associate app attachments to the table that forwards to the security attachment before other routes are allowed.
