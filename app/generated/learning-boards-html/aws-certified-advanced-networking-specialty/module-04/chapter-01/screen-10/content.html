Architecture

Central TGW and AWS RAM

Share a centrally owned TGW with multiple accounts using AWS Resource Access Manager so attachments from application accounts can connect to the hub.

Benefits
  • Centralized route and security control
  • Easier auditing and review of TGW configuration
  • Clear ownership model for network changes
Operational checklist
  • Decide whether to auto-accept shared attachments or require manual acceptance
  • Document who associates attachments to TGW route tables
  • Audit propagations and restrict propagation where necessary
Scenario
Network team owns TGW. App teams attach their VPCs via RAM; network team controls route tables and propagation policies to enforce security boundaries.
