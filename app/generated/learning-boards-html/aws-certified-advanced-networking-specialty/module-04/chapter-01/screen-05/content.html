Module 4 › Chapter 4.1 › What is AWS Transit Gateway?
Definition

Transit Gateway

A managed regional hub that attaches VPCs, VPNs, and Direct Connect Gateways and routes traffic between them using TGW route tables.

Attachment
A logical connection from a VPC, VPN, or Direct Connect Gateway into the Transit Gateway.
TGW route table
Routes that determine how traffic moves between attachments; supports association and propagation.
Concrete example
Ten VPCs attach once to a TGW instead of creating 45 peering connections. TGW route tables control which attachments can reach each other.
Why choose TGW?
  • Simplified connection count and centralized routing
  • Built-in transitive routing between attachments
  • Supports hybrid links like Site-to-Site VPN and Direct Connect
Misconception check
TGW is not a magic resolver for CIDR overlap. Unique CIDR planning remains critical and propagations must be managed intentionally.
