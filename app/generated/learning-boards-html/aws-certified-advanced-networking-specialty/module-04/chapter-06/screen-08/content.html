Security Group Checklist

Verify security groups on instances allow necessary traffic in both directions.

Inbound Rules

Allow traffic on required ports/protocols from the correct source CIDRs or security groups.

Outbound Rules

Ensure instances can initiate connections to their intended destinations.

Key Takeaway

Security groups are stateful instance-level firewalls; verify both inbound and outbound rules for correct ports, protocols, and source/destination ranges.
