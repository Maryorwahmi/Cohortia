AWS Troubleshooting Tools
Amazon CloudWatch

Monitor TGW metrics like BytesIn, PacketsDropCount.

Reachability Analyzer

Static analysis of network configuration for reachability.

Reachability Analyzer Output Example
Path status: Not reachable
Failure reason: Route in TGW-RT-Prod for 10.2.0.0/16 is missing.

Integrated Diagnostics

AWS offers powerful tools for both proactive monitoring and precise path analysis.

CloudWatch Metrics

Monitor TGW health indicators like dropped packets and connection errors for early detection.

Reachability Analyzer

Provides a detailed breakdown of network path failures, pinpointing exact misconfigurations.

Key Takeaway

Combine CloudWatch for monitoring TGW health with Reachability Analyzer for precise, static path analysis to quickly identify and resolve network issues.
