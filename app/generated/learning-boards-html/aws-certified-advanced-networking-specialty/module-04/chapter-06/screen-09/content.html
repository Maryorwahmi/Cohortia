NACL Checklist

NACLs are stateless; ensure explicit rules for both inbound and outbound traffic, and mind the rule order.

Stateless Rules

Explicitly allow both inbound and outbound traffic. Return traffic is not automatically permitted.

Rule Order Matters

NACLs process rules numerically; ensure specific ALLOW rules are before broad DENY rules.

Key Takeaway

NACLs are stateless and process rules in order; always verify both inbound and outbound rules, and be mindful of implicit denies and rule precedence.
