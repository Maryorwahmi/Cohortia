Incorrect VPC Routes

A common oversight is forgetting to configure VPC route tables to direct traffic to the Transit Gateway.

The Problem

Traffic from a source VPC destined for another VPC via TGW never leaves the source VPC.

Solution

Add a route in the source VPC's route table for the destination CIDR, targeting the TGW ID.

Key Takeaway

Always verify VPC route tables first; a missing route to the TGW is a fundamental connectivity blocker.
