Module 4 › Chapter 4.2 › VPC vs TGW Route Tables
TGW Route Table

Forwards between attachments

Uses propagated attachment CIDRs to route traffic to the correct attachment ID.

  • Propagation learns CIDRs from attachments.
  • Association determines which table an attachment uses.
VPC Route Table

Directs traffic out of a VPC

Must have routes that target the Transit Gateway ID for remote CIDRs before traffic will be forwarded by the TGW.

  • Local routes stay inside the VPC.
  • Non-local routes must point to the TGW to reach other VPCs.
Concrete Example
VPC-App1 Route Table
Destination     Target
10.1.0.0/16     Local
10.2.0.0/16     tgw-0123456789abcdef0

TGW Default Route Table
10.1.0.0/16     VPC-App1-Attachment
10.2.0.0/16     VPC-App2-Attachment
Key Takeaway

Both the TGW route table and VPC route tables must be configured: TGW forwards, VPC sends traffic to the TGW.
