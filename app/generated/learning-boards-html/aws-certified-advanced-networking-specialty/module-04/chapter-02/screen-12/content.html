Module 4 › Chapter 4.2 › Verify Inter-VPC Communication
Lab Steps
  1. Launch EC2 instance in VPC-App1 subnet, allow ICMP in SG.
  2. Launch EC2 instance in VPC-App2 subnet, allow ICMP in SG.
  3. From App1 instance, ping App2 private IP; note result.
  4. If fail, verify VPC-App1 route table points 10.2.0.0/16 to TGW ID.
  5. Check TGW route table for propagated 10.2.0.0/16 and correct attachment.
Verification Commands (conceptual)
# Confirm main route table id
aws ec2 describe-route-tables --filters "Name=vpc-id,Values=$VPC_A_ID" "Name=association.main,Values=true"

# Check TGW route table entries in console or via describe-transit-gateway-route-tables
Key Takeaway

Instance-level tests plus route table inspection quickly reveal whether an issue is routing, attachment, or security related.
