Module 4 › Chapter 4.2 › Create a Transit Gateway
Definition

Transit Gateway creation options

Each option affects routing behavior or integration with hybrid networks.

Amazon Side ASN — used for BGP when pairing TGW to on-prem routers. Prefer private ASNs for internal setups.
DNS Support — enables cross-VPC name resolution when configured with resolvers.
VPN ECMP — allows multiple equal-cost VPN tunnels for active/active VPN paths.
Common misconception
Some expect TGW creation alone to enable all cross-account attachments. Resource sharing and acceptance are still required for attachments from other accounts.
Console walkthrough (visualized)
1. Open VPC Console → Transit Gateways
2. Click Create transit gateway
3. Set Name, Description
4. Set Amazon side ASN (e.g., 64512)
5. Enable DNS support? (enable/disable)
6. Enable VPN ECMP? (enable/disable)
7. Leave Auto accept shared attachments=enable for now
8. Create and note TransitGatewayId
Example
Use ASN 64512 for an internal TGW that will peer with no on-prem BGP initially.
Key Takeaway
Pick an ASN and TGW flags that match your hybrid plan; note them for later BGP and routing configuration.
