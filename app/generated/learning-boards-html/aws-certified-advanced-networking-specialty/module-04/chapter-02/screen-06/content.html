Core Concept

Association vs Propagation

Association selects which TGW route table an attachment uses. Propagation causes the TGW to learn the attachment CIDRs.

TGW Route Table Example
When VPC-App1 and VPC-App2 are associated and propagated to the default TGW route table, the TGW contains routes for their CIDRs that point to each attachment.
Misconception
Propagation into TGW does not automatically change VPC route tables; you must add VPC routes pointing to the Transit Gateway ID.

Key Takeaway

Use association to place attachments in the right TGW table and propagation to learn CIDRs; update VPC routes to send traffic to the TGW.
