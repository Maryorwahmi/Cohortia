Deploying and Configuring Transit Gateway

An orientation to the steps, why each one matters, and how this fits into a hub-and-spoke architecture.

In this lesson you'll learn how to create a Transit Gateway, choose an Amazon Side ASN for BGP, attach VPCs with ENIs in multiple AZs, propagate routes into the TGW route table, and then update VPC route tables so traffic flows correctly. We'll also demonstrate sharing the TGW with other accounts using AWS Resource Access Manager.
