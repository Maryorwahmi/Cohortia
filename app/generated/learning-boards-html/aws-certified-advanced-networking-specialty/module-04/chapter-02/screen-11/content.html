Module 4 › Chapter 4.2 › Common Mistakes & Troubleshooting
Troubleshooting Steps
  • Confirm VPC route tables have routes pointing to the Transit Gateway ID for remote CIDRs.
  • Check TGW route table propagation and association for the attachments.
  • Ensure ENIs are present in the expected subnets across AZs.
  • Verify security groups and NACLs allow the test traffic.
  • If using RAM, check the resource share acceptance state.
Practical verification
Launch an EC2 instance in each VPC, allow ICMP in security groups, and attempt to ping. If pings fail, check VPC routes first, then TGW propagation, then security settings.
Common mistake
Assuming TGW propagation alone permits instance traffic. Remember: VPC route tables must target the TGW for egress to other VPCs.
Key Takeaway

Follow a methodical checklist: VPC routes, TGW propagation, ENIs in subnets, and security rules. Use instance-level tests to isolate the failure domain.
