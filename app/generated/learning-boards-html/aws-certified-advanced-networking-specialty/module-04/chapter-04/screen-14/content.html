Chapter Summary

Key Concepts: Inter-Region & Hybrid Connectivity

Essential Terms to Remember

Transit Gateway Peering

A connection between two Transit Gateways in different AWS regions, enabling inter-region network connectivity.

Site-to-Site VPN Attachment

Connecting an on-premises network to a Transit Gateway via a secure IPsec VPN tunnel, typically using BGP.

Direct Connect Gateway (DXGW)

A global resource allowing Direct Connect connections to multiple VPCs or Transit Gateways across regions.

Summary Takeaway

Transit Gateway is central to building scalable inter-region and hybrid cloud networks, leveraging peering, VPN, and Direct Connect Gateway.
