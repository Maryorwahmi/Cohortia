Establishing TGW Peering Connections

Initiating and Accepting Peering Requests

01

Initiate Peering Request

From the requesting TGW's region, create a peering attachment. Specify the peer TGW ID, peer AWS account ID, and peer region. This sends an invitation to connect.

Example

aws ec2 create-transit-gateway-peering-attachment --transit-gateway-id tgw-0aaa --peer-transit-gateway-id tgw-0bbb --peer-account-id 123456789012 --peer-region us-west-2

02

Accept Peering Request

The owner of the peer TGW must accept the incoming request. This action completes the peering connection, changing its state to 'available'.

Important Note

Acceptance is required from the peer account. Without it, the connection remains pending and unusable.

Key Takeaway

TGW peering is a two-step process: initiation by one TGW owner and explicit acceptance by the peer TGW owner.
