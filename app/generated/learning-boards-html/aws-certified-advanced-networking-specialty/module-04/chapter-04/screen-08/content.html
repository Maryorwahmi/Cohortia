Hybrid Connectivity

AWS Site-to-Site VPN with Transit Gateway

Secure and Scalable On-Premises Connections

Simplified VPN Attachment

Instead of individual VPNs to each VPC, create a single VPN connection from your on-premises customer gateway directly to the Transit Gateway. This centralizes routing.

Dynamic Routing with BGP

BGP dynamically exchanges routes between your on-premises network and the TGW, simplifying configuration.

Scalability Benefit

Easily connect new VPCs to the TGW without modifying on-premises VPN configurations.

Key Takeaway

A single Site-to-Site VPN to TGW, using BGP, centralizes on-premises connectivity to all attached VPCs.
