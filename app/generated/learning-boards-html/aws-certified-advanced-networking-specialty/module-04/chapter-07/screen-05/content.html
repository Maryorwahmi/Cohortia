Data Processing: The Variable Cost

How Data Flow Directly Impacts Your TGW Bill

Data Traversal Charge

You pay for every gigabyte of data that moves from one TGW attachment to another. This includes VPCs, VPNs, and Direct Connect connections.

Example: VPC-to-VPC Traffic

If VPC-A sends 100GB to VPC-B through the TGW, you are charged for 100GB of data processing. This is a direct cost for using TGW as the intermediary.

Example: Hybrid Connectivity

Data flowing from your on-premises network to an AWS VPC via Direct Connect Gateway and TGW also incurs this data processing charge.

Key Idea

The data processing charge is the most variable TGW cost, directly proportional to the volume of data flowing between connected networks via the TGW.

Common Misconception

Some believe all traffic within a TGW-connected network is charged. However, only data that actively traverses the TGW from one attachment to another incurs this specific processing fee.

Key Takeaway

Monitor TGW traffic patterns closely to identify and optimize high-volume data flows that contribute most to data processing costs.
