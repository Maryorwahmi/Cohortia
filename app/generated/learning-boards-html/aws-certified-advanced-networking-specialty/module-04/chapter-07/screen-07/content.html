Cost Optimization Strategy

Centralizing Egress for Savings

Consolidating NAT Gateways with TGW

Centralized Egress/Ingress

Route all outbound (egress) and inbound (ingress) traffic through a dedicated security VPC connected to the TGW.

NAT Gateway Consolidation

Deploy a single NAT Gateway (or a highly available pair) in the security VPC to serve multiple application VPCs, reducing overall NAT Gateway costs.

Cost Benefit

Even with TGW data processing charges, the savings from consolidating NAT Gateways often outweigh the TGW costs, leading to a net reduction in your AWS bill.

Key Idea

Centralizing egress through a security VPC with TGW is a powerful cost optimization strategy that consolidates shared services like NAT Gateways, leading to overall cost reductions despite TGW data processing charges.

Example Scenario

Instead of 10 NAT Gateways across 10 VPCs, you have 1 NAT Gateway in a central security VPC. All 10 VPCs route internet-bound traffic through the TGW to this central NAT Gateway, saving on 9 NAT Gateway deployments.

Key Takeaway

Evaluate the total cost of ownership for decentralized vs. centralized shared services; TGW can enable significant savings through consolidation.
