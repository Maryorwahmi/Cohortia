Resilience & Control

Building Resilient TGW Architectures

Ensuring Uptime and Preventing IP Conflicts

High Availability & Resilience

Select subnets in at least two Availability Zones for TGW ENIs, configure both VPN tunnels, and consider redundant Direct Connect connections.

IP Address Management (IPAM)

Implement a robust IPAM strategy across all VPCs and on-premises networks to prevent overlapping CIDR blocks and routing conflicts.

Benefit: AWS IPAM

AWS IPAM helps plan, track, and manage IP address space, simplifying network design and preventing operational headaches.

Key Idea

Designing for high availability by distributing TGW ENIs across AZs and implementing a robust IPAM strategy are critical best practices for building resilient and conflict-free TGW network architectures.

Example: Multi-AZ ENIs

When creating a TGW attachment for a VPC, selecting subnets in us-east-1a and us-east-1b ensures that if one AZ goes down, traffic can still flow through the TGW via the other AZ's ENI.

Key Takeaway

Prioritize multi-AZ deployments for TGW attachments and implement a strong IPAM strategy to ensure network resilience and prevent costly routing issues.
