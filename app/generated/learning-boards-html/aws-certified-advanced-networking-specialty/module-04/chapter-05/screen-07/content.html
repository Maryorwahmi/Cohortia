Implementing TGW Segmentation: Route Tables & Propagations

Step-by-step guide to isolating VPCs using TGW routing.

Key Configuration Actions

  • •**Create TGW Route Tables:** Establish `TGW-RT-Prod`, `TGW-RT-Dev`, and `TGW-RT-Shared`.
  • •**Associate Attachments:** Link `VPC-Prod` to `TGW-RT-Prod`, `VPC-Dev` to `TGW-RT-Dev`, and `VPC-SharedServices` to `TGW-RT-Shared`.
  • •**Propagate Shared Services:** Propagate `VPC-SharedServices` CIDR into `TGW-RT-Prod` and `TGW-RT-Dev`.
  • •**Prevent Direct Propagation:** Crucially, DO NOT propagate `VPC-Prod` CIDR into `TGW-RT-Dev` or vice-versa.
  • •**Update VPC Route Tables:** Ensure each VPC's route table points to the TGW for inter-VPC traffic.
Pro Tip

Use Infrastructure as Code (IaC) like CloudFormation or Terraform to manage TGW configurations for consistency and version control.
