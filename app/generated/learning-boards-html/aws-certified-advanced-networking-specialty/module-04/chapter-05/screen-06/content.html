Scenario Example

Segmenting Prod, Dev, and Shared Services VPCs

Applying TGW route tables for practical network isolation.

The Segmentation Goal

  • •**Prod & Dev Access Shared:** Production and Development VPCs must reach Shared Services (e.g., DNS, AD).
  • •**Prod & Dev Isolation:** Production and Development VPCs must NOT communicate directly with each other.
  • •**Centralized Egress (Upcoming):** All internet-bound traffic should flow through a dedicated Security VPC for inspection.
Why it Matters

Achieving this isolation prevents lateral movement of threats between environments and enforces compliance, critical for enterprise security.
