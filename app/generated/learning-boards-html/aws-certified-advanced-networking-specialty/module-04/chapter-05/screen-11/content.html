Routing Flow

Firewall Integration: Routing to the Appliance

Directing traffic from TGW to the firewall within the Security VPC.

Routing Steps to Firewall

  • •**Application VPCs to TGW:** Application VPCs send traffic to the Transit Gateway.
  • •**TGW Route Table (App VPCs):** TGW route tables associated with application VPCs have routes (e.g., `0.0.0.0/0` or specific CIDRs) pointing to the Security VPC attachment.
  • •**Traffic to Security VPC:** Traffic is directed to the TGW ENI within the Security VPC.
  • •**Security VPC Routing:** Within the Security VPC, routes send traffic from the TGW ENI to the firewall appliance's ENI.
Key Consideration

Ensure VPC route tables in the Security VPC correctly forward traffic from the TGW ENI to the firewall's network interface.
