Firewall Integration: Return Path and 'Sandwich' Architecture

Ensuring traffic returns through TGW after inspection.

The 'Sandwich' Architecture

  • •**Firewall Forwarding:** After inspection, the firewall forwards traffic back.
  • •**Firewall Routing:** Firewall's routing table directs traffic (e.g., `0.0.0.0/0`) back to the TGW ENI in the Security VPC.
  • •**Return to TGW:** Traffic re-enters the TGW via the Security VPC attachment.
  • •**TGW to Destination:** TGW routes traffic to its final destination (another VPC or external network).
Critical Note

This architecture requires careful synchronization of routing tables at the VPC, TGW, and firewall levels to ensure symmetrical traffic flow.
