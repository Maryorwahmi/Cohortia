Configuring Centralized Egress Routing

Implementing the default route to the Security VPC.

Key Configuration Steps

  • •**Application TGW Route Tables:** For each application VPC (e.g., `VPC-App1`, `VPC-App2`), identify its associated TGW route table.
  • •**Add Default Route:** In these application TGW route tables, add a static route for `0.0.0.0/0`.
  • •**Target Security VPC Attachment:** Set the target of the `0.0.0.0/0` route to the attachment ID of your `VPC-Security`.
  • •**Security VPC Routing:** Ensure the `VPC-Security`'s TGW route table has routes to the internet (via IGW/NAT Gateway).
  • •**VPC Route Tables:** Verify application VPC route tables point `0.0.0.0/0` to their TGW ENI.
Example Route

`0.0.0.0/0` -> `tgw-attach-security-vpc-id`
