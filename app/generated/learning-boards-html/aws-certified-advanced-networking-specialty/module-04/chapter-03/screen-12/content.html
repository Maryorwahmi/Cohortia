Module 4 › Chapter 4.3 › Hands-on: Configure Routes
Scenario recap
VPC-App 10.1.0.0/16 and VPC-SharedServices 10.2.0.0/16 attached to TGW tgw-0123456789abcdef0. Create TGW-RT-App and TGW-RT-Shared, associate attachments, enable propagation across tables, and add a static route for 10.2.100.0/24.
TGW_ID="tgw-0123456789abcdef0" # replace with your TGW ID
APP_RT_ID=$(aws ec2 create-transit-gateway-route-table --transit-gateway-id $TGW_ID --tag-specifications "ResourceType=transit-gateway-route-table,Tags=[{Key=Name,Value=TGW-RT-App}]" --query TransitGatewayRouteTable.TransitGatewayRouteTableId --output text --region $AWS_REGION)
SHARED_RT_ID=$(aws ec2 create-transit-gateway-route-table --transit-gateway-id $TGW_ID --tag-specifications "ResourceType=transit-gateway-route-table,Tags=[{Key=Name,Value=TGW-RT-Shared}]" --query TransitGatewayRouteTable.TransitGatewayRouteTableId --output text --region $AWS_REGION)

echo "App RT: $APP_RT_ID"
echo "Shared RT: $SHARED_RT_ID"

# Associate attachments (replace with your attachment IDs)
APP_ATTACH_ID="tgwa-0abcdef1234567890"
SHARED_ATTACH_ID="tgwa-0fedcba9876543210"

aws ec2 associate-transit-gateway-route-table --transit-gateway-route-table-id $APP_RT_ID --transit-gateway-attachment-id $APP_ATTACH_ID --region $AWS_REGION
aws ec2 associate-transit-gateway-route-table --transit-gateway-route-table-id $SHARED_RT_ID --transit-gateway-attachment-id $SHARED_ATTACH_ID --region $AWS_REGION

# Enable propagation between tables
aws ec2 enable-transit-gateway-route-table-propagation --transit-gateway-route-table-id $SHARED_RT_ID --transit-gateway-attachment-id $APP_ATTACH_ID --region $AWS_REGION
aws ec2 enable-transit-gateway-route-table-propagation --transit-gateway-route-table-id $APP_RT_ID --transit-gateway-attachment-id $SHARED_ATTACH_ID --region $AWS_REGION

# Add static route for legacy subnet
aws ec2 create-transit-gateway-route --transit-gateway-route-table-id $APP_RT_ID --destination-cidr-block "10.2.100.0/24" --transit-gateway-attachment-id $SHARED_ATTACH_ID --region $AWS_REGION
Verification steps
  • Open TGW Console → Transit Gateway Route Tables → Select table → Routes and Propagations tabs.
  • Confirm propagated CIDRs appear and that the static 10.2.100.0/24 is listed in TGW-RT-App.
  • From an instance in VPC-App, attempt to reach a resource in 10.2.100.0/24 and observe the path.
Key Takeaway

Use the CLI sequence to reproduce the activity. Always verify routes and propagations in the console and test connectivity end-to-end after changes.
