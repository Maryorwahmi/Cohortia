Static route behavior
Static routes are manual, take precedence, and are useful for overrides and appliance steering.
Example
Add a static route 0.0.0.0/0 in TGW-RT-App pointing to the Egress VPC attachment so all unmatched traffic is forced through a centralized firewall.
Misconception
A propagated route does not override a static route. If you need a propagated route to be preferred, remove or narrow the static entry.
Design tip
Use static routes for critical control paths and document them. Consider tag-based naming to identify purpose and owner.
Precedence rules to remember
  • Static route exists → it takes precedence over propagated entries for the same CIDR.
  • If multiple routes match, longest prefix match determines the winner.
  • Blackhole is a special static target that intentionally drops traffic.
Scenario
You want to ensure a legacy subnet always traverses a monitoring appliance. Create a static route for the legacy subnet in the appropriate TGW route table pointing to the appliance's attachment.
