Border Gateway Protocol (BGP)
Used for dynamic route exchange with VPN and Direct Connect; verify Amazon Side ASN compatibility.
Longest Prefix Match
The most specific matching CIDR determines forwarding; use it to override broad routes with precise ones.
Blackhole Route
A static entry that intentionally drops traffic. Use only when you need a deliberate block and document it.
Closing takeaway

Adopt a short TGW troubleshooting ritual: check BGP, propagations, associations, routes, and VPC route tables to resolve most routing issues quickly.
