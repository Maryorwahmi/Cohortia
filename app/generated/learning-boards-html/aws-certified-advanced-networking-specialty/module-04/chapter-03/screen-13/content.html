Module 4 › Chapter 4.3 › Key Concepts — Part 1
Explicit Association
Defines which TGW route table an attachment uses for traffic originating from that attachment.
Route Propagation
Automatically adds CIDRs from attachments or BGP-learned routes into a TGW route table.
Static Routes
Manual entries that take precedence over propagated routes for precise steering and overrides.
Summary takeaway

Master these three primitives and you can design predictable TGW routing for both cloud-only and hybrid architectures.
