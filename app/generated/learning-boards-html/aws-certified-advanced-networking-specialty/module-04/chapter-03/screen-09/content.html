Module 4 › Chapter 4.3 › Longest Prefix Match
How specificity decides forwarding
The longest (most specific) matching CIDR wins among multiple candidate routes.
Worked example
TGW routes: 10.0.0.0/8 → Attachment-A (propagated); 10.0.1.0/24 → Attachment-B (static). Traffic to 10.0.1.50 will follow 10.0.1.0/24 and go to Attachment-B because it is the longer prefix.
Design implication
Use broad propagated ranges for general reachability and reserve specific static prefixes for appliance routing or security exceptions.
Quick checklist
  • When adding a static child prefix, ensure it is more specific than any existing propagated parent.
  • Confirm no unexpected overlap that could redirect traffic away from intended attachments.
  • Test with specific destination addresses to validate the chosen path.
Misconception
Ordering in the console does not change which route is selected—only prefix specificity matters.
