Module 4 › Chapter 4.3 › Learning Objectives — Practical Milestones
Milestone 1 — Segmented associations
Create two TGW route tables and explicitly associate attachments so that traffic origins use different route tables. Verify one-way access by propagating only the production attachment into the dev table.
Milestone 2 — Static override
Add a static route like a 0.0.0.0/0 entry directing to an Egress VPC attachment to ensure centralized internet egress and firewall traversal.
Milestone 3 — BGP sanity checks
Confirm the Amazon Side ASN and that routes learned from on-premises devices appear as propagated entries in the TGW route table.
Milestone 4 — Blackhole and trace
Introduce a blackhole route for a test CIDR to observe dropped traffic and document the symptoms in TGW and VPC route tables.
Verification checklist
  • Inspect TGW route table Routes and Propagations tabs.
  • Confirm VPC route tables include TGW targets where needed.
  • Run controlled ping or application tests across attachments.
Quick reminder

Plan changes carefully and test in a sandbox. A single 0.0.0.0/0 in the wrong table can redirect traffic unexpectedly.
