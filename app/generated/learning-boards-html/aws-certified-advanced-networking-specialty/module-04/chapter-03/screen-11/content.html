Module 4 › Chapter 4.3 › Troubleshooting TGW Routing
Troubleshooting checklist
  1. Confirm VPC route table has TGW target for the destination.
  2. Check TGW Route Table for a matching route entry.
  3. Inspect Propagations to see if the destination CIDR was learned.
  4. Verify Associations — the source attachment must be associated to the table you checked.
  5. Look for static overrides or blackholes and assess longest-prefix interactions.
  6. For hybrid paths, validate BGP session state and advertised prefixes.
Diagnostic scenario
If VPC-A cannot reach VPC-B: 1) Ensure VPC-A route table points to TGW for VPC-B. 2) In TGW, confirm the table associated with VPC-A contains a route for VPC-B via the VPC-B attachment. 3) If missing, enable propagation of VPC-B into that table or add a static route. 4) Check VPC security groups and NACLs as additional blockers.
Common oversight
Forgetting to add a TGW target in the VPC route table for return traffic often causes apparent one-way connectivity issues.
