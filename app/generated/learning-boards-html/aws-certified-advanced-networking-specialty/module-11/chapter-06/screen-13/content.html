Chapter Recap

Essential Outposts Terminology

Revisiting the foundational terms for AWS Outposts deployments.

AWS Outposts

A fully managed service extending AWS infrastructure, services, APIs, and tools to customer on-premises facilities.

Outposts Rack

A rack-scale deployment of AWS hardware, offering a broad selection of EC2, EBS, and other AWS services on-premises.

Outposts Server

A smaller, 1U or 2U server form factor for deploying AWS compute and storage in existing racks at edge locations.

Summary Takeaway

AWS Outposts extends the cloud to your premises, offering both rack-scale and compact server options to meet diverse hybrid and edge computing needs.
