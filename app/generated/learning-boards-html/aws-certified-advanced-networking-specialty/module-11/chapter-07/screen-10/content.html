Customer-Owned IP Addresses (CoIPs)

Using Your Own IP Ranges on Outpost Resources

  • Custom IP Ranges: Use your own publicly or privately routable IP address ranges on Outpost resources.

  • On-Premises Access: Enables on-premises applications to communicate with Outpost resources using existing IP schemes.

  • Outbound Internet: Route outbound internet traffic from Outpost instances through your on-premises network and firewall.

Key Takeaway

CoIPs provide flexibility in IP addressing, allowing Outpost resources to integrate seamlessly with on-premises networks and security policies.
