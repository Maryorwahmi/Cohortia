The Local Gateway (LGW)

Bridging Outpost Resources to Your Local Network

  • Logical Component: The LGW is a key logical component residing on your AWS Outpost.

  • Network Interface: It serves as the primary network interface between Outpost resources and your on-premises network.

  • Local Communication: Enables Outpost instances to communicate with on-premises resources using private IP addresses.

Key Takeaway

The LGW is essential for integrating Outpost resources with your local network, facilitating seamless on-premises communication.
