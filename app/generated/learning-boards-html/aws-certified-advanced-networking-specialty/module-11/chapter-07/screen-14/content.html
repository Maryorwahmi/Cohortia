Key Concepts

Essential Terms for Outposts Networking

Service Link

The critical network connection between an Outpost and its parent AWS Region for control plane, management, and regional service access.

Local Gateway (LGW)

A logical component on an Outpost that serves as the network interface between Outpost resources and the on-premises network.

Customer-Owned IP Addresses (CoIPs)

IP address ranges that customers own and use for their Outposts resources, allowing on-premises applications to communicate using local IP addresses.

Summary Takeaway

The Service Link, Local Gateway, and CoIPs are fundamental to understanding and configuring robust networking for AWS Outposts, enabling seamless hybrid cloud operations.
