Networking Fundamentals

Connecting in a Local Zone

VPC extension and local internet access.

Key Takeaway

The Local Internet Gateway (LIG) is crucial for minimizing latency by providing direct internet egress from the Local Zone, avoiding traffic routing back to the parent Region.

Example: Localized Web Service

A web application deployed in a Local Zone uses an LIG. User requests from the local city hit the application, and any external API calls made by the application also exit directly from the Local Zone, ensuring end-to-end low latency.
