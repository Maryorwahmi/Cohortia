Key Concepts

Essential terms for AWS edge computing

AWS Local Zone

An extension of an AWS Region into a specific geographic area, bringing select AWS services closer to end-users for ultra-low latency.

AWS Wavelength Zone

An AWS infrastructure deployment embedded within a communication service provider's 5G network, bringing AWS compute and storage to the edge of the 5G network.

Local Internet Gateway (LIG)

A component in a Local Zone that provides direct, low-latency internet access from the Local Zone, bypassing the parent Region.

Summary Takeaway

Local Zones and Wavelength Zones are AWS's strategic solutions for ultra-low latency edge computing, each serving distinct geographical and network requirements.
