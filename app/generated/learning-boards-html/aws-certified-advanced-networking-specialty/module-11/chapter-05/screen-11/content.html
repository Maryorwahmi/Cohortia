Architecture Pattern

Active/Active Distribution Architecture

Achieving global redundancy and load distribution

Active/Active Configuration

  • Multiple Active Regions: Endpoint groups in 2+ regions, all with traffic dials > 0%.
  • Proportional Dials: Set percentages based on capacity or desired load distribution (e.g., 50/50).
  • Nearest Healthy Endpoint: Global Accelerator routes users to the closest healthy active endpoint.
  • Continuous Service: All regions serve traffic simultaneously.

Example: Global SaaS Platform

A SaaS application runs in us-east-1, eu-west-1, and ap-southeast-2, all with 100% traffic dials. Global Accelerator routes users to their nearest region, providing low latency and ensuring continuous operation even if one region experiences issues.

Benefits of Active/Active

  • Maximum Availability: No single point of failure across regions.
  • Optimal Performance: Users routed to the geographically closest endpoint.
  • Load Distribution: Spreads traffic across multiple regions, preventing overload.
  • Enhanced Fault Tolerance: Automatic rerouting to remaining healthy regions during outages.
Key Takeaway

Active/active architecture with Global Accelerator delivers superior availability, performance, and load distribution for truly global applications by utilizing multiple regions concurrently.
