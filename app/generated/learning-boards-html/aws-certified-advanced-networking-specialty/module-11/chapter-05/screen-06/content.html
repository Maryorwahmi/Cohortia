Global Accelerator with Network Load Balancers (NLB)

Achieving extreme performance for TCP/UDP applications

NLB Advantages for GA

  • Layer 4 Operation: Handles TCP, UDP, and TLS passthrough traffic efficiently.
  • Ultra-Low Latency: Designed for millions of requests per second with minimal latency.
  • Static IP Support: Provides a stable IP address for the load balancer.
  • High Throughput: Ideal for applications requiring massive data transfer.

Use Case: Real-time Gaming

A global multiplayer game requires consistent, low-latency connections. Global Accelerator routes players to the nearest NLB, which then efficiently distributes TCP/UDP game traffic to backend game servers, ensuring optimal player experience.

How it Delivers Performance

Global Accelerator directs traffic to the NLB, which operates at the transport layer (Layer 4). This allows for direct forwarding to target instances with minimal processing, making it highly efficient for latency-sensitive and high-throughput applications.
