Global Accelerator Health Checks

Ensuring continuous application availability

How Health Checks Work

  • Continuous Monitoring: Global Accelerator constantly checks endpoint health.
  • Leverages ELB Checks: For ALBs/NLBs, it uses their integrated health check mechanisms.
  • Direct EC2 Checks: For EC2 instances, configure protocol, port, and path directly in GA.
  • Automatic Failover: Unhealthy endpoints are automatically removed from traffic routing.

Example: Regional Application Failure

An application in us-east-1 becomes unresponsive due to a backend issue. Global Accelerator detects this via health checks and instantly reroutes all user traffic to a healthy replica in eu-west-1, minimizing service interruption.

Benefits of GA Health Checks

  • Faster Failover: Network-level routing avoids DNS propagation delays.
  • Enhanced Reliability: Ensures traffic only goes to truly healthy endpoints.
  • Simplified DR: Automates a critical part of disaster recovery.
  • Improved User Experience: Reduces downtime and latency during regional outages.
Key Takeaway

Global Accelerator's health checks are vital for high availability, enabling rapid, automatic failover to healthy endpoints, significantly improving application resilience.
