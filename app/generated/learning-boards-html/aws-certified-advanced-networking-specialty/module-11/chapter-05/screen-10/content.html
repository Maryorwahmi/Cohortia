Active/Passive Failover Architecture

Designing for robust disaster recovery with Global Accelerator

Active/Passive Configuration

  • Primary Region: Traffic dial set to 100% (active).
  • Secondary Region: Traffic dial set to 0% (passive/standby).
  • Health Checks: Global Accelerator continuously monitors both regions.
  • Automatic Failover: If primary fails, traffic automatically shifts to secondary.

Example: DR for a Critical Service

A financial service runs in us-east-1 (primary) with a replica in us-west-2 (passive). If us-east-1 experiences a major outage, Global Accelerator detects the failure and reroutes all client connections to us-west-2, ensuring business continuity.

Benefits for Disaster Recovery

  • Rapid Recovery: Significantly faster failover than DNS-based methods.
  • Consistent Entry Point: Static Anycast IPs remain the same during failover.
  • Reduced RTO: Minimizes Recovery Time Objective by automating traffic redirection.
  • Simplified Operations: Global Accelerator handles the failover logic.
Key Takeaway

Active/passive failover with Global Accelerator provides a robust and rapid disaster recovery strategy, ensuring minimal downtime for critical applications.
