Integration Pattern

Global Accelerator with Application Load Balancers (ALB)

Optimizing web application delivery globally

Key Benefits

  • Global Performance: Routes users to the nearest healthy ALB over the AWS global network.
  • Layer 7 Features: Leverages ALB's path-based routing, host-based routing, and SSL termination.
  • Automatic Failover: Seamlessly redirects traffic to healthy ALBs in other regions upon failure.
  • Static Anycast IPs: Provides a consistent entry point for your application.

Example Scenario: Global Web App

An e-commerce platform uses ALBs in us-east-1 and eu-west-1. Global Accelerator routes North American users to us-east-1 and European users to eu-west-1. If us-east-1 fails, traffic automatically shifts to eu-west-1, ensuring continuous service.

How it Works

Global Accelerator directs HTTP/S traffic to the ALB. The ALB then distributes requests to target EC2 instances. Global Accelerator performs network-level health checks, while the ALB handles application-level health checks and routing.
