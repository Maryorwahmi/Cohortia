Core Concept

Global Accelerator Endpoint Types

Connecting Global Accelerator to your AWS resources

Application Load Balancers (ALB)

Ideal for HTTP/S traffic, providing Layer 7 features like path-based routing and SSL termination. Combines global routing with advanced application-level features.

Network Load Balancers (NLB)

Best for high-performance TCP/UDP traffic, operating at Layer 4 with ultra-low latency and static IP support. Suitable for gaming, IoT, and VoIP applications.

EC2 Instances & Elastic IPs

Directly use individual EC2 instances or Elastic IP addresses as endpoints. Less common for scalable applications, typically for specific or legacy use cases.

Why Endpoint Choice Matters

  • Protocol Compatibility: Match endpoint type to your application's protocol (HTTP/S for ALB, TCP/UDP for NLB).
  • Performance Needs: NLBs offer extreme performance for latency-sensitive applications.
  • Scalability & Features: ALBs and NLBs provide built-in scalability, health checks, and advanced routing.
  • Cost Efficiency: Choose the most appropriate endpoint to optimize resource utilization and cost.
Key Takeaway

Selecting the correct endpoint type is fundamental for optimizing Global Accelerator's performance, availability, and cost-effectiveness for your specific application needs.
