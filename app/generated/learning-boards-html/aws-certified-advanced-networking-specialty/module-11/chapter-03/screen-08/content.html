Module 11 › Chapter 11.3 › AWS WAF
What it does
Application-layer filtering at the edge
WAF inspects HTTP requests and applies rules to block or allow traffic, protecting against attacks like SQL injection and XSS and enabling IP filtering.
Deployment notes
  • Associate a Web ACL with your CloudFront distribution.
  • Start with managed rules then add custom rules for application needs.
  • Use logging and metrics to refine rules and reduce false positives.
Example
Attach a Web ACL that blocks common exploit patterns and add an IP set rule to block known bad actors identified by your security team.
Common mistake
Overly broad rules that block legitimate traffic. Use logs and staged deployments to tune rules safely.
Key Takeaway

WAF applied at CloudFront stops threats before they reach your origin, but must be tuned with logs to avoid availability issues.
