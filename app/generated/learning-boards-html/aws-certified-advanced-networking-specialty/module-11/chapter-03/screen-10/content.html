Module 11 › Chapter 11.3 › Invalidation & Versioning
Invalidate
Remove cached objects by path patterns. Use for urgent fixes, but be mindful of cost and origin load during cache refill.
Best practices
  • Invalidate specific paths rather than using /* when possible.
  • Monitor origin metrics after invalidation to verify capacity.
  • Automate invalidation as part of CI/CD for critical assets.
Versioning
Use unique file names or hashed filenames for new releases. This avoids invalidation and gives clients and caches a clear signal to fetch new assets.
Concrete example
Deploy main.abc123.js for a new release rather than invalidating main.js across all caches.
