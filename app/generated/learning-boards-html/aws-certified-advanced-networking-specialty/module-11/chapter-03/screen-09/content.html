Module 11 › Chapter 11.3 › Signed Access & Encryption
Signed URLs
Best for single-file access. Signature tied to a resource and expiry, commonly used for downloads or protected assets.
Signed Cookies
Best for session-level access across many files. Easier when granting temporary access to directories or streaming sessions.
Field-Level Encryption
Encrypt specific HTTP request fields at the edge so only the origin application can decrypt them with the private key.
Concrete scenario
Use signed cookies to grant a logged-in user access to a set of media files for their session and use field-level encryption for payment fields submitted during checkout so sensitive data remains encrypted until processed by the origin application.
Key Takeaway

Pick signed URLs for single items, signed cookies for sessions, and field-level encryption to protect sensitive fields in transit to the origin.
