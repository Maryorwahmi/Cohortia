Process
How edge compression works
Origin responses
Origin returns content. If uncompressed, CloudFront can compress before delivery.
Edge compression
CloudFront applies Gzip or Brotli based on viewer Accept-Encoding and serves the compressed payload.
Viewer delivery
Viewer receives a smaller response and renders faster, reducing bandwidth costs.
Example
A site serving large CSS and JavaScript files gains reduced page load time when CloudFront compresses these files at the edge rather than relying on the origin CPU.
Common misconception
Some assume compression always lowers latency. For very small files or already compressed types, savings are negligible and can add overhead.
Key Takeaway

Edge compression reduces transfer size for text assets and offloads origin CPU; verify impact with metrics before broad rollout.
