Module 11 › Chapter 11.3 › Objectives — continued
01
AWS WAF Integration
VERIFIED COMPETENCY MILESTONE
Associate a Web ACL to block SQL injection, XSS, and known bad IPs at the distribution level. You will be able to explain the difference between a web ACL and network-level protections.
02
Signed URLs & Cookies
VERIFIED COMPETENCY MILESTONE
Generate time-limited signed URLs for single assets and signed cookies for session-level access across multiple files or directories.
03
Field-Level Encryption
VERIFIED COMPETENCY MILESTONE
Encrypt sensitive fields in requests at the edge so only the origin application with the private key can decrypt them, protecting data in transit and at rest at the origin.
04
Monitoring & Metrics
VERIFIED COMPETENCY MILESTONE
Track cache hit ratio, origin latency, and error rates to decide when to adjust TTLs, invalidate caches, or enable Origin Shield to reduce origin load.
