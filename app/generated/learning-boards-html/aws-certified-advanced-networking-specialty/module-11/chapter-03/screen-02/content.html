Module 11 › Chapter 11.3 › Learning Objectives
01
Advanced Cache Policies
VERIFIED COMPETENCY MILESTONE
Select and tune cache policies to forward only required headers, cookies, and query strings so you maximize cache hit ratio. You will explain trade-offs between personalization and cacheability with a concrete example of forwarding only an authentication cookie to protect session-specific content.
02
Edge Compression
VERIFIED COMPETENCY MILESTONE
Enable Gzip and Brotli at the edge to offload compression from your origin and reduce bandwidth. You will describe when this saves latency and when pre-compressed assets may be preferred.
03
Lambda@Edge Usage
VERIFIED COMPETENCY MILESTONE
Author lightweight functions to modify viewer or origin requests and responses. You will show an example that adds security headers and explain limits such as memory and execution time.
04
Origin Shield & Invalidation
VERIFIED COMPETENCY MILESTONE
Explain how Origin Shield consolidates cache-miss traffic to the origin and apply safe invalidation strategies and asset versioning to keep content fresh without excessive origin load.
