Module 11 › Chapter 11.3 › Cache Policies
Definition
What a cache policy controls
  • Which headers, cookies, and query strings are forwarded.
  • Default, minimum and maximum TTLs for cached objects.
  • Whether requests are cacheable based on method and authorization.
Example
E-commerce static assets should use CachingOptimized. For user-specific pages, forward an authentication cookie only when necessary, and keep product images cacheable without personalization.
Key Takeaway
Minimize forwarded attributes for public assets; version files for updates instead of frequent invalidation.
How to improve hit ratio
Normalize Requests
Use Lambda@Edge to canonicalize headers or remove tracking query strings that do not affect content identity.
Versioning
Use unique file names or query parameters for new releases to avoid invalidations.
Common mistake
Forwarding many headers to preserve personalization by default, which reduces cache hits. Instead, forward only what is essential and use edge logic for minor variations.
