Route 53 Health Checks: Monitoring Endpoint Health

Route 53 can monitor the health of your application endpoints (e.g., EC2 instances, ALBs, Global Accelerator accelerators, or custom HTTP/TCP endpoints).

  • •Sends automated requests (HTTP, TCP) to endpoints at intervals.
  • •Marks endpoints as unhealthy if they fail consecutive checks.
  • •Crucial for enabling intelligent routing policies like failover.
Example Scenario

A health check monitors your web server's HTTP endpoint. If the server stops responding to HTTP requests, the health check fails, signaling Route 53 to stop sending traffic to it.

Key Takeaway

Route 53 health checks are vital for continuously assessing endpoint health, providing the necessary intelligence for routing policies to ensure high availability.
