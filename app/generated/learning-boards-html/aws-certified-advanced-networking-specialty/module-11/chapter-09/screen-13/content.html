Resolver Endpoints: Enabling Bidirectional DNS

Route 53 Resolver endpoints are configured in your VPC to forward DNS queries from Outpost instances to on-premises DNS servers, and vice-versa.

  • •**Inbound Endpoints:** Allow on-premises to query VPC/Outpost DNS.
  • •**Outbound Endpoints:** Allow VPC/Outpost to query on-premises DNS.
  • •Ensures seamless DNS resolution across your hybrid environment.
Example Scenario

An Outpost instance queries `database.onprem.local`. An Outbound Endpoint forwards this to the on-premises DNS. An on-premises server queries `app.outpost.internal`. An Inbound Endpoint resolves this via VPC DNS.

Key Takeaway

Resolver Endpoints are the critical components that enable bidirectional DNS resolution, allowing resources in both cloud and on-premises environments to communicate seamlessly.
