Module 11 › Chapter 11.1 › Key Concepts
AWS Region

A geographic area hosting multiple AZs and the full AWS service set for compliance and locality.

Availability Zone

A discrete data center with independent infrastructure providing redundancy within a region.

Edge Location

Points of presence used for caching, DNS, and network ingress to reduce latency for end-users.

Summary

Remember the mapping: Regions for full services and residency, AZs for redundancy, Edge Locations for caching and ingress. Use CloudFront for CDN, Direct Connect for private links, Global Accelerator for backbone-based routing, and Local/Wavelength Zones for edge compute when needed.
