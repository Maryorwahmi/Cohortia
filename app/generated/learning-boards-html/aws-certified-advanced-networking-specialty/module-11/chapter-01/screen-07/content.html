Module 11 › Chapter 11.1 › Edge Types
CloudFront PoPs

Caching & CDN

Serve static and dynamic content from the nearest PoP to reduce RTT for viewers worldwide.

Example: Cache images, JS, and videos to speed page load.
Direct Connect

Private network ingress

Dedicated physical connections from on-premises to AWS for predictable performance and security.

Example: Large backups or hybrid apps needing steady bandwidth.
Global Accelerator

Backbone-based routing

Ingests traffic at edges and routes over AWS’s private backbone to the optimal endpoint to improve availability and latency for global users.

Example: Routing game or API traffic with consistent performance.
Key Takeaway

Choose the edge type by what you need to achieve: caching, private connectivity, or optimized backbone routing—proximity alone is not sufficient.
