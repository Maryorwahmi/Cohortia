Module 11 › Chapter 11.2 › Key Concepts
Content Delivery Network
A geographically distributed cache network serving content closer to users to lower latency.
CloudFront Distribution
Configuration that defines origins, cache behaviors, and security settings for delivery.
Origin
The source of your content such as S3, ALB, or EC2 instance.
Summary
These fundamentals let you reason about where content lives, how it's delivered, and how to secure and cache it properly.
