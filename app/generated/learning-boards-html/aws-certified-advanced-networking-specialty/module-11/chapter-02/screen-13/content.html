Observability and invalidations

Track cache hit ratio and origin requests; invalidate intentionally and prefer versioning to refresh assets.

Metrics to watch
Cache hit ratio, origin request rate, and edge latency reveal delivery health.
Invalidation guidance
Use invalidations for urgent updates but prefer versioned filenames to avoid frequent invalidations.
Key Takeaway

Use monitoring to detect cache inefficiencies and plan invalidations sparingly; version assets to reduce operational cost.

Concrete example
If a CSS file changes frequently during development, serve it with a short TTL or use a versioned filename like styles.v3.css, then update references in HTML to avoid mass invalidations.
Check
If cache hit ratio drops, inspect forwarded fields and unique cache keys that cause fragmentation.
Pro tip
Automate cache invalidation only for critical paths; otherwise update asset names during builds.
