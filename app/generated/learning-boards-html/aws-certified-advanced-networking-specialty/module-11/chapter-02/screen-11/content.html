Access and transport security

Combine OAC, signed URLs/cookies, HTTPS, and WAF to secure both origin access and viewer access.

Signed URLs vs Signed Cookies
Use signed URLs for single-object access and signed cookies for session-level access to multiple objects.
Transport security
Enforce HTTPS via viewer protocol policies and use ACM-managed certificates for custom domains.
Key Takeaway

Combine origin and viewer controls: OAC stops bypass, signed credentials control who can view, and HTTPS/WAF protect transport and requests.

Concrete example
Protect premium downloads with signed URLs and block common threats with WAF rules attached to the distribution. Use OAC to ensure the objects are only served through CloudFront.
Common mistake
Relying on bucket ACLs or public access alone without OAC leaves gaps; use policy-based control instead.
Pro tip
Use short expiration for signed URLs and rotate keys regularly if you implement custom signing logic.
