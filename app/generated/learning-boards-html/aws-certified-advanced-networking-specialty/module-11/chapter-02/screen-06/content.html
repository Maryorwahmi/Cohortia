Origin comparison

Match origin type to content characteristics and security needs.

S3 origin
Best for static files. Use Origin Access Control to block direct public access and allow CloudFront only.
ALB / EC2 origin
For APIs or dynamic content. Decide which headers, cookies, and query strings need forwarding.
Key Takeaway

Choose S3 for cache-friendly static content and ALB/EC2 when server logic or personalization is required.

Concrete setup scenario
Place index.html and images in S3 and point API paths to an ALB. Create two behaviors: default for S3 with long TTL, and /api/* for ALB with zero TTL and header forwarding.
Common mistake
Allowing public access to S3 without OAC exposes content and bypasses CloudFront's caching and security layers.
Pro tip
Use the most specific path patterns before the default to ensure API routes are matched correctly.
