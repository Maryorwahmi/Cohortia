Definition

CDN concept explained

A CDN caches content at edge locations to reduce round-trip time and origin load while letting you control caching behavior.

Why it matters
Lower latency for users worldwide and decreased load on origin servers improves availability and cost-efficiency.
Common misconception
CDNs are not purely static copies; caching rules, TTLs, and header forwarding control freshness and correctness.
Key Takeaway

A CDN acts as an intelligent cache network; configure it to serve correct and fresh content, not just faster content.

Request lifecycle (illustrative)
Viewer DNS → Edge location → cache check. Hit: serve from edge. Miss: fetch from origin, cache, then serve.
Concrete example
An image stored in S3 is cached at an edge. When many users request it, they get a fast cache hit instead of repeated origin requests.
Check your understanding
When would you prefer a short TTL? Think of personalized API responses.
Pro tip
Start with conservative caching for dynamic paths and increase TTLs for stable static assets.
