Module 11 › Chapter 11.2 › Create a CloudFront distribution

Quick setup steps

  1. Create an S3 bucket and keep "Block all public access" enabled.
  2. Upload index.html and any assets to the bucket.
  3. Create a CloudFront distribution, select the S3 origin, and create Origin Access Control.
  4. Apply the provided bucket policy to allow the OAC to fetch objects.
  5. Wait for distribution deployment and verify via the distribution domain.
Key Takeaway

OAC is essential to prevent users from bypassing CloudFront and directly accessing S3 content.

Starter index.html (upload to S3)
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8" />
  <title>CloudFront Demo</title>
</head>
<body>
  <h1>Hello from CloudFront!</h1>
  <p>This content is served via Amazon S3 and CloudFront.</p>
</body>
</html>
Check
After deployment, visit https://YOUR_DISTRIBUTION_DOMAIN_NAME/index.html and verify content loads.
Verify OAC
Attempting to open the S3 object URL should return Access Denied if OAC and policy are correct.
