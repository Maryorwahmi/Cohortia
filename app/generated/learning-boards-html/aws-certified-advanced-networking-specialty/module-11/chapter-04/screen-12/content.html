Module 11 › Chapter 11.4 › Hands-on Setup
Console steps (summary)
  1. Create an Accelerator and auto-assign IPs.
  2. Add a TCP listener on port 80.
  3. Create an endpoint group for your region; set traffic dial to 100% for testing.
  4. Add your Application Load Balancer as an endpoint and set health check path '/'.
  5. Review and create; wait for deployment and test via the accelerator DNS or static IPs.
Tip
Use low-frequency health checks during tests and tighten them in production for faster detection of failures.
Sample terminal step
Install a simple web server on an EC2 instance to prepare an ALB target. This example uses the package manager and service start command from the chapter source.
sudo yum install nginx -y && sudo systemctl start nginx
# Open port 80 in the instance security group, then create an ALB targeting this instance.
Validation
After the accelerator deploys, visit the accelerator DNS or static IPs and confirm your web page loads. Compare latency from a distant client to verify benefit.
