Module 11 › Chapter 11.4 › What is Global Accelerator?
Definition and purpose

Global Accelerator gives two static Anycast IP addresses and uses the AWS global network to carry traffic from Edge Locations to your regional endpoints. It optimizes the middle and first miles of the network path to reduce latency, jitter, and packet loss.

Concrete example
A gaming client in Europe uses the static IP; traffic is ingested at a nearby PoP and routed over AWS backbone to game servers in another region, lowering response time.
Common misconception
Global Accelerator is not a content cache like CloudFront. It optimizes network paths rather than storing and serving static assets at the edge.
Key Takeaway

Choose Global Accelerator when you need a stable entry point and lower network variability across global users.

How it compares to an internet-only route
  • Ingress at nearest Edge Location instead of the public internet's first hop.
  • Traffic travels over an optimized, low-congestion backbone for most of the journey.
  • Static IPs remove the need to update client configurations when endpoints change.
Analogy
Think of Global Accelerator as a dedicated highway entrance near the user that merges onto a private expressway to the application, while the public internet is local streets and congested highways.
