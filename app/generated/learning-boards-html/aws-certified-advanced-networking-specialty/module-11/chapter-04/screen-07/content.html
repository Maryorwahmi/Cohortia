What listeners do

Listeners accept inbound connections to the accelerator for configured protocols and ports. They map those connections to endpoint groups which represent regions. Listeners operate at the transport layer and are protocol-aware for TCP and UDP.

Concrete example
Create a TCP listener for port 80 and a UDP listener for a game's port. Each listener attaches to endpoint groups for your regions.
Misconception
Listeners are not HTTP-specific routers or caches; they provide protocol/port entry points and delegate routing to endpoint groups.
Listener configuration tips
  • Use separate listeners for differing protocol types to avoid mixing TCP and UDP rules.
  • Attach endpoint groups per listener to control regional distribution per protocol.
  • Plan ports carefully for firewall and client compatibility when using static IPs.
Key Takeaway

Listeners define the network surfaces clients contact and hand connections to endpoint groups for routing and failover.
