Supported endpoint types
  • Application Load Balancer (ALB)
  • Network Load Balancer (NLB)
  • EC2 instances and Elastic IPs
  • AWS Outposts resources
Health check behavior
Global Accelerator runs health checks and shifts traffic away from endpoints that fail checks, improving resiliency across regions.
Operational guidance
  • Configure sensible health check paths and intervals relevant to your application.
  • Combine health checks with traffic dials for controlled failover tests.
  • Use endpoint weights to shift load gradually between endpoints in a group.
Key Takeaway

Health checks and endpoint groups let Global Accelerator maintain availability by routing around failed endpoints without client changes.
