Module 11 › Chapter 11.4 › Accelerator & IPs
What the accelerator gives you
  • Two static Anycast IP addresses advertised from Edge Locations.
  • Stable client-facing entry points that don’t change when endpoints move.
  • Compatibility with firewall whitelisting and devices that require fixed targets.
Operational example
IoT devices can be preconfigured with the accelerator IPs. Backend endpoints change or fail, but devices keep sending data to the same addresses.
Design notes
Redundancy
Two IPs provide redundancy and smoother client behavior if one route becomes less optimal.
Misconception
The static IPs are global; their advertisement points vary to direct clients to the nearest PoP, not to a single fixed region.
Key Takeaway

Static Anycast IPs simplify client configuration while the accelerator manages global ingress and redundancy.
