Instance-Level Control

Security Groups

Stateful Firewalls for EC2 Instances

Stateful Operation

Automatically allows return traffic for any permitted inbound or outbound connection.

Instance-Level Granularity

Rules apply to specific EC2 instances, allowing fine-grained access control.

EC2 Instance

Application Server

Needs specific inbound/outbound access.

Security Group

Virtual Firewall

Filters traffic based on rules.

Allowed Traffic

SSH, HTTP, HTTPS

Only permitted traffic reaches the instance.

Key Takeaway

Security Groups are stateful, instance-level firewalls that provide granular control over traffic to and from EC2 instances.
