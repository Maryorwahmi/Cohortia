Initializing Hybrid Connectivity with AWS CLI

Creating Customer Gateway and Transit Gateway resources.

Scenario Overview

Connect on-premises data center (172.16.0.0/16) to AWS VPCs (AppVPC1, AppVPC2) using Site-to-Site VPN to a Transit Gateway for scalable, centralized connectivity.

Task 1: Create Customer Gateway

Represents your on-premises router. Requires public IP and BGP ASN. The output provides the `CustomerGatewayId`.

Task 2: Create AWS Transit Gateway

Establishes the central hub for all network connections. The output provides the `TransitGatewayId`.

Key Takeaway

Customer Gateway and Transit Gateway are the foundational resources for building a scalable and centralized hybrid cloud network using AWS CLI.

# Assume ON_PREM_PUBLIC_IP is the public IP of your on-premises router.# Assume ON_PREM_BGP_ASN is your on-premises BGP ASN (e.g., 65000).

# 1. Create a Customer Gateway
aws ec2 create-customer-gateway \
    --bgp-asn $ON_PREM_BGP_ASN \
    --public-ip $ON_PREM_PUBLIC_IP \
    --type ipsec.1 \
    --tag-specifications 'ResourceType=customer-gateway,Tags=[{Key=Name,Value=OnPremCustomerGateway}]'

# Output will include CustomerGatewayId. Store it:
# CGW_ID="cgw-xxxxxxxxxxxxxxxxx"

# 2. Create an AWS Transit Gateway
aws ec2 create-transit-gateway --description "HybridTGW" --tag-specifications 'ResourceType=transit-gateway,Tags=[{Key=Name,Value=HybridTGW}]'

# Output will include TransitGatewayId. Store it:
# TGW_ID="tgw-yyyyyyyyyyyyyyyyy"
