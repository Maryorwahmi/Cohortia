AWS Site-to-Site VPN: Encrypted Connectivity

Establishing secure tunnels over the public internet for hybrid integration.

How Site-to-Site VPN Works

Establishes encrypted IPsec tunnels over the public internet between your on-premises customer gateway and an AWS Virtual Private Gateway (VPG) or Transit Gateway.

Key Characteristics

  • Quick to set up and relatively cost-effective.
  • Bandwidth up to 1.25 Gbps per tunnel (multiple for higher aggregate).
  • Performance can be variable due to public internet traversal.
  • Latency is generally higher and less predictable.
Key Takeaway

Site-to-Site VPN provides a secure, flexible, and cost-effective option for many hybrid cloud connectivity needs, especially for lower bandwidth and non-mission-critical workloads.

Example Use Case

A small business needs to securely connect its on-premises accounting server to an AWS-hosted application. Site-to-Site VPN offers a quick, secure, and affordable way to establish this link without requiring dedicated infrastructure.
