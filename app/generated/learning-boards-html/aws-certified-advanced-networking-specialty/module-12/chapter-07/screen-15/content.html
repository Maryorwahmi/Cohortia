What to Remember

Key concepts for advanced network troubleshooting.

Asymmetric Routing

Traffic taking different paths for forward and return, potentially causing connectivity issues with stateful firewalls.

VPN Tunnel Status

Checking the operational status of VPN tunnels in the AWS console and on-premises router for hybrid connectivity.

Direct Connect BGP Status

Verifying BGP session state and route advertisements for Direct Connect connections to ensure hybrid routing.

Basic Network Utilities

`ping`, `traceroute`, `netstat` for in-instance diagnostics and quick reachability checks.

Summary Takeaway

A holistic troubleshooting approach combines AWS native tools with on-premises checks and instance-level diagnostics for complete network visibility.
