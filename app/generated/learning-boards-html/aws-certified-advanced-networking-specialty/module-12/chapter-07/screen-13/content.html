Basic Network Utilities for EC2 Instances

Use `ping`, `traceroute`, and `netstat` for quick checks.

Why Use Them?

Provide immediate, instance-level insights into connectivity, helping to quickly confirm basic reachability and active connections from the perspective of the EC2 instance itself.

Complementary Tools

These commands complement AWS's advanced tools by offering a granular view from the endpoint, essential for a comprehensive troubleshooting strategy.

Key Takeaway

Always start with basic utilities for initial checks. Their output can quickly narrow down the scope of a problem before diving into more complex AWS diagnostics.

Essential Commands

`ping [IP_ADDRESS]`

Checks basic IP reachability and latency. A failure indicates a fundamental block (SG, NACL, route).

`traceroute [IP_ADDRESS]`

Traces the network path to a destination, showing each hop. Helps identify routing issues or where traffic is dropped.

`netstat -tulnp`

Displays active connections, listening ports, and associated processes. Useful for verifying application binding and open ports.

Common Misconception

Assuming that if AWS tools show no issues, the network is fine. Instance-level checks can reveal application-specific or OS-level network problems.
