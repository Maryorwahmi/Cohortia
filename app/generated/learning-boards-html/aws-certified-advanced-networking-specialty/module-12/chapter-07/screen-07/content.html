AWS Reachability Analyzer: Validating Network Paths

Statically analyze network reachability between AWS resources.

What it Does

Analyzes and debugs network reachability between two specified resources within your VPCs (e.g., EC2 to EC2, EC2 to Internet Gateway).

How it Works

Performs a static analysis of your network configuration (route tables, security groups, NACLs) to determine reachability and identify blocking components.

Key Takeaway

Reachability Analyzer is far more efficient than manual checks, providing precise identification of the network component blocking traffic, saving significant troubleshooting time.

Reachability Analysis Process
1

Define Path

Specify source and destination resources (e.g., `EC2_A` to `EC2_B`).

2

Set Protocol/Port

Specify the protocol (TCP/UDP) and destination port.

3

Run Analysis

Initiate the static analysis of the network configuration.

4

Interpret Results

View the path and identify the exact blocking component if unreachable.

Common Blocking Components

Missing Route, Security Group Rule, Network ACL Rule, or incorrect peering/gateway configuration.
