Troubleshooting Direct Connect BGP and VIF Status

Ensure VIF availability and correct BGP session establishment.

VIF & BGP Status

In the AWS console, confirm the Virtual Interface (VIF) status is `available` and the BGP session is `up`. These are foundational for connectivity.

On-Premises BGP Config

If BGP is down, check your on-premises router's BGP configuration: ASN, peer IP, and advertised prefixes. Use `show ip bgp summary`.

Key Takeaway

Beyond BGP session status, verify route advertisements from both sides and ensure AWS security groups/NACLs allow traffic from on-premises CIDRs.

Direct Connect Troubleshooting Checklist
1

AWS Console: VIF & BGP

Verify VIF is 'available' and BGP is 'up'.

2

On-Premises Router BGP

Check ASN, peer IP, and advertised prefixes (`show ip bgp summary`).

3

BGP Route Advertisements

Ensure routes are exchanged correctly from both AWS and on-premises.

4

AWS Security Controls

Confirm SGs and NACLs allow traffic from on-premises CIDRs.

Common Issue

BGP session is up, but routes are not exchanged due to incorrect prefix advertisements or filtering on either side.
