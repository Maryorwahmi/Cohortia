VPC Flow Logs: Your Network's Black Box Recorder

Capture detailed IP traffic information for deep analysis.

What are Flow Logs?

They capture detailed information about IP traffic going to and from network interfaces in your VPC. This includes source/destination IPs, ports, protocols, and action taken.

When to Use

Essential for diagnosing connectivity issues, identifying blocked traffic, and performing security analysis. Enable them for relevant VPCs, subnets, or ENIs.

Key Takeaway

VPC Flow Logs provide granular visibility into network traffic, including both accepted and rejected flows, which is critical for pinpointing root causes.

Flow Log Data Captured

Source/Destination IP

`srcaddr`, `dstaddr`

Source/Destination Port

`srcport`, `dstport`

Protocol

`protocol` (e.g., 6 for TCP)

Action

`action` (`ACCEPT` or `REJECT`)

Log Status

`log_status` (`OK`, `NODATA`, `SKIP`)

Interface ID

`interface_id`

Common Mistake

Only reviewing `ACCEPT` logs. `REJECT` logs are equally, if not more, important for identifying blocked traffic and misconfigurations.
