Diagnosing Site-to-Site VPN Issues

Verify tunnel status and on-premises Customer Gateway configuration.

AWS Side Check

Verify both VPN tunnels are `UP` and `available` in the AWS console. If not, the IPsec tunnel itself is not established.

On-Premises Side Check

Inspect Customer Gateway configuration: public IP, pre-shared key, and firewall rules (UDP 500/4500).

Key Takeaway

Focus on establishing the IPsec tunnels first. Use `tcpdump` on the Customer Gateway to diagnose if traffic is reaching it and if IPsec negotiations are failing.

VPN Troubleshooting Steps
1

AWS Console: Tunnel Status

Confirm both tunnels show 'UP'.

2

Customer Gateway Config

Verify public IP, pre-shared key, and IKE/IPsec parameters.

3

On-Premises Firewall

Ensure UDP ports 500 (IKE) and 4500 (IPsec NAT-T) are open.

4

`tcpdump` on CGW

Check for IPsec negotiation failures or traffic not reaching the gateway.

Common Misconfiguration

Mismatched pre-shared keys or incorrect public IP addresses on the Customer Gateway device are frequent causes of tunnel failures.
