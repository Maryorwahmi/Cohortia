Scenario Walkthrough: The Optimal Solution

Understanding why the best answer is truly the best

Option C leverages AWS Transit Gateway as the central networking hub in each Region, connecting all VPCs. Transit Gateway peering handles inter-Region communication. The existing Direct Connect connection is integrated via a Direct Connect Gateway attached to the Transit Gateway.

  • •Highly Scalable & Manageable: Transit Gateway's hub-and-spoke model.
  • •Multi-Region: Transit Gateway peering for inter-Region connectivity.
  • •Hybrid Connectivity: Direct Connect Gateway attached to Transit Gateway.
  • •Minimizes Operational Overhead: Centralized routing and simplified management.
Key Takeaway

The optimal solution for complex enterprise networking aligns with AWS best practices, offering scalability, manageability, and efficient hybrid connectivity.

Example: Transit Gateway's hub-and-spoke model inherently supports connecting hundreds of VPCs across accounts and Regions, directly addressing the enterprise's scale requirements.
