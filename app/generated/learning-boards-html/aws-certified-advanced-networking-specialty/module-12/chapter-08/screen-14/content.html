Key Concepts

Essential Terms to Remember

Infrastructure as Code (IaC)

Managing and provisioning infrastructure through code instead of manual processes, enabling version control and automation.

AWS CloudFormation

AWS's native declarative IaC service for provisioning and managing AWS resources using YAML or JSON templates.

AWS Cloud Development Kit (CDK)

An open-source framework to define cloud infrastructure in familiar programming languages, synthesizing to CloudFormation.

Summary Takeaway

IaC, CloudFormation, and CDK are fundamental tools for automating and standardizing AWS network infrastructure deployments.
