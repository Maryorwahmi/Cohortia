AWS Cloud Development Kit (CDK): Imperative IaC

Defining Infrastructure with Programming Languages

Core Concept

Imperative IaC

CDK allows you to define cloud infrastructure using familiar programming languages (Python, TypeScript, Java, C#), offering more programmatic control.

Key Feature

Leverages programming language features.

Key Feature

Synthesizes to CloudFormation templates.

CDK vs. CloudFormation

CloudFormation (Declarative)

YAML/JSON templates. Focus on 'what' resources should exist. Lower-level control, explicit dependencies.

CDK (Imperative)

Programming languages. Focus on 'how' to construct resources. Higher-level abstractions, reusable components.

Key Takeaway

CDK bridges the gap between application development and infrastructure provisioning, offering a more developer-friendly IaC experience.
