Connecting Global Networks

Establishing Cross-Region Network Connectivity

Linking VPCs across geographically separate AWS Regions.

  • •Essential for data synchronization and inter-service communication.
  • •VPC peering: Direct, non-transitive connections between two VPCs.
  • •Transit Gateway peering: Connects TGWs across Regions for transitive routing.
  • •TGW peering simplifies complex multi-Region network topologies.

Scenario: Global Application

A company runs its primary application in `us-east-1` and a disaster recovery site in `eu-west-1`. Transit Gateway peering connects their VPCs in both regions, allowing seamless data replication and failover traffic routing.

Key Takeaway

AWS Transit Gateway peering offers a scalable and robust solution for transitive routing between VPCs across different Regions, surpassing VPC peering for complex networks.

VPC Peering vs. Transit Gateway Peering

Choosing the right inter-Region connection

VPC Peering

  • •Direct, 1:1 connection
  • •Non-transitive routing
  • •Simpler for few VPCs

Transit Gateway Peering

  • •Connects TGWs
  • •Transitive routing
  • •Scalable for many VPCs
