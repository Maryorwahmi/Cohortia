Multi-AZ Deployments

Distributing resources across Availability Zones within a single Region.

  • •Availability Zones are isolated locations within a Region.
  • •Distribute critical components (EC2, RDS, ALBs) across 2-3 AZs.
  • •Protects against AZ-wide outages like power or network failures.
  • •Traffic automatically routes to healthy resources in other AZs.

Example: Web Application

An Application Load Balancer (ALB) distributes traffic to EC2 instances in `us-east-1a` and `us-east-1b`. If `us-east-1a` fails, the ALB automatically directs all traffic to `us-east-1b` instances.

Key Takeaway

Distributing critical resources across multiple Availability Zones protects against localized outages and ensures continuous service within a Region.
