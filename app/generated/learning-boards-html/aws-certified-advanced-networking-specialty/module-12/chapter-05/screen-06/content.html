Automating Scalable Network Infrastructure

VPC CIDR: !Ref VpcCidr

The `VpcCidr` parameter, defaulted to `10.0.0.0/16`, defines a large IP address space for the entire VPC, accommodating extensive future growth.

Subnet CIDRs: /24 & /22

Public subnets use `/24` for internet-facing resources, while private subnets use larger `/22` blocks to ensure ample IP addresses for application instances and internal services.

Multi-AZ Deployment

Using `!Select [ 0, !GetAZs '' ]` ensures subnets are distributed across different Availability Zones, providing high availability and fault tolerance for your network.

Key Takeaway

CloudFormation allows you to define and deploy scalable VPC and subnet configurations consistently, automating best practices for network growth.
