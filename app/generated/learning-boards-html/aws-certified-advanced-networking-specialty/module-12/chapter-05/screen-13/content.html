Understanding AWS Networking Limits and Quotas

Planning for Growth and Avoiding Bottlenecks

VPC Limits

  • VPCs per Region (e.g., 5)
  • Subnets per VPC (e.g., 200)
  • IP addresses per ENI

Transit Gateway Limits

  • Attachments per TGW (e.g., 5000)
  • Routes per TGW route table (e.g., 10000)
  • VPN connections per TGW

Route Table Limits

  • Routes per route table (e.g., 50)
  • Associations per route table
  • Propagations per route table
Soft vs. Hard Limits

Soft limits can often be increased by requesting a quota increase from AWS Support, while hard limits are fixed and require architectural adjustments.

Proactive Planning

Regularly review AWS service quotas and plan your network design to stay within them or request increases proactively to avoid unexpected bottlenecks.

Key Takeaway

Understanding and planning for AWS networking limits and quotas is crucial for designing scalable, resilient networks and preventing future operational issues.
