What is ELB?

Elastic Load Balancing automatically distributes incoming application traffic across multiple targets, such as EC2 instances, for high availability and fault tolerance.

Types of ELB

AWS offers Application Load Balancers (ALB) for HTTP/S, Network Load Balancers (NLB) for TCP/UDP, and Gateway Load Balancers (GLB) for virtual appliances.

Key Benefits

ELB provides high availability, fault tolerance by routing around unhealthy targets, and enables horizontal scaling to handle fluctuating traffic efficiently.

Key Takeaway

ELB is essential for distributing traffic, ensuring application availability, and enabling seamless horizontal scaling across multiple targets and AZs.
