Network Security: Defense in Depth

Implementing layered protection for your AWS resources

Core VPC Security

  • •Security Groups (SGs): Stateful, instance-level firewall.
  • •Network ACLs (NACLs): Stateless, subnet-level firewall.

Advanced Threat Protection

  • •AWS Network Firewall: Stateful inspection, IPS/IDS, domain filtering at VPC boundary.
  • •AWS WAF: Layer 7 web application protection against common exploits.
  • •AWS Shield: DDoS protection (Standard and Advanced tiers).

Example: Multi-Layered Defense

Use Network Firewall for VPC ingress/egress, WAF for ALBs, and Security Groups for EC2 instances and databases.

Security Layers in Action

Common Misconception

Confusing Security Groups (stateful, instance-level) with NACLs (stateless, subnet-level). Each has distinct behavior and application.
