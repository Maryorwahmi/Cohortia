Essential Terms to Remember (Part 2)

Advanced AWS Networking Components

VPC Peering

A networking connection between two VPCs that enables you to route traffic between them privately (non-transitive).

AWS Transit Gateway

A network transit hub that connects VPCs and on-premises networks, enabling transitive routing.

VPC Flow Logs

A feature that captures information about the IP traffic going to and from network interfaces in your VPC.

CloudWatch Network Metrics

Metrics collected by CloudWatch for various AWS networking services to monitor performance.

Summary Takeaway

VPC peering and Transit Gateway are key for inter-VPC communication, while Flow Logs and CloudWatch metrics are essential for comprehensive network monitoring and troubleshooting.
