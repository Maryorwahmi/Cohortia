Advanced Network Troubleshooting Techniques

Global View and External Diagnostics

AWS Network Manager

  • •Provides a global view of your network, including on-premises connections.
  • •Helps visualize network topology and monitor performance across hybrid setups.
  • •Part of Transit Gateway, offering centralized management.
Concrete Example

Using `iperf3` between two EC2 instances to measure actual network throughput and identify if bandwidth is a limiting factor.

External Diagnostic Tools

  • •`iperf3` for measuring network throughput between specific endpoints.
  • •`traceroute` for mapping the network path and identifying latency hops.
  • •Run on EC2 instances to diagnose specific connectivity issues.
Key Takeaway

Combine AWS Network Manager for a holistic view with external tools like `iperf3` and `traceroute` for granular diagnostics, always establishing performance baselines for effective troubleshooting.
