AWS Global Accelerator in Action

Leveraging the AWS Global Network for Low Latency

Static Anycast IP Addresses

Users connect to fixed IP addresses advertised from multiple AWS edge locations globally.

AWS Global Network Backbone

Traffic is routed over AWS's highly optimized, low-latency global network, bypassing public internet congestion.

Concrete Example

An online gaming platform uses Global Accelerator to route players to the nearest healthy game server, minimizing lag and improving the gaming experience globally.

Routes to Closest Healthy Endpoint

Automatically directs user traffic to the optimal application endpoint based on health checks and proximity.

Ideal for Non-HTTP/S Traffic

Optimizes performance for protocols like TCP and UDP, where CDNs like CloudFront are not typically used.

Key Takeaway

Global Accelerator enhances global application performance and availability by routing traffic over the AWS backbone via Anycast IPs to the nearest healthy endpoint, especially for non-HTTP/S workloads.
