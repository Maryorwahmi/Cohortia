Essential Terms to Remember (Part 1)

Core Networking Definitions

Network Latency

The time delay for data to travel from one point to another in a network.

Throughput

The amount of data transferred successfully over a network in a given period.

AWS Direct Connect

A dedicated, private network connection from your premises to AWS, bypassing the public internet.

AWS Global Accelerator

A service that uses the AWS global network to route user traffic to optimal application endpoints.

Summary Takeaway

Understanding network latency and throughput, and leveraging services like Direct Connect and Global Accelerator, are fundamental to building high-performance AWS networks.
