Case Study: Uncovering High Egress Costs

Analyzing a common web application scenario to identify potential cost drivers for unexpected egress.

Scenario Overview

Your AWS bill shows unexpectedly high "Data Transfer Out to Internet" costs from your us-east-1 Region. Your web application serves static content from S3 and dynamic content from EC2 instances behind an ALB.

Task: Identify potential sources of high egress costs for this scenario.

1Direct Egress from EC2/ALB

Dynamic content or un-cached static content served directly from EC2 instances or through an Application Load Balancer to the internet.

2Direct Egress from S3

Static content served directly from S3 buckets configured for public access, without a CDN.

3NAT Gateway Egress

Instances in private subnets downloading large files or making frequent API calls to external services over the internet via a NAT Gateway.

Key Takeaway

High egress costs often stem from direct internet traffic, unoptimized S3 access, or NAT Gateway usage.
