Investigating Egress with AWS Cost Explorer

Practical steps to pinpoint cost anomalies in your AWS billing reports using Cost Explorer.

1Navigate to Cost Explorer

Access the Cost Explorer dashboard in the AWS Management Console.

2Filter by Service & Usage Type

Filter by 'Service: EC2 - Other' and 'Usage Type: Data Transfer' to focus on egress costs.

3Group by Usage Type

Group results by 'Usage Type' or 'API Operation' for a granular breakdown of egress sources.

Key Takeaway

Cost Explorer provides a high-level view to quickly identify services and usage types contributing to high egress.

user@console:~$ aws ce get-cost-and-usage --time-period Start=2023-01-01,End=2023-01-31 --granularity MONTHLY --metrics BlendedCost --group-by Type=DIMENSION,Key=SERVICE Type=DIMENSION,Key=USAGE_TYPE
