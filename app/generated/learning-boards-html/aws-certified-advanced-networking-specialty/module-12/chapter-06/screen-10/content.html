Granular Egress Analysis with VPC Flow Logs

Pinpointing the exact sources of data transfer out from your AWS VPCs.

Capture Traffic Data

Records IP traffic flow to and from network interfaces in your VPC, including source/destination, ports, and bytes.

Analyze with CloudWatch/Athena

Query flow logs to identify top talkers, external destinations, and specific traffic patterns contributing to egress.

Key Takeaway

VPC Flow Logs provide detailed traffic insights, essential for diagnosing high egress costs at a granular level.

user@terminal:~$ aws logs describe-log-groups --log-group-name-prefix '/aws/vpc/flow-logs/'
user@terminal:~$ aws logs start-query --log-group-name '/aws/vpc/flow-logs/my-vpc-flow-log' --start-time 1678886400 --end-time 1678972800 --query-string "filter action = 'ACCEPT' and pkt_out_bytes > 0 | stats sum(bytes) as total_bytes_egress by dstaddr, dstport, protocol | sort total_bytes_egress desc | limit 5"
user@terminal:~$ aws logs get-query-results --query-id 
{
  "results": [
    {"dstaddr": "203.0.113.42", "dstport": "443", "protocol": "6", "total_bytes_egress": "123456789"},
