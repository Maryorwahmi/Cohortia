How it Works

Gateway Endpoints provide a private connection from your VPC to S3, routing traffic directly within the AWS network.

Cost Benefit

Eliminates NAT Gateway data processing charges and associated internet egress costs for S3 traffic.

Key Takeaway

S3 VPC Endpoints eliminate NAT Gateway data processing and egress charges for S3 traffic from private subnets.
