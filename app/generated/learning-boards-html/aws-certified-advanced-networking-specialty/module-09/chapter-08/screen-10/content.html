Hands-on Activity: Step 3

Test the Alarm: Simulate State Change

Manually set the alarm state in the AWS Console to verify that SNS notifications are received.

Instructions: Simulate Alarm
  1. Go to the AWS Console → CloudWatch → Alarms.
  2. Find your VPN-Tunnel-1-Down alarm.
  3. Select the alarm, click Actions → Set state → In alarm.
  4. Check your subscribed email address for the SNS notification.
  5. After verification, set the alarm state back to OK.
Expected Outcome

You should receive an email notification from Amazon SNS confirming the alarm state change. This verifies your monitoring and alerting pipeline is functional.

Key Takeaway

Simulating alarm states is a safe and effective way to test your CloudWatch and SNS integration, ensuring alerts are delivered reliably.
