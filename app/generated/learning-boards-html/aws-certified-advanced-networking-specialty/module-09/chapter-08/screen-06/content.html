Module 9›Chapter 9.8›CloudFormation Alarms
CloudFormation Template
MyVPNTunnelStateAlarm:
  Type: AWS::CloudWatch::Alarm
  Properties:
    AlarmName: MyVPNTunnelDownAlarm
    AlarmDescription: "Alarm when VPN Tunnel 1 is down for more than 5 minutes"
    ComparisonOperator: LessThanThreshold
    EvaluationPeriods: 5
    MetricName: TunnelState
    Namespace: AWS/VPN
    Period: 60 # 1 minute
    Statistic: Minimum
    Threshold: 1 # 0 for DOWN, 1 for UP
    Dimensions:
      - Name: VpnId
        Value: !Ref MyVPNConnection # Reference to your VPN Connection ID
      - Name: TunnelIpAddress
        Value: 203.0.113.10 # Public IP of Tunnel 1
    AlarmActions:
      - !Ref NetworkAlertSNSTopic # Send notification to SNS topic
      - !GetAtt VpnRemediationLambda.Arn # Invoke a Lambda function for remediation
    TreatMissingData: notBreaching # Do not alarm if data is missing
Explanation

Key elements of the alarm definition:

  • Metric & Threshold: Monitors TunnelState (0=DOWN, 1=UP) for a VPN connection.
  • Dimensions: Specifies the exact VPN connection and tunnel IP to monitor.
  • Alarm Actions: Triggers notifications via SNS and invokes a Lambda function for remediation.
Key Takeaway

CloudFormation allows you to define CloudWatch Alarms as code, ensuring consistent deployment and enabling automated actions via SNS and Lambda.
