Hands-on Activity: Step 2

Create the CloudWatch Alarm (using CLI)

Configure a CloudWatch Alarm to monitor the TunnelState of your VPN connection and send alerts via the SNS topic.

Command: Put Metric Alarm
aws cloudwatch put-metric-alarm \
  --alarm-name "VPN-Tunnel-1-Down" \
  --alarm-description "Notifies when VPN Tunnel 1 goes down" \
  --metric-name TunnelState \
  --namespace AWS/VPN \
  --statistic Minimum \
  --period 60 \
  --threshold 1 \
  --comparison-operator LessThanThreshold \
  --evaluation-periods 1 \
  --datapoints-to-alarm 1 \
  --dimensions Name=VpnId,Value=YOUR_VPN_ID Name=TunnelIpAddress,Value=YOUR_TUNNEL_IP_ADDRESS \
  --alarm-actions YOUR_SNS_TOPIC_ARN \
  --treat-missing-data notBreaching
Important Notes
  • Replace YOUR_VPN_ID and YOUR_TUNNEL_IP_ADDRESS with your actual VPN connection details.
  • Replace YOUR_SNS_TOPIC_ARN with the ARN obtained in the previous step.
Key Takeaway

The put-metric-alarm CLI command allows programmatic creation of CloudWatch Alarms, ensuring consistent and automated monitoring setup.
