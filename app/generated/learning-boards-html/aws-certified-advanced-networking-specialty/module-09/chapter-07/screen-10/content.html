Scripting with Boto3

Programmatic Virtual Interface (VIF) Creation

Use the AWS SDK (Boto3) to create Private or Transit Virtual Interfaces for Direct Connect.

# Python script using Boto3 to create a Transit VIF
import boto3

def create_dx_vif(connection_id, dx_gateway_id, vlan, customer_address, amazon_address, bgp_asn, region='us-east-1'):
    dx_client = boto3.client('directconnect', region_name=region)
    print(f"Creating Transit VIF for connection {connection_id}...")
    try:
        response = dx_client.create_transit_virtual_interface(
            connectionId=connection_id,
            newTransitVirtualInterfaceAllocation={
                'virtualInterfaceName': f'TransitVIF-{vlan}',
                'vlan': vlan,
                'asn': bgp_asn, # Customer ASN
                'mtu': 1500,
                'amazonAddress': amazon_address,
                'customerAddress': customer_address,
                'directConnectGatewayId': dx_gateway_id,
                'tags': [{'key': 'Name', 'value': f'TransitVIF-{vlan}'}]
            }
        )
        print(f"Transit VIF created: {response['virtualInterface']['virtualInterfaceId']}")
        return response['virtualInterface']['virtualInterfaceId']
    except boto3.exceptions.ClientError as e:
        print(f"Error creating Transit VIF: {e}")
        raise

if __name__ == "__main__":
    dx_connection = 'dxcon-xxxxxxxx'
    dx_gateway = 'dxgw-xxxxxxxx'
    vlan_id = 100
    customer_ip = '169.254.10.2/30'
    amazon_ip = '169.254.10.1/30'
    customer_asn = 65001
    try:
        vif_id = create_dx_vif(dx_connection, dx_gateway, vlan_id, customer_ip, amazon_ip, customer_asn)
        print(f"Successfully initiated Transit VIF creation: {vif_id}")
    except Exception as e:
        print(f"Failed to create VIF: {e}")

Key Parameters for VIF Creation

  • •`connectionId`: The ID of your physical Direct Connect connection.
  • •`directConnectGatewayId`: The ID of the DXGW to which the VIF will connect.
  • •`vlan`: The VLAN ID for this specific virtual interface.
  • •`customerAddress` / `amazonAddress`: The IP addresses for the BGP peering on both sides.
  • •`asn`: The customer's BGP Autonomous System Number.
Key Takeaway

Boto3 provides granular control for creating Direct Connect Virtual Interfaces, enabling dynamic and automated provisioning of logical connections after physical setup.

Pro Tip

Integrate VIF creation scripts into a larger workflow, perhaps triggered by a Lambda function monitoring Direct Connect connection status, for fully automated lifecycle management.
