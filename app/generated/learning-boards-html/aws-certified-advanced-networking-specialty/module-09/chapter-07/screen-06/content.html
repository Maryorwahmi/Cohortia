CloudFormation for Site-to-Site VPN: Customer Gateway

Define your on-premises VPN device as an AWS Customer Gateway using CloudFormation.

# CloudFormation snippet for Customer Gateway
Resources:
  MyCustomerGateway:
    Type: AWS::EC2::CustomerGateway
    Properties:
      BgpAsn: 65000 # Your on-premises ASN
      IpAddress: !Ref OnPremiseRouterIp
      Type: ipsec.1
      Tags:
        - Key: Name
          Value: MyOnPremiseCGW

Explanation of Parameters

  • •`OnPremiseRouterIp` (Parameter): The public IP address of your physical or software VPN device on-premises.
  • •`BgpAsn` (Property): The Border Gateway Protocol (BGP) Autonomous System Number of your on-premises network.
  • •`Type`: Specifies the VPN protocol, typically `ipsec.1` for AWS Site-to-Site VPN.

Concrete Example: Multi-Site Deployment

A company with offices in New York, London, and Tokyo needs to connect each to AWS. A single CloudFormation template can be used, with the `OnPremiseRouterIp` parameter updated for each deployment (e.g., `198.51.100.1` for New York, `203.0.113.1` for London, etc.), ensuring consistent Customer Gateway definitions across all sites.

Key Takeaway

Automating Customer Gateway creation with CloudFormation ensures consistent, parameterized definitions of on-premises VPN devices, simplifying multi-site deployments.

Pro Tip

Always use a private ASN (e.g., 64512-65534) for your on-premises device if you are not a public internet service provider, to avoid conflicts.
