Key Concepts: Transit Gateway & Routing

Essential terms for automating your hybrid cloud network.

AWS Transit Gateway (TGW)

A network transit hub to interconnect VPCs and on-premises networks.

Transit Gateway Attachment

A connection between a Transit Gateway and a VPC, VPN, or Direct Connect Gateway.

Transit Gateway Route Table

Used to control routing between attachments connected to a Transit Gateway.

Virtual Interface (VIF)

A logical connection established over a Direct Connect connection (Private, Public, Transit).

BGP (Border Gateway Protocol)

A routing protocol for exchanging routing and reachability information between autonomous systems.

Summary Takeaway

Understanding Transit Gateway's role, its attachments, routing mechanisms, and the underlying BGP protocol is crucial for automating complex hybrid network designs.
