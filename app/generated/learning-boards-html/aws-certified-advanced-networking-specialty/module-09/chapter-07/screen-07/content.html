CloudFormation for Site-to-Site VPN: Connection & Attachment

Automate the VPN connection and its attachment to a Transit Gateway using CloudFormation.

# CloudFormation snippet for TGW Attachment and VPN Connection
Resources:
  MyTransitGatewayAttachment:
    Type: AWS::EC2::TransitGatewayAttachment
    Properties:
      TransitGatewayId: !Ref TransitGatewayId
      VpcId: vpc-0abcdef1234567890 # Replace with your VPC
      SubnetIds:
        - subnet-0123456789abcdef0
        - subnet-0fedcba9876543210
      Tags:
        - Key: Name
          Value: MyVPNTransitGatewayAttachment

  MyVPNCustomerGatewayAssociation:
    Type: AWS::EC2::TransitGatewayVpnAttachment
    Properties:
      TransitGatewayId: !Ref TransitGatewayId
      CustomerGatewayId: !Ref MyCustomerGateway
      Tags:
        - Key: Name
          Value: MyVPNCGWAssociation

  MyVPNConnection:
    Type: AWS::EC2::VPNConnection
    Properties:
      CustomerGatewayId: !Ref MyCustomerGateway
      TransitGatewayId: !Ref TransitGatewayId
      Type: ipsec.1
      StaticRoutesOnly: false # Set to true if not using BGP
      Tags:
        - Key: Name
          Value: MySiteToSiteVPN

Key Resources Explained

  • •`AWS::EC2::TransitGatewayAttachment`: Connects a VPC to the Transit Gateway.
  • •`AWS::EC2::TransitGatewayVpnAttachment`: Associates the Customer Gateway with the Transit Gateway.
  • •`AWS::EC2::VPNConnection`: Creates the actual Site-to-Site VPN connection.

Concrete Example: Centralized Hybrid Hub

A company uses a central Transit Gateway to connect multiple VPCs. By automating VPN connections to this TGW, all on-premises traffic can flow through a single, managed hub, simplifying routing and security policies. This template ensures new VPNs are always correctly integrated into this hub-and-spoke model.

Key Takeaway

CloudFormation enables comprehensive automation of Site-to-Site VPN connections, including their integration with AWS Transit Gateway for centralized hybrid networking.

Important Note

After deployment, you still need to download the VPN configuration from AWS and apply it to your on-premises VPN device. This step is typically automated using tools like Ansible or custom scripts.
