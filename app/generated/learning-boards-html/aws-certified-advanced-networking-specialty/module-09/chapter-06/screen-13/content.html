Key Concepts

Essential Terms in Automated Network Security

Security Groups (SGs)

Virtual firewalls controlling inbound/outbound traffic for EC2 instances. Stateful.

Network ACLs (NACLs)

Stateless firewalls controlling traffic at the subnet level. Process rules in order.

AWS WAF

Protects web applications from common web exploits (Layer 7).

Summary Takeaway

Mastering the distinct roles of SGs, NACLs, and AWS WAF is foundational for building automated and resilient cloud network security defenses.
