Analyzing the IP Blocking Script

Understanding Dynamic Security Group Management

Script Components

  • •Initializes Boto3 EC2 client.
  • •Iterates through all Security Groups.
  • •Identifies internet-facing SGs (simplified check).
  • •Attempts to revoke ingress for malicious IP.
  • •Includes error handling for existing rules.

Best Practice: NACLs for Broad Blocks

For broad, subnet-level blocking of malicious IPs, Network ACLs are often more effective due to their stateless nature and explicit rule ordering, processing denies before allows.

Key Takeaway

While SGs offer instance-level control, NACLs are better suited for rapid, broad blocking of malicious IPs at the subnet level, leveraging their statelessness and rule order.

Python Boto3 Script (Annotated)
import boto3

def block_ip_in_security_groups(malicious_ip_cidr, region='us-east-1'):
    ec2 = boto3.client('ec2', region_name=region)
    # 1. Initialize EC2 client to interact with SGs
    response = ec2.describe_security_groups()
    
    for sg in response['SecurityGroups']:
        sg_id = sg['GroupId']
        sg_name = sg['GroupName']
        
        # 2. Simplified check for internet-facing SGs
        is_internet_facing = False
        for ingress_rule in sg.get('IpPermissions', []):
            for ip_range in ingress_rule.get('IpRanges', []):
                if ip_range.get('CidrIp') == '0.0.0.0/0':
                    is_internet_facing = True
                    break
            if is_internet_facing:
                break

        if is_internet_facing:
            print(f"Blocking {malicious_ip_cidr} in security group {sg_name} ({sg_id})...")
            try:
                # 3. Revoke ingress for the malicious IP
                ec2.revoke_security_group_ingress(
                    GroupId=sg_id,
                    IpPermissions=[
                        {
                            'IpProtocol': '-1', # All protocols
                            'FromPort': 0,
                            'ToPort': 65535,
                            'IpRanges': [{'CidrIp': malicious_ip_cidr}]
                        }
                    ]
                )
                print(f"Successfully added block rule for {malicious_ip_cidr} in {sg_id}.")
            except boto3.exceptions.ClientError as e:
                # 4. Handle cases where rule already exists or other errors
                if e.response['Error']['Code'] == 'InvalidPermission.NotFound':
                    print(f"Block rule for {malicious_ip_cidr} already exists or was not found to revoke in {sg_id}.")
                else:
                    print(f"Error blocking IP in {sg_id}: {e}")
        else:
            print(f"Skipping {sg_name} ({sg_id}) as it does not appear internet-facing.")

if __name__ == "__main__":
    block_ip_in_security_groups('203.0.113.1/32')
