Core Concepts

Security Groups vs. Network ACLs

Fundamental Controls for Cloud Network Security

Security Groups (SGs)

  • •Operate at the instance level.
  • •Stateful: Inbound allowed means outbound response allowed.
  • •All rules evaluated; most permissive rule wins.

Network ACLs (NACLs)

  • •Operate at the subnet level.
  • •Stateless: Inbound and outbound traffic must be explicitly allowed.
  • •Rules processed in numerical order (lowest first).
Key Takeaway

SGs provide instance-level, stateful protection, while NACLs offer subnet-level, stateless filtering with explicit rule ordering.

Instance Level

Security Group

Stateful firewall for EC2 instances. Allows return traffic automatically.

Stateful
Subnet Level

Network ACL

Stateless firewall for subnets. Requires explicit rules for both directions.

Stateless

Common Mistake

Confusing the stateful nature of Security Groups with the stateless nature of Network ACLs can lead to unexpected traffic blocks or unintended open ports. Always remember to define both inbound and outbound rules explicitly for NACLs.
