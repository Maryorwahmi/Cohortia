Learning Objectives
Master key CloudFormation skills for designing and operating AWS network infrastructure.
01
Design & Implement Network Templates
Build VPCs, subnets, route tables and gateways as resources in templates so networks are reproducible. Practice with the included VPC examples to verify outputs after deployment.
VERIFIED COMPETENCY MILESTONE
02
Parameters, Mappings & Conditions
Use parameters for runtime values and mappings or conditions to support different regions or environments without changing template logic.
VERIFIED COMPETENCY MILESTONE
03
Manage Security Group & NACL Rules
Define security group ingress/egress and stateless NACL rules in templates so access control is consistent and auditable across deployments.
VERIFIED COMPETENCY MILESTONE
04
Deploy at Scale with StackSets
Use StackSets to deploy identical network templates to multiple accounts and regions, controlling concurrency and failure tolerance for safe rollouts.
VERIFIED COMPETENCY MILESTONE
