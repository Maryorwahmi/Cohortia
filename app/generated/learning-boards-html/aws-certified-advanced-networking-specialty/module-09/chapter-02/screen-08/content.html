Code Walkthrough Security Groups
Security Group example
MyWebServerSecurityGroup: Type: AWS::EC2::SecurityGroup Properties: GroupDescription: Enable HTTP/HTTPS and SSH access VpcId: !Ref MyVPC SecurityGroupIngress: - IpProtocol: tcp FromPort: 80 ToPort: 80 CidrIp: 0.0.0.0/0 - IpProtocol: tcp FromPort: 443 ToPort: 443 CidrIp: 0.0.0.0/0 - IpProtocol: tcp FromPort: 22 ToPort: 22 CidrIp: 192.168.1.0/24 SecurityGroupEgress: - IpProtocol: -1 CidrIp: 0.0.0.0/0 Tags: - Key: Name Value: WebServerSG
Explanation
  • Security group rules shown allow HTTP/HTTPS from anywhere and restrict SSH to a CIDR range to reduce exposure.
  • SecurityGroupEgress typically allows all outbound; tighten this only when necessary for segmentation.
  • NACLs should be used when you need subnet-level stateless filtering; remember to define both allow and return rules.
Common Mistake
Leaving SSH open to 0.0.0.0/0 in templates is a frequent security error. Prefer limited CIDR ranges or bastion patterns.
