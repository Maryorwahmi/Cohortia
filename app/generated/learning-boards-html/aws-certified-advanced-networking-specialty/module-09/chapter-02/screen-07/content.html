Architecture Network Components
Component cards
VPC
Defines the IP CIDR block and is the parent for subnets, route tables, and gateways.
Subnet
Partitions the VPC. Public subnets map public IPs; private subnets host internal resources.
Internet Gateway
Attached to the VPC; public route directs 0.0.0.0/0 to the IGW.
NAT Gateway & EIP
Provide outbound internet access for private subnets; NAT must live in a public subnet and use an Elastic IP.
Route Table & Associations
Define routes and associate them to subnets so traffic follows the intended gateways and NATs.
Security controls
Security Groups are stateful and attach to instances. Network ACLs are stateless and attach at the subnet boundary. Define both as resources to keep rules reproducible across accounts.
Example mapping
PublicSubnet -> PublicRouteTable -> Route to IGW PrivateSubnet -> PrivateRouteTable -> Route to NAT Gateway
