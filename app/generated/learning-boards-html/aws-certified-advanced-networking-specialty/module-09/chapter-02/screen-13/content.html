Troubleshooting Common Mistakes
Hardcoded AZs
Use !GetAZs and !Select to pick AZs dynamically instead of hardcoding names that might not exist in another region.
Manual Console Edits (Drift)
Run drift detection when you suspect resources were changed by hand, and reconcile by updating the template or reverting manual edits.
DependsOn & Ordering
Use DependsOn for explicit ordering when a resource requires another to be fully attached or available before creation.
NAT & EIP Placement
Place NAT Gateways in public subnets and create an Elastic IP to ensure private instances can access the internet through the NAT.
Quick Troubleshoot
Check stack events to find the first failing resource, correct the template or prerequisites, validate, then redeploy using a change set.
