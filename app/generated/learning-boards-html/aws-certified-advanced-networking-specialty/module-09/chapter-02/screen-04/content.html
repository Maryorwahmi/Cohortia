Core Concept What is CloudFormation?
Definition

CloudFormation lets you author templates in YAML or JSON declaring AWS resources that are provisioned as a stack. Treat templates as code: store them in version control, validate before deployment, and make changes through the template to avoid drift.

Metaphor
Think of a template as a blueprint. Instead of building a house by hand every time, the blueprint ensures each house matches the design exactly.
Key Takeaway

Declarative templates remove manual steps and provide a single source of truth for network resources.

Example: What a template names
AWSTemplateFormatVersion: '2010-09-09' Description: A simple VPC with a public subnet and Internet Gateway Parameters: VpcCidrBlock: Type: String Default: 10.0.0.0/16 Resources: MyVPC: Type: AWS::EC2::VPC Properties: CidrBlock: !Ref VpcCidrBlock EnableDnsSupport: 'true' EnableDnsHostnames: 'true' MyPublicSubnet: Type: AWS::EC2::Subnet Properties: VpcId: !Ref MyVPC CidrBlock: 10.0.1.0/24 Outputs: VpcId: Value: !Ref MyVPC
Common Misconception
CloudFormation is not just a scripting wrapper; it manages lifecycle and relationships between resources as a stack.
Pro Tip
Keep templates small and modular: use nested stacks to split VPC, subnets and security rules into reusable pieces.
