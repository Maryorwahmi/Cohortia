Definition Change Sets & Drift Detection
Change Sets
Preview the exact resource changes CloudFormation will make. Use change sets as a review step to avoid unintended replacement of network resources.
Drift Detection
Compare live resources to the template and report differences. Drift indicates manual changes were made outside CloudFormation and requires reconciliation.
Workflow
Always create a change set for planned updates, run drift detection periodically, and reconcile drift through the template or by reverting manual changes.
