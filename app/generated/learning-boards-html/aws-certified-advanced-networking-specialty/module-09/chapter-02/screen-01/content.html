Infrastructure as Code with AWS CloudFormation for Networking
Declarative templates to build repeatable, auditable network architecture
This chapter explains how to define core AWS network resources in YAML or JSON templates so you can provision VPCs, subnets, route tables, gateways, NATs, security groups and NACLs in a consistent, repeatable way. You will also explore parameters and intrinsic functions for portability, StackSets for multi-account deployments, and CloudFormation features for safe changes and drift detection.
