Process Flow Intrinsic Functions
Key intrinsic functions
  • !Ref — reference parameter values or resource logical IDs.
  • !GetAtt — read attributes produced when a resource is created.
  • !Sub — substitute variables into strings for resource names and tags.
  • !GetAZs and !Select — choose availability zones dynamically for portability.
  • !If and conditions — control resource creation based on parameters or mappings.
Example pattern
AvailabilityZone: !Select [0, !GetAZs ''] # chooses first AZ in the region
Process: make a template AZ-agnostic
  1. Replace hardcoded AZ names with !GetAZs and !Select.
  2. Move region-specific values into Mappings or Parameters.
  3. Validate with aws cloudformation validate-template and test in another region.
  4. Document defaults so operators know expected CIDR ranges and preferences.
Common Mistake
Hardcoding an AZ name causes a template to fail if that AZ is not available in the target region.
