Code Walkthrough Basic VPC Template
Template snippet (YAML)
AWSTemplateFormatVersion: '2010-09-09' Description: A simple VPC with a public subnet and Internet Gateway Parameters: VpcCidrBlock: Type: String Default: 10.0.0.0/16 Description: CIDR block for the VPC PublicSubnetCidrBlock: Type: String Default: 10.0.1.0/24 Description: CIDR block for the public subnet Resources: MyVPC: Type: AWS::EC2::VPC Properties: CidrBlock: !Ref VpcCidrBlock EnableDnsSupport: 'true' EnableDnsHostnames: 'true' MyInternetGateway: Type: AWS::EC2::InternetGateway AttachGateway: Type: AWS::EC2::VPCGatewayAttachment Properties: VpcId: !Ref MyVPC InternetGatewayId: !Ref MyInternetGateway
Explanation & Notes
  • Parameters: Allow runtime values such as CIDR blocks so templates stay reusable across stacks.
  • Intrinsic functions: !Ref and !GetAZs help reference resources and pick availability zones dynamically for portability.
  • DependsOn: Ensures resources are created in the proper order, e.g., route creation after IGW attachment.
  • Outputs: Provide VPC and Subnet IDs for other stacks or automation to consume.
Common Mistake
Hardcoding availability zone names instead of using !GetAZs causes deployments to fail in other regions.
Try This
Deploy the snippet and verify the Outputs return the VPC and PublicSubnet IDs as expected.
