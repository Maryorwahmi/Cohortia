Key Concepts

Essential terms for event-driven network automation.

Amazon EventBridge

A serverless event bus service that connects applications using data from AWS services, custom apps, and SaaS partners.

AWS Lambda

A serverless, event-driven compute service that runs code in response to events without provisioning or managing servers.

Event Pattern

A JSON structure used in EventBridge rules to filter events based on specific criteria in the event payload.

Event Source

The service or application that generates an event, such as aws.ec2, aws.s3, or your custom applications.

Summary Takeaway

Event-driven network automation relies on EventBridge to route events and Lambda to execute custom logic, using precise event patterns to filter events from various sources.
