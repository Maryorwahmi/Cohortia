Implementing the Security Group Remediator Lambda

Write the Python Lambda function to automatically detect and revoke unauthorized SSH ingress rules.

Lambda Function Logic
  • •Event Parsing: Extract eventName, requestParameters.
  • •Target SG Check: Ensure the event is for the specified TARGET_SECURITY_GROUP_ID.
  • •Rule Detection: Identify SSH (port 22) from 0.0.0.0/0 ingress rules.
  • •Rule Revocation: Use ec2.revoke_security_group_ingress to remove the offending rule.
Critical Safety Measure

The TARGET_SECURITY_GROUP_ID environment variable ensures the Lambda only acts on a specific security group, preventing unintended actions.

sg_remediator.py
import json
import boto3
import os

ec2 = boto3.client('ec2')
TARGET_SECURITY_GROUP_ID = os.environ.get('TARGET_SECURITY_GROUP_ID')

def lambda_handler(event, context):
    print(f"Received event: {json.dumps(event)}")
    try:
        event_name = event['detail']['eventName']
        request_parameters = event['detail']['requestParameters']
        if event_name == 'AuthorizeSecurityGroupIngress':
            group_id = request_parameters.get('groupId')
            if group_id != TARGET_SECURITY_GROUP_ID:
                print(f"Event for SG {group_id} ignored.")
                return {'statusCode': 200, 'body': 'Ignored'}
            ip_permissions = request_parameters.get('ipPermissions', {}).get('items', [])
            for perm in ip_permissions:
                if perm.get('ipProtocol') == 'tcp' and perm.get('fromPort') == 22 and perm.get('toPort') == 22:
                    for ip_range in perm.get('ipRanges', {}).get('items', []):
                        if ip_range.get('cidrIp') == '0.0.0.0/0':
                            print(f"Detected unauthorized SSH rule: {group_id} allowing 0.0.0.0/0 on port 22.")
                            ec2.revoke_security_group_ingress(
                                GroupId=group_id,
                                IpPermissions=[{'IpProtocol': 'tcp', 'FromPort': 22, 'ToPort': 22, 'IpRanges': [{'CidrIp': '0.0.0.0/0'}]}]
                            )
                            print(f"Successfully revoked rule from {group_id}.")
    except Exception as e:
        print(f"An unexpected error occurred: {e}")
        raise
    return {'statusCode': 200, 'body': json.dumps('SG remediation completed.')}
Key Takeaway

The Lambda function's code is responsible for parsing events, identifying non-compliant rules for a specific security group, and programmatically revoking them, enforcing security policies.
