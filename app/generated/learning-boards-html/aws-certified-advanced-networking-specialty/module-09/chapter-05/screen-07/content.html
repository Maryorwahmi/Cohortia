Crafting EventBridge Rules and Patterns

Event patterns are JSON structures that define criteria for matching and routing events to targets.

Key Elements of an Event Pattern
  • •source: Identifies the AWS service or custom application.
  • •detail-type: Describes the type of event (e.g., 'AWS API Call via CloudTrail').
  • •detail: Contains specific event payload attributes for fine-grained filtering.
Example Scenario

Automatically adding a tag to a newly created VPC. This requires filtering for the CreateVpc API call.

event-pattern.json
{
  "source": ["aws.ec2"],
  "detail-type": ["AWS API Call via CloudTrail"],
  "detail": {
    "eventSource": ["ec2.amazonaws.com"],
    "eventName": ["CreateVpc"],
    "responseElements": {
      "vpc": {
        "state": ["pending", "available"]
      }
    }
  }
}
Key Takeaway

Event patterns are critical for precise event filtering, using JSON to specify event source, type, and detailed payload attributes to trigger automation.
