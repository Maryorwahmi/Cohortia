Configuring EventBridge for Security Enforcement

Define an EventBridge rule with a specific event pattern to trigger the Lambda function on unauthorized security group ingress changes.

EventBridge Configuration Steps
  • •Define Event Pattern: Specify source, detail-type, eventName, groupId, ipProtocol, fromPort, toPort, and cidrIp.
  • •Create Rule: Use aws events put-rule.
  • •Add Target: Link the Lambda function to the rule with aws events put-targets.
  • •Grant Permission: Allow EventBridge to invoke Lambda using aws lambda add-permission.
Important Note

Ensure YOUR_TARGET_SG_ID is correctly specified in the event pattern to prevent unintended triggers on other security groups.

event-pattern.json
{
  "source": ["aws.ec2"],
  "detail-type": ["AWS API Call via CloudTrail"],
  "detail": {
    "eventSource": ["ec2.amazonaws.com"],
    "eventName": ["AuthorizeSecurityGroupIngress"],
    "requestParameters": {
      "groupId": ["YOUR_TARGET_SG_ID"],
      "ipPermissions": {
        "items": {
          "ipProtocol": ["tcp"],
          "fromPort": [22],
          "toPort": [22],
          "ipRanges": {
            "item": {
              "cidrIp": ["0.0.0.0/0"]
            }
          }
        }
      }
    }
  }
}
Key Takeaway

Configuring EventBridge involves defining a precise event pattern, creating the rule, adding the Lambda target, and granting necessary invocation permissions to establish the automation pipeline.
