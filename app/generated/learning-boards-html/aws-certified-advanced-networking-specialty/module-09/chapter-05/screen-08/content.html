Automating VPC Tagging with Lambda

A Python Lambda function extracts the VPC ID from the EventBridge event and applies predefined tags.

Lambda Logic Steps
  • •Parse Event: Extract vpcId from the EventBridge payload.
  • •Define Tags: Specify the Key and Value pairs for compliance.
  • •Apply Tags: Use boto3.client('ec2').create_tags API.
  • •Error Handling: Catch KeyError or other exceptions for robustness.
Why it's Important

Ensures consistent tagging across all VPCs, critical for cost allocation, security, and resource management, even for manually created resources.

tag_new_vpc.py
import json
import boto3

ec2 = boto3.client('ec2')

def lambda_handler(event, context):
    print(f"Received event: {json.dumps(event)}")
    try:
        vpc_id = event['detail']['responseElements']['vpc']['vpcId']
        print(f"Processing new VPC with ID: {vpc_id}")
        tags_to_apply = [
            {'Key': 'Environment', 'Value': 'Unclassified'},
            {'Key': 'AutomatedTagging', 'Value': 'True'},
            {'Key': 'Owner', 'Value': 'NetworkOps'}
        ]
        ec2.create_tags(
            Resources=[vpc_id],
            Tags=tags_to_apply
        )
        print(f"Successfully tagged VPC {vpc_id}")
    except KeyError as e:
        print(f"Error: Missing key in event payload: {e}")
    except Exception as e:
        print(f"An unexpected error occurred: {e}")
        raise
    return {'statusCode': 200, 'body': json.dumps('VPC tagging completed.')}
Key Takeaway

Lambda functions process EventBridge events to execute custom logic, like applying tags to new VPCs, ensuring compliance and consistent resource management.
