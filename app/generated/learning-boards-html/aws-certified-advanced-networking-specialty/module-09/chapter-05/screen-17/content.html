Key Concepts (Continued)

Expanding your understanding of automation components.

Target

The AWS resource or service that EventBridge invokes when a rule's event pattern matches an incoming event.

CloudTrail

An AWS service that logs actions taken by users, roles, or AWS services, often used as an EventBridge source.

VPC Flow Logs

A feature that captures information about the IP traffic going to and from network interfaces in your VPC.

CloudWatch Metric Filters

Used to extract metric data from log events in CloudWatch Logs, enabling monitoring of specific patterns.

Summary Takeaway

EventBridge targets define where events go, while CloudTrail, VPC Flow Logs, and CloudWatch Metric Filters provide the crucial event data and monitoring capabilities for advanced automation.
