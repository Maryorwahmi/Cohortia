Setting Up IAM for Automated Remediation

Create an IAM role with policies that grant the Lambda function necessary permissions for logging and security group remediation.

IAM Role & Policies
  • •Execution Policy: Grants logs:*, ec2:DescribeSecurityGroups, ec2:RevokeSecurityGroupIngress.
  • •Trust Policy: Allows lambda.amazonaws.com to assume the role.
  • •Least Privilege: Only grant permissions essential for the task.
CLI Commands

Use aws iam create-role and aws iam put-role-policy to set up the role and attach the policy. Remember to note the Role ARN.

lambda-sg-remediator-policy.json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": ["logs:CreateLogGroup", "logs:CreateLogStream", "logs:PutLogEvents"],
      "Resource": "arn:aws:logs:*:*:*"
    },
    {
      "Effect": "Allow",
      "Action": ["ec2:DescribeSecurityGroups", "ec2:RevokeSecurityGroupIngress"],
      "Resource": "*"
    }
  ]
}
lambda-trust-policy.json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Principal": {"Service": "lambda.amazonaws.com"},
      "Action": "sts:AssumeRole"
    }
  ]
}
Key Takeaway

Proper IAM role configuration with least privilege is foundational for secure automation, granting Lambda only the necessary permissions for logging and specific EC2 actions.
