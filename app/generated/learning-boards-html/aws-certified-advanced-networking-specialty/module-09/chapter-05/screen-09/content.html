Proactive Security Group Remediation

Automatically detect and respond to unauthorized security group changes, such as overly permissive ingress rules.

Common Vulnerability

Security groups modified to allow 0.0.0.0/0 (anywhere) access to sensitive ports (e.g., SSH, RDP) can expose resources to attack.

Automated Response

EventBridge triggers a Lambda function to revert the change, alert security teams, or quarantine affected instances, minimizing exposure.

security-group-event-pattern.json
{
  "source": ["aws.ec2"],
  "detail-type": ["AWS API Call via CloudTrail"],
  "detail": {
    "eventSource": ["ec2.amazonaws.com"],
    "eventName": ["AuthorizeSecurityGroupIngress", "RevokeSecurityGroupIngress"],
    "requestParameters": {
      "ipPermissions": {
        "items": {
          "ipRanges": {
            "item": {
              "cidrIp": ["0.0.0.0/0"]
            }
          },
          "toPort": [22, 3389, 8080] # Sensitive ports
        }
      }
    }
  }
}
Key Takeaway

EventBridge rules can precisely detect security group changes, like 0.0.0.0/0 access to sensitive ports, enabling immediate, automated remediation via Lambda to enhance security.
