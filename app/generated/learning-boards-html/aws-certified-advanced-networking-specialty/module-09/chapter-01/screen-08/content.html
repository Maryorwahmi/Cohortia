AWS CloudFormation and CDK

Declarative Infrastructure Provisioning at Scale

AWS CloudFormation

  • Models and provisions AWS resources.
  • Uses declarative YAML/JSON templates.
  • Manages dependencies and handles rollbacks.
  • Ensures consistent deployments.

AWS Cloud Development Kit (CDK)

  • Defines cloud infrastructure using programming languages (Python, TypeScript, etc.).
  • Synthesizes into CloudFormation templates.
  • Enables higher-level abstraction and reusability.
  • Combines declarative power with code flexibility.
Key Takeaway

CloudFormation and CDK are AWS's primary tools for declarative IaC, allowing you to define and manage your network infrastructure programmatically and at scale.
