Hands-on Activity

Exploring AWS CLI for Network Resources

A Practical Introduction to Querying Network Information

Prerequisites

  • AWS account with IAM permissions to view VPC, EC2, Security Group.
  • AWS CLI installed and configured locally.

Activity Steps

  1. Open your terminal or command prompt.
  2. List your VPCs using aws ec2 describe-vpcs.
  3. List subnets in a specific VPC.
  4. List security groups in a specific VPC.

Terminal Demo: Querying VPCs

$ aws ec2 describe-vpcs --query "Vpcs[*].{ID:VpcId,CIDR:CidrBlock,State:State,IsDefault:IsDefault}" --output table
