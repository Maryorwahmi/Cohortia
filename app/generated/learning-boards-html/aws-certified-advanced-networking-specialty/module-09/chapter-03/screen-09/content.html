Module 9 › Chapter 9.3 › Remediation Cycle
State Manager steps
1. Target by tags or resource groups
2. Schedule frequency and drift checks
3. Detect state and report compliance
4. Remediate only when necessary and persist changes
Logging & monitoring
Send outputs to CloudWatch Logs or S3 and configure CloudWatch alarms for failed remediations so operations can respond quickly.
Safety checks
Include validation and guard clauses in documents to avoid destructive actions and test associations in staging before production.
Key Takeaway

A well-designed State Manager association enforces continuous compliance without causing unintended network disruptions when tested and monitored properly.
