Module 9 › Chapter 9.3 › Security Objectives
Operational checks
Verify SSM Agent and managed instance status in Fleet Manager before running commands.
Use CloudWatch Logs or S3 to capture Run Command outputs for audits and troubleshooting.
Confirm persistence steps (e.g., writing to /etc/sysctl.conf or saving iptables) when changes must survive reboot.
Document design & testing
Parameterize documents to avoid hard-coded values and make them reusable across environments.
Test documents in non-production first, and include checks that avoid making disruptive changes without validation.
Prefer Session Manager for interactive troubleshooting; it provides an auditable channel without exposing SSH.
Milestone
Demonstrate a safe Run Command and a State Manager association in a test account, validate outputs, and show the IAM instance profile has least-privilege permissions for the tasks required.
