Example document snippet
schemaVersion: '2.2'
description: "Ensure specific sysctl setting for network performance"
parameters:
  SysctlKey:
    type: String
    default: "net.ipv4.tcp_tw_reuse"
  SysctlValue:
    type: String
    default: "1"
mainSteps:
  - action: aws:runShellScript
    name: EnsureSysctlSetting
    inputs:
      commands:
        - "CURRENT_VALUE=$(sysctl -n {{SysctlKey}})"
        - "if [ \"$CURRENT_VALUE\" != \"{{SysctlValue}}\" ]; then"
        - "  sudo sysctl -w {{SysctlKey}}={{SysctlValue}}"
        - "  echo \"{{SysctlKey}}={{SysctlValue}}\" | sudo tee -a /etc/sysctl.conf"
        - "else"
        - "  echo \"{{SysctlKey}} is already {{SysctlValue}}\""
        - "fi"
This example demonstrates parameterization and a persistence step that appends to sysctl.conf. When writing documents, include checks that avoid applying changes unnecessarily and ensure idempotence so State Manager can reapply safely.
Best practices
  • Parameterize values for reuse.
  • Make scripts idempotent and non-destructive.
  • Include persistence steps for changes that must survive reboot.
Testing
Validate documents in a staging account and capture outputs so you can roll back or iterate without impacting production networks.
