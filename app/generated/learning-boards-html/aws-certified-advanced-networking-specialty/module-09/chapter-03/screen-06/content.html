Module 9 › Chapter 9.3 › Run Command CLI
Send a command
Example CLI call to inspect a network interface. Replace the instance ID with your target.
aws ssm send-command \
  --instance-ids "i-xxxxxxxxxxxxxxxxx" \
  --document-name "AWS-RunShellScript" \
  --parameters 'commands=["ip a"]' \
  --comment "Check network interfaces" \
  --output json
The response includes a CommandId. Use that to fetch invocation details and output.
Fetch output
Use list-command-invocations with details to retrieve the command plugin output and status.
aws ssm list-command-invocations \
  --command-id "cmd-xxxxxxxxxxxxxxxxx" \
  --details \
  --query "CommandInvocations[0].CommandPlugins[0].Output" \
  --output text
