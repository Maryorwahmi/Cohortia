Module 9 › Chapter 9.3 › State Manager
Association flow
Create an association tying an SSM Document to a set of instances. Choose schedule or event triggers. State Manager will run the document and report compliance status.
Target by tags or resource groups for flexible scope management.
Choose frequency to balance responsiveness and operational load.
Enable compliance reporting so security teams can see remediations and drift metrics.
Concrete scenario
Ensure bastion hosts have fail2ban and a specific iptables OUTPUT rule blocking 1.2.3.0/24. State Manager runs a document that checks presence and applies the rule if missing, saving the rule persistently.
Common misconception
State Manager will not prevent harmful commands if the document is destructive. Author safe, idempotent documents and test them before associations run broadly.
