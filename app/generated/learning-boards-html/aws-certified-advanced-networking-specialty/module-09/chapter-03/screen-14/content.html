Module 9 › Chapter 9.3 › Key Concepts
Operational plane
SSM manages actions inside instances that provisioning tools can’t change post-launch.
Safe documents
Parameterize, make idempotent, and include persistence to avoid unexpected drift or disruption.
Security
Enforce least privilege on instance profiles, restrict who can run documents, and use Session Manager.
Summary takeaway

SSM enables secure, auditable, and scalable in-instance network automation when documents are well-designed and IAM is tightly controlled.
