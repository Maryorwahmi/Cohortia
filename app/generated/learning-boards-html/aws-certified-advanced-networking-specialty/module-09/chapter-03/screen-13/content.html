Verify SSM managed status
Confirm the instance appears in Fleet Manager or use the CLI to check managed instance inventory before sending commands.
# Send an inspection command
aws ssm send-command \
  --instance-ids "i-xxxxxxxxxxxxxxxxx" \
  --document-name "AWS-RunShellScript" \
  --parameters 'commands=["ip a"]' \
  --comment "Check network interface eth0" \
  --output json

# Capture the CommandId from response and then:
aws ssm list-command-invocations \
  --command-id "cmd-xxxxxxxxxxxxxxxxx" \
  --details \
  --query "CommandInvocations[0].CommandPlugins[0].Output" \
  --output text
For a configuration change that must persist, include persistence steps in the script and verify with a follow-up invocation or by checking the file where the setting was saved.
Example change
Increase a kernel parameter temporarily using send-command, then persist it by appending to /etc/sysctl.conf in the same document if desired.
Audit
Check CloudTrail and CloudWatch Logs for command execution records to maintain an audit trail of who executed what and the resulting outputs.
