Integrating Manual Approval for Critical Changes

Leveraging CloudFormation Change Sets for Review

Why Manual Approval?

For critical network infrastructure, human oversight is essential. Manual approval provides a final check by experts, preventing unintended or high-impact changes from being deployed automatically, even after automated tests pass.

CloudFormation Change Sets

A Change Set is a preview of the changes CloudFormation will make to your stack. It clearly outlines all proposed additions, modifications, and deletions, providing transparency for reviewers without needing to read raw IaC templates.

Key Takeaway

Manual approval with CloudFormation Change Sets is a vital safety net, balancing automation with expert human review for critical network infrastructure deployments.

# Example snippet for a CloudFormation deploy action in CodePipeline
{
  "name": "DeployToProd",
  "actions": [
    {
      "name": "CreateChangeSet",
      "actionTypeId": {
        "category": "Deploy",
        "owner": "AWS",
        "provider": "CloudFormation",
        "version": "1"
      },
      "configuration": {
        "ActionMode": "CHANGE_SET_REPLACE",
        "ChangeSetName": "NetworkChanges-${PipelineExecutionId}",
        "StackName": "ProductionNetworkVPC",
        "TemplatePath": "SourceArtifact::vpc.yaml"
      },
      "outputArtifacts": [
        { "name": "ChangeSetArtifact" }
      ],
      "inputArtifacts": [
        { "name": "SourceArtifact" }
      ],
      "runOrder": 1
    },
    {
      "name": "ApproveChangeSet",
      "actionTypeId": {
        "category": "Approval",
        "owner": "AWS",
        "provider": "Manual",
        "version": "1"
      },
      "inputArtifacts": [
        { "name": "ChangeSetArtifact" }
      ],
      "runOrder": 2
    },
    {
      "name": "ExecuteChangeSet",
      "actionTypeId": {
        "category": "Deploy",
        "owner": "AWS",
        "provider": "CloudFormation",
        "version": "1"
      },
      "configuration": {
        "ActionMode": "CHANGE_SET_EXECUTE",
        "ChangeSetName": "NetworkChanges-${PipelineExecutionId}",
        "StackName": "ProductionNetworkVPC"
      },
      "inputArtifacts": [
        { "name": "ChangeSetArtifact" }
      ],
      "runOrder": 3
    }
  ]
}

Pipeline Flow with Approval

  • Create Change Set: CodePipeline creates a Change Set but doesn't execute it.
  • Manual Approval: Pipeline pauses, awaiting human review of the Change Set.
  • Execute Change Set: If approved, the Change Set is executed, applying changes.
