Module 9 › Chapter 9.4 › AWS CLI
Definition
The CLI is an imperative, scriptable interface built on AWS SDKs.
Why use it for automation?
  • Produces JSON you can filter with JMESPath for precise values.
  • Works well in shells, pipelines, and CI jobs to orchestrate steps.
  • Good for quick audits, ad-hoc fixes, and integrating with other tools.
Common mistake
Parsing JSON with grep or awk is fragile; use --query instead.
Key Takeaway

Favor --query and --output text to create predictable, machine-friendly CLI outputs for automation.

Concrete Example
aws ec2 describe-security-groups \
  --query "SecurityGroups[?IpPermissions[?ToPort==`22` && contains(IpRanges[].CidrIp, '0.0.0.0/0')]].GroupId" \
  --output text
This command extracts only the IDs of groups permitting SSH from any source, ideal for an audit or remediation script.
