Main flow (excerpt)
print(f"Creating VPC with CIDR: {vpc_cidr}")
vpc_response = ec2.create_vpc(CidrBlock=vpc_cidr)
vpc_id = vpc_response['Vpc']['VpcId']
waiter = ec2.get_waiter('vpc_available')
waiter.wait(VpcIds=[vpc_id])
igw_response = ec2.create_internet_gateway()
igw_id = igw_response['InternetGateway']['InternetGatewayId']
ec2.attach_internet_gateway(VpcId=vpc_id, InternetGatewayId=igw_id)
The script prints progress for operator visibility and uses waiters to avoid racing dependent steps.
Cleanup note
Implement cleanup that deletes resources in reverse order and handles dependencies such as detaching the internet gateway and disassociating route tables.
Key Takeaway
Scripts should include both create and destroy logic, and use waits and tags so each step completes cleanly and is discoverable later.
