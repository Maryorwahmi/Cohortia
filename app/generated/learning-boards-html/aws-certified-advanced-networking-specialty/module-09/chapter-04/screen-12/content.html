Module 9 › Chapter 9.4 › describe_instances
Recommended approach
response = ec2.describe_instances(
  Filters=[
    {'Name': 'vpc-id', 'Values': [target_vpc_id]},
    {'Name': 'tag:Environment', 'Values': ['Production']},
    {'Name': 'tag:Role', 'Values': ['WebServer']},
    {'Name': 'instance-state-name', 'Values': ['running']}
  ]
)
# Iterate reservations -> instances -> PrivateIpAddress
Efficiency tip
Apply filters server-side to reduce response size. Iterate the Reservations structure to access instance records safely.
Key Takeaway
Use describe_instances with Filters and check instance fields before reading to avoid errors and inefficiencies.
