Retry Strategy
Handle specific exceptions and apply exponential backoff.
Step 1 — Catch
Use try-except to catch ClientError and inspect Error.Code for ThrottlingException.
Step 2 — Backoff
Wait with exponential increments between retries to reduce request rate pressure.
Step 3 — Limit
Stop after a reasonable number of attempts and raise a clear error for human review.
Example pseudocode
@retry(stop=stop_after_attempt(5), wait=wait_exponential(min=4, max=10))
def create_vpc_with_retry(cidr):
  try:
    response = ec2.create_vpc(CidrBlock=cidr)
  except ClientError as e:
    if e.response['Error']['Code'] == 'ThrottlingException':
      raise
    else:
      raise
Misconception
Retrying every error hides bugs. Limit retries to transient errors only.
