What is a waiter?
A helper that polls the API until the resource reaches a desired state, or times out.
Pattern
  1. Call create or modify API and capture the returned ID.
  2. Invoke the matching waiter with the ID to wait for readiness.
  3. Proceed with dependent calls once the waiter completes.
Example
waiter = ec2.get_waiter('vpc_available')
waiter.wait(VpcIds=[vpc_id])
# safe to create subnets now
Misconception
Using fixed sleep times is brittle; waiters adapt to actual readiness and provide clearer failures on timeout.
