def add_ssh_ingress_rule(sg_id, source_ip):
  try:
    ec2.authorize_security_group_ingress(
      GroupId=sg_id,
      IpPermissions=[{
        'IpProtocol': 'tcp','FromPort': 22,'ToPort': 22,
        'IpRanges': [{'CidrIp': source_ip, 'Description': f'SSH from {source_ip}'}]
      }]
    )
  except ClientError as e:
    if e.response['Error']['Code'] == 'InvalidPermission.Duplicate':
      print('Rule already exists')
    else:
      print(f'Error adding SSH rule: {e}')
Replace placeholders for VPC ID, security group name, and your public IP before running.
Verification steps
Run the script, then confirm the inbound rule appears in the EC2 console under Inbound Rules for the security group. Optionally run the revoke function to remove the test rule.
Key Takeaway
Always validate script changes in a safe environment and make scripts idempotent so repeated runs do not create duplicates.
