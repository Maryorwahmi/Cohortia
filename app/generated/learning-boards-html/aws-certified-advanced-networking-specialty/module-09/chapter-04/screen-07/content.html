Module 9 › Chapter 9.4 › CLI vs SDK
AWS CLI
  • Quick commands and audits using --query for precise output.
  • Great for pipelines, CI steps, and ad-hoc remediation.
  • Lower setup for small tasks; no interpreter integration needed.
Boto3 SDK
  • Best for complex workflows, loops, and conditional logic.
  • Offers waiters, structured error handling, and retries in a language environment.
  • Easier to test, integrate, and maintain inside applications.
Concrete example
Use the CLI with JMESPath to list problematic security groups for review. Then use a Boto3 script to add or revoke rules programmatically as part of an automated remediation pipeline with retries and logging.
