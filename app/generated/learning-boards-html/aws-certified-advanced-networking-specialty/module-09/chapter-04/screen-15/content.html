Module 9 › Chapter 9.4 › Remember
Query precisely
Use --query and JMESPath to return only the fields your automation needs.
Script resiliently
Add waiters, retries, and explicit error handling to handle transient states and throttling.
Secure credentials
Use instance roles, profiles, or secrets stores and apply least privilege to every automation principal.
One final tip
Run automation in a test environment first, validate idempotency and cleanup, then promote to production under controlled change processes.
