Customer Gateway Configuration

Prepare the AWS CGW resource and the matching on‑prem IPsec device settings so tunnels form reliably and routing works without manual intervention.

In this lesson

What AWS requires for a CGW, when to use static routing vs BGP, the IPsec Phase 1 and 2 parameters your device must match, and common troubleshooting checks.

Why it matters

A correct CGW and device configuration prevents tunnel failures, avoids routing blackholes, and enables automated failover when you use BGP.

Concept map

CGW → VPN Tunnels → VGW

Customer Gateway
Public IP, BGP ASN, device label
Represents your on‑prem device to AWS so tunnels can be built.
On‑prem VPN Device
Configurable IKE/IPsec, PSK, Tunnel IPs
Performs actual encryption and BGP peering when enabled.
Virtual Private Gateway
AWS endpoint for tunnels
Advertises VPC CIDRs to your device when BGP is used.
Tunnels
Two independent IPsec tunnels
Each tunnel has unique PSK and inside IPs used for routing or BGP peering.
