Module 2 › Chapter 2.2 › Two Redundant Tunnels
Why two tunnels

AWS creates two tunnels with different public IPs and PSKs to provide path redundancy and enable failover.

Step checklist
  1. Download AWS VPN config and copy tunnel parameters.
  2. Create IKE/IPsec profiles matching AWS values.
  3. Configure Tunnel1, test, then configure Tunnel2.
  4. Validate routing and perform a failover test.
Example failure test

Bring down Tunnel1 and confirm that BGP withdraws affected routes or that traffic flows over Tunnel2 for static routing. If traffic is blackholed, recheck route configuration.

Pitfall

Avoid copying Tunnel1 settings onto Tunnel2; each tunnel must use its own PSK and AWS IP target.

Key Takeaway

Treat tunnels independently: configure and validate each with the AWS-supplied values and then test failover behavior.
