Module 2 › Chapter 2.2 › What is a Customer Gateway?
Definition

Customer Gateway: logical AWS resource

Represents your physical or software VPN device so AWS can form VPN tunnels and provide configuration details.

Core fields
  • Public IP address (must be reachable)
  • BGP ASN for dynamic routing or placeholder for static
  • Device name for operator clarity
Concrete example
Create a CGW with public IP 203.0.113.10 and ASN 65001 so AWS can generate tunnel settings and a config file tailored to your device.
Key Takeaway

The CGW tells AWS where to connect and whether BGP will be used; it is not the encrypting device itself.

Analogy

Think of the CGW as a contact card in AWS that stores the address and routing preference for your on‑prem VPN device. AWS uses this contact card to choose where to send tunnel setup traffic and how to build configuration files.

Common confusion

Do not confuse the CGW resource with the physical device's configuration. You still manage encryption, PSKs, and tunnel IPs on your device.
