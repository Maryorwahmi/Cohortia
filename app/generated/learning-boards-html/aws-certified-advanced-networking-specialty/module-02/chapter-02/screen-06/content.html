Core Fields

What to enter when creating a CGW

These values tell AWS where to send IKE and how routing will be handled.

Public IP
A static, internet‑routable address for your VPN device. If behind NAT, ensure NAT‑T and correct external mapping.
BGP ASN
Your on‑prem ASN for dynamic routing. If using static routing, AWS still requires a value as a placeholder.
Device name
A human label that helps with operations and configuration tracking.
Operational tip
Record the CGW public IP in your maintenance runbook and schedule changes in maintenance windows since IP changes break tunnels.
Example entry
Public IP: 203.0.113.10 • BGP ASN: 65001 • Device name: "DC1-CGW-1"
Misstep to avoid

Do not register a dynamic ISP IP as the CGW address; it will disrupt tunnels if the address changes without notice.
