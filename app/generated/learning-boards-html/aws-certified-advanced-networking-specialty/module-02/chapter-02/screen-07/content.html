Definition

Phase 1 (IKE)

Negotiates the secure control channel and agrees keys and algorithms used by Phase 2.

  • Encryption: AES‑128 or AES‑256
  • Hash: SHA1 or SHA256
  • DH group: Group 2, Group 14, etc.
  • Lifetime: commonly 28800 seconds
Example
IKE encryption AES‑256, IKE hash SHA256, DH group 14, lifetime 28800. Copy these from the AWS config and match them exactly on your device.
Common mistake

A mismatch in DH group or hash algorithm causes IKE negotiation to fail; logs will show Phase 1 errors.

Key Takeaway

Verify Phase 1 fields exactly against the AWS configuration to allow the tunnel to progress to Phase 2.
