Definition

Phase 2 (ESP)

Negotiates encryption and authentication for the actual IP packets carried by the tunnel.

  • ESP encryption: AES‑128 or AES‑256
  • ESP hash: SHA1 or SHA256
  • PFS DH group: Group 2 or 14 when required
  • Lifetime: commonly 3600 seconds
Example

ESP AES‑256 with SHA256, PFS Group 14, lifetime 3600. Put these values into your transform-set or IPsec profile exactly as AWS specifies.

Common mistake

Enabling PFS on one side and not the other will break Phase 2 negotiation — always mirror PFS settings.

Key Takeaway

Mirror AWS Phase 2 (ESP) settings exactly to allow encrypted traffic to flow through the tunnel.
