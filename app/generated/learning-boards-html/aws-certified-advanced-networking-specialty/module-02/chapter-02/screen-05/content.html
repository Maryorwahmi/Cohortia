Module 2 › Chapter 2.2 › Static vs BGP
Comparison

Static Routing

  • Manual route entries on both AWS and on‑prem device.
  • Simple to configure for small, stable networks.
  • No automatic withdrawal on tunnel failure — manual intervention needed.

Dynamic Routing (BGP)

  • Automatic route advertisement and withdrawal between your device and the VGW.
  • Supports automatic failover when one tunnel fails.
  • Requires a unique on‑prem BGP ASN and device support for BGP.
Concrete scenario

If your on‑prem network is 10.0.0.0/16 and your VPC is 172.31.0.0/16, static routing requires entering those CIDRs on both sides. With BGP, once the neighbor forms, routes are exchanged automatically and updated if links change.

Misconception

BGP is not inherently risky; it introduces a manageable protocol setup that yields reliable automated failover when configured correctly.

Key Takeaway

Prefer BGP for production to gain automatic route failover; use static only for simple or short‑lived setups.
