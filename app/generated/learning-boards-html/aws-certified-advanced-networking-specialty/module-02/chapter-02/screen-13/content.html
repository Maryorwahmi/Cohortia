Stepwise checklist
  1. Confirm UDP 500/4500 reachability to AWS VGW IPs.
  2. Check IKE Phase 1 SA establishment in the logs.
  3. Check IPsec Phase 2 SA and lifetime.
  4. Verify tunnel interface IPs and reachability.
  5. Confirm BGP neighbor or static route presence and advertised networks.
  6. Test failover by intentionally disrupting one tunnel and observing routing behavior.
Common log messages

Phase 1 errors typically indicate mismatched IKE parameters. Phase 2 failures indicate ESP or PFS mismatches. BGP neighbor problems often point to incorrect neighbor IPs or ASN mismatches.

Quick fixes
  • Copy AWS config values verbatim into device profiles.
  • Open UDP 500/4500 on firewalls and NAT devices.
  • Ensure correct external IP recorded for CGW and port forwarding configured if needed.
Key Takeaway

Use a short, repeatable checklist to validate tunnels and routing; script checks when possible to reduce human error.
