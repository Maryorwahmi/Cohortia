Module 2 › Chapter 2.2 › PSK, Tunnel IPs, BGP
Explanation

AWS provides a PSK per tunnel and a pair of tunnel inside IPs. Set the PSK and tunnel IP on your device, then configure BGP to peer to the AWS tunnel IP if using dynamic routing.

Checkpoints
  • PSK matches exactly — typos cause auth failure.
  • Tunnel IPs used as neighbor addresses for BGP or next‑hop for static routes.
  • Unique PSK per tunnel — do not reuse unless AWS specifies.
Code walkthrough (example)
! --- Tunnel 1 ---
crypto isakmp key MyStrongPSK123 address 52.X.Y.Z no-xauth
interface Tunnel1
 ip address 169.254.20.2 255.255.255.252
 tunnel source GigabitEthernet0/0
 tunnel destination 52.X.Y.Z
!
router bgp 65001
 neighbor 169.254.20.1 remote-as 64512
 address-family ipv4
  network 10.10.0.0 mask 255.255.0.0
  neighbor 169.254.20.1 activate
 exit-address-family
This example maps the AWS-provided PSK and tunnel IPs into device commands; repeat for Tunnel 2 with its PSK and AWS IP.
Key Takeaway

Use the AWS-supplied PSKs and tunnel IPs exactly as provided; they enable authentication and BGP peering for routing exchange.
