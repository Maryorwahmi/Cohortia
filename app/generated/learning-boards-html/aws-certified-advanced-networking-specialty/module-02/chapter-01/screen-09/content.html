Common parameters
  • Pre-shared key (PSK) — must match AWS configuration.
  • Encryption algorithm — provides confidentiality.
  • Hashing algorithm — ensures integrity.
  • Diffie-Hellman group — dictates key exchange strength.
  • SA lifetime — must be coordinated on both sides.
NAT & firewall notes
If your VPN device sits behind NAT, enable NAT Traversal and ensure UDP 500 and 4500 are permitted. Confirm the public IP used in the CGW exactly matches the device’s external address.
