Module 2 › Chapter 2.1 › VPN Architecture
Components
  • Virtual Private Gateway (VGW): logical VPN concentrator attached to a single VPC.
  • Customer Gateway (CGW): AWS representation of your on-premises VPN device, including its public IP and optional BGP ASN.
  • Dual IPsec tunnels: two independent tunnels for redundancy and failover.
Example routing behavior
Key Takeaway

Route propagation and routing preferences determine how traffic fails over between the two tunnels — ensure on-premises routers and VPC route tables are configured to learn and prefer the healthy path.

Visual summary
On-premises CGW (public IP)
↕ IPsec tunnel 1 — ESP + IKE
↕ IPsec tunnel 2 — ESP + IKE (redundant)
VGW attached to VPC — routes propagate to VPC route tables
Remember: VGW is logical and attaches to exactly one VPC. If you need centralized routing between multiple VPCs and on-premises networks, consider Transit Gateway attachments.
