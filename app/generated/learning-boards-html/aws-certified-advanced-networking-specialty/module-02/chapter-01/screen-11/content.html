Module 2 › Chapter 2.1 › Troubleshooting
Common causes
  • Mismatched crypto algorithms or lifetime settings between peers.
  • Incorrect public IP recorded for the Customer Gateway.
  • Blocked UDP 500 or 4500 through firewalls or NAT devices.
  • Missing or incorrect routes on either side, causing black-holing.
Start with IKE logs, then confirm IP reachability and port access, then verify parameter alignment and routing entries. Use AWS-provided vendor config snippets to avoid parameter errors.
Quick remediation
  1. Validate CGW public IP and port reachability.
  2. Confirm PSK and crypto settings match exactly.
  3. Check firewall and NAT rules for UDP 500/4500.
  4. Verify route propagation and routing tables.
