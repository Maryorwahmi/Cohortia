Module 2 › Chapter 2.1 › Routing Choices
Static routing
Use when the remote CIDRs are few and stable. Configure explicit routes in AWS and on-premises devices. Advantages: simplicity and predictability. Drawbacks: manual updates for topology changes.
Dynamic routing with BGP
Exchange routes automatically when you provide a BGP ASN for the Customer Gateway. Scales to many prefixes and improves failover responsiveness. Requires ASN configuration and careful route filtering to maintain control.
Decision guide
Scale: static for small, BGP for many prefixes
Failover: BGP propagates changes automatically
Complexity: static is simpler, BGP needs operational knowledge
