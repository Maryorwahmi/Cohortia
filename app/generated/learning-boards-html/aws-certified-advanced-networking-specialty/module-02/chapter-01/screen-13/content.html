Requirements summary
  • On-premises: 10.0.0.0/16
  • AWS VPC: 172.31.0.0/16
  • Traffic: up to 500 Mbps, secure encryption, high availability
Chosen option: Site-to-Site VPN for quick setup and encrypted connectivity; consider Direct Connect later if sustained traffic exceeds acceptable VPN performance.
Essential components & info
  • VPC with CIDR 172.31.0.0/16
  • Virtual Private Gateway (VGW) attached to the VPC
  • Customer Gateway (CGW) resource with public IP and optional BGP ASN
  • VPN Connection resource linking VGW and CGW
From on-premises: public-facing IP, NAT status, BGP ASN (if using BGP), and the list of internal CIDRs to advertise.
Plan template
# InnovateTech Hybrid Connectivity Plan

## 1. Connectivity Option Justification
- Chosen Option: Site-to-Site VPN
- Reasoning:
    - Bandwidth: suitable for anticipated 500 Mbps with testing; consider Direct Connect later if usage grows
    - Security: IPsec encryption via ESP ensures confidentiality and integrity
    - Availability: dual tunnels plus routing failover
    - Cost/Setup Time: VPN is faster and lower cost initially

## 2. Essential AWS Components
- VPC, Virtual Private Gateway (VGW), Customer Gateway (CGW), VPN Connection

## 3. On-premises Information Required
- Public IP of the VPN device, NAT presence, BGP ASN (optional), internal network CIDRs
