Module 2 › Chapter 2.1 › Tunnel Establishment
Step-by-step
1. Peer discovery and IKE Phase 1: authenticate endpoints and create a secure channel for negotiation.
2. IKE Phase 2 (SA negotiation): agree encryption, hashing, Diffie-Hellman group, and lifetime values.
3. ESP transport: begin transporting encrypted and authenticated packets using the negotiated SAs.
4. Routing: propagate or add routes so traffic uses the new secure path.
Because AWS provisions two tunnels, repeat this process for each tunnel endpoint. Validate each tunnel independently and then confirm route failover behavior.
Quick checklist
  • Matching IPsec parameters on both sides
  • Pre-shared key entered correctly
  • UDP 500 and 4500 allowed through firewalls
  • Public IP of CGW is reachable
