Commands
# 1. Add a static route for on-prem network
aws ec2 create-route --route-table-id rtb-0fedcba9876543210 \
  --destination-cidr-block 10.0.0.0/16 \
  --vpn-gateway-id vgw-0abcdef1234567890

# 2. Enable route propagation for the VGW on a route table
aws ec2 enable-vpn-gateway-route-propagation \
  --route-table-id rtb-0fedcba9876543210 \
  --vpn-gateway-id vgw-0abcdef1234567890

# 3. View routes in a route table
aws ec2 describe-route-tables --route-table-ids rtb-0fedcba9876543210 --query 'RouteTables[].Routes[]'

# 4. Allow inbound ICMP from on-prem 10.0.0.0/16 to EC2 SG
aws ec2 authorize-security-group-ingress --group-id sg-0123456789abcdef0 --protocol icmp --port -1 --cidr 10.0.0.0/16
After running these commands, always use describe-route-tables and a live ping from an EC2 instance to an on-prem host to confirm end-to-end reachability.
Verification tips
  • Look for DestinationCidrBlock '10.0.0.0/16' in describe output
  • Check for origin 'propagated' to confirm BGP learned it
  • Run a ping from EC2 to on-prem and check return path
Key Takeaway

CLI commands are reproducible; pair them with describe commands and pings to validate success.
