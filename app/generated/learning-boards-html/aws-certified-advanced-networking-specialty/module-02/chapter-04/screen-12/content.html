Module 2 › Chapter 2.4 › BGP & Tunnel Verification
Checks to perform
  • Confirm tunnel status is UP in the AWS console
  • On-prem device: run show ip bgp summary and confirm Established
  • Inspect advertised prefixes from the CGW and expected VPC prefixes
If BGP is Established but routes are missing, inspect on-prem advertisement configuration and any prefix filters. Also check that propagation is enabled on the right route table.
Quick reference
AWS Console: VPC → Site-to-Site VPN Connections → [Your VPN Connection] → Tunnel Details → BGP Status
On-prem: show ip route and show ip bgp summary to ensure VPC prefixes are present and BGP peers are exchanging routes.
Key Takeaway

Always validate both tunnel health and BGP advertisements; both are required for propagation to work.
