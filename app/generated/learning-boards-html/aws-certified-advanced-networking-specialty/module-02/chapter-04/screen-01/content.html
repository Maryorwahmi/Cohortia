Routing for Site-to-Site VPN

Control how traffic leaves your VPC and reaches on-premises networks, and vice versa.

In this lesson
Static routes, route propagation, and troubleshooting.
Coming up
AWS CLI examples and verification steps.
Goal
Confirm bi-directional routing over the VPN.
Virtual Private Gateway
VGW is the AWS next hop for on-prem routes.
Example IDs used in this chapter: VPC vpc-0123456789abcdef0, VGW vgw-0abcdef1234567890
Explore Key Topics
Static Routes
Manual route entries pointing on-premises CIDRs to the VGW; required when not using BGP.
Route Propagation
Enable VGW propagation and allow BGP advertisements to populate the VPC route table automatically.
Troubleshooting
Check routes, security groups, NACLs, tunnel status and BGP state to pinpoint failures.
