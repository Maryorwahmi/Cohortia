Module 2 › Chapter 2.4 › Learning Objectives
01
Reason about hybrid routing
Understand how VPC route tables and on-premises routers exchange reachability so traffic flows both ways.
Mnemonic: think "Next Hop Map" — each CIDR needs a clear next hop.
VERIFIED COMPETENCY MILESTONE
02
Configure VPC route tables
Add static routes to the VGW or enable route propagation so VGW-learned prefixes appear automatically.
Mnemonic: "Static equals manual, Propagation equals learned."
VERIFIED COMPETENCY MILESTONE
03
Interpret BGP advertisements
Verify which prefixes your Customer Gateway advertises and confirm they appear in route tables if propagation is enabled.
Mnemonic: "If BGP speaks, propagation listens."
VERIFIED COMPETENCY MILESTONE
04
Troubleshoot routing failures
Work through a checklist: tunnels, routes, security groups, firewall rules, CIDR overlaps and BGP state.
Mnemonic: "Ping, check routes, check firewalls, check BGP."
VERIFIED COMPETENCY MILESTONE
