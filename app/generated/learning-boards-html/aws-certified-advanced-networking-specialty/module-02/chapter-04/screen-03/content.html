Module 2 › Chapter 2.4 › Learning Objectives
CLI Fluency
Use aws ec2 create-route and enable-vpn-gateway-route-propagation to manage routes. Verify with describe-route-tables.
On-prem skills
Configure static next hops to tunnel inside addresses, or establish BGP peering and advertise local CIDRs.
Verification
Run ping tests, check tunnel status in the console, and read route origins to see if they are propagated or manually added.
Troubleshoot checklist
  • Confirm route presence and route table association
  • Validate security group and firewall rules
  • Inspect BGP state and tunnel health
