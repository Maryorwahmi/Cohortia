Module 2 › Chapter 2.4 › Static vs Propagation
Static Routes
  • Manual entries per on-prem CIDR
  • Useful when BGP is unavailable
  • Risk of human error at scale
Example: Add 10.0.0.0/16 → vgw-0abcdef1234567890 via create-route.
Route Propagation (BGP)
  • Automatically learns prefixes via BGP
  • Supports automatic withdrawal on failure
  • Requires established BGP sessions
Example: CGW advertises 10.0.0.0/16 and 10.1.0.0/24; enable propagation to import these prefixes.
Decision Tip
If you expect many on-prem prefixes or automatic failover, prefer BGP propagation. If you have a small static footprint or cannot run BGP, use static routes but maintain good audit controls.
