Module 2 › Chapter 2.4 › Common Mistakes
Checklist
  1. Ping test from EC2 to on-prem and reverse
  2. Verify tunnels are UP in the AWS console
  3. Confirm routes exist in VPC route table and on-prem routing
  4. Check security groups and NACLs for allowed traffic
  5. Inspect BGP state and advertised prefixes
Example command to inspect BGP state (on the device): show ip bgp summary. In AWS console check the VPN connection tunnel details for BGP Status.
Common root causes
  • Missing static route in VPC route table
  • Route added to wrong route table or wrong association
  • Security groups blocking the traffic
  • Overlapping CIDRs creating ambiguity
Key Takeaway

Work down the checklist methodically: verify path, then routing, then firewall, then BGP, so you isolate the exact failure point.
