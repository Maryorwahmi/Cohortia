Module 2 › Chapter 2.4 › What routing means
Definition
Routing determines the next hop for traffic leaving a subnet so packets reach remote CIDRs across the VPN.
Claim
Both sides must have explicit routes for the other side’s CIDR blocks.
Example
VPC 172.31.0.0/16 needs a route to 10.0.0.0/16 with target vgw-0abcdef1234567890 to reach on-premises hosts.
Misconception
An UP VPN tunnel does not imply routing is correct; missing route table entries can still block traffic.
Key Takeaway

Always confirm route entries on AWS and on-premises devices so the VGW has a clear next hop for remote CIDRs.

Annotated Example
Subnet CIDR: 172.31.0.0/16 VPC ID: vpc-0123456789abcdef0 On-prem CIDR: 10.0.0.0/16 VGW: vgw-0abcdef1234567890 If instance 172.31.10.5 → destination 10.0.2.20 Route: 10.0.0.0/16 → target vgw-0abcdef1234567890
Question: If a ping from EC2 to on-prem fails, do you check the AWS route table or the on-prem route first? Try both: a missing route on either side can create one-way or no connectivity.
