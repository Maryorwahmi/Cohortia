Module 2 › Chapter 2.4 › Key Concepts
VGW is next hop
Point on-prem CIDRs to the VGW in VPC route tables for AWS-originated traffic.
Use BGP for scale
Propagation automates route distribution and supports failover when prefixes change.
Check firewalls
Routes alone do not guarantee connectivity; security groups and on-prem firewalls must allow the traffic too.
Final checklist
Verify routes, confirm associations, validate firewalls, check tunnel and BGP state — then test with a live ping.
