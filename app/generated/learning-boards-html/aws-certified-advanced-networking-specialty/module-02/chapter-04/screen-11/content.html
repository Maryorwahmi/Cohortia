Module 2 › Chapter 2.4 › Hands-on Activity
Task
Enable route propagation for the VGW on the main route table, then verify the 10.0.0.0/16 route appears and test connectivity from an EC2 instance.
# Enable Route Propagation
aws ec2 enable-vpn-gateway-route-propagation \
  --route-table-id rtb-0fedcba9876543210 \
  --vpn-gateway-id vgw-0abcdef1234567890

# Verify Route Table
aws ec2 describe-route-tables --route-table-ids rtb-0fedcba9876543210 --query 'RouteTables[].Routes[]'

# Allow ICMP from on-prem to EC2 SG
aws ec2 authorize-security-group-ingress --group-id sg-0123456789abcdef0 --protocol icmp --port -1 --cidr 10.0.0.0/16
Verification & troubleshooting
  • Confirm describe-route-tables shows 10.0.0.0/16 with origin 'propagated'
  • Ping from an EC2 instance to on-prem and check for replies
  • If ping fails: check tunnel status, security groups, route associations, BGP state and on-prem advertisements
Reflection: after enabling propagation, did the route appear immediately? If not, check BGP session state and that your CGW is actually advertising the prefix.
