Key metrics
  • TunnelState: binary indicator of UP (1) or DOWN (0).
  • TunnelDataIn / TunnelDataOut: bytes transferred, reveals throughput trends.
  • TunnelPps: packets per second, shows traffic bursts or drops.
Operational patterns
Create alarms on TunnelState for rapid alerts. Use dashboards that plot data and pps alongside state so you can interpret whether a tunnel is up but idle or up but congested.
Example: alarm on TunnelState with period 1 minute and statistic Minimum triggers immediate notifications.
Misconception: a tunnel reported UP always means traffic is flowing — verify with data and pps metrics.
