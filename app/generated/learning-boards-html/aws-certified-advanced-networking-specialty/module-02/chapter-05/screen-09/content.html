Alarm recipe (high level)
  1. Select metric: Namespace 'AWS/VPN' → TunnelState.
  2. Choose VPN ID and TunnelIpAddress dimensions for both tunnels.
  3. Condition: Statistic = Minimum, Period = 1 minute, Threshold ≤ 0.
  4. Action: attach SNS topic to notify on-call.
Flow log checks

Query flow logs for your on-prem source and VPC destination. Look for accepted entries to confirm reachability or missing entries to indicate packets never reached the VGW.

Tip: correlate timestamps across alarm, CloudWatch metrics, and flow logs to pinpoint the moment and scope of impact.
