Module 2 › Chapter 2.5 › Learning Objectives
01
Implement multiple Customer Gateways
Deploy two or more on-prem devices and create VPN connections to each CGW for device-level redundancy. VERIFIED COMPETENCY MILESTONE
Mnemonic: two boxes with independent public IPs
02
Configure BGP failover
Use BGP so route advertisements switch automatically between CGWs during failover. VERIFIED COMPETENCY MILESTONE
Mnemonic: dynamic routes adapt like tide levels
03
Enable Accelerated VPN when needed
Evaluate latency and jitter. Use Accelerated VPN to send traffic into AWS backbone when internet paths are poor. VERIFIED COMPETENCY MILESTONE
Mnemonic: edge location shortcut
04
Monitor and troubleshoot with CloudWatch and CLI
Collect TunnelState and flow logs, create alarms, and use AWS CLI plus device diagnostics for root cause. VERIFIED COMPETENCY MILESTONE
Mnemonic: measure, alert, and inspect
