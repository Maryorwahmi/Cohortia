Module 2 › Chapter 2.5 › AWS Accelerated VPN
Concept

Traffic enters an AWS edge location near your site, then traverses the AWS backbone to the VGW, bypassing congested public internet segments.

When to use
  • Long-distance or congested internet paths causing latency or jitter.
  • When improved consistency for sensitive application traffic is required.
Note: additional data transfer charges apply for Accelerated VPN.
Example
A remote office experiences packet loss on the internet path. Enabling Accelerated VPN routes traffic into the nearest AWS edge and across AWS backbone, reducing packet loss and improving throughput.
Pro tip: test performance before and after enabling Accelerated VPN to confirm value.
Misconception: Accelerated VPN is not a substitute for CGW redundancy or correct IPsec parameters.
