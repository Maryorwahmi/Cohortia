Module 2 › Chapter 2.5 › Tunnel Up, No Traffic
Routing checks
  • VPC route table entries for on-prem CIDRs point to VGW (static) or route propagation is enabled (BGP).
  • On-prem routes send VPC CIDRs to the correct tunnel interface.
  • Verify BGP advertisements are correct and learned by AWS.
Security and addressing
Check EC2 Security Groups and subnet NACLs allow the expected traffic. Confirm no overlapping CIDRs exist between VPC and on-premises networks. If overlaps exist, traffic will be ambiguous and fail.
Example: flow logs show no accepted packets — security group or NACL likely blocking.
