Module 2 › Chapter 2.5 › Tunnel Not Coming Up
Common causes
  • Mismatched IKE/IPsec Phase 1 & 2 parameters or PSK.
  • Firewall blocking UDP 500 or UDP 4500 to/from VGW public IPs.
  • NAT issues: NAT-T disabled or incorrect external IP mapping.
  • Public IP configured for CGW does not match on-premises external IP.
Actionable checks
1) Use AWS-generated config as your single source of truth. 2) On device, verify IKE SAs and IPsec SAs. 3) Confirm UDP/500 and UDP/4500 reach the appliance. 4) If behind NAT, ensure NAT-T and port forwarding are correct. 5) Verify the public IP used in the CGW matches the NAT device's external IP.
Example: 'show crypto isakmp sa' returns no active SAs — check PSK and IKE parameters against AWS file.
Common mistake: assuming internet connectivity implies correct NAT mapping — external IP must match CGW entry.
