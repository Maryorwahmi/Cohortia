Module 2 › Chapter 2.5 › BGP Failover
Failover steps
  1. Register each on-prem device as a separate CGW with its public IP and configure BGP.
  2. Confirm each CGW establishes an 'Established' BGP session to the VGW.
  3. Verify both devices advertise the same on-prem prefixes to AWS.
  4. Test failover: simulate Router-A outage and observe BGP withdrawals and continued traffic on Router-B.
Check: route propagation and VPC route tables remain correct after failover.
Example scenario
Router-A advertises 10.10.0.0/16, Router-B does the same. Router-A loses internet; its BGP session to VGW stops. VGW receives only Router-B advertisements and traffic keeps flowing through Router-B without manual changes.
Validation: 'show ip bgp summary' shows session states; AWS console 'Tunnel Details' shows BGP up/down.
Pitfall: mismatched advertised prefixes cause route ambiguity and traffic to follow unexpected paths.
