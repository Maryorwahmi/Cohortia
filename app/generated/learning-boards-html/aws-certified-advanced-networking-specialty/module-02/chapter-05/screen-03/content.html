CloudWatch metrics and alarms

Collect TunnelState, TunnelDataIn, TunnelDataOut, and TunnelPps. Use alarms to notify on tunnel DOWN events so you can act before applications fail.

Mnemonic: state, in, out, pps
VPC Flow Logs and reachability

Enable flow logs to verify whether traffic arrives at the VGW and to detect security group or NACL drops affecting traffic flow.

Mnemonic: trace packets to the VGW
IPsec parameter verification

Use the AWS-generated VPN configuration file as the single source of truth when comparing IKE/IPsec algorithms, DH groups, lifetimes, and PSK values.

Mnemonic: match settings exactly
NAT traversal awareness

When a device sits behind NAT, ensure NAT-T is enabled and that the CGW public IP in AWS matches the NAT device's external address with proper port forwarding for UDP 500 and 4500.

Mnemonic: external IP must be accurate
