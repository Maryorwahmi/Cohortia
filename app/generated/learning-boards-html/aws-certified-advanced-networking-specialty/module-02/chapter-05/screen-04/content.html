Module 2 › Chapter 2.5 › Multiple Customer Gateways
Definition

Register each on-premises VPN device as a distinct Customer Gateway with its own public IP, then create a VPN connection from the VGW to each CGW.

Why this matters
  • Device-level failover protects against a single appliance failure.
  • BGP can automate route failover so traffic shifts without manual changes.
Key Takeaway

Separate the public IP and device. Multiple tunnels on one box are not the same as multiple CGWs.

Architecture snapshot
On-Prem
Router-A (public IP A)
Router-B (public IP B)
Each maps to a Customer Gateway resource in AWS.
AWS
VGW attached to VPC
vpn-connection-A, vpn-connection-B
BGP sessions carry route advertisements between CGWs and VGW.
Example validation: check BGP 'Established' on both tunnels and confirm both tunnels show UP in AWS console or via describe-vpn-connections.
Common mistake: Multiple tunnels from one CGW do not protect you from a single device failure.
