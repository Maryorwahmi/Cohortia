Example AWS CLI commands
# Check VPN Connection status
aws ec2 describe-vpn-connections --vpn-connection-ids vpn-0123456789abcdef0

# Check CloudWatch metrics for VPN tunnel state
aws cloudwatch get-metric-data \
    --metric-data-queries '[{"Id":"t1state","MetricStat":{"Metric":{"Namespace":"AWS/VPN","MetricName":"TunnelState","Dimensions":[{"Name":"VpnId","Value":"vpn-0123456789abcdef0"},{"Name":"TunnelIpAddress","Value":"52.X.Y.Z"}]},"Period":300,"Stat":"Average"},"ReturnData":true}]' \
    --start-time $(date -v-1H +%Y-%m-%dT%H:%M:%SZ) --end-time $(date +%Y-%m-%dT%H:%M:%SZ})
Replace placeholders with your VPN ID and tunnel IP when running these commands.
On-premises diagnostics
Use your device show commands to inspect IKE and IPsec state. Example checks: 'show crypto isakmp sa' for IKE SAs and 'show crypto ipsec sa' for IPsec SAs. If SAs are missing, compare IKE/IPsec parameters to the AWS-generated configuration file.
Tip: correlate timestamps between CLI outputs and CloudWatch metric data to identify when the issue began.
