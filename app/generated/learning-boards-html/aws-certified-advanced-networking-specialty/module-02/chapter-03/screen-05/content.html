Process Flow

Steps to create and attach a VGW

  1. Create the VGW: choose default Amazon ASN or custom private ASN if you have BGP needs.
  2. After creation, confirm VGW state is detached; record the VpnGatewayId for CLI flows.
  3. Attach VGW to the target VPC and confirm the attachment moves to attached.
  4. Verify route tables or propagation settings later when you create the VPN connection.
ASN guidance
Default Amazon ASNs (64512 range) are fine for most setups; supply a private ASN only to match BGP planning for your network.
CLI Example
# Create a Virtual Private Gateway
aws ec2 create-vpn-gateway --type ipsec.1 --amazon-asn 64512

# Attach the VGW to your VPC
aws ec2 attach-vpn-gateway --vpn-gateway-id vgw-0abcdef1234567890 --vpc-id vpc-0123456789abcdef0
Common mistake
Assuming creation implies attachment — a detached VGW cannot be targeted by a VPN connection.
Pro tip
Record the VpnGatewayId immediately; it is used in CLI commands and logging during troubleshooting.
