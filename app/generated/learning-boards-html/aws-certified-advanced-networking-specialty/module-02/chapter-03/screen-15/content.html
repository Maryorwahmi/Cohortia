Module 2 › Chapter 2.3 › Key Concepts
Static Routing (VPN)
Manually enter on‑premises CIDR blocks; good for devices without BGP but requires manual failover plans.
Dynamic Routing (BGP)
BGP advertises routes and supports automatic failover when one tunnel fails.
Tunnel Options
IKE version, PSKs, DH groups, ciphers, and lifetimes must match the on‑premises device for tunnels to establish.
Final summary

Routing decisions and exact tunnel parameter matching determine resilience; always use the AWS configuration file as the source of truth for device configuration.
