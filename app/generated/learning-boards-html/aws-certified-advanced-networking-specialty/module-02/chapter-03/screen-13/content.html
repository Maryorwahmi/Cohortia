Activity: Configure VGW and Dynamic VPN

Use this checklist and documentation template as you complete the lab steps in the console or CLI.

Action checklist
  1. Create VGW (accept default ASN).
  2. Attach VGW to vpc-0123456789abcdef0; confirm attached state.
  3. Create VPN Connection named MyHybridConn-VPC1 using dynamic BGP.
  4. Download configuration file and apply parameters to your device.
Validation
  • Both tunnels show as up.
  • BGP sessions are established and prefixes learned in AWS when using dynamic routing.
  • PSKs and inside tunnel IPs match between AWS file and device config.
Documentation template
# AWS VGW and VPN Connection Setup

1. Create Virtual Private Gateway
- Console Path: VPC -> Virtual Private Gateways -> Create Virtual Private Gateway
- ASN: Default Amazon ASN
- VGW ID: [record generated VGW ID]

2. Attach VGW to VPC
- Target VPC ID: vpc-0123456789abcdef0
- Expected status: attached

3. Create VPN Connection
- Name Tag: MyHybridConn-VPC1
- Target Gateway: [VGW ID]
- Customer Gateway: cgw-0fedcba9876543210
- Routing Options: Dynamic (BGP)

4. Download Configuration File
- Console: Select VPN Connection -> Actions -> Download Configuration -> Vendor: Generic
