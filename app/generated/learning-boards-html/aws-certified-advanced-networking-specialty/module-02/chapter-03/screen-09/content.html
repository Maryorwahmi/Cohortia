Tunnel Options

IPsec Parameters to match

IKE version
IKEv1 or IKEv2 — choose based on device support.
Pre‑shared key
AWS generates unique PSKs per tunnel or you can specify your own; keep them secure.
Diffie‑Hellman group
Select compatible DH groups for key exchange strength.
Encryption & Hash
AES‑128/256 and SHA1/SHA256 are common choices; prefer the strongest mutually supported algorithms.
Why this matters
A mismatch in any of these parameters between AWS and your device will prevent the IPsec tunnels from establishing, creating a prolonged outage if not caught early.
Check before applying
  • Compare Phase 1 and Phase 2 parameters from the AWS config file with your device.
  • Use the strongest algorithms both ends support.
  • Test changes in a non‑production environment first.
Common mistake
Failing to update the device to match AWS defaults or custom tunnel options is a frequent root cause of failed tunnels.
