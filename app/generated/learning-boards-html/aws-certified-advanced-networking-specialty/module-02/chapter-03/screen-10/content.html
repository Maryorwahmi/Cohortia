Module 2 › Chapter 2.3 › Redundant Tunnels
Availability

Two IPsec tunnels per connection

Each VPN connection includes two independently provisioned tunnels. Each tunnel has a unique AWS public IP and a unique pre‑shared key. This redundancy improves resilience by providing an alternate path if one tunnel fails.

With BGP, failover is automatic because BGP withdraws routes for the failed tunnel. With static routing, manual intervention or device policies are required to move traffic to the healthy tunnel.

Do not assume automatic load balancing across the two tunnels unless you explicitly configure BGP or device side policies that support multipath behavior.

Troubleshooting checklist
  • Collect both AWS VGW public IPs and PSKs from the config file.
  • Test tunnel establishment one at a time to isolate issues.
  • If BGP is used, verify BGP sessions and route advertisements.
Misconception
Two tunnels provide high availability but not automatic traffic splitting unless you configure routing to do so.
