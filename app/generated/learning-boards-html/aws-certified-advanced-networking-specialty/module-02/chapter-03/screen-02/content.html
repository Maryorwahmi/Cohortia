Learning Objectives

Learn, understand, apply, and verify VGW and VPN setup steps.

Learn → Understand → Apply → Master
01
Explain VGW function

Describe how a VGW serves as the VPN concentrator for a VPC, its regional scope, and attachment constraints.

VERIFIED COMPETENCY MILESTONE
02
Create and attach a VGW

Walk through creation details including ASN choice and the attach action that makes the VGW active for VPNs.

VERIFIED COMPETENCY MILESTONE
03
Configure VPN Connection

Select the Customer Gateway and choose routing: static for manual CIDR entries or dynamic with BGP for automatic propagation.

VERIFIED COMPETENCY MILESTONE
04
Understand redundancy & config files

Recognize the two IPsec tunnels AWS creates, their purpose in high availability, and how to retrieve vendor configuration files.

VERIFIED COMPETENCY MILESTONE
