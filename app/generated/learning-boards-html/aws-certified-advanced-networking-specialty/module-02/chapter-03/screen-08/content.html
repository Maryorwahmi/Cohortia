Module 2 › Chapter 2.3 › Static vs Dynamic
Static Routing

Manual CIDR configuration

  • You manually add on‑premises CIDR blocks (for example 10.0.0.0/16) to the VPN connection.
  • Useful for devices without BGP or small stable networks.
  • Failover is manual unless your device handles path selection automatically.
Dynamic Routing (BGP)

Automatic route exchange

  • BGP advertises routes between the Customer Gateway and the VGW.
  • Automatic failover: BGP withdraws routes when a tunnel fails so traffic moves to the healthy tunnel.
  • Requires the Customer Gateway to have a valid BGP ASN recorded.
Comparison example
If your data center uses 10.0.0.0/16 and you choose static routing, add that CIDR to the VPN configuration so AWS routes it to the tunnel. If you choose BGP, the on‑premises router advertises 10.0.0.0/16 and AWS learns it automatically.
