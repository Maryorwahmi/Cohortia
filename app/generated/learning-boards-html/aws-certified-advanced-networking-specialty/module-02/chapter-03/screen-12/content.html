Common setup mistakes

  • Forgetting to attach the VGW — creation alone is not enough.
  • Choosing static routing but failing to add on‑premises CIDRs, leaving routes missing.
  • Mismatched tunnel options such as IKE version, DH group, or cipher/hash settings.
  • Not downloading and using the AWS configuration file for accurate device configuration.
Safety notes
Keep PSKs secure, test changes in staging before production, and be careful with route table updates that may affect live traffic.
Quick checklist
  1. Create VGW and attach to target VPC.
  2. Create CGW with correct public IP and ASN.
  3. Create VPN connection choosing the right routing option.
  4. Download and apply the AWS configuration file to your device.
