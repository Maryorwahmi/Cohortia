Module 2 › Chapter 2.3 › Key Concepts
Virtual Private Gateway (VGW)
AWS-managed VPN endpoint attached to a single VPC; it concentrates VPN tunnels for that VPC.
VGW Attachment
Linking the VGW to a VPC makes it active; a VPC supports only one attached VGW at a time.
VPN Connection
Defines the IPsec tunnels and routing between the VGW and the Customer Gateway.
Takeaway

Follow the create → attach → create VPN → download config sequence and verify tunnel and route states to ensure a reliable Site‑to‑Site VPN.
