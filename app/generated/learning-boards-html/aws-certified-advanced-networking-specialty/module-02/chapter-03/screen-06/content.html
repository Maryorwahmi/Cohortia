Module 2 › Chapter 2.3 › Customer Gateway
Definition

Customer Gateway (CGW)

A record in AWS that represents your on‑premises VPN device: it holds the device's public IP and, if using BGP, the ASN for peering.

What it stores
Public IP and BGP ASN used by AWS to provision tunnels and BGP sessions.
What it does not do
It does not configure your physical device — you must apply the settings to the device using the AWS config file.
CLI example
# Create a Customer Gateway (example)
aws ec2 create-customer-gateway --type ipsec.1 --public-ip 203.0.113.10 --bgp-asn 65001 --tag-specifications 'ResourceType=customer-gateway,Tags=[{Key=Name,Value=MyOnPremCGW}]'

# Note: record the CustomerGatewayId for use when creating the VPN
Misconception
Creating the CGW does not push configuration to your device. It simply registers the peer details in AWS for tunnel provisioning.
