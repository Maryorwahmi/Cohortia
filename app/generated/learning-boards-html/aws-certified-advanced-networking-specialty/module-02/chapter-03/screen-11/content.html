Module 2 › Chapter 2.3 › Download Configuration
What to download

AWS-generated VPN configuration

The file provides vendor-specific snippets and the exact parameters required to configure your on‑premises VPN device for each of the two tunnels.

Key fields
AWS public IPs, PSKs, inside tunnel IPs, Phase 1/2 parameters, and sample BGP/static configuration.
Where to download
Select the VPN connection in the console and choose Download Configuration; select Generic if your vendor is not listed.
CLI example
# Identify supported device types
aws ec2 get-vpn-connection-device-types --vpn-connection-id vpn-0123456789abcdef0

# Download a sample configuration for the selected device type
aws ec2 get-vpn-connection-device-sample-configuration \
    --vpn-connection-id vpn-0123456789abcdef0 \
    --vpn-connection-device-type-id vpn-connection-device-type-0123456789abcdef0 \
    --output text > MyOnPremVPNConfig.txt
Practical tip
Open the file and copy the AWS public IPs, inside IPs, and PSKs into your device configuration; then validate each tunnel separately before enabling BGP or traffic flows.
