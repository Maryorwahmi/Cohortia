Process

Create Site‑to‑Site VPN Connection

Define the name, target VGW, Customer Gateway, routing type, and optional tunnel options to match your on‑premises device.

Name Tag
Use a descriptive name like MyHybridConn-VPC1 to keep resources clear in the console.
Target & Customer Gateway
Select the attached VGW and the CGW resource representing the on‑premises peer.
CLI Example
# Create the VPN Connection with dynamic BGP
aws ec2 create-vpn-connection \
    --type ipsec.1 \
    --customer-gateway-id cgw-0fedcba9876543210 \
    --vpn-gateway-id vgw-0abcdef1234567890 \
    --options '{"StaticRoutesOnly":false}' \
    --tag-specifications 'ResourceType=vpn-connection,Tags=[{Key=Name,Value=MyHybridVPN}]'

# For static routing, set StaticRoutesOnly to true and add routes
Routing decision
Choose dynamic BGP for automatic route propagation and failover; static when your device lacks BGP support or you require manual control.
