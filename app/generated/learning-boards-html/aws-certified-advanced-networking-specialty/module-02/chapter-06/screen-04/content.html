Module 3 › Chapter 2.6 › Primary Use Cases
Core Concept

Situations that favor Site-to-Site VPN

Quickly establish encrypted connectivity for scenarios where dedicated private circuits are unnecessary or impractical.

Development & Testing
Example: dev teams need secure access to cloud resources during feature testing without a long procurement cycle.
Disaster Recovery (Backup)
Example: replicate backups to AWS or spin up a recovery site; VPN acts as a cost-effective replication path or fallback.
Small Branch Offices & Temporary Links
Example: branch offices or short-term migrations where dedicated circuits are not justified.
Supporting Details
  • VPN is encrypted by default and leverages your existing internet link.
  • Typical throughput per tunnel is limited; aggregate multiple tunnels for higher bandwidth.
  • Deployment is fast—minutes to hours—compared to dedicated circuits.
  • Best practice: use VPN as a backup to Direct Connect for critical workloads.
Example
A dev team sets up a VPN to access test databases in a VPC while the production Direct Connect is reserved for the live database.
Key Takeaway
Use VPN for fast, encrypted connectivity when performance needs are moderate or as a backup to dedicated links.
