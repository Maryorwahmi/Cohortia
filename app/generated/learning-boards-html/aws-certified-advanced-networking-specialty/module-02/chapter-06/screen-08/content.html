Cost Considerations

Primary cost drivers

  • VPN Connection Hour: hourly charge for each active VPN connection.
  • Data Transfer Out: charges for data leaving AWS over the VPN; monitor closely.
  • Inbound data to AWS over VPN is generally free.
Monitoring & Example
Use CloudWatch TunnelDataOut to identify high-traffic flows; if a single VPN shows sustained high DTO, model Direct Connect costs versus VPN DTO charges.
Optimization Tips
Monitor Data
Track TunnelDataOut and identify high-cost flows.
Consolidate Traffic
Use Transit Gateway to centralize VPNs and reduce per-connection overhead.
Evaluate Direct Connect
If DTO is consistently high, Direct Connect can be more economical despite higher fixed costs.
Disable Unused VPNs
Delete inactive connections to stop hourly charges.
Key Takeaway
Small hourly costs can compound; monitor DTO and consolidate or upgrade when volume justifies it.
