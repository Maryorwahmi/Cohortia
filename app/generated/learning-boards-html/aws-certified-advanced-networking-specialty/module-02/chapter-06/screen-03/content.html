Operational Objectives

Skills for routing, cost control, and safe operations.

01
Understand VPN Costs
Know the hourly VPN connection charge and Data Transfer Out implications; monitor with CloudWatch.
VERIFIED COMPETENCY MILESTONE
02
Consolidate with Transit Gateway
Centralize many VPNs to simplify routing and reduce per-connection overhead where appropriate.
VERIFIED COMPETENCY MILESTONE
03
Configure BGP for Failover
Use BGP with the built-in dual tunnels so route changes happen automatically when a tunnel fails.
VERIFIED COMPETENCY MILESTONE
04
Operational Controls
Apply change management, test in staging, and avoid overlapping IP address ranges to prevent outages.
VERIFIED COMPETENCY MILESTONE
Tip: practice reviewing CloudWatch TunnelDataOut metrics during a troubleshooting drill to develop cost-aware responses.
