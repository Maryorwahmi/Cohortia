BGP enables automatic route failover

With BGP, AWS and your on-premises router exchange routes. If a tunnel fails, BGP withdraws routes so traffic moves to the remaining path without manual intervention.

  • Automatic withdrawal and re-advertisement of routes on failure.
  • Use BGP attributes to prefer Direct Connect under normal operation.
  • Combine BGP with dual tunnels, multiple CGWs, and diverse ISPs for full resilience.
Example Route Behavior
# Conceptual BGP flow
# Primary tunnel: preferred
advertise 172.31.0.0/16 via tunnel-0

# If tunnel-0 fails
withdraw 172.31.0.0/16
# Secondary tunnel now carries the route
advertise 172.31.0.0/16 via tunnel-1
Key Takeaway
BGP plus dual tunnels gives automatic route switching; static routes lack that agility and slow recovery.
