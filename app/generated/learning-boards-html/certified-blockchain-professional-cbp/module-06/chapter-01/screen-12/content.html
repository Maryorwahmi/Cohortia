Conceptual interface for supply and borrow

Below is a conceptual interface to illustrate the on-chain calls used by a lending pool. This is for understanding only, not for deployment.

interface ILendingPool {
  function supply(address asset, uint256 amount, address onBehalfOf, uint16 referralCode) external;

Misconception

The frontend initiates but does not enforce rules. The contract executes and enforces invariant checks and state changes.

Checklist for inspection
  • Parameter validation and limits.
  • Reentrancy and access controls.
  • Interest calculation and liquidation paths.
Key Takeaway

Read interfaces and imagine the state change each call produces. That mental model prevents many mistakes.
