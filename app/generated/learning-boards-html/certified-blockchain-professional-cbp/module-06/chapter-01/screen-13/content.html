Module 06 › Chapter 6.1 › Key Concepts
Decentralized Finance (DeFi)
Financial applications built on smart contracts that remove centralized intermediaries.
Decentralized Exchange (DEX)
An exchange that lets users trade directly on-chain without a custodian holding funds.
Automated Market Maker (AMM)
A pricing protocol using liquidity pools and formulas to enable trades without an order book.
Summary

Understand these core primitives and ask how each design choice affects user risk, liquidity, and access.
