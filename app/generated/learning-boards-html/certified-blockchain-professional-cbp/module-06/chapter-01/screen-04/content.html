Module 06 › Chapter 6.1 › What is DeFi?
Core Concept

Definition and promise

DeFi moves custody and execution into smart contracts, enabling open access and composable services without traditional intermediaries.

Quick bullets
  • Smart contracts enforce rules, not a single company.
  • Public blockchains provide transparency of state and flows.
  • Composability lets protocols be combined like Lego.
Analogy

Think of protocols as vending machines: code determines outcomes and users interact directly, but the machine can still be broken or misconfigured.

Key Takeaway

DeFi's value is open composability and direct programmatic control of assets, but code and economic risks still need active management.

Definition

DeFi as operational code

Concrete example

Supply crypto to a lending pool, earn interest automatically, and allow others to borrow against that pooled collateral via smart contract logic.

Common misconception

Decentralized does not imply risk-free. Public code can still have bugs, and open markets still face liquidity and oracle risks.
