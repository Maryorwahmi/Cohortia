Core Concept

Non-Fungible Token (NFT)

A unique token with a tokenId and metadata that together create verifiable ownership and scarcity.

Properties
  • Unique identifier (tokenId)
  • Metadata or URI that describes the item
  • On-chain transfer history for provenance
Common misconception

Owning an NFT does not automatically transfer all intellectual property rights unless explicitly specified in the contract or sale terms.

Concrete example

A single ERC-721 token minted for a generative art piece has one tokenId. ownerOf(tokenId) on the contract returns the wallet that owns that token.

Visual card

Key Takeaway

An NFT is a tokenized certificate that proves ownership and records history for one specific item.
