Fungible vs Non-Fungible

Use the cash versus painting metaphor to anchor the difference in interchangeability.

Fungible (example: crypto)
  • Units are identical and exchangeable
  • Good for currencies and divisible tokens
Non-Fungible (example: NFT)
  • Each token is unique (tokenId + metadata)
  • Used for collectibles, land, tickets, and items
Practical example
ERC-20 transfer moves fungible units between addresses; ERC-721 transferFrom moves a specific tokenId. Use ownerOf(tokenId) to find the owner of that unique item.
Common mistake: Treating NFTs as simple file links. Ownership is about the token record, not a hosted JPEG copy.
Pro tip: Design UX to show what rights a token grants — viewing vs copyright vs transferability.
Key Takeaway

Fungibility affects transfer semantics, economics, and UX design choices.
