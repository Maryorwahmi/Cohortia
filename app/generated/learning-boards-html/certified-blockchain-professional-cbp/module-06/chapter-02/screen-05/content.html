Module 6 › Chapter 6.2 › Blockchain Properties That Matter
Core properties
Immutability
Once recorded, a product event cannot be altered. This secures an audit trail for recalls and compliance.
Transparency
Authorized parties see the same records, reducing disputes over what happened and when.
Decentralization (permissioned)
Control is distributed among participants, removing single points of failure while preserving access rules.
Concrete example
An IoT sensor appends temperature hashes every ten minutes. If a recall is needed, elapsed records prove whether a batch saw out-of-range conditions and who handled it.
Misconception
Immutability does not guarantee truth of input. It guarantees the record cannot change after it is written; you must secure the input process.
Key Takeaway

Match each blockchain property to the operational problem it solves: immutability for audit, transparency for dispute reduction, decentralization for shared control.
