Step-by-step
  1. Create genesis block to anchor the chain.
  2. Add Manufactured event: batch, certificate hash, timestamp.
  3. Add Shipped event: carrier, signed handoff, previous_hash.
  4. Add Received event: receiver confirmation, condition data.
  5. Print chain and run validate to confirm integrity.
Extension
Aggregate sensor readings to hourly digests and store full logs off-chain for detailed audits.
Concrete scenario
Simulate MED_BATCH_X123 moving from factory to pharmacy and validate that any tampering is detected by the validate_chain routine.
Key Takeaway

Hands-on validation reinforces that chained hashes detect unauthorized changes and clarifies trade-offs in schema and storage design.
