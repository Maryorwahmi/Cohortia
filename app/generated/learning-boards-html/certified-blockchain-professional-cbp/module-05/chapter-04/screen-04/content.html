Module 5 › Chapter 5.4 › L1 Limits
What limits Layer 1?
Every node validates every transaction; blocks are finite. This gives strong security but constrains TPS and raises fees under load.
Blockchain Trilemma
You can favor two: decentralization, security, or scalability. Full decentralization and security limit raw scalability.
Common mistake

Expecting hardware increases alone to deliver orders of magnitude more TPS while keeping the same decentralization is unrealistic.

Key Takeaway

Layer 1 is best as a settlement layer; high-volume execution is more efficient off-chain.

Concrete example
During periods of heavy demand, such as popular mint drops, gas prices spike because every user competes for limited block space; throughput is fixed by protocol rules and consensus latency.
Why this matters
Designing for user experience requires considering latency and fees; Layer 1 constraints push architects to Layer 2 solutions.
