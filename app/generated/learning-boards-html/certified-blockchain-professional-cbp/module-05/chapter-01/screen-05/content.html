Module 5 › Chapter 5.1 › Cryptographic Hashing
Core concept

One-way fingerprints

A hash converts data into a fixed-size digest. It is deterministic, collision-resistant, and one-way, so it is ideal for integrity checks.

Pseudocode example
block_content = transactions + previous_hash
block_hash = HASH(block_content)
# HASH is deterministic and one-way; altering transactions changes block_hash
Property
Collision resistance prevents easy hash collisions.
Misconception
Hashing is not encryption; it does not keep the original data secret.
Where hashing is used
  • Block headers to link blocks
  • Merkle roots to summarise many transactions
  • Proof-of-work puzzles that depend on hash output
Example in practice
Many PoW chains use SHA-256 to create block hashes. The hash is used as a compact integrity check and, in PoW, as a difficulty target for mining.
