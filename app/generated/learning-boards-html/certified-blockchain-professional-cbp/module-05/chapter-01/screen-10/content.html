Network attacks

DDoS can reduce node availability. Decentralization raises resilience but very large attacks can still affect performance.

Example
A coordinated flood targeting many public nodes can delay block propagation and confirmations.
Detection
Monitor node latency, peer counts, and unusual traffic patterns to detect possible DDoS activity.

User-level threats

  • Phishing that steals private keys or seeds
  • Malicious wallet software requesting approvals
  • Social-engineering asking users to sign unintended transactions
Practical safeguards
Use hardware wallets, verify transaction details on the device, keep seed phrases offline, and educate users to never share private keys.
Key takeaway
Protocol security reduces some risks, but user and endpoint security are essential to prevent theft and fraud.
