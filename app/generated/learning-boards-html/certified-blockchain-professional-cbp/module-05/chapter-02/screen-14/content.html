Key Concepts

Three concise reminders to guide code review and design.

Reentrancy
Order checks, update state, then interact to avoid recursive exploits.
Arithmetic
Check numeric bounds; use language checks or safe libraries to prevent wrapping.
Access Control
Protect initialization and admin paths; prefer multisig and timelocks for high-value actions.
Summary

Use repeatable patterns, tests, and audits to reduce risk; when in doubt, assume attackers will read your code.
