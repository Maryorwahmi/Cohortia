Module 6 › Chapter 5.5 › Lock-and-Mint Flow
Steps
1. Approve
Allow bridge contract to spend the token on the source chain.
2. Deposit / Lock
Tokens are locked in the bridge contract; this emits an event observed by relayers.
3. Relayer Verification
Relayers submit proofs to the destination chain to trigger minting.
4. Mint Wrapped Token
Wrapped tokens are minted to the user on the destination chain.
Visualized actors
Source Chain
User approves and deposits to Bridge Contract; assets are locked.
→
Relayers / Validators
Observe events, verify proofs, and relay messages across chains.
→
Destination Chain
Wrapped token contract mints equivalent tokens for the user.
Example
User locks 100 MyToken on Ethereum; WrappedMyToken is minted on TargetChain.
Misconception
Wrapped tokens retain value only as long as the bridge’s custody and verification model holds.
