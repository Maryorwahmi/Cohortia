Module 6 › Chapter 5.5 › IBC & XCMP
Inter-Blockchain Communication (IBC)
Secure packet transfer using light clients and relayers; chains verify each other's state commitments.
Guarantee
Authenticated, verifiable messages without introducing custody relationships.
Scope
Sovereign chains that adopt the IBC protocol.
Cross-Chain Message Passing (XCMP)
Polkadot’s message routing between parachains, leveraging the Relay Chain for shared security and routing guarantees.
Guarantee
Parachains send messages with the Relay Chain ensuring proper routing and shared security assumptions.
Scope
Best used within Polkadot’s integrated architecture.
Design note
Choose protocol-level interoperability when your chains are part of an ecosystem that supports it. It simplifies trust assumptions and provides verifiable message semantics compared to bespoke bridges.
