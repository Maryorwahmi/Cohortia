Wrapped Asset Lifecycle
Lock → Mint
Original asset locked on source chain; wrapped token minted on destination chain.
Use and Transfer
Wrapped token functions in destination ecosystem for liquidity or DeFi operations.
Burn → Unlock
Wrapped token burned; proof triggers unlocking of original asset on the source chain.
Concrete example
User locks 100 MyToken on Ethereum; WrappedMyToken appears on TargetChain and can be traded in TargetChain DApps. When burned, MyToken is unlocked back on Ethereum.
Risk reminder
If validators are compromised, wrapped tokens may be minted fraudulently or originals may be locked indefinitely.
Best practice
Prefer bridges with clear dispute windows, multisig backups, and audited contract code for wrapped asset flows.
