Module 5 › Chapter 5.3 › The Blockchain Trilemma
Definition
Decentralization, security, and scalability form a trade-off triangle. Below are compact definitions and a guiding example.
Decentralization: many independent validators, resilient to control.
Security: strong cryptography and consensus make ledger tampering costly.
Scalability: high transaction throughput and low latency under load.
Concrete example
Increasing block size raises TPS but makes it harder for ordinary nodes to store and propagate blocks. That can concentrate validation into fewer, resource-rich nodes, reducing decentralization.
Misconception
There is no silver bullet that increases scalability without changing security or decentralization assumptions. New mechanisms must specify which assumptions change.
Key Takeaway

Use the trilemma to ask precise questions about which properties an application needs and which trade-offs are acceptable.
