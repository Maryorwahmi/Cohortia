Module 5 › Chapter 5.3 › Block Size & Time
What changes do
Increasing block size or reducing block time raises TPS but affects node resource needs.
Effect: Higher TPS and larger chain growth rate.
Cost: More bandwidth, storage, and faster validation hardware needed.
Risk: Potential centralization of validators and miners.
Example & takeaway
Example: Forks that increase block size may temporarily improve throughput but can reduce the pool of users willing to run full nodes due to higher costs. Takeaway: parameter changes are trade-offs that alter decentralization economics.
Key Takeaway

Always model node participation and hardware costs when proposing block-size or block-time changes.
