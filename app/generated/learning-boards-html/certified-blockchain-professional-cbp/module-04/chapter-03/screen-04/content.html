Module 4 › Chapter 4.3 › What is a Layer 2?
Definition & purpose
Layer 2s increase transaction throughput and reduce per-transaction costs by moving execution or state transitions off the Layer 1 blockchain while using L1 for settlement.
Analogy
L1 is the highway; L2s are express lanes that clear congestion and speed traffic while periodically touching the highway for settlement.
Concrete example
A rollup groups 500 transfers into one L1 transaction. The single L1 commit updates all 500 balances with much lower aggregate gas than 500 separate L1 transactions.
Key Takeaway

L2s trade execution locality for scale: they keep costs low and throughput high while relying on L1 settlement or bridges for finality or asset movement.

How L2s differ by data and security
Rollups
Post data or proofs to L1; derive L1 security.
Sidechains
Independent validators, connected via bridges; independent security.
State Channels
Off-chain exchanges between participants; only open/close on L1.
Common misconception: not all L2s inherit full L1 security automatically. Check whether transaction data or validity proofs are posted to L1 and whether the L2 uses its own validators or posts commitments back to the L1.
