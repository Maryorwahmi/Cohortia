Module 4 › Chapter 4.3 › Key Concepts
Layer 2 (L2) Scaling Solution
Protocols built on top of L1 to increase throughput and reduce costs while leveraging L1 for settlement.
Rollups
Execute off-chain, bundle transactions, and submit compressed data or validity proofs to L1 for settlement.
Sidechains & Channels
Sidechains run independent validators with bridges; state channels enable instant off-chain exchanges between participants with only open/close on L1.
Summary takeaway

Use the security, finality, cost, and compatibility lens to choose an L2: each option balances those factors differently, so match them to application needs.
