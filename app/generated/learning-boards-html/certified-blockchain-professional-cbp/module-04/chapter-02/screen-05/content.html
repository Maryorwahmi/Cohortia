Proof of History (PoH)
A cryptographic clock that records an ordered sequence of events for fast verification.
How it works
  • PoH generates a verifiable hash chain that timestamps events.
  • Validators reference PoH to agree on ordering without heavy messaging.
  • Tower BFT finalizes blocks using PoH as an ordering input.
Concrete example
High-frequency trades are ordered by PoH so matching engines can process many parallel transactions while preserving a single canonical sequence.
Supporting features
Sealevel
Parallel smart contracts runtime for concurrent execution when state regions don't conflict.
Gulf Stream
Mempool-less transaction forwarding to speed leader scheduling and reduce latency.
Turbine
Efficient block propagation protocol to distribute data quickly across validators.
Common Mistake

Mistaking PoH for consensus; it assists ordering but works with Tower BFT to reach finality.
