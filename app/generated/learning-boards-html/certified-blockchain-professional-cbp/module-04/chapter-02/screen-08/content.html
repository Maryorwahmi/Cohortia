Designing a subnet
Choose validators, VM, tokenomics, and governance rules to match the application.
Enterprise example
A permissioned subnet for supply chain: validators are consortium members, privacy rules restrict data exposure, and governance enforces compliance checks.
Developer example
A public trading subnet optimized for low-latency matching and gas stability, with token incentives aligned to liquidity providers.
Considerations
  • Governance complexity and validator onboarding.
  • Interoperability needs versus isolation benefits.
  • Security model depends on validator set and staking rules.
Key Takeaway

Subnets are powerful for customizing consensus and governance, especially when enterprise control or tailored performance is required.
