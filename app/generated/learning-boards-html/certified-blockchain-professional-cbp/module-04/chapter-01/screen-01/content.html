Ethereum and the EVM

Learn how Ethereum represents global state with accounts, uses Gas as computation fuel, and runs smart contract bytecode inside the Ethereum Virtual Machine. These ideas are the foundation for building, deploying, and securing smart contracts.

Account Model Snapshot
EOA → Transaction → Contract Account → State change
EOA
Controlled by a private key. Initiates transactions and pays Gas.
Contract Account
Holds code and storage. Executes only when it receives a transaction.
A transaction consumes Gas; Gas used times Gas price equals the fee paid to the block proposer. The EVM executes the same bytecode on every node to keep outcomes deterministic.
