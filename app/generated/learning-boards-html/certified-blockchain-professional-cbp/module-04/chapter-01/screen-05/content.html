Module 04 › Chapter 4.1 › EOA vs Contract
Externally Owned Account (EOA)

Controlled by a private key. Signs transactions and pays Gas to trigger activity on the network.

Characteristics
Holds Ether, signs transactions, initiates contract interactions.
Misconception
An EOA is not the same as a user interface; the EOA secures signing and private key custody matters for security.
Key Takeaway

Protect private keys and treat EOAs as the source of authority that must be secured.

Contract Account

Holds code and storage. Runs its code only when it receives a transaction from an EOA or another contract.

Characteristics
Has an address, stores persistent state, and can make internal calls to other contracts during execution.
Practical note
Design contracts to validate inputs and guard against patterns like unchecked external calls to avoid vulnerabilities.
Reflection
Decide which operations should be triggered only by EOAs and where contracts should enforce their own invariants.
