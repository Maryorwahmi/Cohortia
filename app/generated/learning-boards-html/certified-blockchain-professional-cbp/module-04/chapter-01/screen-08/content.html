What the EVM provides

A deterministic, isolated, stack-based virtual machine that executes compiled bytecode identically on every node.

Stack
Short-lived operand storage used during instruction execution.
Memory
Transient workspace during a call; cleared after execution completes.
Storage
Persistent contract state that contributes to global state and costs more Gas to modify.
Misconception
The EVM cannot access external systems directly; use oracles for off-chain data and expect increased complexity and Gas costs for such interactions.
Why separation matters
Storage writes are expensive and persist across transactions. Memory and stack are cheaper and ephemeral. Optimising where you place data will reduce transaction costs and improve contract performance.
Design hint
Cache transient values in memory during execution and write to storage only when you need persistent state changes.
