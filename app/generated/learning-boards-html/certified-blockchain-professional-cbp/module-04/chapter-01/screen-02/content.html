Learning Objectives

A Bloom progression: Learn → Understand → Apply → Master
01
Explain Ethereum architecture
Describe the account-based state machine and why deterministic execution matters.
Venn: accounts + state + transactions
VERIFIED COMPETENCY MILESTONE
02
Differentiate account types
Identify EOAs vs Contract Accounts and how each is activated and controlled.
Mnemonic: initiator vs responder
VERIFIED COMPETENCY MILESTONE
03
Describe Gas mechanics
Explain Gas units, Gas limit, Gas price and how fees are computed and paid.
Timeline: estimate → set limit → pay
VERIFIED COMPETENCY MILESTONE
04
Understand the EVM
Recognize the EVM as an isolated, deterministic bytecode runtime used by every node.
Mnemonic: stack, memory, storage
VERIFIED COMPETENCY MILESTONE

More applied objectives

05
Estimate and set Gas
Practice choosing Gas limit and Gas price to balance cost and success probability.
VERIFIED COMPETENCY MILESTONE
06
Deploy and interact
Run a local Hardhat deployment and inspect transaction receipts and Gas used.
VERIFIED COMPETENCY MILESTONE
07
Optimize persistent storage
Learn why storing state variables costs more Gas than using transient memory and how to design accordingly.
VERIFIED COMPETENCY MILESTONE
08
Recognize finality and risks
Understand block confirmations as a guard against reorganizations and common contract vulnerabilities to audit for.
VERIFIED COMPETENCY MILESTONE
