Core Concept

Public & Private Keys

An address receives funds; a private key signs transactions to move them. The derivation from private to public is deterministic and one-way.

Analogy: Mailbox
Address = box number. Private key = key that opens the box. Anyone can drop mail; only the keyholder retrieves it.
Common misconception
Wallets hold coins. Reality: coins live on-chain; wallets manage keys that control them.
Key Takeaway

Possession of the private key equates to control. Keep it secret and offline when possible.

Definition & Example
Definition
Private key: secret random number that signs. Public key: derived from private key to verify signatures and derive addresses.
Concrete scenario
Alice shares her public address with Bob. Bob sends funds. If Alice loses her private key, she cannot sign to move funds, and recovery depends only on a backed-up mnemonic.
