Module 2 › Chapter 2.2 › What is a Wallet?

Wallet = Key Manager

Wallets create and store private keys, expose public addresses for receiving funds, and sign transactions when you instruct them to do so.

Software wallets
Run on phones, browsers, or desktops. Convenient and integrated with apps, but connected to the internet.
Hardware wallets
Isolate keys and require physical confirmation for signing, greatly reducing remote compromise risk.
Key Takeaway

Choose a wallet for what you need it to do: convenience for small funds, hardware or cold backup for larger holdings.

Hierarchy
HD wallets & mnemonic
A single mnemonic seed can deterministically generate many private keys and addresses, simplifying backup and account management.
Scenario
If you lose a wallet app but kept your mnemonic, you can restore all derived accounts on a new device; if you lose the mnemonic, you lose access permanently.
