Module 2 › Chapter 2.2 › Private Keys
Definition

Private Key Properties

Private keys must be unpredictable and kept secret because possession equals control. They are used to create cryptographic signatures that authorize transactions.

Randomness prevents guessing; real keys are large numbers with high entropy.
Secrecy is mandatory; sharing the key hands over full control.
Used to sign transactions so networks can verify intent without seeing your secret.
Key Takeaway

Treat private keys like physical keys to safe deposit boxes: keep them offline and secure.

Example & Mistake
Concrete example
If a private key is stored in a cloud text file and an attacker gains access, they can sign transactions and drain funds. Offline storage such as a hardware wallet separates the signing operation from the internet attack surface.
Common mistake
Treating passwords or single-factor backups as sufficient substitutes for cryptographic keys leads to theft or accidental loss.
