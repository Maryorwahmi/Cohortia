Learning Objectives

Progress from understanding key pairs to safely managing wallets and recovery phrases.

Bloom: Learn → Understand → Apply → Master
01
Relate public & private keys

Explain how a private key creates a public key and how the address is derived, and why only the private key must be secret.

Mnemonic: Venn — private controls access, public enables receipt
Verified Competency Milestone
02
Generate a conceptual key pair

Walk through a safe, illustrative generation of a private key and a deterministic derivation to a public key using conceptual code.

Mnemonic: Timeline — seed → key → address
Verified Competency Milestone
03
Differentiate wallet types

Compare hot and cold wallets, hardware and software options, and match them to use cases like frequent spending or long-term storage.

Mnemonic: Icons — speed vs safety
Verified Competency Milestone
04
Secure mnemonic and keys

Describe mnemonic phrases and implement best practices: offline backups, multiple physical copies, and hardware wallet usage for large holdings.

Mnemonic: Checklist — store offline, separate copies
Verified Competency Milestone
Each objective will be reinforced with a short exercise and a conceptual code sample where appropriate.
