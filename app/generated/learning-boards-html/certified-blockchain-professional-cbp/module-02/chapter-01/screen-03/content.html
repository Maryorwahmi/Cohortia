01 — See the avalanche effect
Run a SHA-256 hash on a transaction string, change a single character, and observe the hash change completely.
Try: change one character and compare hashes.

02 — Verify with Merkle proofs
Understand how combining transaction hashes in pairs produces a Merkle root used by block headers to prove inclusion efficiently.
Mnemonic: pairwise hashing builds a root.
VERIFIED COMPETENCY MILESTONE
03 — Private key safety
Practice storing keys offline, understand that loss equals loss of access, and that compromise allows theft of assets.
Mnemonic: key = identity; guard it like a physical key.
VERIFIED COMPETENCY MILESTONE
04 — Map primitives to outcomes
Be able to explain how hashing chains create tamper evidence, and how signatures authorize changes to ledger state.
Mnemonic: chain + seal = secure history.
