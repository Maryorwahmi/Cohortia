Module 2 › Chapter 2.1 › Cryptographic Hashing
Definition and key properties
  • Determinism: same input -> same output, enabling agreement across nodes.
  • Collision resistance: infeasible to find different inputs with the same digest.
  • Irreversibility: you cannot reconstruct original data from the hash alone.
Analogy: A fingerprint uniquely identifies an object but cannot recreate the person.
Common mistake: Hashing is not encryption—hashes do not provide confidentiality.

Key Takeaway

A hash is a compact integrity check: any change produces a new digest, so tampering becomes detectable across chained blocks.
