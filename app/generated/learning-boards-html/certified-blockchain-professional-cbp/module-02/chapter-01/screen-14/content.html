Module 2 › Chapter 2.1 › Key Concepts
Cryptographic Hashing
A one-way fingerprint function for data integrity and tamper detection.
SHA-256
A 256-bit hash algorithm used to produce stable digests for blockchain identifiers.
Merkle Tree
A binary tree of hashes enabling compact inclusion proofs without full block downloads.
Summary

Keep these core ideas ready: hashing for integrity, SHA-256 as the practical algorithm, and Merkle trees for proof efficiency.
