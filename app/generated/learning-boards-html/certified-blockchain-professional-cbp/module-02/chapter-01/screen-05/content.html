What SHA-256 gives you
  • Fixed 256-bit digest for any input size, making identifiers uniform.
  • Strong collision resistance for practical blockchain use.
  • Widely adopted in block headers and transaction identifiers.
Implementation note
Always hash a canonical representation. Differences in serialization change the digest and break consensus between peers.
Concrete example
Convert a transaction to a stable JSON string with sorted keys, encode to bytes, and run the SHA-256 algorithm to derive a transaction id used across nodes.
Example digest (hex): e3b0c44298fc1c149afbf4c8996fb92427ae41e4...
Key Takeaway

SHA-256 creates stable, fixed-size identifiers for data. Consistent encoding is essential to avoid mismatched hashes between peers.
