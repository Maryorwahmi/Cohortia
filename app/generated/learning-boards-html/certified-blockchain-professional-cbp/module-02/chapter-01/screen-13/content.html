Module 2 › Chapter 2.1 › Common Pitfalls
Hashing ≠ Encryption
Hashing verifies integrity; encryption hides content. Choose based on goal.
Private key handling
Never store unencrypted keys on internet-connected machines; backups must be as secure as the original key.
Serialization matters
Canonical formatting before hashing ensures different nodes compute the same digest for the same logical data.
Action checklist

Use canonical serialization, protect private keys offline, document algorithms, and test cross-client equivalence of hashes to avoid these common mistakes.
