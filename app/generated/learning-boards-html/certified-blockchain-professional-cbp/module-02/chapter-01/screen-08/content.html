Module 2 › Chapter 2.1 › Symmetric vs Asymmetric
Symmetric encryption
Uses a single shared secret key for both encryption and decryption. Efficient for large payloads but requires secure sharing of the key beforehand.
Example: encrypting a private off-chain backup file when both parties already share a secret.
Asymmetric encryption
Uses a public/private key pair. Anyone can encrypt to your public key but only you can decrypt with your private key. Solves the key-exchange problem for parties that don't share a secret.
Example: sending a confidential message to someone using their public key without meeting beforehand.
Common mistake

Do not assume encryption equals authentication. Encryption provides confidentiality; signatures provide proof of origin and integrity.
