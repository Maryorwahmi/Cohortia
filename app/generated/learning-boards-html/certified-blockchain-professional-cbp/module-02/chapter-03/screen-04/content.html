Core Concept

Why consensus is required

Without a shared rule for choosing a single history, a distributed ledger fragments and users lose confidence in recorded transactions.

Definition
A protocol that ensures all honest nodes agree on one sequence of blocks despite conflicting inputs.
Concrete example
If Alice tries to send the same coin twice, consensus decides which transaction becomes part of the canonical chain and which is rejected.
Common misconception
Cryptographic signatures prove integrity but do not resolve conflicting blocks; consensus resolves conflicts.
Key Takeaway

Consensus is essential to guarantee a single, tamper-resistant ledger so the network can function as a trustworthy record.

Analogy: Coordinated decision-making
Think of consensus like a rule that makes all participants adopt the same plan, even if some participants lie or messages are delayed.
Why it matters
Prevents double-spend, ensures predictable state for smart contracts, and supports trustless interactions.

Real-world connection
Financial systems require a single ledger so balances are unambiguous; consensus provides the same guarantee for blockchains.
