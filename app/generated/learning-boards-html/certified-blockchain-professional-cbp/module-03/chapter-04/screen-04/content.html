Module 4 › Chapter 3.4 › Web3.js vs Ethers.js
Comparison
API & Ergonomics
Ethers.js uses promise-first patterns and a compact API suitable for modern frontends.
Bundle Size
Ethers.js commonly yields smaller production bundles than Web3.js, which can matter for web performance.
Maturity & Features
Web3.js has a long history and broad examples, but both libraries support providers, signers, and events.
Concrete example (Ethers.js)
// Create a provider and signer with Ethers.js
import { ethers } from "ethers";
const provider = new ethers.BrowserProvider(window.ethereum);
const signer = await provider.getSigner();
const contract = new ethers.Contract(contractAddress, contractABI, signer);
This pattern is idiomatic in Ethers.js: provider for reads, signer for transactions.
Misconception
Bundle choice alone doesn't prevent runtime errors; you still need correct ABI and address, and the right signer or provider at call time.
