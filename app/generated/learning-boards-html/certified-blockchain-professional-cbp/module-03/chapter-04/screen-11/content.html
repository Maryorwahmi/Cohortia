Module 4 › Chapter 3.4 › Common Mistakes
Checklist
  • Confirm contract address and ABI match deployment.
  • Await asynchronous calls and show loading state.
  • Use a signer for transactions; provider for reads.
  • Catch errors and display friendly messages for wallet rejections or reverts.
Debugging tips
Log the contract address, ABI length, and network chain ID before calling. Inspect transaction receipts and revert reasons. Reproduce steps in a controlled environment like Remix's JavaScript VM to confirm contract logic.
If you see unexpected revert errors, verify function inputs and contract require statements rather than changing gas blindly.
