Transaction example
try {
  const tx = await contract.set(123); // signer-bound contract
  // Inform the user: transaction submitted
  const receipt = await tx.wait(); // wait for mining
  // Refresh read state or respond to event
} catch (error) {
  // Handle user rejection, revert, or gas error
}
Always present a clear pending/confirmed UI and catch errors from the wallet or node. Use receipt.status to check final success where applicable.
Gas & estimation
Libraries estimate gas, but complex contracts or interactions with other contracts can lead to underestimation. If a transaction keeps failing, examine require statements in the contract, check provided parameters, and consider manual gas limits as a last resort.
Common error
Using a provider-bound contract to send a transaction results in an error because the provider cannot sign the transaction for the user's account.
