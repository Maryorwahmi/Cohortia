Module 4 › Chapter 3.4 › Providers: MetaMask vs Hosted
Architecture Overview
MetaMask (Wallet)
Holds private keys in the browser and signs transactions for the user. Best for interactive, signed actions.
Infura / Alchemy (Hosted Node)
Provides a stable RPC endpoint for read-only calls, indexing, or server-side workflows without user keys.
Decision guide
  • •Use MetaMask when the user must approve and sign a transaction.
  • •Use Infura/Alchemy for background reads, indexing, and server-side event handling.
  • •Do not rely on hosted nodes for user signing; they cannot access private keys.
Example
A dashboard can use Infura to gather totals, while a button in the UI triggers MetaMask for a user-specific transfer.
