Module 4 › Chapter 3.4 › Instantiate Contract
What you need
  • Contract Address — the unique on-chain location, e.g., 0x... copied from deployment.
  • ABI — JSON array output from the Solidity compiler describing functions and events.
  • Provider or Signer — provider for reads, signer for transactions.
Check
After creating the instance, call a simple read-only function to verify instantiation succeeded.
Ethers.js example
import { ethers } from "ethers";
const provider = new ethers.BrowserProvider(window.ethereum);
const signer = await provider.getSigner();
const contractAddress = "0x..."; // deployed address
const contractABI = [ /* ABI array */ ];
const contract = new ethers.Contract(contractAddress, contractABI, signer);
const readOnly = new ethers.Contract(contractAddress, contractABI, provider);
Remember to use the signer-connected instance for state changes and the provider-connected instance for view calls.
