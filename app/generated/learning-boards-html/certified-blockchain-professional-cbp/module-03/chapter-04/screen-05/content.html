Module 4 › Chapter 3.4 › Providers & MetaMask
Connection Steps
  1. 1Detect window.ethereum and confirm a provider is available.
  2. 2Request accounts using eth_requestAccounts so the user can approve access.
  3. 3Create a provider instance in your library and call getSigner when you need to sign transactions.
  4. 4Listen for accountsChanged and chainChanged and reinitialize contract objects to avoid stale state.
Pro tip
Show connection status and a short account summary to reduce user confusion when MetaMask prompts appear.
Code example (Ethers.js)
// Connect to MetaMask and get a signer
import { ethers } from "ethers";
if (typeof window.ethereum !== 'undefined') {
  const provider = new ethers.BrowserProvider(window.ethereum);
  await provider.send('eth_requestAccounts', []);
  const signer = await provider.getSigner();
}
Common mistake
Calling contract methods that change state with a provider but without a signer causes an error saying the transaction requires a signer.
Why it matters
Proper account handling prevents painful UX around transaction failures and missing confirmations.
