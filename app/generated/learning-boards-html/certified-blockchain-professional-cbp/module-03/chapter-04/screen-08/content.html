Module 4 › Chapter 3.4 › Calling view Functions
Read pattern
// Provider-bound contract for read-only
const readOnlyContract = new ethers.Contract(contractAddress, contractABI, provider);
const value = await readOnlyContract.getCount();
console.log('Count:', value.toString());
Handle return types and errors: convert BigNumber to string before display, and wrap calls in try/catch to show friendly messages if the node is unreachable.
Example
Call getCount on a deployed Counter contract and display the numeric string in the UI.
UI tips
  • Show a loading state while awaiting the view result.
  • Convert numeric returns safely for display with toString().
  • Use events or short polling to keep the UI in sync after transactions.
Common mistake
Forgetting await returns a Promise object, which often leads to wrong UI output like [object Promise].
