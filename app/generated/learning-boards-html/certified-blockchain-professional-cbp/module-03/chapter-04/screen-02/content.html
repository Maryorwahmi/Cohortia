Learning Objectives

Four verified competencies to guide your practice.

01
Describe Web3.js and Ethers.js

Explain how these libraries encode calls, decode responses, and provide helpers for providers, signers, and events. This knowledge helps you choose the right tool for your DApp.

VERIFIED COMPETENCY MILESTONE
02
Configure a Provider

Set up MetaMask for browser use or connect to Infura/Alchemy for server-side access. Practice requesting accounts and handling account changes so your DApp stays reliable.

VERIFIED COMPETENCY MILESTONE
03
Instantiate Contract with Address + ABI

Use the contract address and ABI to build a typed contract object in JavaScript that you can call for both read-only and state-changing operations.

VERIFIED COMPETENCY MILESTONE
04
Differentiate Calls vs Transactions

Recognize when to use a read-only call with a provider and when to use a signer for a transaction that consumes gas. This prevents common runtime errors in your DApp.

VERIFIED COMPETENCY MILESTONE
