On-chain vs Off-chain decisions

When to choose on-chain
  • Actions requiring verifiable settlement (token transfers, trades)
  • Governance votes where immutability matters
  • Critical state whose tamper-proof history must be public
Example: token swap settlement and liquidity accounting belong on-chain to prevent fraud and ensure correctness.
When to choose off-chain
  • Large media files and bulky datasets
  • Compute-heavy processing and real-time indexing
  • UX features that need low latency
Example: store artwork on IPFS and record only its content hash on-chain to link file and token ownership.
Pro tip

Plan upgrade and governance strategies before deployment to handle immutable bugs and evolving requirements.
