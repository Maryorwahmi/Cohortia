Definition What is a DApp?

Working definition

An application that runs backend logic on a decentralized peer-to-peer network, using smart contracts and often decentralized storage, rather than relying on a single centralized server.

Concrete example
A decentralized exchange executes swaps via smart contracts on-chain; no central matching engine controls trades.
Common misconception
Not every part of a DApp must be on-chain; UIs and large media files are typically off-chain for performance and cost reasons.
Key Takeaway

DApps shift trust from an operator to verifiable code and a distributed ledger, while still using familiar frontends for user interaction.

Contrast: Centralized App vs DApp
Centralized App
  • Backend hosted on company servers
  • Company controls policy and data
  • Single point of failure
DApp
  • Backend logic in smart contracts
  • State replicated on many nodes
  • Harder to censor or alter rules
