Definition

Decentralized storage in DApps

Use IPFS or Arweave to host large files and store only a content identifier or hash on-chain. This preserves integrity and links off-chain data to the ledger.
Concrete example
An NFT stores its artwork on IPFS and saves the IPFS hash in the token metadata; ownership changes occur on-chain, while the file is retrieved from IPFS.
Common mistake
Relying on a single gateway or node risks content loss; ensure pinning or distributed availability strategies.
Design checklist
  • Which assets need immutable provenance?
  • Who will guarantee availability (pinning, nodes, incentives)?
  • How will you reference content hashes from smart contracts?
Key Takeaway

Keep large and mutable data off-chain while anchoring integrity on-chain via content hashes and plan availability strategies up front.
