Architecture

DApp architecture layers

Layered components
Frontend
Standard web UI that builds the user experience and collects signatures for transactions.
Web3 library
A client-side library that creates and signs transactions and reads on-chain state.
Smart contracts
On-chain programs that define application rules and manipulate state deterministically.
Blockchain ledger
A replicated database and execution environment that provides immutability and consensus.
Decentralized storage
IPFS or Arweave for large files and off-chain metadata to keep data decentralized without on-chain cost.
Annotated example
NFT marketplace:
  • Frontend shows items and signs purchase transactions.
  • Web3 library encodes transaction for the marketplace contract.
  • Smart contract transfers token ownership and emits events.
  • Artwork files live on IPFS and metadata references the IPFS hash.
Key Takeaway

Design decisions hinge on which state and rules require on-chain guarantees versus which can remain off-chain to save cost and improve UX.
