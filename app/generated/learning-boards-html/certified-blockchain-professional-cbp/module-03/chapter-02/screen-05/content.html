Process steps
Four steps make the lifecycle concrete and auditable.
  1. Deploy: Contract bytecode and initial state are written to the blockchain.
  2. Invoke: A transaction calls a function with specific inputs.
  3. Execute: Each node runs the code deterministically to produce an outcome.
  4. Commit: Consensus accepts the result and the state change is recorded immutably.
Concrete example
Calling a token transfer triggers validation of balances, execution of the balance update by nodes, and inclusion of the state change in a block that finalizes the transfer.
