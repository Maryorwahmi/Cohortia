Module 3 › Chapter 3.2 › Security
Why security matters
Contracts often control funds. A bug can enable theft or permanent loss because immutability prevents simple fixes.
Best practices
  • Write extensive unit tests and simulate edge cases.
  • Use third-party audits and well-audited libraries.
  • Consider formal verification for critical modules.
Concrete example
The DAO incident shows how logic vulnerabilities can lead to major losses; this is why immutable code requires careful review before deployment.
Misconception
More code does not mean more security. Simpler, auditable code is often safer.
