Module 3 › Chapter 3.2 › Upgradeability
Proxy pattern
A proxy holds state and delegates calls to an implementation contract. Swap the implementation to upgrade logic while preserving state.
Migration pattern
Deploy a new contract and move assets or instruct users to migrate. Simpler but requires coordination.
Risks & governance
Upgrade mechanisms add an attack surface and demand secure governance: who can upgrade and how are upgrades approved?
Misconception
Upgradeability is not a free safety net. It requires secure controls and clear governance to avoid centralized risks.
