Module 3 › Chapter 3.2 › What is a Smart Contract?
Definition & origin
A smart contract is self-executing code and state held on a blockchain. Nick Szabo proposed the idea in 1994; blockchains like Ethereum made it practical by providing a distributed runtime.
Concrete example
An escrow contract that holds payments and releases them automatically when a delivery condition is met, removing the need for an intermediary.
Common misconception
Smart contracts are not inherently legal contracts; they are technical enforcement mechanisms. Legal status depends on external laws and agreements.
Key Takeaway

Think of a smart contract as executable agreement logic that lives on-chain and is enforced by distributed nodes rather than courts or intermediaries.

Historical note
Nick Szabo described the idea of digital contracts in 1994. Ethereum provided the runtime environment that allowed those ideas to be implemented widely, introducing the EVM as a shared execution context.
Quick checklist for definition
  • Code expresses the terms of the agreement.
  • Code and state are stored on the blockchain.
  • Execution is automatic when conditions are met.
  • Consensus among nodes records state changes immutably.
