Practical checks

These checks guide your hands-on time in Remix's JavaScript VM.

Compiler
Match pragma version
Selecting the wrong compiler causes errors or subtle miscompiles.
Types
Use uint256 for counters
Short strings can be expensive; bytes may be preferable for fixed-length data.
Visibility
Mind public vs private
Public exposes getters; private limits external access.
Try this

Complete the provided Counter.sol TODOs, compile, deploy to JavaScript VM, and test edge cases such as decrementing at zero.

Common pitfall

Forgetting require checks or using wrong visibility opens contracts to logic errors and unintended calls.
