Module 3 › Chapter 3.3 › Deploy & Interact
Observation steps
  1. Deploy contract to JavaScript VM and expand the instance.
  2. Call the public getter to note the initial value.
  3. Use set with an input like 42 and send the transaction.
  4. Inspect the transaction receipt and then call get again to confirm the new state.
What the console shows
Gas used, transaction hash, and logs. The receipt verifies the state change after mining on the simulated chain.
Try this
Deploy SimpleStorage, call set with 42, inspect the transaction details, then call get to confirm the value persists. Note the difference in behavior between set and get.
Key Takeaway

Transactions change state and produce receipts; view reads return state immediately without gas in the simulated environment.
