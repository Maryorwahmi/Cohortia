Pragma

A single line that defines compatibility with compiler versions. Treat it as a contract between your code and the compiler implementation.

Example directive
// SPDX-License-Identifier: GPL-3.0
pragma solidity ^0.8.0;
The caret indicates compatibility with 0.8.x releases but not 0.9.x.
Why it matters
Compiler behavior affects safety checks, optimizations, and available language features.
Common mistake
Using a compiler outside the pragma range leads to errors or unexpected differences in how operations behave.
Checklist
  • Include a pragma in every file.
  • Match the compiler version in Remix to the pragma range.
  • Update pragma intentionally when using new features.
Key Takeaway

Pragma keeps your source and compiler in agreement, reducing surprises during compilation and deployment.
