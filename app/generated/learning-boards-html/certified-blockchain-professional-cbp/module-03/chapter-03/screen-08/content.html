Code
// SPDX-License-Identifier: GPL-3.0
pragma solidity ^0.8.0;

contract SimpleStorage {
    // State variable to store a number
    uint256 public storedData; // 'public' creates an automatic getter function

    // Function to set the value of storedData
    function set(uint256 x) public {
        storedData = x;
    }

    // Function to retrieve the value of storedData
    function get() public view returns (uint256) {
        return storedData;
    }
}
Annotations
  • SPDX & pragma: license and compiler range set expectations for tools.
  • storedData: a public uint256 state variable with an automatic getter.
  • set(x): updates state and therefore creates a transaction; watch gas usage in Remix.
  • get(): declared view and returns state without modifying the blockchain.
Key Takeaway

A minimal contract demonstrates storage, automatic getters, state updates via transactions, and view-only reads for free inspection.
