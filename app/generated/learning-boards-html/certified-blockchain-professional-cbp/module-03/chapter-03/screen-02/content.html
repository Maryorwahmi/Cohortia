Learning Objectives

Understand, apply, and test basic Solidity contracts.

Bloom: Learn → Understand → Apply → Master
01
Understand Solidity basics
Identify pragma, contract, state variables, and functions and explain why Solidity is statically typed.
Mnemonic: Syntax tree
VERIFIED COMPETENCY MILESTONE
02
Use Remix IDE
Navigate the editor, compiler, and deploy panels to compile and run contracts in a JavaScript VM environment.
Mnemonic: Editor → Compile → Deploy
VERIFIED COMPETENCY MILESTONE
03
Build a simple contract
Declare a pragma, create a contract, add state variables and basic functions, and explain view vs state-changing functions.
Mnemonic: Pragma → Contract → State
VERIFIED COMPETENCY MILESTONE
04
Deploy and interact
Deploy to a local JavaScript VM, call view functions without gas, and send transactions to update state and see logs.
Mnemonic: Read vs Write
VERIFIED COMPETENCY MILESTONE
