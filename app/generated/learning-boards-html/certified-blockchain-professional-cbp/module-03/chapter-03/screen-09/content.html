Common types
uint / uint256
Unsigned integers for counters and balances.
address
20-byte account or contract identifier used for ownership and transfers.
bool
True/false flags for simple logic.
string / bytes
Use bytes for short, fixed-length data; strings are flexible but costly.
mapping
Key-value storage like address → uint256 for balances; efficient but not iterable.
struct / enum
Custom grouped types and restricted named states.
Practical guidance
  • Choose uint256 for counters unless storage/packing reasons require smaller types.
  • Avoid using strings for frequently-written state.
  • Use mappings for lookups and structs for grouped data.
Key Takeaway

Type choices influence gas and usability; favor efficient fixed-size types for on-chain operations.
