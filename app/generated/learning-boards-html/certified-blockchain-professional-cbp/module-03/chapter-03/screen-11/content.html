Module 3 › Chapter 3.3 › Common Mistakes
Visibility & errors
Visibility confusion
Public creates getters; avoid making mutating functions public without access controls.
Overflow/underflow
Modern compilers check arithmetic, but audit older contracts that may wrap values.
Expensive strings
Use bytes for short, fixed-length data to save gas.
Preventative steps
  • Add require checks for preconditions.
  • Restrict mutating functions via visibility and modifiers.
  • Test edge cases in Remix before deploying publicly.
Common pitfall

Making everything public for convenience can unintentionally expose state-changing capabilities to anyone.
