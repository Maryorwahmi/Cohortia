Module 3 › Chapter 3.3 › What is Solidity?
Definition

Contract-oriented and statically typed

Solidity uses contracts to group state and behavior. Types like uint256, address, and bool are explicit, so the compiler can check them before deployment.

Analogy: contract as a wooden chest
State variables are drawers; functions are keys that open or change those drawers under rules you write.
Example
Choosing uint256 for counters avoids unexpected wrap behavior on modern compilers and matches typical storage expectations.
Misconception
Do not assume JavaScript semantics carry over. Solidity's types and gas model change how you structure logic.
Quick reference
Type
uint256
Common for counters and numeric state.
Type
address
Stores 20-byte account or contract identifiers.
Modifier
view
Function that reads state without changing it; no gas when called locally.
Keyword
public
Creates an external getter for state variables and allows external calls to functions.
Key Takeaway

Solidity's types and modifiers encode how code behaves on-chain; design choices affect gas, safety, and accessibility.
