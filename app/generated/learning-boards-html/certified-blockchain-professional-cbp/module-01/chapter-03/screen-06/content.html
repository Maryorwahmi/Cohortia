Module 2 › Chapter 1.3 › Public-key Cryptography
Definition

Private and public keys

A private key is secret and used to sign. A public key is derived from the private key and used to verify signatures and encrypt messages to the owner.

Authenticity and Integrity
Signatures prove who created a message and that the message was not changed after signing.
Security note
Protect private keys like cash: anyone with the private key can move your assets.
Concrete example

Alice generates a private key and derives a public key. When she signs a transfer, others use her public key to confirm the signature matches the transfer content and the claimed sender — this proves the transfer originated from her private key without exposing it.

Common misconception

The public key cannot sign; it only verifies. Treat the private key as the secret authority.

Key Takeaway

Public-key pairs let others verify ownership without ever needing the private key itself.
