Module 2 › Chapter 1.3 › Digital Signatures
How it works
Sign(message, private_key) → signature. Verify(message, signature, public_key) returns true only if signature matches message and key pair.
Authenticity
The signature proves the message was created by the private key holder.
Integrity
A single-bit change in the message will invalidate the signature.
Concrete analogy

Think of a digital signature as a tamper-evident wax seal that only the owner can make. If someone tampers with the letter, the seal no longer matches the content.

Common pitfall
Do not confuse signature with encryption; signatures verify origin, encryption hides content.
Key Takeaway

Signatures let anyone confirm who authorized a transaction and whether the data changed after signing.
