Module 2 › Chapter 1.3 › Misconceptions
Private vs Public

Private key = secret authority; public key = verifier. Sharing a private key hands over control of assets.

Quick check
If you can sign transactions with a key, it must be private. If you only verify signatures, it is public.
Consensus diversity

PoW and PoS are not the only models; different networks use different selection and security incentives according to their goals.

Reality check
Assess consensus by asking what resource it makes costly and how it punishes misbehavior.
Security reminders
  • Back up private keys securely — loss equals loss of control.
  • Assume attackers will target concentration points like large staking pools or mining farms.
  • Design choices change risk; always assess how decentralization, cryptography, and consensus interact.
