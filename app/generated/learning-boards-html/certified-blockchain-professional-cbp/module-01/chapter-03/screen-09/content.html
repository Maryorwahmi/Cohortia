What consensus does

Agreement rules for untrusted participants

Consensus ties the right to add blocks to some costly or staked resource so that dishonest behavior is uneconomical or punishable.

Prevents double-spend
By ordering blocks and making reorganization difficult, consensus prevents the same funds from being spent twice in the canonical chain.
Deters attack
Attackers need to control the required resource — computing power or stake — making fraud expensive or risky.
Fork resolution
Consensus rules define how to pick a canonical chain when multiple proposals exist.
Governance boundary
Consensus focuses on technical agreement; higher-level governance can still change protocol rules through coordinated updates.
Key Takeaway

Consensus turns independent verifiers into a single reliable system by tying agreement to cost or stake.
