Process

Proving inclusion

A Merkle proof provides the necessary sibling hashes so a verifier can recompute the path to the Merkle root without all leaves.

Example path
To prove TxC, provide H(TxD) and H_AB. Verifier computes H_CD = H(H(TxC)+H(TxD)) and then Root = H(H_AB+H_CD).
Verification cost
Only O(log n) sibling hashes are required, so verification bandwidth grows slowly with transaction count.
Privacy note
A Merkle proof shares only the hashes needed for the path, but depending on context some additional metadata may be exposed by the protocol.
Key Takeaway

Merkle proofs enable lightweight, bandwidth-efficient verification of transaction inclusion for devices that do not store full blocks.
