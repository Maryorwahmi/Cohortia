Module 1 › Chapter 1.2 › Genesis block
Special case

The chain’s anchor

Because the genesis block has no predecessor, its previous-hash is a fixed placeholder. It is the agreed starting point for all correct nodes.

Peer syncing
Nodes rely on the same genesis to build a consistent history; incompatible genesis values create separate networks.
Misconception check
Genesis is public and fixed, not secret or changeable without creating a new chain.
Concrete detail
In many systems the previous-hash in the genesis header is a string of zeros; the genesis header and its hash are part of client configuration.
Key Takeaway

The genesis block anchors the ledger and must be agreed upon so nodes share the same historical root state.
