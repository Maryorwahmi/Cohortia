Process

Cascading detection

A block’s stored previous-hash ties its validity to the exact bytes of the prior block; change the prior bytes and the chain breaks.

Step 1
Block N has hash HN stored in Block N+1 as previous-hash.
Step 2
If Block N is altered, recomputed hash HN' != HN and Block N+1’s stored value no longer matches.
Step 3
To hide tampering, an attacker must recompute valid subsequent blocks, which is costly under Proof of Work.
Concrete example
In the Python block linking demo, including the prior hash in the new block string makes the new block hash change when earlier content is changed; the mismatch is immediate and verifiable.
Key Takeaway

The previous-hash field creates a chain of dependency so any modification in the past is visible unless an attacker can recompute an infeasible amount of work.
