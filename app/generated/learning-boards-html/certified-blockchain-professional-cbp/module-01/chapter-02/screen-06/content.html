Module 1 › Chapter 1.2 › Cryptographic hash functions
Definition

What makes a hash function cryptographic?

It provides a fixed-size digest with determinism, one-wayness, collision resistance, and the avalanche effect, which together secure blockchain integrity.

Deterministic
Same input always produces the same digest.
Avalanche effect
A one-character change produces a completely different hash, making tampering obvious.
Misconception check
Hashing is not reversible. You cannot recover the original transaction from its hash, unlike encrypted data with a key.
Example
If a single transaction amount changes slightly, its hash changes and that change propagates up to the Merkle root and header hash, invalidating subsequent links.
Key Takeaway

Hash functions turn arbitrary data into compact fingerprints that reveal any change while remaining impractical to invert or forge.
