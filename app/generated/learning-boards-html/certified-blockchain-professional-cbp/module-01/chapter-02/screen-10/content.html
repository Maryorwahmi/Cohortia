Module 1 › Chapter 1.2 › Merkle tree fundamentals
Hierarchy

Leaf to root

Pairwise hashing of transaction leaf hashes yields parent nodes and ultimately the Merkle root stored in the header.

Construction steps
  1. Hash each transaction to create leaf hashes.
  2. Pair adjacent leaf hashes and hash each pair for parent nodes.
  3. Repeat pairing until one hash remains — the Merkle root.
Odd leaf handling
If there is an odd number of leaves, duplicate the final leaf hash before pairing so every level pairs evenly.
Concrete example
For TxA, TxB, TxC, TxD: H(TxA), H(TxB) → H_AB = H(H(TxA)+H(TxB)); H_CD = H(H(TxC)+H(TxD)); Merkle Root = H(H_AB+H_CD).
Key Takeaway

Merkle roots let you represent an entire transaction set as a single hash and provide compact inclusion proofs for light clients.
