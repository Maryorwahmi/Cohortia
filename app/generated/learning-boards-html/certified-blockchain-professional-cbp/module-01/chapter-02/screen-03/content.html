Practice & Verification

Complete short tasks that demonstrate hashing behavior and Merkle inclusion proofs.

Run the Python hash demo
Use the provided calculate_sha256_hash function to confirm determinism and the avalanche effect.
Simulate block linking
Create a block string with the previous hash and observe how changing a transaction invalidates the link.
Build a Merkle tree
Hash four transactions, pair and re-hash to compute a Merkle root and a proof path for one leaf.
Explain a common misconception
Timestamps indicate creation time but do not provide cryptographic order—only the previous hash links blocks securely.
Verification tip
When you prove inclusion, you need only the Merkle root plus log(n) sibling hashes rather than every transaction.
