Definition

Blockchain as a DLT pattern

It is a distributed ledger that stores data in blocks and links them via the previous block hash so the ledger becomes tamper-evident.

Analogy
Each block is like a ledger page that contains the fingerprint of the prior page; change one page and the fingerprint chain breaks.
Common misconception
Timestamps do not enforce immutable order by themselves; the cryptographic previous-hash link is the core order/immutability mechanism.
Block chain visual
Block N
Header: prev_hash = H(Block N-1), merkle_root, timestamp, nonce
→
Block N+1
Header: prev_hash = H(Block N), merkle_root, timestamp, nonce
This explicit prev_hash field is the cryptographic link that turns pages into a verifiable chain.
Key Takeaway

Blockchain’s defining property is the cryptographic linking of blocks, which makes historical tampering detectable and expensive.
