Module 1 › Chapter 1.2 › Key Concepts
Blockchain
A DLT variant that chains blocks cryptographically to provide tamper evidence.
Cryptographic Hash
Fixed-size, one-way fingerprint with the avalanche effect to reveal any change.
Merkle Tree
A binary hash tree that yields a single root to summarize and prove many transactions.
Summary

These components work together so nodes can detect tampering and verify transaction inclusion efficiently, forming the practical basis of blockchain security.
