InferSchema (explore)
Convenient and fast to iterate, but may be slow on very large files and sometimes inaccurate.
df = spark.read.option("header","true").option("inferSchema","true").csv(path)
Explicit schema (production)
Use StructType to define precise column types and avoid inference surprises.
from pyspark.sql.types import StructType, StructField, IntegerType, StringType, DoubleType
schema = StructType([
  StructField('id', IntegerType(), True),
  StructField('name', StringType(), True),
  StructField('price', DoubleType(), True)
])
df = spark.read.schema(schema).option('header','true').csv(path)
Why it matters
Explicit schemas reduce runtime surprises, speed up read time by avoiding extra passes, and make downstream types reliable.
