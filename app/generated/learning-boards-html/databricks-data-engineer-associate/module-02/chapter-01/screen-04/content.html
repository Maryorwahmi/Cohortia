Workspace sections explained
A clear separation of concerns helps you find artifacts and run workloads reliably.
Workspace
Notebooks, folders, and libraries for development. Use folders to structure projects and version control.
Data
Registered tables, mounts, and the data catalog. Register important datasets for sharing.
Compute
Create clusters, define runtime, and view node counts and states.
Jobs
Schedule notebooks and monitor runs for production workflows.
Guided example
Follow this quick sequence to explore the UI and confirm you can perform each action.
  1. Create a folder under Workspace and add a new Python notebook.
  2. Open Data and search for an existing table or register your uploaded file.
  3. Open Compute and start a small development cluster; wait until status shows running.
  4. Open Jobs to inspect scheduled runs and their last status.
Key Takeaway

Know where to store notebooks, where tables are registered, where to start compute, and where to schedule tasks.
