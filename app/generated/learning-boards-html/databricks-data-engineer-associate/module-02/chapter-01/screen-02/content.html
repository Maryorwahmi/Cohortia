Objective checks
  • List folders in Workspace and open a notebook you create.
  • Use %sql to run a simple SELECT on a table or temporary view.
  • Start or attach to a running cluster and verify Spark context is available.
  • Upload a sample file to /FileStore/tables and read it with spark.read.
Why this matters
These skills let you iterate on data exploration quickly and avoid runtime errors that stall development.
