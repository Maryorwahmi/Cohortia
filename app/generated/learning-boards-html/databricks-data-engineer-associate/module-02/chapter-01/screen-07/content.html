Cluster lifecycle steps
Follow these steps each time you need to run Spark workloads from a notebook.
  1. Create cluster: choose runtime and node sizes.
  2. Start cluster: wait until the status is RUNNING.
  3. Attach notebook to the running cluster.
  4. Run Spark operations, monitor logs, and stop when finished.
If a Spark operation errors with no session, confirm the notebook shows the cluster as attached and that the cluster state is RUNNING.
Practical checks
Run a minimal test after attachment to validate the Spark session.
# Minimal validation to run in a Python cell
print(spark)
print(spark.version)
print('Spark session is available')

# Or a small DataFrame operation
spark.range(5).count()
Common mistake
Trying to run Spark code immediately after cluster creation without waiting for RUNNING state will produce errors; always verify the state and attachment.
