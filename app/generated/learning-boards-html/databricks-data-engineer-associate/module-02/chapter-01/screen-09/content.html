DataFrame basics
DataFrames are distributed and use lazy evaluation; actions trigger execution.
# Read a CSV into a DataFrame
df = spark.read.option("header","true").option("inferSchema","true").csv("/FileStore/tables/sales_data.csv")

df.printSchema()
df.show(5)

# Register for SQL access
df.createOrReplaceTempView("sales_view")
Common operations
  • Select columns: df.select('col1', 'col2')
  • Filter rows: df.filter(df.col > 100)
  • Aggregations: df.groupBy('category').count()
  • Write results: df.write.parquet('/path/to/output')
Misconception
Calling show or printSchema triggers computation; avoid using these on very large datasets without sampling.
