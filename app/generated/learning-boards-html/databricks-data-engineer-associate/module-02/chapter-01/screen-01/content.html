Interacting with Databricks Workspaces and Notebooks
A practical walkthrough of workspace navigation, notebooks, clusters, and loading data into Spark.
This chapter helps you find the Workspace, Data, Compute, and Jobs areas, create notebooks, attach them to clusters, and load files into DBFS so you can begin data exploration.
In this lesson
Workspace layout • Notebooks and magic commands • Cluster lifecycle • Loading CSV/JSON into Spark DataFrames
