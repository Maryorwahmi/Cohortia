Module 2 › Chapter 2.1 › Hands-on: JSON Load
Starter steps
  1. Create sample_users.json locally with two JSON lines and upload to /FileStore/tables/ via the UI.
  2. Create a new Python notebook and attach to a running cluster.
  3. Run the code below to load and inspect the DataFrame.
# Starter code to load JSON
json_path = "/FileStore/tables/sample_users.json"
try:
  users_df = spark.read.option("inferSchema","true").json(json_path)
  print("DataFrame Schema:")
  users_df.printSchema()
  print("First rows:")
  users_df.show(5)
except Exception as e:
  print(f"An error occurred: {e}")
  print("Ensure the file is uploaded and your cluster is running.")
Expected outcomes and checks
  • printSchema shows inferred column types such as id as integer and name as string.
  • show displays the two user rows from the sample file.
  • If an error appears, confirm the notebook attachment and DBFS path spelling.
