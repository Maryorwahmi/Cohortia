Quick debug checklist
Follow these checks in order when a notebook operation fails.
  1. Confirm the notebook is attached to a RUNNING cluster.
  2. Run a minimal spark check like spark.version or spark.range(1).count().
  3. Verify the DBFS path using the file browser and confirm file presence.
  4. Check storage permissions if access is denied.
  5. Inspect a sample of rows to validate types before scaling the job.
Helpful patterns
Use try-except during development to display actionable messages. Keep a small test file to validate load logic quickly.
Pro tip
When in doubt, reproduce the successful sequence: attach cluster, confirm path, read a sample, inspect schema, then run the full job.
