Example: Python to SQL
Create a DataFrame in Python, register a temporary view, then query it with %sql.
# Python cell (default)
data = [(1, 'Alice'), (2, 'Bob')]
columns = ['id', 'name']
users_df = spark.createDataFrame(data, schema=columns)
users_df.createOrReplaceTempView('temp_users')
print('temp view created')

# Next cell begins with %sql to query the view
%sql
SELECT * FROM temp_users
Notice the explicit createOrReplaceTempView call. Without that registration, SQL cells cannot access the DataFrame directly. This pattern supports language-appropriate processing while enabling shared data artifacts.
Common misconceptions
You cannot assume local interpreter variables cross language boundaries. Use temp views or tables to share data across languages.
When to use %sql: Ad-hoc querying and quick aggregations on registered views.
When to use %python: Complex transformations and integration with Python libraries.
When to use %scala or %r: Use language-specific features or performance tests when needed.
Check your understanding
After creating a temp view, try selecting from it in a %sql cell. If you see no rows, ensure the cluster is attached and the view was registered in the same Spark session.
