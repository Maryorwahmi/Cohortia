Safety checks and best practices
Short rules to prevent the most common errors when developing in Databricks.
  • Check cluster status: Ensure the cluster is running and attached before running any Spark code.
  • Verify paths and permissions: Confirm DBFS paths and storage access rights to avoid load errors.
  • Prefer explicit schemas: Use StructType for production datasets to avoid slow or incorrect inference.
  • Use magic commands deliberately: Start a cell with %sql or %python to avoid language confusion.
