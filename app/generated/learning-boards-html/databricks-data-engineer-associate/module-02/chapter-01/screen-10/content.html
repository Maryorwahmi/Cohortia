Upload and read pattern
Use this safe pattern to read CSV files and get helpful error messages.
# Python pattern to read a CSV from DBFS
csv_path = "/FileStore/tables/products.csv"
try:
  df = spark.read.option("header","true").option("inferSchema","true").csv(csv_path)
  print("Loaded products.csv successfully")
  df.printSchema()
  df.show(5)
except Exception as e:
  print(f"Error loading CSV: {e}")
  print("Check that the file exists in /FileStore/tables and that your cluster has access.")
Tips and checks
  • Confirm the uploaded path in DBFS UI before running the notebook.
  • If you see permission errors, verify cluster access to the storage account or object store.
  • For large datasets, prefer reading with an explicit schema to avoid the cost of inferSchema.
