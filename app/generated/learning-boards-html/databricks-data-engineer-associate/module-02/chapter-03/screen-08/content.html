Module 3 › Chapter 2.3 › MERGE INTO for UPSERTS
MERGE pattern
MERGE compares source and target rows using a match condition. Use WHEN MATCHED for updates and WHEN NOT MATCHED for inserts to perform an upsert in a single statement.
Concrete example
-- MERGE INTO products_delta AS target
-- USING new_products_view AS source
-- ON target.item = source.item
-- WHEN MATCHED THEN
--   UPDATE SET target.price = source.price, target.discounted_price = source.discounted_price
-- WHEN NOT MATCHED THEN
--   INSERT (item, price, category, discounted_price) VALUES (source.item, source.price, source.category, source.discounted_price);
Best practices
  • Ensure the ON clause uniquely matches records you intend to update.
  • Validate the result with a SELECT after the MERGE to confirm correct upserts.
  • Use MERGE for deduplication or incremental stream merges to keep tables correct.
Misconception check
MERGE is not separate UPDATE and INSERT statements: it is a single transactional operation and produces one commit entry.
Key Takeaway

Use MERGE for atomic upserts and deduplication. It creates a single commit and preserves table consistency.
