Module 3 › Chapter 2.3 › DML Operations on Delta Tables
Typical DML commands
  • INSERT - add new rows to a Delta table.
  • UPDATE - modify existing rows transactionally.
  • DELETE - remove rows and record the change as a commit.
Example workflow
Insert new products, update Laptop price, then delete Mouse. After each step run a SELECT to confirm the committed view.
Code snippets
-- Insert new rows (example)
-- INSERT INTO products_delta VALUES ('Webcam', 50, 'Electronics', 45.0);
-- UPDATE products_delta SET price = 1250 WHERE item = 'Laptop';
-- DELETE FROM products_delta WHERE item = 'Mouse';
Misconception check
Many expect immutable Parquet files require full rewrites. Delta's log enables transactional DML so you can update and delete rows safely.
Key Takeaway

DML operations are supported and transactional in Delta Lake, making data maintenance simpler and safer than raw file operations.
