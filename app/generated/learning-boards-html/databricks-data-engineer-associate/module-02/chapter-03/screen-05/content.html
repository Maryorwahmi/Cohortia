How ACID works in Delta
  • Atomicity: A commit applies all changes or none, avoiding partial states.
  • Consistency: The table moves between valid states recorded in the log.
  • Isolation: Concurrent operations do not see each other's in-flight commits.
  • Durability: Commits are persisted via the transaction log entries.
Practical Example
When you run a MERGE that updates and inserts rows, Delta writes a new log file describing which data files were added and removed. That new log file defines a new table version and is either fully visible or not visible at all.
Inspecting the log
DESCRIBE HISTORY
Lists commits with user, timestamp, and operation so you can audit changes and pick a version to time-travel to.
Misconception check
Object storage alone doesn’t give isolation or versioned commits. The log is the coordination layer Delta relies on.
Key Takeaway

The transaction log is the durable ledger that makes Parquet files behave like a transactional table with version history.
