Module 3 › Chapter 2.3 › What is Delta Lake?
Definition and role

Delta Lake brings transactions, schema control, and unified batch/stream processing to data lakes by coupling Parquet storage with a transaction log. This combination enables reliable updates, audits, and historical queries.

Analogy
Think of the transaction log as a ledger. Parquet files hold the numbers, and the ledger records every change so you can rewind or audit operations.
Misconception
Delta is more than file format; its transactional log is what provides ACID and time travel.
Components
Parquet Files
Columnar files containing the table's rows and columns.
Transaction Log
Sequence of commit records that enable ACID, time travel, and versioning.
Concrete Example
# Example: write a DataFrame as a Delta table
transformed_df.write \
  .format("delta") \
  .mode("overwrite") \
  .save('/delta/products_delta')

# This creates data files and the initial transaction log for the table.
Key Takeaway

Delta Lake adds a transaction log to Parquet files so tables become transactional, auditable, and versioned.
