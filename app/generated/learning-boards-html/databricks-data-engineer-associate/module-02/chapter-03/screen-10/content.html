Module 3 › Chapter 2.3 › Time Travel and DESCRIBE HISTORY
Reading previous versions
Use SELECT * FROM table VERSION AS OF X or TIMESTAMP AS OF to view historical data as of a specific commit or time. This is useful for audits, experiments, and accidental recovery.
Inspect history
DESCRIBE HISTORY table_name shows a list of commits with version numbers, operations, timestamps, and user info to help select the correct version for time travel.
Example queries
-- Read an earlier version
-- SELECT * FROM sensor_readings VERSION AS OF 0;

-- View the transaction history
-- DESCRIBE HISTORY sensor_readings;
Misconception check
Time travel provides a read-only view of earlier states. To persist a recovered state, copy or write the historical view into a new table or overwrite the existing table deliberately.
Key Takeaway

Time travel plus DESCRIBE HISTORY give you the ability to audit and recover table states without full pipeline reruns.
