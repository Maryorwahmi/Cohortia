DataFrame API example
# Example: Creating a Delta table from a DataFrame
from pyspark.sql.types import StructType, StructField, StringType, IntegerType, DoubleType
dummy_data = [
  ("Laptop", 1200, "Electronics", 1080.0),
  ("Mouse", 25, "Electronics", 22.5),
  ("Monitor", 300, "Electronics", 270.0)
]
transformed_df = spark.createDataFrame(dummy_data, schema=["item","price","category","discounted_price"])

delta_table_path = "/delta/products_delta"
transformed_df.write \
  .format("delta") \
  .mode("overwrite") \
  .save(delta_table_path)

spark.sql(f"CREATE TABLE IF NOT EXISTS products_delta USING DELTA LOCATION '{delta_table_path}'")
This pattern separates physical storage from catalog registration, giving you control over table naming and locations across environments.

Common mistake
Assuming a path write always becomes a metastore table. Register explicitly when you need a named table in queries.
Key Takeaway

Write a DataFrame with format("delta") to create data and a log. Register the location if you need a metastore table.
