Module 2 › Chapter 2.2 › Key Concepts
Lazy evaluation
Transformations build a plan; an action triggers execution.
Temporary view
Register DataFrames as views to run spark.sql queries in the session.
Avoid collect
Do not collect large DataFrames to the driver; use distributed writes or aggregated summaries.
Final summary
Use the DataFrame API and Spark SQL to express intent; inspect plans and apply partitioning and join strategies to keep jobs scalable.
