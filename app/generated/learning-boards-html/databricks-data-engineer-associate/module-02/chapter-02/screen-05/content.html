Patterns

Files, Programmatic, SQL

  • Files: spark.read.parquet/csv/json with path and options.
  • Programmatic: createDataFrame with rows and an explicit schema for tests.
  • SQL: spark.sql returns a DataFrame from a query or a temporary view.
When to use each
Use spark.read for production data, programmatic creation for small test sets, and SQL for ad-hoc exploration or when integrating SQL tools.
Code example
from pyspark.sql.types import StructType, StructField, StringType, IntegerType

data = [("Alice", 1), ("Bob", 2), ("Charlie", 3)]
schema = StructType([StructField("name", StringType(), True), StructField("id", IntegerType(), True)])
programmatic_df = spark.createDataFrame(data, schema=schema)
programmatic_df.show()
Key Takeaway

Choose creation method based on data size and intent: spark.read for production files, programmatic for examples, spark.sql for queries.
