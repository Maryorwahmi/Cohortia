Module 2 › Chapter 2.2 › Register Views & Run SQL
How it works
Call createOrReplaceTempView("name") on a DataFrame to make it queryable by spark.sql for that session. Use spark.sql to run standard SQL statements and receive another DataFrame as the result.
Example query
# register and query example (conceptual)
sales_df.createOrReplaceTempView("sales_data_view")
spark.sql("SELECT category, COUNT(*) AS product_count FROM sales_data_view GROUP BY category ORDER BY product_count DESC").show()
Practical notes
  • Views are session-scoped and not persisted by default.
  • spark.sql returns a DataFrame so you can combine SQL and API steps.
  • Use views for ad-hoc analysis and collaboration with SQL users.
Key Takeaway

Temporary views let you query DataFrames with spark.sql while preserving the ability to continue using the DataFrame API.
