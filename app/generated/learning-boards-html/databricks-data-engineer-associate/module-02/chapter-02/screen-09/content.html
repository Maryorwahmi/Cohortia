Module 2 › Chapter 2.2 › Actions vs Transformations
Transformations
select, filter, withColumn, join, groupBy. They build a logical plan and are lazy until an action runs.
Actions
  • show, count, write, collect
  • Trigger compilation and execution of the plan
  • Can be expensive on large data
Best practices
  1. Preview with limit or show before running a large action.
  2. Avoid collect on large datasets; use write or aggregated results.
  3. Inspect df.explain() to understand execution before running.
Warning

Calling collect on large DataFrames pulls all data to the driver and can cause out-of-memory failures.
