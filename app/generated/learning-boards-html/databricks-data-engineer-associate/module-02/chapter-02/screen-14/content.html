Spark DataFrame
Distributed, immutable, and lazy collection with named columns.
Spark SQL
Run SQL against temporary views; spark.sql returns a DataFrame for further processing.
Performance
Inspect plans, partition data, avoid collect on large datasets, and cache selectively.
