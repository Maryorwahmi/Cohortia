Differentiate actions and transformations
Recognize operations that trigger execution, such as show, count, and write, as opposed to lazy transformations that only build a plan.
Mnemonic: plan vs run.
Verified Competency Milestone
06
Inspect and optimize plans
Use df.explain() to see the logical and physical plan and spot expensive operations like wide shuffles or unpartitioned joins.
Mnemonic: explain then optimize.
Verified Competency Milestone
07
Avoid common pitfalls
Understand the danger of collect on big DataFrames and why distributed aggregations keep your job scalable.
Mnemonic: distributed first.
Verified Competency Milestone
08
Practice with a hands-on task
Create an orders DataFrame, register a temporary view, and perform the same aggregation via spark.sql and the DataFrame API to compare.
Mnemonic: code it twice, API and SQL.
Verified Competency Milestone
