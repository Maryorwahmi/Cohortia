Definition

Spark DataFrame

A distributed collection with named columns. Immutable and lazy, it represents a logical plan until an action runs.

Immutable: transformations return new DataFrames, original is unchanged.
Lazy evaluation: transformations build a plan, actions trigger execution.
Distributed: data and work are partitioned across the cluster for parallelism.
Common misconception
Calling select or withColumn immediately shows results. In reality you must call an action to materialize data.
Analogy
Treat a DataFrame like a query notebook where you write transformations. Spark compiles the notebook into an efficient execution plan before running it on your data.
Example
# conceptually:
transformed = df.select("a", "b").withColumn("c", df.a + df.b)
# no execution yet
# execution occurs when calling an action like:
# transformed.show()
Key Takeaway

DataFrames are declarative plans. Build transformations then run an action to execute at scale.
