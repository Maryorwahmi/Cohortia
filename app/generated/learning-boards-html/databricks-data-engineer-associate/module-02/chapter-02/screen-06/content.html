Module 2 › Chapter 2.2 › DataFrame transformations
API overview

Common methods

  • select() — pick columns
  • filter()/where() — choose rows
  • withColumn() — add or transform a column
  • groupBy().agg() — aggregations like avg and sum
  • join() — combine DataFrames on keys
Pro tip
Write the full pipeline before calling an action so Spark can optimize across steps.
Example
from pyspark.sql.functions import col, lit, avg

sales_data = [("Laptop", 1200, "Electronics"), ("Mouse", 25, "Electronics"), ("Shirt", 30, "Apparel")]
sales_schema = ["item", "price", "category"]
sales_df = spark.createDataFrame(sales_data, schema=sales_schema)

transformed_df = sales_df.select(col("item"), col("price"), lit("USD").alias("currency")) \
                         .filter(col("price") > 50) \
                         .withColumn("discounted_price", col("price") * 0.9)

avg_price_by_category = sales_df.groupBy("category").agg(avg("price").alias("average_price"))
avg_price_by_category.show()
Common mistake

Expecting immediate execution after each transformation; remember to call an action to run the plan.
