Understand DataFrame basics

Create DataFrames from sources
Load Parquet, CSV, JSON via spark.read, construct programmatic DataFrames, or create from SQL queries and views.
Mnemonic: file, programmatic, SQL.
Verified Competency Milestone
03
Transform using the DataFrame API
Use select, filter/where, withColumn, join, groupBy, and orderBy to express data transformations declaratively.
Mnemonic: pick, filter, add, join, aggregate.
Verified Competency Milestone
04
Query DataFrames with Spark SQL
Register temporary views to run spark.sql queries, enabling SQL-based analysis on DataFrame content.
Mnemonic: view then SQL.
Verified Competency Milestone
