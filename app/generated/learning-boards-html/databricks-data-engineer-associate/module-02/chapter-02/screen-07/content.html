Module 2 › Chapter 2.2 › API vs SQL
DataFrame API

Programmatic pipelines

  • Chain transformations with language constructs
  • Dynamic column expressions and custom DSL
  • Preferred for production pipelines
Example: building a derived column using withColumn and UDFs for complex logic.
Spark SQL

Ad-hoc queries

  • Familiar SQL syntax for analysts
  • Register DataFrame as temporary view and query with spark.sql
  • Good for quick exploration and reporting
Example: register sales_df as a view and run a GROUP BY query with spark.sql.
Shared execution
Both APIs produce the same optimized execution plans. The choice is about expressiveness and your workflow, not performance differences in principle.
