Iterative rule design
  • Begin with warn to measure prevalence.
  • Move to drop when the rule consistently isolates invalid data.
  • Use fail only for essential invariants that must stop updates.
Operational tips
Give each expectation a clear, human-friendly name for easier triage.
Set alerts on sudden increases in invalid or dropped counts.
Document remediation steps for quarantined data so teams can act quickly.
