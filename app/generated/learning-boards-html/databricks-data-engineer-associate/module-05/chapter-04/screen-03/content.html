Module 5 › Chapter 5.4 › Learning Objectives
Objective checklist
  • Implement expect and expect_or_drop in a DLT table definition and save the notebook.
  • Trigger a pipeline update and confirm whether violations caused a fail or allowed completion.
  • Open the DLT table details, inspect Data Quality counts, and click through event logs for offending records.
  • Iterate on expectations: tighten or relax rules based on observed dropped or warning counts.
Mnemonic
S.T.E.P
Set expectations, Trigger update, Examine metrics, and Patch sources.
