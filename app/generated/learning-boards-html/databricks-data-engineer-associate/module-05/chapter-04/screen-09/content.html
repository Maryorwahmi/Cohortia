Event logs
Event logs provide row-level examples for failing conditions, timestamps, and run identifiers. Use them to reproduce and fix upstream issues, then rerun your pipeline to confirm improvement.
Action steps
  • Check the Data Quality counts after each update.
  • If dropped counts increase, open event logs to view offending rows.
  • Create a trend dashboard to spot regressions and new data producers causing errors.
Pro tip

Query historic event logs with Spark SQL to analyze recurring failure patterns and plan remediation.
