Module 5 › Chapter 5.4 › Quarantine Tables
What quarantine holds
Quarantine stores the full offending row plus metadata like run id, expectation name and timestamp so teams can inspect and decide on remediation without losing context.
Use case
Regulated records or complex business-rule failures that require human review.
Operational cost
Quarantining increases storage and demands a remediation process to keep the backlog manageable.
Remediation steps
  1. Query quarantined records to identify common failure patterns.
  2. Fix upstream producers or adjust the expectation if rule is too strict.
  3. Re-ingest or correct records as part of a remediation job.
