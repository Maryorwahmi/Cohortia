Module 5 › Chapter 5.4 › Basic expect example
Notebook snippet
import dlt
from pyspark.sql.functions import col, trim, lower

@dlt.table(
    comment="Cleaned customer data with quality expectations."
)
@dlt.expect("customer_id_not_null", "customer_id IS NOT NULL")
@dlt.expect_or_drop("age_positive", "age > 0")
def cleaned_customer_data():
  return (
      dlt.read_stream("raw_customer_stream")
         .select(
             col("customer_id"),
             trim(col("first_name")).alias("first_name"),
             lower(trim(col("email"))).alias("email"),
             col("age").cast("integer").alias("age")
         )
  )
Explanation
  • customer_id_not_null uses expect and defaults to fail if any row lacks a customer identifier.
  • age_positive uses expect_or_drop so negative or missing ages are removed and counted as dropped.
  • DLT will record metrics and event logs so you can find offending rows even when they are dropped.
Key Takeaway

Mix fail rules for invariants and drop for noisy fields to keep pipelines resilient and reliable.
