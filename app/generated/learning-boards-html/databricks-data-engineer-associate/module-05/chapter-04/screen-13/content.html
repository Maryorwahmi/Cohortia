Practice question
Q1:
Which expectation policy causes the pipeline update to fail if a record violates the rule?
Answer: use expect which defaults to FAIL.
Debugging steps
  1. Open the pipeline graph and select the target table.
  2. Review the Data Quality section and click event log links for offending records.
  3. Trace records back to sources and fix or adjust expectations as needed.
