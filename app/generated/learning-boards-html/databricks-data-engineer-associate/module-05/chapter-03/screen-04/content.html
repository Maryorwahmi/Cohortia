Module 5 › Chapter 5.3 › What is DLT?
Definition
Delta Live Tables is a declarative framework for building ETL pipelines on the Lakehouse Platform. Using SQL or Python declarations, engineers define LIVE and STREAMING LIVE tables and DLT manages the DAG, execution, schema enforcement, and operational concerns like checkpointing and retries.
Metaphor
Think of DLT as giving the system a blueprint; you draw the rooms and the builder installs plumbing and wiring automatically.
Concrete example
A streaming ingestion of JSON files becomes a STREAMING LIVE table, and a cleaned view of that stream becomes a LIVE table that DLT keeps updated.
Common misconception
DLT is not just syntactic sugar; it also enforces checkpoints, expectations, and schema behaviors that are critical for production workflows.
Concept cards
LIVE vs STREAMING LIVE
LIVE tables update in triggered or batch runs. STREAMING LIVE tables ingest continuously using Structured Streaming semantics.
Declarative approach
Declare desired tables and dependencies; DLT builds and maintains the execution plan and state.
Operational automation
DLT manages clusters, retries, schema checks, and provides UI visibility into table status and lineage.
Key Takeaway

DLT raises the abstraction level: you declare data state and DLT maintains it, reducing operational overhead while improving reliability.
