Module 5 › Chapter 5.3 › Key Concepts
Delta Live Tables
A declarative framework that automates schema, execution, and operational tasks for ETL pipelines.
LIVE vs STREAMING LIVE
LIVE updates are batch/triggered; STREAMING LIVE handles continuous ingestion and requires checkpointing.
Expectations
Data quality rules that DLT evaluates and reports on during pipeline execution.
Summary
Declare your data state, configure storage and update mode, and use expectations plus the DLT UI to keep pipelines robust and observable.
