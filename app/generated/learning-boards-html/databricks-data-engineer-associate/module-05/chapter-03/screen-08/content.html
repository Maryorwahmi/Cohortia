Why checkpointing matters
cloudFiles.schemaLocation provides a durable path for schema inference and stream state. It is essential for exactly-once semantics and for recovering progress after restarts.
Schema evolution example
If a producer adds an optional field, DLT can auto-evolve the target schema or fail the run to force a review. Choose the behavior based on downstream requirements.
Practical checklist
  • Always set cloudFiles.schemaLocation for streaming sources.
  • Decide whether to allow automatic schema evolution or to require manual changes.
  • Use expectations to detect unexpected nulls or type changes early.
Pitfall
Blindly enabling schema evolution can introduce unexpected columns or types that break downstream consumers. Validate changes in a staging pipeline first.
Key Takeaway

Checkpointing and explicit schema decisions are required for resilient streaming pipelines; make schema evolution intentional and tested.
