Module 5 › Chapter 5.3 › Monitoring
DAG and statuses
UPDATING
Table is currently being processed during a pipeline update.
UP_TO_DATE
Table is current for the configured update mode and has no outstanding updates.
FAILED
A failure occurred; inspect logs and expectation results to locate the root cause.
Monitoring workflow
  1. Start an update and watch the DAG for progress and status changes.
  2. Drill into nodes to view lineage, expectation results, and links to logs.
  3. Validate table contents by running a sample query in the Data persona.
Quick checks
  • Confirm checkpoint paths are writable and accessible.
  • Check expectation failure counts for quality issues.
  • Open logs for stack traces on code or dependency errors.
Key Takeaway

Use the DLT UI to quickly locate failures via the DAG, inspect lineage, and follow links to logs for fast debugging.
