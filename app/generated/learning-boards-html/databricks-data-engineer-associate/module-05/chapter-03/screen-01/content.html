Delta Live Tables for reliable ETL

Delta Live Tables, or DLT, is a declarative pipeline framework that automates runtime concerns like schema enforcement, schema evolution, checkpointing, and data quality checks so you can focus on transformations and correctness.

In this lesson
Define LIVE and STREAMING LIVE tables using Python or SQL, configure pipeline settings, run an update, and monitor the DAG and table health in the Databricks UI.
Why it matters
DLT reduces boilerplate, improves observability, and supports production patterns like checkpointing and expectations so pipelines are easier to operate.
Explore Key Topics
Declarative ETL
Declare the end state of tables and DLT plans the execution and maintenance.
Streaming vs Batch
Use streaming live tables for continuous ingestion and LIVE tables for periodic updates.
Monitoring & Settings
Target schema, storage locations, and update mode determine how DLT runs and persists state.
