Module 5 › Chapter 5.3 › Creating a basic pipeline
Pipeline process
  1. Author notebook: declare streaming_table and table objects or CREATE LIVE TABLE statements.
  2. Configure storage & schema: set storage location and target schema for checkpoints and tables.
  3. Create pipeline in Workflows: attach notebook, choose edition and update mode, optionally set cluster policy.
  4. Start and monitor: DLT provisions the cluster, builds the DAG, and runs updates.
  5. Validate results: query tables in the target schema and inspect lineage and logs for failed steps.
Example pipeline
Raw streaming ingestion → cleaned live table → aggregated summary table. Use cloudFiles for file arrival and a schemaLocation for checkpoints.
Visual checklist
Storage Location
Where DLT stores checkpoints, logs, and schema information. Required for streaming sources.
Target Schema
Database where DLT-managed tables are created; choose a dedicated schema to separate managed tables.
Update Mode
Triggered runs once versus Continuous that runs indefinitely; choose based on latency needs.
Key Takeaway

Follow the checklist: notebook, storage, target schema, pipeline settings, start, and validate.
