Architecture › Notifications
Email notifications
Add recipients for On failure, On success, or On completion in job settings.
Use for team alerts where direct email delivery is acceptable.
Prefer email for summary notifications and low-frequency jobs.
Webhook integration
Send an HTTP POST when a job event occurs to integrate with chatops or incident systems.
Include run metadata in the payload so receivers can link back to Databricks runs.
Use webhooks for automated incident workflows or dashboards.
Key Takeaway
Pick the right channel: email for human recipients, webhooks for automation and incident routing.
Pro Tip
For failures, include a direct link to the run and a short error summary to speed triage.
Check
Limit recipients to reduce noise and avoid alert fatigue for low-priority jobs.
