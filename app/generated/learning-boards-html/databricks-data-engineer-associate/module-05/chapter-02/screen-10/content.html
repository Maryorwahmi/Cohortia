Hands-on Activity › Build the Daily_Customer_Pipeline
Task setup checklist
  1. Create ingest_raw_data_task with widgets for source_path, target_table_name, processing_date.
  2. Create clean_and_transform_task reading input_table_name and writing output_table_name.
  3. Create aggregate_data_task that groups and writes aggregated metrics to gold.
  4. Create Job Daily_Customer_Pipeline and add tasks in order.
  5. Set dependencies: Clean_Transform depends on Ingest_Raw; Aggregate_Data depends on Clean_Transform.
  6. Assign task-level parameters and configure notifications.
Verification steps
  • Run the job with a fixed processing_date for testing.
  • Check the DAG to confirm tasks executed in order and statuses match expectations.
  • Confirm tables: bronze.raw_customers, silver.cleaned_customers, gold.aggregated_customers exist.
  • Inspect run logs to confirm parameters printed and used by each notebook.
Key Takeaway
Follow a checklist: notebooks, job tasks, dependencies, parameters, notifications, then verify outputs.
Pro Tip
Reuse the same job cluster where possible to reduce startup time, or choose separate clusters for isolation.
Check
Ensure processing_date is consistent across all tasks to avoid mismatched data windows.
