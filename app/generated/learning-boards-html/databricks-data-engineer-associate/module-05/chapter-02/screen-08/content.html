Comparison › Conditional Task Execution
Common conditions
  • All successful — run only if every parent succeeds.
  • At least one successful — useful for mixed upstream sources.
  • None successful — run on upstream failure cases.
  • Always — run regardless of upstream outcomes (useful for cleanup).
Example setup
Send_Success_Notification
Run if Data_Aggregation succeeds
Send_Failure_Alert
Run if Data_Aggregation fails
Cleanup
Run always to remove temporary files
Key Takeaway
Use conditional runs to automate notifications and remediation steps based on task results.
Misconception
Conditional execution is not a substitute for good in-notebook error handling and logging.
Check
Would you run a cleanup step always, even on failure, to avoid orphaned artifacts?
