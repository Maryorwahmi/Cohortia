Definition › Task Parameters
What are parameters?
Key-value entries defined at job or task level and read by the task at runtime.
Typical uses: processing_date, source_path, input_table_name, output_table_name.
Access pattern inside notebooks: use the widget-get call to retrieve values.
Example parameter set
source_path = '/databricks-datasets/retail-org/customers/customers.csv'
target_table_name = 'bronze.raw_customers'
processing_date = '2024-01-01'
Security note
Avoid placing secrets in plain parameters; use secure secret scopes instead.
Key Takeaway
Parameters make notebooks reusable and testable by externalizing run values.
Misconception
Not every variable needs to be a parameter; reserve them for run-specific configuration.
Check
Can your notebook run for a different date without code changes if parameters are provided?
