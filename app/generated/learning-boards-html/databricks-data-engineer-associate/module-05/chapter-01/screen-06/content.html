Module 5 › Chapter 5.1 › Create a Single-Task Job
Process

Convert a notebook into a job

1. Prepare notebook
Validate idempotency, parameters, and test locally.
2. Create job
Name the job and add a notebook task with path and language.
3. Configure compute
Choose a new job cluster, runtime, instance type, and auto-termination.
Schedule
Select recurring schedules or cron expressions and timezone.
Test run
Run manually and inspect logs to confirm success before enabling schedule.
Monitor and iterate
Use Runs history to catch failures early and improve robustness.
Pro tip

Always run a job once manually on the configured job cluster to surface runtime or dependency differences before scheduling.
