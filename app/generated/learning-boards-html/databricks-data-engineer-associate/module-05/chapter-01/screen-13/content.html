Quick diagnostic checklist

Check 1: Runs page
Locate the failed run and note whether failure occurred during provisioning or execution.
Check 2: Task logs
Inspect stdout and stderr for the last logged messages and stack traces.
Check 3: Runtime mismatch
Confirm the chosen runtime has required libraries and versions.
Check 4: Data assumptions
Sample inputs to reproduce parsing or casting errors locally.
Pro tip
Keep a few diagnostic print statements in your notebook during development so logs point to the last successful step when failures occur.
