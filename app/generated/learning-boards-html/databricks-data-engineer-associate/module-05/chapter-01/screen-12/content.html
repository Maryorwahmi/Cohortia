Create, Schedule, Validate: Step-by-step

1. Create notebook
Add the cleansing code and test interactively.
2. Create job & task
Reference the notebook, set task language, and name the task clearly.
3. Configure new job cluster
Pick runtime, small nodes, and enable auto-termination.
4. Schedule & test
Add a daily schedule, but run once manually to confirm behavior.
Monitor
Use Runs history to view status, duration, and task logs for errors.
Validate output
Run a select on gold.cleaned_customers to confirm data presence after success.
Key Takeaway
A short manual validation run on the chosen job cluster is the best way to catch environment differences before scheduling.
