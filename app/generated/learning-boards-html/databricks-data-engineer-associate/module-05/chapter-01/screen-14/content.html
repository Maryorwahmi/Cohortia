Module 5 › Chapter 5.1 › Key Concepts
Databricks Workflows
Service that orchestrates and automates notebooks, scripts, and jobs.
Job Cluster
Ephemeral cluster created for a job run and terminated on completion to save cost.
Interactive Cluster
Persistent environment for ad-hoc exploration, not recommended for production scheduled jobs.
Summary Takeaway
Use job clusters for production automation and interactive clusters for development to balance cost and convenience.
