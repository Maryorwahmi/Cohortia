Module 6 › Chapter 5.5 › Cost Optimization
Job clusters
Use job clusters for automated workloads with auto-termination to avoid idle cost. Choose instance types that match memory and CPU needs.
Enhanced autoscaling
For DLT pipelines, enable enhanced autoscaling so cluster size adapts to workload demands.
Spot instances and billing
Consider spot instances for non-critical workloads that tolerate interruptions. Review billing reports regularly to find costly runs.
Key Takeaway
Optimize clusters and autoscaling; prefer job clusters for scheduled work and use spot instances only where safe.
