Module 6 › Chapter 5.5 › Idempotency
Concept
Design tasks so repeated runs with the same input produce the same output.
Overwrite
Use mode("overwrite") when you can replace the entire target safely.
Merge
Use MERGE to update existing rows and insert new ones for incremental, idempotent updates.
MERGE example (template)
A conceptual MERGE statement matches on a unique key and updates or inserts rows so the result is deterministic across retries.
MERGE INTO target_table t
USING source_table s
ON t.id = s.id
WHEN MATCHED THEN
  UPDATE SET t.col1 = s.col1, t.col2 = s.col2
WHEN NOT MATCHED THEN
  INSERT (id, col1, col2) VALUES (s.id, s.col1, s.col2)
Key Takeaway
Choose overwrite for full refreshes, MERGE for incremental idempotent updates that tolerate retries.
