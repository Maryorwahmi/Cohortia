Explanation & notes
This pattern shows how expectations are declarative data quality gates and logging provides context that appears in cluster logs. Expect_or_drop enforces a strict policy by dropping records; expect_or_warn records a soft violation that can be monitored without dropping rows.
Misconception
Expectations replace logging. They complement each other: expectations enforce quality while logs explain the why and where of failures.
Key Takeaway
Use expectations for automated gating and logging for human-readable traces you can correlate with event-log entries.
