Module 6 › Chapter 5.5 › Alerting
Alerting pattern
Design alerts to notify stakeholders about critical failures and major data quality deviations, using webhooks for programmatic routing.
Tiered approach
Page for FAILED runs, channel message for performance degradation, and log tickets for informational events.
DLT note
If DLT native alerts are not granular enough, use a Workflow to poll event logs and trigger webhooks on specific event patterns.
Practical webhook payload
Include timestamp, pipeline name, run id, event type, and a short details snippet. This lets the incident system create a meaningful page and links back to the run for investigation.
Common mistake
Alerting on too many non-actionable events leads to fatigue; be selective and tune thresholds over time.
