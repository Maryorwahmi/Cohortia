When to keep nested
  • Variable keys in maps or original JSON fidelity is required
  • Downstream consumers expect nested objects
  • Write/ingest compactness and schema evolution are priorities
When to flatten
  • Frequent grouping or joins on a sub-field
  • Need to avoid expensive per-element operations or repeated access
  • Analytic workloads prefer simple columnar access
Check yourself
If most queries use a single nested field, flatten that field. If queries vary widely, keep the nested structure.
