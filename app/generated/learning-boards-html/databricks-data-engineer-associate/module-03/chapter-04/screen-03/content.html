Practice plan
  1. Read data with explicit schema for Struct, Array and Map types.
  2. Extract nested fields such as location_info.city into new columns.
  3. Explode arrays to one row per element where arrays exist.
  4. Deduplicate based on event keys, keeping the first occurrence.
  5. Fill null device values with a default and filter error events.
Why sequencing matters
Exploding before deduplication can produce more rows and change which rows are considered duplicates. Filling before validation can mask missing-value issues. Deduplicate early when duplicates distort downstream counts, but validate first when you need to inspect bad records.
