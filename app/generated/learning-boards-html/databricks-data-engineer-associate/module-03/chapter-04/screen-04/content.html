Module 4 › Chapter 3.4 › StructType
Definition
A StructType is a nested record containing named fields, each with its own type and nullability.
Example
from pyspark.sql.functions import col

# Extract city from a struct column
events_df = events_df.withColumn('user_city', col('location_info.city'))
events_df.select('event_id', 'user_city').show()
Key Takeaway

Use dot-access to pull named fields for filtering, grouping, or joins; leaving struct intact preserves nested semantics.

Notes & common mistakes
  • Accessing sub-fields of a null struct returns null; guard with when(column.isNull(), ...)
  • Flattening every struct can increase wide-table overhead and hurt write compatibility with some sinks
  • Use explicit schema when reading JSON to get predictable field types and nullability
Analogy
Think of StructType as a contact card inside a spreadsheet cell. You can keep the card whole or extract a field like phone for a specific task.
