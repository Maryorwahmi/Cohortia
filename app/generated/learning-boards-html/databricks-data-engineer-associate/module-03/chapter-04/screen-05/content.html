Module 4 › Chapter 3.4 › ArrayType & explode
Definition
ArrayType holds an ordered collection of elements of the same type, e.g., a list of item structs or tags.
Code
from pyspark.sql.functions import explode, array_contains, size, col

# Explode tags to one row per tag
exploded = complex_df.select('user_id', explode('tags').alias('tag'))

# Check for tag membership
has_tag1 = complex_df.withColumn('has_tag1', array_contains(col('tags'), 'tag1'))

# Size of an array
with_counts = complex_df.withColumn('num_tags', size(col('tags')))
Key Takeaway

Use explode for element analyses, size and array_contains for lightweight checks, and guard null/empty arrays before exploding.

Practical guidance
  • Filter or coalesce arrays before explode to avoid null-related surprises.
  • Exploding increases the number of rows — consider performance and downstream joins.
  • If you need counts, use size rather than explode to preserve row volume.
Misconception check
Exploding is not always necessary. For many aggregations you can use higher-order array functions or size instead.
