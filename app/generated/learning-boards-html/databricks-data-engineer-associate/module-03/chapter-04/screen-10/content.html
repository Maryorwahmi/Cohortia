Module 4 › Chapter 3.4 › Data Validation
Types of checks
  • Schema enforcement
  • Range checks (age, price)
  • Format checks (email, timestamps)
  • Cross-field rules (end_date > start_date)
Example
# Range check example
valid = df.filter((col('age') >= 0) & (col('age') <= 120))
invalid = df.subtract(valid)

# Cross-field example
valid_dates = df.filter(col('end_date') > col('start_date'))
Quarantine & enforcement
Write invalid records to an error table for later triage. For production, consider Delta Lake CHECK constraints to enforce basic rules at write time and fail fast on schema violations.
Pro Tip
Log counts of invalid records to alert on spikes in bad data and prevent silent failures downstream.
