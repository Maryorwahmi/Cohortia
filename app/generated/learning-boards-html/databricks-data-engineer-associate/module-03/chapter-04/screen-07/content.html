Common code patterns
# Extract city from struct
events_with_city = events_df.withColumn('user_city', col('location_info.city'))

# Check array membership
events_with_tag = events_df.withColumn('has_tag1', array_contains(col('tags'), 'tag1'))

# Compute array size
events_counts = events_df.withColumn('num_tags', size(col('tags')))
Guidance & checklist
  • Prefer explicit schema over inference for stability.
  • Filter null/empty arrays before exploding.
  • Use coalesce or when to handle null maps and structs.
