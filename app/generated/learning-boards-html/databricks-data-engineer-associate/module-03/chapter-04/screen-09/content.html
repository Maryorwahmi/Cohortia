Module 4 › Chapter 3.4 › Distinct vs dropDuplicates
distinct()
Removes exact duplicate rows considering all columns.
distinct_df = duplicate_df.distinct()
distinct_df.show()
dropDuplicates(subset=[...])
Removes duplicate rows based on a subset of columns that define uniqueness.
unique_users = more_duplicate_df.dropDuplicates(subset=['user_id','name'])
unique_users.show()
Practical guidance
  • Use dropDuplicates with window functions if you need to pick the latest or highest-quality row deterministically.
  • distinct is simple for exact de-duping but can be expensive when rows are wide or when many columns vary slightly.
  • Always decide which columns define identity early in your pipeline to prevent overcounting later.
