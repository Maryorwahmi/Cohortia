Module 4 › Chapter 3.4 › Handling Nulls
Key functions
  • na.drop(how='any'|'all', subset=[...])
  • na.fill(value or dict)
  • when().otherwise() for complex types
Example
# Drop rows with null contact or tags
clean = complex_df.na.drop(how='any', subset=['contact_info','tags'])

# Fill tags with a default list
filled = complex_df.na.fill({'tags': ['no_tag']})

# Fill null map with when
from pyspark.sql.functions import when
filled_map = complex_df.withColumn(
  'contact_info',
  when(col('contact_info').isNull(), {'email':'unknown','phone':'unknown'}).otherwise(col('contact_info'))
)
Decision tips
Dropping removes data — use when records are unusable. Filling keeps rows but add a flag column if you want to track imputed values. For complex types prefer conditional logic over na.fill to construct appropriate default structures.
Common Mistake
Using na.fill on MapType expecting a scalar fill — instead, build the default map with when or a UDF.
