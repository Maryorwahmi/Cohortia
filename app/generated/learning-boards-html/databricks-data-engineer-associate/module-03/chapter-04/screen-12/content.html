Starter code excerpt
# 1. Extract city
events_with_city = events_df.withColumn('user_city', col('location_info.city'))

# 2. Explode actions safely
from pyspark.sql.functions import explode
non_empty = events_with_city.filter(col('actions').isNotNull())
exploded = non_empty.withColumn('action', explode(col('actions')))

# 3. Deduplicate
dedup = exploded.dropDuplicates(subset=['event_id','user_id','event_timestamp','action'])

# 4. Fill null device
filled = dedup.na.fill({'device': 'Unknown Device'})

# 5. Filter errors and null timestamps
clean = filled.filter((col('event_type') != 'ERROR') & (col('event_timestamp').isNotNull()))
clean.show()
Explanation & checks
  • Compare counts before and after each step to verify expected changes.
  • Keep an original copy to enable audits and debugging.
  • Consider writing invalid or quarantined records to a separate Delta table for inspection.
