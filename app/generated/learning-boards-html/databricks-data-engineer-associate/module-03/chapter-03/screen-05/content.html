Module 3 › Chapter 3.3 › WindowSpec
Process

Define a WindowSpec in three steps

Step 1 — partitionBy
Choose grouping key(s) to isolate independent windows, for example customer_id or product_category.
Step 2 — orderBy
Define deterministic sequence inside partitions, essential for running totals and lead/lag comparisons.
Step 3 — frame
Limit rows using rowsBetween or rangeBetween. Pick narrow frames for moving averages, and unbounded frames for cumulative sums.
Misconception to avoid: leaving out orderBy for time-based metrics yields non-deterministic or meaningless results. Always verify with a small sample when changing frame definitions.
Quick reference
WindowSpec snippets you will use frequently: 
from pyspark.sql.window import Window
window_spec = Window.partitionBy("customer_id").orderBy("order_date").rowsBetween(Window.unboundedPreceding, Window.currentRow)

moving_avg = Window.partitionBy("product_category").orderBy("total_price").rowsBetween(-1, 0)

Which frame would you choose for a three-period moving average? (Hint: rowsBetween(-2, 0)).
