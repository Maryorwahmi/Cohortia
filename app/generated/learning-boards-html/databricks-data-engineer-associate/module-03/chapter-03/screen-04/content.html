Module 3 › Chapter 3.3 › Window Functions
Definition

What a window function is

A window function computes a value for every row using a set of related rows defined by a WindowSpec. It returns results aligned to the original rows, enabling ranking and rolling metrics.

When to use
  • Running totals and cumulative sums.
  • Ranking items within groups.
  • Moving averages and comparisons to previous or next rows.
Common misconception
Window functions do not collapse rows. If you write groupBy expecting row retention, you'll get different results — use window functions instead.
Illustration
Conceptual cards
PartitionBy: groups rows by key, e.g., customer_id. OrderBy: defines row order within partition for sequential metrics. Frame: limits rows considered for each output row, like last 2 rows.
Concrete scenario
Suppose you want each customer's running order total ordered by date. Partition by customer_id, order by order_date, and use a frame from the earliest row to current row for cumulative sum.
Key Takeaway

Window functions compute contextual aggregates per row; use partition, order, and frame to control scope.
