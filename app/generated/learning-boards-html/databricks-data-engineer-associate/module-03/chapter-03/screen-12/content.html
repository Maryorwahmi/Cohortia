Module 3 › Chapter 3.3 › Broadcast Joins
Example
from pyspark.sql.functions import broadcast

small_lookup_data = [("Laptop", "Electronics Corp"), ("Mouse", "Tech Gadgets Inc")]
small_lookup_schema = ["product_name", "manufacturer"]
small_lookup_df = spark.createDataFrame(small_lookup_data, small_lookup_schema)

joined_df = sales_df.join(broadcast(small_lookup_df), on="product_name", how="left")
joined_df.show()
After running this join, call joined_df.explain(True) to view the physical plan and confirm a BroadcastHashJoin is used.
When to avoid
Do not broadcast large tables that cannot fit comfortably in executor memory. Broadcasting large tables causes memory pressure and potential failures.
Check

Confirm broadcast by inspecting the physical plan and monitoring executor memory usage to ensure the small table fits.
