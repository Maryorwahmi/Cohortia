Module 3 › Chapter 3.3 › Ranking & Moving Avg
Example
Below is a runnable snippet demonstrating rank and moving average from the chapter's sales example. Run it in a live coding notebook to see the DataFrame output.
from pyspark.sql.window import Window
from pyspark.sql.functions import col, rank, avg

sales_data = [
  ("Laptop", "Electronics", 1200.00),
  ("Mouse", "Electronics", 25.00),
  ("Keyboard", "Electronics", 75.00),
  ("Desk Chair", "Furniture", 150.00),
  ("Coffee Table", "Furniture", 80.00),
]

sales_schema = ["product_name", "product_category", "total_price"]
sales_df = spark.createDataFrame(sales_data, sales_schema)

window_spec = Window.partitionBy("product_category").orderBy(col("total_price").desc())
ranked_products_df = sales_df.withColumn("rank_in_category", rank().over(window_spec))

moving_avg_window = Window.partitionBy("product_category").orderBy("total_price").rowsBetween(-1, 0)
sales_df.withColumn("moving_avg_price", avg("total_price").over(moving_avg_window)).show()
Tip: orderBy descending for ranking highest first. For time-series running totals, order by a timestamp column instead of price.
Explain
After applying these transformations, call df.orderBy("product_category","rank_in_category").show() to inspect ranking results and ensure partition boundaries are correct.
Key Takeaway

Use WindowSpec with partition and order to compute ranks and local aggregates; verify with small outputs to catch ordering mistakes.
