Example Code
from pyspark.sql.functions import udf
from pyspark.sql.types import StringType

def price_category(price):
  if price < 100:
    return "Budget"
  elif price < 500:
    return "Mid-Range"
  else:
    return "Premium"

price_category_udf = udf(price_category, StringType())
sales_df.withColumn("price_tier", price_category_udf(col("total_price"))).show()
Note the use of show() to confirm the output. If performance becomes a concern, refactor using when and otherwise or a Pandas UDF for vectorized execution.
Performance tip
Benchmark the UDF and compare to native Spark conditionals. Use df.explain() to check for PythonUDF operator placements in the plan.
Pro tip

If many rows share the same input domain, consider joining to a small mapping table instead of running a per-row UDF.
