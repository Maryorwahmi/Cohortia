Definition & Guidance

When and how to use UDFs

UDFs fill gaps in Spark's API, but they add overhead. Prefer built-in functions. If a UDF is required, keep it stateless, compact, and consider vectorized Pandas UDFs for throughput.
  • Prefer native APIs for performance and portability.
  • Python UDFs serialize data across the JVM boundary—measure this cost.
  • Use Pandas UDFs for vectorized operations when appropriate.
Scenario
A business rule needs a custom mapping of price ranges to tiers. A short UDF can implement this, but benchmark it on realistic data and consider vectorization.
Pitfall

Over-using Python UDFs across large datasets creates large serialization overhead and slows down jobs.
