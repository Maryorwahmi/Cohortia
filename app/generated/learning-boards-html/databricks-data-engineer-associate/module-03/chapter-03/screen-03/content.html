Practical checklist
  • Define WindowSpec with partitionBy and orderBy for deterministic results.
  • Prefer built-in functions; fallback to UDFs only when necessary.
  • Cache only after an action forces materialization; unpersist when done.
  • Use broadcast for small lookup tables to avoid shuffles.
