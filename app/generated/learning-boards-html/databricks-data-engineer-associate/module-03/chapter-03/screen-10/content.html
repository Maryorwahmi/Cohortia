Workflow

Cache when reused

Typical steps: compute the DataFrame, call cache or persist with a chosen storage level, force materialization with an action, then use the cached DataFrame for repeated operations. When done, unpersist to release memory.
# Cache and materialize
processed = some_complex_transformations(raw)
processed.cache()
processed.count()  # triggers caching

# use processed for multiple models
# ...

# free memory when done
processed.unpersist()
Storage levels
MEMORY_ONLY, MEMORY_AND_DISK, and other StorageLevel options trade memory usage against disk I/O. Pick one based on cluster memory and dataset size.
Common mistake

Caching everything by default increases memory pressure; instead cache selectively and unpersist promptly.

Mini exercise
Cache a processed DataFrame and measure the runtime of a repeated count before and after caching. Observe the latency difference to confirm caching benefit.
