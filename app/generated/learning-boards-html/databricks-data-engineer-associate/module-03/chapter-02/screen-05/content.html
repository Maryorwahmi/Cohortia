Process
Create DataFrames
Steps for constructing a DataFrame and choosing a schema approach.
1. From Python data
Wrap a Python list of tuples with a StructType schema and call createDataFrame to produce a typed DataFrame.
2. From files
Read CSV or Parquet. Use inferSchema for exploration or provide schema for production reads to avoid surprises.
3. Verify
Call printSchema to confirm names, types, and nullable flags before downstream processing.
Code example
from pyspark.sql.types import StructType, StructField, StringType, IntegerType, DoubleType

data = [
  ("Alice", 30, 170.5),
  ("Bob", 24, 182.1),
  ("Eve", None, 160.0)
]

schema = StructType([
  StructField("name", StringType(), True),
  StructField("age", IntegerType(), True),
  StructField("height_cm", DoubleType(), True)
])

df = spark.createDataFrame(data, schema)
df.printSchema()
df.show()
This pattern enforces types and clearly marks nullable fields. Use explicit schema to defend against sample-based inference errors.
