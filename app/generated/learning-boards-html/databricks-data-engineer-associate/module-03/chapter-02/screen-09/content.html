Comparison
orderBy / sort
When to sort and how to limit cost in distributed settings.
# Order aggregated sales by descending total
final_sales_report = aggregated_sales_df.orderBy(col("total_category_sales").desc())
final_sales_report.show()

# Preview top 5 efficiently
final_sales_report.limit(5).show()
Use limit after orderBy for previews; for large outputs consider partition-aware strategies to reduce shuffles.
Example
Order categories by sales descending to create a top-sellers view for a report.
Misconception
Assuming orderBy is cheap — it's not. Global ordering can be expensive on large datasets.
Pro tip
For top-N lists prefer orderBy then limit to avoid unnecessary full results being transferred to the driver.
