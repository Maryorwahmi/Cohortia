Practice guide
Quick, focused notebook tasks to validate each objective.
Create
Create a DataFrame from a Python list, define an explicit schema, call printSchema and show to confirm types and nullability.
Transform
Select columns, add a derived column using multiplication or concatenation, and drop an old column. Reassign to capture the new DataFrame.
Aggregate
Group by category column and compute count, sum and avg to create a summary DataFrame for reporting.
Finish by calling explain on a transformation chain and then an action such as show or write to observe when Spark executes the plan.
