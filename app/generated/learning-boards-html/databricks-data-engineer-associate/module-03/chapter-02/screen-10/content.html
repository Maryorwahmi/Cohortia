Join patterns
How to join and considerations for accurate and performant joins.
Example
Inner join city_df with departments_df on the name column to produce enriched employee records for downstream reporting.
Performance note
If one side is small, broadcast it to avoid a full shuffle. If both are large, ensure appropriate partitioning or bucketing strategies later in optimization chapters.
Code snippet
# Inner join on name
joined_df = city_df.join(departments_df, on="name", how="inner")
joined_df.show()

# Broadcast small table
from pyspark.sql.functions import broadcast
joined_broadcast = big_df.join(broadcast(small_df), on="id", how="left")
After joining, inspect row counts and sample rows to confirm expected cardinality and detect accidental cartesian growth.
