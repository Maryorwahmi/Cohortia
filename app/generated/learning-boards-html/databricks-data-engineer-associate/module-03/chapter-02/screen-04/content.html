Definition
What is a DataFrame?
A distributed, schema-aware table abstraction with immutable transformations.
Why immutability matters
  • Safe retries and deterministic recomputation after failures.
  • Transforms create logical plans that Catalyst can optimize.
  • Avoids surprises from in-place changes common in local data frames.
Concrete example
Create a DataFrame from a Python list and call printSchema and show to verify structure and nullability.
Common misconception
Do not assume transformations modify in place like Pandas; reassign if you want to keep the new frame reference.
Key Takeaway

Treat DataFrames as immutable, schema-backed plans that you compose with transformations and materialize with actions.
