select • filter • withColumn • drop
Practical chaining pattern and safety reminders.
from pyspark.sql.functions import col, lit

# Start with df from earlier
df2 = df.select("name", "age", "height_cm")
df2 = df2.withColumn("age_in_months", col("age") * 12)
df2 = df2.filter(col("age").isNotNull() & (col("age") > 20))
final = df2.drop("height_cm")
final.show()
This example creates a derived column, filters out nulls or small ages, and drops an unneeded column. Each step returns a new DataFrame until show triggers execution.
Supporting notes
Example
Add a status column with a constant using withColumn and lit("active"). Useful for labeling environments or partitions.
Common mistake
Calling collect to inspect many rows can exhaust the driver. Use show or limit first for safety.
Pro tip
Chain thoughtfully and call explain before heavy actions to let Catalyst optimize the plan.
Key Takeaway

Compose transformations; they are lazy and safe. Reassign to capture results and avoid collect on large frames.
