Introduction to Apache Spark and Spark Architecture

Understand Spark’s motivations, its distributed architecture, and the main data abstractions you’ll use on Databricks. This lesson builds conceptual models you can apply directly when designing pipelines.

Explore Key Topics
Why Spark
Speed with in-memory compute and distributed execution for big data.
Architecture
Driver, Cluster Manager, Executors and how tasks are scheduled across nodes.
Data APIs
RDDs, DataFrames, and Datasets — choose the right abstraction for the job.
Architecture Snapshot
Driver
Orchestrates the application, creating the SparkSession and scheduling tasks.
Cluster Manager
Allocates CPU and memory and launches Executors on worker nodes.
Executors
Run tasks and keep data in memory to accelerate processing.
Quick analogy
A kitchen: head chef plans (Driver), kitchen manager assigns ovens (Cluster Manager), and many cooks prepare partitions of the meal (Executors). The SparkSession is the chef’s control panel.
