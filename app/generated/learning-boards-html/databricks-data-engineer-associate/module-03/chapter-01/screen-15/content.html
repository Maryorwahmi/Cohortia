Module 3 › Chapter 3.1 › Key Concepts — Part 2
RDD
Immutable, low-level distributed collections for fine-grained control.
DataFrame
Structured, column-based API optimized by Catalyst and ideal for PySpark tasks.
Dataset
Typed, object-oriented API for Scala/Java that combines optimization with compile-time safety.
Final takeaway
Choose DataFrames for most Python tasks, consider Datasets for typed Scala/Java workflows, and rely on immutability and lazy evaluation when reasoning about performance and fault tolerance.
