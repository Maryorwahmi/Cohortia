Module 3 › Chapter 3.1 › Learning Objectives — Verify
How to verify each objective
  • Measure in-memory benefits
    Cache a DataFrame and compare runtime to an uncached run to see memory speedups.
  • Inspect cluster components
    Print the SparkSession and consult the Spark UI to view driver and executor metrics.
  • Compare RDD and DataFrame APIs
    Create the same dataset as an RDD and a DataFrame and run aggregations to see differences in expressiveness.
Quick checklist
Print SparkSession, create a simple DataFrame, call printSchema and show, and observe executor counts in the UI.
