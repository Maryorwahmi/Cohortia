Module 3 › Chapter 3.1 › Immutability & Lazy Evaluation
Immutability

DataFrames and RDDs are immutable. Transformations return new objects, enabling Spark to track lineage and recompute lost data for fault tolerance.

Why this matters
No shared mutable state simplifies distributed fault recovery and reasoning about pipeline behavior.
Lazy evaluation

Transformations are recorded and executed only when an action is invoked. This allows Catalyst to optimize across the whole pipeline before running tasks.

Example
Chain multiple filters; Spark will combine them and apply them efficiently during a single pass when an action runs.
Debug tip
Use the explain method to inspect the logical and physical plans before running expensive actions.
