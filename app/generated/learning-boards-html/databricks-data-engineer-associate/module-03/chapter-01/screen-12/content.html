Module 3 › Chapter 3.1 › Pandas vs PySpark
Pandas mindset
Row-oriented, in-place mutation, designed for single-machine workflows.
Pitfall
Looping over Spark DataFrame rows transfers work to the driver and negates Spark’s parallelism.
Spark best practice
Express logic with DataFrame column operations and aggregations so Spark can optimize and run in parallel across executors.
Example
Use withColumn to compute new columns, and groupBy with aggregation for summary statistics, rather than Python loops.
