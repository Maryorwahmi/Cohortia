Starter code (run in a notebook)
# Part 1: Inspect the existing SparkSession
print(spark)
print(spark.conf.getAll())

# Part 2: Create a simple DataFrame
data = [
    ("Alice", 1, "New York"),
    ("Bob", 2, "London"),
    ("Charlie", 3, "Paris"),
    ("David", 4, "New York")
]

schema = ["name", "id", "city"]

# Create the DataFrame
people_df = spark.createDataFrame(data, schema)

# Part 3: Display DataFrame schema and contents
print("DataFrame Schema:")
people_df.printSchema()

print("
DataFrame Contents:")
people_df.show()

# Part 4: Count the number of rows
row_count = people_df.count()
print(f"
Number of rows in people_df: {row_count}")
What to observe
  • Printed SparkSession details and configuration map.
  • DataFrame schema output from printSchema.
  • Rows shown by show and final count from count.
Avoid this mistake
Do not iterate row-by-row to compute aggregates; use DataFrame aggregations to leverage parallelism.
