Module 3 › Chapter 3.1 › Activity: Create DataFrame
Step-by-step
  1. Print the SparkSession and check spark.conf if needed.
  2. Define a list of tuples and a schema list of column names.
  3. Call spark.createDataFrame(data, schema) to build the DataFrame.
  4. Use printSchema and show to inspect, then count to trigger execution.
Safety note
Do small samples or limits when exploring large datasets to avoid driver memory pressure.
Reflection
How would this pattern change when scaling to millions of rows? Consider partitioning and executor sizing.
