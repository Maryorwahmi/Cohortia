Architecture Overview
A Spark application coordinates distributed work through a Driver, a Cluster Manager, and Executors. These components transform a user program into parallel tasks and execute them on partitions of data.
Driver Program
Runs the main program, creates the SparkSession, and schedules stages and tasks.
Cluster Manager
Allocates resources with YARN, Mesos, Kubernetes, or Databricks-managed clusters.
Executors
Execute tasks, store cached partitions in memory, and report metrics to the Driver.
Partitioning & Tasks
The Driver divides a job into stages and each stage into tasks. Executors run tasks on data partitions in parallel. Proper partition sizing and executor configuration reduce stragglers and improve throughput.
Pro tip
Match number of partitions to executor cores for balanced parallelism; use the Spark UI to identify skew and adjust partitioning strategies.
Scenario
If one executor processes much more data than others, that executor becomes a straggler and slows the whole job. Repartition or tune data skew to fix it.
