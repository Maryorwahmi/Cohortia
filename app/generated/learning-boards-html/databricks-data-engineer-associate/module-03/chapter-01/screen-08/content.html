Module 3 › Chapter 3.1 › SparkSession
Definition

SparkSession is the entry point for interacting with Spark functionality: reading data, creating DataFrames, running SQL, and managing configuration for the application.

Why it matters
It centralizes settings that influence planning and execution and provides the read/write APIs to external storage formats used in data engineering.
Databricks note
In Databricks notebooks the SparkSession named spark is pre-initialized. That lets you immediately create DataFrames and inspect configuration without manual setup.
Example
Use spark.read to load Parquet or Delta files, or spark.createDataFrame to create a DataFrame from a list of rows.
Common mistake
Assuming spark is a lightweight convenience: it is the Driver's main handle for configuration and execution planning, so changes here affect job behavior.
