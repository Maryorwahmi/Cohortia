Module 3 › Chapter 3.1 › Why Apache Spark?
Definition

Apache Spark is a distributed processing engine that emphasizes in-memory computation and a unified set of APIs to process big data efficiently.

In-memory speed
Cache intermediate data to avoid repeated disk IO for iterative tasks.
Unified APIs
High-level DataFrame APIs and SQL let teams work productively across languages.
Parallel execution
Distribute tasks across executors to leverage cluster resources.
Optimizations
Catalyst optimizer rewrites logical plans for efficient execution.
Example
When tuning a model that repeatedly computes the same aggregations, caching the transformed DataFrame avoids repeated costly scans and speeds up iterations.
Common misconception

Treating Spark like a single-node library and iterating row-by-row defeats parallelism and can cause poor performance or memory errors. Use declarative DataFrame operations instead.

Key takeaway
Key Takeaway

Spark is most valuable for large, parallel, and iterative workloads where in-memory execution and optimizer-driven plans reduce runtime.
