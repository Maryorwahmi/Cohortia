Apache Spark
A distributed, in-memory compute engine for big data workloads.
SparkSession
Unified entry point to create DataFrames, run SQL, and manage config; available as spark in Databricks.
Driver Program
Runs the main program, creates the SparkSession, and orchestrates scheduling of tasks and stages.
Summary
These three terms are the foundation for understanding how your code becomes distributed work on Databricks.
