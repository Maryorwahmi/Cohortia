Cluster sizing and auto-scaling

Pick sizes and autoscale bounds that match workload patterns to optimize cost and throughput.

Interactive
Small clusters, auto-terminate after inactivity for developer cost savings.
Batch
Right-size base workers and allow autoscale for bursts to reduce runtime without permanent cost.
Spot instances
Use for fault-tolerant jobs to reduce compute cost; monitor preemptions and retries.
Action

Set conservative min/max autoscale bounds, observe behavior under load, then tune to balance cost with performance.
