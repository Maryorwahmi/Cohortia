A safe profiling workflow

  1. Record baseline: explain plan, scanned bytes, shuffle read/write, task durations.
  2. Apply one targeted optimization based on the plan: cache, broadcast, tune partitions, or OPTIMIZE/ZORDER.
  3. Re-run and compare the same metrics; document results and rollback if negative.
Pitfalls
Applying many changes at once, ignoring memory metrics, or running VACUUM without verifying retention
Checklist
Explain before, apply one change, explain after, compare metrics, and save artifacts for auditing.
