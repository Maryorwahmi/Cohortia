Delta Lake › Chapter 6.2 › VACUUM
Definition

VACUUM removes unreferenced files

Reclaim storage by deleting files older than the retention threshold that are not referenced by the current table version.

Governance note
VACUUM is irreversible for removed versions; set retention to match recovery SLAs and compliance.
SQL Example
VACUUM delta.`/mnt/delta/sales_data` RETAIN 168 HOURS; -- Retain 7 days
Key Takeaway

VACUUM saves storage costs but requires careful retention planning to preserve recoverability.

Warning
Do not shorten retention without verifying backups and recovery requirements.
