Delta Lake › Chapter 6.2 › OPTIMIZE & Small Files
Definition

OPTIMIZE coalesces small files

Reduce the number of files and metadata overhead by compacting data into larger files.

When to run
After many small writes or streaming micro-batches; schedule as a maintenance job to balance cost.
SQL Example
-- Optimize a table to reduce small-file overhead
OPTIMIZE delta.`/mnt/delta/sales_data`
Key Takeaway

OPTIMIZE lowers file count and speeds queries that otherwise scan many small files.

Real-world check
Compare scanned file counts and latency for representative queries before and after OPTIMIZE.
