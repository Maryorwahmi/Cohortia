Module 6 › Chapter 6.2 › Broadcast Joins
Process

Broadcast the small table to every executor

Use broadcast for small lookup tables to avoid shuffles on the large table.

When to use
  • Small dimension tables used in joins with large fact tables.
  • When eliminate shuffle significantly reduces job time.
  • When the small table fits comfortably in executor memory.
Code Example
from pyspark.sql.functions import broadcast

large_transactions_df = spark.read.format("delta").load("/mnt/delta/transactions")
small_products_df = spark.read.format("delta").load("/mnt/delta/products")

joined_df = large_transactions_df.join(broadcast(small_products_df), "product_id")
joined_df.display()
Check

Inspect df.explain() to ensure Exchange steps are removed for this join.

Pitfall
Broadcasting a large table causes memory pressure; do not over-broadcast.
