Delta Lake › Chapter 6.2 › Z-ordering
Definition

Co-locate related values for faster filters

Z-ordering arranges data so related values on chosen columns are stored together, reducing reads for targeted filters.

When to Z-order
When queries frequently filter on the same small set of columns across partitions.
SQL Example
OPTIMIZE delta.`/mnt/delta/sales_data` ZORDER BY (transaction_date, product_id);
Key Takeaway

Z-order targeted columns to shrink scanned files for those queries; validate impact with EXPLAIN.

Misconception
Z-ordering every column will not help and may degrade other query patterns.
