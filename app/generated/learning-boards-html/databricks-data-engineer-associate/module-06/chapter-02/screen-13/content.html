15-minute live coding script

Follow these steps in a notebook or terminal to convert a slow job into a tuned workflow.

Step 1 — Diagnose
Run df.explain(), note Exchanges, scanned files, and shuffle sizes in Spark UI.
Step 2 — Quick fixes
Apply broadcast hints and set spark.sql.shuffle.partitions, then re-run explain and measure timing.
Step 3 — Delta optimizations
Run OPTIMIZE with ZORDER on frequent filter columns and compare scanned bytes after.
Step 4 — Clean up
Run VACUUM with a retention that matches recovery needs to reclaim storage.
Reflection

After the demo, identify the single change that gave the largest latency reduction and consider why it worked for that workload.
