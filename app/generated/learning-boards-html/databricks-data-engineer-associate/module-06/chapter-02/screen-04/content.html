Module 6 › Chapter 6.2 › Caching DataFrames
Definition

Cache stores computed partitions for reuse

Avoid recomputing expensive transformations by materializing partitions in memory or on disk.

When to cache
  • Dataset used multiple times in the same job or notebook.
  • Expensive joins, filters, or aggregations that are repeated.
  • Iterative algorithms that revisit the same partitions.
Common mistake
Caching everything by default, which can cause memory exhaustion and excessive disk spill.
Code Example
# Example of caching (PySpark)
df = spark.read.format("delta").load("/mnt/delta/sales_data")
df.cache()  # Cache the DataFrame
df.count()  # First action triggers computation and caching

filtered_df = df.filter("region = 'North'")
filtered_df.display()

# When finished
df.unpersist()
Key Takeaway

Cache only when reuse is frequent and memory cost is acceptable; unpersist promptly.

Check your work
Compare runtimes and executor memory usage before and after caching.
