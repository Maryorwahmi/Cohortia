Code Walkthrough

Use explain to guide changes

# Extended plan in PySpark
df = spark.read.format("delta").load(delta_path)
filtered = df.filter("event_date = '2023-06-01' AND user_id = 500")
filtered.explain(True)  # Extended plan with statistics
Look for
  • Exchange lines (shuffles) — expensive network operations.
  • Filter pushdown — filters applied early reduce IO.
  • Scan and DataFilters — show what Spark will read from storage.
Example Workflow
  1. Run explain on the original query and note Exchanges and scanned files.
  2. Apply a targeted change: broadcast hint, change shuffle partitions, or OPTIMIZE/ZORDER.
  3. Run explain again and compare; validate with Spark UI metrics.
Key Takeaway

Let the plan reveal where to optimize. Confirm changes by re-running explain and checking runtime metrics.
