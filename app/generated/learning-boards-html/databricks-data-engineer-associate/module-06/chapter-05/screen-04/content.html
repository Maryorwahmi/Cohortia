Module 6 › Chapter 6.5 › Audit & Diagnostic Logs
Definition

Audit logs: immutable records for investigations

Audit logs record user and admin actions across the workspace: sign-ins, privilege changes, cluster and job activity, and data access events. Because they show who did what and when, auditors rely on them to demonstrate compliance and support incident response.

Captured Events
  • User logins and authentication events
  • Cluster and notebook activity
  • Privilege and ACL changes
Diagnostic Logs
  • Cluster lifecycle and driver logs
  • Job run details and API calls
  • Useful for troubleshooting and context
Key Takeaway

Collect both audit and diagnostic logs to a centralized, access-controlled location. Use the combination for faster incident response and compliance evidence.

Process

Centralize and protect your logs

  1. Enable audit and diagnostic log delivery in the workspace.
  2. Route logs to your cloud logging service or storage with restricted access.
  3. Integrate with a SIEM for alerting, correlation, and long-term retention.
Example & Misconception

Example: Configure your Databricks workspace to send audit logs to Azure Monitor Log Analytics and diagnostic logs to a secure Storage Account. Misconception: "Diagnostic logs aren't useful for security." In truth, they provide context that accelerates incident investigations and should not be discarded.
