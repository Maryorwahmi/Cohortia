Configure & Analyze Logs
Set up audit and diagnostic log delivery to your cloud logging service. This lets you retain evidence, run queries, and integrate alerts into a SIEM for investigations.
Mnemonic: Log → Store → Analyze
VERIFIED COMPETENCY MILESTONE
02
Support Compliance Standards
Describe how Unity Catalog, encryption, VNet injection, and audit trails address GDPR, HIPAA, and SOC 2 requirements so you can map platform features to controls.
Mnemonic: Map controls → Evidence
VERIFIED COMPETENCY MILESTONE
03
Implement Secrets Management
Create secret scopes, assign ACLs, and retrieve secrets at runtime so credentials are never hardcoded in notebooks or logs.
Mnemonic: Scope → ACL → Inject
VERIFIED COMPETENCY MILESTONE
04
Integrate Identity Providers
Use SAML or OIDC for SSO and SCIM for provisioning so user lifecycle and authentication are centralized and auditable.
Mnemonic: Authenticate → Provision
VERIFIED COMPETENCY MILESTONE
How to use these objectives
  • Each milestone maps to a hands-on configuration or verification task you can perform in your workspace.
  • Start by capturing logs and verifying they land in your cloud logging service, then implement secrets and test retrieval without exposing values.
  • Finish by wiring SSO and SCIM, and produce a short audit report that maps features to regulatory requirements.
