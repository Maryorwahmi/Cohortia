Module 6 › Chapter 6.5 › Compliance Standards
GDPR

Control and trace PII

  • Unity Catalog: column-level security and lineage to find and control PII.
  • Audit logs: records of processing activities required by GDPR.
  • VACUUM: enforce retention and data deletion policies.
HIPAA

Protect PHI

  • Network isolation: VNet injection and Private Link keep traffic private.
  • Encryption: at rest and in transit, with support for customer-managed keys for key control.
  • Access controls and audit trails to show who accessed PHI and when.
SOC 2

Controls & evidence

  • Audit trails and log retention support the security principle of SOC 2.
  • Platform practices like secure development and penetration testing support availability and integrity controls.
  • Unity Catalog centralizes governance and access controls across data assets.
Key Takeaway

No single feature proves compliance. Build a control map that pairs regulatory requirements with platform features, process controls, and retained evidence.
