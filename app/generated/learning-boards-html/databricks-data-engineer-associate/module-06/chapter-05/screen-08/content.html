Module 6 › Chapter 6.5 › SSO & SCIM Integration
Concept

SSO for authentication, SCIM for provisioning

SSO delegates authentication to your IdP via SAML or OIDC. SCIM automates user and group lifecycle so Databricks permissions reflect your directory state automatically.

Benefits
  • Reduced manual provisioning and fewer stale accounts
  • Consistent authentication and centralized session control
  • Auditability of user lifecycle events
Integration checklist
  1. Configure SAML or OIDC in Databricks and test authentication flow.
  2. Enable SCIM provisioning and map IdP groups to Databricks groups or roles.
  3. Test provisioning, updates, and deprovisioning with a sample user and group.
  4. Ensure SCIM activity is covered in audit logs for evidence.
Common Pitfall

Relying on SSO without SCIM leaves manual provisioning gaps. Combine both to ensure immediate revocation and consistent access mapping.

Scenario Card

Scenario: an engineer changes role. SCIM updates group membership, which immediately changes Databricks permissions; audit logs capture the change for review.
