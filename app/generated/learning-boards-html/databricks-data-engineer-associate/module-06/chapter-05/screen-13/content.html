Module 6 › Chapter 6.5 › Unity Catalog & Governance
Unity Catalog Capabilities
Centralized metadata, consistent access controls, and lineage for audits.
Fine-grained Access
Define permissions down to tables and columns so PII is only visible to authorized roles.
Lineage
Track data flows to support GDPR data subject requests and compliance reporting.
Operational Practices
  • Quarterly access reviews and role cleanups.
  • Annual penetration tests and remediation plans.
  • Ongoing security training tailored to user roles.
Governance Workflow
  1. Register assets in Unity Catalog with metadata tags for sensitivity.
  2. Assign least privilege roles and record ACL changes in audit logs.
  3. Run periodic audits and schedule training for teams handling sensitive data.
Key Takeaway

Effective governance blends Unity Catalog's controls with audits, testing, and user education to produce demonstrable compliance.
