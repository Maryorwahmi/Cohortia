Isolation Patterns
How VNet injection and Private Link work together
Architecture
VNet Injection
Place workspace network interfaces inside your VNet for private compute networking.
Private Link
Create private endpoints so control plane and storage traffic stays on private network paths.
Testing Checklist
  • Validate no public egress for data traffic.
  • Confirm DNS resolves to private endpoints.
  • Verify log delivery and SIEM connectivity over private paths.
Common Pitfall
Forgetting to secure management endpoints or failing to test third-party integrations can reintroduce public egress despite VNet injection.
Example: PHI Processing
A healthcare team configures VNet injection so clusters run in a private subnet. Private Link endpoints connect to storage and the control plane, preventing any traffic from leaving the private network. Combined with access controls and CMK encryption, this supports HIPAA-sensitive processing.
Key Takeaway

Network isolation is foundational — verify private paths end-to-end and test integrations for private connectivity.
