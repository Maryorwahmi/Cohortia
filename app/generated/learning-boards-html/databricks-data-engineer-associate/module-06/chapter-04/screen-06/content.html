Module 6 › Chapter 6.4 › Column-level ACLs vs Table-level grants
Comparison summary
Table-level SELECT
Grants read access to all columns in the table. Use when group needs full dataset for analysis.
Column-level SELECT
Grants read access to a specific list of columns. Use to protect PII or sensitive fields.
Practical scenario
marketing_analysts get SELECT on the table; junior_analysts get SELECT(customer_id, name, segment) only.
Concrete example
-- Full table access
GRANT SELECT ON TABLE marketing.customer_profiles TO `marketing_analysts`;

-- Column-level access (exclude email)
GRANT SELECT (customer_id, name, segment) ON TABLE marketing.customer_profiles TO `junior_analysts`;

-- Verify
SHOW GRANTS ON TABLE marketing.customer_profiles;
Misconception: column ACLs automatically remove broader grants. Unity Catalog enforces the most restrictive effective permission, so design grant strategy intentionally.
