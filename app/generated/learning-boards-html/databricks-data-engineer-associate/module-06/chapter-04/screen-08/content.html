Module 6 › Chapter 6.4 › Lineage and Auditing
Data Lineage
Lineage shows how data moves through transformations. Unity Catalog captures lineage for Spark operations so you can trace derived tables back to their sources and see the operations applied.
Use case
If a report is wrong, follow the lineage graph to find the transformation that introduced the error, such as an incorrect join condition or filter.
Audit Logs
Audit records capture who accessed which data and when. These logs are essential for security monitoring, compliance reporting, and incident analysis. They can be exported to external monitoring systems when needed.
Compliance note
Use audit logs as evidence for compliance frameworks and to investigate unauthorized access.
Key Takeaway

Lineage helps you find where bad data was introduced. Audit logs tell you who accessed or changed data and when.
