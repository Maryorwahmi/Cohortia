Verification steps
  1. Create: Create catalog and schema in Unity Catalog-enabled workspace.
  2. Populate: Create a sample table with sensitive columns such as email.
  3. Assign: Grant SELECT to analyst group and column-level SELECT to junior group.
  4. Confirm: Run SHOW GRANTS on the table to see both full-table and column-level grants.
Mnemonic strip: Create, Assign, Confirm — CAC
Practical note
Permissions inherit downward. A grant on a catalog flows to schemas and tables unless an explicit override is applied. Use this behavior to reduce repetitive grants, but be cautious: inheritance can accidentally broaden access if you are not explicit with fully qualified names.
