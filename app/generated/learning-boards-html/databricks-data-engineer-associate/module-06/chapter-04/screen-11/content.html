Module 6 › Chapter 6.4 › Assessment scenario
Task summary
Grant a data steward rights to create schemas and tables in the finance catalog, and give a data scientist read access to transactions but prevent access to credit_card_number.
Correct high-level steps: create groups, grant CREATE SCHEMA and CREATE TABLE on the finance catalog to the steward group, grant SELECT on the finance.transactions schema to the data scientists group, then grant SELECT on allowed columns of the payments table or revoke the sensitive column for that group. Verify with SHOW GRANTS.
Example commands
-- For Data Steward
GRANT CREATE SCHEMA ON CATALOG finance TO `data_stewards_group`;
GRANT CREATE TABLE ON CATALOG finance TO `data_stewards_group`;

-- For Data Scientist (restrict credit_card_number)
GRANT SELECT ON SCHEMA finance.transactions TO `data_scientists_group`;
-- Restrict sensitive column by granting explicit allowed columns
GRANT SELECT (transaction_id, customer_id, amount, transaction_date) ON TABLE finance.transactions.payments TO `data_scientists_group`;
