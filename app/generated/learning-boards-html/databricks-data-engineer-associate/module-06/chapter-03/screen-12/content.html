Module 6 › Chapter 6.3 › Data Encryption
At rest
Databricks encrypts stored data by default. For stricter control, supply customer-managed keys stored in your cloud key vault to manage key rotation and access policies.
In transit
All communication between the browser, control plane, and cluster nodes uses TLS/SSL, ensuring that data traveling across networks is encrypted against interception.
Key Takeaway

Treat encryption as one layer in a defense-in-depth strategy. Combine encryption with strict identity, ACLs, and private networking for strong protection.
