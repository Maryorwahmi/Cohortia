Module 6 › Chapter 6.3 › Key Concepts
Users & Groups
Group-based permissions scale better than individual assignments and support least privilege.
Table ACLs
Use GRANT and REVOKE to control SELECT and MODIFY; enforce via cluster settings.
Service Principals
Use non-human identities for automation and grant them narrowly scoped privileges.
Credential Passthrough
Use when per-user storage auditability and eliminating shared secrets are required.
VNet / Private Link
Use VNet injection and Private Link to keep traffic private on the cloud backbone and meet network policies.
Encryption
Data is encrypted at rest by default; use customer-managed keys for extra control. TLS protects data in transit.
Keep this checklist handy: model identities, apply ACLs with verification, enable passthrough where needed, and design private networking for sensitive workloads.
