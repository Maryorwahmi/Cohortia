Module 6 › Chapter 6.3 › Table Access Control Lists
SQL examples
Use these SQL commands to manage grants. They are the canonical way to set table ACLs in Databricks.
-- Grant SELECT permission on a specific table to a group
GRANT SELECT ON TABLE default.sales_data TO `data_analysts_group`;

-- Grant ALL PRIVILEGES on a database to a service principal
GRANT ALL PRIVILEGES ON DATABASE production_db TO `service_principal_etl_job`;

-- Revoke a permission
REVOKE MODIFY ON TABLE default.customer_pii TO `data_scientists_group`;

-- Show current grants
SHOW GRANTS ON TABLE default.sales_data;
Practical notes
  • 1. ACLs apply to data objects like tables and databases and can grant SELECT or MODIFY among other actions.
  • 2. MODIFY typically implies INSERT, UPDATE, DELETE, MERGE, and similar privileges—grant carefully.
  • 3. Use SHOW GRANTS to verify what permissions exist on an object after you change them.
  • 4. If a cluster's Table Access Control is not enabled, granted permissions will not be enforced.
Key Takeaway

Table ACLs are powerful but dependent on cluster enforcement. Always verify enforcement by testing under different identities.
