Starter code (Notebook)
Run these commands in a Databricks notebook. The example includes table creation, inserts, grants, and verification.
# --- Step 2: Create a sample Delta table
print("Creating sample finance_data_cohortia table...")
spark.sql("CREATE DATABASE IF NOT EXISTS security_demo_db")
spark.sql("USE security_demo_db")
spark.sql("""
  CREATE TABLE IF NOT EXISTS finance_data_cohortia (
    transaction_id INT,
    amount DOUBLE,
    currency STRING,
    transaction_date DATE
  ) USING DELTA
""")
spark.sql("""
  INSERT INTO finance_data_cohortia VALUES
  (1, 100.50, 'USD', '2023-01-15'),
  (2, 250.75, 'EUR', '2023-01-16'),
  (3, 50.00, 'USD', '2023-01-15')
""")
print("finance_data_cohortia table created and populated.")

# --- Grant permissions
spark.sql("GRANT SELECT ON TABLE security_demo_db.finance_data_cohortia TO `finance_analysts_cohortia`")
spark.sql("GRANT MODIFY ON TABLE security_demo_db.finance_data_cohortia TO `data_engineers_cohortia`")

# --- Verify grants
spark.sql("SHOW GRANTS ON TABLE security_demo_db.finance_data_cohortia").display()
Guided checks
  • 1. Ensure the cluster used for testing has Table Access Control enabled; otherwise enforcement will not occur.
  • 2. After running SHOW GRANTS, confirm SELECT and MODIFY entries appear for the expected groups.
  • 3. If possible, test using a separate user account to confirm expected permission denied errors for unauthorized operations.
Key Takeaway

Hands-on verification is essential: grants are only meaningful if cluster enforcement exists and tests confirm expected behavior under different identities.
