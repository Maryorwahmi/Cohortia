Scenario: Sarah and ETL job
Create data_analysts_group for Sarah and grant SELECT on reporting_db. For the ETL, create a service principal and grant INSERT only on the sales_transactions table. Enable Table Access Control on clusters used for these operations.
Verification steps
  1. Run SHOW GRANTS on the database and table to view active permissions.
  2. Test SELECT as Sarah's account to confirm read access and test INSERT as the ETL service principal to confirm write access.
  3. Check storage logs when using credential passthrough to confirm user-level auditing.
Reflection

When you design permissions, always include a short verification plan so you can prove enforcement and detect misconfigurations early.
