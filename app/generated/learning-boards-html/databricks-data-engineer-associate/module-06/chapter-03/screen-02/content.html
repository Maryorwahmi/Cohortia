Learning Objectives
Bloom path: Learn → Understand → Apply → Master
01 Manage Identities
Create and organize users, groups, and service principals to model human and non-human identities for your workspace. This matters because it enables least privilege and centralized permission management.
VERIFIED COMPETENCY MILESTONE
02 Table ACLs
Grant and revoke SELECT and MODIFY privileges on tables and databases using SQL. Verify enforcement by checking grants and by testing actions under different identities.
VERIFIED COMPETENCY MILESTONE
03 Credential Passthrough
Enable passthrough to use each user's cloud identity for ADLS Gen2 access, removing shared secrets and producing auditable access logs.
VERIFIED COMPETENCY MILESTONE
04 Network & Encryption
Explain VNet injection and Private Link for private connectivity and choose encryption options including customer-managed keys for extra control.
VERIFIED COMPETENCY MILESTONE
