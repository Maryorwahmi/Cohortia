Module 6 › Chapter 6.3 › How you'll demonstrate mastery
Verification checklist
Identity
Create groups and add users. Confirm membership in the Admin Console and practice least privilege when assigning roles.
Table ACLs
Run GRANT/REVOKE and SHOW GRANTS. Observe enforcement when clusters have Table Access Control enabled.
Credential Passthrough
Enable passthrough on a cluster and read data from ADLS Gen2 to confirm access is logged under your cloud identity.
Common pitfall
Creating grants without enabling Table Access Control on the cluster will leave data unprotected. Always confirm cluster settings.
