Definition

Alerts and Exported Metrics

Basic in-platform alerts on success/failure or duration are useful, but exporting to observability systems provides richer thresholds, trend analysis, and notification routing.
Practical alert
Alert when a daily job’s runtime exceeds twice its historical average to detect regressions quickly.
Export targets
Export logs and metrics to monitoring tools to build dashboards and set advanced alerts.
Checklist
  • Decide which metrics to alert on (job duration, cluster CPU, driver OOM).
  • Include context in alerts (run id, job name, cluster name).
  • Test alert delivery by simulating a threshold breach.
Key Takeaway

Design alerts to be actionable and test them. Export to monitoring systems for trend detection and richer notification options.
