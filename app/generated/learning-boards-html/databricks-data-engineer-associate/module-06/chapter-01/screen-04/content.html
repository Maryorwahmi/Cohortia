Module 6 › Chapter 6.1 › Databricks Workspace UI
Definition

Jobs, Clusters, Query History

The Workspace UI lists runs and cluster health, exposing logs you need for first-pass diagnosis.

Jobs
Run history, durations, success/failure, and links to driver/executor logs for the selected run.
Clusters
Cluster state, CPU/memory metrics, attached notebooks, and restart/terminate controls for operations.
Query History
Interactive query list with duration and user details for debugging slow ad-hoc queries.
Concrete Example
You find a failing nightly ETL. The Jobs page shows several recent failures. Open the latest run and scan the driver log for an exception line that indicates why the job failed—often a stack trace or a custom logging message added in your notebook.
Common mistake

Assuming workspace logs always show per-task metrics. They show aggregated driver/executor output; for per-task timing, use the Spark UI.

Key Takeaway

Start at Workspace UI to locate the run and the logs, then escalate to Spark UI for task-level analysis.
