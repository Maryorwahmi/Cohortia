Module 6 › Chapter 6.1 › Learning Objectives — Applied
Verification Steps
  1. Databricks UI: Open Jobs → select run → inspect Logs for custom INFO messages and stack traces.
  2. Spark UI: Open application → Stages tab → sort by duration and inspect shuffle spill metrics for hotspots.
  3. Logging: Add logging.info calls showing record counts; run and confirm messages appear in driver logs.
  4. Alerting: Create a duration threshold; test by running a job longer than the threshold to ensure alert triggers.
Check your understanding
Can you find the stage that causes the most shuffle? Can you find a log line that shows the number of records processed?
Practice Tip

Start with a failing run and use the Spark UI's Stages and Executors tabs to pinpoint a single cause you can fix in code or configuration.
