Module 6 › Chapter 6.1 › Key Concepts
Databricks UI
Web interface for Jobs, Clusters, Query History and initial logs.
Spark UI
Detailed tabs for Jobs, Stages, Tasks, Executors and Storage.
Spark Event Logs
Chronological events for post-mortem analysis and timeline reconstruction.
Driver / Executor Logs
Application output and custom logs viewable in the run's Logs tab.
Custom Logging
Use logging libraries to emit structured, contextual messages for troubleshooting.
Alerting
Notify teams when failures or performance deviations occur, tuned to avoid noise.
Summary

Triage with the Workspace UI, diagnose with the Spark UI and event logs, add context with custom logs, and close the loop with alerting.
