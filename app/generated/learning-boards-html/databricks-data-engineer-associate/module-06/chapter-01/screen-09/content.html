Module 6 › Chapter 6.1 › Starter Script — Fail Fast
Starter Code
from pyspark.sql import SparkSession
from pyspark.sql.functions import rand
import logging

spark = SparkSession.builder.appName("SparkUIMonitoring").getOrCreate()
logging.basicConfig(level=logging.INFO, format='%(asctime)s - %(levelname)s - %(message)s')

num_records = 10000000
logging.info(f"Creating a DataFrame with {num_records} records.")
large_df = spark.range(num_records).withColumn("random_value", rand() * 1000)

logging.info("Attempting to collect large DataFrame to driver. This might cause issues.")
try:
  collected_data = large_df.collect()
  logging.info(f"Successfully collected {len(collected_data)} records.")
except Exception as e:
  logging.error(f"Failed to collect data: {e}")
  print(f"Failed to collect data: {e}")

logging.info("Job finished.")
Activity Steps
  1. Run the script on a cluster and observe the job in Databricks Jobs.
  2. Open the Spark UI from the run and inspect Stages and Executors.
  3. Identify the stage tied to collect and confirm driver memory pressure in Executors.
  4. Change collect to a distributed aggregation and re-run to confirm the fix.
Key Takeaway

Reproducing a failure in a controlled way teaches you where the UI points and what concrete code changes remove the root cause.
