VACUUM: Dry run vs Permanent delete
Understand the difference and follow a safe maintenance workflow.
Dry run
Lists files that would be removed; non-destructive and recommended as a first step.
Permanent delete
Removes files permanently if retention criteria are met. This action is irreversible for those files.
Maintenance checklist
  • Run DRY RUN and inspect file list.
  • Verify files are not referenced by desired historical versions.
  • Confirm retention exceeds long-running queries and audit windows.
  • Schedule actual VACUUM after approvals.
Key Takeaway
Treat VACUUM as a controlled maintenance step: dry run, inspect, and then delete when it's safe.
