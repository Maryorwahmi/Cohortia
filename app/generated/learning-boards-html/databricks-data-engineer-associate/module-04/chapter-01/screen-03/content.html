Learning Objectives — Practical Skills
Concrete tasks you can run in a sandboxed Databricks environment.
Create and modify Delta tables

Run create, insert, update, delete, and merge commands to generate table versions.

Inspect history and versions

Use DESCRIBE HISTORY to find version numbers and timestamps for time travel and restore actions.

Use time travel and restore

Run versioned and timestamped selects and practice RESTORE TABLE to revert to earlier states during recovery drills.

Run VACUUM safely

Always run VACUUM with DRY RUN first, interpret file lists, and set retention beyond long queries and audit windows.
