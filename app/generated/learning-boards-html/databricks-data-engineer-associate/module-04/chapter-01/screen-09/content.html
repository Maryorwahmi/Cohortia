Definition
RESTORE TABLE — rolling back to a prior version
Use after identifying a safe version; restore creates an auditable commit that reverts the active snapshot.
Example SQL
-- Restore to a known version
RESTORE TABLE my_delta_table TO VERSION AS OF 4;

-- Or restore by timestamp
RESTORE TABLE my_delta_table TO TIMESTAMP AS OF '2023-10-25';
Checklist before restoring
  • Confirm the target version exists in DESCRIBE HISTORY.
  • Ensure target files are still available and not removed by VACUUM.
  • Coordinate with downstream consumers to avoid surprise data regressions.
Why coordinate
A restore changes the active dataset for all readers; downstream jobs may need replay or reconciliation.
