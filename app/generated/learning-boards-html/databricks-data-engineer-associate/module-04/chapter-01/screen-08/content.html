Definition
Time Travel queries — examples
Practical queries to reproduce prior table states for auditing and comparison.
Examples
-- Query by timestamp
SELECT * FROM my_delta_table TIMESTAMP AS OF '2023-10-26 10:00:00';

-- Query by version
SELECT * FROM my_delta_table VERSION AS OF 5;
Concrete scenario
You discover a downstream metric was computed against the dataset at version 7. Use VERSION AS OF 7 to reproduce the metric exactly for investigation.
Retention note
Time travel depends on historical files being retained. VACUUM can remove files once their retention window expires.
Key Takeaway

Time travel gives exact historical views, but only while the files for those versions remain available.
