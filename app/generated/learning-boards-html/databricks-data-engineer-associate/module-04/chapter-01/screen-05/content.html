Definition
The Delta transaction log
A ledger of commits that maps each version to the set of data files that implement it.
How it works
  • Each operation writes a commit JSON describing added and removed files.
  • Commits are ordered; the latest commit defines the current snapshot.
  • Readers reconstruct the snapshot by reading file pointers referenced by the commit.
Example: Inspect history
DESCRIBE HISTORY my_delta_table;
This command lists commits with version numbers and timestamps that you can use for time travel.
Analogy
Think of the log as a table of contents that points to which files compose each version. The contents are immutable once published.
Quick fact
The log stores file-level metadata, not full row deltas, keeping it compact and efficient for versioning.
Key Takeaway
The transaction log is the authoritative source that enables snapshots, time travel, and atomic commits.
