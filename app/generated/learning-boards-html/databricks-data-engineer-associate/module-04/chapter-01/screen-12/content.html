Hands-on Activity
Create table, update, and inspect history
Follow these steps in a sandbox to generate versions and practice time travel.
Starter SQL
CREATE TABLE IF NOT EXISTS sales_data (
  id INT,
  product STRING,
  quantity INT,
  price DOUBLE
) USING DELTA;

INSERT INTO sales_data VALUES (1, 'Laptop', 2, 1200.00);
INSERT INTO sales_data VALUES (2, 'Mouse', 5, 25.00);

-- Check history
DESCRIBE HISTORY sales_data;

-- Update to create a new version
UPDATE sales_data SET price = 1250.00 WHERE id = 1;

-- Inspect versions again
DESCRIBE HISTORY sales_data;

-- Time travel to prior version (replace N with the earlier version number)
SELECT * FROM sales_data VERSION AS OF N;
Safety tips
  • Perform this activity in an isolated workspace or sandbox.
  • Run VACUUM only after you finish experiments and after a dry run.
  • Keep retention long enough to examine history for at least the duration of the exercise.
Key Takeaway
This sequence teaches how commits create versions, how to inspect those versions, and how to reproduce earlier results for auditing or recovery.
