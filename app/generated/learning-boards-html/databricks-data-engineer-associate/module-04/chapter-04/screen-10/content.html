Module 5 › Chapter 4.4 › Auditing
Definition

Audit logs and export

Audit logs capture access events and permission changes. Teams export these logs for monitoring, long-term retention, and integration with SIEM tools.

Verify grants
SHOW GRANTS ON TABLE sales_catalog.curated.customer_data;
Use this command to review who has access to a table and detect unexpected permissions.
What audits capture
  • Table and column read events with user identity.
  • Permission GRANT and REVOKE actions.
  • Administrative changes to catalogs, schemas, and metastores.
Operational tips
  • Export logs to a SIEM for alerts on abnormal access.
  • Set retention based on compliance requirements.
  • Automate periodic reviews of privileged grants.
Scenario

Investigate a data leak

If a sensitive dataset appears in an external report, use audit logs to find who queried the table and when, and correlate with permission changes to see if a recent grant caused the exposure.

Common mistake

Relying solely on audit logs. Audits tell you what happened; they don't prevent misuse. Keep access controls tight and use audits to validate them.

Key Takeaway

Combine exportable audit logs with proactive access controls and alerting to maintain compliance and respond quickly to incidents.
