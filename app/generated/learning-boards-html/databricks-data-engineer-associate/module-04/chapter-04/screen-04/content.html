Core Concept
Unity Catalog: definition and benefits
Unity Catalog unifies metadata and security so administrators can manage access and auditing in a single metastore.
  • Central metastore holds catalogs, schemas, tables, and views.
  • ANSI SQL GRANT/REVOKE model for familiar access control.
  • Built-in lineage and audit logging for compliance and impact analysis.
Example
Granting SELECT on a catalog to a data_analysts group provides read access to all current and future tables in that catalog, simplifying access management.
Common Mistake
Over-permissioning individuals instead of using groups causes high maintenance and audit risk.
Key Takeaway

Treat Unity Catalog as the single source of truth for cataloging and permission policy; prefer group grants and column-level controls for sensitive data.

Annotated Components
Metastore
Account-level metadata container that workspaces map to.
Catalog / Schema / Table
Logical grouping: catalogs group schemas; schemas group tables and views.
Lineage & Auditing
Captured runtime lineage and access logs support traceability and compliance.
Want to practice? In the lab you will create a catalog and a schema, then a table with a sensitive column and apply column-level grants.
