Definition
Metastore
Account-level metadata container; workspaces map to one metastore.
Catalog
Logical domain grouping; e.g., sales_catalog or marketing_catalog.
Schema
Organizes tables and views within a catalog, such as raw or curated.
Table / View
Actual data objects where data is stored and queried.
How inheritance works
  • Grants on a catalog apply to all schemas and tables inside it, unless overridden.
  • Table-level grants do not grant higher-level permissions on schemas or catalogs.
  • Use schema-level CREATE permissions to allow controlled table creation.
Concrete example
If you grant CREATE TABLE on sales_catalog.raw to data_engineers, they can create new tables in that schema. If you grant SELECT on sales_catalog to data_analysts, they can read curated and raw tables unless explicit restrictions exist.
Key Takeaway

Design catalogs and schemas to reflect business boundaries so inheritance simplifies permission management.

Pitfall
Avoid assuming table grants grant schema access; always test with SHOW GRANTS and a sample query.
