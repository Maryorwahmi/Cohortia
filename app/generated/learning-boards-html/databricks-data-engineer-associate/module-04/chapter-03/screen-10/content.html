Caching options
Delta cache for disk-level local SSD caching; CACHE TABLE for in-memory caching in Spark executors.
- Delta cache reduces remote storage I/O by caching on local SSDs.
- CACHE TABLE stores data in memory for fast repeated access, ideal for small lookup datasets.
- Monitor memory and disk usage; uncache when datasets change to avoid stale reads.
Concrete scenarios
Large fact table reads → Delta cache speeds repeated scans by using local SSDs.
Small lookup joins → CACHE TABLE keeps the lookup in memory to avoid repeated deserialization and shuffle.
Common mistake
Caching everything wastes memory or local disk. Cache selectively based on size and access patterns.
