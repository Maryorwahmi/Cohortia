Module 4 › Chapter 4.3 › Measuring & validating
Validation checklist
Collect these baseline and post-optimization metrics to verify gains.
- DESCRIBE DETAIL: numFiles and avg file size.
- Query plan: bytes scanned and operator time for representative queries.
- VACUUM DRY RUN: list files candidate for removal before final VACUUM.
Representative code snippets
-- Check table detail
DESCRIBE DETAIL large_events;

-- Dry-run VACUUM to preview files
VACUUM large_events RETAIN 168 HOURS DRY RUN;
Concrete example
Record DESCRIBE DETAIL and query bytes scanned, run OPTIMIZE/ZORDER, then re-measure to see reductions in files and scanned bytes.
