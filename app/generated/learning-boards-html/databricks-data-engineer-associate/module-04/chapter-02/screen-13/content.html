Question 1

A pipeline occasionally adds new fields to feedback data. How do you accept them without failing ingestion?

Answer: use mergeSchema = 'true' during writes (INSERT or MERGE) to add fields while enforcing existing types.
Question 2

What's the difference between mergeSchema = 'true' and overwriteSchema = 'true'?

Answer: mergeSchema is additive and safe for extensions; overwriteSchema replaces the entire table schema and can cause data loss if used carelessly.
Recommended practices
  • Snapshot tables before destructive changes.
  • Test type changes on subsets and transform values first.
  • Use quarantine for streaming invalid records.
