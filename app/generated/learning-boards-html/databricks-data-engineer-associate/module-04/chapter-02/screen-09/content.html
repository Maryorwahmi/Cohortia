Process

Batch validation + quarantine

  1. Validate micro-batch schema against table schema.
  2. Write compatible rows to the main Delta table.
  3. Route incompatible rows to a quarantine or dead-letter location for inspection.
  4. Decide whether to clean data or evolve schema and then reconcile quarantined rows.
This preserves streaming throughput while protecting the table from corruption.
Quick scenario

A producer adds sentiment_score to events. If you accept it automatically, columns change. If you quarantine, you can review and decide to enable mergeSchema or reject changes.

Pro tip: maintain a small schema registry snapshot to compare incoming fields and auto-generate alerts for unexpected changes.
Key Takeaway

Quarantine invalid streaming records and evolve schemas intentionally to keep streams stable.
