Code Walkthrough

Enable additive schema changes

mergeSchema adds new columns found in incoming data without altering existing column types. Rows lacking the new fields get nulls.

Use when sources add optional fields and you want a non-destructive evolution.
Example SQL
-- MERGE with mergeSchema enabled
MERGE INTO my_delta_table AS target
USING new_data_source AS source
ON target.id = source.id
WHEN MATCHED THEN UPDATE SET *
WHEN NOT MATCHED THEN INSERT *
OPTION (mergeSchema = 'true');
After running this, run DESCRIBE my_delta_table to confirm the email or other new columns were added. Expect nulls where older rows lack the new fields.
Key Takeaway

mergeSchema is safe for additive changes; it will not coerce or change existing column types.
