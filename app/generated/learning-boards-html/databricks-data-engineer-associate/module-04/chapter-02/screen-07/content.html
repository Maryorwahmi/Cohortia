Common ALTER operations
  • ADD COLUMN to declare new fields explicitly.
  • ALTER COLUMN TYPE to change types when values are compatible.
  • DROP COLUMN to remove fields (version-dependent).
Mnemonic: toolbox — use the right tool carefully.
Example SQL snippets
-- Add a new column
ALTER TABLE my_delta_table ADD COLUMN email STRING;

-- Change a column type (test first)
ALTER TABLE my_delta_table ALTER COLUMN quantity TYPE BIGINT;

-- Drop a column (version-dependent)
ALTER TABLE my_delta_table DROP COLUMN price;
Before altering types, transform or validate data on a subset. A safe pattern is to UPDATE rows to a castable value, test ALTER, then proceed.
Common mistake: changing types without ensuring safe casts leads to failures or data loss. Test first.
