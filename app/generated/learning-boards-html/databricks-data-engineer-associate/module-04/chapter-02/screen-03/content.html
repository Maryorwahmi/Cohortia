Module 4 › Chapter 4.2 › Apply & Practice
Checkpoint 1 — Observe enforcement

Run an incompatible insert to see Delta reject the write, then inspect error messages and table schema to understand the failure mode.

Checkpoint 2 — Add columns with mergeSchema

Use a MERGE or INSERT with mergeSchema enabled to let Delta add new fields automatically and confirm with DESCRIBE.

Checkpoint 3 — ALTER TABLE safely

Add columns explicitly, and when changing types, pre-transform values so the ALTER succeeds without data loss.

Checkpoint 4 — Streaming & quarantine

For streaming sources expect schema drift; capture invalid records to a dead-letter location for manual fixes.
