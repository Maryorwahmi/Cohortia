Architecture

Notebook ↔ Cluster ↔ Spark

Notebooks are UI clients that send code to a cluster. The cluster runs Spark, and results stream back to the notebook for display. The spark session is provided by the cluster process and is required for DataFrame operations.
Sanity check example: run a lightweight cell that prints a message or lists a DBFS folder to confirm connectivity.
Sizing note: pick a test cluster for quick development and a larger cluster for heavier ETL to avoid runaway costs or failures.
Example run
# After attaching to a running cluster
# Create a small DataFrame and display it
sample_df = spark.createDataFrame([(1, 'a'), (2, 'b')], ['id','val'])
display(sample_df)
Common mistake
Trying to run Spark code without confirming the notebook is attached to a running cluster.
Key Takeaway

Always attach and run a lightweight check before heavy transformations to avoid wasted compute and errors.
