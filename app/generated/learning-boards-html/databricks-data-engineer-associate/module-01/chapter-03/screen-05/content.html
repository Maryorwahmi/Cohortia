Steps

Create a notebook and organize it

  1. 1. Open Workspace and choose a project folder or create one.
  2. 2. Click New Notebook, supply a descriptive name and pick a default language.
  3. 3. Attach the notebook to a cluster for execution.
  4. 4. Add a README notebook or folder-level index to document purpose and owners.
Mnemonic: Name, Language, Attach, Document — a short checklist to follow before executing code destined for reuse.
Concrete example
DBFS_Data_Exploration
A Python notebook in /Projects/AutoData that reads sample CSVs and documents data shape and sources.
Common mistake
Using vague names like 'notebook1' — that makes later discovery and ownership difficult.
Key Takeaway

A small investment in naming and structure saves time for the whole team.
