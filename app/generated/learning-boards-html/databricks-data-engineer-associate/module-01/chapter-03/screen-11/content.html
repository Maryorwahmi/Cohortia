Steps
1. Create Python notebook DBFS_Data_Exploration and attach to a running cluster.
2. Use dbutils.fs.ls to inspect /databricks-datasets and the samples/auto folder.
3. Read auto-mpg CSV into a DataFrame and display it for inspection.
