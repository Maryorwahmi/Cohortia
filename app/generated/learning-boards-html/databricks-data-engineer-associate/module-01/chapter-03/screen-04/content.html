Definition

What the Workspace provides

A unified interface for code, data, compute and lifecycle tools used in data engineering workflows.

Workspace: organize notebooks and folders for collaboration.
Data: browse tables and storage references used in jobs.
Compute: manage clusters that run your notebook code.
Role-based example
Developer
Stores notebooks in Workspace or Repos, tests code on a small cluster, commits to version control.
Data Engineer
Checks Data catalog, attaches to Compute for ETL jobs, schedules with Jobs when ready.
Analyst
Uses notebooks to run queries and visualizations with display for exploration.
ML Practitioner
Uses MLflow and Repos to manage experiments and model code.
Key Takeaway

Treat the sidebar sections as distinct tools. Confirm compute and data references before running production tasks.
