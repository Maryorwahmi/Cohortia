Question 2
How do you run a SQL aggregation inside a Python notebook without changing the default language? Create a temp view and use the SQL magic to run the query.
auto_df.createOrReplaceTempView("cars_temp_view")

%sql
SELECT origin, AVG(mpg) AS average_mpg
FROM cars_temp_view
GROUP BY origin;
Key Takeaway

These two checks prove you can inspect DBFS and combine Python and SQL in a notebook, core skills for Databricks work.
