Module 2 › Chapter 1.3 › Key Concepts
Databricks Workspace UI
The GUI hub for organizing notebooks, data, compute, jobs, and collaboration tools.
Notebooks & Magic
Interactive documents that can mix languages using cell-level magic to choose the interpreter per cell.
DBFS & dbutils
A mounted file system abstraction; use dbutils.fs to inspect and manage files safely.
Summary
These three concepts — UI, notebooks, and DBFS — form the practical foundation for working efficiently and safely in Databricks.
