Module 2 › Chapter 1.3 › Read CSV
Code Example
# Read a CSV file from DBFS
df = spark.read.format("csv") \
  .option("header", "true") \
  .option("inferSchema", "true") \
  .load("/databricks-datasets/samples/auto/auto-mpg.csv")

# Display the DataFrame
display(df)

# Create a temporary view for SQL
df.createOrReplaceTempView("auto_mpg_data")
This code demonstrates reading from DBFS, rendering an interactive table with display, and registering a temp view so SQL cells can query the DataFrame.
Explanation
  • Option header true instructs Spark to use the first row as column names.
  • Infer schema attempts to detect column types for convenience during exploration.
  • display renders a rich table view with quick visualization options built in.
  • Temporary views let you switch to SQL for aggregation without persisting tables.
Misconception
Relying on inferred schema in production can be brittle; favor explicit schemas for reproducible pipelines.
Key Takeaway

Read, inspect, and then register a temp view when you want to combine Python and SQL exploration steps.
