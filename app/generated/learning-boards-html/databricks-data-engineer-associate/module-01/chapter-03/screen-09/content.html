Module 2 › Chapter 1.3 › DBFS & dbutils
Definition & Commands
DBFS provides a convenient mounted namespace for storage. Use dbutils.fs to inspect and manage files; treat DBFS paths like file system locations but remember they map to cloud object storage.
# List a directory and a specific dataset folder
print("Contents of /databricks-datasets:")
dbutils.fs.ls("/databricks-datasets")

print("Contents of /databricks-datasets/samples/auto:")
dbutils.fs.ls("/databricks-datasets/samples/auto/")
Safety notes
Always list and preview before modifying or deleting files.
dbutils.fs.rm can remove files; confirm the target path to avoid accidental loss.
Use export or backup for important notebooks and assets before destructive actions.
Common mistake
Running delete commands without confirming the path or contents first, leading to irreversible deletion.
Key Takeaway

Treat DBFS like any shared storage: inspect, confirm, and back up before destructive operations.
