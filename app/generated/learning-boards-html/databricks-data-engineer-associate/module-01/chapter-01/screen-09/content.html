ML lifecycle steps
  1. Track experiments: record parameters and metrics for each training run.
  2. Package models: store the trained model artifacts with metadata and reproducible environment info.
  3. Deploy and monitor: reference a tracked model in a production pipeline and record serving metrics.
Example
Log hyperparameters and a validation metric for each run; later pick the run with the best metric for promotion.
Practical advice
Make experiment logging consistent: always log the same parameters and metrics so you can compare runs. Link MLflow runs to notebooks and version control for reproducibility.
Misconception
MLflow does not automatically deploy models; it helps manage and version them so deployment is repeatable and auditable.
Key Takeaway

Use MLflow to make model experiments first-class: track parameters, metrics, and artifacts to support reproducible model promotion.
