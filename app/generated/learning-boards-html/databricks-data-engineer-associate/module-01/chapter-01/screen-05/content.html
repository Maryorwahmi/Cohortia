Workspace features
  • Notebooks and folders for collaboration and code history.
  • Left-hand sections: Workspace, Data, Compute, Jobs expose actions and assets.
  • Integration points to attach notebooks to clusters and to schedule jobs.
Example
Create a folder named ETL/Orders and store daily ingestion notebooks there; attach edit permissions only to data engineers.
Practical layout
Workspace
Notebooks and repos.
Compute
Clusters and jobs configuration.
Data
Tables and file pointers (Delta Lake storage).
Jobs
Schedule and run automated workflows.
Key Takeaway

Use the Workspace to organize code, link compute, and control access. It coordinates collaboration but does not replace durable storage like Delta Lake.
