Below are two cells you can run in a Python notebook attached to a cluster. The first demonstrates a simple print; the second uses SQL magic to return a single-row message.
# This is a comment in Python
print("Hello, Databricks Data Engineer Associate!")

# You can also run SQL directly in a Python notebook using a magic command
%sql
SELECT "Welcome to Databricks SQL!" AS message;
Example
Run these cells and observe inline output, then add a markdown cell documenting your intent.
Best practices
  • Attach notebooks to appropriate clusters and detach when done to avoid cost.
  • Use markdown to document assumptions, inputs, and outputs for reproducibility.
  • Store secrets in the secret store; reference them at runtime instead of hardcoding.
Key Takeaway

Notebooks provide fast feedback loops for development and can be promoted to jobs after testing and parameterization.
