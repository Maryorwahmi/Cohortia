Cluster process
1
Request cluster
You specify runtime version, node types, and autoscaling rules.
2
Provisioning
Databricks provisions driver and worker nodes and installs optimized runtime.
3
Run workloads
Jobs or notebooks submit Spark tasks to the cluster.
4
Scale and terminate
Autoscaling adjusts workers; auto-termination stops idle clusters to control cost.
Comparison: all-purpose vs job clusters
All-purpose
Interactive development and ad-hoc analysis.
Job cluster
Ephemeral cluster created for scheduled jobs, better for production.
Example
Set auto-termination to 30 minutes on a dev cluster to avoid overnight charges.
Common mistake
Leaving interactive clusters running without termination leads to unnecessary cost.
