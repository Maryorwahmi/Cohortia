Module 1 › Chapter 1.1 › Learning Objectives — Practical
01 — Define and explain
Milestone: Write two sentences in your notes explaining how Databricks builds on Apache Spark by adding managed services like autoscaling clusters and collaborative notebooks.
Verification
Present the two-sentence explanation to a peer or save it in your notebook.
02 — Identify components
Milestone: From the Workspace, locate a cluster, open a notebook, and describe which piece handles compute, storage, and tracking.
Verification
Attach a screenshot or note in your notebook about those components.
03 — Explain value
Milestone: Explain, with an ETL example, how Delta Lake's ACID transactions help maintain correctness during retries.
Verification
Record a short note or code comment in your notebook describing the effect.
04 — Apply best practices
Milestone: Create a cluster with auto-termination set and store a credential using the secrets feature instead of hardcoding.
Verification
Confirm the cluster terminates after the timeout and the secret is retrievable by a notebook using secure APIs.
