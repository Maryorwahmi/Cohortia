Module 1 › Chapter 1.1 › Operational best practices
Cost control
Enable auto-termination, prefer job clusters for scheduled runs, and use autoscaling to adjust compute to demand.
Example
Set a 30-minute auto-termination on dev clusters and use a job cluster for nightly ETL.
Naming and tagging
Tag clusters and jobs with owner and project to enable cost attribution.
Security & tuning
Store credentials in secrets, use Unity Catalog for access control, and tune Spark shuffle and memory settings where needed.
Common mistake
Hardcoding credentials in notebooks and leaving clusters running are frequent causes of incidents and cost overruns.
Key Takeaway

Adopt autoscaling, secrets, and lightweight tuning as standard practices to keep pipelines reliable, secure, and cost-effective.
