Module 1 › Chapter 1.2 › Key Concepts
Lakehouse Architecture

Combines warehouse guarantees and lake scale into a single platform for BI and ML.

Data Warehouse

Schema-on-write, ACID, and excellent performance for governed reporting.

Data Lake

Stores raw, diverse formats cheaply for exploration and ML with schema-on-read.

Summary

Use a Lakehouse to reduce duplication and allow BI and ML to operate from a consistent, governed source; Delta Lake enables the transactional and schema features that make this possible.
