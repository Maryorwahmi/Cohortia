Core Concept

Data Lake

A large, low-cost repository that stores raw files and supports schema-on-read for flexible exploration and ML.

Strength: stores any data type cheaply at scale
Trade-off: lacks built-in transactionality and strict governance
Common mistake: treating raw files as curated tables for BI workloads
Key Takeaway

Use lakes for raw retention and experimentation, but layer governance before trusting them for dashboards.

Concrete Example
IoT telemetry archive

Store high-volume raw telemetry as files for later exploration and model training. The raw lake is ideal for experimentation but needs curation for dashboards.

Why governance matters
  • Without transactions, concurrent writes can lead to inconsistent file states.
  • Discoverability and data quality suffer without catalogs and policies.
