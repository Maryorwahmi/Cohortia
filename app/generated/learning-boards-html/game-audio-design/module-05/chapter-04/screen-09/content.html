Expose a parameter
Right-click a parameter in the Mixer Inspector and choose Expose to Script. Rename the exposed parameter for clarity.
Scripting example
// Pseudocode usage in a dialogue manager
// Assume "MusicVolume" is an exposed parameter
mainMixer.SetFloat("MusicVolume", -20f); // Duck immediately
// Or Lerp for smoothness in Update:
// float current; mainMixer.GetFloat("MusicVolume", out current);
// float next = Mathf.Lerp(current, -20f, t);
// mainMixer.SetFloat("MusicVolume", next);
Concrete example
Expose the Music group's Volume parameter as "MusicVolume". In your dialogue controller, call SetFloat to lower it when lines start and Lerp back up when they end, ensuring speech remains intelligible over music.
Key Takeaway
Exposed parameters enable precise, script-driven audio behavior that snapshots alone cannot achieve.
Common pitfall
Avoid setting parameters instantly for very short events; prefer smoothing so players do not perceive abrupt volume jumps.
