Module 5 › Chapter 5.4 › Applying Effects
Effects you’ll use
  • Reverb — environment size and decay.
  • Lowpass/Highpass — shape frequency content (muffling, clarity).
  • Chorus/Distortion/Echo — creative coloration or impact.
How to add
Select Mixer Group → Inspector → Add Effect. Adjust parameters like decay, wet/dry, and cutoff until the effect supports the scene.
Warning
Overusing effects makes the mix muddy and reduces important audio cues. Prefer subtlety.
Concrete example
Add SFX Reverb to the SFX group. Set Decay Time and Room Size to simulate a cave. Test by playing a gunshot or explosion and listening for distance cues. If dialog is present in the same group, consider moving dialog to Voice group to avoid unintended reverb.
Pro Tip
Use send/return chains sparingly. When multiple groups need the same effect, a send reduces duplication.
Key Takeaway
Effects change perception; add them where they improve clarity or immersion and measure their impact on gameplay cues.
Check your understanding
If footsteps sound unclear after adding reverb to SFX, what should you check first? (Answer: effect wet/dry and whether voice or UI are unintentionally in the same group.)
