Module 5 › Chapter 5.4 › Audio Mixer Snapshots
What a snapshot captures
  • Exposed volume parameters for groups.
  • Effect parameters like reverb decay or lowpass cutoff.
  • Enabled/disabled state of effects if exposed.
Example
Gameplay: Music -10dB, SFX 0dB, Reverb medium. Paused: Music -30dB, SFX -10dB, Reverb reduced.
Best practices
Use snapshots for distinct game states. Keep parameter exposure consistent so snapshots control the same knobs across the project.
Key Takeaway
Snapshots let you craft and recall whole soundscapes quickly and reliably.
Check your understanding
When should you prefer exposing a parameter and scripting changes versus creating another snapshot? (Answer: when you need continuous or event-driven control rather than discrete states.)
