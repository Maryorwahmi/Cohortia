Practical Objectives

Scripting, ducking, and test strategies to complete the lab.

Bloom: Apply → Analyze → Master
05
Expose Parameters
Make volumes or filter cutoffs available to script so you can change them with SetFloat. Mnemonic: think of exposed parameters as remote controls for mixer knobs.
VERIFIED COMPETENCY MILESTONE
06
Implement Audio Ducking
Lower music automatically during dialogue or important SFX using snapshots or exposed parameters with Lerp for smooth fades.
VERIFIED COMPETENCY MILESTONE
07
Plan Mixer Layout
Design group hierarchies and place effects intentionally to avoid redundant processing and keep clarity in the mix.
VERIFIED COMPETENCY MILESTONE
08
Test & Debug Mixes
Verify routing, check effect wet/dry balance, and test snapshot transitions in-play to ensure real-time responsiveness.
