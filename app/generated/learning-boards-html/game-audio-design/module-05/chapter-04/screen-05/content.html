Module 5 › Chapter 5.4 › Create an Audio Mixer and Groups
Step-by-step
  1. Create Audio Mixer asset: Project → Create → Audio Mixer.
  2. Open the mixer, add groups: Music, SFX, Voice.
  3. Nest groups: SFX → Player SFX, Enemy SFX, Environmental SFX.
  4. Assign AudioSource Output in the Inspector to the proper group.
  5. Verify routing in Play mode and adjust volumes on groups.
Common mistake
Renaming or moving groups without updating AudioSource outputs can leave sources routed to the wrong group or silent.
Example setup
Create MainAudioMixer. Add Music and SFX under Master. Add Player SFX and Enemy SFX as children of SFX. Set BGM_Player AudioSource Output to MainAudioMixer → Music. Set SFX_Player to MainAudioMixer → SFX.
Mnemonic
Master is the roof; groups are rooms, children are furniture.
Pro Tip
Use clear names (Music, SFX.Player) to avoid confusion when assigning outputs.
Key Takeaway
Design hierarchies that balance global controls with per-category detail for efficient mixing.
