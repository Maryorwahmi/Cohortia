Module 5 › Chapter 5.4 › Snapshots vs Exposed Parameters
Snapshots
Saved mixer states for whole-scene or whole-mode swaps. Quick to set up and test in the Editor.
Use when
You need discrete, repeatable audio states like Paused, Combat, or Underwater.
Exposed Parameters
Fine control from scripts for ducking, smoothing, or responding to gameplay metrics in real time.
Use when
You need continuous, event-driven adjustments such as dynamic ducking based on dialogue intensity.
Combined strategy
Use snapshots for major states and expose key parameters for nuanced, script-driven changes inside those states. For example, transition to an Underwater snapshot and use an exposed lowpass to fine-tune cutoff over time.
Key Takeaway
Choose snapshots for simplicity and exposed parameters for precision; combine them for flexible, robust audio design.
