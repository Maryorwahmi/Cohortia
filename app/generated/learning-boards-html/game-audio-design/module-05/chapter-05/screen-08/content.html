Definition

What are Parameters?

Parameters (or RTPCs in Wwise) are variables exposed from the middleware to the game engine, allowing audio designers to map them to various audio properties (volume, pitch, effects) within an Event for real-time dynamic control.

Functionality

Bridging Game Logic & Audio

  • Game state variables (e.g., player speed, health) can drive audio changes.
  • Audio designers define how parameters influence sound properties.
  • Programmers simply update parameter values from the engine.
  • Enables highly responsive and adaptive audio experiences.
Concrete Example

Dynamic Engine Sound

For a car engine sound, an audio designer creates a 'RPM' parameter. They map this parameter to increase the pitch and volume of the engine sound as RPM rises, and perhaps introduce a subtle distortion effect at high RPMs. The game programmer then simply updates the 'RPM' parameter from the car's physics, and the engine sound dynamically adapts, creating a realistic and immersive driving experience.

Key Takeaway

Parameters are crucial for creating dynamic and interactive audio, allowing game logic to directly influence sound properties in real-time, resulting in a more immersive and responsive player experience.
