Step 1: Authoring in Middleware

Creative Sound Design

  • Import raw audio assets (SFX, music, voice).
  • Create Events with layered sounds and effects.
  • Define Parameters (RTPCs) for dynamic control.
  • Build complex audio logic in a visual editor.
  • No coding required for audio designers.
Example

An audio designer creates a 'Wind_Ambient' Event, layering multiple wind samples, adding a high-pass filter, and mapping a 'WindSpeed' parameter to control volume and filter cutoff.

Step 2: Building Banks

Optimized Packaging

  • Compile the middleware project into binary bank files.
  • Banks contain all Events, audio assets, and logic.
  • Optimizes data for efficient loading and memory usage.
  • Prepares audio for integration into the game engine.
  • Essential for game performance.
Why it Matters

Without building banks, the game engine cannot access the complex audio designs created in middleware. This step is the bridge between design and runtime functionality.

Key Takeaway

The middleware workflow begins with audio designers visually authoring complex sound behaviors, which are then compiled into optimized banks, making them ready for efficient integration into the game engine.
