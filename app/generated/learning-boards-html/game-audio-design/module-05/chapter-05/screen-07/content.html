Definition

What are Banks?

Banks are compiled packages of Events and their associated audio assets (sound files, music tracks) from the middleware project. They are loaded into the game engine at runtime for efficient memory management and optimized performance.

Purpose

Optimized Loading & Memory

  • Organize audio data into logical, loadable units.
  • Prevent loading all game audio into memory at once.
  • Reduce memory footprint by loading only necessary assets.
  • Improve game loading times and overall performance.
Example Scenario

Level-Specific Banks

In a game with multiple levels, you might create a 'Level_Forest' bank containing all the ambient sounds, creature calls, and music specific to the forest level. When the player enters this level, only the 'Level_Forest' bank is loaded, and when they leave, it's unloaded, freeing up memory. This is far more efficient than keeping all level sounds in memory simultaneously.

Key Takeaway

Banks are essential for managing game audio efficiently, allowing for selective loading and unloading of sound assets to optimize memory usage and improve game performance.
