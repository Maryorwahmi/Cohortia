Module 6›Chapter 5.5›Designing an Arcane Bolt Spell
Scenario

Interactive Spell Sound

Design the sound for an 'Arcane Bolt' spell that changes based on how long the player 'charges' it (0-100%).

  • Event Name: Spell_ArcaneBolt_Cast
  • Core Sounds: arcane_charge_loop.wav, arcane_cast_short.wav, arcane_cast_long.wav, arcane_impact.wav
  • Parameter: ChargeLevel (Range: 0.0 to 1.0)
Parameter Mapping

Dynamic Audio Properties

  • Charge Loop: ChargeLevel controls volume, pitch, and lowpass filter cutoff.
  • Cast Sounds: Middleware 'Multi-sound' or 'Selector' plays short/long based on ChargeLevel threshold.
  • Overall: Subtle reverb wet mix increases with ChargeLevel for power.
Engine Interaction (Unity C# Pseudo-code)
public class ArcaneBoltSpell : MonoBehaviour{    [FMODUnity.EventRef]    public string arcaneBoltChargeEventPath;    [FMODUnity.EventRef]    public string arcaneBoltCastEventPath;    private FMOD.Studio.EventInstance chargeInstance;    private float currentChargeLevel = 0f;    private bool isCharging = false;    void Start()    {        chargeInstance = FMODUnity.RuntimeManager.CreateInstance(arcaneBoltChargeEventPath);        chargeInstance.set3DAttributes(FMODUnity.RuntimeUtils.To3DAttributes(transform.position));    }    void Update()    {        if (Input.GetMouseButton(0)) // Holding left click        {            if (!isCharging)            {                chargeInstance.start();                isCharging = true;            }            currentChargeLevel = Mathf.Min(currentChargeLevel + Time.deltaTime * 0.2f, 1.0f);            chargeInstance.setParameterByName("ChargeLevel", currentChargeLevel);        }        else if (Input.GetMouseButtonUp(0)) // Releasing left click        {            if (isCharging)            {                chargeInstance.stop(FMOD.Studio.STOP_MODE.ALLOWFADEOUT);                isCharging = false;                FMODUnity.RuntimeManager.PlayOneShot(arcaneBoltCastEventPath, transform.position);            }            currentChargeLevel = 0f;        }    }    void OnDestroy()    {        chargeInstance.release();    }}
Key Takeaway

This example illustrates how game code interacts with middleware Events and Parameters to create highly dynamic and responsive audio, where sound properties adapt in real-time to player actions and game state.
