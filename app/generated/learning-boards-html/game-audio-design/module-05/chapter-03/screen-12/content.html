Module 5 › Chapter 5.3 › AudioSource Architecture
Local AudioSources

Attach to GameObjects for spatialized effects such as footsteps, weapon sounds, or engine hum. Spatial blend should be set to 3D for local sources.

Pros
  • Natural 3D positioning
  • Independent control per object
Centralized AudioSources

Use a SoundManager for UI, music, and shared effects. Keep a small set of global sources and prefer PlayOneShot to layer short effects efficiently.

Pros
  • Consistent global control
  • Simpler volume and mute handling
Recommendation

Use hybrids: spatial local sources for positional sounds and a central manager for UI and music. Document the policy for your team.
