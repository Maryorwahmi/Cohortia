Module 5 › Chapter 5.3 › Event-driven audio
Triggering sounds from events
Common triggers
  • OnCollisionEnter — impact sounds
  • OnTriggerEnter — pickups and zones
  • Input checks — jump, shoot, interact
Best practices
  • Call a public audio method instead of duplicating playback logic.
  • Rate limit rapid events or use PlayOneShot for overlap.
  • Keep audio responsibilities modular and testable.
Scenario

A pickup object calls playerAudioController.PlayPickupSound() in OnTriggerEnter, so the pickup remains simple and the audio handler controls playback and overlap policy.
