Module 5 › Chapter 5.3 › Play vs PlayOneShot
Play()

Plays the assigned clip on the AudioSource. If already playing, Play restarts the clip from the beginning.

Good for:
  • Looped music
  • Resumable ambient sounds
  • One-shot actions where restart is intended
PlayOneShot()

Plays a provided AudioClip immediately without stopping or replacing the AudioSource's current clip, allowing overlap.

Good for:
  • Rapid-fire effects like gunshots
  • Multiple footsteps in quick succession
  • Layered UI blips
Concrete example
If a machine gun fires while another shot is still playing, PlayOneShot allows each "bang" to be heard separately. Using Play would restart the clip on each shot, making the result choppy.
