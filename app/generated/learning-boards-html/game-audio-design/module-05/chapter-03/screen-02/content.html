Learning Objectives
Learn, understand, apply, and demonstrate audio scripting skills.
Learn → Understand → Apply → Master
01
Assign and reference AudioSource
Learn to expose and assign AudioSource and AudioClip fields in the Inspector and guard them in code. Verified competency: script gets a valid AudioSource at runtime without errors.
02
Use Play, Stop, Pause
Understand when Play restarts, Stop resets, and Pause preserves position. Verified competency: implement pause/resume that continues from the paused position.
03
PlayOneShot for overlapping effects
Use PlayOneShot to layer rapid effects without cutting existing sounds. Verified competency: implement a firing effect that overlaps correctly.
04
Control volume & pitch at runtime
Map gameplay variables to AudioSource.pitch and volume using Mathf.Lerp. Verified competency: make an engine hum change with a simulated speed variable.
