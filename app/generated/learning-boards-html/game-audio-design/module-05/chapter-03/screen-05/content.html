Module 5 › Chapter 5.3 › Play / Stop / Pause
Playback semantics
  1. Play() — starts or resumes the assigned clip; restarts if already playing the same clip.
  2. Stop() — stops playback and resets position to start.
  3. Pause() — pauses at current position; Play() resumes from there.
Quick rule

Use Play for loops and resumable audio; Stop to cancel; Pause for temporary holds like menu or cutscenes.

Common pitfall

Calling Play on repeating short clips will repeatedly restart them, producing audible clipping. For short, repeatable SFX, prefer PlayOneShot.

Example scenario

When the player presses jump, you may want the jump sound to start fresh every press. Using Play on a dedicated jump AudioSource is fine. But if multiple jumps happen rapidly and should overlap, PlayOneShot is better.

Key Takeaway

Match method to intended behavior: restart, cancel, or pause.
