Definition

WAV / AIFF vs OGG / MP3

WAV and AIFF are uncompressed formats preferred for short, latency-sensitive effects. OGG and MP3 are compressed and save space for long clips.

WAV / AIFF
High quality, no decode cost at playback, larger file size. Best for immediate SFX.
MP3 / OGG
Compressed, smaller size, suitable for music and long ambience where memory matters.
Key Takeaway

Pick the format by the clip’s role: quality and latency for SFX, size and memory for music.

Concrete Example
UI Click vs Background Music

A short click should be WAV to avoid decode latency. A five-minute ambient track should be OGG or MP3 to save memory and disk space.

Common Mistake

Using stereo WAVs for point sounds ruins 3D spatialization. Convert point SFX to mono when they represent a single source.

Check Your Understanding
  • Is the clip short and latency-sensitive?
  • Does the clip need to stream from disk due to length?
  • Should the clip be mono for spatialization?
