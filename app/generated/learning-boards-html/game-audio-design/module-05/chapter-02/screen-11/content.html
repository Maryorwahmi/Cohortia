Module 5 › Chapter 5.2 › Hands-on Setup
Step-by-step
  1. Import ambient audio and short UI click into Project window.
  2. Create GameObject named AmbientSound and add Audio Source component.
  3. Assign ambient clip, check Play On Awake and Loop, set Spatial Blend = 0, set Volume ≈ 0.5.
  4. Create a UI Button, add Audio Source, assign click clip, uncheck Play On Awake and Loop.
Key Takeaway

Separate ambient autoplay from event-driven SFX to maintain predictable runtime behavior.

Checklist
  • Ambient: Play On Awake = true, Loop = true, Spatial Blend = 0.
  • Button: Play On Awake = false, Loop = false, Spatial Blend = 0.
  • Test in Play mode and adjust volumes before building.
Pro Tip

Keep ambient volume lower than SFX so UI clicks and important cues remain audible.
