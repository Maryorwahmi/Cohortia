Definition

2D vs 3D Sounds

Spatial Blend controls whether the Audio Source is heard relative to the listener position. Adjust Min and Max Distance for attenuation and choose a rolloff curve for falloff shape.

Min Distance
Distance before attenuation begins. Smaller for intimate sounds, larger for broad ambience.
Max Distance
Distance at which sound is inaudible. Set according to gameplay needs.
Concrete Scenario
Door vs Ambient

Door slam: Spatial Blend=1, small Min/Max. Ambient wind: Spatial Blend=0 or blend, larger Min distance if attached to object.

Common Mistake

Using stereo clips for point sounds prevents correct localization. Convert point SFX to mono for accurate 3D placement.
