Format by Role
Short SFX → PCM/WAV. Long music → Vorbis/OGG or Streaming.
Audio Source Intent
Play On Awake for ambient, scripts for one-shots, use Loop appropriately.
Spatialization
Use mono for point sources and set Min/Max Distance and rolloff for natural attenuation.
Closing Prompt

Pick one audio clip in your project and apply the recommended import and Audio Source settings. Test and iterate.
