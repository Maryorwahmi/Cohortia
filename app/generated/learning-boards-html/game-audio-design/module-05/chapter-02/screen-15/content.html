Module 5 › Chapter 5.2 › Key Concepts
Audio Clip
The raw sound file imported into Unity; choose format by use case.
Load Type
Decompress On Load, Compressed In Memory, Streaming control memory and decoding timing.
Audio Source
Component that plays clips and exposes Play On Awake, Loop, Volume, Pitch and Spatial Blend.
Final Takeaway

Make import and Audio Source choices explicitly for each clip role, and verify behavior through focused testing.
