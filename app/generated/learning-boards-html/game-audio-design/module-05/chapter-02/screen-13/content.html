Definition

Common audio issues

Missing sound
Check Audio Clip assignment and console warnings for null references.
Wrong spatialization
Stereo clips on point sources block 3D localization. Use mono for point SFX.
Unexpected autoplay
Play On Awake accidentally enabled. Uncheck for event-driven sounds.
Quick Fix Checklist
  • AudioSource has clip assigned and is active.
  • Play On Awake, Loop, Mute and Bypass settings are intentional.
  • Spatial Blend and mono/stereo selection match the use case.
  • Priority is set for important sounds during crowded playback.
