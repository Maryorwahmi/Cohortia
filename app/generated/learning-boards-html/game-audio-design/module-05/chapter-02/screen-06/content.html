Module 5 › Chapter 5.2 › Compression Formats
Definition

Vorbis, ADPCM, PCM

Compression format defines how audio data is stored and how much CPU and memory are used at runtime. Choose based on quality need, file size limits, and decompression cost.

Vorbis
Good compression for music and ambience with acceptable quality.
ADPCM
Fast to decompress, useful for short effects where speed matters.
PCM
Uncompressed, highest quality, larger size. Best for very short, critical SFX.
Practical Tip

If a clip sounds noticeably degraded after compression, try a different format or higher quality setting. Always test on device.

Common Mistake

Assuming compressed means cheaper CPU. Decompression can cost CPU time at playback, so verify on your build target.
