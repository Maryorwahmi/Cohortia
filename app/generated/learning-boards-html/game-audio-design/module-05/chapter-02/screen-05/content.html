Process Flow

Load Type Modes

Decompress On Load
Loads whole clip uncompressed into memory at scene load. Best for short SFX that must play instantly.
Compressed In Memory
Keeps compressed data in memory and decompresses during playback. Useful for medium-length clips.
Streaming
Streams from disk during playback. Minimizes memory but uses streaming CPU and I/O bandwidth.
Example & Checklist
Example: 5-minute cinematic music

Use Streaming to avoid loading the full file into RAM. Test streaming startup latency during the scene transition.

Checklist
  • Short SFX → Decompress On Load
  • Medium music → Compressed In Memory
  • Very long clips → Streaming
  • Measure memory and start-up performance on target device
Common Mistake

Choosing Streaming for many short SFX increases I/O overhead and can cause delays. Use Decompress On Load for short, immediate sounds.
