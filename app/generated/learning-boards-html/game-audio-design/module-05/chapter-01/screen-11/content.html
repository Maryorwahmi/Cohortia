Module 5 › Chapter 5.1 › Triggering Audio at Runtime
Code pattern (editor-triggered audio)
// pseudocode-style example
// get the source and play in response to an event
AudioSource source = gameObject.GetComponent<AudioSource>();
if (!source.isPlaying) {
  source.Play();
}
Concrete example

On an NPC footstep animation event, call the play method on that NPC’s attached Audio Source so the sound follows the character’s position.

Common mistake

Starting the same source repeatedly without checking isPlaying, causing layered, unintended loudness.

Key Takeaway

Use scripts to trigger sources responsively, but manage playback state and respect spatial setup for consistent results.
