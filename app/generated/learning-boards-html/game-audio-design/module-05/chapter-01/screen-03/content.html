How to test each objective

Short editor checks you can run now to confirm audio behavior.

01 — Verify Listener
  • Open scene and select Main Camera; confirm Audio Listener component exists.
  • If missing, add it and re-run Play to check 3D sounds.
02 — 2D vs 3D test
  • Place identical clips as 2D and 3D; walk the listener to compare perception.
03 — Spatial rules
  • Loop a sound while adjusting Min/Max Distance to observe attenuation.
04 — Workflow check
  • Import, attach to GameObject, set spatial blend, and run the scene to confirm behavior.
