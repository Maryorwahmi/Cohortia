Module 5 › Chapter 5.1 › Audio Source — emitting sound
Definition

Audio Source

Component that plays an audio clip from a GameObject and supplies position data for spatial audio.

Key properties
  • Loop, volume, and spatial blend (2D/3D mix).
  • Min and Max Distance control attenuation range.
Key Takeaway

Sources should be attached to the moving object that creates the sound to preserve direction and falloff.

Practical example and checks
Example

Attach a looping engine hum to a car GameObject. When the car moves, the sound position updates and panning/attenuation change relative to the listener.

Checklist
  • Is the clip assigned to the source?
  • Is Spatial Blend set correctly for intended 2D/3D behavior?
  • Are Min/Max Distance values appropriate for the sound?
Common mistake

Using a single global source for many world sounds prevents accurate localization and distance cues.
