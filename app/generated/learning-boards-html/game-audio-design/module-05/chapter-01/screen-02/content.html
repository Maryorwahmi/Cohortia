Learning Objectives

Learn the vocabulary and practical steps to make sound work reliably in a scene.

Bloom: Learn → Understand → Apply → Master
01
Identify core components

Recognize the Audio Listener and Audio Source and why both are required to hear in-world sounds.

Visual mnemonic: paired ears and speaker icons
VERIFIED COMPETENCY MILESTONE
02
Differentiate 2D vs 3D

Decide when a sound should be spatialized or remain constant across the player’s view.

Visual mnemonic: map pin (3D) vs music note (2D)
VERIFIED COMPETENCY MILESTONE
03
Explain spatial rules

Describe spatialization, attenuation, and Doppler and their audible effects.

Visual mnemonic: distance curve icon
VERIFIED COMPETENCY MILESTONE
04
Perform the basic workflow

Import a clip, attach it to a GameObject, set spatial blend and distances, test in Play mode.

Visual mnemonic: import arrow and gear
VERIFIED COMPETENCY MILESTONE
