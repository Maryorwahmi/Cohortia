Definition

Bit depth explained

Bit depth sets how many amplitude values each sample can take. More bits mean finer amplitude steps, lower quantization noise, and larger file sizes.

16-bit
65,536 possible values. Common for final in-game assets to save memory.
24-bit
Over 16 million values. Useful for recording and mixing to preserve dynamic detail.
Example & guidance
Example: ambience recording
Record ambience at 24-bit so quiet details aren't lost. When exporting for mobile, convert to 16-bit to reduce footprint.
Misconception
Bit depth does not increase the highest frequency; it increases amplitude resolution and dynamic range.
Key Takeaway

Use higher bit depth during production; choose lower depth for final assets when platform and size constraints require it.
