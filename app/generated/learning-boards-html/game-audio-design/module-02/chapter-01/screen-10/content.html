Module 2 › Chapter 2.1 › Inspecting File Properties in a DAW
Procedure

Step-by-step walkthrough

// Example workflow (editor-agnostic)
1. Import audio file into your editor.
2. Check the file's source properties for sample rate and bit depth.
3. Note the project's current sample rate and change it to test playback.
4. If you need a different final rate, resample and export to that rate and desired bit depth.
Keep in mind many editors process internally at higher precision; confirm exported file properties match deployment settings.
Checks & tips
Don't assume the project rate resamples the file unless you explicitly export with resampling enabled.
Listen for pitch/speed issues after changing project rate—those indicate mismatched source and project rates.
Use 24-bit for capture, then export critical assets at higher depth where justified, otherwise 16-bit for distribution.
Key Takeaway

Verify both sample rate and bit depth in your export. Resample purposely and avoid accidental mismatches.
