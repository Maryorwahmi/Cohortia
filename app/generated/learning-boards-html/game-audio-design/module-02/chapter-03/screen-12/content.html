Module 3 › Chapter 2.3 › Key Concepts
Digital Audio Workstation
Software for recording, editing, mixing, and exporting audio without modifying originals.
Tracks & Mixer
Tracks hold clips; the mixer controls levels, pan, and hosts effect inserts for each channel.
Trimming, Splitting, Crossfade
Precise edits and short fades prevent clicks and enable smooth loops and transitions.
One-line summary
Prepare clean, consistent audio by editing non-destructively, keeping levels correct, and using subtle processing that serves clarity and game context.
