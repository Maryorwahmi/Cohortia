Module 3 › Chapter 2.3 › What is a DAW?
Definition & role
A DAW records, arranges, edits, processes, and renders audio without altering the original files.
Why non-destructive matters
  • Allows undo and experimentation.
  • Supports multiple versions for different in-game contexts.
  • Keeps originals intact for reuse.
Common misconception
Edits in a DAW rarely overwrite sources; they record processing and timeline edits instead.
Concrete example: splitting a combined WAV
Import a WAV with dialogue and a clang. Use the split tool to separate the two sounds, trim silence from each, and add a crossfade if they are joined. The original WAV file remains unchanged in your media folder.
Analogy: the DAW is like a photo editor that stores edit instructions rather than burning changes into the original image.
Key Takeaway
Treat the DAW as both a tool for edits and a safe place to store versions and experiment without risking originals.
