Module 3 › Chapter 2.3 › Normalization & Gain Staging
Normalization
Adjust a clip so its loudest sample reaches a specified peak value without changing its internal dynamics.
Gain staging
Set gain at each processing stage so plugins operate with good signal-to-noise ratio and avoid clipping.
Practical rule: normalize clips first, then use track and bus faders to mix while keeping master headroom.
Example workflow
Normalize the dialogue to -0.1 dBFS. Insert SFX and music, reduce their track faders to leave ~6 dB headroom on the master. Check for clipping during heavy moments and adjust plugin gains as needed.
Common error
Normalizing everything to the same peak then summing them without headroom leads to frequent clipping on the master bus.
Key Takeaway
Use normalization for per-clip consistency and gain staging for mix-wide headroom and clean processing.
