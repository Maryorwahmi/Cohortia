Module 3 › Chapter 2.3 › Reverb & Spatialization
Core parameters
  • Decay time: how long reflections last.
  • Pre-delay: time before reflections begin.
  • Wet/Dry: balance between processed and original sound.
Practical rules
Keep dialogue reverb subtle; use longer tails for ambient beds and larger spaces; use pre-delay to protect transient clarity.
Misconception
More reverb does not equal realism; it can hide detail and reduce gameplay-critical clarity if overused.
Example
For a sword impact in a hall, use moderate decay, a short pre-delay (10–30 ms) to preserve the attack, and increase wet slightly so reflections are audible but do not mask the transient.
Key Takeaway
Use reverb to match perceived distance and space while preserving the critical transient information that players rely on.
