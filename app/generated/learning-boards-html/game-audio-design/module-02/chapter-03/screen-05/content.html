Module 3 › Chapter 2.3 › Timeline, Tracks, and Mixer
Timeline: the time ruler
Marks when sounds occur. Use markers and loop regions to audition repeats and refine edits.
Tracks: lanes for sources
  • One logical element per track keeps processing targeted.
  • Group related sounds for quick global adjustments.
Mixer: balance & inserts
Faders set loudness, pan sets stereo position, inserts host EQ and reverb for the channel.
Concrete scenario
Import a WAV that has footsteps and a voiceover. Split them into two clips and place each on its own track. In the mixer, reduce the footsteps track by 2–3 dB so the voice reads clearly over the footsteps. This shows the advantage of separated tracks for fast level control.
Common mistake
Putting multiple unrelated sounds on one track forces you to apply processing that affects everything on that track, making individual fixes harder.
Key Takeaway
Organize by source and purpose: timeline positions events, tracks isolate them, mixer balances and applies processing per channel.
