Module 3 › Chapter 2.3 › Importing & Non-Destructive Editing
Step-by-step import
  1. Open the project and locate your media folder.
  2. Drag the WAV onto a new track or use File > Import.
  3. Name the track logically (Dialogue, SFX, Music).
Non-destructive edits explained
Edits are instruction layers. You can trim, split, and apply fades without changing the original file on disk. This enables rapid iteration and multiple exports.
Concrete example
Import game_dialogue_and_sfx.wav. Split at the dialogue end, trim silence, and add a short fade on each clip. Play back to confirm no clicks. Export a rendered WAV named edited_game_audio.wav so the original remains intact.
Common mistake
Changing source files directly instead of exporting a new file risks losing originals and reproducibility.
Pro tip
Use clear naming conventions with versions, e.g., sfx_sword_v01.wav and sfx_sword_v01_edited.wav, and keep a single export folder for engine-ready files.
