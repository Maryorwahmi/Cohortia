ADPCM and Platform Codecs

Specialized codecs trade a small quality cost for extremely low CPU decompression and small footprint—ideal for frequently played short sounds.

Pipeline pattern
Keep WAV in source control → configure engine import settings → engine transcodes to ADPCM/Ogg/AAC for each platform → runtime uses optimized assets.
Performance note
ADPCM decodes with very low CPU, making it preferable for hundreds of tiny effects; test memory and latency on target hardware.
Concrete example
Footsteps: pack many short samples as ADPCM to keep the active memory footprint small and minimize decode time.
Common-mistake
Assuming platform codecs match desktop behavior. Always profile on the target device because hardware decoders and memory hierarchies differ.
Key Takeaway

Use engine pipelines to generate runtime formats. Choose ADPCM or platform codecs for low-latency, low-CPU short sounds.
