FFmpeg examples

Run these from the terminal to create consistent encodes from a WAV master. Replace input.wav and output names as needed.

# Convert to MP3 96 kbps
ffmpeg -i input.wav -b:a 96k output_mp3_96.mp3

# Convert to MP3 256 kbps
ffmpeg -i input.wav -b:a 256k output_mp3_256.mp3

# Convert to Ogg Vorbis Quality 3
ffmpeg -i input.wav -q:a 3 output_ogg_q3.ogg

# Convert to Ogg Vorbis Quality 8
ffmpeg -i input.wav -q:a 8 output_ogg_q8.ogg

# Convert to FLAC (lossless)
ffmpeg -i input.wav output_flac.flac
Workflow checklist
  • Keep WAV master in source control
  • Export multiple target encodes for comparison
  • Record file sizes and listening notes
  • Test encodes in-engine under normal playback conditions
Concrete example
Export a 10-second complex clip to FLAC and MP3 96/256, then compare file sizes and note where artifacts appear.
Misconception
Re-encoding lossy-to-lossy does not recover quality; always re-encode from the uncompressed master.
Key Takeaway

Automate conversions from WAV masters and keep a record of sizes and perceptual notes for each target format.
