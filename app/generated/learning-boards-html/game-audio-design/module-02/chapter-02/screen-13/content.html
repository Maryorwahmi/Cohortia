Common Mistakes

Over-compressing critical sounds
Lossy artifacts on dialog and UI are noticeable—test and raise bitrate where needed.
Using uncompressed files for everything
This wastes memory and increases installation size with no runtime benefit for many assets.
Transcoding lossy-to-lossy
Quality only degrades; always re-encode from the original WAV master.
Recommended first actions
  • Identify top 10 assets by memory
  • Run encodes at two bitrates for each
  • Automate engine transcodes
Key Takeaway

Adopt a repeatable encode-and-test workflow and automate per-platform builds from your WAV masters.
