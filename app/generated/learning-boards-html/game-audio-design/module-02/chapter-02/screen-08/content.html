Module 2 › Chapter 2.2 › Choosing Formats
Process Flow

Pick a format for each asset type

1. Rate perceptual importance
Decide whether fidelity will be noticed by players in normal gameplay.
2. Consider length and streaming
Long assets favor lossy streaming formats; short assets may use ADPCM or WAV for low latency.
3. Measure runtime cost
Profile decompression CPU and memory to ensure targets meet performance budgets.
4. Test in context
Listen to assets in the engine mixed with other sounds and during streaming conditions.
Quick reference
Music: Ogg/AAC 160–256 kbps. Dialogue: FLAC for masters, high-bitrate Ogg for runtime. UI: ADPCM or 64–96 kbps lossy.
Analogy
Think of each asset as a travel item: some need the full suitcase (uncompressed), others just a carry-on (lossy), and some fit in a pocket (ADPCM).
Key Takeaway

Match format to role: preserve quality where it matters, reduce size where it doesn't.
