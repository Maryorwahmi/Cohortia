FLAC and ALAC

Reduce size without discarding audio data; decompressed audio is bit-for-bit identical to the original.

30–50% typical savings
How it works
  • Find and encode redundant data more efficiently
  • Store metadata and exact reconstruction instructions
  • Decompresses to an exact replica of the original samples
Practical trade-offs
  • Good for archival-quality music and dialog
  • Moderate disk savings but larger than lossy formats
  • Slightly higher CPU decompression vs some lossy decoders
Concrete example
Archive dialog masters as FLAC to save disk space while keeping perfect fidelity for re-encoding or QA.
Common-mistake
Assuming lossless is always best at runtime; larger sizes and CPU cost often make lossy formats more practical for streaming assets.
Key Takeaway
Use lossless when perfect reproduction is needed, especially for archival, QA, or re-encoding workflows.
