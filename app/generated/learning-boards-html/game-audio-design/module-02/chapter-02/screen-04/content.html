Module 2 › Chapter 2.2 › Uncompressed Audio
Definition

WAV and AIFF

Uncompressed containers storing raw PCM samples with perfect fidelity and the largest file sizes.

Typical use cases
  • Production masters and editing source files
  • Very short, latency-critical UI sounds
  • Pre-rendered cinematic audio where memory is less constrained
Concrete example
A one-minute stereo clip at 48 kHz, 16-bit is about 10 MB as a WAV. Keep these as masters for re-encoding.
Key Takeaway

Use WAV/AIFF as source masters and for a few runtime cases where decode latency must be zero.

Common-mistake
Packing every asset as WAV increases installation and memory costs unnecessarily when most assets can be compressed for runtime.
Pro tip
Keep uncompressed masters in source control; export compressed runtime builds from those masters only once the format decisions are final.
