Module 2 › Chapter 2.2 › Testing Workflow

Activity timeline

A short, repeatable process to compare encodes and make defensible choices.

Prepare
Select a WAV master at 48 kHz and 24-bit and note source details in a spreadsheet.
Convert
Create FLAC, MP3 at two bitrates, and Ogg at two qualities for direct comparison.
Compare
Record file sizes and listening notes, then import to the engine and test streaming and preloading.
Example spreadsheet fields
Format | Setting | Size | Listening notes (artifacts, clarity) | Engine test notes
Common-mistake
Relying only on isolated listening—always audition encodes in their in-game playback scenario to catch issues that only appear under load.
Key Takeaway

Document results consistently. The spreadsheet of sizes and notes becomes a repeatable reference for format decisions across the project.
