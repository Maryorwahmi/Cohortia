Module 1 › Chapter 1.2 › Bit depth and dynamic range
Definition

Bit depth

Number of bits per sample determines amplitude precision, dynamic range, and noise floor.

Why it matters
More bits allow finer amplitude steps, making quiet sounds clearer and avoiding quantization noise.
Production guidance
Record and edit at 24-bit for headroom; consider 16-bit for final builds if platform constraints require it.
Key Takeaway
Use higher bit depth during production; preserve masters and only reduce precision when necessary for delivery.
Quick reference
Sampling settings example:
sampling_rate: 48000
bit_depth: 24
file_type: WAV (master)

Export for runtime:
format: OGG
bitrate: 160 kbps
Misconception
You cannot improve a low-bit capture by later rising bit depth; lost precision is gone at capture time.
