Module 1 › Chapter 1.1 › Game vs Linear
Side-by-side
Linear (Film)
Single timeline, fixed edits, full control over sequencing.
Interactive (Game)
Event-driven, modular assets, must blend across unpredictable player choices.
Production Impact
Design assets as stems and variants, document event logic, and plan testing for many states instead of a single playback path.
Common Mistake
Dropping a finished film mix into a game and expecting it to respond naturally — it will not, because it lacks modularity.
