Module 1 › Chapter 1.1 › Dynamic Mixing
Layer Architecture
  • • Ambience: background atmosphere, lowest priority for immediacy.
  • • Music stems: adaptable layers for theme and intensity.
  • • Foley & SFX: immediate, player-action-related sounds.
  • • Voice/UI: highest priority for clarity and information.
Example Rule
On voice line start: reduce music stem by 8 dB, lower ambience by 4 dB for duration.
Practical Cards
Testing Tip
Always test mixes with gameplay audio and music playing together on multiple outputs to ensure balance.
Automation
Create simple conditional ducks for frequent contexts: combat, dialogue, cutscene, UI prompt.
Key Takeaway

Define priority and automation rules so essential sounds remain audible and immersion stays intact.
