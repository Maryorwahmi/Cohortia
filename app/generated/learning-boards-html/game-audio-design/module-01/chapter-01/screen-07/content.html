Module 1 › Chapter 1.1 › Non-linear Audio
State → Event → Parameter
• State: Exploration — calm ambience, lower percussion.
• Event: Enemy spotted — trigger intensity increase.
• Parameter changes: music mix, filter cutoff, ambience level.
Example Rule
If enemyCount > 0 then blend combat theme and raise percussion level proportional to enemyCount.
Key Takeaway

Think in events and states, and map parameters that change to convey game context clearly.

Event Table (Example)
Event: Enemy Spotted — Action: Start combat stem, raise percussion, reduce ambient volume by 6 dB.
Event: All enemies defeated — Action: Return to exploration theme, restore ambience.
Event: Player Low Health — Action: High-pass music, heartbeat low-pass and louder.
