Module 1 › Chapter 1.1 › Analyzing Feedback
Activity Steps
  1. 1. Select a game and a 15–20 minute segment.
  2. 2. Identify five distinct audio cues during play.
  3. 3. For each: name the sound, state the information it gives, how you reacted, and what would be lost without it.
  4. 4. Submit annotated notes as your milestone.
Example Template
Game: [Title]
Segment: [e.g., First boss fight]
Audio Cue 1:
    Sound: [e.g., 'boing' on bounce]
    Information: [e.g., 'successful hit / enemy stunned']
    Influence: [e.g., 'encouraged repeat jumps']
    Without sound: [e.g., 'less impact, uncertain feedback']

[Repeat for 4 more cues]
Key Takeaway

Focused listening reveals which sounds are functional and which are atmospheric; aim to design both with intent.
