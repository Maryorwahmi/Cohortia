Module 1 › Chapter 1.1 › Gameplay Feedback
Workflow
  1. 1. Identify action and required information.
  2. 2. Select sonic attributes that convey meaning quickly.
  3. 3. Build variations to reduce repetition and fatigue.
  4. 4. Test mix against music and ambience for clarity.
Concrete Example
Platformer: whoosh for jump, pluck for landing on a target, distinct stinger for successful combo.
Common Mistake
Using ambiguous or similar sounds for different actions, causing confusion under pressure.
Design Cards
Action → Sound
Pick up item → short metallic chime (confirms collection). Damage taken → low thud with minor dissonant tail (signals harm).
Variation
Create 3 variants per frequent cue using pitch, timing, or layered textures to avoid fatigue.
Key Takeaway
Design feedback to be faster and clearer than visual cues for immediate actions.
