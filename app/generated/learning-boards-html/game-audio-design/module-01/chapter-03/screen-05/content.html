Module 2 › Chapter 1.3 › Pre‑production
Definition

Audio style guide & constraints

Create clear, actionable rules: palette, loudness targets, file types, memory budgets, and naming conventions.

Include platform-specific notes so assets prepared for mobile won't overload console memory, or vice versa.

Define which gameplay parameters (distance, health, speed) will influence audio behavior later in middleware and engine integration.

Key Takeaway

A style guide saves time. It clarifies both creative direction and technical limits before assets are created.

Concrete example
Sci‑fi shooter constraints
Specify compressed gunshot stems under 150kb, synth pad with two loopable layers, and a reverb style for large interiors. List loudness target and sample rate so mixers can keep levels consistent.
Common misconception
Some teams treat the style guide as optional. The reality is that it prevents ambiguity and reduces late-stage fixes that cost weeks of rework.
