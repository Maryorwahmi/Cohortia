Module 2 › Chapter 1.3 › Music Composition
Process

Compose for interaction

Compose layered music that can change intensity based on game states like exploration versus combat.

Provide stems, loop points, tempo maps, and suggested parameter triggers for middleware authors.

Test transitions with simple state changes so music feels seamless during gameplay shifts.

Key Takeaway

Think layers, not single tracks. Layers let the game shift mood fluidly and avoid abrupt musical cuts.

Concrete example
Create three stems for combat: ambience pad, rhythmic pulse, and full orchestral hits. Expose an intensity parameter so middleware crossfades between stems as tension increases.
Common misconception
Avoid treating the score like a linear album. Game music must be prepared for transitions and branching playback.
Try this

Create a two-layer loop that can switch between calm and tense versions using a single intensity parameter in middleware.
