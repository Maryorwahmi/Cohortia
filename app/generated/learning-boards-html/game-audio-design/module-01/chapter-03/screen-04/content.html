Module 2 › Chapter 1.3 › Pipeline Stages
Process

Pipeline timeline

1
Concept & Pre‑production
Set vision, create an audio style guide, list technical constraints and feature needs.
2
Asset Creation
Record, synthesize, compose, and edit assets in a DAW with clear naming and stems.
3
Middleware Implementation
Build events, add variation and parameters for interactive control.
4
Engine Integration
Expose event calls to gameplay code and verify behavior in context.
5
Mix, Optimize & Fix
Balance loudness, reduce memory and CPU, and address playback issues through playtesting.
Key Takeaway

Treat the pipeline as an iterative loop. Early integration tests reveal necessary asset changes and reduce wasted work.

Example
Fantasy RPG case
Early on the team decides on orchestral cues and layered creature vocals. Sound designers record foley and synth layers, composers deliver stems for adaptive battle music, and middleware events combine these into combat states that evolve based on enemy count.
