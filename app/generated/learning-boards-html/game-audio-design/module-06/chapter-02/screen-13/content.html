FMOD Studio: Dynamic Mixing in Action

An Overview of Implementing Ducking and RTPCs

Task 1: Audio Ducking for Dialogue

Learn to create a ducking system where background music lowers when dialogue plays. This involves setting up buses and configuring sidechain compression in FMOD Studio.

Task 2: RTPC for Music Intensity

Implement an RTPC to control music intensity based on a game parameter like 'Danger_Level'. You'll map this parameter to music volume using automation curves.
