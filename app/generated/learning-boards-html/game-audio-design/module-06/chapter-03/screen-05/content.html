File Formats

Choosing the Right Audio Format

The choice of audio file format significantly impacts memory, disk I/O, and CPU. Matching the format to the asset's use case is crucial for optimization.

WAV (Uncompressed)

Highest quality, largest size. Ideal for short, critical one-shot sounds.

OGG Vorbis (Lossy Compressed)

Good compression, decent quality, royalty-free. Popular for music, dialogue, ambient loops.

MP3 (Lossy Compressed)

Common, good compression. Licensing can be a concern for some developers.

ADPCM (Lossy Compressed)

Fast decompression, moderate compression. Often used for smaller, repetitive SFX.

Common Mistake

Using a single format for all audio assets, leading to inefficiencies (e.g., WAV for background music).

Key Takeaway

Match the audio format to the asset's specific needs to optimize for quality, size, and performance.

Format Selection Flow

Is it a short, critical one-shot sound?
Yes: WAV (PCM)
No: Is it a longer sound (music, dialogue)?
Yes: OGG Vorbis / MP3
Other SFX: ADPCM
