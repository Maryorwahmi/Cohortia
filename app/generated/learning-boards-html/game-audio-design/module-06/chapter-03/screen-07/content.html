Compressed Formats

OGG Vorbis & MP3

Lossy compressed formats are essential for managing longer audio files, balancing reduced file size with acceptable audio quality.

Lossy Compression

Discards some audio data to achieve smaller file sizes.

OGG Vorbis

Good compression, decent quality, royalty-free. Ideal for music, dialogue, ambient loops.

MP3

Common, good compression. Licensing considerations may apply.

Example Use Case

A 3-minute background music track for a level. Compressing it with OGG Vorbis significantly reduces memory and disk footprint.

Key Takeaway

Use OGG Vorbis or MP3 for longer audio assets to save memory and disk space, carefully balancing compression quality.

Compression Trade-offs

Smaller File Size

Reduced memory & disk I/O

Potential Quality Loss

Audible artifacts if over-compressed

CPU Decompression

Requires processing power

Memory Efficient

Good for long files
