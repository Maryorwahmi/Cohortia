Compressor controls
  • Threshold: level where compression starts.
  • Ratio: how much loud parts are reduced.
  • Attack: how fast it reacts to peaks.
  • Release: how quickly it returns to normal.
Misconception
Compression always makes things louder. It controls dynamics; use makeup gain separately.
Concrete Example
Punch impact
Start with threshold where gain reduction is visible, ratio 3:1, attack 5–10 ms, release 50–150 ms. Adjust to taste.
Key Takeaway
Use compression to tame dynamics while preserving transient punch. Listen for lifelessness as a sign of over-compression.
