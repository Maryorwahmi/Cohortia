Module 3 › Chapter 3.3 › Reverb vs Delay
Reverb
Creates dense reflections and decay. Use to add natural space or match a game's environment. Keep decay time and wet level conservative for SFX.
When to avoid
If the sound needs precise positional cues, heavy reverb will reduce clarity.
Delay
Repeats the sound at set intervals. Use for echoes, ricochets, or rhythmic space. Short delays can thicken sounds without washing them out.
Creative use
Multiple short delays can simulate fast reflections, while long delays create obvious echoes.
Key Takeaway
Match the effect to the environment. Use subtle settings and test in context to avoid muddiness.
