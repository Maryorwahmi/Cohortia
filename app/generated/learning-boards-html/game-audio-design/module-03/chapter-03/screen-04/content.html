Module 3 › Chapter 3.3 › What is a DAW
Definition

A DAW is software for arranging, editing, applying effects, and exporting audio. It centralizes tools you use to make raw recordings into usable game assets.

Analogy
Think of the DAW as a workshop bench. Tracks are bins, the timeline is a ruler, and effects are tools you clamp on the signal.
Common Misconception
A DAW doesn't replace a good recording. It improves and shapes what you have. Capture quality matters.
Key Takeaway
Focus on how the DAW's parts map to tasks: record, clean, shape, mix, export.
