Module 3 › Chapter 3.3 › Hands-on: Thud Edit
Step Script (example)
1. File → Import → thud.wav
2. Trim leading and trailing silence
3. Apply fade-in 40–80 ms and fade-out 40–80 ms
4. Select clip → Normalize to -3.0 dB
5. EQ: cut 400–800 Hz, small boost 2–4 kHz
6. Compress lightly: threshold moderate, ratio 3:1, attack 5–10 ms
7. File → Export → thud_edited.wav (WAV, 44.1 or 48 kHz, 16-bit)
Reflection
At each step listen and compare. Note which step most improved character and why.
Concrete Checks
  • No clicks at start or end after fades.
  • Peak below 0 dB after normalization.
  • EQ changes increase clarity, not harshness.
  • Export as WAV for source asset.
Key Takeaway
Work in small steps and document each setting so you can repeat results later.
