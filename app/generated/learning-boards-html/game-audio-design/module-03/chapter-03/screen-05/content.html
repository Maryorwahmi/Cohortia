Module 3 › Chapter 3.3 › Basic Editing
Step-by-step
1. Trim: Remove leading/trailing silence but preserve transient energy.
2. Fade: Apply short fade-in and fade-out to avoid clicks.
3. Gain: Set clip-level so processing has headroom.
4. Normalize: Raise peak to target, after trims and fades, usually leaving headroom (e.g. -3 dB).
Common Mistake
Normalizing before trimming can mask the true peak. Always clean then normalize.
Concrete Example
Editing a 'thud' recording
  • Trim silent lead and tail.
  • Apply 50 ms fade-in and 80 ms fade-out.
  • Increase clip gain slightly, then normalize to -3 dB.
Key Takeaway
Order matters: trim, fade, gain, normalize. This preserves transient clarity and avoids artifacts.
