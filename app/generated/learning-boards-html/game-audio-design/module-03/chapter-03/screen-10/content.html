Saturation & Distortion
Add harmonics to thicken or grit to make sounds aggressive. Use subtle saturation for warmth; use stronger distortion for weaponized effects.
Misconception
Louder equals better. Distortion increases perceived loudness but can introduce harsh clipping if overused.
Pitch Shifting
Use to change perceived size or create variations. Combine shifted layers with EQ to keep naturalness.
Key Takeaway
Layer pitched and processed copies for depth. Always check for artifacts when shifting pitch.
