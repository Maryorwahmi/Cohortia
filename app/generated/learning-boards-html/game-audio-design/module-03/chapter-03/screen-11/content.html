Module 3 › Chapter 3.3 › SFX Workflow
Workflow Steps
  1. Import: label tracks and set session sample rate.
  2. Edit: trim, fade, and clean noise.
  3. Process: EQ, compression, saturation, pitch layers.
  4. Mix: balance levels and pan; prepare stems if needed.
  5. Export: render lossless and document settings.
Export tip
Export as WAV for source assets. Use OGG only if required for runtime and after quality checks.
Concrete Example
Export settings checklist
Sample rate: 44.1 or 48 kHz. Bit depth: 16-bit for final assets unless higher is required. Format: WAV for source, OGG for runtime if permitted.
Key Takeaway
Document your session and export settings so assets are consistent and engine-ready.
