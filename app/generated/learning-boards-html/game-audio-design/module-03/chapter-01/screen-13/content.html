Template (use for each SFX)
---
SFX Name: [e.g., Player Sword Swing]
1. Description: [words that capture the sound]
2. Sonic Analysis:
   - Pitch: [high / low / rising / falling]
   - Timbre: [metallic / organic / synthetic / gritty]
   - Dynamics: [sharp attack / swell / steady]
   - Duration: [very short / short / long]
3. Purpose/Emotion: [what does it tell the player?]
4. Alternative Idea: [one change and predicted effect]
---
Use this template to make decisions explicit. Then implement a single change and test in the full mix to see if the meaning shifts as expected.
Example analysis
SFX: UI Menu Select — Description: bright chime. Pitch: high. Timbre: glassy. Dynamics: sharp attack, quick decay. Duration: very short. Purpose: confirms selection, feels pleasant. Alternative: lower pitch slightly to make it feel less urgent and more grounded for a darker UI theme.
Key Takeaway

Practice targeted listening using one change at a time. Test changes in the full game mix to validate design choices.
