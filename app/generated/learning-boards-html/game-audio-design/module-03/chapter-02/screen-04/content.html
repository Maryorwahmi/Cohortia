Core Concept

Four acquisition methods

Each method supplies different sonic qualities and constraints. Think of them as tools in a toolkit: choose based on authenticity, timing, cost, and licensing.

Field recording: unique, real-world ambience and events.
Foley: performed, timed interactions and organic character sounds.
Libraries: fast access to many sounds; check licenses.
Synthesis: build sounds from waveforms and noise; perfect for the unreal.
Concrete Example
Monster roar: field-recorded animal grain for body, foley vocalizations for growl timing, library low-end for weight, synthesis for unnatural modulation.
Common Mistake
Relying only on libraries can make a game sound generic. Always consider processing or layering to make borrowed sounds unique.
Key Takeaway
No single method is always best. Blend methods to achieve authenticity, timing, and creative uniqueness while respecting licensing constraints.
