Module 3 › Chapter 3.2 › Foley Artistry
Definition

Foley: perform to create

Use props and deliberate performance to recreate everyday sounds, emphasizing timing and texture.

Props & Space
A quiet room, condenser mic, and a collection of everyday materials are often enough to start experimenting.
Layering
Record separate passes for footsteps, clothing, and incidental sounds. Mix for realism.
Concrete Example
Monster footstep: wet sponge for squish, a bag of cornstarch for crunch, and a low prop thud for weight. Layer and equalize each element to taste.
Common Mistake
Trying to create a complex sound in a single pass. Better: separate elements and record focused takes.
Key Takeaway

Foley is experimental and performative. Record many takes, keep notes, and build a reproducible technique for each effect.
