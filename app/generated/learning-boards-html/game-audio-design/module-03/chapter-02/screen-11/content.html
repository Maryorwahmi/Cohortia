Definition

Synthesis for SFX

Oscillators create tone, noise creates texture, and envelopes shape dynamics. Use them to design concise, repeatable effects.

Parameter example (conceptual)
oscillator: sine
frequency: 880 Hz
envelope: attack 5 ms, decay 200 ms
add: filtered noise burst, low-pass 5 kHz, length 80 ms
optional: slight pitch modulation for life
Concrete Example
A UI beep layered with filtered noise and mild distortion becomes more present on small speakers while staying short and unobtrusive.
Common Misconception
You don’t need elaborate patches. Thoughtful use of a single oscillator plus a short envelope and a noise layer achieves many common SFX.
Key Takeaway

Synthesis is a precise tool for short SFX and texture layers—experiment with small parameter changes to find character quickly.
