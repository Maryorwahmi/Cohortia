Subtractive Synthesis

Sculpting Sound by Filtering Rich Waveforms

Process Overview

Start with a harmonically rich waveform, then use filters to remove frequencies and shape the sound's timbre.

Key Parameters

  • Oscillator: Generates initial rich waveform (e.g., Sawtooth, Square).
  • Filter: Removes frequencies (Cutoff, Resonance).
  • Envelope: Controls how parameters change over time (Attack, Decay, Sustain, Release).
Key Takeaway

Subtractive synthesis is like sonic sculpting: you start with a full sound and carve away frequencies to achieve your desired timbre and movement.

Rich Waveform

Sawtooth, Square (full of harmonics)

Filter Application

Low-pass, High-pass, Band-pass (Cutoff, Resonance)

Shaped SFX

Laser blasts, engine hums, deep bass, sharp leads
