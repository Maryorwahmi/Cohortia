Module 4 › Chapter 4.2 › Exporting Stems and Synchronization
Export checklist
  • Same start point and zero alignment for all stems.
  • Matching sample rate and bit depth across files.
  • Consistent naming convention for clear organization.
  • Trim or pad so loop points and length match when needed.
Quick verification
Import all exported stems into a fresh session and play them together. If you hear phase thinning or unexpected coloration, check start markers and panning. Re-export if needed.
Example filename convention
Music_Base_Pad.wav
Music_Exploration_Melody.wav
Music_Tension_Drums.wav
Key Takeaway

Synchronized exports eliminate many runtime mix problems; always verify in a fresh session.
