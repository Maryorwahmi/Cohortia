Module 4 › Chapter 4.2 › Runtime Control: Volume, Filters, and RTPCs
Common runtime controls
  • Volume fader driven by a game parameter.
  • Low-pass or high-pass filter applied dynamically.
  • RTPC connections that allow tuning without re-export.
Practical mapping example
Map PlayerHealth to two RTPCs: one increases danger layer gain as health falls, another lowers filter cutoff to muffle other layers during a dream state. Use curves to smooth transitions and prevent abrupt jumps.
Example RTPC mapping
// Conceptual mapping
PlayerHealth -> DangerLayer.Gain (map 50->0 to 0->1)
PlayerHealth -> DreamLayer.LowPassCutoff (map 100->0 to 20000Hz->2000Hz)
