Module 4 › Chapter 4.2 › Mix States and Balancing Layers
Plan key mix states
  1. Calm — Base only at steady level
  2. Exploration — Base + gentle melody at -6 dB
  3. Tension — Base + tension drums + low strings
  4. Critical — Add critical layer, raise bass carefully
Balancing tips
  • Keep base consistent to maintain tempo and harmony.
  • Reduce competing midrange energy when adding new layers.
  • Prefer fading out calm layers as tension grows.
  • Document stem levels per state for integration.
Key Takeaway

Define mix states and set stem presets so runtime behavior matches your musical intent.
