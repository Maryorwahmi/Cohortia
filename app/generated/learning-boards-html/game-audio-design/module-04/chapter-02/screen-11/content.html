Stems to prepare
  • base_loop.wav — ambient pad, always on.
  • tension_layer.wav — low-health texture (30–60).
  • danger_layer.wav — critical tension (60–100).
Conceptual middleware plan
Create an Intensity parameter. Map Intensity to tension_layer and danger_layer volumes with overlapping ranges so fades are smooth. Slightly reduce base_loop level when danger_layer is high.
// Pseudo mapping (conceptual)
if Intensity >= 30 && Intensity <= 60:
  tension_volume = map(Intensity, 30, 60, 0, 1)
if Intensity >= 60:
  danger_volume = map(Intensity, 60, 100, 0, 1)
