Module 4 › Chapter 4.2 › Composing with Layers in Mind
Composition steps
  1. 1) Create base loop with clear harmony and tempo anchors.
  2. 2) Write layers that reuse chord tones and align rhythmically.
  3. 3) Make quick DAW snapshots of key mix states to audition combinations.
  4. 4) Adjust initial stem levels to avoid clutter when multiple layers are active.
Example: Health music
Compose an 8-bar ambient pad, a low-health drone that uses the same chord tones, and a critical layer that adds dissonant intervals only on resolution beats. Export snapshots: base-only; base+low; base+critical; all layers. Listen for clashes and adjust voicings.
Key Takeaway

Plan harmonies and rhythms so each layer both stands alone and supports combinations without dissonance.
