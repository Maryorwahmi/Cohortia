Code walkthrough (pseudo)
This example illustrates waiting for a musical cue, playing a stinger, and then starting the combat loop.
// on EnemyEncounter:
// Wait for Exploration_Loop to reach its next designated transition cue
WaitForMusicalCue(Exploration_Loop, "EndPhrase")
Stop(Exploration_Loop, fadeOutDuration=0.5s) // Optional fade out
Play(Enemy_Stinger)
Play(Combat_Loop, fadeInDuration=1.0s) // Fade in Combat_Loop after stinger
Map the string "EndPhrase" in your DAW to a middleware cue. When an event triggers, call the wait function so the change happens on the next marker rather than immediately.
Implementation notes
  • • Use music segments and playlist containers in middleware where available.
  • • Expose marker names in your middleware so game events can reference them by string labels.
  • • Allow for optional fades and precise offsets to tune timing.
Common mistake
Triggering on the next frame rather than a musical cue. This often causes clipped phrases and a loss of musical flow.
