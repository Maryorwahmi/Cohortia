Module 4 › Chapter 4.3 › Middleware Patterns
Architecture overview
Design your middleware configuration to expose markers, segments, and transition rules so game events map to musical behaviors cleanly.
Music Segment
Register a segment, set entry/exit cues, and attach markers for perfect timing.
Playlist Container
Group related segments and define rules for state-based playback and priority.
Transition Rule
Define how to switch between segments: immediate cut, wait-for-cue, play-stinger, or crossfade with custom curve.
Resource Settings
Control preload, memory usage, and mixing limits to avoid runtime spikes.
Example rule
On EnemyEncounter: WaitForCue(Exploration_Loop, "EndPhrase"); Play(Enemy_Stinger); StartSegment(Combat_Loop, fadeIn=1s).
Testing tip
Use middleware preview and script-driven triggers to validate transitions across all markers and segment permutations.
