Hands-on Activity ThreatLevel mapping

Design choices and testing

Conceptual steps
  1. Create Threat_State with Calm, Tension, Danger or create Game Parameter ThreatLevel 0–100.
  2. Decide thresholds, e.g. 0–33 Calm, 34–66 Tension, 67–100 Danger.
  3. Set Playlist transitions or FMOD Transition Regions to react to the chosen ranges.
  4. Add smoothing/hysteresis to avoid rapid switching.
Scenario card
If ThreatLevel spikes from 20 to 80 because many enemies spawn, ensure the transition to Danger happens at the next loop cue or use a short crossfade to keep musical integrity.
Check: does the player notice abrupt cuts? If yes, lengthen the crossfade or use smoothing on the parameter.
