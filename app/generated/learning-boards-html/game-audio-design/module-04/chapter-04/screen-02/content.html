Learning Objectives

A Bloom ladder helps you see progression from understanding to mastery.

Bloom: Learn → Understand → Apply → Master
01
Explain middleware purpose

Describe why Wwise or FMOD Studio is used and how they separate audio from gameplay logic.

VERIFIED COMPETENCY MILESTONE
02
Import and organize assets

Perform project setup and import stems as Music Segments or timeline regions that are ready to sequence or layer.

VERIFIED COMPETENCY MILESTONE
03
Build interactive music structures

Create playlists or music tracks and define transition rules for smooth musical changes tied to gameplay events.

VERIFIED COMPETENCY MILESTONE
04
Map States, Switches, and RTPCs

Use categorical and numerical parameters to control which segments play and how layers blend in real time.

VERIFIED COMPETENCY MILESTONE
