Process Flow Project setup & import

Steps to prepare and import audio

Step sequence
  1. 1. Prepare stems in your DAW and set consistent samplerate and loop points.
  2. 2. Create new project in Wwise or FMOD Studio and set project settings.
  3. 3. Import stems into the Assets or Project Explorer and verify playback.
  4. 4. Save and back up the middleware project.
Common mistake

Importing unsynced stems or different sample rates causes timing drift and loop errors in interactive playback.

Practical example
Import these three stems as tracks or regions and confirm the loop: 
Base_Layer.wav
Melody_Layer.wav
Tension_Layer.wav
Verify they loop cleanly and align to the same tempo. If loops misalign, correct in the DAW and re-export.
