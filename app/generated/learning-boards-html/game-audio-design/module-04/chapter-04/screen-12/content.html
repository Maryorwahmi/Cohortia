Architecture Engine ↔ Middleware data flow

How engine and middleware communicate

Typical flow
  • Gameplay detects condition → engine code posts Event or sets RTPC/State via plugin.
  • Middleware evaluates rules and adjusts audio (segments, layers, effects).
  • Audio engine mixes and outputs sound to the platform.
Integration notes
Use the vendor plugin to expose middleware functions; programmers trigger Events and update RTPCs on gameplay changes. Profile audio performance frequently to avoid overloaded voice counts.
Misconception: middleware polls game state — it does not. The engine must push parameter updates.
