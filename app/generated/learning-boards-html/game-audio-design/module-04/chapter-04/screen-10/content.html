Conceptual steps

Mapping sequence
  1. Create Music Segment Exploration_Theme with three tracks.
  2. Create RTPC Game_Intensity (0–100).
  3. Map Game_Intensity to Melody_Layer volume (0→50 = 0%→100%).
  4. Map Game_Intensity to Tension_Layer (50→100 = 0%→100%).
  5. Test by sweeping the RTPC value and listen for smooth blends.
