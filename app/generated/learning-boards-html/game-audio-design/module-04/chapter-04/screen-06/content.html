Music Segment vs Playlist Container

Music Segment (vertical layering)
  • Contains multiple Audio Tracks, one per stem.
  • Tracks can be routed, muted, or automated via RTPCs.
  • Best for layering where stems play simultaneously and blend dynamically.
Example: Exploration_Theme with Base, Melody, and Tension tracks where each track is enabled by an RTPC or event.
Music Playlist Container (sequencing)
  • Holds multiple Music Segments and defines order and transition rules.
  • Set crossfade times, entry/exit cues, and transition conditions.
  • Ideal for moving between distinct musical sections like intro → loop → outro.
Example: Area_Music that moves from Calm to Tension to Danger based on a State change.
