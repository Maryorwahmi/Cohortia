Events, Music Tracks, and automation

Event + Music Track

Create an Event and add a Music Track. Place Music Segments as regions on the timeline and use Transition Regions to control crossfades or jumps.

Example: Area_Music Event with a Music Track containing Calm_Loop, Tension_Loop, Danger_Loop and a ThreatLevel parameter on an automation lane.
Automation and Playlist Instruments

Use automation lanes to map parameters to volume, crossfades, or routing. Playlist Instruments enable randomized or weighted playback when variation is desired.

Tip: automation curves let you design how smooth or abrupt transitions are as parameter values change.
