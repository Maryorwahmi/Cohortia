Module 04 › Chapter 4.1 › Vertical Re-orchestration
Core idea
Multiple stems combine to form one evolving texture; volume and filters change over time.
Stems example
Pad stem — holds harmony, rarely cut
Melody stem — core identity, stays in most states
Percussion stem — raises rhythmic intensity
Tension stem — dissonant textures that fade in when needed
Checklist
  • All stems aligned to the same bar and beat.
  • Consistent processing to avoid timbral mismatch.
  • Volume staging so fades feel natural.
Illustration
Exploration
Pad + melody + light percussion
Approach
Pad + melody + percussion + low tension bed
Combat
Pad + melody + heavy drums + full tension
Return
Fade tension/drums, keep pad to restore calm
Key Takeaway

Layering lets you change emotional intensity continuously while preserving the piece’s core identity.
