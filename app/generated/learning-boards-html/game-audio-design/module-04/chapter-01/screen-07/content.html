Module 04 › Chapter 4.1 › Layering vs Sequencing
Side A — Layering
Continuous, subtle changes. Good for proximity, health, and environmental shifts.
Keeps musical identity
Lower memory use for variants
Requires clean stem exports and sync
Side B — Sequencing
Discrete changes that replace musical content. Good for distinct states like exploring vs full combat.
Allows fully different instrumentation
Requires matched tempo/key or bridging stingers
Can increase asset count
Example scenario
Player approaches enemy: fade in percussion (layer). Player spotted: jump to combat loop with matching tempo (sequence).
Common mistake
Relying solely on sequencing for small intensity changes causes abrupt transitions and asset bloat.
