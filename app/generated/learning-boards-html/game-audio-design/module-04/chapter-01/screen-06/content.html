Module 04 › Chapter 4.1 › Horizontal Re-sequencing
Core pattern
Segments are self-contained musical blocks designed to be played in different orders based on game triggers.
Segment types
  • Intro — sets the mood before a loop
  • Loop — main repeating section
  • Variation — alternate energy or instrumentation
  • Outro / Stinger — short bridge or punctuated finish
Transition tips
Match tempo and key, align phrase lengths, and add short stingers when necessary to bridge different feels.
Example map
Exploration Loop (8 bars) → Danger Variation (4 bars) → Combat Loop (8 bars)
Stinger: 2-bar transition in shared key to bridge exploration into combat
Test checklist
  • Do loops resolve at compatible phrase points?
  • Are tempos identical or tempo-mapped?
  • Does the bridge maintain harmonic continuity?
Key Takeaway

Design segments and stingers so the engine can reorder music without breaking musical flow.
