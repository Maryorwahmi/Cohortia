Activity: Build and run a simple AR app
Follow these steps to confirm your project is AR-ready and the runtime initializes on an Android device.
Steps
  1. Create new 3D Core project and open Package Manager → Unity Registry.
  2. Install XR Plugin Management, AR Foundation, and ARCore XR Plugin.
  3. Enable ARCore under Edit → Project Settings → XR Plugin Management → Android.
  4. File → Build Settings → Switch Platform to Android.
  5. Player Settings: set Package Name, Minimum API Level to API 24+, IL2CPP, enable ARM64.
  6. Add XR → AR Session and XR → AR Session Origin. Add plane and raycast managers to the origin.
  7. Create cube prefab, attach PlaceOnPlane script and assign prefab.
  8. Build And Run to an ARCore-compatible Android device and test plane tap placement.
What success looks like
A cube appears at the tap location on a detected plane and remains anchored as you move the device.
Checklist
  • ARCore enabled in XR Plugin Management.
  • Package Name unique and Minimum API set.
  • IL2CPP and ARM64 enabled.
  • ARRaycastManager present and prefab assigned.
Troubleshoot
If build fails, confirm Android Build Support module is installed in the Editor. If app runs but plane detection fails, confirm provider installation and device AR support.
