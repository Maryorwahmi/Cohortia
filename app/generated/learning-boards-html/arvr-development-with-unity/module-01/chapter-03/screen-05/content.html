Module 2 › Chapter 1.3 › XR Plugin Management
Enable provider per platform
Providers must be enabled under the platform tab so Unity initializes the correct XR SDK when building or running.
Checklist
  • Select the target platform tab (Android or Standalone).
  • Check the provider you installed, e.g., ARCore for Android or OpenXR for Standalone.
  • Enable "Initialize XR on Startup" for automatic initialization.
  • Restart the Editor if requested to load native bindings.
Misconception
Do not assume installing ARCore registers it automatically for all platforms. You must enable it in the Android tab. Installation makes it available; XR Plugin Management enables it for a platform.
Key Takeaway

Provider must be active for the platform you build; enabling per-platform is the step that lets Unity talk to the device runtime.

Visual: platform tabs
Android tab — providers: ARCore (checked)
Standalone tab — providers: OpenXR (checked)
Toggle: Initialize XR on Startup (checked)
Concrete example
To target Meta Quest via OpenXR: enable OpenXR in the Android tab and ensure any required OpenXR features are set in the OpenXR settings. Confirm the runtime initializes by testing on device after a build.
Troubleshooting hint
If the app shows a blank screen on Quest, confirm the Android tab has the correct provider enabled and that "Initialize XR on Startup" is checked. Also verify Package Name and architecture in Player Settings.
