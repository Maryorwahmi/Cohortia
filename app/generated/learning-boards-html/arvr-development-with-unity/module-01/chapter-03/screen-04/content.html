Install the essential XR packages
Open Window > Package Manager, choose Unity Registry, and install the packages below in order.
Step-by-step
  1. Open Package Manager and switch to Unity Registry.
  2. Install XR Plugin Management first so Project Settings shows the XR tab.
  3. Install AR Foundation and OpenXR Plugin next.
  4. Install platform providers: ARCore XR Plugin for Android, ARKit XR Plugin for iOS, Meta/Oculus plugins as needed.
  5. If building VR interactions, install XR Interaction Toolkit.
Why order matters
  • XR Plugin Management creates the configuration UI where providers appear.
  • AR Foundation exposes APIs that rely on platform providers for runtime access to hardware.
  • Install providers early so dependencies resolve and Editor warnings are minimized.
Key Takeaway

AR Foundation is the cross-platform API; provider packages are required to actually run AR on devices.

Concrete example
If you want plane detection on Android: install AR Foundation and ARCore XR Plugin, then enable ARCore in XR Plugin Management under Android. Without ARCore selected, AR Foundation cannot access the device's AR runtime and plane detection won't work.
Common mistake
Installing only AR Foundation and assuming plane detection will work on a phone. ARCore or ARKit must also be installed and enabled per platform.
