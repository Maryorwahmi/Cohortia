Learning Objectives
A practical, skills-first checklist to set up AR and VR projects in Unity.
01
Manage Packages
Install XR Plugin Management, AR Foundation, OpenXR, and platform providers via the Package Manager so your editor can target XR runtimes.
Mnemonic: Library shelf
VERIFIED COMPETENCY MILESTONE
02
Enable Providers
Use Edit > Project Settings > XR Plugin Management to enable ARCore, ARKit, OpenXR or Oculus for the platforms you target.
Mnemonic: Platform tabs
VERIFIED COMPETENCY MILESTONE
03
Configure Build Settings
Switch platform, choose texture compression and set scripting backend and architecture required for Android AR builds.
Mnemonic: Build switch
VERIFIED COMPETENCY MILESTONE
04
Create AR Scene
Add AR Session and AR Session Origin, attach AR Plane Manager and AR Raycast Manager, and place a prefab in response to a tap.
Mnemonic: Place & play
VERIFIED COMPETENCY MILESTONE
