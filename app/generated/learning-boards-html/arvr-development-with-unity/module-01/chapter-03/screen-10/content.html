Create a minimal VR scene
Use XR Interaction Toolkit and XR Origin to establish a tracked camera and controllers for immersive testing.
Quick steps
  1. Install XR Interaction Toolkit via Package Manager.
  2. Right-click Hierarchy > XR > XR Origin (VR/Desktop).
  3. Add a Plane at 0,0,0 to serve as the floor and a Cube above it.
  4. Configure XR Plugin Management for the target runtime and build to test.
Interaction note
Attach interactable components to scene objects and use controller interactors so users can pick up or push objects in VR.
Key Takeaway

XR Origin plus XR Interaction Toolkit gives you a working rig and common interaction components so you can test VR scenes quickly.

Common mistake
Forgetting to enable the correct provider per platform. If the runtime is not enabled, the headset will show no scene or the system environment instead of your content.
