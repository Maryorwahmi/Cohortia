Setting Up Your First XR Project in Unity

This chapter shows the exact packages to install, how to enable XR providers for Android and Standalone, and the build and player settings needed for ARCore, ARKit, OpenXR and Meta devices. It ends with two practical scene templates: a tappable AR placement flow and a minimal VR origin.

Project setup
Packages + XR Plugin Management
Enable the provider that matches your target: ARCore for Android AR, ARKit for iOS AR, OpenXR or Oculus for VR. Initialize XR on startup so scenes can call tracking APIs at runtime.
Build & Player
Android settings for AR
Switch platform to Android, set scripting backend to IL2CPP, enable ARM64, and pick a unique package name. These options let the device accept and run your APK with ARCore support.
Quick test
Tap to place a cube
If a prefab appears on a detected plane after you tap, installation and configuration are correct. If not, check plugin providers and build settings first.
