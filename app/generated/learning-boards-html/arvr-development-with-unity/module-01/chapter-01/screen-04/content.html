Module 1 › Chapter 1.1 › What is Virtual Reality (VR)?
Definition
Virtual Reality

A fully simulated environment presented via headsets using stereoscopic imagery and head tracking. Designed to replace the user's surroundings and create presence.

Core traits
  • Stereoscopic 3D displays for depth.
  • Head tracking for natural viewpoint changes.
  • Controllers or hand input for interaction.
Common mistake
Assuming VR is only gaming or that presence happens without tuning frame rates and IPD. Performance and comfort are essential design constraints.
Concrete example
Surgical training in VR

Trainees enter a virtual operating room using a PC-tethered headset, manipulate instruments, and receive performance feedback without risking patients.

Key Takeaway
Key Takeaway

VR requires coordinated hardware and software to create presence. Prioritize performance and comfort when designing immersive experiences.
