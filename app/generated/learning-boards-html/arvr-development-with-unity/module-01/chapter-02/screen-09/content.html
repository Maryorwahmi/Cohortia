The Transform component
Every GameObject includes Transform with Position, Rotation, and Scale values you can edit numerically or via the scene tools.
Transform:
  Position: (X: 0, Y: 0.5, Z: 0)
  Rotation: (X: 0, Y: 0, Z: 0)
  Scale:    (X: 1, Y: 1, Z: 1)
Components that affect appearance and physics
  • Mesh Filter: defines the geometry used by the object.
  • Mesh Renderer: renders the mesh using assigned materials.
  • Rigidbody and Collider: enable physics and collisions.
  • Script Components: custom behavior authored by you in C#.
If a model is invisible, check the Mesh Renderer and material assignment in the Inspector first.
Key Takeaway

Use the Inspector to attach and configure components; remember that GameObjects are containers while Components provide function and appearance.
