Module 1 › Chapter 1.2 › Scene vs Game
Scene View
Editing workspace with full navigation and visual tools to place and adjust GameObjects.
  • Use Move, Rotate, and Scale handles to manipulate objects.
  • Double-click an item in Hierarchy to focus it.
  • Scene View supports snapping and orthographic views for precision.
Game View
Runtime preview rendered through the active Camera; used for testing camera framing and UI placement.
  • Shows post-processing and runtime effects not always visible in Scene view.
  • Do not edit transforms here; use Scene View for layout changes.
  • Use Game View to test input, UI, and camera framing.
Check your understanding

Before pressing Play, verify the active Camera transform, ensure visible objects have Mesh Renderers and materials, and confirm lighting is sufficient for the Game View preview.
