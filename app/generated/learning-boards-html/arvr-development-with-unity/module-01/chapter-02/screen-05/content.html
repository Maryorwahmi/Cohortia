Install & configure
Use Hub to install Editor versions and add build support modules for your target devices.
1
Install Unity Hub
Sign in and open the installs tab to pick an Editor version.
2
Choose build support
Select Android Build Support for mobile AR and Quest builds; select UWP for HoloLens or Windows VR.
3
Create a project
Pick 3D Core, name the project, and choose a safe folder location.
Concrete example
If you're testing on an Android phone or Quest, include Android Build Support and the required SDK tools during Editor install so you can build and deploy immediately.
Pitfall to avoid
Installing the Editor without the needed build modules forces you to reinstall or add modules later, which interrupts your workflow.
Key Takeaway

Use Unity Hub to manage versions and include platform modules now to keep your project deployable.
