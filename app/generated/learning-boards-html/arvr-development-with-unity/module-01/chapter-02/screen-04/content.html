Module 1 › Chapter 1.2 › Why Unity
Definition
Unity is an integrated environment for building interactive 3D applications and deploying them across platforms.
Cross-platform
Write once, configure for multiple targets using build support modules.
Component architecture
Compose behavior by attaching components to GameObjects.
Ecosystem
Packages and community assets speed development.
Common misconception
Unity fixes platform differences automatically. It does not. You still configure input and build settings per target.
Concrete example
Install Android Build Support with the Editor so you can deploy the same project to mobile AR and standalone headsets without reinstalling.
Why this matters
Early platform choices reduce rework and keep your prototype deployable to the devices you care about.
Key Takeaway

Unity gives you a unified authoring environment and reusable components, but plan your targets and build support early.
