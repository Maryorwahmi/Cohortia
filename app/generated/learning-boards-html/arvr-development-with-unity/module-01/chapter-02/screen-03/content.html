Hands-on checklist
  1. Create Cube, Sphere, Cylinder in Hierarchy.
  2. Set transforms: positions, rotation, and scale per instructions.
  3. Create Material in Project, set color, and drag onto objects.
  4. Observe properties in Inspector and save the Scene.
Practice repeatedly and use double-click in Hierarchy to focus if objects disappear from view.
Common troubleshooting
  • If an object is invisible, check for a missing Mesh Renderer or an empty material assignment.
  • If camera preview looks wrong, verify the active Camera and its transform in the Hierarchy.
  • For platform builds, verify the Editor version and required build support modules are installed.
These checks map to the Inspector, Project, and Hub respectively.
