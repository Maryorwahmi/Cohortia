Module 1 › Chapter 1.2 › Transform Tools
Visual tools
Use gizmos to drag along X, Y, Z axes for Move, circular handles for Rotate, and cube handles for Scale.
Move
Translate objects by dragging axis handles or entering values in Inspector.
Rotate
Rotate around world or local axes; use numeric angles for exact orientation.
Scale
Scale uniformly or per axis; beware non-uniform scaling effects on physics and UVs.
Numeric example
// Example transforms used in the hands-on activity
Cube:
  Position: (0, 0.5, 0)
  Rotation: (0, 0, 0)
  Scale: (1, 1, 1)
Sphere:
  Position: (2, 1, 0)
  Scale: (1.5, 1.5, 1.5)
Cylinder:
  Position: (-2, 1, 0)
  Rotation: (90, 0, 0)
Use the above numeric values to reproduce the scene precisely and compare visual results with the Game view.
