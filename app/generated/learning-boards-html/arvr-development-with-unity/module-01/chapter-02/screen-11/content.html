Module 1 › Chapter 1.2 › Hands-on
Step-by-step activity
  1. Create Cube, Sphere, Cylinder in Hierarchy.
  2. Set transforms: Cube (0,0.5,0); Sphere (2,1,0) scale 1.5; Cylinder (-2,1,0) rotate X 90.
  3. Create Material in Project: Create > Material. Choose color and drag onto object.
  4. Navigate Scene using right-click + WASD, middle-mouse pan, scroll zoom. Save the Scene.
Verification
Open Game view and press Play to verify objects render and appear where you expect. If objects are invisible, check Mesh Renderer and materials in the Inspector.
