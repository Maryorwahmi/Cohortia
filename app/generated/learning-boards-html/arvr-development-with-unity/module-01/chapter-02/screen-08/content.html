Module 1 › Chapter 1.2 › Hierarchy & Project
Hierarchy (scene instances)
Lists GameObjects in the current scene. Use it to arrange parent-child relationships and to focus or select objects for editing.
Parent-child relationships
Moving a parent moves its children because transforms are relative to parents.
Scene instances vs assets
Deleting an instance from Hierarchy does not remove the source asset from the Project window.
Project (asset storage)
Stores models, textures, materials, scripts, and prefabs. Organize with folders for clarity and reuse.
Concrete example
Import a 3D model into Project, then drag it into Scene. The model appears as an instance in Hierarchy while the original file stays in Project.
Key Takeaway

Keep Project well organized and treat Hierarchy as the scene’s runtime composition; they are separate layers of your project structure.
