Module 1 › Chapter 1.2 › New 3D Project
Step-by-step
  1. Open Unity Hub and click "New Project".
  2. Select the 3D Core template and give the project a clear name.
  3. Choose a dedicated folder that will hold Assets and Scenes.
  4. Open the Editor, then immediately save the default Scene as "MainScene".
Don't use temporary or synced folders for long-term projects.
