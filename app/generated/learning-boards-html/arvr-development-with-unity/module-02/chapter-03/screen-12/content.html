Key Concepts — Part 1

C# Script
File that defines behavior attached to GameObjects.
MonoBehaviour
Base class that connects scripts to Unity's engine and lifecycle.
Start()
Called once before the first frame for initialization tasks.
Update()
Called every frame; suitable for input and frame-based motion.
Time.deltaTime
Seconds since last frame; use to make motion rate-based instead of frame-based.
Input class
Provides GetKey, GetKeyDown, and mouse checks for prototyping input.
Summary
Keep these core terms handy as you prototype: scripts, MonoBehaviour, Start, Update, delta time, and basic input.
