API

Position, Rotation, Scale

Access transform to set absolute positions or move relative to an object's forward vector.
Examples
// Absolute
transform.position = new Vector3(0f, 1f, 0f);

// Relative
transform.Translate(Vector3.forward * speed * Time.deltaTime);

// Rotation
transform.Rotate(0, 90 * Time.deltaTime, 0);
Physics note
If a Rigidbody controls motion, prefer Rigidbody methods over directly setting Transform to avoid simulation conflicts.
Practice
Try this
Set a Cube at Y = 0.5 in Start, then use Update to translate forward with W and back with S while rotating with A and D.
Misconception
Using Translate without Time.deltaTime will make movement dependent on frame-rate, causing different speeds on different machines.
Key Takeaway

Choose absolute or relative transform methods deliberately and scale motion by delta time for consistent behavior.
