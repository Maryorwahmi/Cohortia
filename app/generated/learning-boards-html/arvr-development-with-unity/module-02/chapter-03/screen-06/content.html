Public vs [SerializeField]

Public fields show in the Inspector. [SerializeField] exposes private fields while keeping encapsulation in code.

Example
public float moveSpeed = 5.0f;
[SerializeField] private GameObject targetObject;
Common mistake
Not assigning references in the Inspector leads to NullReferenceException. Always check for null before using external objects.
Practical tips
  • Keep fields private by default; expose what needs tweaking with [SerializeField].
  • Use clear names like moveSpeed or targetObject so it's obvious in the Inspector.
  • Remember Inspector changes during Play are temporary; copy values back if you want them persistent.
Key Takeaway

Expose tweakable fields to speed iteration, and protect against null references when using assigned GameObjects.
