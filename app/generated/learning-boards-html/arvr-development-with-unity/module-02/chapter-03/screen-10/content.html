Starter code
using UnityEngine;

public class Mover : MonoBehaviour
{
    public float speed = 5.0f;

    void Start()
    {
        Debug.Log("Mover script started!");
    }

    void Update()
    {
        if (Input.GetKey(KeyCode.W))
        {
            transform.Translate(Vector3.forward * speed * Time.deltaTime);
        }

        if (Input.GetKey(KeyCode.S))
        {
            transform.Translate(Vector3.back * speed * Time.deltaTime);
        }

        if (Input.GetKey(KeyCode.A))
        {
            transform.Rotate(0, -90 * Time.deltaTime, 0);
        }

        if (Input.GetKey(KeyCode.D))
        {
            transform.Rotate(0, 90 * Time.deltaTime, 0);
        }
    }
}
Attachment & Test
Create a Cube at X:0 Y:0.5 Z:0, attach Mover, press Play, and use W,A,S,D to move and rotate. Watch the Console for the Debug.Log message from Start to confirm the script ran.
Live tweaking
Change speed in the Inspector during Play to observe immediate effects. Remember those Play-mode edits are temporary unless saved.
Common error
NullReferenceException occurs when references aren't assigned. Add checks like if (targetObject != null) before using it.
Reflection prompt
Which lines run once and which lines run every frame? Why does that distinction matter for initialization and performance?
Key Takeaway

This script ties together lifecycle, inspector fields, transforms, delta-time, and input to form a working prototype you can iterate on.
