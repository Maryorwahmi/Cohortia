Learning Objectives

These four skills prepare you to script basic XR interactions and prototype movement and input quickly.

01
Understand MonoBehaviour & script structure
Identify why scripts inherit from MonoBehaviour and how Unity connects your code to GameObjects. This matters because it gives access to lifecycle hooks and components like Transform.
Verified competency milestone
02
Differentiate Start(), Update(), FixedUpdate()
Explain when to initialize once versus update every frame or run fixed-timestep physics. This avoids heavy work in per-frame updates.
Verified competency milestone
03
Declare variables and use the Inspector
Use public and [SerializeField] to expose values so designers can tweak speed, references, and settings without code edits.
Verified competency milestone
04
Move objects with Transform and Time.deltaTime
Implement Translate or direct position changes multiplied by Time.deltaTime so motion is consistent across frame rates.
Verified competency milestone
