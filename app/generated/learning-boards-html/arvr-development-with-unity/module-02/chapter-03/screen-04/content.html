Definition

What MonoBehaviour provides

MonoBehaviour is the base class that registers your script as a component Unity can manage. It exposes lifecycle hooks, transform access, and component utilities.

Concrete example
Attach public class MyMover : MonoBehaviour to a Cube. Inside Update, calling transform.Translate moves that specific Cube each frame.
Common misconception
A plain C# class not inheriting MonoBehaviour will not be treated as a component and won't receive Start or Update calls from Unity.
Key Takeaway

MonoBehaviour is the bridge that lets Unity call your methods and give your script access to the GameObject's components.

Inspect this
Component behaviors
  • transform property points to the GameObject's Transform component.
  • GetComponent() retrieves sibling components on the same GameObject.
  • Enabled components receive Start and Update; disabled ones do not.
