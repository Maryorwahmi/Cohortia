API Reference

Input.GetKey / GetKeyDown / GetKeyUp

Poll keyboard and mouse states inside Update to react to held keys or single presses.
Examples
// Held
if (Input.GetKey(KeyCode.W)) { /* move forward while held */ }

// Pressed this frame
if (Input.GetKeyDown(KeyCode.E)) { /* trigger once */ }

// Released this frame
if (Input.GetKeyUp(KeyCode.E)) { /* on release */ }
Notes
Where to check
Perform input checks in Update for consistent per-frame sampling. Avoid relying on FixedUpdate for input events.
Use case
Use keyboard checks for rapid prototyping. Later swap to XR controller input without changing the concept of per-frame polling.
Misconception
GetKeyDown detects the press only in the single frame it occurred; don't use it for continuous actions like walking forward.
Key Takeaway

Choose the correct input check for the intended behavior: hold, press-once, or release events.
