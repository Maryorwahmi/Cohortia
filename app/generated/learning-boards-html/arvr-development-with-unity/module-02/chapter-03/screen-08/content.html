Module 3 › Chapter 2.3 › Time.deltaTime
Concept

Use delta time for stable motion

Scaling by Time.deltaTime converts per-frame deltas into per-second rates so movement is consistent across machines.
Code snippet
void Update()
{
    if (Input.GetKey(KeyCode.W))
    {
        transform.Translate(Vector3.forward * speed * Time.deltaTime);
    }
}
Misconception
Assuming fixed frame timing leads to faster movement on high-refresh hardware; always use delta time unless working with fixed timesteps.
Practice
Test idea
Run on machines with different frame rates or change Editor Quality settings to confirm consistent movement when using Time.deltaTime.
FixedUpdate note
For physics operations use FixedUpdate and Time.fixedDeltaTime to align with Unity's fixed timestep.
Key Takeaway

Multiply motion by Time.deltaTime to express speed in units per second and keep movement stable across frames.
