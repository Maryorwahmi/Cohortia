Key Concepts — Part 2

transform
Programmatic access to position, rotation, and scale for direct manipulation.
[SerializeField]
Expose private fields to the Inspector so you can tune values without changing code access modifiers.
Lifecycle discipline
Put initialization in Start, input and motion in Update, and physics in FixedUpdate for predictability.
Chapter summary
These patterns make your XR prototypes easier to build, tune, and debug. Practice converting keyboard tests to XR controller input to continue progressing.
