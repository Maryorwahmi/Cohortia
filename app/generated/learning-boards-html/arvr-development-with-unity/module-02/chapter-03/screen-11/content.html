Module 3 › Chapter 2.3 › Common Mistakes
Typical errors
NullReferenceException
Ensure inspector fields are assigned or add if (target != null) checks before use.
Missing Time.deltaTime
Movement without delta time varies by frame rate; always scale per-frame changes by delta time.
Heavy Update work
Move expensive calculations off Update or cache results to avoid frame drops.
Debugging checklist
  1. Confirm Start runs with Debug.Log to validate attachment.
  2. Inspect assigned fields in the Inspector before Play.
  3. Check Console for exceptions and stack traces to locate missing references.
  4. Profile Update to find costly operations and move them out or cache results.
Developer tip
Add small Debug.Logs and temporarily lower quality settings to reproduce performance issues quickly on your development machine.
Key Takeaway

Follow the checklist: verify initialization, inspector assignments, delta-time usage, and move heavy work away from Update to keep XR experiences stable.
