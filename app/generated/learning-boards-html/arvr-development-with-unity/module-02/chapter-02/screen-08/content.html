Collider types
  • Box Collider — efficient for cuboid shapes.
  • Sphere Collider — efficient for round shapes.
  • Capsule Collider — useful for characters.
  • Mesh Collider — matches complex geometry, more expensive.
Use Is Trigger when you need overlap events but no physical collision response, such as pickups or zone detection.
Practical scenario
To keep a player from walking through a virtual table, ensure the table has a Collider that matches its shape and the player has an appropriate Collider and, typically, a Rigidbody. If the table is static, it can omit a Rigidbody; the player will still collide with the static collider.
Common mistake: expecting visual fidelity from a collider. Mesh Colliders provide shape accuracy, but they can harm performance. Use primitives where possible and combine colliders for complex objects.
Key Takeaway

Colliders define interaction boundaries. Match collider type to shape and performance needs.
