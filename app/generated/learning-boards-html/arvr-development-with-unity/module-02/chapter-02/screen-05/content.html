What each Component does
Transform
Always present. Defines position, rotation, and scale in 3D space.
Mesh Filter + Mesh Renderer
Mesh Filter stores geometry; Mesh Renderer renders it with a material so the object is visible.
Collider + Rigidbody
Collider defines collision boundaries; Rigidbody makes the GameObject respond to physics forces.
Concrete example
To make a bouncing ball: attach a Sphere Mesh Filter, Sphere Mesh Renderer, Sphere Collider, and a Rigidbody. Create a Physics Material with high bounciness and assign it to the collider. Play the scene to confirm the ball bounces instead of passing through the floor.
Common mistake
Expecting Mesh Renderer alone to enable collisions. A visible mesh without a collider will not interact physically.
Key Takeaway

Attach focused Components and test in Play mode to verify their combined effect.
