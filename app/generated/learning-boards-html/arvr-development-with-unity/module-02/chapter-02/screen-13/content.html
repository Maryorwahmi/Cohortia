Module 2 › Chapter 2.2 › Key Concepts
GameObject
The empty container that identifies items in a scene. Components give it capability.
Components
Modular pieces like Transform, Mesh, Collider, Rigidbody, and scripts that you attach to GameObjects.
Transform
Mandatory on every GameObject; sets position, rotation, and scale. Local vs world coordinates matter.
Remember
When something behaves incorrectly, check these components: Mesh Filter & Renderer for visibility, Collider for collisions, Rigidbody for physics, and the parent chain for unexpected transforms.
