Module 2 › Chapter 2.2 › Mesh Filter & Renderer
Roles explained
Mesh Filter: stores mesh geometry (vertices, triangles).
Mesh Renderer: renders that mesh using a material and lighting.
Example: Cube primitive includes both so the object is visible immediately.
Practical notes
If you change the mesh at runtime, ensure colliders still match the visible shape. Materials affect appearance but not physics. Use materials to indicate states like selection or damage without changing physical properties.
Check this when invisible
Verify Mesh Filter has a valid mesh and Mesh Renderer is enabled with a readable material. An empty Mesh Filter results in no visible geometry.
Key Takeaway

Visibility requires both mesh data and a renderer. Changes to appearance don’t imply physics changes.
