Collider + Rigidbody
Both are needed for physical interactions; collider defines shape, Rigidbody enables forces.
Inspector Edits
Make persistent edits outside Play mode. Use Play mode for testing only.
Hierarchy
Use neutral parents for grouping. Children inherit transforms and can simplify coordinated motion.
Final prompt
Before testing a scene, run a quick checklist: Mesh + Renderer for visibility, Collider for interactions, Rigidbody for physics, and parent settings for grouping.
