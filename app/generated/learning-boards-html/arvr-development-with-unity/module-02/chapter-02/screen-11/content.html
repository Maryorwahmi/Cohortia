Module 2 › Chapter 2.2 › Parent & Child
Why use parenting
  • Coordinate movement: move one parent to move many children.
  • Organize scene hierarchy for clarity and performance.
  • Create grouped animations and assembly behaviors.
Example: An empty parent tracks a table; attach multiple props as children so they move together when the table adjusts in AR alignment.
Gotchas
Non-uniform parent scale will multiply into children and may distort meshes and colliders.
Reparenting changes local values; if you need to preserve world position, capture it before reparenting and restore local values after.
Key Takeaway

Use parent objects to group and control children, and avoid unintended distortion by keeping parent scale neutral when possible.
