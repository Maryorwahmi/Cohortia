Transform fields
  • Position: X, Y, Z coordinates in either local or world space.
  • Rotation: orient the object; watch for gimbal rotation in Euler angles.
  • Scale: change the size; non-uniform scaling can distort meshes and colliders.
Example: Parent a virtual lamp to an empty GameObject that tracks a table. When the table moves, the lamp follows because its position is relative to the parent's Transform.
Misconception: Setting a child's global position is the same as changing its local position. They differ: global updates its world coordinates, local updates its coordinates relative to parent.
Practical tips
Use local coordinates for grouped animations and world coordinates for absolute placement.
When precision is required in AR, enter Transform values numerically to match real-world measurements.
If physics drives motion, prefer Rigidbody-based movement over manual Transform changes to avoid conflicts.
Key Takeaway

Master local vs world transforms and prefer Rigidbody for physics-driven motion to avoid transform conflicts.
