Object Manipulation

Transform Tools: Move, Rotate, Scale

Precisely positioning and sizing your GameObjects

The Transform Gizmo

  • •Visual handles that appear on selected objects in Scene view.
  • •Allows direct manipulation along X, Y, Z axes.
  • •Changes are reflected in the Inspector window.
Example

Dragging a red arrow on the gizmo to move an object along the X-axis.

The Tools

  • •Move Tool (W): Translates objects along axes.
  • •Rotate Tool (E): Rotates objects around axes.
  • •Scale Tool (R): Resizes objects uniformly or non-uniformly.
  • •Rect Tool (T): Primarily for 2D UI elements.
Pro Tip

Use keyboard shortcuts (W, E, R, T) to quickly switch between tools.

Key Takeaway

Unity's transform tools and their visual gizmos enable precise control over object position, rotation, and scale, which is fundamental for building accurate 3D environments.
