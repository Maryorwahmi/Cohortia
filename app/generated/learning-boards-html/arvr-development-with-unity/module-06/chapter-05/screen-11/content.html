Common Instruments
  • Time Profiler: samples method execution on threads to reveal hot C# or native calls.
  • Allocations: tracks memory allocations over time and shows allocation stacks.
  • Leaks: finds objects that are never reclaimed and points to retainers.
  • Core Animation / Metal System Trace: helpful for GPU and rendering timing on iOS devices.
Practical Workflow
  1. Deploy a development build to your iOS device.
  2. Open Instruments and select a focused template (Allocations + Time Profiler).
  3. Record while reproducing the issue briefly, then stop and inspect allocation stacks and heavy methods.
  4. Apply a fix and re-run the same trace to compare results.
Key Takeaway

Instruments gives native-level visibility on iOS; use short, repeatable traces to validate fixes and root out leaks or heavy rendering passes.
