Module 6 › Chapter 6.5 › Learning Objectives
Tools and platform focus
Understand the right tool for device-level insight.
Remote Profiling
Connect via Development Build + Autoconnect Profiler to see accurate timings on the connected device.
On-device logging
Use adb logcat on Android and Xcode Console on iOS to read Debug.Log output and crash traces.
Platform profilers
Learn ODT for Quest, Android Studio for OS-level profiling, and Instruments for iOS deep analysis.
Practical milestone
You will deploy a Development Build, connect the Profiler, and verify that a custom marker appears in the CPU Usage timeline.
Mnemonic
D-A-R: Deploy, Attach, Read
Common pitfall
Leaving Deep Profiling enabled for long runs will distort timings—use short captures or custom markers instead.
