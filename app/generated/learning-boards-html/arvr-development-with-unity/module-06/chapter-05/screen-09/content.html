Overview

Oculus Debug Tool (ODT)

An on-headset overlay showing compositor timing, GPU utilization, and texture memory. Use it for live checks while running your build on Quest devices.

Key Readouts
  • • Compositor latency — time to composite final frame buffers.
  • • GPU utilization — relative GPU load; watch sustained peaks.
  • • Texture memory — total texture usage and sudden growth spikes.
Example

While testing a scene, ODT showed high compositor latency concurrent with a texture memory jump. Reducing a few high-resolution textures and switching compression reduced compositor time immediately.

Interpret the overlay

Compositor
Timing, missed frames, and latency spikes that affect perceived smoothness.
GPU
Utilization trends and bursts indicate shader or post-process costs.
Textures
Memory usage and sudden allocations; helpful to catch format or streaming issues.
Key Takeaway

Headset overlays reveal device-level bottlenecks. Always confirm compositor and texture metrics on the target headset after changes.
