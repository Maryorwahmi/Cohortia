Shader Complexity
Complex fragment work, multiple passes, and expensive lighting increase GPU cost and reduce frame rates.
Strategies
  • Use mobile-friendly shaders with fewer instructions and fewer pass
  • Reduce texture resolutions and compress textures for mobile
  • Limit real-time lights and expensive post-processing effects
Misconception
More graphical features always mean better experience — in XR, stable frame rate and low latency trump raw visual fidelity.
Key Takeaway
Tune shaders and URP settings for consistent frame times; measure GPU load on-device before and after changes.
Render Pipeline: URP vs Built-in/HDRP
URP is typically the recommended path for XR because it is lighter and more configurable for mobile targets.
URP advantages
Optimized forward renderer, configurable features, and better mobile performance when tuned.
When not URP
HDRP targets high-end visuals and is usually inappropriate for mobile XR hardware.
Practical check
After switching pipelines or simplifying shaders, profile GPU time on device to confirm real improvement rather than assuming one pipeline is always faster.
