Module 6 › Chapter 6.5 › Deep Profiling
Definition
Deep Profiling records every function call, giving line-level CPU information.
When to use
Short targeted captures to pinpoint invisible hotspots in third-party code or complex scenes.
Misconception
Running Deep Profiling continuously provides reliable runtime numbers — it does not; it distorts timings.
Quick tip
Capture a brief session while reproducing the spike, then disable Deep Profiling and add a targeted custom marker.
Key Takeaway
Use Deep Profiling to find the exact offender, but don't use it to measure final performance metrics.
Example scenario
You see a recurring frame hitch on Meta Quest while many objects update. Start a short Deep Profile capture during the hitch; the profiler shows a third-party update method as the culprit. Drill into the call stack to find the expensive loop.
Capture workflow
  1. Reproduce the hitch on the device via remote profiling to confirm it exists on hardware.
  2. Open Profiler and enable Deep Profile for a short capture span.
  3. Inspect CPU timeline, expand long frames, and follow to the exact function or line.
  4. Add a custom marker around promising code and re-test without Deep Profiling.
