Module 6 › Chapter 6.5 › Key Concepts A
Headset Telemetry
Use device overlays like ODT to see compositor timing, GPU, and texture memory that only appear on hardware.
Profilers + Logs
Correlate timeline data from Android Studio or Instruments with adb logcat or Xcode console entries to find root causes.
Iterative Fixes
Make one change at a time, re-profile on-device, and compare metrics before accepting the result.
Summary

Device-level tools, paired analysis, and repeatable experiments are the practical backbone of XR optimization.
