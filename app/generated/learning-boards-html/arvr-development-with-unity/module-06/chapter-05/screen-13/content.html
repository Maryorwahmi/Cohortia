Module 6 › Chapter 6.5 › Device Bug Debugging
Reproduce & Capture
  • • Reproduce consistently on the target device with a minimal scenario.
  • • Capture a profiler trace and a filtered log stream over the same timeframe.
  • • Add custom profiler markers around suspect code to correlate profiling and logs.
Binary Search Technique

Disable portions of functionality to determine the minimal set required to reproduce the bug. Narrow quickly to isolate the cause.

Logs & Symbolication

Collect device logs and symbolicate native crashes. For Android use adb logcat and for iOS use Xcode device console. Match timestamps to profiler events for root cause analysis.

Common Pitfall

Verbose logging can change timing and hide race conditions. Use conditional, targeted logs instead.

Key Takeaway

Focus on minimal reproduction, bracket code with markers, and correlate profiler data with device logs to find the true cause.
