Remote Profiler connection steps
  1. In Build Settings, enable Development Build and Autoconnect Profiler, then build and deploy to device.
  2. Run the app on the device and ensure device and computer are on the same local network.
  3. Open Unity Profiler and select the connected AndroidPlayer or iOS device from the Active Profiler dropdown.
  4. Reproduce the issue and capture CPU, GPU, Memory, and Rendering timelines for analysis.
On-device logging
Use Debug.Log for targeted messages; view Android logs with adb logcat and iOS logs via Xcode Console. Avoid noisy logs that add overhead.
Platform-specific tools
Oculus Debug Tool (ODT)
Provides headset-level metrics such as compositor stats and texture memory for Quest development.
Android Studio Profiler
Shows OS-level CPU, memory, and network usage that complements Unity's Profiler.
Xcode Instruments
Use Instruments for deep CPU, GPU, and memory traces on iOS devices.
Common mistake
Leaving Development Build and excessive logging on in release builds will slow performance and leak telemetry. Turn them off for production.
