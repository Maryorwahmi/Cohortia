Profiler Walkthrough

Capture CPU & Memory

CPU Timeline

Identify main thread stalls, long-running methods, and sampling hotspots. Short captures focused on the repro are best.

Memory Timeline

Watch for steady allocation growth and large temporary spikes. Use allocation tracking to find hot allocators.

Thread & Trace

Inspect thread activity and method traces to correlate work with frame times and GC events.

ADB Logcat
Use adb logcat to stream device logs. Filter by package name and timestamp to match profiler events. Keep logs focused to avoid perturbing performance.
adb logcat -s Unity ActivityManager PackageManager
Practical Tip

Capture short profiles and a simultaneous logcat stream. Correlate timestamps to pinpoint causes rapidly.

Key Takeaway

Profiler timelines show where things happen; logs explain why. Use both to validate fixes on device.
