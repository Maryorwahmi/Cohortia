Module 6 › Chapter 6.4 › Mesh optimization and LODs
Best practices
  • Reduce polygon count while preserving silhouette.
  • Remove unused vertex attributes like tangents if shaders don't need them.
  • Implement LODs for objects that can be simplified at distance.
When to simplify
If an object's screen size is small or rarely inspected up close, a simplified mesh often suffices and reduces vertex processing cost.
Common mistake
Removing detail where it is visible at close range. Always evaluate LOD switch distances and inspect transitions for popping or quality loss.
Testing tip
Profile scene performance while moving the camera to trigger LOD transitions; confirm triangle counts and GPU time drop as expected.
