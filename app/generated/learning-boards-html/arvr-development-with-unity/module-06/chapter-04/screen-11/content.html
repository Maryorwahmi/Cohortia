Module 6 › Chapter 6.4 › Lighting: baked lightmaps
Baked lighting benefits
  • Precomputes expensive global illumination and shadows into textures.
  • Reduces runtime cost significantly for static scenes.
Light probes
Capture baked lighting at sample points so dynamic objects can receive consistent indirect lighting without full dynamic GI.
Workflow
  1. Mark static geometry and set appropriate lightmap UVs.
  2. Choose bake settings and generate lightmaps via Window → Lighting → Settings.
  3. Place light probes to cover regions where dynamic objects move.
  4. Test runtime appearance and performance.
Misconception
Baked lighting is not a replacement for needed dynamic lights; dynamic lights should be limited and tuned for range and intensity to reduce cost.
