Module 6 › Chapter 6.4 › CPU vs GPU bottlenecks
CPU-bound symptoms
  • High Main Thread time in the Profiler.
  • Large numbers of Batches or SetPass Calls in Rendering.
  • Spikes tied to instantiation, garbage collection, or complex scripting in Update.
Common fixes
  • Static batching, dynamic batching where appropriate.
  • Object pooling to avoid frequent allocations.
  • Cache component references and reduce per-frame allocations.
GPU-bound symptoms
  • High GPU frame time reported by the Profiler.
  • Low number of batches but long fragment or vertex shader times.
  • Performance improves when reducing render resolution.
Common fixes
  • Reduce texture sizes and change compression.
  • Simplify shaders or reduce post-processing effects.
  • Use LODs and reduce overdraw in transparent surfaces.
Quick diagnostic flow
Profile → Is Main Thread or GPU time higher? → Apply corresponding fixes → Re-profile to verify impact.
