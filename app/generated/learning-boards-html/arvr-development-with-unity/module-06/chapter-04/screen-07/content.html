Module 6 › Chapter 6.4 › Static vs Dynamic Batching
Static Batching
Combines non-moving meshes that share a material into a single mesh at build time. Best for large numbers of identical props that will not move.
Pros
  • Massive reduction in draw calls for static scenes.
  • Low runtime CPU overhead for rendering those objects.
Cons
  • Increased build time and potentially higher memory for combined meshes.
  • Not suitable for moving objects.
Dynamic Batching
Combines small meshes at runtime to reduce draw calls for moving objects, but only when meshes meet specific size and shader constraints.
Pros
  • Can reduce draw calls for small, moving meshes without marking them static.
Cons
  • Limited by vertex count, material properties, and shader complexity.
  • Not a replacement for static batching on large numbers of static objects.
Practical rule
Mark only truly static geometry as Static for batching; use dynamic batching selectively and always profile the results.
