Module 6 › Chapter 6.4 › Draw calls and why they matter
What is a draw call?
A draw call is the CPU command to render a set of triangles with a given material and GPU state. Many small draw calls can consume significant CPU time.
Indicators in Unity
  • Profiler: high Batches and SetPass Calls.
  • Scene with many unique objects using separate materials.
Key Takeaway

Reducing draw calls is often the fastest way to lower CPU time for rendering-heavy scenes.

Concrete example
A pack of identical static props like rocks or trees, all sharing a material, can be combined using static batching so the GPU receives a single draw call instead of many.
Common mistake
Relying solely on dynamic batching for large scenes. Dynamic batching is limited to small meshes and has constraints around vertex counts and shader usage.
Action
Mark appropriate GameObjects as Static to enable static batching and re-run the Profiler to compare Batches.
