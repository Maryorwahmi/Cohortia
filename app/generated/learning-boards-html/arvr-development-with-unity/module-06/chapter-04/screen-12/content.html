Module 6 › Chapter 6.4 › Physics optimization
Practical tips
  • Prefer Box, Sphere, and Capsule colliders over Mesh Colliders where possible.
  • Reduce the number of active Rigidbodies and use kinematic where appropriate.
  • Adjust Fixed Timestep in Project Settings to lower physics update frequency if precision allows.
Activation patterns
Delay enabling physics for distant objects or use triggers that only activate simulation when the player is nearby.
Common mistake
Overusing mesh colliders and enabling many rigidbodies unnecessarily. Simplify colliders or combine into fewer physics actors.
Key Takeaway

Tune physics complexity to actual gameplay needs and profile to ensure changes reduce Main Thread time.
