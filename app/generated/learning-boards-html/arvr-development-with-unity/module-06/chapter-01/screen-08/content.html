Module 6 › Chapter 6.1 › Android Settings
Recommended configuration
Minimum API Level: Android 7.0 Nougat (API 24) or higher for ARCore compatibility.
Target API Level: Automatic (highest installed) to align with store requirements.
Scripting Backend: IL2CPP recommended for performance and native plugin compatibility.
Target Architectures: ARMv7 and ARM64 for broad device coverage; prefer ARM64 where possible.
Trade-offs and misconceptions
Including more architectures increases download size. Choose architectures that match your target devices.
IL2CPP reduces managed overhead but increases build time and requires the NDK; plan CI builds accordingly.
Setting an old Minimum API Level to support more devices may exclude newer AR features or break compatibility with XR providers.
Example

Project example: Minimum API 24, Target API Automatic, IL2CPP backend, ARMv7 and ARM64 selected — a balanced starting point for ARCore builds.
