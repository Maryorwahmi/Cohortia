Module 6 › Chapter 6.1 › XR Plug-in Management
How it works
Open Edit → Project Settings → XR Plug-in Management. Each platform has a tab where you can check the providers you need. Unity will prompt to install corresponding packages if they are not present.
Example: Under the Android tab, check ARCore. Unity will ask to install the ARCore XR Plugin if it is missing. After install, ARCore will be available at runtime.
Checks and pitfalls
  • Ensure the plugin package is installed in Package Manager; the checkbox alone is not enough.
  • Only enable providers you will use to keep build size minimal.
  • When targeting multiple platforms, enable providers per-platform tabs, not globally.
Key Takeaway

Use XR Plug-in Management to enable and manage platform-specific XR providers and confirm package installation to avoid runtime failures.
