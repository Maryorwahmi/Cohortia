Module 6 › Chapter 6.1 › Build Modules
Process: Add or verify modules
  1. Open Unity Hub → Installs → gear menu next to your version → Add Modules.
  2. Check Android Build Support or iOS Build Support, include SDK & NDK and OpenJDK where required.
  3. After install, open Unity Editor and confirm external tools via Edit → Preferences → External Tools.
  4. Restart Unity, then run a quick build to verify the toolchain.
Mnemonic: Hub, Modules, Preferences, Restart — follow these steps in order to reduce surprises later.
Common pitfalls and checks
Pitfall: Missing SDK causes "no toolchain" errors when building for Android. Check the SDK/NDK paths in Preferences.
Pitfall: Team members assume the project contains the build module. Each developer's Unity install must include modules they need.
Check: After module install, run an empty scene build to confirm a successful toolchain setup before adding XR features.
Example
Installing Android Build Support prevented a student from seeing compilation errors when exporting an ARCore APK. The missing OpenJDK had been the root cause.
Key Takeaway

Install and verify build modules early to avoid toolchain failures when building for your target platform.
