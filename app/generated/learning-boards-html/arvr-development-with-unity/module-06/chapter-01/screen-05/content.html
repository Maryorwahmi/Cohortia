Module 6 › Chapter 6.1 › External Tools
What each tool does
  • Android SDK: platform libraries and build utilities used to assemble APKs/AABs.
  • Android NDK: native compilers for C/C++ used by plugins and IL2CPP outputs.
  • OpenJDK: Java tools used during packaging and signing steps.
Verification steps
Open Edit → Preferences → External Tools. Confirm SDK and NDK paths or enable Unity's auto-managed options. Verify the OpenJDK checkbox if provided. After changes, restart Unity and run a small Android build to ensure all tools are functional.
Example: IL2CPP compilation failed with native error. The NDK was missing and installing the NDK via Unity Hub resolved the compile failure.
Common misconception

Assuming Android Studio installation alone fixes Unity builds. Unity requires compatible SDK/NDK versions and explicit paths or managed installs.
