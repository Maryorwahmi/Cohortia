Module 6 › Chapter 6.1 › Activity: Configure for ARCore
Step-by-step tasks
  1. Add Android Build Support via Unity Hub (include SDK, NDK, OpenJDK).
  2. File → Build Settings → Select Android → Switch Platform.
  3. Edit → Project Settings → Player: set Company, Product, Package Name to com.cohortia.arplanedetector.
  4. Under Android Other Settings: Minimum API Level 24, Target API Automatic, Scripting Backend IL2CPP, select ARMv7 + ARM64.
  5. Edit → Project Settings → XR Plug-in Management → Android: check ARCore and install ARCore XR Plugin if prompted.
  6. Inspect Assets/Plugins/Android/AndroidManifest.xml to confirm CAMERA permission and AR hardware feature.
Example command visuals
No command line is needed; the lab uses Unity Hub and the Editor UI. Use the listed fields exactly to match store conventions and ARCore requirements.
Common error: after enabling ARCore, the build fails due to a missing package. Fix: open Package Manager, find and install ARCore XR Plugin, then rebuild.
Expected outcome

Project configured for Android ARCore deployment and ready to build an APK or AAB in the next step.
