Module 6 › Chapter 6.1 › Key Concepts
Build Modules
Install Android or iOS build support via Unity Hub so the editor can compile platform packages.
Player Settings
Set package name, API levels, scripting backend, and architectures to control compatibility and identity.
XR Plug-in Management
Enable per-platform providers like ARCore or ARKit and ensure the plugin packages are installed.
Summary

These key items form a deployment checklist: modules, build settings, player metadata, XR providers, signing, and manifests. Verify them before building.
