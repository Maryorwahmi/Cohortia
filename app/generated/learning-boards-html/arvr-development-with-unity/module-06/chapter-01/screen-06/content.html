Module 6 › Chapter 6.1 › Build Settings
Steps to switch platform
  1. Open File → Build Settings.
  2. Select a platform such as Android and click Switch Platform.
  3. Wait for asset re-imports to complete and address any platform-specific warnings.
  4. Confirm Scenes In Build contains your startup scene(s).
Development Build is useful for debugging. Use Release builds for store submissions.
Visual checklist
Confirm: Active Platform shows Android (or iOS) after switch.
Confirm: Scenes in Build contains intended startup scenes; remove test scenes to reduce build size.
Watch: Asset re-import warnings may indicate incompatible plugins or shaders for the platform.
Key Takeaway

Switch platform early in development and manage your scene list to create predictable builds for your target device.
