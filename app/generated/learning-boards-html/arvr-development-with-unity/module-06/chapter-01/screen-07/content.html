Module 6 › Chapter 6.1 › Player Settings
Key fields to set
  • Company Name and Product Name — human-facing and used for defaults.
  • Package Name / Bundle ID — reverse-domain identifier required by platforms.
  • Version and Version Code — increment for each store update.
  • Scripting Backend — Mono or IL2CPP; IL2CPP recommended for performance.
Example package: com.cohortia.arplanedetector — follows reverse-domain style and avoids collisions on stores.
Architecture note
The package identifier is the unique key the operating system and stores use to link updates. Changing the product name does not change this identifier. Plan your identifier before publishing to avoid forcing users to install a new app for updates.
Tip: Use a consistent company domain and include app purpose in the package name to make identification easier.
Check: Before first release, record your keystore and package name in your project documentation.
Key Takeaway

Set stable package identifiers and plan version codes; these values control app identity and update paths on stores.
