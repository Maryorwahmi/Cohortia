Module 6 › Chapter 6.1 › Learning Objectives
01
Install Build Modules
Verify Unity has Android or iOS build support so compilation succeeds.
You will learn how to check and add modules through Unity Hub and why missing modules cause build failures. Mnemonic: Hub → Installs → Add Modules.
VERIFIED COMPETENCY MILESTONE
02
Configure Build & Player Settings
Set package name, API levels, scripting backend, and architectures for your target.
You will practice setting package identifiers and API levels, which determine device compatibility. Mnemonic: Package, API, Backend.
VERIFIED COMPETENCY MILESTONE
03
Enable XR Plug-ins
Use XR Plug-in Management to add ARCore, ARKit, OpenXR, or Oculus providers per platform.
You will enable ARCore under Android or ARKit under iOS so the runtime uses the correct SDK. Mnemonic: XR → Plug-ins per platform.
VERIFIED COMPETENCY MILESTONE
04
Prepare Signing & Manifest
Create or import keystores for Android, and understand iOS provisioning and manifest permissions.
You will generate a keystore and verify AndroidManifest entries like camera permission. Mnemonic: Sign → Manifest → Ship.
VERIFIED COMPETENCY MILESTONE
