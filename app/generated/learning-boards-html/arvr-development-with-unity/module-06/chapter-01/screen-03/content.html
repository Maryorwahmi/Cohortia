Module 6 › Chapter 6.1 › Practical Objectives
Switch Active Build Target
Practice selecting Android or iOS and watch for re-imports. This early change prevents later surprises when packaging for multiple platforms.
Set Player Settings Values
Set company name, product name, package name, API levels, scripting backend, and target architectures ahead of a build.
Enable XR Plug-ins
Enable ARCore for Android or ARKit for iOS so your runtime links the correct SDKs and runtime features.
Verify Manifest & Signing
Confirm camera permission and AR hardware features in the manifest and secure your keystore for signing updates.
Why this matters

These practices reduce build errors, avoid store rejections, and preserve your ability to update published applications.
