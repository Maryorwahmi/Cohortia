Troubleshooting checklist
  1. Confirm Unity build modules are installed.
  2. Check SDK, NDK, OpenJDK paths in Preferences.
  3. Verify active build target and resolve asset re-import errors.
  4. Check XR Plug-in Management and package installation.
  5. Inspect AndroidManifest for permissions and features.
  6. Verify keystore or iOS signing credentials if stores reject packages.
Diagnostic examples
Symptom: Build fails with native compile errors → Check NDK and IL2CPP settings.
Symptom: AR features not initializing → Check that the XR provider is enabled and the plugin package is installed.
Symptom: App installs but camera access is denied → Check AndroidManifest camera permission and runtime permission prompts.
Key Takeaway

Start with modules and tools, then progress through platform, XR providers, manifest, and signing to isolate build and runtime problems quickly.
