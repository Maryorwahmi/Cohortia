Typical manifest entries
<uses-permission android:name="android.permission.CAMERA" />
<uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" />

<uses-feature android:name="android.hardware.camera.ar" android:required="true" />
Edit or place AndroidManifest.xml in Assets/Plugins/Android to control merged output.
Checks and common issues
  • Confirm the camera permission is declared; otherwise runtime camera access will be blocked.
  • Check for AR-specific features required by SDKs; missing features can disable AR functions on some devices.
  • Use the manifest merger report to understand how multiple manifests combine into the final APK.
Key Takeaway

Inspect and, if necessary, manually add permissions and features to the manifest so the OS and store understand your app's requirements.
