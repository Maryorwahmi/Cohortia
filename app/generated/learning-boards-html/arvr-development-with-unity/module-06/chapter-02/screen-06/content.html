Definition

Keystore & Alias

A keystore is a file containing cryptographic keys used to sign Android applications. An alias is a specific key inside that keystore for a particular app.

Create keystore
Open Keystore Manager in Unity's Player Publishing Settings, choose Create New, and select a secure location.
Create alias
Inside the keystore create a new key alias (example: myarkey) with its own password and certificate information.
Select for build
Choose your project keystore and alias before clicking Build so the APK is signed.
Security & Consequence

Use a strong password and back up the keystore file. If you lose it, you cannot sign updates for the same app identity on an app store.

Pro tip
Store the keystore outside your main project folder in a secure backup and document passwords in a password manager.
Key Takeaway

Keystore management is not optional. Treat the keystore and its passwords as the permanent identity of your app.
