Module 6 › Chapter 6.2 › VR Targeting
Checklist
  • Enable Oculus or OpenXR in XR Plug-in Management.
  • Set Minimum API Level appropriate for the headset OS.
  • Consider Linear color space for improved visuals on some headsets.
Sideloading
Use adb install or SideQuest to sideload development builds onto Quest. Use adb logcat to capture headset logs.
Performance note
Headsets often need further optimization compared to phones. Test frame rate and CPU/GPU load with the Unity Profiler connected remotely.
Key Takeaway

Treat VR builds as a special target: plugin, API level, and performance checks matter for a successful headset deployment.
