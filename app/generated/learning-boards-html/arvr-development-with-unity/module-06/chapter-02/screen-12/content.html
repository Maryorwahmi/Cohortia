Module 6 › Chapter 6.2 › On-Device Testing
Test Routine
  1. Install and launch the app on the device.
  2. Run through core scenarios for 60 seconds (plane detection, placement, interaction).
  3. Record performance via Unity Profiler connected remotely.
Diagnostics
Use adb logcat to capture runtime exceptions while the profiler shows CPU and memory pressure. Together they expose where to optimize.
Key Takeaway

A build that runs in the Editor may still perform poorly on device. Always profile and test on the target hardware.
