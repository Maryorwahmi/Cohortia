Module 6 › Chapter 6.2 › adb Install
Commands
adb devices
adb install ARPlaneDetector.apk
adb uninstall com.yourcompany.yourapp
Navigate to your Builds/Android folder in the terminal before running adb install so the command finds your APK immediately.
Example
cd path/to/project/Builds/Android then run the install command for ARPlaneDetector.apk. If install fails because the app already exists, run adb uninstall with the package name and try again.
Common Mistake
Running adb install from a different folder will fail to find the APK. Always confirm your working directory or provide a full path to the apk file.
Key Takeaway

adb install is the reliable, scriptable way to sideload builds during development. Know the folder and package name.
