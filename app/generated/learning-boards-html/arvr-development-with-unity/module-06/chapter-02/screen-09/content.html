Module 6 › Chapter 6.2 › Troubleshooting

Error: INSTALL_FAILED_ALREADY_EXISTS

Cause: Package already present on device. Fix: adb uninstall <package.name> then adb install again.

Error: INSTALL_FAILED_INSUFFICIENT_STORAGE

Cause: Not enough free storage on the device. Fix: free storage or uninstall large apps before reinstalling.

Error: device not found / empty adb list

Cause: USB Debugging off or RSA key not accepted. Fix: enable USB Debugging and accept the computer's RSA prompt on the device.

Check

If errors persist, use adb logcat to capture logs for Unity and ActivityManager to reveal deeper causes.
