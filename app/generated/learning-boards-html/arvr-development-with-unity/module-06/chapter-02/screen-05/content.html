Module 6 › Chapter 6.2 › Build Settings
Definition

Platform & XR Plugin Selection

Choose Android in Build Settings and enable the correct XR plugins in Project Settings to match your target device.

Scenes
Ensure the scenes you want in the build are checked in File > Build Settings.
XR Plug-in Management
Enable ARCore for AR, or Oculus/OpenXR for VR. These control runtime subsystems and device integration.
Player Settings
Confirm package name, Minimum API Level, and recommended color space for your target headset.
Common Mistake
Leaving the wrong XR plugin enabled can cause missing runtime subsystems and errors when the app launches on the device.
Quick Checklist
  • Android selected in Build Settings
  • Correct scenes checked
  • ARCore or Oculus/OpenXR enabled in XR Plug-in Management
  • Player Settings: package name and Minimum API Level verified
Key Takeaway

XR plugin and Player Settings choices directly affect whether the APK will run on your target device; check them before building.
