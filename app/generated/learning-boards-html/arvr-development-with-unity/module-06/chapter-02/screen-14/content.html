Module 6 › Chapter 6.2 › Key Concepts
APK
The Android Application Package produced by Unity for installation.
Developer Options
The hidden system menu that enables USB Debugging for adb access.
Keystore
Holds the cryptographic key that signs your app. Back it up securely.
Summary

Keep a checklist: enable USB Debugging, create and secure a keystore, build a versioned APK, and use adb to install and collect logs for debugging.
