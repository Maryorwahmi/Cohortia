Learning Objectives

Four targeted competencies to practice during the hands-on activity.

Learn → Understand → Apply → Master
01
Build an APK from Unity
Create a distributable Android Application Package and learn where Unity writes the output and which scenes are included.
VERIFIED COMPETENCY MILESTONE
02
Create and manage a keystore
Generate a keystore and alias within Unity's Publishing Settings, understand passwords and the consequence of losing the keystore.
VERIFIED COMPETENCY MILESTONE
03
Prepare your Android device
Enable Developer Options and USB Debugging so your computer can install and debug the app via adb.
VERIFIED COMPETENCY MILESTONE
04
Install and debug with adb
Use adb devices, adb install, and adb logcat to verify installs and capture runtime logs for diagnosis.
VERIFIED COMPETENCY MILESTONE
