Build vs Build And Run

Decide if you want just an APK file or immediate deployment and launch on a connected device.

Build: Compiles APK and saves it to disk for manual installation and archiving.
Build And Run: Compiles and automatically installs on a connected device if adb recognizes it.
Best practice: Save builds to Builds/Android with versioned filenames like ARPlaneDetector_v1.apk.
Example

Create a folder 'Builds/Android' in your project root and save the first APK as ARPlaneDetector.apk. This keeps the output organized and makes manual adb installs straightforward.

Key Takeaway

Use Build for archival control and Build And Run for quick iteration when your device is prepped and recognized.
