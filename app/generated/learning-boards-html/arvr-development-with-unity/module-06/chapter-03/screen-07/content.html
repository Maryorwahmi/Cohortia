Architecture
Xcode Project Structure
Targets
Unity-iPhone target drives build settings and signing.
Info.plist
Contains Camera Usage Description and other runtime keys.
Frameworks
ARKit and system frameworks linked during build.
Quick checks before deploying:
  • Bundle Identifier matches App ID in developer portal.
  • Info.plist contains Camera Usage Description.
  • ARKit framework appears under Link Binary With Libraries.
Example: Info.plist excerpt
<key>NSCameraUsageDescription</key>
<string>Used for augmented reality experiences to place virtual objects in your environment.</string>
Common Mistake

Assuming Unity will resolve signing; in truth you must open Xcode to choose Team and resolve provisioning.
