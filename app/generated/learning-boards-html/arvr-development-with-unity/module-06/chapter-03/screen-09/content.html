Process
Deploy to Device
  1. Connect device via USB and unlock it.
  2. Select device from Xcode scheme selector and press Run.
  3. If prompted on device, go to Settings → General → VPN & Device Management and trust the developer.
  4. Allow camera permission when requested and observe AR initialization.
First-run checks
  • Camera permissions prompt appears and accepts the usage string.
  • AR plane detection initializes without immediate crashes.
  • Xcode console shows no missing framework or signing errors.
Example: Trust flow
On first install from your Team, the device will require you to trust the developer profile under VPN & Device Management to run unsigned apps from that account.
Pro Tip
Keep Console.app open on macOS to capture device logs if the app closes instantly after launch.
