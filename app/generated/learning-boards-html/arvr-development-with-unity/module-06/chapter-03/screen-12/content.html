Build & Deploy Checklist
Prerequisites
Mac + Xcode, Apple Developer account, AR-capable device.
Unity Setup
Switch to iOS, set bundle ID, IL2CPP, ARM64, camera string.
Build & Open
Build to Builds/iOS, open .xcodeproj in Xcode.
Deployment Steps
  1. Select Team under Signing & Capabilities and enable automatic signing.
  2. Connect your device and choose it as the run destination.
  3. Click Run in Xcode and accept trust on the device if prompted.
  4. Verify camera permission and AR plane detection on launch.
Troubleshooting
If you see signing errors, check bundle id matches App ID, account is in Xcode Preferences → Accounts, and device UDID is enrolled in the provisioning profile. Use Xcode console to read runtime errors.
