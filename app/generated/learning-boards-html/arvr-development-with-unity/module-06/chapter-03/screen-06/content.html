Process
Enable ARKit & Build
  • Edit → Project Settings → XR Plug-in Management → iOS → check ARKit provider.
  • Install any prompted ARKit packages via Package Manager.
  • File → Build Settings: ensure your AR scene is checked.
  • Click Build and save into a fresh Builds/iOS folder.
Build Note
Generation produces a Unity-iPhone Xcode project containing targets, frameworks, and Info.plist entries based on your Player Settings.
Example: Build Folder Structure
Builds/iOS/
Unity-iPhone.xcodeproj Unity-iPhone/Info.plist Frameworks/ Libraries/
Key Takeaway

Generate the Xcode project into a clean Builds/iOS folder so you can open it in Xcode and complete signing and deployment.
