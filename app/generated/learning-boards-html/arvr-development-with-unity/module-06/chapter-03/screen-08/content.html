Signing & Provisioning
Steps and checks to prepare your app for deployment to devices.
  1. Open the generated .xcodeproj in Xcode and select the main target.
  2. Go to Signing & Capabilities and select your Team (Apple Developer account).
  3. Enable Automatic signing to let Xcode create provisioning profiles.
  4. If errors appear, verify Bundle Identifier matches an App ID in your developer portal.
  5. Ensure your device UDID is included in the provisioning profile for testing builds.
Example: Common error
"Signing for 'Unity-iPhone' requires a development team. Select a development team in the Signing & Capabilities editor." — typically indicates no Team is selected or the account is not added to Xcode.
Troubleshooting
Add your Apple ID in Xcode Preferences → Accounts, refresh profiles, match bundle ID, or create App ID in developer portal.
Key Takeaway

Automatic signing will solve most cases; address bundle ID mismatches and expired profiles when Xcode reports signing errors.
