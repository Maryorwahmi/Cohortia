Comparison
Unity vs Xcode
Unity
Author scenes, set Player Settings, enable ARKit plug-in, generate Xcode project.
Xcode
Compile for device, sign with certificates, manage provisioning, deploy and debug on hardware.
Quick diagnostic: If the build fails before generating Xcode, fix Unity settings. If signing or device install fails, inspect Xcode’s Signing & Capabilities.
Analogy
Unity prepares the package and paperwork; Xcode is the delivery truck that must be licensed and permitted to drive onto the customer's property.
Common Misconception

Thinking a Unity Build is sufficient to run on device without opening Xcode and resolving signing and provisioning.
