Process Flow

Install XR Plugin Management and AR Foundation

Follow these steps in Unity to prepare your project for AR development.

Step 1: Create project
New 3D project; name it to reflect AR intent.
Step 2: Enable XR Plugin Management
Edit → Project Settings → XR Plugin Management → Initialize XR on Startup for Android and iOS tabs.
Step 3: Package Manager installs
Window → Package Manager → install AR Foundation, then ARCore XR Plugin and ARKit XR Plugin.
Step 4: Enable providers
Return to XR Plugin Management to enable ARCore and ARKit for their platforms.
Example
Why order matters

If you install AR Foundation but forget to enable Initialize XR on Startup, AR subsystems may not initialize when the app launches, causing features to fail even though packages are present.

Common mistake

Installing packages without enabling the matching provider in XR Plugin Management can leave your project incomplete for a target platform.

Key Takeaway

Follow install order and enable providers so Unity initializes the correct native AR subsystem on each device.
