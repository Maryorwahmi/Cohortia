Platform Overview

ARCore, ARKit, and AR Foundation

How platform SDKs and Unity's abstraction work together to deliver cross-platform AR.

ARCore (Android)
Provides SLAM, plane detection, light estimation on supported Android devices.
ARKit (iOS)
Offers similar AR capabilities optimized for Apple's device sensors and OS.
AR Foundation + XR Plugins
Unifies APIs so you write shared Unity code while platform plugins handle native calls.
Practical example
Request plane detection once

You call AR Foundation APIs to enable plane detection and the XR Plugin Management triggers the correct ARCore or ARKit implementation at runtime. This reduces code duplication across platforms.

Common pitfall

Do not assume identical feature parity between platforms; test features like plane finding and light probes across devices.

Key Takeaway

AR Foundation abstracts work across ARCore and ARKit, but device testing remains essential to handle capability differences.
