Learning Objectives

Four focused objectives to guide hands-on setup and conceptual understanding for AR development with Unity.

Bloom: Learn → Understand → Apply → Master
01
Differentiate AR and VR
Explain the difference between immersive virtual worlds and augmented overlays, and why AR keeps environmental context.
VERIFIED COMPETENCY MILESTONE
02
Explain SLAM & Plane Detection
Describe how mapping and flat-surface detection enable stable object placement in dynamic scenes.
VERIFIED COMPETENCY MILESTONE
03
Identify ARCore & ARKit roles
Understand each platform's responsibilities and how Unity unifies them through AR Foundation.
VERIFIED COMPETENCY MILESTONE
04
Configure Unity for AR
Install XR Plugin Management, AR Foundation, ARCore/ARKit plugins, and set Player Settings for device testing.
VERIFIED COMPETENCY MILESTONE
