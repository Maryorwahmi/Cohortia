Skills You'll Practice

Hands-on setup steps and checks that prevent common AR failures on device.

Apply → Test → Iterate
Project creation & XR Startup
Create a new 3D project, then enable Initialize XR on Startup under XR Plugin Management to let AR subsystems start when the app runs.
VERIFIED COMPETENCY MILESTONE
Package Manager installs
Install AR Foundation, then add ARCore XR Plugin and ARKit XR Plugin via the Unity Package Manager to provide platform features.
VERIFIED COMPETENCY MILESTONE
Player Settings checks
For Android set minimum API level to 24, enable IL2CPP and ARM64. For iOS provide a camera usage description to avoid runtime crashes.
VERIFIED COMPETENCY MILESTONE
Scene components
Add AR Session and AR Session Origin, and ensure the AR Camera is managed by the AR Session Origin for correct tracking.
VERIFIED COMPETENCY MILESTONE
