Configure Player Settings

Small changes in Player Settings prevent crashes and enable AR features on mobile devices.

Android
Set Minimum API Level ≥ 24, Scripting Backend to IL2CPP, and enable ARM64.
iOS
Set an appropriate minimum iOS version and provide a Camera Usage Description string.
Why it matters
Incorrect settings can cause immediate crashes when AR tries to access device hardware or native libraries.
Example
Crash on camera start

If an Android build crashes when opening the camera, confirm the Minimum API Level is set to 24 or higher and IL2CPP/ARM64 are enabled. These are common causes of immediate runtime failures.

Common mistake

Ignoring platform-specific build settings and relying on default values often leads to crashes on device even when editor previews work.

Key Takeaway

Validate Player Settings early in your workflow to avoid wasted builds and failing device tests.
