Definition

Plane Detection, Feature Points, Light Estimation

The perception steps that let virtual objects sit naturally in a real scene.

Plane Detection
Groups feature points into flat surfaces for realistic object placement.
Feature Points
Distinct points used to track motion and support mapping.
Light Estimation
Infers ambient light so virtual objects receive appropriate lighting and shading.
Scenario
Placing a virtual lamp

The system detects a table plane, tracks feature points as you move, and uses light estimation to match the lamp's intensity to room lighting. If planes are unstable, the lamp may jitter or sink into the surface.

Common mistake

Assuming plane detection works equally well in low-texture scenes; lack of visual features can produce fragmented planes and unstable anchors.

Key Takeaway

All three systems work together: planes for placement, feature points for tracking, and light estimation for believable visuals.
