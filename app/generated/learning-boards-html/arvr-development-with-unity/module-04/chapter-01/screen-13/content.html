Set Up Your First AR Project

Follow this guided checklist to prepare a Unity project, enable AR providers, and test a simple anchored object on device.

Checklist highlights
Create project → Enable XR Plugin Management → Install AR Foundation & plugins → Configure Player Settings → Add AR Session & Origin → Test on device.
Verification
Place a cube anchored to a detected plane and move around to confirm stability and light matching.
Example steps
  1. Create MyFirstARProject in Unity Hub.
  2. Enable Initialize XR on Startup in XR Plugin Management.
  3. Install AR Foundation, ARCore XR Plugin, ARKit XR Plugin in Package Manager.
  4. Set Android API ≥ 24 and IL2CPP + ARM64; add Camera Usage Description for iOS.
  5. Add AR Session and AR Session Origin to a scene and test on device.
Key Takeaway

Work through the checklist and validate each step on a physical device; real-world testing is the final arbiter of success.
