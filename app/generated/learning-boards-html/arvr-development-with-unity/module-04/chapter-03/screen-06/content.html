Definition
Instantiate(prefab, position, rotation)
Decide if taps create a new object or move an existing one. Manage references and lists for later manipulation.
Single-object pattern avoids clutter and simplifies manipulation logic.
Multiple-object pattern requires lists and UI to select or delete objects.
Pivot and model bounds matter: adjust offsets if a model appears sunk or floating.
Concrete example
Place a chair prefab at hitPose; if the seat is below the plane, correct the prefab pivot or add a small upward offset before instantiating.
Example placement code
// Instantiate at the hit pose
GameObject newObj = Instantiate(objectToPlace, hitPose.position + Vector3.up * yOffset, hitPose.rotation);
// Optionally adjust rotation to face camera
newObj.transform.LookAt(cameraTransform.position);
Key takeaway: the Instantiate call is simple; the surrounding lifecycle management and model alignment determine whether placement feels polished.
