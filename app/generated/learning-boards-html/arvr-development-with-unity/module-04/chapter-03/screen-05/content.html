ARRaycastManager Workflow
Step-by-step: perform a raycast, check results, extract the Pose, then instantiate or move an object.
1. Check Input.touchCount and touch.phase to know when to raycast.
2. Call arRaycastManager.Raycast(touch.position, hits, TrackableType.PlaneWithinPolygon).
3. If hits found, use hits[0].pose.position and .rotation for placement.
4. Store references to spawned objects to move or remove them later.
Code snippet (concept)
// Example pattern
if (arRaycastManager.Raycast(touch.position, hits, TrackableType.PlaneWithinPolygon))
{
  Pose hitPose = hits[0].pose;
  // Use hitPose.position and hitPose.rotation for placement
}
Example card: Use a tiny debug marker at the Pose when learning; this quick feedback confirms plane alignment and helps debug rotation issues before you spawn a final model.
