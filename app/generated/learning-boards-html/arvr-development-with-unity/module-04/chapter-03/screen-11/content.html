Definition
Scale Perception
Help users judge size with visual context and reference objects.
Grid overlay on plane to show units and spacing.
Reference object of known size (e.g., a coin or ruler model).
Soft shadow under object to ground it visually.
Concrete checks
  • Toggle a reference model and compare against a held real object.
  • Test in wide and narrow FOV devices to ensure consistent perception.
  • Offer an optional label that reports approximate real-world dimensions.
Key Takeaway

Small visual cues greatly improve user confidence when judging virtual object size.
