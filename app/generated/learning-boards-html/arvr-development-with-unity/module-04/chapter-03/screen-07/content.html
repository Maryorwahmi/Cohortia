Process Flow
Object Management
Spawn, store, select, move, and remove with clear APIs and simple data structures.
SpawnAtPose: Instantiate and add to List<GameObject>.
MoveToPose: Update transform.position and rotation or use smooth interpolation for UX.
Remove: Destroy and remove from list to avoid leaks.
Select: Raycast against object colliders to pick which object a gesture should affect.
Example: keep a selectedObject variable. When a tap hits an object collider set selectedObject; then gestures modify that object rather than creating a new one.
Selection vs Placement
Placement raycasts target TrackableType.PlaneWithinPolygon. Selection raycasts test spawned object colliders. Keep these concerns separate to avoid placing when the user intended to select.
Concrete example
Tap once to place. Tap an object to select it. Then drag to move the selected object using plane raycasts during movement.
