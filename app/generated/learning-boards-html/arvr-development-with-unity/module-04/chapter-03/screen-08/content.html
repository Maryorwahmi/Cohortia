One-finger Drag
Use TouchPhase.Moved + raycast to update the object's world position along the plane.
Instantiate only on first touch if no placedObject exists.
On moved, raycast and set placedObject.transform.position = hitPose.position.
Optional: smooth movement with Lerp to improve UX.
Common mistake: performing placement Instantiate inside moved logic, which spawns many objects. Only move the existing reference on moved phases.
Code (conceptual)
// On TouchPhase.Moved
if (arRaycastManager.Raycast(touch.position, hits, TrackableType.PlaneWithinPolygon))
{
  Pose hitPose = hits[0].pose;
  placedObject.transform.position = Vector3.Lerp(placedObject.transform.position, hitPose.position, 0.6f);
}
UX tip: tune the lerp factor for responsiveness. Too low feels laggy; too high can feel jittery on noisy tracking.
