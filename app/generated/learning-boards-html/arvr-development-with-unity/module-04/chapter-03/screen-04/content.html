Core Concept
Raycasting
Definition: project a ray from a screen point to detect intersections with AR trackables and receive a Pose for placement.
Why it matters
  • Provides exact world coordinates so objects rest naturally on surfaces.
  • Delivers rotation information so prefabs align with plane normals.
  • Forms the foundation for spawning and manipulation logic.
Common misconception
Raycasts are a placement snapshot, not a permanence guarantee; anchors or other stability tools are needed to maintain placement over time.
Key Takeaway

Use ARRaycastManager to get Pose data—position and rotation—then instantiate or move objects at that Pose.

Raycast example (conceptual)
// Conceptual usage in AR Foundation
if (arRaycastManager.Raycast(touch.position, hits, TrackableType.PlaneWithinPolygon))
{
  Pose hitPose = hits[0].pose;
  // hitPose.position -> world position
  // hitPose.rotation -> surface-aligned rotation
}
Example: tap a table and receive a Pose with a rotation aligned to the table normal.
Debug tip: log position and rotation to inspect misalignments during testing.
Analogy: think of the ray as a laser pointer from the camera through the touch point; the Pose is where that laser first hits a real surface and how it sits there.
