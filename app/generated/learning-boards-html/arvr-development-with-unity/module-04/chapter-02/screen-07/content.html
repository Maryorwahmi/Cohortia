ARPlacementManager.cs (core excerpt)

using UnityEngine;
using UnityEngine.XR.ARFoundation;
using UnityEngine.XR.ARSubsystems;
using System.Collections.Generic;

public class ARPlacementManager : MonoBehaviour
{
  [SerializeField]
  private GameObject objectToPlace;

  private ARRaycastManager arRaycastManager;
  private static List<ARRaycastHit> hits = new List<ARRaycastHit>();

  void Awake()
  {
    arRaycastManager = GetComponent<ARRaycastManager>();
  }

  void Update()
  {
    if (Input.touchCount > 0)
    {
      Touch touch = Input.GetTouch(0);

      if (touch.phase == TouchPhase.Began)
      {
        if (arRaycastManager.Raycast(touch.position, hits, TrackableType.PlaneWithinPolygon))
        {
          Pose hitPose = hits[0].pose;
          Instantiate(objectToPlace, hitPose.position, hitPose.rotation);
        }
      }
    }
  }
}
This small script demonstrates essential placement: get the ARRaycastManager, raycast on touch, and instantiate the object at the returned pose.
Step-by-step explanation
  • Awake: cache ARRaycastManager so raycasts are available.
  • Input: check touch count and phase to act only on initial press.
  • Raycast: use PlaneWithinPolygon to get valid hits inside plane boundaries.
  • Instantiate: use hitPose.position and .rotation to spawn the object aligned with the plane.
Misconception
Assuming TrackableType.PlaneWithinPolygon will return hits outside the polygon; it will not. Use other trackable types for different behaviours.
Key Takeaway

Raycasts convert user input into precise world poses. Use the returned pose to instantiate objects so they appear anchored to detected planes.
