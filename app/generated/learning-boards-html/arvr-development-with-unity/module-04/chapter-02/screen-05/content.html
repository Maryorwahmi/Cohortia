Definition

AR Plane Manager

A manager that receives platform plane detections and instantiates Unity representations using your prefab.

Detect types
Configure horizontal, vertical, or both to suit your scene and reduce false positives.
Prefab requirement
Prefab should include a mesh and an AR Plane component so the manager can attach data and update mesh boundaries.
Dynamic updates
As the system refines planes, the AR Plane Manager updates pose and mesh geometry automatically.
Visualization example
Create a quad prefab, assign a translucent material (fade or transparent), attach an AR Plane component, and set this prefab in the Plane Prefab slot of AR Plane Manager.
Scenario
You're testing on a wooden table: enabling horizontal detection and a light blue translucent prefab makes the table's area obvious while still showing texture underneath for context. If you only need walls, disable horizontal detection to save processing and reduce clutter.
Mistake
Leaving the Plane Prefab empty makes planes invisible even though tracking may be working.
Takeaway
Always provide a visible prefab and test in varied lighting to validate detection behavior.
