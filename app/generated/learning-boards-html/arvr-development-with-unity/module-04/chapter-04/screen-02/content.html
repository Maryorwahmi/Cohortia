Learning Objectives

Practical outcomes and verification milestones.

Learn → Understand → Apply → Master
01
Recognize light estimation data
Identify ambient intensity, color temperature, and main light direction from AR Camera Manager.
VERIFIED COMPETENCY MILESTONE
02
Apply estimates to scene lighting
Map average intensity and color temperature to Directional Light and ambient settings so models match real lighting.
VERIFIED COMPETENCY MILESTONE
03
Create and manage AR Anchors
Use AR Anchor Manager to add anchors at poses and parent virtual content to them for stability.
VERIFIED COMPETENCY MILESTONE
04
Understand anchor limitations
Know when anchors can fail and why cross-session persistence requires extra work like saving anchor data.
VERIFIED COMPETENCY MILESTONE
Each objective pairs a code change with a visual test you can run on a physical device. Use the milestones to verify your project behaves as expected.
