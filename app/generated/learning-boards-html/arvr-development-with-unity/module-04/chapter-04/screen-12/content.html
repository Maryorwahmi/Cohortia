Common mistakes
Flicker
Interpolate light values instead of applying raw numbers each frame.
Null references
Always check for null when using AddAnchor and FindObjectOfType; expose references via inspector where possible.
Bad anchor placement
Create anchors only when tracking confidence and hit results are reliable to avoid storing noisy poses.
Clean up anchors
Remove anchors when objects are deleted or moved to prevent stray anchors and keep the scene tidy.
Test broadly
Run tests in different rooms and lighting to tune scaling factors and smoothing durations for robust behavior.
Key Takeaway

Guard inputs, smooth outputs, and manage anchor lifecycles to produce reliable AR behaviour.
