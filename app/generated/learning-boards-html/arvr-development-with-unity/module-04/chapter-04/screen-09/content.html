Module 5 › Chapter 4.4 › Anchored vs Direct
Direct Transform Placement
Set the GameObject.transform.position and rotation to the raycast hit pose. Quick and simple for short-lived content.
  • Pros: minimal lifecycle code, lower overhead.
  • Cons: object can drift as tracking evolves.
When to use
HUD elements, temporary markers, or quick previews.
Anchor-based Placement
Create an ARAnchor at the hit pose and parent the object to the anchor’s transform so the AR system maintains alignment.
  • Pros: improved stability and persistence during session.
  • Cons: requires anchor lifecycle management and null checks.
When to use
Any object that should remain at a specific real-world location while users move around it.
Misconception check

Anchors don't guarantee persistence across app restarts; they improve stability within the current tracking session.
