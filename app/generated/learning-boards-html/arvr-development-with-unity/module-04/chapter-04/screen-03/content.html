Module 5 › Chapter 4.4 › Practice Steps
Step 1 — Expose light data
Add AR Camera Manager and confirm frame events include average intensity and color temperature. Log values and watch lighting changes in the editor or device.
Step 2 — Apply estimates
Implement ARLightEstimator to set RenderSettings.ambientLight and adjust your main Directional Light's intensity. Test in bright and dim rooms.
Step 3 — Use anchors
Add AR Anchor Manager and update ARPlacementManager to create anchors at hit poses. Verify objects remain stable when you move around.
Verification
  • Lighting tint matches room tone.
  • Shadows respond to intensity changes.
  • Placed objects exhibit reduced drift.
