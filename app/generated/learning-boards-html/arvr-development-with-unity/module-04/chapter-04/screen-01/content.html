Light Estimation & AR Anchors

Make virtual objects match ambient light and stay fixed in a single session using AR Foundation components in Unity.

16:9 HD Classroom
In this lesson
Apply light estimates and create anchors in Unity to improve realism and stability.
Hands-on
Add AR Camera Manager, AR Anchor Manager, and two scripts to your AR Session Origin.
Coming up
Test on a device and observe lighting changes and improved placement stability.
Why this matters

Visuals that match environmental lighting and anchors that keep objects steady are essential for believable AR. Without them, objects look like stickers and can drift away from their intended real-world spot.

Visual Concept
Light Estimation
Ambient color, intensity, main light
Adjust Directional Light intensity and scene ambient settings based on device estimates for consistent shading.
AR Anchor
Stable real-world reference for objects
Create anchors with AR Anchor Manager and parent objects to them to reduce drift inside a session.
Explore Key Topics
Camera Light Data
Values like average intensity and color temperature inform scene lighting.
Directional Light Mapping
Map main light direction to a Directional Light to cast believable shadows.
Anchor Lifespan
Anchors are reliable within a session; cross-session persistence requires extra workflows.
