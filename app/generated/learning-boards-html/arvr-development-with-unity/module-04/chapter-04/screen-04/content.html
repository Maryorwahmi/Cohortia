Module 5 › Chapter 4.4 › What is Light Estimation?
Definition and value

Light estimation produces environmental lighting parameters from camera frames. These values let you adapt ambient and directional lighting so virtual objects match the scene’s tone.

Common outputs
  • averageIntensityInLumens — numeric overall brightness
  • averageColorTemperature or averageColor — color tint
  • mainLightDirection / mainLightIntensity — directional cues
  • spherical harmonics — for diffuse reflections
Why it matters
Matching light reduces the visual gap between real and virtual objects, increasing immersion and reducing the feeling of overlays.
Key Takeaway

Treat light estimation as guide values you apply to lighting components, not a full physical renderer replacement.

Concrete example
Imagine you place a virtual lamp in a dim cafe. If you set RenderSettings.ambientLight using the estimated color and lower the Directional Light intensity using averageIntensityInLumens, the lamp’s materials will pick up warm low light and softer shadows, blending into the cafe scene.
Misconception
Light estimation does not recreate detailed shadows or accurate reflections on glossy surfaces by itself; it supplies inputs to improve the overall impression.
Try this
On-device, toggle a Directional Light’s intensity using the reported lumens and watch shadow strength change as you move between bright and dim areas.
