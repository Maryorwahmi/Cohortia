Core Concept
Gaze Interaction
Selecting items by looking at them for a short time.
Definition
A forward camera ray detects hits and a dwell timer triggers activation after a duration.
Why use gaze
  • Works without controllers — ideal for passive or simple experiences.
  • Low memory and input complexity for basic menus or 360 viewers.
  • Easy to implement with a camera-attached script and Physics.Raycast.
Concrete Example
Attach a camera script that casts a ray every frame, check for a "GazeInteractable" tag, increment a timer, and invoke the target's activation when the timer meets dwell time. Provide a circular progress reticle so users see the countdown.
Key Takeaway

Gaze is simple and accessible, but test dwell times and add strong visual feedback to avoid accidental activations.

Common Mistake

No visual progress indicator — users won’t know a selection is about to trigger and will perceive the app as unresponsive.

Gaze Implementation Sketch
// CameraGaze.cs (concept)
using UnityEngine;

public class CameraGaze : MonoBehaviour {
  public float dwellTime = 1.0f;
  float timer = 0f;
  GameObject current = null;

  void Update(){
    Ray ray = new Ray(transform.position, transform.forward);
    if(Physics.Raycast(ray, out RaycastHit hit)){
      if(hit.collider.gameObject.CompareTag("GazeInteractable")){
        if(current != hit.collider.gameObject){ timer = 0f; current = hit.collider.gameObject; }
        timer += Time.deltaTime;
        if(timer >= dwellTime){ current.SendMessage("OnGazeActivate"); timer = 0f; }
      } else { timer = 0f; current = null; }
    } else { timer = 0f; current = null; }
  }
}
This example shows the core claim, a concrete pattern, and a simple event call to activate the target. In practice add reticle visuals and test dwell length with users.
