Gaze Script Walkthrough
Implement a camera-attached script that detects gaze and fires activation after a dwell.
// CameraGaze.cs (illustrative)
using UnityEngine;

public class CameraGaze : MonoBehaviour {
  public float dwellTime = 1f;
  float timer = 0f;
  GameObject current = null;
  
  void Update(){
    Ray ray = new Ray(transform.position, transform.forward);
    if(Physics.Raycast(ray, out RaycastHit hit)){
      GameObject target = hit.collider.gameObject;
      if(target.CompareTag("GazeInteractable")){
        if(current != target){ timer = 0f; current = target; }
        timer += Time.deltaTime;
        if(timer >= dwellTime){ current.SendMessage("OnGazeActivate"); timer = 0f; }
      } else { timer = 0f; current = null; }
    } else { timer = 0f; current = null; }
  }
}
Notes
  • Use tags or a dedicated component to identify gaze targets.
  • Reset timers when gaze leaves to avoid false activations.
  • Add a progress reticle so users see the dwell advancing.
Concrete Example
Attach this script to the main camera, tag a cube with "GazeInteractable", and implement OnGazeActivate on the cube to perform the action. Test dwell time and reticle visibility to ensure a comfortable pace.
Key Takeaway

A short, Update-based raycast plus a dwell timer is a reliable and readable pattern for gaze activation in simple scenes.
