Comparison
Gaze
Camera-forward selection with dwell.
Pros
  • No controllers required.
  • Low input complexity for passive experiences.
Cons
  • Less precise for object manipulation.
  • Requires careful dwell timing and feedback.
Example
360 viewers where looking at a hotspot opens an info panel after a one-second dwell.
Comparison
Raycasting (Controller)
Laser-like pointer from a hand using XR Ray Interactor.
Pros
  • Precise pointing and grabbing at a distance.
  • Supports teleportation targeting and object highlights.
Cons
  • Requires controller hardware and component setup.
  • Needs visible line or reticle for good feedback.
Example
Right-hand XR Ray Interactor with Line Renderer and reticle prefab, used to grab an interactable cube and to select a teleport target on the floor.
Practical guidance
If your experience requires both simple menus and object manipulation, combine the patterns: use gaze for HUD or tutorial menus and raycasting for in-world object interaction. Always give visual cues for both methods.
