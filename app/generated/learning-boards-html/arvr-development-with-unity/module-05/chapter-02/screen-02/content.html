Learning Objectives
Master practical interaction patterns and the toolkit components that deliver them.
01
Gaze and Raycasting
Identify and implement gaze-based selection and raycasting patterns.
You will attach camera or controller raycasts and create dwell timers or interactors so users can select from either method.
VERIFIED COMPETENCY MILESTONE
02
Teleportation Setup
Configure Teleportation Provider, Area, and Anchor to enable locomotion.
You’ll map components to the XR Origin and ground geometry, ensuring colliders and masks allow teleport targets to be detected.
VERIFIED COMPETENCY MILESTONE
03
Interaction Types
Differentiate direct versus indirect interaction methods.
Understanding which method fits your experience helps avoid confusing affordances and unexpected behaviour for users.
VERIFIED COMPETENCY MILESTONE
04
Troubleshooting & Scripting
Find and fix common raycasting and teleport problems and write small C# scripts to extend interactions.
You’ll learn to check colliders, layer masks, line renderers, and add a gaze timer script to trigger events reliably.
VERIFIED COMPETENCY MILESTONE
