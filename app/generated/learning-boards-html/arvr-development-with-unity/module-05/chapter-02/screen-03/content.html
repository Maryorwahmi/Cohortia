Applied Objectives
Concrete editor tasks, ready to run in Play with a headset.
01
XR Ray Interactor Setup
Add the component to LeftHand and RightHand controllers, assign a Line Renderer and reticle prefab.
This creates the visible pointer and target marker users rely on to aim and teleport.
VERIFIED COMPETENCY MILESTONE
02
Make Objects Interactable
Add XR Grab Interactable or XR Simple Interactable and ensure a Collider is present.
Without a collider, the ray cannot hit the object even if the interactable component exists.
VERIFIED COMPETENCY MILESTONE
03
Teleport Areas & Anchors
Add Teleportation Area to ground planes and Teleportation Anchor to fixed points.
Verify colliders and the Interaction Layer Mask so ray interactors detect the teleport destinations.
VERIFIED COMPETENCY MILESTONE
04
Test & Debug
Run with headset, look for highlights and teleport reticle; if missing, inspect layers and colliders.
This step closes the loop, confirming your scene responds to input as expected.
VERIFIED COMPETENCY MILESTONE
