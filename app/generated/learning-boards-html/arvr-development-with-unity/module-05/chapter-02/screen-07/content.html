Definition
Interactable Objects
Combine a collider and an XR interactable component so rays and physics detect and trigger behavior.
Collider requirement
XR Grab Interactable needs a Collider on the same GameObject or a child so Physics.Raycast or XR Ray Interactor can register hits.
Collider sizing matters
A collider that is too small or offset will cause misses even when the mesh looks hittable. Adjust bounds in the Inspector and test with Gizmos on.
Layer mask check
If colliders are present but no interaction occurs, ensure the object's layer is included in the XR Ray Interactor's Interaction Layer Mask.
Scenario
You add XR Grab Interactable to a vase and forget the collider; the ray shows a reticle but the vase never highlights. Adding a Box Collider and re-testing immediately fixes the missing grabs.
Quick inspector checklist
  • Does the object have a Collider? (Box/Sphere/Mesh)
  • Is the Collider enabled and sized correctly?
  • Is the XR Grab Interactable or Simple Interactable present?
  • Is the object on a layer included by the interactor mask?
Common Mistake
Attaching the interactable only to a child object while the collider is on the parent without enabling the child — ensure colliders and interactable references align on the active GameObject tree.
