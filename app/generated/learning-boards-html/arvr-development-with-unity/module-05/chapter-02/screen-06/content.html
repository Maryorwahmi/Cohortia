Process Flow
XR Ray Interactor Setup
Attach to controllers, add visual components, and align layers.
Step 1 — Attach
Put XR Ray Interactor on LeftHand and RightHand under XR Origin.
Step 2 — Make the ray visible
Add Line Renderer and assign a bright unlit material so the ray is visible in VR.
Step 3 — Reticle prefab
Set a small sphere or quad as the reticle so users see where they are pointing.
Step 4 — Interaction Layer Mask
Include layers used by interactables and teleport areas so the interactor can hit them.
Visual Checklist
  • Line Renderer present and assigned material.
  • Reticle prefab set and visible.
  • Controllers have XR Ray Interactor component attached.
  • Interaction Layer Mask includes interactable layers.
Example scenario
You add XR Ray Interactor to the right-hand controller, assign a green line material on the Line Renderer, and set a small sphere reticle prefab. You then point at an interactable cube and see the reticle and highlight before grabbing.
Pro tip
If the ray is visible but cannot hit objects, toggle the Interaction Layer Mask while watching the Inspector to find the correct layer combination.
