Hands-on Activity
Configure Ray Interactors & Teleportation
Follow the checklist and verify behavior in Play.
Step-by-step
  1. Add XR Ray Interactor to LeftHand and RightHand controllers.
  2. Add a Line Renderer and assign a bright unlit material so the ray is visible.
  3. Create a small sphere prefab and assign it as the reticle in the interactor.
  4. Add Teleportation Provider to the XR Origin if not present.
  5. Add Teleportation Area to the Ground plane and ensure an enabled Collider is present.
  6. Add Teleportation Anchors for fixed locations when desired.
  7. Set Interaction Layer Mask on the ray interactors to include the ground and interactable layers.
Example Test
Enter Play with a headset: you should see a ray from each hand, a reticle when pointing at surfaces, the cube highlight when pointing at an interactable, press the grab input to pick up the cube, and press the teleport input to move to a valid teleport reticle position.
If it fails
Check colliders first, then Interaction Layer Mask, then confirm the Teleportation Provider exists on the XR Origin.
