Module 6 › Chapter 5.5 › Key Concepts
APK (Android)
Package format for standalone headsets like Meta Quest; produced by building Android target.
IL2CPP + ARM64
IL2CPP creates native code; ARM64 targets the Quest CPU architecture for performance and compatibility.
adb & Developer Mode
adb installs APKs and communicates with the headset; Developer Mode and USB debugging must be enabled to allow it.
Summary Takeaway

Approach deployment with a checklist: platform selection, Player Settings, XR provider, external tools, build, adb install, and on-device logging for validation.
