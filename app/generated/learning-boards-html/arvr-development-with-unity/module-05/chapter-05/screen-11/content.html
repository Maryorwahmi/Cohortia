Common Errors & Fixes
Device not found
Check cable, accept USB prompt, install drivers, restart adb server.
Build fails: missing NDK
Configure External Tools or let Unity download required components.
App crashes on launch
Verify IL2CPP + ARM64 and check Logcat output for native exceptions.
Checklist
  • Cable and USB prompt
  • Drivers and adb server
  • Player Settings, IL2CPP, ARM64
  • External Tools configured
Key takeaway
A short, repeatable checklist makes troubleshooting fast and keeps iteration cycles short.
