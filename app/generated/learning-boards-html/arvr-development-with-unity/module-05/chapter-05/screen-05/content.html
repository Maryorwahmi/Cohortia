Module 6 › Chapter 5.5 › Switching to Android & Build Settings
Step-by-step
  1. Open File > Build Settings.
  2. Select Android and click Switch Platform.
  3. Open Edit > Project Settings > Player > Android tab.
  4. Set Company, Product, and unique Package Name.
  5. Set Minimum API Level ≥ 25 for Quest compatibility.
Example Package Name
Use reverse domain notation such as com.yourname.myfirstvr so Android uniquely identifies your app. This matters for updates and installation.
Why Minimum API matters
Setting it too low can allow incompatible system calls; too high will exclude older devices. Choose the lowest level that supports required XR features.
Misconception
Package name is not just cosmetic; it identifies the app to the OS and affects installation and updates.
