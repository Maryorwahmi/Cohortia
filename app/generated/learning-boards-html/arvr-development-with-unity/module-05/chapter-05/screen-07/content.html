Module 6 › Chapter 5.5 › XR Plug-in Management & External Tools
Enable XR Provider
Open Project Settings > XR Plug-in Management. Under Android, check Oculus. For PC, use OpenXR or Oculus under the Standalone tab.
Why this matters
XR providers register platform-specific runtime entry points and render loops required by the headset.
Configure SDK / NDK
Open Edit > Preferences > External Tools. Ensure paths to Android SDK, NDK, and Java are set, or allow Unity to install them.
Build failure symptom
Errors about missing NDK or gradle indicate External Tools are not configured correctly.
Quick checklist
XR provider enabled
SDK/NDK present
Rebuild after changes
