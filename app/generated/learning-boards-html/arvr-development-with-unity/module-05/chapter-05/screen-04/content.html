Module 6 › Chapter 5.5 › APK vs EXE — choosing the right artifact
Comparison
APK — Android (Quest)
  • Packaged for Android runtime, needs IL2CPP and ARM64.
  • Installed via sideloading tools such as adb.
  • Requires XR provider for Android (Oculus).
Windows EXE — PC VR
  • Compiled for x86_64 desktop hardware.
  • Requires PC runtime like SteamVR or Oculus PC app.
  • Simpler build but needs a capable PC to run.
Concrete example
You export two builds: an APK for Quest and a Windows folder for PC. The Quest APK must include ARM64 native libraries; the PC build expects the PC runtime and drivers. Attempting to run the APK on a PC or the EXE on a Quest is not supported and will fail.
Key Takeaway
Select the build platform to match the headset and verify architecture and plug-ins before building.
Common mistake
Not switching Build Settings to the correct platform before building, which causes runtime incompatibilities.
