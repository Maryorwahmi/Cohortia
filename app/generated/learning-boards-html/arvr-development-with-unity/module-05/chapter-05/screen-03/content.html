Practical Lab Objectives
A stepwise checklist to complete during the hands-on exercise
Switch to Android
Use File > Build Settings and click Switch Platform. Wait for asset reimport if prompted.
Set Player Settings
Company, Product, unique Package Name, Minimum API ≥ 25, IL2CPP, ARM64.
Build the APK
Choose a clear folder and filename so you can locate the APK for installation.
Sideload with adb
Enable Developer Mode on Quest, connect USB, run adb devices and adb install.
