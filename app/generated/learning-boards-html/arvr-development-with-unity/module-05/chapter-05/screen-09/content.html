Module 6 › Chapter 5.5 › Using adb to sideload
Terminal commands (example)
adb devices
# returns list of connected devices
adb install C:\Users\You\Desktop\MyVRBuild\MyFirstVR.apk
# returns Performing Streamed Install → Success
Simulated flow (no headset)
Run echo commands to mimic adb output so you can practice command order and interpretation.
Connection checklist
  • Enable Developer Mode via the Meta app.
  • Use a data-capable USB cable and ensure the headset shows the USB debugging prompt.
  • Accept debugging and verify with adb devices.
Note
If the device is listed as offline or not found, try restarting the adb server or checking drivers on your PC.
