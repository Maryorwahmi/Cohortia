Module 6 › Chapter 5.5 › Building the APK
Build steps
  1. File > Build Settings > Android selected.
  2. Click Build and choose folder and filename, e.g., MyVRBuild/MyFirstVR.apk.
  3. Wait for Unity to compile and package the APK.
Tip
Use incremental filenames for quick rollback, and keep a dedicated build folder for each project.
Build output (example)
Building Player: MyFirstVR.apk
Compiling scripts with IL2CPP...
Running Android Gradle build...
Signing APK...
Build succeeded: MyVRBuild/MyFirstVR.apk
If build fails
Check External Tools for SDK/NDK paths, verify IL2CPP and ARM64, then rebuild.
