Module 5 › Chapter 5.3 › XR Grab Interactable
Required components
  • Collider — enables proximity and contact detection.
  • Rigidbody — enables physics simulation on release and throwing.
  • XR Grab Interactable — handles attach/detach and event hooks.
Attachment modes
Kinematic: object follows exactly. Velocity Tracking: records motion for realistic throws.
Example: Preparing an Interactable Cube
1. Create Cube
2. Add Box Collider (auto)
3. Add Rigidbody
4. Add XR Grab Interactable
5. Test: grab, move, release, throw

Troubleshoot: if cube doesn't respond, check Interaction Layer Masks and missing Rigidbody.
Common mistake
Not adding a Rigidbody prevents the object from being thrown with realistic physics — add one and verify mass and drag.
