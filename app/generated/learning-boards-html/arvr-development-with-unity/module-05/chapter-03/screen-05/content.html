Module 5 › Chapter 5.3 › Input Action Setup
Steps to create bindings
  1. Create an Input Action Asset in Project window (Create > Input Actions).
  2. Add Action Maps like LeftHand and RightHand.
  3. Add Actions such as Grab and Select inside each map.
  4. Add Bindings that point to the physical input paths for your controllers.
  5. Assign the asset to the Input Action Manager on XR Origin and link actions in XR Controller components.
Common mistake
Leaving the XR Controller's Select or Grab Action unassigned even after setting up the asset; always verify the link in the Inspector.
Example binding
// In the Input Action Asset UI
Action Map: XRI LeftHand
  Action: Grab
    Binding: <XRController>{LeftHand}/gripButton

// Assign this asset to Input Action Manager, then set XR Controller -> Grab Action to this action.
Key Takeaway

Treat actions as intent. Bindings connect that intent to hardware so your interaction code stays device-agnostic.
