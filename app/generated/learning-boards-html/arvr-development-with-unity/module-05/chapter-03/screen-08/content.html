Module 5 › Chapter 5.3 › Testing Grabs
Checklist for playtesting
  • Verify object has Collider and Rigidbody.
  • Confirm XR Grab Interactable is present and configured for attachment type.
  • Test grabbing, moving, and releasing at different speeds.
  • Tune Rigidbody mass and drag for believable throws.
Troubleshoot
If the object doesn't respond, check the Interaction Layer Mask on the interactor and the object's layer.
Scenario card
Throw test

Grab the cube, accelerate your hand, then release. Observe flight and collisions. If it drops too quickly, reduce drag; if it clips, adjust collider or interpolation settings.

Key Takeaway

Realistic behavior requires both correct attachment mode and tuned Rigidbody parameters.
