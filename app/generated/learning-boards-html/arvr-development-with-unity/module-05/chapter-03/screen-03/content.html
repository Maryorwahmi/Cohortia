Milestones to verify

Each card below maps to a simple test you can run in Play mode. Passing a milestone shows your interaction pipeline is wired end-to-end.

Bind a Grab Action
Create an Input Action Asset, add a Grab action and bind it to controller grip or trigger, then assign the asset to the Input Action Manager on XR Origin.
Make a Grabbable Cube
Add XR Grab Interactable, Collider, and Rigidbody. Grab and throw in Play mode to verify physics handoff.
Enable Hand Tracking
Enable the Oculus XR Plug-in under Android, set Tracking Origin to Floor, and enable Hand Tracking Support.
Detect a Pinch
Write a script that measures the distance between thumb tip and index tip, and triggers on a threshold for a pinch gesture.
Why verify

Small tests surface common issues: missing Rigidbody, incorrect Input Action bindings, or hand prefabs lacking XR Interactor components. Verifying early saves integration time later.

Quick tip
When visual hands can’t interact, check that the hand prefab has XR Direct Interactor components on relevant child objects.
