Module 5 › Chapter 5.3 › Enable Hand Tracking
Step-by-step
  1. Open Project Settings → XR Plug-in Management → Android and enable Oculus.
  2. Open Meta XR SDK (or Oculus XR Plugin) settings in Project Settings.
  3. Set Tracking Origin Mode to Floor.
  4. Under Features set Hand Tracking Support to Supported or Required.
  5. Build to device or test with headset to confirm joint data.
Notes & safety

Hand tracking removes physical controllers. Warn users to clear their play area and design clear visual feedback to show when interactions will occur.

Integration note
Enabling engine support is only the backend step; visualizing hands requires SDK hand prefabs or custom integration with the XR Interaction Toolkit.
