Checklist: Hands appear but can’t grab
  • Does the hand prefab include XR Direct Interactor or XR Ray Interactor on child objects?
  • Is the grabbable object on a layer included by the interactor's Interaction Layer Mask?
  • Does the object have a Rigidbody?
Inspector and runtime checks

Confirm the Input Action Asset is assigned to the Input Action Manager and that each XR Controller’s Grab or Select Action references an action defined in the asset. Check platform plugin enablement for hand joint delivery.

Quick fix
If hands are visible but inert, add interactors to child objects representing fingertip or palm and retest.
