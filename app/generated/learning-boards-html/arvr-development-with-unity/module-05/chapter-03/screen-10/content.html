Module 5 › Chapter 5.3 › Hand Visualization
Typical prefab contents
  • Hand mesh or simple model for visualization.
  • Transforms for joints: wrist, palm, finger tips and knuckles.
  • Scripts or components providing joint data updates.
Integration step
Replace controller models or add the prefab under XR Origin, then attach XR Interactor components to child objects used for direct grabbing or pinching.
Example scenario
Pinch interactor

Add an XR Direct Interactor to a fingertip child transform. Configure its Interaction Layer Mask so it can select XR Grab Interactables when the fingertip collides with them.

Common pitfall
Visual hands without interactors cannot grab. Add interactor components to the appropriate child objects to enable interaction.
