Hands-on Activity: Bake Occlusion and Create LODs
Follow these steps in Unity and verify improvements with the Profiler.
Step 1 — Prepare the scene
Create a room with furniture, mark static geometry as Static in the Inspector so it can be occlusion-baked.
Step 2 — Bake Occlusion
Window → Rendering → Occlusion Culling → Bake. Enter Play Mode and verify occluded objects stop rendering.
Step 3 — Create LOD Group
Duplicate model into 3 variants, add LOD Group, assign LOD0..LOD2, and tune transition heights while moving the camera.
Validation checklist
  • Before changes, capture Profiler baseline.
  • After occlusion and LOD, capture Profiler again and compare CPU/GPU frame times and draw calls.
  • Test on target headset to confirm real-world improvements.
Common mistake
Making many changes at once prevents you from isolating which optimization produced the gain. Change one thing, then re-profile.
Key Takeaway

Measure first, apply one optimization at a time, and validate improvements on the target device.
