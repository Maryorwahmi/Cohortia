Definition
Texture Optimization and Compression
Right-size textures and pick compressed formats matching your target hardware.
Guideline
Use 512x512 or 1024x1024 for most objects. Reserve 2048x2048 for close-up surfaces only.
Compression
Enable platform compression: ASTC for mobile/Quest, DXT for desktop. Compressed formats cut memory and bandwidth costs.
Concrete example
Downgrade a distant wall texture from 2048 to 1024 and observe memory and frame-time improvements in the Profiler without noticeable visual loss.
Practical checks
  • Inspect GPU memory use in the Profiler after changing texture settings.
  • Check streaming and load times to ensure no spikes occur.
  • Test on the target headset to confirm perceived quality.
Common mistake
Leaving all textures at maximum size and uncompressed, which quickly exhausts GPU memory on constrained devices.
Key Takeaway

Reduce texture sizes where possible and apply platform compression to lower memory and bandwidth demands.
