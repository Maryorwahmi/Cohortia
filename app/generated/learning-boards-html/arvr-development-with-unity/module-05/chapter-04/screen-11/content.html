Tool Walkthrough
Using the Unity Profiler and Frame Debugger
Measure CPU/GPU time, draw calls, memory, and physics to target optimizations.
Open the Profiler
Window → Analysis → Profiler. Run on device when possible to capture real platform behavior.
Inspect timelines
Check CPU, GPU, Rendering, Memory, and Physics panels to find the largest contributors to frame time.
Frame Debugger
Step through draw calls to see batching, overdraw, and render order issues causing extra cost.
Quick profiling checklist
  • Reproduce stutter and capture Profiler timeline.
  • Locate spike and expand section to find function or system causing it.
  • Use Frame Debugger to inspect problematic frames' draw calls.
Example Profiler note
Rendering: draw calls 420 CPU Main: 8.6 ms GPU: 11.2 ms Physics: 2.1 ms Texture streaming spike: 16 ms
This synthetic reading shows GPU dominating; inspect shaders and triangles. A texture streaming spike points to large textures or loading in-play—compress or preload them.
Pro tip

Profile iteratively: change one thing, re-profile, and measure the real impact before moving on.
