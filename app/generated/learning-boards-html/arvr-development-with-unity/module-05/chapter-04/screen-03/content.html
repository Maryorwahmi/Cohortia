Practical Skills to Verify
Skills you will perform in Unity and validate with tools.
01
Bake Occlusion Culling
Mark static objects, open Window → Rendering → Occlusion Culling, and bake to stop rendering hidden geometry.
Verified Competency Milestone
02
Create LOD Groups
Assemble LOD0..LOD2 with simpler meshes and tune transition heights for visible savings.
Verified Competency Milestone
03
Manage Materials & Batching
Reuse materials for static batching and be aware of dynamic batching vertex limits.
Verified Competency Milestone
04
Profile and Validate
Use the Profiler and Frame Debugger to measure CPU/GPU time and confirm improvements on target hardware.
Verified Competency Milestone
Mnemonic & Tips
Use the chain: Mark static → Bake occlusion → Add LODs → Reuse materials → Profile. Measure after each step to see where the most time is spent.
Quick tip
Test on your headset. Editor play is useful, but platform-specific GPU/driver behavior changes real results.
Common mistake
Assuming one big texture is fine. Large uncompressed textures consume GPU memory and can stall rendering.
