Process Flow
Level of Detail (LOD) Groups
Create mesh variants and control when the engine swaps between them to reduce rendering cost.
Step 1 — Create variants
Duplicate the model and produce simplified meshes for medium and low detail, or use billboards for the farthest LOD.
Step 2 — Add LOD Group
Create an empty parent, add the LOD Group component, and assign each mesh to its LOD slot.
Step 3 — Tune transitions
Adjust Screen Relative Transition Height to balance performance and visible pop between LODs. Consider cross-fading where available.
Concrete example
For a tree model: LOD0 full leaves, LOD1 simplified branch mesh with fewer leaves, LOD2 a flat billboard textured to look like a tree at distance. Place many trees and observe vertex count reductions as you move away.
Validation
Use the Profiler to compare vertex and triangle counts before and after LODs are active.
Common mistake
Using too-high transition thresholds can cause popping close to the user. Tune for visibility and smoothness.
Key Takeaway

LOD reduces vertex and pixel work for distant objects. Tune transitions to balance performance and visual continuity.
