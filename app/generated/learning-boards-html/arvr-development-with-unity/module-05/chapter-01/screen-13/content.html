Module 5 › Chapter 5.1 › Troubleshooting
Quick checklist
  • Confirm XR provider enabled and packages installed.
  • Check Input Action Manager has an action asset assigned.
  • Verify XR Controller action fields reference asset actions.
  • Ensure colliders and Rigidbody exist on interactables.
  • Remove default Main Camera to avoid conflicts.
Example fault

If grab does nothing, open the XRI Default Input Actions and confirm 'Grab' is present and enabled. Then confirm the XR Controller Grab Action references that action. Most fixes are resolved here.

Final Tip

Work through the wiring checklist before assuming hardware or driver problems; many issues are configuration-based.
