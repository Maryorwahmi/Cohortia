Module 5 › Chapter 5.1 › Install Toolkit & Input
Steps in Package Manager
  1. Select Window > Package Manager and set view to Unity Registry.
  2. Search for 'XR Interaction Toolkit' and install the verified version.
  3. Import starter assets when prompted to get prefabs and the default action maps.
  4. Install 'Input System' if not present and accept the switch when prompted.
Example

After restart you should find XRI Default Input Actions among the imported assets and XR prefabs in the toolkit folder.

Common pitfalls
  • Skipping starter asset import loses the default action maps.
  • Declining the Input System switch prevents the toolkit from receiving controller actions.
Key Takeaway

Install toolkit, import starter assets, and switch to the Input System so actions are available to XR controllers.
