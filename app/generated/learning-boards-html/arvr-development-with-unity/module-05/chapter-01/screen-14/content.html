Module 5 › Chapter 5.1 › Meta Quest Setup & Test
Activity steps
  1. Create Unity 3D Core project.
  2. Project Settings → XR Plug-in Management → Android tab → enable Oculus and accept installs.
  3. Package Manager → install XR Interaction Toolkit and Input System; import starter assets and accept restart.
  4. Add XR Origin (VR/Desktop) and delete Main Camera.
  5. Add Ground plane and Cube with Rigidbody and XR Grab Interactable.
  6. Connect Meta Quest via Link and press Play to test grabbing.
Expected result

In Play mode with Link active you should see head tracking and be able to use the grip to pick up the cube if action assets are assigned correctly.

Key Takeaway

Follow the sequence exactly and validate wiring steps if controllers fail to respond.
