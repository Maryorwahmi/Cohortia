Module 5 › Chapter 5.1 › Physics & Interactables
Essentials
  • Collider must be present and enabled.
  • Rigidbody enables physics motion; uncheck Use Gravity for initial tests.
  • XR Grab Interactable attaches object to controller when Grab action triggers.
Example setup

Cube at (0,1,2) with Collider, Rigidbody, and XR Grab Interactable lets you test grabbing without objects falling away.

Common mistake

Adding only XR Grab Interactable without a Rigidbody or collider makes the object non-interactive because physics and contact detection are missing.

Key Takeaway

Always attach a collider and Rigidbody before making an object grabbable with XR components.
