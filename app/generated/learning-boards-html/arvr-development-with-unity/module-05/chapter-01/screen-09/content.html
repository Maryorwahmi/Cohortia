Module 5 › Chapter 5.1 › Input Action Manager
What to verify
  • Input Action Asset assigned to Input Action Manager.
  • XR Controller select/activate/grab fields point to actions in that asset.
  • Actions in the asset are enabled and have suitable bindings for your controllers.
Example check

Open XRI Default Input Actions and confirm 'Grab' is enabled. Then inspect XR Controller's Grab Action assignment.

Troubleshooting steps
  1. Open the XR Origin and find Input Action Manager.
  2. Ensure an Input Action Asset is present in Action Assets.
  3. Open each XR Controller and confirm action references.
  4. Open the action asset and enable missing actions or adjust bindings.
Key Takeaway

Controller input requires explicit action bindings; check assignments before assuming hardware failure.
