Module 5 › Chapter 5.1 › Hands-on: Test Scene
Step-by-step checklist
  1. Create new Unity 3D Core project.
  2. Enable provider in XR Plug-in Management and accept installs.
  3. Install XR Interaction Toolkit and Input System, import starter assets.
  4. Add XR Origin and delete default Main Camera.
  5. Add Plane named Ground at (0,0,0) scaled (10,1,10).
  6. Add Cube at (0,1,2) with Rigidbody (no gravity) and XR Grab Interactable.
Example scene values
Ground position 0,0,0; Ground scale 10,1,10; Cube at 0,1,2; Rigidbody with Use Gravity unchecked; XR Grab Interactable attached.
Key Takeaway

Follow these steps to create a minimal, reliable test scene that reveals tracking and input issues early.
