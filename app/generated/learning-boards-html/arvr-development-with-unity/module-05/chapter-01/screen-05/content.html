Module 5 › Chapter 5.1 › XR Plug-in Management
What it does

Offers a single place to enable VR/AR providers per build platform and to install corresponding packages Unity needs to communicate with headsets and runtimes.

Step-by-step
  1. Open Edit > Project Settings.
  2. Select XR Plug-in Management.
  3. Choose the target platform tab (Android or PC).
  4. Toggle Oculus and/or OpenXR and accept install prompts.
Common mistake

Enabling a provider under the wrong platform tab or skipping the install prompts prevents the runtime from being added to the project.

Visual checklist
OpenXR

An open standard for cross-platform compatibility; enable for broader device support.

Oculus

Enable when targeting Meta Quest devices under Android.

Key Takeaway

Match the plug-in to your target platform and install the package prompts Unity provides to enable headset communication.
