Module 5 › Chapter 5.1 › OpenXR vs Platform SDKs
OpenXR

An open standard API aimed at cross-platform compatibility. Use it to reduce platform lock-in when supporting many headsets.

When to choose

When targeting more than one device or wanting a future-proof runtime path.

Vendor SDK (Oculus)

A provider tailored to a specific platform, such as Meta Quest. Useful when you need vendor features or tight device integration.

When to choose

When your project targets a single vendor and you need platform-specific features.

Practical tip

Decide early which provider to enable based on target hardware, then accept Unity's install prompts so the runtime packages are present for testing.
