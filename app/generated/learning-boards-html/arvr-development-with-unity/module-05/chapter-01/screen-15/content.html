Module 5 › Chapter 5.1 › Key Concepts
XR Plug-in Management

Unity's system for enabling and installing VR/AR provider runtimes per platform.

XR Interaction Toolkit

A package with components and starter assets for common VR interactions such as grabbing.

XR Origin

A prefab representing the player's head and hands, containing the camera, controllers, and input manager.

Takeaway

Install the right provider, add the toolkit and Input System, assign action assets to XR Origin, and test with a ground and a grabbable cube.
