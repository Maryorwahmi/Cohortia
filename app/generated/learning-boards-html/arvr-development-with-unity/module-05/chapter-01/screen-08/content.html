Action wiring

Assign an Input Action Asset to Input Action Manager so controller components receive Select, Grab, and Activate actions.

Practical steps
  1. Right-click Hierarchy and choose XR > XR Origin (VR/Desktop).
  2. Delete the default Main Camera from the scene.
  3. Select XR Origin and assign the XRI Default Input Actions to the Input Action Manager.
Gotcha

Leaving the Main Camera causes duplicate cameras; forgetting to assign input actions prevents controllers from working.
