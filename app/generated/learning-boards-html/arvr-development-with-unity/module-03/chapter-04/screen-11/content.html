Helper pattern
private void TriggerHaptic(XRBaseController controller, float intensity, float duration)
{
  if (controller != null && controller.inputDevice.isValid)
  {
    controller.inputDevice.SendHapticImpulse(0, intensity, duration);
  }
}
Use this helper in selectEntered and selectExited handlers to centralize haptic calls and to protect against invalid device references.
Usage examples
On grab
TriggerHaptic(controller, 0.3f, 0.1f) for a subtle confirmation when the object is selected.
On release
TriggerHaptic(controller, 0.5f, 0.15f) to emphasize the throw or drop event.
On fire
Trigger a short, strong pulse such as 0.8 intensity and 0.1s duration to match a projectile firing event.
Test values iteratively in Play Mode; start lower and increase intensity only if the tactile distinction is not clear.
