Module 4 › Chapter 3.4 › Controller Setup
Procedure
  1. Add Sphere Collider to each hand. Set Is Trigger.
  2. Add Rigidbody to hand and set Is Kinematic.
  3. Add XR Direct Interactor component to hand object.
  4. For grabbable object, add Collider + Rigidbody; set Is Kinematic based on whether it should be physics-driven.
  5. Add XRGrabInteractable to the object and tune Attach Transform if needed.
Pro tip

If the object snaps oddly, create an empty child at the desired grip position and assign it to Attach Transform.

Illustrated checks
Trigger collider
Should be set to Is Trigger so it detects overlap events instead of causing physics collisions that push objects away.
Rigidbody settings
Hand rigidbodies are kinematic. Interactable rigidbodies can be dynamic for throws or kinematic for static follows.
Behavior test
In Play Mode, reach in with the controller and confirm the object becomes selectable without jitter.
Common failure
If grabs fail, check that the action map is enabled and colliders are correctly layered and not blocked by geometry.
