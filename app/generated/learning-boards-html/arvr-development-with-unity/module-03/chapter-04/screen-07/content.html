Module 4 › Chapter 3.4 › Common Mistakes
Problem
Grab fails or snaps awkwardly.
Collider issues
Ensure the hand collider is set to Is Trigger and that it overlaps the object's collider when attempting to select.
Rigidbody issues
Confirm both objects have Rigidbodies with appropriate Is Kinematic settings for the desired behavior.
Attach Transform
If snap is awkward, supply a child Attach Transform positioned where the hand should grip.
Checks and fixes
Quick fix list
  1. Confirm hand collider Is Trigger.
  2. Confirm both objects have Rigidbody components.
  3. Adjust Attach Transform to correct grip offset.
  4. Ensure action maps are enabled for input events.
Common misconception
Believing collider presence alone is sufficient. Without matching Rigidbody and proper trigger settings, selection will fail.
