Module 4 › Chapter 3.4 › Key Concepts
XR Direct Interactor
Enables direct touch/grab using a hand collider and interactor component.
XR Grab Interactable
Makes an object grabbable and controls attach/follow behavior when selected.
Input System (Unity)
Defines action maps and actions that map controller inputs to abstract events in scripts.
Summary
These concepts form the essential vocabulary for setting up controller-driven interactions and mapping buttons to behavior in Unity XR projects.
