How it works

Attach Transform and Rigidbody behavior

Attach Transform specifies the exact point and rotation used when the object is held. Rigidbody kinematic setting decides whether the object is physics-driven on release or simply follows the interactor.

Grip alignment
Create an empty child at the desired grip and assign it to Attach Transform to prevent misaligned snaps.
Physics vs Snap
Dynamic rigidbodies allow realistic throwing; kinematic rigidbodies produce direct transform following.
Concrete example
Mug grip
Position the Attach Transform near the mug handle and rotate the child so the mug rests naturally in the virtual hand.
Test steps
  • Assign Attach Transform child and run Play Mode.
  • Grab and inspect alignment; adjust the child until the hold is natural.
  • If throwing is desired, ensure Rigidbody Is Kinematic is unchecked so release velocity applies.
