Module 4 › Chapter 3.4 › Input Actions
Setup

Create a FireProjectile action in the XRI RightHand action map and bind it to the right-hand trigger. Set Action Type to Button.

Why this matters
Actions provide device-agnostic inputs, letting you map gameplay logic to an abstract action rather than a specific button path.
Common mistake: forgetting to enable the action map at runtime so performed callbacks never execute.
Example code
using UnityEngine;
using UnityEngine.InputSystem;

public class SimpleActionListener : MonoBehaviour
{
  [SerializeField] private InputActionAsset inputActionAsset;
  private InputAction fireProjectileAction;

  void Start()
  {
    var rightMap = inputActionAsset.FindActionMap("XRI RightHand");
    fireProjectileAction = rightMap.FindAction("FireProjectile");
    rightMap.Enable();
    fireProjectileAction.performed += ctx => OnFireProjectile();
  }

  void OnDestroy()
  {
    if (fireProjectileAction != null) fireProjectileAction.performed -= ctx => OnFireProjectile();
  }

  private void OnFireProjectile()
  {
    Debug.Log("Fire Projectile action performed!");
  }
}
This pattern finds the action, enables its map, and subscribes to the performed callback to run gameplay logic when the button is pressed.
