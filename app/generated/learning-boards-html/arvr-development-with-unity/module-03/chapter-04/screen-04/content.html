Module 4 › Chapter 3.4 › Direct Interaction
Definition

XR Direct Interactor

A component attached to a hand representation that uses a trigger collider to detect and select grabbable objects.

Quick checklist
  • 1. Hand has Sphere Collider (Is Trigger) and Rigidbody (Is Kinematic).
  • 2. Add XR Direct Interactor to hand controller gameobject.
  • 3. Add Collider + Rigidbody + XRGrabInteractable to the grabbable object.
Key Takeaway

All three pieces — interactor, colliders, and rigidbodies — must be configured for reliable direct grabbing.

Illustration
Hand controller
Sphere collider (trigger), kinematic Rigidbody, XR Direct Interactor component attached to this GameObject.
Grabbable object
Collider + Rigidbody (non-kinematic for physics throws) + XRGrabInteractable component.
Example scenario
Place a sphere at (0,1.2,1), attach XRGrabInteractable and a Rigidbody with Is Kinematic unchecked so you can pick it up and throw it normally.
Common mistake: missing Rigidbody or collider not set to trigger; either prevents the interactor from selecting the object.
