What is haptics?

Tactile feedback via controller vibrations

Haptic feedback conveys interaction meaning through intensity and duration. Use it to confirm selection, indicate impact, or provide continuous cues like carrying a heavy object.

Hover
Light, very short pulse (e.g., intensity 0.2, duration 0.05s).
Impact
Moderate pulse, slightly longer (e.g., intensity 0.7, duration 0.1s).
Avoid
High-intensity continuous vibration; causes discomfort and fatigue.
API
// SendHapticImpulse(channel, intensity, duration)
if (controller.inputDevice.isValid)
{
  controller.inputDevice.SendHapticImpulse(0, 0.7f, 0.1f);
}
Key Takeaway

Tune intensity and duration per event; use a small, consistent set of haptic styles for clarity and comfort.
