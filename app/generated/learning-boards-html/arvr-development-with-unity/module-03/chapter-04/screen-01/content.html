Controller-Based Interactions and Haptics

Configure XR Direct Interactor and XR Grab Interactable, wire input actions, and add meaningful haptic feedback to make XR interactions feel tactile and safe.

16:9 HD Classroom
In this lesson

Set up direct grab interactions, detect button actions, and design haptic cues that match events.

Why it matters: tactile cues improve clarity and immersion while correct physics prevent surprising behavior.
Coming up

A hands-on throwable object demo: grab, throw, and fire with haptic pulses on grab, release, and fire.

Explore Key Topics
Direct Interaction
Use XR Direct Interactor plus colliders and rigidbodies to make objects grabbable and follow the controller.
Input Actions
Define actions in an Input Action Asset to map buttons to game events like FireProjectile.
Haptics
SendHapticImpulse lets you vary intensity and duration to communicate different events safely.
Visual Concept
Hand controller + sphere
Hand collider reaches object, XRGrabInteractable responds and follows.
Attach Transform
Defines how the object aligns to the hand. Use a child empty object if hold position is awkward.
Haptic Example
On grab: light pulse. On release: stronger pulse. On fire: short, strong impulse using SendHapticImpulse.
