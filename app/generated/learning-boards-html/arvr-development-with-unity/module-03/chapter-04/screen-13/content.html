Module 4 › Chapter 3.4 › Throwable Demo
Scene steps
  1. Add XR Origin with LeftHand and RightHand controllers.
  2. Give each hand a Sphere Collider (Is Trigger), Rigidbody (Is Kinematic), and XR Direct Interactor.
  3. Create a Sphere at (0,1.2,1) with Collider, Rigidbody (Is Kinematic unchecked), and XRGrabInteractable.
  4. Create FireProjectile and HapticPulse actions in the XRI RightHand map and bind them to triggerPressed.
  5. Attach the provided ThrowableObject script to the Sphere and assign references in the inspector.
Test

In Play Mode grab and throw the sphere. Press the trigger to fire a projectile. Feel the haptic pulses on grab, release, and fire.

Starter code (excerpt)
private void OnGrab(SelectEnterEventArgs args)
{
  Debug.Log(gameObject.name + " grabbed by " + args.interactorObject.transform.name);
  if (args.interactorObject is XRBaseControllerInteractor controllerInteractor)
  {
    TriggerHaptic(controllerInteractor.xrController, grabHapticIntensity, grabHapticDuration);
  }
}

private void OnRelease(SelectExitEventArgs args)
{
  if (args.interactorObject is XRBaseControllerInteractor controllerInteractor)
  {
    TriggerHaptic(controllerInteractor.xrController, releaseHapticIntensity, releaseHapticDuration);
  }
}
Attach projectilePrefab and InputActionAsset in the inspector. If firing does not occur, ensure the action map is named exactly as referenced and is enabled.
