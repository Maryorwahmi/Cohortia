Module 3 › Chapter 3.1 › Common Interactor Types
XR Ray Interactor
Projected ray for distant selection and UI pointing. Use when precision at range matters.
XR Direct Interactor
Proximity-based interactor for touching and grabbing nearby objects with natural contact.
Gaze / Head Interactor
Uses head orientation for selection; useful in limited-input scenarios or AR gaze UX.
Example
A toolbox demo uses a direct interactor for grabbing tools and a ray interactor for toggling distant switches; both interactor types raise the same logical events consumed by Interactables.
