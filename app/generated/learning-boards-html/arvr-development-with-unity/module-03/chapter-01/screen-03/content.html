Module 3 › Chapter 3.1 › Objective Outcomes
Install & enable XRI
Open Package Manager, install XR Interaction Toolkit, and accept recommended samples and settings.
Enable XR Plugin Provider
Enable OpenXR or your target provider in Project Settings to allow runtime tracking.
Create XR Origin
Add XR Origin (VR/AR) to the Hierarchy so camera and controllers have a root to follow.
Assign Input Action Assets
Set XRI Default Input Actions on the XR Interaction Manager and assign the asset on controllers.
