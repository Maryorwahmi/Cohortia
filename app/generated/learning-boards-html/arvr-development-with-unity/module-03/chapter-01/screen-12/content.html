Module 3 › Chapter 3.1 › Assign Actions
Steps to assign
  1. Expand XR Origin and select LeftHand Controller.
  2. In XR Controller (Action-based), set Input Action Asset to your asset.
  3. Repeat for RightHand Controller.
  4. Select XR Interaction Manager and set Default Input Actions to the same asset.
Validation
Enter Play Mode with a connected headset and ensure hover and select events fire when you press mapped buttons.
Common pitfall
Controllers are tracked but actions don’t fire because the action asset is not assigned to the controller or the interaction manager.
