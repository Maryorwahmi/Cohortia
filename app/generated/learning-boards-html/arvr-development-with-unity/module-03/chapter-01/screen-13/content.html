Module 3 › Chapter 3.1 › Troubleshooting
Quick checklist
  • Is XR Interaction Toolkit installed and updated?
  • Is an XR Plugin Provider enabled in Project Settings?
  • Does the scene have an XR Origin and XR Interaction Manager?
  • Are Input Action Assets assigned to controllers and the manager?
Example fix
If controllers track but actions do not fire, open the XR Interaction Manager and confirm the Default Input Actions field references your Input Action Asset. Assign it if empty and restart Play Mode.
Pro tip
Keep a single canonical Input Action Asset for the project and reference it everywhere to avoid mismatches between duplicated assets.
