Module 3 › Chapter 3.1 › Hands-on Activity
Steps
  1. Create a new 3D URP project and install XR Interaction Toolkit.
  2. Enable OpenXR in Edit → Project Settings → XR Plugin Management.
  3. Add XR → XR Origin (VR/AR) to the Hierarchy.
  4. Assign XRI Default Input Actions to the controllers and XR Interaction Manager.
  5. Add a cube and attach XRGrabInteractable. Enter Play Mode and test grabbing.
Checkpoints
  • XR Origin exists and is active.
  • Controllers have XR Controller (Action-based) components.
  • Input Action Asset is assigned to controllers and manager.
  • Interactables respond when the mapped buttons are pressed.
