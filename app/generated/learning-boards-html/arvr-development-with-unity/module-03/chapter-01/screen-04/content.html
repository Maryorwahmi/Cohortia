Module 3 › Chapter 3.1 › 2D vs 3D Input
2D Input (Mouse / Touch)
  • Single plane coordinates and discrete clicks or taps.
  • UI focused; hover and focus states originate from cursor position.
  • Interaction is often instantaneous and local to the viewport.
Concrete example
Clicking a button to open a menu uses a 2D coordinate and a discrete input event.
3D XR Input (HMD, Controllers, Hands)
  • Position and orientation matter; interactions depend on reach and direction.
  • Continuous tracking enables gestures, rays, and direct manipulation.
  • Mapping buttons to logical actions must respect spatial context.
Misconception
Treating XR as 2D UI will break affordances like grabbing and occlusion.
Tip
Use distance thresholds for direct grabs to avoid accidental picks.
Takeaway
Model interactions as spatial affordances, not clicks.
