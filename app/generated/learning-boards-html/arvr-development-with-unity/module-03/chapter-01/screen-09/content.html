Module 3 › Chapter 3.1 › Install & Enable
Step-by-step
  1. Open Window → Package Manager and select Unity Registry.
  2. Search and install XR Interaction Toolkit, accept recommended defaults.
  3. Open Edit → Project Settings → XR Plugin Management.
  4. Enable OpenXR or your target provider and apply settings.
Why order matters
XRI installation provides components; enabling a plugin provider activates runtime tracking required for controllers to report input in Play Mode.
Troubleshoot
If controllers aren’t tracked, verify the XR Interaction Manager exists, the Default Input Actions are assigned, and restart Unity after enabling plugins.
