Module 3 › Chapter 3.1 › Interactors & Interactables
Interactor (tool)
Examples: XR Ray Interactor, XR Direct Interactor. Responsible for detecting targets and raising interaction events.
Key behaviors
  • Detect targets (raycast or overlap)
  • Raise hover/select/activate events
  • Attach or manipulate objects when appropriate
Interactable (object)
Examples: XRGrabInteractable, XRSimpleInteractable. Defines how an object responds to events raised by any Interactor.
Grab behavior
Attach to the Interactor, optionally transfer physics ownership.
Socket behavior
Define a slot that accepts objects when released.
Scenario
A ray interactor selects a distant button, while a direct interactor picks up a nearby tool; both use the same Interactable scripts so object behavior is consistent.
