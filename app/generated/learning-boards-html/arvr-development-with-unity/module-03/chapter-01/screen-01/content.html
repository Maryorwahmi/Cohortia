Understanding XR Input Systems in Unity
A practical walkthrough of XRI, XR Origin, and device-agnostic input.
In this lesson

You will learn the XRI pattern, install and enable plugin providers, create an XR Origin, and configure Input Action Assets so controllers register actions consistently.

Why it matters

Device-agnostic actions save time and let your scene respond the same way whether a user has an OpenXR headset or another runtime.

Starter checklist
  • Install XR Interaction Toolkit from the Package Manager.
  • Enable an XR plugin provider like OpenXR in Project Settings.
  • Create an XR Origin and assign Input Action Assets to controllers.
