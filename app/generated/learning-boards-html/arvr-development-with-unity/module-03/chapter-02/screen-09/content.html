Module 3 › Chapter 3.2 › Setup Steps: Gaze and Ray Interactors
1. Add XR Origin
Start with an XR Origin so camera and controllers are organized for interaction components.
2. Attach XR Gaze Interactor
Add the gaze interactor to Main Camera and test hover events with an XRSimpleInteractable cube.
3. Add XRSimpleInteractable and Dwell
Set Gaze Dwell Time to 2s for gaze-based selection or zero to rely only on explicit select calls.
4. Add Ray Interactors & Line Visuals
Attach XR Ray Interactor and XR Interactor Line Visual to each controller and confirm the reticle appears on hits.
5. Set Interaction Layer Masks
Ensure controllers can only hit intended layers. Mismatched masks are the most common cause of missed hits.
6. Verify Colliders & Rigidbodies
Use non-trigger colliders or pair triggers with a kinematic Rigidbody depending on your physics setup.
7. Attach Event Scripts & Test
Add the color-change scripts, run Play Mode, and verify hover logs, color swaps, and select logs before adding more complexity.
