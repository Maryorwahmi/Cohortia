Module 3 › Chapter 3.2 › Gaze vs Pointer — Choosing the Right Input
Gaze Interaction
Strengths: hands-free, simple to discover. Weaknesses: poor precision, head jitter sensitivity.
Example: gaze a scene button for 2 seconds to change level.
Design tip: add radial progress and hover color to reduce false activations.
Pointer (Ray) Interaction
Strengths: precise aiming and manipulation. Weaknesses: requires a controller or hand-tracking, can be more complex to tune.
Example: use a controller ray to pick up and move a remote object.
Design tip: ensure Interaction Layer Mask includes the object's layer and show a reticle for hit feedback.
