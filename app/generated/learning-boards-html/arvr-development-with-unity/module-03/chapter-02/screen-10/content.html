Module 3 › Chapter 3.2 › Interaction Components and Events
Component Map
XR Origin • Camera (XR Gaze Interactor) • Left/Right Hand (XR Ray Interactor + Line Visual)
Interactable Node
XRSimpleInteractable + Collider (+ Rigidbody if physics-driven) + script subscribing to hover/select events.
Event Flow
  1. Interactor casts ray.
  2. Ray hits Collider on an Interactable.
  3. Interactable fires firstHoverEntered; scripts can respond.
  4. On input or dwell completion, selectEntered fires.
Tip: the XR Interactor Line Visual only draws visuals. Event routing depends on masks, colliders, and the interactable component.
