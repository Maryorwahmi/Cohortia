Module 3 › Chapter 3.2 › Activity Walkthrough: Build and Test Two Cubes
Scene Setup
  1. Create XR Origin and two cubes at (0,1,3) and (2,1,5).
  2. Create HoverMaterial and DefaultMaterial; assign Default to both cubes.
  3. Add XRSimpleInteractable to each cube.
Scripts and Components
  1. Attach GazeInteractableColorChange to the gaze cube; set Gaze Dwell Time = 2s; ensure Main Camera has XR Gaze Interactor.
  2. Attach RaySelectableColorChange to the ray cube; add XR Ray Interactor and XR Interactor Line Visual to controllers.
  3. Set Interaction Layer Masks to include cube layer.
Test & Validate
Enter Play Mode: gaze at the first cube for two seconds to see color change. Point the controller ray at the second cube to see hover color, then press trigger to see select log. If anything fails, follow the troubleshooting checklist.
