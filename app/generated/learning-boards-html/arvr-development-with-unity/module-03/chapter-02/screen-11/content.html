Module 3 › Chapter 3.2 › Troubleshooting Raycast and Collider Issues
Quick Checks
  • Interaction Layer Mask includes object layer.
  • Collider enabled and sized correctly.
  • Trigger colliders paired with Rigidbody if needed.
Logging & Isolation
Attach a minimal script that logs firstHoverEntered and selectEntered. Use a minimal test scene with one cube to isolate the issue from complex scene hierarchies.
If logs never show hover, the problem is likely a mask or collider. If hover logs fire but visuals don't update, check your material handling and renderer references.
Fix Example
If ray passes through: open the controller's XR Ray Interactor, confirm Interaction Layer Mask contains the object's layer, then toggle the collider's enabled state to refresh physics. Add Debug.Log statements to trace event firing.
