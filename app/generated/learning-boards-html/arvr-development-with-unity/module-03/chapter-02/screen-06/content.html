Module 3 › Chapter 3.2 › Pointer (Ray) Interaction: How It Works
XR Ray Interactor Basics
Attach XR Ray Interactor to controller objects. Pair with XR Interactor Line Visual to draw the pointer and reticle.
Interaction Layer Mask: include only layers that should be targeted.
Collider requirements: non-trigger colliders detect hits reliably; triggers may need Rigidbody adjustments.
Reticle: gives precise hit feedback and helps gauge distance.
Concrete Example
Add XR Ray Interactor to LeftHand Controller and RightHand Controller. Add XR Interactor Line Visual to the same GameObjects. Confirm the reticle appears when the ray hits a cube with an XRSimpleInteractable.
Check your understanding: If the ray misses an object that has an XRSimpleInteractable, what are the first two properties to verify? (Hint: layer mask and collider configuration.)
Common Mistake

Leaving interaction layers unconfigured or having trigger colliders with no Rigidbody can make the ray pass through objects.
