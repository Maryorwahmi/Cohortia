Module 3 › Chapter 3.3 › Create a World Space Canvas
Steps
1. Create UIPanel GameObject
Place roughly at head height in front of the player, e.g., 0,1.5,2.
2. Add UI > Canvas
In Inspector, set Render Mode to World Space immediately.
3. Set Rect Transform
Width 500, Height 300, Scale 0.002 uniform to convert to meters.
4. Add TMP Text & Button
Import TMP essentials if needed and position elements within the canvas.
5. Add XR Graphic Raycaster
This allows XR Ray Interactors to target UI elements on the canvas.
Test
Enter Play Mode and verify ray pointer highlights the button and triggers On Click events.
Sizing example
500x300 canvas scaled to 0.002 gives approximately 1.0m by 0.6m. Adjust scale for comfortable reach and readability.
Common mistake
Leaving default scale or forgetting the XR Graphic Raycaster. If the button doesn’t respond, check for the missing raycaster first.
Why it matters
A correctly sized and ray-enabled canvas lets users interact comfortably and preserves immersion, reducing testing friction later.
