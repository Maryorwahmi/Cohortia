Module 3 › Chapter 3.3 › Why XR UI differs
XR UI vs 2D UI
Three-dimensional context changes legibility, interaction, and perceived depth.
  • Depth & Perspective
    UI should respect world depth so users see consistent parallax and distance cues.
  • Input Modality
    Rays, gaze, and direct touch require different collider and component setups than mouse clicks.
  • Readability
    Fonts and control sizes must be tuned for viewing distance in meters, not pixels on a screen.
Key Takeaway

Design UI as physical objects: set scale in meters, add ray-aware components, and test inside the headset.

Analogy
Treat your UI like a physical control panel in the real world — place it at reachable height, make labels big enough to read from a comfortable distance, and avoid tiny targets.
Common mistake
Using Screen Space Overlay in XR because it’s quick. That flattens depth and detaches UI from the world, reducing presence.
Check your understanding
Can you read 12pt text at 1.5 meters in your headset? If not, increase font size or move the panel closer.
