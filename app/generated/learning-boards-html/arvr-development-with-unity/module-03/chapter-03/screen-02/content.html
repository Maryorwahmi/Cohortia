Mnemonic
Think: Canvas → Raycaster → XR UI → Unity Event → Script. Each step passes the interaction to the next.
Why this matters
Proper setup avoids invisible hits, unreachable controls, and UI that pulls users out of the virtual world. Small setup fixes dramatically improve comfort.
