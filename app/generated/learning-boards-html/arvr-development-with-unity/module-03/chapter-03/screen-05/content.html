Module 3 › Chapter 3.3 › Canvas Render Modes
Screen Space - Overlay
Draws UI on top of everything, ignores depth. Fast for menus but unsuitable for immersive VR dashboards.
Screen Space - Camera
Renders to a specific camera; remains camera-relative and flattened, useful for mixed camera effects but still not truly 3D.
World Space
Acts as a 3D object. Set Render Mode to World Space and treat the canvas like a physical panel. Recommended for XR.
Practical hint
Use pixel size + small uniform scale for World Space. Example: 1000x1000 canvas scaled to 0.001 yields ~1 meter.
Visual rule-of-thumb
If you need UI to live on objects, be reachable, or obey perspective, choose World Space.
Check your understanding
  • - Would a floating tablet be best as Overlay, Camera, or World Space?
  • - Does pixel size alone determine world size? (Hint: use scale.)
Common mistake
Not scaling pixel-based canvases for world meters, resulting in panels that are too large or small in VR.
