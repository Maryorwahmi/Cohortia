Script example
Attach this script to a GameLogic object and assign StatusText in the inspector. Wire button On Click to OnButtonClicked and slider On Value Changed to OnSliderValueChanged.
<!-- C# UIManager (escaped for HTML) -->
using UnityEngine;
using TMPro; // If using TextMeshPro

public class UIManager : MonoBehaviour
{
  [SerializeField] private TextMeshProUGUI statusText; // Assign in Inspector

  public void OnButtonClicked()
  {
    Debug.Log("UI Button Clicked!");
    if (statusText != null)
    {
      statusText.text = "Button Pressed!";
    }
  }

  public void OnSliderValueChanged(float value)
  {
    Debug.Log("Slider value: " + value);
    if (statusText != null)
    {
      statusText.text = $"Slider: {value:F2}";
    }
  }
}
Concrete wiring steps
Create GameLogic, attach UIManager, drag StatusText into the field. On Button > On Click, add GameLogic and select UIManager.OnButtonClicked.
Common mistake
Not assigning the TextMeshProUGUI reference results in no visible update. Always verify inspector references before Play Mode.
Key takeaway
Small, focused scripts plus Unity Events make UI logic easy to wire and test in XR.
