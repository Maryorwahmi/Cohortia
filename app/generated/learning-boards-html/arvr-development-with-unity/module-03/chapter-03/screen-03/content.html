Objectives — Practical checks
Each objective below includes an example action and a common mistake to watch for while you build.
Canvas Types — Example
Switch a canvas to Overlay and then to World Space. Observe how overlap and depth change. Misconception: overlay can be used in VR without disrupting presence.
VERIFIED COMPETENCY MILESTONE
World Space Setup — Example
Create a 1000x1000 canvas, scale to 0.001, and place it at 1.5 meters in front of the player. Mistake: leaving default scale makes UI huge or tiny in world meters.
VERIFIED COMPETENCY MILESTONE
XR Interactivity — Example
Add XR Graphic Raycaster and verify ray hits a button. Mistake: forgetting to include the canvas layer in the ray actor's Interaction Layer Mask.
VERIFIED COMPETENCY MILESTONE
Unity Events — Example
Wire a button's On Click to UIManager.OnButtonClicked and confirm the TextMeshPro field updates. Mistake: not assigning the TextMeshPro reference in the inspector.
VERIFIED COMPETENCY MILESTONE
Quick mnemonic
Canvas → Raycaster → XR UI → Events → Script. Run one quick test per stage.
