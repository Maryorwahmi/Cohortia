Module 3 › Chapter 3.3 › Standard UI Elements
Common elements
Buttons, TextMeshPro text, sliders, and toggles are UI building blocks. In World Space they render as meshes on a plane.
TextMeshPro
Use TMP for sharp text. Assign a TextMeshProUGUI to your UIManager to update text at runtime.
XR UI bridge components
Add XR UI Button / Slider / Toggle to bridge standard UI events with XR Interaction Toolkit events.
Concrete example
Create StatusText (TMP) and ActionButton (Button). Add XR UI Button to ActionButton, then attach a Unity Event to call UIManager.OnButtonClicked.
Common mistake
Expecting native UI elements to respond to XR rays without adding XR UI components and the XR Graphic Raycaster.
Try this
Add a slider and confirm On Value Changed fires to update a text field — this validates both ray hits and event wiring.
