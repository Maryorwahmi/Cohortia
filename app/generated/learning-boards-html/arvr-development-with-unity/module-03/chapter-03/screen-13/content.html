Activity: Build a World Space UI Panel
Step through the checklist and verify each stage in Play Mode.
Scene setup
Ensure XR Origin and XR Ray Interactors exist on controllers.
UIPanel & Canvas
Create UIPanel at 0,1.5,2. Add Canvas, set Render Mode to World Space.
Rect Transform
Width 500, Height 300, Scale 0.002 uniform.
XR Graphic Raycaster
Add this component to the canvas to enable ray hits.
UI Elements
Add TextMeshPro StatusText and Button ActionButton. Add XR UI Button to the Button.
Scripting & Wiring
Attach UIManager to GameLogic, assign StatusText, and link Button On Click to UIManager.OnButtonClicked.
Test checklist
Enter Play Mode, point with the ray, confirm the button highlights, press it, and check that StatusText updates and Console logs appear.
Troubleshooting
If the button doesn't respond, verify XR Graphic Raycaster, canvas layer, and the ray interactor's Interaction Layer Mask include that layer.
Extension challenge
Add a slider to the panel and wire On Value Changed to UIManager.OnSliderValueChanged so the status shows the slider value.
