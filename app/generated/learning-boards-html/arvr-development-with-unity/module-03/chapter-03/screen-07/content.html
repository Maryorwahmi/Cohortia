RectTransform → Pixels; Scale → Meters
Use pixel dimensions to place UI elements, then apply a uniform scale to set world size.
Sizing example
1000x1000 canvas scaled to 0.001 ≈ 1 x 1 meter. 500x300 with 0.002 ≈ 1 x 0.6 meters.
Common mistake
Non-uniform scaling distorts layout and hit detection. Always use the same value for X, Y, Z when scaling canvases.
Canvas Scaler note
The Canvas Scaler is helpful for screen-space UI. For World Space, disable or configure it intentionally to avoid unwanted pixel scaling behavior.
Check: hands-on
Create two canvases with different pixel sizes and the same scale. Compare their apparent world sizes to confirm the scale mapping.
Why it matters
Correct scaling avoids unreadable text and unreachable controls, and it ensures consistent interaction geometry for raycasts and direct touches.
