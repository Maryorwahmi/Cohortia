Module 3 › Chapter 3.3 › XR Graphic Raycaster
What it does
Processes ray hits on Canvas graphics and converts them into UI events that XR UI components can use.
Setup checklist
  • - Add XR Graphic Raycaster to the World Space Canvas.
  • - Place the canvas on a layer included in your XR Ray Interactor's Interaction Layer Mask.
  • - Ensure UI elements have XR UI bridge components (e.g., XR UI Button).
Debug tip
If nothing registers, check the Console for pointer logs and confirm the ray interactor is active and targeting the UI layer.
Concrete example
Add XR Graphic Raycaster to WorldSpaceUI. Set the ray interactor to include layer 'UI'. Point and verify the button highlights and triggers the event.
Common misconception
Relying only on physics raycasts for UI. Graphic Raycaster is required for Canvas graphics.
