Module 3 › Chapter 3.3 › Direct vs Ray Interaction
XR Ray Interactor
Best for distant UI. Uses a visible or invisible ray to point at UI elements and trigger events remotely.
XR Direct Interactor
Enables touch and grab mechanics for objects close to the hand, often used with XR Grab Interactable on physical items that contain UI.
Concrete scenario
A tablet: make it XR Grab Interactable so the user can pick it up. Inside, the tablet hosts a World Space canvas with XR Graphic Raycaster so buttons remain interactable while held.
Common mistake
Using direct interaction for all UI assuming it’s always more immersive — this often increases fatigue and complexity.
