Interaction Layer Mask
Assign canvas to a 'UI' layer and include that layer in the ray interactor mask to enable hits.
Checklist
  • - Canvas assigned to UI layer
  • - XR Graphic Raycaster present on canvas
  • - XR UI Button on button elements
  • - Ray Interactor mask includes UI layer
Tuning
Adjust ray length and pointer visuals to help aiming. Use a reticle on hit to confirm target selection.
Concrete example
Set canvas to 'UI' layer. In XR Ray Interactor, add 'UI' to Interaction Layer Mask. Point and confirm the button highlights and triggers the event.
Common mistake
Forgetting to set the canvas layer or leaving the interactor mask unset — resulting in invisible, untargetable UI.
