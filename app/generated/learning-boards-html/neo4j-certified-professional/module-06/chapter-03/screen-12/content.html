Module 6 › Chapter 3 › Security: authentication and authorization
Core Concept

AuthN and AuthZ

Authenticate requests at the transport layer, then perform authorization checks inside resolvers before returning sensitive fields.

Checklist
  • Validate JWT or session at the HTTP layer.
  • Check ownership or role before returning private fields.
  • Apply rate limiting and input validation at the API edge.
Concrete example
Before resolving User.privatePosts, verify the request's user ID matches the User node's owner or that the requester has a role permitting access. Deny or filter results if not authorized.
Misconception
Transport-level authentication is not enough; field-level checks inside resolvers are required to prevent data leaks.
