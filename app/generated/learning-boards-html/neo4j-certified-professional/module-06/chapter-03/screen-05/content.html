Module 6 › Chapter 3 › GraphQL for graph data
Definition

GraphQL: query by shape

Clients specify which fields and nested relationships they want, reducing over- and under-fetching when the schema mirrors the graph model.

Benefits for graph models
  • Single request for nested traversals.
  • Client-driven selection prevents over-fetching.
  • Schema maps clearly to nodes and relationships.
Misconception
GraphQL alone does not guarantee efficient DB access; resolvers must be designed to avoid multiple DB round trips.
Concrete example
A client can request a movie and nested actors in one GraphQL query and receive only the requested fields, avoiding separate endpoints.
query GetMovie($title: String!) {
  movie(title: $title) {
    title
    releaseYear
    actors {
      name
    }
  }
}
Implement resolvers to fetch the movie node and its related actor nodes efficiently, ideally with a single Cypher query or batched loader to avoid an N+1 pattern.
