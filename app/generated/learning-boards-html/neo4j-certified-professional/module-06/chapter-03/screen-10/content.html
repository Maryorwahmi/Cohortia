Architecture

Auto-generated resolvers

The library reads relationship directives and builds the Cypher needed to satisfy queries. It plugs into your GraphQL server so client queries are fulfilled automatically.
Developer benefit
Fewer handwritten resolvers and faster schema-first development.
Verification step
Run queries in a playground, inspect generated Cypher, and measure DB calls. Replace slow paths with custom resolvers when needed.
