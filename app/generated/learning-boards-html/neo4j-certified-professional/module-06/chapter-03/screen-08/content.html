Module 6 › Chapter 3 › Resolvers: role and responsibilities
Core Concept

What resolvers do

  • Authenticate and authorize requests for specific fields.
  • Fetch data from Neo4j via driver, OGM, or generated Cypher.
  • Batch or cache requests to avoid N+1 patterns.
Misconception
Resolvers are not 'free' — each one may translate to a database call if not optimized.
Concrete example
A naive Movie.actors resolver that runs a Cypher query per movie causes N+1 DB calls. Use a batched resolver or a single Cypher that returns movies with collected actors.
MATCH (m:Movie)-[:ACTED_IN]->(a:Actor)
WHERE ID(m) IN $movieIds
RETURN m.id AS movieId, COLLECT(a) AS actors
Distribute the results to each movie resolver instance so you avoid per-movie queries.
