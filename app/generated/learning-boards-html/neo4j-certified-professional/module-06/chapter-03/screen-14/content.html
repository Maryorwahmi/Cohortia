Module 6 › Chapter 3 › Key Concepts
RESTful API
Resource-oriented and stateless, may be chatty for deep traversals.
GraphQL
Query language that returns exactly the requested nested shape, fitting graph use-cases.
Resolvers
Functions that fetch data, enforce auth, and must be optimized to avoid many DB calls.
Takeaway

Design schemas to mirror Neo4j graphs, use GraphQL for nested requests, and optimize resolvers with batching or single-query Cypher to keep APIs efficient and secure.
