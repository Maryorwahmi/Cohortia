Process Flow

Batching pattern

  1. Collect keys requested by child resolvers during the tick.
  2. Run a single batched Cypher with WHERE ID(m) IN $keys.
  3. Map collected results back to each resolver call.
Pro tip
Batching also benefits from caching identical requests within a request lifecycle to avoid duplicate DB queries.
Example batched Cypher
MATCH (m:Movie)-[:ACTED_IN]->(a:Actor)
WHERE ID(m) IN $movieIds
RETURN m, COLLECT(a) AS actors
Use the returned movie records and grouped actors to satisfy each Movie.actors resolver without issuing N queries.
