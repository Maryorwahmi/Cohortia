Module 6 › Chapter 6.5 › Monitoring
Definition
What to monitor for Neo4j
Database metrics
  • Heap usage and GC pauses
  • Page cache hit ratio
  • Disk I/O and swap
  • Query execution time and slow queries
Application telemetry
  • Request latency and error rates
  • Connection pool utilization
  • APM traces to correlate with Cypher executions
Example pipeline
Scrape Neo4j metrics via JMX exporter or scrape metrics CSV, ingest into Prometheus, visualize in Grafana, and correlate with application logs and APM traces for root-cause analysis.
Key Takeaway

Metric correlation between Neo4j and the app is the fastest way to diagnose whether slow responses come from expensive Cypher or application-side bottlenecks.
