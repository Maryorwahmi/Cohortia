A1
Secure credential handling
Retrieve connection URIs and credentials from environment variables or a secure vault instead of hardcoding them.

A2
Prevent Cypher injection
Always use parameterized queries rather than concatenating user input into query strings.
VERIFIED COMPETENCY MILESTONE
A3
Efficient result handling
Iterate returned records and access node properties rather than pulling entire result sets into memory when possible.

A4
Graceful error handling
Catch network and query errors, log meaningful diagnostics, and do not leak sessions or driver resources in error paths.
