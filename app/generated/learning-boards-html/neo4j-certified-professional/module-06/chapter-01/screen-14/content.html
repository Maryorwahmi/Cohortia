Module 6 › Chapter 6.1 › Key Concepts
Neo4j Drivers
Language libraries that expose sessions, transactions, and pooling while translating calls to Bolt.
Bolt Protocol
A performant binary protocol that enables streaming and multiplexing of graph record data.
Parameterized Queries
Pass user values as parameters to avoid injection and to enable plan reuse.
Takeaway

Combine driver usage, Bolt efficiency, parameterization, transactions, and pooling discipline to build reliable and secure Neo4j-backed applications.
