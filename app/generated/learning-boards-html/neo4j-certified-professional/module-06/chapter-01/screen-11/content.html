def add_follow_relationship(tx, follower_name, followed_name):
  # MATCH two users and CREATE a FOLLOWS relationship; use parameters!
  query = (
    "MATCH (a:User {name: $follower}), (b:User {name: $followed})"
    " CREATE (a)-[:FOLLOWS]->(b)"
    " RETURN a.name AS follower_name, b.name AS followed_name"
  )
  result = tx.run(query, follower=follower_name, followed=followed_name)
  return result.single()


def get_followers(tx, user_name):
  # MATCH incoming FOLLOWS and RETURN follower names as a list
  query = (
    "MATCH (f:User)-[:FOLLOWS]->(u:User {name: $name})"
    " RETURN f.name AS follower_name"
  )
  result = tx.run(query, name=user_name)
  return list(result)
Guidance & checks
  • Use parameters follower and followed in the tx.run call to bind values safely.
  • Consider MERGE instead of CREATE if you need idempotent relationships.
  • Return only follower_name to keep result size small.
  • Call session.write_transaction to make relationship creation atomic.
Test scenario
Create Alice and Bob, add a follows relationship from Alice to Bob, then call get_followers for Bob and print the follower names.
