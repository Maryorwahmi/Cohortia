Module 6 › Chapter 6.1 › Secure Connections
Connection steps
1
Define URI: Use neo4j://host:port or bolt://host:port depending on driver and deployment.
2
Fetch credentials: Read username and password from environment variables or a secret manager.
3
Create driver once: Instantiate a single driver at startup to let pooling work.
4
Close driver: Call driver.close at shutdown to release pooled connections.
Example
In Python: call GraphDatabase.driver(uri, auth=(user, pwd)) once and reuse it across requests.
Common pitfalls & fixes
Mistake
Creating driver instances per request leads to high latency and socket exhaustion.
Fix
Create one driver per process and reuse it. Configure pool size to match expected concurrency.
Mistake
Hardcoding passwords in source code.
Fix
Use environment variables or a secret manager and rotate credentials without updating code.
Reflection

If driver creation is expensive, design your deployment to create drivers during process startup and reuse across threads or request handlers.
