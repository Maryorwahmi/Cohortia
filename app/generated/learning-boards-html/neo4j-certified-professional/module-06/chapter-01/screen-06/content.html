Example code (Python)
from neo4j import GraphDatabase

uri = "neo4j://localhost:7687"
username = "neo4j"
password = "your_password"

driver = GraphDatabase.driver(uri, auth=(username, password))

def add_user(tx, name, email):
  query = (
    "CREATE (u:User {name: $name, email: $email})"
    " RETURN u.name AS name, u.email AS email"
  )
  result = tx.run(query, name=name, email=email)
  return result.single()

def find_user(tx, name):
  query = (
    "MATCH (u:User {name: $name})"
    " RETURN u.name AS name, u.email AS email"
  )
  result = tx.run(query, name=name)
  return result.single()

with driver.session() as session:
  user_data = session.write_transaction(add_user, "Alice", "alice@example.com")
  print(f"Added user: {user_data['name']} ({user_data['email']})")
  found = session.read_transaction(find_user, "Alice")
  if found:
    print("Found user.")
  else:
    print("User not found.")

driver.close()
Explanation & notes
  • Driver creation: GraphDatabase.driver returns a reusable driver that manages pooling.
  • Parameterized queries: Use $name and $email placeholders and pass values separately to avoid injection.
  • Transactions: Use session.write_transaction to wrap commits and handle retries provided by the driver.
  • Result handling: result.single() may return None; check before accessing returned fields.
Concrete scenario

Use this pattern when a web handler needs to create or query a user. Create the driver at process start, open a session per request, and use transactions for write operations.
