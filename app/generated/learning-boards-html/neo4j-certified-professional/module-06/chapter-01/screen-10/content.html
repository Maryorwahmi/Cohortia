Module 6 › Chapter 6.1 › Common Mistakes
Mistake vs Fix
Leaking connections
Fix: use context managers, close sessions, close driver on shutdown, monitor pool usage.
Unparameterized queries
Fix: replace string concatenation with parameter placeholders and pass values separately.
Fetching too much data
Fix: project only required properties and page results when datasets are large.
Quick remediation checklist
  • Wrap session usage in with blocks or try/finally to ensure closure.
  • Always pass user data as parameters, never inline it into query strings.
  • Limit and project query results to avoid large memory consumption.
  • Implement retry logic for transient network failures and log meaningful diagnostics.
Concrete example
Replace: "MATCH (u:User) RETURN u" with "MATCH (u:User) RETURN u.name AS name, u.email AS email LIMIT 100" when only names and emails are needed.
