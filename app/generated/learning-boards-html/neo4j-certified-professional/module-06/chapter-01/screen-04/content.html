Driver responsibilities
A concise definition and common responsibilities of official drivers.
  • Connection & auth: open authenticated sockets to Neo4j using URIs and credentials.
  • Bolt protocol: efficient binary transport and streaming of records to the client.
  • Sessions & transactions: provide APIs to scope operations and handle commit/rollback.
  • Pooling & reuse: manage connection pools so your application can reuse sockets efficiently.
Key takeaway

Drivers abstract Bolt complexity and provide safety features like parameter binding and pooling that are essential for production apps.

Process visualization
Application call
Builds Cypher, supplies parameters, calls driver session or transaction API.
Driver and Bolt
Driver packages call into Bolt, binds parameters, streams results back as records.
Application processes records
Records expose node objects and properties for application logic to consume.
Misconception
Drivers do more than send strings; they bind parameters, manage socket reuse, and handle retries and streaming.
Pro-tip
Create one driver per application process and reuse it to leverage built-in pooling and avoid expensive connection setup.
