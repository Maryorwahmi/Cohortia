Module 6 › Chapter 6.2 › Tuning Pitfalls
Common Pitfalls
  • Over-mapping large subgraphs into a single object graph.
  • Relying on lazy loading without profiling.
  • Not using indexes for frequent filters.
Measure query counts and response times during typical use cases to decide whether to introduce eager fetches or custom queries.
Remedies
• Add eager fetching or repository methods that fetch relationships in one pass.
• Write raw Cypher for critical traversals so you control the plan.
• Add indexes for properties used in filters and match clauses.
Key Takeaway

OGMs speed development but require profiling and occasional manual queries to maintain production performance.
