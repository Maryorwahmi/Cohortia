Starter script

A starter product catalog is provided. Define Product and Category StructuredNode classes, add relationships, connect to the database, save nodes, and run simple queries with the nodes manager.

Practical tip
Use unique properties for natural keys like names to reduce accidental duplicates during development and tests.
