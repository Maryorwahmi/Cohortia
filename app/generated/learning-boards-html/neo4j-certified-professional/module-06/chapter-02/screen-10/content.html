Module 6 › Chapter 6.2 › Repository Pattern
When repositories are ideal
  • CRUD operations and simple traversals.
  • Code clarity and testability.
  • Rapid feature development for domain-driven code.
Keep your data access encapsulated so you can replace a repository method with a custom query later without changing service code.
Escape hatch: raw Cypher

For complex or performance-critical traversals, write a custom Cypher query in your repository or execute raw Cypher from the OGM to control the exact traversal and plan.

Pro Tip

Measure generated queries first. Use the escape hatch only when it yields a measurable improvement or necessary expressiveness.
