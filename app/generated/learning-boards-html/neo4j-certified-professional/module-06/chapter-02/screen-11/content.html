Module 6 › Chapter 6.2 › Product Catalog Lab
Step-by-step timeline
  1. Set config.DATABASE_URL to your Neo4j connection string and call db.set_connection.
  2. Define Product and Category StructuredNode classes with required properties and relationships.
  3. Save Category nodes such as Electronics and Books.
  4. Create and save Product nodes and connect them to categories and related products.
  5. Query: Product.nodes.filter(category__name="Electronics") and product.related_products.all().
Checkpoint
Confirm saved nodes appear in Neo4j Browser and that queries return expected related products.
Starter code snippet
# After class definitions and db.set_connection(...)
electronics = Category(name="Electronics").save()
laptop = Product(name="Laptop", price=1200.00).save()
laptop.category.connect(electronics)
# Query
for p in Product.nodes.filter(category__name="Electronics"):
  print(p.name, p.price)
