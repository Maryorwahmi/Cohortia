Module 6 › Chapter 6.2 › Learning Objectives
Practical skills
  • Map entities and relationships to classes in Java or Python.
  • Use repository interfaces and model methods for CRUD.
  • Write targeted custom queries when required.
Checks
Small tests to run locally: confirm a repository save/load cycle, observe when relationship collections trigger additional queries, and test transaction rollback.
Tip
Always profile generated queries before assuming the OGM handles complex traversals efficiently.
Key Takeaway

Use repository and model primitives for routine operations, but measure and correct for performance issues before release.
