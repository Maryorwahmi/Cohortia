Module 6 › Chapter 6.2 › Lazy vs Eager
Lazy Loading

Related nodes are fetched only when accessed. This reduces initial load and memory use but risks many small queries when iterating collections.

Misconception: lazy loading always improves performance. It only helps when related data is rarely accessed; when you need related data for many parents, it generates the N+1 pattern.
Eager Loading

Related nodes are fetched with the primary entity in a single query. This avoids N+1 but can increase memory and transfer size if relationships are large or seldom used.

Key Takeaway

Choose eager fetches when you'll access relationships for many parents; use lazy loading when relationships are rarely accessed.
