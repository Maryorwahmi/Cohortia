Routine operations
  1. Create: instantiate object and save or repository.save.
  2. Read: repository.findById or nodes.get / filter.
  3. Update: modify properties then save.
  4. Delete: repository.delete or node.delete.
For simple traversals, prefer repository-derived methods. For repeated access to relationships across many parents, specify eager fetching in your repository or write a custom query to fetch relationships in one pass.
Concrete example
Find products in a category using a repository method or Neomodel filter. If you will access related products for many categories, fetch them in a single query using a custom query to avoid many small round trips.
Common Mistake

Iterating many parent objects and accessing lazily loaded relationships can cause the N+1 query problem.
