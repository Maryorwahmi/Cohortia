Module 6 › Chapter 6.4 › CDC & Streams
Change Data Capture
Capture and publish every data change so other systems can subscribe without polling.
When to use CDC
  • When many downstream systems need a durable stream of changes.
  • When you want a single integration point rather than many custom triggers.
Misconception
CDC removes the need for downstream idempotency or retry logic — it does not. Consumers must still handle duplicates and ordering as required.
Practical note
Neo4j Streams can connect Neo4j to Kafka so graph changes are published as events. Use this for broad integration, analytics, search indexing, or replication workflows.
Key Takeaway

Choose CDC when you need a durable, system-wide stream of graph changes; choose triggers for isolated, immediate reactions.
