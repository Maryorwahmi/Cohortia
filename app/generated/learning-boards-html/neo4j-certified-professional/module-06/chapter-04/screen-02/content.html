Learning Objectives
Bloom: Learn → Understand → Apply → Master
Bloom progression
01. Explain real-time analytics
Describe how Neo4j processes connected data to produce instant insights and why this outperforms relational joins for some patterns.
VERIFIED COMPETENCY MILESTONE
02. Understand EDA
Explain event-driven design: producers, brokers, consumers, and how loose coupling improves responsiveness and scale.
VERIFIED COMPETENCY MILESTONE
03. Design event flows
Create a consumer that reads events, uses MERGE to create or update nodes and relationships, and commits changes safely.
VERIFIED COMPETENCY MILESTONE
04. React to graph changes
Use APOC triggers or CDC tools to publish graph events outward so other services can react to Neo4j changes.
VERIFIED COMPETENCY MILESTONE
