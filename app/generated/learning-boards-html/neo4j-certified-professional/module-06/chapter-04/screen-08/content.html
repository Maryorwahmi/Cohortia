APOC triggers overview
Define server-side procedures that run when nodes or relationships change to publish events or maintain derived data.
Example intent

Publish a UserCreated event whenever a new User node appears so other services can react immediately.

Caveat
Triggers execute inside the DB process; avoid long-running external calls inside triggers to prevent database impact.
Example trigger (conceptual)
CALL apoc.trigger.add(
  'user_created_event',
  'UNWIND apoc.trigger.nodesByLabel($createdNodes, "User") AS n '
  + 'WITH n CALL apoc.custom.sendEvent("user_created", {userId: n.id, username: n.username}) YIELD value RETURN value',
  {phase:'after'}
)
This trigger selects newly created User nodes and delegates publishing to a custom procedure. For wide distribution prefer a streaming connector.
