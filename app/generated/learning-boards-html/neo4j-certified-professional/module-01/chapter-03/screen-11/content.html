Module 2 › Chapter 1.3 › Connect Desktop to AuraDB
Connection fields
When adding a remote connection, Desktop requests the Bolt URI, username, and password. Enter the Bolt URI exactly as provided, set username to neo4j, and paste the auto-generated password from AuraDB.
Bolt URI: bolt://<host>:<port>
Username: neo4j
Password: (AuraDB auto-generated password)
Troubleshoot
  • Verify the Bolt URI host and port are copied correctly.
  • Confirm the password matches the AuraDB credential and has not been rotated.
  • Ensure you added a remote connection and not a local file reference.
Example
After adding the Bolt URI and credentials, open the remote connection and run MATCH (n) RETURN n LIMIT 5 to confirm the remote graph responds.
