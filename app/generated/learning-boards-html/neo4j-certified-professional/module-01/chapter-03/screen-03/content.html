Checklist
  1. Install Neo4j Desktop and launch the app.
  2. Create MyFirstGraphProject and add a DBMS. Choose latest stable version and set password.
  3. Start the DBMS and open the Neo4j Browser to run an initial query.
  4. Provision AuraDB free-tier, note Bolt URI, username, and password.
  5. Add a remote connection in Desktop using the Bolt URI and credentials to verify remote connectivity.
Risk & Safety
Never hardcode credentials. Use environment variables or a secrets manager for production. For the lab, store credentials temporarily and remove them when the session ends.
