Module 2 › Chapter 1.3 › First Cypher Query
Example
CREATE (a:Person {name: 'Alice'});
-- then
MATCH (p:Person {name: 'Alice'}) RETURN p;
Run the create query, then the match query. The Browser will return the created node and render a simple graph. This confirms the DBMS executes statements and the Browser can visualize a result set.
Why this matters
A successful round-trip proves your environment is healthy and ready for modeling. It also familiarizes you with Cypher's flow: create, match, return.
Misconception
Beginners sometimes think local create operations affect remote databases; confirm which instance you are connected to before running destructive commands.
Key Takeaway
Use simple create and match queries to validate connectivity and visualization in the Browser.
