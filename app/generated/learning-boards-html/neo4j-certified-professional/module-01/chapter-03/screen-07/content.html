Core Concept

DBMS is the running server

A DBMS instance stores your graph data and executes Cypher queries. The Neo4j Browser is a visualization and query client that connects to that server using the neo4j username and the password you set.

Quick check
Confirm the DBMS shows a running indicator before opening the Browser.
Common mistake
Trying to open the Browser without starting the DBMS is the most frequent connectivity error.
Example connection
Username: neo4j
Password: (the value you set during DBMS creation)
Browser connects via HTTP/WebSocket to local DBMS when running.
Key Takeaway
Always start the DBMS and remember the neo4j password to permit browser access and client connections.
