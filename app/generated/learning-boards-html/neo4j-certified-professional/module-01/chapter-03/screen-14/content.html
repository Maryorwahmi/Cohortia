Module 2 › Chapter 1.3 › Key Concepts
Neo4j Desktop
A local app for projects and running multiple DBMS instances for development and experimentation.
Neo4j AuraDB
A managed cloud service that provides hosting, backups, scaling, and a Bolt URI for connections.
Credentials & Bolt URI
AuraDB provides a Bolt URI, username, and password. Keep them secure and use environment variables for applications.
Summary
Use Desktop for fast iteration and AuraDB for managed hosting. Always start local DBMS instances before opening the browser, and treat AuraDB credentials as sensitive secrets.
