Module 2 › Chapter 1.3 › Prototype → Production
Workflow
Prototype
Model in Desktop, iterate quickly, and run local tests without cloud cost.
Validate
Provision AuraDB free-tier to validate remote connectivity and multi-user behavior.
Deploy
Move to a managed AuraDB configuration for production reliability and automated operations.
Example
Prototype schema locally, then provision AuraDB to test client integrations and concurrency behavior before promoting to production.
Misconception
Believing migration requires major code rewrites; often only connection configuration changes are necessary if the schema is compatible.
Key Takeaway

Use Desktop for fast exploration and AuraDB to validate and host stable, collaborative, or production systems. Update connection handling and secure credentials when moving between environments.
