Create Project

Organize your experiments

Create a descriptive project name like MyFirstGraphProject to group related DBMS instances and assets. Projects help you switch context quickly.

Mnemonic
Think: Project = folder; DBMS = server inside that folder.
Add DBMS

Choose version and set password

Select the latest stable Neo4j version for learning. When prompted, set a strong password for the default neo4j user. Keep this password secure and retrievable.
Project: MyFirstGraphProject
DBMS: neo4j-stable
Password: (your chosen password)

Key Takeaway
Projects keep related DBMSs together, enabling organized experimentation on one machine.
