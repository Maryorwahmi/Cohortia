Set Up Your Neo4j Environment

Prepare a local sandbox with Neo4j Desktop and provision a managed AuraDB instance in the cloud. Learn when to use each and how to connect them.

In this lesson

Install Desktop, create a local DBMS, use the Neo4j Browser, and provision AuraDB with secure connections.

Why it matters

A reliable environment reduces friction when designing graph models and testing queries before deployment.

Explore Key Topics
Neo4j Desktop
Local projects and multiple DBMS instances for fast iteration and offline work.
Neo4j Browser
Run Cypher queries and visualize graphs for exploration and debugging.
AuraDB
A managed cloud instance with a Bolt URI, credentials, and reduced operational overhead.
Visual Guide
Local sandbox
Neo4j Desktop manages projects and DBMS instances.
Cloud instance
AuraDB provides Bolt URI and credentials for remote connections.
Connections
Use credentials securely; never hardcode in source code for production.
Key Takeaway

Use Desktop for local experimentation and AuraDB when you want managed hosting and scalability; connect them when you need a smooth path from prototype to deployment.
