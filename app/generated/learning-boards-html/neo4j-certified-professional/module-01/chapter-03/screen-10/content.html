Module 2 › Chapter 1.3 › Provision AuraDB
Steps
  1. Sign up or log in to the Neo4j console and choose Create new instance.
  2. Select cloud provider and region as prompted for the free tier.
  3. Wait for provisioning to complete and copy the Bolt URI, username, and auto-generated password.
  4. Open the built-in browser to verify connectivity or add a remote connection in Desktop.
Concrete example
After creation you see Bolt URI like bolt://<host>:<port> — copy it for client configuration or Desktop remote connection.
Secure record
Store the Bolt URI and password securely. For production, do not commit the password to version control. Use environment variables or a secrets manager instead.
Warning
Do not hardcode credentials into application source. This exposes your database and is difficult to rotate securely.
