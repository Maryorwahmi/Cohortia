Module 2 › Chapter 1.3 › AuraDB Overview
Core benefits
  • Automated backups and patching reduce operational overhead.
  • Built-in scaling and high availability suitable for production workloads.
  • Free tier available for learning and small projects.
Concrete example
Provision an AuraDB instance to host a staging database that teammates can access from different locations.
Connection details
AuraDB provides a Bolt URI in the form bolt://<host>:<port>, along with username neo4j and an auto-generated password. Use these to connect from clients or to add a remote connection in Desktop.
Misconception
AuraDB removes the need for thoughtful data modeling or access control. You still design schema and manage users appropriately.
