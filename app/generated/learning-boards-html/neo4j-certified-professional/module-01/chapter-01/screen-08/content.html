Graph Fundamentals

Nodes: The Entities of Your Graph

Entities like people, products, or locations become nodes.

What is a Node?

  • •A fundamental data entity in a graph.
  • •Represents real-world objects (e.g., Person, Company, Product).
  • •Can have one or more Labels for categorization.
  • •Stores descriptive data as Properties (key-value pairs).
Example Node: Person

A node with label :Person and properties {name: 'Alice', age: 30, city: 'New York'}.

Node Structure
:Person
Alice
name: 'Alice'
age: 30
city: 'New York'
Key Takeaway

Nodes are the core entities, providing a flexible way to represent data points with labels for categorization and properties for detailed attributes.
