Definition

Nodes: The Entities of Your Graph

Categorizing data points with labels for flexible modeling.

  • Entities: Nodes represent distinct items or concepts in your data, like a 'Person' or a 'Movie'.

  • Labels: Named tags that categorize nodes, enabling efficient grouping and querying.

  • Multiple Labels: A single node can have several labels, allowing for flexible, multi-faceted categorization (e.g., Person and Director).

Key Takeaway

Labels are essential for organizing nodes and optimizing query performance by grouping similar entities.
