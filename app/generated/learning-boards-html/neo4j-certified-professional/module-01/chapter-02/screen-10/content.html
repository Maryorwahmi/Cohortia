Graph Modeling: Defining Nodes and Labels

Applying core concepts to a movie database scenario.

Scenario: Movie Database

Represent Actors, Directors (both Persons), and Movies. Tom Hanks acted in "Forrest Gump", Robert Zemeckis directed "Forrest Gump".

Step 1: Nodes and Labels
  • 1

    Identify entities: Tom Hanks, Robert Zemeckis, Forrest Gump.

  • 2

    Assign labels: Person, Actor, Director, Movie.

  • 3

    Example: (tomHanks:Person:Actor {name: 'Tom Hanks'})

Key Takeaway

Careful selection of nodes and labels is the first step to a well-structured and queryable graph.

Conceptual Sketch: Nodes
Node

(tomHanks:Person:Actor {name: 'Tom Hanks'})

Node

(robertZemeckis:Person:Director {name: 'Robert Zemeckis'})

Node

(forrestGump:Movie {title: 'Forrest Gump', releaseYear: 1994})

Common Pitfall

Over-segmenting nodes into too many distinct types instead of using multiple labels for shared entities.
