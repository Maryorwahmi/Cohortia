Properties: Adding Detail to Your Graph

Enriching nodes and relationships with key-value pairs.

  • Key-Value Pairs: Properties store descriptive data, like name: 'Alice' or releaseYear: 1999.

  • On Nodes: Add details to entities (e.g., a Person node with age: 30).

  • On Relationships: Store details about the connection itself (e.g., an ACTED_IN relationship with role: 'Neo').

Key Takeaway

Properties provide crucial context and descriptive data, making your graph model rich and informative.

Property Examples
Node Properties

Person Node:

  • name: 'Alice'
  • age: 30
  • city: 'New York'
Relationship Properties

ACTED_IN Relationship:

  • role: 'Neo'
  • scenes: ['lobby', 'dojo']
Pro-Tip

If a property becomes too complex (e.g., a nested object), consider modeling it as a separate node.
