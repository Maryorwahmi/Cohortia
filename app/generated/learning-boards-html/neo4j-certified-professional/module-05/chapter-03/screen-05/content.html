Module 5.3›Chapter 5.3›Creating New Users
Cypher Command
CREATE USER alice SET PASSWORD 'secure_password_123' CHANGE NOT REQUIRED;
Creates a new user 'alice' with an initial password.
SET PASSWORD

Assigns the initial password for the new user. Always use strong, unique passwords.

CHANGE NOT REQUIRED

Optional clause. If omitted, the user is forced to change their password on first login (recommended for production).

Purpose

Accountability & Control

Unique user accounts enable auditing of actions and precise control over who can access and modify data.

Pro-Tip

Enforce Strong Passwords

Implement policies for password complexity, length, and regular rotation to enhance security and prevent brute-force attacks.

Key Takeaway

Always create unique user accounts and enforce strong password policies to maintain accountability and secure your Neo4j database.
