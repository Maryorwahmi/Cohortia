Built-in Authentication

Internal User Management

Neo4j's default authentication uses usernames and passwords stored directly within the database.

Simple & Direct
Key Takeaway

Authentication verifies user identity; Neo4j supports both internal password storage and external enterprise integrations for flexibility.

External Authentication

LDAP/Kerberos Integration

For enterprise environments, integrate with external identity providers like LDAP or Kerberos for centralized user management and single sign-on.

Enterprise SSO
Common Misconception

Authentication only confirms identity; it does not define what actions the user is permitted to perform. That's authorization's role.
