Cypher Commands
GRANT TRAVERSE ON GRAPH neo4j TO my_analyst_role;
GRANT READ ON GRAPH neo4j TO my_analyst_role;
Grants read and traverse privileges on the 'neo4j' graph to 'my_analyst_role'.
TRAVERSE Privilege

Allows a user or role to navigate the graph structure, essential for most read operations.

READ Privilege

Enables a user or role to read data from nodes, relationships, and their properties.

Definition

Access Permissions

Authorization defines what an authenticated user or role is allowed to do within the database, including specific operations and data access.

Granularity

Fine-Grained Control

Neo4j allows privileges to be set on databases, graph elements (nodes, relationships), properties, and operations.

Key Takeaway

Authorization controls specific actions within Neo4j, using `GRANT` to define precise permissions on graph elements and operations for users and roles.
