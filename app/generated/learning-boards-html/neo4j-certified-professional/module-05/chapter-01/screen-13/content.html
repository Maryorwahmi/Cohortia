Simulating a Backup and Restore Workflow

A guided walkthrough of data protection.

1. Start Neo4j & Create Data

Ensure Neo4j is running and add some sample graph data.

2. Perform Database Dump

Use `neo4j-admin dump` to create a backup file of your current database.

3. Simulate Data Loss & Stop

Delete some data, then stop the Neo4j instance.

4. Restore Database

Use `neo4j-admin restore` to recover your data from the dump file.

5. Start & Verify Data

Restart Neo4j and confirm that all your data has been successfully restored.

Key Takeaway

This hands-on workflow demonstrates the full cycle of data protection, from backup creation to successful recovery and verification.
