Creating Database Dumps

Using `neo4j-admin dump` for portable snapshots.

Command Breakdown
  • `--database`: Specifies the database to dump (e.g., `neo4j`).
  • `--to`: Defines the output path and filename for the dump file.
  • Dynamic Naming: Use `$(date +%Y%m%d)` to include the current date in the filename for better organization.
Key Takeaway

`neo4j-admin dump` creates consistent, portable database snapshots, ideal for backups and migrations, and can be run online.

Example: Database Dump
neo4j-admin dump \
  --database=neo4j \
  --to=/path/to/backup/neo4j_backup_$(date +%Y%m%d).dump
Pro-Tip

Always ensure the `--to` path has sufficient disk space and appropriate permissions for the Neo4j user.
