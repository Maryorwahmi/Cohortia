Disaster Recovery

Restoring Your Neo4j Database

Bringing your data back with `neo4j-admin restore`.

Command Essentials
  • `--from`: Specifies the path to the dump file to be restored.
  • `--database`: Indicates the target database name for the restore.
  • `--force`: Overwrites an existing database; use with extreme caution.
Safety Note

Always have a separate, recent backup of the current database state before performing any restore operation, especially with `--force`.

Example: Database Restore
# Stop the Neo4j instance first
neo4j stop

# Restore the database
neo4j-admin restore \
  --from=/path/to/backup/neo4j_backup_20231027.dump \
  --database=neo4j \
  --force

# Start the Neo4j instance after restoration
neo4j start
Pro-Tip

Test your restore process periodically on a non-production environment to ensure backups are valid and recoverable.
