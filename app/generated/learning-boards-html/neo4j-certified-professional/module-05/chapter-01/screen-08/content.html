Backup Methods

Simple Offline Backups

Copying data files with database downtime.

Step 1: Stop Instance

Completely shut down the Neo4j database server using `neo4j stop`.

Step 2: Copy Data Files

Copy the entire `data/databases/neo4j` directory to a secure, separate location.

Step 3: Restart (Optional)

Restart the Neo4j instance if needed for continued operation.

Drawback

This method incurs significant downtime, making it unsuitable for high-availability production systems.

Key Takeaway

Offline backups are simple but require full database shutdown, limiting their use to non-critical environments.
