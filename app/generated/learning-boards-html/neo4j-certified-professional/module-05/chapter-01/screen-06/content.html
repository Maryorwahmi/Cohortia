Performance Tuning

Essential `neo4j.conf` Settings

Optimizing network and memory allocation.

Key Parameters
  • Network: `dbms.connector.bolt.listen_address` controls Bolt protocol binding (e.g., `0.0.0.0:7687`).
  • Memory: `dbms.memory.heap.initial_size` and `dbms.memory.heap.max_size` manage JVM heap.
Common Mistake

Forgetting to restart the Neo4j instance after modifying `neo4j.conf` will prevent new settings from taking effect.

`neo4j.conf` Snippet
# Bolt connector address
dbms.connector.bolt.listen_address=0.0.0.0:7687

# Initial Java heap size
dbms.memory.heap.initial_size=512m

# Maximum Java heap size
dbms.memory.heap.max_size=2g

# Page cache memory allocation
dbms.memory.pagecache.size=2g
Pro-Tip

Align memory settings with your server's available RAM and expected workload to avoid resource contention or out-of-memory errors.
