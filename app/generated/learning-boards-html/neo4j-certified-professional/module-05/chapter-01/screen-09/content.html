Online Backup Strategies

Minimizing downtime with Enterprise features and `neo4j-admin dump`.

`neo4j-admin backup` (Enterprise)

  • Zero Downtime: Creates consistent backups while the database is running.
  • Consistency: Leverages transaction logs for data integrity.
  • Ideal For: High-availability production environments.

`neo4j-admin dump` (All Editions)

  • Portable Snapshot: Creates a compact dump file of the database.
  • Online Capable: Can be run on a live database, but takes a point-in-time snapshot.
  • Versatile: Good for logical backups and migrations across environments.
Key Takeaway

For production, prioritize online backup methods like `neo4j-admin backup` (Enterprise) or `neo4j-admin dump` to minimize service interruption.
