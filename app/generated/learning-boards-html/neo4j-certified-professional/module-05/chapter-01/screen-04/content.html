Core Concept

Controlling Your Neo4j Instance

Essential commands for managing server operations.

Key Operations
  • Start: Initiates the Neo4j server process, making the database accessible.
  • Stop: Gracefully shuts down the database, committing transactions and closing files.
  • Status: Provides quick feedback on whether the Neo4j server is currently active.
Key Takeaway

Mastering `start`, `stop`, and `status` commands is fundamental for daily Neo4j server management and ensuring data integrity.

Terminal Commands
# Start the Neo4j database server
neo4j start

# Check the current status of the Neo4j instance
neo4j status

# Gracefully stop the Neo4j database server
neo4j stop
Pro-Tip

Always use `neo4j stop` for a clean shutdown to prevent data corruption. Avoid force-killing processes.
