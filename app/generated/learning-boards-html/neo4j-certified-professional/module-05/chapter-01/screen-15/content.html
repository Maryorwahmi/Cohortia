Key Concepts

Essential terms and tools from this chapter.

Online Backup

A backup method that can be performed while the database is running, ensuring minimal downtime (Enterprise Edition).

`neo4j-admin dump`

A utility to create a portable, consistent snapshot of a Neo4j database into a single file.

`neo4j-admin restore`

A utility to recreate a Neo4j database from a previously created dump file.

Summary Takeaway

Online backups, `neo4j-admin` dump/restore, and transaction logs are key for advanced data protection and recovery strategies.
