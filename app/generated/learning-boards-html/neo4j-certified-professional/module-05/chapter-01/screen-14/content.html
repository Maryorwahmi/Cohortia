Key Concepts

Essential terms and tools from this chapter.

`neo4j.conf`

The primary configuration file for a Neo4j instance, controlling various operational parameters.

`neo4j-admin`

A command-line utility for database administration tasks like dumping, restoring, and managing indexes.

Offline Backup

A backup method requiring the database to be stopped, typically involving copying data files directly.

Summary Takeaway

Effective Neo4j management relies on understanding configuration, administrative tools, and the implications of different backup approaches.
