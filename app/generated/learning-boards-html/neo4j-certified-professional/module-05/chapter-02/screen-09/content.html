Strategic Indexing

Smart Indexing: Avoiding Common Mistakes

Balancing read performance with write overhead.

Indexing Best Practices

  • •Analyze Query Patterns: Use PROFILE to understand which properties are frequently accessed.
  • •Index Frequently Used Properties: Focus on properties in WHERE, MATCH, and ORDER BY clauses.
  • •Monitor Write Performance: Be aware of the impact of new indexes on data modification operations.
Key Takeaway

Create indexes strategically on frequently queried properties, avoiding excessive indexing that can degrade write performance.

Common Indexing Pitfalls

  • •Too Many Indexes: Each index adds overhead to write operations, slowing down data creation and updates.
  • •Indexing Rarely Queried Properties: Wastes resources and adds unnecessary write overhead.
  • •Indexing Low Cardinality Properties: Properties with few distinct values (e.g., boolean flags) often don't benefit much from indexing.
Pro Tip

Regularly review your indexes and remove any that are not actively being used or are causing more overhead than benefit.
