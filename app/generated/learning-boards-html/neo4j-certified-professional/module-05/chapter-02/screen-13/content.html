Key Concepts: Part 1

Essential terms for Neo4j performance tuning.

EXPLAIN

A Cypher keyword used to preview the execution plan of a query without running it, showing the intended steps.

PROFILE

A Cypher keyword used to execute a query and then display its actual execution plan along with runtime statistics.

Indexes

Data structures (B-tree, Composite, Full-text) that speed up data retrieval by allowing Neo4j to quickly locate nodes or relationships.

Summary Takeaway

Mastering EXPLAIN, PROFILE, and various index types is fundamental for diagnosing and accelerating Neo4j query performance.
