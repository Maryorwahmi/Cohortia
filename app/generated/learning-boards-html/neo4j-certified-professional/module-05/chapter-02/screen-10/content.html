Memory Management

The Power of Page Cache

Leveraging RAM for faster data access.

What is the Page Cache?

  • •RAM-based Storage: A dedicated memory region in RAM for frequently accessed graph data.
  • •Data Stored: Includes nodes, relationships, and their properties.
  • •Primary Benefit: Significantly reduces disk I/O, as data is retrieved much faster from RAM.
Key Takeaway

The page cache stores frequently accessed graph data in RAM, drastically reducing disk I/O and improving read performance.

Configuring and Monitoring Page Cache

Configuration

Set dbms.memory.pagecache.size in neo4j.conf. Allocate as much RAM as possible to hold your active dataset.

Cache Hit Ratio

A metric indicating the percentage of data requests served from the page cache. Aim for 90-95% or higher.

Common Mistake

Under-allocating page cache size, leading to frequent disk reads and degraded performance, even with ample system RAM.
