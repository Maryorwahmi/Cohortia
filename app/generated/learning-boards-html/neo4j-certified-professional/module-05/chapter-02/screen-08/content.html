Specialized Indexes

Beyond Basic: Composite and Full-Text Indexes

Tailoring indexes for complex query patterns.

Creating a Composite Index:
CREATE INDEX FOR (p:Person) ON (p.firstName, p.lastName);
Creating a Full-Text Index:
CALL db.index.fulltext.createNodeIndex(
  'namesAndBios', 
  ['Person', 'Company'], 
  ['name', 'bio']
);
Querying a Full-Text Index:
CALL db.index.fulltext.queryNodes(
  'namesAndBios', 
  'Alice OR Bob'
);
Key Takeaway

Composite indexes optimize multi-property queries, while full-text indexes enable efficient complex text searches.

When to Use Each Index Type

Composite Indexes

For queries filtering on multiple properties (e.g., WHERE p.firstName = 'John' AND p.lastName = 'Doe').

Full-Text Indexes

For complex text searches, keyword matching, or fuzzy string comparisons across multiple properties.

Misconception Check

Don't use a B-tree index for full-text search. It won't provide the necessary performance benefits for complex text patterns.
