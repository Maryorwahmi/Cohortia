Module 5 › Chapter 5.4 › Hands-on: 3-core
Steps
  1. Create directories for core1, core2, core3 and their conf folders.
  2. Write neo4j.conf for each with dbms.mode=CORE and identical initial_discovery_members.
  3. Start each instance and confirm leader election and cluster health in logs.
  4. Perform a write on the leader and verify followers have replicated it.
Verification
Check logs for discovery success and leader election, and confirm transaction replication across cores.

Common issue
Firewall or network rules blocking discovery ports stops cluster formation.
Pro tip
Test locally with distinct ports, then move to separate machines with proper advertised addresses for production.
Reflection
After simulating, ask: did the cluster elect a leader quickly and did replication keep up with writes?
