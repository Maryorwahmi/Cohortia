Quorum calculation

Majority rules

Quorum ensures a majority of cores agree before committing a transaction. Losing quorum prevents writes to avoid data divergence.

Example
Five-core cluster needs three cores for quorum. If only two are reachable writes are blocked.
Operational checklist
  • Use an odd number of cores.
  • Monitor node reachability and cluster health.
  • Design client retries to handle temporary write unavailability.
Misconception
Quorum loss means data is lost. In reality writes are blocked to preserve the safety of existing data until quorum returns.
Key Takeaway

Quorum protects consistency; plan topology and monitoring so quorum is preserved under common failure modes.
