Learning Objectives

Four practical skills to choose and design scaling strategies for Neo4j

Bloom: Learn → Understand → Apply → Master
01
Differentiate scaling approaches

Explain vertical vs horizontal scaling and when each is appropriate. A mnemonic: 'Scale up until you hit a wall, then scale out.'

VERIFIED COMPETENCY MILESTONE
02
Use read replicas effectively

Describe how adding read replicas to a Causal Cluster distributes read load while writes remain on cores. Use replicas when reads dominate.

VERIFIED COMPETENCY MILESTONE
03
Design with Neo4j Fabric

Explain Fabric's shard federation model and how partitioning decisions affect cross-shard query overhead. Think regions, tenants, or logical domains.

VERIFIED COMPETENCY MILESTONE
04
Evaluate cloud deployment choices

Identify benefits and trade-offs of managed services like Aura versus self-managed cloud deployments on Azure, AWS, or GCP.
