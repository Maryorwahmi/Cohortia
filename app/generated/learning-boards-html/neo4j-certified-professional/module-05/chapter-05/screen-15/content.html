Module 6 › Chapter 5.5 › Key Concepts
Vertical Scaling

Increase CPU, RAM, and storage speed to remove bottlenecks on a single server.

Read Replicas

Add replicas to a Causal Cluster to scale read throughput while cores handle writes.

Neo4j Fabric

Federates queries across multiple databases or clusters when a single cluster is insufficient.

Summary takeaway
Measure first, scale simply, and choose partitioning only when necessary. Match your architecture to workload demands and operational capacity.
