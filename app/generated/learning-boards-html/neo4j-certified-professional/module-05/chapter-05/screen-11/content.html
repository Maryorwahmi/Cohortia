Workload factors

Five dimensions shape scaling choices and architecture decisions.

Data Volume
How large is the graph now and how quickly will it grow?
Query Complexity
Are queries simple lookups or deep traversals that need memory and CPU?
Read/Write Ratio
High read ratios favor replicas; heavy writes require core capacity planning.
Concurrency
Estimate concurrent users or services to scale replicas or tune connection pools accordingly.
Latency Requirements
If low latency is key, minimize cross-shard or cross-region queries. Locality matters.
Key Takeaway

Use this checklist to make deliberate scaling choices: profile, plan, scale vertically or with replicas, and reserve Fabric for cross-cluster needs.
