Properties: The Data Attributes

Key-value pairs that describe nodes and relationships

PROPERTY
Key: Value
name: 'Alice'
age: 30
since: 2020

What are Properties?

Properties are key-value pairs that store descriptive attributes for both nodes and relationships. They provide the actual data content.

Node Properties Example

For a Person node: name: 'Alice', age: 30, city: 'New York'. These describe the person entity.

Relationship Properties Example

For a FRIENDS_WITH relationship: since: 2020. This describes the friendship itself.

Key Takeaway

Properties are essential key-value pairs that add rich, descriptive data to both nodes and relationships in your graph model.
