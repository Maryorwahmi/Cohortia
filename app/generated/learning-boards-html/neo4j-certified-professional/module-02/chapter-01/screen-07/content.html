What are Relationships?

Relationships are the connections between nodes, defining how entities relate. They are first-class citizens in a graph, explicitly defined and navigable.

Directed Flow

Every relationship has a direction, flowing from a start node to an end node. This directionality is crucial for conveying semantic meaning (e.g., Alice FOLLOWS Bob).

Relationship Types

Each relationship has a type (e.g., FRIENDS_WITH, ACTED_IN) that describes its nature. This type adds semantic meaning and makes queries intuitive.

Key Takeaway

Relationships are directed and typed connections that explicitly link nodes, forming the interconnected fabric of your graph data.
