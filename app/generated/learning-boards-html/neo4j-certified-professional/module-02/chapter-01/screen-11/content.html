Cypher CREATE: Your First Graph Elements

Using Cypher to define nodes, relationships, and properties

// Create a node for a person
CREATE (tom:Person {name: 'Tom Hanks', born: 1956})

// Create a node for a movie
CREATE (forrest:Movie {title: 'Forrest Gump', released: 1994, tagline: 'Life is like a box of chocolates...'})

Node Variables & Labels

tom and forrest are variables. :Person and :Movie are labels, categorizing the nodes.

Defining Properties

Properties are key-value pairs within curly braces, like name: 'Tom Hanks', providing descriptive attributes for the node.

Intuitive Syntax

Cypher's syntax is designed to be readable and intuitive, closely resembling how you might draw a graph on a whiteboard.

Key Takeaway

The CREATE clause in Cypher is used to define nodes, assigning them labels and descriptive properties in a clear, declarative way.
