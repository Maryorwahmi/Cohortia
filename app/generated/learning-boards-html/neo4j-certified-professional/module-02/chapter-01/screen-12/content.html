Cypher CREATE: Connecting Entities

Adding relationships with types, direction, and properties

// Create a relationship between them, with a property
CREATE (tom)-[:ACTED_IN {roles: ['Forrest']}]->(forrest)

// Create another person and a relationship
CREATE (robert:Person {name: 'Robert Zemeckis', born: 1951})
CREATE (robert)-[:DIRECTED]->(forrest)

Relationship Syntax

Relationships are defined with -[]->, indicating direction. :ACTED_IN is the relationship type.

Relationship Properties

Just like nodes, relationships can have properties, such as roles: ['Forrest'], adding detail to the connection.

Directionality Matters

The direction of the arrow (->) is crucial, showing the flow from the start node to the end node (e.g., Tom ACTED_IN Forrest Gump).

Key Takeaway

Cypher's CREATE clause allows you to define relationships with types, direction, and properties, building rich, navigable connections between nodes.
