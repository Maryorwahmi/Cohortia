Data Strategy
Integrating Time-Series Data with Graph Entities
Connect time-based events to entities without embedding timestamps as properties.

Anti-Pattern: Embedded Timestamps

Storing a list of timestamps directly as a property on a node (e.g., User {loginTimes: [t1, t2, t3]}). This becomes inefficient for frequent updates or complex temporal queries.

Inefficient for querying ranges or sequences.

Best Practice: Event Nodes

Create dedicated Event nodes with a timestamp property, connected to relevant entities. Example: (User)-[:PERFORMED]->(Action)-[:AT]->(Event {timestamp: ...}).

Enables efficient temporal queries and clear modeling.
Querying Benefits

Easily find events within a specific time range or analyze sequences of actions performed by an entity.

Key Takeaway

Use event nodes to model time-series data, ensuring semantic clarity and query performance.
