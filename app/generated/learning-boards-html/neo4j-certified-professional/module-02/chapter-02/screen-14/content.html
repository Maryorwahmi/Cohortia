Key Concepts

Reinforcing Core Graph Model Enhancements

Label

A named tag used to group nodes into categories, enabling efficient querying and type-specific operations.

Relationship Type

A named category for relationships, defining the semantic meaning of the connection between nodes.

Index

A data structure that speeds up data retrieval operations, typically created on labels and properties to accelerate node lookups.

Chapter Summary

Labels, relationship types, and indexes are fundamental for structuring your graph, adding semantic meaning, and optimizing query performance.
