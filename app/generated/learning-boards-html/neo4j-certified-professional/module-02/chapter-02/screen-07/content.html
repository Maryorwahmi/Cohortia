Accelerating Queries with Indexes

Speeding Up Data Retrieval in Neo4j

What are Indexes?

Data structures that speed up data retrieval by allowing direct lookup of nodes based on property values.

How They Work

Indexes allow Neo4j to quickly locate nodes without scanning the entire dataset, similar to a book's index.

Where to Index

Typically created on labels and properties, especially those frequently used in MATCH or WHERE clauses.

Key Takeaway

Indexes are crucial for efficient query performance, especially in large graphs, by enabling direct data lookups.

MATCH (p:Person)
WHERE p.name = 'Tom Hanks'
RETURN p.born;

Without an index, this query would scan all :Person nodes.

CREATE INDEX FOR (p:Person) ON (p.name);

This index makes the previous query significantly faster.

Example: Indexed Lookup

An index on Person.name allows Neo4j to jump directly to 'Tom Hanks' without checking every person.

Misconception

Indexes speed up reads but can slow down writes. Only index properties frequently used for lookups.
