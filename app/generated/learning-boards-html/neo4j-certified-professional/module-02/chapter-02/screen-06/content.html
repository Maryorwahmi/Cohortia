Defining Relationship Types

Adding Semantic Meaning to Graph Connections

1. Categorize Connections

Assign a specific type to each relationship to define its nature.

2. Provide Semantic Meaning

Clearly communicate the 'why' and 'how' of relationships (e.g., ACTED_IN, DIRECTED).

3. Enhance Query Performance

Allow Cypher to efficiently traverse specific connection types, speeding up queries.

Example: Specific Traversal

MATCH (p:Person)-[:ACTED_IN]->(m:Movie) efficiently finds actors in movies.

Common Mistake

Avoid generic types like :RELATED_TO or encoding too much info into the type itself. Use properties for details.

Key Takeaway

Well-defined relationship types are crucial for a clear, navigable, and performant graph model.
