Practical Application

Applying Enhancements: Academic Network

Hands-on Scenario for Labels, Indexes, and Constraints

Scenario Goal

Extend an academic network model to ensure unique student IDs, unique course codes, required course titles, and fast person name lookups.

Key Actions
  • Create unique constraints for studentId and courseCode.
  • Create an existence constraint for Course.title.
  • Create an index on Person.name.
Key Takeaway

Applying these enhancements ensures data integrity and improves query performance in a real-world academic graph model.

// Create a unique constraint for student IDs
CREATE CONSTRAINT FOR (s:Person) REQUIRE s.studentId IS UNIQUE;

// Create a unique constraint for course codes
CREATE CONSTRAINT FOR (c:Course) REQUIRE c.courseCode IS UNIQUE;

// Create a property existence constraint for Course titles
CREATE CONSTRAINT FOR (c:Course) REQUIRE c.title IS NOT NULL;

// Create an index on Person names
CREATE INDEX FOR (p:Person) ON (p.name);

Test Your Constraints

Attempt to create a duplicate student ID or a course without a title to observe constraint violations.

Verify Your Work

Use CALL db.indexes(); and CALL db.constraints(); to confirm your creations.
