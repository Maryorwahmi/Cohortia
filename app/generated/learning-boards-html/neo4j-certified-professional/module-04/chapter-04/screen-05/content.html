Core Concept

The Precision of PROFILE

Analyzing Actual Query Performance

What it Provides
  • Executes the query and captures real-time metrics.
  • Includes `db hits`, `rows` processed, and `time` for each operation.
  • Crucial for verifying `EXPLAIN` predictions.
  • Identifies actual runtime bottlenecks.
Analogy

If EXPLAIN is the blueprint, PROFILE is the construction site supervisor's report. It tells you exactly how much material was used, how many workers were involved, and how long each phase actually took.

Key Takeaway

Always use PROFILE to confirm the real-world performance of your queries and validate your optimization strategies.

Cypher Query (PROFILE)
PROFILE MATCH (p:Person {name: 'Alice'}) RETURN p.bornIn
