Bottleneck 2: Cartesian Products

Connecting Disconnected `MATCH` Clauses

Problem Identification
  • `CartesianProduct` operation in the query plan.
  • Occurs when independent `MATCH` clauses lack common variables.
Solution

Ensure `MATCH` clauses are connected by relationships or explicitly pass variables using `WITH` to avoid implicit joins.

Example

Instead of `MATCH (a:Person) MATCH (b:Movie)`, use `MATCH (a:Person)-[:ACTED_IN]->(b:Movie)` if a relationship is intended.

Cypher Query: Bad vs. Good
// Bad: Implicit Cartesian Product
PROFILE MATCH (a:Person)
MATCH (b:Movie)
RETURN a.name, b.title

// Output shows CartesianProduct

// Good: Explicit connection (if intended)
PROFILE MATCH (a:Person)-[:ACTED_IN]->(b:Movie)
RETURN a.name, b.title

// Output avoids CartesianProduct
Connecting `MATCH` clauses with relationships eliminates the costly `CartesianProduct`.
