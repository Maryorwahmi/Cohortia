Bottleneck 1: Full Scans

Eliminating `NodeByLabelScan` and `AllNodesScan`

Problem Identification
  • `NodeByLabelScan` or `AllNodesScan` processing many rows.
  • Indicates iterating over a large portion of the database.
Solution

Create appropriate indexes on properties used in `WHERE` clauses or `MATCH` patterns. Example: `CREATE INDEX FOR (n:Label) ON (n.property)`.

Why it Matters

Indexes transform slow, linear scans into fast, logarithmic lookups, drastically improving query response times, especially on large datasets.

Cypher Query & Index Creation
// Inefficient query without index
PROFILE MATCH (p:Product)
WHERE p.category = 'Electronics'
RETURN p.name

// Output shows NodeByLabelScan for Product

// Create an index to optimize
CREATE INDEX FOR (n:Product) ON (n.category)

// Re-run query, output now shows NodeIndexSeek
PROFILE MATCH (p:Product)
WHERE p.category = 'Electronics'
RETURN p.name
Creating an index on `Product.category` will convert the `NodeByLabelScan` into a more efficient `NodeIndexSeek`.
