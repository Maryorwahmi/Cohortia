Efficient Lookups: Index Seek vs. Scans

Understanding Node and Relationship Operations

Index Seek

Direct, efficient lookup using an index (e.g., `NodeIndexSeek`).

Full Scan

Iterates over all nodes/relationships (e.g., `NodeByLabelScan` without index).

Example

If you query `(p:Person {name: 'Alice'})`, an index on `Person.name` leads to `NodeIndexSeek`. Without it, you'll see `NodeByLabelScan` for all `Person` nodes.

Key Takeaway

Always aim for index seeks. If you see scans on large datasets, consider creating an index to drastically improve performance.

Cypher Query & Plan Comparison
// Querying without an index
PROFILE MATCH (p:Person {name: 'Alice'}) RETURN p.bornIn

// Output might show:
// +-------------------+
// | NodeByLabelScan   |
// +-------------------+

// After creating an index:
CREATE INDEX FOR (n:Person) ON (n.name)

// Re-running the query, output might show:
// +-------------------+
// | NodeIndexSeek     |
// +-------------------+
Observe the change from 'NodeByLabelScan' to 'NodeIndexSeek' after index creation.
