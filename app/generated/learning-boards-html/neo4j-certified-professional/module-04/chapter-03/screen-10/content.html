Data Quality

Ensuring Data Presence with Existence Constraints

Requiring specific properties to exist on nodes and relationships.

Node Property Existence

Ensures that a specific property must always exist (not be null) on nodes of a certain label.

Relationship Property Existence

Ensures a specific property must exist (not be null) on relationships of a certain type.

Key Takeaway

Existence constraints enforce that critical properties are always present on nodes or relationships, improving data quality and reliability.

// Node Property Existence ConstraintCREATE CONSTRAINT FOR (m:Movie) REQUIRE m.title IS NOT NULL
Effect on Nodes

Every Movie node created must have a title property. Attempts to create a Movie without a title will fail.

// Relationship Property Existence ConstraintCREATE CONSTRAINT FOR ()-[r:RATED]-() REQUIRE r.score IS NOT NULL
Effect on Relationships

Every RATED relationship must have a score property. This ensures all ratings are recorded.
