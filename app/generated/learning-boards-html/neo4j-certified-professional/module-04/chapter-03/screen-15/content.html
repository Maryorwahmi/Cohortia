Key Concepts

More essential terms to remember.

Node Property Existence Constraint

Ensures a specified property must exist (not be null) on all nodes of a given label.

Relationship Property Existence Constraint

Ensures a specified property must exist (not be null) on all relationships of a given type.

Composite Index

An index created on multiple properties, useful when queries frequently filter on a combination of those properties.

Over-indexing

The practice of creating too many indexes, which can degrade write performance due to the overhead of updating multiple index structures.

Summary Takeaway

Existence constraints ensure data completeness, composite indexes optimize multi-property queries, and avoiding over-indexing prevents write performance degradation.
