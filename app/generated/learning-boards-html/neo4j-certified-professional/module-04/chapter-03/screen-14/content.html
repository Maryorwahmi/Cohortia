Key Concepts

Essential terms from this chapter.

Index

A data structure that improves the speed of data retrieval operations on a database by providing quick lookup access.

B-tree Index

The primary type of index in Neo4j for node properties, optimized for equality and range lookups.

Uniqueness Constraint

A schema rule ensuring a property on a node label holds unique values, automatically creating a B-tree index.

Summary Takeaway

Indexes and constraints are fundamental for accelerating queries and ensuring data integrity, with B-tree indexes and uniqueness constraints being key tools.
