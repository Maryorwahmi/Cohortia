B-tree Indexes: The Core of Neo4j Performance

Exploring the most common and efficient index type for node properties.

What is a B-tree Index?

A highly optimized, self-balancing tree data structure designed for efficient storage and retrieval of sorted data. It minimizes disk I/O operations.

Ideal for Equality Lookups

Significantly speeds up queries using exact matches, e.g., WHERE n.property = 'value'.

Excellent for Range Queries

Optimizes searches for values within a range, e.g., WHERE n.property > 100 or BETWEEN.

Key Takeaway

B-tree indexes are Neo4j's primary tool for fast equality and range-based property lookups, often created automatically by constraints.

Automatic Creation

B-tree indexes are automatically created when you define a uniqueness or existence constraint, simplifying schema management.
