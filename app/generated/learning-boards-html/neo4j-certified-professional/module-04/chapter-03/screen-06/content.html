Creating B-tree Indexes on Node Properties

Using Cypher to define indexes for faster node lookups.

The `CREATE INDEX` Command

This command explicitly tells Neo4j to build a B-tree index on a specified property for nodes with a given label.

Syntax Breakdown
  • FOR (n:Label): Specifies the node label (e.g., Person).
  • ON (n.property): Specifies the property to index (e.g., name).
Key Takeaway

CREATE INDEX explicitly defines a B-tree index for a node label and property, dramatically speeding up property-based lookups.

CREATE INDEX FOR (n:Person) ON (n.name)
Example Query Benefit

A query like MATCH (p:Person {name: 'Alice'}) RETURN p will be significantly faster after indexing p.name.

Common Misconception

An index on (n:Person) ON (n.name) will NOT apply to nodes with only the Employee label, even if they also have a name property. Indexes are label-specific.
