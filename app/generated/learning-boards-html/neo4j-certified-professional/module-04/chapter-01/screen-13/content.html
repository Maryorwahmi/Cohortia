Practical Application

Employee Seniority and Latest Project

Combining `CASE` and `CALL` for a real-world scenario.

Scenario & Task

1

Employee Level: 'Senior' (>5 projects) or 'Junior' (≤5 projects).

2

Latest Project: Find the most recent project for each employee using `completionDate`.

3

Return: Employee name, level, and latest project title (or 'N/A').

Starter Cypher Code
// Assume Employee and Project nodes, and COMPLETED_PROJECT relationships
// with a 'completionDate' property.

MATCH (e:Employee)
CALL {
  WITH e
  OPTIONAL MATCH (e)-[r:COMPLETED_PROJECT]->(p:Project)
  WITH e, p, r
  ORDER BY r.completionDate DESC
  LIMIT 1
  RETURN p.title AS latestProjectTitle
}
WITH e, latestProjectTitle
MATCH (e)-[r_count:COMPLETED_PROJECT]->()
WITH e, latestProjectTitle, count(r_count) AS projectCount
RETURN e.name AS employeeName,
  CASE
    WHEN projectCount > 5 THEN 'Senior'
    ELSE 'Junior'
  END AS employeeLevel,
  COALESCE(latestProjectTitle, 'N/A') AS mostRecentProject
Key Takeaway

This activity demonstrates how `CASE` statements and `CALL { ... }` subqueries can be combined to solve complex, real-world data analysis problems, providing dynamic categorization and precise per-group aggregations.
