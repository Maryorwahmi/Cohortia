Simple `CASE`: Matching Specific Values

Comparing an expression to several possible values for direct categorization.

Simple `CASE` Structure

1

`CASE expression`: Start with the expression to evaluate.

2

`WHEN value THEN result`: Define conditions and their outcomes.

3

`ELSE default_result`: Provide a fallback if no `WHEN` matches (optional but recommended).

4

`END`: Always close the `CASE` statement.

Cypher Example: Categorizing Nationality
MATCH (p:Person)
RETURN p.name,
  CASE p.bornIn
    WHEN 'USA' THEN 'American'
    WHEN 'UK' THEN 'British'
    ELSE 'Other'
  END AS nationality
Key Takeaway

Simple `CASE` statements are ideal for mapping a single expression's value to different results, providing a clear and concise way to categorize data based on exact matches.
