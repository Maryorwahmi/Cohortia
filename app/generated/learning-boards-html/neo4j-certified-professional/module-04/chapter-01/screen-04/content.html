Core Concept

The `WITH` Clause: Chaining Query Parts

Managing intermediate results and query flow in multi-stage operations.

How `WITH` Works

1

Pipeline Data: Passes results from one clause to the next, acting as a bridge.

2

Filter & Refine: Allows filtering, ordering, and aggregation of intermediate results.

3

Introduce Variables: Can create new variables or alias existing ones for clarity.

4

Modular Queries: Improves readability and maintainability by breaking down complex queries.

Cypher Example: Chaining with `WITH`
MATCH (p:Person)-[:ACTED_IN]->(m:Movie) // Match persons and movies
WHERE p.bornIn = 'USA'
WITH p, m.title AS movieTitle // Pass person and movie title
ORDER BY p.name
LIMIT 5
RETURN p.name, movieTitle // Return refined results
Key Takeaway

`WITH` is essential for structuring complex Cypher queries, allowing you to process and refine data incrementally, making queries more manageable and readable.
