Bridging Scopes: `WITH` Inside `CALL { ... }`

How to pass outer query variables into a subquery for contextual operations.

Passing Variables to Subqueries

1

Isolated Scope: Subqueries run in their own variable context.

2

Explicit `WITH`: Use `WITH` immediately inside `CALL { ... }` to pass variables.

3

Contextual Operations: Enables the subquery to operate on specific data from the outer query.

Cypher Example: Passing `movie`
MATCH (movie:Movie)
CALL {
  WITH movie // Crucial: passes 'movie' from outer query
  MATCH (movie)<-[r:ACTED_IN]-(actor:Person)
  RETURN actor.name AS actorName
}
RETURN movie.title, COLLECT(actorName) AS actors
Key Takeaway

Always use `WITH` inside a `CALL { ... }` subquery to explicitly pass variables from the outer query, ensuring the subquery has the necessary context to perform its operations.
