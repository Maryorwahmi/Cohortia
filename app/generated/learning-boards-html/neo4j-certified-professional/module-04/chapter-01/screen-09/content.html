`CASE` Statements: Dynamic Data Transformation

Introducing branching logic into your Cypher queries, similar to `if-else`.

Where to Use `CASE`

1

`RETURN` Clause: Dynamically modify output values.

2

`SET` Clause: Conditionally update node or relationship properties.

3

`WHERE` Clause: Apply complex, conditional filtering logic.

Conceptual Example: Categorizing Movies
MATCH (m:Movie)
RETURN m.title, 
  CASE
    WHEN m.releaseYear < 2000 THEN 'Classic'
    WHEN m.releaseYear >= 2000 THEN 'Modern'
    ELSE 'Unknown'
  END AS category
Key Takeaway

`CASE` statements provide powerful conditional logic, allowing you to dynamically transform, categorize, and filter data within your Cypher queries based on specified conditions.
