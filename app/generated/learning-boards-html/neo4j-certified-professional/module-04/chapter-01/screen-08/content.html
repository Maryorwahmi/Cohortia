Aggregating Per-Group: Top N Actors

Finding specific patterns and limits within each group using subqueries.

Scenario: Top 3 Actors Per Movie

1

Outer Query: Finds all `Movie` nodes.

2

Inner Subquery: For each `movie`, finds `actor`s, `ORDER BY`s, and `LIMIT`s to 3.

3

Result Collection: `COLLECT`s the top actors for each movie.

Cypher Code: Top N Actors
MATCH (movie:Movie)
CALL {
  WITH movie
  MATCH (movie)<-[r:ACTED_IN]-(actor:Person)
  RETURN actor.name AS actorName, r.roles AS roles
  ORDER BY actor.name // Or some other criteria
  LIMIT 3
}
RETURN movie.title AS movieTitle, 
       COLLECT({actor: actorName, roles: roles}) AS topActors
Key Takeaway

Subqueries are invaluable for performing complex, per-group aggregations and applying limits, allowing for precise data selection and transformation within each segment of your graph.
