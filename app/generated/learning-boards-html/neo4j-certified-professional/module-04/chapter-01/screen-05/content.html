Explicit Variable Passing with `WITH`

Understanding variable scope and avoiding 'Variable not defined' errors.

How Variables are Handled

✓

Explicitly Listed: Variables included in `WITH` are carried forward.

✗

Implicitly Dropped: Variables NOT in `WITH` are removed from scope.

!

Error Prevention: Be mindful to avoid 'Variable not defined' errors.

Cypher Example: Variable Dropping
MATCH (p:Person)-[:ACTED_IN]->(m:Movie)
WHERE p.name = 'Tom Hanks'
WITH p // Only 'p' is carried forward. 'm' is dropped.

// If you try to use 'm' here, it will result in an error.
// MATCH (p)-[:DIRECTED]->(otherMovie:Movie) // This is fine
// RETURN p.name, m.title // ERROR: 'm' not defined!

WITH p, m // Correct way to carry both 'p' and 'm'
RETURN p.name, m.title
Common Mistake

Forgetting to explicitly list all necessary variables in `WITH` can lead to `Variable not defined` errors in subsequent query clauses. Always double-check your variable scope.
