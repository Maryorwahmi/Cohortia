Finding ALL SHORTEST PATHS

Retrieving every path of the minimum length

What it does:

  • Finds all paths with the minimum number of relationships.
  • Useful when you need to explore all equally optimal routes.
  • More computationally intensive than shortestPath().
Consideration: Use judiciously on large graphs, as it can return many paths and impact performance.
Key Takeaway

allShortestPaths() provides a comprehensive view of all minimal routes but demands more resources; use it only when necessary.

Example: All Shortest Paths between Alice and Bob
MATCH (start:Person {name: 'Alice'}), (end:Person {name: 'Bob'})
MATCH p = allShortestPaths((start)-[*]->(end))
RETURN p

This query returns every path that has the minimum number of hops between Alice and Bob.

  • allShortestPaths(): Function to find all shortest paths.
  • The function ensures all returned paths are of the same minimal length.
