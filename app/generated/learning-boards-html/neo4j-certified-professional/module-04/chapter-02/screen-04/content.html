Core Concept

Variable-Length Relationships

Match patterns with flexible hop counts

What are they?

Variable-length relationships allow you to match patterns where the number of relationships between two nodes is not fixed, but falls within a specified range. This is fundamental for exploring connections across varying depths.

Example: Finding 'friends of friends' without knowing the exact path length.
Key Takeaway

Variable-length relationships provide flexibility in graph traversal, enabling queries to adapt to dynamic connection depths in real-world data.

Cypher Syntax for Variable Length
MATCH (p1:Person)-[:FRIEND*1..3]-(p2:Person)
RETURN p1.name, p2.name

This pattern matches paths with 1, 2, or 3 FRIEND relationships.

  • *minHops..maxHops: Specifies the range.
  • *1..3: Matches 1 to 3 hops.
  • *..3: Defaults to 1 to 3 hops.
