Path Inspection

Working with the path Variable

Extracting nodes and relationships from matched paths

Why use path?

  • Inspect the full sequence of nodes and relationships.
  • Crucial for debugging and understanding complex connections.
  • Allows for granular extraction of path components.
Benefit: Avoids retrieving entire paths when only specific properties are needed, reducing network traffic.
Key Takeaway

The path variable is essential for understanding and debugging variable-length traversals, allowing precise extraction of nodes and relationships.

Example: Friends of Friends (1-2 hops)
MATCH (p1:Person {name: 'Alice'})-[path*1..2]-(p2:Person)
RETURN
  p1.name,
  p2.name,
  [node IN NODES(path) | node.name] AS pathNodes

Here, path captures the entire connection. NODES(path) extracts all nodes in that path.

  • NODES(path): Returns a list of all nodes in the path.
  • RELATIONSHIPS(path): Returns a list of all relationships in the path.
