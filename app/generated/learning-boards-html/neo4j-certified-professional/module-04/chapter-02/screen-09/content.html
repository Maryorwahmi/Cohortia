Optimization Strategies

Constraining Your Traversal

Start specific, define types, and set direction

1. Specific Starting Node

Always begin with an indexed node (e.g., MATCH (n:Label {property: 'value'})) to limit the initial search space.

2. Relationship Types & Directions

Be explicit (e.g., [:FOLLOWS]-> instead of -[*]-) to prune irrelevant paths and improve efficiency.

Key Takeaway

Precise starting nodes and explicit relationship patterns are fundamental for efficient graph traversal, significantly reducing the search scope.

Example: Specific Traversal
MATCH (alice:Person {name: 'Alice'})
      -[:FRIENDS]->(friend:Person)
RETURN friend.name

This query starts from a specific 'Alice' node and follows a directed 'FRIENDS' relationship.

  • (alice:Person {name: 'Alice'}): Specific starting node.
  • -[:FRIENDS]->: Specific relationship type and direction.
Common Mistake

Starting with MATCH (n) or using generic -[*]- without constraints can lead to very slow queries.
