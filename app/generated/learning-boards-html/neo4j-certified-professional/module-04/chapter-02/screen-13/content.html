Key Concepts: Path Variables & Optimization

Essential terms and techniques to remember

Path Variable (p)

A variable representing an entire path (sequence of nodes and relationships) matched in a query, used for inspection.

Breadth-First Search (BFS)

A graph traversal algorithm exploring all nodes at the current depth before moving to the next, often used for shortest paths.

Dense Nodes (Super-nodes)

Nodes with an exceptionally high number of relationships, which can become performance bottlenecks during traversal if not handled carefully.

Chapter Summary

Effective use of the path variable, understanding BFS, and managing dense nodes are critical for optimizing graph traversal performance.
