Data Summarization

Aggregation Functions: COUNT, SUM, AVG

Summarizing graph data with common statistical functions

Key Aggregation Functions

  • •COUNT(*): Counts all rows.
  • •COUNT(n): Counts non-null values of n.
  • •SUM(property): Sums numeric property values.
  • •AVG(property): Calculates the average of a numeric property.
Example: Average Movie Rating
MATCH (m:Movie)RETURN AVG(m.rating)
This query calculates the average rating across all movies in your graph.
Key Takeaway

Aggregation functions like COUNT, SUM, and AVG are vital for summarizing data, providing statistical insights from your graph.

Common Mistake

Forgetting that Cypher implicitly groups by non-aggregated RETURN items. Be aware of this behavior to avoid unexpected results.
