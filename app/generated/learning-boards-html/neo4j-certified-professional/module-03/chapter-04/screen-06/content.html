Multi-Criteria ORDER BY

Handling ties with secondary sorting rules

How it Works

  • •Specify multiple properties, separated by commas.
  • •Criteria are applied in the order they are listed.
  • •Secondary criteria resolve ties from primary criteria.
  • •Each criterion can have its own ASC or DESC.
Example: Movies by Year then Title
MATCH (m:Movie)RETURN m.title, m.releaseYearORDER BY m.releaseYear ASC, m.title ASC
Movies are first sorted by release year, then by title for movies released in the same year.
Key Takeaway

Multi-criteria sorting ensures a consistent and logical presentation of data, especially when primary sort keys have identical values.

Common Mistake

Forgetting that the order of criteria matters. The first criterion takes precedence over subsequent ones.
