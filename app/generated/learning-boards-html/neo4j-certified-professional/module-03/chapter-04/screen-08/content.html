Data Uniqueness

The DISTINCT Keyword

Ensuring unique results in your query output

When to Use DISTINCT

  • •When graph patterns naturally return duplicates.
  • •To get a list of unique values (e.g., all genres).
  • •Can apply to individual properties or entire rows.
  • •Placed directly after RETURN.
Example: Unique Movie Genres
MATCH (m:Movie)RETURN DISTINCT m.genre
This query returns a list of all unique genres present in your movie graph.
Key Takeaway

DISTINCT is crucial for retrieving unique nodes, relationships, or property values, eliminating redundancy and providing clean, precise results.

Pro Tip

Use DISTINCT judiciously, as it can add overhead, especially on very large result sets. Only use it when uniqueness is a strict requirement.
