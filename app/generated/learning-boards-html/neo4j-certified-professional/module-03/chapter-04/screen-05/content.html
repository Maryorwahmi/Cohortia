Sorting Results

The ORDER BY Clause

Structuring your query results with single criteria

How ORDER BY Works

  • •Sorts results by specified properties.
  • •Default order is Ascending (ASC).
  • •Can explicitly use ASC or DESC.
  • •Applies to any returned property, node, or relationship.
Example: Movies by Release Year
MATCH (m:Movie)RETURN m.title, m.releaseYearORDER BY m.releaseYear ASC
This query returns movie titles and their release years, sorted from earliest to latest.
Key Takeaway

ORDER BY is crucial for presenting data in a structured and readable format, especially for user interfaces or reports.

Pro Tip

Always consider the default sort order. Explicitly using ASC or DESC improves query clarity.
