Introducing SET

Updating Properties and Labels on Existing Graph Elements

Property Updates

Modify the value of an existing property or add a new property to a node or relationship.

Label Addition

Attach one or more new labels to a node, enhancing its categorization without removing existing ones.

Dynamic Data Enrichment

Essential for evolving your graph's schema and enriching data as new information becomes available.

Code Example: Updating a Property
MATCH (m:Movie {title: 'New Sci-Fi'})
SET m.releaseYear = 2025
RETURN m
Key Takeaway

Use SET to precisely modify properties and add labels to existing nodes and relationships.
