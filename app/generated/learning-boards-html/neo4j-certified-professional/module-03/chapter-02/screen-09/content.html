Conditional Logic

Dynamic Actions with ON CREATE and ON MATCH

Tailoring Behavior Based on MERGE Outcome

ON CREATE

Executes statements only if the MERGE clause created a new node or relationship. Ideal for initial property settings.

ON MATCH

Executes statements only if the MERGE clause found an existing node or relationship. Useful for updating timestamps or counters.

Dynamic Data Management

Enables sophisticated logic for managing user activity, audit trails, and data synchronization within a single query.

Code Example: Conditional Property Updates
MERGE (p:Person {name: 'Alice'})
ON CREATE SET p.createdDate = datetime(), p.status = 'active'
ON MATCH SET p.lastSeen = datetime()
RETURN p
Key Takeaway

Use ON CREATE and ON MATCH with MERGE to apply different property updates based on whether an entity was created or matched.
