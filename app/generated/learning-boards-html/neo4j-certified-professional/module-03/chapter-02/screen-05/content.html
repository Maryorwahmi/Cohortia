Introducing CREATE

Adding New Nodes and Relationships to Your Graph

Node Creation

Define labels and initial properties for new nodes. Example: (p:Person {name: 'Jane Doe', born: 1990}).

Relationship Creation

Connect existing or newly created nodes with relationships. Example: (d)-[:DIRECTED]->(m).

Key Characteristic

CREATE always generates new entities, even if identical ones already exist in the graph.

Code Example: Creating Nodes and Relationships
CREATE (p:Person {name: 'Jane Doe', born: 1990})
RETURN p

CREATE (m:Movie {title: 'New Sci-Fi', releaseYear: 2024})
CREATE (d:Person {name: 'Ava Director'})
CREATE (d)-[:DIRECTED]->(m)
RETURN m, d
Key Takeaway

Use CREATE to explicitly add new nodes and relationships, defining their labels and initial properties.
