Introducing REMOVE

Cleaning Up Graph Element Attributes

Property Removal

Delete a specific property from a node or relationship. Example: REMOVE m.rating.

Label Removal

Remove a specific label from a node. Example: REMOVE m:SciFiMovie.

Attribute-Specific

REMOVE targets properties and labels only; it does not delete entire nodes or relationships.

Code Example: Removing a Property
MATCH (m:Movie {title: 'New Sci-Fi'})
REMOVE m.rating
RETURN m
Key Takeaway

Use REMOVE to precisely delete properties or labels, ensuring your graph data remains clean and relevant.
