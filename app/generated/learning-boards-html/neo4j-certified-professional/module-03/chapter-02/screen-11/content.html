SET Techniques

Flexible Property and Label Updates

Leveraging += for properties and adding multiple labels.

Merging Properties (+=)

Use SET n += {map} to add new properties or update existing ones from a map without removing others.

Replacing All Properties

Be cautious: SET n = {map} will replace ALL existing properties on n with the new map.

Adding New Labels

Simply use SET n:NewLabel to add a new label to a node, allowing for multi-categorization.

Code Example: Merging Properties and Adding Labels
MATCH (m:Movie {title: 'New Sci-Fi'})
SET m += {genre: 'Action', rating: 7.5}
RETURN m

MATCH (m:Movie {title: 'New Sci-Fi'})
SET m:SciFiMovie
RETURN m
Key Takeaway

Use SET += for partial property updates and SET :Label for adding new labels to nodes.
