The MATCH Clause: Finding Patterns

Define the Graph Structure You're Looking For

// 1. Match any node
MATCH ()

// 2. Match a node and assign a variable
MATCH (n)

// 3. Match a node with a specific label
MATCH (p:Person)

// 4. Match a node with a variable and label
MATCH (m:Movie)
Syntax Breakdown

Nodes are represented by parentheses (). Labels are prefixed with a colon :. Variables are optional but useful for reference.

Node Representation

Nodes are the entities in your graph. In Cypher, they are visually represented by parentheses ().

Labels for Categorization

Labels categorize nodes, like :Person or :Movie. They are crucial for efficient pattern matching.

Key Takeaway

The MATCH clause is your primary tool for visually describing the graph patterns you want to find.
