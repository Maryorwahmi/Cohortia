Aliasing Results for Better Understanding

Rename Output Columns for User-Friendly Reports

// 1. Alias a property name
MATCH (p:Person)
RETURN p.name AS ActorName

// 2. Alias multiple properties
MATCH (p:Person)-[:ACTED_IN]->(m:Movie)
RETURN p.name AS Actor, m.title AS Film

// 3. Alias an entire node
MATCH (p:Person)
RETURN p AS ThePersonNode
Syntax Breakdown

Use the AS keyword after the item you want to rename, followed by the new alias. Aliases are case-sensitive.

Improved Readability

Aliasing makes your query results more intuitive and easier to understand for both technical and non-technical users.

User-Friendly Output

Custom column names enhance the professionalism and clarity of your data presentations and reports.

Key Takeaway

Use AS to alias nodes, relationships, or properties in your RETURN clause for clearer, more descriptive output.
