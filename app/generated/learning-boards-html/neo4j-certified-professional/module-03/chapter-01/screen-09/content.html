Refining Patterns with WHERE

Apply Conditions to Your Matched Graph Data

// 1. Find movies released after 2000
MATCH (m:Movie)
WHERE m.releaseYear > 2000
RETURN m.title

// 2. Find people named 'Tom Hanks' who acted in movies
MATCH (p:Person)-[:ACTED_IN]->(m:Movie)
WHERE p.name = 'Tom Hanks'
RETURN m.title
Syntax Breakdown

The WHERE clause follows MATCH. Use property access (m.releaseYear) and standard comparison/logical operators.

Powerful Filtering

The WHERE clause allows for complex conditions using comparison, logical, and string matching operators.

Execution Order

WHERE is evaluated after MATCH but before RETURN, ensuring only relevant data is processed.

Key Takeaway

Use the WHERE clause to apply conditions and filter your matched graph patterns for precise results.
