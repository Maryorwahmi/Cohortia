Avoiding Common Cypher Pitfalls

Understand Case-Sensitivity and Syntax Nuances

Missing RETURN Clause

Mistake: Writing only MATCH (n:Node).
Correction: Always include RETURN n to see results.

Incorrect Property Syntax

Mistake: { 'name': 'Value' } or {name: Value}.
Correction: Property keys are unquoted, values are quoted: {name: 'Value'}.

Case-Sensitivity

Mistake: Using :person instead of :Person or name instead of Name.
Correction: Labels, relationship types, and property keys are case-sensitive.

Relationship Direction

Mistake: Using undirected -- when a specific direction is needed.
Correction: Use --> or <-- for clarity and performance when direction is known.

Key Takeaway

Double-check your RETURN clause, property syntax, casing, and relationship direction to avoid common Cypher errors.
