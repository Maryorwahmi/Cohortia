Shaping Your Output with RETURN

Select Exactly What Data You Want to See

// 1. Return entire nodes
MATCH (p:Person)
RETURN p

// 2. Return specific properties
MATCH (p:Person)-[:ACTED_IN]->(m:Movie)
RETURN p.name, m.title

// 3. Return a relationship
MATCH (p:Person)-[r:ACTED_IN]->(m:Movie)
RETURN r
Syntax Breakdown

Specify variables (p, m, r) to return entire elements, or use dot notation (p.name) for properties.

Projection Control

RETURN allows you to precisely control what data is outputted, from full entities to specific attributes.

Efficiency Boost

Returning only necessary data reduces network overhead and processing, improving query performance.

Key Takeaway

The RETURN clause is essential for projecting desired data, whether it's entire nodes, relationships, or specific properties.
