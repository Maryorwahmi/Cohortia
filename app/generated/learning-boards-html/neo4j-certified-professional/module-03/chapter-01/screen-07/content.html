Defining Relationships in Cypher

Traverse the Graph with Directed and Undirected Patterns

// 1. Undirected relationship (matches either direction)
MATCH (a)--(b)

// 2. Outgoing directed relationship
MATCH (a)-->(b)

// 3. Incoming directed relationship
MATCH (a)<--(b)

// 4. Directed relationship with type and variable
MATCH (p:Person)-[r:ACTED_IN]->(m:Movie)
Syntax Breakdown

Hyphens -- represent relationships. Arrows --> or <-- indicate direction. Types are prefixed with :.

Direction Matters

Specifying direction (--> or <--) is crucial for logical correctness and often for query performance.

Relationship Types

Relationship types, like :ACTED_IN, categorize connections and are essential for precise pattern matching.

Key Takeaway

Relationships are defined visually, and their direction is a critical component for accurate graph traversal.
