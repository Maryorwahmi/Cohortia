Specifying Nodes with Labels and Properties

Refine Your Node Matches for Precision

// 1. Match a Person node with a specific name
MATCH (p:Person {name: 'Tom Hanks'})

// 2. Match a Movie node released in a specific year
MATCH (m:Movie {releaseYear: 1999})

// 3. Match a node with multiple properties
MATCH (c:City {name: 'London', country: 'UK'})
Syntax Breakdown

Properties are defined within curly braces {} as key-value pairs. Values must be quoted strings or numbers.

Property Filtering

Properties allow you to filter nodes based on their attributes, making your matches highly specific.

Exact Matches

Properties within {} perform direct equality checks. For more complex filtering, use the WHERE clause.

Key Takeaway

Adding properties to node patterns allows you to pinpoint exact entities, significantly improving query precision.
