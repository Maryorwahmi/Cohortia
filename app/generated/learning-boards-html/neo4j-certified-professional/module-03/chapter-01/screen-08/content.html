Using Wildcards and Simple Queries

Match Any Node or Relationship with Ease

// 1. Match any node (wildcard)
MATCH ()

// 2. Match any relationship (wildcard)
MATCH (a)-[*]-(b)

// 3. Simple query: Find all Person nodes
MATCH (p:Person)
RETURN p

// 4. Simple query: Find all Movie nodes
MATCH (m:Movie)
RETURN m
Syntax Breakdown

Empty parentheses () match any node. -[*]- matches any relationship. The RETURN clause specifies output.

Node Wildcards

Using () without a label or variable acts as a wildcard, matching any node in the graph.

Relationship Wildcards

-[*]- matches any relationship type and direction. Be cautious, as this can be less performant on large graphs.

Key Takeaway

Combine MATCH to find patterns and RETURN to project results, forming complete Cypher queries.
