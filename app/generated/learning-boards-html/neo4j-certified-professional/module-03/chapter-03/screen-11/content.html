Real-World Scenario

User Account Deletion: A Practical Example

Applying deletion clauses in a social network context

The Challenge

A user node is typically highly connected (posts, comments, friendships), making simple DELETE impossible.

DETACH DELETE Solution

DETACH DELETE removes the user node and all its relationships, ensuring a clean removal and graph integrity.

Granular Control

For selective deletion (e.g., keeping posts but disconnecting from user), a multi-step approach with specific DELETE r is needed.

Key Takeaway

DETACH DELETE is ideal for full entity removal, while multi-step deletions offer fine-grained control over relationships.

// Delete user 'user123' and all connections
MATCH (u:User {id: 'user123'})
DETACH DELETE u
// Alternative: Delete relationships, then node
MATCH (u:User {id: 'user123'})-[r]->()
DELETE r
MATCH (u:User {id: 'user123'})
DELETE u

Why it's important

Choosing the correct deletion method ensures data consistency and aligns with specific application requirements for data retention.
