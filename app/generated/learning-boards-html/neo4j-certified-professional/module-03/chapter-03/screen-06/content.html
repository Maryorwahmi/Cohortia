Cypher Clause

The DELETE Clause: Isolated Nodes

Removing nodes without any incoming or outgoing relationships

Condition for Node Deletion

A node can only be deleted using DELETE if it has absolutely no incoming or outgoing relationships.

Error on Connected Nodes

Attempting to delete a connected node with DELETE will result in a runtime error, preventing data inconsistency.

Why this restriction?

It forces explicit handling of relationships, ensuring graph integrity and preventing 'dangling' pointers.

Key Takeaway

DELETE is safe for isolated nodes, but requires prior relationship removal for connected nodes.

// Delete an isolated node
MATCH (orphan:Node {id: 'temp_node'})
DELETE orphan
// What happens if 'orphan' has relationships?
ERROR! Cypher will throw an error: "Cannot delete node
because it still has relationships."

Pro-Tip: Pre-check

Always run a MATCH (n)-[r]-() RETURN n, r query to inspect a node's connections before attempting to DELETE it.
