DETACH DELETE in Practice

Removing a node and all its relationships with a single query

Scenario: Full Entity Removal

When a central entity (e.g., a person) needs to be completely removed from the graph, including all its connections.

Efficiency & Simplicity

DETACH DELETE streamlines the process, avoiding multiple `MATCH` and `DELETE` statements for each relationship type.

Irreversible Action

This operation is permanent. Once executed, the node and its relationships are gone, emphasizing the need for caution.

Key Takeaway

DETACH DELETE is the go-to for complete node removal, but always verify your target before execution.

// Delete 'John Doe' and all his connections
MATCH (p:Person {name: 'John Doe'})
DETACH DELETE p
// What happens?
Success! All relationships connected to 'John Doe' are removed.
Success! The 'John Doe' node itself is then deleted.

Consider This

If you only wanted to remove specific relationships, you would use multiple MATCH and DELETE r statements before deleting the node.
