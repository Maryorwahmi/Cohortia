Module 5 › Chapter 4.4 › Quick Reminders
Enable services
Use systemctl enable --now so services start now and on boot.
Fix labels & permissions
Use chmod/chown and restorecon -Rv to give httpd correct access to files.
Harden MariaDB
Run mysql_secure_installation immediately to remove defaults that increase risk.
Final takeaway

Follow the install, verify, secure pattern for every service. Small steps performed reliably keep systems stable and safe.
