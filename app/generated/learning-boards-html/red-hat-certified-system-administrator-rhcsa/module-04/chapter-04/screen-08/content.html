Module 5 › Chapter 4.4 › Install MariaDB
Install and verify MariaDB server
sudo dnf install -y mariadb-server
sudo systemctl enable --now mariadb
sudo systemctl status mariadb
# Test local login
mysql -u root -p
Confirm that mariadb accepts local connections before running the secure installation helper. If you cannot connect, check mariadb logs and unit status.
Practical guidance
  • Install the package so systemctl can manage the service unit and default configuration files are placed.
  • Enable and start the service to create runtime directories and socket files that some configurations expect.
  • Test login locally; many systems disallow remote root by default and require a secured root password.
Misconception: Installing mariadb-server implies secure defaults. Always run the secure installation helper to remove insecure defaults and set a root password.
Key Takeaway

Install and enable mariadb, then verify a local connection before hardening the server with mysql_secure_installation.
