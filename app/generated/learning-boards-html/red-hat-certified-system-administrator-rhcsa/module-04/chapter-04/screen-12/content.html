Module 5 › Chapter 4.4 › Hands-on Walkthrough
Step-by-step lab timeline
1
Install and enable Apache
sudo dnf install -y httpd; sudo systemctl enable --now httpd
2
Create index and fix labels
echo "<h1>Welcome</h1>" | sudo tee /var/www/html/index.html; restorecon -Rv /var/www/html
3
Open firewall
sudo firewall-cmd --zone=public --add-service=http --permanent; sudo firewall-cmd --reload
4
Install and secure MariaDB
sudo dnf install -y mariadb-server; sudo systemctl enable --now mariadb; sudo mysql_secure_installation
Verify
Browse to http://your_rhel_server_ip and run mysql -u root -p locally to confirm the root password.
