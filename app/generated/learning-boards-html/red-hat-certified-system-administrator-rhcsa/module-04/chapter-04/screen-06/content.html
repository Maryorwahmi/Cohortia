Module 5 › Chapter 4.4 › Open Firewall
Commands to open web traffic
sudo firewall-cmd --zone=public --add-service=http --permanent
sudo firewall-cmd --zone=public --add-service=https --permanent
sudo firewall-cmd --reload
sudo firewall-cmd --list-services --zone=public
Use service names so firewalld opens the right ports for TCP or UDP automatically. Always reload after adding permanent rules.
Checks and troubleshooting
  • If connection still times out, confirm httpd is active with systemctl status httpd.
  • Verify SELinux context and file permissions if you get HTTP 403 errors instead of timeouts.
  • Use curl from another machine or telnet to port 80 to test reachability; timeouts usually indicate a firewall or network ACL issue.
Remember: forgetting to reload firewalld after adding permanent rules is the most common operational mistake here.
Key Takeaway

Open services with permanent rules and reload; verify with --list-services to avoid surprises.
