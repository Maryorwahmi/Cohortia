Install with dnf and enable the httpd service
Commands you will run in the lab.
<sudo dnf install -y httpd>
<sudo systemctl enable --now httpd>
<sudo systemctl status httpd>
<sudo journalctl -u httpd --since '5 minutes ago'>
Note: enabling with --now saves a step. If status reports failure, check journalctl for configuration errors or missing dependencies before changing firewall rules.
Explanation & example
  • dnf installs packaged files to their standard locations so systemctl can manage the unit.
  • systemctl enable --now both starts the service now and enables it at boot, preventing service absence after a reboot.
  • Use journalctl to view recent unit logs if status shows failed; it reveals config errors or permission problems.
Example scenario
You install httpd, enable the service, then browse to the server IP and see nothing. Before opening firewall ports, confirm systemctl status shows active; if not, check journalctl -u httpd.
Key Takeaway

Installing a package is only the first step. Enable and start the service and check logs to ensure the server runs.
