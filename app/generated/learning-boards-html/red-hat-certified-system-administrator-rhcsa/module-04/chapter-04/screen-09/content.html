Module 5 › Chapter 4.4 › Secure MariaDB
Run the interactive hardening script
Follow the prompts and apply recommended answers for production systems.
sudo mysql_secure_installation
# Typical prompts and recommended answers:
# - Set root password? (Y)
# - Remove anonymous users? (Y)
# - Disallow root login remotely? (Y)
# - Remove test database? (Y)
# - Reload privilege tables? (Y)
Why each step matters
  • Setting a root password prevents unauthenticated access to the database server.
  • Removing anonymous users ensures only named accounts can authenticate.
  • Disallowing remote root logins forces use of less-privileged accounts for remote work.
  • Removing the test database closes a common backdoor used during initial installs.
Misconception: skipping these steps because it's 'just a lab' creates unsafe habits. Treat each fresh install as if it will go into production.
Key Takeaway

Hardening with mysql_secure_installation is quick and addresses the most common initial vulnerabilities.
