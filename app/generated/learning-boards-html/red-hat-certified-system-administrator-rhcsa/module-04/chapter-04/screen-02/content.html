Learning Objectives
Concrete outcomes to practice in the lab.
Learn → Understand → Apply → Master
01
Install & configure Apache
Install httpd, place a simple index file in the default document root, and verify the service status.
Mnemonic: Package → Service → Page
VERIFIED COMPETENCY MILESTONE
02
Manage httpd and firewalld
Start, enable, and check httpd with systemctl. Open HTTP and HTTPS in firewalld and reload to apply changes.
Mnemonic: Start → Open → Verify
VERIFIED COMPETENCY MILESTONE
03
Install & secure MariaDB
Install mariadb-server, enable the service, then run mysql_secure_installation to set root password and remove defaults.
Mnemonic: Install → Harden → Test
VERIFIED COMPETENCY MILESTONE
04
Apply basic service security
Understand SELinux contexts, file ownership, least privilege, and how they prevent common service failures and breaches.
Mnemonic: Label → Own → Limit
VERIFIED COMPETENCY MILESTONE
