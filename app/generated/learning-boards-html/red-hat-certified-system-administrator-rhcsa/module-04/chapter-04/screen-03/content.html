Module 5 › Chapter 4.4 › Lab Flow
Practice sequence for predictable results
1
Install packages
Use dnf to install httpd and mariadb-server.
2
Enable & start services
systemctl enable --now ensures services start now and after reboot.
3
Create and label files
Place index.html in /var/www/html and restore SELinux contexts.
4
Open firewall
Add http and https services and reload firewalld.
5
Harden MariaDB
Run mysql_secure_installation to set root password and remove defaults.
6
Verify
Browse to http://server_ip and log into MariaDB locally.
