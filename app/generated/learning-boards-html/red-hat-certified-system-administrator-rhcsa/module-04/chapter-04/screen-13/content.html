Quiz item
Q: Default web root on RHEL? A: /var/www/html
Q: Primary fix for Apache file-label problems? A: restorecon -Rv /var/www/html
Common mistakes
  • Forgetting firewall reload after adding permanent rules.
  • Skipping mysql_secure_installation.
  • Applying overly broad file permissions rather than fixing contexts.
Short answers
Least privilege means granting a user or service only the permissions absolutely required for its task, no more.
Use this checklist when you practice the lab and build a habit of verifying one layer at a time.
