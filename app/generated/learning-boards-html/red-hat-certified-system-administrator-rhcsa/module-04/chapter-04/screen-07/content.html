Restore SELinux contexts for web files
Use restorecon to align file labels with service expectations.
sudo restorecon -Rv /var/www/html
# Verify label type with
ls -Z /var/www/html
If labels already look correct but access fails, review httpd logs and consider SELinux boolean settings for httpd if needed for advanced features; avoid turning SELinux off in production.
Explanation and example
  • SELinux contexts act as an additional access control layer beyond file ownership and permissions.
  • restorecon resets labels to the default types for the distribution, which is usually what httpd expects.
  • Listing files with ls -Z shows the SELinux type; look for httpd_sys_content_t or the expected web content type.
Misconception: Changing file permissions broadly may expose other services. Fix labels first and apply least-privilege permissions.
Key Takeaway

SELinux labels are the correct fix for many 'forbidden' errors; restorecon -Rv is a safe first step.
