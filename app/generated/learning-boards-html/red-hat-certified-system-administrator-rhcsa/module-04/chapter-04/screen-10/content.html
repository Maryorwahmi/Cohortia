Web server timeout vs forbidden
Follow a checklist to isolate the layer causing the problem.
# Service check
sudo systemctl status httpd
# Local test
curl http://localhost/
# Firewall check
sudo firewall-cmd --list-services --zone=public
# SELinux fix
sudo restorecon -Rv /var/www/html
Database connection issues
Check service, local login, and secure installation.
sudo systemctl status mariadb
sudo journalctl -u mariadb
mysql -u root -p
sudo mysql_secure_installation
Pro tip

Change one thing at a time and retest. This isolates cause and prevents cascading misconfigurations.
