Module 5 › Chapter 4.4 › Service Architecture
Single-host architecture overview
Typical flow: client → Apache → application → MariaDB (local).
Apache HTTPD
Listens on 80/443, serves files from /var/www/html and passes dynamic requests to backend components.
MariaDB
Provides relational storage. Secure default: harden root account and prefer local connections.
Controls
systemctl for lifecycle, firewalld for network exposure, SELinux for fine-grained resource access control.
Practical guidance
  • Keep database listeners local unless necessary; use firewalld to restrict access otherwise.
  • Create application database users with only the privileges needed for their tasks.
  • Regularly update packages to patch service vulnerabilities.
Key Takeaway

Segregate access: web-facing components need broader network exposure than database services, which should follow least privilege.
