Module 5 › Chapter 4.4 › Document Root
Default document root: /var/www/html
Create and serve a test page to confirm functionality.
<echo "<h1>Welcome to my Cohortia RHEL Web Server!</h1>" | sudo tee /var/www/html/index.html>
<sudo chmod -R 755 /var/www/html>
<sudo chown -R apache:apache /var/www/html>
<sudo restorecon -Rv /var/www/html>
<curl http://localhost/>
Common mistakes and fixes
  • Permission denied responses often mean wrong ownership or mode; set apache:apache and 755 recursively.
  • HTTP 403 can be caused by incorrect SELinux contexts; restorecon -Rv repairs labels to the expected type.
  • Assuming the firewall is at fault too early wastes time; verify service and file access locally first.
Analogy
Think of /var/www/html as a storefront window. If the light is off (service down) or the window is locked (permissions/SELinux), customers cannot see your page even if you opened the street (firewall).
Key Takeaway

Test locally first. Correct ownership and SELinux contexts are frequent causes of files not being served.
