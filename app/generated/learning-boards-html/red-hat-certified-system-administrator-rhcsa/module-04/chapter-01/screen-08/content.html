Module 4 › Chapter 4.1 › IP Addressing, Netmask, Gateway, and DNS
Core definitions
IP address: the numerical identity of a network interface.
Netmask: defines subnet boundaries and host capacity.
Gateway: router used for traffic outside the local subnet.
DNS: service that resolves domain names to IP addresses.
Misconfiguration traps
  • Wrong gateway leaves external networks unreachable despite local link up.
  • Incorrect DNS yields successful pings to IPs but failed hostname resolution.
Concrete example
Assign 192.168.1.100/24 with gateway 192.168.1.1 and DNS 8.8.8.8 so the server can reach both local hosts and internet hosts by name.
Key takeaway
Always provide address, netmask, gateway, and DNS when configuring a static IP to ensure full connectivity.
Check your understanding
If you can ping 8.8.8.8 but cannot ping google.com, which subsystem is likely misconfigured? Answer: DNS.
