Module 4 › Chapter 4.1 › Learning Objectives
01
Configure network interfaces
Use nmcli and nmtui to set static and dynamic IPs so services have stable addresses. Practice creating and activating a profile and confirm persistence across reboots.
Mnemonic: profile → method → activate
VERIFIED COMPETENCY MILESTONE
02
Manage NetworkManager
Understand the daemon's role in applying profiles and how to start, stop, and query its status during troubleshooting. This is critical when automating or recovering network state.
Mnemonic: daemon first, then profiles
VERIFIED COMPETENCY MILESTONE
03
Verify connectivity
Use ip, ip route, ping, and traceroute to confirm addressing and path to other hosts. Always confirm both IP reachability and DNS resolution when diagnosing failures.
Mnemonic: address → route → name
VERIFIED COMPETENCY MILESTONE
04
Implement firewall rules
Use firewalld zones and firewall-cmd to allow only necessary services. Learn the difference between temporary and permanent changes and how to reload settings safely.
Mnemonic: zone → service → permanent
VERIFIED COMPETENCY MILESTONE
