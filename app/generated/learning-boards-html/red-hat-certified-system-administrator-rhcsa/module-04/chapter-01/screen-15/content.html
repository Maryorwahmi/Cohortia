IP & Netmask
Address identifies host; netmask defines the network scope.
Gateway & Route
Gateway sends traffic off the local subnet; verify with ip route show.
DNS & Firewall
DNS translates names; firewalld zones control service exposure and require permanent + reload for lasting changes.
Final takeaway

Follow the verification order and prefer scripted nmcli changes for reproducibility. Use firewalld zones to limit exposure and always confirm with a remote client.
