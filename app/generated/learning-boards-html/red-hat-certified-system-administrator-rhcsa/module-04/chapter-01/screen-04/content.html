Module 4 › Chapter 4.1 › NetworkManager — what it is and why it matters
Definition
NetworkManager is a dynamic configuration daemon that manages devices, connections, and name resolution settings.
Why it matters
  • It centralizes profiles so servers stay reachable with predictable addresses.
  • It supports both DHCP and manual methods for flexibility across environments.
  • Knowing its state helps you diagnose whether a profile or an external DHCP server set values.
Common misconception
Some think NetworkManager is only for desktops; in RHEL it is the primary networking control service even for servers.
Concrete example
A server profile named my-static-eth0 assigns a static address, gateway, and DNS so monitoring and backups can always reach the host at the same IP.
Key takeaway
Treat NetworkManager as the first place to check and configure network state on modern RHEL systems.
Check your understanding
If a server receives the wrong DNS after boot, should you inspect the connection profile or resolv.conf first? Answer: check the active profile and NetworkManager settings, then resolv.conf if needed.
