Module 4 › Chapter 4.1 › Hands-on nmcli: configure a static IP
Starter checklist
  • Identify interface with ip addr show.
  • Remove or disable conflicting default connection names.
  • Add a named static profile and set method to manual.
  • Bring the profile up and verify with ping and ip commands.
Lab commands (visual only)
# Identify interface
ip addr show

# (Optional) Delete a default connection
sudo nmcli connection delete "System enp0s3"

# Add static profile - example values
sudo nmcli connection add type ethernet con-name my-static-eth0 ifname enp0s3 ip4 192.168.1.100/24 gw4 192.168.1.1 dns "8.8.8.8 8.8.4.4"
sudo nmcli connection modify my-static-eth0 ipv4.method manual
sudo nmcli connection up my-static-eth0

# Verify
ip addr show enp0s3
ping -c 3 8.8.8.8
ping -c 3 google.com
Explanation and traps
  • Deleting a default connection avoids naming collisions when adding a new profile with the same interface.
  • Setting ipv4.method to manual is essential; otherwise NetworkManager may keep using DHCP.
  • Confirm both IP-level reachability and DNS resolution; they test different parts of the network stack.
Concrete scenario
You set a static IP for a backup server so nightly backups always target the same address. Verify connections on completion.
