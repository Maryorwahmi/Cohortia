Module 4 › Chapter 4.1 › nmtui — an interactive text UI
What nmtui offers
  • Menu-driven editing for connections, activation, and hostnames.
  • Works inside a terminal session without a graphical desktop.
  • Good for one-off manual edits and guided configuration.
When to choose nmtui
Use nmtui when you need a clear interactive workflow and are not automating changes. For repeatable deployments, prefer nmcli.
Concrete example
Run nmtui, select Edit a connection, choose the interface, fill in IPv4 settings, save, and activate. Then verify with ip addr show.
Quick tip
nmtui is excellent for initial setup when you are logged into a server via console or emergency rescue mode.
Check your understanding
If you need the same configuration on many hosts, which tool will you script? Answer: nmcli, because nmtui is interactive only.
