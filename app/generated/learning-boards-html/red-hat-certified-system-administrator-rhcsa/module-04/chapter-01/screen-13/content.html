Module 4 › Chapter 4.1 › Hands-on activity: configure static IP and enable SSH
Lab steps
  1. Identify interface: ip addr show.
  2. Create a static profile with nmcli and set ipv4.method to manual.
  3. Activate the profile and verify with ip addr show and ping.
  4. Allow SSH permanently with firewall-cmd and reload.
  5. From a client, SSH to the new static IP to confirm access.
Commands (lab reference)
# Example sequence
ip addr show
sudo nmcli connection delete "System enp0s3"
sudo nmcli connection add type ethernet con-name my-static-eth0 ifname enp0s3 ip4 192.168.1.100/24 gw4 192.168.1.1 dns "8.8.8.8 8.8.4.4"
sudo nmcli connection modify my-static-eth0 ipv4.method manual
sudo nmcli connection up my-static-eth0

# Firewall
sudo firewall-cmd --zone=public --add-service=ssh --permanent
sudo firewall-cmd --reload
sudo firewall-cmd --list-services --zone=public

# From client
ssh user@192.168.1.100
Lab tip
Run verification steps between changes so you can isolate which action produced the expected result.
