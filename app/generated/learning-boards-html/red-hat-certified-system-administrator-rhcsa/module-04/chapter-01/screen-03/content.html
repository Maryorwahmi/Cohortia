Module 4 › Chapter 4.1 › Learning Objectives
01
Profile creation and persistence
You will add a new connection profile, set ipv4.method to manual for static addressing, then bring it up and verify persistence after reboot by listing connections.
Mnemonic: add → modify → up
VERIFIED COMPETENCY MILESTONE
02
NetworkManager recovery
Practice checking NetworkManager status, reloading profiles, and restarting the service when changes do not apply as expected.
Mnemonic: status → reload → restart
VERIFIED COMPETENCY MILESTONE
03
Connectivity checks
Run address and route checks, then ping an IP and a hostname to isolate DNS issues from routing problems.
Mnemonic: ip → route → ping
VERIFIED COMPETENCY MILESTONE
04
Firewall rule workflow
Add services to the appropriate zone permanently, reload firewalld, and verify the list of services for that zone to ensure access works as intended.
Mnemonic: zone → add-service → reload
