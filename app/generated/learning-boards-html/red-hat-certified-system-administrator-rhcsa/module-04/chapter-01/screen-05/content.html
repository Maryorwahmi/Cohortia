Common nmcli workflow
  1. List active connections to identify current profiles.
  2. Create a new connection profile with addressing and DNS fields.
  3. Set ipv4.method to manual for static setups.
  4. Bring the connection up and verify with ip and ping.
Example commands
# List active connections
nmcli connection show --active

# Add a static ethernet profile (example values)
nmcli connection add type ethernet con-name static-eth0 ifname enp0s3 ip4 192.168.1.100/24 gw4 192.168.1.1 dns "8.8.8.8 8.8.4.4"

# Ensure it's manual and bring it up
nmcli connection modify static-eth0 ipv4.method manual
nmcli connection up static-eth0
Explanation points
  • connection add creates a named profile stored by NetworkManager for persistence.
  • modify with ipv4.method manual is necessary to make the address assignment persistent.
  • connection up activates the profile immediately so you can verify reachability.
Check after change
Use ip addr show and ping a known IP and a hostname to confirm both routing and DNS.
Common mistake
Forgetting to set ipv4.method to manual, which can cause a static address to be ignored or overridden.
