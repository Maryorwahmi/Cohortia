Tooling

dig: deep DNS inspection

Verbose query
dig google.com
; <<>> DiG <<>> google.com
;; ANSWER SECTION:
google.com. 299 IN A 172.217.160.142
;; Query time: 30 msec
Target a specific server
dig @192.168.1.1 google.com
Use this to verify whether a configured nameserver answers correctly.
Interpreting results
  • Answer section: contains resolved addresses.
  • Status lines may show SERVFAIL, NXDOMAIN, or successful codes.
Key Takeaway

dig is the go-to tool when you need full details about DNS responses and to test specific servers directly.
