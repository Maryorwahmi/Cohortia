chronyd configuration and verification

Suggested /etc/chrony.conf entries
# Use public NTP servers from the pool project.
pool 0.rhel.pool.ntp.org iburst
pool 1.rhel.pool.ntp.org iburst
pool 2.rhel.pool.ntp.org iburst
pool 3.rhel.pool.ntp.org iburst

# Allow NTP client access from local network.
# allow 192.168.0.0/16

logdir /var/log/chrony
Start and enable
sudo dnf install -y chrony
sudo systemctl enable --now chronyd
sudo systemctl status chronyd
Verify with chronyc
chronyc sources -v
chronyc tracking
Key Takeaway

Use pool lines with iburst, enable chronyd, and confirm a small system time offset and a selected source in chronyc output.
