Module 4 › Chapter 4.2 › Key Concepts
DNS Resolver
Client-side component that queries nameservers to map hostnames to IP addresses.
/etc/resolv.conf
Lists system nameservers and search domains; usually generated by NetworkManager on RHEL.
dig
Verbose DNS query tool that shows answers, authority, and lets you target a server with @address.
Summary
Resolver settings, persistent configuration via NetworkManager, and diagnostic tools like dig are your first line of defense when name resolution breaks.
