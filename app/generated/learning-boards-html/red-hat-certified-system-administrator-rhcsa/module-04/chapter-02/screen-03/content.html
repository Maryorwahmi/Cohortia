How you'll prove mastery

Commands, edits, and verification steps to show working DNS and NTP.
Learn → Understand → Apply → Master
01 Modify DNS with nmcli
Run nmcli connection modify "System enp0s3" ipv4.dns "192.168.1.1 192.168.1.2" and bring the connection up. Verify /etc/resolv.conf lists the nameservers.
02 Query DNS
Run dig google.com and dig @192.168.1.1 google.com to test a specific server. Use host for concise lookups.
03 Configure chronyd
Edit /etc/chrony.conf to add pool lines and iburst, then enable and start chronyd with systemctl enable --now chronyd.
04 Verify NTP
Use chronyc sources -v to see symbols indicating selection and chronyc tracking to read system time offset. If unreachable, check firewalld for ntp service.
