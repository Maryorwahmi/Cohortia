Learning Objectives

Learn, understand, apply, and verify DNS and NTP settings on RHEL.
Learn → Understand → Apply → Master
01 DNS role
Explain the resolver and why hostnames map to IPs.
Mnemonic: phonebook analogy — name to number mapping.
VERIFIED COMPETENCY MILESTONE
02 DNS troubleshooting
Use dig and host to query servers and confirm reachability.
Mnemonic: ask the server directly — dig @server name
VERIFIED COMPETENCY MILESTONE
03 chronyd configuration
Edit /etc/chrony.conf to set pools or servers and enable chronyd.
Mnemonic: pool lines plus iburst for fast initial sync.
VERIFIED COMPETENCY MILESTONE
04 Verification & troubleshooting
Use chronyc sources and chronyc tracking, and check firewalld for UDP 123.
Mnemonic: look for a star or caret in sources output to indicate selection.
VERIFIED COMPETENCY MILESTONE
