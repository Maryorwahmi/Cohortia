Hands-on

Set DNS and verify

Set DNS on the connection
sudo nmcli connection modify my-static-eth0 ipv4.dns "8.8.8.8 8.8.4.4"
sudo nmcli connection up my-static-eth0
Check resolver file
cat /etc/resolv.conf
# Generated by NetworkManager
nameserver 8.8.8.8
nameserver 8.8.4.4
Test each server
dig @192.168.1.1 google.com
If it times out, address reachability first before changing DNS entries.
Temporary tests
Editing /etc/resolv.conf is useful for short tests, but changes may not persist on restart.
Key Takeaway

Make the change in NetworkManager, reactivate the connection, and then test with dig or host to confirm resolution works.
