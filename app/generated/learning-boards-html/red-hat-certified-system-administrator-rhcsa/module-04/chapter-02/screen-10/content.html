Troubleshooting

Checklist for resolution failures

1. Inspect resolver file
cat /etc/resolv.conf — ensure nameserver entries exist.
2. Network reachability
ping the DNS server IP to confirm it's reachable.
3. Targeted queries
dig @192.168.1.1 example.com — test each server directly.
4. Firewall
Ensure firewalld allows DNS traffic if filtering is in place.
5. DHCP vs static
If using DHCP, confirm the server provides correct DNS; otherwise set static DNS in the connection.
Key Takeaway

Work methodically from configuration to network to server to avoid changing the wrong component.
