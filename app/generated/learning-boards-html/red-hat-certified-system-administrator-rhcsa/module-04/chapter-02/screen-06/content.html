Definition

NetworkManager drives resolv.conf

NetworkManager populates /etc/resolv.conf from connection profiles. Edit the connection, not resolv.conf, for persistence.

Example nmcli changes
sudo nmcli connection modify my-static-eth0 ipv4.dns "8.8.8.8 8.8.4.4"
sudo nmcli connection up my-static-eth0
Misconception to avoid
Manually editing /etc/resolv.conf makes permanent changes — NetworkManager or DHCP may overwrite them.
Typical /etc/resolv.conf
# Generated by NetworkManager
search example.com
nameserver 8.8.8.8
nameserver 8.8.4.4
Key Takeaway
For stable DNS configuration, set DNS on the NetworkManager connection profile and reactivate the connection to apply changes.
