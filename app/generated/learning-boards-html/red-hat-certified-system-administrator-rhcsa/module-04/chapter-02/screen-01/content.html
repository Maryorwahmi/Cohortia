Configuring DNS and NTP Services

Learn how RHEL resolves hostnames, configure DNS persistently with NetworkManager, use dig and host for troubleshooting, and synchronize time with chronyd so services behave predictably.

In this lesson
DNS client config, dig/host troubleshooting, chronyd setup and verification.
Why it matters
Name resolution and accurate time are prerequisites for updates, auth, and distributed apps.
Coming up
Hands-on nmcli, dig examples, chronyc verification.
Module map
This chapter prepares you to configure and troubleshoot DNS and keep system time correct with chronyd.
Visual concept
DNS resolver queries name servers
chronyd syncs system clock

Explore Key Topics
DNS configuration
Use nmcli to set DNS servers and avoid editing /etc/resolv.conf directly.
Troubleshooting
Use dig and host to inspect names and test specific DNS servers when things fail.
Time sync with chrony
Configure /etc/chrony.conf, enable chronyd, and verify with chronyc sources and tracking.
