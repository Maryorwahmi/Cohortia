Module 4 › Chapter 4.3 › Key Concepts
SSH (Secure Shell)
A cryptographic protocol for secure remote administration and file transfer.
SSH Key-based Authentication
Uses a private/public key pair; the public key goes in authorized_keys and the private key remains local and protected.
scp / sftp
Secure file transfer tools that run over SSH; scp for quick copies, sftp for interactive sessions.
Final takeaway: combine key-based client setup with careful sshd configuration and permission hygiene to maintain secure, recoverable remote access on RHEL.
