Checklist

Permission checks

  • Home directory should not be world-writable.
  • ~/.ssh directory mode: 700 (drwx------).
  • ~/.ssh/authorized_keys file mode: 600 (-rw-------).
  • Files must be owned by the user who logs in.
Troubleshooting
ls -ld ~
ls -ld ~/.ssh
ls -l ~/.ssh/authorized_keys
# Fix permissions:
chmod 700 ~/.ssh
chmod 600 ~/.ssh/authorized_keys
chown user:user ~/.ssh -R
Common error
Overly permissive permissions cause sshd to ignore authorized_keys and fall back to passwords.
