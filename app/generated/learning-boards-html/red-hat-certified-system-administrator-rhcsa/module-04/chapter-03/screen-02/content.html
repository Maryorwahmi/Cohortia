Learning Objectives

Bloom: Learn → Understand → Apply → Master

Bloom band
Learn
Understand

Master
01
Establish secure SSH connections
Practice ssh username@host, verify host key fingerprints, and confirm the known_hosts entry. Verified competency: connect without unknown-host prompts after fingerprint check.
VERIFIED COMPETENCY MILESTONE
02
Generate and protect key pairs
Use ssh-keygen to create a private/public key pair and secure the private key with a passphrase. Milestone: private key is passphrase protected and stored under ~/.ssh.
VERIFIED COMPETENCY MILESTONE
03
Transfer files securely
Use scp for quick copies and sftp for interactive file sessions. Milestone: transfer a file both to and from the server using scp or sftp.
VERIFIED COMPETENCY MILESTONE
04
Harden the sshd server
Edit /etc/ssh/sshd_config to disable password auth and root login, test changes, and restart sshd safely. Milestone: password auth denied and root login refused when tested.
VERIFIED COMPETENCY MILESTONE
