Module 4 › Chapter 4.3 › Password vs Keys
Password Authentication

Pros and cons

  • Easy to set up and familiar to users.
  • Vulnerable to brute-force and credential theft.
  • Less suitable for automation without additional controls.
Key-based Authentication

Pros and cons

  • Private key never sent over the network; stronger against guessing.
  • Requires key generation, secure storage, and passphrase management.
  • Well-suited for automation when combined with secure agents.
Misconception
Moving to a non-standard port or using keys does not remove the need for correct permissions and backups. Always test hardening changes from a separate terminal session before closing your working session.
