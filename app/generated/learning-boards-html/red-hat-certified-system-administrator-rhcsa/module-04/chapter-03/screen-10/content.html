Configuration

Important sshd directives

PasswordAuthentication no
Forces key-based authentication only. Verify your keys work first to avoid lockout.
PermitRootLogin no
Disables direct root SSH login. Use an unprivileged user then sudo for admin tasks.
AllowUsers / AllowGroups
Limit SSH access to specific accounts or groups to reduce the set of valid logins.
Commands
# Edit sshd_config, then restart:
sudo vi /etc/ssh/sshd_config
# Example lines to add or modify:
# PasswordAuthentication no
# PermitRootLogin no
# Port 2222

sudo systemctl restart sshd
Safety note
Always back up sshd_config and test from a separate client before closing your current session.
