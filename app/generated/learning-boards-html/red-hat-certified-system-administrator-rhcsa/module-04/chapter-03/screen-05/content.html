Module 4 › Chapter 4.3 › Connecting with ssh
Process Flow

Start a secure session

Follow these steps each time you connect to ensure identity and safety.

  1. Run ssh username@server_ip_or_hostname.
  2. On first connect, verify the host key fingerprint against a trusted source.
  3. If valid, accept to add it to ~/.ssh/known_hosts for future checks.
  4. Authenticate with password or key-based method.
Common mistake
Accepting an unknown fingerprint without verification risks man-in-the-middle attacks.
Command example
ssh username@server_ip_or_hostname
# Example prompt on first connect:
# The authenticity of host 'server' can't be established.
# RSA key fingerprint is SHA256:ABC123... Do you want to continue connecting (yes/no)?
known_hosts
Stores server public key fingerprints so subsequent connections can detect unexpected changes.
Verification
When fingerprints change, pause and confirm before connecting; it may indicate a replaced server key or an active attack.
