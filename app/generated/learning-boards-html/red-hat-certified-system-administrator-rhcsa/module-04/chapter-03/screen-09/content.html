Module 4 › Chapter 4.3 › scp & sftp
Code Walkthrough

scp: secure one-shot copies

scp /path/to/local/file username@server:/path/to/remote/directory
scp username@server:/path/to/remote/file /path/to/local/directory
# Example:
scp ./backup.tar.gz alice@10.0.0.5:/home/alice/backups
sftp: interactive transfers
sftp username@server
# Inside sftp: ls, cd, put, get
# Example:
# sftp> put localfile /remote/path
# sftp> get /remote/file localdir
Practical checks
  • After transfer, verify file size and owner on the server.
  • Use checksums if integrity is critical.
  • Prefer sftp for interactive directory exploration and permission checks.
Key Takeaway
scp and sftp operate over SSH. Use the mode that fits your workflow while always verifying transferred files.
