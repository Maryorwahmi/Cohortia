Core Concept

SSH: secure remote channel

SSH provides encrypted authentication and a protected session for command-line administration and file transfer.

Administrator responsibilities
  • Protect private keys with passphrases and safe file permissions.
  • Verify host keys when connecting to new servers.
  • Harden server sshd configuration to reduce the attack surface.
Analogy

SSH as a locked tunnel

Think of SSH as a locked tunnel between your workstation and the server. Authentication proves identity; encryption keeps traffic private.

Concrete example
ssh username@server_ip_or_hostname
# Verify host fingerprint on first connect
# Then authenticate and receive a remote shell
Key Takeaway

SSH is not convenience only; it is the secure foundation for remote admin. Configure it carefully and verify changes.
