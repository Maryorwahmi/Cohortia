Module 4 › Chapter 4.3 › Copy Public Keys
Process

Install your public key on the server

Use ssh-copy-id or a manual pipeline to place the public key into authorized_keys with secure permissions.

ssh-copy-id
ssh-copy-id -i ~/.ssh/id_ed25519.pub username@server_ip
# Appends the public key to ~/.ssh/authorized_keys on the server
Manual alternative
cat ~/.ssh/id_ed25519.pub | ssh username@server_ip "mkdir -p ~/.ssh && chmod 700 ~/.ssh && cat >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys"
Permissions checklist
  • ~/.ssh directory = 700 (drwx------)
  • ~/.ssh/authorized_keys = 600 (-rw-------)
  • User home directory should not be world-writable
Key Takeaway
If SSH still asks for a password after installing a key, check authorized_keys content and file permissions first.
