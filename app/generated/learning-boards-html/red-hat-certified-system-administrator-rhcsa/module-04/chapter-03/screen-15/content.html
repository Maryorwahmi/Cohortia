Module 4 › Chapter 4.3 › Quick Reference
Verify host fingerprint
Confirm the fingerprint on first connect against a trusted source to prevent man-in-the-middle attacks.
Protect private keys
Use a passphrase and proper file permissions so a stolen key cannot be used directly.
Test sshd changes
Back up sshd_config and test from another client before restarting to avoid lockout.
Use these reminders as a short checklist whenever you manage SSH access on RHEL.
