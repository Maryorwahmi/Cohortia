Module 4 › Chapter 4.3 › Generate SSH keys
Definition & Process

Create and protect key pairs

Use ssh-keygen, choose a strong algorithm, and secure the private key with a passphrase.

Command example
ssh-keygen -t ed25519 -b 4096 -C "your_email@example.com"
# Press Enter to accept default location: ~/.ssh/id_ed25519
# Set a strong passphrase when prompted
Private key
Keep this file secret and set permissions to 600. Use a passphrase and ssh-agent when needed.
Public key
This file is copied to the server's ~/.ssh/authorized_keys to enable key-based login.
Check & Example
After generation, verify files:
ls -l ~/.ssh
# Expect files like:
# -rw------- 1 user user  411 id_ed25519
# -rw-r--r-- 1 user user  102 id_ed25519.pub
Key Takeaway

Use ssh-keygen to produce a private/public key pair, secure the private key, and confirm files and permissions before use.
