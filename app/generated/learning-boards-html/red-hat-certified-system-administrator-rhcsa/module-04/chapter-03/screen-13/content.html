Practice scenarios

Disable password & root login
# In /etc/ssh/sshd_config
PasswordAuthentication no
PermitRootLogin no
# Apply changes:
sudo systemctl restart sshd
Key continues to fail
Check permissions and ownership of ~/.ssh and authorized_keys. Use journalctl -u sshd for detailed errors.
Exam tip
Answer with the configuration change, the command to apply it, and a short verification step such as attempting a key-based login or checking sshd logs.
