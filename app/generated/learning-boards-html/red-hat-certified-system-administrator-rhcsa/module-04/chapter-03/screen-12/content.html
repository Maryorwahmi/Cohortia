Hands-on Activity

Step-by-step

1. Generate keys
ssh-keygen -t ed25519 -b 4096 -C "your_email@example.com"
2. Install public key
ssh-copy-id -i ~/.ssh/id_ed25519.pub username@server_ip
3. Test login
ssh username@server_ip
# You should be prompted for private key passphrase
4. Backup & edit sshd_config
sudo cp /etc/ssh/sshd_config /etc/ssh/sshd_config.bak
sudo vi /etc/ssh/sshd_config
# Set PasswordAuthentication no
# Set PermitRootLogin no
Safety step
Keep an open session and test from a separate terminal before restarting sshd. If you change Port, update the firewall and test with ssh -p.
Final check
After restart, confirm key login works and that password and root logins are denied. If problems occur, restore the backup and re-evaluate permissions and authorized_keys.
