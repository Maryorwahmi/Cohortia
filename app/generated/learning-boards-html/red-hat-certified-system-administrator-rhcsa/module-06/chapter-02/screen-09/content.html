Module 6 › Chapter 6.2 › Web app scenario
Symptom

After deploying files to a non-standard web path, Apache refuses to serve them even with correct UNIX perms.

Investigate
ls -Z /opt/mywebapp
# Look for object_r:default_t or another non-httpd type
sudo journalctl -xe | grep "SELinux"
Quick fix (test)
sudo chcon -Rt httpd_sys_content_t /opt/mywebapp
# Test access; not persistent
Persistent fix
sudo semanage fcontext -a -t httpd_sys_content_t "/opt/mywebapp(/.*)?"
sudo restorecon -Rv /opt/mywebapp
