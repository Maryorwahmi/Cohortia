How you will practice each objective

This slide maps objectives to terminal tasks for lab verification.

Mode verification
Use sestatus and setenforce

Confirm mode, run a test in Permissive if needed, then return to Enforcing.

Mnemonic: check → test → restore
Read contexts
ls -Z and ps -eZ

Identify type fields to determine why a process or file is allowed or denied access.

Booleans
getsebool -a and setsebool -P

Use booleans to enable common capabilities without custom rules.

Troubleshooting
journalctl and audit2allow

Inspect AVC denials, try restorecon, and only create modules after careful review.
