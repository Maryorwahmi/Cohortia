Module 6 › Chapter 6.2 › SELinux modes
Enforcing

Policy is enforced; denials are blocked and logged. Default for secure systems.

Permissive

Policy not enforced but denials are logged. Useful to identify what would break.

Disabled

SELinux is off. Requires reboot to change; not recommended for production.

Quick commands
sestatus
sudo setenforce 0   # Permissive
sudo setenforce 1   # Enforcing
# For permanent change, edit /etc/selinux/config and reboot
Practical rule

Test policy fixes in Permissive to collect logs, then switch to Enforcing after validation. Avoid prolonged Permissive states.
