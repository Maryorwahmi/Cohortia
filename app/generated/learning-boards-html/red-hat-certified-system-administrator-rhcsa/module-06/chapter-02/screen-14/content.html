SELinux (MAC)
A mandatory access control system that enforces policy using labels.
Enforcing mode
Policy is applied and denials are blocked and logged.
Security context
Labels like user:role:type:level; type is crucial for daily admin tasks.
Summary takeaway

Check types and modes first; toolset: ls -Z, ps -eZ, restorecon, semanage fcontext, getsebool, setsebool, and careful use of audit2allow.
