restorecon
Reset contexts to policy defaults; use -Rv for recursive verbose application.
semanage fcontext
Register persistent path mappings so restorecon applies the correct types.
audit2allow & semodule
Generate and install modules from AVCs, but review source before installing.
Final takeaway

SELinux adds a critical safety net. Learn to read contexts, use booleans, prefer persistent semanage fixes, and only generate custom modules after careful review.
