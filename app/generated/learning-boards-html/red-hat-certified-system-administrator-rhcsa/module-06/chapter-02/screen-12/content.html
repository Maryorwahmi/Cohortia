Module 6 › Chapter 6.2 › AVC & audit2allow
Find AVC denials
# Recent SELinux denials in journal
sudo journalctl -xe | grep "SELinux"

# Or inspect audit log
sudo grep AVC /var/log/audit/audit.log | tail -n 50
Generate a module (careful)
sudo grep "SELINUX_ERR" /var/log/audit/audit.log | audit2allow -M mywebserver
sudo semodule -i mywebserver.pp
Safety tips
  • Prefer booleans or semanage/restorecon before custom modules.
  • Review generated .te source; ensure rules are minimal.
  • Test in Permissive and then apply in Enforcing after validation.
