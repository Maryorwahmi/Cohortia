Module 6 › Chapter 6.2 › Mode commands
Terminal demo
$ sestatus
SELinux status:                 enabled
SELinuxfs mount:                /sys/fs/selinux
SELinux root directory:         /etc/selinux
Current mode:                   enforcing
Target mode:                    enforcing

$ sudo setenforce 0   # put system in Permissive temporarily
$ sudo setenforce 1   # return to Enforcing

# Permanent change (requires reboot): edit /etc/selinux/config
# SELINUX=enforcing  or  SELINUX=permissive  or  SELINUX=disabled
Tip

Collect logs while in Permissive, then address denials and validate before returning to Enforcing.

Misconception

setenforce is temporary. If you expect permanence, update /etc/selinux/config and reboot.
