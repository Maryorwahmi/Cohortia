Module 6 › Chapter 6.2 › SELinux Booleans

Booleans: quick control switches

Use to enable policy features without writing new rules.

List booleans
getsebool -a | grep httpd
Toggle example
# Enable for current session
sudo setsebool httpd_can_network_connect on
# Persist change across reboots
sudo setsebool -P httpd_can_network_connect on
Operator note

Check booleans before crafting custom rules; booleans cover many common needs while keeping policy manageable.
