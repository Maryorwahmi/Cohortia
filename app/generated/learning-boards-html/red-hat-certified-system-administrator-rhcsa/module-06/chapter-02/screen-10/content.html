Module 6 › Chapter 6.2 › Context management

Tools and intent

Select chcon for quick tests, semanage for persistent mappings, restorecon to apply defaults.

chcon

Quick, immediate context change. Not persistent across relabels.

semanage fcontext

Register a persistent mapping for a path so restorecon knows the correct type.

restorecon

Apply default or registered contexts to files and directories recursively when needed.

# Test access quickly
sudo chcon -Rt httpd_sys_content_t /opt/mywebapp

# Make mapping persistent, then apply
sudo semanage fcontext -a -t httpd_sys_content_t "/opt/mywebapp(/.*)?"
sudo restorecon -Rv /opt/mywebapp
