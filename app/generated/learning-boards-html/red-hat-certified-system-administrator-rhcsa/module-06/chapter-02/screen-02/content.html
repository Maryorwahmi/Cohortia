Learning Objectives

Progress from explanation to applied troubleshooting and policy management.

Bloom: Learn → Understand → Apply → Master
01
Explain SELinux modes

Describe Enforcing, Permissive, and Disabled and when each is appropriate.

VERIFIED COMPETENCY MILESTONE
02
Interpret security contexts

Read user:role:type:level, focus on the type field to decide access behavior.

VERIFIED COMPETENCY MILESTONE
03
Manage SELinux booleans

Use getsebool and setsebool to alter policy behavior without custom modules.

VERIFIED COMPETENCY MILESTONE
04
Troubleshoot AVC denials

Use audit logs, restorecon, semanage fcontext, and audit2allow carefully to remediate denials.

VERIFIED COMPETENCY MILESTONE
