Module 6 › Chapter 6.2 › Security contexts
Definition

user:role:type:level

Each field has a role, but for system administration the type field is the primary tool for solving access problems.

Type examples

httpd_sys_content_t is for web files; httpd_t is the process domain for Apache. Matching types enable intended access patterns.

What to inspect

Use ls -Z to inspect file contexts and ps -eZ for process contexts. Compare types to see if policy allows the operation.

Analogy

Think of type as a service's job description. If a process's job doesn't include writing config files, policy blocks that write even if UNIX perms allow it.

Key Takeaway

When in doubt, check the type field first; it's the usual culprit for denials.
