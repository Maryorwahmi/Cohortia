Module 6 › Chapter 6.2 › Policy best practices

Manage policy safely

Document changes

Record semanage and setsebool -P changes in CMDB or runbooks so they can be audited and reproduced.

Minimize custom policy

Prefer booleans and fcontext entries; use audit2allow only after review.

Regular audits

List modules and contexts periodically: semodule -l and semanage fcontext -l to detect drift.

Testing

Validate changes in a test environment and use Permissive mode to collect evidence before altering policy.
