Core Concept Performance Bottlenecks

What a bottleneck is and why it matters

Understand the four resource classes and the specific metrics that indicate pressure on each. This prevents misdirected fixes and preserves system stability.

Resource Checklist
  • CPU: sustained high %user/%system, long run queue; use top/htop.
  • Memory: growing si/so in vmstat implies swapping and slowdown.
  • Disk I/O: high %util or avgqu-sz in iostat; long I/O wait times.
  • Network: high interface utilization or many sockets shown by ss.
Concrete analogy
Think of the system as a highway network: the CPU is a tollbooth lane, memory is parking for cars, disk is a ferry crossing with limited capacity, and network is the bridge bandwidth. Congestion at any one point slows all traffic.
Example metrics snippet
vmstat 1
procs -----------memory---------- ---swap-- -----io---- -system-- ------cpu-----
 r  b   swpd   free   buff  cache   si   so    bi    bo   in   cs us sy id wa st
 2  0  524288  102400  20480 5000000  0    100  0     1024  500 1000 30 10 50 10 0
The above shows swap-out activity (so) and non-zero run queue (r). This suggests combined memory pressure with runnable processes.
Key Takeaway

Always correlate multiple tools: a single metric can mislead. Use at least one tool for trends and one for process-level detail before acting.
