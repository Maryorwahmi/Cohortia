Module 6 › Chapter 6.5 › lsof Diagnostics
Essential lsof patterns
# list listening sockets and owning processes
sudo lsof -i -P -n

# find processes with deleted files
sudo lsof +L1

# who has /var/log/myapp.log open
sudo lsof /var/log/myapp.log
Flags: -P shows ports numerically, -n avoids DNS lookups, +L1 lists files with link count less than 1 (deleted).
Practical example
You rotated logs and removed the old file, but disk space didn't return. Run:
sudo lsof +L1 | grep /var/log
myapp   2345    root  log    8u   REG  8,1   10485760  /var/log/myapp.log (deleted)
Action: restart or gracefully ask process to close log; that releases space.
Pro Tip
Check owning PID and command line before killing. Prefer service restart if available to avoid lost state.
