Learning Objectives

Master monitoring and basic diagnostics to reduce downtime and preserve logs for postmortem analysis.

01
Identify Bottlenecks

Detect whether CPU, memory, disk I/O, or network is limiting performance. This helps you target fixes precisely and avoid unnecessary changes.

VERIFIED COMPETENCY MILESTONE
02
Use Monitoring Tools

Run top, htop, vmstat, iostat and ss to gather real‑time metrics. Knowing each tool’s focus prevents misreading broad system load as a CPU problem when it’s I/O.

VERIFIED COMPETENCY MILESTONE
03
Collect Diagnostics Safely

Gather dmesg, journal logs, strace and lsof output before forceful actions. This preserves clues about hardware or application failures.

VERIFIED COMPETENCY MILESTONE
04
Apply Simple Remedies

Terminate misbehaving processes gracefully and reconfigure applications based on evidence. Document changes and re‑measure to confirm improvement.

VERIFIED COMPETENCY MILESTONE
