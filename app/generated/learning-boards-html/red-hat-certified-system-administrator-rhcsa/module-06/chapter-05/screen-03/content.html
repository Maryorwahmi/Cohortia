Tools & Diagnostics

Practice interpreting each tool’s primary metric so you can quickly map symptoms to root cause.

Mnemonic Grid
top / htop — Processes & CPU
vmstat — si / so (swap signs)
iostat — %util / avgqu-sz
ss — sockets to PID mapping
Verification Tasks
  1. Run vmstat 1 and interpret si/so trend.
  2. Capture iostat -x 1 during heavy writes and note %util.
  3. Use ss -tunap to find processes with many connections.
