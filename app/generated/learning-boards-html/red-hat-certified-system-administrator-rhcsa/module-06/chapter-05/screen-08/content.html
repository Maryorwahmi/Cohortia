Process Flow ss & socket mapping

Find which process owns network connections

Use ss to identify heavy connection sources, then trace to PID and inspect the service.

Command example
ss -tunap
# Shows TCP/UDP sockets with PID and program name
# Look for many ESTAB lines or unexpected LISTEN sockets
If you find a suspicious PID, use lsof -p PID or lsof -i to inspect open sockets and file descriptors for that process.
Investigation checklist
  • Run ss -tunap and count established connections per PID.
  • Measure interface throughput with ip -s link or ifstat to confirm bandwidth pressure.
  • Correlate with service logs to see request patterns and whether connections are short-lived or persistent.
Why it matters

Identifying the owning process prevents you from blocking ports blindly and helps you tune service behavior or firewall rules appropriately.
