Definition vmstat — si / so

Observe swap trends to find memory pressure

vmstat is best used for observing trends; combine short samples to decide if swapping is sustained or transient.

Example vmstat output
vmstat 1
procs -----------memory---------- ---swap-- -----io---- -system-- ------cpu-----
 r  b   swpd   free   buff  cache   si   so    bi    bo   in   cs us sy id wa st
 1  0  1048576  65536  10240 2000000  0    120   0    2048  300  800 25 10 40 25 0
 0  0  1153432  45000  10240 1950000  50   110  0    1024  250  650 35 12 30 23 0
Here you see so and si non-zero across samples: the system is actively swapping which indicates insufficient RAM for current workloads.
Practical steps
  • Confirm persistent si/so with vmstat 1 for several samples.
  • Use top/htop to find processes using most memory.
  • Consider adding RAM, tuning swappiness, or optimizing the culprit application.
Common Mistake

Tweaking swap settings before identifying the root cause can mask memory leaks and delay proper remediation.
