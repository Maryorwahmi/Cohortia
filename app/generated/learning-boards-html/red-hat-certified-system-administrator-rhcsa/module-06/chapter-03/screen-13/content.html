Module 6 › Chapter 6.3 › Common Mistakes
Mistake
Disabling passwords before testing
Always verify key login from a separate terminal first.
Mistake
Wrong file permissions
Set ~/.ssh to 700 and authorized_keys to 600 immediately after transfer.
Mistake
Sharing private keys
Never share private keys; only distribute public keys to servers.
Key Takeaway

Adopt test-first processes and permission checks as part of your change routine to avoid the most common SSH hardening failures.
