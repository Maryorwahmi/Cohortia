Module 6 › Chapter 6.3 › ssh-agent & ssh-add
Common commands
eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_rsa
ssh-add -l   # list keys
ssh-add -d ~/.ssh/id_rsa  # remove key
Add keys once per session to avoid typing your passphrase for every connection. Consider locking your workstation or removing keys when leaving an untrusted environment. On servers, avoid running long-lived agents that keep keys available indefinitely.
Security trade-off
Agent convenience vs. exposure: keys in memory are accessible while the agent runs, so limit lifetime and scope.
Pro tip
Use ssh-add -t to add a key with a timeout if your client supports it, reducing window of exposure.
Key Takeaway

ssh-agent improves usability while keeping the private key encrypted on disk; manage agent lifetime and loaded keys to reduce risk.
