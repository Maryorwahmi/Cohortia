Module 6 › Chapter 6.3 › Restart & Verify
Checklist
  1. Keep your original admin session open as a rollback path.
  2. From another terminal, attempt a new SSH connection that will validate the change.
  3. Execute sudo systemctl restart sshd to apply changes.
  4. Test the new connection immediately; inspect logs on failure.
Useful commands
sudo systemctl restart sshd
journalctl -u sshd --since "5 minutes ago"
Troubleshoot
If login fails after restart, check permissions for ~/.ssh and authorized_keys, verify the public key is present, and review sshd logs for explicit rejection messages.
Operational tip

Automate backups of sshd_config before edits so you can quickly restore a known-good configuration if required.
