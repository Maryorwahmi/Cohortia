Module 6 › Chapter 6.3 › Client SSH Config
Sample config
# In ~/.ssh/config
Host prod-db-01
    Hostname <IP_ADDRESS_OF_PROD_DB_01>
    User dbadmin
    IdentityFile ~/.ssh/id_rsa_db
    Port 2222
Now run ssh prod-db-01 and ssh will use the specified hostname, user, key, and port automatically.
Best practices
  • Use IdentityFile to avoid ssh trying many keys and hitting rate limits.
  • Keep entries named clearly to avoid confusion across environments.
  • Do not store passphrases or plaintext secrets here; use ssh-agent instead.
Key Takeaway

A correct ~/.ssh/config reduces human error and ensures the intended key and port are used for each host.
