Activity: Implement and verify key-based SSH
Client steps
  1. ssh-keygen -t rsa -b 4096 -C "my_admin_key@myclient"
  2. eval "$(ssh-agent -s)" and ssh-add ~/.ssh/id_rsa
  3. ssh-copy-id adminuser@<REMOTE_SERVER_IP>
Server steps
  1. Edit /etc/ssh/sshd_config to set PasswordAuthentication no and PermitRootLogin no
  2. Optionally add AllowUsers adminuser
  3. sudo systemctl restart sshd and test from another session
Remember: keep one session open as a rollback path until you confirm the new settings allow expected access. If a test fails, verify permissions on ~/.ssh and authorized_keys before changing sshd_config back.
Example verification

Open a new terminal and run ssh adminuser@<REMOTE_SERVER_IP> to confirm you can connect with keys before making server hardening permanent.
