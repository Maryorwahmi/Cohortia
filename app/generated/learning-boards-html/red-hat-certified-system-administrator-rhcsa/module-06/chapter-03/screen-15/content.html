Module 6 › Chapter 6.3 › Key Concepts
ssh-copy-id
Quickly installs your public key and corrects permissions on the server.
sshd_config directives
PasswordAuthentication no, PermitRootLogin no, and AllowUsers restrict authentication methods and accounts.
ssh-agent / ssh-add
Holds decrypted keys in memory to avoid repeated passphrase entry during a session.
Closing summary

Harden SSH by combining key-based auth, permission controls, server directives, and agent management, and always verify changes from a separate session.
