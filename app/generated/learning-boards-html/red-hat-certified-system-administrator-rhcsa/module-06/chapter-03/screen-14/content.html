Module 6 › Chapter 6.3 › Key Concepts
SSH (Secure Shell)
A protocol for secure, encrypted remote access and file transfer.
Key-based authentication
Private key proves identity; public key on server verifies the match.
ssh-keygen
Create key pairs; include a comment and protect the private key with a passphrase.
Summary

Use keys, protect them, check permissions, and verify server changes from a separate session to harden remote access safely.
