Learning Objectives

Practical skills that secure remote access and keep you in control.

Bloom: Learn → Understand → Apply → Master
01
Implement key-based authentication
Generate an RSA key pair, protect the private key with a passphrase, and install the public key on the server to eliminate password authentication. VERIFIED COMPETENCY MILESTONE
02
Harden the SSH daemon
Edit /etc/ssh/sshd_config to disable password authentication and block direct root login, then restart sshd and verify connectivity. VERIFIED COMPETENCY MILESTONE
03
Use client config for convenience
Create ~/.ssh/config host entries to define username, identity file, and port so commands are simple and consistent. VERIFIED COMPETENCY MILESTONE
04
Manage key lifecycle and agents
Use ssh-agent and ssh-add to hold decrypted keys and know how to revoke or rotate keys if compromised. VERIFIED COMPETENCY MILESTONE
