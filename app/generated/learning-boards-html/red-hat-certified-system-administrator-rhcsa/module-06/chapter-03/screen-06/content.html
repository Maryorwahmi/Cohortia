Module 6 › Chapter 6.3 › Permissions & authorized_keys
Required modes
chmod 700 ~/.ssh
chmod 600 ~/.ssh/authorized_keys
# ensure home is not writable by group/others
If keys fail, check ownership and file modes. SSH often logs authentication rejections with messages pointing to insecure permissions; consult the system log to confirm the cause.
Diagnostic checklist
  • Is ~/.ssh owned by the user? (ls -ld ~/.ssh)
  • Are permissions 700 for ~/.ssh and 600 for authorized_keys?
  • Is the user's home directory not writable by group/others?
  • Are there duplicate keys or malformed lines in authorized_keys?
Example log
sshd[1234]: Authentication refused: bad ownership or modes for directory /home/adminuser
Key Takeaway

Correct ownership and strict modes are prerequisites for key authentication; fix permissions before assuming configuration errors.
