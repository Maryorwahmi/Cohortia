Module 6 › Chapter 6.3 › sshd Hardening
Directive
PasswordAuthentication no
Forces key-based authentication only; prevents brute-force password attempts.
PermitRootLogin no
Prevents direct root SSH. Use a regular user + sudo for administrative tasks.
AllowUsers / AllowGroups
Limit logins to specific users or groups for tighter access control and auditability.
Example edits
# In /etc/ssh/sshd_config
PasswordAuthentication no
PermitRootLogin no
AllowUsers adminuser alice
Restart required: sudo systemctl restart sshd. Test login from another terminal before closing your current session to avoid accidental lockout.
Common mistake

Editing sshd_config without a live test and restart often results in confusion; remember to restart and verify from a separate session.
