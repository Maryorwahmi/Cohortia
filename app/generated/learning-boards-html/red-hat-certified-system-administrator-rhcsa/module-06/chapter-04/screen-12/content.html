Module 06 › Chapter 6.4 › Hands-on activity
Step 1
Emit and inspect
Use logger to emit a message, then confirm it is visible in journalctl when filtered by programname.
logger -t mycustomservice "Test message"
journalctl -t mycustomservice --since "5 minutes ago"
Step 2
Add rsyslog rule and test
Add /etc/rsyslog.d/mycustomservice.conf, restart rsyslog, emit logger messages, and confirm file contents.
:programname, isequal, "mycustomservice" /var/log/mycustomservice.log
& stop
sudo systemctl restart rsyslog
logger -t mycustomservice "Another test"
Step 3
Create a logrotate file, run in debug, and force rotation to confirm archives and permissions.
sudo logrotate -d /etc/logrotate.d/mycustomservice
sudo logrotate -f /etc/logrotate.d/mycustomservice
ls -l /var/log/mycustomservice.log*
Key Takeaway

An end-to-end test proves that logs are collected, routed, and rotated without losing entries or leaving stale file handles.
