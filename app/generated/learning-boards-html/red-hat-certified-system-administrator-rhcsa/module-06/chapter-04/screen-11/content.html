Module 06 › Chapter 6.4 › logrotate example
Sample config
# /etc/logrotate.d/mycustomservice
/var/log/mycustomservice.log {
    daily
    rotate 5
    compress
    missingok
    notifempty
    create 0640 root root
    postrotate
        /usr/bin/systemctl kill -s HUP rsyslog.service > /dev/null 2&&1 || true
    endscript
}
This rotates daily, keeps five archives, compresses, and signals rsyslog so it reopens file handles and continues writing to the new file.
Test and debug
sudo logrotate -d /etc/logrotate.d/mycustomservice  # debug
sudo logrotate -f /etc/logrotate.d/mycustomservice  # force rotate
ls -l /var/log/mycustomservice.log*
Common mistake

Not testing postrotate hooks; services may continue writing to old file descriptors unless signaled properly.

Key Takeaway

Always run logrotate in debug, then force to confirm rotation behavior and file ownerships.
