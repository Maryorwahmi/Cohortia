Module 06 › Chapter 6.4 › rsyslog validation
Checklist
Safe restart and verification
  1. Validate config syntax or test on staging.
  2. Restart rsyslog: systemctl restart rsyslog.
  3. Emit test messages with logger and confirm they appear.
  4. If missing, check journalctl for rsyslog service errors and revert if needed.
Commands and checks
sudo systemctl restart rsyslog
logger -t mycustomservice "Check log"
sudo tail /var/log/mycustomservice.log
journalctl -u rsyslog.service --since "5 minutes ago"
Troubleshooting

If rsyslog fails, journalctl often shows the error and line number in the config file that needs correction.

Key Takeaway

Always validate and test to avoid silent log loss after configuration changes.
