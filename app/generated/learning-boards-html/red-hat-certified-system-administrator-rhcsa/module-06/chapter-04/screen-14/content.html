Module 06 › Chapter 6.4 › Key Concepts
systemd-journald
Structured, binary logs for advanced querying and boot-based inspection.
rsyslog
Routes messages, writes text files, and forwards logs for aggregation.
logrotate
Automates rotation, compression, and retention so logs do not exhaust disk space.
Summary

Use the right tool for each stage: journals for queries, rsyslog for persistent writing and forwarding, and logrotate for lifecycle management.
