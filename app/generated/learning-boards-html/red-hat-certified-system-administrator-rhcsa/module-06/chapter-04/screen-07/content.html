Module 06 › Chapter 6.4 › rsyslog configuration
Architecture
Files and flow
Main file: /etc/rsyslog.conf. Per-service rules: /etc/rsyslog.d/*.conf. Rules select messages using facility.priority and can route them to files, sockets, or remote servers.
Selector example
authpriv.* /var/log/secure
Best practice
Keep custom rules in /etc/rsyslog.d/ with clear naming, validate syntax, and test in a staging environment before applying to production.
Safety note

Incorrect rules can prevent messages from being recorded. Validate and restart carefully.

Key Takeaway

Organize rules, use selectors deliberately, and always test changes.
