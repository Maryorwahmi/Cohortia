Module 06 › Chapter 6.4 › Custom rsyslog rule
Goal
Route mycustomservice to its own log file
Write a rule in /etc/rsyslog.d/ that matches the programname and writes to /var/log/mycustomservice.log, then stops further processing.
Test by emitting messages with the logger utility and confirm they land in the dedicated file and not in /var/log/messages.
Example file
# /etc/rsyslog.d/mycustomservice.conf
:programname, isequal, "mycustomservice" /var/log/mycustomservice.log
& stop
Test steps
  1. Restart rsyslog: sudo systemctl restart rsyslog
  2. Emit a test message: logger -t mycustomservice "Test message"
  3. Check file: sudo cat /var/log/mycustomservice.log
Common mistake

Not signaling rsyslog or failing to check programname conventions, causing misrouted messages.

Key Takeaway

Use programname matching and stop to ensure dedicated logs and avoid duplication into global files.
