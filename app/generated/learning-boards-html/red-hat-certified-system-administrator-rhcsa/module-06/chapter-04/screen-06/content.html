Module 06 › Chapter 6.4 › Persistent journald
Process
Enable persistent journal storage
  1. Check existence of /var/log/journal to determine persistence.
  2. Create the directory with correct ownership and permissions if absent.
  3. Restart the systemd-journald service so it uses on-disk storage.
  4. Verify by checking logs across a reboot or looking for file growth.
Why it matters: persistent journals preserve audit trails and historical events that are crucial for post-incident analysis and compliance.
Commands
ls /var/log/journal
sudo mkdir -p /var/log/journal
sudo systemctl restart systemd-journald
journalctl -b -1
Common mistake

Assuming creating the directory alone is enough; restart journald and validate across a reboot to be certain.

Key Takeaway

Persisting journals ensures that logs remain available for later analysis and compliance checks.
