Core Commands
Common journalctl filters
  • Filter by time windows using the since and until options to limit scope.
  • Filter by unit to see a specific service's records for focused troubleshooting.
  • Use the priority selector to surface errors and critical messages during incidents.
  • The follow mode streams new entries in real time for active debugging.
Example scenario
Find SSH daemon errors in the last two hours and follow new messages as they arrive during a live troubleshooting session.
Command examples
journalctl --since "2 hours ago"
journalctl -u sshd.service
journalctl -p err
journalctl -b -1
journalctl -f
Common mistake

Assuming journal files are persistent across reboots; enable persistent storage to retain older boots.

Key Takeaway

Compose filters to reduce noise and focus on the right timeframe, unit, and severity.
