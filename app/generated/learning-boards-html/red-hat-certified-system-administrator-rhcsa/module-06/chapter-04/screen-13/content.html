Module 06 › Chapter 6.4 › Troubleshooting
Checklist
  • Confirm the emitter wrote a message and its programname or facility.
  • Search the journal to inspect fields used for selectors.
  • Verify rsyslog rules match the exact selector values and include a stop if needed.
  • Check file permissions and ownership for destination log files.
Checks
Use journalctl to view rsyslog service errors, and inspect /var/log/messages and the dedicated log file for duplicates. Confirm postrotate scripts signal rsyslog after rotation so new entries go into the fresh file.
Common misconception

Thinking only one layer is broken; logging issues often span emitter, collector, router, and rotation stages.
