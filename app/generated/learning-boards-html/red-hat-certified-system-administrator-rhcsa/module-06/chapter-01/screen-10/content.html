Module 6 › Chapter 6.1 › Rich Rules: Fine-Grained Policies
Rich rule example
sudo firewall-cmd --zone=public --add-rich-rule='rule family="ipv4" source address="192.168.1.100" service name="ssh" accept' --permanent
sudo firewall-cmd --reload
This accepts SSH only from the specified IPv4 address, reducing exposure of SSH to the internet.
When to use
  • Limit administrative access to known IPs.
  • Permit services only from certain networks.
  • Combine with services and ports for layered control.
Key Takeaway

Rich rules provide readable, expressive policies and should be the first choice for source-aware restrictions.
