Module 6 › Chapter 6.1 › Direct Rules: Low-Level Control
What direct rules do
They insert raw netfilter commands so you can implement policies not possible with rich rules. This gives maximum flexibility at the cost of complexity.
Use only when necessary
Operational caution
Because direct rules bypass some abstractions, they must be documented and tested. They can interact with higher-level rules unpredictably if not planned.
Warning

Avoid direct rules for routine access control; prefer rich rules for clarity and maintainability.
