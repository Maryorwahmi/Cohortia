Module 6 › Chapter 6.1 › Allowing Web and SSH Services
Commands to run
sudo firewall-cmd --zone=public --add-service=ssh --permanent
sudo firewall-cmd --zone=public --add-service=http --permanent
sudo firewall-cmd --zone=public --add-service=https --permanent
sudo firewall-cmd --reload

# verify
sudo firewall-cmd --zone=public --list-all
Run verification from another machine, for example attempt an HTTP request or an SSH connection, to confirm services are reachable.
Example verification
After reloading, you should see ssh, http, and https in the public zone. If a service is missing, confirm you ran the command with --permanent and reloaded.
Key Takeaway

Make persistent changes for production services and always verify from a second host to avoid locking yourself out.
