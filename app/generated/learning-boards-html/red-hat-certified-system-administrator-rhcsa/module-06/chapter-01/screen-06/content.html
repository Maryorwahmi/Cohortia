Module 6 › Chapter 6.1 › Services vs Ports
Services (intent)
Services group known ports. They make rules readable and reduce mistakes. Example: ssh maps to port 22 and its transport settings.
Use when: standard apps, clarity, multi-port services
Example command
sudo firewall-cmd --zone=public --add-service=http --permanent
sudo firewall-cmd --reload
Ports (precision)
Open an explicit port when an application uses a custom TCP or UDP port. This is exact and exposes only what you specify.
Use when: custom apps, nonstandard ports
Example command
sudo firewall-cmd --zone=public --add-port=8080/tcp --permanent
sudo firewall-cmd --reload
