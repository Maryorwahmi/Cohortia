These milestones move you from inspection to persistent configuration and advanced policy. Each objective maps to a verified competency you can test on a lab server.

01
Zones, services, ports
Identify zones and how services/ports map to them. Knowing this lets you apply the right trust profile to each interface.
VERIFIED COMPETENCY MILESTONE
02
Configure access
Use firewall-cmd to add and remove services or open specific ports so required services can communicate.
VERIFIED COMPETENCY MILESTONE
03
Runtime vs permanent
Understand temporary changes and how to persist them with --permanent plus reload to survive reboots.
VERIFIED COMPETENCY MILESTONE
04
Rich and direct rules
Implement restricted access using rich rules and know when to use direct rules for low-level control.
VERIFIED COMPETENCY MILESTONE
