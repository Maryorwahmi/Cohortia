Module 6 › Chapter 6.1 › Troubleshooting firewalld
Step-by-step checks
  1. Confirm application listens on expected port.
  2. sudo firewall-cmd --get-active-zones to find interface mapping.
  3. sudo firewall-cmd --zone=public --list-all to view rules.
  4. Temporarily stop firewalld to test if it blocks traffic, then restart.
  5. Review logs and repeat after adjustments.
Commands for diagnostics
sudo ss -tlnp        # check listening TCP ports
sudo firewall-cmd --get-active-zones
sudo firewall-cmd --zone=public --list-all
sudo systemctl stop firewalld   # diagnostic only
sudo systemctl start firewalld
Always restart firewalld immediately after a diagnostic stop to restore protection.
