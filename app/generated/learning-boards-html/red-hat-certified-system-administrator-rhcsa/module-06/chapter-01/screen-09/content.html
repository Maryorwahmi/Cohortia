Module 6 › Chapter 6.1 › Opening Custom Ports
Command example
sudo firewall-cmd --zone=public --add-port=8080/tcp --permanent
sudo firewall-cmd --zone=public --add-port=8443/tcp --permanent
sudo firewall-cmd --reload

# verify
sudo firewall-cmd --zone=public --list-all
If you prefer temporary testing, omit --permanent, test accessibility, then repeat with --permanent and reload if successful.
Scenario example
You host a web app on 8080 and an admin console on 8443. Open only those ports and use rich rules to restrict 8443 to trusted IPs when possible.
Misconception check

Do not assume a successful curl means the firewall was the only factor; verify the service listener and network routes too.
