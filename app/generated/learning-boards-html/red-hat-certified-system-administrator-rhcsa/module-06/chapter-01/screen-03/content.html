Commands to verify
  • sudo systemctl status firewalld — confirm the service is running
  • sudo firewall-cmd --get-active-zones — shows which zones are bound to interfaces
  • sudo firewall-cmd --zone=public --list-all — lists services, ports, and rich rules for a zone
Safe troubleshooting checklist
1. Confirm service is listening on expected port.
2. Check active zones and ensure rule is in correct zone.
3. Temporarily stop firewalld only for diagnostic purposes and restart immediately.
4. Use logs and firewall-cmd listings to trace policies.
