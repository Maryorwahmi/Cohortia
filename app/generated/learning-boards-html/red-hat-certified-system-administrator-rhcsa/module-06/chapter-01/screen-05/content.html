Module 6 › Chapter 6.1 › Using firewall-cmd
Common inspection commands
sudo systemctl status firewalld
sudo firewall-cmd --get-active-zones
sudo firewall-cmd --zone=public --list-all
Run these read-only checks first. They reveal which zone applies and what the current policy is before making changes.
Pro tip

If an interface moved zones after a cable change or NetworkManager update, your rules might be in a different zone than you intended.

Example output (annotated)
public
  interfaces: eth0
  sources: 
  services: ssh http https
  ports: 8080/tcp
  rich rules:
    rule family="ipv4" source address="192.168.1.100" service name="ssh" accept
This shows eth0 in the public zone, services allowed, an open custom port, and one rich rule restricting SSH to a single IP.
