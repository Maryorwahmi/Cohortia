Definition
Access Control Lists
ACLs let you specify permissions for particular users or groups without changing the file owner or primary group. They are additive and are indicated by a + in ls -l output.
Commands & example
# grant qa1 read and execute recursively
sudo setfacl -R -m u:qa1:rx /project/data

# allow developers group full access
sudo setfacl -R -m g:developers:rwx /project/data

# view ACLs
getfacl /project/data
Tip: Use -R with care. Overuse of ACLs across many files increases administrative overhead; prefer group ownership when possible.
