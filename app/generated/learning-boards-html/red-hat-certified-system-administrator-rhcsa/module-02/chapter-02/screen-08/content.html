Core Concept
chown and chgrp

chown user[:group] file — change the file owner and optionally the group.

chgrp group file — change only the group ownership.

Only root can change a file's user owner to a different user; group changes may be restricted to group members.

# set directory to root:developers
sudo chown root:developers /project/data

# change only group
sudo chgrp developers somefile.txt

# recursive change
sudo chown -R alice:developers /srv/project
Cards
When to use chown
Assign a new owner when responsibility for files changes, for example service accounts owning their config files.
When to use chgrp
Switch group ownership to enable team access without changing the file owner.
Pitfall
Changing ownership broadly can break service expectations; always verify with ls -l.
