Permissions
ls -l, sudo chmod u+x file, sudo chmod 755 file
Ownership
sudo chown alice:devs /path, sudo chgrp devs file, use -R when intentional
ACLs
sudo setfacl -m u:qa1:rx /project/data; getfacl /project/data
Final tip

Document every change and verify with ls -l and getfacl to ensure your policies behave as intended.
