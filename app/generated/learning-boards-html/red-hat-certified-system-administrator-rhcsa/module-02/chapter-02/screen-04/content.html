Core Concept
r, w, x — concrete meanings

File — read: view contents; write: change contents; execute: run as a program.

Directory — read: list names; write: create/delete entries; execute: traverse and access entries by name.

Misconception: listing file names (read) is not sufficient to open files without execute on the directory.

Key Takeaway

Treat directory execute as traversal permission; set directory bits intentionally to control access to contents.

Examples & analogy
File: script.sh — chmod 755
Owner: read/write/execute; others: read and execute. Necessary to run the script as a program.
Directory: /data — chmod 750
Owner: full; group: read+execute to view and traverse; others: none. Prevents public access while allowing group collaboration.
Analogy
Think of a directory as a locked hallway. Read shows the door names; execute opens the door to go inside.
