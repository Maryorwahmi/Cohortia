Step-by-step commands
# 1. create and set ownership
sudo mkdir -p /project/data
sudo chown root:developers /project/data

# 2. set SGID and permissions (owner root, group developers)
sudo chmod 2770 /project/data

# 3. grant QA read+execute recursively
sudo setfacl -R -m u:qa1:rx /project/data

# 4. verify
ls -ld /project/data
getfacl /project/data
Expected verification
ls -ld should show drwxrws--- and an s in the group execute position, indicating SGID.
getfacl should list an entry for u:qa1:rx confirming QA access.
Check common mistake: if nested files lack correct group, rerun chown -R before setting SGID or ACLs.
Reflect: did you reduce other access while preserving developer workflow? If not, adjust group membership rather than resorting to permissive others bits.
