Learning Objectives
Gain practical skills for secure access control on RHEL systems.
Bloom
Learn
Understand
Apply
Master
01
Interpret rwx for owner, group, others
You will read permission strings and explain what read, write, and execute mean for both files and directories. This matters because misinterpreting a string can leave data exposed or unusable.
Mnemonic: 3 sets = user, group, others.
Verified competency milestone
02
Change permissions with chmod (symbolic & octal)
You will perform common chmod commands and explain when to use symbolic versus octal notation for scripts and single fixes.
Mnemonic: symbolic for tweaks, octal for scripts.
Verified competency milestone
03
Change owners with chown and chgrp
You will reassign user or group ownership and understand when root privileges are required to do so safely.
Mnemonic: chown for user, chgrp for group.
Verified competency milestone
04
Use special bits and ACLs safely
You will set SUID, SGID, and sticky bits and use setfacl/getfacl for targeted access, balancing convenience and security.
Mnemonic: SGID for shared groups, sticky to protect uploads.
Verified competency milestone
