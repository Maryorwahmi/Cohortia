Process Flow
Reading the permission string

Type char: - (file) or d (directory). Then owner, group, others triplets: r w x. Special bits replace x with s or t.

Trailing plus indicates an ACL is set.

-rwsr-sr--  1 root root  14768 Jun  1 12:34 passwd
drwxrwxrwt 10 root root  4096 Jun  6 09:02 /tmp
-rw-r--r--+ 1 root root   234 Jun  2 08:00 config.conf
Example outputs: note s for SUID/SGID, t for sticky, and + for ACLs.
Explainer cards
Owner triplet
Controls what the file owner can do. Look here first when troubleshooting access for the file owner.
Group triplet
Group permissions enable team collaboration. SGID in this triplet affects newly created child files in directories.
Others triplet
Least-privilege zone. Keep these bits strict to avoid exposing data to all users.
Quick check: the presence of '+' after the mode means ACLs exist and may override or supplement the basic bits.
