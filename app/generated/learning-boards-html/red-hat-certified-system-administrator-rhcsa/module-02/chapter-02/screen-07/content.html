Comparison
Octal vs Symbolic
  • Octal is concise and reproducible in scripts.
  • Symbolic is readable and safer for small interactive tweaks.
  • Use a leading octal for SUID/SGID/sticky bits.
# common examples
sudo chmod 755 script.sh   # rwxr-xr-x
sudo chmod 644 document.txt # rw-r--r--

# set SGID on a dir and allow owner/group full access
sudo chmod 2770 /project/data  # rwsrwx--- (2 for SGID)
Quick mental map
Values
4=read, 2=write, 1=execute. Sum per entity.
Leading digit
4=SUID, 2=SGID, 1=sticky. e.g., 4755 sets SUID.
Pro tip
When scripting, prefer octal for repeatable environments; document the meaning in comments.
