Definition
Symbolic chmod

Format: [u|g|o|a][+|-|=][r|w|x]. Combine with commas for multiple operations.

Useful for quick human-readable edits and scripts that should be self-describing.

# add execute for owner
sudo chmod u+x script.sh

# remove all permissions for others on a directory
sudo chmod o-rwx /srv/secret

# add read+write for user and group, remove others
sudo chmod ug+rw,o-r file.txt
Explanation cards
Operator types
+ adds, - removes, = sets exact permissions overwriting previous bits.
Common pitfall
Using = unintentionally removes other bits. Audit before running bulk changes.
Pro tip
Use symbolic mode in interactive work and octal in scripts where compactness matters.
Remember to use -R when you want recursive application to a directory tree.
