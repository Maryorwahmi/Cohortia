Module 2 › Chapter 2.2 › Key Concepts
Least privilege
Grant only needed permissions; prefer restrictive others bits and group-based access.
Right tool for the job
Symbolic for interactive fixes, octal for scripts, ACLs for specific user exceptions.
Audit special bits
Review SUID/SGID and sticky bits regularly; remove or restrict them if not required.
Summary takeaway

Combine owner/group bits, special bits, and ACLs thoughtfully to balance collaboration and security; verify with ls -l and getfacl.
