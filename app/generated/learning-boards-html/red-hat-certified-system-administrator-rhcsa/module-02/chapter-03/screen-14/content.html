Module 3 › Chapter 2.3 › What to Remember
Create explicitly
Use -m, -s, -c, -g when creating users to avoid surprises.
Append groups
Use usermod -aG to add supplementary groups safely.
Edit sudo safely
Use visudo and prefer group entries like wheel; avoid NOPASSWD unless justified.
Final takeaway
Operational discipline — explicit commands, verification, and safe edits — prevents common account-management errors and keeps systems secure.
