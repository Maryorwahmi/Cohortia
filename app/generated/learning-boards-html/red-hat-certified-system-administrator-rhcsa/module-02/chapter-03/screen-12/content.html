Hands-on Activity

Onboard Alice and Bob

Execute these commands in sequence, then run verification commands to confirm state.

sudo groupadd developers

sudo useradd -m -s /bin/bash -c "Alice Admin" alice
sudo passwd alice
sudo usermod -aG wheel alice

sudo useradd -m -s /bin/bash -c "Bob Developer" -g developers bob
sudo passwd bob

# verification
id alice
id bob
grep developers /etc/group
Tips
Run commands with sudo and avoid scripting passwords in plain text. Use chage -d 0 to force initial password change if desired.
Common mistake
Omitting -a when adding groups removes existing memberships. Always append with -aG.
Key Takeaway

Provision accounts, set passwords, add necessary groups, and verify with id and /etc/group entries immediately.

Try this in your lab
Practice the sequence on a throwaway VM. After onboarding, test sudo by running sudo ls /root as alice. If sudo fails, check wheel membership and the sudoers file via visudo.
