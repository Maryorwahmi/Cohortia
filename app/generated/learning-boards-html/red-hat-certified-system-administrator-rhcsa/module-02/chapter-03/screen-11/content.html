Definition

Sudo and visudo basics

Use visudo to edit /etc/sudoers safely. Grant rights with group entries to avoid editing many individual lines.

Common entries
# allow wheel group to run any command
%wheel ALL=(ALL) ALL
# allow wheel members to run any command without password
%wheel ALL=(ALL) NOPASSWD: ALL
Example workflow
Add alice to wheel: sudo usermod -aG wheel alice. Edit sudoers with sudo visudo and verify with sudo -l as the user.
Misconception
Giving NOPASSWD: ALL is convenient but reduces accountability. Prefer least privilege and command-specific entries where possible.
Key Takeaway

Use visudo for safe edits and prefer group-based sudo entries to manage elevated privileges centrally.
