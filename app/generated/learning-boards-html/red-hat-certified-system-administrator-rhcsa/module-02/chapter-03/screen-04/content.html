Core Concept

useradd usage and examples

Create a user with options to ensure a home directory, default shell, comment, and primary group for predictable permissions.

Command example
sudo useradd -m -s /bin/bash -c "Jane Doe" -g developers jane.doe
sudo passwd jane.doe
Common mistake
Omitting -m leaves no home directory; omitting -g can create an unexpected private group. Verify with id and ls -ld /home/username.
Pro tip
Make scripts explicit about shell and group choices so provisioning is predictable across systems.
What to verify
  • id jane.doe shows UID, primary group, and supplementary groups.
  • ls -ld /home/jane.doe confirms ownership and permissions.
  • cat /etc/passwd | grep jane.doe shows the shell and home path fields.
Key Takeaway

Always create accounts with the options required for immediate use and run verification commands to confirm correct setup.
