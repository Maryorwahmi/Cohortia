Tasks & Files to Practice

Account lifecycle
  • Create with useradd and set home, shell, and primary group.
  • Set password with passwd and verify login works.
  • Remove with userdel -r to remove home and mail spool.
Group & sudo management
  • Create and modify groups with groupadd and groupmod.
  • Add users to supplementary groups with usermod -aG.
  • Configure sudo via visudo and group entries like wheel.
Inspect system files

Use cat and grep to read /etc/passwd, /etc/shadow (root only), and /etc/group to confirm account metadata and membership.

Verification commands
Practice: id username, grep username /etc/passwd, grep groupname /etc/group to confirm changes.
