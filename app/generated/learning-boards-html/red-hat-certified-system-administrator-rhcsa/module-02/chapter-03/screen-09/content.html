Definition

Password management essentials

Set initial passwords, require change on first login when needed, and enforce strength with pam_pwquality settings in PAM configuration files.

Commands
sudo passwd bob
# lock an account
sudo passwd -l compromised_user
# force change on first login
sudo chage -d 0 newuser
Security note
Never transmit plaintext passwords in scripts or logs. Use vaulting for automation and force password change at first login.
Misconception
passwd does not enforce system policy by itself; PAM configuration determines allowed password complexity.
Key Takeaway

Enforce password strength via PAM and avoid insecure handling of plaintext passwords in automation.
