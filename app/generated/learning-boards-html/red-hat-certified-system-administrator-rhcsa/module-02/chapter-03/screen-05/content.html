Definition

UIDs and GIDs explained

Numeric identifiers are how the kernel tracks ownership. Names map to IDs in configuration files but are secondary to the kernel’s view.

Primary group
Controls default group ownership of new files; assigned at account creation and recorded as GID in /etc/passwd.
Supplementary groups
Grant additional permissions across shared resources, added using usermod -aG.
Inspecting IDs
id alice
# sample output: uid=1001(alice) gid=1001(alice) groups=1001(alice),1002(developers)
Analogy
Think of UIDs/GIDs like employee ID numbers. A name may change but the ID is how payroll and access systems recognize the person.
Common mistake
Assuming renaming a group updates ownership on disk; ownership follows numeric IDs, so ensure GIDs and memberships are consistent when migrating data.
Key Takeaway
Always verify numeric IDs when moving files between systems to avoid access surprises.
