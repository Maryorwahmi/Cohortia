Definition

Group management commands

  • sudo groupadd project_alpha — create a new group
  • sudo groupmod -n project_beta project_alpha — rename a group
  • sudo groupdel project_beta — remove a group after verifying members
Example
Create a developers group, add bob: sudo groupadd developers; sudo usermod -aG developers bob; verify with grep developers /etc/group.
Checklist before delete
Confirm no user has the group as primary, reassign ownership of files with find and chown if needed, then groupdel.
Key Takeaway

Groups scale access management: change group membership to change access for many users at once.
