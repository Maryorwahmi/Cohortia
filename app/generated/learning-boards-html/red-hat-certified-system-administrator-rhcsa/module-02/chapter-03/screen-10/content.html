Core Concept

Key account and group files

  • /etc/passwd — user account fields (username, UID, GID, home, shell)
  • /etc/shadow — restricted password hashes and aging, readable only by root
  • /etc/group — group definitions and member lists
Example entries
jane.doe:x:1002:1002:Jane Doe:/home/jane.doe:/bin/bash
# /etc/shadow has hashed passwords and is root-only
developers:x:1002:bob,alice
Warning
Editing these files manually can break authentication. Use vipw and vigr or the user/group utilities to make changes safely.
Key Takeaway

View configuration files to inspect state, but prefer utilities for modifications to avoid syntax and locking issues.
