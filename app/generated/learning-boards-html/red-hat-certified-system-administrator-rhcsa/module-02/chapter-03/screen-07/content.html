Process Flow

Safely removing a user account

  1. Archive files: sudo tar -czf /var/archives/olddev-home.tgz /home/olddev
  2. Verify archive integrity and move to secure storage.
  3. Delete account and home: sudo userdel -r olddev
  4. Confirm removal: grep olddev /etc/passwd and find / -uid UID
Common mistake
Running userdel without -r leaves homes and mail spools, which can contain sensitive data and waste disk space.
Alternative: disable first
If unsure, lock the account with sudo passwd -l username or set shell to /sbin/nologin until you confirm data preservation policies.
Key Takeaway

Always archive and verify before deleting accounts and use userdel -r when you intend to remove the home and mail spool.
