Process Flow

Common usermod operations

  1. Append to supplementary groups: sudo usermod -aG sales,marketing jane.doe
  2. Change login shell: sudo usermod -s /bin/zsh jane.doe
  3. Move home directory: sudo usermod -d /home/newdir -m jane.doe
  4. Rename account: sudo usermod -l newname oldname
Pitfall
user﻿mod -G list without -a replaces memberships. That can remove access unexpectedly.
Example
sudo usermod -aG developers,git bob
sudo usermod -s /bin/bash bob
sudo usermod -d /home/bob_new -m bob
Verify
Run id bob and grep bob /etc/passwd to confirm shell and home directory changes.
Key Takeaway
Use usermod for safe in-place changes and always verify the result to avoid accidental loss of group memberships.
