Module 2 › Chapter 2.1 › Pitfalls & Recovery
Common Pitfalls
  • Formatting the wrong device due to mis-identified /dev names.
  • Editing /etc/fstab with incorrect UUIDs or mount points and rebooting.
  • Extending LV but not growing the filesystem.
Recovery steps
If fstab breaks boot, use rescue mode to edit /etc/fstab. If a wrong device was formatted, restore from backup. If lvextend fails, check vgdisplay and free extents.
Safety Reminder
Back up before destructive operations. Test commands in a disposable VM first. Prevention is far easier than recovery.
