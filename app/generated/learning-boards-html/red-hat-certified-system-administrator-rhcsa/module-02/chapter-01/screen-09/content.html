Definition
PV, VG and LV explained
Physical Volumes are disks or partitions initialized for LVM. Volume Groups pool those PVs into free space. Logical Volumes are carved from VGs and formatted with file systems.
pvcreate
Initialize /dev/sdc as a physical volume so LVM can manage it.
vgcreate
Combine PVs into a volume group like vg_data, which provides a pool of extents.
lvcreate
Carve a logical volume from the VG, create a filesystem, and mount it just like a partition.
Example commands
sudo pvcreate /dev/sdc
sudo vgcreate vg_data /dev/sdc
sudo lvcreate -L 10G -n data_lv vg_data
sudo mkfs.xfs /dev/vg_data/data_lv
sudo mount /dev/vg_data/data_lv /mnt/data
