Core Concept
MBR and GPT compared
MBR is limited to 2TB and four primary partitions. GPT supports larger disks and many partitions and is the recommended modern format for new systems. Choose the correct tool: fdisk for MBR, gdisk for GPT.
Common mistakes
  • Using fdisk on a 3TB disk may produce partitions that cannot use full capacity.
  • Not checking existing partition start/end sectors can cause overlaps.
  • Forgetting to set the correct type flags for special partitions like BIOS boot or EFI.
Comparison
Visual summary
fdisk vs gdisk
MBR (fdisk)
Up to 4 primary partitions, 2TB limit, legacy boot compatibility, use when required by older systems.
Example: Small boot-only media or legacy appliances.
GPT (gdisk)
Supports many partitions and disks larger than 2TB, required for modern large-volume servers and new installations.
Example: Use gdisk on a 3TB backup disk to access full capacity.
Quick verification commands
sudo fdisk -l /dev/sdb
sudo gdisk -l /dev/sdb
sudo parted -l
These commands show the partition table type and sizes so you can confirm the correct tool before creating partitions.
Key Takeaway
Prefer GPT for disks over 2TB. Use fdisk only for MBR/legacy scenarios and always verify the table type before writing changes.
