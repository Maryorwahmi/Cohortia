Verification & Safety

Develop repeatable checks that protect data during partitioning, formatting, and resizing workflows.

Confirm devices and UUIDs
Use block listing and blkid to confirm the correct disk and its UUID before editing /etc/fstab or running mkfs.
Mnemonic: See it, then change it
Test fstab with mount -a
After updating /etc/fstab run mount -a to catch syntax errors without rebooting. Fix errors before a production restart.
Mnemonic: Test, then trust
Check LVM state before changes
Use vgdisplay and lvdisplay to see free extents and current sizes. Never extend without confirming available space.
Backups and cautious steps
Always snapshot or backup critical data before destructive operations. Small verification steps avoid large recovery work.
