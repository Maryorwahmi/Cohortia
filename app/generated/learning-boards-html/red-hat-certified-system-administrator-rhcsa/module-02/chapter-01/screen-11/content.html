Module 2 › Chapter 2.1 › Extend LV & Resize FS
Definition
Extending an LV and its filesystem
lvextend adds space to the LV. Filesystems must then be grown to use the space: resize2fs for ext4, xfs_growfs for XFS (mounted).
Common mistakes
  • Running lvextend but forgetting to resize the filesystem.
  • Attempting to shrink XFS — it is not supported without complex steps.
  • Extending without free VG space.
Commands example
# Add 5GB to LV
sudo lvextend -L +5G /dev/vg_web/lv_html

# If ext4
sudo resize2fs /dev/vg_web/lv_html

# If XFS (operate on mount point)
sudo xfs_growfs /var/www/html

# Verify
sudo lvdisplay /dev/vg_web/lv_html
df -h /var/www/html
Always confirm the filesystem type before choosing the resize command.
Key Takeaway
Extending storage is a two-stage operation: expand the LV, then expand the filesystem. Verify with lvdisplay and df.
