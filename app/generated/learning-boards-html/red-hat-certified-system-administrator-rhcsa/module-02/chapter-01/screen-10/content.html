Module 2 › Chapter 2.1 › Create LVM Volumes
Core Concept
Three primary commands
pvcreate, vgcreate, and lvcreate form the basic creation sequence. Run them in order, then format and mount the new logical volume like any other block device.
Verification
Use pvdisplay, vgdisplay, and lvdisplay to confirm state and sizing before and after changes to avoid allocation errors.
Commands example
sudo pvcreate /dev/sdc
sudo vgcreate vg_data /dev/sdc
sudo lvcreate -L 10G -n mydata_lv vg_data
sudo mkfs.xfs /dev/vg_data/mydata_lv
sudo mount /dev/vg_data/mydata_lv /mnt/data
Remember to create the mount point directory before mounting and to confirm the LV path with lvdisplay.
Key Takeaway
Follow pvcreate → vgcreate → lvcreate, then mkfs and mount. Verify using display commands to avoid allocation and naming mistakes.
