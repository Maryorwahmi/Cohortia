Definition
ext4 and XFS characteristics
ext4 is a stable journaling filesystem for mixed workloads. XFS is designed for scalability and large files. Choose based on file sizes, performance needs, and whether you may need online growth capabilities.
Create ext4
sudo mkfs.ext4 /dev/sdb1
Create XFS
sudo mkfs.xfs /dev/sdb1
Example scenario
You provision a 2TB volume for media storage. Choose XFS for better handling of large files and run mkfs.xfs, then mount and confirm write/read performance under expected load.
Misconception: XFS cannot be grown — it can be grown online with xfs_growfs while mounted, but cannot be shrunk easily.
Key Takeaway
Format after verifying device, and pick ext4 for general use or XFS for large-file performance; test before production use.
