Learning Objectives

Master practical storage tasks and verify competency with hands-on commands and checks.

01
Partition disks with fdisk and gdisk
You will learn to use fdisk for MBR and gdisk for GPT to create partitions like /boot and swap, ensuring no overlap and correct sizes.
Mnemonic: Sector map — plan start and end sectors
VERIFIED COMPETENCY MILESTONE
02
Create ext4 and XFS filesystems
Practice mkfs.ext4 and mkfs.xfs options and understand defaults that suit most workloads for journaling and large-file performance.
Mnemonic: Make first, mount next
VERIFIED COMPETENCY MILESTONE
03
Mount and persist with /etc/fstab
Learn correct fstab syntax, test entries with mount -a, and avoid boot problems by validating UUIDs and mount points.
Mnemonic: UUID, mount point, type, options
VERIFIED COMPETENCY MILESTONE
04
Manage LVM and grow volumes
Practice pvcreate, vgcreate, lvcreate, lvextend and use resize2fs or xfs_growfs to consume added space safely.
Mnemonic: Initialize, group, carve, grow
VERIFIED COMPETENCY MILESTONE
