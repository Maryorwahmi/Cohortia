Module 2 › Chapter 2.1 › Webserver Expansion Lab
Scenario
Expand /var/www/html by 5GB using a new disk
You added /dev/sdc. The LV is /dev/vg_web/lv_html (XFS). We'll pvcreate, vgextend, lvextend, then xfs_growfs on the mounted path.
Warnings
Verify device names and confirm vgdisplay shows free space. Back up critical content before making changes to production storage.
# 1. Initialize new disk as PV
sudo pvcreate /dev/sdc

# 2. Add PV to existing VG
sudo vgextend vg_web /dev/sdc

# 3. Add 5GB to the LV
sudo lvextend -L +5G /dev/vg_web/lv_html

# 4. Grow the XFS filesystem (on mount point)
sudo xfs_growfs /var/www/html

# 5. Verify
sudo lvdisplay /dev/vg_web/lv_html
df -h /var/www/html
Example verification
Check vgdisplay for Free PE before lvextend. After growth, lvdisplay shows the new LV size and df shows the filesystem size increased.
