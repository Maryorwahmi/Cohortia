Managing Local Storage & File Systems

This lesson shows how to turn raw disks into usable storage for a Linux system. We'll cover partition schemes, creating ext4 and XFS file systems, mounting with /etc/fstab, and using LVM to build resizable volumes so your services can grow safely.

Partitioning
Choose MBR for legacy needs or GPT for modern large disks. Use fdisk or gdisk accordingly.
File Systems
Create ext4 for general use or XFS for large files and performance using mkfs utilities.
LVM
Combine disks into PVs, create VGs, carve LVs, and resize volumes without reformatting.
