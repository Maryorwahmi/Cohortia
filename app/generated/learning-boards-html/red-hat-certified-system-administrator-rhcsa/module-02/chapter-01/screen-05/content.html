Module 2 › Chapter 2.1 › fdisk Workflow
Definition
Using fdisk to create MBR partitions
fdisk is interactive. You will explicitly create partitions, set types, and write the table. Stop if unsure — do not write until you have verified the device and sizes.
Common mistake
Writing changes to the wrong device. Always verify with a device listing command first and consider using a VM test disk when learning.
Process
A safe fdisk sequence and verification:
# 1. List and confirm device
sudo lsblk -o NAME,SIZE,TYPE,MOUNTPOINT

# 2. Start fdisk for /dev/sdb
sudo fdisk /dev/sdb

# 3. Inside fdisk: n (new), p (primary), select start/end, w (write)

# 4. Inform kernel and create filesystem
sudo partprobe /dev/sdb
sudo mkfs.ext4 /dev/sdb1
Use partprobe or reboot to make the kernel aware of partitions before formatting.
Example card
Example: create a 1GB /boot partition and leave the rest for root. After fdisk, run mkfs on each partition and mount to test access before adding fstab entries.
