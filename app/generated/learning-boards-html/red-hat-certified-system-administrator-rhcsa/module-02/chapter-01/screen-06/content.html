Module 2 › Chapter 2.1 › gdisk Workflow
Definition
gdisk for GPT partition tables
gdisk manages GPT tables and supports large disks. Use it when disks exceed 2TB or when you need many partitions.
Common oversight
Not creating the EFI partition on a UEFI system when partitioning a boot disk. Plan boot partitions separately from data partitions.
Process
A safe gdisk sequence and verification:
# 1. Confirm device
sudo lsblk -o NAME,SIZE,TYPE,MOUNTPOINT

# 2. Start gdisk for /dev/sdb
sudo gdisk /dev/sdb

# 3. Inside gdisk: n (new), specify size or sector, t (type) if needed, w (write)

# 4. Inform kernel and format
sudo partprobe /dev/sdb
sudo mkfs.xfs /dev/sdb1
Choose mkfs.xfs for large-file workloads; mkfs.ext4 for general purpose use.
Example card
Example: On a 3TB disk create one GPT partition, format it as XFS for database backups, then mount it under /mnt/db_backups and add a persistent fstab entry.
