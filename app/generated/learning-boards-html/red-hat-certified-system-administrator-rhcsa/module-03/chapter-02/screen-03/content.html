Verification checklist
Commands you will use during the lab and what they tell you.
pvcreate / pvs
Initialize disks and list PVs to confirm size and UUIDs.
vgcreate / vgs
Create VG and check free extents before allocating LVs.
lvcreate / lvs
Create LVs and confirm their device names and sizes.
Check filesystem
Use df -h to confirm mount size and verify changes after grow operations.
Common mistake
Extending an LV alone does not resize the filesystem. You must run the appropriate grow tool for the filesystem type.
