Allocate an LV and make it usable
Commands to create lv_web, format as ext4, and mount.
sudo lvcreate -L 2G -n lv_web vg_data
sudo mkfs.ext4 /dev/vg_data/lv_web
sudo mkdir -p /var/www/html
sudo mount /dev/vg_data/lv_web /var/www/html
df -h /var/www/html
Checks and notes
After lvcreate, confirm the device appears in /dev and lvs output. mkfs creates the filesystem; mount makes it accessible. Use df -h to confirm the size shown by the filesystem matches the LV size.
Example
In the lab, lv_web of 2GB was formatted ext4 and mounted to /var/www/html for web content storage.
Misconception
lvcreate does not imply a filesystem exists; you must run mkfs and mount separately.
