Learning Objectives
A skills checklist you can apply in a lab or production environment.
01
Explain LVM concepts
Describe PV, VG, LV and extents.
Knowing the architecture helps you design pools that match capacity and redundancy needs. Misconception: LVM is not a backup — it only provides flexibility, not redundancy by itself.
VERIFIED COMPETENCY MILESTONE
02
Create Physical Volumes
Use pvcreate to initialize disks or partitions.
Practical skill: you will initialize /dev/sdb and /dev/sdc as PVs, then verify with pvs. This prepares storage for inclusion in a VG.
VERIFIED COMPETENCY MILESTONE
03
Build and extend Volume Groups
Combine PVs into a VG and add more PVs later.
You will create vg_data and practice vgextend. Why it matters: VGs let you allocate storage across disks without repartitioning.
VERIFIED COMPETENCY MILESTONE
04
Create and resize Logical Volumes
Use lvcreate, lvextend and filesystem grow tools.
You will format an LV and later extend it using lvextend, then run xfs_growfs or resize2fs. Common mistake: forgetting the filesystem resize step after lvextend.
VERIFIED COMPETENCY MILESTONE
