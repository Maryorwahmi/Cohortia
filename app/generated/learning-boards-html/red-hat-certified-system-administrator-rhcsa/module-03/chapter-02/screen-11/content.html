Extent planning
Understand how extent size affects allocation and how to verify free space.
• Extent size is chosen when a VG is created and controls the smallest allocation unit.
• Use vgs to view VFree and the number of free extents available for allocation.
• If an lvcreate fails due to insufficient extents, add a PV and run vgextend or request a smaller LV.
Example
A VG with 4MB extents requires about 2560 extents to allocate 10GB. Plan VG size accordingly if you expect large LVs.
