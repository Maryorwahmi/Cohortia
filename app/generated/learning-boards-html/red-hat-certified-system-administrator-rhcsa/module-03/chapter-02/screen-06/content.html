Prepare disks for LVM
Use pvcreate to initialize raw disks or partitions so LVM can manage them.
Key commands
sudo pvcreate /dev/sdb /dev/sdc
sudo pvs
sudo pvdisplay
Example and checks
Example: initialize two new virtual disks for a demo. After pvcreate, run pvs to confirm the PVs appear and show expected sizes. If a disk contained data, pvcreate would overwrite its metadata, so always verify first.
Misconception
pvcreate does not preserve existing filesystems. It prepares the device for LVM metadata only.
Pro tip
Run lsblk and blkid to confirm a device is not in use before running pvcreate to avoid data loss.
