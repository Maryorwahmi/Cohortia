Create and grow a Volume Group
Commands and checks to combine PVs and add capacity later.
Create VG
sudo vgcreate vg_data /dev/sdb /dev/sdc
sudo vgs
sudo vgdisplay vg_data
Extend VG
# After pvcreate /dev/sdd
sudo vgextend vg_data /dev/sdd
sudo vgs
Why this matters
VGs let you decouple physical growth from logical allocation; you can add disks later without touching existing LVs.
Common mistake
Forgetting to run vgs or vgdisplay after vgextend can leave you unaware of free extents available for new LVs.
Check question
After vgextend, run vgs. What field tells you how much free space is available for new LVs? (Answer: VFree or VSize/VFree columns.)
