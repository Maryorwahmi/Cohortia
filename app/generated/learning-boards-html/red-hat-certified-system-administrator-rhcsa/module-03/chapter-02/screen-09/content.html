Grow a Logical Volume
Add space to an LV, then expand the filesystem to use it.
Commands
sudo vgs
# add 1GB to lv_web
sudo lvextend -L +1G /dev/vg_data/lv_web
sudo lvs
Filesystem resize
# XFS (mounted)
sudo xfs_growfs /var/www/html
# ext4 (can be online or offline)
sudo resize2fs /dev/vg_data/lv_web
sudo df -h /var/www/html
Example
In the lab add 1GB to lv_web and run resize2fs; df -h should then show the larger filesystem size.
Common mistake
Forgetting the filesystem step leaves applications unaware of the new blocks even though the LV grew.
Check
If lvextend fails, add a PV to the VG with pvcreate and vgextend, then retry lvextend.
