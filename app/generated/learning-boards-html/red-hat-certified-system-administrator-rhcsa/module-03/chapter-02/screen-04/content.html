Module 3 › Chapter 3.2 › What LVM is
Definition and purpose
LVM pools disks and provides resizable logical volumes for filesystems.
• LVM abstracts physical storage so you can treat many disks as a single pool.
• Logical volumes behave like partitions but can be extended or moved more flexibly.
• LVM itself is not a backup or redundancy solution; pair it with RAID if you need fault tolerance.
Analogy: Think of PVs as bricks, a VG as the wall, and LVs as rooms carved from that wall. Rooms can be expanded by adding more bricks to the wall.
Concrete example
You have /dev/sdb (2GB) and /dev/sdc (3GB). Initialize them as PVs, create vg_data, then create lv_web of 2GB. Mount and use it as a single filesystem without partitioning a larger disk.
Key takeaway
LVM adds a flexible layer between disks and filesystems, making growth and reallocation easier.
