Filesystem grow comparison
Which commands to use after extending an LV and what to check.
XFS
Use xfs_growfs against the mount point while mounted. Example: sudo xfs_growfs /var/www/html
ext4
Use resize2fs against the device: sudo resize2fs /dev/vg_data/lv_web. Confirm with df -h.
Practical note
Always run lvextend first. If df -h shows no change, you likely missed the filesystem grow step.
