Step-by-step lab
Execute these commands in order and verify results after each step.
Initialize PVs
sudo pvcreate /dev/sdb /dev/sdc
sudo pvs
Create VG and LV
sudo vgcreate vg_data /dev/sdb /dev/sdc
sudo lvcreate -L 2G -n lv_web vg_data
Format, mount, verify
sudo mkfs.ext4 /dev/vg_data/lv_web
sudo mkdir -p /var/www/html
sudo mount /dev/vg_data/lv_web /var/www/html
df -h /var/www/html
Extend and resize
sudo lvextend -L +1G /dev/vg_data/lv_web
sudo lvs
sudo resize2fs /dev/vg_data/lv_web
df -h /var/www/html
