Core Concept

Swap space defined

Swap is disk space the kernel uses as virtual memory to hold inactive pages. It prevents out-of-memory errors but is slower than RAM.

Key points
  • Swap stores inactive pages when RAM is low.
  • It improves stability but can slow performance if overused.
  • Common checks: free -h and swapon -s.
  • Not a substitute for proper capacity planning.
Key Takeaway

Swap protects against memory exhaustion but is slower than RAM. Use it as a buffer, not as a replacement for RAM.

Analogy: Emergency overflow

Think of RAM as your desk and swap as a filing cabinet. When the desk is full, you move inactive papers to the cabinet. You can keep working, but accessing moved papers takes longer.

Common misconception

Some think increasing swap replaces low RAM. In reality, swap masks the symptom and can hide memory leaks. Plan RAM first, add swap for safety.
