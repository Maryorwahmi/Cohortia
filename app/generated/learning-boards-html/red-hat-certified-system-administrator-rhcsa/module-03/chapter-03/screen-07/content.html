Commands to create a 1GB swap file

# 1. allocate
sudo fallocate -l 1G /swapfile
# 2. secure permissions
sudo chmod 600 /swapfile
# 3. initialize
sudo mkswap /swapfile
# 4. enable
sudo swapon /swapfile
# 5. verify
free -h
swapon -s
# 6. persist (add this line to /etc/fstab)
# /swapfile none swap defaults 0 0
Keep the file on a filesystem with enough free space. If fallocate is unavailable, dd can be used but is slower to allocate space.
Safety checklist
  • Use chmod 600 to restrict access before initializing.
  • Run mkswap to format the file for swap use.
  • Enable with swapon and verify with free -h.
  • To remove, run swapoff, remove fstab entry, then delete file.
Example fstab line
/swapfile none swap defaults 0 0
