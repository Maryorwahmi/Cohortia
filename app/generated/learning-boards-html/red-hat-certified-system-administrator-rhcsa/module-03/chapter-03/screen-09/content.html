Commands
# Show memory and swap
free -h
# List active swap devices/files
swapon -s
# Check kernel swap table
cat /proc/swaps
Run these before and after enabling swap to verify the change. If nothing appears, confirm mkswap and fstab entries.
Example outputs
# free -h (sample)
              total        used        free      shared  buff/cache   available
Mem:           1.0G        700M         50M         10M        250M        200M
Swap:          1.0G        128M        872M

# swapon -s (sample)
Filename                Type        Size    Used    Priority
/swapfile               file        1048572 131072  -2
These samples show a 1GB swapfile with 128MB used. Use them as references when you test on your VM.
