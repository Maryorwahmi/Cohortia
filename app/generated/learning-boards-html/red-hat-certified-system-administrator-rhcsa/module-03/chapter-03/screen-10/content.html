Process

Removal sequence

  1. Deactivate: sudo swapoff /swapfile or sudo swapoff /dev/sdb2.
  2. Edit /etc/fstab and remove the swap entry.
  3. Delete the swap file or remove the partition definition.
  4. Verify no swap is active and system runs stable.
If swapoff fails because RAM is low, schedule a maintenance window or stop services to free memory first.
Commands
# Deactivate swap
sudo swapoff /swapfile
# Remove from fstab (edit with sudo)
# Then delete file
sudo rm /swapfile
# Verify
free -h
swapon -s
Always confirm swap is gone before removing backing storage. Deleting an active swap store causes kernel errors.
