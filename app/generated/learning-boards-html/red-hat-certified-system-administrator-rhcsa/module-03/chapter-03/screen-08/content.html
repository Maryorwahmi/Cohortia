Comparison

Swap Partition

  • Dedicated partition formatted with mkswap.
  • Referenced in fstab by UUID for stability.
  • Historically slightly faster, especially on spinning disks.
  • Requires repartitioning to change size.
Comparison

Swap File

  • Created as a regular file with fallocate or dd.
  • Flexible size and easy to add or remove.
  • Requires chmod 600 and mkswap before use.
  • May interact with filesystem features; test compatibility.
Decision guide
Temporary scaling → swap file
Stable performance → partition
Always initialize and secure first
