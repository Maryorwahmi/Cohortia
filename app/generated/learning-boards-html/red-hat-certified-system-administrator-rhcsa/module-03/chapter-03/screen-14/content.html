Module 3 › Chapter 3.3 › Key Concepts
Swap Space
Disk area used when RAM is scarce. Slower than RAM but prevents crashes.
Swap File vs Partition
Files are flexible; partitions are dedicated. Both need mkswap and swapon.
chattr & lsattr
Set and view special attributes. Immutable and append-only control modification behavior at a low level.
Summary
Initialize and secure swap before enabling. Use attributes for protection but keep clear maintenance procedures. Verify often with the provided commands.
