Learning Objectives

These objectives prepare you to configure swap and apply file attributes for system reliability and security.

01
Explain swap purpose
Describe why the kernel swaps pages and how swap prevents out-of-memory failures. This matters when planning memory for VMs or small servers.
Mnemonic: RAM → Disk when idle
VERIFIED COMPETENCY MILESTONE
02
Create and enable swap
Run fallocate or dd, set strict permissions, initialize with mkswap, and activate with swapon. These steps are sequential and required.
Mnemonic: Allocate → Secure → Initialize → Activate
VERIFIED COMPETENCY MILESTONE
03
Persist swap across reboots
Add correct entries to /etc/fstab. Use UUIDs for partitions to avoid device name changes. Test with mount -a after adding.
Mnemonic: fstab = Forever
VERIFIED COMPETENCY MILESTONE
04
Apply file attributes
Use chattr and lsattr to set immutable (+i) or append-only (+a). Know that these attributes can block root-level changes until removed.
Mnemonic: chattr locks, lsattr shows
VERIFIED COMPETENCY MILESTONE
