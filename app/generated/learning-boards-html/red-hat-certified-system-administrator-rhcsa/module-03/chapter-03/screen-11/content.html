Definition

What chattr and lsattr do

Attributes modify how the filesystem treats a file. They are orthogonal to UNIX permissions and can prevent modification even by root.

Common attributes
  • i — immutable: cannot be modified or deleted.
  • a — append-only: can only be opened for append.
Key Takeaway

Attributes are powerful protections. Use them to harden critical files but document and test removal procedures before applying in production.

Commands — view and change
# Show attributes
lsattr /path/to/file
# Make immutable
sudo chattr +i /path/to/file
# Remove immutable
sudo chattr -i /path/to/file
# Make append-only
sudo chattr +a /path/to/logfile
# Remove append-only
sudo chattr -a /path/to/logfile
Confirm attributes with lsattr. If an attribute blocks maintenance, remove it first with chattr -i or -a.
