Definition & Use

Append-only (+a)

Append-only allows only adding data to the end of a file. This prevents modification of historical entries. It is ideal for audit logs and append-only ledgers.

Example command
sudo chattr +a /var/log/audit/audit.log
Operational notes
  • Plan for log rotation: remove attribute, rotate, then reapply.
  • Document attribute changes in change control processes.
  • Attributes affect root; have documented procedures to remove them when needed.
