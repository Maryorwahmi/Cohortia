Module 3 › Chapter 3.3 › Command Reminders
Swap commands
fallocate/dd, chmod 600, mkswap, swapon, swapoff, free -h, swapon -s.
Persistence
Add correct fstab entry. Use UUID for partitions. Test with mount -a.
Attributes
Use chattr +i and +a for protection. Remove attributes before necessary maintenance.
Final tip
Practice the full sequences in a disposable VM so you can safely observe behavior and learn the exact commands and error messages described in this chapter.
