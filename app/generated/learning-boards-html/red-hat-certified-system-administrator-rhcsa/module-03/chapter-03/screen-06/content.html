Swap partition steps

  1. Create a partition and set type to Linux swap (MBR type 82 or GPT 8200).
  2. Initialize the partition: sudo mkswap /dev/sdb2.
  3. Activate: sudo swapon /dev/sdb2.
  4. Verify: free -h and swapon -s.
  5. Persist: add UUID=... none swap defaults 0 0 to /etc/fstab.
Pitfall

Do not add the partition to fstab before running mkswap. Initialization is required for the kernel to recognize swap format.

Terminal walkthrough
# After partitioning and finding /dev/sdb2
sudo mkswap /dev/sdb2
sudo swapon /dev/sdb2
# Verify
free -h
swapon -s
# Get UUID and add to fstab
sudo blkid /dev/sdb2
# In /etc/fstab
# UUID=1111-2222-3333-4444 none swap defaults 0 0
Use blkid to find a stable UUID. Testing with mount -a after editing fstab is a safe way to validate the entry without rebooting.
