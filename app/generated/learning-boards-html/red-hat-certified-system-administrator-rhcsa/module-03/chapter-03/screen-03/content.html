Demonstrable checkpoints

Use these lab actions to verify each learning objective during practice or an exam session.

01 — Explain swap behavior
Run free -h, watch available memory and swap. Explain when the kernel will move inactive pages to swap and why excessive swapping hurts performance.
Check: Can you describe a low-memory scenario where swap prevented OOM?
02 — Create and enable swap
Perform fallocate, chmod 600, mkswap, swapon. Verify with swapon -s and free -h. Note any errors and their causes.
Check: Is the swap active and listed by swapon -s?
03 — Persist swap
Add the fstab entry and run mount -a. If using a partition, confirm the UUID and use it in fstab to avoid device-name drift.
Check: Does free -h show swap after a reboot or mount -a test?
04 — Apply file attributes
Create a dummy config, chattr +i it, attempt modification, observe permission denied, then remove attribute with chattr -i.
Check: lsattr should show an i or a flag after applying.
