Module 3 › Chapter 3.1 › fdisk: MBR workflow
Interactive commands you'll use
p — print partition table
n — new partition
d — delete partition
w — write changes to disk
Remember: fdisk stages changes in memory. If you want to exit without saving, use q. Always verify with p before w.
Example session
$ sudo fdisk /dev/sdb
Command (m for help): p
Disk /dev/sdb: 4 TiB, ...
Command (m for help): n
Partition type: primary
Partition number (1-4): 1
First sector (2048-...): 
Last sector, +sectors or +size{K,M,G,T,P} (2048-...): 
Command (m for help): w
The partition table has been altered.
Common misconception

Assuming fdisk writes immediately — always check before writing. Use q to quit safely.
