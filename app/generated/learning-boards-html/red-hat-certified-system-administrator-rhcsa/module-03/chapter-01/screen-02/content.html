Module 3 › Chapter 3.1 › Learning Objectives
01
Identify MBR vs GPT

Understand partition scheme limits and practical implications for disk sizes and partition counts. This matters for choosing tools and avoiding data loss on large disks.

Verified Competency Milestone
02
Use fdisk, gdisk, parted

Be comfortable entering interactive tools, printing partition tables, creating, deleting, and writing partitions safely. Learn command names and the write confirmation pattern.

Verified Competency Milestone
03
Format with XFS or ext4

Create filesystems with mkfs utilities and understand when XFS is preferred on RHEL and when ext4 remains appropriate.

Verified Competency Milestone
04
Mounting and fstab

Mount and unmount filesystems, use UUIDs in /etc/fstab, and test entries safely with mount -a to avoid boot problems.

Verified Competency Milestone
