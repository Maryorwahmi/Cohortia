gdisk — fdisk for GPT

gdisk offers an interactive prompt with commands similar to fdisk but understands GPT and GUIDs. Use it for manual partitioning on modern disks.

$ sudo gdisk /dev/sdb
Command (? for help): p
Command (? for help): n
Command (? for help): w
parted — scriptable and versatile

parted can create labels and partitions non-interactively. It's suitable for scripting and precise size specifications like 1MiB and 10GiB boundaries.

$ sudo parted /dev/sdb mklabel gpt
$ sudo parted /dev/sdb mkpart primary 1MiB 10GiB
Checklist after writing
  • Run lsblk or fdisk -l to confirm partitions
  • If kernel still shows old layout, use partprobe or reboot
  • Confirm the partition type if required by your workflow
