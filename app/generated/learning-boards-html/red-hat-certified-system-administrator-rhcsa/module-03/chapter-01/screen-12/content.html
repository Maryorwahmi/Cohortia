Module 3 › Chapter 3.1 › Testing fstab & Troubleshooting
Safe edit checklist
  • Create the mount point directory
  • Mount manually and verify access
  • Add the fstab line using UUID
  • Run sudo mount -a and fix any errors
Common failure modes
• Typo in UUID or filesystem type
• Mount point missing or not empty
• Using /dev names that change after hardware changes
If mount -a reports an error, correct fstab and re-run mount -a. Use journalctl -xe to see related system messages if needed.
