Step-by-step commands
# 1. Create mount point
sudo mkdir -p /data/projectX

# 2. Partition the disk with gdisk (interactive):
sudo gdisk /dev/sdb
# type 'g', then 'n', then 'w'

# 3. Format partition as XFS
sudo mkfs.xfs /dev/sdb1

# 4. Get UUID
sudo blkid /dev/sdb1

# 5. Add to /etc/fstab (replace <UUID> with actual value)
echo "UUID=<UUID> /data/projectX xfs defaults 0 0" | sudo tee -a /etc/fstab

# 6. Test mounts
sudo mount -a
df -h /data/projectX
Verify: df -h shows the mount
If mount -a fails: check /etc/fstab syntax
If umount fails: use lsof or fuser to find locks
