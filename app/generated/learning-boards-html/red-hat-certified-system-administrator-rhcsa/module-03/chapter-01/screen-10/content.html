Fields in an /etc/fstab line
# device       mountpoint    fstype  options    dump pass
UUID=abcdef...  /mnt/data      xfs     defaults   0    0

The device field can be a UUID or device path. The options field may be defaults or a comma-separated list. The last two fields control dump and fsck behavior.

Why UUIDs?

Device names can reassign when hardware changes. UUIDs are stable identifiers embedded in the filesystem metadata, making fstab robust across device reordering.

Verify after editing
$ sudo mount -a
# will attempt to mount all fstab entries and report errors
