Module 3 › Chapter 3.1 › Formatting Filesystems
Common filesystems
XFS — default on many RHEL systems, good for large files
ext4 — mature and reliable journaling filesystem
Always format partitions, not whole disks, and verify with lsblk -f or blkid.
Example commands
$ sudo mkfs.xfs /dev/sdb1
meta-data=/dev/sdb1 isize=512 agcount=4, agsize=... 
$ sudo mkfs.ext4 /dev/sdb2
mke2fs 1.45.5 (07-Jan-2020)
After formatting, run sudo blkid /dev/sdb1 to capture the UUID for /etc/fstab entries.
Key Takeaway

Formatting prepares a partition for use. Pick XFS for RHEL default workloads and always verify with blkid or lsblk -f.
