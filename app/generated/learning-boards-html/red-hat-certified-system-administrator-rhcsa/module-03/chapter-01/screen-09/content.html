Module 3 › Chapter 3.1 › Mounting & Unmounting
Manual mount steps
$ sudo mkdir -p /mnt/data
$ sudo mount /dev/sdb1 /mnt/data
$ df -h /mnt/data
Always ensure the mount point exists and is empty. Use the mount or df commands to confirm the filesystem is accessible.
Clean unmount
$ sudo umount /mnt/data
umount: /mnt/data: device is busy

If the device is busy, run lsof /mnt/data or fuser -m /mnt/data to find processes that must be stopped or detached first.
