Module 3 › Chapter 3.1 › Key Concepts
Partitioning
Dividing a disk into logical sections to host filesystems.
Filesystem
XFS or ext4; organizes files and metadata on a partition.
Mount Point
A directory where a filesystem is attached and accessed.
Summary

Use GPT for large disks, format partitions with mkfs, mount them, and register UUID-based entries in /etc/fstab for reliable reboots.
