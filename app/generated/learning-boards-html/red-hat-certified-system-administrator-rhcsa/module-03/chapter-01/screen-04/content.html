What is a partition table?

A partition table is metadata that subdivides a disk into entries that operating systems use to find filesystems and boot loaders. MBR and GPT store this metadata differently and impose different limits.

MBR — older, 2 TB limit, up to 4 primary partitions
GPT — modern, many partitions, supports very large disks
Common misconception

Using fdisk on a large disk will fail if the disk exceeds MBR limits; switch to gdisk or parted for GPT operations.

Concrete example

You attach a 4 TB disk to a RHEL VM. fdisk reports the disk is too large. The correct response is to initialize the disk with GPT using gdisk or parted so you can create partitions that span the full 4 TB.

Quick checklist
  • Confirm disk size with lsblk or fdisk -l
  • Choose GPT for >2 TB disks
  • Back up data before changing partition tables
Key Takeaway

Pick GPT for modern large disks; treat partition table writes as a deliberate, confirmed action.
