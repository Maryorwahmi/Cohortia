01
Mount & Unmount

Learn the commands to mount and unmount and how to interpret "device is busy" errors. Practice using the mount point path and device path interchangeably when appropriate.

Verified Competency Milestone
02
Create Filesystems

Use mkfs.xfs and mkfs.ext4 and understand why RHEL defaults to XFS for many installations. Include example commands and quick sanity checks after formatting.

Verified Competency Milestone
03
Use UUIDs in fstab

Retrieve UUIDs with blkid and add entries to /etc/fstab. Using UUIDs makes fstab entries resilient to device name reordering.

Verified Competency Milestone
04
Test with mount -a

Always run mount -a after editing /etc/fstab to detect typos or missing mount points before rebooting. This prevents boot-time failures.

Verified Competency Milestone
