Module 3 › Chapter 3.1 › blkid & UUIDs
Example output
$ sudo blkid /dev/sdb1
/dev/sdb1: UUID="abcdef12-3456-7890-abcd-ef1234567890" TYPE="xfs"

Copy the UUID and reference it in /etc/fstab to avoid dependency on device node names.

Append to /etc/fstab safely
$ echo "UUID=abcdef12-3456-7890-abcd-ef1234567890 /data/projectX xfs defaults 0 0" | sudo tee -a /etc/fstab
$ sudo mount -a

Testing with mount -a ensures errors are caught before rebooting.
