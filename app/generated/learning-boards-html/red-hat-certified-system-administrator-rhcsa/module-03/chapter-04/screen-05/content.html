Module 4 › Chapter 3.4 › Enable quotas (ext4)
Step-by-step
1. Edit /etc/fstab
Add usrquota and/or grpquota to the mount options for the filesystem.
2. Remount
sudo mount -o remount /data/shared to apply options without rebooting.
3. Initialize
Run quotacheck -cug to create or update quota files, then quotaon to enable enforcement.
Key Takeaway

Quotas require both kernel mount options and on-disk accounting files. Skipping initialization leaves quotas inactive.

Terminal walkthrough (example commands)
Follow these commands to enable quotas on /data/shared and set a user limit.
# edit /etc/fstab: add 'usrquota' to the options for /data/shared
sudo mount -o remount /data/shared
sudo quotacheck -cug /data/shared
sudo quotaon /data/shared
sudo edquota -u student
sudo repquota -u /data/shared
Common-mistake
Not running quotacheck leaves no quota files and quotaon will fail silently.
Check
Use repquota and try a controlled write to test enforcement.
