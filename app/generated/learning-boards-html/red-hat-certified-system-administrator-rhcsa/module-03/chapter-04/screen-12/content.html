Module 4 › Chapter 3.4 › Full disk & mounts
Quick diagnostic steps
  • Run df -h to find full filesystems.
  • Use du -sh on directories to locate large files.
  • Inspect dmesg and journalctl for mount or device errors.
  • Check /etc/fstab for incorrect options causing mount failure.
Key Takeaway

Combine df, du, and logs to find root causes; remember open file handles can keep space allocated until processes are restarted.

Terminal examples and notes
Commands to find what is filling a filesystem and to inspect logs for mount failures.
df -h
sudo du -sh /var/log/* | sort -h
# check kernel and boot logs for mount errors
dmesg | grep -i mount
sudo journalctl -xe | grep -i mount
# find processes holding deleted files
sudo lsof +L1
Common-mistake
Deleting large files without restarting the holding service; space remains used until process releases handle.
Fix
Rotate logs and remove old archives; correct fstab entries and remount to prevent boot surprises.
