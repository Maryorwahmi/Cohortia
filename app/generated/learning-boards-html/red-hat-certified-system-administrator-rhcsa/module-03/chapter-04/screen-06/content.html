Module 4 › Chapter 3.4 › XFS quotas
XFS quota characteristics
XFS manages quotas via xfs_quota. Quotas can be set during mkfs or enabled later; runtime tooling differs from ext4's quotacheck flow.
Enable quotas
xfs_quota -x -c "quota on /mnt/data" turns quotas on for a mounted XFS filesystem.
Set and report
Use xfs_quota subcommands to set limits and generate reports to confirm enforcement.
Key Takeaway

Treat XFS quotas as a separate workflow and use xfs_quota to manage and verify limits; do not rely on ext4 tools for XFS.

Example commands
An example to enable quotas and report usage on /mnt/data.
sudo xfs_quota -x -c "quota on /mnt/data"
sudo xfs_quota -x -c "limit -u bsoft=100m bhard=120m student" /mnt/data
sudo xfs_quota -x -c "report -h" /mnt/data
Misconception
Assuming quotacheck is required for XFS; use xfs_quota instead.
Verify
After setting limits, create a test file to confirm behavior during and after grace periods.
