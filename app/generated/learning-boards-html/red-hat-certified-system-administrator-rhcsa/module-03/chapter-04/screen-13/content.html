Module 4 › Chapter 3.4 › Hands-on Activity
Guided checklist
Follow each step and verify outputs before proceeding to the next.
RAID1 build
  1. Partition /dev/sdb and /dev/sdc as RAID type.
  2. Create array: mdadm --create /dev/md0 --level=1 --raid-devices=2 /dev/sdb1 /dev/sdc1.
  3. Monitor cat /proc/mdstat until clean; format and mount the array.
Enable quotas on ext4
  1. Add usrquota to /etc/fstab for /data/shared and remount.
  2. Run sudo quotacheck -cug /data/shared and sudo quotaon /data/shared.
  3. Edit quotas with edquota -u student and verify with repquota.
Verification
Confirm mdadm --detail, cat /proc/mdstat, df -h for mounts, and repquota for limits. Ensure mdadm.conf or initramfs is updated when appropriate.
Common pitfalls
Forgetting quotacheck, not saving mdadm metadata, or mis-editing fstab entries can prevent correct behavior after reboot.
Example commands (summary)
Use these as a quick reference while you perform the lab.
sudo mdadm --create /dev/md0 --level=1 --raid-devices=2 /dev/sdb1 /dev/sdc1
sudo mkfs.xfs /dev/md0
sudo mount /dev/md0 /mnt/raid1_data
# quotas on existing ext4
sudo mount -o remount /data/shared
sudo quotacheck -cug /data/shared
sudo quotaon /data/shared
sudo edquota -u student
sudo repquota -u /data/shared
