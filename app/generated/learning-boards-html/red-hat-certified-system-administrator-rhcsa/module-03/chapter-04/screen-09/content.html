Module 4 › Chapter 3.4 › Create RAID1
Step checklist
  1. Partition each disk with Linux RAID partition type and note the partition names.
  2. Create the array with mdadm --create and specify level and devices.
  3. Format the array, create a mount point, and mount it.
  4. Persist the mount using the array UUID in /etc/fstab.
Key Takeaway

Verify each stage: partition types, mdadm creation status, filesystem health, and fstab UUID entries so the array assembles correctly on reboot.

Terminal commands (example)
Follow these commands in sequence and monitor /proc/mdstat during creation and rebuilds.
# assume /dev/sdb1 and /dev/sdc1 are RAID partitions
sudo mdadm --create /dev/md0 --level=1 --raid-devices=2 /dev/sdb1 /dev/sdc1
cat /proc/mdstat
sudo mkfs.xfs /dev/md0
sudo mkdir -p /mnt/raid1_data
sudo mount /dev/md0 /mnt/raid1_data
sudo blkid /dev/md0   # copy UUID and add to /etc/fstab
Common-mistake
Not saving the mdadm metadata or updating mdadm.conf, which breaks auto-assembly at boot.
Check
Use mdadm --detail /dev/md0 to confirm component roles and state.
