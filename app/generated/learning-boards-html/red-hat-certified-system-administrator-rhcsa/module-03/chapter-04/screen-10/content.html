Module 4 › Chapter 3.4 › RAID recovery
Degraded to healthy: step sequence
  1. Detect degraded array with cat /proc/mdstat or mdadm --detail.
  2. Mark the failed device as faulty and remove it from the array.
  3. Partition and prepare replacement disk with RAID partition type.
  4. Add replacement to array and monitor rebuild until complete.
Key Takeaway

Follow the fail/remove/add sequence and monitor /proc/mdstat; do not skip failing a device before removing it.

Example commands and monitoring
Use these commands to safely replace a failed component and watch the rebuild process.
# mark failed and remove
sudo mdadm /dev/md0 --fail /dev/sdb1
sudo mdadm /dev/md0 --remove /dev/sdb1
# prepare replacement /dev/sdd1 then add
sudo mdadm /dev/md0 --add /dev/sdd1
# monitor
watch -n 2 cat /proc/mdstat
sudo mdadm --detail /dev/md0
Common-mistake
Removing a device without failing it first can corrupt array state and confuse mdadm.
Pro tip
Log rebuild progress and check system load; rebuilds can affect I/O performance.
