RAID level comparison
RAID0 (striping)
Improves throughput by striping data across disks. No redundancy; a single disk failure loses the array.
RAID1 (mirroring)
Replicates data across two or more disks for redundancy. Capacity equals one disk; survives a single disk failure.
Key Takeaway

Select RAID0 for performance-only use cases and RAID1 when redundancy matters; always combine RAID with backups.

mdadm in practice
Create and inspect arrays using mdadm, and monitor with /proc/mdstat.
# create a RAID1 array from two partitions
default: sudo mdadm --create /dev/md0 --level=1 --raid-devices=2 /dev/sdb1 /dev/sdc1
# monitor
cat /proc/mdstat
sudo mdadm --detail /dev/md0
Misconception
RAID is not backup. Use independent backups alongside RAID.
Pro tip
Record mdadm --detail output and add array definitions to mdadm.conf for rebuilds.
