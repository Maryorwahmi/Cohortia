Module 4 › Chapter 3.4 › Learning Objectives
Verification-focused checkpoints
Each objective pairs an action with a verification command or file you will inspect.
Quota initialization
Use quotacheck to create quota files, then quotaon to enable them. Verify with repquota and by triggering a write past the soft limit during the grace period.
VERIFIED COMPETENCY MILESTONE
XFS quota enforcement
Practice xfs_quota commands to set limits and confirm with xfs_quota -x -c 'report'. Ensure you understand quota on vs off states.
VERIFIED COMPETENCY MILESTONE
tune2fs checks
Adjust the maximum mount count and interval for fsck to balance maintenance windows and safety. Verify with tune2fs -l.
VERIFIED COMPETENCY MILESTONE
RAID monitoring and rebuild
After adding or replacing a device, watch the rebuild progress in /proc/mdstat and confirm array health with mdadm --detail.
