Module 4 › Chapter 3.4 › Disk quotas
What quotas measure
Blocks (space) and inodes (number of files). Use both to prevent runaway storage or many small files from exhausting metadata.
Soft limit
A threshold that starts a grace period when exceeded; allows temporary overage without immediate denial.
Hard limit
An absolute ceiling that prevents further writes once reached.
Key Takeaway

Quotas prevent future writes beyond set limits and require initialization and verification; they do not reduce existing files.

Concrete example & commands
Example: enforce 100MB soft and 120MB hard block limits for user 'student' on an ext4 mount at /data/shared.
# initialize quota files
sudo quotacheck -cug /data/shared
sudo quotaon /data/shared
# edit 'student' limits
sudo edquota -u student
# verify
sudo repquota -u /data/shared
Common mistake
Forgetting to remount or run quotacheck after editing /etc/fstab options.
Pro tip
Test quota behavior with a controlled file write to see grace period behavior.
