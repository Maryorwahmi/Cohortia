Upgrade
Using rpm -Uvh
Upgrade replaces the previous package if present, or installs if absent. It does not fetch dependencies.
sudo rpm -Uvh /root/my_app-2.0-1.el8.x86_64.rpm
If the new version introduces dependencies, rpm will report them and fail. Use dnf update when you have repository access and want automatic resolution.
Scenario
A vendor sends you an updated RPM to patch a bug. You can use rpm -Uvh to apply that exact file on the server without pulling from a repository. This gives a deterministic, single-file upgrade path.
Common mistake: using -i to 'upgrade' an installed package. -i will attempt to install a new package alongside or conflict — prefer -U for upgrades.
