Lab objectives
Download or stage a local RPM, install with rpm, inspect files, verify package integrity, simulate a change, and clean up by removing the package.
Step-by-step terminal commands
# Fetch a local RPM (if networked)
# dnf download tree --destdir=/tmp

# Install locally
sudo rpm -ivh /tmp/tree-1.8.0-1.el8.x86_64.rpm

# List files installed by package
rpm -ql tree

# Inspect package info
rpm -qi tree
Verification and cleanup
# Verify package integrity
rpm -V tree

# Simulate a change (lab only)
sudo touch /usr/bin/tree
rpm -V tree

# Revert simulation and remove
sudo rm /usr/bin/tree
sudo rpm -e tree
Reflection prompt
Consider when you would use rpm in production: offline vendor updates, auditing, or targeted troubleshooting when DNF is not an option. What did rpm output tell you about state changes during the lab?
