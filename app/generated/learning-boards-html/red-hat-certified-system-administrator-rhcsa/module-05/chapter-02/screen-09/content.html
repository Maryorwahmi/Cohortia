Verify
Use rpm -V to audit files
Command and example flags you might see:
rpm -V httpd
# Output example flags explained
# S file size changed
# 5 checksum mismatch
# T mtime changed
# M mode (permissions) changed
Practical steps
  1. Run rpm -V package_name to get verification output.
  2. Interpret flag letters to determine what changed.
  3. Decide: restore from backup, reinstall the package, or accept the change.
Simulation: touch a binary or edit a config and re-run rpm -V to observe the change flags during a safe lab exercise.
