What the RPM database stores
  • Package metadata: name, version, release, vendor, build date.
  • File lists: full paths of files installed by each package.
  • Attributes and checksums used by rpm -V (sizes, MD5 sums, permissions, types, owners).
  • Ownership relationships used by rpm -e to check reverse dependencies.
Key question: Which package owns a path? Use rpm -qf /path/to/file to ask the database.
Common queries
rpm -qa
rpm -qi httpd
rpm -ql tree
rpm -qf /usr/bin/tree
Remember: the database stores metadata only. If metadata and actual files differ, rpm -V will flag the discrepancy.
