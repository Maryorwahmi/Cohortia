Managing Software with RPM
Using the low-level rpm tool to install, query, verify, and remove packages
In this lesson
You will see how rpm interacts with .rpm files and the local RPM database. Practice installing a local file, listing its files, verifying file integrity, and removing a package manually.

Explore Key Topics
Install
Use rpm -ivh to install a local .rpm file when no network or repository is available.
Verify
Use rpm -V to compare installed files against stored checksums and attributes for integrity checks.
Query & Remove
List installed packages and files with rpm -qa, -qi, -ql, and remove with rpm -e.
