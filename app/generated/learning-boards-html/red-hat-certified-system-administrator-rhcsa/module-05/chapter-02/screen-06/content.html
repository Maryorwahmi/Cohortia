Install a local RPM
Follow these steps to attempt a local install and interpret output.
  1. Place the .rpm in a known path, e.g., /tmp.
  2. Run: sudo rpm -ivh /tmp/package.rpm and watch the verbose output and hash marks.
  3. If rpm reports missing dependencies, note the package names it requests.
  4. Either obtain those RPMs and install them, or use dnf to fetch and resolve dependencies.
Misconception: rpm will resolve dependencies. It will not. You must supply or fetch missing packages.
Command example
sudo rpm -ivh /tmp/my_custom_app-1.0-1.el8.x86_64.rpm
If dependencies are missing you'll see output naming the missing packages. Use that list to fetch or install prerequisites.
Scenario card: You have no internet access. Obtain RPMs beforehand or use dnf download on a machine with network access.
