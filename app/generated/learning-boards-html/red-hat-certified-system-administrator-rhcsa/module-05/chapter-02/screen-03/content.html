Practical Objectives
Actionable commands and outcomes to practice in a lab.
Install
Use rpm -ivh <file.rpm> to attempt a local install and observe dependency errors when prerequisites are missing.
Query
Use rpm -qa, -qi, and -ql to find packages, metadata, and installed files for troubleshooting.
Verify
Use rpm -V to detect changes and interpret the flags that indicate size, checksum, or permission differences.
Example command snippet
sudo rpm -ivh /tmp/tree-1.8.0-1.el8.x86_64.rpm
rpm -ql tree
rpm -V tree
sudo rpm -e tree
