Commands
rpm -qa
rpm -qa | grep httpd
rpm -qi httpd
rpm -ql tree
rpm -qf /usr/bin/tree
Use these commands to find packages, inspect versions and vendor info, and locate installed files for editing or removal.
Example workflow
  1. Find package owning a file: rpm -qf /etc/httpd/conf/httpd.conf
  2. Inspect package metadata: rpm -qi httpd
  3. List all installed files: rpm -ql httpd
Pro tip: Pipe rpm -qa into grep to quickly locate a package by partial name when the list is long.
