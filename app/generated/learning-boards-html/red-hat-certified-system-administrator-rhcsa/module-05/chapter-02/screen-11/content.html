Module 5 › Chapter 5.2 › Dependency Hell
rpm: explicit failures
rpm reports exactly which dependencies are missing. Use that output as a checklist to obtain or install the required RPMs.
Fixes: install listed RPMs, use dnf on a networked host to fetch them, or use dnf download to build an offline set.
DNF: resolver behavior
DNF will fetch and install dependencies automatically from configured repositories, reducing manual work and the chance of partial installs.
When to prefer DNF: everyday installs and upgrades when repositories are available and you want dependency resolution.
