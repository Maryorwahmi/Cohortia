Explain RPM's role

Install & upgrade local RPMs
Use rpm -ivh and rpm -Uvh correctly and anticipate dependency failures when packages require other libraries.
VERIFIED COMPETENCY MILESTONE
03
Query the RPM database
Use rpm -qa, -qi, and -ql to list packages, inspect metadata, and see files owned by a package for troubleshooting.
VERIFIED COMPETENCY MILESTONE
04
Verify & remove safely
Use rpm -V to detect local file changes and rpm -e to erase packages while recognizing dependency constraints.
