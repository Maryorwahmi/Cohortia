Erase
Removing a package
sudo rpm -e tree
rpm -q --whatrequires tree
rpm -ql tree
Check reverse dependencies and file lists before erasing to avoid breaking other packages or losing configs you need to back up.
Scenario
If rpm -e refuses due to dependencies, consider dnf remove which will present a dependency plan. Never forcibly remove packages without understanding the consequences on production systems.
Warning: Removing shared libraries can render other packages unusable; always inspect what requires the package first.
