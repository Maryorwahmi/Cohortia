Module 5 › Chapter 5.3 › Enable vs Start
Enable / Disable
sudo systemctl enable httpd
sudo systemctl disable httpd

These commands change whether systemd will start the service automatically during boot, but do not immediately start or stop the service.

Start / Stop
sudo systemctl start httpd
sudo systemctl stop httpd

These commands change the service state immediately for the running system but do not alter boot-time behavior.

Key Takeaway

Manage runtime and boot persistence separately: start/stop now, enable/disable for the future.
