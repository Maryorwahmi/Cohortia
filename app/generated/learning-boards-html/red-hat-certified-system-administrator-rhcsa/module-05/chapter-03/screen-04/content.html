Module 5 › Chapter 5.3 › Processes vs Services
Definition

Process

An instance of a running program with a unique PID and runtime resource usage. Can be transient or long-lived.

Example
You run a maintenance script from your shell. It appears as a process with a PID and exits when finished.
Common misconception
Killing a service process directly may leave systemd confused or cause an automatic restart. Prefer systemctl for managed services.
Definition

Service (Daemon)

A background process managed by systemd via unit files that can be started, stopped, and configured to run at boot.

Example
Installing and enabling the httpd package creates a service so the web server can be started at boot and managed centrally.
Key Takeaway

Inspect processes with ps/top, but control services through systemctl to keep unit state and logs coherent.
