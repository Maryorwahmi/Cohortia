Learning Objectives

Solid, verifiable skills to operate processes and services on RHEL.

Learn → Understand → Apply → Master
01
Identify system processes

Read ps output and interpret PID, user, CPU and memory to decide what to investigate.

VERIFIED COMPETENCY MILESTONE
02
Control processes with signals

Send SIGTERM then escalate to SIGKILL when necessary, and use killall carefully.

VERIFIED COMPETENCY MILESTONE
03
Manage services with systemctl

Start, stop, restart, reload, enable and disable services to control runtime and boot behavior.

VERIFIED COMPETENCY MILESTONE
04
Analyze service logs

Use journalctl to filter logs by unit, follow in real time, and restrict by time ranges for troubleshooting.

VERIFIED COMPETENCY MILESTONE
