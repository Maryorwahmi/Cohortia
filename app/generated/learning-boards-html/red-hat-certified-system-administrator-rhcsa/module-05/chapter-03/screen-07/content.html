Module 5 › Chapter 5.3 › Signals & kill
Common signals
kill PID          # sends SIGTERM (15) by default
kill -9 PID       # sends SIGKILL (9)
killall name       # kills all processes with that name
SIGTERM requests a clean shutdown. SIGKILL forces immediate termination and should be used with care.
Cautionary example
If a database writer gets killed with SIGKILL while writing, you can leave files in an inconsistent state. Prefer graceful signals and check application logs first.
Check your understanding

Before using kill -9, confirm PID, try SIGTERM, and consult service management if the process is part of a unit.
