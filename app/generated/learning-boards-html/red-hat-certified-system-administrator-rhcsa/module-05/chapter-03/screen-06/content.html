Module 5 › Chapter 5.3 › top vs htop
top (default)
top
# Shows CPU, tasks, and a dynamic list sorted by CPU by default

Available on a default install, useful for quick investigation and low-overhead monitoring.

htop (optional)
sudo dnf install htop -y
htop
# Color, tree view, mouse and easier signaling

When you need better interaction and a clearer visual grouping of processes, htop is helpful. Install when appropriate.

When to use

Use top for immediate checks and htop when you need color, tree view, or interactive signaling to inspect relationships between processes.

Misconception

Seeing a high CPU value once doesn't prove a leak; observe behavior over time before killing processes.
