Module 5 › Chapter 5.3 › Key Concepts
Process
Instance of a running program with a PID used to identify and signal it.
Service
Long-running background process managed by systemd using unit files.
systemctl
Primary tool for controlling service lifecycle and boot-time behavior on RHEL.
Summary takeaway
Observe processes, prefer graceful actions, verify with status and journalctl, and make persistence changes only when intentional.
