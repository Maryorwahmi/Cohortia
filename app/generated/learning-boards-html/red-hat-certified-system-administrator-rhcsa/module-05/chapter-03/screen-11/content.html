Module 5 › Chapter 5.3 › Practice: httpd
Lab steps
  1. Install: sudo dnf install httpd -y
  2. Check status: systemctl status httpd
  3. Start: sudo systemctl start httpd
  4. Enable at boot: sudo systemctl enable httpd
  5. Inspect processes: ps aux | grep httpd
  6. View logs: journalctl -u httpd --since "5 minutes ago"
  7. Stop and disable when done: sudo systemctl stop httpd && sudo systemctl disable httpd
Example verification
systemctl status httpd
# look for: Active: active (running)
journalctl -u httpd -f
# follow live logs while requesting a reload or testing a request
Key Takeaway

Practice the sequence until confirming status and logs are second nature: install, start, enable, inspect, verify, stop, disable.
