Module 5 › Chapter 5.3 › journalctl
Inspect unit logs
journalctl -u httpd
journalctl -u httpd -f
journalctl -u httpd --since "2 hours ago"

Start with systemctl status for a quick view, then drill into journalctl for full context and follow new entries while testing.

Practical example
After starting httpd, use journalctl -u httpd --since "5 minutes ago" to verify that no startup errors occurred and that listeners bound successfully.
Key Takeaway

Use unit-scoped logs and time filters to rapidly find relevant entries for a service without noise from unrelated system messages.
