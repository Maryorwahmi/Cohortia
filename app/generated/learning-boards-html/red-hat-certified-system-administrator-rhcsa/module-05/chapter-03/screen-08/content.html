Module 5 › Chapter 5.3 › systemctl basics
Common commands
systemctl status httpd
sudo systemctl start httpd
sudo systemctl stop httpd
sudo systemctl restart httpd
sudo systemctl reload httpd
Use status to confirm state and read short logs. Prefer reload for configuration changes when the service supports it; restart is more disruptive but guarantees a clean start.
Practical hint
After starting or changing a service, run systemctl status to verify and inspect recent log lines embedded in the status output.
Misconception

enable does not start a service now; it only makes the service start at boot.
