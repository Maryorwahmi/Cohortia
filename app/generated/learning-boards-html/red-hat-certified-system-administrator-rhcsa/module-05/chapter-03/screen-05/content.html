Module 5 › Chapter 5.3 › ps aux
Command
ps aux
ps aux | grep httpd
Read these columns
  • USER: who owns the process
  • PID: unique process identifier used by kill and other tools
  • %CPU / %MEM: quick way to find resource hogs
  • COMMAND: program name and arguments
Example
To find Apache worker PIDs: ps aux | grep httpd. Confirm the PID and user before signaling.
Common mistake
Relying on process name alone can misidentify a process. Always pair name with PID and USER when taking action.
Key Takeaway

ps aux is a snapshot that helps you find PIDs and resource usage before taking any action.
