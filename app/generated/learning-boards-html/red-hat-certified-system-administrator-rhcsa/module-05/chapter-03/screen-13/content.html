Module 5 › Chapter 5.3 › Assessment
Scenario 1
You updated a web server configuration and want minimal disruption. Choose between reload and restart.
Best choice: systemctl reload service_name if supported; it re-reads config without a full stop. Restart is more disruptive.
Scenario 2
A background process started from shell consumes 95% CPU and ignores SIGTERM. The system is sluggish.
Best choice: try kill PID, verify; if unresponsive and critical, use kill -9 PID. Confirm it is not a managed unit before using systemctl.
