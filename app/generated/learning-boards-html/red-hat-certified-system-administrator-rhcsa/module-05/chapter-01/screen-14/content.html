What to Remember
Three compact cards
DNF

Primary RHEL package manager that resolves dependencies and executes transactions using repository metadata.

Repository

Source of packages and metadata; enable and disable repositories carefully to control available software.

Dependency

Packages required by others; DNF resolves and installs dependencies automatically but will report conflicts when they arise.

Summary
Use install, update, remove, search, and info as your core commands, keep repositories curated, and refresh metadata when troubleshooting.
