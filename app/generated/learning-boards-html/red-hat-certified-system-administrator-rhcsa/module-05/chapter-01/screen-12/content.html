Core Concept
Detect → Analyze → Resolve
Typical conflict output
Error: Package: A requires libXYZ = 2
  Installed: libXYZ-1
  Available: libXYZ-2 from some-repo
Conflict: package B requires libXYZ = 1
Inspect which repo supplied the available versions and whether removing or replacing a package is acceptable for your environment.
Resolution strategies
  • Identify package origins and prioritize trusted repositories.
  • Consider removing the conflicting package if it is not required.
  • Find an alternative package or repository with compatible versions.
Misconception

Dependency conflicts are not always bugs; they are signals about incompatible version constraints between packages or repositories.
