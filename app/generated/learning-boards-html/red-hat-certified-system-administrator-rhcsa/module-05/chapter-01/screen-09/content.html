Definition
Where DNF finds packages
Repository anatomy
  • ID: repository identifier used by DNF.
  • baseurl: the HTTP(S) location of package files and metadata.
  • enabled: whether DNF will query the repo.
Config files live in /etc/yum.repos.d/. Edit them carefully and prefer trusted sources.
When repos cause problems
Conflicting package versions often stem from multiple repositories offering the same package.
Temporarily disable the third-party repo or prioritize repositories to recover a stable state.
Warning

Adding untrusted repos may introduce unstable or insecure packages.
