Remove vs Autoremove
Remove

sudo dnf remove package_name will remove the package and show any dependent packages that will also be removed. Inspect the summary carefully.

If a shared library is required elsewhere, DNF will either stop or propose removing the dependent package too; do not accept if the dependent package is critical.
Autoremove behavior

DNF often removes orphaned dependencies automatically during remove. You can also run dnf autoremove to clean orphans separately.

Common Mistake

Accepting a removal without checking the list can uninstall shared libraries needed by other applications.
