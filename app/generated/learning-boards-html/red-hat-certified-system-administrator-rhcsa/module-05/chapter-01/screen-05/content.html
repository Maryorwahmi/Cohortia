Process Flow
Request → Resolve → Confirm → Install
Step-by-step
  1. Run sudo dnf install package_name to request the package.
  2. DNF queries repositories and computes dependencies.
  3. DNF shows a transaction plan for review and confirmation.
  4. After confirmation, DNF downloads and installs the packages.
Pro tip: avoid -y for unfamiliar transactions so you can inspect proposed changes.
