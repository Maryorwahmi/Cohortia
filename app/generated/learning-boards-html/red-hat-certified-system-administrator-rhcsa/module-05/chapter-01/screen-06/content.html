Terminal example and verification
Run this sequence
sudo dnf install htop
# read the transaction summary, then:
y
# verify
dnf list installed htop
dnf info htop
If install fails: try dnf search htop to confirm package name or check dnf repolist to ensure repositories are enabled.
Expected output snippets
"Dependencies resolved." — DNF found required packages.
"Transaction Summary" — lists installs and upgrades to occur.
Use dnf info to see package description and repository origin.
Key Takeaway

Verify installations and read transaction summaries to avoid unexpected changes.
