Module 5 › Chapter 5.1 › Learning Objectives
Bloom: Learn → Understand → Apply → Master
01
Explain DNF's role

Describe why DNF is the primary package manager for RHEL and how it improves dependency resolution compared to older tools. This matters when you diagnose package behavior.

VERIFIED COMPETENCY MILESTONE
02
Install, update, remove

Use sudo dnf install, dnf update, and sudo dnf remove safely, and review DNF’s proposed changes before accepting them.

VERIFIED COMPETENCY MILESTONE
03
Manage repositories

List, enable, and disable repositories with dnf repolist and config-manager; inspect .repo files when resolving issues.

VERIFIED COMPETENCY MILESTONE
04
Search and resolve

Find packages with dnf search and examine them with dnf info. Learn to interpret dependency errors and use cache commands to recover from stale metadata.

VERIFIED COMPETENCY MILESTONE
