Practical command map
Install: sudo dnf install htop — adds software and its dependencies after confirmation.
Update: sudo dnf update — refreshes packages from enabled repositories to newest versions.
Remove: sudo dnf remove package_name — removes package and orphaned dependencies.
Quick checklist
  • Always use sudo for system changes.
  • Preview DNF’s proposed changes before confirming.
  • Use dnf repolist when packages can’t be found.
