Module 6 › Key Concepts
Load Average
Average number of runnable or waiting processes over 1, 5, 15 minutes; compare to core count.
Swap Space
Disk-backed virtual memory; heavy, sustained use indicates physical RAM is insufficient.
Inode
Filesystem entry that stores metadata for files and directories; running out of inodes prevents new file creation.
Summary

Remember these basic concepts to interpret monitoring outputs correctly and choose the right remediation path.
