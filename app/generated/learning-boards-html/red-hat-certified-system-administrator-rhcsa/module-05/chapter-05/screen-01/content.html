CPU & Load
Use uptime for load averages and top for per-process CPU to decide if cores are saturated.
Memory & Swap
free -h shows actual and available memory; heavy swap use indicates the need for more RAM.
Disk & I/O
df and du locate space usage; iostat reveals device %util and whether a disk is a bottleneck.
