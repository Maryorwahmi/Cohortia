Memory Monitoring free -h & Swap
Read memory values correctly
Focus on available memory and swap used to assess true memory pressure.
Example output
              total        used        free      shared  buff/cache   available
Mem:           16G         14G        1.0G        200M        1.0G         6G
Swap:          8.0G        4.0G        4.0G
Despite 14G used, 6G available means cache can be reclaimed. Swap used at 4G is a warning: physical RAM has been exhausted earlier.
Decision points
  • If available is healthy, no immediate action.
  • If swap is high and remains so, add RAM or reduce app memory.
  • Use top to find memory-hungry processes and consider tuning them.
Common mistake
Treating 'used' as the only metric — kernel cache can make used look large even when memory is available.
Key Takeaway

Look at available and swap together; persistent swap activity means the system is starved for RAM.
