06 • Inspect Network Sockets
Use ss -tuln to list listening ports and ss -s for a socket summary to uncover connection floods or unexpected services.

Combine CPU, memory, disk, and network outputs to form a clear diagnostic hypothesis before taking corrective action.

Interpret metrics to advise actions such as increasing RAM, cleaning disk space, adjusting logging, or optimizing an I/O-heavy application.
