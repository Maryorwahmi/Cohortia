Disk Space df vs du & Inodes
Blocks, files, and inodes
Use df, du, and df -i together to find both large files and inode exhaustion.
Example commands
# Check block usage
$ df -h /
Filesystem      Size  Used Avail Use% Mounted on
/dev/sda1        50G   10G   37G  22% /

# Check inode usage
$ df -i /
Filesystem     Inodes  IUsed   IFree IUse% Mounted on
/dev/sda1      3276800 3276800 0     100% /

# Find large dirs
$ sudo du -sh /var/log
2.6G    /var/log
Practical guidance
  • Use df -h for overall space; use du -sh to locate large subtrees.
  • Run df -i when users report inability to create files despite free space.
  • Remove or rotate logs and consider filesystem reformat only when necessary.
Common Mistake

Assuming df -h alone is sufficient; it will not reveal inode exhaustion which prevents file creation.
