Network Monitoring ss
Inspect listeners and connections
Quickly surface listening ports and socket counts that affect service health and security.
Example commands and output
$ ss -tuln
Netid State  Recv-Q Send-Q Local Address:Port  Peer Address:Port
tcp   LISTEN 0      128    0.0.0.0:22        0.0.0.0:*
udp   UNCONN 0      0      0.0.0.0:123       0.0.0.0:*

$ ss -s
Total: 123 (kernel: 100)
TCP:   20 (estab 10, closed 5, orphaned 0, timewait 5)
If established connections are unexpectedly high, the service or clients may be misbehaving or under a flood attack.
Checklist
  • Run ss -tuln to list listening sockets and validate expected services.
  • Run ss -s to see totals and watch for unusual counts like many timewait sockets.
  • Correlate with application logs to identify client-side issues or attacks.
Warning

Large numbers of sockets in TIME-WAIT or ESTABLISHED can indicate load or connection churn; investigate before scaling horizontally.
