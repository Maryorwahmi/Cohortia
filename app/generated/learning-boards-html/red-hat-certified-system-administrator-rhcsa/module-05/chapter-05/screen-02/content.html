Learning Objectives
Understand and apply monitoring commands to detect and diagnose system resource issues.
01
Monitor CPU and Load Average
Use uptime, top, and htop to see per-process CPU and 1/5/15-minute load averages. Learn to compare load to core count to judge saturation.
VERIFIED COMPETENCY MILESTONE
02
Analyze Memory and Swap
Use free -h to read total, used, buff/cache, and available memory and detect when swap use indicates RAM shortage.
VERIFIED COMPETENCY MILESTONE
03
Evaluate Disk Space and Inodes
Use df -h and df -i to check blocks and inodes, and du -sh to pinpoint large directories consuming space.
VERIFIED COMPETENCY MILESTONE
04
Monitor Disk I/O and Network Sockets
Use iostat -x for %util, r/s, w/s and ss -tuln or ss -s to examine listening ports and socket summary for network issues.
VERIFIED COMPETENCY MILESTONE
