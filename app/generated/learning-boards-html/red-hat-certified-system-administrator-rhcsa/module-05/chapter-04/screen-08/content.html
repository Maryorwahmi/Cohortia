Module 5 › Chapter 5.4 › Periodic vs Crontab
Periodic directories

cron.daily / cron.hourly

Place executable scripts; run-parts executes each script on the configured interval. Best for simple, package-level tasks.
Tip: scripts must be executable and use absolute paths to reliably find commands and files.
Crontab lines

Precise scheduling

Use crontab entries for minute-level control, ranges, or weekday-only execution. Supports lists and ranges in fields.
Warning: misplaced fields can change timing; always verify with crontab -l and test logs.
