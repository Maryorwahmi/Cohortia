Architecture

Where system cron lives

/etc/crontab — global file that includes a user field.
/etc/cron.d — directory for package-installed cron files, each file is a separate job definition.
Periodic directories — cron.hourly, cron.daily, cron.weekly, cron.monthly use run-parts to execute every script inside.
Example /etc/crontab line
# m h dom mon dow user  command
0 2 * * * root /usr/bin/system_maintenance.sh >> /var/log/system_maintenance.log 2>&1
Using separate files in /etc/cron.d keeps package jobs isolated and easier to manage or remove.
