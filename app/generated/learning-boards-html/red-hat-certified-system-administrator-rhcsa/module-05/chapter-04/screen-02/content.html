Learning Objectives

These four objectives guide the hands-on tasks and verification checks in the lab walkthrough.

01
Understand cron purpose
Describe recurring scheduling use cases and where cron runs in RHEL.
Verified competency milestone
02
Create and manage crontab
Use crontab -e, crontab -l, and crontab -r to manage user jobs safely.
Verified competency milestone
03
Configure system-wide cron
Place files in /etc/cron.d or use /etc/crontab and periodic directories for packaged jobs.
Verified competency milestone
04
Schedule one-time tasks with at
Use at and atq/atrm to manage single future executions; ensure atd is running.
Verified competency milestone
