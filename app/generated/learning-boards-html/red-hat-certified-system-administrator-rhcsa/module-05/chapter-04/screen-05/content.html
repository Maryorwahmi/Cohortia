Module 5 › Chapter 5.4 › Crontab Syntax
Definition

Five fields control the schedule

Minute (0-59), Hour (0-23), Day of Month (1-31), Month (1-12), Day of Week (0-7, 0 or 7 = Sunday).
Use asterisk for every value, commas for lists, and hyphens for ranges.
Common example
# Run backup every day at 2:00 AM
0 2 * * * /usr/local/bin/backup_script.sh >> /var/log/backup.log 2>&1

# Run a check every hour on weekdays
0 9-17 * * 1-5 /usr/bin/check_status.sh >> /var/log/check.log 2>&1
Tips and pitfalls
  • Use absolute paths for commands and files to avoid PATH issues.
  • Redirect stdout and stderr so you can diagnose failures.
  • Be careful with ranges and lists; a misplaced comma or number can change timing dramatically.
