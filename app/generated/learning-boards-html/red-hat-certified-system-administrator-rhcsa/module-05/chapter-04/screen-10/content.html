Module 5 › Chapter 5.4 › Using at
Definition

Schedule a one-off task

Start with at and a time expression. Enter the commands to run, one per line, then Ctrl-D. Use atq to list queued jobs and atrm to remove them.
Terminal example
$ at now + 5 minutes
at> echo "At job ran at $(date)" >> /tmp/at_output.log
at>   # Press Ctrl+D here

$ atq
1		Tue Oct 27 10:30:00 2023 a user

$ atrm 1
Confirm atd is active using systemctl status atd before relying on scheduled jobs.
