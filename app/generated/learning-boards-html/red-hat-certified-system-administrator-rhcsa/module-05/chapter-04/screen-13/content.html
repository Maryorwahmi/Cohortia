Quiz question
Which crontab entry runs /opt/scripts/daily_report.sh every weekday at 6:00 PM?
Answer: 0 18 * * 1-5 /opt/scripts/daily_report.sh
Troubleshooting checklist
  • Confirm crontab entry exists with crontab -l.
  • Check /var/log/cron or journalctl -u crond for invocation evidence.
  • Run the script manually to inspect errors and permissions.
  • Ensure absolute paths and output redirection are used.
