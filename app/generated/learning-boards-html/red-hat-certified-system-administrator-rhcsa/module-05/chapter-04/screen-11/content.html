Process Flow

Create, schedule, verify, remove

  1. Create the script and make it executable.
  2. Test the script manually and confirm output to /tmp.
  3. Add a crontab entry for short-term testing.
  4. Confirm with crontab -l and check /tmp or /var/log/cron.
  5. Remove the test entry when done.
Starter commands
echo '#!/bin/bash' | sudo tee /usr/local/bin/my_cron_job.sh
echo 'echo "Cron job ran at $(date)" >> /tmp/cron_output.log' | sudo tee -a /usr/local/bin/my_cron_job.sh
sudo chmod +x /usr/local/bin/my_cron_job.sh

# crontab -e  (add the line below for testing)
# * * * * * /usr/local/bin/my_cron_job.sh >> /tmp/cron_output.log 2>&1
After confirming, remove the entry to avoid leaving a high-frequency job running.
