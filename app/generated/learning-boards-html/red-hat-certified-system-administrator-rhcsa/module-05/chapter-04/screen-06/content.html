Module 5 › Chapter 5.4 › User Crontab Management
Process Flow

Edit, verify, test, remove

Step 1 — Create script and test
Write the script, give execute permission, and run it manually to confirm behavior.
Step 2 — Add to crontab
Use crontab -e to add a testing line then crontab -l to confirm it appears.
Step 3 — Verify execution
Check a test log file or /var/log/cron for evidence the job ran.
Terminal demo snippet
# Create a quick test script
echo '#!/bin/bash' | sudo tee /usr/local/bin/my_cron_job.sh
echo 'echo "Cron job ran at $(date)" >> /tmp/cron_output.log' | sudo tee -a /usr/local/bin/my_cron_job.sh
sudo chmod +x /usr/local/bin/my_cron_job.sh

# Add to your crontab (for testing every minute)
# crontab -e
# * * * * * /usr/local/bin/my_cron_job.sh
Remove test entries promptly with crontab -e or crontab -r when you finish to avoid leftover high-frequency jobs.
