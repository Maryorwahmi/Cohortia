Definition

file and ls -l — content and context

Use file to learn what a file contains; use ls -l to learn who can access it and when it changed.

Examples
$ file /bin/bash
/bin/bash: ELF 64-bit LSB executable, x86-64

$ file /etc/passwd
/etc/passwd: ASCII text

$ ls -l /etc/passwd
-rw-r--r-- 1 root root 2768 Jun 1 10:00 /etc/passwd
Common misconception

File extensions are not authoritative on Linux. Rely on file and permissions to decide how to open or execute a file.

Practical check

Before executing a script, run file scriptname and then ls -l to confirm it is text and has an execute bit for your user.

Key Takeaway

Inspect both type and permissions — one tells you what it is, the other who can do what with it.
