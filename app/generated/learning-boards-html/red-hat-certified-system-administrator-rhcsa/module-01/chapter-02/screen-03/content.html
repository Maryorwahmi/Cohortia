Practice and Safety Objectives

Short, repeatable sequences to try on your lab VM and simple safeguards to protect data.

Create
mkdir -p reports/2023/q4 — build nested folders in one command.
Mnemonic: build parents first
Move & Rename
mv summary.txt reports/2023/q4/ — move or rename without copying contents.
Mnemonic: move is rename when target is a filename
Delete (Safety)
Use rm -ri when unsure; rm -rf is irreversible and must be used sparingly.
Mnemonic: prompt before you purge
Verified milestone: run the create, move, cat sequence on your lab VM, then remove the tree using an interactive deletion and confirm the results with ls.
