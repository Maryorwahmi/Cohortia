Assessment Idea

Practical assessment: move and view

Execute a short sequence that demonstrates creation, movement, context change, and viewing with verification steps.

Expected command sequence
mkdir -p reports/2023/q4
mv summary.txt reports/2023/q4/
cd reports/2023/q4
cat summary.txt
Verify each step with ls and pwd to ensure the file is where you expect.
Log inspection assessment

Inspect a large system log without loading it fully and search for the term error. Expected approach: less /var/log/syslog then type /error to search.

Key Takeaway

Assessments should include verification steps; a correct sequence is not just the commands but also the checks that prove success.
