Process Flow

Hands-on practice sequence

A safe sequence to run on your lab VM that includes verification after each step.

Step list
  1. pwd and ls -la to confirm starting point.
  2. mkdir -p projects/web/html/css and cd into projects/web/html.
  3. touch index.html style.css script.js and echo "Hello RHEL!" > index.html.
  4. cat index.html to verify content.
  5. cp index.html about.html and mv script.js app.js.
  6. ls -l to confirm files and sizes.
  7. View /etc/hosts with cat and a large log with less to practice paging.
  8. Cleanup: cd ~ then rm -ri projects and verify removal with ls.
Example command block
pwd
mkdir -p projects/web/html/css
cd projects/web/html
touch index.html style.css script.js
echo "Hello RHEL!" > index.html
cat index.html
cp index.html about.html
mv script.js app.js
ls -l
cd ~
rm -ri projects
Safety reminder

Practice on non-critical files and use interactive deletion until you are comfortable with recursive removal.
