Key Concepts

Filesystem Root
All files and directories branch from '/'; use absolute paths for clarity.
Right Command
Use mkdir/cp/mv/rm appropriately; recursive flags are required for directories.
Inspect Before Acting
Use file and ls -l, and preview content with cat or less before modifying or deleting.
Final Takeaway

Build the habit: check where you are, inspect targets, then act. Verification steps prevent costly mistakes.
