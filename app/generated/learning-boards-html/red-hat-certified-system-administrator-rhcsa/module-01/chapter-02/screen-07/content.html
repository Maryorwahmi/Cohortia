Process Flow

mkdir, rmdir, touch — create and remove safely

A reliable flow: create nested folders, add placeholder files, verify contents, then remove using interactive deletion when testing.

Command examples
mkdir -p projects/web/html/css
cd projects/web/html
touch index.html style.css script.js
ls -la
rmdir empty_folder   # succeeds only if empty
rm -ri projects      # interactive recursive deletion
Key Takeaway

Prefer mkdir -p for nested creation and rm -ri for safe cleanup during learning.

When rmdir fails

rmdir will fail on non-empty directories. Use ls to inspect contents, then decide whether to remove individual files or use rm -r when appropriate.

Common mistake

Using rm -rf without checking the path can delete important data. Always confirm pwd and the target path before running destructive commands.

Try this

Create a small test tree with mkdir -p, add files with touch, then practice removing with rm -ri to observe prompts and confirm behaviors.
