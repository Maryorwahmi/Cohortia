Code Walkthrough

cp and mv — copy then move

Use copying for backups and templates, moving to relocate or rename without duplication.

Commands to try
touch index.html
cp index.html about.html    # create a duplicate
cp -r /etc/skel /home/newuser/profile_template    # recursive copy
mv about.html public/about.html    # move file into directory
ls -l public
Key Takeaway

Choose cp when you need a copy; choose mv to rename or relocate without keeping the original file in place.

Common pitfalls
  • Forgetting -r when copying directories results in an error or an incomplete operation.
  • Assuming cp preserves all metadata; use flags if ownership and timestamps must be retained.
Scenario

You have index.html and want a second page. Copy it to about.html, edit about.html, then move it into the public directory for deployment.
