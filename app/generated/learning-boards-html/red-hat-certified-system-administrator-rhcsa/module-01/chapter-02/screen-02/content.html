Learning Objectives

Progress from basic navigation to safe file manipulation and confident inspection of system files.

01
Navigate the filesystem
Use pwd and cd to find and move between directories. This skill avoids errors when editing system files.
Mnemonic: breadcrumb path
VERIFIED COMPETENCY MILESTONE
02
Create and remove files and directories
Use mkdir, rmdir, touch, rm, cp, and mv with options that prevent accidental data loss.
Mnemonic: build, move, clean
VERIFIED COMPETENCY MILESTONE
03
View and page file contents
Use cat for small files, and less or more to page and search large logs without loading everything into memory.
Mnemonic: peek, page, probe
VERIFIED COMPETENCY MILESTONE
04
Identify file types and attributes
Use file and ls -l to determine text versus binary, permissions, owner, and size — essential for troubleshooting.
Mnemonic: inspect before acting
VERIFIED COMPETENCY MILESTONE
