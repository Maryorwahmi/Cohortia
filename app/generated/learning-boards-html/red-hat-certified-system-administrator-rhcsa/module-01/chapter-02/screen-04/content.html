Core Concept

Filesystem tree and root directory

Treat the filesystem as a single rooted tree starting at '/'. This mental model clarifies absolute vs relative paths.

Key definitions
  • Root (/): the top-most directory containing all files and directories.
  • Absolute path: begins with '/', lists each directory from root to target.
  • Relative path: listed from current working directory; uses '.' and '..' for current and parent.
Example: Absolute path: /etc/hosts — the hosts file in system config.
Example: Relative path: ../config refers to a sibling directory of the current folder.
Annotated path cards
Absolute
/etc/sysconfig/network-scripts
Use when you must be unambiguous about location.
Relative
../config or my_project/data
Use for quick local navigation, but verify pwd when uncertain.
Key Takeaway

Always confirm your current working directory before running destructive commands that use relative paths.

Common misconception

Home is not root. Home is ~/. It is often /home/youruser, which is a branch under root. Using absolute paths prevents confusion about where operations will run.
