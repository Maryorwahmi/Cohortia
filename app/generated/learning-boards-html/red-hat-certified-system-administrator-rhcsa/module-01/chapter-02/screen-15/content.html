What to Remember

Confirm Context
Use pwd and ls before acting to avoid surprises.
Choose Correct Operation
Create with mkdir -p, duplicate with cp -r, relocate with mv, delete with caution.
Inspect First
Use file and ls -l and view content with less when files are large.
Summary

Small habits — check, inspect, confirm — make your CLI work safer and more predictable on RHEL.
