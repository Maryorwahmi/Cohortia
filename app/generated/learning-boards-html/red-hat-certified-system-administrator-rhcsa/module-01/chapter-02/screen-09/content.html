Core Concept

rm and rmdir — deletion with care

Deletion is permanent on most systems; confirm targets and use interactive modes during learning.

Examples and patterns
# Remove empty directory
rmdir temp_dir

# Interactive recursive deletion during practice
rm -ri projects

# Dangerous: force recursive deletion (use with extreme caution)
rm -rf important_data
Common mistake

Using rm -rf without verifying the path can remove system files or your home directory. Always pause and inspect what you're about to delete.

Pro tip

List the target with ls -la before deletion. Consider moving to a temporary archive folder first, then delete after verifying backups.

Key Takeaway

Deletion is permanent; make it deliberate by inspecting, prompting, and backing up when necessary.
