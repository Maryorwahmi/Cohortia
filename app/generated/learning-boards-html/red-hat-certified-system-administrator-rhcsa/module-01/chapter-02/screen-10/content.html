cat, less, more — pick the right viewer

Small file? Use cat. Large file or log? Use less for paging and searching.

Commands and tips
# View small files
cat /etc/os-release

# Page a large log
less /var/log/messages    # use /error to search, q to quit

# Pipe command output into less
dmesg | less
Key Takeaway

Prefer less for large files; learn basic navigation and search keys to find content quickly.

Example scenario

Troubleshooting a service: open /var/log/messages with less, search for the service name, and note timestamps around failures to correlate events.

Common misconception

less does not edit files. It is a pager for safe, read-only exploration. Use an editor to make changes after confirming the file and its location.
