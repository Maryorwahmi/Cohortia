pwd and cd — verify then move

A safe workflow: print your path, change directory, then confirm the new path.

Step-by-step
  1. Run pwd to see the current absolute path.
  2. Run cd with an absolute or relative path to move.
  3. Run pwd again to confirm you are in the expected directory.
  4. Use cd - to return to the previous directory when needed.
Example sequence
pwd
cd projects/web/html
pwd
cd -
Shortcuts and notes
  • cd ~ returns to your home directory.
  • cd .. moves up one level; repeat for higher levels.
  • cd - toggles to previous working directory.
Common mistake

Relying on relative paths without checking pwd can cause operations to run on the wrong files or directories.

Check your understanding

If you are in /home/cohortiauser/projects and type cd ../.. what is your new path? Answer by thinking of the tree structure and parent levels.
