Comparison

ls vs ls -l vs ls -a

Compare simple listing, long listing for metadata, and showing hidden files.

Example outputs
$ ls
bin  config  index.html

$ ls -l
-rw-r--r-- 1 cohortiauser cohortia  128 Jun  1 12:00 index.html
drwxr-xr-x 2 cohortiauser cohortia 4096 Jun  1 11:58 config

$ ls -la
drwxr-xr-x 3 cohortiauser cohortia 4096 Jun  1 11:58 .
-rw-r--r-- 1 cohortiauser cohortia  256 Jun  1 11:57 .bashrc
Key Takeaway

When troubleshooting permissions or missing files, combine ls -l and ls -a to reveal ownership and hidden entries.

How to read the first column in ls -l
  • First char: file type (d for directory, - for file).
  • Next nine chars: permission bits in three triplets for owner, group, others.
  • Use this to spot missing execute bits or other permission problems.
Common mistake

Not using -a when searching for config files leads to thinking files are missing. Hidden dotfiles often store user-level configurations.

Try this

Run ls -la in your home directory and identify any .bashrc or .profile files. Check ownership and modification time with ls -l.
