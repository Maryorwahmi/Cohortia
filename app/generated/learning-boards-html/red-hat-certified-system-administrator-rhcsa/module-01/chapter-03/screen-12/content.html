Create sysadmin user

Follow this sequence and verify each step before proceeding.

Commands
groupadd ops
groupadd monitoring
useradd -m -g ops -G monitoring -s /bin/bash sysadmin
passwd sysadmin
Verify
id sysadmin grep '^sysadmin:' /etc/passwd grep monitoring /etc/group
Key Takeaway

Create groups first, then the user. Verify membership to avoid surprises in permission behavior.
