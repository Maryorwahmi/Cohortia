Module 2 › Chapter 1.3 › Core Account Files

What each file contains

/etc/passwd
Fields: username:x:UID:GID:GECOS:home:shell. The 'x' points to /etc/shadow for the password hash.
/etc/shadow
Contains hashed passwords and aging rules. Root-only readability protects passwords from ordinary users.
/etc/group
Groupname:x:GID:member1,member2 — supplementary members listed explicitly here.
When debugging logins, check /etc/passwd for shell or home misconfiguration, and /etc/shadow for locked accounts or expired passwords.
Visual sample
# /etc/passwd example
devuser1:x:1001:1001:Dev User:/home/devuser1:/bin/bash
# /etc/group example
developers:x:101:devuser1,tester1
# /etc/shadow (root-only) shows hashed passwords and aging
Misconception

Editing the username in /etc/passwd without adjusting the UID will not change file ownership; ownership is numeric.
