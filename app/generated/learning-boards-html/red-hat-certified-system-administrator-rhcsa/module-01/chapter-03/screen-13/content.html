Two short exercises

Question 1
Create sysadmin with ops primary and monitoring supplementary; default shell /bin/bash; set password. Verify with id and grep.
Question 2
Which commands show disk and memory usage in human-readable form? How do you run them?
Answer hints

Create groups first and use useradd -m -g ops -G monitoring -s /bin/bash sysadmin; use df -h and free -h for disk and memory.
