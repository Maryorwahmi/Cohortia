Module 2 › Chapter 1.3 › Live Terminal Demo
Demo commands
# as root
su -
# create group and users
groupadd developers
useradd -m -G developers -s /bin/bash devuser1
passwd devuser1
useradd tester1
passwd tester1
# add tester1 to developers safely
usermod -aG developers tester1
# lock and unlock
usermod -L devuser1
usermod -U devuser1
# cleanup
userdel -r tester1
userdel devuser1
groupdel developers
Pause before userdel -r to avoid accidental data loss. Confirm with ls /home before deletion.
Verification steps
Verify account: id devuser1
Verify passwd entry: grep '^devuser1:' /etc/passwd
Verify group: grep developers /etc/group
Reflection

How would you script these verifications to run after provisioning an account? Think about id and grep checks as tests.
