Module 2 › Chapter 1.3 › Lock / Unlock
Commands

Lock and unlock

# lock an account
usermod -L devuser1
# attempt login should fail
$ su - devuser1
Authentication failure
# unlock
usermod -U devuser1
Locking is reversible and preserves home directories and file ownership. Use for maintenance or investigations.
Comparison

Lock vs change shell

Changing a shell to /sbin/nologin stops interactive shells but does not change password state. Locking manipulates the shadow password and prevents all password-based authentication for the account.
Pro tip

Use locking for temporary suspension; change shell for long-term service accounts where you want no interactive login.
