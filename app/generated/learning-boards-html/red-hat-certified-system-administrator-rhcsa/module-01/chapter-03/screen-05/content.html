Module 2 › Chapter 1.3 › Create & Verify User
Step-by-step

Create, set password, verify

Create group first
groupadd developers — ensure supplementary group exists before using -G.
Create user
useradd -m -G developers -s /bin/bash devuser1
Set password
passwd devuser1 — root can set others' passwords.
Key Takeaway

Always verify with id and grep to confirm UID, GID, home directory, and shell.

Terminal Demo (visual)
# create a group
$ groupadd developers
# create user with home and supplement group
$ useradd -m -G developers -s /bin/bash devuser1
# set the password
$ passwd devuser1
# verify
$ id devuser1
uid=1001(devuser1) gid=1001(devuser1) groups=1001(devuser1),101(developers)
$ grep '^devuser1:' /etc/passwd
devuser1:x:1001:1001::/home/devuser1:/bin/bash
Check the home path and the shell field in /etc/passwd to confirm defaults.
