Module 2 › Chapter 1.3 › Group Management
Commands
# create a group
groupadd developers
# rename
groupmod -n devs developers
# delete (fails if members exist)
groupdel devs
Verify membership and primary groups before deletion. Use grep to inspect group entries.
Scenario

Rename and verify

After renaming, check /etc/group and any ACLs or files expecting the old name. Remember file ownership uses numeric GID, so renaming keeps the same GID mapping.
Safety note

If groupdel fails, remove the users from the group or change their primary group, then retry.
