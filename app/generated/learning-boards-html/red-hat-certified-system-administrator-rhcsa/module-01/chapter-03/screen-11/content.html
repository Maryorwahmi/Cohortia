Essential checks

Identity: hostname; hostnamectl
Kernel: uname -r; uname -a
Disk: df -h
Memory: free -h
Network: ip a
Combine these outputs to form a quick report: hostname, kernel, disk use, memory state, and network addresses. This is your starting point for diagnosis.
Example outputs
$ uname -r
5.14.0-xyz
$ df -h
Filesystem Size Used Avail Use% /
/dev/sda1  20G  18G  1.5G  93%
$ free -h
              total used free
Mem:           8G   7G   1G
$ ip a
2: enp0s3: inet 192.0.2.10/24
Misconception

Seeing a free value in free -h doesn't always mean the system has no memory pressure; look at buffers and cache as part of analysis.
