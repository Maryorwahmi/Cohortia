Module 2 › Chapter 1.3 › Supplementary Groups
Why it matters

Append, don't replace

Supplementary groups give shared access. Use -a to avoid removing previous memberships accidentally.

Correct command
usermod -aG developers tester1 — adds developers without removing others.
Danger
usermod -G monitoring tester1 replaces the full supplementary list and can remove access unexpectedly.
Check your work

Verify with id and /etc/group immediately after changes.

Terminal pattern
# add tester1 to developers safely
$ usermod -aG developers tester1
# verify membership
$ id tester1
uid=1002(tester1) gid=1002(tester1) groups=1002(tester1),101(developers),102(testers)
# inspect /etc/group
$ grep '^developers:' /etc/group
developers:x:101:devuser1,tester1
If membership is missing, re-run usermod with -aG for each group or use a scripted reconciliation.
