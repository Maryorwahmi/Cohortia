Module 2 › Chapter 1.3 › Quick Reference
User Commands
useradd, passwd, usermod, userdel — know flags like -m, -g, -G, -s, -r.
Group Commands
groupadd, groupmod, groupdel — rename with groupmod -n safely.
Core Files
/etc/passwd, /etc/shadow (root-only), /etc/group — inspect them to verify accounts and memberships.
Final tip

Build a short verification script that runs id, grep, df -h, and free -h after changes to confirm expected state automatically.
