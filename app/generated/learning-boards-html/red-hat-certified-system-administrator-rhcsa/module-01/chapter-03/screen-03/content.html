Practice & Safety

A reproducible lab: create group, create user, add to group, set password, verify, lock/unlock, check system info, clean up.

Create group: groupadd developers
Create user: useradd -m -G developers -s /bin/bash devuser1
Set password: passwd devuser1
Common Mistake
Using usermod -G without -a will remove existing supplementary groups.
Pro tip
Verify changes with id username and grep on the core files before proceeding.
