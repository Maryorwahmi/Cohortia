Module 2 › Chapter 1.3 › UIDs & GIDs
Definition

Numeric identifiers

UIDs and GIDs are used internally to attribute processes and files to identities. Usernames are mapped to UIDs in /etc/passwd and groups to GIDs in /etc/group.

Concrete example
File owned by alice (UID 1001), group staff (GID 50). The kernel checks numbers, not names, to grant access.
Common misconception
Renaming a user does not change their UID. Files owned by that numeric UID remain owned even if the name changes.
Key Takeaway

Inspect numeric IDs when debugging ownership; keep system and regular UIDs separated.

Analogy

UID = Social Security number

A username is like a person's display name. The UID is the immutable numeric identifier the system trusts for ownership.

Quick check
# show id and numeric mapping
id alice
# shows uid=1001(uid=1001) gid=50(staff) groups=50(staff),100(devs)
