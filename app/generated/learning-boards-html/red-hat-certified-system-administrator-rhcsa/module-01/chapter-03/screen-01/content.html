Users, Groups, and Quick System Checks

Understand identifiers, core files, and the commands you’ll use for daily administration.

Duration target: 15 minutes
User Identity
UIDs map users to ownership; UIDs 0-999 are system accounts, regular users start at 1000.
Group Access
Groups bundle permissions. Supplementary groups expand access without changing file owners.
System Info
A few commands reveal hostname, kernel, disk, memory, and network state for troubleshooting.
Explore Key Topics
Create & Manage Users
useradd, passwd, usermod, userdel
Groups & Membership
groupadd, groupmod, groupdel, usermod -aG
System Checks
id, hostnamectl, uname, df -h, free -h, ip a
Visual Concept
Identifiers
Usernames map to UIDs; groups map to GIDs. Files store the name but the kernel uses the numeric IDs.
Core files
/etc/passwd, /etc/shadow, and /etc/group hold the canonical account and group info used by authentication and tools.
Daily commands
A handful of commands let you create and verify accounts and inspect system status quickly.
