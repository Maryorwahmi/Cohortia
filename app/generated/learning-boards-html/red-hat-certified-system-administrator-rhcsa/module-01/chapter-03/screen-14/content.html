UID & GID
Numeric IDs drive ownership; inspect numbers when troubleshooting.
Group Membership
Use usermod -aG to append supplementary groups; verify with id and /etc/group.
System Checks
Run hostnamectl, uname -r, df -h, free -h, and ip a to collect a system snapshot quickly.
Takeaway

Small, repeatable verification steps prevent many common admin mistakes: check numeric IDs, append groups safely, and run a short system checklist when troubleshooting.
