Learning Objectives

What you will be capable of after this chapter

Learn → Understand → Apply → Master
01
Explain UIDs and GIDs
Define numeric identifiers and why regular user UIDs start at 1000; this prevents conflicts with system accounts.
VERIFIED COMPETENCY MILESTONE
02
Create, modify, delete users
Use useradd, passwd, usermod, and userdel safely, including when to use -r to remove home directories.
VERIFIED COMPETENCY MILESTONE
03
Manage groups and membership
Create, rename, delete groups and add users to supplementary groups using -aG to preserve membership.
VERIFIED COMPETENCY MILESTONE
04
Retrieve system info
Run id, whoami, hostnamectl, uname, df -h, free -h, and ip a to inspect system identity and resource usage.
VERIFIED COMPETENCY MILESTONE
