Practical Outcomes

These outcomes align to lab tasks you will perform and demonstrate during walkthroughs and assessments.

Obtain RHEL media
Register for a developer subscription and download the correct ISO for RHEL 8 or 9 for lab use.
Build VM in VirtualBox
Create a new VM, allocate minimum recommended resources, and attach the ISO for installation.
Run Anaconda installer
Choose automatic partitioning for quick labs or manual partitioning to practice RHCSA objectives.
Verify networking
Use the ip a command and ping to confirm connectivity and learn the difference between NAT and Bridged modes.
