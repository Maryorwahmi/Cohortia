Anaconda Installer — Key Steps

Installation Destination

Choose the virtual disk where RHEL will be installed. Automatic partitioning is fine for labs; manual partitioning is an exam skill.

Example
Select the VDI created earlier and proceed with automatic partitioning for a quick install.
Network & Host Name

Enable the network adapter, set DHCP or static IP, and assign a hostname like rhcsa-vm for easy identification in multi-VM labs.

Root Password
Set a strong root password during installation to secure the superuser account.
User Creation
Create a non-root user for daily tasks and elevate only when necessary.
Takeaway
Careful installer choices make the difference between a throwaway VM and a reusable lab image.
