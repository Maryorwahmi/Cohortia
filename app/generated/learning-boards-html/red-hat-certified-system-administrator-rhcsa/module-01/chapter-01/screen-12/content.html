Activity: Build and Test a RHEL VM

Create VM checklist
  1. Download RHEL ISO via developer subscription.
  2. Create VM: name RHCSA-Lab, Type Linux, Version Red Hat (64-bit).
  3. Memory 2048 MB, Processors 2, Disk 25 GB VDI.
  4. Attach ISO and boot the Anaconda installer.
Installer and post-checks
  1. Set Installation Destination and use automatic partitioning for now.
  2. Enable Network & Host Name; set hostname and confirm adapter enabled.
  3. Set root password; create non-root user cohortiauser.
  4. Reboot, log in, run ip a and ping google.com. Create a snapshot.
Result
A reproducible VM you can revert to, ensuring rapid recovery after experiments.
Common pitfall
Failing to enable the network adapter or forgetting to attach the ISO before boot prevents installation progress.
