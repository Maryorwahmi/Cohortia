Module 1 › Chapter 1.1 › Key Concepts
RHEL
An enterprise Linux distribution prioritizing support and long-term stability.
Virtual Machine (VM)
A software-based emulation of a computer that runs a guest OS on a host system.
Hypervisor
Software such as VirtualBox or KVM that creates and runs VMs by virtualizing hardware.
Network Modes
NAT, Bridged, and Host-Only determine how a VM connects and whether it accepts inbound connections.
Anaconda Installer
The guided installer used by RHEL; configure disk, network, root, and users during setup.
Snapshot
A saved VM state enabling quick reversion to a known good configuration.
Summary takeaway
Master these core terms and workflows to build a reproducible lab for RHCSA practice and to reason about network reachability and system recovery.
