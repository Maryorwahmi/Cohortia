Snapshots and Recovery Workflow

When to snapshot
  • After a clean installation and updates.
  • Before attempting manual partitioning or major configuration changes.
  • Before installing services that affect system boot.
Snapshot workflow
  1. Create a labeled snapshot: "clean-install".
  2. Make changes and test. If tests fail, revert to the labeled snapshot.
  3. Remove old snapshots you no longer need to conserve disk space.
Pro tip
Use descriptive names and dates for snapshots to avoid confusion when reverting.
Not a backup
Snapshots are great for quick reverts but keep separate backups for important data.
Key Takeaway
Snapshots speed experimentation and recovery, enabling more effective RHCSA practice without repeated installs.
