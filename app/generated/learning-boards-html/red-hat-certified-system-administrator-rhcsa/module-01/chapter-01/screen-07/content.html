Acquire RHEL and Prepare Host

Step-by-step checklist
  1. Register for a developer subscription to access RHEL ISOs.
  2. Download the correct RHEL 8 or 9 ISO for your architecture.
  3. Install VirtualBox or ensure KVM/libvirt is available on Linux.
  4. Create a VM and attach the ISO to boot the installer.
Host preparation
Reserve sufficient disk space for VM images and snapshots. Close unnecessary applications while running multiple VMs. Keep backups of downloaded ISOs to avoid repeated downloads during labs.
Why snapshots first
Create a snapshot after a clean install so you can return to a known good state quickly after mistakes or experiments.
Pro tip

Store ISOs and VM disks on a fast drive to reduce installation time and snapshot size.

Watch out

Downloading the wrong architecture ISO can prevent the VM from booting. Confirm 64-bit selection for most modern hosts.
