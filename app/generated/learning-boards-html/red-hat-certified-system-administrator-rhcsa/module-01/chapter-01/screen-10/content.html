VirtualBox Network Modes Explained

NAT
Provides internet access via the host but usually blocks inbound connections from host or network machines unless port forwarding is set.
Use when you only need outbound access for updates and downloads.
Bridged Adapter
Makes the VM appear as a separate device on the physical network, getting its own IP and allowing inbound connections from other machines.
Use when you want SSH access from hosts or to simulate a production server on the network.
Host-Only Adapter
Creates an isolated network between host and VMs without direct external network access. Combine with NAT for selective internet access.
Use when building multi-VM labs that should not be exposed to the wider network.
Misconception
Internet access inside VM implies inbound reachability. This is not true for NAT mode.
Example
Switching to Bridged Adapter lets you SSH into the VM from another machine on the same LAN.
