Create a VM and Allocate Resources

VirtualBox New VM steps
  1. Open VirtualBox and click "New"; name your VM (e.g., RHCSA-Lab).
  2. Type: Linux; Version: Red Hat (64-bit).
  3. Base Memory: 2048 MB; Processors: 2 cores.
  4. Hard Disk: create VDI dynamically allocated, 25 GB suggested.
Resource planning card
Choose resources that keep the VM responsive during package installation and basic tasks. Increase RAM or CPU on hosts with spare capacity for smoother multitasking.
Example
2GB RAM and 2 CPUs with 25GB disk is a practical starting point for RHCSA lab work.
Tip
Use snapshots after the initial install to avoid repeating setup steps.
Trap
Too-small disks cause package installs to fail mid-way; always provision a comfortable margin.
Takeaway
Balance guest needs with host constraints; start with recommended minimums and adjust as you use the VM.
