Post-Installation Network Checks

Commands to run
ip a
ping -c 4 8.8.8.8
ping -c 4 google.com
Run ip a to list interfaces and assigned addresses. Use ping with an IP first to test routing, then with a domain to test DNS resolution.
Sample expected output
2: enp0s3: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500
    inet 192.168.1.45/24 brd 192.168.1.255 scope global dynamic enp0s3
PING 8.8.8.8 (8.8.8.8) 56(84) bytes of data.
64 bytes from 8.8.8.8: icmp_seq=1 ttl=115 time=20 ms
If ip a shows only loopback, check VirtualBox adapter settings. Reboot after changing adapter mode to apply new network assignments.
Troubleshooting
If ping fails but ip a shows an IP, check DNS and firewall settings.
Example
Switch to Bridged Adapter and re-run ip a to see a new IP from your network DHCP server.
Key Takeaway

Use ip a and ping as the first steps to confirm your VM has network connectivity and to diagnose reachability issues.
