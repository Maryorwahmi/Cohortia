Module 3 › Chapter 3.1 › Learning Objectives — Practical Steps

Quick verifications

Hub vs Switch
Run two transfers at once. A hub will show collisions and retransmits; a switch lets separate ports transmit simultaneously.
MAC learning
Connect a new host, send traffic, then inspect the MAC address table to see the source MAC mapped to a specific port.
Frame parts
Capture one ARP request and identify the destination and source MAC fields in the frame header.

Practical checks

ARP and ARP cache
Run the ARP cache command and compare before and after a ping to see how ARP populates IP-to-MAC mappings.
Port security test
Configure a port to allow one MAC and plug in a different device. Observe the switch's configured action.
