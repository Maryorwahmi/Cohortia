Module 3 › Chapter 3.1 › Ethernet Frame Structure
Definition

Important fields

  • Destination MAC: guides where the frame should go.
  • Source MAC: used by switches to learn and map ports.
  • Payload: carries ARP or IP data used by higher layers.
  • Frame check sequence: validates frame integrity.
ARP example
An ARP request is sent to the broadcast MAC. The source MAC is the requester's NIC. Switches learn the source from the request and flood the broadcast so all devices can respond if they own the IP.
Misconception: switches inspect payloads. They do not need payloads to forward; header MACs are sufficient for Layer 2 switching.
