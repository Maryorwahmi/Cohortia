Module 3 › Chapter 3.1 › Key Concepts
MAC Address
Unique hardware address used for Layer 2 identification.
Ethernet Frame
Contains source/destination MACs, payload, and error-checking for Layer 2 communication.
Switch
Layer 2 device that forwards frames based on a learned MAC address table.
Takeaway

Switching fundamentals combine MAC learning, selective forwarding, collision isolation, and local port controls to make LANs efficient and manageable.
