Module 3 › Chapter 3.1 › Port Security Basics
Definition

What port security does

Restricts which MAC addresses may transmit on a specific physical port and defines the switch's response to violations.

Allow a fixed number of MACs or specific MACs on a port.
Configure an action such as restrict traffic or shut the port when a violation occurs.
Scenario
You configure Gi0/3 to accept only a known workstation MAC. A visitor plugs in a laptop; the switch blocks the laptop's traffic or shuts the port, depending on the configured action.
Misconception: Port security is a complete defense. It's one layer; MAC spoofing and other attacks still require additional protections.
