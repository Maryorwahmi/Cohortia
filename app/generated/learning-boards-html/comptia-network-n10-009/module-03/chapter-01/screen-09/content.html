Module 3 › Chapter 3.1 › Observing ARP
Code examples
# Windows
ipconfig /all
arp -a
ping 192.168.1.1  # replace with your router's IP
arp -a

# macOS / Linux
ifconfig   # or: ip a
arp -a
ping 192.168.1.1  # replace with your router's IP
arp -a
Practical notes
  • The ARP cache shows IP-to-MAC mappings your host has learned recently.
  • Pinging a device typically causes an ARP request and populates the cache when a reply arrives.
  • Clearing the ARP cache forces new ARP requests and temporary flooding on the network while discovery occurs.
Misconception: ARP entries are permanent. They age and update as hosts come and go.
