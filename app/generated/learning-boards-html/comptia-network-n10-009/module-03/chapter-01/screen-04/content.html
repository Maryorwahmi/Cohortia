Module 3 › Chapter 3.1 › Hub vs Switch
Comparison

Hub (Layer 1)

Repeats electrical signals to all ports. All connected devices share a single collision domain, so simultaneous transmissions collide.

Collision domain: single, shared
Use case: legacy networks, testing only
Comparison

Switch (Layer 2)

Forwards frames using MAC addresses. Each physical port is its own collision domain, permitting full-duplex simultaneous send and receive.

Collision domain: per port
Use case: modern LANs for improved throughput
Example scenario
Two hosts on different switch ports transfer large files simultaneously and do not collide. On a hub both transfers would suffer collisions and retransmission delays.
Key takeaway
Switching isolates collisions per port, improving concurrency and throughput.
