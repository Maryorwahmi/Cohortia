Module 3 › Chapter 3.1 › MAC Learning
Process

Steps the switch follows

  1. Receive frame and read the source MAC address from the Ethernet header.
  2. Create or update a MAC table entry mapping the source MAC to the ingress port.
  3. If destination MAC is known, forward out the mapped port; if unknown, flood to other ports.
  4. Aging: entries expire after a period of inactivity and are removed.
Concrete example
Host A (AA:BB:CC:DD:EE:FF) on Gi0/1 sends an ARP request. Switch adds AA:BB:CC:DD:EE:FF → Gi0/1. When Host B replies, switch adds B's MAC and future frames are forwarded directly.
Misconception: MAC tables are permanent. Reality: entries age out and must be relearned.
Key takeaway: Dynamic MAC learning builds a mapping that enables efficient unicast forwarding.
