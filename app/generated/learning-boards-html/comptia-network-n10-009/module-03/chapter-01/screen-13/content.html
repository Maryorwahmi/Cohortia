Module 3 › Chapter 3.1 › Hands-on Activity

Step-by-step

  1. Open terminal and run ipconfig /all or ifconfig / ip a to find your MAC.
  2. Run arp -a and note current IP-to-MAC mappings.
  3. Ping your default gateway to trigger ARP if needed.
  4. Run arp -a again and compare changes.
  5. Generate traffic from another host and observe switch learning via MAC table inspection.
Notes
If a new MAC does not appear in the MAC table, ensure the host transmits frames. If ARP entries do not appear, check connectivity and repeat the ping step.
Reflection: How did the switch's learning change traffic flow after the ARP exchange?
