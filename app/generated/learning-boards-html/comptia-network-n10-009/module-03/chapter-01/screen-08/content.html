Module 3 › Chapter 3.1 › Collision vs Broadcast Domains
Collision Domain

Per-port isolation

A switch makes each port its own collision domain, letting devices transmit without colliding with other ports. Full-duplex removes the collision problem between two devices on a switched link.

Broadcast Domain

Shared across ports

Broadcast frames are forwarded to all ports within the same broadcast domain. Switches do not, by default, block broadcasts; logical segmentation is required to limit them.

Example
An ARP request sent by one host is broadcast and reaches all hosts through the switch. But two hosts on different switch ports can exchange unicast frames simultaneously without collisions.
Key takeaway
Switches isolate collisions but not broadcasts; plan segmentation if broadcasts become excessive.
