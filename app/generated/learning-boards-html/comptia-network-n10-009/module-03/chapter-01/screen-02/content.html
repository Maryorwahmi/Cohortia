Learning Objectives

Four practical objectives you can verify by inspection or simple commands.

Learn
Understand
Apply
Master
01
Compare hubs and switches

Explain how a hub repeats signals and creates one collision domain, while a switch forwards selectively and isolates port collisions. Verified competency milestone: explain a slowdown caused by a hub in a troubleshooting scenario.

02
Describe MAC learning and forwarding

State how switches record source MACs in a MAC address table and forward frames by lookup, flooding only when unknown. Milestone: read a MAC table and explain an observed entry.

03
Identify Ethernet frame parts

Recognize source/destination MAC fields and frame purpose at Layer 2. Milestone: point to MAC fields when shown a sample frame breakdown.

04
Explain collision vs broadcast domains and port security

Distinguish the two domain types and describe how a port can be restricted to specific MAC addresses to stop unauthorized access. Milestone: describe a port security behavior for a misconnected device.
