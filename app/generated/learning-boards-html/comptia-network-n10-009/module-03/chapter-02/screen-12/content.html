STP Mechanics

BPDUs, root bridge, and port states

BPDUs let switches elect a root and decide which ports forward and which block to avoid loops.

BPDU role
BPDUs communicate priority and path cost information so switches can build a loop-free tree.
Port states
Ports can be root, designated, or blocked. Blocked ports don't forward user frames but do listen for BPDUs.
Quick checklist
  • Root chosen by lowest Bridge ID (priority + MAC).
  • Root ports have lowest cost to root.
  • Designated ports serve each segment.
  • Blocked ports prevent loops but listen for BPDUs.
Key Takeaway

BPDUs are essential to STP; they carry the information used to elect the root and set port roles to prevent loops.
