Problem Statement

Layer 2 loops and broadcast storms

Redundant active paths can let broadcasts circulate and multiply, consuming bandwidth and crashing devices.

Concrete failure
Two switches connected by two active links can create a loop where a single broadcast frame is forwarded repeatedly until the network is overwhelmed.
Why redundancy can fail
Redundant links provide alternate paths but without a loop-avoidance protocol there is no mechanism to block looping traffic.
Design guidance
Always enable STP
STP blocks redundant paths as needed while keeping the network resilient to failures.
Key Takeaway

Redundancy without loop prevention risks broadcast storms; use STP to get safe fault tolerance.
