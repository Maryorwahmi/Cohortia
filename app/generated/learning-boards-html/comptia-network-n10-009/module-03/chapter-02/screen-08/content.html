Inter-VLAN Communication

Routing is required between VLANs

VLANs create separate Layer 2 domains. To cross those domains you must route packets at Layer 3.

Analogy
Think of VLANs as separate rooms; routers are doors that let selected traffic pass under controlled rules.
Practical check
If two hosts in different VLANs cannot talk, ensure a router or Layer 3 interface exists and subnets are correctly assigned.
Scenario
Example
Sales VLAN 10 and HR VLAN 20 remain isolated. To share a file server between them, configure routing between the VLAN subnets on a router or L3 switch.
Key Takeaway

VLANs are isolation at Layer 2. Inter-VLAN services require Layer 3 routing to allow controlled communication.
