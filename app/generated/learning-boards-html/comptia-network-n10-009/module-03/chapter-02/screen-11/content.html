Common misconfigurations

Trunk mismatch
One side trunking, one side not. Result: some VLANs don't cross the link.
Native VLAN mismatch
Untagged frames land in different VLANs if native VLANs differ.
Access mode omission
Forgetting switchport mode access leaves ports in unexpected modes and VLANs.
Troubleshooting checklist
  • Confirm both ends are configured as trunk where needed.
  • Ensure allowed VLAN lists include required VLAN IDs.
  • Match native VLANs on both ends to avoid untagged mismatches.
  • Set access ports explicitly with switchport mode access.
Quick tip
Document trunk settings and native VLANs so changes are consistent across the network.
