802.1Q Trunking

Trunk links and VLAN tags

A trunk carries multiple VLANs by tagging frames so receiving switches can map frames to VLANs.

How tagging works
802.1Q inserts a 4-byte tag into the Ethernet frame containing the VLAN ID, so the remote switch knows the VLAN context.
Common misconfig
Mismatched allowed VLANs or native VLAN differences can cause dropped frames or unexpected untagged traffic.
Practical scenario
Example
VLAN 10 frames travel across a trunk between Switch A and Switch B. The tag indicates VLAN 10 so frames reach only Sales ports on the other switch.
Verification checklist
  • Confirm trunk mode on both ends.
  • Confirm allowed VLAN list includes required VLANs.
  • Check native VLAN consistency to avoid untagged mismatches.
Key Takeaway

Trunks let many VLANs ride one link; always align trunk and native VLAN settings on both sides.
