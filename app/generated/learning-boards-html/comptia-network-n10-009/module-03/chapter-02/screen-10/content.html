STP Process

Elect root, set roles, block loops

STP exchanges BPDUs to elect a root bridge and determine which ports forward and which block to stop loops.

Step 1 — Root Bridge
Switch with the lowest Bridge ID becomes root. The BID includes priority and MAC address.
Step 2 — Root & Designated Ports
Root ports provide the best path to root. Designated ports serve a link's best path to the root. Others block.
Failure recovery
If an active link fails, STP recalculates and may transition a blocked port to forwarding to restore connectivity.
Roles quick reference
  • Root Bridge — central reference point.
  • Root Port — best path from a non-root to root.
  • Designated Port — best path for a segment to the root.
  • Blocked Port — prevents loops; listens for BPDUs.
Key Takeaway

STP uses BPDU exchange to pick a root and block redundant links so frames do not loop.
