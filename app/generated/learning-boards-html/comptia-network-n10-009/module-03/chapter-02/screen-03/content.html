Module 3 › Chapter 3.2 › Practice Plan

How you'll practice

Step-by-step lab actions and checkpoints that confirm competence.

Step 1
Create VLANs

Define VLAN IDs and names for departments. This reduces broadcast scope and maps users to logical segments.

Step 2
Assign access ports

Set access mode on end-user ports so they carry a single VLAN only. This avoids accidental mixing of department traffic.

Step 3
Verify and troubleshoot

Use show commands to confirm VLAN membership and port modes. Check trunk settings and native VLAN consistency across links.

Checkpoint
Can you explain why two devices in different VLANs cannot reach each other without routing?
