Confirm return paths
Ensure both routers have routes for each other's networks to avoid asymmetric failures.
Interpret route codes
Codes like C and S reveal how a route was learned; metrics explain preference.
Check NAT state
When internet access fails, inspect translation tables to see if PAT mappings exist or expired.
Final tip

Combining routing verification with NAT checks resolves most connectivity problems between local networks and the internet.
