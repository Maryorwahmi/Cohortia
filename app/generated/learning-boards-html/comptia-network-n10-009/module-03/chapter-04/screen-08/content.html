Module 4 › Chapter 3.4 › Configure a Basic Static Route
Terminal sequence (simulated)
Follow these steps in order: enter enable, enter configure terminal, add the ip route command, then exit and verify with show ip route. The next-hop argument should be the reachable neighbor on the shared link.
RouterA> enable
RouterA# configure terminal
RouterA(config)# ip route 192.168.2.0 255.255.255.0 10.0.0.2
RouterA(config)# exit
RouterA#
This command instructs Router A to reach 192.168.2.0/24 via next-hop 10.0.0.2. After this, use show ip route to verify the static route appears with an S code in the routing table.
Concrete tip
On a point-to-point serial link, some admins try to use the interface name instead of the next-hop IP. While this can work in specific scenarios, it often causes ambiguity; explicitly specifying the next-hop IP reduces mistakes.
Key Takeaway

Practice the command sequence in a simulator, then verify the route entry to confirm correct next-hop and mask.
