Module 4 › Chapter 3.4 › Key Concepts
Router
A Layer 3 device that forwards IP packets between networks based on routing information.
Routing Table
Contains destinations, next-hops, exit interfaces, metrics and route sources used for forwarding decisions.
NAT / PAT
Translate private addresses to public addresses; PAT uses ports so many hosts share one public IP.
Takeaway

Mastering routing tables, route selection, and NAT concepts will help you design reachable, resilient networks that connect to the internet reliably.
