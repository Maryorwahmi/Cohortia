Module 4 › Chapter 3.4 › Verify with show ip route
Sample output (simulated)
Codes: C - connected, S - static, R - RIP, O - OSPF
Gateway of last resort is not set

     10.0.0.0/30 is subnetted, 1 subnets
C       10.0.0.0 is directly connected, Serial0/0/0
     192.168.1.0/24 is variably subnetted, 1 subnets, 2 masks
C       192.168.1.0/24 is directly connected, GigabitEthernet0/0
S*     192.168.2.0/24 [1/0] via 10.0.0.2
Read the codes to determine route origins. The S indicates static; C indicates directly connected networks. The presence of an S* line shows a static route that also has a candidate default marker in this simulated output. Use this output to confirm the next-hop and the interface are correct and reachable.
Practical checks
  • Confirm the next-hop IP is on a directly connected network shown as C.
  • Check the metric in brackets when multiple routes exist to determine preference.
  • If the static route is missing, re-run the ip route command and ensure you are in the correct configuration mode.
  • Verify physical and logical interface status to ensure reachability to the next-hop.
