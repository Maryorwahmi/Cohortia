Module 4 › Chapter 3.4 › NAT and PAT
NAT overview
NAT remaps private source addresses to a public address for outgoing connections and reverses translations for incoming replies so internal hosts can communicate with the internet.
PAT (NAT Overload)
PAT maps multiple private IPs to a single public IP by translating source ports and keeping a table of public IP:port to private IP:port mappings.
Home network example

Your router uses PAT so every device shares the ISP-assigned public IP. The router assigns unique source ports to track each session.

Operational note
The router maintains translation state and timeouts. If a translation expires, new packets create a new mapping. NAT does not replace proper firewall controls; it simply translates addresses and ports.
Check your understanding
Why is PAT necessary in IPv4 home networks? Answer: because IPv4 public addresses are scarce and PAT allows many private hosts to use a single public IP by distinguishing sessions with ports.
