Module 4 › Chapter 3.4 › Static Routing
Advantages
  • Simple to configure in small networks.
  • No routing protocol overhead or periodic updates.
  • More secure by default since only configured routes exist.
Disadvantages
  • Not scalable for large networks.
  • Requires manual updates after topology changes.
  • Human errors can cause misrouting or one-way traffic.
Common mistake

Forgetting to add the return route on the remote router or using a wrong next-hop address leads to black-holing traffic.

Scenario
Router A connects to a local LAN and to a point-to-point link with Router B. To reach Router B’s remote LAN, a static route on Router A points to Router B’s link IP as the next-hop. This is stable and efficient when the link rarely changes, but you must ensure Router B also knows how to return traffic to Router A’s LAN.
Check your understanding
If communication is one-way after adding a static route, what is the likely cause? Answer: the remote side lacks a route back to the original network.
