Module 4 › Chapter 3.4 › How a Router Forwards a Packet
Step-by-step
1. Receive frame and extract IP packet.
2. Inspect destination IP address in the packet header.
3. Lookup routing table and apply longest-prefix match.
4. Decrement TTL and forward to next-hop via exit interface.
5. If no match, use default route or drop and send ICMP Destination Unreachable.
Key Takeaway

Forwarding is deterministic: correct routes in both directions are required for successful communication.

Example scenario
Router A has 192.168.1.1/24 and a serial link 10.0.0.1/30 to Router B (10.0.0.2). A host 192.168.1.10 wants 192.168.2.5. Router A’s routing table contains: S 192.168.2.0/24 via 10.0.0.2. Router A forwards packets to 10.0.0.2. If Router B lacks a return route to 192.168.1.0/24, the reply is dropped and communication fails.
Troubleshooting hint
Check both the outgoing route on the sender’s router and the return route on the remote router. One-way routing often means the return path is missing or incorrect.
