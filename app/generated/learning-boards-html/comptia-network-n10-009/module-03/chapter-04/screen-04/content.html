Module 4 › Chapter 3.4 › What is a Router?
Definition
A router forwards IP packets between distinct networks by selecting routes based on destination addresses and routing information.
Key points
  • Each router interface has an IP and connects to a different network.
  • Routing decisions use the destination IP and the routing table’s longest-prefix match.
  • Default routes cover unknown destinations; no route means the packet is dropped.
  • Routers operate at Layer 3, not by MAC tables like switches.
Key Takeaway

A router connects separate networks; correct addressing and routes are required for end-to-end packet delivery.

Concrete example
Imagine a home router with a LAN interface 192.168.1.1/24 and a WAN public IP. A laptop at 192.168.1.10 sends a packet to a web server on the internet. The router sees the destination is not in 192.168.1.0/24, consults its routing table, and forwards the packet to the ISP next-hop. When the reply returns, NAT or PAT will translate and forward it back to the laptop if configured.
Common misconception
Treating routers as simple switches: routers forward based on network addresses and routing state, not MAC-forwarding tables. Security and route policies at Layer 3 affect reachability.
Check your understanding
How does a router decide to drop a packet? Answer: when no matching route and no default route exist, and it may send an ICMP Destination Unreachable back to the source.
