Common metrics
  • RIP: hop count (limited to 15).
  • OSPF: link cost, often derived from bandwidth.
  • EIGRP: composite metric of delay, bandwidth and others.
  • BGP: path attributes and policy decisions, not a simple numeric cost.
Administrative preference
Routers may prefer routes from certain sources over others using administrative distance; this can override a metric when deciding the active route.
Example
If both a static route and an OSPF-learned route exist for the same prefix, the router uses administrative preference to decide which becomes active. If both are equal and the router supports ECMP, traffic may be balanced across equal-cost paths.
Troubleshooting tip

When paths are unexpected, inspect metric values and route source codes to understand why a route was chosen.
