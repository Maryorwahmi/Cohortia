01
Explain router role
Describe how a router forwards IP packets between networks and why each interface has its own IP.
VERIFIED COMPETENCY MILESTONE
02
Read routing tables
Identify destination, next-hop, exit interface, metric and route source when troubleshooting.
VERIFIED COMPETENCY MILESTONE
03
Configure static routes
Use the ip route command to add routes; understand the next-hop and interface forms.
VERIFIED COMPETENCY MILESTONE
04
Identify routing protocols
Recognize RIP, OSPF, EIGRP and BGP at a conceptual level and their typical use cases.
VERIFIED COMPETENCY MILESTONE
Practical skills
05
NAT and PAT
Explain how private addresses map to public addresses, and how port numbers let many hosts share one IP.
VERIFIED COMPETENCY MILESTONE
06
Troubleshoot one-way routing
Understand asymmetric routes and the need for return paths to avoid black-holing traffic.
VERIFIED COMPETENCY MILESTONE
07
Verify routes
Interpret a sample show ip route output and identify static, connected and candidate default routes.
VERIFIED COMPETENCY MILESTONE
08
Apply knowledge
Combine routing and NAT knowledge to design simple home or small office connectivity that reaches the internet.
VERIFIED COMPETENCY MILESTONE
