Module 3 › Chapter 3.3 › /24 → /26 Example
Start

192.168.10.0/24 split into four /26 subnets

Borrow 2 bits (because 2^2 = 4). New prefix /26 → mask 255.255.255.192 → last octet binary 11000000 → block size 64.

Subnet list
Subnet 1: 192.168.10.0/26
Network: 192.168.10.0
Hosts: 192.168.10.1 - 192.168.10.62
Broadcast: 192.168.10.63

Subnet 2: 192.168.10.64/26
Network: 192.168.10.64
Hosts: 192.168.10.65 - 192.168.10.126
Broadcast: 192.168.10.127
Continuation
Subnet 3: 192.168.10.128/26
Network: 192.168.10.128
Hosts: 192.168.10.129 - 192.168.10.190
Broadcast: 192.168.10.191

Subnet 4: 192.168.10.192/26
Network: 192.168.10.192
Hosts: 192.168.10.193 - 192.168.10.254
Broadcast: 192.168.10.255
Key takeaway
Use the block size to step through the address space and list network and broadcast boundaries precisely.
