Why IPv6

128-bit addressing for scale

IPv6 provides enormous address space to accommodate modern device growth. It also supports features like stateless address autoconfiguration and built-in improvements for routing and security operations.

Notation example
2001:0db8:85a3:0000:0000:8a2e:0370:7334
Compressed forms use :: to shorten consecutive zero fields when allowed.
Operational notes
  • No widespread broadcast; multicast replaces many broadcast use cases.
  • SLAAC can auto-assign addresses without DHCP in many cases.
  • NAT is usually unnecessary because of abundant addresses.
