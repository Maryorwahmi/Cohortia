Reserved Ranges
Common private blocks:
  • 10.0.0.0 - 10.255.255.255 (10.0.0.0/8)
  • 172.16.0.0 - 172.31.255.255 (172.16.0.0/12)
  • 192.168.0.0 - 192.168.255.255 (192.168.0.0/16)
How NAT works
NAT translates private internal addresses to a public address for outbound internet traffic and rewrites return traffic so internal hosts remain addressable.
Design note
When connecting networks (for example via VPN), overlapping private ranges cause routing conflicts. Choose subnets to avoid overlap or plan address translation at the connection point.
Analogy
Think of private addresses as internal extension numbers in a company; the public phone number is what outsiders call and the receptionist translates it to the correct extension.
