Module 3 › Chapter 3.3 › Quick Reminders
Host Count
2^(host bits) - 2
Remember to subtract network and broadcast for IPv4.
Block Size
256 - mask octet or 2^(host bits in octet)
Use block size to step through subnet ranges cleanly.
IPv6 Types
GUA, LLA, ULA, Multicast
Know the prefix hints and how each type is used.
Study tip

Practice by writing out a few subnet ranges from a /24 with different borrowings. Doing the arithmetic and listing examples builds reliable intuition for real network design.
