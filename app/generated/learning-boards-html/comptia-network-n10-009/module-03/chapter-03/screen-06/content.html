Module 3 › Chapter 3.3 › Subnetting in Practice
Numbered Steps
1. Count host bits
Host bits = 32 - original prefix. For /24: 8 host bits.
2. Borrow bits for subnets
Find smallest n with 2^n >= required subnets. For 4 subnets, n = 2.
3. Compute new prefix and mask
New prefix = original + borrowed. /24 + 2 = /26 → 255.255.255.192.
4. Block size and ranges
Block size in changing octet = 256 - mask octet. For /26 last octet 192 → block 64.
Worked example
Start: 192.168.10.0/24. Need 4 subnets. Borrow 2 bits → /26. Block size 64 → subnets at .0, .64, .128, .192. Each subnet offers 62 usable hosts.
Subnet 1: 192.168.10.0/26
- Hosts: 192.168.10.1 - 192.168.10.62
- Broadcast: 192.168.10.63
Subnet 2: 192.168.10.64/26
- Hosts: 192.168.10.65 - 192.168.10.126
- Broadcast: 192.168.10.127
Key takeaway
Follow the steps in order and validate counts with 2^n checks to avoid miscalculations.
