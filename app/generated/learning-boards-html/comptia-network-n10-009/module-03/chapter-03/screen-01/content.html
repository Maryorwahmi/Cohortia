Practical orientation

We’ll make subnetting practical by focusing on bit math, CIDR notation, and two worked examples: splitting a /24 into four /26 subnets and splitting a /24 into eight /27 subnets. Each step shows calculations and the final host ranges you can use in a real network.

Visual Concept
IPv4 (32-bit)
Dotted-decimal, e.g. 192.168.1.1
IPv6 (128-bit)
Hexadecimal, e.g. 2001:db8::1
Subnetting visual
Network bits fixed by mask, host bits available for devices. Subnets create separate broadcast domains and define routing boundaries.
Quick tip
Always check the host count formula
Use 2^(host bits) - 2 for usable hosts in IPv4 subnets, subtracting network and broadcast addresses.
