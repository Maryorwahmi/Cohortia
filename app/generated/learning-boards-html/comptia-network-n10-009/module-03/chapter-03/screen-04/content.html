Module 3 › Chapter 3.3 › What is an IP address?
Definition

Logical address for routing

IP addresses identify network interfaces. Routers read the network portion to move packets between networks and deliver them to the correct host portion inside the destination network.

Analogy
Network bits are like a city, host bits like a house number. The city tells the postal system where to route the letter.
Concrete example
192.168.1.10/24: /24 is the mask, so the first 24 bits identify the network 192.168.1.0.
Visual
IPv4 format
192.168.1.10 /24
- Network: 192.168.1.0
- Broadcast: 192.168.1.255
- Usable hosts: 192.168.1.1 - 192.168.1.254
Key takeaway
Routing uses the network portion only; ensure masks match to be in the same subnet.
Common misconception
An IP address does not represent a physical location. It represents an address in the network topology, which can change when devices move between subnets or networks.
