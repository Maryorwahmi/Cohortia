Global Unicast
Routable
Used like public IPv4 addresses; typically begin with 2 or 3.
Link-Local
Local only
Start with fe80::/10 and are automatically configured for local neighbor tasks.
Unique Local
Private
fc00::/7 range for private addressing inside organizations; not for global routing.
Multicast
Multicast begins with ff00::/8 and is used to send a packet to multiple destinations simultaneously. It replaces many IPv4 broadcast uses and is central to service discovery and group communication in IPv6 networks.
Design note
Plan ULAs and GUAs carefully when networks will connect externally. LLAs will always exist for interfaces and are useful for diagnostics and initial communication.
