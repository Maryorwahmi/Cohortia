Module 3 › Chapter 3.3 › CIDR & Masks
Concept

Prefix length defines network bits

CIDR notation shows the number of network bits. Convert that to dotted-decimal by filling each octet with ones for network bits, then converting to decimal.

Example conversions
/24 = 255.255.255.0
/26 = 255.255.255.192
/27 = 255.255.255.224
Host count formula
Usable hosts = 2^(32 - prefix) - 2. For /26: 2^6 - 2 = 62 usable hosts.
Pro tip
Memorize common masks: /24, /26, /27 to speed network planning; use bit arithmetic for unusual prefixes.
Quick visual
Binary view helps: for /26 the last octet has 11000000 (192). That gives a block size of 64 in the last octet, producing subnets at .0, .64, .128, .192 when starting from a .0 base.
Check your understanding
If you see 255.255.255.192, can you name the prefix? Yes—/26. Can you compute usable hosts? 62.
