How you'll practice

Work with two concrete subnetting problems: split a /24 into four /26 subnets, and split another /24 into eight /27 subnets. For each, compute the subnet mask, block size, network and broadcast addresses, and usable host ranges. Watch for common mistakes like counting totals without subtracting network and broadcast, or borrowing the wrong number of bits.

Practical mnemonic
Think "Borrow, Block, Bound": borrow bits, compute block size, list network/broadcast bounds.
