Step-by-step strategy
  1. Count host bits: 32 minus prefix length.
  2. Decide how many subnets you need and compute borrowed bits: smallest n with 2^n >= required subnets.
  3. New prefix = original prefix + borrowed bits; convert to dotted-decimal.
  4. Compute block size (increment) and list network/broadcast/usable ranges.
Mnemonic
Borrow → Block → Bound
Avoid this mistake
Don't forget to subtract 2 from host counts in IPv4 subnets

Network and broadcast addresses cannot be assigned to hosts; forgetting this yields an incorrect host capacity estimate.
