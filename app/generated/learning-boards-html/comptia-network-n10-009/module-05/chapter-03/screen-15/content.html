Module 5 › Chapter 5.3 › Key Concepts
Physical Layer Issues
Cables, NICs, and ports cause many complete outages; confirm link lights first.
IP Configuration
Read adapter details for address, mask, gateway, and DNS. Renew leases as needed.
DNS Resolution
If IP pings succeed but hostnames fail, run lookup tools to identify which DNS server is failing.
Summary takeaway
Use layered checks and concise command tests to narrow down the root cause quickly, document findings, and only then implement a remediation or escalate with evidence.
