Definition
IP Address Conflict
A conflict occurs when two devices use the same IP address on a local network. This creates unpredictable connectivity for both devices.
Immediate steps
Document the addresses, identify the conflicting MAC, and either reassign the static address or force a DHCP renew on one host.
DHCP Client Issues
When a client fails to obtain an IP, check that the DHCP server is reachable, scope is not exhausted, and the client can reach the server across the network.
Example
Run the adapter details command to see if a lease exists or if a self-assigned address is present, then try a DHCP renew sequence.
Common Mistake
Assigning a new static IP without checking the DHCP scope can create more conflicts for other users.
Key Takeaway

Resolve conflicts by documenting and removing duplicate assignments; prefer DHCP reservations for fixed devices.
