Core Concept
Recognize and contain security-related network issues
Indicators
  • Sudden traffic spikes from a single host.
  • Repeated failed logins or scans detected by IDS.
  • Unusual outbound flows to unknown destinations.
Containment steps
  1. Isolate the suspect host or VLAN.
  2. Collect flow logs and timestamps for analysis.
  3. Apply ACLs or firewall rules to block malicious traffic.
Example
Monitoring shows an internal host creating many outbound connections; isolate the host and review logs for signs of compromise.
Common Mistake
Treating security anomalies as configuration problems delays containment and broadens impact.
Key Takeaway

When traffic or behavior looks abnormal, collect evidence and isolate quickly so incident response can investigate and remediate.
