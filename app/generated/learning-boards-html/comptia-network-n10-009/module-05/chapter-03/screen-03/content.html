Module 5 › Chapter 5.3 › Learning Objectives — Tools
Quick tool map
Physical
Link lights & cable swaps
Example: a workstation with no link light often needs a new cable or a good port.
Configuration
ipconfig /all, ip addr show
Example: a wrong subnet mask isolates a host from its gateway even when the cable is fine.
DNS
nslookup, dig
Example: pinging 8.8.8.8 works but google.com fails — DNS is likely the issue.
Performance
Use ping/traceroute and flow tools to detect latency and bandwidth saturation. Example: traceroute shows a slow hop in the ISP network.
Security & Environment
Unexpected traffic surges could be DoS or a misbehaving device; environmental issues include overheating and power instability.
