Core Concept
Inspect adapter settings with commands
Common commands
Windows:
  ipconfig /all
  ipconfig /release
  ipconfig /renew
Linux:
  ip addr show
  sudo systemctl restart network  (or restart networking)
Use these to capture the full adapter state. Note DNS entries and any DHCP lease timestamps.
What to look for
  • IPv4 address in the correct subnet for the site's network plan.
  • Subnet mask that allows reachability to the gateway.
  • Default gateway present and not unreachable.
  • DNS servers configured and reachable from the host.
Example
If ipconfig shows 192.168.2.50/24 but the gateway is 192.168.1.1, the host is on the wrong subnet and cannot reach the gateway.
Common Mistake
Forcing a reconnect without noting current values can lose evidence; always document before changing settings.
Quick Fix
If DHCP is expected but missing, request a DHCP renew. If static assignment is wrong, reassign to a correct address consistent with the network plan.
