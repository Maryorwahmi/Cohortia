Core Concept
Diagnose DNS with lookup tools
Commands to run
nslookup google.com
nslookup 8.8.8.8  (reverse lookup)
dig google.com   (where available)
These show the server queried and whether it returned a valid IP. If the server times out, check DNS server settings and firewall rules on UDP port 53.
Example scenario
You can ping 8.8.8.8 but nslookup google.com shows no response from your DNS server. That suggests the DNS server is unreachable or not resolving names.
Temporary test: configure a known public DNS server for the client to confirm whether resolution returns. Remember to revert if this was a test-only change.
Common Mistake
Assuming a DNS outage across the internet. Often the client's DNS server or firewall rules are the issue.
Pro tip
Check both forward and reverse lookups; reverse failures often point to misconfigured authoritative servers.
Key Takeaway

Hostname failures with successful IP pings mean DNS. Use lookup tools to identify which server fails and whether traffic is blocked.
