Hands-on Activity
Simulated terminal walkthrough
Verify symptoms
ping 8.8.8.8         (confirm IP-level reachability)
ping google.com      (confirm hostname fails)
If IP ping works and hostname fails, proceed to adapter details and DNS tests.
Inspect and test DNS
Windows:
  ipconfig /all
  nslookup google.com
  ipconfig /release
  ipconfig /renew
Linux:
  ip addr show
  nslookup google.com
  sudo systemctl restart networking
Document the DNS servers and use nslookup to query them directly. If necessary, test with a public DNS server temporarily and then revert.
Example decision
nslookup fails against the configured server but works against a public server — contact DNS admin or replace the server entry through DHCP.
Common Mistake
Changing multiple settings at once prevents you from knowing which change fixed the issue.
Key Takeaway

Follow one-step-at-a-time tests: confirm IP, inspect adapter, test DNS, renew DHCP if needed, and document everything for reproducibility.
