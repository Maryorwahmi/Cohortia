Definition
NIC vs Switch Port Failure
A NIC failure prevents a single endpoint from forming a link even with known-good cables and ports. A switch port failure prevents devices using that specific port from connecting. Distinguish them by swapping endpoints and cables.
Test sequence
  1. 1. Try the suspect cable on another device that works.
  2. 2. Move the suspect device to a known-good port.
  3. 3. Observe link LED behavior and speed negotiation.
Document
Record MAC, switch port, and time of failure so replacements or firmware updates can be traced.
Scenario and resolution
Example: Device A had no link. You move cable from Device A to Device B and Device B works. Then you plug Device A into Device B's working port and Device A still has no link. That isolates Device A's NIC as the likely root cause.
Pro tip
If the link is unstable, check speed/duplex settings and try forcing a lower speed to test stability.
Common Mistake
Assuming the switch is bad because one port fails; intermittent ports can be caused by faulty cabling elsewhere in the patch panel wiring.
Key Takeaway

Use systematic swapping to identify whether a cable, NIC, or switch port is the true cause before replacing hardware.
