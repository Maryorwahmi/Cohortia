Module 5 › Chapter 5.1 › Troubleshooting Patterns
Recommended sequence
  1. Confirm anomaly with baselines.
  2. Poll devices with SNMP for counters and traps.
  3. Review NetFlow for traffic contributors.
  4. Capture packets for targeted conversations if needed.
Avoid these mistakes
  • Using one data source as the sole truth.
  • Setting alert thresholds from a single sample.
  • Capturing broad packet traces without filters.
Key Takeaway

Use a reproducible triage path and combine multiple data types to avoid misdiagnosis and wasted time during incidents.
