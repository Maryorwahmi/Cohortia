SNMP Basics
Agent, Manager, MIBs, Polling, Traps
An SNMP agent runs on networked devices and exposes MIB objects. A manager polls those objects periodically and can receive traps when a device signals an event. Use SNMP to monitor counters, status, and device health across many devices efficiently.
Use case example
Poll interface octet counters to compute bandwidth, monitor CPU percent, or receive traps when an interface flaps. These signals help you spot failing hardware or misconfigurations early.
Contrast
SNMP provides device state and counters but not detailed conversation records. NetFlow and packet captures handle per-flow and packet-level detail respectively.
Security note
Prefer SNMPv3 where possible for authentication and encryption. Treat community strings in v1/v2c like passwords if still used.
Key Takeaway

Use SNMP to monitor device health and counters; it tells you what devices report but not the contents of conversations.
