Module 5 › Chapter 5.1 › Tool Comparison
SNMP
Device state and counters
Use to poll interface counters, CPU, memory, and to receive traps when events occur.
NetFlow
Per-flow traffic summaries
Good for top talkers, heavy users, and trend analysis without capturing payloads.
Packet Capture
Packet-level inspection
Use when you need to see headers and payloads to confirm retransmissions, malformed frames, or protocol errors.
Triage sequence
  1. Alert or symptom observed.
  2. Check baseline and SNMP counters for device anomalies.
  3. Use NetFlow to find heavy users or unusual destinations.
  4. Capture packets for the specific conversation if deeper proof is needed.
Key Takeaway

Pick the tool that matches the question. Use SNMP, NetFlow, and packet capture together, not in isolation.
