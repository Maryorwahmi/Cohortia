Baselining
Establish normal metrics

Collect typical CPU, latency, and bandwidth over time so deviations become meaningful alerts. This matters because it reduces false positives and focuses responses.

Packet Analysis
Use a packet sniffer

VERIFIED COMPETENCY MILESTONE
How you will apply these skills
  • Use baselines to tune alert thresholds and reduce noise.
  • Inspect SNMP counters for interface errors and CPU anomalies.
  • Analyze NetFlow to find heavy users or unusual destinations.
  • Capture traffic to confirm retransmissions or slow server replies and act accordingly.
Reflection
Which tool would you choose first on a CPU spike?

Baselining identifies the spike as abnormal, then SNMP or flow data helps narrow whether device processes or traffic caused it.
