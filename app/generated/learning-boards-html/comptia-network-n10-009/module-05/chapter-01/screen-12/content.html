Module 5 › Chapter 5.1 › Terminal Demo
Step 1: ping
ping google.com
Observe average RTT and packet loss. High loss implies packet delivery problems requiring deeper inspection.
Compare with ping to local gateway to separate local from upstream issues.
Step 2: traceroute / tracert
traceroute google.com  # Linux/macOS
tracert google.com     # Windows
Identify the hop at which latency increases or probes disappear. Use that hop to focus network device checks.
Step 3: netstat
netstat -an
netstat -ano   # Windows
netstat -tulnp  # Linux (requires root)
Look for unexpected established connections or services listening on unexpected ports. Record PIDs where available to trace back to processes.
Reflection

Document each output and decide: poll SNMP for device counters, query NetFlow for traffic patterns, or capture packets for deeper proof.
