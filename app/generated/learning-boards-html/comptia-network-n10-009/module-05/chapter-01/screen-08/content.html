Module 5 › Chapter 5.1 › Terminal Tools
Examples
Use these commands during initial triage to collect latency, hop, and connection information before deeper capture or log analysis.
ping
ping google.com
traceroute / tracert
traceroute google.com  # Linux/macOS
tracert google.com     # Windows
netstat
Inspect active connections and listening ports to find unexpected services or suspicious remote hosts.
netstat -an        # show active connections and listening ports
netstat -ano       # Windows: includes PID
netstat -tulnp     # Linux: ports with process, requires root
Checklist
  • Record ping RTT and packet loss for local gateway and remote host.
  • Run traceroute to identify latency or hop failures.
  • Use netstat to spot abnormal or many established connections that indicate overload.
Key Takeaway

Terminal checks give immediate, actionable clues; use them to decide whether to poll devices, analyze flow data, or capture packets.
