Module 5 › Chapter 5.1 › Baselining
Definition
Establish a normal performance benchmark for network metrics.
Baselining requires representative sampling across times and conditions. Use rolling averages and percentiles to avoid overreacting to short-lived spikes. Record both central tendency and variation so you can set thresholds that matter.
Common baseline metrics
  • CPU utilization on routers and switches
  • Average and peak bandwidth per interface
  • Typical latency and jitter for critical links
  • Interface error rates and retransmissions
Process example
Collect five-minute samples over two weeks, compute the 95th percentile for bandwidth, and use that value to tune alert thresholds. This approach captures heavy but expected bursts while still flagging sustained excess use.
Mistake to avoid
Don't set alerts from a single day's readings; that often creates noise. Use representative windows and compare similar periods (weekday vs weekend).
Key Takeaway

Baselines provide context for alerts. They make thresholds meaningful and keep your monitoring signal clear.
