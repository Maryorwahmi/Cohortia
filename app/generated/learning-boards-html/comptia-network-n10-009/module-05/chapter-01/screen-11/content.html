Module 5 › Chapter 5.1 › Monitoring Metrics
Primary metrics
  • CPU and memory utilization on routers/switches
  • Interface throughput and utilization (percent of capacity)
  • Error counters: CRC, input errors, collisions
  • TCP retransmissions and duplicate ACKs
  • Latency and jitter for critical paths
  • Top talkers and heavy flows from NetFlow
Correlation example
If retransmissions and input errors rise together, suspect a physical link issue. If CPU spikes without traffic increase, check processes or configuration loops.
How to act
Set sensible thresholds from baselines, create alerts for multi-metric patterns, and drive triage: baseline → SNMP counters → NetFlow → capture.
Avoid alert fatigue by combining signals: alert when both utilization and error counters exceed baselined thresholds.
Key Takeaway

Monitor a balanced set of device, interface, and flow metrics and correlate them — that combination points to actionable root causes.
