Applied objectives and milestones

Create a logical diagram
Produce a clear map of IP subnets, VLANs, and routing paths with a designated default gateway. This artifact should enable troubleshooting of inter-VLAN routing.
VERIFIED COMPETENCY MILESTONE
Sketch a physical layout
Show rack placement, switch ports, and cable runs so a technician can locate and replace hardware without guesswork.
VERIFIED COMPETENCY MILESTONE
Define naming rules
Create consistent device names and a cable-label format that include location, device type, and ID for quick identification.
VERIFIED COMPETENCY MILESTONE
Follow change management
Adopt a simple workflow to plan, approve, implement, and then update documentation after every network change.
VERIFIED COMPETENCY MILESTONE
