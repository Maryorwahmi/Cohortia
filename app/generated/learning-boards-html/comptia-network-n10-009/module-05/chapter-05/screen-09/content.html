Process

Labeling & Naming

Define and publish a naming pattern. Enforce it in inventory entries and device hostnames so humans and tools find items consistently.
Device name pattern

[Location]-[DeviceType]-[Role]-[ID] — e.g., BLDG1-SW-FLOOR2-01

Cable label example

"SW1 G0/1 → RACK3 SRV5 NIC1" — include source, port, destination, and destination port.

Common mistake

Using informal or inconsistent abbreviations that differ between teams and spreadsheets.

Comparison: poor vs good
Poor

Device name: switch01, cable label: "Patch A3" — vague and ambiguous.

Good

Device name: NYC-SW-DIST-02, cable: "SW1 G0/1 → RACK3 SRV5 NIC1" — clear and actionable.

Key Takeaway

Precise naming and labels prevent confusion and speed physical and logical troubleshooting.
