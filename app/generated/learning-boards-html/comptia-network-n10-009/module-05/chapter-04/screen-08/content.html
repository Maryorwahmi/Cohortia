Designing a Management ACL
Create explicit allow rules for trusted admin hosts and a final deny any. Apply to the management interface or VTY lines.
Example ACL sequence
access-list 10 permit 192.168.10.50
access-list 10 deny any
line vty 0 15
access-class 10 in
exit
Concrete example
Permit only 192.168.10.50 to access VTY; deny all others.
Testing tip
Apply in a maintenance window and verify access from allowed and denied hosts before closing the window.
Pitfall
Overly broad denies can block monitoring or automation; include exceptions for required services.
