Learning Objectives
Learn, Understand, Apply, Master
Bloom: Learn → Understand → Apply → Master
01
Implement hardening techniques
Apply firewall rules, disable unused ports, and remove defaults to reduce attack surface.
VERIFIED COMPETENCY MILESTONE
02
Manage patches safely
Create a regular patch cycle with scanning, testing, deployment windows and a rollback plan.
VERIFIED COMPETENCY MILESTONE
03
Enforce secure device access
Use SSH, ACLs, strong passwords and MFA to restrict management interfaces to trusted sources.
VERIFIED COMPETENCY MILESTONE
04
Plan for physical security and recovery
Secure facilities and document DR/BC plans, define RTO and RPO, and test recovery procedures regularly.
VERIFIED COMPETENCY MILESTONE
