Module 5 › Chapter 5.4 › What is Network Hardening?
Definition & Scope

Network hardening combines policy, configuration, patching, access control, and physical safeguards to make systems more resilient. It is continuous and must be maintained over time.

Why it matters
Prevents attackers from exploiting default credentials or known vulnerabilities.
Concrete example
Changing default switch credentials and enabling SSH prevents trivial takeover and eavesdropping.
Common mistake
Relying solely on tools like antivirus without secure configs and patching.
Hardening components
Patch Management
Regular updates to software and firmware.
Configuration Mgmt
Disable defaults and keep versioned configs.
Access Controls
ACLs, strong passwords, and MFA for admins.
Physical Security
Locked racks, access systems, and environmental monitoring.
Key Takeaway

Treat hardening as continuous hygiene: patch, standardize, restrict, and protect physically.
