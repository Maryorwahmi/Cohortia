Learning Objectives — Applied Skills
Skills you can practice right away
Practical mnemonics included
01
Configuration baselines
Create a known-good baseline and store configs under version control for predictable rollbacks.
Mnemonic: BASELINE = Backup, Approve, Store, Enforce
VERIFIED COMPETENCY MILESTONE
02
ACL enforcement
Apply rules to limit management access and follow least privilege for traffic flows.
Mnemonic: LEAST = Limit, Evaluate, Allow, Secure, Test
VERIFIED COMPETENCY MILESTONE
03
Physical safeguards
Use locks, controlled access, and environmental sensors to protect hardware and cabling.
Mnemonic: LOCK = Limit, Observe, Control, Keep monitored
VERIFIED COMPETENCY MILESTONE
04
DR & BC basics
Define RTO and RPO, keep offsite backups, redundant links, and test plans regularly.
Mnemonic: TEST = Triage, Exercise, Store, Tweak
VERIFIED COMPETENCY MILESTONE
