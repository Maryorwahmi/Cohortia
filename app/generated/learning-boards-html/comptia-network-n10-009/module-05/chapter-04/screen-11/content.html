Simulated hardening commands
Use these steps as a checklist. They establish secure access, disable defaults, and persist the configuration.
enable
configure terminal
hostname MyCoreSwitch
enable secret <strong_password>
line console 0
password <console_password>
login
line vty 0 15
password <vty_password>
login
transport input ssh
exit
crypto key generate rsa
ip domain-name mynetwork.local

interface GigabitEthernet0/24
shutdown
exit

access-list 10 permit 192.168.10.50
access-list 10 deny any
line vty 0 15
access-class 10 in
exit

copy running-config startup-config
Why each step
Hostname and secrets protect identity and privileged access; RSA keys enable SSH; shutting ports stops rogue connections; ACLs restrict management access; saving persists changes.
Common pitfall
Not testing SSH key generation or forgetting to save the running config before reboot.
Key Takeaway
Perform these hardening steps immediately and document the changes for future audits.
