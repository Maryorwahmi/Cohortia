Module 5 › Chapter 5.4 › Common Mistakes
Frequent Errors
  • Leaving default accounts and passwords active.
  • Applying untested patches directly to production.
  • Not keeping configuration backups or change logs.
Example
Unstaged firmware update broke routing and required manual rollback because no config backup was available.
Mitigations
Keep baselines, automate and schedule backups, test patches in a lab, and require approval for high-risk changes.
Pro tip
Start with a small pilot group when deploying new updates to catch issues early.
