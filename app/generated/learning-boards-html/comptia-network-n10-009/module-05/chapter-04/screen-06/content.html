Architecture for Configuration Management
Design a system that automates backups, enforces baselines, and requires approval for changes.
Baseline
Store a known-good config for each device type.
Change Control
Require review and approval before changes go live.
Versioning
Keep time-stamped config versions to enable rollbacks.
Practical controls & checks
  • Automate nightly config backups for all network devices.
  • Use scripts or tools to compare running configs against baselines and alert on drift.
  • Keep an approval log for configuration changes and link to change tickets.
Common mistake

Not keeping backups or approvals: a single undocumented change can cause outages that are hard to diagnose.
