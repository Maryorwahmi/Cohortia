Module 5 › Chapter 5.4 › Securing Device Access
Protocol Comparison
SSH (Secure Shell)
Encrypted, preferred for CLI management. Supports key-based authentication.
Telnet
Plaintext protocol. Avoid for management because credentials and commands are exposed.
HTTPS vs HTTP
HTTPS encrypts web management interfaces; HTTP does not.
Best practices
  • Generate RSA keys and enable SSH to replace Telnet.
  • Use strong, unique admin passwords and enable multi-factor authentication where possible.
  • Apply ACLs to management interfaces to permit only trusted IPs or subnets.
Concrete example
Allow SSH to the management IP only from 192.168.10.0/24.
Misconception
Complex passwords without encrypted transport can still be captured.
