Module 5 › Chapter 5.2 › Verify Full System Functionality
Verification checklist
  • Re-run initial tests that demonstrated the failure.
  • Ping internal and external resources as appropriate.
  • Verify DNS resolution for critical services.
  • Ask the user to perform typical tasks to confirm behavior.
  • Monitor logs and dashboards for anomalies after the change.
Example follow-ups
After replacing a cable, confirm the user can access the file server, the printer, and a public website if required for their workflow. Then watch monitoring for 15–30 minutes to catch intermittent failures.
Key Takeaway

Don’t stop at the symptom. Verify all dependent services and confirm with users and monitoring to ensure a durable fix.
