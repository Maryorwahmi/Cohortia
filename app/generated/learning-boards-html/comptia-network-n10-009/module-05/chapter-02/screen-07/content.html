Commands to use
Use read-only commands first to observe configuration and reachability.
Windows
ipconfig /all
Linux
ip addr show
Reachability
ping <suspected-ip>
Example test sequence
  1. Confirm the user’s IP with ipconfig /all.
  2. Ping the gateway to verify local forwarding.
  3. If ping fails, check link lights or swap the cable to rule out physical issues.
Recording results
Capture command outputs and timestamps. These records help correlate with logs and prevent rework when multiple teams are involved.
Pro Tip

Prefer safe, observable checks first. Avoid disruptive changes until you have a confirmed cause and a rollback plan.
