Documentation template
Include a short problem summary, diagnostic steps, root cause, solution, verification, and prevention actions. Add timestamps and author initials.
Problem: User cannot access file server
Steps: ipconfig /all, ping gateway, swapped cable
Root cause: Faulty patch cable at user port
Solution: Replaced cable; verified access
Verification: User tested file open; monitoring normal
Prevention: Replace aging cables in Building A; note spare availability
Why this matters
A single documented incident can save hours later by showing what to check first and what fixes to avoid.
Pro Tip

Include failed tests and reasoning so others understand why some paths were dismissed during diagnosis.
