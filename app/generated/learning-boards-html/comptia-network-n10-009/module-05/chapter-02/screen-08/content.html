Module 5 › Chapter 5.2 › Plan of Action & Implement
Plan template
  • Action: what you will change
  • Impact: who might be affected
  • Rollback: how to revert if needed
  • Timing & notification: when and who to tell
Example
If a cable is faulty, action is to replace with a spare; impact is limited to one user; rollback is to reinsert the old cable if necessary; notify the user before swapping.
Implementation checklist
  1. Confirm backups and snapshots if relevant.
  2. Notify affected users and schedule the change.
  3. Execute the change and record steps and timestamps.
  4. Run verification tests immediately after.
Common Mistake

Applying a fix without a rollback plan often turns a small incident into a larger outage.
