Module 5 › Chapter 5.2 › Hands-on Activity: No Connectivity
Step-by-step simulation
  1. Identify: ask timing, scope, and observe link lights.
  2. Theorize: bad cable, incorrect IP, or switch port issue.
  3. Test: run ipconfig /all or ip addr show; ping the gateway.
  4. Implement: swap cable or move port; follow rollback plan if needed.
  5. Verify: user confirms file and web access; monitor logs.
  6. Document: record cause, steps, verification, and prevention.
Commands to observe (no change)
ipconfig /all    (Windows)
ip addr show      (Linux)
ping <gateway>   (reachability)
Example Documentation Entry

Problem: No connectivity for User A. Cause: faulty patch cable. Solution: replaced cable; verified file server and internet access. Prevention: replace aged patch cables in area; update inventory.
