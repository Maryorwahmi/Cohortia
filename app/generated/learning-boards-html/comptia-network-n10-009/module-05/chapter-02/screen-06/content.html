Module 5 › Chapter 5.2 › Establish a Theory of Probable Cause
Ranked theories
List plausible causes with the most likely first. This ordering guides low-impact tests and keeps changes safe.
Example: single user can't reach network
  • Theory A: bad cable or NIC
  • Theory B: incorrect IP configuration (gateway or mask)
  • Theory C: IP address conflict
Test selection
Choose the least intrusive test that will confirm or deny the top theory, for example swapping a cable or checking IP settings before rebooting infrastructure.
Practical tip
Write your theories down. A short list keeps you from jumping between ideas and preserves the chain of reasoning for documentation.
Misconception check
Do not assume a complex root cause when the symptom is localized. Start with simple checks like cable condition, link lights, and IP configuration.
Key Takeaway

Rank and test simple theories first; this reduces risk and speeds correct diagnosis.
