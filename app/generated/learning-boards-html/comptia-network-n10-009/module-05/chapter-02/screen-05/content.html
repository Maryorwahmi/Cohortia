Module 5 › Chapter 5.2 › Identify the Problem
Essential questions
  • When did it start and was anything changed recently?
  • Who is affected: one user, one department, or everyone?
  • Is the problem intermittent or constant?
  • What error messages or status indicators appear?
Checks to perform
Check link lights, Wi‑Fi status, monitoring alerts, and recent change logs before forming theories.

Common Mistake

Assuming the scope from a single report—always verify whether others are affected before concluding a root cause.
