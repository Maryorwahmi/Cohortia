Module 5 › Chapter 4.4 › AAA Framework
Core Concept

Authentication → Authorization → Accounting

A process flow that first verifies identity, then enforces permissions, and finally records activity for audits and troubleshooting.

Authentication
Credentials, certificates, or MFA prove who the requester is.
Authorization
Maps identity to roles, groups, or ACLs to permit or deny actions.
Accounting
Logs session start/stop, accessed resources, and usage metrics for audits.
Process Flow
Step 1
Authenticate
User provides credentials; system verifies identity, possibly using RADIUS or TACACS+.
Step 2
Authorize
Permissions are checked and access decisions are enforced per role or policy.
Step 3
Account
Activity is logged for auditing, billing, or forensic analysis.
Concrete Example
A user logs in and RADIUS authenticates credentials, a role gives file share access, and the login time plus accessed files are logged for auditing.
Common Mistake
Relying only on passwords without MFA leaves authentication vulnerable to compromise.
Key Takeaway

Use centralized AAA with strong authentication and comprehensive accounting to enforce least privilege and retain audit trails.
