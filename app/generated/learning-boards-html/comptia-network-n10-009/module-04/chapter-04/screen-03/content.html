Module 5 › Chapter 4.4 › Learning Objectives
01 — AAA Demonstration
Trace a login through RADIUS: authentication verifies credentials, authorization maps permissions, and accounting records the session for audit. Explain why logs are vital for incident response.
02 — 802.1X Walkthrough
Describe a supplicant initiating EAP to the authenticator, the authenticator forwarding to the authentication server, and the port opening only after success.
03 — VPN Scenarios
Sketch an SSL/TLS remote access session for a single user and an IPsec tunnel connecting two router networks for site-to-site traffic.
Mnemonics
AAA — Verify, Permit, Log. 802.1X — Plug, Auth, Open. VPN — Tunnel secures traffic.
Assessment Tip
When asked which VPN to use, match the scope: individual remote user or full network-to-network connection.
