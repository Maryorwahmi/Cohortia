Module 5 › Chapter 4.4 › VPN Comparison
Remote Access VPN
Connects a single user device to the corporate network. Often uses SSL/TLS or IPsec clients and may be clientless via a browser for web resources.
Use case
An employee at home accessing internal applications securely through an encrypted tunnel.
Site-to-Site VPN
Connects two entire networks, typically using IPsec tunnel mode to encrypt full IP packets between routers or gateways.
Use case
Two office locations share resources as if on a single private network over the internet.
Watch out
Split tunneling can allow traffic to bypass the VPN, exposing internal resources.
Security
Ensure strong authentication like MFA for remote users to avoid credential-based intrusions.
Selection tip
Match VPN type to scope: user-level access or network-to-network connectivity.
