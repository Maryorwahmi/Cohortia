Modes
Transport Mode
Encrypts only the IP payload; original header remains, useful for host-to-host protection.
Tunnel Mode
Encrypts entire original IP packet, adds a new header; common for site-to-site VPNs.
AH (Authentication Header)
Provides integrity and authentication but does not provide confidentiality.
ESP (Encapsulating Security Payload)
Provides confidentiality and often integrity and authentication; commonly used for encrypted tunnels.
Concrete Example
Two virtual routers establish an IPsec tunnel in tunnel mode using ESP so that all traffic between branch networks is encrypted across the internet.
Misconception
Assuming IPsec always hides headers; transport mode may leave some header information visible.
Key Takeaway

Choose mode and components that match whether you need payload-only protection or full packet encapsulation for network-level links.
