Module 5 › Chapter 4.4 › 802.1X
Architecture

Supplicant → Authenticator → Authentication Server

Port remains unauthorized until the authentication server validates the supplicant's credentials via the authenticator.

Supplicant
Client device that initiates authentication.
Authenticator
Switch or AP that enforces port state and relays credentials.
Authentication Server
Performs credential validation, often RADIUS.
Scenario
A laptop plugs into an office switch port, the supplicant sends credentials, the switch forwards them to RADIUS, and on success the port opens to the corporate VLAN.
Common Mistake
Neglecting secure onboarding for non-supplicant devices such as printers; provide a separate, controlled process.
Key Takeaway

802.1X enforces device authentication at the port level, blocking unauthorized devices until they validate with an authentication server.
