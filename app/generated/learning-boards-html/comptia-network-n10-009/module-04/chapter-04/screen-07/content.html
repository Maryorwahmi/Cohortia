Module 5 › Chapter 4.4 › Accounting
What to record
  • Authentication attempts and outcomes with timestamps.
  • Session start and stop events and assigned IP addresses.
  • Resources accessed and volume or duration of usage.
  • Source identifiers such as user name and originating IP.
Concrete example
A RADIUS accounting message logs a VPN session start and the assigned internal IP; later file access logs reference the same internal IP to link activity to the user session.
Practical considerations
Decide retention periods based on compliance and storage.
Protect logs from tampering by centralizing and restricting access.
Integrate with SIEM for correlation and alerting.
Key Takeaway
Comprehensive accounting is as important as authentication and authorization; without logs you lose the ability to investigate and remediate incidents effectively.
