Learning Objectives

Learn, Understand, Apply, Master

Bloom: Learn → Understand → Apply → Master
01
Explain AAA
Define Authentication, Authorization, and Accounting. Explain how RADIUS or TACACS+ connect to directory services for centralized control.
Verified Competency Milestone
02
Describe 802.1X
Explain port-based access control using the supplicant, authenticator, and authentication server workflow, and when ports transition to authorized state.
Verified Competency Milestone
03
Differentiate VPN types
Contrast remote access and site-to-site VPNs and name common protocols such as IPsec and SSL/TLS and their usual use cases.
Verified Competency Milestone
04
Explain VPN benefits
Describe encryption, integrity, and secure remote access benefits, plus common mistakes like weak credentials and split tunneling.
Verified Competency Milestone
