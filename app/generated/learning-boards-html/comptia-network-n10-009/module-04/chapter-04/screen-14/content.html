Module 5 › Chapter 4.4 › Key Concepts
VPN
Encrypted tunnel for private communications over public networks.
IPsec
Suite for securing IP traffic; use ESP for confidentiality and tunnel mode for site-to-site links.
VPN Concentrator
Device that manages many remote connections; protect it with strong authentication and monitoring.
Final takeaway
Match VPN type and IPsec mode to the connectivity need, enforce strong authentication, and apply least privilege so a compromised credential does not become a full network breach.
