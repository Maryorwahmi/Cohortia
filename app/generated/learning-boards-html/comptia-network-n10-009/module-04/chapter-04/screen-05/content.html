Module 5 › Chapter 4.4 › Authentication
Definition

Prove identity before access

Authentication can use something you know, something you have, or something you are. Combining categories increases assurance.

Password
Simple to deploy but vulnerable to reuse and phishing.
Certificate
Strong when centrally issued and revoked; used for device and user authentication.
Biometrics
Convenient but requires careful privacy and fallback planning.
Concrete example
A VPN login that requires a password and an approving push notification demonstrates multi-factor authentication in practice.
Common Mistake
Assuming long passwords alone are sufficient. Credential compromise via phishing or reuse still grants access without another factor.
Key Takeaway

Use multi-factor authentication and central credential management to increase assurance and make compromise harder for attackers.

Pro Tip
Prefer managed certificates for devices and enforce MFA for user VPN access to reduce risk from stolen passwords.
