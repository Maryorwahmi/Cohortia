Module 4 › Chapter 4.3 › Learning Objectives — Continued
Hands-on mindset
Configure, test, and document wireless settings so that authentication and encryption are enforced for every user.
Detect Rogue APs
Look for unknown SSIDs tied to internal subnets or duplicate SSIDs with different signal sources.
Disable WPS
WPS PIN brute-force is documented; turn it off unless absolutely necessary.
RADIUS Setup
Add the AP as a client, set a shared secret, and create user accounts or integrate directory services.
Test with a user
Walk through an authentication to ensure per-user keys are issued and access is logged.
Bloom bar
Learn → Understand → Apply → Master
These objectives move you from knowing protocol names to configuring and defending a real wireless deployment.
