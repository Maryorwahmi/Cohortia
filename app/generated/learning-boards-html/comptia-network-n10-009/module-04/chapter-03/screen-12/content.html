Hands-on Activity › Configure WPA2-Enterprise (conceptual)
Access Point (AP) configuration
  • • Set SSID to "CorpNet_Secure" or similar.
  • • Select WPA2-Enterprise and enable 802.1X.
  • • Configure RADIUS server IP (example: 192.168.1.100) and a strong shared secret.
  • • Disable WPS, change admin credentials, update firmware.
RADIUS server configuration
  • • Add AP as a RADIUS client using its management IP.
  • • Configure the same shared secret on the RADIUS server.
  • • Create user accounts or integrate with a directory like Active Directory.
  • • Enable logging and set authentication policy (password or certificate).
Alice's authentication walkthrough
1) Alice selects "CorpNet_Secure." 2) Her device prompts for username and password. 3) AP forwards credentials to RADIUS. 4) RADIUS returns Access-Accept. 5) AP assigns a unique session key and grants network access.
# AP example
ssid "CorpNet_Secure"
security wpa2-enterprise
radius-server ip 192.168.1.100
radius-shared-secret superSecretSharedKey
# Disable WPS
wps disable
