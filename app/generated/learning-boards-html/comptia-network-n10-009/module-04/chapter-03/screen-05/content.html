Definition › WEP and WPA: historical weaknesses
WEP: an insecure baseline
WEP's cryptography allowed easy key recovery, so it failed as a confidentiality control.
  • • Weak key scheduling and short IV space enabled fast attacks.
  • • Tools can recover keys in minutes, making WEP unsuitable for protection.
WPA and TKIP
WPA introduced TKIP to patch WEP without replacing hardware. TKIP added per-packet mixing and dynamic keys, but compatibility compromises left residual vulnerability compared to AES.
Concrete example
A legacy AP in a café running WEP allowed an attacker outside to capture traffic and decrypt client frames quickly. After replacing the AP with WPA2-capable hardware using AES, the same attacker could no longer trivially recover session traffic without knowing the strong passphrase or credentials.
Common mistake

Assuming "WPA" always means secure. Inspect whether TKIP or AES is in use; prefer AES and modern modes.

Next step: move to WPA2/AES or WPA3 when possible and replace or upgrade equipment that only supports legacy modes.
