Module 4 › Chapter 4.1 › Integrity
Definition

Integrity: detect and prevent tampering

Use hashing and signatures to confirm data hasn't been altered. Integrity verifies accuracy and origin when paired with signatures.

Hashing
A hash value changes if the file changes, letting you detect tampering.
Digital signatures
Bind a hash to a verified source, providing stronger assurance of origin and integrity.
Protect verification artifacts
Store hashes and signatures where attackers cannot trivially replace them.
Concrete example
Distribute software with a published hash; users compute the hash after download to detect modification during transfer.
Common mistake

Publishing verification material on the same insecure channel as the file allows an attacker to replace both, defeating integrity checks.

Key Takeaway

Integrity tells you if data changed. Make verification robust by protecting the verification channel.
