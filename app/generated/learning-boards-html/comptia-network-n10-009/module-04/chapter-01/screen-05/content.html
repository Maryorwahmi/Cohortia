Definition

Confidentiality in networks

Ensure that only authorized users can access sensitive information. Implemented with encryption and access controls.

Encryption
Protects data in transit and at rest; example: TLS for web traffic.
Access control & authentication
Restrict who can read or decrypt data and log access events for auditing.
Data classification
Label data by sensitivity so protections match risk and value.
Concrete example
Classify customer payment data as high sensitivity, encrypt it at rest and in transit, and restrict access to payment processing roles only.
Common mistake

Assuming a firewall makes data private. If internal storage is unencrypted, a breach still reveals secrets.

Key Takeaway

Combine encryption, access controls, and classification so a single failure doesn't expose sensitive data.
