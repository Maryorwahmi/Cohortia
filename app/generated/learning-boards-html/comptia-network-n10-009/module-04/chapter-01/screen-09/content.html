Malware types and behaviors
Virus
Attaches to programs and requires user action to run. Example: an infected document that executes code when opened.
Worm
Self-replicates across networks, spreading without user action and potentially infecting many systems quickly.
Trojan
Masquerades as useful software while performing malicious actions in the background.
Ransomware
Encrypts files to deny availability until a ransom is paid; recovery depends on backups and containment.
Spyware
Collects user information without consent, compromising confidentiality.
Defensive mix
Combine endpoint protection, patching, segmentation, and backups to detect, contain, and recover from malware.
Key Takeaway

Match defenses to malware behavior: stop spread with segmentation and patching, detect with endpoint tools, and recover with tested backups.
