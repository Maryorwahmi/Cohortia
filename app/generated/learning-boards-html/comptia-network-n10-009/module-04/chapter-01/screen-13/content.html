Module 4 › Chapter 4.1 › Security Controls
Controls compared
Technical Controls
Firewalls, IDS/IPS, encryption, antivirus. Automated defenses that enforce security rules.
Administrative Controls
Policies, procedures, training, incident response plans. Guide people and processes.
Physical Controls
Locks, cameras, guards, environmental controls. Protect physical assets and prevent tampering.
Key Takeaway

No single control type is sufficient. Combine policies, technology, and physical measures so compromises in one layer do not immediately expose assets.
