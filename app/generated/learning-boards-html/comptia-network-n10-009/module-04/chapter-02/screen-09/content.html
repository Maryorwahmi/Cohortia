Module 4 › Chapter 4.2 › Packet-filtering vs Stateful Firewalls
Packet-filtering
  • Inspects headers of individual packets (IP, port, protocol).
  • Stateless: no memory of prior packets; each is evaluated alone.
  • Fast and simple; needs explicit rules for both directions if required.
Stateful inspection
  • Maintains a connection state table of active sessions.
  • Allows return traffic for established connections without separate rules.
  • More intelligent filtering suitable for modern networks; common in most firewalls today.
Why it matters
Choose packet filters for very high-performance, simple filtering at the edge. Choose stateful firewalls when you need correct connection behavior and fewer rules to manage bidirectional flows.
