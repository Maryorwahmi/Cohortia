Module 4 › Chapter 4.2 › Hands-on: Configure Router1 for SSH and ACL
Starter checklist
  1. Console into Router1 and set hostname and domain.
  2. Generate RSA keys (e.g., 1024 or 2048), create user netadmin with a strong secret.
  3. Configure line vty 0 4 to transport input ssh and login local.
  4. Create access-list 1 permit 192.168.10.50 and access-list 1 deny any.
  5. Apply access-class 1 in on VTY, test from allowed and denied hosts, save config.
Verification steps
1. From 192.168.10.50 initiate SSH and expect a successful login.
2. From any other host attempt SSH and expect the connection to be denied.
3. Confirm running-config contains the ACL and VTY access-class and that the config is written to memory.
Tip: Keep console access ready to recover if a configuration change blocks management unintentionally.
