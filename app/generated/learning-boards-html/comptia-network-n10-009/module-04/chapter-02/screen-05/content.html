Module 4 › Chapter 4.2 › Change Default Credentials
Step-by-step
  1. Create a unique admin username on the device and assign minimal required privileges.
  2. Set a strong password or secret following complexity guidance and rotate regularly.
  3. Remove or disable factory default accounts and blank passwords.
  4. Document owners and rotate credentials; backup the configuration after changes.
  5. Test login and failover procedures to ensure no accidental lockouts.
Common mistakes
  • Reusing passwords across multiple devices.
  • Keeping Telnet or unauthenticated management enabled during setup.
  • Forgetting to save the running configuration to persistent memory.
Check

After changing credentials, run an authentication test and save the config to ensure persistence.
