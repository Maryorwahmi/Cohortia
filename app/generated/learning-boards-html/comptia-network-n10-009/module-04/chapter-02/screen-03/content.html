Module 4 › Chapter 4.2 › Objectives — Practical Checks
Lab verification steps
Device Hardening
Confirm default accounts removed, run a port scan to check open management ports.
Secure Access
Attempt Telnet/HTTP — expect failures. Try SSH and HTTPS — expect encrypted sessions and authentication.
ACLs
Test permit and deny cases from permitted and non-permitted IP addresses; note implicit deny behavior.
Firmware
Back up config, follow vendor upgrade steps, and validate device functionality post-upgrade.
