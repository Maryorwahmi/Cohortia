Module 4 › Chapter 4.2 › Configure SSH on a Cisco-like Device
Command Walkthrough (visual)
Router> enable
Router# configure terminal
Router(config)# hostname MyRouter
MyRouter(config)# ip domain-name example.com
MyRouter(config)# crypto key generate rsa modulus 2048
MyRouter(config)# username admin secret MyStrongPassword!
MyRouter(config)# line vty 0 4
MyRouter(config-line)# transport input ssh
MyRouter(config-line)# login local
MyRouter(config-line)# exit
MyRouter(config)# exit
MyRouter# write memory
Note: this is a visual code panel; test each step in a lab environment.
Explanation & checks
  • Hostname and domain are required for key generation to produce host-unique keys.
  • The RSA key encrypts SSH sessions; choose 2048 bits when device performance allows.
  • VTY lines must be configured to accept SSH only — prevents Telnet fallback.
  • Create local users or point to centralized auth for larger deployments.
Common misconception

Generating keys without restricting VTY or testing can still leave Telnet or other paths open. Test before saving.
