How ACLs work
ACLs are ordered rules evaluated sequentially. The first rule that matches a packet determines whether it is permitted or denied. If no rule matches, the implicit deny drops the packet.
Rule ordering matters. Place specific permits before broad denies.
Implicit deny prevents unknown traffic — explicitly permit required flows.
Test ACLs in a lab or maintenance window to avoid outages.
Concrete example
Router(config)# access-list 10 permit 192.168.1.10
Router(config)# access-list 10 deny any
Router(config)# line vty 0 4
Router(config-line)# access-class 10 in
Router(config-line)# exit
This permits only 192.168.1.10 to access VTY and denies everything else due to explicit deny and implicit deny if rule absent.
