Concept Map
16:9 HD Classroom
Device Hardening
Remove defaults, disable services, enforce strong admin credentials.
Access Control
ACL rules permit or deny traffic; implicit deny applies at the end.
Secure Remote Access
Use SSH and HTTPS; avoid Telnet and HTTP for management.
Firmware
Keep firmware current; backup configs before upgrades and download from vendors only.

Practical steps like changing default passwords and applying ACLs immediately reduce risk. We'll practice SSH configuration and an ACL to limit management access during the hands-on activity.
