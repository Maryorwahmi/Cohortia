Module 4 › Chapter 4.2 › Disable Unnecessary Services
Common services to evaluate
  • Telnet and HTTP — prefer SSH and HTTPS for management.
  • SNMP — use v3 with authentication and limit community strings or disable if not required.
  • Unused routing protocols or demo services — disable if not part of the design.
Before disabling, review automation and monitoring to avoid breaking operations.
Example checklist
Inventory current services and who relies on them.
Plan maintenance window and backups before changes.
Disable services incrementally and verify monitoring and access.
