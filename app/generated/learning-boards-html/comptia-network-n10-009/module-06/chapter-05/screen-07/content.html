HSRP / VRRP and Clustering

HSRP and VRRP provide a virtual gateway address so hosts have a single default gateway even when multiple routers are present. Clustering and load balancing let services continue when a server fails.

Gateway redundancy
Configure virtual IPs with one active router and standby peers. Tune timers for quicker failover if needed.
Service clustering
Group servers with shared responsibilities and use health checks so failed peers are removed from service pools.
Pitfall
Failover without health checks can route traffic to a corrupted instance. Always combine device redundancy with service-level checks.

Active / Standby gateway
