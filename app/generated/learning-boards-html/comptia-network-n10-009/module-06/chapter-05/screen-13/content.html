Task: Identify single points of failure
  • Single server host
  • Single NIC and cable
  • Single power supply and circuit
  • Single switch port or single upstream switch
Proposed Redundancy
  • Redundant power supplies, each on separate UPS/circuit
  • Multiple NICs configured for failover or LACP
  • RAID for local disk redundancy
  • Connect NICs to separate switches when possible
Network Redundancy Approach

Configure NIC teaming or LACP to combine links for bandwidth and failover. If using separate switches, ensure spanning-tree or switch design avoids loops and provides resilience.

Test Plan (Minimal)
# 1. Simulate NIC failure: disable secondary NIC and verify traffic continues # 2. Simulate power supply failure: remove PSU and confirm server stays online # 3. Restore and document timings and any errors
Key Takeaway

Design redundancy across hardware, network, and power, then validate with controlled tests to ensure failover works as expected.

Common Mistake

Designing redundancy without verifying it operationally; test every failover scenario to find hidden dependencies.
