Module 6 › Chapter 6.4 › SSH Configuration (Conceptual)
Secure Remote Access
Move from plaintext protocols to encrypted management with proper keys and access restrictions.
Conceptual command sequence
configure terminal
line vty 0 4
 transport input ssh
 login local
exit
crypto key generate rsa modulus 2048
ip ssh version 2
ip ssh authentication-retries 3
ip ssh timeout 60
username admin privilege 15 secret 
write memory
Note: These commands are typical conceptual steps. Always consult your device's reference for exact syntax.
Why this helps
  • Encrypts management traffic and credentials.
  • Keys prevent password replay and brute force when used properly.
  • Restricting admin IPs limits exposure to trusted hosts.
Misconception

Enabling SSH without limiting source IPs or preferring key-based auth still leaves management open to credential attacks. Combine controls for better security.

Key Takeaway

SSH should be configured with keys, restricted sources, and tested before disabling insecure services.
