Learning Objectives
Learn → Understand → Apply → Master
01
Implement patch management

Create a schedule to identify, test, and deploy firmware and OS updates so known vulnerabilities are closed quickly. Testing in a non-production environment reduces disruption and risk.

VERIFIED COMPETENCY MILESTONE
02
Protect configurations

Back up device configurations to encrypted, offsite storage and use version control to roll back unwanted changes. Encryption prevents exposure of stored credentials or ACLs.

VERIFIED COMPETENCY MILESTONE
03
Apply access control

Enforce physical controls and logical policies such as strong passwords, MFA, least privilege, and immediate removal of default accounts to reduce unauthorized access.

VERIFIED COMPETENCY MILESTONE
04
Use secure remote access

Choose encrypted protocols like SSH, disable Telnet or plain FTP, and restrict management access to specific admin IPs to protect credentials in transit.

VERIFIED COMPETENCY MILESTONE
