DNS resolution failures and tools

Use IP-level tests then name queries to determine whether DNS is the root cause.

# Basic checks
C:\> ping 8.8.8.8        # tests IP reachability
C:\> ping google.com     # tests name resolution + reachability

# Query DNS directly
C:\> nslookup google.com
C:\> nslookup google.com 8.8.8.8   # force query to Google's public DNS

# On Linux
$ dig @8.8.8.8 google.com
Practical example
If ping 8.8.8.8 succeeds but nslookup google.com fails against your local DNS and succeeds against 8.8.8.8, the local DNS server is likely misconfigured or unreachable for forwarders.
Misconception

An application error does not always mean DNS is fine. Verify by resolving names directly with nslookup or dig before blaming the app.
