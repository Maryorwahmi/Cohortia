DHCP failures and APIPA

APIPA (169.254.x.x) appears when DHCP leasing fails. Confirm reachability to DHCP server and scope availability before reconfiguring clients.

Commands to try
# Windows example
C:\> ipconfig /all
# Look for IPv4 Address or 169.254.x.x and DHCP Server entry

C:\> ipconfig /release
C:\> ipconfig /renew

# Linux example
$ ip addr show
$ sudo systemctl restart NetworkManager
Checklist
  • Verify link light and cable.
  • Ping the DHCP server IP to confirm reachability.
  • Check DHCP scope for available addresses and lease exhaustion.
  • If necessary, confirm IP helper addresses on routers for cross-subnet DHCP.
Key Takeaway

APIPA is a signal, not a solution. It tells you where to look: DHCP reachability and server scope health.
