Learning Objectives

Learn, Understand, Apply, Master

Bloom: Learn → Understand → Apply → Master
01
Diagnose connectivity issues

Use a layer-by-layer method to isolate no connectivity, intermittent, and slow cases so you fix the correct subsystem.

Mnemonic: Layer checklist
VERIFIED COMPETENCY MILESTONE
02
Troubleshoot IP addressing

Identify DHCP failures, APIPA addresses, and misconfigured static IP details and correct scope or helper settings.

Mnemonic: IP checklist
VERIFIED COMPETENCY MILESTONE
03
Identify DNS failures

Use nslookup or dig and basic ping tests to determine whether name resolution or reachability is broken.

Mnemonic: Resolve by IP then name
VERIFIED COMPETENCY MILESTONE
04
Address physical and link faults

Detect cable faults, EMI, interface errors, and duplex mismatches, and apply the right tool or setting to fix them.

Mnemonic: Cable → Link → Config
VERIFIED COMPETENCY MILESTONE
