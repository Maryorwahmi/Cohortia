Common Network Issues and Resolution

This lesson teaches a layer-by-layer approach to diagnose no connectivity, intermittent problems, slow performance, IP and DNS failures, and the right tools to confirm each hypothesis.

16:9 HD Classroom
Presentation mode: terminal demo
Why this matters

Network faults cause downtime and lost productivity. A repeatable troubleshooting flow reduces mean time to repair and prevents repeated misconfigurations.

What you'll practice

Physical checks, ipconfig/ifconfig, nslookup/dig, interpreting APIPA, spotting duplex mismatch, and conceptual packet capture analysis.

Explore Key Topics
No connectivity
Start physical checks and verify IP assignment to find whether it’s Layer 1/2 or DHCP.
DNS failures
Use nslookup or dig to separate name resolution from reachability by IP.
Performance
Establish baselines and use netstat or packet captures to find bottlenecks.
Visual concept
Layer checklist
  • Layer 1: link lights, cables, NIC status
  • Layer 2: VLANs, MAC table, duplex settings
  • Layer 3: IP assignment, gateway, APIPA
  • DNS & higher: nslookup, dig, application checks
Start with the simplest test
A plugged-in cable and a working link light rule out many causes before you pull logs.
