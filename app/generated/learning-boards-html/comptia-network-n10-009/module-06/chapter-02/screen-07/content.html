Duplex mismatch

Different duplex settings on either end of a link cause collisions and retransmits under load, reducing effective throughput.

Symptoms
High collision counts, late collisions, and slow throughput that worsens with traffic.
Fix
Prefer auto-negotiation on both sides; if required, set identical speed and duplex manually on both devices.
Check your understanding

If collisions drop to near zero after matching settings, you have resolved a duplex mismatch.

Example interface stats
Interface GigabitEthernet0/1
  Full-duplex?      : Yes
  Collisions        : 0

Interface FastEthernet0/2
  Full-duplex?      : No
  Collisions        : 1245

# Mismatch between these two ends causes the observed collisions.
