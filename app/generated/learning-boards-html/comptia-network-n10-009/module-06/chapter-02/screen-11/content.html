Scenario: name resolution fails, IP succeeds

Follow these steps to determine whether the problem is client, local DNS server, or upstream DNS.

Step 1: Verify IP reachability
ping 8.8.8.8 — if this works, network routing is likely fine.
Step 2: Check DNS configuration
ipconfig /all or cat /etc/resolv.conf to list configured DNS servers.
Step 3: Test DNS server reachability
ping the DNS server IP to ensure it’s reachable from the client.
Step 4: Use nslookup/dig
nslookup intranet.local then nslookup google.com 8.8.8.8 to force a public query.
Expected outputs
# Example failing nslookup
C:\> nslookup intranet.local
*** Can't find intranet.local: No response from server

# Example forced success
C:\> nslookup google.com 8.8.8.8
Server:  google-public-dns-a.google.com
Address:  8.8.8.8

Name:    google.com
Address: 142.250.190.142
