Module 6 › Chapter 6.2 › VLANs & MAC tables
Definition

Layer 2 issues: VLANs and MAC tables

Frames are forwarded by VLAN and MAC learning. Misconfigurations here block traffic despite an active link.

Check VLAN membership
Ensure the access port is assigned to the expected VLAN and that trunk ports carry that VLAN between switches.
Inspect MAC table
Use switch commands to find where the host MAC is learned. Missing entries indicate a forwarding problem.
Example symptom
Host has correct IP but cannot reach other hosts in the subnet; investigate VLAN mismatch or isolated port.
Quick checks & commands
# On the switch (example syntax varies by vendor)
show vlan brief
show mac address-table | include 

# On the host
ipconfig /all   # or ifconfig
If the switch shows the MAC on a different port, investigate port moves or duplicated MACs caused by virtualization or bridging.
