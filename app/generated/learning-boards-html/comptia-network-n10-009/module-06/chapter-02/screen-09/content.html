Module 6 › Chapter 6.2 › Static vs Conflict
Static IP misconfiguration
  • Symptoms: correct IP but wrong mask/gateway prevents reaching other subnets.
  • Check: validate IP, subnet mask, and default gateway against network plan.
  • Fix: correct the static settings or convert to DHCP if appropriate.
IP conflict
  • Symptoms: intermittent connectivity, OS duplicate IP warning, erratic behavior.
  • Check: scan the network for duplicate IPs and map MAC addresses to devices.
  • Fix: change one device's address or update DHCP reservations to prevent reuse.
Example command
# Find the MAC for an IP using ARP table on a router or host
C:\> arp -a

# Use switch MAC table to locate physical port for that MAC
show mac address-table | include
