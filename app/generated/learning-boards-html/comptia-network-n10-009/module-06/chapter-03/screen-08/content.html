Network Diagram

Exporter → Collector → Analysis

Exporter
Router/switch exports flow records with metadata about each conversation.
Collector
Receives flow records, aggregates them, and stores for querying.
Analysis
Identify top talkers, heavy applications, and anomalous conversations.
Concrete Example
A collector shows a single host generating the largest outbound byte count to a cloud storage IP; this points to a heavy backup or copy and helps you schedule or throttle it.
Misconception
Flows provide metadata, not payloads. Use them for traffic patterns and accounting, not content inspection.
Key Takeaway

Use flow data to identify heavy users and applications, then combine with SNMP and Syslog for complete diagnostics.
