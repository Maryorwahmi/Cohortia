Definition

Baselining

Record typical values for metrics like throughput, latency, CPU, and errors so you can detect deviations that signal problems.

Example
If daytime uplink utilization averages 40% and jumps to sustained 85% for days, the baseline shows true saturation.
Common Misconception
A single spike doesn’t always indicate a problem; compare against time-based baselines and percentiles before escalating.
Key Takeaway

Collect baseline data over time and use sustained deviations to trigger investigation or capacity planning.

Baselining Process
Collect
Poll SNMP counters regularly and ingest into a time-series store.
Analyze
Compute averages, peaks, and percentiles by time window.
Set thresholds
Trigger alerts on sustained deviations, not instantaneous blips.
Review
Regularly revisit baselines as usage patterns change.
