Common Commands & What to Look For

Run these commands to gather interface and latency data, then compare values across time to spot anomalies.

<!-- Windows: Ethernet statistics --> netstat -e <!-- Linux/macOS: interface statistics --> netstat -i <!-- Or with more detail --> ip -s link show eth0 <!-- Use ping for latency and loss --> ping -c 10 8.8.8.8
What to Inspect
  • Non-zero "Errors" or "Dropped" counters.
  • Rising "Bytes" and high utilization percentages.
  • Ping packet loss and increasing round-trip time.
Concrete Example
If netstat shows non-zero discards and ip -s link shows RX-ERR increasing, suspect duplex issues or bad cabling and check physical layer before blaming applications.
Pro Tip
Capture repeated samples, or use sar/iftop for continuous views, then add these metrics to your baseline for long-term tracking.
Key Takeaway

Use CLI outputs as quick checks and incorporate their counters into your monitoring pipeline for trends and alerts.
