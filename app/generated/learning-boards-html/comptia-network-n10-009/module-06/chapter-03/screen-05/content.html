Metrics Snapshot

Latency
Time for packets to travel; impacts responsiveness. Measured as round-trip using ping.
Throughput
Actual data transferred per second; tells you effective speed experienced by users.
Utilization
Percent of link capacity in use. Sustained high values suggest need for capacity planning.
Comparison

Loss & Jitter

Packet Loss
Packets that never arrive. Small percentages badly affect VoIP and streaming.
Jitter
Variation in packet delay. Causes choppy audio/video unless smoothed by buffers.
Concrete Example
High utilization paired with rising latency and occasional packet loss during backups indicates congestion rather than faulty hardware.
Key Takeaway

Monitor metrics together and compare them with your baseline to see user impact.
