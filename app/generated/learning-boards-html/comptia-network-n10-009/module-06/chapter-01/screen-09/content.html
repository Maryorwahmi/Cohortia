Module 06 › Chapter 6.1 › Ping & Traceroute
What ping shows

Reachability and round-trip latency to an IP. Use it to confirm basic connectivity and approximate performance.

What tracert/traceroute shows

Each router hop along the path and the response time for each hop. Use it to find the hop where delays or failures begin.

Command examples
ping 8.8.8.8
tracert google.com    (Windows)
traceroute google.com (Linux/macOS)
Interpretation tips
  • If ping to IP works but ping to a name fails, suspect DNS or application-layer resolution.
  • Asterisks or timeouts on a traceroute hop may indicate ICMP being deprioritized, not necessarily end-to-end failure.
  • Use multiple tests and times to avoid transient misleading results.
Key Takeaway

Ping gives a yes/no reachability check; traceroute localizes where along the path latency or failures appear. Use both to form a precise hypothesis.
