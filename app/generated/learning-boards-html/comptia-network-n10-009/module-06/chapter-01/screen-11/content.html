Module 06 › Chapter 6.1 › Lab: DNS vs Routing
Step-by-step terminal workflow
  1. Run ipconfig /all or ifconfig and note IP, gateway, and DNS.
  2. Ping the default gateway: ping <gateway_ip>.
  3. Ping an external IP: ping 8.8.8.8.
  4. Ping a hostname: ping google.com.
  5. If IP ping works but name ping fails, run tracert/traceroute for further evidence.
Example expected outputs
# If ping 8.8.8.8 succeeds but ping google.com fails
# Hypothesis: DNS resolution failing
# Next steps: verify DNS server listed in ipconfig, test DNS service, and check DNS server reachability
Wrap-up

Document your findings, state the hypothesis and tests you ran, and make only one configuration change at a time when attempting remediation. Capture outputs so you can roll back if needed.
