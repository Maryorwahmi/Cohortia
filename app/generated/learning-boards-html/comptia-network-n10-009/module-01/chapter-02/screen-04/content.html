Module 1 › Chapter 1.2 › Physical vs Logical
Definition and Contrast

Physical topology describes cables and device placement. Logical topology describes data flow and addressing behavior.

Example
A LAN wired as a star may behave like a bus for broadcast traffic; troubleshooting must consider both views.
Misconception
Topology is not the same as protocol. A topology does not imply a single protocol behavior.
Key Takeaway

Always identify both the physical connections and the logical flow when diagnosing a network issue.

Annotated Example
A small office: desktops connect to a switch in a closet. The closet links to a server via fiber. Physically: star endpoints to a switch and a fiber trunk — hybrid. Logically: servers and cross-floor traffic traverse the backbone; broadcasts reach all subnets unless segmented. Use this understanding to choose monitoring points and test cable continuity before changing routing.
Check: cable continuity and connector pins.
Check: ARP tables and broadcast storms for logical issues.
