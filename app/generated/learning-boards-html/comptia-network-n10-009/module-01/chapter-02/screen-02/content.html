Module 1 › Chapter 1.2 › Learning Objectives
01
Differentiate physical vs logical

Describe the actual cable/device layout and explain how data moves. This helps you diagnose whether a cable fault or a protocol issue is to blame.

Mnemonic: layout vs. flow
VERIFIED COMPETENCY MILESTONE
02
Identify common topologies

Explain star, mesh, bus, ring and hybrid forms, with pros and cons for redundancy, cost, and fault isolation.

Mnemonic: STAR for central, MESH for many links
VERIFIED COMPETENCY MILESTONE
03
Select cable types and connectors

Match Cat5e/6/6a, SMF/MMF, and coax to distance, bandwidth, and EMI requirements for a job.

Mnemonic: Distance, Bandwidth, EMI
VERIFIED COMPETENCY MILESTONE
04
Perform termination and spot issues

Understand T568A/B, make straight-through and crossover pairs, and recognise EMI and crosstalk symptoms in cabling.

Mnemonic: A/B order matters
VERIFIED COMPETENCY MILESTONE
