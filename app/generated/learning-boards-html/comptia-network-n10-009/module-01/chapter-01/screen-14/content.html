Key Concepts — Quick Reference

Three one-line reminders to carry forward into practice.

Scope
Identify if it’s PAN, LAN, WLAN or WAN — scope drives technology choices.
Components
Hosts, network devices, media, and protocols must all be considered.
Model
Choose client‑server for centralized control; P2P only for small, simple setups.
If you can answer scope, components, and model quickly, you’ll diagnose and document networks more effectively.
