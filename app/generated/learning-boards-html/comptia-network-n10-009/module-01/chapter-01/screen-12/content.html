Network Identification Activity

Classify each scenario and justify your reasoning using the chapter concepts.

Scenario 1 — Coffee Shop
Network Type: WLAN. Network Model: Client-Server (POS to cloud). Justification: Wireless customer access is local; POS uses a remote cloud server.
Scenario 2 — Corporation
Network Type: WAN. Network Model: Client-Server. Justification: Multiple geographic locations sharing central servers and VPN links indicate WAN and centralized services.
Scenario 3 — Personal Devices
Network Type: PAN. Network Model: Peer connections centered on a personal device. Justification: Short-range Bluetooth connections between personal devices.
Scenario 4 — LAN Party
Network Type: LAN. Network Model: Peer-to-Peer. Justification: Local switch connects PCs directly and players share files without dedicated servers.
Reflection prompt: For each scenario, note which component you would check first if connectivity failed and why.
