You’ll practice identifying network types from scenarios, learn which devices and media make networks work, and use two reference models to reason about where problems occur.

PAN
Very short range; personal peripherals paired to a phone.
LAN/WLAN
Local networks in homes or offices using Ethernet or Wi‑Fi.
WAN
Large geographic scope; the internet is an example.
