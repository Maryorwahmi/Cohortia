Network Components

Identify the role and examples of hosts, devices, media and protocols.

Hosts / End Devices

Devices that generate or consume data such as workstations, servers, phones and IoT sensors.

Network Devices
Switches, routers, and access points that forward and manage traffic.
Network Media
Copper, fiber, radio waves — each affects speed and reach.
Protocols
Rules and standards like those in the TCP/IP suite that allow devices to communicate.
Example Walkthrough
Loading a web page
Host: browser on laptop. Device: access point and router. Media: Wi‑Fi and ISP link. Protocols: TCP/IP and HTTP.
Misconception: Blaming only the ISP when local devices or Wi‑Fi settings are the real cause.
Key Takeaway

Check hosts, devices, media and protocols together when troubleshooting; they work as a system.
