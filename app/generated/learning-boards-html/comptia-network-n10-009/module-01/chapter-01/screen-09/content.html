OSI Model: Seven Layers

A conceptual stack for talking about network functions and troubleshooting.

Layer Stack
  1. Physical — bits on the wire or radio
  2. Data Link — frames, MAC addressing, switches
  3. Network — packets, IP addressing, routing
  4. Transport — end‑to‑end delivery, reliability
  5. Session — dialogs and connection management
  6. Presentation — data formatting and translation
  7. Application — user-facing services and programs
Practical Troubleshooting Guide
If devices can’t connect wirelessly, start with Layer 1: check power, antennas, and interference.
If frames are dropped on a switched network, examine Layer 2: check MAC tables and switch ports.
If packets aren’t routed between subnets, investigate Layer 3: verify IP addressing and routing tables.
Misconception: OSI is not a protocol list; it’s a conceptual map used to isolate faults and communicate clearly.
Key Takeaway

Use the OSI layers as a checklist when diagnosing network problems, moving from physical up through application until the fault is found.
