Process Flow
Router
Examines destination IP and consults routing table to forward packets across networks.
Routing table entries
  • Connected routes — networks directly attached to interfaces.
  • Static routes — manually configured paths to a network.
  • Dynamic routes — learned from routing protocols.
Example
A router with 192.168.1.1 on the LAN and an ISP-facing address will forward packets bound for internet addresses out the ISP interface according to its default or learned routes.
Troubleshooting prompt
If internal hosts can reach internal servers but not the internet, investigate the router's routing table, default gateway, and upstream connectivity. Use tracert to locate where packets stop.
Key Takeaway

Routers connect networks by forwarding on IP addressing and routes. When external reachability fails, the router is the most likely boundary to inspect.
