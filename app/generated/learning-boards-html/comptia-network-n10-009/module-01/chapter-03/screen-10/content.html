Code Walkthrough
ping
Sends ICMP echo requests to test reachability and measure round-trip time.
ping 192.168.1.1 Pinging 192.168.1.1 with 32 bytes of data: Reply from 192.168.1.1: bytes=32 time=2ms TTL=64 Reply from 192.168.1.1: bytes=32 time=1ms TTL=64 ping 8.8.8.8 Pinging 8.8.8.8 with 32 bytes of data: Reply from 8.8.8.8: bytes=32 time=25ms TTL=117
Command
tracert www.google.com
Shows each hop: hop 1 is usually your gateway, later hops are ISP routers. If tracert stops at a hop, that indicates where packets are dropped or filtered.
Key Takeaway

Use ping for reachability and tracert to locate which network hop drops traffic. Remember some devices may block ICMP.
