Firewall
Monitors and filters traffic to enforce security rules between trusted and untrusted networks.
Use hardware firewalls at network boundaries and software firewalls on endpoints to create layered defense.
Bridge
Connects two network segments using MAC-based filtering.
Bridges behave like small switches and are useful for connecting legacy segments without routing.
Repeater / Extender
Regenerates and retransmits signals to extend the physical reach of a network segment.
Often used for Wi-Fi coverage, though throughput and latency trade-offs exist.
Key Takeaway

Match the device to the problem: firewalls for security, bridges or switches for Layer 2 connection, and repeaters/extenders for reach. Misusing them can hide the real issue.
