Hands-on Activity
Identify Device A and Device B
Given a small diagram, determine device type and verify connectivity using command-line tools.
Step 1 — Identify
If PC1, Laptop1, and Server1 communicate directly on the same LAN segment, Device A is a switch. Device B, with the external connection, is a router.
Step 2 — Commands
From PC1 run ping 192.168.1.11 to reach Laptop1, and tracert www.google.com to map the path to a public website.
Expected ping output
Repeated reply lines indicating low ms times and no packet loss indicate successful reachability to Laptop1. If replies fail, check local firewall or cabling before assuming device is offline.
Diagram description
PC1 — Port1 → Device A; Laptop1 — Port2 → Device A; Server1 — Port3 → Device A; Device A Port4 → Device B → Internet.
Key Takeaway

Work from the inside out: test local links first, then the gateway, then external hops with tracert to isolate where packets stop.
