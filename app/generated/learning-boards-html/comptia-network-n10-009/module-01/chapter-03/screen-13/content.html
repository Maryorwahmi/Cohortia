Module 1 › Chapter 1.3 › Key Concepts
Hub
Layer 1 device that broadcasts to all ports and creates a single collision domain.
Switch
Layer 2 device that forwards using MAC addresses and supports VLANs to control broadcast domains.
MAC Address
Unique hardware identifier assigned to a network interface used for Layer 2 forwarding.
Summary
These definitions are the building blocks for deciding which device to inspect when you encounter collisions, unreachable hosts, or unexpected broadcast traffic.
