Process Flow
Troubleshooting flow
1. Physical
2. IP config
3. Gateway ping
4. External ping
5. Tracert
Use this flow with device roles in mind. If a physical link is fine but local MAC learning fails, suspect a switch or VLAN misconfiguration. If local connectivity is fine but the traceroute stops at the first hop, suspect router misconfiguration or NAT issues. If traceroute shows drops further along, the issue may be upstream with the ISP or a remote router. Keep in mind that ICMP filtering can mask reachability — a failed ping alone is not definitive evidence of a device being offline.
Pro tip

Document each step and the results. That record makes it easier to escalate to ISP support or to roll back recent changes that may have caused the issue.
