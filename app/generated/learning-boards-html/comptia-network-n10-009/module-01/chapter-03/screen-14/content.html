Module 1 › Chapter 1.3 › Key Concepts
Router
Forwards packets between IP networks using a routing table; separates broadcast domains.
Modem / WAP
Modem translates ISP signals; WAP provides wireless access and SSID broadcasting.
ping / tracert
ping verifies reachability and latency; tracert maps each router hop to the destination.
Final takeaway
Match a problem to the device role: collisions → hub/switch area; broadcast noise → VLANs or router boundaries; no external access → router or ISP. Use ping and tracert to validate each step.
