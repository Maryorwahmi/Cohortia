Definition
Modem
Converts digital signals to the ISP's transmission format and back again.

Use a modem to terminate an ISP link. It is responsible for modulation and demodulation, not for routing traffic between IP networks.

Definition
Wireless Access Point
Advertises an SSID and bridges wireless clients onto the wired network while handling wireless security.

In larger environments deploy dedicated WAPs for coverage. In homes the router often integrates a WAP, but the conceptual roles remain separate.

Example
A homeowner sees no internet: checking which device is at fault requires knowing whether the ISP link (modem) has sync and whether the router has an IP; wireless issues often point to the WAP settings or signal coverage.
