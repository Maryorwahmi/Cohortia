Module 2 › Chapter 2.2 › Mesh Topology
Definition

Mesh: multiple direct links

Full mesh connects every device to every other device; partial mesh connects only key nodes for redundancy while limiting cost.

When to use

Critical backbones and inter-router links where multiple paths are required for uptime.

Cost trade-off

Full mesh grows connections quickly; partial mesh limits links to essential devices.

Example

Three core routers in full mesh have three links between pairs. If one link fails, routing protocols choose alternate paths automatically.

Misconception: more links always mean simpler management — in fact routing and link monitoring become more complex.
Practical Notes
Manageability

Document links and use protocols that support multiple paths. Monitor link health to prevent asymmetric routing surprises.

Key Takeaway

Use mesh where redundancy is critical. Prefer partial mesh to control cost while protecting core services.
