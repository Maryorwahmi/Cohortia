Module 2 › Chapter 2.2 › Client-Server Architecture
Definition

Client-Server: dedicated services

Servers host services centrally; clients request resources. This centralization simplifies management but concentrates responsibility on servers.

Advantages

Centralized security, backups, and easier administration.

Disadvantages

Can be expensive and servers are potential single points of failure.

Example

A company file server provides shared storage and regular backups. Policies and permissions are enforced centrally for compliance and recovery.

Misconception: central servers remove all admin work — admins still need capacity planning and redundancy to avoid outages.
Design Considerations
Redundancy

Plan backups and failover for critical servers to reduce single points of failure.

Key Takeaway

Client-server supports centralized control and backups. Address server redundancy and capacity to maintain availability.
