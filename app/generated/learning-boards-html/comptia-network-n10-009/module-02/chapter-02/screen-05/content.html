Core Concept

Star: centralized wiring

All endpoints connect to a central switch or hub. Isolate cable issues easily, but plan for the central device as a possible single point of failure.

When to use

Small to medium LANs where manageability, simple troubleshooting, and predictable cabling matter.

Watchouts

Ensure switch redundancy or backups for critical segments; check port counts when planning growth.

Example

Connect 8 workstations, 2 printers, and 1 server to a central gigabit switch. If workstation 3 loses link, only that device is affected.

Misconception: switching always solves collisions — switches reduce collisions but logical domains and VLANs still determine broadcast reach.
Architecture View
Central switch

Label switch ports and plan patch panels to manage cabling as the network grows.

Key Takeaway

Star is the default for LAN wiring: simple and manageable, but protect the central device for availability.
