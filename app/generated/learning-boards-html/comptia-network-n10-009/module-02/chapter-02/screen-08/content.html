Module 2 › Chapter 2.2 › Ring Topology
Concept

Ring: looped connections

Devices form a closed loop. Token systems avoid collisions by granting access in order. A single break can stop the ring unless redundancy is added.

Strength

Orderly medium access, reduced collisions.

Weakness

A single break can disrupt the whole loop unless countermeasures are in place.

Example

Dual-ring configurations provide redundancy: if one ring fails, the counter-rotating ring maintains connectivity.

Misconception: ring means token ring only. Rings can be logical constructs implemented with modern switching and routing for redundancy.
Practical View
Deployment

Use ring patterns where orderly access or dual-path redundancy is required, and implement logical protections to reduce maintenance windows.

Key Takeaway

Rings give orderly access and can be resilient with counter-rotating links, but plan for failure handling and maintenance complexity.
