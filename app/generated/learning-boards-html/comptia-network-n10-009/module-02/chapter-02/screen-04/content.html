Definition

Physical and Logical Topologies

Physical topology is the wiring and device placement. Logical topology is how frames and packets flow. Both guide different design and troubleshooting actions.

Physical

Blueprint of cables, ports, and switches. Use for runs, labeling, and fault isolation.

Logical

How data is delivered and which devices see traffic. Use for VLANs, collision domains, and routing.

Concrete Example

A floor wired to a single switch is a physical star. If all ports are in the same VLAN, the logical topology lets broadcasts reach every device on that switch, acting like a shared segment.

Common mistake: changing cable runs without checking VLANs or spanning tree when traffic behavior is the real issue.
Diagram

Key Takeaway

Always document both the physical wiring and the logical domain boundaries so you can diagnose whether a problem is a cable fault or a protocol behavior.
