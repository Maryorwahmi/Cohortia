Module 2 › Chapter 2.2 › Performance, Scalability & Fault Tolerance
Analysis Steps
  1. Inventory critical services and traffic patterns.
  2. Identify single points of failure in topology and architecture.
  3. Apply redundancy where it protects critical services cost-effectively.
  4. Use VLANs and routing to limit broadcast impact and improve performance.
Example

If a file server is critical, consider redundant uplinks, a secondary server, or a partial mesh for the core to avoid service loss if a single switch fails.

Common Trade-offs
Cost vs Reliability

Add redundancy selectively for critical services rather than full redundant fan-out which is costly.

Logical Control

VLANs and routing let you limit broadcast domains and scale more predictably than raw cabling alone.

Key Takeaway

Design to the requirement: balance cabling and redundancy to match the criticality of services and the available budget.
