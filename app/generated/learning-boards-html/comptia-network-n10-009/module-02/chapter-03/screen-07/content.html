T568A and T568B orders

Memorize the order and practice aligning wires before crimping.

T568A pin order (left to right)
1: Green-white
2: Green
3: Orange-white
4: Blue
5: Blue-white
6: Orange
7: Brown-white
8: Brown
T568B pin order (left to right)
1: Orange-white
2: Orange
3: Green-white
4: Blue
5: Blue-white
6: Green
7: Brown-white
8: Brown
Termination checklist
  • Choose A or B and stick with it across the run.
  • Keep twists to a minimum when preparing wires.
  • Insert fully so each wire contacts the plug blades, then crimp and test.
Visual aids & example
Example scenario
You crimp a cable using T568B at both ends to connect a laptop to a switch — this is a straight‑through cable and should link up immediately if pairs and crimps are correct.
Common mistake
Mixing A and B unintentionally on the same run can create a crossover where you expect straight-through behavior or cause no link if pairs are misordered.
Check your work
Always use a cable tester to confirm continuity and correct pair mapping before deployment.
Key Takeaway

Learn the two orders, be consistent, preserve twists, and verify with a tester to avoid expensive downtime.
