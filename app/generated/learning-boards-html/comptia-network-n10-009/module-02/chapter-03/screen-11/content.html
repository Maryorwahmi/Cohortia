Core Concept

Switches and MAC learning

Switches forward frames by consulting a MAC address table learned from incoming frames.
Learning process
Switch observes source MAC and maps it to the ingress port in its table; unknown destinations trigger flooding to learn the location.
Managed switch features
VLANs, QoS, port security and monitoring help segment traffic and enforce policies.
Misconception
Switches do not route between IP subnets—routing requires a Layer 3 device or a Layer 3-capable switch.
Key Takeaway

Switches keep LAN traffic local by forwarding frames only where needed; managed features let you shape and secure that behavior.

Annotated architecture
Example: VLAN use
Segment guest and corporate traffic on a single switch using VLAN tagging and separate access ports.
Patch panel relationship
Permanent runs terminate at the patch panel; short patch cords connect panel ports to switch ports so you can reconfigure without touching fixed cables.
Check your understanding
If two devices on the same VLAN cannot reach each other, confirm switch MAC tables, port VLAN assignments, and patch‑panel mappings before suspecting routing faults.
