DHCP Troubles and Resolutions
Compare common failure modes and practical fixes.
Reservation
Binds a MAC to an IP so a device always receives the same address via DHCP. Useful for devices that require stable addresses without manual static configuration.
Tip: Use reservations for printers and servers.
Scope exhaustion
Occurs when the DHCP pool is fully allocated. New clients no longer receive offers until leases expire, are released, or scope is enlarged.
Fix: Expand scope or shorten lease time temporarily.
Conflicting servers
Multiple DHCP servers on the same segment can give different configurations and cause intermittent connectivity issues.
Check: Network segments and server bindings.
Example: In a 50-address scope with 60 devices, new laptops fail to boot onto the network. Inspect the lease table, confirm lease expiry times, and consider temporary lease-time reduction to free addresses faster.
Key takeaway: Use logs and lease tables first; configuration changes should be targeted and reversible.
Misconception: A reservation is not a client-side static IP—it still depends on DHCP and the client's MAC matching the reservation.
