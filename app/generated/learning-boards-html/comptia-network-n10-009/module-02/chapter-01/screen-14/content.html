Key Concepts
Core definitions to remember for quick recall.
DNS
A distributed naming system that resolves domain names to IP addresses and provides service records.
DHCP
Automates IP assignment and configuration using the Discover, Offer, Request, Acknowledge exchange.
NAT
Remaps internal addresses to public addresses; PAT allows many internal hosts to share one public IP.
Summary takeaway

Use quick terminal checks to map symptoms to these services and apply focused fixes. Name problems are DNS, address problems are DHCP, and translation issues point to NAT.
