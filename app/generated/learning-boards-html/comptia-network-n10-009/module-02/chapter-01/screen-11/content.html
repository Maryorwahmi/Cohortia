Simple Network Management Protocol (SNMP)
Collect and manage device metrics using agents, managers, and MIBs with attention to security.
Components
  • Manager: Software that polls or receives traps from devices.
  • Agent: Runs on the device and responds to queries.
  • MIB: Hierarchical database of object definitions used to read or set values.
Misconception: SNMP is only read-only; in fact, certain writable MIBs allow configuration changes when permitted.
Security and practice
Prefer SNMPv3 with authentication and encryption. Avoid default community strings and restrict access with ACLs to trusted management stations.
Tool: Use snmpwalk or similar to fetch MIB objects for verification.
Example: Poll interface counters to detect high error rates and plan maintenance.
Pro tip: Map OIDs to friendly names in your monitoring dashboard using standard MIBs.
