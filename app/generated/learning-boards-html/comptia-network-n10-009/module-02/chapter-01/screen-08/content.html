Network Address Translation (NAT)
Remap private addresses to public addresses and hide internal hosts from the internet.
NAT types
  • Static NAT: one-to-one mapping used for servers that must be reachable externally.
  • Dynamic NAT: maps internal addresses to a pool of public addresses on a first-come, first-served basis.
  • PAT (NAT overload): many-to-one mapping using unique source ports so multiple hosts share a single public IP.
Pitfall: NAT rules that do not include proper port translation or reverse mappings will break inbound connections to services hosted internally.
Concrete example
Two internal devices, 10.0.0.5 and 10.0.0.6, browse a website. The gateway replaces their private source addresses with the gateway's public IP, 203.0.113.5, and assigns distinct source ports so return traffic is routed to the correct internal host.
Misconception: NAT is not a security boundary. It hides addresses but should be combined with firewall policies for real protection.
Key takeaway: PAT enables address sharing and is the most common NAT form in small networks.
Pro tip: When you need inbound access, configure static NAT or port forwarding with explicit rules.
