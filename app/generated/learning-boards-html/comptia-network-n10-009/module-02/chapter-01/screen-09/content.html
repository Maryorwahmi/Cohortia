NAT Modes Compared
Pick the mapping that matches service reachability needs.
Static NAT
One-to-one mapping suitable for servers that need a permanent public address.
Use when inbound access must be stable and address translation predictable.
Dynamic NAT
Maps internal addresses to a pool of public addresses on demand.
Useful when multiple public addresses are available but not always required.
PAT (NAT Overload)
Many-to-one using port numbers; the default for most small networks sharing a single public IP.
Remember: inbound services need explicit forwarding rules when using PAT.
Example: Small office uses PAT to share one ISP address. The administrator configures static NAT for the internal web server to allow inbound HTTP requests.
Pro tip: Check the gateway NAT translations to map public source ports back to internal hosts when diagnosing connectivity.
Misconception: NAT equals firewall. NAT only rewrites addresses; separate firewall policies control access.
