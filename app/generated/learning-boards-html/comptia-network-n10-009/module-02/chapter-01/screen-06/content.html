DHCP: Discover, Offer, Request, Acknowledge
Automatic address assignment with a predictable handshake and lease lifecycle.
DORA steps
Discover: Client broadcasts to find DHCP servers.
Offer: Server proposes an IP with configuration and lease time.
Request: Client indicates which offer it accepts.
Acknowledge: Server confirms the lease and the client applies the configuration.
Common mistakes
Multiple DHCP servers on an unsegmented network or an exhausted DHCP scope causes intermittent or no IP assignment.
Check with system commands
# Windows
ipconfig /all

# macOS / Linux
ip a
# or
ifconfig
These commands show the assigned IP, subnet mask, default gateway, and the DNS servers provided by DHCP. If values are missing or show 0.0.0.0, the DORA exchange may have failed.
Example: A reservation binds a MAC address to a fixed IP so servers have stable addresses.
Pro tip: Inspect lease duration to know how long a client keeps an address before renewal.
