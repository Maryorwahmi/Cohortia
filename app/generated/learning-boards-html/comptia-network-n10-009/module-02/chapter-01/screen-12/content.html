Terminal Demo: Key Commands
Run these commands to gather evidence and narrow down problems quickly.
Inspect IP configuration
# Windows
ipconfig /all

# macOS / Linux
ip a
# or
ifconfig
Confirm the IP address, subnet mask, default gateway, and DNS servers provided by DHCP or static configuration.
DNS and path checks
nslookup cohortia.com

# Trace the path to a host
tracert cohortia.com   # Windows
traceroute cohortia.com # macOS / Linux
Use nslookup to confirm who answered the DNS query and traceroute to observe hop-by-hop routing. Repeat commands if results look inconsistent, because caches may affect one-off queries.
Example workflow: Run ipconfig to find the DNS server, then run nslookup and confirm the same server returned the answer. If you can reach the IP but not the name, DNS is the likely issue.
