Quality Attributes
Performance • Scalability • Security
Make qualities measurable and use them to drive tactics such as caching, partitioning, or encryption.
Performance
Response time, throughput, and latency targets that influence caching and async design.
Scalability
Ability to handle increased load. Consider vertical vs horizontal scaling and partitioning strategies.
Security
Protect data and operations via authentication, authorization, encryption, and auditing.
Interactions and trade-offs
Quality attributes often interact. Improving one can degrade another. Make trade-offs explicit by scoring impact and risk.
Reliability
Design for redundancy and error handling so the system meets uptime expectations.
Maintainability
Modular designs and clear interfaces make code easier to update and extend.
Usability
APIs and error handling are architecture-level choices that affect the user experience.
Misconception: NFRs are optional. Reality: they must be captured and prioritized to avoid unacceptable behavior in production.
