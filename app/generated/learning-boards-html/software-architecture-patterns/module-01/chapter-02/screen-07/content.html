Performance
Measurable targets and tactics
Translate performance desires into numbers and design choices to meet them.
Metrics
Response time, throughput, and percentiles (e.g., 99th percentile latency).
Tactics
Caching, async processing, batching, and service co-location reduce critical path latency.
Key Takeaway

Define performance with numbers, pick targeted tactics, and validate with tests and monitoring.

Concrete example
Payment latency < 2s
To meet this, consider a dedicated payment service, local caching of tokenized data, and asynchronous reconciliation for non-critical steps.
Mistake
Relying only on faster servers without addressing latency sources in the design.
Check
Have you defined percentiles and run load tests to validate the target?
