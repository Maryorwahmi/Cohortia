Architecture vs Design
Compare scope, timescale, and consequences.
Architectural choice
Example: Splitting the system into microservices. Consequences include independent deploys, cross-service communication, and data partitioning decisions.
Design choice
Example: Selecting JWT for tokens inside authentication. Consequences are local to the service: token format, validation, and rotation policies.
Quick test
Ask: Will changing this decision force reworking multiple services and deployment scripts? If yes, classify it as architectural.
Misconception
Not every platform choice is tactical. Selecting a database style or cloud provider can be architectural when it shapes data models and operational practices.
Key Takeaway

Use scope as your guide: strategic = architecture; local = design.
