Module 1 › Chapter 1.1 › Defining Software Architecture
Definition
The fundamental organization of a system and the principles guiding its evolution.
Core definition
Architecture describes components, their relationships, interactions with the environment, and the governing principles. It makes strategic choices that are costly to change later.
Analogy
Building blueprint vs. interior finishes.
Common misconception
Architecture is not only documentation; it is a set of decisions that shape implementation and operations.
Example
Choosing microservices or a monolith is an architectural decision because it affects deployment, team boundaries, data ownership, and operational complexity.
Key Takeaway

Architecture = strategic structure; design = tactical implementation within that structure.
