Activity
Classify each scenario and justify why it is architectural or design-level.
1. Microservices with message queue
Classification: Architectural — affects deployment, interfaces, and operations.
2. Use JWT for authentication
Classification: Design — local to authentication service implementation.
3. NoSQL for users, SQL for content
Classification: Architectural — shapes data strategy and migrations.
4. Interface for CourseRepository
Classification: Design — internal API of a single service.
5. Selecting a cloud provider
Classification: Architectural — affects operations, cost models, and platform capabilities.
Why this helps
Classifying decisions by impact prepares you to capture assumptions and communicate trade-offs early.
Key Takeaway

Practice classifying decisions; justification matters more than label alone.
