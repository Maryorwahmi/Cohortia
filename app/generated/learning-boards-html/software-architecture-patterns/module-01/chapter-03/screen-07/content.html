Definition

Logical View

Shows functional decomposition, components, and responsibilities to help developers understand the system's conceptual organization.

Naming guideline
Name components by responsibility, not by implementation detail.
Link to code
Annotate boxes with repository paths or ADR references to make diagrams actionable.
Concrete Example
# Logical Component: User Service
class UserService:

  def get_user(self, user_id):

Key Takeaway
Logical views clarify responsibilities and interfaces; annotate them with code links and ADRs to keep them actionable.
