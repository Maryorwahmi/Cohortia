Module 4 › Chapter 4.3 › Applied Objectives
Demonstration
Mock a View, verify Presenter calls display methods; write a unit for a ViewModel property and a command's effect on the Model.
Scenario Review
Compare a legacy form and a reactive web form to choose MVP or MVVM based on binding requirements and lifecycle control.
Watchouts
Avoid pushing UI logic into the Model and avoid fat ViewModels that duplicate business logic.
Quick checklist
  • Can the Presenter/ViewModel be unit tested without UI? ✔
  • Does data binding reduce imperative sync code? ✔
  • Is presentation logic kept out of Model? ✔
