Module 4 › Chapter 4.3 › Counter → MVVM
Model
// CounterModel
class CounterModel {
  constructor(initialCount = 0) {
    this._count = initialCount;
  }

  getCount() {
    return this._count;
  }

  increment() {
    this._count++;
    return this._count;
  }
}
ViewModel
// CounterViewModel
class CounterViewModel {
  constructor(model) {
    this.model = model;
    this.displayCount = this.model.getCount();
  }

  incrementCommand() {
    this.model.increment();
    this.displayCount = this.model.getCount();
  }
}
In a real framework displayCount would be observable so the View updates automatically when it changes.
Check

Unit tests can mock the model, call incrementCommand, and assert displayCount changed without any UI code.
