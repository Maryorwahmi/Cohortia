Module 4 › Chapter 4.3 › MVVM anatomy
ViewModel
Exposes properties and commands that the View binds to. Holds presentation state and formatting logic but not core business rules.
Properties
Reactive properties like displayCount that the View observes and renders automatically.
Commands
Encapsulate actions such as save or increment; the View binds a button to a command.
Example: Counter
ViewModel exposes displayCount and incrementCommand. Binding keeps the display in sync without imperative calls from ViewModel to the View.
Key Takeaway

MVVM fits declarative UI frameworks where binding and commands simplify synchronization between state and UI.
