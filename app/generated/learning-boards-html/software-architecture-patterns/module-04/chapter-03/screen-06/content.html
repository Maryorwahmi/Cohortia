Module 4 › Chapter 4.3 › MVP interaction
Steps
  1. 1. User triggers an event in the View.
  2. 2. View forwards event to Presenter (e.g., presenter.onAction()).
  3. 3. Presenter calls Model and applies presentation mapping.
  4. 4. Presenter updates the View using interface methods.
  5. 5. Assertions: Presenter calls and formatted data are verifiable in tests.
Common mistake

Letting a View perform validation or presentation transforms reduces testability. Move that logic to Presenter or Model.

Example test sketch
// Arrange: mock view and model
const mockView = createMockView();
const mockModel = createMockModelReturningSuccess();
const presenter = new LoginPresenter(mockView, mockModel);

// Act
presenter.onLoginButtonClicked('user','pw');

// Assert
expect(mockView.displayUserDetails).toHaveBeenCalledWith(expect.objectContaining({name: 'User'}));
Key Takeaway

Express interactions as clear steps so you can test each transition from event to view update.
