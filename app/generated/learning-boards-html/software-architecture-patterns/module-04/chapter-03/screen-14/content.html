Module 4 › Chapter 4.3 › What to Remember
Presenter (MVP)
Mediator that applies presentation logic and updates the passive View via an interface.
Passive View (MVP)
Exposes methods and forwards events. Contains no presentation logic.
ViewModel (MVVM)
Exposes properties and commands for declarative binding; ViewModel is testable without the UI.
Summary Takeaway

Both patterns reduce coupling and improve testability. Choose based on binding support, lifecycle needs, and team workflow.
