Module 5 › Chapter 4.4 › Key Concepts
Single Page Application (SPA)
Loads one HTML shell and updates content with JavaScript.
Client-Side Rendering (CSR)
Browser runs JS to render and update UI; server provides data.
API-Driven Communication
Frontend consumes data from REST or GraphQL APIs, decoupling UI and backend.
Summary takeaway

SPAs deliver rich UX by moving rendering to the client; strong API contracts and careful state design make them reliable. Use SSR or pre-rendering when first-load or SEO is critical.
