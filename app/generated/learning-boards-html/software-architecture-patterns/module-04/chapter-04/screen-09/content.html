Module 5 › Chapter 4.4 › Composition Strategies
Build-time
Pre-assembled bundles

Micro-frontends are combined during build into a single deployable artifact. Runtime is simple but deploy independence is limited.

Server-side
Edge or server composition

Server stitches fragments or uses edge includes to assemble pages, offering good perceived performance and partial autonomy.

Client-side
Browser composition

Shell app dynamically loads micro-frontends as scripts or web components, maximizing independent deploys at the cost of runtime complexity.

Concrete scenario

An e-commerce shell can server-side include a header for fast first paint, while loading product and cart micro-frontends client-side to allow independent updates by teams.

Key Takeaway

Composition choice depends on the balance between runtime simplicity, deployment independence, and perceived performance.
