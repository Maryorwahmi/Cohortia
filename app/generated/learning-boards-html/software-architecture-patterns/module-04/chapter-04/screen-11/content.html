Micro-frontend behavior

Each script registers a custom element and encapsulates its rendering and eventing. The shell coordinates layout and global concerns like authentication.

Notes
Communication

Micro-frontends can communicate via custom events, a shared state library, or a pub/sub channel provided by the shell.

Pitfall

Loading multiple frameworks can increase payload. Share common libraries or use federation to avoid duplication.

Key Takeaway

Web components provide a runtime composition model that supports independent deployment; manage shared dependencies and events to maintain performance and consistency.
