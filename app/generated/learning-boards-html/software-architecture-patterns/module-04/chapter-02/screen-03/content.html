Practice & Assessment

Tasks that connect concept to code and two short assessment questions to confirm understanding.

Task
Add product details

Modify the Model to add get_by_id, add a route that fetches by id, and create a template that renders the product.

VERIFIED COMPETENCY MILESTONE
Assessment
Flow question

Describe the steps from user form submission to updated display. Use MVC terms and mention notification or redirect where appropriate.

Design question
Where does business logic live?

Explain why a complex loyalty discount belongs in the Model rather than Controller or View, and what problems that avoids.

Why this matters

These exercises convert conceptual understanding into code patterns you can test, review, and reuse across projects and teams.
