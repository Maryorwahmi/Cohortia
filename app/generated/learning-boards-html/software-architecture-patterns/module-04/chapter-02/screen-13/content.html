Why Models make testing easy
  • Unit test business rules directly without a UI.
  • Mock controllers in view tests to focus on rendering behavior.
  • Refactor domain rules safely with focused tests.
Example test idea

Write a unit test that calls Product.create with invalid price and asserts it raises an error or returns a validation result. No templates or HTTP required.

Key Takeaway

Design Models for testability and reuse; simpler controllers and views follow naturally.
