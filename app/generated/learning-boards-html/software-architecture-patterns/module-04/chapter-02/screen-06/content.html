Module 4 › Chapter 4.2 › The View
Core claim

Views display Model data and capture user input. Keep them declarative, not procedural.

  • Format and layout data for the user.
  • Capture actions and submit them to controllers.
  • Avoid placing domain logic or persistence here.
Misconception

Putting discounts or domain decisions in templates couples the display to rules and multiplies maintenance work.

Example: simple template (Jinja2)
<!-- templates/index.html -->
<h1>Products</h1>
<ul>
{% for product in products %}
  <li>{{ product.name }} - ${{ "{:.2f}".format(product.price) }}</li>
{% endfor %}
</ul>
<p>Add New Product form goes here</p>
Why it matters

Well-structured views make it easy to restyle or provide an alternate representation without touching domain rules. They also simplify A/B tests or accessibility updates.
