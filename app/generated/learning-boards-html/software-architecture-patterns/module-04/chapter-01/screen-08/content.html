Primary teaching visual
A clear split: fetchProducts, renderProducts, and submit handler that delegates to addProduct.
<!-- simplified visual example, < and > are escaped for clarity -->

async function fetchProducts() {
  const response = await fetch('/api/products');
  const products = await response.json();
  return products;
}

function renderProducts(products) {
  const list = document.getElementById('productList');
  list.innerHTML = '';
  products.forEach(p => {
    const item = document.createElement('div');
    item.className = 'product-item';
    item.textContent = `${p.name} - $${p.price.toFixed(2)}`;
    list.appendChild(item);
  });
}

async function handleAdd(event) {
  event.preventDefault();
  const name = document.getElementById('productName').value;
  const price = parseFloat(document.getElementById('productPrice').value);

  // delegate to application layer
  const ok = await addProduct({ name, price });
  if (ok) await fetchProductsAndRender();
}
Supporting notes
  • Keep fetch logic independent so you can stub it in tests.
  • Render functions should accept data and output UI without side effects beyond the DOM.
  • Submit handlers should collect input and delegate business work to the application layer.
