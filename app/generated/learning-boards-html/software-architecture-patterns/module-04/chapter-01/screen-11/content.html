Module 4 › Chapter 4.1 › Identify Concerns Activity
Task steps
  1. Review HTML and mark display elements.
  2. Find code that manipulates the DOM and tag as display logic.
  3. Locate API calls and tag as data logic.
  4. Mark event handlers that coordinate actions as interaction logic.
Refactor goal
Extract one responsibility into its own function and run the UI to confirm no behavioral regressions.
Example outcome
After refactor you should have a fetchProducts function, a renderProducts function, and a submit handler that only delegates. This makes both rendering and data fetching independently testable.
Reflection
Was the refactor straightforward? If not, which responsibilities were entangled and why?
