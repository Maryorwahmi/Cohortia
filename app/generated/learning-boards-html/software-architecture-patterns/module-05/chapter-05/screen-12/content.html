Module 6 › Chapter 5.5 › Bulkhead Implementation
Executor-based bulkheads
Create separate bounded executors for different downstream services and use rejection policies to avoid unbounded queues.
Example config
ProfileExecutor: core=5,max=10,queue=50. AuthExecutor: core=10,max=20,queue=200. Tune based on criticality.
Connection & queue isolation
Limit outbound connections per integration and use bounded queues with backpressure or rejection to prevent global exhaustion.
Operational guidance

Emit metrics for pool saturation and rejections so you know when to adjust sizes or route traffic differently.

Misconception check

Avoid sharing database connections across bulkheads; shared low-level resources can negate isolation benefits.
