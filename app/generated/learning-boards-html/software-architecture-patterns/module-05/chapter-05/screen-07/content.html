Module 6 › Chapter 5.5 › Circuit Breaker States
Closed
Normal operation. Requests pass through and failures are counted. Transition to Open when threshold is exceeded.
Open
Requests are rejected immediately or sent to fallback. After a timeout, move to Half-Open to test recovery.
Half-Open
Allow limited test requests. If they succeed, close the circuit; if they fail, re-open.
Example walkthrough
Failure count reaches 5 in 1 minute → circuit opens for 30 seconds → after 30s allow 3 test requests → if 2 of 3 succeed, transition to Closed; otherwise back to Open.
Misconception check

Don't set very short open timeouts; you may flood the dependency during Half-Open if it hasn't recovered. Tune based on observed recovery behaviour.
