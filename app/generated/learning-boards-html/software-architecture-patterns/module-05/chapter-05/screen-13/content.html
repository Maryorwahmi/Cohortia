Closed
Action: Allow requests; count failures. Transition condition: failures > threshold in sliding window.
Open
Action: Immediately return fallback or queue request. Transition condition: timeout elapsed.
Half-Open
Action: Allow limited test requests. Transition: close on success; re-open on failure.
Suggested fallback
Queue the shipping rate lookup for async processing and accept the order with a note that shipping will be confirmed. Optionally return a cached estimate for immediate user feedback.
Monitoring
Track circuit open events, fallback invocations, queue backlog, and half-open test success rates to tune thresholds and detect regressions.
