Understand resilience
Explain resilience as the ability to recover and continue functioning in degraded mode. This matters because planning for failure reduces downtime and user impact.

Explain Circuit Breaker
Describe the three states and why preventing repeated failed calls conserves resources and helps recovery. The mnemonic: Closed, Open, Half-Open.

03
Describe Bulkhead
Explain resource isolation using separate pools so one slow service cannot starve the application. The ship compartment analogy helps remember the approach.

Apply patterns
Design a protection plan for a microservice interaction, including fallback strategies, monitoring, and configuration considerations to avoid false positives.
