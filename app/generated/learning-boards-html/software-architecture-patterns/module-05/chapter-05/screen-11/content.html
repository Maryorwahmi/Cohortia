Module 6 › Chapter 5.5 › Bulkhead Pattern
Analogy
Watertight Compartments

Like a ship's bulkheads, software bulkheads contain failures in separate resource compartments so one breach doesn't sink the whole system.

Concrete example
Separate thread pools for ProfileService and AuthService calls; if ProfileService is slow, AuthService still operates.
Design guidance
  • Identify independent interaction classes to isolate.
  • Allocate pools sized by criticality and expected load.
  • Avoid sharing low-level resources across bulkheads that defeat isolation.
Pitfall

Misconfigured sizes either starve features or waste capacity; size based on observed usage and criticality.
