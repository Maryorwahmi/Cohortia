Module 6 › Chapter 5.5 › Tuning & Mistakes
Key settings
  • Failure threshold and sliding window size.
  • Open timeout before attempting half-open.
  • Number of test requests in half-open.
  • Timeout per request to avoid long waits being counted as success.
Common mistakes
  • Using defaults without validating against real traffic.
  • Setting thresholds that cause false positives during short spikes.
  • Using costly fallbacks that reintroduce load.
  • Not instrumenting circuit events, so opens go unnoticed.
Key Takeaway

Tune based on observed errors and latency. Instrument opens and fallback usage so thresholds evolve from data, not guesswork.
