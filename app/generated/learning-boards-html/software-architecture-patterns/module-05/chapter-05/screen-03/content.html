01 • Identify fragility
Map failure sources, their blast radius, and quick containment options. Example: a slow payment provider suggests a circuit breaker to avoid backlog growth.

02 • Configure circuit breakers
Set thresholds, timeouts, and half-open sampling limits. Example: only allow a few test requests during half-open to avoid a thundering retry.
VERIFIED COMPETENCY MILESTONE
03 • Design bulkheads
Allocate separate pools for critical integrations. Example: separate thread pools for ProfileService and AuthService calls to avoid mutual starvation.

04 • Combine with monitoring
Add metrics and alerts for circuit state transitions and pool exhaustion so you can react before user impact grows.
