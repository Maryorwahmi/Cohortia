What it is
Circuit Breaker

A protection mechanism that stops calls to failing services after repeated errors, returning a fallback or error immediately.

Practical example
If PaymentService times out frequently, the OrderService circuit trips and uses a fallback that queues payment for later processing.
Important elements
  • Failure detection threshold: how many failures before opening the circuit.
  • Timeout: how long to wait for a response before considering it a failure.
  • Reset timeout: how long to wait before trying test requests in half-open.
  • Fallback: what to return when the circuit is open.
Misconception check
An overly aggressive threshold creates false positives; overly lenient thresholds delay protection. Tune based on real error and latency patterns.
