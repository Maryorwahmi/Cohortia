Module 5 › Chapter 5.3 › Key Concepts
Asynchronous Communication
Sender does not wait; operations can proceed independently and systems are more resilient.
Message Queue
One-to-one delivery for reliable task processing; typically FIFO and consumed by a single worker.
Publish-Subscribe
One-to-many distribution; topics let multiple subscribers react independently and support replay when retained.
Summary Takeaway

Select queue patterns for single-worker reliability and pub/sub for fan-out. Enforce idempotency, durability, DLQs, and monitoring to keep message-driven systems robust.
