Guidelines
  • Include correlationId to trace the saga across services.
  • Keep events focused: send only data required by subscribers.
  • Design steps to be idempotent and safe to retry.
Misconception
Don't publish huge domain snapshots; large events complicate backward compatibility and increase coupling.
Key Takeaway

Design concise event shapes and idempotent handlers so saga steps are observable, traceable, and safe to retry.
