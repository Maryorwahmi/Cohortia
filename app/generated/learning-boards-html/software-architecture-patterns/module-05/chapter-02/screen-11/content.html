Module 5 › Chapter 5.2 › Gateway Responsibilities
Cross-cutting concerns
  • Authentication and authorization — verify identity at the edge.
  • Rate limiting and throttling — protect backends from spikes.
  • SSL termination and certificate management.
  • Request logging, metrics, and basic response aggregation.
Design rule
Keep the gateway stateless where possible and avoid embedding domain logic. If aggregation is needed, prefer orchestrator services that can be scaled and tested independently.
