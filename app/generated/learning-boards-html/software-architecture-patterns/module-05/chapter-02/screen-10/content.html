Module 5 › Chapter 5.2 › API Gateway
Responsibilities
  • Routing and request forwarding to backend services.
  • Authentication and authorization enforcement.
  • Rate limiting, caching, and request aggregation.
  • SSL termination and logging/monitoring of client traffic.
Example implementations mentioned earlier include Spring Cloud Gateway, Kong, and AWS API Gateway. Use the gateway for cross-cutting concerns, not business rules.
Design checklist
Implement timeouts and clear error mapping so backend slowness does not block clients.
Avoid business logic here; keep orchestration minimal and declarative.
Scale the gateway independently and monitor its health closely, as it is the public face of your system.
Common mistake
Turning the gateway into a business logic layer creates a new monolith and undermines microservice isolation.
