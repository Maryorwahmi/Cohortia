Module 5 › Chapter 5.2 › What is Service Discovery?
Service Discovery — short definition
A registry-backed process where services register their addresses so others can resolve live instances dynamically.
Service Registry
Stores IP and port for each running instance; used by discovery queries.
Discovery Query
A client or router asks the registry for available instances of a service name.
Selection Strategy
Random, round-robin or least-loaded choices determine which instance receives the request.
Key Takeaway

Discovery prevents brittle networking by keeping clients unaware of instance lifecycles and enabling dynamic routing.

Concrete example: OrderService → ProductService
ProductService starts two instances and registers both. OrderService calls discover for product-service and receives a list. It selects an instance and proceeds. If one instance fails, the registry removes it and discovery avoids the dead address, improving availability.
Common misconception
Discovery is not a substitute for resilience patterns. You still need timeouts, retries, and health checks to handle slow or failing instances.
