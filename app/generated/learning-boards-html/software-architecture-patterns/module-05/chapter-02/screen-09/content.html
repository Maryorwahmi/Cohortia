Module 5 › Chapter 5.2 › Registration & Health Checks
Registration flow
Start → register with registry → send heartbeats → provide health endpoint → deregister on shutdown.
Graceful deregistration
Service informs registry before shutting down to avoid routing to it.
Heartbeat TTL
Registry removes instance after a missed heartbeat window.
External health checks
Routers or registries can probe endpoints and remove unhealthy instances early.
Practical guidance
Configure heartbeat intervals and TTLs so the registry detects failures quickly but without causing false positives during brief hiccups. Pair health checks with graceful shutdown hooks to avoid ghost entries.
Key Takeaway
Design registration and health checks to be reliable: heartbeats for liveness, health endpoints for readiness, and graceful deregistration for planned shutdowns.
