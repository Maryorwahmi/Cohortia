Module 5 › Chapter 5.2 › Pitfalls & Safety
Operational pitfalls
  • Gateway becomes a monolith if overloaded with business logic.
  • Missing timeouts cause cascading slowdowns.
  • Unmonitored registries lead to silent failures and stale records.
Security and resilience
  • Secure gateway endpoints with authentication and logging.
  • Replicate registries and set alerts for abnormal churn or missing heartbeats.
  • Test failure scenarios such as crashes and network partitions.
