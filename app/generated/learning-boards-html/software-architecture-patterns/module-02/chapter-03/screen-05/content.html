Core Responsibilities
Registry, API, event bus, lifecycle, configuration.
Plugin Registry
Track plugins, their versions, and provide lookup by capability or name.
Stable API
Define a minimal contract (e.g., execute method) and version it to avoid breaking plugins.
Event Bus & Services
Provide decoupled communication so plugins can react to events without tight coupling.
Design cards
Rule of thumb
If it needs to change often or is feature-specific, implement it as a plugin.
Misstep: bloated core
Moving feature logic to core increases regression risk and slows releases.
Practical tip
Document the API and maintain clear versioning and deprecation paths.
Key Takeaway

Define a minimal set of coordinating services that every plugin can rely on; keep everything else outside the core.
