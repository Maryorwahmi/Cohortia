Module 3 › Chapter 2.3 › Fault Isolation & Security
Isolation Strategies
Processes, containers, or sandboxes restrict plugin failures and access.
Process isolation
Run plugins externally and communicate over an IPC mechanism to avoid in-process crashes.
Sandboxing
Limit filesystem, network, and system calls; allow only what a plugin specifically needs.
Security measures
Integrity checks
Sign plugins and verify signatures before loading to prevent tampering.
Permission model
Assign minimal privileges per plugin based on required features.
Operational tracing
Log plugin lifecycle events and failures to enable fast incident analysis.
Key Takeaway

Isolation reduces risk but must be combined with signing, permissions, and clear logging to be effective.
