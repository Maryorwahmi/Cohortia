Plugin Anatomy
Registration, metadata, interface, event subscriptions.
Registration
Plugins must register themselves with the core so the kernel can route requests to them.
Metadata
Name, version, capabilities, and dependencies help with discovery and compatibility checks.
Interface
A simple callable like execute provides a uniform delegation point for the core.
Practical cards
Concrete example
A text formatter plugin exposes execute(text) returning formatted text and registers as format_text.
Versioning tip
Use semantic versioning for plugin interfaces and the core API to manage compatibility.
Misconception
Don't let plugins rely on internal core implementation details; rely only on documented APIs.
Key Takeaway

Design a small, stable plugin contract and require metadata so the core can manage discovery and compatibility.
