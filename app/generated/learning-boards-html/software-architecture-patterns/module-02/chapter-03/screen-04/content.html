Module 3 › Chapter 2.3 › What is a Microkernel?
Definition
A small core provides essential services; plugins extend behavior via a contract.
Analogy
Think of the core as a basic operating system kernel and plugins as device drivers and utilities you can add or remove.
Core responsibilities
Registry, API, event routing, basic stable services.
Plugin characteristics
Independent, registerable, implements a known interface like execute.
Key Takeaway

Keep the core minimal. Put behavior in plugins that follow a stable API.

Concrete Example
IDE example
The editor core manages open files and the extension API; language support and debuggers are plugins. Users add only what they need.
Misconception
Putting too much in the core creates a bloated microkernel and erases the benefit of modularity.
Check your understanding
If you add a feature, ask whether it requires core privileges or can be implemented as a plugin.
