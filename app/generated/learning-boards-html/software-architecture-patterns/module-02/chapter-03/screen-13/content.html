Module 3 › Chapter 2.3 › Pitfalls & Safety
Common Mistakes
Bloated core
Move only essential managing services into the core—avoid feature accumulation.
Poor API design
Unstable or overly complex APIs hinder plugin development and longevity.
Lack of sandboxing
Running untrusted plugins without isolation risks system integrity.
Remedies
Design fixes
Document API, version it, and provide migration paths for plugin authors.
Lifecycle controls
Implement transactional load/unload and clear error reporting for diagnostics.
Operational step
Benchmark inter-plugin paths early to reveal performance hotspots.
Key Takeaway

Anticipate bloat, API instability, security gaps, and lifecycle issues. Plan mitigations before they appear.
