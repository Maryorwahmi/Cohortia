Module 3 › Chapter 2.3 › Plugin Lifecycle
Lifecycle Steps
  1. Discover: find plugins via filesystem, registry, or marketplace and read metadata.
  2. Validate: check compatibility and signatures.
  3. Load: initialize plugin and register services; do this transactionally.
  4. Run: handle normal operation and event subscriptions.
  5. Unload/Update: quiesce, replace code, and release resources safely.
Common mistake

Not rolling back partial initialization can leave the core in a corrupted state when a plugin fails to start.

Practical cards
Isolation strategies
Run plugins in separate processes or sandboxes to prevent crashes from affecting the core.
Transactional loading
Only commit plugin registration once initialization completes successfully.
Operator tip
Provide clear diagnostics that show which step failed and why to speed recovery.
Key Takeaway

Treat loading and updating as carefully managed operations with validation, rollback, and clear error reporting.
