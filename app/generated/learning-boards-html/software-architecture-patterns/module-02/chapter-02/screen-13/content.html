Scenario: Two Applications

Decide which pattern fits each app and justify two advantages.

Application A: Online Banking

Requirements: strong security, data integrity, centralized control.

Chosen Pattern: Client-Server
  • Centralized authentication simplifies secure access control.
  • Single authoritative database supports strong data consistency and audits.
Application B: Distributed File Sharing

Requirements: robust sharing of large files, resilience to node failures.

Chosen Pattern: Peer-to-Peer
  • Peers add bandwidth and storage, improving distribution efficiency.
  • Decentralization reduces single points of failure and improves availability.
