Client-Server: Compact Cards

Request-Response
Clients initiate requests; servers respond and act as authority for data.
Stateless Scaling
Stateless requests allow any server to handle traffic, enabling horizontal scaling.
Single Point of Failure
Without redundancy, the centralized server can become an outage risk.
Summary
Use client-server when centralized control, strong consistency, and centralized security are essential. Mitigate risks with redundancy, TLS, and proper scaling.
