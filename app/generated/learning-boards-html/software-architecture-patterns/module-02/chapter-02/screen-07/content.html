Module 2 › Chapter 2.2 › Peer-to-Peer Pattern
Definition

Peer-to-Peer (P2P)

Each node can act as both client and server; the network lacks a single central authority.

  • Decentralized: No central server controls the network.
  • Resilient: The network survives many node failures.
  • Resource sharing: Bandwidth, storage, and compute are distributed.
Example
A distributed file-sharing network where students store chunks of datasets and request missing pieces from each other.
Supporting details
Discovery

Peers need mechanisms to find each other, like bootstrap nodes or distributed hash tables.

Security

Trust and validation are harder; cryptographic proofs and reputation systems are common mitigations.

Key Takeaway

P2P trades centralized control for resilience and distributed resources but requires strong discovery and validation design.
