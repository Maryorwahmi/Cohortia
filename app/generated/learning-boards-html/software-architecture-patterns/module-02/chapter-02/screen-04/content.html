Definition

Client-Server Pattern

Clients request services; servers provide authoritative data and enforce policies.

  • Request-response: Clients initiate requests; servers respond.
  • Centralized control: Servers manage shared resources and policies.
  • Statelessness common: Each request carries needed context for scalability.
Example
A web browser requests a page; a web server returns HTML and manages authentication and persistent data in a central database.
Key Takeaway

Centralization simplifies security and updates but requires planning for availability and scaling.

Supporting details
Scalability note

Stateless requests allow horizontal scaling behind a load balancer; stateful workloads need session management or sticky routing.

Misconception

Centralized does not imply a single server machine; it means a central authority which can be made highly available with redundancy.
