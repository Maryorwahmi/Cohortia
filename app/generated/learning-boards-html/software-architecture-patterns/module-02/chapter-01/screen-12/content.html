Module 2 › Chapter 2.1 › Common Pitfalls
Architecture Erosion
Occurs when layers are bypassed and higher layers directly access lower ones, increasing coupling and maintenance cost.
Symptom
UI code that includes SQL or direct data model references.
Leaky Abstractions
When a lower layer exposes internal details such as raw error codes or schema specifics to higher layers.
Mitigation
Translate errors to domain-friendly exceptions and keep interfaces focused on intent.
