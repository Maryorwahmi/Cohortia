Module 2 › Chapter 2.1 › Data Access Layer
What DAL provides
  • CRUD methods with domain-oriented signatures.
  • Mapping between domain objects and persistence models.
  • Error translation to domain-friendly exceptions.
Key takeaway
A stable repository API shields services from storage changes.
Example
OrderRepository exposes save_order and get_order_by_id. The service never performs raw SQL or depends on schema formats.
Pro Tip
Design repository APIs around domain actions, not storage operations, to keep intent clear.
Mistake
Returning raw database rows to services couples them to the schema and breaks the abstraction.
