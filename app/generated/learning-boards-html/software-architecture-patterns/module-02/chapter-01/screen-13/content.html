Template: Online Recipe Book
  1. Presentation: Web UI, recipe form, list view, controllers.
  2. Business Logic: RecipeService, validation, tagging, search rules.
  3. Data Access: RecipeRepository with save_recipe, find_by_keyword.
  4. Database: recipes, ingredients, tags tables; indexes for search.
Trace: Add new recipe
The UI gathers input and performs minimal checks. The controller passes data to RecipeService. The service validates business rules, creates a recipe entity, and calls RecipeRepository.save_recipe. The repository maps the entity to tables and commits to the database. The service may publish an event or clear caches afterward.
