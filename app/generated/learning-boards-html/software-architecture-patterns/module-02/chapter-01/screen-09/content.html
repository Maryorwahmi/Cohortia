Strict Layering
Only call the adjacent lower layer; enforce via interfaces and reviews.
Check
If changing storage forces UI edits, layering has been violated.
Risk
Relaxed calls accelerate architecture erosion and increase coupling.
Guidelines
  • Prefer interfaces between layers.
  • Require design review for any bypass.
  • Write tests that exercise layers through defined interfaces.
Key Takeaway
Strict adjacency preserves separation of concerns and prevents hidden coupling.
