Module 2 › Chapter 2.1 › Key Concepts
Layered Architecture
Organize systems into horizontal layers with restricted communication to adjacent layers.
Separation of Concerns
Each layer addresses a distinct concern to improve clarity and testability.
Strict Layering
Prefer adjacent-layer calls; bypasses risk architecture erosion and coupling.
Final Takeaway

Design layers for intent, name methods by domain actions, and protect boundaries with interfaces, reviews, and tests.
