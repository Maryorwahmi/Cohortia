Module 2 › Chapter 2.1 › What is Layered Architecture?
Definition
A pattern that organizes system concerns into stacked horizontal layers, each with a single role and defined communication paths.
Analogy
A multi-story building: reception, offices, services, and storage interact through stairs and elevators — a clear ordering of responsibilities.
Key Takeaway
Layers reduce coupling and let you test business rules independent of UI and storage.
Common Mistake
Treating layering as an excuse to split functionality arbitrarily without clear boundaries.
Layer metaphor cards
UI
Presentation Layer
Handles user input and visualization; delegates processing.
BL
Business Logic Layer
Encodes domain rules, validations, and orchestration.
DAL
Data Access Layer
Abstracts persistence details and provides CRUD operations.
DB
Database Layer
The physical storage system holding tables, schemas, and records.
