Module 6 › Chapter 6.5 › Key Concepts
Architectural Runway
Minimal foundation and prototypes that let near-term features be implemented without large rework.
Technical Debt
The implied cost of shortcuts. Distinguish prudent, planned debt from reckless, unmanaged debt.
Evolutionary Architecture
Design for change using modularity, tests, and short feedback loops to evolve safely.
Summary

Keep runway visible, manage debt by impact, and adopt evolutionary practices so your architecture supports change without stalling delivery.
