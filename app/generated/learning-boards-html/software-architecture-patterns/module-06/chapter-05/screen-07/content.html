Module 6 › Chapter 6.5 › Strategies for Managing Debt
Process

A reproducible workflow for debt

  1. 1. Visibility
    Record debt as backlog items with impact, risk, and owner so stakeholders can make informed trade-offs.
  2. 2. Prioritization
    Rank by how much the debt slows delivery or increases failure risk. Prioritize high-impact repayment first.
  3. 3. Dedicated Time
    Allocate sprint capacity or timeboxes for refactoring. Small, continuous work avoids big disruptive rewrites.
  4. 4. Refactor with Tests
    Write tests before changing behavior, refactor in small steps, and run regression suites to maintain safety.
  5. 5. Continuous Learning
    Invest in training and knowledge sharing to prevent repeated poor choices and to spread best practices.
Example workflow
A tangled payment function: create tests for existing behavior, extract a payments adapter, update callers gradually, then remove the old function.
Pro Tip
Use small measurable milestones for repayment so you can show progress each sprint.
Key Takeaway

Turn debt into a sequence of testable, timeboxed tasks and measure repayment progress to avoid silent accumulation.
