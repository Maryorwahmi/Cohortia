Module 6 › Chapter 6.5 › Hardcoded Config & Refactor
Code Walkthrough

From hardcoded to configurable

Original (debt)
def send_report():
  endpoint = "https://api.example.com/production"
  api_key = "PROD_SECRET"
  # call external service with these hardcoded values
Hardcoding binds you to an implementation and forces code changes for configuration updates or key rotation.
Refactored (paying down debt)
def send_report(config, secrets):
  endpoint = config.get("report_endpoint")
  api_key = secrets.get("REPORT_API_KEY")
  # call external service using injected config and secrets
Injecting config and secrets makes the function flexible, testable, and safe for rotation.
Refactor Steps
1) Add tests for behavior. 2) Introduce config/secrets interfaces. 3) Migrate callers incrementally.
Common Mistake
Rewriting everything at once. Instead, refactor piecewise with tests.
Key Takeaway

Small, tested refactors transform debt into planned improvements without disrupting delivery.
