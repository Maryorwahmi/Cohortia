Module 6 › Chapter 6.5 › Evolutionary Architecture
Principles

Small steps, reversible changes

  • Modularity: Break systems into replaceable parts with clear contracts.
  • Loose coupling: Minimize direct dependencies to allow independent change.
  • Automated safety net: Tests and CI guard refactors and preserve behavior.
  • Continuous feedback: Use metrics and experiments to guide decisions.
Pro Tip

Treat refactors as part of delivery. Small improvements every sprint compound into sustainable systems.

Example Pattern

Adapter pattern for provider changes

Define a minimal adapter interface for a payment provider. Implement one provider initially, and add others by implementing the same interface.

# Adapter pseudo-example
class PaymentAdapter:
  def charge(self, amount, currency):
    pass

class StripeAdapter(PaymentAdapter):
  def charge(self, amount, currency):
    # uses stripe SDK
    pass

# Business code uses PaymentAdapter only
Key Takeaway

Build change-friendly boundaries and protect them with tests so you can evolve safely and quickly.
