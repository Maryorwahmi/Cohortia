Frame the problem
Write a concise problem statement and list prioritized requirements before evaluating options.
Measure the trade-offs
Map alternatives to prioritized NFRs and constraints; prefer measurable impacts.
Document and revisit
Record decision, rationale, trade-offs, and acceptance criteria so the team can re-evaluate later.
Final thought

Use these three checks in every design review to keep architecture decisions practical, measurable, and revisable.
