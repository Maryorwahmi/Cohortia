Lab: Cloud Provider Matrix
Follow these spreadsheet steps to evaluate two providers.
1. Pick two providers as your alternatives.
2. Enter criteria and weights (example set provided in task).
3. Score each provider 1–5 and add evidence notes.
4. Multiply scores by weights and sum to get totals.
5. Run sensitivity checks by adjusting important weights.
