C4 Levels
Context (L1): Who uses the system and which external systems interact with it. Good for executives and product.
Container (L2): Major deployable parts like services and databases. Suitable for technical leads and product owners.
Component (L3): Internal responsibilities of a single container. For implementation planning with developers.
Code (L4): Class or sequence-level detail for developers building or refactoring code.
Practice Pattern
For new systems produce a Context diagram and a Container diagram before deep dives. Annotate each with the intended audience and decision to be made.
Example
Context: Recommendation Service interacts with frontend and analytics platform. Container: API service, engine, DB, model store.
Tip
Use progressive disclosure in presentations: start with L1, then reveal L2 for technical questions.
Key Takeaway

The C4 hierarchy helps you talk to different audiences without rework—start broad, then zoom in.
