Module 6 › Chapter 6.4 › Operations & Security
Operational Artifacts
  • Deployment diagram showing nodes and runtimes.
  • Monitoring and alerting plan with key SLOs and thresholds.
  • Failure modes and recovery procedures.
Example
A service requires 2 vCPU and 4 GB RAM with autoscaling; alerts trigger at 70% CPU sustained for 5 minutes.
Security Artifacts
  • Data flow diagrams that identify sensitive data paths.
  • Access control matrix and authentication/authorization approach.
  • Compliance notes and any required encryption or audits.
Pro Tip
Surface security controls early to avoid late rework and hidden costs.
Common Mistake
Treating security as an afterthought, rather than a design constraint.
Key Takeaway

Operational and security stakeholders need concrete constraints and recovery plans, not abstract intent.
