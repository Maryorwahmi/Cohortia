Sequence Diagrams
Use when order and timing of messages matter. Example: payment authorization sequence with gateway, order service, and notification service.
When to pick
Whenever interaction ordering could affect correctness or consistency.
Deployment & Class Diagrams
Deployment diagrams map software to infrastructure for operations. Class diagrams describe data models for developers. Use them when structural or deployment precision is required.
Pro Tip
Create a short UML view to answer a single technical question, then retire it once the question is resolved.
Misconception
Assuming UML must be exhaustive. Target it to a problem and keep it minimal.
