Module 06 › Chapter 6.2 › Consequences: Impacts & Actions
Consequences — What to include
  • Positive: expected benefits with a short justification.
  • Negative: operational cost, security exposure, performance impacts.
  • Action Items: concrete tasks needed to implement the decision.
  • Monitoring: how to detect regressions or validate assumptions.
Concrete example items
  • Positive: improves horizontal scalability; reduction in gateway load estimated at 40%.
  • Negative: introduces token revocation complexity and requires secure storage.
  • Action items: integrate OAuth provider, add token validation in gateway, implement refresh token rotation.
  • Monitoring: add token failure metrics and alerts for unusually high revocation rates.
Mistake to avoid

Do not leave consequences vague or omit action items; vague consequences prevent operational follow-through.
