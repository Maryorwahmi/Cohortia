Module 06 › Chapter 6.2 › ADR Writing Activity
Task Instructions
  1. Context: Describe data to store and key NFRs: high write throughput, scalability, low latency reads, flexibility, cost-effectiveness.
  2. Choose two database types to consider (e.g., MongoDB and a persistent message log or relational DB).
  3. Decision: pick one and state clearly why.
  4. Alternatives Considered: explain why the other choice was rejected.
  5. Rationale & Consequences: tie the choice to requirements and list action items.
