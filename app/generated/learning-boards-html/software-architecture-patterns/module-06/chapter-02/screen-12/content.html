Module 06 › Chapter 6.2 › Storing ADRs & Workflow
Repository placement
  • Common path: docs/arch/decisions or docs/decisions.
  • Keep ADRs as markdown files so they are searchable and versioned.
  • Include a README index with short summaries and statuses for discovery.
Workflow integration
  • Draft ADRs during design, attach them to related pull requests.
  • Accept ADRs when code implementing the decision merges; update status/date.
  • Link ADRs to tickets or diagrams to provide context without duplicating content.
Adoption tip: make ADR updates part of the definition of done for significant changes.
