Module 06 › Chapter 6.2 › Common Mistakes
Mistakes
  • Vague rationale — does not link to requirements.
  • No alternatives — suggests lack of due diligence.
  • Missing consequences — no follow-through.
  • Not version-controlled — hard to find and maintain.
Fixes
  • Tie rationale to explicit NFRs and constraints.
  • List alternatives with clear rejection reasons.
  • Include measurable consequences and action items.
  • Store ADRs with code and update status when changed.
Quick exercise: take a weak ADR and rework it to include one measurable consequence and one explicit action item.
