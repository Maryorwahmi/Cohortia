Module 4 › Chapter 3.4 › Order Saga Architecture
Order Service
Create order as PENDING. Compensation: mark order CANCELLED.
Payment Service
Process payment. Compensation: refund payment and publish PaymentRefundedEvent.
Inventory Service
Decrement stock. Compensation: increment stock to restore levels.
Shipping Service
Schedule shipment. Compensation: cancel shipment and notify carrier.
Operational features
  • Correlation IDs across messages for tracing.
  • Idempotent handlers so retries do not duplicate effects.
  • Durable logs or state store for orchestrator-based designs.
Example failure
If inventory fails after payment, the Saga must refund payment and mark order cancelled. These are compensation transactions coordinated by events or the orchestrator.
