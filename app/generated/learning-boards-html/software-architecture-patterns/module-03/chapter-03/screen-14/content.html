Module 03 › Chapter 3.3 › Key Concepts
API Gateway

A single entry that routes requests and handles cross-cutting concerns like auth and rate limiting.

Request Routing

Routes use predicates and filters to forward and transform requests to internal services.

Resilience Features

Rate limiting, caching, and circuit breakers protect backends and improve availability.

Takeaway

Adopt the Gateway to centralize cross-cutting concerns, but design for high availability, clear responsibilities, and observability.
