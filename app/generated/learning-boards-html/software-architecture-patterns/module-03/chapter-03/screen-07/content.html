Comparison

Techniques and Trade-offs

Caching

Speeds repeated reads but needs TTL and invalidation. Use for relatively static or read-heavy endpoints.

Rate Limiting

Throttles client requests to protect backends. Choose per-client or global strategies based on your needs.

Circuit Breakers

Detect failing services and short-circuit calls to avoid cascading faults. Useful for graceful degradation.

Concrete scenario

A public API experiences a sudden spike. Rate limiting prevents one client from saturating resources, and a cache serves repeat requests for static content. If a backend fails, the Gateway opens the circuit and returns a fast error to callers while alerts trigger investigations.

Benefit

Improved availability and predictable backend load.

Tuning

Set realistic limits and TTLs and monitor hit rates and error rates to adjust policies.

Key Takeaway

Resilience features at the Gateway protect services, but require careful monitoring and tuning.
