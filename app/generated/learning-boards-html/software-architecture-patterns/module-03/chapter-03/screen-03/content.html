Practice and Trade-offs

Hands-on objectives and operational guidance to make your Gateway reliable and focused.

Hands-on

Run two backend services and an API Gateway locally. Use path rewriting to keep client URLs consistent while forwarding to backend endpoints.

Testing

Use curl to exercise gateway routes and validate status codes, headers, and rewritten paths to ensure correct forwarding.

Operational Safety

Plan for high availability, monitoring, and avoid placing core business logic in the Gateway to keep it manageable.

Practical Tip

Consider Backend for Frontend when different clients need very different response shapes. It reduces Gateway complexity by splitting responsibilities per client type.
