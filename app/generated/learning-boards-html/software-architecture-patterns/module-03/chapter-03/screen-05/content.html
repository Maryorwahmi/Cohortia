Process

Route Matching

Routes consist of predicates and filters. The Gateway tests predicates against request attributes, then applies filters to adjust the request or response.

Predicate types
  • Path patterns (e.g., /api/products/**)
  • Header or method-based matching
  • Custom predicates for advanced use
Common filters
  • StripPrefix / RewritePath
  • RateLimiter, JwtAuthFilter
  • Header injection and response transforms
Common Mistake

Overcomplicating predicates. Keep route rules explicit and test them thoroughly.

Example
# Conceptual route that rewrites path and limits rate
- id: service_a_route
  uri: http://localhost:8081
  predicates:
    - Path=/api/a/**
  filters:
    - RewritePath=/api/a/(?.*), /a/${segment}
    - RateLimiter=10,1s
Why rewrite?

Allows external URLs to remain stable while internal services keep their own paths.

Rate limiting

Protects the backend by controlling request rates before they reach services.
