Conceptual application.yml

This example shows three simple routes that forward to local services and apply filters like RewritePath and rate limiting.

server:
  port: 8080

spring:
  application:
    name: api-gateway
  cloud:
    gateway:
      routes:
        - id: service_a_route
          uri: http://localhost:8081
          predicates:
            - Path=/api/a/**
          filters:
            - RewritePath=/api/a/(?.*), /a/${segment}
            - RateLimiter=10,1s

        - id: service_b_route
          uri: http://localhost:8082
          predicates:
            - Path=/api/b/**
          filters:
            - RewritePath=/api/b/(?.*), /b/${segment}
Test steps
  1. Run service-a on port 8081 and service-b on 8082.
  2. Run the gateway on port 8080.
  3. curl http://localhost:8080/api/a/hello and expect the service-a response.
Troubleshooting

If you see a 404, verify path predicates and that the backend is reachable on the configured port.

Hands-on Reminder

This configuration is conceptual. In a real system you might use service discovery or load-balanced URIs instead of hard-coded localhost addresses during testing.

Key Takeaway

Start simple: configure one route, test it, then add filters and additional routes incrementally.
