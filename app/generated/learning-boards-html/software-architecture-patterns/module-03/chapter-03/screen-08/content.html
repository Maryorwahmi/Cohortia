Module 03 › Chapter 3.3 › Gateway Components

Core Components

Routing Engine

Matches predicates and selects destination services or load-balanced pools.

Filter Chain

Request and response filters for rewrites, auth, headers, and transforms.

Security Module

JWT validation, OAuth proxying, and delegating identity to services.

Resilience & Cache

Rate limiting, circuit breakers, and caching layers to protect backends.

Observability hooks

Centralized logging and metrics from the Gateway give a single vantage point for traffic patterns and errors.

Deployment Choices
  • Stateless instances behind a load balancer for horizontal scaling.
  • High availability with multiple gateway nodes to avoid single points of failure.
  • Distributed rate limit stores for consistent throttling across nodes.
Design Tip

Prefer moving complexity out of the Gateway by using specialized components like BFFs or separate gateways per client type when needed.
