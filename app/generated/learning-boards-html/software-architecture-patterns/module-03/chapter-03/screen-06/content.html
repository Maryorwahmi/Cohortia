Module 03 › Chapter 3.3 › Authentication & Authorization
Definition

Centralized Security

The Gateway validates identity (authentication) and enforces access rules (authorization) consistently before requests reach services.

Example flow

Client presents JWT → Gateway verifies signature and claims → Gateway rejects or forwards with trusted headers to services.

Delegation pattern

Gateway can translate external credentials into internal tokens or headers trusted by downstream services.

Guidance

Centralize coarse-grained checks such as token validation, but keep fine-grained authorization near the data or resource owner service.

Benefit

Consistency across services and simpler auditing.

Pitfall

Relying only on the Gateway for authorization can leave services without necessary context for sensitive decisions.
