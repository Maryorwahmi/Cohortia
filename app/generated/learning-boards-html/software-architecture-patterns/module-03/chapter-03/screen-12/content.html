Module 03 › Chapter 3.3 › Implementation Choices

Managed Gateways

Cloud-managed API gateways provide built-in features like authentication, throttling, SDK generation, and analytics with less operational overhead.

When to choose

When you prefer reduced operational load and ready-made integrations over deep customization.

Open-source & Frameworks

Frameworks and proxies like reverse proxies or framework gateways allow deeper customization and integration with service discovery and custom filters.

When to choose

When you need custom filters, tight control over routing, or to integrate with an existing discovery system.

Key Takeaway

Align your Gateway choice to team skills and operational model. Managed for simplicity, self-hosted for flexibility.
