Module 03 › Chapter 3.3 › Hands-on Activity

Lab Steps

service-a
  1. Create a Spring Boot app with Spring Web.
  2. Add RestController GET /a/hello returning a simple string.
  3. Set server.port=8081 in application.properties.
service-b
  1. Create a Spring Boot app with Spring Web.
  2. Add RestController GET /b/hello returning a simple string.
  3. Set server.port=8082 in application.properties.
api-gateway
  1. Create a Spring Boot app with Spring Cloud Gateway.
  2. Configure routes for /api/a/** and /api/b/** and use RewritePath filters.
  3. Run the gateway on port 8080 and test with curl.
Test commands
curl http://localhost:8080/api/a/hello
curl http://localhost:8080/api/b/hello
Troubleshoot

If you see a 404, confirm backend ports and that RewritePath uses the correct capture group pattern.

Lab Takeaway

Practice routing and filters incrementally. Add security and resilience only after routes are correct and tested.
