Common Mistakes

Pitfalls and how to fix them

Overly granular events
Emit only events that represent meaningful domain occurrences to reduce operational overhead and ease schema evolution.
Smart broker anti-pattern
Avoid embedding business decision logic into the broker; instead, implement rules in subscribers or publishers.
Missing error handling
Configure acknowledgements, retries, and dead-letter queues so failed messages are visible and recoverable.
No schema management
Use event contracts and registries to coordinate changes across services and avoid incompatible updates.
Pro tip

Start small: adopt EDA for parts of the system that benefit most from decoupling, and iterate on broker features and contracts as you gain experience.
