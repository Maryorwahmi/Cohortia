Module 3 › Chapter 3.2 › Hands-on: NotificationService
Activity

Implement a NotificationService consumer

Steps
  1. Ensure RabbitMQ is running locally.
  2. Use the provided publisher to emit OrderCreated events.
  3. Declare queue order_events with durable=True in your consumer.
  4. Parse JSON, implement process function, and ack after success.
  5. Handle malformed messages with nack and requeue policy; implement idempotence.
Starter hints
Record processed order IDs to avoid double notifications, simulate email send with a short sleep, and log all failures for inspection. Add a dead-letter queue for messages that fail repeatedly.
Outcome

Run the publisher and consumer together, restart the consumer, and observe that events published while it was offline are processed when it reconnects.
