Module 3 › Chapter 3.1 › Key Concepts
Eventual Consistency
Accept temporary divergence as updates propagate and replicas converge over time.
Domain Events
Use events to broadcast state changes so other services can react asynchronously.
Distributed Transactions
Prefer sagas over two-phase commit to manage long-running workflows across services.
Final takeaway
Decide early which operations require strong consistency and which can be eventual; pick APIs or events accordingly.
