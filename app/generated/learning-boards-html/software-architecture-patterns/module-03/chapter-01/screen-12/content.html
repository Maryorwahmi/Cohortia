Module 3 › Chapter 3.1 › Hands-on Activity
Activity checklist
Implement, run, and verify ProductService using H2 and REST.
Step 1 — Project setup
Create Spring Boot project with Spring Web, Spring Data JPA, and H2 dependencies.
Step 2 — Model & Repo
Add Product entity and ProductRepository extending JpaRepository.
Step 3 — Controller
Implement POST /products, GET /products/{id}, PUT /products/{id}.
Step 4 — Configure H2
Use jdbc:h2:mem:productdb and spring.jpa.hibernate.ddl-auto=update for the demo.
Step 5 — Run & test
Start the app and run the sample curl commands to create and retrieve a product.
Step 6 — Reflect
Decide whether consumers should call the API or subscribe to events for product data in your scenario.
Why this matters
Running the demo proves ownership and clarifies the operational boundaries that prevent accidental coupling across services.
