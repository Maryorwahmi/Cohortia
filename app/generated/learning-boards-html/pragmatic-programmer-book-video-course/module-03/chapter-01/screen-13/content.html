Module 3 › Chapter 3.1 › Key Concepts
Don't Repeat Yourself (DRY)
Every piece of knowledge should have one authoritative representation.
Single Source of Truth
Pick a clear owner for shared rules: function, module, or service.
Duplication Types
Code, data, docs, and process duplication each require different handling.
Summary

Centralize changeable knowledge, add tests to protect it, and avoid abstractions that reduce clarity.
