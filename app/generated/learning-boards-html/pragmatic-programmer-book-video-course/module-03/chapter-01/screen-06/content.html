Choose the right owner
Local function: simple, low overhead for single-app usage. Shared module: good for repo-level reuse. Internal API: useful when many independent services need the rule.
Misconception: owning in a remote service is not always better; complexity can outweigh benefits.
Concrete plan
Refactor duplicated discount calculations into calculate_discount in a shared utilities module. Update callers to use this single function and add focused unit tests.
Why it matters: a single owner reduces places to edit and centralizes testing.
