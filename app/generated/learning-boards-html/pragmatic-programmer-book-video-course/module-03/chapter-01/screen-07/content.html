Module 3 › Chapter 3.1 › Techniques to Implement DRY
Toolbox
  • Functions & methods for behavior extraction.
  • Classes and objects for related data and operations.
  • Modules/packages and shared libraries for reuse.
  • Configuration files for changing values.
  • Code generation for repetitive boilerplate.
Refactor process
1. Detect duplication. 2. Design single owner. 3. Implement and replace callers. 4. Add tests. 5. Monitor for regressions.
Example: extract apply_gold_discount and call it from both checkout and invoice generation.
