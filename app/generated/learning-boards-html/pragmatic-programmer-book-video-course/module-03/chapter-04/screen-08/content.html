Module 3 › Chapter 3.4 › Design by Contract
DbC Components
Precondition
Requirement the caller must satisfy before calling a function.
Postcondition
Condition the supplier guarantees after execution completes.
Invariant
A property that must always hold for an object's state across public method calls.
Practical guidance
  • Document the contract in code and tests so callers know their responsibilities.
  • Use asserts for development-time enforcement of contract clauses.
  • Verify invariants after state changes to catch internal bugs.
Key Takeaway

DbC clarifies who must ensure which conditions and helps isolate defects to caller or supplier code.
