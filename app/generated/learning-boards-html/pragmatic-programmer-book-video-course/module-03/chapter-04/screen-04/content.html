Module 3 › Chapter 3.4 › Error Handling vs Assertions
Error Handling (Recoverable)
Used for external and expected problems where the program can recover.
  • Use try-except or explicit validations for files, network, or user input.
  • Return errors or show user messages so the system can continue.
  • Essential checks must run in production.
Example
If a file is missing, catch the exception and prompt the user or retry.
Assertions (Fail-Fast)
Used for internal sanity checks that indicate programmer errors.
  • Assert invariants and assumptions that should never be false.
  • Fail fast to reveal bugs early and precisely.
  • Do not use for validating external or user-provided data.
Example
A function that expects positive numbers should assert that property to catch caller bugs.
