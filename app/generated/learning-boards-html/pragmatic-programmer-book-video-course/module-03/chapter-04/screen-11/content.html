Starter code
class SimpleQueue:
    def __init__(self, capacity):
        # Initial capacity check - should be positive
        self._capacity = capacity
        self._elements = []

    def enqueue(self, item):
        # Precondition: Queue should not be full
        self._elements.append(item)

    def dequeue(self):
        # Precondition: Queue should not be empty
        if not self._elements:
            return None
        return self._elements.pop(0)
Task: add asserts in __init__, enqueue, dequeue, implement _check_invariant, and call it at the end of each modifying method. Test violations like SimpleQueue(0), dequeue on empty, and enqueue when full.
Checklist
  • Assert capacity > 0 in constructor.
  • Implement _check_invariant asserting len(elements) <= capacity.
  • Assert not full before enqueue, not empty before dequeue.
  • Call _check_invariant after each change.
