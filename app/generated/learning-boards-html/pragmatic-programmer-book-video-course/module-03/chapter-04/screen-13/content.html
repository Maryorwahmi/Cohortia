Module 3 › Chapter 3.4 › Common Mistakes
Mistake
Using asserts for user input or security checks where they may be disabled.
Mistake
Over-asserting small invariants that add noise instead of clarity.
Mistake
Catching AssertionError as normal control flow and hiding the original bug.
Best practices
  • Keep asserts for programming errors and critical invariants used during development.
  • Write explicit validations for anything that must be enforced in production.
  • Test assertion failures intentionally to ensure they trigger correctly.
