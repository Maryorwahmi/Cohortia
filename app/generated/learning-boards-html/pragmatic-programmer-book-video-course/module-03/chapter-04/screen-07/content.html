Fail-Fast Flow
Place checks where assumptions are made and stop when those assumptions are violated.
Steps
  1. Validate external input with explicit conditionals.
  2. Assert internal assumptions made by your code.
  3. On failure, use the trace to locate the faulty caller or callee.
  4. Fix the root cause rather than patching downstream effects.
Concrete scenario
A parser asserts the data shape after deserialization. If an upstream change breaks the shape, the assert flags the change immediately so you can update the parser or the producer.
Common mistake
Catching assertion failures and treating them like runtime errors hides the true bug and increases debugging cost.
