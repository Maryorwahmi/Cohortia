Module 3 › Chapter 3.4 › What is an Assertion?
Definition

An assertion checks an internal assumption; failure signals a bug. It is a development-time tool to make failures obvious and local.

Why it matters
Assertions help you find logic errors quickly and avoid longer chains of corrupted state caused by a single wrong assumption.
Concrete analogy
Think of an assertion as a sensor on a machine part that trips if an impossible condition occurs, forcing inspection before damage spreads.
Misconception
Assertions are not a substitute for validating user input or handling external failures.
Pro tip
Place asserts at API boundaries and after state changes to document expectations and catch violations quickly.
