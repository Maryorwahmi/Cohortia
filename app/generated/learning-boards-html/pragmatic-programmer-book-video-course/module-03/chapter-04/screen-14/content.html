Module 3 › Chapter 3.4 › Mini-Quiz
Question
You are writing calculate_average(numbers) that expects a non-empty list. Which is correct: assert non-empty or raise ValueError?
Correct answer
Use an assert if the non-empty requirement is a documented programmer contract. Use ValueError if empty lists are expected in normal operation or come from user input.
Reflection
When in doubt, prefer explicit validations for anything that could legitimately be incorrect at runtime, and reserve asserts for invariants and developer assumptions.
