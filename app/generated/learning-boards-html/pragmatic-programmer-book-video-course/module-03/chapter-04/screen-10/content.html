BankAccount (conceptual)
class BankAccount:
    def __init__(self, initial_balance):
        assert initial_balance >= 0, "Initial balance cannot be negative (Precondition)"
        self._balance = initial_balance
        self._check_invariant()

    def _check_invariant(self):
        assert self._balance >= 0, f"Invariant violated: Balance is negative ({self._balance})"

    def deposit(self, amount):
        assert amount > 0, "Deposit amount must be positive (Precondition)"
        self._balance += amount
        self._check_invariant()

    def withdraw(self, amount):
        assert amount > 0, "Withdraw amount must be positive (Precondition)"
        assert self._balance >= amount, "Insufficient funds (Precondition)"
        self._balance -= amount
        self._check_invariant()
Notes
The invariant ensures balance never becomes negative; preconditions prevent invalid operations from the caller. Use tests that violate each clause to confirm behavior.
Key Takeaway

Mapping assertions to contract clauses makes it clear who is responsible for correctness and where bugs originate.
