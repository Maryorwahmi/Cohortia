Module 3 › Chapter 3.4 › Key Concepts
Assertion
A programmer check that signals impossible internal states when false.
Fail-Fast
Immediately report impossible conditions so you can debug the root cause.
Design by Contract
A specification style using preconditions, postconditions, and invariants.
Summary: Assertions and DbC help you catch programmer errors early, document expectations, and assign responsibility for correctness between caller and supplier.
