Dependency Injection
Provide collaborators externally so components are unaware of creation details.
Why it helps
  • Tests inject fakes instead of doing expensive setup.
  • Replace implementations without editing the consumer.
  • Make dependencies visible and explicit.
Pattern example
class Service:
  def __init__(self, repo):
    self.repo = repo

# caller provides repo implementation
repo = SQLiteUserRepository('app.db')
service = Service(repo)
Key Takeaway
DI turns hidden creation into explicit wiring, enabling isolated tests and easy substitution of implementations.
