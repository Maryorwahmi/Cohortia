Common mistakes and fixes
Practical corrections that restore orthogonality without overengineering.
Hidden globals
Fix: Encapsulate state and pass it explicitly to consumers.
Premature abstraction
Fix: Start with a small interface justified by a test or swap scenario.
Over-separation
Fix: Ensure each new class adds clear value and preserves readability.
Performance fear
Fix: Measure hotspots; orthogonality rarely hurts real-world performance and helps maintainability.
Key Takeaway
Use small, test-driven abstractions and make dependencies explicit; avoid hidden coupling and huge classes.
