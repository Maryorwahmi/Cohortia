Why globals and god objects harm orthogonality
Shared mutable state creates hidden coupling; large classes hide multiple responsibilities.
Symptoms
  • Hard-to-reproduce bugs due to stateful interactions
  • Tests that must set global state to succeed
  • Classes that change for many unrelated reasons
Remedies
  • Encapsulate state in a dedicated component
  • Pass dependencies explicitly via DI
  • Split god objects into focused classes with single responsibilities
Key Takeaway

Encapsulation and explicit dependencies keep state predictable and components independently testable.
