Quick Reference
Three one-line rules to apply immediately.
Explicit Contracts
If a component needs something, give it an interface and pass it in.
Test-Driven Abstraction
Keep an abstraction if it makes testing simpler or supports clear substitutions.
Small Steps
Refactor in small, tested increments to reduce risk.
Final Prompt
Reflect: pick one module in your project and outline a three-step plan to make it more orthogonal.
