Objectives — Examples & Mnemonics
Mnemonic: Orthogonal Axes
Picture two axes. Changing one coordinate doesn't affect the other. Map axis A to a repository and axis B to a formatter — they should move independently.
Checklist: Single Responsibility
  • One reason to change?
  • Can I test it with a fake?
  • No global state?
Mini-task: Inject a Fake
Replace direct instantiation with a constructor parameter and run a test that supplies a fake implementation.
Refactor Timeline
  1. Extract interface
  2. Inject dependency
  3. Add isolated test
Key Takeaway

Small, testable refactors and clear mnemonics make orthogonality practical and repeatable across your codebase.
