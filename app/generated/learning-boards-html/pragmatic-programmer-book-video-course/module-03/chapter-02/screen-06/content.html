Module 3 › Chapter 3.2 › Techniques to Achieve Orthogonality
Decoupling Process
1
Loose Coupling
Limit knowledge of internals; depend on behavior, not structure.
2
Interfaces
Declare contracts that consumers use without assuming implementation details.
3
Dependency Injection
Pass collaborators from outside so tests can provide fakes.
4
Messaging
Use events to decouple senders and receivers for scalable systems.
5
Avoid Globals
Encapsulate state and pass it explicitly to avoid hidden dependencies.
Small refactor pattern
1) Extract interface, 2) Accept interface via constructor, 3) Provide concrete implementation and tests with a fake.
Key Takeaway
Apply one technique at a time and verify with isolated tests to ensure progress.
