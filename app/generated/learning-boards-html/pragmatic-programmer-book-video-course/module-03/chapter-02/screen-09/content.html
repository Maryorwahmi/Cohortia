OrderProcessor after refactor
class OrderProcessor:
  def __init__(self, notification_sender: NotificationSender):
    self.notification_sender = notification_sender

  def process_order(self, order_id, customer_phone, items):
    total_amount = sum(item['price'] * item['quantity'] for item in items)
    confirmation = f"Your order {order_id} for ${total_amount:.2f} has been processed!"
    self.notification_sender.send_notification(customer_phone, confirmation)
    return True
Test tip: create a FakeNotificationSender that stores messages in a list. Inject the fake, run process_order, and assert the fake received the expected message. This proves the order logic is orthogonal to notification transport.
Key Takeaway
Dependency injection makes business logic independently testable from side-effecting systems.
