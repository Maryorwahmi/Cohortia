Core Concept
What is a Tracer Bullet?
A focused, end-to-end slice built early and well.
Essential properties
  • Touches all major layers: UI, API, business logic, data.
  • Production-quality foundation, not disposable mock.
  • Fast to build, easy to extend.
Example
A task create-and-list path proves that the chosen stack integrates end-to-end.
Common mistake
Confusing a UI-only mock with a tracer bullet; the slice must exercise backend and storage too.
Key Takeaway

A tracer bullet converts risky assumptions into a runnable path you can test, measure, and iterate on.

Analogy
Like firing a visible bullet to see its trajectory and correct your aim, a tracer bullet reveals integration and design errors while correction is inexpensive.
What to build

One small feature that goes from input to database and back to display.

Quality rules

Keep code clean, add basic tests, and use version control; this code becomes the project's skeleton.

Reflection

Pick one smallest user action in your project. How would you build an end-to-end slice for it in a single day?
