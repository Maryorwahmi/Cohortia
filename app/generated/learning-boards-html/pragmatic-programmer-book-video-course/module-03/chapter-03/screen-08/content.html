End-to-End Slice
What the slice includes
UI Input

A minimal form or control that captures the user's intent.

Backend Endpoint

A single route that accepts the input and calls business logic.

Persistence & Retrieval

A small table and a read route that returns what was stored.

Concrete example
A blog post tracer bullet: form with title and content, POST to create_post, SQLite posts table, and index page listing posts.
Key Takeaway

If any layer is skipped, you miss the slice's diagnostic power. Build the round trip.

Pro tip

Use an embedded database like SQLite for initial tracer bullets to simplify setup and iteration.
