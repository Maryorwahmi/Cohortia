Module 4 › Chapter 3.5 › Caching Strategies
Definition
Caching
Store expensive results for reuse to reduce repeated cost.
Common layers: in-memory caches, DB query caches, CDNs, and HTTP caching.
Trade-offs: memory usage and invalidation complexity versus latency improvements.
Example
Use an LRU cache decorator to memoize function results for repeated calls with identical inputs.
import functools

@functools.lru_cache(maxsize=128)
def expensive_calculation(n):
  import time
  time.sleep(1)
  return n * n

# First call is slow; subsequent calls with same n are fast
Measure memory use and eviction behavior after enabling a cache. Document what is cached and why.
Key Takeaway

Caching reduces repeated cost but requires bounds and invalidation rules. Measure both speed and memory after adding a cache.
