Module 4 › Chapter 3.5 › Lazy Loading
Definition
Lazy Loading
Defer creation until a value is needed to save startup cost.
Use lazy loading when resources are heavy and not always used. Combine with caching to avoid repeated load cost.
Example
A loader holds a path but reads the file only on first access, then caches the result for later.
class ImageLoader:
  def __init__(self, image_path):
    self._image_path = image_path
    self._image_data = None

  def get_image(self):
    if self._image_data is None:
      # load on first use
      self._image_data = f"Data for {self._image_path}"
    return self._image_data
Measure both startup improvement and first-access latency to ensure the trade-off is acceptable.
Key Takeaway

Lazy load heavy resources to reduce startup cost; combine with caching to avoid repeated loads.
