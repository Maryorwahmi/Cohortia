Skill 01 — Caching
Cache expensive but stable results to avoid repeated work. Balance memory use and eviction strategy.
Mnemonic: store once, reuse often

Skill 02 — Lazy Loading
Defer creation of heavy resources until they are needed to reduce startup cost.
Mnemonic: wait until asked

Skill 03 — Concurrency & Parallelism
Use concurrency for I/O overlap and parallelism for CPU-bound work. Watch for platform specifics like the GIL.
Mnemonic: I/O → threads, CPU → processes
VERIFIED COMPETENCY MILESTONE
Skill 04 — Resource Hygiene
Always release handles and use context managers to avoid leaks and degraded performance over time.
Mnemonic: close when done
