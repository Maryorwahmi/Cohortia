Process Flow
Profiling workflow
Baseline → Profile → Identify hotspots → Optimize → Verify.
1. Record a baseline measurement for the operation you care about.
2. Run a profiler while exercising the scenario to capture call-level costs.
3. Focus on the small set of functions using most time or memory.
4. Make a targeted change and re-measure to confirm impact.
Pro Tip
Use representative inputs and run the profiler under similar load to production when possible.
Code examples
Simple timing with timeit and conceptual profiling with cProfile.
import timeit

def slow_function():
  sum(range(10**7))

print(timeit.timeit(slow_function, number=3))
