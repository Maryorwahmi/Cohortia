Code example
# Example: Simple build script for a Python project
#!/bin/bash
echo "--- Running build script ---"

# 1. Install dependencies (if not already in a virtual env)
# python -m venv venv
# source venv/bin/activate
pip install -r requirements.txt

# 2. Run linters/static analysis
echo "Running flake8..."
flake8 . || { echo "Flake8 found issues!"; exit 1; }

# 3. Run tests
echo "Running tests..."
pytest --cov=my_app tests/ || { echo "Tests failed!"; exit 1; }

# 4. Create distribution package (e.g., wheel, sdist)
echo "Building package..."
python setup.py sdist bdist_wheel

echo "Build successful!"
Explanation
  • Install dependencies first so subsequent steps run in a known environment.
  • Run linters to catch style and likely bugs before executing longer tests.
  • Run tests with coverage to produce measurable safety nets for refactoring.
  • Package only after earlier steps succeed to avoid releasing broken artifacts.
Example outcome
If flake8 fails, the script exits early and the package step never runs, preserving CI time and giving early feedback.
Pro-tip
Keep the script simple and idempotent. Add explicit exit codes so CI can detect failures cleanly.
