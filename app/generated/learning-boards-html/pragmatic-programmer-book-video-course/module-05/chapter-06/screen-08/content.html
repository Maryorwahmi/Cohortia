Module 05 › Chapter 5.6 › Deployment Automation (CI/CD)
Pipeline stages
1. Build
Install deps, lint, run unit tests, build artifacts.
2. Test
Run integration and end-to-end suites as appropriate.
3. Deploy
Push artifacts to staging or production with idempotent scripts.
Benefit
CI/CD reduces manual steps and provides automated, auditable deployments with consistent checks.
Practical setup
  • Store pipeline config in version control so changes are auditable.
  • Run fast checks on every commit and longer suites in gated stages.
  • Use idempotent deploy scripts so retries are safe.
Misconception
CI/CD is not magic; it requires maintenance. Treat pipeline scripts like code and assign ownership for upkeep.
