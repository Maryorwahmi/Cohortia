Use these stages to plan practice: start by explaining the automation principle, then implement simple scripts, and finally integrate them into CI so they run automatically on commits.
Milestone checklist
  • Run the provided build script and see tests pass with coverage.
  • Build the Docker image and verify the container starts.
  • Create a CI job that runs build and test on each push.
  • Add a clean target to your Makefile to remove artifacts.
