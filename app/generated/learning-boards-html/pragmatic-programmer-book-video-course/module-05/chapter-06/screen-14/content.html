Module 05 › Chapter 5.6 › Testing & Maintaining Automation
Treat as code
Keep automation in version control, review changes in pull requests, and create tests or dry-run modes so changes can be validated automatically.
Idempotence
Design operations so running them multiple times leaves the system in the same desired state.
Operational checks
  • Include precondition checks and clear error outputs.
  • Log actions so CI and ops can audit automation runs.
  • Assign ownership and schedule reviews to prevent bit rot.
Closing question
How will you test that your automation is safe to run repeatedly in your environment?
