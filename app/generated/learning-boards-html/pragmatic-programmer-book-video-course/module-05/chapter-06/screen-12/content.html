Module 05 › Chapter 5.6 › Automation Anti-Patterns
Comparison
Automated with tests
Reproducible, auditable, maintained as code.
Ad-hoc scripts
Hard to reproduce, single-point-of-failure, not versioned.
Practical guidance
Prioritize automating stable, repeatable processes and invest in tests and maintenance.
Checklist
  • Fix the manual process before automating.
  • Write tests for automation where possible.
  • Keep automation under version control with owner(s) assigned.
Warning
A broken automation script can be as harmful as a bug; test and review automation code before using it in production.
