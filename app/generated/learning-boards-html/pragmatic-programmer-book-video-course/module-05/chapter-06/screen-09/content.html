Dockerfile
FROM python:3.9-slim

WORKDIR /app

# Install dependencies
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# Copy application code
COPY . .

# Expose the port the app runs on
EXPOSE 8000

# Command to run the application
CMD ["gunicorn", "my_app:app", "--bind", "0.0.0.0:8000"]
Build the image in CI and publish a tagged artifact. Avoid embedding secrets; pass them at runtime.
Why it matters
  • Reproducibility: the same image runs locally, in CI, and in production.
  • Onboarding: new developers run a container instead of installing many packages.
  • Consistency: environment drift is minimized because configuration is code.
Misconception
Containers are not a substitute for good packaging; they complement scripts and CI pipelines to produce consistent artifacts.
