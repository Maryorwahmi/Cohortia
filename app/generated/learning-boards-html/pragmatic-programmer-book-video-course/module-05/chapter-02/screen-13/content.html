Design Review Checklist
Quick questions to focus your review.
Single reason to change?
If no, consider splitting responsibilities.
Hidden state or globals?
If present, make dependencies explicit or document rationale.
Direct instantiation?
If yes, evaluate DI to improve testability.
Test isolation possible?
Aim for unit tests without heavy integration setup.
Assessment idea

Refactor an OrderProcessor and demonstrate independent unit tests for the validator, repository, and email service.
