Module 5 › Chapter 5.2 › Dependency Injection
DI Process
Identify direct new calls, extract interface, pass dependency externally.
Step 1
Find where classes call constructors for collaborators.
Step 2
Extract the expected behavior into a focused interface or class.
Step 3
Refactor constructors or composition root to pass concrete implementations.
Step 4
Replace with mocks in tests to verify behavior in isolation.
Example

Instead of creating a DB connection inside ReportGenerator, accept a SalesRepository and a Formatter to enable testing without a DB or PDF library.
