Module 5 › Chapter 5.2 › Refactor: ReportGenerator
Target decomposition
Repository → Processor → Formatter → Orchestrator
SalesRepository
Fetches sales records only; no processing or formatting.
SalesReportProcessor
Calculates totals, aggregates, and business metrics.
ReportFormatter
Renders output in PDF or console formats; independent of processing logic.
Practical steps
  1. Add small characterization tests for current behavior.
  2. Extract repository and replace DB calls with repository calls.
  3. Move calculations into processor and test it in isolation.
  4. Introduce formatter implementations and wire them via the orchestrator.
Key Takeaway

Extract one responsibility at a time and verify behavior with tests to keep refactor safe.
