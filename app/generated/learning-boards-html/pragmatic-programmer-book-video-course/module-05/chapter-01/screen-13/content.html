Assessment: Spot and Fix a DRY Violation

Sample question

You have three handlers each validating emails separately. Is this a DRY violation? If yes, outline tests and a refactor plan to centralize validation.

Expected: extract validator, write unit tests for validator, replace handlers, run integration checks.
Rubric
  • Detection: finds repeated logic and explains why it is the same knowledge.
  • Naming: gives a clear name for the extracted rule.
  • Plan: tests + extraction + replacement steps present.
  • Verification: shows how to validate behavior after refactor.
Key Takeaway

Assessment measures applied judgment: knowing when to refactor and how to do it safely.
