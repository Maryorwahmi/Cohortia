Middleware for Authentication and Authorization

Pattern
  1. Extract auth logic to middleware that validates tokens or sessions.
  2. Attach an authenticated context to the request object.
  3. Handlers rely on the context and do not re-check credentials.
  4. Change policy in one place and tests exercise middleware behaviors.
Concrete scenario

If password reset, profile update, and admin routes each re-checked permissions, central middleware reduces code and provides a single test surface for access rules.

Key Takeaway

Middleware centralizes cross-cutting knowledge and lowers the chance of inconsistent access rules.
