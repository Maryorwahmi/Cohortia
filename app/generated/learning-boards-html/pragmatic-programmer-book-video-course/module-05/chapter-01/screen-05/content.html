Forms of Duplication

Identify what is duplicated to apply the right refactor.

Comparison table
Syntactic duplication: identical functions or blocks. Fix: extract shared function or helper.
Knowledge duplication: same business rule in multiple places. Fix: single authoritative routine or module.
Data duplication: storing derived data redundantly. Fix: store canonical value and derive others.
Process duplication: manual repeated steps. Fix: automate with scripts or CI pipelines.
Example scenarios
  • Email validation in three forms → knowledge duplication → extract to shared validator.
  • Age and birthdate stored separately → data duplication → derive age from birthdate.
  • Copying SQL queries with small edits → knowledge duplication of access patterns → centralize in a repository.
Pro Tip

Name the piece of knowledge clearly before refactoring; the name becomes the authoritative contract.
