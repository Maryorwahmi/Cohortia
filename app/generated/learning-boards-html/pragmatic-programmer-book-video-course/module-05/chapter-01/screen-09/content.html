Choosing the right abstraction

Function / Module
Use for small, focused rules like validators or formatters. Test and name clearly.
Domain Service
For business rules used across features, a domain module or service centralizes logic and state.
Middleware / Interceptor
Cross-cutting concerns like auth and logging belong here to avoid sprinkling checks across handlers.
Configuration loader pattern

Centralize the knowledge of which settings exist and how to convert them. A loader merges defaults, environment, and user overrides into one authoritative config object.

Pro Tip

Keep abstractions small and well-named. If a future divergence occurs, splitting a named abstraction is easier than undoing a tangled one.
