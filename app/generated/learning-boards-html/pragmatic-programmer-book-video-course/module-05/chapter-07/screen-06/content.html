Definition Unit Test Example
Key rules for unit tests
  • Test a single behavior per test.
  • Avoid external I/O; use mocks for dependencies.
  • Assert public behavior, not internal structure.
  • Keep tests fast so they are run frequently.
Key Takeaway

Small, clear unit tests are inexpensive safety nets for refactoring and bug fixes.

Code Example (Python)
# Example: Unit test for a simple calculator function
import pytest

def add(a, b):
  return a + b

def test_add_positive_numbers():
  assert add(2, 3) == 5

def test_add_negative_numbers():
  assert add(-1, -5) == -6

def test_add_zero():
  assert add(0, 0) == 0
