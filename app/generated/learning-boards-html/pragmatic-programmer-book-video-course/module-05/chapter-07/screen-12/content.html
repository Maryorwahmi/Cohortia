Process Flow Integration Test
Integration test checklist
  • Use a fresh in-memory repository per test.
  • Test one seam or flow per test case.
  • Avoid network or file I/O to keep tests deterministic.
Example (pytest)
# Integration test using the real in-memory ProductRepository
import pytest

def test_create_and_retrieve_product():
  repo = ProductRepository()
  service = ProductService(repository=repo)
  service.create_product('p1', 'Widget', 12.5)
  product = repo.get_product('p1')
  assert product is not None
  assert product.name == 'Widget'
