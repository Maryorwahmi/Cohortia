Core Concept Property-Based Testing

When to use it

Use property-based tests for functions with broad input domains or many combinations where handcrafted examples risk missing edge cases.

Benefits: finds subtle bugs, generates diverse inputs, and often shrinks failing cases to a minimal counterexample for diagnosis.
Example (conceptual)
from hypothesis import given, strategies as st

@given(weight=st.floats(min_value=0.1, max_value=100.0),
       zone=st.sampled_from(["A","B","C"]))
def test_shipping_cost_is_never_negative(weight, zone):
  cost = calculate_shipping_cost(weight, zone)
  assert cost >= 0.0
Property tests are powerful but should complement, not replace, focused unit tests that document specific expected behavior.
