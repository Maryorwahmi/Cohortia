Hands-on Lab Overview
You will implement unit tests for ProductService using a mock ProductRepository, then run an integration test using the provided in-memory repository. The unit tests focus on price validation and not-found logic; the integration test confirms persistence behavior.
Unit tests: fast, isolated, run locally
Integration test: real repository, verifies seams
Property tests: find edge cases with generated inputs
Diagnosis: speed, flakiness, isolation
Tip
Create a fresh in-memory repository per integration test to guarantee isolation. Use mocks for unit tests to avoid I/O.
