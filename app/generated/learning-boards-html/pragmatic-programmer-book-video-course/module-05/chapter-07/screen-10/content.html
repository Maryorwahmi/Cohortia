Comparison Mocks & Isolation

Mock vs Stub

Mock: Simulates an object and allows assertions about interactions.
Stub: Returns canned responses without verifying calls.
Use mocks to keep unit tests deterministic and fast. Use real small in-memory implementations for integration tests to validate behavior.
Practical example
When testing ProductService.create_product, mock ProductRepository.add to confirm the service calls it for valid inputs and raise for invalid prices to test error handling without touching storage.
Pitfall

Mocking internal private helpers couples tests to implementation. Prefer testing through public methods and interfaces.
