Definition Integration Tests

When to write them

Write integration tests for boundaries: API contracts, database schemas, and external service interactions. They validate that components speak the same language.
Use test DBs or in-memory stores to ensure repeatability.
Keep scope focused to one seam to limit complexity.
Mock truly external services when realistic or expensive to run.
Example (conceptual)
# Integration test: user registration flow
# Use a test database and test server fixture
response = requests.post(base_url + '/register', json={"email": email, "password": password})
assert response.status_code == 201
data = response.json()
assert "user_id" in data
# verify user exists in test database
Keep integration tests targeted and isolated to avoid long, brittle suites.
