Module 5 › Chapter 5.4 › What is a Prototype?
Definition

Prototype

A quick experiment designed to answer a single question, built without long-term maintenance in mind.

When to use
Exploring UI flows, testing an algorithm, or checking a third-party API integration quickly.
Danger
The prototype trap: accidentally making throwaway code the production path increases technical debt.
Concrete Example
A developer writes a quick script to measure algorithm performance on a sample dataset with hardcoded paths and no tests. This answers whether the algorithm is fast enough but is not production-ready. The script's results inform a proper implementation that will be written with tests and error handling.
Analogy
A prototype is like a paper mock of a UI: cheap, fast, and disposable once you learn what you need.
Key Takeaway

Use prototypes to answer narrow questions quickly, then reimplement production-quality solutions informed by those lessons.
