Module 5 › Chapter 5.4 › Tracer Bullet vs Prototype
Tracer Bullet

Validate the path

Real code, production intent, touches all layers and the pipeline. Evolve into the system core.
• Purpose: architecture and deployment validation.
• Implementation: minimal, tested, maintainable.
• Fate: evolve and iterate.
Prototype

Answer a question

Rapid, disposable experiments to test UI, algorithms, or unfamiliar APIs. Not production-ready.
• Purpose: focused feasibility or design feedback.
• Implementation: quick, low-maintenance, throwaway.
• Fate: discard and reimplement properly if useful.
Communication rule
Label experiments clearly, set expectations with stakeholders, and record the learning outcome so you avoid the prototype trap.
