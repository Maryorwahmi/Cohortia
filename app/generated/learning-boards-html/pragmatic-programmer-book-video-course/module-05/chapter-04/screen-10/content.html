Module 5 › Chapter 5.4 › The Prototype Trap and Technical Debt
Risk

Prototype trap

When prototypes are promoted to production, missing tests and quick hacks become long-term liabilities.
Symptoms
Fragile releases, frequent hotfixes, unclear ownership, and high change cost.
Safeguards
Label experiments, require reimplementation for production, and enforce minimal test coverage before promotion.
Practice

Convert lessons, not code

If a prototype proves useful, port its insight into a new, well-designed implementation with tests and documentation.
Pro Tip

Keep a short retro: capture what you learned from the prototype and list actions for a proper implementation if the idea is kept.
