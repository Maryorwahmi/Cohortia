Module 05 › Chapter 5.5 › Three-Point Estimation
Formula
The PERT weighted average uses optimistic (O), most likely (M), and pessimistic (P) values. It captures central tendency while accepting tails.
/* PERT formula */            PERT = (O + 4 * M + P) / 6            Example: O = 4, M = 6, P = 14            PERT = (4 + 4*6 + 14) / 6 = 42 / 6 = 7 hours
Key Takeaway

PERT produces a defensible estimate when you must combine uncertainty into one number; always list the assumptions behind O, M, and P.

Concrete Example
Task: Create API endpoint to fetch profile. O = 3 hours if data model exists; M = 5 hours for standard implementation; P = 8 hours if migration or data clean-up required. PERT = (3 + 4*5 + 8) / 6 = (3 + 20 + 8) / 6 = 31 / 6 ≈ 5.17 hours.
Misconception
PERT eliminates uncertainty.
Reality: it models uncertainty based on your inputs and assumptions.
