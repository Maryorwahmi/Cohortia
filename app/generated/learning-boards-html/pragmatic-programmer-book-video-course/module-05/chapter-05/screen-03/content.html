Demonstrating each objective

A short artifact for each objective proves you can use estimation as a planning and communication tool.

01 Evidence
Write a short note describing the cone of uncertainty and list one technical unknown for a proposed feature.
02 Evidence
Produce a Work Breakdown Structure with 5–7 tasks that separate UI, API, DB, validation, and tests.
03 Evidence
Run a mini planning poker round or supply PERT calculations for selected tasks; record assumptions.
04 Evidence
Share an updated estimate and the reason for the change, including any altered assumptions.
Quick Checklist
  • State assumptions explicitly.
  • Provide ranges or confidence levels, not single numbers.
  • Break tasks until each is estimable and testable.
  • Revisit estimates when new facts appear.
Producing these artifacts encourages transparent planning and trust with stakeholders.
