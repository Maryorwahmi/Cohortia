Module 5 › Chapter 5.3 › Configuration Over Code
Why it helps

Config allows the same build to behave differently across environments, enabling quick rollbacks and A/B settings without code changes.

Store endpoints and keys in environment variables or a config service.
Validate configuration on startup to fail fast on invalid settings.
Example
A config file declares the payment provider name. The app loads the provider and constructs the matching adapter at runtime. To switch providers, change the config and restart or reload the provider mapping.
Quick checklist
  • Keep config declarative and small.
  • Document who owns each config value.
  • Ensure config changes are auditable and reversible.
