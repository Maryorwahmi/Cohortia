Module 5 › Chapter 5.3 › Feature Flags (Feature Toggles)
Definition

Run-time control for features

A flag gates a feature by config so it can be enabled selectively in production without a code deploy.

Rollout pattern
  1. Deploy feature behind a flag with default off.
  2. Enable for internal team and automated tests.
  3. Enable for a small percentage of users and monitor metrics.
  4. Gradually increase exposure or disable if issues occur.
Example: Toggle a new checkout UI for 5% of users and observe conversion and error rate before full rollout.
Housekeeping

Track flag intent, owner, and removal date. Stale flags increase cognitive load and obscure code paths.

Pro-tip: Automate removal of flags when metrics show stability.
Pitfall: Too many long-lived flags make testing combinatorial and fragile.
