Module 5 › Chapter 5.3 › No irreversible decisions
Definition

Reversibility explained

Reversibility is the property of a design that allows you to change it later with predictable cost. It is not indecision; it is a defensive strategy that preserves options while you learn.

  • Helps you pivot when requirements change.
  • Reduces cost of future adaptations.
  • Beware: excessive indirection is still a risk.
Key Takeaway

Ask how hard reversing a decision will be in the medium term. If it is painful, add a small abstraction or rollback plan now.

Concrete example
Feature Flag rollout

Use a flag to expose a new UI to 5% of users, watch metrics, then increase exposure. If a defect appears, flip the flag and rollback instantly.

Misconception check

Delaying decisions is not the same as paralysis. You still make small, testable choices and learn quickly. Avoid adding abstractions without need.
