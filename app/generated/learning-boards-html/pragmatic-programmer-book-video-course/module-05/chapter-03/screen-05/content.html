Module 5 › Chapter 5.3 › Where decisions become irreversible

Common irreversible areas

Databases
Data migration and query rewrites make changing stores expensive.
Vendor APIs
Deep use of vendor features without an adapter creates lock-in.
File formats & protocols
Changing formats can break integration and require data conversion pipelines.

Risk classification

Estimate reversal cost: low, medium, high. Use this to decide whether to invest in an abstraction now.

Low cost
Swap UI components or small modules with minimal data changes.
High cost
Migrating a database with schema and data transformations.
Action

Inventory likely lock-in areas at project start and design small adapters or import/export plans for high-risk choices.
