Module 5 › Chapter 5.3 › Designing for Reversible Data Storage
Task summary

Implement an abstract UserPreferencesStore, a JsonFilePreferencesStore, a mocked MongoDbPreferencesStore, and a UserPreferencesService that accepts the store via dependency injection.

Requirements
  1. Define get_preferences and save_preferences on the interface.
  2. JsonFilePreferencesStore should read and write JSON files safely.
  3. Mocked MongoDbPreferencesStore simulates a database with an in-memory map.
  4. UserPreferencesService should call the store without knowing its type.
Starter code
from abc import ABC, abstractmethod
import json
import os

# 1. Define the abstract base class (interface)
class UserPreferencesStore(ABC):
    @abstractmethod
    def get_preferences(self, user_id: str) -> dict:
        pass

    @abstractmethod
    def save_preferences(self, user_id: str, preferences: dict):
        pass

# 2. Implement JsonFilePreferencesStore
class JsonFilePreferencesStore(UserPreferencesStore):
    def __init__(self, base_dir="data"):
        self.base_dir = base_dir
        os.makedirs(self.base_dir, exist_ok=True)

    def _get_filepath(self, user_id: str) -> str:
        return os.path.join(self.base_dir, f"{user_id}_prefs.json")

    def get_preferences(self, user_id: str) -> dict:
        filepath = self._get_filepath(user_id)
        if os.path.exists(filepath):
            with open(filepath, 'r') as f:
                return json.load(f)
        return {}

    def save_preferences(self, user_id: str, preferences: dict):
        filepath = self._get_filepath(user_id)
        with open(filepath, 'w') as f:
            json.dump(preferences, f, indent=4)
        print(f"Preferences for {user_id} saved to {filepath}")
