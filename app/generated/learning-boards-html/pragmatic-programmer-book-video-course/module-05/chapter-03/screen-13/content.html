Module 5 › Chapter 5.3 › Assessment Case Study
Scenario A

Choosing a front-end framework

Advice: build core logic and APIs independent of UI. If a framework is needed, contain framework-specific code in a small layer and prototype critical flows first.
Scenario B

Hardcoded loyalty rules

Advice: extract loyalty calculation to its own service or strategy objects, and make rules data-driven. Use flags to test new rule sets in production without redeploying core services.
Reflection

For each scenario, identify the minimal abstraction that isolates volatility and enables safe change. Document tests and rollback steps before you deploy.
