Process › Doc Triage
Triage checklist
  1. Catalog documents and last-updated dates.
  2. For each: is it accurate, useful, and maintainable?
  3. Decide: update, generate from code, or delete.
  4. Record authoritative source and link from other docs.
Integrate triage into pull requests and the definition of done to prevent rot.
Scenario
A six-month-old API guide lists deprecated endpoints. Triage actions: update the OpenAPI spec, remove the outdated guide, and add a redirect to the generated docs.
Exercise:
  • Pick a doc, run the checklist, and record your decision.
  • If updating, make the change in the same commit as the code change.
