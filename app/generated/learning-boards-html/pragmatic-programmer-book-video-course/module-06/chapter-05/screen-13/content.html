Warning › Documentation Rot
Symptoms & causes
  • Outdated examples or parameter lists.
  • Contradictory comments vs. code behavior.
  • Duplication across multiple documents.
Recovery steps
  1. Run triage and prioritize risky inaccuracies.
  2. Consolidate facts into an authoritative source and link others to it.
  3. Add tests or validation to prevent future drift.
Action

Start by fixing the documentation that, if incorrect, would cause a bug or broken integration for users. Use that fix to introduce a small validation test.
