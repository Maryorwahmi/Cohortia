# Factorial API

A simple Flask API that calculates the factorial of a given non-negative integer.

## Setup
1. pip install Flask flasgger

## Run
python app.py

## Example
curl http://127.0.0.1:5000/factorial/5  # expected: {"number":5, "factorial":120}
