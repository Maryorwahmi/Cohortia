Skills you will practice
Hands-on habits that keep documentation accurate and lightweight.
Docstrings that explain why
Write concise docstrings for intent, constraints, and edge cases that cannot be deduced from the code alone.
Minimal README
Provide setup, run, test commands, and example requests so a new developer is productive in minutes.
OpenAPI-driven API docs
Generate interactive docs from a machine-readable specification to create living documentation.
Doc triage
Decide whether to keep, refactor, generate, or delete documents based on their ongoing value.
