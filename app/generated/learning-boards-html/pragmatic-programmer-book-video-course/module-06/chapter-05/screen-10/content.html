What are executable specs?
Human-readable specifications that are also runnable as automated tests. They document expected behavior and validate implementation at the same time.
- Useful for business rules and API behaviors.
- Prevents documentation rot by associating docs with failing tests.
Practical tip
Start with the most critical user flow or a bug-prone behavior and write one executable scenario that captures the expected outcome.
Exercise:
  1. Choose a critical behavior or previously broken case.
  2. Write a short, human-readable scenario that asserts the behavior.
  3. Run the scenario as a test; update either the code or the scenario until both agree.
