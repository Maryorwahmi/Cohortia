Module 6 › Chapter 6.4 › API Integration Case
Scenario

Third-party API causes delay

Work through identification, impact assessment, options, and communication.

Identify early
Acknowledge the complexity and estimate the new effort.
Assess impact
Quantify timeline shift and which features are affected.
Formulate options
Extend release; defer a feature; try an alternative API.
Communicate
Share the facts, the options, a recommendation, and request input.
Key Takeaway

Present the problem early with choices; avoid overtime as the default remedy.

Prepared message example

"We've hit an unexpected challenge integrating X API; integration time is now estimated at 10–12 days. Impact: release date at risk. Options: 1) extend release by 5 days; 2) defer Feature Z; 3) investigate a simpler API for 2 days. We recommend Option 2 to keep the delivery date while minimizing risk. We request your approval to defer Feature Z."

Decision checklist
State the new estimate, the impact, present options, give recommendation, and ask for a decision or further input.
