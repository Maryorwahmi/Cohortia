Module 6 › Chapter 6.4 › Assessment: Pragmatic Choices
Assessment Idea

Choose pragmatic responses

Evaluate options that balance quick action, transparency, and stakeholder involvement.

Scenario 1
Stakeholder requests a large new feature at mid-project. Best initial action: acknowledge, explain impact, and start a change request/prioritization.
Scenario 2
Critical bug affects small user set but corrupts data. Best action: fix immediately and notify sponsor and affected users with a clear explanation.
Key Takeaway

Pragmatic responses act quickly when necessary, explain impacts, and invite stakeholder decisions where appropriate.

Example exam question

"A stakeholder asks for a major feature mid-sprint. The most pragmatic initial response is to acknowledge, explain potential impacts, and start a formal evaluation process."

Explanation
This response shows responsiveness while preventing uncontrolled scope changes and preserving team commitments.
