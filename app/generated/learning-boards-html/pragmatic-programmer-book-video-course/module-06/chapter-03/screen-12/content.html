Estimate breakdown (story points)

Decompose before sizing to reveal hidden tasks and risks.

# API endpoint estimate (example)
Setup route & controller: 2 pts
DB interaction (read/write): 3 pts
Error handling & logging: 1 pt
Auth/Authorization integration: 2 pts
Unit & integration tests: 3 pts
Documentation & API spec update: 1 pt
Total: 12 story points

Note: Main risk is the new authentication module. Consider a 1-day spike to verify integration approach.
Communication sample

"This looks like ~12 points. Our team does 10–15 points/week, so expect about one week. Authentication is the key unknown; it could stretch to 1.5 weeks unless we spike."

Reflection

Compare this breakdown to a single-point estimate. Notice how tests, docs, and error handling add effort that is often overlooked.

Key Takeaway

Breakdown exposes real work. Use velocity and stated risks to translate points into a defensible delivery window.
