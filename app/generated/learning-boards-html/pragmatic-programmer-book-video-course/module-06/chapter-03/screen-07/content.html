Process Flow

Time-box a spike to learn fast

Define a short experiment with clear questions and a fixed duration. Use findings to update the estimate for the real work.

When to spike

Unknown integrations, unfamiliar tech, or unclear data shapes.

Keep it tight

Set success criteria and a maximum time-box to prevent scope creep.

Example spike

Goal: Confirm payment gateway supports required webhooks. Time-box: 1 day. Success: receive and parse a sample webhook and document expected retries. Outcome: estimate for integration narrows from 5–13 points to 3–5 points.

Key Takeaway

A short spike reduces unknowns and produces a more defensible estimate for the real work.
