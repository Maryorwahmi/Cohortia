Module 6 › Chapter 6.1 › Activity: Recipe App
Activity steps
  1. Identify 3 user types: Home Cook, Professional Chef, Dietary Planner.
  2. For each user, list two features (eg. add recipe, search, categorize).
  3. Write user stories in the "As a..., I want..., so that..." format.
  4. Define at least 3 acceptance criteria per story and perform teach-back.
Example starter for Home Cook
// User Story
As a Home Cook, I want to add a new recipe to my collection so that I can easily find and use it later.

Acceptance Criteria:
1. The system allows input of recipe name, ingredients, and instructions.
2. The recipe name must be non-empty before saving.
3. The user may optionally upload an image and the save redirects to the recipe detail page.
Use this example as a template for other user types and features. After drafting, role-play the stakeholder to validate each story’s assumptions.
