Learning Objectives
Learn → Understand → Apply → Master
01
Articulate the Big Picture

Explain the business value and user problem the project solves. This helps prioritize features and avoid wasted development.

VERIFIED COMPETENCY MILESTONE
02
Elicit and Analyze Requirements

Use interviews, observation, and prototypes to discover needs that stakeholders may not state directly. Results should guide initial scope.

VERIFIED COMPETENCY MILESTONE
03
Document with User Stories

Capture functional requirements as user stories with clear acceptance criteria for implementation and testing.

VERIFIED COMPETENCY MILESTONE
04
Manage Scope and Change

Evaluate new requests against objectives, document trade-offs, and use a clear change process to prevent scope creep.
