Module 6 › Chapter 6.2 › Minimum Viable Feature
Definition

What makes a feature minimal and viable?

Focus on delivering observable user value, not completing internal components.

Checklist for MVF
  • End-to-end user capability exists.
  • Has acceptance criteria and basic tests.
  • Delivers measurable value or learning.
Key Takeaway

Pick increments that produce real user interactions and measurable feedback, not just internal progress.

Concrete example: add-to-cart

Add-to-cart lets users express purchase intent and lets the team validate whether the cart model meets user expectations. It’s a minimal, shippable experience.

Common mistake

Treating a backend API or internal component as an MVF when it does not provide direct user value will delay feedback and increase risk.

Practical tip: write a single acceptance test that demonstrates the MVF in action before coding.
