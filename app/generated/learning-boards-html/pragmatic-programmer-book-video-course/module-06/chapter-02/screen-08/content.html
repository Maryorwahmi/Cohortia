Module 6 › Chapter 6.2 › Decompose Feature
Activity

Plan four shippable increments

Define the tangible functionality and the value for each increment and identify the acceptance test that proves it.

Increment goals
  • View profile: username, placeholder avatar, bio.
  • Edit basic info: change username and bio with validation.
  • Upload picture: replace placeholder with validated image.
  • Privacy settings: control field visibility.
Example acceptance test

When a user updates the bio and saves, the profile view displays the new bio immediately.

Starter plan (commented outline)
// Main Feature: User Profile Management

// Increment 1: Basic Profile Viewing
// Functionality:
// - User can view their own profile page.
// - Profile displays username, profile picture (placeholder if none), and a short bio (placeholder if none).
// - No editing capabilities yet.
// Value: Users can see their public identity on the platform.

// Increment 2: Editing Basic Profile Information
// Functionality:
// - User can edit their username and short bio.
// - Changes are saved and immediately reflected on their profile page.
// - Basic input validation (e.g., username not empty).
// Value: Users can personalize their profile.

// Increment 3: Profile Picture Upload
// Functionality:
// - User can upload a profile picture from their device.
// - The uploaded image replaces the placeholder.
// - Basic image validation (e.g., file type, size).
// Value: Users have a stronger visual identity.

// Increment 4: Privacy Settings for Profile
// Functionality:
// - User can set visibility for certain profile fields (e.g., bio visible to "Friends Only", "Public").
// - These settings affect how other users view their profile.
// Value: Users control their personal data visibility.
Key Takeaway

Write a small acceptance test per increment to define when it is done and to enable fast feedback.
