Module 6 › Chapter 6.2 › Iteration Cycle
Process Flow

Plan → Build → Test → Deploy → Learn

A repeatable rhythm that creates a tested increment and feeds learning back into planning.

Planning

Choose a small scope with clear acceptance criteria and a testable outcome.

Build & Test

Implement the slice and add automated tests so the increment is verifiable.

Deploy & Learn

Release the increment and gather user feedback to refine the next iteration.

Concrete example: profile view increment
  • Plan: view-only profile with username and placeholder avatar.
  • Build: implement UI and read-only API endpoint.
  • Test: automated unit test for API and visual smoke test.
  • Deploy: make it available and ask users to view their profile.
Misconception

Short cycles do not remove responsibility for good design; they encourage emergent design through continuous refinement, not design chaos.

Try a practice: set one acceptance test that defines when the increment is done.
