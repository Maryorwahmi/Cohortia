Module 2 › Chapter 2.3 › Assessment: Two scenario questions
Scenario 1 — Firebase tied into business logic
Risk: vendor lock-in. Mitigation: introduce IAuthService and implement FirebaseAuthService as an adapter. Change composition only.
Tests: unit tests for IAuthService contract and adapter integration tests that mock Firebase responses.
Scenario 2 — Proprietary analytics pipeline
Risk: closed data format. Mitigation: isolate ingestion behind an AnalyticsService and ensure event exports into JSON or CSV. Estimate cost of reprocessing events for migration.
Tests: export/import tests verifying data parity and a small migration rehearsal in a staging environment.

Think of a past project where vendor lock-in created work later. How would you refactor it now, using an interface and an export plan?
