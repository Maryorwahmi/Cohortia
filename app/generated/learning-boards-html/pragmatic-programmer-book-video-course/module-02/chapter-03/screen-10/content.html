Module 2 › Chapter 2.3 › Hands-on: Refactor Storage
Starter problem
UserManager creates AWSS3Storage itself. That spreads vendor coupling into business code, raising migration cost.
Refactor plan
  1. Create IFileStorage ABC with upload_file and download_file.
  2. Make AWSS3Storage inherit IFileStorage.
  3. Add LocalFileStorage implementing the same interface for dev and tests.
  4. Change UserManager to accept an IFileStorage instance in its constructor.
Misconception
This is not over-engineering if applied to high-impact boundaries like core storage or auth systems.
Code snapshot
# storage_interfaces.py
import abc

class IFileStorage(abc.ABC):
  @abc.abstractmethod
  def upload_file(self, file_content: bytes, filename: str) -> str:
    pass

  @abc.abstractmethod
  def download_file(self, filename: str) -> bytes:
    pass

# app.py (refactored snippet)
class AWSS3Storage(IFileStorage):
  def __init__(self, bucket_name):
    self.bucket_name = bucket_name

  def upload_file(self, file_content: bytes, filename: str) -> str:
    # Simulate upload
    return f"s3://{self.bucket_name}/{filename}"

class LocalFileStorage(IFileStorage):
  def __init__(self, base_dir='./local_storage'):
    self.base_dir = base_dir

  def upload_file(self, file_content: bytes, filename: str) -> str:
    # Simulate local write
    return f"{self.base_dir}/{filename}"

class UserManager:
  def __init__(self, storage_service: IFileStorage):
    self.storage = storage_service

  def upload_user_avatar(self, user_id: str, avatar_data: bytes, filename: str):
    path = f"avatars/{user_id}/{filename}"
    return self.storage.upload_file(avatar_data, path)
Key Takeaway

Decoupling composition from usage is the simplest path to reversible choices in code.
