Abstraction — step-by-step
1
Identify the boundary
Find where business logic touches vendor APIs: storage, auth, queues.
2
Define a small interface
Limit methods to what business code needs, e.g., upload_file, download_file.
3
Implement adapters
Create concrete classes for each vendor and a local stub for testing.
4
Inject the implementation
Use configuration or dependency injection so swapping is a single change.
Example
UserManager depends on IFileStorage. Both AWSS3Storage and LocalFileStorage implement that interface. Changing storage requires only swapping the instance passed to UserManager.
Implementation snapshot
class IFileStorage:
  def upload_file(self, file_content: bytes, filename: str) -> str: ...
  def download_file(self, filename: str) -> bytes: ...

class UserManager:
  def __init__(self, storage_service: IFileStorage):
    self.storage = storage_service

  def upload_user_avatar(self, user_id, avatar_data, filename):
    path = f"avatars/{user_id}/{filename}"
    return self.storage.upload_file(avatar_data, path)
Key Takeaway

Small, focused interfaces plus adapter implementations buy the option to switch providers cheaply.
