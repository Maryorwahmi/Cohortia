Process Code Archaeology and Audits
Practical tools and routines to keep a codebase lean
Tools & Signals
  • Search and symbol analysis to find unreferenced code.
  • Coverage reports to spot untested code.
  • Static analysis for dead exports and unreachable branches.
  • Telemetry and logs to identify unused features.
Small Audit Recipe
90-minute pass: mark, test-delete, run CI, document.
Team Practices
Small deletions, clear commit messages, and team communication reduce fear and make cleaning routine.
Key Takeaway

Frequent small audits beat infrequent big cleanups for safety and momentum.
