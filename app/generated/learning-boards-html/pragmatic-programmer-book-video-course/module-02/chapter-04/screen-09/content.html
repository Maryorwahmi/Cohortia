Refactoring Strategy Delete, Don't Comment
Why removing irrelevant code is safer and how to do it confidently
Practical Steps
  • Identify candidate code with coverage or search.
  • Run tests and static checks locally.
  • Delete the code in a short-lived branch.
  • Run full CI and smoke tests before merging.
  • Use VCS history to recover if needed.
Emotional Barrier
Attachment and fear of losing clever code slow deletions. Use data and clear commit messages to justify removals.
Key Takeaway

Deleting unused code reduces complexity and is low risk when version control is available.
