What to Remember
Six short prompts to guide daily decisions.
Measure Value
Will this feature deliver measurable user value now?
Profile First
Is optimization supported by profiling data?
Defer Abstractions
Can abstraction wait until there are multiple, concrete users?
Check Usage
Does telemetry or logs show real usage of this code?
Delete Safely
Can deletion be verified with tests and CI and recovered via VCS if needed?
Final Takeaway

Use short prompts during reviews to choose pragmatic work, reduce technical debt, and keep teams focused on present value.
