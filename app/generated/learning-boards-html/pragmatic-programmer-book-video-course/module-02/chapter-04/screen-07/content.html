Core Principle YAGNI
You Ain't Gonna Need It
Avoid speculative features until evidence justifies them.
Example
Building integrations for multiple message queues when only one is currently required increases testing, dependencies, and complexity.
When to defer
If no current user needs the feature, postpone it.
Low-cost alternative
Document expected extension points; design small APIs that can be extended later.
Misconception
YAGNI is not laziness. It is strategic restraint to prioritize present value.
