Module 2 › Chapter 2.1 › Testing
Checklist
Tests to protect refactors
Email tests
Valid example, missing '@', missing domain, and at least one edge case that matters for your product.
Password tests
Minimum length, contains digit, empty value, and optional policies like special character requirements.
Integration tests
Simulate POST requests to the register and update endpoints to confirm responses and status codes remain unchanged.
Pro tip
Run tests locally and in CI to ensure that future changes to validators are caught automatically.
Quick test example
def test_valid_email():
  assert is_valid_email('user@example.com') is True

def test_invalid_email():
  assert is_valid_email('useratexample') is False
