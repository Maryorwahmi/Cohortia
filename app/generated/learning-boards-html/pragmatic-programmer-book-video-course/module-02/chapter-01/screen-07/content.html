Module 2 › Chapter 2.1 › Refactoring Workflow
Process
  1. Detect duplication using search and clone tools.
  2. Add tests that capture existing behavior.
  3. Extract the logic into a single, well-named module.
  4. Replace callers incrementally and run tests after each change.
  5. Parameterize differences rather than over-abstracting.
Example
Extract a password-check function used in registration and profile update routes, run tests, then replace both locations with the shared call.
Common mistake
Overcomplicating the extracted module. Keep the API minimal and clear. If it becomes complex, split responsibilities instead of creating a monster abstraction.
Check your understanding
After extraction, do tests pass? If not, examine differences in callers; those differences may need parameterization instead of full consolidation.
