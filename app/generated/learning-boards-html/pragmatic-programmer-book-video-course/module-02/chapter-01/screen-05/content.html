Module 2 › Chapter 2.1 › Code vs Data vs Knowledge
Comparison
How duplication types differ
Code duplication
Same or similar blocks. Fix by extracting functions, classes, or packages.
Data duplication
Same data stored in multiple locations. Fix with normalization and references to a single table or service.
Knowledge duplication
Business rules implemented in multiple places. Fix by centralizing logic into a single module or service.
Example
Email validation in three handlers is code duplication; storing address in two tables is data duplication; computing discounts in two services is knowledge duplication.
When to act
Prioritize refactors where a change in rules would require updates in multiple places. That signals knowledge or data duplication with high maintenance cost.
Common mistake
Rushing to abstract every repetition. Abstraction carries complexity; refactor gradually after demonstrating the need.
Check your understanding
Ask: If the rule changes, where will I need to edit? That question reveals the type and priority of duplication.
