Practice & Consequences
Techniques and the long-term costs of duplication.
01
Extract reusable functions
Move repeated logic into a named function with parameters to handle differences. VERIFIED COMPETENCY MILESTONE
02
Create a domain service
Encapsulate business rules in a service so all callers use the authoritative logic. VERIFIED COMPETENCY MILESTONE
03
Normalize data
Store information once and use references to avoid inconsistent records. VERIFIED COMPETENCY MILESTONE
04
Avoid premature abstraction
Iterate small refactors and keep code readable rather than forcing a generic solution too soon. VERIFIED COMPETENCY MILESTONE
Mnemonic
Think 'knowledge, not repetition' — refactor when the repeated item carries intent that could change.
