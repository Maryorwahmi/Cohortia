Orthogonality and Decoupling
Design systems so components are independent, predictable, and easy to change. This reduces bugs and makes features easier to extend.
In this lesson
Define orthogonality, contrast coupling and cohesion, and practice refactoring concrete code into interface-driven components that are testable and swappable.
Coming up
A step-by-step refactor of a ReportGenerator to accept abstract data loaders and formatters.
Why it matters
Orthogonal components let you change implementations, run isolated tests, and reason about behavior without surprise dependencies.
