Module 2 › Chapter 2.2 › Decoupling Workflow
Step-by-step
  1. Write a test that exercises current behavior to lock expected output.
  2. Create IDataLoader and IReporter abstractions in a new file.
  3. Modify concrete loaders and reporters to implement their interfaces.
  4. Change ReportGenerator to accept abstractions via its constructor.
  5. Compose concrete instances in main and run tests after each change.
Example test idea
Construct ReportGenerator with a fake data loader that returns two users. Assert that the reporter receives the expected list without performing file IO.
Optional challenge
Add a JSON loader and an HTML reporter that implement the interfaces and show swapping them without editing ReportGenerator.
