Practice & Assessment Objectives
Translate principles into measurable refactors and tests.
01
Identify Coupling Smells
Spot classes or functions that cause frequent, global changes.
Mnemonic: ripple test

Improve Testability
Write unit tests that avoid IO by using abstract dependencies.
Mnemonic: mockable pieces
VERIFIED COMPETENCY MILESTONE
03
Refactor Safely
Use small, reversible steps and tests to guard behavior while changing structure.
Mnemonic: small jumps
VERIFIED COMPETENCY MILESTONE
04
Use Patterns to Encapsulate Variation
Select Strategy, Command, or Observer to keep behavior decoupled from orchestration.
Mnemonic: swap without edit
VERIFIED COMPETENCY MILESTONE
Quick practice
Take a small class from your codebase and ask: What single responsibility can I extract? What interface would let me swap its dependency?
Outcome
You will be able to plan and execute a minimal refactor that introduces a stable abstraction and preserves behavior through tests.
