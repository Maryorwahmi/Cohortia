Module 2 › Chapter 2.2 › Key Concepts
Orthogonality
Independent modules with stable contracts so changes stay local.
Coupling & Cohesion
Aim for low coupling between modules and high cohesion within them.
Dependency Inversion
Depend on abstractions, inject implementations at composition time.
Summary Takeaway

When design lets you swap implementations and write isolated tests, you have achieved orthogonality. Use small, test-backed refactors to get there.
