Module 3 › Chapter 2.5 › Learning Objectives

Skills you'll apply

  • Type hints: annotate parameters and returns so expected types act as lightweight contracts.
  • Assertions: add precondition and invariant checks that fail fast during development.
  • Tests from contracts: write unit tests that validate both correct outcomes and contract violations.
Quick mapping
Contracts → Code: assertions and type hints. Contracts → Tests: positive and negative cases. Contracts → Docs: readable guarantees for callers.
