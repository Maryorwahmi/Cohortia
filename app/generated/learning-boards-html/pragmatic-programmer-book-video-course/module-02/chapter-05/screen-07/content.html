Object integrity

What invariants do

They keep the object's internal model consistent across operations, enabling safer assumptions by callers and clearer tests for implementers.

Example
For Wallet, invariant: balance >= 0. Check after constructor and after public methods that might change balance.
Best practices
  • Assert invariants at object creation and at the end of public methods.
  • Allow temporary internal invariant violations but re-establish them before returning.
  • Document invariants so tests can assert them explicitly.
Key Takeaway

Invariants reduce error surface by keeping an object's essential properties consistent across operations.
