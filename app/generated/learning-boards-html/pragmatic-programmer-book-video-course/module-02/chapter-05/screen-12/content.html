Module 3 › Chapter 2.5 › Testing contracts
Contract → Test mapping
  • Preconditions: negative tests that expect assertion or exception.
  • Postconditions: assert outcome and state changes.
  • Invariants: assert after operation sequences.
Example test snippets
def test_deposit_increases_balance():
  w = Wallet(100)
  w.deposit(50)
  assert w.get_balance() == 150

def test_withdraw_insufficient_funds_asserts():
  w = Wallet(50)
  with pytest.raises(AssertionError):
    w.withdraw(150)
Key Takeaway

Treat contract tests as executable documentation: they confirm both correct outcomes and correct failure modes.
