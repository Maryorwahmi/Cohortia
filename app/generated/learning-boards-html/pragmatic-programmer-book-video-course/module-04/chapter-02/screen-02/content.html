Learning Objectives
Learn, Understand, Apply, Master
Bloom: Learn → Understand → Apply → Master
01
Explain importance
State how automation improves consistency and lowers errors. Example: automated tests reduce last-minute bug discovery.
Verified competency milestone
02
Differentiate tools
Recognize when Make, npm scripts, or Gradle/Maven are appropriate. Example: small C projects vs. large Java apps.
Verified competency milestone
03
Create basic scripts
Author a Makefile or package.json scripts to compile, test or bundle. Example: a build and a clean target.
Verified competency milestone
04
Integrate into workflow
Use scripts to speed feedback loops and reduce environment problems. Example: run tests on every push or locally before commit.
Verified competency milestone
