Module 4 › Chapter 4.2 › Monorepo Build Orchestration
Using a tool
Example: lerna run build orchestrates package builds and may add caching and parallelism when configured.
Shell loop alternative
A minimal root-level npm script can run: for d in packages/*; do (cd "$d" && npm run build); done — this runs each package's declared build.
Assessment prompt
Write the root-level script you would add, explain why it avoids duplication, and mention how you would handle failures or caching.
