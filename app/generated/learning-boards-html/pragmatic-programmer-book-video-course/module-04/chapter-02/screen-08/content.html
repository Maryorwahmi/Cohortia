package.json (scripts)
{
  "scripts": {
    "start": "node app.js",
    "test": "node test.js",
    "build": "echo 'Simulating build process...'"
  }
}
Run npm start to see the app message, npm test to run the assertion, and npm run build to simulate a build step. Chain commands: "lint && npm test && npm run build" for a single pipeline.
