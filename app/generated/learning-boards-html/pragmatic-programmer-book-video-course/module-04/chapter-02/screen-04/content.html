Module 4 › Chapter 4.2 › What is Build Automation?
Definition
Automating compilation, tests, and packaging
  • Common tasks: compile, lint, test, package, minify, generate docs.
  • Property: idempotence — re-running should not cause harm.
  • Benefit: consistent outputs regardless of developer or machine.
Key Takeaway

Automate routine steps to reduce errors and speed feedback.

Analogy
A recipe vs. cooking by memory
A build script is a recipe: it documents ingredients, order, and expected result. Relying on memory leads to inconsistent dishes; scripts produce the same output every time.
