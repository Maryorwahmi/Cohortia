Module 4 › Chapter 4.2 › Makefiles: Targets & Dependencies
Core Concept
Targets, dependencies, timestamps

Target: the file or action make must produce.

Dependency: a prerequisite file; if it's newer, the target is rebuilt.

Commands: shell steps that create the target from dependencies.

Key Takeaway

Correct dependency declarations make builds fast by avoiding unnecessary work.

Example Makefile
# Makefile
CC = gcc
CFLAGS = -Wall -g

TARGET = my_program

all: $(TARGET)

$(TARGET): main.o utils.o
	$(CC) $(CFLAGS) -o $(TARGET) main.o utils.o

main.o: main.c
	$(CC) $(CFLAGS) -c main.c

utils.o: utils.c
	$(CC) $(CFLAGS) -c utils.c

clean:
	rm -f $(TARGET) *.o
	@echo "Cleaned up build artifacts."

.PHONY: all clean
Try changing main.c and run make. Only main.o and the final link step should run, demonstrating timestamp-based decisions.
