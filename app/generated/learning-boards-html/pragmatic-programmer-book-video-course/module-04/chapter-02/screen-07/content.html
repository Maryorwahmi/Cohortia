Module 4 › Chapter 4.2 › npm Scripts
Definition
Lightweight scripts in package.json

Scripts map short names to shell commands and are run via npm run <name>.

They are useful for dev servers, tests, builds, and simple orchestration.

Chaining with && allows sequential commands in a single script.

Example package.json
{
  "name": "my-node-app",
  "version": "1.0.0",
  "main": "app.js",
  "scripts": {
    "start": "node app.js",
    "test": "node test.js",
    "build": "echo 'Simulating build process...'"
  }
}
Run npm start, npm test, and npm run build. Use && to chain steps like lint && test && build for a single command pipeline.
