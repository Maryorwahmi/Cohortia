Common commands
$ git clone 
$ git push origin feature/subtract
$ git pull origin main
Remember: origin is an alias for the remote you cloned from. Pushing publishes your branch so others can fetch it.
Example workflow

Clone, branch, implement a feature, push the branch, then open a pull request or request a review so others can merge the change after verification.

Warning

Avoid force pushing to shared branches unless you have explicit team agreement, as it can overwrite others' commits.
