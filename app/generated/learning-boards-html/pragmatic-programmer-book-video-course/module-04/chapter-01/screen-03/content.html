Commands to master
git init — create a local repository
git add — stage changes selectively
git commit -m "..." — save a snapshot with a message
git log, git status — inspect history and state
Practice note: compose messages that explain both what and why. Use feature branches for isolation and prefer small commits that describe a single logical change.
Practice checklist
  1. Init a repo and commit an initial file.
  2. Create a feature branch and implement a change.
  3. Merge the feature and resolve any conflict.
