Module 4 › Chapter 4.1 › Destructive Commands
Examples and impact
# Discard last two commits locally
$ git reset --hard HEAD~2

# Force-push rewritten history (dangerous on shared branches)
$ git push --force origin feature/branch
If you have already pushed commits and then reset them locally, pushing with --force will remove those commits for everyone who relies on them. Coordinate before rewriting public history.
Safer alternatives
  • Use git revert to undo changes in a way that preserves history.
  • Use git push --force-with-lease to avoid clobbering recent remote changes unintentionally.
Pro tip

Before destructive operations, create a backup branch: git branch backup-before-reset.
