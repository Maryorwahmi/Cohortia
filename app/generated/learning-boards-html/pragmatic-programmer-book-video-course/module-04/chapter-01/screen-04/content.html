Module 4 › Chapter 4.1 › What is a Version Control System?
Definition

A VCS records changes to files over time, storing snapshots and metadata so you can revisit any version.

Why it matters: revert broken changes quickly.
Why it scales: track authors and timestamps for accountability.
Practical example
If a recent commit introduces a regression, you can inspect the commit, view its changes, and either revert or correct the code. That single action can save hours of debugging and lost context.
Distributed vs Centralized
  • Centralized stores one server copy; Git gives each developer a full repository copy.
  • Git enables offline work and robust branching because history exists locally.
Key Takeaway

Version control is not optional. It converts change into a manageable, reviewable history that supports collaboration.
