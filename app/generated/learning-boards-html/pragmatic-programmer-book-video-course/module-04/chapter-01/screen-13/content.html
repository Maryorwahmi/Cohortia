Assessment question example
Question: You've made two commits that introduced a bug. You want to discard them and return to the state before those commits. Which command do you use and why is it dangerous?
Expected answer
Use git reset --hard HEAD~2. Danger: it discards working changes and rewrites history; if those commits were pushed, you risk overwriting others' work.
Practical tasks
  1. Init a repo and make three commits. Use reset to remove two and observe the log.
  2. Create conflicting edits on two branches and resolve the merge using an editor.
Key Takeaway

Good assessment pairs command accuracy with an explanation of safety and collaboration impact.
