Terminal walkthrough
$ git status
On branch main
Untracked files:
  (use "git add ..." to include in what will be committed)
    calculator.js

$ git add calculator.js
$ git commit -m "feat: implement add function"
[main 1a2b3c4] feat: implement add function
 1 file changed, 8 insertions(+)
Commit messages are change documentation. Prefer context like "feat: implement subtract to support negative results" over vague text such as "work".
Example: calculator
Start with add, commit it clearly, then add subtract in a separate commit so each feature is easy to understand and revert if needed.
Common mistake

Committing too much unrelated work in one commit will make debugging and history navigation harder.
