How to practice
  • Initialize a repo and make a small, meaningful commit with a clear message.
  • Create a feature branch for a change and merge via a review process.
  • Simulate a conflict by editing the same line on two branches to practice resolution.
These objectives prepare you for hands-on terminal demos and the calculator example in the chapter.
