What happens on conflict
Git inserts conflict markers in the file showing both versions. You must edit to choose the correct content, remove markers, then stage and commit the resolution.
<<<<<< HEAD
console.log("Adding 5 and 3:", add(5, 3));
======
console.log("Adding five and three:", add(5, 3));
>>>>>> feature/change-logging
Resolution steps
  1. Edit the file to choose or combine changes.
  2. git add the resolved file.
  3. git commit to finalize the merge.
Key Takeaway

Conflicts need judgment. Resolve deliberately and test to ensure combined behavior is correct.
