Module 4 › Chapter 4.1 › Initializing a Repository
Command demo
$ mkdir my-calculator
$ cd my-calculator
$ git init
Initialized empty Git repository in /path/to/my-calculator/.git/
After init, .git becomes the repository. Do not manually edit files inside .git unless you deeply understand Git internals.
What .git stores
  • Commits and object database that represent snapshots.
  • Refs like branches and tags pointing to commits.
  • Configuration and hooks used by Git commands.
Common mistake

Deleting .git or copying files without .git loses history. Keep backups before destructive operations.
