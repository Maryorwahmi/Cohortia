Editor terminal uses
  • Run quick scripts like node index.js or npm scripts.
  • Run test suites and linters without changing windows.
  • Keep multiple named terminal tabs for different tasks.
Try this
Open the integrated terminal, run the project's start script, and observe output while editing. Use editor tasks to bind lint and format commands to the command palette.
Key Takeaway

The integrated terminal keeps you in a single context and reduces disruption between coding and running commands.
