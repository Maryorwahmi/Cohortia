Module 4 › Chapter 4.5 › Hands-on Setup
Commands to run
npm init -y
npm install --save-dev eslint prettier

# package.json scripts (example)
"scripts": {
  "lint": "eslint .",
  "format": "prettier --write ."
}

# VS Code settings.json snippets
{
  "editor.formatOnSave": true,
  "editor.defaultFormatter": "esbenp.prettier-vscode"
}
Practical notes
  • Install extensions for Prettier and ESLint in your editor.
  • Prefer project-level config files to maintain consistency.
  • Enable format-on-save to reduce manual formatting steps.
Key Takeaway

Repository-level formatter and linter configuration ensure consistent code style and early warnings across the team.
