Module 4 › Chapter 4.5 › Extensions & Plugins
What to install
  • Formatter (Prettier) and linter (ESLint).
  • Language Server for your primary languages.
  • Debugger adapters and Git integrations.
Tip: prefer extensions that integrate with your project's configuration files so behavior is consistent across contributors.
Safety checks
  • Check publisher reputation and update frequency.
  • Test an extension in a sandbox workspace before enabling globally.
  • Document required extensions in project README for teammates.
Key Takeaway

Extensions are powerful but should be curated for performance, security, and team consistency.
