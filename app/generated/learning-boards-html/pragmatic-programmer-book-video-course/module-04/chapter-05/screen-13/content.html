Debug steps
  1. Set breakpoint on discount calculation line.
  2. Run debugger and step into the function to inspect values.
  3. Use conditional breakpoints for specific values like 15.
  4. Apply fix, then re-run to confirm results.
Refactor: rename the 'disc' variable to 'additionalDiscount' via Rename Symbol. Inspect the preview and run the script to ensure behavior is unchanged.
Checks before commit
  • Run format and lint scripts.
  • Run the script or tests in the integrated terminal.
  • Review the git diff to ensure only intended changes are staged.
Key Takeaway

Combine the debugger to find the cause with safe refactors and automated checks to make the fix robust and reviewable.
