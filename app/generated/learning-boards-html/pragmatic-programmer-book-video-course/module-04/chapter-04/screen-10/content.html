create_project.sh

#!/bin/bash

# Safety: Exit on error, treat unset variables as error, pipefail
set -euo pipefail

PROJECT_NAME=$1

# Check if project name is provided
if [ -z "$PROJECT_NAME" ]; then
  echo "Usage: $0 "
  exit 1
fi

# Check if directory already exists
if [ -d "$PROJECT_NAME" ]; then
  read -p "Directory '$PROJECT_NAME' already exists. Overwrite? (y/N): " CONFIRMATION
  if [[ ! "$CONFIRMATION" =~ ^[yY]$ ]]; then
    echo "Operation cancelled."
    exit 0
  fi
  echo "Removing existing directory '$PROJECT_NAME'..."
  rm -rf "$PROJECT_NAME"
fi

echo "Creating project structure for '$PROJECT_NAME'..."

mkdir "$PROJECT_NAME"
cd "$PROJECT_NAME"

mkdir src
touch README.md

echo "# $PROJECT_NAME" > README.md
echo "" >> README.md
echo "This is a new project created by the project setup script." >> README.md

echo "Project '$PROJECT_NAME' created successfully!"
ls -R
Explanation
This script demonstrates argument validation, an interactive overwrite confirmation, and simple file creation commands useful for scaffolding.
Safety note
The script uses rm -rf after confirmation. Test on a dummy folder first to avoid accidental deletion of real work.
Try this
Run the script with a test name, then run it again to trigger the overwrite prompt and verify the confirmation logic works as intended.
