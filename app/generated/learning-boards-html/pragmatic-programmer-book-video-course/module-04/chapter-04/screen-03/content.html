Module 4 › Chapter 4.4 › Learning Objectives
Bloom → Learn
Spot repetition

Describe a repeated routine you do and why automation reduces cognitive load. Milestone: a short note explaining the automation benefit.

Bloom → Understand
Identify scenarios

List at least two development tasks—deploy, setup, logs—that could be automated. Milestone: a short plan listing commands to run.

Bloom → Apply
Write scripts

Create a script that accepts an argument, validates it, and performs a small action. Milestone: run without errors on test data.

Bloom → Master
Harden scripts

Apply set -euo pipefail, quote variables, and add checks. Milestone: script fails fast and prints clear error messages when used incorrectly.
