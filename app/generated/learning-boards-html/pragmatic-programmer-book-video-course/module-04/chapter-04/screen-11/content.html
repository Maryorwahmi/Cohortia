Definition

Common mistakes & debugging

  • Unquoted variables break on spaces. Always use "$VAR" when expanding.
  • Not executable: remember chmod +x to run scripts as commands.
  • Ignoring exit codes allows hidden failures; use strict modes to catch them.
Debug patterns
Use echo to reveal variable content, run with bash -x for tracing, and add a dry-run switch to preview destructive operations.
Example
Add a DRY_RUN variable; when set, commands should be printed instead of executed. This lets you validate behavior safely.
Pitfall
Hardcoding sensitive data in scripts. Use environment variables or credential stores rather than embedding secrets directly.
