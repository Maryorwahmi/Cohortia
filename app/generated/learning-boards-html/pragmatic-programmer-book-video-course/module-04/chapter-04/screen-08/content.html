Definition

Safety & Robustness

Adopt a small set of safety measures to make your scripts predictable and safe to run.
Strict modes
Use set -euo pipefail to detect errors early and prevent silent failures.
Input validation
Check arguments and file existence and print clear error messages if expectations are not met.
Quoting
Always quote expansions like "$FILE" to handle spaces and special characters correctly.
Practical snippet
#!/bin/bash

# Safety: Exit immediately if a command exits with a non-zero status.
set -e
# Safety: Treat unset variables as an error.
set -u
# Safety: The return value of a pipeline is the value of the last command to exit with a non-zero status.
set -o pipefail

DIR="$1"
if [ -z "$DIR" ]; then
  echo "Usage: $0 <directory>"
  exit 1
fi

if [ ! -d "$DIR" ]; then
  echo "Error: directory '$DIR' does not exist."
  exit 1
fi

# safe to proceed
