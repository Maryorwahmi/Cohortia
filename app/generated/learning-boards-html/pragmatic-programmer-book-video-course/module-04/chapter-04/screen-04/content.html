Core Concept

What is scripting?

Scripting captures a sequence of commands into a single executable file so tasks are repeatable, consistent, and documented.

Why it matters
  • Reduces human error by performing steps exactly the same way each run.
  • Saves time for repeated tasks and frees cognitive load for more complex work.
  • Serves as executable documentation for teammates and future you.
Concrete example
A scaffold script that creates a project folder, src directory, and a README with a title saves several manual steps and is easy to share.
Key Takeaway

Scripting replaces repetition with reliable automation; start with small focused scripts that document intent.

Definition Visual
#!/bin/bash

# A tiny scaffold example - creates a project and README
PROJECT=$1
if [ -z "$PROJECT" ]; then
  echo "Usage: $0 <project_name>"
  exit 1
fi
mkdir -p "$PROJECT/src"
printf "# %s

This is a new project." "$PROJECT" > "$PROJECT/README.md"
Misconception
Scripts must be huge to be useful. Small scripts are often the most valuable.
Pro tip
Start by recording your manual steps, then translate them into commands and script them.
