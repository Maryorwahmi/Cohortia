Bash building blocks

This example shows safety flags, argument checking, variables, and a greeting function for clarity.
<?xml version='1.0'?>#!/bin/bash

# Safety flags
set -euo pipefail

NAME=$1
if [ -z "$NAME" ]; then
  echo "Usage: $0 <name>"
  exit 1
fi

greet() {
  echo "Hello, $NAME!"
}

for i in 1 2 3; do
  greet
done
Explanation
  • set -euo pipefail: make failures visible and prevent unset variables.
  • NAME=$1: positional argument assignment; check it before use.
  • Functions group behavior so scripts remain readable and testable.
Common mistake
Not quoting variables like "$NAME" leads to errors when values include spaces or special characters.
