Module 4 › Chapter 4.3 › The Testing Pyramid
Pyramid layers
Unit Tests
Fast and precise checks for individual functions. Run these frequently during development.
Integration Tests
Verify that components such as services and databases integrate correctly.
End-to-End Tests
Simulate user scenarios to validate the whole application; use sparingly for crucial paths.
Practical allocation
Aim for a large base of unit tests, a smaller collection of integration checks for services and databases, and a few end-to-end tests covering critical user journeys.
Concrete example
Unit test: validate that sum of two numbers is correct. Integration test: ensure an API endpoint stores and retrieves a user record. E2E test: user signs in and lands on the dashboard.
Gotcha
Relying mainly on E2E tests leads to brittle suites and slow feedback. Use them sparingly for the highest-value flows.
Key Takeaway

Choose the right test at the right level: unit for speed, integration for interactions, E2E for critical user journeys.
