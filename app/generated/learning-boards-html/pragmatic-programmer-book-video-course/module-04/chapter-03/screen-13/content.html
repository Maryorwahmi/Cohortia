Module 4 › Chapter 4.3 › Key Concepts
End-to-End Test
Simulates user flows across the full system; use sparingly for critical journeys.
TDD
Write tests before code to drive design, then refactor safely with tests ensuring behavior remains stable.
Test Suite & Coverage
A test suite is the collection of tests. Coverage measures exercised code but is not a substitute for meaningful assertions.
Final takeaway
Balance speed, scope, and maintenance cost: many unit tests, focused integration checks, and a small set of E2E tests for the most critical user journeys.
