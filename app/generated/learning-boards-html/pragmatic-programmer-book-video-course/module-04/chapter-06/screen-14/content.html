Module 5 › Chapter 4.6 › Key Concepts
Pipeline
An automated sequence moving code from source to deployable artifact and environments.
Workflow / Job / Step
Workflow triggers jobs; jobs run steps on a runner to perform tasks.
Artifact
The immutable build output you store, tag, and deploy across environments.
Summary Takeaway

Use pipelines to enforce repeatable delivery, structure workflows clearly, and rely on artifacts to keep environments consistent.
