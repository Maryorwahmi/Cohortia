Module 5 › Chapter 4.6 › Learning Objectives
01
Explain CI, CD, and Continuous Deployment
Be able to state the purpose of each practice and when to adopt it.
Mnemonic: A three-step ladder: integrate, prepare, deploy.
VERIFIED COMPETENCY MILESTONE
02
Identify pipeline stages and artifacts
Name source, build, test, and deploy; explain what an artifact is and why it matters.
Mnemonic: S-B-T-D — Source Builds Tested Deployable.
VERIFIED COMPETENCY MILESTONE
03
Configure a basic CI pipeline
Use GitHub Actions YAML to run checkout, setup, install, test, and build steps for a Node.js project.
Mnemonic: YAML drives the runner steps — name your triggers.
VERIFIED COMPETENCY MILESTONE
04
Adopt pragmatic safety practices
Secure secrets, isolate environments, plan rollbacks, and avoid flaky tests to keep automation reliable.
Mnemonic: Secure, Isolate, Rollback — SIR.
VERIFIED COMPETENCY MILESTONE
