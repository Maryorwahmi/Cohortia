Module 5 › Chapter 4.6 › Testing Strategy
Testing tiers
Unit tests (fast)
Run on every push for immediate feedback.
Integration tests (medium)
Run on PR merge or nightly to validate component interaction.
End-to-end (slow)
Run a small smoke set in staging; full suites run less frequently.
Common problems & remediations
  • Slow tests: identify and move to secondary gates or parallelize them.
  • Flaky tests: quarantine and fix; flaky tests reduce trust in CI.
  • Missing test coverage for critical flows: add targeted smoke tests for production-significant paths.
Practical example
Run unit tests in the CI main job, run integration tests as a follow-up job, and run smoke E2E on staging before release.
Check
Are your slow tests blocking rapid feedback? If yes, reorganize them into secondary gates.
