Module 5 › Chapter 4.6 › Hands-on Lab
Steps at a glance
  1. Create the Node.js project and add a test script in package.json.
  2. Initialize git, commit files, push to a GitHub repo on main.
  3. Create .github/workflows/node-ci.yml and commit it.
  4. Observe the Actions tab to see the workflow run and inspect each step output.
Starter commands
mkdir github-actions-demo cd github-actions-demo npm init -y # add a test script in package.json
Example package.json snippet
{ "name": "github-actions-demo", "version": "1.0.0", "scripts": { "test": "echo \"Running dummy tests...\" && exit 0", "start": "node index.js" } }
Commit workflows and lock files, push to main, then open Actions to watch the 'Node.js CI' workflow run. Intentionally failing the test script shows a failed job and step logs you can inspect.
