Module 5 › Chapter 4.6 › Common Mistakes
Slow tests
Move lengthy tests out of the fast gate; parallelize and cache where possible.
Ignored failures
Treat red builds as urgent; assign ownership and make fixes part of the workflow.
Missing lock files
Commit package-lock.json so npm ci can install consistent versions and reproduce builds.
Action plan
  1. Audit tests by runtime, move slow tests to gated pipelines.
  2. Enforce green builds as a merge requirement and fix the owners of failing jobs.
  3. Commit lock files and use artifact tagging to ensure reproducible deploys.
