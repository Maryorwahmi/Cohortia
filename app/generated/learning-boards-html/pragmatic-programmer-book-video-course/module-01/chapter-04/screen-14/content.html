Sample questions
  • MCQ: Which comment best explains a workaround for a legacy API? (Answer: the one naming the legacy issue and behavior.)
  • Short write: Rewrite a vague feature request as an acceptance criterion with two clarifying questions.
  • Commit rewrite: Turn "fix: auth changes" into a subject and body that explain security improvements and migration steps.
Key Takeaway

Assess both clarity and actionability: can someone act on the documentation or commit without asking questions?
