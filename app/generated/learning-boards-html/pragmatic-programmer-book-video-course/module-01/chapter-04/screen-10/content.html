Module 2 › Chapter 1.4 › External Documentation
What to document
Setup & run instructions
Architecture rationale
Migration and rollback steps
API contracts and error cases
Keep high-impact docs current. Automate when possible: generate API specs from code annotations to reduce drift.
Pitfall
Outdated documentation misleads. Prefer a small, accurate README to a large, stale manual.
Key Takeaway

Document the decisions others must act on and keep that documentation in your workflow.
