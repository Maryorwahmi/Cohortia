Module 2 › Chapter 1.4 › Audience Awareness
Definition
Adapting language and detail to match the listener's background and their goal for the information.
Diagnostic questions: What do they know? What decision do they need to make? How will they use this info?
Example: Database change → peer: index strategy; product: page load and user impact.
Misconception: More technical detail always helps. Often it doesn't.
Practice prompt
Take a recent change and write a two-sentence explanation for a non-technical stakeholder: state outcome and expected impact.
Key Takeaway

A short, audience-appropriate summary speeds decisions more than a long technical note.
