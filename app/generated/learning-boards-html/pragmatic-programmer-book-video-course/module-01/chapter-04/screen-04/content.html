Scenario: Vague request
"Add a dashboard with all key metrics" leads to assumptions. This slide shows the chain of decisions that cause rework.
Request received: "All key metrics"
→
Developer assumes full metrics pipeline
→
Two sprints of implementation
→
Stakeholder needs three KPIs only
Pragmatic fix
  • Ask targeted questions: "Which decisions will this inform? Who will use it?"
  • Deliver a focused prototype with three metrics to validate assumptions.
  • Iterate after feedback rather than building up-front.
Key Takeaway

Clarify intent early: ask "why" and "who" to shrink scope and deliver value faster.
