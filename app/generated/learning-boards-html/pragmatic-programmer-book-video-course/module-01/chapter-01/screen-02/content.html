Learning Objectives

Practiceable goals for taking responsibility in code and communication.

Bloom: Learn → Understand → Apply → Master
01
Understand Broken Windows

Explain how small signs of neglect change team behavior and increase technical debt. Recognize examples in code and repos.

Mnemonic: Venn - Neglect + Visibility = Decay
VERIFIED COMPETENCY MILESTONE
02
Take Ownership

Apply small, practical fixes that improve readability and robustness, and leave clear commit messages describing intent.

Mnemonic: Timeline — Notice → Fix → Commit
VERIFIED COMPETENCY MILESTONE
03
Prevent Technical Debt

Adopt practices like named constants and small refactors to avoid accumulating hidden rework costs.

Mnemonic: Icons — Spade for digging debt early
VERIFIED COMPETENCY MILESTONE
04
Communicate Constructively

Report issues with facts, impact, and suggested fixes — offer help rather than assigning blame.

Mnemonic: Short checklist — Symptom · Impact · Suggestion
VERIFIED COMPETENCY MILESTONE
