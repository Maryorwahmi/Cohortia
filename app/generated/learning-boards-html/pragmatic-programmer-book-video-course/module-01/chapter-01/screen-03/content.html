Practice & Communication

Translate broken-window awareness into habits and team-friendly messages.

Tactics
  • Rename unclear identifiers when safe.
  • Extract duplicated logic into a function.
  • Introduce named constants for magic numbers.
Prioritization

Fixes do not all need to block release. Prefer in-touch-file fixes and small follow-ups when time is constrained.

Communication Pattern
Symptom · Impact · Suggestion. Offer to help implement the fix.
Hands-on
Identify three broken windows in a short script, refactor one, and create a clear commit message describing intent and impact.
Quick tip
A one-line commit that explains 'why' is as important as the code change itself.
