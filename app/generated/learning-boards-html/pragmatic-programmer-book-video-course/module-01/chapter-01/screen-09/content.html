Small moves that prevent debt

  • Replace magic numbers with named constants.
  • Extract duplicated logic into single helpers.
  • Add minimal tests for discovered edge cases.
  • Standardize naming and formatting in touched files.
Concrete scenario
Two functions parse similar inputs differently. Extract a single parser and add a unit test to keep behavior consistent.

Implementation pattern

When you touch a file
Fix one small code smell if it avoids future bugs or confusion.
Commit message tip
Explain the why and what was improved, e.g., 'Introduce PRICE_MULTIPLIER constant to clarify business rule.'
Misconception
Small fixes are not a waste of time — they compound into significant savings in maintenance.
