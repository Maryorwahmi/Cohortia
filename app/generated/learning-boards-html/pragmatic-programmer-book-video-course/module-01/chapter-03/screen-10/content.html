Step 1: Core user story

Write a single line describing the minimal outcome to validate, for example: receive an email when order status becomes shipped.

Step 2: Key components
  • OrderService publishes OrderStatusChanged event
  • NotificationService listens and writes notification DB record
  • NotificationQueue decouples NotificationService and EmailSender
  • EmailSender worker sends actual emails and updates status
Step 3: End-to-end flow (pseudocode)
// In OrderService:
function updateOrderStatus(orderId, newStatus):
  order = getOrder(orderId)
  order.status = newStatus
  saveOrder(order)
  if newStatus == 'Shipped':
    eventBus.publish(new OrderStatusChangedEvent(order.userId, order.id, 'Shipped'))

// In NotificationService:
on(OrderStatusChangedEvent event):
  message = "Your order " + event.orderId + " has been shipped!"
  notification = createNotificationRecord(event.userId, 'email', message, 'pending')
  notificationQueue.enqueue(notification)

// In EmailSender worker:
on(notificationQueue.message):
  notification = dequeueMessage()
  user = getUser(notification.userId)
  sendEmail(user.email, "Order Shipped!", notification.message)
  updateNotificationStatus(notification.id, 'sent')
