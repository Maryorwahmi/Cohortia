Encapsulate permissions
Replace repeated if-role checks with a single method on User or a dedicated service.
# Example: AccessControlService
class AccessControlService:
  def has_permission(self, user, feature_name):
    # centralized permission logic
    ...
Best practices
  • Name abstractions clearly to express intent.
  • Keep interfaces small and well-tested.
  • Avoid generic, over-engineered abstractions before they’re needed.
Pro tip: extract an abstraction when three callers need the same logic, or when a change would affect multiple modules.
