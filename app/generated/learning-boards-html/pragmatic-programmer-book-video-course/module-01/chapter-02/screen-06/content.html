Module 1 › Chapter 1.2 › Forms of Duplication
Code duplication

Literal copy-paste blocks. Fix by extracting a function or utility.

Logical duplication

Different code paths with the same intent. Fix by unifying the intent into a single routine.

Data duplication

Same data stored or derived multiple ways. Fix by canonicalizing and deriving secondary values from the canonical source.

Knowledge duplication

Information living in people or scattered notes. Fix by documenting, automating, or centralizing runbooks.

Process duplication

Manual, repeatable steps. Fix by automating with scripts or CI jobs.

Key Takeaway

Different duplication types require different fixes; prioritize those that increase change cost.
