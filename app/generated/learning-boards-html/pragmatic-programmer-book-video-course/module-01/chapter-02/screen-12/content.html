Module 1 › Chapter 1.2 › Common Mistakes
Over-abstraction (YAGNI)

Building very generic systems before real reuse emerges creates complexity and fragile code. Favor smaller, explicit helpers instead.

Hidden duplication

Slightly different implementations can encode the same rule. Look for intent, not just identical text.

Pro tip: write a test that captures the intent and run it against both implementations to reveal hidden duplication.
