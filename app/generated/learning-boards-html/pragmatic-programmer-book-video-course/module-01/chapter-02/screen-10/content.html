AccessControlService (concept)
A small service with a single responsibility: answer permission questions. Keep the API minimal, for example has_permission(user, feature_name).
class AccessControlService:
  def has_permission(self, user, feature_name):
    # central policy logic
    ...
Benefits
  • Change policy in one place.
  • Front-end mirrors permission map for UI decisions only.
  • Tests validate policy changes and avoid regressions.
Common mistake: relying solely on client-side checks for security.
