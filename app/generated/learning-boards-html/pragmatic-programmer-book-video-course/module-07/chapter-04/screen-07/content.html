Module 7 › Chapter 7.4 › Extract Method — Steps
Step-by-step
  1. Locate a coherent block with one responsibility.
  2. Name the new helper to describe intent, not implementation.
  3. Move the block into the helper, pass explicit parameters, and return results.
  4. Replace the original block with a call and re-run tests.
  5. Iterate with smaller blocks if tests fail.
Pro-tip: pick blocks that minimize local-state dependencies so the helper’s contract is simple.
Concrete orchestration pattern
After extracting helpers, the original method becomes an orchestrator that reads like a script: validate, calculate, persist, notify. This improves readability and testability.

Key Takeaway

Extract Method shortens routines and reveals high-level intent, making code easier to reason about and test.
