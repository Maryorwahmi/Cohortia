Module 7 › Chapter 7.4 › Red-Green-Refactor
Red
Confirm failing test when adding or changing behavior, or ensure current tests are green before refactoring.
Green
Make minimal changes to make tests pass. For refactors, preserve passing tests by moving code without altering outputs.
Refactor
Improve structure in small steps, rerun targeted tests after each step, and then run the full suite.
Practice checklist
  • Run targeted tests before the change.
  • Extract one helper and re-run those tests.
  • Repeat and run the full suite before pushing.
