Module 7 › Chapter 7.4 › Boy Scout Rule
The habit
Make a small cleanup whenever you touch code. A single rename or extract makes future changes easier and reduces reviewer friction.
Keep changes small so reviewers can focus on behavior. If your change grows beyond a tiny cleanup, split it into separate commits and justify the intent in the message.
Micro-refactor checklist
  • Confirm tests are green.
  • Make one small improvement, such as renaming or extracting a small method.
  • Re-run tests and write a short commit message explaining the intent.
Key Takeaway

Small disciplined changes create a maintainable codebase and prevent large technical-debt cleanups.
