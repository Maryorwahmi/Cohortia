Module 7 › Chapter 7.4 › Common Code Smells
Smells and causes
Long methods
Do too many tasks. Extract Method to isolate responsibilities and make code testable.
Large classes
Multiple responsibilities suggest extracting a class or service to reflect SRP.
Duplicate code
Copy-paste increases maintenance cost. Introduce a shared helper or function.
Smells continued
Feature envy
A method that uses data from another object too often. Consider moving the method or adding a collaborator.
Magic numbers/strings
Literals without explanation. Introduce named constants to reveal meaning.
Poor naming
Names that hide intent increase cognitive load. Prefer intent-revealing names.
Mapping smells to refactors reduces guesswork during reviews.
