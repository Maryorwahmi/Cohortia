Module 7 › Chapter 7.4 › What Is Refactoring?
Refactoring defined
Change internal structure to improve readability, maintainability, and extensibility while keeping external behavior identical.
Why it matters
Cleaner code reduces cognitive load, makes tests easier to write, and lowers the cost of future changes.
Misconception check
Refactoring is not adding features. If behavior changes, treat the work as a feature change with tests, then refactor in separate steps.
Concrete pattern: Extract Method
Move a coherent block of statements into a new function with a name that describes the intent. Replace the block with a call to that function.
Benefits
  • Shorter functions that read like a story.
  • Helpers that can be unit-tested independently.
  • Clearer names that document intent.
Key Takeaway

Refactoring is safe when done in small steps with tests; prefer clarity and intent-revealing names.
