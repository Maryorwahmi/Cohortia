Learning Objectives
A practical breakdown of the skills this chapter builds.

Practice self-critique
Learn to review your code for clarity and responsibility. This habit prevents technical debt and surfaces refactor opportunities.

VERIFIED COMPETENCY MILESTONE

Apply refactors
Use Extract Method, Introduce Constant, and Extract Class to improve readability and testability.
VERIFIED COMPETENCY MILESTONE

Adopt small steps with automated tests and the Red-Green-Refactor cycle to avoid regressions.
