Why write tests first
  • Specifies expected behavior before implementation.
  • Produces immediate pass/fail feedback for knowledge checks.
  • Makes refactoring safer and measurable.
Misconception

Tests must be exhaustive to be useful. For learning, write a single targeted test to verify one idea at a time.

Starter test: test_stack.py
import unittest
from stack import Stack

class TestStack(unittest.TestCase):
  def test_new_stack_is_empty(self):
    stack = Stack()
    self.assertTrue(stack.is_empty())
    self.assertEqual(stack.size(), 0)

  def test_push_adds_element(self):
    stack = Stack()
    stack.push(10)
    self.assertFalse(stack.is_empty())
    self.assertEqual(stack.size(), 1)

if __name__ == '__main__':
  unittest.main()
