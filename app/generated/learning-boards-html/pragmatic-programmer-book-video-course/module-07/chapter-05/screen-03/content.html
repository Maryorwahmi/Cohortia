Module 7 › Chapter 7.5 › Objectives — Practice and Tools
Objective details
  • Design spikes: Keep experiments tiny and time-boxed so you get a clear answer fast.
  • TDD for learning: Use failing tests to force clarity in what you expect from a new API or technique.
  • CI automation: Run tests automatically after pushes so feedback arrives without manual steps.
  • Reflection: Record short notes to turn experiences into lasting memory.
Mnemonic
Think: Hypothesis → Spike → Test → CI → Reflect
Verified Competency Milestone

Run a spike that includes at least one failing test and a CI check that runs those tests automatically.
