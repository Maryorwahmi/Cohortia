Module 7 › Chapter 7.5 › Red → Green → Refactor
Cycle details
Red
Write a failing test that names the behavior you want to learn.
Green
Make the smallest change to pass the test. Confirm the behavior is implemented.
Refactor
Clean up code while keeping tests green. Note design lessons learned.
After the cycle, write a one-line reflection: what was confirmed, and what next question should you test? This turns each cycle into a documented learning step.
