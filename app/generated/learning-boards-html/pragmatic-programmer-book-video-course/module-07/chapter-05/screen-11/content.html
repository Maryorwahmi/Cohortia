Module 7 › Chapter 7.5 › Sync vs Async Experiment
Synchronous example
def main_sync():
  urls = ["http://example.com/1", "http://example.com/2", "http://example.com/3"]
  start_time = time.time()
  for url in urls:
    print(f"Fetching {url}...")
    time.sleep(1) # Simulate network delay
    print(f"Finished fetching {url}")
  end_time = time.time()
  print(f"Sync total time: {end_time - start_time:.2f} seconds")
Asynchronous example (concept)
async def main_async():
  tasks = [fetch(url) for url in urls]
  start_time = time.time()
  results = await asyncio.gather(*tasks)
  end_time = time.time()
  print(f"Async total time: {end_time - start_time:.2f} seconds")
Experiment note
Measure wall-clock time. Expect asynchronous version to be faster when tasks mainly wait for I/O. Record times and decide whether the hypothesis was supported.
