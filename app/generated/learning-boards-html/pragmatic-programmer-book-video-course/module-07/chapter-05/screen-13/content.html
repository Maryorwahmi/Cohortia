Module 7 › Chapter 7.5 › Build a Queue with TDD and CI
Challenge steps
  1. Write a narrow test for enqueue then dequeue of a single element.
  2. Run tests, implement minimal queue behavior to pass.
  3. Add tests for size, peek, and empty dequeue behavior.
  4. Push and observe CI run the test suite automatically.
  5. Record a short reflection with hypothesis, result, and next question.
Outcome
A repository with recorded experiments, passing tests, and a CI badge is a verifiable learning artifact you can revisit and extend.
Reflection prompt
What did the first passing test teach you about the API design? Save that as a commit message and a one-line note.
