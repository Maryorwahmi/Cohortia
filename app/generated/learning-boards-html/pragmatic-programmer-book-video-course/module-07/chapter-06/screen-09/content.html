Timeline

Show the cost in time

Translate the request into person-weeks, a shifted delivery date, and features at risk. Use a simple visual timeline or bullet list for clarity.

Baseline plan: Core API — 4 weeks
Added work: Reporting — +3 weeks
Result: Release delayed or other features cut
Spike option
Propose a short, time-boxed investigation to produce a more accurate estimate before deciding.
Template impact statement
"This change requires X weeks for integration, will delay the current release by Y weeks, and will force us to cut Z features to keep the date. Recommendation: defer or run a 1-week spike."
Check your estimate
Account for legacy code and tests. If the module lacks tests, investigate first — effort can balloon unexpectedly.
