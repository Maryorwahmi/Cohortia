Activity

Draft a refusal for the loyalty integration

Use a one-paragraph message that acknowledges the idea, states the impact, quantifies delay, and offers alternatives like deferment, a spike, or a temporary solution.

Starter template
"Thanks — the loyalty system is a valuable idea. Integrating it now would require API and schema changes plus UI updates, and we estimate it would delay the launch by about two weeks. To keep the launch stable, I recommend deferring this work to a post-launch sprint or running a one-week spike to validate effort. Alternatively, we could use a vendor tool temporarily and integrate later. Which option should we prioritize?"
Evaluation checklist
  • Acknowledge the value and intent.
  • State concrete technical impact and timeline.
  • Offer at least two pragmatic alternatives.
Reflection prompt

After sending the message, note the stakeholder response and whether your alternative satisfied the need. Use that feedback to refine future refusals.
