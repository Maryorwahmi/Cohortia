Starter code
from flask import Flask, render_template_string, request

app = Flask(__name__)

# This would come from config or a flag service in production
FEATURE_PROMO_BANNER_ENABLED = True

HTML_TEMPLATE = """



  
Our Products

  {% if promo_enabled %}
    

      
Limited Time Offer! Get 20% off all items!

    

  {% endif %}
  
  • Product A
  • Product B
  • Product C



"""

@app.route('/')
def index():
  return render_template_string(HTML_TEMPLATE, promo_enabled=FEATURE_PROMO_BANNER_ENABLED)

@app.route('/toggle_promo')
def toggle_promo():
  global FEATURE_PROMO_BANNER_ENABLED
  FEATURE_PROMO_BANNER_ENABLED = not FEATURE_PROMO_BANNER_ENABLED
  return f"Promotional banner is now: {FEATURE_PROMO_BANNER_ENABLED}."
Steps
  1. Run the app and visit root to see the banner.
  2. Call /toggle_promo to flip the flag and refresh.
  3. Extend persistence and permissions for production readiness.
Reflection

Think how this simple pattern could guard a new API or algorithm before full exposure.
