Architecture overview

A proxy or gateway intercepts requests. For a chosen seam, the proxy routes to the new service while leaving other traffic to the legacy system. As coverage increases, the legacy module shrinks.

Step 1
Identify the seam to extract.
Step 2
Implement new service with its own data and tests.
Step 3
Route traffic via a facade and monitor before expanding.
Analogy

Like a new tree vine growing around the old trunk, the new system wraps and gradually replaces parts of the legacy code without uprooting it.

Common mistake

Not automating parity checks. Without tests, the facade can flip routes and introduce subtle regressions.
