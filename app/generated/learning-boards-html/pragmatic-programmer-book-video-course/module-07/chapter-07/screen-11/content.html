Module 07 › Chapter 7.7 › Flag patterns
Dark launch

Deploy behind a flag to observe behavior in production without exposing it to users. Use to validate performance and integrations.

A/B testing

Expose different variants to user segments and measure impact on defined metrics before full release.

Gradual rollout

Increase user exposure in controlled increments while monitoring success criteria at each step.

Kill switch

Provide an immediate, auditable way to disable a feature if it negatively impacts the system or users.

Operational checklist
  • Define metrics and alert thresholds before enabling a flag.
  • Assign an owner and removal date for every flag.
  • Automate flag toggles with audit logs for safety.
