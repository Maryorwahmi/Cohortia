Module 7 › Chapter 7.3 › Technical Debt
Definition

Technical Debt from Tools

Outdated or unused tools add maintenance costs, compatibility issues, and cognitive load for the team.

Inventory
List tools, owners, and frequency of use to identify candidates for pruning.
30-day Retirement Pilot
Temporarily stop using a tool to reveal hidden dependencies before permanent removal.
Measure Impact
Track any disruption and the maintenance time saved to justify pruning decisions.
Key Takeaway
Deliberate pruning reduces long-term maintenance costs and keeps the team focused on high-value work.
