Activity

Automate with a CLI Tool

Identify a repetitive task, choose a CLI tool, and run a short POC. The example uses jq for JSON processing.

Example input (data.json)
{ "users": [ {"id": 1, "name": "Alice", "email": "alice@example.com"}, {"id": 2, "name": "Bob", "email": "bob@example.com"}, {"id": 3, "name": "Charlie", "email": "charlie@example.com"} ] }
Suggested jq command
cat data.json | jq '.users[].name'
Expected output: each name on its own line, quoted.
POC Checklist
  • Identify the repetitive task and a candidate CLI tool.
  • Install and run a single command on sample data.
  • Note time saved, edge cases, and integration concerns.
  • Document the commands and reflect on value to the team.
Key Takeaway

Hands-on spikes give far more insight than reading docs. Small experiments reveal integration costs and real utility.
