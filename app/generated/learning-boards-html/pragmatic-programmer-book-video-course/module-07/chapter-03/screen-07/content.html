Basic GitHub Actions Workflow

Use this minimal workflow as a POC to validate build reproducibility and test feedback.

name: Python CI

on:
  push:
    branches: [ main ]
  pull_request:
    branches: [ main ]

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
    - uses: actions/checkout@v2
    - name: Set up Python
      uses: actions/setup-python@v2
      with:
        python-version: '3.9'
    - name: Install dependencies
      run: |
        python -m pip install --upgrade pip
        pip install -r requirements.txt
    - name: Run tests
      run: |
        pytest
POC Goal
Confirm reproducible builds and faster test feedback.
Watch For
Secrets, caching, environment parity, and ownership of pipeline code.
Key Takeaway
A minimal pipeline surfaces integration costs without heavy upfront investment.
