Skill Breakdown

These tasks turn objectives into verifiable steps you can complete in a single week.

Practice
Compare idioms
Rewrite a small function in two styles and note differences.
Document
Paradigm one-pager
List typical abstractions and when to prefer them.
Build
Small project
Implement the GET and POST endpoints in a new language.
Assessment
Verification Tests
  • Run the sample server and verify responses with curl.
  • Show an idiomatic rewrite of a function and explain why it is idiomatic.
Reflection
Transfer note
Write a short note describing how the new paradigm changed one design decision in your main language.
