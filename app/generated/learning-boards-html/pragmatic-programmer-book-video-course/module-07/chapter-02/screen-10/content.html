Process

Tooling and ecosystem

Setup

Install runtime, package manager, and use a starter template to scaffold the app so you learn conventions.

Testing

Follow the community testing approach: unit tests, request tests, or fixtures. Test your GET and POST endpoints.

Error handling

See how the community models errors: exceptions, results, or typed errors — and adopt the language's conventions.

Tip

Use the ecosystem templates to learn the expected project layout and dependency practices quickly.

Key Takeaway

Tooling reveals idioms and best practices. Follow templates so you learn the community's way of working.
