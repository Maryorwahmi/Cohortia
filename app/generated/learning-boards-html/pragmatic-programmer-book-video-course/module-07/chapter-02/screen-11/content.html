Cross-training

Choose one idea

Pick a single insight from the new language — immutability, pure functions, ownership — and apply it to a small feature in your main codebase.

Refactor example

Replace shared mutable state with a pure function plus an explicit state update and test the difference in unit tests.

Reflection prompt: Did test complexity decrease? Were side-effects easier to isolate?
Measure
  • Count focused unit tests before and after.
  • Note whether debugging became simpler.
Key Takeaway

Transfer a single idea first. Measure improvements in tests, readability, or fewer bugs.
