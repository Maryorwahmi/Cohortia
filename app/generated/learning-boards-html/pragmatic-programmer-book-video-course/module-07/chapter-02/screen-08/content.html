Example: Flask (reference)

Use this example as a functional spec while you implement the same API in your chosen language.

from flask import Flask, request, jsonify

app = Flask(__name__)

@app.route('/hello', methods=['GET'])
def hello():
  return "Hello, Pragmatic Programmer!"

@app.route('/echo', methods=['POST'])
def echo():
  data = request.get_json()
  return jsonify(data), 200

if __name__ == '__main__':
  app.run(debug=True)
Tip: Use the example to focus on routing and JSON semantics, not on copying structure line-by-line.
Project checklist
  • Set up runtime and package manager for the language.
  • Bootstrap a minimal app using the language's community template.
  • Implement GET /hello and POST /echo and verify with curl.
  • Write two simple tests or curl commands to validate behavior.
Key Takeaway
