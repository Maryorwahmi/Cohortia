Definition

Declarative and logic programming

Express relationships and goals; let the runtime satisfy constraints instead of manually orchestrating steps.

Idea: State your facts and rules; ask the system for solutions.
Exercise

Take a search or scheduling problem you solved imperatively. Try expressing constraints and let the language infer a solution. Observe how the mental load shifts from control flow to specification.

Example: Database queries are declarative — you describe the rows you want rather than how to traverse tables.
Misconception

Declarative does not remove complexity. It relocates it into constraints; you must design good predicates and rules to avoid performance issues.

Key Takeaway

Practice expressing goals and constraints to see when declarative tools reduce cognitive load.
