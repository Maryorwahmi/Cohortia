Concept

Garbage Collector basics

The GC automatically frees memory for objects that are no longer referenced. Large or frequent allocations cause pauses when the GC runs.

Example allocation pitfall
Creating new collections or strings inside Update every frame adds many short-lived objects that trigger GC.Collect.
Mitigations
  • Reuse collections and buffers instead of newing them.
  • Avoid boxing and use structs carefully.
  • Implement object pooling for high-frequency GameObjects.
Detecting GC issues

Open the Profiler and watch for GC.Collect spikes in CPU Usage and Memory allocation growth in the Memory module. Correlate spikes with gameplay actions.

Common mistake

Assuming GC spikes are only caused by huge single allocations. Often many small allocations add up quickly.
