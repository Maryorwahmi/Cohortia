Module 6 › Chapter 6.4 › Meshes & LOD
Why it matters

Reduce vertex processing with LODs

Use multiple mesh resolutions and let Unity swap them based on distance to save GPU work.

Practical steps
Create decimated LODs in your modeling tool, import them, and assign to an LOD Group component with appropriate screen-relative thresholds.
Import tip
Uncheck Read/Write for models that won’t be modified at runtime to avoid CPU memory duplication.
Comparison
Single high-detail mesh
Simple to manage but wastes vertex processing on distant objects and can duplicate memory if Read/Write is enabled.
LOD group with 3 levels
Swaps meshes by distance, reducing GPU load while preserving the appearance at relevant ranges.
Key Takeaway

Use LODs and disable unnecessary Read/Write to reduce both GPU and CPU memory usage while maintaining visuals where they matter.
