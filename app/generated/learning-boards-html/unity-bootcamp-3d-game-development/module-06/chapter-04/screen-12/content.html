Module 6 › Chapter 6.4 › Lab: Object pooling
Lab steps
1. Identify object
Choose a frequently created object like a bullet or particle effect.
2. Create pool
Add ObjectPool.cs to an ObjectPoolManager GameObject and assign the prefab and pool size.
3. Refactor spawner
Replace Instantiate with GetPooledObject, set transform, and call Activate on the behavior.
4. Return objects
On lifetime expiry or collision, call ReturnPooledObject to deactivate and reuse the object.
Profiler verification
  1. Capture profiles before changes during intense spawning and note GC.Collect spikes.
  2. Apply pooling and capture the same scenario again.
  3. Compare allocation graphs and GC events; you should see fewer allocations and less frequent GC spikes.
Pro tip

If pooling doesn't reduce GC, inspect other allocations in the profiled timeline; temporary collections, string allocations, or other systems may still allocate heavily.
