Module 6 › Chapter 6.4 › Detecting leaks
Common causes
Unsubscribed events
Publishers retain delegates to destroyed subscribers, preventing collection.
Static references
Static fields holding scene objects keep them alive across scene changes.
Stuck coroutines
Coroutines that never finish can keep references alive indefinitely.
Profiler workflow
  1. Run a scenario that should release objects (scene unload or repeated spawn cycles).
  2. Take Memory snapshots before and after the scenario.
  3. Compare snapshots for objects that persist unexpectedly and inspect retaining paths.
Real-world check

Reload the same scene several times and watch total memory. If it rises each load, investigate retained references and unsubscribe or clear statics as needed.
