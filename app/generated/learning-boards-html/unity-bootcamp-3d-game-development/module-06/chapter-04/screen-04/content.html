Module 6 › Chapter 6.4 › Why asset optimization matters
Definition

Optimize assets to control memory and build size

Small changes to import settings yield large savings in RAM and reduce startup and runtime stalls.

Texture example
Background prop: drop from 4K to 512 or 1024 and enable Mip Maps. Use ASTC/ETC for mobile or DXT on desktop.
Mesh example
Convert a distant 50k polygon model to LODs: 10k for medium distance, 2k for far distance to cut GPU vertex work.
Audio example
Short impact SFX: Decompress on Load. Long music: Stream from disk to avoid high RAM usage.
Key Takeaway

Match asset fidelity to screen space and use compression and streaming to reduce memory without harming visible quality.

Practical checklist
  • Inspect large textures; reduce Max Size where detail is unnecessary.
  • Enable Mip Maps for 3D textures to save GPU memory when distant.
  • Disable Read/Write unless runtime mesh access is required.
  • Add LOD groups to complex models to reduce vertex work at distance.
  • Choose audio load type based on clip length and frequency of playback.
Common misconception
Higher resolution always improves perceived quality. In many cases, properly compressed and sized assets are visually indistinguishable but far cheaper in memory.
