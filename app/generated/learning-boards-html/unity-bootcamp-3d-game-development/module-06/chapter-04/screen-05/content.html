Module 6 › Chapter 6.4 › Texture optimization
Step-by-step
  1. Audit Project window and sort by asset size to find largest textures.
  2. Decide screen-space need and set Max Size accordingly (e.g., 512, 1024).
  3. Choose Compression format for target platform (DXT / ETC / ASTC).
  4. Enable Generate Mip Maps for 3D use to save GPU memory when distant.
  5. Test in-scene, use the Profiler Memory to confirm savings.
Concrete example
A 4K foliage texture used at distance can be lowered to 1024, compressed to ASTC, and still appear identical in-game while freeing VRAM and lowering build size.
Supporting notes
  • Normal maps need normal-specific import settings; treat them separately.
  • UI elements sometimes require higher bit depth for crisp alpha; balance that with memory budget.
  • Use platform overrides in Import Settings to set different formats for mobile and desktop.
Key Takeaway

Apply the smallest acceptable texture sizes and platform-appropriate compression, and rely on mip maps for distant geometry.
