Optimization checklist

Audit large textures and reduce Max Size where possible.
Enable Mip Maps for 3D textures to save GPU memory.
Use platform-appropriate compression formats (DXT, ETC, ASTC).
Create LODs and disable Read/Write unless needed at runtime.
Choose audio load types: Decompress On Load for SFX, Streaming for music.
Avoid allocations in Update; reuse collections and buffers.
Implement and test object pooling for frequent spawns.
Unsubscribe events, clear statics, and stop coroutines to prevent leaks.
Key Takeaway

Measure before and after each change using the Profiler to ensure real gains and avoid over-optimizing where it isn't needed.
