Triage steps
  1. Detect — Automated alerts for crashes and spikes in error rates.
  2. Reproduce — Gather logs, device info, and reproduction steps.
  3. Prioritize — Crash/data loss first, then major play blockers, then minor issues.
  4. Fix & Test — Minimal change, staging test, then release with rollback plan.
Pro Tip

Keep a clear version map (release notes + branch mapping) so you can reproduce and revert fixes quickly.

Example: Hotfix flow
An incident occurs: players report crashes on launch after a recent update. Follow the flow below.
1. Isolate & reproduce
Collect logs, get a reproducible case, and create a minimal debug build.
2. Patch minimal code
Avoid large refactors. Roll back the risky change or guard it with runtime checks.
3. Stage & deploy
Verify on staging, then publish a hotfix and monitor for improvements.
