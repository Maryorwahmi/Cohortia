Learning Objectives
Learn → Understand → Apply → Master
01
Plan updates & patch strategy
Define branches for development, testing, and release. This reduces accidental shipping of unfinished work and helps organize hotfixes.
Mnemonic: BRANCH — Build, Review, Approve, Nightly, Coldfix, Hotfix
VERIFIED COMPETENCY MILESTONE
02
Enable Unity Analytics
Link the project to an organization and enable Analytics to start sending events and measuring retention, conversions, and level success rates.
Mnemonic: INIT — Identify, Name events, Instrument, Track
VERIFIED COMPETENCY MILESTONE
03
Choose ethical monetization
Understand IAP and Ads trade-offs. Prefer cosmetics and opt-in rewarded ads to protect fairness and retention.
Mnemonic: FAIR — Free-friendly, Accountable, Informed, Respectful
VERIFIED COMPETENCY MILESTONE
04
Prepare for store submission
Gather required metadata, signing keys, and store assets to avoid common rejections and speed review time.
Mnemonic: LIST — Logs, Images, Signing, Terms
VERIFIED COMPETENCY MILESTONE
