Programmatic Frame Rate Control

Using Application.targetFrameRate and QualitySettings.vSyncCount for precise control.

Set Target FPS

Use Application.targetFrameRate = value; in Awake() or Start() to define desired FPS.

Disable VSync for Control

Set QualitySettings.vSyncCount = 0; to prevent VSync from overriding your target frame rate.

Key Takeaway

Explicitly setting targetFrameRate and disabling VSync provides granular control over your game's performance profile.

FrameRateController.cs
using UnityEngine;

public class FrameRateController : MonoBehaviour
{
    public int targetFPS = 60; // Set this in the Inspector

    void Awake()
    {
        // Set the target frame rate
        Application.targetFrameRate = targetFPS;

        // Optionally, disable VSync if you want full control
        // QualitySettings.vSyncCount = 0; 
    }
}
Considerations

Disabling VSync (QualitySettings.vSyncCount = 0;) gives targetFrameRate full control but can introduce screen tearing. For mobile, 30 FPS is often a good balance for battery life.
