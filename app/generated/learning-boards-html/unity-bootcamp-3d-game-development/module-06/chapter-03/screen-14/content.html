Essential Performance Terms

Key ideas to remember from this chapter.

Performance Optimization

The process of improving a game's efficiency to run smoothly and consistently.

Unity Profiler

A powerful tool for real-time analysis of CPU, GPU, memory, and other game performance metrics.

CPU Bottleneck

When the CPU is the limiting factor in game performance, often due to complex calculations or excessive script execution.

Summary Takeaway

Mastering performance optimization begins with understanding key terminology and utilizing powerful diagnostic tools like the Unity Profiler to identify and address bottlenecks.
