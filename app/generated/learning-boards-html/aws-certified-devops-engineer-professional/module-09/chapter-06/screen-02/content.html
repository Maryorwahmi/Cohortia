Learning Objectives

A progression from understanding to application.

Bloom: Learn → Understand → Apply → Master
01
Explain serverless concepts

Describe the model where the cloud provider manages servers and you pay for execution time. Recognize suitable use cases such as event-driven processing and APIs.

VERIFIED COMPETENCY MILESTONE
02
Understand the execution model

Explain runtimes, triggers, execution environments, cold starts, and concurrency so you can predict performance and scale behavior.

VERIFIED COMPETENCY MILESTONE
03
Deploy a basic Lambda function

Use the AWS Console to create a Python function, assign a role, upload code, add an API Gateway trigger, and test the endpoint.

VERIFIED COMPETENCY MILESTONE
04
Apply best practices and avoid pitfalls

Design idempotent functions, choose memory and timeouts wisely, leverage layers, and use secure secret stores to prevent credential leaks.

VERIFIED COMPETENCY MILESTONE
