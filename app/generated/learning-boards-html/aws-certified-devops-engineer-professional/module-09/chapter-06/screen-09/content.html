Module 9 › Chapter 9.6 › Add API Gateway
Process Flow

Wire API Gateway

Select API Gateway as a trigger, choose REST API, and create a stage such as dev to expose a public URL.

Test steps
  1. Open the displayed endpoint URL in a browser.
  2. Append ?name=YourName to confirm dynamic responses.
  3. Check CloudWatch Logs for the event payload and function logs.
Pitfall

Not redeploying the API after mapping changes leaves clients hitting old configurations.

Remember: for production secure the API with proper authorization and limit exposure.
Debugging & Observability
CloudWatch Logs

Your handler's print statements reveal the exact event sent by API Gateway and simplify mapping and debugging.

Response format

Use statusCode, headers, and body fields when using Lambda proxy integration to ensure correct HTTP responses.

Key Takeaway

Testing the endpoint and checking logs closes the loop between configuration, invocation, and observability.
