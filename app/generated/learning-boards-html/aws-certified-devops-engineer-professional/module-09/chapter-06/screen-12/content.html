Architecture

Roles and secrets

Grant least privilege and use secret stores rather than hardcoding credentials.

Execution role

Define minimal permissions for the Lambda to access only required resources.

Secret management

Use Secrets Manager or Parameter Store with SecureString and grant read permission to the function only.

Warning

Overly broad roles or embedded secrets are common sources of compromise; audit roles regularly.

VPC trade-offs

Configure subnets and security groups when your function needs access to private resources like RDS. Be aware that ENI creation can add cold-start latency, so enable VPC access only when required.

Checklist
  • Only enable VPC if necessary
  • Specify small, appropriate subnet sets and secure SGs
  • Consider provisioned concurrency if latency is critical
