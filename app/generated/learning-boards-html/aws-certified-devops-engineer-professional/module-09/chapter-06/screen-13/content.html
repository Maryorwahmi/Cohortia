Timeline

Troubleshooting steps

  1. Reproduce with a test event similar to production.
  2. Inspect CloudWatch Logs to see the exact event and error traces.
  3. Check CloudWatch Metrics: errors, duration, throttles, concurrency.
  4. Review the execution role for missing permissions.
  5. For performance, profile cold starts and memory usage; consider provisioned concurrency or resizing.
Alerting on errors and duration spikes helps you catch regressions early.
Observability cards
Structured logs

Emit JSON logs to simplify search and analysis in CloudWatch Logs Insights.

Metrics & alarms

Create alarms for error rate thresholds and duration increases to trigger investigations.

Common Mistake

Relying solely on console tests instead of validating with actual production events and logs.

Key Takeaway

Combine logs, metrics, and alerts to quickly isolate permission, payload, and performance problems in production.
