How Lambda is invoked

Different services act as triggers and produce different invocation patterns and payloads.

  1. API Gateway (sync) — request/response, map headers and status codes.
  2. S3 (async) — object-created events with bucket and key metadata.
  3. SQS / SNS (async) — message-based, handle retries and idempotency.
  4. DynamoDB Streams / Kinesis — ordered stream processing and checkpointing.
  5. EventBridge / CloudWatch Events — scheduled or routed events.
Design question: what retry and ordering guarantees does your trigger provide, and how will your handler ensure idempotency?
Examples & Cards
API Gateway

Use for building HTTP APIs. Configure integration type and map responses.

SQS

Batch delivery to Lambda. Ensure idempotency and handle partial failures if processing multiple messages.

DynamoDB Streams

Good for change-data-capture; preserve ordering if your business rules depend on it.

Common Mistake

Treating all triggers the same. Retry behavior and payload structure differ across services.
