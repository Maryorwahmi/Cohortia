Module 9 › Chapter 9.6 › Create a Python Lambda
Process

Console steps

  1. Lambda → Create function → Author from scratch; name and select Python 3.9.
  2. Choose execution role: Create new role with basic Lambda permissions.
  3. Replace lambda_function.py with the handler code and Deploy.
  4. Add API Gateway trigger, choose REST API, open security, new stage dev, Add.
  5. Open the endpoint URL to test and append ?name=Cohortia for a custom greeting.
Remember: grant CloudWatch Logs permission and Deploy after code changes.
Example code
import json

def lambda_handler(event, context):
    # Log the event for debugging purposes
    print("Received event: " + json.dumps(event, indent=2))

    # Extract name from query parameters or path parameters, default to 'World'
    name = "World"
    if event.get('queryStringParameters') and 'name' in event['queryStringParameters']:
        name = event['queryStringParameters']['name']
    elif event.get('pathParameters') and 'name' in event['pathParameters']:
        name = event['pathParameters']['name']
    elif event.get('body'):
        try:
            body = json.loads(event['body'])
            if 'name' in body:
                name = body['name']
        except json.JSONDecodeError:
            pass

    message = f"Hello, {name} from Lambda!"

    return {
        'statusCode': 200,
        'headers': {
            'Content-Type': 'application/json'
        },
        'body': json.dumps({'message': message})
    }
Key Takeaway

A small handler plus a properly configured role and trigger yields a public API endpoint quickly from the console.
