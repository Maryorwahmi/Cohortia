Definition

Lambda execution model

Packaging, runtime, environment lifecycle, memory, CPU, and role determine how functions run and scale.

Packaging options

Zip packages or container images. Use layers for shared dependencies to reduce package size and cold starts.

Runtimes

Choose a runtime that matches your language and performance needs. Lighter runtimes often cold-start faster.

Memory and CPU

Memory allocation affects billing and the amount of CPU available, a key tuning parameter for performance.

Key Takeaway

Packaging, runtime, and memory choices directly affect cold starts, latency, and cost.

Architecture Snapshot
Environment lifecycle

Cold start: environment init. Warm start: reuse. Environments are discarded after inactivity.

Concurrency mapping

Each concurrent invocation runs in its own environment. Reserved concurrency limits or guarantees capacity.

Security

Attach an execution role with least privilege. Never hardcode credentials; use secret stores instead.
