Module 9 › Chapter 9.6 › Key Concepts
Serverless Computing

Provider-managed servers; pay per execution time.

AWS Lambda

Runs your code in response to events with managed execution environments.

Triggers

API Gateway, S3, SQS, SNS, Streams, and EventBridge each have different semantics.

Summary

Combine these concepts when designing serverless applications: choose appropriate triggers, make handlers idempotent, secure roles and secrets, and monitor with logs and metrics.
