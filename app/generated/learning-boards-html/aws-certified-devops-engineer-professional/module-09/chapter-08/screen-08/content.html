Module 9 › Chapter 9.8 › Lambda versions and aliases
Concepts
Publish an immutable version of your function code. Use aliases to reference versions and to shift production traffic safely.
Version
Immutable snapshot of code and configuration with its own ARN.
Alias
A pointer to a specific version that clients can invoke using a stable name.
Key Takeaway

Always publish versions and update aliases for production traffic so rollbacks remain predictable and auditable.

SAM template example
MyApiFunction:
  Type: AWS::Serverless::Function
  Properties:
    Handler: app.lambda_handler
    Runtime: python3.9
    CodeUri: ./my_api_function
    AutoPublishAlias: Live
    DeploymentPreference:
      Type: Canary10Percent5Minutes
      Alarms:
        - !GetAtt MyApiFunctionErrorsAlarm.Arn
        - !GetAtt MyApiFunctionInvocationsAlarm.Arn
This snippet demonstrates AutoPublishAlias and a canary deployment preference that ties into CloudWatch alarms to determine health during rollout.
