Module 9 › Chapter 9.8 › Build stage: sam build, packaging, and artifacts
Build stage responsibilities
  • • Run sam build or cdk synth to assemble code and dependencies.
  • • Run unit tests to provide fast feedback and fail fast.
  • • Package artifacts with sam package into S3 and produce packaged.yaml.
  • • Produce build artifacts for deploy stage: packaged template and zipped function code.
Common mistake
Packaging after tests fail wastes time. Run unit tests before packaging and uploading artifacts.
Example buildspec.yaml
version: 0.2
phases:
  install:
    runtime-versions:
      python: 3.9
    commands:
      - pip install aws-sam-cli
  build:
    commands:
      - echo "Building SAM application..."
      - sam build --template template.yaml --build-dir .aws-sam/build
      - sam package --template-file .aws-sam/build/template.yaml --s3-bucket <YOUR_ARTIFACT_BUCKET_NAME> --output-template-file packaged.yaml
  post_build:
    commands:
      - echo "Build and package complete."
artifacts:
  files:
    - packaged.yaml
Key Takeaway

Keep tests before packaging and ensure CodeBuild roles can write to the artifact S3 bucket so deploys reference correct artifacts.
