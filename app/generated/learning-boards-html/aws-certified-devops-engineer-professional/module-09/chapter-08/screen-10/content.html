Module 9 › Chapter 9.8 › SAM template updates for CodeDeploy integration
What AutoPublishAlias and DeploymentPreference do
  • • AutoPublishAlias publishes an immutable version and points an alias at it.
  • • DeploymentPreference instructs CodeDeploy to perform canary or linear traffic shifting and to monitor specified alarms.
  • • Hooks let you run validation functions before or after traffic is shifted.
Common mistake

Not attaching alarms to DeploymentPreference removes automated safety checks and forces manual monitoring during a canary.

Template example (excerpt)
MyApiFunction:
  Type: AWS::Serverless::Function
  Properties:
    Handler: app.lambda_handler
    Runtime: python3.9
    CodeUri: ./my_api_function
    AutoPublishAlias: Live
    DeploymentPreference:
      Type: Canary10Percent5Minutes
      Hooks:
        PreTrafficHook: !Ref PreTrafficLambdaFunction
        PostTrafficHook: !Ref PostTrafficLambdaFunction
      Alarms:
        - !GetAtt MyApiFunctionErrorsAlarm.Arn
        - !GetAtt MyApiFunctionInvocationsAlarm.Arn
This configuration lets SAM and CodeDeploy coordinate to publish a version, run optional hooks, and shift traffic while checking alarms.
