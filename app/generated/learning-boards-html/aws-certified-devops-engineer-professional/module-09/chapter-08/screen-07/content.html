Module 9 › Chapter 9.8 › Observability: CloudWatch Logs, Metrics, and X-Ray
Logging and metrics
Structured logs in CloudWatch and default Lambda metrics are your first line of observability. Create dashboards and alarms on Errors, Duration, and Throttles.
CloudWatch Logs
Emit JSON logs with request IDs, input event, and error context for faster querying.
CloudWatch Metrics
Use built-in metrics and create alarms to detect and react to failures during canary deploys.
Tracing with X-Ray
X-Ray shows the request path across API Gateway, Lambda, DynamoDB, and other services, letting you find bottlenecks and error origins.
Example
A trace shows that the second Lambda call waits on a slow DynamoDB query. Correlate trace ID and logs to see the exact request payload and timing.
Pro Tip

Use the same CloudWatch alarms for both operational alerts and deployment health checks so rollback decisions use production-grade signals.
