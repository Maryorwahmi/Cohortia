Module 9 › Chapter 9.8 › Deployment hooks and alarms
Lifecycle hooks
Pre-traffic hooks let you run checks against the new version before traffic shifts. Post-traffic hooks validate after full or partial traffic shift. Hooks use the CodeDeploy lifecycle API to report success or failure.
Example hook behavior
A pre-traffic hook runs a small integration test. If it succeeds, it signals CodeDeploy to continue. If it fails, CodeDeploy stops the rollout and the alias remains pointed at the old version.
CloudWatch alarms
Attach high-signal alarms to DeploymentPreference, such as an Errors alarm (threshold zero) or an Invocations alarm that detects drops in traffic. CodeDeploy evaluates these alarms during the canary window.
Common mistake

Relying on verbose or noisy alarms can cause false rollbacks. Choose alarms that directly indicate degraded user experience.
