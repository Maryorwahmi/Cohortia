Module 9 › Chapter 9.8 › Serverless CI/CD pipeline stages
Process Overview
Each stage produces specific artifacts and validation to protect production.
Source
SAM/CDK code and Lambda handlers stored in Git. Commits produce a source artifact.
Build
Run sam build or cdk synth, run unit tests, and package artifacts to S3 for later deployment.
Test
Integration and end-to-end tests run against a staging deploy to validate service interactions.
Deploy
CloudFormation/CodeDeploy update stacks, publish versions, and update aliases for safe rollouts.
Diagram: stage artifacts

CloudFormation stack updates, versions published, alias adjusted
Key Takeaway

Design the pipeline so artifacts are immutable and tests run at the stage that gives the best trade-off between speed and confidence.
