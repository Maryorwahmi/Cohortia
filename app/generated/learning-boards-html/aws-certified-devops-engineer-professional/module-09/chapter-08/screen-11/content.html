Module 9 › Chapter 9.8 › Create CodePipeline and CodeBuild for SAM apps
Pipeline steps (practical)
  1. Source: GitHub or CodeCommit repository, branch selection.
  2. Build: CodeBuild project runs buildspec to build, test, and package.
  3. Test: optional separate integration tests against staging deploy.
  4. Deploy: CloudFormation action uses packaged.yaml and CodeDeploy for canaries.
Remember to choose the CloudFormation execution role with permissions to create/update all resources your SAM template defines. Also select a CodeDeploy deployment config such as CodeDeployDefault.LambdaCanary10Percent5Minutes if you want canary behavior to match your DeploymentPreference.
Checklist for roles and artifacts
  • • CodeBuild service role can write artifacts to S3 and run sam commands.
  • • CloudFormation execution role can create/update Lambda, API Gateway, DynamoDB, CloudWatch, CodeDeploy.
  • • CodeDeploy role can manage alias updates and monitor alarms.
Key Takeaway

Use a clear artifact flow from CodeBuild to CloudFormation and limit each service role to least-privilege to reduce blast radius in case of misconfiguration.
