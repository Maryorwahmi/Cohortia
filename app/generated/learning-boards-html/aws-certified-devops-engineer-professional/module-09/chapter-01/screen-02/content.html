01
Explain containerization

Describe portability, isolation, consistency, and why containers avoid the "works on my machine" problem. You will connect the definition to everyday deployment issues.

Mnemonic: Venn of portability + isolation

02
Understand Docker components

Explain images as blueprints, containers as running instances, and the Docker Engine's daemon, API, and CLI that build and run those images.

Mnemonic: Image → Container → Engine
VERIFIED COMPETENCY MILESTONE
03
Run basic Docker commands

Use commands to confirm installation, pull and run the hello-world image, list containers, stop and remove containers for local experimentation and debugging.

Mnemonic: verify → run → list → cleanup
VERIFIED COMPETENCY MILESTONE
04
Create and optimize Dockerfiles

Author a Dockerfile, understand layered builds and caching, and apply best practices like using .dockerignore, ordering COPY and RUN, and avoiding large base images.

Mnemonic: small base + cached layers
