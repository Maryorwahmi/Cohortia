Module 9 › Chapter 9.1 › Build & Run
Commands
docker build -t my-flask-app .
docker run -p 8080:80 my-flask-app
The -t flag tags the image; the final dot sets the build context. The -p hostPort:containerPort flag maps a host port to the container port so a browser can reach the app.
Example verification

After running with port mapping, open http://localhost:8080 to see the Flask app greeting. If nothing appears, check container logs for errors and confirm the container exposes the expected port in the Dockerfile.

Common mistake
Forgetting to expose or map the correct port prevents the host from reaching the service even if the container is healthy.
Key Takeaway

Tag images meaningfully and map ports intentionally so local testing mirrors production network expectations.
