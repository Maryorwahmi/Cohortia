Module 9 › Chapter 9.1 › AWS Container Services
Amazon ECR
A fully managed Docker registry for storing and versioning images. Use ECR to keep images close to your deployment infrastructure and integrate with CI/CD systems.
Amazon ECS
A scalable container orchestrator that runs Docker containers. Choose EC2 launch type to manage instances, or Fargate to run containers serverlessly.
Amazon EKS
A managed Kubernetes control plane for teams wanting Kubernetes APIs and portability across environments. EKS runs your Kubernetes control plane and integrates with other AWS services.
Choosing a service
  • Use ECR to store and manage images.
  • Use ECS for AWS-native orchestration; prefer Fargate to avoid server management.
  • Choose EKS if you require Kubernetes features or team familiarity with Kubernetes.
Key Takeaway

ECR stores images; ECS or EKS run them. Fargate reduces operational overhead by removing server provisioning.
