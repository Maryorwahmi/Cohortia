Module 9 › Chapter 9.1 › Docker Commands Demo
Terminal commands
docker --version
docker run hello-world
docker ps
docker ps -a
docker stop <container_id>
docker rm <container_id>
Explanation
  • docker --version confirms the client and basic connectivity.
  • docker run hello-world pulls the image if needed and runs it to confirm the runtime.
  • docker ps lists running containers. Add -a to see stopped ones.
  • docker stop and docker rm manage lifecycle and clean up.
Pro tip

Script these commands in CI to ensure ephemeral test containers are removed after tests complete.

What you will see
When the hello-world container runs successfully, the output confirms the Engine pulled the image and executed it. Use ps to find the container id, stop it by id, then remove it. If image pulls fail, confirm network access and Docker Hub availability.
Common mistake
Not removing stopped containers and dangling images can fill disk space. Use cleanup commands periodically in local and CI environments.
Key Takeaway

Master the verify-run-list-stop-remove cycle to develop confidence running containers locally.
