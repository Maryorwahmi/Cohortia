Module 9 › Chapter 9.3 › CLI Steps
Essential commands
# create cluster
aws ecs create-cluster --cluster-name my-nginx-fargate-cluster --region us-east-1

# create ALB (note subnets and security groups)
aws elbv2 create-load-balancer --name my-nginx-alb --subnets SUBNET1 SUBNET2 --security-groups ALB_SG --scheme internet-facing --type application --region us-east-1

# create target group (target-type ip)
aws elbv2 create-target-group --name my-nginx-tg --protocol HTTP --port 80 --vpc-id VPC_ID --target-type ip --health-check-path / --region us-east-1

# register task definition
aws ecs register-task-definition --cli-input-json file://nginx-task-def.json --region us-east-1

# create service
aws ecs create-service --cli-input-json file://nginx-service.json --region us-east-1
Verification tips
  • Use describe-load-balancers to get the ALB DNS name.
  • Use describe-target-groups to confirm TargetGroupArn and health.
  • Check tasks and service status with describe-services and describe-tasks.
Common troubleshooting: If you see CannotPullContainerError: AccessDeniedException, inspect ecsTaskExecutionRole permissions for ECR access.
