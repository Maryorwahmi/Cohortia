Minimal Fargate task definition (JSON)
{
  "family": "my-web-app-task-def",
  "networkMode": "awsvpc",
  "cpu": "256",
  "memory": "512",
  "executionRoleArn": "arn:aws:iam::YOUR_ACCOUNT_ID:role/ecsTaskExecutionRole",
  "containerDefinitions": [
    {
      "name": "my-web-app-container",
      "image": "YOUR_ACCOUNT_ID.dkr.ecr.us-east-1.amazonaws.com/my-web-app:latest",
      "portMappings": [ { "containerPort": 80, "protocol": "tcp" } ],
      "essential": true,
      "logConfiguration": {
        "logDriver": "awslogs",
        "options": {
          "awslogs-group": "/ecs/my-web-app",
          "awslogs-region": "us-east-1",
          "awslogs-stream-prefix": "ecs"
        }
      }
    }
  ],
  "requiresCompatibilities": ["FARGATE"]
}
Field explanations
  • requiresCompatibilities: set to FARGATE for serverless tasks.
  • networkMode: awsvpc assigns ENIs to tasks and is required for Fargate.
  • executionRoleArn: grants ECS permissions to pull images and write logs.
  • logConfiguration: enables CloudWatch logs for troubleshooting.
Tip: replace placeholder ARN and image URI with your account values before registering.
Key Takeaway
Author task definitions carefully: missing execution role or logs will break startup or make debugging difficult.
