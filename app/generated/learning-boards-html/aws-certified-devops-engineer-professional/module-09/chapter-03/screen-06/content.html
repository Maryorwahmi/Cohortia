Deployment steps (process)
1. Create Fargate cluster
Name it, then use it when creating services.
2. Register Task Definition
Specify awsvpc, ecsTaskExecutionRole, image URI, CPU, memory, and port mappings.
3. Create ALB & Target Group
Target type: ip, health check path: /. Configure listener on port 80.
4. Create Service
Choose task definition and attach ALB target group. Set desired count.
5. Configure Auto-Scaling
Use CPU or custom metrics, set scale-out and scale-in thresholds.
Example verification checklist
  • Tasks move to RUNNING state.
  • Target group shows healthy targets.
  • ALB DNS returns the application page.
  • CloudWatch logs show container startup messages.
Common mistake
Forgetting to allow traffic between ALB and task security groups will prevent successful HTTP responses even when tasks are healthy.
