Module 9 › Chapter 9.3 › Launch Type Comparison
EC2 Launch Type
You manage the instances. Use custom AMIs, tune the OS, and utilize Spot or Reserved Instances for cost control.
  • Full node control and customization.
  • Operational overhead: patching, scaling, and instance lifecycle.
  • Best for predictable, long-running workloads.
When to pick EC2: need host-level access or custom drivers.
Fargate Launch Type
Serverless compute for containers. Specify resources per task and let AWS provision and maintain the infrastructure.
  • No EC2 instance management required.
  • Pay for CPU and memory consumed by tasks.
  • Ideal for variable or unpredictable workloads.
When to pick Fargate: reduce ops, faster deployments, serverless billing.
Misconception
Fargate is always more expensive. Evaluate total cost including operational time and utilization.
Pro tip
Prototype on Fargate for speed, then evaluate EC2 if you need host customizations or long-term cost optimizations.
Check
Confirm your workload's network and dependency requirements before choosing the launch type.
