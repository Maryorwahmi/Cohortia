Module 9 › Chapter 9.3 › Lab: Nginx to Fargate
Lab checklist
  • Confirm ECR image and ecsTaskExecutionRole exist.
  • Create cluster and ALB with target group.
  • Register task definition, create service with network config.
  • Verify ALB DNS returns the Nginx page.
  • Clean up: delete service, cluster, and ALB resources.
Clean-up commands (examples)
# delete service
aws ecs update-service --cluster my-nginx-fargate-cluster --service nginx-fargate-service --desired-count 0
aws ecs delete-service --cluster my-nginx-fargate-cluster --service nginx-fargate-service

# delete cluster
aws ecs delete-cluster --cluster my-nginx-fargate-cluster

# remove ALB resources: delete listener, target group, then load balancer
aws elbv2 delete-listener --listener-arn LISTENER_ARN
aws elbv2 delete-target-group --target-group-arn TG_ARN
aws elbv2 delete-load-balancer --load-balancer-arn ALB_ARN
