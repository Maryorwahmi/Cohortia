Module 9 › Chapter 9.3 › ECS Components
Definitions
Clear definitions reduce deployment mistakes. Read these before authoring a task definition or creating a service.
Cluster
Logical grouping of tasks and services. Can be backed by EC2 or Fargate.
Task Definition
Blueprint describing containers, resources, ports, network mode, and execution role.
Task
A running instantiation of a task definition.
Service
Maintains a desired number of tasks and integrates with load balancers.
Practical example
Imagine you register a task definition named my-web-app-task-def. When you create a service using that definition and set desired tasks to 2, ECS will run two task instances of that definition inside your cluster. If a task fails health checks, the service replaces it.
Key Takeaway
Know which artifact is a definition, which is a running instance, and which object manages availability.
Common mistake
Confusing task definition with a running task; updating a task definition alone does not change running tasks until the service is updated.
