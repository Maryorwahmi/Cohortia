Module 9 › Chapter 9.3 › ALB & Target Groups
Architecture summary
ALB routes incoming requests to the target group. For Fargate use target type ip so task ENIs are reachable by the ALB.
ALB Listener (HTTP 80)
Target Group (target-type: ip)
Fargate Tasks with ENIs and container port 80
Configuration checklist
  • Target group health check path set to application health endpoint.
  • Task security group allows inbound traffic from ALB security group on container port.
  • ALB registered in at least two subnets for high availability.
Common issue: health checks mispointed to a path that returns non-200 responses.
Key Takeaway
Verify security groups, health check path, and that target type is ip when using Fargate.
