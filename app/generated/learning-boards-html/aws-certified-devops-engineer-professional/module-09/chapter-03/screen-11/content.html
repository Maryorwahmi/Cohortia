Module 9 › Chapter 9.3 › Troubleshooting
Diagnose failures
  1. Check stoppedReason in describe-tasks and CloudWatch logs.
  2. Verify ecsTaskExecutionRole has ECR and CloudWatch logs permissions.
  3. Confirm ALB and task security groups allow necessary traffic.
  4. Ensure subnets have free IPs for awsvpc ENIs.
Concrete example
If CloudWatch shows CannotPullContainerError: AccessDeniedException, inspect the ecsTaskExecutionRole. The task execution role is responsible for pulling images and writing logs; missing permissions here cause immediate task failures.
Pro tip: keep separate task roles for application permissions and minimize privileges on the execution role to follow least privilege.
