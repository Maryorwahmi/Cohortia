Console steps to deploy
  • Create a Fargate cluster and name it.
  • Register a task definition with awsvpc and ecsTaskExecutionRole.
  • Create a service, attach ALB, and set desired count.
  • Configure health checks and autoscaling.

CLI quick checklist
  • Create cluster with aws ecs create-cluster.
  • Register task definition using register-task-definition with JSON.
  • Create ALB, target group, listener, then create-service referencing target group.
  • Verify with describe-services and describe-tasks.
VERIFIED COMPETENCY MILESTONE
Safety reminder
Grant ecsTaskExecutionRole only the permissions required to pull images and write logs. Use task-specific roles for additional application permissions.
Verification
Confirm ALB DNS returns the expected page and target group health checks pass before declaring the deployment healthy.
