Process Flow › SAM CLI workflow
Steps
1. Initialize or prepare project
Create template.yaml and the function code directory structure.
2. Build
Run sam build to package dependencies and create a .aws-sam artifact directory ready for deployment.
3. Deploy guided
Run sam deploy --guided to select stack name, region, and let SAM upload artifacts and create a CloudFormation stack.
Terminal examples
sam init --runtime python3.9 --name my-serverless-app sam build sam deploy --guided
Key Takeaway

SAM produces CloudFormation stacks; monitor stack events to understand resource creation and failures.
