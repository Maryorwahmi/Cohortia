Architecture › Service Integrations
Integration cards
API Gateway
Use Api events in SAM or LambdaRestApi in CDK to expose HTTP endpoints that trigger Lambda functions.
DynamoDB
Declare the table and grant read-write permissions; pass the table name via environment variables to the function.
SQS
Declare a queue and wire it as an event source so Lambda processes messages reliably.
Policy & permissions
In SAM use managed policy snippets like DynamoDBReadWritePolicy. In CDK call table.grant_read_write_data(function) to grant least-privilege access. Avoid wildcard permissions that expose more than needed.
