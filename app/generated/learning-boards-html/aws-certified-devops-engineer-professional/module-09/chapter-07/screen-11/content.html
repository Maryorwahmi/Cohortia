Mistake checklist
IAM Permissions
Ensure your function role includes exactly the actions needed for DynamoDB, SQS, or other services.
Environment variables
Pass resource names and configuration via environment variables in the template or stack.
CodeUri path
Validate that the path to your function code is correct before building and deploying.
Debugging tips
When a deploy fails, open the CloudFormation stack events to find the failing resource. For runtime access errors, check the function's execution role. For local differences, compare logs from sam local and CloudWatch after deployment.
Pro tip

Keep a short deploy checklist in your repo: policies, env vars, CodeUri, and a smoke-test curl command for the API endpoint.
