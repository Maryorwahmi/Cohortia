Module 9 › Chapter 9.7 › Learning Objectives (cont.)
Local testing skills
You will use sam local invoke with a synthetic event and sam local start-api to exercise HTTP endpoints locally. Practice creating an event.json for POST requests and confirm behavior with curl. Attach a debugger when you need to step through function logic.
Integration and configuration
Define DynamoDB tables and SQS queues in your template or CDK stack. Grant permissions via SAM policies or CDK grants and pass resource names to Lambda through environment variables so runtime code is environment-agnostic.
Hands-on objective
Follow the provided steps to create the project directory, add template.yaml and app.py, run sam build, sam deploy --guided, and verify the generated API endpoint with POST and GET requests.
Assessment practice
Prepare to explain why you would select CDK for programmatic reuse or SAM for concise serverless templates. Be ready to identify the SAM CLI commands for local testing and the common IAM and configuration pitfalls.
