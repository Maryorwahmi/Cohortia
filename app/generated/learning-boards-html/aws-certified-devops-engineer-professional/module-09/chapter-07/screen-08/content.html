Process Flow › Local Testing & Debugging
Key commands
sam local invoke
Invoke a function with an event file to validate logic and return values.
sam local start-api
Start a local HTTP server that emulates API Gateway so curl or a browser can hit your endpoints.
Example event.json and curl
{ "httpMethod": "POST", "path": "/items", "body": "{\"id\": \"item-local\", \"data\": \"local-value\"}" } # After starting local API # curl -X POST -H 'Content-Type: application/json' -d '{"id":"item-local","data":"local-value"}' http://127.0.0.1:3000/items # curl http://127.0.0.1:3000/items
Warning

Local emulation cannot perfectly replicate IAM contexts and managed service nuances; always run a deployed integration test before trusting production behavior.
