Module 9 › Chapter 9.2 › ECR lifecycle policies
Definition

Automated image lifecycle management

Write rules that select images by tag status, age, or count and expire them automatically to control storage and clutter.

Rule types

Common rules: expire untagged images older than N days, keep only the latest M images for a tag prefix.

Why test

Apply lifecycle policies first to non-production repos to verify they match intended retention before applying to critical registries.

Example scenarios
  • • Keep only the five most recent production images tagged with prod- prefix.
  • • Expire untagged images older than 90 days to remove orphaned layers.
  • • Keep more images for release branches and fewer for feature branches.
Key Takeaway

Use lifecycle rules to enforce retention policies that match your release strategy and reduce storage costs.
