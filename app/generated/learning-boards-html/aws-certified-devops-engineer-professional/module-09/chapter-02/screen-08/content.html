Module 9 › Chapter 9.2 › Pulling and verifying images
Process Flow

Pull to verify published images

Pull an image after push to validate availability and then run it locally or in a test environment.

Command (example)
docker pull <YOUR_ACCOUNT_ID>.dkr.ecr.us-east-1.amazonaws.com/my-web-app:latest
If the pull succeeds, run the image locally or in a test cluster to confirm expected runtime behavior.
Concrete check

Pull and run the image, then compare logs and responses with local expectations to confirm correctness.

Security note

A successful push does not equal a safe image — review scan results before deployment.

Permissions for pulls

Ensure the pulling principal has ecr:BatchGetImage and ecr:GetDownloadUrlForLayer permissions. For automated pulls in deploy stages, grant these to the deployment role only.

Key Takeaway

Use docker pull to validate that pushed images are available and use scan results to decide if a deployment should proceed.
