Module 9 › Chapter 9.2 › Create an ECR repository
Process Flow

Create repository with CLI

Decide mutability and whether to enable scanOnPush, then run the CLI command and note the repository URI.

Command (example)
aws ecr create-repository \
    --repository-name my-web-app \
    --image-tag-mutability MUTABLE \
    --image-scanning-configuration scanOnPush=true \
    --region us-east-1
Note the repositoryUri in the command output — it is required when tagging images before pushing.
Example decision

Use MUTABLE in development for fast iteration; prefer IMMUTABLE for production releases to prevent accidental overwrites.

Common mistake

Creating the repository in the wrong region or forgetting to record the repositoryUri will block later push steps.

Verification

After running the command, open the ECR console in the same region, locate my-web-app, and confirm scanOnPush and tag mutability settings.

Why it matters
  • • Mutability affects deployments and repeatability.
  • • scanOnPush provides early vulnerability detection as part of your pipeline.
  • • Repository URI is the canonical address for pushing images.
Key Takeaway

Create repositories with the right mutability and scanning settings to match your development and production needs.
