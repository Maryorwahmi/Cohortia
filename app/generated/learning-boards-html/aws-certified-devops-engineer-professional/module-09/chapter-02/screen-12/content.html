Module 9 › Chapter 9.2 › Apply lifecycle policy
Process

Attach lifecycle policy via CLI

Save the JSON to a file and use put-lifecycle-policy to apply it to the repository, then verify in the console.

Command (example)
aws ecr put-lifecycle-policy \
    --repository-name my-web-app \
    --lifecycle-policy-text file://my-lifecycle-policy.json \
    --region us-east-1
Confirm the JSON file path and that the repositoryName matches the target repository. The command returns the policy text on success.
Verification

Open the ECR console and check the repository's lifecycle policy tab to ensure rules are present.

Pitfall

Incorrect file URI or malformed JSON will cause the CLI to fail; validate JSON formatting first.

Automation tip

Include lifecycle policy application in repository provisioning templates so repositories start with standard retention rules.

Key Takeaway

Apply lifecycle policies with the CLI and verify in the console so retention behaves as expected across repositories.
