Architecture

Build, push, scan, deploy

A typical pipeline: CI builds an image, pushes to ECR, ECR scans on push, and deploy stages pull the image for ECS or EKS.

Build stage

Builds the container image and uses an IAM role that can authenticate and push to ECR.

ECR (push & scan)

Receives the pushed image, scans on push if enabled, and stores the image for consumption by deploy stages.

Deploy stage

Pulls the approved image using a role with pull permissions and deploys to runtime environments.

Security integration

Image scanning surfaces vulnerabilities early. Decide whether scan findings block promotion to production, then encode that logic into the pipeline gating steps.

Key Takeaway

Integrate ECR with CI/CD: let builds push, enable scanning on push, and gate deployments on scan and policy checks to keep releases safe.
