Module 9 › Chapter 9.2 › What is Amazon ECR?
Core Concept

Amazon ECR — private, managed registry

ECR stores Docker images privately and integrates with IAM and AWS services for secure, automated workflows.

Why it matters

Managed scaling, private access, and native AWS integrations reduce operational and security overhead.

Concrete example

A CI job builds a web image, pushes it to ECR, and a deployment pipeline pulls the image for ECS.

Common misconception

ECR is not just storage; it enforces access and integrates with CI/CD and security tooling.

Key Takeaway

Treat ECR as the secure image hub for your AWS-based pipelines and enforce access through IAM roles and policies.

Analogy
Analogy: Private artifact warehouse

Imagine a private warehouse where only authorized teams can store or retrieve build artifacts. ECR is that warehouse for container images, with access controls and automated inspections.

Quick list — ECR features
  • • Private by default, integrated with IAM
  • • Managed infrastructure: scaling and availability
  • • Lifecycle policies for cleanup
  • • Image scanning integration with Amazon Inspector
