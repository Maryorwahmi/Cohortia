Learning Objectives

Learn, understand, apply, and prepare to master ECR workflows.

Bloom: Learn → Understand → Apply → Master
01
ECR role
Explain ECR as a private registry

Describe how ECR stores images privately and integrates with IAM to control access.

VERIFIED COMPETENCY MILESTONE
02
Authentication
Authenticate Docker CLI to ECR

Use the AWS CLI token with docker login via password standard input and explain token lifetime and security considerations.

VERIFIED COMPETENCY MILESTONE
03
Image flow
Push and pull images

Tag a local image with the repository URI and push it, then pull to verify the published image.

VERIFIED COMPETENCY MILESTONE
04
Governance
Configure lifecycle policies

Create rules to expire untagged or older images to control storage and image sprawl.
