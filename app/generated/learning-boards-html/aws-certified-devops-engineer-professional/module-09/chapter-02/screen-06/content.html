Module 9 › Chapter 9.2 › Authenticate Docker to ECR
Definition

Secure Docker authentication

Use the AWS CLI to get a short-lived auth token and pipe it into docker login to avoid exposing credentials.

Command (example)
aws ecr get-login-password --region us-east-1 | docker login --username AWS --password-stdin <YOUR_ACCOUNT_ID>.dkr.ecr.us-east-1.amazonaws.com
Expected output: "Login Succeeded" if credentials and region are correct. Remember to replace the account ID and region with your values.
Example

CI job runs the AWS CLI with a role, pipes the token into docker login, then tags and pushes the built image.

Common mistake

Using inline password arguments or echoing the token can leak credentials in shell history or logs.

Token lifetime and automation

The login token is short-lived. For automation prefer IAM roles attached to build agents or ephemeral credentials refreshed by the CI system.

Checklist before authenticating
  • • Ensure AWS CLI is configured with credentials and correct region.
  • • Use the repository URI that matches the region.
  • • Avoid exposing the token in logs or shell history.
Key Takeaway

Pipe the AWS CLI password into docker login to authenticate securely and rely on CI roles for automation.
