Amazon ECR
A fully managed, private Docker registry integrated with IAM for access control.
Push and Pull
Authenticate with AWS CLI token, tag images with repository URI, then push and pull to publish and verify.
Lifecycle Policies
Rules that expire images by age or count to manage storage and reduce image sprawl.
Summary

Use ECR as a secure, managed image hub, authenticate safely, automate retention, and integrate scanning into your CI/CD pipeline.
