Comparison

Push failures vs Pull failures

Push failures
  • • Missing GetAuthorizationToken or PutImage permissions
  • • Wrong region or repository URI
  • • Token expired before push completes
Pull failures
  • • Missing BatchGetImage or GetDownloadUrlForLayer permissions
  • • Image not pushed to expected repository/tag
  • • Region mismatch between CLI and repository
Required ECR actions
  • • For push: ecr:GetAuthorizationToken, ecr:BatchCheckLayerAvailability, ecr:InitiateLayerUpload, ecr:UploadLayerPart, ecr:CompleteLayerUpload, ecr:PutImage
  • • For pull: ecr:BatchGetImage, ecr:GetDownloadUrlForLayer
Best practice

Create least-privilege IAM policies for CI roles: give build roles push rights and deployment roles pull rights only.

Key Takeaway

Check region, repositoryUri, and specific ECR actions to prevent most push and pull failures.
