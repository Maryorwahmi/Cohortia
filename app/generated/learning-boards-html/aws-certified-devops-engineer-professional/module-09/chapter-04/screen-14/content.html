Module 9 › Chapter 9.4 › Key Concepts
Amazon EKS
AWS-managed Kubernetes control plane that reduces operational overhead for API and etcd maintenance.
eksctl
CLI tool that creates clusters declaratively using a YAML file and automates CloudFormation provisioning.
IRSA
Assign IAM roles to Kubernetes Service Accounts so Pods have least-privilege access to AWS services.
Summary Takeaway

Use eksctl for repeatable cluster creation, validate with kubectl, and secure Pod access with IRSA while planning networking and cost strategies for worker nodes.
