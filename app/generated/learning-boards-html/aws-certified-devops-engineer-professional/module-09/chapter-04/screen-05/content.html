Module 9 › Chapter 9.4 › Cluster Creation
Step-by-step
  1. Install eksctl and kubectl following platform documentation.
  2. Create a cluster YAML that defines metadata and managed node groups.
  3. Run eksctl create cluster -f cluster.yaml and wait for resources to provision.
  4. Confirm with kubectl get nodes and kubectl get svc -n kube-system.
Common mistake

Not setting the correct region or version in cluster YAML leads to failed or mislocated clusters. Validate the YAML before creation.

Example cluster.yaml
apiVersion: eksctl.io/v1alpha5
kind: ClusterConfig

metadata:
  name: my-eks-cluster
  region: us-east-1
  version: "1.28"

managedNodeGroups:
- name: ng-1
  instanceType: t3.medium
  minSize: 2
  maxSize: 3
  desiredCapacity: 2
  volumeSize: 20
  ssh:
    allow: true
    publicKeyName: my-key-pair
Run: eksctl create cluster -f cluster.yaml. The command orchestrates CloudFormation to build the control plane, VPC, subnets, security groups, and node groups. Expect 15–20 minutes in a typical account.
