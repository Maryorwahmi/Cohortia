Module 9 › Chapter 9.4 › Learning Objectives
01
Understand EKS architecture and core Kubernetes components

Form a clear model of the managed control plane, worker nodes, Pods, Services, and Deployments so you can reason about availability and responsibility.

Mnemonic: three-tier sketch — control plane, nodes, pods
VERIFIED COMPETENCY MILESTONE
02
Create an EKS cluster using eksctl or CloudFormation

Understand cluster config fields like region, Kubernetes version, and managed node group settings so creation is repeatable and auditable.

Mnemonic: YAML template + single CLI command
VERIFIED COMPETENCY MILESTONE
03
Deploy and manage applications with kubectl and manifests

Write Deployment and Service manifests, apply them, and interpret kubectl status outputs to validate your application state.

Mnemonic: manifest -> apply -> verify
VERIFIED COMPETENCY MILESTONE
04
Integrate EKS securely with AWS services

Use IAM Roles for Service Accounts for least privilege, understand VPC CNI addressing, and choose the correct load balancer approach for HTTP traffic.

Mnemonic: one role per service account
VERIFIED COMPETENCY MILESTONE
