Module 9 › Chapter 9.4 › VPC CNI & Networking
How it works
The VPC CNI assigns Pod IP addresses from your VPC so Pods behave like first-class network endpoints. This eases communication with RDS, ElastiCache, and other VPC services because security groups and routing work as expected.
Pitfall
IP exhaustion can occur if you choose instance types without enough ENI or IP address capacity for the expected pod density.
Mitigation and checks
  • Pick instance types with adequate ENI/IP limits for pod density.
  • Use CNI configurations like prefix delegation where appropriate.
  • Inspect CNI logs and verify Pod IP assignments during scaling tests.
