Module 9 › Chapter 9.4 › kubectl Verification
Essential commands
kubectl get nodes — lists worker nodes and Ready status.
kubectl get svc -n kube-system — checks system services like CoreDNS.
kubectl config get-contexts — shows current kubectl context.
kubectl describe node <name> — inspects node conditions and events.
Common troubleshooting step
If nodes are NotReady, verify node IAM permissions and VPC CNI logs on the node before assuming Kubernetes control plane issues.
Terminal examples
# list nodes
kubectl get nodes

# check system services
kubectl get svc -n kube-system

# describe a node for events
kubectl describe node <node-name>
Run these commands after cluster creation. They provide the most direct signals about node health and whether system controllers are running correctly.
