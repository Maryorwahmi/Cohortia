Comparison

Blue/Green: ECS vs EKS

Both run parallel environments; traffic is shifted to the new version once validated.

ECS: CodeDeploy creates a Green task set and shifts traffic via ALB, then removes Blue tasks.
EKS: Use CodeDeploy with the Load Balancer Controller or external tools to shift between services.
Watchouts: prepare for data migrations and reduce Green capacity if cost is a concern.
Deployment Steps
  1. Deploy Green environment and run smoke tests.
  2. Shift a percentage of traffic to Green and monitor alarms.
  3. On success, shift all traffic and terminate Blue; on failure, revert instantly to Blue.
Example: CodeDeploy for ECS will create a new task set and use ALB routing to move traffic, then automatically rollback if CloudWatch alerts exceed thresholds during the shift.
