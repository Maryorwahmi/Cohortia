Process Flow

CodeBuild: Build, Tag, Push

Configure an image with Docker, enable privileged mode, and provide a buildspec to produce and push images.

Pre-build: Authenticate to ECR and derive IMAGE_TAG from the commit hash.
Build: docker build, docker tag for commit and latest.
Post-build: docker push and write imagedefinitions.json as artifact.
Scenario
You create a project named my-container-build, choose a managed image with Docker pre-installed, enable privileged mode, and select your buildspec.yaml in the repo. After a successful build check ECR for tags and the S3 artifact ZIP for imagedefinitions.json.
