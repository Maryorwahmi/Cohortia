Core Concept

Typical CI/CD Workflow

A repeatable chain from commit to production with a single image artifact.

1. Source: Commit triggers pipeline
2. Build: CodeBuild builds, tests, tags image
3. Test: Deploy to staging for integration and scans
4. Deploy: CodeDeploy/ECS/EKS to production
Key Takeaway

Design the pipeline so the image pushed to ECR is the exact artifact tested and deployed.

Process Flow
Source
CodeCommit/GitHub trigger
Build
CodeBuild: Docker build & tag
Test
Staging deploy & scans
Deploy
CodeDeploy/ECS/EKS
Artifact and verification
  • CodeBuild pushes an image to ECR and writes imagedefinitions.json for deployments.
  • Staging runs integration tests and vulnerability scans to validate the image.
  • Only a validated image is promoted to production to ensure consistency.
Example
A commit triggers CodePipeline; CodeBuild outputs an image tagged with the commit hash; the image appears in ECR and the pipeline pauses if the scan finds high-severity vulnerabilities.
