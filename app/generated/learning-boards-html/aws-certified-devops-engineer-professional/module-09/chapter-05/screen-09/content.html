Process Flow

Testing & Staging Deployments

Deploy built images to a staging environment that mirrors production to run integration and security tests.

Integration Tests
Validate service interactions and API behavior under load.
End-to-End
Simulate user flows on the staged service.
Security Scans
Run ECR scans or tools like Trivy and fail on critical findings.
Example Scenario
After a build, the pipeline deploys an image to a staging ECS service behind an ALB, runs integration tests, and checks CloudWatch logs for errors. If any test or scan fails, the pipeline halts and does not advance to production.
