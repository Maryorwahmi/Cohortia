Learning Objectives

Learn, understand, apply, and master container CI/CD practices on AWS.

01
Design CI/CD Pipelines
Create an end-to-end pipeline using CodeCommit/CodeBuild/CodePipeline/CodeDeploy to move image artifacts to production.
VERIFIED COMPETENCY MILESTONE
02
Automate Image Build & Push
Use CodeBuild with a buildspec.yaml to build, tag, and push Docker images to ECR and emit imagedefinitions.json.
VERIFIED COMPETENCY MILESTONE
03
Integrate Vulnerability Scanning
Enable ECR image scanning or run tools like Trivy in CodeBuild and gate deployment on critical findings.
VERIFIED COMPETENCY MILESTONE
04
Implement Safe Deployments
Understand Blue/Green and Canary releases with CodeDeploy to reduce downtime and enable automatic rollback.
VERIFIED COMPETENCY MILESTONE
