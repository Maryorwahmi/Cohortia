ECR, Tagging & imagedefinitions.json

Store immutable images in ECR and pass the exact image URI to the deployment step via a simple JSON artifact.

Tagging: Commit-hash tags for immutability; latest for convenience but avoid relying on it for rollback.
Artifact: imagedefinitions.json maps container name to the image URI for CodeDeploy.
Check: Ensure the artifact in S3 contains the expected imageUri before deployment.
Example imagedefinitions.json
[{"name":"my-web-app-container","imageUri":"123456789012.dkr.ecr.us-east-1.amazonaws.com/my-web-app:abc1234"}]
Why imagedefinitions.json?
It creates a stable contract between the build and deployment stages so the exact image is deployed, not an inferred tag.
