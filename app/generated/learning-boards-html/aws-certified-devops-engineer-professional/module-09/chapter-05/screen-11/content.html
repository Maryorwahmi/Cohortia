CodePipeline Orchestration

Link artifacts and services so builds flow to deployments reliably and auditable.

Artifacts: include imagedefinitions.json and deployment config files in pipeline artifacts.
Roles: ensure pipeline, build, and deploy roles have precise permissions only for required actions.
Monitoring: wire CloudWatch alarms into CodeDeploy for automatic rollback triggers.
