Definition

Source Stage & Triggers

Commits or PR events start the pipeline and pin the revision used to build images.

Why it matters: ensures traceability from running container back to source commit.
Common mistake: tagging images only with branch names loses immutability and traceability.
Practical check: tag images with the short commit hash and verify it in ECR.
Examples & Scenarios
GitHub PR Build
A PR triggers a build that deploys to a temporary staging environment for review.
CodeCommit Main Branch
Commits to main trigger full pipeline including production deployment gates.
Pro Tip

Configure your pipeline to pass the commit hash into the build environment so tagging is deterministic.
