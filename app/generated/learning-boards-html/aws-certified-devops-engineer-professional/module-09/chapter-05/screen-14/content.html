Module 9 › Chapter 9.5 › What to Remember
Canonical Image
Build once and reference the same image URI for all environments.
Gated Promotion
Use testing and image scans to block unsafe images from progressing.
Safe Rollouts
Blue/Green or Canary releases with alarms and rollback protect production.
Summary
Design pipelines so artifacts are traceable, scanning gates risk, and deployments can revert automatically when alarms detect issues.
