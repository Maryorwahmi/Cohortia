Core Concept

Vulnerability Scanning

Use ECR image scanning or run scanners in the build step to detect vulnerabilities and block unsafe images.

ECR Built-in Scan
Automatic scans on push with severity classifications.
Third-party Scanners
Run Trivy or Clair in CodeBuild for custom rules and early detection.
Practical Steps
  • Enable ECR scanning on the repository and review findings after push.
  • Optionally run Trivy in build and fail the job on critical results.
  • Decide which severities block promotion and document that policy.
