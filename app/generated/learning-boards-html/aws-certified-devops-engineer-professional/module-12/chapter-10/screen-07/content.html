Example FIS Template (simplified)
This JSON defines targets, actions and a stop condition for a safe experiment.
{
  "description": "Terminate a random EC2 instance in a specific ASG",
  "targets": {
    "OneEc2InstanceInAsg": {
      "resourceType": "aws:ec2:instance",
      "selectionMode": "COUNT(1)",
      "resourceArns": [
        "arn:aws:ec2:us-east-1:123456789012:instance/i-0abcdef1234567890",
        "arn:aws:ec2:us-east-1:123456789012:instance/i-0abcdef1234567891"
      ],
      "filters": [
        {
          "path": "Tags.Name",
          "values": ["MyWebAppInstance"]
        }
      ]
    }
  },
  "actions": {
    "TerminateInstance": {
      "actionId": "aws:ec2:terminate-instances",
      "parameters": {
        "instanceIds": "${OneEc2InstanceInAsg}"
      }
    }
  },
  "stopConditions": [
    {
      "source": "aws:cloudwatch:alarm",
      "value": "arn:aws:cloudwatch:us-east-1:123456789012:alarm:MyCriticalAppAlarm"
    }
  ],
  "roleArn": "arn:aws:iam::123456789012:role/FISExperimentRole"
}
Explanation
  • • targets: selects the specific EC2 instances by ARN or tag and a selection mode of COUNT(1).
  • • actions: the AWS API call to perform, here terminate-instances using the selected instance IDs.
  • • stopConditions: a CloudWatch alarm ARN that will automatically stop the experiment if triggered.
  • • roleArn: an IAM role granting FIS the minimum permissions needed for the actions.
Key Takeaway

Stop conditions give you an automatic circuit breaker. Tie them to user-facing alarms whenever possible.

Security Note

Grant FIS least privilege: only the actions and resource ARNs required by the experiment.
