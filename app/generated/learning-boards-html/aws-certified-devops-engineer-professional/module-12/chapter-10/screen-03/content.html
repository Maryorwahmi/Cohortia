Module 12 › Chapter 12.10 › Learning Objectives
Verification Milestones
Small, observable tasks that prove competency.
  • 01
    Steady-state Definition
    Document one SLI and threshold used as your experiment success metric.
  • 02
    Experiment Plan
    List impact, blast radius, rollback and who is notified on escalation.
  • 03
    FIS Template
    Create an experiment template that targets one instance using a tag filter.
  • 04
    Run Report
    Produce a short analysis comparing observed metrics with your hypothesis and list fixes.
Practical mnemonic
PLAN: Pick steady-state, List impact, Automate small blast, Notify responders. Use PLAN before every experiment.
Safety note
Always include stop conditions, limit blast radius, test in non-production first, and ensure IAM least privilege for FIS roles.
