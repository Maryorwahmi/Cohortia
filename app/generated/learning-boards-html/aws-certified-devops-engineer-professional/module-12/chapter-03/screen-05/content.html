Lambda structured logging
Use a JSON formatter, remove default handlers, and attach a StreamHandler so logs are emitted as JSON lines.
import json
import logging
import os
import datetime

class JsonFormatter(logging.Formatter):
  def format(self, record):
    log_entry = {
      "timestamp": datetime.datetime.fromtimestamp(record.created, tz=datetime.timezone.utc).isoformat(),
      "level": record.levelname,
      "message": record.getMessage(),
      "service": os.environ.get("SERVICE_NAME", "unknown-service"),
      "function_name": os.environ.get("AWS_LAMBDA_FUNCTION_NAME", "unknown-function"),
      "request_id": getattr(record, 'aws_request_id', 'N/A'),
      "details": getattr(record, 'details', {})
    }
    return json.dumps(log_entry)

logger = logging.getLogger()
logger.setLevel(logging.INFO)

if logger.handlers:
  for handler in logger.handlers:
    logger.removeHandler(handler)

handler = logging.StreamHandler()
handler.setFormatter(JsonFormatter())
logger.addHandler(handler)

def lambda_handler(event, context):
  logger.info("Processing event", extra={'details': {'event_type': 'test_event', 'data_size': len(json.dumps(event))}})
  logger.warning("Potential issue detected", extra={'details': {'component': 'processor', 'status': 'degraded'}})
  logger.error("Critical error occurred", extra={'details': {'error_code': 500, 'error_message': 'Failed to connect to DB'}})

  return {
    'statusCode': 200,
    'body': json.dumps('Logs generated!')
  }
Verification
  • Invoke the Lambda and confirm single-line JSON entries appear in CloudWatch Logs.
  • Ensure log fields are present and types are consistent across invocations.
Checkpoints and common mistakes
Common mistake
Leaving the default handler causes mixed formats. Remove defaults to ensure uniform JSON output.
Performance note
Keep logging non-blocking; avoid heavy serialization in the hot path. Use asynchronous transports if needed.
Pro tip
Attach request identifiers so you can correlate traces and logs across systems.
Key Takeaway

A simple JSON formatter in your Lambda gives immediate gains for parsing and downstream analytics.
