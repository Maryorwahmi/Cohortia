Process
Create delivery stream
  1. Select source: CloudWatch Logs or Direct PUT.
  2. Choose destination: Amazon OpenSearch Service.
  3. Set index name prefix (example: devops-logs) and rotation (daily).
  4. Configure buffer size and interval (e.g., 1MB, 60s for testing).
  5. Provide IAM role for Firehose to write to OpenSearch and S3 for backups.
  6. Enable S3 backup for failed or unprocessed records.
Verification steps
Invoke the source to generate logs and wait for Firehose to batch and deliver.
Create an index pattern in OpenSearch Dashboards for your prefix and use Discover to validate fields are present.
Check S3 backup bucket for any failed records and investigate causes if present.
Tip: keep a short buffer interval for low-latency dashboards, and increase buffer size for cost-effective batching under steady load.
