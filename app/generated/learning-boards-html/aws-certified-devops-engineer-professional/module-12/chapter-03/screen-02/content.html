Learning Objectives
Learn the skills needed to build a structured, aggregated, and searchable logging pipeline that is secure and cost-effective.
01
Design structured logging
Model logs as JSON with consistent fields so you can filter, aggregate, and alert reliably. Verified competency milestone: produce searchable JSON logs from an application.
Mnemonic: think of logs as records with fixed columns.
VERIFIED COMPETENCY MILESTONE
02
Aggregate logs with Kinesis
Use Firehose for managed delivery to OpenSearch or S3; use Data Streams when you need custom consumers. Milestone: configure a CloudWatch subscription to forward logs to Firehose.
Mnemonic: pipe logs to a single delivery stream.
VERIFIED COMPETENCY MILESTONE
03
Centralize in OpenSearch
Index, search, and visualize logs with dashboards and alerts. Milestone: create an index pattern and discover structured log fields in OpenSearch Dashboards.
Mnemonic: index then explore.
VERIFIED COMPETENCY MILESTONE
04
Retention, access, cost
Apply retention policies, S3 archival, IAM controls, and right-sized OpenSearch tiers to balance cost and compliance. Milestone: implement lifecycle rules for archived logs.
Mnemonic: policy, protect, and prune.
VERIFIED COMPETENCY MILESTONE
