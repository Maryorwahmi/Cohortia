Pro Tip
Right-size and archive
Combine node sizing, UltraWarm tiers, and S3 lifecycle to control costs while keeping recent data fast to query.
Hot tier
Recent logs kept for quick queries and dashboards. Keep shard sizes reasonable and monitor CPU and IO.
Cold/Archive
Use UltraWarm or S3 archives for older logs; query them when needed via cheaper storage.
Example lifecycle
0–30 days: hot OpenSearch; 31–365 days: UltraWarm or S3 queryable archive; >365 days: Glacier via S3 lifecycle for compliance.
Key Takeaway

Tier data by access frequency and automate transitions to ensure predictable costs and performance.

Monitoring metrics to watch
  • Indexing throughput and latency
  • Query latency and slow queries
  • Disk usage per node and shard sizes
  • S3 storage growth and Glacier transitions
