Hands-on Activity
Deploy and verify pipeline
  1. Create Lambda with JSON formatter and set SERVICE_NAME environment variable.
  2. Test function and confirm CloudWatch Logs show one-line JSON records.
  3. Create Kinesis Firehose delivery stream to OpenSearch with S3 backup and buffer hints.
  4. Create CloudWatch subscription filter to forward your Lambda log group to Firehose.
  5. Invoke Lambda, then create an index pattern in OpenSearch Dashboards and check Discover.
Troubleshooting checklist
  • No documents in OpenSearch: verify Firehose role, network access, and S3 error bucket for failing records.
  • Missing fields: confirm your formatter emitted fields and that Firehose did not transform or drop them.
  • High cost: check indexing rate, retention, and compress or archive older indices to S3.
Checklist: run small tests, inspect S3 backups for failed records, and then scale buffer settings for production.
