Assessment prompts

Scenario 1
Intermittent timeouts to RDS where the DB is healthy. Recommended next step: query VPC Flow Logs for REJECT records between the EC2 and RDS IP, focusing on the DB port.
Scenario 2
High CPU on a production instance where SSH is disallowed. Recommended action: use Systems Manager Session Manager, run top and related diagnostics, and collect evidence to guide remediation.
Grading guidance
Require commands, expected outputs, evidence artifacts, and a safe remediation with rollback steps. Emphasize auditable actions and minimal scope.
