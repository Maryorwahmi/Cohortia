Common diagnostic commands

top / htop
CPU and memory consumers; sort by usage to find hot processes.
df -h
Disk usage by filesystem; full partitions often break services.
netstat / ss
Active sockets and listening ports; useful to confirm service bindings.
lsof
Identify which process holds files or sockets open.
Example workflow
If you see high CPU in top, note the process ID, collect its logs with a timestamp, check open sockets with lsof, and inspect recent kernel messages with dmesg for OOM or hardware errors before restarting it.
Safety reminder
Avoid destructive commands until you have backups or redundancy. When in doubt, collect data and consult the incident checklist.
Key Takeaway

Use diagnostic tools to form evidence-backed actions; then perform minimal, auditable changes.
