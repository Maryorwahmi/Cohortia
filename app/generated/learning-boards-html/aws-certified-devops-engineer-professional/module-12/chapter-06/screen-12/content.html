Diagnose Network Connectivity — Activity

Prerequisites
  • EC2 with SSM Agent and an instance profile (AmazonSSMManagedInstanceCore)
  • VPC Flow Logs enabled to CloudWatch Logs
  • Security Group with temporary HTTP rule
Safety
Simulate a block in a test environment or during maintenance windows; capture evidence before remediation.
Steps
  1. Start a Session Manager session and run ping google.com to verify outbound access.
  2. Remove inbound HTTP/HTTPS rule from the instance Security Group and attempt curl http://<EC2-Public-IP> from your client.
  3. Run the CloudWatch Logs Insights REJECT query for your instance private IP to confirm blocked traffic.
  4. Re-add the inbound rule and verify curl succeeds; attach outputs to the incident log.
Key Takeaway

Perform simulated blocks in controlled environments, use Session Manager and Flow Logs to gather proof, and always document timestamps and outputs for post-incident review.
