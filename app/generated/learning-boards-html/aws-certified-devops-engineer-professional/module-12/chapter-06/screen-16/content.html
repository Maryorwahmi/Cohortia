Module 12 › Chapter 12.6 › Key Concepts
Network ACLs (NACLs)
Stateless subnet-level rules that can explicitly deny traffic and override expectations from Security Groups.
Route Tables
Define how traffic is routed within and out of a VPC; missing routes break connectivity despite correct firewall rules.
Operational safety
Capture evidence, apply minimal changes, and ensure all access is auditable to support learning and compliance.
Closing takeaway
Build a short checklist that you can run in incidents: verify instance and LB health, collect CLI outputs and flow logs, use Session Manager for access, and then remediate with auditable steps.
