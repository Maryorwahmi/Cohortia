Module 12 › Chapter 12.6 › Network Troubleshooting
Security Groups
Stateful, instance-level firewalls. Ensure inbound and outbound rules permit intended ports and sources.
Network ACLs
Stateless, subnet-level rules. Explicit denies override permissive security group assumptions.
Route Tables
Define where traffic flows. Missing routes to gateways block connectivity even when security groups permit it.
VPC Flow Logs
Flow logs capture IP traffic metadata for ENIs. They help you find REJECT actions and identify source and destination IPs that experienced blocked traffic.
Practical sequence: confirm security group rules first, then network ACLs, then route tables. If traffic is still failing, run a Flow Log query to find rejects and confirm whether the packet reached the VPC boundary.
