Definition

Session Manager overview

A method to access EC2 shells through the SSM Agent, without SSH keys or open inbound ports.

Why use it
  • No inbound port exposure or bastions.
  • All sessions can be logged to CloudWatch Logs or S3 for auditability.
  • Simpler permission model via IAM instance profiles.
Start a session (example)
aws ssm start-session --target i-0abcdef1234567890
Ensure the instance role includes AmazonSSMManagedInstanceCore and the SSM Agent is running.
Key Takeaway

Use Session Manager for auditable, port-free access in production incidents.

Instance diagnostics
Once connected, common commands include top, htop, dmesg, journalctl, netstat, and lsof for process and network diagnostics. Collect outputs to logs before making changes.
Common misconception
Session Manager is not a debugging magic wand; it requires agent health and correct IAM role configuration to work reliably.
Check your setup
  • SSM Agent running on the instance.
  • Instance profile with AmazonSSMManagedInstanceCore.
  • CloudWatch or S3 configured for session logs if audit is required.
