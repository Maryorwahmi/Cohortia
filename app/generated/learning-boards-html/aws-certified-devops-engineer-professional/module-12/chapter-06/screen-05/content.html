5 Whys — iterative root-cause analysis

Ask why repeatedly to connect symptoms to process or design gaps.

Why 1
Website is slow → database overloaded.
Why 2
Database overloaded → inefficient query.
Why 3
Inefficient query → missing index.
Why 4
Missing index → developer unaware of indexing requirement.
Why 5
Documentation and review process missed data-model guidance.
Action
Add index and update developer checklist and code review template to catch missing indexes.
