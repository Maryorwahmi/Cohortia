Avoiding common pitfalls

Symptom-chasing
Don't apply fixes that only silence alerts. Find the root cause.
Skipping simple checks
Verify instance and health check status before deep debugging.
Unsafe commands
Avoid destructive commands without backups; capture evidence first.
Best practice
Document every verification step, include timestamps, and save CLI outputs and flow log queries to the incident record for future learning.
Key Takeaway

Follow safe, auditable steps: evidence first, minimal changes, and post-incident improvements.
