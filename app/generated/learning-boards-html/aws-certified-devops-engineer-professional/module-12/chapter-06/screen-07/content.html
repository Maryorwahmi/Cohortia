EC2 Instance Status

Instance status checks

Use this to confirm system and instance health and to see scheduled events.

aws ec2 describe-instance-status --instance-ids i-0abcdef1234567890
Look for 'InstanceStatus' and 'SystemStatus' fields and any recent events; include the JSON in your incident log.
CloudWatch Metrics

ALB 5xx counts

Retrieve sum of 5xx responses over a window to identify backend errors.

aws cloudwatch get-metric-statistics \
  --namespace AWS/ApplicationELB \
  --metric-name HTTPCode_Target_5XX_Count \
  --dimensions Name=LoadBalancer,Value=app/my-elb/abcdef123 \
  --start-time 2023-10-27T10:00:00Z \
  --end-time 2023-10-27T10:30:00Z \
  --period 60 \
  --statistic Sum
Graph the returned datapoints against your incident timeline and correlate with instance logs or application traces.
