Lab Walkthrough: Codify and Validate
Step 1: Write a CloudFormation template that creates a CloudWatch dashboard and an alarm tied to an EC2 instance. This proves monitoring is deployed as code and versioned.
Step 2: Deploy the stack in a non-production account and verify the dashboard and alarm appear in CloudWatch. Replace the example instance ID with your actual instance ID.
Step 3: Prepare a runbook that explains how to respond to the HighCPU alarm and validate it during a game day exercise.
Checkpoint
Milestone: Deployed stack with Dashboard URL and Alarm exists; runbook reviewed by team.
