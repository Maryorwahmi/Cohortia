Alerting and Notification Architecture
Connect telemetry to guided response paths.
Alerting steps
1) Collect metrics and logs (CloudWatch Metrics, Logs)
2) Define alarms and anomaly detection
3) Route alarm to SNS topic for notifications
4) Attach runbook link and context to the notification
Concrete example
HighCPUAlarm publishes to an SNS topic that notifies on-call and includes a link to the HighCPU runbook and the CloudWatch dashboard URL for troubleshooting context.
Key Takeaway

Ensure alerts include context and a versioned runbook so responders can act quickly and accurately.
