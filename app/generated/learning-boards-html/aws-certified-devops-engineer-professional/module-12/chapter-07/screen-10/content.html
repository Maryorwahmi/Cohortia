Module 12 › Chapter 12.7 › Lambda Remediation
What the Lambda does
  • Parses invokingEvent to find resource name
  • Performs S3 actions such as put_public_access_block
  • Logs progress and returns status for Config to record
Permissions required
Grant only the minimal S3 and Config permissions the function needs, and avoid wildcard actions where possible.
Simplified Python snippet
import json
import boto3
import os

s3 = boto3.client('s3')

def lambda_handler(event, context):
    invoking_event = json.loads(event['invokingEvent'])
    configuration_item = invoking_event['configurationItem']
    bucket_name = configuration_item['resourceName']

    s3.put_public_access_block(
        Bucket=bucket_name,
        PublicAccessBlockConfiguration={
            'BlockPublicAcls': True,
            'IgnorePublicAcls': True,
            'BlockPublicPolicy': True,
            'RestrictPublicBuckets': True
        }
    )
This example focuses on the Block Public Access API. In practice add error handling, retries, and logging for visibility.
