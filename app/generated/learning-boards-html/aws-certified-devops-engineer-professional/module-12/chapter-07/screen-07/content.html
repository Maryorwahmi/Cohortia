Module 12 › Chapter 12.7 › Disk Full Remediation
Step-by-step
  1. CloudWatch alarm triggers on DiskUtilization > 90%.
  2. EventBridge rule matches the alarm transition to ALARM.
  3. EventBridge invokes SSM Automation document with InstanceId.
  4. Automation modifies EBS, runs resize and cleans logs via Session Manager.
  5. Publish SNS notification and record Automation execution for audit.
Key Takeaway

Make sure in-guest filesystem resize runs after volume changes and validate the final free space before marking the remediation successful.

Quick checklist before production
  • Test volume modification and resize in a sandbox instance.
  • Confirm SSM Agent and Session Manager access on instances.
  • Grant SSM and EC2 permissions with least privilege to the automation role.
  • Add a retry policy and timeout to prevent runaway changes.
Example event payload note
EventBridge will receive the CloudWatch alarm state-change event; ensure your rule's event pattern filters to the specific alarm name or resource to avoid false triggers.
