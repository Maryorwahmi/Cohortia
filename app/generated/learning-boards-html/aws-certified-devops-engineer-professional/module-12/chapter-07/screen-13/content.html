Module 12 › Chapter 12.7 › Lab Walkthrough
Task checklist
  1. Create Lambda function S3PublicAccessRemediator with s3:PutBucketPublicAccessBlock permission scoped to your test bucket.
  2. Add environment variable AWS_ACCOUNT_ID and deploy.
  3. Create AWS Config rule s3-bucket-public-read-prohibited and enable automatic remediation.
  4. Select managed SSM document AWS-DisableS3BucketPublicReadWrite or link your custom Lambda via a remediation action.
  5. Test by making the test bucket public and observe remediation correcting it.
Terminal-style checks
Use console views to verify compliance and Automation executions. After remediation, check that "Block all public access" is re-enabled and that Config rule shows "Compliant". Save execution logs for audit.
Safety
Use a disposable test bucket, minimize IAM scope, and revert changes after validation.
