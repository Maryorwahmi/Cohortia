Module 12 › Chapter 12.7 › Self-Healing Architecture
Components
  • Auto Scaling Groups: replace unhealthy EC2 instances
  • EventBridge: route events and error patterns
  • Lambda and SSM: custom remediation logic or runbooks
  • AWS Health events: preemptive reactions to provider-level issues
Design reminders
Use multiple health signals, test remediation actions under load, and ensure observability for each automated step.
Scenario
If error rates spike for a service, EventBridge can match a log pattern and invoke Lambda to restart a container, while ASG replaces an instance if the container restart fails repeatedly. If retries continue to fail, escalate to on-call rather than loop infinitely.
Pro Tip

Model remediation as small, composable actions that can be chained and observed; avoid single large scripts that do many unchecked changes.
