Module 12 › Chapter 12.7 › What is Self-Healing?
Claim
Automatically detect and remediate known issues to reduce downtime and manual toil.
Characteristics
  • Automated detection and trigger
  • Deterministic remediation steps
  • Auditable execution and notifications
Common quick wins
Restart failed service
Replace unhealthy instance (ASG)
Reapply security settings from Config
Analogy
Think of a self-healing system like a thermostat: it senses temperature, decides what corrective action to take, and applies it to maintain the desired state. The difference in software is the complexity of decisions and the possible need for multi-step actions.
Misconception
Automation is not a substitute for observability and testing. Poorly designed automation can make incidents worse if it lacks safeguards or rollback paths.
Key Takeaway

Start with small, reversible automation, add observability, and require explicit rollback criteria before wider rollout.
