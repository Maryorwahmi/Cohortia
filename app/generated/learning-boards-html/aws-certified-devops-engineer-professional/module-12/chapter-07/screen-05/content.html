Module 12 › Chapter 12.7 › Remediation Strategies
Process Steps
1. Detect
Metrics, logs, or Config rule evaluations identify the issue state.
2. Route
EventBridge or alarm actions select the appropriate automation runbook.
3. Remediate
SSM Automation, Lambda, or ASG actions perform the fix with logged steps.
4. Verify
Confirm the resource is healthy and notify stakeholders; record execution for audit.
Concrete example
Disk full scenario
  • CloudWatch alarm on DiskUtilization crosses 90%
  • EventBridge rule triggers SSM Automation document named ExtendEBSVolumeAndCleanDisk
  • Automation modifies EBS size, runs resize and log cleanup, then publishes SNS
Common Mistake

Automating without verification or circuit breakers can cause repeated, cascading changes when underlying metrics are noisy.
