Module 12 › Chapter 12.7 › AWS Config Remediation
How Config works
Config evaluates resource state against rules and records compliance status. When non-compliant, it can trigger remediation actions configured on the rule.
Remediation targets
  • Managed SSM Automation documents (e.g., AWS-DisableS3BucketPublicReadWrite)
  • Custom SSM Automation documents
  • Lambda functions invoked by Config remediation
Example: public S3 bucket
Config rule detects public bucket; remediation can enable Block Public Access via a managed SSM document or invoke a Lambda that applies a restrictive bucket policy. Ensure roles have ssm:StartAutomationExecution or lambda:InvokeFunction permissions.
Pitfall

Do not automatically remediate high-impact changes without staged testing and a rollback strategy.
