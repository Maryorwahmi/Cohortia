Hands-on Activity › Lambda Instrumentation Lab
Steps
  1. Create an S3 bucket and note the name.
  2. Create a Python Lambda with AWSXRayDaemonWriteAccess and enable active tracing.
  3. Deploy the sample code and set S3_BUCKET_NAME env var.
  4. Invoke the function and inspect traces in X-Ray.
Validation: locate the Lambda node on the service map, open traces, and find the S3Operations subsegment with annotated s3_operation entries.
Starter snippet (visual)
s3_client.put_object(Bucket=BUCKET_NAME, Key=object_key, Body='Hello')
xray_recorder.current_subsegment().put_annotation('s3_operation', 'put_object_success')
Troubleshoot
If downstream calls are missing, ensure patch_all() ran and the collector or Lambda active tracing is enabled. Check role permissions for X-Ray write access.
