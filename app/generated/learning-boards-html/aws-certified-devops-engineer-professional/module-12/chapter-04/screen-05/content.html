Process › Instrumenting Flask
Key steps
  1. Install aws-xray-sdk and the Flask middleware.
  2. Patch AWS SDK clients to capture downstream calls.
  3. Initialize XRayMiddleware(app, xray_recorder) and add subsegments for business logic.
  4. Run X-Ray daemon or enable Lambda active tracing to deliver segments.
Common mistake
Not patching AWS SDK clients leads to missing downstream segments and an incomplete trace.
Example code (visual)
from flask import Flask
from aws_xray_sdk.core import xray_recorder
from aws_xray_sdk.ext.flask.middleware import XRayMiddleware
from aws_xray_sdk.ext.aws.client import patch_all
import boto3

app = Flask(__name__)
patch_all()
XRayMiddleware(app, xray_recorder)

dynamodb = boto3.resource('dynamodb')

@app.route('/')
def hello_world():
  with xray_recorder.in_segment('index_page_load'):
    xray_recorder.current_subsegment().put_annotation('user_id', 'test_user')
    try:
      table = dynamodb.Table('MyExampleTable')
      table.get_item(Key={'id': '123'})
    except Exception as e:
      xray_recorder.current_subsegment().add_exception(e)
      return 'Error', 500
    return 'Hello, X-Ray!'
This example adds a custom segment, annotates it with user context, and relies on patch_all to include DynamoDB calls in the trace.
Key Takeaway

Custom annotations and patching make traces searchable and complete; run the daemon to upload segments.
