Process › Instrumenting Lambda
Checklist
  • Attach AWSXRayDaemonWriteAccess to the execution role.
  • Enable Active tracing in Lambda configuration.
  • Configure xray_recorder and create subsegments inside the handler.
  • Add annotations for searchability and add_exception for errors.
Hands-on activity
Deploy the sample Lambda, set the S3 bucket env var, invoke it several times, and observe traces in X-Ray.
Lambda starter code (visual)
import boto3
from aws_xray_sdk.core import xray_recorder
from aws_xray_sdk.ext.aws.client import patch_all

xray_recorder.configure(service='XRayTracedFunction')
xray_recorder.begin_segment('LambdaInit')
try:
  patch_all()
finally:
  xray_recorder.end_segment()
During the handler create a subsegment for S3 operations and annotate success or failure so traces show the business context you need.
Pro tip

Annotate identifiers you will filter on later, and avoid adding very large metadata objects to every trace.
