Module 12 › Chapter 12.4 › Learning Objectives
Instrumentation
Daemon, SDKs, and Lambda tracing
  • Run the X-Ray daemon for EC2, ECS, and EKS to collect UDP segments from instrumented apps.
  • Use language-specific SDKs to create segments and subsegments and patch AWS SDK clients for automatic tracing.
  • Enable active tracing in Lambda to capture handler invocations without an external daemon.
Visual mnemonic: agent -> SDK -> service
Trace quality
Annotations, metadata, and sampling
  • Add annotations like user_id to make filters precise and searches efficient.
  • Use metadata for larger context that is searchable at the trace level.
  • Configure sampling rules to trace a representative subset and control costs in production.
Visual mnemonic: filterable tags
