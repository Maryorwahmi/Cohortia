Module 12 › Chapter 12.8 › Tracking Action Items
Action item template
Title: concise description
Owner: named person or team
Due: calendar date
Verification: concrete test or metric to prove effectiveness
Verification examples
- CI test added and failing on known slow queries; show three passing builds.
- Index added and top N query latency reduced from 2s to 200ms on staging.
Follow‑up cadence
Close actions only after verification. Schedule a post‑implementation review after one sprint to confirm no recurrence and update the post‑mortem if needed.
Key Takeaway

Verification with evidence is the difference between an implemented change and an effective, durable improvement.
