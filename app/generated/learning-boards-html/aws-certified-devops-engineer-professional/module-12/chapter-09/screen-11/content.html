Good practice vs common mistakes
Match practice to avoid repeating incidents.
Mistake: Long unprioritized lists
Fix: Prioritize by impact and assign an owner with verification criteria.
Mistake: One‑off live fixes
Fix: Update IaC and pipeline so change is systemic and repeatable.
Mistake: Skipping tests on IaC
Fix: Use the same CI, code review, and staging validation for infrastructure changes as for app code.
Key takeaway
Avoid fatigue and drift by prioritizing, templating, and testing improvements the same way you treat feature work.
