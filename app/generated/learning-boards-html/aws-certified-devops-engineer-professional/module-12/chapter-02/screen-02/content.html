Learning Objectives

These objectives focus on configuration and practical outcomes for proactive monitoring and anomaly detection.

01
Configure custom metrics
Publish application-level indicators and pick appropriate resolution for real-time needs.
VERIFIED COMPETENCY MILESTONE
02
Enable metric streams
Route metrics to Kinesis, S3, or third-party tools for analytics and long-term retention.
VERIFIED COMPETENCY MILESTONE
03
Implement synthetic canaries
Simulate user flows to detect availability and content correctness from outside your VPC.
VERIFIED COMPETENCY MILESTONE
04
Use ML for anomalies
Apply CloudWatch Anomaly Detection and Lookout for Metrics to reduce false positives and find root causes.
VERIFIED COMPETENCY MILESTONE
Bloom's taxonomy
Learn → Understand → Apply → Master
Each objective maps to a practical milestone: instrument, export, simulate, and let ML refine alerts. Practice in a lab to verify competence.
