Definition › Custom Metrics
How to publish
Pick a namespace, metric name, and optional dimensions. Decide between standard and high-resolution based on detection speed and cost. Publish via CLI or SDK from the application at logical event points.
Common pitfalls
  • Sending many low-value metrics increases cost without improving signal.
  • Not using dimensions makes filtering and correlation harder.
  • Choosing unnecessarily high resolution without need increases charges.
CLI example
aws cloudwatch put-metric-data \
  --metric-name SuccessfulApiCalls \
  --namespace 'MyApp/API' \
  --value 1 \
  --dimensions Service=UserService,Endpoint=/users
Run this from a process that counts successful calls. Use dimensions to slice by service or endpoint.
Pro tip

Publish aggregated metrics at a sensible interval. For high-frequency events, consider aggregating in-process before sending to reduce API calls and cost.
