Process Flow › Synthetics Canaries
Canary types
Heartbeat monitors for basic availability, and scripted canaries for multi-step flows that validate content and functionality.
Artifacts captured
  • Screenshots on failure for visual diagnosis.
  • HAR files for network-level analysis.
  • Execution logs for step-level errors.
Example: Checkout canary
A canary that navigates to product, adds to cart, submits payment, and checks for a confirmation string will surface front-end, third-party, or network failures before customers report them.
Common mistake

Running too many complex canaries at high frequency increases cost and noise. Start with critical paths and capture artifacts on failure.
