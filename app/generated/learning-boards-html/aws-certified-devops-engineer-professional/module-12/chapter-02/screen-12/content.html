Hands-on Activity › Canary + Anomaly Detection
Task 1: Create a Canary
  1. Open CloudWatch, choose Synthetics → Canaries → Create canary.
  2. Select Heartbeat monitor, set name (e.g., MyWebsiteHealthCheck), enter public URL, and schedule (5 minutes).
  3. Run and observe availability, latency, screenshots, and HAR files.
Task 2: Configure Anomaly Detection
  1. In CloudWatch, find EC2 → Per-Instance Metrics → CPUUtilization for your instance.
  2. Create an alarm, choose Anomaly Detection as the condition, and set band width (start with 2).
  3. Attach SNS notifications and create the alarm; observe the band on the graph as it learns.
Expected outcomes
Your canary will report availability and latency metrics plus artifacts. The CPU metric will display an anomaly band and the alarm will fire if the metric falls outside the learned range.
Key Takeaway

Use both tools together: synthetics prove user impact, and anomaly detection reduces noisy threshold alerts by learning normal behavior.
