Architecture › Metric Streams
Why stream metrics?
Streaming provides long-term retention, cross-service correlation, and the ability to run advanced queries and ML outside CloudWatch's native console.
Typical pipeline
  1. CloudWatch Metric Streams publish metrics to Kinesis Data Firehose.
  2. Firehose writes transformed records to S3 with partitioning.
  3. Run Athena queries or feed data into ML workflows.
Practical example
Stream metrics into S3 and use Athena to join metrics with application logs to find when a business metric broke and which component caused it. This is especially useful for retrospective analysis.
Key Takeaway

Metric streams unlock analytics and ML use cases that complement CloudWatch dashboards and alarms.
