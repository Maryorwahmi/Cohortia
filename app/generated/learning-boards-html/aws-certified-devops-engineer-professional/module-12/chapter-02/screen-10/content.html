Definition › Anomaly Detection
How it works
The service builds a statistical model of recent metric behavior, including seasonality, and presents a detection band. Alarms can trigger when values fall outside this band.
Tips
  • Give models time to learn baseline patterns.
  • Adjust band width to change sensitivity.
  • Interpret early alerts as candidates for tuning, not immediate truth.
Concrete example
Enable Anomaly Detection for EC2 CPUUtilization and set the band width to 2. The graph will show a shaded band representing expected CPU. Only values outside the band will trigger alarms.
Key Takeaway

Use anomaly detection to reduce noise and surface statistically significant deviations in metrics with seasonal patterns.
