Learning Objectives — Practical Focus

Turn each objective into a validated milestone you can run in a lab or during onboarding checks.

01 Publish custom metrics
Instrument code or use the CLI to publish business events as metrics. Choose high-resolution for rapid detection when needed; otherwise use standard resolution to save cost.
VERIFIED COMPETENCY MILESTONE
02 Create metric streams
Set up a stream to Kinesis or Firehose to land metrics in S3 for Athena queries or third-party analytics.
VERIFIED COMPETENCY MILESTONE
03 Deploy synthetics canary
Use a canary blueprint to simulate critical pages and capture HAR and screenshots for investigation.
VERIFIED COMPETENCY MILESTONE
04 Enable ML anomaly detection
Turn on a detection band, give the model time to learn, and compare CloudWatch Anomaly Detection with Lookout when you need multi-dimensional correlation.
VERIFIED COMPETENCY MILESTONE
