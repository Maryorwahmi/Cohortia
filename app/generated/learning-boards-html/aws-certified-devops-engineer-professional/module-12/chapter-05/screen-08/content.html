Module 12 › Chapter 12.5 › Automation Architecture
Pattern
CloudWatch alarm → EventBridge rule → SSM Automation document. The Automation document runs with an IAM execution role to perform the remediation.
EventBridge rule
Match CloudWatch Alarm State Change events for the named alarm and route them to SSM.
SSM Automation
Runbooks-as-code such as AWS-RestartEC2Instance perform the action; custom documents can scale ASGs or run scripts.
Security
Use least-privilege roles for Automation execution and require approval steps for high-risk changes.
Event pattern example
{
  "source": ["aws.cloudwatch"],
  "detail-type": ["CloudWatch Alarm State Change"],
  "detail": {
    "alarmName": ["WebTier-HighCPU"],
    "state": { "value": ["ALARM"] }
  }
}
Safety note
Test automations in non-production and ensure execution roles have only the permissions needed for the action.
