Post-mortem checklist
Timeline
Record detection time, triage decisions, actions taken, and resolution time.
Evidence
Attach metrics, logs, automation execution records, and commands used during diagnostics.
Root cause & contributing factors
State the root cause and any systemic issues that enabled the incident.
Action items
Assign owners, deadlines, and verification steps; update runbooks and automation as required.
Follow-up
Schedule a verification check after fixes are implemented to confirm the incident cannot recur via the same path.
