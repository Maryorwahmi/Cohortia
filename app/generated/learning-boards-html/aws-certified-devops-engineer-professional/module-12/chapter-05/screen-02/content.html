Learning Objectives
Learn the skills to triage incidents, write runbooks, and automate safely.
01
Define the incident lifecycle
Name detection, triage, response, resolution, and post-mortem so your team shares a common workflow.
VERIFIED COMPETENCY MILESTONE
02
Establish severity levels
Set criteria for Critical, High, Medium, and Low so teams prioritize consistently during stress.
VERIFIED COMPETENCY MILESTONE
03
Author runbooks
Create trigger conditions, triage steps, mitigation, communications, and escalation paths for common incidents.
VERIFIED COMPETENCY MILESTONE
04
Automate safe actions
Use EventBridge and Systems Manager Automation for repeatable tasks and always test automations in non-production first.
VERIFIED COMPETENCY MILESTONE
