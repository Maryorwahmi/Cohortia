Module 12 › Chapter 12.5 › Hands-on Flow
Step-by-step flow
1
Create CloudWatch Alarm
Metric: EC2 → Per-Instance → CPUUtilization. Use a test-friendly threshold for validation.
2
Select or create SSM Automation document
Use AWS-RestartEC2Instance or a custom document with idempotent, reversible steps.
3
Create EventBridge rule
Match CloudWatch Alarm State Change for your alarm and set SSM Automation as the target. Map instance ID from event detail to Automation parameters.
4
Test in non-production
Generate CPU load, observe alarm to ALARM state, and confirm Automation executes and recovers the instance.
Common mistake
Not limiting IAM permissions for Automation roles and not validating parameter mapping from the event to Automation inputs.
