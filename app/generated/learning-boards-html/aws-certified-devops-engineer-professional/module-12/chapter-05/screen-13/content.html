Module 12 › Chapter 12.5 › Activity
Activity steps
  1. Create CloudWatch alarm for CPUUtilization on a non-production EC2 instance and name it clearly.
  2. Choose AWS-RestartEC2Instance as the Automation document and verify the execution role's permissions.
  3. Create EventBridge rule matching the alarm state change and add SSM Automation as the target; pass instance id from the event.
  4. Generate CPU load on the test instance, observe alarm -> EventBridge -> Automation flow, and review execution logs.
  5. Update the runbook with exact alarm names, parameter mapping, and role ARNs after successful test.
Testing tip
Keep a short test threshold and a sandbox instance so you can validate automation without business impact.
