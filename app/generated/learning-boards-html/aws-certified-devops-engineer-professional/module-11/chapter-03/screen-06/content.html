Retrieving Right-Sizing Recommendations

Using AWS CLI with Compute Optimizer

Prerequisite: Enable Compute Optimizer

AWS Compute Optimizer must be enabled in your account to collect data and generate recommendations. This is a one-time setup per account.

Interpreting Recommendations

The CLI output provides the current instance type, the recommended type, and estimated monthly savings. This data helps you make informed decisions about instance changes.

Automation Potential

Using the CLI allows you to integrate recommendation retrieval into automated scripts or CI/CD pipelines, enabling continuous, programmatic cost optimization.

AWS CLI Example: Get EC2 Recommendations

# Example: Using AWS CLI to get recommendations from Compute Optimizer for EC2 instances
# Note: Compute Optimizer needs to be enabled in your account first.
aws compute-optimizer get-ec2-instance-recommendations \
    --instance-arns arn:aws:ec2:us-east-1:123456789012:instance/i-0abcdef1234567890 \
    --query 'InstanceRecommendations[].{InstanceARN:InstanceArn,CurrentType:CurrentInstanceType,Recommendation:RecommendationOptions[0].InstanceType,Savings:RecommendationOptions[0].SavingsOpportunity.EstimatedMonthlySavings}'
Key Takeaway

The AWS CLI provides a powerful way to programmatically access Compute Optimizer recommendations, enabling automated right-sizing and cost management.
