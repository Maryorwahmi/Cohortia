Spot Instances: Leveraging Unused Capacity

Achieving massive discounts for fault-tolerant workloads

Deep Discounts

Spot Instances offer up to 90% savings compared to On-Demand pricing by utilizing AWS's unused EC2 capacity.

Ideal Workloads

Best for fault-tolerant, flexible, and stateless applications like batch processing, data analytics, rendering, or containerized microservices that can handle interruptions.

Key Consideration: Interruption

AWS can terminate Spot Instances with a two-minute warning. Your application must be designed to gracefully handle these interruptions, saving state and resuming work.

Spot Instance Lifecycle

1

Request Spot Instance with max price

2

AWS launches instance if current Spot price is below max

3

Instance runs at current Spot price

4

If Spot price exceeds max, or capacity is reclaimed, instance receives 2-minute warning

5

Instance is terminated

Key Takeaway

Spot Instances offer massive cost savings for fault-tolerant, interruptible workloads, but require careful application design to handle potential terminations gracefully.
