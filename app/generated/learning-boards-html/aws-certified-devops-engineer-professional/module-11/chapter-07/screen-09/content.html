Endpoint Types

Choosing the Right VPC Endpoint

Gateway Endpoints are free for S3/DynamoDB, while Interface Endpoints incur hourly and data processing charges.

When to Use Each Type

  • •
    Gateway Endpoints: Always for S3 and DynamoDB from private subnets to eliminate NAT Gateway costs.
  • •
    Interface Endpoints: For other AWS services or PrivateLink-enabled services, evaluate if the endpoint cost is less than NAT Gateway data processing.
Key Takeaway

Prioritize Gateway Endpoints for S3 and DynamoDB to achieve immediate and significant cost savings on data transfer.

VPC Endpoint Comparison
Gateway Endpoint
  • •For S3 & DynamoDB only
  • •FREE to use
  • •Routes via VPC route table
  • •No network interface
Interface Endpoint
  • •For many AWS services (PrivateLink)
  • •Hourly + per-GB charges
  • •Uses Elastic Network Interfaces (ENIs)
  • •Requires security group config
CloudFormation Example: S3 Gateway Endpoint
S3GatewayEndpoint:
  Type: AWS::EC2::VPCEndpoint
  Properties:
    VpcId: !Ref MyVPC
    ServiceName: !Sub "com.amazonaws.${AWS::Region}.s3"
    RouteTableIds:
      - !Ref PrivateRouteTable1
    VpcEndpointType: Gateway

This snippet creates a free Gateway Endpoint for S3, routing traffic privately.
