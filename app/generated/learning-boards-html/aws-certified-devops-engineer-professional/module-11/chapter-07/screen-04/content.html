Core Concept

The Golden Rule of AWS Network Costs

Ingress is generally free, egress costs money, and inter-region egress costs even more.

Understanding Data Flow Costs

  • •
    Ingress (Data In): Data moving into AWS is typically free. Think uploads to S3 or traffic into an EC2 instance.
  • •
    Egress (Data Out): Data moving out of AWS to the internet incurs charges. This is a primary cost driver.
  • •
    Inter-Region Egress: Data moving between different AWS regions is charged at an even higher rate.
Key Takeaway

Proactively design your architecture to minimize egress and inter-region data transfers to control network costs effectively.
