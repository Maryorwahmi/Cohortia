S3 Intelligent-Tiering: The "Set It and Forget It" Option

Automatically optimizing costs for data with unknown or changing access patterns.

1

Automatic Data Movement: Intelligent-Tiering monitors access patterns and automatically moves objects between two access tiers.

2

Frequent Access Tier: For data that is actively being accessed, offering low latency and high throughput.

3

Infrequent Access Tier: If an object hasn't been accessed for 30 consecutive days, it's moved to this lower-cost tier.

4

No Retrieval Fees: Unlike S3 Standard-IA or Glacier, there are no retrieval fees when data is moved back to the frequent access tier by Intelligent-Tiering.

Use Case Scenario

User-Generated Content

A social media platform stores millions of user photos. Some are viewed daily, others only once a year. Intelligent-Tiering automatically optimizes storage costs for each photo based on its actual access frequency, without requiring manual management or complex rules.

Key Takeaway

S3 Intelligent-Tiering is ideal for data with unpredictable access patterns, providing automated cost savings without operational overhead or retrieval fees.

Misconception

Intelligent-Tiering is Always Cheapest

While highly effective, Intelligent-Tiering has a small monthly monitoring and automation fee per object. For data with very predictable, consistently infrequent access, a direct transition to Standard-IA or Glacier via lifecycle policies might be slightly more cost-effective.
