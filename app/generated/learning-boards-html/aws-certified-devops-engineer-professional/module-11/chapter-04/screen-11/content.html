CLI for Unattached EBS Volume Detection

Using AWS CLI to list and safely delete orphaned volumes.

# Example: Listing unattached EBS volumes
aws ec2 describe-volumes \
    --filters Name=status,Values=available \
    --query 'Volumes[].{ID:VolumeId,Size:Size,Type:VolumeType,AZ:AvailabilityZone}'

# Example Output:
[
    {
        "ID": "vol-0abcdef1234567890",
        "Size": 8,
        "Type": "gp2",
        "AZ": "us-east-1a"
    }
]

# Example: Deleting an unattached EBS volume (replace with actual Volume ID)
# aws ec2 delete-volume --volume-id vol-0abcdef1234567890
Command Breakdown

Understanding the CLI Query

  • `describe-volumes`: Retrieves information about EBS volumes.
  • `--filters Name=status,Values=available`: Narrows results to volumes not attached to an instance.
  • `--query 'Volumes[].{...}'`: Formats the output for readability, showing key details.
  • `delete-volume`: The command to permanently remove an EBS volume.
Key Takeaway

Regularly use the AWS CLI to identify and safely delete unattached EBS volumes, ensuring you only pay for storage actively in use.

Safety Precaution

Verify Before Deleting

Before executing `delete-volume`, always confirm that the volume is truly unattached and contains no critical data. Deletion is irreversible, so caution is paramount.
