Advanced Strategies

Backtrack & Graviton Instances

Consider these advanced Aurora features and instance types for further cost optimization.

  • Backtrack: Allows rewinding the database to a point in time. Incurs additional costs for storing change records. Evaluate if the recovery window justifies the expense.
  • Graviton Instances: For provisioned Aurora clusters, Graviton2-based instances (e.g., db.r6g) offer better price-performance than x86 instances.
Pro Tip

For non-critical environments, a traditional snapshot-based recovery might be more cost-effective than Aurora Backtrack.

Key Takeaway

Carefully assess the cost-benefit of advanced features like Backtrack and leverage Graviton instances for superior price-performance.
