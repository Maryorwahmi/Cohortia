Storage Strategy

Cost-Effective RDS Storage

Choosing the right storage type and capacity is crucial to avoid unnecessary costs.

  • General Purpose SSD (gp2/gp3): Most common. gp3 offers better price-performance and independent IOPS/throughput scaling than gp2.
  • Provisioned IOPS SSD (io1/io2): For I/O-intensive transactional workloads requiring consistent, high performance. More expensive.
  • Avoid Over-Provisioning: You pay for allocated storage, not just consumed. Monitor usage and right-size.
Pro Tip

Migrate from gp2 to gp3 for potential cost savings and more granular performance control without downtime.

Key Takeaway

Right-sizing storage and leveraging gp3 are key for RDS storage cost optimization.

CLI Example: Modify RDS Instance
# Example: Modifying an RDS instance to a smaller type
# Requires instance to be in 'available' state
# Replace <DB_INSTANCE_IDENTIFIER> with your RDS instance ID
# Replace <NEW_INSTANCE_CLASS> with the desired class (e.g., db.t3.small)

aws rds modify-db-instance \
    --db-instance-identifier <DB_INSTANCE_IDENTIFIER> \
    --db-instance-class <NEW_INSTANCE_CLASS> \
    --apply-immediately # Or --no-apply-immediately
Safety Note

Modifying production RDS instances can cause brief downtime. Always perform changes during maintenance windows and test thoroughly in non-production environments.
