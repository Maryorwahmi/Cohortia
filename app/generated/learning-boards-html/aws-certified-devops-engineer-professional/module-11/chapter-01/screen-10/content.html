Module 11 › Chapter 11.1 › Embedding cost checks in IaC and CI/CD
IaC patterns
Defaults and parameters that favor cost-effective choices for non-production environments.
Cost-optimized defaults
Set smaller instance types for dev and staging, and require explicit overrides to pick larger sizes.
Template parameters
Expose instance type and storage class as parameters with sensible defaults and tags applied at creation.
Reviewer checklist

Include a step to verify that changes raise the bill only with explicit justification and owner approval.

CI/CD gates
  • Automated diff checks for increased instance sizes or new high-cost services
  • Fail pipelines when a template removes required tags
  • Require a cost rationale for changes that increase hourly estimates
Misconception
Treating cost checks as optional; they are most effective when part of the default pipeline and review flow.
