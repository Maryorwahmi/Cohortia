Module 11 › Chapter 11.1 › Common tagging mistakes
Frequent errors
Simple mistakes that break reporting.
Inconsistent keys
Different teams using different key names prevents aggregation in cost reports.
Missing tags
Quick-test resources without tags create blind spots and orphan spend.
Sensitive data in tags
Tags appear in billing and management views — avoid secrets or sensitive info.
How to avoid them
A combination of taxonomy, templates, and automation.
Publish a short taxonomy
Keep keys minimal and documented: Owner, Project, Environment, CostCenter.
Enforce in IaC
Require tags in templates so resources are created correctly every time.
Automate remediation
Use Config rules to detect issues and trigger notifications or remediation steps.
