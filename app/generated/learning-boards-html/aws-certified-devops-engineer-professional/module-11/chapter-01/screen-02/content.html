Learning Objectives
Four practical outcomes focused on visibility, ownership, tagging, and integration into DevOps workflows.
01
Explain cost in DevOps
Describe why teams that build and run systems must manage their cloud spend. This matters because design choices become recurring costs and must be visible during development.
VERIFIED COMPETENCY MILESTONE
02
Identify cloud waste
Find common waste like always-on non-production instances or unattached volumes and quantify their impact with simple examples.
VERIFIED COMPETENCY MILESTONE
03
Apply the Shared Responsibility Model
Explain which cost decisions are AWS's responsibility and which are yours, with examples like instance selection and storage tiers.
VERIFIED COMPETENCY MILESTONE
04
Implement tagging and automation
Design a basic tag taxonomy, enforce it with simple automation, and add cost-awareness to IaC templates and reviews.
