Module 11 › Chapter 11.1 › Resource tagging fundamentals
Minimal tag taxonomy
Owner, Project, Environment, CostCenter — start small and enforce consistently.
Owner
Person or team accountable for lifecycle and cost.
Project
Business or engineering initiative the resource supports.
Environment
dev, test, staging, or prod — helps set appropriate sizing policies.
Pro tip

Keep keys exactly consistent and publish the taxonomy in a shared place; automate checks that reject resources with unknown keys.

Tag enforcement process
1
Require tags in IaC
Add required tag parameters to templates so resources are created with the correct keys.
2
Detect with Config
Use policies that flag untagged resources and send alerts or create remediation tickets.
3
Automate remediation
For temporary test resources, automatically add expiration tags or terminate resources without owners after a grace period.
Common mistake
Allowing free-form tag keys leads to inconsistent reports; normalize keys and enforce via templates and rules.
