Module 11 › Chapter 11.1 › Launch EC2 with tags (CLI)
Starter CLI commands
Replace the AMI and instance details as needed for your region and account.
aws ec2 run-instances \
  --image-id ami-053b0d53d2792c340 \
  --instance-type t3.micro \
  --count 1 \
  --tag-specifications 'ResourceType=instance,Tags=[{Key=Project,Value=ProjectX},{Key=Environment,Value=Dev},{Key=Owner,Value=DevTeamA},{Key=CostCenter,Value=12345}]' \
  --query 'Instances[0].InstanceId' --output text

# Verify tags
aws ec2 describe-instances \
  --instance-ids  \
  --query 'Reservations[0].Instances[0].Tags'

# Terminate when done
aws ec2 terminate-instances --instance-ids
Note: Passing tags at launch ensures the instance is tagged from creation. If you add tags later, there may be a period where cost reporting misses the association.
Try this

Use the command above in a sandbox account, verify tags, then terminate the instance to practice the full lifecycle.

Common pitfalls
  • Inconsistent key capitalization or naming conventions
  • Forgetting to include tags in IaC templates
  • Storing sensitive information in tags — avoid secrets
Safety note
Do not include secrets or sensitive identifiers in tags, since they may appear in billing or management views.
