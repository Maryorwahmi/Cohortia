Module 11 › Chapter 11.1 › Activity: Implement tagging
Activity steps
Follow these steps in a sandbox account or encode them into IaC for a dry-run.
# Step 1: Launch instance with tags
aws ec2 run-instances --image-id ami-053b0d53d2792c340 --instance-type t3.micro --count 1 --tag-specifications 'ResourceType=instance,Tags=[{Key=Project,Value=ProjectX},{Key=Environment,Value=Dev},{Key=Owner,Value=DevTeamA},{Key=CostCenter,Value=12345}]' --query 'Instances[0].InstanceId' --output text

# Step 2: Verify
aws ec2 describe-instances --instance-ids  --query 'Reservations[0].Instances[0].Tags'

# Step 3: Terminate
aws ec2 terminate-instances --instance-ids
If using IaC: add tag parameters to your template and run a plan/dry-run to inspect the generated resource tags before apply.
Reflection prompts
  • Did the Owner and Project tags match a responsible person or team?
  • Would finance be able to allocate this cost to a project?
  • Was the resource terminated after verification?
Key takeaway
Small habits — tagging at launch and immediate verification — make cost allocation reliable and reduce reconciliation work.
