Module 11 › Chapter 11.1 › Shared Responsibility Model — cost
Where responsibilities lie
AWS: infrastructure efficiency. You: configuration and resource selection.
Customer responsibilities
  • Selecting instance types and sizes
  • Choosing storage classes and retention policies
  • Provisioning only necessary resources and scheduling non-prod shutdowns
AWS responsibilities
Operating the global infrastructure and providing managed services efficiently, but not selecting per-account resource sizes for you.
Misconception check

Believing AWS will automatically choose the most cost-effective instance or storage tier for your workload is incorrect; these choices depend on your workload and must be made by your team.

Example scenario
If you pick a database instance size larger than needed for staging, AWS will run it efficiently but you will still pay for the larger instance every hour. A better approach is to choose smaller staging sizes or schedule them to stop when not in use.
Actionable step
Add a cost review gate for IaC changes that increase instance sizes or storage tiers, so design choices are deliberate and visible.
