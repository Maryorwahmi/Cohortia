Module 11 › Chapter 11.1 › Detecting untagged or orphaned resources
Scan → Classify → Remediate
A repeatable loop to find and resolve resource waste.
Scan
Use resource-tagging APIs or Config rules to identify missing tags across services.
Classify
Decide whether the resource is temporary, production, or backup data to choose appropriate remediation.
Remediate
For temporary resources, add ExpirationDate or schedule termination. For production, notify owner and require action logs.
Automation touchpoints
  • Config rules to flag missing tags
  • Scheduled Lambda to check for expired ExpirationDate tags and terminate
  • Integration with ticketing to route owner notifications
Misconception
Assuming detection is a one-time project; instead make scans routine and automated so drift is caught early.
