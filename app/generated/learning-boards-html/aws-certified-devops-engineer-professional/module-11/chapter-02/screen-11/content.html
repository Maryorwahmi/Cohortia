Hands-on Activity
Hands-on: Create a Cost Budget
Set up a monthly budget with SNS alerts for tagged resources.
Key Takeaway

Successfully configuring a budget with specific filters and SNS alerts provides practical experience in proactive AWS cost management.

Activity Goal

To create a $100 monthly cost budget for resources tagged `Project: InternalTools` and receive an SNS alert when actual costs exceed 80%.

Steps Overview

1. Create SNS Topic & Subscribe Email.

2. Create Cost Budget: $100/month, Filter: `Project: InternalTools`.

3. Configure Alert: Actual cost > 80%, SNS recipient.

4. Review and Create Budget.

Starter Code (CLI Example)
# Note: Budget creation is typically done via Console or CloudFormation.
# CLI example for SNS topic creation (requires confirmation):
# aws sns create-topic --name InternalToolsBudgetAlerts --region us-east-1
# aws sns subscribe --topic-arn  --protocol email --notification-endpoint your-email@example.com --region us-east-1
