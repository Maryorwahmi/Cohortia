Assessment Idea
Check Your Understanding: Cost Drivers
Identify the best tool for analyzing spending patterns.
Key Takeaway

AWS Cost Explorer is the go-to tool for analyzing historical spending to pinpoint top cost-driving services and projects.

Scenario

Increasing AWS bill, unclear cost drivers.

Need to identify top 5 services and projects from last quarter.

Solution

**Tool:** AWS Cost Explorer

**Steps:** 1. Set time range (last quarter). 2. Group by 'Service', sort descending. 3. Filter by 'Project' tag, group by 'Project', sort descending.
