Automation Example › Stop Idle Instances
Automated stoppage with safe overrides
Use scheduled events and Lambda to stop idle, non-exempt instances after notification and grace period.
Design pattern
  • Detect with CloudWatch schedule or Config.
  • Filter instances by tag and runtime.
  • Notify owner and wait, then stop if no exemption.
Pitfall
Not notifying owners or lacking override tags can interrupt productive work; include clear communication and audit logs.
Example sequence (pseudo-commands)
# CloudWatch scheduled rule triggers Lambda daily
# Lambda pseudo-logic:
# 1. Describe instances with state=running
# 2. Filter where LaunchTime older than 24 hours
# 3. Exclude instances with tag Key=do-not-stop,Value=true
# 4. Publish notification to SNS using Owner tag
# 5. If no exemption after grace period, stop instances via EC2 stop-instances

# This pattern balances automation with owner notification and override handling.
