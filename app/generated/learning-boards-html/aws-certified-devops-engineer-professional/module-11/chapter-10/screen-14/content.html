What to Remember
Key Concepts
Cost Governance
Policies, processes, and tools that manage cloud spending and align tech decisions with business goals.
SCPs
Organization-level policies that prevent disallowed or costly actions across accounts.
AWS Config Rules
Continuous checks that evaluate resource configurations and can trigger remediation or alerts.
Summary Takeaway

Use tagging for visibility, SCPs for prevention, Config for detection and remediation, and pipeline checks to shift governance left. Combine tools with FinOps culture for continuous improvement.
