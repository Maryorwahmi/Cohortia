Hands-on Activity › Create a Config Rule for Tagging
Activity steps
Create the required-tags rule, test with compliant and noncompliant instances, and clean up.
Step summary
  1. Enable AWS Config and record EC2 instances.
  2. Create the required-tags managed rule with Owner as the key.
  3. Launch a noncompliant instance and a compliant one to observe results.
  4. Decide on notifications or remediation, then clean up test resources.
Starter command
aws configservice put-config-rule \
    --config-rule '{"ConfigRuleName":"ec2-owner-tag-required", "Description":"Checks if EC2 instances have the Owner tag.", "Scope":{"ComplianceResourceTypes":["AWS::EC2::Instance"]}, "Source":{"Owner":"AWS","SourceIdentifier":"REQUIRED_TAGS"}, "InputParameters":"{\"tag1Key\":\"Owner\"}"}' \
    --region us-east-1
Testing and cleanup
After verifying compliance states, terminate test instances and delete the Config rule if it was temporary. If this is a permanent rule, attach notifications and remediation carefully.
Reflection
Would you start enforcement with alerts only or with automated remediation? Choose the least disruptive path for initial rollout.
