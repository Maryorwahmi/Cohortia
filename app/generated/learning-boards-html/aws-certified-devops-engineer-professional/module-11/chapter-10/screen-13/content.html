Preventive, detective, corrective
Select controls based on whether you need prevention, detection, or correction.
When to use SCPs
Preventive guardrails at the organization level for high-impact actions like blocking large instances.
When to use Config
Continuous detection and remediation for per-resource settings such as tags and encryption.
When to use CI/CD checks
Shift-left prevention: estimate template cost and run policy-as-code validations to stop nonconforming templates before they reach the control plane.
