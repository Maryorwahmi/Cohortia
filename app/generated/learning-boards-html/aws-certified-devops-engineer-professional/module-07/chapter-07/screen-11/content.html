Module 7 › Chapter 7.7 › S3 Cross-Region Replication
CRR overview
Asynchronous replication for objects to other Regions; useful for DR and static content distribution.
Use cases
  • Static asset distribution for lower latency.
  • Cross-Region backups and compliance storage.
  • Disaster recovery for user-uploaded content.
Design considerations
Enable versioning, consider replication filters, and account for eventual consistency windows when serving newly uploaded objects from other Regions.
Common mistake
Expecting immediate replication and using CRR for transactional data. CRR is asynchronous and best for objects and static content.
Key Takeaway

Use CRR for static asset distribution and backups, and pair it with database replication solutions for transactional data.
