Routing policy comparison
Select the policy that matches performance, compliance, or rollout needs.
Latency-based
Routes to the Region that provides lowest measured latency. Improves performance for global users but depends on resolver paths.
Geolocation
Routes based on user geographic location. Useful for regulatory or localized content delivery.
Geoproximity
Biases traffic by geographic distance and optional traffic shift controls between endpoints.
Weighted
Distribute traffic by weight for rollouts and testing. Combine with health checks to avoid routing to unhealthy endpoints.
Practical notes
  • Always attach health checks to critical records to enable automatic failover.
  • Latency routing selects the lowest-latency Region from the resolver's perspective, not necessarily geographic distance.
  • Combine policies sparingly — complex stacks can be hard to reason about during outages.
