Learning Objectives
Skills and outcomes you will achieve
Learn → Understand → Apply → Master
01
Design Active/Active deployments
Build applications deployed and serving traffic from multiple Regions so outages in one Region do not cause service interruptions. This matters when you require near-zero RTO and global low latency.
Verified Competency Milestone
02
Implement Route 53 routing policies
Use latency, geolocation, geoproximity and weighted policies together with health checks to route users to optimal or healthy Regions for performance and compliance reasons.
Verified Competency Milestone
03
Leverage Global Accelerator
Use static IPs and the AWS global network to reduce latency and provide faster failover than DNS alone, especially for non-HTTP traffic or when static IPs are required.
Verified Competency Milestone
04
Manage cross-Region replication & consistency
Configure DynamoDB Global Tables, S3 CRR, and understand constraints of relational replication. Plan for eventual consistency and synchronization strategies in active-active writes.
Verified Competency Milestone
