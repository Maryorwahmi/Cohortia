Module 7 › Chapter 7.3 › Graceful Degradation & Backpressure
Operational Strategy

Keep the core user journey working under stress

Graceful degradation

Design fallback behaviors so nonessential features can be disabled while core flows continue.

Example

If a recommendation engine fails, allow purchases without recommendations to avoid blocking checkout.

Backpressure mechanisms
  • Queue depth-based throttling.
  • Return explicit rate-limit responses so callers can slow down.
  • Switch clients to asynchronous mode when downstream is overloaded.
Pitfall

No monitoring or signals: if you can’t detect overload, you can’t apply backpressure effectively.

Key Takeaway

Plan reduced-function modes and explicit throttling signals to stop overloads from becoming outages.
