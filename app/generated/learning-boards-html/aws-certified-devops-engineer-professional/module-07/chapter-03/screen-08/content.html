Module 7 › Chapter 7.3 › Amazon SQS for Decoupling
Architecture

Use SQS to decouple and buffer work

How it helps
  • Buffers bursts of traffic.
  • Allows independent scaling of producers and consumers.
  • Durable storage prevents message loss between services.
Operational signals

Monitor queue depth, age of oldest message, and receive counts to detect backlog or poison messages.

Example: sending a message (Python)
import boto3
import json

sqs = boto3.client('sqs')
queue_url = 'YOUR_SQS_QUEUE_URL'

message_body = {
  "orderId": "12345",
  "productId": "ABC",
  "quantity": 2
}

response = sqs.send_message(
  QueueUrl=queue_url,
  MessageBody=json.dumps(message_body),
  MessageGroupId='OrderProcessing', # Required for FIFO queues
  MessageDeduplicationId='unique-order-12345' # Required for FIFO queues
)
print(f"Message sent: {response['MessageId']}")
Key Takeaway

SQS decouples components so work can be retried or inspected later without blocking producers.
