Scenario

Three-tier web application

RTO: 4 hours. RPO: 1 hour. Decide a DR approach and list services per tier to implement it.

Recommended strategy
Pilot Light: maintain replicated data and a minimal compute footprint in the DR Region to meet the RTO and RPO at moderate cost.
Implementation by tier
  • Web Tier: store AMIs and CloudFormation templates; small ASG in DR Region to hold code.
  • Application Tier: same templates and a minimal ASG; keep deployments synchronized via CI/CD.
  • Database: RDS cross-region read replica that can be promoted to primary.
  • Static Assets: S3 Cross-Region Replication and CloudFront with multi-origin if desired.
Checks
  • Test promoting the DB replica and verifying integrity.
  • Validate scaling operations to meet the four-hour RTO.
  • Automate DNS changes and run smoke tests post-failover.
Key Takeaway

Map each tier to replication and provisioning patterns, automate promotion, and practise the end-to-end recovery to be confident you meet RTO and RPO targets.
