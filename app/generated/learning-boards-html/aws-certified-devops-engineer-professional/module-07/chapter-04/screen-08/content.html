Module 7 › Chapter 7.4 › Multi-Site Active/Active
Pattern

Active / Active

Fully deploy and serve traffic in multiple Regions with continuous data synchronization and global routing, achieving near-zero RTO and RPO.

Considerations:
  • Data consistency strategies and conflict resolution.
  • Global routing and health checks.
  • Significant operational and cost overhead.
When to pick

Mission-critical systems that require immediate continuity and minimal data loss, such as high-volume financial processing.

Key Takeaway

Active-active provides the best user experience during region failures but adds the highest cost and complexity. Use it only when near-zero RTO and RPO are required.
