Routing options

Route 53 and Global Accelerator

Use Route 53 failover, latency-based routing, or Global Accelerator to direct user traffic to healthy Regions. Configure health checks to automate failover where appropriate.

Operational tips
  • Automate DNS updates as part of the recovery runbook.
  • Keep DNS TTLs balanced to reduce propagation time.
  • Run smoke tests after failover to validate service health.
Key Takeaway

Automated, validated DNS changes are essential to minimize RTO; plan TTLs and health checks to avoid blind spots during failover.
