Module 7 › Chapter 7.4 › Pilot Light
Concept

Pilot Light

Keep a minimal, ready-to-scale core in the DR Region: critical data replicated and small compute running with the application code present.

Typical components
Read replicas for databases, S3 replication for objects, and a small compute footprint with deployment artifacts kept current.
Recovery process
  1. Promote the DB replica to primary and verify data integrity.
  2. Scale compute to production capacity using ASG or templates.
  3. Update DNS so clients route to the DR Region and run smoke tests.
Key Takeaway

Pilot Light balances reduced RTO/RPO with moderate ongoing cost. Automate promotion and DNS changes to achieve predictable recovery times.
