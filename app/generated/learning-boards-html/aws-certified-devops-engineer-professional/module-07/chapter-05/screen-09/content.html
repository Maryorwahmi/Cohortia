Module 7 › Chapter 7.5 › Cross-Region Copy
What it does

Copy recovery points across Regions

Add copy actions to backup rules to replicate recovery points to a destination vault in another Region and apply retention specific to the copy.
Example rule snippet
"CopyActions": [
  {
    "DestinationBackupVaultArn": "arn:aws:backup:us-west-2:123456789012:backup-vault:Default",
    "Lifecycle": { "DeleteAfterDays": 365 }
  }
]
Operational notes
Cross-Region copies are asynchronous and require KMS grants and appropriate IAM roles. Validate that copies appear in the destination vault and that you can restore from them during testing.
Key takeaway: Cross-Region copy ensures isolation of recovery points from a single Region failure.
Common mistake: Not granting the destination KMS key the right permission prevents decryption of copied recovery points.
