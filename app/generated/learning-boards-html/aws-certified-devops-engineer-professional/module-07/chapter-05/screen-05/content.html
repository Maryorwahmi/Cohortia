Module 7 › Chapter 7.5 › AWS Backup
Supported resources

One service, many targets

Services supported include EC2 snapshots, EBS volumes, Amazon RDS, DynamoDB tables, Amazon EFS, Amazon FSx, and AWS Storage Gateway volumes.
Centralization simplifies policy enforcement, auditing, and lifecycle management across these resource types.
Example
Define a single backup plan that schedules daily snapshots for both RDS and EC2 instances tagged as Production so new instances inherit protection automatically.
Operational notes
Use a backup vault for storage and encryption, and ensure AWS Backup has the IAM role it needs to manage snapshots. Without the role, backups will fail.
Benefit
Consistent backups across services and simplified compliance reporting.
Common mistake
Not assigning the correct IAM role to AWS Backup, preventing snapshots and copy actions.
