Module 7 › Chapter 7.5 › Backup Plan Design
Process

From RTO/RPO to backup rules

1. Schedule
Choose cron or daily expressions to meet RPO requirements.
2. Backup Window
Pick a start window that avoids peak load and allows completion.
3. Retention
Set retention to meet recovery and compliance needs.
4. Lifecycle & Copy Actions
Transition older backups to colder storage and add cross-Region copies for offsite durability.
Concrete example
Daily backups at 05:00 UTC, StartWindow 60 minutes, CompletionWindow 180 minutes, Retain 35 days. Cross-Region copy retained 365 days and lifecycle transition to archival after 90 days.
Common mistake
Not accounting for backup duration and causing overlapping jobs that can fail or extend past completion windows.
Key takeaway
Translate service-level RTO/RPO to concrete schedule, windows, retention and lifecycle settings, then test them.
