Practical checklist

Step-by-step tasks to practice core backup and S3 operations.

1. Launch a tagged EC2 instance and verify tags.
2. Create an AWS Backup plan: daily schedule, 7-day retention, cross-Region copy.
3. Assign resources by tag to the backup plan.
4. Enable S3 versioning and configure CRR between Regions, then upload a file and verify replication.

Quick warnings & tips

Tip: Use tags for consistent selection and fewer manual steps.
Warning: Missing IAM role for AWS Backup or S3 replication will block operations.
Validation: Always run a simulated restore into a test environment and update runbooks with the results.
