Durability

S3 durability and storage

S3 offers high durability for backups and is suited for object storage, including logs and archived configuration files. Consider storage class choices when planning cost and retrieval time.
Versioning & Object Lock

Protect object history

Enable versioning to preserve prior object states. Enable object lock for WORM-style protection to prevent deletion or modification for a retention period.
CLI reminder
aws s3api put-bucket-versioning --bucket my-source-bucket --versioning-configuration Status=Enabled
Key takeaway
Versioning plus object lock provides recoverability and regulatory protection, but plan lifecycle and cost implications before enabling both.
