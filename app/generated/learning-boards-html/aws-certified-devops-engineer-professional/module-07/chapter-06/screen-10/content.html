Module 7 › Chapter 7.6 › Hands-on Activity
Activity steps (condensed)
  1. Launch primary RDS PostgreSQL in us-east-1 and enable automated backups.
  2. Create table and insert sample data to verify baseline.
  3. Create Cross-Region read replica in us-west-2 and wait for availability.
  4. Query replica to confirm read replication; attempt writes to confirm read-only state.
  5. Optional sandbox: promote the replica and validate write capability, then document steps for automation.
Verification SQL (visual)
-- On primary (us-east-1)
INSERT INTO products (name, price) VALUES ('Keyboard', 75.00);

-- On read replica (us-west-2) after a short delay
SELECT * FROM products;
Record how long replication takes and any manual configuration you needed. Use results to parameterize automation timeouts and health check windows.
