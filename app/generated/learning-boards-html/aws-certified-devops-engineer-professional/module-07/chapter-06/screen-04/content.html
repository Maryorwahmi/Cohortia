Module 7 › Chapter 7.6 › Pilot Light Architecture
Definition
Keep core data replicated in a DR Region while compute is provisioned when required using versioned IaC templates.
How it works
  1. Configure Cross-Region read replica for RDS (asynchronous replication).
  2. Keep CloudFormation/CDK templates in version control for compute and networking.
  3. On failover: promote replica, launch stacks, reconfigure app endpoints, update DNS using failover routing.
Example scenario
Primary DB in us-east-1 with replica in us-west-2. Promote the replica, launch a small EC2/ALB stack from CloudFormation, attach the DB endpoint, then move DNS via Route 53 failover.
Common mistake
Not keeping AMIs and templates up-to-date causes configuration drift and failed launches during recovery.
