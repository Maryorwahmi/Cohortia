Pilot Light and Warm Standby DR Architectures
How to keep data replicated, templates ready, and traffic routed during a Region failure.
In this lesson
Compare Pilot Light and Warm Standby, set up Cross-Region RDS replication, maintain IaC templates, and automate failover with Systems Manager or Lambda.
Why it matters
Critical applications need predictable RTO/RPO. These patterns let you trade cost for reduced downtime while keeping recovery repeatable and testable.
Explore Key Topics
Cross-Region Read Replica
Asynchronous replication of RDS to a recovery Region, promoted on failover.
IaC for DR
Keep CloudFormation or CDK stacks in version control so DR provisioning is repeatable.
Route 53 Failover
Use health checks and failover routing to redirect traffic to the DR Region when needed.
Interactive Concept
Pilot Light — Data first
Keep the database replicated; provision compute on demand via templates.
Warm Standby — Running app
Scaled-down application runs continuously and can be scaled up quickly on failover.
Automation
Systems Manager automation and Lambda help make failover repeatable and auditable.
