Learning Objectives
Skills you'll demonstrate for Pilot Light and Warm Standby
Learn → Understand → Apply → Master
01
Design Pilot Light with IaC
Author CloudFormation or CDK templates that define DR compute, networking, and deployment so you can bring up compute quickly when needed.
Verified Competency Milestone
02
Configure Route 53 failover
Create failover records and health checks so DNS automatically points to the DR endpoint when the primary fails.
Verified Competency Milestone
03
Set up Cross-Region replicas
Provision RDS read replicas in a separate Region to maintain an up-to-date replica ready for promotion during failover.
Verified Competency Milestone
04
Automate failover and failback
Use Systems Manager Automation, Lambda, and CloudWatch to promote replicas, scale groups, and update DNS with repeatable scripts.
Verified Competency Milestone
