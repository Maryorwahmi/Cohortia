Module 8 › Chapter 7.8 › AWS Resilience Hub
What Resilience Hub does
Discover
Import app resources to build a resilience model.
Assess
Evaluate components against RTO/RPO policies and best practices.
Recommend
Actionable fixes such as enabling Multi-AZ or backups.
Validate
Orchestrate tests and track SOPs for recovery validation.
Example scenario
Non-Multi-AZ DB
Resilience Hub flags a critical DB in a single AZ for a workload with tight RTO. Recommendation: enable Multi-AZ or configure replica promotion runbook.
Assessment checklist
  • Import resources from CloudFormation or AppRegistry.
  • Define RTO and RPO targets per application.
  • Review prioritized recommendations and remediation cost.
  • Schedule validations and link to FIS experiments as needed.
Key Takeaway

Use Resilience Hub to make resilience measurable and to prioritize fixes that reduce risk to business targets.
