Module 8 › Chapter 7.8 › Chaos Engineering
Core principles
  1. Hypothesize a steady state and expected behavior under failure.
  2. Vary realistic events that mimic production faults.
  3. Run experiments safely, starting small and increasing scope.
  4. Automate and record experiments, then use results to improve systems.
Representative experiments
Instance termination
Terminate a single worker and verify ASG replacement and client continuity.
Network latency
Inject latency to exercise timeouts and retry behavior.
Checklist
  • Define steady state metrics to measure impact.
  • Create explicit stop conditions and roles to limit blast radius.
  • Start small, observe, then increase scope.
  • Document results and update runbooks.
Pro Tip

Use staging to validate experiment design before any production injection. Small experiments often find the biggest issues.
