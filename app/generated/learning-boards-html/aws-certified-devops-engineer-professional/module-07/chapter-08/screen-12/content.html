Module 8 › Chapter 7.8 › CI/CD Integration
Pipeline checks
  • Static policy checks for RTO/RPO alignment (e.g., Multi-AZ flags).
  • Integration tests for health checks and autoscaling in staging.
  • Automated FIS experiments in a gated stage with approval for production runs.
Example
Pre-release resilience gate
Run a check that ensures backups and Multi-AZ are enabled. Fail the build if the check fails and open a remediation task.
Operational advice

Keep fast pipelines free of heavy experiments. Use staged pipelines with approvals for experiments that touch production. Capture experiment artifacts for audits and learning.

Key Takeaway

Automated checks in CI/CD prevent regressions and ensure resilience stays aligned with code and infra changes.
