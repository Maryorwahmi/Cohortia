Process Flow
ALB → Target Group → Listener
Steps
1. Create ALB
Choose public subnets in at least two AZs and an appropriate security group.
2. Create Target Group
Set protocol and port, and a health check path such as /health that validates application readiness.
3. Create Listener
Create a listener on port 80 or 443 that forwards to the target group and verify routing behavior.
Tip
Attach an ASG to the target group so instances register automatically and are balanced across AZs.
CLI snippet
# create load balancer
aws elbv2 create-load-balancer --name my-ha-alb --subnets subnet-0a subnet-0b --security-groups sg-aaa --scheme internet-facing --type application

# create target group
aws elbv2 create-target-group --name my-app-targets --protocol HTTP --port 80 --vpc-id vpc-0 --health-check-protocol HTTP --health-check-path /health
Validation
After launch, wait for targets to become healthy, then browse the ALB DNS and refresh to verify requests hit different instances.
