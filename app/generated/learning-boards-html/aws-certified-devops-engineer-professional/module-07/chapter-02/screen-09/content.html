Definition
ElastiCache Multi‑AZ
Replication groups and AZ distribution preserve cache availability and reduce database pressure during failures.
Redis replication groups
  • Create a replication group with automatic failover enabled to promote a replica if the primary fails.
  • Place nodes in different AZs to tolerate AZ outages.
  • Test failover and client reconnection to confirm minimal impact.
Memcached considerations
Memcached relies on client-side sharding and node replacement; distribute nodes across AZs so losing one node does not eliminate the entire cache. Warm caches as part of bootstrapping where possible.
Common mistake
Assuming a cache miss is harmless. Losing warm cache state can spike database load and increase latency.
Key takeaway

Treat cache HA as a first‑class concern: replication, AZ placement, and failover testing keep application latency predictable during failures.
