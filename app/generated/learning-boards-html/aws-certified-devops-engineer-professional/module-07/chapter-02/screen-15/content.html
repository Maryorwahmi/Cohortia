Module 7 › Chapter 7.2 › What to Remember
Place redundancy across AZs
Distribute compute, data, and caches so no single AZ outage causes service loss.
Use meaningful health checks
Probe application readiness endpoints so load balancers and DNS make correct routing decisions.
Automate and test
Use templates for repeatability and run staged failovers to measure RTO and RPO.
Final thought

Design for failure: assume components will fail and bake in automated, tested recovery across layers.
