Module 7 › Chapter 7.2 › Learning Objectives
01
Implement ASG & ELB

Create Auto Scaling Groups and Application or Network Load Balancers to distribute traffic and maintain desired capacity across multiple AZs. This matters because automatic replacement of failed instances preserves availability without manual intervention.

Verified Competency Milestone
02
Configure Multi‑AZ RDS & ElastiCache

Enable Multi‑AZ so AWS provisions a synchronous standby in another AZ for automatic failover. Practice checking failover times and distinguishing Multi‑AZ from asynchronous read replicas.

Verified Competency Milestone
03
Use S3 durability and replication

Leverage S3’s inherent multi‑AZ durability, enable versioning, and configure cross‑region replication for disaster recovery and protection from accidental deletions.

Verified Competency Milestone
04
Route 53 health checks and failover

Configure Route 53 health checks and failover records so DNS automatically redirects clients away from unhealthy endpoints. Verify health checks reflect application readiness, not just host availability.

Verified Competency Milestone
