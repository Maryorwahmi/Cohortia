Definition
Elastic Load Balancers
Route client requests to healthy targets and integrate with ASG for capacity and resilience.
Compare ALB and NLB
Application Load Balancer
HTTP/HTTPS routing, host and path based rules, ideal for web apps.
Network Load Balancer
TCP/UDP, static IPs, ultra low latency and high throughput.
Health checks
  • Use an application endpoint such as /health that verifies database connectivity and request handling.
  • Set appropriate intervals and thresholds so transient spikes don’t mark targets unhealthy prematurely.
CLI example: create ALB and target group
aws elbv2 create-load-balancer \
    --name my-ha-alb \
    --subnets subnet-0abcdef1234567890 subnet-0fedcba9876543210 \
    --security-groups sg-0123456789abcdef0 \
    --scheme internet-facing \
    --type application

aws elbv2 create-target-group \
    --name my-app-targets \
    --protocol HTTP \
    --port 80 \
    --vpc-id vpc-0abcdef1234567890 \
    --health-check-protocol HTTP \
    --health-check-path /health \
    --health-check-interval-seconds 30 \
    --health-check-timeout-seconds 5 \
    --healthy-threshold-count 2 \
    --unhealthy-threshold-count 2
Example note
This sequence sets up a basic ALB and target group with a health check path. Automate it with CloudFormation or CDK for repeatable HA deployments.
