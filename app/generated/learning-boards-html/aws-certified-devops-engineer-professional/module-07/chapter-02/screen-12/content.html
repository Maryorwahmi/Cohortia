Hands-on Activity
Launch Template user data
Use this script in your Launch Template user data to install Nginx and display AZ information.
#!/bin/bash
yum update -y
yum install -y nginx
systemctl start nginx
systemctl enable nginx
AZ=$(curl -s http://169.254.169.254/latest/meta-data/placement/availability-zone)
HOST=$(hostname -f)
echo "<h1>Hello from ${HOST} in AZ ${AZ}</h1>" > /usr/share/nginx/html/index.html
Activity steps
  1. Create a VPC with at least two public subnets in separate AZs and appropriate route tables.
  2. Create a Launch Template that uses the user data above and an AMI with Amazon Linux 2.
  3. Create a target group for port 80 and an ALB across the public subnets; set health check path to /.
  4. Create an ASG with desired capacity 2, min 2, max 4, using the Launch Template and attach it to the target group.
  5. Validate by visiting the ALB DNS and refreshing to see different AZ hostnames; terminate an instance and observe replacement.
