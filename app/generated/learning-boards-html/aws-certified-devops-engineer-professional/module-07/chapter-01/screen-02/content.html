Learning Objectives
Skills and competence milestones you'll achieve.
Bloom: Learn → Understand → Apply → Master
01
Differentiate HA, FT, DR
Explain each term, with examples of cloud patterns like multi-AZ, active-active replication, and cross-region failover. This skill matters because accurate terms drive correct design choices.
VERIFIED COMPETENCY MILESTONE
02
Understand RTO and RPO
Define recovery time and recovery point objectives, compute targets for services, and see how they constrain replication and failover approaches.
VERIFIED COMPETENCY MILESTONE
03
Explain AWS global infrastructure
Describe Regions, Availability Zones, and Edge Locations and how their isolation and connectivity affect availability and disaster recovery plans.
VERIFIED COMPETENCY MILESTONE
04
Identify failure causes and cost trade-offs
List common system failures, match mitigation strategies, and evaluate cost implications so designs align with business priorities.
VERIFIED COMPETENCY MILESTONE
