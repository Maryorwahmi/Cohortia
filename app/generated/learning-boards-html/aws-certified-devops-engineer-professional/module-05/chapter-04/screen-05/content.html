Protocols at a glance
HTTP/S
Best for integrations like PagerDuty. Supports structured JSON and immediate incident creation.
Lambda
Use for enrichment, transformation, and conditional routing. Requires proper IAM permissions and robust error handling.
SQS
Durable buffering; ideal as DLQ or decoupling layer when processing may be slow or unreliable.
Design guidance
  • Separate topics by severity and ownership to control who gets notified.
  • Apply filter policies so subscribers see only relevant messages.
  • Attach DLQs for subscriptions that target code or external endpoints.
Concrete scenario
A payment-service publishes to CriticalPaymentAlerts. PagerDuty receives CRITICAL via HTTPS; a Lambda enriches with transaction details for internal audit logs.
