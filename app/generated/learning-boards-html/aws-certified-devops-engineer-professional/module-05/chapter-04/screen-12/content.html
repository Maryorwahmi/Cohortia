Module 5 › Chapter 5.4 › Mistakes & Practices
Common mistakes
  • Not configuring a DLQ for critical subscriptions.
  • Using a single topic for all severities, causing alert fatigue.
  • Assuming delivery implies successful processing by subscribers.
Best practices
  • Attach a DLQ and test it.
  • Use message attributes and filters to reduce noise.
  • Monitor SNS failure metrics and set alarms.
