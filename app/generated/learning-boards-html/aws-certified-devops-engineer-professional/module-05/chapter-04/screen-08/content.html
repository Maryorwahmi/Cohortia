Module 5 › Chapter 5.4 › Subscribe with DLQ
Step-by-step CLI
# Create SQS queue
aws sqs create-queue --queue-name MySnsDlqQueue

# Get its ARN
DLQ_ARN=$(aws sqs get-queue-attributes --queue-name MySnsDlqQueue --attribute-names QueueArn --query 'Attributes.QueueArn' --output text)

# Create SNS subscription with DLQ (example for Lambda protocol)
aws sns subscribe \
  --topic-arn  \
  --protocol lambda \
  --notification-endpoint  \
  --attributes "RedrivePolicy={\"deadLetterTargetArn\":\"$DLQ_ARN\"}"
Notes & checks
  • Confirm the SQS queue ARN is correct and accessible from SNS.
  • Simulate a failing endpoint and then inspect the DLQ for the message.
  • Remember to give SNS permission to send messages to the SQS queue if necessary.
Common pitfall
Misformatting the RedrivePolicy JSON will create a subscription without a working DLQ. Use correct escaping in CLI commands.
