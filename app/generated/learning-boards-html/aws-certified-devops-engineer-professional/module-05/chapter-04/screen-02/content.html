Send SNS messages to PagerDuty's HTTPS endpoint or use Lambda to map payloads. Verified competency: a PagerDuty incident is created by a test alert.

04
Build Lambda-based alert logic

Enrich, transform, and route alerts programmatically. Verified competency: Lambda transforms an incoming SNS message and forwards to a test endpoint.
