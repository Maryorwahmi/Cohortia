Module 5 › Chapter 5.4 › Message Filtering
Process

Publish with attributes → Subscriber filter evaluates

Publish messages with attributes and create a subscription filter policy to allow or deny delivery to that subscriber.

Filter policy example
{
  "severity": ["CRITICAL", "HIGH"]
}
Concrete CLI example
aws sns publish \
  --topic-arn arn:aws:sns:us-east-1:123456789012:CriticalApplicationAlerts \
  --message "Database connection error on Production server!" \
  --message-attributes 'severity={DataType=String,StringValue=CRITICAL},environment={DataType=String,StringValue=Production}'
Test by publishing a LOW severity message and confirm the filtered subscriber does not receive it. Filters do not change the message body.
