Module 5 › Chapter 5.4 › Testing & Validation
Test 1 — Delivered

Publish a CRITICAL message and confirm PagerDuty creates an incident. Validate payload fields and timestamps.

Example publish command includes message attributes for severity and environment. Observe the endpoint receives the JSON and PagerDuty records the incident.
Test 2 — Filtered

Publish a LOW severity message and confirm it does not reach the subscriber, validating your filter policy.

Confirm by checking the mock endpoint logs and that no PagerDuty incident is created.
Test 3 — DLQ capture

Make endpoint unreachable, publish a CRITICAL message, and after retries, confirm it appears in the SQS DLQ for inspection and replay.
