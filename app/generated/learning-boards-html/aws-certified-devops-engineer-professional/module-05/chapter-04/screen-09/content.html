Module 5 › Chapter 5.4 › PagerDuty Integration
Quick setup
Create an SNS subscription with protocol HTTPS and the PagerDuty integration URL. Decide whether to enable raw message delivery based on PagerDuty's expected schema or use a Lambda transformer to shape the payload.
aws sns subscribe \
  --topic-arn  \
  --protocol https \
  --notification-endpoint https://events.pagerduty.com/integration//enqueue
Testing checklist
  • Test 1: Publish CRITICAL → confirm an incident is created in PagerDuty.
  • Test 2: Publish LOW → confirm it is filtered out if appropriate.
  • Test 3: Simulate endpoint failure → confirm message lands in DLQ.
