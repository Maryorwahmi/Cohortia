Module 5 › Chapter 5.3 › Practice Plan

Practice & Assessment

Short, focused activities map to each learning objective so you can practice safely in a real AWS account or sandbox.

Activity: Create Lambda & Rule
Create a Python Lambda that logs events, then author an EventBridge rule that triggers on EC2 stopped state and connect the Lambda as the target. Test by stopping an instance and verifying CloudWatch Logs.
Activity: Pattern Authoring
Practice writing JSON event patterns that match nested fields, numeric ranges, or anything-but clauses. Use the console's test feature to validate your pattern before creating the rule.
Activity: Schema Registry
Send a sample event and allow EventBridge to infer the schema. Publish it to the registry and generate code bindings to confirm type safety in your IDE.
Assessment Idea
Choose the correct event pattern to capture S3 DeleteObject events via CloudTrail, and explain why other patterns would be too broad or reference the wrong detail-type fields.
