Python Lambda example

This minimal handler logs the event, extracts instance id, state, and time, and returns a success response. Extend it to restart instances or publish notifications safely.

import json
import os
import boto3

def lambda_handler(event, context):
  print("Received event:", json.dumps(event, indent=2))

  instance_id = event['detail']['instance-id']
  state = event['detail']['state']
  time = event['time']

  message = f"EC2 instance {instance_id} changed state to {state} at {time}."
  print(message)

Concrete extension
Add idempotency checks using a DynamoDB lock or record to avoid repeated restarts on retries.
Common pitfall
Do not assume nested fields always exist. Validate the event shape before accessing nested keys to avoid handler errors.
Debugging tip
Print the entire event to CloudWatch on first runs to confirm the shape, then remove verbose logging after validation.
Key Takeaway

Start by logging and validating events, then add safe remediation steps and idempotency guards before taking destructive actions.
