Query example
fields @timestamp, @message
| filter @logStream like /ERROR/
| parse @message "Request ID: *" as request_id
| stats count(*) by request_id, bin(1m)
| sort @timestamp desc
| limit 20
Explanation: filter finds candidate events, parse extracts a field, stats groups and counts by time bin, and limit prevents large result sets.
Tips and pitfalls
  • Start broad; refine with filters to avoid missing variant messages.
  • Use parse with simple patterns; complex regex can be slow.
  • Always apply limit and binning to keep queries responsive.
Example scenario
Find all errors in the last five minutes and count by request id to find a failing client or API endpoint.
