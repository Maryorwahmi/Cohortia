How subscription filters work
Define a filter pattern on a log group and send matching events to a destination in real time.
Destination
Lambda, Kinesis, or Firehose
Filter Pattern
Empty (all) or specific patterns like "ERROR" or structured patterns for fields.
Permissions
Destination must allow CloudWatch Logs to deliver using the provided role ARN.
Example AWS CLI
aws logs put-subscription-filter \\
  --log-group-name MyLogGroup \\
  --filter-name MyLambdaSubscriptionFilter \\
  --filter-pattern "" \\
  --destination-arn arn:aws:lambda:us-east-1:123456789012:function:MyLogProcessorFunction \\
  --role-arn arn:aws:iam::123456789012:role/CloudWatchLogsLambdaAccessRole
Quick rules
  • Empty filter forwards everything.
  • Specific patterns lower cost and load.
  • Verify role permissions to avoid delivery failures.
Check your understanding
When would you use an empty pattern? When you need to deliver all events, for example to an archival Firehose pipeline.
