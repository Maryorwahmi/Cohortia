Configure CloudWatch Agent

Query with Logs Insights

VERIFIED COMPETENCY MILESTONE
03
Implement subscription filters
Stream matching events to Lambda, Kinesis, or Firehose for real-time alerting, enrichment, or delivery.

04
Design Firehose delivery
Choose buffers, compression, and IAM roles so Firehose reliably writes partitioned files to S3 or forwards to Redshift/OpenSearch.

Mnemonic & Mapping
Think: Collect → Query → Stream → Store. Each step maps to: Agent/Service logs → Logs Insights → Subscription Filters/Lambda → Kinesis Firehose → S3/Redshift/OpenSearch.
Collect
Agents and automatic service exports.

Stream

Store
