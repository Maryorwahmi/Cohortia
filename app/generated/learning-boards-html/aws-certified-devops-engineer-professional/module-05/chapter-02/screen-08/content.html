Python Lambda Example
import json
import base64
import gzip

def lambda_handler(event, context):
    # Decode and decompress the log data
    compressed_payload = base64.b64decode(event['awslogs']['data'])
    uncompressed_payload = gzip.decompress(compressed_payload)
    payload = json.loads(uncompressed_payload)

    print("Decoded Payload:", json.dumps(payload, indent=2))

    # Process each log event
    for log_event in payload['logEvents']:
        print(f"Log Event Message: {log_event['message']}")

    return {'statusCode': 200, 'body': json.dumps('Logs processed successfully!')}
Replace prints with enrichment, alerts, or forwarding logic. Watch for Lambda timeouts on high-volume streams.
Practical notes
  • Ensure the Lambda role grants logs:PutLogEvents so the function can write its own logs.
  • Handle partial failures and implement retries or dead-letter queues for lossless processing.
  • Filter at the log group when possible to limit Lambda invocation volume.

Why must you decode and decompress the subscription payload? Because CloudWatch Logs forwards it base64 encoded and gzipped to save bandwidth and standardize delivery format.
