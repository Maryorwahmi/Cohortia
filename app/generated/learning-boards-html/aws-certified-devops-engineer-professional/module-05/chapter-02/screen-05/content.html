Example agent config
Save as /etc/amazon/amazon-cloudwatch-agent/config.json and then start the agent.
{
  "agent": {
    "metrics_collection_interval": 60,
    "run_as_user": "root"
  },
  "logs": {
    "logs_collected": {
      "files": {
        "collect_list": [
          {
            "file_path": "/var/log/messages",
            "log_group_name": "/ec2/messages",
            "log_stream_name": "{instance_id}",
            "timezone": "UTC"
          },
          {
            "file_path": "/opt/myapp/logs/access.log",
            "log_group_name": "/myapp/access-logs",
            "log_stream_name": "{instance_id}",
            "timezone": "UTC",
            "timestamp_format": "%Y-%m-%dT%H:%M:%S%z"
          }
        ]
      }
    },
    "log_stream_name": "{instance_id}"
  }
}
After saving the config, run the agent control command to apply it and check CloudWatch for events.
Commands and verification
sudo yum install -y amazon-cloudwatch-agent # create a sample log and restart agent sudo mkdir -p /opt/myapp/logs sudo echo "INFO: Application started" | sudo tee -a /opt/myapp/logs/app.log sudo /opt/aws/amazon-cloudwatch-agent/bin/amazon-cloudwatch-agent-ctl -a append-config -m ec2 -c file:/tmp/config.json -s
Common mistakes
Wrong file path, missing timestamp format for custom timestamps, and not restarting the agent after editing the config.
