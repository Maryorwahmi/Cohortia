Module 5 › Chapter 5.2 › Use Cases
Real-time (Subscription + Lambda)
  • Low latency processing and alerting
  • Enrichment from databases before notification
  • Watch for invocation cost and throttling
Example
Filter for "Access Denied" to trigger immediate security alerts via Lambda and SNS.
Archival (Firehose → S3/Redshift)
  • Buffering and compression for cost efficiency
  • Time-partitioned storage for analytics
  • IAM and buffer tuning are operationally important
Example
Stream all access logs to Firehose and query them in Athena for usage patterns.
