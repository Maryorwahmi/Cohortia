Module 5 › Chapter 5.2 › Pipeline Design
Tiered architecture
Map sources to groups, then split events by urgency: real-time vs archival.
Collection
CloudWatch Agent, service integrations write to log groups.
Real-time
Subscription filters to Lambda for alerts and enrichment.
Archival
Firehose delivers partitioned files to S3 for Athena queries and long-term retention.
Example flow
Application logs → CloudWatch Log Group /myapp/prod → Subscription filter for ERROR → Lambda alerting; Firehose receives full stream and writes to s3://my-log-bucket/year/month/day/
Operational checklist
Define naming, set group retention, create subscription filters with appropriate patterns, attach IAM roles, and confirm delivery in the target.
