Delivery options & tuning
Firehose buffers data, optionally runs transformations, compresses, and writes to destination. Choose buffer size and interval to match throughput and latency needs.
S3 delivery
Writes compressed objects into time-partitioned folders for Athena queries.
Redshift
Uses S3 as staging, then COPY into Redshift for analytics.
OpenSearch
Streams transformed JSON documents for near real-time search and dashboards.
Practical checklist
  • Set buffer size and buffer interval for delivery frequency.
  • Attach an IAM role that can write to the destination.
  • Enable compression and optional Lambda transforms for enrichment.
Example settings
Buffer size: 5 MB, Buffer interval: 300 seconds for moderate throughput; adjust to match your application's log volume.
