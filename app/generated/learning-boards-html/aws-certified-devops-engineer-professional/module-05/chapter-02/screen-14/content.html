Module 5 › Chapter 5.2 › Operational Tuning
Buffer & compression choices
Example defaults: Buffer size 5 MB and Buffer interval 300 seconds. For low-latency needs reduce interval; for cost savings increase buffer size.
Compression
Use gzip for Athena-compatible compressed files. Beware of many small compressed files—combine when possible.
Partitioning
Time-partitioned S3 paths (year/month/day/hour) make queries efficient while keeping objects manageable.
Cost control strategies
  • Tier logs: high-value logs get low-latency paths, verbose logs go to cheaper archival.
  • Use lifecycle rules in S3 to move old objects to cheaper storage classes.
  • Monitor Firehose and CloudWatch costs and adjust buffers accordingly.
Check your understanding
Why avoid many tiny compressed files? They increase request overhead and reduce query efficiency in Athena.
