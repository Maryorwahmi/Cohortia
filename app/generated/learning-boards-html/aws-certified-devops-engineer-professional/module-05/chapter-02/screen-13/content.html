Module 5 › Chapter 5.2 › Troubleshooting
Collection issues
Check agent process, config file paths, and restart the agent after edits. Confirm log events appear in the expected stream by appending a trace message.
Subscription and delivery issues
If subscription forwarding fails, inspect CloudWatch Logs metrics and destination service logs for errors. For Firehose, check delivery stream monitoring for failed S3 writes.
Permission problems
IAM role misconfiguration is a frequent cause of delivery failure. Ensure the role used by the subscription or Firehose has the required write permissions to the destination.
Quick tip
Inject a unique test log line and trace it through CloudWatch, Lambda logs, and the destination to locate the failure point quickly.
