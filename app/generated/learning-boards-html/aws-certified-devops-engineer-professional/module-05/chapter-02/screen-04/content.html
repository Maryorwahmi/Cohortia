Module 5 › Chapter 5.2 › Log Groups & Retention
Definition & Best Practices
A log group groups related streams. Streams are sequences from a single source. Apply retention at the group level to manage cost and compliance.
Naming convention
Use /service/environment/component, for example /myapp/prod/nginx-access
Retention policy
Set shorter retention for debug logs, longer for audit logs; verify with lifecycle tests.
Common mistake
Forgetting to assign the agent to the correct log group or setting retention too short for critical logs.
Key Takeaway

Design groups by function, map streams to distinct sources, and set retention according to legal and operational needs.

Concrete example
/myapp/prod/access-logs — retention 365 days /myapp/prod/debug-logs — retention 7 days /security/audit — retention Never Expire
Why it matters: time partitioning and naming let you find relevant streams quickly and apply the correct lifecycle to each set of logs.
Check your understanding
If you need to retain security logs for audits, which retention option prevents deletion? (Answer: Never Expire.)
