Verification Milestones
Each objective includes a concrete test you can run to prove the step works in your environment. Verification reduces guesswork during incidents.
Agent & Ingestion
Confirm the agent is running and events appear in the expected log group and stream. Create a temporary test log line to validate.
Logs Insights
Run a query that returns known error messages and extracted fields to validate parsing and filters.
Subscription & Lambda
Send a test event that matches the filter pattern and confirm the Lambda received and decoded the payload.
Firehose Delivery
Check the S3 bucket path for compressed, time-partitioned files and verify IAM role write permissions.
Quick Mnemonic
Remember: Test each handoff. Agent → CloudWatch → Subscription → Lambda/Firehose → Destination.
