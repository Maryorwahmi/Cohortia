Module 6 › Chapter 5.7 › Activity: create a detector
Step-by-step
  1. Upload historical CSV to s3://your-bucket/historical/ and live CSV to s3://your-bucket/live/.
  2. Create IAM role LookoutMetricsS3AccessRole with S3 read privileges.
  3. Create detector MyWebAppDetector with 5 minute interval.
  4. Add MetricSet: timestamp, error_rate (AVG), latency_ms (AVG), dimensions service_name, region.
  5. Run backtest and validate baseline; upload an anomalous live row to test detection.
Checks & tips
Confirm timestamp format and header names match dataset settings.
Use representative historical files that include normal peaks.
Attach RCA context to SNS alerts for faster triage.
Reflection: what automated checks would prevent noisy alerts in your environment?
