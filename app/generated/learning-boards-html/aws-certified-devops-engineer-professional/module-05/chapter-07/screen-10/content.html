Root Cause Analysis

RCA shows which dimension values and metrics explain the anomaly. These contributors let you narrow the blast radius quickly.

Example RCA
Primary contributors: service_name: CheckoutService (60%), region: eu-west-1 (30%). Focus your investigation there.
Misconception: RCA is exact cause. It highlights likely contributors; combine it with logs and traces to confirm root cause.
