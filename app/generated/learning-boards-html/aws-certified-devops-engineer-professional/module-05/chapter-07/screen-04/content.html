Module 6 › Chapter 5.7 › Why static thresholds fail
Static Thresholds

Simple but brittle

  • Hard to tune for seasonality or trend.
  • Produces many false positives during known peaks.
  • Requires manual maintenance as patterns change.
Common Mistake

Setting thresholds without examining long-term trends or multiple dimensions leads to noisy alerts.

ML-based Detection

Adaptive and contextual

  • Learns normal behavior from historical data and adjusts to seasonality.
  • Supports dimensions so alerts can be scoped to service and region.
  • Reduces false positives and surfaces gradual degradations.

Key Takeaway

Prefer learned baselines where metrics are dynamic or seasonally variable; keep thresholds for simple, stable signals.
