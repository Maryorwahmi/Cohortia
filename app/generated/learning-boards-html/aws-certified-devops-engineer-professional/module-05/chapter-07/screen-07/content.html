Detector

The monitor that runs continuously

A detector contains MetricSets and configuration for monitoring frequency, encryption, and deployment. It orchestrates model building and scoring.

MetricSet elements
  • MetricList: metric names and aggregation (AVG, SUM, etc.).
  • DimensionList: categorical columns for segmentation.
  • TimestampColumn: name and format for time parsing.
  • Interval & Offset: ingestion cadence and alignment.
Dataset example
Required fields: timestamp, metric columns like error_rate, and dimensions like service_name. Use consistent naming and types.
Good
Include service_name and region so RCA can pinpoint contributors.
Bad
Omitting critical dimensions or using inconsistent timestamps breaks model accuracy.
Pro Tip: verify IAM role permissions and CSV header spelling before starting the backtest.
