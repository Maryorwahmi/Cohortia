Module 6 › Chapter 5.7 › What is anomaly detection?
Core Definition

Detect unusual behaviour in time-series

Anomaly detection identifies points or patterns that differ meaningfully from the expected baseline, considering trends and seasonality.

Concrete Example
Checkout service error rate normally 0.01; a sudden rise to 0.10 in one region is anomalous and should be investigated for recent deployments or infra changes.
Misconception

Not every anomaly is a problem; some reflect expected seasonal patterns or transient noise. Use RCA and context to judge.

How ML helps
  • Automatically models baseline behavior from historical data.
  • Handles seasonality, trends, and multi-dimensional segmentation.
  • Provides anomaly scores and contributing factors for targeted investigation.
