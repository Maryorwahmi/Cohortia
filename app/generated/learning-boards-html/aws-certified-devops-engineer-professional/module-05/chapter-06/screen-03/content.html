Module 5 › Chapter 5.6 › Objectives — Tasks
01 — Explain AMP

Task: Describe how AMP stores Prometheus time-series data, provides multi-tenant scaling, and offloads long-term retention from your cluster.

Milestone: Able to list three operational benefits of AMP compared to self-hosted Prometheus.
02 — Configure exporters

Task: Install Node Exporter and verify the metrics endpoint is reachable.

Milestone: Demonstrate curl to the /metrics endpoint and interpret a few sample metrics.
03 — Remote write

Task: Configure Prometheus with remote_write to send samples to the AMP workspace endpoint.

Milestone: Confirm Prometheus is not storing locally and metrics appear in AMP-backed queries.
04 — Grafana panels

Task: Connect AMG to AMP, create a dashboard panel, and validate a PromQL query in Explore first.

Milestone: Build a dashboard showing CPU utilization across nodes using PromQL and grouping by instance or pod.
