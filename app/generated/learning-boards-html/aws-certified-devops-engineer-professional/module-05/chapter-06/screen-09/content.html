Module 5 › Chapter 5.6 › AMG ↔ AMP
Steps to connect
  1. Create an AMG workspace and choose an authentication method such as AWS IAM Identity Center.
  2. Add Amazon Managed Service for Prometheus as a data source and select your AMP workspace.
  3. Verify IAM permissions so AMG can read from AMP.
  4. Use Explore to validate queries before adding panels to dashboards.
IAM pitfall
If the AMG workspace lacks permission to query AMP, your panels will show errors or empty data. Ensure the AMG role or user has the needed AMP HTTP query permissions and any cross-account role is correctly assumed.
Validation
In Grafana Explore, run a basic PromQL like node_cpu_seconds_total to confirm connectivity before authoring dashboards.
Key Takeaway

Link AMG to AMP and validate with the Explore tab; double-check IAM roles and the selected AMP workspace endpoint to avoid data access failures.
