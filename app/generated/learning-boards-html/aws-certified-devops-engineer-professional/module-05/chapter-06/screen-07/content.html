Module 5 › Chapter 5.6 › Scrape → Remote Write
Pipeline steps
  1. Exporter exposes metrics at /metrics.
  2. Prometheus scrapes endpoints at scrape_interval.
  3. Prometheus forwards samples via remote_write to AMP.
  4. AMP ingests and stores samples; AMG queries them with PromQL.
Validation checklist
  • curl exporter /metrics to confirm exposure.
  • Check Prometheus target page to ensure successful scrapes.
  • Watch Grafana Explore to validate samples appear from AMP.
Operational note
When high-cardinality metrics or high scrape frequency produce heavy sample volumes, adjust Prometheus queue_config and shard settings in remote_write to avoid dropped samples.
Common mistake

Assuming exporters push metrics; they must be scraped. Configure Prometheus to scrape then remote_write to AMP.

Key Takeaway
Verify each hop in the pipeline: exporter, scraper, remote write, and visualization to find where samples are lost.
