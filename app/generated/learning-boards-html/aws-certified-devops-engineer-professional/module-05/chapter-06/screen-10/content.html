Module 5 › Chapter 5.6 › PromQL Basics
Compose PromQL by selecting metrics, narrowing with labels, applying functions, and aggregating results. Test queries in Explore before adding to dashboards.
# Example selections and transformations
rate(node_cpu_seconds_total{mode="idle"}[5m])

sum(container_memory_usage_bytes{namespace="production"}) by (pod)
Common misconception
Applying rate to a gauge yields incorrect results. Use rate for counters and instantaneous functions for gauges.
Practice tip
Use the Explore tab in AMG to iterate on queries and add range vectors like [5m] to smooth noisy counters before dashboarding.
