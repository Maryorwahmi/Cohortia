Module 5 › Chapter 5.6 › Prometheus Exporters
Exporters present metrics in Prometheus format on an HTTP endpoint. Prometheus scrapes these endpoints and gathers samples for each scrape interval. Exporters are not push clients; they are passive endpoints that expose current metrics.
Node Exporter
Exposes host-level metrics such as CPU, memory, and disk I/O, typically on port 9100.
kube-state-metrics
Exposes Kubernetes object metrics like pods, deployments, and replica counts.
App-specific exporters
Databases, caches, and web servers often provide exporters to expose internal metrics.
Example
Run Node Exporter on an EC2 instance and visit the /metrics path or curl it to verify it exposes numeric counters and gauges. Then configure Prometheus to scrape that endpoint regularly.
Common mistake
Expecting exporters to push to AMP directly. They should be scraped by Prometheus, which then remote_writes to AMP.
Pro tip
Use curl or a browser to check the exporter endpoint and sample metric names before configuring Prometheus scraping.
