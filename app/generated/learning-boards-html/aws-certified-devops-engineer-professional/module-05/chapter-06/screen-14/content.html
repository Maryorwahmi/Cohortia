Module 5 › Chapter 5.6 › Key Concepts
Amazon Managed Service for Prometheus
A managed, Prometheus-compatible storage and ingestion service for time-series metrics.
Prometheus Exporters
Agents that expose host or application metrics via HTTP for Prometheus to scrape.
Remote Write
Prometheus feature that forwards scraped samples to a remote storage backend such as AMP.
Summary

Keep these concepts handy when designing your observability pipeline and when troubleshooting pipeline failures.
