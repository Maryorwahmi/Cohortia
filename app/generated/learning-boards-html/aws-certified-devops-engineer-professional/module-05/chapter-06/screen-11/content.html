Module 5 › Chapter 5.6 › CPU Utilization (PromQL)
Use PromQL to convert counter rates into a percent utilization metric that is easy to visualize and alert on.
# Example PromQL to compute average CPU utilization per instance
100 - (avg by (instance) (rate(node_cpu_seconds_total{mode="idle"}[5m])) * 100)
Misconception
Don't treat rate output as a percentage without converting; rate returns per-second increments and must be multiplied appropriately.
Check
Compare the PromQL result with system tools to ensure labels and aggregations match the observed host-level CPU.
