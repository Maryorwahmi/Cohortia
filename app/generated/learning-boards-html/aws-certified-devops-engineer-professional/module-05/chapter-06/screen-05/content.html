Module 5 › Chapter 5.6 › What is AMP?
AMP is a fully managed, Prometheus-compatible monitoring service. It accepts Prometheus remote write data, preserves the Prometheus data model, and provides long-term storage and availability without operator maintenance.
Scales
Handles large ingestion volumes and sharding concerns for you.
Prometheus-compatible
Keep labels, metrics, and PromQL semantics unchanged.
Retention
Stores time-series data for extended periods without local storage maintenance.
Concrete config example
# Example: Creating an AMP workspace via AWS CLI
aws amp create-workspace --alias my-devops-workspace
Use the workspace endpoint for Prometheus remote_write configuration on your Prometheus server.
Common misconception
AMP does not alter Prometheus metric semantics. Labels and metric names remain the same, so alerts and dashboards built for Prometheus continue to function.
