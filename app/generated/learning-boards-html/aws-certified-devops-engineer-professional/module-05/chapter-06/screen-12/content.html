Module 5 › Chapter 5.6 › Percentiles with histograms
Percentiles require the histogram bucket semantics. Use rate over buckets, aggregate by bucket boundary, then apply histogram_quantile to compute the desired percentile.
# Example PromQL for p99
histogram_quantile(0.99, sum by (le) (rate(http_request_duration_seconds_bucket[5m])))
Pitfalls
Missing sum by (le) or using an insufficient range window will yield inaccurate percentiles for low-traffic services.
Practical check
Visualize p50, p90, and p99 to understand tail latency and validate against synthetic load tests when possible.
