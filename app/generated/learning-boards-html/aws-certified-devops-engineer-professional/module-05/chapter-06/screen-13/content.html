Module 5 › Chapter 5.6 › Terminal Demo
Follow these terminal steps in sequence. Replace placeholders with your AMP workspace values and ensure the EC2 instance role includes AmazonPrometheusRemoteWriteAccess.
Create AMP workspace (CLI)
# Create an AMP workspace via AWS CLI
aws amp create-workspace --alias my-devops-workspace
Install Node Exporter (EC2)
wget https://github.com/prometheus/node_exporter/releases/download/v1.7.0/node_exporter-1.7.0.linux-amd64.tar.gz
tar xvfz node_exporter-1.7.0.linux-amd64.tar.gz
cd node_exporter-1.7.0.linux-amd64
./node_exporter & # Run in background
Install Prometheus
wget https://github.com/prometheus/prometheus/releases/download/v2.49.1/prometheus-2.49.1.linux-amd64.tar.gz
tar xvfz prometheus-2.49.1.linux-amd64.tar.gz
cd prometheus-2.49.1.linux-amd64
prometheus.yml (snippet)
# Replace YOUR_AMP_WORKSPACE_ENDPOINT with your AMP remote write URL
global:
  scrape_interval: 15s
  evaluation_interval: 15s

scrape_configs:
  - job_name: 'node_exporter'
    static_configs:
      - targets: ['localhost:9100']

remote_write:
  - url: YOUR_AMP_WORKSPACE_ENDPOINT
    sigv4:
      region: <YOUR_REGION>
Validation steps
  • curl http://localhost:9100/metrics to confirm Node Exporter is up.
  • Open Prometheus targets to confirm successful scrapes.
  • In AMG Explore, run node_cpu_seconds_total to ensure AMP receives samples.
