Module 5 › Chapter 5.1 › Composite Alarm: CloudFormation
CloudFormation example
Resources:
  MyCompositeAlarm:
    Type: AWS::CloudWatch::CompositeAlarm
    Properties:
      AlarmName: MyApplicationCriticalHealthCompositeAlarm
      AlarmDescription: "Triggers if both CPU and Memory are critically high."
      AlarmActions:
        - !ImportValue MySnsTopicArnForCriticalAlerts
      AlarmRule: "ALARM(\"arn:aws:cloudwatch:us-east-1:123456789012:alarm:MyCpuAlarm\") AND ALARM(\"arn:aws:cloudwatch:us-east-1:123456789012:alarm:MyMemoryAlarm\")"
      ActionsEnabled: true
Notes
  • Verify child alarm ARNs and region/account context.
  • Use exported SNS ARNs or parameters to keep templates portable.
  • Test composite behavior by simulating child alarm states in staging.
Key Takeaway

Use AlarmRule to encode logical combinations of child alarm states and test thoroughly before production use.
