Module 5 › Chapter 5.1 › Composite Alarms
How they work
A composite alarm references child alarm ARNs and evaluates an AlarmRule expression built from AND, OR, NOT operators to determine its state.
Design tips
  • Combine noisy metrics with corroborating signals for higher confidence.
  • Create tiered composites: critical rules for operations and simple alerts for diagnostics.
  • Test composite behavior with simulated child alarm state changes.
Concrete scenario
Trigger only when CPU AND Memory alarms are in ALARM on the same instance to indicate a server under full load rather than isolated spikes.
Key Takeaway

Composite alarms help you act on correlated problems by requiring multiple alarm states before notifying responders.
