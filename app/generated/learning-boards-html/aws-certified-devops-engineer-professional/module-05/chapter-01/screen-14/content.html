Module 5 › Chapter 5.1 › Cross-Account Monitoring
Core idea
A monitoring account receives shared metrics, logs, and alarms from source accounts via an explicit link, enabling centralized dashboards and alerts.
Security
Grant the monitoring account only the permissions it needs and use resource policies to avoid over-privileging. Always follow the principle of least privilege.
Operational notes
  • Use a dedicated monitoring account for consolidated dashboards.
  • Share only the required namespaces or metrics to limit exposure.
  • Test links and permissions end-to-end in staging before production.
Key Takeaway

Cross-account monitoring centralizes observability but must be configured with explicit links and least-privilege permissions to remain secure.
