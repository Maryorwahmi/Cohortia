Module 5 › Chapter 5.1 › Metric Math: Error Rate
Steps to create ErrorRate
  1. Ensure OrderCount and FailedOrderCount are published with the same namespace and dimensions.
  2. Add both metrics to the metric graph in CloudWatch.
  3. Click Add math expression and enter (m2 / (m1 + m2)) * 100 and name it ErrorRate.
  4. Validate values by publishing test metrics and confirming graph output.
Validation checklist
  • Same Namespace and Dimensions for both metrics.
  • Compatible StorageResolution and Period alignment.
  • Non-zero denominators during tests to avoid division issues.
Expression example
(m2 / (m1 + m2)) * 100
If the expression returns no data, confirm that both metrics have points for the same period and dimensions. If you see noisy values, adjust periods or use smoothing functions like AVG over a window before alerting.
Key Takeaway

Always validate metric math expressions with test data and document the inputs so alerts are explainable to responders.
