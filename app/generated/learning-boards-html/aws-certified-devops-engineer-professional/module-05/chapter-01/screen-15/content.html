Module 5 › Chapter 5.1 › Cross-Account Implementation
Implementation checklist
  1. Choose a monitoring account and define what to share.
  2. Create an IAM role in source accounts with minimal CloudWatch read permissions.
  3. Establish a CloudWatch link granting the monitoring account access to specified data.
  4. Test visibility from the monitoring account and confirm alarms appear.
  5. Document and audit access; rotate credentials and monitor logs.
Permissions guidance
  • Grant only cloudwatch:GetMetricData, cloudwatch:ListMetrics, logs:DescribeLogGroups where needed.
  • Avoid granting broad IAM permissions or full admin rights to the monitoring account.
  • Prefer roles and short-lived sessions for access instead of long-lived keys.
Key Takeaway

Centralize observability with explicit links and least-privilege roles, and validate access with staged tests before production use.
