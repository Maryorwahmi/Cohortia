Module 5 › Chapter 5.1 › Metric Math Pitfalls
Common causes of empty or wrong results
  • Mismatched namespaces or missing dimensions between metrics.
  • Incompatible storage resolutions or period alignment.
  • Sparse metric emission that yields noisy math outputs.
  • Incorrect function choice or division by zero.
Best practices
  • Validate expressions with test data and confirm alignment.
  • Document inputs, units, and intended period for each expression.
  • Smooth sparse data using AVG or windowed functions before alerting.
  • Add denominator guards or conditional checks to avoid division-by-zero.
Pro Tip

Create and test metric math expressions in a staging namespace first, then promote them to production after verification.
