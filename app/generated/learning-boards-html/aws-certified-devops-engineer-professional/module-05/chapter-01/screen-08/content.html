Why use metric math?
It keeps calculations close to the data, reduces export complexity, and lets you alert on derived values like error rate or percentiles.
Common functions
  • SUM, AVG, MIN, MAX
  • RATE for derivatives
  • PERCENTILE or P90/P99 for latency distributions
Example expression
(m2 / (m1 + m2)) * 100 — where m1=SuccessfulRequests, m2=FailedRequests
Validate expressions in the console before using them in alarms. Give expressions readable labels so your dashboards and alarms are understandable to the team.
Key Takeaway

Metric math lets you derive meaningful operational signals without external tooling; confirm compatible metric resolutions and dimensions first.
