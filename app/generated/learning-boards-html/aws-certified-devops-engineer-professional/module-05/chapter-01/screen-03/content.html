Bloom's taxonomy
Learn
Identify signals and define namespaces and metric names for your application.
Understand
Interpret dimensions, units, and storage resolution for accurate analysis.
Apply
Publish metrics, create metric math expressions, and configure alarms based on derived signals.
Master
Design composite alarms and cross-account links with least-privilege security controls.
Use the lab activity to verify each stage: publish metrics, validate metric math, create a composite alarm, and set up a link to a monitoring account.
