Core Concept
Segments, Subsegments, Traces
Understand the building blocks of every trace and how they surface timing and metadata.
Segment
One compute resource's work record; includes duration, metadata, and exceptions.
Subsegment
Fine-grained operation timing inside a segment, created for SDK-wrapped calls or manual subsegments.
Trace
A collection of segments and subsegments sharing a trace ID representing the entire request path.
Key Takeaway

Use the trace ID to correlate segments across resources, and inspect subsegments to locate the exact operation causing latency or errors.

Service Map (visual)
Nodes represent services; edges represent connections and show aggregated health.
Color cues
Green = healthy, yellow = warnings, red = errors; use colors as a triage guide, not a definitive cause.
Drill down
Click a node or edge to open trace details and a timeline that shows durations for segments and subsegments.
Analogy
Think of a trace as a flight itinerary: segments are flights, subsegments are taxi, security, and baggage steps helping you pinpoint delays.
