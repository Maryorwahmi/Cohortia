Hands-on Activity
Instrument and analyze
Follow these steps to verify traces appear end to end.
1. Create Lambda and role
Ensure the execution role includes X-Ray write permissions like AWSXRayDaemonWriteAccess.
2. Deploy code with aws-xray-sdk
Package dependencies or use a layer for aws-xray-sdk and any HTTP client library.
3. Enable Active tracing
aws lambda update-function-configuration --function-name XRayDemoFunction --tracing-config Mode=Active
4. Invoke and inspect
Invoke several times, open X-Ray Traces, and inspect timeline and metadata for subsegments.
Example Lambda snippet
from aws_xray_sdk.core import xray_recorder
@xray_recorder.capture('my_lambda_handler')
def lambda_handler(event, context):
    with xray_recorder.in_subsegment('internal_processing'):
        import time
        time.sleep(0.03)
    return {'statusCode':200,'body':'X-Ray demo complete!'}
Key Takeaway

Validate traces after each change: code, packaging, permissions, and configuration are common failure points.
