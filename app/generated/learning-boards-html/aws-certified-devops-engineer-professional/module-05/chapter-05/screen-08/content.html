Definition
Service map and trace details
Use the map to find hotspots and the trace timeline to confirm the root cause.
Service map cues
  • Green nodes: healthy.
  • Yellow edges: potential latency or warnings.
  • Red edges: frequent errors needing immediate attention.
Misconception

Don't treat colors as proof. Drill into trace timelines and metadata for the true cause.

Trace timeline analysis
Look for the longest segment/subsegment, inspect metadata and exception details, and correlate HTTP codes or DB duration to determine root cause.
Scenario
API shows high latency. Trace reveals Lambda segment with DynamoDB subsegment taking most time and returning throttling errors in metadata. Conclusion: optimize the DynamoDB query or add retries with backoff.
