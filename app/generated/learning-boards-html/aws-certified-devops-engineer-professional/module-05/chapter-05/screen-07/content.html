Architecture
X-Ray SDK + Daemon
SDK instruments and emits segments; the daemon buffers and uploads them to the X-Ray service.
Flow
Application → X-Ray SDK → UDP → X-Ray daemon → X-Ray service.
IAM requirement
Daemon's role needs xray:PutTraceSegments and xray:PutTelemetryRecords or the managed AWSXRayDaemonWriteAccess policy.
Operational tip

Ensure AWS_XRAY_DAEMON_ADDRESS points to the running daemon and that network/firewall rules allow UDP to the daemon port.

Example CloudFormation snippet (daemon role)
Resources:
  XRayDaemonRole:
    Type: AWS::IAM::Role
    Properties:
      AssumeRolePolicyDocument: ...
      ManagedPolicyArns:
        - arn:aws:iam::aws:policy/AWSXRayDaemonWriteAccess

  XRayInstanceProfile:
    Type: AWS::IAM::InstanceProfile
    Properties:
      Roles:
        - !Ref XRayDaemonRole

  MyEC2Instance:
    Type: AWS::EC2::Instance
    Properties:
      IamInstanceProfile: !Ref XRayInstanceProfile
      UserData: |
        # install and start the X-Ray daemon
Checklist
  • Install and start the daemon on the host.
  • Set SDK environment variables to reach the daemon.
  • Confirm IAM role includes X-Ray write permissions.
