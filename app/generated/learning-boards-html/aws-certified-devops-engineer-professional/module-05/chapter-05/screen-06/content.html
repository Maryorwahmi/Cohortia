Python Lambda example
This handler shows capture and subsegments with metadata and error handling.
from aws_xray_sdk.core import xray_recorder
from aws_xray_sdk.core.lambda_launcher import LambdaContext

@xray_recorder.capture('my_lambda_handler')
def lambda_handler(event, context):
    print("Processing event:", event)

    # Simulate a delay
    import time
    time.sleep(0.05)

    # Create a subsegment for an external HTTP call
    with xray_recorder.in_subsegment('external_api_call') as subsegment:
        try:
            # Example HTTP client call
            import requests
            response = requests.get('https://docs.aws.amazon.com/index.html', timeout=2)
            subsegment.put_metadata('http_status', response.status_code)
            subsegment.put_metadata('response_length', len(response.text))
        except Exception as e:
            subsegment.add_exception(e)
            subsegment.add_error()

    # Internal processing
    with xray_recorder.in_subsegment('internal_processing'):
        time.sleep(0.03)

    return {
        'statusCode': 200,
        'body': 'X-Ray demo complete!'
    }
Packaging note
Include aws-xray-sdk and any HTTP clients in your deployment or use a Lambda Layer.
Runtime check
Invoke multiple times and inspect trace timeline for the handler segment and its subsegments.
Common mistakes
Missing dependencies, forgetting to add metadata or mark exceptions, and lacking IAM permissions are frequent causes of incomplete traces.
Key Takeaway

Capture the handler, create subsegments for important calls, and add metadata/errors so traces are actionable.
