Sampling rules
Define reservoirs and fixed rates to balance visibility and cost.
Key terms
  • Reservoir: fixed number of traces per second guaranteed.
  • FixedRate: percentage of additional requests to trace.
Rule example (conceptual)
{
  "RuleName": "LoginHighSampling",
  "Reservoir": 1,
  "FixedRate": 1.0,
  "MatchConditions": { "URLPath": "/login" }
}
This conceptual block shows reserving traces and setting full sampling for a critical path.
Key Takeaway

Start with conservative sampling and increase coverage only for specific endpoints or error conditions that require full visibility.
