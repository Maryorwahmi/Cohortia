What to Remember
Three compact reminders for reliable production tracing.
Enable managed tracing
Quick visibility with no code change for supported services.
Run SDK and daemon
SDK emits segments, daemon uploads; both must be present and reachable.
Tune sampling
Capture errors and critical endpoints; start conservative and adjust based on data and cost.
Final takeaway

X-Ray helps you connect symptoms to root causes when instrumentation, collection, and sampling are configured and validated.
