Process Flow
Enable tracing on managed services
Turn on Active tracing for Lambda, API Gateway, and AppSync to generate segments automatically.
CLI example
aws lambda update-function-configuration \
    --function-name MyLambdaFunction \
    --tracing-config Mode=Active
When to add SDK
Add the X-Ray SDK where you need timing or metadata for downstream calls inside the function or service.
Common mistake

Assuming managed tracing replaces SDK instrumentation. It provides segments but not necessarily detailed subsegments for internal calls.

Practical check
After enabling tracing, invoke the service and confirm a trace appears in the X-Ray console for that resource.
Example: API Gateway + Lambda
Enable tracing on API Gateway and Lambda to see the edge between them and drill into the Lambda trace to inspect subsegments.
Why it matters
Immediate visibility reduces time-to-first-evidence when investigating production latency or errors.
