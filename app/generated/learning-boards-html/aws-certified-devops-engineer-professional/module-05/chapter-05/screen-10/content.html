Why traces are incomplete
A short checklist compares likely root causes and fixes.
Cause: Missing SDK config
Fix: Wrap downstream calls or enable automatic instrumentation for AWS SDKs so subsegments are created.
Cause: Daemon not running
Fix: Start the X-Ray daemon on host or set AWS_XRAY_DAEMON_ADDRESS to a reachable host and port.
Cause: IAM permissions
Fix: Ensure the daemon or task role has X-Ray write permissions such as the AWSXRayDaemonWriteAccess policy.
Cause: Sampling rules
Fix: Adjust sampling rules to increase coverage for the affected endpoints or error classes.
Pro tip

Replicate an issue with verbose SDK and daemon logs to quickly identify whether data is emitted, collected, or uploaded.
