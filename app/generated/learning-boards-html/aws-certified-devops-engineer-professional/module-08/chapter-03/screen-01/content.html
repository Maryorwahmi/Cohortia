Protect your delivery pipeline

Learn how secrets, ephemeral builds, image scanning, and automated testing combine to enforce security gates in CI/CD.

Secret Management
Store and rotate credentials with Secrets Manager or Parameter Store.
Build Hardening
Use ephemeral CodeBuild workers and least-privilege roles to limit exposure.
Image Scanning
Scan images in ECR and block risky artifacts from promotion.
Automated Testing
Shift-left SAST, SCA, and DAST into your pipeline stages.
Why this chapter matters

CI/CD automation touches credentials, deploys artifacts, and runs tests. If compromised, pipelines enable supply chain attacks and unauthorized deployments. Treating the pipeline as code that must be secured prevents those risks.
