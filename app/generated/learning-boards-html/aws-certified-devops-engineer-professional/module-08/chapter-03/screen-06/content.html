Module 08 › Chapter 8.3 › Secrets Manager vs Parameter Store
AWS Secrets Manager
Automatic rotation, credential lifecycle, fine-grained policies, and auditing. Ideal for database credentials and API keys that require rotation.
When to choose
Rotating DB passwords, central credential management with rotation workflows.
Operational notes
Support for Lambda rotation functions and integrated auditing of secret usage.
SSM Parameter Store
SecureString parameters for configuration values and non-rotating secrets. Simpler billing and good for environment variables and feature toggles.
When to choose
Static config, many small parameters, or where rotation is not required.
Operational notes
Use with KMS keys for SecureString and scope GetParameter permissions for builds.
Common mistake

Treating Parameter Store as a drop-in replacement for Secrets Manager when rotation is required. Choose based on rotation and lifecycle needs.
