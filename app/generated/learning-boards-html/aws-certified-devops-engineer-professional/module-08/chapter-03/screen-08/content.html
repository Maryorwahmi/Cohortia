Module 08 › Chapter 8.3 › Secure build environments
Process Flow

Harden the build lifecycle

1. Ephemeral workers
Ensure builds run on disposable artifacts that are destroyed after use to avoid persistence.
2. Hardened images
Create custom build images with only required tools and keep them updated and scanned.
3. Minimal IAM roles
Grant only the actions and resource ARNs that the build requires.
Example policy focus
Allow ecr:PutImage for arn:aws:ecr:REGION:ACCOUNT:repository/my-app-repo and secretsmanager:GetSecretValue for arn:aws:secretsmanager:REGION:ACCOUNT:secret:my-app/db-api-key. Avoid wildcard actions that allow access to all secrets or all repositories.
Common-mistake
Granting AdministratorAccess or overly broad actions to simplify setup. This creates large attack surfaces when builds are compromised.
Key Takeaway

Scope build permissions and shrink the runtime environment to reduce possible exploitation paths.
