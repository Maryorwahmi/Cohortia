Module 08 › Chapter 8.3 › Secret Management
Definition

Secrets Manager vs Parameter Store

Both store secrets securely, but Secrets Manager adds rotation and credential lifecycle features while Parameter Store is lightweight and ideal for configuration.

AWS Secrets Manager
Automatic rotation, auditing, and integrations for credentials.
SSM Parameter Store
SecureString parameters for config and simple secrets without rotation workflows.
Concrete example
Store a DB password in Secrets Manager and grant CodeBuild permission to get-secret-value. The build can then read the value as an environment variable without ever committing it.
Misconception
Some teams assume Parameter Store is less secure. When SecureString and KMS are used, Parameter Store can be secure, but it lacks Secrets Manager's rotation features and credential lifecycle automation.
Pro tip

Favor Secrets Manager for rotating database credentials; use Parameter Store for static config and feature flags.

Why it matters
Rotation and centralized access reduce long-lived secrets and make audits and revocation practical when a credential is suspected compromised.
