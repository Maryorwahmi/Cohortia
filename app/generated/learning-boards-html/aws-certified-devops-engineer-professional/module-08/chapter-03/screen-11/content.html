Module 08 › Chapter 8.3 › Common mistakes

Frequent errors

  • Broad IAM permissions on CodeBuild/CodePipeline roles
  • Echoing secrets into build logs for debugging
  • Using unscanned public base images
  • Ignoring ECR/SAST/SCA scan results
  • Not rotating credentials

Mitigations

Policy hardening
Replace wildcard policies with least-privilege allow lists scoped to ARNs.
Log hygiene
Prevent secrets from being printed; redact or avoid including them in diagnostic outputs.
Automated gating
Fail pipeline promotions when critical scan results are present.
Pro tip

Treat scan alerts as part of your backlog triage and set a policy for acceptable risk levels so teams know when to pause promotions.
