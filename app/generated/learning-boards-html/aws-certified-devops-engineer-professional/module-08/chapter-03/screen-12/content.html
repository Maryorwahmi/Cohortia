Module 08 › Chapter 8.3 › Hands-on activity
Lab Steps
  1. Create Secrets Manager secret named my-app/db-api-key with a dummy value.
  2. Enable ECR image scanning or create a repository with scanning enabled.
  3. Create a CodeBuild project and role with scoped secretsmanager:GetSecretValue and ecr permissions for the repo only.
  4. Update buildspec to reference the secret ARN under env -> secrets-manager, then build, tag, and push the image.
  5. Verify build success and inspect ECR scan results. Configure the pipeline to fail on critical findings.
# Simplified buildspec snippet for lab
version: 0.2
env:
  secrets-manager:
    DB_API_KEY: "arn:aws:secretsmanager:REGION:ACCOUNT_ID:secret:my-app/db-api-key-xxxxxx"
phases:
  pre_build:
    commands:
      - echo "Logging in to Amazon ECR..."
  build:
    commands:
      - docker build -t my-app-image .
      - docker tag my-app-image:latest $AWS_ACCOUNT_ID.dkr.ecr.$AWS_DEFAULT_REGION.amazonaws.com/my-app-repo:latest
  post_build:
    commands:
      - docker push $AWS_ACCOUNT_ID.dkr.ecr.$AWS_DEFAULT_REGION.amazonaws.com/my-app-repo:latest
Safety notes
  • Do not echo secrets or write them to logs or artifacts.
  • Scope role permissions to the minimal ARNs required.
  • Review ECR scan outputs and treat critical findings as blockers.
Key Takeaway

This lab demonstrates end-to-end secure retrieval of a secret during build and verifying image security before deployment.
