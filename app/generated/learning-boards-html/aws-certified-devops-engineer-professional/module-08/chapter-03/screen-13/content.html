Timeline

From commit to production: security milestones

Commit
Pre-commit hooks, linters, and SAST PR checks.
Build
SAST, SCA, secret retrieval, and unit tests.
Artifact
Push to registry and run ECR image scanning.
Staging
Deploy and run DAST and integration tests.
Production
Final promotion, monitoring, and incident response.
Why staged checks work

Each stage catches different issues at the most cost-effective time: fix code early, patch images before deploy, simulate attacks in staging.

Misconception

Delaying all security to production monitoring assumes prevention failed; staged checks prevent many problems from ever reaching production.
