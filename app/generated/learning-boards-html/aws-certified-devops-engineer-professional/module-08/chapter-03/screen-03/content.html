How objectives reduce risk

Each objective addresses a class of pipeline risk. Below are short rationale cards and a small mnemonic to help you remember the defensive layer each objective provides.

Secrets: confidentiality
Centralizing secrets prevents leaks to source control and enables rotation policies.
Image scanning: integrity
Catches known CVEs before images are deployed.
SAST & SCA: shift left
Detect code and dependency vulnerabilities early in the build.
DAST: runtime checks
Find issues only visible when the app runs in a realistic environment.
Mnemonic
Think C-I-L: Confidentiality for secrets, Integrity for artifacts, Limited blast radius for roles.
Quick checklist
  • Enable Secrets Manager or SecureString parameters
  • Grant CodeBuild only retrieval permissions needed
  • Use ECR scanning and block critical CVEs
  • Run SAST in build and DAST in preprod
