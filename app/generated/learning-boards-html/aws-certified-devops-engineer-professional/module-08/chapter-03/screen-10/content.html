Module 08 › Chapter 8.3 › SAST, DAST & SCA
Comparison

What each test finds

SAST
Static checks on source and binaries for insecure code patterns.
SCA
Dependency scanning for known vulnerabilities in libraries.
DAST
Runtime testing against a running app to find behavior-based issues.
Pipeline placement
  • Run SAST and SCA early in build to fail fast.
  • Run DAST in staging after deployment before production promotion.
Example tools
SAST: Bandit or CodeGuru Security. SCA: Snyk or Dependency-Check. DAST: OWASP ZAP or commercial scanners. Integrate them as steps that output machine-readable reports for gating logic.
Misconception
Assuming one category of tool replaces others. Each addresses different vulnerability classes and should be used together.
Key Takeaway

Combine SAST, SCA, and DAST at the right pipeline stages to detect different classes of vulnerabilities effectively.
