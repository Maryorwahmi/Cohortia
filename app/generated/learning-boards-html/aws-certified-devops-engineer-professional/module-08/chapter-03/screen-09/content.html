Architecture

Image build and scan pipeline

1. Build
CodeBuild creates the Docker image and tags it.
2. Push
Image is pushed to an ECR repository with scanning enabled.
3. Scan & Gate
ECR runs a scan and the pipeline checks results before promotion.
Example
If the scan reports a critical vulnerability in an OS package, configure the pipeline to fail the promotion stage and notify the team to rebuild with a patched base image.
Operational notes
  • Enable ECR image scanning on push.
  • Automate gating: fail promotions on critical/high CVEs.
  • Use Inspector-enhanced scanning for deeper coverage if available.
Misconception
Relying solely on runtime WAF or host protections; scanning during build prevents deploying vulnerable artifacts in the first place.
