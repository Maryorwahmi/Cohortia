Module 8 › Chapter 8.1 › Shifting Security Left
Process Flow

Add the right checks at each SDLC stage

Design
Threat modeling and security requirements to reduce risky architecture choices.
Development
Static analysis, dependency scanning during CI for early feedback.
Build / Provision
Container image scanning, IaC linting, and template validation before deploy.
Operate
Continuous monitoring, incident automation, and drift detection in production.
Key Takeaway

Place fast, automated checks earlier. Keep runtime monitoring. Iterate to reduce false positives and expand coverage.

Example
Concrete pipeline change
Add dependency scanning in CodeBuild or your CI so high severity vulnerabilities block merges. Fixes occur before deployment, reducing rework.
Misconception
Shifting left does not remove the need for production monitoring; it complements it by reducing noise and frequency of incidents.
Try this
Choose one fast check and add it to your next CI run. Measure how many issues are caught earlier and adjust rules to reduce false positives.
