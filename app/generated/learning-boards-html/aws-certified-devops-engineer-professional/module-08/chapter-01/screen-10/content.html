Module 8 › Chapter 8.1 › Container Image and Dependency Scanning
Process

Scan artifacts during build and packaging

When to scan
After build and image creation, and during development for dependency checks.
Block promotion
Make artifact promotion conditional on passing scans for critical issues to prevent deployment of vulnerable artifacts.
Triage and automation
Record findings centrally, prioritize fixes, and automate rebuilds when fixes are available.
Example
Concrete example
A scan finds a vulnerable library in a built image. The pipeline fails and a ticket is created with remediation steps. The developer updates the dependency and re-runs the build.
Key Takeaway

Treat scanning as part of artifact quality gates so unsafe images or packages never reach production environments.
