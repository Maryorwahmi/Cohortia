# Shared Responsibility Model Analysis

## Scenario: Web Application Deployment on AWS (EC2, RDS, S3)

### AWS Responsibilities (Security OF the Cloud):
1. Physical security of AWS data centers.
2. Hardware maintenance for EC2 hosts.
3. Network infrastructure and managed control planes.

### Your Team's Responsibilities (Security IN the Cloud):
1. Configuring network access to EC2 instances.
   - AWS Service/Practice: Security Groups
2. Encrypting data stored in the S3 bucket.
   - AWS Service/Practice: S3 server-side encryption
3. Managing user access to services and resources.
   - AWS Service/Practice: IAM roles and policies
Guidance
After completing the template, share it with security and operations to validate ownership and identify automation opportunities such as IaC guards or pipeline checks.
Example output
Deliverable
A short document listing responsibilities and recommended AWS services for each team-owned item, suitable for design reviews or audits.
Key Takeaway

Convert the Shared Responsibility Model into concrete checklists and automation tasks so nothing important is left ambiguous.
