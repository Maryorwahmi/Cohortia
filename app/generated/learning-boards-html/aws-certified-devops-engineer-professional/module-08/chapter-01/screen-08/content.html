Module 8 › Chapter 8.1 › Infrastructure as Code Security
Definition

Prevent misconfiguration at provision time

Use linting and policy checks on IaC templates so insecure defaults are flagged and fixed before resources are created.

Practical rule
Reject templates that create unencrypted storage or wildcard IAM permissions. Fail early, show remediation steps.
Key Takeaway

Make IaC validation a non-optional build step so misconfigurations are caught and corrected once, not repeatedly fixed in production.

Example & Misconception
Concrete example
Add CloudFormation template checks that ensure S3 buckets require server-side encryption and deny public-read ACLs before deployment.
Common misconception
Thinking IaC validation replaces runtime checks. IaC reduces risk but runtime monitoring and drift detection remain necessary.
