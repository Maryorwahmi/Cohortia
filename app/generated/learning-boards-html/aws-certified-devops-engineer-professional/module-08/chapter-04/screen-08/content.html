Core Concept
DynamoDB: default encryption and key selection
Pick keys based on sensitivity and audit needs.
AWS Owned Keys
Minimal management; no direct audit control. Good for public or low-risk data.
AWS Managed Keys
Managed by AWS but visible in your account; lower overhead with some administrative visibility.
Customer Managed Keys
Full control over policies, rotation, and audit logs. Best for sensitive tables with compliance requirements.
Example
Use a customer-managed key for a table storing PII so you can restrict decryption to a vaulting role and track key usage in CloudTrail.
