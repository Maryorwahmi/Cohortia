Core Concept
RDS and EBS Encryption
Amazon RDS
Enable encryption at instance creation. Backups, read replicas, and snapshots are encrypted once the instance is encrypted.
Example: create a production database with a customer-managed KMS key so decryption calls are auditable and limited to a DB role.
Misconception
You cannot simply toggle encryption on an existing unencrypted database without recreating or restoring from encrypted snapshots.
Amazon EBS
Create encrypted EBS volumes using KMS; snapshots of encrypted volumes remain encrypted. Enforce default encryption at the region level for consistency.
Operational tip: automate volume creation in your provisioning templates to avoid accidental unencrypted volumes.
Key Takeaway

Provision encrypted storage from the start and include snapshot and replica protections in deployment automation.
