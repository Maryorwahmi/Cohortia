Core Concept
Encryption in Transit: ACM and TLS
What ACM provides
  • Provision public and private TLS certificates for ALBs, CloudFront, and API Gateway.
  • Automated certificate renewal to avoid outages from expired certs.
  • Integration with AWS services for seamless deployment.
Misconception check: using TLS with an invalid or self-signed certificate still produces trust errors. Use ACM for managed public certificates when exposing public endpoints.
Architecture example
Place an ACM certificate on an Application Load Balancer to terminate TLS at the load balancer. Use VPC private connectivity to forward traffic to backends, keeping internal traffic off the public internet.
Key Takeaway

Use ACM-managed certificates to ensure reliable TLS for public and internal endpoints and reduce renewal risk.
