Learning Objectives
Skills to implement and verify secure data handling in AWS.
Bloom: Learn → Understand → Apply → Master
01
Encrypt storage with KMS
Configure SSE with KMS for S3, enable RDS and EBS encryption, and choose customer-managed keys for auditability.
VERIFIED COMPETENCY MILESTONE
02
Encrypt traffic with ACM
Provision and attach TLS certificates via ACM to ALBs, CloudFront, and API Gateway to ensure client-server confidentiality and automated renewal.
VERIFIED COMPETENCY MILESTONE
03
Classify data sensibly
Use categories like public, internal, confidential, restricted to pick key types, retention policies, and access controls that match risk.
VERIFIED COMPETENCY MILESTONE
04
Automate key and secret rotation
Enable KMS rotation for customer-managed keys and use Secrets Manager to automate credential rotation for databases and services.
VERIFIED COMPETENCY MILESTONE
