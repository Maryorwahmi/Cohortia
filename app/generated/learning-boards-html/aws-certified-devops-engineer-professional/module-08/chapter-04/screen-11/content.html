Automate key and secret rotation
KMS key rotation
Enable automatic annual rotation for customer-managed keys. The key identifier stays the same while cryptographic material rotates, preserving access behavior.
Note: rotation of a KMS key changes the cryptographic material but not the logical key ID that services reference.
Secrets Manager
Configure automatic rotation for database credentials and custom secrets. Use rotation Lambdas to update credentials and the stored secret atomically.
Example
Rotate an RDS user password every 30 days using Secrets Manager rotation and ensure your application retrieves secrets from the store on a refresh interval.
Common mistake

Not designing applications to refresh rotated secrets leads to outages. Implement secrets retrieval patterns and caching with refresh hooks.
