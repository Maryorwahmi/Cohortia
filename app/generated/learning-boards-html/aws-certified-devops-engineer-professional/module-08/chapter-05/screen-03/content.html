Module 8 › Chapter 8.5 › Skills & Verification
Skill: Configure Security Groups

Create WebSG, AppSG, DBSG with least privilege rules. Verify with netcat and SSH from allowed IPs only.

Verification mnemonic: connect, confirm, restrict
Skill: VPC Endpoint for S3

Add a gateway endpoint and update route tables so private instances access S3 without a NAT. Verify with the CLI list command from a private instance.

Verification mnemonic: no internet, still works
Skill: WAF and Shield basics

Create a simple WAF rule to block a SQL injection pattern and observe blocked requests via logs. Understand Shield Standard protections and when Shield Advanced is needed.

Verification mnemonic: simulate, observe, document
Skill: GuardDuty monitoring

Enable GuardDuty, review findings for unusual API calls or instance behavior, and create a simple response flow to notify the team or trigger an investigation runbook.

Verification mnemonic: detect, validate, respond
