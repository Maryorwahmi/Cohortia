Module 8 › Chapter 8.5 › Common Mistakes
Frequent misconfigurations
  • Allowing SSH or DB ports from 0.0.0.0/0.
  • Missing egress restrictions on sensitive instances.
  • Relying on default VPC layouts in production.
Operational gaps
  • Not using VPC Endpoints for sensitive service traffic.
  • Ignoring GuardDuty findings and not automating responses.
  • Overcomplicating NACL deny lists that are hard to maintain.
Remediation checklist

Include network rule linting in CI, enforce IaC reviews for security groups and endpoints, and integrate GuardDuty findings into incident workflows.
