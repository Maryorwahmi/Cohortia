Module 8 › Chapter 8.5 › Hands-on: SGs & S3 Endpoint
Create Security Groups
Define WebSG, AppSG, DBSG and attach to the respective instances. Reference security groups instead of IPs for inter-tier traffic to keep rules dynamic and resilient.
Verification commands
# From Web Instance (should fail to reach DB)
nc -vz <DB_PRIVATE_IP> 3306

# From App Instance (should succeed to reach DB)
nc -vz <DB_PRIVATE_IP> 3306

# From App Instance (verify private S3 access)
aws s3 ls s3://your-private-s3-bucket-name/
Create Gateway Endpoint
Create an S3 gateway endpoint and ensure the route table for private subnets points to it. Update the S3 bucket policy to allow access only from your VPC endpoint or VPC ID.
Key Takeaway

Testing connectivity from the correct instance types verifies the intended isolation and private service access controls.
