Module 8 › Chapter 8.5 › Key Concepts
VPC
A logical network boundary where you design subnet segmentation and routing.
Security Group
Stateful resource-level allow-list. Reference other SGs to enforce least privilege.
NACL
Stateless subnet filter supporting allow and deny rules for broad protections.
VPC Endpoint
Gateway or Interface endpoints to keep service traffic private within AWS.
WAF / Shield
WAF filters application-layer requests; Shield mitigates DDoS and protects availability.
GuardDuty
Continuous threat detection using logs and network signals to generate security findings.
Summary takeaway

Combine these building blocks to create a repeatable, least-privilege network security posture for DevOps on AWS.
