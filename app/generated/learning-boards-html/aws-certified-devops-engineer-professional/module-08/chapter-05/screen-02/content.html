Learning Objectives
Learn, understand, apply, and master network security patterns for DevOps.
Bloom taxonomy
Learn
Understand
Apply
Master
01
Design secure VPC architectures

Design public and private subnets, route tables, and gateways so deployment targets are properly segmented and databases remain private. Verified competency milestone.

Mnemonic: Layered zones (public → app → private)
VERIFIED COMPETENCY MILESTONE
02
Configure Security Groups and NACLs

Create stateful security groups for instances and stateless NACLs for subnet-level filtering. Learn when to use each layer and how to avoid overly permissive rules. Verified competency milestone.

Mnemonic: Instance-level allow, subnet-level filter
VERIFIED COMPETENCY MILESTONE
03
Use VPC Endpoints for private service access

Implement gateway and interface endpoints to keep traffic to S3 and other services inside the AWS network and remove internet exposure. Verified competency milestone.

Mnemonic: Keep traffic on the backbone
VERIFIED COMPETENCY MILESTONE
04
Deploy WAF, Shield, and GuardDuty

Protect apps from web exploits and DDoS, and enable continuous threat detection so alerts translate to automated investigation or response. Verified competency milestone.

Mnemonic: Protect, Detect, Respond
VERIFIED COMPETENCY MILESTONE
