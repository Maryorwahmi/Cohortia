Security Group behavior

Stateful, instance-level allow rules only. Use security group references rather than IPs when possible. Avoid open SSH and database ports to the internet.

Example rule
{
  "IpProtocol": "tcp",
  "FromPort": 443,
  "ToPort": 443,
  "IpRanges": [{"CidrIp": "0.0.0.0/0"}],
  "Description": "Allow HTTPS from anywhere"
}
Concrete example

WebSG: permit 80/443 from 0.0.0.0/0, SSH only from corporate IP. AppSG: permit app port from WebSG. DBSG: permit database port from AppSG only. This enforces least privilege without exposing DBs to the internet.

Pro tip

Use security group references to avoid managing IP lists and to keep rules resilient to dynamic instance changes.
