Module 8 › Chapter 8.5 › WAF & Shield
AWS WAF

Define custom rules to block SQL injection, XSS, and suspicious headers. Attach to CloudFront, ALB, or API Gateway and monitor blocked requests for tuning.

Use case
Block repetitive malformed requests that indicate automated exploit attempts or scanning activity.
AWS Shield

Shield Standard offers baseline DDoS protection. Shield Advanced adds cost protection, metrics, and expert support for severe events. Use Shield as part of an incident response plan for large-scale attacks.

Monitoring
Integrate WAF and Shield metrics into alerts so blocked patterns and volumetric spikes trigger investigation steps.
Key Takeaway

WAF defends the application layer against exploit patterns; Shield defends availability during DDoS. Use both alongside secure coding practices.
