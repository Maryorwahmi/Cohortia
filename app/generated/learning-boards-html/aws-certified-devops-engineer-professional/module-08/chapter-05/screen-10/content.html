Module 8 › Chapter 8.5 › GuardDuty
What GuardDuty watches
  • VPC Flow Logs — unusual traffic flows and connections.
  • AWS CloudTrail — suspicious API activity and access patterns.
  • DNS logs — domain-based indicators of compromise.
Findings include unusual API calls, instance compromise signals, and crypto-mining. Use these to drive investigation and response workflows.
Operational flow
  1. Enable GuardDuty across accounts.
  2. Forward findings to Security Hub or EventBridge.
  3. Automate triage: enrich, validate, isolate if necessary.
Practice: review a finding, validate with flow logs or CloudTrail, and execute a documented response.
Key Takeaway

GuardDuty surfaces suspicious behavior. Integrate findings into automated workflows so detection leads to timely response rather than alert fatigue.
