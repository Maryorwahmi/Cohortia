Module 8 › Chapter 8.5 › VPC Endpoints
Endpoint types
  • Gateway endpoint — S3 and DynamoDB. Adds routes in route tables.
  • Interface endpoint — PrivateLink. Creates ENIs in your subnets to access other services.
Security tip
Update bucket policies to require the endpoint and avoid public exposure. Prefer endpoints over NAT for sensitive access.
Concrete workflow

Create a gateway endpoint for S3, attach it to route tables for private subnets, and update the S3 bucket policy to allow calls only from that endpoint or VPC. Verify by running the AWS CLI list command from a private instance and confirming no internet egress is used.

Key Takeaway

Use gateway endpoints for S3/DynamoDB to keep traffic on the AWS network and reduce public internet exposure.
