What are Access Keys?
An access key ID and secret access key are long-term credentials for programmatic API access. They must be protected similarly to passwords.
Danger
Hardcoded keys in repositories or scripts are a frequent cause of breaches.
Alternative
Use IAM roles, aws sts assume-role, or Secrets Manager to supply short-lived creds to applications.
Rotation
Rotate any remaining keys regularly and audit their usage through CloudTrail.
Checklist for Removing Hardcoded Keys
  • Identify code or scripts with embedded keys and replace them with role-based access.
  • Use Secrets Manager for cases that cannot assume a role and enable automatic rotation where available.
  • Implement key rotation policies and monitor key usage via CloudTrail.
  • Enforce code reviews and scanning to prevent accidental commits of keys.
