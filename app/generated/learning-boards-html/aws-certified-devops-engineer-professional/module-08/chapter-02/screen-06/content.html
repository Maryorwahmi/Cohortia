Module 8 › Chapter 8.2 › Create IAM Role for EC2
Policy Template
{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Effect": "Allow",
            "Action": [
                "s3:GetObject",
                "s3:PutObject",
                "s3:DeleteObject"
            ],
            "Resource": [
                "arn:aws:s3:::my-app-data-bucket-12345",
                "arn:aws:s3:::my-app-data-bucket-12345/*"
            ]
        }
    ]
}
Use this JSON as the role's permissions. Replace the bucket ARN with your actual bucket name.
Verification Commands (run on the EC2 instance)
# Verify temporary credentials are being used
curl http://169.254.169.254/latest/meta-data/iam/security-credentials/WebAppS3AccessRole

# Attempt to list contents of your specific bucket (should succeed)
aws s3 ls s3://my-app-data-bucket-12345/

# Attempt to list all buckets (should fail with Access Denied)
aws s3 ls

# Upload a test file (should succeed)
echo "Hello from EC2" > testfile.txt
aws s3 cp testfile.txt s3://my-app-data-bucket-12345/testfile.txt
If aws s3 ls fails without a bucket, the role is correctly scoped. If a needed action fails, add only the missing API to the policy.
