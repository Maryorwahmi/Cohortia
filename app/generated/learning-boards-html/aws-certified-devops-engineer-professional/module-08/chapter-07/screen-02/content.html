Learning Objectives
Bloom: Learn → Understand → Apply → Master
01
Automate patching with Patch Manager

Define patch baselines and maintenance windows so security updates apply consistently without manual steps. Verified competency milestone: baseline created and applied to a patch group.

VERIFIED COMPETENCY MILESTONE
02
Scan with Amazon Inspector

Integrate automatic assessments for EC2 and ECR images to catch vulnerabilities early. Milestone: a successful Inspector finding for a test image or instance.

VERIFIED COMPETENCY MILESTONE
03
Build golden AMIs with Image Builder

Author image recipes with hardening and tests so new instances start in a patched state. Milestone: a tested Image Builder pipeline produces a new AMI.

VERIFIED COMPETENCY MILESTONE
04
Manage third-party dependencies

Use SCA tools during builds and keep libraries updated to reduce supply chain risk. Milestone: SCA scan added to CI build stage and alerts configured.

VERIFIED COMPETENCY MILESTONE
