Module 08 › Chapter 8.7 › Activity: Patch Manager
Step-by-step
  1. Launch an EC2 instance with an IAM instance profile including AmazonSSMManagedInstanceCore.
  2. Confirm the SSM Agent is running and the instance is a managed instance in Systems Manager.
  3. Create a custom patch baseline for Amazon Linux 2 and set ApproveAfterDays to 7 for security updates.
  4. Tag the instance: PatchGroup=MyWebAppServers and map the patch group to the baseline.
  5. Create a maintenance window and register AWS-RunPatchBaseline targeting the patch group.
CLI snippet for tagging an instance (conceptual):
# Tag your EC2 instance (replace <INSTANCE_ID>)
aws ec2 create-tags --resources <INSTANCE_ID> --tags Key=PatchGroup,Value=MyWebAppServers
Checks & observations
  • Verify command execution status in Systems Manager Run Command history.
  • Review patch compliance reports to confirm installed updates.
  • Test patching on a small group before broad rollout.
Key Takeaway

Automate patching with clear baselines and small-scope testing to avoid widespread regressions.
