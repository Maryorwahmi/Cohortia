Module 08 › Chapter 8.7 › Patch vs Rebuild
Patching running instances
  • Fast response for critical fixes.
  • Can be automated with Patch Manager and maintenance windows.
  • Risk: configuration drift and inconsistent state.
Rebuilding images (immutable)
  • Consistent, repeatable images produced by Image Builder.
  • Simpler rollbacks by deploying previous AMIs.
  • Requires deployment pipelines that replace instances safely.
Scenario
For stateful services prefer careful patch testing and controlled rolling replacements. For stateless services, rebuilding AMIs and replacing instances is often preferable.
