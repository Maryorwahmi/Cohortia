Module 08 › Chapter 8.7 › Key Concepts
Vulnerability Management
Continuous identification, assessment, and remediation of security issues across systems and applications.
Systems Manager Patch Manager
Automates approval and application of OS updates using baselines, groups, and windows.
Amazon Inspector
Automated assessments for EC2 and container images that produce prioritized findings and remediation notes.
Summary Takeaway

Combine Patch Manager, Inspector, and Image Builder into automated pipelines to keep systems and images secure and verifiable.
