Module 08 › Chapter 8.7 › EC2 Image Builder
Image Builder workflow
  1. Select base image and define components (agents, packages, hardening).
  2. Run build and automated tests in the pipeline.
  3. Publish the AMI and deploy via replacement or Auto Scaling.
Example test
Verify that security agents are running, that the kernel is updated, and that a smoke test of the application succeeds before publishing.
Operational benefits
  • Immutable instances reduce configuration drift.
  • Rollbacks are simpler: launch prior AMI versions.
  • Image tests enforce quality gates before deployment.
Key Takeaway

Bake security into images and automate validation so new instances launch in a known-good state.
