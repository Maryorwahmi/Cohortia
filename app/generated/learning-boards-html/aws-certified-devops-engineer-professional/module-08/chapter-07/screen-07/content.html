Module 08 › Chapter 8.7 › Amazon Inspector
What Inspector does
  • Discovers packages and configuration issues on EC2 and in ECR images.
  • Generates findings with severity and remediation guidance.
  • Integrates with automation via EventBridge for alerts and actions.
Key Takeaway

Inspector helps you shift vulnerability detection left and provides structured findings for programmatic remediation.

Pipeline integration example
# Example: Trigger an Inspector scan for an ECR image (CLI)
# This is often integrated into a CodePipeline stage after image push
aws inspector2 start-software-vulnerability-assessment --resource-arn arn:aws:ecr:REGION:ACCOUNT_ID:repository/my-app-repo/image/my-app-image:latest
When a finding appears, you can fail the pipeline or route the finding to a remediation workflow. Inspector is detection — remediation is patching or rebuilding images.
