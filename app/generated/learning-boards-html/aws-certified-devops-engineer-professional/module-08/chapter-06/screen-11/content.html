Process Flow
EventBridge → Lambda remediation
EventBridge matches a finding and invokes a Lambda remediation function. The Lambda performs an idempotent, logged fix and records actions in CloudTrail.
Low-risk auto fixes
Enable bucket encryption, remove public ACLs.
High-risk actions
Access revocation or network changes should require approval.
Checklist for safe remediation
  • Idempotent actions with clear logs
  • Least-privilege execution role
  • Auditable change records in CloudTrail/Config
  • Classification of auto vs manual fixes
Key Takeaway

Automated remediation reduces time-to-fix but must be safe, auditable, and scoped to low-risk actions.
