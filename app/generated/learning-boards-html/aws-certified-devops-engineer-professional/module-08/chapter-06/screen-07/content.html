Definition
Lambda-backed Config Rule
The Lambda inspects the invoking event and returns COMPLIANT, NON_COMPLIANT, or NOT_APPLICABLE.
Example code (simplified)
import json

def lambda_handler(event, context):
  invoking_event = json.loads(event['invokingEvent'])
  configuration_item = invoking_event['configurationItem']

  resource_type = configuration_item['resourceType']
  resource_id = configuration_item['resourceId']

  if resource_type == "AWS::S3::Bucket":
    tags = configuration_item.get('tags', {})
    if tags.get('Environment') == 'Production':
      if configuration_item['supplementaryConfiguration']['BucketVersioningConfiguration']['Status'] == 'Enabled':
        compliance_type = 'COMPLIANT'
      else:
        compliance_type = 'NON_COMPLIANT'
    else:
      compliance_type = 'NOT_APPLICABLE'
  else:
    compliance_type = 'NOT_APPLICABLE'

  return {'compliance_type': compliance_type, 'annotation': f"Resource {resource_id} is {compliance_type}"}
Guidance
  • Give the Lambda least privilege—read Config and resource metadata only.
  • Unit-test the handler with mocked invoking events for each state.
  • Keep evaluation separate from remediation for auditability.
Key Takeaway

Implement custom rules as safe evaluators and test them before enabling wide-scope evaluations.
