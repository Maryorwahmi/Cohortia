S3 default encryption workflow
Follow these steps to create the managed rule and validate buckets.
# Create a non-compliant bucket
aws s3 mb s3://your-unique-bucket-name-noncompliant

# Create a compliant bucket and enable AES256 default encryption
aws s3 mb s3://your-unique-bucket-name-compliant --region YOUR_REGION --create-bucket-configuration LocationConstraint=YOUR_REGION
aws s3api put-bucket-encryption --bucket your-unique-bucket-name-compliant --server-side-encryption-configuration '{"Rules": [{"ApplyServerSideEncryptionByDefault": {"SSEAlgorithm": "AES256"}}]}'

# Re-evaluate the Config rule if needed
aws configservice start-config-rules-evaluation --config-rule-names s3-bucket-default-encryption-kms
Checks and gotchas
  • Ensure Config is recording S3 resources in the region.
  • Enable Security Hub to see aggregated findings.
  • Wait for Config re-evaluation or trigger it manually for quicker feedback.
Key Takeaway

Test both failing and passing resources to validate detection and aggregation flow before automating remediation.
