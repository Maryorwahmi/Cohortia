Process Flow
CI/CD compliance stages
  1. Static template validation and linting during pull request.
  2. Policy-as-code checks that validate resource properties against rules.
  3. Pre-deploy acceptance checks and staging evaluations with Config.
  4. Post-deploy monitoring and automated remediation triggers for safe fixes.
Concrete example
Add a pipeline stage that runs cfn-lint and a policy check; reject templates that create public S3 buckets or omit encryption settings. Record the failure in the pipeline logs for auditability.
Key Takeaway

Shift-left compliance prevents risky infra from deploying and makes remediation predictable.
