Process Flow
AWS Config flow
Record → Evaluate → Flag. Config records resource state, evaluates rules, and marks resources as compliant or not.
Inventory
Rules
Evaluations
Design tip: Scope rules with tags or resource filters so only intended resources are evaluated. That reduces false positives and keeps teams focused on relevant findings.
Example: Tag + versioning rule
A Lambda-backed custom rule checks that production S3 buckets have Environment: Production and versioning enabled. If neither condition is met, it returns NON_COMPLIANT.
Common mistake
Treating NOT_APPLICABLE resources as failures. Use NOT_APPLICABLE wisely to avoid noise.
Key Takeaway

Custom rules let you encode organizational policy. Scope and least-privilege reduce noise and risk.
