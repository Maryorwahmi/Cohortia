Definition
AWS CloudTrail
Records API and management events and optionally data events like S3 object access for forensic analysis.
Best practice
Send logs to a central, encrypted S3 bucket in a dedicated logging account and enable multi-region logging.
Common mistake
Not enabling data events for S3 or Lambda, which can hide important access activity.
Concrete example
If an IAM role modifies a bucket policy, CloudTrail stores the API call, caller identity, and request parameters so you can trace the change and correlate with Config findings.
Pro tip
Protect the logging account with strict IAM and MFA and use bucket encryption and lifecycle rules for retention.
Key Takeaway

Complete, centralized logs are the foundation for both audits and incident response.
