Core Concept
Compliance as Code — definition

Policies and controls are written, versioned, and executed so compliance becomes continuous and testable.

Analogy
Think of rules as unit tests for cloud configuration. They fail when a resource drifts from its expected state.
Practical pattern
Versioned rules in Git
Test in staging
CI gate checks
Automated remediation
Common misconception: automation removes the need for audits. Reality: automation provides consistent evidence and reduces manual effort, but human review remains essential for exceptions.
Key Takeaway

Treat policies as code so you can test, version, and run them continuously, improving speed and reproducibility.
