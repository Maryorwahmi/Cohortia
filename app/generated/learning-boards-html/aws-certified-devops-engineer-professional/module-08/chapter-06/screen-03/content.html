Module 8 › Chapter 8.6 › Learning Objectives
How you'll practice
  • Enable Config to record S3 resources and create the managed s3-bucket-default-encryption-kms rule.
  • Write or inspect a Lambda-backed custom rule to validate tags or versioning on S3 buckets.
  • Link Config findings to Security Hub and validate a non-compliant and compliant bucket scenario.
  • Use EventBridge to trigger a Lambda remediation and re-evaluate the rule.
Why this matters
Automating these steps produces reproducible evidence for auditors and shrinks detection and remediation times.
