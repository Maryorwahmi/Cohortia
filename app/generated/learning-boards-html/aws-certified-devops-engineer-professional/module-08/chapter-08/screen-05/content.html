Module 8 › Chapter 8.8 › Running DAST in Staging
DAST process
1. Deploy to a temporary staging environment that mirrors production.
2. Run an authenticated DAST scan using OWASP ZAP or a commercial scanner.
3. Parse the scan report; fail pipeline on critical issues and create tickets for others.
4. Aggregate DAST with SAST findings for developer triage and remediation planning.
Concrete example
You deploy a commit to an ephemeral environment, run OWASP ZAP with test credentials, and then parse the JSON report. If an authentication bypass is found, the pipeline fails and the PR is blocked until fixed.
Pro tip: run quick DAST checks on feature environments and full scans nightly to catch slow-to-appear issues.
Key Takeaway

DAST finds runtime issues that SAST cannot. Use it on ephemeral staging and gate promotion on critical findings to reduce risk.
