Module 8 › Chapter 8.8 › Security Chaos — Two practical experiments
Experiment A — IAM revocation
Hypothesis: revoking a specific permission will cause a controlled failure without exposing secrets. Steps: identify scope, snapshot state, revoke permission in test account, monitor logs, and rollback if necessary.
Monitoring checklist: • CloudTrail logging • Application traces • Error rates and alarms
Experiment B — DDoS simulation
Hypothesis: WAF and Shield trigger mitigations under attack conditions. Steps: use authorized simulation tools in an isolated environment, confirm mitigations, and validate incident playbook usability.
Safety checklist: • Non-production endpoints only • Pre-approved test window • Rollback and traffic limits
Key Takeaway

Design experiments with explicit hypotheses, measurements, and rollback plans so you learn without risking production services.
