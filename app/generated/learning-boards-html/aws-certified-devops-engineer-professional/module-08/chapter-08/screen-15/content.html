Module 8 › Chapter 8.8 › Key Concepts — Part 2
RASP
Active runtime protection that detects and can block attacks inside the application.
Security Chaos Engineering
Injecting failures in controlled tests to validate controls and incident response mechanisms.
Security Hub & Automations
Use custom actions, EventBridge patterns, and Lambda to automate validated remediation with logging and auditability.
Final takeaway
Combine multiple testing approaches, validate resilience through controlled experiments, and automate remediations with safety and oversight to build secure, resilient systems.
