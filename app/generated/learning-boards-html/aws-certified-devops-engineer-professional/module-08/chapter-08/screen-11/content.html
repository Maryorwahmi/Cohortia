Simplified Lambda example (excerpt)
import json
import boto3

s3 = boto3.client('s3')
securityhub = boto3.client('securityhub')

def lambda_handler(event, context):
  for finding in event['detail']['findings']:
    finding_id = finding['Id']
    product_arn = finding['ProductArn']
    for resource in finding['Resources']:
      if resource['Type'] == 'AwsS3Bucket':
        bucket_name = resource['Details']['AwsS3Bucket']['BucketName']
        s3.put_public_access_block(
          Bucket=bucket_name,
          PublicAccessBlockConfiguration={
            'BlockPublicAcls': True,
            'IgnorePublicAcls': True,
            'BlockPublicPolicy': True,
            'RestrictPublicBuckets': True
          }
        )
        securityhub.batch_update_findings(
          FindingIdentifiers=[{'Id': finding_id,'ProductArn': product_arn}],
          Workflow={'Status': 'RESOLVED'}
        )
This function applies a public access block and marks the finding resolved. Ensure your role only has the minimal permissions it needs.
Operational checklist
  • Give Lambda least privilege (s3:PutBucketPublicAccessBlock, securityhub:BatchUpdateFindings).
  • Log every remediation attempt and exception.
  • Test in non-production and validate Security Hub finding updates.
Common mistake

Avoid broad IAM roles for remediation functions. Over-privileged automations create risk if compromised.

Key Takeaway

Remediation functions must be treated as first-class code: least privilege, test coverage, logging, and human review for high-impact actions.
