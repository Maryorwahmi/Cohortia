Module 8 › Chapter 8.8 › Penetration Testing and AWS Authorization
When to use pen tests
Use pen tests to validate complex attack paths and business-logic vulnerabilities that automated tools cannot easily find. They should follow a clear scope and authorization model.
• Define scope, timelines, and allowed vectors.
• Prepare monitoring and forensic capture prior to tests.
• Collaborate with security and operations teams.
AWS policy considerations
Generally, testing of customer-managed resources in your VPC does not require prior approval. Services that affect the security of the cloud or shared infrastructure may require AWS approval. Always review the current AWS policy before testing.
Key Takeaway

Use penetration testing to complement automated tools, but plan scope and authorization carefully to avoid service disruption and to capture useful findings.
