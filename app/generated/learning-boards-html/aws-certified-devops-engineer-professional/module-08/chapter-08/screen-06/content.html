Module 8 › Chapter 8.8 › IAST and RASP — Runtime complements
IAST
IAST instruments the app and reports data-flow issues with code context and reproducible traces. It reduces false positives by linking runtime evidence to code paths.
• High-fidelity findings useful for developers.
• Deployed as an agent within the runtime environment.
• Not a replacement for SAST or DAST; it augments them.
Concrete analogy
IAST is like instrumenting an appliance to record how inputs travel through internal circuits; it reveals the exact component that overheats when a certain input occurs.
RASP
RASP actively protects by detecting attacks inside the application and blocking malicious inputs in real time. Use it where immediate prevention is required, while continuing to fix root causes.
• Immediate blocking can reduce impact but may affect availability.
• Should be combined with remediation and code fixes.
• Ensure agent permissions adhere to least privilege.
Key Takeaway

IAST gives precise developer-focused context; RASP provides active defense. Use both where their tradeoffs fit your risk profile.
