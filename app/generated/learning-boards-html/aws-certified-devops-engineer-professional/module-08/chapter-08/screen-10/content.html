Module 8 › Chapter 8.8 › EventBridge Rule for Security Hub Findings
Example rule pattern
{
  "source": ["aws.securityhub"],
  "detail-type": ["Security Hub Findings - Imported"],
  "detail": {
    "findings": {
      "ProductFields": {
        "aws/securityhub/ProductName": ["GuardDuty"]
      },
      "Severity": {"Label": ["CRITICAL"]},
      "Compliance": {"Status": ["FAILED"]},
      "Resources": [{"Type": ["AwsEc2Instance"]}]
    }
  }
}
This pattern routes only critical GuardDuty findings that show failed compliance and reference EC2 instances. Adjust values to fit your environment and test thoroughly.
Implementation notes
• Prefer specific ProductName and Severity filters to reduce false positives. • Consider Step Functions for multi-step remediation. • Log all matches and remediation attempts to an audit trail.
Key Takeaway

Use EventBridge patterns to target the exact class of findings you trust to be remediated automatically, and tune patterns after observing real events.
