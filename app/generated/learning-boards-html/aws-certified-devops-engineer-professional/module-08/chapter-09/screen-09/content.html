Comparing core services
Each service plays a distinct role in detection and forensics.
Amazon GuardDuty
Threat detection producing findings that indicate suspicious behavior and priorities for investigation.
AWS CloudTrail
Audit trail of API calls used to reconstruct who did what and when during an incident.
VPC Flow Logs
Network metadata that shows source/destination IPs and ports for flow-level analysis.
Example correlation
A high-severity GuardDuty finding triggers automation. CloudTrail shows the creation of the instance and IAM activities. VPC Flow Logs show outbound connections to a malicious IP and possible exfiltration patterns.
