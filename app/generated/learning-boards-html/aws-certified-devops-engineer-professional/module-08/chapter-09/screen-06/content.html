Module 9 › Chapter 8.9 › Automation Architecture
Event-driven remediation
Combine EventBridge, Lambda, and Systems Manager to automate containment and forensic data collection.
Detect
GuardDuty or CloudWatch emits a finding.
Route
EventBridge matches a rule and forwards the event.
Remediate
Lambda or SSM executes containment and collects evidence.
Safety patterns
  • Scope EventBridge rule patterns to specific types and severities.
  • Grant minimal IAM permissions to Lambda and SSM documents.
  • Prefer isolation and snapshots over immediate termination.
Example workflow
GuardDuty finding -> EventBridge rule filters on severity and type -> Lambda creates EBS snapshot and modifies security groups -> SSM Automation collects logs and runs remote diagnostics.
Pro tip
Use automation documents for multi-step actions because they provide execution history and easier auditability compared to ad-hoc Lambda scripts.
