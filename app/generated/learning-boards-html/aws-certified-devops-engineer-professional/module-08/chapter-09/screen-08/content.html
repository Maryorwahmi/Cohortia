Collecting evidence in AWS
A standardized collection preserves chain-of-custody and supports reliable analysis.
CloudTrail
Records API calls. Export to a centralized encrypted S3 bucket and enable versioning and MFA delete where required.
VPC Flow Logs
Show network flows to and from interfaces, useful to detect suspicious external connections or large transfers.
CloudWatch & Snapshots
Collect application logs and take EBS snapshots to preserve disk state for offline analysis.
Checklist
  • Preserve snapshots before making changes to disks.
  • Store logs in a separate logging account with encryption and versioning.
  • Record timestamps and handlers for chain-of-custody.
