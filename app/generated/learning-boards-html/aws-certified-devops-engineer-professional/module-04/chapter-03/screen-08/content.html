Core Concept › Patch Manager Fundamentals
Key components
  • Patch Baseline: rules that approve or reject patches.
  • Patch Group: instances grouped by tags and associated with a baseline.
  • Maintenance Window: scheduled time to run disruptive operations like patching.
Concrete scenario
Schedule critical Windows updates for development servers on the second Tuesday each month by creating a baseline that approves those security patches, tagging the servers into a PatchGroup:Dev-Windows, and scheduling a maintenance window for that cadence.
Common mistake
Applying broad baselines to production without rejecting known bad patches can lead to outages. Maintain separate baselines per environment.
Key Takeaway

Patch Manager automates safe, auditable updates when you control approvals with baselines and scope with patch groups and windows.

Monitoring
Patch Manager provides compliance reports listing compliant and non-compliant instances and patch reasons, useful for audits and troubleshooting.
