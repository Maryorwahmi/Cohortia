Hands-on Activity › Verify Drift Remediation
Steps
  1. Create and test InstallApacheWebServer document with Run Command on staging.
  2. Create association ApacheWebServerConfig targeting SSM-Demo-Instance with a test schedule.
  3. Enable compliance reporting and monitor Last execution.
  4. Simulate drift by stopping httpd and observe remediation on the next run.
  5. Create a patch baseline, tag an instance into a patch group, and run patches during a maintenance window to verify compliance.
After the test, revert short schedules and remove test artifacts. Record the compliance evidence for your learning log or audit sample.
Safety
Do not leave port 80 open on production instances after verification; close temporary exposure immediately.
Key Takeaway

The lab demonstrates remediation and compliant patching; use it to validate policies and create audit evidence for your environment.
