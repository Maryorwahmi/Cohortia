Process Flow › Create Association Walkthrough
Step-by-step
  1. Name the association: ApacheWebServerConfig.
  2. Select the tested document: InstallApacheWebServer (or your custom document).
  3. Choose targets: select instances manually or target by tag like Environment:Production.
  4. Specify schedule: short interval for testing; longer for production.
  5. Enable compliance reporting and create the association.
Verification checklist
  • Check Last execution and view standard output to confirm commands succeeded.
  • Simulate drift by stopping the service and observe remediation on next run.
  • Confirm the instance shows Compliant in State Manager after remediation.
Safety reminder
Use short schedules only for validation, not production. Excessively frequent runs can add load and noise; balance responsiveness with operational cost.
Key Takeaway

Create clear associations, test them, and use compliance reporting to prove enforcement. Simulate drift to confirm your policy repairs as expected.
