Configuration Drift
When actual system state diverges from the intended baseline.
Why it occurs
  • Manual troubleshooting that changes packages or services.
  • Ad hoc updates or missed deployments on some hosts.
  • Different runbooks or inconsistent automation across teams.
Concrete example
If a monitoring agent is stopped on a host, State Manager can detect and reapply the desired configuration to reinstall or restart it on its next scheduled run.
Key Takeaway

Drift is silent but remediable: define the desired state and use State Manager associations to enforce it continuously.

Analogy
Think of a desired state as a recipe and drift as a cook who adds the wrong spice to a single serving. State Manager is the head chef who periodically checks each plate and corrects the seasoning.
Common misconception
Drift only affects files. In reality, services, package versions, and runtime configurations all drift. Enforcement must cover installation and runtime state.
