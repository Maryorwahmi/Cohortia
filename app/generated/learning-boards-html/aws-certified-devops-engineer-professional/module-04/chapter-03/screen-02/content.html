Learning Objectives
Master the skills that prevent drift and automate patching safely.
01
Configure State Manager
Author an SSM document and create an association that targets instances and runs on a schedule. This enforces a desired configuration and reduces manual fixes.
VERIFIED COMPETENCY MILESTONE
02
Understand configuration drift
Recognize causes of drift and how continuous enforcement via State Manager detects and corrects deviations.
VERIFIED COMPETENCY MILESTONE
03
Implement Patch Manager
Define patch baselines and use maintenance windows to apply approved patches without disrupting users.
VERIFIED COMPETENCY MILESTONE
04
Monitor patch compliance
Use compliance reporting and AWS Config to show which instances are compliant and which patches were applied or rejected.
VERIFIED COMPETENCY MILESTONE
