Architecture › Baselines & Patch Groups
Recommended architecture
Production Baseline
Approve critical security patches only; reject problematic or disruptive updates.
Staging Baseline
Approve a broader set of updates for validation before production rollout.
Development Baseline
More permissive approvals to catch integration issues early.
Tag instances into patch groups such as PatchGroup:Prod-Web or PatchGroup:Staging-App. Associate each group with the appropriate baseline and schedule a maintenance window. Include snapshots and health checks as automation steps to reduce rollback risk.
Practical tip
Promote baselines after successful validation in development and staging to keep production stable.
Key Takeaway

Separate baselines by environment and use patch groups plus maintenance windows to limit impact and provide auditable control.
