Document (YAML) — copy and test
schemaVersion: "2.2"
description: "Installs and starts Apache HTTP Server."
mainSteps:
  - action: aws:runShellScript
    name: installApache
    inputs:
      commands:
        - "sudo yum update -y"
        - "sudo yum install -y httpd"
        - "sudo systemctl enable httpd"
        - "sudo systemctl start httpd"
        - "echo '<h1>Hello from State Manager!</h1>' | sudo tee /var/www/html/index.html"
      timeoutSeconds: 300
    precondition:
      StringEquals:
        - platformType
        - Linux
Testing checklist
  • Run this document with Run Command on a staging instance and inspect stdout/stderr.
  • Verify /var/www/html/index.html contains the test page and httpd is active.
  • Simulate drift by stopping httpd and wait for a scheduled association run to confirm remediation.
Note
Escaping HTML in commands matters; the document writes a small index file for quick verification but always sanitize user inputs in production.
Key Takeaway

Test documents via Run Command before associations, keep steps idempotent, and validate remediation by simulating drift.
