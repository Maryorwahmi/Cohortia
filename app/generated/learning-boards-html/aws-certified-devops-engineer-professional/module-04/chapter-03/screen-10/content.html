Comparison › Compliance Reporting
State Manager reports
  • Association execution history with timestamps and output.
  • Instance compliance status: Compliant or Non-compliant.
  • Use this to demonstrate that a desired state is enforced.
Patch Manager reports
  • Which instances have missing approved patches and why.
  • Patch IDs, approval state, and execution results after maintenance windows.
  • Useful for audits and automated compliance checks.
Operational patterns
Export compliance data into dashboards and alerting systems. If non-compliance appears, link to automated remediation runbooks so issues are resolved quickly and documented for audit trails.
Key Takeaway

Collect and use compliance data from State Manager and Patch Manager to prove policy enforcement and drive automated remediation workflows.
