Module 4 › Chapter 4.7 › Conceptual Lab
Activity steps
  1. Open Service Catalog and locate a portfolio shared with your account.
  2. Choose a product like "Development Web Server" and start a launch.
  3. Enter allowed parameters and submit the launch request.
  4. Observe the provisioned product status and inspect outputs when available.
Self-reflection prompts
  • Which parameters would you restrict with a template constraint?
  • What permissions must the launch role include to provision this product?
  • How would you document expected outputs for end-users?
