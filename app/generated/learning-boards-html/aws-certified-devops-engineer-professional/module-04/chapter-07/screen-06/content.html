Module 4 › Chapter 4.7 › Portfolios vs Products
Product (single unit)
Represents one deployable service defined by a CloudFormation template, with parameters and outputs. Examples: development web server, managed database instance.
Characteristics
  • Template-backed, repeatable provisioning
  • Has parameters, tags, and outputs
  • Designed for consistency
Portfolio (collection)
A container of products used to grant sets of users access to approved services. Use portfolios to separate environments and roles, and to simplify permission management.
When to use portfolios
Group by team, environment, or compliance need so users see only the products appropriate for them.
Example: Developer Portfolio
Contains development server and test database products with relaxed cost limits.
Example: Production Portfolio
Contains hardened products and strict template constraints to enforce sizes and encryption.
Quick Tip
Prefer fewer portfolios focused on clear boundaries rather than many overlapping ones.
