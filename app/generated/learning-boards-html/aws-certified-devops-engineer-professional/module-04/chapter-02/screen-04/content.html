Module 4 › Chapter 4.2 › Run Command — definition
Core Concept

Run Command

Run immediate commands on managed instances using prebuilt or custom command documents. Results are aggregated for inspection.

Common uses
  • Check disk space across web servers
  • Restart a service after deployment
  • Install a package quickly on a few instances
Common mistake
Running broad commands without limiting targets or concurrency risks unintended impact; always test and scope targets.
Key Takeaway

Use Run Command for quick, single-step operations and centralized output; preserve Automation Documents for multi-step orchestration.

Example: check disk and restart a service
# Command Document: AWS-RunShellScript
# Commands sent to SSM agent on each instance
Commands:
  - df -h
  - sudo systemctl restart myservice
Targeting
Use tags, resource groups or instance IDs to scope execution.
Permissions
Ensure the SSM agent role has required permissions or commands will fail.
