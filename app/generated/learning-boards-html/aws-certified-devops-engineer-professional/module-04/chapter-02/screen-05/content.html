Module 4 › Chapter 4.2 › Command Documents
Pre-defined

AWS-provided documents

Use these for common tasks: shell scripts, Windows PowerShell, installs, or updates. They save time and have known behavior.

Examples
  • AWS-RunShellScript
  • AWS-RunPowerShellScript
  • AWS-InstallApplication
Misconception
Pre-defined docs are not a substitute for testing. They still require correct parameters and permissions.
Custom

Author your own document

Create custom documents when your workflow requires specific commands, environment variables, or orchestration not covered by built-ins.

Checklist before use
  • Test in non-production
  • Verify SSM agent IAM permissions
  • Keep steps idempotent where possible
Prompt
When would a custom command document be required in your environment? Consider package managers or custom service names.
