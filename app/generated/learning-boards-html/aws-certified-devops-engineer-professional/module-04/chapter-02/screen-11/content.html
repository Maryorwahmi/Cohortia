Module 4 › Chapter 4.2 › InstallNginxAutomation Lab
Step-by-step
  1. Create IAM role for Automation and attach AmazonSSMAutomationRole policy.
  2. Open Systems Manager Automation and create a new YAML document.
  3. Paste the InstallNginxAutomation YAML and save with a name like InstallNginxAutomation.
  4. Execute the document, select the automation role, pass InstanceId, and run.
  5. Monitor steps and review the verify step output for a successful curl response.
Safety note
If you open port 80 to verify the welcome page, close it immediately after verification.
Document snippet
description: "Installs Nginx on a specified EC2 instance."
schemaVersion: "0.3"
parameters:
  InstanceId:
    type: String
mainSteps:
  - name: installNginx
    action: aws:runShellScript
    inputs:
      InstanceIds: ["{{ InstanceId }}"]
      Commands:
        - "sudo yum update -y"
        - "sudo amazon-linux-extras install nginx1 -y"
        - "sudo systemctl enable nginx"
        - "sudo systemctl start nginx"
  - name: verifyNginx
    action: aws:runShellScript
    inputs:
      InstanceIds: ["{{ InstanceId }}"]
      Commands: ["curl -I localhost"]
    outputs:
      - Name: NginxStatus
        Selector: "$.stdout"
        Type: String
