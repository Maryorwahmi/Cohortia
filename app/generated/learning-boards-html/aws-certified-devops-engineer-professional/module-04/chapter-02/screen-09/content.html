Module 4 › Chapter 4.2 › Parameters & Outputs
Parameters (inputs)
Define variables such as InstanceId or PatchGroup so the document is reusable. Parameters are provided at execution time and keep documents environment-agnostic.
Example parameter
InstanceId: type: String
Outputs (observability)
Capture a step result using a selector, for example the stdout of a shell script. Use that value to validate success or drive conditional cleanup or rollback.
Example output
Name: ServiceStatus Selector: $.stdout Type: String
