Module 4 › Chapter 4.2 › Rate Control
MaxConcurrency
Limit how many instances run the command at once. Use small values in production to reduce blast radius.
Example
MaxConcurrency: 10 — only 10 instances run concurrently.
ErrorThreshold
Set how many failures are allowed before stopping the execution on remaining instances.
Example
ErrorThreshold: 5 — stop if five instances fail.
Staged rollout
Combine small canary runs, conservative MaxConcurrency, and a low ErrorThreshold for safer rollouts. Adjust settings after validating results in each stage.
