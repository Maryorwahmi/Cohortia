Module 4 › Chapter 4.6 › Remediation & IAM
Testing and Approval
Always validate remediation logic in a staging environment. Implement dry-run modes and require human approval for high-risk changes.
Throttling
Prevent rapid-fire remediation by adding rate limits or queuing through SQS between detection and action.
IAM for Remediation
Define IAM roles with the minimal set of permissions the remediation Lambda needs to change a resource. Avoid broad ARNs or wildcard actions.
Pitfall
Over-privileged remediation IAM roles can cause accidental widespread changes if the Lambda has a bug.
