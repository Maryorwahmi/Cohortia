Module 4 › Chapter 4.6 › Integrations
Config Rule triggers an event
When a resource is non-compliant, Config emits an event that can be routed to SNS or CloudWatch Events.
SNS dispatches to subscribers
SNS fan-out supports multiple subscribers, such as Lambda, email, or SQS for queueing.
Lambda performs remediation
Lambda can attempt fixes, but always validate in staging and use least-privilege roles.
Central Aggregation
Forward Config findings to Security Hub for centralized visibility, and use Control Tower for multi-account guardrails.
Safety pattern
Add approval gates or rate limits to remediation to prevent cascading changes in production.
Practical example
A non-compliant S3 bucket triggers SNS, Lambda runs a script to revert ACLs, and Security Hub records the finding for triage.
