Module 4 › Chapter 4.6 › What is AWS Config?
Definition & Purpose
AWS Config captures and stores point-in-time configuration items for supported AWS resources, creating a timeline useful for governance and troubleshooting.
Analogy
Like a security camera plus an auditor: records state and keeps the record for later inspection.
Misconception
Config is not a replacement for CloudTrail; use Config for state and CloudTrail for API actors.
Why it matters
Audits and forensic investigations depend on accurate, historical configuration data to trace incidents and verify compliance.
Key Takeaway

Config is the canonical historical view of resource configuration; pair it with CloudTrail for complete audit context.

Configuration Item (CI) Example
{
  "resourceType": "AWS::S3::Bucket",
  "resourceId": "my-public-config-test-bucket",
  "configuration": {
    "publicAccessBlock": false,
    "bucketPolicy": "..."
  },
  "captureTime": "2026-01-01T12:34:56Z"
}
Each CI contains the resource’s attributes at a point in time. Use the timeline to compare successive CIs when troubleshooting.
