Module 4 › Chapter 4.6 › Configuration Items
What a CI contains
  • Resource type and identifier
  • Configuration attributes captured at that time
  • Capture timestamp and related metadata
Example question
Which CI shows when disk encryption was turned off? Use the timeline to find the CI where the encryption attribute changes.
Using the Timeline
Open a resource in Config and click the Timeline tab to compare consecutive CIs. Look for attribute diffs and capture times to reconstruct the event sequence.
// Conceptual diff
CI at T1: { "encryption": true }
CI at T2: { "encryption": false }
// Use CloudTrail to find the API call near T2 and identify the actor.
