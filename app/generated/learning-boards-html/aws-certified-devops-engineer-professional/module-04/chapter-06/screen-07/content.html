Managed Rule Object
{
  "ConfigRuleName": "s3-bucket-public-read-prohibited",
  "Description": "Checks if S3 buckets are publicly readable.",
  "Scope": {
    "ComplianceResourceTypes": ["AWS::S3::Bucket"]
  },
  "Source": {
    "Owner": "AWS",
    "SourceIdentifier": "S3_BUCKET_PUBLIC_READ_PROHIBITED"
  }
}
This JSON configures Config to run the built-in S3 public-read evaluator over S3 buckets in scope.
S3 Non-Compliance Scenario
Create a bucket with public read enabled and the managed rule will mark it non-compliant after evaluation.
