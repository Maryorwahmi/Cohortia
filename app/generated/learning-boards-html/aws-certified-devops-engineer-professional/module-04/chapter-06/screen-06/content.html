Module 4 › Chapter 4.6 › Managed vs Custom Rules
Managed Rules
Pre-built by AWS to check common best practices. Quick to deploy and low maintenance.
  • Examples: S3 public access checks, EBS encryption.
  • Pros: maintained by AWS, lower operational burden.
  • Cons: may not cover organization-specific needs.
Tip

Search for a managed rule before building a custom one to save effort.

Custom Rules (Lambda)
Use Lambda to implement logic that evaluates resources against bespoke policies, such as tag presence or runtime constraints.
  • Pros: full control and tailored checks.
  • Cons: requires Lambda code, testing, and careful IAM permissions.
  • Watch out for false positives and Lambda time limits when evaluating many resources.
Common mistake

Creating too many untested custom rules can produce noise and unexpected Lambda costs.
