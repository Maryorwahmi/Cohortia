Module 4 › Chapter 4.6 › Lab Walkthrough
Step 1 — Enable AWS Config
Get started in the console, create a delivery S3 bucket, and create the service-linked role for Config.
Step 2 — Add Managed Rule
In Rules, add s3-bucket-public-read-prohibited and let Config begin evaluation.
Step 3 — Create Public Bucket
Create a bucket with block public access unchecked and add a public-read bucket policy.
Observe & Investigate
Wait for the rule to evaluate, then open the rule, view resources in scope, and inspect the resource timeline to see the configuration items that show the change.
Safety reminder
Delete the public bucket and remove the rule after the lab to avoid security exposure and extra costs.
