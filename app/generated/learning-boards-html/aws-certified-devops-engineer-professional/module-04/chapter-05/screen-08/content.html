Conceptual OpsWorks Stack JSON

This snippet is a planning artifact. It reflects the parameters you'll set when creating a stack and layers.

{  
  "StackName": "MyWebAppStack",
  "Region": "us-east-1",
  "ServiceRoleArn": "arn:aws:iam::123456789012:role/aws-opsworks-service-role",
  "DefaultInstanceProfileArn": "arn:aws:iam::123456789012:instance-profile/aws-opsworks-ec2-role",
  "Layers": [
    {
      "Name": "WebServerLayer",
      "Type": "aws-opsworks-web",
      "AutoScaling": { "MinInstances": 1, "MaxInstances": 3 },
      "CustomRecipes": { "Setup": ["my_cookbook::webserver_setup"], "Deploy": ["my_cookbook::webserver_deploy"] }
    },
    {
      "Name": "AppServerLayer",
      "Type": "aws-opsworks-app",
      "AutoScaling": { "MinInstances": 1, "MaxInstances": 2 },
      "CustomRecipes": { "Setup": ["my_cookbook::appserver_setup"], "Deploy": ["my_cookbook::appserver_deploy"] }
    }
  ],
  "AppSources": [ { "Type": "git", "Url": "https://github.com/myorg/my-app.git", "Revision": "main" } ]
}
Service & Instance Roles
Define service role and default instance profile ARNs so OpsWorks and EC2 have required permissions.
Custom Recipes
Map recipes to lifecycle events to automate install and deploy tasks.
AppSources
Point to a Git repository or other source to let OpsWorks pull application code during Deploy.
