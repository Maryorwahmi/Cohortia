Module 4 › Chapter 4.5 › Lifecycle Events
Events
  1. Setup: run when an instance starts to install packages and register services.
  2. Configure: apply configuration changes to running instances.
  3. Deploy: pull application code, run migrations, restart services.
  4. Undeploy: remove application artifacts safely.
  5. Shutdown: clean up before termination.
Concrete walkthrough
Attach my_cookbook::webserver_setup to Setup to install Nginx and register with a load balancer. Attach my_cookbook::webserver_deploy to Deploy to pull code and restart the service. Test by creating an instance and observing Setup run once.
Pitfall: non-idempotent recipes may fail on re-run and prevent instances from reaching a stable state.
Idempotency
Write recipes so repeated runs do not change the desired state unexpectedly.
Testing
Test lifecycle recipes in a dev stack before production deployments.
Recovery
Plan error handling in recipes so a failed Setup doesn’t leave instances unusable.
