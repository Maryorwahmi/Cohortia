Architecture

Layer-based design

Layers represent logical roles. Each layer defines instance settings, security groups, and lifecycle recipes.

  • WebServer layer: install web server, register with load balancer.
  • AppServer layer: deploy app runtime, run migrations on Deploy event.
  • Database layer: careful with stateful deployments and backups.
Example Stack
{
  "StackName": "MyWebAppStack",
  "Region": "us-east-1",
  "Layers": [
    { "Name": "WebServerLayer", "Type": "aws-opsworks-web" },
    { "Name": "AppServerLayer", "Type": "aws-opsworks-app" }
  ],
  "AppSources": [ { "Type": "git", "Url": "https://github.com/myorg/my-app.git" } ]
}
Design Tip

Define IAM instance profiles early so recipes can access S3, Parameter Store, or other resources securely during lifecycle events.
