Module 4 › Chapter 4.5 › OpsWorks vs SSM
Systems Manager

Agent-centric, supports ad-hoc commands, patching, Parameter Store and session manager. Great for operational tasks across diverse instances.

OpsWorks

Application-centric, lifecycle events, Chef/Puppet integration and managed master options. Best for cookbook-driven multi-tier deployments.

When to use SSM
Ad-hoc ops, patching, and instance troubleshooting across a heterogeneous fleet.
When to use OpsWorks
Structured, lifecycle-driven application deployments using Chef or Puppet workflows.
Complementary use
It is common to use SSM for patching and OpsWorks for deployment automation together.
