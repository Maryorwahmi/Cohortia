Module 4 › Chapter 4.5 › Recipes & Modules
What to write
  • Cookbooks: group recipes, templates, and files for a feature area.
  • Recipes: sequences of resources that enforce desired state, e.g., install packages, configure files.
  • Puppet modules: encapsulate classes and resources for reuse across nodes.
Idempotency example

A package resource that ensures Nginx is present should not attempt to reinstall if already installed. Design checks or use resource primitives that are safe to run multiple times.

Pitfall: non-idempotent scripts attached to lifecycle events can break scaling and recovery.
Key Takeaway

Treat cookbooks and modules as testable code. Validate idempotency and failure modes so OpsWorks lifecycle automation is reliable.
