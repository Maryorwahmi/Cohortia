Module 4 › Chapter 4.5 › What is OpsWorks?
Definition & Purpose

OpsWorks organizes configuration management around application stacks and layers. It supports Chef and Puppet in managed or stack-based modes so teams can reuse existing cookbooks or modules while reducing operational overhead.

Common misconception: OpsWorks is not just an instance manager — it models application layers and lifecycle automation.
Concrete example
A cookbook that installs Nginx and deploys code can be attached to a web layer. When an instance enters Setup, the cookbook runs to install packages and register with a load balancer.
Terms to know
  • Stack: An application model containing layers and instances.
  • Layer: Logical grouping of instances by role.
  • Lifecycle event: A trigger like Setup or Deploy that runs recipes.
Key Takeaway

OpsWorks packages configuration management around application stacks and lifecycle events, and offers managed servers for Chef or Puppet to reduce operational load.
