Step-by-step plan
  1. Create stack: name, region, OS, service role.
  2. Define layers: WebServer and AppServer with security groups and scaling.
  3. Attach recipes: map cookbooks to Setup and Deploy events.
  4. Add AppSources: point to Git and choose revision.
  5. Add instances or set auto-scaling and test a deploy in dev.

  • What rollback or recovery steps are in your plan?
