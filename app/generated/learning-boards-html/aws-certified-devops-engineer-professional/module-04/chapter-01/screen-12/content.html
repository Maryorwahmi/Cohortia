Hands-on Activity

Verify Agent & Run Command

Follow these high-level steps exactly as written to validate SSM configuration and then execute the demo script.
  1. Launch an EC2 using Amazon Linux 2 and attach an IAM instance profile with AmazonSSMManagedInstanceCore.
  2. Do not open SSH in the security group; SSM manages the host outbound-only.
  3. Confirm the instance appears in Systems Manager > Managed instances.
  4. Run the AWS-RunShellScript command targeting the instance with the demo script below.
  5. Open the Command ID and check the Output tab for expected text and file listing.
Troubleshoot

If not appearing: verify the IAM role, verify the agent service is installed and running, and confirm outbound access to SSM endpoints or VPC endpoints for Systems Manager.

Demo script (paste into Run Command)
#!/bin/bash
echo "Hello from SSM Run Command on $(hostname)!" > /tmp/ssm_hello.txt
cat /tmp/ssm_hello.txt
ls -l /tmp/ssm_hello.txt
Expected output

Standard output should include the greeting line and the file listing. Command status should report Success for the target instance.

Key Takeaway

This activity proves the agent and role are functioning and that you can execute remote commands securely without SSH.
