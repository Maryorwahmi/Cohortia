Comparison

Run Command vs State Manager

Run Command
  • Ad-hoc execution
  • Immediate remediation or diagnostics
  • Per-instance output and status
State Manager
  • Declare desired state
  • Continuous enforcement
  • Prevents configuration drift
Misconception

Using Run Command as a repeated band-aid for drift is brittle. Use State Manager or configuration tools to maintain long-term consistency.

Scenario

Your team notices that a package on web servers sometimes gets updated manually, producing drift. Choose State Manager to declare the desired package version and schedule periodic enforcement, rather than repeatedly running a corrective script via Run Command.

Check your understanding

If a change should be permanent and automatically corrected when drift occurs, which tool do you use? (Answer: State Manager.)

Key Takeaway

Match Run Command to episodic tasks and State Manager to declarative, persistent configuration enforcement.
