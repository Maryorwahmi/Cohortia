Definition

Managed Instance

An instance running the SSM Agent and registered with Systems Manager. Appears in Managed Instances and is eligible for operations and inventory collection.

Inventory & use

SSM can gather package lists and configuration data to help you target operations and prove compliance across your fleet.

Practical checks
  • Confirm the instance appears under Systems Manager > Managed Instances after boot.
  • Ensure agent is installed and running on custom AMIs or on-premises servers.
  • Verify network routes or endpoints allow outbound SSM connectivity from private networks.
Example

An on-premises VM is turned into a managed instance after installing the SSM Agent and completing registration. It can then be targeted just like an EC2 instance for commands and state enforcement.
