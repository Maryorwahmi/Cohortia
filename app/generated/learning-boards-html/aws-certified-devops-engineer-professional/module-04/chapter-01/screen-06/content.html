Process Flow

Run Command steps

  1. Choose a command document such as AWS-RunShellScript.
  2. Provide the shell or PowerShell script to execute.
  3. Select target instances by tags or manually.
  4. Run with rate controls if needed and monitor output per instance.
Misconception check

Run Command is not an interactive shell. It executes provided commands and returns their output for inspection.

Common-mistake

Running untested commands at fleet scale without rate limits can produce widespread failures.

Concrete example
#!/bin/bash
echo "Hello from SSM Run Command on $(hostname)!" > /tmp/ssm_hello.txt
cat /tmp/ssm_hello.txt
ls -l /tmp/ssm_hello.txt
What to observe

Per-instance output includes printed lines and file listing. Command status shows Success or Failed.

Safety tip

Run in staging first, then apply rate controls and thresholds when scaling to production.

Key Takeaway

Use Run Command for repeatable, auditable, remote execution with structured outputs and status for each host.
