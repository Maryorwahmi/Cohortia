Module 4 › Chapter 4.1 › Key Concepts
AWS Systems Manager

A collection of capabilities to automate tasks, enforce state, and orchestrate workflows across managed hosts.

SSM Agent

Installed on instances, it creates an outbound encrypted channel for secure command execution and reporting.

Run Command & State Manager

Run Command for ad-hoc execution; State Manager to declare and continuously enforce desired state.

Summary Takeaway

Confirm agent presence and IAM role, choose the right SSM capability, and automate common runbooks to make operations safer and more repeatable.
