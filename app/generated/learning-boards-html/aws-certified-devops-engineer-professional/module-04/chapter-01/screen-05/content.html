Definition

SSM Agent

A process on managed instances that receives instructions from Systems Manager, executes them, and reports status back securely.

Outbound encrypted channel

No inbound ports required for management commands.

Status reporting

Agents return structured results and exit codes for central analysis.

Common mistake

Assuming the agent is installed and running on custom AMIs. Always confirm installation and service status before relying on SSM for management.

Key Takeaway

The agent is the bridge — without it, SSM cannot manage the instance. Verify agent presence and correct IAM role to enable management.

Agent checks and diagnostics
  • Confirm the agent service is running on the instance and set to start automatically.
  • Ensure the instance is visible in the Systems Manager > Managed instances list after boot.
  • Verify the IAM instance profile grants SSM permissions, such as AmazonSSMManagedInstanceCore or equivalent.
  • Check outbound network access to SSM endpoints if the instance is in a restricted subnet.
Example scenario

You launch an EC2 from a custom AMI and it does not appear in Managed instances. First check the IAM instance profile, then confirm the agent service is installed and running. If either is missing, the instance won't register and SSM commands will fail.
