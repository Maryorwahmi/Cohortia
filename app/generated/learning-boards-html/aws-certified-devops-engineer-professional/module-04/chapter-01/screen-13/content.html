Best Practice

Safety patterns for SSM

  • Test in staging and validate outputs before production runs.
  • Use rate controls and batch operations to limit blast radius.
  • Define error thresholds and automatic halting behavior.
  • Record outputs and integrate with CloudWatch and Config for audits.
Common mistakes

Running untested scripts at scale, missing instance profiles, and assuming the agent is present are recurring causes of failure. Avoid them with small tests and checks.

Pro tip

After a successful ad-hoc Run Command remediation, convert it into an Automation Document so the runbook becomes repeatable, auditable, and safer for future incidents.

Key Takeaway

Design workflows that limit impact, include verification steps, and convert manual fixes into automated documents to improve reliability and auditability.
