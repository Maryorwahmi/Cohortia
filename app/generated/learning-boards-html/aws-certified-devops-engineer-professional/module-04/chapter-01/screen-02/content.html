Learning Objectives

Bloom: Learn → Understand → Apply → Master

01
Explain SSM capabilities

Describe Run Command, State Manager, Automation Documents, and their roles in operational automation. You will explain how each capability reduces manual intervention and supports repeatable operations.

Venn: Capability → Automation → Compliance
VERIFIED COMPETENCY MILESTONE
02
Identify key components

Recognize the SSM Agent, managed instances, and IAM instance profiles and match each to its primary operational use case. This helps you choose correct architecture and permissions.

Mnemonic: Agent → Instance → Role
VERIFIED COMPETENCY MILESTONE
03
Understand the SSM Agent

Explain how the agent communicates securely to run commands and report status, and why this removes the need for direct SSH in many workflows.

Timeline: Install → Register → Report
VERIFIED COMPETENCY MILESTONE
04
Apply SSM in a lab

Complete the hands-on activity to verify an agent, attach the correct IAM profile, and execute a Run Command, confirming output and status.

Mnemonic: Launch → Verify → Run
VERIFIED COMPETENCY MILESTONE
