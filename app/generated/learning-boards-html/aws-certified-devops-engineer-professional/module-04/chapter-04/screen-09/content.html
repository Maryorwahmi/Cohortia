Configuration checklist
  1. Name the association (e.g. NginxInstallationAssociation).
  2. Select the InstallNginxLinux document.
  3. Choose targets: manual instance select for initial testing.
  4. Set schedule: cron or rate expression.
  5. Configure parameters and output (S3/CloudWatch).
Monitoring and verification
After creation, observe association status in State Manager. Check execution logs and the instance's SSM command output. Then verify the web server by visiting the instance public IP and confirming the Nginx welcome page.
Warning

Avoid deploying new associations fleet-wide without testing, as conflicting associations may cause disruption.
