Module 5 › Chapter 4.4 › Run Command
How it works
  • Choose a document (AWS-RunShellScript or AWS-RunPowerShellScript).
  • Provide command text and target instances by IDs, tags, or resource groups.
  • Optionally send output to S3 or CloudWatch Logs for auditing.
Misconception: Run Command equals configuration management. Use State Manager for desired state enforcement instead.
Example command
# Using AWS-RunShellScript to install htop on Amazon Linux
sudo yum install -y htop

# For Ubuntu:
sudo apt-get update -y
sudo apt-get install -y htop
Tip

Send command output to CloudWatch or S3 to retain evidence and debug failures.
