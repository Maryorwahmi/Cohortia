Example workflow (golden AMI)
  1. Stop the instance (aws:stopInstances).
  2. Create a snapshot and AMI (aws:createImage, aws:createSnapshot).
  3. Start the instance (aws:startInstances).
  4. Notify completion to an SNS topic or invoke a Lambda for post-processing.
Design Automation documents with parameters for resource IDs and explicit error handling so you can retry or roll back on failure.
Best practices
  • Parameterize resource identifiers and credentials.
  • Include retries and explicit error paths.
  • Emit notifications or logs for observability.
