What an association contains
  • Document to apply (predefined or custom).
  • Targets (instance IDs, tags, resource groups).
  • Schedule expression (cron or rate).
  • Parameters and output options (S3/CloudWatch).
Example: Nginx association
Name: NginxInstallationAssociation
Document: InstallNginxLinux
Schedule: cron(0 0 ? * * *) (daily) or rate(30 minutes) for testing
Common mistake

Deploying untested associations or overlapping associations that conflict. Test in isolation first.
