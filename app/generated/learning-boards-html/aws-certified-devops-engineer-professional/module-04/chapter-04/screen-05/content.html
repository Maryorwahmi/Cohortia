Module 5 › Chapter 4.4 › Instance Profile
Step-by-step
  1. Create IAM role for EC2 and attach AmazonSSMManagedInstanceCore.
  2. Name the role e.g. SSMManagedInstanceRole for clarity.
  3. Launch EC2 and select the instance profile during configuration.
  4. Optionally add fine-grained ssm:GetParameter permissions scoped to parameter ARNs.
Misconception: broad EC2 permissions help debugging. In fact, narrow permissions reduce blast radius and align with least-privilege.
Verification checks
SSM Console: instance appears as managed
Inside instance: agent logs show successful registration
Try a test Run Command to confirm permissions and connectivity
Key Takeaway

Attach AmazonSSMManagedInstanceCore and scope additional permissions to required Parameter Store paths only.
