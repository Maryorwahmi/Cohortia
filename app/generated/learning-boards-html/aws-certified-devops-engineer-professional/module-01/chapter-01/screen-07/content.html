Architecture

Service categories for a pipeline

Source & Artifact
Managed repositories and artifact stores to host code and build outputs.
Build & Test
Build services that execute reproducible builds and tests in isolated environments.
Orchestration
Pipeline services to sequence and gate stages from commit to deployment.
Compute & Observability

Choose the compute model that fits your deployment pattern — virtual machines for some workloads, containers for microservices, and serverless for event-driven functions. Observability collects logs, metrics, and traces to validate deployments.

Concrete example

A commit triggers a pipeline: build produces an image, tests run, then deploys to a container service. Monitoring captures metrics and sends alerts if health checks fail.

Common mistake

Relying on a single service to solve all stages. The right approach composes specialized services for clarity and reliability.
