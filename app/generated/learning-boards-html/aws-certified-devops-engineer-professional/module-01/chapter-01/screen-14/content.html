Module 1 › Chapter 1.1 › Exploring the AWS DevOps Service Landscape
Activity

Map services in the console

Identify key services under Developer Tools, Management & Governance, Compute, and Security. Note their console descriptions and roles in a pipeline.

Developer Tools

Find source, build, deploy, and pipeline orchestration services and note each description.

Management & Governance

Locate monitoring, logging, and configuration services and capture their purpose.

Sketch prompt

Draw a simple pipeline: Code repository → pipeline orchestrator → build → test → staging deploy. Annotate where monitoring and IaC would integrate.

Reflection

Choose one service you want to explore next and list one experiment you can run to learn it better.

Key Takeaway

Exploring the console and sketching a pipeline builds mental models that make later hands-on labs faster and more effective.
