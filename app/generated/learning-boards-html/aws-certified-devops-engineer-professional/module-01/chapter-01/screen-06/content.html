Module 1 › Chapter 1.1 › CI / CD
Definition

Continuous Integration and Continuous Delivery

CI runs frequent builds and tests after code merges. CD ensures those artifacts can be safely released, often via automated pipelines and staging environments.

Example pipeline

Commit → build → unit tests → integration tests → deploy to staging → manual or automated production release.

Misconception

CI/CD is not just automation; it requires test quality and deployment verification to be valuable.

Concrete scenario

A team uses a managed source repository that triggers a build service which produces an artifact. That artifact is automatically tested and then pushed to a staging environment where further checks run before a release decision.

Key Takeaway

CI/CD reduces friction and risk when you pair automation with good tests and release validation.
