Automation — Scope and Services

Three automation domains: CI/CD, infrastructure as code, and security/ops automation.

CI/CD Automation
CodePipeline orchestrates stages; CodeCommit, CodeBuild, and CodeDeploy provide source, build/test, and deployment functions.
Infrastructure Automation
CloudFormation and the CDK define repeatable stacks; Systems Manager automates operational tasks across instances.
Security Automation
AWS Config and Security Hub provide continuous posture checks and aggregated findings; Lambda can drive automated remediation.
Common mistake

Automating without clear rollback and measurement means you can deploy changes faster but still break production faster.

Process example
Trigger
Push to CodeCommit starts CodePipeline.
Build & Test
CodeBuild compiles, runs unit tests, and produces artifacts.
Deploy & Validate
CodeDeploy releases to EC2 and CloudWatch metrics validate health.
