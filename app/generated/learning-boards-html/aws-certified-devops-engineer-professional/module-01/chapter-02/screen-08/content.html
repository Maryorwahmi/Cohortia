Definition

Infrastructure as Code — CloudFormation and CDK

Model resources as code to enable version control, review, and repeatable provisioning.

Concrete example
A CloudFormation template in CodeCommit describes networking, EC2, and security groups. Changes to the template go through the pipeline so infrastructure updates are tracked and tested.
Key Takeaway

Treat templates as code: review, test, and validate changes before applying them to production.

Why it matters

IaC reduces configuration drift and enables consistent environments for development, test, and production. It supports auditability and rollback through version control.

Misconception
IaC is not a one-time shift; templates must be maintained, reviewed, and scanned for security issues like overly permissive roles.
Example template snippet

  "Resources": {
    "AppInstance": {
      "Type": "AWS::EC2::Instance",
      "Properties": {

      }
    }
  }
