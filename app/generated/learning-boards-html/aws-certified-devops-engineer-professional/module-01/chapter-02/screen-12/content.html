Module 1 › Chapter 1.2 › Measurement Tools
Comparison

CloudWatch, X-Ray, CloudTrail, Kinesis, OpenSearch

Understand each service's role and pair them for full observability.

CloudWatch
Metrics, logs, alarms, dashboards for operational health.
X-Ray
End-to-end tracing for distributed applications.
CloudTrail
Audit trail of API activity for security and compliance.
Kinesis & OpenSearch
High-volume streaming and searchable log indexing for analysis at scale.
Use case

To debug a sudden error spike: CloudWatch surfaces the spike, X-Ray finds slow RPCs, CloudTrail reveals recent config changes, and OpenSearch lets you search logs for correlated exceptions.

Key Takeaway

Combine metrics, traces, and logs to reduce mean time to detect and repair incidents.
