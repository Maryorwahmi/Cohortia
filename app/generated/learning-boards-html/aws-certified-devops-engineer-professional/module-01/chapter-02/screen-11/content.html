Measurement

Metrics, Logs, and Traces

Use a combination of tools to get a full operational picture and to validate changes.

CloudWatch
Collects metrics, monitors logs, and supports alarms and dashboards for operational health.
X-Ray
Provides end-to-end request traces helpful for debugging distributed applications.
CloudTrail and streaming
CloudTrail records API activity for auditing; Kinesis and OpenSearch support real-time log analysis at scale.
Key Takeaway

Measurement is essential for validating deployments and improving systems over time.

Scenario

A deployment increases latency. CloudWatch alarms trigger, X-Ray traces show a specific downstream service latency, and CloudTrail shows a recent configuration change to that service.

Misconception
Logging alone is not enough; without metrics and traces you cannot quickly validate user impact or trace requests end-to-end.
