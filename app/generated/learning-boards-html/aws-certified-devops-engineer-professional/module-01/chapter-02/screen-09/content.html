Definition

Security Automation and Least Privilege

Use continuous checks and automated responses while enforcing minimal permissions for each action.

Services involved
AWS Config for configuration checks, Security Hub for aggregated findings, Lambda for automated remediation, and CloudTrail for auditing.
Concrete example
Config flags a public security group; Security Hub records a finding and a Lambda function restricts the rule. CloudTrail records the remediation action for audit.
Warning

Avoid broad automation roles; design least-privilege IAM policies and require approval for destructive remediation.

Checklist
  • Ensure Config rules are in place for critical resource types.
  • Aggregate findings in Security Hub for centralized triage.
  • Give Lambda remediation roles only the permissions required for the specific fix.
  • Record all automated actions in CloudTrail for auditing.
