Activity

Design a Basic CI/CD Pipeline

Plan the pipeline stages and identify service roles without deploying resources.

1
Identify services
Source: CodeCommit. Build/Test: CodeBuild. Deploy: CodeDeploy. Orchestration: CodePipeline. Monitoring: CloudWatch.
2
Sketch the flow
Push to repo triggers pipeline → run build and tests → deploy on success → monitor metrics and logs.
3
Define triggers and feedback
Start on push or merge. Use CloudWatch alarms and X-Ray traces as feedback for validation and rollback decisions.
Security note
Ensure IAM roles for CodeBuild, CodeDeploy, and pipeline orchestration follow least privilege and that CloudFormation templates are reviewed for security issues.
Example mapping
  • Source: CodeCommit
  • Build: CodeBuild
  • Deploy: CodeDeploy to EC2
  • Orchestration: CodePipeline
  • Monitoring: CloudWatch
Key Takeaway

When planning, define triggers, validation metrics, and least-privilege roles before writing templates or automation.
