Definition
Core Git Commands
A terminal-first sequence to create and record local changes.
git init — create a new local repository that tracks your project history.
git clone <url> — copy a remote repository so you can work locally.
git add — stage changes for the next commit; stage intentionally.
git commit -m "message" — record staged changes in local history with a message.
Common misconception: committing pushes to the remote. It does not — you must run git push to share commits.
Code example
# Example Git workflow
git clone https://git-codecommit.us-east-1.amazonaws.com/v1/repos/my-app
cd my-app
echo "Hello, DevOps!" > README.md
git add README.md
git commit -m "Initial commit with README"
Verify: run git status to see staged and unstaged files.
Pro tip: write commit messages that explain why the change was made.
