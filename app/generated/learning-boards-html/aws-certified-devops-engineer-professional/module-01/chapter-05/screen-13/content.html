Hands-on Activity
Terminal walkthrough
Follow these commands in your terminal to complete the activity and verify in the CodeCommit console.
# Configure credential helper (if using HTTPS with AWS CLI)
git config --global credential.helper '!aws codecommit credential-helper $@'
git config --global credential.UseHttpPath true

# Clone the repository
# git clone https://git-codecommit.us-east-1.amazonaws.com/v1/repos/my-devops-app
# cd my-devops-app

echo "This is my first file in CodeCommit." > README.md
git add README.md
git commit -m "Added initial README.md file"
git push origin master

# Create and push a feature branch
git branch feature/add-example
git checkout feature/add-example
echo "Example code" > example.txt
git add example.txt
git commit -m "Add example file"
git push origin feature/add-example
Verification & checks
  • After push, open the CodeCommit console and confirm the README is visible in the repository's code view.
  • Confirm the feature branch shows up under branches and the commit history reflects your messages.
  • If push fails, check IAM permissions and that the credential helper or SSH key is configured correctly.
Safety reminder: do not commit secrets. Use environment variables or AWS Secrets Manager and remove secrets from history if they were accidentally committed.
