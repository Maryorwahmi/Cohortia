Definition
Branching
Create isolated lines of development for features, fixes, or experiments.
git branch <name> — create a new branch pointer at the current commit.
git checkout <name> — switch to the named branch. Newer Git supports git switch as well.
git merge <name> — merge commits from another branch into the current branch.
Misconception: branches are heavy. In Git they are cheap and intended for frequent use to support reviewable changes.
Concrete example
Commands to add a feature branch and push it to CodeCommit are shown below. Short branches keep review loops tight.
# Create and switch to a feature branch
git branch feature/new-dashboard
git checkout feature/new-dashboard
# After commits
git push origin feature/new-dashboard
Pro tip: push branches early so CI can run and reviewers can see work in progress.
Check: keep branches focused on a single concern to simplify reviews and reverts.
