Authentication Methods
Pick an authentication method that fits your team's security and automation needs.
HTTPS Git credentials — IAM-generated username/password pair for Git access.
SSH keys — upload public key to IAM and use private key locally with SSH agent.
AWS CLI credential helper — uses your AWS CLI profile and temporary credentials to authenticate Git operations.
Configuring the AWS credential helper
# Configure Git to use the AWS credential helper
git config --global credential.helper '!aws codecommit credential-helper $@'
git config --global credential.UseHttpPath true
This configuration allows you to clone CodeCommit repositories over HTTPS while the helper uses your AWS CLI credentials to perform authentication automatically.
Misconception: credential helper stores long-lived Git passwords. It leverages existing CLI credentials and temporary tokens for better rotation.
Pro tip: choose a method that aligns with your CI agents and automation so scripts can authenticate without manual steps.
