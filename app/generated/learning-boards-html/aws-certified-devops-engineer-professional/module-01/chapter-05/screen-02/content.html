Learning Objectives
Learn, Understand, Apply, Master — practical milestones for version control and CodeCommit.
01
Explain Version Control
Describe what a version control system records and why it enables parallel work, history, and safe rollbacks. This objective is essential for team collaboration and incident recovery.
VERIFIED COMPETENCY MILESTONE
02
Perform Core Git Commands
Use clone, add, commit, push, and pull from the command line to maintain local and remote history. Practice makes the flow habitual and error-free.
VERIFIED COMPETENCY MILESTONE
03
Create & Manage CodeCommit
Create repositories in CodeCommit and understand required permissions and the HTTPS URL you will clone from. This enables secure hosting inside AWS.
VERIFIED COMPETENCY MILESTONE
04
Branching & Best Practices
Adopt branching strategies and avoid common mistakes like pushing secrets or skipping code review. Branching reduces risk and enables parallel feature development.
VERIFIED COMPETENCY MILESTONE
