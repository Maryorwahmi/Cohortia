Process Flow
Push and Pull
Push uploads your commits; pull fetches and merges remote changes into your branch.
git push — upload local commits to the remote branch so collaborators can access them.
git pull — download remote commits and merge them locally; handle conflicts if they appear.
Conflict handling — when pull results in conflicts, open the files, resolve changes, stage, and commit the resolution.
Common mistake: not pulling before starting new work. Always synchronize first to reduce merge conflicts.
Example
# Push example
git push origin master

# Pull example
git pull origin master
Team practice: protect main/master; require pull requests and automated tests before merging.
Verification: after push, confirm the commit appears in the CodeCommit console under the repository's Code view.
