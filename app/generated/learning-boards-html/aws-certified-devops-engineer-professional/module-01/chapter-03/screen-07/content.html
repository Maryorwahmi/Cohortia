Comparison

Mutable vs Immutable

Mutable changes modify running instances and can be faster for emergency fixes but increase drift. Immutable deployments replace components, improving consistency and rollback but can have higher deployment overhead.

Preferred services
CloudFormation for reproducible stacks; Systems Manager for automation and parameters; Secrets Manager for secure secrets handling.
Pitfall
Avoid storing secrets in code or granting broad IAM policies to speed development—the exam penalizes insecure but convenient choices.
Concrete example

Scenario: multiple instances need a config update with auditability. Best approach: update a CloudFormation template and roll the change as a stack update, or use Systems Manager Automation to run a controlled, auditable update across instances.

Decision checklist
Is the change repeatable, auditable, and safe to automate? If yes, choose IaC or Systems Manager. If not, identify safeguards and rollback plans.
Key Takeaway

Prefer declarative IaC and managed configuration; avoid manual changes and insecure secret handling on the exam.
