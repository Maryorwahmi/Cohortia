Module 1 › Chapter 1.3 › Exam Blueprint and Domain Weightings
Process

Map domains → services → study time

Use the domain percentages to allocate practical lab and question practice time. The goal is more hands-on work where the exam emphasizes it.

SDLC Automation — 22%
Focus: CI/CD pipelines, deployments (blue/green, canary), CodeBuild, CodePipeline, CodeDeploy.
Configuration & IaC — 17%
Focus: CloudFormation, Systems Manager, configuration management, secrets management.
Monitoring & Logging — 15%
Focus: CloudWatch, CloudTrail, X-Ray, log aggregation and analysis.
Incident & Event Response — 18%
Focus: Lambda, SNS, SQS, Config, Systems Manager automation.
HA, Fault Tolerance & DR — 14%
Focus: Multi-AZ, Auto Scaling, ALB/NLB, Route 53, RTO/RPO planning.
Security & Compliance — 14%
Focus: IAM, KMS, WAF, Shield, Security Hub, least privilege.
Study allocation
Example allocation for a 10-hour study week: SDLC Automation ~2.2 hours, Incident Response ~1.8 hours, Configuration & IaC ~1.7 hours, Monitoring ~1.5 hours, HA/DR ~1.4 hours, Security ~1.4 hours. Round to practical lab increments.
Practical step
Build one pipeline that runs code quality, unit tests, and a blue/green deploy. Record the time it takes and the failure modes you need to handle.
Key Takeaway

Weightings guide where hands-on practice will most improve your exam score; align labs to the highest percentages.
