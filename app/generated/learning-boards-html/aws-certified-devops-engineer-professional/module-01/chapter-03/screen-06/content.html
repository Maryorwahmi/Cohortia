Architecture

Pipeline anatomy

A robust CI/CD pipeline includes source control triggers, build and test stages, artifact storage, deployment steps, validation, and rollback mechanisms. Know how each component leads to safer releases.

Key services
CodeCommit, CodeBuild, CodePipeline, CodeDeploy — use them to implement build and deployment automation and progressive rollout patterns.
Deployment patterns
Blue/green, canary, and immutable deployments each trade off speed, complexity, and rollback simplicity. Know when to choose each.
Concrete example

Scenario: a microservices app on ECS requires minimal downtime. Solution: pipeline runs tests in CodeBuild, pushes images to a registry, deploys new task sets using CodeDeploy with an ALB-driven blue/green deployment, shifts traffic gradually after health checks, and records metrics for rollback decisions.

Common mistake
Assuming a single deployment step is sufficient without automated validation and rollback paths.
Pro tip
Automate tests and validation early in the pipeline so failed changes never reach production traffic shifts.
Key Takeaway

Practice full pipelines including validation and rollback. In questions, prioritize options that reduce blast radius and allow safe verification.
