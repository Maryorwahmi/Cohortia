Module 1 › Chapter 1.3 › Security & Compliance
Definition

Least privilege and encryption

Security scenarios require careful permission scoping, secure secret handling, and encryption. The exam prefers solutions that balance security and operations without introducing broad access.

Key services
IAM, KMS, Secrets Manager, WAF, Shield, Security Hub — use managed controls and audit logs where possible.
Pitfall
Avoid granting broad admin permissions for speed; the exam tends to penalize insecure convenience choices.
Concrete example

Requirement: pipeline needs to deploy and read secrets. Best practice: pipeline assumes an IAM role with narrowly scoped permissions and uses Secrets Manager with KMS-managed keys for encryption and rotation, plus CloudTrail logging for auditing.

Key Takeaway

Choose secure, managed options and verify auditability; least privilege is often the correct exam choice.
