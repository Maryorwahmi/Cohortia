Module 1 › Chapter 1.3 › Incident & Event Response
Process

Detection → Notify → Remediate

An event flow typically detects a problem, notifies stakeholders, gathers forensic data, and executes remediation steps where safe. Each step should include validation and logging.

Services
Lambda for automation, SNS/SQS for pub/sub and queuing, Systems Manager for runbooks, and Config for drift detection.
Design goal
Reduce manual steps while keeping remediations auditable and reversible.
Scenario example

If error rate spikes, CloudWatch alarm triggers SNS, which pages on-call and invokes a Lambda to collect logs. If safe, a Systems Manager automation restores a healthy instance or rolls back a recent deployment.

Common pitfall
Automating destructive fixes without verification or rollback increases risk; prefer safe, reversible automations.
Key Takeaway

Tie detection to controlled automations and ensure runbooks and audit trails exist for every automated remediation path.
