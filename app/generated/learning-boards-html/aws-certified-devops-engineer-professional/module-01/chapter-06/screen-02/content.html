Learning Objectives
Learn the vocabulary and practical skills to design CI/CD pipelines on AWS.
Bloom: Learn → Understand → Apply → Master
01
Define CI and CD
Explain how CI automates builds and tests, and how CD extends this to deployable artifacts with optional approval. Verified competency milestone: conceptual definition and example.
02
Identify pipeline stages
Recognize source, build, test, deploy, and approval stages and state the purpose of each. Verified competency milestone: stage mapping exercise.
03
Map AWS services
Choose CodeCommit, CodeBuild, CodeDeploy or CloudFormation per stage and explain why. Verified competency milestone: service selection checklist.
04
Differentiate Delivery vs Deployment
Decide when to use manual approvals vs full automation and explain trade-offs. Verified competency milestone: risk and testing rubric.
