Module 2 › Chapter 1.6 › Delivery vs Deployment
Continuous Delivery
Automated pipelines produce deployable artifacts, with a manual approval before production.
When to use
Business validation, compliance, or when you want a human safety net.
Example
Deploy to staging automatically, then require approval before production deployment.
Continuous Deployment
Every change that passes automated tests is deployed to production automatically, with no manual gate.
When to use
High trust in tests and monitoring, fast feedback from production, low tolerance for manual delays.
Pitfall
Insufficient tests can let bugs reach production quickly. Add more tests before enabling full automation.
Practical question: If your team lacks end-to-end automated tests, which delivery model should you pick and why?
