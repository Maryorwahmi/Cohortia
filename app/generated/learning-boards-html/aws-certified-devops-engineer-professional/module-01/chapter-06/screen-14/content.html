Module 2 › Chapter 1.6 › Key Concepts
Continuous Integration
Automated builds and tests on every merge to keep the codebase healthy.
Continuous Delivery
Ensures deployable artifacts and typically includes a manual approval before production.
Continuous Deployment
Automatically deploys every tested change to production. Requires strong tests and monitoring.
Summary

Pick a delivery model that matches your test maturity and risk tolerance. Iterate toward more automation as tests and monitoring improve.
