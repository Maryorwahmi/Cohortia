Module 2 › Chapter 1.6 › Build Stage
Build responsibilities
Compile, run unit tests, and create the artifact that downstream stages will consume.
Reproducibility
Pin dependencies and record build metadata so artifacts can be traced to commits.
Test separation
Keep fast unit tests in build. Move slow, end-to-end tests to the test stage.
Example build spec (conceptual)
# install
pip install -r requirements.txt
# run unit tests
pytest tests/unit
# package for SAM
sam package --template-file template.yaml --s3-bucket artifact-bucket --output-template-file packaged.yaml
# upload artifact: packaged.yaml and code bundle to S3
Key Takeaway

Design builds to be fast and reproducible. Use separate test stages for slow checks so CI stays responsive.
