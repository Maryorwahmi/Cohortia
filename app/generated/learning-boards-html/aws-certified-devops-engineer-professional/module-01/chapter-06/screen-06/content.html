Pipeline Stage Sequence
A clear, single-responsibility flow keeps feedback fast and artifacts reliable.
Source
Detect commits and trigger the pipeline.
Example: CodeCommit or GitHub webhook.
Build
Compile, run unit tests, create artifacts.
Example: CodeBuild packaging a SAM template.
Test
Integration and performance tests validate behavior.
Run in a dedicated environment post-build.
Deploy
Move artifacts to staging or production.
Example: CodeDeploy or CloudFormation apply.
Approval
Optional manual gate for production releases.
Used when human validation or compliance is required.
Design tip
Keep long-running checks out of the build stage to preserve CI speed.
Security note
Use least-privilege IAM roles for each pipeline actor and validate artifacts before deploy.
Example flow
Commit → CodeBuild package → Integration tests → Manual approval → CloudFormation deploy.
