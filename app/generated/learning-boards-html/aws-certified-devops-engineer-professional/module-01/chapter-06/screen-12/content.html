Sketch a Serverless CodePipeline
Use this checklist to document your pipeline design before building it.
Stages
  • Source (CodeCommit)
  • Build (CodeBuild: unit tests + SAM package)
  • Test (deploy package, integration tests)
  • Deploy Staging (CloudFormation)
  • Approval (optional)
  • Deploy Production (CloudFormation)
Artifacts
Packaged SAM template and zipped Lambda code stored in an S3 bucket or container images with tags. Name the bucket in your sketch.
Rollback & Safety
Use CloudFormation change sets, Lambda aliases or canary deployments, and least-privilege IAM roles. Plan a rollback trigger on health check failures.
Example flow (guidance)
CodeCommit → CodeBuild package → deploy to test env → integration tests → manual approval → CloudFormation production deploy.
