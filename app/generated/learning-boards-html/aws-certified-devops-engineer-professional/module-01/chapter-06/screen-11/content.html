Module 2 › Chapter 1.6 › CodePipeline Overview
CodePipeline orchestrates specialized services
Think of CodePipeline as the conductor that tells each service when to run and which artifact to use.
Source
CodeCommit, GitHub
Build
CodeBuild compiles and packages
Test
CodeBuild or custom actions run tests
Deploy
CodeDeploy or CloudFormation apply changes
Notify / Approve
SNS notifications and manual approval actions
Example flow
CodeCommit push → CodeBuild package → integration tests → manual approval → CloudFormation deploy. SNS informs stakeholders on status changes.
