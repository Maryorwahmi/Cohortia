Module 2 › Chapter 1.6 › Source & Artifacts
Source triggers
Sources can be repositories or S3. A detected change starts the pipeline flow.
Common sources
CodeCommit, GitHub, Bitbucket, or S3 for prebuilt artifacts.
Concrete example
A push to CodeCommit on main triggers the pipeline to fetch source and start build.
Artifacts
Artifacts are immutable packages produced by build and consumed by later stages.
Serverless artifact
A SAM or CloudFormation package bundling Lambda code and templates.
Container artifact
A Docker image pushed to a registry and referenced by tag.
Key Takeaway

Explicit, immutable artifacts make pipelines reliable. Name the artifact format and location as part of your design.
