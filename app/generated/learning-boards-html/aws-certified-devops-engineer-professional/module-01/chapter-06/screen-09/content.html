Types of tests and where to run them
Select tests by scope and runtime cost, and place them accordingly in the pipeline.
Unit Tests
Fast, run in build, verify small code units.
Integration Tests
Slower, run in test stage against deployed artifacts to validate interactions.
Performance & Security
Performance tests and deep security scans often run in dedicated test environments or nightly runs.
Common pitfall
Running heavy integration suites on every push slows development. Use selective or scheduled runs where appropriate.
Example
Deploy SAM package to a staging environment and run end-to-end API tests as part of the test stage.
