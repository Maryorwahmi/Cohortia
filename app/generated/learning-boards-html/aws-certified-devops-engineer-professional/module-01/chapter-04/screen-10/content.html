Module 1 › Chapter 1.4 › Development environment
AWS Cloud9
Browser IDE pre-configured with AWS CLI and SDKs. Great for collaborative labs and quick starts.
Use for: quick cloud demos, shared workspaces, or when you want no local setup.
Local IDEs (VS Code)
Offer rich extension ecosystems and local debugging. Combine with AWS Toolkits for cloud integration.
Checklist
  • Install Git and configure user.name/user.email
  • Install AWS CLI and authenticate with a secure profile
  • Enable necessary language extensions (Python, Node.js, Java)
Key Takeaway

Choose Cloud9 for speed and shared access; choose local IDEs for deeper tools and local debugging, but secure credentials in both.
