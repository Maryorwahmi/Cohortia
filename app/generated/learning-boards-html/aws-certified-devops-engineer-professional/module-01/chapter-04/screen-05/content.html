Module 1 › Chapter 1.4 › IAM constructs
Definitions
IAM User
Represents a person or application with long-lived credentials for the console or CLI.
Group
A collection of users that share the same policies for easier management.
Role
An assumable identity that issues temporary credentials, ideal for services and cross-account access.
Example
A backup EC2 instance needs read access to a single S3 bucket. Create an IAM role with a policy granting s3:GetObject on that bucket only, attach it to the EC2 instance, and avoid storing keys on disk.
Common misconception
Applying AdministratorAccess to many users is easier but dramatically increases risk. Prefer small, focused policies that are auditable.
Key Takeaway

Use roles for services, groups to manage users, and policies scoped to exact resources and actions.
