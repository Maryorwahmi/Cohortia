Module 1 › Chapter 1.4 › Enable MFA
Step-by-step
1. Register root MFA
Use a hardware or virtual MFA and store recovery safely.
2. Create admin IAM user
Grant minimal required privileges and enable MFA on the user.
3. Document recovery
Record device owners and recovery steps in a secure location.
Why it matters
MFA prevents attackers who have passwords from gaining full access, adding an extra layer before account configuration and billing actions can be performed.
Example
An admin's password leak is limited by MFA. Even with the password, the attacker cannot log in without the second factor.
Common mistake

Relying on passwords alone or storing recovery codes in an unsecured location.

Key Takeaway

Enable MFA for root and admins; document recovery, and use roles for automation.
