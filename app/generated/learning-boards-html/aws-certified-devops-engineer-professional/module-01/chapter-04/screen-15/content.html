Module 1 › Chapter 1.4 › Key Concepts
IAM User
Represents a person or application that interacts with AWS.
Root Account
The original account identity with unrestricted access; never for daily use.
Multi-Factor Authentication (MFA)
Requires an additional verification factor to strengthen identity security.
Summary
These identity controls are the foundation for secure automation: create dedicated users, reserve root, and enable MFA everywhere high privilege exists.
