What is a profile?
A profile is a named set of credentials and configuration stored by the AWS CLI. It makes switching between accounts or roles simple and repeatable.
Example
aws configure --profile devops-cli-profile
aws s3 ls --profile devops-cli-profile
Security tips
  • Set file permissions on ~/.aws/credentials so only you can read it.
  • Avoid committing credentials to git or copying them into logs.
  • Prefer roles for compute-based automation.
Key Takeaway

Profiles let you manage multiple accounts cleanly; protect the credentials file and prefer roles for compute resources.
