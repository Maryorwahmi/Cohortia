Install & Verify
Use the official platform installer for CLI v2 or your package manager. Verify installation then configure credentials securely with profiles.
# Example: verify and configure (visual only)
aws --version

# Configure a named profile
aws configure --profile devops-cli-profile
AWS Access Key ID [None]: AKIAEXAMPLEDEV
AWS Secret Access Key [None]: EXAMPLESECRETKEYDEV
Default region name [None]: us-east-1
Default output format [None]: json

# Test listing buckets
aws s3 ls --profile devops-cli-profile
Security note
Do not hardcode credentials. Use the credentials file with proper file permissions, environment variables for ephemeral sessions, or IAM roles for compute resources.
Key Takeaway

Install CLI v2, configure profiles, and verify access with simple commands before scripting pipelines.
