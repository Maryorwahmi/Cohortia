05 Configure IDE or Cloud9

Choose Cloud9 for browser-based convenience or VS Code locally with AWS extensions. Ensure Git is installed and credentials are configured for commits.

06 Manage AWS service limits

Review Service Quotas regularly and request increases for soft limits before heavy provisioning or CI workloads to avoid pipeline failures.

VERIFIED COMPETENCY MILESTONE
07 Create roles for services

Use IAM roles for EC2, Lambda, and other services so they receive temporary, automatically rotated credentials instead of embedded keys.

VERIFIED COMPETENCY MILESTONE
08 Credential hygiene & cleanup

Rotate keys, delete or restrict test users, and remove AdministratorAccess when learning tasks are complete to reduce long-term exposure.
