Module 1 › Chapter 1.4 › Credentials comparison
Hardcoded keys
Fast but insecure. Keys can be checked into repositories and are long-lived unless rotated manually.
Environment variables
Good for ephemeral sessions but can leak in process listings or logs. Manage lifecycle and scope carefully.
IAM Roles
Best practice for compute. Roles grant temporary credentials, rotated automatically and scoped to needed permissions.
Example
Attach an S3-read-only role to a reporting EC2 instance instead of baking keys into its user data script.
Key Takeaway

Use roles for compute and avoid hardcoded keys; use env vars only for short-lived sessions with careful handling.
