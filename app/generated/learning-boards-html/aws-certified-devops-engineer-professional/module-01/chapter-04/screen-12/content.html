Module 1 › Chapter 1.4 › Activity: IAM user & CLI
Part 1 — Create IAM user
  1. Log in as administrative IAM user.
  2. IAM → Users → Add user: name devops-cli-user, programmatic access.
  3. Attach AdministratorAccess for the lab, then Create user and download the CSV.
Part 2 — Configure CLI
Open your terminal and run:
aws configure --profile devops-cli-profile
# Enter the Access Key ID and Secret Access Key from the CSV
# Set default region and output format
Test & Cleanup
Run aws s3 ls --profile devops-cli-profile to confirm. After the lab, delete the user or remove AdministratorAccess and apply a narrower policy.
Key Takeaway

Practice safely: create dedicated users for learning, test profiles, then reduce permissions or delete the user to prevent lingering risk.
