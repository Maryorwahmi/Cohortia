Secure & organized account

Create a dedicated admin IAM user, protect the root account with MFA, and keep billing and operational access separated. This reduces blast radius and supports audits.

02
IAM users, groups & roles

Assign permissions by role where possible and place users in groups for consistent policy assignment. Use roles for services that need temporary credentials.

VERIFIED COMPETENCY MILESTONE
03
Install & configure AWS CLI

Enable reproducible CLI usage with named profiles and region/output defaults so scripts run the same way on different machines.

VERIFIED COMPETENCY MILESTONE
04
Protect credentials & use profiles

Store credentials securely in the AWS credentials file or use roles and environment variables. Avoid committing keys to version control.
