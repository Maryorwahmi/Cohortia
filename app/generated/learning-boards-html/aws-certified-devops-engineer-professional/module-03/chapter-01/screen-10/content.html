Module 3 › Chapter 3.1 › Common Pitfalls

Frequent errors and fixes

YAML syntax
Use consistent indentation and validate templates before deploying to avoid parsing errors.
Missing CAPABILITY_IAM
Add the capability flag when your template creates IAM resources to avoid deploy failures.
Ref vs GetAtt
Use Ref for default identifiers and GetAtt for attributes like ARNs and IPs.
Dependency ordering
When CloudFormation cannot infer order, use DependsOn to guarantee sequencing.
Insufficient permissions
Ensure the deploy role has permissions to create, update, and delete all resource types in the template.
Rollback & events
Use stack events to find the failing resource. CloudFormation may roll back automatically; review events for the root cause.
Quick checklist

Lint and validate templates, include capability flags when needed, confirm deployer permissions, and monitor stack events to speed troubleshooting.
