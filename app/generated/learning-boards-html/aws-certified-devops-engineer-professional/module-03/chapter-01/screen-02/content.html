Learning Objectives

Build skill with templates, deployment, and troubleshooting
Bloom: Learn → Understand → Apply → Master
01
Explain IaC principles
Describe how versioned templates reduce manual configuration and enable automated, repeatable environments. Verified competency milestone: recognize IaC benefits in a deployment scenario.
Mnemonic: think of infrastructure as code commits in your repo
02
Identify template components
Explain Resources, Parameters, Outputs and intrinsic functions like reference and get attribute. Verified competency milestone: map each section to its role in a template.
Mnemonic: P-R-O — Parameters, Resources, Outputs
03
Author and deploy YAML templates
Create a simple S3 bucket template and deploy it with the console or aws cloudformation deploy for pipeline automation. Verified competency milestone: deploy and view stack events.
Mnemonic: write, validate, deploy
04
Troubleshoot common errors
Recognize YAML syntax problems, missing IAM capabilities, and dependency errors; use console events and CLI describe commands to diagnose. Verified competency milestone: identify and fix a sample error.
Mnemonic: Lint before deploy
