Module 3 › Chapter 3.1 › Deploy Process
Console Deployment
  1. Open CloudFormation and choose Create stack.
  2. Upload template, enter a stack name, and set parameters.
  3. Watch stack events to verify resource creation and resolve errors.
Console is useful for learning and troubleshooting because you get a visual events timeline and resource status updates.
CLI Deployment
aws cloudformation deploy \
  --template-file my-s3-bucket-template.yaml \
  --stack-name MyDevOpsS3BucketStack \
  --parameter-overrides BucketName=my-unique-devops-bucket-12345 \
  --capabilities CAPABILITY_IAM
The deploy command streamlines uploads and makes the process pipeline-friendly. Include capability flags when creating IAM entities.
Monitoring and events
Use describe-stack-events and the console event view to trace which resource failed and why. Events surface errors like permission denied or quota limits.
Common error
Forgetting CAPABILITY_IAM when your template creates IAM roles leads to an access denied style failure. Add the flag to acknowledge IAM changes during deploy.
Key Takeaway

Choose the console for visibility and the CLI for automation. Monitor events and validate templates before deploy.
