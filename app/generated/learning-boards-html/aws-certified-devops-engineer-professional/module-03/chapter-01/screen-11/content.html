Module 3 › Chapter 3.1 › Web Server Template
Starter template architecture
Key elements: parameters for user input, a security group for HTTP/SSH, an IAM role and instance profile for S3 read-only access, and an EC2 instance with UserData to install Apache.
# Parameters include KeyPairName, InstanceType, AMIId
# Resources include WebServerSecurityGroup, WebServerIAMRole, WebServerInstanceProfile, WebServerInstance
# UserData installs httpd and writes a simple index.html
# Output returns the instance public IP via !GetAtt WebServerInstance.PublicIp
Security note
Allowing SSH from anywhere is fine for a lab but not production. Use restricted source ranges and bastion hosts for real deployments.
Concrete step
After deployment, open the Public IP in a browser to verify Apache is serving the sample page created by UserData.
Why it matters

This starter demonstrates end-to-end IaC: parameterized templates, resource linking, instance boot configuration, and retrieving outputs for verification.
