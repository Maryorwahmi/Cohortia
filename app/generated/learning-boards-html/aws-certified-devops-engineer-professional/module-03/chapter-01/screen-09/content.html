Module 3 › Chapter 3.1 › CLI Deploy
Command breakdown
aws cloudformation deploy \
  --template-file webserver-template.yaml \
  --stack-name MyDevOpsWebServerStack \
  --parameter-overrides KeyPairName=YOUR_KEY_PAIR_NAME AMIId=YOUR_AMI_ID \
  --capabilities CAPABILITY_IAM
Parameter overrides inject values at runtime. Capabilities flags are explicit acknowledgements for IAM entities to protect against accidental privilege creation.
Validation & pipeline tips
  • Run aws cloudformation validate-template to check structure before deploy.
  • Lint YAML and use template-specific linters for resource schema checks.
  • Stage deploys in non-prod accounts and capture Outputs for downstream steps.
Misconception
The deploy command does not remove the need for careful permissions and validation. It automates operations but requires correct flags and parameter handling.
