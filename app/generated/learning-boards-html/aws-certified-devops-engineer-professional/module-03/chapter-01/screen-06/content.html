Module 3 › Chapter 3.1 › Template Anatomy

Top-level sections

Parameters: Define user-supplied values for reuse and customization.
Resources: Declare the AWS resources to create, with logical IDs and properties.
Outputs: Expose values such as names, ARNs, or IPs after stack creation.
Mappings, Conditions, Metadata: Optional sections for environment-specific behavior and documentation.
Intrinsic functions
Use Ref, GetAtt, and Sub to connect template values. Ref returns a parameter or resource reference; GetAtt returns a named attribute; Sub interpolates variables into strings.
Concrete examples
Parameter: InstanceType with allowed values. Resource: MyS3Bucket type AWS::S3::Bucket with properties. Output: S3BucketName using Ref to return the bucket name. Intrinsic: !GetAtt MyS3Bucket.Arn for the bucket ARN.
AWSTemplateFormatVersion: '2010-09-09'
Parameters:
  BucketName:
    Type: String
Resources:
  MyS3Bucket:
    Type: AWS::S3::Bucket
    Properties:
      BucketName: !Ref BucketName
Outputs:
  S3BucketName:
    Value: !Ref MyS3Bucket
  S3BucketARN:
    Value: !GetAtt MyS3Bucket.Arn
Misconception
Do not assume Ref and GetAtt are interchangeable. Use GetAtt for specific attributes such as ARNs or IP addresses.
