Practical Skills to Practice

Complete tasks that demonstrate authoring, deployment, and safe deletion of CloudFormation stacks.

Task
Author a YAML template
Create Resources, Parameters, and Outputs. Verify with a linter and version control. Milestone: template stored in repo and validated.
Task
Deploy via console and CLI
Use the console to watch stack events. Use aws cloudformation deploy in a pipeline. Milestone: stack reaches CREATE_COMPLETE.
Task
Build a web server stack
Include EC2, Security Group, IAM role, and UserData for Apache. Milestone: verify Apache on the public IP.
Task
Safely delete stacks
Use the CLI to delete stacks and confirm resources are removed. Milestone: no orphaned resources remain.
