Step-by-step timeline

  1. Create webserver-template.yaml and define parameters.
  2. Add Security Group for HTTP and SSH (lab only — tighten for production).
  3. Create IAM Role and Instance Profile with S3 read-only access.
  4. Add EC2 Instance with references to Security Group and Instance Profile and a UserData bootstrap.
  5. Declare an Output for the public IP.
  6. Run aws cloudformation validate-template and lint YAML.
  7. Deploy with aws cloudformation deploy and parameter-overrides; include capability flags for IAM.
  8. Monitor stack events until CREATE_COMPLETE and capture Outputs.
  9. Verify Apache through the public IP, then delete the stack when finished.
Verify
Use describe-stacks to retrieve Outputs or view the console Outputs tab to copy the Public IP.
Cleanup
Run aws cloudformation delete-stack with your stack name to remove resources and avoid costs.
Safety tip

Confirm the resources listed in the stack match your expectations before deleting to avoid accidental data loss.
