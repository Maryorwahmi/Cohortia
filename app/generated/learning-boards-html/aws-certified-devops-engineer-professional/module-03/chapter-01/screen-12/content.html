IAM Role & Instance Profile
Define a Role that EC2 can assume and attach a managed policy for needed permissions. Create an InstanceProfile resource that lists the Role and reference that profile from the EC2 instance so the instance gets the role at launch.
WebServerIAMRole:
  Type: AWS::IAM::Role
  Properties:
    AssumeRolePolicyDocument: ...
    ManagedPolicyArns:
      - arn:aws:iam::aws:policy/AmazonS3ReadOnlyAccess

WebServerInstanceProfile:
  Type: AWS::IAM::InstanceProfile
  Properties:
    Roles: - !Ref WebServerIAMRole
UserData example (concept)
The UserData script installs and starts Apache, then writes a confirmation HTML file. CloudFormation wraps it with Fn::Base64 to provide correct encoding.
Troubleshooting tips
If the web server doesn't start, check the instance system logs and verify UserData executed successfully. Confirm the instance profile is attached for expected permissions to access S3.
Key Takeaway

Instance permissions and bootstrapping are separate concerns; ensure the instance profile is referenced and UserData is validated for successful boots.
