Module 3 › Chapter 3.3 › Key Concepts
Multi-tier Architecture
Split infrastructure into Networking, Application, and Data stacks for reuse and ownership.
Cross-Stack Reference
Export outputs and import them with Fn::ImportValue; watch region scope and deletion order.
Custom Resource
Invoke a Lambda with ServiceToken to perform non-native actions and report status back to CloudFormation.
StackSets (Summary)
Use StackSets to deploy a single template to many accounts and regions. Configure admin and execution roles, permission model, and auto-deployment for large-scale rollouts.
Final Takeaway

Plan modular stacks and export names carefully, extend with custom resources only when necessary, and automate multi-account deployments with StackSets while testing lifecycle and rollback paths.
