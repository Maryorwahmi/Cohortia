Module 3 › Chapter 3.3 › Custom Resources
How it works
  • Define a Custom resource with a ServiceToken that is the Lambda ARN.
  • CloudFormation invokes Lambda on Create, Update, Delete with event details.
  • Lambda performs operations and sends a success or failure response back.
Misconception check: Custom resources are not a replacement for careful architecture. They should be used only when no native resource exists.
Concrete scenario
You need to tag the account root ARN with OwnerEmail on stack creation. A Lambda called by a Custom::AccountTagger resource calls the tagging API and reports success to CloudFormation so the stack completes.
Pro tip
Ensure the Lambda sends CloudFormation responses promptly and implements retries and idempotent behavior on repeated invocations to avoid leaving stacks in rollback states.
