Module 3 › Chapter 3.3 › Rollback & Errors
Common failure causes
  • Missing or incorrect IAM permissions for Lambda or StackSet roles.
  • Export name collisions or wrong region scope for Fn::ImportValue.
  • Lambda timeouts or unhandled exceptions in custom resources.
Mitigation checklist
  • Make custom resource handlers idempotent and log operations.
  • Test Create, Update, Delete flows in staging accounts.
  • Maintain a deletion plan that removes importers before exporters.
Check your understanding
If a stack using Fn::ImportValue fails to create, validate that the named export exists in the same region and that the exporting stack is in a stable state. If a custom resource causes ROLLBACK_FAILED, inspect Lambda logs and implement safe idempotent delete behavior.
