Module 3 › Chapter 3.3 › Hands-on Activity
Step 1 — Prepare artifacts
Create logging-bucket-template.yaml, custom-tagger-template.yaml, and zip the Lambda code. Output BucketName and BucketARN in the bucket template.
Step 2 — Upload
Upload zip and templates to an S3 bucket in the administrator account. Ensure correct S3 paths in templates.
Step 3 — Create StackSets
Create OrgBaselineStackSet for logging and OrgAccountTagger for custom tagging with SERVICE_MANAGED and CAPABILITY_IAM.
Validation & cleanup
Verify buckets exist in each target account/region and confirm OwnerEmail tags via resource tagging API. Clean up by deleting instances then StackSets then uploaded artifacts.
