Skill 1 — Stack decomposition
Design a NetworkingStack, ApplicationStack, and DataStack so infrastructure teams can iterate independently and reuse templates.
Check: Can ApplicationStack create resources only after NetworkingStack exports VPCId?
Skill 2 — Cross-Stack wiring
Use Outputs with Export names and Fn::ImportValue so stacks reference concrete identifiers without manual parameter passing.
Check: Are export names unique per region and stable across updates?
Skill 3 — Custom resource lifecycle
Implement Lambda handlers that respond to Create, Update, and Delete and make operations idempotent to avoid rollback failures.
Check: Does your Lambda send success or failure using CloudFormation response semantics?
Skill 4 — StackSets at scale
Configure a StackSet with proper admin and execution roles, set permission model, and enable auto-deployment when using AWS Organizations.
Check: Are target accounts reachable and do they have the execution role in place?
