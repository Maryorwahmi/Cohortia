Module 3 › Chapter 3.3 › Export Rules
Core rules
  • Export names must be unique within a region.
  • Exports are region-scoped; identical names in different regions are independent.
  • The exporting stack must exist before importers can be created.
Operational checklist
  1. Document export names and owning stacks.
  2. When changing export names, update importers first and coordinate deployment order.
  3. Delete importers before deleting exporters.
Analogy
Think of exports as pins you insert into a shared board: other stacks hang their hooks on those pins. Removing a pin while hooks remain will drop the items. Remove the hooks first, then the pin.
