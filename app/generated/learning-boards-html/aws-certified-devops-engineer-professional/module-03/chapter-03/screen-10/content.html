Module 3 › Chapter 3.3 › StackSets Overview
When to use StackSets
  • Deploy baseline infrastructure to many accounts and regions.
  • Enforce consistency for security or logging resources.
  • Automate deployment to new accounts using auto-deployment.
Requirements and roles
  • Administrator account creates the StackSet and initiates instances.
  • Target accounts require an execution role; service-managed simplifies this with Organizations.
  • Include CAPABILITY_IAM for templates that create IAM resources.
Analogy
Think of StackSets as a distribution system: one master recipe that is applied in many kitchens; each kitchen must have the right permissions and ingredients to run the recipe successfully.
