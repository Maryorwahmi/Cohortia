Process
Export and import workflow
  1. Export values from the source stack using Outputs and a unique Export Name.
  2. Create or update the consuming stack using Fn::ImportValue with the exported name.
  3. Confirm the exporting stack exists and exports are available before creating importers.
  4. When removing an exported value, delete importing stacks first.
Misconception check: ImportValue is not a parameter — it directly resolves the exported name at stack operation time.
Correct exporting example (YAML)
Outputs:
  VPCId:
    Description: The ID of the VPC.
    Value: !Ref MyVPC
    Export:
      Name: MyWebApp-VPCId
  PublicSubnetId:
    Description: The ID of the Public Subnet.
    Value: !Ref MyPublicSubnet
    Export:
      Name: MyWebApp-PublicSubnetId
Correct importing example
Resources:
  MyWebServer:
    Type: AWS::EC2::Instance
    Properties:
      VpcId: !ImportValue MyWebApp-VPCId
      SubnetId: !ImportValue MyWebApp-PublicSubnetId
      # ... other properties ...
