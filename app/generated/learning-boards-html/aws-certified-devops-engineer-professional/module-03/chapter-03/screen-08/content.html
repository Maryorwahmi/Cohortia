Module 3 › Chapter 3.3 › Custom Resource Handler
What the handler must do
  • Inspect event['RequestType'] for Create, Update, Delete.
  • Perform the desired action using AWS SDK calls.
  • Send success or failure back to CloudFormation and include any response data.
  • Implement idempotent operations and retries where appropriate.
Handler example (Python snippet)
import json
import boto3
import cfnresponse

def handler(event, context):
    print(json.dumps(event))
    response_data = {}
    try:
        if event['RequestType'] == 'Create':
            # perform creation logic, e.g., tag account
            response_data['Message'] = 'Created'
        elif event['RequestType'] == 'Update':
            # perform update logic
            response_data['Message'] = 'Updated'
        elif event['RequestType'] == 'Delete':
            # perform delete logic
            response_data['Message'] = 'Deleted'
        cfnresponse.send(event, context, cfnresponse.SUCCESS, response_data)
    except Exception as e:
        print(f'Error: {e}')
        cfnresponse.send(event, context, cfnresponse.FAILED, response_data, reason=str(e))
