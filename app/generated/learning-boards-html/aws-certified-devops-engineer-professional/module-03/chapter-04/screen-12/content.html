Definition › Project Structure
cdk.json
CLI configuration that tells CDK how to run and pass context to your app.
lib/ or src/
Where stack classes and constructs live. Separate stacks by concern for easier deployment and testing.
package.json / requirements.txt
Manage language-specific dependencies and build scripts that run before synth or deploy.
Best Practices
  • Keep stacks small and focused (for example, NetworkStack vs ServiceStack).
  • Place asset code like Lambdas inside dedicated directories referenced by Code.fromAsset.
  • Use context and environment variables carefully to maintain reproducible synth outputs.
