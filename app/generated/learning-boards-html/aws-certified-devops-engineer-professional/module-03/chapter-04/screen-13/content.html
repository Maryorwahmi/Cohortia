Common Mistake › Debugging CDK

Frequent Errors

  • Missing bootstrap: deployments fail due to absent asset bucket or roles.
  • Incorrect construct scope: resources must be children of a stack.
  • Credential or region misconfiguration: deploy cannot call AWS APIs.
Pro Tip
When in doubt, run cdk synth to reveal the CloudFormation template and then review CloudFormation events in the console for detailed failure messages.

Debugging Checklist

1) Run cdk synth and redirect to a file. 2) Confirm cdk bootstrap has been executed for the target account/region. 3) Verify AWS credentials and region. 4) Inspect CloudFormation events for error causes.
Key Takeaway

Use synth and CloudFormation events as your primary debugging tools, and ensure bootstrap and credentials are correct before deploy.
