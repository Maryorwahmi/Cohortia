Hands-on Objectives

These objectives prepare you to bootstrap, deploy, and debug CDK stacks in an AWS account.

05
Run cdk bootstrap
Provision account-level resources required for CDK assets, such as an S3 bucket and IAM role.
Mnemonic: one-time account prep
VERIFIED COMPETENCY MILESTONE
06
Deploy and verify outputs
Use cdk deploy to create resources and inspect output values like API endpoints for testing.
Mnemonic: deploy then verify
VERIFIED COMPETENCY MILESTONE
07
Author a serverless API stack
Wire a Lambda function to API Gateway, output the endpoint, and test via browser or curl.
Mnemonic: function plus gateway
VERIFIED COMPETENCY MILESTONE
08
Debug common CDK errors
Inspect synthesized templates, review CloudFormation events, and check bootstrap and credentials when troubleshooting.
Mnemonic: synth, events, creds
VERIFIED COMPETENCY MILESTONE
