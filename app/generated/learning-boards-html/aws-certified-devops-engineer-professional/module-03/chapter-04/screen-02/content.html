Learning Objectives

These objectives focus on practical fluency: install, code, synthesize, and deploy with CDK.

01
Explain CDK vs CloudFormation
Describe how CDK’s programming model adds loops, conditionals, types, and testing compared to static YAML templates.
Mnemonic: code brings control structures
VERIFIED COMPETENCY MILESTONE
02
Identify App, Stack, Construct
Explain the responsibilities of each abstraction and how they organize resources for deployment and reuse.
Mnemonic: container, deploy unit, building block
VERIFIED COMPETENCY MILESTONE
03
Set up local CDK environment
Install Node and the CDK CLI, verify the version, and initialize a project scaffold for TypeScript or Python.
Mnemonic: install, verify, init
VERIFIED COMPETENCY MILESTONE
04
Write and synthesize a CDK stack
Author a simple TypeScript stack to define an SQS queue and run cdk synth to inspect the resulting CloudFormation.
Mnemonic: code, synth, inspect
VERIFIED COMPETENCY MILESTONE
