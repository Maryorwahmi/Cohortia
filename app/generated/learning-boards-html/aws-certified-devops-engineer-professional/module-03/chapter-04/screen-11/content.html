Lambda handler (example)

import json

def handler(event, context):
    print(f"Received event: {json.dumps(event)}")
    return {
        'statusCode': 200,
        'headers': {'Content-Type': 'application/json'},
        'body': json.dumps({'message': 'Hello from CDK Lambda!', 'path': event.get('path', '/')})
    }
Place this file under lambda/ and reference it from your stack with Code.fromAsset pointing to lambda/ and handler set to the file and function name.

Stack wiring (concept)

Define a lambda.Function, then an apigateway.LambdaRestApi that points to that function. Add a CfnOutput to export the endpoint URL so you can test after deploy.
Key Takeaway

Serverless patterns in CDK combine assets and managed services; ensure your code directory is referenced and included before deployment.

Test and Cleanup
After deploy, copy the ApiGatewayEndpoint output and open it. Use curl to validate the JSON response. When finished, remove the environment with cdk destroy to avoid unexpected charges.
