Core Concept › Imperative vs Declarative

Definition and Benefits

Imperative code lets you use language features to reduce duplication and apply software engineering practices to infrastructure.

Reusability
Encapsulate common patterns as constructs and reuse them across stacks and apps.
Testability
Unit tests can exercise construct wiring before synthesis.
Tooling
IDE completion and linters reduce manual errors compared to raw YAML editing.
Key Takeaway

CDK adds expressive language features to IaC while still emitting CloudFormation for deployment.

Common Mistake
Assuming CDK will remove the need to inspect synthesized templates; always inspect generated CloudFormation when debugging.

Concrete Example

Instead of repeating subnet definitions in YAML, use a loop in your language to create three subnets with consistent naming and tags. This reduces copy-paste errors and keeps code maintainable across environments.
Explanation Bullets
  • Imperative code builds an object model which CDK later converts to CloudFormation.
  • Language features let you create abstractions and libraries of constructs for teams.
  • CDK preserves transparency by producing a standard CloudFormation template at synth time.
