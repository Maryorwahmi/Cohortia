Process Flow › Deploy (cdk deploy)

Deploy Steps

  1. cdk deploy runs synth to produce the template.
  2. The CLI creates a CloudFormation change set representing the changes.
  3. Change set is executed; CloudFormation performs resource operations.
cdk deploy
# CLI will show changes and may prompt on IAM modifications
Key Takeaway

Deploy runs an automated CloudFormation workflow; use CloudFormation events to debug failures and verify outputs after success.

Troubleshooting Tips

  • Inspect CloudFormation events for resource-specific errors and failure reasons.
  • Confirm your AWS credentials and region are correct for the target deploy.
  • If an IAM change is required, confirm you trust and accept the change before proceeding.
Example
After deployment, a CfnOutput such as ApiGatewayEndpoint will appear in the outputs; copy and test it to validate the service is reachable.
