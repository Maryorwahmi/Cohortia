Summary › Key Concepts
AWS CDK
A code-first framework to define infrastructure in languages like TypeScript and Python and synthesize CloudFormation.
App & Stack
App is the top-level container; Stack is the unit of deployment and maps to a CloudFormation stack.
Constructs (L1/L2/L3)
Building blocks with L1 mapping to CloudFormation, L2 providing defaults, and L3 offering full patterns.
Summary Takeaway

Use CDK to bring software engineering practices to infrastructure: write reusable constructs, synthesize to CloudFormation, bootstrap accounts, and deploy with confidence.
