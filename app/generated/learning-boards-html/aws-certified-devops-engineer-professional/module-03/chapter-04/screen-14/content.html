Activity › Deploy a Serverless API

Step-by-step

  1. cdk init app --language typescript
  2. Create lambda/hello.py or .ts with a handler returning JSON
  3. In stack, create lambda.Function using Code.fromAsset pointing to lambda/
  4. Create apigateway.LambdaRestApi and output the URL
  5. cdk synth > template.yaml
  6. cdk bootstrap aws://ACCOUNT/REGION (if needed)
  7. cdk deploy, then test the endpoint; finally cdk destroy

Example Commands

mkdir cdk-serverless-api
cd cdk-serverless-api
cdk init app --language typescript
# add lambda/hello.py and stack code
cdk synth > template.yaml
cdk bootstrap aws://YOUR_ACCOUNT/YOUR_REGION
cdk deploy
# test endpoint, then
cdk destroy
Key Takeaway

Follow the full cycle from init to destroy to validate your understanding of CDK’s synth and deploy workflow.

Cleanup Reminder
Always run cdk destroy when experimenting to remove stacks created during the lab and avoid unexpected AWS charges.
