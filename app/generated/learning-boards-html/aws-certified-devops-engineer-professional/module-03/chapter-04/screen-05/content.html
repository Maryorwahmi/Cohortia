Comparison › Construct Levels
L1 — CFN Resources
Direct mapping to CloudFormation resource types
Fine-grained control for every property, used when exact CloudFormation configuration is required.
L2 — AWS Constructs
Opinionated, resource-focused constructs
Provide defaults and combine multiple L1 resources into a single developer-friendly API.
L3 — Patterns
Complete architecture patterns
Encapsulate best practices and multiple resources to accelerate common application architectures.
Concrete Example
To create a VPC with public and private subnets, an L2 Vpc construct will create the subnets, route tables, and gateway automatically. With an L1 approach you would create each subnet and route table individually in YAML or as CfnSubnet and related resources.
Quick Decision Guide
  • Need exact CFN properties: use L1.
  • Want sensible defaults and less code: use L2.
  • Need a full pattern with best practices: use L3.
