Code Walkthrough › SQS Queue (TypeScript)

Source Snippet

// lib/my-cdk-app-stack.ts
import * as cdk from 'aws-cdk-lib';
import * as sqs from 'aws-cdk-lib/aws-sqs';
import { Construct } from 'constructs';

export class MyCdkAppStack extends cdk.Stack {
  constructor(scope: Construct, id: string, props?: cdk.StackProps) {
    super(scope, id, props);

    // Define an SQS queue
    new sqs.Queue(this, 'MySimpleQueue', {
      visibilityTimeout: cdk.Duration.seconds(300),
      queueName: 'my-devops-professional-queue',
      encryption: sqs.QueueEncryption.KMS_MANAGED,
    });
  }
}

Explanation

  • Import the CDK core and SQS module so you can reference the L2 Queue construct.
  • Extend cdk.Stack to create a deployable unit; the constructor wires resources to the stack scope.
  • The second parameter to new Queue is a logical identifier used in the synthesized template.
  • Properties like visibilityTimeout and encryption configure the created SQS resource.
Key Takeaway

An L2 construct yields concise code while producing explicit CloudFormation during synthesis.

Common Mistake
Using a physical name accidentally may cause collisions; prefer logical IDs and only set explicit names when needed.
