Quick Setup Commands

npm install -g aws-cdk
cdk --version
mkdir my-cdk-app
cd my-cdk-app
cdk init app --language typescript
These commands install the CLI, verify it, and scaffold a TypeScript app. For Python choose --language python and use pip to manage dependencies.
Key Takeaway

A consistent local environment and CLI are required before writing and deploying CDK apps.

Pro Tip
Use your preferred package manager for global installs and version managers to pin Node versions across teammates.

Project Structure Explained

cdk init creates a small scaffold: a cdk.json that tells the CLI how to run your app, a lib or project package area for stacks, and a package.json or requirements file to manage dependencies. This layout separates application code, stack definitions, and CLI configuration for clarity.
Checklist
  • Node and npm installed (or language SDK for Python).
  • CDK CLI installed globally and verified.
  • Project scaffold initialized with cdk init.
  • AWS credentials configured for deploy operations.
