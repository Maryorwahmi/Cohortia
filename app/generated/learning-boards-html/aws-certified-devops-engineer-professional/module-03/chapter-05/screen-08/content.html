What Aspects Do
  • Traverse the construct tree and call a visit method on each node.
  • Apply tags, validations, or property modifications programmatically.
  • Run at synthesis time so their changes appear in the generated template.
When to use

Aspects are ideal for retrofitting policies across multiple codebases or ensuring all resources have required governance properties, such as a CostCenter tag or bucket encryption checks.

Warning

Mis-scoped aspects can modify unexpected resources. Test aspects on small stacks before wide application.
