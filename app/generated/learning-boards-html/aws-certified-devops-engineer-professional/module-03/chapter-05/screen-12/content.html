Module 03 › Chapter 3.5 › Hands-on Activity
Steps
  1. Initialize project: cdk init app --language typescript.
  2. Create lib/secure-bucket-construct.ts with encryption=KMS_MANAGED, blockPublicAccess, versioning, logging bucket fallback, and outputs for BucketName and BucketARN.
  3. Create lib/tagging-aspect.ts implementing IAspect to add a Project tag to CfnResource instances.
  4. In your stack, instantiate SecureBucket and add cdk.Aspects.of(this).add(new ProjectTagger('Project','DevOpsProfessional')).
  5. Run cdk synth to inspect the template, then cdk deploy if you want to verify in console.
  6. Verify: encryption, public access block, access logging bucket exists, and tags applied to both primary and logging buckets.
