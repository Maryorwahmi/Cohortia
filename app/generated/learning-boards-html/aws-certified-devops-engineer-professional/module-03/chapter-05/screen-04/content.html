Module 03 › Chapter 3.5 › L3 Constructs
Definition

What an L3 construct gives you

  • Encapsulates multiple L2 resources into a single API surface.
  • Provides sensible defaults aligned to AWS best practices.
  • Reduces boilerplate and enforces consistent deployment topology.
Common misconception
Patterns replace all customization. In reality, they expose hooks to tweak networking, scaling, and security while handling the standard plumbing for you.
Pattern Example
ApplicationLoadBalancedFargateService — creates VPC, cluster, Fargate service, task, ALB, and security groups.
Why use it

Use L3 patterns when you want reliable defaults and fast delivery for common application topologies such as containerized web services.

Key Takeaway

Patterns speed up standard deployments while preserving customization when required. Inspect the synth output to trust the defaults.
