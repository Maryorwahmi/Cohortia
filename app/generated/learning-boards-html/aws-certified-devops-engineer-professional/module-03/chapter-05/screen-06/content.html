Module 03 › Chapter 3.5 › Custom Constructs
Concept

What to encapsulate

  • Security posture (encryption, access logging, block public access).
  • Tagging and naming conventions.
  • Common network and resource wiring (ALB + service + database).
Design rules: keep APIs small, provide sensible defaults, and expose outputs for other stacks to reference.
Analogy
Think of a custom construct as a language library that packages a tested function. Callers pass parameters and receive well-formed resources and outputs.
Common Mistake

Rewriting existing L3 constructs. Prefer composition: use L2/L3 constructs inside your custom construct rather than re-creating service wiring from scratch.
