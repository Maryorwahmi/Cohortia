Module 03 › Chapter 3.5 › CDK Pipelines
Pipeline Stages
  1. Source: connect to CodeCommit or GitHub.
  2. Synth: run install, build, and npx cdk synth in a CodeBuild step.
  3. Test: run unit tests and policy scans.
  4. Deploy: add stages for Dev and Prod with optional manual approval in Prod.
Operational Note

Ensure pipeline roles have IAM permissions for target deployments and bootstrap the target accounts/regions before cross-account deploys.

Example Snippet
// pipeline creation (conceptual)
const pipeline = new pipelines.CodePipeline(this, 'Pipeline', {
  synth: new pipelines.CodeBuildStep('Synth', {
    input: pipelines.CodePipelineSource.codeCommit(repo, 'main'),
    commands: ['npm ci', 'npm run build', 'npx cdk synth'],
  }),
});

pipeline.addStage(new MyCdkAppStage(this, 'Dev'));
const prod = pipeline.addStage(new MyCdkAppStage(this, 'Prod'));
prod.addPost(new pipelines.ManualApprovalStep('ApproveProductionDeployment'));
