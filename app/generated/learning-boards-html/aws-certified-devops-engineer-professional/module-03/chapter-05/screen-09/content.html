Module 03 › Chapter 3.5 › Tagging Aspect
Snippet
<!-- Tagger aspect (escaped) --> import { IAspect, Stack, Tag } from 'aws-cdk-lib'; import { IConstruct } from 'constructs'; export class Tagger implements IAspect { private readonly key: string; private readonly value: string; constructor(key: string, value: string) { this.key = key; this.value = value; } public visit(node: IConstruct): void { if (node instanceof Stack) { Tag.add(node, this.key, this.value); } } }
Usage & Checks
Apply with cdk.Aspects.of(stack).add(new Tagger('Project', 'DevOpsCourse')). Then run cdk synth and inspect the template for the applied tags on resources. Use aspects for governance and retrofitting policies across codebases.
Pro Tip

Run aspects against a small test stack first to confirm scope and avoid widespread accidental changes.
