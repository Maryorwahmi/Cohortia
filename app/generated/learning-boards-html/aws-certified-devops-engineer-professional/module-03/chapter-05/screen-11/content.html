Module 03 › Chapter 3.5 › CfnInclude
Example
new CfnInclude(this, 'ExistingTemplate', {
  templateFile: path.join(__dirname, '..', 'existing-vpc.yaml'),
  // optional overrides
});
When to use
  • Migrating legacy stacks incrementally.
  • Integrating third-party CloudFormation templates.
  • When a full rewrite is risky or time-consuming.
Limitations

Included templates stay as CloudFormation. They cannot adopt imperative construct behaviors until reimplemented in CDK.
