Validation checkpoints

L3 Pattern Check
Run cdk synth and confirm the pattern emitted an ALB, ECS service, task definition, and security groups without extra configuration.
Custom Construct Check
Instantiate the construct in two stacks and compare outputs to ensure consistent resource naming, tagging, and settings.
Aspect Check
Apply the aspect and run cdk synth. Confirm tags or validations appear on expected resources in the template.
Pipeline Check
Create a pipeline stage for Dev and Prod, run the pipeline, and check that a manual approval gate halts production until approved.
