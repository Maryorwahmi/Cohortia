Pipeline stage example
A typical pipeline runs: synth (for CDK) -> cfn-lint syntax checks -> checkov/terrascan security checks -> unit/integration tests -> approval gate -> deploy. Fail on critical security findings and surface remediation steps in CI output. 
# CI pseudo-steps
- checkout
- install cfn-lint, checkov
- synth (if using CDK)
- run cfn-lint template.yaml
- run checkov -f template.yaml
- fail pipeline on high severity
Operational tips
  • Annotate CI findings so reviewers see them inline with code changes.
  • Classify rule severities and tune false positives carefully.
  • Run scans on synthesized templates to reflect the actual deployment artifact.
