Governance checklist

Template linting and scanning
Automate cfn-lint and checkov in CI to catch errors and security issues early.
Code review and approval
Require reviews and manual approval gates for production changes.
Drift detection and remediation
Regularly run CloudFormation drift detection and respond with plans to reconcile drift.

Practical tips

  • Keep templates in version control and require PR reviews for changes.
  • Automate scans and fail CI on severe findings to keep the pipeline healthy.
  • Use Config rules to both detect and, where safe, remediate common violations automatically.
