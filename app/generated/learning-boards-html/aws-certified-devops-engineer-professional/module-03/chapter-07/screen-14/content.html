Module 4 › Chapter 3.7 › Key Concepts
Principle of Least Privilege
Grant deployment roles only the actions and resources they need; review policies as templates evolve.
Secrets Management
Use Secrets Manager or SSM SecureString; never embed credentials in templates or repo history.
Template Scanning
Run cfn-lint and security scanners in CI to catch syntax and security issues early.
Summary Takeaway

Layer preventive SCPs with detective Config rules, integrate scanning in CI, and treat IaC with the same security rigor as application code.
