How Config works

Config records resource state and evaluates rules. Managed rules provide common checks; custom rules allow business-specific policies. When a rule detects non-compliance it can emit events, mark resources non-compliant, and invoke remediation actions.

Example: automatic bucket fix
A Config rule flags public S3; a Lambda remediation applies BlockPublicAccess and updates the policy.
Design note
Remediations must be idempotent and auditable. Avoid destructive fixes without human approval for high-impact resources.
Limitations and pairing
Config detects issues after creation. For prevention, use SCPs or CI gates to block misconfigurations before they reach the API.
