Module 4 › Chapter 3.7 › AMI Hygiene
Golden AMI pipeline
  1. Build a new AMI from a base and configuration scripts.
  2. Run security scanning and configuration tests against the AMI.
  3. Publish the AMI ID to SSM Parameter Store or an artifact catalog if it passes.
  4. Deploy stacks referencing the approved AMI parameter.
Practical guidance
Parameterize AMI IDs, run CVE scans during image bake, and schedule periodic rebuilds so images stay current.
Common pitfall
Relying on a single manual AMI selection that becomes outdated. Automate rebuilds and rollouts to keep the fleet patched.
Why it matters

Regularly updated AMIs reduce the risk of known vulnerabilities entering production and ensure consistent configuration across instances.
