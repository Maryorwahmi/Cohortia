Module 3 › Chapter 3.6 › Failures & Remedies
Resource creation failed
Check template resource properties, validate AMI IDs and CIDR blocks, and correct invalid inputs.
Access Denied
Identify missing permissions from Events and add the minimal required IAM actions to the deployment role.
Invalid parameter value
Validate parameter definitions and AllowedValues and correct any incorrect inputs before redeploying.
Custom resource failure
Inspect CloudWatch Logs for the Lambda, make handlers idempotent, and return clear FAILED signals with descriptive reasons.
ROLLBACK_FAILED
Identify the resource that could not be reverted, fix or manually delete it, then continue update rollback or correct and redeploy.
Remediation sequence
Find the earliest FAILED event, read its status reason, check resource logs, apply a focused fix, and redeploy. Avoid deleting the stack prematurely.
