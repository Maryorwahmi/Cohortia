Module 3 › Chapter 3.6 › DeletionPolicy
Options explained
  • Retain: keep the resource when the stack is deleted.
  • Snapshot: create a snapshot of the resource before deletion.
  • Delete: remove the resource (default).
When to use each
Use Retain for buckets with critical assets, Snapshot for databases you may need to restore, and Delete for ephemeral infrastructure.
YAML example
Resources:
  MyProductionDatabase:
    Type: AWS::RDS::DBInstance
    DeletionPolicy: Retain # Prevents accidental deletion
    Properties:
      # ...
Verify these settings in your templates before deploying to production so that deletion actions are safe.
