1 — Inspect Events
Find the earliest FAILED event and read the status reason to locate the root cause quickly.
2 — Protect critical data
Apply DeletionPolicy: Retain or Snapshot, and enable termination protection for production stacks.
3 — Design idempotency
Make custom resource handlers idempotent and return clear failure signals to CloudFormation.
Final reminder

These three operational rules will reduce downtime and prevent accidental data loss during IaC operations.
