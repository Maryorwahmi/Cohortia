Module 3 › Chapter 3.6 › Compare & Reconcile
Step 1 — Analyze
CloudFormation reads the incoming template and the stack’s internal record to determine the difference.
Step 2 — Plan
It computes a set of actions: create, update, or delete and orders them by dependencies.
Step 3 — Execute
CloudFormation attempts the changes, and will automatically roll back on failure unless otherwise configured.
Practical checks
  • Use CDK diff or change sets to preview replacements.
  • Confirm DeletionPolicy for resources that must not be lost.
  • Back up data before changes that may replace resources.
Example scenario
Changing a property that requires replacement will result in a create followed by delete workflow or an in-place update when supported. Preview changes first to avoid surprises.
Key Takeaway

Preview planned actions and set protection policies before executing updates that could replace critical resources.
