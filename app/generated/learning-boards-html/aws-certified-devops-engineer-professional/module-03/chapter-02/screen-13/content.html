Module 3 › Chapter 3.2 › Lab Walkthrough: Modular Web Application
Task Checklist
  1. Create vpc-template.yaml with VPC, subnet, IGW, route table, and Outputs for VPCId and PublicSubnetId.
  2. Modify webserver-template.yaml to accept VPCId and PublicSubnetId, add SG and IAM role, output WebServerPublicIP.
  3. Create database-template.yaml with CreateDatabase parameter and Condition to gate the RDS resource.
  4. Upload templates to S3 and create parent-stack.yaml referencing those TemplateURLs.
  5. Create stack-policy.json to deny delete on WebServerInstance and MyRDSInstance.
  6. Deploy parent stack with CreateDatabase=false; create and review a change set to set CreateDatabase=true.
CLI Snippets (examples)
# Upload templates
aws s3 cp vpc-template.yaml s3://your-cf-templates-bucket/vpc-template.yaml
aws s3 cp webserver-template.yaml s3://your-cf-templates-bucket/webserver-template.yaml
aws s3 cp database-template.yaml s3://your-cf-templates-bucket/database-template.yaml

# Deploy parent stack initial
aws cloudformation deploy \
  --template-file parent-stack.yaml \
  --stack-name MyModularWebAppStack \
  --parameter-overrides KeyPairName=YOUR_KEY_PAIR_NAME AMIId=YOUR_AMI_ID CreateDatabase=false \
  --capabilities CAPABILITY_IAM \
  --stack-policy-during-update file://stack-policy.json

# Create change set to enable DB
aws cloudformation create-change-set \
  --stack-name MyModularWebAppStack \
  --template-body file://parent-stack.yaml \
  --change-set-name EnableDatabaseChangeSet \
  --parameter-overrides KeyPairName=YOUR_KEY_PAIR_NAME AMIId=YOUR_AMI_ID CreateDatabase=true \
  --capabilities CAPABILITY_IAM
