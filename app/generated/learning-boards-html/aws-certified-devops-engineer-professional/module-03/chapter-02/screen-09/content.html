Child Output (example)
Outputs:
  VPCId:
    Value: !Ref MyVPC
    Export:
      Name: MyProject-VPCId
  PublicSubnetId:
    Value: !Ref PublicSubnet
The child exposes only the values the parent needs. Use clear, stable output names as the contract between stacks.
Parent uses GetAtt
WebServerStack:
  Type: AWS::CloudFormation::Stack
  Properties:
    TemplateURL: s3://your-bucket/webserver-template.yaml
    Parameters:
      VPCId: !GetAtt VPCStack.Outputs.VPCId
      PublicSubnetId: !GetAtt VPCStack.Outputs.PublicSubnetId
Confirm output keys and test child stacks independently before composing them in a parent.
