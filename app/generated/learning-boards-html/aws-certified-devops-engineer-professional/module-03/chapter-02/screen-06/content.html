Mapping Table
Mappings:
  RegionMap:
    us-east-1:
      AMI: ami-0abcdef1234567890
      InstanceType: t2.medium
    eu-west-1:
      AMI: ami-0fedcba9876543210
      InstanceType: t2.large

# Use FindInMap to select values
ImageId: !FindInMap [RegionMap, !Ref "AWS::Region", AMI]
Mappings are static tables in the template. They make templates portable across regions and minimize condition complexity.
Why it matters
Centralizing AMIs avoids multiple parameter overrides and reduces errors when you deploy to many regions. It also simplifies reviews because the mapping table is compact and obvious.
Example
Use the AWS::Region pseudo parameter with FindInMap to select the correct AMI for the target region at deployment time, keeping one template usable everywhere.
