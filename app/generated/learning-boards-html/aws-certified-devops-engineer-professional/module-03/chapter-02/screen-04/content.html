Module 3 › Chapter 3.2 › Intrinsic Functions Deep Dive
Definition
Intrinsic functions return computed values during deployment. They reduce hardcoding and let templates adapt to parameters, pseudo parameters, mappings, and conditions.
  • !Join concatenates a list using a delimiter.
  • !Sub substitutes variables inside a string for clarity.
  • !If picks a value based on a Condition.
  • !FindInMap looks up values from a Mapping table.
Common Mistake
Overusing Join for complex strings makes templates hard to read; prefer Sub for clarity. Also, failing to validate uniqueness when building names can cause deployment failures.
Code Examples
# Example: Join builds a bucket name
BucketName: !Join ['-', ['my-app', !Ref Environment, 'bucket']]

# Example: Sub builds an ARN
S3Arn: !Sub 'arn:aws:s3:::${MyS3Bucket}'

# Example: FindInMap retrieves AMI
ImageId: !FindInMap [RegionMap, !Ref "AWS::Region", AMI]

# Example: If uses a condition
InstanceType: !If [IsProduction, t2.large, t2.micro]
Example
Use FindInMap to map region to AMI so one template works in many regions.
Key Takeaway
Pick the function that expresses intent: substitution, concatenation, condition, or lookup.
