Parent / Child Pattern
Declare child stacks as AWS::CloudFormation::Stack resources with TemplateURL and Parameters. Upload child templates to S3 so the parent can reference them during deployment.
# ParentStack.yaml (snippet)
Resources:
  VPCStack:
    Type: AWS::CloudFormation::Stack
    Properties:
      TemplateURL: s3://your-bucket/vpc-template.yaml
      Parameters:
        VPCCidr: 10.0.0.0/16

  WebServerStack:
    Type: AWS::CloudFormation::Stack
    Properties:
      TemplateURL: s3://your-bucket/webserver-template.yaml
      Parameters:
        VPCId: !GetAtt VPCStack.Outputs.VPCId
        PublicSubnetId: !GetAtt VPCStack.Outputs.PublicSubnetId
Benefits
Separation of concerns, easier updates, team ownership, and reusable building blocks across projects.
Pitfall
If child templates are not uploaded or the TemplateURL is incorrect, the parent deployment fails. Test child stacks independently first.
