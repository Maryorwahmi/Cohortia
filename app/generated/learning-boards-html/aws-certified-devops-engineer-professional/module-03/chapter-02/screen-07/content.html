Module 3 › Chapter 3.2 › Conditions and Conditional Resources
Steps
  1. Declare parameter CreateDatabase (true/false).
  2. Define Condition ShouldCreateDatabase using Fn::Equals.
  3. Attach Condition to the RDS resource with Condition: ShouldCreateDatabase.
  4. Optionally control outputs with the Condition.
YAML Snippet
Parameters:
  CreateDatabase:
    Type: String
    AllowedValues: [true, false]
    Default: false

Conditions:
  ShouldCreateDatabase: !Equals [!Ref CreateDatabase, 'true']

Resources:
  MyRDSInstance:
    Type: AWS::RDS::DBInstance
    Condition: ShouldCreateDatabase
    Properties:
      DBInstanceClass: db.t2.micro
Example
Toggle CreateDatabase to avoid billing in dev while allowing production creation via a change set.
Common Mistake
Forgetting to add the Condition attribute to the resource so it is still created despite the condition definition.
