Scenario

Multi-region deployment needs consistent AMI selection and production protections. Use a Mapping for AMIs and enforce a Stack Policy plus Change Sets for production updates.

Quick question:
You want to enable a database only after review. How do you implement that flow?
Answer Outline
  1. Define CreateDatabase parameter and ShouldCreateDatabase condition.
  2. Attach Condition to the child DB resource or nested DB stack.
  3. Create a change set to flip CreateDatabase to true and review it.
  4. Execute the change set after approval.
