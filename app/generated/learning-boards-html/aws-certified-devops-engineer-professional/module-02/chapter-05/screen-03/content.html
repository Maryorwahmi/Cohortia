Module 02 › Chapter 2.5 › Skills & Milestones

Skills you will practice

Each objective maps to a verifiable deployment or code artifact you can inspect.

Template deployment

Deploy the provided CloudFormation template, verify the CodeCommit repo and CodeBuild project, and observe outputs for clone URL and build project name.

CDK construct reuse

Create a reusable pipeline construct in CDK and synthesize it to a template used by multiple stacks.

Change set reviews

Prepare change sets for production updates and review the planned changes before execution.

Drift management

Run drift detection regularly and plan whether to update templates or revert manual changes when drift is found.
