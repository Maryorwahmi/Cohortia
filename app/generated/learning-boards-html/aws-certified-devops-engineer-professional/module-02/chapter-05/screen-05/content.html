Concept

Templates, stacks, and outputs

Templates declare resources; stacks apply the template to create an environment. Outputs expose values for other stacks or tooling.

Parameters
Allow environment-specific customization, like repository and bucket names.
Outputs
Return important values such as clone URLs and project names for integration.
Intrinsic functions
Use reference and get-attribute to connect resources within or across nested stacks.
Example
Resources:
  MyCodeBuildProject:
    Type: AWS::CodeBuild::Project
    Properties:
      Name: MyWebAppBuildProject
      ServiceRole: !GetAtt CodeBuildServiceRole.Arn
      Artifacts:
        Type: S3
        Location: !Ref BuildArtifactsBucket
      Environment:
        ComputeType: BUILD_GENERAL1_SMALL
        Image: aws/codebuild/amazonlinux2-x86_64-standard:4.0
      Source:
        Type: CODECOMMIT
        Location: !GetAtt MyCodeCommitRepo.CloneUrlHttp
This snippet shows a CodeBuild resource referencing a service role and an artifacts bucket through intrinsic functions.
Key Takeaway

Use parameters and outputs for reuse, and preview updates with change sets before applying them.
