Module 02 › Chapter 2.5 › CloudFormation vs CDK
CloudFormation

Declarative templates

  • Explicit, easy to audit in templates.
  • Direct support for change sets, outputs, and drift detection.
  • Preferred when strict template review is required.
When to pick
Regulated environments or teams that want direct template control.
AWS CDK

Programmatic constructs

  • Write constructs in TypeScript, Python, Java, or C# and synthesize templates.
  • Encourages reuse and encapsulates best practices as constructs.
  • Reduces boilerplate for large, repeated pipeline patterns.
When to pick
Large organizations with many similar pipelines who want shared constructs and abstraction.
Both approaches end up as CloudFormation templates when applied; CDK simply gives you higher-level language features to generate those templates. Keep using change sets and drift detection as part of your release process regardless of the tool.
