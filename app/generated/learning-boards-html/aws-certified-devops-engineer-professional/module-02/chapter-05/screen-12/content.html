Module 02 › Chapter 2.5 › Custom Resources
Pattern

Lambda-backed custom resources

Define an AWS::CloudFormation::CustomResource that calls a Lambda. The Lambda implements create, update, and delete handlers and signals status back to CloudFormation.

Use case
Registering webhooks or configuring third-party CI integrations that CloudFormation cannot natively manage.
Security note
Do not embed secrets in templates; grant the Lambda the narrowest permissions and store secrets in a secure store referenced by the function.
Checklist
  • Make the Lambda idempotent and fast.
  • Handle failures clearly so CloudFormation can roll back or report errors.
  • Secure any external credentials via managed secrets, not template literals.
Key Takeaway

Custom resources fill functional gaps but require operational discipline: idempotency, security, and clear failure handling.
