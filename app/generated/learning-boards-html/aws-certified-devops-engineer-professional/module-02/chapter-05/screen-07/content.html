Module 02 › Chapter 2.5 › Intrinsic Functions
Concept

!Ref and !GetAtt

Reference returns a resource name or parameter; get-attribute returns a specific property such as an ARN or clone URL. They are resolved when CloudFormation processes the template.

When to use
Use reference for values like bucket names and get-attribute for properties not returned by reference, like role ARNs or resource endpoints.
Nested stacks
Expose outputs from child stacks and retrieve them in the parent using Fn::GetAtt or cross-stack references where supported.
Scenario
Suppose you have a nested template that creates a CodeCommit repository and returns its clone URL as an output. The parent stack can get that clone URL and pass it into a CodeBuild project's source location so builds know where to pull code.
Misconception
These functions are not runtime queries. They are template-level references resolved by CloudFormation during stack operations.
Key Takeaway

Use intrinsic functions to wire resources, expose outputs for reuse, and keep templates modular.
