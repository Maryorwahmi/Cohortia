EventBridge rules

Match pipeline events and route them to targets like SNS or Lambda for automation or notification.

Sample event pattern
{
  "source": ["aws.codepipeline"],
  "detail-type": ["CodePipeline Stage Execution State Change"],
  "detail": {
    "state": ["FAILED"]
  }
}
Testing tip
After creating a rule, trigger a controlled failure and confirm the SNS topic or Lambda receives the event and acts correctly.
Concrete example
Create a rule that sends stage failures in ProductionWebAppPipeline to MyPipelineAlertsTopic. Add a Lambda target to format messages for Slack if desired.
Common-mistake

Make rules too broad. Narrow by pipeline and stage to avoid noisy triggers and reduce downstream load on targets.
