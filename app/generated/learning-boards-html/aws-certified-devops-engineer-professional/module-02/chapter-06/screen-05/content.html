Key Pipeline Metrics

  • CodePipeline: PipelineExecutionCount, PipelineExecutionFailed, ActionExecutionFailed.
  • CodeBuild: BuildDuration, FailedBuilds, SucceededBuilds.
  • CodeDeploy: DeploymentSuccess, DeploymentFailure, DeploymentDuration.
Dashboard tip
Combine raw counts, rates, and rolling averages. Show recent event timeline and last failure messages to speed triage.
Metric example
Create a widget that shows BuildDuration over time and a secondary metric for FailedBuilds. A rising duration often precedes failure spikes.
Misconception
Alarming every metric causes noise. Focus alarms on user-impacting signals and use dashboards for low-priority visibility.
Key Takeaway

Select a small set of business-relevant metrics, visualize trends, and set tested alarms to catch regressions early.
