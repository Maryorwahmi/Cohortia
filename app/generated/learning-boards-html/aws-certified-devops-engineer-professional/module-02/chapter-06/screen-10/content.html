Hands-on Activity › Alarm + EventBridge

Step-by-step

  1. Select metric: AWS/CodePipeline → PipelineExecutionFailed for MyStaticWebsitePipeline.
  2. Create alarm: Statistic Sum, Period 5m, Threshold >= 1 → Action: MyPipelineAlertsTopic.
  3. Create EventBridge rule: match stage FAILED and target the same SNS topic or a Lambda.
  4. Test: commit a breaking change, observe notifications, then revert.
Event pattern example
{
  "source": ["aws.codepipeline"],
  "detail-type": ["CodePipeline Stage Execution State Change"],
  "detail": {
    "state": ["FAILED"],
    "pipeline": ["MyStaticWebsitePipeline"]
  }
}
Key Takeaway

Testing alarms and rules with a controlled failure validates your monitoring and reduces surprises in production.
