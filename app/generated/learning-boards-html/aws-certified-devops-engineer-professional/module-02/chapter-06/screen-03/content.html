Module 3 › Chapter 2.6 › Notifications & Reliability
Design pattern
Granular SNS topics and escalation
Create separate topics for critical failures, approvals, and non-critical notifications. Map topics to teams and integrate via Lambda to Slack or PagerDuty for routing.
Mnemonic: Separate, Route, Escalate
Operational checks
Test alerts with controlled failures
Intentionally break a deploy, verify CloudWatch alarm fires, see EventBridge forward to SNS, and confirm team receives and acknowledges the alert. Then revert changes and document the test.
Dashboard
Single pane of glass
Build CloudWatch dashboards combining PipelineExecutionFailed counts, BuildDuration, and DeploymentSuccess metrics so you can triage quickly.
Escalation
Automatic escalation rules
Implement time-based escalation: initial alert to team channel, then escalate to on-call or PagerDuty if not acknowledged within a window.
