CloudTrail auditing

Record API activity to find who changed roles, policies, or resources that impact CI/CD pipelines.

Investigation checklist
  1. Filter CloudTrail events for the relevant time and service.
  2. Look for API calls like DetachRolePolicy, DeleteRolePolicy, or PutImage failures.
  3. Identify the principal and correlate with pipeline executions and CloudWatch logs.
Example
If ECR push fails, search CloudTrail for ecr:PutImage or authorization token calls that were denied. That shows if a role lacks the required actions or if a policy was removed.
Key Takeaway

CloudTrail is your timeline. Use it to connect configuration changes to pipeline failures and support secure post-incident reviews.
