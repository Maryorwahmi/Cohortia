Assessment Scenario › ECR push Access Denied

Diagnosis steps

  1. Check CloudWatch Logs for the exact Access Denied message and resource names.
  2. Search CloudTrail for failed ECR API calls at the same timestamp.
  3. Use IAM Policy Simulator to test the CodeBuild service role.
  4. Update role policy with required ECR actions and deploy via IaC.
Required ECR actions
ecr:GetAuthorizationToken, ecr:BatchCheckLayerAvailability, ecr:InitiateLayerUpload, ecr:UploadLayerPart, ecr:CompleteLayerUpload, ecr:PutImage.
Key Takeaway

Confirm issues with logs and CloudTrail, validate permissions with the simulator, and apply permanent fixes through IaC to avoid drift.
