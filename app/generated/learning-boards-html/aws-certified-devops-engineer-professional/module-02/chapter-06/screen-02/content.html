Learning Objectives

Learn, understand, and apply monitoring, event rules, auditing, and troubleshooting for CI/CD pipelines.

01
Implement CloudWatch monitoring
Configure logs, metrics, and dashboards for CodePipeline, CodeBuild, and CodeDeploy. This matters because real-time visibility makes failures actionable.
Mnemonic: Metrics + Logs = Insight
VERIFIED COMPETENCY MILESTONE
02
Configure EventBridge rules
Create event patterns for stage and action failures to route to SNS, Lambda, or SQS so your system reacts automatically when problems occur.
Mnemonic: Event → Rule → Action
VERIFIED COMPETENCY MILESTONE
03
Use CloudTrail for auditing
Track API calls to investigate permission changes or resource deletions. Audits help you find root causes and demonstrate compliance.
Mnemonic: Who, When, What
VERIFIED COMPETENCY MILESTONE
04
Apply advanced troubleshooting
Reproduce failures locally, isolate actions, enable verbose logs, and use IAM simulation and CLI inspection to resolve complex pipeline issues.
Mnemonic: Reproduce → Isolate → Verify
VERIFIED COMPETENCY MILESTONE
