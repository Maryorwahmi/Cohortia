CloudWatch Logs

Collect build and deploy output, then query with Logs Insights to surface error patterns and timestamps.

Why use Logs Insights
  • Query multiple log streams for matching error patterns or timestamps.
  • Aggregate counts of errors to detect spikes across builds.
  • Filter by log fields to speed diagnosis of environment-specific issues.
Common-mistake
Relying only on a single stream. Successful diagnosis inspects related streams and correlates timestamps with pipeline stages.
Logs Insights — sample query
fields @timestamp, @message
| filter @message like /ERROR/ or @message like /AccessDenied/
| sort @timestamp desc
| limit 50
Concrete example
If CodeBuild shows a dependency error, query all recent build logs for that error string. A cluster of errors after a time indicates a dependency or network change.
Key Takeaway

Use Logs Insights to search, correlate, and validate fixes. Expand logging only when it helps diagnosis and retain useful indices.
