What to Remember › Key Concepts
Amazon CloudWatch
Monitoring service for logs, metrics, and alarms across pipeline components.
CloudWatch Logs
Collects and stores build and deployment output; queryable with Logs Insights.
CloudWatch Metrics
Time-ordered values like failure counts and build durations used for dashboards and alarms.
Summary

Combine logs, metrics, and alarms with event rules and audits to make CI/CD pipelines observable and operationally resilient.
