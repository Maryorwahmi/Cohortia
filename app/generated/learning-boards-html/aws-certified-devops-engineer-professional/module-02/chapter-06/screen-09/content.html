Process Flow › Troubleshooting Checklist

Checklist

  1. Reproduce the failure locally using Docker or the same environment.
  2. Isolate the pipeline stage or action causing the failure.
  3. Enable verbose logs and inspect agent/process logs.
  4. Use IAM Policy Simulator to validate permissions.
  5. Use AWS CLI calls to retrieve execution and deployment objects for context.
CLI inspection examples
aws codepipeline get-pipeline-execution --pipeline-name MyStaticWebsitePipeline --pipeline-execution-id <id>
aws codebuild batch-get-builds --ids <build-id>
aws codedeploy get-deployment --deployment-id <id>
Common-mistake

Making ad-hoc permission changes in the console without updating IaC. Always fix via your CloudFormation or CDK templates to prevent drift.
