Module 2 › Chapter 2.4 › Learning Objectives — Assessment
Competency Checks
  • Design a multi-stage pipeline with proper artifact names and a defined S3 artifact store.
  • Integrate CodeCommit, CodeBuild, and a deploy provider; demonstrate a successful run.
  • Add a Manual Approval stage and show the pipeline pauses and notifies via SNS.
  • Provide a CloudFormation or CDK template that recreates the pipeline resources.
Common Pitfalls
Mismatched artifact names, insufficient IAM permissions like iam:PassRole, and missing artifact stores are frequent causes of pipeline failure.
Practical Exercise
Build a static website pipeline that deploys index.html to an S3 website bucket, then add a Manual Approval stage before production deploy.
Success Indicator
On commit, pipeline runs, pauses for approval, and after approval your S3 website updates with the new index.html.
