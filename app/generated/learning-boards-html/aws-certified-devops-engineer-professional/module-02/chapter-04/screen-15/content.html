Module 2 › Chapter 2.4 › Quick Reference
Explicit Artifacts
Name InputArtifacts and OutputArtifacts and use an S3 artifact store.
Least-Privilege IAM
Ensure pipeline and provider roles have only the permissions necessary, including iam:PassRole when needed.
Pipeline-as-Code
Use CloudFormation or CDK so pipeline definitions are versioned, repeatable, and auditable.
One-sentence takeaway

Design pipelines with explicit artifacts, least-privilege permissions, and pipeline-as-code to deliver reliably and securely.
