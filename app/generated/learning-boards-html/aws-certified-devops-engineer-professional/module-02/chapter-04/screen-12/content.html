Event-driven Alerts
Configure EventBridge rules for pipeline events and route them to SNS for team alerts or Lambda for automated responses.
Example
Match CodePipeline state change events and notify an SNS topic so reviewers are alerted when approval is required or a stage fails.
Troubleshooting Checklist
  • Check CodeBuild logs in CloudWatch for build failures.
  • Inspect CodeDeploy logs and deployment events for deploy failures.
  • Verify IAM roles for CodePipeline and invoked services; look for iam:PassRole needs.
Common Mistake
Granting overly broad permissions to fix a problem increases risk; instead identify and add only the required actions.
