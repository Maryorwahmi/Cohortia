Learning Objectives
Skill goals and verified milestones
Bloom: Learn → Understand → Apply → Master
01
Design multi-stage pipelines
Map source, build, test, approval, and deploy stages to your application’s release requirements. Practice creating a pipeline diagram for a containerized app to define where tests and approvals run.
VERIFIED COMPETENCY MILESTONE
02
Integrate AWS developer tools
Wire CodeCommit, CodeBuild, and CodeDeploy together and include S3 or Lambda where needed. Understand artifact exchange and provider configuration so stages consume the right outputs.
VERIFIED COMPETENCY MILESTONE
03
Add approvals and custom actions
Implement manual approval gates for controlled releases and design custom actions using Lambda when a third-party tool must run inside the pipeline.
VERIFIED COMPETENCY MILESTONE
04
Manage pipelines as code and monitor them
Author pipelines with CloudFormation or CDK, enable EventBridge events and SNS notifications, and troubleshoot common failures with logs and IAM checks.
VERIFIED COMPETENCY MILESTONE
