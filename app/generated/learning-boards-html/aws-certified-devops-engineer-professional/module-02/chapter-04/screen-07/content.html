Artifact Concepts
Artifacts pass outputs from one action to the next. Use S3 as the artifact store and name artifacts explicitly so InputArtifacts and OutputArtifacts match across actions.
Example
Source action: OutputArtifacts: [SourceOutput]. Build action: InputArtifacts: [SourceOutput], OutputArtifacts: [BuildOutput]. Deploy action: InputArtifacts: [BuildOutput].
Practical Checkpoints
  • Confirm artifact names match exactly between action definitions.
  • Ensure pipeline ArtifactStore references a valid S3 bucket.
  • When skipping build steps, point Deploy to SourceOutput if it contains deployable files.
Common Mistake
Mismatched artifact names cause a silent failure to find inputs and stop the pipeline from progressing.
