Module 2 › Chapter 2.4 › Extending with S3, Lambda & Step Functions
Integration Patterns
S3: artifact store and static website target.
Lambda: implement custom actions that signal success or failure back to CodePipeline.
Step Functions: orchestrate multi-step custom workflows invoked by a custom action.
Misconception
Avoid running heavy compute in Lambda; for sustained compute use CodeBuild or Step Functions with larger compute resources.
Example: Security Scan
Create a custom action that triggers a Lambda which starts a Step Functions workflow to run multiple scanners. The workflow aggregates results and the Lambda calls PutJobSuccessResult or PutJobFailureResult to notify CodePipeline.
Key Takeaway
Extend pipelines with the right AWS service for the job and keep clear contracts for inputs, outputs, and permissions.
