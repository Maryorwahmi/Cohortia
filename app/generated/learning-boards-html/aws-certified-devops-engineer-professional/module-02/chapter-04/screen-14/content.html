Module 2 › Chapter 2.4 › Key Concepts
CodePipeline
Orchestration layer that sequences stages and actions for reliable releases.
Artifacts
Named outputs passed between actions and stored durably in an S3 artifact store.
Approvals & Extensions
Manual approvals for control; Lambda and Step Functions for custom actions and orchestration.
Summary Takeaway

Design pipelines as coordination layers, make artifacts explicit, and use approvals and custom actions to balance automation with control.
