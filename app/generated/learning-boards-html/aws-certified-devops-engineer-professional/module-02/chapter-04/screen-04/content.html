Module 2 › Chapter 2.4 › What is AWS CodePipeline?
Definition & Purpose

CodePipeline provides a visual workflow that models release processes so teams can deliver application and infrastructure changes reliably. It manages transitions between stages and passes artifacts from one action to the next.

Analogy
A conveyor belt with inspection stations: stages are stations, actions are machines performing tasks on artifacts.
Misconception
Do not use CodePipeline as a build runner; delegate builds and tests to CodeBuild or external providers and use CodePipeline to orchestrate them.
Concrete Example
Source: CodeCommit → Build: CodeBuild builds Docker image and outputs to ECR → Test: integration tests → Approval → Deploy: CodeDeploy to ECS.
Key Takeaway

Treat CodePipeline as the coordinator that ensures artifacts flow through validation and deployment steps in a predictable, auditable manner.
