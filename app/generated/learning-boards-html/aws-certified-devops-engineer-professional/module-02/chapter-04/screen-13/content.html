Module 2 › Chapter 2.4 › Static Website Pipeline Activity
Prerequisites & Steps
  1. Create a CodeCommit repo with index.html.
  2. Create an S3 bucket for website hosting and an artifacts bucket for the pipeline.
  3. Create a CodePipeline with Source (CodeCommit) and Deploy (S3) stages.
  4. Add a ManualApproval stage between Source and Deploy and configure SNS notifications if desired.
  5. Commit a change and observe the pipeline pause for approval before deploy.
Terminal Example
aws s3 mb s3://my-pipeline-artifacts-YOUR_ACCOUNT_ID --region YOUR_REGION
# Then create the pipeline in the console or use a CloudFormation template to define stages and artifact store.
Check
After commit the pipeline should start, pause at ManualApproval, and after approval the S3 website should show the updated index.html.
