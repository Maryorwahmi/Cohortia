Module 2 › Chapter 2.4 › Integrating Core Developer Tools
Provider Comparison
CodeCommit — Source
Hosts repository and emits SourceOutput artifact to start the pipeline.
CodeBuild — Build & Test
Runs builds and tests, creates build artifacts or container images and pushes to registries.
CodeDeploy — Deploy
Applies artifacts to compute targets and supports blue/green or in-place strategies.
Example: Docker Microservice
Source commit → CodeBuild builds Docker image, tags and pushes to ECR, produces BuildOutput containing image tag. Deploy stage uses that BuildOutput to update ECS via CodeDeploy and perform traffic shift.
Pro Tip
Include metadata such as image tag in build artifact so the deploy action can reference the exact image to run.
