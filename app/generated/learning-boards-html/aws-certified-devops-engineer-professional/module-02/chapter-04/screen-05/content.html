Module 2 › Chapter 2.4 › Stages and Actions
Pipeline Steps
1
Source
CodeCommit or S3 places SourceOutput artifact for the pipeline.
2
Build & Test
CodeBuild compiles, runs unit tests, and emits BuildOutput or image references.
3
Approval
Manual approval pauses the pipeline and can notify teams via SNS before production deploy.
4
Deploy
CodeDeploy or S3 deploys the validated artifact to the target environment.
Artifact Flow Diagram
Explicit artifact names and run order matter. Example names: SourceOutput → BuildOutput. Configure InputArtifacts and OutputArtifacts so actions can locate the correct files.
Example
A CodeBuild action consumes SourceOutput, runs tests, and produces BuildOutput which Deploy uses.
Common Mistake
Leaving artifact names implicit or mismatched often causes the next action to fail to find its inputs — always name artifacts explicitly.
