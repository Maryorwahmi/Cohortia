Custom Action Pattern
Define a custom action type and implement the execution logic. Use Lambda or an agent to perform the work and call PutJobSuccessResult or PutJobFailureResult.
Example
A proprietary scanner runs in Lambda, produces a report in S3, and signals CodePipeline with success or failure depending on findings.
Design Considerations
  • Handle long-running tasks using Step Functions or asynchronous patterns.
  • Ensure invoked roles have least-privilege permissions only for required resources.
  • Provide clear artifacts or links for auditors to verify the custom action’s outputs.
Common Mistake
Not returning an explicit success or failure causes pipelines to hang or fail unpredictably.
