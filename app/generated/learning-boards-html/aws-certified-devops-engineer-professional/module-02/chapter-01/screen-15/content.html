What to Remember
Prefer roles for automation
Avoid embedding long-lived keys and rotate human credentials.
Enforce branch protection
Use approval rules and IAM denies together for an enforceable policy.
Avoid large binaries
Use S3 or external LFS and implement detection to keep repos lean.
Closing takeaway

Secure identities, enforce review gates, and keep the repository healthy for reliable CI/CD in production environments.
