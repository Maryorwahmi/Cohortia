Module 2 › Chapter 2.1 › Assessment scenarios and common mistakes
Assessment scenarios
Work through the scenario logic and identify the correct CodeCommit and IAM features to use.
Q1: Enforce two approvals and block direct pushes to master
Answer: Create an approval rule template requiring two approvers from SeniorDevs and associate it with the repo. Add IAM deny statements for developers to block direct pushes to refs/heads/master while granting merge permissions to the approver role.
Q2: Large binary pushed to master
Answer: Rewrite history locally with a history-clean tool and force-push the cleaned history, then implement prevention via S3 or pre-push checks. Deleting in a later commit is not sufficient.
Exam strategy
Always map the requirement to CodeCommit features and IAM controls, then describe operational steps including coordination, role updates, and testing. Watch for distractors that suggest only UI changes or optimistic deletion of files.
Key Takeaway

Answer exam questions by specifying both policy enforcement and operational steps; combine IAM, approval rules, and coordinated remediation when needed.
