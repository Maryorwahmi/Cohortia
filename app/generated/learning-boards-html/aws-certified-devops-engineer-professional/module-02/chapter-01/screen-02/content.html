Learning Objectives
Practical capabilities to demonstrate in a lab or exam
Bloom: Learn → Understand → Apply → Master
01
Configure and secure CodeCommit
Create repositories and define fine-grained IAM policies so users have only the permissions they need. This protects branches and eases audits by narrowing allowed actions to specific ARNs and verbs.
VERIFIED COMPETENCY MILESTONE
02
Implement branching strategies
Adopt Gitflow for strict release cycles or GitHub flow for continuous deployment, and enforce consistency through repository conventions. Clear branch roles reduce merge conflicts and deployment risk.
VERIFIED COMPETENCY MILESTONE
03
Use pull requests and approval rules
Require a defined number of approvers or an approval pool for critical branches so merges are gated by reviewers. This enforces quality and compliance before code reaches production branches.
VERIFIED COMPETENCY MILESTONE
04
Integrate CodeCommit with AWS services
Trigger builds, notifications, or Lambdas using EventBridge and CodePipeline so changes flow into automated CI/CD stages. Automation reduces manual steps and accelerates feedback.
VERIFIED COMPETENCY MILESTONE
