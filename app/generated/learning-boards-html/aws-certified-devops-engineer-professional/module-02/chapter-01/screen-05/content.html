Module 2 › Chapter 2.1 › Authentication: IAM, HTTPS Git credentials, and SSH keys
Authentication flow
Match credential type to actor and scope permissions via IAM.
1
Human developers
Use IAM users with HTTPS Git credentials or SSH keys generated for that user. Store and rotate credentials securely.
2
CI/CD systems
Assign an IAM role to the service (CodeBuild, EC2) so it can assume permissions without static keys.
3
Rotation & secrets
Rotate human credentials and store them in secrets managers. Never hard-code access keys in repositories or pipelines.
Supporting cards
Example
A CodeBuild role with scoped codecommit:GitPull permission lets builds clone repos without manual credential handling, simplifying secure automation.
Common mistake
Embedding IAM user keys in scripts. If leaked, rotate immediately and replace with role-based access for services.
Quick checklist
  • Use roles for machines, credentials for humans only when necessary.
  • Enforce rotation and store secrets in a secure manager.
  • Scope policies to repository ARNs and branch refs.
Key Takeaway

Match credential patterns to the actor and prefer temporary, role-based access for automated systems.
