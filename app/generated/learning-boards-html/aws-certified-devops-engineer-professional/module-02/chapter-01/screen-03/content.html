Secure handling, policy design, and maintenance practices
Bloom: Learn → Understand → Apply → Master
05
Manage Git credentials securely
Use IAM-generated HTTPS credentials or SSH keys and rotate them regularly. Prefer IAM roles and temporary credentials for programmatic access in EC2 or CodeBuild.
VERIFIED COMPETENCY MILESTONE
06
Design fine-grained IAM policies
Grant specific CodeCommit actions on repository ARNs and branch references to enforce least privilege for developers and leads. Scoped policies reduce accidental destructive actions.
VERIFIED COMPETENCY MILESTONE
07
Identify and mitigate security risks
Avoid embedding access keys in scripts and prefer roles with temporary credentials. Use approval rules and monitoring to detect suspicious activity quickly.
VERIFIED COMPETENCY MILESTONE
08
Manage large files and repository health
Plan for large binary assets by using S3 references or cleaning history with tools, and monitor storage to avoid performance issues when cloning or fetching.
VERIFIED COMPETENCY MILESTONE
