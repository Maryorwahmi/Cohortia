Step-by-step debugging
  1. Open CloudWatch logs for the build run and find the failing timestamp.
  2. Read the failing command output and exit code to identify the error.
  3. Check buildspec syntax, artifact and cache paths, and runtime-versions.
  4. Confirm the service role has required IAM permissions for S3, ECR, and other services.
  5. Iterate: fix the smallest item and re-run to confirm the resolution.
Common examples
"command not found" → missing tool in runtime; "Cache not found" → wrong path or permissions; "AccessDenied" → update service role policy.
Pro tip
Make a reproducible failing build with minimal steps so the logs show only the necessary output to diagnose the issue quickly.
