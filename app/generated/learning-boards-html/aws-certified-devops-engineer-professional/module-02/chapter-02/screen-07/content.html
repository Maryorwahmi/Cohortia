Module 2 › Chapter 2.2 › Example buildspec for Node.js
Why this example works
  • Runtime version ensures node behavior is consistent across builds.
  • Separate phases make failures easier to locate: install vs build vs post_build.
  • Cache path for npm reduces install time when restored.
Troubleshooting hint
If you see "Cache not found" check IAM permissions and that the build project cache configuration points to the correct S3 bucket and prefix.
buildspec.yml (copyable)
version: 0.2
phases:
  install:
    runtime-versions:
      nodejs: 18
    commands:
      - echo "Installing dependencies..."
      - npm install
  pre_build:
    commands:
      - echo "Running linting and security checks..."
      - npm run lint
  build:
    commands:
      - echo "Building application..."
      - npm run build
      - echo "Running unit tests..."
      - npm test
  post_build:
    commands:
      - echo "Packaging artifacts..."
      - cp -r build/* .
artifacts:
  files:
    - '**/*'
  base-directory: 'build'
cache:
  paths:
    - '/root/.npm/**/*'
