Module 2 › Chapter 2.2 › What is AWS CodeBuild?
Core definition

CodeBuild compiles source code, runs tests, and generates artifacts. It provides on-demand compute and avoids managing build servers.

Analogy
Think of CodeBuild like a rental build machine you script: you provide the recipe, and CodeBuild runs it, scales as needed, then returns the output.
Common misconception
It is not an orchestrator by itself. Use CodePipeline or other tools to coordinate stages.
Quick scenario
A push to your repository triggers a pipeline. CodeBuild checks out the code, runs install and build commands defined in buildspec.yml, executes tests, and places the artifact in S3 for deployment.
Key takeaway
Key Takeaway

CodeBuild automates builds at scale; you must provide the build recipe and environment to make builds reproducible and secure.
