Module 2 › Chapter 2.2 › Key Concepts
AWS CodeBuild
Managed CI service that compiles code, runs tests, and produces artifacts.
Build Environment
Managed images or custom Docker images holding runtimes and tools.
buildspec.yml
Defines install, pre_build, build, post_build, artifacts, and cache settings.
Summary takeaway

Design environments intentionally, write clear buildspecs, and use caching and logs to make builds faster and easier to debug.
