Managed images

Provide common runtimes quickly for Java, Node.js, Python, Go, .NET, and Docker. They minimize setup but may not contain every build tool your project needs.

When to use custom Docker
  • Pre-install proprietary tools, compilers, or exact tool versions.
  • Remove repeated install time by baking dependencies into the image.
  • Store the image in ECR and reference it from CodeBuild.
Security note
Scan custom images for vulnerabilities and build from trusted base images to reduce risk.
Architecture sketch
Managed image: Quick start, no image maintenance.
Custom image in ECR: preinstalled tools, reproducible environment.
Trade-off: image size affects startup time; keep images lean.
Key takeaway
Key Takeaway

Choose managed images for convenience and custom images for control, optimizing image size to reduce build startup time.
