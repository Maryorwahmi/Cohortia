Scenario 1: missing build tool
If the install phase fails with "mvn not found" despite runtime version set, install Maven in the install phase or use a custom image with Maven preinstalled. Verify by running a build and checking CloudWatch logs for the install output.
Scenario 2: cache not restored
"Cache not found" suggests incorrect cache.paths, wrong S3 configuration, or missing s3 permissions. Verify cache path, check the CodeBuild project cache settings, and ensure the service role has s3:GetObject and s3:PutObject.
Quick checklist
Read the logs carefully, confirm buildspec paths, inspect the service role policies, validate S3 bucket and prefix, and iterate with small changes to isolate the root cause.
