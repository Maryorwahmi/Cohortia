Module 2 › Chapter 2.2 › Learning Objectives
01
Design custom build environments
Create managed or custom Docker images with required runtimes and tools so builds match your development environment. Keep images lean to reduce startup time and scan them for vulnerabilities.
VERIFIED COMPETENCY MILESTONE
02
Master buildspec.yml
Author phases: install, pre_build, build, post_build plus artifacts and cache paths so the build executes reliably and artifacts are collected.
VERIFIED COMPETENCY MILESTONE
03
Optimize performance & cost
Use S3 or local caches for dependencies and choose an appropriate compute type to balance speed and cost; avoid oversized instances for simple builds.
VERIFIED COMPETENCY MILESTONE
04
Integrate & troubleshoot builds
Connect CodeBuild to CodePipeline and grant the least-privilege IAM role it needs. Use CloudWatch logs to find failing commands and missing permissions.
VERIFIED COMPETENCY MILESTONE
