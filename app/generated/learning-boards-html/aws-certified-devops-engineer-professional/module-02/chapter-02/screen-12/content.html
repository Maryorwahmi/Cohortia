Module 2 › Chapter 2.2 › Hands-on Activity
Steps
  1. Create my-nodejs-app with package.json and index.js and commit to CodeCommit.
  2. Add buildspec.yml with install/build/post_build and cache.paths for /root/.npm.
  3. Create an S3 bucket for artifacts and cache.
  4. Create CodeBuild project my-nodejs-build, select managed image, set S3 cache, and assign a service role with S3 and CloudWatch permissions.
  5. Run the build once, then run again and observe "Restoring cache..." to confirm speed-up.
Example files
package.json
{
  "name": "my-app",
  "version": "1.0.0",
  "scripts": {"start": "node index.js","test": "echo \"No tests specified\" && exit 0"},
  "dependencies": {"express": "^4.17.1"}
}

index.js
const express = require('express');
const app = express();
const port = 3000;
app.get('/', (req, res) => { res.send('Hello from CodeBuild Node.js App!'); });
app.listen(port, () => { console.log(`App listening at http://localhost:${port}`); });
Follow the activity to see caching reduce the install phase and to learn how to check CloudWatch logs and S3 cache artifacts.
