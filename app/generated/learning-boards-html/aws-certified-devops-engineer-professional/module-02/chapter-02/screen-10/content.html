Module 2 › Chapter 2.2 › Integrate & Roles
Pipeline flow
Source stage → CodeBuild action → Artifacts to S3 or ECR → Deploy stage. CodeBuild acts on the artifact provided by the source stage and passes outputs to later stages.
Service role checklist
  • Permissions for source access (CodeCommit, S3, or GitHub).
  • S3 Put/Get for artifacts and cache.
  • ECR push/pull if building images.
  • CloudWatch Logs permissions to stream build logs.
Troubleshooting role errors
If builds fail with permission errors, inspect CloudWatch logs for denied actions, then tighten or extend the role policy to grant only the required actions. Avoid wild-card permissions when possible.
Key takeaway
Key Takeaway

Integrate CodeBuild into CodePipeline for automation and use a least-privilege service role to enable required actions while reducing risk.
