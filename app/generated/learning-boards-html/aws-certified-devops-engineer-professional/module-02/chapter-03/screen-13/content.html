Hands-on Activity
Blue/Green Walkthrough — Lab steps
Starter checklist
  • Create my-web-app with index.html version 1 and an AppSpec at the root.
  • Place scripts/install_nginx.sh, start_nginx.sh, and validate_nginx.sh in scripts/ and make them executable.
  • Zip app-v1.zip and upload to S3, then perform an initial deployment to Blue instances behind an ALB.
  • Update index.html to Version 2, zip app-v2.zip, change deployment group to blue/green, configure GreenTargetGroup, and deploy.
Observe the console timeline as CodeDeploy provisions green instances (or replaces task set), runs install and ValidateService hooks, and reroutes traffic. If ValidateService fails, CodeDeploy will roll back, demonstrating an automated safety net.
Mini-challenge
Modify ValidateService to check a specific HTML token present only in v2. Deploy v2 and observe whether the validation distinguishes the versions as expected.
Key Takeaway

Hands-on practice exposes common pitfalls like missing execute bits, wrong script paths, and insufficient IAM permissions more quickly than theory alone.
