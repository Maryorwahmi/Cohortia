Core Concept What is CodeDeploy?
CodeDeploy in one sentence
A managed orchestration service that deploys revisions to EC2, ECS, Lambda, and on-premises targets while running lifecycle hooks and coordinating traffic shifts.
Repeatable deployments with a revision and deployment history.
Lifecycle hooks to validate, start, and clean up during deployments.
Integration with CloudWatch for alarms and automatic rollback triggers.
Key Takeaway

Treat CodeDeploy as an execution engine: focus on robust hooks and monitoring, not just file transfer.

Concrete example
Deploy a static web bundle from S3 to EC2 instances. AppSpec copies files, AfterInstall starts the web server, ValidateService checks the HTTP endpoint, and CodeDeploy will rollback if validation fails.
Common misconception
Do not assume CodeDeploy fixes broken application scripts. If your lifecycle scripts fail or lack permissions, the deployment will fail and rollback may be triggered.
