Designing ValidateService
Best practices
  • Check a real user-facing endpoint and validate the response body.
  • Use retries with exponential backoff during startup windows.
  • Fail explicitly with non-zero exit codes on functional regressions.
  • Emit detailed logs so script failures are diagnosable from agent logs.
Example snippet
A ValidateService script that curls http://localhost, checks for an HTTP 200 code, and optionally verifies a response token or JSON key gives higher confidence than a simple process check.
Common mistake: returning success when the endpoint is reachable but returns an error page. Validate content, not just connectivity.
