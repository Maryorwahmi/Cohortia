AppSpec Structure & Hooks
Example AppSpec (EC2/on-premises)
version: 0.0
os: linux
files:
  - source: /
    destination: /var/www/html/my-app
hooks:
  BeforeInstall:
    - location: scripts/install_dependencies.sh
      timeout: 300
      runas: root
  AfterInstall:
    - location: scripts/start_application.sh
      timeout: 300
      runas: root
  ApplicationStop:
    - location: scripts/stop_application.sh
      timeout: 60
      runas: root
    - location: scripts/cleanup.sh
      timeout: 60
      runas: root
  ValidateService:
    - location: scripts/validate_service.sh
      timeout: 180
      runas: root
Hook guidance
  • Make hooks idempotent and tolerant to partial state.
  • Set realistic timeouts to avoid stalled deployments.
  • Run ValidateService as a strong end-to-end health check, not a superficial check.
  • Ensure scripts have executable permissions and correct paths.
Key Takeaway

AppSpec defines the deployment contract. Treat it as code: test, lint, and validate hooks before production use.
