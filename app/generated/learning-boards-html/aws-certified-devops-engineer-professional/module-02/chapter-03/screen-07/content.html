Process Flow
Blue/Green Deployment Steps
1. Provision green
New instances, task set, or function version.
2. Deploy & run hooks
Install, start, and validate scripts run in green.
3. Verify health
Run end-to-end checks and watch CloudWatch alarms.
4. Shift traffic
Switch ALB listener or update Lambda alias to route to green.
Example: Using an ALB with BlueTargetGroup and GreenTargetGroup, deploy v2 to the green target group, validate with health checks and integration tests, then reroute the listener. If alarms trip, reroute back to blue immediately.
Why it matters
Blue/green minimizes user impact and provides an instant fallback to the previously known good environment. It is ideal for high-availability services and schema-incompatible changes.
Common mistake
Skipping robust ValidateService checks. Superficial or missing checks can let a broken green environment receive live traffic and require a costly rollback.
