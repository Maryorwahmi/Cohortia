Module 2 › Chapter 2.3 › Learning Objectives
Apply these skills in a release
  • • Create a deployment group using instance tags or an Auto Scaling group to scope targets.
  • • Write AppSpec hooks that install dependencies, start the app, and validate health using real checks.
  • • Configure CloudWatch alarms for error rate or latency and link them to CodeDeploy for automatic rollback.
  • • Inspect agent logs and the deployment timeline to pinpoint lifecycle hook failures and script output.
Mnemonic
TAG → GROUP → HOOK → ALARM. Use tagging to target, group to scope, hooks to run checks, and alarms to protect.
