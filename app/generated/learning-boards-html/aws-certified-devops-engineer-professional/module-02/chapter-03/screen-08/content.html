Canary Deployment Pattern
Staged traffic shift
Step 1: Shift 10% of traffic and observe for N minutes.
Step 2: If healthy, shift a larger portion, then observe again.
Step 3: Complete rollout when metrics look stable.
Example: ECS service with CodeDeploy moves 10% traffic to a new task set for 5 minutes. CloudWatch alarm monitors 5XX errors. If alarm enters ALARM state, CodeDeploy rolls back to previous task set automatically.
Monitoring tips
  • Monitor error rates, latency, and healthy host counts.
  • Set short evaluation windows during the canary step to reduce exposure time.
  • Use synthetic checks to supplement real-user metrics.
Warning: Canary without alarms provides little protection. The value is in early detection and automated rollback.
