Troubleshooting Steps
Step-by-step
  1. Open CodeDeploy console and inspect the deployment timeline for failing hooks and instance IDs.
  2. SSH into affected EC2 instances and open agent logs under /opt/codedeploy-agent/deployment-root/.
  3. Review script stdout/stderr logs in the per-deployment logs folder to see exact errors.
  4. For ECS/Lambda, open CloudWatch Logs for task or function output and inspect recent invocations.
  5. Fix scripts, permissions, or IAM roles, then redeploy in staging before production.
Common root causes
  • AppSpec syntax errors or incorrect file paths.
  • Scripts missing execute permission or incorrect runas user.
  • Missing dependencies or network access for validation steps.
  • Insufficient IAM permissions for CodeDeploy service role.
Pro tip: add verbose logging to ValidateService and capture environment variables to speed diagnosis.
