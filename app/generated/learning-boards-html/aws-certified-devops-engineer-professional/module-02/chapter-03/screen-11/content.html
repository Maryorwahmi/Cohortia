Process
Automated Rollbacks
Architecture
Deploy → ValidateService → Monitor CloudWatch alarms → If alarm, trigger rollback. For blue/green, rollback means shifting ALB traffic back to blue. For Lambda canary, revert alias. For ECS, revert task set.
Use error-rate or 5XX metrics for user-visible failures.
Set short evaluation windows during canary steps to shorten exposure.
Test rollback behavior in staging to confirm end-to-end behavior.
Practical checklist
  • Attach CloudWatch alarms to the deployment group and specify thresholds.
  • Ensure CodeDeploy service role has permission to read alarm state.
  • Choose metrics that reflect real user impact, not internal counters only.
Pitfall: alarms that trigger too late or are mis-scoped will not protect users; tune both metric and scope carefully.
