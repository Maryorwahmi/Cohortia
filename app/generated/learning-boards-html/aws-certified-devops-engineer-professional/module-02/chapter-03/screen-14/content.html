Key Concepts
Applications & Groups
Logical application container and deployment groups map to targets and load balancers.
AppSpec & Hooks
YAML file that copies files and runs lifecycle scripts; ValidateService must validate real behavior.
Deployment Strategies
Choose concurrency and traffic-shift models: AllAtOnce/OneAtATime/HalfAtATime, blue/green, canary with alarms for rollback.
Summary takeaway
Design deployments as code: scope targets precisely, write robust AppSpec hooks that validate real functionality, and wire monitoring to enable safe automated rollbacks.
