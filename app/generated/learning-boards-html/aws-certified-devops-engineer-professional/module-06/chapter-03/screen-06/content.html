Module 6 › Chapter 6.3 › Triggers: CloudWatch vs EventBridge
Direct CloudWatch Alarm
Quick and simple: alarm action invokes Automation document when state changes.
Setup: add SSM document as an alarm action.
Pros: low-latency, simple mapping.
Cons: limited filtering and transformation.
EventBridge Rule
Flexible routing: filter alarms, enrich events, call multiple targets, and map parameters into InputTemplate.
Use case
Send alarm to EventBridge, match by AlarmName, and invoke Automation with InputTemplate to set InstanceId parameter.
Benefits
Filtering, enrichment, retries, and ability to trigger multiple targets such as notifications or follow-up audits.
Example InputTemplate: {"InstanceId":"","ServiceName":"myapp"}
Key Takeaway

Choose EventBridge when you need filtering, enrichment, or multi-target orchestration; use direct alarms for fast, simple triggers.
