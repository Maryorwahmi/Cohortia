Module 6 › Chapter 6.3 › Key Concepts
Automation Documents
Structured YAML/JSON runbooks with parameters, steps, and failure rules for repeatable tasks.
Event Integration
CloudWatch alarms can call documents directly or route through EventBridge for filtering and enrichment.
Automation Assume Role
The IAM role SSM assumes must be narrowly scoped; use approvals for high-risk actions.
Takeaway
Combine well-designed runbooks, EventBridge orchestration, and least-privilege roles to build reliable, auditable self-healing systems.
