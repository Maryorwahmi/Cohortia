Verified Competency Milestones at each card
01
Design Runbooks
Author YAML or JSON documents with parameters, steps, and failure behavior. Practice writing a restart service runbook and version it for testing.
VERIFIED COMPETENCY MILESTONE
02
Invoke Actions Safely
Use actions like aws:runCommand and aws:changeInstanceState with timeouts and outputs. Verify idempotency during retries.
VERIFIED COMPETENCY MILESTONE
03
Event Integration
Wire CloudWatch alarms to EventBridge or direct alarm actions. Learn how EventBridge allows filtering and post-processing before invoking Automation.
VERIFIED COMPETENCY MILESTONE
04
Secure Execution
Create an Automation Assume Role with least privilege, consider aws:approve steps for critical actions, and test rollbacks before production deployment.
VERIFIED COMPETENCY MILESTONE
