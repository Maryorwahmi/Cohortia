Automated Remediation with Systems Manager Automation
Define runbooks in YAML or JSON to detect, respond, and self-heal production incidents.

Automation documents let you sequence actions such as running shell commands, restarting instances, applying patches, or calling other AWS services. They are idempotent, versionable, and can be invoked manually, by CloudWatch alarms, or through EventBridge for flexible event routing.

We will explore document structure, common actions like aws:runCommand and aws:changeInstanceState, integration patterns, and security best practices for the Automation Assume Role.
