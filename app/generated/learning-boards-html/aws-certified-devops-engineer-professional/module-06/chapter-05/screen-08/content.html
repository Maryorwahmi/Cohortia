Trust Policy

Define who can assume the role and under which conditions like MFA and ExternalId.

{
  "Statement": [
    {
      "Effect": "Allow",
      "Principal": {"AWS": "arn:aws:iam::111122223333:root"},
      "Action": "sts:AssumeRole",
      "Condition": {"Bool": {"aws:MultiFactorAuthPresent": "true"}}
    }
  ]
}
Permissions Policy

Attach a permissions policy that precisely lists actions the responder needs when operating in the target account.

Example actions commonly granted for diagnostics:
  • ec2:DescribeInstances
  • cloudwatch:GetMetricData
  • ssm:StartAutomationExecution
Operational controls
  • Set maximum session duration for the role.
  • Log assume-role and API activity in CloudTrail and alert on unusual patterns.
  • Avoid AdministratorAccess and use permission boundaries where needed.
