Module 6 › Chapter 6.5 › STS & Temporary Credentials
Definition

Temporary credentials via STS

Assume a role to obtain temporary, limited-privilege credentials that expire automatically.

CLI profile example
[profile cross-account-ir]
role_arn = arn:aws:iam:::role/CrossAccountIncidentResponder
source_profile = default
mfa_serial = arn:aws:iam:::mfa/your-mfa-device
Run the command and enter an MFA code when prompted to receive temporary credentials for the session.
Practical notes
  • Avoid long-lived access keys for responders; prefer assume-role flows.
  • Use tools like aws-vault to manage session injection and MFA prompts securely.
  • Ensure session duration is appropriately short for the task and logged.
Common mistake
Embedding temporary credentials in automation without rotation and expiry monitoring.
Key Takeaway

Temporary credentials plus MFA reduce long-lived key exposure and improve auditability of assume-role events.
