Module 6 › Chapter 6.5 › Least Privilege
Core Concept

Least privilege for responders

Create narrowly scoped roles for specific tasks and avoid AdministratorAccess during an incident.

Why it matters
Reduces attack surface if credentials are compromised during a stressful incident.
Common mistake
Granting AdministratorAccess because it seems faster; it exposes critical resources unnecessarily.
Key Takeaway

Plan several narrowly scoped responder roles by task and force temporary sessions to limit exposure.

Definition
Example role: EC2 diagnostics
  • ec2:DescribeInstances
  • ssm:StartSession
  • cloudwatch:GetMetricData
Analogy

Think of roles as task-specific keys. Give the key that opens only the doors necessary for that job.

Practical checklist
  • Create multiple narrow roles for common IR tasks.
  • Use permission boundaries where appropriate.
  • Require MFA and temporary sessions for elevated roles.
