Advanced Objectives

Move from configuration to verification and operational controls.

Practice-ready milestones
01
Audit role usage

Ensure CloudTrail logs assume-role and privileged API calls so you can reconstruct events during a forensic review.

Verified competency milestone
02
Design break-glass access

Create emergency roles that require approvals, logging, and time-limited sessions to minimize misuse risk.

Verified competency milestone
03
Mitigate common IR mistakes

Address over-privilege, long-lived keys, missing logs, and neglected SCPs through governance and reviews.

Verified competency milestone
04
Test assume-role flows

Verify that MFA is required, sessions expire as expected, and SCPs continue to block prohibited actions during tests.

Verified competency milestone
