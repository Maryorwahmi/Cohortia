Securing Incident Response

Implement least privilege, enforce MFA for role assumption, apply temporary credentials, and use SCPs to guard production accounts.

In this lesson
MFA enforcement
Cross-account roles
SCP guardrails
Principle
Least Privilege

Limit responder permissions to only what is required and make access temporary.

Mechanism
MFA + STS

Require MFA in trust policies and use STS to issue temporary credentials at assume-time.

Guardrail
Service Control Policies

SCPs set org-wide boundaries that even privileged roles cannot bypass.
