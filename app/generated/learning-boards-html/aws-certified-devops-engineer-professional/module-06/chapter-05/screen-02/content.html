Learning Objectives

Use these objectives to guide hands-on practice and verification.

Bloom: Learn → Understand → Apply → Master
01
Implement least privilege for responders

Configure roles that only permit the specific actions responders need and plan permission boundaries so escalation is prevented.

Verified competency milestone
02
Design cross-account access with trust policies

Create target-account roles with trust policies that allow the security account to assume them under defined conditions like MFA and external IDs.

Verified competency milestone
03
Enforce MFA and temporary credentials

Require aws:MultiFactorAuthPresent and use STS sessions so credentials are short-lived and harder to compromise.

Verified competency milestone
04
Apply SCPs to create guardrails

Use Organization SCPs to prevent destructive actions like deleting logs or disabling detection services across production accounts.

Verified competency milestone
