Configure cross-account role with MFA

Follow these steps in your primary and target accounts to validate MFA-based assume-role.

Primary account
  1. Enable MFA on your IAM user.
  2. Attach policy allowing sts:AssumeRole on the target role ARN.
Target account
  1. Create CrossAccountIncidentResponder role.
  2. Attach trust policy requiring aws:MultiFactorAuthPresent.
  3. Attach scoped permissions for diagnostics and SSM automation.
CLI test
[profile cross-account-ir]
role_arn = arn:aws:iam:::role/CrossAccountIncidentResponder
source_profile = default
mfa_serial = arn:aws:iam:::mfa/your-mfa-device

# Then run:
aws ec2 describe-instances --profile cross-account-ir --region
If you skip the MFA code the assume-role call fails; with MFA it succeeds and issues temporary credentials logged in CloudTrail.
