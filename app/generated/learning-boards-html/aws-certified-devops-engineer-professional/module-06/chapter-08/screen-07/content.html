Module 7 › Chapter 6.8 › Backup & Restore
Process steps
  1. Schedule and verify backups for EBS, RDS, and S3 assets on a suitable cadence.
  2. Replicate backups to a DR region using cross-region replication or copy workflows.
  3. Maintain AMIs and configuration scripts for quick rebuilds in the DR region.
  4. In an incident, provision resources, restore from backups, and update DNS to point to new endpoints.
Example

Use automated daily RDS snapshots and S3 replication, then run a quarterly restore drill to a separate account to validate recovery procedures.

Trade-offs & tips
  • Cost: Low. Recovery speed: Slower.
  • Must automate restores to lower manual errors and measure actual RTO.
  • Keep AMIs and infra-as-code up to date with production.
Common mistake

Backups that are not tested for restore, or missing configuration needed to boot restored systems.
