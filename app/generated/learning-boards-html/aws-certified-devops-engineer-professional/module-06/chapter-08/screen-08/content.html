Module 7 › Chapter 6.8 › Pilot Light
Architectural pattern
Pilot Light maintains a small, running set of core services and artifacts in the DR region. These are the foundation you scale in an incident.
Keep running

Database replicas, configuration management, and pre-baked AMIs.

Scale on demand

Use CloudFormation and Auto Scaling to build out the environment.

Operational notes
  • Perform periodic drift detection on AMIs and configurations.
  • Automate scale-up workflows to reduce manual steps during failover.
  • Secure pilot light resources to match production controls.
Key takeaway

Pilot Light reduces cost while enabling faster recovery than cold restores, but requires active maintenance and automation.
