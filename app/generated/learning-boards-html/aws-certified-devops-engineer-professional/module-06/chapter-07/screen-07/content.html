Lambda: parse, enrich, send
This example shows the core parsing and Slack post flow. Use Secrets Manager in production.
import json
import os
import urllib.request

SLACK_WEBHOOK_URL = os.environ['SLACK_WEBHOOK_URL']

def lambda_handler(event, context):
  print(f"Received event: {json.dumps(event)}")

  message = json.loads(event['Records'][0]['Sns']['Message'])
  alarm_name = message.get('AlarmName')
  new_state = message.get('NewStateValue')
  reason = message.get('NewStateReason')
  instance_id = "N/A"
  if 'Trigger' in message and 'Dimensions' in message['Trigger']:
    for dim in message['Trigger']['Dimensions']:
      if dim.get('name') == 'InstanceId':
        instance_id = dim.get('value')
        break

  slack_message = {
    "text": f"🚨 *AWS Incident Alert: {alarm_name}* 🚨
State: `{new_state}`
Reason: `{reason}`
Affected Instance: `{instance_id}`
Link: {message.get('AlarmArn')}`"
  }

  req = urllib.request.Request(SLACK_WEBHOOK_URL, data=json.dumps(slack_message).encode('utf-8'),
                               headers={'Content-Type': 'application/json'})
  with urllib.request.urlopen(req) as response:
    response.read()

  return {'statusCode': 200, 'body': json.dumps('Message sent to Slack!')}
Explanation
• The function parses the SNS record and extracts alarm fields. It looks for an InstanceId in trigger dimensions.
• It creates a concise Slack payload with emoji and code-style fields so responders can scan quickly.
• In production, replace environment secrets with Secrets Manager, add retries, and handle HTTP errors in try-except blocks.
• Use CloudWatch Logs to verify the Lambda received the correct SNS payload and troubleshoot delivery failures.
Scenario
After deployment, trigger your test alarm and confirm a formatted Slack message arrives with the expected fields.
Common mistake
Hardcoding webhook URLs or not catching HTTP failures may cause lost alerts.
Key Takeaway

Keep enrichment focused, secure credentials, and add error handling so alerts are reliable.
