Process
Design a notification strategy
Balance urgency and noise so responders stay effective.
Prioritize: separate critical from informational alerts with different topics and channels.
Escalate: configure PagerDuty or Opsgenie policies to escalate when pages are unacknowledged.
Suppress: pause non-critical alerts during maintenance windows to avoid noise.
Enrich: include context so responders need fewer lookups.
Key Takeaway

Clear priorities and regular testing keep alerts meaningful and reduce fatigue.

Design checklist
  • • Create separate SNS topics for critical and non-critical alerts.
  • • Route critical alerts to PagerDuty and to Slack via Lambda for context.
  • • Use maintenance windows to suppress noisy non-critical alerts.
  • • Run periodic end-to-end tests to validate routing and escalation.
Example flow
Critical alarm → 'critical' SNS topic → PagerDuty webhook + Lambda for Slack enrichment.
