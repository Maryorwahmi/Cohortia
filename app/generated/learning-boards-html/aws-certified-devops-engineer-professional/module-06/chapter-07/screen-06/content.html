Definition
Event enrichment with Lambda
Use Lambda to add tags, links, and summaries so responders can act without extra lookups.
• Query EC2 tags or AWS Resource Groups for owner and service name.
• Attach a permalink to dashboards or runbooks for fast context.
• Include concise error messages or recent metric values to prioritize actions.
• Avoid adding large logs inline; prefer links to logs when possible.
Analogy
Think of enrichment as attaching a one-paragraph incident summary to a pager message so the responder knows what to do first.
Key Takeaway

Add only what helps decisions: owner, affected resource, short reason, and a link to diagnostics.

Enrichment patterns
Lookup tags
Fetch EC2 or autoscaling tags to identify owner or service.
Attach metrics
Include recent CPU or error-rate snapshots to help triage.
Add links
Provide a dashboard or runbook link so the responder can act immediately.
