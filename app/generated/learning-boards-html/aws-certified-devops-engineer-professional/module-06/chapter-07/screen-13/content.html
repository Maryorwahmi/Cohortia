Hands-on Activity
Deploy Slack Notifier Lambda
Follow these steps in your terminal and AWS console to build the pipeline.
  1. Create a Slack incoming webhook for your channel and copy the URL.
  2. Deploy the Python Lambda (slack_notifier.py) and set SLACK_WEBHOOK_URL as an environment variable.
  3. Subscribe the Lambda to your IncidentResponseTopic using the SNS subscribe command and add permission for SNS to invoke Lambda.
  4. Trigger the High-CPU-Webserver-Alarm and inspect CloudWatch Logs and Slack channel for the enriched message.
Terminal hints
aws sns subscribe --topic-arn <YOUR_TOPIC_ARN> --protocol lambda --notification-endpoint arn:aws:lambda:<REGION>:<ACCOUNT>:function:SlackNotifierLambda

aws lambda add-permission --function-name SlackNotifierLambda --statement-id SNSTopicInvoke --action lambda:InvokeFunction --principal sns.amazonaws.com --source-arn <YOUR_TOPIC_ARN>
Testing
Publish test messages and confirm Slack content and CloudWatch logs match expectations.
Security note
Use Secrets Manager for production webhook secrets and grant minimal permissions to the Lambda role.
