Core Concept
SNS as the central hub
A single topic can deliver the same alarm to multiple destinations and protocols.
• Decouples alarm producers from consumers so you can change subscribers without updating alarms.
• Supports multiple protocols: email, SMS, HTTP/S, Lambda, and more.
• Use separate topics by severity or service to simplify routing and policy management.
Example
Publish a high-severity alarm to a 'critical' SNS topic with PagerDuty and Slack subscribers.
Common mistake
Using one topic for all alarms, which makes severity filtering and policy management harder.
Key Takeaway

Use SNS to centralize delivery and then add Lambda subscribers for enrichment or custom formatting.
