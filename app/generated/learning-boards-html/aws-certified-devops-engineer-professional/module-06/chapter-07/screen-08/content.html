Definition
Webhooks and API Gateways
Webhooks accept POSTs; API Gateway adds control, validation, and auth for custom endpoints.
• Webhooks are convenient for third-party services that provide a URL to receive alerts.
• If the service expects a specific schema, use Lambda to reformat SNS messages first.
• API Gateway is useful for internal routers where authentication, validation, or throttling is required.
Example
Use API Gateway + Lambda to validate incoming payloads and forward to multiple internal services.
Pitfall
Assuming SNS format matches webhook expectations; always validate and test the POST body.
Quick checklist
  • • Confirm the expected JSON schema for the webhook.
  • • If needed, subscribe a Lambda to SNS to translate the payload.
  • • Use API Gateway when you need auth, input validation, or throttling.
  • • Ensure endpoints are reachable and supported by the third-party tool.
Why it matters

Correctly formatted webhooks ensure third-party tools receive alerts immediately and reliably.
