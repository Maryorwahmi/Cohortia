Module 6 › Chapter 6.2 › Event Targets
Lambda — Enrich & Notify
Use for lightweight enrichment, transformations, and direct API calls to ticketing or chat systems.
Step Functions — Orchestration
Use for multi-step remediation, waits, approvals, and retries with visible state history.
SQS / Kinesis — Durable queues
Route events to queues when you need reliable, backpressure-friendly processing at scale.
Concrete pattern
EventBridge receives CloudWatch alarm events, a Lambda enriches and formats them, Step Functions handles escalation with multiple steps, and SQS ensures reliable retries for long-running workers.
Operational reminder

Always grant least privilege to EventBridge and targets, and design handlers to be idempotent because events may be delivered more than once.
