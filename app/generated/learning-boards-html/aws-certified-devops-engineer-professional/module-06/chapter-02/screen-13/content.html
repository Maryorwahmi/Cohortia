Module 6 › Chapter 6.2 › Naming & Patterns
Best practices
Naming
Include service, component, metric, and purpose in alarm names. Keep namespaces consistent.
Thresholds
Use anomaly detection for fluctuating metrics. Use metric math for ratios and normalization.
Event Patterns
Match structured fields and avoid brittle identifiers. Test patterns with sample events.
Documentation
Embed runbook links and owner information in alarm descriptions or enrich events so responders have immediate context.
Operational checklist

Use test events, simulate alarms, confirm EventBridge matches, and verify targets process and log events. Automate these checks in CI where possible.
