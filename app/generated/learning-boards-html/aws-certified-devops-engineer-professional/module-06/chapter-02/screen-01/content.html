Automating Incident Detection
From derived metrics to routed events — build alerting that acts.
Interactive 16:9 Masterclass
This chapter shows you how metric math, anomaly detection, and composite alarms reduce noise, and how EventBridge acts as the central router that transforms alarms into automated responses like enrichment, ticketing, or self-healing.
Visual Concept
Metric Math produces derived signals, e.g., error rate.
Anomaly Detection defines a dynamic band for expected values.
What EventBridge Adds
EventBridge receives alarm state-change events, matches them with event patterns, and routes to Lambda, Step Functions, SQS, or another event bus for orchestration and enrichment.
