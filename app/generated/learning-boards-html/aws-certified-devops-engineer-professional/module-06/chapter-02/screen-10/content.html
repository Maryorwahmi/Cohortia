Module 6 › Chapter 6.2 › EventBridge → Lambda
Design the rule
Match CloudWatch alarm state change events for a specific alarm and route to a Lambda target that enriches and forwards events.
Important elements:
  • Precise event pattern to avoid noisy matches.
  • Target Lambda with proper invoke permission.
  • Input transformer to send only necessary fields if desired.
Lambda example (Python)
def lambda_handler(event, context):
    # Log and enrich the incoming EventBridge event
    print("Received event:")
    print(event)
    # Example enrichment: add runbook link and instance metadata
    enriched = {
        'alarm': event.get('detail', {}).get('alarmName'),
        'state': event.get('detail', {}).get('state', {}).get('value'),
        'runbook': 'https://runbooks.example.com/incident-123'
    }
    print('Enriched event:', enriched)
    return {'statusCode': 200, 'body': 'Enriched event processed'}
Keep the handler idempotent and small. For complex orchestration use Step Functions as the target instead of embedding long pipelines in a single Lambda.
