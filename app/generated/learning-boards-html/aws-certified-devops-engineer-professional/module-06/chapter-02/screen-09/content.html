What EventBridge does
It matches incoming events to rules and routes them to one or more targets for processing or storage.
Design considerations:
  • Craft event patterns that are neither too broad nor too specific.
  • Use input transformers or a Lambda for enrichment before downstream systems.
  • Consider cross-account and cross-region routing for centralized incident telemetry.
Example event pattern
{
  "source": ["aws.cloudwatch"],
  "detail-type": ["CloudWatch Alarm State Change"],
  "detail": { "alarmName": ["High-CPU-Webserver-Alarm"], "state": { "value": ["ALARM"] } }
}
This pattern targets a single alarm name and state. Broaden or constrain fields depending on your routing needs.
Best practice
Test patterns using sample events and the console's test feature. Use input transformers to reduce the payload size sent to simple targets like SNS.
