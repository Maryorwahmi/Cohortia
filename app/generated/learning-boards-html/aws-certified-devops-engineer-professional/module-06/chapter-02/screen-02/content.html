Learning Objectives
Learn, Understand, Apply, Master — practical outcomes for incident detection.
Bloom: Learn → Understand → Apply → Master
01
Design Metric Math
Compose metrics to create actionable derived signals, such as error rate, and set alarms on those signals to avoid volume-dependent noise.
VERIFIED COMPETENCY MILESTONE
02
Configure Anomaly Detection
Enable and train an anomaly detector so CloudWatch learns normal patterns and reduces false alarms on fluctuating metrics.
VERIFIED COMPETENCY MILESTONE
03
Author Composite Alarms
Combine child alarms with logical expressions to escalate only when multiple conditions indicate a real problem.
VERIFIED COMPETENCY MILESTONE
04
Route Events with EventBridge
Create precise event patterns and targets so alarms flow into enrichment, ticketing, and automated remediation pipelines.
VERIFIED COMPETENCY MILESTONE
