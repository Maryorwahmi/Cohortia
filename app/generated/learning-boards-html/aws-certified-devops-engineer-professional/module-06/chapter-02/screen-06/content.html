What is Anomaly Detection?
A machine-learned model creates expected upper and lower bounds for a metric given historical patterns and seasonality.
Practical notes:
  • Good for metrics without clear static thresholds.
  • Allows dynamic thresholds that account for daily and weekly cycles.
  • Model requires several days of history to become reliable.
Example

Enable an anomaly detector on EC2 CPUUtilization and create an alarm that fires when CPU is outside the learned band. This prevents constant alerts during predictable peak periods.

Common mistakes
  • Turning on anomaly detection and immediately expecting instant alerts — model requires training.
  • Using anomaly detection for highly erratic metrics with no pattern — it may not learn a stable baseline.
