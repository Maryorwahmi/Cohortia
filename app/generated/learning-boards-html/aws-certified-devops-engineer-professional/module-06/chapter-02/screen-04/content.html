Metric Math — Definition
Compose arithmetic expressions across metrics to produce a new time series for analysis and alarming.
Key points:
  • Ensure inputs use the same period and statistic so the expression is valid.
  • Use metric math to normalize counts into rates or percentages.
  • Label derived series clearly so dashboards and alarms point to the correct signal.
Concrete example
Compute error rate by dividing 5xx count by total requests to get a traffic-normalized view. Alarm on the resulting series rather than raw 5xx count.
Key Takeaway

Metric math reduces false alerts by deriving signals that reflect true service problems, not traffic volume.

Implementation notes
When authoring expressions in CloudWatch, use metric IDs like m1 and m2 and a final expression that returns data. ReturnData flags control which series are visible and alarmable.
Common mistake
Mixing periods or aggregations across inputs. If one metric uses 1-minute averages and another uses 5-minute sums, the derived result will be misleading. Always align period and statistic.
Check your understanding
If your total requests double but 5xx count stays the same, what happens to the error rate derived by metric math? Think about whether the alarm should fire.
