Module 6 › Chapter 6.1 › CloudWatch vs CloudTrail vs Config
Side-by-side comparison
Follow a consistent lookup order and document queries in your runbook for rapid analysis.
CloudWatch
Metrics, alarms, and logs to detect operational issues.
CloudTrail
API history and actor details for forensic timelines.
AWS Config
Resource state timelines and configuration snapshots.
Runbook lookup order
  1. Confirm symptom in CloudWatch and capture related logs.
  2. Search CloudTrail for recent deploy or change API calls.
  3. Inspect AWS Config timeline for resource property changes.
Concrete example
An alarm for increased error rate triggers. CloudTrail shows a recent deploy by a pipeline user. AWS Config shows altered security group rules. Together they reveal a likely misconfiguration introduced during deployment.
Key Takeaway
Use CloudWatch to find problems; use CloudTrail and Config to explain how they happened.
