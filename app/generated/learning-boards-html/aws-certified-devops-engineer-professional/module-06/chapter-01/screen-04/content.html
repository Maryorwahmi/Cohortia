Module 6 › Chapter 6.1 › What is an Incident?
Incident — clear definition
An incident is an unplanned interruption or reduction in service quality. Classify by impact and domain before reacting.
Classification
  • By scope: single instance, availability zone, region, or global.
  • By type: performance (5xx), configuration, or security breach.
Common misconception
Not every alert is an incident. Use thresholds and impact analysis to decide when to declare an incident and start your runbook.
Concrete example
Intermittent 5xx responses lead to a declared incident if user transactions fail at scale. Use CloudWatch and CloudTrail to find recent deployments or config changes as possible causes.
Key Takeaway

Define incidents by impact and deviation; classify quickly to route appropriate resources and reduce confusion.

Why classify?
Classification focuses scarce responder effort where it matters and determines the necessary telemetry and AWS services to consult.
