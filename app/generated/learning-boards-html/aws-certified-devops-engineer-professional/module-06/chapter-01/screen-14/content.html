Module 6 › Chapter 6.1 › 5xx Error Walkthrough
Step-by-step
Follow a structured investigation to preserve evidence and minimize user impact.
1. Confirm
Use CloudWatch metrics and logs to verify elevated 5xx rates and capture timestamps.
2. Investigate
Check CloudTrail for recent deployments, and AWS Config for configuration changes around the start time.
3. Contain
Isolate suspect instances or scale down new nodes while preserving logs.
4. Remediate
Roll back the recent deployment or apply configuration fixes as the runbook specifies.
5. Recover & Review
Validate user flows and run a post-incident review to update tests and playbooks.
Remember
Do not destroy forensic data. Use Systems Manager for diagnostics. Notify via SNS and keep a running timeline for the post-incident review.
