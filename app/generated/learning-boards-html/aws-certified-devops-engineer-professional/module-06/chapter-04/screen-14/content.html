Module 6 › Chapter 6.4 › Key Concepts
Visual orchestration
State machines give a single view of the playbook and an execution history for audits.
Service integrations
Task states call Lambda, SNS, SSM and others to perform the work defined by the playbook.
ASL state types
Choice, Wait, Parallel, Map and Task let you express branching, timing, concurrency and iteration declaratively.
Summary: Model your incident playbook as a state machine that coordinates small, testable service tasks, handles errors, and records an execution history for operations and audit needs.
