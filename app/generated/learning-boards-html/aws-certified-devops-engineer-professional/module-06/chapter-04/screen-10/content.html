Walkthrough notes
  • GatherIncidentDetails collects context for later decisions.
  • NotifyOnCallTeam uses SNS integration to publish the same payload automatically.
  • CheckSeverity branches with Choice so logic is visible and auditable.
Misconception check: ASL Resource fields reference ARNs or special integration strings; they are not code. Put complex logic in services and keep ASL declarative.
