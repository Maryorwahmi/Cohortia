Module 6 › Chapter 6.4 › Choice states
When to use Choice
Choice evaluates variables in the execution input and selects the next state. Use it for severity routing, compliance gating, or selecting a remediation path based on collected evidence.
Example decision rules
  • If $.Severity equals CRITICAL → IsolateAffectedResources
  • If $.Severity equals HIGH → AttemptAutomatedRemediation
  • Default → LogAndMonitor
Common mistake
Not normalizing input leads to choices that never match and unexpected Default transitions.
Practical tips
Use a prior Task to assemble a consistent IncidentSummary object. Apply Parameters to shape the input to the Choice state and include a Default branch for safety. Keep Choice rules simple and document the expected structure.
Check your understanding
If your Choice state never matches, what should you inspect first? Answer: the structure and values of the execution input and whether ResultPath removed needed fields.
