Core ASL concepts
  • StartAt: entry state name. Defines where execution begins.
  • Task: runs work by calling a service or Lambda via a Resource ARN.
  • Choice: branches based on execution data without running code.
  • Wait: pauses for a defined time or until an event.
  • Parallel / Map: run branches concurrently or iterate collections.
Practical tip: use Parameters to shape task input and ResultPath to merge outputs so you preserve required context for downstream choices and verifications.
Common mistake
Overwriting execution input by not using ResultPath carefully, which can remove fields needed by later Choice states.
ASL in practice
Define StartAt, then name each state. Each Task includes a Resource ARN or an integrated service descriptor; Choice entries inspect input variables. Use Pass for lightweight transformations and Succeed/Fail to end executions cleanly.
Example
{
  "StartAt": "GatherIncidentDetails",
  "States": {
    "GatherIncidentDetails": { "Type": "Task", "Next": "NotifyOnCallTeam" }
  }
}
