Module 6 › Chapter 6.4 › Error handling & retries
Retry and Catch patterns
Define Retry blocks with ErrorEquals, IntervalSeconds, BackoffRate and MaxAttempts. Use Catch to handle final failures and transition to notification or escalation states. Preserve diagnostic output so post-incident analysis has context.
Example actions after failure
  • Log error details to DynamoDB or CloudWatch
  • Publish a detailed message to SNS for paging
  • Transition to an Escalate state that creates a ticket
Common mistakes
Not scoping Retry to specific errors, missing Catch paths, and failing to record the exception details make failures harder to diagnose.
Key Takeaway
Define retries for transient failures and Catch to notify and escalate when automated attempts fail.
