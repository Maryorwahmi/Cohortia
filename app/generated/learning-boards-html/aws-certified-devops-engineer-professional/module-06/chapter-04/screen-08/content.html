Module 6 › Chapter 6.4 › Parallel & Map
Parallel
Run independent branches at the same time, then continue once all complete. Useful for simultaneous checks like metric verification, log queries, and external service pings.
Map
Iterate over an array in the input and execute the same sub-workflow for each element. Ideal for remediating multiple affected instances or resources.
Pro-tip
Throttle branch concurrency with backoff and consider service limits. Test a Map with a small array first.
Example: multi-instance restart
Use Map to iterate instance IDs and call SSM Automation in each iteration to restart services. Collect results and choose escalation if any fail.
Misconception check
Parallel is not automatic scaling of services; it runs concurrent branches and may hit service quotas that you must plan for.
