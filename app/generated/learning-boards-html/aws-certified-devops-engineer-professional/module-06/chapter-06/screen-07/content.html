Module 6 › Chapter 6.6 › AWS CloudTrail
What CloudTrail gives you
Caller identity and ARN, source IP address, event time, event name, request parameters, and response elements when available.
Delivered to S3 for archival and query with Athena. Ideal for reconstructing the sequence of API calls that led to an outage.
Example query goal
Find StopInstances events to confirm who stopped an instance and when.
Checklist before querying
  • Confirm CloudTrail is enabled and delivering logs to S3.
  • Ensure Athena tables are created to read CloudTrail JSON format.
  • Check log delivery latency—allow a few minutes after an event for delivery.
  • Restrict query results to authorized reviewers and redact sensitive fields.
