Module 6 › Chapter 6.6 › CloudWatch Logs
Runtime trace analysis

Use application logs to find error patterns, exceptions, or degraded performance that coincide with API events or configuration changes.

Logs are essential to prove causality: did the code throw an error leading to an operator action, or did the operator action trigger the error?

Using Logs Insights
Run queries to aggregate errors by timestamp, host, or request ID to find correlated spikes.
Include log excerpts in your report to support conclusions, with sensitive info redacted.
Check retention to ensure logs for the incident window are available.
