Action item template
Title: Clear description of the change.
Owner: Person responsible for delivery.
Deadline: Date by which the action is expected to be complete.
Acceptance criteria: Measurable test or evidence that confirms the fix works.
Verification: Who will verify and how (test steps, queries, or audit).
Evidence links: Attach CloudTrail queries, Config snapshots, or log excerpts.
Example
Action: Add CloudWatch alarm for error rate > 5% for 5 minutes.
Owner: On-call lead. Deadline: 2 weeks. Acceptance: Alarm triggers on simulated error, runbook updated. Verifier: Ops engineer runs test and uploads screenshot of alarm state.
