Configuration timelines
AWS Config captures snapshots of resource properties over time and records configuration changes.
In RCA, Config helps answer: what was the resource state just before the incident and who or what changed it?
Example: for an S3 public access event, use Config to find when the public flag toggled and compare previous ACLs or policies.
Quick tips
  • Use Config snapshots as evidence for the post-mortem timeline.
  • Combine Config and CloudTrail: call vs. state.
  • Limit access to snapshots and redact sensitive policy content before sharing.
