Timeline reconstruction

Collect all time-stamped artifacts and order them. For each event include: timestamp, actor, API call or config change, logs showing effects, and any mitigations applied.

Annotate uncertain items as hypotheses and mark what additional evidence would confirm them.

Five Whys example
  1. Why did the instance stop? Because a StopInstances API was invoked.
  2. Why was the API invoked? An automation script ran the call.
  3. Why did the script run? A scheduled job triggered it with a malformed filter.
  4. Why was the filter malformed? Tests didn't cover this path and there was no validation.
  5. Why no validation? The runbook and CI checks lacked this case.
Contributing factors
  • Missing alarms or low monitoring granularity.
  • Ambiguous runbooks or incomplete automation tests.
  • Slow communication or unclear incident ownership.
Key Takeaway
RCA ties evidence to systemic fixes; document assumptions and required verification steps for each action item.
