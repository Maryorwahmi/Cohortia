Module 6 › Chapter 6.6 › Lab: Athena & CloudTrail
Step 1: Confirm CloudTrail to S3
Verify your trail delivers logs to an S3 prefix you control and that Athena can access that bucket.
Step 2: Create Athena table
CREATE EXTERNAL TABLE cloudtrail_logs (
  eventVersion STRING,
  userIdentity STRUCT,
  eventTime STRING,
  eventName STRING,
  sourceIPAddress STRING,
  requestParameters STRING
)
ROW FORMAT SERDE 'com.amazon.emr.hive.serde.CloudTrailSerde'
LOCATION 's3://your-cloudtrail-bucket/AWSLogs//CloudTrail//';
Step 3: Simulate an action (CLI)
aws ec2 stop-instances --instance-ids i-0123456789abcdef0
Step 4: Query Athena to find the event
SELECT eventTime, userIdentity.userName, sourceIPAddress, requestParameters
FROM cloudtrail_logs
WHERE eventName = 'StopInstances'
ORDER BY eventTime DESC
LIMIT 10;
Include these queries in your post-mortem report and link to the S3 objects used as evidence.
