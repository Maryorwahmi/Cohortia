Module 6 › Chapter 6.6 › Forensic Data Sources
Service roles in forensics
AWS CloudTrail: authoritative API audit logs. Use to reconstruct who performed API calls and from where.
AWS Config: historical configuration snapshots and change timeline for resources.
CloudWatch Logs: application and infrastructure logs; analyze patterns and correlate events across components.
Amazon Athena: run SQL queries against S3-stored logs for fast forensic searches without provisioning servers.
Practical correlation
  • Find an API call in CloudTrail, then check AWS Config for resource state before and after the call.
  • Use CloudWatch Logs to understand application errors that occurred around the time of the API call.
  • Run Athena queries to scan large archives and locate suspicious actions quickly.
Safety note
Redact or limit distribution of sensitive data. Grant forensic access only to authorized personnel.
