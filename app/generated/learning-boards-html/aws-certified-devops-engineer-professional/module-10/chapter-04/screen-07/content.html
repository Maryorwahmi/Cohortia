Canary Deployments with CodeDeploy

Testing new versions with a small user segment before full rollout.

How Canary Deployments Work

  • •Traffic is shifted in two distinct increments.
  • •First Increment: A small percentage (e.g., 10%) shifts to the new version.
  • •Wait Time: A specified period for monitoring and testing the canary.
  • •Second Increment: The remaining traffic (e.g., 90%) shifts after validation.
Key Takeaway

Canary deployments enable early issue detection by exposing new versions to a small user segment first, minimizing potential impact.
