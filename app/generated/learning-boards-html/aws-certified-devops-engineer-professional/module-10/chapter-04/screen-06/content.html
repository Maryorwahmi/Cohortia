Traffic Shifting

Linear Deployments with CodeDeploy

Shifting traffic in equal, timed increments for controlled rollouts.

How Linear Deployments Work

  • •Traffic is shifted in predefined, equal increments.
  • •Each increment occurs over a set time period.
  • •Provides a controlled, time-based rollout.

This method allows for continuous monitoring and early issue detection at each stage of the rollout.

Key Takeaway

Linear deployments offer predictable, time-based traffic shifts, enabling measured observation and quick intervention during rollouts.
