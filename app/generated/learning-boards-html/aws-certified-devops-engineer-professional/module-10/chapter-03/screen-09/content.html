App Mesh Configuration

Canary Routing with App Mesh

Defining routes for weighted traffic.

Key Elements of an App Mesh Route

  • 1routeName: Unique identifier for the route.
  • 2httpRoute: Defines rules for HTTP traffic.
  • 3weightedTargets: Specifies virtual nodes and their traffic distribution percentages.
  • 4match: Defines conditions for the route to apply (e.g., URL prefix, headers).
Key Takeaway

App Mesh routes provide powerful, flexible traffic control for canary deployments, allowing for both simple weighted splits and complex rule-based routing.

{
  "routeName": "my-service-route",
  "spec": {
    "httpRoute": {
      "action": {
        "weightedTargets": [
          {
            "virtualNode": "my-service-v1",
            "weight": 99
          },
          {
            "virtualNode": "my-service-v2",
            "weight": 1
          }
        ]
      },
      "match": {
        "prefix": "/"
      }
    }
  }
}
