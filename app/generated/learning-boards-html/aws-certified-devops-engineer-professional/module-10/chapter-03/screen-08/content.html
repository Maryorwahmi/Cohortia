App Mesh Components

Building Blocks of App Mesh

Understanding virtual services, nodes, and routers.

Core App Mesh Concepts

  • 1Virtual Service: An abstraction of a real service, providing a logical name for clients.
  • 2Virtual Node: Represents a logical pointer to a specific service instance (e.g., my-service-v1).
  • 3Virtual Router: Handles traffic for a virtual service, directing it to appropriate virtual nodes.
  • 4Route: Specific rules within a virtual router that determine how traffic is directed (e.g., weighted, header-based).
Key Takeaway

App Mesh's virtual components create a powerful abstraction layer, enabling flexible and precise traffic management for microservices.

App Mesh Hierarchy

Example: Service Discovery

A client requests my-service.example.com (Virtual Service). The Virtual Router for my-service then evaluates its routes and directs the request to either my-service-v1 or my-service-v2 (Virtual Nodes) based on defined traffic weights or rules.
