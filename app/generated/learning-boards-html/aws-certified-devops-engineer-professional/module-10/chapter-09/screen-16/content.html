Key Concepts: AWS DR Services & Strategies

Tools and approaches for multi-region resilience

Multi-Site (Active-Active)

DR strategy where the application runs simultaneously in multiple regions, serving traffic from all.

Route 53 Failover Routing

A Route 53 policy that automatically routes traffic to a healthy secondary resource if the primary becomes unhealthy.

S3 Cross-Region Replication (CRR)

Automatically replicates objects between S3 buckets in different AWS regions.

Summary Takeaway

AWS provides a rich set of services and strategies, from Active-Active deployments to specific replication tools, to build highly resilient multi-region architectures.
