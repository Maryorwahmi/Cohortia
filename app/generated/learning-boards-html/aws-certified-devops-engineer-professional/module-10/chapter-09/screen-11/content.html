Multi-Region Deployment

Active-Passive Deployment: Data Replication

Ensuring data consistency across regions

RDS Cross-Region Read Replicas

Asynchronously replicate data from a primary RDS instance to a read replica in a different region. During failover, the replica is promoted to a standalone primary.

Minimizes database RPO

S3 Cross-Region Replication (CRR)

Automatically replicates objects uploaded to a source S3 bucket in one region to a destination bucket in another region.

Ensures object data redundancy

Trade-offs & Considerations

  • Data Loss Potential: Asynchronous replication means some data loss is possible (RPO > 0) depending on replication lag.
  • Comprehensive Replication: Ensure all critical data, including configuration, secrets, and static assets, are replicated.
  • Cost: Replication incurs costs for data transfer and storage in the secondary region.
Key Takeaway

Careful planning for data replication, considering RPO and comprehensive coverage, is essential for a successful Active-Passive DR strategy.
