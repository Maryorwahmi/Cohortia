Key Concepts: Immutable Deployments

Essential terms and ideas to remember

Immutable Infrastructure

A paradigm where servers are never modified after deployment; changes require replacement with new servers from an updated image.

Amazon Machine Image (AMI)

A template containing the OS, application server, and applications required to launch an EC2 instance, serving as the consistent blueprint.

AWS Auto Scaling Group (ASG)

A collection of EC2 instances managed for automatic scaling and orchestrating rolling updates based on new AMIs.

Chapter Summary

Immutable deployments, powered by AMIs and ASGs, provide a robust strategy for consistent, reliable, and easily reversible infrastructure, minimizing configuration drift and enhancing operational efficiency.
