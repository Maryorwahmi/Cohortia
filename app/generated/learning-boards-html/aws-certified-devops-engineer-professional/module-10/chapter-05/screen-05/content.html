AWS Foundation

AMIs and Auto Scaling Groups: The Core

Building blocks for immutable deployments on AWS

Amazon Machine Image (AMI)

  • A template for launching EC2 instances.
  • Contains OS, application server, application code, and dependencies.
  • Application and dependencies are 'baked' directly into the image.
  • Ensures instances are ready to serve traffic immediately upon launch.

AWS Auto Scaling Group (ASG)

  • Manages a collection of EC2 instances as a logical unit.
  • Ensures desired capacity and health of instances.
  • Orchestrates the rollout of new AMIs by replacing old instances.
  • Crucial for maintaining application availability during updates.

How They Work Together

  • New application version is baked into a new AMI.
  • ASG's Launch Template is updated to reference the new AMI.
  • ASG gradually replaces old instances with new ones from the updated AMI.
  • Achieves zero-downtime deployments and consistent environments.
Key Takeaway

AMIs provide the consistent, pre-configured server images, while ASGs orchestrate their deployment and management, forming the backbone of immutable infrastructure on AWS.
