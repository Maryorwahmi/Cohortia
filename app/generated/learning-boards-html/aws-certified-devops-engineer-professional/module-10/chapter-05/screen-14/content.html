Hands-on Lab

Lab: Create Launch Template and ASG

Orchestrating instances with your new AMI

Instructions: Create Launch Template

  1. Create a Launch Template named nginx-lt.
  2. Choose my-nginx-v1-ami as the AMI.
  3. Select an instance type (e.g., t2.micro).
  4. Configure a security group allowing HTTP (port 80).
  5. Do NOT specify User Data for this initial setup.

Instructions: Create Auto Scaling Group

  1. Create an Auto Scaling Group named nginx-asg.
  2. Use nginx-lt as the Launch Template.
  3. Set desired, min, max capacity to 2.
  4. Select appropriate VPC and subnets.
  5. (Optional) Configure a load balancer.
  6. Review and create the ASG.

Verification Step

Once instances are launched by the ASG, get their public IPs from the EC2 console and verify they show "Hello from Nginx v1.0" when accessed in a browser.

Key Takeaway

Configuring a Launch Template and ASG allows for automated, scalable deployment of instances from your immutable AMI, ensuring consistent environments from the start.
