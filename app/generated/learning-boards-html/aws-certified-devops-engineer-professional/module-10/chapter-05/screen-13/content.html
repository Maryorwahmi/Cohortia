Hands-on Lab

Lab: Prepare Base Instance & Create AMI v1.0

Setting up your initial immutable image

Instructions: Prepare EC2 & Nginx

  1. Launch a minimal EC2 instance (e.g., Amazon Linux 2).
  2. SSH into the instance.
  3. Install Nginx: sudo yum install nginx -y.
  4. Modify Nginx default page: echo "<h1>Hello from Nginx v1.0</h1>" | sudo tee /usr/share/nginx/html/index.html.
  5. Start Nginx: sudo systemctl start nginx.
  6. Enable Nginx on boot: sudo systemctl enable nginx.
  7. Clean up temporary files/logs.

Instructions: Create AMI v1.0

  1. From EC2 console, select your instance.
  2. Actions -> Image and templates -> Create image.
  3. Name it my-nginx-v1-ami.
  4. Add a description.
  5. Create the image and wait for it to become available.

Expected Outcome

You will have a custom AMI named my-nginx-v1-ami available in your AWS account. This AMI is pre-configured with Nginx serving a 'Hello from Nginx v1.0' page, ready to be used as a consistent base for your Auto Scaling Group.

Key Takeaway

Creating a pre-configured AMI ensures that every instance launched from it is identical and immediately operational, forming the consistent base for immutable deployments.
