Designing for Manual Approval Workflows

Applying Step Functions for human-gated production deployments.

Pause with `waitForTaskToken`

A `Task` state sends a unique `TaskToken` to an external system (e.g., SQS) and pauses, awaiting a signal.

External Approval & Signal

An external process (human or system) calls `SendTaskSuccess` or `SendTaskFailure` with the token to resume/fail.

Key Takeaway

The `waitForTaskToken` pattern is ideal for implementing robust manual approval steps with configurable timeouts in Step Functions workflows.

"WaitForApproval": {
  "Type": "Task",
  "Resource": "arn:aws:states:::sqs:sendMessage.waitForTaskToken",
  "Parameters": {
    "QueueUrl": "https://sqs.us-east-1.amazonaws.com/123456789012/MyApprovalQueue",
    "MessageBody": {
      "TaskToken.$": "$$.Task.Token",
      "Message": "Deployment to staging complete. Approve for production?"
    }
  },
  "TimeoutSeconds": 86400, // 24 hours
  "Catch": [
    {
      "ErrorEquals": ["States.Timeout"],
      "Next": "ApprovalTimeout"
    }
  ],
  "Next": "DeployToProd"
},
"ApprovalTimeout": {
  "Type": "Fail",
  "Cause": "Manual approval timed out."
}
