Implementing Manual Approvals with Task Tokens

Pausing Workflows for Human Decision-Making

The Task Token Mechanism

  • A `Task` state configured with `.waitForTaskToken` pauses execution.
  • Step Functions sends a unique `TaskToken` to an integrated service (e.g., SQS).
  • An external system (human or automated) processes the request.
  • The external system calls `SendTaskSuccess` or `SendTaskFailure` with the token.
  • Workflow resumes or fails based on the signal.
Key Takeaway

Task Tokens provide a robust mechanism for integrating human approval steps into automated workflows, ensuring critical decisions are made before proceeding with deployments.

ASL Snippet: Manual Approval Step
{
  "WaitForApproval": {
    "Type": "Task",
    "Resource": "arn:aws:states:::sqs:sendMessage.waitForTaskToken",
    "Parameters": {
      "QueueUrl": "https://sqs.us-east-1.amazonaws.com/123456789012/MyApprovalQueue",
      "MessageBody": {
        "TaskToken.$": "$$.Task.Token",
        "DeploymentId.$": "$.DeploymentId",
        "Message": "Deployment to staging complete. Approve for production?"
      }
    },
    "Catch": [
      {
        "ErrorEquals": ["States.Timeout"],
        "Next": "ApprovalTimeout"
      }
    ],
    "Next": "DeployToProd"
  }
}

Real-world Connection: Compliance

Many industries require strict compliance and human sign-off before changes can be deployed to production. Task Tokens in Step Functions provide an auditable and reliable way to enforce these critical gates within an automated pipeline.
