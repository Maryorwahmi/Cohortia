Module 10 › Chapter 10.1 › Practice Goals
Objective checklist
  • Document expected downtime and rollback plan for each strategy.
  • Implement a simulated all-at-once update and note outage duration.
  • Run a rolling update across multiple instances and verify compatibility.
  • Deploy a blue/green switch and validate instant rollback.
Measuring success
  • Automation: pipeline run time, reproducibility, and rollback script readiness.
  • Observability: health checks, error rate, latency, and trace sampling for the new version.
  • Business: customer impact window and recovery time objective.
VERIFIED COMPETENCY MILESTONE • Run the simulation and report results against the checklist.
