Module 10 › Chapter 10.1 › Simulation Steps
All-at-once (single EC2)
  • docker build -t my-app:2.0.0 .
  • docker stop my-app-v1 && docker run -d -p 80:80 --name my-app-v2 -e APP_VERSION=2.0.0 my-app:2.0.0
  • Observe downtime while container restarts.
Rolling (three instances)
  • Remove one instance from rotation, update container, wait for health checks.
  • Return instance to rotation; repeat for next instance.
  • Ensure compatibility since old and new versions coexist briefly.
Blue/Green (two instances)
  • Deploy v2.0.0 to idle green instance and run integration tests.
  • Switch load balancer target from blue to green; validate traffic.
  • If issues, switch back to blue for instant rollback.
Note: these steps are conceptual instructions to help you design and observe rollout behaviors; adapt commands to your environment and security rules.
