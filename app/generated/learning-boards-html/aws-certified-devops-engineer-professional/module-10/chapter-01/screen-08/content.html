app.py
from flask import Flask
import os

app = Flask(__name__)

# Environment variable to define the version
APP_VERSION = os.environ.get('APP_VERSION', '1.0.0')

@app.route('/')
def hello_world():
  return f'Hello from Cohortia App! Version: {APP_VERSION}'

if __name__ == '__main__':
  app.run(host='0.0.0.0', port=80)
Dockerfile
FROM python:3.9-slim-buster
WORKDIR /app
COPY requirements.txt .
RUN pip install -r requirements.txt
COPY . .
ENV APP_VERSION=1.0.0 # Default version
EXPOSE 80
CMD ["python", "app.py"]
Instructions: build an image with a tag for each version and run containers with APP_VERSION set to the appropriate value to observe version behavior under different deployment strategies.
