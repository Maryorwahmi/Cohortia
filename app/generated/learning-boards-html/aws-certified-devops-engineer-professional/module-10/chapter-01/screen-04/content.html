Module 10 › Chapter 10.1 › All-at-once
Definition

Update every instance simultaneously

You replace all running instances with the new release in a single operation. It requires minimal orchestration but carries high risk for production traffic.

Risk
Highest blast radius; entire service may go down if the release is faulty.
When to use
Internal tools, development environments, or low-criticality services where brief downtime is acceptable.
Concrete example
You have three EC2 instances behind a load balancer. An all-at-once deploy stops containers on all instances, updates images to version 2.0.0, and starts them. During the update window, no instance serves the old release, so users may see errors until all instances are healthy.
Key takeaway

Fast and simple, but not suitable for critical production services without compensation like exhaustive testing and very fast rollback automation.
