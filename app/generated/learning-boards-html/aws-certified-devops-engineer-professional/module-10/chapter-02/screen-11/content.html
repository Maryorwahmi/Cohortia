AppSpec File

Deployment Instructions

A YAML file defining source files, lifecycle hooks, and target service properties for CodeDeploy.

Key Takeaway

The AppSpec file is your blueprint for CodeDeploy, detailing every step from deployment to validation through lifecycle hooks.

AppSpec Structure
version: 0.0
Resources:
  - TargetService:
      Type: AWS::ECS::Service
      Properties:
        TaskDefinition: <TASK_DEFINITION_ARN>
        LoadBalancerInfo:
          ContainerName: "your-container-name"
          ContainerPort: 80
Hooks:
  BeforeInstall:
    - Location: scripts/before_install.sh
  AfterInstall:
    - Location: scripts/after_install.sh
YAML Format

AppSpec files use YAML for clear, structured definitions.
