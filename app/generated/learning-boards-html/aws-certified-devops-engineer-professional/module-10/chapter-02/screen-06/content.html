Traffic Shifting Mechanisms for EC2

Controlling how users transition to the new green environment

Core Action

Load Balancer Reconfiguration

CodeDeploy re-registers 'green' instances with the production load balancer (e.g., ALB/NLB) and de-registers 'blue' instances.

Validation Steps

Health Checks & Automated Tests

Before traffic shift, CodeDeploy performs health checks and allows for optional manual approval or automated tests on the green environment.

Key Takeaway

Flexible traffic shifting options allow you to balance deployment speed with risk, ensuring a controlled transition to the new application version.

Traffic Shift Strategies

All-at-once

All traffic immediately shifts from blue to green. Fastest, highest risk.

Linear

Traffic shifts in equal increments over a set period (e.g., 10% every 5 minutes). Controlled, moderate risk.

Canary

Traffic shifts in two increments: small percentage first, then the remainder. Lowest risk, slowest.
