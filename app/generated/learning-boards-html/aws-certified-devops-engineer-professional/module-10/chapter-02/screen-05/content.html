Green Environment Provisioning

How CodeDeploy prepares the new application version for EC2 instances

Process Step 1

New Instance Provisioning

CodeDeploy provisions a new set of EC2 instances (the 'green' environment) based on your updated launch configuration or Auto Scaling Group.

Process Step 2

Application Deployment

The new application version is then deployed to these newly provisioned 'green' instances, preparing them for validation.

Key Principle

Blue Environment Remains Active

Crucially, the 'blue' environment continues to serve all production traffic, ensuring zero downtime during the green environment setup.

EC2 Workflow

Blue Environment (Live)

Old App Version, Serving Traffic

Green Environment (Staging)

New App Version, Under Deployment

Key Takeaway

The green environment is built in isolation, ensuring no impact on live users.
