Configuring CodeDeploy: Application & Deployment Group

Setting up the core components for blue/green deployments

Component 1

Application

A logical grouping of deployment groups, representing a single application or service.

Component 2

Deployment Group

Defines deployment settings: compute platform (EC2/on-premises or ECS), service role, load balancer, and blue/green configuration.

Key Takeaway

The Deployment Group is where you specify the blue/green deployment type and configure traffic shifting and original environment retention.

Hierarchy

CodeDeploy Application

Logical Grouping

Deployment Group

Blue/Green Settings, Load Balancer, Service Role

Crucial Link

Deployment Group links to your compute platform (EC2/ECS).
