Liquibase: Feature-Rich and Flexible

Advanced capabilities for complex migration scenarios

Key Features of Liquibase

  • • Supports multiple formats: SQL, XML, YAML, JSON for changesets.
  • • Offers advanced features like contexts and preconditions.
  • • Provides built-in rollback capabilities for additive changes.
  • • Ideal for complex environments requiring fine-grained control.
Example Changeset (YAML)
databaseChangeLog:
  - changeSet:
      id: 1
      author: dev
      changes:
        - createTable:
            tableName: products
            columns:
              - column:
                  name: id
                  type: INT
                  autoIncrement: true
                  constraints:
                    primaryKey: true
                    nullable: false
