Tooling Overview

Database Migration Tools

Automating and managing schema evolution

Why Use Migration Tools?

  • • Provides structured, version-controlled schema changes.
  • • Tracks applied migrations in a schema history table.
  • • Ensures consistency across development, staging, and production environments.
  • • Reduces manual errors and simplifies rollback planning.
Analogy

Think of migration tools as Git for your database schema, providing version control and a clear history of changes.

Popular Open-Source Tools

Flyway(SQL-focused)
Liquibase(Feature-rich)
Misconception

Migration tools are not ORMs; they manage schema changes, not data mapping or object-relational persistence.

Key Takeaway

Database migration tools are essential for automating and safely managing schema evolution within CI/CD pipelines.
