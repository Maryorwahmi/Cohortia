Flyway: Simple and SQL-Focused

Convention over configuration for database migrations

Key Features of Flyway

  • • Uses plain SQL scripts for defining migrations.
  • • Follows a convention-over-configuration philosophy.
  • • Each script is versioned (e.g., V1, V2) and applied in order.
  • • Maintains a `flyway_schema_history` table in the database to track applied changes.
Example Script Naming

V1__Create_Users_Table.sql
V2__Add_Email_Column.sql

How Flyway Works

SQL Scripts
Database
Flyway reads scripts, applies them, and updates the schema history table.
Key Takeaway

Flyway provides a straightforward, SQL-based approach to managing database schema versions, ensuring ordered and traceable changes.
