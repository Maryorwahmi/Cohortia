Flyway Integration with AWS CodeBuild

Example buildspec.yaml for automated migrations

version: 0.2
phases:
  install:
    commands:
      # Download and install Flyway CLI
      - wget -qO- https://repo1.maven.org/maven2/org/flywaydb/flyway-commandline/7.15.0/flyway-commandline-7.15.0-linux-x64.tar.gz | tar xvz
      - export PATH=$PATH:$(pwd)/flyway-7.15.0
  build:
    commands:
      # Copy migration scripts from source artifact
      - cp -r migrations/ sql/
      # Execute Flyway migration
      - flyway -url=jdbc:postgresql://<DB_HOST>:<DB_PORT>/<DB_NAME> -user=<DB_USER> -password=<DB_PASSWORD> migrate

Explanation of Steps

  • • **Install Phase:** Downloads and extracts the Flyway CLI, adding it to the system PATH.
  • • **Build Phase:** Copies SQL migration scripts from your source repository to a directory accessible by Flyway.
  • • **Flyway Migrate:** Executes the `migrate` command, connecting to the database and applying all pending versioned scripts.
  • • **IAM Roles:** CodeBuild requires appropriate IAM roles for database access (e.g., via Secrets Manager for credentials).
Key Takeaway

AWS CodeBuild can automate Flyway migrations by defining installation and execution steps within the buildspec.yaml, ensuring controlled schema evolution.
