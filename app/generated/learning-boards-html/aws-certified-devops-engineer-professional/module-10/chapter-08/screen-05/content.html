Definition

Dark Launches: Testing in Production

Deploying code without exposing it to end-users.

Core Idea

A new feature or code version is deployed to production but remains inaccessible to end-users, typically controlled by a configuration switch.

Purpose

To validate performance, stability, and integration under real production load and conditions without impacting user experience.

Benefit

Identifies bottlenecks and issues in a live environment, reducing risk before any user is affected.

The Dark Launch Cycle

1. Deploy New Code (Hidden)
2. Monitor Performance & Stability
3. Validate & Prepare for Release

Example: A new payment gateway is deployed but only processes shadow transactions for a week.

Key Takeaway

Dark launches provide a crucial safety net, allowing teams to rigorously test new features in a live production environment before any user is impacted.
