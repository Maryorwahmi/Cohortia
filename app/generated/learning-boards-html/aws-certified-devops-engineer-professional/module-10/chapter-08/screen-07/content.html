Feature Flag in Action: Python Example

A practical illustration of conditional feature logic.

Conditional Logic

The `if is_feature_enabled(...)` statement dynamically switches between old and new functionality.

Dynamic Control

The `is_feature_enabled` function can query a service to enable features for specific users or percentages.

No Redeployment

Changes to feature flag rules (e.g., enabling for more users) do not require code deployment.

# Example of a feature flag in Python
def get_product_recommendations(user_id):
    if is_feature_enabled("NEW_RECOMMENDATION_ENGINE", user_id):
        return new_recommendation_engine.get_recommendations(user_id)
    else:
        return old_recommendation_engine.get_recommendations(user_id)

def is_feature_enabled(feature_name, user_id):
    # This logic would typically query a feature flag service
    # e.g., AWS AppConfig, LaunchDarkly, or a custom database
    if feature_name == "NEW_RECOMMENDATION_ENGINE":
        # Enable for specific users, or a percentage, or based on region
        if user_id in ["admin", "beta_tester_1"] or random.random() < 0.05:
            return True
    return False

This code snippet illustrates how a feature flag (`NEW_RECOMMENDATION_ENGINE`) controls which recommendation logic is executed.

Key Takeaway

Feature flags embed dynamic decision points in your code, allowing for flexible feature activation based on various criteria without redeployment.
