Module 4 › Chapter 4.1 › Discovery Tooling
Definition

What discovery tools capture

Configuration: CPU, memory, disk sizes, installed packages and OS versions for inventory and licensing checks.

Utilization: average and peak CPU, memory, and I/O to inform right-sizing and savings potential.

Network peers: outbound and inbound connections to identify coupled systems that should move together.

Why it matters
Peers reveal migration groupings; utilization informs instance sizing and reserved instance planning.
Misconception
Assuming peak utilization equals required cloud size can cause overspend; use typical and percentile metrics.
Simulated discovery snippet
# discovery-sample.json
{
  "server":"ecom-front",
  "cpu_avg":12,
  "cpu_95pct":46,
  "mem_avg":38,
  "disk_io":120,
  "peers":[{"host":"db02","port":3306},{"host":"cache01","port":6379}],
  "owner":"web-team",
  "compliance":"standard"
}
Use this output to
  • Decide whether to right-size compute or consider managed services for databases.
  • Flag synchronous peer groups to migrate together or to use cross-region strategies carefully.
  • Estimate data transfer and cutover approaches based on I/O and peer volume.
