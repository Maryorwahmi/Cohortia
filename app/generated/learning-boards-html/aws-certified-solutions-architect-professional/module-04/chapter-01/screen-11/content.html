Module 4 › Chapter 4.1 › Phased Planning

Wave definition steps

  1. Use dependency maps to form candidate groups.
  2. Score groups by criticality and readiness.
  3. Define success criteria and rollback procedures for the group.
  4. Rehearse the cutover in non-production and document lessons learned.
Example wave plan
Wave 1: Internal file shares (low risk). Wave 2: Customer-facing frontend (scale tests). Wave 3: Backend databases (coordinated cutover).

Success criteria checklist

  • Performance within X% of baseline.
  • All integration tests pass.
  • Backups verified and restore tested.
  • Stakeholder sign-off and documented rollback steps.
Key Takeaway

Define waves using dependency data, rehearse cutovers, and set measurable acceptance criteria for each wave.
