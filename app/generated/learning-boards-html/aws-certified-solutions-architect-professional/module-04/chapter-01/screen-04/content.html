Module 4 › Chapter 4.1 › Portfolio Discovery
Process Flow

Inventory → Dependency Map → Validation

Start with an automated inventory that lists servers, databases, and storage. Enrich each item with owner, criticality, and compliance flags.

Collect runtime metrics and network peers to build a dependency map. Identify high-traffic links and grouped components that must migrate together.

Validate findings with application owners to confirm non-obvious dependencies and to capture business constraints.

Example artifact
CSV rows with server, role, owner, CPU avg, memory avg, and top outbound peers.
Common mistake
Trusting a single automated pass; always validate with owners and logs to catch transient dependencies.
Key Takeaway

Discovery must include runtime network data and owner validation to form safe migration waves.

How to use this output
  • Group servers with mutual peers for coordinated migration waves.
  • Flag systems with high memory or CPU for sizing estimations in TCO.
  • Record owners and compliance tags before planning cutovers.
