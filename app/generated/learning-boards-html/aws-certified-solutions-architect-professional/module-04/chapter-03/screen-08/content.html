Design notes

  • Ensure idempotency and retries for distributed operations.
  • Instrument tracing and metrics across service boundaries.
Concrete code example
A simple Lambda that stores a user in DynamoDB and publishes an SNS message shows the focused responsibilities of a refactored microservice.
# Lambda function to process a new user registration (part of a refactored auth service)
import json
import os
import boto3

dynamodb = boto3.resource('dynamodb')
users_table = dynamodb.Table(os.environ['USERS_TABLE_NAME'])
sns_client = boto3.client('sns')

def lambda_handler(event, context):
  try:
    body = json.loads(event['body'])
    username = body['username']
    email = body['email']
    password_hash = body['password_hash']

    users_table.put_item(
      Item={
        'username': username,
        'email': email,
        'passwordHash': password_hash,
        'status': 'pending_verification'
      }
    )

    sns_client.publish(
      TopicArn=os.environ['VERIFICATION_TOPIC_ARN'],
      Message=json.dumps({
        'username': username,
        'email': email,
        'verificationCode': 'some_generated_code'
      }),
      Subject='New User Registration'
    )

    return {
      'statusCode': 200,
      'body': json.dumps({'message': 'User registered successfully. Verification email sent.'})
    }

  except Exception as e:
    print(f"Error processing registration: {e}")
    return {
      'statusCode': 500,
      'body': json.dumps({'message': f'Error: {str(e)}'})
    }
Key Takeaway

Small, focused functions are easier to test and deploy, but you must plan for observability and distributed error handling.
