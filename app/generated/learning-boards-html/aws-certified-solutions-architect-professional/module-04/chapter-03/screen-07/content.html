Definition
Refactoring (Re-architect)
Fundamental redesign to leverage serverless, containers, and event-driven architectures.
Breaking a monolith into microservices reduces blast radius and enables independent deployments and scaling.
Refactoring commonly uses Lambda, API Gateway, Step Functions, SQS, and SNS or container orchestration like EKS/ECS for complex services.
The approach requires CI/CD maturity, distributed tracing, retries, and a cultural shift to manage services instead of servers.
Key Takeaway

Refactoring maximizes cloud benefits but requires investment in architecture, tools, and skills.

Concrete refactor example
Extract authentication into a Lambda behind API Gateway, store users in DynamoDB, and publish events to SNS for verification workflows.
Benefits
  • Independent scaling and faster deployments.
  • Smaller teams owning discrete services.
  • Event-driven decoupling for resilience.
Challenges
  • Increased operational overhead and distributed tracing needs.
  • Complexity in data consistency across services.
