Module 4 › Chapter 4.6 › CI/CD
Flow
  1. Source commit triggers pipeline (CodeCommit or other).
  2. Build stage builds artifact: SAM package or Docker image (CodeBuild).
  3. Test stage runs unit and integration tests and security scans.
  4. Deploy stage applies changes: CloudFormation/SAM deploy or ECS/EKS rollout.
Use immutable artifacts and promote them between stages rather than rebuilding in each environment.
Example checks
  • Unit tests for function logic and containerized app code.
  • Integration tests that hit a staging endpoint.
  • Image vulnerability scan and secret detection.
Operational tip
Use canary or blue/green deployments to reduce blast radius when updating production services.
