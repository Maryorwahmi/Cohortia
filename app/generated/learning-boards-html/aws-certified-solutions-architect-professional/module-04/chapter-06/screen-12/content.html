Module 4 › Chapter 4.6 › Monitoring & Security
Observability
Use CloudWatch metrics for Lambda and Container Insights or Prometheus for containers. Add X-Ray for traces to see distributed request paths.
Security
Apply least-privilege IAM roles for functions and tasks. Scan images and avoid embedding credentials in images or code.
Operational checks
  • Alerts on error rate and latency increase.
  • Pipeline gates for performance and security checks.
  • Runbook for incident response and rollback procedures.
