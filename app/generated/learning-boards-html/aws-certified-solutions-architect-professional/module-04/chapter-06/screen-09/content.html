Commands (conceptual)

Deployment notes
Use task roles and secrets stored in parameter store or secrets manager rather than bake-time variables. For Fargate, you do not manage nodes, only task definitions and scaling policies.
Pro tip
Use multi-stage builds and remove dev dependencies to speed deploys and reduce attack surface.
Pitfall
Forgetting to grant the task role ECR pull permissions or to configure appropriate security groups for networking.
Ask: what parts of your CI pipeline should verify image security before deployment?
