Definition

Dockerfile example

# Example Dockerfile for a Node.js application FROM node:16-alpine WORKDIR /app COPY package*.json ./ RUN npm install COPY . . EXPOSE 3000 CMD ["npm", "start"]
This sequence installs dependencies separately to leverage build cache, then copies source and defines the default command. Smaller base images and multi-stage builds reduce final image size.
Practical notes
  • Use multi-stage builds to remove build-time dependencies from final images.
  • Scan images for vulnerabilities and minimize layers for faster pulls.
  • Push images to ECR and reference them in task definitions or manifests.
Key Takeaway

Containers give runtime control and portability. Optimize image size and scan for security before deployment.
