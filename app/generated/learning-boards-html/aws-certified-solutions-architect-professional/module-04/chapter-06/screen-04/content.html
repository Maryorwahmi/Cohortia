Module 4 › Chapter 4.6 › Serverless Computing
Definition

AWS Lambda

Run code without managing servers. Pay-per-use billing and automatic scaling for event-driven workloads.

Why use it
  • Fast iteration for small units of work.
  • Automatic scaling with traffic.
  • Lower operational overhead for many scenarios.
Key Takeaway

Serverless fits short, stateless tasks. Use queues and event buses to decouple and absorb bursts.

Example
// Image thumbnailer example // Trigger: ObjectStore upload event function handler(event) { // fetch object, resize, save thumbnail }
Design considerations
  • Limit execution time and keep functions stateless.
  • Mitigate cold-starts with provisioned concurrency when needed.
  • Use IAM roles scoped to required resources only.
Common mistake
Treating functions like long-running services.
Pro tip
Push heavy or stateful work to containers or managed compute if duration or drivers are needed.
