Module 4 › Chapter 4.6 › Cost & Performance
Serverless tips
  • Measure function execution time and tune memory to optimize cost.
  • Use provisioned concurrency for latency-sensitive endpoints only.
  • Buffer bursts with SQS to avoid synchronous scaling costs.
Container tips
  • For predictable load, right-size EC2 instances or use reserved capacity.
  • Use Fargate for variable workloads to avoid over-provisioning.
  • Consider Spot for fault-tolerant tasks to reduce compute costs.
Key Takeaway
Optimization is measurement-driven. Validate tuning with load tests and cost estimates before applying to production.
