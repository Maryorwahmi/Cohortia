Module 4 › Chapter 4.4 › Homogeneous vs Heterogeneous
Definitions
Homogeneous Migration
Same engine on source and target; primary focus is data movement and minimizing downtime.
Heterogeneous Migration
Different engines; requires schema conversion, code refactor, and compatibility testing.
Common Misconception
Assuming DMS converts stored procedures. DMS migrates data; SCT handles schema and code analysis and conversion.
Key Takeaway

Classify the migration early to pick the right tools and estimate manual conversion effort.

Concrete Example
Scenario: A 500 GB SQL Server application with many stored procedures needs to move to Aurora PostgreSQL. This is a heterogeneous migration that requires SCT to detect incompatible stored procedures, manual refactoring of T-SQL to PL/pgSQL where needed, and DMS to migrate data with CDC to keep downtime short.
