Module 4 › Chapter 4.4 › Common Mistakes
Mistakes & implications
Incomplete Schema Conversion: SCT flags issues; manual refactor is often required.
Data Type Mismatches: Can cause data loss or corruption if not correctly mapped and tested.
Network Latency: High latency increases replication lag; consider Direct Connect for large transfers.
Under-sized Replication Instance: Causes CPU, memory, or IO bottlenecks and slows replication.
Transaction Log Retention: Must keep sufficient history for CDC to read changes; configure retention accordingly.
Safety & testing
Conduct functional testing, data integrity checks, and performance tests in a staging environment. Prepare rollback plans and ensure encryption in transit and at rest for endpoints. Automate verification steps where possible to reduce human error during cutover.
Key Takeaway

Treat migration like a software release: test, size, secure, and rehearse cutover in staging before production.
