Module 4 › Chapter 4.4 › Migration Plan Activity
Phase checklist
  1. Assessment: run SCT and catalog incompatibilities.
  2. Target prep: provision Aurora, consider Babelfish.
  3. Networking & security: ensure replication connectivity and encryption.
  4. Replication: create DMS endpoints, instance, and start full-load-and-CDC.
  5. Verify: checksums, smoke tests, performance tuning in staging.
  6. Cutover: write freeze, CDC catch-up, validate, switch clients, monitor.
Challenges & mitigations
Complex procedures: schedule manual rewrite using SCT reports and test coverage.
Application compatibility: trial with Babelfish or refactor queries identified by SCT.
Key Takeaway

Break the migration into phases and rehearse each phase in staging to reduce risk during production cutover.
