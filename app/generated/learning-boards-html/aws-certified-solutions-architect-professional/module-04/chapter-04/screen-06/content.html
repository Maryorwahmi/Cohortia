Migration types
Full Load
Copies all current data; simplest but requires downtime if no CDC.
CDC (Change Data Capture)
Streams ongoing changes; used to keep target synchronized after initial load.
Full-load-and-CDC
Initial full copy plus CDC for minimal-downtime cutovers.
Operational checklist
  • Choose tables and schemas to include to limit data size.
  • Start full load during off-peak or in parallel with replication.
  • Monitor replication lag, transaction log retention, and network throughput.
  • Plan a short write freeze for cutover: stop writes, wait for catch-up, validate, and redirect clients.
Key Takeaway

Full-load-and-CDC is typically required when downtime must be minimal. Prepare table mappings and monitoring in advance.
