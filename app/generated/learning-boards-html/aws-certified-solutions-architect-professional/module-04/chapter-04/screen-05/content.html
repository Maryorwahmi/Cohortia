Module 4 › Chapter 4.4 › AWS DMS
What DMS provides
  • Replication instance: the compute that performs migration tasks.
  • Endpoints: credentials and connection details for source and target.
  • Replication tasks: define table mappings and migration type (full load, CDC, or both).
  • Monitoring: metrics for lag, CPU, memory, and I/O to validate performance.
Common Mistake

Under-sizing the replication instance or ignoring network bandwidth produces replication lag and jeopardizes cutover windows.

Concrete scenario
You create a replication instance, configure an on-premises source endpoint and an Aurora PostgreSQL target endpoint, then start a task using full-load-and-CDC. Monitor replication lag in CloudWatch and the DMS console. Increase instance class if lag grows during peak times. Validate data with row counts and checksums before cutover.
Key Takeaway

DMS is for data movement plus CDC; size resources and network capacity to meet recovery-time objectives.
