Module 4 › Chapter 4.4 › AWS SCT
What SCT does
  • Generates an assessment report highlighting incompatible objects.
  • Attempts automatic conversions for schema objects and some code.
  • Creates converted DDL and suggests manual rewrite for flagged items.
Common Mistake

Assuming SCT eliminates the need for manual testing and rewrite of stored procedures; always plan for manual refactor work.

Before / After example
Before: T-SQL stored procedure using SQL Server types and built-in functions. After: SCT converts tables and simple queries, flags the stored procedure for manual rewrite to PL/pgSQL. Use the SCT report to estimate engineer hours and prioritize high-risk objects.
Key Takeaway

Run SCT early to scope conversion work and schedule manual refactors into your migration timeline.
