Cutover process — numbered checklist
  1. Full load: run initial DMS copy for selected tables and schemas.
  2. Enable CDC: start streaming ongoing changes to the target.
  3. Pre-cutover verification: run row counts, checksums, and smoke tests against target.
  4. Write freeze: stop writes to source, wait for CDC to apply remaining changes.
  5. Switch connections: update application endpoints and start services on the target.
  6. Monitor & validate: ensure logs, performance, and integrity are correct.
Verification
Use sample checksums, not only row counts, and include application smoke tests.
Rollback plan
Prepare an explicit rollback path and test it in staging so you can revert quickly if needed.
Monitoring
Watch replication lag, database errors, and application logs immediately after cutover.
