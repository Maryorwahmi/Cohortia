Module 4 › Chapter 4.4 › Monitoring & Post-Migration
Runtime monitoring
  • Replication lag, CPU, memory, and disk I/O metrics via CloudWatch.
  • Alarms for lag thresholds and resource saturation.
  • Network throughput monitoring to detect bottlenecks.
Scaling tip

Scale replication instance or tune parallelism when lag is sustained during high throughput periods.

Post-cutover checklist
  • Run comprehensive data integrity checks and reconcile critical reports.
  • Tune indexes and queries on the target to match performance requirements.
  • Rotate secrets, validate backups, and update security rules.
  • Plan decommissioning only after a retention and verification window.
Key Takeaway

Continue monitoring and tuning after cutover; successful migration includes the stabilization phase.
