Module 5 › Chapter 4.7 › FinOps Cycle
Process Flow

Observe → Analyze → Act → Review

Follow a short, repeatable cycle so financial decisions are data-driven and reversible where necessary.

01
Observe
Collect costs, tags, and utilization metrics using Cost Explorer and CloudWatch.
02
Analyze
Identify underutilization, storage tiering opportunities, and anomalous spend.
03
Act
Right-size, change storage class, schedule non-prod shutdowns, or apply Savings Plans where suitable.
04
Review
Measure impact, update runbooks, and repeat the cycle on a regular cadence.
Example scenario
A batch processing service runs nightly. Analyze average CPU and memory across weeks. If utilization is consistently low, resize the instances, or migrate the job to Spot Instances if it tolerates interruptions. Validate that job completion time remains acceptable post-change.
Misconception
Buying a long-term commitment without right-sizing first can lock in waste. Always measure before purchase.
Key Takeaway

Continuous cycles yield sustained savings; small, repeatable actions compound over time.
