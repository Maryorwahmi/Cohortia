Module 5 › Chapter 4.7 › Threat Detection
Detect
Enable GuardDuty to analyze account and network activity and run Amazon Inspector for workload assessments.
Aggregate
Send findings to Security Hub to unify alerts and prioritize remediation by severity and business impact.
Example
GuardDuty flags suspicious API usage for an IAM role; Security Hub aggregates it and triggers a runbook to rotate keys and quarantine resources.
Remediate
Automate urgent remediation and route longer tasks to ticketing systems with clear ownership and timelines.
Key Takeaway
Detection without prioritized response wastes time. Build playbooks for the top findings and automate what you can safely remediate.
