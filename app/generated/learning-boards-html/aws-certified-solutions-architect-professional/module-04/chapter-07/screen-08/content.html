Code walkthrough

This Lambda function iterates regions, filters running instances by an Environment tag, and stops them. Use as a scheduled cost-saver for non-production.

# --- Example Lambda function for stopping non-prod EC2 instances ---
import boto3

def lambda_handler(event, context):
  ec2 = boto3.client('ec2')
  regions = ec2.describe_regions()['Regions']

  for region_data in regions:
    region = region_data['RegionName']
    ec2_region = boto3.client('ec2', region_name=region)
    
    # Find instances tagged for non-production and running state
    reservations = ec2_region.describe_instances(
      Filters=[
        {'Name': 'tag:Environment', 'Values': ['dev', 'test', 'staging']},
        {'Name': 'instance-state-name', 'Values': ['running']}
      ]
    )['Reservations']

    instances_to_stop = []
    for reservation in reservations:
      for instance in reservation['Instances']:
        instances_to_stop.append(instance['InstanceId'])
    
    if instances_to_stop:
      print(f"Stopping instances in {region}: {instances_to_stop}")
      ec2_region.stop_instances(InstanceIds=instances_to_stop)
    else:
      print(f"No non-production instances to stop in {region}.")

  return {
    'statusCode': 200,
    'body': 'Non-production instances stopped.'
  }
Pro tip
Add a dry-run mode that logs instance IDs without stopping, and require an exempt tag to skip critical instances.
How to test safely
  1. Run the function in dry-run mode in a dev account with a known tagged instance.
  2. Confirm logs show expected instance IDs and no untagged instances are affected.
  3. Enable stop actions after approvals and add a notification step for teams.
Key Takeaway

Automations save money but require safe defaults: dry-run, logs, exempt tags, and non-production testing.
