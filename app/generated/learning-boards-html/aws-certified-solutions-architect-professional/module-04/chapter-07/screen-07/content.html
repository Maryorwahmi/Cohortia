Storage Optimization

Tier by access pattern

Use lifecycle policies to move objects to S3 Glacier or Deep Archive. Delete unused EBS volumes and snapshot strategically.

Example
Archive logs older than 90 days to Glacier Deep Archive, retaining retrieval options aligned with business needs.
Takeaway
Lifecycle rules reduce manual effort and ensure data is stored at the right cost point.
Serverless Cost Management

Tune memory and execution

Adjust Lambda memory to balance CPU and duration. For DynamoDB choose on-demand for spikes or provisioned capacity for stable loads.

Example
Reduce a Lambda function's memory after profiling to cut execution time and cost while maintaining acceptable latency.
Common mistake
Assuming serverless removes the need to optimize code. Inefficient code increases duration costs.
