Module 5 › Chapter 4.7 › Security Posture
Identity & Access

Review IAM roles for least privilege and use Access Analyzer to detect risky permissions. Rotate keys and enforce MFA for privileged users.

Network controls
Harden Security Groups, apply WAF rules, and consider Shield for DDoS-sensitive services.
Data & Detection

Encrypt at rest and in transit using KMS. Enable GuardDuty and aggregate alerts in Security Hub for prioritized response.

Vulnerability management
Scan container images and run Inspector assessments regularly.
Key takeaway
Security is continuous: combine automated detection with scheduled reviews and remediation runbooks.
