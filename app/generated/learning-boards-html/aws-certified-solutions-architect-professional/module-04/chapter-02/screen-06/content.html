Module 4 › Chapter 4.2 › AWS MGN Architecture
MGN components
Agent
Collects disk blocks and streams changes to AWS.
Staging area
Temporary storage where replicated blocks are held and transformed.
Conversion
MGN converts blocks into an EC2-compatible volume image.
Launch
Automated provisioning of EC2 instances using launch settings.
Monitoring signals
  • Data replication state and lag duration indicate readiness.
  • Use logs and test launches to confirm application behavior before cutover.
Practical checklist
Before replication
Confirm IAM permissions, network access for agent, and encryption requirements for data in transit and at rest.
During replication
Monitor lagDuration and ensure continuous replication states are healthy.
Before cutover
Run test launches, validate security groups and IAM, and prepare rollback instructions.
Key Takeaway

MGN automates replication and provisioning but relies on thorough pre-cutover validation to avoid surprises during production cutover.
