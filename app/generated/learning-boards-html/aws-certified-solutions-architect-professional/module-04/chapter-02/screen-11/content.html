3-Wave Example (100 VMs)
Group by criticality and apply cutover strategy per wave
Wave 1
Category A (30 VMs) — Low criticality. Recommended: Big Bang or simple cutover. Pre: Install agents and start replication. Post: Right-size and integrate monitoring.
Wave 2
Category B (50 VMs) — Medium criticality. Recommended: Phased DNS Swap with extra test launches. Pre: Multiple test cutovers. Post: Implement automated patching and scaling policies.
Wave 3
Category C (20 VMs) — High criticality. Recommended: Pilot Light/Warm Standby for low RTO. Pre: Dedicated connectivity and rehearsed promotions. Post: Harden security and finalize scaling runbooks.
Key Takeaway

Use iterative waves to reduce risk. Start with low-risk systems to validate processes, then apply lessons to more critical waves with stricter cutover controls.
