Module 4 › Chapter 4.2 › Post-Migration Optimization
Optimization steps
  1. Measure utilization with CloudWatch for CPU, memory, and disk.
  2. Right-size EC2 instances to match observed usage.
  3. Apply security best practices: Security Groups, IAM, logging.
  4. Integrate automation and monitoring for operations.
  5. Choose cost-saving commitments only after stable sizing.
Example sequence
If instances show under 15% CPU and 30% memory, plan right-sizing before buying Reserved Instances or Savings Plans. Use Systems Manager for patches and CloudWatch for alerting.
Key Takeaway

Optimize based on measured patterns. Right-size first, secure and monitor, then commit to savings plans to avoid wasted spend.
