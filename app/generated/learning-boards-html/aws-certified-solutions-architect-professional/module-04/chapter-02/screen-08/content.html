Module 4 › Chapter 4.2 › Cutover Strategies
Strategy comparison
Big Bang
All services switch at once. Simpler coordination but longer downtime window; use when hybrid operation is undesirable and rollback is clear.
Phased DNS Swap
Migrate components in groups and update DNS after validation. Offers control; requires DNS planning and session-state management.
Pilot Light / Warm Standby
Run minimal or scaled infrastructure in AWS that can be promoted. Best for very low RTO but costs more to maintain.
Practical considerations
  • DNS propagation delays affect Phased strategies — plan TTLs and routing carefully.
  • Maintain rollback docs for any cutover; test the rollback path during rehearsals.
  • For Pilot Light, rehearse scaling actions to ensure you can promote quickly.
Key Takeaway

Choose the cutover that aligns RTO/RPO, dependencies, and budget. Test the plan multiple times to uncover hidden risks.
