Common CLI sequence
Use these commands to inspect, test, and cut over a source server.
# 1. List source servers discovered by MGN
aws mgn describe-source-servers

# Expected output includes sourceServerID and dataReplicationInfo

# 2. (Console or script) Configure launch settings or a launch template
# Example: set instance type t3.large for the target

# 3. Launch a test instance
aws mgn start-test-launch --source-server-ids s-1234567890abcdef0

# 4. Perform cutover after validation
aws mgn start-cutover --source-server-ids s-1234567890abcdef0
Verification
Check system logs, application endpoints, and network reachability after test launch.
Rollback plan
Ensure DNS and traffic cutover steps can be reverted, and document a clear rollback path.
Test launch checklist
  • Confirm replication state is CONTINUOUS and lag is acceptable.
  • Verify instance boots and services start correctly.
  • Test integrations like databases and DNS resolution.
  • Document any configuration drift and fix before cutover.
Key Takeaway

Treat test launches as the critical gate. Multiple validation runs under realistic conditions reduce cutover risk substantially.
