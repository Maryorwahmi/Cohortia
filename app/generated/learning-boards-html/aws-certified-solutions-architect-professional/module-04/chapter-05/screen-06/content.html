Module 4 › Chapter 4.5 › AWS Transfer Family
Definition

Protocol-compatible file transfer

Offer SFTP, FTPS, or FTP endpoints that deposit files into S3 or EFS without changing external clients.

Concrete scenario
A partner with existing SFTP clients continues to upload daily files. You replace the on-prem server with Transfer Family, preserving client behavior while storing files directly in S3 for analytics.
Design items
  • Authentication method and user mapping.
  • IAM role mapping to target buckets or file systems.
  • CloudWatch logging for auditing transfers.
When to choose Transfer Family
  • External partners require unchanged client behavior.
  • Daily to frequent transfers of small-to-medium size files.
  • Need managed endpoints with audit logs and IAM control.
Misconception
Transfer Family is not primarily designed for bulk offline migration of petabytes; use Snow Family for extreme volumes.
