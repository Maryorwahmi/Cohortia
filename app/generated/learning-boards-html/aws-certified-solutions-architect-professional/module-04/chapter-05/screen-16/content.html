Module 4 › Chapter 4.5 › Key Concepts
AWS Snow Family
Physical devices for offline transfer and edge compute.
AWS DataSync
Managed service to accelerate secure online transfers and syncs.
AWS Transfer Family
Managed SFTP/FTPS/FTP endpoints into S3 or EFS for legacy workflows.
Online / Offline Transfer
Online moves data over networks; offline ships physical devices to bypass bandwidth limits.
AWS Direct Connect
Dedicated connection option for predictable high-throughput transfers.
Checksums
Integrity checks used to validate data before and after migration.
Summary

Match service to constraint, validate with a pilot, and include security and integrity checks in every migration plan.
