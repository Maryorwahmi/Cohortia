Security

Encryption, access control, and auditing

  • Encrypt data at rest and in transit; Snow devices encrypt data locally before shipping.
  • Use least-privilege IAM roles for DataSync, Transfer Family, and S3 access.
  • Use VPC endpoints to keep traffic on the AWS network and reduce exposure.
  • Enable CloudTrail for auditing API calls related to migration tasks and device operations.
Chain-of-custody
Document who receives, handles, and returns Snow devices and control unlock credentials to meeting compliance needs.
Key Takeaway

Treat the migration as a secure project: define encryption, roles, network isolation, and logging up front and validate them during the pilot.
