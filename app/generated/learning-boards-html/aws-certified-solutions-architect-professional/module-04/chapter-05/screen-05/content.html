Module 4 › Chapter 4.5 › AWS DataSync
Process Flow

Agent → DataSync → S3/EFS

Deploy an agent on-prem, configure source and destination locations, create a task, and run scheduled or ad-hoc transfers.

Agent deployment
Deploy a VM image and activate the agent with a key to connect on-prem storage to DataSync.
Task configuration
Set verify mode, overwrite behavior, and logging to CloudWatch to meet integrity and audit requirements.
Performance
DataSync uses parallel streams and an optimized protocol to outperform general-purpose copy tools.
Key Takeaway

DataSync is optimized for secure, accelerated online transfers and ongoing synchronization; include agent placement, IAM, and monitoring in your plan.

Concrete example & code
A conceptual set of CLI steps shows how a DataSync task is created and started. Use the AWS CLI to create agent, locations, task, then start the task. The service handles integrity checks and parallelization.
# --- AWS CLI commands for DataSync (conceptual) ---

# 1. Create a DataSync Agent (on-premises)
# aws datasync create-agent --agent-name "OnPremAgent01" --activation-key "your-activation-key"

# 2. Create a source location (NFS)
aws datasync create-location-nfs \
    --server-hostname "your-nfs-server.local" \
    --subdirectory "/export/data" \
    --on-prem-config "AgentArns=arn:aws:datasync:us-east-1:123456789012:agent/agent-xxxxxxxxxxxxxxxxx" \
    --tags Key=Name,Value=OnPremNFSLocation

# 3. Create a target location (S3)
aws datasync create-location-s3 \
    --s3-bucket-arn "arn:aws:s3:::your-target-bucket" \
    --s3-config "BucketAccessRoleArn=arn:aws:iam::123456789012:role/DataSyncS3AccessRole" \
    --tags Key=Name,Value=TargetS3Location

# 4. Create and start a DataSync task
aws datasync create-task \
    --source-location-arn "arn:aws:datasync:us-east-1:123456789012:location/loc-xxxxxxxx" \
    --destination-location-arn "arn:aws:datasync:us-east-1:123456789012:location/loc-yyyyyyyy" \
    --cloud-watch-log-group-arn "arn:aws:logs:us-east-1:123456789012:log-group:/aws/datasync/task/your-task-name" \
    --name "MigrateNFSDataToS3" \
    --options VerifyMode=POINT_IN_TIME_CONSISTENT,OverwriteMode=ALWAYS,TaskQueueing=ENABLED

# Start:
# aws datasync start-task-execution --task-arn "arn:aws:datasync:us-east-1:..."
Misconception
Don't assume DataSync is a drop-in for legacy FTP workflows; it's built for system-to-system transfers and synchronization. For protocol compatibility with partners, consider Transfer Family instead.
