Module 4 › Chapter 4.5 › Assessment Explanation

Assessment walkthrough

Convert bandwidth into practical transfer time, include overhead, and compare to deadlines. If the network path cannot meet the time requirement, select a Snow device sized for the dataset.

Practical calculation
Estimate effective throughput, then divide dataset size by throughput to estimate wall-clock transfer time; include headroom for retries and protocol overhead.
Decision rule
If estimated network time exceeds the deadline, choose a Snow Family device with appropriate usable capacity and plan logistics.
Key Takeaway

Numeric estimates guide the right choice: convert Mbps into expected days, include overhead, and decide between network or device based on timeline feasibility.
