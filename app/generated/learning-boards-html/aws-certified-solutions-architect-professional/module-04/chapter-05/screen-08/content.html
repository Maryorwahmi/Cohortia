Module 4 › Chapter 4.5 › Snow Family Workflow
Process Flow
  1. Order device — Plan capacity and timeline, order appropriate Snow device.
  2. Connect & copy — Attach device to local network and use provided tools to copy data, ensuring encryption is enabled.
  3. Ship to AWS — Return the device with chain-of-custody tracking enabled.
  4. AWS ingestion — AWS uploads data to S3 and confirms completion; validate checksums against originals.
Operational notes
  • Plan shipping and customs lead time.
  • Consider parallel devices to shorten overall migration time.
  • Document who can unlock and access devices to preserve chain-of-custody.
Example
For a 500 TB archive with limited bandwidth, order multiple Snowball Edge devices, copy partitions of the archive in parallel, and ship them back staggered to reduce overall migration time.
Common mistake

Underestimating logistics and not allowing buffer time for shipping, customs, and ingestion leads to missed deadlines even when physical transfer is chosen.
