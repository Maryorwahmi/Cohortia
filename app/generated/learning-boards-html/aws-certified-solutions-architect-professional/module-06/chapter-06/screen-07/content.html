Event-driven isolation
Design rules that trigger only on high-severity findings. Automate isolation and evidence capture to reduce response time.
EventBridge rule matches GuardDuty high severity.
Lambda is invoked to isolate instance and snapshot volumes.
Tagging and notifications ensure traceability and team awareness.
Common mistake: overly broad EventBridge patterns or Lambda permissions that trigger isolation on low-confidence signals.
EventBridge Rule Example (conceptual)
{
  "source": ["aws.guardduty"],
  "detail-type": ["GuardDuty Finding"],
  "detail": {
    "severity": [
      { "numeric": [ ">=", 7 ] }
    ],
    "type": [
      "Backdoor:EC2/C&CActivity.B",
      "UnauthorizedAccess:EC2/MaliciousIpCaller.Custom"
    ]
  }
}
Analyst note
This pattern ensures the rule triggers on high-severity EC2 findings. Test with sample events before production deployment.
