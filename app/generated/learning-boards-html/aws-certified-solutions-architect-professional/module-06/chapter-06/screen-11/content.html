Forensic Readiness
Isolated evidence workflow
Copy artifacts into a dedicated forensic account using controlled mechanisms and strict policies; analyze there to avoid contamination.
Use cross-account snapshot copy for EBS volumes.
Replicate CloudTrail to a forensic S3 bucket with strict access.
Run read-only collection commands via Systems Manager into the forensic store.
Practical tags and metadata
Consistently tag snapshots and resources with IncidentID and ForensicReady to simplify evidence correlation by analysts.
Common mistake
Analyzing evidence in the compromised account can modify metadata and break chain-of-custody.
Key Takeaway

Move evidence to a locked forensic account and analyze there under strict access controls to preserve integrity.
