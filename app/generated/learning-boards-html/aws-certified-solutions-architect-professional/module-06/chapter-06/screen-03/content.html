Learning Objectives — Implementation
Concrete verification steps and safe practices.
Learn → Understand → Apply → Master
01: Runbooks & Exercises
Create concrete runbooks with exact AWS console or CLI steps. Verify with a tabletop or a controlled simulation.
VERIFIED COMPETENCY MILESTONE
02: Automation Test
Deploy EventBridge and Lambda, then invoke with a test payload to confirm isolation and snapshot behavior.
VERIFIED COMPETENCY MILESTONE
03: Forensic Account
Automate secure copying of snapshots and logs to a dedicated forensic account. Verify access controls regularly.
VERIFIED COMPETENCY MILESTONE
04: Post-Incident Improvement
Document actions, update runbooks, and close action items after a lessons-learned review.
VERIFIED COMPETENCY MILESTONE
