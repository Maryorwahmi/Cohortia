Scenario: Automate isolation
Follow these steps in your lab account to validate automation and evidence capture.
  1. Create IAM role for Lambda with scoped EC2 rights and basic execution.
  2. Deploy Lambda IsolateCompromisedEC2 and test by invoking with instance_id.
  3. Create EventBridge rule matching GuardDuty severity >= 7 for Instance resource and add Lambda as target.
  4. Validate: instance is isolated, snapshots exist, and tags include IncidentID.
Verification tips
  • Manually invoke Lambda for a known instance to observe expected actions.
  • Inspect CloudTrail to confirm assume-role and snapshot APIs are logged.
  • Confirm snapshots are tagged with IncidentID and ForensicReady=true.
Pro Tip

Use a staging forensic account for verification and never use production logs for experimental tests.
