Module 6 › Chapter 6.7 › AWS Config Rules
Capability

Continuous configuration evaluation

Rules evaluate resources on configuration change and periodically to identify drift from desired state.

Example rule
A managed rule named encrypted-volumes checks whether EBS volumes are encrypted and marks unencrypted volumes non-compliant.
Remediation

Use notifications and automated remediation pipelines when a rule detects non-compliance. Pair rules with playbooks for human review when needed.

Pitfall

Not acting on findings leads to compliance drift. Schedule regular reviews of rule results and remediation status.
