Module 6 › Chapter 6.7 › Control Tower
What it does

Control Tower landing zone

  • Automates account factory and core accounts
  • Configures AWS Organizations at baseline
  • Deploys guardrails (prevention and detection)
Example guardrails
Prevent public S3; detect unencrypted EBS; require logging and centralized logs.
Design notes

Decide which controls must be preventive (implemented by SCPs) and which can be detective (Config Rules with remediation).

Operational tip

Enroll existing accounts or apply equivalent guardrails to avoid inconsistent security posture.

Common Mistake

Assuming Control Tower replaces all governance controls — it sets a baseline and must be complemented by Config Rules and remediation processes.
