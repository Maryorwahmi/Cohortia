Module 6 › Chapter 6.7 › Encrypted Volumes Rule
Managed rule

encrypted-volumes

# Example: AWS Config managed rule
# Rule Name: encrypted-volumes
# Description: Checks whether Amazon EBS volumes are encrypted.
# Trigger: On configuration changes and periodic evaluations
# Action: Marks unencrypted EBS volumes as NON_COMPLIANT
Test

Enable the managed rule and create a non-encrypted EBS volume to verify the rule marks it non-compliant.

Remediation options
  • Automated snapshot + create encrypted volume
  • Replace volume in maintenance window
  • Raise operational ticket with SLA
Common Mistake

Assuming detection equates to remediation; document and test the remediation path.
