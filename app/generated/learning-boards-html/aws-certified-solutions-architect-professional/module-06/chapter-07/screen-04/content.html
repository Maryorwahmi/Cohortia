Definition

Shared Responsibility Model

A framework dividing responsibility for security between AWS and the customer.

AWS is responsible for
  • Physical infrastructure and global network
  • Host and hypervisor security
  • Managed service availability and isolation
You are responsible for
  • Data, encryption, and key management
  • OS, application config, and IAM
  • Network configuration and security groups
Key Takeaway

Document ownership for each control area to avoid compliance gaps during audits.

Analogy

Think of AWS as the building and utilities; you are responsible for the content of your office and its locks.

Example Task
Create an ownership matrix across Compute, Storage, Network, and Identity showing who patches, who configures encryption, and who audits logs.
Common Mistake

Assuming AWS certifications remove your need to secure data and manage configurations.
