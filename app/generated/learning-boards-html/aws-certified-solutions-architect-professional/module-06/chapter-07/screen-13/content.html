Module 6 › Chapter 6.7 › Pitfalls

Common mistakes and anti-patterns

Ownership gaps

Assuming AWS handles application or configuration security — leads to uncovered controls.

Static rules

Not updating Config Rules over time causes false confidence as services change.

Unmanaged accounts

Failing to enroll accounts in Control Tower causes inconsistent baselines and extra audit work.

Practical guardrails

Automate detection, define remediation playbooks, and schedule regular compliance reviews that include Audit Manager outputs.
