Module 6 › Chapter 6.7 › Audit Manager
Process

Set up an assessment

1
Choose a framework
Select a pre-built framework such as PCI DSS, HIPAA, or GDPR to map controls automatically.
2
Connect evidence sources
Point Audit Manager to Config, CloudTrail, Security Hub, and other sources to collect evidence continuously.
3
Review and report
Use auditor-friendly reports and track findings. Export evidence for your auditor when needed.
Example

Run a PCI DSS assessment and have Audit Manager collect evidence from Config rules that check encryption and from CloudTrail for access logs.

Pro Tip

Define who reviews evidence items and how remediation is tracked so that Audit Manager feeds into an operational process, not just a report.

Misconception

Audit Manager organizes evidence but does not remediate resources automatically; pair it with Config or automation for fixes.
