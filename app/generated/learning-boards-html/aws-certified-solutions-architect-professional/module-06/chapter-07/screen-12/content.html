Monitor IMDSv2 with AWS Config

Four steps to detect EC2 instances that do not enforce IMDSv2.

Step 1 — Enable AWS Config

Ensure Config is recording all supported resource types and has permissions to read EC2 state.

Step 2 — Add Rule

In Config Rules, search for ec2-imdsv2-enabled and add it with default triggers (configuration change, periodic).

Step 3 — Test

Optionally launch an EC2 instance configured for IMDSv1 only and wait for Config evaluation to show non-compliant status.

Step 4 — Review

Open the rule in Config to see non-compliant resources and review details for remediation planning.

Why this matters

IMDSv2 reduces metadata attack surface. Detecting instances without it protects credentials and metadata-based attacks.
