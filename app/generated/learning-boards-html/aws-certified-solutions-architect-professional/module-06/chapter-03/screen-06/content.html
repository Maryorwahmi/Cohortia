AWS-managed key
Service-controlled, minimal setup, limited audit control.
Customer-managed CMK
Full policy control, rotation, and auditability — preferred for sensitive data.
Imported key material
Bring your own key material into KMS for specialized compliance needs.
Step-by-step best practices
  1. Create clear aliases and document key owner and purpose.
  2. Define a minimal set of administrators and usage principals.
  3. Grant kms:GenerateDataKey to uploaders and kms:Decrypt to readers only.
  4. Use CloudTrail to monitor GenerateDataKey and Decrypt activity.
Concrete scenario
A backup pipeline uses GenerateDataKey to get a data key for envelope encryption during upload, then the key is discarded. Analytics systems later call Decrypt via a restricted role to read the objects.
Misconfiguration
If you grant broad Decrypt permissions in IAM but do not update the KMS policy, the operation will still fail. Both must authorize the action.
