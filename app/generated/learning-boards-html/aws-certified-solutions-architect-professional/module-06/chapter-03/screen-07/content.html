Comparison › S3 encryption modes
SSE-S3
S3-managed keys, minimal config, low control and auditability.
SSE-KMS
Uses a KMS CMK you manage. Enables auditing, rotation, and explicit key policies.
SSE-C
Customer-provided key per request. AWS does not store the key; you must manage it externally.
Client-side encryption
Encrypt before upload using client libraries and your own key store. Highest control, highest responsibility.
Concrete example
For regulated financial data: use SSE-KMS with a customer-managed CMK so you can audit GenerateDataKey and Decrypt events, rotate keys on a defined schedule, and scope who can use the key.
