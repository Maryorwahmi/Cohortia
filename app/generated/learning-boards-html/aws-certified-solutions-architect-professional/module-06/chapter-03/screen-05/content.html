Definition › AWS KMS essentials
KMS responsibilities
  • Create and manage CMKs (AWS-managed, customer-managed, imported).
  • Authorize cryptographic operations through key policies.
  • Integrate with many AWS services to encrypt data at-rest.
Practical configuration tips
  • Name keys with clear aliases to map to datasets or applications.
  • Grant least privilege for kms:Decrypt and kms:GenerateDataKey.
  • Enable rotation where audit requirements permit automated rotation.
Concrete example
Create a customer-managed CMK named MySensitiveDataCMK, grant an application role permission to kms:GenerateDataKey, and use that key for SSE-KMS on an S3 bucket used for backups. Verify CloudTrail logs show GenerateDataKey calls from the role during uploads.
Misconception
Giving broad IAM permissions alone does not grant key use unless the KMS key policy or grants also permit it.
Key Takeaway

KMS is the control plane for keys; design key policies and service policies together to avoid access denied errors.
