Architecture › KMS integration
Service examples
  • S3: SSE-KMS with GenerateDataKey & Decrypt calls.
  • EBS: volume encryption configured with a CMK at creation.
  • RDS: storage and snapshot encryption driven by KMS keys.
  • Lambda: decrypt environment secrets or use keys for encryption.
Concrete example
Use one CMK for an application's backups and EBS volumes so audit logs show key usage across resources when troubleshooting access requests.
Integration checklist
  • Specify the correct CMK when creating resources.
  • Grant precise permissions to roles that will call GenerateDataKey or Decrypt.
  • Use CloudTrail to validate who used the key and for which service.
Common mistake
Assuming KMS will automatically protect all resources without explicitly configuring each service to use the CMK is a frequent oversight.
