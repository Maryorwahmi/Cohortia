Module 6 › Chapter 6.3 › Learning Objectives
01
Choose encryption for rest and transit

Select the appropriate encryption mode for stored and moving data, balancing control, compliance, and cost. You'll practice mapping sensitivity levels to modes like SSE-KMS or client-side encryption.

VERIFIED COMPETENCY MILESTONE
02
Master AWS KMS key management

Create and manage customer-managed CMKs, control key policies, and enable audit logging to track key usage across services. Learn rotation and lifecycle practices that meet compliance.

VERIFIED COMPETENCY MILESTONE
03
Apply S3 advanced controls

Use bucket policies to enforce encryption headers, configure access points for scale, and use object lock for WORM protection where needed.

VERIFIED COMPETENCY MILESTONE
04
Design cross-account encryption

Configure KMS key policies and S3 bucket policies so roles in other accounts can decrypt and access objects safely while preserving owner control and audit trails.
