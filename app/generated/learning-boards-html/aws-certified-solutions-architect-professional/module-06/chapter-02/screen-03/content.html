Learning Objectives — Applied

Concrete validation steps you should complete to verify competency.

Bloom: Apply → Master
01 — Cross-account role verification
  • Create role in workload account with trust for a specific auditor role.
  • Attach read-only EC2 policy and confirm assume-role via CLI.
  • Test you cannot perform write operations when assumed.
VERIFIED COMPETENCY MILESTONE
02 — Federation checks
  • Register SAML or OIDC provider in IAM and map assertions.
  • Create role with Federated principal and correct Condition (SAML:aud or OIDC issuer).
  • Validate signed assertions or JWTs and required audience fields.
VERIFIED COMPETENCY MILESTONE
03 — ABAC validation
  • Tag principal and resource the same and apply conditional policy using aws:PrincipalTag.
  • Test matching tags allow actions; mismatched tags deny them.
  • Use Policy Simulator for edge-case verification.
VERIFIED COMPETENCY MILESTONE
04 — Risk audits
  • Audit trust policies for wildcard Principals and broad Actions/Resources.
  • Require MFA or external ID for sensitive assume-role operations where appropriate.
  • Enforce permissions boundaries when delegating administration.
VERIFIED COMPETENCY MILESTONE
