Module 6 › Chapter 6.1 › Security tooling account
What to centralize
  • CloudTrail logs from all accounts.
  • GuardDuty and Security Hub findings aggregated.
  • S3 archives with retention and immutability where required.
Operational notes
Ensure secure cross-account logging permissions. Protect the security account's root and admin roles with strict MFA and limited operator access. Use automation to register new accounts to send logs centrally.
Key Takeaway

A security account increases visibility and simplifies correlation of security events across your entire organization.
