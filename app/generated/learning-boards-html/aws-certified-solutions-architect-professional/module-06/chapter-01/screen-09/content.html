Module 6 › Chapter 6.1 › SCP example
SCP JSON
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Deny",
      "Action": [
        "organizations:LeaveOrganization",
        "cloudtrail:StopLogging",
        "cloudtrail:DeleteTrail"
      ],
      "Resource": "*"
    }
  ]
}
Attach this SCP to an OU to ensure member accounts cannot disable logging or remove themselves from the organization.
Example test
Attach to sandbox OU, then in a member account try to stop CloudTrail and observe an explicit Access Denied message.
Pro tip
Protect the management account with strict controls and MFA, since it manages policy attachments and billing.
