Module 6 › Chapter 6.1 › SCP fundamentals
SCP definition

An SCP is a JSON policy attached to an OU or account that denies or allows actions in member accounts but does not grant permissions by itself.

Key property
SCPs limit the maximum available permissions; IAM still controls effective permissions within that bound.
When to use
Use SCPs for organization-wide guardrails like preventing account removal or disabling logging.
Concrete example
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Deny",
      "Action": [
        "organizations:LeaveOrganization",
        "cloudtrail:StopLogging",
        "cloudtrail:DeleteTrail"
      ],
      "Resource": "*"
    }
  ]
}
This SCP prevents member accounts from leaving the organization or stopping CloudTrail, enforcing continuity of logs.
Misconception

An SCP is not a substitute for fine-grained IAM policies; use both together for defense in depth.
