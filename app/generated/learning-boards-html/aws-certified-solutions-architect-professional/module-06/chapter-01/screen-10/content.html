Module 6 › Chapter 6.1 › Hands-on SCP
Policy JSON (template)
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Deny",
      "Action": "ec2:RunInstances",
      "Resource": "*",
      "Condition": {
        "StringNotEquals": {
          "aws:RequestedRegion": [
            "us-east-1",
            "eu-west-1"
          ]
        }
      }
    },
    {
      "Effect": "Deny",
      "Action": "s3:DeleteBucket",
      "Resource": "arn:aws:s3:::*prod-data*",
      "Condition": {
        "StringLike": { "s3:prefix": ["*"] }
      }
    }
  ]
}
Attach to your Production OU. Then try launching EC2 in Sydney or deleting a bucket named my-prod-data-backup to confirm denials.
Test steps
  1. Create SCP in Management Account.
  2. Attach to sandbox Production OU.
  3. Attempt denied actions in member account.
Caution
Wildcard ARNs can block more than intended. Test broadly named patterns in a sandbox first.
