Module 7 › Chapter 6.8 › Reference Architectures
Secure Web App
CloudFront + WAF, ALB, private app servers, RDS in private subnets, KMS, and centralized logging.
Secure Data Lake
Encrypted S3 with Lake Formation, Glue ETL roles, Athena/Redshift Spectrum, and Macie for sensitive data discovery.
Serverless
API Gateway + WAF, Cognito, Lambda with least-privilege roles, DynamoDB with SSE-KMS, and audit logging.
Key Takeaway
Standardized blueprints make it easier to enforce least privilege, consistent encryption, and centralized monitoring across teams.
