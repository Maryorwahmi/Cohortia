Module 7 › Chapter 6.8 › Practice & Verification
Exercises
Security group design checklist
  • Identify ports and exact source security group IDs required for each tier.
  • Use SG references rather than IP ranges when possible for tighter controls.
  • Restrict outbound rules to only necessary downstream groups or services.
Verification steps
  1. Attempt direct access to app and DB ports from internet — expect fail.
  2. From web servers, try app port — expect success.
  3. Review CloudTrail logs and VPC Flow Logs for unexpected traffic.
Marketplace evaluation
Confirm the product can be deployed in an inspection VPC, uses IAM roles for access, and forwards logs to your central collector without creating blind spots.
Quick mnemonic
Design → Apply → Verify → Monitor
Small tests and logs turn designs into enforced reality.
