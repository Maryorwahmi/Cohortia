Module 7 › Chapter 6.8 › Defense-in-Depth
Layer map
Network Layer
VPC, subnets, security groups, NACLs, WAF, Shield, Transit Gateway and inspection VPCs for central filtering.
Compute Layer
Hardened AMIs, IMDSv2, host firewalls, vulnerability scanning and endpoint protection.
Data Layer
KMS/CloudHSM encryption, TLS for transit, S3 policies, Object Lock, and data discovery tools.
Identity Layer
IAM roles, MFA, federation, ABAC and least privilege to control who can act on resources.
Logging & Monitoring
CloudTrail, Config, GuardDuty, Security Hub, and centralized logging create detection, alerting and audit paths.
Practical tip
Map each asset to one or more layers and ensure logs for that layer are ingested into your central collector for correlation.
Common mistake
Relying on a single perimeter control and neglecting endpoint and data protections undermines defense-in-depth.
