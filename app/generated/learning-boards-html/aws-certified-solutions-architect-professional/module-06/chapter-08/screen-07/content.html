Module 7 › Chapter 6.8 › Zero‑Trust
What zero‑trust requires
  • Strong identity: roles, ABAC, short‑lived credentials, and MFA.
  • Micro‑segmentation: security groups and VPC boundaries that make flows explicit.
  • Continuous validation: telemetry and automated detection to verify behavior.
Concrete scenario
A Lambda function must assume a role limited to DynamoDB actions and call the table only via a VPC endpoint and an SG that permits that traffic. Logs and GuardDuty alerts validate the action.
Misconception
Zero‑trust is not only a network policy. Without identity controls and telemetry, segmentation alone is insufficient.
Practice prompt
Identify one high‑risk role and plan two steps to add continuous verification: stricter IAM conditions and additional logging for that role's operations.
