Module 7 › Chapter 6.8 › Compute Protections
Key controls
  • Hardened AMIs and automated image pipelines.
  • IMDSv2 enforced so metadata requires session tokens.
  • Host firewalls, EDR/antivirus, and vulnerability scanning (Inspector).
Operational prompts
Add IMDSv2 enforcement to instance launch templates, document which roles need instance profile access, and limit outbound egress for critical instances.
Common mistake
Assuming a patched AMI removes the need for runtime detection. Combine both patching and monitoring for best results.
