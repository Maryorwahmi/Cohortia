Module 7 › Chapter 6.8 › Micro-segmentation Process
Step-by-step
1. Inventory ports and flows
List exactly which ports each tier needs to accept and initiate.
2. Define security groups and rules
Create WebTierSG, AppTierSG, DBTierSG with inbound/outbound rules referencing each other.
3. Attach and verify
Attach SGs to instances and run connectivity checks and log reviews.
4. Harden and monitor
Remove unnecessary outbound rules and feed VPC Flow Logs into monitoring to detect anomalies.
Example rule set (conceptual)
WebTierSG inbound: HTTP/HTTPS from 0.0.0.0/0. WebTierSG outbound: Custom TCP port 8080 to AppTierSG. AppTierSG inbound: Custom TCP 8080 from WebTierSG. AppTierSG outbound: TCP 3306 to DBTierSG. DBTierSG inbound: TCP 3306 from AppTierSG.
Check your understanding
Why reference another security group as the source instead of using an IP range? Answer: SG references remain accurate as instances scale and they bind access to an identity boundary rather than mutable IPs.
Key Takeaway

Use SG references and restrict outbound traffic to prevent a compromised instance from reaching unexpected targets.
