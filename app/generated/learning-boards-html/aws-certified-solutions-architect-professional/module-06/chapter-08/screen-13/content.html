Module 7 › Chapter 6.8 › Hands-on Activity
Task steps (conceptual)
  1. Identify web, app, and db placeholders and their ports.
  2. Create WebTierSG, AppTierSG, DBTierSG with scoped rules referencing SG IDs.
  3. Attach SGs to instances and run connectivity tests to confirm enforcement.
  4. Review CloudTrail and VPC Flow Logs for recorded traffic paths.
Verification prompts
  • Internet → App Port: should be blocked.
  • Web → App Port: should succeed.
  • App → DB Port: should succeed.

# Conceptual security group relationships
WebTierSG: Inbound HTTP/HTTPS from 0.0.0.0/0
WebTierSG: Outbound TCP 8080 to AppTierSG
AppTierSG: Inbound TCP 8080 from WebTierSG
AppTierSG: Outbound TCP 3306 to DBTierSG
DBTierSG: Inbound TCP 3306 from AppTierSG
Key Takeaway

Use security group references, restrict outbound, and validate with logs so segmentation is enforced and observable.
