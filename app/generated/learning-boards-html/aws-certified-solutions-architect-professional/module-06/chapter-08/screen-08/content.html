Module 7 › Chapter 6.8 › Data Layer Controls
Core practices
  • Encrypt at rest with KMS/CloudHSM and enforce least privilege on key usage.
  • Use TLS for all in‑flight traffic and validate certificates.
  • Use discovery tools to find sensitive objects and apply Object Lock where required.
Example checklist
Map buckets and databases, assign KMS keys per sensitivity level, restrict decrypt to specific roles, enable Macie scanning, and review S3 policies for public access.
Key Takeaway
Encryption is most effective when combined with least privilege and discovery controls to limit who can use keys and access objects.
