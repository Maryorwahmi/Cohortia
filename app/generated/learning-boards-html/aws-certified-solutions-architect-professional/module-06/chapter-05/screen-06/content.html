Step-by-step test flow
Follow these validated steps to observe compliance change and enable remediation.
1. Enable AWS Config
Record all resources and set an S3 delivery bucket for snapshots.
2. Add rule
Select s3-bucket-public-read-prohibited and keep default triggers.
3. Test resource
Create a bucket with public access enabled and upload a public object.
4. Observe evaluation
Wait for Config to evaluate and show Noncompliant on the rule details page.
5. Remediate
Attach a Systems Manager automation document or manual step to remove public access.
6. Validate
Confirm rule returns to Compliant and recorded configuration shows the corrected policy.
Example scenario
You create a public bucket for testing. Config flags it Noncompliant. An automation document removes public ACLs and notifies the security channel.
Best practice

Use a test account for deliberate noncompliance so remediation runs safely and you can verify playbooks.
