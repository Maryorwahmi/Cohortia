Module 6 › Chapter 6.5 › Amazon Detective — investigation
What Detective gives you
Unified investigative views built from CloudTrail, VPC Flow Logs, and GuardDuty to trace behavior over time.
Use case
If an IAM credential is suspicious, Detective shows all API calls by that principal, associated IPs, and timeline for rapid scope assessment.
Method
Statistical analysis and graph models connect events and resources so you can follow relationships and interactions efficiently.
Investigation tip
Preserve evidence before containment actions that change log state. Use Detective to build your timeline first when safe to do so.
Misconception
Detective is not a prevention tool; it accelerates understanding and root cause analysis after detection.
Key Takeaway

Detective turns logs into an investigator-friendly timeline and relationship graph to find root causes faster.
