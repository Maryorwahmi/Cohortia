Practical validation steps
Each objective maps to a concrete check you can perform and observe.
CloudTrail verification
Create a multi-region trail with log-file validation, deliver logs to a centralized bucket, confirm delivery and validation markers to prove immutability.
Checks: bucket object list, CloudTrail delivery events, validation flag
AWS Config rule test
Enable Config, add the s3-bucket-public-read-prohibited rule, then create a public bucket and watch the rule change to Noncompliant.
Checks: rule compliance state, recorded resource snapshot
GuardDuty review
Inspect a sample finding, identify affected resources and recommended actions, and map a finding to an EventBridge rule for automation.
Checks: finding details, resource list, detected behavior
Security Hub aggregation
Confirm findings from GuardDuty and Config appear in Security Hub and review the compliance checks such as the AWS Foundational Security Best Practices.
Checks: findings list, compliance score
