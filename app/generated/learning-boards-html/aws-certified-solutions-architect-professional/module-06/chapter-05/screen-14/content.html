Module 6 › Chapter 6.5 › Key Concepts — Part 1
AWS CloudTrail
Records API calls and events for auditing, including caller identity and resources affected.
AWS Config
Continuously records resource configurations and evaluates them against rules for compliance.
Amazon GuardDuty
Detects malicious or anomalous behavior using ML, anomaly detection, and threat intelligence.
Takeaway

These three services form the evidence, evaluation, and detection layers of a proactive security posture.
