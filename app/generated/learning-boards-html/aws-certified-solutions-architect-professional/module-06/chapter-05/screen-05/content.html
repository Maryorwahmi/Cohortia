Module 6 › Chapter 6.5 › AWS Config — continuous recording
What AWS Config provides
Resource inventory, configuration snapshots, and continuous evaluation against rules.
• Continuous recording of resources and attribute changes for audit and troubleshooting.
• Config Rules to evaluate configuration compliance automatically.
• Integration points for alerts, remediation, and Security Hub findings.
Example rule
s3-bucket-public-read-prohibited evaluates whether buckets allow public read access and marks Noncompliant if they do.
Key Takeaway

Config is the continuous compliance lens. Use rules plus automation to maintain policy state rather than only detect drift.

Operational notes
  • Record all resource types relevant to security and choose triggers that balance timeliness and cost.
  • Grant Config an IAM role with cross-account read for centralized aggregation when using a central aggregator account.
  • Pair Config Rules with Systems Manager automation for immediate remediation of simple policy violations.
Analogy
Think of Config as a security camera that records every configuration snapshot and raises a flag when a baseline is violated.
Pitfall
Relying on manual checks instead of enabling automated rules and remediation increases mean time to repair.
