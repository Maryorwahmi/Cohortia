Module 6 › Chapter 6.5 › Operationalizing alerts
From finding to action
Use EventBridge rules to channel findings to automation targets like Lambda, SNS, or Systems Manager.
• Route GuardDuty high-severity findings to an EventBridge rule for containment.
• Lambda can isolate an instance by modifying security groups or trigger snapshot creation first.
• Use SNS or ticketing integrations for human-in-the-loop approvals when needed.
Pre-containment checklist
  • Snapshot EBS volumes or export CloudTrail objects to preserve evidence.
  • Log the automation steps and maintain an audit trail of actions taken.
  • Ensure least-privilege IAM roles for automation and test in a sandbox.
Example mapping
GuardDuty finding → EventBridge rule → Lambda to isolate instance → SNS to alert ops → Security Hub updates ticket.
Key Takeaway

Automated responses speed containment, but always preserve evidence first and require least-privilege automation roles.
