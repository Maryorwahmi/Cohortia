In this session you will practice configuration, detection, aggregation, and operational design.
01
Centralize CloudTrail & Config
Enable multi-region CloudTrail and AWS Config across accounts and deliver logs to a secure S3 bucket to retain an untampered audit trail. VERIFIED COMPETENCY MILESTONE
Mnemonic: single source of truth
02
Enable GuardDuty
Turn on GuardDuty in all accounts to detect anomalies, suspicious API calls, or crypto-mining behavior, and forward findings for response. VERIFIED COMPETENCY MILESTONE
Mnemonic: continuous anomaly watch
03
Aggregate with Security Hub
Use Security Hub to consolidate findings, run compliance checks, and route prioritized alerts to ticketing or event buses. VERIFIED COMPETENCY MILESTONE
Mnemonic: single pane of glass
04
Design monitoring & response
Combine CloudWatch alarms, EventBridge, and automated playbooks to act on high-priority findings and maintain compliance. VERIFIED COMPETENCY MILESTONE
Mnemonic: detect, prioritize, act
