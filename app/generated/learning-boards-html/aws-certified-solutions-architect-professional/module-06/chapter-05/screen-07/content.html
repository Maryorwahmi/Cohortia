Module 6 › Chapter 6.5 › GuardDuty — threat detection
How GuardDuty detects threats
It ingests CloudTrail, VPC Flow Logs, and DNS logs to surface anomalous patterns and threat intel matches.
• Machine learning models detect deviations in API usage or instance behavior.
• Integrated threat feeds flag known malicious IPs and domains.
• Findings include resource context so you can scope impact quickly.
Example finding
Backdoor:EC2/C&CActivity points to suspicious outbound connections that may indicate a compromised instance communicating with a command-and-control server.
Automated response
Route findings to EventBridge and trigger a Lambda to isolate the instance by updating its security group.
Investigation note
Preserve CloudTrail logs and instance snapshots before taking destructive containment actions.
Enablement checklist
  • Enable GuardDuty in every account and enable multi-account delegation if needed.
  • Review sample findings and tune suppression or trusted IP lists carefully.
  • Integrate with Security Hub and EventBridge for workflow automation.
Key Takeaway

GuardDuty provides prioritized, contextual findings. Use them to trigger containment while preserving evidence for investigation.
