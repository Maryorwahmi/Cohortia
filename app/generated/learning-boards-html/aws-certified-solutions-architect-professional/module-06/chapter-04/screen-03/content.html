Module 6 › Chapter 6.4 › Learning Objectives
Objective validation checklist
  • WAF: Create Web ACL, add managed SQLi/XSS groups, test with harmless payloads in staging.
  • Shield: Document which resources need Advanced and what incident support is available.
  • Firewall Manager: Create a policy targeting production OUs and confirm automatic associations.
  • Architecture: Produce a diagram that lists edge, network, and inspection controls.
Monitoring & logging to prove success
Enable WAF logging to CloudWatch or S3, review blocked request samples, and use Firewall Manager compliance reports to confirm coverage across accounts.
Common verification pitfalls
Don’t rely on a single test. Validate rules against a suite of typical application requests and synthetic malicious strings to catch false positives and unintended blocks.
Micro-mnemonic
Create, Test, Log, Enforce — repeat until you have consistent evidence and acceptable false-positive rates.
