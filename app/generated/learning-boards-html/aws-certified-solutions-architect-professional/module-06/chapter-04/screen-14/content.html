Module 6 › Chapter 6.4 › Key Concepts
AWS WAF
Application-layer firewall that uses Web ACLs and managed rule groups to block SQLi and XSS.
Shield Standard
Automatic DDoS protection for common Layer 3 and 4 attacks at no extra cost.
Shield Advanced
Enhanced DDoS protection, cost protection, and access to the DDoS Response Team.
Summary takeaway
Combine WAF at the application layer with Shield for volumetric defense and use Firewall Manager to enforce policies across accounts.
