Module 6 › Chapter 6.4 › Monitoring & Testing
Logging to enable analysis
  • Enable WAF sampled requests and CloudWatch metrics for block counts.
  • Use CloudTrail to capture changes to policies and ACL associations.
  • Store logs in a central S3 bucket for cross-account analysis if needed.
Testing strategy
  1. Deploy rules in monitor/count mode in staging.
  2. Review sampled requests and adjust priorities or exclusions.
  3. Gradually move to blocking mode and expand scope via Firewall Manager when stable.
Check your understanding
A bot that uses legitimate-looking parameters can trigger managed rules. Without sampling you might block that bot unexpectedly. Always analyze samples before enforcing blocks.
