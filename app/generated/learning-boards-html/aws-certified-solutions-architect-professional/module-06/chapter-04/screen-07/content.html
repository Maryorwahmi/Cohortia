Module 6 › Chapter 6.4 › Multi-layered design
Recommended layers
  1. Edge protection: CloudFront + WAF to block application-layer threats and cache content.
  2. DDoS mitigation: Shield Standard by default, Shield Advanced for critical workloads.
  3. Network segmentation: VPCs, subnets, security groups, and NACLs to isolate tiers.
  4. Inspection & IDS: Optional third-party firewalls in a centralized inspection VPC using Transit Gateway.
  5. Centralized enforcement: Firewall Manager to apply Web ACLs and policies across accounts.
This layered approach reduces single points of failure and makes incident diagnosis easier because each layer has distinct telemetry and controls.
Scenario card
An online store uses CloudFront with WAF and Shield Advanced for public traffic, ALB for application routing, and private subnets for database servers. Firewall Manager ensures all ALBs in production OUs have the same Web ACL.
Key Takeaway

Layered defenses reduce risk: edge filters block many attacks, Shield defends volumetric events, and internal segmentation contains breaches.
