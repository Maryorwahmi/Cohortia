Module 6 › Chapter 6.4 › AWS WAF — purpose
What WAF does
  • Inspects Layer 7 HTTP requests and evaluates rules against headers, body, URI, and IP.
  • Applies managed rule groups for common threats like SQLi and XSS.
  • Integrates with CloudFront, ALB, API Gateway, and AppSync for flexible placement.
  • Provides sampling and logging to CloudWatch or S3 for analysis.

      "SearchString": "union select",
      "PositionalConstraint": "CONTAINS"

  }
}
Teaching points
  • Use managed rule groups for broad coverage and custom rules for application-specific patterns.
  • Always test in non-production to avoid blocking legitimate traffic.
  • WAF complements secure coding; do not rely on it as the only defense.
Analogy
Think of WAF as a parser at your web perimeter that reads each request and stops suspicious payloads before they reach your application.
Key Takeaway

WAF inspects application requests and blocks known exploit patterns while requiring careful testing to avoid false positives.
