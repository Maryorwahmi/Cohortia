Network Security Deep Dive

WAF, Shield, and Firewall Manager provide complementary protections: Layer 7 filtering, DDoS mitigation, and centralized policy enforcement. This lesson shows how to combine them for resilient public-facing systems.

In this lesson
Configure Web ACLs and managed rules. Understand Shield tiers. Use Firewall Manager to enforce policies across accounts.
Why it matters
Protect public applications from exploitation and DDoS while keeping your large organization consistent and auditable.
Explore Key Topics
AWS WAF
Layer 7 filtering and managed rule groups for SQLi and XSS protection.
AWS Shield
Standard is free for common L3/L4 attacks; Advanced adds visibility, mitigation, and cost protection.
Firewall Manager
Centralize WAF and Shield policies across accounts to reduce misconfiguration risk.
Layered protection sketch
CloudFront + WAF + Shield Advanced at the edge, ALB validation, VPC segmentation inside.
Edge: CloudFront
WAF: Layer 7
Shield: DDoS
Manager: Org-wide
Quick start note
Create a Web ACL in a non-production region, test managed rule groups for false positives, then roll the ACL to production and use Firewall Manager to enforce it across accounts.
