Module 6 › Chapter 6.4 › Firewall Manager process
Steps to create a Firewall Manager policy
1. Enable AWS Organizations integration and confirm delegated administrator.
2. Create a new policy: select policy type (WAF, Shield Advanced, security groups).
3. Define scope: target OUs, accounts, and resource types (e.g., ALB).
4. Configure the Web ACL or Shield settings to enforce, then deploy the policy.
5. Monitor Firewall Manager compliance reports and remediate noncompliant resources.
Practical notes
  • Scope policies narrowly to avoid applying rules where they cause unexpected behavior.
  • Use staging OUs to validate a policy before broad rollout.
  • Firewall Manager supports automatic remediation for matching resources.
Key Takeaway

Centralized policy enforcement scales security, but requires careful scoping and staged rollout to avoid operational disruption.
