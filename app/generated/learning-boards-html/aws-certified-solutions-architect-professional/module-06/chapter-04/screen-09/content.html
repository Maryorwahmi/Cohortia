Module 6 › Chapter 6.4 › Hands-on: Web ACL
Conceptual steps
  1. Select the region and an existing ALB.
  2. Create Web ACL: Name it MyWebAppProtectionACL and set resource type to ALB.
  3. Add rules: choose AWS managed rule groups for CRS, SQL database, and XSS, set default action to Block.
  4. Keep default priorities, enable CloudWatch metrics and sampled requests.
  5. Review and create, then test in staging before production rollout.
Verification scenario
After associating the ACL, craft a test parameter with a harmless SQL-like string or an XSS test vector in staging. Confirm that WAF blocks the request and that CloudWatch shows a blocked request metric. Do not test on production users.
Key Takeaway

Follow create, test, and monitor steps to ensure protections work as intended and to prevent customer impact from false positives.
