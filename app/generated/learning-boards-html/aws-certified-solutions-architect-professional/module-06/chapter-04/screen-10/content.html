Module 6 › Chapter 6.4 › Managed Rule Groups
Why use managed rules
  • Quickly cover common exploit patterns without authoring each match.
  • Receive updates from AWS or sellers as new patterns emerge.
  • Combine with custom rules for application-specific protections.
Operational guidance
  • Enable sampling and CloudWatch metrics to review matches before blocking decisively.
  • Use staged rollouts and exceptions to reduce false positives.
  • Maintain a list of exclusions for legitimate traffic that triggers managed rules.
Pro tip

Start with monitoring mode for new rule groups, then move to blocking when you have confidence in the signal and exclusions.
