Definition
S3 Cross-Region Replication
Asynchronously copy objects from a source bucket to a destination bucket in another region for durability and availability.
Example Replication Rule
{
  "Role": "arn:aws:iam::ACCOUNT_ID:role/s3-replication-role",
  "Rules": [
    {
      "ID": "MyReplicationRule",
      "Status": "Enabled",
      "Priority": 1,
      "Filter": { "Prefix": "" },
      "Destination": { "Bucket": "arn:aws:s3:::my-dr-bucket-us-east-1" },
      "DeleteMarkerReplication": { "Status": "Enabled" }
    }
  ]
}
Operational Notes
  • Ensure replication role has the minimum necessary permissions.
  • Enable encryption in transit and at rest for compliance.
  • Monitor replication metrics and failures via S3 metrics.
Misconception
Do not assume objects are available instantly in the destination; plan for propagation delay and CDN fallbacks.
Reflection: are there regulatory constraints that prevent replicating specific objects across borders?
