Comparison
Synchronous
Writes wait for confirmation from both primary and secondary.
  • RPO: 0 (no data loss)
  • Write latency: higher, increases with distance
  • Use case: tight consistency within close proximity
Pitfall
Blocking writes if the secondary is unreachable—plan availability strategies.
Comparison
Asynchronous
Primary acknowledges write immediately; replication happens later.
  • RPO: greater than zero, depends on replication lag
  • Write latency: low on primary, suitable for cross-region
  • Use case: global content, backups, and large distance DR
Monitoring
Track ReplicaLag metrics and set alarms to understand your effective RPO.
Concrete Scenario
If you operate a global social feed, asynchronous replication keeps writes fast for users worldwide. Expect short windows of divergence and design operations and UX to tolerate that. If instead you operate a settlement system, synchronous replication within a single region or AZ may be required.
