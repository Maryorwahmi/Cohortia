Process Flow
Create the Replica
Run the create-db-instance-read-replica command in the destination region using the source DB ARN.
CLI Example
aws rds create-db-instance-read-replica \
  --db-instance-identifier my-dr-mysql-replica \
  --source-db-instance-identifier arn:aws:rds:us-west-2:ACCOUNT_ID:db:my-primary-mysql-db \
  --destination-region us-east-1 \
  --db-instance-class db.r5.large \
  --no-multi-az \
  --region us-east-1
Verification
Use describe-db-instances to confirm the replica's status and check CloudWatch ReplicaLag under AWS/RDS namespace.
Monitor ReplicaLag
Set a CloudWatch alarm scoped to the replica's DBInstanceIdentifier and choose a period and threshold appropriate for your RPO.
CloudWatch Alarm CLI
aws cloudwatch put-metric-alarm \
  --alarm-name "RDS-DR-ReplicaLag-High" \
  --alarm-description "Alarm when RDS Read Replica lag exceeds 60 seconds" \
  --metric-name "ReplicaLag" \
  --namespace "AWS/RDS" \
  --statistic "Maximum" \
  --period 60 \
  --threshold 60 \
  --comparison-operator "GreaterThanThreshold" \
  --dimensions "Name=DBInstanceIdentifier,Value=my-dr-mysql-replica" \
  --evaluation-periods 1 \
  --alarm-actions "arn:aws:sns:us-east-1:ACCOUNT_ID:MySNSTopic" \
  --region us-east-1
Operational Tip
Create the alarm in the DR region and test it to ensure notification routing works during incidents.
