Module 5 › Chapter 5.4 › Verification & Runbook
Verification steps
  • Confirm identical infrastructure deployed to both regions via IaC.
  • Exercise traffic failover using health checks and observe user experience and latency.
  • Verify replication correctness for each data store and measure replication lag.
Runbook Item
Sequence to fail region and validate traffic continuity.
Metric
RTO and replication lag thresholds.
Post-mortem
Record actions and gaps for continuous improvement.
Mnemonic
DR = Deploy + Replicate + Route + Verify
Use this checklist in your runbook to ensure each active region remains a true production endpoint.
