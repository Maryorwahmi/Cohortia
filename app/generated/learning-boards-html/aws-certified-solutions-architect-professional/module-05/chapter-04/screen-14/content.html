Module 5 › Chapter 5.4 › Key Concepts
Multi-Site Active/Active
Run production in multiple regions simultaneously to achieve near-zero RTO/RPO.
Route 53
DNS routing policies control how users reach healthy regions with latency, weighted, and geolocation options.
Global Accelerator
Provides static Anycast IPs and faster edge-based failover across regions through the AWS global network.
Summary Takeaway

Active/Active delivers the fastest recoveries but requires carefully chosen replication models, automated deployments, consistent IAM, and frequent DR drills to be dependable.
