Module 5 › Chapter 5.4 › Design Activity
Requirements
  • Global availability with minimal RTO/RPO.
  • Front-end: S3 + CloudFront; API: EC2 behind ALB; Data: DynamoDB.
  • Regions: us-east-1 and eu-west-1 active simultaneously.
Deployment: Use IaC to create identical stacks and CI/CD to deploy to both regions with automated health checks and DR drill scripts.
Implementation notes
Front-end: S3 buckets in both regions, CloudFront origin groups. API: ALBs in both regions attached to Global Accelerator endpoints. Data: DynamoDB Global Tables for active-active writes. Auth: evaluate Cognito replication or federation strategy.
Design choice exercise: decide whether user profile writes require strong consistency. If not, use local writes with DynamoDB Global Tables. If yes, centralize writes and accept cross-region latency or implement additional coordination logic.
Example Task

Document a runbook describing failover steps, expected RTO/RPO, and how to validate data integrity after a region failover.
