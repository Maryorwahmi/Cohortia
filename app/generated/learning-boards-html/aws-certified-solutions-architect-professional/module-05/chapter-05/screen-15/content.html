Key Concepts — Part 1

AWS Resilience Hub
Centralized discovery, assessment, and recommendations against RTO/RPO.
DR Drills
Planned simulations to validate recovery procedures, measure RTO/RPO, and train teams.
AWS FIS
Inject faults programmatically to test system behavior under failure with safety controls.
Summary takeaway
Assess, test, and verify—then repeat. Use Resilience Hub to find gaps, run drills to prove recovery, and use FIS to test specific failure modes safely.
