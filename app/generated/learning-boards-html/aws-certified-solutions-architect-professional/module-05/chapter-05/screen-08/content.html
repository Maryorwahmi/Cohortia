Create an app from a CloudFormation stack

Example CLI to register an application so Resilience Hub can discover resources.

# Example: Register an application defined by a CloudFormation stack
aws resiliencehub create-app \
    --name "MyWebApp" \
    --description "E-commerce web application" \
    --resource-mappings '[{"ResourceType":"CfnStack","LogicalResourceId":{"Identifier":"MyWebAppStack"}}]'
Checklist after create-app
  • Confirm the discovered resource list contains your EC2, RDS, and S3 resources.
  • Select or create a resilience policy with your RTO/RPO targets.
  • Run an assessment and download the report for drill planning.
Practical note
Substitute your stack identifier. If discovery misses resources, add them manually before trusting the assessment.
Misconception
Creating the app does not set RTO/RPO; you must select or author a resilience policy separately.
