FIS Experiment Template

Template to terminate two random EC2 instances tagged as production in us-west-2; used to validate ASG and ALB behaviors.

{
  "description": "Terminate random EC2 instances in primary region",
  "targets": {
    "Instances": {
      "resourceType": "aws:ec2:instance",
      "selectionMode": "COUNT(2)",
      "parameters": {
        "filters": [
          {"path": "State.Name", "values": ["running"]},
          {"path": "Tags.Environment", "values": ["production"]},
          {"path": "Tags.Region", "values": ["us-west-2"]}
        ]
      }
    }
  },
  "actions": {
    "TerminateInstances": {
      "actionId": "aws:ec2:terminate-instances",
      "parameters": {
        "instanceIds": "${Instances}"
      }
    }
  },
  "stopConditions": [
    {"source": "none"}
  ],
  "roleArn": "arn:aws:iam::ACCOUNT_ID:role/FISActionsRole"
}
What to verify
ASG launches replacement instances, ALB healthy host count returns to acceptable levels, and application remains functional.
Safety checklist
Run in staging first; set stop conditions tied to application health; limit IAM role permissions to necessary actions only.
