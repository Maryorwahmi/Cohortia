Core Tool

AWS Fault Injection Simulator

Run controlled chaos experiments to validate Auto Scaling, load balancing, and failover automation.

  • Actions: terminate instances, reboot RDS, inject network latency, overload CPU/memory.
  • Targets: specify resource types, selection modes, and filters for safe targeting.
  • Safety: IAM role scoping, stop conditions, and start in non-production.
Example experiment goal
Terminate two random EC2 instances in production ASG to validate replacement and ALB routing, starting in staging first and with stop conditions in place.
Safety reminder
Define stop conditions and begin with low-impact tests. Ensure FIS role has only the permissions it needs.
