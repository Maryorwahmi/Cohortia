Executing a DR Drill

Run controlled simulations, follow the runbook, and capture detailed logs to measure recovery performance.

  • Pre-checks: AMIs, templates, read replica synchronization, runbook availability.
  • Simulate failure: stop instances, fail Route 53 health checks, or run FIS in staging.
  • Execute recovery: promote DB, launch EC2 in DR region, update DNS, verify app.
  • Document timestamps to compute RTO and check data for RPO.
Verification checklist
Endpoint accessibility, report generation, data integrity checks, RTO time measurement, and confirm no undocumented manual steps were needed.
Common mistake
Skipping detailed time logs prevents root cause analysis and makes it hard to validate you met RTO/RPO.
