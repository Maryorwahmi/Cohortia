Process Flow

Discovery & Resource Mapping

Import CloudFormation, Resource Groups, or AppRegistry to build an application model for assessment.

  1. Register app: point Resilience Hub at the CloudFormation stack or AppRegistry entry.
  2. Scan resources: Resilience Hub enumerates EC2, RDS, S3, and other components.
  3. Validate model: confirm all critical resources are included before assessment.
Example
Importing a CloudFormation stack for an app should reveal the RDS instance that requires cross-region backups and the ASG that needs multi-AZ subnets.
Discovery Checklist
  • Confirm CloudFormation stacks are current and include all resources.
  • Check tags and identifiers to ensure correct grouping into one application model.
  • After import, review the detected resource list before running the assessment.
Why validate?
Missing resources produce falsely optimistic resilience scores. Manual confirmation keeps assessments honest.
Pro tip
Use consistent tagging and keep CloudFormation templates current so discovery reflects reality.
