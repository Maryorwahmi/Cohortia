Milestone checklist
  • Pilot Light: RDS read replica present, AMIs copied, CloudFormation templates stored, activation runbook tested.
  • Warm Standby: Minimal ASG running, secondary DB promoted path validated, scale-up tested under load.
  • Route 53: Health checks configured, failover record set created, TTLs and EvaluateTargetHealth set appropriately.
  • CI/CD: Pipeline copies AMIs and updates templates in DR region to avoid drift.
Verification mnemonic
Sync, Test, Promote — keep configuration synchronized, run full tests, and promote read replicas during drills. This three-step mnemonic helps ensure readiness.
