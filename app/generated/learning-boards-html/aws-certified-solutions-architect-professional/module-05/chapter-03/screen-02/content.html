These objectives emphasize practical application: design, implement, compare, and configure. Each maps to hands-on tasks you will practice.

01
Pilot Light
Design and implement a Pilot Light architecture using AMIs, CloudFormation, and cross-region replication so critical data is continuously protected and compute can be launched on demand.
VERIFIED COMPETENCY MILESTONE
02
Warm Standby
Provision a scaled-down, running environment in the DR region and perform a scale-up activation that minimizes downtime and state loss.
VERIFIED COMPETENCY MILESTONE
03
Compare RTO/RPO
Estimate RTO and RPO impacts and calculate ongoing cost differences so you can recommend Pilot Light or Warm Standby for a given SLA.
VERIFIED COMPETENCY MILESTONE
04
Route 53 Failover
Configure Route 53 failover records and health checks so DNS automatically redirects traffic to the DR region when primary health checks fail.
VERIFIED COMPETENCY MILESTONE
