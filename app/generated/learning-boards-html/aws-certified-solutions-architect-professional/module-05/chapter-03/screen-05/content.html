Module 5 › Chapter 5.3 › Activation Workflow
Step-by-step
1
Promote or restore replicated data
Promote RDS read replica or restore cross-region snapshot so the DR region has a writable database.
2
Deploy infrastructure
Run CloudFormation/Terraform templates stored in the DR region to create ASGs, ALBs, security groups.
3
Launch compute from AMIs
Use pre-copied AMIs so instances boot already configured with app dependencies and configuration tools.
4
Update DNS and verify
Update Route 53 failover records to point at the DR ALB, then run health checks and smoke tests to confirm service integrity.
CLI examples
# Create CloudFormation stack in DR region
aws cloudformation create-stack \
  --stack-name MyPilotLightAppStack \
  --template-body file://app-stack.yaml \
  --parameters ParameterKey=DBEndpoint,ParameterValue=my-dr-rds-endpoint.us-east-1.rds.amazonaws.com \
  --region us-east-1
# Route 53 change-batch example (see change-batch.json pattern in chapter)
aws route53 change-resource-record-sets \
  --hosted-zone-id Z1234567890ABCDEF \
  --change-batch file://change-batch.json
Practical tip
Use short DNS TTLs for application records and set EvaluateTargetHealth to true so Route 53 respects ALB health checks during failover.
