Module 5 › Chapter 5.3 › Testing & Pitfalls
Drill checklist
  • Promote DR database and confirm write capability.
  • Deploy CloudFormation stack in DR and launch instances from DR AMIs.
  • Update Route 53 failover records and validate client routing behavior.
  • Run smoke tests and measure end-to-end RTO and RPO.
CI/CD integration
Have pipelines that automatically copy AMIs, upload templates to DR S3, and rotate DR environment variables as part of each release cycle.
Common mistakes
  • Not testing full failover end-to-end.
  • Out-of-sync CloudFormation templates or AMIs in DR.
  • Long DNS TTLs and not using EvaluateTargetHealth.
Pro tip
Create an automated timed drill that fails if RTO or RPO objectives are not met; use the results to prioritize automation work.
