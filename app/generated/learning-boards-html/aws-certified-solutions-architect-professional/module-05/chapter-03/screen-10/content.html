Module 5 › Chapter 5.3 › Data Replication
Relational options
RDS Read Replica: cross-region replica that can be promoted. Aurora Global Database: low-latency global replication designed for fast promotion and very low RPO.
NoSQL & objects
DynamoDB Global Tables offer multi-region active-active replication. S3 Cross-Region Replication keeps objects synchronized for recovery or rehydration.
Operational checks
  • Monitor replication lag and set thresholds for automated alerts.
  • Include replication verification in failover drills.
  • Ensure DR region secrets and parameter values are synchronized.
Concrete scenario
For RTO<5 minutes and RPO<1 minute: use Aurora Global Database for cross-region replication and a small running Warm Standby cluster that can be promoted and scaled.
Caveat
Replication alone is not enough — ensure configuration, network, and secrets are available in DR to allow services to start immediately after promotion.
