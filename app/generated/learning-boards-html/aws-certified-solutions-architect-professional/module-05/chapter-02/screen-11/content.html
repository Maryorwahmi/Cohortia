Module 05 › Chapter 5.2 › Cross-Account & Cross-Region Copies
Implementation checklist
  1. Create destination vault or bucket in DR account and region.
  2. Attach a resource policy that allows the source account's backup role to write copies.
  3. Configure a KMS key in the target account and add key policy grants for the backup role and restore principals.
  4. Confirm COPY actions reference the destination vault ARN and test a restore into the DR account.
Example risk
If the destination KMS key denies access, the copy will fail even if vault policies are correct.
Key takeaway
Cross‑account copies provide isolation but must be validated end‑to‑end including KMS and vault policies.
