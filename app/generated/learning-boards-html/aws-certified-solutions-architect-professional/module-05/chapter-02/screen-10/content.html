Module 05 › Chapter 5.2 › EBS vs AMI vs RDS
EBS Snapshots
Incremental block backups. Restore by creating a new volume. Best for file systems and volume-level recovery.
AMIs
Instance templates that include boot configuration. Use for quick redeploy of application servers and scale-out images.
RDS Snapshots
Daily snapshots + transaction logs for point‑in‑time recovery. Required for tight database RPOs.
Decision guidance
  • Map RPO/RTO to primitives: RDS PITR for low RPO, AMIs for redeploy speed, snapshots for volume recovery.
  • Automate and test each restore path; do not assume compatibility across primitives.
  • Remember cross‑region copies and encryption when durability and isolation are required.
