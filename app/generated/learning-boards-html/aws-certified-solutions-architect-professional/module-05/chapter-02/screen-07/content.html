Module 05 › Chapter 5.2 › AWS Backup: Centralized Plans
Core Concept

One plan to manage many resources

Define schedules, lifecycle, and copy actions centrally and attach resources with backup selections.

Example rule
Daily backups → keep 30 days locally → move to cold storage after 7 days → copy to DR vault in another account and region with 365 day retention.
Operational notes
  • Destination vaults require resource policies for cross‑account access.
  • Encryption keys must be available in the target account and region for copies to succeed.
  • Restore workflows still rely on service-specific restore steps (e.g., RDS PITR, EBS volume creation).
Key takeaway
Use AWS Backup for governance and consistent retention, but validate service-level behavior during restores.
