Module 05 › Chapter 5.2 › RDS Automated Backups and PITR
Core Concept

Automated backups + transaction logs = point‑in‑time recovery

RDS retains a daily snapshot and streams transaction logs so you can restore to a precise moment within retention.

Behavior
  • Daily full snapshot captured automatically.
  • Transaction logs stored throughout the day to enable PITR.
  • Retention configurable up to 35 days for automated backups.
Example scenario
If a schema change was applied at 10:21:32 UTC and you need the state at 10:20:00 UTC, restore using PITR to that second within the retention window.
Key takeaway
Automated backups with logs let you recover to a specific second — essential for low RPOs.
Common mistake
Not verifying KMS key and cross‑region permissions before relying on cross‑region restores.
Pro tip
Use manual snapshots for long‑term snapshots you must retain beyond the automated window.
