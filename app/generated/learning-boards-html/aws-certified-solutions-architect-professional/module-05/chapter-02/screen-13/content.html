Task: Create and apply a DLM policy

Follow these steps to automate daily snapshots and cross‑region copies.

1. Author policy JSON
Save a JSON file similar to the earlier example that defines TargetTags, CreateRule, RetainRule, and CrossRegionCopyRules.
2. Apply with CLI
aws dlm create-lifecycle-policy --region us-west-2 --cli-input-json file://dlm-policy.json
3. Verify and test
Confirm snapshots are created, confirm copies appear in us-east-1, and restore a copied snapshot to validate KMS and data integrity.
Key takeaway
Automate snapshot lifecycles, then validate by performing restores in the target region and account.
