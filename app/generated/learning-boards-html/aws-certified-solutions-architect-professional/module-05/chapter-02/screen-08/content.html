Module 05 › Chapter 5.2 › DLM for EBS
Process

Tag → Schedule → Retain → Copy

Use tags to target resources, define create and retain rules, and add cross‑region copy rules with encryption settings.

Example DLM JSON
{
  "Description": "Daily snapshots for Production EBS volumes with cross-region copy",
  "State": "ENABLED",
  "TargetTags": [
    {"Key": "Environment", "Value": "Production"},
    {"Key": "Backup", "Value": "True"}
  ],
  "PolicyDetails": {
    "PolicyType": "EBS_SNAPSHOT_MANAGEMENT",
    "ResourceTypes": ["VOLUME"],
    "Schedules": [
      {
        "Name": "DailySnapshotSchedule",
        "CreateRule": {"Interval": 24, "IntervalUnit": "HOURS", "Times": ["03:00"]},
        "RetainRule": {"Count": 30},
        "CrossRegionCopyRules": [
          {"TargetRegion": "us-east-1","RetainRule": {"Count": 90},"Encrypted": true}
        ]
      }
    ]
  }
}
Checklist & tips
  • Use consistent tags for selection; confirm they match actual volume tags.
  • Specify target region and KMS key ARN for encrypted copies.
  • Test restores from both local and copied snapshots regularly.
Common mistake
Assuming copies are encrypted by default in the target region without specifying encryption or a target CMK.
