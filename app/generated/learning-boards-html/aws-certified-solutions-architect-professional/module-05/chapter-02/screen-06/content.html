Versioning and Cross‑Region Replication

Versioning preserves object history; CRR copies objects to a geographically separate bucket for redundancy.

Requirements
Enable versioning on both source and destination; create IAM role for replication permissions; set destination encryption.
Example
Replicate customer data from us-west-2 to us-east-1 in a separate account, encrypt destination with a CMK owned by the DR account.
Lifecycle and archival
Transition older object versions to Glacier or Glacier Deep Archive to reduce storage cost while retaining compliance snapshots.
Checklist
  • Enable versioning on both buckets.
  • Create IAM role with replication permissions and attach bucket policy on destination.
  • Configure lifecycle rules to move older versions to Glacier after policy-defined days.
Common mistake
Replicating without versioning or forgetting to configure destination encryption and permissions.
