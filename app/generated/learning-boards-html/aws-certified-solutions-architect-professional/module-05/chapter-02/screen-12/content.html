Module 05 › Chapter 5.2 › Testing Restores

Restore drill checklist

EBS test
Create volume from snapshot, attach, mount, and verify data integrity.
RDS test
Restore snapshot or perform PITR to test DB instance and validate application connectivity.
S3 test
Retrieve older versions or objects from replicated buckets and validate object integrity.
Common findings
Missing IAM permissions, KMS key access issues, incomplete runbook steps, and expired recovery points.
Key takeaway
A backup that is not restored periodically is an untested assumption. Validate restores end-to-end.
