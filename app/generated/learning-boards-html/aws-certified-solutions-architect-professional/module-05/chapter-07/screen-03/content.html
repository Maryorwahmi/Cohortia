Skills You'll Practice

Concrete deliverables to produce during design and audit.

Classify Applications
  • Map app to mission/business/non-critical.
  • Set RTO and RPO targets per tier.
Cost Model
  • Estimate baseline using RIs or Savings Plans.
  • Apply storage lifecycle and Intelligent-Tiering for backups.
Compliance Checklist
  • Enforce KMS encryption for snapshots and S3.
  • Respect data residency in region selection.
Audit Proofs
  • Enable multi-region CloudTrail and centralize logs.
  • Use AWS Config rules to prove resource compliance over time.
