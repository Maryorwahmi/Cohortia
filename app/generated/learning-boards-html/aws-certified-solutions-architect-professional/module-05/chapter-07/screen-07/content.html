Module 6 › Chapter 5.7 › Spot Instances in DR
Definition

Use Spot for fault-tolerant work

Spot can lower DR provisioning costs but requires careful architectural choices.

When to use
  • Large-scale batch recoveries or parallel workers.
  • Temporary test infrastructure during drills.
Precautions

Never use Spot for primary, stateful services. Plan for interruptions and implement graceful shutdown and checkpointing.

Example Pattern
Use reserved or on-demand databases, add Spot workers to process queued jobs on recovery, checkpoint progress to durable storage so work can resume if interrupted.
Common Mistake

Treating Spot as identical to On-Demand for critical services; interruptions can cause data loss if not designed properly.
