Process

Automate cleanup after tests

Use tagging, event triggers, and runbooks so test resources do not become a recurring cost.

Recommended Flow
  1. Tag DR test resources with a lifecycle tag.
  2. Trigger a Lambda or runbook via CloudWatch Events after test completion or a timeout.
  3. Terminate or scale-down resources and log actions to CloudTrail.
Example

A scheduled job finds resources with tag "dr-test" older than 8 hours and terminates them after recording the operation in the central audit bucket.

Safety Patterns
  • Use precise tags to avoid accidental termination.
  • Include an approval gate for manual failovers.
  • Write audit logs for every automated action.
Key Takeaway

Automate cleanup but design safe guards and logging to prevent accidental data loss or billing surprises.
