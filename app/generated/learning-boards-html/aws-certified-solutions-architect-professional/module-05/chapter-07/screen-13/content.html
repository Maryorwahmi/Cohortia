Checklist

Test and verify auditability

A proper DR drill validates recovery steps and produces the evidence auditors need.

Pre-Test
  • Verify backup integrity and KMS key availability.
  • Tag test resources and set automations for cleanup.
During Test
  • Execute recovery steps and validate application health.
  • Confirm CloudTrail shows the expected API events.
Post-Test
Cleanup & Review
  • Run automated teardown and confirm no unexpected running resources.
  • Collect cost report for the drill and identify savings opportunities.
  • Update application tiering if recovery took longer than expected.
Reflection

Did the audit trail capture every recovery step? If not, update logging and repeat the drill.
