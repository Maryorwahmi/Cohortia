Cost and Usage Report (CUR)
Export detailed usage and cost rows to S3 for analysis and billing.
Architecture
  • CUR files delivered to S3 (hourly or daily granularity).
  • Query with Athena or import into analytics and billing systems.
  • Join CUR rows with tagging and cost categories for showback.
Practical pattern
Partition CUR by month in Athena and build queries that aggregate costs by Project tag to produce internal invoices.
Key Takeaway

Use CUR for precise, auditable cost datasets; it is required for accurate showback and chargeback.

Checks and Misconceptions
Don't rely only on Cost Explorer for auditing. CUR lets you reconcile line items and detect untagged spend.
Misalignment
If tags are missing, CUR rows will be unassigned—automated audits catch this.
Automation
Schedule recon jobs that compare CUR aggregates to Cost Explorer summaries.
