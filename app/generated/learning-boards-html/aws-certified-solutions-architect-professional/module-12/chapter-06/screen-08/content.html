Create a budget
Set scope, amount, filters and alerts to notify owners.
  1. Name the budget, choose period (monthly) and fixed amount.
  2. Filter by tag: Project -> MyWebApp so only matching resources count.
  3. Add alerts at thresholds such as 80% and 100%, delivery via email or SNS.
  4. Optional: attach an action to stop instances (requires a role).
Practical tips
  • Always scope budgets by tag or category to avoid noisy alerts.
  • Use forecast alerts to catch growth early, not just actuals.
  • Pair budget alerts with owner tags so the right person is notified.
Key Takeaway

Budgets are your first-line guardrail. Filter them carefully and pair with enforced tagging for reliable alerts.
