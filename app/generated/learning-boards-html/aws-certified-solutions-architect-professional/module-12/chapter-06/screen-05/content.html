Cost Categories
Create rules to group costs into business-relevant buckets.
How it works
  • Define rules over accounts, tags, services, and regions.
  • Evaluate costs into named categories for reporting and budgets.
  • Use categories in Cost Explorer and AWS Budgets for consistent views.
Concrete Scenario
Group accounts and any resource tagged Project:LegacyApp into a "Legacy" category so finance sees a single cost line for retirement planning.
Best Practice
Document category rules and reconcile outputs with CUR.
Misconception
Categories replace tags — they don’t. Use both for maximal flexibility.
Key Takeaway
Cost Categories provide a finance-oriented aggregation layer that complements tags and accounts.
