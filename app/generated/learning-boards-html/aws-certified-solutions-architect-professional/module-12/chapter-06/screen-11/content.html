Spot for cost-efficient compute
Ideal for fault-tolerant, flexible workloads like batch and analytics.
  • Use Spot Fleet or mixed instance Auto Scaling for resilience.
  • Combine with on-demand base capacity if needed.
  • Ensure orchestration restarts interrupted tasks and uses checkpoints.
Examples
Run batch ETL on Spot nodes with autoscaling and a job queue that retries failed tasks. Use EKS with mixed instances and node termination handlers to gracefully drain pods.
Common Mistake
Using Spot without interruption strategies leads to failed work and unpredictable costs.
Key Takeaway

Spot yields the best savings for interruption-tolerant workloads when combined with autoscaling and task orchestration.
