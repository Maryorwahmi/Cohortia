Module 12 › Chapter 12.6 › RIs vs Savings Plans
Reserved Instances
Tied to instance attributes; best for fixed, long-running instances.
  • Strong savings for predictable usage.
  • Less flexible if you need to change instance type or region.
Savings Plans
Commit to $/hour usage; applies broadly to compute and across instance families.
  • Greater flexibility across instance types and services.
  • Preferred when fleets evolve or use multiple compute services.
Analyze first
Use CUR/Cost Explorer to identify steady baselines before buying commitments.
Common Mistake
Buying RIs for ephemeral or frequently changing instances wastes spend.
Key Takeaway
Prefer Savings Plans for flexibility; reserve RIs for fixed, predictable workloads.
