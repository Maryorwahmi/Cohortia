Architecture › Serverless + CDN + Tiered Storage

Pattern components

  • • CloudFront caches content close to users to reduce origin requests.
  • • Lambda processes content on demand, eliminating always-on workers.
  • • S3 lifecycle rules move cold objects to Glacier classes for efficient storage.
Key Takeaway

This composition minimizes transfers and idle compute while preserving responsiveness through edge caching.

Concrete example

A media site uses CloudFront to cache thumbnails, Lambda to generate thumbnails only on first request, and archives raw footage to Glacier after 180 days. This reduces repeated origin processing and long-distance transfers.

Common mistake

Relying only on serverless without caching: on-demand processing for every request increases compute and transfer; combine both for best results.
