Definition › Serverless Computing

Why serverless helps sustainability

Provider-managed scaling and pay-per-use execution reduce idle capacity and let infrastructure run at higher overall utilization.

When to use
Event-driven tasks, spiky workloads, lightweight compute bursts.
Watchouts
Long-running, stateful jobs may be better on dedicated compute.
Concrete example

An image ingestion service uses Lambda to resize images only when a new object is created. There are no idle workers consuming CPU between uploads, so energy per image is reduced.

Key Takeaway

Match workloads to serverless when demand is intermittent or event-driven to reduce idle resource consumption and improve efficiency.
