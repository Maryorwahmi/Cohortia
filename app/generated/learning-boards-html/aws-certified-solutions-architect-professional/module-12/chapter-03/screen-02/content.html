01
Design hybrid connectivity
Choose Direct Connect or VPN for performance and availability. Verified competency: recommend a connectivity plan for a low-latency workload.
Mnemonic: Cable vs Tunnel
02
Centralize routing with Transit Gateway
Attach many VPCs and on‑prem networks to a single hub to avoid complex peering. Verified competency: diagram a hub-and-spoke and list route table considerations.
Mnemonic: Hub not Mesh
03
Integrate Active Directory
Pick AD Connector or Managed AD based on trust, sync, and management needs. Verified competency: map an AD integration pattern to an application requirement.
Mnemonic: Proxy or Managed
04
Select data transfer tools
Use Snow Family for petabyte moves, DataSync for automated file transfers, and DMS for database migrations. Verified competency: choose a transfer mechanism given size and downtime constraints.
Mnemonic: Ship, Sync, Migrate
How you’ll be assessed
  • Design a hybrid network
    Produce a plan using Direct Connect or VPN, show Transit Gateway attachments, and specify route tables and HA considerations.
  • Map identity integration
    Explain when to use AD Connector versus Managed AD and the implications for user authentication.
  • Choose migration tooling
    Recommend Snow Family, DataSync or DMS based on dataset size and acceptable downtime.
