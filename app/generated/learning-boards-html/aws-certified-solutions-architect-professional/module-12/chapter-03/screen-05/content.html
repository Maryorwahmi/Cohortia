Module 12 › Chapter 12.3 › Setting up AWS Direct Connect
Step-by-step
Order circuit and coordinate with partner
Arrange cross-connect at a Direct Connect location.
Create Direct Connect connection and VIF
Define private VIF for VPC access and public VIF for AWS public endpoints if needed.
Configure BGP and Direct Connect Gateway
Advertise prefixes and attach the Direct Connect Gateway to VPCs or Transit Gateway.
Validate and test performance
Check BGP session status, measure throughput, and confirm route propagation.
Example mapping
After provisioning a Direct Connect circuit, create a private VIF to a Direct Connect Gateway. Attach that gateway to your Transit Gateway so multiple VPCs can share the dedicated path without individual VIFs per VPC. Monitor BGP for stability.
Key Takeaway
Direct Connect requires physical provisioning and BGP setup; it delivers predictable bandwidth but still needs routing discipline.
