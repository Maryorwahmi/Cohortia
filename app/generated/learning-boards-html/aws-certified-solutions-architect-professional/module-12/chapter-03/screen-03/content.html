Module 12 › Chapter 12.3 › Learning Objectives — Operational Skills
Objective cards
01
Configure Transit Gateway
Create attachments, enable association and propagation, and update VPC route tables to route on-premises CIDRs through the Transit Gateway.
02
Establish VPNs with HA
Create Customer Gateway resources, configure IPSec tunnels, and ensure redundancy with multiple tunnels or devices.
03
Run network diagnostics
Use ping, traceroute, MTR and VPC Flow Logs to locate routing problems, blocked traffic, or latency sources.
04
Pick migration tooling
Decide between Snow Family, DataSync, and DMS depending on dataset size, bandwidth, and acceptable downtime.
Verification and mnemonic
Verified Competency Milestone: Implement a Site-to-Site VPN into a Transit Gateway and validate connectivity using ping and VPC Flow Logs. Perform a dry run for a DataSync job or request a Snow device evaluation for large datasets.
Tip
Always design redundancy into tunnels and gateways. A single customer gateway device or single VPN tunnel is a common single point of failure.
Common mistake
Forgetting to update VPC route tables to point to the Transit Gateway attachment often prevents traffic from reaching on-premises resources.
