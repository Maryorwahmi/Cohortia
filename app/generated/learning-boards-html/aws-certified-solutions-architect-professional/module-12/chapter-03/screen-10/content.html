Module 12 › Chapter 12.3 › Troubleshooting hybrid networks
Systematic checklist
  1. Verify physical status: Direct Connect circuit state or VPN tunnel status.
  2. Validate routing: BGP sessions, route tables, and route propagation in Transit Gateway.
  3. Check security: security groups, NACLs, and on‑premises firewall rules.
  4. Use network tools: ping, traceroute, and MTR from both sides to see where packets stop.
  5. Review AWS diagnostics: VPC Flow Logs and Network Access Analyzer for blocked traffic or unexpected paths.
Example quick commands
# From an on-prem host
ping 10.1.0.10
traceroute 10.1.0.10

# From an EC2 in a private subnet
ping 192.168.10.5
traceroute 192.168.10.5
Key Takeaway
Start with basic reachability checks, then validate routing and security policies, and use AWS logging to locate blocked traffic.
