Module 12 › Chapter 12.3 › Integrating Active Directory
Service options
AD Connector
A proxy that forwards authentication to on‑premises AD without syncing user accounts to AWS.
AWS Managed Microsoft AD
A fully managed, highly available AD hosted on AWS that can be trusted or used standalone.
Simple AD / standalone
Suitable for small or cloud-native setups where on‑premises integration is not required.
Design considerations
  • Decide whether you need proxy authentication or a managed directory in AWS.
  • Factor in latency and connectivity: authentication calls traverse the network and affect login times.
  • Consider management overhead: AD Connector reduces replication but increases dependency on on‑premises uptime.
Key Takeaway
Use AD Connector to keep a single on‑premises source of truth without syncing accounts; use Managed Microsoft AD when you need AWS-hosted directory services.
