Lab tip
If pings fail, check VPN tunnel state, ensure route tables include the on‑prem CIDR pointing to the Transit Gateway attachment, and verify security group rules allow ICMP for testing.
Example verification
1) Ensure VPN tunnels are reported UP in the console. 2) From OnPremServer, attempt ping to ProdAppServer private IP. 3) From ProdAppServer, traceroute to OnPremServer private IP. 4) Confirm return paths and security group permissions.
Common mistake
Neglecting to enable association and propagation on Transit Gateway attachments prevents routes from being learned and applied across attachments.
