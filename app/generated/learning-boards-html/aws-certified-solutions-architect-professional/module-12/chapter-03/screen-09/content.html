Module 12 › Chapter 12.3 › Choosing data transfer mechanisms
Tool summary
Snow Family
Physical devices for terabytes or petabytes; ship data to AWS when network transfer is impractical.
DataSync
Automated online transfer for file systems and object stores with scheduling and data integrity checks.
Database Migration Service
Migrate databases with minimal downtime using continuous replication and change data capture.
Decision factors
  • Volume of data: small, large, or petabyte-scale favors different approaches.
  • Network bandwidth: constrained links often point to Snow devices.
  • Acceptable downtime: DMS supports near-zero downtime migrations for databases.
  • Data integrity and automation: DataSync provides scheduling and verification for files.
Scenario: Petabyte archive
Order a Snow device to avoid saturating your WAN and speed the transfer.
Scenario: File server sync
Use DataSync to move files to S3 or EFS, with validation and scheduling.
Key Takeaway
Select transfer tooling by volume, bandwidth, and downtime requirements rather than defaulting to online copy for large datasets.
