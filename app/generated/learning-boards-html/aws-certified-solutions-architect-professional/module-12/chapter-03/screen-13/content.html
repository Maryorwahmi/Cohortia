Module 12 › Chapter 12.3 › Activity walkthrough & cleanup
Verification checklist
  1. Confirm VPN tunnels are UP in the console.
  2. Run ping and traceroute between simulated on-prem and VPC EC2s.
  3. Validate Transit Gateway route table propagation and associations.
  4. Check Security Groups and NACLs for allowed traffic during tests.
Cleanup steps
1. Delete VPN connection and Customer Gateway.
2. Detach and delete Transit Gateway attachments.
3. Delete Transit Gateway after attachments are removed.
4. Terminate EC2 instances and delete VPCs and subnets.
Common mistake
Attempting to delete a Transit Gateway while attachments exist will fail; remove attachments first to prevent orphaned resources and charges.
