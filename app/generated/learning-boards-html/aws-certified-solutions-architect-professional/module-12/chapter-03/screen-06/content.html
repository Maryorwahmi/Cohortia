Module 12 › Chapter 12.3 › Site-to-Site VPN
How it works
  • Define a Customer Gateway representing your on‑premises VPN device and its public IP.
  • Create a VPN connection to a Virtual Private Gateway or to a Transit Gateway as the AWS endpoint.
  • Establish IPSec tunnels and configure static routes or BGP for dynamic routing.
Best practice
Deploy at least two tunnels and, where possible, redundant customer gateway devices to avoid single points of failure.
Example checklist
Create Customer Gateway
Record the public IP of your on‑prem VPN device and choose BGP or static routing.
Create VPN connection
Select the Transit Gateway as the AWS target to centralize routing for multiple VPCs.
Configure on-prem device
Download VPN configuration from the console and apply IPSec settings. Allow UDP 500 and 4500 where necessary.
Key Takeaway
VPNs are fast to deploy and flexible; make them production-ready by adding redundancy and checking route tables.
