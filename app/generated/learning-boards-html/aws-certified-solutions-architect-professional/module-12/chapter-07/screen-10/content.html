Module 12 › Chapter 12.7 › Drift Management
Three-layer strategy
Prevent

Use IAM to deny console edits for IaC-managed resources and require pull requests for infra changes.

Detect

AWS Config rules and periodic stack drift detection reveal divergence from declared templates.

Remediate

Automate remediation with Config actions or reconciliation loops that apply the declared state from Git.

Example

Detect a modified security group, open an incident, and either automatically revert or require a PR to accept the intentional change.

Common mistake

Only detecting drift without remediation or policy controls allows repeated divergence and confusion about the true state.
