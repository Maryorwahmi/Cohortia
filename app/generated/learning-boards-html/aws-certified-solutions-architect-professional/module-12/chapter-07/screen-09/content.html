GitOps pattern

Commit changes to a Git repository that holds your declarative templates. An automated pipeline detects the commit and reconciles the infrastructure to the declared state.

Example

A CloudFormation template change in Git triggers CodePipeline to synthesize and deploy a stack update with policy checks applied.

Operational note

Treat Git as the source of truth and ensure only approved merge paths allow direct changes to production branches.

Key Takeaway

GitOps improves traceability and enables automated reconciliation, but it must be combined with role controls and policy checks.
