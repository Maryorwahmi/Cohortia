Module 12 › Chapter 12.7 › Shift-Left Security
Security steps inside the pipeline
  • Static IaC analysis with cfn-nag or checkov during the build stage.
  • Policy validation with CloudFormation Guard or equivalent before deploy actions.
  • Vulnerability scanning for container images or dependencies in CodeBuild.
Example

A synthesized template containing a public S3 bucket is flagged by a scanner and fails the build before deployment.

Key Takeaway

Fail-fast on critical security issues, and include clear remediation guidance in build logs for developers.

Misconception

Adding checks does not equal slowing down when they are focused on high-risk fails and quick feedback for fixes.
