Verify pipeline behavior

Concrete checks and audits you should run while building pipelines and IaC.

Checkpoint
  • Confirm CodeBuild can synthesize CDK and outputs a CloudFormation template artifact.
  • Validate CloudFormation stack creation with required capabilities and execution role.
  • Test pipeline rollback behavior by injecting a failing test.
Policy checks
  • Run static IaC scanners before deploy.
  • Enforce minimum permissions for build and deploy roles.
  • Use CloudFormation Guard or AWS Config for template rules.
Lab task
Synthesize and deploy a CDK app via CodePipeline and observe outputs.
Audit
Record who triggered pipelines and verify artifacts in the build stage.
Milestone
Automated deploy with a security scan that blocks risky changes.
