Module 12 › Chapter 12.7 › CI/CD Composition
Process Flow
1. Source

CodeCommit (Git) stores application and infrastructure code. Commits trigger pipeline starts.

2. Build & Test

CodeBuild runs unit tests, integration tests, and synthesizes IaC artifacts like CloudFormation templates.

3. Policy checks

Static IaC analysis and image vulnerability scans run here; failures block deployment.

4. Deploy

CodeDeploy or CloudFormation executes changes with deployment strategies like blue/green or canary.

Supporting details
  • Parameterize pipelines so the same definition can target dev, staging, and production with different inputs.
  • Use manual approvals only at critical gates and combine with automated security checks for speed and safety.
  • Ensure build artifacts include synthesized templates and metadata for traceability and rollback.
Example

A commit runs cdk synth in CodeBuild; the artifact is deployed via CloudFormation action in CodePipeline.

Key Takeaway

Design pipelines as reusable, parameterized templates with early security checks and clear rollback behavior.

Common mistake

Creating separate, manually configured pipelines per environment leads to drift and inconsistent deploys.
