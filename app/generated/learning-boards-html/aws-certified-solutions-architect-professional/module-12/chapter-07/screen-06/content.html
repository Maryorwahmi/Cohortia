Code example (Python CDK)
from aws_cdk import (
    Stack,
    aws_lambda as _lambda,
    aws_apigateway as apigw,
)
from constructs import Construct

class MyServerlessAppStack(Stack):
    def __init__(self, scope: Construct, construct_id: str, **kwargs) -> None:
        super().__init__(scope, construct_id, **kwargs)

        # Define the Lambda function
        my_lambda = _lambda.Function(
            self, 'MyLambdaHandler',
            runtime=_lambda.Runtime.PYTHON_3_9,
            code=_lambda.Code.from_inline("def handler(event, context):
    return {'statusCode': 200, 'body': 'Hello from CDK Lambda!'}"),
            handler='index.handler'
        )

        # Define the API Gateway
        apigw.LambdaRestApi(
            self, 'MyApiGateway',
            handler=my_lambda,
            proxy=True
        )
Example note

Synthesize this stack with cdk synth to produce a CloudFormation template for deployment.

Supporting points
  • CDK lets you create reusable constructs to reduce boilerplate and enforce standards.
  • Synthesized templates should be scanned and versioned as pipeline artifacts.
  • Keep constructs small and well-documented to simplify auditing and reviews.
Key Takeaway

CDK combines programming abstractions with CloudFormation outputs for productivity without losing auditability.
