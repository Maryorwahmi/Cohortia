# Push project to CodeCommit and create pipeline that runs cdk synth in CodeBuild
Note

Ensure CodeBuild role has permissions to run cdk synth and upload artifacts to the pipeline artifact bucket.

Pipeline configuration
  • Source: CodeCommit repository and branch.
  • Build: CodeBuild project that installs CDK and runs synth.
  • Deploy: CloudFormation action that applies the synthesized template with required capabilities.
Key Takeaway

Automate the entire synth-and-deploy cycle so every change in Git is a reproducible infrastructure update.
