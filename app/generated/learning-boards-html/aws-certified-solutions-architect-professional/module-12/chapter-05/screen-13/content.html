Forensic Readiness
Logs and snapshots are only useful if they are protected and preserved.
CloudTrail
Record API activity across accounts for timeline reconstruction.
VPC Flow Logs
Capture network traffic metadata to trace lateral movement and exfiltration.
S3 Versioning & MFA Delete
Protect critical logs and backups from tampering or accidental deletion.
Common mistake
Storing logs only on instances or ephemeral storage which can be lost when machines are replaced.
Runbook step
On detection, snapshot affected systems, preserve logs with versioning, and document collection with timestamps and owners.
Key Takeaway

Design logging and backups for immutability and quick retrieval so investigations are accurate and defensible.
