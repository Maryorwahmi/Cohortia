Incident Response Phases
Identify
Confirm events using GuardDuty, CloudTrail, and host telemetry.
Contain
Limit blast radius by isolating compromised credentials and network access.
Eradicate
Remove malicious code, patch systems, and rotate secrets.
Recover
Restore from verified backups and confirm integrity before returning to production.
Analyze
Document root cause, update runbooks and add automated checks to prevent recurrence.
Forensic readiness
Preserve CloudTrail and VPC Flow Logs, enable S3 versioning and MFA Delete for critical logs, and ensure snapshots are immutable for legal and analysis needs.
Runbooks
Define roles, contacts, escalation rules and exact steps for common findings so response is predictable and auditable.
Key Takeaway

Prepare logs and runbooks in advance. Practice with tabletop exercises and controlled drills to validate readiness.
