Automation Patterns
Detect, notify, quarantine, remediate — with logging and rollback.
Detect
Use GuardDuty, Inspector or Config rules to surface findings.
Notify
Push findings to Security Hub or an SNS topic for human review when needed.
Remediate
Trigger a Lambda for low-risk changes like tightening security group rules or disabling root keys.
Concrete scenario
A Config rule detects an open SSH port to the world. Automated remediation first adds a more restrictive rule, logs the action, and creates a ticket for owner review.
Common mistake
Running destructive automation without staging or rollback; always test and log every action.
