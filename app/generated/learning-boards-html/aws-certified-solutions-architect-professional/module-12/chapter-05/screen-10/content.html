Module 12 › Chapter 12.5 › AWS Services
Amazon GuardDuty
Continuous threat detection using machine learning and threat intelligence to find compromised instances or unusual API activity.
Amazon Inspector
Automated assessment of EC2 instances for software vulnerabilities and network exposure.
AWS WAF
Protect web apps and APIs from common exploits and block malicious traffic patterns.
AWS Security Hub
Aggregate findings, run automated checks, and serve as a central place to orchestrate remediation and reporting across accounts.
Design pattern: route GuardDuty and Inspector findings to Security Hub, apply automated playbooks for low-risk remediation, and escalate high-risk findings to incident response owners with runbooks.
