Process Flow
Cataloging and ETL with AWS Glue
Crawl to catalog, then run ETL to produce curated datasets.
Step 1 — Register S3 locations
Register the bucket with Lake Formation and give the crawler permissions to read it.
Step 2 — Run Glue crawler
Crawler discovers schema and writes table definitions into the Glue Data Catalog.
Step 3 — ETL job
Glue ETL performs cleaning, removes sensitive columns, partitions by date, and writes Parquet to curated prefix.
Key Takeaway

Maintain the catalog as the authoritative index and automate crawlers and ETL to keep metadata accurate.

Concrete example — sales CSV discovery
order_id,customer_id,product,amount,region,sensitive_info
1,101,Laptop,1200.00,North,ABC123
2,102,Mouse,25.00,South,DEF456
3,101,Keyboard,75.00,North,GHI789
Crawler creates mydatalake_db.sales_data. ETL job drops sensitive_info and writes partitioned Parquet for analytics.
Common mistake
Not scheduling crawlers after schema changes leads to stale table definitions and query failures.
