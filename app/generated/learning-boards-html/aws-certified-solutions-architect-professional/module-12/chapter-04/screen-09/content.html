Core Concept
Lake Formation for Fine-Grained Access
Centralize permissions and apply column-level restrictions integrated with Glue and analytics services.
Registering locations
Register S3 prefixes so Lake Formation can manage access to those datasets.
Granting permissions
Grant SELECT/DESCRIBE at database, table, and column levels. Use exclusions for sensitive columns.
Integration
Athena, Redshift Spectrum, and EMR honor Lake Formation permissions when configured to use the Glue Data Catalog.
Concrete example
Grant AnalystRole SELECT on mydatalake_db.sales_data but exclude column sensitive_info. Admins see full data; analysts see a safe view.
Check
As the restricted user, run SELECT * FROM sales_data; you should not see the excluded column. Attempt SELECT sensitive_info FROM sales_data; should return access denied.
Key Takeaway

Lake Formation centralizes and simplifies fine-grained lake permissions across analytics services.
