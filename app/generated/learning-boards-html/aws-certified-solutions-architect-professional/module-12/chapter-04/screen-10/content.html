Hands-on Activity
Build a Secure Data Lake
Follow these steps in your lab environment to register and protect data.
1. Create S3 bucket
Enable default encryption with SSE-S3 or a KMS CMK. Create sales_data/ prefix.
2. Upload sample CSV
Upload sales.csv into the sales_data prefix to use for discovery and testing.
3. Register and crawl
Register the S3 location in Lake Formation, create sales_data_crawler in Glue, and run it to populate mydatalake_db.sales_data.
4. Grant Lake Formation permissions
Grant SELECT and DESCRIBE to AnalystRole and exclude sensitive_info column to test column-level control.

-- As restricted analyst (column excluded):
SELECT * FROM mydatalake_db.sales_data; -- sensitive_info not visible
SELECT sensitive_info FROM mydatalake_db.sales_data; -- access denied
Common mistake
Forgetting s3:GetObject or Lake Formation registration prevents discovery and denies queries unexpectedly. Grant least privilege but validate the required read permissions for crawlers and jobs.
