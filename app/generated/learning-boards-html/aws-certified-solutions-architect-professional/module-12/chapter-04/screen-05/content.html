Definition
Data Lake
Flexible storage for raw and semi-structured data, typically on Amazon S3.
Use cases
Exploratory analytics, machine learning, archival of raw data.
Governance needs
Glue Data Catalog, Lake Formation permissions, lifecycle rules to avoid data swamps.
Definition
Data Warehouse
Structured, optimized store for reporting and BI, commonly Redshift.
Use cases
Business dashboards, complex SQL reporting, low-latency aggregated queries.
Governance needs
Schema governance, permission controls, and lineage from ETL that feeds the warehouse.
Example flow: raw CSVs → Glue ETL transforms → Curated Parquet in lake → Redshift ingest for BI dashboards.
