Module 12 › Chapter 12.10 › Hybrid Networking
Architecture
Transit Gateway + Direct Connect pattern
Core Components
  • AWS Direct Connect for private bandwidth
  • Transit Gateway as centralized router
  • Transit GW attachments for VPCs and DX Gateway
  • Site-to-Site VPN as resilient backup
Security Controls
  • VPC segmentation and private subnets
  • Least-privilege IAM and KMS for transit data
  • Centralized logging (CloudWatch, VPC Flow Logs)
  • WAF and centralized inspection where required
Data Sync Patterns
Use synchronous replication for critical ERP transactions only if latency budget allows. Prefer asynchronous events (EventBridge, SQS) for bulk updates and decoupling. For database migrations, use DMS with continuous replication and validated cutovers.
Example Topology
Direct Connect & Transit GW connect on-premises ERP to multiple AWS VPCs (e-commerce, analytics, shared-services). VPN acts as active backup. Route propagation and prefix lists control access.
Pro Tip

Test failover regularly: simulate Direct Connect outage and measure ERP latency over VPN to validate SLA alignment.

Pitfall
Relying only on VPN over the internet without bandwidth planning can cause inconsistent performance for inventory and order flows during peak events.
