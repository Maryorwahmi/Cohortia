Module 12 › Chapter 12.10 › Target Architecture
Layered Component Cards
Front-end: S3 + CloudFront + Route 53 for global low-latency delivery.
Application: EKS/ECS with Fargate or Lambda for microservices, behind an ALB for HTTP routing.
Data: RDS for transactional data, DynamoDB for high-scale access, ElastiCache for sessions and caching.
Messaging: SQS for buffering, SNS for notifications, EventBridge for event routing.
Cross-Cutting Concerns
Analytics: Kinesis → S3 data lake → Glue → Athena/Redshift.
Security: IAM, KMS, WAF, GuardDuty, Security Hub, AWS Config.
Hybrid Connectivity: Direct Connect + Transit Gateway with VPN fallback for ERP integration and consistent network performance.
Example justification: Choose DynamoDB for shopping cart if you need massive scale and sub-10ms reads even if eventual consistency is acceptable; document this trade-off in the HLD.
