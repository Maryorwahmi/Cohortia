Architecture
CloudTrail & Centralized Logging
Centralize trails to a logging account and protect logs from tampering to preserve audit evidence.
Claim
CloudTrail records API activity and is essential for investigations and providing audit evidence.
Concrete example
Stream CloudTrail logs into a centralized S3 bucket in a logging account and query them with Athena for investigations.
Safety note
Enable trails in all regions and protect the S3 bucket with policies and MFA Delete to prevent tampering or accidental deletion.
Key Takeaway

Design a logging account, enable regional and global trails, and harden log storage to ensure reliable audit evidence.

Logging pattern
Ingest
Create a CloudTrail that writes to a centralized S3 bucket in a dedicated logging account.
Protect
Apply S3 bucket policies to prevent deletion from member accounts and enable MFA Delete if required by policy.
Analyze
Use Athena, Security Hub, or SIEM tools to search logs and produce audit reports.
