Process Flow
Guardrail → Detect → Remediate
Design a closed-loop governance workflow to prevent, detect, and correct non-compliant resources.
Guardrail
SCPs and IAM policies limit allowed actions and set boundaries across accounts.
Detect
AWS Config rules evaluate resource state; CloudTrail records activities for investigation.
Remediate
A remediation Lambda applies fixes and logs its actions for auditors.
Key Takeaway

Implement the loop iteratively: start with high-impact resources, verify remediation safely, and expand coverage while preserving logs for audits.

Example application
Protect data stores with SCPs preventing unapproved regions, detect unencrypted buckets with Config, and remediate with Lambda.
Document the loop in runbooks and include audit references to Config evaluations and CloudTrail entries.
Measure success by reduction in NON_COMPLIANT findings and time from detection to remediation.
