Core Concept
AWS Config & Rules
Continuously evaluate resource configurations and trigger actions on non-compliance.
Definition
Config records configuration states and lets you create rules to evaluate compliance against desired settings.
Example rule
s3-bucket-server-side-encryption-enabled — flags buckets without default encryption and can trigger remediation.
Design decision
Decide which rules use automatic remediation and which require human review based on risk impact.
Key Takeaway

Use Config for continuous evaluation and remediation triggers; pair it with CloudTrail for full audit context.

Evaluation & remediation pattern
Detect
Config evaluates resources against a rule and marks NON_COMPLIANT when a violation occurs.
Notify
Config can send events or SNS notifications to indicate violations and start workflows.
Remediate
Trigger a Lambda function to apply a fix such as enabling default encryption on an S3 bucket.
