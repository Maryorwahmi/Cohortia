Process Flow
Config Rule → Lambda Remediation
Detect a non-compliant resource with Config and invoke Lambda to apply a corrective action automatically.
Lambda remediation (Python)
<pre><code>import boto3 import json s3 = boto3.client('s3') def lambda_handler(event, context): # Received event from AWS Config change notification print(f"Received event: {json.dumps(event)}") invoking_event = json.loads(event['invokingEvent']) configuration_item = invoking_event['configurationItem'] bucket_name = configuration_item['resourceName'] print(f"Attempting to encrypt bucket: {bucket_name}") try: s3.put_bucket_encryption( Bucket=bucket_name, ServerSideEncryptionConfiguration={ 'Rules': [ { 'ApplyServerSideEncryptionByDefault': { 'SSEAlgorithm': 'AES256' } } ] } ) print(f"Successfully enabled default encryption for bucket: {bucket_name}") return { 'statusCode': 200, 'body': json.dumps(f"Enabled default encryption for bucket: {bucket_name}") } except Exception as e: print(f"Error encrypting bucket {bucket_name}: {e}") raise e </code></pre>
IAM role for Lambda
Lambda needs s3:PutBucketEncryption and CloudWatch Logs permissions. Use least privilege.
<pre><code>{ "Version": "2012-10-17", "Statement": [ { "Effect": "Allow", "Action": ["s3:PutBucketEncryption"], "Resource": "arn:aws:s3:::*" }, { "Effect": "Allow", "Action": [ "logs:CreateLogGroup", "logs:CreateLogStream", "logs:PutLogEvents" ], "Resource": "arn:aws:logs:*:*:*" } ] } </code></pre>
Example flow
Create an unencrypted bucket, let Config evaluate it as NON_COMPLIANT, then observe Lambda enabling default encryption and Config returning the resource to COMPLIANT.
Misconception
Automation does not remove the need for logs and evidence. Ensure all steps are recorded for audits.
