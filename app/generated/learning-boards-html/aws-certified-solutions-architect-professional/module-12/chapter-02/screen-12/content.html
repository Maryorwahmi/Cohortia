Module 12 › Chapter 12.2 › Triggers & Observability
Configure triggers
Add SQS as a trigger for each Lambda function in the console and set batch size to 1 for testing. Increase batch size for throughput when behavior is validated.
Visibility timeout
Set visibility timeout longer than expected processing time to avoid premature redelivery. Tune based on observed execution durations.
Observe CloudWatch logs
Verify each Lambda logged processing lines for messages sent to the queue. Logs prove separate consumers processed messages independently.
Common mistake
Expecting SQS to broadcast to multiple consumers. Use SNS or EventBridge when true fan-out is required.
Key Takeaway

Test with small batches, confirm logs, and tune visibility timeout to match processing duration to avoid duplicate work.
