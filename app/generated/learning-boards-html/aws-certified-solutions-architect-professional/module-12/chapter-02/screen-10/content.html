IAM policy (scoped to your queue ARN)
{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Effect": "Allow",
            "Action": [
                "sqs:ReceiveMessage",
                "sqs:DeleteMessage",
                "sqs:GetQueueAttributes"
            ],
            "Resource": "arn:aws:sqs:REGION:ACCOUNT_ID:OrderProcessingQueue"
        },
        {
            "Effect": "Allow",
            "Action": [
                "logs:CreateLogGroup",
                "logs:CreateLogStream",
                "logs:PutLogEvents"
            ],
            "Resource": "arn:aws:logs:*:*:*"
        }
    ]
}
Replace REGION and ACCOUNT_ID with your values. Attach a trust policy that allows lambda.amazonaws.com to assume the role.
Checklist
  • Create SQS queue named OrderProcessingQueue and note ARN.
  • Create IAM role with the policy shown and a Lambda trust policy.
  • Attach role to Lambda functions that will consume messages.
Tip
Use least privilege and scope the SQS resource to the queue ARN to avoid broad permissions.
