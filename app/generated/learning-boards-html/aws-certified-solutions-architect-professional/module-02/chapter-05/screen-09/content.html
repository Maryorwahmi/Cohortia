Module 2 › Chapter 2.5 › Hands-on: Provision NAT Gateway and S3 Gateway Endpoint (CLI)
Starter commands
# Allocate an Elastic IP for the NAT Gateway
aws ec2 allocate-address --domain vpc

# Create a NAT Gateway in the public subnet
aws ec2 create-nat-gateway --subnet-id subnet-pub123 --allocation-id eipalloc-0abcdef1234567890

# Update private route table to use the NAT Gateway
aws ec2 create-route --route-table-id rtb-priv789 --destination-cidr-block 0.0.0.0/0 --nat-gateway-id nat-0fedcba9876543210

# Create an S3 Gateway Endpoint for the VPC
aws ec2 create-vpc-endpoint \
  --vpc-id vpc-1234567890abcdef0 \
  --service-name com.amazonaws.us-east-1.s3 \
  --vpc-endpoint-type Gateway \
  --route-table-ids rtb-priv789
Verification
From a private instance, verify internet and S3 access with package updates and an S3 list. Use a bastion host for SSH if needed.
Example checks
ping 8.8.8.8 -c 4, curl https://example.com, aws s3 ls — all should succeed from the private instance if routes are correct.
Wait note
NAT Gateway creation can take minutes. Wait for it to reach available state before creating routes to avoid transient failures.
