Module 2 › Chapter 2.5 › Data Transfer Costs — Where and why they apply
Definition and rules
  • Same AZ traffic is typically free; cross-AZ traffic usually costs a small per-GB fee.
  • Cross-region transfer is expensive; avoid moving large datasets between regions.
  • Internet egress from AWS to the public internet incurs per-GB charges.
  • CloudFront caching reduces repeated origin egress by serving cached objects close to users.
Example
If a processing pipeline downloads 5 TB daily from S3, using an S3 Gateway Endpoint keeps that traffic inside the region and avoids internet egress charges that would apply if accessed through a NAT or Internet Gateway.
Diagram substitute: Traffic map
High-volume flows: tag them. Place compute and storage in the same AZ or region. If cross-region is required, compress or reduce transfers and cache responses.
Key Takeaway

Label and minimize high-volume network flows first; co-location and caching are the cheapest optimizations.
