Module 2 › Chapter 2.5 › VPC Endpoints — Private connectivity without the internet
Interface vs Gateway
  • Gateway Endpoint: route table entry, S3 and DynamoDB only, free to use.
  • Interface Endpoint: PrivateLink-powered ENIs, supports many services, incurs costs.
Concrete example
An analytics cluster that repeatedly reads S3 data should use an S3 Gateway Endpoint so reads stay within the region and avoid NAT or internet egress.
Decision guide
  1. Is the target service S3 or DynamoDB? Use a Gateway Endpoint.
  2. Does the service support PrivateLink or require an ENI? Use an Interface Endpoint.
  3. Estimate traffic: high-volume storage flows favor gateway endpoints where possible.
Common mistake
Assuming all endpoints are free. Interface endpoints can add per-hour and per-GB charges, so confirm costs before wide deployment.
