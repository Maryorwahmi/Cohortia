Module 2 › Chapter 2.5 › Lab Scenario: Step-by-step architecture
Numbered steps
  1. Create a public and a private subnet in the VPC.
  2. Allocate an Elastic IP and create a NAT Gateway in the public subnet.
  3. Add a 0.0.0.0/0 route in the private route table to the NAT Gateway.
  4. Create an S3 Gateway Endpoint and attach it to the private route table.
  5. Launch a private EC2, SSH via bastion, and verify internet and S3 access.
Verification tips
After updating routes, check connectivity, and use Cost Explorer to monitor data transfer after a day or two of traffic to confirm savings.
Analogy
Think of the S3 Gateway Endpoint as a private hallway between your servers and storage. It keeps traffic inside the building rather than sending it out through public streets.
Common pitfalls
  • Forgetting to attach the endpoint to the correct route table.
  • Not waiting for NAT Gateway to become available before updating routes.
