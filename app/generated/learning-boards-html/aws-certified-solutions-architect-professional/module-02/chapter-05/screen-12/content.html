Module 2 › Chapter 2.5 › Common mistakes and safe optimizations
Common mistakes
  • Not using gateway endpoints for S3/DynamoDB.
  • Relying on a single NAT instance without HA or scaling.
  • Cross-region replicas without transfer optimization.
Safe optimizations
  • Use S3 Gateway Endpoints for high-volume storage access.
  • Prefer NAT Gateway for production to reduce operational risk.
  • Compress or schedule cross-region transfers and use caching.
Reflection
Which single change to your network would reduce cost the most while maintaining security? Start with the largest volume path you control.
