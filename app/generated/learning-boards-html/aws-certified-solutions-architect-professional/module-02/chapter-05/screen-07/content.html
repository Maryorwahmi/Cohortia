Module 2 › Chapter 2.5 › AWS Global Accelerator
What it provides
  • Two static Anycast IP addresses as fixed entry points.
  • Routing to the nearest edge and across AWS backbone to endpoints.
  • Automatic failover between healthy endpoints.
Example
A global application routes users to the nearest edge; traffic then travels the AWS backbone to the primary region, saving significant latency versus internet-only paths.
When to use
Use Global Accelerator when global latency matters, when you need static IPs for clients, and when faster failover improves availability. Pair with CloudFront for caching static assets.
Misconception check
Global Accelerator is not a caching layer. Use CloudFront for caching and Global Accelerator to optimize routing of dynamic or non-HTTP flows.
