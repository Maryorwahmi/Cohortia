Module 2 › Chapter 2.5 › What to Remember
Co-locate & Cache
Keep compute and storage close; use CloudFront for public caching to reduce origin egress.
Privatize Service Access
Use gateway and interface endpoints to keep AWS service traffic off the public internet.
Prefer Managed NAT
Use NAT Gateway in production for reliability; consider NAT instance only for very low traffic.
Final reflection
Start by mapping traffic, then apply co-location, endpoints, and managed services. Monitor to confirm both cost and security outcomes.
