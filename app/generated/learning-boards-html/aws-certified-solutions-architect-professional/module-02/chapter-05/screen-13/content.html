Functional checks to run
  • ping 8.8.8.8 -c 4
  • yum update or apt-get update on the private instance
  • aws s3 ls to list S3 buckets from the private instance
Cost checks
Use Cost Explorer to filter by data transfer and NAT Gateway metrics. Compare processed bytes and trend lines against baseline usage.
Validation trick
Temporarily remove the NAT route to confirm S3 access still works via the Gateway Endpoint. If it breaks, the endpoint is not attached properly.
Safety note
Do not make S3 buckets public to avoid egress. Always prefer private endpoints and IAM controls over public access for cost and security reasons.
