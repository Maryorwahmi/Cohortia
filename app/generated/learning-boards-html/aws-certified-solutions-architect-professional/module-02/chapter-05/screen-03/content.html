Module 2 › Chapter 2.5 › Learning Objectives — Continued
Practical tasks
  • Configure an S3 Gateway Endpoint and route table entry.
  • Provision a NAT Gateway and update private routes for outbound traffic.
  • Verify private instance internet and S3 access through configured paths.
  • Read Cost Explorer and CloudWatch to spot egress hot spots.
Assessment pointers
Each task should include a verification step: a route table entry, a successful package update from a private instance, and an S3 list command that succeeds without using the internet gateway.
Pro tip
Treat gateway endpoints as first-class design elements for storage-heavy workloads; they eliminate egress and reduce blast radius.
Common mistake
Relying on internet gateways for service access instead of endpoints, which increases costs and exposes traffic to the internet.
