Module 3 › Chapter 2.6 › Key Concepts
Custom Route Table
A user-defined routing table in a VPC that directs subnet traffic to specific gateways or targets.
Transit Gateway Route Table
Controls traffic flow between TGW attachments and supports route propagation and association for segmentation.
BGP
Dynamic protocol for exchanging routing information between autonomous systems, used for Direct Connect and dynamic VPNs.
Summary
Use route table design, TGW propagation control, and BGP attribute planning together to enforce segmentation and predictable path selection across hybrid networks.
