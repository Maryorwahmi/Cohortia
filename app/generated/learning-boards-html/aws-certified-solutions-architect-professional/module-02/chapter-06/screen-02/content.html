Learning Objectives
Progress from configuration to diagnosis and remediation.
Bloom: Learn → Understand → Apply → Master
01
Configure custom route tables
Create and associate route tables per subnet and design TGW route tables for attachment isolation. This matters because proper association enforces segmentation and prevents unintended traffic paths.
Mnemonic: Subnet → single route table
VERIFIED COMPETENCY MILESTONE
02
Implement BGP for hybrid links
Set up BGP peering with correct ASNs and use attributes to influence routing when multiple links exist. This reduces manual route maintenance and supports scalable exchange of prefixes.
Mnemonic: ASN + attributes = path control
VERIFIED COMPETENCY MILESTONE
03
Use Reachability Analyzer
Validate static paths between resources and identify the blocking component reported by the analyzer. This saves time during incident response and avoids trial-and-error changes.
Mnemonic: Source → Analyzer → Blocking rule
VERIFIED COMPETENCY MILESTONE
04
Analyze logs and use Network Manager
Interpret VPC Flow Logs for accept/reject patterns and use Transit Gateway Network Manager for topology and performance monitoring. Central visibility speeds diagnosis across global networks.
Mnemonic: Logs + topology = fast root cause
VERIFIED COMPETENCY MILESTONE
