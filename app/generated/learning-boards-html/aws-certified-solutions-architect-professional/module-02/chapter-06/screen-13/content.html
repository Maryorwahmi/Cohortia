Module 3 › Chapter 2.6 › Common Scenarios
Asymmetric Routing
Occurs when inbound and outbound paths differ, often due to BGP attributes or route table mismatches.
Security Group / NACL Conflicts
Check both stateful security groups and stateless NACLs; overlapping rules can block expected traffic.
DNS Resolution
Confirm VPC DNS settings, Route 53 Resolver, and firewall rules on DNS ports.
MTU Mismatch
Mismatched MTU can cause fragmentation and performance problems across VPN or DX paths.
BGP Peering Failures
Check ASNs, neighbor IPs, and authentication. If BGP is down, routes aren't exchanged and reachability fails despite correct route tables.
Key Takeaway

Classify the symptom, gather logs and analyzer findings, then apply a single verified change with a rollback plan to avoid cascading issues.
