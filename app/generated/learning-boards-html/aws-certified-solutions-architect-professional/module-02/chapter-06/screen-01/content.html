Concept Map
VPC & Subnet Routes
Custom route tables map subnets to gateways and targets like NAT, IGW, or TGW.
Example: Private subnet route 0.0.0.0/0 → NAT Gateway, keeps instances private while allowing outbound internet access.
Transit Gateway
TGW route tables control which attachments can reach each other and support propagation from attachments.
Example: Use separate TGW route tables to isolate prod and dev attachments despite a shared TGW.
