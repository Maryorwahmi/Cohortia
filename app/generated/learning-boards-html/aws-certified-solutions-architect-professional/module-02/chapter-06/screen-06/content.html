What BGP does
BGP advertises and learns prefixes between autonomous systems, enabling dynamic routing for hybrid networks.
Concrete example
On Direct Connect, your on-prem router advertises its CIDRs; AWS advertises the VPC CIDRs back. Routes are then visible in TGW or VPC routing tables depending on attachments.
Common misconception
BGP advertisement alone does not ensure connectivity. Security Groups, NACLs, or TGW route table configuration can still block traffic after routes exist.
ASN
Autonomous System Number identifies each routing domain for BGP peering and is required on both peers.
Peering
Establish a BGP session with matching neighbor IPs and ASNs to exchange routes.
Verify
Confirm advertised prefixes and BGP session state before trusting the control plane.
Key Takeaway

BGP removes manual route churn for hybrid connectivity, but you must pair routing verification with security and route table validation to ensure true reachability.
