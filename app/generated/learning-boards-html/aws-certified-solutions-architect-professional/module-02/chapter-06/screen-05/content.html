Module 3 › Chapter 2.6 › Transit Gateway Route Tables
TGW Concepts
Create multiple TGW route tables, associate attachments, and choose whether to propagate routes from attachments.
Attachment association
Associating an attachment ties it to the route rules of that TGW table. Only associated attachments follow the table's routes.
Route propagation
Propagation adds routes learned from an attachment into the TGW route table automatically, simplifying management for dynamic sources.
Isolation pattern
Create separate TGW route tables for prod and dev and only associate respective attachments. Control propagation so routes do not cross environments unintentionally.
Example checklist
  • Confirm attachments are associated with the intended TGW route table.
  • Check propagated route entries to ensure expected prefixes appear.
  • Add static routes only when propagation is not desired.
Key Takeaway

Design TGW route tables to mirror your security boundaries. Associations and propagation together determine reachability, so manage both deliberately.
