Module 3 › Chapter 2.6 › VPC Flow Logs
What to collect
  • Flow Log entries for source and destination ENIs.
  • Time window around the failure event.
  • Protocol, source/destination ports and action fields.
Interpretation
REJECT on inbound suggests Security Group or NACL block. ACCEPT with no end-to-end reachability suggests routing or on-premises filtering.
Example query idea
# Use CloudWatch Logs Insights or Athena to filter by source IP, dest IP and time
fields @timestamp, srcaddr, dstaddr, action
| filter srcaddr = "10.1.1.10" and dstaddr = "10.2.1.10"
| sort @timestamp desc
| limit 50
This sample shows how you would filter logs by IPs to find ACCEPT or REJECT entries tied to the event.
Key Takeaway

Use Flow Logs to prove whether packets were accepted by AWS network controls. Combine with reachability analysis to complete the diagnosis.
