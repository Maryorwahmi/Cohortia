Module 3 › Chapter 2.6 › Reachability Analyzer
How it works
Static analysis inspects configuration artifacts — SGs, NACLs, route tables, TGW settings — and reports whether a path is reachable and where it is blocked.
Example
Analysis from instance-A to instance-B on TCP/22 returns a 'SecurityGroupRule' block. Fixing the security group resolves reachability.
Best practice
  • Run analyzer before making changes to see the blocking control.
  • Use analyzer findings to craft minimal, auditable fixes.
  • Confirm findings with Flow Logs to validate runtime behavior.
Key Takeaway

Reachability Analyzer isolates the blocking component in static configuration. Use it to target your fixes and avoid blind changes to production routing.
