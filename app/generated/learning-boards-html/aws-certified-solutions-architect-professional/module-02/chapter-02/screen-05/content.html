Process: Create and operate a Site-to-Site VPN
1. Create a Virtual Private Gateway (VGW)
Attach it to the VPC that hosts your private resources.
2. Create a Customer Gateway (CGW)
Specify the public IP and BGP ASN of your on-prem router.
3. Create VPN connection with two tunnels
Choose dynamic BGP for automatic route exchange or static routes for manual control.
Example
A corporate router with ASN 65000 peers with AWS using BGP; when an on-prem subnet is added, it is advertised to AWS automatically.
Common mistake
Not updating the VPC route table to include the on-prem CIDR; the tunnel can be UP but traffic still fails.
Visual: component cards
Customer Gateway (CGW)
Represents the on-prem device and public IP; includes BGP ASN for dynamic routing.
Virtual Private Gateway (VGW)
AWS endpoint attached to a single VPC; receives VPN tunnels.
Tunnels and redundancy
Two tunnels with separate public IPs provide resilience. If one fails, traffic shifts to the other.
