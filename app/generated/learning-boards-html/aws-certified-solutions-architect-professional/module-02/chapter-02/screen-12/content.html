Module 2 › Chapter 2.2 › Common connectivity issues and diagnostics
Diagnostic checklist
1. Tunnel status
Confirm both tunnels are UP; if down, inspect IPsec config, keys, and network reachability.
2. Routing
Check VPC route tables and on-prem route advertisements; ensure correct CIDRs and next-hops are configured.
3. BGP and ASNs
Verify BGP neighbor status and correct ASNs; mismatched ASNs prevent route exchange.
Key Takeaway

A systematic check of tunnel state, routing, and security rules quickly reveals most hybrid connectivity issues.

Scenario example
Symptom
Tunnel shows UP but instances cannot be reached from on-prem.
Diagnosis steps
1) Check VPC route table for route to on-prem; 2) Confirm on-prem advertises VPC CIDR; 3) Inspect NACLs and security groups.
Prevention
Document routing maps and test failover scenarios regularly to catch misconfigurations early.
