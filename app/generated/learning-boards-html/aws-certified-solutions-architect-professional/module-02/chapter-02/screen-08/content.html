Module 2 › Chapter 2.2 › VIFs and Direct Connect Gateway
VIF types and purpose
Private VIFs connect to your VPCs through VGW or Direct Connect Gateway to carry private IP traffic. Public VIFs carry traffic to public AWS services over the private link.
Private VIF
Used for VPC private IP traffic; attach to Direct Connect Gateway for multi-VPC reachability.
Public VIF
Used to access AWS public endpoints like S3 without traversing the internet.
Key Takeaway

Use Direct Connect Gateway to scale a single connection across multiple VGWs and accounts while managing routes via BGP.

Scenario card
Enterprise example
A single Direct Connect with a Private VIF attached to a Direct Connect Gateway serves VGWs in multiple accounts for centralized connectivity.
Operational note
Ensure ASNs and BGP sessions are correctly configured so routes propagate from on-prem to each VGW through the Direct Connect Gateway.
