Module 2 › Chapter 2.2 › Simulated lab: configure and verify a Site-to-Site VPN
Step checklist
1. Create and attach VGW to your VPC.
2. Create CGW with on-prem public IP and ASN.
3. Create VPN with dynamic routing (BGP).
4. Download config and apply to router; configure IPsec and BGP peers.
5. Update VPC route table and verify tunnels are UP.
Expected outcome

Both tunnels report UP, BGP routes appear in route tables, and traffic flows between on-prem and VPC subnets.

Verification commands
Use these checks to validate each step.
# Verify VPN connection
aws ec2 describe-vpn-connections --vpn-connection-ids vpn-0fedcba9876543210

# Check route tables and route entries
aws ec2 describe-route-tables --filters "Name=route.target,Values=vgw-0a1b2c3d4e5f6g7h8"

# Confirm tunnel status and BGP peer info via the console or SDK outputs
