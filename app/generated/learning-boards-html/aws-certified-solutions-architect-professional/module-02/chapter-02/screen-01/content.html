Hybrid Cloud Connectivity: VPN and Direct Connect

Learn when to use encrypted internet tunnels, when to order dedicated private links, and how routing and redundancy differ between these approaches.

Why this matters
Hybrid connectivity controls performance, security, and cost for enterprise workloads moving across environments.
What you'll do
Evaluate VPN vs Direct Connect, configure a Site-to-Site VPN, and design Direct Connect with VIFs and gateway routing.
Visual preview
Concept map
Site-to-Site VPN
IPsec tunnels over the internet, two tunnels for redundancy, BGP or static routing.
Direct Connect
Dedicated private connection, VIFs, Direct Connect Gateway for multi-VPC access.
Client VPN
Managed client access for remote users, integrates with Active Directory or certificates.
Combined HA
Direct Connect primary with Site-to-Site VPN fallback for full redundancy.
