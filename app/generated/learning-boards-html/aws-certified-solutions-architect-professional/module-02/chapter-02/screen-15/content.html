Module 2 › Chapter 2.2 › Key Concepts — Quick reference
Customer Gateway
On-prem device that peers with AWS for Site-to-Site VPN.
Virtual Private Gateway
AWS gateway attached to a VPC that accepts VPN tunnels.
Virtual Interface (VIF)
Logical interface on Direct Connect: Private VIF for VPCs, Public VIF for public AWS endpoints.
Final note
Use these terms as a checklist while designing and operating hybrid connectivity: verify nodes, routes, and redundancy before trusting production traffic to a link.
