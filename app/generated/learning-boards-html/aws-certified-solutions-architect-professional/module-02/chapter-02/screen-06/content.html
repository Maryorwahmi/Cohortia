Module 2 › Chapter 2.2 › AWS Client VPN
What it is and when to use it

Client VPN grants remote users secure access to VPC resources and on-prem networks using a managed OpenVPN service. It supports directory and certificate authentication and provides authorization rules per subnet.

Concrete example
A remote engineer uses Client VPN to access a private build server in a VPC without exposing the server to the internet.
Design note
Plan subnet associations and route propagation so users can reach required subnets and resources.
Misconception
Client VPN is for user access, not for permanent site-to-site connectivity — don't replace CGW/VGW with Client VPN for datacenter links.
Operational checklist
Authentication
Integrate with Active Directory or certificate stores to control user access.
Authorization rules
Define which VPC CIDRs and subnets users can access and log connections for auditing.
Key Takeaway

Use Client VPN for user-level secure access; maintain separate Site-to-Site tunnels for persistent datacenter connectivity.
