Module 2 › Chapter 2.2 › What is hybrid cloud connectivity?
Definition and analogy

Hybrid cloud connectivity lets on-premises networks and cloud VPCs communicate securely and reliably. The analogy: Direct Connect is a leased private line, Site-to-Site VPN is secure parcels sent over public mail.

When to use which
Match Direct Connect to workloads needing predictable latency; use VPN for quicker, cost-sensitive setups.
Common mistake
Assuming VPN is always ok for production without checking bandwidth and latency requirements.
Key Takeaway

Start with workload needs: bandwidth, latency, and security determine whether VPN or Direct Connect is the right choice.

Illustrative cards
Office example
Real-time trading systems use leased lines; developer laptops use VPN to reach cloud resources.
Operational benefit
Direct Connect lowers egress costs for heavy data flows and provides more predictable performance.
Misconception
Dedicated links eliminate the need for security controls — you still must enforce IAM, security groups, and NACLs.
