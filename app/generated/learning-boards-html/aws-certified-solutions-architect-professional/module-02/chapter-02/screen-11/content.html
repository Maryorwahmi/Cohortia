Starter commands (example)
Use these aws ec2 commands as a template. Replace IDs and IPs with your environment values.
# 1. Create a Virtual Private Gateway (VGW)
aws ec2 create-vpn-gateway --type ipsec.1 --amazon-side-asn 64512

# Attach VGW to VPC
aws ec2 attach-vpn-gateway --vpn-gateway-id vgw-0a1b2c3d4e5f6g7h8 --vpc-id vpc-1234567890abcdef0

# 2. Create a Customer Gateway (CGW)
aws ec2 create-customer-gateway --type ipsec.1 --public-ip <ON_PREM_PUBLIC_IP> --bgp-asn 65000

# 3. Create a Site-to-Site VPN connection with BGP
aws ec2 create-vpn-connection \
  --type ipsec.1 \
  --customer-gateway-id cgw-0123456789abcdef0 \
  --vpn-gateway-id vgw-0a1b2c3d4e5f6g7h8 \
  --options '{"StaticRoutesOnly":false}'

# 4. Verify VPN connection and tunnel status
aws ec2 describe-vpn-connections --vpn-connection-ids vpn-0fedcba9876543210
Apply the downloaded config
Use the vendor configuration to program IPsec parameters, pre-shared keys, and BGP neighbors on your router.
Verification and checks
Route tables
Add routes for on-prem CIDRs to the VPC route table pointing to the VGW.
Tunnel status
Confirm both tunnels are UP; check configuration if either is down.
Firewall rules
Ensure NACLs and firewalls allow traffic between on-prem and VPC subnets; NACLs are stateless so allow both directions.
