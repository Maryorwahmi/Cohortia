Module 2 › Chapter 2.2 › Learning Objectives — Practical outcomes
Objective application
Each objective maps to a concrete operational step: plan bandwidth, order the right Direct Connect type, configure BGP peering, and test failover procedures.
Capacity planning
Choose Dedicated for 1/10/100 Gbps or Hosted for partner-provided smaller increments.
Routing plan
Prefer BGP for dynamic route exchange; use static only for simple, stable environments.
Verification and safety
Test tunnel failover, rotate pre-shared keys regularly, and verify NACLs in addition to security groups.
Failover test
Simulate a primary link outage and confirm traffic moves to the backup path and routes update correctly.
Security checklist
Ensure encryption settings, rotate keys, and limit access through VIF and gateway controls.
