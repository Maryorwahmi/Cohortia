Module 2 › Chapter 2.3 › Route 53 Resolver
Inbound Endpoint
Create ENIs in your VPC with IPs that on-prem DNS forwards to so those servers can resolve private AWS names.
Steps
  1. Create Inbound Endpoint in Route 53 Resolver and note ENI IPs.
  2. Configure on-prem DNS to conditionally forward AWS domain queries to those IPs.
  3. Test resolution from on-prem network.
Outbound Endpoint
Allows VPC resources to forward queries to on-prem DNS servers via forwarding rules and the outbound ENI IPs.
Steps
  1. Create Outbound Endpoint and forwarding rule for on-prem domains.
  2. Specify on-prem DNS server IPs as targets in the forwarding rule.
  3. Validate by resolving on-prem hostnames from an EC2 instance.
Concrete example
Create an Outbound Endpoint and a rule for corp.local that forwards queries to 10.10.10.5 and 10.10.10.6. From EC2, run a DNS query to confirm resolution.
Common mistake
Forgetting to update security groups or network ACLs for the ENI IPs so on-prem and VPC traffic can reach the endpoints.
Key Takeaway

Resolver endpoints simplify hybrid DNS by making forwarding explicit and manageable; verify network rules and forwarding configurations during setup.
