Module 2 › Chapter 2.3 › DNSSEC & Security
What DNSSEC does
Cryptographically signs DNS zone data so validating resolvers can detect tampering or spoofed responses.
Operational steps
  • Enable DNSSEC in Route 53 for the public hosted zone.
  • Retrieve the Delegation Signer (DS) record from Route 53.
  • Publish the DS record at your domain registrar.
Remember to confirm registrar support and plan key management and rollovers.
Example
Enable DNSSEC for example.com, export the DS record and add it to your registrar configuration so resolvers see a trust chain to Route 53's signature.
Common mistake
Assuming DNSSEC removes the need for strict IAM and registrar protection. If an attacker can change registrar records or Route 53 access, DNSSEC alone is insufficient.
Key Takeaway

DNSSEC strengthens trust for public DNS responses, but enabling it requires registrar coordination and disciplined key management practices.
