Module 2 › Chapter 2.3 › Private Hosted Zones
What is a private hosted zone?
A container for DNS records resolvable only within associated VPCs, allowing private names for internal resources.
Design checklist
  • Choose a private domain namespace like internal.example.com
  • Associate the zone with required VPCs
  • Grant IAM access controls for record management
Example
Create private hosted zone internal.example.com and add api.internal.example.com pointing to an internal load balancer IP, then associate with the app VPC.
Hybrid access
To let on-premises hosts resolve private names, configure a Route 53 Resolver Inbound Endpoint and instruct on-premises DNS to conditionally forward the private domain queries to it.
Common mistake
Assuming private zones automatically propagate across accounts or regions; you must explicitly associate VPCs and design cross-account access with care.
Key Takeaway

Private hosted zones keep internal names scoped to VPCs; use Resolver endpoints for controlled hybrid resolution rather than ad-hoc DNS servers in VPCs.
