Module 2 › Chapter 2.4 › AWS WAF fundamentals
Definition

What WAF does

WAF inspects HTTP/S requests and applies rules that match IPs, headers, body contents, or URI strings to detect common web exploits.

Actions
Allow, Block, or Count. Use count to tune rules before blocking in production.
Managed Rule Groups
Curated protections for common classes like SQL injection or XSS so you don't need to write every rule.
Concrete Example
Attach the "AWS Managed Rules for SQL database" rule group to a Web ACL for an ALB. When a malicious request contains SQL injection patterns the rule matches and the action blocks the request, typically returning a 403 Forbidden response.
Misconception
WAF is not a substitute for secure coding and validation; it reduces exposure but does not fix application bugs.
Key Takeaway

Use WAF for Layer 7 protections, prefer managed rule groups when you need fast coverage, and monitor before blocking.
