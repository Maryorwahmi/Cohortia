Module 2 › Chapter 2.4 › Key Concepts
AWS WAF
Inspects HTTP/S requests to block application-layer exploits.
AWS Shield
Standard is automatic; Advanced adds DRT support and cost protection.
Network Firewall
Centralized stateless and stateful filtering at the VPC boundary.
Summary Takeaway
Use WAF, Shield, and Network Firewall together, and enable Flow Logs to validate behavior and investigate incidents.
