Module 2 › Chapter 2.4 › Layered Security
Process Flow

Design steps

  1. Instance layer: Security Groups and NACLs for port and IP controls.
  2. Application layer: WAF to inspect HTTP content and block SQLi/XSS.
  3. Network boundary: Network Firewall for stateless/stateful rules and IPS-like checks.
  4. DDoS mitigation: Shield for volumetric and protocol attacks.
  5. Telemetry: VPC Flow Logs for auditing and investigations.
Key Takeaway

Layering reduces single points of failure and gives you the telemetry you need to validate protections.

Example
Scenario: public web application behind an ALB. The ALB receives HTTP requests, WAF inspects and blocks SQL injection patterns, Shield reduces the impact of SYN and UDP floods, and Network Firewall enforces company-wide egress policies for inter-VPC traffic.
Why WAF
Stops application exploits that target input parsing and session handling.
Why Network Firewall
Provides deep inspection and centralized policy enforcement across VPCs.
Common mistake
Blocking without testing: aggressive rules can block DNS or health checks. Use count or monitoring modes before blocking in production.
