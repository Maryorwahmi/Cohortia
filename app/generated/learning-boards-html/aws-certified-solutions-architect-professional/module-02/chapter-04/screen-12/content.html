Module 2 › Chapter 2.4 › Stateless vs Stateful
Stateless
Fast packet filtering. Each packet is evaluated independently, ideal for IP and port blocks and high-throughput needs.
Best practice
Use stateless rules for broad network filters and to reduce load on stateful inspection engines.
Stateful
Tracks connections and allows decisions that depend on session context. Useful for application protocol checks and allowing return traffic for established connections.
Trade-offs
  • Stateful inspection uses more resources and requires symmetric routing.
  • Asymmetric routing will cause stateful checks to fail or drop legitimate traffic.
  • Balance performance and security needs by combining both rule types.
Key Takeaway

Choose stateless for high-speed packet drops and stateful for connection-aware filtering; ensure routing supports your choice.
