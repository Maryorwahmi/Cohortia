Module 2 › Chapter 2.4 › VPC Flow Logs
What they record
  • Source and destination IP addresses and ports.
  • Protocol, bytes, packets, start and end timestamps.
  • Action: ACCEPT or REJECT by security controls.
Publish to CloudWatch Logs for near real-time alerting, or to S3 for archival and forensic analysis. Integrate with SIEM or Security Hub for correlation with other signals.
Example Investigation
You notice outbound traffic to an unknown IP. Flow Logs show the internal source IP and port, the destination IP and port, protocol TCP, the total bytes, and that the flow was accepted. With this you can identify the instance and the security rule that allowed the flow.
Note
Flow Logs do not contain payloads; they provide metadata for fast triage and pattern detection.
Key Takeaway

Use Flow Logs as the primary network telemetry source for investigations and integrate with SIEM for correlation.
