Module 2 › Chapter 2.4 › CLI: Create Web ACL
Starter Commands
# 1. Create a Web ACL
aws wafv2 create-web-acl \
    --name MyWebAppACL \
    --scope REGIONAL \
    --default-action Allow={} \
    --visibility-config CloudWatchMetricsEnabled=true,MetricName=MyWebAppACL,SampledRequestsEnabled=true \
    --description "Web ACL for my web application"

# 2. Add an AWS Managed Rule Group (SQLi)
aws wafv2 update-web-acl \
    --name MyWebAppACL \
    --scope REGIONAL \
    --id  \
    --lock-token  \
    --default-action Allow={} \
    --visibility-config CloudWatchMetricsEnabled=true,MetricName=MyWebAppACL,SampledRequestsEnabled=true \
    --rules '[
        {
            "Name": "AWSManagedRulesSQLiRuleSet",
            "Priority": 1,
            "Statement": {
                "ManagedRuleGroupStatement": {
                    "VendorName": "AWS",
                    "Name": "AWSManagedRulesSQLiRuleSet"
                }
            },
            "Action": {"Block": {}},
            "VisibilityConfig": {"SampledRequestsEnabled": true,"CloudWatchMetricsEnabled": true,"MetricName": "AWSManagedRulesSQLiRuleSet"}
        }
    ]'

# 3. Associate the Web ACL with your ALB
aws wafv2 associate-web-acl \
    --web-acl-arn  \
    --resource-arn

Replace placeholders with your values, run in a staging environment when possible, and check CloudWatch metrics and sampled requests to tune rules.
Practical Notes
  • Use REGIONAL scope for ALBs and GLOBAL for CloudFront.
  • Monitor sampled requests before changing actions to block.
  • Ensure IAM permissions for WAF operations and resource associations.
