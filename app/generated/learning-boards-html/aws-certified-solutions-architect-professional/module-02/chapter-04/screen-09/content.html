Architecture

Security VPC + Transit Gateway

Centralize enforcement by routing traffic through a security VPC that hosts Network Firewall. This enables consistent rules for ingress, egress, and inter-VPC traffic.

Benefits: simplified policy updates, centralized logging, and easier compliance audits.
Pitfall: asymmetric routing breaks stateful inspection; ensure both directions traverse the firewall path.
Example Checklist
  • Configure Transit Gateway attachments for each VPC.
  • Route VPC egress through the security VPC subnets with firewall endpoints.
  • Validate return paths and NAT behavior for asymmetric traffic.
  • Enable Flow Logs for verification and auditing.
Key Takeaway

Centralization simplifies enforcement but requires careful routing so stateful inspection works correctly.
