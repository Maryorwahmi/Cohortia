Module 2 › Chapter 2.4 › Network Firewall
Definition

What it enforces

Network Firewall filters at the network and transport layers with stateless packet filters and stateful rules that track connections for deeper protocol-aware inspection.
Stateless rules
Fast packet filters that do not track connection state; useful for IP and port blocks.
Stateful rules
Track sessions and inspect protocols like HTTP or TLS for more precise control.
Concrete Use
Centralize inspection by routing traffic through a security VPC. Use stateless rules at high volumes for quick filtering and stateful rules where connection context matters.
Misconception
Network Firewall does not replace WAF; it complements WAF by handling network-level threats and IPS-like functions.
Key Takeaway

Use Network Firewall for centralized, scalable network filtering and pair it with WAF for application-layer protection.
