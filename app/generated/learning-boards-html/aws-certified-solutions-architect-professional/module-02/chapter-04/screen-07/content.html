Module 2 › Chapter 2.4 › AWS Shield Comparison
Shield Standard
Always-on detection and inline mitigation for common network and transport layer attacks. No additional configuration or cost is required and it integrates with CloudFront, Route 53, and load balancers.
Use when
You need baseline protection for standard workloads and public endpoints.
Shield Advanced
Provides enhanced detection, near real-time visibility, access to the AWS DDoS Response Team, and financial protections for scaling costs. It integrates with WAF for coordinated mitigation during major attacks.
Use when
You operate business-critical services where availability and rapid response are top priorities.
Decision guide
Cost
Standard: none. Advanced: paid service with additional protections.
Response
Advanced includes DRT engagement and custom mitigation support.
Visibility
Advanced gives near real-time attack metrics and integration with WAF for targeted rules.
