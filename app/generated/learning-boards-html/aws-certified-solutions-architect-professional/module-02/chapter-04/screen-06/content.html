Module 2 › Chapter 2.4 › WAF Rule Tuning
Rule Types
  • IP match conditions and IP sets for known bad or trusted addresses.
  • Header and user-agent conditions to allow or block based on client identity.
  • URI and body inspection for SQL injection, XSS, and other payload patterns.
  • Managed rule groups for fast coverage of common threats.
Tuning workflow
  1. Enable managed rule in count mode.
  2. Review sampled requests and CloudWatch metrics.
  3. Add allow conditions for false positives or adjust rule priority.
  4. Switch to block when confident.
Scenario
A managed SQLi rule flags many requests from a crawler. You examine sampled requests, note the crawler's user-agent and IP range, and then create an allow rule for that IP set before switching the SQLi rule to block mode.
Common mistake
Changing rule action to block immediately without monitoring causes service interruptions for legitimate clients.
Key Takeaway

Observe impacts in count mode and tune exceptions before enforcing blocks.
