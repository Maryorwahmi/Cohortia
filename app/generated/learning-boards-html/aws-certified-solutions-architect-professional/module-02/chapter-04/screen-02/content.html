Learning Objectives

Progress from understanding to applying layered network protections on AWS.

Learn → Understand → Apply → Master
01
Implement AWS WAF rules

Create Web ACLs, apply managed rule groups, and protect an ALB or API Gateway. This stops common application exploits and reduces data-risk exposure.

VERIFIED COMPETENCY MILESTONE
02
Understand Shield tiers

Recognize when Shield Standard suffices and when Shield Advanced is needed for high-value services requiring DDoS response and cost protections.

VERIFIED COMPETENCY MILESTONE
03
Configure Network Firewall

Design stateless and stateful rule sets, centralize enforcement in a security VPC, and ensure consistent policies across VPCs.

VERIFIED COMPETENCY MILESTONE
04
Use VPC Flow Logs

Capture and analyze flow records to investigate unexpected traffic, determine accepted or rejected flows, and feed SIEM for correlation.

VERIFIED COMPETENCY MILESTONE
