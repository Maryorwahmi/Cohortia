Module 2 › Chapter 2.1 › Troubleshooting
Triage Sequence
  1. Confirm TGW attachment and route table association.
  2. Verify TGW propagation entries for expected CIDRs.
  3. Check VPC route tables point to TGW for inter-VPC CIDRs.
  4. Inspect NACL inbound/outbound pairs for blocked ports.
  5. Review Security Group rules for instance-level permissions.
Operational safeguards
  • Make changes in staging; validate DNS and NTP before production.
  • Keep runbooks with rollback steps and test probes for critical paths.
  • Use visualization tools to detect unexpected propagation or associations.
Warning
Changing NACLs without matching outbound rules can silently break application responses. Always pair rules and test.
Key Takeaway

Validate changes methodically: attachments, propagation, VPC routes, NACLs, then Security Groups. Test DNS and NTP early.
