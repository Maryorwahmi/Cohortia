Module 2 › Chapter 2.1 › TGW Configuration Steps
Step-by-step
  1. Create Transit Gateway and attachments for each VPC.
  2. Create TGW route tables for separate traffic domains.
  3. Associate attachments and configure propagations.
  4. Update each VPC route table to send inter-VPC traffic to the TGW.
  5. Test connectivity and validate DNS/NTP.
Example configuration
SharedServices-TGW-RT: propagate shared-services attachment; add static TGW routes for prod and dev CIDRs. Isolation-TGW-RT: associate prod and dev attachments and propagate the shared-services attachment selectively so prod and dev cannot reach one another.
Check list before go-live
  • Correct associations and propagations in TGW route tables.
  • VPC route tables updated to use TGW for target CIDRs.
  • DNS and NTP still reachable after route changes.
Key Takeaway

Follow the sequence exactly and validate each step to avoid incomplete or unsafe connectivity changes.
