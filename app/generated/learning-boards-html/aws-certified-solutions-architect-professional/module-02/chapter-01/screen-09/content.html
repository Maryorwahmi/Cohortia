Module 2 › Chapter 2.1 › Network ACLs
Behavior

Stateless subnet-level firewall. Rules are evaluated in order; both inbound and outbound must be explicitly allowed for two-way traffic.

Example
Allow inbound TCP 80/443 from internet; allow outbound ephemeral ports 1024–65535 so the web server can send responses.
Best practices
  • Use NACLs to implement deny-by-default subnet boundaries for compliance workloads.
  • Order rules carefully and include necessary ephemeral outbound allowances.
  • Test changes in staging to avoid breaking critical services.
Pitfall
Forgetting the outbound return rule results in one-way connectivity failures. Always pair inbound and outbound rules for expected flows.
Key Takeaway

Use NACLs for broad subnet filters and compliance controls, and ensure paired inbound/outbound rules due to their stateless nature.
