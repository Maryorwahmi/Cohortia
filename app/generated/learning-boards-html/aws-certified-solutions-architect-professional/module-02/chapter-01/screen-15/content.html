Module 2 › Chapter 2.1 › Key Concepts
Multi-VPC Architecture
Isolate by role and plan CIDR space to support growth and on-prem connections.
AWS Transit Gateway
Central hub for attachments; use route tables, associations, and propagations to enforce traffic domains.
Security Groups & NACLs
Security Groups are stateful instance firewalls; NACLs are stateless subnet filters best for coarse boundaries.
Summary Takeaway

Plan VPC roles, prefer Transit Gateway for scale, and layer Security Groups with NACLs for defense-in-depth and compliance.
