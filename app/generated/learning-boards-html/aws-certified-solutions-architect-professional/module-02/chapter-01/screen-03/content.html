Module 2 › Chapter 2.1 › Applied Objectives
01 — Design
Define VPC roles, reserve CIDR spaces, and document growth assumptions. This prevents address collisions when VPCs are later connected.
02 — Transit Gateway
Create TGW attachments and separate route tables to allow shared services while isolating pairs of VPCs that must not communicate directly.
03 — Firewall Layers
Use Security Groups for instance-level rules and NACLs for subnet boundary policy, with deny-by-default behavior where required.
04 — Validation
Run tests in staging: check route propagation, DNS, NTP, and that only intended paths are reachable. Keep an operational checklist for changes.
Mnemonic
Plan, Attach, Filter, Validate — a repeatable workflow when adding VPCs or services to the network.
Key Takeaway

Translate objectives into step-by-step actions so designs remain enforceable and testable at scale.
