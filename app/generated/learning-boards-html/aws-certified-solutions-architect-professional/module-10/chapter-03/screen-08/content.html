Module 10 › Chapter 10.3 › Indexing (RDS)
What an index does
Provides fast lookup structures for columns used in WHERE, JOIN, and ORDER BY clauses.
When to add an index
  • Frequent use in WHERE clauses
  • Columns used in JOIN conditions
  • Columns used in ORDER BY for pagination or sorting
Example
A products table with frequent queries by category and popularity benefits from a composite index on (category, popularity) to serve sorted listing queries without extra sorting cost.
Write implications
Each index increases write cost; test write throughput impact and storage growth.
Misconception
Adding many indexes always improves overall performance — false. It may improve reads but harm write latency and resource usage.
Key Takeaway

Index based on measured patterns; prefer selective, composite indexes that match query shapes.
