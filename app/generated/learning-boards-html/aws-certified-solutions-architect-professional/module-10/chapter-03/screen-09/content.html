Module 10 › Chapter 10.3 › DynamoDB Indexes
Primary key recap
Partition key distributes items across partitions; add a sort key for range queries per partition.
Local Secondary Index (LSI)
Shares partition key, different sort key, strong consistency in the same partition. Use when you need alternate sort orders but only within a partition.
Global Secondary Index (GSI)
Different partition and optional sort key, spans partitions, has separate throughput and is eventually consistent by default. Use for cross-partition queries.
Concrete example
Table primary key: orderId. Need queries by userId and orderDate for a user's history. Create a GSI with userId as partition key and orderDate as sort key, projecting required attributes for query performance.
Key Takeaway

Design indexes to match access patterns. GSIs let you query across users; LSIs only reorganize data within the same partition key.
