From query to trace
Use Logs Insights to surface request IDs, then locate those IDs in X-Ray to inspect the timed segments and identify where most latency occurs.
Example flow
  1. Run a Logs Insights query to list slow requests and capture requestId values.
  2. Search X-Ray traces by that requestId or use the trace's annotations to find the same identifier.
  3. Open the trace and inspect segment timing to see which service hop contributed most latency.
  4. Document the finding, then apply a minimal fix and re-check the same requestId for verification.
Practical tips
  • Always inject a correlation ID at the edge and persist it in logs and traces.
  • If traces are sampled, ensure sampling rates are high enough in production incidents to capture examples.
  • Use Logs Insights first to reduce the number of candidate traces you must inspect in X-Ray.
Common misconception

Expecting logs alone to show timing; traces reveal per-hop latency and are necessary for accurate bottleneck identification.
