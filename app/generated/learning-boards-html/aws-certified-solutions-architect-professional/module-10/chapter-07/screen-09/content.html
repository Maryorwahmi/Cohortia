Module 10 › Chapter 10.7 › EventBridge & AWS Config
Event-driven diagnostics
Create rules that trigger Lambdas on alarms to capture logs, traces, and flow logs automatically. This reduces time-to-evidence and ensures consistent data collection.
Example rule
Rule: when CloudWatch alarm state = ALARM → Invoke diagnostic Lambda that runs Logs Insights queries and stores results.
AWS Config usage
Use Config to see the exact configuration of resources and their change history so you can tie incidents to changes and roll back when necessary.
Key Takeaway

Combine EventBridge for automation with AWS Config for historical context to reduce manual investigation steps and accelerate root cause discovery.
