Architecture

Balancing performance, cost, and complexity

Choose fixes that are targeted, measurable, and proportional to the criticality of each endpoint.

Low complexity
Lazy init, code refactor, or caching often yield big wins with little ongoing cost.
Medium complexity
Memory tuning and API Gateway caching need measurement and occasional adjustments.
Higher complexity
Provisioned Concurrency and SnapStart require continuous cost and test validation.
Key Takeaway

Start with low-complexity changes and measure. Use cost-per-latency improvement to decide on heavier investments.
