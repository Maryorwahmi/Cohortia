Analysis

Service map and trace inspection

Use the service map to identify slow nodes and drill into traces for segment timing and subsegments.

Service map
Visual overview of how services interact and which connections carry latency.
Traces & subsegments
Detailed timing inside Lambda and for external calls; add custom subsegments around costly operations.
Concrete check
If a trace shows a long initialization segment, consider lazy init or provisioned concurrency. If external calls dominate, optimize or cache results.
Key Takeaway

Use X-Ray to determine whether the bottleneck is init, code logic, or external calls and prioritize the most impactful fix.
