Process

Experimenting with memory settings

Change one memory value at a time, run repeated invocations, and compare Duration percentiles and cost per request.

Step 1 — Baseline
Record current Duration and cold start traces with X-Ray before any change.
Step 2 — Increase memory
Adjust memory to next level, invoke repeatedly, and compare.
Step 3 — Analyze cost
Compute cost per request after the change to see if savings pay off.
Concrete example
Example: compression init
A function that decompresses a large binary on init might see cold start reduce significantly when memory is raised because CPU increases along with memory.
Misconception
More memory always reduces cost — false. Cost increases per ms but duration may fall; calculate net effect per request.
Key Takeaway

Test memory in steps and measure both duration and cost to find the optimal allocation.
