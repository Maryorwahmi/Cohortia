Module 10 › Chapter 10.4 › Lambda Cold Start
Definition

What a cold start is

Cold starts happen when Lambda creates a fresh execution environment and runs module-level initialization. This adds latency prior to handler execution.

Example
A function that initializes a large library at import will show a longer Duration on first invocation after idle.
Common misconception
Cold starts only affect rarely used functions — false. Deployments, scaling, and account activity can trigger cold starts for any function.
Key Takeaway

Avoid heavy work at module import, or use provisioned concurrency for critical, latency-sensitive endpoints.

Detecting cold starts
Use Logs and Traces
  • Look for first-invocation messages and longer Duration in CloudWatch.
  • Enable X-Ray to separate initialization segments from handler execution.
  • Record controlled invocations to compare before/after tuning.
Action checklist
  • Move nonessential imports into the handler or lazily initialize resources.
  • Measure Duration percentiles after any change.
  • Consider Provisioned Concurrency for critical paths.
