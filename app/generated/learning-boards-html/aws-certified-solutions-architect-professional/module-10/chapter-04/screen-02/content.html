Learning Objectives

Skills you'll practice and validate with traces and metrics.

Bloom: Learn → Understand → Apply → Master
01
Mitigate Cold Starts

Identify causes of cold starts and apply memory tweaks, provisioned concurrency, or SnapStart when appropriate.

VERIFIED COMPETENCY MILESTONE
02
Tune Concurrency

Configure reserved, unreserved, and maximum concurrency to prevent throttling and protect downstream services.

VERIFIED COMPETENCY MILESTONE
03
Optimize API Gateway

Use caching, TTL, and throttling strategically; minimize heavy transformations in the gateway when it increases latency.

VERIFIED COMPETENCY MILESTONE
04
Trace with X-Ray

Instrument Lambdas and API Gateway to get a service map and subsegments that reveal which operations add latency.

VERIFIED COMPETENCY MILESTONE
