Module 11 › Chapter 10.9 › Graceful degradation vs Load shedding
Comparison
Graceful Degradation
Reduce optional features, use cached or default responses, and keep core flows working.
Load Shedding
Intentionally drop lower-priority requests to preserve capacity for critical operations.
Example scenario
During a traffic surge, disable recommendation calls and serve cached lists so checkout continues to function. If surge persists and core latency rises, shed background telemetry to preserve checkout throughput.
Misconception

Shedding or degrading is not always visible to the user if architected well; prioritize preserving business-critical flows.
