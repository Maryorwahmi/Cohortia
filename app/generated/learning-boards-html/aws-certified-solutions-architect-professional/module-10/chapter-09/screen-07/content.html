Module 11 › Chapter 10.9 › Running a safe FIS experiment
Step-by-step
  1. Confirm ASG health checks and desired capacity (min=1, desired=1, max=1 example).
  2. Create an IAM role for FIS with AWSFISServiceRolePolicy and a focused ec2:TerminateInstances inline policy.
  3. In FIS, add a target for the instance and an action aws:ec2:terminate-instances, count=1.
  4. Add stop conditions based on CloudWatch alarms and create the template.
  5. Start the experiment, observe termination, and verify ASG replacement and health recovery.
Cleanup: delete the FIS template and role and tear down the ASG to avoid lingering charges.
Monitoring & safety
  • Add CloudWatch alarms for increased error rates and high latency to stop the experiment.
  • Ensure logging and traces are enabled to debug the replacement process and any failures.
  • Limit blast radius: target a single instance or a small subset first.
Common oversight

Not providing narrow IAM permissions increases risk; prefer least privilege for test roles.
