Module 11 › Chapter 10.9 › Practical Outcomes
Demonstrable Skills
  • Run distributed load tests and interpret CPU, memory, latency, and error rate trends.
  • Create safe chaos experiments and observe recovery behavior for Auto Scaling Groups and services.
  • Implement circuit breakers and bulkheads to reduce blast radius of failures.
  • Design backpressure and queue-based buffering so upstream producers can continue operating.
Each skill includes a verification milestone: run a test, collect metrics, and explain the mitigation you implemented.
Checklist
  1. Define steady-state and test scenarios.
  2. Deploy a distributed load generator and run a sustained peak test.
  3. Create a small FIS experiment and verify safety controls.
  4. Implement and validate at least one resilience pattern in staging.
