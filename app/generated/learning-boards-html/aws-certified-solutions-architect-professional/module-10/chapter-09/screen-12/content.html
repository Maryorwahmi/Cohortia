Module 11 › Chapter 10.9 › Active-active multi-region deployments
Architecture

Distribute traffic, synchronize data, test failover

Active-active routes traffic to multiple regions to maximize availability and reduce latency. Use network routing solutions that detect healthy endpoints and fail over quickly.

Routing: Global Accelerator provides fast failover with static IPs and AWS backbone routing.
Data: choose replication strategy that fits consistency and latency constraints, test conflict resolution.
Example
Deploy API backends in two regions and use Global Accelerator endpoint groups to route users to the nearest healthy region while monitoring replication lag for stateful data stores.
Key Takeaway

Active-active increases availability but demands explicit design for data synchronization and controlled failover testing.
