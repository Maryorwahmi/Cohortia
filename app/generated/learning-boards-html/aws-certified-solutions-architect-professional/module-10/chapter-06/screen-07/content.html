Process Flow
Transit Gateway Attachment Steps
A reliable sequence to avoid routing gaps.
1. Create TGW
Provision the Transit Gateway resource in the region.
2. Create Attachments
Attach VPCs or VPNs, choosing private subnets for route propagation.
3. Associate & Propagate
Associate attachments to TGW route tables and enable propagation for learned routes.
4. Update VPC Routes
Add routes in VPC route tables that target the Transit Gateway for remote CIDRs.
Validation
Use ping and iperf3 between instances in attached VPCs to confirm connectivity and throughput.
Throughput Note
Attachments have limits—design for expected traffic and distribute load if needed.
Common Mistake
Forgetting propagation leads to missing routes and apparent connectivity failures.
