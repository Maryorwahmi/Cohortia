iperf3 Example
Run these commands on two EC2 instances to measure TCP throughput.
# On Server 1 (receiver):
iperf3 -s

# On Server 2 (sender):
iperf3 -c <Server1_Private_IP> -P 8   # -P for parallel streams
Interpretation
Look for aggregate throughput, retransmits, and per-stream fairness. Compare values before and after changes like ENA or MTU tuning.
Test Checklist
  • Ensure security groups allow iperf3 traffic between private IPs.
  • Enable ENA on instances when supported.
  • If using Jumbo Frames, confirm MTU 9001 across all hops.
  • Run iperf3 with parallel streams to saturate the link.
Key Takeaway

Use iperf3 to get real throughput numbers; correlate with VPC Flow Logs and CloudWatch to diagnose limits.
