Definition
Security Groups
Stateful, instance-level filtering that is efficient for allowed return traffic.
Keep rules minimal and well-scoped to reduce complexity and to improve manageability and performance.
Definition
Network ACLs (NACLs)
Stateless and evaluated per packet; many rules can add processing overhead.
Common Mistake
Applying overly numerous or redundant NACL rules that create unnecessary per-packet evaluation.
Key Takeaway

Use Security Groups for precise instance-level control and keep NACLs simple to avoid adding packet-processing delays; validate changes with Flow Logs and traffic tests.
