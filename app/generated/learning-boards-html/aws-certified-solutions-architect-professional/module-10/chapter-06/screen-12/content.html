Definition
VPC Flow Logs
Capture IP traffic metadata for analysis in CloudWatch or S3.
Use Flow Logs to find denied packets, unexpected source IPs, or traffic volume patterns.
Export to CloudWatch Logs Insights to run queries and surface anomalies quickly.
Instance Tools
Ping, traceroute, netstat, and iperf3 provide endpoint-level measurements.
Ping and traceroute map latency and path hops; netstat checks socket states.
iperf3 measures actual TCP throughput and helps identify bandwidth ceilings.
Troubleshooting Workflow
  1. Check CloudWatch Network metrics for spikes or drops.
  2. Query VPC Flow Logs for denied traffic or unexpected flow patterns.
  3. Run traceroute and ping to identify hops and latency.
  4. Run iperf3 to measure throughput and validate improvements after configuration changes.
