Hands-on Activity
Transit Gateway Lab
Create VPC-A, VPC-B, attach to TGW, and test with iperf3.
Starter Steps
  1. Create VPC-A and VPC-B with private subnets.
  2. Launch one instance in each private subnet and install iperf3.
  3. Create Transit Gateway and attachments for each VPC.
  4. Associate and propagate attachments in TGW route table, update VPC route tables.
Testing & Validation
Start iperf3 server on one instance and run a client from the other with parallel streams to measure throughput. Use VPC Flow Logs to confirm no denied packets.
Troubleshooting Hints
  • Check Transit Gateway attachment status and route propagation.
  • Validate security groups and NACLs allow traffic between CIDRs.
  • Confirm ENA is enabled if testing high packet rates and check MTU for Jumbo Frames.
Key Takeaway

A controlled lab proves topology and configuration work as intended; use iperf3 and Flow Logs to iterate until throughput and latency meet requirements.
