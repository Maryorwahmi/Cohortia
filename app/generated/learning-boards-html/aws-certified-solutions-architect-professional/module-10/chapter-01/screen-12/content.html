Designing dashboards
Choose widget types and layout to tell a clear operational story.
Widget guidance
  • Line charts for trends and percentiles
  • Number widgets for KPIs like error rate
  • Logs Insights panels for drill-down queries
Layout patterns
  • Top row: critical KPIs and alarm states
  • Middle: service-level graphs grouped by application
  • Bottom: troubleshooting widgets and Logs Insights
Pro tip
Create separate dashboards for operations, business stakeholders, and incident response to keep views focused.
