Definition
CloudWatch Logs Insights
An interactive query language for searching and aggregating logs.
Query example
fields @timestamp, @message
| parse @message "latency: *ms" as latency
| filter latency > 500 and @message like /GET \/api\/v1\/users/
| sort by @timestamp desc
| limit 20
This query finds recent high-latency GET requests to the users endpoint and returns the latest 20 matches.
Best practices
  • Structure logs as JSON to simplify parsing
  • Scope queries to relevant log groups and time ranges
  • Extract important fields like requestId and latency at emission
Check your understanding
If latency is present in multiple formats, ensure your parse covers variants or normalize at log emission.
