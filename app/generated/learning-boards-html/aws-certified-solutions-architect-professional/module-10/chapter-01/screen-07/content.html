Metric Math: deriving meaningful signals
Create expressions to compute error rates, combined latency, or other derived metrics.
Steps
  1. Identify base metrics and their statistics (Average, Sum).
  2. Define a Metric Math expression such as m1 / m2 or m1 + m2.
  3. Visualize the expression and create an alarm targeting it directly.
Example: m1 = AuthService Duration (avg), m2 = PaymentService Duration (avg), expression = m1 + m2.
Example expression
// visualize combined average latency
m1 = Metric('AuthService','Duration',stat='Average')
m2 = Metric('PaymentService','Duration',stat='Average')
expression = m1 + m2
Create an alarm on the expression when the result stays above 1000 ms for 5 minutes. This approach directly maps to the operational requirement.
Misconception
Metric Math is only cosmetic. Actually you can alarm on expressions, which is the recommended path for combined signals.
