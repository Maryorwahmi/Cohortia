Publishing custom metrics
Use the CLI or SDK to send application-specific telemetry.
CLI example
aws cloudwatch put-metric-data \
  --metric-name APILatency \
  --namespace "MyApplication/API" \
  --value 150 \
  --dimensions Service=UserService,Endpoint=/users/{id} \
  --unit Milliseconds
This command publishes a single datapoint. Repeat or batch from the application depending on your SDK and design.
In-code pattern (Python)
# inside request handler
start = time.time()
# handle request
duration = (time.time() - start) * 1000
cloudwatch.put_metric_data(
  Namespace='MyApplication/Orders',
  MetricData=[{
    'MetricName': 'OrderProcessingTime',
    'Dimensions':[{'Name':'ServiceName','Value':'OrderProcessorService'}],
    'Value': duration,
    'Unit':'Milliseconds'
  }]
)
Verify by invoking the function multiple times and checking CloudWatch for the namespace and dimensions you selected.
Design note
Batch metrics when possible, avoid per-request dimensional explosion, and choose aggregation periods that match your alerting cadence.
