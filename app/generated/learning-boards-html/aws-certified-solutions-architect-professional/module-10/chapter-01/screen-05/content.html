Definition
CloudWatch telemetry model
Metrics, logs, and events serve distinct troubleshooting roles.
Namespaces
Group metrics (for example, MyApplication/Orders) so related metrics don't collide.
Dimensions
Attach key-value pairs like ServiceName and Endpoint to filter and compare metrics.
Cardinality caution
Avoid high-cardinality dimensions such as user IDs unless necessary for a targeted analysis.
Examples
Built-in metric
Lambda Duration provides average or p99 durations out of the box.
Custom metric
OrderProcessingTime in namespace MyApplication/Orders with dimension ServiceName=OrderProcessorService.
Why this matters

Clear telemetry boundaries make dashboards and alarms reliable and easier to interpret during incidents.
