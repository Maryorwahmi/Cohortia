Architecture
Aggregating logs for analysis
Stream logs from source accounts to a central store for consistent analysis.
Pattern
  • Use Kinesis Data Firehose to stream logs
  • Deliver to S3 for archive or to CloudWatch Logs in the monitoring account
  • Include account and region metadata in each record
Best practices
  • Log structured JSON to ease parsing and querying
  • Tier retention by environment to manage cost
  • Parse common fields at ingestion where possible
Example
Stream application logs to S3 and query them via Logs Insights in the monitoring account to find high-latency requests across multiple services.
