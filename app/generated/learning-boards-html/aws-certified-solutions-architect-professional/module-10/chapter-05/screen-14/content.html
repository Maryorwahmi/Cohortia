CloudFront
CDN caching at edge locations for low latency and high transfer speeds.
Cache Key & TTL
Include only request parts that change the response; use versioned URLs to avoid invalidation.
Lambda@Edge
Run lightweight request/response logic at the edge to normalize or secure traffic.
Final summary
Use CloudFront for caching and edge-level control, Global Accelerator for optimized network paths and static IPs, and secure distributions with OAC, signed URLs, and WAF.
