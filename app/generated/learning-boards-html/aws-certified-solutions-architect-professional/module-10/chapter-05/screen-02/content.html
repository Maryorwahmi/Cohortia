Bloom: Learn → Understand → Apply → Master
01
Design CloudFront distributions
Configure origins, path patterns, viewer protocol policy, and cache behaviors to deliver content securely and quickly. This matters because misconfigured behaviors hurt cache efficiency and security.
VERIFIED COMPETENCY MILESTONE
02
Implement caching strategies
Choose cache keys, TTLs, and versioning to maximize cache hit ratio and minimize origin load. A good cache strategy reduces cost and latency.
VERIFIED COMPETENCY MILESTONE
03
Use Global Accelerator
Route global users over the AWS backbone, use static IPs, and improve availability for dynamic or non-HTTP workloads. This matters when backend locations remain fixed but latency must improve.
VERIFIED COMPETENCY MILESTONE
04
Secure edge delivery
Apply Signed URLs/Cookies and AWS WAF to protect private content and block common web threats at the edge. Security at the edge reduces origin exposure and simplifies access control.
VERIFIED COMPETENCY MILESTONE
