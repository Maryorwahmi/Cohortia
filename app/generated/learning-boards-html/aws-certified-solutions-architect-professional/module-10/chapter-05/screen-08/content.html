Module 10 › Chapter 10.5 › Lambda@Edge
Use cases
Authorization, header normalization, A/B tests, URL rewrites, and conditional caching.
• Normalize Accept-Language to reduce cache key variants.
• Strip tracking query parameters before cache lookup to increase hits.
• Implement lightweight auth checks and redirect unauthorized requests before origin contact.
Best practices
Keep functions small, avoid heavy compute, and test latency impact. Use edge logic when it reduces origin calls or improves correctness for caching.
Common misconception
Lambda@Edge is not a full application runtime. It is best for short, deterministic tasks that reduce origin interactions.
Quick task
Identify a header or query parameter you can normalize at the edge to improve cache hit ratio, and plan a small function to do it.
