Module 10 › Chapter 10.5 › CloudFront vs Global Accelerator
CloudFront
Caching, Lambda@Edge, WAF, Layer 7 features for delivering and securing content at the edge.
Best for static assets, edge modifications, and application-layer protections.
Global Accelerator
Static IPs and optimized routing over the AWS backbone to improve network performance for dynamic or non-HTTP traffic.
Best for low-latency network paths, jitter reduction, and scenarios needing stable entry IPs.
Combined pattern
Use CloudFront for static assets and caching. Use Global Accelerator to improve the initial network path to your ALB or to CloudFront where static IPs or reduced jitter are required.
