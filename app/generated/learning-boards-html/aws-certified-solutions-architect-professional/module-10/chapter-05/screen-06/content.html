Module 10 › Chapter 10.5 › Cache Keys
Which parts to include
Guidance for headers, cookies, and query strings.
• Path only: for immutable static objects.
• Path + header: when server varies output by Accept-Language or Accept-Encoding.
• Path + query string: when the query truly changes content, e.g., ?size=large.
• Cookies: include only when user-specific content must differ and caching remains safe.
Example decisions
You have a product image that uses a CDN URL with a ?v= parameter for versions. Exclude that parameter from the cache key if it doesn't change the image; instead, use versioned filenames so the path changes when the content does.
Common error
Including session cookies for static content creates one cached object per user and collapses the benefit of the CDN.
Pro tip
Normalize request headers with Lambda@Edge when header variations are superficial but must be part of the key.
