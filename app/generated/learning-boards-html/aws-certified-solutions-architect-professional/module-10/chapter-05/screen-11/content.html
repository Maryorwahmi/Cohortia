Module 10 › Chapter 10.5 › Lab: S3 + CloudFront
Step-by-step
  1. Create an S3 bucket and upload index.html (public) and premium/secret.txt (private).
  2. Create an Origin Access Control in CloudFront and attach it to your S3 origin.
  3. Create a CloudFront distribution. Default behavior for public files; add a behavior for premium/* that restricts viewer access.
  4. Create a CloudFront key pair, save the private key, then generate a signed URL for premium/secret.txt.
  5. Test: index.html should load normally; premium file should return 403 unless using the signed URL before expiry.
Checklist & tips
• Use Redirect HTTP to HTTPS. • Select caching policy CachingOptimized for static assets. • Avoid frequent invalidations; use versioned filenames.
Key Takeaway

OAC + signed URLs keep S3 private while CloudFront serves content securely from the edge.
