Compute Optimizer
Fetch recommendations, inspect reason codes, then validate before applying changes.
CLI example
Run this command to retrieve EC2 recommendations filtered for under- or overprovisioned findings.
aws compute-optimizer get-ec2-instance-recommendations \
    --filters "names=FindingReasonCodes,values=Underprovisioned,Overprovisioned" \
    --max-results 10
The output includes recommended instance types and estimated savings. Use this as a prioritized list for manual review and testing.
Interpreting findings
  • Check the finding reason codes to understand the driver, for example low CPU or inflated I/O.
  • Validate whether peak patterns justify the current instance before downsizing.
  • Test changes in staging and monitor latency and error rates during a controlled window.
Key Takeaway

Use Compute Optimizer to find candidates, but always validate with workload-specific testing and monitoring.
