Core Concept Definition
What this trade-off means
Frame performance goals, measure costs, and choose the right corrective action.
Illustrative example
You have an API that occasionally spikes. Two options: upsizing a single instance, or adding more small instances behind a load balancer.
Vertical scale
Higher single-instance performance, higher per-hour cost, lower operational complexity.
Horizontal scale
Better resilience and cost-per-request optimization, requires load distribution and state design.
Explanation & common misconceptions
  • Assume changes by measurement: collect CPU, memory, and latency before deciding.
  • Serverless is not free: costs come from duration, memory, API Gateway, and data transfer.
  • Don’t buy long-term for short transient peaks; use burstable or autoscaling options.
Key Takeaway

Make measurable decisions: choose the change that meets SLAs for the least added cost and verify with experiments.
