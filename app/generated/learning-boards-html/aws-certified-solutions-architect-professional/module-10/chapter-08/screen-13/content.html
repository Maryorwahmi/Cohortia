Hands-on Activity
Audit & Act: Compute Optimizer + Cost Explorer
Starter CLI snippet
aws compute-optimizer get-ec2-instance-recommendations \ 
  --filters "names=FindingReasonCodes,values=Underprovisioned,Overprovisioned" \ 
  --max-results 10
Use this output to build a prioritized review list and validate each candidate in staging before production change.
Checklist
  1. Enable Compute Optimizer and wait for recommendations.
  2. Use Cost Explorer to group costs by instance type and service.
  3. Validate recommendations with tests and roll out changes during low traffic.
Reflection

Document outcomes and track savings to build organizational confidence for further optimization.
