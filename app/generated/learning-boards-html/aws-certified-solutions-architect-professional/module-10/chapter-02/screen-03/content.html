Module 10 › Chapter 10.2 › Learning Objectives
Practical skills
Install, verify, benchmark, and iterate.
01
Diagnose bottlenecks with CloudWatch
Use CPU, disk I/O, and network metrics; install the CloudWatch Agent for memory and detailed disk metrics.
02
Benchmark storage
Run fio with representative workloads and compare observed IOPS and throughput to provisioned values.
03
Verify ENA and SR-IOV
Check driver status and SR-IOV capabilities whenever you migrate AMIs or change instance families.
04
Perform mount and fstab steps reliably
Attach secondary EBS volumes, format, mount, and add fstab entries for persistence and consistent performance tests.
VERIFIED COMPETENCY MILESTONE
Mnemonic & checklist
Checklist: choose instance, provision EBS IOPS, enable ENA/SR-IOV, run fio, confirm metrics in CloudWatch, and validate with OS tools.
Practice run
Follow the lab: attach a secondary volume, format it, run fio tests, and verify ENA with ethtool.
Common mistake
Assuming average CloudWatch metrics show no issues; transient spikes and queue depth require detailed metrics and agent install.
