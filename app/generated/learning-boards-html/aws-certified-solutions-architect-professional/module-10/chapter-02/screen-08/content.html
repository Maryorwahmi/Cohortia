Module 10 › Chapter 10.2 › Auto Scaling
Scaling policies
Choose policies that maintain performance under variable load.
Target Tracking
Set a target metric and let AWS continuously adjust capacity to keep the metric near the target.
Predictive Scaling
Forecast demand and provision capacity ahead of anticipated spikes to prevent performance degradation during predictable patterns.
Health checks & Cooldown
Ensure instances are healthy before receiving traffic, and tune cooldown periods to avoid rapid flapping in scaling actions.
Example scenario
A web service with predictable daily peaks can use predictive scaling to add capacity before the morning spike, and target tracking keyed to request latency to maintain steady user experience.
Misconception
Using CPU alone as the scaling metric can fail when throttling occurs in other layers; prefer metrics that map to user-perceived performance.
Check your understanding
When should you add predictive scaling to target tracking? (Answer: when load patterns are predictable and historical data is available to forecast demand.)
