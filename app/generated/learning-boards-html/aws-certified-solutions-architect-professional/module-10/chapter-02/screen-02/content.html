Learning Objectives
Bloom: Learn → Understand → Apply → Master
01
Select instance & EBS pairing
Evaluate family, processor, and EBS bandwidth to match compute and I/O needs. This reduces bottlenecks and cost by right-sizing resources.
02
Enable ENA and SR-IOV
Install and verify network drivers so instances achieve high packet throughput and low latency, critical for HPC or real-time systems.
03
Design placement groups
Choose Cluster, Spread, or Partition to balance latency and fault isolation for tightly coupled services.
04
Optimize ASG for performance
Use target tracking and predictive scaling to maintain performance under variable load while avoiding flapping.
VERIFIED COMPETENCY MILESTONE
Mnemonic
Think of performance tuning as tuning four dials: Instance, EBS, Network, Scaling. Each dial affects both capacity and latency.
Venn
Where instance and EBS overlap is I/O bandwidth; where instance and network overlap is packet rate and latency.
Why verification matters
Benchmarks and driver checks prevent surprises when traffic increases or when migrating AMIs.
