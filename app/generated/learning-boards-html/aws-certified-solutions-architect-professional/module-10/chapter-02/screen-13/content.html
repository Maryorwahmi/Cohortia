Module 10 › Chapter 10.2 › Pitfalls & Fixes
Common problems
Symptoms and first-response actions.
Mismatched EBS vs instance
If observed IOPS are below provisioned, verify instance EBS bandwidth and consider instance upgrade or distributing I/O.
Missing CloudWatch Agent
Install the agent to capture memory and finer disk metrics that CloudWatch does not include by default.
Driver regressions
Validate ENA and SR-IOV drivers during AMI lifecycle to avoid network performance regressions.
Runbook snippet
Quick triage: 1) Confirm CloudWatch metrics; 2) Run iostat and fio; 3) Check ENA driver; 4) Verify instance EBS bandwidth. Prioritize fixes that restore latency first.
ASG flapping
If instances are repeatedly added and removed, extend cooldowns, improve health checks, and consider target tracking with predictive scaling for stable capacity.
Key Takeaway
Turn symptoms into reproducible tests. Benchmarks and agent metrics convert guesswork into actionable configuration changes.
