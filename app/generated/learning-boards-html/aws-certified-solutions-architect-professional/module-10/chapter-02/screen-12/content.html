Commands to run
Example terminal sequence for benchmarking and validation.
# List block devices
lsblk

# Check ENA driver
ethtool -i eth0 | grep driver

# Run fio workloads
sudo fio --name=randwrite --ioengine=libaio --iodepth=16 --rw=randwrite --bs=4k --direct=1 --size=1G --numjobs=1 --runtime=60 --group_reporting --filename=/data/testfile.fio

# Observe I/O while fio runs
iostat -xz 1
Interpret output by correlating fio-reported IOPS and latency with iostat queue depth and service time. If ENA driver is not shown, reinstall and validate the kernel modules.
Scenario
You run fio and observe IOPS are significantly lower than provisioned. iostat shows a high avgqu-sz. That points to either instance EBS bandwidth limit or volume contention; next steps are verifying instance limits and trying a different instance or RAID layout for throughput.
Cleanup
Unmount test volumes, remove fstab entries, and terminate the instance when the lab completes to avoid leftover costs or stale mounts.
