Hierarchy
Container Scaling: ECS, EKS, and Fargate
Balancing operational effort, cost, and elasticity
ECS / EKS on EC2
You manage nodes, can use Spot and specialized instances, and tune for cost at scale.
AWS Fargate
Serverless containers: specify CPU and memory, AWS manages hosts and scaling, excellent for variable workloads.
Load Balancing
ALB auto-registers and deregisters tasks. Use request count per target or custom metrics to scale task count.
Concrete example
Front-end on Fargate behind an ALB. Configure ECS Service autoscaling to add tasks when ALB request count per target rises above a threshold.
Consideration
For consistent high utilization, EC2-backed clusters with reserved instances or Spot nodes may reduce cost compared to Fargate.
