Comparison
ALB vs NLB vs GWLB
Match OSI layer and features to your traffic patterns
Application Load Balancer (ALB)
Layer 7 routing for HTTP/HTTPS. Supports path, host, and header-based routing, SSL termination, and integration with WAF.
Network Load Balancer (NLB)
Layer 4: TCP/UDP/TLS with static IPs and ultra-low latency. Handles extreme performance and custom protocols.
Gateway Load Balancer (GWLB)
Layer 3 gateway for virtual appliances such as firewalls and inspection systems. Scales appliances transparently.
Concrete choice
High-throughput TCP with static IP → NLB + ECS/Fargate. Web routing and microservices → ALB + ASG or Fargate. Appliance chaining → GWLB.
Misconception
ALB can handle every workload — no. ALB lacks static IPs and the low-level protocol support of NLB.
