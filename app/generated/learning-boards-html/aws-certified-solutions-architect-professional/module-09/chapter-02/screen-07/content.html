ASG Scaling Policies — Target Tracking
CLI example you can adapt for your environment
What this does
Creates a launch template, an Auto Scaling Group with min/max/desired, and applies a CPU target tracking policy to keep average CPU at 60%.
Remember to replace AMI, subnets, and security group IDs with your real values.
Starter CLI (adapt values)
# Create a Launch Template (replace AMI and instance type)
aws ec2 create-launch-template \
  --launch-template-name MyWebLaunchTemplate \
  --version-description "Initial version" \
  --launch-template-data '{"ImageId":"ami-0abcdef1234567890", "InstanceType":"t3.medium", "SecurityGroupIds":["sg-0123456789abcdef0"], "UserData":"IyEvYmluL2Jhc2gNCnN1ZG8geXVtIHVwZGF0ZSAtIHkNCnN1ZG8geXVtIGluc3RhbGwgaHR0cGRkIC15DQpzdWRvIHN5c3RlbWN0bCBzdGFydCBodHRwZGQNClN1ZG8gc3lzdGVtY3RsIGVuYWJsZSBodHRwZGQNQ2hvICJoZWxsbyB3b3JsZCIgPiAvaW5kZXguaHRtbA=="}'

# Create the Auto Scaling Group
aws autoscaling create-auto-scaling-group \
  --auto-scaling-group-name MyWebAppASG \
  --launch-template LaunchTemplateName=MyWebLaunchTemplate,Version='$Latest' \
  --min-size 2 \
  --max-size 10 \
  --desired-capacity 2 \
  --vpc-zone-identifier "subnet-0abcdef1234567890,subnet-0fedcba9876543210" \
  --target-group-arns "arn:aws:elasticloadbalancing:REGION:ACCOUNT_ID:targetgroup/MyWebAppTargetGroup/1234567890abcdef" \
  --health-check-type ELB \
  --health-check-grace-period 300 \
  --tags Key=Name,Value=MyWebAppInstance,PropagateAtLaunch=true

# Apply a Target Tracking Scaling Policy
aws autoscaling put-scaling-policy \
  --auto-scaling-group-name MyWebAppASG \
  --policy-name CPU60TargetTrackingPolicy \
  --policy-type TargetTrackingScaling \
  --target-tracking-configuration '{"PredefinedMetricSpecification":{"PredefinedMetricType":"ASGAverageCPUUtilization"},"TargetValue":60.0}'
Concrete example
Set the ASG to maintain 60% CPU to balance throughput and cost, then run a controlled load test to confirm scale-out timing.
Misconception
Target tracking makes instant perfect scaling—no. It moves capacity to meet a metric and is subject to warm-up and cooldown delays.
