Operational Practices

Observability checklist

Centralize logs
Send logs to a single store so queries can span services and time ranges.
Distributed tracing
Propagate a request or event ID so you can trace end-to-end execution across services and queues.
Health & metrics
Expose health checks and key metrics so orchestrators and ALBs can act on unhealthy instances.
Security
Enforce least-privilege between services using IAM roles, authorizers, or a service mesh.
Anti-patterns
Distributed Monolith
Services that are tightly coupled or share databases behave like a monolith and negate microservice benefits.
Practical tip
Start with clear boundaries and observability. Propagate a request ID from the API edge through both sync calls and async events to simplify debugging.
