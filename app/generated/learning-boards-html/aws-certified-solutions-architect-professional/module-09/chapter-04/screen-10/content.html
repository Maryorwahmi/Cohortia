CloudFormation: API Gateway + Lambda

Use the template to deploy a simple User Profile microservice. After deploy, test using curl and inspect CloudWatch logs.

# AWS CloudFormation snippet for an API Gateway to Lambda microservice
AWSTemplateFormatVersion: '2010-09-09'
Description: 'Serverless Microservice for User Profile (API Gateway + Lambda)'

Parameters:
  FunctionName:
    Type: String
    Default: UserProfileServiceLambda

Resources:
  UserProfileLambda:
    Type: AWS::Lambda::Function
    Properties:
      FunctionName: !Ref FunctionName
      Handler: index.handler
      Runtime: python3.9
      Code:
        ZipFile: |
          import json
          def handler(event, context):
              print(event)
              if event['httpMethod'] == 'GET':
                  user_id = event['pathParameters'].get('user_id')
                  if user_id == '123':
                      return {
                          'statusCode': 200,
                          'headers': {'Content-Type': 'application/json'},
                          'body': json.dumps({'userId': user_id, 'name': 'John Doe', 'email': 'john.doe@example.com'})
                      }
                  else:
                      return {
                          'statusCode': 404,
                          'headers': {'Content-Type': 'application/json'},
                          'body': json.dumps({'message': 'User not found'})
                      }
              elif event['httpMethod'] == 'POST':
                  body = json.loads(event['body'])
                  return {
                      'statusCode': 201,
                      'headers': {'Content-Type': 'application/json'},
                      'body': json.dumps({'message': 'User created', 'data': body})
                  }
      MemorySize: 128
      Timeout: 30
Testing
After deployment, find the ApiGatewayEndpoint in stack outputs and run GET and POST curl commands as described in the activity instructions.
Operational note
Check CloudWatch logs to see incoming events and debug behavior. Ensure Lambda has execution role and API Gateway permission to invoke it.
Example Calls
Use the ApiGatewayEndpoint and run:
curl "${API_ENDPOINT}/123"
curl -X POST -H "Content-Type: application/json" -d '{"userId":"789","name":"Jane Doe","email":"jane.doe@example.com"}' "${API_ENDPOINT}"
Common pitfall
For production, add authentication, parameter validation, and idempotency for POST handlers to avoid duplicate behavior on retries.
