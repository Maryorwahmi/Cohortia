Comparison

Lambda vs ECS vs EKS

AWS Lambda
Serverless for short-lived, stateless functions; automatic scaling and pay-per-execution.
Amazon ECS
Managed container orchestration, run on EC2 or Fargate; good balance of control and simplicity.
Amazon EKS
Managed Kubernetes for teams requiring K8s ecosystem features and flexibility, with greater operational overhead.
Scenario
Example workload choices
Payment processing that is short and stateless → Lambda. Long-running matching engine → ECS. Complex polyglot microservices with custom scheduling → EKS.
Common mistake
Choosing Kubernetes by default even when serverless or ECS would reduce operational burden and cost; match platform to need.
