Process Flow

HTTP/REST and gRPC

Synchronous calls require immediate responses; choose them when you need up-to-date information.

HTTP/REST
Simple, language-agnostic, integrates with ALB and API Gateway.
gRPC
High performance, useful for inter-service low-latency calls when supported across services.
Guidance
Design rules
  • Set timeouts and retries to avoid cascading failures.
  • Use idempotent operations so retries are safe.
  • Prefer cache or stale reads when strict freshness is not required.
Scenario
A Ride Service calls User Service synchronously to authorize a request. If the call times out, the Ride Service may use cached user data or return an informative error without blocking the entire workflow.
