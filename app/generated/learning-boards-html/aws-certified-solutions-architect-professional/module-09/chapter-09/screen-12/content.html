Module 10 › Chapter 9.9 › Cost Optimization
Optimization checklist
  • Measure duration and compute cost per invocation at multiple memory sizes.
  • Use event-driven processing to avoid blocking user requests.
  • Apply API Gateway throttling and usage plans to protect against traffic spikes.
  • Use provisioned concurrency only for functions with strict latency SLAs.
Practical tips
Batch work to reduce per-message overhead.
Use SQS to smooth spikes and lower peak concurrency costs.
Instrument functions to map cost to features and identify expensive handlers.
Key Takeaway

Measure, experiment, and choose the configuration that balances latency and total cost for your workload.
