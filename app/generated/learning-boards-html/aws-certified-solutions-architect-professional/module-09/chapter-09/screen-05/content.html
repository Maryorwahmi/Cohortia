Module 10 › Chapter 9.9 › API Gateway Types
Comparison
REST API
Full feature set: models, transformations, stages, and advanced monitoring. Use when you need fine-grained API management.
HTTP API
Lower latency and lower cost for common RESTful patterns. Prefer when you require simple routing and fast responses.
WebSocket API
Bidirectional, real-time communication for chat, collaboration, or IoT when server push is required.
Authorizers & Security
Lambda Authorizer
Custom authentication logic in Lambda. Use when you need bespoke identity checks or custom token validation.
IAM Authorizer
Leverage AWS IAM for signed requests and role-based access control.
Cognito User Pools
Managed user directory and authentication that integrates with API Gateway.
Key Takeaway

Match API Gateway type to your feature needs and latency budget; choose appropriate authorizers for security requirements.
