Module 10 › Chapter 9.9 › Lambda Fundamentals
Definition

Lambda runs code in response to events. Functions are stateless, scale automatically, and are billed per execution.

Example
A registration function validates input, writes to DynamoDB, and publishes an SNS event for downstream processing.
Misconception
Do not rely on in-memory state between invocations. Container reuse is an optimization, not a contract.
Pro tip
Increase memory to improve CPU and reduce runtime for CPU-bound functions; measure cost vs time trade-offs.

Key Takeaway

Design functions to be stateless, single-purpose, and externally stateful when needed.
