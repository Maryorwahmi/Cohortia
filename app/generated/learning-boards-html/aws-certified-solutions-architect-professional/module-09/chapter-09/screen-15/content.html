Module 10 › Chapter 9.9 › What to Remember
Stateless Functions
Persist data externally; avoid relying on in-memory state.
API Type
Select HTTP, REST, or WebSocket based on feature and latency needs.
Security
Use appropriate authorizers and least-privilege IAM roles.
Final Takeaway

Measure, instrument, and choose the right balance between latency, cost, and complexity when building serverless microservices.
