Objective checklist
  • API type decision: Choose HTTP for low latency, REST when full features are needed, WebSocket for bidirectional traffic.
  • Least privilege: Limit Lambda IAM roles to required DynamoDB or SNS actions only.
  • Event-driven wiring: Use SNS fan-out and SQS for retries and queueing.
  • Cost checks: Measure ms per invocation, compare cost at multiple memory sizes.
Practice cues
Validate cold start times with CloudWatch metrics and traces.
Simulate production load and observe reserved concurrency behavior.
Deploy a SAM template and perform curl verification of the endpoint.
