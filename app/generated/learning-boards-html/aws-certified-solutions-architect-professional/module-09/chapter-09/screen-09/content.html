Module 10 › Chapter 9.9 › Event Integrations
Integration cards
DynamoDB
Serverless, fast key-value store for persistent state used by Lambda functions.
SQS
Buffered, reliable queue for asynchronous processing and retries.
SNS
Publish-subscribe fan-out for notifying multiple subscribers concurrently.
Step Functions
Coordinate multi-step workflows with state, retries, and compensation logic.
Concrete scenario
User registration: API Gateway → RegisterUserLambda → DynamoDB write → SNS publish → SendWelcomeEmail and UpdateAnalytics Lambdas subscribe. This ensures the registration API returns quickly and downstream work runs asynchronously.
Key Takeaway

Favor asynchronous, event-driven patterns to decouple services and improve responsiveness.
