Module 10 › Chapter 9.9 › Cold Starts
Cold start process
Step 1
Provision environment
AWS sets up the runtime and file system for your function.
Step 2
Initialize code
Runtime loads dependencies and runs any global initialization.
Step 3
Handle request
Handler executes business logic and returns response.
Mitigation
Use provisioned concurrency for critical, latency-sensitive functions and minimize init work.
Caution
Provisioned concurrency increases cost; validate that latency benefits justify the expense.
Concrete example
A SendMessage endpoint for chat experiences might use provisioned concurrency to ensure users never see initial delays after idle periods. Measure cold start times in CloudWatch to validate the need.
Key Takeaway

Provisioned concurrency removes cold starts for warmed environments but plan for its steady cost.
