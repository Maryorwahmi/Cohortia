Module 10 › Chapter 9.9 › Security
Authorizers
Lambda Authorizer
Custom logic for token validation or complex authorization checks.
IAM Authorizer
Use signed AWS requests when callers can authenticate with IAM credentials.
Cognito User Pools
Managed user directory for standard sign-in flows and tokens.
IAM & Secrets

Assign the minimum permissions needed to Lambda functions and avoid embedding secrets in plain environment variables. Use Secrets Manager or encrypted parameters for credentials.

Key Takeaway

Combine appropriate authorizers with least-privilege IAM roles and secure secret storage for a robust security posture.
