Module 10 › Chapter 9.9 › Memory & CPU
Concept

Memory controls CPU allocation in Lambda. More memory usually increases CPU and network, often reducing execution time for compute-heavy functions.

Example test
Run the same invocation at 128MB, 512MB, and 1024MB and compare average duration and cost.
Misconception
More memory always reduces cost. Not always—measure cost-per-invocation before committing to higher memory for many functions.
Practical steps
  • Identify CPU-bound functions with heavy computation.
  • Run experiments across memory sizes and record duration and billed ms.
  • Compute cost-per-invocation and choose the configuration with lowest cost for acceptable latency.
Key Takeaway

Tune memory based on measurable performance data, not assumptions about needing more RAM.
