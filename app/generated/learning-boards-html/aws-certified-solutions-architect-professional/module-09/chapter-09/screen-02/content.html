How to use these objectives

Treat the objectives as a design checklist. After reading each lesson, review the milestones and apply them to a sample microservice. Use the hands-on SAM activity to deploy and observe behavior in the console.

Milestone

Deploy a Hello World Lambda behind API Gateway and demonstrate a secured, low-latency endpoint.

Tip

Measure cold start latency in CloudWatch and compare cost at different memory settings to find the performance sweet spot.
