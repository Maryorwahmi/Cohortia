Module 9 › Chapter 9.6 › Hands-on: Run the Simulation and Test Patterns
Step-by-step activity
Run the script, observe output, and experiment with configuration parameters.
1. Save the script as resilience_patterns.py and run python resilience_patterns.py.
2. Observe circuit breaker transitions: closed, open, half-open, and back to closed.
3. Observe retry attempts, backoff timings, and jitter variation in sleep durations.
4. Change failure_threshold and recovery_timeout and rerun to see effects.
5. Add an idempotency key store and verify duplicate calls return stored results.
6. Use controlled delays to simulate a slow downstream service and confirm fallbacks trigger.
Key Takeaway

Hands-on experiments reveal how tuning affects protection and recovery; practice tuning with metrics and logs.
