Security Considerations Between Tiers
Combine network controls, IAM, and encryption
Network isolation rules
  • Presentation tier in public subnets; application and data tiers in private subnets.
  • Security Groups: allow only necessary ports between tiers.
  • Use NACLs for coarse boundary protections where needed.
Key Takeaway
Defense in depth: network controls, IAM, and encryption work together to protect each tier.
Practical example
Configure the ALB to accept HTTPS, targets in private subnets, application servers with IAM roles to access RDS and S3, and an RDS instance that accepts connections only from the application security group.
Mistake
Placing databases in public subnets or embedding credentials in application code exposes you to unnecessary risk.
Check
List three IAM or network controls you would apply to prevent lateral movement between tiers.
