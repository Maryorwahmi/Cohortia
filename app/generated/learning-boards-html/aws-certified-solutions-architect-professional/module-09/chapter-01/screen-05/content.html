Presentation Tier
Delivery, Caching, and Availability
Optimize for low latency and global reach
Service mapping
Primary services
  • S3 for static hosting and asset storage.
  • CloudFront for CDN, TLS at edge, and caching.
  • ALB for dynamic HTTP routing and TLS termination.
Design notes
Use CloudFront behaviors to separate static and API paths. Keep TLS termination at the ALB or CloudFront depending on your architecture. Ensure the ALB spans multiple AZs for availability.
Concrete example
Host a React app artifact and product images in S3, attach CloudFront to serve them globally, and route API calls through an ALB to application services in private subnets. This minimizes latency and offloads traffic from compute.
Pro Tip
Configure cache invalidation for rapid deployments and use short TTLs for paths that change frequently.
Mistake to avoid
Do not give the presentation tier direct network access to databases; always route through application services.
