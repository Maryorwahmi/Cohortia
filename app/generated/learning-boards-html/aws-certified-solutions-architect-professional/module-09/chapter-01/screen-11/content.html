Scaling Strategies and Caching
Autoscaling, caching, and sizing decisions
Scaling guidance
  • Scale horizontally with ASGs or service autoscaling.
  • Use Lambda where bursty concurrency is common.
  • Cache hot reads with ElastiCache to reduce DB load.
Key Takeaway
Autoscale the tier that experiences the bottleneck and introduce caching before expensive horizontal scaling of the database.
Concrete example
If product pages see 10x read traffic, add ElastiCache for product details, scale presentation and application tiers horizontally, and monitor cache hit ratio to tune TTLs.
Mistake
Relying on a single large database instance without caching will likely become a bottleneck under scale.
Check
Which metric would you monitor to decide whether to add cache versus add compute instances?
