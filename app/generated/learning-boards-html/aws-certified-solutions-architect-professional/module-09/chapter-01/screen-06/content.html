Options
  • EC2 Auto Scaling for full-control monoliths.
  • ECS/EKS for container orchestration and microservices.
  • Lambda for event-driven, serverless functions.
Key Takeaway

Match compute type to service lifecycle and traffic pattern; mix models where appropriate.

Concrete design
Use ECS Fargate for stateless microservices that scale independently. Use Lambda for background jobs like thumbnail generation. Put everything behind an ALB or API Gateway for unified routing and TLS management.
Pitfall
Assuming serverless is always cheaper; evaluate cost and performance for sustained high loads.
