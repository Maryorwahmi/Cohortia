Anomaly Detection

Apply ML to learn normal metric patterns and detect deviations that need investigation. Useful for noisy or seasonal signals.

When to use
For metrics with variable baselines where static thresholds are too noisy.

CloudWatch Synthetics

Create canaries that simulate user traffic to test endpoints and measure availability and latency from outside the VPC.

Example
A canary runs a login and checkout flow every five minutes to alert when user journeys fail.
Benefit
Catch regressions invisible to internal metrics.
Pitfall
Too-frequent canaries raise cost; stale canary scripts give false confidence.
Takeaway
Combine anomaly detection and synthetics to detect and validate incidents proactively.
