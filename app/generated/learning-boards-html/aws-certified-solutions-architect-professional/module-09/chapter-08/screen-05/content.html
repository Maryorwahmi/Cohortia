Module 9 › Chapter 9.8 › Centralized Logging
Definition

CloudWatch Logs as a central store

Collect logs from EC2, Lambda, ECS and other sources into CloudWatch Logs. Use log groups to scope services and log streams to separate instances or tasks.

Best practice
Adopt a naming convention and apply retention policies to control cost and retain useful history.
Warning
Never ship unredacted sensitive data to logs. Mask PII and secrets before sending.

Architecture snapshot

Sources
  • EC2 with CloudWatch Agent
  • Lambda native logging
  • ECS container logging driver
Destinations
  • CloudWatch Logs Groups & Streams
  • Optional stream to OpenSearch for dashboards
Example
ECS tasks stream stdout to a log group named '/ecs/payment-processing/app-logs' with a stream per task id.
Key takeaway
Centralized logs enable cross-service searches and consistent retention; plan naming and masking early.
