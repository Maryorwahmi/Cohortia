Module 9 › Chapter 9.8 › AWS X-Ray Tracing

Traces and segments

A trace represents one request and is built from segments. Subsegments capture downstream calls such as database queries or external HTTP requests.

Service map
Visual graph showing services, connections, latency and error rates; used to spot hotspots quickly.

Instrumentation

Add the X-Ray SDK to services and ensure trace IDs are passed between services. Many managed services have native tracing options, but custom code needs explicit support.

Pitfall
Partial instrumentation leads to incomplete traces and blind spots in the service map.
Example
A request flows from API Gateway to payment service, to DynamoDB and an external gateway. X-Ray shows which call added the most latency.
Takeaway
Traces complete the picture by revealing sequence and duration of calls across services, enabling precise bottleneck identification.
