Module 9 › Chapter 9.8 › Log Management

Log groups and streams

Group logs by service or application. Use streams for per-instance, per-task, or per-invocation separation to make time-ordered queries simple.

Retention
Set retention based on debugging needs and compliance. Short retention reduces cost; long retention aids historical analysis.
Insights
Use CloudWatch Logs Insights queries to find errors, parse latency, and compute aggregates like p95 latency across time windows.

Practical example

Run a query to show recent errors and average latency around an alarm time. Parse latency fields from log messages and use stats to compute average and percentile values. If you need richer dashboards, stream the same logs to OpenSearch Service.

Common-mistake
Not parsing useful fields from logs. Structure logs or parse them in Insights to create actionable metrics rather than raw text dumps.
Key takeaway
Design log naming and retention, parse key fields, and use Insights or OpenSearch depending on search and visualization needs.
