Module 9 › Chapter 9.8 › Metrics, Alarms & Dashboards
Steps
  1. Identify service-level metrics and SLO-aligned indicators.
  2. Publish custom metrics where needed.
  3. Create alarms with evaluation periods and actions.
  4. Compose dashboards and enable anomaly detection.

Practical guidance

Prefer percentile latency metrics over averages, set meaningful evaluation windows, and wire alarms to a concrete playbook. Use synthetics to validate availability from outside your VPC and capture user facing latency.

Example
Alarm on p95 latency over 500ms for 5 minutes triggers a notification and a runbook for investigation.
Pro-tip
Use anomaly detection to catch regressions that static thresholds miss and reduce noisy alerts.
Key Takeaway

Metrics detect symptoms, alarms escalate, dashboards orient the operator, and synthetics validate availability from the outside-in.
