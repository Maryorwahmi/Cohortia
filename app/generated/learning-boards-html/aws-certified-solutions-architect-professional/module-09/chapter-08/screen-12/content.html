Module 9 › Chapter 9.8 › Observability Strategy

Workflow design

  1. Define SLOs and key metrics per service.
  2. Create alarms and dashboards to surface SLO violations.
  3. When alerted, query logs and extract request IDs.
  4. Open traces for those request IDs to find the bottleneck.
Practice
Run incident drills using a synthetic failure and time the mean time to detection and resolution.

Governance

Define retention policies, apply least privilege IAM for telemetry agents, and ensure logs are sanitized to remove sensitive data before sending to centralized stores.

Example
A runbook: confirm alarm, capture relevant logs for the alarm window, locate traces by request id, identify failing service or external call, apply mitigation, and update incident notes.
Key Takeaway

An observability strategy maps detection to diagnosis: alarms drive logs queries and traces to locate root causes fast.
