AWSTemplateFormatVersion: '2010-09-09'
Description: 'CodePipeline for ECS Blue/Green Deployment with CodeDeploy'

Resources:
  MyCodePipeline:
    Type: AWS::CodePipeline::Pipeline
    Properties:
      Stages:
        - Name: Source
          Actions:
            - Provider: CodeCommit
        - Name: Build
          Actions:
            - Provider: CodeBuild
              OutputArtifacts:
                - Name: BuildOutput # contains imagedefinitions.json
        - Name: Deploy
          Actions:
            - Provider: CodeDeploy
              Configuration:
                ApplicationName: !Ref CodeDeployApplication
                DeploymentGroupName: !Ref CodeDeployDeploymentGroup

  CodeBuildProject:
    Properties:
      Source:
        Type: CODEPIPELINE
      BuildSpec: |
        version: 0.2
        phases:
          pre_build:
            commands:
              - aws ecr get-login-password --region $AWS_DEFAULT_REGION | docker login --username AWS --password-stdin $AWS_ACCOUNT_ID.dkr.ecr.$AWS_DEFAULT_REGION.amazonaws.com
          build:
            commands:
              - docker build -t $ECR_REPO_NAME:$IMAGE_TAG .
              - docker push $AWS_ACCOUNT_ID.dkr.ecr.$AWS_DEFAULT_REGION.amazonaws.com/$ECR_REPO_NAME:$IMAGE_TAG
          post_build:
            commands:
              - printf '[{"name":"container-name-in-task-definition","imageUri":"%s"}]' $AWS_ACCOUNT_ID.dkr.ecr.$AWS_DEFAULT_REGION.amazonaws.com/$ECR_REPO_NAME:$IMAGE_TAG > imagedefinitions.json
      Artifacts:
        Type: CODEPIPELINE
Mapping checklist
  • Where does CodeBuild push the image? → Amazon ECR.
  • What artifact tells CodeDeploy which image to use? → imagedefinitions.json.
  • Which roles need least privilege? → CodePipeline, CodeBuild, CodeDeploy service roles.
Practical note

This template assumes ECS cluster, task definition, ALB and target groups already exist. Prepare those before deploying.
