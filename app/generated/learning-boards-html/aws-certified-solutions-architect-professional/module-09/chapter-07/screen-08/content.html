Stage responsibilities
  • Source: host Git repos in CodeCommit or external Git providers.
  • Build: CodeBuild compiles, tests, and builds container images.
  • Artifact: push image to ECR and emit imagedefinitions.json for deploy.
  • Orchestration: CodePipeline moves artifacts and triggers deploy stages.
  • Deploy: CodeDeploy or pipeline actions update ECS/EKS with chosen strategy.
Concrete handoff

CodeBuild pushes the Docker image to ECR and writes imagedefinitions.json. CodePipeline consumes this artifact and hands it to CodeDeploy which performs the deployment to ECS with traffic control via ALB target groups.

Common misconception

Assuming build logs or artifacts alone are enough; you must produce explicit deployable artifacts that the pipeline expects, like imagedefinitions.json for CodeDeploy.
