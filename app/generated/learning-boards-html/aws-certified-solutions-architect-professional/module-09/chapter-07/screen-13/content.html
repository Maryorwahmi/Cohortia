Definition › Feature Flags & Dark Launches
Feature flags

Toggle features at runtime to enable subset rollouts, A/B tests, or emergency disables without code deploys. Centralize flags with AppConfig for consistency.

Dark launches

Deploy features hidden from users to measure performance and behavior under production load before enabling them.

Concrete example

Push a new recommendation engine code path but keep it off. Monitor latency and CPU under real traffic. If acceptable, enable for 5% of users using a flag, then grow the audience.

Warning: manage flag lifecycle to avoid accumulating dead code and configuration debt.
Key Takeaway

Feature flags and dark launches allow production validation with minimal user impact; pair them with Canary strategies for controlled exposure.
