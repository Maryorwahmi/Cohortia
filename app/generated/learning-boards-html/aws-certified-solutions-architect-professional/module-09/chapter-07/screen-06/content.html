Definition › Blue/Green Deployment
Pattern

Run two identical environments. Deploy Green fully, test it, then shift production traffic from Blue to Green via ALB target groups or DNS.

AWS details
  • CodeDeploy configures target group pairs for ECS and EC2/ASG.
  • ALB listener rules or Route 53 can move traffic to the Green group.
  • AutoRollback can use CloudWatch alarms to revert to Blue if thresholds are breached.
Concrete e-commerce example

Deploy Product Catalog image to Green tasks. Shift a small Canary slice to Green for 15 minutes while monitoring error and latency alarms. If metrics are healthy, move 100% traffic; otherwise, switch back to Blue and terminate Green when resolved.

Common mistake

Assuming switching traffic avoids DB migration risk — schema changes still need compatibility planning across Blue and Green.

Key Takeaway

Use Blue/Green for critical services where instant rollback and validated green environments outweigh the cost of duplicate capacity.
