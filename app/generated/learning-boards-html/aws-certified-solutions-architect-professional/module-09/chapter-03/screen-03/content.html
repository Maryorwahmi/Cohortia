01 Configure SQS
  • Create Standard and FIFO queues and understand throughput tradeoffs.
  • Set visibility timeout and enable long polling to reduce empty responses.
  • Attach DLQs to capture repeatedly failing messages for inspection.
VERIFIED COMPETENCY MILESTONE
02 SNS & Fan-out
  • Create an SNS topic and subscribe SQS, Lambda, and HTTP endpoints.
  • Use SNS for immediate push notifications to many targets.
  • Combine SNS with SQS to get durable fan-out processing.
VERIFIED COMPETENCY MILESTONE
03 Kinesis Streams
  • Design shards to match producer throughput and consumer speed.
  • Use Firehose for managed delivery to storage and analytics targets.
  • Run analytics with SQL or Flink for real-time insights.
VERIFIED COMPETENCY MILESTONE
04 EventBridge
  • Create rules to route events from AWS services and custom applications.
  • Use the schema registry to share event shapes across teams.
  • Integrate SaaS events without building custom polling connectors.
