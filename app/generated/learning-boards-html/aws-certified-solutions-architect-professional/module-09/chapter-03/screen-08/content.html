Module 9 › Chapter 9.3 › Amazon SNS — Pub/Sub and Fan-out
SNS fundamentals

Publishers send messages to a topic. SNS pushes to every subscribed endpoint immediately, enabling near real-time fan-out to many consumers.

Supported endpoints

SQS, Lambda, HTTP/S, email, mobile push.

Use cases

Notifications, fan-out to multiple processing pipelines, alerting.

Pro-tip

Subscribe SQS queues to topics to combine SNS fan-out with durable per-consumer buffering and retries.

Example

An order service publishes "OrderPlaced" to an SNS topic. Subscribers include: an SQS queue for billing, a Lambda for confirmations, and an HTTP endpoint for analytics. If the analytics endpoint is unavailable, the SQS-backed workflows continue unaffected.

Misconception

SNS alone does not provide the same persistent buffering guarantees as SQS. Use SQS subscriptions when durability and replay are required.

Quick check

Which subscribers should be durable and which can be invoked directly? Use that answer to choose SQS subscriptions or direct Lambda/HTTP subscriptions.
