Module 9 › Chapter 9.3 › Amazon SQS: Standard vs FIFO
SQS Overview

SQS lets you decouple producers and consumers by reliably storing messages until processed. Key features are visibility timeout, long polling, and DLQs.

Standard Queue

High throughput, at-least-once delivery, best-effort ordering; duplicates possible.

FIFO Queue

Exactly-once processing and strict ordering within message groups; lower throughput but strong guarantees.

Key Takeaway

Pick FIFO only when ordering matters; otherwise prefer Standard for scale.

Example: orders

If a payment sequence must be applied in order, use a FIFO queue with a MessageGroupId per account so updates are strictly sequential and deduplicated. For events like image processing where order is not critical, use Standard queues for higher throughput.

Misconfiguration trap

Forgetting MessageGroupId in FIFO sends or not enabling DLQs can cause lost ordering guarantees or unhandled failures—plan these settings at queue creation.
