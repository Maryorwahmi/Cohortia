Module 9 › Chapter 9.5 › Security & IAM
Core practices
Encrypt data at rest and in transit for every datastore.
Grant least-privilege IAM roles scoped to the specific table or instance.
Use temporary credentials and IAM roles instead of embedded keys.
Restrict network access with VPCs and endpoints.
Key Takeaway

Secure datastores through encryption, least-privilege roles, and network controls before production rollout.

Example checklist
  • Enable TLS for client connections.
  • Enable encryption-at-rest for RDS, DynamoDB, and other stores.
  • Create resource-scoped IAM policies for each service role.
  • Audit access and enable tracing to spot anomalies.
