Module 4 › Chapter 3.7 › Storage Gateway
File Gateway
Presents NFS/SMB file shares backed by S3 objects. Useful for migrating file shares to S3 with low application change.
Example: Deploy File Gateway on an EC2 or VM, create an S3-backed file share, mount on the server, copy files, and verify objects in S3.
Volume & Tape Gateways
Volume Gateway exposes iSCSI volumes with cached or stored modes. Tape Gateway replaces physical tapes with virtual tapes stored in Glacier classes for long-term retention.
Verify cache sizing for cached volumes and lifecycle policies for tape archives to control storage class transitions.
Pro tip
Simulate production access patterns to size local cache before cutover.
Key Takeaway
Storage Gateway provides a phased migration path allowing apps to keep running while data is moved to AWS.
Common mistake
Neglecting IAM roles and bucket policies risks unauthorized access or failed gateway operations.
