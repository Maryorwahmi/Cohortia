Module 4 › Chapter 3.7 › Homogeneous vs Heterogeneous
Homogeneous migrations
Same engine family migrations usually need fewer code changes. Example: Oracle to Oracle on RDS involves schema export/import and data transfer with minimal procedural rewrite.
When to choose
When you can preserve code and expect parity in features and behavior.
Heterogeneous migrations + SCT
SCT converts schemas and many code objects. It flags items requiring manual remediation, especially vendor-specific procedural code and certain data type mappings.
Concrete example
Converting Oracle PL/SQL stored procedures to PostgreSQL functions usually needs manual rewriting after SCT conversion.
Misconception
SCT will not remove the need for human review on complex code objects.
Pro tip
Run SCT early, iterate conversions, and validate converted objects in a staging cluster before cutover.
Key Takeaway
Expect automation plus manual remediation; schedule staff time for code fixes in heterogeneous moves.
