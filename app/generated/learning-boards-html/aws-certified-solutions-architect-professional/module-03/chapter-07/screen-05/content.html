Module 4 › Chapter 3.7 › DMS setup
Step-by-step
  1. Discovery: measure size, change rate, and dependencies.
  2. Endpoints: create and test connectivity for source and target.
  3. Replication instance: choose class based on throughput needs.
  4. Migration task: set full load, CDC options, and table mappings.
  5. Verification: compare row counts, sample checksums, and test queries.
Pro tip
Script endpoint validation and CloudWatch alarms into your automation so you detect reachability or performance issues early.
Verification checklist
  • Endpoint connectivity confirmed from the replication instance.
  • Replication instance metrics show CPU and network headroom.
  • Sampled data matches by row count and key checksums.
  • Application queries against the target return expected results in read-only mode.
Common Mistake

Starting a migration without endpoint validation wastes time. Always test connectivity and credentials first.
