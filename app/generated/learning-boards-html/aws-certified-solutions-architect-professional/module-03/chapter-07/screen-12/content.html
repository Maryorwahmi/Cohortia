Module 4 › Chapter 3.7 › Lab scenario
Lab checklist
  1. Provision Aurora MySQL target and required network/security groups.
  2. Create DMS replication instance and test source/target endpoints.
  3. Create a migration task with full load + CDC and monitor progress.
  4. Deploy File Gateway, create S3 bucket, mount and copy archival files.
  5. Verify objects in S3 and validate DMS replication consistency before cutover.
Verification
Compare row counts and checksums, confirm application queries on the target, and ensure S3 objects match your local files.
CLI template reminder
Use the example commands to create replication instances and endpoints; replace placeholders with your ARNs and endpoints. Always test connectivity first.
Key Takeaway

Execute the lab in a test account, validate every step, and update your migration playbook with any discovered edge cases.
