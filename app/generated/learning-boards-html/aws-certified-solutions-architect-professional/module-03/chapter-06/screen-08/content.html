Backup plan JSON and CLI steps
<backup-plan.json> { "BackupPlan": { "BackupPlanName": "DailyRDSBackupPlan", "Rules": [ { "RuleName": "DailyRDSBackupRule", "TargetBackupVaultName": "MyRDSDrVault", "ScheduleExpression": "cron(0 5 ? * * *)", "StartWindowMinutes": 60, "CompletionWindowMinutes": 480, "Lifecycle": { "DeleteAfterDays": 7 }, "CopyActions": [ { "DestinationBackupVaultArn": "arn:aws:backup:us-west-2:123456789012:backup-vault:MyRDSDrVaultWest", "Lifecycle": { "DeleteAfterDays": 30 } } ] } ] } }
Use the CLI to create vaults, create the plan, and attach resources. Verify IAM role for backup service to perform copy actions and KMS permissions if encrypted.
Operational Notes
Create destination vault in DR region first. Then run create-backup-plan and put-backup-selection with the RDS ARN. Monitor jobs and test restores.
Common mistake
Forgetting to grant the AWS Backup service role permissions to copy snapshots across regions or to use the destination KMS key.
