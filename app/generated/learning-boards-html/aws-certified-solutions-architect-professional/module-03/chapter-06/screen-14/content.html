Module 3 › Chapter 3.6 › Security & Governance
Best practices
Encryption, IAM, and auditability
Use KMS keys for vault and S3 encryption, restrict backup and restore operations to minimal roles, and ensure cross-account key grants when copying backups between accounts.
Audit and alert
Log backup jobs and vault access; alert on failed copy actions or unauthorized vault changes.
Object Lock & compliance
Enable WORM for records that must be immutable and ensure retention windows meet legal requirements.
Operational checks
  • Validate IAM roles for Backup and EC2 AMI copy tasks
  • Test cross-region KMS grants
  • Include access and key recovery in DR playbooks
Pitfall

Misconfigured KMS permissions can quietly prevent restores; verify key access during drills, not just in setup.
