Architecture
Pilot Light for EC2 + RDS
Keep a read replica of the RDS database and copy AMIs to the DR region. Pre-create networking, IAM roles, and minimal services to speed failover.
Pre-provisioned items
  • VPC, subnets, routing, and security groups
  • IAM roles for instances and backup operations
  • Target groups and load balancer configuration
DR runtime actions
  • Promote read replica to primary
  • Launch EC2 instances from copied AMIs
  • Update DNS and scale application servers
Example
RDS read replica in us-west-2; AMI copy scheduled nightly. During a disaster promote the replica and launch two t3.medium instances from the latest AMI.
Common mistake
Failing to replicate secrets or parameter store values to the DR region; application fails even when database and AMIs are available.
Pro tip

Automate AMI copies and store the latest AMI ID in a central location accessible to DR runbooks.
