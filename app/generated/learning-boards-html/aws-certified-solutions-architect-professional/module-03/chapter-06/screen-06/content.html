Process
Backup & Restore
Define plan, assign resources, confirm vault and IAM, run regular restores. Ensure AMIs and DB snapshots are available and documented.
Runbook excerpt — restore
  1. Restore DB from latest backup into available subnet.
  2. Launch EC2 instances from latest AMI and attach configuration.
  3. Update DNS to point to new load balancer and validate traffic.
  4. Run smoke tests and validate data consistency.
Example
Daily RDS snapshot restored to a new instance and AMIs used to recreate web servers. Typical RTO: several hours.
Process
Pilot Light
Keep a read replica and copied AMIs in the DR region. Maintain minimal networking and IAM so scaling up is quick.
Runbook excerpt — pilot light promotion
  1. Promote cross-region RDS read replica to standalone primary.
  2. Launch EC2 instances from copied AMI and attach to target group.
  3. Update application configuration or secret store with new DB endpoint.
  4. Switch DNS and scale application as needed.
Example
Promote a read replica in us-west-2 and run two EC2 instances from an AMI copy; DNS cutover reduces RTO to tens of minutes in practiced runs.
