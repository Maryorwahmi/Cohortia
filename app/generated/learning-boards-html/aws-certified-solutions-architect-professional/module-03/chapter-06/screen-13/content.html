Module 3 › Chapter 3.6 › Hands-on Pilot Light
Checklist
Tasks to prepare and test Pilot Light
  1. Create backup vault in DR region and configure KMS keys.
  2. Create backup plan with CopyActions to the DR vault and assign RDS resource ARNs.
  3. Schedule AMI creation for EC2 and automate AMI copying to DR region.
  4. Create cross-region read replica of the RDS instance in DR region.
  5. Pre-provision VPC, subnets, security groups, and IAM roles in DR region.
  6. Run a promotion and launch drill and measure timings against RTO/RPO.
CLI snippets
# Create DR vault in us-west-2 aws backup create-backup-vault --backup-vault-name MyRDSDrVaultWest --region us-west-2 # Copy an AMI to us-west-2 (after creating it in us-east-1) aws ec2 copy-image --source-image-id --source-region us-east-1 --name "my-webapp-ami-us-west-2" --destination-region us-west-2 --encrypted # Create cross-region read replica (RDS) aws rds create-db-instance-read-replica --db-instance-identifier my-webapp-db-dr --source-db-instance-identifier my-webapp-db --db-instance-class db.t3.medium --region us-west-2 --no-publicly-accessible
Verify permissions for the backup role and KMS keys, then run a full drill to validate RTO meets the 30-minute target.
