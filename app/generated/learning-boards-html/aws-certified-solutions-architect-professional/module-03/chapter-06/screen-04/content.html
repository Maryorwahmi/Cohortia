Module 3 › Chapter 3.6 › AWS Backup
Definition
AWS Backup explained
A centralized service to schedule backups, enforce retention, and copy backups across regions and accounts for many AWS resources.
Core features:
  • Policy-based backup plans and vaults
  • Lifecycle transitions and retention
  • Cross-region and cross-account copy actions
  • Centralized auditing and compliance
Concrete example
Daily RDS backups to a local vault retained 7 days with a copy to a us-west-2 vault retained 30 days for DR.
Key Takeaway

Centralized backup plans reduce human error and ensure consistent lifecycle and cross-region protection when tested regularly.

Process flow
From policy to cross-region copy
Step-by-step
  1. Define a Backup Plan with ScheduleExpression and Lifecycle rules.
  2. Create or select a Backup Vault and configure encryption and IAM role permissions.
  3. Assign resources to the plan using resource ARNs and selection rules.
  4. Configure CopyActions to a secondary region or account and set retention for the copy.
  5. Regularly test restores and audit backup completion and vault metrics.
Common mistake
Relying on ad-hoc snapshots without lifecycle or cross-region copies; this leaves gaps for compliance and regional failures.
