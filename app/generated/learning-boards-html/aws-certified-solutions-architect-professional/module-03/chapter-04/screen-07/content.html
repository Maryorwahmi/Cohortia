Module 3 › Chapter 3.4 › AWS Glue
Glue Data Catalog
A central metadata repository used by Glue, EMR, Athena, and Redshift Spectrum. Crawlers inspect files and create table definitions automatically.
Glue ETL
Serverless Spark jobs written in Python (PySpark) or Scala that Glue runs without exposing the underlying cluster to you.
Practical example
Firehose writes parquet to S3. A Glue crawler creates a table. A Glue ETL job converts raw records into a curated table partitioned by date.
When to choose Glue
Event-driven ETL, schema inference, and lower operational overhead for Spark transformations.
When EMR is better
Long-running clusters, heavy tuning, custom versions, or frameworks not supported serverlessly.
Key Takeaway
Glue reduces operational burden with a central catalog and serverless ETL, but EMR is the choice for full control and advanced tuning.
