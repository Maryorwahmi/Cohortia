Module 3 › Chapter 3.4 › Spot & Fleets
Spot Instances
Offer deep discounts but can be interrupted. Use them for task nodes or stateless work that tolerates eviction.
Instance Fleets
Define multiple instance types and Spot/On-Demand allocation strategies per node role. Fleets improve capacity acquisition and resilience by allowing the cluster to accept different types when defaults are unavailable.
Pitfall
Placing critical storage on Spot-backed core nodes without replication risks data loss if instances are reclaimed. Use Spot primarily for replaceable compute.
Example configuration
Task fleet with three instance types, 80% Spot allocation, and fallback On-Demand to ensure capacity during spikes.
Managed scaling
Automatically adjusts the number of instances based on workload metrics, reducing over-provisioning risk.
