Module 3 › Chapter 3.4 › Kinesis Firehose
What Firehose does
Buffer, batch, compress, and deliver streaming records to destinations without writing consumer code.
Buffering & conversion
Set buffering hints such as a buffer interval of 60 seconds and enable data format conversion to produce parquet files from JSON input before delivery to S3.
Use case
Deliver raw events to an S3 data lake with Parquet conversion so downstream analytics and Glue crawlers can operate efficiently on columnar data.
Example setup
Firehose with a 60-second buffer, Parquet conversion enabled, and an S3 prefix partitioned by timestamp tokens.
Common mistake
Expecting full ordering semantics for multi-consumer processing. Use Data Streams when strict ordering across consumers is required.
Key Takeaway
Firehose is the right choice for managed, schema-converted delivery to analytic sinks with minimal operational overhead.
