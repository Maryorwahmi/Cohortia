Module 3 › Chapter 3.4 › Lab Overview
Hands-on Activity
Set up a real-time ingestion pipeline and validate batch analytics using Glue and EMR.
Step 1 — Kinesis
Create MyLogStream with shard-count 2 and simulate producers to push log events for validation.
Step 2 — Firehose
Create a delivery stream MyLogFirehose that writes to an S3 bucket with buffering set to 60 seconds and Parquet conversion enabled.
Step 3 — Glue Crawler
Run a crawler against the Firehose S3 prefix to populate the Glue Data Catalog database and table.
Step 4 — EMR
Launch an EMR cluster with Spark and configure it to use the Glue Data Catalog as the metastore; enable managed scaling and Spot where appropriate.
Step 5 — Run ETL
Upload the provided PySpark script, run it as a Spark step on EMR, and verify aggregated output in S3.
Safety check
Ensure IAM roles allow Firehose, Glue, and EMR access to the S3 bucket and that your test data is small when first validating the pipeline.
