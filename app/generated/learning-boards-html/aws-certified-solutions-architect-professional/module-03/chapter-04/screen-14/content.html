Key Concepts
Remember these concise definitions.
Amazon EMR
A managed cluster platform to run Hadoop, Spark, Hive, Presto, and Flink with full control for tuning and frameworks.
AWS Glue
Serverless ETL and a central Data Catalog for schema discovery and metadata management across the data lake.
Amazon Kinesis
A suite for streaming: Data Streams for ordered ingestion, Firehose for delivery, and Data Analytics for continuous processing.
Summary takeaway
Design pipelines combining streaming for immediacy and S3 + Glue + EMR for historical analytics, and tune instance choices to match workload characteristics.
