Learning Objectives
Skills to design, run, and optimize big data systems on AWS.
Bloom: Learn → Understand → Apply → Master
01
Design EMR pipelines
Choose frameworks, instance types, and cluster patterns to meet scale and latency requirements. Practice matters because compute selection directly affects performance and cost.
VERIFIED COMPETENCY MILESTONE
02
Use Glue ETL & Data Catalog
Run serverless Spark jobs, build crawlers to infer schema, and maintain a central catalog for downstream analytics. This reduces operational burden and makes datasets discoverable.
VERIFIED COMPETENCY MILESTONE
03
Architect Kinesis streaming
Configure Kinesis Data Streams, Firehose, and Data Analytics for ordered ingestion, durable delivery, and continuous queries. This enables real-time dashboards and anomaly detection.
VERIFIED COMPETENCY MILESTONE
04
Optimize cost & performance
Use Spot Instances, instance fleets, and managed scaling to reduce cost while maintaining resilience. Monitoring and right-sizing are essential to avoid throttling or wasted spend.
VERIFIED COMPETENCY MILESTONE
