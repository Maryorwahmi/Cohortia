Pipeline steps
Devices / Producers
Kinesis Data Streams
Kinesis Data Analytics / Lambda
Firehose → S3
Glue crawlers pick up new parquet objects in S3 and populate the Data Catalog. EMR reads the Glue catalog to run complex batch analytics and writes refined parquet back to S3 for reporting.
Real-time path
Kinesis Data Streams → Data Analytics or Lambda for alerts and live dashboards.
Batch path
Firehose delivers to S3 → Glue crawler → EMR jobs for deep aggregation and ML training.
Example
IoT telemetry streams from devices. Use Data Analytics to compute rolling averages, and Firehose to create columnar files for historical analysis.
Mistake to avoid
Treating this as a single system. Design separately for real-time SLA and batch throughput and instrument both paths independently.
Key Takeaway
Design hybrid pipelines: use streaming for immediacy and S3 + Glue + EMR for deep, cost-effective analytics on historical data.
