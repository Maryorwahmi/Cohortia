Module 3 › Chapter 3.3 › S3 Data Lake Design
Organize using logical prefixes
Use folders that match common queries: year, month, day, region, etc.
Example prefix: s3://my-clickstream-data/year=2023/month=01/day=01/clicks.parquet. This structure enables partition pruning by query engines.
Format choice
Prefer Parquet or ORC for analytics because they are columnar and compress efficiently.
Lifecycle & security
Apply lifecycle policies to move cold data to cheaper classes and always encrypt at rest and in transit.
Pitfall

A flat unpartitioned bucket causes full scans and high query cost. Partition by typical query filters to avoid that.

Key Takeaway

Logical organization and columnar formats are the fastest, most cost-effective design for S3 analytics.
