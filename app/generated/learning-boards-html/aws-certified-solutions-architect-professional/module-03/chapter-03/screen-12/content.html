Glue Data Catalog & Crawlers
Crawlers infer schema from S3 and populate the Catalog for discoverability.
Verify crawled schemas, adjust column types if needed, and ensure partitions are recognized properly before querying from Athena or Spectrum.
# Example: create a Glue crawler (CLI pattern)
aws glue create-crawler \
  --name clickstream-data-crawler \
  --role arn:aws:iam::123456789012:role/GlueServiceRole \
  --database-name clickstream_db \
  --targets '{"S3Targets":[{"Path":"s3://<YOUR_CLICKSTREAM_BUCKET>/year=2023/"}]}' \
  --schedule "cron(0 0 * * ? *)"

# Then start the crawler
aws glue start-crawler --name clickstream-data-crawler
Glue ETL
Use Glue ETL jobs to convert, clean, and partition data into Parquet for efficient analytics.
Practical Tip

Run crawlers after ingest, then use ETL jobs to standardize formats and push curated data into sinks or partitioned folders.
