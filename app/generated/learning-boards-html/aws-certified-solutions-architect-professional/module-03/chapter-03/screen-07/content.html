Module 3 › Chapter 3.3 › Distribution Styles
Distribution styles explained
AUTO — Let Redshift pick; good starting point for many tables.
KEY — Colocate rows with same key; great for frequent joins on that key.
ALL — Copy small tables to every node; avoids shuffles for stable dimensions.
EVEN — Uniform distribution; use when joins are rare or key would skew.
Example
A clicks table joined on user_id benefits from KEY distribution on user_id to reduce data movement during joins with users.
Decision flow
  1. Identify frequent join columns and table sizes.
  2. If a large table is frequently joined on a stable key, consider KEY distribution.
  3. If a small table is often joined, use ALL to avoid shuffles.
  4. If no good key exists, or to avoid skew, use EVEN or AUTO.
Pitfall

Choosing a KEY that causes data skew concentrates load on a few slices and slows queries. Analyze distribution of key values before applying KEY distribution.
