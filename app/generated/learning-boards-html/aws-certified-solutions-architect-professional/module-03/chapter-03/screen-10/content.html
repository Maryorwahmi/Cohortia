Code pattern: create external schema
Use an IAM role that has access to S3 and the Glue Data Catalog, then create the external schema once the catalog is populated by a crawler.
-- Create an external schema in Redshift
CREATE EXTERNAL SCHEMA clickstream_spectrum
FROM DATA CATALOG
DATABASE 'clickstream_db'
IAM_ROLE '<YOUR_REDSHIFT_IAM_ROLE_ARN>'
CREATE EXTERNAL DATABASE IF NOT EXISTS;

-- Verify the external table
SELECT * FROM clickstream_spectrum.clicks LIMIT 10;

-- Example join with an internal Redshift table
SELECT s.user_id, s.sale_date, c.page_url, c.event_time
FROM sales s
JOIN clickstream_spectrum.clicks c ON s.user_id = c.user_id
WHERE s.sale_date = '2023-01-01' AND c.event_time >= '2023-01-01T00:00:00Z'
LIMIT 10;
Practical notes
  • Use Parquet or ORC for smaller scans and faster reads.
  • Partition S3 by common filters like year/month to avoid full scans.
  • Verify Glue table schemas before querying from Redshift.
Key Takeaway

Spectrum gives you the flexibility to query S3 in place, but plan formats and partitions to control performance and cost.
