Data Warehousing and Lake Solutions
Design analytics platforms that balance performance, cost, and governance using Redshift and S3.

In this chapter you'll compare warehouses and lakes, learn Redshift operational choices like RA3, distribution and sort keys, and implement a workflow connecting S3 data to Redshift via Spectrum and Glue.

In this lesson

AWS Glue & Lake Formation
Metadata, crawlers, ETL, and centralized access control.
Redshift Spectrum
Query S3 data in place using Glue Data Catalog tables.

How the pieces connect
Data flow snapshot
Raw events land in S3. Glue crawlers register schemas. Redshift queries S3 via Spectrum or loads curated tables for fast BI.
Common optimization
Partition S3 data by filters like year/month, choose distribution keys in Redshift based on join patterns, and use RA3 to right-size compute.

Redshift tuning

Metadata & security
