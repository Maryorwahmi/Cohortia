Learning Objectives
Targets for design, optimization, metadata, and governance
Learn → Understand → Apply → Master
01
Design scalable Redshift
Choose instances and layout for performance. Practice right-sizing compute and storage to control cost and meet SLAs.
VERIFIED COMPETENCY MILESTONE
02
Use RA3 & Concurrency Scaling
Scale storage independently and handle query bursts with temporary capacity. This helps avoid over-provisioning base clusters.
VERIFIED COMPETENCY MILESTONE
03
Build an S3 data lake
Organize and partition raw data to reduce scan costs for Athena and Spectrum and speed exploratory queries.
VERIFIED COMPETENCY MILESTONE
04
Manage metadata & access
Use Glue Data Catalog for discoverability and Lake Formation for table, column, and row-level permissions across analytics services.
VERIFIED COMPETENCY MILESTONE
Each milestone maps to a hands-on task: create an S3 partitioned dataset, run a Glue crawler, configure Spectrum, and define Lake Formation permissions.
