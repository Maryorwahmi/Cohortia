Amazon Aurora: Cloud-Native Relational Design
Distributed storage, compute separation, and near-zero replica lag.
Architecture highlights
  • Storage replicates six copies across three AZs for durability and fault tolerance.
  • Compute instances attach to shared storage, allowing many readers without data copies.
  • Supports up to 15 read replicas that access the same storage for near-zero lag.
Practical example
A reporting tier that requires up-to-the-second read accuracy benefits from Aurora replicas because they reflect committed transactions quickly. This reduces application logic to reconcile stale views.
Common misconception
Treating Aurora replicas the same as RDS read replicas. Aurora uses shared storage so replication characteristics differ.
