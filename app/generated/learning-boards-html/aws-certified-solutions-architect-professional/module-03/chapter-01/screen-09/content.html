Performance Tuning: Queries, Indexes, and Monitoring
Measure, tune, and validate changes to avoid regressions.
Monitoring checklist
  • Use Performance Insights to find top SQL by load.
  • Check CloudWatch for CPU, IOPS, and connection counts.
  • Track long-running transactions and lock waits.
Tuning actions
  • Add targeted indexes to avoid table scans for frequent filters.
  • Consider connection pooling to reduce session overhead before scaling instances.
  • Measure write impact after adding indexes to avoid slowing critical DML.
Example
Replacing a table scan with an index reduced average query time from seconds to milliseconds for a reporting endpoint.
