Code Walkthrough
CLI snippet (create table & GSI)
# Create UserProfile table (us-east-1)
aws dynamodb create-table \
  --table-name UserProfile \
  --attribute-definitions AttributeName=userId,AttributeType=S AttributeName=email,AttributeType=S \
  --key-schema AttributeName=userId,KeyType=HASH \
  --billing-mode PROVISIONED \
  --provisioned-throughput ReadCapacityUnits=5,WriteCapacityUnits=5 \
  --region us-east-1

# Add GSI for email
aws dynamodb update-table \
  --table-name UserProfile \
  --attribute-definitions AttributeName=email,AttributeType=S \
  --global-secondary-index-updates '[{"Create":{"IndexName":"EmailIndex","KeySchema":[{"AttributeName":"email","KeyType":"HASH"}],"Projection":{"ProjectionType":"ALL"},"ProvisionedThroughput":{"ReadCapacityUnits":5,"WriteCapacityUnits":5}}}]' \
  --region us-east-1
Enable Streams, TTL, and Global Table
# Enable Streams
aws dynamodb update-table --table-name UserProfile --stream-specification StreamEnabled=true,StreamViewType=NEW_AND_OLD_IMAGES --region us-east-1

# Configure TTL
aws dynamodb update-time-to-live --table-name UserProfile --time-to-live-specification Enabled=true,AttributeName=lastActive --region us-east-1

# Switch to ON_DEMAND before globalization
aws dynamodb update-table --table-name UserProfile --billing-mode ON_DEMAND --region us-east-1

# Add replica (example: eu-west-1)
aws dynamodb update-table --table-name UserProfile --replica-updates '[{"Create":{"RegionName":"eu-west-1"}}]' --region us-east-1

Key Takeaway

Follow sequence: create table, add GSI, enable Streams & TTL, switch billing, create replica, validate replication with a test write.
