Definition
Partition key and Sort key
Partition key maps items to storage partitions and affects throughput distribution. Sort key orders items within a partition for range queries.
Example
Orders table: Partition key = customerId, Sort key = orderTimestamp to query recent orders for a customer.
Misconception: A natural key always balances partitions. Reality: Some natural keys are skewed; measure cardinality and request distribution and consider composite keys if necessary.
Validation & monitoring
  • Check consumed capacity per partition
  • Use CloudWatch metrics for throttling and hot keys
  • Consider write throttling as an indicator of key skew
Sharding technique
If one key is too hot, add a random suffix or shardId to the partition key to distribute writes across partitions, then handle aggregation in reads where needed.
Key Takeaway

Pick partition keys for even distribution and sort keys for ordered intra-partition queries; validate with metrics.
