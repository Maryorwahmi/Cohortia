Definition
S3 Intelligent‑Tiering
Automatically monitors access and moves objects between frequent and infrequent tiers. Ideal for datasets with unknown or changing read patterns.
When to use
Data lakes, logs with uncertain access, or any bucket where manual tiering is costly to maintain.
Why it matters
Reduces administrative overhead and can lower cost without manual lifecycle rules for unpredictable data.
Key Takeaway

Use Intelligent‑Tiering when access patterns are unknown; monitor the automation fee and combine with lifecycle rules for deep archival.

Concrete scenario
A data science team stores many feature sets and experiment outputs. Access is sporadic. Intelligent‑Tiering automatically keeps commonly used features hot and moves stale outputs to a cheaper tier without manual rules.
Misconception
It does not replace Glacier for long-term archival. Use lifecycle rules for tiering into Glacier classes for long retention.
Operational note (example)
Enable Intelligent-Tiering at object upload and review monthly monitoring charges versus savings.
