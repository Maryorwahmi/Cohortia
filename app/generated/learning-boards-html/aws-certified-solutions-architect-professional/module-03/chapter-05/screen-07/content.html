Save and apply lifecycle policy
# Save lifecycle policy to a file
cat << EOF > lifecycle-policy.json
{
    "Rules": [
        {
            "ID": "LogRetentionPolicy",
            "Prefix": "logs/",
            "Status": "Enabled",
            "Transitions": [
                { "Days": 30, "StorageClass": "STANDARD_IA" },
                { "Days": 90, "StorageClass": "GLACIER" }
            ],
            "Expiration": { "Days": 365 },
            "NoncurrentVersionExpiration": { "NoncurrentDays": 7 }
        }
    ]
}
EOF

# Apply policy
aws s3api put-bucket-lifecycle-configuration \
    --bucket my-company-data \
    --lifecycle-configuration file://lifecycle-policy.json \
    --region us-east-1
Verification steps
  • Upload test objects to logs/ and check object storage-class metadata after 35 and 95 days (or simulate).
  • Use S3 Storage Lens or CloudTrail events to observe transitions and API calls.
  • If unexpected, disable or update the rule and review CloudTrail for who changed it.
Key Takeaway

Use CLI for repeatable application of lifecycle policies, but verify on sample objects and monitor results before broad rollout.
