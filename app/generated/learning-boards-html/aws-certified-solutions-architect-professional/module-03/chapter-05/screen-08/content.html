Definition
Object Lock & Versioning
Object Lock enforces WORM retention; Versioning preserves multiple versions for recovery. Together they meet regulatory immutability needs.
Governance vs Compliance mode
Governance allows certain privileged users to alter retention; Compliance prevents all alterations until retention expires.
Bucket creation note
Object Lock must be enabled when creating the bucket. If the bucket lacks it, create a new one for immutable archives.
Key Takeaway

Plan object lock at bucket creation and enable versioning to maintain immutable object history for compliance.

Concrete example
For archives/ set default retention to 7 years in Governance mode. If regulators require stronger protection, use Compliance mode and apply legal holds only when legally necessary.
Example: apply default retention
{
    "ObjectLockEnabled": "Enabled",
    "Rule": {
        "DefaultRetention": {
            "Mode": "GOVERNANCE",
            "Days": 2555
        }
    }
}
Misconception
You cannot enable Object Lock after bucket creation. If you need WORM, create a new Object Lock enabled bucket and migrate objects carefully.
