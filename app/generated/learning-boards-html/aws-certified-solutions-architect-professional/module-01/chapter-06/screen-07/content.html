Module 2 › Chapter 1.6 › Guardrails
Preventive

Preventive guardrails use Service Control Policies to block specific actions across accounts. Use them when an operation must be disallowed everywhere, such as preventing public S3 buckets.

Example
An SCP can deny s3:PutBucketAcl to prevent granting public access.
When to use
Use preventive guardrails for actions you must never allow, to reduce the attack surface at the organization level.
Detective

Detective guardrails use AWS Config rules to detect non-compliance and generate alerts. They are useful when you need visibility and remediation workflows rather than absolute prevention.

Example
A Config rule can flag unencrypted EBS volumes for remediation or alerting.
Misconception
Guardrails are not a replacement for resource-level policies and templates; combine them for layered security.
