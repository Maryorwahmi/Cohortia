What Control Tower automates
  • Initial Organizations setup and OU structure.
  • Centralized logging and baseline network settings.
  • Guardrails implemented as preventive SCPs and detective Config rules.
Practical note
Use Control Tower to reduce setup time, then extend with StackSets where you need specific IAM roles or extra logging configurations.
Account Factory
Account Factory is a self-service mechanism for teams to request pre-configured accounts that automatically inherit baselines and guardrails.
Guardrails
Guardrails are high-level rules. Preventive guardrails use Service Control Policies to block actions; detective guardrails use AWS Config to detect and alert on non-compliance.
