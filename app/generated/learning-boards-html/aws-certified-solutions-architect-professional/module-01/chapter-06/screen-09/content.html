Module 2 › Chapter 1.6 › Security Auditor Template
Purpose

This template creates an IAM role for security auditing in member accounts. When deployed via StackSets it ensures the role exists everywhere you target.

Important
Replace the placeholder principal with your audit account ARN for production. Provide CAPABILITY_NAMED_IAM during StackSet creation.
Key fields
  • RoleName and AssumeRolePolicyDocument
  • ManagedPolicyArns (SecurityAudit, ReadOnlyAccess)
  • Outputs exposing the role ARN
Template (security-auditor-role.yaml)
<?yaml>AWSTemplateFormatVersion: '2010-09-09' Description: IAM Role for Security Auditors in member accounts. Resources:   SecurityAuditorRole:     Type: AWS::IAM::Role     Properties:       RoleName: CohortiaSecurityAuditorRole       AssumeRolePolicyDocument:         Version: '2012-10-17'         Statement:           - Effect: Allow             Principal:               AWS: !Sub 'arn:aws:iam::${AWS::AccountId}:root' # Replace with your Audit Account ID for production             Action:               - sts:AssumeRole       ManagedPolicyArns:         - arn:aws:iam::aws:policy/SecurityAudit         - arn:aws:iam::aws:policy/ReadOnlyAccess       Description: Provides read-only and security audit access to the account. Outputs:   SecurityAuditorRoleArn:     Description: The ARN of the Security Auditor Role.     Value: !GetAtt SecurityAuditorRole.Arn</?yaml>
