Module 2 › Chapter 1.6 › StackSet CLI
Create the StackSet
aws cloudformation create-stack-set \
  --stack-set-name Cohortia-SecurityAuditorRole-StackSet \
  --template-body file://security-auditor-role.yaml \
  --capabilities CAPABILITY_NAMED_IAM \
  --permission-model SERVICE_MANAGED \
  --auto-deployment Enabled=true,RetainStacksOnAccountRemoval=false \
  --stack-set-description "Deploys Security Auditor Role to all member accounts"
This command defines the StackSet and enables automatic deployment to new accounts when auto-deployment is set.
Create stack instances
aws cloudformation create-stack-instances \
  --stack-set-name Cohortia-SecurityAuditorRole-StackSet \
  --deployment-targets OrganizationalUnitIds='ou-xxxxxxxx' \
  --regions us-east-1 us-west-2
Target the correct OU and regions. Verify the OU ID and that the accounts have permission to accept the StackSet if not service-managed.
Safety checklist
  • Test template in a non-production OU.
  • Confirm CAPABILITY_NAMED_IAM is present for IAM resources.
  • Verify cross-account resources like central buckets exist and accept writes.
