Module 1 › Chapter 1.3 › Assigning permission sets
Process

Create → Assign → Provision

Assignment targets a user or group for a chosen account and permission set. Identity Center then provisions a role to enable the access.
Workflow
  1. Enable Identity Center and select identity source.
  2. Create user dev_user and group Developers.
  3. Create ReadOnlyAccess permission set.
  4. Assign Developers to DevAccount-001 with ReadOnlyAccess.
Example result
dev_user logs in and chooses DevAccount-001 with the ReadOnly role visible in the portal.
Pro tip
Prefer group assignments
Assigning permission sets to groups simplifies onboarding and offboarding.
Common mistake
Assigning broad permission sets across many accounts without periodic review increases exposure.
