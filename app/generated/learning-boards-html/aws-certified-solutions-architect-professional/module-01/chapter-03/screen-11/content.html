Best Practices

Integrate, minimize, enforce

Integration with IdP, least privilege in permission sets, and enforced MFA form the core of a secure centralized identity strategy.
Integrate IdP
Use Azure AD or other SAML IdPs so corporate lifecycle events handle onboarding and offboarding.
Least privilege
Start with ReadOnlyAccess and add permissions as required to avoid over-permissioning.
MFA & audits
Enforce MFA and use CloudTrail to regularly review sign-ins and permission set assignments.
Concrete action
Schedule quarterly access reviews
Review group membership, assigned permission sets, and CloudTrail events to ensure compliance with least privilege.
Key Takeaway

Security is operational: integrate identity, constrain permissions, enforce MFA, and audit regularly.
