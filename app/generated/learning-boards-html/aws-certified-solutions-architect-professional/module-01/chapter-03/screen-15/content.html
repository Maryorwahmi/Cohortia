Module 1 › Chapter 1.3 › Mistakes & Assessment
Common mistakes
  • Not integrating an external IdP and duplicating identities.
  • Over-permissioning permission sets instead of starting from ReadOnlyAccess.
  • Failing to enforce MFA for elevated users.
  • Using Identity Center for programmatic access when manual roles are appropriate.
Assessment ideas
  1. Describe steps to grant AdministratorAccess to an Azure AD user via Identity Center.
  2. Given an environment inventory, mark which identities should be centralized and which should remain manual roles.
  3. Perform the lab to create ReadOnlyAccess and demonstrate the user can assume the role in DevAccount-001.
Concrete check
Verify provisioning events
Use CloudTrail to confirm assignment events and role creation in the member account.
Reflective prompt
How will you balance centralized human access with necessary programmatic cross-account roles?
