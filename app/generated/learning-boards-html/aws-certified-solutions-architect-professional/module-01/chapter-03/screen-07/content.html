Module 1 › Chapter 1.3 › Permission sets
Definition

Reusable permission templates

Permission sets define the maximum permissions a user can assume in a target account and are versioned centrally.
Example
ReadOnlyAccess assigned to the Developers group for DevAccount-001 so members can view resources without editing.
Pro tip
Start with ReadOnlyAccess and add permissions incrementally to follow least privilege.
Key Takeaway

Permission sets let you author permissions once and reuse them across accounts, reducing policy drift.

Mapping
When you assign a permission set to a user or group for an account, Identity Center provisions an IAM role in the member account that enforces the permission set.
Analogy
Permission set = role template
Check
Does this set follow least privilege?
