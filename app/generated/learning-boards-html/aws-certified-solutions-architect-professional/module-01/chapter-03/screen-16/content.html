Module 1 › Chapter 1.3 › Key Concepts
AWS IAM Identity Center
Central SSO and access control plane that automates cross-account role provisioning.
Identity Provider (IdP)
System that authenticates users; integrate to avoid duplicate identities and centralize lifecycle.
Permission Set
A reusable collection of IAM policies that determines the maximum permissions in a target account.
Summary
Centralize human access with Identity Center, prefer external IdP integration, assign least-privilege permission sets, enforce MFA, and audit with CloudTrail.
