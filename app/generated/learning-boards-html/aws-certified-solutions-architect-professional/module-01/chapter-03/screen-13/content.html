Step-by-step

Enable Identity Center and create dev_user

Follow the checklist to enable the service, choose the internal directory for the lab, create a user, and create a Developers group.
# Management account: enable Identity Center
# Console: Navigate to IAM Identity Center and click Enable

# Choose identity source: AWS IAM Identity Center directory (for lab)

# Create user (console steps):
# Users → Add user → Username: dev_user, Email: dev_user@example.com → Add user

# Create group: Groups → Create group → Name: Developers → Create
# Add dev_user to Developers group
Confirm the invitation email is queued and that the user appears in the console. If you integrated an external IdP you would sync instead of creating internal users.
Concrete check
dev_user appears in Users list
Verify email invitation and group membership before proceeding to permission sets.
Key Takeaway

Enabling Identity Center and creating a user are preparatory steps; permissions are assigned next to provision roles in member accounts.
