Module 1 › Chapter 1.3 › Identity Source
Process

Decide and map groups to permission sets

Map corporate groups to permission sets to scale assignments. External IdP integration reduces duplication and improves lifecycle control.
Step 1 — Choose
Internal directory to start quickly or external IdP for enterprise governance.
Step 2 — Map
Define which corporate groups map to which permission sets such as Developers or SecurityAuditor.
Example
Azure AD to Identity Center
Synchronize users and groups from Azure AD so employees sign in with corporate accounts and group membership drives permission set assignments.
Misconception
Assuming integration is optional for governance. In enterprises, integration is key to avoid duplicated identity management and to automate lifecycle events.
