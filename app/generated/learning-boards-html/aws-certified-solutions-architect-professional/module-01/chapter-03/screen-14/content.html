Step-by-step

Create permission set and assign

Create a ReadOnlyAccess permission set, then assign it to the Developers group for DevAccount-001 and verify provisioning.
# Console steps:
# Permission sets → Create permission set → Predefined permission set → ReadOnlyAccess → Create

# AWS accounts → Select DevAccount-001 → Assign users or groups
# Select Groups → Developers → Next → Choose ReadOnlyAccess → Submit

# Wait for provisioning; then test:
# Open IAM Identity Center portal URL, login as dev_user, click DevAccount-001 → Select ReadOnlyAccess role
If the role does not appear immediately, allow a short provisioning interval and re-check the member account's IAM roles for the new role that references Identity Center in its trust policy.
Concrete test
dev_user can assume ReadOnlyAccess
Confirm the portal lists the account and that console navigation is allowed but edits are blocked.
Key Takeaway

This assignment completes the path from central policy to enforced role in the member account; validate behavior in the portal to confirm success.
