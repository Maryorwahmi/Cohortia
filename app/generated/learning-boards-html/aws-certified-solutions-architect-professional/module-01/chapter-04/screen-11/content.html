Module 1 › Chapter 1.4 › Hands-on: Cost Explorer & Budget
Checklist
  1. Log in to the AWS Organizations management account and open Cost Explorer.
  2. Set date range to last month, filter by Development OU accounts, group by service to find top spenders.
  3. Export results if you need to share with finance.
  4. Open Budgets, create MonthlyOrgCostBudget, set amount to 10 USD for a test, and add an Actual alert at 80%.
  5. Add recipients (finance and engineering) and confirm SNS/email delivery in a test.
Example Budget Spec
{
  "BudgetName": "MonthlyOrgCostBudget",
  "Period": "Monthly",
  "BudgetType": "Cost",
  "BudgetLimit": {"Amount": 10, "Unit": "USD"},
  "Alert": {"Type": "Actual", "ThresholdPercent": 80}
}
Key Takeaway

Use a small test budget and a scoped Explorer query to validate alerts and tagging before wider rollout.
