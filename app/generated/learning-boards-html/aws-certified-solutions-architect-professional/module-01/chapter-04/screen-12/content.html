Module 1 › Chapter 1.4 › Cleanup & Monitoring
Common idle resources
Look for unattached EBS volumes, old snapshots, unused Elastic IPs, idle load balancers, and development environments left running.
Audit process
Use Cost Explorer to find cost spikes, map costs to resource tags, notify owners, and apply lifecycle rules or deletions after a grace period.
Automation
Schedule non-production resources to run only during business hours and use automated policies to clean expired test environments.
Example rule
Tag test resources with a TTL tag and run a daily process that emails owners when resources reach the expiry date; remove after a defined grace period.
Key Takeaway

Combine explorer signals, tags, and automation to safely remove idle resources and reduce recurring costs.
