Module 1 › Chapter 1.2 › Learning Objectives
Build modular SCPs
Break large policy requirements into smaller SCPs so each rule can be tested and versioned independently.
Mnemonic: small rules reduce blast radius.
VERIFIED COMPETENCY MILESTONE
Use Condition keys
Apply aws:RequestedRegion, resource name patterns, or principal ARNs to scope Deny statements precisely.
Example: deny any region not in an allowlist using aws:RequestedRegion.
VERIFIED COMPETENCY MILESTONE
Test in a sandbox OU
Validate SCP behavior in a non-production OU before broad application to avoid service disruption.
Testing steps: attach, attempt blocked action, verify "Access Denied", detach.
VERIFIED COMPETENCY MILESTONE
Keep a break-glass plan
Ensure a recoverable management path if an SCP causes an unintended lockout, and never deny organizations management actions at root without caution.
Have an emergency role or process to detach harmful SCPs quickly.
