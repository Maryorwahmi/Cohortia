Definition
Management Account
Creates the organization, controls consolidated billing, and applies top-level governance. Treat this account with highest security.
Definition
Organizational Units (OUs)
Logical groupings that inherit policies. Use OUs to map environments, functions, or business units and apply SCPs.
Definition
Member Accounts
Individual AWS accounts that belong to the organization. Prefer creating accounts via Organizations for a clean baseline.
Concrete example
Create a Security OU that holds a centralized logging account and a Workloads OU for application accounts. Apply an SCP to the Security OU that prevents removal of logging exports, and apply environment-specific SCPs in Workloads for additional restrictions.
