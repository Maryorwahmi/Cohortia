Process

Create Organization — Steps

  1. Log in to the designated management account with organizations:* permissions.
  2. Open AWS Organizations and click Create organization.
  3. Enable All features to unlock SCPs and advanced capabilities.
  4. Create top-level OUs such as Workloads and Security.
  5. Decide whether to create new accounts or invite existing ones.
Console-style walkthrough (terminal demo style)
> Sign in as management account user
> Open Organizations console
> Click Create organization
> Choose: Enable all features
> Create OU: Workloads
> Create OU: Security
Why this matters

Enabling all features and defining OUs up front ensures you can apply the governance model immediately and avoid inconsistent account setups later.
