Invite

Invite existing account

Good for migrating legacy accounts that already contain resources. Requires acceptance and may bring inconsistent configurations.
When to use: migrating an existing project with active resources; short-term consolidation needs.
Create

Create new account

Recommended when you need a clean baseline. The management account controls lifecycle and policies from creation.
When to use: provisioning new environments, applying governance at account creation, establishing clear ownership.
Example decision
If a team requests a new account for a new project, create it via Organizations. If a long-running account needs consolidation, plan an invitation and migration path with configuration review.
