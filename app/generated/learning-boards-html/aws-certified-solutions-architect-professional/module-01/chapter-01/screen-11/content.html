Hands-on

Terminal-style steps

# Sign in to management account with organizations:* permissions
# Open AWS Organizations
# Create organization — Enable all features
# Select Root → Actions → Create new organizational unit
# Name: Workloads
# Repeat: Create OU named Security
# Select Workloads → Actions → Add AWS account → Create AWS account
# Provide Account name: DevAccount-001; Email: unique@example.com
# Wait for creation to complete and verify under Accounts
Hint
Plan SCPs and tags before creating accounts to ensure governance and cost attribution from day one.
Common mistake
Not configuring centralized logging to a Security account; remember to set log exports and retention policies.
