Encryption in transit
Require TLS everywhere
Enforce TLS for external clients and internal service-to-service traffic. Use load balancers, API gateways, or service meshes to ensure encryption and authentication.
Checklist
  • Enable TLS on ALBs and API endpoints.
  • Use mutual TLS or service mesh for sensitive internal traffic.
  • Keep certificates and rotation policies automated.
Sensitive data discovery
Amazon Macie for PII detection
Use Macie to scan S3 and identify PII or other sensitive content. Forward findings to Security Hub for prioritized remediation.
Example
Macie flags S3 objects containing PII. Security Hub correlates the evidence with Config to show whether the bucket is encrypted and access controls are correct.
Common mistake
Assuming transit encryption only matters at the network edge; internal service communications often carry sensitive data too.
