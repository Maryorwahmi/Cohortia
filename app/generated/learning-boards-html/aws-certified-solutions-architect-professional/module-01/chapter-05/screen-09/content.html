Module 1 › Chapter 1.5 › Enforcement Mechanisms
Service Control Policies
Preventative guardrails
SCPs restrict API operations across accounts; use them to stop risky actions before resources change.
Example: Block s3:PutBucketPolicy that allows public access.
AWS Config
Detective controls
Detect drift from baselines and produce auditable evidence for compliance reporting.
Example: s3-bucket-server-side-encryption-enabled rule flags noncompliant buckets.
CloudFormation StackSets
Deployment automation
Automate consistent provisioning of logging buckets, IAM roles, or Config aggregators across many accounts.
Example: Deploy a CloudTrail aggregator role and immutable S3 bucket to all accounts.
Key takeaway
Use SCPs to prevent, Config to detect and prove, and StackSets to deploy the control plane—combined they enforce consistent security at scale.
