Three-step baseline process
1
Define
Choose mandatory settings: MFA, encryption by default, CloudTrail centralization, and VPC Flow Logs.
2
Deploy
Use SCPs for preventative guardrails, Config rules for detection, and StackSets or Organizational Config Rules to scale deployments.
3
Verify
Centralize logs, review Security Hub compliance checks, and remediate findings with automated playbooks where possible.
Example
To prevent public S3 buckets, use an SCP to restrict the API surface, deploy an Organizational Config Rule to detect violations, and alert via Security Hub.
Supporting cards
Why combine guardrails?
Preventive guardrails reduce the chance of misconfiguration while detection catches drift; both are required for strong baselines.
Common mistake
Relying on human reviews rather than automated enforcement and continuous verification.
Key Takeaway
A repeatable define-deploy-verify cycle prevents drift and keeps baselines enforceable across many accounts.
