Module 1 › Chapter 1.5 › Learning Objectives
01 Central enablement
Enable GuardDuty and delegate an admin
You will enable GuardDuty in the management account and delegate a member account to manage findings across the Organization, reducing permission sprawl and separating duties.
VERIFIED COMPETENCY MILESTONE
02 Organizational Config
Create Organizational Config Rules
Deploy a rule like s3-bucket-server-side-encryption-enabled to all accounts via Organizations integration so rules are consistent and auditable.
VERIFIED COMPETENCY MILESTONE
03 Central logging
Centralize CloudTrail and Flow Logs
Collect API and VPC flow logs in an immutable S3 bucket in a logging account to make investigations reliable and tamper-resistant.
VERIFIED COMPETENCY MILESTONE
04 Findings management
Review Security Hub findings
Use Security Hub's automated checks and the consolidated findings stream to prioritize remediation and link findings to Config and GuardDuty evidence.
VERIFIED COMPETENCY MILESTONE
