Module 1 › Chapter 1.5 › Centralized Logging
Central logging pattern
Collect CloudTrail from all accounts into an immutable S3 bucket in a dedicated logging account and include VPC Flow Logs for network context.
Implementation steps
  1. Enable organization-wide CloudTrail and set destination to the logging account bucket.
  2. Enable S3 object lock or other immutability mechanisms and restrict write/delete permissions.
  3. Enable VPC Flow Logs and route them to the same logging account for correlation.
Example investigation
An analyst uses CloudTrail entries in the logging bucket to trace when an API key was used, then uses VPC Flow Logs to check for suspicious outbound connections at the same timestamp.
Common mistake
Keeping trails and flow logs fragmented across accounts makes timelines incomplete and investigations slow or impossible.
Log sample
{ "eventTime": "2023-01-01T12:00:00Z",
  "eventName": "CreateUser",
  "userIdentity": { "arn": "arn:aws:iam::123456789012:user/Alice" }
}
Key Takeaway
Central, immutable logs are the foundation of forensic analysis and compliance reporting across many accounts.
