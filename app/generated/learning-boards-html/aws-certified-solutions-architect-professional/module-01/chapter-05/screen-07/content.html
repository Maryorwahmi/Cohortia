Module 1 › Chapter 1.5 › AWS Config
What Config does
Record configuration, evaluate rules, and provide evidence of compliance or drift.
Baseline examples
  • All S3 buckets have server-side encryption enabled.
  • All EBS volumes are encrypted by default.
  • Security groups do not permit 0.0.0.0/0 on high-risk ports.
Deployment patterns
Use Organizations integration and Organizational Config Rules, or deploy rules using StackSets to ensure all member accounts inherit the baseline.
Example
An Organizational Config Rule flags newly created S3 buckets without default encryption; your pipeline uses that evidence to block deployment until fixed.
Supporting bullets
  • Config provides point-in-time snapshots of resource settings useful for audits.
  • Combine Config rules with SCPs for preventative guardrails and detective coverage.
  • Forward Config findings to Security Hub to correlate with behavioural alerts.
Common mistake
Creating non-centralized rules per account that drift over time; central deployment avoids inconsistencies.
Key Takeaway
Use AWS Config with Organizations to catch configuration drift at scale and provide auditable evidence for compliance checks.
