Module 11 › Chapter 11.1 › Edge Locations
What an Edge Location does
  • Terminate client connections close to the user.
  • Cache static and semi-static content for immediate delivery.
  • Forward cache misses to Regional Edge Caches or origin Regions over the AWS backbone.
Analogy: Edge Locations are like local post offices that hold common parcels for quick pickup instead of sending every request back to a central warehouse.
Scenario

A user in Tokyo loads a video thumbnail. The nearest PoP serves it instantly. If the PoP doesn't have it, the request goes to a Regional Edge Cache which often has a larger copy, reducing trips back to the origin Region.

Misconception
Edge Locations are not full Regions and should not be used for persistent compute or primary storage assumptions.
Key Takeaway: Use PoPs for frequently accessed static assets and connection termination to achieve the fastest user experience.
