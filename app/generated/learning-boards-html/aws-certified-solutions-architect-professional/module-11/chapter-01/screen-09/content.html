Module 11 › Chapter 11.1 › CLI: Regions & AZs
Commands to run
aws ec2 describe-regions --query 'Regions[].RegionName' --output text

aws ec2 describe-availability-zones --region us-east-1 --query 'AvailabilityZones[].ZoneName' --output text
These commands list Region names and AZ names so you can confirm deployment targets and script automation using accurate identifiers.
Concrete example

Run the first command to see available Regions. Choose one that has the services you need. Then run the second command with that Region to enumerate its AZs and use those AZ names in multi-AZ templates.

Misconception: AZ labels can map differently per account; always query the account you're operating in rather than assuming AZ names are globally identical.
Key Takeaway: Validating Regions and AZs via CLI avoids surprises during deployment and ensures your architecture's availability assumptions are grounded.
