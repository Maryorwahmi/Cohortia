Module 11 › Chapter 11.1 › Key Concepts — Part 1
AWS Region
Geographic area containing AZs for core compute and storage.
Availability Zone
Isolated data center(s) inside a Region designed for high availability.
Edge Location (PoP)
Near-user cache and connection termination point for low-latency delivery.
Summary Takeaway

Use Regions/AZs for durability and availability; use Edge Locations to reduce latency and protect origins with edge security.
