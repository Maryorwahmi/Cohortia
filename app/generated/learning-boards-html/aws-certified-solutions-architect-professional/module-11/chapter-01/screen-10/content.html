Layered architecture
Map workload types to infrastructure tiers. Durable state in Regions with multi-AZ replication, stateless compute across AZs for resilience, and cacheable assets at the edge.
Region & AZ
Databases, durable storage, and services that require strong consistency and locality.
Edge
Static assets, content delivery, connection termination, and early security filtering.
Example: S3 + CloudFront for static assets; EC2/RDS across AZs for application and data.
Checklist
  • Map each service by durability and latency needs.
  • Set cacheability and TTLs for edge-served assets.
  • Use Global Accelerator for non-HTTP low-latency traffic.
