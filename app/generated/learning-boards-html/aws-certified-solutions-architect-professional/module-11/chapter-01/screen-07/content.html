Module 11 › Chapter 11.1 › Global Accelerator & WAF
AWS Global Accelerator

Routes traffic through the AWS backbone from the nearest Edge Location to your application endpoint, improving performance for non-HTTP and latency-sensitive workloads.

Example: Multiplayer gaming traffic benefits from reduced jitter and fewer public internet hops when using Global Accelerator.
AWS WAF at the Edge

Filter malicious traffic at the edge to stop attacks before they consume origin resources, helpful for DDoS mitigation and common web exploits.

Key Takeaway: Use Global Accelerator for path optimization and WAF at the edge to prevent harmful traffic from reaching your origin.
Misconception
DNS geolocation does not ensure the best network path; Global Accelerator provides optimized routing through AWS network backbone.
Pro tip
Combine WAF with CloudFront to block bad traffic at the PoP and reduce origin costs.
Check
Measure latency and origin request volume before and after enabling edge services to validate benefit.
