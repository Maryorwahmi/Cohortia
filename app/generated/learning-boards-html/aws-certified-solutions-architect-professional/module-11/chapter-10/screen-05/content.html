Module 12 › Chapter 11.10 › CloudFront Access Logs
Log anatomy
  • Viewer IP: locate affected client regions.
  • Date/Time, Method, URI: reproduce the request.
  • Status & Bytes: detect errors or heavy transfers.
  • x-edge-result-type: Hit vs Miss classification.
  • TLS fields: diagnose certificate or protocol issues.
Common mistake
Assuming 'Miss' equals origin failure. Often a Miss results from a changed cache key or forwarded query strings; check request URI and query parameters first.
Example excerpt
2026-09-01 12:02:33 ABCDE12345 example.com GET /index.html?rand=123 200 1024 "-" "Mozilla/5.0" Miss 0.002 x-edge-response-result-type:Miss
Investigation
Filter for x-edge-result-type:Miss and group by query string to find whether unique parameters cause misses.
Next step
If many unique query parameters appear, review cache policy for unnecessary forwarded query strings and revert or tighten policy.
