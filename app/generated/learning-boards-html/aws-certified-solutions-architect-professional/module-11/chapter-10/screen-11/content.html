Module 12 › Chapter 11.10 › Proactive Monitoring
Dashboard design
Include CloudFront CacheHitRatio and OriginErrorRate, Route 53 health-checks, and Global Accelerator HealthyEndpointCount. Add a compact log-search panel or a link to access logs to pivot quickly from metric to evidence.
Alarm tuning
  • Require multiple evaluation periods (for example 3 of 5) to avoid flapping alerts.
  • Use composite alarms to combine signals like low CacheHitRatio and high OriginErrorRate.
  • Alert on CloudTrail events for configuration changes that could cause incidents.
Concrete alarm example
Create a CloudWatch alarm: metric CacheHitRatio, condition Lower/Equal, threshold 80, datapoints to alarm 3 out of 5, action: notify SNS topic.
Pro-tip
Combine metric alarms with CloudTrail alerts to know whether a bad configuration change preceded the metric anomaly.
Check
Review alarm noise quarterly to adjust thresholds and keep signal quality high.
