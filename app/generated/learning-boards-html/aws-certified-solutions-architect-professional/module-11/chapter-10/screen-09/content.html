Module 12 › Chapter 11.10 › Global Accelerator Metrics
Key metrics
  • HealthyEndpointCount: number of endpoints considered healthy.
  • UnhealthyEndpointCount: number marked unhealthy by checks.
  • BytesIn / BytesOut: accelerator throughput.
  • ActiveFlowCount: concurrent network flows, useful for capacity insight.
Misconception
Global Accelerator indicates endpoint state but does not replace direct checks of ALB/NLB target health or instance metrics. Always inspect resources beneath the accelerator.
Example
If HealthyEndpointCount falls for eu-west-1, check ALB target groups and instance health in that region. Security group rules blocking health-check traffic can also cause endpoints to be marked unhealthy.
Pro-tip
Cross-reference Global Accelerator metrics with CloudWatch metrics of the underlying load balancer for faster root cause identification.
Check your understanding
If ActiveFlowCount is rising but HealthyEndpointCount is stable, what might you investigate? (Answer: capacity constraints on endpoints or traffic spikes.)
