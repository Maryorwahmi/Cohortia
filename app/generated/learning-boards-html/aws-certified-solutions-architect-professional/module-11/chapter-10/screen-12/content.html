Module 12 › Chapter 11.10 › CLI Checks
CloudWatch example
# Replace DISTRIBUTION_ID with your ID
aws cloudwatch get-metric-statistics \
  --namespace AWS/CloudFront \
  --metric-name CacheHitRatio \
  --dimensions Name=DistributionId,Value=DISTRIBUTION_ID \
  --start-time 2026-09-01T11:00:00Z \
  --end-time 2026-09-01T12:00:00Z \
  --period 300 --statistics Average --unit Percent
Route 53 health check
# Replace HEALTH_CHECK_ID with your check ID
aws route53 get-health-check-status --health-check-id HEALTH_CHECK_ID
Run both commands to see if CacheHitRatio dropped while Route 53 reports the endpoint Unhealthy. If CacheHitRatio dropped but health is healthy, focus on cache policy and access logs; if health is Unhealthy, examine DNS and endpoint reachability.
