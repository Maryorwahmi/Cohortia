What to validate
  • • Dashboards that show CacheHitRatio, OriginErrorRate, and health-check status together.
  • • CloudTrail trails for configuration changes to distributions and hosted zones.
  • • Query logs and dig/nslookup checks from multiple locations for DNS issues.
A solid validation plan includes alarms that minimize false positives, a dashboard for triage, and an audit trail to find the who and when of changes. Practice scenarios will confirm each objective.
