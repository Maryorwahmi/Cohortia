Module 12 › Chapter 11.10 › Route 53 Health Checks
Definition
Health checks periodically probe endpoints and report state. They are used by Route 53 to make failover and routing decisions. Query logs capture DNS queries for hosted zones and are useful for auditing and troubleshooting resolution problems.
Checklist
  • Is the health check targeting the right host and path?
  • Are thresholds for unhealthy status appropriate to avoid flapping?
  • Are private hosted zones associated with the correct VPCs for hybrid DNS?
Example & troubleshooting
If failover does not trigger, run dig from multiple regions to see if the record resolves and inspect the health check status. A health check that uses the wrong URL path may return 200 but still be functionally invalid for failover.
Pro-tip
Use shorter TTLs for records you expect to update frequently, but be mindful of increased query volume.
Check
For private zones, verify VPC associations and that network connectivity (Direct Connect/VPN) is active for hybrid resolution.
