CloudFront edge compute options

Use the edge to personalize content, reduce origin load, and apply security rules with JavaScript that runs earlier in the request lifecycle.

Lambda@Edge
Regional Lambda extended to run at edge events. Suited for complex logic and network calls.
CloudFront Functions
Tiny JavaScript running in the PoP for sub-millisecond transforms and header changes.
Why choose one?
Trade latency, cost, and capability: network calls and longer runtime favor Lambda@Edge; scale and latency favor Functions.
In this lesson: you will inspect event types, limits, code examples and a short lab to implement a URL rewrite with a CloudFront Function.
