Module 11 › Chapter 11.4 › Service Comparison
CloudFront Functions
  • Run in PoP, sub-millisecond latency.
  • JavaScript only, ~1 ms limit, ~2 MB memory, no network access.
  • Best for URL rewrites, headers, IP checks, A/B splits at scale.
Lambda@Edge
  • Runs in regions closest to PoP, supports Node.js and Python.
  • Execution time up to 5s (viewer) or 30s (origin), network calls allowed, memory limits apply.
  • Best for authentication checks calling external APIs or heavy transforms.
Cost
CloudFront Functions are cheaper per invocation. For very high traffic, cost favors Functions for simple logic.
Scale
Functions excel at massive request volumes due to minimal overhead; Lambda@Edge scales but with higher cost and replication behavior.
Decision checklist
Ask: Do I need network calls? Is the logic tiny and stateless? Will this run at very high volume? Use checklist to select service.
