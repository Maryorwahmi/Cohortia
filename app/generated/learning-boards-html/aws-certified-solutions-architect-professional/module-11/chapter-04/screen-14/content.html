Lambda@Edge
Regionally executed Lambda with network access for complex edge logic.
CloudFront Functions
Tiny JS in the PoP for ultra-low latency, no network calls and strict limits.
Event types
Viewer Request, Origin Request, Origin Response, Viewer Response define when you can run logic.
Summary Takeaway
Choose the least-powerful service that meets your needs, test under realistic scenarios, and instrument logs and metrics to manage cost and reliability.
