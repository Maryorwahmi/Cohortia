Module 11 › Chapter 11.4 › Edge Compute Rationale
Definition

Edge compute runs code at CloudFront locations to inspect and mutate requests and responses before they traverse the network to origin servers.

Latency: sub-millisecond opportunities for critical request handling.
Origin load: fewer requests to back-end services and lower bandwidth.
User experience: faster first meaningful paint through early rewrites and routing.
Concrete example: URL rewrite

A CloudFront Function can canonicalize '/about' to '/about/index.html', saving an origin lookup and avoiding a redirect response. This improves latency and reduces origin hits.

Misconception
Not every task belongs at the edge. Heavy computation and stateful work should stay at origin or regional services.
Try this
Pick a simple request transform in your app and estimate whether it needs network access; if it doesn't, consider moving it to a CloudFront Function.
