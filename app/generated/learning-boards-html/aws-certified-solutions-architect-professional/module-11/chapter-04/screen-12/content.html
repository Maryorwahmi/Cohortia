Module 11 › Chapter 11.4 › Deploy & Monitor
Deployment steps
  1. Author and test function in console.
  2. Publish CloudFront Functions; associate with distribution behaviors.
  3. For Lambda@Edge, deploy in required region and grant logging permissions.
Testing & Monitoring
  • Use the function Test feature for representative events.
  • Enable CloudWatch logs for Lambda@Edge and inspect real-time CloudFront logs for traffic patterns.
  • Track invocation counts and errors to manage cost and reliability.
Pitfall
Not verifying behavior during cache hits can hide header or rewrite issues. Test both cache-hit and cache-miss cases.
