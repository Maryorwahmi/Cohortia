Module 11 › Chapter 11.7 › What is AWS Global Accelerator?
Core Concept
Network-layer routing with fixed IPs

Global Accelerator gives two static, anycast IP addresses and routes user traffic into the AWS network at the nearest edge location. It is focused on TCP and UDP performance, not caching.

Concrete example: A multiplayer game uses UDP and benefits from reduced jitter when players hit the nearest edge.
Misconception: Not a CDN. Do not use it to replace CloudFront for static asset caching.
Operational tip: Static anycast IPs allow client whitelisting across regions.
Key Takeaway

Global Accelerator optimizes the network path for non-HTTP/S and dynamic workloads by using the AWS backbone and static anycast IPs for consistent connectivity.

Annotated flow
User connection
Client opens a TCP/UDP connection to the accelerator's static anycast IP. The address is advertised from multiple edge locations.
Edge entry
Traffic enters the AWS edge point of presence, then travels on the AWS global backbone towards the selected region.
Origin reach
Traffic arrives at the healthy endpoint in a region (ALB, NLB, EC2, EIP). Global Accelerator continuously checks endpoint health and reroutes if necessary.
Scenario card
Imagine players worldwide connecting to a UDP game server. With Global Accelerator, their packets enter the network at the closest edge point, reducing packet travel across congested public links and improving responsiveness.
