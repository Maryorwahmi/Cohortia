Module 11 › Chapter 11.7 › Global Accelerator vs CloudFront
AWS Global Accelerator
Layer 4 routing: TCP/UDP. Provides static anycast IPs, optimized backbone routing, and fast failover for dynamic and non-HTTP/S workloads.
Use cases: gaming, VoIP, IoT, global APIs needing static IPs.
Strength: predictable network path and quick reroute without DNS delays.
Amazon CloudFront
Layer 7 CDN: caches HTTP/S content at edge locations. Great for static assets and reducing origin load through caching.
Use cases: websites, video streaming, static content delivery, API response caching.
Strength: caching reduces origin requests and improves perceived request latency for cached items.
Decision guide
Need Layer 4 optimization → Global Accelerator
Need caching and edge logic → CloudFront
Need both? Use both services together for complementary strengths.
