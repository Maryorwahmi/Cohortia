AWS Global Accelerator
Network-layer performance and availability with fixed anycast IPs and fast failover.

Global Accelerator routes user traffic into the AWS backbone at edge points, giving you predictable IPs and better latency for TCP/UDP workloads that do not benefit from CDN caching. You'll learn components, differences from CloudFront, and patterns for global deployment.

Visual summary
Static IPs · Edge entry · AWS backbone
Accelerator: two static anycast IPs
Listener: TCP/UDP and port ranges
Endpoint Groups: regional routing + traffic dial
In this lesson
Compare, configure, and design global routing with Global Accelerator
Interactive 16:9 Masterclass
Why use it
Predictable IPs, lower latency, fast failover for non-HTTP/S traffic.
Design patterns
Active/active, active/passive with traffic dial for DR.
Compare
Global Accelerator is Layer 4; CloudFront is Layer 7 CDN.
