Module 11 › Chapter 11.7 › Listeners
Definition
Listener = protocol + ports

Configure a listener for TCP or UDP and specify port(s) or ranges. The listener controls what the accelerator accepts from clients and forwards to endpoint groups.

Example: TCP ports 80 and 443 for web traffic.
Tip: Match listener protocol and ports to the endpoint’s configuration to avoid linkage errors.
Pitfall: Do not expect Layer 7 handling like TLS termination or caching.
Configuration checklist
  • Choose protocol: TCP for reliable streams, UDP for low-latency datagrams.
  • Define ports or port ranges used by your application.
  • Ensure endpoints in endpoint groups accept the same protocol and ports.
Scenario card
A streaming game service uses a UDP port range for in-game telemetry and a TCP listener for control messages. Configure separate listeners if needed to segregate traffic types.
