Module 11 › Chapter 11.7 › Accelerator & Static IPs
Definition
Accelerator: two static anycast IPs

When created, an accelerator receives two global anycast IP addresses. They act as fixed entry points, advertised from AWS edge locations worldwide so clients can connect without per-region DNS changes.

Why two IPs: redundancy in routing announcements and easier operational failover.
Whitelisting use case: corporate firewalls can permit accelerator IPs once for global access.
Misuse: not a replacement for CDN caching or Layer 7 features.
Operational checklist
  • Confirm accelerator IPs are noted and distributed to partners for whitelisting.
  • Verify security groups allow inbound from Global Accelerator health check addresses.
  • Do not expect Layer 7 caching or header rewrites at the accelerator level.
Scenario
A B2B API requires partner firewalls to whitelist source IPs. Using an accelerator means partners whitelist two global IPs once, instead of many region-specific addresses.
