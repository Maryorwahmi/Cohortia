Module 11 › Chapter 11.7 › Key Concepts
AWS Global Accelerator
A network-layer service that improves performance and availability using the AWS global backbone.
Accelerator & IPs
Each accelerator provides two static anycast IPs for consistent global entry and whitelisting.
Listeners & Endpoint Groups
Listeners accept TCP/UDP ports; endpoint groups map listeners to regions and use traffic dials to control distribution.
Summary
Global Accelerator is the right choice when you need network-layer optimization, static IPs, and rapid failover for global, dynamic traffic. It complements CloudFront rather than replacing it.
