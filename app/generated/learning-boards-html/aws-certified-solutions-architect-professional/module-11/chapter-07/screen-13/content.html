Module 11 › Chapter 11.7 › Lab Walkthrough
Console steps (summary)
  1. Create two minimal web servers and ALBs in Region A and Region B, each serving a region-specific page.
  2. Create a Global Accelerator, note the two static IP addresses.
  3. Add a TCP listener for port 80 and create endpoint groups for each region.
  4. Register each ALB as an endpoint in its region and set traffic dials as required.
  5. Test: curl the static IP and observe the region-specific response; simulate an outage and validate automatic failover.
Testing tip
Use curl to verify the body content shows the region identifier and stop one backend to watch rerouting behavior. Check that health probes are permitted through security groups.
Terminal-style command examples
curl -v http://<GLOBAL_ACCELERATOR_IP>
# Expect body: "Hello from Region A" or "Hello from Region B"

# Simulate failure by stopping instance in Region A
# Then curl again and observe response from Region B
Key Takeaway

Validate that the static IP returns region-specific responses and that failover happens when endpoints become unhealthy.
