Module 11 › Chapter 11.7 › How traffic travels
Process Flow
  1. Client connects to accelerator IPs. Two static anycast IPs are the fixed entry point clients use.
  2. Traffic enters nearest edge location. Edge Locations advertise the anycast IPs so clients hit the closest ingress.
  3. Traffic moves on AWS backbone. The optimized private network carries packets toward your selected region.
  4. Global Accelerator routes to healthy endpoints. Continuous health checks steer traffic away from unhealthy endpoints without DNS propagation.
Example: VoIP sessions experience fewer packet drops because ingress bypasses congested public links.
Misconception: it does not remove distance — long-haul latency still exists, but path variability is reduced.
