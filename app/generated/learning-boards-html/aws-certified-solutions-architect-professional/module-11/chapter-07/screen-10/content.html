Module 11 › Chapter 11.7 › Endpoints
Supported endpoints and guidance
Application Load Balancer (ALB): good for HTTP/S origins that need Layer 7 routing.
Network Load Balancer (NLB): suited for TCP/UDP, high throughput, low latency.
EC2 instance: direct target when running services on instances.
Elastic IP (EIP): use when you need a fixed public IP per endpoint.
Health checks: ensure endpoints respond on expected probe ports and paths so Accelerator correctly identifies unhealthy targets.
Security note: open security groups and NACLs to allow health probes and traffic from the Global Accelerator service ranges.
Scenario
If you need path-based routing at the application layer, place an ALB behind the accelerator. If you need raw TCP or UDP forwarding, use an NLB for minimal processing latency.
