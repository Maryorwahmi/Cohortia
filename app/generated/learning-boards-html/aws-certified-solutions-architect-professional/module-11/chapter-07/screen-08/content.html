Module 11 › Chapter 11.7 › Endpoint Groups & Traffic Dial
Process
An endpoint group ties a listener to a specific AWS Region. Inside each group you list endpoints and set a traffic dial percentage that controls regional traffic share.
Use case: Blue/green deploys — gradually increase the traffic dial for the new environment.
DR: Keep passive region at 0% then raise to 100% in a disaster for an instant shift without DNS TTL waits.
Operational tip
After adjusting dials, validate by checking region-specific response headers or logs and monitor health events to ensure no unintended rerouting.
Example: staged rollout
Start with 10% to a new region, observe metrics and error rates, then increment traffic dial to 50% and so on. If issues occur, roll back by lowering the dial immediately.
Common mistake
Incorrect dials can route unexpected traffic shares. Always document and test dial changes during maintenance windows.
