Module 11 › Chapter 11.7 › Multi-Region Active/Active
Architecture
Deploy identical application stacks across regions, add each region as an endpoint group, and allow Global Accelerator to route users to the nearest healthy region automatically.
Performance: users go to the nearest healthy region, reducing latency.
Resilience: rapid failover occurs without DNS changes, improving availability.
Operational caution
Active/active requires careful data replication and consistency strategies; validate state synchronization across regions before relying on this model.
Scenario card
Example: an e-commerce API deployed in two regions uses Global Accelerator to reduce checkout latency worldwide and to keep the service available if a region goes down.
Key Takeaway

Active/active with Global Accelerator routes users to the closest healthy region, but plan data and session consistency carefully.
