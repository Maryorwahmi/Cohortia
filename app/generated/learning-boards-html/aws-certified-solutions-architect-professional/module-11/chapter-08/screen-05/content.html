Web ACL anatomy
A Web ACL contains ordered rules and a default action for unmatched requests.
How rules are evaluated
  1. Requests are evaluated against the first rule. If it matches, the rule's action applies.
  2. If not matched, evaluation continues to the next rule in order.
  3. If no rules match, the Web ACL default action is applied (Allow or Block).
Best practice
Place Managed Rule Groups early for broad protections, then add targeted custom rules for your application logic. Always review rule order after adding groups.
Managed Rule Groups
AWS-managed groups like CommonRuleSet and BotControl are updated by AWS to address evolving threats.
Advantages
  • Reduced maintenance overhead compared to custom rules.
  • Regular updates for emerging attack patterns.
  • Quick baseline coverage across common exploits.
Example setup
Attach AWSManagedRulesCommonRuleSet and AWSManagedRulesBotControlRuleSet to your Web ACL, set them initially to COUNT, tune, then change to BLOCK when safe.
