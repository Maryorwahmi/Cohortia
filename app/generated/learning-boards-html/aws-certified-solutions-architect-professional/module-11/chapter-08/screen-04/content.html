Module 11 › Chapter 11.8 › What is AWS WAF?
Definition and purpose
WAF evaluates HTTP/S requests and applies allow, block, or count actions based on rules.
Analogy
Think of WAF as a bouncer at the edge: it checks visitor attributes against a guest list and policies before allowing entry to the venue. It can also keep a log of suspicious visitors for later review.
Key bullets
  • Inspects IP, headers, query strings, URI and request body.
  • Applies rules in a Web ACL with a default action for unmatched requests.
  • Supports allow, block, and count actions for safe testing.
Key Takeaway

WAF is your first line of application-layer defense, inspecting requests before they reach backend services.

Concrete example
Protect a public website by creating a Web ACL for the CloudFront distribution, attach Managed Rule Groups for SQLi and bot control, and add a rate-based rule to deter credential stuffing against the login endpoint.
Common misconception: WAF solves all DDoS — false. WAF handles application-layer threats; Shield handles volumetric attacks.
Check your understanding
