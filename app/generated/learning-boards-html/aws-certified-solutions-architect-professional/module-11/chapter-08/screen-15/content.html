Module 11 › Chapter 11.8 › Key Concepts
AWS WAF
Web application firewall that filters HTTP/S requests based on rules.
Web ACL
An ordered collection of rules with a default action for unmatched requests.
Managed Rule Groups
Prebuilt rule sets maintained by AWS to address common exploits and bots.
Summary takeaway

Use WAF at the edge with Managed Rule Groups as a baseline, test rules in COUNT mode, and document rule order for predictable behavior.
