Rate-based rule
Counts requests per IP over five minutes; scope to endpoints to reduce collateral blocks.
Shield tiers
Standard is automatic; Advanced adds DRT access, cost protection and advanced diagnostics for critical apps.
Logging & metrics
Enable WAF logs and CloudWatch metrics to tune rules and confirm protections are working as intended.
Final takeaway

Combine scoped detection rules, shield protections for volumetric attacks, and continuous logging to create a resilient edge security posture.
