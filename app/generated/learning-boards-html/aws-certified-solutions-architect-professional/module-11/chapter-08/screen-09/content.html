Module 11 › Chapter 11.8 › WAF + CloudFront
Why CloudFront
CloudFront is the global CDN edge, so applying WAF here filters malicious traffic before it reaches regional origins.
Integration steps
  1. Create a Web ACL in Global (CloudFront) region.
  2. Add Managed Rule Groups in COUNT mode and any custom rules.
  3. Associate Web ACL with your CloudFront distribution.
  4. Enable logging to CloudWatch or S3 for validation.
Example test flow
After associating the Web ACL, simulate a SQLi or XSS string against your distribution and verify CountedRequests increase in the WAF console. When confident, change actions to BLOCK.
Pitfall: Creating the Web ACL in a regional region by mistake will prevent association with CloudFront. For CloudFront, use Global.
