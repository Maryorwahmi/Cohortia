Module 11 › Chapter 11.8 › ALB & API Gateway
ALB scenarios
Use WAF on ALBs for internal or regional applications not served via CloudFront. Web ACLs must be in the same region as the ALB.
Benefits
  • Stops malicious payloads at the regional boundary.
  • Prevents attack traffic from reaching backend instances.
API Gateway scenarios
Protect REST and WebSocket APIs from injection and abuse. WAF evaluates API requests similar to web requests and can block suspicious payloads or bots.
Operational note: For APIs with global reach, consider a CloudFront distribution in front of the API to apply global protections, otherwise use regional Web ACLs for API Gateway.
