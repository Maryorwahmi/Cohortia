Rule types at a glance
IP set
Blocks or allows specific IPs or CIDR ranges. Use for known bad sources or corporate allow-lists.
String / Regex match
Inspect headers, query strings, URIs or body. Regex suits complex patterns but test carefully.
Size constraint
Prevent unusually large payloads or extremely small requests used for probing.
Specialized protections
SQLi / XSS rules
Pre-configured detectors for common injection patterns. Good baseline protection.
Rate-based rules
Count requests per IP in five minutes and block if threshold exceeded. Useful for brute-force protection.
Tip: Start in COUNT mode for any new rule, and check logs to reduce false positives before switching to BLOCK.
