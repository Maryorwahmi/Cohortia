Module 11 › Chapter 11.8 › Console Walkthrough
Step-by-step
  1. Create Web ACL in Global (CloudFront) region named MyCloudFrontWebAppACL.
  2. Add AWSManagedRulesCommonRuleSet and AWSManagedRulesBotControl in COUNT mode.
  3. Associate Web ACL with CloudFront distribution and wait for deployment.
  4. Simulate SQLi/XSS tests and check CountedRequests metrics.
  5. Tune rules and switch to BLOCK when safe.
Console notes
Always use a staging or low-risk test endpoint for simulated attacks, and ensure logging is enabled to inspect request samples before changing actions to BLOCK.
