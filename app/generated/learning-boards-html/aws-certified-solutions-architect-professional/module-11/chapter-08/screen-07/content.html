Module 11 › Chapter 11.8 › Request Evaluation
Step-by-step evaluation
  1. WAF receives the HTTP/S request at the associated resource.
  2. Evaluate against the first rule in the Web ACL.
  3. If matched, apply rule action and stop further evaluation.
  4. If no rules match, apply the Web ACL default action.
Operational check: After changing rule order or adding groups, validate behavior in COUNT mode and inspect metrics.
Scenario
You attach the AWSManagedRulesCommonRuleSet first, then a custom rule to allow a partner's IP range. If the managed rule blocks a request from that partner, re-evaluate order or add a more specific allow rule earlier to prevent false blocking.
Common mistake
Assuming default action applies before rules. In reality, rules are evaluated first and default action only used when no rule matches.
Key Takeaway

Document rule order and test in COUNT mode; correct ordering prevents unintended blocks.
