Learning Objectives
Progress from configuration to monitoring so you can optimize performance and security at the edge.
01
Cache Policies
Design managed and custom cache policies

Create policies that set TTLs and choose which headers, cookies, and query strings form the cache key so static assets remain cacheable and dynamic content stays fresh.

VERIFIED COMPETENCY MILESTONE
02
Compression
Enable Gzip and Brotli at the edge

Use edge compression to reduce bytes transferred. Choose Brotli for better ratios on static text assets, but avoid double compression from both origin and CloudFront.

VERIFIED COMPETENCY MILESTONE
03
WAF Integration
Protect at the edge with AWS WAF

Attach a Web ACL to CloudFront to filter SQL injection, XSS, bots, and rate-based threats before they reach your origin.

VERIFIED COMPETENCY MILESTONE
04
Monitoring & Origin
Analyze metrics and secure origin access

Use CloudWatch metrics and access logs to diagnose cache hit ratios and origin errors, and configure custom headers or Origin Shield for better origin protection and scaling.

VERIFIED COMPETENCY MILESTONE
