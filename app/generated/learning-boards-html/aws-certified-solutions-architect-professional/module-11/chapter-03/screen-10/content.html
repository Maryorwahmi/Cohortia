How WAF works with CloudFront

Attach a Web ACL to your CloudFront distribution in the Global scope. Rules evaluate requests at the Edge and take actions like Count, Allow, or Block before the request reaches your origin.

Managed Rules
Use AWSManagedRulesCommonRuleSet to catch common exploit patterns.
Custom Rules
Add IP blacklists, rate-based rules, or application-specific patterns.
Best practice: start with Count mode to measure potential false positives, then promote rules to Block once you confirmed expected traffic is unaffected.
Concrete example
Create a Global Web ACL named MyCloudFrontWAF, attach your distribution, add AWSManagedRulesCommonRuleSet and BotControl, keep them in Count initially, and monitor CloudWatch metrics.
Misconception check
WAF is not a substitute for secure application code or origin access controls; it is an edge-layer filter that reduces origin exposure.
